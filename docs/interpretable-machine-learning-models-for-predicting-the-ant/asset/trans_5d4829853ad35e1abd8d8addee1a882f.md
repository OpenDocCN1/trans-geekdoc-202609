### 2.1.3 数据补充。

为解决数据集中缺失值，本研究采用基于 Jaccard 相似系数 的插补方法，通过以下步骤实现：（i）相似性计算阶段：对于每个包含缺失值的数据样本，计算其完整特征与所有其他样本之间的 Jaccard 相似系数；（ii）插补执行阶段：选择与缺失样本 Jaccard 相似系数最高的完整样本，并使用其对应的特征值进行插补。该插补过程所使用的算法以及完整的机器学习工作流程可在“数据可用性”部分列出的 GitHub 仓库中获取。

在本研究中，数据点之间的相似性使用 Sφ 系数（公式（1））和 Jaccard 相似系数（公式（2））进行衡量。相似性指标基于列联表（表 1）。

表 1 中：a 表示两个变量均为 1 的位置数。b 表示第一个变量为 1 而第二个变量为 0 的位置数。c 表示第一个变量为 0 而第二个变量为 1 的位置数。

## 2.2 机器学习

### 2.2.1 Light Gradient Boosting Machine (LightGBM)。

LightGBM 是一种高效的梯度提升框架，利用基于直方图的学习算法有效处理大规模和高维数据。在本研究中，进行了网格搜索以优化关键参数，如学习率、树深度和叶节点数。最佳参数组合通过交叉验证选择，并使用优化后的 LightGBM 模型进行模型构建和性能评估。

### 2.2.2 卷积神经网络 (CNN)。

卷积神经网络（CNNs）是为从一维数据中自动提取特征和分类而设计的深度学习模型。该架构包含两个卷积层，分别使用 32 和 64 个滤波器，核大小为 3。每个卷积层后均跟随一个最大池化层（池化大小为 2），以降低特征图的维度。在卷积和池化操作之后，数据被展平并通过两个全连接层处理。最终输出通过 sigmoid 激活函数获得，有助于二分类。该模型灵活，可适应不同的输入维度。

### 2.2.3 多层感知机 (MLP)。

多层感知机（MLP）是一种经典的前馈神经网络，可学习输入特征之间的非线性关系。该模型包含三个全连接层，其中输入特征首先通过一个包含 128 个神经元的层，然后是包含 64 个神经元的隐藏层，最后是产生单一预测的输出层。输出层应用 sigmoid 激活函数进行二分类。MLP 特别适合处理展平的输入数据，并捕捉描述符之间复杂的非线性关系以做出准确预测。

### 2.2.4 随机森林 (RF)。

随机森林是一种基于决策树的集成方法，对处理高维特征具有鲁棒性和有效性。在本研究中，使用了 WEKA 实现的随机森林，基于默认数量构建树并随机选择特征。个别树的多数投票（分类）或平均计算（回归）产生最终预测。该方法作为比较复杂非线性数据的基线模型。

### 2.2.5 极限梯度提升 (XGBoost)。

XGBoost 是梯度提升的高效实现，具有强大的正则化和并行计算能力。在本研究中，XGBoost 使用默认参数，包括固定的学习率和最大树深度，以评估其在数据集上的预测能力。

### 2.2.6 支持向量机 (SVM)。

支持向量机（SVM）利用核函数将数据映射到更高维空间，以最大化间隔优化分类边界。本研究中使用了径向基函数（RBF）核，正则化参数设置为默认值。SVM 用于建模描述符数据中的线性可分性和复杂边界。

### 2.2.7 逻辑回归。

逻辑回归是一种基于 sigmoid 函数输出概率的线性分类方法。在本研究中，逻辑回归作为基线模型使用，未调整正则化参数以评估描述符的线性可分性。

### 2.2.8 k-最近邻 (kNN)。

k-最近邻（kNN）是一种基于实例的预测方法，其中目标样本被分配其在特征空间中 k 个最近邻居的多数类（分类）或均值（回归）。k 的最佳值通过交叉验证自动选择，距离度量采用欧几里得距离。

### 2.2.9 朴素贝叶斯。

朴素贝叶斯是一种基于贝叶斯定理的分类方法，假设特征之间相互独立。在本研究中，模型假设描述符之间条件独立，并输出分类的后验概率。

## 2.3 模型验证与评估

模型的准确性通过五折交叉验证以及对测试集的预测来估计。测试集通过对一系列合成金属氧化物纳米颗粒的细胞实验获得。

为评估模型的性能，计算了以下指标：ROC、AUC、精确率、召回率、F1 分数和平衡准确率。此外，还绘制了混淆矩阵以评估分类性能，显示正确分类的实例数量以及被错误分类的化合物（假阳性和假阴性）。

计算参数的公式如下：

灵敏度（Sn），也称为真正率，衡量模型正确识别的实际阳性比例。

Sn = TP/(TP + FN)

其中 TP 为真正例数，FN 为假负例数。

特异性（Sp），也称为真负率，衡量模型正确识别的实际阴性比例。

Sp = TN/(TN + FP)

其中 TN 为真负例数，FP 为假阳例数。

精确率（Pr）衡量阳性预测中实际正确的比例。

Pr = TP/(TP + FP)

召回率（R）等同于灵敏度（Sn），因为它也衡量正确识别的实际阳性比例。

Recall = Sn

F1 分数是精确率和召回率的调和平均值，在两者之间提供平衡。

F1 = 2 × (Pr × recall)/(Pr + recall)

平衡准确率（AC）是灵敏度和特异性的平均值，在类别分布不平衡时提供分类质量的单一指标。

AC = 0.5 × (Sn + Sp)

这些指标使用标准 Python 库计算，允许在纳米颗粒毒性预测的背景下全面评估模型性能。

## 2.4 合成实验

### 2.4.1 ZnO。

将 98 mL 无水乙醇加入 250 mL 圆底烧瓶中，并使用油浴加热至恒定 80 °C。向烧瓶中加入 0.577 g SDS 并搅拌至完全溶解。然后，迅速加入 2 mL 0.5 mol L−1 乙酸锌溶液，以 1 × 10−3 mol 乙酸锌引发反应。30 分钟后，停止加热，将样品冷却至室温并离心。用去离子水和无水乙醇至少洗涤三次所得粉末，然后风干得到白色粉末。

### 2.4.2 CdO。

将 1 g 硫酸镉（3CdSO4·8H2O）溶解于 50 mL 特氟龙衬里不锈钢高压釜中，加入 3 mL 30% 双氧水和 27 mL 蒸馏水。使用氨水调节溶液 pH 至 10，然后在烘箱中 100 °C 反应 12 小时。冷却后，过滤并用蒸馏水和无水乙醇洗涤，然后在空气中 80 °C 干燥 2 小时得到白色粉末。

### 2.4.3 Cu2O。

配制 CuSO4 反应溶液，并在水浴中搅拌下保持 70 °C。向 CuSO4 溶液中加入 1.6 g L−1 聚乙烯吡咯烷酮（PVP），随后加入 NaOH 溶液（2 mol L−1）。缓慢加入 N2H4·H2O 溶液。反应溶液由蓝色变为绿色，产生橙黄色沉淀。4 小时后，用无水乙醇洗涤沉淀，并在 70 °C 真空干燥 8 小时得到粉末样品。

### 2.4.4 CeO2。

将含有 Ce(NO3)3 的微乳液在磁力搅拌器上搅拌约 5 分钟，反应过程中通入 N2 气体。搅拌下加入含有氨水的微乳液，在 pH = 10 时形成淡黄色沉淀。
