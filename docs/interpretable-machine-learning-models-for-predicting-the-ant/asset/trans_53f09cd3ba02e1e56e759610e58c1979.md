为了训练我们的模型，我们选择了九种主流且具有代表性的机器学习算法，包括卷积神经网络（CNN）、74 多层感知机（MLP）、75 随机森林、76 极端梯度提升（XGBoost）、77 Light Gradient Boosting Machine（LightGBM）、78 支持向量机（SVM）、79 逻辑回归、80 k-最近邻（kNN）、81 和朴素贝叶斯。82

2765 个样本的数据集按 2:1 的比例划分为训练集和测试集，外部分验证集由后续实验数据组成。模型训练和评估使用 Python 3.9.13 实现，并采用 PyTorch、Scikit-learn、XGBoost 和 LightGBM 库。

鉴于数据集存在类别不平衡，模型评估主要集中于 F1 分数和受试者工作特征曲线下面积（AUC-ROC），因为在类别分布倾斜的情况下，这两个指标比准确率更具信息量。F1 分数被选为核心指标，因其能够平衡精确率和召回率，且特别强调召回率以减少假阴性并提高对有毒样本的敏感性。

为解决模型训练过程中的类别不平衡问题，我们采用了针对性策略：对于神经网络模型（CNN 和 MLP），应用了加权交叉熵损失，为少数类（有毒类）分配更高的权重。对于梯度提升模型（XGBoost 和 LightGBM），我们使用了统一的超参数（200 棵树，学习率 = 0.1，最大深度 = 8），因为这些模型通过分裂增益函数固有地缓解不平衡。其他分类器的参数则单独优化。SVM 和 kNN 作为基线方法被纳入，以评估在不平衡条件下的鲁棒性。

LightGBM 模型（一种集成决策树模型）中的全局贡献比较（图 6a）通过计算分裂节点处特征的频率和信息增益来评估特征重要性。重要性前十的特征为 concentration、diameter、zeta potential、exposure time、cells、coat、test、nanoparticle、n_o/∑x 和 CA。这些特征显著影响细胞存活率的预测，与研究人员的实验经验一致。然而，特征重要性并不能显示每个特征如何影响最终结果。因此，引入了 SHAP 值以进行进一步分析，揭示更多隐藏信息。
