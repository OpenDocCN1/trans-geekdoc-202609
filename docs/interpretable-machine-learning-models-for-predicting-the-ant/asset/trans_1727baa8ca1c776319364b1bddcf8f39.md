
# 用于预测金属和金属氧化物纳米材料抗肿瘤效应的可解释机器学习模型†

Youfu Ma,‡ Yu Jiang,‡ Houlin Su, Jiajia Lei, Wenguang Xiao, Haijun Tian, Yawei Ma, Li Zhu, Yuxi Liang, Lisheng Wang,* Mingqing Yuan* and Xu Liu*

理解金属和金属氧化物纳米颗粒（M/MOx NPs）的毒性行为对于有效肿瘤诊断和治疗至关重要，然而由于数据有限、采样变异、未报告的复杂性、低模型准确性和缺乏可解释性，泛化研究结果仍然具有挑战性。为解决这些问题并最大限度地减少大量实验，我们结合量子化学计算与已发表的毒性数据，开发了一种机器学习模型，在交叉验证中实现了超过90%的准确率。利用从152篇文献中提取的39个描述符，我们的数据集包含2765个实例，涵盖各种纳米颗粒类型、检测方法和细胞类型。我们利用Jaccard相似系数增强数据表示，并采用特征重要性和Shapley Additive Explanations（SHAP）来识别影响细胞毒性的关键因素，如浓度、暴露时间、zeta电位、直径、COSMO面积（CA）、包覆、测试方法、细胞类型、金属电负性、HOMO能量和分子量。此外，我们分析了这些特征之间的相互作用及其对预测的影响，合成了新型金属氧化物纳米颗粒，并评估了其物理化学性质和抗肿瘤毒性。利用新合成纳米颗粒进行的细胞毒性实验进一步验证了模型的准确性和泛化能力，揭示了隐藏的关系并能够对以前未见的样本进行预测。该方法支持初步计算机辅助筛选，显著减少了劳动密集型实验的需求。

## 1 引言

癌症仍然是全球主要的死亡原因，其发病率持续上升。1,2 纳米技术在应对常规疾病的诊断和治疗方面获得了越来越多的研究关注。3-6 特别是，金属和金属氧化物纳米材料在肿瘤的诊断和治疗中发挥着重要作用。7-10

纳米材料的毒性效应通常受其各种物理化学性质的影响，如尺寸、形状、表面积、化学组成和稳定性。11 在用于评估纳米材料毒性的各种生物学测定中，体外细胞毒性测定是最重要的毒理学测量方法之一。12 这些测定使用活细胞来观察和检测纳米材料的毒性效应，因其相对简单、快速且成本效益高而受到青睐。此外，由于细胞毒性测试不使用动物，因此避免了伦理问题。因此，已发表了大量关于纳米颗粒细胞毒性效应的研究。13-17 然而，纳米材料的复杂性和异质性、不同的测试条件、检测方法和细胞系使跨研究比较和分析变得复杂。此外，金属和金属氧化物纳米材料的体外和体内毒性评估可能非常耗时且成本高昂。

计算毒理学是体外和体内实验的替代方法，已广泛应用于毒理学研究。已开发并应用了各种计算机模拟方法，包括药理学建模、18 比较分子场分析、19,20 分子对接、21-23 分子动力学模拟、24,25 基于网络的算法、26-29 以及定量构效关系（QSAR）建模、30-40 和深度学习等机器学习方法。41,42

其中，机器学习最近已成为研究纳米材料细胞毒性最流行的方法之一。作为人工智能的一个分支，机器学习旨在开发计算算法从现有数据中推断数学模型，为加速所需纳米颗粒的开发提供有希望的工具。43 当应用于变量与未知结果之间的复杂关系时，机器学习可以揭示数据中的隐藏特征，为导致纳米毒性的特征提供更深入的见解。例如，研究人员使用偏最小二乘（PLS）回归建立了纳米-QSAR模型，发现电荷密度和表面电荷是金纳米颗粒外排的主要因素。44 另一项研究基于蛋白冠的组成，使用几种线性和非线性机器学习算法预测金纳米颗粒的生物活性，确定了促进或抑制细胞关联的关键蛋白。45 一项最新研究使用决策树建模和特征选择算法发现，细胞毒性测试指标是活力结果的重要决定因素。46

当前研究主要集中于无机纳米材料对环境和普通细胞的影响，而非专门针对肿瘤细胞。47–62 此外，尽管数据集中存在一些相关数据，但仍存在数据稀缺、关键数据大量缺失、模型准确性低和模型可解释性不足等重大问题。

在本研究中，如图1所示，我们收集并整理了金属和金属氧化物纳米材料对肿瘤细胞的毒性及其内在特征（化学组成、金属电负性、氧原子数、金属原子数、分子量、金属阳离子电荷、包覆/功能基团、粒径、浓度、zeta电位、肿瘤细胞类型、来源、形态和暴露时间、检测方法、干扰检查、胶体稳定性以及阳性对照设置）共2765组文献数据。此外，为了更好地理解纳米-QSAR研究中的构效关系，我们通过PM7半经验方法计算并引入了16个量子化学描述符63，包括生成热（HoF）、COSMO面积（CA）、COSMO体积（CV）、电离势（IP）、最高占据分子轨道（HOMO）、最低未占据分子轨道（LUMO）、填充能级数（NFL）、分子量、点群、团簇电负性（Tχ）、分子硬度、电负性、带隙能量（Eg）、极化率（Pol）、软度（S）。我们使用Jaccard相似系数64–66补充缺失数据，并选择九种经典算法模型进行训练。其中，LightGBM67模型实现了90.78%的最高预测准确率和95%的曲线下面积（AUC）。为了提高模型的可解释性并确定最佳决策过程，我们使用特征重要性、偏依赖图（PDP）和个体条件期望（ICE）。68 为了进一步验证模型的准确性并探索其泛化能力，我们用涉及三种常见金属（ZnO、CdO、Cu2O）和三种稀土金属（CeO2、Er2O3、Nd2O3）的240组新数据补充了数据集。新的实验结果证实了我们模型的可靠性和准确性。这些结果将显著减少研究人员的时间和经济成本，消除过度的劳动密集型实验，并实现纳米材料在生物医学用途方面的快速开发。

## 2 材料与方法

### 2.1 数据集

### 2.1.1 文献检索和协调。

最初，使用多个数据库进行系统迭代文献检索，包括Google/Google Scholar、PubMed和Web of Science，使用各种关键词组合（例如，“金属和金属氧化物纳米颗粒 + 肿瘤细胞毒性”、“金属和金属氧化物纳米颗粒 + 细胞 + 反应”、“金属和金属氧化物纳米颗粒 + 存活率”）。该阶段获得了约400篇同行评审的原始研究论文，报道了直径<1000 nm的纳米颗粒（NPs）体外细胞毒性评估。所有通过此检索识别的研究均被评估以纳入出版物数据库进行分析。

纳入荟萃分析的资格是基于以下标准确定的：NPs至少描述了核心材料、尺寸和剂量；具体细胞类型和NP暴露持续时间已指定；并且平均细胞存活率/毒性±标准差/误差已明确报告。为了限制异质性并确保有意义的结论，仅选择使用常见细胞活力/细胞毒性测定开发的数据点。这些包括中性红摄取测定（NR）、使用四唑盐的线粒体毒性测定（MTT、MTS、XTT、WST-1、WST-8）、ATP生物发光测定、乳酸脱氢酶（LDH）释放测定、间二酚（Alamar Blue）细胞活力测定以及活/死（膜完整性）测定。类金属基NPs和负载NPs被排除在本研究的范围之外。
