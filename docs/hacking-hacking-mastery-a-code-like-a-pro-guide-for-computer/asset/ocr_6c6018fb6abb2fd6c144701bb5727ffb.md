6. Port Scan Attack: this is a technique that is used in order to find the weakness on any given server. Normally it is used by those who are responsible for security in order to find vulnerabilities within the system.

Port Scan Attacks are used to send messages to a port while waiting for a response. The data that is received from the open port is then an invitation for a hacker to get into your server.
