# 17. “You’re Not Getting Paid to Test!”

What about new features? Can’t — fixing bugs. What about going back and refactoring some code to use a new library? Can’t — fixing bugs. What about some custom work for a client? Can’t — fixing bugs.

I’m sure you’re starting to spot a theme here.

The value of having your developers write tests that can be automated is that you are far more likely to find bugs before they get into production. That is the ultimate goal of testing– moving code swiftly out of the developer’s environment and into production where it is fulfilling the goals of the application.
