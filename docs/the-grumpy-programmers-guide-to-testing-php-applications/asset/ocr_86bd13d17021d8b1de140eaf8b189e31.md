Validation tests are great for figuring out if your API has changed without anyone realizing it—that uncertainty can lead to bad experiences and weird errors appearing in production. To be perfectly clear, there is extra work involved because someone will have to create and maintain the OpenAPI specifications. You can use tools like Stoplight Studio[^5] to create the specification at the same time you are creating your API.
