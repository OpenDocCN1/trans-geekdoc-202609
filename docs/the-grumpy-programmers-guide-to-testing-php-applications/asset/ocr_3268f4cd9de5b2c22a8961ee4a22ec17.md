# Wrappers From Up High

Now that I'm using the wrapper, I can create something which behaves like the JSONPlaceholder object I'm expecting but doesn't speak to the API at all.

```
<?php
declare(strict_types=1);

require '../src/JsonPlaceHolder.php';

class FakeJsonPlaceHolder extends JsonPlaceHolder
{
    public function getPosts()
    {
        /**
         * We know that a record should look something like this:
         * {
         * "userId": 1,
         * "id": 1,
         * "title": "sunt aut facere repellat provident occaecati",
         * "body": "quia et suscipit suscipit recusandae consequuntur"
         * }
         */
        $response = [];
        $x = 1;
        while ($x <= 100) {
            $post = [
                'userId' => 1,
                'id' => uniqid('', true),
                'title' => uniqid('', true),
                'body' => uniqid('', true)
            ];
            $response[] = $post;
            $x++;
        }

        return $response;
    }
}
```
