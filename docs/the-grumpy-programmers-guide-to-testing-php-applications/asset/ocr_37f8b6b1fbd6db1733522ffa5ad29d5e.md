# ## No Tests? No Problem!

The default state for most PHP applications is not to have any auto-mated tests. In the past, I would have started talking about a lack of professionalism or even frame it as a moral failure when discussing this. This is, of course, a terrible way to be. Instead, it’s better to focus on how you can get from no tests to at least one test and hopefully pointed in the direction of having more tests.
