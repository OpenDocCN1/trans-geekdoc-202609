# 11. WRAPPERS

```
<?php
declare(strict_types=1);

require '../vendor/autoload.php';
require 'FakeJsonPlaceHolder.php';
require '../src/JsonPlaceHolderWrapper.php';

class JsonPlaceHolderTest extends PHPUnit\Framework\TestCase
{
    /**
     * @test
     */
    public function callToPostsReturns100Posts()
    {
        $jph = new FakeJsonPlaceHolder();
        $wrapper = new JsonPlaceHolderWrapper($jph);
        $posts = $wrapper->getPosts();
        $this->assertCount(100, $posts);
    }
}
```

The downside to this approach is you are exposing some of the implementation details of your dependencies via your tests. This is a very simple example of creating a test double, but I have written tests which required several layers of doubles returning doubles return doubles. It’s fragile, and the tests easily no longer represent reality if the dependency itself has changed.
