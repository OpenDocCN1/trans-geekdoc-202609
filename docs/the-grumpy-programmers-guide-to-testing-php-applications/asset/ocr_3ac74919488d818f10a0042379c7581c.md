+   - It reports back if it passed or failed

One of the advantages of getting to this final stage is you are taking advantage of something that computers are very good at, doing what you tell them to do over and over again, usually without complaining. So if I can get another computer to react to what I am doing and run my tests for me, I can concentrate on solving problems instead of remembering a sequence of commands that I have a high probability of accidentally messing up.

# Final Thoughts

The purpose of tests is to give you the confidence that any defects that make it into your code are detected before the application makes it up into production. That confidence also allows you to refactor or rewrite your code with the knowledge that if you accidentally break something that was previously working, you’ll know before your users do.
