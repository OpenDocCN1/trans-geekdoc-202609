

# 服装供应链中的物联网安全问题

需要解决不同类型的物联网安全问题，包括物联网设备信任、访问控制、数据完整性、物理篡改和用户隐私。一项物联网技术部署调查得出结论，70%的物联网设备因加密相关问题、无保护接口和不当授权而存在漏洏（Lee & Lee, 2015）。在强调不同的隐私和安全问题时，一组研究人员（Cam-Winget et al., 2016）指出，由于在处理和分析来自庞大的异构物联网设备网络生成的数据时存在可扩展性问题，以及满足实时需求的需要，最近的系统安全解决方案是不充分的。由于动态拓扑和分布式特性，适当的安全和隐私方法被认为在基于物联网的信息系统环境中不可用。此外，当前基于服务器计算平台的互联网架构可能无法应对海量设备和海量数据，因为单个服务器可能成为网络攻击和物理损坏的单点故障。例如，物联网设备面临DDoS攻击、数据窃取和远程劫持的风险。此外，Marjani及其同事（Marjani et al., 2017）认为，一些基于物联网的应用缺乏服务级别协议（SLA）来保护隐私法要求的“个人身份信息”（PII）。因此，这可能对数据完整性产生负面影响。因此，系统安全在个人和企业的隐私保护方面可能受损（Suresh et al., 2014）。

此外，服装供应链业务合作伙伴可能对产品信息在企业价值链流动过程中的物理安全性和机密性存有顾虑。尽管基于物联网的信息系统帮助供应链交换合作伙伴验证供应链中物品的真实性，但仍然存在对物联网设备易受伪造、克隆和欺诈行为（如未经授权的访问、篡改和内容操纵）影响的担忧。例如，如果RFID标签被攻破，可能会绕过安全措施，并在自动验证过程中引入新的漏洞（Kumar & Iyengar, 2017）。此外，在集中式数据库中手动检索和存储有关唯一标签身份的信息，使得随时复制或伪造这些信息成为可能（Lin et al., 2017）。因此，很难识别伴随误导性溯源历史的假冒产品（Hua et al., 2018）。

最后，集中式系统可能给服装制造业中基于物联网的系统部署用于溯源操作带来劣势。集中式商业组织的存在可能导致不信任，从而阻碍供应链的未来发展（Tse et al., 2017）。用于数据存储和处理的集中式方法可能导致与数据完整性、安全性和隐私相关的多种商业风险和运营问题。例如，用于监控物联网数据的基于云的解决方案可能面临操纵风险，以及将大量机密和高度敏感信息导出到其他司法管辖区的外部服务时产生的隐私立法问题（Khetri, 2017; Kamilaris et al., 2019）。此外，这些解决方案可能造成不透明性，并加剧供应链交换合作伙伴之间的信息不对称。另一个因素是集中式信息系统充当黑箱，协作业务节点不知道其数据如何被存储、管理、利用和保护（Galvez et al., 2018）。区块链技术可以帮助缓解其中的几个问题。

# 区块链技术在服装业务中的应用

自2008年比特币这一数字加密货币的创新以来（Nakamoto, 2008），区块链技术已将自己置于各类研究人员和从业者的关注焦点。区块链是一个去中心化账本，它以安全、可验证和透明的方式，在点对点（P2P）网络上存储所有已发生的交易。区块链相较于现有技术的主要优势在于，它使双方能够在没有任何中介方干预的情况下，通过互联网安全地进行交易。省去第三方可以降低处理成本，同时提高交易的安全性和效率。

鉴于区块链给信息处理带来的显著效益，这项技术正将其适用性扩展到供应链管理和物流管理等新领域。如今，区块链也作为新兴“信任经济”中的守门人而屹立不倒，全球服装供应链在此运作以服务其供应商和客户。全球服装供应链的效率依赖于不同利益相关者之间的信任，而区块链与物联网技术的交互可以帮助提高业务网络中信息的可追溯性和可靠性。为实现这一战略目标，物联网技术应与服装企业的企业资源规划（ERP）和销售点（POS）系统集成，以在每个阶段共享和监控实时信息，如图1所示。

全球范围内，区块链技术提供了一种记录交易或任何数字交互的方式，其设计旨在安全、透明、高度抗中断、可审计且高效。换句话说，区块链技术为基于物联网的信息系统安全引入了一个有效的解决方案。区块链增强了物联网设备发送数据以纳入共享交易存储库的能力，该存储库具有防篡改记录，并使业务合作伙伴能够在无需中央控制和管理干预的情况下访问和提供物联网数据，从而创建了数字融合。

因此，区块链现在是服装业务中不同企业应用的关键且重要的技术。简单来说，“区块链”是一种以分布式方式使用的特定数据结构（称为“分布式账本” - DL），它将数据以称为“区块”的包形式存储和传输，这些区块在数字“链”中相连。分布式账本的概念源于“共享账本”的概念。共享账本可以是一个具有分层权限的单一账本，也可以是一个分布式账本，后者由分布式节点网络（或业务活动）维护的多个账本组成。分布式账本技术（DLT）是指一种跨多个数据存储（或账本）记录和共享数据的新颖且快速发展的方法。该技术允许在不同网络参与者的分布式网络中记录、共享和同步交易和数据。区块链采用“加密”和算法方法，以“不可变的方式”在网络中记录和同步数据。区块链的简单图示表示如图2所示。
