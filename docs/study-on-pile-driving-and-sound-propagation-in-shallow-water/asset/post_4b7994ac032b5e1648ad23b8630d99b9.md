Normal mode theory is one of the commonly used theories to describe the propagation law of the sound field in the ocean and is suitable for sound field modeling in the horizontally layered medium. It is an important calculation method of the shallow water sound field and has been widely practiced. The main idea of normal mode theory is to decompose the sound field into horizontal traveling waves and vertical standing waves, and only partially normal waves of one frequency can travel long distances in one waveguide. Assuming that the underwater acoustic environment is a two-dimensional axisymmetric layered medium, a cylindrical coordinate system is established with the radial axis and the vertical axis. Ignoring the time factor, the Helmholtz equation can be written as

```
\frac{1}{r} \frac{\partial}{\partial r} (r \frac{\partial p}{\partial r}) + \frac{\partial^2 p}{\partial z^2} + k^2 p = 0
```

where p is the sound pressure, k = \frac{\omega}{c} is the wave number in the water. Using the separation variable method, the sound pressure can be expressed as

```
p = \Phi(x)R(r)
```

Substituting Equation (13) into Equation (12) and introducing a separation constant k_m, we can get

```
\frac{\partial^2 \Phi_r(x)}{\partial x^2} + (k^2 - k_m^2)\Phi_m(x) = 0
```

```
\frac{1}{r} \frac{\partial}{\partial r} (r \frac{\partial R(r)}{\partial r}) + k_m^2 R(r) = 0
```

where the separation constant k_m is the horizontal wave number.

Equation (14) describes the characteristics of the sound field for the radial coordinate (propagation direction), which is a classic Bessel equation, and its solution is a combination of two Hankel functions. ## 3. Physics-informed neural network

In this section, we briefly illustrate how the physics-informed neural network for solving problems of pile driving and sound propagation in shallow water is constructed. And then we put forward a suggestion to help the neural network avoid lazy learning and learn partial differential equations better.

### 3.1. Implement procedure

In this study, we use DeepXDE to implement our tasks including forward and inverse problems. DeepXDE is a library in python on open-source deep learning platforms (TensorFlow, PyTorch, JAX, PaddlePaddle). The motivation for using DeepXDE is that it is a developed

tool and is believed to be able to train, test, predict and solve partial differential equations, and compute unknown parameters in the vibroacoustic model of pile driving.

The brief workflow of DeepXDE for solving partial differential equations of pile driving is illustrated in Table 1, and the brief workflow for function approximation of sound propagation in shallow water is shown in Table 2.

The computational domain in our work is one or two-dimension, namely the position along the axial direction of the pile or radial distance along the horizontal direction, and the output is axial displacement, radial displacement, and sound pressure as follows

```
$x \in \mathbb{R}^{d_{in}}$ (18a)

$u, w \in \mathbb{R}^{d_{low}}$ (18b)

$x, r \in \mathbb{R}^{d_{low}}$ (19a)

$p \in \mathbb{R}^{d_{low}}$ (19b)
```

A neural network with inputs, N-layers, and outputs is built for simulating partial differential equations of pile driving or approximating sound propagation in shallow water, and can be mathematically expressed as

```
$N \left( x, u; \frac{\partial u}{\partial x} \frac{\partial^2 u}{\partial x^2}, w, \frac{\partial w}{\partial x}, \cdots \right) = 0, x \in \mathbb{R}^{d_{in}}$ (20)
```

The neural network includes an input layer, hidden layers, and an output layer, in which the relu function, the sigmoid function, the sine function, and the hyperbolic tangent function are used as the nonlinear activation function. For instance, using the sine function as the activation function, a neuron in a hidden layer can be written as

```
$y^{i+1}(x) = \sigma(W^i x + b^i) = sin(W^i x + b^i)$ (21)
```

where $W^i$ and $b^i$ are weights and biases in the i layer, respectively.
