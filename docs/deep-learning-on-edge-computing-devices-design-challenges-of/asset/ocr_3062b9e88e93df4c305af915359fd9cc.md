# 3.3 Model compression

With rapid development of deep learning, more and more parameters are used in deep neural network model. Models with outstanding results in ImageNet Challenge [1] all have massive parameters, such as the ResNet-50 model [10], which has 50 million parameters, and the VGG-16 model [14], which has 130 million parameters. In addition, the number of parameters of the GPT model [21] in the field of natural language processing has expanded from 110 million in GPT1 to 175 billion in GPT3. Large models with massive parameters not only consume a lot of resources during training, but also prevent the deployment to mobile devices such as mobile phones and robots.
