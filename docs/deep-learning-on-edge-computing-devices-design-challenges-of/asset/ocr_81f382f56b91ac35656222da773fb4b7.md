A traditional approach to achieve image compression is using additional logic devices, like image/video coding approaches [34–37], which potentially increase the cost and computation complexity at the system level. To address the challenge, in this paper, we propose an efficient method for unified object detection and image compression. The basic idea is optimizing and reusing the convolution operation of the convolutional neural network to perform feature extraction and image compression simultaneously; therefore there is no requirement for extra computational overhead, saving the cost and computation occupation of wireless computer vision applications.

The proposed approach is based on the modern compressive sensing technique. By solving undetermined linear systems it has been proved that the sparsity of the image signal makes it possible to be recovered from fewer samples [38]. To recover a compressed image, the theory of compressive sensing requires a sufficient incoherence condition, which is applied through the isometric property [39,40]. At the front end, traditional compressive sensing methods use random matrices for data embedding, which can meet incoherence conditions with high probability [41–44].

It is not trivial to incorporate the compressive sensing in the deep learning framework. The proposed incoherent convolution operation is deterministic and can be learned from samples, which is different from the work of random convolution operation [11]. To accurately recover the image, the incoherent condition must be satisfied, so the proposed method defines a relaxed measurement of the mutual coherence between the sensing and basis matrices. By minimizing the coherence measurement in the regularized training process the original image can be compressed with higher quality.
