# ### 9.2.1 Standard compressive sensing

Compressive sensing is a low-rate sampling approach for the signals that are known to be sparse. Suppose the signal x is an N-dimensional vector, which can be sampled using a sensing matrix \(\Phi \in \mathbb{R}^{M \times N}\) as

```
y = \Phi x. \qquad \text{(9.1)}
```

The constant M determines the sampling rate. Because M is smaller than N in compressive sensing, Eq. (9.1) is underdetermined, and the signal x cannot be uniquely recovered from \(\Phi\) and y. However, the assumption of sparsity allows the signal x to be represented using a set of sparse coefficient \(s \in \mathbb{R}^N\) and a matrix of basis \(\Psi \in \mathbb{R}^{N \times N}\) as x = \(\Psi s\). Then we have y = \(\Phi \Psi s = \Theta s\), where \(\Theta = \Phi \Psi\) is an M x N measurement matrix. Since s is sparse, it is possible to retrieve the value of s by solving the L1 norm minimization problem as

```
s = \min_s \|s\|_1, \quad \text{s.t. } \|y - \Theta s\|_2 < \xi. \qquad \text{(9.2)}
```

After solving Eq. (9.2), we can approximate the original signal x by \(\hat{x} = \Psi s\).

Generally, based on Eqs. (9.1) and (9.2), one of the main goals of compressive sensing is to learn the sensing matrix \(\Phi\). Researches mainly focus on two points.
