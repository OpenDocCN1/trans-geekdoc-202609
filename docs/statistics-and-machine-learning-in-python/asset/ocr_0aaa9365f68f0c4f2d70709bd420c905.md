What benefit has been obtained by using ℓ₂ regularization?



Lasso regression penalizes the coefficients by the ℓ₁ norm. This constraint will reduce (bias) the capacity of the learning algorithm. To add such a penalty forces the coefficients to be small, i.e. it shrinks them toward zero. The objective function to minimize becomes:

> Lasso(β) = ||y − Xβ||₂² + λ||β||₁. (12.13)

This penalty forces some coefficients to be exactly zero, providing a feature selection property.
