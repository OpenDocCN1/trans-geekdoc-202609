+   - Choose the model with the smallest coefficient vector, i.e. smallest ℓ₂ (‖β‖₂) or ℓ₁ (‖β‖₁) norm of β, i.e. ℓ₂ or ℓ₁ penalty. See also bias-variance tradeoff.
+   - Choose the model that uses the smallest number of predictors. In other words, choose the model that has many predictors with zero weights. Two approaches are available to obtain this: (i) Perform a feature selection as a preprocessing prior to applying the learning algorithm, or (ii) embed the feature selection procedure within the learning process.

# Sparsity-induced penalty or embedded feature selection with the ℓ₁ penalty

The penalty based on the ℓ₁ norm promotes **sparsity** (scattered, or not dense): it forces many coefficients to be exactly zero. This also makes the coefficient vector scattered.
