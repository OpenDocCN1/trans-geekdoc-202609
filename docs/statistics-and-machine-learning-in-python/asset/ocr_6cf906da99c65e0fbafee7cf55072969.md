+   - Each row v_i provides the mixing coefficients of dictionary items to reconstruct the sample x_i
+   - It may be understood as the coordinates on the new orthogonal basis (obtained after the initial rotation) called principal components in the PCA.

# 10.2.3 SVD for variables transformation

V transforms correlated variables (X) into a set of uncorrelated ones (UD) that better expose the various relationships among the original data items.

X = UDV^T,  (10.1)
XV = UDV^T V,  (10.2)
XV = UDI,  (10.3)
XV = UD  (10.4)

At the same time, SVD is a method for identifying and ordering the dimensions along which data points exhibit the most variation.

from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

#     on full_matrices.

plt.figure(figsize=(9, 3))
