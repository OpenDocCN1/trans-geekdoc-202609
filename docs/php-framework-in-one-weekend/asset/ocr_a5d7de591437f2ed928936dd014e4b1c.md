# Chapter 9
Design and Layout

Let's turn our attention to the front-end for a while and make the output look a bit more professional. The publicfolder is the only web-accessible folder in our project. We are using PHP's built-in web server for our development environment, but eventually this is where the production web server will be pointing.

Until now our publicfolder has contained just the index.phpfile that is used to launch our App. It creates the $requestobject from PHP's global request variables, instantiates the App, passes the $requestto the app and then sends the generated $response.

We will now put some other files in this publicfolder so that our site users will be able to download them over the web. We don't have any CSS or JavaScript yet. Let's make use of Twitter Bootstrap, as it's a quick way to get started. We'll use the pre-compiled and minified version for now. Download the bundle from the getting started page[4], extract the archive and copy the css, fonts, and jsfolders into your publicfolder.
