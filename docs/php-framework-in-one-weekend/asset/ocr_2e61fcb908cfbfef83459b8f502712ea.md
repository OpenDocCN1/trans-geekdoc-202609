# # Chapter 7
Controllers

We’ve come a long way since our first “Hello World!” example where we did everything in a single PHP script. We now have some structure in place, but everything is still in the single run()method of our Appclass.

In a web framework you will often find that separate objects are responsible for different types of request. The front controller dispatches the request to the appropriate controller to generate the response. The two routes we have defined so far could both be handled by the same controller. If you look at the basic router we created, the code that generates the content is almost the same. Let’s create a BasicPageControllerclass that encapsulates this functionality.

Following the naming rules for autoloading from PSR-4, we create a folder for our controllers called src/Controller. Our Weekend namespace maps to the src folder, so the namespace for our controllers will be Weekend\Controller. If we ever need to refer to our new controller class in full it will be called Weekend\Controller\BasicPageController. Listing 7.1 shows the code of our new BasicPageControllerclass.
