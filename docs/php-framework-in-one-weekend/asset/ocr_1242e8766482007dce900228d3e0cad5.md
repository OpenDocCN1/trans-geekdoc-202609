Now let's get the rest of the system converted over to use templates. This means changing public/index.phpSo that it no longer has HTML markup hard-coded inside it. For now, we will replace this with the code to load and execute Twig.

Twig is a very flexible system made up of various components. To get started you just need a *Template Loader* so that Twig knows how to load template files, and a *Twig Environment* where all template processing happens.

Listing 4.3 shows the new public/index.phpfile, with the template loader created in line 9 and the Twig environment loaded in line 10.

```
1 <?php
2 use Symfony\Component\HttpFoundation\Request;
3 require __DIR__.'.././vendor/autoload.php';
4
5 $request = Request::createFromGlobals();
6
7 $name = $request->get('name');
8
9 $loader = new Twig_Loader_Filesystem(__DIR__.'.././templates'); 10 $twig = new Twig_Environment($loader);
11
12 echo $twig->render('index.html',['name' => $name]);
```

# **Listing 4.3: public/index.php**

The HTML markup has been removed, and is now generated when we call the render() method on the $twigobject on line 12. The call to $twig->render()takes two arguments. The first is the template name, and the second is the array of *template variables* to pass to the template. In our template file (templates/index.html) we had one expression {{ name }}that referenced one variable called name. In the call to render we pass the $name variable we retrieved from the request object.

Run the PHP built-in web server again, if not still running from before. If you load the following URL you should see “Hello World!”.
http://localhost:4000/?name=World

Notice that if you go directly to http://localhost:4000without providing the name parameter you just see “Hello !” The basic test script we created in chapter 2 (listing 2.1) will fail. Let’s fix this by providing a default value for name.

Listing 4.4 shows the use of Twig’s default()filter. The pipe symbol (|) is used to *pipe* the output of the *name*variable into the *default*filter. Twig has many filters available[12]. This one simply provides a default value, if the input is empty.

```
1 <!doctype html>
2 <html lang="en">
3 <head>
4 <meta charset="UTF-8">
5 <title>Document</title>
6 </head>
7 <body>
8 <h1>Hello {{ name | default('World') }}</h1>
9 </body>
10 </html>
```
