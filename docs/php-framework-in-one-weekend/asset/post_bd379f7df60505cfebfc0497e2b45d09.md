<?php

use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Weekend\Service\ConfigService;
use Weekend\Service\TemplateService;

class BasicPageController
{
protected $menu;
protected $theme;

public function __construct(TemplateService $theme, ConfigService $config) {
$this->theme = $theme;
$this->config = $config;
}

public function get(Request $request)
{
$path = $request->getPathInfo();
$page = ($path == '/')? 'index' : substr($path, 1);
$menu = $this->config->getConfig();
if (isset($menu[$page]))
{
$content = $this->theme->render('basic.html', $menu[$page]);
return new Response($content);
}
return Response::create("not found", 404);
}
}

## Where Next?

You now have the start of your own PHP web framework. Here are some ideas of where to go next...

- Use it to create a starting point for projects. Collect together your own preferred set of PHP packages with configuration, and boilerplate code, to save you time when starting new projects.
- Experiment with alternative dependency injection containers. Try using Pimple[24] as the basis for an app. Do you prefer that as a way of working? Or do you like the YAML configuration files?
- Add support for caching to improve performance.
- Finish and improve the form handling in the contact controller.
- Read up on PHP security, including CSRF[18]. How can you extend the framework here to make it more secure? What facilities can you provide in the framework that make it easier to implement security on future projects?
- Replace our basic router with your own improved version. Read this blog[7] about using regular expressions and try FastRoute[8]. Or, if you prefer a friendlier API try Route[22].
- Check the Awesome PHP[3] list for packages you think would be useful for your projects and integrate them into your framework.
- Add a user login system using Symfony's Session component as the basis for storing user sessions.
- Install PHPUnit and write some real unit tests.
- Add documentation in DocBlock format to improve support in IDEs like PHPStorm.
- Choose the right license. Most PHP projects use an open source MIT license.
- Provide more ways for users to customise how the app works. Look at implementing events[6] as a way to hook into core functionality.
