## Preface

> “a weekend, the fundamental unit of coding self-improvement”
> Peter Shirley

I recently enjoyed working through Peter Shirley's Ray Tracing in One Weekend[21]. Over the course of a few chapters, Peter guides you through the process of building a basic ray tracing application. It's not a comprehensive tool, but in one weekend you cover enough material to learn the fundamental concepts. Peter says he included “the most primal set of these assignments so that it's very doable in a weekend, the fundamental unit of coding self-improvement.”

## About this project

I have followed Peter’s approach here, and will guide you through a short project that should be easily doable over the course of a weekend. The project is based on a 2 day training course I have run with small groups of PHP developers. I have refined the content to a simple set of examples, each one building on the last.

It is not intended to be a tool you can immediately go and use on real websites, but as a starting point to learn the basic concepts used in modern PHP web applications. It is also not intended to be an introductory course in web technology. Some familiarity with HTML, CSS, JavaScript, and PHP is assumed.

Another objective of this course is to teach modern PHP. There are a lot of old books, tutorials, and guides that teach PHP that would not pass code review today. In this project we will aim to use modern PHP best practises. But, one weekend is not enough time to cover the whole of modern PHP. You are encouraged to read through PHP The Right Way[16], for a more detailed overview of the modern way to use PHP.

This weekend project is about exploring modern PHP and the ecosystem of PHP packages and libraries. Over the course of this weekend you will learn some of the fundamental concepts that modern PHP apps are built on. Projects such as Drupal, phpBB, Laravel, eZ Publish, Joomla!, Magento, Piwik, and many more are using Symfony Components[25] as a foundation on which to build. We will use these, and more, to build our own PHP Framework.

## Conventions

Text in monospace font is either a snippet of code, or a command to be entered at the command line. I use iTerm2 on OSX, but any environment where PHP runs should work. I use the $ character to indicate the command prompt. If you see a line that begins with this character, followed by a space, then it is a command to be entered at the terminal.

```
$ pwd
/Users/darren/dev/book
```

Any lines in the shell block that do not begin with a $ character are output returned by the command. You should expect to see this appear in your terminal as a result of running the preceding command.

Other uses of monospace font include code examples, PHP keywords, filenames, classes, functions, and commands. You will see partial code examples, included inline, like this:

```
$name = $_GET['name'];
```

You will also see full code listings of entire source files. These will include PHP, CSS, JavaScript, Twig templates, and JSON configuration files, for example listing 1. The caption alongside a code listing is provided to indicate which file it relates to. The line numbers on the left of the source code indicate which lines from the source file are quoted. As you can see in this example, lines 2-6 have been provided. A listing may list the whole file, or it may list a selected number lines only that highlight the issue being discussed.

```
2 require __DIR__.'../vendor/autoload.php';
3 $name = "World";
4 ?>
5 <!DOCTYPE html>
6 <html lang="en">
```

**Listing 1:** public/index.php Note The source files are provided as examples. They are meant to illustrate the concepts being discussed. You are expected to write the code yourself. Please don't copy and paste. Read the code, understand it, but then write your own version of it. You will learn more if you write code yourself, improvise, and adapt to your liking. You are welcome to use the provided code for whatever means you wish, but it is only supposed to be used as a reference.

If you get stuck check the GitHub repository[23] or contact the author[2].

## Chapter 0

### Getting Started

You should use the latest stable version of PHP. I am using PHP 7, but this project should work without issues on PHP 5.6. You can check the installed version of PHP with the php -v command.

```
$ php -v
PHP 7.0.6 (cli) (built: May 12 2016 15:13:35) ( NTS ) Copyright (c) 1997-2016 The PHP Group
Zend Engine v3.0.0, Copyright (c) 1998-2016 Zend Technologies
```

If you are on OSX you can update and install PHP using Homebrew[10]:

```
$ brew update
$ brew install homebrew/php/php70
```

We will use an application called Composer to download PHP packages, and make them available to our PHP code.

If you don't already have Composer installed you can find installation instructions on the Composer website[5]. You can install Composer locally to this single project, but I prefer to install it globally. I will assume you have done the same and made the composer executable available on your PATH. If you have installed it differently, you may need to update the example commands.

```
$ composer
```

If you run the command above you should see some basic help about Composer, its options, and a list of available commands.
