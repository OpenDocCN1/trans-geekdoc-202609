# Getting Started

You should use the latest stable version of PHP. I am using PHP 7, but this project should work without issues on PHP 5.6. You can check the installed version of PHP with the php -vcommand.

```
$ php -v
PHP 7.0.6 (cli) (built: May 12 2016 15:13:35) ( NTS ) Copyright (c) 1997-2016 The PHP Group
Zend Engine v3.0.0, Copyright (c) 1998-2016 Zend Technologies
```

If you are on OSX you can update and install PHP using Homebrew[10]:

```
$ brew update
$ brew install homebrew/php/php70
```

We will use an application called Composer to download PHP packages, and make them available to our PHP code.

If you don't already have Composer installed you can find installation instructions on the Composer website[5]. You can install Composer locally to this single project, but I prefer to install it globally. I will assume you have done the same and made the composerexecutable available on your PATH. If you have installed it differently, you may need to update the example commands.

```
$ composer
```

If you run the command above you should see some basic help about Composer, it's options, and a list of available commands.
