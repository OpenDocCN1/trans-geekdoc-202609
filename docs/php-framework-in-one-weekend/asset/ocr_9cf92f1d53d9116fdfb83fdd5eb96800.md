# Server Configuration

The process for configuring your front controller will depend on what server you are using. I give hints at how to configure this on both Apache and Nginx below. For this weekend we are only using the PHP built-in web server. This dev server doesn’t need any configuration. We automatically get routing to our index.phpfile for free when we start the built-in server with:

```
$ php -S localhost:4000 -t public/
```

If you are using Apache then you can create a .htaccessfile to add your web server configuration. Something like this will work for Apache:

```
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f RewriteCond %{REQUEST_FILENAME} !-d RewriteRule . index.php
[L]
```

This requires Apache’s rewrite module to be enabled. The configuration first checks that the request is not for an existing file (images, css, js, etc) and then routes everything else to index.php.

Nginx is another popular web server used with PHP. In which case you will add something like this to your nginx.conf:

```
try_files $uri $uri/ /index.php;
```
