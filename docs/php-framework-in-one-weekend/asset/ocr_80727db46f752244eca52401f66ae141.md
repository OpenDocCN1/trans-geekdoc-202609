There are many options available for PHP, including:

+   - Symfony provides a DI component[26] that allows you to configure dependencies using XML, JSON or PHP.
+   - Pimple[24] is a good stand-alone option that is used by the Silex micro-framework.
+   - Container[11] is a solution offered by the same team of developers that created the filesystem abstraction we are using.
+   - Auryn[1] provides auto-wiring of dependencies.

**Note** It is important to note that the DI container should only be used to create the objects needed to run your app. You should never pass a DI container into a class as a dependency. This actually happens quite a lot, and is considered an *anti-pattern* (i.e. opposite to best practise). What you've done in this case is convert your DI container into a *service locator* which does the opposite of what dependency injection should do. It hides dependencies deep inside your classes, when you're really trying to expose and provide all dependencies at the top level.
