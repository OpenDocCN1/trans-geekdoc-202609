Aside In the ConfigServiceclass constructor I have actually defined the parameter type as FilesystemInterface. An interface is a bit like a contract. It doesn't specify any details about the implementation, it only states what functionality exists. It’s a specification. Classes can declare that they implement the interface specification, meaning that they provide an implementation for all the functionality described by the interface specification. This allows us to easily swap in other implementations later. We only use functionality defined in the interface, so we can be sure that any other implementation provided will work.
