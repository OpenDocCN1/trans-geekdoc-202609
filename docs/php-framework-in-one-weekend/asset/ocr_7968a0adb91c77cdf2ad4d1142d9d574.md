# Testing

Testing is an important concept in modern PHP development, and it would not do it justice to try and cover it in this weekend. For our purposes we will define a simple test script, but on real projects you will more likely use a testing framework like PHPUnit[17].

At the moment, all our application does is print out “Hello World!”. If we were to write a test for this we would request the page, then check that it contains the text “Hello World!”. Create a file called test.php as per listing 2.1.

```
1 <?php
2 ob_start();
3 include 'public/index.php';
4 $output = ob_get_clean();
5 echo strpos($output, "Hello World!"), PHP_EOL;
```

# Listing 2.1: test.php

This simple test starts an output buffer, includes the index.phpfile, then grabs the content of the buffer into a string variable $output. The final line of the script tests that the string “Hello World!” occurs in the output.

You can now run this test from the command line using PHP:

```
$ php test.php 109
```

You should see a number (like 109) printed out. This is the position of the “Hello World!” string within the output. If you see a blank line then the test failed to find the require “Hello World!” string in the output.

You can probably imagine how testing in this way will get complicated and time consuming as your project gets bigger. At some point you will want to use a testing framework.

We will also strive to make our code easy to test by separating out functionality into components so they can be tested independently.

In the example above we are testing more than just the correct output of our $namevariable. We are also testing any other functionality in the index.phpfile. This will become more clear as the project gets bigger. Ideally we want a way to test every bit of functionality independently. For example, if the output in our very basic app was generated by a callback function, we could test this single function independently:

```
1 <?php
2 require 'vendor/autoload.php';
3 $controller = new HelloController();
4 $output = $controller->run("World");
5 if ($output == "Hello World!") echo "Test Passed!";
```
