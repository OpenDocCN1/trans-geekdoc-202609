

# VAE-GAN 模型详解

## 模型 D 的额外功能

VAE-GAN 的模型 D 比普通 GAN 的模型 D 多做一项工作。从模型 D 倒数第二层神经层，VAE-GAN 的模型 D 输出两批向量。每批向量中每个向量的维度可达数千。来自真实图像的一批向量（`V[X]`）和来自假图像的一批向量（`V[X̃]`）被用来替换 VAE 系统重构损失函数中的真实图像和假图像。根据 VAE-GAN 论文，这个修改后的重构损失函数名为 `L_like^(Dis[l])`，它是解码器损失函数的一部分，也是编码器损失函数的一部分。公式 ([5.7](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5eqn7)) 中的 `L_prior` 是 `q(Z|X)` 与多元标准正态分布 `N(0,I)` 之间的 Kullback-Leibler 散度。

```
L_P = L_like^(Dis[l]) - L_GAN = MSELoss(V[X], V[X̃]) - L_GAN
```
(5.6)

```
L_Q = L_like^(Dis[l]) + L_prior = MSELoss(V[X], V[X̃]) + D_KL(q(Z|X) || p(Z))
```
(5.7)

## 模型训练与损失函数平衡

模型 D、P 和 Q 使用各自的损失函数进行训练。这三个模型的损失函数值不在同一量级，特别是当这些值通过每批求和计算时。许多人通过每批平均损失求和来计算三个损失函数的值，并使用 `L_P = γ L_like^(Dis[l]) - L_GAN` 和/或 `L_Q = 5 L_like^(Dis[l]) + L_prior` 来平衡这些损失值，其中 `γ = 15` 或 `25`。

在后续的 VAE-GAN 项目中，损失函数值通过每批求和计算。由于 `L_GAN` 和 `L_prior` 的值与 `L_like^(Dis[l])` 相比非常小，`L_like^(Dis[l])` 前的超参数 `γ` 被设置为 `1.0`。潜在维度通过 `z_dim = 2` 设置为 2，以便我们能在图 [5.7](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig7)(A) 中展示潜在空间。在模型训练期间，Cell 11 每五个 epoch 会输出一批真实图像和一批假图像，如图 [5.6](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig6) 所示。

## 判别器 D 的结构差异

Cell 07 中的判别器 D 与第 [3.2.2](#Chapter_3.xhtml#bk98-0-7503-6244-3ch3s3-2-2) 节中 GAN 的模型 D 略有不同。它有两个输出。一个输出是一批范围在 `[0,1]` 内的标量，这与通常情况相同；另一个输出来自第 04 层的一批向量，每个向量有 1024 个元素。第二个输出用于替换图像（真实或假）以进行重构损失计算。向量的元素数量越多，模型训练所需时间越长，生成的假图像质量越好。

由于我们再次使用 GAN，我们面临着相同的问题：选择学习率以平衡图像生成器和图像判别器的“智力”。在 Cell 01 中，三个模型的初始学习率（`lr`）均设置为 `10^(-3)`。模型 Q 和 P 使用相同的学习率。在 GAN 的模型训练中，我们通常对模型 D 使用较小的学习率。但在 VAE-GAN 中，我们必须对模型 D 使用较大的学习率（`10 × lr`）以使假图像更清晰（Cell 09 第 05 行）。
