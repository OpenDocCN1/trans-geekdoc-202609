

# ViT 模型架构与实现

## 前向传播与 Token 嵌入

在 Cell 03 中定义的类的前向函数里，输入是一个形状为 `[b, 3, 224, 224]` 的图像批次，其中参数 `b` 为批次大小。通过 Cell 02 中定义的类的一个实例（包含一个卷积和一个 permute 操作），输入图像被分割成一个形状为 `[b, 784, 192]` 的张量。Cell 03 第 06 行的代码创建了一个可学习的 `cls` token。第 14 行的代码将其扩展以适应批次中的每一张图像。在将 `cls` token 前置到批次中每张图像的 token 序列前后，我们为每张图像的每个 token 加上一个位置嵌入张量。PyTorch 会通过广播机制处理这两个张量之间的维度差异。为了减少过拟合问题，我们需要对 Cell 03 的输出进行 dropout 操作。在 Cell 03 之后的一个额外单元格中运行代码 `f2=Embeded_Imgs(config);emb_img=f2(my_img); emb_img.shape`，我们将得知对于仅包含一张图像的批次，Cell 03 的输出形状为 `[1, 785, 192]`。

## Transformer 编码器架构

基本 ViT 模型的架构如图 [10.2](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10fig2) 左侧所示。来自 Cell 03 或公式 ([10.1](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn1)) 的那些 token 由 12 个串联的 transformer 编码器层处理。它们细化输入图像的表征。编码器层的结构如图中间所示。在编码器层内部，有一个多头注意力块，它包含六个并联的自注意力头来处理每个批次的 token。单个自注意力头的结构如图右侧所示。每个自注意力头的输入和输出形状相同，均为 `[b, 785, 192]`。根据公式 ([10.2](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn2))，我们可以在 Cell 04 中编写自注意力头的代码。在公式和图中，两个张量之间的点表示点积。三个张量 `Q`、`K` 和 `V` 分别是三个全连接层的输出。任意全连接层的输入相同：一批图像的 token 批次，且 `D` 等于 192（颜色补丁的像素数：3 × 8 × 8）。所有六个自注意力块的输出随后由 Cell 05 第 18 行的代码拼接成一个形状为 `[b, 785, 192 × 6]` 的更大张量。然后由第 21 行的代码使用一个全连接层将该大张量投影回形状为 `[b, 785, 192]` 的张量。经过一个作用于投影结果的 dropout 操作后，最终结果作为一个包含两个元素的元组输出。第一个元素是一个批次 token 的注意力张量，元组的第二个元素用于注意力概率。我们可以运行代码 `f4=MultiHeadAttention(config); Y=f4(emb_img)[0]; Y.shape` 来检查类代码是否正常工作。

$$
\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{Q \cdot K^{T}}{\sqrt{D}} \right) \cdot V
$$

## 编码器层细节

Transformer 编码器的输入是一批图像的 token。因为每张图像的每个 token 都嵌入了位置信息，所以我们在编码器中不应使用批归一化，而应使用层归一化。此外，编码器块中使用了两个残差连接（Cell 06 第 19、21 行）。在编码器层的 MLP（多层感知机）块中，有两个全连接层，中间夹着一个激活类 `nn.GELU()`（Cell 06 第 12 行）。MLP 块中也使用了 Dropout。

Cell 07 中每个 12 个 (=L) 编码器层的数学运算可用公式 ([10.3](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn3)) 和 ([10.4](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn4)) 表示。以第一层为例，输入 token `z[0]` 经过第一个层归一化的输出为 `LN(z[0])`，随后由多头自注意力块处理得到 `MSA(LN(z[0]))`。利用公式 ([10.3](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn3))，我们获得第一个编码器层中第一个残差块的临时输出 `Φ[0]`。将 `Φ[0]` 作为第一个编码器层中第二个残差块的输入并使用公式 ([10.4](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn4))，我们得到 `z[1]`，即第一个编码器层的输出。最后一个编码器层的输出也是一个包含两个元素的元组，分别关于 token 和注意力分数。

$$
\Phi[\ell - 1] = \text{MSA}(\text{LN}(z[\ell - 1])) + z[\ell - 1] \quad \ell = 1, 2, ..., L
$$

(10.3)

$$
z[\ell] = \text{MLP}(\text{LN}(\Phi[\ell - 1])) + \Phi[\ell - 1] \quad \ell = 1, 2, ..., L
$$

(10.4)

$$
y = \text{MLP}(z[L][:,0])
$$

(10.5)

我们仅使用 `z[L][b, 0, 192]` 进行图像分类。公式 ([10.5](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10eqn5)) 中 `z[L][:,0]` 的形状为 `[b, 192]`。在最后一个 transformer 层之上添加一个分类头，以便进行图像分类预测。我们可以通过在 Cell 07 之后的一个额外单元格中运行代码 `f6=Vit(config); f6(my_img)` 来确保上述所有类中的代码均正常工作。使用第 2 章项目 [2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2ueqn1) 中 Cell 10 的代码，你会发现 Cell 07 中定义的 ViT 模型共有 14,443,018 个参数。

## 10.2 用于 CIFAR10 图像分类的 Hugging Face ViT

我想将上述 ViT 模型用于 CIFAR10 图像分类。由于模型参数量超过 1000 万，ViT 模型训练的计算任务对于我的笔记本电脑来说过于繁重，无法处理调整大小为 224 × 224 的 5 万张图像。我必须使用预训练的 Hugging Face ViT 模型来展示视觉 transformer 的强大能力。因为预训练模型约有 8600 万个参数，我必须冻结它们，仅训练最后一层中用于图像分类的少量参数以节省时间。从 YouTube、GitHub、Kaggle 和 Google Colab，我们可以找到演示如何微调用于 CIFAR10 的 Hugging Face ViT 模型的代码。我的代码受这些人的代码启发。以下项目 [10.2](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10ueqn5) 的图像分类准确率在训练集、验证集和测试集上分别为 94.9%、94.5% 和 94.7%。代码运行时间约为 33 分钟（10 个 epoch）。
