# 第 3 章

## 使用 GAN 进行图像生成

本章介绍如何使用生成对抗网络（GAN）和条件 GAN 生成与六个数据集（MNIST、Fashion MNIST、Anime Face、CelebA 和 Rock Paper Scissors）中的图像相似的假图像。使用一个简单的二次曲线数据集，以便于理解 GAN 的数学原理。

图像生成比图像分类更难。这对人类和计算机都是如此。自从 Ian Goodfellow 及其同事于 2014 年发表题为“生成对抗网络”的论文以来，许多基于 GAN 的算法被开发出来。如今，计算机可以被训练创建逼真的人脸照片。只需搜索“this person does not exist”，你就会找到一个网站，在那里可以看到令人惊叹的假人脸照片。GAN 拥有两个神经网络或模型：一个生成器和一个判别器。生成器从纯噪声中创建假数据样本。判别器以假样本和真样本作为输入，并对它们进行评估以找出假样本。在模型训练期间，这两个网络相互竞争。生成器试图生成数据（图像）来欺骗判别器，而判别器设法正确识别出生成的数据。训练过程持续进行，直到生成器创建的数据如此逼真，以至于判别器无法将其与真实数据区分开来。在模型训练结束时，GAN 可以找到数据集中图像像素的概率密度函数（PDF）。利用 PDF 的参数，计算机可以生成与真实图像相似的假图像。

### 3.1 GAN 理论

一个 GAN 模型被用作生成器（G），它被训练从 1D 噪声向量生成假图像。噪声向量中的元素数量可以是 1、2，甚至超过 100。这些向量来自标准正态分布函数（第 [1.1.1 节](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1s1-1-1)）。模型 G 有许多待训练的参数（*θ*[*g*]inline-graphic style="height:1.25em;" xlink:href="bk978-0-7503-6244-3ch3ieqn1.gif"/）。另一个模型被用作判别器（*D*），它被训练从数据集中区分假图像和真图像。它也有许多待训练的参数（*θ*[*d*]inline-graphic style="height:1.125em;" xlink:href="bk978-0-7503-6244-3ch3ieqn2.gif"/）。模型 G 就像一名由他的老师列奥纳多·达·芬奇（即模型 D）教导绘画的美术学生。在观看了老师的许多杰作后，学生画出了他的第一幅画。老师告诉学生哪里画错了，以及如何提高技艺。学生接着画了第二幅画。老师再次检查画作并给出更多建议；这个过程重复多次。最终，学生能够画出另一幅《蒙娜丽莎》，没有人能说它是赝品。这是一个理想的结果。然而，如果学生不够聪明，无法理解大师的想法和建议，或者老师不是列奥纳多·达·芬奇，而只是一个普通人，会发生什么？在这两种情况下，训练都会失败。
