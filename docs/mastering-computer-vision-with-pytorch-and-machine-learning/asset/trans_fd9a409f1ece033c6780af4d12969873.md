### I DDPM 前向过程后验分布与 `L`[VLB]

```
q(x_{t - 1}\mid x_{t},x_{0}) = \frac{q\left( x_{t - 1},x_{t},x_{0} \right)}{q\left( x_{t},x_{0} \right)} = \frac{q\left( x_{t}\mid x_{t - 1},x_{0} \right)q\left( x_{t - 1},x_{0} \right)}{q\left( x_{t}\mid x_{0} \right)q\left( x_{0} \right)}
```

```
q(x_{t - 1}\mid x_{t},x_{0}) = \frac{q\left( x_{t}\mid x_{t - 1},x_{0} \right)q\left( x_{t - 1}\mid x_{0} \right)q\left( x_{0} \right)}{q\left( x_{t}\mid x_{0} \right)q\left( x_{0} \right)} = q(x_{t}\mid x_{t - 1},x_{0})\frac{q\left( x_{t - 1}\mid x_{0} \right)}{q\left( x_{t}\mid x_{0} \right)}
```

```
q\left( {x_{t - 1} \mid x_{t},x_{0}} \right) = \mathbb{N}\left( {x_{t - 1};\widetilde{\mu}\left( {x_{t},x_{0}} \right),{\widetilde{\beta}}_{t}I} \right) = q\left( {x_{t} \mid x_{t - 1},x_{0}} \right)\frac{q\left( {x_{t - 1} \mid x_{0}} \right)}{q\left( {x_{t} \mid x_{0}} \right)}
```

```
\propto \exp \ \left( {- \frac{1}{2}\frac{\left( {x_{t} - \sqrt{\alpha_{t}}x_{t - 1}} \right)^{2}}{\beta_{t}} - \frac{1}{2}\frac{\left( {x_{t - 1} - \sqrt{{\overline{\alpha}}_{t - 1}}x_{0}} \right)^{2}}{1 - {\overline{\alpha}}_{t - 1}} + \frac{1}{2}\frac{\left( {x_{t} - \sqrt{{\overline{\alpha}}_{t}}x_{0}} \right)^{2}}{1 - {\overline{\alpha}}_{t}}} \right)
```

```
= \ \exp \ \left( {- \frac{1}{2}\left\lbrack {\frac{x_{t}^{2} - 2\sqrt{\alpha_{t}}x_{t}x_{t - 1} + \alpha_{t}x_{t - 1}^{2}}{\beta_{t}} + \frac{x_{t - 1}^{2} - 2\sqrt{{\overline{\alpha}}_{t - 1}}x_{0}x_{t - 1} + \alpha_{t}x_{0}^{2}}{1 - {\overline{\alpha}}_{t - 1}} - \frac{\left( {x_{t} - \sqrt{{\overline{\alpha}}_{t}}x_{0}} \right)^{2}}{1 - {\overline{\alpha}}_{t}}} \right\rbrack} \right)
```

```
= \ \exp \ \left( {- \frac{1}{2}\left\lbrack {\left( {\frac{\alpha_{t}}{\beta_{t}} + \frac{1}{1 - {\overline{\alpha}}_{t - 1}}} \right)x_{t - 1}^{2} - \left( {\frac{2\sqrt{\alpha_{t}}}{\beta_{t}}x_{t} + \frac{2\sqrt{{\overline{\alpha}}_{t - 1}}}{1 - {\overline{\alpha}}_{t - 1}}x_{0}} \right)x_{t - 1} + \left( {\frac{x_{t}^{2}}{\beta_{t}} + \frac{\alpha_{t}x_{0}^{2}}{1 - {\overline{\alpha}}_{t - 1}} - \frac{\left( {x_{t} - \sqrt{{\overline{\alpha}}_{t}}x_{0}} \right)^{2}}{1 - {\overline{\alpha}}_{t}}} \right)} \right\rbrack} \right)
```

```
= \ \exp \ \left( {- \frac{1}{2}\left\lbrack {\left( {\frac{\alpha_{t}}{\beta_{t}} + \frac{1}{1 - {\overline{\alpha}}_{t - 1}}} \right)x_{t - 1}^{2} - 2\left( {\frac{\sqrt{\alpha_{t}}}{\beta_{t}}x_{t} + \frac{\sqrt{{\overline{\alpha}}_{t - 1}}}{1 - {\overline{\alpha}}_{t - 1}}x_{0}} \right)x_{t - 1} + C_{0}\left( {x_{t},x_{0}} \right)} \right\rbrack} \right)
```

```
= \ \exp \ \left( {- \frac{1}{2}\left( {\frac{\alpha_{t}}{\beta_{t}} + \frac{1}{1 - {\overline{\alpha}}_{t - 1}}} \right)\left\lbrack {x_{t - 1}^{2} - 2\left( {\frac{\alpha_{t}}{\beta_{t}} + \frac{1}{1 - {\overline{\alpha}}_{t - 1}}} \right)^{- 1}\left( {\frac{\sqrt{\alpha_{t}}}{\beta_{t}}x_{t} + \frac{\sqrt{{\overline{\alpha}}_{t - 1}}}{1 - {\overline{\alpha}}_{t - 1}}x_{0}} \right)x_{t - 1} + C_{1}\left( {x_{t},x_{0}} \right)} \right\rbrack} \right)
```

在上述公式中，`C(x[t],x[0])` 是一个不涉及 `x[t-1]` 的函数，细节省略。遵循标准高斯密度函数，其中 `α[t] = 1 − β[t]`，`\overline{\alpha}_{t} = \prod_{i = 1}^{t}\alpha_{i}`，`q(x[t − 1]∣x[t],x[0])` 的均值和方差可以参数化如下：

```
\widetilde{\beta}_{t} = \left( {\frac{\alpha_{t}}{\beta_{t}} + \frac{1}{1 - \overline{\alpha}_{t - 1}}} \right)^{- 1} = \left( \frac{\alpha_{t}\left( {1 - \overline{\alpha}_{t - 1}} \right) + \beta_{t}}{\beta_{t}\left( {1 - \overline{\alpha}_{t - 1}} \right)} \right)^{- 1} = \left( \frac{1 - \overline{\alpha}_{t}}{\beta_{t}\left( {1 - \overline{\alpha}_{t - 1}} \right)} \right)^{- 1}
```
