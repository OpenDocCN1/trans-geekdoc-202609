
`pose` 矩阵左上角的 3×3 子矩阵等于新的旋转矩阵 `R`。从 `pose` 最后一列顶部的 3×1 子矩阵，我们得到一条射线原点，即相机旋转后的世界坐标，其中 `r` 是两个坐标系之间的距离。我们使用 `pose` 矩阵将 `X⃗[c]` 转换为 `X⃗[w]` 以供查询点使用。在模型训练期间，所有查询点和射线原点都通过第 04 个单元格中最后一个函数定义的函数进行位置编码。超参数 `L` 是编码函数的数量。查询点和射线原点的 `L` 值分别设置为 6 和 4。在下面的方程中，`q` 是一批查询点，批量大小为 `B`，其中 `L` = 6 为编码函数的数量。`q` 的坐标乘以 2π2⁰ 后，sin 函数对其逐元素作用，cos 函数也对其逐元素作用。这两个三角函数的运算结果被追加到 `q` 后面，构建一个包含九个元素的列表：[`q`，sin(2π2⁰`q`)，cos(2π2⁰`q`)]，频率为 2⁰。

```
sin(2π2ⁱq) = sin(2π2ⁱ [ q_x1 q_y1 q_z1; q_x2 q_y2 q_z2; ...; q_xB q_yB q_zB ]) i ∈ [0, (L - 1)]
```

`q` 的位置编码结果列表被拼接以获得形状为 `B`×(3+3×2×`L`) 的张量，作为第 05 个单元格中定义的 MLP 模型的两个输入之一。有了上述背景信息，应该很容易理解附录 [K](#Appendix1.xhtml#bk978-0-7503-6244-3AppAsA-K) 中列出的 tiny NeRF 项目代码。我的代码受 [Bmild](https://github.com/bmild/nerf/blob/master/tiny_nerf.ipynb) 启发。模型训练时间约为 125 分钟（每条射线 128 个查询点），PSNR 值约为 28.5。训练好的 MLP 模型随后由第 13 个单元格中的代码保存。保存的模型文件大小为 301 kB。运行第 14 个单元格中的代码，我们可以加载保存的模型，在距离 `r` 约为 4 处的任意 `θ` 和 `φ` 角度合成一张乐高图像。图 [12.7](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12fig7) 中右侧显示的图像是以下代码的输出。您可以更改以下函数第一行中 theta、phi 和 `r` 的值，以查看不同的合成图像。为了提高合成图像的质量，我们需要增加每条射线上的采样点，但我们会面临 GPU 显存限制和模型训练时间的问题。现在有许多新的 NeRF 算法使我们能够实时重建照片级真实感视频。计算机视觉的发展非常迅速。当您阅读本书时，书中的一些技术可能已经过时了。
