
# 条件概率与贝叶斯定理

条件概率是指在事件 *X* 已经发生或已知的情况下，事件 *Y* 的概率。记作 *P*(*Y*∣*X*)，表示给定 *X* 条件下 *Y* 的概率。

例如，掷骰子得到点数 5，随后抛硬币。硬币的条件概率仍为二分之一：
*p*(*y*[1]∣*x*[*i*] = 5) = ½，*p*(*y*[2]∣*x*[*i*] = 5) = ½（见表 [1.2](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t2)）。

条件概率表 *P*(*Y*∣*X*) 可通过联合概率表 *P*(*X*,*Y*) 底部的 *P*(*X*) 元素，对表 [1.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t1) 的六列分别归一化得到。*P*(*Y*∣*X*) 表 [1.2](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t2) 中的 12 个元素均为 ½。

同理，条件概率表 *P*(*X*∣*Y*) 可通过联合概率表 *P*(*X*,*Y*) 右侧的 *P*(*Y*) 元素，对两行分别归一化得到。*P*(*X*∣*Y*) 表 [1.3](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t3) 中的 12 个元素均为 1/6（见表 [1.3](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t3)）。

根据 **贝叶斯定理**，*p*(*x,y*)、*p*(*x*∣*y*)、*p*(*y*∣*x*)、*p*(*x*) 和 *p*(*y*) 之间的逐元素关系由公式 ([1.11](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn11)) 确定：

```
p(y | x) = p(x, y) / p(x) = p(x | y) / p(x) * p(y)
```

## 表 1.3 条件概率 *P*(*X*∣*Y*)

| *P*(*X*∣*Y*) | 骰子点数 (*X*) |
| :--- | :---: |
|  | One (*x*[1]) | Two (*x*[2]) | Three (*x*[3]) | Four (*x*[4]) | Five (*x*[5]) | Six (*x*[6]) |
| Head (*y*[1]) | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |
| Tail (*y*[2]) | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |

在上述公式中，*p*(*x*) 和 *p*(*y*) 为边缘概率或先验概率，*p*(*x*∣*y*) 是给定 *y* 条件下 *x* 的似然度，*p*(*y*∣*x*) 是给定 *x* 条件下 *y* 的后验概率。

以下例说明这些概率名称。某小岛上，55% (= *p*(*x*[1])) 为女性，45% (= *p*(*x*[2])) 为男性。女性中 10% (= *p*(*y*[1]∣*x*[1])) 吸烟，男性中 30% (= *p*(*y*[1]∣*x*[2])) 吸烟。吸烟者和不吸烟者变量分别为 *y*[1] 和 *y*[2]。已知某人正在吸烟（通过声音和气味），求该吸烟者为女性的概率？

为解答此问题，需根据上述数据构建后验概率 *P*(*X*∣*Y*) 子表（见表 [1.4](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t4) 右侧三列）。我们从似然度子表 *P*(**Y*∣*X*) 开始（表左侧三列）。‘吸烟者(*y*[1])’ 行单元格数值和边缘 *P*(*X*) 行数值已知。‘不吸烟者(*y*[2])’ 行数值可逻辑推得：女性中 90% 不吸烟，男性中 70% 不吸烟。

由似然度 *P*(*Y*∣*X*) 子表，可构建联合概率子表 *P*(*X*,*Y*)（表中间三列）。*P*(*X,Y*) 表中四个单元格的值依公式 ([1.11](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn11)) 计算：*p*(*x,y*) = *p*(*y*∣*x*) *p*(*x*)。

现知岛上所有人中：5.5% 为吸烟女性；13.5% 为吸烟男性；49.5% 为不吸烟女性；31.5% 为不吸烟男性。吸烟者和不吸烟者的边缘概率 *p*(*y*[1]) 和 *p*(*y*[2]) 分别为 19% 和 81%。

利用联合概率子表，可计算后验概率 *P*(*X*∣*Y*) 右侧四个单元格的值。计算同样基于公式 ([1.11](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn11))：*p*(*x*∣*y*) = *p*(*x*,*y*)/*p*(*y*)。例如，吸烟者为女性的概率 *p*(*x*[1]∣*y*[1]) = *p*(*x*[1], *y*[1]) /*p*(*y*[1]) = 28.9%。

即使只有男、女、吸烟、不吸烟四个变量，上述后验概率计算解释仍显复杂。鉴于有限的生命和资源，我们只能探索可及的世界部分。借助可获取数据和贝叶斯定理，我们能推导整个系统的信息。

在上例中，联合概率表 *P*(*X,Y*) 反映全岛人口的相对概率。先验概率表 *P*(*Y*∣*X*) 来自调查，反映各子人群（男、女）的相对概率。后验概率表 *P*(*X*∣*Y*) 由先验概率表和联合概率表推导，反映各子群体（吸烟者、不吸烟者）的相对概率。

实际上，无需构建表 [1.4](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t4) 中的三个子表。直接应用贝叶斯定理：
*p*(*x*[1]∣*y*[1]) = *p*(*y*[1]∣*x*[1])*p*(*x*[1])/*p*(*y*[1]) = *p*(*y*[1]∣*x*[1])*p*(*x*[1]) / [*p*(*y*[1]∣*x*[1])*p*(*x*[1]) + *p*(*y*[1]∣*x*[2])*p*(*x*[2])] = 28.9%。

可见，先验概率或似然度为已知数据，后验概率是从这些已知数据推断得出。

根据表 [1.4](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1t4) 中的概率，可利用以下公式计算联合熵 *H*(*X,Y*)、先验条件熵 *H*(*X*∣*Y*)、后验条件熵 *H*(*Y*∣*X*) 和互信息 *I*(*X,Y*)：

```
H(X, Y) = - Σ_{i=1}^{2} Σ_{j=1}^{2} p(x_i, y_j) ln(p(x_i, y_j)) = 1
```
