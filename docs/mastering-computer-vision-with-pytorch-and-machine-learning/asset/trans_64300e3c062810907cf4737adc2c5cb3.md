

在 Cell 01 中导入了更多的库或工具。`Torch` 是一个用于多维张量及其数学运算的 PyTorch 包。`Torch` 还为神经网络构建和模型训练提供了许多实用工具。我们将使用 `torch.nn` 来构建线性回归模型，并使用一个名为 `lr_scheduler` 的模块来实现可变学习率。Pandas DataFrame 将用于记录模型训练历史。`Pandas` 是一个 Python 包。Pandas DataFrame 是一个带有行和列的二维数据结构。你注意到了吗？在用于数据输入的 Cell 02 中，变量 `X` 和 `Y` 是 torch FloatTensor（浮点张量）？张量是一种数据容器，可用于存储一维、二维、三维甚至四维以上的数组或矩阵。一批批量大小为 64、图像分辨率为 256 × 256 的彩色照片，可以存储在一个形状为 64 × 3 × 256 × 256 的四维 PyTorch 张量中。在 Cell 02 中，来自 csv 文件的数据被存储在一个 NumPy 二维数组中。其两列随后分别被转换为形状为 9 × 1 的 float32 张量。此处 `view(-1, 1)` 和 `reshape(-1, 1)` 完成相同的工作。我们不需要将一个 ONES 张量与 `X` 连接起来。PyTorch 会处理这些额外的工作。如果你在 Cell 01 下方添加一个额外的单元格，并在该单元格中运行 `CF.dtype` 或 `X.dtype`，你会发现数组 `CF` 的数据类型是 'floating64'，而张量 `X` 的数据类型是 `torch.float32`。张量数据类型有很多种。有时我们需要将一种类型转换为另一种类型。在计算机视觉项目中，大多数时候我们将处理 `torch.float32`。偶尔，我们会使用 `torch.float16` 以节省内存和模型训练时间。

Torch 类 `nn.Linear(1,1)` 用于在模型中创建一个具有一个变量输入和一个变量输出的全连接神经网络层。从数学上讲，该模型旨在完成线性回归模型的工作：`X`@`w`^(`T`)。默认情况下，权重张量 `w` 是一个形状为 1 × 2 的张量。该张量的第一个和第二个元素分别代表斜率和截距（或偏置）。这个 Torch 模型所做的工作比数学运算 `X`@`w`^(`T`) 更多。它初始化权重数组 `w`，并存储模型的权重参数。请仔细阅读 Cell 03 的输出。它打印出了优化器的参数。在 Cell 04 中，我们将使用 `optimizer.param_groups[0]['lr']` 这一项在模型训练期间获取学习率。默认情况下，类 `nn.MSELoss()` 根据公式 ([1.34](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn34)) 执行任务。通过使用 `nn.MSELoss(reduction = 'sum')` 可以避免除以 `n`，从而减少模型训练时间。运行关于损失函数的 Extra-Cell-01 中的代码后，你会知道在该示例中平均损失等于 4.0（`loss` = [3 × (2 − 0)²]/3）。

有多种优化器，它们用于计算损失函数的梯度，并在模型训练期间通过 `optimizer.step()` 自动更新模型权重数组。Adam（自适应矩估计）优化器是最流行的。深入研究优化器的数学算法既不容易，也没有必要。

![](images/bk978-0-7503-6244-3ch1uf12_pr.gif)

学习率是模型训练中最重要的超参数。PyTorch 提供了许多学习率调度器，用于在模型训练期间改变学习率。最通用的调度器是 `LambdaLR`。你可以定义任何以训练轮数（`i`）为变量的函数。初始学习率（`lr`[0]）通常在 Cell 01 中为优化器设定，第 `i` 个 epoch 的学习率等于 `lr`[0] 乘以 Lambda 函数的值。在 Extra-Cell-02 中，第一个函数用于恒定学习率：`lr`[`i`] = 0.5 × `lr`[0]。使用第二个 lambda 函数，学习率在 20,000 个 epoch 的模型训练过程中线性下降。如果选择第三个或第四个函数，学习率将呈指数下降。第五个 lambda 函数与 PyTorch 中的 `CosineAnnealingLR` 调度器相同。第六个 lambda 函数有三个区段：`i` < 10,000，`i` 在 10,000 和 17,000 之间，以及 `i` > 17,000。最后一个 lambda 函数类似于 PyTorch 中的 `StepLR` 调度器。它从一个名为 `lr_list` 的列表中，按索引 `i`//5000 选取一个数字。
