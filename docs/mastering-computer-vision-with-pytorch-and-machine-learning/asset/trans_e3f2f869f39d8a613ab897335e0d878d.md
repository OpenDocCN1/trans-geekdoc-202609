
# OpenAI 的 ChatGPT（生成式预训练 Transformer）的诞生是计算机科学领域的一次突破

人们可以与计算机聊天，讨论任何主题。ChatGPT 似乎无所不知，能够回答人们提出的许多问题。在 ChatGPT 网站的界面上，我使用了文本提示词“please write Python codes about logistic regression for me”（请为我编写关于逻辑回归的 Python 代码）。随后在几秒钟内，我就能从 ChatGPT 复制代码并粘贴到 VS Code 的一个单元格中运行。计算机已通过图灵测试，这是 AI 领域的一种探究方法，用于判断计算机是否具备像人类一样思考的能力。

ChatGPT 是一种语言模型，它使用 Transformer（Vaswani *et al* [2017](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10bib4)）进行自然语言处理（NLP）任务，如语言翻译、文本分类和文本生成。Transformer 中包含一个编码器和一个解码器。用自然语言编写的文本提示词中的单词被数字化为高维向量空间中的 Token。Token 是一个小的信息单元。这些嵌入了文本提示词中单词序列信息的 Token 被用作 Transformer 编码器的输入。Transformer 中使用自注意力机制来捕捉论文中不同 Token 之间的依赖关系。Transformer 的使用给 NLP 任务带来了革命性的改进。

视觉 Transformer（ViT）是经过修改的 NLP Transformer，用于计算机视觉任务，如图像分类和目标检测。视觉 Transformer 由 Dosovitskiy *et al* 在其 2020 年的论文（Dosovitskiy *et al* [2020](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10bib1)）中提出，题为“An Image Is Worth 16 × 16 Words: Transformers for Image Recognition at Scale”（“一幅图像胜过 16 × 16 个词：大规模图像识别 Transformer”）。与传统卷积神经网络使用一系列卷积和池化层从图像中提取局部特征不同，基于 NLP Transformer 的 ViT 可以捕捉图像不同部分之间的空间关系。

## 10.1 基础 ViT 模型的架构

在基于 ViT 论文（Dosovitskiy *et al* [2020](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10bib1)）的基础 ViT 模型中，仅有一个经过修改的编码器，没有解码器。输入 ViT 模型的任何彩色图像都应调整大小为 `3 × 224 × 224`，然后按指定的补丁大小分割成一个补丁网格。如果补丁大小为 8，则图像被分割成 784 (=224/8 × 28) 个补丁。每个彩色补丁随后被展平为一个一维数组，作为一个包含 192 (=3 × 8 × 8) 个元素的 Token。ViT 的核心思想是将图像视为一系列 Token，然后使用 Transformer 的编码器处理这些 Token。这使得 ViT 能够捕捉整幅图像的全局信息，而不仅仅是 CNN 网络从特定区域获取的局部信息。视觉 Transformer 已取得最先进的性能。它们也已被用于各种应用，包括图像描述生成、图像生成和视频分类。以下项目 [10.1.1](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10ueqn1) 中的代码用于解释基础 ViT 模型的架构。

照常，单元格 01 中的代码导入项目所需的库，并在一个名为 `config` 的字典中设置超参数。在单元格 02 中定义的类里，使用了一个名为 `einops` 的工具或库，根据文本指令 `b c (h h1) (w w1) -> b (h w) c h1 w1` 重塑和排列输入图像，其中 b、c、h1 和 w1 分别代表批次大小、图像通道数（=3）、行和列方向上的补丁大小（= 8 像素）。基于已知的输入图像尺寸（224），该类的一个实例计算出另外两个参数 h 和 w（28 = 224/8）。Einops 是计算机视觉中用于张量操作的强大库。名称 `einops` 代表“Einstein operations”（爱因斯坦运算），灵感源自物理学中爱因斯坦在其相对论中用于表达张量运算的爱因斯坦求和约定。文本指令中一对括号内的两个参数用于表示一个参数的值，该值等于这两个参数的乘积。例如，`(h h1)` 对应图像高度 224 这一参数，其值等于 28 × 8。虽然我们可以使用 PyTorch 工具（如 `reshape` 和 `permute`）完成相同的工作，但 `einops` 配合文本提示词更易于理解。然后，图像的每个彩色补丁被展平为一个包含 192 个元素的张量（D = 3 × 8 × 8）。通过上述操作，一个二维图像 *x* ∈ ℜ^(*C* × *H* × *W*) 被分割成一系列展平的二维补丁 *x*[*p*] ∈ *R*^(*N* × (*P*² ⋅ *C*))，其中 *H*×*W* 是输入图像的分辨率，*C* 是图像通道数，*P* 是补丁大小，而 *N* (= *HW*/*P*²) 是补丁数量。每个展平的补丁就像 NLP 中的词 Token 一样是一个 Token。Token 的使用使 ViT 能够学习图像不同区域之间的关系，并基于图像的整体上下文进行预测（图 [10.1](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10fig1)）。
