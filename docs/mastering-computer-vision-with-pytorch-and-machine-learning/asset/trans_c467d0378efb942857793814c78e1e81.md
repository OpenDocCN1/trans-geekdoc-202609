

# YOLOv8 发布与应用

2023 年 1 月 10 日，Ultralytics 创始人 Glenn Jocher（几年前也发布了 YOLOv5）发布了 YOLOv8。基于之前 YOLO 版本的成功，YOLOv8 的设计旨在更快、更准确且更易于使用。如果你曾设法在电脑上安装过 YOLOv3，你就会体会到 YOLOv8 团队为我们所做的工作。我曾花了一周时间在电脑上编译 YOLOv3 的 darknet，因为我必须想办法协调 VC++、OpenCV、Nvidia CUDA 和其他第三方软件以共享它们的库。对于 YOLOv8，只需在 VS Code 终端中使用一条 DOS 命令 `pip install ultralytics`，即可在几分钟内在 VS Code 的虚拟环境中安装 YOLOv8，具体时间取决于你的网速从 YOLOv8 网站下载文件。有许多模型支持预训练参数文件供下载。这些文件不大，且便于人们使用。在 YOLOv8 的主页上，有关于如何安装 Ultralytics 和使用预训练模型的详细说明。YOLOv8 的 DOS 命令行界面 (CLI) 让我们能够在各种任务上训练、验证或推理模型。以下是一个使用笔记本电脑摄像头为自己拍摄视频的 DOS 代码示例。在 DOS 代码前加上感叹号 `!`，甚至可以在 VS Code 单元格中运行它。如果你将以下 DOS 命令中的保存选项设为 True，你的视频将被保存到一个文件中。我从 YouTube 下载了一个交通视频并将其保存到名为 `d:/traffic.mp4` 的文件中。将 DOS 命令的 source 选项从 0 改为视频文件名，我就可以观看带有边界框、标签和概率的视频帧。视频处理速度约为 100 FPS。使用 YOLOv3 和 YOLOv7 模型时，速度分别为 2 和 20 FPS。将 source 改为名为 `d:/dog.jpg` 的图像文件，你可以看到来自预训练 yolov8 模型的目标检测结果。然而，图像在我电脑屏幕上很快就消失了。将模型改为 `yolov8n-seg.pt`、`yolov8n-cls.pt`、`yolov8n-pose.pt` 和其他预训练模型，我们可以使用单行代码进行实例分割、图像分类和姿态估计。模型名称中 yolov8 后面的字母可以是 `n`、`s`、`m`、`l` 和 `x`，分别表示预训练 YOLOv8 模型的大小，从 nano、small、medium、large 到 extreme large。

```
yolo task=detect mode=predict model=yolov8n.pt source=0 conf=0.25 iou=0.5 conf=0.15 show=True save=False
```
