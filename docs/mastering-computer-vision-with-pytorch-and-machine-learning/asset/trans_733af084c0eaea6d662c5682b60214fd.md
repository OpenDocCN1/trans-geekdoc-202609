
2023年5月，Deci AI发布了用于目标检测的YOLO-NAS模型。缩写NAS代表“神经架构搜索”，这是Deci发明的一项技术，用于自动化神经网络架构的设计过程。在`Deci/super-gradient`的GitHub仓库中，声称“新的YOLO-NAS以无与伦比的精度-速度性能提供了最先进（SOTA）的表现，优于`YOLOv5`、`YOLOv6`、`YOLOv7`和`YOLOv8`等其他模型。”`SuperGradients`是一个基于PyTorch的训练库。基于`SuperGradients`，Deci在开源许可下提供了三个预训练模型：`yolo_nas_s`、`yolo_nas_m`和`yolo_nas_l`，并提供了可用于非商业用途的预训练权重。我们可以使用`pip install super-gradients`在配备Python v7-9和PyTorch 1.9-1.10的VS Code虚拟环境中安装`SuperGradients`。使用小、中、大三种尺寸模型的目标检测速度分别为15、10和10 PFS。从上一节可知，模型`yolov8n.pt`和模型`yolov8l.pt`的速度分别为80和30 FPS。令人惊讶的是，在我的电脑上YOLO-NAS比YOLOv8慢。Nicolai Nielsen的一个YouTube视频也显示YOLOv8比YOLO-NAS快。受Aarohi Singla和Roboflow代码的启发，我编写了代码对大型YOLO-NAS模型进行微调，用于我的MNIST4yolov7数据集。训练100个epoch耗时超过四小时。YOLOv8模型训练100个epoch仅需0.3小时，且YOLOv8模型训练代码只有几行。我不展示微调大型YOLO-NAS模型的代码，因为它们非常长。

# 第9章

## 用于图像分割的U-Net和用于图像生成的扩散模型

U-Net是一种具有特殊架构的ResNet，易于训练且所需训练样本少。在第[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9s9-1)节中，U-Net被用于视网膜血管分割。附录[H](#Appendix1.xhtml#bk978-0-7503-6244-3AppAsA-H)中列出了将U-Net作为图像生成器用于同一任务的WGAN-GP代码。在第[9.3](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9s9-3)节中，基于U-Net的Hugging Face预训练扩散模型被用于为牛津花卉数据集生成照片级真实感图像。数学原理在第[9.2](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9s9-2)节中通过生成二次曲线的代码进行了解释。使用Hugging Face的Stable Diffusion模型，我们甚至可以指示计算机根据我们的文本提示生成美丽的图像。

YOLOv8在目标检测和分割方面非常强大，但这些目标必须是可计数的。许客体如我们体内的血管系统和地球上的河流系统具有分形结构。为了分割来自显微镜或卫星的、关于具有分形结构的不可计数物体的图像，我们可以使用U-Net，这是一种由Olaf Ronneberger、Philipp Fischer和Thomas Brox在他们2015年发表的论文（Ronneberger *et al* [2015](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9bib6)）中提出的残差卷积网络。该论文标题为“U-Net：用于生物医学图像分割的卷积网络”。U-Net架构已被证明在各种图像分割任务中有效，特别是在可用训练数据有限的情况下。使用少于100张图像训练U-Net，我们就能快速获得优秀的分割结果。它能够实现准确且详细的分割结果，捕捉图像中的局部和全局信息。U-Net也被用于扩散模型进行图像生成。来自扩散模型的生成图像具有照片级真实感质量。

### 9.1 DRIVE数据集的U-Net视网膜血管分割

DRIVE数据集用于演示U-Net的超强能力。该数据集名称是“用于血管提取的数字视网膜图像”（Digital Retinal Images for Vessel Extraction，DRIVE）的缩写。该数据集由Joes Staal *et al*在其论文（Staal *et al* [2004](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9bib7)）中引入，论文标题为“基于脊线的视网膜彩色图像血管分割”。我们可以从Kaggle下载该数据集的zip文件。压缩文件大小小于30 MB。解压文件到名为`d:\Retina`的文件夹后，我们可以找到一个“training”子文件夹和一个“test”子文件夹。这两个子文件夹各自包含一个“images”子文件夹，里面有20张TIF格式的彩色眼底图像（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(A)）。所有彩色图像的分辨率相同：565 × 584像素，每通道8位（三通道）。根据Staal的说法，这些图像来自荷兰的一个糖尿病视网膜病变筛查项目，40张图像中有7张涉及异常病理病例。在训练子文件夹中，有一个名为`1st_manual`的文件夹，包含20张黑白GIF图像（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(B)）。它们是由一位眼科专家手动分割的结果，并被用作模型训练的真值。从图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)所示图像中，我们可以了解我们要对这些图像做什么：在下面的项目[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9ueqn2)中，利用U-Net从这些彩色眼底图像自动生成血管的黑白图像（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(C)）。U-Net架构有几个关键特征：

*   **收缩路径**（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(C)左侧）由一系列卷积层和池化层组成，逐步降低空间分辨率同时增加特征通道数。该路径捕捉上下文并从输入图像中提取高层特征。
*   **扩张路径**（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(C)右侧）由一系列转置卷积层和卷积层组成，增加空间分辨率同时减少特征通道数。它将收缩路径的低层特征与高层特征相结合，以生成详细的分割图。
*   **跳跃连接**（图[9.1](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9fig1)(C)中的水平箭头）连接收缩路径和扩张路径中对应的层，使网络能够同时利用局部和全局信息进行准确分割。跳跃连接即残差连接。
*   **最终层**：U-Net的最后一层是一个1 × 1卷积层。
