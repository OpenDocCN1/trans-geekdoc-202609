## 知识蒸馏及其在DINO和SAM中的应用

2023年，Facebook发布了许多基于视觉Transformer的计算机视觉模型。尽管它们非常强大，但体积过大，不适合在资源/功率受限的设备上实时使用。知识蒸馏被用于将预训练的巨型模型的智能迁移到小型模型中。第[11.1](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11s11-1)节演示了第[2](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2)章中使用的从`ResNet9`到`ResNet6`的知识蒸馏。第[11.2](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11s11-2)至[4](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11s11-4)节的示例展示了Facebook的`DINO`、`DINOv2`和`SAM`模型在自监督学习中寻找图像或视频帧中目标特征的智能。由于`SAM`需要8 GB GPU显存，我不得不在CPU上运行它，速度非常慢。来自中国的`fastSAM`模型使我们能够以比`SAM`快50倍的速度分割任何物体。

### 11.1 用于神经网络压缩的知识蒸馏

根据摩尔定律，集成电路（IC）芯片中的晶体管数量大约每两年翻一番。这使得更快的处理器、更大的内存容量以及各种计算设备性能的提升成为可能。计算机视觉项目和机器学习项目中神经网络的参数数量也显著增加，以构建更强大、功能更丰富的模型。在线性回归模型（项目[1.3.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn15)）中，只有两个参数；在关于用于图像分类的基础视觉Transformer模型的项目[10.1.1](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10ueqn1)中，有14,443,018个参数。ChatGPT模型（基于GPT 3.5）拥有1750亿个参数。然而，随着模型参数量从百万级增加到十亿级，模型训练和部署的计算成本将更加高昂。随着智能手机、智能手表等各类智能移动设备的兴起，我们需要一个小型神经网络模型（学生模型）来具备巨型模型（教师模型）的功能。知识蒸馏（Hinton *et al* [2015](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11bib2)）是指一种机器学习技术，教师模型在学生模型的训练过程中通过使用“软目标”将其知识迁移给学生模型。知识蒸馏的目标是将大型模型包含的知识压缩到可部署在资源受限设备上的较小模型中。知识蒸馏已成功应用于计算机视觉、自然语言处理和语音识别等许多领域。它是一种流行的模型压缩和迁移学习技术，允许将大型模型的知识迁移到可用于实际应用的较小模型中。

软目标是教师模型的输出。来自项目[2.3](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2ueqn22)的预训练`ResNet9`模型（用于CIFAR10图像分类）被保存为教师模型，用于以下项目[11.1](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11ueqn1)。其对训练集、验证集和测试集中图像的分类预测准确率分别为99.5%、92.6%和92.3%。从项目[2.3](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2ueqn22)的单元格10可以看到，训练好的`ResNet9`对测试数据加载器中仅一张图像的一个批次的输出`y_hat`为`[[−103.4488, −113.6267, −95.8173, −90.3314, −70.0091, −96.2804, −94.8856, −100.3270, −113.8334, −108.6170]]`。`y_hat`中的10个元素中的每一个都是一个logit ![image](images/bk978-0-7503-6244-3ch11ieqn1.gif)，它在温度`T`下为预训练教师模型产生一个软目标概率`p[i]`，其中`i` =0,1…,9

$$p\_{i} = \\frac{e^{v\_{i}/T}}{\\sum\\limits\_{j = 1}^{C}e^{v\_{j}/T}}$$
