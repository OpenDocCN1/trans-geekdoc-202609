# 前言

### 本书内容简介

《Mastering Computer Vision with Pytorch and Machine Learning》（使用PyTorch和机器学习掌握计算机视觉）一书为从零开始使用Python和PyTorch掌握用于图像处理的高级计算机视觉技术提供了详尽且广泛的指南。计算机视觉是人工智能和计算机科学的一个领域，专注于使计算机能够解读和理解来自周围世界的视觉信息。计算机视觉和机器学习是紧密相关的领域。机器学习用于计算机视觉，以使计算机能够自动在大量图像和视频数据集中发现模式和关系。本书专注于实际应用，涵盖了诸如Kullback-Leibler散度、最大似然估计、卷积神经网络（`CNN`）、生成对抗网络（`GAN`）、Wasserstein生成对抗网络（`WGAN`）、带梯度惩罚的WGAN（`WGAN-GP`）、信息最大化生成对抗网络（`infoGAN`）、变分自编码器（`VAE`）等核心概念，以及它们在图像分类/图像生成中的应用。读者还将学习如何利用最新的计算机视觉技术，如用于目标检测的`Yolov8`、用于图像生成的稳定扩散模型、用于零样本目标检测的视觉变换器、用于神经网络压缩的知识蒸馏、用于自监督学习的`DINO`、分割一切模型（`SAM`），以及用于3D场景合成的`NeRF`和3D高斯泼溅。本书是专业人士、研究人员和希望扩展其使用PyTorch的高级计算机视觉技术知识的学生的宝贵资源。通过清晰的解释、实际示例和真实用例，读者将学习如何将计算机视觉技术应用于图像分析任务，并培养构建和训练用于高级图像分析的自有模型所需的技能。无论您是初学者还是经验丰富的数据科学家，本书都将为您提供成功所需的知识和工具。

### 读者前置要求

计算机视觉项目使用神经网络模型或视觉变换器作为数学函数来处理图像。这些函数的输出可能是用于图像分类的整数、用于图像生成的与训练数据集中图像相似的新图像，或用于目标检测的带有类别标识和概率的边界框。模型中的神经网络是按特定序列组织的数学算子。大规模计算机视觉模型可能拥有数十亿个参数，需要从训练数据集中学习。模型训练时间取决于输入数据的大小、Python代码以及处理数据的计算机硬件。本书面向具备矩阵计算线性代数知识和统计学基本概念的读者。有了这样的数学背景，读者即使不了解Python——一种简单且功能强大、具有卓越机器学习功能的编程语言——也能编写代码。`Kaggle`和`Google Colab`为拥有Google账户的任何人提供免费GPU。在这两个免费的互联网平台上，强大的计算机硬件和软件随时可用。本书列出的大多数代码可以在任一平台上运行。读者无需购买昂贵的计算机。

鉴于`Kaggle`和`Google Colab`存在某些限制，最好拥有安装了以下开源软件的自己的计算机。首先是`Microsoft Visual Studio Code`（`VS Code`）。它是微软提供的免费代码编辑器，适用于Windows、Linux和macOS。它拥有许多用于编辑、调试和用多种编程语言开发代码的功能和扩展。由于其易用性、可定制性和社区驱动的开发模式，它是各种技能水平人群的热门选择。在`VS Code`终端中，我们可以安装许多扩展，例如`Python`、`Jupyter notebook`、`PyTorch`、`Torchvision`、`NumPy`、`Pandas`、`Matplotlib`、`OpenCV`、`tqdm`等。计算机科学的发展日新月异。我们需要在`VS Code`中拥有多个虚拟工作区，以适配不同版本的Python和其他库。本书中的大多数代码可以在Python v3.6下运行，而最后六章中的许多代码必须在Python v3.9至v3.11下运行，以支持最新的计算机视觉技术，如`Ultralytics Yolov7`至`Yolov9`、Hugging Face零样本目标检测、Facebook `DINO`和`SAM`。
