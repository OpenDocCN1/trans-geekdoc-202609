```
python train.py --weight yolov7.pt --data MNIST4yolov7/data.yaml --batch-size 4
```

`train.py` 存在一个问题，许多人在网上搜索解决方案。对于我的电脑，一种解决方法是在 `yolov7` 文件夹下的 `train.py` 文件第 4 行的 `import os` 之后添加 `os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"`。还有一个问题也困扰了许多人。模型训练的默认批次大小为 16。我的笔记本电脑内存不够大，所以我将批次大小减小到 4。一旦解决了第二个问题，漫长的训练过程便开始了。

默认训练轮数为 300。经过约 2.3 小时的模型训练后，我发现训练结果不佳。混淆矩阵（图 [8.1](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8fig1)）对角线上的数值较低。数字 3 和数字 5 的数值甚至低于 0.4。在理想结果中，混淆矩阵对角线上的每个数字都应等于 1。这意味着每个真实标签都能被 100% 正确预测。随后，我使用每次训练得到的最佳权重文件 `best.pt` 又进行了六次训练，每次将轮数设为 200。最终结果如图 [8.1](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8fig1) 所示。混淆矩阵对角线上 10 个数字的数值均高于 0.9。训练 200 个轮次耗时 1.5 小时。总训练时间约为 12 小时。在 VS Code 终端中使用以下命令，我得到了图 [8.1](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8fig1) 右下角显示的带有数字的黑白图像：

```
python detect.py --weights best6MNIST.pt --conf 0.4 --img-size 448 --view-img --source 0614.jpg
```

训练好的 YOLOv7 模型适用于 MNIST4yolov7 数据集。在纸上书写数字并将上述 DOS 命令中的 source 改为 0，我惊讶地发现训练好的模型无法识别我手写体中的任何数字。随后，我将 MNIST4yolov7 图像复制到手机上，将手机屏幕上显示的图像对准笔记本电脑的摄像头，训练好的模型工作良好。YOLOv7 模型很容易对 Chess 数据集进行训练。仅用 300 个轮次，训练结果就非常好。从 Rob Mulla 发布的 YouTube 视频 ([www.youtube.com/watch?v=RXbtSwZsoEU](https://www.youtube.com/watch?v=RXbtSwZsoEU)) 中，你可以了解更多关于如何使用 YOLOv7 训练自有数据集的信息。

## 8.2 YOLOv7 实例分割

图像分割是一项计算机视觉任务，旨在将图像或视频帧划分为不同的区域或片段。它可用于帮助我们在更细粒度的层面上理解和分析图像内容。图像分割主要有三种。第一种是语义分割，它用相同的颜色标记同一类别所有目标的所有像素，甚至图像上的背景（天空、草地、树木）像素也会被标记上颜色。第二种是实例分割，它仅标记图像上可计数目标的像素，并且图像上同一类别的每个目标都通过不同的掩码颜色加以区分。第三种是全景分割，它是上述两种分割的结合。利用 Detectron2 的库，YOLOv7 模型可以为我们执行实例分割。Detectron2 是 Facebook (Meta AI) Research 推出的新一代开源目标检测框架。

在 WongKinYiu 的 GitHub 仓库网站上，有一个 mask 分支。mask 分支中的代码将 Detectron2 的一些模块与 YOLOv7 进行了集成。我们可以从 mask 分支下载一个 zip 文件，并将其解压到 VS Code 工作区中名为 `mask` 的文件夹内。YOLOv7 的虚拟环境可用于 mask 代码。我们还需要从 Detectron2 的 GitHub 仓库下载一个 zip 文件，并将其解压到一个名为 `detectron2` 的文件夹中。在我的 VS Code 工作区中，`detectron2` 文件夹、`mask` 文件夹和 `yolov7` 文件夹位于同一层级。有许多 YouTube 视频指导我们如何在电脑上安装 Detectron2。这并非易事，因为需要 Visual Studio 2022 来编译 `detectron2` 文件夹中的某些 C++ 文件。在我的电脑上，大多数问题源于 CUDA 库。解决 Detectron2 安装问题后，我们就能站在巨人的肩膀上做一些伟大的事情。打开一个新的 Jupyter 笔记本，将其命名为 `mask` 并保存在 VS Code 工作区中 `mask` 文件夹内，然后将项目 [8.2](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8ueqn3) 的单元格 01-05 复制到该笔记本中。单元格 01 第 04 至 06 行的代码从 `../mask/utils` 子文件夹中的文件导入库。第 07 至 10 行的代码从 `../detectron2` 子文件夹中的文件导入库。随后，单元格 02 中的代码导入 YOLOv7 模型，并加载预训练权重文件：`yolov7-mask.pt`。根据单元格 02 第 02 行的代码，许多超参数也从文件 `hyp.scratch.mask.yaml` 中导入。你可以在单元格 02 之后的一个额外 VS Code 单元格中使用 `print(hyp)` 来查看这些参数。
