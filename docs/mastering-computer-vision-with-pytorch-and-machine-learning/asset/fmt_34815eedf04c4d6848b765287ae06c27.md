
## 5.2.1 Project: Generation of Fake Quadratic Curves

In the following project [5.2.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5ueqn12) for generation of fake quadratic curves, only two fully connected layers are used in both the encoder model (`Q`) and the decoder model (`P`) of a beta-VAE system. In Cell 01, the hyperparameter `z_dim` is set to be equal to 2 for convenience of data visualization. That means that each curve with 21 points is generated from a 2D latent vector. The decoder of the system will use two numbers sampled from a 2D Gaussian distribution to restore each curve with 21 points. The hyperparameter beta is set to be equal to 0.5 so we can balance the contributions of the two parts in the loss function. Noises are added to the quadratic curves (line 04 of Cell 02). In figure [5.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig1)(A), the 64 real curves are not smooth because of the noises. We do not have a dataset for the project. The data for model training is generated whenever we need a batch of data in a dataloader, and the batch number per epoch is set to be 5.

The architecture of a VAE system is shown in figure [5.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig1)(A). Each real curve in a batch with noise was processed by the encoder model `Q` to obtain two vectors for a multivariate Gaussian distribution: a mean vector (`μ`) and a standard deviation vector (`σ`). Then a latent vector `z` is generated by `z = μ + σε` for each real curve, where `ε` is a random number generated from a standard multivariate normal distribution `N(0,I)`. In the following project codes, you will see a trick which shows how to calculate the standard deviation vector (`σ`) in which each element must be a positive number. The decoder's model `P` uses a batch of the latent vectors `Z` to generate a batch of fake images (`X̂`). Those fake curves shown in figure [5.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig1)(A) are very noisy at the beginning of model training. Then at epoch 20,000, noises are filtered out and the fake curves shown in figure [5.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig1)(C) are smooth.

The encoder class defined in Cell 04 uses a batch of real curves as its input which is processed by a fully connected layer. The encoder outputs a latent vector `z`, a mean (`μ`) tensor, and a log variance (`ln(σ²)`) tensor. The latent vector `z` is sampled from a normal distribution `N(μ,σ²)` by `z = μ + σε`, where `ε` is a random number generated by a standard normal distribution `∼N(0,I)`. This is the trick to calculate standard deviations (std) which must be positive numbers. From the log variance, we can get the standard deviation by `σ = √(e^(ln(σ²)))`. The decoder `P` defined in Cell 05 has two fully connected layers as usual. It uses a batch of latent vectors as its input. The output of the decoder is a batch of fake curves. According to equation ([5.4](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5eqn4)), the loss function is defined in Cell 06. If the two parts in the loss function are calculated with `mean` instead of `sum`, we have to adjust the `β` value to be around 0.01. The Adam optimizer is used for model training. The training function defined in Cell 07 uses a pandas dataframe to record loss values during model training. In each epoch, five batches of real curves are generated for model training. Each batch of the training data is processed by the encoder model `Q`. The output `z` of model `Q` is the input of model `P` to generate fake curves. Then loss values are calculated, and the parameters of the two models are updated by the Adam optimizer. Loss function curves are shown in figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(A).

Codes in Cell 09 calculate the trained `Q`'s outputs with five batches of training data for `mu`, `std` and `z`. The latent vectors (`z`) are then plotted in figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(B), and their distribution pattern follows a 2D standard normal distribution function. If `β` = 4.0, each element of the `mu` array is very close to 0.0, and each element of the `std` array is very close to 1.0. If `β` = 0.0, the dots in figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(B) are in a straight line, and each element of the `std` vectors is very close to zero. The hyperparameter `β` can be used to compress the latent vectors into an area following a standard normal distribution. That is the job of the autoencoder network. In figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(B), coordinates of two latent vectors marked by ⊗ and ⊕ are [−2,0] and [2,0] respectively. From them, two smooth fake curves were generated by the decoder `P`, and are shown in figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(C). The value `z[0]` of a latent vector can be used to tune vertical positions of fake curves. The value of `z[1]` gives us power to adjust the smoothness of fake curves. The zig-zag fake curve in figure [5.2](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5fig2)(C) was generated with a latent vector `z` = [−2, 15]. Every time you run the codes of the project, the controllers for fake curves would be different. Sometimes, value of `z[1]` could control the positions of fake curves on the `y`-axis.
