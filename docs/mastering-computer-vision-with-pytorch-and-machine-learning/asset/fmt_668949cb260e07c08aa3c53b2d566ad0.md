
# 模型输出与交叉熵计算

在方程（[2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn1)）左侧，`ŷ`张量是模型对数据加载器中一批图像的输出，其中`n`是批次大小。在Extra Cell THREE示例中，批次大小为3。`ŷ`张量有`m`列，对应数据集中的`m`个类别。在同一示例中，`m`等于4。Extra Cell FOUR的第一行使用`SoftMax`函数，作用于`ŷ`张量每行的每个元素，并带有选项`dim = 1`，如方程（[2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn1)）所示。这样，方程（[2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn1)）右侧`Ŷ`张量每行的和等于1。张量`Ŷ`用于表示`SoftMax`操作作用于`ŷ`张量的结果。然后，`1 × n`张量`targets = [2,1,0]`在Extra Cell FOUR第03行被独热编码为（`n × m`）目标张量`p`。张量`p`中大多数元素的值为零，只有`p[0,2]`、`p[1,1]`、`p[2,0]`被设置为1。交叉熵随后根据方程（[1.7](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn7)）计算，该方程修改为方程（[2.2](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn2)）。张量`p`每行中唯一的非零元素用于选取`Ŷ`张量同一位置的元素进行交叉熵计算。由于这些数学操作由交叉熵损失函数自动完成，我们在图像分类模型中无需提及`SoftMax`操作。

# 训练循环与预测统计

在Cell 06中，`model.train()`函数将模型设置为训练模式，以便计算损失函数对模型参数的梯度。在一个`for`循环中，训练数据加载器中的每一批图像和标签通过`cuda()`加载到GPU内存。经过模型输出每行的`SoftMax`函数处理后，`Ŷ`张量每行都有一个最大值。通过`torch.argmax`函数，我们可以找到每行最大值所在的列索引。这些索引存储在Cell 06第07行名为`predictions`的`1 × 32`张量中。下一行使用`torch.sum(predictions == targets)`计算正确预测的数量。运行额外单元格中的代码`a = torch.tensor([1,0,3,2]); b = torch.tensor([1,2,3,1]); torch.sum(a == b)`，你将了解如何找到两个1D张量中匹配元素的总和。Cell 06中的其余代码并无新意。由于损失函数带有选项`reduction = 'sum'`，变量`total_loss`的值被除以60,000（训练数据集中的总图像数）。此外，变量`n_correct`记录数据集中标签的正确预测数量。返回值`100 * n_correct / 60000`给出了准确预测百分比。Cell 07用于`test_dataloader`，以检查训练好的模型是否存在过拟合问题。该单元格中的代码`model.eval()`将模型设置为评估模式（不计算梯度）。Cell 07的输出是测试损失和测试准确率。在Cell 08中，使用`pandas`数据框记录训练历史。返回的数据框在Cell 09中用于绘制训练结果。

# 过拟合分析与模型对比

我们必须使用测试数据集进行模型训练，以发现分类准确率的过拟合问题。测试准确率应低于训练准确率。图[2.3](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2fig3)显示，测试数据集的预测准确率比训练数据集低约2%。在模型训练开始时，模型参数由PyTorch随机设置，模型未经过良好训练，因此测试准确率可能高于训练准确率。根据准确率和损失图表，模型训练存在一定的过拟合问题。这对于模型训练是正常的。`Adam`和`SGD`优化器均可用于模型训练，测试准确率均约为98%。如果模型仅有一个神经层，代码为`nn.Linear(784,10)`，测试准确率超过92%。如果模型有三个全连接层和两个激活函数，测试准确率仍在98%左右。从Cell 10的输出可知，简单模型有79,510个参数。为了提高测试分类准确率，我们需要使用具有不同算法和更多参数的模型。

# 混淆矩阵与评估指标

在用于图像分类、图像分割和目标检测的计算机视觉项目中，评估模型训练的首要指标是准确率，但这还不够。从Cell 11中代码获得的关于测试数据集的混淆矩阵（表[2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2t1)），可以得到四个更多指标（表[2.2](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2t2)），用于获取关于模型训练结果的详细信息。在混淆矩阵表中，左列的类别名用于真实标签，顶行的类别名用于训练模型预测的标签。我们将仅以类别名“Five”（数字5）所在行为例解释混淆矩阵。在892张数字5的图像中，只有870张预测正确。有2张数字5被预测为0，8张被预测为3，……，1张被预测为9。对于训练数据集的混淆表，除对角线上的10个数字外，所有数字均为零。表[2.1](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2t1)中混淆矩阵对角线上的那10个数字是10个类别的真阳性（TP）值。表中某行的求和称为“support”（支持度），等于该类别的总真实值。支持度包含两部分：该类别的真阳性（TP）和假阴性（FN）。一个名为**recall**（召回率）的指标等于TP与（TP+FN）的比率。它反映了在某类别真实值中正确预测的百分比。
