## 12.2 用于3D场景合成的神经辐射场

还有另一种称为神经辐射场的计算机视觉技术（Li *et al* [2022](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib4)）（NeRF），它也可用于图像深度估计。然而，NeRF最令人印象深刻的功能是利用围绕物体拍摄的一组2D图像合成物体的3D模型，然后该3D模型的数据可被其他软件（如[Meshlab](https://www.meshlab.net/)）用于3D打印。从高中数学知识出发，我们可以推导出公式，从相机在两个位置拍摄的两张图像中提取物体的3D信息。这就是为什么许多动物和昆虫在进化过程中拥有两只眼睛，以获得我们世界的立体视觉。利用相机围绕物体拍摄的20~100张图像，NeRF拥有足够的数据通过智能算法合成3D场景。原始NeRF论文（Mildenhall *et al* [2020](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib7)）发表于2020年8月。由于NeRF的模型训练时间非常慢（数小时甚至数天），近年来提出了许多基于原始NeRF的模型。Nvidia的即时NeRF（Müller *et al* [2022](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib8)）可以在几秒钟内从图像合成3D场景。我们甚至不需要从Nvidia的[GitHub](https://github.com/NVlabs/instant-ngp)网站安装Python文件，因为Nvidia提供了一个可执行的二进制文件[instant-ngp.exe](https://github.com/NVlabs/instant-ngp/releases/download/continuous/Instant-NGP-for-RTX-2000.zip)供下载，用于Windows操作系统。按照GitHub网站的说明，我用手机围绕图[12.3](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12fig3)所示的一尊公牛和母牛雕塑拍摄了35张照片。为了节省计算时间，我将这些图像的分辨率从4096×2304调整为843×474。使用[Colmap](https://colmap.github.io/)和[colmap2nerf.py](https://github.com/NVlabs/instant-ngp/blob/master/scripts/colmap2nerf.py)，我获得了一个关于我相机`内参`的`transforms.json`文件，如下所列。在该文件中，每张图像都有一个4×4的`变换矩阵`，用于将每张图像的像素坐标转换为图像中每个物体的3D世界坐标。

### 12.2.1 相机内参矩阵和外参矩阵

我们在计算机视觉项目的模型训练中使用了大量来自数码相机的照片。数码相机将我们3D世界中的物体投影到其2D光子传感器（CCD或CMOS阵列）上以创建数字图像。利用NeRF技术，我们可以利用一组图像来重建或合成3D世界中物体的3D场景。为了理解NeRF，我们需要了解数码相机中的四个笛卡尔坐标系。如图[12.4](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12fig4)所示，它们分别是世界坐标系、相机坐标系、图像坐标系和传感器坐标系。在第一个坐标系中，`z[w]`轴方向向上，`x[w]`*`–y[w]`平面是水平的。相对于固定的真实世界坐标系，可移动相机坐标系的`z[c]`轴在相机移动和旋转前与`y[w]`轴平行，其`x[c]`轴可以指向任意方向。为简化起见，我将`x[c]`轴和`x[w]`轴设为相反方向。对于一个3D世界向量`X⃗[w]` = `[1,1,1]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn25.gif"/，如果相机位于由真实世界向量`C⃗[w]` = `[0,−100,0]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn27.gif"/设定的位置，我们可以确定相机坐标系中的向量为`X⃗[c]` = `[−1,1,101]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn26.gif"/。从向量`C⃗[w]`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn28.gif"/可知，两个坐标系之间的距离为100。这些坐标的单位可以是毫米（mm）。从图中可得一个方程，用于计算相机系统中3D世界点`[1,1,1]`的坐标`X⃗[c]` = `R` ⋅ (`X⃗[w]`−`C⃗[w]`) = `R` ⋅ `X⃗[w]` + `t⃗`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn29.gif"/，其中`R`是关于旋转操作的正交矩阵，`t⃗` =  − `R` ⋅ `C⃗[w]` = `[0,0,100]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn30.gif"/是关于相机坐标系到真实世界坐标系的平移操作。从`t⃗`inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn31.gif"/的坐标可知世界坐标系原点在相机系统中的位置。我们还有`R^(−1)` = `R^(T)`inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn32.gif"/和`RR^(T)` = `R^(T)R` = 1inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn33.gif"/。
