## 11.3 DINOv2 用于图像检索、分类与特征可视化

2023 年 4 月，Meta AI 发布了四个预训练的 DINOv2 模型：一个从头训练的 ViT-g 模型，以及三个从 ViT-g 蒸馏出的模型（ViT-s、ViT-b、ViT-l）。一个大规模、精心策划、多样化的数据集 (LVD-142M) 被用于根据一篇论文（Oquab *et al* [2023](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11bib8)）中描述的方法训练这些模型：“DINOv2: Learning Robust Visual Features without Supervision”（DINOv2：无监督学习鲁棒视觉特征）。与依赖标注数据或人工标题来解读图像含义的其他预训练模型不同，DINOv2 可以从任何图像数据集中学习，而无需配套的元数据。通过避免关键背景信息的遗漏，DINOv2 能够全面掌握图像细节，直至像素级别。DINOv2 的突出之处在于消除了微调的需求。其输出的高性能特征可直接搭配简单的线性层等分类器，用于各种计算机视觉任务。每个 DINOv2 模型接收一张图像作为输入，并返回一个类 token 和补丁 token。DINOv2 模型可用于图像分类、图像分割、图像检索、目标检测和目标深度估计。

利用一个名为 `dinov2_vits14` 的预训练小型 DINOv2 模型，项目 [11.3.1](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11ueqn7) 中的代码可以在第 [9](#Chapter_9.xhtml#bk978-0-7503-6244-3ch9) 章使用的花卉数据集中检索花卉图像。从项目的输出中，你会发现寥寥数语的标题不足以描述一张照片，因为“一图胜千言”。Cell 04 的代码从批次大小为六的训练数据加载器中输出一批花卉图像（图 [11.4](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11fig4)(A)）。通过在 Cell 06 中选择一个 0 到 5 之间的整数 (`n`)，我们可以选取一张特定类别的花卉图像作为查询图像，随后项目的其余代码将从验证数据集中挑选出六张花卉图像。检索到的花卉与查询花卉应为同一类别。在图 [11.4](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11fig4)(A) 中，`n` = 1 和 5 处有两张蒲公英图像。使用这两个位置中任意一张图像作为查询图像，我们得到了图 [11.4](#Chapter_11.xhtml#bk978-0-7503-6244-3ch11fig4)(B) 和 (C)。预训练的 DINOv2 模型能够区分不同生命阶段的蒲公英图像：黄色花朵和白色种子。一个英文单词“dandelion”（蒲公英）不足以区分它们。
