
# 3D Gaussian Splatting 模型训练

3D Gaussian splatting 的模型训练非常简单。事实上，这种新技术并不涉及神经网络模型。我们只需要训练一个包含许多参数的拟合函数，这些参数会在模型训练过程中更新。

你可以使用手机或无人机拍摄某物周围的照片（如雕塑、埃及金字塔、埃菲尔铁塔，甚至温哥华市中心的建筑），以此开始你的 3D Gaussian splatting 项目。随后，你可以使用 [Colmap](https://colmap.github.io/) 或其他免费软件，从照片中获取物体表面 3D 点的点云文件。

3D Gaussian splatting 项目的代码会将这些点初始化为 3D Gaussian 橄榄球。在模型训练期间，根据方程（[12.5](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12eqn5)），数百万个橄榄球会被投影到某个相机位置的共轭平面上。这个过程称为“光栅化”（rasterization）。GPU 会对所有橄榄球到共轭平面的距离进行排序。共轭平面上每个 16x16 像素的“瓦片”（tile）作为一个批次，供 GPU 计算该瓦片上的预测图像。相机在该位置拍摄的图像被用作真值（ground truth）。L1 损失函数和结构相似性指数（SSIM）损失函数用于计算预测图像与真值之间的差异。

在模型训练期间，每个橄榄球的位置、大小、方向、颜色和不透明度将根据损失函数对部分橄榄球参数的梯度进行更新。如果某个橄榄球的不透明度足够低（或透明度足够高），该橄榄球将被删除；如果损失函数对某橄榄球位置坐标的梯度范数足够大，该橄榄球将被克隆，且在克隆出的橄榄球尺寸足够大时，这两个相同橄榄球的尺寸将被缩小。此过程将针对所有真值图像重复，以调整每个橄榄球的位置、大小、方向、颜色和不透明度。最终，我们可以在物体周围的任意视角看到逼真的预测图像。

唯一的问题是，模型训练需要海量的 GPU 内存，以使用数百万个 3D Gaussian 重建逼真的 3D 场景。我的 RTX 2060 GPU（6 GB 显存）在项目 [12.3.1](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12pro8) 中只能处理 3536 个 2D Gaussian。在撰写本章时，[LUMA](https://lumalabs.ai/interactive-scenes) AI 提供免费网络服务，用户可上传照片并下载由其照片训练的 3D Gaussian splatting 模型。我只能用一个 2D Gaussian splatting 项目来演示这项新技术的概念。我的代码受 [OutofAi](https://github.com/OutofAi/2D-Gaussian-Splatting/blob/main/2D_Gaussian_Splatting.ipynb) 启发。

图 [12.8](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12fig8)A 中的真值图像经项目 [12.3.1](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12pro8) 代码处理，获得了包含 3536 个 2D Gaussian 的合成图像。我花费约 1.5 小时获得了足够好的输出，结构相似性指数（SSIM）达到 0.882。SSIM 最早由 IEEE 论文（Wang *et al* [2004](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib11)）于 2004 年提出。它优于上一节使用的 PSNR，因为其取值范围在 \[0,1\] 之间。

`Cell 02` 中定义的 SSIM 损失函数基于 [kornia](https://kornia.readthedocs.io/en/latest/losses.html) 库中一个类的实例。该损失函数的值等于 `(1-SSIM)/2`。若预测图像与其真值完全匹配，则 SSIM = 1 且 loss = 0。SSIM 损失的最大值为 0.5。

`Cell 02` 第 11 行随机选取 5000 个像素作为 `Cell 01` 输入松鼠图像的云点。利用这些点的坐标，该单元格中定义的函数返回每个云点的 RGB 颜色和归一化坐标。这些归一化坐标的取值范围为 \[–1, 1\]。第 16 行使用反双曲正切函数将这些云点坐标的范围扩展到 \[–∞, ∞\]，以减小损失函数对坐标的梯度，从而实现平滑的模型训练。否则，由于“内存溢出”问题，Gaussian 的分裂速度过快，无法获得良好的训练结果。

该单元格第 12 至 14 行代码随机设置每个 2D Gaussian 的 `sigma`、`rho` 和颜色密度。所有这些参数被打包为形状为 `[5000,9]` 的权重张量。在模型训练期间，权重张量将被更新，导致部分 Gaussian 被克隆、删除、调整大小、移动。在此过程中，这些 Gaussian 的 RGB 颜色也会发生变化。

对于具有 σ[*x*]，σ[*y*] 和相关系数 ρ 的 2D Gaussian，其协方差矩阵及其逆矩阵将由方程（[12.9](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12eqn9)）设定。这些矩阵在 `Cell 03` 中用于计算一批 2D Gaussian。三个 2D Gaussian 的 PDF 轮廓线会作为示例打印在屏幕上。第三个 Gaussian 的 PDF 轮廓线是椭圆，因为其 *x* 和 *y* 变量不独立。这些椭圆的方向由相关系数 ρ 决定。

`Cell 04` 中定义的函数将三个 2D Gaussian 的 PDF 着色并整合成一幅彩色图像。一个名为 `theta` 的 2D 仿射矩阵用于将每个 Gaussian 连同颜色转置到其中心（云点坐标）。使用 `Cell 04` 最后三行代码，我们可以看到仅由这三个 2D Gaussian 生成的彩色图像。该模型函数将在模型训练中用于生成包含数千个 Gaussian 的彩色图像。

```
\Sigma = \begin{pmatrix} \sigma_{x}^{2} & {\rho\sigma_{x}\sigma_{y}} \\ {\rho\sigma_{x}\sigma_{y}} & \sigma_{y}^{2} \\ \end{pmatrix}\mspace{40mu}\Sigma^{- 1} = \frac{1}{\sigma_{x}^{2}\sigma_{y}^{2}(1 - \rho)}\begin{pmatrix} \sigma_{y}^{2} & {- \rho\sigma_{x}\sigma_{y}} \\ {- \rho\sigma_{x}\sigma_{y}} & \sigma_{x}^{2} \\ \end{pmatrix}
```
