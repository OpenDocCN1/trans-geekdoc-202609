

# Cell 05 中的模型训练代码

`Cell 05` 中的代码用于模型训练。在前 2000 个 epoch 中，模型训练速度约为每 epoch 1.5 秒。随着越来越多的高斯球被优化以合成图像，速度会变得非常慢。程序会因“内存不足”问题而中断。或者，如果你发现程序运行非常缓慢，可以随时中断程序。

## 检查点机制

如果输出中的高斯球数量超过 1000 个，`Cell 05` 中的代码会每 100 个 epoch 为我们保存一个检查点。通过将 `Cell 02` 第 25 行末尾的三个单引号移动到第 11 行前面，我们可以从之前的检查点继续训练模型，再训练 1000 个 epoch。当我们第一次使用检查点时，需要将 `Cell 01` 中的 `densification interval`（稠密化间隔）参数改为 100。使用检查点可以加快模型训练速度。

## 3D 高斯泼溅技术的进展

虽然 3D 高斯泼溅技术仍处于起步阶段，但其在计算机视觉 3D 图形领域的前景是毋庸置疑的。原始的 3D 高斯泼溅只能处理静态 3D 场景。高斯泼溅技术推出三个月后，已有七篇[论文](https://github.com/MrNeRF/awesome-3D-gaussian-splatting#dynamics-and-deformation)发表，提出了用于可动画化（Luiten *et al* [2023](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib6)，Li *et al* [2023](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib5)）3D 高斯泼溅的智能算法。

## SuGaR 方法

**SuGaR**（Guédon 和 Lepetit [2023](#Chapter_12.xhtml#bk978-0-7503-6244-3ch12bib1)）是一种用于从 3D 高斯泼溅表示中进行高效 3D 网格重建和高质量网格渲染的新方法。SuGaR 通过操作网格而非高斯球本身，使得使用传统软件能够轻松地对高斯球进行编辑、雕刻、绑定、动画制作、合成和重新打光。使用 SuGaR 获取此类可编辑网格以进行逼真渲染只需几分钟，同时还能提供更好的渲染质量。
