

# 目标跟踪与计数

目标跟踪与计数是指在视频或图像序列中定位和监控目标，然后计算属于感兴趣类别的目标数量的过程。目标跟踪与计数在许多领域都有应用，如监控、交通监测、人员计数、零售分析、体育分析和野生动物监测等。

此类计算机视觉任务主要包含三个步骤：

1.  使用 `YOLO` 或其他目标检测算法进行**目标检测**。
2.  **目标跟踪**，旨在将当前帧中检测到的目标与前一帧中已跟踪的目标进行关联。
3.  **目标计数**。

将以下项目 [8.4.3](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8ueqn9) 的代码应用于视频文件，我们将分别跟踪并计数相反方向行驶的汽车。视频中汽车旁行驶的卡车将被忽略。该项目代码受 FREEDOM TECH 的 [YouTube](https://www.youtube.com/watch?v=DXqdjWndooI) 视频及其 [GitHub](https://github.com/freedomwebtech/yolov8counting-trackingvehicles/blob/main/tracker.py) 仓库启发。

在由预训练的 `YOLOv8` 模型处理之前，每个视频帧都会被调整大小为 1024 × 512。图 [8.5](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8fig5) 所示的处理后视频帧描绘了在高速公路上行驶的车辆。左侧车辆正朝向摄像头移动（方向 **down**：帧的从上到下）。右侧车辆正远离摄像头移动（方向 **up**：帧的从下到上）。

**单元格 01** 中的代码导入库和一个小型预训练 `YOLOv8` 模型。单元格中还设置了七个超参数。其中第 03 行和第 04 行的两个参数设置了如图所示绿线和红线的 *y* 轴位置。对应绿线在 `y=340` 的位置，由 `340-dy ≤ y ≤ 340+dy` 定义的帧上的绿色区域作为向上行驶汽车的检测区，其中 `dy` 由第 05 行代码设置为 6 个像素。同理，`y=370` 处的红线设置了一个相同大小的红色区域，用于检测向下行驶的汽车。其余四个超参数稍后解释。

我们从最后一个单元格：**单元格 04** 开始解释项目代码，它与项目 [7.5](#Chapter_7.xhtml#bk978-0-7503-6244-3ch7ueqn23) 的单元格 07 几乎相同。该单元格中的代码逐帧读取视频文件。一帧经单元格 03 中定义的函数处理后，如上图所示，相关信息会被添加到处理后的帧中。左下角的数字表示从第 0 帧到当前帧向下行驶的汽车数量；右下角的数字表示向上行驶的汽车数量。

当汽车处于检测区域内时，其边界框中心会用一个白点标记，其 ID 号显示在点旁边。ID 号的颜色与检测区水平线的颜色一致。左上角显示图像处理速度（方差较大）。当道路上没有车辆时，FPS 计算中可能会发生“除以零”错误；使用一个很小的数（`10^(-5)`）来防止这种情况。当前帧的序号和视频总帧数显示在右上角。

在第 140/572 帧（如图所示），已计数 4 辆向上行驶的汽车和 2 辆向下行驶的汽车。图像处理速度为 57 FPS。此时，一辆 ID 为 229 的黑色汽车正向下行驶，并处于红色区域内。

![](images/bk978-0-7503-6244-3ch8uf11_pr.gif)

**单元格 03** 中定义的名为 `yolov8tc` 的函数表明，使用预训练的 `YOLOv8` 模型进行目标跟踪和计数。该函数修改了项目 [8.4.2](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8ueqn8) 单元格 01 中定义的 `yolov8` 函数。

- 第 02 行将原始视频帧调整大小为 1024 × 512。
- 调整大小后的帧由 `YOLOv8` 模型处理，以获得边界框坐标（`boxes`）和 COCO 类别身份编号（`labels`）。
- 第 07–11 行筛选汽车，并将每辆汽车边界框的四个坐标（`x`、`y`、`X`、`Y`）打包成列表追加到 `car_list` 中。
- 第 12 行通过 `Tracker` 类实例的 `track` 函数（在单元格 02 中定义）处理 `car_list`。输出列表 `cxcyid` 与输入长度相同。`cxcyid` 中的每个子列表包含三个元素：中心坐标（`cx`、`cy`）和一个分配的 ID 号。
- 中心坐标计算公式为：`cx = int((x + X) / 2)` 和 `cy = int((y + Y) / 2)`。
- `Tracker` 跨帧关联检测结果；新目标将获得一个新的、更高的 ID 号。

在当前帧上，每辆汽车都有一个 ID 和中心坐标。第 13–30 行检查汽车的 *y* 轴位置：

- 如果汽车在**绿色区域**内（第 15 行），则用白点标记并打印其 ID。该汽车被登记在字典 `vh_down` 中（用于向下行驶的汽车）。
- 如果 `vh_down` 中某汽车的 ID 触及**红色区域**，且该 ID 对列表 `n_down` 而言是新的（第 21 行），则将该 ID 追加到 `n_down`。`n_down` 的长度代表向下行驶汽车的计数。
- 第 23–30 行应用相同逻辑计算向上行驶汽车的数量（使用 `vh_up` 和 `n_up`）。

两个计数结果分别打印在帧的左下角和右下角，并绘制绿/红区域线。函数 `yolov8tc` 返回标注后的帧。
