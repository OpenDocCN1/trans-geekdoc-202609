
# GAN Model Training Challenges

GAN model training is still a challenge. One big issue of GAN's model training is 'mode collapse'. For example, you took 120 min to train your models to generate MNIST images for ten digits, but the outputs only had one digit. There are many parameters in the two models, and there are also many hyperparameters in your codes. How can you adjust them to get what you want in a short time? Before we face those model training challenges, we need to build our training machine for GANs. There are four parts to the machine. The first part is for data input, the second part is for constructions of the two models, the third part is for model training, and the fourth part is for data visualization. Only the second part is new for us.

## Training Loop for Model D and Model G

Model D and model G are trained in a for-loop for each batch of real images in a dataloader with a batch size `m`:

1.  From the dataloader, take a batch of image samples: `{x[1], x[2]…, x[m]}`.

2.  Using model D to convert `x[i]` into a scalar `ŷ[i] = D(x[i]) ∈ [0,1]`, (`i` = 1, 2…, `m`).

3.  Set any real image's target as ONE: `y[i] = 1`, (`i` = 1, 2, …, `m`).

4.  Calculate BCE loss between the targets and the predictions by `(-1/m) * Σ ln(D(x_i))` (i=1 to m).

5.  Generate a batch of noise vectors from a standard normal distribution: `{z[1], z[2]…, z[m]}`.

6.  Create a batch of fake images from the noise vectors: `x̃[i] = G(z[i])`, (`i` = 1, 2…, `m`).

7.  Convert any fake image into a scalar `D(x̃[i]) ∈ [0,1]` as a fake prediction.

8.  Set each fake image's target as ZERO.

9.  Calculate BCE loss by `(-1/m) * Σ ln(1 - D(x̃_i))` (i=1 to m) without updating model G.

10. Calculate model D's loss:

    ```
    L_D(θ_d) = (-1/m) * Σ ln(D(x_i)) - (1/m) * Σ (1 - ln(D(x̃_i)))  (i=1 to m)
    ```

    (3.1)

    ```
    L_D(θ_d) = -E[ln(D(X))] - E[ln(1 - D(G(Z)))]
    ```

    ```
    → -∫ p_r(x) ln[D(x)] dx - ∫ p_z(z) ln[1 - D(G(z))] dz
    ```

    ```
    → -∫ p_r(x) ln[D(x)] dx - ∫ p_g(x) ln[1 - D(x)] dx
    ```

    ```
    = -∫ (p_r(x) ln[D(x)] + p_g(x) ln[1 - D(x)]) dx
    ```

    This is the training criterion for the discriminator `D` with a given generator `G`. In the condition of `G` is given, it is possible to find an optimized discriminator `D*` to minimize the loss function by `d/dD(x) (p_r(x) ln[D(x)] + p_g(x) ln[1 - D(x)]) = 0` at a fixed `x`. The optimized discriminator `D*` is found to be: `D_G*(x) = p_r(x) / (p_r(x) + p_g(x))`, where we have:

    ```
    L_D(θ_d) = 2 ln(2) - 2 D_JS(p_r || p_g)
    ```

    Based on equation (1.8): `0 ≤ D_JS(p_r | p_g ≤ ln(2))`, we have `0 ≤ L_D(θ_d) ≤ 2 ln(2)`. In case `p_r = p_g`, model D's loss achieves a maximum: `2 ln(2)`.

11. Update D's parameters `θ_d` without changing `θ_g`: `θ_d ← θ_d - η ∇[θ_d] L_D(θ_d)`.

12. Then with a new batch of noises from a normal distribution: `{z[1], z[2]…, z[m]}`.

13. Create a new batch of fake images from the noises: `x̃[i] = G(z[i])`.

14. Convert each `x̃[i]` into a scalar `D(x̃[i]) ∈ [0,1]` as a real prediction.

15. Set each fake image's target as ONE.

16. Calculate BCE loss:

    ```
    L_G(θ_g) = (-1/m) * Σ ln(D(x̃_i))  (i=1 to m)
    ```

    (3.2)

17. Update G's parameters with `θ_g ← θ_g - η ∇[θ_g] L_G(θ_g)`.

## 3.1.1 Implement a GAN for Quadratic Curve Generation

It is better to implement GAN theory to a simple dataset in the beginning. In the following project [3.1.1](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3ueqn7), only two fully connected layers are used in the generator model (`G`) and the discriminator model (`D`) shown in figure [3.1](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3fig1)(A). These models handle data in three spaces. The first space is the observed space or real space with 21 dimensions for real quadratic curves. The data of each real curve in a batch of a dataloader come from a quadratic function `y = ax^2 + b`, where `x` is a 1D array generated by a NumPy function: `np.linspace(-1, 1, 21)`. The factor `a` in the function is also a 1D array generated by a uniform distribution function: `np.random.uniform(1, 2, size = 64)` and is reshaped into a 64 × 1 NumPy array. Another constant `b` in the function is set to be equal to `(a - 1)`. A batch in a dataloader generated by a function `training_data()` defined in Cell 02 is a 64 × 21 array. The output of Cell 03 is a graph with 64 real quadratic curves. When printing out data of the last curve `y[63]` in an extra cell after Cell 01, we would see a 1D NumPy array with 21 floating numbers.
