
# GAN 模型训练挑战

GAN 模型训练仍然是一个挑战。GAN 模型训练的一个主要问题是“模式崩塌”。例如，你花费了 120 分钟训练模型以生成十个数字的 MNIST 图像，但输出结果只包含一个数字。这两个模型中有许多参数，你的代码中也有许多超参数。如何在短时间内调整它们以获得想要的结果？在面对这些模型训练挑战之前，我们需要为 GAN 构建训练机器。机器由四部分组成。第一部分用于数据输入，第二部分用于构建两个模型，第三部分用于模型训练，第四部分用于数据可视化。只有第二部分对我们来说是新的。

## 模型 D 和模型 G 的训练循环

模型 D 和模型 G 在一个 for 循环中针对数据加载器中每一批真实图像（批量大小为 `m`）进行训练：

1.  从数据加载器中取出一批图像样本：`{x[1], x[2]…, x[m]}`。

2.  使用模型 D 将 `x[i]` 转换为标量 `ŷ[i] = D(x[i]) ∈ [0,1]`，(`i` = 1, 2…, `m`)。

3.  将任意真实图像的目标设为 1：`y[i] = 1`，(`i` = 1, 2, …, `m`)。

4.  通过 `(-1/m) * Σ ln(D(x_i))` (i=1 到 m) 计算目标与预测之间的 BCE 损失。

5.  从标准正态分布生成一批噪声向量：`{z[1], z[2]…, z[m]}`。

6.  从噪声向量创建一批假图像：`x̃[i] = G(z[i])`，(`i` = 1, 2…, `m`)。

7.  将任意假图像转换为标量 `D(x̃[i]) ∈ [0,1]` 作为假预测。

8.  将每个假图像的目标设为 0。

9.  通过 `(-1/m) * Σ ln(1 - D(x̃_i))` (i=1 到 m) 计算 BCE 损失，**不更新模型 G**。

10. 计算模型 D 的损失：

    ```
    L_D(θ_d) = (-1/m) * Σ ln(D(x_i)) - (1/m) * Σ (1 - ln(D(x̃_i)))  (i=1 到 m)
    ```

    (3.1)

    ```
    L_D(θ_d) = -E[ln(D(X))] - E[ln(1 - D(G(Z)))]
    ```

    ```
    → -∫ p_r(x) ln[D(x)] dx - ∫ p_z(z) ln[1 - D(G(z))] dz
    ```

    ```
    → -∫ p_r(x) ln[D(x)] dx - ∫ p_g(x) ln[1 - D(x)] dx
    ```

    ```
    = -∫ (p_r(x) ln[D(x)] + p_g(x) ln[1 - D(x)]) dx
    ```

    这是在给定生成器 `G` 的条件下判别器 `D` 的训练准则。在 `G` 给定的条件下，可以通过在固定 `x` 处令 `d/dD(x) (p_r(x) ln[D(x)] + p_g(x) ln[1 - D(x)]) = 0` 来找到一个优化的判别器 `D*` 以最小化损失函数。找到的优化判别器 `D*` 为：`D_G*(x) = p_r(x) / (p_r(x) + p_g(x))`，此时我们有：

    ```
    L_D(θ_d) = 2 ln(2) - 2 D_JS(p_r || p_g)
    ```

    根据公式 (1.8)：`0 ≤ D_JS(p_r | p_g ≤ ln(2))`，我们得到 `0 ≤ L_D(θ_d) ≤ 2 ln(2)`。当 `p_r = p_g` 时，模型 D 的损失达到最大值：`2 ln(2)`。

11. 更新 D 的参数 `θ_d` 而不改变 `θ_g`：`θ_d ← θ_d - η ∇[θ_d] L_D(θ_d)`。

12. 然后从正态分布中取新的一批噪声：`{z[1], z[2]…, z[m]}`。

13. 从噪声创建新的一批假图像：`x̃[i] = G(z[i])`。

14. 将每个 `x̃[i]` 转换为标量 `D(x̃[i]) ∈ [0,1]` 作为真实预测。

15. 将每个假图像的目标设为 1。

16. 计算 BCE 损失：

    ```
    L_G(θ_g) = (-1/m) * Σ ln(D(x̃_i))  (i=1 到 m)
    ```

    (3.2)

17. 更新 G 的参数：`θ_g ← θ_g - η ∇[θ_g] L_G(θ_g)`。

## 3.1.1 实现用于二次曲线生成的 GAN

最好从在简单数据集上实现 GAN 理论入手。在以下项目 [3.1.1](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3ueqn7) 中，生成器模型 (`G`) 和判别器模型 (`D`) 如图 [3.1](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3fig1)(A) 所示，均仅使用两个全连接层。这些模型在三个空间中处理数据。第一个空间是观测空间或真实空间，针对真实二次曲线具有 21 个维度。数据加载器中一批数据内每条真实曲线的数据来自二次函数 `y = ax^2 + b`，其中 `x` 是由 NumPy 函数生成的一维数组：`np.linspace(-1, 1, 21)`。函数中的因子 `a` 也是由均匀分布函数生成的一维数组：`np.random.uniform(1, 2, size = 64)`，并重塑为 64 × 1 的 NumPy 数组。函数中的另一个常数 `b` 设定为等于 `(a - 1)`。由单元格 02 中定义的函数 `training_data()` 生成的数据加载器中的一批数据是一个 64 × 21 的数组。单元格 03 的输出是一张包含 64 条真实二次曲线的图表。在单元格 01 之后的一个额外单元格中打印出最后一条曲线 `y[63]` 的数据时，我们将看到一个包含 21 个浮点数的一维 NumPy 数组。
