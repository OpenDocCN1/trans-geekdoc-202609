每个点 $x[j]$ 都可视为具有边缘概率 $p(x[j])$ 的随机数，该概率通过公式 ([1.28](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn28)) 获得。数据集的联合概率密度函数为 $P(X) = p(x[1])p(x[2])\ldots p(x[n])$。数据集模型训练的损失函数为：

$$L = - \ln \left( {P\left( X \right)} \right) = \ln \prod_{i = 1}^{n}{p\left( x_{j} \right)} = - \sum\limits_{j = 1}^{n}{\ln \left( {\sum\limits_{i = 1}^{m = 3}{p\left( {x_{j} \mid z_{i}} \right)p\left( z_{i} \right)}} \right)}$$

$$p\left( {z_{i} \mid x_{j}} \right) = \frac{p\left( {x_{j} \mid z_{i}} \right)p\left( z_{i} \right)}{p\left( x_{j} \right)} = \frac{p\left( {x_{j} \mid z_{i}} \right)p\left( z_{i} \right)}{\sum\limits_{k = 1}^{3}{p\left( {x_{j} \mid z_{k}} \right)}p\left( z_{k} \right)}$$

### 1.2 使用梯度下降算法进行线性回归

我们将通过使用梯度下降算法完成一个线性回归项目，这是编写机器学习代码的方式。在项目 [1.2.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn10) 中，我们需要找到两个温标之间的线性关系：华氏度 (F) 和摄氏度 (C)。一个数组用于存储以摄氏度测量的温度：$C = [-20, -15, -10, -5, 0, 5, 10, 15, 20]$，另一个数组通过函数 $F = 32 + 9C/5$ 生成华氏度温度：$F = [-4, 5, 14, 23, 32, 41, 50, 59, 68]$。这是一项非常简单的作业。只需将 C 数组和 F 数组中的那些数字输入到 Microsoft Excel 表格的两列中，通过几次鼠标点击，屏幕上就会显示一条直线和一个线性回归函数 $F = 30.0+1.8C$。但我们必须使用 VS Code 中的 Jupyter Notebook 文件作为集成开发环境 (IDE) 来完成额外的工作。
