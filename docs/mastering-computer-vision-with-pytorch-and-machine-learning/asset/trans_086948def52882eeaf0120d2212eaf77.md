

## 变分下界公式

$$L\_{VLB} = D\_{KL}(q(x\_{T}\mid x\_{0})\mid\mid p\_{\theta}(x\_{T})) + \sum\limits\_{t = 2}^{T}D\_{KL}(q(x\_{t - 1}\mid x\_{t},x\_{0})\mid\mid p\_{\theta}(x\_{t - 1}\mid x\_{t})) - \mathbb{E}\_{q}\left\lbrack {\log\ p\_{\theta}(x\_{0}\mid x\_{1})} \right\rbrack$$

$$L\_{VLB} = L\_{T} + \sum\limits\_{t = 2}^{T}L\_{t - 1} + L\_{0}$$

该过程的变分下界是每个时间步损失之和：$L = L\_0 + L\_1 + \dots + L\_T$。$L\_{VLB}$ 中的每个 $D\_{KL}$ 项（$L\_0$ 除外）都是关于两个高斯分布之间的差异，因此可以直接计算。$L\_{T}$ 在模型训练期间可以忽略，因为它是一个常数；$L\_0$ 也被忽略，因为 DDPM 论文的作者发现不包含该项时效果更好。

基于 $q(x\_{t-1}\mid x\_t,x\_0) = \mathcal{N}(x\_{t-1};\tilde{\mu}(x\_t,x\_0),\tilde{\beta}\_t I)$ 和 $p\_{\theta}(x\_{t-1}\mid x\_t) = \mathcal{N}(x\_{t-1};\mu\_{\theta}(x\_t,t),\sigma\_t^2 I)$，我们得到以下公式，其中 $C$ 是与模型训练无关的常数，$t = 2,3,\dots,T$：

$$L\_{t - 1} = D\_{KL}(q(x\_{t - 1}\mid x\_{t},x\_{0})\mid\mid p\_{\theta}(x\_{t - 1}\mid x\_{t})) = \mathbb{E}\_{q}\left( {\frac{1}{2\sigma\_{t}^{2}}{\mid\mid}{\tilde{\mu}}\_{t}(x\_{t},x\_{0}) - \mu\_{\theta}(x\_{t},t){\mid\mid}^{2}} \right) + C$$

DDPM 论文的作者将预测的 $\mu\_{\theta}(x\_t,t)$ 设置为与公式 (9.5) 中所示的 $\tilde{\mu}\_t(x\_t,x\_0)$ 具有相同格式，并忽略公式中的所有繁杂项，得到一个重加权版本的 $L\_{VLB}$，该版本强调重建质量，其中 $\varepsilon\_{\theta}$ 是一个旨在从 $x\_t$ 预测 $\varepsilon$ 的函数逼近器：

$$L\_{t-1} = E\_{x\_0,\varepsilon}(\parallel\varepsilon - \varepsilon\_{\theta}(x\_t,t)\parallel^2) \tag{9.9}$$

我们训练 U-Net 模型在时间步 $t$ 预测噪声 $\varepsilon\_{\theta}$，然后根据公式 (9.9) 在均方误差 (MSE) 损失函数中计算预测噪声 $\varepsilon\_{\theta}$ 与噪声 $\varepsilon$ 之间的差异，其中 $x\_t = \sqrt{\bar{\alpha}\_t}x\_0 + \sqrt{1 - \bar{\alpha}\_t}\varepsilon$。

`Cell 06` 中定义的一个函数用于根据上述 DDPM 理论训练 U-Net，并做了一点修改。为了节省模型训练时间，我们不在每个批次中对每张图像使用所有时间步。`Cell 07` 第 10 行的代码生成一批从 0 到 $T-1$（包含）的随机整数作为时间步。通过第 12 行的代码，我们通过添加第 11 行代码生成的一批噪声 $\varepsilon$，获得那些时间步下的一批潜在图像 $x\_t$。然后 U-Net 为我们预测噪声 $\varepsilon\_{\theta}$，以便根据公式 (9.9) 计算 MSE 损失。

`Cell 05` 中定义的第一个函数用于时间戳。U-Net 的主干网络与第 9.1 节中的相同，但有许多修改。我们必须通过基本块（`Cell 06` 的 `Basic` 类）中的时间嵌入用时间戳标记潜在图像。我们在第 3.3 节中为条件 GAN 使用了标签信息嵌入。时间嵌入可以通过多种方式完成。`Cell 05` 中定义的 `sinusoidal_embedding` 函数代码受 Brian Pulfer 的 [GitHub](https://medium.com/mlearning-ai/enerating-images-with-ddpms-a-pytorch-implementation-cef5a2ba8cb1) 仓库代码启发。多头自注意力类（`MHSA`，Petit 等人 [2020]）用于桥接部分。该类实例内部有四个自注意力头。该实例的输入 Q、K 和 V 相同：一个经过层归一化和重塑的桥接张量。关于多头自注意力的详细信息将在第 10 章提供。单头交叉注意力类（`Attention`）用于修改 U-Net 的跳跃连接。我在观看 DigitalSreeni 的 [YouTube 视频](https://www.youtube.com/watch?v=KOF38xAvo8I) 并阅读 Attention U-Net 论文（Oktay 等人 [2018]）后编写了单头交叉注意力代码。带有注意力机制的 U-Net 给图像的相关部分更大的权重。在 `Cell 06` 的 `Basic` 类中，使用快捷连接构建残差网络，并使用了层归一化。花费了很长时间才得到图 9.4(C) 所示的平滑二次曲线。`Cell 09` 中定义的函数基于公式 (9.5)–(9.6) 从纯噪声生成图像。

## 9.3 使用 Hugging Face 的预训练 U-Net 生成图像

上一节中的注意力 U-Net 对 MNIST 足够强大，但对 CIFAR10 不够智能。为了为 CelebA 和 STL10 等其他数据集生成高质量假图像，我们需要更强大的 U-Net。幸运的是，Hugging Face 为不同数据集提供了预训练的 U-Net 模型。我们只需编写几行代码即可生成精美图像。以下项目 9.3.1 中的代码用于演示 Hugging Face 扩散模型的强大功能。运行代码前，请在工作区的 VS Code 终端中使用 DOS 命令 `pip install Hugging Face diffusers`。第 2 行的 `model_id` 是特定数据集预训练参数文件的名称。首次运行代码时，将为 `DDPMPipeline` 下载一个约 500 MB 的 U-Net 文件。你可以从 Hugging Face 找到更多带有预训练参数的文件，第 2-3 行列出了几个此类文件的名称。第 5 行 `DDPMPipeline` 实例的输出是一个包含名为 `sample` 的键的字典。该键的值是一个仅包含一个元素的列表，即从纯噪声生成的图像。第 6 行代码提取并显示该图像。图 9.5 显示了由三个预训练 U-Net 生成的三张假图像。我相信，仅用六行代码的程序生成的图像质量可以与著名网站 *This Person Does Not Exist* 上的图像质量相媲美。你可以尝试在笔记本电脑或 Google Colab 上运行这段简短的代码。在我的配备 RTX 2060 GPU 的笔记本电脑上，程序运行时间约为 2.5 分钟。
