

### 5.2 beta-VAE 在假二次曲线中的应用

$$L = - \sum\limits_{j = 1}^{n}{\ \ln\ \sum_{z}{q\left( {z\mid x_{j}} \right)}\frac{p\left( {x_{j},z} \right)}{q\left( {z\mid x_{j}} \right)}} \leqslant - \sum\limits_{j = 1}^{n}{\sum_{z}{q(z\mid x_{j})\ln\ \frac{p\left( {x_{j},z} \right)}{q\left( {z\mid x_{j}} \right)}}}$$

$$L \leqslant \sum\limits_{j = 1}^{n}\left\lbrack {\sum\limits_{z}{q(z\mid x_{j})\ln\ \frac{q(z\mid x_{j})}{p{(z)}}} - \sum\limits_{z}{q(z\mid x_{j})\ln\ \left( { p(x_{j}\mid z)} \right)}} \right\rbrack$$

$$L \leqslant \sum\limits_{j = 1}^{n}\left( {D_{KL}(q(z\mid x_{j}){\mid\mid}p{(z)}) - Ε_{z \sim q(z\mid x_{j})}\ln\ \left( { p(x_{j}\mid z)} \right)} \right)$$

(5.2)

我们还可以为 VAE 系统构建一个解码器网络（`P`）。解码器使用来自编码器模型 `Q` 的潜在向量来生成一张假图像（`x̂`）。我们将解码器训练为分布 `p(x∣z)`，作为一个具有单位方差的正态分布：$p\left( {x_{j}\mid z} \right) = \frac{1}{\sqrt{\left( {2\pi} \right)^{m}{\mid I \mid}}}e^{- \frac{1}{2}{({x_{j} - \mu_{\theta}{(z)}})}^{T}I{({x_{j} - \mu_{\theta}{(z)}})}}$，其中 `θ` 是解码器的一组参数，而 `x̂[j] = μ[θ](z)` 是解码器的输出。有了上述信息，VAE 系统的损失函数可以写成以下方程（忽略常数）：

$$L \leqslant \sum\limits_{j = 1}^{n}{\sum\limits_{i = 1}^{m}\left( {\mu_{i,j}^{2} + \sigma_{i,j}^{2} - \ln\ \left( \sigma_{i,j}^{2} \right) - 1} \right)} + \frac{1}{2}\sum\limits_{j = 1}^{n}{\parallel {x_{j} - {\widehat{x}}_{j}} \parallel}^{2}$$

(5.3)

如果我们能最小化方程 (5.3) 的右侧，那么合乎逻辑的是我们也能最小化方程的左侧，因为左侧小于或等于右侧。方程 (5.3) 右侧的第一部分称为“正则化损失”，第二部分称为“重构损失”。在上述表格和方程中，我们将潜在变量 `z` 视为离散变量。实际上，在 VAE 系统中，潜在变量 `z` 可以是连续变量。利用 ∫[z]q(z∣x[j])dz = 1 和 `D[KL] ⩾ 0`，我们也可以通过以下数学推导得到关于 VAE 损失函数的相同结果：

$$L = - {\ln\ }\left( {P\left( X \right)} \right) = - {\ln\ }\prod\limits_{j = 1}^{n}{p\left( x_{j} \right)} = - \sum\limits_{j = 1}^{n}\left\lbrack \ln\ \left( { p\left( x_{j} \right)} \right)\int_{z}\left. q(z\mid x_{j})\mathit{dz} \right\rbrack \right.$$

$$L = - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( { p\left( x_{j} \right)} \right)\mathit{dz}}} = - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{ p\left( {z,x_{j}} \right)}{p\left( {z\mid x_{j}} \right)} \right)\mathit{dz}}}$$

$$L = - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( {\frac{ p\left( {z,x_{j}} \right)}{q\left( {z\mid x_{j}} \right)}}\frac{q\left( {z\mid x_{j}} \right)}{p\left( {z\mid x_{j}} \right)}} \right)\mathit{dz}}}$$

$$L = - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{ p\left( {z,x_{j}} \right)}{q\left( {z\mid x_{j}} \right)} \right)\mathit{dz}}} - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{q\left( {z\mid x_{j}} \right)}{p\left( {z\mid x_{j}} \right)} \right)\mathit{dz}}}$$

$$L = - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{ p\left( {z,x_{j}} \right)}{q\left( {z\mid x_{j}} \right)} \right)\mathit{dz}}} - \sum\limits_{j = 1}^{n}{D_{KL}\left( {q(z\mid x_{j}){\mid\mid}p(z\mid x_{j})} \right)}$$

$$L \leqslant - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{ p\left( {x_{j}\mid z} \right)p\left( z \right)}{q\left( {z\mid x_{j}} \right)} \right)\mathit{dz}}}$$

$$L \leqslant \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( \frac{q\left( {z\mid x_{j}} \right)}{p\left( z \right)} \right)\mathit{dz}}} - \sum\limits_{j = 1}^{n}{\int_{z}{q(z\mid x_{j})\ln\ \left( { p\left( {x_{j}\mid z} \right)} \right)\mathit{dz}}}$$

$$L \leqslant \sum\limits_{j = 1}^{n}\left( {D_{KL}(q(z\mid x_{j}){\mid\mid}p{(z)}) - Ε_{z \sim q({z\mid x_{j}})}}\ \ln\ \left( { p\left( {x_{j}\mid z} \right)} \right)} \right)$$

这是关于损失函数 (5.3) 两部分的一个问题。这两部分的数值不在同一量级上。Higgins 及其同事在 2017 年的论文中提出了解决方案（Higgins *et al* [2017]），引入超参数 `β` 来平衡损失函数两部分的贡献。他们将具有修正后损失函数（方程 (5.4)）的 VAE 命名为“beta-VAE”。如果 `β` = 1.0，我们得到一个常规的 VAE 系统；如果 `β` > 1.0，正则化损失（`D[KL]`）会迅速降至零，我们会在后续项目的假图像生成中遇到“模式崩塌”问题；如果 `β` = 0.0，我们的 VAE 系统就变成了一个自编码器系统。使用更大的 `β`，我们会得到非常模糊的假图像，但我们将拥有更强的能力在不同阶段调整新的假图像。

$$L = \beta\sum\limits_{j = 1}^{n}{\sum\limits_{i = 1}^{m}\left( {\mu_{i,j}^{2} + \sigma_{i,j}^{2} - \ln\ \left( \sigma_{i,j}^{2} \right) - 1} \right)} + \frac{1}{2}\sum\limits_{j = 1}^{n}{{\mid\mid}x_{j} - {\widehat{x}}_{j}\mid\mid^{2}}$$

(5.4)
