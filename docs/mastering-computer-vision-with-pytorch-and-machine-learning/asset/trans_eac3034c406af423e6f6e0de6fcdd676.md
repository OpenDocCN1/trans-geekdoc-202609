

为了稳定模型训练，WGAN 论文指导模型 D 的训练次数（`n_critic` = 5）应多于模型 G。在 Cell 08 的第一个 for 循环中，每一批真实曲线和生成曲线都要训练 `n_critic` 次。这些额外的计算会显著增加训练时间。但如果我们确信模型训练能在数小时或数天内产出良好结果，我们就愿意等待。Cell 08 中的另一个 for 循环通过裁剪（`c` = 0.01）来限制模型 D 的权重，这是专门针对 WGAN 的。论文指示我们这样做是为了满足模型 D 的 1-Lipschitz 连续性。图 [4.1](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig1) 展示了上述代码在三种条件下的输出。WGAN-GP 论文（Gulrajani *et al* [2017](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4bib2)）指导我们使用 Adam 优化器。但从图 [4.1](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig1)(B) 可以看出，对于该项目，RMSprop 优化器优于 Adam。损失函数曲线和 WGAN-GP 的梯度惩罚曲线如图 [4.2](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig2) 所示。

### 4.2 将 WGAN-GP 用于 Fashion MNIST

由于使用 MNIST 数据集的项目太简单，我们将重点放在将 WGAN-GP 用于 Fashion MNIST 数据集上。如果您愿意，可以在以下项目 [4.2.1](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4ueqn9) 的 Cell 02 中更改数据集名称，以获得两个数据集结果的对比。虽然 Fashion MNIST 和 MNIST 具有相同的结构，但前者的图像包含详细图案，例如鞋子和 T 恤上的商标。这些详细信息不易在生成图像上还原。由于 ResNet9 在第 [2](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2) 章项目的图像分类任务中表现良好，也许 ResNet9 有能力为生成图像保留详细的图像结构信息。只有在模型 D 中使用修改后的 ResNet9 后，才能生成更好的生成图像，但与真实图像相比仍不够好。我使用 ResNet9 进行模型训练的时间在 30 个 epoch 下超过了两小时。生成的 Fashion MNIST 图像如图 [4.3](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig3) 所示。

### 4.4 针对剪刀石头布数据集的 cWGAN-GP 实现

WGAN-GP 只能随机生成图像。使用条件 WGAN-GP (cWGAN-GP) 系统，我们可以为由我们设定类别标签的数据集生成图像。为了节省模型训练时间，选择了较小的剪刀石头布数据集来演示 cWGAN-GP 在彩色图像上的应用。以下项目 [4.4.1](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4ueqn19) 的模型训练时间约为 64 分钟（100 个 epoch）。图 [4.5](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig5) 展示了数据集中的真实图像和由以下 cWGAN-GP 代码生成的生成图像。最好在模型 D 中用 `nn.InstanceNorm2d()` 替换 `nn.BatchNorm()`。否则，图 [4.6](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4fig6) 中的损失函数值将高于 10,000，且生成图像的质量会很差。对于该项目，Adam 优化器似乎优于 RMSprop 优化器。在 Cell 09 计算梯度惩罚时，我们必须从一张真实图像和一张生成图像生成一张插值图像。我们应该使用真实图像的真实标签，还是生成图像的生成标签？结果发现使用生成标签是正确的选择。用真实标签替换生成标签会导致模型崩溃问题。针对 MNIST 或 Fashion MNIST 的 cWGAN-GP 系统应用代码列在附录 [E](#Appendix1.xhtml#bk978-0-7503-6244-3AppAsA-E) 中。
