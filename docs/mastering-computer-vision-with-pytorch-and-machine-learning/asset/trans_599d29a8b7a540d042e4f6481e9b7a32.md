## 10.4 基于 Hugging Face OWL-ViT 的零样本目标检测

最先进的 YOLOv8 模型可用于目标检测、图像分类和实例分割。YOLOv8 比 YOLOv7 更快、更准确。无论 YOLO 模型多么先进，我们都必须花费大量时间用边界框标注图像。假设我们有 10,000 张来自光学显微镜的病理组织切片照片，并且我们想构建一个数据集来训练用于癌症诊断的 AI 模型。你可以想象聘请至少两位最优秀的病理学家来标注这些照片会有多昂贵。只有在使用标注数据集训练模型所需的漫长时间（几天甚至几个月）之后，我们才能得到可用于应用的模型。后来，我们可能需要向数据集中添加一个或多个类别。例如，发现了一种新型癌细胞，因此我们必须将关于这种癌细胞的额外类别标签添加到组织切片数据集中。在这种情况下，我们必须重新进行模型训练。

Hugging Face 为我们提供了一种用于目标检测的替代方法。使用 Hugging Face 的 OWL-ViT transformer 库，我们可以在无需模型训练（零样本）的情况下检测目标。OWL-ViT 是“用于开放世界定位的视觉 transformer” 的缩写。该名称源自 Matthias Minderer 及其合作者于 2022 年发表的一篇论文（Minderer *et al* [2022](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10bib2)）。借助预训练的 OWL-ViT 模型，无需标注数据集，也不需要训练模型。图 [10.3](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10fig3) 展示了使用预训练 OWL-ViT [模型](https://colab.research.google.com/drive/1IMPWZcnlMy-tdnTDrUcOZU3oiGg-hTem?usp=sharing#scrollTo=WxDNWqSDzoao) 进行零样本目标检测的结果。我的代码源自 Owl-ViT 的 Google Colab 网站上的代码并作了修改。因为不需要模型训练，所以项目 [10.4](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10ueqn10) 的 Cell 01 中不需要超参数。Cell 01 导入的一些库中，`OwlViTProcessor` 和 `OwlViTForObjectDetection` 是新增的。前者用于将文本提示和图像打包成字典，以供预训练模型进行数据输入；后者用于获取模型的输出。

在 Cell 03 的第 03 行代码中，使用 `OwlViTProcessor` 的一个实例，我们将类别名称列表和图像打包成一个名为 `inputs` 的字典，供具有多种增强功能的预训练 OWL-ViT 模型使用。其中一种增强是将每张图像调整为分辨率为 3 × 768 × 768 的新图像。在该字典中，有三个键：`input_ids`、`attention_mask` 和 `pixel_values`。通过代码 `model(**inputs)`，我们获得模型的输出，这也是一个字典。从 `outputs['pred_boxes']` 和 `outputs['logits']` 中，我们获得边界框、标签和标签分数（Cell 03 第 07-10 行）。图 [10.3](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10fig3) 所示照片中有一只蝴蝶。但 VOC 和 COCO 类别中没有此类标签。只需在 Cell 01 的 VOC 类别列表中添加 `butterfly`，OWL-ViT 模型就能找到并标记蝴蝶。Kaggle 和 Google Colab 在使用代码 `cv2.imshow()` 动态显示图像时存在问题。

我曾尝试在笔记本电脑上安装 Hugging Face 的 transformer 库，但导入 `OwlViTProcessor` 库时遇到问题。经过几天的探索和搜索，我发现问题是由 Python v3.6 引起的，随后在使用 Python v3.9 的虚拟环境中安装了带有 `OwlViTProcessor` 的 Hugging Face transformer 库。项目 [10.4](#Chapter_10.xhtml#bk978-0-7503-6244-3ch10ueqn10) 中的代码可用于幻灯片式展示带边界框的图像，从摄像头或视频文件检测目标。使用 VOC 数据集的类别作为模型的文本查询。将标签 `cup` 和 `butterfly` 添加到文本查询中，以便模型能检测杯子和蝴蝶。IOU 和 NMS 阈值设置在 Cell 01 的最后一行。Cell 02 中用于 IOU 和 NMS 的代码来自第 [7](#Chapter_7.xhtml#bk978-0-7503-6244-3ch7) 章。Cell 03 以图像为输入，输出带有边界框/标签/概率的图像。Cell 03 第 02 行的 H、W 和 C 参数被保存用于边界框。从预训练模型中，我们在每张图像上获得 576 个边界框。每个边界框都有其概率和类别标签。这些概率来自 SoftMax 函数（Cell 03 第 07 行）作用于预训练模型的一个输出。相对边界框是第 16 行列表中的列表。列表中列表的每个元素都是一个边界框的 xc、yc、w、h、标签和概率。这四个坐标是 0 到 1 之间的相对数值。我将它们打包成一个列表，以便使用第 [7](#Chapter_7.xhtml#bk978-0-7503-6244-3ch7) 章中定义的两个函数，从这 576 个边界框中挑选出几个优质的边界框。OWL-ViT 模型灵敏度足够高，能够检测背景中的许多小目标。Cell 03 第 13 行的代码用于忽略极小的目标。项目 [7.5](#Chapter_7.xhtml#bk978-0-7503-6244-3ch7ueqn23) 中 Cell 05-07 的代码被重用以显示文件夹中的图像或来自摄像头的视频帧。图像处理速度约为 10 FPS。当计算机焦点位于图像窗口时，你可以随时按 Esc 键终止程序。OWL-ViT 目标检测的准确率低于 YOLOv8 模型。
