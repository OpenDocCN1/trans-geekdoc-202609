# 第 5 章

## 利用 VAE 进行图像生成

本章介绍用于无监督学习以生成假二次曲线和假 MNIST 图像的变分自编码器 (VAE)。VAE 中的模型易于训练，但 VAE 生成的图像质量不如 GAN 生成的好。VAE-GAN 是这两种技术的混合体，并已在 MNIST、Fashion MNIST 和 Anime 数据集上实现。

在第 [3](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3) 章中，我们使用生成对抗网络生成假图像。由于模式崩溃和其他问题，DCGAN 和 cDCGAN 的模型训练仍然是一个挑战。需要花费大量时间来调整初始学习率、学习率调度器和其他超参数，以实现成功的模型训练。在第 [4](#Chapter_4.xhtml#bk978-0-7503-6244-3ch4) 章中，使用了 WGAN-GP 来稳定模型训练。我们也可以使用无监督学习算法来生成图像。基于该算法的生成模型（Kingma 和 Welling [2013](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5bib2)）是变分自编码器 (VAE)，它们易于训练。它们可用于通过学习数据集底层结构的紧凑表示，生成与给定数据集中的图像相似的新数据样本（图像）。VAE 系统中也有两个模型。编码器模型或网络将输入数据映射到低维表示（将每张图像压缩为一个低维潜在向量）。潜在向量可以有 1D、2D、3D 甚至超过一百个维度。例如，一张 MNIST 图像可以被压缩为 2D 潜在空间中仅包含两个元素的向量。然后，系统中的解码器网络使用潜在向量生成一张与原始 MNIST 图像相似的图像。图像压缩比为 392 (= 784/2)。然而，VAE 并非为图像压缩而设计，因为 VAE 算法不如 JPEG 算法好。VAE 比 GAN 发明得更早。理论更难理解，且 VAE 生成的假图像质量通常不如 GAN 生成的清晰。那么，为什么我们要浪费时间学习 VAE 呢？

我们感兴趣的不是假图像，而是由 VAE 系统生成的那些低维潜在向量。潜在向量中的每个元素都是 VAE 系统学到的一个图像特征。通过调整潜在向量中这些元素的值，我们可以编辑图像以生成新图像。例如，我们可以将图像中的人脸表情从愤怒变为微笑，将图像中的月相从满月变为新月。借助基于 VAE 算法的新技术，如向量量化变分自编码器 (VQ-VAE)，我们可以在无监督学习中达到最先进的结果。我们可以将 VAE 与 GAN 结合，利用这两种技术的优势进行模型训练。VAE 已被用于许多领域，包括图像生成、异常检测和强化学习。

### 5.1 VAE 和 beta-VAE

在 VAE 系统用于图像生成的应用中，数据集中的每张图像都是高维观测空间中的一个点。例如，每张 MNIST 图像都是 784 维空间中的一个点。通常，我们的计算机内存不足以容纳数据集中的所有图像。我们必须将图像数据集切片为一个包含许多批次的数据加载器。它们的批次大小是一个常数 `n`。一个批次中的图像是观测数据：`x[1]`、`x[2]`、…、`x[n]`。每张图像由一个包含元素的潜在向量生成：`z[1]`、`z[2]`、…、`z[m]`，其中 `m` ≪ `n`。表 [5.1](#Chapter_5.xhtml#bk978-0-7503-6244-3ch5t1) 显示了观测数据点和未知潜在向量的未知联合概率。`p(x[j])` 的边际概率也是未知的（`j` = 1, 2, …, `n`）。我们假设先验分布 `p(z[i])` 服从标准正态分布 `N(0,I)`，其中 `I` 是单位矩阵。根据公式 ([1.28](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn28))，我们有 `p(x_j) = ∑_{i=1}^m p(x_j,z_i) = ∑_z p(x_j,z)`。从数据集的负似然，我们得到一个损失函数：

```
L = - ln ( P( X ) ) = - ln ∏_{j=1}^n p( x_j ) = - ∑_{j=1}^n ln ( ∑_z p( x_j,z ) )
```

(5.1)

**表 5.1.** VAE 系统的未知联合概率。

| `P(X,Z)` | | `x[1]` | | `x[2]` | | … | | `x[n]` | | `P(Z)` |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `z[1]` | | `p(x[1],z[1])` | | `p(x[2],z[1])` | | … | | `p(x[n],z[1])` | | `p(z[1])` |
| `z[2]` | | `p(x[1],z[2])` | | `p(x[2],z[2])` | | … | | `p(x[n],z[2])` | | `p(z[2])` |
| … | | … | | … | | … | | … | | … |
| `z[m]` | | `p(x[1],z[m])` | | `p(x[2],z[m])` | | … | | `p(x[n],z[m])` | | `p(z[m])` |
| `P(X)` | | `p(x[1])` | | `p(x[2])` | | … | | `p(x[n])` | | 1.00 |

由于联合概率未知，我们无法直接使用上述公式对损失函数做任何处理。幸运的是，我们可以构建一个编码器网络，它使用数据加载器中每一批图像作为编码器的输入，以获得批次中每张图像的均值向量和方差向量。然后，均值向量和方差向量被用来为每张图像构建一个多元正态分布 `q(z|x)`。图像的潜在向量的每个元素随后通过从 `q(z|x)` 采样获得。利用 VAE 编码器的先验概率和第 [1.1.4](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1s1-1-4) 节中关于 `g(x) = -ln(x)` 的 Jensen 不等式，我们可以间接找到 VAE 系统损失函数的最小值。在下面的负对数函数内部是关于 `z` 的 (`p`/`q`) 的平均值，它应该小于或等于 `-ln(p/q)` 的平均值。
