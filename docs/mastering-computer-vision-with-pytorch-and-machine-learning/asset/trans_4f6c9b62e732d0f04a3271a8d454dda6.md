## 1.3 自动梯度计算与学习率调度器

在每个计算机视觉项目中，模型训练期间我们都必须至少计算一个损失函数对参数的梯度。在一个包含数十亿参数、分布在许多神经层的模型中，几乎不可能手动推导梯度公式。PyTorch 可用于自动计算这些梯度，而无需提供梯度公式。我们知道，标量函数 *f*(*x,y,z*) 对向量 *V* = [*x,y,z*] 的梯度仍是一个向量，其分量为偏导数：∇*f* = [∂*f*/∂*x*, ∂*f*/∂*y*, ∂*f*/∂*z*]。例如，函数 *f*(*x,y,z*) = *x*² + *y*² + *z*² 在点 *V* = [1,2,3] 处的梯度为：∇*f* = [2*x*, 2*y*, 2*z*] = [2, 4, 6]。以下 VS Code 用于通过 PyTorch 自动计算梯度。`torch` 包在 Cell 01 的第一行导入。它支持多维张量的数据结构，并为这些张量提供数学运算。Torch 张量类似于 NumPy 的数组，二者可以相互转换。使用 torch 张量的主要优势在于 torch 张量可以被移动到 NVIDIA GPU 上进行并行计算，从而节省时间。

![](images/bk978-0-7503-6244-3ch1uf7_pr.gif)

要计算标量函数的梯度，作为 torch 张量的向量必须将其属性 `requires_grad` 设为 True（第 02 行）。有了这个设置，向量的所有数学运算都会被 PyTorch 记录下来。在 Cell 01 的 for 循环中，*f* 函数必须放在循环内部，然后必须调用 `f.backward()` 函数来计算所有运算中的梯度。函数的梯度随后累积在 `V.grad` 中。关于 Cell 01 的输出，第一次迭代中的梯度计算是正确的，另外两次是错误的。只有当你删除第 08 行前面的井号符号 # 时，所有计算才会正确。每次使用 PyTorch 自动计算梯度时，你都需要通过 `grad.zero_()` 将梯度重置为零，或使用稍后提到的其他方法。

对于包含多个变量的标量函数，我们可能需要忽略某个变量对函数梯度的贡献。上述 Cell 02 中的代码可用于进一步了解 PyTorch 中用于自动梯度计算的 `backward()` 函数和 `detach()` 函数。这里有另一个函数 *R* = *y* + *z*，其中 *y* = *x*[1]² + *x*[2]² + *x*[3]²，*z* = *x*[1]³ + *x*[2]³ + *x*[3]³，在 *x* = [*x*[1], *x*[2], *x*[3]] = [1,2,3] 处。我们可以用公式 [2*x*[1] + 3*x*[1]², 2*x*[2] + 3*x*[2]², 2*x*[3] + 3*x*[3]²] 计算梯度 ∇[*x*]*R* = ∂*R*/∂*y* ∂*y*/∂*x* + ∂*R*/∂*z* ∂*z*/∂*x*。使用 PyTorch，我们不需要知道梯度公式。只需调用函数 `R.backward()`，∇[*x*]*R* 的所有中间梯度都会被 PyTorch 的反向传播算法记录和跟踪。然后通过调用 `x.grad`，通过累积所有中间梯度获得 ∇[*x*]*R*。

通过设定 ∂*R*/∂*y* = 0，我们可以忽略 *y* 对 ∇[*x*]*R* 的贡献。在第 [3](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3) 章的生成对抗网络（GANs）项目中，我们将遇到这类任务。在这种情况下，我们有 ∇[*x*]*R* = [3 × 1², 3 × 2², 3 × 3²]。在上述 Cell 02 中，`y.detach()` 用于实现 ∂*R*/∂*y* = 0。你可以将 `y.detach()` 改为 `z.detach()` 以查看梯度输出的差异。基于 PyTorch 中自动梯度计算的知识，我们可以用另一种方式编写项目 [1.3.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn15) 的代码，用于关于温度转换的简单线性回归。
