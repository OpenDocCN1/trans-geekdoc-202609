# 第 6 章

## 利用 infoGAN 进行图像生成

信息最大化生成对抗网络也是一种无监督计算机视觉技术，利用它我们可以在不使用标签的情况下生成特定风格的图像，这些图像与训练数据集中的图像相似。首先使用二次曲线数据集来解释 infoGAN 原理，然后将该技术用于 MNIST、动漫人脸和剪刀石头布数据集。

虽然使用原始 GAN 随机生成逼真的假图像很重要，但使用条件 GAN 生成期望的假图像更为重要。由于条件 GAN 可以将数据集中图像的标签信息编码进去，它们具有使用我们预设的标签生成特定图像的能力。不幸的是，许多数据集没有标签，因为数据集标注成本非常高。对于无监督学习我们能做什么？使用变分自编码器是为无标签数据集生成期望假图像的一种解决方案。然而，VAE 系统生成的假图像通常模糊不清，不够锐利。2016 年，Xi Chen 及其合作者发表了一篇论文（Chen *et al* [2016](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6bib1)），题为“InfoGAN: Interpretable representation learning by information maximizing generative adversarial nets”（InfoGAN：通过信息最大化生成对抗网络进行可解释的表征学习）。利用 infoGAN 系统，我们的代码在模型训练期间足够智能，能自动发现数据集中图像的不同特征，并使我们能够改变与这些特征相关的某些参数，从而生成具有期望类别和效果的假图像。

### 6.1 使用 infoGAN 生成二次曲线
