### 8.3 使用 YOLOv7 进行人体姿态估计（关键点检测）

人体姿态估计是一项计算机视觉任务，用于从图像或视频帧中估计人体关节（关键点）的位置和朝向。姿态估计有许多应用。通过随时间跟踪一个人的姿态，可以分析和识别特定的动作或手势。人体关键点是我们身体运动的关键部位。YOLOv7 可追踪人体的 18 个关键点。人鼻尖为 0 号点。连接双肩的线段的中点为 1 号点。从左到右，六个点位于双臂关节上，六个点位于双腿关节上。然后两个点用于双眼，两个点用于双耳。通常，姿态估计需要昂贵的位置跟踪硬件。也有姿态估计软件，如 Google DeepPose 和 MediaPipe。它们分两阶段工作：人体检测和关键点检测。YOLOv7-pose 是一种单阶段多人关键点检测器。在 WongKinYiu 的 YOLOv7 GitHub 仓库中，有一个供我们下载的 pose 分支。将从该分支下载的文件解压到我们 VS Code 工作区的 'mask' 文件夹后，我们即可使用权重文件 `yolov7-w6-pose.pt` 运行预训练的关键点检测模型，以进行人体关键点检测（Maji *et al* [2022](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8bib1)）。

项目 [8.3.1](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8ueqn5) 中单元格 01 的第 02–04 行代码分别从 Python 文件 `datasets.py`、`general.py` 和 `plots.py` 导入函数。这些文件位于 `../mast/utils/` 文件夹中。单元格 02 中定义的函数用于加载 YOLOv7 姿态模型和预训练权重文件。如果 GPU 可用，模型将被移至 GPU 内存，并使用半精度浮点数（float16）以节省时间。你可以打印模型以查看其结构，也可以打印 `model.yaml` 文件以查看模型的一些超参数。单元格 03 第 02 行的代码用于保持输入图像的尺寸，以便单元格 03 第 18 行的代码可将带有关键点的输出图像尺寸调整为原始图像尺寸。单元格 03 第 03 行的代码使用 `letterbox` 函数修改输入图像以适配模型。其中一项修改是将输入图像调整为 960 × 960。单元格 03 中 `process_img()` 函数的输出是一张带有关键点的图像。我们可以复用上一节中的单元格 04 和 05 来显示图像或视频，只需将 `yolov7` 改为 `process_img`。处理结果图像如图 [8.3](#Chapter_8.xhtml#bk978-0-7503-6244-3ch8fig3) 所示。YOLOv7 姿态模式的图像处理速度约为 15 FPS，而预训练的 Detectron2 姿态模型约为 3 FPS（附录 [F](#Appendix1.xhtml#bk978-0-7503-6244-3AppAsA-F)）。
