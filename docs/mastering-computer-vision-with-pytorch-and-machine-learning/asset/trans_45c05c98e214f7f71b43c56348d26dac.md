### 1.4 数据集、数据加载器、GPU 与模型保存

计算机视觉项目中用于模型训练的数据应打包进数据集。通常，数据集的体量巨大。许多无私的数据集创建者已将众多数据集打包完毕。下载数据集后，我们需要将每个数据集切片为包含多个批次的数据加载器，因为计算机内存不足以在单个批次中处理数据集的所有数据。这就像吃大蛋糕，我们必须用刀将其切成小块，以便每块都能放进嘴里。我们将在项目 [1.4.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn22) 中学习如何将温度 CSV 文件中的数据打包进数据集并将其切片为数据加载器。这些对于简单项目来说都是额外的工作，但却是计算机视觉项目处理大型数据集的必要步骤。

![](images/bk978-0-7503-6244-3ch1uf16_pr.gif)

在单元格 01 中导入了更多 Python 和 PyTorch 库，作为我们将数据打包进数据集并将数据集切片为数据加载器的工具。数据在数据集内部是如何打包的？或者说数据集的结构是怎样的？项目 [1.4.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn22) 单元格 02 中的代码作为示例，展示了如何将数据打包进数据集。通过从 PyTorch 的 `torch.utils.data` 导入的子类 `Dataset`，定义了一个名为 `C2F` 的类。`C2F` 类中的 `__init__` 函数使用 `np.loadtxt` 函数，以字符串形式的文件名从 CSV 文件输入数据。选项 `np.float32` 很重要，因为我们需要它将数据转换为 float32 张量。然后记录两列数据及每列的长度。`C2F` 类中的第二个函数 `__getitem__` 可用于在特定索引处选取数据集中的单个数据对。借助 `C2F` 类中的最后一个函数 `__len__`，我们可以查明数据集中有多少数据对。在单元格 03 中，文件名字符串为 `d:/C2F.csv` 的 CSV 文件被用作 `C2F` 类的一个实例。你可以看到 `C2F` 类完全按预期工作。在单元格 03 的 `my_dataset[0]` 中，如果将 `0` 改为 `:`，将打印出数组 x 中的所有九个元素和数组 y 中的所有九个元素。

使用 PyTorch 中来自 `torch.utils.data` 的子类 `DataLoader` 将数据集切片为许多小批次非常容易。在单元格 04 中设置选项 `shuffle = False`，数据顺序不会改变。对于未来用于模型训练的图像数据加载器，我们需要将此选项设为 True 以减少过拟合。单元格 04 中的一个 for 循环打印出数据加载器的第一个批次。当然，如果你移除 `break`，将打印出所有三个批次。
