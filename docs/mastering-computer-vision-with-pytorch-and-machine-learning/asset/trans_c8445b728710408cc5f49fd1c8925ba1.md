

## 6.1 二次曲线项目中 infoGAN 的实现

$I(c, G(z, c)) \ge L_I(G, Q) = E_{x \sim G(z, c)}[E_{c' \sim P(c, \sim, x)}[\ln[Q(c', \sim, x)]]] + H(c)$

(6.4)

通过最大化互信息的下界来最大化互信息是合乎逻辑的。利用梯度下降算法，我们需要找到下界负值的最小值。这就是为什么在模型 G 的损失函数（[6.3](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6eqn3)）中使用高斯负对数似然损失函数的原因。在以下用于二次曲线项目的 infoGAN 项目 6.1 的代码中，大多数超参数和所有库都列在 `Cell 01` 中。照例，`Cell 02` 生成数据，`Cell 03` 利用这些数据绘制真实的二次曲线。图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(B) 和 (C) 展示了由 infoGAN 代码生成的假曲线。模型 D1 的损失函数值非常接近其理论数值。但模型 G 的损失曲线非常嘈杂。这些噪声来自图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(E) 中所示的高斯负对数似然损失 `loss_con`。超参数 `lambda_info` 用于限制 `loss_con` 对模型 G 损失的贡献。

在 `Cell 09` 中，噪声张量生成器函数 `noise4G_input` 对我们来说是新的。它生成三个随机张量并将它们连接成一个 $m \times 16$ 的张量 `Z`，这是该函数的第一个输出。该张量将用于生成一批假曲线。该函数的另外两个输出（`labels` 和 `con_c`）将在模型训练期间更新，并可用于调整这些假图像以达到我们期望的效果。`Cell 10` 中的 `train_D1` 函数与普通 GAN 中的一样。在 `Cell 11` 中关于名为 `train_G` 的函数，损失函数有三个部分。第一部分是用于欺骗模型 D1 的 BCE 损失；第二部分是用于建立模型 Q 的 logits 输出与潜在标签之间联系的交叉熵损失；第三部分是高斯负对数似然损失。它用于确保服从正态分布 $N(c[3]; \mu, \sigma^2)$ 的潜在代码中的风格变量，其中 `mu` 和 `var` = $\sigma^2$ 是模型 Q 的两个输出。我们使用 Pytorch 的一个名为 `nn.GaussianNLLLoss` 的类来计算损失值。

`Cell 12` 到 `14` 的代码用于训练模型并显示模型训练结果。模型训练后，生成了一条单独的假曲线，如图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(F) 所示。其数据由 `Z = torch.randn(1, Z_dim)` 生成，然后通过 `Z[:,13] = 0`、`Z[:,14] = 1` 和 `Z[:,15] = -0.1` 进行设置。使用标签代码 `c[1] = 0` 和 `c[2] = 1`，infoGAN 系统生成一条最低点低于 $y = 0.5$ 的假曲线；而使用标签 `c[1] = 1` 和 `c[2] = 0`，infoGAN 系统生成一条最低点高于 $y = 0.5$ 的假曲线。风格变量 `c[3]` 可用于沿 $y$ 轴连续调整假曲线的最低点。如果 $|c[3]|$ 太大（$\gg 1$），假曲线将不平滑。基于 infoGAN 理论的额外工作赋予了我们在没有数据集标签信息的情况下调整假图像的能力。

### 6.2 MNIST 数据集中 infoGAN 的实现

凭借第 [3.2.2](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3s3-2-2) 节中关于 DCGAN MNIST 项目的知识以及上一节关于生成假二次曲线的 infoGAN 结构，我们应该很容易理解项目 6.2.1 中关于使用 infoGAN 生成假 MNIST 图像的以下代码。我们应该注意的关键是 `Cell 01` 中的参数 `k`。它是模型 G 的学习率与模型 D1 的学习率之比。在 infoGAN 论文中，它被设置为 5。正如第 [3.2.2](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3s3-2-2) 节所述，我们知道模型 G 不如模型 D 聪明。我们应该为该比率使用一个更大的数字（`k = 25`），以便两个模型具有相同的智能来相互竞争。花费了很长时间来同时调整初始学习率（`lr`）和比率（`k`），以生成图 [6.2](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig2)(A) 所示的高质量假图像，这些是 `Cell 15` 的输出。这些假图像清晰锐利，无法与 `Cell 04` 输出的真实图像区分。那些假图像的每一列都有相同的数字。这意味着我们的 infoGAN 算法有效。
