
从这些随机变量的联合似然 ${likelihood}\left( {Y \mid X} \right) = \prod\limits_{i = 1}^{n}p_{i}\left( {y_{i} \mid x_{i}} \right)$，我们得到损失函数 $L = - \ln\left( \prod_{i = 1}^{n}{\frac{1}{\sqrt{2\pi\sigma^{2}}}}e^{- \frac{1}{2}{(\frac{y_{i} - \mu_{i}}{\sigma})}^{2}} \right)$

$$L = \frac{\beta}{2}\sum\limits_{i = 1}^{n}\left( {\mu_{i} - y_{i}} \right)^{2} - \frac{n}{2}\ln\left( \beta \right) + \frac{n}{2}\ln\left( {2\pi} \right)$$

(1.23)

为了获得 *W* 和 *β*，我们需要最大化似然函数。这等同于最小化损失函数。由 ∇[*W*]*L =* 0 和 ∇[*β*]*L =* 0，我们得到：

*W* = (*X*^(*T*)⋅*X*)^( − 1) ⋅ *X*^(*T*) ⋅ *Y*

(1.24)

$$\beta = \frac{1}{N}\sum\limits_{i = 1}^{N}\left( {\mu_{i} - y_{i}} \right)^{2}$$

(1.25)

如果 *β* = 1，公式 ([1.23](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn23)) 变为 MSE 损失函数。损失函数中的常数不影响损失函数的梯度。事实上，在岭回归（Hilt *et al* [1977](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1bib2)）中，我们向 MSE 损失函数添加一个常数，通过调整参数 λ 来对抗过拟合问题：$L = \frac{1}{2}\sum\limits_{i = 1}^{N}\left( {{\widehat{y}}_{i} - y_{i}} \right)^{2} + \frac{\lambda}{2}{\mid\mid}\mathit{W}{\mid\mid}^{2}$，其中  ∣ ∣*W* ∣ ∣² = *w*[0]² + *w*[1]² + … + *w*[*M*]²

*W* = (*X*^(*T*)⋅*X*+*λ**I*)^( − 1)*X*^(*T*) ⋅ *Y*

(1.26)

### 1.1.6 期望最大化算法在寻找 PDF 中的应用

在许多机器学习项目中，我们需要在高维空间中找到数据集的 PDF。**期望最大化算法**（Dempster *et al* [1977](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1bib1)）是为这些项目执行最大似然估计的一种有用方法。在一个教师给学生一个包含 1D 数据集的 csv 文本文件作为作业以寻找 PDF 的场景中，学生首先应该做的是使用项目 [1.1.2](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn8) 中的代码绘制数据的直方图。从图 [1.2](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1fig2)(A) 所示的直方图来看，学生可以猜测教师用三个高斯分布生成了数据文件，并且它们对数据集 PDF 的贡献相同（权重 = 1/3）。从直方图中，学生还可以猜测这三个正态分布的均值和方差分别为：\[−5.5, 0.0, 4.0\]，\[1.0, 1.0, 1.0\]。如果学生仅凭猜测就完成了作业，教师不会给学生及格分数。
