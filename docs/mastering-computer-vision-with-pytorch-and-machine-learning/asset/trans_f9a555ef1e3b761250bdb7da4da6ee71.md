

# infoGAN 架构

在图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(A) 所示的 infoGAN 架构中，共有四个模型：模型 `G`、模型 `D0`、模型 `D1` 和模型 `Q`。第一个是生成器模型 `G`，其结构与普通 GAN 中的生成器模型相同。最后一个是“辅助模型” `Q`。`D0` 和 `D1` 是第 [3.1.1](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3s3-1-1) 节中 GAN 判别器模型 `D` 的两个部分。模型 `D` 中有两个全连接层。其最后一个神经层被移除以构建模型 `D1`，而另一个神经层用于模型 `D0`。模型 `D0` 的输出由模型 `D1` 和模型 `Q` 共享。模型 `Q` 的三个输出分别命名为“logits”、“mu”和“var”。

第 3.11 节 GAN 中模型 `G` 的输入是由多元标准正态分布生成的一批噪声向量，每个噪声向量用包含 `z_dim` 个元素的小写字母 `z` 表示。在 infoGAN 系统中，我们用大写字母 `Z` 表示模型 `G` 输入的噪声向量。向量 `Z` 是不可压缩噪声向量、标签向量和风格向量的拼接结果。不可压缩噪声向量即 GAN 系统中的噪声向量（`z`），我们无法调整它们以获得伪造图像的任何期望效果。对于二次曲线项目，标签向量的元素是均匀分布的离散数（整数）。对于二次曲线项目，风格向量中的元素是 [-1,1] 范围内均匀分布的连续数。在 infoGAN 论文中，后两个向量的拼接被称为潜在代码 `c`，其元素命名为 `c[1]`、`c[2]`，……`c[L]`。对于简单项目，不可压缩噪声向量的元素数、标签的元素数和风格的元素数分别被任意选定为 `z_dim` = 13、`n_class` = 2 和 `n_styles` = 1。如图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(A) 所示，噪声向量 `Z` 的维度为 `Z_dim` = (13 + 2 + 1)。每一批 `Z` 向量由项目 6.1 的 Cell 09 中定义的函数生成。

我们进行上述额外工作是为了获得期望的伪造曲线或图像。再举一个不使用标签信息的 MNIST 数据集的例子，我们想利用 infoGAN 生成期望的伪造数字图像。在这种情况下，标签向量的数量设为 `n_class` = 10（对应其 10 个类别），`n_styles` = 2（对应两种图像风格）。由于每张 MNIST 图像有 28 × 28 个像素，我们为不可压缩噪声向量 `z` 的元素数选择 `z_dim` = 62。对于简单的二次曲线项目，每条曲线有 21 个数字，因此我们可以设定 `z_dim` = 13。我们实际上并不了解那些二次曲线的标签和风格信息，而是想看看 infoGAN 能从设定了 `n_class` = 2 和 `n_styles` = 1 的二次曲线数据中学到什么。根据 infoGAN 论文，潜在代码名称“c”用于表示二次曲线项目中所有潜在变量 `c[1]`、`c[2]` 和 `c[3]` 的拼接。我们可以对潜在代码使用分解概率分布

$$P(c_{1},c_{2},\ldots,c_{L}) = \prod\limits_{i = 1}^{L = 3}{p(c_{i})}$$

(6.1)

每一批噪声向量（`Z`）被模型 `G` 用来生成一批伪造图像，如图 [6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6fig1)(C) 所示。模型 `D0` 以一批伪造曲线或一批真实曲线作为输入。`D0` 的输出是一个 `m` × `n_hidden` 张量，其中 `m` = 批次大小，`n_hidden` = 128。该输出由模型 `D1` 和模型 `Q` 共享。模型 `D1` 经过训练，通过使用以下 BCE 损失函数 `L[D1]`（与普通 GAN 相同），确保伪造图像与真实图像相比具有良好的质量

$$L_{D1} = \frac{- 1}{m}\sum\limits_{i = 1}^{m}{\ \ln\ \left\lbrack {D1\left( {D0\left( x_{i} \right)} \right)} \right\rbrack} - \frac{1}{m}\sum\limits_{i = 1}^{m}{\ \ln\ \left\lbrack {1 - D1\left( {D0\left( {\widetilde{x}}_{i} \right)} \right)} \right\rbrack}$$

(6.2)

模型 `D0` 的输出张量也被模型 `Q` 使用，后者有三个输出：一个 `m` × 2 的 logits 张量、一个 `m` × 1 的均值张量 `μ`，和一个 `m` × 1 的方差张量 `σ`²。如下式 ([6.3](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6eqn3)) 所示，损失函数 `L[G]` 包含三个部分。第一部分是一个 BCE 损失函数，用于训练模型 `G` 生成足以欺骗模型 `D1` 的、与真实图像一样好的伪造图像；第二部分是关于潜在代码中的标签与模型 `Q` 输出的 logits 之间的交叉熵损失函数；第三部分是一个高斯负对数似然损失函数，它在 `Z` 向量中的一批 `c[3]` 与模型 `Q` 的两个输出（`μ` 和 `σ`²）之间建立了数学联系。正如 infoGAN 论文所述，方程 ([6.3](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6eqn3)) 中的超参数 `λ` 应为一个较小的数值，因为来自风格变量的损失函数值可能非常大。伪造图像与潜在代码之间的数学联系是第 2.1.3 节提到的互信息 `I(c, G(z, c))`。我们可以像使用旋钮一样利用该联系来调节模型 `G`，以生成具有期望效果的伪造图像

$$L_{G} = \frac{- 1}{m}\sum\limits_{i = 1}^{m}{\ \ln\ \left\lbrack {D1\left( {D0\left( {\widetilde{x}}_{i} \right)} \right)} \right\rbrack} + {Cross}E_{Loss}\left( {\text{logits},{labels}} \right) + \frac{\lambda}{2m}\sum\limits_{i = 1}^{m}\left( {\ln\ \sigma_{i}^{2} + \frac{\left( {\left( c_{3} \right)_{i} - \mu_{i}} \right)^{2}}{\sigma_{i}^{2}}} \right)$$

(6.3)

在第 [1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1) 章第 1.1.3 节提到的赌博机中，一枚均匀硬币和一个均匀骰子是独立的，因此它们的互信息等于零。我们无法从桌上掷出的骰子点数预测硬币的正反面。为了利用潜在代码调节伪造图像以产生期望效果，我们应根据方程 ([1.18](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn18)) 最大化潜在代码 `c` 与伪造图像之间的互信息：`I(c, G(z, c)) = H(c) − H(c | G(z, c))`。我们从方程 ([6.1](#Chapter_6.xhtml#bk978-0-7503-6244-3ch6eqn1)) 知道 `c` 的 PDF，因此可以计算其熵 `H(c)`。但我们不知道伪造图像 `G(z, c)` 的 PDF，也无法直接计算 `I(c, G(z, c))`。通过引入辅助模型 `Q`，infoGAN 论文的作者规避了该问题，并找到了互信息的下界：`L[I](G, Q)`
