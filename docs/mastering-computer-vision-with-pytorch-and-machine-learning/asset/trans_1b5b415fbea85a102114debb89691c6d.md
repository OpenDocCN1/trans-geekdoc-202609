

# 计算机视觉项目中的工具与模型训练

许多计算机视觉项目都非常复杂。它们并非“易如反掌”，而是“硬骨头难啃”。我们必须使用强大的工具来解决这些项目中的问题。

## Jupyter Notebook 与 VS Code

**Jupyter Notebook** 是一个开源的基于 Web 的交互式计算环境，支持多种编程语言，包括 Python、R、Julia 等。Jupyter Notebook 文件以 `*.ipynb*` 为后缀保存，可在任何网页浏览器中打开，用户可在单元格中运行代码以获取结果。

**VS Code** 是一款免费的开源代码编辑器。它支持多种编程语言，包括 Python、C++、JavaScript 等。它提供语法高亮、调试、代码补全和 GitHub 集成等功能。

在 Jupyter Notebook 中，我们可以创建一个数学模型或拥有数百万甚至数十亿参数的模型，从海量数据中提取隐藏信息，用于计算机视觉项目。数据可以是图像、视频、语音、文本、时间序列图表（如股价）。数据文件的大小可以从几百兆字节 (MB) 到数十吉字节 (GB)。我们不可能也不必将这些数据逐个输入计算机。我们只需知道如何将数据文件下载到计算机中。Python 和 PyTorch 拥有许多库或工具，可帮助将数据输入 VS Code。

## 神经网络层与参数

通常，机器学习模型包含许多神经网络层。这些数字神经元不同于我们大脑中的生物神经元。在计算机视觉模型中，神经元层是一组人工神经元，用于处理输入数据并产生输出数据。这些层可被视为一系列过滤器，依次提取和细化输入数据中包含的信息。数字神经元是数学算子。每个神经元层都有一些可学习参数。模型中的所有这些参数在模型训练期间会自动更新，它们被称为模型**参数**。

例如，完成关于数组 C 和数组 F 关系的项目后，我们将在一个线性函数中获得斜率 1.8 和截距或偏置 32.0。它们是线性模型的两个参数。

要通过模型训练获得模型的参数，我们需要一个准则，通过将模型的输出与原始数据进行比较来评估模型的优劣。在机器学习中，准则也称为**损失函数**。在模型训练的每一步或每个周期中，我们使用**梯度下降算法**来降低损失函数的值。我们需要设置学习率和训练步数（周期数）来训练模型。这些由我们自己设置的参数不同于模型参数，我们称它们为模型的**超参数**。

训练过程可能需要几秒钟、几小时、几天甚至几周。训练时间取决于数据规模、代码和计算机硬件。计算机中需要有一个或多个图形处理单元 (GPU) 以缩短模型训练时间。GPU 经过并行处理优化，可以同时执行许多计算任务。

## 梯度下降与自动微分

令函数 `y = f(x)` 的导数 `y' = 0`，很容易找到该函数的最小值或最大值。我们可以将函数（如 `y = x² + 2x + 3`）的梯度设为零（`y' = 2x + 2 = 0`），从而在 `x = -1` 处找到函数的最小值。

通常，模型中有数百、数千甚至数十亿个参数分布在许多神经网络层中。其中大多数参数以数组或矩阵形式存在，而非标量。我们很难为这些数组显式写出损失函数梯度的公式。您知道从附录 [B](#Appendix1.xhtml#bk978-0-7503-6244-3AppAsA-B) 中的损失函数（公式 ([1.28](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn28))）推导出公式 ([1.30](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn30))–([1.32](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1eqn32)) 有多难。

## 线性回归项目实战

现在，我们在 VS Code 中创建一个 `Jupyter Notebook` 文件并将其命名为 `LinearRegression.ipynb`。在 Notebook 中，我们可以添加许多单元格。在每个单元格中，我们编写代码以完成特定任务。所有单元格中的代码就像流水线上的特定机器。它们协同工作，可以处理海量数据。

所有项目中第一个单元格的代码用于导入 Python 和 PyTorch 库作为工具。模型训练的超参数也列在第一个单元格中。每个项目第 02 个单元格的代码用于读取和打包数据。在项目 [1.2.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn10) 的 Cell 02 中，一个“逗号分隔值”文本文件 `d:/C2F.csv` 被加载到计算机内存中。

借助 Cell 01 第 01–02 行的代码（以井号 `#` 开头的行号为第 0 行），为线性回归项目导入了两个 Python 库。为了节省输入篇幅，我们将使用其缩写名称：`np` 和 `plt`。

Cell 02 中的 NumPy 函数 `np.loadtxt()` 从硬盘加载一个 csv 文件，并将数据作为一个名为 `CF` 的 9 × 2 数组存储在计算机内存中。如果您用 MS Excel 打开该 csv 文件，将看到两列，每列都有名称。模型训练不需要列名，因此我们在 Cell 02 第 01 行的函数中设置选项 `skiprows = 1`。如果您在文本编辑器中打开该文件，将看到所有数据均由逗号分隔，因此我们设置该函数的另一个选项 `delimiter = ','` 以读取数据。
