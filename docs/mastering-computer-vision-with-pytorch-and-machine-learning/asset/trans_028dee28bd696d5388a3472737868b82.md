

# 使用 PyTorch 和机器学习掌握计算机视觉

## 书籍概览

本书共包含十二章。

**第 1 章** 介绍了计算机视觉和机器学习的数学概念与工具：概率、最大似然、香农熵、梯度、激活函数、损失函数、数据集、数据加载器、学习率等。本章以九组摄氏度和华氏度温度转换的数值对为例，跨不同项目逐步引入这些数学概念。

**第 2 章** 介绍了用于三个数据集图像分类的深度卷积神经网络：`MNIST`、`CIFAR10` 和 `Vegetable Images`。这些是监督学习项目，模型基于带标签的训练数据学习进行预测。

**第 3–6 章** 涵盖了使用不同算法进行图像生成：`GANs`、`VAEs`、`WGANs` 和 `infoGANs`。利用条件 `GANs`、`infoGANs`、`VAEs` 或 `VAE-GANs`，我们可以生成具有特定风格的目标图像。`VAEs` 和 `infoGANs` 用于无监督学习项目。无监督学习的主要优势在于，它无需任何先验知识或带标签数据，即可发掘数据中隐藏的模式和结构。

**代码结构**：本书所列所有项目的代码均遵循相同的四部分风格：
1. 数据输入
2. 数据显示
3. 数据处理
4. 输出数据可视化

**第 2–9 章** 使用一个用于二次曲线生成的简单数据集，帮助读理理解新模型中的复杂算法。在许多项目中，读者只需关注第三部分（模型构建与数据处理）。

**第 7–12 章** 介绍了最新的计算机视觉技术（截至 2024 年 2 月），用于图像分类、图像生成、目标检测、目标分割和 3D 场景合成。Ultralytics 的 `YOLOv8` 是目标检测和分割的最新技术之一；它易于安装和使用，可用于图像分析任务。OpenAI、Hugging Face、Meta AI 和智能系统实验室提供了用于图像分析的新工具。借助它们的库，我们只需编写几行代码，即可生成逼真图像、检测/分割/分类物体、检索图像，并估计图像相对深度，而无需模型训练（零样本）。最后一章介绍了使用 `NeRF` 或 `3D Gaussian Splatting` 进行 3D 场景合成。许多详细的数学推导和额外的项目代码可在附录中找到。

## 关键词

计算机视觉、机器学习、Kullback-Leibler 散度、最大似然、PyTorch、CNN、GAN、WGAN、WGAN-GP、infoGAN、VAE、图像分类、目标检测、图像分割、图像生成、图像检索、YOLO、U-Net、Stable Diffusion、零样本、ViT、知识蒸馏、DINO、SAM、fastSAM、MiDaS、NeRF、3D 场景和 3D 高斯泼溅。

# 第 1 章：计算机视觉的数学工具

本章涵盖计算机视觉项目的数学工具以及 `Python`/`PyTorch` 平台。

**第 1.1 节** 介绍了关于信息熵、统计概率分布函数、Kullback-Leibler 散度、Jensen 不等式以及非线性回归中的过拟合问题的数学概念。

其余四节涵盖了用于机器学习模型训练的梯度下降算法、用于数据集、数据加载器、激活函数、GPU 使用以及模型训练/保存的 `Python`/`PyTorch` 库（工具）。本章反复使用一个简单的数据文件来引入这些概念和库。
