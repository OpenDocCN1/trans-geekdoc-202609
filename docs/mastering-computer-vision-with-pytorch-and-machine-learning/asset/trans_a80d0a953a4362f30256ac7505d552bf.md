

# 我们的世界因许多现象具有非线性而变得美丽

在计算机视觉项目中，我们必须使用多个神经层来处理非线性数学问题。然而，模型中一系列的多个线性层工作起来就像单个线性层一样。例如，假设我们的模型有两个全连接线性层：`Y[1] = w[1]*X + b[1]` 和 `Y[2] = w[2]*Y[1] + b[2]`，我们将得到 `Y[2] = w[2]*w[1]*X + (w[2]*b[1] + b[2])`，这仍然是一个线性层。为了避免这一数学问题，我们必须在两个线性层之间添加一个激活函数。激活函数有很多种，它们都是非线性的。以下是四种常用的激活函数类别：

1.  **Sigmoid 类** `nn.Sigmoid()`: `f(x) = 1 / (1 + e^{-x})`
2.  **双曲类** `nn.Tanh()`: `f(x) = (e^{x} - e^{-x}) / (e^{x} + e^{-x})`
3.  **线性整流单元类** `nn.ReLU()`: `f(x) = x (x >= 0), 0 (x < 0)`
4.  **Leaky ReLU 类** `nn.LeakyReLU(0.1)`: `f(x) = x (x >= 0), 0.1x (x < 0)`

我们将在项目 [1.5.1](#Chapter_1.xhtml#bk978-0-7503-6244-3ch1ueqn30) 中针对 `y(x) = e^{-5x}` 的非线性回归使用 Sigmoid 类作为激活函数。所有激活函数中的变量 `x` 可以是标量或数组。如果 Sigmoid 函数的输入是数组或矩阵，Sigmoid 函数将逐元素作用于该数组。Sigmoid 函数输出的每个元素值都在范围 `[0, 1]` 内。在该项目中，根据函数 `y(x) = e^{-5x}` 创建了一个 csv 数据文件，其中 `x` 在 0.0 和 1.0 之间。`x` 数组的长度为 51。我们希望使用一个具有两个全连接层的模型来模拟这个指数函数。

# 第 2 章

## 卷积神经网络图像分类

本章介绍构建和使用卷积神经网络（模型）对两个简单标注数据集 MNIST 和 CIFAR-10 中的图像进行分类。引入迁移学习以使用预训练模型对蔬菜图像数据集进行图像分类。在 MNIST 图像分类项目中获得的混淆矩阵用于展示如何计算模型训练的一些指标：召回率、精确率、F1 分数和交并比 (IOU)。

人类婴儿很容易知道他们看到了什么（图像分类），即使他们可能会被父母的“双胞胎”搞混。图像分类是计算机视觉的一个分支，始于 20 世纪 60 年代。经过 60 多年，计算机在图像分类方面的智能已超越人类。如今，城市红绿灯旁的智能摄像头可以读取行驶汽车的车牌；手机可以识别用户的人脸。图像分类被广泛应用于自动驾驶汽车和生物医学诊断系统等领域。我们应将计算机视觉的成功归功于许多先驱的人工智能理论、更强大的计算机硬件，以及许多包含海量数据的免费数据集。本章使用三个数据集来训练图像分类算法或模型。它们是 MNIST、CIFAR-10 和蔬菜图像。这些图像数据集带有标签，我们利用它们训练模型进行监督学习。这就像给三岁孩子看图画书上的动物图片，你告诉孩子：“那是狗，那是猫，或者那是鸟。”孩子的大脑通过这些带标签的图片得到训练。随后，带孩子到户外展示真实动物，并反复问多次：“那只动物叫什么名字？”在不同环境下进行。孩子回答正确的百分比是一个基准，表明孩子训练得有多好。同样，在用图像数据集训练图像分类模型后，你的模型可以预测照片中是否有猫、狗、鸟或数字“5”。一个训练良好的模型可能拥有百万级参数。这些参数和模型结构可以被保存并写入专用集成电路 (IC) 芯片以用于特定应用。
