## 3.2 深度卷积 GAN 的应用

图 [3.3](#Chapter_3.xhtml#bk978-0-7503-6244-3ch3fig3)(B) 中显示的虚假 MNIST 图像不够清晰，因为仅包含两个全连接层的模型 G 和模型 D 不够“聪明”。我们将使用强大的深度卷积 GAN (DCGAN) 来重复该项目。在 DCGAN 中，模型 D 使用卷积神经层将每张图像转换为一个标量，模型 G 使用转置卷积神经层从一个标量恢复每张图像。我们需要了解转置卷积的数学运算。

### 3.2.1 ConvTranspose2D 的数学运算

利用卷积运算，DCGAN 的判别器模型将数据加载器中一个批次的图像压缩为一个标量张量。从公式 ([2.3](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn3)) 可知，二维卷积的输出大小为：`m = (n - f + 2p)/s + 1`。DCGAN 的生成器模型使用转置卷积运算将标量转换回图像。该运算也有许多选项，例如：输入通道、输出通道、核大小、步幅、填充、偏置等。转置卷积运算的输出大小可从公式 ([2.3](#Chapter_2.xhtml#bk978-0-7503-6244-3ch2eqn3)) 推导得出，其中 `m` 为输入张量大小，`n` 为转置卷积运算的输出张量大小。

`n = (m-1)s + f - 2p`

(3.3)

运行以下 Extra Cell ONE 中的代码，你将发现 `ConvTranspose2d` 类是如何工作的。使用 0 到 8 这九个整数构建一个 `1 × 1 × 3 × 3` 的张量 `X`，其中 `m = 3`。张量 `X` 是 `ConvTranspose2d` 类实例的输入。输入的批次大小为 1，批次中唯一图像的分辨率为 `3 × 3`，图像通道数为 1。然后将整数张量转换为 float32 张量，因为转置卷积实例接受这种类型的张量，而不接受整数张量。通常，名为 “CT” 的实例的权重和偏置由 PyTorch 随机初始化。然后通过使用 `nn.Parameter()` 将算子的权重赋值为一个 `1 × 1 × 3 × 3` 的全 1 张量，并将实例的偏置赋值为一个标量零张量。
