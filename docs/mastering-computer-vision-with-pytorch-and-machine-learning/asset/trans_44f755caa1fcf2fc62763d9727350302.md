
# 人类拥有想象、创造和建造前所未有的新事物的能力

创新和发明的能力是人类智慧的关键特征之一，并推动了科学、技术、工程和艺术等各个领域的重大进步。我们在城市中建造摩天大楼供人居住，制造手机放在口袋里用于通讯，发射火箭将卫星送至太阳系边缘以探索宇宙。所有这些工程成就都基于物理学和数学定律，例如牛顿万有引力定律、麦克斯韦电磁定律、爱因斯坦相对论、量子力学等。这些定律是我们文明的基石。它们是我们理解和改造世界的钥匙。然而，仅了解这些物理和数学定律是不够的，专家或专业人士还必须依据他们的经验开展工作。这些经验源于毕生的实践。曾经，当一位专家离世，该专家的所有经验也随之流失。如今，专业人士可以利用机器学习算法训练计算机，从而使人类经验得以传承并永久存储在计算机中。计算机视觉研究的目标是赋予计算机类人的感知能力。机器学习是人工智能（AI）的一个分支，涉及算法和统计模型的开发。机器学习使计算机能够从数据中“学习”，而无需显式编程。在机器学习中，基于算法的模型在数据集上进行训练，以发现数据集中的模式来预测新数据。机器学习有几种类型，包括监督学习、无监督学习、半监督学习和强化学习，每种类型都有其独特的算法和方法。

## 1.1 概率、熵和 Kullback–Leibler 散度

图像由像素组成，像素是屏幕上的微小点。当大量像素按特定配置（模式）排列时，它们就形成了一幅图像。图像的分辨率由其包含的像素数量决定。更高的图像分辨率能为我们提供更清晰、更细致的视觉效果。从图像像素在空间中分布的模式或概率出发，我们可以生成新图像。要开始计算机视觉的学习，必须掌握统计学概念，尤其是概率。利用贝叶斯概率定理和香农信息熵理论，我们可以推导出用于模型训练的损失函数。这些模型将变得非常智能，不仅能告诉我们图像中是否有狗或猫，还能根据我们的文本提示生成逼真的图像/视频。

### 1.1.1 概率和香农熵

对于一枚均匀硬币，抛掷时其“正面”和“反面”出现的概率相同（50%）。在硬币系统中，我们有一个在 {'正面', '反面'} 空间内的离散随机变量 `X`，其概率质量函数（PMD）为 `P(X) = {1/2, 1/2}`。若硬币不均匀，其正面概率为 `p = 0.45`，我们抛掷 10 次（`n = 10`），出现 4 次正面（`x = 4`）的概率是多少？这个不均匀硬币系统有一个在 {0, 1, …, 10} 空间内的离散随机变量 `X`，服从二项分布函数。将这些参数代入公式 (1.1)，即可得到答案：23.8%。

```
P(X = x) = n! / (x!(n - x)!) * p^x * (1 - p)^(n - x)
```

(1.1)

我们身体的身高变量（`X`）是一个服从高斯分布函数的连续随机数，这是机器学习中最重要的概率密度函数（PDF）。尽管许多图像数据集的概率密度函数过于复杂，无法显式写出，但我们仍可尝试用高斯分布函数来近似它们。

```
P(X = x) = N(x; μ, σ²) = 1 / √(2πσ²) * e^(-1/2 * ((x - μ)/σ)²)
```

(1.2)

在公式 (1.2) 中，`μ` 是 `X` 的**均值**或期望值，`σ` 是 `X` 的标准差，`σ²` 是 `X` 的**方差**。对于任何具有已知 PDF 的随机变量 `X`，其期望值 `E[p][X]` 和方差 `E[p][(X-μ)²]` 为：

```
μ = Σ(i=1 to n) x_i * p(x_i)  或  ∫(-∞ to ∞) x * p(x) dx
```

(1.3)

```
σ² = Σ(i=1 to n) (x_i - μ)² * p(x_i)  或  ∫(-∞ to ∞) (x - μ)² * p(x) dx
```

(1.4)

信息的香农**熵**是包含在随机变量中的“信息量”，或编码一个系统信息所需的最小比特数。

```
H(p) = - Σ(i=1 to n) p_i * log₂(p_i)  或  - ∫(-∞ to ∞) p(x) * log₂(p(x)) dx
```

(1.5)

均匀硬币系统的熵为 `H(p) = - 2 * 1/2 * log₂(1/2) = 1` 比特，均匀骰子系统的熵为 `H(p) = - 6 * 1/6 * log₂(1/6) = 2.585` 比特。为了机器学习中的数学便利性，我们通常使用自然对数，熵的单位为“奈特”。硬币的熵和骰子的熵分别为 0.69 奈特和 1.79 奈特。

### 1.1.2 Kullback–Leibler 散度和交叉熵

在同一随机变量 `X` 存在两个分布函数 `p` 和 `q` 的情况下，它们的对数似然比是一个函数 `f(x) = ln[p(x) / q(x)]`。对数似然比的期望值称为** Kullback–Leibler 散度**（`D_KL`）：

```
D_KL(p||q) = E_p[ln(p(X) / q(X))] = Σ(i=1 to n) p(x_i) * ln(p(x_i) / q(x_i))
```

(1.6)

`D_KL` 用于度量具有相同随机变量 `X` 的系统中两个 PDF 之间的差异。如果 `p` 和 `q` 相同，则 `D_KL = 0`。交叉熵是量化两个 PDF 之间差异的另一个指标，常用作机器学习中的损失函数。

```
H(p,q) = - Σ(i=1 to n) p(x_i) * ln(q(x_i)) = D_KL(p||q) + H(p)
```
