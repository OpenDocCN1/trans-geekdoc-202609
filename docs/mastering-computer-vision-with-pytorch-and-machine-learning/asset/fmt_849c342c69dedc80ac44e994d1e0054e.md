The input of model D defined in Cell 05 is a batch of 64 curves. Each curve with 21 points is processed by model D to become a positive scalar tensor whose value is in the range [0,1]. An activate function `LeakyReLU(0.2)` is used between those two fully connected layers. This function multiplies a factor 0.2 to each negative number, and keeps each positive number as it is for the outputs of the first layer. Both of these models are sent to GPU by `cuda()`.
