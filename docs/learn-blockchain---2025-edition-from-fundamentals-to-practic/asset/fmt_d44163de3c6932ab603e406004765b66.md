## Patient Data Management

Patient data management is one of the areas where blockchain has the potential to make the biggest impact. It offers a unique approach to handling the storage and sharing of sensitive information, ensuring that data remains secure and accessible only to authorized parties.

### Secure Data Storage

Blockchain allows medical records to be stored on a decentralized network, protected by advanced encryption algorithms. Instead of directly storing data on the blockchain, it can be kept in secure external systems, while cryptographic hashes are recorded on-chain to ensure integrity and authenticity.

```python
import hashlib

class PatientRecord:

    def __init__(self, patient_id, record_data):
        self.patient_id = patient_id
        self.record_data = record_data
        self.hash = self.generate_hash()

    def generate_hash(self):
        record_string = f"{self.patient_id}{self.record_data}"
        return hashlib.sha256(record_string.encode()).hexdigest()

patient_record = PatientRecord("Patient123", "Medical data: Blood Test Results")
print(f"Patient ID: {patient_record.patient_id}, Hash: {patient_record.hash}")
```

The code illustrates how patient data can be protected through hashing, ensuring any changes are easily detectable.

### Data Sharing with Permissions

In the traditional model, medical records are generally isolated in different systems, making it difficult to exchange information between institutions. Blockchain addresses this fragmentation by creating a single reference record that can be accessed by authorized parties with patient consent.

Smart contracts play a central role in this process, automating permission checking and controlling who can access data.

```solidity
pragma solidity ^0.8.0;

contract HealthRecord {

    struct Record {
        string dataHash;
        bool isShared;
    }

    mapping(address => Record) public records;
    mapping(address => mapping(address => bool)) public permissions;

    function addRecord(string memory dataHash) public {
        records[msg.sender] = Record(dataHash, false);
    }

    function grantAccess(address doctor) public {
        permissions[msg.sender][doctor] = true;
    }

    function viewRecord(address patient) public view returns (string memory) {
        require(permissions[patient][msg.sender], "Access Denied");
        return records[patient].dataHash;
    }
}
```

The smart contract allows patients to share their medical records with specific doctors or hospitals while maintaining full control over their data.

### Reducing Errors and Fraud

Medical errors are a global concern, often caused by incorrect or outdated information. Blockchain ensures that patient data is accurate and immutable, reducing the likelihood of errors related to duplicate or divergent information.

Additionally, it can help combat fraud, such as issuing false prescriptions, by providing a transparent, auditable record of all interactions related to medications and treatments.

## Benefits for Medical Research

In addition to improving data management, blockchain has promising applications in medical research, where large volumes of data need to be collected, shared, and analyzed ethically and efficiently.

### Ethical Consent and Privacy

Informed consent is fundamental to data collection in medical research. With blockchain, participants can provide consent for the use of their data in a granular way, specifying which types of research can access their information.

Smart contracts automate this process, ensuring that consent conditions are strictly followed.

```solidity
pragma solidity ^0.8.0;

contract ResearchConsent {

    struct Consent {
        bool isGranted;
        string researchType;
    }

    mapping(address => Consent) public consents;

    function grantConsent(string memory researchType) public {
        consents[msg.sender] = Consent(true, researchType);
    }

    function revokeConsent() public {
        consents[msg.sender].isGranted = false;
    }

    function checkConsent(address participant) public view returns (bool, string memory) {
        return (consents[participant].isGranted, consents[participant].researchType);
    }
}
```

The contract allows participants to grant and revoke consent for different types of research, promoting transparency and ethical compliance.

### Secure Data Sharing for Research

Researchers often face challenges accessing high-quality health data due to privacy and interoperability concerns. Blockchain offers a means of sharing data anonymously and securely using encryption and data masking methods.

```python
class ResearchData:

    def __init__(self, data, anonymize=True):
        self.data = data
        self.anonymized_data = self.anonymize_data() if anonymize else data

    def anonymize_data(self):
        return hashlib.sha256(self.data.encode()).hexdigest()

research_data = ResearchData("Patient medical data")
print(f"Original Data: {research_data.data}, Anonymized Data: {research_data.anonymized_data}")
```

The code demonstrates how data can be anonymized before being shared, ensuring participants' privacy.
