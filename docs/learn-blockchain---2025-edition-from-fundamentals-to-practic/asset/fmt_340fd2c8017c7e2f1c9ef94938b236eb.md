
# Fungible Tokens

Fungible tokens, such as those based on Ethereum's ERC-20 standard, are interchangeable and have the same value regardless of their origin. They are often used for digital currencies, financial assets and rewards systems.

```solidity
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MyToken is ERC20 {
    constructor(uint256 initialSupply) ERC20("MyToken", "MTK") {
        _mint(msg.sender, initialSupply);
    }
}
```

The code demonstrates how to create a fungible token using the ERC-20 standard, which is widely adopted for issuing coins and utility tokens.

# Non-Fungible Tokens (NFTs)

Non-fungible tokens (NFTs), on the other hand, are unique and represent digital property. They're ideal for assets like art, game items, and digital certificates.

```solidity
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";

contract MyNFT is ERC721 {
    constructor() ERC721("MyNFT", "MNFT") {}

    function mint(address to, uint256 tokenId) public {
        _mint(to, tokenId);
    }
}
```

This code creates an NFT using the ERC-721 standard, allowing digital items to be registered as unique on the blockchain.

# DeFi (Decentralized Finance) and Its Impacts

Decentralized Finance (DeFi) represents a transformative application of blockchain, allowing individuals to carry out financial transactions without intermediaries. Using smart contracts, DeFi eliminates the need for banks and other institutions, offering services such as lending, trading, insurance, and more.

## Fundamental Principles

DeFi is built on three main principles: accessibility, transparency and automation.

- **Accessibility**: Anyone with an internet connection can participate in DeFi platforms, regardless of location or financial background.
- **Transparency**: All transactions are recorded on the blockchain, ensuring traceability and reducing the risk of corruption.
- **Automation**: Smart contracts replace traditional intermediaries, reducing costs and speeding up processes.

## Examples of DeFi Applications

### Loans and Secured Loans

Platforms like Aave and Compound allow users to lend or borrow without the need for a bank. Borrowers provide collateral in cryptocurrencies, while lenders earn interest.

```solidity
pragma solidity ^0.8.0;

contract LendingContract {
    mapping(address => uint) public balances;
    mapping(address => uint) public borrowed;

    function deposit() public payable {
        balances[msg.sender] += msg.value;
    }

    function borrow(uint amount) public {
        require(balances[msg.sender] >= amount, "Insufficient collateral");
        borrowed[msg.sender] += amount;
        payable(msg.sender).transfer(amount);
    }
}
```

This master agreement illustrates how to create a secured loan system.

## Benefits of DeFi

- **Elimination of Intermediaries**: Reduces costs and increases efficiency.

- **Scalability**: Blockchain infrastructure can face congestion.

# CHAPTER 10. SCALABILITY ON BLOCKCHAIN

---

Scalability is one of the main challenges facing blockchain networks as their adoption grows across the world. While the technology offers significant benefits in terms of decentralization, security and transparency, its limitations in the ability to process large volumes of transactions quickly have raised concerns about its viability for large-scale use cases.

Solutions to scalability problems seek to balance performance with the fundamental principles of blockchain. Among the most relevant approaches are the Lightning Network, a second-layer solution, and sharding, which alters the underlying structure of the blockchain to improve efficiency.

## Scalability Issues

Traditional blockchain faces scalability issues due to its architecture. On public networks like Bitcoin and Ethereum, all nodes on the network must process, validate and store each transaction. This ensures security and decentralization, but also limits the number of transactions that can be processed per second.

### Low Transaction Rate

Bitcoin processes an average of 7 transactions per second (TPS), while Ethereum processes around 15 to 20 TPS. These fees are insufficient to compete with traditional systems like Visa, which can process thousands of TPS.

### Network Congestion

Increased transaction volume can cause congestion, resulting in longer wait times and higher transaction fees. This issue is evident during periods of high demand, such as during token launches or spikes in interest in NFTs.

### Energy and Resource Costs

Consensus based on Proof of Work (PoW) requires high levels of computing power, increasing energy costs and hindering environmental sustainability.

## Solutions for Scalability

Several solutions have been proposed and implemented to overcome these challenges, covering approaches at higher layers and in the blockchain architecture itself.

### Lightning Network

The Lightning Network is a second-layer solution designed to improve Bitcoin's scalability. It allows users to create payment channels outside of the main blockchain, where transactions can occur instantly and with minimal fees.

Channels are established with a smart contract, which holds both parties' funds in a multi-signature address. Transactions are recorded on these channels and once completed, the final state is transmitted to the main blockchain.

class LightningChannel:
    def __init__(self, balance_a, balance_b):
