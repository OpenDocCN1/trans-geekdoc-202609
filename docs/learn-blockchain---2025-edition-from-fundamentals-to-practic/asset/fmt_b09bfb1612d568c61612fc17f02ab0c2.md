
# Altcoins, Stablecoins, and Tokens

Altcoins, or alternative currencies, refer to all cryptocurrencies that are not Bitcoin. They were created to overcome limitations of Bitcoin or to offer unique functionalities that suit different use cases.

## Litecoin

Litecoin was designed as a lighter alternative to Bitcoin with a focus on fast and affordable transactions. It uses a different hashing algorithm called Scrypt, which reduces dependence on specialized mining hardware.

```python
# Transaction time simulation between Bitcoin and Litecoin

def transaction_time(block_time, transactions):
    return block_time * transactions

bitcoin_time = transaction_time(10, 5)  # Average Bitcoin time: 10 minutes per block
litecoin_time = transaction_time(2.5, 5)  # Average Litecoin time: 2.5 minutes per block

print(f"Bitcoin: {bitcoin_time} minutos, Litecoin: {litecoin_time} minutos")
```

Litecoin reduces average transaction times, making it ideal for fast payments and microtransactions.

## Ethereum

Ethereum is the second largest cryptocurrency in terms of market capitalization and has introduced smart contracts on the blockchain. While Bitcoin is limited to value transfers, Ethereum allows the execution of programmable code in the form of decentralized applications (dApps).

Developers can create smart contracts that automate processes like lending, insurance, or even decentralized governance.

```solidity
pragma solidity ^0.8.0;

contract SimpleContract {
    address public owner;

    constructor() {
        owner = msg.sender;
    }

    function getOwner() public view returns (address) {
        return owner;
    }
}
```

The Solidity code demonstrates how to create a simple contract to manage ownership, illustrating the flexibility of Ethereum.

## Cardano

Cardano is a blockchain platform that focuses on sustainability and scalability. Using a Proof of Stake consensus algorithm called Ouroboros, it reduces energy consumption while maintaining security.

Its features include smart contracts and the ability to interact with multiple blockchains, promoting interoperability.

## Polkadot

Polkadot facilitates communication between different blockchains, allowing information and assets to be transferred between different networks. This functionality, called interoperability, solves the problem of fragmentation in the blockchain ecosystem.

## Monero

Monero is a privacy-focused cryptocurrency offering anonymous transactions. Using technologies such as stealth addresses and ring signatures, it ensures that senders, recipients and transacted amounts remain hidden.

```python
# Anonymous transaction simulation using masked values

class MoneroTransaction:
    def __init__(self, sender, receiver, amount):
        self.sender = self.mask_address(sender)
        self.receiver = self.mask_address(receiver)
        self.amount = amount

    def mask_address(self, address):
        return f"MASKED-{address[-4:]}"

transaction = MoneroTransaction("Alice123", "Bob456", 100)
print(f"Sender: {transaction.sender}, Receiver: {transaction.receiver}, Amount: {transaction.amount}")
```

Monero's approach exemplifies how privacy can be integrated into financial transactions.

## Stablecoins

Stablecoins are cryptocurrencies designed to minimize volatility by tying their value to stable assets such as fiat currencies, commodities or controlling algorithms.

### Stablecoins Backed by Fiat Currencies

These stablecoins hold reserves equivalent to the number of tokens in circulation. For each unit issued, a corresponding fiat currency is stored in an escrow account.

Tether (USDT) and USD Coin (USDC) are popular examples of this category. They offer stability and are widely used for international transfers, payments and protection against volatility in cryptocurrency markets.

```python
class FiatBackedStablecoin:
    def __init__(self, fiat_reserve):
        self.reserve = fiat_reserve
        self.tokens = 0

    def mint(self, amount):
        if amount <= self.reserve:
            self.tokens += amount
            self.reserve -= amount
            return f"{amount} tokens minted"
        return "Insufficient reserve"

stablecoin = FiatBackedStablecoin(1000)
print(stablecoin.mint(500))
```

The script demonstrates the issuance of stablecoins backed by fiat reserves.

### Cryptocurrency-Backed Stablecoins

These stablecoins use other cryptocurrencies as collateral. Because cryptocurrencies are volatile, they often require overcollateralization to ensure stability.

DAI is an example of a cryptocurrency-backed stablecoin where users lock Ether in smart contracts to issue DAI.

### Stablecoins Algorítmicas

Algorithmic stablecoins do not rely on reserves, but use algorithms to adjust their supply based on demand. If the token price rises, the algorithm increases the supply; if it falls, it reduces supply.

```python
class AlgorithmicStablecoin:
    def __init__(self, supply, price_target):
        self.supply = supply
        self.price_target = price_target

    def adjust_supply(self, market_price):
        if market_price > self.price_target:
            self.supply += 10  # Increase to supply
        elif market_price < self.price_target:
            self.supply -= 10  # Reduce supply

stablecoin = AlgorithmicStablecoin(1000, 1.0)
stablecoin.adjust_supply(1.2)
print(f"New supply: {stablecoin.supply}")
```

The code exemplifies how algorithmic stablecoins adjust supply to stabilize their price.

## Tokens

Tokens are digital assets created on existing blockchains. They can represent a wide range of utilities, from voting rights to access to services.

### Fungible Tokens

Fungible tokens, like ERC-20 on Ethereum, are interchangeable. They are used in applications such as decentralized finance (DeFi) and crowdfunding.

```solidity
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MyToken is ERC20 {
    constructor(uint256 initialSupply) ERC20("MyToken", "MTK") {
        _mint(msg.sender, initialSupply);
    }
}
```

The code creates an ERC-20 standard fungible token, illustrating the simplicity of creating tokens on Ethereum.

### Non-Fungible Tokens (NFTs)

NFTs are unique and not interchangeable. They are used to represent digital property in art, games, and collectibles.

```solidity
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";

contract MyNFT is ERC721 {
    constructor() ERC721("MyNFT", "MNFT") {}

    function mint(address to, uint256 tokenId) public {
        _mint(to, tokenId);
    }
}
```

The code demonstrates the creation of a non-fungible token using the ERC-721 standard.
