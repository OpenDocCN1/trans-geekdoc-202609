
# Blockchain Security and Supply Chain Applications

## Security Mechanisms

- **Proof of Stake** requires validators to have a significant stake in the network, aligning their interests with the success of the system.
- **Proof of Authority** uses verified identities, making it difficult to create multiple fake identities.

### Advanced Cryptography

Cryptography protects data and transactions on the blockchain, making it almost impossible for attackers to tamper with information.

Public and private keys are used to authenticate transactions, while hashing algorithms such as `SHA-256` ensure the integrity of blocks.

```python
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives import serialization

# Generate key pair
private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()

# Serialize the keys
pem_private_key = private_key.private_bytes(
    encoding=serialization.Encoding.PEM,
    format=serialization.PrivateFormat.PKCS8,
    encryption_algorithm=serialization.NoEncryption(),
)

pem_public_key = public_key.public_bytes(
    encoding=serialization.Encoding.PEM,
    format=serialization.PublicFormat.SubjectPublicKeyInfo,
)

print(pem_public_key)
```

The code demonstrates how to generate and serialize public and private keys to secure transactions.

### Monitoring and Detection

Monitoring tools help detect anomalous behavior, such as a sudden increase in the number of transactions or the concentration of power in a small group of miners.

Regular audits and analysis of network traffic can identify vulnerabilities and help mitigate attacks before they cause significant damage.

### Redundancy and Resilience

Blockchain networks must be designed to withstand partial failures. Redundancy, such as replicated nodes in different regions, ensures that the network remains operational, even during attacks.

### Top Tier Solutions

Platforms like `Lightning Network` and sidechains help reduce the load on the main blockchain, mitigating the impact of DDoS attacks and congestion.

### Protocol Updates

The constant evolution of blockchain protocols is essential to maintain security. Soft forks and hard forks are used to fix vulnerabilities and introduce improvements.

Security on blockchain depends on a combination of decentralization, robust protocol design, and continuous monitoring measures. While attacks such as 51%, Sybil, and DDoS pose significant threats, effective preventive strategies can minimize their impacts and ensure network reliability.

With the growing adoption of blockchain, the importance of proactive security solutions will continue to increase, protecting the integrity of systems that are shaping the future of the economy and technology.

# CHAPTER 12. BLOCKCHAIN IN THE SUPPLY CHAIN

The integration of blockchain into the supply chain has brought a significant transformation to the industry, offering accurate tracking and unprecedented transparency. The supply chain, a complex system that connects suppliers, manufacturers, distributors and consumers, has historically faced challenges related to lack of visibility, fraud and inefficiencies. Blockchain solves many of these problems by allowing involved parties to share trusted information in a decentralized and secure manner.

## Tracking and Transparency

Tracking products in the supply chain is one of the most important applications of blockchain. Using a decentralized and immutable ledger, each step of the process can be recorded, from the origin of the raw material to delivery to the end consumer.

### Blockchain-Based Tracking

Blockchain technology creates an immutable digital record for each product or batch. This record contains data such as location, storage conditions, transfers and audits carried out along the way.

Products can be identified using QR codes, RFID tags or IoT devices connected to the blockchain. Each event is recorded as a transaction, ensuring that all network participants have access to the same information.

```python
class SupplyChain:
    def __init__(self):
        self.records = []

    def add_record(self, product_id, location, status):
        self.records.append({"product_id": product_id, "location": location, "status": status})

    def track_product(self, product_id):
        return [record for record in self.records if record["product_id"] == product_id]

supply_chain = SupplyChain()
supply_chain.add_record("Product123", "Factory", "Manufactured")
supply_chain.add_record("Product123", "Warehouse", "Stored")
supply_chain.add_record("Product123", "Retailer", "Available")

tracking_info = supply_chain.track_product("Product123")
print(tracking_info)
```

The code demonstrates how to record and track a product's history across a supply chain.

### Transparency Guarantee

Transparency in the supply chain reduces risks associated with unethical practices, such as slave labor, and fraud, such as product adulteration. Every transaction recorded on the blockchain is visible to all authorized parties, allowing audits to be carried out quickly and efficiently.

In traditional systems, information is often fragmented between different stakeholders, making data reconciliation difficult. Blockchain eliminates these gaps by creating a single source of truth for everyone involved.

```python
class Blockchain:
    def __init__(self):
        self.chain = []

    def add_block(self, data):
        self.chain.append({"block_id": len(self.chain) + 1, "data": data})

    def get_chain(self):
        return self.chain

supply_chain_blockchain = Blockchain()
supply_chain_blockchain.add_block({"product_id": "Product123", "status": "Manufactured", "location": "Factory"})
supply_chain_blockchain.add_block({"product_id": "Product123", "status": "Stored", "location": "Warehouse"})
supply_chain_blockchain.add_block({"product_id": "Product123", "status": "Available", "location": "Retailer"})

print(supply_chain_blockchain.get_chain())
```

This code simulates how supply chain records might be stored on a blockchain, ensuring data is available and protected from tampering.

## Practical Use Cases in Industries

### Food Industry

In the food sector, traceability is critical to guarantee the safety and authenticity of products. Blockchain allows consumers to know exactly where their food comes from and under what conditions it was stored.

Large companies already use blockchain to track foods such as meat, vegetables and dairy products. This helps mitigate contamination risks and quickly identify the source of problems in recalls.

### Health and Pharmaceuticals

In the pharmaceutical industry, blockchain is used to combat counterfeit medicines and ensure supply chain integrity. Each batch of medicines is registered, allowing regulators and consumers to verify the authenticity of the product.

Additionally, blockchain helps monitor transportation conditions such as temperature and humidity for sensitive medicines such as vaccines.

```python
class PharmaChain:
    def __init__(self):
        self.records = []

    def add_medication(self, batch_id, conditions):
        self.records.append({"batch_id": batch_id, "conditions": conditions})

    def verify_batch(self, batch_id):
        return [record for record in self.records if record["batch_id"] == batch_id]

pharma_chain = PharmaChain()
pharma_chain.add_medication("Batch001", {"temperature": "2-8°C", "humidity": "45%"})

verification = pharma_chain.verify_batch("Batch001")
print(verification)
```

The code shows how to monitor and verify medicines in a pharmaceutical chain.
