#### 3. Transparent Tracking

### Code: IoT Data Record on Blockchain

```solidity
pragma solidity ^0.8.0;

contract IoTDevice {
  struct DataRecord {
    uint256 timestamp;
    string data;
  }

  mapping(uint256 => DataRecord) public records;
  uint256 public recordCount;

  function addData(string memory data) public {
    records[recordCount] = DataRecord(block.timestamp, data);
    recordCount++;
  }

  function getData(uint256 recordId) public view returns (uint256, string memory) {
    DataRecord memory record = records[recordId];
    return (record.timestamp, record.data);
  }
}
```

This contract stores time-stamped data from IoT devices, ensuring traceability and security.

## Challenges in Integrating Blockchain and IoT

1. **Latency**: Validating transactions on blockchain can be slow for real-time applications.

4. **Interoperability**: The integration of different blockchain devices and platforms requires common standards.
5. **Privacy**: Ensuring that stored data respects privacy regulations such as `GDPR` is essential.
