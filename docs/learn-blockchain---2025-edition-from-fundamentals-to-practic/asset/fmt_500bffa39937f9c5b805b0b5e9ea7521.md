
Each algorithm has advantages and disadvantages, and the choice depends on factors such as scalability, security and energy consumption.

### Impact of Decentralization and Consensus

The combination of decentralization and consensus has transformed sectors such as finance, healthcare, supply chain and governance. In financial systems, for example, these technologies eliminate intermediaries and enable low-cost, almost instantaneous transfers of value.

In healthcare, decentralized blockchain facilitates the secure sharing of medical records between different providers, ensuring data privacy and integrity. In governance, algorithms such as `DPoS` have been used to create participatory models, where citizens can vote directly on decisions of public interest.

Decentralization and consensus algorithms are fundamental pillars of blockchain, enabling its broad application and ensuring security, transparency and trust. As technology evolves, new approaches and improvements continue to emerge, further expanding its possibilities.

# CHAPTER 4. SMART CONTRACTS

---

Smart contracts are one of the most revolutionary elements of blockchain technology. They expand the use of blockchain beyond a transaction recording tool, enabling the automated execution of agreements based on predefined conditions. These contracts work as code scripts that are deployed and executed on blockchain networks, eliminating intermediaries, reducing costs and increasing efficiency in various applications.

#### What Are Smart Contracts

A smart contract is a program that operates on a blockchain network, executing automatically when specific conditions are met. Its essence lies in combining programming logic with blockchain principles of immutability and decentralization. This automation ensures that agreed terms are met without the need for human intervention.

Smart contracts are made up of three main elements:

1.  **Entries**: Data or actions that trigger the contract.
2.  **Logic**: Set of programmed rules that determine how the contract should react to inputs.
3.  **Outputs**: Actions performed by the contract, such as token transfers or execution of functions.

Using smart contracts eliminates the risk of manual errors, increases transparency and reduces the likelihood of disputes as all conditions and results are recorded on the blockchain.

#### How Smart Contracts Work

Smart contracts are written in specific blockchain languages, such as `Solidity` for Ethereum, and deployed to the network as part of a block. Each contract has a unique address, allowing participants to interact with it by sending data or tokens.

When a smart contract is activated, it automatically checks whether predefined conditions have been met. If so, it performs the programmed actions such as transferring funds, recording data or updating information on the blockchain.

Execution is transparent and verifiable by all network participants, ensuring trust and eliminating the need for intermediaries.

```solidity
pragma solidity ^0.8.0;

contract SimpleContract {

    address public owner;
    uint public balance;

    constructor() {
        owner = msg.sender;
    }

    function deposit() public payable {
        balance += msg.value;
    }

    function withdraw(uint amount) public {
        require(msg.sender == owner, "Only owner can withdraw");
        require(amount <= balance, "Insufficient balance");
        payable(owner).transfer(amount);
        balance -= amount;
    }
}
```

In this smart contract, the owner can deposit and withdraw funds. The use of checks, such as `require`, guarantees that only the authorized owner can make withdrawals, protecting funds against unauthorized access.

#### Examples of Use in Public Blockchains

Smart contracts have broad applications in public blockchain networks, ranging from decentralized finance to gaming and digital identity.

##### Decentralized Finance (DeFi)

DeFi is one of the areas where smart contracts play a central role. They enable the creation of platforms that offer lending, staking, trading and other financial services without traditional intermediaries.

For example, a smart contract can be used to offer a secured loan. The borrower provides cryptocurrency collateral, and the smart contract automatically verifies the value and grants the loan. If the collateral falls below a set threshold, the contract automatically liquidates the collateral to protect the creditor.

```solidity
pragma solidity ^0.8.0;

contract LoanContract {

    address public borrower;
    address public lender;
    uint public loanAmount;
    uint public collateralAmount;
    bool public loanRepaid;

    constructor(address _lender, uint _loanAmount) payable {
        require(msg.value > _loanAmount, "Insufficient collateral");
        borrower = msg.sender;
        lender = _lender;
        loanAmount = _loanAmount;
        collateralAmount = msg.value;
        loanRepaid = false;
    }

    function repayLoan() public payable {
        require(msg.sender == borrower, "Only borrower can repay");
        require(msg.value == loanAmount, "Incorrect repayment amount");
        loanRepaid = true;
        payable(lender).transfer(loanAmount);
        payable(borrower).transfer(collateralAmount);
    }

    function liquidateCollateral() public {
        require(!loanRepaid, "Loan already repaid");
        require(msg.sender == lender, "Only lender can liquidate");
        payable(lender).transfer(collateralAmount);
    }
}
```

This smart contract implements a basic collateralized lending system. It ensures that both parties are protected by automating the liquidation of collateral if the loan is not repaid.

##### Blockchain-Based Games

Smart contracts have revolutionized the gaming industry by introducing transparency and digital ownership. In blockchain-based games, digital assets such as items and characters are represented as non-fungible tokens (NFTs). These NFTs are managed by smart contracts that guarantee authenticity and ownership.

In a game, a smart contract can be used to manage the transfer of items between players. When a player purchases an item, the contract updates ownership of the associated token and records the transaction on the blockchain.

```solidity
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";

contract GameItems is ERC721 {

    uint public nextTokenId;
    address public admin;

    constructor() ERC721("GameItems", "GI") {
        admin = msg.sender;
    }

    function mint(address to) external {
        require(msg.sender == admin, "Only admin can mint");
        _safeMint(to, nextTokenId);
        nextTokenId++;
    }

    function transfer(address to, uint tokenId) external {
        require(msg.sender == ownerOf(tokenId), "Not owner");
        _transfer(msg.sender, to, tokenId);
    }
}
```

This smart contract implements a basic in-game item management system. It uses the ERC-721 standard to create and transfer NFTs, allowing players to securely own and trade their digital assets.

##### Digital Identity

Smart contracts are also being used to create decentralized digital identity systems. These systems allow individuals to manage their personal information and share only the necessary data with third parties, without the need for a centralized intermediary.

A smart contract can store identity data such as name, age and address. When an organization requests identity verification, the contract verifies the necessary information and grants access only to what has been authorized by the holder.

```solidity
pragma solidity ^0.8.0;

contract IdentityContract {

    struct Identity {
        string name;
        uint age;
        string city;
        bool isVerified;
    }

    mapping(address => Identity) public identities;

    function createIdentity(string memory name, uint age, string memory city) public {
        identities[msg.sender] = Identity(name, age, city, false);
    }

    function verifyIdentity(address user) public {
        require(msg.sender != user, "Cannot verify yourself");
        identities[user].isVerified = true;
    }

    function getIdentity(address user) public view returns (string memory, uint, string memory, bool) {
        return (
            identities[user].name,
            identities[user].age,
            identities[user].city,
            identities[user].isVerified
        );
    }
}
```
