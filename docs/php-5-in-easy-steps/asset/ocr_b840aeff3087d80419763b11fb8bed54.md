# # Creating a user table

It is useful to restrict access to parts of a website by requiring visitors to enter a user name and password for authentication against a list of authorized users. A PHP script could verify the input against a list stored in a text file, but it is faster and more efficient to maintain the list in a database.

In this case the table will need to have four columns to store the user's first name, last name, user name and password. The table can be created using the create_table.php script described in the previous chapter on pages 146–148.

First specify that four fields are needed, then submit the form.
