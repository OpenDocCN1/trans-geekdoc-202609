# Creating an upload form

The upload form is similar to the forms used in previous examples, but with two important differences. First, the form tag must include an “encrypt” attribute with “multipart/form-data” assigned as its value. Second, the form must feature an input of the “file” type, which puts a text field and a browse button on the page.

The HTML code below creates an upload form with all of the features and a submit button.

![](bbox=[0.168, 0.273, 0.269, 0.375])

```
<html><head><title>File Uploader</title></head>
<body><h3>File Uploader</h3>
Select a file to upload:<br>

<form action="uploader.php" method="post"\ enctype="multipart/form-data">

<input type="file" name="file" size="45">
<br>
<input type="submit" value="Upload File">
</form>

</html>
```

Notice that the form handler to process this form is the uploader.php script assigned to the form’s action attribute – this is listed on the next page.
