# Getting started with PHP

All the examples that follow in this book are identical on both Windows and Linux platforms except that, where paths are mentioned, they should be appropriate to the operating system. For instance, the typical Apache root directory in Windows is C:\Apache\htdocs and in Linux it's at /usr/local/apache/htdocs.

nThis chapter introduces the PHP syntax requirements and demonstrates how to use variables and functions.
