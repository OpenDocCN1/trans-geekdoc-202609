# Sessions without cookies

The example on the previous page demonstrated how the PHPSESSID cookie is used to store the unique identifier required by the session process. This would seem to duplicate the ability to store and retrieve data directly in cookies.

There is, however, another way to make the unique identifier accessible across an entire website without requiring the browser to accept cookies. This method app the unique identifier to the URL in each hyperlink to other pages on this website.

This method is more reliable than using cookies: some prefer to set their browsers to decline cookies, so the intended functionality of the PHP script will not work.

![](bbox=[0.045, 0.368, 0.138, 0.435])

When the unique identifier is found in a PHPSESSID cookie, the SID constant is then null.

PHP has a constant SID that contains details of the unique session identifier as a key-value pair. Here PHPSESSID is the key and the identifier string is the value. This value can be simply added to the URL in a hyperlink as a query string. The syntax to do this uses the URL followed by a question mark, followed by SID as:

```
<a href="target.php?<?php echo ( SID ); ?>">link</a>
```

![](bbox=[0.045, 0.546, 0.138, 0.613])

To disable cookies in Netscape/Mozilla browsers navigate through Edit-Preferences-Privacy & Security-Cookies, click the radio button option to Disable cookies.

When the link is followed, the session identifier is sent to the target page, making the session variables available on page.

The following example is illustrated using a Mozilla browser with cookies disabled running on Windows. For it is easier to disable cookies in Mozilla than it in Internet Explorer. The first page starts the session and provides a hyperlink to another page with the SID appended as a query string. The session_id() function displays the unique identifier part of the SID on both pages.

![](bbox=[0.183, 0.746, 0.283, 0.813])

session_start.php

```
<?php session_start(); ?>
<html><head><title>Session starter</title></head><body>
<a href="next.php?<?php echo ( SID ); ?>">Next page </a>
<hr>
<?php echo( session_id() ); ?>
</body></html>
```
