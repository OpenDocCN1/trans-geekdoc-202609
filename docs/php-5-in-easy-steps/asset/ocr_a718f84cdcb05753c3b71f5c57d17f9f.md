Fruit items are:

This is just a simple example. Further query possibilities might be:

+   * query("/food/fruit/item[position() = 1]") returns just the first "item" element nested within the "fruit" element.
* query("/food/fruit/item[@id='2']") returns just the "item" element having an "id" attribute value of "2".
* query("/food/veg/item") returns all the "item" elements nested within the "veg" element.
