Order data can be specified by adding an "order" clause to the end of the SQL query. Adding "order by first_name" to the query arranges the data alphabetically by first_name:

![](bbox=[0.052, 0.435, 0.135, 0.52])

The method of working with MySQL via PHP follows this pattern —

+   1) connect to MySQL
2) select a database to use
3) build a SQL query
4) execute the query
5) make use of the returned result set data.
