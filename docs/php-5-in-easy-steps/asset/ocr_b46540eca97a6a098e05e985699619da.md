# Browser redirection

The PHP header() function supplies raw HTTP headers to the browser and can be used to redirect to another location. The redirection script should be at the very top of the page to prevent any other part of the page from loading.

The target is specified by using the "Location: header as the argument to the header() function. After calling this function, the exit() function can be used to halt parsing of the code on that page.

In this example a drop-down selection box offers the user a variety of locations to visit. When the form is submitted, the page is reloaded and the $location variable is used to redirect the browser.

![](bbox=[0.203, 0.345, 0.293, 0.455])

```
<?php $location = $_POST['location']; #assign values
$self = $_SERVER['PHP_SELF']; #assign values

if ($location != null) {
    header("Location:$location"); exit;
}
?>

<html><title>Redirect</title></head>
<body>
Choose a site to visit:
<form action="?php $self ?>">
<select name="location">
  <option value="http://www.ineasysteps.com">In Easy Steps</option>
  <option value="http://www.amazon.com">Amazon</option>
  <option value="http://www.w3.org">World Wide Web Consortium</option>
  <option value="http://www.reuters.com">Reuters News</option>
  <option value="http://www.ebay.com">Ebay</option>
</select>
<input type="submit" name="submit" value="Go">
n</form>
</body>
</html>
```

The header() function sends a header to the browser. It must appear at the start of the page, before any content is sent to the browser.
