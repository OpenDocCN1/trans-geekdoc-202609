Opening the new XML document in a web browser confirms that each new element has been correctly added, nested inside the root element. They appear after the final original “title” element, with the appropriate specified text content inserted as excerpt.

![](bbox=[0.037, 0.435, 0.125, 0.523])

Although this example saves the changes in a new document, the DOM can be manipulated "on the fly" and new elements accessed dynamically.

```
http://localhost/newbooks.xml
<?xml version="1.0" encoding="iso-8859-1" ?>
<books>
  <title>
    <topic>JavaScript</topic>
    <series>in easy steps</series>
    <pic>js.gif</pic>
  </title>
```
