
## Altering tables

Existing table column properties can be changed with the SQL command `alter table table-name modify column-name property`.

The script below alters the my_table table on the facing page to restrict the "id" column to numbers containing at most three digits. Similarly, it extends the permissible character length of the column named "last_name" from 16 characters to 32 characters.

![](img/7faa63a7fa0add8f53300594ebae949f_152_0.png)

```php
<?php
// connect to MySQL
$conn = mysql_connect("localhost", "mike", "bingo") or die("Err:Conn");
// select the specified database
$rs = mysql_select_db("my_database", $conn) or die("Err:Db");

// execute the 1st query
// reduce field to 3 number length
$query = "alter table my_table modify id int(3)";
$rs = mysql_query($query, $conn) or die("Err:Query 1");

// execute the 2nd query
// extend field to 32 character length
$query = "alter table my_table modify last_name char(32)";
$rs = mysql_query($query, $conn) or die("Err:Query 2");
?>
```

![](img/7faa63a7fa0add8f53300594ebae949f_152_1.png)

The alter statements must include the columns' data types or they will not be modified.

![](img/7faa63a7fa0add8f53300594ebae949f_152_2.png)

## Retrieving data from a table

Data can be retrieved from a MySQL database using the SQL command "select field-names from table-name" to specify the fields required and the name of the table to search.

The PHP mysql_fetch_array() function returns an associative array of all the requested data from the table, row by row. This function requires the query result set as its argument. Each piece of data in the array is associated to the column name. The data is assigned to an array variable using a while loop so that the data for each row can be retrieved using its associated column name on iteration.

The following example retrieves the data from two columns of the my_table_table, shown on page 150. Each iteration of the loop assigns a row's data to an array called "Row", then the value associated with the column first_name for each row is written out.

![](img/7faa63a7fa0add8f53300594ebae949f_153_0.png)

```html
<html><head><title>Get data</title></head><body>
<?php
#connect to MySQL
$conn = @mysql_connect("localhost", "mike", "bingo") 
or die("Err:Conn");

#select the specified database
$rs = @mysql_select_db("my_database", $conn) 
or die("Err:Db");

#create the query
$sql="select id, first_name from my_table";

#execute the query
$rs = mysql_query($sql,$conn);

#write the data
while ($row = mysql_fetch_array($rs)) {
	echo("ID: " . $row["id"]);
	echo(" FIRST NAME: " . $row["first_name"] . "<br>;");
}
?>
</body></html>
```
