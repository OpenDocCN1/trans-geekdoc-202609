# Reloading a page

Previous examples have used a different file as a form handler to process submitted data, but the same page can be used as the form handler by assigning the PHP environment variable `$_SERVER['PHP_SELF']` to the form's action attribute.

The following example demonstrating this is a guessing game that generates a random number when it is first loaded and assigns it to a hidden input. The page contains an initial code block that starts with a call to PHP header(). Its specified argument "Cache-Control:no-cache" indicates that the browser should always reload this page, rather than use a cached copy. The initial code block contains a function called setnum(), which generates a random number between 1 and 20 and assigns it to a variable `$num`. Later the page reloads and retains the value of the $num variable. If the user guesses the number correctly, the script calls the setnum() function to assign a new target number to the $num variable.

```php
<?php header("Cache-Control:no-cache");

function setnum() {
    global $num;
    $num = rand((double)microtime() * 1000000);
    $num = rand(1, 20);
}
```

```html
<html><head><title>Number guess</title></head><body>
<?php $num = $_POST['num']; $guess = $_POST['guess'];
$self = $_SERVER['PHP_SELF']; // assign values
?>
```

Notice that the syntax to check for non-numeric entries uses `is_numeric($guess)`.
