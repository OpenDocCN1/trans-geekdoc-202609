# How does PHP work?

A typical PHP document will contain one or more PHP elements, HTML markup elements, and the actual textual page content.

When a web browser requests a PHP page from a web server that is PHP-enabled, the server will call up the PHP parser to process all the PHP elements on that page.

The PHP parser executes the PHP script instructions on the page, generating a HTML document that is then sent to the web browser as a response to the original request.
