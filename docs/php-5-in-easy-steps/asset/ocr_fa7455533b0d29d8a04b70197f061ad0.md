# Viewing the guestbook

Following the link on page 170 loads the guestbook-view.php script listed below. This extracts the data from each field of the latest three records in the guestbook database table, arranged in descending time order.

The script writes a HTML table for each record and displays the stored name, email address, comments and formatted time entry.
