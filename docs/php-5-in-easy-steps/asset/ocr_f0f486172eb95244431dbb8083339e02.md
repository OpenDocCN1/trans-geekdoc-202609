# Sending email with PHP

This chapter features a feedback form on a web page, where visitors can enter comments, which will automatically be sent to a specified email address by PHP. Examples demonstrate how to send plain text messages, HTML-formatted messages and emails with attachments. Error checking is added to prevent the submission of incomplete forms.
