# Displaying authorized users

The add_user.php interface from the previous page has been used to add a total of 10 users to the "users" database table that was created at the beginning of this chapter.

Complete details of each user can be retrieved from the users database table and displayed in a HTML table.

This script uses the SQL "select * from table-name" command to collect the entire data from the users database table.

A variable called `$list` is used to build a string containing a complete HTML table. This starts with a row of column headings for First Name, Last Name, User Name and Password. Each row of the users database table is then added to the string as in the HTML table. Once the HTML table is complete, it is written out on the page to display all the users' details.

![](img/7faa63a7fa0add8f53300594ebae949f_161_0.png)

```php
<html><head><title>Get Users</title></head>
<body>
<?php
#connect to MySQL
$conn = mysql_connect("localhost", "mike", "bingo") or die("Could not connect");

#select the specified database
$rs = mysql_select_db("my_database", $conn) or die("Could not select database");

#create the SQL query
$sql = "select * from users";

#execute the query
$rs = mysql_query( $sql, $conn) or die("Could not execute query");

#start building a HTML table for the users' details
$list = "<table border=\"1\" cellpadding=\"2\">";
$list .= "<tr><th>First Name</th>";
```

# The log-in handler

The log-in handler script checks that there are entries in both "username" and "password" fields. If so, the script looks in the "users" database table, earlier in this chapter, and seeks matches for the $username and $password values.

```php
<?php
$username = $_POST['username'];
$password = $_POST['password'];
$referer = $_SERVER['HTTP_REFERER'];

if (!$username || !$password) {
    header("Location:$referer");
    exit();
}

#connect to MySQL
$conn = @mysql_connect("localhost", "mike", "bingo") or die("Could not connect");

#select the specified database
$rs = @mysql_select_db("my_database", $conn) or die("Could not select database");

#create the SQL query
$sql="select * from users where user_name='$username'
and password = password('$password')";

#execute the query
$rs = mysql_query($sql, $conn) or die("Could not execute query");

#get number of rows that match username and password
$num = mysql_numrows($rs);

#if there is a match the log-in is authenticated
if ($num == 1) {
    $msg = "Welcome $username - your log-in succeeded!";
} else or return to the log-in page
    header("Location:$referer");
    exit();

?>A successful log-in attempt is illustrated on the next page.

<html><head><title>Log-In Authenticated</title></head>
<body><?php echo ($msg); ?></body></html>
```
