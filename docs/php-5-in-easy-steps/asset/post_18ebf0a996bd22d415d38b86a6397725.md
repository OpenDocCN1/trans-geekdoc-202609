
## Validating email address formats

PHP's `preg_match()` function can assess if an email address appears to be in the expected format for each part of the address by matching permitted patterns for.

The example on page 124 could be modified with the code below that checks for "@" and `.` symbols, and permitted characters.

```php
if (!$useraddr) {
    $smsg = "Enter email address:<br>"; $valid = false;
} else {
    $useraddr = trim($useraddr);
    #patterns for name,domain and top-level domains
    $name = "/[^\-!#\$\%'*\+\.\/0-9=?A-Z^_`{}|~-]+";
    $host = "/([0-9A-Z-])]+\.+\.+";
    $tlds = "([0-9A-Z]){2,4}$/i";
    #check validity of email format
    if (!preg_match("@".$host->."."$tlds, $useraddr)) {
        $smsg = "Email address has incorrect format!<br>";
        $valid = false;
    }
}
```

## Introducing databases

Databases are simply containers that store data in a structured manner. Every database is composed of one or more tables, which structure the data into organized rows and columns. This makes it easier to reference and manipulate the data.

Each database table column has a label to identify the data stored within the cells in that column. Each row contains an entry called a “record,” which places data in each cell along that row.

A typical database table looks like this:

| member_id | fname | lname | tel | email |
| :--- | :--- | :--- | :--- | :--- |
| 1 | John | Smith | 555-1234 | john@mail.com |
| 2 | Anne | Jones | 555-5678 | anne@mail.com |
| 3 | Mike | McGrath | 555-3456 | mike@mail.com |

## Exploring database tables

Open the MySQL monitor in a root shell window, or a Command Prompt window on Windows systems, type "show databases"; at the mysql> prompt to see all the available databases.

The MySQL installation creates two databases by default – an empty one called "test", and one called "mysql" that is used by MySQL itself. The SQL command "use database-name", selects a database to work with.

Type "use mysql"; to select the mysql database, then type the "show tables"; command to see a list of tables inside that database.

The SQL command "explain table-name" can be used to see the format of a table. This displays all the field names in the table together with details of the data they may contain. Using the mysql database, type "explain user", to see the format of the table.

## Creating a new database

The SQL command "create database-name" is used to create a new database. For example, `CREATE DATABASE test;`.

The MySQL monitor will respond with "Query OK, 1 row affected". To see the new database, type `SHOW DATABASES;`.

```
mysql> create database test;
Query OK, 1 row affected (0 sec)

mysql> show databases;
+--------------------++
| Databases           |
+--------------------++
| information_schema |
| mysql               |
| test                |
+--------------------++
```

## Creating a database table

To create a table, you must first select a database using the `USE database-name` command. For example, `USE test;`.

Then, use the `CREATE TABLE` command to define the table's columns.

```
mysql> create table students (
    id int,
    name varchar(50),
    major varchar(50)
);
Query OK, 0 row affected (0 sec)
```

To see the structure of the table, use the `DESCRIBE table-name` or `EXPLAIN table-name` command.

```
mysql> describe students;
+------+------+------+------+------+---------+
| Field | Type | Null | Key | Default | Extra |
+------+------+------+------+------+---------+
| id | int | NO | PRI | NULL | |
| name | varchar(50)| YES | | NULL | |
| major| varchar(50)| YES | | NULL | |
+------+------+------+------+------+---------+
```_

## Inserting table data

To add data to a table, use the `INSERT INTO` command. For example:

```sql
mysql> insert into students (id, name, major) values (1, 'Alice', 'Computer Science');
Query OK, 1 row affected (0 sec)

mysql> insert into students (id, name, major) values (2, 'Bob', 'Physics');
Query OK, 1 row affected (0 sec)
```

To view the data in the table, use the `SELECT` command.

```sql
mysql> select * from students;
+------+------+-----------------------------+
| id | name  | major           |
+------+------+-----------------------------+
|  1 | Alice | Computer Science |
|  2 | Bob   | Physics         |
+------+------+-----------------------------+
```

## Altering an existing table

To modify an existing table, use the `ALTER TABLE` command. For example, to add a column:

```sql
mysql> alter table students add age int;
Query OK, 0 row affected (0 sec)
```

To change a column's data type:

```sql
mysql> alter table students modify name varchar(100);
Query OK, 0 row affected (0 sec)
```

## Updating records

To update existing data, use the `UPDATE` command. Always use a `WHERE` clause to avoid updating all records.

```sql
mysql> update students set major = 'Mathematics' where id = 1;
Query OK, 1 row affected (0 sec)
```

## Deleting data

To remove specific rows from a table, use the `DELETE` command.

```sql
mysql> delete from students where id = 2;
Query OK, 1 row affected (0 sec)
```

## Deleting tables & databases

To delete an entire table, use the `DROP TABLE` command.

```sql
mysql> drop table students;
Query OK, 0 row affected (0 sec)
```

To delete an entire database, use the `DROP DATABASE` command.

```sql
mysql> drop database test;
Query OK, 0 row affected (0 sec)
```

## SQL queries

The `SELECT` statement is used to retrieve data from a database. The most basic syntax is:

```sql
SELECT column1, column2 FROM table_name;
```

You can use the `WHERE` clause to filter results:

```sql
SELECT * FROM students WHERE major = 'Physics';
```

Other clauses include `ORDER BY` for sorting, `GROUP BY` for aggregation, and `LIMIT` to restrict the number of rows returned.
