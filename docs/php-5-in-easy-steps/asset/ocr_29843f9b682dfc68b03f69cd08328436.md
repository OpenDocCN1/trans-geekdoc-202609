# Escaping characters

The "\slash character can be used to apply special significance to the character that immediately follows. It is especially useful to include quotation marks within a string of text to be written with the echo() function. As the string is itself enclosed by quotes, the php parser would be confused by additional quotes and deliver an error message. This is avoided by preceding the additional quotes by a backslash character to escape.

Additionally the newline syntax "\n" can be used to move to a new line in text areas and "\t" to cross a text area.

The following example creates a HTML text area content that includes an escaped quotation and demonstrates the newline and tab features. The quotes containing the HTML attribute values for rows and columns (cols) are also escaped.

echo("</textarea>");
