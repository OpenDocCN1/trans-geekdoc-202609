This second script reopens the file created by the first script, appends a string to the existing heading. Notice that the mode specified to the fopen() function is “w” (write) in the first script but “a” (append) in the second script.

![](bbox=[0.143, 0.436, 0.288, 0.526])

```php
$filename = "C:\Documents and Settings\\nAll Users\\Desktop\\newfile.txt";

$file = fopen($filename, "a");

$string = "I went out to Charing Cross, to see-general Harrison hanged,drawn, and quartered, which was done there, he looked as cheerful as any man could do in that condition\n\tOctober 13,1660";

fwrite($file, $string);
fclose($file);
```
