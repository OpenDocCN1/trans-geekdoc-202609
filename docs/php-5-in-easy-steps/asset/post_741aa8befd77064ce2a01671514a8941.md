# PHP functions for MySQL

The table below describes special PHP functions that are used to work with MySQL databases. These functions feature in active demonstrations inside this book.

| mysql_connect(server-name, user-name, password); | Attempts to open a connection to a MySQL server. Returns a link-identifier on success or false on failure |
| mysql_create_db(database-name, link-identifier); | Attempts to create a new database on the server associated with the specified link-identifier. Returns true on success or false on failure |
| mysql_select_db(database-name, link-identifier); | Sets the current active database on the server's associated with the specified link-identifier. Returns true on success or false on failure |
| mysql_drop_db(database-name, link-identifier); | Attempts to delete an entire database on the server with the specified link-identifier. Returns true on success or false on failure |
| mysql_fetch_array(result-resource); | Returns an array that corresponds to a database table row or returns false if there are no more rows |
| mysql_list_dbs(link-identifier); | Lists the databases available on a MySQL server |
| mysql_num_rows(result-resource); | Returns the number of rows in a result-resource |
| mysql_list_tables(database-name, link-identifier); | Lists the tables in the specified database |
| mysql_query(SQL-string, link-identifier); | Sends a query to the currently active database on the server that's associated with the specified link-identifier. Returns a result-resource answering the query on success or false on failure |

The examples and examples in this book are demonstrated with Apache 1.3.31, MySQL 4.0.18, and the final release of PHP 5.0.00 – modifications may be required for other versions. The source code of all the examples can be downloaded from this book's web at www.ineasystems.com.

# PHP in this book

This book is an introduction to the PHP 5 server-side language using examples to demonstrate many different features.

PHP can be used to create interactive dynamic websites and is rapidly gaining in popularity because it is a flexible, cross-platform technology amazingly powerful.

You may have visited some impressive websites where the URL address ends with a file extension of “.php” or “.shtml”. These are dynamic web pages served up to the web browser of the PHP scripting language on the server.

![](img/7faa63a7fa0add8f53300594ebae949f_9_0.png)

The examples given throughout this book detail PHP source code and the resultant output that appears in the web browser.

# What you need to know

PHP code exists alongside HTML code in the original PHP document on the server, so it is expected that you are familiar with the HyperText Markup Language (HTML).

Examples relating to databases comes using the Structured Query Language (SQL). Previous knowledge of SQL is helpful, but not essential, but this book includes an introduction to basic SQL commands in a chapter introducing relational databases.

> MOT TIP Code that is executed on the server, such as PHP, is called "server-side" code that is executed by the browser, such as JavaScript, is "client-side" code.

Those readers with some experience of other scripting languages, such as JavaScript, will more quickly understand some of the examples, but no previous knowledge of scripting is assumed by the book's text – you don't need to be a JavaScript guru to learn PHP!

# Required software

The book provides instructions on how to create a PHP development environment under the Windows operating system combining the free Apache web server, the free MySQL database server and the free PHP processor itself. This allows you to test PHP scripts on your own personal computer before launching them live on the global Internet, or on a local intranet.
