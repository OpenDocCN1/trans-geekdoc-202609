
# Assignment operators

The operators that are commonly used in PHP to assign values are all listed in the table below. Each of them except the simple = assign operator is a shorthand form of a longer expression, so each equivalent is also given for clarity.

| Operator | Example | Equivalent |
| --- | --- | --- |
| = | $a = $b | $a = $b |
| += (for numbers) | $a += $b | $a = $a + $b |
| .= (for strings) | $a .= $b | $a = $a . $b |
| -= | $a -= $b | $a = $a - $b |
| *= | $a *= $b | $a = $a * $b |
| /= | $a /= $b | $a = $a / $b |
| %= | $a %= $b | $a = $a % $b |

![](img/7faa63a7fa0add8f53300594ebae949f_37_0.png)

The equality operator compares values and is explained fully, with examples, on page 38.

It is important to regard the = operator as meaning "assign" rather than "equals" to avoid confusion with the == equality operator. In the example in the table, the variable named $a is assigned the value that is contained in the variable named $b, assigning this as its new value.

In the table, the += operator adds the numeric value contained in variable $a to the numeric value contained in the variable named $b and then assigns the result as the new value contained in variable $a.

The .= operator is very useful and has been used in earlier examples to add a second string to an existing string.

All the other operators in the table work in the same way as the += operator, making the arithmetical operation between the two values first, then assigning the result to the first variable.

# Comparison operators

The operators that are commonly used in PHP to compare values are listed in the table:

| Operator | Comparative Test |
| --- | --- |
| == | Equality |
| != | Inequality |
| > | Greater than |
| < | Less than |
| >= | Greater than equal to |
| <= | Less than equal to |

The equality operator == compares two operands and returns true if both are equal in value: if both are the same number then they are equal, or if both strings contain the same characters then they are equal. Boolean operands are both true, or false.

Conversely, the != operator returns true if two operands are not equal, using the same rules as the == operator.

Equality and inequality operators are useful in testing the state of variables for conditional branching.

The > operator compares two operands and will return true if the first is greater than the second.

The < operator makes the same, but returns true if the first operand is lesser than the second.

Adding the = operator after > or < makes them also return true if the two operands are exactly equal. The > operator is frequently used to test the value of a counter in a loop.

# Conditional operator

The PHP coder's favorite operator is probably the conditional operator. This first evaluates an expression for a true or false value and then executes one of two statements depending upon the result of the evaluation. The conditional operator has this syntax:

( test-expression ) ? if-true-do-this : if-false-do-this ;

This operator can be used to assign an appropriate value to a variable, as seen in some examples earlier in this chapter, or to call a function, as demonstrated in the example below.

![](img/7faa63a7fa0add8f53300594ebae949f_41_0.png)

```php
<?php
function is_odd() {
    global $num; echo("$num is an odd number<hr>");
}
function is_even() {
    global $num; echo("$num is an even number<hr>");
}
?>
```

# Conditional if statement

The “if” keyword is used to perform the basic PHP test to evaluate an expression for a boolean value. The statement following the evaluation will be executed only when the expression is true. The syntax for the “if” statement looks like this:

```php
if ( test-expression ) statement-to-execute-when-true ;

{
```

The code to be executed may contain multiple statements if they are enclosed in a pair of curly brackets to form a “statement block”.

In the example below the expression to be tested uses the modulus operator to determine if the value contained in the variable $num is exactly divisible by 2. The statement block has two statements – one to assign a string value to a variable and another to call the PHP echo function.

```html
<html>
<head><title>If Statement</title></head>
<body>
<?php
$num = 7;
if ( $num % 2 != 0 ) {

$msg = "$num is an odd number.";
echo( $msg );
}
?>
</body>
</html>
```
