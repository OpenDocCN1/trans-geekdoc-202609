# Deleting files

The PHP unlink() function permanently deletes the file specified as its argument (if it is a valid file name).

In this example it appears at the beginning of the code in a custom function that attempts to delete a file and writes a message confirming if the attempt succeeded or failed. This function is called twice later in the code to delete files.

```
<?php function try_to_delete( $file ) {
    if ( unlink( $file ) {
        echo ("$file<br>has been deleted<hr>"); 
    } else { echo ("Unable to delete $file<hr>"); };
}
```
