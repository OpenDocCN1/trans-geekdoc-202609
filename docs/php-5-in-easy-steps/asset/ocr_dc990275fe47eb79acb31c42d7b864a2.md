# Identifying browser & platform

PHP creates some useful variables, which can be seen on the phpinfo.php page that was used to setup the PHP environment at the beginning of this book; these include an environment variable called HTTP_USER_AGENT, which identifies the user's browser and operating system.

The script below uses the getenv() function to assign a value to this environment variable and then writes it out to the page. The illustrations depict the script output in Internet Explorer on Windows XP and in the Mozilla browser on Linux:

```
<html><head><title>Get browser &amp; platform</title></head><body><?php $viewer = getenv("HTTP_USER_AGENT"); echo("Browser details:<br>\$viewer"); ?></body></html>
```

![](bbox=[0.188, 0.323, 0.283, 0.435])

The details in Windows identify Internet Explorer 6.0 as a Mozilla-compatible web running on Windows XP (shown as NTS.I). In Linux the genuine Mozilla browser is correctly identified.
