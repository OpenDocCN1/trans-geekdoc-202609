# Creating an attachment form

To send an attachment with an email message, an "encype" attribute must be added to the HTML <form> element and assigned a value of "multipart/form-data".

This example builds on the previous feedback form by adding input fields for subject and file attachment. The user can push the Browse button to open a dialog box that lets them select a file to attach to the message. On submission, the values entered in the fields named "to", "from", "re", "comments" and "att" are sent to the form handler sendmixed.php, listed on page 122.

![](bbox=[0.193, 0.316, 0.283, 0.405])

This example puts the inputs inside table cells for better presentation.

```
<html><head><title>Attachment Form</title></head>
<body>
<form action="sendmixed.php" method="post"
enctype="multipart/form-data">
<table>
<tr><td>To:</td>
<tr><td><input type="text" name="to" size="40"></td></tr>
<tr><td>From:</td>
<tr><td><input type="text" name="from" size="40"></td></tr>
<tr><td>Subject:</td>
<tr><td><input type="text" name="re" size="40"></td></tr>
<tr><td>Message:</td>
<td>
<textarea cols="30" rows="5" name="comments"></textarea>
</td></tr>
<tr><td>Attachment:</td>
<tr><td><input type="file" name="att" size="26"></td></tr>
<tr><tr><td colspan="2">
<input type="submit" value="Send Form">
</td>
</tr>
</table>
</form>
</body></html>
```
