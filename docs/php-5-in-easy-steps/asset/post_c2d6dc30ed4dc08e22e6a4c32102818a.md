## Creating a guestbook database table

A guestbook application first requires a database table to store the messages that visitors will leave. This can be created directly in the MySQL monitor, or with a PHP script.

The following script uses the existing database "my_database". It creates a table called "guestbook" with fields for "id", "name", "email address", "comments" and an automatic timestamp entry of the date and time that the message was recorded.

This script needs to run just once to build the guestbook.

## Using timestamp data

The MySQL 14-digit timestamp number records the date and time, where the first four numbers are the year, then each successive pairs of numbers are the month, day number, hour, minutes and seconds.

The PHP substr() function can be used to return a part of the timestamp specified as its first argument. Its second argument states the required starting character position as an integer, and its third argument specifies the character length of substring.
