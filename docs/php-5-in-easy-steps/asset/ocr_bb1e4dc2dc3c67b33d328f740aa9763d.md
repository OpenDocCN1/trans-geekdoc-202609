# Creating an upload script

When a file is selected for upload, PHP automatically adds it to the special $_FILES environment variable. This is a three-dimensional array that is followed by two of square brackets with the syntax:

$_FILES['file-name'] ['property']

The upload file can be referenced by inserting its name within quotes in the first set of brackets. Various information about that file can be referenced by inserting properties of "name", "size", "type", "tmp-name" or "error" within quotes in the second set of brackets.

To accommodate the possibility that a file transfer may not complete successfully, the PHP die() function can be used to terminate the execution of a script and display a string specified as its argument.

The example below attempts to copy a file uploaded by the HTML form list on the previous page to Apache's htdocs directory, will display the file's details upon completion.

```
<php
if ($_FILES['file']['name'] != "") {
    copy ($_FILES['file']['tmp_name'],
    "C:/Apache/htdocs/" . $_FILES['file']['name'])
    or die("Could not copy file");
} else{die("No file specified"); };
```
