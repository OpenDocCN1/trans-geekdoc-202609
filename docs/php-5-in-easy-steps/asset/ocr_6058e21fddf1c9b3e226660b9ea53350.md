# Signing the guestbook

Once the “guestbook” database table has been created, the script on the previous page, data can be stored in it by submission from an HTML form using PHP. When first loaded in a browser the following PHP script displays a form containing fields for “name”, “email” and “comments”. Upon submission, the form will be displayed once more if any of the three fields are blank.

If the form has been completely corrected, the script will add the input entries to the corresponding columns of the guestbook database table. The page will display a confirmation and provide a hyperlink to another page where the guestbook data can be seen.
