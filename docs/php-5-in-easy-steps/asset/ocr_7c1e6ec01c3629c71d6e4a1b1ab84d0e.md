# Adding error-checking

Previous examples in this chapter have created a form and
separate form handler, but this example combines the feedback
form with the form handler script as a single web page.

Assigning the
username.
$useraddr
$comments
variables to the
input fields ensures that any
ent values are retained
when the form is submitted.

It assigns the $_SERVER['PHP_SELF'] environment variable to
the form's attribute so that the form is reloaded when the
is is submitted. The entire HTML form is contained inside a
variable $form, which is written when the page is first
loaded. The script ensures that all input fields have been completed
before it sends the email, otherwise it will write appropriate
error messages and rewrite the form, complete with any entered
values. When all input fields have entries, the variable called valid
remains true, so the email is sent and a confirmation is displayed.
