The column-round transforms the four columns like so:

```
**QR**(x₀, x₄, x₈, x₁₂)
**QR**(x₁, x₅, x₉, x₁₃)
**QR**(x₂, x₆, x₁₀, x₁₄)
**QR**(x₃, x₇, x₁₁, x₁₅)
```

The row-round transforms the rows by doing the following:

```
**QR**(x₀, x₁, x₂, x₃)
**QR**(x₅, x₆, x₇, x₄)
**QR**(x₁₀, x₁₁, x₈, x₉)
**QR**(x₁₅, x₁₂, x₁₃, x₁₄)
```

In a column-round, each **QR** takes xᵢ arguments ordered from the top to the bottom line, whereas a row-round's **QR** takes as a first argument the words on the diagonal (as in the array on the right in Figure 5-12) rather than words from the first column.
