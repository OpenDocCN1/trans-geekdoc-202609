# Textbook RSA Signatures

A textbook RSA signature is the method that signs a message, x, by directly computing y = x^d mod n, where x can be any number between 1 and n − 1. Like textbook encryption, textbook RSA signing is simple to specify and implement but insecure in the face of several attacks. One such attack involves a trivial forgery: upon noticing that 1^d mod n = 1 and (n − 1)^d mod n = n − 1, regardless of the value of the private key d, an attacker can forge signatures of 1 or n − 1 without knowing d.

More worrying is the blinding attack. For example, say you want to get a third party’s signature on some message, M, that you know they’d never knowingly sign. To launch this attack, first find some value, R, such that R·M mod n is a message that your victim would knowingly sign. Next, you’d convince them to sign that message and to show you their signature, which is equal to S = (R·M)^d mod n, or the message raised to the power d. Given that signature, you can derive the signature of M, namely, M^d, with the aid of some straightforward computations.

Because you can write S as (R·M)^d = R^{ed}M^d, and because R^{ed} = R (by definition), you have S = (R·M)^d = R M^d. To obtain the signature M^d, divide S by R as follows:

S / R = R M^d / R = M^d

This is often a practical and powerful attack.

# The PSS Signature Standard

The RSA Probabilistic Signature Scheme (PSS) is to RSA signatures what OAEP is to RSA encryption. It was designed to make message signing more secure, thanks to the addition of padding data.
