

# DDoS 攻击始于黑客入侵数千台联网计算机

DDoS 攻击始于黑客入侵数千台联网计算机并在其上安装旨在向目标发送“SYN”数据包的命令和控制恶意软件。[图 2.9](#c02.xhtml#c2-fig-0009) 的右侧将恶意软件表示为带刺斑点。一旦足够多的被攻陷机器被组装起来，黑客就会自动化与命令和控制恶意软件的通信以开始发送 SYN 数据包。目标接收到 SYN 并回复 SYN ACK，然后等待来自客户端的 ACK，但没有任何 ACK 到达。最终会话超时，但在此之前，目标服务器的所有网络资源都已被无效连接的数据包占用。互联网上任何试图与服务器通信的其他机器都会被恶意软件发起的连接洪流有效地阻断。

DDoS 攻击用于关闭竞争对手网站的效用显而易见，国家行为体也曾使用 DDoS 来削弱或羞辱其对手。从这个意义上说，国家行为体的网络犯罪活动现在是竞争对手威胁的一种特例。尽管“竞争对手”和“国家行为体”都在 STIX 威胁行为者类型列表中，但在知识产权盗窃的背景下，区分两者变得越来越困难。也就是说，国家行为体会入侵服务于其他国家的组织，寻找能够提升自身全球经济形象的信息。他们不仅针对政府机构，还经常入侵本国企业的国外竞争对手。在这些攻击中被盗取的知识产权和商业秘密会被移交给本国企业以供利用和开发。起初，这种活动并未被广泛报道，部分原因是攻击目标不愿承认自身存在漏洞（Epstein 和 Elgin [2008](#c02.xhtml#c2-bib-0007））。但随着国家行为体攻击的复杂性不断提高，对目标全球经济地位造成损害的概率也随之增加（Perlroth [2021](#c02.xhtml#c2-bib-0028)）。

2010 年，Google 大胆宣布自己曾是此类攻击的目标。黑客在其网络中潜伏数月，收集并存储了算法及其他知识产权的数据，随后将大批数据从 Google 网络中窃取。2009 年，Google 安装了新的网络安全软件，该活动随即变得可见。尽管如此，消除威胁仍花费了数月时间。那一年，“高级持续性威胁”（APT）一词被创造出来，用于描述系统性的持续性针对性间谍活动，随后该术语被用于标识此类行为者（例如 APT1）（Mandiant [2013](#c02.xhtml#c2-bib-0011)）。

# 典型的竞争对手攻击将聚焦于客户数据和/或知识产权

典型的竞争对手攻击将聚焦于通常存储在数据库管理系统（DBMS）中的客户数据和/或知识产权。最早且至今仍相当常见的此类攻击之一，利用了 Web 服务器处理一种名为结构化查询语言（SQL）的编程语言时的漏洞。该攻击被称为“SQL 注入”，因为威胁行为者能够将 SQL 命令“注入”到 Web 服务器中。

网站“表单”旨在收集数据并将其存入数据库。它会为用户呈现一个空白的“表单字段”供其输入，然后获取输入内容并将其存储在计算机内存中，接着将内存字段发送到数据库进行存储。[图 2.10](#c02.xhtml#c2-fig-0010) 中的图表以过度简化的方式说明了这一简单概念。用户在网站登录表单中输入姓名和密码，计算机将这些字段发送到数据库，以便数据库能够在浏览器中收集并显示用户的数据。[图 2.10](#c02.xhtml#c2-fig-0010) 中的前两个登录和密码字段显示了用户通常会输入的数据。右侧的两个字段显示了黑客可能尝试输入的内容，以查看 Web 服务器是否会在不检查字段是否不含计算机代码的情况下，直接将字段内容传递给数据库。如果是，黑客就可以直接从 DBMS 获取数据，而无需登录。

尽管知识产权通常无法从面向公众的 Web 服务器获取，但它通常存储在可从内部 Web 服务器访问的 DBMS 中。如果竞争对手能通过其他方式访问内部 Web 服务器，SQL 注入攻击仍然可能奏效。[图 2.11](#c02.xhtml#c2-fig-0011) 显示了黑客尝试 SQL 注入攻击的两条不同攻击路径。第一条路径针对面向公众的（即外部）Web 服务器。构成攻击的一系列事件用带编号的圆圈标记，数据用实线表示。第二条路径针对内部 Web 服务器。构成攻击的一系列事件用带编号的三角形标记，数据用虚线表示。

黑客位于 [图 2.11](#c02.xhtml#c2-fig-0011) 的左下角。内部攻击中使用的统一资源定位符（URL）为：`">[https://www.acme.com/innocuousurl?field=“select ALL from table”](https://www.acme.com/innocuousurl?field=%E2%80%9CselectALLfromtable%E2%80%9D)`。浏览器连接到 `www.acme.com` 网站，该网站的代码将该代码纳入其数据查询中，导致 DBMS 返回比正常情况下更多的数据。

在外部攻击中，初始访问始于网络钓鱼，该词发音类似于“fishing”，之所以这样称呼，是因为它使用诱饵来引诱目标。“ph”这一拼写是对黑客早期时代的回溯，当时计算机滥用主要包括电话诈骗。网络钓鱼攻击的诱饵是一个旨在对受害者显得有趣或有用的网站链接。在第 2 步中，用户点击链接，恶意 C&C 软件会下载到用户易受攻击的桌面上。此恶意软件允许黑客以类似于 Web 服务器上 log4j 攻击第 1 阶段的方式，在用户的家用桌面上输入命令，即让桌面上的恶意软件向黑客服务器查询恶意命令。黑客利用这种交互式 C&C 功能记录用户的按键并读取处理器内存，以获取用户在内部 Web 服务器上的凭据。随后，黑客利用家庭用户访问其雇主（即威胁行为者的真正目标）的虚拟专用网络（VPN）进行搭便车。威胁行为者在内部网络上冒充该用户（第 4 步），并对内部网站发起 SQL 注入攻击（第 5 步）以访问商业秘密和知识产权。对于企业而言，这看起来像是内部威胁，因为被盗数据被窃取到家庭用户的桌面上。随后，黑客将使用 C&C 功能从用户的家用桌面检索数据。

SQL 注入看似是一种可以轻易避免的简单编程错误。然而，进入 Web 应用程序设计领域的新程序员通常会犯此错误。只有具备足够知识、能够定期扫描代码以发现此类错误的软件开发团队，才能完全避免此类问题。开放 Web 应用程序安全项目（OWASP）和系统管理员、审计、网络与安全（SANS）是两个维护程序员和管理员（admins）最常犯错误列表的组织，这些错误会使系统面临黑客攻击的风险。这种 SQL 注入攻击的某种形式已在两个列表中存在数十年（OWASP [2021](#c02.xhtml#c2-bib-0027)）。
