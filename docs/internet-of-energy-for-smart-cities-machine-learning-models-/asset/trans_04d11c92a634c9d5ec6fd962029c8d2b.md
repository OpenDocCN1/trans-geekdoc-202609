智慧城市涉及大数据和云计算技术，以便将嵌入到各种智能应用中的传感器设备连接起来。除此之外，其他设备也连接到云计算基础设施，以交换信息并生成大量结构化数据。这些未经请求的大量数据被收集并存储在云中。因此，可以使用带有并行算法的编程模型来处理大型数据集，用于数据分析，从存储的数据中获取价值。

为了处理这些海量数据，机器学习（ML）方法可以是一个不错的选择，因为 ML 能够可靠地处理大量数据且不会疲劳 [1, 19]。与这些任务相关的主要挑战需要从数据中进行高效且相关的特征提取。所有任务的数据激增及其类型和数量并不相同，因此 ML 的实现需要针对不同类型的数据部署专用算法。

大数据可能包含标记数据、未标记数据或两者的混合。根据数据的类型和可用性，网络研究人员必须使用特定的学习模型训练算法 [2]。在受监督的学习方式中，算法使用标记数据进行学习 [4, 27]。更具体地说，在受监督学习模型中，输入和输出都已提供。基于标记数据，算法预测未来的数据。相比之下，无监督模型 [15] 是指算法仅提供输入数据，而没有相应的输出数据作为训练数据集。无监督算法能够自由地运作，以便从数据中学到更多并探索发现，因为没有输出值或教师。另一方面，半监督模型使用标记数据和未标记数据的组合进行学习。通常，这种组合包含少量标记数据和大量未标记数据。

## 7.2 机器学习框架

关于机器学习（ML）方法在智慧城市管理中的运行原理可能会产生疑问 [6]。良好理解 ML 技术对于高效设计和实现智慧城市是必需的。本节描述了通用的 ML 方法和不同的 ML 算法及其在智慧城市设计中的应用。

### 7.2.1 机器学习方法

ML 算法中最简单的方法之一是使用标记或未标记的数据集对其进行训练以生成模型。将新的输入数据引入 ML 算法，算法根据模型进行预测。这些方法会进行准确性评估，当系统达到可接受的准确性水平时，就被视为成功模型 [29]。另一方面，如果系统未获得所需的响应，则通过不断输入更多数据反复训练，直到系统的响应达到满意水平。图 7.3 展示了 ML 技术的一个简单过程。但是，生成成功模型涉及各种因素和步骤。

### 7.2.2 机器学习模型

为了独立处理大量传感器数据，机器需要通过数学和统计方法，从各种标记或未标记以及不同结构的数据中学习。这些 ML 模型由四个独立的技术家族组成，将简要讨论如下。

- 受监督学习
- 无监督学习
- 半监督学习
- 强化学习

### 7.2.2.1 受监督学习模型

受监督模型的关键思想是，让一位主管像照顾者/老师教孩子识别颜色、水果和数字一样来训练机器。在这种方法中，老师检查孩子的每一步，孩子必须从他/她产生的结果中学习 [14]。

在受监督的 ML 模型中，有两个变量，即 x 和 y。假设 x 为输入，y 为输出，我们可以写出一个函数 y = f(x)。目标是进行映射，使得每当有新的输入数据 x 时，就能预测 y 的输出。

也就是说，在受监督的 ML 方法中，训练数据集的每个实例由不同的输入属性和一个提取的输出组成。训练数据集的输入属性可以是任何类型的数据集。例如，它可以是图像的一个像素、数据库的值，甚至可以是频率直方图。对于每个输入实例，都关联一个提取的输出级别。该值可以是离散的（表示一个类别），也可以是实连续值。无论哪种情况，算法都学习生成提取输出的输入模式。现在，一旦算法训练完成，就可以用来预测从未见过的输入的正确输出。

受监督学习应用的一些示例如下：

- **语音自动化**：语音自动化软件（如“Cortana”）使用语音进行训练。训练完成后，它开始基于训练工作。这是受监督学习的一个应用。如果有人说“嘿 Google，给 Rocky 打电话”，它会自动通过检测语音笔记从手机中给 Rocky 拨打电话。
- **天气预报**：考虑一些先验知识，例如当天气晴朗时温度较高，当天气多云时湿度较高。它可以在给定时间内预测参数。
- **生物特征考勤**：在用几个生物特征识别输入对机器进行训练后，训练完成后，机器可以识别任何特定人员的未来输入。
- **银行业**：在银行业，受监督学习用于通过构建机器学习模型来查找有故障的属性（例如提供逾期和非逾期客户的数据），以预测信用卡持卡人的信用度。
- **医疗行业**：在医疗中心，它通过提供患者治疗管理和再入院数据来构建回归模型，用于预测患者再入院率，以显示与入院最相关的变量。
- **零售店**：在零售业，它用于分析客户一起购买的产品。它通过构建受监督模型来识别事务数据中的频繁项集和关联规则。
