留一法交叉验证：它是交叉验证的一种特殊情况，其中分区数（k）等于数据集的大小（N），即数据集中的实例数或样本数。因此，验证数据集在学习模型中恰好包含一个样本，其余所有样本在每次迭代中作为训练数据集，类似于统计学中的删一法估计。验证集上的误差不仅用于决定何时停止训练并避免过拟合，还用于确定模型的泛化性能。

## 8.5.3 模型性能评估指标

各机器学习算法使用的指标各不相同。下文将讨论分类和回归算法中最常用的指标。

### 8.5.3.1 分类指标

模型性能可通过不同指标进行评估。在分类算法中，表 8.1 报告的四种错误类型主要用于评估指标。

Table 8.1

不同类型的错误

| 真实标签 | 预测标签 | 错误类型 |
| :--- | :--- | :--- |
| 是 | 是 | 真阳性 (TP) |
| 否 | 否 | 真阴性 (TN) |
| 否 | 是 | 假阳性 (FP) |
| 是 | 否 | 假阴性 (FN) |

准确率被广泛用作评估指标，通过将正确预测数除以预测总数来计算 [21]。在下文的准确率和误差率公式中，TP、TN、FN 和 FP 分别表示各类别的预测总和。

```
Accuracy rate = \frac{\text{Number of correct predictions}}{\text{Total predictions}} = \frac{TP + TN}{TP + TN + FP + FN} \quad (8.1)
```

```
Error rate = \frac{\text{Number of incorrect predictions}}{\text{Total predictions}} = \frac{FN + FP}{TP + TN + FP + FN} = 1 - Accuracy rate
```

除了准确率和误差率指标外，在涉及类别不平衡的预测时，精确率和召回率指标也被广泛使用。精确率指标衡量预测的精确度，因为它考虑了被预测为正例的输出百分比，如下所示：

```
Precision = \frac{TP}{TP + FP} = \frac{\text{Positive samples correctly predicted}}{\text{All samples predicted as Positive}} \quad (8.2)
```

另一方面，召回率指标衡量预测的完整性，因为它考虑模型正确识别的预测正例输出占所有真实正例的百分比，定义如下：

```
Recall = \frac{TP}{TP + FN} = \frac{\text{Positive samples correctly predicted}}{\text{All samples with true label Positive}} \quad (8.3)
```

此外，F-测度是另一种指标，它是精确率和召回率指标的组合。根据精确率和召回率值在公式中的权重，存在不同类型的 F-测度。最常见的如下：

- $F1 测度$：精确率和召回率值具有相同的加权平均值，如下方公式所示：
- $F2 测度$：召回率的权重高于精确率的权重
- $F0.5 测度$：精确率的权重高于召回率的权重

$F1 = 2 \times \frac{\text{精确率} \times \text{召回率}}{\text{精确率} + \text{召回率}}$ (8.4)

该值范围为 0 到 1，数值越高表示分类性能越好 [22]。

混淆矩阵是一种用于汇总误分类错误的表格。在测试数据集的真实值已知时，它用于表示分类器的性能 [23]。它相对容易理解，但其术语有时在实现时可能比较复杂。基于实际值和预测值，四种不同的可能性说明如下：

- 真阳性 (TP)：该单元格包含被正确预测为正例的样本。
- 真阴性 (TN)：该单元格包含被正确预测为负例的样本。
- 假阳性 (FP)：该单元格包含被错误预测为正例的样本。
- 假阴性 (FN)：该单元格包含被错误预测为负例的样本。

每个单元格包含每种错误类型的样本计数或百分比，如表 8.2 所示。

Table 8.2

**混淆矩阵**

| | 预测类别标签 | |
|---|---|---|
| | 是 | 否 |
| 真实类别标签 是 | 真阳性 (TP) | 假阴性 (FN) |
| 否 | 假阳性 (FP) | 真阴性 (TN) |

在混淆矩阵中，真阳性和真阴性值（即预测输出正确的输入）位于对角线上。另一方面，非对角线值与误分类输出（即预测输出错误的输入）相关。因此，对角线值的总和越高或非对角线值的总和越小，表示分类器学习模型的整体性能越好。在混淆矩阵中，指标定义如下：

- _准确率_：对角线值的总和除以预测总数。
- _误差率_：同样，非对角线值的总和除以预测总数。

混淆矩阵提供了关于分类器性能的非常重要的信息，通过观察它可以轻松理解模型正在犯哪些类型的误分类。例如，当模型在分类真实负例或正例标签时存在问题。总之，混淆矩阵在一个表格中汇总了各种分类错误类型，其中对角线值和非对角线值用于计算不同的性能指标并评估分类器在学习模型中的整体性能。此外，它还表明哪种类型的误分类对分类模型来说最成问题。

### 8.5.3.2 回归指标

回归评估指标与分类指标略有不同，因为回归学习输出给定范围内的连续值。用于评估回归性能的不同指标包括均方误差 (MSE)、根均方误差 (RMSE)、平均绝对误差 (MAE)、平均绝对百分比误差 (MAPE) 以及 _R_<sup>2</sup> 或决定系数。

均方误差 (MSE) 广泛用于评估回归学习结果，因为它可微分且更易于优化。它定义为实际值与预测值之间平方差的平均值，如下方公式所示，其中 n 为预测总数。由于差值的平方，它甚至会考虑微小的错误，并会因为模型高估学习性能有多差而对其进行惩罚。

\( MSE = \frac{1}{n} \sum (y - \hat{y})^2 \quad \text{(8.5)} \)

根均方误差 (RMSE) 是评估回归性能最广泛使用的指标。它是实际值与预测值之间平方差平均值的平方根，如下方公式所示。它是最受青睐的指标，因为它对大错误施以严厉惩罚，大错误通常会严重损害模型性能。因此，当大错误被严肃考虑且不希望发生时，使用 RMSE。

\( RMSE = \sqrt{\frac{1}{n} \sum (y - \hat{y})^2} \quad \text{(8.6)} \)

平均绝对误差 (MAE) 是实际值与预测值之间绝对差的平均值，如下方公式所示。与 MSE 不同，该指标对异常值和高误差值具有鲁棒性，不会对错误进行极端惩罚。由于 MAE 是线性得分，意味着所有差异在指标中具有相同的权重，因此当异常值至关重要时，它不适用于此类应用。

\( MAE = \frac{1}{n} \sum |y - \hat{y}| \quad \text{(8.7)} \)
