## 图 7.5 简单线性回归模型

**线性回归：** 线性回归是一种统计模型，通过考察两个因素来预测自变量和因变量之间的关系。第一个因素是考察哪些变量（特别是哪些变量）是结果变量的显著预测因子；第二个重要判断是回归线的显著性如何，以便以最高可能的精度进行预测。

由于线性回归是在变量之间绘制一条直线，因此含有一个因变量和一个自变量的简单线性回归方程的最简形式表示为：

```
y = m * x + c
```

- y 是因变量
- x 是自变量
- m 是直线的斜率；m = (y2-y1)/(x2-x1)
- c 是直线的截距

假设我们要根据降雨量来绘制作物产量。由于无法改变降雨量，因此将其视为自变量 x。另一方面，作物生长量取决于降雨量，故作物产量被视为因变量 y。我们可以据此在数据中间绘制一条直线，找到如图 7.5 所示的回归线，从而能够根据降雨量轻松预测作物产量。

如果存在多个自变量，则多元线性回归的方程变为：

```
y = m_1 * x_1 + m_2 * x_2 + .... + m_n * x_n + c
```

![](img/617e854c2620a5a4bed0116cef33155a_201_0.png)

其中，X1、X2、X3 是自变量，m1、m2、m3 是它们各自对应的斜率，且只有一个截距 c。

线性回归在机器学习中的一些应用如下：

- 通过线性回归算法计算 GDP 来预测国家的经济增长。
- 该方法可用于预测产品未来的价格。
- 通过评估以前比赛的表现可以预测球员的得分。

## 7.2.2.2 无监督学习模型

无监督学习模型源自有监督学习，没有监督者来训练模型，也没有预定义的正确答案。已经开发了各种算法来获取相似类型的数据，并展示数据中有趣的结构。从数学上讲，无监督机器学习仅涉及输入数据 x，没有相应的输出变量。无监督机器学习的目标是对数据中的底层结构或分布进行建模，以便了解更多数据 [27]。

在无监督学习方法中，训练数据集的数据实例没有预期输出；无监督算法根据输入数据的独特特征检测模式。应用无监督学习的机器学习任务示例是聚类。在此任务中，相似的数据实例被分组在一起以识别数据聚类。

图 7.10 显示了无监督学习模型。可以观察到，最初将各种水果视为输入。让我们假设 x 为水果集合，模型将使用无监督学习算法根据其品种创建聚类。它将相似水果分组以形成一个聚类。
