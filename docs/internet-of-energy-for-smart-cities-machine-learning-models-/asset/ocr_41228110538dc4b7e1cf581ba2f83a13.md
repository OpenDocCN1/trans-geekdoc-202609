# 7.2.2.2 Unsupervised Learning Models

The unsupervised learning models derived from supervised learning with no supervisor to train the model and also there is no predefined correct answer. Various algorithms have been developed to obtain similar types of data and to present the interesting structure in the data. Mathematically, unsupervised machine learning only involves input data x and no corresponding output variable. The goal of unsupervised machine learning is to model the underlining structure or distribution in data in order to learn more about data [27].

In the unsupervised learning approach, data instant of a training data set does not have expected output; the unsupervised algorithm detects pattern based on the unique characteristic of input data. An example of a machine learning task that applies unsupervised learning is clustering. In this task, similar data instances are group together to identify clusters of data.
