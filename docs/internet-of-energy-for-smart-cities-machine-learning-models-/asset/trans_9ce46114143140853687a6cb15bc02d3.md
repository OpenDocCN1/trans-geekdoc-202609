无监督机器学习的应用如下：

- 银行业：在此场景中，无监督机器学习用于基于行为特征对客户进行细分，通过聚类开发出多个细分群体。

- 医疗保健行业：在医疗保健行业，无监督机器学习可用于使用正常或异常图像对MRI数据进行分类。系统利用无监督学习技术构建模型，从图像的不同特征中学习以识别模式。

- 零售行业：无监督机器学习方法可用于零售行业，帮助客户根据客户过去的购买记录找到合适的产品。系统通过基于过去购买记录构建协同过滤模型来实现此功能。

### K-Means算法

K-means执行将对象划分为簇的操作，簇内对象相互相似，与属于另一个簇的对象不相似。如果我们有一些未标记的数据，可以使用此算法对其进行聚类。术语K是一个数字，因此，我们需要告诉系统需要多少个簇来执行操作。

为了深入了解此算法，让我们考虑一场板球比赛的例子。击球手跑得多但获得分数少（击中少个球门柱）。相比之下，投球手跑得少但拿到的击球门数最多。在图7.11(a)中，我们绘制了跑分与击球门的对比图。图7.11(b)显示了图7.11(a)的聚类模型。

第一步，我们需要选择希望在数据集中识别的簇的数量。这就是K-means聚类中的“K”。在此示例中，假设K = 2，并在图表上选取两个随机点（图7.12(a)）。然后，我们确定每个数据点与每个随机分配点之间的距离。距离较近的点被分配到图7.12(b)中表示的一种数据类型。

下一步是确定这两个簇的实际中心点的实际中心点。此过程持续进行，直到质心的重新定位固定如图7.12(c)所示，最终簇如图7.12(d)所示。发现算法已收敛。

假设我们有输入(x1, x2, x3,...)并将其分割为k个簇。质心的重新定位过程可分为以下四个步骤：

- 步骤1：第一步是选取k个随机点作为簇中心，称为质心。假设这些点为c1, c2, c3,...,ck，我们可以表示为

C = c1, c2, c3, ..., ck (7.3)

其中，C是所有质心的集合。

- 步骤2：在此步骤中，我们将每个数据点分配到最近的中心点，这是通过计算欧几里得距离完成的

arg min_{c_i \in C} dist (c_i, x)^2 (7.4)

- 步骤3：在此步骤中，通过取分配到该簇的所有点的平均值来找到新的质心。

c_i = \frac{1}{|S_i|} \sum_{x_i \in S_i} x_i (7.5)

其中，S_i是分配到第i个簇的所有点的集合。

- 步骤4：在此步骤中，我们重复步骤2和步骤3，直到没有任何簇分配发生变化，即直到簇稳定为止，我们重复该算法。

K-Means算法的实际应用包括

- 根据学生的成绩/分数对学生进行分组
- 将搜索结果分组形成簇
- 无线传感器网络，其中聚类算法在寻找收集各自簇所有数据的簇头方面发挥着重要作用。

### 层次聚类算法

将对象划分为簇的方法，簇内对象相互相似，与属于另一个簇的对象不相似。层次聚类是根据某些相似度度量将数据分离到不同组中的过程。层次聚类有两种类型：一种是“聚合型”，它将事物聚合在一起；另一种是“分裂型”，它将事物分开。聚合型聚类采用自底向上的方法，而分裂型聚类采用自顶向下的方法（图7.13）。

假设我们有一些点在平面上如图7.14(a)所示，我们试图找到两个数据点之间的最小距离以形成簇。找到两点之间的最小距离后，我们需要形成多点簇。这由一种称为树状图（Dendrogram）的树状结构表示。对于图7.14(a)所示的三组簇，相应的树状图显示在图7.14(b)中。然后，对于两个最近的点，我们再次创建一个树状图。当形成一个簇时，过程结束。

层次聚类的一些应用如下：

- 广泛用于超市的客户细分。
- 它还利用社交网络分析来排序客户更喜欢或不喜欢哪些商品。
- 对于城市规划，该算法在将不同区域（如工业区、商业区、住宅区）相互分隔方面发挥着至关重要的作用。

### 7.2.2.3 半监督学习模型

半监督学习模型是监督学习模型和无监督学习模型的组合。然而，在半监督学习模型中，数据集分为两部分：标记部分和未标记部分。当标记数据或收集带标签的数据非常困难或昂贵时，常使用此技术。带标签的数据部分可能也质量较低[25]。例如，如果我们进行癌症医学影像，让医生在数据集中保持标记工作成本很高，而且这些医生还需要处理更紧急的工作。医生已经标记了数据集的一部分，并留下另一部分未标记。最后，研究表明，即使数据集只部分标记，这种机器学习技术也能以良好的精度工作。此外，未标记的数据易于获取，并且大量可用。
