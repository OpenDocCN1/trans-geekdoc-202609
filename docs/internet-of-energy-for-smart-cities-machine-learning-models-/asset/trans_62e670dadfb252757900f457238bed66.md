
要么计算或估算光伏板在白天接收到的太阳辐射，要么，对于带有太阳跟踪系统的面板，计算面板倾角以尽可能接收到最高水平的辐射。研究表明，即使对于固定光伏板，为一年中不同周期选择最佳倾角也能带来能量产出的重要增加 [30]。

互联网上有多种可用的太阳位置计算器，最常用的是 SunCalc.org (www.suncalc.org)、NOAA Solar Position Calculator (https://www.esrl.noaa.gov/gmd/grad/solcalc)、SunCalc.net (www.suncalc.net)、SunEarthTools (www.sunearthtools.com)。除了知道太阳位置，了解日出和日落时间也很重要。有了这些信息，我们可以选择与太阳能转换相关的数据时间区间，或者选择光伏系统所用能量来自储能电池或电网的时间段。

https://suncalc.org/#/lat,lon,zoom/date/time/objectlevel/maptype

其中 lat = 纬度，lon = 经度，zoom = 地图缩放级别，date = 日期，time = 时间，objectlevel = 用于阴影计算的对象高度，maptype = 地图类型（0 = OpenStreet Map，1 = Esri-Satellite，2 = Esri-Topo，3 = Esri-Street）。

## 9.6 光伏板运行监测中的机器学习技术

能源发电系统中可用数据的增加使我们能够使用机器学习技术，在数据中发现虽然自然但隐藏的模式，这些模式可以更好地洞察系统和流程，帮助人们做出更好的决策和预测。

机器学习算法的使用基于数据的可用性，通过使用不同的计算方法，我们可以直接从数据中了解关于过程的相关信息。不需要拥有数学模型或一组方程来提取信息。模型是通过学习获得的，随后用于对新进入的数据进行预测。

基于不同的学习风格，机器学习算法可分为四个不同的类别：

监督学习：该方法基于一个训练过程以获得模型。训练过程使用包含正确和错误预测的数据集。当这些预测错误时，会对模型进行修正。训练是一个迭代过程，当模型使用训练数据达到预期精度水平时结束。

无监督学习：在这种方法中，数据集未贴标签，因此，模型是通过首先识别输入数据中的现有模式或结构来获得的。这可以通过减少冗余、按相似性组织数据并提取非可见规则来实现。

半监督学习：在这种方法中，模型基于同时包含标记和未标记数据的数据集获得。因此，算法必须基于正确和错误的预测来修正模型，还必须在标记和未标记数据中识别结构。

强化学习：在这种学习类型中，机器被训练以做出特定决策。训练基于试错过程，数据会不断馈送到模型中。机器从过去的数据集（经验）中学习，并添加用于做出最佳预测以采取下一个最佳决策的知识。

机器学习技术的另一种分类可以根据解决问题所使用的方法获得。
