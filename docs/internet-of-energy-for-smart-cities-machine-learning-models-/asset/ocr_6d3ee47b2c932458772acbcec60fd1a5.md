# 6.3.2 FOG COMPUTING

Generally, Fog Computing concept grows with spreading of IoT applications, it differs from cloud computing by adding a new concept called an edge computing which are majorly devices at an edge between supplier and customer gateways. These edge devices represent the new layer added to bridge terminals with the system computation core as shown in Figure 6.9. Simply, the Fog computing never eliminates the cloud computing but represent an evolutionary version that is complement cloud computing by adding edge node. As growing of Fog computing and its applications in developing systems, IoE also is involved in this development and various proposals and demonstrations are introduced as discussed in previous sections.
