
确定性不确定性集。这些算法不需要不确定变量的明确概率分布，且明确定义不确定性集的假设确保了模型在多项式时间内求解。如前文小节所述，强健优化不需要数据测量，并且与超前预测配合使用效果良好。但是必须指出，强健优化本质上是一种最坏情况优化问题，这意味着它针对不确定性的最坏实现确定了目标函数的最优值。这会导致过于悲观或保守的解。

因此，根据面向实时算法的第一组解题技术，两阶段强健优化模型非常适合能源系统运行的在线优化。虽然第一阶段针对不确定变量的最坏情况实现来最大化/最小化目标函数，但第二阶段是一种纠正决策，一旦获得不确定变量的精确信息，就会在最优解中进行实时更新。两阶段强健优化模型可在数学上表示为以下 min-max-min 问题 [29]。

```
min f(x) + max min d(y) + e(u)                                         (1.4)
     s.t. A(x) ≥ b                                                       (1.5)
     F(x) + G(y) ≤ v                                                     (1.6)
H(u,x) + I(y) + J(u) = w; u ∈ U                                          (1.7)
```

这里，第一个 min 是第一阶段问题，通过确定“确定”决策变量 x 的最优值来最小化目标 f(x)。这意味着该阶段的最优决策是即时决策，因为变量 x 不受不确定性影响。因此，这些变量的最优值在第一阶段确定，并在剩余优化过程中保持固定。max 指的是不确定性函数 e(u) 的最大化，表示不确定变量 u 的最坏情况实现。一旦最坏情况不确定性实现，第二个 min 函数通过计算最优决策变量 y 来最小化第二阶段目标函数 d(y)。由于变量 y 在最坏情况不确定性发生后进行优化，这些被称为等待观察决策。

在强健优化问题中，不确定变量由不确定性集或预算表征，这些集由上下限明确定义。不确定变量 u 的不确定性预算 U 是预测数据中不确定性的度量。这意味着，拥有更宽的不确定性集表明模型能够应对更高水平的不确定性。然而，这也会导致更高的成本和更保守的解。因此，预算的选择必须在模型的保守性和鲁棒性之间仔细权衡。更常用的多面体不确定性集由以下表达式定义 [42]。

$U = \{u^t \in \mathbf{IR}^n : u^{t,min} \le u^t \le u^{t,max}, \forall t \sum_{t \in T} u^t \mu^l \le \frac{\sum_{t \in T} u^t}{\sum_{t \in T} u^{t,f}} \le \mu^u \} (1.8)$

其中，$u^{t,min}$ 和 $u^{t,max}$ 分别是不确定变量 $u$ 在时间 $t$ 的最小值和最大值。此外，$u^{f,t}$ 是 $u$ 在时间 $t$ 的预测值，$\mu^l$ 和 $\mu^u$ 是相应不确定性集的下限和上限。

两阶段强健优化问题的求解需要分解技术，这些技术在文献中已被广泛使用。这些分解方法（如 Bender’s 分解和列与约束生成法）具有计算效率高、求解时间短的优点。值得注意的是，计算时间随着不确定性水平的增加并不会显著增加。这些特性非常适合能源系统所需的在线优化。分解算法将强健优化模型分为主问题和从问题，并迭代求解。因此，第一阶段解针对第二阶段中不确定性的最坏情况实现进行优化。然而，在实践中，最坏情况不确定性很少出现。因此，对于在线算法，在不确定变量实际发生后，会对第二阶段变量进行*实时调整*。

### 1.3.4.2 带纠正决策的随机规划

随机规划是运筹学的一个领域，假设可以为优化模型中的不确定变量估计概率分布。然后使用这些概率分布函数生成随机场景出现，并优化目标的期望值。虽然强健优化处理硬约束满足问题，但随机规划通常用于软约束问题，预计平均能产生良好结果。带纠正决策的随机规划本质上是一个两阶段问题，在没有不确定性的情况下进行第一阶段优化，并将第二阶段决策推迟到不确定性实际存在或不确定变量有精确信息可用的后续时间。

让我们考虑一种能源系统运行，其中某些信息可提前获得，而不确定性则在接近实时时显现。可为该运行制定随机优化模型，其中第一阶段问题是 $min f(x) : x \in F$，第二阶段问题是 $min g(y) : y \in G(x, u)$。这里，$x$ 是第一阶段的确定性决策变量。它是确定已知的，因此，第一阶段决策可以在不确定性实际发生之前计算。因此，这些变量被称为“即时”决策变量。在实时运行期间发生不确定性 $u$ 时，将进行第二阶段优化，确定不确定性场景，每个场景关联一个出现概率 $\lambda$。该阶段的决策变量 $y$ 相应地被称为纠正或“等待观察”决策，并更新第一阶段决策。因此，两阶段随机规划模型可在数学上表示如下 [30]。

```
min \{f(x) + \mathbb{E}[H(x, u)]\}
```

这里，第二阶段优化决策（也称为纠正决策）由 H(x, u) 表示。第二阶段优化在一段时间内的期望值由 \mathbb{E}[H(x, u)] 给出。为便于计算，随机模型重新表述为确定性等效模型。然而，这种重新表述关联于不确定性场景出现次数有限的假设。每个不确定性场景都关联一个出现概率。因此，第二阶段的期望值可表示如下 [39]。

```
\mathbb{E}[H(x, u)] = \sum_{n=1}^N \lambda_n H(x, u_n)
```

带纠正决策的随机规划模型的一般求解过程包括基于不确定变量的概率分布函数确定不确定性场景。从微电网角度来看，常见的不确定变量是光伏输出、风力发电和电气负载。观察到这三个不确定变量分别服从 Beta、Weibull 和 Normal 分布。场景使用蒙特卡洛模拟等采样技术生成。然而，为每个样本执行运算的高计算负担使该模型不适合在线优化。因此，前向约简和后向约简等场景约简技术被发现能有效将大量不确定性场景约简为一个小型但具有代表性的集合。因此，得到一个等效确定性模型，然后使用经典求解技术求解。两阶段随机规划框架的确定性等效模型可表示如下。

```
min_{x,y_n} \{f(x) + \sum_{n=1}^N \lambda_n g(y_n)\}; x \in F; y_n \in G(x, u_n)
```

这里，N 是不确定场景的数量，每个场景关联一个出现概率 \lambda_n。
