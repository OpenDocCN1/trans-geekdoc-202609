

大学/学院具有三个权限级别，如下：

- Super-admin：有权创建或删除用户和位置，
- Admins：可以通过向学生（或组织中的员工）授予和撤销访问权限，来管理分配位置的权限。
- Students（或组织中的员工）：只能访问管理员允许的他/她有权访问的位置的设备。

高级别拥有低级别的所有权限，但反之则不然。用户可以查看允许位置的设备的*实时*状态。这就是如何在大型组织（此处为大学/学院）中进行严格监控和管理权限的方法，也可以避免任何不当行为。最重要的是，这将有效地最大限度地降低功耗，这种功耗通常是由于设备一直开启直到有人发现并将其关闭而产生的。当某人希望在前往该位置前几分钟远程开启空调等设备时，这也可能很有帮助，他/她可以从所在的位置远程访问。

## 10.2 相关工作

无线家居自动化系统（WHAS）涉及通过物联网在互联网上完成的各种系统之间的通信、控制和信息处理。要通过计算机或移动设备远程控制基本家用电器，使用 ZigBee 的家居自动化系统在控制器和用户部分之间使用无线传感器 [10]。传输过程涉及通过 Web 应用程序从移动设备或 PC 输入，以及接收部分 ZigBee RX 接收信息并处理所需输出。微控制器在 WHAS 中实现，一旦创建无线连接，系统就会实现发射器-接收器以建立 ZigBee 连接。

可以使用蓝牙或 Web 服务器来无线控制 Raspberry Pi GPIO [12]。但是，使用蓝牙连接会导致远程控制设备出现问题，因此要实现远程连接，可以创建自己的 Web 服务器，该服务器将借助 HTTP 请求来控制 GPIO。创建 Web 服务器的最简单方法是使用 Flask 库。因此，每当发出请求时，就会执行一段代码，该段代码包含用于控制特定 GPIO 引脚以实现远程控制的代码。

使用 ESP 模块和 Wi-Fi 的基于物联网的设备监控和控制系统 [13] 可用于从中心远程位置操作电气设备，以持续跟踪其状态（即开启或关闭）和工作状况。它授予访问权限并管理室内和室外照明。它使用传感器检查设备中的缺陷，并在遇到缺陷时使用模拟信号发送警报，以使系统更高效。为了减少或最大限度地降低

家中的电气设备可以连接到互联网控制开关盒 [14]，以便随时远程控制它们。智能开关盒集成了电源单元、Wi-Fi 开关、继电器、双向开关以及移动设备上的 Android 应用程序。ESP8266 芯片充当 Wi-Fi 设备，并在其中实现了 Web 套接字，以在相同的 Wi-Fi 环境中将智能开关盒与手机连接起来。要打开或关闭连接到智能盒的设备，该设计选择 ESP8266 作为主控制芯片来控制继电器。表 10.1 显示了用于实现智能系统的不同无线技术之间的比较。

连接到远程服务器的电气设备可以通过登录到服务器 PC 来使用计算机接口 [15] 从远程位置进行控制。要登录，会创建一个使用真实 IP 的网页或使用虚拟 IP 的 Microsoft 远程协助系统。登录后，客户端或最终用户可以查看任何连接设备的*实时*状态，并通过开发的应用程序 [16] 获取这些设备的状态更新。数据由客户端 PC 的 ID 号组成，可即时显示电气设备的状态，由 TCP/IP 监听器接受，然后通过设备在互联网上发送到所需地址的特定端口。

## 10.3 方法论

本项目旨在控制实验室/房间/办公室内的风扇和 LED 等电气设备，考虑访问控制问题及其解决方案。在深入实现细节之前，让我们先了解所使用组件的详细信息。

Raspberry Pi - 它是一款非常基本且经济实惠的计算机，运行 Linux 操作系统，并提供一组 GPIO（通用输入/输出）引脚，允许用户控制电子元件进行物理计算，并探索物联网（IoT）。

继电器模块 - 它是一种用于远程设备切换的独立硬件设备。它有助于通过网络或互联网远程控制设备。设备可以根据来自 Raspberry Pi 的命令远程开启或关闭。它有助于从办公室另一端或世界各地控制计算机、外设或其他供电设备。

## 10.4 实验设置与结果

继电器模块通过 GPIO 引脚连接到 Raspberry Pi。这些引脚用于向继电器模块发送信号。它们包含两种信号，HIGH 和 LOW。当信号为 HIGH 时，继电器通道开启；当信号为 LOW 时，继电器关闭。原型中使用 4 通道继电器模块，即一次最多可将四个设备连接到一个模块。继电器通道上的每个设备都有一个专用引脚连接到 Raspberry Pi GPIO。脚本根据要求进行编程，然后通过运行该脚本来控制模块。图 10.4 显示了原型实验设置的电路。
