离线问题按定义是在较长的时间尺度上实现且计算速度较低。由于这些问题通常与系统设计过程相关，因此包含复杂的技术和经济模型，这些模型增加了数学模型的维度和复杂度。因此，这些问题具有更高的计算负担和更长的求解时间。然而，由于离线决策变量的最优值在实时运行过程中不实际应用，因此较高的计算时间通常是可接受的。相比之下，智能能源系统中的在线问题要求在实时运行过程中计算决策，以对多个快速作用设备和不确定的RES进行最优控制。

优化器的核心是一个优化问题，它在较小的时间尺度上执行，并计算优化的决策变量以生成各个系统控制器的控制信号。设计优化器的一般方法包含三个步骤。首要步骤是识别和形式化所需EMS的目标。此外，必须识别所有基本技术约束。其次，制定优化器目标函数和约束的数学表达式。这一组完全定义所考虑问题以及特定系统的一般/技术基本特征的数学关系称为模型。模型的一般形式可以表示为以下优化问题。

```
min_x f(x), x \in \Re^n
```

其中f(x)是优化器的最小化目标，x是决策变量集合，\Re指欧几里得空间。该问题受以下等式和不等式约束：

```
g(x) = 0
h(x) \le 0
```

在这一步骤中，对在(1.1)-(1.3)中形式化的问题进行评估。对适合的求解算法进行分析和测试，以评估其在求解EMS模型中的相对性能。由于能源管理通常是一个小时间尺度问题，计算速度是求解算法非常重要的期望参数。因此，如果数学问题无法在EMS实际实现的时间范围内求解，则使用不同的分布式优化或分解方法对模型进行适当转换。然后执行修改后的优化模型并获得决策变量的最优值。这构成了第三步。然后在实际运行条件下对模型进行性能评估测试。一旦模型在实时条件下经过测试和分析了性能，通常有必要通过灵敏度评估进行后优化分析。一个变量\alpha_i相对于另一个变量\alpha_j的灵敏度，按定义，是指由于\alpha_j值的扰动而导致的\alpha_i值的变化。这是为了识别敏感变量，这些变量的值在不改变优化模型最优值的情况下不能改变。必须指出，开发合适的EMS模型是设计精度与计算效率之间的权衡。

## 1.3.4 实时优化

实时优化是指一组优化方法，这些方法将实际实时输入和状态估计纳入数学优化模型，以最优地执行实时过程，同时满足某些实际约束。能源系统中的小时间尺度问题，例如发电源和储能系统的最优调度、需求响应计划、负荷控制和点对点能源共享，是在线运营中的一些操作，这些操作需要在智能能源系统中开发实时优化模型。模型的实时实现面临着测量输入不确定性的挑战，并且需要在定期时间间隔后重新评估最优值。通常的情况是，优化模型的目标函数和约束的输入变量（通常预先测量）与实际发生时的预测值存在可测量的差异。结果，优化模型的输出往往是次优的，使得模型不准确。

在微电网中，不确定性主要由于RES渗透率增加、动态用户偏好和实时电价等因素而产生。值得注意的是，太阳辐照度具有高度不确定性，这可能导致光伏输出在1分钟内波动高达其额定容量的15%。此外，风速存在较高的时间变化，因此可能在几秒钟内上升至预测值的2-3倍。这意味着风力发电输出在几秒钟内可能变为原来的8-27倍[29]。输入数据的不确定性可能导致优化模型出现潜在不准确。由于系统运营商的持续努力旨在平衡负荷和发电，因此对预测值的低估或高估都不利于系统可靠性。因此，系统运营商被迫削减负荷或为因次优调度而未满足的需求支付罚款。

由于惯性较低和能量缓冲有限，小型能源系统深受不确定性影响。如果系统并网，配电网络将受到越来越大的压力，而离网系统中的未满足负荷会增加，导致用户不满。发电和负荷之间长期的不匹配可能导致在意外情况下由于次优运行而对系统组件造成显著劣化。电力分配网络及其相关资产（如配电变压器）可能承受显著过载，这可能加速设备老化，并因更早更换而导致更高的投资。此外，从用户角度来看，意外的发电短缺会导致效用和舒适度降低，并造成消费者不满。确保在这样的不确定条件下高效系统运行需要定期更新最优调度，以满足实时优化的要求。

实时优化是通过使用输入变量的测量值，或者使用实际运行前的输入数据预测值来执行的。不使用测量的方法包括名义优化和稳健优化。在使用测量的方法中，文献中已知三种广义类型的方法，即：(i) 过程模型自适应、(ii) 优化自适应和(iii) 直接输入自适应[11]。这些方法说明如下：

- 1. 过程模型自适应：测量值可用于改进模型，这意味着函数的数学表达式在连续优化迭代之间更新。这种自适应通过更新模型参数来执行。示例包括两阶段或多阶段过程。
- 2. 优化自适应：测量值也可用于直接修改优化问题。使用这些方法，确定用于修改优化模型的修正项。这些项直接添加到保持不变的公式中的数学表达式中。这种方法的示例包括偏差更新和约束自适应。
- 3. 直接输入自适应：这一类方法提议以受控制启发的方式直接修改输入。然而，这种方法的主要困难是构建具有所需自优化特性的控制问题。示例包括跟踪有效约束和极值寻求控制。

如上所述，为确保可靠的系统性能和用户舒适度，处理能源系统中不确定性的出现是迫在眉睫的。对于在线能源系统运营，这可以通过设计实时系统优化器来实现。在运筹学中，不确定性处理已通过多种方法进行讨论，例如灵敏度分析、稳健优化方法、机会约束和随机规划。灵敏度分析方法是一种后优化过程，因此不适用于在线优化。不确定性处理方法之间的另一个主要区别基于关于不确定性的可用信息类型。如果不确定变量被观察到遵循标准概率分布函数，则它们被称为概率不确定性。然而，在实际情况中，非概率不确定性更为常见。因此，Bertsimas 等人概述了稳健优化和随机优化之间的基本区别如下。“在稳健优化中，决策者构建一个在给定集合中对不确定性的任何实现都可行的解，而随机规划则寻求在某种概率意义上对随机不确定性免疫的解”[7]。下面简要讨论了这些方法中的每一种。
