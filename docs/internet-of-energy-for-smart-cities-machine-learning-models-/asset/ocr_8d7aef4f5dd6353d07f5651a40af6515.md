# 11.2.3 ADVANCED POWER METERING

Sensing devices installed in an IoT infrastructure generate vast chunks of data which is forwarded to the main system e.g. a server hosted on a cloud platform through a gateway for real-time or non-real-time decision making and/or actuation. Smart electricity meter is such an example of IoT device which are now-a-days being installed in domestic and industrial premises in order to monitor the power consumption along with various services like billing, load forecasting, and dynamic pricing. A smart meter includes various sensors, namely line frequency and phase currents and voltages. Besides, the auxiliary parameters such as system temperature and time stamp are also collected, for studying the electricity consumption pattern and system health, which are sent to the control center. It may also control the operation of the devices at the customer premises through command signals. On a regular basis, the utility provider receives the electricity consumption data from the customers’ various devices.
