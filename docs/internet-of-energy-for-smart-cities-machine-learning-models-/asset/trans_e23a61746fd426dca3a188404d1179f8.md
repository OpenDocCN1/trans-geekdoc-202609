**图 10.5** 通过移动应用程序访问 LED

平均而言，单个 8W LED 灯泡的能耗约为 8 Wh（0.008 KWh），而企业建筑或学校、大学等教育建筑，平均每间房间包含 10–12 个 LED 灯泡。假设一个房间有 12 个此类 LED 灯泡且全部使用，则消耗的能量约为 100 Wh（0.1 kWh）。

经常发生这种情况：进入房间的人一上来就把所有电器都打开，而不管他/她将在房间的哪个区域坐下工作。在理想情况下，单个人只需点亮 1 或 2 个 LED 灯泡（消耗约 16 Wh 能量），但在实际场景中，所有 LED 灯泡都被点亮。这导致不必要地点亮的 10 个 LED 灯泡消耗近 80 Wh（0.08 KWh）的能量。

通过使用所提议的智能控制系统，可以通过智能控制打开的 LED 或电器数量，将能耗问题降至最低。使用计算机视觉模块，系统将自动检测该房间内人员的存在，并相应地打开人员所在区域的电器。图 10.6 显示了使用智能系统时房间内能耗与人数之间的关系。

根据对原型机计算机视觉模型进行的模型训练，模型的平均准确率约为 50%。利用这些数据，我们可以预测，能耗最多可降低 40 Wh。

**图 10.6** 使用智能系统的能耗

常规系统的平均能耗 = 100 Wh
使用智能系统的平均能耗 = 60 Wh
使用智能系统每小时平均节省能量 = 100 – 60 = 40 Wh
实施智能系统一年节省的总能量 ≈ 40 * 24 * 365 Wh ≈ 350.400 KWh。

## 10.5 讨论与结论

当今，由于资源匮乏和能源需求过剩，尽量降低能耗的概念变得更加重要且日益关键。因此，能源需求激增，但由于资源有限，供应只能有限。

此外，由于一些局限性以及管理能耗效率低下，传统的灯光控制系统长期来看不可行，也无法成功安装。访问的便捷性也是开发智能系统的一个重要因素，消费者可以使用这些系统远程轻松访问其电器。

所提议的系统既能最大限度地降低能耗，又能让消费者远程访问其电器。能源通过训练好的计算机视觉模型节省，该模型能准确识别建筑物特定房间所需的光照强度并自动进行管理，以最大限度地节省能源并减少交互，同时系统还为用户提供特权访问权限，即它允许不同用户访问同一电器，某些用户可能暂时访问特定电器，而某些用户可能永久访问。因此，通过使用所提议的系统，我们可以同时实现这两个目标。

## 10.6 局限性

当前原型机存在一些局限性，目前正处于修改阶段，并致力于系统开发。面临的主要局限性是：当网络连接较弱时，HTTP 响应和请求速度缓慢。这是因为使用的是免费版本的 RESTful API，其延迟比付费 API 更高。另一个问题是使用计算机视觉模块进行的人员存在检测，其准确度中等。目前没有可用的适当数据集来训练计算机视觉模型，因此正在开发一个数据集，利用该数据集可以制作出更准确、更高效的模型，从而在系统原型开发过程中实现理论上预测的最大限度降低能耗的主要目的。原型机仅限于照明电器。

## 10.7 未来改进

系统正在使用开发的定制数据集进行开发。因此，所提议的模型是开发一个比当前原型机更高效的系统，当前原型机对房间内人员存在检测的准确率仅约为 50%。因此，计算机视觉模块可以通过使用更好的房间内存在检测算法来提高效率，从而以较低成本优化能耗。

系统面临的 HTTP 请求和响应延迟高的问题可以通过开发更高效的 API 来解决。系统可以兼容更多电气设备，而当前原型机仅兼容照明电器。该系统的应用程序可以在 iOS 和 Android 平台上使用，并以更高的效率完全集成所有模块。
