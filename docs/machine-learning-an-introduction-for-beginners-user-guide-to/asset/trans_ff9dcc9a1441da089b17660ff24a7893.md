
# 第11章：神经网络与深度学习

神经网络是一种受生物学启发的编程范式，用于让计算机从观察到的数据中学习。深度学习是一套技术，你将用于神经网络。神经网络和深度学习都将为你提供解决在图像、语音和自然语言识别与处理时可能遇到的任何问题的最佳方案。人类的视觉系统复杂，是你可以研究的最有趣的事物之一，因为你永远无法完全理解它如何与身体其他部分协同工作。以书写为例，许多人能够看见某段文字并毫不费力地告诉你它写的是什么，但实际识别文字所付出的微小努力却具有欺骗性。如果你观察大脑的不同半球，你会发现你的视觉皮层有数百万个神经元相互连接。然而，你的视觉并不会直接与视觉皮层相连，而是通过一系列皮层传递，使视觉信息到达能够处理最复杂图像的区域。大脑内部本质上是一个经过进化精心优化的超级计算机。识别书写并非总是轻松，但你的大脑已经适应了这种能力，使你能够不自觉地完成它。我们很少有机会思考视觉系统的真正复杂程度。就像很难识别视觉模式一样，计算机也不会遇到这些问题。但它的工作方式与人类不同。我们的大脑识别形状和书写方式，但如何向计算机传达这一点呢？你需要制定规则，而这些规则最终会因你为处理例外和边界情况而创造的繁复规则而丢失意义。神经网络的方法则截然不同。它会将大量手写数字作为输入，并训练模型识别各种形状，从而实现类似人脑的功能。基本上，神经网络会利用数据中的示例来推断其内在的识别规则。你添加的训练示例越多，网络越能学习书写的各种变体，提高准确率。神经网络会使用一种称为“感知器”的人工神经元，该感知器于60年代由Frank Rosenblatt提出。但从今天的角度来看，它的使用方式与其他人工神经元模型相同。你的主要神经元被称为“逻辑函数”（sigmoid neuron），但要理解逻辑函数，必须先理解感知器。感知器会接收多个二元输入并输出一个二元结果。Rosenblatt提出了一个规则，用于确定感知器的输出。在此过程中，权重（weights）作为表达实数及其对输入输出重要性的方式出现。神经元的输出要么是0，要么是1，它会根据加权和与阈值的大小关系来决定。阈值是一个实数，作为神经元的参数使用。你可以把感知器看作一种通过权衡证据做出决策的设备。例如，如果你计划一次家庭出游，需要考虑以下几点来决定是否按计划进行：

1. `Is the car big enough for everyone that wants to go?`

2. `Is the weather going to be good?`

3. `What do you need to pack for the amount of time that you are going to be out?`
