第1章：机器学习 在深入机器学习之前，您必须了解机器学习的概念。机器学习是人工智能的一个分支，其核心思想是系统能够从数据中学习、识别其中的模式，并无需人工干预即可做出决策。如果有的人工干预，干预程度也应极小。系统利用收集的数据分析，然后自动根据数据构建模型。那么，机器学习为什么重要呢？因为它与贝叶斯分析和数据挖掘的流行原因相同。随着数据量的不断增长以及数据种类的多样化，计算成本降低，计算能力增强。这使得企业能够存储数据，并更快、更准确地分析更复杂的数据集，快速生成更大、更复杂的模型。这将帮助公司更清楚地了解在哪里可以赚取更多利润，以及在哪里需要谨慎以避免未知风险。正如您在后续章节中将学到的，银行、政府、医疗、营销、交通以及石油和天然气行业都在使用机器学习。它们利用该技术提高效率、发现赚钱机会，并识别需要削减支出的领域。在机器学习中，有四种流行的方法：监督学习、无监督学习、半监督学习和强化学习。第一种是监督学习，即算法在标记数据上进行训练，以了解输入与期望输出的对应关系。例如，工厂设备的数据点被标记为“故障”（F）或“运行”（R）。算法接收输入及其对应的输出，并通过比较给定的输出与正确输出来学习错误位置。随后，它会相应地修改模型。通过分类、预测、回归和梯度提升等监督学习方法，算法会创建模式，以便在未标记的额外数据中预测标签值。监督学习通常出现在历史数据用于预测未来事件的应用场景。下一种学习是半监督学习，它通常与监督学习一起应用。半监督学习将标记数据和未标记数据结合用于训练。标记数据通常较少，而未标记数据占大部分，因为未标记数据获取成本低且无需太大努力即可获取。当标记成本过高，无法进行完全标记的训练时，半监督学习将发挥作用，它使用与监督学习相同的方法，但仅在标记成本过高时才有用。无监督学习用于数据中不存在历史标签的情况，系统没有像监督或半监督学习那样拥有正确答案。第一步是让算法理解它所看到的内容。目标是让机器探索数据，发现是否存在结构。无监督学习也会使用交易数据。强化学习通常出现在导航系统、游戏和机器人中。强化学习通过试错来让算法“发现”最佳行为，从而获得最大回报。在强化学习中，至少包含三个组件：第一是代理（agent），即决策者；第二是环境（environment），即代理交互的环境；第三是代理所执行的动作（actions）。目标是让代理选择能在一定时间内最大化预期回报的正确动作。只要代理遵循良好的策略（policy），就能更快达到回报。因此，强化学习的目标是找出最佳策略。机器学习还包括一种学习类别，即程序根据以往经验的 inductive bias 进行学习。发展性学习（developmental learning）等同于机器人学习，程序能根据其经历生成自己的学习序列，通过自我探索和与人类及其他程序的交互，获得新技能的 repertoire。此外，机器学习还包括一种基于输出的类别。 

1. 输入的分类将分为至少两类。用户需要构建一个模型，能处理用户未见的输入，这些输入通常来自监督学习，例如电子邮件过滤器区分垃圾邮件和正常邮件。 

2. 回归也是监督学习的一种，其输出为连续值，而非离散值。 

3. 聚类（clustering）会将输入集分成多个组。但聚类与分类的区别在于，聚类在形成组时用户不需要事先知道这些组，因此这是一个无监督任务。
