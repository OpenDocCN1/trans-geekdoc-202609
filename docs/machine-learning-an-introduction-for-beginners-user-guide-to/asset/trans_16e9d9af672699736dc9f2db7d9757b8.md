
# 第5章：机器学习示例

近年来，机器​​学习已被应用于各个商业领域，并被传递给其他公司以及消费者。机器学习与人工智能相结合，使得新产品能够向公众发布。这些产品随后推动其他产品的推出，并帮助改善了面向消费者的产品。其中一个产品是Hello Barbie玩具，它在项链上内置了麦克风。每当孩子说话时，他们的语音会被传输到Toy Talk服务器并进行分析，以便发送适当的回复。整个过程只需少于一秒钟完成。Hello Barbie能够回复8,000行对话，并能够保存答案，以便在后续回答诸如孩子最爱食物的存放位置等问题。

可口可乐公司在200个国家销售超过500种饮料，使其成为全球最大的饮料公司。通过分析每个国家的数据，可口可乐能够了解该国最畅销的饮品，并淘汰销量不佳的饮品。这意味着他们能够最大化利润并最小化利润损失率。

海尼根同样做法，但他们利用人工智能和机器学习来改善其在美国的客户服务、营销、广告和运营，从而实现扩张。

你听说过Watson吗？Watson已被应用于各行各业的多个领域，包括烹饪艺术。Chef Watson已成为厨房中的副主厨，负责开发食谱并辅助其人类同事，使厨房工作比以前更高效。Watson还被输入过高迪（Gaudi）的作品图像，以便他能够观察并分析这些作品，从而学习其影响来源。它学习了包括巴塞罗那在内的各种影响，以及文化、传记和历史数据，以便将这些信息与人类艺术家分享，帮助其创作出与高迪风格一致的雕塑。Watson甚至被赋予了帮助作曲家在音乐元素上获得灵感的算法，并协助他们判断哪首歌曲将成为热门。Watson通过利用对话、演讲和报纸标题来获取灵感。

BP是全球能源行业中最大的公司之一，认识到机器学习和人工智能对其行业具有巨大的潜力。通过使用最新的技术，他们能够提升资源利用率和石油和天然气精炼过程的安全性。通过优化运营，他们能够将所有数据交到能够做出高风险决策的人手中，这些决策最终将改变世界。

在能源行业，通用电气（GE）也在使用机器学习、物联网（IoT）和大数据来构建能源物联网，将所有数据全部传输。他们能够优化数据，推动其实现数字化电厂的愿景。

在金融领域，数据量约为3.6千 petabytes，且每日持续增长。每天，部分人会通过Experian等信用机构查看自己的信用，因此他们从各种营销数据库、公共记录和交易记录中接收到大量数据。他们目前正在改进系统，机器学习使服务能够更快做出决策。他们希望更快地向消费者传递这些决策，避免人们在购买时因等待数日而延迟信用决策。

美国运通公司（American Express）目前使用超过1.1亿张正在使用的卡片，并处理超过一万亿美元的交易。因此，他们依赖于专门用于实时欺诈检测的机器学习算法，这为公司节约了数百万美元。此外，AmEx正在通过开发允许卡片持卡人登录并访问账户的应用来控制数据流，这也有助于他们了解用户的在线业务趋势。

Google的Deep Mind开发了一种能模仿人类思维过程的机器。Deep Mind已能够在各类游戏中击败人类，但其可能性远不止于此。Deep Mind有潜力帮助医疗保健领域，从而缩短治疗方案制定的时间，使诊断更快速。

机器学习帮助沃尔沃（Volvo）预测车辆部件何时可能故障或需要保养。这帮助挽救了无数生命。沃尔沃也在开发自己的自动驾驶汽车。

# 第6章：免费数据集

您在使用机器学习时使用的数据集将位于已被同行评审学术期刊引用的数据集中。数据集是机器学习的关键部分，您必须了解它们才能理解机器学习。正如我们之前讨论的，该领域已取得重大进展。得益于用户对计算机硬件的了解、将用于计算的算法以及高质量训练数据集的可用性。

大多数数据集将是受监督的，甚至可能是半监督的，因为它们涉及算法，而由于数据标记的高成本和难度，生成这些算法很困难。如果数据不需要标记，则可以留作无监督，这对大多数公司来说成本过高。

您用于图像数据的大多数数据集将是用于面部或动作识别的集合，同时也用于识别纸上书写的手写体和字符。

文本数据包括人与人之间发送的消息、网上留下的评论、Facebook或Twitter上发布的帖子，或任何输入到任何计算机程序中的文本。

音频数据指任何声音，如语音或音乐，可以放置在计算机上并进行分析。

物理数据是从地球科学、天文学和其他系统中收集的数据，这些系统可以通过物理方式进行测量。

信号数据是用于跟踪电力或其他运动的数据，例如交通在城市中的流动情况。

多元数据是测量天气、互联网流量、金融以及甚至人口普查等数据。

最后，生物数据测量药物发现、植物生长、动物生长和人类生长等。因此，生物数据测量任何可被测量的生物。
