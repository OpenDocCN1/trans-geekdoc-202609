分类机器学习模型将通过使用保留法等准确率估计技术进行验证。保留法在训练和测试数据集合之前将数据划分，然后在测试集上评估模型的性能。然而，如果查看 n 重叉验证，则会发现数据会随机划分为子集，其中 k-1 个实例用于训练模型，而第 k 个实例用于测试模型的预测能力。与此同时，保留法和交叉验证方法会使用 n 个实例的样本。数据来自数据集，并用于评估模型的准确性。除此之外，研究者还会发现一个总体准确率，并将其报告为特异性和灵敏度，例如真阳性率和真阴性率。这意味着真阳性率和真阴性率有时会报告假阳性率或假阴性率。但正是这些率未能显示分子和分母，导致总体特征曲线（ROC）成为有效展示模型诊断能力的方法。总体特征曲线还会揭示前面提到的率中的分子和分母。这意味着总体特征曲线能提供比单纯的率更多的信息，包括受曲线下面积（AUC），其属于受曲线下面积。由于这些特性，机器学习经常引发大量伦理问题。用于处理收集的数据的系统会因训练数据中体现的偏见而变得有偏见，这会数字化文化偏见。因此，数据收集所带来的责任在机器学习中占据重要地位。由于使用的语言会引发机器学习中的偏见，我们在使用机器学习时，实际上是在使用经过偏见训练的机器。  
第2章：机器学习中的主要问题 机器学习仍在不断发展，并且每天都在被使用。随着使用的增多，我们能够更好地发现问题所在以及需要做什么来解决它们。有些问题目前尚未得到解决，但这并不意味着未来不会有解决方案。一个问题是自然语言处理和语言理解在机器学习中仍然是一个挑战，即使是最深层的网络也难以应对。由于众多语言和方言的存在，机器很难辨认所说的内容。但这并不阻止它们尝试。Siri 和 Cortana 等程序不断更新，以更好地服务于用户。图像可以通过机器学习进行分类，但无法理解图像内部的具体情境。要真正理解图像内容，就无法进一步分类。不过，我们可以确定图像中影响因素的位置，并尝试在相同风格下重现作品。这也指向语义分割的解决——机器需要学会识别每个像素的含义，从而更好地理解图像。深度强化学习也需要得到稳定。如果没有损坏，为什么还要去修改？有时旧方法效果最佳，没有必要对已经运行良好的模型进行调整。一旦深度强化学习得到稳定，就能让其处理目前机器学习尚未涉及的更复杂问题，例如《马里奥》中的“复仇”关卡。稳定的强化学习还能够指数级提升机器人控制的可能性，可能性无限。机器人能够找到获得奖励的最佳方式，换句话说，它们可以像人类一样行动，但拥有明确的激励机制，决定应做什么才能获得奖励。生成对抗网络（GAN）是一种作用于特定人工智能类别的生成模型，属于无监督学习范畴，由两个神经网络在零和博弈框架下相互对抗组成。虽然它们在游戏领域表现出色，但因高度稳定且经常导致崩溃，使得游戏变得更具挑战性。深度网络的训练同样是一个问题，因为“梯度碎片”论文证明，当前从事机器学习的人尚未完全掌握如何正确训练网络。这也说明，目前人们对深度网络的工作原理并不完全清楚。虽然有人撰写论文阐述深度网络的必要性，也有人撰写论文指出其不必要性，导致情况更加复杂。那么，深度网络到底是为了什么？我们真的需要它们吗？最后，还需要让人们停止过度担忧诸如 Skynet 这类问题以及经济影响。首先，Skynet 是《终结者》电影中的虚构公司，根本不会实现。在机器人能够自行决策之前，必然会有安全机制防止机器人反叛并伤害人类。Skynet 仅是一部深受数百万观众喜爱的电影系列的情节设定。其次，机器学习的经济影响——随着机器学习的应用，企业能够找出更大利润的方向，从而将更多资金注入经济。除去一些尚未稳定的机器学习技术外，机器学习本身并没有许多问题。我们必须记住，机器学习仍处于起步阶段，正随着技术发展不断被训练，因此需要保持耐心，认识到在问题得到解决之前，还会出现更多挑战。
