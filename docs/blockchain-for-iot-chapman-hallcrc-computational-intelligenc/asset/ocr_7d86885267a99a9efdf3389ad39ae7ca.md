First, the client uses the authorization server to seek permission from the resource owner. Second, the authorization server submits the login credentials to the client. In the third step, the client authenticates oneself to the authorization server using the login credentials obtained from the AS to request an access token from the AS. The AS verifies the user and provides the client with an access token in the fourth step. In the fifth step, the client uses the obtained access token to request access to secure resources from the AS. The AS authenticates the access token in the sixth step, and if the validation is correct, the client is permitted to access the protected services.
