# 2.4.2.3 Blockchain Signaling System (BLOSS)

The Blockchain signaling system (BloSS) [26] is a solution for security management, designed for cooperative defenses (like distributed denial of service [DDOS] attacks) by using software denied networks (SDN). BloSS was designed and prototyped in a global experiment to build specific protocols and registries to overcome the attacks and improve security vulnerabilities for a distributed network. This is built on Blockchain and could be further exploited in hybrid systems of integrated Blockchain-based IoT systems.
