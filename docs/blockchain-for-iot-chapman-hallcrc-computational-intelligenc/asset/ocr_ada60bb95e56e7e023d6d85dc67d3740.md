# 2.3.4 IoT Levels

To truly understand the functioning of an IoT system, it is important to highlight the various levels of IoT systems. An IoT system consists of components such as a device, the resources (software components), a controller and web service components (Web Socket protocols), the database (either local or cloud-based), an analysis component, and finally the application as an interface to interact between the users and devices. Illustrated in [20], there are six IoT levels. Each level improves accordingly with the inclusion of cloud-based analytic tools introduced from level 3. Levels 4 and 5 have multiple end nodes and can handle more complex data. Level 6 improves on these further by working with independent multiple-end codes using a centralized controller, a cloud-based application for visualizing the data.
