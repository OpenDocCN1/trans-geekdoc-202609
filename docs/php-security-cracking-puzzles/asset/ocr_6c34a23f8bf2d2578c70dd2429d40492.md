# I.8.6. Extracting an Exchange Rate from an XML File

In addition to the regular HTML pages, the RSS format has become popular on the Internet. News, catalogs, forum messages, and other frequently-changed information is stored in XML files. XML files are easy to load and parse because their structure does not change as that of HTML pages. Many sites make information available in the XML format, making it possible for other site owners and search robots to access information in a more convenient format than that of HTML pages.

As an example of obtaining such information, look up current currency exchange rates relative to the euro. The source for this information will be the site of the European Central Bank, the http://www.ecb.eu/stats/euroxfref/euroxfref-daily.xml listing I.8.1 shows the contents of the XML file located at this URL.

> The euroxfref-daily.xml file can be found in the /scripts/8 directory on the accompanying CD-ROM.
