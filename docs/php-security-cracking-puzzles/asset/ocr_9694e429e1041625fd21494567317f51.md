# Chapter II.7: Authorization and Authentication

Most people prefer passwords that start with the last letters of the alphabet or with higher digits. The characters in the array can be arranged in an order other than ascending or descending. For example, the most often used letters can be placed at the beginning of the array, and the least used ones can be moved to the end.

However, it is unlikely that a real-life password will be made up of only four lowercase English alphabet letters. Including digits in the set of the possible password characters (Listing II.7.7) increases the password guessing time threefold (Fig. II.7.2).

# Listing II.7.7. Adding digits to the possible password character set

```
<?php
sarr = array('a', 'b', 'c', 'd', 'e', 'f', 'g',
      'h', 'i', 'j', 'k', 'l', 'm', 'n',
      'o', 'p', 'q', 'r', 's', 't', 'u',
      'v', 'w', 'x', 'y', 'z',
      '1', '2', '3', '4', '5', '6',
      '7', '8', '9', '0');?>
```

> Fig. II.7.2. Guessing passwords by character enumeration using the Listing II.7.2 character set

In addition to digits and uppercase and lowercase letters, a password can contain special characters, such as the period, comma, exclamation and question marks, equal sign, parentheses, and ampersand.
