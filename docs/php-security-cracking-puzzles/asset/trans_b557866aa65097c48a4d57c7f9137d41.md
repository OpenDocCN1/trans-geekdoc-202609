### II.3.18. 向文件添加记录

要向文本文件添加新记录，必须确定最大索引值。接下来，向文件中添加索引等于最大值加一的行。最后，保存更新后的文件（列表 II.3.28）。

### II.3.28. 向文件添加记录

```php
<?php
// 文件名
$filename = "text.txt";
$str = "Pascal programming";

// 确定最大索引
$arr = file($filename);
$maxval = 0;
foreach($arr as $line) {
    preg_match('/^(\d+)([^\n]+)$/', $line, $out);
    if ($maxval < $out[1]) $maxval = $out[1];
}

// 读取文件
$content = file_get_contents($filename);
// 添加新行
$content = "\n".($maxval + 1).$str;

// 保存更新后的结果
$fd = fopen($filename, "w");
fwrite($fd, $content);
fclose($fd);
?>
```
