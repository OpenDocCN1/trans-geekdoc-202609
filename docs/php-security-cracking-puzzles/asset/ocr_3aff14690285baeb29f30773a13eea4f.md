# # Chapter I.14: Telltale Scripts

![](bbox=[0.106, 0.146, 0.931, 0.313])

All PHP Web application developers make the utmost effort to protect their work. However, the amount of effort the defending party has to apply to protect against a break-in is many times that the attacker has to spend to perpetrate one. Under these circumstances, you should not only build your defenses but also develop a complex of measures to rapidly detect and neutralize a break-in. As a rule, when crackers break into a system they spend some time exploring it before undertaking any actions. Therefore, it is a good idea to install telltale scripts that react to any anomalies in the system. Developing post-break-in complexes and their scripts is the subject of this chapter.
