## I.2.13. Interpreting bbCode Tags

Tags enclosed in square brackets, also called phpBB-style tags (phpBB is a popular forum), are widely used on the Internet. The convenience of using such tags is that all HTML tags can be prohibited by converting them into the safe form using the htmlspecialchars() function, leaving visitors to use their equivalents instead. For example, it is possible to use [i] instead of <i> and [code] instead of <code>. Tags enclosed in square brackets can be replaced by <a> tags in angle brackets only after the text has been converted using the htmlspecialchars() function. This conversion is usually applied to [url] tags that have the following syntax:

```
[url=link]name[/url]
```

In the course of output, this template must be converted into the following format:
<a href="link">link name</a>

As another example, suppose that the following form of the tag is used:
[url]link[/url]

The following hyperlink will be output to the page:
<a href="link">link</a>

## I.3.5. Saving Text and Graphics Files

The download counter script solves another problem related to system security: Namely, it hides the true path to files from the user. You can hide them deeply nested somewhere within the system; the visitor will see only the download page address.

Nevertheless, if the download file is a text file, the browser won't display the download window. Instead, the browser will load the file, thus not only disclosing the path to the file but also forcing the user to save the file on his or her own using the Save As... menu. The same is true for graphics files, as well as for all files the browser can open and display. Develop a script for storing text and graphics files, providing an appropriate window for downloading files (Fig. I.3.4).

## I.3.14. Deleting Directories
