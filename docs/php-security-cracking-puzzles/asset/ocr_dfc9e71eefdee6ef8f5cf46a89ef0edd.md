# Chapter 1.1: Strings

![](bbox=[0.061, 0.137, 0.882, 0.311])

Strings are the mainstay for any type of programming. Mastering strings allows programmers to create short and efficient programs. Various studies have shown that the concentration of errors in programs depends not on the programming language but only on the qualification level of the programmer. The shorter the program is, the fewer errors and vulnerabilities it has. Solid knowledge of specific string features will allow you to expertly determine, which code sections are problematic in terms of possible bugs and vulnerabilities. This chapter considers several puzzles and problems; solving them will allow you to improve your knowledge of PHP string functions and your string-manipulation skills.
