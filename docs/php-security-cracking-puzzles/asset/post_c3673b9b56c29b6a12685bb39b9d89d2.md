The `<Cube time='2006-01-20'>` tag specifies the date to which the information in the XML file pertains. The `<Cube currency='CCC' rate='X.XXXX'>` tags provide the exchange rate of a specific currency relative to the euro. Here, CCC stands for a three-letter currency abbreviation (e.g., USD for the U.S. dollar and JPY for the Japanese yen), X.XXXX is the rate. Develop a script to download the XML file and display the current exchange rate of the euro against the U.S. dollar. As can be seen in Listing I.8.1, on January 20, 2006, euro 1.00 was worth $1.2068.

## I.8.7. Determining the Exchange Rate History

In addition to currency exchange rate information, the site of the European Central Bank provides information about the currency exchange rate history since 1999. The information is available as a 2-MB XML file that can be downloaded from http://www.ecb.int/stats/euroxfref/euroxfref-hist.xml.

Create a script to download the currency exchange rate history of the euro against the dollar for a 1-month period from the current date, then display it as a table (Fig. I.8.9) and as a bar graph (Fig. I.8.0).

Keep in mind that no trades are held weekends and holidays, so the number of citations for the month will be fewer than the number of days in the corresponding period.

# Chapter 1.9: File Transfer Protocol

![](img/a893312ec68b8170fe567f785e95c06e_90_0.png)

The file transfer protocol (FTP) is one of the oldest applications. It was first developed in 1971, long before the Web came into. Until the early 1990s, FTP was responsible for half of the Internet traffic. The protocol is still used today for distributing software and accessing hosts. This chapter considers how to develop an HTTP application for accessing a remote server from another remote or from a local machine running Apache.

FTP is defined in request for comment (RFC 959), available at http://www.rfc-editor.org/rfc/959. All examples from this chapter can be found in the /scripts/ directory on the accompanying CD-ROM.

## I.9.1. Determining the Operating System

## I.9.2. Listing FTP Files

## I.9.3. Uploading and Downloading Files

Develop scripts for uploading and downloading files to and from a server.

## I.9.4. Changing Access Permissions

Develop a script for changing access permissions for a file.

## I.10.2. Obtaining HTTP Headers from a Server

When working with remote host data, the entire body, which is an HTML page or a file, often does not have to be received. The only things necessary are the HTTP headers, which contain information about the server and the server's requirements for processing its contents (setting cookies, opening sessions, authentication requirements, etc.). Develop a PHP script for obtaining headers from a server.

## I.10.3. Determining the Remote File Size

One common Web task is determining the size of a file on a remote host. Develop a function for determining the size of a remote file without downloading the file and using only HTTP headers.

## I.10.4. Sending Data Using the POST Method

Suppose that you have the simplest HTML form, containing the name text field, a password field, and a button to send data (Listing I.10.1).

Listing I.10.1. The HTML form

```html
<form method="post">
Name: <input type="text" name="name"><br>
Password: <input type="text" name="pass"><br>
<input type="submit" name="send" value="Send">
</form>
```

When the Send button is clicked, the data from the text field are sent to the handler.php file (Listing I.10.2) using the POST method.

Listing I.10.2. The handler.php file

```php
<?php
echo "Name - " . $_POST['name'] . "<br>";
echo "Password - " . $_POST['pass'] . "<br>";
?>
```

Using sockets, pass the POST data to the handler.php file directly, bypassing the HTML form.
