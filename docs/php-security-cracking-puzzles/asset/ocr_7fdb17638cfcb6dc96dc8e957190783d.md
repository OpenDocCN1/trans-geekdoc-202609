# ## II.9.1. Determining the Operating System

A connection with an FTP server is established using the `ftp_connect` function. Its general syntax is the following:

```
resource ftp_connect (string host [, int port [, int timeout]]])
```

The function accepts the FTP server's address as the `host` parameter. The optional `port` parameter is used to specify the port number for the connection. By default, port 21 is used to open a connection. The optional `timeout` parameter specifies the time in seconds, during which the function will wait for the server to respond. If this parameter is not specified, the default timeout value is 90 seconds.

If a connection attempt fails, the function returns `false`. With a successful connection, the function returns a link identifier to be used for further operations with the FTP server.

After a connection to the FTP server is opened, the user is registered with the help of the `ftp_login()` function. Its general syntax is the following:

```
bool ftp_login (resource link, string username, string password)
```
