# ## II.1.6. Passing an Array Using the GET Method

To pass an array using the GET method, it is necessary to form a hyperlink, the elements of which would be passed through the parameters of the query string, for example: http://www.mysite.ru/second.php?filename[]=first&filename[]=second., where first, second, and so on, stand for the names of the first, and so on, files.

# ### II.1.10. Passing an array using the GET method

```
```php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Joining array elements into the string
// filename[]=firstfilename[]=second&....
$url = implode("&$filename[]=", $filename);
$url = "second.php?filename[]=" . $url;
echo "<a href="$url">Link to the second.php file</a>";
?>
```
