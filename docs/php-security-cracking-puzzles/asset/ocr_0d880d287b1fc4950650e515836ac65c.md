To allow graphics files of all formats, only the first five characters of the $_FILES['image']['type']` element are checked, as follows:

```
if (substr($_FILES['image']['type'], 0,S) == 'image')
```

If they are image, the file is a graphic. The script's logic following this piece of code is the same as that in Listing II.4.34, with the only difference being that images, not hyperlinks, are displayed in the area under the image download form. The src attribute of the <img> tag is passed a link to the get.php file, contents are shown in Listing II.4.38.

# Listing II.4.38. Downloading an image from a database

```
<php
// Connecting to the database
require_once("config.php");

// Checking whether the id_mp3 parameter
// was passed and whether it's an integer,
// thus protecting against an SQL injection
if(!preg_match("^\\\d+\$", $_GET['id_image'])) {

    exit("Invalid format of the URL query!");
}

// Extracting the image file from the database
$query = "SELECT * FROM image
WHERE id_image = $_GET[id_image];
$img = mysql_query($query);
if(!$img) exit(mysql_error());
$image = mysql_fetch_array($img);

// Sending headers for file download
header("Content-type: image/*");
// Sending the file to the user
echo $image['content'];

?>
```

Here, the "Content-type: image/*" HTTP header is sent before the contents of the graphics file. It informs the browser that a graphics file of an unknown format follows.
