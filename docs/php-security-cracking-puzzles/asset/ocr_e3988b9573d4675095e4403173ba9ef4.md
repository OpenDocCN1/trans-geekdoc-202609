# Listing II.4.8. Switching the places of the name and the pass fields

```
SELECT * FROM userslist WHERE id_user = 1
UNION
SELECT id_user, pass, name, email, url FROM userslist WHERE id_user = 2
ORDER BY id_user DESC
```

Because the names of the fields are formed by the first query, the switch places
in the password to the user name field (Fig. II.4.4).

![](bbox=[0.153, 0.342, 0.946, 0.523])

Fig. II.4.4. Displaying the password in the browser window

The UNION statement can only be used with SELECT queries; therefore, this type of
SQL injection is not destructive by itself. Nevertheless, if it produces a password to
the control panel, the consequences don't have to be described.

To prevent potential break-ins perpetrated using this type of SQL injection, all
numeric parameters must be carefully checked using regular expressions. In this in-
stance, the expression |[^\d]+|$ can be used, which is considered in detail in Sec-
tion II.2.8.
