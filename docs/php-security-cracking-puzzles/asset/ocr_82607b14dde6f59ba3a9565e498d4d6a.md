# II.1.4. Outputting Data in Three Columns

To output a table according to the variant shown in Fig. I.1.3, it is necessary to implement the counter ($counter) that would be reset to zero after reaching the defined value. When the counter value is set to zero, the <tr> tag is output (List II.1.7). At the moment the counter is reset to zero, for the string, </tr>, is output.

II.1.7. The first variant of the script that outputs a three-column table

```
<?php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Computing the number of elements in the array
$total = count($filename);
// Number of columns in the table
$numcols = 3;
$counter = 0;

echo "<table border = 1>";
for($i = 0; $i < $total; $i++) {
    if($counter == 0) echo "<tr>";
    if ($counter == $numcols) {
        echo "</tr>";
        $counter = 0;
    }
    echo "<td>".$filename[$i]."</td></td>";
}
```
