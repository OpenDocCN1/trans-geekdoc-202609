# II.1.12. Displaying Numbers in the Currency Format

The easiest way to display numbers in the currency format is to use the number_format() function (Listing II.1.23).

### Listing II.1.23. Using the number_format() function

```
<?php
echo number_format(18439529234.5678, 2, '.', '');
?>
```

# II.1.13. Replacing bbCode Characters

It is easiest to replace bbCode characters using the typical str_replace() function shown in II.1.24.

### Listing II.1.24. Using the str_replace() function

```
<?php
$text = 'This is [b]bold[/b] text';
$text = str_replace("[b]", "<b>", $text);
$text = str_replace("[/b]", "</b>", $text);
echo $text;
?>
```

In this case all characters are replaced, including the ones enclosed in tags (Fig. II.1.3).
