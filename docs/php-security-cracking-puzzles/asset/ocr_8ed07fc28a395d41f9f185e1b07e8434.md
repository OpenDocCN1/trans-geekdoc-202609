# I.3.3. Vulnerability in an Upload Script

Listing I.3.1 shows the upload.php script for uploading files. This script contains a vulnerability. Find this vulnerability and exploit it to destroy the upload.php file. Develop an upload script protected against this vulnerability.

> The script shown in Listing I.3.1 can be found in the /scripts/3/upload.php file on the accompanying CD-ROM.

# Listing I.3.1. Vulnerable script for uploading files to the remote server

```
<form enctype='multipart/form-data' method=post>
<input type="file" size="32" name="filename"><br>
<input class="button" type="submit" value='Upload'>
</form>
<?php
// Form handler
if(!empty($_FILES['filename']['tmp_name']))
{
    // Saving the file in the current directory
    if(copy($_FILES['filename']['tmp_name'],
        $_FILES['filename']['name'])
    {
        echo "The file has been uploaded successfully - <a href="" .
            $_FILES['filename']['name'] . " ">" .
            $_FILES['filename']['name']."</a>";
    }
}
?>
```
