To check that operation with cookies is enabled, it is necessary to set the test cookie value using the setcookie() function. In this case, the setcookie() function takes two parameters. The first parameter is the cookie name, and the second parameter is the cookie value.

# II.5.5. Forging Cookies

To forge a cookie, it is necessary to send the HTTP header of the following format:

```
Cookie: name1 = value1; name2 = value2; ...
```

Here, name1, name2, and so on, are cookie names; value1, value2, and so on, are their values. This operation can be carried out using the browser, allowing you to edit cookies, or using specialized programs. In this example, this task will be carried out using the PHP script that will send a query and obtain a server response using sockets.
