# I.1.12. Displaying Numbers in the Currency Format

Assume that you have the following number: 18439529234.5678. Output this number in the currency format, rounding it two decimal places and inserting blank characters as the thousand separators, like this: 18 439 529 234.57.

# I.1.13. Replacing bbCode Characters

Assume that you have the following text: This is [b]bold[/b] [b]text. Replace the bbCode characters ([b] and [/b]) with their HTML equivalents (<b> and </b>) without using regular expressions. In other words, the problem must be solved using only string functions.
