# Listing II.5.3. Output the list of currently present visitors

```
<?php
// Establishing the database connection
include "config.php";
// Outputting the names of all visitors for whom
// there are records in the session table
$query = "SELECT FROM session";
$auth = mysql_query($query);
if(!$$auth) exit("<p>Error requesting the session table</p>");
// If someone is present, outputting the table
if(mysql_num_rows($query) > 0) {
echo "<table>";
while($auth = mysql_fetch_array($auth)) {
    // If the user hasn't registered, outputting
    // the anonymous string instead of the name
    if(empty($auth['user'])) echo "<tr><td>Anonymous</td></tr>";
    else echo "<tr><td>" . $auth['user'] ."</td></tr>";
}
echo "</table>";
}
?>
```

The loop forms the table with the names of the site's visitors. If the user name is unknown (e.g., the user hasn't been authorized), then it is necessary to display the `Anonymous` name.

# II.5.2. Custom Sessions Mechanism

The custom sessions mechanism can be implemented by registering handlers using the `session_set_save_handler()` function, which has the following syntax:

```
session_set_save_handler(open, close, read, write, destroy, gc);
```

The function accepts six string arguments, which are the names of handler functions. These names have the following meanings:

+   - open The method that executes at session initialization in the client code by applying the `session_start()` function. The code for establishing the database connection must be placed here.
