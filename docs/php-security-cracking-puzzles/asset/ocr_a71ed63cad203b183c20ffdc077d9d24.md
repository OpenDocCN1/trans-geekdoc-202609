# I.3.5. Saving Text and Graphics Files

The download counter script solves another problem related to system security: Namely, it hides the true path to files from the user. You can hide them deeply nested somewhere within the system; the visitor will see only the download page address.

Nevertheless, if the download file is a text file, the browser won't display the download window. Instead, the browser will load the file, thus not only disclosing the path to the file but also forcing the user to save the file on his or her own using the Save As... menu. The same is true for graphics files, as well as for all files the browser can open and display. Develop a script for storing text and graphics files, providing an appropriate window for downloading files (Fig. 1.3.4).
