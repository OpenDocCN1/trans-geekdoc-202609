## Chapter I.4: MySQL and SQL Injections

![](img/a893312ec68b8170fe567f785e95c06e_42_0.png)

The MySQL database management system is the de facto standard because of its high performance, distribution by open source license, and popularity among host providers. By using databases when developing Web applications, you can considerably improve your performance. However, careless use of MySQL introduces serious vulnerabilities. These vulnerabilities are known as SQL injections.
