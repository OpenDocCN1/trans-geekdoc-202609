# II.5.7. Cross Cross-Site Scripting

Cross-site scripting (XSS) is based on a vulnerability caused by not filtering data entered by the user. This vulnerability allows JavaScript scripts to be run. In List- I.5.5, the vulnerability is related to the string shown in Listing II.5.14.

Listing II.5.14. Listing demonstrating XSS vulnerability

```
<?php
...
    echo "<a href=${_SERVER[PHP_SELF]?name=$data[0]>
        htmlspecialchars($data[0]).</a><br>";
...
?>
```

The reference name is processed by the htmlspecialchars() function, but the name parameter isn't processed. If the intruder supplies the new_user<script>alert('Hello world!')</script> string instead of this pa-meter, this would allow him or her to execute the JavaScript script, displaying
