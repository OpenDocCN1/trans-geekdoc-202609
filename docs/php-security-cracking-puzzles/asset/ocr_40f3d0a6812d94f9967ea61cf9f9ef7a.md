# Chapter II.14: Teltale Scripts

![](bbox=[0.275, 0.115, 0.725, 0.597])

For Windows to treat PHP scripts as executable programs, a PHP interpreter must be linked to the .php extension. This can be done as follows: Select any PHP file and select the Properties item in the context menu (Fig. II.14.2).

Click the Change button, and click the Browse button in the dialog window that opens. In the Open with... file selection dialog window, navigate to the C:\php\php.exe file and click the Open button (Fig. II.14.3).

> The following three executable modules are located in the PHP root directory: php.exe, php-cgi.exe, and php-win.exe. The php-cgi.exe file is used for working with a Web server, and it processes requests to PHP scripts when PHP is installed as a CGI binary and not as a module. The php.exe file is used for processing scripts in the console. When it run, the console window opens, in which all script output is displayed. The php-win.exe file is used to run PHP scripts without opening the console window as a process. If you don't want that PHP scripts open windows when run, use this PHP interpreter.
