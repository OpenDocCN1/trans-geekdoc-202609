### II.2.1. Removing Tags

HTML tags can be removed using regular expressions with the `preg_replace()` function. The function’s general format is as follows:

```
preg_replace (mixed pattern, mixed replacement, mixed subject [, int limit)
```

The function searches the `subject` string for a substring matching the `pattern` regular expression and replaces the found substring with the `replacement` argument. The optional `limit` parameter specifies the number of substitutions to make. If this parameter is not set or is set to -1, all matches are replaced. The replacement argument can contain references of the `\n` type; each reference of this type is replaced by the substring matching the regular expression in the parentheses. The `n` parameter can take values from 0 to 99; `\0` corresponds to the entire pattern. If a substring is found that matches the pattern, the function returns the modified value of the subject; otherwise, the original value of the string is returned.

The first three parameters of the preg_replace() function can be one-dimensional arrays. When an array with string keys is processed, the keys are referenced in the order, which they are located in the array.

When the pattern and replacement parameters are arrays, preg_replace() sequentially extracts a pair of elements from both arrays and uses them for search and replace. If the replacement array has more elements than the pattern array, the missing elements in it are replaced with null strings. If the pattern parameter is an array and the replacement parameter is a string, the target string is compared with each element of the pattern array, and any matches are replaced with the replacement string. In other words, each element of the pattern array is used as the pattern, and the replacement string is fixed. The option, which pattern is a string and replacement is an array, is meaningless.

Perl-compatible regular expressions must be enclosed in delimiter characters. In II.2.1, the single quote is used as the delimiter. Any symbol other than an alphanumeric character or backslash can be used as the delimiter. A delimiter character used within a regular expression, must be preceded by an escape character, the backslash. The ending delimiter may be followed by modifiers that affect the entire regular expression. The `i` modifier specifies that the regular expression is case-insensitive; the `s` modifier means that the regular expression takes multiple lines.
