To sort the obtained file, its lines are loaded into an array using the file() function, and the array is sorted using the sort() or rsort() functions, depending on the desired sort order. An example of a script for sorting the array in ascending order is shown in Listing II.3.22.

# Listing II.3.22. Sorting the lines in the text.txt file

```
<?php
// The file's name
$filename = "text.txt";
// Reading the file's contents
$lines = file($filename);
// Sorting the records by index
sort($lines);
// Removing all trailing spaces
array_walk($lines, 'trim_array');
// Saving the updated results
$fd = fopen($filename, "w");
fwrite($fd, implode("r\n", $lines));
close($fd);

function trim_array(&$item, $key) {
    $item = trim($item);
}
?>
```
