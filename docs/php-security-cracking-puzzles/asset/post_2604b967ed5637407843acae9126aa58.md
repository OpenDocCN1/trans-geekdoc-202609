## II.4.10. Deleting Several Items

To delete several items from the products table, the following SQL query must be constructed:

```sql
DELETE FROM products WHERE id_product IN (4, 6, 8, ..., 20)
```

This query removes all records with a value for id_product primary key that matches one of the values in IN operator.

## II.4.11. Storing MP3 Files in a Database

To store MP3 files in a MySQL database, create a table named mp3, one of whose fields will be of the binary large object (BLOB) type. BLOB fields are intended for storing binary data, and information stored in them will not be damaged by applying different encodings. The mp3 table will consist of the following three fields:

- id_mp3 — Primary key with the AUTO_INCREMENT attribute
- name — File's
- content — Binary contents of an MP3 file

### II.4.33. The mp3 table

```sql
CREATE TABLE mp3 (
id_mp3 INT(11) NOT NULL auto_increment,
name tinytext NOT NULL,
content longblob NOT NULL,
PRIMARY KEY (id_mp3)
) TYPE = MyISAM;
```

> MP3 files are usually large; therefore, make sure that all server directives allow you to work with them. In particular, the post_max_size and the upload_max_filesize directives in the php.ini file must allow the necessary volume of data to be sent using the POST method and the file upload facility, respectively. Moreover, the max_allowed_packet directive in the my.ini file must be set to allow long SQL query manipulations.
