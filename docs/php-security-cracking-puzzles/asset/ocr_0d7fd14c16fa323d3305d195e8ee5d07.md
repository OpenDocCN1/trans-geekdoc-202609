As you can see in Listing II.3.30, the handler consists of the following three blocks:

+   - The data verification block
- The block to check that the name is not already in use
- The user registration block

The data verification block checks whether the required fields (name and password) are filled, whether the passwords match, and whether any entered email address is of the proper format.

The second block opens the text.txt file and read the names of registered users from it. If the name entered by the new user matches one of the names in the file, the script's execution is interrupted and the user is advised to select another name.

The last block formats a data line in the configuration using the test.txt file and appends this record to the file. Afterward, the script is reloaded to zero out the POST data. If no reload is done, when the user refreshes the page the procedure of adding data to the test.txt file will be repeated.
