Two arrays, $rus and $eng, are declared in the script, containing Russian and English letters, respectively, that look similar. Because user names are made entirely from Russian or English letters, the following three situations for terminating the registration process are checked:

+   - The name of the new user is the same as one in the authors table.
- The name of the new user matches one in the authors table after all English letters in the name are replaced with Russian ones.
- The name of the new user matches one in the authors table after all Russian letters in the name are replaced with English ones.

If none of these conditions is met, the new user name is unique to the system and is added to the authors table.

# II.7.9. Session-Based Authorization

If the number of records in the database meeting the login and password criteria is greater than zero, the user is allowed to enter the system: The login and password are stored in a session. The bug in the registration system is that the number of records is stored in the temporary variable $total, which is not initialized. If the register_globals directive in the php.ini configuration file is set to On, it is possible to pass a value directly to the variable using the POST or GET method. This means that all that must be done to enter the system is the value of the total parameter
