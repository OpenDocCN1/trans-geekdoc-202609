# Chapter II.9: File Transfer Protocol 313

The function accepts the following three parameters: the link identifier returned by the ftp_connect() function, the user name, and the password. The function returns true for a successful login and false for an unsuccessful one.
An FTP connection is closed using the ftp_close function, whose general syntax is the following:

```
void ftp_close(resource link)
```

The function accepts the link identifier of an open FTP connection as the only parameter. Listing II.9.1 shows a script for opening an FTP connection to a remote server.

![](bbox=[0.068, 0.335, 0.146, 0.435])

When accessing an anonymous FTP server, the user name can be given as anonymous and an email address can be used as the password.

# Listing II.9.1. Connecting to an FTP server

```
<?php
// The FTP server's address
$ftp_server = "ftp.server.ru";
// The user name
$ftp_user = "user";
// The password
$ftp_password = "password";
// Setting the script's timeout to 120 seconds
set_time_limit(120);
// Attempting to connect to the FTP server
$link = ftp_connect($ftp_server);
if (!$link) echo("Failure to open a connection to $ftp_server FTP server");
// Registering on the server
$login = ftp_login($link, $ftp_user, $ftp_password);
if (!$login) echo("Failure logging onto the server.
Please check the login data.");

?>
```
