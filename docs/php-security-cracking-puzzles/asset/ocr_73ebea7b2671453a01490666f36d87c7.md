# Listing I.4.1. The userlist table

```
CREATE TABLE userslist (
id_user int(11) NOT NULL auto_increment,
name tinytext NOT NULL,
pass tinytext NOT NULL,
mail tinytext NOT NULL,
url tinytext NOT NULL,
PRIMARY KEY (id user)
) TYPE = MyISAM;
```

The userslist table has five fields with the following names:

+   - id_user — Master key of the table, which has the AUTO_INCREMENT attribute
- name — User name
