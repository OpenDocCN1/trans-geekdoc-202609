For a script to be launched by cron, the former has to be assigned the necessary execution permissions. In UNIX systems, this can be done using the chmod command.

As explained in Chapter II.9, access permissions in UNIX are assigned for three categories of users: owners, group members, and others. Each group can have the rights to read, write or modify, and execute or view a file.

An example of access rights denoted by this system may look like this: rwxrxr--. As explained in Section II.9.4, access permissions in UNIX can also be specified using octal numbers, with read rights denoted by the digit 4, write rights by 2, and execution rights by 1. Overall rights for a group are specified by a sum of these digits; thus, 7 denotes full access permissions to a file or directory. Using this format, the octal 0755 means that the directory owner has full rights (rwx), with all other users having rights to view files in and the contents of the directory (r-xr-x). The execution permissions (rwxr-xr-x or 0755) for the index.php file are assigned by executing the chmod command as follows:

```
chmod 755 index.php
```

Listing II.14 shows PHP code for executing this command.

# Listing II.14.2. Changing access permissions using PHP

```
<?php
chmod("index.php", 0755);
?>
```
