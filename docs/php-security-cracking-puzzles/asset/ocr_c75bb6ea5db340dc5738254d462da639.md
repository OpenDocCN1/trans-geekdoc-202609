# II.15.2. Page Preload Script

If visitors are sent directly to the 1.php page (Listing I.15.1) and have to wait until it is loading, they may think that the site hung up. Therefore, they should be redirected to the 2.php page (Listing II.15.2) first.

Listing II.15.2. The page preload script (2.php)

```
<?php
// This is the 2.php file.
echo
"<p>Computing the result may take some time. Please wait 5 seconds.</p>
// Redirecting to the 1.php page
echo "<HTML><HEAD>
<META HTTP-EQUIV='Refresh' CONTENT='0'; URL=1.php'>
</HEAD></HTML>"
?>
```

In this way, when the script from Listing II.15.2 is loaded, the message “Computing the result may take some time. Please wait 5 seconds.” is displayed to the visitor while the browser is waiting for the execution results. After 5 seconds, the browser is redirected to the 1.php page, and the “The results of the lengthy computation process” message is displayed.
