# Listing II.1.12. The contents of the $GET superglobal array

```
Array (
  [filename] => Array (
    [0] => all.php
    [1] => auth.php
    [2] => auth.txt
    [3] => base.txt
    [4] => chat.html
    [5] => config.php
    [6] => count.txt
    [7] => count_new.txt
    [8] => counter.dat
    [9] => counter.php
    [10] => create.php
    [11] => dat.db
  )
)
```

Thus, to obtain in the second.php file the $filename array with the same contents as in file.php, it is necessary to make an assignment:

$filename = $_GET['filename'];

However, it is not always convenient to pass data using the GET method. This is because the length of the address string is often limited to 8 KB by the Web server. Consequently, it is impossible to pass considerable data amounts. Furthermore, a long address string is inconvenient and allows even inexperienced users to easily forge data.
