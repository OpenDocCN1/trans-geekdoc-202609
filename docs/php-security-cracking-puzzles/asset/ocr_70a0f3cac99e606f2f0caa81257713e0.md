# ## II.7.1. File-Based Authorization

After the user name and password are entered, the user name is checked for being listed in the text.txt file. If the check result is positive, the password supplied by the user is compared with the password associated with the user name stored in the file. If they match, the form for editing data is displayed. The corresponding script is shown in Listing II.7.1.
