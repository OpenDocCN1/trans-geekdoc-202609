# I.10.2. Obtaining HTTP Headers from a Server

When working with remote host data, the entire body of the answer, which is a voluminous HTML page or a file, often does not have to be received. The only things necessary are the HTTP headers, which contain information about the server and the server's requirements for processing its contents (setting cookies, opening sessions, authentication requirements, etc.). Develop a PHP script for obtaining HTTP headers from a server.

# I.10.3. Determining the Remote File Size

One common Web task is determining the size of a file on a remote host. Develop a function for determining the size of a remote file without downloading the file and using only HTTP headers.
