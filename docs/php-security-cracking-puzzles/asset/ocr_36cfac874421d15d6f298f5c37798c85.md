The list is needed to hide and display different versions of the second dropdown list. Each version of the list is called product$i, where $i sequentially takes values from the messageIdList array. Moreover, each drop-down list is set to the $id attribute, which is the same as the current number $i. This makes the list easier to access from JavaScript. To hide a drop-down list, the value of the style attribute of the <select> tag must be set to display:none; to display a list, the value of style is set to display:block. Before you display the selected list, all lists must be hidden so that at each moment only one version of the second drop-down list is displayed. This operation is carried out by the handler of the onchange event of the first drop-down list.
