# Listing II.9.3. Listing files and subdirectories

```
<?php
// Opening a connection to the FTP server
require once("config.php");
// Obtaining all files in the root directory
$file_list = ftp_rawlist($link, "/");
// Displaying the $file_list array
foreach($file_list as $line) echo $line.\<br>";
?>
```

The results of the Listing II.9.3 script operation may look as follows:

| drwx------ | 9 root 512 | Dec 27 19:07 | |
| drwx------ | 9 root 512 | Dec 27 19:07 | |
| -rw-r--r-- | 1 root 27154 | Jan 6 13:30 readme.txt |
| -rw-r--r-- | 1 root 1144 | Dec 31 11:14 licence.txt |
| -rw-r--r-- | 1 root 73373 | Jan 6 12:23 version.txt |
| drwx------ | 2 root 512 | Sep 18 2003 db |
| drwx-xr-x | 2 root hosting 512 | Jan 6 01:48 logs |

> The ftp_rawlist() function returns information in the format of the UNIX ls utility executed with the -l switch. The ls utility returns the contents of the current directory in the expanded format.

The first substring of each entry is the drwx------ format; it is ten characters long and defines the file type and its access permissions. The first character defines the file type, which can be one of the following:

+   - A A regular file
- d A directory
- l A symbolic link
- s A socket
- p A named channel

Only the first two types are encountered in actual FTP operations: directories and regular files.
