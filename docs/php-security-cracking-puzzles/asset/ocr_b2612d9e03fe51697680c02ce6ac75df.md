# I.2.6. Verifying URLs

Develop a HTML form whose handler would verify the supplied uniform resource locator (URL). The Web address may be given with or without the protocol; that is, both http://www.softtime.ru and www.softtime.ru are allowed. It is necessary to take into account that the address might contain a path and parameters after the domain name, for example, http://www.softtime.ru/php5/index.php?fid_article=43.
