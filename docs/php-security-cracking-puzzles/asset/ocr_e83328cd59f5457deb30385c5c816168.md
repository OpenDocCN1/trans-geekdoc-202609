# I.15.3. Emulating the Tar Utility

Section 13.4 considered working with the Tar and Gzip utilities. The Tar utility,
how, is rarely available in Windows. Develop a script emulating the Tar utility,
that is, joining files into one large file and doing the reverse conversion that un-
packs the file.

> NOTE All files in the archived directory are text files. The archive produced by the script
does not have to be compatible with the real Tar utility.
