# I.2.13. Interpreting bbCode Tags

Tags enclosed in square brackets, also called phpBB-style tags (phpBB is a popular forum), are widely used on the Internet. The convenience of using such tags is that all HTML tags can be prohibited by converting them into the safe form using the htmlspecialchars() function, leaving visitors to use their equivalents instead. For example, it is possible to use [i] instead of <i> and [code] instead of <code>. Tags enclosed in square brackets can be replaced by by tags in angle brackets only after the text has been converted using the htmlspecialchars() function. This conversion is usually applied to [url] tags that have the following syntax:

```
[url=link]name[/url]
```

In the course of output, this template must be converted into the following format:
<a href=link>link name</a>

As another example, suppose that the following form of the tag is used:
[url]link[/url]

The following hyperlink will be output to the page:
<a href=link>link</a>
