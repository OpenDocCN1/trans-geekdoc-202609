## II.6.6. Protecting against Download Managers

Consider one of the popular download managers, whose user agent has the following format:

-   Teleport Pro/1.29

To achieve the formulated goal, it is enough to place the string presented in Listing II.6.10 in the beginning of the page.

Listing II.6.10. Protecting against download managers

```php
<?php
if(substr($_SERVER['HTTP_USER_AGENT'], 0, 8) == "Teleport") exit();
?>
```

The method of protecting against undesirable downloading of the site's contents by download managers is not universal. Because the $_SERVER['HTTP_USER_AGENT'] string is formed by the client — to be precise, by the download manager whose main goal is to download the page at all costs — this string is often forged or even remains blank.

## II.6.7. Forging User Agents

To forge a user agent, it is necessary to forge the User-Agent header. For example, a Windows XP user might have the following user agent:

```
Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)
```

<?php
$hostname = "host";
$path = "/path/index.php";
$line = "";

// is passed in the $hostname parameter
$fp = fsockopen($hostname, 80, $errno, $errstr, 30);
// Checking whether the connection has been established successfully
if (!$fp) echo $errstr ($errno)<br />

else {
    // Forming HTTP headers for transmission
    // to the server
    $headers = "GET $path HTTP/1.1\r\n";
    $headers .= "Host: $hostname\r\n";
    // Forging the user agent
    // masquerading as a Windows XP user
    $headers .= "User-Agent: Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1\r\n";
    $headers .= "Connection: Close\r\n";
    // Sending an HTTP request to the server
    fwrite($fp, $headers);
    // Receiving the response
    while (!feof($fp)) {
        $line = fgets($fp, 1024);

    fclose($fp);
