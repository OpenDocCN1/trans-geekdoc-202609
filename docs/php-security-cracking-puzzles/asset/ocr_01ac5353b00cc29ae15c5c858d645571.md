# # Chapter I.4: MySQL and SQL Injections

![](bbox=[0.068, 0.191, 0.882, 0.355])

The MySQL database management system is the de facto standard because of its high performance, distribution by open source license, and popularity among host providers. By using databases when developing Web applications, you can considerably improve reliability and performance. In addition, it considerably reduces the time required for application development. However, careless use of MySQL introduces serious vulnerabilities related to the possibility of inserting unauthorized fragments into SQL queries. Vulnerabilities of this type are known as SQL injections.
