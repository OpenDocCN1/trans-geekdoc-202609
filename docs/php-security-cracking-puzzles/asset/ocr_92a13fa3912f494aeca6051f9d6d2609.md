# # Chapter I.13: UNIX

![](bbox=[0.105, 0.146, 0.943, 0.313])

The UNIX operating system is the cornerstone of the Internet, because the overwhelming majority of the Web servers are run under some type of UNIX-like operating system. UNIX-like operating systems come in commercial and freeway varieties. Their common features are the command line interface and the canonical operating system commands, which are supported by all clones of this legendary operating system.

In PHP, operating system commands can be executed using one of the following functions: `exec()`, `system()`, and `passthru()`. (For brevity, these functions will be referred to as the `exec` family of functions.)

> For security reasons, the feature for executing the `exec` family of functions is often disabled on Internet servers. Another security measure enables the safe mode, which automatically disables the use of these functions.

All examples from this chapter can be found in the /scripts/12 directory on the accompanying CD-ROM.
