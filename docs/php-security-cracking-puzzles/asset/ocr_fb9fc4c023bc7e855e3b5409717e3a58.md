Code %20 denotes a space. It is not necessary to remember the codes for all prohibited characters, because a URL string can be cleaned up by processing its text with the urlencode() function.

The UNION statement, available as of MySQL 4.0, can be used to combine two queries of the same format (Listing II.4.3).

# Listing II.4.3. Using the UNION statement

```
SELECT * FROM userslist WHERE id_user = 1
UNION
SELECT * FROM userslist WHERE id_user = 2
```

The SQL injection code is set in bold. The table produced by this query will contain records from both the first and the second queries. A URL query in this case may look as follows:

```
user.php?7id_user=1%20UNION%20SELECT%20*
%20FROM%20users%20WHERE%20id_user%20=%202
```

Nevertheless, it displays information about the user associated with primary key 1 in the browser window (Fig. II.4.2).

The query from Listing II.4.3 returns two records: one for the user with primary key 1 and the other for the user with primary key 2 (Listing II.4.4).

# Listing II.4.4. Records returned by the query from Listing II.4.3

```
1, 'cheops', *****, 'cheops@mail.com', 'http://www.softtime.ru'
2, 'barton', *****, 'barton@mail.com', ''
```
