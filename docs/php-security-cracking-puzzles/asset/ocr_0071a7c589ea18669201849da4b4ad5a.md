# II.1.10. The Calendar

When forming a calendar, the main problem is that the month often starts in the middle of a week. A calendar is a table, in which the number of columns equals the number of days in a week and the number of rows equals the number of weeks in a month. Therefore, it is expedient to form a calendar as a two-dimensional array. The script to be developed must contain three blocks:

+   - The first week
- Subsequent weeks
- The calendar output

The script that implements the output of the calendar for the current month in the American format is shown in Listing II.1.19.
