# II.11.6. Determining the Mail Relay's Address

The names of the mail relays of a specific SMTP server can be determined by the script in Listing II.11.10. The script displays a list of the mail relays and their priorities.

# II.11.10. Obtaining a list of mail relays

```
<?php
// An email address
$email = "mail@yandex.ru";
// Breaking the address into a two-element array:
// the mailbox name and the server name
$arr = explode("@", $email);
// Placing the mail server name into the $host variable
$host = $arr[1];
// Determining the mail relays of the $host server and
// displaying them, indicating the priorities
getmxrr($host, $mxostsarr, $weight);
echo
echo "Email on the server $email is posted by the following hosts: <br>";
for ($i = 0; $i < count($mxostsarr); $i++) {
    echo ("$mxostsarr[$i] = $weight[$i]<br>");
}
?>
```

The list of the server's mail relays is obtained using the getmxrr() function. Its general syntax is the:

```
string getmxrr(string hostname, array mxhost, {}, array weight);
```

The function accepts the host name in the given domain as a parameter and fills the mxhost array with the names of the mail relays of this domain. If the optional weight array argument is specified, the function fills it with preferences for each corresponding relay. The list of mail relays used, for example, by the Yandex SMTP server for posting messages returned by the script in Listing II.11.10 will be the following:

```
mx2.yandex.ru = 10
mx1.yandex.ru = 0
```
