# ## II.3.1. Uploading Files

To make an unrestricted number of fields for selecting files to upload available, you will have to use the JavaScript client language to dynamically create an HTML form (Listing II.3.1). The script requires that the directory, in which the Web application is located, contains a subdirectory files whose access permissions allow the script to write to it.

> The Web application is constructed to contain the HTML form and its handler in the same file. However, it is possible to place the HTML form and the handler into separate files.

Listing II.3.1. Uploading an unrestricted number of files

```
<form enctype='multipart/form-data' method=post>
<table>
<tr>
<td><input type="file" size="50" name="att[]" class="input></td></td>
```
