# ## II.14.1. Monitoring a Link on a Remote Page

A possible solution to the problem is to load the contents of the page and use a regular expression to verify the presence of the link. A script for implementing this type of mass mailing may look like the one shown in Listing II.14.1.

Listing II.14.1. Monitoring a link on a remote page

