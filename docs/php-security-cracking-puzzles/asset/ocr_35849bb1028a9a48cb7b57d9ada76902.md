```
Array

  [9] => Content-Type: text/html;charset=ISO-8859-
```


The first line, header 0, is a standard server replying the user that the request was successfully processed (reply code 200). If the requested resource does not exist, reply code 404 is returned (HTTP/1.1 404 Not Found).

Header 1, Date, provides the date and the document was formed on the server; this information is necessary for the caching mechanism, which is considered-later.

Header 2, Server, provides information about the type and version of the Web server. Thus, the first three headers in Listing II.10.5 tell you that the http://www.php.net portal is run by an Apache 1.3.26 Web server using UNIX and PHP 4.3.3 to serve back-end pages.

Header 3, X-Powered-By, tells you that the page was generated using PHP 4.3.3. Header 4, Last-Modified, provides information about when the page was last modified. This HTTP header is not pertinent for dynamically generated site contents.

Header 5, Content-Language, informs you that the contents sent to the browser are in English in this example.
