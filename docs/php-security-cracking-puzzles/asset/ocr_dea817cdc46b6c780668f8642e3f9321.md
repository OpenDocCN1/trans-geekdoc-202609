# II.7.6. Protecting Text Files from Being Viewed
in a Browser

Text files can be stopped from appearing in the browser by creating the .htaccess file shown in Listing II.7.11.

# Listing II.7.11. The .htaccess file

```
<Files "*.txt">
    deny from all
</Files>
```
