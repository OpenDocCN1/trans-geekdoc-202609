# I.7.4. A Dictionary Attack on Passwords

If you carefully considered the previous task and accomplished it, you will have discovered that guessing even the shortest password takes considerable time. However, users rarely make a meaningless password. The password typically is a word, sometimes padded by several digits. This provides rich possibilities for dictionary attacks. A well-chosen dictionary allows someone to discover passwords in a reasonable amount of time. Guess the passwords with the hash codes shown in List-7.1 using the standard dictionary of the Linux operating system. This dictionary can be found in the /usr/share/dict/linux.words file.

# I.7.5. Password Generator

The two preceding tasks clearly demonstrate that short and meaningful passwords can be guessed quickly and easily. The way out of this situation is the restriction on the password length. Registration system might require users to supply passwords no shorter than six characters, containing both letters and digits. However, the most efficient protection is automatic generation of longer and highly-protected passwords. Develop a small Web application for generating such passwords (Fig. I.7.5).

```
http://localhost/1.php - Microsoft Internet Explorer
```
