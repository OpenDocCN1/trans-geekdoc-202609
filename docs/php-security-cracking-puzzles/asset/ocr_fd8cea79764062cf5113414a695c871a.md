# I.8.7. Determining the Exchange Rate History

In addition to currency exchange exchange rate information, the site of the European Central Bank provides information about the currency exchange rate history since 1999. The information is available as a 2-MB XML file that can be downloaded from http://www.ecb.int/stats/euroxfref/euroxfref-hist.xml.

Create a script to download the currency exchange rate history of the euro against the dollar for a 1-month period from the current date, then display it as a table (Fig. I.8.9) and as a bar graph (Fig. I.8.0).

Keep in mind that no trades are held weekends and holidays, so the number of citations for the month will be fewer than the number of days in the corresponding period.
