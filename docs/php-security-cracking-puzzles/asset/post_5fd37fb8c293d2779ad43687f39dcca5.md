# I.4.5. User Deletion and SQL Injections

Assume that a service for automatic deletion of user registration information is implemented for the user registration system described in Section I.4.1. The registered user can enter his name and password into a form, after which that user's information will be automatically deleted from the system (Listing I.4.5).

> NOTE
> The script shown in Listing I.4.5 can be found in the /scripts/4/4.5/1.php file on the accompanying CD-ROM.

# Listing I.4.5. The system for removing users

```html
<table>
<form method="post">
<tr>
<td>Name:</td>
<td><input type="text" name="name" value="<?= echo $_POST['name']; ?>"></td>
</tr>
<tr>
<td>Password:</td>
<td><input type="password" name="pass" value="<?php echo $_POST['pass']; ?>"></td>
</tr>
<tr><td>&nbsp;</td><td><input type="submit" value='Remove' /></td></tr>
</form>
</table>
```

```php
<?php
// Establishing the connection to the database
require_once("config.php");

if(!empty($_POST)) {
    // Removing the user name
    // if the name and password match in the system
    $query = "DELETE FROM userslist
             WHERE pass = '" . $_POST['pass'] . "' AND
             name = '" . $_POST['name'] . "'";
    if(mysql_query($query)) {
        echo "User " . $_POST['name'] . " has been successfully deleted<br>";
    }
}

echo "List of users:<br>";
$query = "SELECT * FROM userslist
          ORDER BY name";
$usr = mysql_query($query);
if(!$usr) exit("Error - " . mysql_error() . "");
while($usr = mysql_fetch_array($usr)) {
    echo $usr['name']."<br>";
}
?>
```

The interface of this small Web application is shown in Fig. I.4.5. Using the script in Listing I.4.5, remove all users from the system. Note that to succeed it is not necessary to know even a single user password.

Listing I.4.6 presents a database containing two tables:

- catalogs — Table of directories of spare computer parts (Fig. I.4.6)

Listing I.4.6. The catalogs and products tables

```sql
CREATE TABLE catalogs (
  id_catalog int(11) NOT NULL auto_increment,
  name tinytext NOT NULL,
  PRIMARY KEY (id_catalog),
  FULLTEXT name (name)
);
CREATE TABLE products (
  id_product int(11) NOT NULL auto_increment,
  name tinytext NOT NULL,
  price decimal(7,2) default '0.00',
  count int(11) default '0',
  mark float(4,1) NOT NULL default '0.0',
  description text,
  id_catalog int(11) NOT NULL default '0',
  PRIMARY KEY (id_product),
  KEY id_catalog (id_catalog),
  FULLTEXT KEY search (name,description)
);
```

The catalogs table is intended for storing directories. It has two fields:

- id_catalog — Primary key, AUTOINCREMENT
- name — Name

The products table is intended for storing information about parts. It has seven fields:

- id_product — Primary key, AUTOINCREMENT
- name — Name
- price — Price
- count — Number
- mark — Mark
- description — Description
- id_catalog — Foreign key to catalogs
