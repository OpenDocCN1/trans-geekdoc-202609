# II.14.3. Watching for New Files

The best way to traverse a directory and its subdirectories is to recursively descend the directory tree. This will be done using the scan_dir() function, which extracts the contents of the current directory and displays the names of files created or modified during the current day. The creation or last modification time of the scripts is checked using the filetime() function. If a function encounters a subdirectory, it calls itself recursively, passing the subdirectory as the argument. Listing II.14.8 shows a script recursively descending the subdirectories in the root catalog of system.
