### II.11.1. Sending Email from a Site

Mail in PHP is sent using the `mail()` function, whose general format is the following:

```
mail(string to, string subject, string body [,string headers], [,string parameters])
```

The function accepts the following parameters:

- to — The recipient's email address
- subject — The subject of the message
- message — The message text
- headers — Additional headers
- parameters — Additional parameters

If the fourth parameter, `headers`, is not specified, no additional mail headers are attached to the message. However, the message format often needs to be changed from plain text to HTML text, or to have a certain character set specified. The message format and character set are specified with the help of the `Content-Type` and `charset` mail headers, respectively, as follows:

```
Content-Type: text/html; charset = ASCII\r\n
```

To mail a message in, for example, Greek, Greek International Standard Organization (ISO) encoding must be specified instead of ASCII.

Thus, a script for posting email messages may look like the one shown in Listing II.11.1.

#### Listing II.11.1. Using the mail() function to post email messages

```php
<?php
$theme = "Site report";
$message = "<html>
<head></head>
<body>
 The message posted on ".date("m.d.Y H:i:s")."<br>
The size of the sending script is:
".filesize($_SERVER['PHP_SELF'])".
</body>
</html>";
$message = convert_cyr_string($message, 'w', 'k');
$headers = "Content-Type: text/html; charset=ASCII\r\n";
if(mail($to, $subject, $message, $headers)) {
    echo "Message successfully posted.";
} else {
    echo "Error posting the message.";
}
?>
```

When the message is received, the server’s address will be used as the sender’s address. This can be prevented by specifying any return address with the help of the From mail header, as follows:

From: name <e-mail>

The name parameter is any name to be shown by the client mail agent as the sender’s, and the e-mail parameter is the return email address. A script to form the necessary headers variable may look like the one shown in Listing II.11.2.

#### Listing II.11.2. Forming mail headers

```php
<?php
$headers = "Content-Type: text/html; charset = ASCII\r\n";
$headers .= "From: server someone@somewhere.com";
?>
```

An email message sent with the headers shown in Listing II.11.2 will be presented as sent by server from someone@somewhere.com.

### II.11. Sending Email with Attachments

To post a message with an attachment, create an HTML form containing the following fields: a text field, named mail_to, for the destination address; a text field, named mail_subject, for the message subject; a textarea field for the message body; a file field for the file to attach; and a button for sending the data from the HTML form to the handler. The corresponding script is shown in Listing II.11.3.

#### Listing II.11.3. The script for posting an email with an attachment

```php
<?php
if(!empty($_POST)) 
{
    // The HTML form handler
    include "handler.php";
}
?>
<table>
<form enctype='multipart/form-data' method='post'>
<tr>
    <td width="50%">To:</</td>
    <td align="right"><input type="text" name="mail_to" maxlength="32"></td>
</tr>
<tr>
    <td width="50%">Subject:</</td>
    <td align="right"><input type="text" name="mail_subject" maxlength="64"></td>
</tr>
<tr>
<td colspan="2">
  Message:<br><textarea cols=50 rows=8 name="mail_msg"></textarea>
</td>
</tr>
<tr>
<td width="50%">Photo:</</td>
<td align="right"><input type="file" name="mail_file" maxlength="64"></td>
</tr>
<tr colspan="2"><input type="submit" value='Send'></td>
</tr>
</form>
</table>
```

The handler.php file, included at the beginning of the script, is the form handler. Its contents are shown in Listing II.11.4. 

#### Listing II.11.4. The HTML form handler

```php
<?php
if (empty($_POST['mail_to'])) exit("No mail to address provided!");
// // Using a regular expression to verify the address format.
$pattern = "/^([0-9a-z\-]+\.).[a-z]{2,6}$/i";
if (preg_match($pattern, $_POST['mail_to'])) {
  exit("The address must be in the format somebody@server.com!");
}
$_POST['mail_to'] = htmlspecialchars(stripslashes($_POST['mail_to']));
$_POST['mail_subject'] = htmlspecialchars(stripslashes($_POST['mail_subject']));
$_POST['mail_msg'] = htmlspecialchars(stripslashes($_POST['mail_msg']));

  // Uploading the file

if (copy($FILES['mail_file']['tmp_name'], $path)) $picture = $path;
}
$thm = $_POST['mail_subject'];
$msg = $_POST['mail_msg'];
$mail_to = $_POST['mail_to'];
// Posting the message
if (empty($picture)) $mail($mail_to, $thm, $msg);
else send_mail($mail_to, $thm, $msg, $picture);
// An auxiliary function for posting
// a message with an attachment
function send_mail($to, $thm, $html, $path)
{
$fp = fopen($path,"r");
if ($fp)
{
print "Error reading the file $path";
exit();
}
$file = fread($fp, filesize($path));
close($fp);

$boundary = "--".md5(uniqid(time())); // Generating a separator
$headers = "MIME-Version: 1.0\n";
$headers .= "Content-Type: text/multipart; boundary=\$boundary\n";
$multipart = "--$boundary\n";
$code = 'ASCII'; // Or code = 'swe7';
$multipart .= "Content-Type: text/html; charset=$code\n";

mail($to, $thm, $multipart, $headers);
}
?>
```

### II.11.3. Mass Mailing

Mass mailing can be implemented in the following ways:

- Sending messages in a loop, sequentially through email addresses. This method is used when a unique message is sent to each address.
- Sending messages listing the recipient addresses in mail headers. This method is used when the same message is sent to all recipients.

Listing II.11.5 shows a script using the first method.

#### Listing II.11.5. Sending messages in a loop

```php
<?php
// The subject of the message
$theme = "Subject";
// The contents of the message
$body = "Message body";
// The name of the file with the email addresses
$filename = "mail.txt";
// Reading the contents of the file into the
// $listemail array using the file() function
$listemail = file($filename);
// Sending messages in a loop
foreach($listemail as $email)
{
    mail(trim($email), $theme, $body);
}
?>
```

Using the mail() function is a rather labor- and resource-intensive procedure. Posting more than 100 messages using this function may take a significant amount of time. This may be unacceptable if the posting script is linked to the script for adding new forum or bulletin board messages. In this case, it is better to list the recipient addresses in Cc or Bcc headers. With the first option, each recipient will see the other recipients; with the second option, will not. A script for implementing this type of mass mailing may look like the one shown in II.11.6.

> Any number of Bcc or Cc headers can be added to a message. Each header accepts one address. For example, Bcc: somebody@mail.com\r\n.

#### Listing II.11.6. A script for mass mailing using mail headers

```php
<?php
// The subject of the message
$theme = "Subject";
// The contents of the message
$body = "Message body";
// The name of the file with the email addresses
$filename = "mail.txt";
// Reading the contents of the file into the
// $listemail array using the file() function
$listemail = file($filename);
// Forming the mail header in a loop
$headers = "";
foreach($listemail as $email) {
    $headers .= "Bcc: " . trim($email) . "\r\n";
}
mail("sender@example.com", $theme, $body, $headers);
?>
```
