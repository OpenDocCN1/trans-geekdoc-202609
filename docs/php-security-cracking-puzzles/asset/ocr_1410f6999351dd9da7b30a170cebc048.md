# Listing I.10.1. The HTML form

```
<form method=post>
Name: <input type=text name=name><br>
Password: <input type=text name=pass><br>
<input type=submit name=send value=Send>
</form>
```

When the Send button is clicked, the data from the text field are sent to the handler.php file (Listing I.10.2) using the POST method.

# Listing I.10.2. The handler.php file

```
<?php
echo "Name - \$_POST[name] <br>";necho "Password - \$_POST[pass] <br>";n?>
```

Using sockets, pass the POST data to the handler.php file directly, bypassing the HTML form.
