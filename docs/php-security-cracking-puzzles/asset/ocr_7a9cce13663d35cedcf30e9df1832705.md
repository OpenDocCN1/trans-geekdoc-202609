# # Chapter 1.7: Authorization and Authentication

![](bbox=[0.105, 0.196, 0.933, 0.368])

Authorization and authentication play an important role when building Web applications. This is because every site, for which it is necessary to distinguish among users, must authorize visitors using passwords. IP addresses are not constant, and lots of users can connect to the Internet using the same IP address. Thus, to distinguish among visitors, it is necessary to resort to user authorization. The value of the user account access in some chat room or forum is not equivalent to that of the user account providing access to a private panel in an e-shop or to that of the user account providing access to some FTP site. As a rule, user authorization is carried out somewhere in the protected area of the site, where HTTP traffic is transmitted over the secure sockets layer (SSL) protocol, ensuring HTTP data encryption and eliminating eavesdropping on passwords (recall that in HTTP passwords are not encrypted). Whether or not SSL is used, careless implementation of the authorization code might result in cracking.
