# II.6.7. Forging User Agents

To forge a user agent, it is necessary to forge the User-Agent header. For example, a Windows XP user might have the following user agent:

```
Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)
```

# Listing II.6.11. Forming the forged user agent

```
<?php
$hostname = "host";
$path = "/path/index.php";
$line = "";

// Establishing the connection whose hostname parameter
// is passed in the $hostname parameter
$fp = fsockopen($hostname, 80, $errno, $errstr, 30);
// Checking whether the connection has been established successfully
if (!$fp) echo $errstr ($errno)<br />

else {
    // Forming HTTP headers for transmission
    // to the server
    $headers = "GET $path HTTP/1.1\r\n";
    $headers .= "Host: $hostname\r\n";
    // Forging the user agent
    // masquerading as a Windows XP user
    $headers .= "User-Agent: Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1\r\n";
    $headers .= "Connection: Close\r\n";
    // Sending an HTTP request to the server
    fwrite($fp, $headers);
    // Receiving the response
    while (!feof($fp)) {
        $line = fgets($fp, 1024);
    }
    fclose($fp);
}
echo $line;
?>
```
