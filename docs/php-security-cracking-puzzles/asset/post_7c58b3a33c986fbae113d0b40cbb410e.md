
# Chapter II.7: Authorization and Authentication

```php
(
    Header("WWW-Authenticate: Basic realm = \"Admin Page\"");
    Header("HTTP/1.0 401 Unauthorized");
    exit();
}
// If there is no such user, displaying the password entry window
if (mysql_num_rows($list) == 0) {
    Header("WWW-Authenticate: Basic realm = \"Admin Page\"");
    Header("HTTP/1.0 401 Unauthorized");
    exit();
}
// If all checks are successful, comparing the password hashes
$pass = @mysql_fetch_array($list);
if (md5($SERVER['PHP_AUTH_PW']) != $pass['pass']) {
    Header("WWW-Authenticate: Basic realm = \"Admin Page\"");
    Header("HTTP/1.0 401 Unauthorized");
    exit();
}
?>
```

As can be seen from the listing, in the case of an unsuccessful authorization, another authorization invitation is sent:

WWW-Authenticate: Basic realm = "Admin Page"
HTTP/1.0 401 Unauthorized

Afterward, the script execution is terminated by the exit() function. The number of attempts to enter the password can be limited. This can be done by sending the HTTP/1.0 404 Page not Found header instead of the headers described previously.

The security_mod.php security module must be included at the beginning of pages to be password-protected using the include statement.

## II.8.1. Downloading HTML Pages

A page from a remote host can be downloaded using the standard file-handling functions by simply passing the network path as the file name to these functions.

Listing II.8.1. Downloading HTML pages (PHP 4.3.0 and later versions)

```php
// Downloading a page from the remote host
$content = file_get_contents("http://www.php.net/");
// Saving the contents of the page in a file
$fd = fopen("url.txt", "w");
fwrite($fd, $content);
close($fd);
?>
```

Executing the Listing II.8.1 script saves the contents of the index page of the url.txt file. The http://www.php.net site in the url file_get_contents() function is quite convenient and returns the contents of a local or remote file as a string.

# Chapter II.8: Using Information from Other Sites 295

However, it has been available only as of PHP 4.3.0. For earlier PHP versions, the script shown in Listing II.8.2 has to be used.

# Listing II.8.2. Downloading HTML pages (versions before PHP 4.3.0)

```php
<?php
// Obtaining the remote page handle
$fd = fopen("http://www.php.net/", "r");
if (!$fd) exit("Cannot find the requested page!");
$content = "";
// Reading the contents of the file into the $content variable
while (!feof($fd)) {
    $content .= fgets($fd, 1024);
}
// Closing the file
close($fd);

// Saving the contents of the page in a file
$fd = fopen("url.txt", "w");
fwrite($fd, $content);
close($fd);
?>
```

In this case, the fgets() function loads the page by extracting the data from the line by line. The function's second parameter specifies the maximum number of bytes the function can read at. As a rule, the string length does not exceed 1,024 characters, so this parameter may be left as is. The script downloads files slower than the file_get_contents() function does; whereas the function executes binary code created in C. This approach, however, is more suitable for downloading large files. The maximum amount of memory that a script may consume is limited by the memory_limit directive in the php.ini file. This directive is usually set to 8 MB or 16 MB. This amount of memory is what a PHP script and all variables and arrays it may consume. Thus, if a 10-MB file is read completely into a variable, it will not be possible to perform even a replacement with that variable, because this would require 20 MB of memory. The approach used in the Listing II.8.2 script allows the file to be processed one line at a time without loading the entire contents of the file into the memory allocated for the script.

## II.8.2. Extract Links from Yahoo

Load the page specified by the following URL into the browser:

```
http://search.yahoo.com/search?p=PHP&sm=Yahoo%21+Search&fr=FP-tab-web-t&toggle=1&cop&ei=UTF-8
```

Save it as a file name search.php on the hard drive to make it more convenient to analyze its HTML code.

In Internet Explorer, the HTML code of a Web Page is obtained by right-clicking the page and selecting the View Source item in the context menu that appears.

A link to a search item looks as follows:

```html
<a class="yschttl href="http://rds.yahoo.com/?ylt=A9htddlc.M9DXG8B4j1lXNyoA;ylu=X3dOMTEIN2Rwc22WnGB8D2QRSaAlTdTMQRb3MDOMQRZWWMDC3IEdnRp2ANPT1A1XzU-/SIG=-117gljb0/EXP=1317789404**http://www.php.net/"><B>PHP</B> Hypertext Preprocessor</a>
```

Listing II.8.3 shows a script to extract all URLs, which are located between the \*\* character sequence and the first double quote.

# Listing II.8.3. Extracting URLs

```php
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search in
$url = "search.htm";
// Loading the contents of the page
$contents = file_get_contents($url);
// The regular expression for URLs
$pattern = "/\*\*(([^\"]+)\"/";
// Performing the search
preg_match_all($pattern, $contents, $out);
// Displaying the results of the search
for($i = 0; $i < count($out[1]); $i++) {
    echo $out[1][$i] . "<br>";
}
?>
```
