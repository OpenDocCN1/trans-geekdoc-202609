# I.2.14. Highlighting PHP Code

PHP provides two standard functions for highlighting the code: highlight_string() and highlightfile(). These functions have two serious drawbacks: They support only PHP code, and the code must be enclosed in the <?php and ?> or (<? < and ?>). Develop a custom function for highlighting the syntax that is free from these drawbacks.
