## I.15.2. Page Preload Script

As the Internet access speeds are increasing, site visitors are becoming increasingly impatient for a page to load. If a user has to wait for this, on average, more than ten seconds, he or she simply leaves it. However, there are pages that require lengthy computations before they can be displayed, for example, a database query or a difficult discrete calculus calculus problem. In this case, the bottleneck is not the channel bandwidth but the server's computational capacity. To keep visitors leaving the resource in this case, it is often enough to politely inform them that their request requires extensive computations that will take time. As a rule, it is being kept in the dark about what is going on in users' mind, not waiting 15–20 seconds.

Listing I.15.1 shows a script for emulating lengthy computations.

### Listing I.15.1. Using the sleep() function to emulate lengthy computations

```php
<?php
// Emulating lengthy computations
sleep(5); // Time in seconds
echo "The results of the lengthy computation process.";
?>
```

Develop a script to inform users before the script from Listing I.15.1 is run that it will take time to produce the results.

### II.1.1. Listing Files in a Directory

PHP provides a special type of quotation mark called backtick (``). If a system command is enclosed in backticks, PHP attempts to execute it as a shell command. In the program shown in Listing II.1.1, the `dir` built-in command is executed because it is enclosed in backticks.

> The `dir` command can accept both fully-qualified and relative paths to the directory as parameter. If the parameter is not specified, the command outputs the contents of the current directory.

### Listing II.1.1. Using the backtick operator to execute the dir command

```php
<?php
echo "<pre>";
echo htmlspecialchars(`dir`);
```

Because the format of the command's output is intended for the command line, Windows system functions output their results in cp866 because by default the command line uses this encoding for backward compatibility with earlier versions of console applications. In Windows XP, it is possible to change the encoding using the chcp command. If this command is called without parameters, it returns the current code page (Listing II.1.2).

### Listing II.1.2. Displaying the current encoding

```php
<?php
echo `chcp`;
?>
```

As a result of the operation of the script shown in Listing II.1.2, the browser displays the following: Current code page: 866. If you pass the code page name to the chcp command, it will change the current code page to the specified one. Thus, the program in Listing II.1.1 can be rewritten as shown in Listing II.1.3.

## II.1.2. Right Alignment

The most suitable approach to aligning file names along a right boundary is using the `printf()` function, which allows you to format strings.

### Listing II.1.5. Aligning file names along the right boundary

```php
<?php
$filename = array("all.php", "auth.php", "auth.txt", "base.txt", "chat.html", "config.php", "count.txt", "count_new.txt", "counter.dat", "counter.php", "create.php", "dat.db");

// Traversing the array and discovering
// the number of characters in the
// longest file name
$max_length = 0;
foreach($filename as $name) {
    $length = strlen($name);
    if($length > $max_length) $max_length = $length;
}
// Outputting the names of files, aligning them along
// the right boundary
echo "<pre>";
foreach($filename as $name) printf("%$max_lengths\n", $name);
echo "</pre>";?>
```

In the first loop, the script finds the number of characters in the longest file name.
