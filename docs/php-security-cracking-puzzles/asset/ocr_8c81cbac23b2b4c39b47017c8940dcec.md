Returning to the archived file, it now has to be compressed using the Gzip library. This can be done using the script shown in Listing II.15.5.

# Listing II.15.5. Compressing the archive.tar file

```
<?php
// Reading the contents of the archive.tar file
// into the $content variable
$content = file_get_contents("archive.tar");
// Opening the archive.tar file
$zf = gzopen("archive.tar.gz", "w9");
// Saving the compressed file
gzwrite($zf, $content);
// Closing the file
gclose($zf);

```

When the file is opened using the gzopen() function, the level of compression is shown in the second parameter (w9 is the maximum compression). archive.tar.gz file can be decompressed back into the archive.tar file with the help of the script shown in Listing II.15.6.
