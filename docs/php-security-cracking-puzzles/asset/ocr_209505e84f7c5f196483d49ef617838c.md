# ## I.3.20. A File-Based Registration System

Develop a system that stores information about registered users in a file. Each line of this data file must correspond to an individual user and be of the following format:

User name::password::email::url

The name, password, email address, and home page must be delimited by two colons (::). The system must not allow registration of a user with a name that has already been registered. In addition, develop a script for viewing information about registered users.

# ## I.3.21. Outputting a Random File

Assume that you have a directory containing image files. Develop a script that puts a randomly chosen image when loading a page.

# ## I.3.22. Determining the Image Creation Date

No matter how the IPEG image was created, it must always contain the date of image creation. Develop a script to automatically retrieve this date from JPEG files.
