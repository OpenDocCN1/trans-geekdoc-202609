The catalogs table is intended for storing the names of directories. This table has two fields:

+   - id catalog — Primary key of the table with the AUTO_INCREMENT attribute
- name — Directory name

The products table is intended for storing information about part numbers. It has seven fields:

+   - id product — Primary key of the products table with the AUTO_INCREMENT attribute
- name — Name of the spare part
- price — Price of the spare part
- count — Number of items in stock
- mark — Mark of the spare part
- description — Description of the spare part
- id catalog — Foreign key for the catalogs table that can be used to determine, which includes a specific part
