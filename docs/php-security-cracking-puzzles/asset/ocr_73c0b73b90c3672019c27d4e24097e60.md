# Chapter II.4: MySQL and SQL Injections

To execute a SQL injection, the first query must be completed and a second query must be added with the help of the UNION statement, as shown in Listing II.4.12.

# Listing II.4.12. The modified query for selecting all registered users

```
SELECT * FROM userslist
WHERE name LIKE ''\nUNION
SELECT * FROM userslist
WHERE name LIKE '%'\nORDER BY name
```

The injection SQL query is set off in bold. The results of its execution are shown in Fig. II.4.7.

This trick will not work if the magic quotes mode is enabled on the server. As mentioned previously, when the magic quotes mode is enabled, all quotation marks passed using the GET and POST methods and using cookies are escaped with a backslash. The mode is enabled by setting the value of the magic_quotes_gpc directive to On.
