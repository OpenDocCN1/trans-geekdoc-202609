The scan_dir() function reads the $dirname directory and returns the $arr array. The keys of the array's elements are the files' names, and their values are the files' contents.

Afterwards, the $arr array is packed into a binary string with the help of the serialize($) function. The obtained string is saved in the archive.tar file. The script shown in Listing II.15.4 performs the reverse task of unpacking the archive.tar file.
