# I.13.1. The Ping Utility

Create a Web interface for the ping utility.

# I.13.2. The File Inode

UNIX assigns each file a unique number, called an inode. File names are only pseudonyms used for user convenience. Create a script to return the file's inode from its name and a script to return the name from its inode.

# I.13.3. Access Permissions

Develop a Web interface to change access permissions for files and directories.

# I.13.4. Archives

Develop a script to pack a directory into a .tar.gz archive and a script to do a reverse conversion: unpack a .tar.gz archive into the current directory.
