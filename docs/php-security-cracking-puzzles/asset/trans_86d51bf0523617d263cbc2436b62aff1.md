### II.2.1. 删除标签

可以使用正则表达式配合 `preg_replace()` 函数删除 HTML 标签。该函数的通用格式如下：

```
preg_replace (pattern, replacement, subject [, limit])
```

函数在 `subject` 字符串中搜索匹配 `pattern` 正则表达式的子字符串，并用 `replacement` 参数进行替换。可选的 `limit` 参数如果不设置，则替换所有匹配项。`replacement` 参数可以包含数字 类型的引用；该类型的引用将被匹配正则表达式的括号部分替换。`n` 参数可以取 0 到 99 的值；`\0` 对应于整个模式。如果找到了匹配模式的子字符串，函数返回修改后的 `subject`；否则，返回字符串的原始值。`preg_replace()` 函数的前三个参数可以是一维数组。处理带有字符串键的数组时，按照它们在数组中的顺序引用。如果 `replacement` 数组的元素多于 `pattern` 数组，`preg_replace()` 会从两个数组中顺序提取元素并用于搜索和替换。如果 `pattern` 参数是数组而 `replacement` 参数是字符串，则目标字符串与 `pattern` 数组的每个元素进行比较，并将任何匹配项替换为 `replacement` 字符串。也就是说，`pattern` 数组的每个元素被用作模式，替换字符串是固定的。pattern 为字符串且 replacement 为数组的选项没有意义。

兼容 Perl 的正则表达式必须包含在分隔符。在 II.2.1 中，使用单引号作为分隔符。除了字母数字或反斜杠外的任何符号都可以作为分隔符。正则表达式内部使用的分隔符必须由转义字符反斜杠引导。结束分隔符可以是影响整个正则表达式的修饰符。`i` 修饰符指定正则表达式不区分大小写；`s` 修饰符意味着正则表达式跨越多行。

### II.2.1. 从 HTML 页面删除标签

```php
<?php
// 提取 index.html 文件的内容
$content = file_get_contents("index.html");

// 模式数组
$search = array("<script[^>]*?</script>",
    "<<\/!\*?[^<]*?>",
    "([\r\n\s]+",
    "quot|#34;", "i",
    "amp|#38;", "i",
    "lt|#60;", "i",
    "gt|#62;", "i",
    "nbsp|#160;", "i",
    "iexcl|#161;", "i",
    "cent|#162;", "i",
    "pound|#163;", "i",
    "copy|#169;", "i",
    "&#\(d+);", "e");

// 替换数组
$replace = array(
    "",
    "\\",
    "",
    "&",
    "<",
    ">",
    "",
    chr(161),
    chr(162),
    chr(163),
    chr(169),
    "chr(\\1)");

// 删除标签并在浏览器窗口中显示
```
