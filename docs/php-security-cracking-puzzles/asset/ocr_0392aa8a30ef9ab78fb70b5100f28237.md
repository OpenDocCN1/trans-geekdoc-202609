# II.12.2. Determining Ownership of European IP Addresses

The problem is solved by using the fsockopen() function to connect to port 43 of the whois.ripe.net server and then receiving and displaying the server's reply. A script for this is shown in Listing II.12.2.

+   Listing II.12.2. Determining ownership of European IP addresses

```
<form method=post>
<input type=text name=ip size=35>
<input type=submit value='Enter the IP address'>
</form>
<?php
if (empty($_POST['ip']))
{
  // Connecting to the TCP socket listening to
  // port 43 on the whois.ripe.net server
  // A file pointer, $sock, is returned.

$sock = fsockopen("whois.ripe.net", 43, $errno, $errstr);
if (!$sock) exit("$errstr");
else
{
  // Writing the string from the $_POST["ip"] variable
  // into the file pointer
  fputs($sock, $_POST["ip"]."\r\n");
  // Reading from the file pointer
  while (!feof($sock))
{
    echo (str_replace(":", ":&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;",",
    fgets($sock,128))."<br>");
  }
}
```
