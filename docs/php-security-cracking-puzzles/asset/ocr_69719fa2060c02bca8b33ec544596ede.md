# I.7.6. Protecting Text Files from Being Viewed in a Browser

Even if you use complex and long passwords subject to irreversible encryption, storing information in text file available for viewing through a browser is a potential security hole. The intruder can study the text file structure, understand the internal organization of your site, and use unprotected and unencrypted information in his or her purposes. For example, it is possible to use email addresses to organize lists. Using the .htaccess configuration file, protect all text files stored in a specific directory from being viewed in the browser window (Fig. I.7.6).
