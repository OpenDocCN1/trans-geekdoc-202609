
## Chapter II.8: Using Information from Other Sites 299

The HTML code of the page received using the file_get_contents() function is simpler:

```html
<li><div class="yschttl href="http://www.php.net/"><p>PHP</p><a href=": Hypertext Preprocessor</a></div>
```

Considering all of this, for Listing II.8.3 to work it must be modified as shown in Listing II.8.5.

### Listing II.8.5. Extracting URLs from Yahoo search system pages

```php
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://search.yahoo.com/search?p=PHP&sm=Yahoo%21+Search&fr=FP-tab-web-t&toggle=1&cop&ie=UTF-8";
// Loading the contents of the page
$contents = file_get_contents($url);
// The regular expression for URL
$pattern = "|<li>[\s]*<div>[\s]*<a[class=yschttl[^"]]+href=\"([^"]+)\"|";
// Performing a search against the regular expression
preg_match_all($pattern, $contents);
```

A list of hyperlinks can be formed using the script shown in Listing II.8.6.

### Listing II.8.6. Extracting hyperlinks from Yahoo search system pages

```php
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://search.yahoo.com/search?p=PHP&sm=Yahoo%21+Search&fr=FP-tab-web-t&toggle=1&cop&ie=UTF-8";
// Loading the contents of the page.
$contents = file_get_contents($url);
// The regular expression for URLs
$pattern = "<li>([\s]*<div>[\s]*a[\s]*class=yschtl[^"]]*href=\"([^"]+)\">([\s]*.*?)<a></li>";
// Performing a search against the regular expression
preg_match_all($pattern, $contents, $out, PREG_PATTERN_ORDER);
// Displaying the results of the search
for ($i = 0; $i < count($out[1]); $i++)
{
    echo "<a href=\"$out[1][$i]\">$out[2][$i]</a><br>";
}
?>
```

### II.8.6. Extracting an Exchange Rate from XML File

In the XML file loaded from the site of European Central Bank, of interest are the following tags:

- <Cube time='2006-01-20'> - The current date
- <Cube currency='USD' rate='1.2068'/> - The Exchange rate of the euro against the U.S. dollar (1.00 was worth $1.2068)

Create a universal script, extracting the exchange rate for all currencies shown in Listing II.8.13.

### Listing II.8.13. Extracting currency rates

```php
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://www.ecb.eu/stats/euroref/euroref-daily.xml";
// Loading the contents of the page
$contents = file_get_contents($url);

// Extracting the date
$pattern = "|Cube time=([^']+*)'|";
// Performing a search against the regular expression
preg_match($pattern, $contents, $out);
echo "The exchange rate for $out[1].<br><br";

// Extracting the currency exchange rates
$pattern = "|Cube currency=([^']+*)' rate='([^']+*)'|";
// Performing a search against the regular expression
preg_match_all($pattern, $contents, $out, PREG_PATTERN_ORDER);
// Displaying the results of the search
for($i=0; $i < count($out[1]); $i++) {
    echo "1. $out[1][$i]. - " . $out[2][$i]." EUR<br";
}
?>
```
