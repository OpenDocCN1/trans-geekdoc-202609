## II.1.4. Outputting Data in Three Columns

To output a table according to the variant shown in Fig. I.1.3, it is necessary to implement the counter ($counter) that would be reset to zero after reaching the defined value. When the counter value is set to zero, the `<tr>` tag is output (List II.1.7). At the moment the counter is reset to zero, for the string, `</tr>`, is output.

II.1.7. The first variant of the script that outputs a three-column table

```php
<?php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Computing the number of elements in the array
$total = count($filename);
// Number of columns in the table
$numcols = 3;
$counter = 0;

echo "<table border = 1>";
for($i = 0; $i < $total; $i++) {
    if($counter == 0) echo "<tr>";
    if ($counter == $numcols) {
        echo "</tr>";
        $counter = 0;
    }
    echo "<td>".$filename[$i]."</td>";
    $counter++;
}
echo "</table>";
?>
```

To implement the variant shown in Fig. I.1.4, it is difficult to use only a single $filename array. To solve this problem, it is most convenient to organize an intermediate two-dimensional array (Listing II.1.8).

# Listing II.1.8. The second variant of outputting a three-column table

```php
<?php
$filename = array("all.php", "auth.php",
"auth.txt", "base.txt",
"chat.html", "config.php",
"count.txt", "count_new.txt",
"counter.dat", "counter.php",
"create.php", "dat.db");

// Computing the number of elements in the array
$total = count($filename);
// Number of columns in the table
$numcols = 3;

// Computing the number of strings
$number = (int)($total/$numcols);
if((float)($total/$numcols) != $number) $number++;

// Forming an intermediate two-dimensional array
for($i = 0; $i < $number; $i++) {
  for($j = 0; $j < $numcols; $j++) {
    $arr[$i][$j] = $filename[$j*$number + $i];
  }
}

// Outputting a table
echo "<table border = 1>";
for($i = 0; $i < $number; $i++) {
  echo "<tr>";
  for($j = 0; $j < $numcols; $j++) {
    echo "<td>$arr[$i][$j]</td>";
  }
  echo "</tr>";
}
echo "</table>";
?>
```

The variants presented in Listings II.1.7 and II.1.8 can be extended to any number of columns in the output table. To achieve this, it is enough to change the value of the $numcols variable.

## II.1.5. Passing an Array from Page to Page

The script that passes an array from first.php file to second.php file using the include instruction is presented in II.1.9.

```php
<?php
// Including the array
$filename = include "first.php";
// Outputting the array
foreach($filename as $value) echo "$value<br>";
?>
```

This method of passing arrays is not always acceptable. For example, it is not possible to pass large arrays from first.php. There are two instructions for including files: include and require. If the file is missing, the include instruction generates a warning while the require instruction terminates.

## II.1.6. Passing an Array Using GET Method

To pass an array using the GET method, it is necessary to form a query string, for example: `mysite/second.php?filename=...`.

```php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Joining elements into the string
$url = implode("&filename[]=", $filename);
$url = "second.php?filename[]=" . $url;
echo "<a href=\"$url\">Link to second.php</a>";";
```

However, to obtain the array in the second.php file it is necessary to make an assignment:

`$filename = $_GET['filename'];`

Furthermore, it is not always convenient to pass data using the GET method because the length of the address string is often limited to 8 KB by the Web server. Consequently, it is impossible to pass considerable data.

## II.1.7. Passing an Array Using POST Method

There are two ways of passing data using the POST method:

- Directly through sockets
- Through HTML forms

Working with sockets will be covered in detail in other chapters. This section focuses on passing data through HTML forms. For this purpose, it is necessary to dynamically create a form in the first.php file. This HTML form must contain a number of hidden fields that matches the number of elements in the $filename array. In addition, the form will contain a button for sending data to the second.php file (Listing II.1.13).
