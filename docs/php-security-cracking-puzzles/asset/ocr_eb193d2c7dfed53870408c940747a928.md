# Chapter II.14: Telltale Scripts 369

This sequence of actions will assign the PHP Script Interpreter<sup>1</sup> as the inter-
preter for PHP files (Fig. II.14.4). Now PHP scripts will act like regular executables\and can be launched by pressing the <Enter> key or double-clicking the selected file.

Now when the script is triggered by the system as regular executable it can be
lunched by cron at the scheduled time. Tasks for execution are scheduled by edit-
ing cron.tab configuration file.

In Windows, the cron.tab file can be found in the C:\Program Files directory; in UNIX,
it is usually located in the \etc directory. For more detailed information regarding the
UNIX cron.tab file, consult the documentation for the specific operating system.

![](bbox=[0.046, 0.259, 0.131, 0.345])

Each line in the cron.tab file describes one scheduled task. In addition to
the task lines, the file can contain comments, which start with the pound sign (#).
The task line format is the following:

```
minutes day_of_month day_of_week command
```

The parameters can take take on the following values:

+   - minutes—0–59
- hours—0–23
- day_of_month — 1–31
- month — 1–12
- day_of_week — 0–7 (0 and 7 denote Sunday)
- command — The command to be executed, for example, d:/main/reserve.php

The parameters are delimited by a space. The asterisk given as a parameter
value denotes the entire range for the particular parameter. For example, consider
the following task directive:

```
0 23 * * d:/main/reserve.php
```

It specifies launching the d:/main/reserve.php script every day at 23:00. Sev-
erals for each parameter can be specified if they are delimited with comma,
Thus, you can have the following task directive:

```
0 8,16 * * d:/main/cleanup.php
```

It specifies that the d:/main/cleanup.php script will be launched every day at
00:00, 8:00, and 16:00.

> ¹¹ It is possible that the command line interpreter (CLI) will be assigned as the PHP interpreter.
