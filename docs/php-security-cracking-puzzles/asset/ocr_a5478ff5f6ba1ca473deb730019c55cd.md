# II.2.13. Interpreting bbCode Tags

The square brackets around tags can be replaced by angle brackets using the script shown in Listing II.2.16.

It is important that the greediness modifier, U, is used in regular expressions to make them react to the first closing tag of the last one. The modifier makes the expressions react to the newlines between the starting and the closing tags, ensuring that tags are properly interpreted.

# Listing II.2.16. Interpreting bbCode tags

```
<?php
// Extracting the contents of the bb.txt file
$content = file_get_contents("bb.txt");
```

```
// Replacing [i] with <i> and [/] with </i>
$content = preg_replace("#\\\[i\](.+)\\\[/i\]#", "<i>$1</i>", $content);
```
