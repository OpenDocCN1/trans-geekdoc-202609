> Fig. II.10.1. Viewing the home page of http://www.php.net from the local host

The beginning of a page contains HTTP headers, which the browser hides from users; these are followed by the page body interpreted by the browser and displayed in the window. HTTP headers can be removed using the strstr() function, which returns part of the string specified in the first parameter — the part from the first occurrence of the substring given in the second parameter to the end.
