# Listing II.3.37. Deleting files in the current directory

To protect against such developments, the angle brackets must be converted into their HTML entities (i.e., < into &lt; and > into &gt;) using, for example, the htmlspecialchars() function (Listing II.3.38).

# Listing II.3.38. Filtering user input

```
<?php
// The form handler
if(empty($_POST['name']) && empty($_POST['!msg']))
{
    $_POST['name'] = htmlspecialchars($_POST['name']);
    $_POST['!msg'] = htmlspecialchars($_POST['!msg']);
    $Smsg = "<tr><td>$_POST[name]</td></tr>";
    $Smsg .= "<tr><td>$_POST[msg]</td></tr>";
}
// Opening the file and adding a new record
$fd = fopen("msg.txt", "a");
if($fd)
{
    fwrite($fd,$Smsg);
    fclose($fd);
}
// Outputting the messages added to the text file
echo "<table>";

?>
```
