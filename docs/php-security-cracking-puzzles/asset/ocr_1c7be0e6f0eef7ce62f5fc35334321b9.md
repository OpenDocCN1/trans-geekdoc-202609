# I.12.4. Determining the IP Address from a Domain Name

The Whois service uses the IP address to provide detailed ownership information, including the physical address of the person to whom, or the legal entity to which, the given IP address is registered. Developers, however, often deal with domain names and not IP addresses. Create a Web application to convert a domain name into the corresponding IP address and return a Whois service report for this IP address.
