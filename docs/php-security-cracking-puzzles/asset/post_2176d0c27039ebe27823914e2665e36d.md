## II.13.1. The Ping Utility

You should remember that unlike its Windows counterpart, UNIX ping utility keeps executing until you terminate it by pressing the <Ctrl>+C> combination. Because it is rather difficult to imitate this action from a Web application, the execution can be terminated with the help of the -c switch, which specifies the number of echo requests to send. To check, IP address 192.168.200.3, the ping command is executed as follows:

```
ping 192.168.200.3 -c 4
```

All that remains is to create an HTML form that specifies the IP address to check and the number of echo requests to send. A script that solves this problem is shown in Listing II.13.1.

II.13.3. Access Permissions

Create an HTML form with a text field to specify the file whose access permissions have to be changed and with nine checkboxes to set the access permissions.

In UNIX, access permissions can be specified by an octal number. In this format, read rights are denoted by the digit 4, write rights by 2, and execution rights by 1. Overall rights for a group are specified by a sum of these digits. For example, 6 (4+2) denotes read and write rights, and 7 (4+2+1) gives full access to a file or directory.

Access permissions are changed using the chmod command. For example, to set access permissions for the index.php file to 777, the command is executed as follows:

```
chmod 777 index.php
```

Based on this script, a script like the one shown in Listing II.13.4 can be created.
