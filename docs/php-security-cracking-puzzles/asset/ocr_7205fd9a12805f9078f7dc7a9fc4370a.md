# I.5.6. Bypassing an HTML Form Protected by Sessions

In Section I.5.3, you had to develop an HTML form protected, using a session, against being filled automatically on a third-party host. Such protection can be bypassed only by using a script that would accept cookies from the server and then send them to the server in the course of further queries. In other words, such scripts emulate the browser's operation. Now, create a script that would implement such behavior.

The HTML form for authorization, index.php, and its handler, handler.php, can be found in the /scripts/5/5.6/ directory on the accompanying CD-ROM.

# I.5.7. Cross-Site Scripting

In Section I.3.20, it was suggested that you develop a system for user authentication that would log the information about registered users in the text file named text.txt (Listing I.5.4). Every line in that file must correspond to the individual user and appear in the following format:

```
user name::password::email::url
```

User name, password, email address, and home page are separated by the sequence of two colons (::).
