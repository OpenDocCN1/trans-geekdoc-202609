# II.3.18. Adding Records to Files

To add a new record to a text file, the value of the maximum index must be determined. Next, a line with an index equaling the maximum plus one is added to the file. Finally, the updated file is saved (Listing II.3.28).

Listing II.3.28. Adding a record to a file

```
<?php
// The file's name
$filename = "text.txt";
$str = "Visual Basic programming";

// Determining the maximum index
$arr = file($filename);
$maxval = 0;
foreach($arr as $line) {
    preg_match('/^(\d+)([^\n]+)$$/', $line, $out);
    if ($maxval < $out[1]) $maxval = $out[1];
}

// Reading the file's contents
$content = file_get_contents($filename);
// Adding a new line
$content = "\n".($maxval + 1).""$str;

// Saving the updated results
$fd = fopen($filename, "w");
fwrite($fd, $content);
fclose($fd);
?>
```
