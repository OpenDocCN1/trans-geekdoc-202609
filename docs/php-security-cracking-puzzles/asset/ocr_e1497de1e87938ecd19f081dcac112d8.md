```
// the number of characters in the
// longest file name
$max_length = 0;
foreach($filename as $name) {
    $length = strlen($name);
    if($length > $max_length) $max_length = $length;
}
// Outputting the names of files, aligning them along
// the right boundary
echo "<pre>";
foreach($filename as $name) printf(\%%$max_length\s\n", $name);
echo "</pre>";?>
```

In the first loop, the script finds the number of characters ($max_length) in the longest file name. The length of this file name will be considered the right boundary. In the second loop, the script outputs file names using the printf() function, where the $max_length value obtained in the first loop plays the role of the field width spec.
