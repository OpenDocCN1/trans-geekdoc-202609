# II.3.11. Counting Lines in Project Files

Lines in project files are counted by recursively traversing the project’s directory and counting the lines in files whose extension matches those specified in the $extensions array (Listing II.3.13). The array is declared to be global, so you need not pass the reference to it using the parameters of the scan_dir() recursive function. This approach is justified because the array does not change throughout the script’s operation. Moreover, the $count variable, which stores the current number of lines, is declared.
