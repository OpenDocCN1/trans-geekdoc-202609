This script sends the data using the POST method. The POST method, in contrast to the GET method, sends the data in the area that follows headers instead of the query string. Passing several parameters is similar to that of the GET method: groups name = values are joined using the ampersand (&) character. Taking into account that the HTML form accepts parameters such as name = admin, pass = admin, and session_id, with the values obtained in first access attempt through sockets, the data string might appear as follows:

```
name = admin & pass = admin\r\n\n
```

When sending the data using the POST method, it is necessary to send the Content-length HTTP header, with the number of bytes in the data string, and to send the following Content-type HTTP header: application/x-www-form-urlencoded. This header specifies the method used to send the data.

A more detailed description of using the POST method is provided in Chapter II.10.
