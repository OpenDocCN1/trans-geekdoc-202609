# II.14.2. Verifying Link Validity

It is not necessary to load the entire document server pointed to by a link to verify that the given link is valid. Instead, inspect only the Web server's reply to the request for the given page. This is because loading a significant number of pages may take considerable time. Create an intermediate function named get_code(). The function accepts two parameters: $hostname and $path, the path to the page relative to the root site's directory. It returns the Web server's reply code. A script implementing the get_code() function is shown in Listing II.14.5.
