# II.6.6. Protecting against Download Managers

Consider one of the popular download managers, whose user agent has the following format:

+   Teleport Pro/1.29

To achieve the formulated goal, it is enough to place the string presented in Listing II.6.10 in the beginning of the page.

Listing II.6.10. Protecting against download managers

```
<?php
if(substr($_SERVER['HTTP_USER_AGENT'], 0, 8) == "Teleport") exit();
?>
```

The method of protecting against undesirable downloading of the site's contents by download managers is not universal. Because the $_SERVER['HTTP_USER_AGENT'] string is formed by the client — to be precise, by the download manager whose main goal is to download the page at all costs — this string is often forged or even remains blank.
