To delete all users from the database, the malefactor doesn't even have to know any passwords. You could try to protect against this attack by using the LIMIT statement to limit to one the number of records that can be deleted at a time (Listing II.4.19).

# Listing II.4.19. Limiting the number of deletions

```
DELETE FROM userslist
WHERE pass = 'password' AND
name = 'name'
LIMIT 1
```
