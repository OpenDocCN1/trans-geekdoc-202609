## II.2.9. Converting the Case

Problems, in which the case of letters must be changed, are good candidates for applying the preg_replace_callback() function. This function is similar to the preg_replace() function except that the actual replacement is performed by a callback function. The function's syntax is the following:

```
mixed preg_replace_callback(mixed pattern, callback,
mixed subject [, int limit])
```

Instead of the replacement parameter used in the preg_replace() function, the callback function is specified. This function is passed the array of the found matches and returns the replacement string.

## II.2.10. Converting the text case

```php
<?php
$text = "PROGRAMMING is an ART worth devoting your entire LIFE to.";
$text = preg_replace_callback(
    "/[A-Z]{2,}/",
    "replace_text",
    $text
);
```

```php
echo $text;
function replace_text($matches)
{
  return substr($matches[0], 1).strtolower(substr($matches[0], 1));
}
```

The regular expression [A-Z]{2,} searches for all words with two or more uppercase letters in a row. These words are replaced with the result returned by the replace_text() callback function. The function's parameter is an array of the matched strings, the first element in array elements containing the matches for successive parenthesized parts of the regular expression. The function leaves the first letter of each matched string unchanged and changes to lowercase the remaining letters with the help of strtolower() function.

PHP has a special function for converting the first letter of a word to uppercase and the rest into lowercase: ucfirst(). However, in most cases, it does not work properly with national language characters; therefore, for fail-safe operation on all servers the solution presented in Listing II.2.10 is preferable.

The wordwrap() function breaks a string (passed to it in the first parameter) into substrings whose length is specified by a number (passed to it in the second parameter). ## 2.11.11. Splitting Text into Sentences

The preg_split() function breaks the supplied text into sentences according to a regular expression. It has the following syntax:

```
array preg_split (string pattern, string subject
    , int limit (, int flags))
```

The function returns an array holding substrings obtained by breaking the subject string at the sentence boundaries that match the pattern template.
The optional limit parameter is set, the function returns the number of substrings specified by it; if the parameter is not set or set to -1, the number of substrings returned by the function is not limited. The last parameter, flags, can be any combination of the following flags (delimited using the | operator):

- PREG_SPLIT_NO_EMPTY — If set, the function returns nonempty substrings.
- PREG_SPLIT_DELIM_CAPTURE — If set, the parenthesized expression in the delimiter pattern is also extracted from the subject string and returned.
- PREG_SPLIT_OFFSET_CAPTURE — If set, the position of each found string in the subject string is returned. The data for this flag are returned in a format different from that of others: For each match an array is returned whose 0th element contains the found substring and first element contains the offset.

The regular expression for locating the end of a sentence that will produce the best results is a period followed by space characters: \. [\s]+. HTML tags may interfere with the splitting operations; therefore, use the solution in Section II.2.1 to remove them from the text. The complete code for solving the problem is shown in Listing II.2.12.
