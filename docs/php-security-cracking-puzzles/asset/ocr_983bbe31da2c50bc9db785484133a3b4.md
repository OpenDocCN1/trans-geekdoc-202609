# Listing II.1.17. Using cookies to pass arrays

```
<?php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Packing the array into the string
$content = serialize($filename);
// Setting the cookie
// Here, time() + 3600 is the cookie lifetime.
// Setting the lifetime to 1 hour
setcookie('filename', $content, time() + 3600);
// Outputting the reference to the second.php page.
echo "<a href = second.php?Link to the second.php page"></a>";
?
```

Now, to obtain access to the $filename array, it is necessary to retrieve array from the cookie. This script is shown in List II.1.18.

# Listing II.1.18. Retrieving an array from the cookie

```
<?php
// Retrieving the packed array
// from the cookie
$filename = unserialize(stripsslashes($_COOKIE['filename']));
// Outputting the contents of the array
echo "<pre>";
print r($filename);
echo "</pre>";
?
```

Before saving the data in the cookie, all special characters and quotation marks are preceded by an escape character, the backslash. Therefore, for the unserialize() function to unpack the array, it is necessary to get rid of extra backslash characters using the stripsslashes() function.
