# II.2.12. Counting Words

Words can be counted using the preg_match_all() function, which unlike the preg match() function, finds all matches for the regular expression in the subject string. The function's syntax is the following:

```
int preg_match_all(string pattern, string subject, array matches
[, int flags, int offset])
```
