
In the beginning of the script, the current session_id is obtained using the session_id() function. If such identifier is missing from the session table, then a new record is added to the database, which is equivalent to the arrival of the new visitor. The SID is present in the session table, this visitor has already entered and it is necessary to update the time of visit and the user name in case the visitor has been authorized under another name or has carried out the authorization. At the end of the script, all records, for which more than 20 minutes have elapsed since the last update of the visit time, are deleted from the database. Thus, the script registers visitors' departure.

In chat applications, it is common practice to inform other visitors that a specific user has left the resource. For this purpose, it is necessary to select all records, for which more than 20 minutes have elapsed since the last update and output a message to visitors with the corresponding names have left the chat.
