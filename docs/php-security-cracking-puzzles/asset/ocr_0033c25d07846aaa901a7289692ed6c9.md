At the beginning of the script, a two-dimensional array, $servers, is created. It holds information about the coverage zone of a particular Whois server, its address, and the format of the phrase the server returns when the requested domain name is not in its database. Next, the first-level domain name is extracted from the domain name stored in the $domain variable, which is com in Listing II.12.8. This name is used to locate in the $servers array the address of the Whois server responsible for the given coverage zone.

Using sockets, the script addresses port 43 of the Whois server and passes the domain name to it. The server's response is analyzed for the no-such-domain-name phrase using regular expressions. If such a phrase is found, the domain name is available; otherwise, it is taken.
