The enctype attribute of the form determines the encoding browser applies to the form's parameters. The default value of this attribute is application/x-www-form-urlencoded. For file uploading to work, its value must be set to multipart/form-data.

The HTML form contains an unrestricted number of file type fields, whose names are joined in an array named att[]. This turns the typically two-dimensional array into a three-dimensional array, and the files are processed in a loop. The copy() function copies the file from the temporary directory to the destination directory. Then the unlink() function deletes the temporary file, and the access permissions of the file in files directory are set to 0644.
