# I.4.11. Storing MP3 Files in a Database

On the servers of host providers, you must pay for the space for files hosted virtually, in contrast to the space allocated for database tables. Storing large files in a database allows people to avoid purchasing more expensive hosting plans.

Another reason files might be stored in a database is to protect them against unauthorized downloading that bypasses the authorization system or billing system. If the files are stored on a hard disk, the chances of unauthorized downloading increase considerably.

If there is no reason to store binary files in MySQL databases, it is not advisable to do so. MySQL was designed as an extremely fast database intended for working with short text. Furthermore, by placing files in database tables, you reduce the reliability of your Web application; such applications are more reliable if files are stored directly on the hard disk.

Create a database table and a script that allows MP3 files to be stored in that table (Fig. I.4.12). The system must also provide a script that outputs the list of MP3 files available for downloading. Following the link must download the chosen file from the server to the visitor's computer. The file must not be saved as a temporary file on the server. Ensure that the file is transmitted directly from the database to the client.
