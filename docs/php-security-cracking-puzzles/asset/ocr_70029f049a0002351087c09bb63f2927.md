# I.4.5. User Deletion and SQL Injections

Assume that a service for automatic deletion of user registration information is implemented for the user registration system described in Section I.4.1. The registered user can enter his or name and password into a form, after which that user's information will be automatically deleted from the system (Listing I.4.5).

> NOTE
The script shown in Listing I.4.5 can be found in the /scripts/4/4.5/1.php file on the accompanying CD-ROM.

# Listing I.4.5. The system for removing users

<table>
