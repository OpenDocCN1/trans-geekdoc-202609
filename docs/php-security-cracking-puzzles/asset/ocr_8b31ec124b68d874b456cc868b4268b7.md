When traversing the directory tree, it is important to exclude the . (current) and . (parent) directories from those that descend recursively to prevent the script from entering an endless loop.
The scandir() function finds files created or modified during the current day using the following condition:

```
if(date("Y") == date("Y", $ftime) &&
    date("m") == date("m", $ftime) &&
    date("d") == date("d", $ftime)
```

Change the condition to the following:

```
if(date("Y") == date("Y", $ftime) &&
    date("m") == date("m", $ftime)
```

Thus, files created or modified during the current month will be listed.
