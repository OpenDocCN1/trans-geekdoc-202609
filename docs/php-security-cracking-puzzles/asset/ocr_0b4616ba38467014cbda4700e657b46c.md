# Part II: Solutions

The remaining nine characters define the file or directory access permissions. They are divided into three-character subgroups, defining the following:

+   - Owner access permissions
- Group members access permissions
- Access permissions for users other than owners or group members

The permissions for each group are the following:

+   - `r` — Read the file.
- `w` — Write or modify the file.
- `x` — Execute the file if it is a script or program; view the item if it is a directory.

Thus, string `-rw-r--` describes a regular file whose owner has read and write rights, with the group members and other users having only read rights. String `drwx-xr-x` describes a directory whose owner has all rights, with all other users having only read and view rights.

The following substrings indicate the number of blocks in the file, its user owner, its group owner, its size in bytes, the creation date, and its name.

The `ftp_realpath()` function returns superfluous information, so often the `ftp_nlist()` function is used instead, which returns a list of files in the current directory without any additional information. The function's syntax is the following:

```
array ftp_nlist (resource link, string directory)
```

The function accepts a link identifier and a directory name as the parameters. The name of the current directory can be determined using the `ftp_pwd()` function, which accepts the link identifier as the parameter:

```
string ftp_pwd (resource link)
```

The current directory is changed with the help of the `ftp_chdir()` function, as shown in Listing II.9.4.

# Listing II.9.4. Changing the current directory

```
<?php
// Opening a connection to the FTP server
require_once("config.php");
// Changing the current directory
ftp_chdir($Slink, "new_dir");
?>
```
