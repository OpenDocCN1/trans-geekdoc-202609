# II.15.3. Emulating the Tar Utility

The easiest way to imitate the UNIX Tar utility is to create an associative array with the file names used as the keys and the contents of the files as the values of the array's elements. The array is then packed into a string using the serialize() function, which is saved as a file. Thus, a functional equivalent of the Tar utility is obtained. Listing II.15.3 shows a function implementing it.

+   II.15.3. Joining files into a tarball

```
<?php
//////////////////////////////////////////////////////
// A recursive function to descend the directory tree
//////////////////////////////////////////////////////
function scan_dir($dirname)
{
    // Opening the current directory
    opendir($dirname);
    // Reading the current directory in a loop
    while (($file = readdir($dir)) != false) {
        // Checking whether the $file variable
        // equals the current or "." or the upper-level directory
        if ($file != "." && $file != "..") {
            // If the current item is a file,
            // placing it in the $arr array
            $arr[$dirname."/"$file] = file_get_contents($dirname."/"$file);
        }
    }
    // Closing the directory
    closedir($dir);
    return $arr;
}
```
