# II.9.3. Uploading and Downloading Files

Files can be added to the current directory by uploading them to the FTP server from the client side. File uploaded is initiated using the ftp_nb_put() function, whose general syntax is the following:

```
int ftp_nb_put(resource link, string remote_file, string local_file, int mode, int startpos)
```

The function accepts the link identifier of an open connection as the first parameter, link. The second parameter, remote_file, specifies the path, at which the uploaded file will be saved to the FTP server. The third parameter, local_file, is the path to the local file to be uploaded. The fourth parameter, mode, defines the mode to be used for the transfer: FTP_ASCII for text files or FTP_BINARY for binary files. The fifth parameter, startpos, can be used to specify the position in bytes, from which the file transfer should be started.

The function returns one of the following constants:

+   FTP_FAILED — When the upload fails FTP_FINISHED — When the upload is successful FTP_MOREDATA — When the upload is still in progress

Listing II.9.5 shows a script for uploading files to an FTP server. If the function return the FTP_MOREDATA constant, the scripts continues uploading the file using the ftp_nb_continue() function in a while loop to control the process. The function accepts the link identifier returned by the ftp connect() function as its only parameter. The ftp_nb_continue() function returns the same constants as the ftp_nb_put() function.

After the file is uploaded, the ftp_nb_continue() function returns the FTP_FINISHED constant and the script exits the while loop.
