# I1.7.3. Guessing a Password

A password is guessed by going through all possible combinations of characters, starting with a one-character password and increasing the length by one character to n characters after all combinations of the previous length are exhausted. In this case, you know that the password length n is not greater than four and that only lowercase English letters are used. Because character codes occupy a continuous range from 97 to 127, they are usually generated in a loop. Nevertheless, the script more flexible and allow national characters to be used, make all possible characters placed into the $pass array. Because the password length is generally not known and can vary without restrictions, the guessing script is constructed using a recursive function, named decrypt_md5($pass, $answer), that accepts two parameters. The first parameter is the encrypted password string. The other parameter is used for technical purposes: The current provisional password is sent using it, and its value is a null string when the function is called for the first time. The function returns the guessed password or an empty string if the length of the current tentative password exceeds the specified limit, which is four characters in this case.
