The next line in the file is found using the regular expression #([\d]+) ([^\n]+) (\n|\s*$))#U. The first parenthesized expression corresponds to the number; the second parenthesized expression corresponds to any sequence of characters except the newline character (\n). The last parenthesized expression corresponds to the newline character or the end-of-line character ($). The search for the end-of-line character is necessary to properly identify the last line, which does not end in a new line character.

### II.3.18. Adding Records to Files

To add a new record to a text file, the value of the maximum index must be determined. Next, a line with an index equaling the maximum plus one is added to the file. Finally, the updated file is saved (Listing II.3.28).

### Listing II.3.28. Adding a record to file

```php
<?php
// The file's name
$filename = "text.txt";
$str = "Pascal programming";

// Determining the maximum index
$arr = file($filename);
$maxval = 0;
foreach($arr as $line) {
    preg_match('/^(\d+)([^\n]+)$/', $line, $out);
    if ($maxval < $out[1]) $maxval = $out[1];
}

// Reading the file
$content = file_get_contents($filename);
// Adding a new line
$content = "\n".($maxval + 1).$str;

// Saving the updated results
$fd = fopen($filename, "w");
fwrite($fd, $content);
fclose($fd);
?>
```

### II.3.19. Outputting Pages

To output file contents in three-record pages, the contents of the file are extracted and only the specified three records are displayed (Listing II.3.29). In this implementation, the number of records per page is stored in the $number variable and can be changed as desired.

### Listing II.3.29. Outputting pages

```php
<?php
// The file's name
$filename = "text.txt";
// Setting the number of records per page
$pnumber = 3;
// Opening the source file for reading
$buffer = file_get_contents($filename);

// Finding all lines using regular expression
preg_match_all("/(\d+) ([^\n]+)(\n|)$/u",
$buffer,
$out,
PREG_PATTERN_ORDER);

// Forming a temporary array
for($i = 0; $i < count($out[1]); $i++) {
	$temp[] = trim($out[2]);
}

// Checking whether the current page was passed
if(isset($_GET['page'])) $page = $_GET['page'];
else $page = 1;
// The number of pages
$total = count($temp);
$number = (int)($total/$pnumber);
if((float)($total/$pnumber) - $number != 0) $number++;

$start = ($page - 1) *$pnumber + 1;
$end = $page*$pnumber + 1;
if($end > $total) $end = $total;

// Displaying the contents of the pages
for($i = $start; $i < $end; $i++) {
	echo $temp[$i]."<br>";
}

// Outputting pages
for($i = 1; $i <= $number; $i++) {
    // Processing a page other than the last
    if($i != $number) {
        if($page == $i) {
            echo ($i - 1)*$pnumber + 1."".$i*$pnumber;
        } else {
            echo "<a href = $_SERVER['PHP_SELF']?page = ".$i."">".($i - 1)*$pnumber + 1)."-".$i*$pnumber."</a>";
        }
    }
    // If this is the last page, changing the last number to
    // the maximum number of elements in the $temp array
    else {
        if($page == $i) {
            echo ($i - 1)*$pnumber + 1."".($total - 1);
        } else {
            echo "<a href = $_SERVER['PHP_SELF']?page = ".$i."">".($i - 1)*$pnumber + 1)."-".($total - 1)."</a>";
        }
    }
}
?>
```
