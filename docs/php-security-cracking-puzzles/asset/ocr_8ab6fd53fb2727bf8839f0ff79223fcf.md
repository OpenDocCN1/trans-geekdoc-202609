# # Chapter I.6: User Agents and Referrers

![](bbox=[0.105, 0.201, 0.934, 0.375])

Every client that accesses the server can identify itself using the `USER_AGENT` agent, according to which it is possible to determine, which operating system is installed on the client machine and which browser is used. In general, it is also possible to determine whether this client is a human being or a robot.

Furthermore, using the referrer, it is possible to discover, from which the user was redirected to your site. If this was from the search engine, then you'll be able to determine the keywords entered by the user of the search system. The referrer allows you to trace the dynamics of visitors' navigation from external links to your site and their navigation among pages of that site.

However, both the agent and the referrer can be easily falsified. Therefore, you mustn't blindly rely on them. Remember that they can be falsified by a client at any moment.
