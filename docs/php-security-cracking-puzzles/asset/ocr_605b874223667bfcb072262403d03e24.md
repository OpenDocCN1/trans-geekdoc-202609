# Listing II.10.1. Using the fsockopen() function

```
<?php
function get_content($hostname, $path) 
{
    $line = "";
    // Establishing a connection with the host
    // whose name was passed in the $hostname variable
    $fp = fsockopen($hostname, 80, $errno, $errstr, 30);
    // Verifying the connection
    if (!$fp) echo "$errstr ($errno)<br />\n";
    else
    {
        // Constructing an HTTP request to
        // send to the server
        $headers = "GET $path HTTP/1.1\r\n";
        $headers .= "Host: $hostname\r\n";
        $headers .= "Connection: Close\r\n";
        // Sending the HTTP request to the server
        fwrite($fp, $headers);
        // Receiving a reply from the server
        while (!feof($fp))
        {
            $line = fgets($fp, 1024);
        }
        fclose($fp);
    }
    return $line;
}
$hostname = "www.php.net";
$path = "/";
// Setting a longer script execution time
// The page will not be displayed until
// all of it has been loaded.
set_time_limit(180);
// Calling the custom function
echo get_content($hostname, $path);
?>
```
