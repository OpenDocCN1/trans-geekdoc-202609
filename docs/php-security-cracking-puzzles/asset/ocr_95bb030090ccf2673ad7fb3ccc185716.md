Applying the explode() function to a line from the text.txt file creates the fourelement $data array. The date[0] element holds the user name, the date[1] element holds the passwords, the date[2] element holds the email address, and the date[3] element holds the URL of the user's home page. In the text.txt file are formed in the Windows format using the \n character sequence. The explode() function, however, is guided by UNIX-style newlines, which use only the \r character sequence. Consequently, to get rid of it, the array element will end in an invisible \r character sequence. The string is processed by the trim() function, which removes extra leading and trailing characters. Any user-supplied variable must be processed by the htmlspecialchars() function, which converts HTML tags into their HTML entities. This procedure guards against petty tricks users may play, for example, entering a redirect to their site (Listing II.3.32) instead of a user name.
