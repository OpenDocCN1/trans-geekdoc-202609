Sessions and cookies play an important role in building Web applications. They often are used as a target of attacks and as a tool for protection against attacks.

# I.5.1. Online Users

In many Web applications, such as chats, forums, and e-commerce sites, it is necessary to track currently active users and when they leave the site. Such a technique might also be useful for controlling protected areas of a site. For example, if only two users have access to a protected area but you notice that the third user is present, this would allow you to prevent penetration, or at least minimize its consequences.

Assume that user authorization is implemented on the site and that the user name is registered in the superglobal array named $_SESSION['user']. If the user is not an authorized user, then the system would display Anonymous instead of the user name.
