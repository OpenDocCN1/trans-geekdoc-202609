Successive searches start not from the beginning of the subject string but from the last match.

The flags parameter can be a combination of any of the following flags:

+   PREG_PATTERN_ORDER — If set, the results are ordered in the following fashion: The $matches[0] element contain an array of full pattern matches, the $matches[1] element holds an array of matches for the first parenthesized regular expression, the $matches[2] holds an array of matches for the second parenthesized expression, and so on. if three matches are found for the given regular expression, the last match for the pattern will be stored in the $matches[0][3] array element, and the match for the first parenthesized regular expression for the full match will be stored in the $matches[1][3] array element.

+   PREG_OFFSET_CAPTURE — If set, the results are ordered in the following fashion: The $matches[0] array element contains the first set of matches, the $matches[1] array contains the second set of matches, and so on. In this case, the $matches[0] array holds the first set of matches: The $matches[0][0] element contains the first match for the entire regular expression, the $matches[0][1] element holds the match for the first parenthesized regular expression, the $matches[0][2] elements holds the match for the second parenthesized regular expression, and so on. In the same fashion, the $matches[1] array holds the second set of matches, and so on, for each found set of matches.

+   PREG_SPLIT_OFFSET_CAPTURE — If set, the position of each found substring in the subject string is returned. The data for this flag are returned in a different format: For each match an array is returned where 0th element contains the substring and first element contains the offset.

The preg_match_all() function returns the number of found matches (there may be none) or FALSE if an error occurs during the execution.

To solve the original problem, all extraneous HTML tags must be removed from the text. The regular expression for one-letter words is \b[w]{1}\b s. The b sequence is boundary; unless it is specified, the regular expression \[w]{1} will correspond to each letter of any word.
