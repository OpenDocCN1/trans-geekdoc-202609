# II.1.11. Outputting Strings Vertically

A string can be output vertically using several approaches — for example, using the str_split() function as shown in Listing II.1.21.

# Listing II.1.21. Using the str_split() function

```
<?php
$str = "Hello world!";
$arr = str_split($str);
foreach($arr as $char) echo "$char<br>";
?
```

With the second method of vertical string output, it is possible to treat the string as an array of characters, in which index 0 corresponds to the first character.

# Listing II.1.22. Alternative method of vertical output

```
<?php
$str = "Hello world!";
for($i = 0; $i < strlen($str); $i++) echo $str[$i].<br>";
?
```
