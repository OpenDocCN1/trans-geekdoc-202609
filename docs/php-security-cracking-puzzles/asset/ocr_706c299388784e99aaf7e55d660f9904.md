# Chapter II.3: Working with Files

Listing II.3.18. Random output from a file

```
<?php
// The file's name
$filename = "text.txt";
// Placing the contents of the count.txt
// file into the $lines array
$lines = file($filename);
// Generating a random index for the $lines array
$index = rand(0, count($lines) - 1);
// Displaying the line number $index
echo $lines[$index];
?>
```

# II.3.16. Editing Files

To edit a file, its contents must be read. Then, the necessary string must be found using a regular expression and replaced with the specified replacement. An example of a script for doing this is shown in Listing II.3.19.

Listing II.3.19. Editing a file

```
<?php
// Looking for the line with index 7
$index = 7;
// The file's name
$filename = "text.txt";
// Opening the source file for reading
$fd = fopen($filename, "r");
// Reading the file's contents
$buffer = fread($fd, filesize($filename));
// Closing the file
close($fd);
// Locating the line with the $index index
$buffer = preg_replace("|[\\n]*",|", "$index C/++ programming", $buffer);
// Saving the updated results
```
