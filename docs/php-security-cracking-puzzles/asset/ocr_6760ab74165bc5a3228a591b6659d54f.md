At the beginning of the script, the GET order parameter is checked. If its value matches one table's column names, the $order variable is set to this value. Otherwise, the $order variable is set to the default value name. This cumbersome checking system is necessary to protect against SQL injection attacks. When the register_globals mode is enabled, the PHP interpreter automatically creates variables for GET parameters. This creates a possibility to pass an SQL injection through the order parameter when running the script. Therefore, when using the GET, POST, or COOKIE method, variables passed among pages must always be explicitly checked, because with these methods one of the intermediaries is the client machine, where the transmitted data can be modified.
