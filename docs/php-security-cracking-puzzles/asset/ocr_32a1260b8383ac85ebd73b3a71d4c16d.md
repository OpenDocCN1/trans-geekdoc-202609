# # Chapter II.2: Regular Expressions 133

The regular expression for locating the end of a sentence that will produce the best results is a period followed by space characters: \. [\s]+s. HTML tags may interfere with the splitting operations; therefore, use the solution in Section II.2.1 to remove them from the text. The complete code for solving the problem is shown in Listing II.2.12.

# ## Listing II.2.12. Splitting text into sentences

```
<?php
// Extracting the contents of the index.htm file
$content = file_get_contents("index.htm");

// The array of patterns
$search = array("<script[^>]*>.*?</script>","si",
    "\\<[^\/!]*?[^>]*>","si",
    "\\([\r\n]) [\\s]+","i",
    "\\&quot| #34;","i",
    "\\&amp| #38;","i",
    "\\&lt| #60;","i",
    "\\&gt| #62;","i",
    "\\&nbsp| #160;","i",
    "\\&excl| #161;","i",
    "\\&cent| #162;","i",
    "\\&pound| #163;","i",
    "\\&copy| #169;","i",
    "\\&#\\d+\;","e");

// The replacement array
$replace = array("",
    "",
    "\\\\1",
    "\\\",
    "&",
    "\\<",
    "/>",
    ">",
    chr(161),
    chr(162),
    chr(163),
    chr(169),
    \);
```
