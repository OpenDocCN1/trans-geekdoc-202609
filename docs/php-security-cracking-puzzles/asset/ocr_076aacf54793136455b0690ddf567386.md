With all preparatory work, creating a script for verifying a list of URLs is an easy task. The script shown in Listing II.14.7 reads a URL list from the links file, breaks it into components using the parse url() function, and places the checking results returned by the get_code() function into the links log file.

# Listing II.14.7. Verifying link validity

```
<php
// Breaking the contents of the links file
// into the $links array. Each element of the
// array holds a single file line.
$links = file("link");

$fd = fopen("link.log", "a");
if ($fd) {
    foreach ($links as $link) {
        $link = trim($link);
        $arr = parse_url($link);
        $code = get_code($arr['host'], $arr['path']);
        $str = date("d.M.Y H:i:s").trim($code).". "$link\r\n";
        fwrite($fd, $str);
    }
?>
```
