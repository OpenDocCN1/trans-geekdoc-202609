# # Chapter I.11: Electronic Mail

![](bbox=[0.105, 0.143, 0.933, 0.305])

Electronic mail, or email for short, is an integral part of the modern Internet. Consequently, good knowledge of email operations is a must for any Web developer.

> > NOTE All examples from this chapter can be found in the /scripts/11 directory on the accompanying CD-ROM.

# ## I.11.1. Sending Email from a Site

Develop a script for sending HTML ASCII-encoded email from a site. The current time and the size of the sending script must be sent in the body of the letter.

# ## I.11.2. Sending Email with Attachments

Develop a script for sending email from a site and allowing a file to be attached to any messages.
