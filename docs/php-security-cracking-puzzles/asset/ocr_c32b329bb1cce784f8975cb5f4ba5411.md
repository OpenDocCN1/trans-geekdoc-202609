# Chapter II.8: Using Information from Other Sites

# Listing II.8.11. Extracting URLs from an AltaVista search page

```
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://www.altavista.com/web/results?itag-odyq=regular+expression&kgs=0&klis=0";
// Loading the contents of the page
$contents = file_get_contents($url);
// The regular expression for URLs
$pattern = "|<span class="nn>([^<]+)</span>|isU";
// Performing a search against the regular expression
preg_match_all($pattern, $contents, $out, PREG_PATTERN_ORDER);
// Displaying the results of the search
for ($i=0; $i<count($out[1]); $i++) {
echo "http://"$out[1][$i]."<br>";
}
?>
```

A list of hyperlinks can be formed using the script shown in Listing II.8.12. URLs and headers are extracted in separate operations because it would be too difficult to construct a single regular expression; a mistake could be easily made.

Extracting information in several stages is a common practice. Also, pages are often broken into parts or cleaned of unnecessary fragments interfering with searches that use simple patterns.
