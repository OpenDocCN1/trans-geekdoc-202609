# II.13.3. Access Permissions

Create an HTML form with a text field to specify the file whose access permissions have to be changed and with nine check boxes to set the access permissions.

In UNIX, access permissions can be specified by an octal number. In this format, read rights are denoted by the digit 4, write rights by 2, and execution rights by 1 Overall rights for a group are specified by a sum of these digits. For example, 6 (4+2) denotes read and write rights, and 7 (4+2+1) gives full access to a file or directory.

Access permissions are changed using the chmod command. For example, to set access permissions for the index.php file to 777, the command is executed as follows:

```
chmod 777 index.php
```

Based on this script, a script like the one shown in Listing II.13.4 can be created.

# Listing II.13.4. Changing access permissions

```
<form method=post>
<table>
<tr><td>Name</td><td><input type=text name=name></td></tr>
<tr>
<td>Access permissions:</td>
<td>
<input type=checkbox title='Read by owner' name=ur>
<input type=checkbox title='Write by owner' name=uw>
<input type=checkbox title='Execute by owner' name=ux>
&nbsp; &nbsp;
<input type=checkbox title='Read by group members' name=gr>
<input type=checkbox title='Write by group members' name=gw>
<input type=checkbox title='Execute by group members' name=gx>
&nbsp; &nbsp;
<input type=checkbox title='Read by others' name=or>

<input type=checkbox title='Execute by others' name=ox>
</td>
</tr>
<tr><td>&nbsp;</td><td><input type=submit value='Set'></td></tr></table>
```
