# II.2.2. Removing Images from HTML Pages

Images can be removed from an HTML page using the `<img[^>]+>.si` regular expression as the pattern and an empty string as the replacement (Listing II.2.3).

Listing II.2.3. Removing images from HTML pages

```
<?php
// Extracting the contents of the index.htm file
$content = file_get_contents("index.htm");

// The regular expression
$search = "|<img[^>]+>|si";n// The replacement
$replace = "";

// Stripping image tags and displaying the text in the browser window
echo preg_replace($search, $replace, $content);
?>
```

The element has no ending tag; therefore, after the `<img` substring is found, all text between it and the closing angle bracket must be deleted. The subpattern used for this is `[^>]+`.

The title of an HTML page can be extracted using the `preg_match()` regular expression function, which has the following syntax:

```
int preg_match(string pattern, array matches (, int flags, , int offset))
```
