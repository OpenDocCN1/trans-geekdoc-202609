Line feed is implemented by prefixing all newline characters (\n) with the HTML soft carriage return tag <br>. This makes it possible to preserve the original formatting of the PHP source code code when displaying it in the browser window.

At the next stage, functions are highlighted. PHP has a huge number of functions; programmers can define their own functions. Therefore, the typical approach of creating a list of possible functions is impractical. On the other hand, all functions have one thing in common: When declared, they are followed by a parameter list enclosed in parentheses, which generally is empty. The function name can be followed by any number of space characters or even carriage return characters. Thus, the regular expression will be '\(\w+)(\s*)?\(\)i'. The regular expression for the function name is '\(\w)+', which specifies one or more letters. The spaces following the function name are expressed by the \(\s)* regular expression. Finally, the opening parenthesis is expressed by the \(\[ regular expression.

![](img/a893312ec68b8170fe567f785e95c06e_156_0.png)

The [\w] expression is equivalent to the [a-zA-Z0-9] expression; the [\s] expression is equivalent to the [\f\n\r\t\v] expression.

The second parameter of the preg_replace() function uses the result saved by the two parenthesized subexpressions: \1 corresponds to the function name and \2 corresponds to the spaces between the name and the opening parenthesis.

After functions are processed, operators are highlighted in dark green. The final stage consists of highlighting PHP reserved keywords (e.g., while, if, and else) in dark blue. Because selecting these keywords against the background of other program elements is rather difficult, they are enclosed in parentheses and stored in an array. This ensures that they are saved as the first parameter (\1). The $replace replacement array used as the second argument of the preg_replace() function is automatically formed using the array_fill() function. To highlight keywords used in other programming languages, keywords from this language must be placed into the $str array.
