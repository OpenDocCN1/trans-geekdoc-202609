The function starts by converting brackets, &lt; and &gt; into their HTML character entities: &lt;amp&gt; respectively.

Next, the &php<?, and ?? tags are highlighted in dark red. Because all brackets are converted into character representations at the previous stage, the regular expressions for all of these tags look as: '&lt;?php;si', '&lt;?&gt;:si', and '&gt;si. This operation is performed using the preg_replace function, and an array holding the replacement strings. The third parameter is the string, which contains the PHP code code, in which replacements are to be made.

After converting PHP tags, PHP comments are highlighted in light blue. The regular expression possible for this conversion, '((?:://)[^\n]|/\*)' can be broken into three parts. The '/\n*' part is responsible for highlighting multi-line, C-style comments (/*). The asterisks (*) and any number of characters can be contained within the / and * character sequences, specified by the *?. The (?:://)[^\n]* is responsible for highlighting single-line comments: those denoted with the double slashes (//) used in C++ and those denoted with the pound sign used in command-shell style ($). These comment characters can be followed by any number of characters, or no characters, but cannot be followed by the newline character sequence, as specified by (?: The character sequence specifies that the results for the given subexpression are not to be saved. This frees you from worrying about the number of saved results and uses the only saved result (1, which pertains to the outside parentheses) as the second parameter in the preg_replace() function when replacing the found matches.
