# I.3.24. Hacking a Guest Book

Listing I.3.3 contains the script for adding new messages to a guest book. Exploit the vulnerability contained in this code to delete all files in the directory, in which this script is located. Then correct the code to eliminate the vulnerability that allows the intruder to execute third-party code on the server.

> The script shown in Listing I.3.3 can be found in the /scripts/3/3.24/1.php file on the accompanying CD-ROM.

<?php
// Form handler
if(!empty($_POST['name']) && !empty($_POST['msg'])) {
    $msg = "<tr><td>\$POST['name']\</td></td>/</tr>";
    $msg = "<tr><td>\$POST['msg']\</td></td>/</tr>";
    // Open the file and add a new record to it.
    $fd = fopen("msg.txt", "a");
    if($fd) {
        fwrite($fd, $msg);
        fclose($fd);
    }
    // Outputting messages added to the text file
    echo "<table>";
if(file_exists("msg.txt")) include "msg.txt";
