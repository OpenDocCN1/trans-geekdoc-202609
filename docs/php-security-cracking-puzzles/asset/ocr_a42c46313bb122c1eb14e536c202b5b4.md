# # Chapter 1.2: Regular Expressions

![](bbox=[0.096, 0.196, 0.903, 0.363])

Regular expressions are a programming language in miniature. There are two approaches to solving a complicated problem: creating either a complex solution using a simple technology or an easy solution using a sophisticated technology. The situation is the same with regular expressions. Regular expressions are difficult to master; however, after grasping their main idea, you'll be able to provide short and neat solutions to problems that would require hundreds of lines of code if solved using string functions. In Chapter 1.1, it was mentioned that the shorter program, the lower its concentration of errors. Regular expressions make it possible to create not simply short programs but concise ones. This chapter considers several problems directed at developing skills for working with regular expressions.
