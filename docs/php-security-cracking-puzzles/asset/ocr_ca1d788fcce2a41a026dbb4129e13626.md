# ## II.7.5. Password Generator

One way to generate passwords is to randomly select their characters from an array of possible password characters. The frequency of the character distribution in the password can be controlled by repeating certain array elements. For example, letters are often doubled by uppercase letters, because a password with lots of uppercase letters looks "nice." This impulse must be suppressed, because changing the frequency distribution of the password characters plays into hands of male-factors: It allow them to significantly reduce the time it takes to guess the password once they learn the specifics of the password-generating algorithm.
