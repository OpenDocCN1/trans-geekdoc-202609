# Chapter 1.8: Using Information from Other Sites

![](bbox=[0.097, 0.187, 0.903, 0.405])

Information made publicly available on a Web site may be specially prepared for use on sites other than the original without any additional processing. That is, information can be downloaded from one site and displayed on another as an HTML page in the browser window. Such specially prepared information is usually available as extensible markup language (XML) files. The Rich Site Summary (RSS) format has become popular on the Internet for distributing news, price lists, catalogs, and similar information. You should know how to prepare RSS files and read them using both standard means for reading XML files and regular expressions. The latter is necessary when the syntax of an XML file deviates from the standard syntax or a file is too large to be processed by a PHP script, for which only 16 MB are usually allocated on servers.

Such information is typically made available as regular XML pages, which have to be parsed. If you intend to use information from other sites on your site, you have to ask for the owner's permission. Network relations place no limitations on what browser can be used to view a site's contents; you are not required to do this with a classic browser such as Internet Explorer or Opera but can use, for example, a PHP script. Thus, you have the right to manipulate the contents of other people's sites in any way: Save them in databases, load them onto the local host, and so on.
