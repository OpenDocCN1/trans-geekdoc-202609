
## II.1.8. Passing an Array Using Sessions

To initialize a session, it is enough to place the call to `session_start()` function into the beginning of the script. After that, it is possible to place any data into the `$_SESSION` superglobal array. All data placed one page will be available on another page.

### Listing II.1.15. The script that uses sessions to pass an array

```php
<?php
$filename = array("all.php", "auth.php",
"auth.txt", "base.txt",
"chat.html", "config.php",
"count.txt", "count_new.txt",
"counter.dat", "counter.php",
"create.php", "dat.db");

// Initiating the session
session_start();
// Removing old data
unset($_SESSION['filename']);
// The loop forms hidden fields containing array elements.
foreach($filename as $name) {
    $_SESSION['filename'][] = $name;
}
// Outputting the link to the second.php page
echo "<a href='second.php'>Go to second.php</a>";
?>
```

To access the `$_SESSION` superglobal array on the second.php page, it is necessary to include the call to `session_start()` function into the beginning of the script (Listing II.1.16).

### Listing II.1.16. The script that outputs the dump of the $_SESSION superglobal array

```php
<?php
// Initiating the session
session_start();

echo "<pre>";
print_r($_SESSION);
echo "</pre>";
?>
```

The data placed into the session will be available only to the user that called them. Third-party users cannot view this data without knowing the unique session identifier (SID). The data are stored on the server, and the server and client exchange information using the unique SID. The SID is passed as a parameter in the address string or using cookies. Lastly, session cookies are most common. Because the unique SID is passed through cookies, working with sessions has the same features as working with hypertext transfer protocol (HTTP) headers, which means that headers must be sent before the document body. This means that the call to `session_start()` function must take place before any output into the browser window using functions such as `echo`, `print`, or any symbols not enclosed in `<php` and `?>` tags.

## II.1.9. Passing an Array Using Cookies

Cookies are small text files located on client computers. Some information stored in cookies is limited, and some users disable cookies in the settings of their browsers. However, in contrast to sessions, the lifetime of cookies is set by the developer. As a rule, sessions exist only until the client exits the browser or for a strictly-defined interval, which usually doesn't exceed a few hours. Cookies are set using the `setcookie()` function, after which PHP scripts, including scripts located on different pages, provide the possibility of accessing the saved values using the `$_COOKIE` superglobal array. Unfortunately, it is difficult to set the array value using the `setcookie()` function. Therefore, it is expedient to pack the array into the string using the `serialize()` function. Later, the string obtained using `serialize()` function can be expanded into an array using the `unserialize()` function.

The `serialize()` and `unserialize()` functions are especially convenient to use when passing multidimensional arrays. This is because the transmission is reduced to passing a single text string.

### Listing II.1.17. Using cookies to pass arrays

```php
<?php
$filename = array("all.php", "auth.php",
    "auth.txt", "base.txt",
    "chat.html", "config.php",
    "count.txt", "count_new.txt",
    "counter.dat", "counter.php",
    "create.php", "dat.db");

// Packing the array into the string
$content = serialize($filename);
// Setting the cookie
// Here, time() + 3600 is the cookie lifetime.
// Setting the lifetime to 1 hour
setcookie('filename', $content, time() + 3600);
// Outputting the reference to the second.php page.
echo "<a href='second.php'>Link to the second.php page</a>";
?>
```

Now, to obtain access to the `$filename` array, it is necessary to retrieve the array from the cookie. This script is shown in Listing II.1.18.

### Listing II.1.18. Retrieving an array from the cookie

```php
<?php
// Retrieving the packed array
// from the cookie
$filename = unserialize(stripsslashes($_COOKIE['filename']));
// Outputting the contents of the array
echo "<pre>";
print_r($filename);
echo "</pre>";
?>
```

Before saving the data in the cookie, all special characters and quotation marks are preceded by an escape character, the backslash. Therefore, for the `unserialize()` function to unpack the array, it is necessary to get rid of extra backslash characters using the `stripsslashes()` function.
