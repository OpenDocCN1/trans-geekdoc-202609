# Listing II.2.15. Counting words with a different number of letters

```
<php
for($i = 1; $i <= 10; $i++)
{
    // Counting one-letter words
    preg_match_all("\\b[w].{$i}\\b", $content, $out, PREG_PATTERN_ORDER);
    print "The number of $i-letter words is: ".count($out[0])."<br>";
}
?>
```
