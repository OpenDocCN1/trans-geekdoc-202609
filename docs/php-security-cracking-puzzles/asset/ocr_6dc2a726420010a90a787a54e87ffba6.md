# II.1.8. Passing an Array Using Sessions

To initialize a session, it is enough to place the call to the session_start() function into the beginning of the script. After that, it is possible to place any data into the $ SESSION superglobal array. All data placed one page will be available on another page.

Listing II.1.15. The script that uses sessions to pass an array

```
<?php
$filename = array("all.php", "auth.php",
"auth.txt", "base.txt",
"chat.html", "config.php",
"count.txt", "count_new.txt",
"counter.dat", "counter.php",
"create.php", "dat.db");

// Initiating a session
session_start();
// Removing old data
unset($ SESSION['$filename']);
// The loop forms hidden fields
// containing array elements.
foreach($filename as $name) 
{
    $SESSION['$filename'][] = $name;
}
// Outputting the link to the second.php page
echo "<a href = second.php>Go to second.php page</a>\";
?>"
```

To access the $ SESSION superglobal array on the second.php page, it is necessary to include the call to the session_start() function into the beginning of the script (Listing II.1.1.16).

Listing II.1.16. The script that outputs the dump of the $ SESSION superglobal array

