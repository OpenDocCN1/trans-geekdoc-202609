# II.13.4 Archives

The .tar.gz archives are built in two stages: First, all files in the directory are joined into one file with the .tar extension; next, the obtained TAR file, or "tarball," is compressed with the help of the Gzip utility and is given the .tar.gz extension. A .tar.gz archive is unpacked in the reverse order: First, the archive is unpacked into a TAR file, which is then broken into the individual files. Files are joined into a TAR file using the Tar utility. The utility can also be used to compress files, for which it is run with the `z` option specified (Listing II.13.7).

# Listing II.13.7. Archiving the current directory

```
<?php
// Archiving files
exec("tar cvfz dir.tar.gz .");
?>
```

A .tar.gz archive can be unpacked and separated using the script shown in Listing II.13.8.

# Listing II.13.8. Unpacking a .tar.gz archive into the current directory

```
<?php
// Unpacking files
exec("tar xvf dir.tar.gz");
?>
```
