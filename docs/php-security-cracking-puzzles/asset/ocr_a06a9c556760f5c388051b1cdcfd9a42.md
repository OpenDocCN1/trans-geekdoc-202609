# Chapter II.2: Regular Expressions 121

The first three parameters of the preg_replace() function can be one-dimensional arrays. When an array with string keys is processed, the keys are referenced in the order, in which they are located in the array.

When the pattern and replacement parameters are arrays, preg_replace() sequentially extracts a pair of elements from both arrays and uses them for search and replace operations. If the replacement array has more elements than the pattern array, the missing replacement elements in it are replaced with null strings. If the pattern parameter is an array and the replacement parameter is a string, the target string is compared with each element of the pattern array, and any found matches are replaced with the replacement string. In other words, each element of the pattern array is used sequentially as the pattern, and the replacement string is fixed. The option, in which pattern is a string and replacement is an array, is meaningless.

Perl-compatible regular expressions must be enclosed in delimiter characters. In II.2.1, the single quote character is used as the delimiter. Any symbol other than an alphanumeric character or backslash can be used as the delimiter. A delimiter character used within a regular expression, must be preceded by an escape character, the backslash. The ending delimiter may be followed by modifiers that affect the entire regular expression. The i modifier specifies that the regular expression is case-insensitive; the s modifier means that the regular expression takes multiple lines.
