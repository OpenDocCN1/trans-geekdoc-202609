# II.4.9. Double Drop-Down List

The first drop-down list is displayed on an HTML form with the <select> tag, located in the loop for processing the results of an SQL query, selecting records from the catalogs table. Each list item <option> is a catalog name, and the value attribute takes the value of the primary key of the current catalog. To-automatically reload the form, a handler for the onChange event (i.e., when an item is selected from the list) is added to the <select> tag as follows: onchange='this.form.submit()'. After the page is reloaded, the id_parameter (the name of the first drop-down list) is monitored for having been passed. To prevent potential SQL injection attacks, you must also check that this parameter is an integer. A regular expression is used for this purpose.
