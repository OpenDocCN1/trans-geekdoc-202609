Verifying the complete set of parameters is passed using the GET method is not the best solution, because the total parameter can also be passed using the POST method or even in a cookie. An effective solution would be to set the value of the register_globals variable in the php.ini configuration file or in the .htaccess file to Off(register_globals off and php_flag register_globals off, respectively).

However, these configuration files are not always accessible to site owners on rented servers; therefore, the most appropriate solution is to correct the code itself. This can be done by getting rid of the $total variable, as shown in Listing II.7.17.
