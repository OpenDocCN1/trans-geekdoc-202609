Using the mail() function is a rather labor- and resource-intensive procedure. Posting more than 100 messages using this function may take a significant amount of time. This may be unacceptable if the posting script is linked to the script for adding new forum or bulletin board messages. In this case, it is better to list the recipient addresses in Cc or Bcc mail headers. With the first option, each recipient will see the other recipients; with the second option, will not. A script for implementing this type of mass mailing may look like the one shown in II.11.6.

![](bbox=[0.056, 0.532, 0.128, 0.626])

> Any number of Bcc or Cc headers can be added to a message. Each header accepts one address. For example, Bcc: somebody@mail.com\r\n.
