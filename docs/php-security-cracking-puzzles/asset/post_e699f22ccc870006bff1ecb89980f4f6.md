Files are downloaded from an FTP server using the ftp_nb_get() function, whose general syntax is the following:

```
int ftp_nb_get(resource link, string local_file,
string remote_file, int mode, int resumpos);
```

The function accepts the link identifier of an open FTP connection as the first parameter. The second parameter, local_file, specifies the path, at which the downloaded file is to be saved to the local machine. The third parameter, remote_file, is the path, at which the file to be download is located on the FTP server. The fourth parameter, mode, defines the mode to be used for the transfer: FTP_ASCII for text files or FTP_BINARY for binary files. The optional fifth parameter, resumpos, can be used to specify the position in bytes, from which the file transfer is to resume.

The function returns one of three constants listed previously for the ftp_nb_put() function.

## Chapter II.9: File Transfer Protocol

Listing II.9.6 shows a script for downloading files from an FTP server. As in the file upload script in Listing II.9.5, the file download process is controlled in a while loop using the ftp_nb_continue() function considered previously.

## Listing II.9.6. Downloading a file from an FTP server

```php
<?php
// Opening a connection to the FTP server
require_once("config.php");
// Initializing file download
$ret = ftp_nb_get($link, "C:\file.zip", "/path/file.zip", FTP_BINARY);
// The download loop
while ($ret == FTP_MOREDATA) {
// Displaying dots to inform the user
// that the download is in progress
echo ";";
// Continuing the download
$ret = ftp_nb_continue($link);
}
// If an error occurs during the download,
// the user is informed about it
if ($ret != FTP_FINISHED) {
    exit("<br>Error downloading the file...");
    exit();
}
?>
```

## II.9.4. Changing Access Permissions

In addition to specifying access permissions in text form as described previously, in UNIX access permissions can be specified using octal numbers. In this format, read permissions are denoted by the digit 4, write permissions by 2, and execution permissions by 1. Overall permissions for a group are specified by a sum of these digits. For example, 6 (i.e., 4+2) denotes read and write permissions, and 7 (i.e., 4 + 2 + 1) gives full access rights to a file or directory. Using this format, the octal number 0755 means that the directory owner has full rights (rwx) and all other users view files in the directory and view the contents of the directory (r-x).

In PHP, octal numbers are prefixed with a zero.

Access permissions for files and directories are set using the ftp_chmod() function, which has the following general syntax:

```
string ftp_chmod(resource link, int mode, string directory)
```

Most like other FTP functions, the function accepts the link returned by the ftp_connect() function as the first parameter. The second parameter, mode, is an octal number specifying permissions for the directory. The last parameter, directory, names the directory whose access permissions are being changed. The function returns the newly-assigned permissions if there is success and otherwise returns false. Listing II.9.7 shows a script for setting file or directory access permissions.

## Listing II.9.7. Setting access permissions for files and directories

```php
<?php
// Opening a connection to the FTP server
require_once("config.php");
// Setting the directory's access permissions
ftp_chmod($link, 0755, "logs");
// Changing the file's access permissions
ftp_chmod($link, 0644, "/path/file.zip");
?>
```

## II.10.1. Downloading a Page

A connection to the remote server is opened using the `fsockopen()` function, whose general format is the following:

```
resource fsockopen (string target, int port [, int errno [, string errstr [, float timeout]]])
```

The function accepts five parameters, the first two of which are mandatory. These are the host address, `target`, and the port number, `port`. The function returns a file pointer if there is a successful connection attempt, and otherwise returns false. If the optional `errno` and `errstr` parameters are passed to the function, the error code and a text description, respectively, are placed into them. The fifth parameter, also optional, specifies the timeout (in seconds) for establishing a connection.

Listing II.10.1 shows an example of using the `fsockopen()` function in a script to download the home page of the `http://www.php.net` site.

## Listing II.10.1. Using the fsockopen() function

```php
<?php
function get_content($hostname, $path) 
{
    $line = "";
    // Establishing a connection with the host
    $fp = fsockopen($hostname, 80, $errno, $errstr, 30);
    // Verifying the connection
    if ($fp) {
        // Constructing the HTTP request
        $headers = "GET $path HTTP/1.1\r\n";
        $headers .= "Host: $hostname\r\n";
        $headers .= "Connection: Close\r\n\r\n";
        // Sending the request to the server
        fwrite($fp, $headers);
        // Receiving a reply from the server
        while (!feof($fp)) {
            $line .= fgets($fp, 1024);
        }
        fclose($fp);
    } else {
        // Output the error
        echo "Error: $errstr ($errno)<br>";
    }
    return $line;
}
$hostname = "www.php.net";
$path = "/";
// Setting a longer execution time
set_time_limit(180);
// Calling the function
echo get_content($hostname, $path);
?>
```
