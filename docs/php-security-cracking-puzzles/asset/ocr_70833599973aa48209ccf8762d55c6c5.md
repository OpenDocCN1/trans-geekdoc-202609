When the script is loaded for the first time, the first form opens. The only controls that the form has are filename and the Open button for sending data, using the GET method, to the handler, which is located in the same file. If the $_GET['filename'] array is not empty, the file's contents are loaded into the buffer variable, from which the contents are placed into the text area of the second form. In addition to the content text field, the form contains a hidden field filename, through which the file's name is sent. When the button of the second form is pressed, the edited data are sent to the current script again, but this time using the POST method. If the $_POST['content'] array is not empty, the form handler at the beginning of the script retrieves the contents of the file being edited. To ensure proper script execution at the end of the handler, the name of the file is copied from the $_POST into the $_GET-global array. The @ character is attached to the beginning of the fopen() function to suppress the PHP warning messages in the browser window when the function cannot find the text file.
