# # Chapter 1.9: File Transfer Protocol

![](bbox=[0.049, 0.187, 0.871, 0.355])

The file transfer protocol (FTP) is one of the oldest application protocols. It was first developed in 1971, long before the Web came into being. Until the early 1990s, FTP was responsible for half of the Internet traffic. The protocol is still used today for distributing software and accessing remote hosts. This chapter considers how to develop an HTTP Web application for accessing a remote FTP server from another remote server or from a local machine running an Apache+PHP package.

FTP is defined in request for comment (RFC) 959, available at http://www.faqs.org/rfcs/rfc959.html.

All examples from this chapter can be found in the /scripts/9 directory on the accompanying CD-ROM.
