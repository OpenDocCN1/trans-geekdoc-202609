## II.3.13. Uploading a File in Parts

Suppose that there is a file, site.rar, that must be broken into parts, each 10,000 bytes in size. Listing II.3.15 shows a script that can be used to carry out this task.

# Listing II.3.15. Breaking a file into parts

```php
<?php
// The file's name
$filename = "site.rar";
// Breaking the file into 10,000-byte parts
$piece = 10000;
// Opening the source file for reading
$fp = fopen($filename, "r");
// Reading the file's contents into a buffer
$buffer = fread($fp, filesize($filename));
// Closing the file
close($fp);
// Calculating the number of parts,
// into which the file should be broken
$count = (int)filesize($filename)/$piece;
if((float)filesize($filename)/$piece) - $count != 0) $count++;
// A loop to break the file's contents
// in the $buffer variable into parts
for($i = 0; $i < $count; ++$i) {
    $part = substr($buffer,$i*$piece,$piece);
    // Saving the current part in a separate file
    $fp = fopen("site.tm".$i, "w");
    fwrite($fp, $part);
    fclose($fp);
}
?>
```

Each of the resulting parts produced by the script is given the extension .tmN, where N is the part's number. The script shown in Listing II.3.16 performs the inverse task of assembling the file from the parts.

# Listing II.3.16. Assembling the file from its parts

```php
<?php
$buffer = "";
for($i = 0; $i < 100000; ++$i) {
    // Generating a file name
$filename = "site.tm";$i;
// If a file with this name exists,
// adding its contents to $buffer
if (file_exists($filename)) {
    $fp = fopen($filename, "r");
    $buffer = fread($fp, filesize($filename));
    fclose($fp);
} else {
    // If there is no file with such a name,
    // leaving the loop
    break;
}
// Placing the parts assembled in the $buffer
// variable into the final file
$fp = fopen("site_final.rar", "w");
fwrite($fp, $buffer);
fclose($fp);
}
?>
```

## II.3.15. Random Output from a File

This problem of outputting a random line requires the rand() function (Listing II.3.18). The function's syntax is the following:

```php
int rand (int min, int max);
```

The function generates a random integer in the range specified by two optional integer parameters, min and max. If the parameters are not specified, the function generates a random integer in the 0 to RAND_MAX (32,768) range.

Unless a random number generator is seeded, it always generates the same sequence. Usually, a random number generator is seeded manually. In PHP, the rand() function is used to seed the random number generator.
