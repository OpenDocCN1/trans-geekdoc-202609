# Listing II.4.34. Uploading MP3 files to a database

```php
<form enctype='multipart/form-data' method='post'>
<input type="file" name="mp3"><br>
<input type="submit" value="Upload">
</form>
<?php
// Connecting to the database
require_once("config.php");

// The HTML form handler
if(!empty($_FILES)) {

    // Checking whether the uploaded file is in the MP3 format
    if($_FILES['mp3']['type'] == 'audio/mpeg') {

        // Reading the file's contents
        $content = file_get_contents($_FILES['mp3']['tmp_name']);

        // Deleting the file in the temporary directory
        unlink($_FILES['mp3']['tmp_name']);

        // Escaping special characters in the file's binary contents
        $content = mysql_escape_string($content);

        // Constructing a query to add the file to the table
        $query = "INSERT INTO mp3 VALUES
(NULL, '" . $_FILES['mp3']['name'] . "', '" . $content . "')";
        if(mysql_query($query)) {

            // Automatically reloading the page
            // to clear the POST data
            echo "<HTML><HEAD>
            <META HTTP-EQUIV = 'Refresh' CONTENT = '0; URL = $SERVER['PHP_SELF']'
            </HEAD></HTML>";
        } else exit(mysql_error());
    }
}

// Listing the files
$query = "SELECT * FROM mp3";
$mp = mysql_query($query);
if (!$mp) exit(mysql_error());
// If there is at least one record,
// displaying it
if (mysql_num_rows($mp) > 0)
{
    while ($mp3 = mysql_fetch_array($mp))
    {
        echo "<a href=get.php?id_mp3=$mp3[id_mp3]$mp3[name]</a><br>";
    }
}
?>
```

After an MP3 file is uploaded to the server and into the temporary directory, the following if construction checks that the file actually is in the MP3 format:

If it is, the contents of the file are transferred to the $content variable and the temporary file is deleted using the unlink() function. Before the contents of the MP3 file are placed into the database, they are processed by the mysql_escape_string() function to escape special characters that may be distorted when the query is transferred over the network.

The code at the end of the script displays a list of the MP3 files already in the database. Each list item is a hyperlink to the get.php file. The primary key of the record-must be made available for downloading is passed to this file using the id_mp3 parameter. The script of the get.php file may look as shown in Listing II.4.35.

# Listing II.4.35. Transferring a file from the database to a user

```php
<?php
// Connecting to the database
require_once("config.php");

// Checking whether the id mp3 parameter
// was passed and whether it's an integer,
// thus protecting against an SQL injection
if(!preg_match("^|\\d]+$", $_GET['id_mp3']))
{
    exit("Invalid format of the URL query!");
}
// Extracting the MP3 file from the database
$query = "SELECT * FROM mp3
WHERE id_mp3 = $_GET['id_mp3']";
$mp3 = mysql_query($query);
if (!$mp3) exit(mysql_error());
$file = mysql_fetch_array($mp3);

// Setting the name of the file to download
header("Content-Disposition: attachment; filename = $file[name]");
// Sending headers for file download
header("Content-type: application/octet-stream");
// Sending the file to the user
echo $file['content'];?>
?>
```

After a regular expression checks that the GET id_mp3 parameter is a number, the record of the requested MP3 file is extracted from the mp3 table. Next, HTTP headers with the file's name and the content description (binary data) are sent to the browser. Unless these headers are sent, the browser will treat the file as a regular page and display it. In the final part of the script, the echo () function sends the binary data.

> The echo $file['content'] statement must not be followed by any output to the browser window, including spaces and line feeds after the >> tag, if it is, the file will be corrupted.

## II.4.12. Saving Images in a Database

To store images in a MySQL database, create a table named image, one of whose fields will be the BLOB type. The image table consists of the following three fields:

- id_image — Primary key with the AUTO_INCREMENT attribute
- name — File's name
- content — Binary contents of the graphics file

# Listing II.4.36. The image table

```sql
CREATE TABLE image (
id_image INT(11) NOT NULL auto_increment,
name tinytext NOT NULL,
content longblob NOT NULL,
PRIMARY KEY (id_image)
) TYPE = MyISAM;
```

Like MP3 files, image files are usually large; therefore, make sure that all server directives allow you to work with them. See the preceding section for more information about the specific directives.

Listing II.4.37 shows the script for uploading graphics files to the server and storing them in a database.
