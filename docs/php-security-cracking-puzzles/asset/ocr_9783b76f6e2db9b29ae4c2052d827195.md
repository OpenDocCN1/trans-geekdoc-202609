Another way to verify uploaded files is to check the type of the uploaded file stored in the $FILES['filename']['type'] array element. For uploaded graphics files, values of the type image/gif, image/jpeg, and the like are placed into this array element, and the text/plain value is used for PHP and HTML files. If only graphics files can be uploaded, their validity can be verified by checking this array element using a script similar to the one shown in Listing II.3.4.
