# II.8.7. Determining the Exchange Rate History

To solve this problem, a URL must be constructed and the XML file loaded.
A script for doing this is shown in Listing II.8.15.

> If you have no broadband Internet access, the XML file should be saved to the local
hard drive first.

Listing II.8.15. The exchange rate history for the euro against the dollar
in table format

```
<php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://www.ecb.eu/stats/eurofxref/eurofxref-hist.xml";
// Loading the contents of the page
$contents = file_get_contents($url);

// Extracting the date and the rate for the euro against the dollar
$pattern = "||<Cube time="([^"]+)"\>Cube currency=\n"USD\" rate="([^"]+)"\>is";";
// Performing a search against the regular expression
preg_match_all($pattern, $contents, $out, PREG_PATTERN_ORDER);
// Displaying the results of the search
$begin_date = "";
if (count($out[1]) > 0) {
    echo "<table border=1>";
    for ($i = 0; $i < count($out[1]); $i++) {
        echo "<tr><td>"$.$out[1][$i]."/</td><td>"$.$out[2][$i]."/</td></tr>";
    }
    echo "</table>";
    if (empty($begin_date)) {
        // The starting date
        $begin_date = mktime(0);
        0,
        0,
    }
}
```
