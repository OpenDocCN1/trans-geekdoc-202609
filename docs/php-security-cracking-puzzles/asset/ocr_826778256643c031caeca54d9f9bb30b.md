After the input data are verified, a check is made for whether a file was attached to the message. If no file is attached, the message is sent using the standard mail() function. If a file is attached, it is loaded from the temporary directory into the current one and the message is posted using the custom send_mail() function. The first three parameters of the send_mail() function are the same as those of the mail() function. The fourth parameter is the name of the file that has to be attached to the message. Afterward, the function forms the body of the message and the mail headers for posting the message with the attached file.

# II.11.3. Mass Mailing

Mass mailing can be implemented in the following two ways:

+   - Sending messages in a loop, sequentially going through email addresses. This method is used when a unique message is sent to each address.

+   - Sending messages listing the recipient addresses in mail headers. This method is used when the same message is sent to all recipients.

Listing II.11.5 shows a script for sending messages using the first method.
