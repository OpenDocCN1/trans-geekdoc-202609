# II.8.2. Extract Links from Yahoo

Load the page specified by the following URL into the browser:

```
http://search.yahoo.com/search?p=PHP&sm=Yahoo%21+Search&fr=
FP-tab-web-t&toggle=1&cop&ei=UTF-8
```

Save it as a file name search.php on the hard drive to make it more convenient to analyze its HTML code.

In Internet Explorer, the HTML code of a Web Page is obtained by right-clicking the page and selecting the View Source item in the context menu that appears.

A link to a search item looks as follows:

```
< A class=yschttl
href="http://rds.yahoo.com/?ylt=A9htddlc.M9DXG8B4j1lXNyoA;ylu=

/SIG=-117gljb0/EXP=1317789404**http://www.php/net/"><B>PHP</B>
Hypertext Preprocessor</>
```
