
# Listing II.5.5. The session.php file

```php
<?php
// Opening the session
function open($save_path, $session_name)
{
    // Network address of the MySQL server
    $dblocation = "localhost";
    // Database name
    $dbname = "boo";
    // Database user
    $dbuser = "root";
    // User password
    $dbpasswd = "";
    // Establishing the database connection
    $dbcnx = mysql_connect($dblocation, $dbuser, $dbpassword);
    if (!$dbcnx) exit(
        ("Unfortunately, MySQL server is not available: ".mysql_error());
    );
    // Selecting the database
    if (!$mysql_select_db($dbname, $dbcnx))
    exit("Unfortunately, the database is not available: ".mysql_error());

    return true;
}

function close()
{
    // Closing the database connection
    mysql_close();

    return true;
}

function read($id)
{
    // Reading the session value
    $query = "SELECT * FROM session WHERE session = '$id'";
    $ses = mysql_query($query);
    if(!$ses) exit(mysql_error());
    $session = mysql_fetch_array($ses);
    // Returning the data placed into the session
    return $session['value'];
}

function write($id, $sess_data)
{
    // Checking whether the session with this name
    // has been registered
    $query = "SELECT COUNT(*) FROM session WHERE session = '$id'";
    $ses = mysql_query($query);
    if(!$ses) exit(mysql_error());
    if(mysql_result($ses, 0) > 0)
    {
        // This is the first attempt at accessing the session; therefore;
        // it is necessary to register this session in the database.
        $query = "INSERT INTO session
        VALUES (NULL, '$id', NOW(), '$sess_data')";
        $ses = mysql_query($query);
        if(!$ses) exit(mysql_error());
        return true;
    }
}

function destroy($id)
{
    // Removing the session with the $id identifier
    $query = "DELETE FROM session WHERE session = '$id'";
    if(!mysql_query($query)) exit(mysql_error());
    return true;
}

function gc($maxlifetime) {
  // "Taking out the trash,
  // or deleting old records
  $query = "DELETE FROM session"
  WHERE putdate < NOW() - INTERVAL 20 MINUTE;
  if(!mysql_query($query)) exit(mysql_error());
  return true;
}

session_set_save_handler("open",
"close",
"read",
"write",
"destroy",
"gc");
```

# Listing II.5.6. Using the custom sessions mechanism (index.php)

## II.5.3. Protecting HTML Forms Using Sessions

If the document is in use, it is possible to deny access to a second user trying to access it, thus ensuring data consistency and integrity. In other words, there are lots of application areas for the custom sessions mechanism.

HTML forms often must be protected when it is necessary to secure the service on your site against access from the third-party servers. To achieve this, it is necessary to relate the HTML form to the session. Having obtained the SID using the session_id() function in the index.php file, it is necessary to place it into the hidden field of the form that requires protection (Listing II.5.9).

Listing II.5.9. Corrected variant of the index.php file

```php
<?php
// Initiating the session
session_start();
?>
<table>
<form action=2.php method=post>
<input type=hidden name=session_id value='<?php session_id(); ?>'>
<tr>
<td>Name:</td>
<td><input type="text" name=name></td>
</tr>
<tr>
<td>Password:</td>
<td><input type="password" name=pass></td>
</tr>
<tr>
<td>&nbsp;</td>
<td><input type="submit" value='Enter'></td>
</tr>
</form>
</table>
```

After that, the HTML form checks whether the SID obtained from the HTML form matches the current value.

## II.5.5. Forging Cookies

To forge a cookie, the script sends the following HTTP header:

```
Cookie: name1 = value1; name2 = value2; ...
```

Here, name1, name2, and so on, are cookie names; value1, value2, and so on, are their values.

# Listing II.5.12. The script that forges cookies

```php
<?php
$hostname = "localhost";
$path = "/test/1.php";

// Establishing the connection whose name is passed
// in the $hostname parameter
$fp = fsockopen($hostname, 80, $errno, $errstr, 30);
// Checking whether the connection has been established successfully
if (!$fp) echo $errstr.<br />\n";
else {
    // Forming HTTP headers to be passed to the server
    $headers = "GET $path HTTP/1.1\r\n";
    $headers .= "Host: $hostname\r\n";
    // Forging the cookie
    $headers .= "Cookie: name=cheops; admin=1\r\n";
    $headers .= "Connection: Close\r\n\r\n";
    // Sending an HTTP query to the server
    fwrite($fp, $headers);
    // Sending the following response: while (!feof($fp)) {
        $line = fgets($fp, 1024);
    }
    fclose($fp);
    echo $line;
}
?>
```
