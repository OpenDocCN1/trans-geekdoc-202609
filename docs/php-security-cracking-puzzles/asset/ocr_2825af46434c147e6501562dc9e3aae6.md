# I.7.3. Guessing a Password

In the previous section, you were shown how to protect data using irreversible encryption. However, this doesn't make an attack on passwords impossible. After all, a password can be guessed. Listing I.7.1 contains four passwords encrypted using the MD5 algorithm. Decrypt these passwords using a brute-force attack.

> These passwords can be found in electronic form in the /scripts/7/password file on the accompanying CD-ROM.
