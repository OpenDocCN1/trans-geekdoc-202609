The $begin_date variable holds the starting date as the number of seconds elapsed from midnight, January 1, 1970. The $current_date variable holds the current date in the same format.

The XML file can be parsed using standard PHP extensions, but these don't work with XML files of the wrong syntax and are somewhat inconvenient. For example, if 300 KB of a 2-MB file are loaded, any standard XML parser will refuse to work with the cut-down XML file. Another extreme is XML files larger than 10 MB. PHP scripts are usually allocated only 8 MB for their needs (less than 16 MB are allocated), and parsing a 10-MB file will require 20 MB at the minimum. Regular expressions are more flexible because they allow a file to be parsed in parts.
