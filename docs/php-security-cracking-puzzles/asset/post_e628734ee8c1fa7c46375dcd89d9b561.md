### II.4.7. Alphabetic Navigation

The alphabetization problem can be solved by extracting the first letters of the spare parts' names from the products table and grouping them using the GROUP construction. Listing II.4.23 shows a query that does this.

Listing II.4.23. A query to extract the first letters of spare parts' names

```sql
SELECT SUBSTRING(name, 1, 1) AS letter
FROM products
GROUP BY letter
ORDER BY letter
```

Next, the obtained letters are used to form links, and the selected letter is passed using a GET parameter. A query to select all item names starting with the selected letter is shown in Listing II.4.24.

Listing II.4.24. A query to select items that start with the chosen letter

```sql
SELECT * FROM products
WHERE SUBSTRING(name, 1, 1) = 'D'
ORDER BY price
```

Listing II.4.25 shows the script combining both queries.

### II.4.8. Sorting

The results of an SQL query request are sorted in ascending order using the ORDER BY statement followed by the name of the column, by which the sorting is be carried out. Specifying the optional DESC keyword will cause the results to be sorted in descending order. Thus, solving the problem comes down to constructing an SQL query with the column name, by which to sort the results added after the ORDER BY statement dynamically. This query may be the following:

```sql
SELECT * FROM products
ORDER BY $order $desc
```

Here, the $order variable holds the name of the column, by which the result should be sorted. Depending on the sorting order, the value of the $desc variable is either blank or set to DESC.

### II.4.26. Sorting

```php
<?php
// Checking the parameters passed to the script
$order = "name";
if($_GET['order'] == 'name') $order = "name";
if($_GET['order'] == 'price') $order = "price";

ORDER BY $order desc";

if(!$prd) exit(mysql_error());
// If the current directory contains least
// one item, displaying the item
if(mysql_num_rows($prd) > 0) {
    echo "<table border=1>
<tr>
<td><a href=\"\$SERVER['PHP_SELF']?order=name&add=$add\">Name</a></td><td><a href=\"\$SERVER['PHP_SELF']?order=price&add=$add\">Price</a></td><td><a href=\"\$SERVER['PHP_SELF']?order=grade&add=$add\">Grade</a></td><td><a href=\"\$SERVER['PHP_SELF']?order=count&add=$add\">Qty</a></td>
</tr>
</table>";
    while ($product = mysql_fetch_array($prd)) {
        echo "<tr><td>\$product['name']</td><td>\$product['price']</td><td>\$product['grade']</td><td>\$product['count']</td></tr>";
    }
    echo "</table>";
}
?>
```

At the beginning of the script, the GET parameter is checked. If its value matches one table's column, the $order variable is set to this value. Otherwise, the $order variable is set to the default name. This checking system is necessary to protect against SQL injection. When register_globals is enabled, the PHP interpreter automatically creates variables for GET parameters. This creates a possibility to pass an SQL injection through the order parameter when running the script. Therefore, when using the GET, POST, or COOKIE method, variables passed among the client machine must be explicitly checked.

### II.4.9. Double-Down List

The first drop-down list is displayed on an HTML form with the <select> tag, located in the loop for processing the results of an SQL query, selecting records from the catalogs table. Each list item <option> is a catalog name, and the value attribute takes the value of the primary key of the current catalog. To automatically reload the form, a handler for the onChange event (i.e., when an item is selected from the list) is added to the <select> tag as follows: onchange='this.form.submit()'. After the page is reloaded, the id_parameter (the name of the first drop-down list) is monitored for having been passed. To prevent potential SQL attacks, you must also check that this parameter is an integer. A regular expression is used for this purpose.
