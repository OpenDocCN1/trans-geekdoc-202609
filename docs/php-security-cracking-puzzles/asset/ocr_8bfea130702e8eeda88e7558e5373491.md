# Listing II.1.13. HTML form for sending data using the POST method

```
<?php
$filename = array("all.php", "auth.php",
"auth.txt", "base.txt",
"chat.html", "config.php",
"count.txt", "count_new.txt",
"counter.dat", "counter.php",
"create.php", "dat.db");
?>
<form action='second.php' method=post>
<?php
// The loop forms hidden fields
// containing array elements.
foreach($filename as $name)
{
echo "<input type=hidden name=filename[] value=$name">";
}
?>
<input type='submit' value='Send an array'>
</form>
```

Now, to view the array dump on the second.php page it is necessary to access the $_POST instead of the $_GET superglobal array (Listing II.1.14).

# Listing II.1.14. The script that outputs the dump of the $_POST superglobal array

```
<?php
echo "<pre>";
print_r(\$_POST);
echo "</pre>";
?>
```
