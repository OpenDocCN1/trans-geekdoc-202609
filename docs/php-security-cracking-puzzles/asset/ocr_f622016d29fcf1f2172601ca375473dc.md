If all HTML tags must be deleted, the strip_tags() function is often most convenient (Listing II.2.2).

> NOTE Tags that should not be stripped by the strip_tags() function can be specified in its optional second argument.

# Listing II.2.2. Using the strip_tags() function

```
<?php
// Extracting the contents of the index.htm file
$content = file_get_contents("index.htm");
```

```
// Stripping tags and displaying the text in the browser window
echo strip_tags($content);
```
