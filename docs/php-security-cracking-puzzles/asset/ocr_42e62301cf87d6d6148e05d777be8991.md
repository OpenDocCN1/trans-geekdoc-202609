# Chapter I.10: Hypertext Transfer Protocol

![](bbox=[0.049, 0.187, 0.874, 0.355])

HTTP is used for transferring HTML pages and data from HTML forms, and it is the main Web application protocol. Knowledge of this protocol's features makes it possible both to circumvent site defenses and defend against attacks on Web applications.

> HTTP is defined in RFC 2616.

> All examples from this chapter can be found in the /scripts/10 directory on the accompanying CD-ROM.
