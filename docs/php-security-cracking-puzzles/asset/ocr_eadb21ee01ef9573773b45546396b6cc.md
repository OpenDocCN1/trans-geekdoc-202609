# II.3.15. Random Output from a File

This problem of outputting a random line requires the rand() function (Listing II.3.18). The function's syntax is the following:

```
int rand (int min, int max);
```

The function generates a random integer in the range specified by two optional integer parameters, min and max. If the parameters are not specified, the function generates a random integer in the 0 to RAND_MAX (32,768) range.

Unless a random number generator is seeded, it always generates the same sequence. Usually, a random number generator is seeded manually. In PHP, the rand() function is used to seed the random number generator. However, as of PHP 4.2, seeding is done automatically. The initial seeding function, however, has been preserved for backward compatibility.
