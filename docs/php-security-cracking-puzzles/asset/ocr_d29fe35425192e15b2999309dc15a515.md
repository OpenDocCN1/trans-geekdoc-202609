The names of the downloaded files are stored in the $file name array; when a new archive for downloading is added, it is automatically registered in the system. The advance registration is necessary for several reasons. First, when a file name is passed in the down parameter, it must be checked against allowed for downloading. Second, processing files in an array is much easier than processing them individually. Thus, the $count array, which stores the number of the file downloaded, is automatically created on the $file name array holding the names of the files registered for downloading. For convenience, the $count array is converted into a byte-stream representation string using the serialize() function and back into the value using the unserialize() function.

>  is is to to remember that all headers can only be sent before the main content is sent. Sending them in a different order is impossible; the PHP interpreter will issue the following warning message: "Warning: Cannot modify header information— already sent by." This is because HTTP sends headers first and sends the contents of the document. Thus, any initial output into the browser window is interpreted as headers with the document body expected to. If it is impossible to avoid sending the contents before the buffers, output control functions should be used to place the output into a buffer and then send it to the browser window at the end of the script's execution.

When the script is run for the first time, the filecount.txt file does not exist. It is created when the page is loaded for the first time. The creation process is initiated by the 0 value for each file from the $file name array.

# II.5. Saving Text and Graphics Files

A browser can only interpret a file if it knows its contents. The browser learns about the file’s contents from the server, because each file is accompanied with HTTP headers telling the client about the file’s contents, its size, and other service information, such as having to set a cookie. If the type of the file is unknown, it is sent as a binary stream.
