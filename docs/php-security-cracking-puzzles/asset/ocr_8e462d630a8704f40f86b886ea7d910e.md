# ## I.3.6. Determining File Size

Develop a function that accepts the file name as its only argument and returns the file's size in bytes, kilobytes, or megabytes, depending on its size. If the file size is smaller than 1024 bytes, then the file's size must be evaluated in kilobytes. If the 1024-KB threshold is exceeded, then the file's size must be evaluated in megabytes.

# ## I.3.7. Determining the Number of Lines in a File

Develop a function that accepts a file name as its only argument and returns the number of lines in that file.

# ## I.3.8. Reversing the Line Order in a File

Locate the text.txt file supplied on the accompanying CD-ROM (/scripts/3/text.txt). Develop a script to change the order of lines within that file so that the first line becomes the last one, the second line becomes the next to last line, and so on, with the last line of the file becoming the first one.

# ## I.3.9. Listing Files and Subdirectories

Develop a script to output a list of files and subdirectories in the current directory. The script must also output a list of files and subdirectories for each subdirectory (Fig. I.3.5).
