The values of the variables $ftp_server, $ftp_user, and $ftp_password are set to the address of the FTP server, user name, and password, respectively.

For further FTP work, the code in Listing II.9.1 may be placed into a separate file named, for example, config.php. The file is then included in scripts with the help of the include instruction. Thus, you avoid writing out the connection code in each script.

# II.9.2. Listing FTP Server Files

A list of the files and subdirectories in the current directory can be obtained with the help of the $ftp_rawlist() function (Listing II.9.3). Its general syntax is the following:

```
array $ftp_rawlist(resource link, string directory)
```

The function accepts a link identifier as the first parameter and the path to the directory as the second parameter. It returns an array of strings, each of which contains information about a subdirectory or a file.
