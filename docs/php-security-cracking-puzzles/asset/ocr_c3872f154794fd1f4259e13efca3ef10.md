# Preface

This book is a collection of PHP problems, with emphasis on protecting Web sites and applications.

The main problem of Web application developers is that they think differently than Web application breakers. Moreover, Web application developers seldom test their products for vulnerabilities because they are subconsciously loath to abuse their babies. This book is intended to dispel this state of mind. To this end, along with Web application protection problems, it offers numerous problems focused on breaking into sites using diverse technologies, from cross-site scripting and SQL injections to password guessing using the dictionary method. This will let you see how easy it is to disrupt a Web site’s operation and how dearly carelessness when developing may cost you.

Along with destructive problems, many problems directed at constructing site defenses are offered. Solving these problems will let you obtain the knowledge necessary to build a powerful protection system for your own site. The system will differ from similar commercial and freeware analogues in that you will learn every nut and bolt in it it will be able to modernize easily, recover from break-ins rapidly, and discover all of its weaknesses.

The book is divided into two parts: the problems and the answers. You can solve all problems in the order they are presented or if, for example, you need urgently to protect your site, which you can avail yourself of the ready solutions, which can be found on the CD-ROM accompanying the book.
