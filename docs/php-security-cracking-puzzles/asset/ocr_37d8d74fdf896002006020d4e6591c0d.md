Listing II.8.14 shows a script that separates the exchange rate for the euro against the dollar from the overall exchange rate information.

# Listing II.8.14. Separating the exchange rate for the euro against the dollar

```
<?php
// Setting unlimited execution time for the script
set_time_limit(0);
// The page to search
$url = "http://www.ecb.eu/stats/eurofxref/eurofxref-daily.xml";
// Loading the contents of the page
$contents = file_get_contents($url);

// Extracting the date
$pattern = "<Cube time='([^']+)'>is";
// Performing a search against the regular expression
preg_match($pattern, $contents, $out);
echo "The exchange rate for " .$out[1] .".<br><br>";

// Extracting currency exchange rates
$pattern = "<Cube currency='([^']+)' rate='([^']+)'\>is";
// Performing a search against the regular expression
preg_match_all($pattern, $contents, $out, PREG_PATTERN_ORDER);
// Displaying the results of the search
for ($i = 0; $i < count($out[1]); $i++) {
    if ($out[1][$i] == "USD") {
        echo "1. .$out[1][$i] . "." .$out[2][$i] . " EUR<br>";
    }
}
?>
```

The script in Listing II.8.14 compares three-character currency notations against the first parenthesized expression, which contains the string USD. If they match, the script displays the exchange rate; otherwise, it ignores the output.
