The wordwrap() function breaks a string (passed to it in the first parameter) into substrings whose length is specified by a number (passed to it in the second parameter). The third parameter allows the break character to be specified. If the last parameter is set to 1, the subject string is broken exactly at the specified length, meaning that if a break falls in the middle of a word it will be made at that point instead of at the nearest space character.

Without a regular expression, the wordwrap() function is inflexible because it is intended for working with text, not individual words.

# 2.11.11. Splitting Text into Sentences

The preg_split() function breaks the supplied text into sentences according to a regular expression. It has the following syntax:

```
array preg_split (string pattern, string subject
    , int limit (, int flags))
```

The function returns an array holding substrings obtained by breaking the subject string at the sentence boundaries that match the pattern template.
The optional limit parameter is set, the function returns the number of substrings specified by it; if the parameter is not set or set to -1, the number of substrings returned by the function is not limited. The last parameter, flags, can be any combination of the following flags (delimited using the | operator):

+   - PREG_SPLIT_NO_EMPTY — If set, the function returns nonempty substrings.
- PREG_SPLIT_DELIM_CAPTURE — If set, the parenthesized expression in the delimiter pattern is also extracted from the subject string and returned.
- PREG_SPLIT_OFFSET_CAPTURE — If set, the position of each found string in the subject string is returned. The data for this flag are returned in a format different from that of others: For each match an array is returned whose 0th element contains the found substring and first element contains the offset.
