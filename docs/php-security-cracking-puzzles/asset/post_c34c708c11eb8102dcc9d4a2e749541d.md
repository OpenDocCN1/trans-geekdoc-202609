Listing II.15.4. Unpacking the archive. file

```php
<?php
// Opening the archive. file
$filename = "archive.tar";
$fd = fopen($filename, "r");
if(!$fd) exit("Error opening the archive.tar file!");
$str = fread($fd, filesize($filename));
fclose($fd);
// Converting the serialized string back into an array
$arr = unserialize($str);
// Creating files
foreach($arr as $file => $contents)
{
    $fd = fopen($file, "w");
    if(!$fd) exit("Error opening the $file file!");
    fwrite($fd, $contents);
    fclose($fd);
}
```
