# I.6.2. Protecting an HTML Form Using a Referrer

Assume that there is an HTML form intended for user authorization. This form is contained in the index.php file, the code of which is shown in Listing I.6.1.

# Listing I.6.1. HTML form of the authorization system

```
<table>
<form action=handler.php method=post>
<tr>
<td>Name:</td>
<td><input type=text name=name></td>
</tr>
<tr>
<td>Password:</td>
<td><input type=password name=pass></td>
</tr>
<tr>
<td>&nbsp;</td>
<td><input type=submit value='Enter'></td>
</tr>
</form>
</table>
```

As be seen from Listing I.6.1, the HTML form passes data to the handler stored in the handler.php file. For simplicity, the authorization system would check whether the user name and password are equal to the admin string. If they are, the system would send an email notification using the `mail()` function (Listing I.6.2).
