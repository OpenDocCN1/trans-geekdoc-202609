# II.10.3. Determining the Remote File Size

This problem can be solved using the script shown in Listing II.10.6. The script employs the custom get_content() function defined in Listing II.10.4, which returns the number of bytes in the file in the HTTP Content-Length header.

+   Listing II.10.6. A script for determining the remote file size

```

$hostname = "www.softtime.ru";
$path = "/files/configs.zip";

// Joining the array elements into a string
$lines = implode(" ", $out);
```
