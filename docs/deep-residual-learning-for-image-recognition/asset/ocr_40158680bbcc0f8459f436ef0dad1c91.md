# Deep Bottleneck Architectures.

We describe our deeper nets for ImageNet. Because of the time we can afford, we modify the building block as a "bottleneck" design. For each residual function $\mathcal{F}$, we use a stack of 3 layers instead of 2 (Fig. 5). The three layers are 1, 3, 3, and 1 convolutions, where the 1x1 layers are responsible for reducing and increasing (restoring) dimensions, using the 3x3 layer as a bottleneck with input/output dimensions. Fig. 5 shows an example, where bottleneck designs have similar complexity depth.

The parameter-free identity are particularly important for the bottleneck architectures. If the identity shortcut is replaced with projection, we show (Fig. 5) that the complexity and model size are doubled, as the shortcut is connected to the two different dimensions. Identity shortcuts lead to more efficient models for the bottleneck architectures.
