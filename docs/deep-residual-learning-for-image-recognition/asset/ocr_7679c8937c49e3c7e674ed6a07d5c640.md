# # 3. Deep Residual Learning



Let us consider $H(x)$ as an underlying mapping to be fixed by a few layers (not necessarily the entire entry), with $x$ denoting the input to the first of these. If we hypothesize that multiple nonlinear layers approximately approximate functions, then it is equivalent to hypothesize that they learn the residual, $H(x) - x$ (assuming that the input and output are of the same dimensions). Rather than learning stacked layers, we explicitly let these layers approximate a residual function $\mathcal{F}(x) \equiv H(x) - x$. The original function then becomes solely to help approximate the desired function (as hypothesized), making the learning effort much different.

This reformulation is motivated by the counterintuitive phenomenon of degradation problem (Fig. 1, left). As we discussed, if the layers are constructed as identity mappings, deeper model would show training error no greater than its shallower counterpart. The degradation problem suggests that we have difficulties in approximating identities by multiple nonlinear layers. With the residual reformulation, identity mapping becomes optimal, so solvers drive the weights of the multiple nonlinear layers toward identity mapping.

In real cases, it is identity mapping better than optimal, but reformulation may help precondition the problem. If the optimal function is to identity mapping to a zero, then it should be easier for the solvers to learn it with reference to identity mapping, than to learn it from scratch. We show by experiments (Fig. 7) that the learned functions in general have reasonable responses, suggesting that identity mapping provides reasonable reasoning.



We adopt residual learning to every few stacked layers. A building block is shown in Fig. 2. Formally, in this paper we consider a building block defined as:

```
$y = \mathcal{F}(x, \{W_i\) + x.$
```

Here $x$ and $y$ are the input and output vectors of the layers considered. The function $\mathcal{F}(x, \{W_i\})$ represents the residual mapping to be learned. For the example in Fig. 2 that has two layers, $\mathcal{F} = W_2\sigma(W_1x)$ where $\sigma$ denotes

ReLU and the biases are omitted for simplifying operations. The $F + x$ is performed by shortcut connection and element-wise addition. We adopt the nonlinearity after the addition (i.e., $\sigma(y)$, see Fig. 2). The shortcut connections in Eq.(1) introduce extra parameters but no computation complexity. This is not only advantageous but also important for comparing performance between plain and residual networks. We can easily perform plain/residual networks that simultaneously have the same number of parameters, depth, and computational cost.

The dimensions of $x$ and $F$ must match in Eq.(1). If this is not the case (e.g., when the input and output mismatch), we can learn a projection $W_s$ for the shortcut connection to match the dimensions:

```
$y = \mathcal{F}(x, \{W_i\}) + W_s x.$
```

We use a square matrix for $W_s$. We will show by experiments that the identity mapping is sufficient for addressing the degradation problem and is, so $W_s = I$ is used when matching dimensions.

The form of the residual function $F$ is flexible. Experiments in this paper use two layers (Fig. 5), more layers are possible. If $F$ has only one layer, Eq.(1) is similar to a linear layer $y = W + x$, which we have not observed advantages. We also show that although we use fully-connected layers, they are applicable to convolutional layers. The function $\mathcal{F}(x, \{W_i\})$ represents multiple convolutional layers. The element-wise addition is performed on feature maps, channel by channel.



We have tested plain/residual networks, and have observed consistent performance. To provide instances of this, we describe two models for ImageNet as.

Plain Network. Our plain baseline (Fig. 3, middle) are mostly inspired by the architecture of VGG networks [40] (Fig. 3, left). The convolutional layers have 3x3 filters and follow two simple design rules: for the input feature map size, the layers have the same number of filters; and if the feature map size is halved, the number of filters is doubled to preserve the network complexity. We perform downsampling by using convolutional layers that have a stride of 2. The network ends with a global pooling layer and a 1000-fully connected layer. The total number of weighted layers is 34 in Fig. 3 (middle).

It is worth noting that our model has fewer filters and lower complexity than VGG networks [40] (Fig. 3, left). Our layer baseline has 3.6 billion operations (multi-adds), which is only 18% of VGG-19 (19.6 billion FLOPs).
