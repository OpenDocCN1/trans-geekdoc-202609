+   - Zoning technique – this method approximate user location based on the technical specifications of Bluetooth, infrared, and 802.11x protocol coverage limit. The intution is user location can be guessed based on their respective discoverability; and their corresponding signal strength to these connections. For example, a smart space can be divided into distinct zones where each zone is covered by one AP. In the area where AP(s) coverage overlaps; user proximity is guessed based on the signal strength of the user (mobile phone WIFI signal) towards the AP sets. In the case where 2 AP(s) is discovered and if gain A is higher than gain B; then the user is deduced to be closer to APA. Similar to RTTA, the zoning technique is prone to the fluctuation of WIFI Signal due to interference. The zoning technique addresses the problem where there exist multiple AP in each zone. The coverage overlapping is what made the improved approximation when more AP(s) spatial cues are used for triangulation (Kho, 2015).
