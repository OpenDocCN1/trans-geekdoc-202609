+   5. Cluster head advertises the messages to nodes (Steady Phase).

+   6. If the node is cluster head, then it computes the received data from nodes aggregate it and send to the base station otherwise it is a node itself send data to the cluster head.

+   7. If (Eₙ <0) then calculates dead nodes.

+   8. One round completed.
