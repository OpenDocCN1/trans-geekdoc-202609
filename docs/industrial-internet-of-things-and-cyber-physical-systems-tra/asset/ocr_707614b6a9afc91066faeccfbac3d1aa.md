Alattas 2016 proposed a scheme against Black Hole Attack by using multiple base stations and check agents to detect Black Hole Attack. A table of neighbor nodes is maintained in every node in the system. Check agents, special nodes in the network are also added into the network. The check agents will try to monitor the incoming and outgoing packets of those nodes. Once a node with zero incoming and outgoing traffic is detected, the node is flagged as suspicious node. Then, the algorithm of the multiple base stations will be executed. Packets or route request will be sent to those suspicious nodes.
