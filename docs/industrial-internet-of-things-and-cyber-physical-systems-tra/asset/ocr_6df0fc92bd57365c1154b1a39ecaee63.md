# Security Against Transport Layer Attacks

This layer is majorly prone to flooding attacks, acknowledgement spoofing and de-synchronization attacks. The flooding attacks can be prevented via connection authentication. For de-synchronization attacks, each type of network packet (e.g. control packet and data packet) needs to be authenticated. Header or full packet authentication can be useful for preventing de-synchronization attacks. Here firewalls can be useful to protect network from flooding and de-synchronization attacks. The firewalls aim to provide reliable, authenticated and secure connection between two data transmitting nodes. .
