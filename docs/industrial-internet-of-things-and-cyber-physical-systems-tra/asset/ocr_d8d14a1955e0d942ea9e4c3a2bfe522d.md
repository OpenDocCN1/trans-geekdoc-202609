# FRAMEWORK OVERVIEW

Migration requires structured approach to assure consistent value realization; LAMP2C acts as a guiding principle and provides process guidelines that needs to go along while legacy application is getting migrated. Framework support migration in efficient way, which increases the likelihood of a successful cloud migration by having elaborate upfront comprehensive migration plan, along with continuous and pertinent communications among stakeholders and their involvement in entire migration journey. LAMP2C suggest to follow phased manner approach and never compels to follow activities cover-to-cover. LAMP2C support all migration related activities and helps in speeding up migration effective and efficient manner. It can be used to evaluate and enhance enterprise existing migration processes.

Proposed LAMP2C framework is divided into three parts. At highest level is **Area**. Areas is sub-divided into **Phases**. Phases are further sub-divided in **Activities**. Ref. Figure 2.
