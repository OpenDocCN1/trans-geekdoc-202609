# Latency in Node to Node Discovery

The latency for neighborhood discovery indicate the reliability of the discovery protocols. This is measured in (1) the number of nodes discovered and (2) the time used for detecting these neighbors. For (1), the higher number which indicate a more general-purpose discovery is favored; and for (2) shorter time which indicate faster discovery is better.
