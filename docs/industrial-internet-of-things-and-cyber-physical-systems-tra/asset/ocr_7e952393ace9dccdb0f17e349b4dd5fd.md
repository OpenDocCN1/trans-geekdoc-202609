$ACL = \sigma_{c} = \sum_{i}^{n} \frac{(fC_{n} - \mu_{c})^{2}}{n}$

# ASK Belt

ASKB has two part; one ASKB Right i.e. ASKB$_{\mathrm{R}}$ and second is ASKB Left i.e. ASKB$_{\mathrm{L}}$. ASKB$_{\mathrm{R}}$ and ASKB$_{\mathrm{L}}$ can be calculated as shown below:

ASKB$_{\mathrm{R}}$ = ASKP + ACL

ASKB$_{\mathrm{L}}$ = ASKP - ACL

**ASK Belt** (ASKB) helps to create boundary for identified parameter with the help of ASKP and ACL. ASKP, ASKB (ASKB$_{\mathrm{R}}$ and ASKB$_{\mathrm{L}}$) and ACL helps to calculate $f(x)$ using the below formula:

$f(x) = \frac{1}{\sqrt{2\pi\sigma^{2}_{c}}} e^{\frac{-(x-\mu_{c})^{2}}{2\sigma_{c}}}$

Constant values and other values for the above given formula are as below:

+   \begin{aligned}&\pi=3.14\\& e=2.71\text{ and}\\& x=\text{Parameter Impact}\\& \mu_{c}=\text{ASKP}\\& \sigma_{c}=\text{ACL}\end{aligned}
