The implementation of the SSL record protocol is given as:

+   - The message at the application layer is being processed to the transport layer.
- Data is broken down into segments

- Add the Message Authentication Code with compressed data. MAC can be generated using the hash function (MD5 or Secure hash algorithm-1).
- Apply conventional encryption methods to encapsulate the MAC and compressed data.
- Append SSL header with encrypted data and send it to the receiver.
