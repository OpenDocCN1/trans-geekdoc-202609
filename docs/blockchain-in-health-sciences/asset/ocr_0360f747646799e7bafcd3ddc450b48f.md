+   **Proof of Elapsed Time (PoET):** A randomized timing method is used in place of the mining-intensive rights necessary for Proof of Work in the PoET process. By distributing the odds of winning among the greatest number of network users, the PoET consensus mechanism increases the likelihood that a random lottery system will choose each node. Node in the blockchain network will produce a random wait time before going to sleep for that amount of time. The node that becomes the block leader at this point is the first to wake up, (the first in the network to have its timer expire after the predetermined amount of waiting time.) This node creates the new block, signs using its private key address before adding it to the blockchain network. The required data is then sent to every peer network, and the procedure is repeated to find the next block leader.
