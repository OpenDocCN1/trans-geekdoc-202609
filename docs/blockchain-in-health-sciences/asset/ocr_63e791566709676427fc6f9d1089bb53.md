# 17.3.4.1 Fit and Compile Model

The previous steps only involve loading the model. To make it functional, we need to compile and train it. Compilation of the model is the process of configuring the model for training. This step specifies various parameters that affect how the model is trained, such as the choice of optimizer, loss function, and evaluation metrics.

+   Hyperparameters in compiling a model: While compiling a model, we need to specify the parameters which affect the model will function. Some of the most common parameters to be specified while compiling a convolutional neural network are:

+   Loss function: Loss function should be measured as measures the correctness of the neural network model [19]. For different cases, the value of loss function changes Table 17.1.

+   Optimizer: Optimizer defines the function that should be optimized while training the model [20]. Common values for these parameters are Adam or Stochastic Gradient Descent (SGD) [21].

+   Metrics: The metrics parameter defines the evaluation metric(s) used to assess the performance of the model. It can be a string or a list of strings. Some common values for this parameter are: accuracy, precision, recall, and f1-score.

+   Learning rate: For optimizers such as SGD and Adam which involve learning rate, we can also specify the learning rate, typically ranging from 0.001 to 0.00001. However, it's recommended to experiment with various values and have a look at the history curve of the model to come at the best learning rate.
