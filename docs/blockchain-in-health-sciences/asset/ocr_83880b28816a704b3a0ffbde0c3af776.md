types of blockchain can be categorized as follows [14]. (1) A public blockchain is one that is both available to everyone and does not require permission to use, making it a trustless system. There is no requirement for members of the network to establish trust, and any unknown node can join the network. All the nodes are publicly informed about the transactions. To validate the blocks, any node in the network can participate in consensus techniques. This type of network is exemplified by the Bitcoin blockchain, for example [12]. (2) Permissioned private blockchains: To maintain a high degree of trust among users, nodes are meticulously selected and validated before they may join the network. Improved privacy for blockchain transaction data is a result of the access control mechanism. Additionally, this blockchain provides better efficiency when it comes to verifying blocks. For example, MultiChain is one of this type [15]. (3) Public and permissioned consortium blockchains: This type of blockchain combines elements of both public and permissioned blockchains, providing a balanced solution that balances efficiency and trust. A pre-determined set of nodes is responsible for managing the ledger. Nodes on the network must obtain permission to join, much like with private blockchains. Block and transaction validation occurs when a selected group of nodes achieves consensus. The specific procedure varies according to the predefined regulations of the consensus method. A specific instance of a platform in this category is Hyperledger [16].
