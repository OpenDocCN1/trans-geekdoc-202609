# 2.5.1 Protection and Integrity for the Internet of Things

Concerns like privacy and security are considered paramount in IoT designs. Because of this, a great deal of research has been done to address these issues. Here are a few succinct descriptions of the current solutions:

+   (a) Lightweight authentication for wearable devices using basic cryptographic hash functions was proposed by Gupta et al. [31] to ensure secure network connections. Reason being, these devices aren't superpowers when it comes to memory and processing speed. This is why conventional methods of protecting user data on mobile devices are inadequate for usage with wearable gear. By masking device IDs with XOR and hashing techniques, the proposed system maintains privacy and anonymity.

+   (b) Gope and Sikdar [32] introduced a lightweight two-factor authentication solution to safeguard the privacy of Internet of Things devices. Authors have emphasised device authentication more due to the open and public deployment of IoT devices, which makes them vulnerable to physical and closing threats. This technique uses physically irreplaceable functions constructed of ICs and unique one-way hash values to introduce random physical deviations into the micro-structure of ICs, making them distinct.

+   (c) IoT; the subsequent iteration of devices, will be connected using IPv6, which was created especially for this. Due to the fact it provides many features and a larger address space than the antiquated IPv4 Internet Protocol [33]. However, because to its design, it is vulnerable to denial-of-service (DoS) assaults during IP address configuration, which could obstruct communication between the two nodes in a network [34]. Liu et al. [33] proposed a unique approach called Addressless IoT Server to solve this issue and enable safe communication between the Internet of Things client and server.
