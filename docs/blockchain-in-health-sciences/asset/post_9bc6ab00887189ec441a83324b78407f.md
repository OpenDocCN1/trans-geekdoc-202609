## 18.6 Security Features and Challenges

IoT-based healthcare systems involve multilayer communication, wherein data storage and access are carried by multiple users at multiple layers. As a result, implementing security mechanisms in such systems is complex [34–37]. The essential security features that an IoT-based healthcare system must provide include:

- a) End-to-End Encryption: Encryption of raw data detected by sensors, as well as processed data saved on fog/cloud servers, is critical for maintaining healthcare system confidentiality. It ensures that an attacker cannot access actual data or information even if communication messages are intercepted on public networks. At the same time, it should be free of man-in-the-middle attacks, in which an attacker sits between two communication parties and intercepts all ongoing messages interacting with them without their knowledge. Furthermore, the encryption key should be strong enough that no unauthorized user can derive it.
- b) Secure Authentication: Authentication mechanisms are used to identify legitimate users or devices. It is critical for healthcare systems to establish mutual authentication prior to initiating communication. It enables the fog/cloud nodes to allow only registered IoT devices to connect.

Also, it enables sensor nodes to communicate with legitimate fog/cloud nodes. Similarly, users and cloud/fog servers should be mutually authenticated.

- c) Access Control: In an IoT-based healthcare system, multi-access levels should be established so that all authorized users, such as physicians, hospital managers, paramedical personnel, and patients, do not have access to all information. Instead, each group of users should only have access to the information they need. Through access control, insider attacks can be prevented.

- d) Data Integrity Verification: Data integrity ensures that data cannot be modified without authorization during storage or transmission. To prevent change, cryptographic primitives such as digital signatures or hash functions are required. Even if a change occurs, it should be quickly detected.

- e) Secure Device Management: In IoT-based healthcare systems, each device must be managed and monitored properly to prevent the deployment of any malicious devices. For this, each device must be properly registered at the time of deployment. Additionally, all registered devices must be authenticated before the start of the communication. Furthermore, keys of all devices must be managed securely and efficiently.

- f) Secure Communication Protocols: Since the communication between fog nodes and the sensor nodes occurs over public channels, there should be the use of standard communication protocols like Transport Layer Security (TLS) to provide security and confidentiality. Additionally, the communication protocols should resist eavesdropping attacks.

Even though incorporating security measures into IoT-based health care systems can improve their robustness and reliability, some challenges hinder their in practice. The major challenges faced by such systems are:

- a) Interoperability: In health care systems, multiple sensor nodes are grouped together to sense the health of patients, environments, or equipment. All sensor nodes may need to communicate with each other to function fully. However, different sensors may be made by different manufacturers; therefore, they might employ different communication protocols and standards. Hence, they may be incompatible with each other. This problem may cause hindrance in communication.

- Scalability: As the IoT based solutions become mature, it requires deployment of large number of IoT devices. Also, these large numbers of devices will also produce large volume of data at the fog server and at the cloud server. Handling large number of sensors or large volume of data is a tedious task. Thus, achieving scalability is a challenging task in IoT-based solutions.

- Reliability and Latency: It is crucial to have low latency and reliable networks in IoT-based systems to achieve real-time information getting. Fog servers are introduced to minimize latency by processing and storing data nearby the sensors. But still the communication channel established between IoT devices and fog nodes should maintain low latency and avoid congestion.

- Resource Constraints: It is important to understand that sensor nodes are very small and have limited memory, computing capacity, as well as battery life. Despite many of the security requirements discussed above, implementing a complex security mechanism at the sensor level is very challenging. Only very lightweight security protocols can be implemented here. Therefore, there must be a balance between constraints on resources and demands for security.

- Data Management and Analytics: Since sensor nodes continuously generate large amount of data, it becomes difficult to process these data to get valuable insights immediately. However, applications that do real-time monitoring or dealing with critical cases require immediate insights for making clinical decisions. Thus, it is imperative to have very powerful as well as efficient analytics and machine tools for data processing.

## 18.7 Future Advances in IoT-Powered Healthcare

So far, researchers have done extensive studies in the field of IoT in healthcare, especially in areas such as cybersecurity, patient health monitoring, personalized medicine, disease prediction, etc. This field is growing very fast which provides huge opportunities for research and development in the future. This section outlines potential research areas that can further broaden the impact and efficiency of IoT in healthcare.

- a AI and Machine Learning Integration: The use of artificial intelligence (AI) and machine learning (ML) techniques can play an important role in improving healthcare systems. Researchers use it to find out more information by processing the data by sensors [38]. However, they need to pay more attention to system more productive, automatic and efficient so that the load of healthcare professionals gets reduced. Also, AI-enabled healthcare systems can provide better real-time health monitoring, diagnosis, personalized care, and predictive analysis.

- b Enhanced Data Security and Privacy Measures: A lot of research has been done on ensuring privacy and security in IoT based healthcare systems, there is still a need to develop a robust and comprehensive cybersecurity framework specifically for such systems. This framework can include advanced encryption methods that can be applied to power constrained devices as sensors. This framework can also involve blockchain technology for providing security to patient data as well as preventing unauthorized access [39].

- c Integration of Virtual Reality (VR) and Augmented Reality (AR): Just like gaming and entertainment, the use of AR/VR technologies in healthcare will have many benefits. In integration with IoT, these technologies will help in understanding patient data in a more interactive way. These technologies will also be helpful during the training of healthcare professionals. They may also contribute to improving the surgical outcomes. Additionally, they have the potential to open new dimension in the medical field where surgery can be done remotely. This area has lots of potential, researchers need to investigate it more.
