# 15.8.1 Blockchain Node's Fundamental Responsibilities Are

+   1. Connecting to the blockchain system,
2. Keeping a precise record of transactions,
3. Paying attention to exchanges,
4. Initiating valid network transactions,
5. Watching for blocks that have just been sealed,
6. Securing newly sealed blocks by checking transactions,
7. Creating and transmitting initial blocks [38, 39].

# 15.8.2 Advantages

+   (a) Available: The fact that it's ‘open source’ means that anybody can help advance blockchain technology.
(b) Endless: Because blockchain technology establishes a decentralized network with several reliable nodes, numerous copies of data are saved at each original node, eliminating the possibility of data loss.
(c) Uncensored: Deals may be authorized automatically using the agreement process of blockchain technology, which employs smart contracts to verify them. Blockchain technology is now unrestricted because of this.
(d) Empirical: Blockchain technology is used to store information in a decentralized manner, allowing everyone to verify the data s delicate nature. This is achieved by using zero-knowledge evidence, to show another party the data's delicate nature without disclosing any information about the data [40, 41].
