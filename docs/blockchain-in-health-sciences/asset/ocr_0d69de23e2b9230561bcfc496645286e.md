# A. Security Proofs

Cloud computing has completely changed how data is managed and stored in recent years. Data security concerns are now more important than ever because of this development. In the dynamic cloud environment, traditional encryption approaches might not be sufficient, which is why researchers are investigating newer ways like CP-ABE (Ciphertext-Policy Attribute-Based Encryption). This research uses a game-based methodology to look deeply into the field of cloud data security, with a primary focus on CPABE. We examine the complexities of CP-ABE, analyze the game-based security proofs, and discuss how tasks are assigned to fog nodes. DOs are regarded as completely reputable organizations, although DUS are thought to be partially benevolent. Furthermore, it is expected that important questions are asked in a flexible way, yet.
