Smart Contracts: These are agreements that self-execute and have the contract explicitly encoded into the code. Automated and trust less transactions are via smart contracts, which are stored and performed on the blockchain. When the terms and conditions of a digital agreement signed and saved on a blockchain network are fulfilled, the contract immediately goes into execution. The terms and conditions are expressed in programming languages designed specifically for blockchains, such as Solidity [19]. Network: The network architecture connects each and every blockchain node. It can be public, private or consortium-based. A decentralized network is created with some verified peers working the same as the blockchain network. However, this is accessible by only verified peers. It may be managed by an organization that manages the consensus on their own and allows the partition of peers according to the requirements [20]. Cryptographic Hashing: The integrity of data saved in blocks is protected by hash functions. Every block includes a cryptographic hash of the one before it, tampering becomes more challenging. Blockchain protocol measures the message block and links the blocks together in a chain using a cryptographic hash function. Wallets: On the blockchain, wallets are software programs that let users transmit, receive, and store tokens or cryptocurrencies. They oversee the private keys that allow users to access their money. The ability to manage many cryptocurrency types, such as Bitcoin and Ethereum, is provided by a blockchain wallet. Interfaces: Interfaces for users to interact with the blockchain network are known as user interfaces. These could be command-line interfaces,-phone apps, or web-based programs. In blockchain, and more particularly in Solidity, an interface is a set of function declarations that are defined but not implemented. They facilitate interoperability and standardized communication among contracts on the blockchain by acting as contracts or blueprints that other contracts can follow [22].
