Ethereum smart contracts form the foundation of the system, consisting of algorithms and code that execute transactions between parties and govern those interactions. The Ethereum network ensures fair payouts to the individuals involved via smart contracts. Its components are:

+   - Events: Record significant events on the set and broadcast them to the primary audience.
- Modifiers: Pre-execution conditions can be checked or specified to alter the behavior of a function. For instance, guaranteeing the agreed-upon shipping cost before the deposit of customer funds.
- Variables: Values that change or depend on the circumstances of execution. In this smart contract, variables like freight tariff, start date, and receipt date are crucial.

For the secure delivery of pharmaceuticals, the vendor initiates the smart contract and deposits the cargo into the intelligent container. A package check confirms adherence to dispatch specifications. Based on this check, the freight either proceeds or undergoes necessary rectifications, ensuring both seller and consumer confidence in the shipment's reliability.

Once the smart contract confirms a successful package check, it triggers an event prompting the consumer to deposit the amount and receive a unique hash. When the goods arrive, this hash serves as a verification code to confirm the end user's identity. To open the container and release the goods, the customer must enter the correct secret code at the location. The smart contract grants the user a 72-hour window to enter the correct code and rectify any errors.
