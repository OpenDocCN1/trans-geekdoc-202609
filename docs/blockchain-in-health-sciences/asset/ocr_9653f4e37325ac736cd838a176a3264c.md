# 17.3.4 Approaches for Data Classification

+   - Binary classification: As the name suggests, it is a combination of two words- binary, meaning two and classification to categorize. This approach involves labeling the testing data into either of the classes, class A or class B [17, 18]. The procedure for typical binary classification convolutional neural network machine learning model is - The model starts with two convolutional layers followed by max-pooling layers, then two convolutional layers with max-pooling again, followed by flattening and finally a dense layer for binary classification applying a sigmoid function. The last layer of the neural network has only one neuron/unit as there is only one output that is provided at the end of computation.

+   - Multiple classification: As the name suggests, when the problem statement requires one of the many classes, multiple classification is used. Here, the number of neurons in the last layer must be equal to the number of classes available into which the image can be classified. A model is defined, consisting of convolutional layers followed by max-pooling layers, flattening, and finally a dense layer consisting of 10 neurons (equal to the number of classes) applying softmax activation for multi-class classification.
