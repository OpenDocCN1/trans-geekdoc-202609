# A. Bilinear Maps
Bilinearity Property:

```
e(ua,vb) = e(u,v)ab (11.1)
```

Equation (11.1) represents the bilinearity property of the bilinear map e, where ua and vb are elements from G0, and u, v, a, and b are elements from Zp.

# Non-degeneracy Property:

```
e(g, g) ≠ 1 (11.2)
```

Equation (11.2) reflects the non-degeneracy property of the bilinear map. It states that if the bilinear map applied to the generator g and itself is not equal to 1, then the map is non-degenerate.

# Monotone Access Structure:

```
If B ∈ A and B ⊆ C, then C ∈ A (11.3)
```

Equation (11.3) describes the property of a monotone access structure. It implies that if a subset B is part of the access structure A, and B is also a subset of another set C, then C must be included in the access structure A. This concept is used for managing and controlling access to private medical records based on specified characteristics P1, P2, ..., Pn.

# Access Structure:

A key idea in our suggested plan is access structures. The terms and conditions under which access to particular data or resources are allowed are outlined in an access structure. A collection containing non-empty subsets of the characteristics P1, P2,..., Pn is used to represent it. If set B is in A and B is a subset of C, then access structures can be monotone, which implies that C is also in A. Access to private medical records is managed and controlled by these frameworks.
