+   a AI and Machine Learning Integration: The use of artificial intelligence (AI) and machine learning (ML) techniques can play an important role in improving healthcare systems. Researchers use it to find out more information by processing the data set by sensors [38]. However, they need to pay more attention to system more productive, automatic and efficient so that the load of healthcare professionals gets reduced. Also, AI-enabled healthcare systems can provide better real-time health monitoring, diagnosis, personalized care, and predictive analysis.

+   b Enhanced Data Security and Privacy Measures: A lot of research has been done on ensuring privacy and security in IoT based healthcare systems, there is still a need to develop a robust and comprehensive cybersecurity framework specifically for such systems. This framework can include advanced encryption methods that can be applied to power constrained devices as sensors. This framework can also involve blockchain technology for providing security to patient data as well as preventing unauthorized access [39].

+   c Integration of Virtual Reality (VR) and Augmented Reality (AR): Just like gaming and entertainment, the use of AR/VR technologies in healthcare will have many benefits. In integration with IoT, these technologies will help in understanding patient data in a more interactive way. These technologies will also be helpful during the training of healthcare professionals. They may also contribute to improving the surgical outcomes. Additionally, they have the potential to open new dimension in the medical field where surgery can be done remotely. This area has lots of potential, researchers need to investigate it more.
