# 21.1.2 Relevance and Objectives of the Chapter

A decentralized digital ledger called blockchain technology (BT) keeps track of transactions made on a network of linked computers [30]. It ensures the security and integrity of the data kept in the ledger using encryption [31]. A blockchain is made up of a series of blocks, each of which contains several transactions [32]. Each block is connected to the block before it, creating a continuous chain of blocks hence the term “blockchain.” The genesis block is the first block in the chain [33]. Every time a new transaction takes place, it is shared with the network of computers that keep the blockchain up to date.
