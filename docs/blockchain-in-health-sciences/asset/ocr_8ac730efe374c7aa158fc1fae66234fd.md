# 7.3.1 Blockchain in Healthcare

The operation of Blockchain underpins the principles of decentralization, transparency, and immutability. A block can be referred to as data storage unit that keeps record of transactions or other data. Every block or node is linked to the previous ones using cryptographic hashing and stores data permanently and ensures immutability. Updated data is introduced to a new node without affecting the stored data in an existing node [52]. Blockchain uses a Peer to Peer (P2P) network to maintain distributed ledger. The blockchain's internal organizational structure and the manner in which nodes are interconnected with one another while preserving data confidentiality and immutability are seen in Figure 7.3.
