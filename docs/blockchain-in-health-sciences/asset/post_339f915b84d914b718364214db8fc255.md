## 17.3.2 Architecture of Convolutional Neural Networks

Convolutional Neural Networks (CNNs) excel in image processing tasks due to their unique architecture, which is inspired by the hierarchical structure of the biological visual system. Unlike traditional image processing methods that rely on hand-crafted features, CNNs automatically learn to recognize patterns and features through a series of processing stages. This section elucidates the fundamental components of CNN architecture by drawing an analogy to the workflow of a medical imaging examining an X-ray Figure 17.4. The parameters of convolutional layers are as follows:

- Kernel cost: Neurons are also termed kernels. Hence, the complexity of the patterns learned by a layer in a neural network can be directly related to the number of kernels specified.
- Kernel Size: Size is a direct representation of the number of pixels the kernel will focus at a given time while learning patterns from the image. A smaller kernel size focuses on local characteristics while a bigger kernel learns patterns with a global outlook.
- Stride: Stride refers to how much the kernel move when it is covering the image. A larger stride reduces the spatial dimensions of the output, while a smaller stride preserves more spatial information.
- Padding: In simple terms, padding is used to bring the information on the borders to the center so that they can be well recognized by the algorithm. By doing so, the kernel will cover it for more instances and hence will give more weight to that specific characteristic.
- Name: We can also give names to individual layers using the name parameter, which does not have any relation with computing, but helps in identifying the layers.
