Because we've heard the phrase “hashing in blockchain” so frequently, we almost take it for granted that we know what hashing is. Hashing is essentially a technique used by blockchains to distinguish between distinct blocks [23]. Hashing gives each block in a blockchain a distinct identity. Each block in a blockchain can theoretically be individually identified; thanks to its hash, which is used for both identification and integrity checks. A self-certifying identifier is an identification string that maintains its own integrity. Public keys are produced via the hashing algorithms.
