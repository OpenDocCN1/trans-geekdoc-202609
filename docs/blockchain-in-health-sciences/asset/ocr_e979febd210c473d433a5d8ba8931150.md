4 main layers - data layer, processing layer, application layer, and security layer. Different layers perform different operations [12].

+   The data layer comprises two key sections, namely, blockchain storage and data repository. While blockchain storage contains transaction data states of smart contracts and references to outputs generated by artificial intelligence, data repositories store immense datasets for AI training and analysis, maintained off-chain to maximize efficiency.
Two things make up the processing layer: smart contracts and an AI engine. These are self-executing contracts with terms of the agreement between buyer and seller directly written into lines of code which then exist across a distributed, decentralized blockchain network, such that the “smart” in smart contracts is the ability to eliminate intermediaries like banks or lawyers from transactions that result in increased trust between parties, it is only executed if certain pre-established conditions are met. Such agreements can either trigger artificial intelligence (AI) actions or use AI knowledge to generate informed decisions.
