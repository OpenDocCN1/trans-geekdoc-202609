Machine learning models work on statistics, which means whatever patterns are there in the data are plotted as a function and depending on the final expression derived, further predictions are made. Activation functions are operations applied to the output of a neuron to make it learn the non-linear relationship among the elements of the data [6–8, 11]. There are some common activation functions:

+   Rectified Linear Unit (ReLU): The most widely used activation function in CNNs. It outputs the input directly if it’s positive, and zero otherwise f(x) = max(0, x).

```
ReLU(x)=max(0,x)\text[ReLU](x) = \max(0, x) ReLU(x)=max(0,x).
```

This function returns zero for any input value less than zero and returns the input value for any input greater than zero Figure 17.2. Consequently, the range of the ReLU activation function is [0,+∞][0,+∞]. This characteristic allows ReLU to introduce non-linearity to the model while maintaining computational efficiency. ReLU helps alleviate the vanishing gradient problem (where gradients become very small during backpropagation, hindering learning).
