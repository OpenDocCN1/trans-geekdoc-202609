# 15.8 Blockchain: Distributed Ledger Technology

A cryptographic one-way hash function generates the so-called hash, which links each block in the blockchain. It also ensures the anonymity, immutability, and tightness of the block [36, 37]. Nodes sign all the transactions before sending them out to the network for confirmation. The integrity and validity of a transaction may be guaranteed by using a digital signature that uses the private key. The first is that, signing the transaction requires a specific private key, and the second is that, decryption cannot proceed in the event of a data transmission failure. In networks that use proof-of-work or proof-of-stake as its consensus method, a group of nodes called miners collect all the transactions that have been distributed and accepted by the network into time-stamped blocks. After the blocks are broadcast to the network, the validation nodes check them. This is accomplished by referencing the previous block in the chain, and using the hash associated with the block to ensure that the blocks they have received legitimate transactions. Once both conditions are met, the nodes will add the block to the blockchain. If the conditions are not met, the obstacle is removed.
