# 12.3 Blockchain for Pharmaceutical Supply Chain Management

We divide the conceptual flow of pharmaceutical SCM system using blockchain technology into (i) blockchain basics, (ii) data collection and generation phase of each component, and (iii) technical challenges in blockchain for SCM.

# 12.3.1 Blockchain Basics

Blockchain technology relies on the concept of block. The data in blockchain is stored in the form of individual blocks. As a linked list, the blockchain data structure is a collection of blocks that are linked together. Typically, each block in a blockchain comprises multiple fields, such as, *previous hash* (it stores the hash value of the previous block), and *current hash* (it is the hash value of the present block that can be used to refer to this block) [15]. With reference to PCM systems, the actual data may contain the pharmaceutical transaction details, or the asset details of the pharmaceutical company. A new block is created when a transaction is executed, and a request is made by an authenticated stakeholder in the system. The possibility of successful addition of a new block within a particular blockchain system depends on the consensus of the participants/stakeholders within the same system. After verification and approval by participants, a new block is added to the storage/database of previously stored blocks in the form of a chain. The blocks are stored through the formation of Merkle trees and the chain is maintained by hash pointers. The immutability property of blockchain is achieved by the characteristics of hash pointers, timestamp, name and incorporation of the concept of digital signatures of the stakeholders that take part in action. Along with the data storage structure, the data distribution in the blockchain model does not follow the widely accepted client-server model. Instead, it adopts the peer-to-peer (P2P) model, which considers any central authority to control. Hence, the client-server model, the data in the P2P model is stored in all the participant nodes of the network.
