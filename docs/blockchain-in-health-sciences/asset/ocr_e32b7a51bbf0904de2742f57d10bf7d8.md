# IOT AND BLOCKCHAIN SECURITY FOR MEDICAL DATA 237

Blockchain handles a number of tasks, including ciphertext indexes, managing sessions, auditing, and authentication. After data is stored on a cloud service provider, it stores the index. Three smart contracts are produced by the technology for session management, user authentication and verification, and index storage. The encrypted ciphertext index and required settings are included in the indexing smart contract to enable safe data storage and retrieval. The content of the ciphertext that the user has requested is verified by the user authentication and verification smart contract. Lastly, the duration and quantity of tries for every user authentication session are verified using the session management contract. Every instance of misconduct is documented in the system that is used for auditing, session management, authentication, and ciphertext storage. Index Storage: The blockchain enables the safe archiving and retrieval of electronic medical records. Smart Contracts: They serve as a safe means of data retrieval and storage and are employed in session management, user authentication, and data.

The Trusted Authority (TA) bears the responsibility of creating, dispersing, and overseeing the security settings and keys. Being in charge of creating, distributing, rescinding, and maintaining keys and security settings, it ensures that the system is robustly secured. Individuals known as Data Owners (DOs) are for whom IoT devices have information is gathered by IoT devices. Both patients and physicians are included in this group to ensure patient-centric data control and privacy, physicians and patients collaborate in mutual partnership. Medical personnel who need access to the stored data to provide treatment are known as Data Users (DUs). This applies to physicians, nurses, and other medical workers. Medical experts who need access stored data for therapeutic purposes can do so with the use of data decryption procedures, blockchain-based authentication, and secure access requests.
