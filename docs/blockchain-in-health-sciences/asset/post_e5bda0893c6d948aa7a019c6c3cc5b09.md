## 1.3 Working of Blockchain

### 1.3.1 How Does Blockchain Work?

A unique variation of the decentralised digital ledger idea is blockchain. This is made possible by technology that makes sure the documents are verified and preserved, so they cannot be changed on computers connected to a peer-to-peer (P2P) network, as cooperative copying and peer-to-peer transfers. It fulfils its mission to function in a safe, unchanging, transparent, democratic, and controllable manner in this way [13]. A few requirements have been met by this vision, and several common concepts across all blockchain technologies address these objectives. These include multiple stakeholders able to write records in a shared and trustworthy storage environment, the lack of trust or hierarchy among these actors who can add records, the rejection of the necessity or need for a mediator or central authority, the rejection of purposeful or inadvertent record alteration, and the requirement that users in the ecosystem have a degree of anonymity that will be decided based on fiction.

Blockchain is a method in which transactional data is stored in a secured manner. Here, blocks are connecting in a cryptographic order which is predefined. Transparency, decentralization, and security makes this technique one of the best methods for secure data storage. Whenever a new transaction or block is added to the network algorithms are needed to assess, validate, and process the block's history across all the nodes within the same blockchain which they are part of. When the appropriate nodes verify the block's history and signature a new block is added to the ledger and the blockchain is modified [14]. Finally, a consensus mechanism is run, and the block cannot be published to the blockchain if a consensus is not reached. As the consensus process is distributed, blockchains operate as distributed ledgers, which eliminates the need for a centralized authority to validate blockchain transactions. A blockchain-based transaction is therefore considered to be safe.

## 1.3.2 Blockchain Architecture

For deeply understanding the architecture of blockchain, different aspects of this technology need to be considered. These include the blockchain nodes, transactions that comprise blocks, secure policies, consensus algorithm and a mechanism to add new blocks to the chain. The architecture of blockchain consists of distributed and decentralized ledger system [15].

Figure 1.2 depicts the blockchain architecture. Some of the few essential elements of blockchain architecture are as follows:

- **Nodes**: Nodes are defined as individual computers or electronic devices connected to the blockchain network. Nodes of a blockchain takes part in the consensus process and keep a copy of the entire blockchain. It executes the software for the blockchain protocol, enabling it to validate the transaction and network security. Blockchain nodes exchange messages with one another. The network is increasingly decentralized the more nodes it has [16].
- **Transactions**: On the blockchain network, transactions are logs of data transfers or other activities. Before being included on the blockchain, these transactions are collected into blocks. All nodes instantly record, validate, and settle transaction data, including price, asset, and ownership, when a transaction is added to the blockchain. Every verified alteration that is noted on one ledger copy is noted on all other ledger copies simultaneously [17].
- **Blocks**: The multiple transactions are added to the block in an orderly manner and connected with the cryptographic hash. A chain is formed by each block having a reference to the one before it. Within the blockchain database, blocks are data structures that permanently record transaction data related to cryptocurrencies. Initially, a block is composed of the unverifed transactions in the network which are further verified by the miners [15, 18].
- **Consensus Mechanism**: Consensus mechanisms are methods that bring all nodes in a distributed blockchain network together around a common set of data. They act as the standards for validation that every blockchain transaction needs to meet to be approved. These protocols allow nodes to agree on the legitimacy of transactions and the sequence in which they should be added to the blockchain. Proof of Work (PoW), Proof of Stake (PoS), and their corresponding variants are well-known examples.
- **Smart Contracts**: These are agreements that self-execute and have the contract explicitly encoded into the code. Automated and trust less transactions are via smart contracts, which are stored and performed on the blockchain. When the terms and conditions of a digital agreement signed and saved on a blockchain network are fulfilled, the contract immediately goes into execution. The terms and conditions are expressed in programming languages designed specifically for blockchains, such as Solidity [19].
- **Network**: The network architecture connects each and every blockchain node. It can be public, private or consortium-based. A decentralized network is created with some verified peers working the same as the blockchain network. However, this is accessible by only verified peers. It may be managed by an organization that manages the consensus on their own and allows the partition of peers according to the requirements [20].
- **Cryptographic Hashing**: The integrity of data saved in blocks is protected by hash functions. Every block includes a cryptographic hash of the one before it, tampering becomes more challenging. Blockchain protocol measures the message block and links the blocks together in a chain using a cryptographic hash function. The hash created for the newly created block and as well having the hash of previous block to create the [21].
- **Wallets**: On the blockchain, wallets are software programs that let users transmit, receive, and store tokens or cryptocurrencies. They oversee the private keys that allow users to access their money. The ability to manage many cryptocurrency types, such as Bitcoin and Ethereum, is provided by a blockchain wallet.
- **Interfaces**: Interfaces for users to interact with the blockchain network are known as user interfaces. These could be command-line interfaces, phone apps, or web-based programs. In blockchain, and more particularly in Solidity, an interface is a set of function declarations that are defined but not implemented. They facilitate interoperability and standardized communication among contracts on the blockchain by acting as contracts or blueprints that other contracts can follow [22].
