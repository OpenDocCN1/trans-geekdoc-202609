## 6.4 Emergence of Blockchain in Cloud Technology

The healthcare industry handles data in terms of EMR, EHR, and PHR, which are stored in the cloud, where intruders and hackers attempt to erase or steal the data for profit. Therefore, safeguarding the cloud is essential. Various researchers have worked on this issue and provided solutions using cryptographic techniques and various encryption algorithms. However, all of these solutions are based on a centralized approach. A decentralized approach has emerged, namely blockchain, which serves as a solution to security issues in healthcare cloud computing. It operates over the Internet, which is used in various real-time applications like online shopping and messaging.

Figure 6.2 depicts the workflow of blockchain, which starts with a request message, followed by block creation, approval of the block, and its addition to the chain. Finally, the transaction begins its execution. Data storage and maintenance are handled by cloud storage.

## 6.5 IoT-Assisted Healthcare System

IoT-assisted healthcare systems bring applications to patients and health-care practitioners through remote monitoring, integration of medical devices, and the connection of sensors and devices. The role of IoT devices is to collect data from various medical cases and to provide visualization and analysis of the data with greater accuracy. IoT can handle different software and hardware for communication. Figure 6.3 represents the system model of an IoT-based healthcare system.

It consists of the following blocks:

### Infrastructure

It is essential to read the data sensed by sensors and to display them on a device for visibility. It is composed of hardware and software components.

### Sensor

Different types of sensors are used depending on the type of medical application. Examples include pulse oximeters, electrocardiograms, thermometers, fluid level sensors, and sphygmomanometers (blood pressure monitors) that read the current patient status (data).

## 6.6 Blockchain Integration with IoT and Cloud Technology

Integrating IoT with blockchain provides abstraction and offers services to consumers. When the medical database is integrated with cloud technology, there may be more possibilities of data leakage. Hence, security should be enforced on the cloud side. Additionally, with the integration of IoT technology, the efficiency of devices should be increased through proper testing. The Figure 6.4 depicts the flow of proposed model.

While adopting blockchain, a multilevel authentication scheme is needed. Therefore, in the healthcare database, integrating blockchain, IoT, and cloud technology with enhanced security is considered. This provides double-ended security in the cloud server when data are uploaded. Whenever data are uploaded to the cloud, a hash value is generated, which is used by the healthcare industry to view patient details. The data are then pushed into a block. By implementing various emerging IoT devices that perform patient data collection, the data are pushed into blockchain technology. Software engineers at the company check for alterations or breaches by hackers, ensuring the integrity and security of electronic medical records.

Optimized machine learning algorithms are applied for data analysis, and the data are pushed into the cloud, where ML algorithms are applied again for data integration and upload into the blockchain. The security of the blockchain is ensured through modified encryption algorithms and hash key generation for both the hospital and patient sides, satisfying requests from both parties.
