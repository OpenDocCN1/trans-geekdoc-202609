# 18.4 Fog Computing and Cloud Integration

The advantage of an IoT-based healthcare system is that a patient in a rural location may still obtain high-quality healthcare services without physically visiting metropolitan hospitals. Researchers have designed traditional healthcare systems [8–11, 16, 21, 24] that rely on IoT. These systems contain only two layers: 1: Sensor layer; 2: Cloud layer. The sensors or IoT devices at the sensor layer are used to collect health-related data and send it to the cloud server. The cloud server is utilized to store information by employing AI tools, which aid physicians or doctors in understanding the patients' health condition or making informed decisions. The physicians can access patients' data from the cloud via internet connectivity. These systems were fundamental and very easy to maintain. Cloud service providers can effortlessly ensure the security of data through the implementation of authentication and encryption/decryption mechanisms.
