The convolutional layers in a CNN function similarly to the early visual processing stages of the brain. When a medical professional examines an X-ray, they start by identifying basic elements such as edges, textures, and simple shapes. In a CNN, small filters, akin to image kernels, scan the image's tiny regions to extract low-level information like edges and gradients. These filters operate over the entire image, creating feature maps that highlight essential visual characteristics.

+   Pool Layers–Summarizing Information: The Convolutional layers learn everything, by increasing the computational requirement exponentially. Hence, we need MaxPool (taking maximum value) to filter out the important characteristics and pass these picked features to the next layers for further computations. This reduces the dimensionality of the data extracted by the convolutional layer and helps to:
    - Control overfitting (when the model memorizes the training data too well and performs poorly on unseen data).
    - Make the network more computationally efficient.

+   Flatten layers: These layers reduce the dimensionality of the neural network. By transforming the high-dimensional data coming from the MaxPool layer to a one-dimensional data structure before passing it to the next convolutional layer or the output layer.

+   Output layer – Fully Connected Layers: The output layer is the final layer of the neural network, which again does not perform any computations.

+   Activation Function – Introducing Non-Linearity: In convolutional neural networks (CNNs), activation functions play a crucial role in introducing non-linearity into the network. This non-linearity is essential for CNNs to learn complex patterns in images and videos, which are inherently non-linear data structures.
