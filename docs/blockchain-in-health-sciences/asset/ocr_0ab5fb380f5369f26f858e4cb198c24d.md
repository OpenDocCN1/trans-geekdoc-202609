+   Scalability: As the IoT based solutions become mature, it requires deployment of large number of IoT devices. Also, these large numbers of devices will also produce large volume of data at the fog server and at the cloud server. Handling large number of sensors or large volume of data is a tedious task. Thus, achieving scalability is a challenging task in IoT-based solutions.

+   Reliability and Latency: It is crucial to have low latency and reliable networks in IoT-based systems to achieve real-time information getting. Fog servers are introduced to minimize latency by processing and storing data nearby the sensors. But still the communication channel established between IoT devices and fog nodes should maintain low latency and avoid congestion.

+   Resource Constraints: It is important to understand that sensor nodes are very small and have limited memory, computing capacity, as well as battery life. Despite many of the security requirements discussed above, implementing a complex security mechanism at the sensor level is very challenging. Only very lightweight security protocols can be implemented here. Therefore, there must be a balance between constraints on resources and demands for security.

+   Data Management and Analytics: Since sensor nodes continuously generate large amount of data, it becomes difficult to process these data to get valuable insights immediately. However, applications that do real-time monitoring or dealing with critical cases require immediate insights for making clinical decisions. Thus, it is imperative to have very powerful as well as efficient analytics and machine tools for data processing.
