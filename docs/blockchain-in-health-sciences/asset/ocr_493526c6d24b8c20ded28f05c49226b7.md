# 10.4.2 Cost Performance Analysis

This part focuses on measuring the price and gas amount consumed by each function to assess the performance of the dynamic smart contract. Furthermore, the smart contract has a minimum gas cost, which covers the transaction of deploying any of the commands onto the Ethereum network, and this must be met for the entire transaction to execute. The Remix IDE, which is capable of showing the purchaser gas cost for every transaction through the output console, is a very helpful tool. An illustration of the fees and costs associated with different smart contract features is provided in Figure 10.12. This chart serves as a good example of the patterns of smart resource consumption. Additionally, the red line in Figure 10.12 represents the computation costs incurred in all transactions executed by each user. The blue line, included on the Y-axis for medium and large transaction sizes, represents the transaction fees, which include the charges for sending the code of the dynamic smart contract to the Ethereum blockchain. The main analysis of resource utilization and the evaluation of dynamic smart contracts must be based on this kind of study.
