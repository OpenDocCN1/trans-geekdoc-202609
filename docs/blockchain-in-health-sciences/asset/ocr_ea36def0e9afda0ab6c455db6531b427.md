# 11.4 Proposed System

# A. System Model Terminals, Blockchain, Cloud Service Providers (CSPs), Fog Aggregation (FNs), Internet of Things Devices, Trusted Authorities (TA), Data Owners (DOs), and Data Users (DUs) are the eight distinct entity that comprise our system paradigm.

The IoT devices gather therapy and measurement data for patients at an aggregation terminal. The data is processed by aggregate terminals and forwarded to fog nodes, who create ciphertext index and store it on the blockchain. The fog node activates a smart contract for user authentication and identity verification via blockchain communication.

The system retrieves the requested ciphertext and encrypted random value upon successful completion of the authentication procedure and attainment of the encrypted ciphertext index. After the fog node decrypts the encrypted random value, DU uses GetFunction and the random value to calculate the symmetric key. Figure 11.1 shows the system model for the approach we recommend.
