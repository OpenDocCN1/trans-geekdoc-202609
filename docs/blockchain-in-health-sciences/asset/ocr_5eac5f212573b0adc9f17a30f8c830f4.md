The application of blockchain technology was covered in this paper [8] to develop an algorithm for smart contract that will benefit users of a platform for medical records. The algorithm ensured immutable execution, addressed identification and reliability issues, and controlled access to healthcare systems. Executable distributed code is used in the construction of the approach, which integrates the automated administration of clinical history in a distributed environment. The technique was created for a permission, private architecture using the Solidity programming language. In addition, a proposed consensus method is implemented, which uses a hash function that is 22% faster and uses a lot processing power.
