
# Stuxnet的起源与奥林匹克运动会行动

Stuxnet的构想始于两年多前，源于一个绝望的两难困境。2005年，伊朗强硬派总统马哈茂德·艾哈迈迪-内贾德上台后，公开炫耀发展国家核能力的意图。这包括将铀浓缩到可用于核能的等级。但国际监督机构指出，伊朗只有一座核电站，且已由俄罗斯供应浓缩铀。他们怀疑动机远不止于此：艾哈迈迪-内贾德想要核武器——以色列极可能将其视为生存威胁，并可能引燃整个中东。

早在1980年代，伊朗政府就在与伊拉克的残酷战争中寻求获得核武器，当时怀疑伊拉克领导人萨达姆·侯赛因也在谋求制造核弹。但两国均未实现原子野心，随后几十年里，伊朗加入世界核强国行列的进展仅是蹒跚前行。

然而，在2005年夏季艾哈迈迪-内贾德当选两个月内，他废除了伊朗与国际原子能机构（IAEA）达成的暂停核发展的协议。多年来，伊朗一直在纳坦兹（Natanz，伊朗中部城市）地表下25英尺处建设两座27万平方英尺的大型地下设施，旨在将铀浓缩至武器级纯度。在艾哈迈迪-内贾德领导下，纳坦兹项目重新全速推进。

2005年，美国情报机构估计伊朗需6至10年才能制造核弹。以色列情报估计约5年。但伊朗重启纳坦兹浓缩计划后，以色列情报将估计缩短至最少2年。私下里，以色列官员告诉美方，核弹可能在6个月内就绪。危机迫在眉睫。

随着截止日期逼近，布什国家安全团队提出两个选项，均无吸引力：要么允许伊朗这个不可预测且极具侵略性的政府获得毁灭性武器，要么对纳坦兹发动导弹袭击——这是战争行为。事实上，无论哪种选择，战争似乎都不可避免。若伊朗逼近实现核野心的临界点，以色列强硬政府将自行发动袭击。“我需要第三条路”，布什反复告诉顾问。

这条路就是Stuxnet。这是一个诱人的构想：一段代码旨在像物理破坏一样有效地瘫痪伊朗核计划，深入纳坦兹核心实施，却避免了全面军事打击的风险和附带损害。五角大楼战略司令部联同美国国家安全局（NSA）精英进攻性黑客团队“定制访问行动”（TAO）及以色列网络安全团队“8200部队”，开始开发前所未有的恶意软件。它不仅能破坏纳坦兹的关键设备，还能摧毁设备。

到2007年，一批能源部国家实验室已获得伊朗使用的同款P1离心机——粗如电话杆、高近6.5英尺的光亮圆筒。数月来，实验室悄悄测试这些机器的物理特性，实验如何仅凭数字指令摧毁它们。（部分测试在爱达荷国家实验室进行，大致同期该实验室研究人员正进行“极光”黑客演示，证明几行代码即可摧毁大型柴油发电机。主导“极光”工作的迈克·阿桑特拒绝回答任何关于Stuxnet的问题。）

测试开始不久，布什的情报顾问在桌上摆出了一台仅凭代码就被摧毁的离心机的金属碎片。总统印象深刻，批准了部署这款精妙恶意软件的计划，代号“奥林匹克运动会”。这被证明是一种极其复杂的网络战工具，让爱沙尼亚和格鲁吉亚的网络攻击看起来像中世纪的投石机。

2009年初布什卸任时，“奥林匹克运动会”仍处早期阶段。Stuxnet刚开始展现渗透和降级伊朗浓缩过程的潜力。布什与奥巴马举行紧急交接会议，向继任者亲自阐述了这一前所未有的网络战任务的地缘政治重要性与微妙性。

奥巴马在倾听。他不仅选择继续Stuxnet行动，还将其大幅扩展。

# 离心机与浓缩原理

所幸人类种族得以延续，将铀浓缩至制造世界最毁灭性武器所需的纯度，是一个极其复杂的过程。铀矿石开采时，主要由同位素铀-238组成，铀-235（这种银白色金属稍轻的形式，可用于核裂变，释放足以供电或摧毁整座城市的能量）含量不足1%。核能需要约3%至5%的铀-235，而核武器要求核心由高达95%的稀有同位素组成。

这就是离心机的用武之地。为将铀浓缩成武器级材料，必须将其转化为气体并泵入离心机的长铝筒。筒内腔室由一端电机驱动，以每分钟数万转高速旋转，腔室外缘速度超音速。由中心向旋转腔室壁的离心力高达百万倍重力，分离出较重的铀-238，从而吸取铀-235。为达到武器级浓度，该过程须通过离心机“级联”反复进行。因此，隐藏在纳坦兹地下的核浓缩设施需要成千上万台高大、脆弱、高精密的旋转机器组成的庞大“森林”。

Stuxnet旨在成为投入这些运转中的完美、隐形扳手。

2008年某时，纳坦兹工程师开始面临神秘问题：看似随机时间，某台离心机会失控旋转，内部腔室转速超出其精密轴承设计极限；其他情况下，腔室内压力增大将其推离轨道，旋转筒以超音速撞击外壳，从内部将机器撕裂——正如一年前爱达荷国家实验室“极光”测试中柴油发电机自我撕裂般。

纳坦兹操作员在离心机数字监控中未见任何迹象或预警解释机器突然“自杀”。故障却持续发生。最终，工厂管理员指派员工肉眼盯着离心机寻找线索。他们甚至报废整组164台离心机级联以隔离问题。均无效。
