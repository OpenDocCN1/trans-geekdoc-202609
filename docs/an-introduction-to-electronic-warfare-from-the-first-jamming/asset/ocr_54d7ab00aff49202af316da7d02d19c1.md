If a long pulse is used, then the radar needs to wait for an even longer time to receive the signal reflected back from the aircraft. Consequently, the radar’s response time can be too long. To solve these issues, pulse compression techniques need to be applied. In the following two sections, two popular LPI radars based on pulse compression principles, phase coded radar, and frequency modulated continuous wave (FMCW) radar will be explained.
