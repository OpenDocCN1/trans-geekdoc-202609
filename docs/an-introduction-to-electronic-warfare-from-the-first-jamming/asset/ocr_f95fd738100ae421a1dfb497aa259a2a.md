The purpose of jamming is to cause a premature detonation when the missile is still far away from the target aircraft. One simple way to jam a proximity fuze is to amplify the received radar signal and retransmit it so that if the proximity fuze is activated based on the amplitude of Doppler signal, the jamming signal can cause a premature detonation. To counter this repeater jamming method, some fuzes detonate the shell only when the Doppler signal’s amplitude is above the threshold and the Doppler signal’s frequency changes rapidly.
