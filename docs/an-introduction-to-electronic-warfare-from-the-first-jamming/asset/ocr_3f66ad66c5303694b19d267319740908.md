However, this arrangement can be difficult to use for detecting a target because the antenma gain and size of main beam size are related and higher gain means a narrower main beam. The chance of hitting a target using a microwave signal with a very narrow main beam is, of course, small.

The comprmised approach is to use an antenna with medium gain and covering a reasonable angle. For example, a common approach is to create a vertical fan-shaped beam. The beam is narrow in the azimuth direction and wide in the elevation direction. To form this type of beam, the antenna will be wide in the horizontal direction but short in the elevation direction as shown in Figure 2.8. The beam shown in Figure 2.8 is called the fan beam and a beam that is narrow in both azimuth and elevation directions is referred to as the pencil beam. This antenna will rotate in horizontal direction. If a target is detected, the azimuth angle is known. The elevation can be found from a different antenna directed in the desired azimuth direction.
