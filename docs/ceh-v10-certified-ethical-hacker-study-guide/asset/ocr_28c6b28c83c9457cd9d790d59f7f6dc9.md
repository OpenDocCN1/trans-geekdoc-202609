At the bottom, you can see the different share names. This includes the IPC$, which is used for interprocess communication between hosts. This allows for management of systems remotely. Using enum4linux, we can finally see the master browser on the network. The system named STEVEDALLAS holds the current authoritative list of all of the systems on the network. This is a system that has been elected by other systems on the network, which essentially means it has volunteered and, based on its characteristics, no one else has challenged it.
