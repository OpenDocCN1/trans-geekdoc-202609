## 11.10 智能缺陷分类算法

在本节中，我们介绍与机器学习领域相关的算法。
它们的作用是检测和定位故障。它们也被称为人工智能技术。其中包括：`ANN-AG`、`SVM`、`KNN` 和 `ELM`。在下面的内容中我们将详细介绍各自的理念。需要注意的是，这些算法在学习阶段后有可能实现自主运行。这对我们的研究也很重要，因为目标是在任何时刻决定机器的状态。

### 11.10.1 人工神经网络与遗传算法（ANN-AG）

由于每次手动设置参数来寻找合适的架构存在困难，我们选择将遗传算法与 `ANNs` 结合，以自动化和优化获得实现最佳分类或能够以最佳精度检测旋转机器不同状态的架构。事实上，目前在几乎所有工业领域，旋转机器的监测都很流行，可靠性是最重要的标准。这意味着用于监测这些机器的系统必须达到最高标准，以保证运行的连续性并避免严重事故。在文献中，已证明人工神经网络（`ANNs`）可以用于此类问题并进行适应 \[[23](#ch11.xhtml#r11_23),[24](#ch11.xhtml#r11_24)\]。遗传算法（`GA`）也在多个参考文献中有所介绍 \[[24](#ch11.xhtml#r11_24),[25](#ch11.xhtml#r11_25)\]。在其发展的短暂时期内，`GAs` 显示出其卓越的能力，并在许多领域得到成功应用。

#### 11.10.1.1 人工神经网络

基于人类大脑功能的人工神经网络以并行分布式网络模型的形式开发。`NAS` 的应用十分广泛，例如在数据分析、模型识别和控制中 \[[26](#ch11.xhtml#r11_26),[27](#ch11.xhtml#r11_27)\]。而在不同类型的 `NAS` 中，多层感知器（`MLP`）最受欢迎，并在大多数工作中使用，本研究亦是如此。在本项目中，由于没有其他类型的神经网络，术语 `RNA` 和 `MLP` 互换使用。这里给出 `MLP` 的简要介绍以求完善。`MLP` 网络由输入层源神经元、一个或多个隐藏层以及输出层组成。输入层和输出层的神经元数量分别取决于输入变量的数量和期望类别的数量。隐藏层的数量和每个隐藏层中的神经元数量影响网络的泛化能力。对于较少的隐藏层和神经元，执行可能不成比例。请注意，隐藏神经元过多可能存在过度拟合数据的风险。有各种启发式和系统化的方法来选择隐藏层和神经元的数量 \[[26](#ch11.xhtml#r11_26)\]。

[图 11.18](#ch11.xhtml#f11_18) 显示了一个典型的 `MLP` 架构，由三层组成；分别用于输入、隐藏和输出层的 `M`、`N` 和 `O`。
