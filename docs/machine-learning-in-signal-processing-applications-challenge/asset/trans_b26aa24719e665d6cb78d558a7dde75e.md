
在本章中，我们概述了自适应滤波器和神经网络，强调了已经证明在实践中有用的应用和基本算法。尽管在各自领域已有诸多贡献，研究工作仍在快速推进，并且未来很可能开发出新的应用。神经网络领域涵盖了许多其他类型的网络结构和学习算法。确实，它们已成为一门跨学科的学科，在神经科学、心理学、数学、物理科学和工程学方面有着深厚的根基。毋庸置疑，它们对自适应信号处理产生了重大影响，特别是在需要使用非线性的应用中。
