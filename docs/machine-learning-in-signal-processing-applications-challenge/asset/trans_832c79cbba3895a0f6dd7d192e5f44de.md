

在电感应电机机电故障诊断中，并不仅仅是如本研究中所述的 `MCSA`、高分辨率信号处理（`HRM`）方法和学习机算法的组合。事实上，过去曾使用诸如 `MCSA`、`PCA` 和信号处理方法等组合来执行相同的工作。尽管这些技术所使用的信号处理方法已取得良好结果，但它们各自或多或少都存在局限性，不允许将其扩展到所有研究案例中。例如 `FFT` \[[1](#ch11.xhtml#r11_1)\]（快速傅里叶变换）就是这种情况，尽管它在信号处理中被广泛使用，但无法提供频率分量出现的时间信息；或者 `DWT`（离散小波变换），尽管它对信号在时频域给出了解释，但在高频时提供良好的时间分辨率而频率分辨率较差，在低频时提供良好的频率分辨率而时间分辨率较差。此外，这些方法需要非常高的信号处理知识水平，而且不要忘记 `PCA` \[[2](#ch11.xhtml#r11_2)\] 是一种线性方法，因此在大多数情况下不适用于非线性的常规机器。考虑到这一观察，研究人员已逐步转向更合适的解决方案；因此选择了这种组合，除了摆脱所研究系统的性质外，还能在机器运行过程中提供智能且可适应的诊断（[`Table 11.1`](#ch11.xhtml#t11_1)）。

### [`TABLE 11.1`](#ch11.xhtml#t11_1b) 现有方法的技术缺陷

| 方法 | 技术缺陷 |
|---|---|
| `MCSA + FFT` | 不提供频率分量出现的时间信息 |
| `MCSA + PCA` | `PCA` 是一种线性方法，在大多数情况下不适用于非线性的常规机器 |
| `MCSA + DWT` | 在高频时提供良好的时间分辨率而频率分辨率较差 在低频时提供良好的频率分辨率而时间分辨率较差 |

## 11.3 异步电机

异步电机是一种交流电机，定子和转子之间没有连接。术语“异步”源于转子速度与定子电流的脉动不同。

我们选择重点关注异步电机的原因是，异步电机在工业应用中被广泛使用，因为由于其设计，其成本相对低于其他电机，其电磁鲁棒性高，且不同制造商之间具有良好的标准化。然而，该机器设计的简单性隐藏了相当重要的功能复杂性。还应提到，异步电机在高功率领域长期以来与同步电机激烈竞争，直到电力电子技术的出现。如今它在许多应用中都能找到，特别是在交通（地铁、火车、船舶推进）、工业和家用电器领域。

起初它仅用于发动机，但得益于电力电子技术，它越来越多地用于发电机。例如风力涡轮机就是这种情况。

这些异步电机由一个称为定子的固定部分和一个称为转子的运动部分组成，根据机器的运行模式（电动机或发电机），转子提供感应的来源。

## 11.4 机电故障

这些机器由一组机械系统组成，最常遭受众多故障的影响，这些故障影响其运行，甚至影响其生产率，甚至影响其物质和人类环境的安全，如核电站的情况。它们无疑众多，但本文仅关注以下四种故障类型。

### 11.4.1 轴承故障

在文献中，旋转机器故障的主要原因是由于疲劳剥落、润滑剂污染、过载或其他原因或电气原因（如逆变器引起的泄漏电流流动）造成的故障 \[[3](#ch11.xhtml#r11_3)\]。轴承故障是旋转机器中几种效应的根源，即：噪声水平增加以及转子围绕机器纵轴运动引起的振动出现 \[[3](#ch11.xhtml#r11_3)\]。这种类型的故障还会导致机器负载转矩的变化（振荡），从而导致转子阻塞。还应提到，滚珠轴承由两个环组成，一个是内环，另一个是外环，两者之间有若干滚珠或旋转滚子。当轴承在正常条件下运行时，疲劳故障始于位于滚道和滚动元件表面下方的微小裂纹，并逐渐在接触表面传播。此外，轴承故障最常与导致转子不对称的偏心故障相关。另一方面，与滚珠轴承相关的故障可按如下分类 \[[3](#ch11.xhtml#r11_3)\]：外圈故障、内圈故障、滚珠和保持架故障。此外，由于滚珠轴承支撑机器的转子，任何轴承故障都可能导致转子与定子之间的径向位移。这些由轴承振动引起的气隙变化通过在定子电流中产生谐波来影响内部磁通的变化 \[[4](#ch11.xhtml#r11_4),[5](#ch11.xhtml#r11_5)\]。在 [图 11.3](#ch11.xhtml#f11_3) 中，我们通过示意图展示了轴承的外观及其可能遭受的故障，即内圈损坏、外圈损坏和保持架故障（[图 11.4](#ch11.xhtml#f11_4)）。

### 11.4.2 转子断条故障

异步电机转条的断裂是一种在实验室中最常研究的故障，因为其实现简单。转条断裂导致转子不对称。不对称的结果是在转差频率下产生一个与定子产生的场旋转方向相反的场。因此，在定子绕组中产生额外电流 \[[6](#ch11.xhtml#r11_6)\]。转子断条故障如图 [图 11.5](#ch11.xhtml#f11_5) 所示。
