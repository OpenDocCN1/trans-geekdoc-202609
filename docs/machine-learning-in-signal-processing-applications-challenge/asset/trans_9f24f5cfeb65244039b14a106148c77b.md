## 5.1 深度学习：导论

深度学习 \[[1](#ch05.xhtml#r5_1)\] 是机器学习的一个子集，专注于从输入信息中学习巨大的特征，特别是在信息复杂的情况下。这基本上是针对复杂信息类型（如图像、视频、音频等）而设计的常见特征提取器的替代品。传统或基础的机器学习方法最初被用于图像处理 \[[2](#ch05.xhtml#r5_2),[3](#ch05.xhtml#r5_3)\]、自然语言处理（NLP） \[[4](#ch05.xhtml#r5_4), [5](#ch05.xhtml#r5_5) 和 [6](#ch05.xhtml#r5_6)\] 以及音频处理 \[[7](#ch05.xhtml#r5_7),[8](#ch05.xhtml#r5_8)\]。

在图像中存在具有不同光照或角度的相似物体时，距离度量在实际上几乎失效。此外，使用传统的线性分类器方法 \[[9](#ch05.xhtml#r5_9)\]，输入图像的每个像素估计都会被评估并标记，以确定其是否可以作为匹配的边界。通常会采用像素的加权平均估计来进行比较，这就是为什么图像中的所有困难区域 \[[10](#ch05.xhtml#r5_10)\]（例如，光照、不同角度或图像视角、噪声、背景杂乱以及同一物体的多种变体）会导致算法无法匹配输入图像。

在自然语言处理中，深度学习方法通常基于神经网络，并依赖于称为词嵌入的连续词向量表示。本节首先介绍词嵌入的概念以及创建此类表示的各种无监督方法。利用词嵌入的自然语言处理应用在章节末尾进行了描述。传统的自然语言处理任务 \[[4](#ch05.xhtml#r5_4)\]，例如词性标注（POS）或语义角色标注（SRL），包括为句子中的每个词标注标签。另一类问题，例如命名实体识别（NER）或浅层解析（分块），包括识别并命名短语（例如词组）并赋予预定义标签。此类任务可以通过识别短语边界而不是直接识别整个短语来表述为词序列问题。

在音频分析领域 \[[7](#ch05.xhtml#r5_7)\]，表征音频数据的低级特征可分为音调和时域特征。音调与频域相关，并表征特征，例如音轨中存在的频率 \[[8](#ch05.xhtml#r5_8)\]，以及区分基频和泛音频率。时域特征在时间域中定义。许多从音频信号中提取特征的方法已被研究用于音频内容分析。

这些专门设计的提取音频数据的方法取得了许多已记录的成功，并改善了不同问题领域的音频分析性能。然而，这些方法并非为音乐信息设计。它们是为语音音频设计的，语音音频只是音乐曲目中的单一组成部分，而使用这些方法进行特征提取的研究表明，它们确实从音乐音频中分离出一些重要信息。

## 5.2 深度学习的过去、现在和未来

长期以来，深度学习不断发展，对行业和商业领域造成了巨大的冲击。深度学习是机器学习的一个分支，它使用算法进行信息处理并复制推理过程，甚至创造出映射。深度学习利用算法层进行信息处理，理解人类语音，并视觉识别物体。
