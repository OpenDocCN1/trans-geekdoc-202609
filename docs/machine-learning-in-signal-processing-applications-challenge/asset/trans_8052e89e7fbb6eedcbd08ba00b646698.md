## 5.3.5 命名实体识别

`NER` 是一个经典的 NLP 任务；它旨在为文本中的每个词找到预定义的类别，这些类别包括人名、组织名称、时间表达等。命名实体标签的输出可用于许多应用，例如在搜索引擎中查找相关网页以及根据识别的文本投放广告。大多数 `NER` 系统接收未经标注的文本块，并输出标注后的文本，或由命名实体标签组成的序列。

`NER` 是一个具有挑战性的问题，不仅因为并非每种语言都有足够的标注数据，而且因为能够成为命名实体的词类型存在一些限制。解决该任务的大多数现有方法都是线性统计模型，如隐马尔可夫模型 (`HMMs`)、最大熵马尔可夫模型 (`MEMMs`) \[[67](#ch05.xhtml#r5_67)\] 和 `CRF` \[[68](#ch05.xhtml#r5_68)\]。随着深度学习的兴起，`CNN` 已被用于解决 `NER` 问题 \[[55](#ch05.xhtml#r5_55)\]，以及 `RNN`，如 Graves 和 Schmidhuber \[[69](#ch05.xhtml#r5_69)\]。目前，`NER` 的流行解决方案是使用 `Bi-LSTM` 结合 `CRF` \[[54](#ch05.xhtml#r5_54)\]。`Bi-LSTM` 层可以从文本的两个方向捕获文本关系，而 `CRF` 层能够创建输出标签的规则，以避免像 ‘`B-PER`’ 后跟 ’`B-ORG`’ 这样情况（组织名称的开头不可能跟在人名开头之后）。

`NER` 可以用两种方法进行评估，要么逐词匹配，要么跨度级评估。词级评估逐个查看每个词，是最简单的评估方法。跨度级评估更为严格，要求不仅每个单独的词正确，而且连接类别的完整长度也正确。因此，如果一个实体跨越多个词，则该子序列内的所有词都必须正确，预测才被视为正确。一般而言，结果报告为调和平均值或 `F1-score`，其细节在方法部分进一步说明。当前研究正在寻找减少创建良好数据集所需昂贵标注的方法 \[[70](#ch05.xhtml#r5_70)\] 并提高跨领域的性能 \[[71](#ch05.xhtml#r5_71)\]。

### 5.4.1 图像处理和计算机视觉简介

深度学习目前在计算机视觉领域无处不在。作为一种人工智能设备，深度神经网络擅长理解高维数据，例如图像。深度学习模型最初在计算机视觉中用于图像识别 \[[73](#ch05.xhtml#r5_73),[74](#ch05.xhtml#r5_74)\]。然而，计算机视觉研究的目的是构建能够看的机器。这需要能够从图像和视频中提取比识别更丰富的信息的模型，以解决计算机视觉中的其他问题。

#### 5.4.1.1 场景理解

语义像素级分割需要对每个像素的语义类别进行估计，如 [图 5.10](#ch05.xhtml#f5_10) 所示 \[[75](#ch05.xhtml#r5_75)\]。它是受挑战性数据集推动的活跃研究课题 \[[76](#ch05.xhtml#r5_76), [77](#ch05.xhtml#r5_77), [78](#ch05.xhtml#r5_78), [79](#ch05.xhtml#r5_79), [80](#ch05.xhtml#r5_80) 和 [81](#ch05.xhtml#r5_81)\]。在深度学习出现之前，表现最好的技术通常依赖于可用的设计特征独立对像素进行分组。

通常，将图像块输入到分类器，例如随机森林 \[[82](#ch05.xhtml#r5_82),[83](#ch05.xhtml#r5_83)\] 或提升 \[[84](#ch05.xhtml#r5_84),[85](#ch05.xhtml#r5_85)\]，以预测中心像素的类别概率。基于外观 \[[83](#ch05.xhtml#r5_83)\] 或基于运动和外观 \[[82](#ch05.xhtml#r5_82),[84](#ch05.xhtml#r5_84),[85](#ch05.xhtml#r5_85)\] 的特征已被探索。这些来自分类器的每像素嘈杂预测（通常称为一元项）然后通过使用成对（或更高阶）条件随机场 (`CRFs`) \[[84](#ch05.xhtml#r5_84),[85](#ch05.xhtml#r5_85)\] 进行平滑以提高精度。后来的方法旨在通过尝试预测块中所有像素的标签而不是仅中心像素来生成高质量的一元项。这改善了基于随机森林的一元项的结果 \[[86](#ch05.xhtml#r5_86)\]，但在精细结构上降低了性能。另一种方法主张使用流行手工设计特征和时空超像素的组合来获得更高精度 \[[87](#ch05.xhtml#r5_87)\]。
