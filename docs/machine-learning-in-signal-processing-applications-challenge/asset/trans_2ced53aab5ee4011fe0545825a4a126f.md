
在有损压缩中，解压缩后的信号与原始信号不完全相同。会发生信息损失，信号可能会失真。在有损压缩中，压缩率优于无损压缩。为了实现有损压缩，其方法是保持重建质量在一定限度内。同样地，与原始信号的差异和失真在限度内是允许的。对于有损压缩算法，必须使用一些方法来衡量重建质量。由于应用领域多样，正在使用多种方法。对于衡量声音重建质量，可以使用高级音频编码（AAC）、自适应变换声学编码（ATRC）和 Windows Media Audio（WMA）。

### 4.3.4 压缩音频与机器学习应用
在机器学习应用中，为了准确评估模型，必须了解音频数据内部发生了什么。没有关于数据的适当信息，就无法确认模型正在学习什么。对音频数据的理解有许多方面，其中一个突出方面是用于表示压缩音频信号的编解码器。通过分析来自 YouTube 等任何来源的各种音频内容，可以很容易地理解该内容是使用各种编解码器以及不同质量级别编码的。为了利用此音频数据库，必须获得有关编解码器如何与原始音频信号实现的信息，以及这对模型会有什么影响 \[[5](#ch04.xhtml#r4_5)\]。只有这样，才能正确解释机器学习和训练方法的验证结果。

在用编解码器测试机器学习模型时，可以使用以下三种方法来提高分类质量。
* 还原或去噪原始音频信号。
* 扩展使用受损音频的训练数据。
* 设计并开发对受损音频最鲁棒的属性。

多家软件组织多年来一直在努力开发能够提高音质的编解码器。如果研究人员和专业人员在机器学习模型中使用高质量的非参数编解码器，对他们来说会相对容易，他们还必须确保扩充其训练数据集。

## 4.4 数字图像处理
图像可以定义为二维函数 `F(x, y)`。这里，函数 `F(x, y)` 表示在 `x` 和 `y` 上的幅度，`x` 和 `y` 为空间坐标。幅度 `F` 也称为点 (`x`, `y`) 处的图像强度。当 `F`、`x` 和 `y` 均为有限时，图像称为数字图像。换句话说，图像可以表示为行和列或二维数组。图像由有限数量的小元素组成，称为像素。数字图像处理是数字信号处理的一个领域，其中数字计算机使用特定算法处理图像。数字图像处理倾向于减少失真和噪声，而这些是模拟图像处理中的主要问题。数字图像处理将图像作为输入，并使用各种步骤和算法处理图像，以产生用户相关的输出图像。如今，随着智能手机使用量的指数级增长，数字图像处理的应用变得非常流行。

### 4.4.1 与图像处理重叠的领域
随着数字图像处理的发展，其他领域对专业人员和研究人员变得更加重要。这些包括计算机视觉、计算机图形学和人工智能 \[[6](#ch04.xhtml#r4_6)\]。这些领域与数字图像处理的关系在 [图 4.6](#ch04.xhtml#f4_6) 中得以体现。如果输入和输出都是图像，则称为数字图像处理。如果输入是图像而输出是某种描述、知识或信息，则该子领域是计算机视觉。另一方面，如果输入是某种描述或信息，但输出是图像，则该子领域是计算机图形学。如果输入和输出都是某种代码、描述或知识，则是人工智能。

### 4.4.2 数字图像处理系统
典型的数字图像处理系统如图 [图 4.7](#ch04.xhtml#f4_7) 所示，包含六个阶段。第一个阶段是图像获取，其中设备捕获输入图像 \[[7](#ch04.xhtml#r4_7)\]。该设备可以是相机或传感器，具体取决于应用。第二阶段是预处理，涉及图像重建、图像恢复和亮度感知。图像恢复从退化图像估计原始图像。特征提取阶段识别并提取特征，然后使用它们来减少数据。观测值被映射到特征空间域，以便在保持必要信息的同时减少维度。在下一个阶段，使用关联存储器，即高速内容可寻址存储器，来存储模式的关联对。知识库阶段的目标是使用不同技术对信息进行分类。分类规则用于知识库阶段。最后一个阶段是比较阶段，其中特征提取后产生的数据与从数据中学到的内容进行比较 \[[8](#ch04.xhtml#r4_8)\]。该阶段用于图像分类和神经网络训练。

### 4.4.3 机器学习与数字图像处理
在当今情况下，计算机系统不仅能够对图像进行分类，还能够对照片的不同元素进行描述。此外，计算机变得智能，可以通过为每个段落编写文本描述来总结图片。这得益于深度学习网络的演进，该网络能够学习图像中自然存在的模式 \[[9](#ch04.xhtml#r4_9)\]。用于训练卷积神经网络 (`CNNs`) 的最大数据库之一是“Imagenet”。训练是通过 GPU 加速的深度学习框架进行的，例如 `Tensor Flow`、`Chainer`、`Caffe2`、`Pytorch` 等。利用多级结构，深度学习模型在获取图像的关键信息方面非常显著。`CNN` 是另一个利用 GPU 将图像处理中的计算时间大幅减少的模型。图像数据处理的深度学习需要图像分类、数据标注和位置检测。

#### 4.4.3.1 图像分类
使用图像分类，图像被分为不同类别。利用 `CNN` 进行图像分类被发现是最有效的，因为 `CNN` 提高了该过程的准确性。对于图像分类，必须提供给 `CNN` 的关键输入参数是图像数量、图像尺寸、像素中的级别以及通道数。

#### 4.4.3.2 数据标注
数据标注的主要目标是识别图像中嵌入的实际对象，如文本或其他符号。最好手动执行数据标注，以便学习算法自行做出预测。用于数据标注的一些工具是 SuperAnnotate、ImageTagger、VoTT 等。
