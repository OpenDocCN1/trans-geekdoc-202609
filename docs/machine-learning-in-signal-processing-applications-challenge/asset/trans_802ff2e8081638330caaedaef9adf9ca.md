
`P(x, y) = P(y|x) ⋅ P(x)`

如果我们将两边相等并除以 `P(y)`，我们得到贝叶斯规则：

$$
P\left( x \middle| y \right) = \frac{\left. P(y \middle| x)~ \cdot ~P\left( x \right) \right.}{p\left( y \right)}
$$

(10.3)

**贝叶斯规则**：贝叶斯规则对统计学和机器学习的大部分内容至关重要。正如前面所暗示的，它是贝叶斯统计的驱动力。这个简单的规则使我们能够在从数据中收集更多观察结果时更新我们对数量的信念。我肯定会在后期的文章中更详细地讨论贝叶斯规则（和贝叶斯统计）[[19](#ch10.xhtml#r10_19)]。

### 10.2.2.3 独立性与条件独立性

在前面的例子中，我们看到 `P(x|y) ≠ P(x)` 因为观察到 `y` 给了我们关于 `x` 的信息。这总是如此吗？让我们想象 `P(x, y)` 是一个联合分布，其中 `x` 表示商店中的冰淇淋数量，而 `y` 表示月球每天被物体击中的次数。知道其中一个值会给我们关于另一个值的任何信息吗？当然不会！因此，在这种情况下，`P(x|y) = P(x)`！将它代入链式法则，我们发现在此场景中得到 `P(x, y) = P(x|y) ⋅ P(y) = P(x) ⋅ P(y)`。这直接引出了我们对 **独立性** 的定义。两个变量 `x` 和 `y` 如果 `P(x, y) = P(x) ⋅ P(y)` 则被称为独立。

一个类似的概念是 **条件独立性**。两个变量 `x` 和 `y` 在给定另一个变量 `z` 的情况下被称为条件独立，如果 `P(x, y|z) = P(x|z) ⋅ P(y|z)`。例如，`x` 是一个随机变量，表示是否下雨，而 `y` 是一个随机变量，表示室外道路是否湿润。它肯定可以表明这些事件彼此依赖。如果地面湿润就意味着肯定下过雨，如果下雨，地面就会变得湿润。现在变量 `z` 可以表示是否真的在室外下雨，并且肯定表明我的草地是湿的。因此，下雨的条件使我的下雨时间与草地是否湿润相互独立！

在表示巨大的联合分布时，独立性和条件独立性的概念相当重要。这里的独立性术语允许我们将分布分解为相对简单且不复杂的项，从而促进高效的内存利用以及快速计算。

这些数学概念在构建概率语言方面发挥作用，以便以概率的方式支持机器学习技术框架 [[22](#ch10.xhtml#r10_22)]。

## 10.3 机器学习的基本概念

机器学习基本上是一组算法，可以使系统通过经验自行学习。机器学习可以定义为人工智能（AI）的一个子集，主要侧重于基于样本数据进行模型构建，该样本数据被称为“训练数据”，可以在没有为该任务设计的任何程序的情况下支持预测或模型构建。机器学习概念的应用领域可以从电子邮件过滤到计算机视觉不等，在这些领域开发执行相同任务的传统程序在实质上是困难的或在技术上不可行的。机器学习的广阔领域包含一个称为计算统计的子集，主要关注使用基于统计的算法进行决策的过程。然而，这在任何情况下都不能反映所有机器学习都可以归类为机器学习 [[22](#ch10.xhtml#r10_22)]。

数学优化领域主要涉及方法和理论以及与机器学习领域相关的应用领域。数据挖掘可以定义为与通过无监督学习进行探索性数据分析等领域相关且更专注的领域。由于其在商业问题中的应用，机器学习也可以被描述为预测分析

各种机器学习方法如下：

* **监督学习**：监督学习的概念主要侧重于从标记数据中学习，即对于给定的输入 `X`，期望的输出 `Y` 可以被预测。
  监督学习的某些实际示例包括以下内容：
  * 识别图像中的各种组件。
  * 股票或公司相关特征的价格预测。
  * 文件中恶意行为的存在。
  * 患者的疾病诊断或识别。

* **给定场景中概率的作用**：`X` 到 `Y` 的映射可以通过各种方式执行。通过可能值 `Y` 的概率分布，即 `P(Y|X)`，我们在观察后获得一个新的样本 `X`。用于识别该分布的机器学习算法被称为 **判别算法** [[23](#ch10.xhtml#r10_23),[24](#ch10.xhtml#r10_24)]，例如，有人声称他看到了一种动物，它有毛皮和一条长尾巴，高两英寸。然而，我们无法在可能的动物中具体识别并猜测它是什么。
  `P(Y|X)` 可以作为一种替代技术尝试，其中概率分布是在带有标签的输入上进行的。进行它的特定算法被称为 **生成算法。** 考虑到老鼠的需求、它们的各种特征以及可能的值范围，例如，老鼠可能的身高、毛绒程度和尾巴长度的描述，是一种生成所有可能老鼠的方式。
  生成模型的概念可以在借助偏置规则的帮助下协助动物分类练习。偏置规则指出，`P(Y)` 的细节，即任何给定特定动物的概率，可以从给定的训练数据集中提取，其中 `P(X)` 可以定义为任何特定特征配置的概率。这些给定的术语可以通过贝叶斯规则以 `P(Y|X)` 的形式解释 [[25](#ch10.xhtml#r10_25)]。
  可以学习从 `X` 到 `Y` 的映射，该映射目前不是概率分布的形式。可以将确定性函数 `f` 与训练数据关联以给出 `f(X) ≈ Y` 作为输出。可以改进分布的标准肯定是采用概率模型，该模型可以量化不确定性度量，而任何给定的常规模型可能无法做到。例如，为疾病诊断设计的算法可能会做出判断，认为只需要一个月的寿命。在这种情况下，函数 `f` 可能无法表达对评估的置信度度量。算法在训练数据中从未见过的特征可能很少，这清楚地表明需要减少猜测来预测结果。在这里，概率模型 **量化不确定性**，而常规函数无法做到这一点 [[26](#ch10.xhtml#r10_26)]。
