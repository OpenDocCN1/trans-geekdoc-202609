
## 8.3 多分辨率分析
为了研究从小波系数重构函数以及 `WNN` 背后的思想，多分辨率分析 (`MRA`) 起着重要作用。`MRA` 在不同逼近水平或尺度上观察函数。将函数 *x*(*t*) 分解为不同尺度始于将其投影到足够高的分辨率子空间 **C**[*M*] 中，即

$$x\_{M} = \\sum\\limits\_{k}c\_{M,k}\\phi\\left( {2^{M}t - k} \\right) \\in \\mathbf{C}\_{M}$$

(8.13)

因此，子空间 **C**[∞] 是原始模拟（连续时间）信号 *x*(*t*) 的空间，而 *x*[*M*] ∈ **C**[*M*] ⊆ **C**[∞] 是其较低分辨率版本。每个层级的子空间 **C**[*j*] 本身由更粗的逼近子空间 **C**[*j* − 1] 和一个小波子空间 **W**[*j* − 1] 组成。由于子空间是嵌套的，我们可以写成

**C**[*M*] = **W**[*M* − 1] + **C**[*M* − 1]

$$= \\sum\\limits\_{i = 1}^{I}\\mathbf{W}\_{M - i} + \\mathbf{C}\_{M - I}$$

(8.14)

其中
1. *I* 是子空间或小波分解的层数。

对应子空间中的信号关系如下

$$x\_{M}\\left( t \\right) = \\sum\\limits\_{i = 1}^{I}y\_{M - i}\\left( t \\right) + x\_{M - I}\\left( t \\right)$$

(8.15)

其中
1. *x*[*M* − *I*](*t*) 是 *x*[*M*] 的最粗近似，且

$$x\_{j}\\left( t \\right) = \\sum\\limits\_{k}c\_{j,k}\\phi\\left( {2^{j}t - k} \\right) \\in \\mathbf{C}\_{j}$$

(8.16)

$$y\_{j}\\left( t \\right) = \\sum\\limits\_{k}w\_{j,k}\\psi\\left( {2^{j}t - k} \\right) \\in \\mathbf{W}\_{j}$$

(8.17)

### 8.3.2 小波神经网络
`WNN` 将小波和神经网络的原理结合为一体。由式 (8.15) 可知，任意函数都可以用来自小波和逼近子空间的基函数来逼近。这一思想导致了 `WNN` 的发展，其中尺度和位置因子被迭代调整以逼近目标函数。

`WNN` 的最简单形式仅由一个隐藏神经元组成，如 [图 8.3](#ch08.xhtml#f8_3) 所示。它由输入 *x*、平移 *τ* 并伸缩因子 *δ* 的小波函数组成。函数的输出为 *y*，计算如下：

![图 8.3 一个单一的 wavelon.](`images/Fig08_03.jpg`)

[**图 8.3**](#ch08.xhtml#f8_3b) 一个单一的 wavelon。

$$y = \\psi\_{\\delta,\\tau}\\left( x \\right) = \\psi\\left( \\frac{x - \\tau}{\\delta} \\right)$$

(8.18)

这种神经元的输出 *y* 只有当输入位于函数 *ψ*[*δ*, *τ*](*x*) 的支撑域内时才非零。若干个这样的单个“小波神经元”或“wavelon”构成 `WNN` 的隐藏层，其输出线性组合以逼近给定函数。

小波神经网络主要根据其架构分为两种类型。第一种基于关系式 (8.16)，其中给定函数仅使用尺度函数 *ϕ* 进行逼近。在这种 `WNN` 变体中，小波分析和神经网络操作是分开执行的（[Veitch 2005](#ch08.xhtml#r8_51)）。这类网络称为 *wavenet*，其中信号输入在隐藏层中使用不同的小波基进行分解，然后在输出层组合。在 wavenet 的架构中，平移和伸缩因子初始固定，在神经网络的学习过程中不发生变化。只有从隐藏层到输出节点的权重 *w*[*i*] 被修改。这种网络的输出为

$$y = \\sum\\limits\_{i = 1}^{N\_{\\phi}}w\_{i}\\phi\_{\\delta,\\tau}\\left( x \\right)$$

(8.19)

其中
1. *N*[*ϕ*] 是覆盖待分析函数定义域所需的隐藏层单元数，且 *ϕ*[*δ*, *τ*] 为尺度函数。

Wavenet 受其固定基函数集的限制，不适合建模具有时变响应的信道。在训练过程中，隐藏单元的平移和伸缩参数以及网络的输出权重也会被修改的小波网络架构。在普遍的命名法中，这类网络被称为 *wavelet networks*，并在本工作中予以考虑。在所有后续讨论中，我们将 `WNN` 仅指小波网络。[图 8.4](#ch08.xhtml#f8_4) 显示了一维 `WNN` 的架构。与下一节讨论的多维 `WNN` 相比，该网络的输入 *x* 为标量或一维序列。该网络中的 wavelon 显示为 *ψ*[1], …, *ψ*[*N*[*ψ*]]，其对应的平移参数值为 *τ*[1], …, *τ*[*N*[*ψ*]]，伸缩参数值为 *δ*[1], …, *δ*[*N*[*ψ*]]。输出 *y* 通过加权求和得到

![图 8.4 一维小波神经网络.](`images/Fig08_04.jpg`)

[**图 8.4**](#ch08.xhtml#f8_4b) 一维小波神经网络。

$$y = \\sum\\limits\_{i = 1}^{N\_{\\psi}}c\_{i}\\psi\_{i}\\left( x \\right) + a\_{0}$$

(8.20)

其中
1. *c*[1], …, *c*[*N*[*ψ*]] 为输出层权重。

式 (8.20) 中的项 *a*[0] 为偏置参数，且对于均值不为零的函数逼近是必需的。

## 8.4 多维小波神经网络
基于 [Alexandridis and Zapranis (2013)](#ch08.xhtml#r8_6) 中的 `WNN` 模型，构建了一个多维小波网络，其中不同输入与多个隐藏单元相互连接。隐藏单元 *ψ*[*j*](**x**) 的输出以及直接输入 *x*[*i*] 然后线性组合，以得到最终输出 *ŷ*。[图 8.5](#ch08.xhtml#f8_5) 显示了单隐藏层多维 `WNN` 的结构。对于具有 *N*[*I*] 个输入和 *N*[*ψ*] 个隐藏单元或 wavelon 的小波网络，输入-输出关系为

$$\\hat{y} = f\\left( \\mathbf{x} \\right) = \\sum\\limits\_{j = 1}^{N\_{\\psi}}c\_{j}\\psi\_{j}\\left( \\mathbf{x} \\right) + \\sum\\limits\_{i = 1}^{N\_{I}}a\_{i}x\_{i} + a\_{0}$$

(8.21)

其中
1. *c*[*j*] 为 wavelon 到输出的权重，
2. *a*[*i*] 为输入层到输出的权重，
3. *a*[0] 为输出层的偏置。

在式 (8.21) 的表达式中，*ψ*[*j*](**x**) 为多维小波，给出为

$$\\psi\_{j}\\left( \\mathbf{x} \\right) = \\prod\\limits\_{i = 1}^{N\_{I}}\\psi\\left( z\_{ij} \\right)$$

(8.22)

其中
1. *z*[*i**j*] = (*x*[*i*]−*τ*[*i**j*])/*δ*[*i**j*]。
2. 权重 *τ*[*i**j*] 对应平移，*δ*[*i**j*] 对应伸缩因子。

为了评估所提均衡器的性能，采用 Mexican hat 函数作为母小波，给出为

*ψ*(*z*) = (1−*z*²)*e*^( − *z*²/2)

(8.23)

考虑一个具有 *N*[*I*] 个输入和标量输出 *ŷ* 的 `WNN`，它使用一组 *N* 个示例 {**x**(*n*),*y*(*n*)} 进行训练，其中 **x**(*n*) = [*x*[1](*n*),…, *x*[*N*[*I*]](*n*)]^(*T*) 为训练示例 *n* 的输入向量。训练的目标是最小化均方误差 (MSE) *E*\[|*y*−*ŷ*|²\]，即目标输出 *y*(*n*) 与实际网络输出 *ŷ*(*n*) 之间的误差。`WNN` 可以表示为参数化非线性模型的形式（[图 8.5](#ch08.xhtml#f8_5)）：

*ŷ*(*n*) = *f*(**x**(*n*),**w**)

(8.24)

其中 `WNN` 的可调参数集合为 **w** = {*a*[0], *a*[*i*],*c*[*j*],*τ*[*i**j*],*δ*[*i**j*]}，其中 *i* = 1, …, *N*[*I*] 且 *j* = 1, …, *N*[*ψ*]。
