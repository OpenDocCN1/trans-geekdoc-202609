
# 神经网络与群智能在信道均衡中的应用

## 循环神经网络、储层计算与深度神经网络

最近关于循环神经网络（RNNs）的一些发展也促进了信道均衡研究。RNNs 是一种具有反馈的神经网络。它们通常用于建模动态系统，其中输出不仅取决于当前输入，还取决于之前的状态。尽管训练复杂度很高，RNN 仍能够优于 MLP 和 RBF 神经网络。文献中提出了几种基于 RNN 的计算高效均衡器设计（[Zhao 等 2011](#ch08.xhtml#r8_58)；[Li 等 2017](#ch08.xhtml#r8_23)）。[Li 等 (2017)](#ch08.xhtml#r8_23) 利用卷积神经网络的平移不变性来学习匹配滤波器。学习到的匹配滤波器随后被输入到具有长短期记忆（LSTM）记忆单元的 RNN 中，用于信道的时序建模。总体而言，RNN 的流行训练方法计算成本高昂，且通常收敛速度极慢。储层计算（RC）技术常被提议作为 RNN 的替代方案。[Mosleh 等 (2017)](#ch08.xhtml#r8_36) 提出了一种基于回声状态网络（ESN）的 MIMO-OFDM 均衡与检测技术。ESN 神经网络属于储层计算技术的大类，其训练无需 RNN 的复杂性。在 [Bauduin 等 (2015)](#ch08.xhtml#r8_9) 和 [Majumder](#ch08.xhtml#r8_29) (2020a) 的研究中，ESN 被应用于非线性卫星和无线通信信道的均衡。深度神经网络（DNNs）也在信道均衡领域得到越来越多的应用。通常，DNNs 是具有大量隐藏层的神经网络，具有特征学习能力。在 [Ye 等 (2017)](#ch08.xhtml#r8_56) 中，DNN 用于 OFDM 网络的信道估计和信号检测。在 ([Caciularu 和 Burshtein 2020](#ch08.xhtml#r8_11)) 中提出了一种基于变分自编码器的盲信道均衡器和解码器，其中作者考虑了通过 ISI 信道传输的符号的检测。他们证明了与现有技术（如恒模算法（CMA）均衡器）相比，误码率有显著且稳定的改善。在 [Aboutaleb 等 (2020)](#ch08.xhtml#r8_3) 的研究中，提出了一种基于 DNN 的均衡器，用于多层磁记录的均衡和检测。在这项工作中，卷积神经网络被用于均衡和分离信号。最后，检测由多层磁记录 Viterbi 检测算法执行。

## 小波神经网络

小波神经网络（WNN）是时间序列分析中的重要工具。与 RBF 神经网络类似，它们是一个单隐藏层网络，由多个神经元组成，这些神经元在线性叠加到输出节点。但与 RBF 神经网络不同，WNN 隐藏层中的神经元利用小波函数进行激活（[Yang 和 Hu 2016](#ch08.xhtml#r8_53)）。尽管人工神经网络（ANNs）可用于建模任何非线性动态系统，经典的 Sigmoid 网络存在一系列缺点。使用 Sigmoid 激活函数，训练算法收敛到局部最小值的可能性很大。此外，传统神经网络中随机的权重初始化会导致训练时间延长。WNN 允许对网络参数进行高效初始化的构造性程序，从而减少训练时间（[Alexandridis 和 Zapranis 2013](#ch08.xhtml#r8_6)）。WNN 已被用于多种预测应用，如负荷预测（[Ribeiro 等 2019](#ch08.xhtml#r8_45)）、风速预测（[Zhang 等 2019](#ch08.xhtml#r8_57)）、分布式协作学习（[Xie 等 2019](#ch08.xhtml#r8_52)）和信道均衡（[Majumder 2020b](#ch08.xhtml#r8_30)；[Majumder 和 Giri 2020](#ch08.xhtml#r8_31)）。Pradhan 等提出了第一个用于线性与非线性信道 WNN 均衡的算法之一（[Pradhan 等 2006](#ch08.xhtml#r8_44)）。他们提出了一种使用基于扩展卡尔曼滤波的递归算法训练 WNN 的方案，并证明了其优于 MLP 和 RBF 神经网络。最近，Nanda 等开发了基于 WNN 的均衡器，该 WNN 由共生有机体搜索（SOS）算法训练（[Nanda 和 Jonwal 2017](#ch08.xhtml#r8_37)）。他们优化了 WNN 的输出权重以实现期望性能，同时保持平移和伸缩参数不变。

## 群智能与优化

近年来，群智能算法在各个领域的求解问题中受到了广泛关注（[Nayyar 等 2018](#ch08.xhtml#r8_39)；[Nayyar 和 Nguyen 2018](#ch08.xhtml#r8_40)）。群智能是指人工智能的一个领域，其中通过借鉴自然界中动物或昆虫的集体行为来设计智能多智能体系统以解决问题的领域（[Beni 2020](#ch08.xhtml#r8_10)）。在 [Lipa 等 (2015)](#ch08.xhtml#r8_25) 的研究中，为认知无线电网络提出了一种仿生时间同步协议。该协议受到了萤火虫同步现象的启发，萤火虫似乎会一起发光或变暗。该算法允许认知无线电节点以去中心化的方式同步。Sutantyo 和 Levi 提出了一种受萤火虫和青蛙启发的算法，用于促进机器人群内的调度（[Sutantyo 和 Levi 2015](#ch08.xhtml#r8_50)）。他们通过仿真和实验表明，所提出的基于群的模型对水下群机器人来说是稳健且可行的。群智能被应用于风能潜力和风速预测的研究中 [Zhao 等 (2019)](#ch08.xhtml#r8_60)，这对风电场管理有益。

### 基于群的优化算法

近年来提出了各种基于群智能的优化算法。蚁群优化和粒子群优化是此类优化算法的最佳示例，且非常流行（[Mavrovouniotis 等 2017](#ch08.xhtml#r8_33)）。受蚱蜢群行为的启发，提出了一种名为蚱蜢搜索优化（GOA）的优化算法，用于寻找桁架杆和悬臂梁的最佳形状（[Saremi 等 2017](#ch08.xhtml#r8_48)）。Mirjalili 等基于水母在海洋中移动和觅食时的群集行为，提出了一种名为水母群优化（SSA）的优化算法（[Mirjalili 等 2017](#ch08.xhtml#r8_35)）。除了群智能算法外，另一类受自然启发的算法是进化算法。与其说是群行为，它们的能力来源于进化理论以及物种如何在多代中发展。此类优化算法包括遗传算法（[Mirjalili 2019](#ch08.xhtml#r8_34)）、差分进化（DE）（[Opara 和 Arabas 2019](#ch08.xhtml#r8_41)）和基于生物地理学的优化（BBO）（[Ma 等 2017](#ch08.xhtml#r8_28)）。
