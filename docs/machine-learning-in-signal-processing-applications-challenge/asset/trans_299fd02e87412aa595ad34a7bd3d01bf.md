
频谱和倒谱是音频信号处理的两个重要属性。从数学上讲，音频信号的频谱是通过计算其傅里叶变换得到的，傅里叶变换将时域信号转换为频域信号。换句话说，利用频谱，音频信号在频域中表示。为了形成倒谱，首先计算频谱的对数幅度，然后计算该对数幅度的逆傅里叶变换。这是一个既不在时域也不在频域的信号。创建音频信号的频谱和倒谱的步骤如图 [图 4.2](#ch04.xhtml#f4_2) 所示。

考虑音频信号频率的基本原因与耳朵听觉过程的生物学相关。耳蜗是人耳的一部分，充满液体，内部含有数千根与神经相连的微小毛发。这些毛发的长度各不相同，长度较短的毛发与较高频率共振，而长度较长的毛发与较低频率共振。空气压力的时域信号被转换为频率频谱，然后由大脑处理。这样，人耳可以被视为一种天然的傅里叶变换分析仪。

### 4.2.1.2 梅尔频率倒谱系数

人类听觉的一个事实是，如果声音频率超过 1 kHz，人耳对频率的选择性会降低。这与梅尔滤波器组相似。梅尔倒谱可以通过将频谱输入梅尔滤波器组，然后对结果取对数幅度并进行离散余弦变换（DCT）来产生。该过程在 [图 4.3](#ch04.xhtml#f4_3) 中演示。DCT 获取了音频摘要的重要信息和峰值。通常，MFCC 是从梅尔倒谱中获得的前十三个系数。MFCC 包含有关音频信号的宝贵信息，因此它们被用于训练机器学习模型。

### 4.2.1.4 构建分类器

构建分类器时，可以利用 GFCC 和 MFCC 的特殊特征，此外，还可以使用 GFCC 和 MFCC 的组合。第一步是将输入音频信号分类到不同的类别中。例如，系统可能会将输入音频分类为音乐、语音、动物等。在下一步中，使用数据集且不进行任何微调，我们可以估计该分类模型检测音频类别的能力。然后，可以应用 GFCC 和 MFCC 等特殊特征进行适当的流派分类。一些流派可能正确，而一些则有改进的可能性。为了进行适当的流派分类，必须考虑以下几点。

* 检查数据质量以确保其足以进行分类。其他特征包括转录或文本。是否最好使用不同的分类器？
* 是否已研究使用神经网络进行分类？

这些特征肯定能从输入音频信号中获取重要信息，机器可以利用这些特征更好地学习并提取有关音频信号的适当信息。

## 4.3 音频压缩

音频压缩是数据压缩的一个非常重要的子领域。在计算机系统上存储音频需要大量内存，因此音频必须在保存在计算机系统上之前进行压缩。此外，由于音频压缩，手机能够以更好的语音进行通信。音频压缩方法在计算机软件中作为音频编解码器实现。音频压缩的应用包括数字电视、电影、DVD 等。最优音频压缩算法可分为有损算法和无损算法。有损压缩算法具有相对更高的压缩率，通常用于压缩实时音频。有损压缩和无损压缩的主要目标都是使用模式识别、编码和预测等不同技术来减少冗余。

### 4.3.1 建模和编码

压缩算法开发的两个主要构建块是建模和编码。在建模阶段，数据中存在的冗余信息使用模型表示。在编码阶段，使用二进制符号对模型的描述进行编码。编码可以以有损格式或无损格式进行。无损格式的编码用于保留媒体源的原始质量。使用其他无损格式进行后续编码可能会导致轻微的退化。

### 4.3.2 无损压缩

几乎所有无损压缩算法所考虑的方法在 [图 4.5](#ch04.xhtml#f4_5) 中有所说明。在第一步中，使用某种“预测算法”进行信号近似。“预测算法”的参数被选择以产生与输入波相似的波形。然而，尽可能使用最少的位数来表示真实信号与预测波形之间的差异。为了创建样本的正确值，将预测信号加到误差信号上。为了预测后续样本，预测算法会再次基于过去样本和新的预测样本执行 [[4](#ch04.xhtml#r4_4)]。在信号近似中，信号被分解为高斯函数，这些函数被归一化并线性组合。这倾向于将信号聚焦到更小的维度，因为带宽和采样步长是数据自适应的。这种方法在音频信号处理和许多其他信号处理应用中可能很有用。为了实现标准化、安全、减少空间、速度和保密，使用近似编码器。近似编码器是电路、设备、软件、算法、换能器或人，它将以一种格式或代码表示的信息转换为另一种格式。音频压缩中的错误意味着未知的格式或不受支持的编解码器已被表示。错误编码器将信号近似与输入信号的相加作为输入，然后从错误编码器的输出可以得出编解码器是否受支持。错误数组打包和近似数组打包的组合结果产生压缩信号。
