在这种学习中，学习算法未指定标签，使其能够独立地在输入中发现结构。无监督学习本身就是一个目标，通过揭示数据中的隐藏模式，或作为通往最终目标——特征学习的一种手段 [[2](#ch03.xhtml#r3_2)]。

## 3.2 监督学习方法

应用机器学习实践的主流是监督学习。算法用于研究从输入到输出的映射函数，其中 `x` 为输入变量，`Y` 为输出变量，如公式 3.1 所示。这里学习者被赋予标记的输入数据。数据包含输入对和输出对的序列。学习者的意图是了解从输入数据到输出数据的映射过程。如果输出数据是离散数据，则函数 `Y` 被称为分类器；如果输出数据是连续的，则为回归函数。

`Y = f(x)`

(3.1)

目标是通过输入数据 (`x`) 来估计映射函数，以预测这些数据的输出变量 (`Y`)。监督方法也被称为监督学习的原因是，在数据集训练后，算法学习过程模仿了监督学习方法的一位教师。学习在算法达到可接受的性能水平时停止 [[4](#ch03.xhtml#r3_4), [5](#ch03.xhtml#r3_5) 和 [6](#ch03.xhtml#r3_6)]。

每个监督机器算法都以预先定义好的标签集 `C` 为中心，训练集 `T` 由分配了一个或多个来自 `C` 的标签的文章组成。算法使用 `C` 和 `T` 来训练模型，并将模型应用于对未标记文章进行分类。

在模型中，对训练集 `T` 进行处理并根据分类法 `C` 构建分类模型。该方法包括三个阶段，将作者、关键词和期刊与 `C` 中的一个或多个标签相关联。记录的多个频率值随后被分类算法用于有效控制未分类论文的标签。研究文章的主流包含置于摘要和引言之间的一组关键词。因此，标题中出现的词语也被视为文档信息的代表，可用于训练模型。

考虑训练集 `T` 中属于 `P` 的论文 `p`，其包含关键词 `K[p]`，并被标记为属于 `C` 的一个或多个研究领域 `C[p]`。目标是建立 `p` 的每个关键词与研究领域 `C[p]` 之间的相关性。由于关键词 `k` 可能出现在属于不同研究领域的众多论文中，因此引入了类似于 `k-NN` 算法的算法。这是通过构建 (`k`, `c`) 对获得的，我们将其存储在显著性解释向量 `K` 中。通过计算两个频率值 `|P[k]|` 和 `|P[k][, c]|`，前者表示包含关键词 `k` 的论文数量，而后者表示包含 `k` 并被映射到领域 `c` 的论文数量。该算法展示了训练 `K` 的重要步骤。对于训练集中的每篇论文 `p`，识别所有研究领域 `C[p]` 和关键词 `K[p]` 是一项更大的任务。为属于 `C[p]` 的每个研究领域 `c` 创建 (`k`, `c`) 对 [[7](#ch03.xhtml#r3_7), [8](#ch03.xhtml#r3_8), [9](#ch03.xhtml#r3_9) 和 [10](#ch03.xhtml#r3_10)]。文章分类中模型训练的算法如下所示：

```
1. Initialize K, A, J
2. for each paper p ∈ T
3. C^P ← ExtractResearchAreas(p)
4. Phase 1: Processing of the keywords
5. K^P ← ExtractKeywords (p)
6. for each keyword k ∈ K^P
7. |P^k|←|P^k|+1
8. for each research area c ∈ C^P
9. Create pair (k, c)
10. if K.search (k, c) =false
11. K.insert(k, c)
12. |P k, c|←1
13. else
14. |P^( k,c)|←|P^( k,c)|+1
15. Phase 2: Processing of the authors
16. AP ← ExtractAuthors (p)
17. for each author a ∈ A^p
18. |P^a|←|P^a|+1
19. for each research area
20. c ∈ C^p
21. Create pair (a, c)
22. if A.AP.search(a, c) = false
23. A.AP.insert (a, c)
24. |P^(a,c)[AP]|← 1
25. else
26. |P^(a,c)[AP]|← |P^(a,c)[AP]|+ 1
27. for each author a⁰ ∈ A^p
28. Create tuple (a, a⁰, c)
29. If A.AA.search (a, a⁰, c) = false
30. A.AA.insert(a, a⁰, c)
31. |P^(a,c)[AA]|← 1 else
32. |P^(a,c)[AA]|← |P^(a,c)| + 1
33. Phase 3: Processing of the journals
34. J ← Extract Journal (p)
35. |P^j|← |P^j| + 1
36. for each research area c ∈ C^p
37. Create pair (j, c)
38. if Search(j, c) =false
39. J .insert (j, c)
40. |P^j^(,c)|← 1
41. Else
42. |P^j^(,c)|← |P^j^(,c)| +1
```
