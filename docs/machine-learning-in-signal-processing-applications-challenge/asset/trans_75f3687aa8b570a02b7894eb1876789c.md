在全连接层之前可以有多个交错的卷积层和池化层。卷积层对输入特征图序列和卷积矩阵执行卷积操作以获得高层特征。池化层提取主导特征并负责降维。池化层以一系列特征图作为输入，并输出一系列维度更低的特征图。池化层使用的两种池化类型是最大池化和平均池化 [[15](#ch12.xhtml#r12_15)]。最大池化会丢弃信号中的噪声，通常比平均池化更好。

全连接层学习卷积层和池化层的高层特征的非线性组合。一般来说，全连接层使用多层感知机（MLP）实现。原始时间序列在经过多次卷积和池化操作后被转换为一系列特征图。特征图被展平成列向量，作为多层感知机的输入。MLP 的输出具有与时间序列可能类别数相等的神经元数量。[图 12.2](#ch12.xhtml#f12_2) 说明了用于 TSC 的具有三个卷积层的卷积网络架构。

## Inception 时间
Inception 网络是一个深度卷积网络。在 Inception 网络中，卷积层和池化层被 Inception 模块取代。CNN 中的 Inception 模块通过堆叠的 1 × 1 卷积进行降维，从而更高效地执行更多计算。它解决了计算开销、过拟合和其他问题。Inception 模块通过多个不同大小的核滤波器并行学习同一输入数据，而不是顺序堆叠。例如，Inception 并行执行 1 × 1、3 × 3 和 5 × 5 以及更多卷积变换和一些池化。然后它将所有变换的输出堆叠起来，并允许模型从中选择信息。

Inception 模块由四层组成。第一层降低输入数据的维度，从而减少计算成本和特征数量。它还加快了训练过程。第二层是不同大小的并行卷积层集合，例如 1 × 1、3 × 3、5 × 5 等，它们作用于同一输入特征图。第三层是最大池化层。最后，最后一层是拼接层，它将并行卷积和最大池化的输出拼接起来，形成 Inception 模块的输出多变量时间序列。

## 回声状态网络（ESN）
它是一种 RNN。通常，RNN 在 TSC 中很少使用。通过消除对隐藏层梯度测量的需求、减少训练时间并避免梯度消失问题，ESN 被设计用于缓解 RNN 的问题 [[16](#ch12.xhtml#r12_16)]。隐藏层构成一个水库并随机初始化 [[17](#ch12.xhtml#r12_17)]。水库中的每个神经元为输入序列创建其非线性激活函数。水库中的互连权重和输入权重不进行训练。水库的输出由诸如逻辑回归或岭分类器之类的学习算法准备。RNN 基于 ESN 并加快训练过程，因为它们关系非常稀疏，大多数权重先验设置为随机选择的值 [[18](#ch12.xhtml#r12_18)]。经过快速准备后，它们显示出令人印象深刻的结果。此外，它们有利于处理混沌时间序列。

ESN 的基本方程如下所示，方程 (12.5) 和 (12.6)：

```
s(n+1) = f(W^(in)·i(n+1)+W·s(n)·W^(back)·o(n))
```
(12.5)

```
o(n+1) = f^(out)(W^(out)·i(n+1), s(n), o(n))
```
(12.6)

其中
1. `i(n)`、`s(n)` 和 `o(n)` 分别是 ESN 的输入向量、状态向量和输出向量。
2. 项 `f` 和 `f^(out)` 分别是水库处理单元内部神经元和输出单元的激活函数。

[图 12.3](#ch12.xhtml#f12_3) 说明了 ESN。

`R[w]^(in)` 表示输入权重连接矩阵。连接矩阵连接输入层和水库。`R[w]` 在 [图 12.3](#ch12.xhtml#f12_3) 中表示连接水库和内部神经元的内部权重连接矩阵；`R[w]^(back)` 表示输出层之间的反馈权重连接矩阵。`R[w]^(out)` 表示连接水库和输出层的输出权重连接矩阵，这是唯一需要训练的关键参数。

## 12.4 Morlet、墨西哥帽、频率 B 样条小波在 ECG 信号分类中的比较
在基于物联网的医疗保健系统最近的进步中，心电图在心脏病诊断中发挥着重要作用。物联网生物传感器用于记录这些 ECG 信号 [[19](#ch12.xhtml#r12_19), [20](#ch12.xhtml#r12_20) 和 [21](#ch12.xhtml#r12_21)]。ECG 信号以电活动形式捕捉心脏状况并传达心脏功能的不同病理数据。医务人员根据 ECG 电信号的特征判断心脏功能状态。然而，这种单纯依靠肉眼的诊断并非适用于每位患者。患者数量、时间有限和大量数据等因素增加了医生高效工作的复杂性。因此，物联网传感器设备、人工智能和自动计算机辅助诊断系统对于基于 ECG 的心脏病诊断是必需的。

在本研究中，来自 MIT-BIH 心律失常实验室 Physionet 数据库的心律失常数据被用于实验目的。该数据库包含 45 名受试者的 48 条 ECG 信号记录，其中 19 名女性年龄在 23–89 岁之间，26 名男性年龄在 32–89 岁之间。总的来说，MIT-BIH 心律失常数据集包含 13,724 次心跳。数据库中附带有一个注释文件，用于标记每个信号记录的复杂性和心跳类型 [[22](#ch12.xhtml#r12_22),[23](#ch12.xhtml#r12_23)]。

ECG 信号的分类涉及区分心律失常（ARR）、充血性心力衰竭（CHF）和正常窦性心律（NSR）心脏功能障碍 [[24](#ch12.xhtml#r12_24),[25](#ch12.xhtml#r12_25)]。心律失常代表在心脏窦房结检测到的不适当电活动。充血性心力衰竭是由于心脏泵血效率低下而发生的 [[13](#ch12.xhtml#r12_13)]。在这些情况下，由于 CHF，血液会在腿、手、肝脏和肺等器官中积聚。正常窦性心律是由于窦房结刺激的退出并扩散到左心室而发生的。由于 NSR 心脏疾病异常的 ECG 信号特征如下所示 [表 12.1](#ch12.xhtml#t12_1)。
