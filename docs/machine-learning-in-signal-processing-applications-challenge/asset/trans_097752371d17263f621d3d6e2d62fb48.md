
检测嵌入在图像中的物体的位置是一个必须执行的重要方面。物体的位置可使用基于区域的 CNN（`RCNN`）轻松检测。如今 `RCNN` 已发展为 `Mask RCNN`，其能够实现达到人类水平的图像认知。

## 4.5 视频压缩

在当前计算世界中，视频在传输实时信息方面发挥着重要作用。随着社交媒体的日益普及，巨大的视频内容在网络上生成并共享。此外，在监控和安全方面，视频发挥着至关重要的作用，因为高分辨率和低空间占用是此类实时信息传输的优先事项。视频分辨率与所需内存之间存在权衡，因此需要视频压缩。

### 4.5.1 视频压缩模型

典型的视频压缩模型有两个主要组成部分；首先是视频编码器，另一个是视频解码器。视频编码器负责将视频帧转换为一串比特。在接收端，这一串比特由视频解码器解码以重建视频帧。典型视频压缩模型的框图如图 [图 4.8](#ch04.xhtml#f4_8) 所示。视频编码器的功能分为预测器、变换编码和编码器。另一方面，解码器的功能分为逆变换编码和解码器。预测器识别视频帧中存在的不同冗余元素。在识别冗余之后，通过应用合适的变换编码获得变换系数。最后，编码器消除表示不同冗余的系数。解码器解码传入的视频流并获得压缩视频帧的变换系数。完成此操作后，在接收端应用逆变换编码以获得压缩并重建的视频帧 \[[11](#ch04.xhtml#r4_11)\]。

### 4.5.2 视频压缩中的机器学习

机器学习算法现已应用于基于人工智能的视频压缩系统。研究人员和专业人士也开始使用深度学习方法来改进基于人工智能的视频压缩。在视频编码和视频压缩过程中，使用监督算法。在机器学习中，监督学习充当一个函数，用于将输入映射到输出。在现代视频压缩工具中，已包含实现人工智能属性和特征的函数。这些解决方案利用机器学习算法和技术，倾向于自动化视频内容的格式化和压缩。此外，基于机器学习的视频压缩方法能够在上传视频内容期间执行压缩 \[[12](#ch04.xhtml#r4_12)\]。这些方法还能够在用户下载之前在上传时压缩视频。与传统视频压缩方法相比，视频压缩的机器学习方法通过自动化任务和流程节省了大量时间、技能和精力。应用机器学习于视频压缩的两个重要好处如下列出。

#### 4.5.2.1 开发节省

视频压缩和视频编解码器是两个不同的领域。视频编解码器的算法相当复杂，其开发可能需要大量时间和精力。基于机器学习方法的软件减少了工作量和时间，因为在这种情况下，系统能够自行学习以适应自身，且几乎不需要或不需要人工干预。

#### 4.5.2.2 提高编码器密度

许多机器学习算法在图形处理单元（`GPU`）中执行，而其他算法在中央处理单元（`CPU`）中执行。`GPU` 中的逻辑核心数量少于 `CPU`，这使得系统能够并发执行简单计算。

`Autoencoders` 也在视频压缩中变得流行。`Autoencoders` 是人工神经网络（`ANNs`），它们经过训练以学习压缩输入，但可以在没有任何监督的情况下执行重建。

## 4.6 数字通信

数字通信已成为日常生活中极其重要的组成部分。当一台计算机与另一台计算机交互而不论其位置和距离时，通信本质上是数字的。随着蜂窝用户数量的快速增长以及 `IoT` 的演进，数字通信的作用变得更加关键。除了在设备之间传输包括视频、图片和音频在内的模拟数据外，数字通信的另一个重要应用是在光学和磁性介质上存储大量数据。数字通信系统的元素如图 [图 4.9](#ch04.xhtml#f4_9) 所示。源通常生成消息，该消息首先传递到发送端的换能器，将其转换为电信号，然后进行模数转换 \[[13](#ch04.xhtml#r4_13)\]。源编码器消除冗余位并压缩数字信号。信道编码器在数字信号中添加一些额外的位以进行错误检测和纠正。然后数字调制器将数字信号再次转换回模拟信号，以便可以通过通信信道传输。

![图 4.9 数字通信的元素.](images/Fig04_09.jpg)

[**图 4.9**](#ch04.xhtml#f4_9b) 数字通信的元素。

在接收端，从信道接收到的信号被解调并转换为数字信号。信道解码器解码数字序列并检查是否存在潜在错误。如果序列有误，则信道解码器通过添加冗余位来纠正 \[[14](#ch04.xhtml#r4_14)\]。源解码器通过执行采样和量化来重建数字信号。输出换能器将数字信号转换回原始消息。
