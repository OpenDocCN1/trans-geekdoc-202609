
机器学习的一个非常重要的应用是在早期药物发现的过程中。机器学习工具可应用于药物开发过程的各个阶段，包括药物识别、药物验证、药物再利用、提高药物疗效以及分析生物医学信息。精准医学和下一代测序在探索药物发现的替代途径方面可以发挥有效作用。

### 4.6.2.7 Outbreak Prediction
基于人工智能（AI）的技术现正被用于监测情况并预测即将到来的流行病。在来自不同来源的大量数据的帮助下，如实时社交媒体数据、网络数据、卫星信息等，人工神经网络能够预测各种类型的爆发，如疟疾、登革热和其他高度传染性疾病。这种疫情预测对于医疗基础设施不足且不完善的发展中国家来说非常重要。

## 4.6.3 Seismology
地震学是学习和科学研究地震波在地球内部和周围传播的领域。地震波是在地球内部岩石突然破裂或发生爆炸时产生的能量波。当地球内部能量水平发生变化时，这些波会被地震仪记录下来。地震学是一个重要的研究领域，因为地震波和地震会产生其他环境副作用，如海啸、火山喷发、海洋风暴、地壳构造过程等。其中许多副作用对人类来说是致命的。

### 4.6.3.1 Interpreting Seismic Observations
地震观测是使用一种明确的方法进行解释的，如[图 4.11](#ch04.xhtml#f4_11)所示。理解地震波的第一个阶段是对记录的分析，其中信号在噪声背景中被检测到。然后，测量信号的各种参数，如振幅、表观周期、极化以及到达时间，随后进行特定形式的初步波形识别。第二阶段是对震源的分析，其目的是获取震中、机制、震级、能量、震源深度和震源尺寸等震源参数[[24](#ch04.xhtml#r4_24)]。在这些震源参数的帮助下，最终完成波形的识别。在第三阶段，构建基本规律，包括地震波运动学、地震波动力学以及地震活动性中的统计关系。第四阶段也是最后阶段，对地球结构、地震物理学和震源识别做出地震学结论。爆炸探测也在此阶段进行。

### 4.6.3.2 Machine Learning in Seismology
地震学家现在利用机器学习算法，结合高计算能力的机器、庞大的地震数据集和架构来预测即将发生的地震事件。此外，基于机器学习的方法也可用于保存过去地震的模拟记录。研究人员还使用深度神经网络来学习现有过去地震数据与预测结果之间的复杂关系。由于存储大量数据的介质通常会退化，地震学家正努力保护这些关键信息。能够识别图像的机器学习方法也是以经济有效的方式保存地震数据的潜在候选方案。一些研究人员使用机器学习检查地震数据以识别火山活动和地震余震，并监测标志着板块边界处变形构造震动[[25](#ch04.xhtml#r4_25)]。也有一些基于机器学习的少量研究正在进行，以定位地震起源并将低强度地震与周围存在的地震噪声区分开来。机器学习的技巧，如深度学习和 CNN，也可应用于[图 4.11](#ch04.xhtml#f4_11)中强调的地震观测的不同阶段。它们可用于高效、快速地分析记录、分析震源、构建规则并得出重要结论。

## 4.6.4 Speech Recognition
语音识别是计算语言学和计算机科学的综合领域，旨在设计和开发能够使用数字计算机将口语识别并翻译成文本形式的方法和技术。语音识别背后的两个基本要素是声学建模和语言建模。语音和音频的语言成分关系由声学建模表示，而语言建模用于将词语序列与声音匹配以区分发音相似的词语。为了提高语音识别系统的准确性，通常使用隐马尔可夫模型来识别语音中的时间模式[[26](#ch04.xhtml#r4_26)]。另一方面，自然语言处理（NLP）以简便且高效的方式执行语音识别。一般的语音识别系统如图[图 4.12](#ch04.xhtml#f4_12)所示。

信号、声学和语言是语音识别的三个重要组成部分。在信号层级，首先提取不同的语音片段，然后通过 MFCC 或深度学习进行特征提取。在声学层级，声音分类使用机器学习方法进行。在声学层级还会收集额外的上下文信息。在语言层级，声音被翻译成词语，词语组合成句子，并使用深度学习方法生成模型。机器学习方法利用句子结构、语法和句法以及语音和音频信号的对齐来处理语音。基于机器学习的软件会持续学习，随着使用量的增加，学习也会增加，由于这种改进的学习，理解口音等基本要素会变得更容易。
