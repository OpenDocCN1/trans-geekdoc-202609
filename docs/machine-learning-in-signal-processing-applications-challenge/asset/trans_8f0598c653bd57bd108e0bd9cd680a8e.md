
## 11.10.4 支持向量机

SVM 是允许在数据集之间找到一个或多个边界的分类算法 \[[29](#ch11.xhtml#r11_29)\]。对于所谓的线性可分数据，它们可能很简单，但对于不可分数据，有时可能非常复杂。但使它们强大的原因是，无论是哪种情况，它们总能对其进行分类。事实上，它们的力量基于一种被称为核技巧的强大哲学。而且必须说，这确实是一个技巧。它们由 Vapnik 在 1998 年左右学习理论统计的工作中开发。

### 11.10.4.1 工作原理

原则是找到分离给定对象的最优方案。但首先要记住的是先进行我们所说的学习。后者将使我们能够提出一个模型，该模型稍后能够对新对象做出决策。为此，我们必须在进行学习过程之前对学习数据进行标记。否则，就像接近两个相反极性的磁铁一样。当数据不是线性时，我们使用所谓的核函数。它在于找到问题的对偶解，以找到原问题的解。因此，我们使用多个核来决定哪一个能提供最佳方案以实现最佳分离。因此，有两个重要参数可以帮助找到该最优方案。

这些是 `C` (`BoxConstraint`) 和 `gamma` (`KernelScale`)。本工作中使用的核是：
* 多项式核
* 高斯核
* 线性核。

使用的求解算法有：
* `SMO` 算法
* `ISDA` 算法
* `L1QP` 算法

## 11.10.5 K-最近邻 (K-NN)

`K-Nearest Neighbors` 其缩写为 `K-NN` 是开发分类模型最简单的分类技术之一。由于其简单的哲学，它有时被认为是一种惰性算法，根据该算法，对象的类别是这些最近（距离概念）邻居的所属类别。简而言之，思想是根据这些邻居的类别给出样本的类别。这意味着如果您有一批中的对象并且想要对其进行分类，您必须找到这些邻居的类别并衡量它们彼此之间的接近程度。示例：假设任何具有四条边的几何图形都是四边形。那么，让我们取另一个不具有相同特征的图形。那么很容易说这不是四边形。这意味着具有相同输入值（或特征参数）的样本似乎属于同一类。换句话说，具有相同特征的样本应归为同一类。表达式随着最近邻的接近而变得更加明显。因为一切都在于此。确实，该表达式的量化明确决定了新样本的类别。因此，有了著名的 `K-NN` 中的 `K`。如果我们有合适的 `K`，我们将对任何分类序列做出良好的分类。否则，如果作为 `K` 函数的模型不理想，从长远来看，会出现分类结果与现实不符的情况。我们称之为坏模型。这使我们能够宣布以下内容：最好的 `K-NN` 算法是从数据云中找出最佳邻居数量的算法，以便能够在任何时刻完全正确地区分每个对象的归属。在结果部分，您将看到该方法如何用于识别旋转机器中轴承的故障或健康状况。 [图 11.23](#ch11.xhtml#f11_23) 显示了 `K-NN` 的示意图。

## 11.10.6 极限学习机

`ELM` 是一种新型的单隐层神经网络型学习算法，与传统的流行学习算法不同。除了具有单隐层之外，`ELM` 不使用学习机器或机器学习中使用的学习规则，后者使用反向传播的概念来调整突触权重，并且在计算时间方面成本很高。这使其在执行时间方面比其前身快 1,000 倍。更重要的是，其在最新研究中的应用已证明其在学习泛化方面具有良好的性能。而这对于迄今为止已知的神经网络来说并非如此。

### 11.10.6.1 原理或算法

它按如下方式工作 \[[30](#ch11.xhtml#r11_30)\]：
1. 隐层输入权重 (`W[i]`) 和偏置的随机分配
2. 隐层输出矩阵的计算
3. 输出权重 `β` 的计算

其中

`β = H^(ϕ) T`

(11.26)

其中

`H^(ϕ) = (H^(t) H)^(-1) H^(t)`

(11.27)

是 Moore-Penrose 逆矩阵，而 `T` 为输出向量。

`T = [t[1], t[2], …, t[0]]^T`

(11.28)
