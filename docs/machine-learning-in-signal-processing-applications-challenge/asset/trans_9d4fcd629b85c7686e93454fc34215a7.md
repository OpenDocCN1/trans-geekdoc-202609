
常见研究针对时隙耐久性的解决方案是使用单次测试，该测试用于提高信噪比 \[[100](#ch06.xhtml#r6_100)\]，与多试验评估形成对比，并将分阶段训练放在后续的 `BCI` 设备附加组件上处理。众多自适应和零训练的分类器作为解决方案被评估，见参考文献 \[[95](#ch06.xhtml#r6_95)\]。

## 信息传输率
对于指令 `BCI` 系统，广泛使用的测量指标是比特。有两个选择，正确目标和交付的平均时间。因此，选择性注意策略获得的 `ITR` 比想象 `BCI` 更好，因为它们的交付选择更广泛。

### 6.7.2 技术问题
在技术挑战中，存在一些问题，如非线性、噪声、非平稳性、训练单元和组织规模

#### 非线性
在人类中，大脑是一个特别复杂的非线性系统，其中神经元集合可以表现出混沌行为。因此，非线性动态技术比线性技术更能更好地描述 `EEG` 信号。

#### 非平稳性和噪声
非平稳性由于趋势、周期和随机游走而难以预测。设计一个 `BCI` 机器的主要问题是非电生理脑信号的非平稳功能 \[[102](#ch06.xhtml#r6_102)\]。这导致信号随时间在记录组之间或组内不断交替。不同会话中状态的智力和情感遗产将导致 `EEG` 信号的可变性。一些内部非平稳成分通常以疲劳和意识水平来考虑。在经历 `BCI` 技术面临的严峻挑战并导致非平稳性问题时，噪声也是一个巨大的贡献者。这涉及由于电极位置变化和环境噪声引起的不必要信号 \[[82](#ch06.xhtml#r6_82)\]。

#### 小型训练单元
由于可用性问题影响训练过程，训练阶段和集合的规模较小。尽管受试者考虑到长时间训练会花费进食和分心的时间，但它们为使用者提供了处理系统并学习如何监测其神经生理信号的关键体验。因此，在 `BCI` 的设计中，一个基本任务是在用户脑信号感知的技术复杂性与命中界面操作所需的训练量之间取得平衡 \[[93](#ch06.xhtml#r6_93)\]。

#### 维度灾难
在 `BCI` 结构中，为了保持过高的空间精度，指标是从多个通道报告的。由于正确识别单独指标所需的信息量会随着向量维度的增加而呈指数增长，因此提出了不同的特征提取策略。在识别区分特征方面，它们发挥着至关重要的作用。因此，分类器的整体效率只能通过有限的、独特模式的广泛范围来实现，而不是可能包含冗余的整个报告信号。

在至少五到十种情况下，通常建议使用与维度数量相符的、与类别一致的训练样本数量 \[[101](#ch06.xhtml#r6_101)\]。然而，由于 `BCI` 机器导致维度灾难的增长 \[[103](#ch06.xhtml#r6_103)\]，这种解决方案无法在令人惊讶的无维度环境中维持。

### 6.7.3 建议解决方案
为了应对和限制先前提到的技术挑战的影响，已经探索了多种解决方案。众多 `BCI` 机器附加组件可以分散在它们之上。以下章节提供了用于增强基于 `BCI` 的结构性能的几种技术的概述。

#### 6.7.3.1 噪声去除
预处理有助于在空间、时间和频率域中改善信号，尤其是在外部因素的帮助下。积极地说，有时噪声可以提高 `BCIs` 的准确性。降低噪声水平和提高 `SNR`（信噪比）在参考文献 \[[104](#ch06.xhtml#r6_104)\] 中进行了讨论。

无偏独立成分分析 (`ICA`) 是一种常用的空间滤波过程 \[[105](#ch06.xhtml#r6_105)\]。`ICA` 以无管理的方式对独立成分进行空间滤波。通过将项目相关 `EEG` 的成分与不适当的 `EEG` 和任务伪影的成分分离，它旨在提高 `EEG` 信号的 `SNR`。

脑电眼动图 (`EOG`) 测量眼睛前后之间的角膜视网膜静止电位 (`CRSP`)。使用眼动记录电极，`EOG` 污染的 `EEG` 信号的线性组合，基于临时的主要预处理将导致从信号中去除伪影 \[[106](#ch06.xhtml#r6_106)\]。混合变量是使用线性回归技术计算的。由于肌肉检测电极定位的困难，虽然它是去除 `EEG` 指标中眼动伪影最常见的方法，但它不再像处理 `EMG` 信号那样令人满意。

频带滤波允许去除噪声和伪影。此外，它可以为处理内部非平稳成分提供有价值的帮助。任务相关频率可在 `BCI` 系统中用于额外评估。对于要放置的眼部或肌肉运动，这种形式的滤波不再涉及更大的电极。滤波实现的优点是其简单性。Neela 和 Kahlon 进行了批判性综述 \[[99](#ch06.xhtml#r6_99)\]。

#### 6.7.3.2 多类分离
为了将使用者的意图转化为真正的愿望，使用了机器学习技术。它们区分并意识到所选择的优越性。因此，它们也在努力实现更好的效率和更好的 `ITR` 结果。接下来，这里简要介绍了三种不同的机器，学习算法如线性判别分析 (`LDA`)、支持向量机 (`SVM`) 和 k 近邻 (`KNN`)。

##### 线性判别分析 (LDA)
一种最小化维度的技术是 `LDA`。为了找到代表相应信号特征的特征向量的线性组合，部署了 `LDA`。`LDA` 尝试区分两种或更多种不同类别的物体类型。在数据集中，它在保留尽可能多的数据的同时减少维度/变量。它使用超平面来实现这一任务。超平面是决策平面或在具有不同组的对象组之间划分的空间。

`LDA` 步骤如下：
1. 计算类内和类间的散布矩阵。
2. 计算散布矩阵的特征向量和相应的特征值。
3. 对特征值进行排序并选择前 `k` 个值。
4. 构建一个新矩阵，其中特征向量映射到 `k` 个特征值。
5. 通过将数据点积与矩阵相乘，从第 4 步获得新的特征（即 `LDA` 分量）。

`LDA` 算法具有非常低的测量要求且易于实现。在各种形式和多类的 `BCI` 系统中，`LDA` 已得到满意的应用。但由于其对非平稳性问题的免疫性，它通常能给出理想且良好的结果，而其线性性在某些具有复杂非线性 `EEG` 实际情况的情况下可能导致整体性能下降。
