## 4.1 引言

机器学习技术倾向于使机器从先前存储的信息和新的环境中自行学习。持续学习的目的是改进系统以获得更好的结果。机器学习算法可分为监督学习算法、无监督学习算法和强化学习算法。监督学习算法可进一步分为分类和回归算法，而聚类和关联是无监督学习的两个子类别 \[[1](#ch04.xhtml#r4_1)\]。各种现代计算系统通常执行某种信号处理以提高信号的效率、质量和传输。信号处理获取、解释、说明并修改系统的物理现象。信号处理中的概率、统计学、数学和随机过程用于解释和建模系统的物理现象以提取关键信息。当然，机器学习算法可以提高该过程的有效性，这得益于其众多优势，包括易于模式识别、无需人工干预、持续改进以及处理多维多变数据的能力。在本章中，讨论了十种信号处理应用，这些应用现在在不同的计算环境中被大量使用，并且也利用了机器学习方法。具体而言，强调了机器学习方法在音频信号处理、音频压缩、数字图像处理、视频压缩、数字通信、医疗保健、地震学、语音识别、计算机视觉和经济预测中的应用。

## 4.2 音频信号处理

作为一种物理过程，语音或声音可以描述为分子的振动，通常会改变某些介质（如空气）特定区域的压力。这些振动的测量由一种称为麦克风的设备进行，其中膜片由于压力变化而被迫移动。膜片的这种运动随后使用磁铁和音圈转换为电压信号。该电压信号由膜片产生是一个连续信号，在任何时刻都取某个定义值 \[[2](#ch04.xhtml#r4_2)\]。典型的音频处理系统如图 [图 4.1](#ch04.xhtml#f4_1) 所示。

由于内存有限，计算机系统只能存储代表有限数值的有限值。因此，必须记录无限次出现的无限数量的数字，即必须进行模拟值到数字值的转换。此外，从数字信号重建模拟信号也必须可行。整个过程包括几个阶段，称为采样、量化和重建。模数转换器（ADC）是一种对模拟信号进行采样和量化的设备并产生数字信号，而数模转换器（ADC）执行重建并从数字信号产生模拟信号。

### 4.2.1 音频信号处理中的机器学习

音频信号处理中机器学习模型的发展需要对音频信号特征有清晰的理解。特征可以描述为“现象的可测量属性和特征”。特征非常重要，因为利用特征，机器可以理解数据，将其分类到不同类别，并进行预测 \[[3](#ch04.xhtml#r4_3)\]。在本节中，讨论了可在音频处理和机器学习中利用的音频特征。
