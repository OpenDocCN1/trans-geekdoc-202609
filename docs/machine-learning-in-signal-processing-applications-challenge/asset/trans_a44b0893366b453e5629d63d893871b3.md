## 1.2 基本术语

在深入研究信号处理、机器学习和 SPML 的高级概念之前，了解一些核心概念很重要。在本节中，我们将介绍一些与信号处理和机器学习相关的基本术语。

### 1.2.1 信号处理

#### 1.2.1.1 连续信号和离散信号

信号通常定义为随时间变化的物理量 \[[14](#ch01.xhtml#r1_14)\]，示例包括由传感器或测量系统捕获的光、音频、图像和视频。它是相对于时间传递信息的量。例如，声音信号传递了随时间变化的空气压力变化信息。

信号根据其在时间上是连续还是离散进行分类。[图 1.1a](#ch01.xhtml#f1_1) 和 b 表示这两种不同类型。连续时间信号在所有时间点都有值，现实世界中的信号大多是连续的，时间从 −∞ 变化到 +∞。

#### 1.2.1.2 采样和量化

数字信号有两个组成部分：时间和幅度，每个样本可以取自预定整数集的值。数字化是一个两步过程，包括两个不同的操作：采样和量化。最初，通过采样，模拟信号 `s[t]` 转换为离散信号 `s[n]`，信号以规则的时间间隔 `nT` 进行采样，其中 `n` 是样本数，`T` 是采样周期（秒），如公式 (1.3) 所示。然而，通过采样过程，模拟信号被转换为具有连续幅度值的离散时间信号 `s(nT)` \[[14](#ch01.xhtml#r1_14)\]。

`s[n]` = `s(nT)`

(1.3)

由于采样信号包含连续幅度值，它尚未成为完全的数字信号。因此，需要对其进行量化处理，其中连续幅度通过为每个样本的值分配一个离散数字来量化。因此，总而言之，离散时间信号量化时间以及信号幅度。理想采样器可以与每 `T` 秒打开和关闭一次的简单开关相比，采样周期由公式 (1.4) 给出。

```
T = ~\frac{1}{f_{s}}
```

#### 1.2.1.3 基变换

大多数信号处理应用需要将信号分解为其各个信号成分，以便对每个单独成分执行操作。信号分解也可以称为信号变换，其中信号从一个域变换到另一个域，例如从时域到频域。信号变换有助于分析信号，这需要从一个坐标系到另一个坐标系的基变换。
