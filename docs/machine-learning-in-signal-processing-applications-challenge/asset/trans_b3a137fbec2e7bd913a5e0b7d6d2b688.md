
## 6.2 BCI 的框架/架构
在 BCI 中，个体想象活动主要可根据 `μ` 和 `β` 节律的调整及其空间分布进行分类。模型和分类法被视为 BCI 系统设计的通用框架。在 BCI 框架中，错误相关电位 (`ErrPs`) 被研究以确定机器是否已选择执行用户给出的任务或指令。可以将此任务细分为两个独立阶段。第一个是外部节律的计算机驱动的基于提示的同步 BCI，具有预定义的时间窗口，第二个是内部节律的用户驱动的非提示型异步 BCI。已知的多数 BCI 像基于提示那样工作。同步 BCI 与异步 BCI 的主要区别在于，在异步 BCI 中，自定节奏系统必须独立工作，可能处于静止或空闲状态。该框架支持 [图 6.2](#ch06.xhtml#f6_2) 中所示的 BCI 特性。所提出的框架和基本架构是通过研究现有 BCI 技术而创建的。它应与 `TTD`（思想翻译装置）进行比较。

## 6.3 BCI 的功能
BCI 的大多数功能与用户状态相关，并使用户能够传达其想法。BCI 提供了一个非肌肉性通信通道，根据患者情况，可在医疗保健中使用，以支持运动功能极度受损的患者。使用侵入性或非侵入性技术，为完成预期任务，BCI 系统记录脑信号并将其发送到计算机系统。为了传达想法或调节实体，然后使用这些传输的波。

BCI 的主要功能是通信与控制以及客户端状态检查。

### 6.3.1 通信与控制
BCI 子系统在人类大脑和外部环境之间建立联系以记录、解码和解释信号，并且这消除了对日常文档传输技术的需要。它们处理从人类大脑传输信息并翻译其静默思考。因此，它们可以通过各种策略帮助残疾人与人交流并记录他们的结论和想法，例如在拼写程序包 \[[4](#ch06.xhtml#r6_4)\]、语义关联 \[[5](#ch06.xhtml#r6_5)\] 或静默言语通信中。

BCI 只需要融合大脑信号即可实现大量指令，且不需要肌肉群干预 \[[2](#ch06.xhtml#r6_2),[6](#ch06.xhtml#r6_6),[7](#ch06.xhtml#r6_7)\]。BCI 辅助机器人可以为受损客户在日常和专业生活中提供帮助，增加他们在构建其社区中的协作 \[[8](#ch06.xhtml#r6_8)\]。

### 6.3.2 客户端状态检查
早期的 BCI 应用主要集中在有行动或言语困难的残疾客户上。它们的目的是为这些客户提供一个可选的通信通道。然而，之后，BCI 也进入了健康人群的世界。它充当生理测量工具，获取并利用有关某人情绪、智力或深度状态的统计数据。在所称的被动 BCI \[[1](#ch06.xhtml#r6_1)\] 中，大脑信号利用的目的已扩展到在控制任何物体或提供特定功能替代之前。正如 \[[10](#ch06.xhtml#r6_10)\] 中研究人员所指出的那样，精确的知识将影响识别与脑信号相关的实际行为。

在 HCIs 中，BCI 个体状态监测能力被视为一种辅助手段，并根据被评估客户的情绪或认知状态对其进行调整 \[[10](#ch06.xhtml#r6_10)\]。

它还促进了智能环境和情感设计应用的发展 \[[3](#ch06.xhtml#r6_3)\]。工作环境评估和教学方法评估是可通过估计客户大脑状态获益的各个领域的实例。下文介绍了几个涉及脑机接口的程序。

*   获取脑信号
*   分析它们
*   翻译这些指令
*   转发至输出工具

BCI 允许在基于源自硬膜下皮层或头皮癫痫或侵入性电生理方法的自愿电、磁或其他物理表现的心理兴趣的函数的基础上操作合成仪器，即通过信号电极或多电极阵列在皮层内捕获的心理信号。在硬膜下血肿患者中，创伤后癫痫发作 (`PTS`) 是一种严重并发症 (`SDH`)。

这样，BCI 功能侧重于支持、增强或修复人类认知或感觉运动功能。

## 6.4 BCI 的应用
BCI 还可以使免提程序对通过大脑操作设备的个人来说变得简单方便。它们只需要整合脑波的信号来执行多项指令，且不需要肌肉干预 \[[2](#ch06.xhtml#r6_2),[6](#ch06.xhtml#r6_6),[7](#ch06.xhtml#r6_7)\]。支持 BCI 的机器人将协助残疾人在日常生活和职业生活中，扩展他们在发展其社区中的合作 \[[8](#ch06.xhtml#r6_8)\]。BCI 领域已在各种研究和应用领域受到关注。BCI 的几种应用如下所示，并在 [图 6.3](#ch06.xhtml#f6_3) 中显示，其中一些在此讨论。

### 6.4.1 医疗保健
BCI 在医疗保健领域的使用范围涵盖了包括神经假体、轮椅和人形机器人在内的广泛子系统。癫痫手术可以成为数千名医学上难以控制的患者亚组中的改变生活策略。由于 BCI 系统需要一定程度的信号和计算知识，实际中大多数应用的整合将需要更多时间。在医疗诊所和实验室中，操作性治疗仍然受到原始癫痫发作记录程序的启发。在需要颅内 EEG (`icEEG`) 评估的外科患者子集中，癫痫发作的记录和癫痫发作起始区的定位是迄今为止 *致癫痫的* 组织的最佳可用替代标志。`icEEG` 带来了一些风险和挑战，使其成为受益于优化的前沿。
