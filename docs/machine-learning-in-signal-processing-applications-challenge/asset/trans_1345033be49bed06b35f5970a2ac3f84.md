
## 11.7 电机电流特征分析（MCSA）

电机电流特征分析（MCSA）是一种用于旋转机械的状况监测技术，用于诊断感应电动机中的问题 \[[9](#ch11.xhtml#r11_9),[10](#ch11.xhtml#r11_10)\]。该概念起源于20世纪70年代初期，最初被提议用于核电站中难以接近的电动机和位于危险区域的电动机 \[[11](#ch11.xhtml#r11_11)\]。但随着时间的推移，它在工业中迅速获得了越来越多的认可。测试是在线进行的，无需中断生产，电动机在正常运行条件下带载运行 \[[11](#ch11.xhtml#r11_11),[12](#ch11.xhtml#r11_12)\]。MCSA方法可作为预测性维护工具，用于早期检测常见的电机故障，从而避免昂贵的灾难性故障、生产中断并延长电机使用寿命。它可作为诊断工具，并可作为振动和热监测的有力补充（使用多种技术检查故障） \[[13](#ch11.xhtml#r11_13),[14](#ch11.xhtml#r11_14)\]。MCSA是更广泛的电气特征分析（ESA）领域中的一种方法 \[[15](#ch11.xhtml#r11_15)\]，可用于分析不仅是电感应电动机，还包括发电机、电力变压器和其他电气设备。这些技术中最流行的是：电流特征分析（CSA），我们使用它以及其他技术，如VSA（电压特征分析）、EPVA（扩展帕克矢量法）和IPSA（瞬时功率特征分析）。

### 11.7.1 异步电机定子电流的建模

电感应电机的故障检测已被广泛研究。它基于对其振动的监测。所获得结果的可靠性在很大程度上取决于放置在这些机器上的加速度计的位置，并沿其垂直、轴向和径向轴布置。事实上，这个位置是这种振动建模技术的困难任务。此外，它还可能受到电机转速变化的影响，尤其是在机械部件 deteriorated 时。然而，这些技术成本高昂，因为它们需要额外的传感器。它们的使用只有在大型机器或关键应用的情况下才有意义。

定子电流线的监测确实是最有趣的建模基础，也是故障检测最有吸引力的选择。这有两个主要原因。首先，定子电流可用于诊断电气和机械故障，例如：相不平衡、定子绕组短路、轴承故障、扭曲轴、断裂转子条等。然后，定子电流非常容易获取，因为它可以直接测量并且用于控制机器本身。这为所指出的建模技术提供了重要优势。

将CSA定子电流分析技术应用于异步电机的故障诊断需要精确了解定子电流频率谱中包含的各种频率和幅度分量。该电流取自发电机模式下的机器。事实上，其分析允许正确区分异步电机的调制和故障特征。为此，有必要构建一个模拟真实物理现象的复杂信号。该信号的分析模型必须准确描述真实定子电流的行为和演变。它必须包含所有相应的故障信息。该电流通常用于命令和控制目的。

为研究上述故障的检测，异步电机的定子电流由离散信号 `x[n]` 表示。我们通过以步长等于 `T[s] = 1/F[s]` 采样电流 `x(t)` 得到它。在存在机械和/或电气故障的情况下，电感应电机的该定子电流 `x[n]` 表达如下 \[[8](#ch11.xhtml#r11_8)\]：

$$x\\left\\lbrack n \\right\\rbrack = \\sum\\limits\_{k = - L}^{L}a\_{k}\\cos\\left( {2\\pi f\_{k}\\left( {w\\left( n \\right)} \\right) \\times \\frac{n}{F\_{k}} + \\phi\_{k}} \\right) + b\\left\\lbrack n \\right\\rbrack$$

(11.1)

其中

1. `x[n]` 对应于定子电流的一个采样。
2. `b[n]` 是高斯噪声的一个采样。

参数 `L` 是由故障引入的边频数。量 `f[k](w)`、`a[k]`、`ϕ[k]` 分别对应频率、幅度和相位。`ω(n)` 是在阶为 `n` 的每个瞬间需要估计的参数。它取决于所研究的故障。假设谐波的时间和空间不被考虑。需要解决的问题被视为统计估计问题。这是对基频、已发生故障的特征频率以及相对幅度的估计。它是通过计算定子电流谱 `x[n]` 来进行的。

该信号的唯一问题是它单独不足以正确诊断机器的状态（例如，当你想在给定时刻决定机器的运行状态时）。因此，有必要将其与能够跟踪机器运行状态特征参数的技术相关联。其中包括诸如：快速傅里叶变换、快速傅里叶变换的瞬时功率、解调电流的频谱、小波分析等方法在旧研究中已被证明有效。但事实证明，这些技术在时间上非常昂贵。这促使我们探索其他途径，例如基于ESPRIT方法变体和智能故障分类算法的技术。

## 11.8 ESPRIT方法的变体

ESPRIT 代表通过旋转不变技术估计信号参数，是一种使用旋转不变技术估计信号参数的方法。它是一种用于确定和检测谐波的算法，具有非常高的频率和幅度估计精度。这与所使用的窗口大小无关。它是一种获得可靠的谱估计结果而不受同步效应影响的适当方法 \[[8](#ch11.xhtml#r11_8)\]。它基于平移不变性。它自然存在于离散时间序列与相应的信号子空间之间，从而导致旋转不变性。在这种情况下，信号自相关矩阵的特征向量 `U` 使用两个选择矩阵 `γ[1]` 和 `γ[2]` 定义两个子空间（信号和噪声）。

`S[1] = γ[1]U`, `S[2] = γ[2]U`

(11.2)

两个子空间之间的旋转不变性导致以下方程：

`S[1] = ϕ S[2]`

(11.3)

其中

$$\\phi = \\begin{bmatrix} e^{j2\\pi f\_{1}} & 0 & \\cdots & 0 \\\\ 0 & e^{j2\\pi f\_{2}} & \\cdots & 0 \\\\ \\vdots & \\vdots & \\cdots & \\vdots \\\\ 0 & 0 & \\cdots & e^{j2\\pi f\_{N}} \\\\ \\end{bmatrix}$$

(11.4)

矩阵 `ϕ` 包含有关 `N` 个频率分量的所有信息。估计矩阵 `S[1]` 和 `S[2]` 可能包含误差 \[[8](#ch11.xhtml#r11_8)\]。此外，TLS最小二乘法允许通过最小化误差矩阵的Frobenius范数来找到矩阵 `ϕ`。该矩阵的确定允许获得由以下公式定义的频率估计：

$$f\_{k} = \\frac{\\text{Arg}\\left( \\phi\_{k;k} \\right)}{2\\pi},~\\quad k = 1,\\, 2,\\ldots,N.$$

(11.5)
