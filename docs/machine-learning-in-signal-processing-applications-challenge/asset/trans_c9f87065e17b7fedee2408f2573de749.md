
## 3.3 无监督学习

收集和积累标记数据受资源限制，且耗时。在无监督学习中，实现准确标记非常困难。在无监督学习中，学习者被提供未标记的输入数据是一个前提。对于新的数据实例，学习者的意图是找到信息中的固有模式，以用于找到正确的输出信息。假设输入空间具有结构；因此，某些模式比其他模式更常出现，这在统计学中被称为密度估计 \[[21](#ch03.xhtml#r3_21),[22](#ch03.xhtml#r3_22)\]。无监督学习技术在传感器网络应用中非常有用。传感器网络应用通常在可变且不断变化的环境中组织。[图 3.5](#ch03.xhtml#f3_5) 显示了机器学习中的聚类。

无监督学习方法可分为聚类问题和关联问题。

* **聚类问题**：发现特定数据中的固有群体被称为聚类问题。例如，购买行为特别与聚类问题相关。
* **关联**：关联是指学习问题中发现规则定义信息或数据的大部分。

以下是无监督学习算法的良好示例：

* `k-means` 用于聚类问题。
* Apriori 算法用于关联规则学习问题。

### 3.3.1 无监督学习的示例

以下是不同无监督学习方式的说明。

> **示例：发现客户细分**
>
> 聚类是一种无监督方法，其意图是在特征空间中找到自然群体或簇并推断输入数据。它包含许多类型的聚类过程。一种常见的方法是将数据点划分为每个数据点落入与同一组中其他数据点相似的组，具体取决于特征空间中预定义的相似性或分离度量。聚类经常用于在营销数据中定义客户细分。营销团队成员以不同方式接触客户细分以找到不同类别的客户。性别、位置、教育、年龄、收入等是考虑的特征。

> **示例：降低问题的复杂性**
>
> 降维是一种常用的无监督学习方法；这里的目标是减少关注的随机变量数量。具有众多实际应用，降维最常见的用途是通过将特征空间映射到低维空间来克服问题的复杂性。因此，机器学习系统中测量的相关变量更少。PCA 和 t-SNE 以及 UMAP 是最常用的算法 \[[23](#ch03.xhtml#r3_23), [24](#ch03.xhtml#r3_24) 和 [25](#ch03.xhtml#r3_25)\]。主要来说，这些方法有利于降低问题的复杂性，并以更好的方式可视化数据示例。

> **示例：特征选择**
>
> 尽管特征选择和降维旨在减少特征唯一集合中的特征数量，了解特征选择的工作原理，有助于更好地理解降维。考虑银行系统的例子，其中个人想要贷款，银行必须预测个人是否有能力偿还贷款。因此，要智能地了解这一点，银行应配备机器学习系统，以便银行可以向只能偿还贷款金额的贷款申请人提供贷款。这需要关于每个客户申请的巨大信息来做出假设。机器学习数据库中最重要的属性应为申请人的平均月收入、借记账户和信用历史。有时观察到申请期间收集的信息不包含所有必要文件 \[[26](#ch03.xhtml#r3_26), [27](#ch03.xhtml#r3_27) 和 [28](#ch03.xhtml#r3_28)\]。某些属性与是否偿还无关；例如，个人的年龄、性别和教育程度无关紧要。在这里，特征选择通过减少不太重要信息的使用来删除不重要的属性并添加最重要的、最有帮助的属性。

## 3.4 半监督学习方法

在这种学习中，大量输入数据 `x` 和仅部分输出数据 `y` 存在；此类学习问题称为半监督学习。它们存在于监督学习和无监督学习之间。在动物照片集合中，少数动物图片被标记，例如猫、狗，而主流则是未标记的。大多数现实世界的 ML 问题属于这一领域。领域专家标记数据，这需要更多时间和时间消耗。因此，标记数据比未标记数据更昂贵。未标记数据易于在收集时存储，因为它们不需要专家，因此时间和成本更少。利用无监督学习方法来发现并学习输入数据中的结构 \[[29](#ch03.xhtml#r3_29), [30](#ch03.xhtml#r3_30) 和 [31](#ch03.xhtml#r3_31)\]。监督学习方法也用于预测未标记数据或信息并将其反馈作为训练数据输入监督学习方法。此模型可用于预测未见信息或数据。

监督学习程序的一个重要缺点是，考虑数据集的机器学习工程师或数据科学家必须进行手工标记程序。在处理大型数据集时，该程序成本高昂。应用范围的限制是监督方法的重大弱点。为了克服这些缺点，引入了半监督学习。特征上，标记数据和未标记数据的组合包含少量标记数据和更多未标记数据。涉及的基本步骤是，首先程序员将通过无监督学习算法对相似数据进行分组，最后使用现有的标记数据对剩余的未标记数据进行标记。它们共同的特性是，未标记数据的获取成本相对较低，而标记数据的成本非常高。
