
显然，`NL 0` 是一个线性函数（线性函数是非线性函数的一个子类），而另外两个关系表示不同的非线性程度。

在 [表 8.2](#ch08.xhtml#t8_2) 中，报告了线性信道 [信道 1](#ch01.xhtml#c1) 和 [信道 2](#ch02.xhtml#c2) 的训练和测试 `MSE` 的稳定值。而在本实验中，所考虑的非线性模型为 `NL 0`，训练和测试在 20 dB `SNR` 下进行。观察到，由 `CSO` 算法训练的提出的 `WNN DFE` 在所有考虑的技术中提供了最低的 `MSE`。此外，次于所提出算法，由 `PSO` 优化的 `FIR DFE` 提供了最具竞争力的性能。在两个信道之间，所有考虑的算法在 [信道 1](#ch01.xhtml#c1) 中表现出相对更好的性能。此外，可以观察到，在 `ANN` 基于模型中缺乏线性映射的情况下；它们的性能相比于 `FIR DFE` 和所提出的方案更差。

在 [表 8.3](#ch08.xhtml#t8_3) 中，报告了非线性对 `MSE` 性能的影响。在本实验中，仿真设置包括线性信道 [信道 1](#ch01.xhtml#c1) 与 `NL 1` 或 `NL 2` 级联。接收信号 `SNR` 对于所有方案再次保持在 20 dB。在此场景下，所提出的均衡方案对于 `NL 1` 和 `NL 2` 都显示出最佳性能。与前面给出的线性信道场景不同，`ANN SFLA` 算法在 20 dB 下的非线性信道中表现第二好。这表明，与 [Iqbal et al. (2015)](#ch08.xhtml#r8_20) 的简单 `FIR DFE` 结构相比，基于神经网络的均衡器在逼近非线性函数方面更好。

### 8.5.4.2 EVR 的影响

在下一组仿真中，我们研究信道的特征值比（`EVR`）对所提出均衡器 `BER` 性能的影响，并将其与其他文献中的方案进行比较。`EVR` 定义为 `λ[max]`/`λ[min]`，其中 `λ[max]` 和 `λ[min]` 分别是接收信号相关矩阵 `R` = `E`[`x` `x`^(T)] 的最大和最小特征值（[Haykin 2008](#ch08.xhtml#r8_17)）。如果信道的 `EVR` 较高，则接收机输入信号更集中于对应最大特征值的特征向量方向。传输信号通常是不相关的，但在通过具有较大 `EVR` 的信道时，它会产生强相关，导致严重的 `ISI`。另一方面，如果信道的 `EVR` 较低，则传输信号受信道影响较小，且 `ISI` 很小。总的来说，更大的 `EVR` 会导致更大的失真，需要更复杂的均衡器。

为研究 `EVR` 的影响，我们考虑以下长度为 `N[h]` = 3 的升余弦信道（[Haykin 2008](#ch08.xhtml#r8_17)）：

$$h_{i} = \\left\\{ \\begin{matrix} {\\frac{1}{2}\\left\\lbrack {1 + \\cos\\left( {2\\pi\\left( {i - 2} \\right)\\text{/}\\Lambda} \\right)} \\right\\rbrack,~~i = 1,2,3} \\\\ {\\quad\\quad\\quad\\quad\\quad\\quad\\quad\\quad\\quad\\quad 0,~\\,\\text{otherwise}} \\\\ \\end{matrix} \\right.$$  

(8.43)

其中

1. 参数 `Λ` 控制信道的 `EVR`。

例如，式 (8.38) 中的 [信道 1](#ch01.xhtml#c1) 和式 (8.39) 中的 [信道 2](#ch02.xhtml#c2) 的 `EVR` 分别为 200 和 635（[Iqbal et al. 2015](#ch08.xhtml#r8_20)）。

`EVR` 变化对不同信道的影响如图 [图 8.8](#ch08.xhtml#f8_8)–[图 8.10](#ch08.xhtml#f8_10) 所示。在 [图 8.8](#ch08.xhtml#f8_8) 中，当传输信号通过式 (8.43) 指定的线性信道时，不同均衡器在 `SNR` 为 15 dB 时的 `EVR` 影响进行了比较。[图 8.9](#ch08.xhtml#f8_9) 和 [图 8.10](#ch08.xhtml#f8_10) 显示了信号通过式 (8.43) 中的线性信道与非线性函数 `NL 1` 和 `NL 2` 级联传输时的仿真结果。在所有图中，`BER` 随着 `EVR` 的增加和非线性的引入而增加。在所有这些结果中，所提出的均衡器相比于所有考虑的方案显示出显著更好的性能。

### 8.5.4.3 时变信道的影响

式 (8.43) 中信道的传递函数可表示为 `H(z)` = `h[1]` + `h[2]` `z`^(−1) + `h[3]` `z`^(−2)，其中 `Λ` 取给定值。如果假设信道随时间变化且信道系数为 `h[i](n)`，则信道的线性部分如下所示（[Zhao et al. 2011](#ch08.xhtml#r8_58)）：

`H[n](z)` = `h[1](n)` + `h[2](n)` `z`^(−1) + `h[3](n)` `z`^(−2)  

(8.44)

信道滤波器系数的时变生成方式为 `h[i](n)` = `h[i]` + `f[LPF]`(`ρ` `w(n)`)，其中 `f[LPF]` 为低通滤波器（`LPF`），归一化截止频率为 0.1。`w(n)` 为白高斯噪声，其标准差 `ρ` 取为 0.1。[图 8.11](#ch08.xhtml#f8_11) 中的仿真结果表明，对于较低的 `EVR` 值，所提出均衡器的性能相比于 `FIR DFE` 均衡器更差，但对于 `EVR` 高于 400 的情况，所提出技术表现出显著改善的 `BER` 性能。所有其他均衡器的 `BER` 性能与所提出的均衡器相比远为逊色。
