
所提出的 `WNN` `DFE` 的框图如图 [图 8.6](#ch08.xhtml#f8_6) 所示。均衡器由三个子部分组成：`N[ψ]` 个小波基函数，将输入映射到向量 [`ψ[1](x)`,…, `ψ[1](x)`]，具有系数 `b[1]`,…, `b[N[B]]` 的反馈有限脉冲响应 (`FIR`) 滤波器，以及具有系数 `a[1]`,…, `a[N[I]]` 的前馈 `FIR` 滤波器，连接输入到输出 `ŷ(n)`。均衡器的输入 `x(n)` 由长度为 `N[I]` 的向量组成，该向量被应用于 `N[ψ]` 个小波子或小波基函数以及前馈 `FIR` 滤波器。反馈滤波器部分的输入是均衡器的延迟硬判决输出 [`û(n−1)`,…, `û(n−N[B])`]。输出 `ŷ(n)` 通过将这三个子部分的信号相加得到。

![图 8.6 基于小波神经网络的判决反馈均衡器。](images/Fig08_06.jpg)

[**图 8.6**](#ch08.xhtml#f8_6b) 基于小波神经网络的判决反馈均衡器。

$$\\hat{y}\\left( n \\right) = \\sum\\limits\_{j = 1}^{N\_{\\psi}}c\_{j}\\psi\_{j}\\left( {\\mathbf{x}\\left( n \\right)} \\right) + \\sum\\limits\_{i = 1}^{N\_{I}}a\_{i}x\_{i}\\left( n \\right) + \\sum\\limits\_{k = 1}^{N\_{B}}b\_{k}\\hat{u}\\left( {n - k} \\right) + a\_{0}$$

(8.25)

在式 (8.25) 中，`c[j]`，`j` = 1,…, `N[ψ]` 是从多维小波 `ψ[j](x(n))` 的输出到输出加法器的连接权重。对于二进制传输，发送符号的估计在接收端获得为（[图 8.6](#ch08.xhtml#f8_6)）

`û(n)=sign{ŷ(n)}`

(8.26)

其中
1. `sign{ŷ}` 返回 `ŷ` 的符号。

均衡器的参数为：

`w` = {`a[0]`, `a[i]`, `c[j]`, `τ[i j]`, `δ[i j]`, `b[k]`}

(8.27)

其中
1. `i` = 1,…, `N[I]`，`j` = 1,…, `N[ψ]` 且 `k` = 1,…, `N[B]`。

训练均衡器的基本思想是调整参数向量 `w` 以最小化由下式给出的均方误差

$$\\mathcal{M}\\left( \\mathbf{w} \\right) = \\frac{1}{2N}\\sum\\limits\_{n = 1}^{N}\\left| {y\\left( n \\right) - \\hat{y}\\left( n \\right)} \\right|^{2}$$

(8.28)

均方误差代价函数 ℳ(`w`) 中的参数表明其值取决于网络权重向量 `w`。训练 `WNN` 的传统技术涉及算法如 `BP`、`EKF`、`LMS`，它们遵循爬山法来实现最优性。然而，这些技术受限于收敛速度慢且容易陷入局部最优。在本工作中，ℳ 通过 `CSO` 算法迭代最小化。

### 8.5.2 布谷鸟搜索优化

`CSO` 是一种模仿布谷鸟繁殖行为的优化算法（[Yang and Deb 2014](#ch08.xhtml#r8_55)）。布谷鸟以其激进的繁殖策略而闻名。为了提高后代存活的概率，它们采用各种类型的巢寄生。许多布谷鸟物种，如欧洲普通布谷鸟，会将卵产在寄主物种的巢中。一般来说，布谷鸟的卵比寄主鸟的卵孵化得更早，布谷鸟雏鸟可以在被发现之前逃脱。此外，布谷鸟卵的壳比寄主鸟更坚固，因此不易受损。但巢寄生对寄主物种造成的代价很高，寄主会尽一切努力识别并移除布谷鸟的卵。因此，存在一种进化“军备竞赛”，布谷鸟试图欺骗寄主物种使其抚养自己的雏鸟，而寄主鸟则试图阻止它。这种竞争行为在 `CSO` 中被用于寻找最优解。

Levy 飞行是模拟昆虫、鸟类和动物觅食的随机或准随机游走。研究表明，一些果蝇通过沿直线飞行后突然 90 度转弯来探索地貌。同样，在一些人类狩猎采集部落中，狩猎是通过沿一系列直线路径探索地貌然后突然转弯来进行的。Levy 飞行的时序表示在整个时序中以短暂的活动爆发为特征，导致“重尾”分布。也就是说，它具有短步长的高度集中和大步长的低集中，尽管大步长的集中度高于通常的随机游走。Levy 飞行区别于普通随机游走的一个显著特征是其方差增长速度更快，这使其在探索更广的搜索空间方面具有优势。这将所需的迭代次数减少了大约四个数量级，相比于普通随机游走（[Mareli and Twala 2018](#ch08.xhtml#r8_32)）。

在 `CSO` 中，潜在解与布谷鸟卵相关联。布谷鸟将卵产在其他鸟的巢中，希望其后代能由代理父母抚养。如果其中一些被寄主鸟识别，它们将被从巢中移除。基于这些思想，`CSO` 是基于以下规则开发的（[Abdelaziz and Ali 2015](#ch08.xhtml#r8_1)）：
* 每个布谷鸟产一个卵并随机将其放置在任意一个巢中。
* 具有优质卵（或解）的巢将被允许传递到下一代。
* 在固定比例 `p[a]` ∈ [0,1] 的巢中，寄主鸟能够识别寄生卵。在这种情况下，这些卵要么被丢弃，要么寄主鸟完全放弃该巢。

基于这三个规则，`CSO` 算法总结在算法 1 中。在实现中，最初生成 `P` 个随机解 `w[p]^{(0)}`，`p` = 1,…, `P`。第 (`l+1`) 代第 `p` 只布谷鸟的新解 `w[p]^{(l+1)}` 生成为

`w[p]^{(l+1)} = w[p]^{(l)} + α L(β)`

(8.29)

其中
1. 0 < `β` ≤ 2 是 Levy 飞行参数且
2. `α` > 0 是步长缩放因子。
3. `L(β)` 是从 Levy 分布中抽取的随机数。

实际上，Levy 飞行使用 Mantegna 算法生成，如（[Yang 2010](#ch08.xhtml#r8_54)）：

`L(β) = s (w[p]^{(l)} - w[min]) ⊗ r`

(8.30)

其中
1. `w[min]` 是最佳巢（成本最低），
2. `r = [r[1],…,r[D]]^T` 且 `r[i] ∼ N(0,1)`，⊗ 表示向量的逐元素乘法。

在式 (8.30) 中，步长 `s` 计算为

$$s = \\frac{u}{\\left| v \\right|^{1/\\beta}}$$

(8.31)

其中
1. `u ∼ N(0,σ[u]²)` 且
2. `v ∼ N(0,σ[v]²)` 是具有标准差的高斯随机变量。

$$\\sigma\_{u} = \\left( \\frac{\\Gamma\\left( {1 + \\beta} \\right)\\sin\\left( \\frac{\\pi\\beta}{2} \\right)}{\\Gamma\\left\\lbrack \\frac{\\left( {1 + \\beta} \\right)}{2} \\right\\rbrack\\beta~^{2^{{({\\beta - 1})}/2}}} \\right)^{1/\\beta}$$

(8.32)

`σ[v] = 1`

(8.33)

然而，为了适应算法的探索能力，部分比例 `p[a]` 的新解按如下生成（[Abdelaziz and Ali 2015](#ch08.xhtml#r8_1)）：

`w[p]^{(l+1)} = w[p]^{(l)} + α δ ⊗ H(p[a] - ó) ⊗ (w[i]^{(l)} - w[j]^{(l)})`

(8.34)

其中
1. `δ` 是步长，
2. `H` 是 Heaviside 函数，
3. `ó` 是均匀分布的随机数。

* 算法 1 `Cuckoo Search Optimization (CSO)`
1. **输入：** 目标函数 `ℳ(w)` 且 `w = [w[1],…, w[D]]^T`
2. **初始化：** 生成 `P` 个巢 `w[p]^{(0)}` 的种群，`p = 1,…, P`。
3. 评估每个巢的成本为 `ℳ[p]^{(0)}`，其中 `w[min]` 具有最小成本 `ℳ[min]`。
4. **当** (`l < MaxGeneration`) 或（停止准则）时执行
   1. 使用 `w[min]` 和式 (8.29) 为 `p = 1,…, P` 生成新解 `w[p]^{(l)}`。
   2. 评估其成本为 `ℳ[p]^{(l)}`，`p = 1,…, P`。
   3. **如果** `ℳ[p]^{(l)} > ℳ[p]^{(l-1)}` **则**
      1. 用旧解 `w[p]^{(l-1)}` 替换 `w[p]^{(l)}`。
   4. **结束**
