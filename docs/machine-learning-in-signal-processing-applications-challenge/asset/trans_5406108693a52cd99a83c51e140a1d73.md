
### 4.6.4 ASR 中的机器学习范式
应用于自动语音识别（ASR）的机器学习方法包括生成学习、判别式学习、监督学习、半监督学习、主动学习和深度学习。ASR 中的机器学习范式及其关键属性在[图 4.13](#ch04.xhtml#f4_13)中突出显示。基于损失函数和决策函数的性质，机器学习范式已被归类为生成学习和判别式学习。模型的性质和训练目标中的核心组成部分是生成学习和判别式学习之间两个主要差异。生成学习包含生成模型并采用基于联合似然损失的训练目标函数。然而，判别式学习范式使用判别模型或旨在对模型应用判别训练\[[27](#ch04.xhtml#r4_27)\]。根据可用训练数据的种类，监督学习、半监督学习和主动学习是 ASR 中的机器学习范式类型。在监督学习范式中，训练数据集包含从联合分布获得的不同输入输出对。主要目标是最小化经验风险并进行正则化。监督学习与半监督学习之间的细微差别在于，后者还处理未标记数据集。

![图 4.13 语音识别中机器学习的范式。](`images/Fig04_13.jpg`)

[**图 4.13**](#ch04.xhtml#f4_13b) 语音识别中机器学习的范式。

主动学习与半监督学习略有不同，因为它考虑选择性标记数据集。主动学习的主要目的是使最具信息量的数据集被标记以提高分类性能。根据输入表示，ASR 中的另一种机器学习范式是深度学习。深度学习本质上与使用多层非线性转换来提取语音特征相关。由于庞大训练数据集的易得性，ASR 现在利用机器学习范式的强大功能。

### 4.6.5 计算机视觉
计算机视觉是一个旨在设计和开发方法与技术以使计算机能够看到、分析和理解包括图像和视频在内的数字内容。互联网上的数据同时包含文本和多媒体。对于搜索和索引文本内容，可以使用简单直接的算法和工具。但是，对于搜索和索引图像和视频等多媒体内容，算法必须知道图像和视频包含的内容，即计算机必须看到图像内部的内容\[[28](#ch04.xhtml#r4_28)\]。计算机视觉与人工智能和机器学习密切相关。计算机视觉拥有大量应用，包括机器检测、医学成像、汽车安全、动作捕捉、生物识别等。

众所周知的计算机视觉应用尝试在图像中执行以下操作：
*   **对象分类**：对图像中的物体进行宽泛类别分类。
*   **对象识别**：识别图像中物体的种类。
*   **对象验证**：检查图像中是否存在物体。
*   **对象检测**：检测图像中物体的位置。
*   **对象关键点检测**：找出图像中物体的关键点。
*   **对象分割**：识别属于物体的像素。
*   **对象识别**：找出图像中是什么物体以及它们的位置。

计算机视觉首先获取图像或实时的大量照片或视频，然后应用机器学习或深度学习模型来自动化该过程。最后在解释步骤中，机器学习或深度学习模型被部署以输出分数和决策。图像多级计算机视觉过程中遵循的基本步骤在[图 4.14](#ch04.xhtml#f4_14)中说明。首先，对输入图像数据进行图像分割，然后进行特征提取，随后进行目标识别。图像分割过程由分割参数集和用于参数适应的遗传算法支持。学习新对象特征与特征提取过程同步进行。对象模型获取和优化也在目标识别过程中同时进行。

![图 4.14 图像的计算机视觉过程。](`images/Fig04_14.jpg`)

[**图 4.14**](#ch04.xhtml#f4_14b) 图像的计算机视觉过程。

基于机器学习的方法倾向于改进计算机视觉以实现更好的识别和跟踪。它们为改进图像获取、图像处理和聚焦对象提供有效技术，这些都是计算机视觉的主要组成部分\[[29](#ch04.xhtml#r4_29)\]。对于目标识别，最常见的机器学习方法是尺度不变特征变换（SIFT）。SITF 使用对象的重要属性并将它们保存在数据库中。在图像分类中，这些对象属性由 SITF 检查并与数据库中保存的属性进行匹配。深度学习用于目标识别最常见的方法是 CNN。

### 4.6.6 经济预测
经济预测涉及对影响国家经济状况的各种经济参数进行预测。诸如通货膨胀、财政赤字、GDP、就业率、汇率等参数被预测以提前进行财务分析。经济预测是识别国家经济中存在的关键财务模式的一种手段\[[30](#ch04.xhtml#r4_30)\]。政府官员和企业管理人员利用经济预测来规划财政政策和未来经济活动。基于机器学习的方法被证明对金融预测领域有效且耗时更少。机器学习在金融预测中的主要优势是其能够分析结构化数据和非结构化数据。结构化数据的来源包括组织的 ERP 数据、内部审计报告或仓储系统，而非结构化数据可以从公司产品和服务的评论中收集。

在企业中采用机器学习方法时，第一阶段是确定范围，即业务的特定领域，如支出和收入。在此阶段还进行数据可用性和质量检查。范围必须包括组织影响最大的领域。在第二阶段，提出假设以确定业务驱动因素。在第三阶段，构建适当的机器学习模型以测试假设并考虑业务驱动因素。在最后阶段，将各种工具集成到金融预测过程中，然后进行可视化和报告。采用机器学习进行金融预测的过程在[图 4.15](#ch04.xhtml#f4_15)中显示。
