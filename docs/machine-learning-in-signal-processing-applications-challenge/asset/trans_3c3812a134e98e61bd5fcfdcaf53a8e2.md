
除数据预处理之外，数据的转换以及收集的关于问题的知识对于某些特定的机器学习算法也可能需要。为了训练从给定语音样本数据中提取各种模式的机器学习模型，通常采用信号处理。这里，用于训练机器学习模型的语音样本特征为音高、梅尔频率倒谱系数（`MFCC`）[[32](#ch10.xhtml#r10_32)]。

这里，可用的数据集可分为两类：一组用于训练模型，而另一组则满足测试需求。划分比例为 75%–25%。训练集用于训练机器学习模型，而测试集则用于评估机器学习算法的有效性和性能。

训练过程旨在泛化特征向量与类别标签之间共享的底层关系，其中特征向量由提供给监督学习算法的输入组成，而类别标签则涉及监督学习器的输出。所开发的机器学习模型的有效性可通过称为交叉验证的验证技术来评估。在训练过程中同样至关重要的一点是避免过拟合，过拟合可能导致泛化能力差以及执行阶段出现错误分类。

通常使用准确率、召回率和混淆矩阵等各种指标来评估机器学习算法的有效性和性能。如果需要在算法中加入改进，则可以重复之前的步骤，并在之前的步骤中应用更改。

一旦机器学习模型经过充分训练以提供令人满意的结果，即可进入执行阶段，此时将未标记的语音样本实例作为输入提供给训练好的分类器以识别其所属人员。

## 2. 输入 DNA 序列的数字信号处理机器学习
地球上居住着约 870 万种生物，其中约 150 万种不同物种已被识别、分类以及归类[[33](#ch10.xhtml#r10_33)]。从未识别的 86% 物种类别来看，据估计其中约 91% 存在的物种是仍待分类的海洋生物。为了执行识别和分类所有物种这一具有挑战性的任务，已经提出了多种不同的技术来执行基因组序列分析以及比较。这些提出的方法大致可分为两组：
* 基于比对
* 无需比对

有多种方法和软件工具基于比对技术设计，例如 `MEGA7` [[3](#ch10.xhtml#r10_3)]，它基于使用 `MUSCLE` [[4](#ch10.xhtml#r10_4)] 或 `CLUSTALW` [[5](#ch10.xhtml#r10_5),[34](#ch10.xhtml#r10_34)] 的序列比对构建。

尽管比对方法在基因组分类等领域已被证明是成功的，但在涉及多基因组规模序列数据中多序列比对问题的重时间或内存计算成本的情况下实施时，它们失败了。此类方法和数据类型通常需要依赖先验假设。典型的例子是间隙罚分和阈值作为统计参数[[7](#ch10.xhtml#r10_7)]。下一代测序（`NGS`）发挥着重要作用；比对来自基因组各部分的各种短读段可能相当具有挑战性[[8](#ch10.xhtml#r10_8)]。为了应对比对方法通常失败或证明不足的场景，已经提出了无对齐方法[[9](#ch10.xhtml#r10_9)]，其中包括基于 DNA 序列混沌游戏表示的方法[[10](#ch10.xhtml#r10_10), [11](#ch10.xhtml#r10_11) and [12](#ch10.xhtml#r10_12)]、随机游走[[13](#ch10.xhtml#r10_13)]、图论[[14](#ch10.xhtml#r10_14)]、迭代映射[[15](#ch10.xhtml#r10_15)]、信息论[[16](#ch10.xhtml#r10_16)]以及类别-位置-频率[[17](#ch10.xhtml#r10_17)]等方法。

尽管无对齐方法采用的概念能够处理比对方法难以管理的一些问题，但该方法仍存在某些需要应对的挑战，讨论如下：
1. 概念缺乏适当的软件实现：大多数已识别的无对齐算法在技术基础方面仍处于探索阶段。它们主要缺乏软件实现，而软件实现对于在通用数据集集合上比较各种方法至关重要。
2. 使用模拟序列或非常小的真实世界数据集：大多数现有无对齐方法使用模拟序列或非常小的真实世界数据集进行测试。这一因素使得在各种工具之间做出选择变得相当困难。专家很难在各种工具之间做出选择。
3. 内存开销：对给定多基因组数据进行的可能扩展相对于基于词的方法可能会导致内存开销，通常在长 `k`-mers 使用的情况下。这种挑战可以通过使用 `ML-DSP` 概念来解决，该概念将监督机器学习与对输入 DNA 序列执行的数字信号处理相结合，作为通用无对齐方法以及用于跨所有分类层级的基因组 DNA 序列分类的软件工具[[35](#ch10.xhtml#r10_35)]。

`ML-DSP` 的主要贡献是我们建议由监督学习算法使用的 `feature vector`。给定基因组 DNA 序列，其特征向量由以下两者的成对皮尔逊相关系数（`PCC`）组成：（i）通过将字母 A、C、G、T 适当地数值编码为数字从给定序列获得的数字信号的离散傅里叶变换（`DFT`）的幅度谱，以及（ii）训练集中所有其他基因组序列的 `DFT` 的幅度谱。
