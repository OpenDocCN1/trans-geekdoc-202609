
随着 `IoT` 和普适计算成为我们日常生活的一部分，时间序列数据由众多应用生成，包括金融应用、环境监测、医疗和健康等。 通常，时间序列数据的高维性会使通用机器学习算法性能下降或失效。 因此，为了从时间序列数据中提取有意义的知识，需要高效的算法。 时间序列分类 (`TSC`) 算法用于根据数据中存在的模式对未知的时间序列示例进行分类。 作为分类的第一步，可以使用 `DWT` 降低时间序列数据的维度以提高分类准确率。 此外，`DWT` 还可用于降低时间序列数据中的噪声以获得更好的分类性能。 隐式地，小波使时间序列数据平滑以实现更有效的分类。

## 12.3.1 时间序列分类算法

与通用分类算法类似，`TSC` 算法也涉及从现有标记的时间序列实例中学习，并利用所学知识对标签未知的新的未知实例进行分类。 时间序列数据由 `IoT` 设备以及应用领域生成，例如图像和语音识别（如识别所说的话）、医学诊断（如从 `ECG` 信号检测心脏病）、手势检测等。

小波分析背后的基本概念是将信号表示为一组函数的线性组合（小波变换，`WT`），该组合通过移动和伸缩一个称为母小波的单一函数获得。 信号分解导致一组称为小波系数的系数。 因此，作为由小波系数加权的小波函数的线性组合，信号可以重建。 必须计算足够数量的系数才能实现信号的精确重建。 时频局部化是小波的主要功能。

通常，将 `DWT` 集成到时间序列数据分类中有两种方法 [[11](#ch12.xhtml#r12_11)]。 第一种方法是将分类方法应用于小波域，第二种方法是将多分辨率特性纳入分类过程。

在第一种方法中，分类是在变换后的数据上执行，而不是在原始数据上执行。 这里的主要任务是确定适合应用分类的分解层级。 该问题的解决方案主要取决于数据和应用领域。 该方法可用于许多领域，例如医学、音频和纹理。 分类可以在小波变换后的数据上执行，而不是在原始数据上执行。 例如，在医学信号分类中，使用 `DWT` 识别原始信号中的突出特征。 医学信号的分类，例如，`EEG` 信号被分解为不同频率的子带。 之后，小波系数被输入到像神经网络这样的分类器中以执行分类任务。 在 [[12](#ch12.xhtml#r12_12)] 中，作者将 `EEG` 信号分类为正常或癫痫。 `DWT` 保留具有显著频率的 `EEG` 信号。 为此，首先将 `EEG` 信号以 200 个采样数字化。 对每个信号应用 `DWT`，生成分解后的信号。 在分解时，每个 `i` 级的信号会产生该信号对应的近似系数和细节系数 `A[i]` 和 `D[i]`。 不同的频率范围和由此产生的小波系数为医学从业者提供有意义的信息。 未提供太多显著信息的分量在分类模型的神经网络中不予考虑。

基于小波的 `TSC` 在分类过程中纳入了 `DWT` 的多分辨率特性。 具有小波系数中较大能量值的信号的主导特征被选用于分类，并由具有较大能量值的小波系数计算，然后用于分类。

下面列出了在 `TSC` 中使用的一些分类算法：

1. `One Nearest Neighbor (1NN)`: `1NN` 分类是 `KNN` 的一种特化，其中 `k` 值设为一。 一般来说，`kNN` 基于相似性度量（如欧几里得距离、曼哈顿距离等）来计算最近邻。 在时间序列数据中，底层最佳度量是动态时间规整 (`DTW`)、时间扭曲编辑距离 (`TWED`)、实序列编辑距离 (`EDR`)、最小跳跃成本 (`MJC`)，以及需要距离度量来查找最近邻的 `kNN` [[6](#ch12.xhtml#r12_6), [7](#ch12.xhtml#r12_7) 和 [8](#ch12.xhtml#r12_8)]。

2. `Shapelet Transform`: 该算法的工作方式类似于决策树分类。 它试图从训练集中找到最具代表性的子序列作为 shapelet。 Shapelets 代表一个类别。 然后该 shapelet 用于匹配未知的时间序列数据。 通过优化将时间序列数据划分为子序列的数据收益并从序列段中选择最佳候选，获得 shapelet。 此外，建议 Shapelet Transform (`ST`) 从每个类别中找到并使用 top `k` 个 shapelet，通过测量序列与每个 shapelet 之间的距离来转换数据集 [[9](#ch12.xhtml#r12_9),[10](#ch12.xhtml#r12_10)]。 将时间序列数据转换为 shapelet 后，还可以使用通用分类来对时间序列数据进行分类。

3. `Time Series Forest Classifier (TSF)`: 作为随机森林分类器用于时间序列数据 [[14](#ch12.xhtml#r12_14)]。 `TSF` 遵循的基本步骤如下：
    1. 它将时间序列信号划分为具有随机长度和起始周期的随机区间。
    2. 从每个随机区间提取统计特征，如均值、标准差、斜率等，形成单一特征向量。
    3. 提取的特征使用决策树分类器进行训练。
    4. 重复上述三个步骤，直到构建所需数量的树。
