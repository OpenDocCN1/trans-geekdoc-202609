
**Conclusion**: The observation is the same as the previous one. All that is needed is to find the right `K` value, the right distance assessor, and it doesn’t matter how the `SNR` pitch varies.

Based on these two results, we realized that, whether in the frequency or time domain, if we have the right parameters, we can have very good detection accuracies.
