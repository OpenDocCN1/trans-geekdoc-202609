
AI 是一门管理从信息中获得的计算进步的科学。根据 Arthur Samuel（1959）\[[9](#ch02.xhtml#r2_9)\]，AI 是“使 PCs 在没有被明确定制的情况下学习的研究领域”。Kevin Murphy 在他的原著 \[[10](#ch02.xhtml#r2_10)\] 中，将 AI 特征化为一系列算法，这些算法自动识别信息中的模式，利用揭示的示例来预测未来信息或其他感兴趣的结果。

机器学习由不同的算法组成，这些算法被计算机用于在没有任何外部人工规则的情况下执行一组指定的任务，并且从信息中学习（[图 2.1](#ch02.xhtml#f2_1)）。

### 2.2.2 扬声器 ID – 信号处理中机器学习计算的一种利用
Speaker ID（[图 2.3](#ch02.xhtml#f2_3)）是通过对语音属性的检查来识别个人的过程 \[[12](#ch02.xhtml#r2_12)\]。在这个受监管的分类应用中，一个有标签的准备语音测试集（来自一组扬声器）被用于学习周期。

![图 2.3 扬声器 ID。](images/Fig02_03.jpg)

[**图 2.3**](#ch02.xhtml#f2_3b) 扬声器 ID。

语音测试/记录不能直接在学习周期中使用。为了进一步处理，可能需要检查、清理（去除噪声或无效示例等），或重新组织示例到合理格式。此步骤称为“数据预处理” \[[9](#ch02.xhtml#r2_9)\]。

同样，我们可能需要更改特定于 ML 计算的信息和问题的信息。为了训练 ML 模型识别语音测试中的示例，使用信号处理对语音测试进行特征提取。在这种情况下，用于训练 ML 模型的特征是音高和 Mel-Frequency Cepstrum Coefficients（MFCC） \[[13](#ch02.xhtml#r2_13)\] 从语音测试中提取。

通常，可用的数据集（信息语音测试集）分为两组：一组用于准备模型，另一组用于测试需求（通常为 75%–25% 比例）。准备集用于训练 ML 模型，测试集用于评估 ML 计算的充分性和执行情况。

准备阶段应努力概括组件向量（对受监管学习计算的贡献）与类名称（受管学生的输出）之间的基本连接。交叉验证是评估 ML 模型推测能力的验证策略之一。

准备阶段还应避免过拟合，这可能导致执行阶段的弱推测和错误安排。如果计算的性能需要改进，我们需要返回并对过去的步骤进行更改。某些度量指标如 precision、recall、accuracy、F1 score、AUC-ROC 框架通常用于评估 ML 计算的有效性和执行情况 \[[14](#ch02.xhtml#r2_14)\]。

在 ML 模型经过足够准备以提供令人满意的执行后，我们继续进行执行阶段。在执行阶段，当未标记的语音测试实例被呈现给准备好的分类器时，它识别该实例所属的个人。

### 2.2.3 语音和音频处理
每部手机，无论是否智能，都严重依赖于语音准备策略使（至少两个）个人之间的语音通信成为可能——从模拟到数字转换到语音改进（分离、混响、噪声和程序化拾音控制）到账户侧的语音编码到语音解释到语音升级（通常是筛选和增益控制）到播放侧的模拟转换。信号处理始终是首选工具。没有信号准备，现代数字助手，例如 Siri、Ok Google 和 Cortana，就无法识别客户的声音。

声音压缩程序，例如 MP3 和 AAC，改变了我们收听音乐的方式。我们现在可以将世界的音乐旋律库存握在手掌中，并在旅途中欣赏音乐，甚至可以通过蓝牙完全无束缚。再次，信号准备促成了这一切。

### 2.2.4 语音识别
语音识别是信号处理的重要利用；它也是最容易理解的。信号处理控制信号中的数据内容以促进自动语音识别（ASR）。它有助于从语音信号中提取数据，然后将其翻译成明显的词语。语音识别技术存在于战斗机、“与文本对话”应用程序在高级手机上、有用应用程序、语言解释和学习，以及为残疾人士提供的识别程序 \[[15](#ch02.xhtml#r2_15)\]。

### 2.2.5 听力设备
你现在能听到我们吗？听力设备创新的核心是四个同步部件：放大器、处理器、接收器和力源。信号准备参与获取环境中的声音并处理它们以升级和增强佩戴者听到的内容。立即，声音从模拟转换为数字再转换回模拟，然后声音被投射到耳中 \[[16](#ch02.xhtml#r2_16)\]。

虽然创新的基本组件将保持不变，但便携式放大器变得越来越先进——减少来自整体环境的噪声和反馈，以帮助人们听到新鲜、清晰的声音。信号处理还减少了意外的嘈杂噪音，例如喇叭，甚至允许放大器远程与手机或电视连接。

### 2.2.6 独立驾驶
曾经是科幻小说的素材，独立车辆现在是现实。为了正常工作，这些自动驾驶车辆依赖于来自多特定传感器阵列的贡献，包括超声波、雷达和摄像头——为了防止碰撞，它们必须转换获得的信息并将其过滤为控制活动所需的数据。信号处理对该技术至关重要。它决定车辆是否需要停止或继续，并且是用于解释天气条件如降雨或雾的雷达的重要组成部分 \[[17](#ch02.xhtml#r2_17)\]。

### 2.2.7 图片处理和分析
事实可能比小说更离奇。我们日常生活中数字相机和屏幕无处不在，例如在我们的手机、车辆、无人机、监视系统、飞机、医院和客厅中，反映了我们不断增长的需求，即以更高的细节水平查看、分享和与我们的视觉环境连接。在医学中，几乎所有诊断现在都涉及某种成像。然而，这块迅速出现的冰山隐藏了许多鲜为人知但极其基本的应用，尤其是在社会、军事、健康和科学研究领域。信号处理对从采集到显示的广泛应用至关重要：
* 数字恢复图片和视频
* 紧凑检测采集（例如，单像素相机）
