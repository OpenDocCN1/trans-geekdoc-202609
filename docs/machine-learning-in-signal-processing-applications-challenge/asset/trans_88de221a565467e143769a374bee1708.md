
最近，应用于均衡问题的元启发式技术相比传统算法显示出显著改进。与传统的基于梯度的优化算法不同，自然启发式或元启发式学习技术可以避免陷入局部最优。粒子群优化（PSO）就是这样一种启发式算法，已被应用于信道均衡器中权重的优化（[Al-Awami 等 2011](#ch08.xhtml#r8_5)；[Al-Shaikhi 等 2019](#ch08.xhtml#r8_7)；[Iqbal 等 2014](#ch08.xhtml#r8_19)）。[Al-Awami 等 (2011)](#ch08.xhtml#r8_5)提出了对 PSO 算法的改进，使自适应均衡器的性能相比其他类似方案得到提升。[Al-Shaikhi 等 (2019)](#ch08.xhtml#r8_7)提出了对 PSO 算法的改进，称为混合 PSO（HPSO），以提高均衡器性能。HPSO 包括随机化和对粒子惯性权重的分配，使其不会陷入局部极小值。在[Iqbal 等 (2014)](#ch08.xhtml#r8_19)的研究中，提出了一种用于单载波频分多址（SC-FDMA）系统的 PSO 训练均衡器，作者证明了其在高多普勒场景下的鲁棒性。判决反馈均衡器（DFE）以性能而言已知优于线性 FIR 均衡器。[Iqbal 等 (2015)](#ch08.xhtml#r8_20)的研究中提出了针对高特征值扩展信道的多个输入多输出（MIMO）系统的 DFE 均衡器。在其中，作者提出了 PSO 与最小均方（LMS）算法的混合，以证明相比仅使用 PSO 的均衡器性能有所提升。[Nanda 和 Garg (2019)](#ch08.xhtml#r8_38)提出了由蛾群优化（MFO）优化的 FIR 和无限脉冲响应（IIR）滤波器的均衡器结构。虽然所提出的 FIR 均衡器是自适应均衡器，但 IIR 均衡器是针对 IIR 信道的盲自适应均衡器。

由于人工神经网络（ANN）在准确建模无线信道中存在的非线性方面的能力，文献中提出了几种由自然启发算法优化的神经网络。一种由 PSO 算法训练的神经网络均衡器被提出用于恢复经 ISI 和非线性信道传输的信号（[Das 等 2014](#ch08.xhtml#r8_14)）。Panda 等提出了基于定向搜索优化（DSO）的神经网络训练算法，用于非线性信道的均衡（[Panda 等 2015](#ch08.xhtml#r8_42)）。随后，作者还在[Panda 等 (2014)](#ch08.xhtml#r8_43)中提出了由混洗蛙跳算法（SFLA）训练的神经网络均衡器。[Sahu 等 (2018)](#ch08.xhtml#r8_47)的研究中引入了径向基函数神经网络用于无线通信信道的均衡，其中作者提出用 SFLA 训练 RBF-NN。在他们的研究中，[Ingle 和 Jatoth (2020)](#ch08.xhtml#r8_18)用 Levy 搜索增强了 JAYA 优化算法，以缓解其因种群多样性缺乏和弱探索能力而带来的不足。然后所提出的优化算法被用于训练 FLNN 均衡器。[Das 等 (2018)](#ch08.xhtml#r8_13)提出了量子行为 PSO 算法用于训练基于 ANN 的均衡器。在这项工作中，除了训练网络权重外，作者还使用量子 PSO 算法优化 ANN 拓扑。

通过广泛的文献调研，已观察到基于神经网络的均衡器比具有 FIR 结构的自适应均衡器更适合于非线性信道的均衡。此外，判决反馈均衡器在具有深谱零点和时变信道的信道中提供更好的误码率（BER）性能。尽管有一些关于由自然启发算法训练的简单 DFE 均衡器的最新工作（[Iqbal 等 2015](#ch08.xhtml#r8_20)），但基于神经网络的 DFE 及其由元启发式算法训练的文献很少。受 WNN 基均衡器及其由 SOS 算法训练的启发（[Nanda 和 Jonwal 2017](#ch08.xhtml#r8_37)），我们提出了一种用于受 ISI 和非线性影响的通信信道的 WNN 判决反馈均衡器（WNN DFE）。本工作的重大贡献如下：
1. 提出了基于 WNN 和判决反馈原理的新均衡器架构。所提出的结构允许对通过时变信道和具有深谱零点的信道传输的符号进行均衡。
2.  在本工作中，我们使用布谷鸟搜索优化（CSO）开发了一种新的 WNN 训练方法。据我们对现有文献的调查，目前尚无使用 CSO 训练 WNN DFE 均衡器的现有方案。
3.  与[Nanda 和 Jonwal (2017)](#ch08.xhtml#r8_37)中提出的 WNN 均衡器相比，其中仅在训练过程中修改外层权重，所提出的 WNN DFE 训练网络的所有权重，包括平移和伸缩参数。这尤其具有挑战性，因为涉及大量参数，但结果显著提高了性能。

本章其余部分组织如下。研究系统模型和均衡的一些基本原理在[第 8.2 节。](#ch08.xhtml#h8_2)中介绍。小波原理和小波神经网络的架构在[第 8.3 节。](#ch08.xhtml#h8_3)中描述。[第 8.4 节](#ch08.xhtml#h8_4)介绍了 CSO 算法并提出了 WNN DFE 的建议架构。WNN DFE 的基于 CSO 的训练算法也在本节中给出。仿真结果在[第 8.5 节。](#ch08.xhtml#h8_5)中呈现并讨论。最后，本章在[第 8.6 节](#ch08.xhtml#h8_6)中总结，并讨论了一些未来工作的范围。

## 8.2 系统模型

### 8.2.1 信道均衡

所提出均衡器的系统模型如图[图 8.1](#ch08.xhtml#f8_1)所示。其中，信道被建模为 FIR 滤波器，其冲激响应为 `h` = [`h`[1],…`h`[`i`],…, `h`[`N`[`h`]]]，其中 `N`[`h`] 为响应的长度。冲激响应 `h` 反映了信道响应、发射和接收滤波器的综合效应。在本工作中，我们考虑基带等效模型，信道由二进制相移键控（BPSK）符号 `u`(*n*) ∈ {+1,−1} 在时间 `n` 处激励。信道对输入 `u`(*n*) 的响应为

```
$$v\\left( n \\right) = \\sum\\limits\_{i = 1}^{N\_{h}}h\_{i}u\\left( {n - i} \\right)$$
```
(8.1)

`x`(*n*) = `Φ`(`v`(*n*)) + `w`(*n*), `n` = 1,…, `N`
(8.2)

1. `N` 为接收符号的数量。
