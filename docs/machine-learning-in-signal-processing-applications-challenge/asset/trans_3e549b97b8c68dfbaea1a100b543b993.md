# 12 小波变换和机器学习技术在物联网系统数字信号分析中的应用

Rajalakshmi Krishnamurthi and Dhanalekshmi Gopinathan

Jaypee Institute of Information Technology

## 12.1 引言

物联网分析的全球市场趋势预计到2022年复合年增长率（CAGR）将增长26% \[[1](#ch12.xhtml#r12_1)\]。在当今情况下，由于物联网的各种优势和能力，物联网在学术和商业领域取得了非凡的增长。它通过创建各种应用和有用的服务在很大程度上提高了生活质量。它已将现实世界中每个可以借助互联网相互通信和协调的对象连接起来。所有连接到互联网的项目都可以通过物联网以最少的个人努力相互通信。物联网普遍存在于环境中，具有多个连接对象（有线或无线），它们产生最新的应用程序和服务，如智能家居、智能交通、智能能源、智能城市等。

物联网是动态的和全球网络的基础设施。它能高效地处理事物的自配置。由于技术领域的巨大发展，物联网已涉及各种其他技术，如无线传感器网络（WSN）、云计算等。物联网已将人类与可以随时随地访问的对象连接起来。物联网在每个领域都有应用。它增强了医疗保健服务，因为健康监测可以实时进行。物联网还优化了交通运输领域的运营成本。各种家庭活动都可以通过物联网实现自动化。然而，物联网在成功部署时也面临各种挑战，例如物联网传感器设备产生的大量数据。

物联网设备产生大量数据，在保持数据完整性的同时维护此类数据是一项复杂任务。物联网设备、平台和操作系统存在高度异构性。因此，处理它们之间的协调是一项困难的任务。随着物联网设备和服务需求的快速增长，系统应具有高度可扩展性以保持效率和有效性。如今，随着物联网技术的进步，各种物联网设备在人们的家中、工作场所、车辆等处无处不在。物联网设备可以快速确定与特定用户环境相关的各种信息，如习惯、某些模式等。然而，用户物联网设备无法轻易确定在其物理附近的其他物联网设备。因此，在 \[[4](#ch12.xhtml#r12_4)\] 中，提出了一种使用声啁啾的方法，其中物联网设备可以发现附近的不同物联网设备。在邻近检测系统之后，第二个设备发出音频信号和数据包。信号通过麦克风检测，数据包被接收。之后，为了近似两个设备之间的距离，第一个设备使用音频和数据包之间的相关性。然而，重大挑战是执行物联网系统的维护，从生成原始数据中获得知识洞察。

在 \[[2](#ch12.xhtml#r12_2)\] 中，提出了一种新的方法来处理物联网系统的维护。所提出的方法可以轻松找到工作不正确并产生错误信息的故障物联网节点。此外，还使用了连续时间马尔可夫链，使物联网网络的监控过程更高效。使用此方法，物联网控制器通过预测节点的即将到来的值来检测在时间控制期到期后将出现故障的物联网节点。之后，控制器发送信号以更换该特定节点。为了在连续时间内收集数据，该方法在故障节点的位置创建一个虚拟传感器，以便即使在物联网设备发生故障期间也能保持数据的可靠性。在 \[[3](#ch12.xhtml#r12_3)\] 中，提出了一种远程面部表情监测系统，该系统使用高数据率的肌电图（EMG）信号。Wi-Fi通信用于传输数据，云计算用于快速高效的信号处理。此提议的机制也可用于需要高数据率EMG信号的各种其他应用。

物联网是各种事物的系统，它们共同与环境合作并借助互联网传输数据。数百万个由物联网启用的设备，如传感器、智能手机等，连接起来执行各种任务。物联网系统面临需要有效解决方案的各种问题，如高效能源、事件的适当调度、数据安全、故障检测、节点定位等。这些问题的解决方案存在于机器学习中 \[[4](#ch12.xhtml#r12_4)\]。通过使用物联网的机器学习，物联网的性能通过探索已收集的信息并在不额外努力的情况下优化性能而显著提高。

物联网系统监控快速变化的动态环境。因此，机器学习可以使系统更具适应性，以便自主高效地处理场景。物联网系统需要机器学习技术来自行校准新信息，以便在难以到达的环境中高效运行，如火山喷发监测。机器学习在提高物联网系统的决策能力方面也发挥着非常重要的作用。使用物联网的机器学习也存在一些挑战，例如物联网设备资源有限，而机器学习方法会更快地消耗能量。

深度学习在实现物联网系统的实时要求方面也发挥着至关重要的作用 \[[5](#ch12.xhtml#r12_5)\]。例如，对象识别任务必须在捕获和响应目标任务时具有显著更低的延迟等。各种进行实时处理的智能物联网设备需要仅在有限位置可用的更好质量的稳定网络。通过将深度学习与物联网集成，网络连接质量将不再是问题。物联网设备计算能力低、内存有限，因此无法在物联网设备上启用深度学习。深度学习方法功耗高，需要高性能计算。大多数深度学习库使用第三方库，这些库不易迁移到物联网设备。
