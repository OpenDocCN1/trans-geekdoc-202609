
`CNNs` 最初是为计算机视觉创建的，例如用于图像分析。自 2011 年以来，它们在 `NLP` 中变得越来越流行 [[55](#ch05.xhtml#r5_55)]。Kim [[47](#ch05.xhtml#r5_47)] 和 Kalchbrenner 等 [[60](#ch05.xhtml#r5_60)] 有效地将 `CNNs` 用于 `NLP` 任务，例如句子分类和句子建模。Kim 的句子分类工作将在本节中进一步探讨，因为它是一种适当的方法来分解文本以进行情感预测。首先，将给出关于 `CNN` 基本思想的简要说明。

A `CNN` 由卷积层和池化层组成。输入信息被传递到至少一个卷积层的堆叠中，其后跟一个池化层。这种卷积-池化层结构可以重复以创建更深的结构，形成深度 `CNN` [[1](#ch05.xhtml#r5_1)]。卷积层将滤波器模式应用于信息。这有助于将输入信息映射到特征图并发现它们之间的局部关联。滤波器设计通过将输入的一部分映射到一个特征来减少网络中的权重数量。此外，池化层缩小特征图并合并语义相似的特征。卷积层可以包含多个滤波器设计，这在 [图 5.5](#ch05.xhtml#f5_5) 中堆叠结构所示。

![图 5.5 用于句子分类的 CNN。](images/Fig05_05.jpg)

作者将各种类型的 `CNNs` 应用于不同的句子排序和问题分类任务，例如区分正面或负面的电影评论。他们的 方法在四个任务中超越了最先进的方法。他们为句子中的每个词取一个预训练的 `word2vec` 词嵌入并构建一个维度为 `n k` 的矩阵。因此，`k = ED` 表示词嵌入的维度，而 `n` 表示句子的长度。该矩阵作为其 `CNN` 的输入。他们在卷积层中使用双曲正切作为滤波器。然后对提取的特征图应用最大池化层。他们的模型将 `FNN` 与 dropout 结合作为最后一层来对信息句子进行分类。Kim 方法的变体 [[61](#ch05.xhtml#r5_61)] 已被成功应用于预测自然或临床 [[62](#ch05.xhtml#r5_62)] 科学中的类别。

## 5.3.4 特征选择和预处理

特征选择和预处理是人工智能中的重要任务，主要代表信息准备。特别是在 `NLP` 中，该任务对文本分析的成功具有巨大影响 [[63](#ch05.xhtml#r5_63)]。这通常是由文本信息无结构和主观的性质造成的。此外，机器需要结构化和数学信息。存在几种用于此转换任务的方法，例如词嵌入或向量空间模型。

本节的范围在于不同预处理和特征选择程序的理论基础。本部分将以英语短语“the best fox is running”作为示例来说明预处理的使用。并非总是情况是合理的预处理方法在每个应用中都会带来更好的结果 [[64](#ch05.xhtml#r5_64)]。

### 5.3.4.1 分词

为了处理书面自然语言，将消息分成更小的单元是不可避免的，这些单元称为 tokens。计算机需要识别书籍的单个实体，而分词用于创建它们。通常，token 代表基本单词，它们是自然语言最小的独立单元。此外，token 可以包含俚语或连字符，例如“user-created”。分词将连续文本分解为短文本元素，是任何文本预处理周期中的第一个任务。除了分割小单元之外，整个句子也可以是分词器的输出。基本词分词器 [[65](#ch05.xhtml#r5_65)] 可以通过在空格字符出现处分割文本在许多语言中实现。这种基本基准方法有一些缺点，因为缺乏区分语义上属于一起的词。然而，基本分词器将上面介绍的短语分解为以下五个 token，如 [图 5.6](#ch05.xhtml#f5_6) 所示。

### 5.3.4.2 停用词移除

减少 `NLP` 中庞大原始输入空间的重要方法之一是停用词移除 (`SWR`)。大多数语言都有特定单词，它们出现的频率高于其他单词或不包含关于文本内容的大量信息，例如助动词或冠词。因此，在进一步分析中禁止这些所谓的停用词通常是有意义的。在英语中，这样的词可能是“the”、“a”或“an”，而在德语中，常见的停用词是冠词“der”、“bite the dust”和“das”。可以通过将单词与规范化的停用词列表进行核对来进行删除。

这些列表在文献中可获得，并经常在不同的编程包中实现 [[66](#ch05.xhtml#r5_66)]。在我们的模型中，“the”和“is”被移除。`SWR` 应谨慎使用，如 [图 5.7](#ch05.xhtml#f5_7) 所示，特别是在情感分析中，它试图预测书籍的正面或负面意图。移除会拒绝可以改变整个表述的词，例如“not”或“none”。

### 5.3.4.3 词干提取

除了停用词结束之外，词干提取是一种有价值的策略，将单词映射到其承诺词干并进一步减少输入维度。这有助于提取书籍的真正含义并改善机器可用的无结构信息。第一个基于删除最长后缀和拼写特例的词干提取算法于 1968 年创建。此时，守卫词干提取算法是最先进的方法，它从单词中剥离后缀以保留词干。

虽然该策略在英语中表现良好，但对于德语来说有一些缺点，因为德语单词通常不是通过添加后缀来工作的。然而，基于 Porter 思想和字符串处理语言 `Snowball` 的德语等价物存在。通过使用英语 `Porter Stemmer`，单词“best”、“fox”和“running”被分配到以下单词，如 [图 5.8](#ch05.xhtml#f5_8) 所示。
