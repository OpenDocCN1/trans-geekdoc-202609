## 6.1 BCI 及其组件简介

我们人体中最复杂的器官是大脑，拥有超过 1000 亿条神经，传递着数万亿个突触（神经元与肌肉细胞之间的连接）。 目前文献中使用的脑-计算机接口（BCI）这一术语最早由 Vidal 等人于 1973 年至 1977 年间在加州大学洛杉矶分校提出。 BCI 是用户与计算设备之间的强大子系统。 BCI 检测大脑信号，对其进行分析，并将神经信息解释为相关输出设备。 现在，有多种侵入性和非侵入性测量脑活动的方法，包括脑电图（EEG）、脑磁图（MEG）、功能性磁共振成像（fMRI）、功能性近红外光谱（fNIRS）和光学成像。

BCI 子系统中的技术支持大脑与外部人工设备之间即时的交换通道。 BCI 系统的目的是协助、增强或恢复人类的认知或感觉运动特征。 电极是电流通过（进入或离开）的导体。 BCI 使能够主要基于从皮层或头皮硬膜外、硬膜下或侵入性电生理手段获得的自愿性电、磁或各种身体表现的脑活动能力来操作人工系统，即使用单或多颅内皮质电极阵列（MIEA）捕获的大脑信号。 然而，在 BCI 网络中，最有效的 EEG 监测和相关技术因技术、时间决策、实时性和价格限制而被使用。

He 等 \[[73](#ch06.xhtml#r6_73)\] 和 Abdulkader \[[115](#ch06.xhtml#r6_115)\] 提供了关于神经元电活动的更多信息，频带较宽，因此大脑信号经过预处理、滤波和去噪以提取相关数据，最后，在同步控制的帮助下或更准确地说在自定节奏或异步控制的帮助下，该统计数据被解码并转换为工具命令，以便确定用户是否正在处理某事。 除了控制接口输入外，原始脑信号还可作为某些特定 BCI 任务的刺激。 因此，该领域研究人员的光明前景促使他们研究 BCI 在医疗应用中在生活中的作用，并且范围现已扩展到包括非医疗应用，以提高人机接口（HCI）系统的准确性。 总体上 BCI 系统有两种，称为内源性和外源性。 内源性 BCI 基于自发活动，控制信号在内部产生，不依赖外部刺激，可通过专注于特定心理任务来调节。 另一方面，外源性 BCI 基于任务提示，取决于外部刺激，使用脑信号。

BCI（脑机接口）创新自此已成为用户和计算机的开创性专业子系统。 为了提供指令并完成协作 \[[9](#ch06.xhtml#r6_9)\]，不需要外部设备或肌肉干预。 为了改进 BCI 的设计，需要一种良好的信号处理方法。 许多学者主张为确实检查或受保护的客户恢复改善能力并取代丧失的运动功能 \[[2](#ch06.xhtml#r6_2)\]。 本章编写旨在提供不同技术、不同信号处理思想及其应用的简明指南。 BCI 所预期的光明前景促使研究网络不要忘记 BCI 在医疗应用中对非残疾人生活方式的贡献。 因此，这里在 BCI 系统/子系统的背景下展示了一些选定的特征提取和分类方法。 在人类应用中，输出反馈通过在监视器上可视化或显示皮层反应或其他电位的实际脑反应声学来实现。 因此，BCI 框架提供了一种现代化的通信形式，可直接将信息和指令从大脑中继到外部世界。

1. **信号采集：** 信号采集阶段捕获主要供给 BCI 的电生理信号，以增强信号并降低噪声。 根据分析的大脑信号，可能需要感觉刺激。

2. **信号预处理：** 信号预处理的需要是提高信噪比（SNR）。 它可能包括伪影减少策略并应用先进的信号处理方法。

3. **特征提取：** 为了生成改进信号的合适表示，需要特征提取算法，减少应用于类别因子的统计数据的规模。 电生理数据的提取特征简化了脑信号模式的检测。 特征提取方法的例子是幅度测量和用于去噪、变化、稀疏等的自编码器族。

4. **分类：** 生成的特征由分类器翻译。 分类器组件使用特征提取器产生的特征来分配和分类脑模式，并将产生的函数转换为设备指令 \[[2](#ch06.xhtml#r6_2)\]。 单次试验 EEG 数据集通过阈值方法检测。
