
## 9.1 深度学习概述

通过深度学习技术和算法的使用，模型可以从数据中学习多层次的抽象和表示。主要地，深度学习（`DL`）算法在各种应用领域表现优异。`DL` 是一类机器学习技术，基于 `artificial neural networks`。`DL` 算法通过使用不同数量的层来处理数据。网络层的第一层和最后一层分别称为 `input layer` 和 `out layer`。中间的层称为 `hidden layers`。主要地，深度学习概念并非新事物；它们源于海量数据集可用性、新算法和高计算能力的进展。McCulloch 和 Walter [[3](#ch09.xhtml#r9_3)] 提出了一个 `neural network model`，其中每个神经元被假设为处于二元状态，即在深度学习演进的初始阶段处于开启或关闭状态。Rosenblatt [[4](#ch09.xhtml#r9_4)] 提出了 `perceptron` 的概念，它从数据中学习的方式类似于生物神经元。Hubel 和 Weisel [[5](#ch09.xhtml#r9_5)] 实现了基于 `receptive field` 的神经元，用于检测猫视觉系统的局部特征。Fukushima [[6](#ch09.xhtml#r9_6)] 提出了 `convolutional neural network` 用于视觉模式识别，以模拟动物视觉皮层的组织结构。Lecun [[7](#ch09.xhtml#r9_7)] 开发了基于 `convolutional neural network` 的 `backpropagation` 用于邮政编码识别。后来，Lecun [[8](#ch09.xhtml#r9_8)] 实现了 `LeNet` 用于基于梯度的学习的文档识别。`Deep convolutional neural network` (`DCNN`) 是各种应用的基础模型，如 `image classification`、`object detection`、`tracking` 等。

Hinton [[9](#ch09.xhtml#r9_9)] 提出了一种方法，使用 `multilayer network` 将高维数据转换为低维编码以降低数据维度。主要地，他们使用了 `restricted Boltzmann machines` 而不是随机权重初始化。Alex 和 Stskever [[10](#ch09.xhtml#r9_10)] 开发了 `deep convolutional neural networks` 用于 `ImageNet` 上 1,000 个不同类别的分类。在过去，`region-based convolutional neural networks` (`RCNNs`) 用于 `object classification` 和检测。过去四年中，使用只看一次（`yolo`）方法和 `single shot detectors` 来通过边界框进行物体的定位检测。过去 50 年来，处理海量数据并找到底层隐藏模式是一项具有挑战性的任务。从二十一世纪开始，当前研究主要集中在深度学习以解决这一问题。重点应用是 `object detection`、`social media analytics`、`spam detection` 等。

几年内，深度学习将成为许多软件应用的一部分，将能力嵌入设备中以提升客户体验。这些基于深度学习的系统在使用 `natural language processing` 理解和处理简单人类语言方面非常有用。

### 9.1.3 最新方法

Mohanty 等 [[11](#ch09.xhtml#r9_11)] 在 `plant village dataset` 上提出了 `convolution neural network`。该方法获得了 85.3% 的准确率。该方法训练数据所需时间更长，并且仅限于在均匀背景上对单片叶子进行分类。当他们在训练时使用的各种条件下拍摄的一组图像上进行测试时，模型准确率自动大幅下降。Fuentes 等 [[12](#ch09.xhtml#r9_12)] 使用了结合的元架构，如 `R-CNN` 和 `SSD` 与 `deep feature extractors`。这里，该方法的挑战部分在于考虑一个小的样本集，其中一些具有高模式变化的类别容易与其他类别混淆，导致假阳性或平均精度降低。Ferentinos [[13](#ch09.xhtml#r9_13)] 提出了 `CNN` 方法，其主要缺点是整个摄影材料仅包括实验设置中的图像，而不包括种植田间的真实条件。另一个需要注意并应解决的重要问题是，用于评估模型的测试数据集是构成训练集的同一数据库的一部分。Bhatt 等 [[14](#ch09.xhtml#r9_14)] 应用了一个模型，该模型使用少量图像进行训练和评估，模型具有不同的分辨率，如质量、焦点和亮度，因为它们是通过参与式感知方法使用不同摄像头的手机捕获的。他们在茶叶中使用了 `single shot detection` 的应用，有助于通过自动化减少病虫害的检测时间。从这些结果还可以看出，仅分类在单张图像中出现多种害虫和疾病状况时无法可靠地提供帮助。Anandakrishnan 和 Hanson [[15](#ch09.xhtml#r9_15)] 提出了基于深度学习的 `CNN` 方法，使用苹果叶病数据集图像，该数据集包括在田间条件下拍摄的图像以及实验室图像数据集。通过该方法，获得的准确率仅限于 78.80。Durmuş 等 [[16](#ch09.xhtml#r9_16)] 应用了一种方法来提高 `GoogLeNet` 和 `cifar-10` 模型在检测植物病害方面的准确率并减少参数。在此方法中，这里使用的激活函数是 `ReLU`。`GoogLeNet` 的准确率为 98.9，而 `cifar` 模型的平均准确率为 98.9。他们使用了较少现有图像的数据集以及通过旋转和翻转操作增强的数据集。在此方法中，他们使用了 3,060 张图像的数据集，其中 80% 用于训练，20% 用于测试。该方法使用了 `pooling`，该操作使准确率提高了 5%。
