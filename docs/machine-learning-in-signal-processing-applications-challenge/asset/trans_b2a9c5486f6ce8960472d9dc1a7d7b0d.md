
## 2.5 无监督学习

在无监督学习过程中，系统没有具体的数据集，大多数问题的结果在很大程度上是未知的。用简单的术语来说，AI 系统和机器学习目标在运行中是“盲”的。系统拥有无懈可击且庞大的逻辑运算来引导其进行，但缺乏适当的输入和输出算法使得过程更加具有挑战性。尽管整个过程听起来不可思议，但无监督学习能够通过输入数据和存在于所有计算机系统中的二进制逻辑机制来解释并找到无限量数据的解决方案，如[图 2.6](#ch02.xhtml#f2_6)所示。系统完全没有参考数据。

既然我们期望读者现在对无监督学习有一个基本的概念，那么通过举例使理解更简单是恰当的。只需考虑我们有一张数字图像，其上有多样化的彩色几何形状。这些几何形状需要根据颜色和其他分类特征进行分组匹配。对于遵循监督学习的系统来说，整个过程有点太简单了。

该过程极其直接，因为你只需要教会计算机有关图形的所有细节。你可以让系统知道所有四边形被称为正方形，八边形被称为八边形等。我们还可以教会系统解释颜色并查看发出的光是如何分类的。

## 2.7 强化学习

该机器学习算法是一种学习技术，它通过执行动作与当前环境协作并发现错误或奖励。探索搜索和延迟奖励是强化学习的两个最重要的特征。强化学习是一种机器学习技术，使智能体能够在交互环境中通过试错，利用自身行为和经验的反馈进行学习 \[[25](#ch02.xhtml#r2_25),[26](#ch02.xhtml#r2_26)\]。

尽管监督学习和强化学习都使用输入和输出之间的映射，但与监督学习不同，后者向智能体提供的反馈是执行任务的正确动作集合，强化学习则使用奖励和惩罚作为正面和负面行为的信号。

与无监督学习相比，强化学习在目标上有所不同。虽然无监督学习的目标是找到数据点之间的相似性和差异，但在强化学习中，目标是找到一个合适的动作模型，以最大化智能体的总累积奖励。[图 2.10](#ch02.xhtml#f2_10) 表示了强化学习模型涉及的基本思想和要素。

### 2.8.1 特征和分类器

前述的人工分类任务概述了大量模式识别问题背后的原理。用于分类的测量值，在本例中为均值和标准差，被称为特征。在更一般的情况下，使用 `l` 个特征 `x[i]`，`i` = 1, 2, …, `l`，它们形成特征向量

`x = [x[1], x[2],..., x[l]]^(T)`

每个特征向量唯一标识一个模式 \[[27](#ch02.xhtml#r2_27)\]。在本课程中，特征和特征向量将分别被视为随机变量和向量。不同模式产生的测量值表现出随机变化。这部分是由于测量设备的测量噪声，部分是由于每个模式的独特特征。这就是前一图中每个类别中点散布的原因。该图中的直线被称为决策线，它构成了分类器，其作用是将特征空间划分为对应于类别 ◦ 或类别 + 的区域。

如果对应于未知模式的特征向量 `x` 落在类别 ◦ 区域，则将其分类为类别 ◦，否则分类为类别 +。这并不一定意味着决策是正确的。如果不正确，则发生了误分类。为了在前一图中绘制直线，我们利用了我们知道图中每个点的标签（类别 ◦ 或 +）这一事实。真实类别已知且用于设计分类器的模式（特征向量）被称为训练模式（训练特征向量）

在概述了定义和原理之后，让我们指出分类任务中出现的基本问题：

* 特征是如何生成的？
* 使用多少个特征 `l` 最合适？
* 在采用了适当的特征后，如何设计分类器？（最优性准则）。
* 一旦分类器设计完成，如何评估所设计分类器的性能？（分类错误率）。
