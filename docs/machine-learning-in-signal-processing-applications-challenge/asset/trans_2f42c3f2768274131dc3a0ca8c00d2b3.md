
存在于 `Python` 中的不同模块允许对音频频率进行分析和映射到频谱图图像 \[[139](#ch05.xhtml#r5_139)\]，如 [图 5.13](#ch05.xhtml#f5_13) 所示。 该方法着眼于音乐信号的不同部分，如节拍、人声和乐器。 这些类别共同构成音频信号，并且可以通过对信号数据的分析检测到。 一些模块如 `Librosa` 还提供分离音频信号不同特征的能力，有助于以不同的方式转换频谱图。 音乐识别工具的进步允许调整音频信号的不同变量和参数，使视觉表现更加突出。 处理图形和音频也非常消耗资源，这要求生成和解释它们的工具具有更好的效率。 一些研究集中于优化框架，以帮助在性能和准确性之间取得平衡。

频谱图分析只是一种可以处理和观察音频信号的方法。 该领域受益于基于音频和图像的研究，这意味着随着更好方法的出现，它将得到改进。 频谱图也被证明在音乐流派识别中很有用，而该领域目前仍依赖人工协助。 高精度图形中持续出现显著差异，表明原始音频文件的细微变化会导致不同的视觉效果。 然而，常见特征可以通过该方法 \[[140](#ch05.xhtml#r5_140)\] 轻松检测，从而实现信号在更高层面的匹配。

频谱图分析中的主要问题是音频信号中的噪声 \[[141](#ch05.xhtml#r5_141)\]。 错误率略有增加，使得像语音识别工具这样的应用难以准确。 机器学习可以帮助检测和减少噪声，但对其完善的研究仍在进行中。 音频信号的人类感知匹配似乎是不可能的，尤其是考虑到噪声的减少是完全主观的。 频谱图分析有可能实现语音分离并增强所得信号。

### 5.5.3 基于小波的特征提取

音频信号中的模式识别可以应用特征提取方法。 基于小波的方法可以同时定位数据的时域和频域，便于识别有用的模式。 在神经网络中，该方法可以与前向选择相结合，即数据变量一次一个地添加到模型中。 \[[142](#ch05.xhtml#r5_142)\] 指出了一种使用离散小波变换 (`DWT`) 应用此类特征提取的方法。 要求是计算信号的子带码。 这种方法被证明更加高效和快速。 音频信号的声学特征决定了获取特征的方法。 这些特征适用于音频信号的分类，尤其是在音乐文件中。 梅尔频率倒谱系数也是音频信号的重要参数，其成功主要体现在语音识别方面。 在转换后的音频信号上应用 `support vector machines` 可进行机器学习训练，提高结果准确性。

在完善分析结果时，音频信号频率上的短期特征是适用的 \[[143](#ch05.xhtml#r5_143)\]。 这些特征包括频谱熵、能量熵、能量、频谱扩展和谐波比等。 提取此类特征已被证明会针对某些声音产生歧视，这使得它们在确定信号性质方面不准确。 在音频文件指纹识别中的实现显示了使用 `DWT` 过程的成功 \[[144](#ch05.xhtml#r5_144)\]。 在这种情况下，研究人员将统计学与音频信号处理相结合，以寻找定义信号的独特特征。 尽管不同类型的音频编码会丢失一些信息，但该过程在每次创建唯一指纹方面显示出很大潜力。 特征提取技术的可靠性也更高，但结果需要通过进一步的技术来增强，例如应用滤波器、采样信号和减少存在的噪声。 压缩音频文件也有其局限性，随着音频质量下降，准确性降低。

感知小波包过程通过在分割信号后对变换进行滤波，并在提取有意义参数后计算必要的系数来处理特征提取，如 [图 5.14](#ch05.xhtml#f5_14) 所示 \[[145](#ch05.xhtml#r5_145)\]。 高通和低通滤波器保留了分析所需的组件。 基于该技术的算法被证明比传统比较有效得多。 该技术能够处理嘈杂信号中的成功降噪或识别。 该方法的性能要好得多，并且可以通过调整参数进一步改进。 用于音频分析的基于小波的特征提取工具数量不断增加，`Python` 可通过可用模块访问。 这些模块的准确性和性能各不相同，但总体结果表明该技术具有光明的前景。 用于 `support vector machines` 的多项式核在语音识别中显示出更高的准确性。 这表明音频和语音分析相关的工作距离完美还有很长的路要走，但该领域的研究正在稳步改善结果。 与自学习算法和机器学习的结合正在创造更好的工具和技术。

### 5.5.4 当前方法

#### 5.5.4.1 音频分类

研究人员最近已将深度学习方法应用于音频文件分类。 这一过程可以通过构建针对音频信号的分类模型来实现 \[[146](#ch05.xhtml#r5_146)\]。 该过程涉及使用 `CNN` 模型，由于它们是为自然图像设计的，因此需要修改。 音频图像中的时间因素使得传统 `CNN` 模型难以工作。 训练好的 `ImageNet` 分类模型的结果显示出高准确性，尤其是在实际音频使用前进行训练时。 此外，微调显示出获得更准确结果的更好前景。
