
### 1. 光学性能监测 (OPM)
`OPM` 可以被描述为新兴软件定义网络领域的主要使能技术。通过使用 `OPMs`，`SDNs` 可能能够监测当前网络状况以及动态配置各种收发器和网络元素参数，例如频谱分配、发射功率、波特率、调制格式以及前向纠错 (`FEC`) 编码以实现最佳传输性能 [[2](#ch10.xhtml#r10_2), [3](#ch10.xhtml#r10_3) 和 [4](#ch10.xhtml#r10_4)]。最近基于 `ML` 的 `OPM` 技术因其为光网络设计一种具有成本效益的多损伤监测技术而变得流行。其中一些流行技术包括人工神经网络 (`ANNs`) [[5](#ch10.xhtml#r10_5),[34](#ch10.xhtml#r10_34)]、主成分分析 (`PCA`) [[6](#ch10.xhtml#r10_6),[7](#ch10.xhtml#r10_7)]、支持向量机 (`SVM`) [[8](#ch10.xhtml#r10_8)]、深度神经网络 (`DNNs`) [[9](#ch10.xhtml#r10_9),[10](#ch10.xhtml#r10_10)] 和基于核的方法 [[11](#ch10.xhtml#r10_11)]。

### 2. 光纤非线性缓解
基于 `ML` 的算法非常适用于补偿光纤非线性失真。该技术主要基于从观测数据中学习非线性损伤可能出现的各种特征和属性，并从这些损伤中构建各种概率模型，这些模型可用于提供对这些损伤的补偿或量化引入的损坏程度。一些基于 `ML` 的非线性补偿技术基于极限学习机 (`ELM`) [[12](#ch10.xhtml#r10_12)]、随机反向传播 (`SBP`) [[13](#ch10.xhtml#r10_13)]、期望最大化 (`EM`) 算法 [[14](#ch10.xhtml#r10_14)]、高阶统计均衡器 [[15](#ch10.xhtml#r10_15)] 和 `M`-ary `SVM` [[16](#ch10.xhtml#r10_16)] 基于的方法。

### 3. 主动故障检测/预防
*任何* 给定光网络的可靠运行都需要一个强制系统来生成早期预警以及将主动保护工作模型纳入网络。近年来，研究人员提出了相当数量的基于 `ML` 的技术用于光纤网络的认知故障检测/预防，例如使用双指数平滑 (`DES`) 和 `SVM` 的组合进行网络设备故障预测或由相干接收机执行的 proactive 光纤损坏检测以识别机械应力依赖性。

### 4. 软件定义网络
*该* `ML` 技术已能够在 `SDNs` 中实现若干关键功能方面找到其应用。在文章 [[20](#ch10.xhtml#r10_20)] 中，`ANNs` 概念已与大数据分析一起用于网络流量建模。基于预测的流量量/方向，虚拟网络拓扑 (`VNT`) 具有自我重新配置的能力。与静态 `VNT` 设计方法相比，该方法已被证明在显著减少路由器所需中继器数量方面有益，从而降低了能源消耗和成本。

## 10.7 结论
本章主要讨论了针对各种信号类型的机器学习方法，即平稳信号、自相关以及线性和判别分析。它涵盖了机器识别各种信号类型所需的各种数学概念。本章随后详细讨论了关于数字信号处理及其在对携带信号的数据集进行分类方面的各种机器学习方法，这些信号代表音频和基于图像的信号或其他光通信，以及它们在各个行业中的贡献。
