### 6.4.6 安全与认证

本节回顾文献中描述的不同安全和认证方面。如果将 BCI 运行阶段视为 BCI 循环，我们就需要分析影响这些阶段或 BCI 循环的安全攻击。安全系统中使用了基于知识、基于对象和/或基于生物特征的认证。此外，还需要讨论其影响和对策。像简单的易受攻击的密码、通过设备监视用户、盗窃滥用以及生物特征的故意且可重复的扭曲一样，它们已被证明存在许多缺点 \[[64](#ch06.xhtml#r6_64)\]。认知生物特征或电生理学，其中以最真实的方式使用生物信号作为经过验证事实的来源，为这些漏洞提供了解决方案 \[[65](#ch06.xhtml#r6_65) 和 [66](#ch06.xhtml#r6_66)\]。现有的大部分文献仅考虑信号采集过程，忽略了神经元的刺激。

探索电生理学可行性的背后诱因在于，生物信号不能被外部观察者随意获取。此外，它们对缺乏相应身体特征的受损患者用户可能具有极大的益处。这使得某些信号难以合成，从而增加了生物识别系统对欺骗攻击的抵抗力。除了脑电图（EEG）\[[67](#ch06.xhtml#r6_67)\]之外，当合法用户处于外部压力情况下时，可以将隐蔽警报作为生物特征模态发送。这里所述的保护一词是指为确保完整性、保密性和可访问性，防止信息和信息系统未经授权的访问、使用、披露、中断、修改或破坏。

众多研究已考虑将动作产生的 EEG 信号作为智能驾驶系统的一部分进行认证 \[[68](#ch06.xhtml#r6_68) 和 [69](#ch06.xhtml#r6_69)\]。为了按需检查驾驶员身份，研究人员使用了在心理任务条件下进行简化驾驶的模拟器。无意识驾驶员的认证对于分析和讨论是必要的 \[[70](#ch06.xhtml#r6_70)\]。

有用于监测脑信号的有创和无创方法。任何基于 BCI 的设备中最重要的添加物之一是测量大脑产生的振荡。它显示了用户当前行为产生的自愿神经运动。\[[115](#ch06.xhtml#r6_115)\] 中研究了不同的信号采集技术。BCI 的应用及其预期用户类别决定了获取信号的正确方法及其可观察的测量真实性。

### 6.5.1 有创技术

在头皮下方，侵入性记录方法插入电极。在有创技术中，方法通过 `electrocorticography`（ECoG）以及皮层内记录来实现并进行检查。电极通过神经外科植入到人脑内部或大脑表面。来自运动皮层的皮层内或皮层表面的大脑神经活动可以被排序。它们的主要优势在于具有高时间分辨率和空间分辨率，提高了接收到的出色信号和信噪比。

尽管如此，这些方法仍存在若干问题。除了由于手术护理存在而产生的可用性问题外，系统输出方面也存在问题。其中之一是这些植入物控制的大脑区域尺寸很小。添加后，它们不会在其他任何领域转化为精神活动的度量。其次，新身体的适应可能会引发医疗并发症，也可能失败。与植入物稳定性和防止感染相关的问题也可能增加。因此，侵入性真实世界记录传统上仅限于为少数不利人群提供的基于 BCI 的医疗子系统 \[[72](#ch06.xhtml#r6_72)\]。

在利用猴子的 BCI 系统研究中，与 He 等人 \[[73](#ch06.xhtml#r6_73)\] 一致，也尝试了有创系统。少数患有 `tetraplegia`（由损伤引起的瘫痪）的患者使用了植入电极。这里给出了有创方法的资料。

#### 6.5.1.1 皮层内

Hochberg 等人 \[[74](#ch06.xhtml#r6_74)\] 展示的最有创技术是皮层内采集过程。植入电极阵列到大脑的手术技术需要使用皮层内电极阵列进行皮层内刺激以评估大脑电活动。它种植在大脑皮层表面之下。与仅尝试从大脑表面进行相比，皮层内刺激电极更深入大脑以更有效地激活初级视觉皮层，这可能导致不需要的视觉信号、不适，甚至对神经组织的损伤。可以单电极或一系列电极来执行它，测量单个神经元的运动信号。由于其特别高的空间分辨率，其在源定位问题中的使用得到了广泛鼓励。然而，皮层内采集应伴随长期信号变异。这可能是由于细胞死亡或组织电阻升高所致。此外，如果设备需要可检测的变化来触发残疾的腿或肢体，这种额外的刺激也可能产生主要的噪声效应 \[[73](#ch06.xhtml#r6_73)\]。

慢皮层电位（SCPs）的自我调节最初源于动物实验。在皮层内有创采集中，主要是大鼠和猴子在 BCI 研究中被广泛使用。提取的记录有助于估计运动意图并实现训练算法以进行自适应运动预测。研究人员成功帮助猴子使用真正的机械臂进食 \[[72](#ch06.xhtml#r6_72)\]。
