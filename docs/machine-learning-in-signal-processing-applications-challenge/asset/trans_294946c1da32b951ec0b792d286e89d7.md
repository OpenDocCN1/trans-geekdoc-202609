
# 概率的数学框架

考虑到概率的数学框架，有重要的理论和公理是必需的，以便充分利用该理论作为机器学习的工具。概率的概念主要关乎各种结果的可能性。这里，所有可行结果的集合称为 **样本空间**。例如，抛硬币的样本空间是 {正面，反面}，或水的温度是在冰点和沸点之间可能出现的每个值。在任何给定时间，只有被考虑的样本空间中的一个结果是可能的 [[17](#ch10.xhtml#r10_17)]。

这里，事件 `ω` 的概率为 `P(ω)`。

`Ω`（大写欧米伽）是样本空间

`ω`（小写欧米伽）是特定结果。

概率的两个基本公理可定义如下：

* `0 ≤ P(ω) ≤ 1`
* `∑_{ω} P(ω) = 1`

根据给定规则，任何给定事件发生的概率必须介于 0（即不可能）和 1（对应于必然）之间，且所有事件的概率之和应为 1。该公理可进一步扩展为样本空间必须包含所有可能的结果。因此，某个可能结果的发生是相当确定的（概率为 1）。

## 随机变量

任何 **随机变量**（`x`）可定义为从所考虑的样本空间中随机选取任何值的变量。例如，假设 `x` 表示抛硬币的结果，它可以定义为持有特定结果 `x` = 正面/反面。

随机变量可以取离散值，如硬币结果，或连续值，即在某个范围内有无限多个可能结果。

为了定义给定随机变量 `x` 的每个可能取值的机会，可以指定一个 **概率分布**。这里随机变量（`x`）可定义为 `x ~ P(x)`，表示它是从概率分布 `P(x)` 中抽取的随机数。这里的概率分布因子根据随机变量是离散还是连续而有不同的描述 [[18](#ch10.xhtml#r10_18),[19](#ch10.xhtml#r10_19)]。

### 离散分布

离散随机变量可以用 **概率质量函数**（PMF）来定义，它将所考虑变量样本空间内的每个值映射到概率。例如，在 `n` 个可能结果上的均匀分布：`P(x = x) = 1/n`。

这可以计算为“`x` 取值为 `x` 的概率是可能值的数量的倒数 1。”它被称为均匀分布，因为每个结果具有相同的可能性（结果的可能性在所有可能值上均匀分布）。这里，公平骰子的掷骰由均匀分布建模，因为骰子的每个面都有相同的出现机会。 loaded die 用分类分布建模，如 [图 10.3](#ch10.xhtml#f10_3) 所示，其中每个结果都附带不同的概率。

### 连续分布

连续随机变量由 **概率密度函数**（PDFs）定义，如 [图 10.4](#ch10.xhtml#f10_4) 所示图形表示，对于随机变量 `x` 表示为 `f(x)`。PDFs 可以将任何给定的无限样本空间映射到相对可能的输出值。例如，通常称为钟形曲线的 Gaussian（正态）分布主要用于模拟各种自然事件，如每个性别的身高，其近似服从高斯分布。这里使用的两个主要参数是 ***均值*** `μ`（mu）和 ***方差*** `σ²`（sigma squared）。均值可定义为分布的中心，而方差指定分布的宽度 [[20](#ch10.xhtml#r10_20)]。

其他因素如标准差 `σ` 可定义为方差的平方根。为了表示 `x` 是从均值为 `μ`、方差为 `σ²` 的高斯分布中抽取的随机变量，我们可以写成：

`X ~ N(μ, σ²)`

其中，

`X` 从均值为 `μ`、方差为 `σ²` 的正态分布中抽取。

PDF 的函数形式定义为

```
f(x | μ, σ²) = 1/√(2πσ²) e^{-(x - μ)²/(2σ²)}
```

(10.1)

其中

`x` 的 PDF 由 `μ` 和 `σ²` 给出。

在任何情况下，所有可能发生的概率之和都必须为 1。如何计算范围内无限多个值的总和这一主要挑战可以通过采用微积分的方法和概念以积分形式解决，可重写为：

`∫[Ω] f(x) dx = 1`

(10.2)

这里，PDF 的积分，即在样本空间上计算的曲线下面积为 1，这可以进一步描述为在无限值范围内计算的广义求和。因此，PDF 下的面积对应于高斯分布的总概率 [[21](#ch10.xhtml#r10_21)]。

### 联合概率分布

联合概率分布的概念可以解释为覆盖多个随机变量的分布，这些随机变量可以定义为向量 `x`。定义在 `x` 上的联合分布指定了考虑到 `x` 中存在的所有随机变量的特定值设置的概率，例如，对于两个给定的随机变量 `x` 和 `y`，联合概率因子可定义为（[图 10.5](#ch10.xhtml#f10_5)）：

`P(x = x, y = y)` or just `P(x, y)`.

对于定义在概率空间上的任意给定随机变量 `X`、`Y`、…，测量的联合概率分布是提供概率的概率分布，其中每个值可归类于特定范围或为该变量分类的离散值集合。对于两个随机变量，它是二元分布，而推广到任意数量的随机变量时，它给出多元分布 [[17](#ch10.xhtml#r10_17)]。

### 边缘概率分布

边缘概率分布情况下的求和规则可定义为：

`P(x) = Σ_y P(x, y)`

这里，项 `P(x)` 可定义为 **边缘概率分布**。例如，确定在各种季节选项范围内穿连帽衫的概率的计算是：

我会穿连帽衫，`P(Hoodie) = P(Hoodie, Sunny) + P(Hoodie, Cloudy) + P(Hoodie, Rainy) = 3/9`。相同的计算概念可用于在所有天气条件下找到所有衣物品种的边缘概率。

### 条件概率分布

给定 `y` 时 `x` 的 **条件概率分布** 可定义为

`P(x|y) = P(x, y)/P(y)`

这里，在观察到 `y` 之后对 `x` 的条件概率，即在观察为 `y = y` 的情况下，计算为 `x = x` 的概率是 `P(x, y)/P(Y)` [[18](#ch10.xhtml#r10_18)]。

条件概率仅在 `P(y) > 0` 的情况下存在。在 `y` 不可能发生的情况下，从一开始就没有 `y` 的观察。

将上一个等式的两边乘以 `P(y)`，可以得到概率的 **链式法则** 为 `P(x|y) = P(x, y) ⋅ P(y)`。

链式法则可用于假设任意数量随机变量的联合分布：`P(x, y, z) = P(x|y, z) ⋅ P(y, z) = P(x|y, z) ⋅ P(y|z) ⋅ P(z)`。

### 贝叶斯规则

两个变量的链式法则可以写成两种等价形式：

* `P(x, y) = P(x|y) ⋅ P(y)`
