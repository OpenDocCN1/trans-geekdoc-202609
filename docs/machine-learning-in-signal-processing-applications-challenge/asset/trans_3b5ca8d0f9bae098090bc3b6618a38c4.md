
In general, a `NN` is a system that is implemented to operate the way in which the brain performs a particular task. The `NN` is usually designed by using electronic components or is simulated using software on a digital computer. The complexity of `ANN` is much lesser when compared to the complexity of the brain. But there are two key similarities between `ANN` and biological `NN`. First, building blocks of both the networks are computational devices called neurons, which are highly interconnected. Interneuron connection strengths (called as synaptic weights) are used to keep a record of acquired information. Second, knowledge is acquired by both the networks from its environment through a learning process. Learning algorithm (i.e., procedure used for the learning process) modifies the synaptic weights of the inter-connected network in a required manner to achieve a required design objective \[[8](#ch07.xhtml#r7_8), [9](#ch07.xhtml#r7_9) and [10](#ch07.xhtml#r7_10)\]. The modification of synaptic weights is the traditional method for the design of `ANN`. Such an approach is similar to adaptive filter theory, which is already well developed and successfully applied in many fields. `NN` are also called connectionist networks, neurocomputers, parallel distributed processors, etc.

Any `NN` consists of the following basic layers:
1.  `Input Layer`: 它由人工神经元组成，这些神经元从物理世界获取输入，`NN` 将基于此学习或处理信息以产生所需结果。
2.  `Hidden Layer`: 它位于输入层和输出层之间。可以有多个隐藏层来处理从输入层接收到的输入数据。
3.  `Output Layer`: 隐藏层处理后的数据在输出层可用。输出层位于输入层和隐藏层之间（[图 7.12](#ch07.xhtml#f7_12)）。

![图 7.12 神经网络架构。](images/Fig07_12.jpg)

`ANN` 还可以表示为加权有向图，其中人工神经元对应于节点，不同层之间节点间的互连对应于具有权重的有向边。`ANN` 以模式、流和图像的向量形式从外部世界获取信息。每个输入都乘以其对应的权重。通常，权重表示 `NN` 内部人工神经元之间互连的强度，并由 `NN` 用于实现所需目标。加权输入全部在计算单元中累积。如果加权和为零，则添加偏置以使输出非零或放大系统响应。偏置的权重和输入始终等于“1”。该和可以在 0 到 ∞ 之间的任何值 \[[10](#ch07.xhtml#r7_10), [11](#ch07.xhtml#r7_11), [12](#ch07.xhtml#r7_12), [13](#ch07.xhtml#r7_13) and [14](#ch07.xhtml#r7_14)\]。

为了获得所需输出，激活函数被设为传递函数。激活函数可以是线性的或非线性的。常用的激活函数有 binary、sigmoidal（线性）和 tan hyperbolic sigmoidal 函数（非线性）（[图 7.13](#ch07.xhtml#f7_13)）。

`ANN` 的常用训练算法如下：
*   `Hebbian Learning Rule`
*   `Self-Organizing Kohonen Rule`
*   `Hopfield Network Law`
*   `LMS` (最小均方) 算法
*   `Competitive Learning`

### 7.5.1 ANN 中的学习技术
*   `Supervised Learning`：在监督学习中，训练数据作为输入馈送到网络，其中预期输出是已知的。权重会不断更新，直到算法产生所需值。
*   `Unsupervised Learning`：这种类型的学习是在无监督的情况下进行的，这意味着环境不会提供反馈来指示所需输出是什么以及是否正确。
*   `Offline Learning`：只有在整个训练集都输入到 `NN` 后，权重向量和阈值才会被调整。它也称为批学习。
*   `Online Learning`：在每次将训练样本输入到 `NN` 后，权重向量和阈值都会被调整。
*   `Reinforcement Learning`：输出的值未知，但 `NN` 提供反馈以帮助检查输出是否正确。它也称为半监督学习。

## 7.6 单层和多层神经网络
单层和多层神经网络是两类网络架构。`NN` 的组织方式直接与用于训练 `NN` 的学习方法相关联。

### 7.6.1 单层神经网络
它是 `NN` 的最简单形式，仅包含一层输入节点，该层将加权输入转发到下一层接收节点。`Perceptron` 和单层二值线性分类器是单层神经网络的早期示例。在单层 `NN` 中，信息仅沿从输入到输出的方向移动。因此，单层神经网络也可以视为 `feedforward neural networks` 的一部分（[图 7.14](#ch07.xhtml#f7_14)）。

![图 7.14 单层神经网络。](images/Fig07_14.jpg)

[`FIGURE 7.14`](#ch07.xhtml#f7_14b) 单层神经网络。

### 7.6.2 多层神经网络
多层神经网络在输入层和输出层之间使用隐藏层来处理非线性输入集。从几何角度看，额外的隐藏层被称为额外的超平面，以提高神经网络的计算能力。[图 7.15](#ch07.xhtml#f7_15) 显示了典型的多层网络架构。

![图 7.15 多层神经网络架构。](images/Fig07_15.jpg)

[`FIGURE 7.15`](#ch07.xhtml#f7_15b) 多层神经网络架构。

多层神经网络也称为“`multilayer perceptron`”（`MLP`），它是 `feedforward artificial neural network` 的典型示例。多层神经网络使用 `back propagation algorithm` 进行训练。特定层中的每个人工神经元都与后续层中的所有神经元相连。分配给链接的权重系数显示了该连接在神经网络工作中的重要性。

多层神经网络有两种模式：训练模式和预测模式。训练集和测试集是两个数据集，它们对于多层 `NN` 的训练以及使用多层神经网络进行预测是必要的。在训练开始时，连接的权重被赋予随机值。然后，多层 `NN` 递归进行。完整训练集的每次迭代称为一个 `epoch`。每个 `epoch` 的目标是减少误差。随着权重调整的递归过程进行，权重会缓慢收敛到一组最优值。对于给定的训练集，完成训练需要许多 `epochs`。`Back-propagation algorithm` 用于更新权重 \[[15](#ch07.xhtml#r7_15), [16](#ch07.xhtml#r7_16), [17](#ch07.xhtml#r7_17), [18](#ch07.xhtml#r7_18), [19](#ch07.xhtml#r7_19) and [20](#ch07.xhtml#r7_20)\]。
