
数字信号处理的概念在技术上可以用于对基因组序列进行比较分析，以比较基因组学为背景，因为基因组序列可以作为离散的数字序列在数字信号方面进行数值通信。已在各种文献中提出了大量DNA序列的数学表示方法，这些方法使用附加到单个核苷酸的数字，例如，数字信号处理（DSP）可以在比较基因组学的背景下使用，因为基因组序列可以被数值表示为离散的数值序列，如[表10.1](#ch10.xhtml#t10_1)所示，因此可被视为数字信号。许多研究人员提出了大量采用附加到单个核苷酸的数字的DNA序列数值表示方法[[28](#ch10.xhtml#r10_28)]，例如，从每个核苷酸到随机数字的固定映射创建的DNA测序数字，该数字不具有生物学意义，即使用从其理化性质推导出的核苷酸到数值值的映射或从其起源的双联体或密码子中提取的映射[[28](#ch10.xhtml#r10_28),[29](#ch10.xhtml#r10_29)]。各种研究人员声称，表示的数值选择对所获得的结果几乎没有显著影响。研究人员随后对小数据集上各种数值表示技术进行了比较研究[[32](#ch10.xhtml#r10_32)]。此外，他们得出的结论是，多维表示（如混沌游戏表示）产生的基因组比较结果优于任何单维数据表示[[36](#ch10.xhtml#r10_36)]。

数字信号处理通常遵循选择合适的DNA序列数值表示形式，该形式可通过称为基因组信号处理（GSP）的过程应用于输出离散数值序列[[29](#ch10.xhtml#r10_29)]。DSP的应用领域是DNA序列比较，即区分编码区和非编码区[[33](#ch10.xhtml#r10_33),[35](#ch10.xhtml#r10_35),[36](#ch10.xhtml#r10_36)]，将基因组信号映射用于生物序列分类[[37](#ch10.xhtml#r10_37)]，用于全基因组系统发育分析以及分析基因组序列的其他特性[[37](#ch10.xhtml#r10_37)]。

## 10.5 基于信号识别的机器学习方法应用

机器学习技术已在各个行业中用于基于其各种特征和特性的信号分类，具体讨论如下。

### 10.5.1 机器学习用于音频分类

多媒体技术的最新发展趋势引发了对音频信号分类的需求，以便提供更有效、更准确且易于处理庞大数据库的内容检索过程。音频信息在把握多媒体的整体概念内容方面发挥着至关重要的作用。随着数据量的快速增长，对过滤所需数据以及存储更多相关数据的过程进行自动化存在需求。此收集的音频数据可用于获取重要信息以及为视频索引和内容分析等过程请求结果。人的耳朵只需聆听音频信号的一小段即可感知并区分各种音频信号类型，但在考虑的声音较弱或伴有噪声因素时则面临挑战[[31](#ch10.xhtml#r10_31)]。为机器制定此类挑战的解决方案已被证明极具挑战性，其中最困难的问题是执行自动分类。使用计算机解决此问题已被证明非常困难。该领域的一个主要挑战是音频信号的自动分类。目前，音频信号分类是吸引许多热心研究人员兴趣的热门技术之一，使其变得非常流行，已在媒体服务、搜索引擎和智能人机系统中找到了其应用领域[[33](#ch10.xhtml#r10_33)]。

音频分类可被认为很重要，原因如下：

1. 不同质量和类型的音频需要不同的处理要求。
2. 由于音频被分布到基于其质量的各个子类中，检索任何特定音频数据的搜索空间已显著减少。

每个分类的音频片段都可以唯一地处理和索引，以便进一步比较和检索有效。

使用机器学习方法用于分类过程的从给定音频信号中提取的各种特征为[[29](#ch10.xhtml#r10_29)]以下：

1. **采样频率或速率**：在固定时间跨度内考虑的样本数量的速率。
2. **振幅**：在所考虑的时间段内声波变化的量度。
3. **傅里叶变换**：将时间/信号的函数分解为其构成的频率，即底层函数中存在的每个频率的振幅。
4. **功率谱**：它描述功率在离散频率分量中的分布。
5. **倒谱**：它是通过考虑信号估计功率谱的对数的傅里叶变换计算得出的。
6. **频谱图**：它是信号频率谱随时间变化的视觉表示。
7. **耳蜗**：这是位于人耳内部的螺旋腔，包含柯蒂器官。它对声音振动产生神经冲动响应。
