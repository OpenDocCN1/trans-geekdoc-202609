## 5.3.1 词嵌入

在最近十年中，词嵌入 \[[48](#ch05.xhtml#r5_48),[49](#ch05.xhtml#r5_49)\] 已确立为众多 NLP 框架的核心组件。毫无疑问，NLP 技术处理的是自然语言，通常以文本形式出现。这种内容本身由更小的单元如词和字符组成，这些单元对计算机而言在任何人类意义上都不是直接可理解的。因此，词嵌入被期望以数学方式表示文学信息，使其能够被计算机程序读取、理解和处理。这一需求随着深度学习的爆发而得到强调，深度学习证明可以解决不同领域的大量问题。

NLP 研究人员 \[[55](#ch05.xhtml#r5_55)\] 需要将有前景的深度学习模型应用于文本数据，需要想出一种数学方法来表示词。这导致了广泛的研究，以最佳方式表示印刷信息，使描述能够捕捉词的语义和句法含义。实际上，用向量表示一个词有几种不同的方法。最简单的一种可能是独热编码。

### 5.3.1.1 Word2vec

`Word2vec` 模型由 Mikolov 等 \[[56](#ch05.xhtml#r5_56)\] 提出。其思想是将一个词转换为一个连续向量，该向量还表示词的局部上下文。`Word2vec` 的嵌入没有独热编码词向量的不足，后者只能识别一个词是否完全相同。`Word2vec` \[[57](#ch05.xhtml#r5_57)\] 通过包含词的前驱和替代词使这些区分更具体。

词表示包含语义和句法信息，这些信息是从上下文词中恢复的。[图 5.3](#ch05.xhtml#f5_3) 展示了二维空间中词向量的分布。箭头显示了两个词之间的数值距离。例如，余弦距离是计算词向量差异的合适度量。在嵌入空间中，词之间的等价关系可以用相似的距离和方向来表示。例如，英语单词 “man” 和 “woman” 与 “king” 和 “queen” 具有可比的距离。这意味着 “man” 与 “woman” 之间的逻辑差异等于 “king” 与 “queen” 之间的差异。与男性性别相关的词与 “man” 和 “king” 一起使用，而 “woman” 和 “queen” 则被更多女性词结构所包围。因此，词的语法结构和语义被整合到词表示中。这就是词嵌入或 `Word2vec` 的真正优势。它使找到等价词并更轻松地把握说话者的意图变得更容易。

![图 5.3 箭头显示二维空间中两个词嵌入之间的距离。](images/Fig05_03.jpg)

[`FIGURE 5.3`](#ch05.xhtml#f5_3b) 箭头显示二维空间中两个词嵌入之间的距离。

`Word2vec` 的原始论文提出了两种从包含 `N` 个词表的文本语料中学习词向量的不同方法。第一种方法是连续词袋 (`CBOW`)，它根据其唯一上下文预测一个词。随后的方法称为 `Skip-gram` \[[58](#ch05.xhtml#r5_58)\]，它估计词的唯一上下文。这两种方法限制了计算复杂性并依赖于 `FNN`，它们在 [图 5.4](#ch05.xhtml#f5_4) 中展示，更详细地描述了这两个模型。

![图 5.4 CBOW 和 skip-gram 模型的 FNN 架构。](images/Fig05_04.jpg)

[`FIGURE 5.4`](#ch05.xhtml#f5_4b) CBOW 和 skip-gram 模型的 FNN 架构。

为了计算词的向量表示，`CBOW` 的神经网络将词 `wt` 左侧的上下文词 `wt−2`、`wt−1` 和右侧的 `wt+1`、`wt+2` 作为输入。该词窗口可以根据与词嵌入 `vt` 相关的局部上下文的大小进行调整。实际上，`CBOW` 的上下文窗口为 5，`Skip-gram` 为 10 是优选的1。`CBOW` 采用每个输入词的独热编码并将其传递给网络以预测目标词 `wt` 的独热编码。`FNN` 模拟输出向量中 1 的位置，这可以被视为一个分类任务。

`Skip-gram` 中使用的网络交换了输入和输出。目标词现在是输入，而 `FNN` 预测词的唯一上下文。`Skip-gram` 在小语料上产生更好的结果，而 `CBOW` 更高效，推荐用于更大的文本集。为了训练词向量 \[[57](#ch05.xhtml#r5_57),[58](#ch05.xhtml#r5_58)\]，两种方法都使用具有一个隐藏层的多层感知机。因此，网络有两个权重矩阵。第一个 `W (1)` 位于输入层和隐藏层之间。`W (2)` 是第二个网络，连接隐藏层和输出层。隐藏层的神经元数量设置为 300，两种方法在输出层都使用 softmax 激活。

## 5.3.2 词表示的全局向量

`Global Vectors for Word Representation` (`GloVe`) 采用了构建词向量的另一种方法。它们最初由 Pennington 等 \[[59](#ch05.xhtml#r5_59)\] 提出；此外，它们强调的不仅是词的局部上下文。`GloVe` 向量的训练依赖于全局词到词共现矩阵 `Xij`。该矩阵存储了两个词 `wi` 和 `wj` 在语料库中在相同上下文中出现的频率。

因此，不仅考虑了由共现矩阵决定的局部上下文，还考虑了语料库中的统计视角。首先，矩阵在一次遍历阶段构建，其中每个文本只被查看一次。由于共现结构需要大量内存来解析海量数据，只有包含至少一次共现的词组合才会被保存。
