
`MS` 的真实位置位于由 `U`、`V` 和 `W` 表示的圆的交集区域内。从该输入中提取用于 `ANN` 模型训练的输出参数。所取的输入参数为交集值，即 `U`、`V` 和 `W`，而在 `ANN` 模型的输出端，`MS` 的位置被预测。此外，`ANN` 模型通过考虑 `AOA` 测量和三个 `TOA` 测量得到了增强。三个 `TOA` 和一个 `AOA` 信息的交集给出了 `MS` 相对于 `BS` 的对齐情况。

单个 `AOA` 测量有助于找到服务 `BS` 与 `MS` 之间的角度。因此，三个 `TOA` 与 `AOA` 之间的交集作为输入提供给 `ANN`，并估计 `MS` 的位置。这些参数作为输入提供给 `ANN` 模型，作者发现所提出的算法可以减少 `NLOS` 错误并获得更精确的 `MS` 位置估计。

### 7.7.3.2 基于 ANN 的移动蜂窝网络呼叫切换管理方案
在 \[[30](#ch07.xhtml#r7_30), [31](#ch07.xhtml#r7_31), [32](#ch07.xhtml#r7_32), [33](#ch07.xhtml#r7_33) 和 [34](#ch07.xhtml#r7_34)\] 中，提出了基于 `ANN` 的切换算法，该算法具有提供更准确结果的能力。切换过程基本上是在移动台从一个小区移动到另一个小区时更换控制基站。因此，为了使通话连续，需要进行切换过程。切换必须以这样的方式启动，即没有不必要的切换，也没有通话中断。切换取决于速度特性和路径损耗，而路径损耗进一步取决于发射基站与移动台之间的距离、路径损耗指数以及 `MS` 的速度。因此，本文基于这些因素开发了一种算法。

考虑了服务基站和目标基站的信号强度以及服务基站和目标基站的业务强度。设计中选择了三层 `ANN` 模型。服务基站和目标基站的信号强度是使用结合瑞利衰落的最小二乘估计方法估计的。`ANN` 模型的输入参数为移动台来自服务基站和发射基站的信号强度、服务基站和目标基站的业务强度。根据这些参数，`ANN` 模型将决定是否需要切换。因此，切换过程在网络的适当状态下启动。

### 7.7.3.3 基于人工神经网络的混合路径损耗预测模型
在 \[[38](#ch07.xhtml#r7_38)\] 中，作者提出了一种混合的、基于误差校正的 `NN` 模型，用于预测郊区在 800 和 2,600 MHz、ECC-33、Ericsson 9999、Okumura Hata 以及 3GPP 的 TR 36.942 下的路径损耗。前馈 `ANN` 模型是通过结合经验传播模型设计的。混合模型的效率和准确性与常见类型的经验模型以及使用相关工作中常用的输入数据训练的简单 `NN` 进行了比较。最后，混合 `NN` 获得了最低的 `RMSE` 指标，除此之外，几乎使模拟数据和实验数据的分布相等，表明与测量结果具有更大的相似性。预测数据由 Ericsson 9999、Free Space、ECC-33 和 TR 36.942 模型计算得出。

实验设置在郊区，频率为 800 和 2,600 MHz。ECC-33 模型用于 2,600 MHz，而 Free Space 模型用于 800 MHz 频率；Ericsson 和 TR 36.942 覆盖了两个频段。使用经验模型的基于误差校正的 `ANN` 模型用于路径损耗预测。`ANN` 被训练以学习与预期值的偏差。误差是通过预测路径损耗与预期路径损耗之差得到的。`E = PL[measured] - PL[predicted]`。`ANN` 的输出是校正后的路径损耗。使用了具有两个输入、一个输出和一个隐藏层的前馈多层感知器类型。输入数据流由两个向量组成，每个向量有 455 个元素（在 2,600 MHz 场景中，而在 800 MHz 情况下，它由 450 个元素组成）。隐藏层和输出层使用的传递函数分别为正切-sigmoid 和线性，而训练网络所选的算法是 Levenberg-Marquardt 反向传播 \[[35](#ch07.xhtml#r7_35), [36](#ch07.xhtml#r7_36), [37](#ch07.xhtml#r7_37), [38](#ch07.xhtml#r7_38) 和 [39](#ch07.xhtml#r7_39)\]。

### 7.7.3.5 使用 ANN 的信道容量估计
由于技术的不断发展和对频谱需求的增加，无线电频谱已成为一种稀缺资源。最相关的正在开发的技术，使人们能够更有效地利用可用频谱 \[[17](#ch07.xhtml#r7_17)\] 是认知无线电 (`CR`)。认知无线电试图识别哪些频段是空闲的，哪些频段被主用户占用。设计了一个 `ANN` 系统来估计接收信号的信道容量。所获得的信息在理论上进行分析，随后通过合适的仿真方案进行验证，以识别给定频段中的可能白空间。此处的信道信息是信道容量，它是从扫描信道的 `SNR` 和发射系统与接收系统之间的距离预测的。假设在 `AWGN` 信道上进行 `QPSK` 传输和接收系统。信道带宽取为 5 KHz。通过确定带宽效率和互信息来分析该信道状态信息以识别频谱空洞。我们观察到，由 `ANN` 模型预测的信道容量可以被视为声明信道占用状态的决策参数，因为它提供了信道上带宽效率、熵 (`H`) 和互信息 (`I`) 的度量。

在本节中，我们讨论了如何将 `ANN` 应用于各种通信系统以提高系统的 `QoS`。`ANN` 可用于使通信系统学习并适应环境 \[47–49\]。随着 `ANN` 被应用于通信系统的各个优化方面，它使这些系统更具适应性和智能性。
