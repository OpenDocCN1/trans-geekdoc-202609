
**结论**：观察结果与之前相同。所需只是找到合适的 `K` 值、合适的距离评估器，而 `SNR` 变化如何并不重要。

基于这两个结果，我们意识到，无论是在频域还是时域，只要参数正确，就能获得非常好的检测精度。
