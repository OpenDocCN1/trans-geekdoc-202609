
## 第10章
介绍平稳信号、自相关以及线性与判别分析的概念。机器学习中自相关度量的思想已被明确规划为帮助在给定时间序列内滞后值与真实值之间可比性估计的循环。线性判别分析 (`LDA`)、普通判别分析 (`NDA`) 或判别函数分析，是费舍尔线性判别的一种广义形式，是一种在统计学、模式识别和人工智能中用于找到能够描述或区分两个或多个对象或事件类别的特征线性组合的策略。所得的组合还可作为线性分类器使用，或在后续分类前用于降维。本章详细讨论了固定信号、自相关以及线性与判别分析在机器学习中区分不同示例和机器中明显特征中的作用。

## 第11章
描述了一种用于旋转机电机器故障检测的智能系统。对于机电框架，可能会发生一些故障（轴承缺陷、转子棒断裂、未对准、不规则性、断裂或损坏的齿轮）。为了保证足够的可靠性和安全性，需要有效的诊断方法（特别是在缺陷出现的最早期阶段）以及监测和考虑缺陷，以避免每次停机或生产损失并减少额外维修成本。通过定子电流分析方法识别这些问题已被广泛研究和应用。在这些方法中，主成分分析 (`PCA`) 或 `MCSA`（电机电流特征分析）主要基于使用先进信号处理算法对定子电流的分析。

## 第12章
介绍用于物联网系统中数字信号分析的小波变换和机器学习技术；此外，应包含高效的数字信号分析以识别引发的不同事件。数值模型和人工智能，以及深度学习策略，是在物联网应用中执行这些数字信号分析的高效方法。因此，本章围绕与物联网视角相关的不同信号处理方法展开。此外，本章讨论了不同的机器学习和深度学习方法，以对物联网传感器设备中的事件进行分类和预测。最后，介绍了一个基于使用连续小波变换和机器学习模型预测物联网设备事件的案例分析。由于技术领域的巨大发展，物联网已与无线传感器网络 (`WSNs`)、云计算等不同技术相关联。物联网将人与可以随时随地访问的对象连接起来。物联网在每个领域都有应用。它改善了医疗保健服务，因为健康监测可以实时进行。
