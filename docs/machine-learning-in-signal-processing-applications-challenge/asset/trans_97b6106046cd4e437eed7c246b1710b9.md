### 3.5.2 分类准备

实际上，建议尝试并结合多种算法组合，以便选择最适合解决问题的方案。此过程将受到可用数据、特征和样本数量、不同类别以及它们是否线性可分等因素的很大影响。

接下来，我们将探索不同的分类算法，并学习哪一种更适合执行每项任务。

#### 3.5.2.1 逻辑回归模型

当算法在权重评估过程中无法收敛但仍合格时会出现分类问题。当线性分离不可行时，逻辑回归便被引入 [[32](#ch03.xhtml#r3_32), [33](#ch03.xhtml#r3_33) 和 [34](#ch03.xhtml#r3_34)]。为了解决二分类问题，使用逻辑回归。线性可分的类别通过 `OvR` 技术扩展到多分类。

#### 3.5.2.2 优势比

通过优势比可以更好地理解逻辑回归的概念。优势比是理解逻辑回归思想的重要概念。某事件发生的概率可由优势比得知。其可写为如下形式：

`Odds Ratio = prp/(1−prp)`

`prp` = 正事件的概率

#### 3.5.2.3 Logit 函数

`lfp = log(prp/1 − prp)`

`lfp = log(Odds Ratio)`

对数几率是对数优势比，称为 logit 函数。该函数接受 0 到 1 之间的数值，并将其从二元范围转换为从 −∞ 到 +∞ 的实数范围。对数几率与特征值之间的关系可用线性表达式表示

`logit(prp(y=1|x)) = w[0]x[0] + … + w[m]x[m] = sum(w[i]x[i]) = w[t]x`

`prp(y = 1|x)` 是给定特征 `x` 属于类别 1 的条件概率。

#### 3.5.2.4 Sigmoid 函数

Sigmoid 函数的表达式为

$$\phi\left( z \right) = \frac{1}{1 + e^{- z}}$$

该表达式通常称为 sigmoid 函数，是 logit 函数的逆。净输入用 `z` 表示 [[35](#ch03.xhtml#r3_35), [36](#ch03.xhtml#r3_36) 和 [37](#ch03.xhtml#r3_37)]。样本特征与权重的线性组合表示为

`z = w^(t)x = w[0] + w[1]x[1] + … + w[m]x[m]`

`z` 与 Ф(`z`) 的图形表示如图 [图 3.8](#ch03.xhtml#f3_8) 所示。

#### 3.5.2.6 最大间隔线

为了设置极值间隔，会添加两条平行线（间隔），并最大化到原始决策线的距离。错误或被误分类的点（错误）、间隔与线之间的点将被考虑。大间隔决策线倾向于具有较低的总体误差。换句话说，具有小间隔的模型更不容易过拟合 [[43](#ch03.xhtml#r3_43), [44](#ch03.xhtml#r3_44), [45](#ch03.xhtml#r3_45), [46](#ch03.xhtml#r3_46), [47](#ch03.xhtml#r3_47), [48](#ch03.xhtml#r3_48), [49](#ch03.xhtml#r3_49), [50](#ch03.xhtml#r3_50), [51](#ch03.xhtml#r3_51), [52](#ch03.xhtml#r3_52), [53](#ch03.xhtml#r3_53), [54](#ch03.xhtml#r3_54), [55](#ch03.xhtml#r3_55), [56](#ch03.xhtml#r3_56), [57](#ch03.xhtml#r3_57) 和 [58](#ch03.xhtml#r3_58)]。

最大化函数的计算如下：

$$\begin{array}{l} {w_{0} + w^{T}\\, x_{\text{pos}} = 1} \\ {w_{0} + w^{T}x_{\text{neg}}\,\, = - 1} \\ \end{array}$$

表达式相减得到

`⇒ w^(T)(x[pos]−x[neg])=2`

向量 w 的长度，

$$\left\| w \right\| = \sqrt{\sum\limits_{j = 1}^{m}{w^{2}{}_{j}}}$$

该过程导致间隔误差表达式

$$\frac{w^{T}\left( {x_{\text{pos}} - x_{\text{neg}}} \right)}{\left\| w \right\|} = \frac{2}{\left\| w \right\|}$$

`x[pos]` 是正超平面，`x[neg]` 是负超平面。在上述表达式中，间隔已得到改进。实际上，通过最小化倒数项可以获得二次规划的解

$$\text{Margin} = \frac{1}{2}\left\| w \right\|^{2}$$
