```python
import numpy as np
import matplotlib.pyplot as plt

X = np.array([[0,0], [0,1], [1,0], [1,1]])
Y = np.array([[01]])

# model specifications
Ni = 3; No = 1

# parameter and array initialization
trials = 100
wo = np.random.rand(No, Ni); dwo = np.zeros(wo.shape)
error1 = np.array([])
error2 = np.array([])

for trial in range(trials):
    y = 1 / (1 + np.exp(-X @ wo)) # output for all pattern
    delta = (1 - y) * (Y - y) # delta output
    # update weights with momentum
    dwo = 0.9 * dwo + delta @ X.T
    error1 = np.append(error1, np.sum((Y - y)**2))
    error2 = np.append(error2, np.sum(np.abs(Y - y) < 0.1))
```

An example curve where we show the difference between the desired and actual output of the network is shown on the left in Fig 5.1 by the blue line. The error is getting smaller, indicating that some learning takes place. The error does not reach 0, this comes from the fact that we use sigmoid function which approaches a value of 1 asymptotically. However we can introduce post-processing step in which we apply threshold function. This corresponds to the error that we calculate in the program. The corresponding learning curve is shown in orange on the left in Fig 5.1. This demonstrates that this perceptron can solve the Boolean function with post-processing step. The error function as used for training is somewhat as it shows that there is progress during learning when threshold stays constant, although the values themselves do not tell the story. The thresholded values give us some indication of how many patterns are recognized, but it would be better to check each pattern separately, which omitted to keep the program short. It is very useful to always calculate error that can be interpreted in terms of the performance that a user is looking for, which is not necessarily the loss used for gradient descent.

This is batch training, since we use the whole batch of training examples for each weight step. Let us consider the XOR function which is not linearly separable. This led to the perceptron demise in the 1970s although it was clear that multilayer layers could solve this problem. It became popular again 1986 by Rumelhardt, Hinton, and Williams.

We should now ask which functions can be approximated by multilayer perceptrons. The answer is, in principle, any. A multilayer feedforward network is a universal approximator. This means that, given enough hidden nodes, any mapping functions can be approximated by these networks. While this can be formally proven, it is also nice to explain why this is possible. Each hidden node adds another free parameter. For example, with the combination of two sigmoidal nodes that have the shown on the left of Fig 5.13. With such functions, that can be in size and location of the bump, one can build up arbitrary non-linear functions in as much precision as ones.

We will first consider a special case of multilayer network where all nodes in hidden layers have linear activation functions $g(x) = x$. Eq 5.58 simplifies to

```python
y = w^o w3 w2 w1 x = \tilde{w}x
```

In the last step we have used the fact that the multiplication of a series of matrices yields another, which we labelled $\tilde{w}$. Eq 5.58 represents a single-layer network it is therefore essential to include non-linear activation functions, at least in the hidden layers, to take advantage of computational advantages of hidden layers that we are about to discuss. The remaining problems involve knowing how many hidden nodes we need, and finding the right weight values. The general approximation characteristics does not tell us if it is better to use more hidden layers or to increase the number of nodes in one hidden layer. These are important concerns for practical engineering applications of those networks.
