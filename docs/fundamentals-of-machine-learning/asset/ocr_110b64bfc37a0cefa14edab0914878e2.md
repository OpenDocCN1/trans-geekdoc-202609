$\nabla_w \log p(x|w) = \frac{1}{p(x|w)}\nabla_w p(x|w), \quad (10.35)$

so that we can replace the gradient term in Enq 10.37.

$\nabla_w J = \int_x p(x|w)\nabla_w \log p(x|w)\rho(x)dx. \quad (10.36)$

If we expand the log-probability of a trajectory

$\nabla_w \log p(x|w) = \nabla_w \log(s_0) + \nabla_w \log p(a|s;w) + \nabla_w \log(s'|s,a) \quad (10.37)$

and the probability of the first state and the transition probability do not depend the model parameters, $\nabla_w \log(s_0) = 0$ and $\nabla_w \log(s'|s,a) = 0$, we that we do not need a model to evaluate the gradient. Also we can now write the gradient of loss function as an expected value,

$\nabla_w J = E[\nabla_w \log p(a|s;w)]_{x\sim\pi(a|s)} \quad (10.38)$

This nice result for model-free learning of the actor is called the policy gradient theorem. With this we see that we can estimate the gradient by sampling the log-probabilities of policies and multiplying this with the sample rewards of the trajectories,

$\nabla_w J \approx \frac{1}{N} \sum_{x=1}^N \sum_{t=0}^T \log p(a_t|s_t;w)|\sum_{t=0}^T \rho(s_t, \pi(a_t|s_t;w)). \quad (10.39)$

This concludes the principle of introducing an actor critic. This algorithm is called

REINFORCE: $w_{t+1} \leftarrow w_t - \alpha(\nabla_w \log(\pi)R), \quad (10.40)$

where $R$ stands for the accumulated reward of a trajectory. Unfortunately, in practice it turns out that the samples for the gradient of the log-policies have very high variance so that making variance smaller is to take the change of $R$ with each sample from the average of some batch or samples $R$ into account. This **baseline** version is given by

REINFORCE with baseline: $w_{t+1} \leftarrow w_t - \alpha(\nabla_w \log(\pi)(R-\bar{R})), \quad (10.41)$

and have there been of other tricks introduced in the literature. However, an important other method is introduced in the next section.
