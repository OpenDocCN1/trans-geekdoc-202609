We will here outline the idea behind such techniques. One is to work out the algebraic expression of a derivative by hand and then code the result. For example, let's assume we want to find the gradient of the function

```
f(x, y) = \sin(x) + x * y + \ln(y)
```

which we can find by applying the analytic differentiation rules to be

```
\frac{\partial f(x,y)}{\partial x} = \left( \frac{\cos(x) + y}{x + \frac{1}{y}} \right).
```

The expressions on right can also be found with symbolic mathematical manipulations implemented in symbolic code for tools like Maple or Mathematica. We can then use these expressions to calculate the values of the gradients at specific points $x_0$ and $y_0$. For example, the partial derivative of the function in $x$-direction at $x=0$ and $y=1$ is $|\frac{\partial f(x,y)}{\partial x}|_{(0,1)} = 2$.

While such methods are exact save manual mistakes, another possibility is we to use numeric approximations based on finite difference quotients for the partial derivatives like

```
\frac{\partial f(x,y)}{\partial x} = \frac{f(x + \Delta x, y) - f(x, y)}{\Delta x}
```

Such an approximation is easy to implement but introduces numerical errors. For example, with a width of $\Delta x=0.1$ we get a value of $|\frac{\partial f(x,y)}{\partial x}|_{(0,1)} \approx 1.998$ for our example. While this seems acceptable, in such errors can result in large variances for complex non-linear functions that are rarely used in machine learning.

The common way of implementing gradient calculations in machine learning is to represent functions as graphs of basic functions and then use a chain rule to represent their derivatives as a graph of derivatives. Backpropagation itself is actually an example of such a strategy. We first explain the basic idea with a forward mode for automatic differentiation. We can represent the example above with the primal graph in Fig. 5.15 where

```
v_1 = x (=0)
v_2 = y (=1)
v_3 = \sin(v_1) (=0)
v_4 = \ln(v_2) (=0)
v_5 = v_1 * v_2 (=0)
v_6 = v_3 + v_4 + v_5 (=0).
```

This is like a neural network with weights always to 1 but where every node can have a different gain function. This underlines the fact that a neural network is mostly a graphical representation of a complex function. In brackets, we show the evaluation of these functions with input $x=0$ and $y=1$.
