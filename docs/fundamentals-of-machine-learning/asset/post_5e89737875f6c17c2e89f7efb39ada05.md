## 2.2 Basic language elements

### 2.2.1 Basic data types and arrays

As a general purpose language, Python contains basic programming concepts such as basic data types, loops, conditional statements, and subroutines. We will briefly review the associated syntax with examples provided in file FirstProgram.ipynb. In addition to such programming constructs, major languages like Python are supported by a large number of libraries that enable a wide array of programming styles and specialized functions. We are mainly interested in scientific computing in contrast to system programming. We therefore base almost all programs in this book on the NumPy library. NumPy provides basic support of scientific constructs and functions such as trigonometric functions and random number generators. Most importantly, it provides support for N-dimensional arrays. NumPy has become the standard in scientific computing with Python. We will use these established constructs to implement vectors, matrices and higher dimensional arrays. While there is a separate matrix class, this construct is limited to a two dimensional structure and has gained widespread acceptance.

An established way to import the NumPy library in our programs is to map them to the space "np" with the command `import numpy as np`. In this way, the specific methods or functions of NumPy are accessed with the prefix `np.`. In addition to importing NumPy, we always import a plotting library as plotting results we will specifically use the popular pyplot package of the Matplotlib library. Hence, we nearly always start our program with the two lines:

Most of the time we will be working on a large collection of data so that we need a concept to accept the data collection. In Python, there are several forms of lists. For example, a 1-dimensional list is given by enclosing elements in square brackets such as

Such lists are useful for collecting data. However, since we need to perform well-defined mathematical operations on lists, it is useful to introduce a more versatile construct of such data: arrays. Before proceeding, it might be good to review some of the naming conventions. A basic structure for a collection of data is called an "array" in computer science. In contrast to these simple data structure constructs, the mathematical concepts of vectors are different in that they include defined operations. Thus, the mathematical concept of a vector is a one-dimensional array on which some operations are defined, such as adding two vectors with the same dimension by adding their components, or multiplying a vector with a scalar by multiplying each component of the vector with a scalar. Similarly, a matrix is a two-dimensional construct with correspondingly defined operation. We can even generalize to higher dimensions, and such mathematical constructs are tensors. It is convenient to view a vector or matrix operation just as a special case of general tensor operations.

To create a NumPy array we use `array()`. For example, a 1-dimensional Python list can be turned into a NumPy vector:

```python
aVector = np.array([1, 2, 3])
print(aVector)
[1 2 3]
print(aVector[0], aVector[-1])
1 3
print(aVector[1])
2
```

As shown in the second print statement, we can access an element of the array with indices in square brackets. The first element in an array has the index 0. Hence, the print command returns the value 1. It is useful to think about this as the offset from the first element. The index —1 accesses the last element in the vector. The third print command shows how to access a range of indices. Unfortunately, there is no distinction between a vector and a column vector in NumPy, so this needs some careful consideration when a distinction is necessary. We return to this point in a moment.
