The transition depends on the policy, we need to choose one. We chose the one specified on the left in Fig. 10.2 which the agent would leave in state s = 1 and to the right in state s = 2 and s = 3. This happens to be the optimal solution, as we will show later, so that this will give us a solution for the optimal value. We use this policy to construct the transition matrix by hand as shown on the right in Fig. 10.2. For example, if we are in state s = 4 and move to the left, a = -1, corresponding to the-index=7, then we end up in state s = 3, from which the policy goes right, a = 1. This correspond to the to-index=9. Thus, the transition matrix should have an entry T(7, 9) = 1. Going through all the cases results
