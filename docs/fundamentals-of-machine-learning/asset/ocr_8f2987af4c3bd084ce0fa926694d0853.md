# Listing 2.31 MatrixMultiplication.ipynb (fragment)

```
def matmulslow(a,b):
    m = a.shape[1]
    c=np.zeros((m,m))
    for i in range(m):
        for j in range(m):
            for k in range(m):
                c[i,j]=c[i,j]+a[i,k]*b[k,j]
    return c
```

and a fast version of this operation in the method matmulfast which call the NumPy dot.
