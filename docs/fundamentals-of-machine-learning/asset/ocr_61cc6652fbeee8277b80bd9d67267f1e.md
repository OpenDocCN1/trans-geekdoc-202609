The question in practice is then with corresponding attribute value we use to split the data. A popular choices to make this decision is a measure called 'information gain' or a related measure called 'Gini impurity.' For the information we calculate the entropy of the data before and after the split. The entropy H describes how uniform the data is, with larger values of the entropy indicating more homogeneous data. Thus, for our classification purpose, we look for splits that separate the data well and lead to a lower entropy in each partition. The Shannon entropy is calculated as

```
$H = -sum_{y} p(y)\log_2p(y), \quad (3.10)$
```

where $p(y)$ is a probability of a label. Thus in our example Fig. 3.7 entropy before the split is $H = -4/15\log_2(4/15) - 11/15\log_2(11/15) \approx 0.84$. The weighted average entropy of the indicated vertical split $H = 6/15(-4/6\log_2(4/6) - 2/6\log_2(2/6)) = 0.37$. This is an information gain of around 0.47. We split the data with the dashed horizontal line, then the entropy $H = 10/15 + 4/10\log_2(4/10) - 6/10\log_2(6/10) \approx 0.45$ which leads only to a information gain of 0.39. As mentioned earlier, some decision trees use the Gini impurity instead of the entropy to measure how the data are in a set, which is defined as

```
$G = 1 - sum_{y} p^2(y). \quad (3.11)$
```

The results are very similar, but the Gini impurity is numerically less descending. Nice features of decision trees is that the algorithm does a form of (attribute) selection based on some information theoretic measures. A disadvantage is that it does not usually consider combinatorial features.

A common problem with decision trees is that they tend to overfit along the way that are made from individual features. This is where the random forest idea comes into play. A random forest is an ensemble method which makes decisions based on an ensemble of decision trees. The different decision trees are created by different training sets for each of by random sampling. This has already been discussed as bagging. This is particularly effective to create a variety of trees where a vote of all the trees in the end can make better decisions as it prevents some form of overfitting. This is why it is common in practice to use random forests instead of a single decision tree
