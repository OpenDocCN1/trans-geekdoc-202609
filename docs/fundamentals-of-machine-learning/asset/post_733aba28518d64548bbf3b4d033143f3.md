
# 8 Generative models

This chapter is an introduction to the important topic of building generative models. These are models that are aimed at understanding the variety of a class such as cars or trees. A generative mode should be able to generate feature vectors for instances of the class they represent, and such models should be able to characterize the class with all its variations. We discuss this subject both in a Bayesian and in a deep learning context, and also within supervised and unsupervised context. This area is related to important algorithms as k-means clustering, expectation maximization (EM), naive VAEs, generative adversarial networks (GANs), and variational autoencoders (VAE) that are discussed in this chapter.

## 8.1 Modeling classes

In the previous sections we introduced the idea that understanding the world should be based on a probabilistic model of the world. For example, building a good recognition system means estimating a large density function over the probability of objects given sensory data. We have done so far to use classification models as a discriminative recognition model that take feature values $x$ and make a prediction of an output (label) $y$. In the probabilistic framework, models were formulated as parameterized functions that represent the conditional probability $p(y|x)$; A model that distinguishes between classes based on the feature values is a **discriminative model**. Building a discriminative model directly from example data can be a daunting task as we learn how each item is distinguished from every other possible item. It worked on some examples earlier because we have mainly used simple models in low dimensions to illustrate the ideas. However, many real-world problems have much larger dimensions.

We will now outline a different strategy: of learning first about the nature of specific classes and then using this knowledge to learn a classification prediction. We will therefore have to learn a **generative models**,

```
$p(y|x; \theta)$
```

and then use an inference mechanism to use this knowledge for decision-making. Such a learning strategy seems resemble human learning closely. Generative models can be used with an inference engine to solve diverse tasks such as classification. For example, we might first learn about chairs, and independently about tables, and when we are shown pictures with different furnitures we can draw on this knowledge to classify them.

Let's talk briefly about the inference engine. In order to use probabilistic models as in 8.1, we need to ask how we can combine the knowledge about different classes to undertake classification. Of course, the answer is provided by Bayes' theorem, so that in this case we can use the rules of probability theory as inference engine. This is the ideal situation in a probabilistic setting. In practice, the following we show some examples where we can use Bayes rule. There are situations where undertaking analytically with Bayes rule is difficult. Complete or approximate numerical implementations of Bayes rules is an important topic. There are good examples where scientists have shown that humans make Bayesian decisions in specific experiments, although there is of no evidence that humans use direct calculations by Bayes theorem.

In order to make a discriminative model from the generative models using Bayes theorem, we need to know the class priors, such as the relative frequencies of the classes. We can then calculate the probability that it features $x$ belonging to a class as $y$

```
$$p(y|x; \theta) = \frac{p(x|y; \theta)p(y)}{p(x)}$$ $(8.2)$
```

A decision can be made directly based on this conditional probability. The Bayesian decision of predicting the class with the largest posterior probability is

```
$$\arg max_y p(y|x; \theta) = \arg max_y \frac{p(x|y; \theta)p(y)}{p(x)}$$ $(8.3)$$
$$= \arg max_y p(x|y; \theta)p(y)$$ $(8.4)$
```

While we have used the fact that the denominator does not depend on $y$ and thus can be ignored. In the case of binary classification, this reads:

```
$$\arg max_y p(y|x; \theta) = \arg max_y p(x|y=0; \theta)p(y=0), p(x|y=1; \theta)p(y=1).$$ $(8.5)$
```

While using generative models for classification seem to be more elaborate, we will later see that there are several arguments which make generative models attractive for machine learning. To start with, it seems much easier and efficient to learn generalize from similar objects than to learn from difficult discrimination examples.

## 8.2 Supervised generative models

### 8.2.1 1D Gaussian example

Classification with generative models have been used for some time. We will be discussing an example here which is related to a method called linear discriminant analysis which goes back to a paper by Fisher in 1936. This is the same Fisher who collected the iris dataset that we use in Chapter 2. We will start by outlining the idea in a 1-dimensional Gaussian before deriving the more general case with more attributes and more classes in the next subsection.

An example of the distribution of an attribute $x$ for two classes is shown in Fig. 8.1. As can be seen, these classes are not fully discriminated by this attribute value as the attribute values are overlapping. Thus, a good lesson to learn that 100 cent classification is not always possible. However, we can still predict with some high confidence in some cases. A good choice, and indeed the best choice, is to predict the blue class on the left for attribute values less than 1 and the red class on the right for attribute values 1.

![](img/2087e3fd78fc2bbc9ee0bfaab663bde_168.png)
Fig. 8.1 overlapping classes with attribute values.

We formalize this for the specific example of two distributions as shown in Fig. 8.1, which were generated with the following:

```
$p(x|y=1) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{x^2}{2\sigma^2}}$ $(8.6)$
$p(x|y=2) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ $(8.7)$
```

In the particular example with $\mu = 2$ and $\sigma = 1$, the Bayesian decision is given by the point where the posteriors are equal:

```
$p(y=1|x) = p(y=2|x) \implies p(x|y=1)p(y=1) = p(x|y=2)p(y=2)$ $(8.8)$
```

Since we assume equivalent priors $p(y=1) = p(y=2) = 1/2$, this simplifies to:

```
$e^{-\frac{x^2}{2\sigma^2}} = e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ $(8.9)$
```

Solving for $x$, we find the decision boundary $x_D = \mu/2$. The error of predicting class $c_1$ incorrectly (when $x > x_D$) is:

```
$e_{c1} = \int_{x_D}^{\infty} \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{x^2}{2\sigma^2}} dx$ $(8.10)$
```

Similarly, the error for class $c_2$ is:

```
$e_{c2} = \int_{-\infty}^{x_D} \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}} dx$ $(8.11)$
```

Using the error function, we can write these as:

```
$e_{c1} = \frac{1}{2} - \frac{1}{2}\text{erf}\left(\frac{x_D}{\sqrt{2}\sigma}\right)$ $(8.12)$
$e_{c2} = \frac{1}{2} - \frac{1}{2}\text{erf}\left(\frac{x_D-\mu}{\sqrt{2}\sigma}\right)$ $(8.13)$
```

Thus, in the case illustrated in Fig. 8.1 with $\mu=2$ and $\sigma=1$, the best achievable accuracy is:

```
$\text{Acc} = 1 - e_{c1} = \frac{1}{2} + \frac{1}{2}\text{erf}(1/\sqrt{2}) \approx 0.84.$
```

We carry the same idea to the more general case of $k$ classes, and we assume that each class has members which are Gaussian distribution over $n$ attribute values. An example for $n=2$ is shown in Fig. 8.2A. The following is a direct generalization of the 1-dimensional case.

$p(y=k) = \phi_k, \quad (8.14)$
