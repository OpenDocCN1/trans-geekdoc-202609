The indicator function $\mathbb{I}(x=y)$ is simply 1 if $x=y$ and zero otherwise. Therefore, when put into a sum it counts the number of cases in which condition is true. While we do not know the class labels, we can follow a similar strategy to the $k$-means clustering algorithm and propose some labels and use them to estimate the parameters. We can use the new estimate of the distributions to find better labels for the data, and repeat this until a stable configuration is reached. In general, this strategy is outlined in Fig. 8.5. In this version the EM algorithm for expectation-maximization. The algorithm is hard-classify the data into one or another, but we take a more soft classification approach that considers the probability estimate of a point belonging to each class.

+   1. Initialize parameters $\phi_j, \mu_j, \Sigma$ randomly.
2. Repeat until convergence:
   **E step:**
   For each data point $i$ and class $j$ (soft-classify data as)
   $w_j^{(i)} = p(z^{(i)}=x^{(i)};\mu_j, \Sigma)$
   **M step:**
   Update the parameters according to
   $\phi_j = \frac{\sum_{i=1}^m w_j^{(i)}}{\sum_{i=1}^m w_j^{(i)}}$
   $\mu_j = \frac{\sum_{i=1}^m w_j^{(i)}x^{(i)}}{\sum_{i=1}^m w_j^{(i)}}$
   $\Sigma_k = \frac{\sum_{i=1}^m w_j^{(i)}(x^{(i)}-\mu_j)(x^{(i)}-\mu_j)^T}{\sum_{i=1}^m w_j^{(i)}}$

Let us assume that the world knows only of data from two Gaussian distributions with equal likelihood, and that we do not know the specific realizations (parameters) of these distributions. The pre-knowledge of two Gaussian distributions encodes a specific **hypothesis** which makes up this **heuristic model**. In this simple example, we have chosen the heuristics to match the actual data-generating system (world); that is, we have explicitly some knowledge of the world.
