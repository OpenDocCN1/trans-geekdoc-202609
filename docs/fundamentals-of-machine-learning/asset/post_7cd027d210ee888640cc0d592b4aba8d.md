The decision point between the two classes with equal class prior is given by the point where the probabilities for the two classes (Eqn 8.24) is the same. This gives

```

```

With simplifying notations it is easy to see that this decision boundary is a linear, $a + wx = 0.$ (8.28)

As this is a linear equation, this method with the Gaussian class distributions with equal variances are called linear discriminant analysis (LDA). The vector $w$ is perpendicular to the decision surface. Examples are shown in Fig. 8.2. If we do not make the assumption of equal variances of the classes, then we have a quadratic equation for the decision boundary, and the method is called quadratic discriminant analysis (QDA). Which method should be used? In LDA we make the assumption that each class is Gaussian distributed. If this is the case, then LDA is the best method we can use. Discriminant analysis is also popular since it is easy to apply and work well when the classes are not strictly Gaussian. Logistic regression is more general since it does not make the assumption that the class distributions are Gaussian. However, as long as we consider only linear models, logistic regression will have problems with the data shown in Fig. 8.2b.

## 8.3 Naïve Bayes

In the previous example, we used 2-dimensional feature vectors to illustrate the classification problems with 2-dimensional plots. However, machine learning applications work with high-dimensional feature vectors. We will now discuss high-dimensional feature vectors with generative models, which is called naïve Bayes, often used with.

## Generative models

To do this, we first need to represent a message as either spam ($y=1$) or non-spam ($y=0$). We consider a vocabulary, and $x$ is represented by a vector where:

```
$x = \begin{aligned} 0 & \text{if word not present} \\ 1 & \text{if word present} \end{aligned} \quad (8.32)$
```

The probability that a word appears in a spam or non-spam message is usually simplified to a binomial distribution. We want to model the probability $p(x|y)$, which is the likelihood:

$p(x|y) = \prod_{j=1}^{50,000} \phi_{j,y}^{x_j} (1-\phi_{j,y})^{1-x_j} \quad (8.33)$

Using Bayes' theorem, the probability that a message is spam is:

$p(y=1|x) = \frac{p(x|y=1)p(y=1)}{p(x|y=1)p(y=1) + p(x|y=0)p(y=0)} \quad (8.34)$

This is the case with $50,000-1$ parameters to learn. Using the assumption that words are independent, we get:

$p(y=1|x) = \frac{p(x|y=1)p(y=1)}{p(x|y=1)p(y=1) + p(x|y=0)p(y=0)} \quad (8.35)$

This big advantage of this Naïve Bayes model is that the number of parameters are fairly small compared to more complex models. There are many examples where naive Bayes models work well which are, of course, cases where the naive Bayes assumption is appropriate. Course, words in a text should be highly correlated, but the gist is here that pure frequency of words correlates with the text.
