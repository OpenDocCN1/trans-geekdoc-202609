Instead of going into the details of variations of gated recurrent networks, it is useful to mention one more ingredient in recurrent models to be crucial for boosting performance: **attention**. Attention has been considered an important part of human information processing since the release of William James' seminal *The Principles of Psychology* in 1890. At its heart, attention captures the ability of humans to orient towards important information, or to weigh information as greater than others and to inhibit others. Different forms of attention have been identified in the early visual system to emphasize such features like letter "A" in a sea of letters "C". This leads to the common effect that we perceive objects as "popping out," which quickly narrows down the search space for objects.

This feature-based bottom-up attention is not the only effect. Indeed, our ability to direct attention, either to spatial locations or to objects, shows some form of top-down attention. Some consequences of attention on neuronal firing have been recorded. For example, 9.8A shows experimental responses of neurons that are sensitive to objects moving in a certain direction in the visual scene. Response curves of neurons are called "tuning curves" in neuroscience. The squares show when the subject attends to a "fixation point" and not attending to the motion... This is demonstrated in Fig. 9.8B with the program below. We draw a Gaussian which curves down slightly (blue curve). When adding a constant we get shifted blue curve, whereas if we multiply the original with 1.5 we get the red curve that represents the experimental results in Fig. 9.8A.

Gated memory networks already represent some form of attention since the release of information that is triggered by some context can be seen as attention. In general, attention can be seen mathematically as some form of non-linear processing. The simplest form is thereby a multiplicative gating as shown earlier. ## 9.4 Models with symmetric lateral connections

### 9.4.1 Markov (conditional) random field

In the first part of this chapter we discussed a form of recurrent neural networks with re-entry connections. We now consider a special form of recurrent neural networks: those with symmetric connections

```
w_{ij} = w_{ji}.
```

These networks have been an important part of the development of neural networks. Before going into more specific examples, let us first outline their relations to probabilistic graphical models.

### 9.4.2 The Hopfield model

This type of networks has received a great deal of attention in neuroscience. It has been known for some time that an area of the neocortex the hippocampus in humans is important for some form of memory, in particular episodic memory, the memory of specific events. This area has interesting structures, including an area CA3 which has a lot of connections. In 1971, David Marr proposed an explanation for such networks, suggesting that they could facilitate associative memory, the memory of recall that could be triggered by partial cubes. The Hopfield model is a good abstraction of this kind of memory.

To demonstrate associative memory, we run a small experiment with binary neurons. We choose to represent these states as -1 and 1. We can easily transform the network to other state representations, but it turns out that this representation helps with the compactness of the program. We use hard threshold units in this example with the “update rule"

```
$s(t + 1) = sign(ws(t - 1)).
```

The sign function returns -1 if the element is less than zero or otherwise 1. This is just another version of a threshold perceptron. We now want to store some patterns $x^k$ in this network. The new part is how we train this network. We use here the

```
Hebb rule: $w = \sum_{\mu} xx'$
```
