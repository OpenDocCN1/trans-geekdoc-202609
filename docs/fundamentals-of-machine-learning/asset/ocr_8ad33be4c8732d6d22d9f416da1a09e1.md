In Fig. 9.2, we visualized the generation of the input vector by tabbing the input
sequence with delay lines of different lengths. Representing a finite portion of
sequence in spatial way this is sometimes called a tapped delay line. With such a
representation of time sequence we can immediately apply a deep neural networks
or the sequence forecasting. An example of such a simple network with one hidden
layer is shown in Fig. 9.2.

For the following discussion, let's simplify this network with only one hidden
node as shown in Fig. 9.3A. We can generalize this easily to more hidden nodes
 many layers of hidden; we have chosen this simple version for the
illustration purposes. With this reduced figure it becomes clear that we assume the
values of the inputs at different times can have different influences on the sequence
prediction as we allow the weights to the hidden node to have different values that
of course be learned. This is the most general case, at least for a fixed
sequence which occur at any position, then we can use a convolution
out the input vector to search for this pattern. For example, in text processing of the
 "You should not use an umbrella because it is raining," the word "umbrella"
is highly predictive of the word "raining", although the relative position is variable.
Convolutional networks have smaller filters compared to dense networks. This
will us parameters as we already discussed for position invariant feature detection
is. The 1-dimensional convolutional solution is illustrated in Fig. 9.3B. A
model with fewer parameters usually require less training examples to learn, and
convolution makes sense in many cases.

We reduce the network complexity even further if we assume that the previous
time steps only influence the current time in a transient or diminishing way. This
is often a good assumption. For example, it is well known that the probability of a
 is higher than a sunny day than a rainy day. We can describe a situation
where the current value influences time periods at $t + \delta$ of the activation of the
hidden nodes

```
$h(t) = \mathbf{vx}(t) + \mathbf{uvx}(t-1) + \mathbf{u}^2\mathbf{vx}(t-2) + \dots, \quad (9.4)$
```

where $u$ are weights with value less 1. We can then simplify this network with
t architecture shown in Fig. 9.3C we represent the exponentially decaying
memory of the input by a delayed input to the hidden node of its previous value.
Mathematically, we are only replacing a diminishing sum with a recursive function,

```
$h(t) = \mathbf{vx}(t) + \mathbf{u}(\mathbf{vx}(t-1) + \mathbf{uvx}(t-2) + \dots) \quad (9.5)\n= \mathbf{vx}(t) + \mathbf{uh}(t-1), \quad (9.6)$
```

which is illustrated in Fig. 9.3C. Since this includes the re-entry of the information
through the backward connections, this is called a recurrent neural network (RNN).
