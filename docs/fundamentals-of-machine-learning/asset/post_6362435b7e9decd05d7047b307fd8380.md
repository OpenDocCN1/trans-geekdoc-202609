A common misconception about randomness is that one cannot predict anything about random variables. While we might not be able to predict a specific value, it is often the case that some values might be more likely than others. We might be able to say something about how often a certain number will appear when drawing many examples. We might even be able to state how confident we are with this number, or in other words, how likely these predictions are. Complete knowledge of a random variable, $x$, is captured by the probability density function $f(x)$ in the continuous case and by probability mass function $P(x)$ in the discrete case. We discuss some specific examples of such functions in the following. In these examples, we assume that such probability functions are *a priori*, but in many practical applications we must estimate this function. Indeed, estimation of probability functions is in some sense the essence of machine learning. If we would know the "world probability density function", the probability function of all possible events in the world, then we could predict as much as possible and in all this world.

Probability theory is the theory of random numbers. We define such numbers by letters to distinguish them from random numbers written in lower case. A random variable, $X$, is a quantity that can have different values each time the variable is inspected, as such in experiments. This is fundamentally different to a regular, $x$, which does not change its value once it is assigned. A random number is thus a new mathematical concept, not included in the regular mathematics of numbers. A specific value of a random number is still meaningful as if might influence specific processes in a deterministic way. For example, a restaurant owner might be uncertain about how many people will come to the restaurant, but once people are in it should serve this number of people.

Since the value of a random number can change every time it is inspected, its uncertainty is captured by the mathematical construct of probability. Note that it is often a debate whether random numbers should be defined solely on the basis of a frequency measurement, or if they should be treated as a special kind of object with this inherent property. This philosophical debate between "Frequentists" and "Bayesians" is importance for our applications. We do not ask where the uncertainty is coming from, we use the probability construct as a tool to describe uncertainty, it is of minor importance to us if this is an inherent limitation or simply a lack of knowledge.

We formalize the idea of expressing probabilities of drawing specific values for random variable with some compact notations. For these notations we sometimes need to distinguish discrete random numbers and continuous random numbers. There is, in principle, not much difference between these two kinds of random variables except that the mathematical formulation has to be slightly different to be mathematically correct. For example, the probability mass function for discrete random numbers,

```
$P(x) = P(X = x)$
```

describes the frequency with which each possible value $x$ of a discrete variable $X$ occurs. Note that $x$ is a regular variable, not a random variable. The value of $P(x)$ predicts the fraction of times we get a value $x$ for the random variable $X$ if we draw many examples of the random variable. Probabilities are sometimes written as a percentage, but we will still stick to the fractional notation. It follows that the frequency of having any of the possible values is equal to 1, which is an important normalization condition for a probability function,

```
$$\sum_{x} P(x) = 1. \quad (6.2)$$
```

In the case of continuous random numbers, we have an infinite number of possible values $x$ so that the fraction for each number becomes infinitesimally small. It is necessary to write the probability distribution function $P(x) = p(x)dx$, where $p(x)$ is the probability density function (pdf). Note that we have used uppercase and lower-case letters. The sum in Eq 6.2 then becomes an integral, and the normalization condition for a continuous random variable is

```
$$\int p(x)dx = 1. \quad (6.3)$$
```

A finite probability value makes sense then only for a certain range of numbers such as

```
$$\P(a < x < b) = \int_{a}^{b} p(x)dx. \quad (6.4)$$
```

We will formulate the rest of this section in terms of continuous random variables. The corresponding formula for discrete random variables can easily be deduced by replacing the integrals over the pdf with sum over the probability function. It is also possible to use the delta-function to write discrete random processes in a continuous form. The delta-function $\delta(x)$ is a very convenient notation, which formally is a functional since it is only defined within an integral or the limiting case of a function series. One can think of it as a density function which is 0 except for its arguments for which it is infinite,

```
$$\int_{-\infty}^{\infty} \delta(x_1)f(x)dx = f(x_1). \quad (6.5)$$
```

The delta function is useful for writing discrete in a continuous form. For example, we could write the density function for throwing a dice

```
$$\P(x) = \frac{1}{6} \text{ for } x = \{1, 2, ..., 6\}. \quad (6.6)$$
```

as a density function

```
$$\p(x) = \frac{1}{6}\delta(x-x_i) \text{ with } x_i = \{1, 2, ..., 6\}. \quad (6.7)$$
```

Note that we are here only playing with notations in order to introduce a concise language.

Since we don't know the probability density function of the quantities of interest in machine learning, we will have to estimate pdfs. This approximation is the learning process in machine learning, and we will use outline specific methods to do this.

Communicating the form of a pdf is difficult, and traditionally it is common to describe random variables with a small set of numbers that are meant to capture some properties of density function. For example, we might ask what the most frequent value is when drawing many examples. This number is given by the largest value of the distribution.

$p^{max} = \argmax_x p(x).$

Even more common is to ask about the average value of the random sample when drawing examples. A common quantity is to think the expected arithmetic average of these numbers, which is called the mean, expected value, or expectation value of the distribution. This is defined as

$$\mu = \int_{-\infty}^{\infty} xp(x)dx.$$

This formula formalizes the calculation of adding all the different numbers with their corresponding frequencies.
