If the agent finds a solution that gives it reward, the question might remain if this is a good solution or if the agent should search for a better solution or stick to the known rewards. This problem is commonly stated as “exploration versus exploitation trade-off.” Let us assume that the rodent (agent) found the smaller reward at the end of the left arm of the T-maze. It is then likely that the rodent will turn in subsequent trials to receive food reward. The agent learned that taking a left turn and going to the end of the maze is associated with food reward. Of course, in this case the rodent could also receive larger reward when exploring the right arm of the maze, which illustrates the exploration-exploitation trade-off in such learning settings.

To illustrate the different reinforcement learning schemes in this chapter, we will apply these algorithms to a simplified version of the T-maze mentioned above. To keep the problem minimal and clear, concentrate on the upper linear part for the maze. States s of the maze are labeled 0 to 4. Reward of 1 is provided in state 0 and reward of 2 is provided in state 4. The discrete Q-function has 10 values corresponding to each action in each state. In states 1, 2, and 3 the agent move left or right. The states with the reward, states 0 and 4, are terminal states and the agent would stay in these states if unprompted to move.
