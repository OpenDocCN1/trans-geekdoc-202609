import numpy as np
import matplotlib.pyplot as plt

pat=2*np.random.randint(1, size=(500,10))#Rand binary pattern
w=pat.T                                 #Hebbian learning
s = pat+10*np.random.randn(500,100)      #Initialize network

plt.plot(s.T@500)                      #plot overlaps

After training, we start the network on a random version of the one pattern. While the overlap between the network and the stored pattern is not good initially, we can see that one gets perfectly recovered (overlap = 1). It can be shown that the patterns are fix-point under the network dynamics. Interestingly, sometimes we can see that the overlap to one pattern goes to -1, so that the inverse of the pattern is also a fix-point under the dynamics.

## 9.4.3 The Boltzmann machine

A more general form of such a network was introduced by Geoffrey Hinton and Terence Sejowski from the mid-1980s which they called the Boltzmann machine. These recurrent networks incorporate two important aspects. One is that they hidden nodes that are not connected to the outside world directly. With perceptrons, hidden nodes allow an unlimited internal structure that allows in principle an unbounded complexity of computations. The second advancements over the basic Hopfield network is the Boltzmann machine considers stochastic nodes and therefore represents a general probabilistic model.

Such a dynamic network, a recurrent system with hidden nodes, together with the adjustable connections, provide the system with enough degrees of freedom to approximate any dynamical system. While this has been recognized for a long time, finding practical training rules for such systems have been a major challenge for which there was only recently major progress. These machines use unsupervised learning to learn hierarchical representations based on the statistics of the world. Such representations are key to more advanced applications of machine learning and to human abilities.

The connections between the weights $w_{ij}$ specify how much they influence the on-state of connected nodes. Such systems can be described by an energy function. The energy between two nodes that are symmetrically connected with strength $w_{ij}$ is

```
$H^{nm} = -\frac{1}{2}\sum_{ij}w_{ij}s_i^n s_j^m.$ (9.26)
```

The state variables, $s$, have superscripts $n$ or $m$ which can have values $v$ or $h$ to indicate visible and hidden nodes. We consider the probabilistic update,

```
$p(s_i^n = +1) = \frac{1}{exp(-\beta\sum_j w_{ij}s_j^m)}.$ (9.27)
```

with inverse temperature, $\beta$, which is called the Glauber dynamics in physics, and describes the competitive interaction between minimizing the energy and the randomizing thermal force. The probability distribution for such a stochastic system is the Boltzmann-Gibbs distribution. This, distribution of visible states, in thermal equilibrium, is given by

```
$p(s^n; w) = \frac{1}{Z}\sum_{m\in h} exp(-\beta H^{nm}).$ (9.28)
```

where we summed over all hidden states. In other, this function describes the distribution of visible states of a Boltzmann machine with specific parameters, representing the weights of the recurrent network. The normalization term, $Z = \sum_{n,m}exp(-\beta H^{nm})$, is the partition function, which provides the correct normalization so that the sum of the probabilities of all states sums to 1.

Let us consider the case where we have chosen enough hidden nodes so that the system can, give the right values, implement a generative model as a function of the parameters. To define a learning rule, we want to minimize the distance between two probability distributions. A common measure for the difference between two distributions is Kulback–Leibler divergence,

```
$KL(p(v); p(w)) = \sum_{s} p(v) \log \frac{p(v)}{p(w)} \quad (9.29)$
$= \sum_{s} p(v) \log p(v) - \sum_{s} p(v) \log p(w). \quad (9.30)$
```

To minimize this with a gradient method, we need to calculate the derivative of this distance measure with respect to the weights. The first term in the difference in Eqn 9.30 is the entropy of sensory states, which does not depend on the Boltzmann machine. Minimizing the Kulback-Leibler divergence is equivalent to maximizing the average-likelihood function,

```
$l(w) = \sum_{s} p(v) \log p(v; w) = \langle \log p(v; w) \rangle. \quad (9.31)
```

Once we have seen the argument for maximizing the log-likelihood function several times, although we now put this into the context of a recurrent model. In other words, we treat the probability distribution produced by the Boltzmann machine as a generative model as a function of the parameters, $w_{ij}$, and choose the parameters which maximize the likelihood of the training data (the actual world states). Therefore, the log-likelihood of our average increases the better the model approximates the world. A standard method of maximizing this is gradient ascent, which for given with respect to the weights. We omit the detailed derivation, but we note that the resulting learning rule can be written in the

```
$\Delta w_{ij} = \eta \frac{\partial l}{\partial w_{ij}} = \eta \frac{\beta}{2} (\langle s_i s_j \rangle_{clamped} - \langle s_i s_j \rangle_{free}). \quad (9.32)$
```

The meaning of the terms on the right-hand side is as follows. The term labelled "clamped" is the average of correlation between two nodes when the visible nodes are fixed. The term labelled "free" is the thermal average when the recurrent system is running free. The Boltzmann machine can then be trained, in principle, to represent any arbitrary density functions, that the network has a sufficient number of hidden nodes.
