However, there is a major difference. Previously we iterated over all possible states with the knowledge of the transition function and the reward function; then an agent does not have to explore the environment and can "sit there" and calculate what the optimal option is. This is the benefit of model-based reinforcement learning. In contrast, we here discuss the case where we do not know the transition function and the reward function and have to explore the environment by acting in it. This is usually associated with a physical movement, which takes times and hence limits the exploration we can do. Thus, it is common that an agent cannot explore all possible states in large environments. Also, learning a rate of $\alpha=1$ is not always advisable since some more certain is that reward is probabilistic. A smaller value of $\alpha$ then represents a form of taking a sliding average and hence the expected value of the reward.

**Fig. 10.4** Example of the "back-propagation" of reward (not to be confused with backpropagation algorithm in supervised learning). In this, an episode starts in the left-most state and the policy is to always go right. A reward is received in the right-most state.

It is useful to go through some iterations of the SARSA algorithm by hand for a linear-maze example. In the example in Fig. 10.4, we changed the situation to a linear maze where the state starts at the left-most state and a reward of $r=1$ is received in the right-most state. The policy is to always go right, which is also the optimal policy in this situation. At the first time of the first episode we are in the left-most state and the value of going right. In the corresponding state to the right there is no reward, and the value function is 0. So the value of this state-action is updated to $\gamma$ plus the reward of the next state. In the second episode the value of the first and second state remains 0, but the third is updated to $\gamma+1$ since the value of the next state following the policy is given by 1, and we discount this by $\gamma$. Going through more episodes it can be seen that the value "back-propagates" by one step in each episode. Note that this back-propagation of the reward is not to be confused with the backpropagation algorithm in supervised learning. Also, notice that the values for the $Q$-function for going left are not updated as we only followed optimal policy deterministically. Some exploration states will eventually update these values, although it might take a long time until these values propagate through the system.
