```
import numpy as np
import matplotlib.pyplot as plt

pat=2*np.random.randint(1, size=(500,10))#Rand binary pattern
w=pat.T                                 #Hebbian learning
s = pat+10*np.random.randn(500,100)      #Initialize network
for t in range(10):
    s[:t]=np.sign(w@s[:t])               #Update network
plt.plot(s.T@500)                      #plot overlaps
```

In the right graph of Fig.9.1 we show the result of this simulation by showing the overlap between the network states and the vectors representing the ten random patterns. The value of this overlap is 1 if the vectors are the same, and -1 if all the features are inverted, and 0 for random relations. After training, we start the network on a random version of the one pattern. While the overlap between the network and the stored pattern is not good initially, we can see that one gets perfectly recovered (overlap = 1). It can be shown that the patterns are fix-point under the network dynamics. Interestingly, sometimes we can see that the overlap to one pattern goes to -1, so that the inverse of the pattern is also a fix-point under the dynamics.

Before leaving the Hopfield model, it should be mentioned that there has been a theoretical results derived for this type of model, including its stochastic counterpart. We mentioned earlier that this network represents a dynamical system which point attractors as the stable states in basins. This is a consequence of the symmetric weights as well as the monotonicity of the function used. Breaking such symmetries with associative learning rules or random asymmetries brings us to richer dynamics. The symmetric version of the stochastic model trained with Hebbian learning is related to spin nodes and, in particular, models can be called spins. The phase structure of possible solutions in such states has been quite well characterized and can form the basis of a much deeper understanding of the behavior of such networks.

# 9.4.3 The Boltzmann machine

A more general form of such a network was introduced by Geoffrey Hinton and Terence Sejowski from the mid-1980s which they called the Boltzmann machine. These recurrent networks incorporate two important aspects. One is that they hidden notes that are not connected to the outside world directly. With perceptrons, hidden nodes allow an unlimited internal structure that allows in principle an unbounded complexity of computations. The second advancements over the basic Hopfield network is the Boltzmann machine considers stochastic nodes and therefore represents a general probabilistic model.

Such a dynamic network, a recurrent system with hidden nodes, together with the adjustable connections, provide the system with enough degrees of freedom
