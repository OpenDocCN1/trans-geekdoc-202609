Representing the original signal with these basis functions has a big advantage. For example, if we store a set of basis functions in several computers, then we can transmit the signal with only two numbers for the coefficients $a_1$ and $a_2$. Of course, we can not expect real signals to be made up of only these two functions. So in practice, we want to create a long list of "appropriate" basis functions. A common example for basis functions is sine waves which are usually good choices for periodic signals. A composition of a signal into such sine of cosine functions is called a Fourier transformation

```
$x(t) = \int_{0}^{\infty} a(\lambda)\sin(2\pi\lambda t) + b(\lambda)\cos(2\pi\lambda t)d\lambda \quad (4.10)$
```

Another common for more localized functions are however similar to $y_1$ in $y_1$. Such functions are called wavelets and the corresponding decomposition is a wavelet transform. These functions are usually chosen by hand and have been designed specifically for certain applications. The filters in deep neural networks can be seen as representing a form of basis functions for a specific feature decomposition. The interesting part of neural networks is that these functions are learned from data so we do not need to design basis functions by hand.

Since we take a large or even infinite number of basis functions into account, it is possible to represent any function with appropriate basis functions. However, having arbitrary basis function is also not the best choice. That is, if we have a long list of basis functions, then we might still need a large number of coefficients. Indeed, if we make end up with the same representation as a signal for which we just store the value at each time point. An important insight to make efficient use of resources while extracting the "essence of signals" is **Sparse representation** is a representation where we might have a large number of basis functions in our dictionary (nodes in a deep network) but only using a relatively small number of active nodes to represent each example. In fact this might correspond

```
$y(t) = a_1x_1(t) + a_2x_2(t) + a_3x_3(t) + a_4x_4(t) + a_5x_5(t) + a_6x_6(t) + ... \quad (4.11)$
```

with coefficient vector

```
$a = (1, 3, 0, 0, 0, 0, ...). \quad (4.12)$
```
