# 6.4.2 Functions of random variables and the central limit theorem

A function of a random variable $X$

is a random variable, $Y$, and we often need to know the pdf of this new variable. Calculating with functions of random variables is a bit different from calculating with regular functions, something to which we pay attention. Let us illustrate how to do this with an example. Say we have an equally distributed random variable $X$, commonly approximated by pseudo-random number generators on a computer. The probability density of this variable is given

```
$p(x) = \begin{cases} 1 & \text{for } 0 \leq x \leq 1 \ 0 & \text{otherwise.} \end{cases} \quad 6.23$
```

We are seeking the probability density function $p_Y(y)$ of the random variable

```
$Y = e^{-X^2}. \quad 6.24$
```

The random number $Y$ is not Gaussian as we might nicely think. To calculate the probability density we can use the cumulative density function of Egn 6.21 by notting

```
$P(Y \leq y) = P(e^{-X^2} \leq y) = P(X \geq \sqrt{-\ln y}). \quad 6.25$
```

Thus, the cumulative probability function of $Y$ can be calculated from the cumulative probability function of $X$.

```
$P(X \geq \sqrt{-\ln y}) = \int_{-\sqrt{-\ln y}}^{y} p(x)dy = 1 - \sqrt{-\ln y} y \leq 1, \text{otherwise.} \quad 6.26$
```

The probability density of $Y$ is the derivative of this function,

```
$p_Y(y) = \begin{cases} -\sqrt{-\ln y} & \text{for } e^{-1} \leq y \leq 1 \ 0 & \text{otherwise.} \end{cases} \quad 6.27$
```
