
To undertake linear regression, we will follow an example of describing house prices. The table on the left in Figure 5.1 lists size in square feet and the corresponding asking prices of some houses. These data points are plotted in the graph on the right in Figure 5.1. The question is, can we predict from these data the likely asking price for houses with different sizes?

To this prediction we assume that the house price depends essentially on the size of the house in a linear way. However, a twice size should double the price. Of course, this linear model clearly does not capture all dimensions of the problem. Some houses might be new. Some houses might need repair and other houses might have special features. Of course, everyone we keep in mind that there might be unobserved, so-called latent dimensions in the data that might be important in explaining the relations. However, we ignore hidden cases at this point and use the linear model size-over as our hypothesis.

The linear model of the relation between the house size and the asking price can be made mathematically explicit with the linear equation

```
$$y(x; w_1, w_2) = w_1x + w_2 \quad (5.1)$$
```

where $y$ is the asking price, $x$ is the size of the house, and $w_1$ and $w_2$ are model parameters. Note that $y$ is a function of $x$, and we follow a notation where the parameters of a function are included after a semi-colon. Then this function can be used to predict the price of a house for any size. The general theme of supervised learning; we assume a specific function with parameters that we can use to predict new data.

The remaining question is what these parameters should have? For this we need example data, or training data. Also, to evaluate how good choices of for the model parameters are, we must define how we undertake the evaluation of these values. This evaluation is specified in a loss function $\mathcal{L}$. We will start here by using a traditional method of the mean square error (MSE) function,

```
$$L(w_1, w_2; x^{(i)}, y^{(i)}) = \frac{1}{2N} \sum (w_1x^{(i)} + w_2 - y^{(i)})^2 \quad (5.2)$$
```

and we will later discuss when this is a good choice. The superscript $i$ labels the different training examples and we put this in brackets so it is not confused with an exponent. This function considers the square distance between the predicted values (linear function) and the actually asking prices. Note that we view this as a function of the model parameters $w_1$ and $w_2$ (the unknowns), and the training data $x^{(i)}$ and $y^{(i)}$ are the parameters of that function that are given. The loss function is central in machine learning and designing the right loss function is an important discussion we need to have. We will see later that this is best achieved using a probabilistic view of machine learning, and we will continue here describing the use of a loss function.

We use the loss function to determine the model parameters. More specifically, the values of the model parameters that minimize the loss result in the best predictor for new data. To find these values we have to minimize the loss function as functions of the parameters. Since the loss function here is a sum of square functions,

We will however use this opportunity to introduce a method called **gradient descent** that is a dominant technique in machine learning. The idea is to start with a random value for each parameter and improve the learning in successive steps by changing the values along the negative gradient,

$$\begin{pmatrix} w_1 \\ w_2 \end{pmatrix} \leftarrow \begin{pmatrix} w_1 \\ w_2 \end{pmatrix} - \alpha \nabla L(w_1, w_2; x^{(i)}, y^{(i)}) \quad (5.3)$$

The **hyperparameter** is called the learning rate, and the Nabla operator $\nabla$ represents the gradient.

$$\nabla L(w_1, w_2; x^{(i)}, y^{(i)}) = \frac{\partial}{\partial w_1, \partial w_2} L(w_1, w_2; x^{(i)}, y^{(i)}) \quad (5.4)$$

Minimizing the loss with gradient descent is an important part of machine learning and the basic principle to derive the learning rule for specific models. In our case, calculating the derivative for MSE loss function (5.2) with the linear prediction function (5.1) gives the following learning rules for the two parameters

$w_1 \leftarrow w_1 - \alpha \frac{1}{N} \sum_{i} (w_1 x^{(i)} + w_2 - y^{(i)})x^{(i)} \quad (5.5)$

and

$w_2 \leftarrow w_2 - \alpha \frac{1}{N} \sum_{i} (w_1 x^{(i)} + w_2 - y^{(i)}) \quad (5.6)$
