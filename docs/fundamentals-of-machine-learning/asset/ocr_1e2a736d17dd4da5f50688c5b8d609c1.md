Next, we can use Bayes theorem to relate the posterior p(\mathbf{w}|\mathbf{x}, y) to the data model, namely

```
p(\mathbf{w}|\mathbf{x}, y) = \frac{p(y|\mathbf{w})p(\mathbf{w})}{\int_{\mathbf{w}' \in W} p(y,\mathbf{x}|\mathbf{w}')p(\mathbf{w}')d\mathbf{w}'}
```

where W is the domain of the possible parameters. For this we should note that the denominator, which is called the partition function, does not depend on the parameters as we are integrating (summing) over all possible values. The most likely values for the parameters can be calculated without this term and are given by a maximum posteriori (MAP) estimate,

```
\mathbf{w}^{MAP} = \text{argmax}_{\mathbf{w}} p(\mathbf{x}, y|\mathbf{w}).
```

The name of the method shows that we modify our prior knowledge of parameters, is summarized as prior distribution p(\mathbf{w}) by combining this to measurements (\mathbf{x}, y) from specific realizations of the parameters, which is given by the likelihood function p(\mathbf{x}, y|\mathbf{w}). The resulting posterior distribution should then be a better estimate of the probability of values for the parameters. The function \text{argmax}_{x}(f(x)) picks the argument $x$ for which the function $f(x)$ is maximal. The argument of the function is the set of parameters that is, in a Bayesian sense, the most likely value for the parameters, where of course, we now treat the probability as a function of the parameters (e.g., a likelihood function). For a uniform prior, p(\mathbf{w}) = const, we get

```
\mathbf{w}^{MAP} = \mathbf{w}^{MLE}
```

While a prior of the parameters has an early choice, this can give us a great insight into regularization from a probabilistic perspective. In section 5.4 we introduced $L^2$ regularization by introducing a bias in the parameters. In the probabilistic models we can do this very elegantly by providing a prior for the parameters that encapsulate the bias in choice of character as argued previously.
