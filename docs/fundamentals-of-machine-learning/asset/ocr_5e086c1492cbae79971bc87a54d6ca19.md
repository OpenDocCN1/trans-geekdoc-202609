We then iterate over trials. We implemented here the batch version where we propagate all samples from the training set and update the weights. This code is very compact, using matrix notations. In general, it is useful to think about the layers of the neural network for performing operations as building the dot product between the input vector and the weight matrix. This computation helps a great deal with building complex models. However, to clarify the vector notation with a component-wise formulation, we offer and example here for calculating the network output for patterns.
