As can't be stressed, our objective in supervised learning is to find a good model that minimizes the generalization error. To state this differently by using nomenclature common in the discussions, we call the error function the risk function $R$; in the case of binary classification, the expected risk. is the probability of misclassification,

```
$R(h) = P(h(x) \neq y).$$
```

Overall, we generally do not know this density function. We assume that the samples are iid (independent and identically distributed) data, and we can estimate what is is called the empirical risk with the help of the test data,

```
$$\hat{R}(h) = \frac{1}{m} \sum_{i=1}^{m} I(h(x^{(i)}, \theta) = y^{(i)}).$$
```
