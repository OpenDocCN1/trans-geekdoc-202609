```
$h = \arg\min_{h} \hat{R}(h)$. (3.49)
```

As a side note, we will later talk about the maximum likelihood estimate (MLE), and the empirical risk is the MLE of the Bernoulli-distributed random variable with true mean $R(h)$. Thus, the empirical risk is itself a random variable for each possible hypothesis. Let us first assume that we have $k$ possible hypothesis $h_i$. We now draw on a theorem that shows the Hoeffding inequality provides an upper bound for the sum of random numbers to it,

```
$P(|R(h_i) - \hat{R}(h_i)| > \gamma) > 2\exp(-2\gamma^2m)$. (3.50)
```

This formula states that there is a probability that we make an error larger than $\gamma$ for each hypothesis of empirical risk compared to the expected risk, the good news is that this probability is bounded, and the bound itself grows exponentially with the number of validation examples. This is already an interesting results, but we now want to know the probability that all possible hypotheses, are less than $\gamma$. Using the fact that the probability of the union of several events is always less or equal to the sum of the probabilities, we can show that with probability $1-\delta$ the error of a hypothesis is bounded by

```
$|R(h) - \hat{R}(h)| > \sqrt{\frac{2k}{2m}\log\frac{1}{\delta}}$. (3.51)
```

This is a great results shows how the error of using an estimate for the risk, the empirical risk that we can evaluate from the test (or validation) data, becomes smaller with training examples and with the number of possible hypotheses.

While the error scales only with the log of the number of possible hypotheses, the values still extend to infinite when the number of possible hypotheses extends to infinite, more closely resembles the situation when we have parameterized hypotheses. However, Wapnik was able to show the following generalization in the infinite case. Given a hypotheses space with Wapnic-Chervonencis dimension VC(h), then, with probability $1 - \delta$, the error of the empirical risk compared to the expected risk (true risk) is

```
$|R(h) - \hat{R}(h)| > O \left(\sqrt{\frac{VC}{m} \log \frac{m}{VC}} + \frac{1}{m}\right).$
```

The VC dimension is thereby a measure of how many points can be divided by a member of the hypothesis set for possible label combinations of the point. For example, consider three arbitrary points in two dimensions as shown in Fig. 3.12, and let us consider the hypothesis class of all possible lines in two dimensions. We can always divide the three points under any class membership condition, of which two examples are also shown in the figure. By contrast, it is easy to find examples with four points that cannot be divided by a line in two dimensions. The VC dimension of lines is thus $VC = 3$.

## 3.6.5 Support vector regression

While we have mainly classified in the last few sections, it is time to consider the general case of regression and connect these methods to the general principle of maximum likelihood estimation outlined in the previous chapter. It is again easy to illustrate the method for the linear case before generalizing it to the non-linear case similar to the strategy for SVMs.

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_70_0.png)

Fig. 3.13 Illustration of support vector regression and the $\epsilon$-insensitive cost function.

The idea in support regression is that data points connect to a regression line are expected to fluctuate but that should not take outliers into much account. This can be achieved with an error function which does not count deviations from the hypothesis that are less than $\epsilon$ form the hypothesis. Such an error function is often called an $\epsilon$-insensitive error function and is illustrated in Fig. 3.13. Three points of different classes cannot be separated by a single line, but these are singular points that are not effective in the definition of VC dimension.

```
$$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i}(\xi_i + \xi^*), \quad (3.53)$$
```

subject to the constraints

```
$y^{(i)} - \mathbf{w}^T\mathbf{x} - b \ge \xi_i \quad (3.54)$
$$y^{(i)} - \mathbf{w}^T\mathbf{x} - b \le \xi_i^* \quad (3.55)$$
$$\xi_i, \xi_i^* \ge 0. \quad (3.56)$$
```

The dual formulations again only depend on scalar products between the training examples, and the regression line can also be expressed by a scalar product between the support vectors and the prediction vector,

```
$h(\mathbf{x}; \alpha_i, \alpha_i^*) = \sum_{i=1}^{m}(\alpha_i - \alpha_i^*)\mathbf{x}_i^T\mathbf{x}. \quad (3.57)$
```

Thus, we can again use kernels to generalize the method to non-linear cases. In practice it has been more challenging to get SVR models to learn effectively and they are now mostly replaced by neural networks.

## 4.1 Neurons and the threshold perceptron

The brain is composed of specialized cells. These cells include neurons, which are thought to be the main information-processing units, and glia, which have a variety of supporting roles. A schematic example of a neuron is shown in Fig. 4.1a. Neurons are specialized in electrical and chemical information processing. They have extensions called an axon to send signals, and extensions called dendrites. The contact zone between the neurons is called a synapse. A sending neuron is often referred to as the presynaptic neuron and the receiving cell is a postsynaptic neuron. When an neuron becomes active it sends a spike down the axon where it can release chemical neurotransmitters. The neurotransmitters can then bind to receptors on the dendrite that triggers the opening of ion channels. Ion channels are specialized proteins that form gates in the membrane. When charged ions change the voltage (membrane potential) of the neuron. The dendrite and cell body acts like a cable and a capacitor that integrates (the sums) of all synapses. When the combined voltage at the axon reaches a certain threshold, a spike is generated. The spike can then travel down the axon and affect further neurons.

This outline of the functionality of a neuron is, of course, a major simplification. For example, we ignored the description of the specific time opening and closing of ion channels and hence some of the more detailed dynamics of activity. Also, we ignored the description of the transmission of the electric signals within the neuron; this is why such model is called a point-neuron. Despite these simplifications, this model captures important aspects of neuron functionality. Such model serves for us to build simplified models that demonstrate some of the information-processing capabilities of such simplified neuron or a network of simplified neurons. We will now describe this model in mathematical terms so that we can simulate such neurons with the help of a computer.
