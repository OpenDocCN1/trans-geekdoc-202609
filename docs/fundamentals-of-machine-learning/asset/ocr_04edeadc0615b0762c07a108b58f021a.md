As in the discussion of support vector regression, there it is common to use the $\epsilon$-insensitive loss function, where errors less than a constant $\epsilon$ do not contribute to the error measure, only errors over this value. The corresponding probabilistic models in this case are

```
$E = ||y - h(x);\mathbf{w}||_\epsilon = p(y;\mathbf{w}) = \frac{p}{2(1-\epsilon)}exp(-||y - h(x);\mathbf{w}||_\epsilon). \quad (7.19)$
```

We only mention these examples that probabilistic regression can be seen as regressing a deterministic model with an appropriate loss function that depends on the nature of the noise.

# 7.3 Probabilistic classification

We have already encountered classification methods such as support vector machines and decision trees. We now argue that classification can be seen as an important special case of probabilistic regression. In classification, features are mapped to a finite number of categories. We now discuss binary classification again, which is the case of only two classes where the target function (y-values) might have two possible values as 0 and 1. Later, we can easily generalize the ideas to more classes. We start here by describing a binary random variable.

# 7.3.1 MLE of the Bernoulli model

An important model of a binary random variable is the Bernoulli model. In this model, a random number takes the value of 1 with probability $\phi$, and the value 0 with probability $1-\\phi$ (the probability of being either of the two choices to be 1). That can be nicely contained in the formula,

```
$p(y) = \phi^y(1-\phi)^{1-y}. \quad (7.20)$
```

Such a random variable is called Bernoulli distribution. A Bernoulli distribution is characterized by one parameter, $\phi$. Tossing a coin is a good example of a Bernoulli process (a process of generating random numbers). We can use maximum likelihood estimation, MLE, to estimate the parameter $\phi$ from such trials. That, let us consider $m$ trials with $h$ heads have been found. The log-likelihood of such $m$ trials is

```
$l(\phi) = \log \prod \phi^{(i)}}(1-\phi)^{1-y^{(i)}} \quad (7.21)\n= \log(\phi^h(1-\phi)^{m-h}) \quad (7.22)\nl= h\log(\phi) + (m-h)\log(1-\phi). \quad (7.23)$
```

To find the maximum with respect to $\phi$ we set the derivative of $l$ with respect to the parameters $\phi$ to 0,

```
$$\frac{dl}{d\phi} = \frac{h}{\phi} - \frac{m-h}{1-\phi}} \quad (7.24)$
```
