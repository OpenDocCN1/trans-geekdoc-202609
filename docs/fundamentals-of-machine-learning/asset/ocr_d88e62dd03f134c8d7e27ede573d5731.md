With these rules we get

```
$$\frac{\partial E}{\partial w_j} = \frac{1}{N}\sum_i \left(y^{(i)} - y(\mathbf{x}^{(i)}; w)\right)(-1) \frac{\partial y}{\partial w_j} (5.48)$
```

The derivative of our model with respect to its parameters is

```
$$\frac{\partial y}{\partial w_j} = \frac{\partial}{\partial w_j} \frac{1}{1+e^{-\sum_i w_{x_i}}} = \frac{e^{-\sum_i w_{x_i}}}{(1+e^{-\sum_i w_{x_i}})^2} \frac{\partial \sum_i w_{x_i}}{\partial w_j} (5.49)$
```

In the remaining derivative over the sum, only the term that contains the $w_j$. Hence this derivative is $x_j$. Also, we can write some of this equation in terms of the original function to simplify the expression, namely

```
$$\frac{e^{-\sum_i w_{x_i}}}{(1+e^{-\sum_i w_{x_i}})^2} = y(1-y), (5.50)$
```

and hence

```
$$\frac{\partial y}{\partial w_j} = y(1-y)x_j. (5.51)$
```

We can now collect all the pieces and write the whole update rule for the weight values as

```
$w_j \leftarrow w_j - \alpha \frac{1}{N}\sum_i \left(y^{(i)} - y(\mathbfmathbf{x}^{(i)}; w)\right)y(\mathbfmathbf{x}^{(i)}; w)(1-y(\mathbfmathbf{x}^{(i)}; w))x_j^{(i)} (5.52)$
```

The first factor within the body of the sum is called the delta in the term.

```
$$\delta(\mathbf{x}^{(i)}; w) = y^{(i)} - y(\mathbf{x}^{(i)}; w))y(\mathbf{x}^{(i)}; w)(1-y(\mathbf{x}^{(i)}; w)). (5.53)$
```

or, if we write this without the arguments to see the structure clearly, this is

```
$$\delta = (y^{(i)} - y)y(1-y). (5.54)$
```

We can use the learning rule in a generic form

```
$w_j \leftarrow w_j + \alpha \frac{1}{N}\sum_i (delta(\mathbf{x}^{(i)}; w))x_j^{(i)}). (5.55)$
```
