The main point to realize now is the dividing hyperplane that maximizes the margin is most likely to be a good choice. Why is that? We should assume the training data, shown in the figure, are some examples of the underlying density function describing the distribution of points within each class and representative of the most likely data. It is then likely that new data points, which we want, are close to the already existing data points. If we use the separating hyperplane as far as possible from each point, then we probably won't make misclassification on future data points. Or, in other words, a separating hyperplane like the one dashed in the figure, is simply to offer better generalization than the maximum margin hyperplane. Thus, the maximum margin hyperplane can be considered the best choice if we assume that both classes have the same expected variance from the training data. Such maximum margin classifier can hence be expected to be a good choice.

Let formalize the maximization of the margin a bit more. Learning a linear margin classifier on labeled data means finding the parameters $w$ and $b$ that maximize the margin. For this we could compute the distances of each point from the hyperplane, which is simply a geometric exercise,

$$\gamma^{(i)} = y^{(i)} \left( \frac{|\mathbf{w}^T\mathbf{x}^{(i)} + b|}{\|}{\\mathbf{w}\|} \right). \quad (3.14)$

The vector $w/|\w\|$ is the normal vector of the hyperplane, a vector of unit length perpendicular to the hyperplane. The norm $|\w\|$ is the Euclidean distance of the vector $w$. The margin we want to maximize is the distance to the closest point,

$$\gamma = \min_i \gamma^{(i)}.$ \quad (3.15)$

We formulate the maximum margin calculation by realizing from Egn 3.14 that maximizing $\gamma$ is equivalent to minimizing $|\w\|$, or, equivalently, of minimizing

$$\frac{1}{\w,2}|\w\|^2.$ \quad (3.16)$

Of course, we want to maximize this margin under the constraint that no point should lay within the margin. Since we have the freedom to choose a scale, we can define this distance as 1, so that the decision boundaries become

$$\w^T\mathbf{x}^{(i)} + b \ge 1 \quad y^{(i)} = 1$ \quad (3.17)$

$$\w^T\mathbf{x}^{(i)} + b \le -1 \quad y^{(i)} = -1.$ \quad (3.18)$
