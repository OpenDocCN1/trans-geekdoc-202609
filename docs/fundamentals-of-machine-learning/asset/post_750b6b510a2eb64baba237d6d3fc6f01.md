```python
def matmulslow(a,b):
    m = a.shape[1]
    c=np.zeros((m,m))
    for i in range(m):
        for j in range(m):
            for k in range(m):
                c[i,j]=c[i,j]+a[i,k]*b[k,j]
    return c
```

### 2.4.1 Basic plots of iris data

Since machine learning requires data, we are commonly faced with importing data from files. There are a variety of tools to handle specific file formats. The most basic one is to reading data text files. We can then manipulate the data and plot them in a form which can help us gain insights into the information we want to get from the data. We will discuss some classical machine learning examples. These data are now included in the libraries so it will save us some time. However, preparing data to be used in machine learning is a large part of applying machine learning in practice. The following examples are provided in the program HouseMNIST.ipynb.

We start with the example of the well-known classification problem of iris flowers. The iris dataset was collected from the same day as the Gaspé region of eastern Quebec in Canada. These data were first used by the famous statistic statistic Ronald Fisher in a 1936 paper. The data consists of 150 samples, 50 samples of each of 3 species of the iris flower called Setosa (0), Versicolor (1), and Iris Virginica (2). For our purpose, we simply give each class a label such as a number, shown in the bracket after the flower names in this example.

The dataset is given on the book's web with three files, named iris.data, feature_names.txt, and target_names.txt, to start practising handling. These are basic text files and their contents can be inspected by loading them into an editor. We are now exploring this data with the program iris.ipynb. The file contains both the feature values and the class label, and we can load this data into a NumPy array with NumPy functions. Printing the shape of the array reveals that there are 150 lines of data, for each sample, and 5 columns. The first four values are the measured length and width of sepals and petals of the flowers. The last number is the class label. The following code separates this data array into feature matrix and a target vector for all samples. We also show how text can be handled with the NumPy function genfromtxt.
