# 9.3.2 Other gated architectures and attention

A popular slightly modified variant of LSTM is the gated recurrent unit (GRU) defined in Fig. 9-A. This model is defined by the following equations

```
$z(t) = \sigma(\mathbf{w}_z\mathbf{x}(t), \mathbf{h}(t-1))\ntr(t) = \sigma(\mathbf{w}_r\mathbf{x}(t), \mathbf{h}(t-1))\n\tilde{h}(t) = \tanh(x(t), r(t)\mathbf{h}(t-1))\n\mathbf{h}(t) = (1 - z(t))\mathbf{h}(t-1) + z(t)\tilde{h}(t)$
```

This model has a read gate $r$ and a zero gate $z$, but it uses the hidden state itself as memory state. It is a slightly more compact version of the LSTM with fewer parameters. Both the GRU and LSTM usually exhibit similar performance.

There are also various extensions of the gated recurrent units discussed above. A major step is to take the idea further in form of an external memory. The first version of such a model was called the Neural Turing (NTM). The basic idea is to use a separate external memory with reading and writing gates. The memory itself is a combination of an location-based memory and content-addressable memory. It is also important that all operations are differentiable in order to train such recurrent models with backpropagation through time. The advanced version of NTM is therefore called the differentiable neural computer (DNC). Such an architecture is outlined in Fig. 9.B.
