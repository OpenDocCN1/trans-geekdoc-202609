For multi-class problems, the equivalent of the sigmoid is the softmax function

```
$p(\tilde{y}=i|\mathbf{x};\mathbf{w})=\frac{e^{xW_i}}{\sum_{j=1}^N e^{xW_j}} (7.76)
```

$N$ is the number of classes. You can easily see the equivalence to the sigmoid in the case of having two classes where one of them has input,

```
$p(\	ilde{y}=0)=\frac{e^0}{e^0+e^{xw}}=\frac{1}{1+e^{xw}}=1-\frac{1}{1+e^{-xw}}\n$p(\	ilde{y}=1)=\frac{e^{xw}}{e^0+e^{xw}}=\frac{e^{xw}}{1+e^{xw}}=\frac{1}{1+e^{-xw}}$
```

The derivation of the gradient for this multi-class case works out the same as the binary classification,

```
$\frac{dL}{d(x\mathbf{W})}=p(\mathbftilde{y})-\mathbf{y} (7.77)\n$\frac{dL}{d\mathbf{x}}}=(p(\mathbftilde{y}))\mathbf{W}^T (7.78)\n$\frac{dL}{d\mathbf{W}}=\mathbf{x}^T(p(\mathbftilde{y})-\mathbf{y}) (7.79)
```

Thus, in summary. A neural network, regardless of having many or fewer, is in this case implementation of a probabilistic model for classification or logistic regression when the output layer is chosen to be a softmax function and the loss function is the negative entropy. This concludes the conclusion of our second point, how neural networks are linked to probabilistic regression.

# 7.6.2 Stochastic and Bayesian neural networks

We have outlined how we can use a neural network as parameterized function approximator $y=f(\mathbf{x};\mathbf{w})$. We have used this to approximate a probability function $p(y|\mathbf{x})$ where we determined the parameters from a learning rule such as maximum likelihood estimation. In a Bayesian inference we want to go a step further where we want not just to use a point estimate of the parameters but know the posterior probability of all kind of values of the parameters that could have generated the training data, $p(\mathbf{w}|\mathbf{x};y)$. With this function we can make true estimates of the probability of predictions of the label $y^0$ for a new data point $\mathbfmathbfx}^0$.

```
$p(y^0|\mathbf{x}^0)=\int p(y|\mathbf{x}^0;\mathbf{w})p(\mathbf{w}|\mathbf{x};y)d\mathbf{w} (7.80)
```

Unfortunately, the posterior $p(\mathbf{w}|\x;y)$ is usually not tractable, and approximate techniques like variational inference have to be used. While a detailed discussion is beyond the scope of this book, we recommend work by David McKay, Radford Neal, and Zoubin Ghahramani for further studies.
