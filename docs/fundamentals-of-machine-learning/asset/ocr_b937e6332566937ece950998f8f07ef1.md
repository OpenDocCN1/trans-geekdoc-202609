A momentum term of $m = 0.9$ is a common starting value, but such hyperparameters of the algorithms are of course problem-dependent and need to be evaluated on a case-by-case basis.

Local minima have often been stated as a main difficulty for gradient descent, although true minima are increasingly difficult to realize in higher dimensions. To be a true local minimum, it is necessary that all changes and combination of directions of the parameters lead to larger loss values. It is clear that with increasing dimensions there is therefore an increasing chance to find an ‘escape route’. However, even so, it is now known that true local minima are not likely to be the problem with high-dimensional learning scenarios, saddle points, or at least shallow areas of the loss functions seem to present a problem in many applications. A momentum term is a common way to help with such areas.

There are additional techniques in common use tools. For example, we can change the learning rate based on the history of the learning performance, and such adaptive learning rates are now commonly used. For example, a very popular algorithm is the ADAM optimizer. ADAM stands for adaptive moment estimation which is a slight modification of the momentum method. Instead of strictly using the last entry of the gradient the ADAM method uses a sliding average of the gradient

```
$$m \leftarrow \alpha_1 m + (1 - \alpha_1)\nabla L^{(i)}$$
```

as well as the variance of the gradient

```
$$v \leftarrow \alpha_2 v + (1 - \alpha_2)(
abla L^{(i)})^2$$
```

to modulate the update with the gradient. The model parameters are updated according to

```
$$w \leftarrow w - \alpha \frac{m/(1-\alpha_3)}{\sqrt{v/(1-\alpha_2)} + \epsilon}$$
```

where the small factor $\epsilon$ is added to prevent possible divisions by zero.

There are more advanced variants of gradient descent methods in use. For example, it is possible to take into account higher-order gradient terms that describe the curvature of the loss functions. While this requires the calculation of derivatives or, in general, the Hessian, it will allow much larger learning rate parameters that will speed up learning.
