# 3.7.2 Logistic regression

In machine learning we usually consider the case of classification when the parameter $\phi$, depends on an attribute $x$. We can thus write a probability model

```
$p(y=1|\mathbf{x};\mathbf{w})=f(\mathbf{x};\mathbf{w}) (7.27)$
```

```
$p(y=0|\mathbf{x};\mathbf{w})=1-f(\mathbf{x};\mathbf{w}), (7.28)$
```

where $f(\mathbf{x})$ is a hypothesis function that we need to specify further. We can combine the probabilities into one

```
$$p(y|\mathbf{x};\mathbf{w})=(f(\mathbf{x};\mathbf{w}))^y(1-f(\mathbf{x};\mathbf{w}))^{1-y} (7.29)$
```

The corresponding log-likelihood function is

```
$$l(\mathbf{w})=\sum_{i=1}^m y^{(i)}\log(f(\mathbf{x}^{(i)};\mathbf{w}))+(1-y^{(i)}))\log(1-f(\mathbf{x}^{(i)};\mathbf{w}))) (7.30)$
```

To find the maximum we can use the gradient ascent algorithm, which is like the gradient descent algorithm with a changed sign,

```
$$\mathbf{w} \leftarrow \mathbf{w}+\alpha\nabla_{\mathbf{w}}l(\mathbf{w}). (7.31)$
```

To calculate the gradient we can calculate the partial derivative of the log-likelihood function with respect to each parameter,

```
$$\frac{\partial l(\mathbf{w})}{\partial w_j}=\frac{1}{f}(1-y)\frac{1}{1-f}\frac{\partial f(\mathbf{w})}{\partial w_j} (7.32)$
```

where we dropped indices for better readability.

Let us apply this to logistic regression. An example of 100 samples of two classes (crosses and stars) are shown in Fig.7. The data shows that it is more likely that the class is $y=0$ for small values of $x$ and that the class is $y=1$ for large values of $x$, and that the probabilities are more similar. Thus, we put forward the hypothesis that the transition between the low and high probability region is smooth and quadratic if this hypothesis as parameterized density function known as a logistic function or sigmoid function

```
$$f(\mathbf{w})=\frac{1}{1+\exp(-\mathbf{w}^T\mathbf{x})} (7.33)$
```
