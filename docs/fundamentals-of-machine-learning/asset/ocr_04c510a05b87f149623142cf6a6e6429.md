After importing the necessary libraries, we start by defining the encoder model. We use here three convolution layers with $3 \times 3$ kernels. In the second layer we use a stride that eliminates the need for max pooling that we use in Chapter 4. We use the shape of the output after the convolutional layers as we need this later to up-sample in the inverse way. We then flatten the output so that we can feed into a dense layer with thirty-two nodes and finally to two output layers, representing the mean and the variance of an $n$-dimensional Gaussian. The $n$ is here the dimension of the latent space, set to 2 in this example as will be a useful dimension to visualize.

# **Listing 8.2** VAE.ipynb (part 1)

```
import numpy as np
import matplotlib.pyplot as plt
from keras import models, layers, optimizers, datasets, utils, losses
from keras import backend as K

# encoder model
input = layers.Input(shape=(28, 28, 1))
latent_dim = 2
x = layers.Conv2D(32,(3,3),padding='same',activation='relu')(input)
x = layers.Conv2D(64,(3,3),padding='same',activation='relu',strides=(2,2))(x)
x = layers.Conv2D(64,(3,3),padding='same',activation='relu')(x)
shape, _,, flattening = K.int_shape(x)
x = layers.Flatten(x)
x = layers.Dense(32, activation='relu')(x)

z_mean = layers.Dense(latent_dim)(x)
z_log_var = layers.Dense(latent_dim)(x)
```

We then implement the sampling from the Gaussian that is specified by the decoder. Since every operation in Keras has to be implemented as a layer, we need to show here a useful technique. As a simple way to implement an arbitrary expression as Keras is to use the layer wrapped Lambda. We can define functions which we then pass to this wrapper layer so that the output of this layer becomes the sample we need as input to the decoder. The decoder then simply uses reshaping and transpose convolutions to generate images with the original image size.
