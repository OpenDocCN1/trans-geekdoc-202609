# 10.2.3 Bellman function for optimal policy and value ($Q$) iteration

Since we are primarily interested in the optimal policy, we could try to solve the Bellman equation immediately for this policy,

```
$Q^*(s, a) = \rho(s, a) + \gamma Q^*(	au(s, a), \pi'(\tau(s, a))). \quad (10.16)
```

The problem is that this equation now depends on the unknown $\pi^*$. However, we can check in each state all actions and the one which gives us the best return. This should be equivalent to the equation above in the optimal case. Here we propose

**Optimal Bellman equation:** $Q^*(s, a) = \rho(s, a) + \gamma \max_{a'} Q^*(\tau(s, a), a'). \quad (10.17)

We can solve this equation again with the iterative method when the transfer function and the rewards function are known,

**Q-iteration:** $Q_{i+1}(s, a) \leftarrow \rho(s, a) + \gamma \max_{a'} Q_i(\tau(s, a), a'). \quad (10.18)

The corresponding code for our example is

Listing 10.2 RL.ipynyb (Part 12)

```
print('--> Q-iteration')
Q.new = np.zeros([5,2])
Q.zeros = np.zeros([5,2])
policy = np.zeros(5)
for iter in range(3):
    for s in range(0,5):
        for a in range(-1,2):
            maxValue = np.max(Q[tau(s,a),0], Q[tau(s,a),1])
            Q.new[s,Q.id(a)] = rho(s,a) + gamma*maxValue
    Q.copy(Q.new)

policy = calc_policy(Q)
print('Q values:\n' + np.str(transpose(Q))
print('policy:\n' + np.str(transpose(policy)))

--> Q-iteration

[0. 0.5 1. 2. 0.]]

```

In this example we used only three iterations which are sufficient to reach the correct values. In practice, we can terminate the process if the changes are sufficiently small, which we did not implement here to keep the code short.

There is an interesting difference between this value iteration method and the previous policy iteration. In the policy iteration method we followed the policy to calculate the value function. We call such a method **on-policy**. In contrast, in the ($Q$) iteration, we check out all possible actions from this state for the update of the value function. Such a procedure is **off-policy**.
