We will here outline the idea behind such techniques. One is to work out the algebraic expression of a derivative by hand and then code the result. For example, let's assume we want to find the gradient of the function

```
f(x, y) = \sin(x) + x * y + \ln(y)
```

which we can find by applying the analytic differentiation rules to be

```
\frac{\partial f(x,y)}{\partial x} = \left( \frac{\cos(x) + y}{x + \frac{1}{y}} \right).
```

The expressions on right can also be found with symbolic mathematical manipulations implemented in symbolic code for tools like Maple or Mathematica. We can then use these expressions to calculate the values of the gradients at specific points $x_0$ and $y_0$. For example, the partial derivative of the function in $x$-direction at $x=0$ and $y=1$ is $|\frac{\partial f(x,y)}{\partial x}|_{(0,1)} = 2$.

While such methods are exact save manual mistakes, another possibility is we to use numeric approximations based on finite difference quotients for the partial derivatives like

```
\frac{\partial f(x,y)}{\partial x} = \frac{f(x + \Delta x, y) - f(x, y)}{\Delta x}
```

Such an approximation is easy to implement but introduces numerical errors. For example, with a width of $\Delta x=0.1$ we get a value of $|\frac{\partial f(x,y)}{\partial x}|_{(0,1)} \approx 1.998$ for our example. While this seems acceptable, in such errors can result in large variances for complex non-linear functions that are rarely used in machine learning.

The common way of implementing gradient calculations in machine learning is to represent functions as graphs of basic functions and then use a chain rule to represent their derivatives as a graph of derivatives. Backpropagation itself is actually an example of such a strategy. We first explain the basic idea behind automatic differentiation. We start with the forward mode for automatic differentiation. We can represent the example above with the primal graph in Fig. 5.15 where

```
v_1 = x (=0)
v_2 = y (=1)
v_3 = \sin(v_1) (=0)
v_4 = \ln(v_2) (=0)
v_5 = v_1 * v_2 (=0)
v_6 = v_3 + v_4 + v_5 (=0)
```

This is like a neural network where every node can have a different function. In brackets, we show the evaluation of these functions with input $x=0$ and $y=1$.

If we want to take the derivative of the function with respect to the inputs, we can apply the chain rule. To simplify the notation, we can write the partial derivative as an adjoint variable. Then we have the derivative graph similar to the primal graph with

```
\hat{v}_6 = 1
\hat{v}_5 = \frac{\partial \hat{v}_6}{\partial v_5} = \hat{v}_6 * 1 (= 1)
\hat{v}_4 = \frac{\partial \hat{v}_6}{\partial v_4} = \hat{v}_6 * 1 (= 1)
```

These are again elementary function nodes that form a graph for the derivative, analog to the primary function graph. At this point it is wise to note that such functions are already implemented as code so that they can be used to calculate the values of the gradients at specific points. For example, if we want to calculate the partial derivative with respect to $x$, then $dv_1=1$ and $dv_2=0$. All other variables are given by the expressions in the brackets above.

The forward mode of automatic differentiation is easy to implement but there are other algorithms that can be more suited for what we have to calculate like neural networks and show how backpropagation algorithm is a form of automatic differentiation. The reverse mode starts with a forward pass through the network. We also define adjoint variables

```
\frac{\partial f}{\partial v_i}
```

which specifies how much the variable $v_i$ contributes to the change in the output. With these notations we can unravel the chain rule in reverse order

```
\hat{v}_6 = 1
\hat{v}_5 = \frac{\partial \hat{v}_6}{\partial v_5} = \hat{v}_6 * 1 (= 1)
\hat{v}_4 = \frac{\partial \hat{v}_6}{\partial v_4} = \hat{v}_6 * 1 (= 1)
```

## 6 Basic probability theory

Probably the biggest challenge in using data to build models is the nature of uncertainty. This includes the limited knowledge about the world, such as relying on noisy or unreliable sensors. Even knowing if a sample set is appropriate to cover the dependencies we want to uncover, some uncertainty exists in machine learning. The mathematical description of uncertainty is covered in probability theory, and it should not be a surprise that this language with a refresher in probability theory has helped enormously to formalize the areas of machine learning for a deeper understanding.

This chapter provides a refresher in probability theory, in particular with respect to the formulations that build the theoretical language of modern machine learning. Probability theory is the formalization of random numbers, and we outline what these are and how they are characterized by probability density or probability mass functions. We discuss how functions have traditionally been characterized and provide a review of how to work with such mathematical objects as transforming density functions and how to measure differences between density function.

### 6.1 Random numbers and their probability (density) function
