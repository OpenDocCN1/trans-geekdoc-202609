# #### 7.6.1 Neural networks as probabilistic regression

As argued, coming up with a parameterized model is often the hard part in machine learning. Up until this time we have tried to specify causal models with explicit analytic expression for its components to specify a multinomial density function. In Chapter 4 we see how we can use neural networks as a tool to simplify complex models. The question now is how we can reconcile neural networks with the probabilistic view of modeling. We will touch on three aspects of this discussion: that of generic versus specific models, of representing probability functions, and of stochastic models.

Let us with the first: of building functional descriptions for a specific problem that we want to model using neural networks that seem to offer a generic solution. We already discussed Wolpert’s “No free lunch” theorem, and it is clear that we should not expect that high-dimensional models are optimal compared to models that are close to the truly underlying world model. However, in practice there is the problem of finding this specific model, and building a very general machine is one way of moving forward.
