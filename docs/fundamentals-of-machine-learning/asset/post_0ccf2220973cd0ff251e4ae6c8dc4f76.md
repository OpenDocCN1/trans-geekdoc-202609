Let us illustrate the basic idea with an example in two-dimensions. A linear function with two attributes that span the 2-dimensional feature space is given by

```
$y = w_0 + w_1x_1 + w_2x_2 = \mathbf{w}^T\mathbf{x},$
```

with

```
$$\mathbf{x} = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}
```

and weight vector

```
$$\mathbf{w}^T = (w_0, w_1, w_2).$
```

Let us say that we cannot separate the data with this linear function but that we could separate it with a polynomial that would include second-order terms like

```
$y = \tilde{w}_0 + \tilde{w}_1x_1 + \tilde{w}_2x_2 + \tilde{w}_3x_1x_2 + \tilde{w}_4x_1^2 + \tilde{w}_5x_2^2 = \tilde{\phi}(\mathbf{x}).$
```

We can view the second equation as a linear separation on a feature vector

```
$$\mathbf{x} \rightarrow \phi(\mathbf{x}) = \begin{pmatrix} x_1 \\ x_2 \\ x_1x_2 \\ x_1^2 \\ x_2^2 \end{pmatrix}
```

This can be seen as mapping the attribute $(1, x_1, x_2)$ to a higher-dimensional space with the mapping function $\phi(\mathbf{x})$. We call this a feature map. The separating hyperplane is then linear in this higher-dimensional space. Thus, we can use the linear maximum classification method in non-linear cases if we replace all occurrences of the attribute $\mathbf{x}$ with the mapped feature $\phi(\mathbf{x})$.

There are only three problems remaining. One is that we don't know what the mapping function should be. The somewhat ad-hoc solution to this problem will be that we try out some functions and see which works best. We will discuss this further later in this chapter. The second problem is that we have the problem of overfitting

The third problem is that with an increased number of dimensions the evaluation of the equations becomes more computational. However, there is a useful trick to alleviate the last problem in the case when the calculations always contain dot product between feature vectors. An example of this is the solution of the minimization problem of the dual problem in the earlier discussions of the linear SVM. The problem to be minimized in this formulation depends only on the dot product between a vector $\mathbf{x}^{(i)}$ of one example and another example $\mathbf{x}^{(j)}$. Also, when predicting for a new input vector $\mathbf{x}$ from Eq. 3.24 when adding the feature maps, we only need the resulting values for the dot products $\phi(\mathbf{x}^{(i)})^T\phi(\mathbf{x})$. We now discuss how such dot products can be represented with functions called kernel,

```
$K(\mathbf{x}, \mathbf{z}) = \phi(\mathbf{x})^T\phi(\mathbf{z}).$
```

Instead of actually specifying a feature map, which is often a guess to start with, we could actually specify a kernel function. For example, let us consider a quadratic kernel between two vectors $\mathbf{x}$ and $\mathbf{z}$

```
$K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z} + 1)^2.$
```

We can then write this in the form of Eq. 3.38 to find the corresponding feature map. That is,

```
$K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z})^2 + 2\mathbf{x}^T\mathbf{z} + 1$
$= (x_1z_1 + x_2z_2)^2 + 2x_1z_1 + x_2z_2 + 1$
$= x_1^2z_1^2 + x_2^2z_2^2 + 2x_1z_1x_2z_2 + 2x_1z_1 + 2x_2z_2 + 1$
$= \phi(\mathbf{x})^T\phi(\mathbf{z}),$
```

with

Except for the factors of $\sqrt{2}$ that do not matter as these can be absorbed into the definition of the weight parameters, this is the mapping function we discussed earlier. Instead of calculating dot product in mapped space, we can calculate a dot product in the original-dimensional space and simply square the result. Also, savings of computational complexity become even more pronounced with higher-order polynomials which we replace calculation of $O(n^2)$ with a fixed calculation in the original attribute space. There is an impressive saving of computations with this kernel trick.
