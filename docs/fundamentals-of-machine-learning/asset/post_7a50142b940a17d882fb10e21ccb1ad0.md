While the neural network approach to SARSA can be applied to a continuous state and action space, many applications have a finite and relatively small set of possible actions, and it is more common to use a $Q$-learning (off-policy) strategy in this case. Here we compare the $Q$-values of all possible actions from a specific state. While we could iterate over the previous network, we can also learn a network that has been taken by Riedmeier in 2005 with the nearly fitted $Q$-iteration (NFQ) algorithm. The basic idea is shown in Fig. 10.7 with network B. In this case we can train the network with the following loss-function

```
$E(s_t, a_t) = (r_t + \gamma \max Q(s_{t+1}; w) - Q(s_t, a_t; w))^2$
```

which corresponds to training the connections to the winning node as well as the connections feeding into it through backpropagation. To apply this strategy to the maze environment, if the agent is in state 2 then we can write the 1-hot input vector to the network as `s=np.array([0,0,1,0,0,0])`. Such a network is illustrated in Fig. 10.7C. We then have to modify our layer functions to calculate the next state, and we need a small function to identify if the state is a final state.

-   **Listing 10.16** RL_mlp.py (Part 1)

```python
import numpy as np
import matplotlib.pyplot as plt
from keras import models, layers, optimizers

def tau(s,a):
    if s[0] and s[4] == 0 : s:=np.roll(s,a)
    return s

def rho(s):
    return ((s[0]==1)+2+(s[4]==1))

def terminal_state(s):
    return (s[0]==1 or s[4]==1)

gamma=0.5
invT = 1
```

The variable invT represents the inverse temperature for the exploration. It is very high at the beginning, but we will later decay this value. So there is a lot of exploration at the beginning but much less later.

We define a small dense network with five inputs for the state vector, ten hidden nodes, and two output nodes, each representing the Q-value for each action, that of going left or right.

## 10.4.2 Deep Q-learning

At the time of the TD-Gammon, the MLP with one hidden layer has been the state of the art, elaborate models with more hidden layers have been difficult to train. However, deep learning has made major progress over several factors, including faster computers with specialized processors such as GPUs, larger databases with lots of training example, the rediscovery of convolutional networks, and better regularization techniques. The combination of deep learning with reinforcement learning has recently made major breakthroughs in AI. These breakthroughs have been demonstrated by playing Atari games and winning the chessboard game Go against a grandmaster by the deep learning system AlphaGo by DeepMind. The Atari games are a great example of learning directly from sensory data in an environment that is much more complex than typical low-dimensional environments to RL systems have been applied. Mastering the game is relevant as it has been considered one of the most challenging examples for AI and was thought to require deep intuition by the players. ## 10.5 Actors and-critics

### 10.5.1 Policy search

So far we have focused on finding a value function and we derived from the greedy policy as the action that leads to the largest return. The value function can be seen as a critic to adapt the policy. Another approach, especially when using function approximators, is to consider a parameterized policy directly and to search for good parameters of the policy. Such approach is called an actor. We need to find parameters that maximize the payoff. We illustrated this with a setting in 10.1.1C. It is now time to think about the implementation of this actor as deep neural network which takes observations such as pictures from a camera and produces outputs such as motor commands for a mobile robot.
