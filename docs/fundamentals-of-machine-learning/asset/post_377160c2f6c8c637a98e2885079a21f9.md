### 5.6.1 The sigmoid perceptron and the delta learning rule

We are now ready to look at applying gradient descent to neural network models. We will start with a simple sigmoid neuron and generalize our approach to the multipayer perceptron.

As usual, we will start with a parameterized model and define an appropriate loss function. In Chapter 4 we started with the threshold perceptron. However, the threshold function is not differentiable and hence this model cannot be solved by gradient descent. However, we can use a differentiable approximation for the gain function in form of a sigmoid called the logistic function,

```
$g(x; \beta) = \frac{1}{1+e^{-\beta x}}. (5.39)
```

This is a differentiable approximation of the threshold function in the sense that when the parameter $\beta$ describes the slope of the function around $x=0$ goes to infinity, the threshold function is recovered. While we argued for this gain function in terms of approximating a threshold function, the logistic perceptron is a specific model or parameterized hypothesis functions in its own right, and we will later see that we can give this gain function a probabilistic interpretation.

The input to this perceptron is the weighted sum over the input channels

```
$h(x; \mathbf{w}) = \sum_{i} w_i x_i = \mathbf{w}^T \mathbf{x}, (5.40)
```

and the output is calculated with the gain function,

```
$y(x; \mathbf{w}) = g(h(x; \mathbf{w})) (5.41)
$$\frac{1}{1+e^{-\mathbf{w}^T \mathbf{x}}} (5.42)
```

where we have absorbed the parameter $\beta$ as a scaling factor in the parameters w. A. A graphical representation of this model is shown in Fig. 5.10A. The logistic perceptron

At this point we already know that to solving the problem is a gradient descent on a loss function. We will choose a common function in traditional neural networks by using the mean square error,

```
$E(\mathbf{w}) = \frac{1}{2N} \sum_{i} (y^{(i)} - y(x^{(i)};\mathbf{w}))^2.
```

The 1/2 in this formula is simple convention. We will later discuss which loss functions are appropriate, arguing that the loss function should be chosen carefully from a probabilistic interpretation. However, at this point it can be seen as a simple example.

To find this minimum we use gradient descent, and go through these steps as a reviewing exercise. In the gradient descent learning rule, weights are updated according to

```
$w_j \leftarrow w_j - \alpha \frac{\partial E}{\partial w_j},$
```

where $\alpha$ is a learning rate parameter. We can now calculate the gradient in order to provide a formula that can be implemented with Python. For this we have to recall two rules from calculus, namely that the derivative of an exponent function is

```
$$\frac{d}{dx}x^n = nx^{n-1}.$
```

The derivative of the Euler function is,

```
$$\frac{d}{dx}e^x = e^x,$
```

which is an interesting fact in its own right as this means that the function is equal to its slope at every point. This is not coincidental as the functionals is actually defined as such. Finally, we need the chain rule

```
$$\frac{d}{dx}f(g(x)) = \frac{df}{dg} \frac{dg}{dx}.$
```

With these rules we get

```
$$\frac{\partial E}{\partial w_j} = \frac{1}{N}\sum_i \left(y^{(i)} - y(x^{(i)};\mathbf{w})\right) (58)
```

The derivative of our model with respect to its parameters is

```
$$\frac{\partial E}{\partial w_j} = \frac{1}{N}\sum_i \left(y^{(i)} - y(x^{(i)};\mathbf{w})\right) (59)
```

The derivative over the sum, only the term that contains $w_j$.

```
$$\frac{\partial E}{\partial w_j} = \frac{1}{N}\sum_i \left(y^{(i)} - y(x^{(i)};\mathbf{w})\right) (50)
```

Hence this derivative is $x_j$. Also, we can write some of this equation to simplify the expression,

```
$$\frac{\partial E}{\partial w_j} = \frac{1}{N}\sum_i \left(y^{(i)} - y(x^{(i)};\mathbf{w})\right) (51)
```

The first factor within the body of the sum is called the delta in the term.

```
$$\delta(\mathbf{x}^{(i)}; w) = y^{(i)} - y(x^{(i)};\mathbf{w}) (52)
```

or, if we write this without the arguments to see the structure clearly, is

```
$$\delta = (y^{(i)} - y)y(1-y). (53)
```

We can use the learning rule in a generic form

```
$w_j \leftarrow w_j + \alpha \frac{1}{N}\sum_i (\delta(\mathbf{x}^{(i)}; w))x_j^{(i)}). (54)
```
