
# Probabilistic regression and Bayes nets

The logarithmic function increases monotonically. Hence, the maximum of $L$ is also the maximum of $l$. The maximum (log-)likelihood can be calculated from the training data as

```
$w^{MLE} = \text{argmax} l(w; x^{(1)}, ..., x^{(m)}) \quad (7.13)$
```

Of course, we still have to find the maximum in practice. We might be able to calculate this analytically or use one of the search algorithms to find a maximum from this function like gradient descent.

Let us apply this to the Gaussian model of the robot example. The log-likelihood function of our hypothesis function for this example

```
$l(w) = \log \prod_{i=1}^m \frac{1}{2\pi} \exp\left(-\frac{(y^{(i)} - w^T x^{(i)})^2}{2}\right) \quad (7.14)$
= \sum_{i=1}^m \log \frac{1}{\sqrt{2\pi}} - \frac{(y^{(i)} - w^T x^{(i)})^2}{2} \quad (7.15)$
```

or

```
$l(w) = -\frac{m}{2} \log 2\pi - \sum_{i=1}^m \frac{(y^{(i)} - w^T x^{(i)})^2}{2} \quad (7.16)$
```

Here you can see why using a small number is as good as a sum instead of having a large product of potentially small numbers. Since the first term in the expression Eq 7.16, $-\frac{m}{2} \log 2\pi$, is independent of $w$, maximizing the log-likelihood is equivalent to minimizing (because of the minus sign) a quadratic error term

```
$E = \frac{1}{2}(y - h(x;w))^2 \iff p(y|x;w) = \frac{1}{\sqrt{2\pi}}\exp\left(-\frac{(y-h(x;w))^2}{2}\right) \quad (7.17)$
```

This is the square-error loss function, or mean square (MSE) error if we consider a batch algorithm and divide the value by the number of examples in the batch. This loss function has given the choice for linear regression. It has also become in machine learning approaches such as multilayer perceptrons for a long time. In terms of probabilistic learning, the MSE is equivalent to MLE for Gaussian data with linear dependence of the mean and a constant variance.

However, these assumptions may or not hold in different applications. The data might not be Gaussian, and even if they are, the variance might be different for different features. In this case we would need to minimize 7.16 with a sigma in the denominator. Also, the mean might vary in a non-linear way with the parameters. But, the point here is the following: a Gaussian model of noise is clearly a good choice due to the central limit theorem. However, it is possible that there are better choices for specific applications that can lead to superior predictions.

We have discussed Gaussian distributed data in most of this section, but one can similarly consider corresponding functions for other distributions. For example, a polynomial loss function correspond more generally to a density model of the

```
$E = \frac{1}{p}||y - h(x;w)||^p \iff p(y|x;w) = \frac{1}{2\Gamma(1/p)}\exp(-|y-h(x;w)||^p) \quad (7.18)$
```

As in the discussion of support vector regression, there it is common to use the $\epsilon$-insensitive loss function, where errors less than a constant $\epsilon$ do not contribute to the error measure, only errors over this value. The corresponding probabilistic models in this case are

```
$E = ||y - h(x);\mathbf{w}||_\epsilon = p(y;\mathbf{w}) = \frac{p}{2(1-\epsilon)}exp(-||y - h(x);\mathbf{w}||_\epsilon) \quad (7.19)$
```

We only mention these examples that probabilistic regression can be seen as regressing a deterministic model with an appropriate loss function that depends on the nature of the noise.

# 7.3 Probabilistic classification

We have already encountered classification methods such as support vector machines and decision trees. We now argue that classification can be seen as an important special case of probabilistic regression. In classification, features are mapped to a finite number of categories. We now discuss binary classification again, which is the case where the target function (y-values) might have two values as 0 and 1. Later we can easily generalize the ideas to more classes. We start here by describing a binary random variable.

### 7.3.1 MLE of Bernoulli model

An important model of binary random variable is the Bernoulli model. In this model, a random number takes the value of 1 with probability $\phi$, and the value 0 with probability $1-\phi$ (the probability of not being 1). That can be nicely contained in the formula

```
$p(y) = \phi^y(1-\phi)^{1-y} \quad (7.20)$
```

Such a random variable is called Bernoulli distribution. A Bernoulli distribution is characterized by one parameter, $\phi$. Tossing a coin is a good example of a Bernoulli process (a process of generating random numbers). We can use maximum likelihood estimation, MLE, to estimate the parameter $\phi$ from such trials. That, let us consider $m$ trials with $h$ heads. The log-likelihood of such $m$ trials is

```
$l(\phi) = \log \prod_{i=1}^m \phi^{(y^{(i)})}(1-\phi)^{(1-y^{(i)})} \quad (7.21)$
= \log(\phi^h(1-\phi)^{m-h}) \quad (7.22)$
= h\log(\phi) + (m-h)\log(1-\phi) \quad (7.23)$
```

To find the maximum with respect to $\phi$ we set the derivative of $l$ with respect to parameters $\phi$ to 0,

```
$\frac{dl}{d\phi} = \frac{h}{\phi} - \frac{m-h}{1-\phi} \quad (7.24)$
$= 0 \quad (7.25)$
$\rightarrow \phi = \frac{h}{m} \quad (7.26)$
```

As one might expect, the maximum likelihood estimate of the parameter $\phi$ is the fraction of heads in $m$ trials.

### 7.3.2 Logistic regression

In machine learning we usually consider the case of classification when the parameter $\phi$ depends on attribute $x$. We can thus write a probability model

```
$p(y=1|\mathbf{x};\mathbf{w})=f(\mathbf{x}) \quad (7.27)$
$p(y=0|\mathbf{x})=1-f(\mathbf{x}) \quad (7.28)$
```

where $f(\mathbf{x})$ is a hypothesis function that we need to specify further. We can combine the probabilities into one

```
$p(y|\mathbf{x};\mathbf{w})=(f(\mathbf{x}))^y(1-f(\mathbf{x}))^{1-y} \quad (7.29)$
```

The corresponding log-likelihood function is

```
$l(\mathbf{w})=\sum_{i=1}^m y^{(i)}\log(f(\mathbf{x}^{(i)};\mathbf{w}))+(1-y^{(i)})\log(1-f(\mathbf{x}^{(i)};\mathbf{w})) \quad (7.30)$
```

To find the maximum we can use the gradient ascent algorithm, which is like the gradient descent algorithm with a changed sign,

```
$\mathbf{w} \leftarrow \mathbf{w}+\alpha\nabla_{\mathbf{w}}l(\mathbf{w}) \quad (7.31)$
```

To calculate the gradient we can calculate the partial derivative of the log-likelihood function with respect to each parameter,

```
$\frac{\partial l(\mathbf{w})}{\partial w_j}=\frac{1}{f}(1-y)\frac{1}{1-f}\frac{\partial f(\mathbf{w})}{\partial w_j} \quad (7.32)$
```

where we dropped indices for better readability.

Let us apply this to logistic regression. An example of 100 samples of two classes (crosses and stars) are shown in Fig.7. The data shows that it is more likely that the class is $y=0$ for small values of $x$ and that the class is $y=1$ for large values of $x$, and that the probabilities are more similar. Thus, we put forward the hypothesis that the transition between the low and high probability region is smooth and if we model this hypothesis as parameterized density function known as a logistic function or sigmoid function

```
$f(\mathbf{w})=\frac{1}{1+\exp(-\mathbf{w}^T\mathbf{x})} \quad (7.33)$
```

As before, we can treat this density function as a function of the parameters $\mathbf{w}$ for the given data values (likelihood function), and use maximum likelihood estimation to estimated values for the parameters so that the data are most likely.

We can now calculate the derivative of the hypothesis function $f$ with respect to the parameters for the specific choice of the logistic functions. This is

```
$$\begin{aligned}
\frac{\partial f}{\partial w} &= \frac{\partial}{\partial w} \frac{1}{1+e^{-wx}} && (7.34)$
&= \frac{1}{(1+e^{-wx})^2} e^{-wx}(-x) && (7.35)$
&= \frac{1}{1+e^{-wx}}(1) - \frac{1}{1+e^{-wx}}(-x) && (7.36)$
&= -f(1-f) && (7.37)$
\end{aligned}$$
```

Using this in Eqn 7.32 and inserting it into Eqn 7.31 with the identity

```
$$\begin{aligned}
\left(\frac{1}{f_j^{(i)}} - (1-y_j)\frac{1}{1-f_j^{(i)}}\right)f(1-f) &= y(1-f)-(1-y)f && (7.38)$
&= y-yf+yf && (7.39)$
&= y-f && (7.40)$
\end{aligned}$$
```

gives the learning rule

```
$$w_j \leftarrow w_j + \alpha (y_j^{(i)} - f(\mathbf{x}^{(i)})) x_j^{(i)} \quad (7.41)$
```

This is an interesting result this learning rule for logistic regression is similar to the learning rule for linear regression on Gaussian data. Also, logistic regression is equivalent to a simple neural network called a perceptron for which this learning rule was proposed on heuristic grounds in the 1950s, and it is usually called the perceptron learning rule. Our derivation shows that this old heuristic rule relates to assumptions of a probabilistic model.
