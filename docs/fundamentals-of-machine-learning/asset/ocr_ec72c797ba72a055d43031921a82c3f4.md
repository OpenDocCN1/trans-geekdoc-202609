To look for the larger $2 \times 2$ red patch in the image, we can define a $2 \times 2$ matrix which we call a filter. This filter swept over the image as we place the $2 \times 2$ matrix in the upper-left corner of the image and multiply the filter element with the corresponding image elements and sum all the results. For the red patch recognition we define filters, for each color channel, which we then add together.

**Listing 2.47.** `cv1.ipynb (part 7)`

```
# 2x2 convolution
f1=np.array([[2,2],[2,2]])
f2=np.array([[-1,-1],[-1,-1]])
f3=np.array([[-1,-1],[-1,-1]])
img=np.zeros((7,7))
for i in range(7):
    for j in range(7):
        img[i:i+2,j:j+2]=np.sum(f1*img[i:i+2,j:j+2]+f2*img[i:i+2,j:j+2]+f3*img[i:i+2,j:j+2], axis=None)
plt.imshow(img, cmap='gray')
max_idx=np.argmax(img)
max_position=np.unravel_index(max_idx,(7,7))
print(max_position)
```

The maximum of the resulting map is now at location of the larger red patch as shown in Fig. 2.9E.

The operation that we have just implemented-of element-wise multiplication of two matrices, adding up the values and repeating this for all positions of the filter is an operation called convolution. This operation represents a 2-dimensional convolution over each channel with possibly different filters, and then an addition of the channels. We will now discuss in more detail a single convolution, but it is good to keep in mind that the real operations we need in deep neural networks are convolutions over channels and adding channels.
