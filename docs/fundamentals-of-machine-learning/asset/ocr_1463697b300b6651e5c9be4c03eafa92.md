Such lists are useful for collecting data. However, since we need to perform well-defined mathematical operations on lists of data, it is useful to introduce a more versatile construct of such data in forms of a NumPy array.

Before proceeding, it might be good to review some of the naming conventions. A basic structure for a collection of data is called an "array" in computer science. In contrast to these simple data structure constructs, the mathematical concepts of a vector or matrix are different in that they include well defined mathematical operations on these data structures. Thus, the mathematical concept of a vector is a 1-dimensional array on which some operations are defined, such as adding two vectors with the same dimension by adding their components, or multiplying a vector with a scalar by multiplying each component of the vector with a scalar. Similarly, a matrix is a 2-dimensional construct with correspondingly defined operation. We can even generalize to higher dimensions, and such mathematical constructs are tensors. It is convenient to view a vector or matrix operation just as a special case of general tensor operations.

To create a NumPy array we use the NumPy array(). For example, a 1-dimensional Python list can be turned into a NumPy vector,

As shown in the second print statement, we can access an element of the array with indices in square brackets. The first element in an array has the index 0. Hence, the print command returns the value 1. It is useful to think about this as the offset from the first element. The index —1 accesses the last element in the vector. The third print command shows how to access a range of indices. Unfortunately, there is no distinction between a vector and a column vector in NumPy, so this needs some careful consideration when a distinction is necessary. We return to this point in a moment.
