# 6.4 Some advanced concepts

### 6.4.1 Cumulative probability (density) function and the Gaussian error function

We have mainly discussed probabilities of single values as specified by the probability (density) functions. However, in many cases we need to know the probabilities of having values within a certain range. The probability of a specific value of a continuous variable is actually infinitesimally small (nearly zero), and only the probability of a range is finite and has a useful meaning of probability. This integrated version of a probability density is the probability of having a value $x$ for the random variable $X$ in the case of $x_1 \leq x \leq x_2$ and is given

```
$P(x_1 \leq X \leq x_2) = \int_{x_1}^{x_2} p(x)dx. \quad (6.19)$
```

A common what we often need to calculate is the probability that a normal (Gaussian) distributed variable has values between $x_1=0$ and $x_2=y$. The probability of Eq. 6.19 then gives us a function of $y$. The **Gaussian error function**

```
$\frac{1}{\sqrt{2\pi}\sigma} \int_{-\infty}^{y} e^{-\frac{(x-\mu)^2}{2\sigma^2}}dx = \text{erf}(\frac{y-\mu}{\sqrt{2}\sigma}), \quad (6.20)$
```

The name of this function comes from the fact that this integral occurs when calculating confidence intervals with Gaussian noise and is often abbreviated as erf. This Gaussian error function for normally distributed variables (Gaussian distribution with mean $\mu=0$ and variance $\sigma=1$) is commonly tabulated in books on statistics. Mathematical programming libraries usually include routines that return the values for specific arguments. In Python, this is implemented by the routine scipy.special.erf, and values for the inverse of the error function are returned by the routine scipy.special.erfinv.

Another general case of Eq. 6.19 is when $x_1$ in the equation is equal to the lowest possible value of the random variable (usually $-\infty$). The integral in Eq. 6.19 then corresponds to the probability that a random variable has a value smaller than a certain value, $y$. The function of $y$ is called the cumulative density function (cdf),^4

```
$p_{cum}(x < y) = \int_{-\infty}^{y} p(x)dx, \quad 6.21$
```

which we will utilize further.

### 6.4.2 Functions of random variables and the central limit theorem

A function of a random variable $X$ is a random variable, $Y$, and we often need to know the pdf of this new variable. Calculating with functions of random variables is a bit different from calculating with regular functions, something to which we pay attention. Let us illustrate how to do this with an example. Say we have an equally distributed random variable $X$, commonly approximated by pseudo-random number generators on a computer. The probability density of this variable is given

```
$p(x) = \begin{cases} 1 & \text{for } 0 \leq x \leq 1 \\ 0 & \text{otherwise.} \end{cases} \quad 6.23$
```

We are seeking the probability density function $p_Y(y)$ of the random variable

```
$Y = e^{-X^2}. \quad 6.24$
```

The random number $Y$ is not Gaussian as we might nicely think. To calculate the probability density we can use the cumulative density function of Eq. 6.21 by noting:

```
$P(Y \leq y) = P(e^{-X^2} \leq y) = P(X \geq \sqrt{-\ln y}). \quad 6.25$
```

Thus, the cumulative probability function of $Y$ can be calculated from the cumulative probability function of $X$.

```
$P(X \geq \sqrt{-\ln y}) = \int_{-\sqrt{-\ln y}}^{y} p(x)dy = 1 - \sqrt{-\ln y}, y \leq 1, \text{otherwise.} \quad 6.26$
```

The probability density of $Y$ is the derivative of this function,

```
$p_Y(y) = \begin{cases} -\sqrt{-\ln y} & \text{for } e^{-1} \leq y \leq 1 \\ 0 & \text{otherwise.} \end{cases} \quad 6.27$
```
