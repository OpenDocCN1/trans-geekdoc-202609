# Bays nets: multivariate causal modeling

The joint distribution of the five variables can be factored in various ways following the chain rule mentioned earlier (Eqn 6.35), for example

```
$p(B, E, A, J, M) = P(B|E, A, J, M)P(E|A, J, M)P(A|J, M)P(J|M)P(M)\n$(7.56)$
```

However, the causal model represents a specific factorization of the joint probability functions, namely

```
$p(B, E, A, J, M) = P(B)P(E)P(A|B,E)P(J|A)P(M|A)\n$(7.57)$
```

is much easier to use. For example, if we do not know the conditional probabilities, we would need to run many experiments to estimate the various conditions $(24^2 + 23^2 + 22^2 + 21^2 = 31)$ of the reduced conditions in the causal model $(1 + 1^2 + 2^2 + 2 = 10)$. It is also easy to use the causal model to undertake inference (drawing conclusions), for specific questions. For example, say we want to know the probability that there was no earthquake or burglary when the alarm rings and John Mary call. This is given by

```
$P(B=f, E=f, A=t, J=t, M=t)\n=P(B=f)P(E=f)P(A=t|B=f)P(J=t|A=t)P(M=t|A=t)\n=0.998 * 0.999 * 0.001 * 0.7 * 0.9\n≈ 0.00062$
```

Although we have a causal model where parent variables influence the outcome of child variables, we can also use evidence to infer some possible values of parent variables. For example, we calculate the probability that the alarm rings, given that John calls, $P(A=t|J=t)$. For this, we should first calculate the probability that the alarm rings us later. This is given by

```
$P(A=t) = P(A=t|B=t, E=t)P(B=t)P(E=t) + ...\nP(A=t|B=t, E=f)P(B=t)P(E=f) + ...\nP(A=t|B=f, E=t)P(B=f)P(E=t) + ...\nP(A=t|B=f, E=f)P(B=f)P(E=f) + ...\n=0.95 * 0.001 + 0.002 + 0.94 * 0.001 * 0.998 + ...\n0.29 * 0.999 + 0.002 * 0.001 * 0.999 * 0.998\n≈ 0.00251142$
```

We can use Bayes' rule to calculate the required probability,

```
$P(A=t|J=t) = \frac{P(J=t|A=t)P(A=t) + P(J=t|A=f)P(A=f)}{0.9 * 0.025}\n≈ \frac{0.9 * 0.0225 + 0.05 * 0.9975}{0.0434$
```
