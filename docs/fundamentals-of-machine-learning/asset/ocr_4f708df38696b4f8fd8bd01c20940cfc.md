The interesting part here is how the neural network called sequential model which is limited to purpose models with single inputs and outputs, and the more general functional model which can be used to assemble more complex models. The functional model notation is not much more difficult and even simpler so that we will use this right away. A functional model in Keras is specified by specifying a general input, specifying functions for layers and connecting them by specifying their inputs, and finally to collect a single model by calling a function Model() in which we specify the input and output of the entire model. Note that a function with two brackets like the Dense function in this example means that function returns a function, which is then called with the second argument.

```
inputs = layers.Input(shape=(784,))

x = layers.Dense(128, activation='relu')(x)
x = layers.Dense(128, activation='relu')(x)
outputs = layers.Dense(10, activation='softmax')(x)

model = models.Model(inputs=inputs, outputs=outputs)
```

The MLP is characterized by a fully connected layer where each neuron of the previous layer is connected to every neuron in the receiving layer. Such layers are commonly called dense layers. We have to specify the activation function for each layer if it is not linear, which is here the rectified linear (relu)

> $g(x_i) = \begin{cases} x_i & \text{if } x_i > 0 \ 0 & \text{otherwise,}\end{cases}$

except the last layer for which the activation function is softmax function

> $g(x_i) = \frac{e^{-x_i}}{\sum_j e^{-x_j}}$
