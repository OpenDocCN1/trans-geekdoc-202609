If we want to take the derivative of the function with respect to the inputs, we can apply the chain rule. To simplify the notation, we can write the partial derivative as an operator D. Then we have the derivative graph similar to the primal graph with

```
Dv1 = Dx (= 1)
Dv2 = Dy (= 0)
Dv3 = cos(v1) * Dv1
Dv4 = (= 0)
5 = Dv1 * v2 + v1 * Dv2 (= 1)
Dv6 = Dv3 + Dv4 + Dv5 (= 2).
```

These are again elementary function nodes that form a graph for the derivative analog to the primary function graph. At this point it is wise to note that such functions are already implemented as code so that each graph representing code can be used to calculate the values of the derivatives at specific points. For example, if we want to calculate the partial derivative with respect to $x$, then $Dv1 = 1$ and $Dv2 = 0$. All other variables are given or computed by the expressions. We included the corresponding numbers for the example of the derivative in the $x$-direction at points $x = 0$ and $y = 1$ in brackets in the above equations. This illustrates the basic idea behind automatic differentiations.

The forward mode of automatic differentiation is easy to implement, there are other algorithms that can be more suited for what we have to calculate in gradients like neural networks and show how the backpropagation algorithm is a form of automatic differentiation. The reverse mode starts with a forward pass through the network. We also define an adjoint variable

```
$$\frac{\partial f}{\partial v_i}$
```

which specifies how much the variable $v_i$ contributes to the change in the output value. With these notations we can unravel the chain rule in reverse order

```
$\hat{v}_6 (= 1)$$
$\hat{v}_5 = \frac{\partial\hat{v}_6}{\partial v_5} = \hat{v}_6 * 1 (= 1)$$
$\hat{v}_4 = \frac{\partial\hat{v}_6}{\partial v_4} = \hat{v}_6 * 1 (= 1)$
```
