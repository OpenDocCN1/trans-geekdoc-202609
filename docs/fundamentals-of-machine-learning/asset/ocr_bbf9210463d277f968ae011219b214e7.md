While inference is an important application of causal models, inferring causality from data is another where causal models revolutionize scientific investigations. Many traditional methods evaluate co-occurrences of events to determine dependencies, such as a correlation analysis. However, such a correlation is usually not a good indication of causality. Consider the example in Fig. 7.7. When the alarm rings, it is likely that John and Mary call, the event that John calls is mutually independent of the event that Mary calls. Sometimes we might just be interested in knowing the likelihood of co-occurrence, for which a correlation analysis can be a good start, but if we are interested in describing the causes of the observations, then we need another approach. Some algorithms have been proposed for structural learning, such as an algorithm called inferred causation (IC), which deduct the most likely causal structure given data.

# 7.52 Discrete probabilistic modeling in Using Lea

There are several tools for working with probabilistic models and Bayesian graphs. A most general probabilistic programming toolbox is Stan (http://mc-stan.org/), but we will here give an example using the Lea3 (http://bitbucket.org/pideniis/lea/) which is a simpler tool for working with discrete models in Python. In particular, Lea has direct support for Bayesian models. This brief section is not meant to be a tour introduction to this tool but merely give an example to demonstrate the usefulness of such tools. We will show an example program for the burglary/earthquake example.

The main part of the program is to define the graph structure and the associated conditional probability tables. The corresponding code is fairly self-explanatory.

Listing 7.1 LeaExample.ipynb (part 1)

```
import lea

burgary = lea.event(0.001)
earthquake = lea.event(0.002)
alarm = lea.joint(burglary , earthquake).switch((True , True ) : lea.event(0.950),
(True , False ) : lea.event(0.940),
(False , True ) : lea.event(0.290),
(False , False) : lea.event(0.001) )
JohnCalls = alarm.switch(True: lea.event(0.90), 
                                   False: lea.event(0.05) 
)
MaryCalls = alarm.switch(True: lea.event(0.70), 
                                   False: lea.event(0.01) 
))
```

This notation includes the specification of the discrete probability tables, and it contains the relations between the variables so that there is no need for a separate specification of the network graph.
