In practice, the following we show some examples where we can use Bayes rule. There are situations where undertaking analytically with Bayes rule is difficult. Complete or approximate numerical implementations of Bayes rules is an important topic. There are good examples where scientists have shown that humans make Bayesian decisions in specific experiments, although there is of no evidence that humans use direct calculations by Bayes theorem.

In order to make a discriminative model from the generative models using Bayes theorem, we need to know the class priors, such as the relative frequencies of the classes. We can then calculate the probability that it features x belonging to a class as y

```
$$p(y|x; \theta) = \frac{p(x|y; \theta)p(y)}{p(x)}$$ $(8.2)$
```

A decision can be made directly based on this conditional probability. The Bayesian decision of predicting the class with the largest posterior probability is

```
$$\arg max_y p(y|x; \theta) = \arg max_y \frac{p(x|y; \theta)p(y)}{p(x)}$$ $(8.3)$
$$= \arg max_y p(x|y; \theta)p(y)$$ $(8.4)$
```

While we have used the fact that the denominator does not depend on y and thus can be ignored. In the case of binary classification, this reads:

```
$$\arg max_y p(y|x; \theta) = \arg max_y p(x|y=0; \theta)p(y=0), p(x|y=1; \theta)p(y=1)$.$$ $(8.5)$
```

While using generative models for classification seem to be more elaborate, we will later see that there are several arguments which make generative models attractive for machine learning. To start with, it seems much easier and efficient to learn generalize from similar objects than to learn from difficult discrimination examples.
