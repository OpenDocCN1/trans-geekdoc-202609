In the detection network above, we switch from a convolutional to a fully connected layer at a specific point, and we could ask how many convolutional layers we should have before switching to dense layers. In this context, it is good to view a dense network with N nodes as a convolutional layer with N channels and an i x j kernel (receptive field), where i and j are the width and height of the previous layer that is assumed to be 2-dimensional besides the channel dimension. So, a dense network is like a convolutional network with small receptive fields after small filter sizes can be seen more as a local operation. Such a node can access a lot of relevant information through the hierarchy of previous representations, and it is possible that during training, the features in previous layers are organized so that they can be accessed. Thus, convolutions with small kernels still make sense in a deep network.

This architecture from the Oxford Visual Geometry Group (VGG16) was an entry in the ImageNet competition in 2014 and had sixteen layers, hence the name VGG16. It was viewed as a very deep network at time, although today there are networks in use that may have more layers, even running to the hundreds. Implementing VGG16 is a great exercise.
