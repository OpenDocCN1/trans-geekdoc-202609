```
$p(x|y) = \prod_{j=1} p(x|y). \quad (8.36)
```

To estimate these parameters we can use maximum likelihood estimation, which gives

```
$$\phi_{j,y=1} = \frac{1}{\|{y=1\|} \sum_{i \in [y=1]} x_j^{(i)} \quad (8.37)
```

```
$$\phi_{j,y=0} = \frac{1}{\|{y=0\|} \sum_{i \in [y=0]} x_j^{(i)} \quad (8.38)
```

```
$$\phi_y = \frac{\|\|{y=1\|}}{m} \quad (8.39)
```

The first equation is the probability that the word j appears in a spam text, the second equation is that the word j appears in a non-spam text, and the third equation specifies the frequency of spam examples in the data set.

With these parameters we now calculate the probability that email x is spam

```
$p(y=1|x) = \frac{\prod_{j=1}^{50,000} \phi_{j,y=1} \phi_{y=1}}{\dots + \prod_{j=1}^{50,000} \phi_{j,y=0} \phi_{y=0}} \quad (8.40)
```

This big advantage of this Naïve Bayes model is that the number of parameters are fairly small compared to more complex models. There are many examples where naive Bayes models work well which are, of course, cases where the naive Bayes assumption is appropriate. Course, words in a text should be highly correlated, but the gist is here that pure frequency of words correlates with the text.
