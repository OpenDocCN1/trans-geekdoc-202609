To illustrate this with a point example, let us think tabular RL if we implement learning to play a computer game. Let us discuss the example of Atari 2600 games that have been implemented in an arcade environment by Michael Bowling and the University of Alberta. This environment simulates video of 210 × 168 RGB video at 60Hz. An example of these games is shown in Fig. 10.6. The state of each game is equivalent to a state input vector of length 100,800 every 1/60 of a second. Even if each pixel is allowed to have, say 8 bits representation, $2^8$ possible values, and all the pixels are independent, there are $256^{100800}$ possible states. Clearly this is impossible to implement with the tabular methods cited earlier. Bellman noticed these practical limitations and coined the phrase “curse of dimensionality.” The principle of using function approximators to represent the functions, and it comes at no surprise that we will specifically use deep neural networks for these function approximations.
