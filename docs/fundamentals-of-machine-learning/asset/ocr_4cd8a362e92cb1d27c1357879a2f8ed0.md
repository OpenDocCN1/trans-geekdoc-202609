# 6.4.3 Measuring the difference between distributions

An practical consideration is how to measure the similarity or difference between two density functions, say the density function $p$ and the density function $q$. Note that such a measure is a matter of definition, similar to distance measures of real numbers or functions where we can come up with a variety of definitions. However, there are some basic properties that we expect from a distance measure $d(a, b)$ between two items, $a$ and $b$. For example, a distance measure should be 0 if the items to be compared are same, that is $d(a, a) = 0$. Also, the value should be positive, $d(a, b) > 0$ for $a 
eq b$, and a distance measure should be symmetric, meaning that $d(a, b) = d(b, a)$.

To measure the difference between distributions we could just plot them on top of each other and measure the difference in area. However, as we will see later, we can define the information content in form of a logarithm of the probability, and the difference of logarithms is equal to the logarithm of the quotient. In probability theory, this measure should be weighted itself with the probability of the densities. A popular measure of similarity between two density functions is hence the-called Kullback-Leibler divergence is given by

```
$d^{KL}(p,q) = \int p(x) \log\frac{p(x)}{q(x)}dx - \int p(x) \log(q(x))dx. \quad (6.29)$
```

This measure is 0 if $p=q$ and always larger than 0 if $p \neq q$. However, this measure is not symmetric and is called a divergence instead of distance. A KL is related to the information gain or relative entropy in information theory.
