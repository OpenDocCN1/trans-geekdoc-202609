# Sequence processing

Our examples of neural network applications have focused on tasks where an output should be predicted from one input vector. Another common application that we will discuss now is sequence processing. There are many types of sequence task such as forecasting the stock market or the weather from past observations, or progress of patients due to medical interventions. While it is common to have naturally sequential data, there are even reasons to process data in a sequential format such as searching large images in patches to locate specific objects. The human visual system uses sequence processing as scenes are commonly explored by a series of eye movements called saccades. We will start discussing such sequence processing with the basic tasks of temporal predictions where a value of a sequence at position t is to be predicted from previous data:

```
x(t) = f(x(t-1), x(t-2), ...).
```

In general, we should talk about a sequence position, though we commonly view a sequence as a time series. It is common to use the symbol t for the index of a sequence position.

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_186_0.png)

Fig. 9.2 Example of a tapped delay line to represent temporal sequences to a neural network.

We will now consider several architectures of systems for such sequence processing. The first one we consider is to use a regular feed-forward network to do sequence prediction from a finite number of previous sequence data. For example, we can place sequence values of n previous values of the sequence into an input vector:

```
x = \begin{pmatrix} x(t-1) \\ \vdots \\ x(t-n) \end{pmatrix}, \quad (9.2)
```

and then do a one-step-ahead prediction of the value $s(t)$ as the output:

```
y = x(t). \quad (9.3)
```

In Fig. 9.2, we visualized the generation of the input vector by tapping the input sequence with delay lines of different lengths. Representing a finite portion of sequence in a spatial way this is sometimes called a tapped delay line. With such a representation of time sequence we can immediately apply deep neural networks or sequence forecasting. An example of such a simple network with one hidden layer is shown in Fig. 9.2.

For the following discussion, let's simplify this network with only one hidden node as shown in Fig. 9.3A. We can generalize this easily to more hidden nodes and many layers of hidden; we have chosen this simple version for the illustration purposes. With this reduced figure it becomes clear that we assume the values of the inputs at different times can have different influences on the sequence prediction as we allow the weights to the hidden node to have different values that of course be learned. This is the most general case, at least for a fixed sequence which can occur at any position, then we can use a convolution out the input vector to search for this pattern. For example, in text processing of the "You should not use an umbrella because it is raining," the word "umbrella" is highly predictive of the word "raining", although the relative position is variable. Convolutional networks have smaller filters compared to dense networks. This will save us parameters as we already discussed for position invariant feature detection is. The 1-dimensional convolutional solution is illustrated in Fig. 9.3B.
