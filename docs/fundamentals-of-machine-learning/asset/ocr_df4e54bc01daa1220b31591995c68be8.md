Another solution to the problem is to use lots of data to constrain the number of parameters. For the most part we can loosely equate the number of parameters with the complexity of the model. Of course, the specific architecture, such as a hierarchical flat representations, is of course part of the complex equation and as we are thinking more about how we can sufficiently constrain the parameters. Data collections such as ImageNet have therefore been essential in demonstrating the abilities of deep networks. However, more often than not, tend tend to have enough training data, and **data augmentation** is a common and essential technique even in large of face data sets are good candidates for sound augmentation. Shifting an image is actually a good example to see where certain transformations should alter its content, and rotation and some form of stretching does changing individual pixels in a high-resolution image does not have a drastic impact on recognition abilities. Thus, generating more images with these transformations from the labeled training set is a good way to increase the training data set. Injecting noise either at an input level or an output level is another example of such data transformations for data augmentation. The data augmentation technique is a good example where we use expert knowledge to augment the data set in defining which transformations should not alter the content. However, some caution is in order as such transformations are not necessarily suitable in every situation. To some extent we must already know the data distribution required to generate proper examples, which is of course what we want to model. Thus, this can be a chicken-and-egg situation.
