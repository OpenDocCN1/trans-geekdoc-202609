The performance of the model after learning is of utmost importance for us
However, it is also very instructive and important for the development of the models
to monitor the performance of the model learning. We call graphs learning
curves. We can draw different types of curves, either evaluated on the training set or
evalu on the validation set. It is easy to plot curves in Keras as the fit function
already has a history of evaluations as a callback function, and Keras provides the
framework to code your callback function. Other deep learning frameworks also\commonly use a way to visualize the progress during learning. In the code above
we assigned the return pointer of the fit function to dictionary variable history.
 key() function lists the keys for the included values,
