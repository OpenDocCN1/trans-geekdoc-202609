# Mathematical formulation of the basic learning problem

Much of what is currently most associated with the success of machine learning is supervised learning, sometimes also called predictive learning. The basic task of supervised learning is that of taking a collection of input data, such as the values of an image, measured data, or robotic sensor data, and predicting an output y such as the name of an object in an image, the state of a patient's health, or the location of obstacles. It is common that each input has many components, as millions of pixels values in an image, and it is useful to collect these values in a mathematical structure such as a vector (1-dimensional), a matrix (2-dimensional), or a tensor that is the generalization of such structures to higher dimensions. We often refer to machine learning problems as high-dimensional which refers, in this context, to the large number of components in the input structure and not to the dimension of the input.

We use the mathematical terms vector, matrix and tensor mainly to signify a data structure. In a programming context these are more commonly described as 1-dimensional, 2-dimensional, or higher-dimensional arrays. The difference between arrays and tensors (a vector and matrix are special forms of a tensor) is, that the mathematical definitions also include rules on how to calculate with these data structures. This book is not a course on mathematics; we are only users of mathematical notations and methods, and mathematical notation helps us to keep the text short while being precise. We follow here a common notation of denoting a vector, matrix, or tensor with bold-faced letters, whereas we use regular fonts for scalars. We call... the output could also be a multi-dimensional object such as a vector or tensor itself. Mathematically, we can denote the relations between the input and output as a function

```
$y = f(\mathbf{x}).$$
```

We consider the function above as a description of the true underlying world, and our task in science or engineering is to find this relation. In the formula we consider a single output value and several inputs for illustration purposes, although we see that we can extend this readily to multiple output values.

Before proceeding, it is useful to clarify our use of the term "feature." Features represent components that describes the input to our learning systems. Feature values are often measured data in machine learning. The sometime word "attributes" is used instead. In the most part, we use these terms interchangeably. However, sometimes researchers make a small distinction between the terms, using attributes to denote unique content while using feature as a derived value, such as the square of an attribute. This strict distinction is usually crucial for the understanding of the context so we use of the term feature includes attributes.
