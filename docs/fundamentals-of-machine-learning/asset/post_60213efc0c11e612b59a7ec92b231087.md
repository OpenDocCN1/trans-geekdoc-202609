
## 3.6 Support vector machines (SVM)

### 3.6.1 Linear classifiers with large margins

In this section we outline the basic idea behind support vector machines (SVM) that have been instrumental in a first wave of industrial applications due to their robustness and ease of use. A warning: SVMs have some intense mathematical underpinning, although our goal is to outline only some of the mathematical deunderpinnings behind this method. It is not strictly necessary to read this section in order to follow the rest of the book, but it provides a summary of concepts that have been instrumental in previous progress and are likely to influence the development of further methods and research. This includes some examples of advanced optimization techniques and the idea of kernels. While we mention some formula in what follows, we do not derive the steps and will only use them to outline the form to understand why we can apply a kernel trick. Our purpose here is to provide some intuitions.

SVMs, and the underlying statistical learning theory, was largely invented by Vladimir Vapnik in the early 1960s, but some first breakthroughs were made in the late 1990s with collaborators such as Cor Cortes, Chris Burges, Alex Smola, and Bernhard Scholkkopf to name a few. The SVMs are concerned with binary classification. Fig. 3.9 shows an example of two classes, depicted by different symbols, in a 2-dimensional attribute space. We distinguish here between features and attributes. Attributes are the raw measurements, whereas features can be made up by combining attributes. For example, the attribute $x_1$ and $x_2$ could be combined in a feature vector $(x_1, x_2, x_1^2, x_2^2)^T$. This will become important later. Our training set consists of $m$ data where it has attribute values $x^{(i)}$ and labels $y^{(i)}$. We put the superscript index $i$ in brackets so it is not mistaken as a power. For this discussion we consider the binary labels of two classes represented with $y \in \{-1, 1\}$. This will simplify some equations.

Fig. 3.9 Illustration of linear support vector classification.

The two classes in the Fig. 3.9 can be separated by a line, which can be parameterized as

$$w_1x_1 + w_2x_2 - b = 0,$$

$$w^T\mathbf{x} - b = 0,$$

While the first line shows the equation with its components in two dimensions, the next expression in a matrix notation is the same in any dimension. Of course, in three dimensions we would talk about a plane. In general, we will talk about a hyperplane in any dimensions. The particular hyperplane is the dividing or separating hyperplane between the two classes. We also introduce what the margin $\gamma$, which is the perpendicular distance between the dividing hyperplane and the closest point.

(3.13)

The main point to realize now is the dividing hyperplane that maximizes the margin is most likely to be a good choice. Why is that? We should assume the training data, shown in the figure, are some examples of the underlying density function describing the distribution of points within each class and representative of the most likely data. It is then likely that new data points, which we want, are close to the already existing data points. If we use the separating hyperplane as far as possible from each point, then we probably won't make misclassification on future data points. Or, in other words, a separating hyperplane like the one dashed in the figure, is simply to offer better generalization than the maximum margin hyperplane. Thus, the maximum margin hyperplane can be considered the best choice if we assume that both classes have the same expected variance from the training data. Such maximum margin classifier can hence be expected to be a good choice.

Let us formalize the maximization of the margin a bit more. Learning a linear margin classifier on labeled data means finding the parameters $w$ and $b$ that maximize the margin. For this we could compute the distances of each point from the hyperplane, which is simply a geometric exercise,

$$\gamma^{(i)} = y^{(i)} \left( \frac{|\mathbf{w}^T\mathbf{x}^{(i)} + b|}{\|\mathbf{w}\|} \right). \quad (3.14)$$

The vector $w/\|\mathbf{w}\|$ is the normal vector of the hyperplane, a vector of unit length perpendicular to the hyperplane. The norm $\|\mathbf{w}\|$ is the Euclidean distance of the vector $w$. The margin we want to maximize is the distance to the closest point,

$$\gamma = \min_i \gamma^{(i)}. \quad (3.15)$$

We formulate the maximum margin calculation by realizing from Eq. 3.14 that maximizing $\gamma$ is equivalent to minimizing $\|\mathbf{w}\|$, or, equivalently, of minimizing

$$\frac{1}{\|\mathbf{w}\|^2}\|\mathbf{w}\|^2. \quad (3.16)$$

Of course, we want to maximize this margin under the constraint that no point should lay within the margin. Since we have the freedom to choose a scale, we can define this distance as 1, so that the decision boundaries become

$$\mathbf{w}^T\mathbf{x}^{(i)} + b \ge 1 \quad y^{(i)} = 1 \quad (3.17)$$

$$\mathbf{w}^T\mathbf{x}^{(i)} + b \le -1 \quad y^{(i)} = -1. \quad (3.18)$$

These equations can be combined into one equation when we use labels for the set $y = \{-1, 1\}$, namely

$$-(y^{(i)}(\mathbf{w}^T\mathbf{x} + b) - 1) \geq 0. \quad (3.19)$$

So, to summarize, we have a quadratic minimization problem (Eq. 3.16) with the linear inequalities Eq. 3.19 as constraint. Optimization can be framed with the Lagrange formalism. For this, we add the constraints to the main objective or function with some parameters $\alpha_i$ that are generally called Lagrange multipliers,

$$\mathcal{L}^P(\mathbf{w}, b, \alpha_i) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^m \alpha_i y^{(i)}(\mathbf{w}^T\mathbf{x} + b) - 1. \quad (3.20)$$

Lagrange multipliers determine how well the constraints are observed. In the case of $\alpha_i=0$, constraints does not matter. To conserve the constraints, we should make these values as large as we can. Finding the maximum classifier is here given by the so-called primal problem

$$p^* = \min \max \mathcal{L}^P(\mathbf{w}, b, \alpha_i)$$

### 3.6.2 Soft margin classifier

Thus far have only discussed the linear separable case, but how about the case when there are overlapping classes? It is possible to extend the optimization problem by allowing some points to be in the margin by penalizing these points. We therefore include slack variables $\xi_i$, that reduce the effective margin for each data point, and add a penalty to the optimization that penalizes the sum of these slack variables is large,

$$\min_{w,b} \frac{1}{2}\|w\|^2 + C \sum \xi_i \quad (3.30)$$

subject to the constraints

$$y^{(i)}(w^T x + b) \geq 1 - \xi_i \quad (3.31)$$
$$\xi_i \geq 0 \quad (3.32)$$

The constant $C$ is free parameter in this algorithm. Making this large means fewer points to be in the margin. This parameter must be tuned and it is advisable to try to vary this parameter in order to verify that the results do not dramatically affect an initial choice.

### 3.6.3 Non-linear support vector machines

We have treated the case of overlapping classes while assuming that the best we can do is a linear separation. However, what if the underlying problem is separable with a function that might be more complex? An example is shown in Fig. 3.10. And we will now look into the non-linear generalization of the SVM.

Lagrange multipliers determine how well the constraints are observed. In the case of $\alpha_i=0$, constraints does not matter. To conserve the constraints, we should make these values as large as we can. Finding the maximum classifier is here given by the so-called primal problem

$$p^* = \min \max \mathcal{L}^P(\mathbf{w}, b, \alpha_i)$$

However, Vapnik went further by realizing that the margin can be maximized by the so-called dual

$$d^* = \max \mathcal{L}^D(\mathbf{w}, b, \alpha_i)$$

Since this is only over the support vectors, which should be a few points from the training set, classification becomes very efficient after training.

Once we find the support vectors with $S$, we can calculate $w$ from Eq. 3.24 and $b$ from a similar equation. Then, if we are new input vector to be classified, then it can be calculated with the hyperplane

$$y = \begin{cases} 1 & \text{if} \sum_{i \in S} \alpha_i y^{(i)} x > 0 \\ -1 & \text{otherwise} \end{cases} \quad (3.29)$$

The actual optimization can be done with several algorithms. John Platt developed the sequential minimal optimization (SMO) algorithm which is very efficient for this problem. Note that the optimization problem is convex and can be solved without the danger of getting stuck in local minima. From this optimization it turns out that the $\alpha_i \neq 0$, those lying on the margin, are the only ones which are called support vectors.

In the dual problem we can use kernel trick, discussed later to generalize to non-linear cases. Substituting this into the optimization problem, we get

$$w = \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)} \quad (3.25)$$

The vector $w/\|\mathbf{w}\|$ is the normal vector of the hyperplane, a vector of unit length perpendicular to the hyperplane. The norm $\|\mathbf{w}\|$ is the Euclidean distance of the vector $w$. The margin we want to maximize is the distance to the closest point,

$$\gamma = \min_i \gamma^{(i)}. \quad (3.15)$$

We formulate the maximum margin calculation by realizing from Eq. 3.14 that maximizing $\gamma$ is equivalent to minimizing $\|\mathbf{w}\|$, or, equivalently, of minimizing

$$\frac{1}{\|\mathbf{w}\|^2}\|\mathbf{w}\|^2. \quad (3.16)$$

These equations can be combined into one equation when we use labels for the set $y = \{-1, 1\}$, namely

$$-(y^{(i)}(\mathbf{w}^T\mathbf{x} + b) - 1) \geq 0. \quad (3.19)$$
