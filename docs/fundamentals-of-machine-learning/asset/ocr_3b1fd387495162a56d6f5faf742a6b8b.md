# 9.1 Sequence processing

Our examples of neural network applications have focused on tasks where an output (label) should be predicted from one input vector. Another common application that we will discuss now is that processing sequences. There are many types of sequence task such as forecasting the stock market or the weather from past observations, or the modeling of progress of patients due to medical interventions. While it is common to have naturally sequential data, there are even reasons to process data in a sequential format such as searching large images in patches to locate specific objects. The human visual system uses sequence processing as scenes are commonly explored by a series of eye movements called saccades. We will start discussing such sequence processing with the basic tasks of temporal predictions where a value of a sequence at position t is to be predicted from previous data points,

```
x(t) = f(x(t-1), x(t-2), ...).
```

In general, we should talk about a sequence position, though we commonly view a sequence as a time series. It is common to use the symbol t for the index of a sequence position.
