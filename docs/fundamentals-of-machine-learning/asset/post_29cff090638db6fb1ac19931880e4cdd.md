## 10.1.3 Return and value functions

The goal of the agent is to maximize the total expected reward in the future from every initial state. This quantity is called return in economics. Of course, if this goes on forever, then we have henceforth to be a bit more careful. One common choice is to define the average reward in a finite time interval, also called the finite horizon case. Another common way to keep the return finite is to use a discounted return when an agent values more reward than a reward to be obtained far in the future. To capture this we define a discount factor $0 < \gamma < 1$. In the example program we will use a value of $\gamma=0.5$,

**List 10.2** RL.ipynb (Part 2)
```python
# discount factor
gamma=0.5
```

although values merge close to 1 as $\gamma=0.99$, are common. For this case we define a **state-action value function**. This function gives us a numerical value of the return (all discounted reward) when the agent is in state $s$ and takes action $a$ and then follows the policy for the following actions:
Value function (state-action): $Q^*(s,a) = \rho(s,a) + \sum_{t=1}^{\infty} \gamma^t \rho(s_t, \pi(s_t))$. (4)

In other words, these functions tell us how good an action is in state $s$, and the knowledge of this value function should guide the actions of the agent. The value-based reinforcement learning is to estimate this function. Here we consider first the deterministic case and another formulation in the stochastic case for finite horizon cases. Sometimes we are only interested in the value function when we follow the policy for the first step in the action sequence. Then this value function does not depend explicitly on the action, and is defined as the total discounted return from state $s_0$:
Value function (state): $V^\pi(s) = Q^\pi(s, \pi(s))$.

The goal of the RL is to find the policy which maximizes the return. If the agent knows the optimal value function, then the optimal policy is simply given by taking the action that leads to the expected return:
Optimal value function: $V^*(s) = \max_a Q^*(s, a)$, (6)
Optimal policy: $\pi^*(s) = \arg_a Q^*(s, a)$. (7)

This is implemented here with the python code for calc_policy. The optimal value function and the optimal policy are closely related. We will discuss in the following methods to calculate or estimate the value function from which the policy can be derived. These methods can be put under the heading of value-search (where agents are commonly called critic) and policy-search (where corresponding agents are called actor). At the end we will argue that combining these approaches in actor-critic scheme has attractive features, and such schemes are increasingly used in practical applications with the help of neural networks.

## 10.2 Model-based reinforcement learning

In this section we assume that the agent has a model of the environment, which includes both the reward $\rho(s, a)$ and transition functions $\tau(s, a)$. The knowledge of these functions, or a model thereof, is required for model-based RL. The basic challenge in practical applications is to learn these functions from examples of the agent acting in the environment.

### 10.2.1 The basic Bellman equation

The key to learning the value functions is the realization that the right-hand side of Eq. (4) can be written in terms of the Q-function itself:
$Q^*(s, a) = \rho(s, a) + \gamma \sum_{t=1}^{\infty} \gamma^t \rho(s_t, \pi(s_t))$ where the term in the square bracket is equal to the value of the state reached after the transition $\tau(s, a)$:
$Q^*(s,a), \pi(s)) = V^\pi(\tau(s,a))$. (8)

The Q-function and the V-function are equivalent since we are following the policy in these steps. Using this fact in the equation above, we get **Bellman equation**: $Q^*(s,a) = \rho(s,a) + \gamma Q^*(\tau(s,a), \pi(s))$. (9)

If we combine this with known dynamics in the continuous domain, then this becomes the Hamilton-Jacobi-Bellman equation, which often encountered in engineering problems. As stated, we realize that the reward function $\rho(s,a)$ and the transition $\tau(s,a)$ are known. At this point the agent follows a specific policy $\pi(s)$. Let us assume that we have $n_s$ states and $n_a$ actions in each state. We have $n_s \times n_a$ unknown quantities $Q^*(s,a)$ which are governed by the Bellman equation. More precisely, the Bellman Eq. (9) is $n_s \times n_a$ coupled linear equations with the unknown $Q^*(s,a)$. It is convenient to convert this to a matrix system with vectors
$Q^* = R + \gamma \mathbf{T}^\pi Q^*$. (10)

Where $\mathbf{T}^\pi$ is an appropriate transition matrix which depends on the policy. Which can also be written as
$R = (\mathbf{I} - \gamma \mathbf{T}^\pi)^{-1}R$; (11)
where $\mathbf{I}$ is the identity matrix. This equation has the solution
$Q^* = (\mathbf{I} - \gamma \mathbf{T}^\pi)^{-1}R$. (12)
if the inverse exists. In other words, as the agent knows the reward function and the transition function, it can calculate the value function for a specific policy without taking a single step. This is an example of a deliberative system where the agent can use the models of reward and the environment to calculate optimal decisions, hence the designation as model-based RL.

To demonstrate how to solve the Bellman equation with linear algebra tools, we need to define the corresponding vectors and matrices used in Eq. (12). We then order quantities as $\rho$ and $Q$ with 10 indices. The first corresponds to $(s=0, u=-1)$, the second to $(s=0, u=1)$, the third to $(s=1, u=-1)$, etc. The reward vector can be coded as:
