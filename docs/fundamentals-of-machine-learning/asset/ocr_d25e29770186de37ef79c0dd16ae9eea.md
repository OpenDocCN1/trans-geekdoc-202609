The term in the square bracket is equal to the value of the state that is reached after the transition $	au(s, a)$

$Q^*(	au(s,a), \pi(	au(s,a))) = V^\pi(	au(s,a))$. (10.8)

The Q-function and the V-function are here equivalent since we are following the policy in these steps. Using this fact in the equation above, we get

**Bellman equation**: $Q^*(s,a) = ho(s,a) + \gamma Q^*(	au(s,a), \pi(s,a)))$. (10.9)

If we combine this with known dynamics in the continuous domain, then this becomes the Hamilton-Jacobi-Bellman equation, which often encountered in engineering problems.

As stated, we realize that the reward function $ho(s,a)$ and the transition $	au(s,a)$ are known. At this point the agent follows a specific policy $\pi(s)$. Let us assume that we have $n_s$ states and $n_a$ actions in each state. We have $n_s 	imes n_a$ unknown quantities $Q^*(s,a)$ which are governed by the Bellman equation. More precisely, the Bellman Eq 10.9 is $n_s 	imes n_a$ coupled linear equations with the unknown $Q^*(s,a)$. It is convenient to convert this to matrix system with vectors

$Q^* = R + \gamma \mathbf{T}^\pi Q^*$. (10.10)

Where $\mathbf{T}^\pi$ is an appropriate transition matrix which depends on the policy. Which can also be written as

$R = (\mathbf{I} - \gamma \mathbf{T}^\pi)^{-1}R^*$; (10.11)

where $\mathbf{I}$ is the identity matrix. This equation has the solution

$Q^* = (\mathbf{I} - \gamma \mathbf{T}^\pi)^{-1}R$. (10.12)

if the inverse exists. In other words, as the agent knows the reward function and the transition function, it can calculate the value function for a specific policy without taking a single step. This is an example of a deliberative system where the agent can use the models of reward and the environment to calculate optimal decisions, hence the designation as model-based RL.
