# Mathematical formulation of the basic learning problem

Much of what is currently most associated with the success of machine learning is supervised learning, sometimes also called predictive learning. The basic task of supervised learning is that of taking a collection of input data, such as the values of an image, measured data, or robotic sensor data, and predicting an output y such as the name of an object in an image, the state of a patient's health, or the location of obstacles. It is common that each input has many components, as millions of pixels values in an image, and it is useful to collect these values in a mathematical structure such as a vector (1-dimensional), a matrix (2-dimensional), or a tensor that is the generalization of such structures to higher dimensions. We often refer to machine learning problems as high-dimensional which refers, in this context, to the large number of components in the input structure and not to the dimension of the input.

We use the mathematical terms vector, matrix and tensor mainly to signify a data structure. In a programming context these are more commonly described as 1-dimensional, 2-dimensional, or higher-dimensional arrays. The difference between arrays and tensors (a vector and matrix are special forms of a tensor) is, that the mathematical definitions also include rules on how to calculate with these data structures. This book is not a course on mathematics; we are only users of mathematical notations and methods, and mathematical notation helps us to keep the text short while being precise. We follow here a common notation of denoting a vector, matrix, or tensor with bold-faced letters, whereas we use regular fonts for scalars. We call... the output could also be a multi-dimensional object such as a vector or tensor itself. Mathematically, we can denote the relations between the input and output as a function

```
$y = f(\mathbf{x}).$$
```

We consider the function above as a description of the true underlying world, and our task in science or engineering is to find this relation. In the formula we consider a single output value and several inputs for illustration purposes, although we see that we can extend this readily to multiple output values.

Before proceeding, it is useful to clarify our use of the term "feature." Features represent components that describes the input to our learning systems. Feature values are often measured data in machine learning. The sometime word "attributes" is used instead. In the most part, we use these terms interchangeably. However, sometimes researchers make a small distinction between the terms, using attributes to denote unique content while using feature as a derived value, such as the square of an attribute. This strict distinction is usually crucial for the understanding of the context so we use of the term feature includes attributes.

Returning to the world model in input 1.1, the challenge for machine learning is to find this function, or at least to approximate it sufficiently. Machine learning offers several approaches to deal with this. One approach that we will predominantly follow is to define a general parameterized function

```
$$\hat{y} = f(\mathbf{x}; \mathbf{w}).$$
```

# Introduction

This formula describes how we make a parameterized hypothesis in which we specify a function $f$ that depends on parameters $w$ to approximate the desired input-output relation. This function is called a **model**:

> A model is an approximation of a system to study specific aspects of the system and to predict behavior

This means that not all of the underlying world has to be captured in depth. For example, a building engineer might make a model of a bridge to its static without including the aesthetic aspects that an architect might emphasize in a model. In our context the model is synonymous with approximation. We have indicated in the formula that this model is an approximation of the desired relation using a hat symbol above $y$ and $f$. However, we frequently drop the hat when the relation is clear from the context. Also, in the context of machine learning, a typically includes parameters so that their presence in the notation is synonymous with a model.

Coming with the right approximation function is the **hard problem in machine learning**, and we will later discuss several choices. There are methods to develop the approximation function from the data systematically, generally called non-parametric methods. At this point we assume that we have a parameterized approximation.

We specify the set of parameters as $w$ before a semi-colon in the function arguments. A more appropriate mathematical statement would be that equation 1.2 defines a set of functions in the parameter space. **Learning** is the challenge of finding the values for these parameters that best describe the data, and even better, predicting outputs $y$ from inputs $x$. So, the parameters are estimated from data $w = (x, y)$. Searching for these parameters is done with a learning algorithm. A common way of realizing such a learning algorithm is to define a function that describes the goal of learning, such as minimizing the number of wrong classifications. We call this function the **loss function** $\mathcal{L}$, although other terms are sometimes used in the literature such as objective function, error function, or risk. A common algorithm to minimize such a loss for a set of data is to use an algorithm called **gradient descent**, which is an iterative method over the training data that changes the parameters along the negative gradient
$\nabla_w \mathcal{L}$ of the loss function,

```
$w_i = w_i - \alpha\nabla_w\mathcal{L} \quad (1.3)$
```

where $\alpha$ is called the learning rate and

While the gradient descent can find parameters to minimize the loss of the training data, our real goal is to find the values of $w$ that best predict data that have not been

seen before. Just describing the training data acts somewhat more like a memory, but being able to generalize is the main goal of machine learning. A good solution of the machine (model) learning problem is represented by a point in the parameter space that approximates the true underlying world. However, since we usually don't know the true underlying world, we estimate how good this model is by evaluating how good new predictions are.

In some applications of supervised learning we want to predict a continuous output variable. For example, we might want to predict the price of a house from some size information. This is called regression. In contrast, sometimes we want to predict discrete values such as the categories of object in a picture. This is called classification. The output variable y in classification is called a label. It is now common to generally refer to the output of the supervised learning as label, even in the case of regression where we have a continuous "label". We will later that regression and classification are closely related; binary classification can be seen as a regression problems with a discrete function f(x) such as a function which would give us two labels, positive and negative.

An important part of our treatment learning is to consider cases with uncertainty. For example, we might not be able to predict an exact label or value, and we would be best-served if we consider the probability that a certain value will occur. This is for several reasons. For example, it is common that the process includes random (stochastic) factors or hidden (latent) factors that create variations in results for the same sensory status. Thus, we pose that the true underlying model we seek to describe is better described by a probability density function

```
p(Y = y|x).
```

This function gives the probability density, or probability mass in the case of categorical data, of the label Y having a value given that we have an input x. The arguments of density functions are provided after the vertical bar, and we write random variables as upper-case letters and we specific values with lower-case letters.

Formulating machine learning in a probabilistic (stochastic) context has been most useful and provides us with the formulation that carries many insights. In the probabilistic framework we are then modeling a density function

```
p(Y = y|x; w).
```

Density function approximation is in some sense a special case of function approximation as the density is still a function, albeit with constraints such as a normalization fp(y)dy = 1. However, modeling density functions is also the general case for modeling functions in the sense that they provide the probabilistic information of how likely label values are given a certain input.

A probabilistic framework can be used for a more general formulation of learning. Given a parameterized model as written in equation 1,6, we want to know for all possible parameters how likely they are to describe the data well. This is not necessarily a single solution, and ideally we would like to know the probability density function of the parameters by the data,

```
p(w|y, x).
```
