```
import numpy as np
import matplotlib.pyplot as plt

# Choose 100 Gaussian data with mean (1,1) and (5,5)
n=100; x = np.random.randn(2n,2); x[n,:]+=1; x[n,:]=5
plt.plot(x[:,0],x[:,1], 'ko') # Plot points
mul=[5,1]; mu2=[1,5] # initial centers (arbitrary)

plt.plot(mul[0],mul[1], 'kx', markersize=12)
plt.plot(mu2[0],mu2[1], 'bx', markersize=12)
plt.show()

# repeat this block
y = ((x-mul)**2).sum(1) < ((x-mu2)**2).sum(1) # expectation
x1=x[y<0.5]; x2=x[y>=0.5]
plt.plot(x1[:,0],x1[:,1], 'rx')
plt.plot(x2[:,0],x2[:,1], 'b+')
mul=x1.mean(0); mu2=x2.mean(0); # maximization
plt.plot(mul[0],mul[1], 'kx', markersize=12)
plt.plot(mu2[0],mu2[1], 'kx', markersize=12)
plt.show()
```

In the above we did not really settle the means randomly but chose a particular task in order to see the effect of the algorithm better. It is a good idea to play around with different configuration of this program such as changing the initial conditions to a random start or the shape of the data distribution.
