After this transformation we were able to use a linear model in this transformed space. The transformed space was larger than the original space, but in this transformed space we were able to use a linear regression model. This is sometimes called generalized linear regression. Finding the right transformation $\phi$ is not easy and somewhat we transformed the problem into the problem of finding the appropriate non-linear transformation. Deep learning can be seen as learning these functions from the data.

It is worthwhile to consider another non-linear example function to our house data. For this we choose a series of Gaussian functions,

```
$y = \sum_{i} w_{1,i}e^{-(w_{2,i}-x)^2/w_{3,i}},$
```

We have three parameters in this model, and the corresponding learning rules

```
$w_{1,i} \leftarrow w_{1,i} - \alpha(y-\hat{y})e^{-(w_{2,i}-x)^2/w_{3,i}}$
```

```
$w_{2,i} \leftarrow w_{2,i} + \alpha(y-\hat{y})2(w_{2,i}-x)e^{-(w_{2,i}-x)^2/w_{3,i}}$
```

```
$w_{3,i} \leftarrow w_{3,i} - \alpha(y-\\hat{y})frac{(w_{2,i}-x)^2 e^{-(w_{2,i}-x)^2/w_{3,i}}}{w_{3,i}^2}$
```

A fit of the data with a single Gaussian is shown in Fig. 5.5A, which looks similar to the fit with the 12-order polynomial, but with only three parameters. However, the reason to bring this function is to realize that with an increasing number of parameters and higher complexity the we can easily overfit. For example, if we take the number of Gaussians to be equal to the number of training points, we can produce a curve that goes through almost all the training points as shown in Fig. 5.5B. It is clear that this function would only generalize as we do not expect that houses outside these examples costing nothing as predicted by the model. This is a clear demonstration of overfitting.
