# 8.5 Generative neural networks

### 8.5.1 Generative adversarial network (GAN)

We have far assumed specific functional forms of generative models to discuss generative models in the Bayesian context. We are now going back to deep neural networks which are useful to learn more complex models from data when specific causal models are not known. There are several approaches to building generative models of which we want to mention two, namely generative adversarial networks and the variational autoencoders. The basic idea behind generative adversarial neural networks (GANs) is to train a generator neural network model so that the generated examples are able to fool a discriminator network which is itself trained to discriminate network-generated examples and real example. The overall architecture is outlined in Fig. 8.7. The basic components are a generator network and a discriminator network, but the main idea is how to use them. The discriminator network is typically a deep recognition network like the convolutional networks we used for MNIST or ImageNet. It is either fed a real part or a fake input. So this network is like a forgery expert that needs to distinguish real from fake, a simple binary decision. The discriminator is trained on a combination of real and fake images where the fake images are generated by the generator network. This is done by providing a random input to this network which can be viewed as a random example from a latent space of the objects that should be generated.

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_179_0.png)

**Fig. 8.7** Outline of a generative adversarial network (GAN).

At the beginning the generated objects are certainly not very good, neither is the discriminator. Once the discriminator gets better we can then use the information learned by the discriminator to make the generator better. This is done by combining the generator and discriminator network with a large adversarial network where the weights of the discriminator part are fixed and the weights of the generator are adjusted with the label of "real" to make the generator output more similar to inputs that would be categorized as real by the discriminator network. The use of the network is hence a bit different from deep networks in the target function. The better the generator gets, the more the discriminator has to adjust, and this information in turn drives changes in the generator. In practice, it is not so easy to implement these networks, and many tricks are commonly used. In particular, it is recommended to use both tanh or leaky linear units (LLU), to adjust the learning rates, and to monitor the progress of each network. However, it has been shown that good results can be achieved with such networks after learning.

### 8.5.2 Variational autoencoder (VA)

We have already discussed the autoencoder in section 4.7 which can be seen as an encoder into a latent space and a decoder from that latent space back into the feature space. Previously we also labelled this latent space as semantic as we assume that this lower-dimensional space represents some meaning. If we vary the latent activation could generate outputs with the decoder so that autoencoders could be seen as generative models. However, the question is how to generate this variation in a way in order to generate novel examples which still represent the expected distribution of a target class. We usually do not know much about the structure of the latent space which prevents us from making systematic variations.
