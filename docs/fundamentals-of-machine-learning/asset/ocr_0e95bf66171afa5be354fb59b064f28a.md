The following code reads data, restricts the vocabulary size to 20,000 unique words, and then represents each document as a string of 8 unique words (maxlen = 8) to reduce the size of this example so we execute it on a simple laptop. If the document has more than eight words, then the Keras function `pad_sequences()` would using some 0 padding to make sure each document is of max length.

Listing 9.6 LSTM.ipynb (part 1)
```python
from keras.preprocessing import sequence
from keras import models, optimizers, datasets, utils, losses

vocabulary_size = 20000
batch_size = 32

x_train, y_train, x_test = datasets.imdb.load_data(num_words=vocabulary_size)
x_train = sequence.pad_sequences(x_train, maxlen)
x_test = sequence.pad_sequences(x_test, maxlen)
```

We can define the model, where the input is funneled into the embedding layer so that this layer can be trained within the task. The embedding representation is then used by the LSTM layer, and finally we use a single sigmoid node for the classification of the sentiment. We also added dropout to the output of the recurrent layer for regularization to prevent overfitting. Dropout to the recurrent layer is a bit trickier as small errors stack up in the recurrent network dynamics and lead to problems of correct recall. An excellent treatment of this issue is given by Gal and Gajahramani in an NIPS paper called "A theoretical grounding of dropout in recurrent neural networks." The recurrent layers in Keras have parameters which include dropout in these layers that are strongly recommended. In this example, we used a high dropout rate.

Listing 9.7 LSTM.ipynb (part 2)
```python
inputs = layers.Input(shape=(maxlen))
e=layers.Embedding(max_features, 128)(inputs)
h=layers.LSTM(128, dropout=0.8, recurrent_dropout=0.8)(e)
h=layers.Dropout(0.7)(h)
outputs=layers.Dense(1, activation='sigmoid')(h)
model = models.Model(inputs, outputs)
```

This model is compiled and trained in the binary cross-entropy as shown in Listing 9.8.
The evaluation accuracy is around 70 percent after this short training. However, this is only a small example of a simple language processing task. In general, it is good to learn vector embeddings on better tasks as a language model aims to predict the next word in a sequence. Good word embeddings have been achieved with large datasets. Two popular ones are Word2Vec and GloVe, and it is possible to download these to use for pre-embedding. Using recurrent models with sophisticated word embeddings are among the best current models.
