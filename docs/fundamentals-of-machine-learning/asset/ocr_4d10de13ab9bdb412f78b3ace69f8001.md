Instead of going into the details of variations of gated recurrent networks, it is useful to mention one more ingredient in recurrent models to be crucial for boosting performance: **attention**. Attention has been considered an important part of human information processing since the release of William James' seminal *The Principles of Psychology* in 1890. At its heart, attention captures the ability of humans to orient towards important information, or to weigh information as greater than others and to inhibit others. Different forms of attention have been identified in the early visual system to emphasize such features like letter "A" in a sea of letters "C". This leads to the common effect that we perceive objects as "popping out," which quickly narrows down the search space for objects.

This feature-based bottom-up attention is not the only effect. Indeed, our ability to direct attention, either to spatial locations or to objects, shows some form of top-down attention. Some consequences of attention on neuronal firing have been recorded. For example, 9.8A shows experimental responses of neurons that are sensitive to objects moving in a certain direction in the visual scene. Response curves of neurons are called "tuning curves" in neuroscience. The squares show when the subject attends a "fixation point" and not attending to the motion... This is demonstrated in Fig. 9.8B with the program below. We draw a Gaussian which curves down slightly (blue curve). When adding a constant we get shifted blue curve, whereas if we multiply the original with 1.5 we get the red curve that represents the experimental results in Fig. 9.8A.

Listing 9.9 attention.ipynb

```
import numpy as np
import matplotlib.pyplot as plt

f = lambda x: np.exp(-x**2)-0.2
x = np.linspace(-2,2,221)

plt.plot(x,f(x))
plt.plot(x,f(x)*.15,'b--')
plt.plot(x,f(x)=1.5,'r')
```
