The general question we have to solve is how to weight the different evidence in light of the reliability of this information. Solving this problem is easy in a probabilistic framework and is one of the main reasons so that much progress has been made with the application of probabilistic machine learning.

Prior knowledge should be combined with prior knowledge is an important question. Luckily, we already know how to do it in a probabilistic sense. Namely, if we divide the chain rule (Eq. 6.34) by $p(y)$, which is possible as long as $p(y) > 0$, we get the

```
$$p(x|y) = \frac{p(y)p(x)}{p(y)}, \quad (6.41)$
```

which is called Bayes rule after the inventor Thomas Bayes. This theorem is important because it tells us how to combine prior knowledge on a random variable $x$ to estimate, $p(x)$, with the likelihood $p(x|y)$ of data given $y$. The likelihood can often be measured in some way, for example by measuring sensors reading $y$ when controlling the state $x$. The posterior distribution, $p(x|y)$, which is the new knowledge of the distribution with new data, can be calculated by multiplying the likelihood for the prior $x$ and normalizing this properly by the marginal distribution of having such data, $p(y)$, also called evidence. We will see that, in practice, knowing the marginal of the data is difficult, but we will also see that the non-normalized version is useful in some applications as classification, as discussed later.

Bayes rule in the chain rule and the rule of total probability is basically all the rules we need to do probabilistic inference. Probabilistic inference is basically how we use these rules with the known or estimated density functions to derive probabilistic statements. For example, let us calculate how likely it is to rain if a meteorologist is predicting rain.

```
$$p(X = r|Y = r) = ?. \quad (6.42)$
```

```
$$p(X = r) = 0.3, \quad (6.43)$
```

```
$$p(X = \hat{f}) = 1 - p(X = r) = 0.7. \quad (6.44)$
```
