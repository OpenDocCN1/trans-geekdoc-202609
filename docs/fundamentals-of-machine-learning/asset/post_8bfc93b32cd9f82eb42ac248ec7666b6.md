```python

inputs = layers.Input(shape=(784,))
x = layers.Dense(128, activation='relu')(inputs)
x = layers.Dense(128, activation='relu')(x)
x = layers.Dense(128, activation='relu')(x)
x = layers.Dense(128, activation='relu')(x)
outputs = layers.Dense(10, activation='softmax')(x)

model = models.Model(inputs=inputs, outputs=outputs)
```

The MLP is characterized by a fully connected layer where each neuron of the previous layer is connected to every neuron in the receiving layer. Such layers are commonly called dense layers. We have to specify the activation function for each layer if it is not linear, which is here the rectified linear (relu)

> $g(x_i) = \begin{cases} x_i & \text{if } x_i > 0 \\ 0 & \text{otherwise,}\end{cases}$

except the last layer for which the activation function is softmax function

> $g(x_i) = \frac{e^{-x_i}}{\sum_j e^{-x_j}}$

The model has to be compiled. This is different from sklearn and the reason is at this step the model is prepared for execution on GPUs if available. Most of the examples in this book are prepared to be small enough that a GPU is not required.

In the compilation step we specify which function to use, which optimizer we will use, and also metric we use to evaluate the results. Of course, we have to discuss these choices in more detail, but for now we want to show that such networks with popular choices can do remarkable things. It is common that this simple model results in a test accuracy of around 98 per cent on the MNIST dataset. In contrast, a comparable SVM achieves around 91 per cent on the MNIST dataset.

## 4.3 Representational learning

Here, we are discussing feedforward neural networks which can be seen as simple transformations or mapping from an input space to a latent space to an output space. The latent space is spanned by neurons between the input nodes and the output nodes, which are sometimes called hidden neurons. We of course observe the activity of the nodes in our programs that are not really hidden. All the weights are learned from the data so that the transformations implemented by the neural network are learned from examples. However, we can guide these transformations with the architecture. The representations should be learned so that the final classification in the last layer is better than the raw sensory space. Also, the network and hence the representation it represents should make generalizations to previously unseen examples easy and robust. It is useful to pause for a while and here discuss representations.

### 4.3.1 Signal decomposition and sparse features

To illustrate again the representation of a signal with filters, consider basic signal analysis. Let us consider time-varying signals that are represented with floating point values for each time step. Say we are sampling an EEG signal that is recorded from electric electrodes attached to the head with 500HZ. That is, we have one data point every 0.002 second. If we assume that a floating point is typically represented computer word of 64 bits, then a 10-minute length would take over 2 MB of storage. An example $x(t)$ is illustrated at the top in Fig. 4.6. While this is a relatively complicated signal, we have created this signal from two template signals that we call basis functions. With these basis functions we can reconstruct the signal as

$$x(t) = a_1y_1(t) + a_2y_2(t)$$

Representing the original signal with these basis functions has a big advantage. For example, if we store a set of basis functions in several computers, then we can transmit the signal with only two numbers for the coefficients $a_1$ and $a_2$. Of course, we cannot expect real signals to be made up of only these two functions. So in practice, we want to create a long list of "appropriate" basis functions. A common example for basis functions is sine waves which are usually good choices for periodic signals. A composition of a signal into such sine and cosine functions is called a Fourier transformation

$$x(t) = \int_{0}^{\infty} a(\lambda)\sin(2\pi\lambda t) + b(\lambda)\cos(2\pi\lambda t)d\lambda \quad (4.10)$$

Another common for more localized functions are however similar to $y_1$ in $y_1$. Such functions are called wavelets and the corresponding decomposition is a wavelet transform. These functions are usually chosen by hand and have been designed specifically for certain applications. The filters in deep neural networks can be seen as representing a form of basis functions for a specific feature decomposition. The interesting part of neural networks is that these functions are learned from data so we do not need to design basis functions by hand.

Since we take a large or even infinite number of basis functions into account, it is possible to represent any function with appropriate basis functions. However, having arbitrary basis function is also not the best choice. That is, if we have a long list of basis functions, then we might still need a large number of coefficients. Indeed, if we end up with the same representation as a signal for which we just store the value at each time point. An important insight to make efficient use of resources while extracting the "essence of signals" is Sparse representation is a representation where we might have a large number of basis functions in our dictionary (nodes in a deep network) but only using a relatively small number of active nodes to represent each example. In fact this might correspond

$$y(t) = a_1x_1(t) + a_2x_2(t) + a_3x_3(t) + a_4x_4(t) + a_5x_5(t) + a_6x_6(t) + ... \quad (4.11)$$

with coefficient vector

$$a = (1, 3, 0, 0, 0, 0, ...). \quad (4.12)$$
