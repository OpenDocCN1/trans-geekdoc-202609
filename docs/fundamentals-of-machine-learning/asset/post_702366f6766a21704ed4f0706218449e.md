## 8.4 Self-supervised generative models

### 8.4.1 k-means clustering

In the previous learning methods we had training examples with feature vectors $x$ and labels $y$. We now discuss an example of unsupervised learning where no labels are given. Such data are widespread. For example, it is easy to take pictures with a digital camera and get huge numbers of pictures. What usually takes time is label the pictures, as in the ImageNet dataset, or even to segment particular objects in the picture. We can not use the unsupervised learning methods we have discussed so far.

However, samples of unlabeled collections still have information embedded in them, and self-supervised learning has important applications. In particular, we can glean structure from the data which can help in representational learning and speed up supervised learning. Self-supervised or unsupervised does not mean that the learning is not guided; the learning follows specific principles that are used to guide the organization of the data itself.

We start here by discussing a widespread use of methods for data clustering. In this problem domain, we are given unlabeled data described by a set of features and to put them into $k$ clusters. In the first example of clustering, we categorize the data proximity to a mean value. Then we assume a model that specifies a mean value of the data and classifies the data based on the proximity to the mean value. Of course, we do not know this mean value for each class. The idea is to start with a guess for this mean value and label the data accurately. Then we use the label from this hypothesis to improve the model by calculating a new mean, and repeat these steps until convergence is reached.

More formally, we consider a training set of data points $\{x^{(1)}, x^{(2)}, ..., x^{(m)}\}$ and a hypothesis of clusters, $k$, for the k-means clustering algorithm. The algorithm starts by choosing random initial means for each of the $k$ classes. The next two steps are iterated. Given the means, we can choose the label of each data points according to the class label of the closest mean, giving these calculated labels we now update the mean among these data. These steps are iterated until convergence. This algorithm is summarized in Table 8.4. An example of the initial state and two iterations of this algorithm is shown in Fig. 8.4. ### 8.4.2 Mixture of Gaussian and the EM algorithm

We can now extend the idea of $k$-means clustering to the more rigorous case of assuming a specific model for each class. We will again use Gaussian models here as the example, but it should be clear that we can use any form of model for the in-class distribution. Here we assume that we have $k$ Gaussian classes, where each class is chosen from a multinomial distribution,

$$p(z^{(i)} = j) \propto \text{multinomial}(\Phi)_j \quad (8.43)$$
$$p(x^{(i)}|z^{(i)} = j) \propto N(\mu_j, \Sigma_j). \quad (8.44)$$

This is called Gaussian mixture model. The corresponding log-likelihood function is

$$L(\Phi, \mu, \Sigma) = \sum_{i=1}^m \log \sum_{z^{(i)}=1}^m p(x^{(i)}|z^{(i)}; \mu, \Sigma)p(z^{(i)}; \Phi). \quad (8.45)$$

Since we consider unsupervised learning, we are given input data $x$ without labels. We then use the symbol $z$ for the labels that we assume to be latent variables $z^{(i)}$. Knowing the labels makes the problem harder than the supervised Gaussian model discussed earlier. If given the class membership, the log-likelihood would be

$$L(\Phi, \mu, \Sigma) = \sum_{i=1}^m \log p(x^{(i)}; z^{(i)}, \mu, \Sigma), \quad (8.46)$$

which we could use to calculate the maximum likelihood estimates of the parameter (seq Eqs 8.17–8.19),

$$\phi_k = \frac{1}{m} \sum_{i=1}^m \mathbb{1}(z^{(i)} = k) \quad (8.47)$$
$$\mu_k = \frac{\sum_{i=1}^m \mathbb{1}(z^{(i)} = k)x^{(i)}}{\sum_{i=1}^m \mathbb{1}(z^{(i)} = k)} \quad (8.48)$$
$$\Sigma_k = \frac{\sum_{i=1}^m \mathbb{1}(z^{(i)} = k)(x^{(i)} - \mu_k)(x^{(i)} - \mu_k)^T}{\sum_{i=1}^m \mathbb{1}(z^{(i)} = k)} \quad (8.49)$$

The indicator function $\mathbb{I}(x=y)$ is simply 1 if $x=y$ and zero otherwise. Therefore, when put into a sum it counts the number of cases in which condition is true. While we do not know the class labels, we can follow a similar strategy to the $k$-means clustering algorithm and propose some labels and use them to estimate the parameters. We can use the new estimate of the distributions to find better labels for the data, and repeat this until a stable configuration is reached. In general, this strategy is outlined in Fig. 8.5. In this version the EM algorithm for expectation-maximization. The algorithm is hard-classify data into one or another, but we take a more soft approach that considers the probability estimate of a point belonging to class.

1. Initialize parameters $\phi_j, \mu_j, \Sigma$ randomly.
2. Repeat until convergence:
   - **E-step:** we make assumptions of training labels from the current model (expectation step).
   - **M-step:** use this hypothesis to update the parameters of the model to maximize the probability of the observations (maximization step).
