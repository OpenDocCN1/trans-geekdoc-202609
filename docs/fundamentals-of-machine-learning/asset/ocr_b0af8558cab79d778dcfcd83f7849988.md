This seems to be a daunting task, but we will see that there are elegant solutions available with fully convolutional networks. To discuss this, we go back to the VGG16 network discussed at the end of the section. We can strip the top (dense) layers and then add another layer that up-samples the last layer of the VGG16. This up-sampling can be some form of interpolation, although the filters can also be learned. It is best to think about this up-sampling as the inverse of pooling. In this way we can recover the size of the original image. We can then use a segmentation as a fine-grained label for each pixel and train on the corresponding loss. It is common to drop some of the connections so that only specific regions contribute to training in each iterations. This procedure mimics some of training on individual objects. We can then combine this coarse semantic information with more fine-grained information from the original input, or from early layers convolutional layers. This resembles what the skip connections discovered earlier. Needless to say, there are now a variety of new versions of segmentation networks discussed in the literature.
