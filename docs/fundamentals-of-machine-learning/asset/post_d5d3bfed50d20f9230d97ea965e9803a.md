While learning algorithms have received a lot of attention, a big factor for the success of a network is the number of training examples we need. Unfortunately, there is no simple rule for how many training examples are necessary. Efficient training depends on many factors such as the training algorithm itself, the right regularization, and of course, on the complexity of the problem itself. The only fact is that a more complex model generally requires more data. While “big data” has been a buzzword in certain circles, many applications do not have infinite labeled examples, and making deep learning with limited data is a very interesting and relevant area in practice. Learning feature representations in early layers should be to some extent independent of the higher-level tasks. It is therefore common to utilize pre-trained networks in vision and other domains such as natural language processing.

Finally, important techniques that helps enormously to find good solutions in the model space is input normalization and batch normalization. We commonly normalize the input by subtracting the mean of the data, either over all the data, or more commonly over each batch of the input data, and dividing this by the standard deviation of the data.

```
$$\mu = \frac{1}{n_B} \sum_{i=1}^{n_B} x_i \quad (4.13)$$
```

```
$$\sigma^2 = \frac{n_B}{n_B} \sum_{i=1}^{n_B} (x_i - \mu)^2 \quad (4.14)$$
```

```
$x_i \leftarrow \frac{x_i - \mu}{\sigma} \quad (4.15)$$
```

Sometimes there is a small number around $\sigma^2$ to prevent the fraction in the last equation becoming too large when $\sigma^2$ is close to 0. Input normalization will often help the speed of learning, and we will discuss this later. If normalization of input data helps, then why not apply it to each layer in the network? This is now common called batch normalization. One problem with this procedure is that by changing the overall scaling and a shift of the data in each batch, then the following network has to unlearn the specific weights. This seems rather counterproductive. Batch normalization therefore includes two separate parameters to absorb the overall effect of the shift and scale,

```
$x_i \leftarrow \gamma x_i + \beta. \quad (4.16)$
```

With these trainable parameters, the training algorithm itself can adjust the right rate of changes.

There are many other tricks and techniques to make deep neural networks work for some applications, and working with such techniques is not always easy. For example, it is not always the case that batch normalization helps and sometimes it could even worsen the training early in the training process. The same holds for dropout and the choice of learning rule. As we stressed already several times, at the end it depends on the structure of the problem whether the specific model proposed through deep learning is appropriate for this application. This is another reason to understand the principles behind such methods, such as regularization in general, which we will consider in the following chapter.
