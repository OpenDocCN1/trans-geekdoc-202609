# Episode 1

To realize this we introduce an eligibility trace we call $e(s, a)$. At the beginning, this eligibility trace is set to $0$ for all states. For each visited state we set the eligibility trace to $1$ for this current state, and we discount the eligibility for all other states by $\gamma$. This is demonstrated in Fig. 10.5. In the figure we indicate the eligibility trace building up during one episode until reaching the rewarded state, at which time the values of all states are updated in the right proportion. This algorithm does therefore only one optimal episode to find the correct value function, at least in case a learning rate of $\alpha = 1$. and update all $Q$-values proportional to the TD error of this step multiplied by the eligibility trace,

```
$Q(s, a) \leftarrow Q(s, a) + \alpha TD * e(s, a). \quad (10.24)$
```

While this algorithm requires some memory, we see that we need to store an eligibility trace which indirectly sequences the sequence agent took. It is also easy to extend this algorithm to a more general form TD($\lambda$) where we can interpolate the original TD algorithm with no eligibility trace, called TD(0), with the perfect memory of TD(1). An exponential decay of an eligibility trace can be implemented simply by including a factor $\lambda$ in Eq 10.23,

```
$e(s, a) \leftarrow e(s, a)\gamma\lambda \quad \text{for all } s, a. \quad (10.25)$
```
