# Example of basic RMB on MNIST data

While the principles behind RBMs are mathematically advanced, their implementation is straight forward. We can illustrate the principle with a simplified layer model and training on some examples from the MNIST data set. For this we load the MNIST dataset from Keras, although we do not need Keras for the network in this program. The network consists of 784 = 28 x 28 nodes as this is the size of the input. We choose 100 hidden nodes. We intend selected examples for each number from the training set.
