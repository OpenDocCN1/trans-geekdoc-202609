An example curve where we show the difference between the desired and actual output of the network is shown on the left in Fig. 5.11 by the blue line. The error is getting smaller, indicating that some learning takes place. The error does not, reach, 0. This comes from the fact that we use a sigmoid function which approaches a value of 1 only asymptomically. However we can introduce post-processing step in which we apply a threshold function. This corresponds to the error that we calculate in the program. The corresponding learning curve is shown in orange on the left graph in Fig. 5.11. This demonstrates that this perceptron can solve the Boolean function with this post-processing step. The error function such as the loss used for training is somewhat as it shows that there is continuous progress during learning when the threshold stays constant, although the values themselves do not tell the story. The thresholded values give us some indication of how many patterns are recognized, but it would be better to check each pattern separately, something which we omitted to keep the program short. It is very useful to always calculate error numbers that can be interpreted in terms of the performance that a user is looking for, which is not necessarily the loss function used for the gradient descent.

We have already discussed batch versus online learning in the linear case and it might be good to go for backpropagation. We have derived the learning rule based on the mean square error over all the training points. This corresponds to applying all the training examples and calculating the average gradient before updating the weight values based on this average. This is batch training, since we use the whole batch of training examples for each weight update step.
