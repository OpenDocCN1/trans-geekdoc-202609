# 9.3 Gated neural networks, natural language processing, and attention

As outlined earlier, the basic recurrent network has the form of a memory that takes earlier states into account. However, the influence of these states fades exponentially when the weight values are smaller than 1, which they have to be would exponentially overwhelm the input. The basic RNN is hence a form of short-term memory. Such a short-term memory is usually insufficient for many applications. For example, in natural language processing it is necessary to take context into account that might be relative to words at the current sequence position. Hence some memories should "kick in" at some appropriate time which might be triggered by another word. It is important to remember these memories until they are used at a later state of processing.

## 9.3.1 Long short term memory (LSTM) and sentiment analysis

The first network which has taken longer-term memory into consideration is called LSTM which stands for "long short-term memory". This network is illustrated in Fig. 9.6.

This gated network introduces another cell $c(t)$ which represents an intrinsic memory state. Its value is forwarded to the next time step and can be modified in each time step with two operations, a forgetting gate $f_t$, and an input (write) gate $i_t$,

> $$\mathbf{c}(t) = f(t)c(t-1) + i(t)\tilde{c}(t)$$

The new memory addition depends on the new input and is calculated as

> $$\tilde{c}(t) = \tanh\{x(t), h(t-1)\} + b_c$$

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_193_0.png)

**Fig. 9.6** Long Short Term Memory (LSTM; adapted from colah's ).

As a reminder, the curly brackets signify here a concatenation operation. This is like a usual hidden layer equation used in the basic RNN. The gating functions themselves are learned with corresponding weight values and a sigmoid gain function of the logistic variety to scale these terms to the range 0 (total forgetting, no memory update) and 1 (keep memory state, add input fully);

```
$f(t) = \sigma(w_f\{x(t), h(t-1)\} + b_f)$
$i(t) = \sigma(w_o\{x(t), h(t-1)\} + b_x)$
```

Finally, we produce an output for the recurrent node from its memory state

```
$h(t) = o(t)\tanh(c(t))$
```

```
$o(t) = \sigma(w_o\{x(t), h(t-1)\} + b_o)$
```

In order to demonstrate an LSTM in Keras follow the common example of a sentiment analysis. Sentiment analysis is here just another example of classification in the context of giving documents labels representing sentiments like good or bad. We use the Large Movie Review Dataset (IMDB), which contains 50,000 movie reviews which are train either positive or negative. The task is to use the documents for training and test the other if the sentiment of the test reviews can be predicted. This program is included in Keras examples that we provide here a simplified version. In Chapter 8 we mentioned the bag of words. We want to represent the text itself as a sequence of words, which is much better way to approach natural language processing (NLP). This embedding here, transforms an arbitrary representation to a dense vector space in which words are commonly related. A common step in NLP is to learn an *embedding*. While this helps with the dimensionality of the representation, this does not capture relations between words. In Keras we can realize this with an embedding layer. The following code reads the IMDB data, restricts the vocabulary size to 20,000, and then represents each document as a string of max length (maxlen = 8).

```python
Listing 9.6 LSTM.ipynb (part 1)
from keras.preprocessing import sequence
from keras import models, optimizers, datasets, utils

vocabulary_size = 20000
batch_size = 32

x_train, y_train, x_test = datasets.imdb.load_data(num_words=vocabulary_size)
x_train = sequence.pad_sequences(x_train, maxlen)
x_test = sequence.pad_sequences(x_test, maxlen)
```

We can define the model, where the input is funneled into the embedding layer so that this layer can be trained within the task. The embedding representation is then used by the LSTM layer, and finally we use a single sigmoid node for classification of the sentiment. We also added dropout to the output of the recurrent layer for regularization to prevent overfitting. Dropout to the recurrent layer is a bit trickier as errors stack up in the recurrent network. An excellent treatment of this issue is given by Gal and Ghramani in a NIPS paper called "Theoretical grounding of dropout in recurrent networks." The recurrent layers in Keras include dropout in these layers that are strongly recommended. In this example, we used high dropout rate.

```python
Listing 9.7 LSTM.ipynb (part 2)
inputs = layers.Input(shape=(maxlen,))
e = layers.Embedding(max_features, 128)(inputs)
h = layers.LSTM(128, dropout=0.8, recurrent_dropout=0.8)(e)
h = layers.Dropout(0.7)(h)
outputs = layers.Dense(1, activation='sigmoid')(h)
model = models.Model(inputs, outputs)
```

This model is compiled and trained in binary cross-entropy as shown in Listing 9.8. The evaluation accuracy is around 70 percent after this short training. However, this is only a small example of a simple language processing task. In general, it is good to learn vector embeddings on better tasks as a language model aims to predict the next word in a sequence. Good word embeddings have been achieved with large datasets. Two popular ones are Word2Vec and GloVe, and it is possible to download these to use for pre-embedding. Using recurrent models with sophisticated word embeddings are among the best current models.
