The idea is to start with a random value for each parameter and improve the learning in successive steps by changing the values along the negative gradient,

$$\begin{pmatrix} w_1 \ w_2 \end{pmatrix} \leftarrow \begin{pmatrix} w_1 \ w_2 \end{pmatrix} - \alpha \nabla L(w_1, w_2; x^{(i)}, y^{(i)}) \quad (5.3)$

The **hyperparameter** is called the learning rate, and the Nabla operator $
abla$ represents the gradient.

$$\nabla L(w_1, w_2; x^{(i)}, y^{(i)}) = \frac{\partial}{\partial w_1, \partial w_2} L(w_1, w_2; x^{(i)}, y^{(i)}) \quad (5.4)$

Minimizing the loss with gradient descent is an important part of machine learning and the basic principle to derive the learning rule for specific models. In our case, calculating the derivative for MSE loss function (5.2) with the linear prediction function (5.1) gives the following learning rules for the two parameters

$w_1 \leftarrow w_1 - \alpha \frac{1}{N} \sum_{i} (w_1 x^{(i)} + w_2 - y^{(i)})x^{(i)} \quad (5.5)$

and

$w_2 \leftarrow w_2 - \alpha \frac{1}{N} \sum_{i} (w_1 x^{(i)} + w_2 - y^{(i)}) \quad (5.6)$
