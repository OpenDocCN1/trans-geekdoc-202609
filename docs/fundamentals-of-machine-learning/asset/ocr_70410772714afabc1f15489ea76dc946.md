$$-(y^{(i)}(\mathbf{w}^T\mathbf{x} + b) - 1) \geq 0. \quad (3.19)$

So, to summarize, we have a quadratic minimization problem (Eq. 3.16) with the linear inequalities Eq.3.19 as constraint. Optimization can be framed with the Lagrange formalism. For this, we add the constraints to the main objective or function with some parameters $\alpha_i$ that are generally called Lagrange multipliers,

```
$$\mathcal{L}^P(\mathbf{w}, b, \alpha_i) = \frac{1}{2}|\mathbf{w}||^2 - \sum_{i=1}^m \alpha_i y^{(i)}(\mathbf{w}^T\mathbf{x} + b) - 1. \quad (3.20)$
```

Lagrange multipliers determine how well the constraints are observed. In the case of $\alpha_i=0$, constraints does not matter. To conserve the constraints, we should make these values as large as we can. Finding the maximum classifier is here given by the so-called primal problem

```
$p^* = \min max \mathcal{L}^P(\mathbf{w}, b, \alpha_i) \quad (3.21)$
```

However, Vapnik went step further by realizing that the margin can be maximized by maximizing the so-called dual Lagrangian

```
$d^* = max min \mathcal{L}^D(\mathbf{w}, b, \alpha_i), \quad (3.22)$
```

since one can show that

```
$p^* \leq d^*. \quad (3.23)$
```

Note that in these formulae we interchange the minimum and maximum operations. While we will not destroy this dual problem, the reason for this step is the following. While it is straightforward to solve the primal optimization problem, solving the dual problem leads to a formulation in which we can use a kernel trick, discussed later to generalize the method to non-linear cases. Moreover, the equality holds when the optimization function and the constraints are convex. So, if we minimize $\mathcal{L}$ by looking for solutions of the derivatives $\frac{\partial\mathcal{L}}{\\mathbf{w}}$ and $\frac{\partial\mathcal{L}}{\\alpha_i}}$, we get

```
$$\mathbf{w} = \sum_{i=1}^m \alpha_i y^{(i)}\mathbf{x}^{(i)} \quad (3.24)$
```

```
$0 = \sum_{i=1}^m \alpha_i y^{(i)} \quad (3.25)$
```

Substituting this into the optimization problem, we get the final form of our optimization problem,

```
$$\max_{i,j} \alpha_i - \frac{1}{2}\sum_{i,j} y^{(i)}y^{(j)}\alpha_i\alpha_j\mathbf{x}^{(i)}^T\mathbf{x}^{(j)}, \quad (3.26)$
```

subject to the constraints

```
$$\alpha_i \geq 0 \quad (3.27)$
```

> ^Under these assumptions, there are other conditions that hold, called the Karush-Kuhn-Tucker conditions, that are useful in proving proof of the convergence of the methods outlined here.
