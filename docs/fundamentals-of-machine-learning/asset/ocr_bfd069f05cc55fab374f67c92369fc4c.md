# 5.3 Advanced gradient optimization (learning)

Learning in machine learning means finding parameters of the model w that minimize the loss function. There are many methods to minimize a function, and each would constitute a learning algorithm. However, the workhorse in machine learning is usual some form of a **gradient descent** algorithm that we encountered earlier. Formally, the basic gradient descent minimizes the sum of the loss values over all training examples, which is called a **batch algorithm** as all training examples the batch for minimization. Let us assume we have $m$ training data, then gradient descent iterates the equation

> $$w_i \leftarrow w_i + \Delta w_i$ (5.7)

with

> $$\Delta w_i = -rac{\alpha}{N} \sum_{k=1}^{N} \frac{\partial L(y^{(i)}, \mathbf{x}^{(i)})}{\partial w_i}$ (5.8)

where $N$ is the number of training samples. We can also write this compactly for all parameters using vector notation. The Nabla operator $\nabla$

> $$\Delta \mathbf{w} = -rac{\alpha}{N} \sum_{i=1}^{N} \nabla L^{(i)}$ (5.9)

with

> $$L(y^{(i)}, \mathbf{x}^{(i)})$ (5.10)
