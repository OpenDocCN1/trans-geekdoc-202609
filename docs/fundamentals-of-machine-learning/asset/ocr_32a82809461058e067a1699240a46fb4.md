# 200 Cyclic models and recurrent neural networks

Let us consider the case where we have chosen enough hidden nodes so that the system can, give the right weight values, implement a generative model of a given world. Thus, by choosing the right weight values, we want this dynamical system to approximate the probability function, $p(s^v)$, of the sensory states (states of visible nodes) caused by the environment. To define a learning rule, we need to define an objective function. In this case, we want to minimize the difference between two density functions. A common measure for the difference between two probabilistic distributions is Kulback–Leibler divergence,

```
$KL(p(s^v); p(s^w)) = \sum_{s} p(s^v) \log \frac{p(s^v)}{p(s^w)} \quad (9.29)\n= \sum_{s} p(s^v) \log p(s^v) - \sum_{s} p(s^v) \log p(s^v; w). \quad (9.30)
```

To minimize this with a gradient method, we need to calculate the derivative of this "distance measure" with respect to the weights. The first term in the difference in Eqn 9.30 is the entropy of sensory states, which does not depend on the Boltzmann machine. Minimizing the Kulback–Leibler divergence is equivalent to maximizing the average log-likelihood function,

```
$l(w) = \sum_{s} p(s^v) \log p(s^v; w) = \langle \log p(s^v; w) \rangle. \quad (9.31)
```

Once we have seen the argument for maximizing the log-likelihood function several times, although we now put this into the context of a recurrent model. In other words, we treat the probability distribution produced by the Boltzmann machine as a generative model as a function of the parameters, $w_{ij}$, and choose the parameters which maximize the likelihood of the training data (the actual world states). Therefore, the log-likelihood of our average increases the better the model approximates the world. A standard method of maximizing this is gradient ascent, which for given with respect to the weights. We omit the detailed derivation, but we note that the resulting learning rule can be written in the

```
$\Delta w_{ij} = \eta \frac{\partial l}{\partial w_{ij}} = \eta \frac{\beta}{2} (\langle s_i s_j \rangle_{clamped} - \langle s_i s_j \rangle_{free}). \quad (9.32)
```

The meaning of the terms on the right-hand side is as follows. The term labelled "clamped" is the average of correlation between two nodes when the visible nodes are fixed. The term labelled "free" is the thermal average when the recurrent system is running free. The Boltzmann machine can then be trained, in principle, to represent any arbitrary density functions, that the network has a sufficient number of hidden nodes.
