# Cyclic models and recurrent neural networks

In probabilistic models, we can represent such bilateral neural networks as undirected Bayesian networks of random variables. The random variables are as usual illustrated as nodes in such networks. We illustrated non-directed networks earlier in Fig. 9.1. Here we want to show the usefulness of such models with a segmentation example. In Chapter 4, we discussed fully convolutional networks which we illustrate again in Fig. 9.9 The segmentation is based on the prediction of class probability for every pixel of the image.

```
$p(\mathbf{y}|\mathbf{x}) = \prod p(y_i|\mathbf{x})$  (9.21)
```

```
$= \frac{1}{Z(\mathbf{x})} \sum_{\Sigma} f(\mathbf{x};\mathbf{w}),  (9.22)
```

where $\mathbf{x}$ is the input and $\mathbf{y}$ are the class labels. The output of the convolutional network $f(\mathbf{x};\mathbf{w})$ with a softmax function to convert this to probabilities, where $Z(\mathbf{x})$ is the normalization constant or partition function.

![](bbox=[0.198, 0.403, 0.802, 0.597])

**Fig. 9.9** Segmentation using a fully convolutional network with a Conditional Random Field layer as output layer.

We indicate here that we consider the class labels as independent from each other so that we could write the joint distribution as a product. However, there is a lot of information in the relations between the pixels, because we are looking for objects in continuous space. There, there is a high probability that a pixel has the same label as a neighboring pixel. We could add such dependencies in our models with parameters $\mathbf{v}$

```
$p(\mathbf{y}|\mathbf{x}) = \frac{1}{Z(\mathbf{x})} \sum f(\mathbf{x};\mathbf{w}) + \sum_{\Sigma_{nn}} v_{i,i+nn},$  (9.23)
```

where $nn$ stands for the next neighbors. Of course, we could consider other interaction patterns beyond the nearest pixels. In the next section, we will outline an example where all the output labels interact.

Training these networks, and Markov (conditional) random fields in general, requires algorithms like believe propagation to calculate the partition function efficiently. We will not discuss this further but will instead discuss an interesting example that has historically attracted a lot of attention.
