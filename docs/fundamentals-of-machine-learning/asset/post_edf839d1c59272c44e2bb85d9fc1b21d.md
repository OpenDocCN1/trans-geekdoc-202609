## 1.4 Recent advances

Many advances have been made in recent years based on machine learning, in particular with deep learning for image processing, natural language processing, and more general analytics. Many companies are now enthusiastic about data analytics, using data in a wider sense to gain insights into customer profiles or other data tasks. Machine learning is an important part of a data analytics engine. Data analytics often require additional care as data security to ensure privacy, the ability to acquire and maintain large data collections, and also to make results available in a format useful for humans. We will not delve into many of these aspects but concentrate on the data modeling aspects.

One of the most visible impacts of deep learning has been made in computer vision convolutional neural networks. The basic applications in this area are mostly based on recognition networks and methods for semantic segmentation. However, such methods have now also advanced object localization, object tracking, and scene understanding, to name but a few. Examples from my own projects are shown in Fig. 1.7. The left-hand image shows semantic segmentation to identify and localize crop and weed for a robotic farming application. The right-hand image shows an application of fish tracking for aquaculture applications.

Another area that has seen a huge improvement is the area of natural language processing (NLP). It has long been an important tasks to build programs that understand natural languages for applications such as translation, sentiment analysis, or to enable some of formal analysis of technical reports. Various methods for sequence modeling have contributed greatly to this area, in particular recurrent neural networks, discussed later in this book.

A developing area in machine learning is generative models. Generative models are models that can make examples of instances of a class. For example, a generative models can learn from cars and then generate images of cars by itself. Such networks could be used in some creative way. Examples of systems that can learn generative models are variational autoencoders (VAEs) and generative adversarial networks (GANs). These methods demonstrate an important advance: the ability to capture the probabilistic structure of objects in which can be exploited in various ways.

Machine learning methods have shown that it can produce solutions to problems that have been previously intractable. For example, computer programs to play the Chinese board "Go" have been mostly available at an advance level until a few years ago. However, in 2016, a machine learning program "Alpha-Go" that combined superbly and reinforcement learning was able to beat a player, Mr. Lee Sedol, who is considered one of the best players of the decade and had previously sixteen world titles. Go was considered to be a real challenge for AI systems as it was considered to rely on "gut feelings" rather than quantifiable strategies. It was a huge success when computers, which had only reached levels of an advanced beginner a few years prior, could win against an accomplished player.

Finally, AI has been strongly associated with the understanding of the human mind. While the subject of this book is far from explaining machine intelligence, the advances in machine learning have shed light on aspects of human cognition and brain processes. For example, generative models with sparseness constraints are able to reproduce the form of representations that brain scientists have measured in the early visual cortex, and is a lot of evidence, by comparing brain imaging data to deep learning vision systems, that are some aspects covered by networks. Bayesian reasoning and reinforcement learning are areas that are now inspiring new approaches in psychiatry. The brain has many aspects that are not captured by current machine learning models but these models capture some aspects of application domains that have long been difficult to program with traditional computers.

## 1.5 No free lunch, but worth the bite

Neural networks and other models, such as support vector machines and decision trees, are fairly models in contrast to Bayesian models that are much better at specifying a causal structure of interpretable models. More specific models should outperform more general model as they faithfully represent the underlying structure of the world model. This is captured by David Wolpert's "No free lunch" theorem, which states that there is not a single algorithms that covers all applications better than some other algorithms. The best model is, of course, the real world model, as discussed earlier, which we do not know. Applying machine learning algorithms is somewhat of an art and requires experience and knowledge of the constraints of the algorithms. Discussions of what is an appropriate model are sometimes cumbersome can distract us from making good use of them. We take a more practical approach, letting a user define what an appropriate contribution is for a machine learning model. For example, the best accuracy of a prediction might not always be the goal, and other considerations such as the speed of processing, the number of required training data, and the ability to interpret data be important factors. We will therefore include briefs of some classic machine learning algorithms even if they do not represent the latest research in this area.

An interesting remark that often cops up in discussions of some machine learning algorithms and, in particular, neural networks is that these methods are commonly described, and somewhat criticized, as black box methods. By "back box" we usually mean that the internal structure is not known. However, machine learning models usually live in a computer where we can inspect all components; these methods are known as white box methods. A better way to describe the difficulties with human interpreting machine learning models is due to the fact that deep learning models are commonly complex models that implement complex decision rules. While some application may have a goal of the learning of human interpretable decision rules, other might be interested in achieving better prediction performance, which requires more fine-grained rules.

We will see in Chapter 3 that writing a program to apply machine learning to data is not very difficult. New algorithms will often find their way to graphical data mining tools, which makes them available to an larger application community. applying algorithms correctly in different domains can be challenging and it is well known that some experience is required. We will therefore concentrate in the following explaining what is behind these algorithms and how different theoretical concepts are explored by them. Some understanding of the algorithms is absolutely necessary to avoid pitfalls in their application.

The first step for the application of ML methods is how to represent the data. We mentioned already some data structures of inputs as vectors or tensors. However, there are usually many different ways to represent a problem numerically. In the past it has been crucial to work out an appropriate highlevel data representation as summary statistics to keep the dimensionality of the model low. However, the recent progress in deep learning made it possible to treat this representation as part of the learning process. Representational learning has thus become an important part of machine learning.

Once the problem has been defined by representing the data and possible goals in an appropriate way, and once the appropriate ML algorithm has been chosen, it is then the main challenge to choose good parameters of the algorithms, such as the number of neurons or layers of neurons in neural networks, which kernel to use in support vector machines, how many training steps to take in gradient descent, or how many data to use for learning validation. We call these parameters of the algorithms the hyperparameters. Choosing the right hyperparameters is commonly a major question, and to make it clear that, there is no simple answer. Thinking about how to approach this question with appropriate experiments and to understand the options and possible approaches is thus a major part of machine learning applications. The point I want raise here is that learning about the algorithms rather than simply applying them is a direction worth taking.
