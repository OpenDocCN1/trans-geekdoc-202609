
the higher probability, given the input attribute. This **Bayesian decision point, $x^t$,** or dividing hyperplane in higher dimensions, is given by

$p(1|x^t) = p(0|x^t) \rightarrow x^t\mathbf{w}^T\mathbf{x}^t = 0.$ (7.42)

We have considered binary classification with linear decision boundaries as logistic regression, and we can also generalize this method to problems with non-linear decision boundaries by considering hypothesis functions with different functional forms. As already stressed earlier, neural networks are a common way to specify more complex functions.

## 7.4 Maximum a posteriori (MAP) and regularization with priors

Before moving to consider more multivariate models, this is a good opportunity to discuss regularization again within a Bayesian framework. Maximum likelihood estimation is the workhorse of supervised learning, though it is useful to put this into a wider context of probabilistic modeling. In the probabilistic sense, choosing parameters given data, should be based on a model of the parameters themselves,

$p(w|\mathbf{x}, y)$. (7.43)

Let us assume we can know this conditional distribution. For example, let us assume it looks like the 1-dimensional example shown in Fig. 7.4. If we know this distribution we can pick a parameter value that we like. For example, we could pick the value $w_1$, which is the most probable value given the specific data. This is called the **maximum a posteriori (MAP)**

$w^{MAP} = \text{argmax}_w p(w|\mathbf{x}, y)$. (7.44)

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_154_0.png)

**Fig. 7.4** Example of a possible probability distribution of a parameter $w$ given some data.

The main difficulty with MAP or using another procedure based on the distribution $p(w|\mathbf{x}, y)$ is that we do not know this distribution priori. Instead, our approach has been to formulate a probabilistic model in the form of a parameterized density function

$p(y|\mathbf{x}; w)$. (7.45)

We will now discuss the relation of these density functions. To start with, in the probabilistic model of Eqn 7.45, we assumed that the feature data are magically given, but we could also consider how we select data values in a randomized fashion so that we can again consider the more general case

```
p(y,\mathbf{x}) = p(y|\mathbf{w})p(\mathbf{x}|\mathbf{w})
```

Again, if we train the data uniformly, so that the marginal distribution over the features is just a constant,

```
p(y,\mathbf{x}) \propto p(y|\mathbf{w}).
```

Next, we can use Bayes theorem to relate the posterior $p(\mathbf{w}|\mathbf{x}, y)$ to the data model, namely

```
p(\mathbf{w}|\mathbf{x}, y) = \frac{p(y|\mathbf{w})p(\mathbf{w})}{\int_{\mathbf{w}' \in W} p(y,\mathbf{x}|\mathbf{w}')p(\mathbf{w}')d\mathbf{w}'}
```

where $W$ is the domain of the possible parameters. For this we should note that the denominator, which is called the partition function, does not depend on the parameters as we are integrating (summing) over all possible values. The most likely values for the parameters can be calculated without this term and are given by a maximum posteriori (MAP) estimate,

```
\mathbf{w}^{MAP} = \text{argmax}_{\mathbf{w}} p(\mathbf{x}, y|\mathbf{w}).
```

The name of the method shows that we modify our prior knowledge of parameters, is summarized as prior distribution $p(\mathbf{w})$ by combining this to measurements $(\mathbf{x}, y)$ from specific realizations of the parameters, which is given by the likelihood function $p(\mathbf{x}, y|\mathbf{w})$. The resulting posterior distribution should then be a better estimate of the probability of values for the parameters. The function $\text{argmax}_{x}(f(x))$ picks the argument $x$ for which the function $f(x)$ is maximal. The argument of the function is the set of parameters that is, in a Bayesian sense, the most likely value for the parameters, where of course, we now treat the probability as a function of the parameters (e.g., a likelihood function). For a uniform prior, $p(\mathbf{w}) = \text{const}$, we get

```
\mathbf{w}^{MAP} = \mathbf{w}^{MLE}
```

While a prior of the parameters has an early choice, this can give us a great insight into regularization from a probabilistic perspective. In section 5.4 we introduced $L^2$ regularization by introducing a bias in the parameters. In the probabilistic models we can do this very elegantly by providing a prior for the parameters that encapsulate the bias in choice of character as argued previously. For example, let us assume that the values of the parameters should more likely be small than large. More specifically, let's assume that we can write the MAP estimate (Eqn 7.49) as

```
\mathbf{w}^{MAP} = \text{argmax}_{\mathbf{w}} p(\mathbf{x}, y|\mathbf{w})\mathcal{N}(0, \sigma^2).
```

As usual, we maximize the logarithm of the corresponding likelihood functions instead, which leads to

![](img/2087e3fd78fc2bbc9ee0bfaab66e3bde_156_0.png)

**Fig. 7.5** Three distribution commonly used as priors for the parameters when learning with a maximum likelihood estimate.

```
$w^{MAP} = \text{argmax}_w \log(p(x, y|w)) + \alpha||w||^2,$ (7.52)
```

```
$\alpha = \log \frac{1}{2x^2}.$ (7.53)
```

Thus, we previously discussed $L^2$ regularization corresponds to a Gaussian prior on the weights. $L^1$ regularization corresponds to a prior of an isotropic Laplace distribution

```
$p(w) = \frac{1}{2b} \exp \left( -\frac{|w|}{b} \right),$ (7.54)
```

which is more peaked towards 0 as be seen by comparison of these distributions in Fig. 7.5. The $L^1$ regularization forces more weights towards 0 compared to the $L^2$ regularization. This is another example of how a probabilistic interpretation sheds some light on techniques that have been originally introduced heuristically. A simple summary of the three priors and their resulting equivalence between MLE and MAP is shown in the table on the right of the figure.

Finally, we have discussed the common quantities of MAP and MLE in machine learning, it is good to realize that learning methods only give a **point estimate**, a single answer for the most likely values of the parameters given a specific data set from which likelihood has to be estimated. A point estimate is used to make decisions about which actions to take. However, it is possible that other sets of parameter value might only have a smaller likelihood value, and it is therefore more prudent to consider other values. For example, looking again at the example in Fig. 7.4, another strategy might be to pick a weight value in a range where variations in this value would not change the probability considerably in some range, such as values around $w_0$.

Moreover, in a Bayesian sense, all choices should be taken into account with their corresponding likelihood. This is particularly true when estimating our confidence for an estimation. In a Bayesian sense, we need to combine all possible estimates with their likelihood. Thus, a limit of the estimation methods discussed earlier, which are dominating most of the current practices in machine learning, is that they do not take distribution of answers into account. Some people thus distinguish machine learning from more advanced probabilistic programming. While such probabilistic techniques can give us answer to much deeper questions, the machine learning methods discussed in this book with point estimates are commonly easier to apply to high-dimensional problems.

## 7.5 Bayes nets: multivariate causal modeling

### 7.5.1 Causal models

In the previously discussed probabilistic regression examples, we mainly consider models for one random variable, or at most two. We now consider complex models with many more factors described by random variables. Probability theory nicely generalizes to multiple random variables. Multivariate cases are simply described by a joint probability outlined in the review of probability theory.

An example from Sebastian Thrun of a model to diagnose when a car is not starting is shown in Fig. 7.6. This example is reasonably sized, although real-world problems would be even larger than this. This model considers fourteen random numbers to determine possible cases if the car does start ("car does not start" is not a random number as we are using this model when we already know that the car is not starting). Now let us simplify the model by only considering binary values. That is, the age of the battery would only be specified as new or old. The joined probability table for the 14 variables would then have $2^{14} - 1 = 16383$ entries. These parameters have to be estimated (learned) from examples using MAP or MLE.
