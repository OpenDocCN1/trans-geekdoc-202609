+   1. Set a minimum password length of 8 characters.

+   2. Set the password “Cisc0ena” for the privileged mode.

+   3. Configure the console ports and virtual access lines.

+   3.1. Set “Cisc0con” as the password for the console port and set the inactivity interval to 5 minutes.
