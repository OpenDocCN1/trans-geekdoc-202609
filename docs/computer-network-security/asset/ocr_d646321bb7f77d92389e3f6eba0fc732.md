# Web Access Policy Wizard

# Web Access Policy Rules

This wizard creates a default rule that allows all internal users access to the Internet. You can also create a default blocking rule.

Do you want the wizard to create a default rule that blocks access to potentially malicious URL categories?

+   - Yes, create a rule blocking the minimum recommended URL categories

+   - No, do not create the rule for me

You can edit the default blocking rule or create your own blocking rule on the next page of the wizard.

# Blocked Web Destinations

A rule "Blocked Web Destinations" will be created. You can define exceptions to the rule on the next page of this wizard.

Block access to these Web destinations:

+   - Games
+   - News
+   - Entertainment

To apply URL filtering to rules using URL categories or category sets, Forefront TMG queries the remotely hosted Microsoft Reputation Service. The full URL string is sent to the service, using a secure connection.
