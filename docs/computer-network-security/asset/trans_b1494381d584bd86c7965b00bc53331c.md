## CCNA安全简介

“CCNA安全”证书是一项考试，用于验证保障由思科基础设施组成的网络所需的知识和资格。

这使网络专业人员能够展示所需的技能，以开发安全基础设施、识别网络威胁和网络漏洞，并减轻这些威胁，从而维护数据和设备的完整性、机密性和可用性。

### 前提条件

1) 为了优化您从本书中获得的学习效果，强烈建议您查看以下认证所要求的目标：

- 思科CCENT；
- 思科CCNA路由与交换。

### 命令语法约定

2) 本书用于呈现命令语法的约定如下：

- 文本为**粗体**：表示命令或关键字；
- *斜体*：表示参数或用户变量；
- 竖线(|)：表示互斥的替代元素；
- 方括号([])：表示可选元素；
- 花括号({})：表示必选项；
- 方括号内的花括号([{}])：表示可选元素中的必选项。
