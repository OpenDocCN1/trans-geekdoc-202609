# How it works...

Step 1 is by now a very familiar model creation step. This is elaborated by the addition of a second variable in the formula, which is added using the + operator. This is therefore a simple additive model and more complicated formulas are needed if you are checking or want to model interactions between variables. The summary (expression) shows us that we have six genes, three treatments, and three replicas. The following summary (model_1) shows that there is a likely effect of Treatment on expression, though it's not clear what.
