# Using Markdown and Quarto for literate computation

A common task in bioinformatics is writing out our results to communicate them to colleagues or to have a good record in our laboratory books (electronic or otherwise). A key skill is to make the work as reproducible as possible so that we can rerun it ourselves when we need to revisit it or someone else needs to replicate the process. One popular way to solve this problem is to use literate programming techniques and executable notebooks that are a mixture of human-readable text, analytical code, and computational output rolled into a single document. In R, the Markdown extension of the Markdown syntax and the Quarto command-line tool (and R package) allow us to combine code and text in what we create output documents in a variety of formats. # How it works...

The Quarto system is based on the versatile and powerful Pandoc for converting different documents. One of its most useful features is the ability to translate between various markup languages, such as HTML and LaTeX, and Markdown and Microsoft Office, making it a valuable tool for writers, researchers, and developers. This means that if you have a document written in one format, you can easily convert it to another without having to manually reformat the entire document. Pandoc can also perform various transformations, such as adding footnotes, tables, and images, making it a great tool for formatting and preparing documents for publication. For example, if you need to prepare a report for submission to a journal, you can use Pandoc to convert your R Markdown to PDF or Word, add images, and format it according to the journal’s specifications. Formats are specified by options in YAML headers or configuration files rather than in the markup itself, so prepping a document to be rendered into multiple formats from the same source is simply a matter of setting the configuration correctly. In this recipe, we’ll look at how to do that, specifically for HTML, PDF, and Word document outputs.
