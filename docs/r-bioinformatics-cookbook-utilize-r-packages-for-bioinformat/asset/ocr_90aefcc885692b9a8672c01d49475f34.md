# How to do it...

The datapasta tool is implemented as an add-in for RStudio, so we begin by setting that up:

+   1. Use the RStudio **Tools | Addins | Browse Addins** menu and then **Keyboard Shortcuts**. You get to choose which combination you want to use for pasting.

+   2. Click the middle column next to the operations, as shown in the following screenshot, and press the keys you want to. The combination in *Figure 2.1* is a good choice:

![](bbox=[0.118, 0.259, 0.851, 0.755])

Figure 2.1 – Selecting key shortcuts

+   3. Get a web table—for example, go to this page on **Wikipedia**: `https://en.wikipedia.org/wiki/Tab-separated_values`—and copy the whole text-based example table using the browser's right-click **Copy** feature.
