# How it works...

In this simple recipe, we take advantage of ChatGPT's ability to predict documentation from defined code. This works well and plays to ChatGPT's statistical strengths as the documentation follows an extremely structured format that is quite predictable. In step 1, we simply ask for Roxygen2 format documentation since this is most widely used in R, and pass the function to be documented.

Step 2 shows the output from one run; we have a nicely formatted and clear description, and ChatGPT has created usage examples for the user. A nice time saver for us.

# There's more...

You can go one step further with this and ask ChatGPT to make the code more readable for humans with a prompt like this:

```
Tidy up the following R function for ease of human readability:
factorise_cols <- function(df, col_list) {
not_all_na <- function(x) any(!is.na(x))

for ( i in col_list) {
  df <- df %>% dplyr::mutate(!!(i)) := as.factor(!!(i)) )
}
df <- df %>%select_if(not_all_na)

```
