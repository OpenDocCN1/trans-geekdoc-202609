# How it works...

This recipe condenses the familiar creation of the task, learner, resampling strategy, and evaluation measure into step 1. The data are loaded and the objects are created, specifying a logistic regression class.log_reg learner and a three-fold cross-validation resampling (cv). The measure on which we assess the models is singular and specified by the mlr() function as classification accuracy (class.acc). All will be used repeatedly as we go through the different values of parameters for the logistic regression.

With the learner set up, we can examine to see what parameters could be optimized. We do that in step 2 by coercing the object to a data.table. The output (truncated a little) looks like this:

```
special_vals
## 1: dispersion
ParamUty NA NA Inf FALSE <list [0]>
## 2: epsilon
ParamDbl -Inf Inf Inf FALSE <list [0]>
## 3: etastart
ParamUty NA NA Inf FALSE <list [0]>
## 4: maxit ParamDbl -Inf Inf
```

We can see that the epsilon and maxit parameters are double numbers ParamDbl and can take values from +/- infinity. We will optimize these in the example.

In step 3, we use the package mlr3 to access tuning/optimization objects and functions set up the selected parameters in the learner using learner$param_sets$$set_values(), to which we pass the range of possible values we wish to store using to_tune() functions. This means the values here will be changed each run according to our chosen optimization scheme, which will be defined later.
