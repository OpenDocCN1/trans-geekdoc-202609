# How to do it...

We can cluster with the following code

+   1. Load the data and run a PCA:

```
```r
library(factoextra)
library(Biobase)
library(rbioinfcookbook)
expr_pca <- prcomp(exprs(modencodeely.eset), scale = TRUE,
center=TRUE)
fviz_screeplot(expr_pca)
```
```

+   2. Extract the principal components and estimate the optimal clusters:

```
```r
main_components <- expr_pca$rotation[, 1:3]
fviz_nbclust(main_components, kmeans, method = "wss")
```
```

+   3. Perform k-means clustering to visualize:

```
```r
kmean_clus <- kmeans(main_components, 5, nstart=25, iter.
max=1000)
fviz_cluster(kmean_clus, data = main_components,
  palette = RColorBrewer::brewer.pal(5, "Set2"),
  theme = theme_minimal(),
  main = "k-Means Sample Clustering"
```
```

This code gives us the clustering we want.

# How it works...

In step 1, we load libraries, including the rbioinfcookbook library that provides us with modencodeely.eset to work on. We use it in the Biobase function expr(), which extracts the expression measurements as a rectangular matrix and passes that to the prcomp() function, which performs PCA and returns a PCA object, expr_pca. We then plot the PCA with the factoextra function fviz_screeplot() and see the result in Figure 11:10.
