# Getting ready

We'll use a modified version of the PlantGrowth data, available in the rbioinfocookbook package. We'll also use dplyr.

# How to do it...

We proceed to the t-test by building a linear model and interpreting its outputs. Take the following steps:

+   1. Load the data and examine it:
```
library(rbioinfocookbook)
summary(plant_growth_two)
```

+   2. Build the linear model:
```
model_1 <- lm(weight - group, data = plant_growth_two)
summary(model_1)
```

+   3. Manually work out the group difference:
```
library(dplyr)
group_means <- plant_growth_two |>
group_by(group) |>
summarize(mean_wt = mean(weight))
```

group_means
difference_in_means <- group_means$mean_wt[1] - group_means$mean_wt[2]
difference_in_means

These few steps are all we need.

# How it works...

Step 1 clarifies to us that we have just two treatments in our data loaded from rbioinfocookbook. The summary() function shows that there are ten measurements in each. Note that the t-test can't be done on data with more than two groups. If you try to do this evaluation with data with more groups, the interpretation falls apart.
