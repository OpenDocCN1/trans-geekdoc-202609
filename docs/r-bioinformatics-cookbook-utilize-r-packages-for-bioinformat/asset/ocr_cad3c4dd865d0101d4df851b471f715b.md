# Clarifying label placement with ggrepel

Bioinformatics datasets often have thousands of data points. These can be genomic positions or genes within a genome, and as part of our data analysis, we will frequently want to label positions or genes so that the reader can identify them. A problem arises in that the labels easily overlap or clash in the plots. The ggrepel package provides geoms for ggplot2 that allows labels to be positioned more clearly, incorporating label layout algorithms and connecting lines intelligently. In this recipe, we'll look at the most important options for applying that to a genomics dataset.

# Getting ready

We will need the ggplot2 and ggrepel packages and the fission yeast gene expression dataset in the rbioinfcookbook data package. This data frame contains yeast gene IDs in one column, the log 2-fold change of gene expression for that, and the p-value from a statistical test.

# How to do it...

We can create a noisy plot as follows:

```
library(rbioinfcookbook)
library(ggplot2)
library(ggrepel)

set.seed(44)
fission_ge |>
dplyr::mutate(
  signif = dplyr::if_else(padj < 0.05, TRUE, FALSE),
  scaled_p = -log10(padj)
) |>
gplot() +
  geom_text_repel(aes(x = log2FoldChange, y = scaled_p, label = id),
  max.time = 60,
  point.padding = NA,
  arrow =
    length = unit(0.03, "npc"),
    type = "closed",
    ends = "last"),
```
