# Performing Quantitative RNA-seq

```
fvarLabels: gene
fvarMetadata: labelDescription
experimentData: use 'experimentData(object)'
Annotation:
```

+   Then, specify experiments of interest:

```
experiments_of_interest <- c("L1Larvae","L2Larvae")
columns_of_interest <- which (
phenoData(modencodefy.eset)[['stage']] %in%
experiments_of_interest
)
```

+   Form the grouping factor:

```
grouping <- droplelevels(
phenoData(modencodefy.eset)[[['stage'][columns_of_interest]]
)
```

+   Form the subset of count data:

```
counts_of_interest <- exprs(modencodefy.eset)[,columns_of_interest_]
```

+   Create the DGE object:

```
eset_dge <- edgeR::DGEList(
counts = counts_of_interest,
group = grouping
)
```

+   Perform differential expression analysis:

```
design <- model.matrix(~ grouping)
seset_dge <- edgeR::estimatedDisp(eset_dge, design)
fit <- edgeR::glmQLFit(eset_dge, design)
result <- edgeR::glmQLFTTest(fit, coef=2)
TopTags(result)
```
