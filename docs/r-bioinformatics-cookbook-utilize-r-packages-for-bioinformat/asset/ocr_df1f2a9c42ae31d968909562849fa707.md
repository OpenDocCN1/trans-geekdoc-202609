# Getting ready

For an analysis like this, we need alignments of sequence reads from a splice-aware aligner and annotation for the genome. The Bioconductor RNASeqData.HNRNPC.bam.chr14 package provides 8 BAM files from a TopHat2 alignment of paired-end Illumina data against the human genome (hg19), we TxDb.Hsapiens.UCSC.hg19.knownGene Bioconductor package carries annotations for the correct version of the genome. Analysis and plotting will be done with GSSeq package and DESSeq from Bioconductor.

Beware of step 4 - it takes a long time to run; about 1.5 hours per BAM file on my laptop (an M Mac). There are options to parallelize this in the package that the code will be using here defaults. If this takes too long for you, there is a precomputed version of this step's output in the rbioccookbook called package_sgfc.
