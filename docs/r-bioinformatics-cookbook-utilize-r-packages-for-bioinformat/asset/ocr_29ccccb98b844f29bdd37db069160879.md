# Using a linear model to compare the mean of two groups

Step 2 builds the model in the same manner that we saw in the Modeling data with a linear model recipe. The code is nearly identical, but the interpretation of the output is the key, so let's look at that:

```
## Call:
## lm(formula = weight ~ group, data = plant_growth_two)

## Residuals:
## Min 1Q Median 3Q Max
## -0.862 -0.410 -0.006 0.280 1.078

## Coefficients:
## Estimate Std. Error t Pr(>t|)
## (Intercept) 5.0320 0.1637 30.742 <2e-16 ***
## grouptrt2 0.4940 0.2315 2.134 0.0469 *

## Sigif. codes: 0 '****' '***' '**' '*' .001 '01 .05 .01 ' 1
## Residual standard error: 0.5176 on 18 degrees of freedom
## Multiple R-squared: 0.2019 Adjusted R-squared: 0.1576
## F-statistic: 4.554 on 1 and 18 DP, p-value: 0.04685
```

In this output, from the Coefficients: block, we can see that the difference between the two groups is 0.494, indicating that the mean of tr2 is half a gram greater than the mean of the ctrl. We also see that the Pr(>||) is 0.0469. We already know that the value Pr(>||) (or the p-value of the coefficient) tells us the probability that we would see the slope observed or greater in random samples if the difference were zero, so we can interpret this as the p-value of t-test. In case, if we see a value less than the typical cutoff of 0.05, indicating that the slope size would not happen by chance. Together, these suggest that the difference between the two groups is not likely to be zero, so can be interpreted as significant.

In step 3, we use a dplyr code to evaluate the difference between the two groups as a confirmation of the result:

```
## # A tibble: 2 x 2
## group mean_wt
## <fct> <dbl>
## # 1 ctrl 5.03
## # 2 trt2 5.53
```

The difference between ctrl and trt2 is -0.494, corresponding to the value of the coefficient observed in step 2.
