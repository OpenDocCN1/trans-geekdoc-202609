# Phylogenetic Analysis and Visualization

In step 3, the treespace () function from the package of the same name does an awful lot of analysis. It first runs pairwise comparisons of all trees in the input and carries out clustering using PCA. These are returned in a list object with a member, D, containing the pairwise distances for the trees and P, containing the PCA. The default distance metric, the Kendall-Colijn distance, is particularly suitable for rooted gene trees as we have here, the metric can be changed. The nf argument tells us how many principal components to retain. Our aim is plotting, and we won't need more than three.

We plot a distance matrix in step 4. This comes from comparisons$D and is done with the table. image () function. The nclass argument tells us how many levels of color to use. We get a plot like the one in Figure 9.7:
