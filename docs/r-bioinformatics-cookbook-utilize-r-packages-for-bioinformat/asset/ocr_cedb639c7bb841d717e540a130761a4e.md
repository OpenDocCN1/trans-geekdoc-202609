# Using ClusterProfiler for determining GO enrichment in clusters

Step 1 in such an analysis is to set up GO term definitions and accession mappings to their relevant

genes. In the real world, these annotations can come from lots of places, including Bioconductor annotation packages or downloads from model genome websites and BioMart. In our example, we have a straightforward annotation in a dataframe, mo_go, that contains gene IDs and their GOs. So, for clusterProfiler, step 1 uses and sets up termgene, which contains only the gene ID and GO term accession, and termname, which contains only the GO accession and the GO description. We also set up a list of unique genes ID to represent the entry. In step 2, we extract the list of genes and expression values to analyze with GO; in real analysis, this would likely come from your experiment directly.

Step 3 is where we get to perform the enrichment analysis; we carry out using the clusterProfiler function called enricher(), passing the data we prepared in step 1 and the gene IDs from the gene expression data. We get back a complicated enrichResult object, but we can view that nicely using the as.data.frame() function as in step 4.

With step 5, we can visualize the result; the dotplot() function gives a nice representation as in Figure 10.1, and clearly shows that calcium binding is enriched in these genes:
