# How it works...

In step 1, we create a GRanges object that describes the features of the genome you're interested in. The three functions create all information from different file types and return the necessary GRanges objects. In step 2, we make use of GFF and GFF text functions to create two GRanges: gr_from_gff and gr_from_txt. These are used in the subsetting. In step 3, we subset on feature attributes. The code finds the features of the gene type. Note the difference in syntax finding genes and features. The base columns in the GRanges object - namely seqnames, width, and start - all accessor functions that return vectors. Hence, we use that in the second part of the condition. All other columns - called metadata in GRanges parlance - can be accessed with the standard $ syntax, so we use that in the first part of the condition.

In step 4, we create a special minimal GRanges object. more could be added just by putting more values for regions in the manually specified vectors. Finally, in step 5, we use the findOverlaps () function to get the indices of features in the gr_from_gff object that overlap the manually created regions_of_interest_gr and use those to subset the larger gr_from_gff object.
