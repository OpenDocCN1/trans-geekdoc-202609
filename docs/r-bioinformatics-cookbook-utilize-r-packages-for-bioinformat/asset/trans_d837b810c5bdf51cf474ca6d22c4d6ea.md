
.Rproj 文件是在创建 R 项目时自动创建的特殊文件。该文件包含了关于项目的重要信息，例如工作目录、环境变量和其他设置。它还包含了项目中的 R 版本。这些信息存储在单个文件中，便于他人共享项目并共同进行工作。

使用 RStudio 和 R 项目的一个主要优势是，它可以让你轻松地组织和管理不同项目的文件和目录。当你创建一个 R 项目时，RStudio 会创建一个新目录，其中包含与项目相关的所有文件和目录。这允许用户保持文件整洁，并在不同项目之间轻松切换。此外，.Rproj 文件方便与他人共享项目并进行项目协作。

## 准备工作

对于本教程，我们需要安装一个版本的 R 和一个版本的 RStudio。需要 R 似乎显而易见，但我这样做是为了区分 R 和 RStudio。安装其中一个并不会安装另一个一个，因此你需要确保已从 https://www.r-project.org/ 安装了 R，并从 https://posit.co/products/open-source/rstudio/ 安装了 RStudio Desktop。此外，升级其中一个不会影响另一个，尽管同时升级两者是明智的。我们还将使用 `usethis` 包。

## 如何操作...

通过以下 RStudio 菜单选项进行设置：

- 1. 使用 RStudio 菜单创建一个新项目：
  - I. 从菜单栏选择 `File | New Project...`（见视图 1.1）。
  - II. 在弹出窗口中选择 `New Directory`（见图 1.2）。
  - III. 选择 `New Project`（见图 1.3）。
  - IV. 为你的顶层文件夹选择一个描述性的名称并输入到名称框中。
  - V. 通过勾选框创建一个 Git 仓库。
  - VI. 通过勾选选框使用 `renv`。
  - VII. 最后，勾选 `Open in the new session`。

- 2. 创建一些实用的目录。在新项目的控制台（Console）中输入以下内容：
  `sapply(c("R", "data", "analysis", "src"), dir.create)`

- 3. 在根目录下创建一个 `README.md` 文件来描述项目：
  ```
  usethis::use_readme_md()
  ```

## 工作原理...

在 *步骤 1* 中，我们使用 RStudio 在新目录中创建一个新项目。向导设置了我们所需的所有部分，包括用于跟踪项目的 `.Rproj` 文件，以及用于更自动化使用 Git 和 `renv` 的 `.gitignore`、`.Rprofile` 和 `renv` 文件夹。方框的正确选择可以见前面的图表。选择 **Use renv with this project** 意味着通过 `install.packages()` 或 `renv::install()` 安装的包将直接安装到该 `renv` 文件夹中，而不是 R 的中心库，因此我们在项目中使用的版本将是针对该项目的。`Opening in a new session` 意味着我们在内存中获得了一个新的 R 实例，而没有任何之前加载的缓存或现有对象的污染。

当新会话打开时，它将以项目文件夹为基础，因此所有路径都可以从这里开始引用。此外，每当我们关闭项目后想返回项目时，只需点击 `.Rproj` 文件，RStudio 会话就会在正确的项目文件夹中启动。

在 *步骤 2* 中，我们在控制台中中使用 R 创建了一些实用的目录：`R` 用于包含可重用函数的 R 源文件；`data` 用于存放我们分析处理的原始输入数据；`analysis` 用于 Rmarkdown 和其他分析类文档；`src` 用于项目也使用的非 R 语言脚本和其他内容。我们将它们每个命名为一个向量，并让 `sapply()` 在每个项目上运行 `dir.create` 函数。
