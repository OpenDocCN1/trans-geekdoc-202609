# Customizing plots with ggasy

One of the key aspects of customizing plots in ggplot2 is the theme () function, which allows users to customize elements of the plot' overall appearance. Customizing plots in ggplot2 can be a littleintuitive. Although the theme () is powerful, it does require the user to manually specify each element of the plot, such as axis labels, titles, colors, and shapes. The ggplot package, built on top of ggplot, aims to make plot customization more accessible by providing a simpler, more intuitive syntax for many common customization tasks. ggasy provides a set of simple wrapper functions around theme () that make important things a lot easier to remember. With this recipe, we'll look at customizing labels, legends, and axes in a plot created initially in ggplot2.

# Getting ready

We'll need the ggplot2, ggasy, and palmerpenguins packages.

# How to do it...

We can customize a plot as follows.

Make a base plot:

```
library(ggplot2)
library(ggasy)
library(palmerpenguins)
```

```
p <- penguins | 
dplyr::filter(!is.na(sex)) | |
ggplot() + 
  aes(x = species, y = bill_length_mm) + 
  geom_boxplot(aes(fill = sex),
               position = position_dodge(width = 0.75)) + 
  geom_dotplot(
    aes(fill = sex),
    binaxis = 'y',
    stackdir = 'center',
    method = "histodot",
    position = position_dodge(width = 0.75),
    alpha = 0.5,
    dotsize = .5
  ) +
  theme_minimal()
```
