# How to do it...

Predicting open reading frames in long reference sequences can be done by performing the following steps:

+   1. Load the libraries and input the genome:

```
library(Biostrings)
library(systemPipeR)

dna_object <- readDNASet(
fs::path_package("extdata",
  "arabidopsis.chloroplast.fa",
  package="rbioinfobook"
)
)
```

+   2. Predict the ORFs:

```
predicted_orfs <- predORF(dna_object, n = 'all', type = 'gr',
mode='ORF', strand = 'both', longest_disjoint = TRUE
predicted_orfs
```

+   3. Calculate the properties of the reference genome:

```
bases <- c("A", "C", "T", "G")nraw_seq_string <- strsplit(as.character(dna_object), "")

probs <- unlist(lapply(counts, function(base_count){signif(base_
count / seq_length, 2))})
```
