# There’s more...

It's possible to go the other way around, from some R object to a definition of that object using the dpasta () function, which can coerce frames, tibbles, and vectors into definitions. This is really useful for reproducible examples. This example shows how to actually build the object with code so that we don't have to share the file and everything is in one source document:

```
library(dpasta)
mtcars |>
dpasta ()
```

This shows how the dpasta package is a super-useful tool for turning objects from the web and within R code into.
