This shows how much of the variance in the data is captured by each principal component. The first three components capture over 70% of the variance. We can use these instead of the whole 150-column dataset, simplifying the process and speeding up the analysis greatly.

In *step 2*, we extract the main components by subsetting on the rotation slot of the `expr_pca` object extracting the first three columns. These correspond to the three components.
