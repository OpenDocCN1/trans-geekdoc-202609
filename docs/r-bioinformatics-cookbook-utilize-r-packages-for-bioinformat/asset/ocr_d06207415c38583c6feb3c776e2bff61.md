# Loading, Tidying, and Cleaning Data in the tidyverse

The dplyr package provides functions for manipulating and cleaning data, including a function called join() that can be used to join tables based on one or more common columns. The join function supports various types of joins, including inner, left, right, and full outer joins. In this recipe, we'll look at each of these joins works.

# Getting ready

We'll need the dplyr package and the rbioinfo cookbook package, which will give us a short gene dataset of 10 Mapnagorte oryza, and related annotation data of approximately 60,000 rows for the entire genome.

# How to do it...

The process will begin with loading a data frame from the data package. The mo_gene_exp, mo_go_acc, and mo_go_evidence objects are all available as data objects when you load the rbioinfocookbook library, so we don't have to load them from the file. You will see this behavior in our R tutorials. For our work, this mimics the situation where you will already gone through the process of loading in data from a file on disk or received a data frame from an upstream function.

The following will help us to join tables:

+   1. Load the data and add terms to genes:

```
library(rbioinfocookbook)
library(dplyr)
```

```
x <- left_join(mo_gene_exp, mo_terms, by = c('gene_id' = 'Gene
stable ID'))
```

+   2. Add accession numbers:

```
y <- right_join(mo_go_acc, x, by = c('Gene stable ID' = 'gene_
id' ))
```

+   3. Add evidence code:

```
z <- inner_join(y, mo_go_evidence, by = c('GO term accession' =\n'GO term evidence code\'))
```

+   4. Compare the direction of joins:

```
a <- right_join(x, mo_go_acc, by = c('gene_id' = 'Gene stable
ID') )
```
