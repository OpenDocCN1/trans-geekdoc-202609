Achieving this needs a bit of setup and custom functions. First, we define the bases we will use as a character vector. Then, we get a character vector of the original DNA sequence by splitting the as.character version of dna_object. We use this information to work out the proportions of each base in the input sequence by first counting the number of each base (resulting in counts), then dividing it by the sequence length, resulting in probs. In both steps, we use lapply() to loop over the vector bases and list counts and apply an anonymous function that uses these two variables to get lists of lists. unlist() is used on final to reduce it to a simple vector.

Once we have the setup done, we can build our longest_orf_in_random_genome() simulation function. This generates a random genome by sampling length characters from the bases with probabilities in probs. We use paste0() to make the vector into a single string and convert it into a DNAStringSet for the predORF() function. This time, we ask for only the longest ORF using N = 1 and return the length of that.

This will result in the following output:

+   ## GRanges with 11 ranges and 2 metadata columns:
| ranges strand | subject_id | inframeend |
| <Rle> | <IRanges> | <Rle> | <integer> | <numeric> |
| 1 chloroplast | 87692-93358 | + | 1 | 2 |
| 2 chloroplast | 72371-73897 | + | 2 | 2 |
| 3 chloroplast | 54937-56397 | + | 3 | 3 |
| 4 chloroplast | 51747-58541 | + | 1 | 1 |

Now, we can run the function, which we do 10 times using lapply() and the length, probs, and bases information we calculated previously. unlist() turns the result into a simple vector and extract the longest of the ORFs with max(). We can use subset on our original predicted_orfs object to keep the ORFs longer than the ones generated by change.

# There’s more...

Once you've got a set of ORFs you're happy with, you'll likely want to save them to a file. You can do that using getSeq() function in the BSgenome package, passing the original sequence object and the ranges, and then getting the result with same names before saving to a file with writeXSet(). The following code does:

```
extracted_orfs <- BSgenome::dna_object, orfs_to_keep)
names(extracted_orfs) <- paste0("orf", 1:length(orfs_to_keep))
writeStringSet(extracted_orfs, "saved_orfs.fa")
```

The results go into the saved_orfs.fa file, which you can change as your wish.
