# Working with lists in purr

Lists are incredibly useful data structures that allow you to store and organize various types of objects, as vectors, matrices, dataframes, and even other lists. Unlike vectors, matrices, or dataframes, lists can accommodate different data types and structures within a single object. This flexibility makes them a powerful tool for data manipulation and analysis in R.

As a result the purr package provides lots of functions for working with lists, and in this short recipe, we'll look at a few for summarizing, simplifying, and extracting data.

# Getting ready

We'll just need the purr package.

# How to do it...

We can manipulate lists in purr using the following functions:

+   1. Filter a list of elements:

```
set.seed(2345)
1 <- list(
  a = rnorm(10, mean = 1),
  b = rnorm(10, mean = 10),
  c = rnorm(10, mean = 20)
)

library(purrr)

keep(1, function(x) mean(x) >= 10)
keep(1, ~ mean(.x) >= 10)
detect_index(1, ~ mean(.x) >= 10)
every(1, ~ mean(.x) >= 10)
some(1, ~ mean(.x) >= 10)
```

+   2. Rework the list:

```
names <- c("ones", "tens", "twenties")
1 <- set_names(1, names)

short_l <- modify(1, function(x) x[1:3])ntranspose(short_l)
```

These are short and sweet steps to work with lists.
