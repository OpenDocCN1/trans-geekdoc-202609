## Setting up your machine for the compilation of source packages

The following are some further instructions for Apple Silicon machines.

- 4. Download and install the gfortran library in the macOS Terminal:

```
curl -LO https://mac.r-project.org/tools/gfortran-12.0.1-20220312-is-darwinwin20-arm64.tar.gz
```

```
sudo tar xvf gfortran-12.0.1-20220312-is-darwinwin20-arm64.tar.gz
-C /
```

```
sudo ln -sfn $(xrun --show-sdk-path) /opt/R/arm64/gfortran/SDK
```

- 5. Download and unpack OpenMP:

```
wget https://mac.r-project.org/openmp/openmp-12.0.1-darwin20-Release.tar.gz
sudo tar xvf openmp-12.0.1-darwin20-Release.tar.gz -C /
```

- 6. Update some local variables.

Add the following lines to "/Users/your_username/.R/Makevars", which you should create if it doesn't exist, and make sure you replace your_username with your username!

```
CPPFLAGS=-I/usr/local/include -Xclang -fopenmp
```

```
LDFLAGS+=-L/usr/local/lib -lomp
```

```
FC=/opt/R/arm64/gfortran/bin/gfortran -mtune=native

LIBS=-L/opt/R/arm64/gfortran/lib/aarch64-apple-darwin20.6.0/12.0.1 -L/opt/R/arm64/gfortran/lib -lgfortran -lemrt3 -lim
```

These configuration-heavy steps should be what you need to make your computer ready to compile packages. So for macOS it will be easier than Windows!

## How it works...

Step 1 is a Windows-specific step and it's the only step we need to get the full toolchain for Windows. We simply download and run an installer for the RTools package. Make note of the version of R that you are running and match the version of RTools to (see Figure 1.5 and Figure 1.6). You can see the R version in the console at the top of a new session or the Console in RStudio.

Step 2 is a general step for macOS machines. xcode-select installs a set of tools for development on macOS, and there's a good chance you already have it. If not, go ahead and install it as in Figure 1.7.

Step 3 is the first of the steps particular to machines with M1 or M2 Silicon processors. The Apple Silicon xcodechain lacks a Fortran compiler and some other libraries at the time of the writing, and we put them in. Here, we download, unpack, and link the compiler using sudo for root permissions.

Step 4 is similar in that we download and unpack OpenMP, and step 5 sets Bash that R will load from the Makevars script on startup so it uses the tools correctly.

## Using the renv package to create a project-specific set of packages

In the context of software development, an environment refers to a specific set of dependencies and software versions that is used to run a particular application or project. They are useful for avoiding conflicts between different projects that may require different versions of the same package, and ensuring that the application runs consistently across different development, test, and production environments. The renv R package is a dependency management tool for R projects.
