# How to do it...

We start creating these embeddings by preparing the data:

+   1. Load libraries and data:

```
library(palmerpenguin)
library(tidyr)
library(dplyr)
library(tibble)

penguins_filtered <- penguins |
drop_na(-year) |
select(-year) |
mutate(ID=row_number())

penguins_scaled <- penguins_filtered |
select(where(is.numeric)) |
column_to_rowenames("ID") |
scale() )
```

+   2. Define the parameter space and embedding function:

