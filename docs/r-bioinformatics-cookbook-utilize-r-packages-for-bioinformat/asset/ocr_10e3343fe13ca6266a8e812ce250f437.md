We next load a dataframe of IDs and gene expression values and prepare the sgene_list, which must be a named vector of all genes in which the names of the vector are the gene IDs and the values are a factor of '0' or '1' levels, indicating whether the gene is in the list of interest or not. In step 2, we create the topGO_data_object using the constructor. We pass new (the ontology we're interested in, the list of all genes, and a node size threshold that will analyze GO IDs with the minimum number of genes (in this case, 3). By step 3, we set all to ready to perform statistical tests. the runTest() function takes our input data and allows us to define the algorithm and test we want to use. Here we first use the elim method and the parent-child method, analyzing each with Fisher's exact.

In step 4, we combine the results of the tests into a single dataframe for analysis; note that it contains columns of p-values for both algorithms and they give different results.
