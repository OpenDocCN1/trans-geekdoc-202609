# How it works...

The recipe runs on a series of first lookups on the database, each time we receive a little more information to work with.

In step 1, after loading the biomaRt library, we get a list of marts available at the host URL. You can change the URL as needed. We get a dataframe of the available maps and use that information in step 2, which uses the useMart() function to create a connection to gamarene stored in garene_connection.

In step 3, we use the connection to retrieve the datasets available using the listDatasets() function, and we get a result like this:
