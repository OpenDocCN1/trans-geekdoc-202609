# There’s more...

If you need to get the full example file for this recipe, you can extract it from the rbioinfcookbook package like this:

```
qmd_path <- fs::path_path("extdata", "shiny.qmd",
package="rbioinfcookbook")
file.copy(qmd_path, 'somewhere/on/your/system/shiny.qmd')
```

So, you can easily see the structure of the document and hopefully save some typing.
