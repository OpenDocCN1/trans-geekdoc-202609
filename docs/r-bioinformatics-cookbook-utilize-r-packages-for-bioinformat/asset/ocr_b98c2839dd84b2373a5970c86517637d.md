# How it works...

The first part of this recipe is pretty familiar. In step 1, we load in the libraries and use Biostrings to load in our protein sequences. Note that our sequences in the seqs object are an instance of the XCString class. In step 2, we create a basic dot plot using the dotplot() function. The arguments are the sequences we want to plot. Note that we can't pass the XCString objects directly; we need to pass character vectors, so we coerce our sequences into that format with the as.character() function. Running this code gives us the dot plot in Figure 9.13:

In step 3, we elaborate on the basic dot plot by first changing the way a match is considered. With the size option, we state that we are looking at 7 residues at a time (instead of the default of 1), the wstep option tells the plotter to jump 5 residues at each step, and the nmatch option tells the plotter to mark a window as matching if four of the residues are identical.
