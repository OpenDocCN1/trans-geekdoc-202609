```r
# Convert named columns to factors
#
# code{factorise_cols} returns a copy of the passed data frame
# in which all
# explicitly named columns are converted to factors with \ncode{as.factor}
# All columns with only NA values are omitted.
#
# @param df data frame
# @param col_list vector of quoted column names
# @keywords internal
#
factorise_cols <- function(df, col_list) {
  not_all_na <- function(x) any(!is.na(x))

  for ( i in col_list) {
    df <- dplyr::mutate(!!(i)) := as.factor(!!(i))
  }
  df <- dplyr::select_if(not_all_na)
}
```

- Read the response:
This R code defines a function called `factorise_cols` that converts explicitly named columns of a data frame into factors using the `as.factor` function. The function takes two parameters:

- 1. `df`: This is the data frame that contains the columns to be converted.
- 2. `col_list`: This is a vector of quoted column names.

The function uses `not_all_na` to check if there are any non-NA values. Inside the loop, the variable `i` represents each element (column) of `col_list`. The `mutate` function uses `!!(i)` to convert the column to a factor. Finally, the `select_if` function is used to remove columns that contain only NA values.

- Ask for clarification on a tricky bit:
You said `!!(i)` syntax is used to unquote. Can you go into more depth?

Read the response:
Certainly! In the loop, the variable `i` represents each element of `col_list`. Within the `mutate` function, `i` needs to be unquoted and evaluated as an expression. This is because `mutate` expects column names to be provided as expressions. The `!!` operator is used to perform this unquoting. It is part of the tidy evaluation framework provided by `dplyr`. By wrapping `i` with `!!`, it instructs `mutate` to evaluate `i` as an expression, resulting in an unquoted column name.
