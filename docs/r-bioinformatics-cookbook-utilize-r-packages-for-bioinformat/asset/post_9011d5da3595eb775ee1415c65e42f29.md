
# How to do it...

We start creating these embeddings by preparing the data:

- 1. Load libraries and data:

```r
library(palmerpenguin)
library(tidyr)
library(dplyr)
library(tibble)

penguins_filtered <- penguins |
  drop_na(-year) |
  select(-year) |
  mutate(ID=row_number())

penguins_scaled <- penguins_filtered |
  select(where(is.numeric)) |
  column_to_rownames("ID") |
  scale()
```

- 2. Define the parameter space and embedding function:

```r
library(Rtsne)
space <- expand.grid(perp = seq(5, 50, by = 10), dim = 1:3)

tsne <- function(p, d) {
  tsn <- Rtsne(penguins_scaled, perplexity = p, dimensions = p)
  data.frame(
    SNE1 = tsn$Y[,1],
    SNE2 = tsn$Y[,2],
    perplexity = p,
    dimensions = d,
    species = penguins_filtered$species
  )
}

res <- purrr::map2(space$perp, space$dim, tsne) |>
  purrr::list_rbind()
```

- 3. Plot the results:

```r
library(ggplot2)
ggplot(res) +
  aes(SNE1, SNE2) +
  geom_point(aes(colour = species)) +
  facet_grid(perplexity ~ dimensions) +
  theme_minimal()
```

- 4. Repeat the whole thing with UMAP and specific parameters:

```r
library(umap)

space <- expand.grid(n_neighbours = c(5,25,50) , min_dist =
  c(0.01, 0.1, 0.5, 0.99))

do_umap <- function(n, m) {
  map <- umap(penguins_scaled, n_neighbours = n, min_dist = m)
  data.frame(
    UMAP1 = map$layout[,1],
    UMAP2 = map$layout[,2],
    n_neighbours = n,
    min_dist = m,
    species = penguins_filtered$species
  )
}

purr::map2(space$n_neighbours, space$min_dist, do_umap) |>
  purrr::list_rbind()

ggplot() +
  aes(UMAP1, UMAP2) +
  geom_point(aes(colour = species)) +
  facet_grid(n_neighbours ~ min_dist) +
  theme_minimal()
```

This code gives us two different plots of our data.

# How it works...

The first step is to make sure that we have cleaned and scaled the data, in step 1, we use a tidyverse style pipeline to remove NA (using drop_na()), remove the uninformative year column using select (-year), and add a new row-based ID column. We keep this with penguins_filtered in order to retain the species data we need. We go on to extract the numeric columns to a new dataframe, the ID column to the rownames attribute (so, really out of the actual dataframe), and then when we have numeric columns that we want to visualize, we can apply the scale () function to bring all the data into similar ranges and prevent the algorithm from giving one variable more weight than others.

In step 2, we start t-SNE by loading the library and preparing a data structure to hold the values of the parameter search space. The expand.grid() function returns a dataframe of all combinations of the vectors passed to, so we get a perp column (for perplexity) with values 5 to 50 in increments of 10 and a dim column (for dimension) with values 1 to 3. Next, we define a function that can conduct t-SNE using the passed perplexity and dimension parameters. The object is passed into a dataframe to record the parameters and results. After the function is defined, we run it on the search space using purr::map2, which will iterate over two equal-sized vectors—the two columns in space—and send their values to the named function, t-SNE. The resulting list of data frames is condensed into a single dataframe.

Step 3 is a standard ggplot2 plot of the data, showing in each facet the visualization for each combination of the two parameters we varied. We get a result like the one in Figure 11.8:

# Clustering with k-means and hierarchical clustering

It is common in bioinformatics to want to classify things into groups without first knowing what or how groups there may be. This process is usually known as clustering and is a type of unsupervised ML. This is commonly used in genomics experiments, particularly RNAseq and count-based technologies. In this recipe, we'll start with a large gene expression dataset with around 150 samples. We'll learn how to estimate how many groups of samples there are and apply a method to cluster them based on the reduction of dimensionality by PCA followed by a k-means cluster.

# Getting ready

We'll need the factextra, RColorBrewer, and Bioconductor biobiase libraries. We’ll also use the modencode_eset object from rbioinfcookbook package.

# How to do it...

We can cluster with the following code

- 1. Load the data and run a PCA:

```r
library(factoextra)
library(Biobase)
library(rbioinfcookbook)

expr_pca <- prcomp(modencode_eset, center = TRUE, scale = TRUE)
```

- 2. Extract the principal components and estimate the clusters:

```r
main_components <- expr_pca$rotation[, 1:3]
```

- 3. Perform k-means to visualize:

```r
kmean_clus <- kmeans(main_components, k = 5, nstart = 25, iter.max = 1000)
fviz_cluster(kmean_clus, data = main_components,
  palette = RColorBrewer::brewer.pal(5, "Set2"),
  theme = theme_minimal(),
  main = "Sample Clustering")
```

This code gives us the clustering.

# How it works...

In step 1, we load libraries including rbioinfcookbook that provides us with modencode_eset to work on. We use it in the prcomp() function which performs PCA and returns a PCA object. We then plot the PCA with the factoextra function fviz_screeplot() and see the result in Figure 11.10.

In *step 2*, we extract the main components by subsetting on the rotation slot of the expr_pca object the first three columns. These correspond to the three components. We save these in a variable called main_components and use the fviz_nbcluster() function on it and the kmeans() function to create the following diagram:

In this function, the data are divided into increasing numbers of clusters and the Within Sum of Squares (wss) is computed—this being a measure of the variability within each cluster. It decreases greatly up about five clusters, after which it levels off and no much improvement is seen. This indicates that the data contains about five clusters.

In step 3, we perform a k-means clustering using the kmeans () function, providing main_components as the data for the max argument and setting the number of clusters to five. The values of nstart and iter.max arguments are reasonable options for most runs of the algorithm. We pass the kmeans_clust result object to fviz_cluster () and set some display options.
