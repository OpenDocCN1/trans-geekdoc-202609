In this recipe, we will use the external **tmhmmer** and **pureseqTM** programs to find transmembrane domain candidates.

# Getting ready

We'll be using the "richelbildebeek/tmhmmer" and "richelbildebeek/pureseqtm" GitHub hosted packages. These have some custom install steps, we will do the installation as part of this recipe. These programs will currently work only on a Linux machine. Linux machines are common in bioinformatics but you might not be working on one as your computer. If you don't have easy access to a Linux machine, then you can use a Google Colab notebook as an alternative. Look at the *See also* section of this recipe to learn how to do.

The tmhmmer program has a specialist license. You can only get that by going to the software authors at `https://services.healthtech.dtu.dk/service.php?TMHMM-2.0.` They'll send you a URL from which to download the software. You can use that in this recipe to let the package download and install the actual tool.

The example data for this recipe comes from a file of Receptor-like Kinase (RLK) proteins in a file provided in the rbioinfo own

# How to do it...

We can find transmembrane domains with tmhmmer and pureseqTM as follows:

+   1. Install tmhmmer:
```
my_url <- "whatever_the_url_you_get_is"
library(tmhmmer)
install_tmhmmer(my_url)
```

+   2. Run a protein FASTA file through tmhmmer:
```
fasta_file <- fs::path_package(
  "extdata",
  "rlk_proteins.fa",
  package = "rbioinfocookbook"
)

tmmer_predictions <- tmhmmer::predict_topology(fasta_filename)
```
