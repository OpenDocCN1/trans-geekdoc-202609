# Interpreting complicated code with ChatGPT assistance

> To illustrate with an example

This unquoting operation is necessary in this context because the `mutate` function expects column names to be provided so that it can perform the necessary data manipulation operations. The `!!` operator allows us to unquote within the `mutate` function.

Note that the response from ChatGPT will be somewhat different depending on context and you may not get exactly what was generated. That is the nature of the thing, but you could get something with the same meaning.

# How it works...

The code in this example comes from a package called beshr that creates estimation statistic plots for visual scoring data. The tool must take in arbitrary column names and work within the tidy %>%, so it uses some advanced coding techniques to that to happen. We first go and get the code from the repository on GitHub (https://github.com/TeamMacLean/beshr/blob/master/R/functions.R) and paste that into ChatGPT’s prompt box asking it for an explanation.

In *step 2*, we can see the explanation provided (note that the one you get if you try may be different as the model is not guaranteed to reproduce its predictions). The detail is largely correct; certainly, it is sufficient to give us a clear idea of what the code attempts to do and how it does it.

Some parts of the explanation aren’t clear, in *step 3*, we ask for clarification of a tricky bit, again by typing into the prompt box. And in *step 4*, we see a more in-depth description of that part.

In this way, we can get a clear and readable, plain English description of the job done by a particular piece of code very quickly.
