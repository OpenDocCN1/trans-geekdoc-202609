Step 2 shows us the suffixed forms of the map ( ) function. This work as map ( ) but force a particular return type. The map_dbl ( ) ensures a double number is returned:

```
## small_nums big_nums
## 2 200
```

map_chr ( ) ensures character data is returned:

```
## small_nums big_nums
## "2.000000" "200.000000"
```

Note that the third example, map_lgl ( ), tries to return logical (TRUE/FALSE) values, but will fail on the log funciones expected, since can't logically be co-erced.

Suffixed versions of map2 ( ) and pmap ( ) also exist.
Step 3 finishes this recipe by using some other map ( ) functions. The map_dfc ( ) applies the log funciones expected, but instead of returning a list, it returns a dataframe of bound columns (hence_dfc):

```
## small_nums big_nums
## <dbl> <dbl>
## 1 0 4.61
## 2 0.693 5.30
## 3 1.10 5.70
```

A function called map_dfr ( ) for row binding exists.
Finally, we use walk ( ), which iterates over the dataframe, but does nothing to it. It returns the input completely unchanged. The usefulness, though, is in that it allows us to carry out a side-effect action (such as writing to file or printing to screen) for each element without messing up the data.
