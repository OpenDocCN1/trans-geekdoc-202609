# How to do it...

Let's look at the ordinal case first, considering how to build a data frame to ensure R knows about
t order in the data:

+   Set the type of values explicitly:

```
library(rbioinfook)
library(dplyr)

scores <- disease_scores | transmute(
strain = as.factor(strain),
replicate = as.factor(replicate)
score = as.factor(score)
)
```

+   Set the ordering and rank the scores:

```
scores <- scores | transmute(
score = factor(score, levels = c("1","2","3","4"), ordered =
TRUE),
rank_score = rank(score),
strain, replicate
)
```

+   Model and count ANOVA on the ranked scores:

```
model <- lm(rank_score, data = strain = scores)
library(multcomp)
summary(glht)
model, linfect = mcp(strain = "Tukey")
)
```

+   Load in the nominal side effects data and tabulate and perform a proportion test:

```
library(rcomppanion)
tabulated <- xtabs(frequency - treatment + side_effect, data =
side_effects)

tabulated
pairwiseNominalIndependence(tabulated, method = "fdr")
```
