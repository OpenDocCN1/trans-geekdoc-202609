# How to do it...

Performing a logistic regression and optimizing it using tuner objects can be done as follows:

+   Set up the task, learner, and resampler:

```
library (mlr3)
library (mlbench)
library (mlr3learners)
data ("BreastCancer")

selected <- BreastCancer[c("Cl.thickness","Cell.size","Cell.
shape","Marg. adhesion","Epith.c.size","Bl.chromatin","Normal
nucleoli","Mitoses","Class\)]

task <- as_task_classify(selected, target="Class")
learner <- lrn("class.log_reg")
resamp_kcv <- rsmp("cv")
resamp_kcv$param_setValues = list(folds = 3)
measure <- msr("class.acc")
```

+   Inspect the parameters we can optimize:

```
as.data.table(learner$param_set)
```

+   Set dynamic limits on parameters:

```
library(mlr3tuning)
learner$param_set$set_values(epsilon = to_tune(0, 10),
maxit = to_tune(1, 10) )
```

+   Decide how the optimization task should terminate:

```
terminate <- trm("run_time", secs = 5)
```

+   Compile the input into a tuning object:

```
tunit <- ti(
task = task,
learner = learner,
resampling = resamp_kcv,
measures = measure,
terminator = terminate
)
```
