# How it works..

In step 1, we load the necessary libraries. The ComplexHeatmap library is used to generate complex heatmaps, viridisLite is used for color scales, stringr is used for text manipulation, RColorBrewer is used for generating palettes of colors for the heatmaps, circize is used for circular visualization, and rbioinfoctbook is this book's package for the data we need.

The at_tf_dex dataset is a DataFrame and is created from it by log-transforming a subset of that dataset - specifically, the columns 5 to 55 - as, matrix(at_tf_dex[, 5:55]). This step is done to scale the data and make it visually interpretable.

Then, theocyte and part of the samples are extracted by splitting the column names of the matrix using the stringr::str_split function, where in ecotype, the split is by , and in part, the split is by ' ' (note the space in the pattern in the one - this is a quick way of removing fiddly leading space in the match). The str_split() function takes three arguments: the string you want to split, the delimiter by which you want to split the string, and whether you want the output to be simplified or not. The simplify=TRUE argument tells the function to return a vector, where the string is split at every occurrence of the delimited delimiter, rather than returning a list of vectors.
