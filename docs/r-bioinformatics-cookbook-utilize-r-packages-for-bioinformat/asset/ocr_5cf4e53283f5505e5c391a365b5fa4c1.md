# Doing tests for differences in data in two categorical variables

proportion tests. First, we must mutate the input data frame using xtabs (), which takes a formula syntax input for collapsing the data. It looks like this:

```
## side_effect
## headache nausea none
## regime_a 30 110 100
## regime_b 32 120 70
## regime_c 30 142 0
```

Then, we pass the tabulated object to the pairwiseNominalIndependence () function, which will carry out a range of tests. The "fix" option tells it which method to use to adjust the p-value. The results show that regime_a and regime_b don't show any differences in their side effects (at adj.p < 0.05) that regime_c differs from the others:

```
## Comparison p.Fisher p.adj.Fisher p.Gtest p.adj.Gtest p.Chisq p.adj.Chisq
## regime_a : regime_b 7.81e-02 7.81e-02 0.0773 0.0773 7.81e-02
## regime_a : regime_c 1.66e-28 4.98-28 0.0000 0.0000 1.89e-02 5.67e-21
## regime_b : regime_c 5.26e-20 7.89e-02 0.0000 0.0000 3.38e-15 5.07e-15
```
