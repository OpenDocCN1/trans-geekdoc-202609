
# How to do it...

We can look at the changes in distributions using the following steps:

- 1. Plot overlapping distributions:

```r
library(ggplot2)
library(ggridges)
library(palmerpenguins)

gplot(data = penguins) +
  aes(x = bill_length_mm, y = species,
      fill = species,
      color = species) +
  geom_density_ridges(scale = 2,
      position = "raincloud",
      alpha = 0.5,
      jittered_points = TRUE
  ) +
theme_ridges()
```

- 2. Color the peaks with a gradient:

```r
gplot(data = penguins) +
  aes(x = bill_length_mm, y = species),
      fill = stat(x)
) +
geom_density_ridges_gradient(scale = 2,
      rel_min_height = 0.01,
) +
theme_ridges()
```

- 3. Add in quantile markers:

```r
gplot(data = penguins) +
  aes(x = bill_length_mm, y = species),
      fill = factor(stat(quantile))
) +
stat_density_ridges(
  geom = "density_ridges_gradient",
  calc_ecdf = TRUE,
  quantiles = c(0.05, 0.95)
) +
scale_fill_manual(
  name = "Probability",
  values = alpha(c("goldenrod", "gray",
"steelblue"), 0.05,
  labels = c("< 0.05", "0.05 to 0.95", " > 0.95 ")
) +
theme_ridges()
```

This is all we need to have a nice showing differences in the distributions.

# How it works...

In step 1, we create a basic ridge plot. It's constructed as extra geoms for ggplot2, so we build a standard ggplot plot description and add the geom to that. The penguins plot is set up to have each distribution of bill length against the species and the geom_density_ridges geom used to draw the ridge plot. The position and jittered_points parameters add on to the scatter point visualization of the actual points underneath the curve. The scale parameter affects the amount of overlap. See Figure 3.4:

# Customizing plots with ggasy

One of the key aspects of customizing plots in ggplot2 is the theme () function, which allows users to customize elements of the plot's overall appearance. Customizing plots in ggplot2 can be a little intuitive. Although the theme () is powerful, it does require the user to manually specify each element of the plot, such as axis labels, titles, colors, and shapes. The ggplot package, built on top of ggplot, aims to make plot customization more accessible by providing a simpler, more intuitive syntax for many common customization tasks. ggasy provides a set of simple wrapper functions around theme () that make important things a lot easier to remember. With this recipe, we'll look at customizing labels, legends, and axes in a plot created initially in ggplot2.

# Getting ready

We'll need the ggplot2, ggasy, and palmerpenguins packages.

# How to do it...

We can customize a plot as follows.

Make a base plot:

```r
library(ggplot2)
library(ggasy)
library(palmerpenguins)
```

```r
p <- penguins | 
dplyr::filter(!is.na(sex)) |
ggplot() + 
  aes(x = species, y = bill_length_mm) + 
  geom_boxplot(aes(fill = sex),
               position = position_dodge(width = 0.75)) + 
  geom_dotplot(
    aes(fill = sex),
    binaxis = 'y',
    binwidth = 0.1,
    position = position_dodge(width = 0.75),
    alpha = 0.5
  )
```

Customize its appearance

```r
p +
  theme_minimal() +
  theme(
    legend.position = "bottom",
    plot.title = element_text(face = "bold", size = 14),
    axis.title = element_text(size = 12)
  )
```

# Customizing plots with ggasy

```r
p +
  theme_classic() +
  labs(
    title = "Penguin Bill Length by Species",
    subtitle = "Data from the penguins dataset",
    x = "Bill Length (mm)",
    y = "Species"
  ) +
  theme(
    legend.position = "right",
    panel.grid.major = element_blank()
  )
```
