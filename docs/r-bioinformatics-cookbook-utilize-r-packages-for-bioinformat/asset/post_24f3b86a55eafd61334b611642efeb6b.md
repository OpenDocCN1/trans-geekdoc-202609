
# Finding Genetic Variants with HTS Data

```r
IRanges(c(40700), width = c(1500) )
\overlap_hits <- findOverlaps(region_of_interest, se)
data_in_region <- se[subjectHits(overlap_hits)]
assay(data_in_region)
```

This is all we need to estimate the copy number.

# How it works...

In step 1, we use the csaw package to get read counts in 100 bp windows over our small section of human chromosome 17. The read filtering options are in the param argument. In step 2, we extract the first and only column of data to give us a simple vector of the counts using the assay() function and subsetting. Next, in step 3, we use the quantile() function to get the min_count value in the lower 10th percentile of counts vector. The double-bracket subsetting is needed to get a single number from the named vector that the quantile() function returns. The min_count value is a cut-off. All values in counts vector lower than this are set to NA to remove them from the analysis - this acts as a low coverage threshold and the percentile used can be modified in your adaptations of the recipe as needed.

In step 4, we add some regions with doubled coverage so that we can detect them. We select several windows to double and then create a multiplier of equal length that contains 1 where we want to change counts and 2 where we want them. We apply the multiplication. Step 4 will not likely be in your analysis as it is a synthetic data generation step.

In step 5, we compute the background coverage level. Here our function is a simple mean that is saved in mean_cov, but you can use many other summary functions. We also calculate log2() of the ratio of each window count to the global mean_cov and save it in a one-column matrix called ratio since we need the result to a matrix in our final SummarizedExperiment object. We quickly use plot and can see the count of doubled windows in the middle of the data.

# See also

The calculation for the background level in this recipe is really simple – which is great for learning the recipe, but it might be quite underpowered in your real data. There are numerous options you could take to modify the way you calculate the background level for your data. Check out the rollmeans() and rollmedians() functions in the zoo package. These can give you the mean or median in rolling windows of arbitrary step length and give you a moving window background average that may be more appropriate. A related analysis to copy number is the estimation of ploidy from SNP allele frequencies. You can check out the vocR package's freq_peaks() function as a starting point to estimate ploidy from variant information in BAM files.

# #8 Searching Gene and Protein Sequences for Domains and Motifs

The sequences of genes, proteins, and entire genomes hold clues to their function. Repeated subsequences or sequences with strong similarities to each other can be clues to things such as evolutionary conservation or functional relatedness. Sequence analysis for motifs and domains is a core technique in bioinformatics. Bioconductor contains many packages for analyzing genes, proteins, and genomes. In this chapter, you will learn how to use Bioconductor to analyze sequences for features of functional interest, such as de novo DNA motifs and known domains from widely used databases. You'll learn about some packages for kernel-based machine learning to find protein sequence features. You will also learn about large-scale alignment techniques for many sequences or very long sequences. You will use Bioconductor and other statistical learning packages.

In this chapter, we will cover the following recipes:

- * Finding DNA motifs with universalmotif
- * Finding domains with PFAM and db3D
- * Finding InterPro
- * Finding transmembrane domains with HMMER
- Creating features of proteins
- Performing multiple alignments
- Aligning genomic sequences
- Novel feature detection in proteins

# Finding DNA motifs with universalmotif

A very common task when working with DNA sequences is finding instances of motifs – a short sequence – within a longer sequence. These could represent protein-DNA binding sites as transcription factor binding sites in a gene promoter or enhancer region. There are two starting points for this analysis – you either have a database of motifs that you want to scan target DNA sequences and extract wherever the motif occurs or you just have the sequences of interest and you want to find out whether there are any repeating motifs in there. We'll look at ways of doing both of these things in this recipe.
