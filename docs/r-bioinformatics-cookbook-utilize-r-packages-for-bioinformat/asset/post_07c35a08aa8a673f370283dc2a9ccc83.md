# How it works...

In this recipe, we saw two ways of estimating differential expression with edgeR. In the first half of this recipe, we use edgeR to load data from a count table, and in the second, we did the same analysis from an ExpressionSet object. Let's break them down in detail.

# Using edgeR from a count table

- Step 1 uses the rbiocbook library, which is required to access the count_dataframe object. The count_dataframe object is modified by extracting the gene column and storing it in a separate object called genes, and removing the gene column from count_dataframe. The modified count_dataframe object is converted into a matrix using the as.matrix() function and the resulting matrix is stored in an object called count_matrix. The rows of count_matrix are set to the values in the genes object using the rownames() function.

- Step 2 creates an object experiments_of_interest that contains the L3Var and L2LVar character strings. Another object called columns_of_interest is created by using the which() function to identify the columns in pheno_data, where the 'stage' column is equal to one of the experiments.

- Step 3 creates a grouping factor called grouping using the forcats::as_factor() function from the forcats package. The grouping factor is created by extracting the 'stage' column from pheno_data and converting it into a factor. We index which refers to a column in the counts table. In the example, the three columns in the data would be results of a different sample, and so on. We can use any symbols in the grouping vector to represent the groups. The more complicated the grouping vector, the more complicated experiment design can be. In our recipe, we use a simple test/control design, like this:

# Performing Quantitative RNA-seq

A simple vector like this does, but you can also use the factor object - R's categorical data type. Factors are vectors of integers under the hood but they have associated name labels called levels. These are used instead of numbers to give you a prettier read out the factor. The factor object retains all levels it knows, even when a subset is taken without all levels, which sometimes results in empty levels.

- Step 4 creates a subset of the count_matrix object called counts_of_interest that includes only the columns produced by the columns_of_interest object.

- Step 5 loads the edgeR library and then a DEGList object called count_dge using the DEGList() function. The counts of _interest object and the grouping factor are passed as arguments to DEGList().

- Step 6 performs differential expression analysis on the count_dge object using a series of functions from the edgeR package. We first create the experimental design descriptor object with the matrix() function using the grouping variable. The estimateDisp() function is used to estimate the dispersion parameter of the count data, the glmQLFit() function is used to fit a generalized linear model to the data, and the glmQLTest() function is used to perform a likelihood ratio test to identify differentially expressed genes. The resulting object is stored in an object called result. Finally, the topTags() function is used to display the top differentially expressed genes. The columns show the name, the F value, the P value, and the false detection rate (FDR), which is usually the column from which we make statistical conclusions.
