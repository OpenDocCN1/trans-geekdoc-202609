# How it works...

The key to this approach is finding out whether the database're trying to use carries the domain
information. That what happens in step 1 – we use the keytypes () function to list the search
available and we can see PFAM in the results. Once we've verified that we can use this database for
the information we want, we can follow a fairly standard procedure from step 2. In step 2, we have a
list of keys to query – like gene names. We pull them from the database directly, but they could
come from anywhere. In step 3, we query the database with the select ( ) function to pull data for
given keys. The columns argue it that data to pull. In step 4, we make a list of PFAM
IDs and descriptions. We load the PFAM.db package and use the PFAMDE object it to get
mapping between IDs and descriptions. This will result in the following output:

```
##
## 1 ENSG00000121410 PF13895
## 2 ENSG00000175899 PF02027
## 3 ENSG00000175899 PF17789
## 4 ENSG00000175899 PF07677
## 5 ENSG00000175899 PF17791
## 6 ENSG00000175899 PF01835
## 7 ENSG00000175899 PF07703
## 8 ENSG00000175899 PF07678
```

We can then get the actual descriptions with mappedkeys () in step 5, and extract and convert
the descriptions of all the IDs into a DataFrame in step 6. Finally, we join the conversions of the
domains to the IDs by using the columns that contain common data (PFAM and ac), resulting in
t following output:

```
##
## 1 ENSG00000121410
PF13895

## 2 ENSG00000175899 PF02027

domain MG4

A-macroglobulin receptor binding domain

Macroglobulin domain MG3
```

This is a DataFrame with the gene ID and the PFAM attached.
