# Plotting variability and confidence intervals better with ggdist

Together, these steps show us how to make highlighted plots.

Confidence intervals are used to make inferences about a population based on a sample of data. They capture the variability of the data by providing a range of possible values for some parameter, rather than a single point estimate. The interval is a measure of how sure we are that the interval contains the true population parameter. It is common to share distributions and annotate them with range markers or confidence intervals. With this recipe, we will look at how to use ggplot::ggdist extension to make informative and great-looking plots of distributions.

# Getting ready

For this recipe, we need the ggdist, ggplot2, and palmerpenguins packages.

# How to do it...

We can create plots with confidence intervals as follows:

- 1. Create a raincloud plot:

```
library(ggplot2)
library(ggdist)
library(palmerpenguins)

ggplot(penguins) +
aes(x = flipper_length_mm, y = island) +
geom_dots(side = "bottomleft", aes(colour = island)) +
stat_slabinterval(aes(fill = island)) +
theme_minimal()
```

- 2. Delimit arbitrary regions in a curve:

```
ggplot(penguins) +
aes(x = flipper_length_mm, y = island) +
stat_halfeye(aes(fill=(x > 190 & x < 200))) + 
geom_vline(xintercept = c(190, 200), linetype = "dashed") +
scale_fill_manual(values = c("gray", "steelblue")) +
theme_minimal()
```

- 3. Create a gradient plot:

```
ggplot(penguins) +
  aes(x = flipper_length_mm, y = island) +
  stat_gradientinterval(aes(colour=island, fill=island)) +
  theme_minimal ()
```

And that is all we need to make plots with representations of variability.

# How it works...

Step 1 shows how to create a raincloud plot, as seen in Figure 3.11. We set up the data and aesthetic layer in ggplot as usual, adding the geom_dots () function from ggdist, which will add a layer of dots representing each data point to the plot. We use the side parameter to put the dots underneath the line "bottomleft". The density plot and the range markers in black are added with a stat layer, not a geom layer, and range and point markers in black need to be calculated from the data before plotting—stat_slabinterval () does this for us. Note that 'slabs' is ggdist's naming convention for distribution glyphs:

We also use the geom_vline() function to add a dashed-line to further demarcate the regions across the y axis. The last part of this step adds a custom palette:

# Making interactive plots with plotly

Interactive plots are great tools for data exploration, allowing users to explore interactively large datasets to gain insights and identify patterns in data. They are useful for programmers wishing to create dashboards for visualizing real-time data and help with interactive presentations that communicate complex data relationships in an engaging manner. plotly is a data visualization library for Python, R, and JavaScript. It provides a high-level interface for drawing attractive and interactive statistical graphics, and the ggplot package in R allows you to convert static ggplot2 to interactive plots through a high-level interface. In this recipe, we'll create a fairly involved ggplot visualization of mutation sites on a genome and then convert it to plotly to get a first-level interaction layer.

# Getting ready

We'll need the ggplot2, plotly, and rbioinfbook packages for this recipe. The allele_freq data object is a frame of allele frequencies of single nucleotide polymorphisms (SNPs) from genomic sequencing of a bulked population. The columns give the genomic positions and effect of mutation in the genome.

# How to do it...

The steps we need to create an interactive plot are set out as follows:

- 1. Create a ggplot:

```
library(ggplot2)
library(plotly)
library(rbioinfbook)

p <- ggplot(allele_freq) +
  aes(x = Pos, y = Allele_Freq, label = info) +
  geom_point(aes(color = type)) +
  facet_grid(Chr ~, scales = "free", space = "free") +
  scale_color_manual(values = c("steelblue", "gray", "goldenrod", "red")) +
  theme_minimal()
```

- 2. Convert to plotly:

```
ggplot(p, dynamicTicks = TRUE,
  dragmode = "zoom",
  tooltip = c("Chr", "Pos", "info"))
```

# How it works...

Step 1 creates a plot using the data, the allele frequency on the y axis and the position of the SNP on the x axis. Note that the aes() function also carries a mapping for the label attribute to the info column; plotly only knows about stuff that is built into the ggplot object, so it needs to have a mapping in this stage. The plot is faced such that each chromosome gets its own face, with scales changing to match them. The point color is set to the type column, with the most likely mutations being those that are non-synonymous, in a coding region, and with a CT/GA transition, those are colored red. Together, this specification creates a plot of SNP density across the genome.

When the plot is created, we can go ahead and convert it to plotly to be able with it, which we do with ggplot(). Setting the dynamicTicks argument allows the scales to redraw when zooming: dragmode allows us to use a drag-box zoom, and tooltip sets the order of the label items in the on-hover tooltip when a point is selected. Rendering the plot through this function also creates a menu that allows, among other things, resetting the view, highlighting tracks by clicking on the legend, and exporting the current view to a PNG file.
