# Differential peak analysis

Extract the data and annotate the rows:

```
counts <- assay(arab_infection.rse)

if ( ! is.null(names(rowRanges(arab_infection.rse))) ) {
    rownames(counts) <- rowRanges(arab_se)
} else {
    rownames(counts) <- make_tag(rowRanges(arab_infection.rse))
}
```

Two steps are needed here, but they're very powerful.

# How it works...

In step 1, two R libraries, rbioinfcookbook and SummarizedExperiment, are loaded. The rbioinfcookbook provides the dataset we need, the SummarizedExperiment package provides a container for storing the results of an experiment, with the reads that we align to a genome.

Additionally, a function named made_tag is defined. This function takes in an object of the Ranges class, which is a container for genomic ranges and annotations, and creates a tag by concatenating the sequence name, the start position, and the end position of the range. This function will be used later to create tags for the rows of a DataFrame.

In step 2, the assay() is used to extract the data of the arab_infection.rse object, which is saved to the variables. The if statement checks if rowRanges(arab_infection.rse) contains names. If true, it assigns the names to the rows of DataFrame using names(rowRanges(arab_infection.rse)); otherwise, it assigns rows to the counts DataFrame using the make_tag function on rowRanges(arab_infection.rse).
