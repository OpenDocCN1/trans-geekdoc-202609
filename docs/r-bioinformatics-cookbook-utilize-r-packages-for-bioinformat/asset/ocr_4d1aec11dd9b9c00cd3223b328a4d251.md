# Retrieving and working with SNPs

SNPs and other polymorphisms are important genomic features and we of the want want to retrieve SNPs in particular genomic regions. In this recipe, we will look at that in two different BioArts that hold different types of data. In the first part, we’ll use gramene to look retrieving plant SNPs. In the second part, we’ll look at how to find information on human SNPs in the Ensembl database.

# Getting ready

As before, we’ll only need the biomaRt package from Bioconductor and a working internet connection.

# How to do it...

Retrieving and working with SNPs can be done using the following steps:

+   1. Get the list of attributes, and filters from gramene:
```
library(biomaRt)
listMaps(host = "https://ensembl.gramene.org")
gramene_connection <- useMart(biomaRt = "ENSEMBL_MART_PLANT_SNP",
                               host = "https://ensembl.gramene.org")
listDatasets(gramene_connection)
data_set_connection <- useMart("ataliana_eg_snp",
                               biomart = "ENSEMBL_MART_PLANT",
                               host = "https://ensembl.gramene.org")
nlistAttributes(data_set_connection)
listFilters(data_set_connection)
```
