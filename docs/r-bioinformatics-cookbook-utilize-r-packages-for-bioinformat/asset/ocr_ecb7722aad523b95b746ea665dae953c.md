```
blocks <- unlist(alignment[[1]])

```

That is all we need to do for a genome length alignment.

# How it works...

The DECIPHER package is very powerful, so there is a bit of setup to do before we can get the alignments. In step 1, we load the necessary libraries and sequence data into long_seqs, DNAStringSet; in step 2, we build an on-disk SQLite database for the subsequent steps. This is done with the Segs2DB() function, which takes long_seqs, an input type (here, XStringSet, which is the parent class of DNAStringSet), a name for the database, and a vector of sequences. Once we get the database, in step 3, we find the syntenic blocks in the database with FindSynteny(), which results in the following output:
