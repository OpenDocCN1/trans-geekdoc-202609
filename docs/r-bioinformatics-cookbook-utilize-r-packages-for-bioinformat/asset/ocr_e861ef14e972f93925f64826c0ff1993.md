# How it works...

Step 1 sets up the basic plot object, giving the data and aesthetic layer that form the axes and limits of the eventual plot. The geom layers are not yet added, so viewing this plot (by typing p) will show an empty plot with just axes. Step 2 adds the necessary geoms. Note in Figure 3.1 how the geoms are layered in the order declared such that the boxplot completely obscures the rest.
