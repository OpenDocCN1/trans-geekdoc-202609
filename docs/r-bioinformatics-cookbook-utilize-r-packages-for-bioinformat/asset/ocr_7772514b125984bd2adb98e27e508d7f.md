# How to do it...

Searching for enriched pathways in KEGG goes as follows:

+   1. Find the KEGG code:

```
library(clusterProfiler)
search_kegg_organism('mgr', by='kegg_code')
```

+   2. Load some genes of interest:

```
library(rbioinfcookbook)
mo_gexp <- fs::path_package(
"extdata",
mo_gexp.csv",
package="rbioinfcookbook"
)
```

```
genes <- readr::read_csv(mo_gexp)
```

+   3. Perform the enrichment:

```
kegg_result <- enrichKEGG(gene = genes$gene_id, organism="mgr"
pvalueCutoff = 0.05)
as.data.frame(kegg_result)
4. Send the result to the web for visualisation:
browseKEGG(kegg_result, "mgr00513")
```

This is all we need to do for enrichment of KEGG.

# How it works...

This code is a nice variant of the GO enrichment we've already seen, with an important change in step 1. We must use KEGG to get the code for our organism of interest. All the codes are listed on the KEGG website at https://www.genome.jp/kegg/catalog/org_list.html. You can also use the search_kegg_organism() function to retrieve information by setting the option to any of the column names that we get in the output without arguments, as exemplified here:

