# Clustering with k-means and hierarchical clustering

It is common in bioinformatics to want to classify things into groups without first knowing what or how groups there may be. This process is usually known as clustering and is a type of unsupervised ML. This is commonly used in genomics experiments, particularly RNAseq and count-based technologies. In this recipe, we'll start with a large gene expression dataset with around 150 samples.
