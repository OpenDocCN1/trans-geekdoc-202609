Having established the pattern of using mutate and map() to tidy the complex object to a dataframe. In step 3, we use the broom::tidy() to turn the lm() object into a tibble (a type of dataframe). The nested dataframe looks like this:

```
## A tibble: 3 x 4
## model tidy_model
## cyl data <list>
## <dbl> <list>
## #1 6 <tildeble [7 x 10]> <lm> <tibble [2 x 5]>
## #2 4 <tildeble [11 x 10]> <lm> <tibble [2 x 5]>
## #3 8 <tildeble [14 x 10]> <lm> <tibble [2 x 5]>
```

Step 4 uses the unnest() function to return everything to a simpler dataframe; the second argument, tidy_model, is the column we wish to unpack. We end up with the following result:

We now have a dataframe with the model unpacked. Note that we should wish, we use normal tidyverse to remove the list-based column, column. The operations are all compatible with the pipe operator and can be combined into a single pipeline, without having to save intermediate steps as we have here.

# See also

The unnest () function will only work when the nested list-based column members are compatible and can be sensibly aligned and recycled, according to the normal rules. In many cases, this won't be true, so you will need to manipulate the output with a function of your devising. For help, refer to the map family of functions, described in the Using map family of functions in purr recipe in this chapter.
