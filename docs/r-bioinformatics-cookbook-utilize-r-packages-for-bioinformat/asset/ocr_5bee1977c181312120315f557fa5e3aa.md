In this recipe, we'll look how to build a pre-processing step such as PCA into an mlr3 pipeline rather than an external step.

# Getting ready

For this recipe, we'll use the mlr3 package, it's accessory packages mlr3learners, mlr3pipelines, and mlr3tuning, and the data package mlrbench. We'll also need the magrittr package.

# How to do it...

To build a pipeline with a PCA preprocessing step, we proceed as follows:

+   1. Build the pipeline component for scaling and PCA:
```r
library (mlr3pipelines)
scale <- po("scale")
pca <- po("pca")
```

+   2. Build the start of the pipeline:
```r
library (magrittr)
pipel <- scale %>%
pca
npipelplot()
```

+   3. Add a learner as a pipeline object:
```r
library (mlr3learners)
learner = lrn("classif.knn")
learner$param_set$set_values(k = 4)
pipel <- pipel %> po("learner", learner = learner)
pipelplot()
```

+   4. Convert the pipeline to a learner:
```r
p_learner <- as_learner(pipel)
```
