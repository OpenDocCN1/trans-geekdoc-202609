# Using a linear method to compare the mean of two groups

The t-test is a statistical method used to help us decide whether there is likely to be a difference between the means of two groups. t-tests are the most widely used tests in bioinformatics, usually applied without consideration to whether the assumptions of the test and can be interpreted without criticism. By learning how to do the t-test through building a linear model, you will be able to test the assumptions hold since a well fit model implies a good fit to the assumptions. The t-test is a special case of the linear model because it can be framed as a linear regression problem with a binary predictor variable.

In the linear model, we try to fit a linear equation that describes the relationship between a response output variable (dependent variable) and one or more predictor input variables (independent variables). In the case of a t-test, we have one binary predictor variable, which represents the two groups being compared.

Suppose we want to compare the mean dry weight of plants grow under two different treatments, a test (B) and a control (A). We can set up a linear model where the response variable is the weight and the predictor variable is a binary variable for treatment. The linear model equation can be written as follows:

```
$dryWeight = \beta_0 + \beta_1 \cdot treatment + \epsilon$
```

where $\beta_0$ is the intercept, $\beta_1$ is the coefficient associated with the binary predictor variable treatment, and $\epsilon$ is the error term.

The t-test can be derived from this linear model by testing whether the coefficient $\beta_1$ is likely to be zero. If it is not, there is evidence of a significant difference in the mean dry weight between the two treatments.
