2. Use the suffixed forms to force a return type:

```
map_dbl(df, mean)
map_chr(df, mean)
map_lgl(df, mean)

# How it works..

Step uses the most common forms of map(). At the start of this step, we set up a data frame as a structure to work on, then first use map() to iterate over that dataframe, calling the map() function on each element. In this case, the element is each column of the dataframe. We get back a list, which looks like this:

```
## $small_nums
## [1] 2
##
## $big_nums
## [1] 200
```

Each list is named after the original dataframe and contains the result of the function.

We use this list (m) as input to map2(), which iterates over two things, the second being the original dataframe (o). We ask text to apply a custom function that divides the original values by the mean (o / m), thereby normalizing the data to give us norm, which looks like this:

```
## $small_nums
## [1] 0.5 1.0 1.5
##
## $big_nums
## [1] 0.5 1.0 1.5
```

In last line of step 1, we use map() to iterate over an arbitrary number of things by wrapping them in a first list. We can then apply any function to them and the elements are taken from them in turn and used in the function. Here, we use the data.frame() function to make a dataframe of the results:

```
## $small_nums
## original_value means normalised
## 1 2 0.5
