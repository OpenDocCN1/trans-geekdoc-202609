# swGetting ready

We'll need an installation of conda from https://docs.conda.io/projects/conda/latest/user-guide/install/index.html. Note there are two versions: Anaconda, which gives you all the packages and takes up about 3 GB of disk space, and Miniconda, which takes Either will be fine so choose the one that fits for you. Note that there is a version for commercial users that you'll need to look at if that applies to you (see https://www.anaconda.com/blog/anaconda-commercial-edition-faq). We'll also need the R package, reticulate.

# How to do it...

We'll start this recipe in the command line to set up conda and install software into a specific environment, move into R to run the installed programs from your selected environment:

+   Connect conda to the biconda channel at the command line (not the R console):

bash
conda config --add channels defaults
conda config --add channels biconda
conda config --add channels conda-forge
conda config --set channel_priority strict
```

+   Create and activate a new environment into which we can install external binaries, again in the command line:

```bash
conda create --name bioinformatics_project
conda activate bioinformatics_project
```

+   Install the bioinformatics tools:

```bash
conda install minimap2 gatk samtools==1.15.1
```

+   Get the path to the installed binary program in an R script:

```r
env_path <- function(env, program = "") {
  df <- reticulate::conda_list()
  b <- df$python[which(df$name == env)]

  if (length(b) == 0) {
    stop("no environment with that name found")
  }

  file.path(dirname(b), program)
}
```
