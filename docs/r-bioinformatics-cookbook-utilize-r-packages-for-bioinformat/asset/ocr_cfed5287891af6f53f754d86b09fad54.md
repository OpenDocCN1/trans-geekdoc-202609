# How it works…

This recipe is fiddly to set up but brief in its execution, so it should be simpler after the first run. In *step 1*, we use the URL from the software authors to download and install tmhmm. In *step 2*, we get the input data for RLK proteins and pass that to the tmhmm ::predict_topology () function to receive a DataFrame of topology predictions.

In *step 3*, we start to use theIPSETTM tool, which can be installed via the pureseqtminstall package without any further information. The package also contains the code for running the tool. Note that the primary function is in *step 4* as it is in *step 2*, but they come from different packages. If you're running, it's safest to use the fully resolved pathname ::function syntax to prevent name masking from becoming a problem. Again, we get a DataFrame of topology predictions, which is the final output and what we wanted to get from this recipe.

Both packages have a plot_topology () function that will draw the proteins for you.
