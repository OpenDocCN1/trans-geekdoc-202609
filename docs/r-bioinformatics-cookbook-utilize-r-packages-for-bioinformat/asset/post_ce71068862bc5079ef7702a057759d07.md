## Using the map family of functions in purrr

R's base functional programming tool kit is the purrr package was created in order to extend it and create a complete and consistent set of tools for working with functions and data structures. purrr provides a set of functions for functional programming, including the widely used map family of functions. The map functions allow you to iterate over a collection (such as a list or vector) and apply a function to each element, returning the results as a list or vector.

The functions vary according to what they expect as input, what they iterate over, and what types and structures they return. Like the apply functions, they can simplify repetitive tasks, such as data manipulation or model fitting, by automatically handling the iteration process for you but by ensuring they always return the specified types and structures they help us to build more streamlined and effective code that is less prone to bugs.

In this recipe, we'll look at some examples of the map family in use.

## Getting ready

For this recipe, we just need the purrr package.

## How to do it...

Using the map family of functions can be done in the following examples:

- 1. Use the basic map () to get back a list iterating over different inputs:

```
library(purrr)
df <- data.frame(
  small_nums = 1:3,
  big_nums = c(100, 200, 300)
)

means <- map(df, mean, na.rm=TRUE)

norm <- map2(df, means, function(o, m){o / m })

result <- pmap(list(df, means, norm), function(o, m, n){
  data.frame(original_value = o,
  means = m,
  normalised = n)
} )
```

- 2. Use the suffixed forms to force a return type:

```
map_dbl(df, mean)
map_chr(df, mean)
map_lgl(df, mean)
```

- 3. Examine other forms:

```
map_dfc(df, log)
walk_result <- walk(df, print)
```

That is all we need to know to use map functions.

## How it works..

Step uses the most common forms of map(). At the start of this step, we set up a data frame as a structure to work on, then first use map() to iterate over that dataframe, calling the map() function on each element. In this case, the element is each column of the dataframe. We get back a list, which looks like this:

```
$small_nums
[1] 2

$big_nums
[1] 200
```

Each list is named after the original dataframe and contains the result of the function.

We use this list (m) as input to map2(), which iterates over two things, the second being the original dataframe (o). We ask text to apply a custom function that divides the original values by the mean (o / m), thereby normalizing the data to give us norm, which looks like:

```
$small_nums
[1] 0.5 1.0 1.5
$big_nums
[1] 0.5 1.0 1.5
```

In last line of step 1, we use map() to iterate over an arbitrary number of things by wrapping them in first list. We can then apply any function to them and the elements are taken from them in turn and used in the function. Here, we use data.frame() function to make a dataframe of the results:

```
$small_nums
original_value means normalised
1 0.5
2 1.0
3 1.5
```

## Functional Programming with purrr and base

Step 2 shows us the suffixed forms of map (). This work as map () but force a particular return type. The map_dbl () ensures double is returned:


map_chr () ensures character is returned:

Note that the third example, map_lgl (), tries to return logical (TRUE/FALSE) values, but fail on expected, since logically data can't be coerced. Suffixed versions of map2 () and pmap () also exist. Step 3 finishes this recipe by using other map () functions. The map_dfc () applies expected, but instead of returning a list, it returns dataframe of bound columns:

```

dbl <dbl

2 0.693

```

A function called map_df () for row binding exists. Finally, we use walk (), which iterates over the dataframe, but does nothing to it. It returns the input unchanged. The usefulness, though, is in that it allows us to carry out side-effect action (such as writing to file or printing to screen) for each element without messing up the data.

## Working with lists in purrr

Lists are incredibly useful data structures that allow you to store and organize various types of objects, as vectors, matrices, dataframes, and even other lists. Unlike vectors, matrices or dataframes, lists can accommodate different types and structures within a single object. This flexibility makes them a powerful tool for data manipulation and analysis in R

As a result the purrr package provides lots of functions for working with lists, and in this short recipe, we'll look at a few for summarizing, simplifying, and extracting data.

## Getting ready

We'll just need the purrr package.

## How to do it...

We can manipulate lists in purrr using the following functions:
