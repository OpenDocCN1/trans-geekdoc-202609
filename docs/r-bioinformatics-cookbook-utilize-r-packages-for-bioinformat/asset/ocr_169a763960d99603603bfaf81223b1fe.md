# Expand the GO annotation:

```
library(GO.db)

go_annots <- select(GO.db,
    keys=annots$GO,
    keytype = "GOID",
    columns = "DEFINITION")
```

# Combine the two:

```
dplyr::left_join(annots, go_annots, by = c("GO" = "GOID"))
```

And that's how we get annotations from AnnoDB.

# How it works...

The neat recipe starts in step 1 by loading the AnnoDB package for the organism we're interested in and checking what type of data it can give us the columns () function, which gives us a returning thing like:

```

"ENTREZID" "ENZYME" "EVIDENCE" "EVIDENCEALL" "GENENAME"

"PMID" "PROSITE" "REFSEQ" "SYMBOL" "UCSCKG"
```

These entries are just the column header of all the different types and are not verbose. For a description of each, we can use the R help system with one of the values, as help ("ACCNUM"), and a description should pop up in the R help window.

In step 2, we use the keytypes() function to check which keys we want to query — these are the sorts of things we'll need to provide to the package to get the other annotations. It returns:
