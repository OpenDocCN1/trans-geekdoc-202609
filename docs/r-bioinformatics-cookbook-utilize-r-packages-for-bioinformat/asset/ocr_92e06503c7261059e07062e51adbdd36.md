# Zooming and making callouts from selected plot sections with facetzoom

We're already seen in these recipes which bioinformatics datasets can encompass very large scales. Genomes can be thousands of bases long and contain tens of thousands of genes, taxa have thousands of members, and biomes can have billions of individuals in a wide range of sizes. Contextual information is therefore often important in analysis and visualization; we may want to see a detail of subset of data in our broader context. We can do that by using plots with callout-style subplots—zoomed-in around the wider area. In this recipe, we will look at using the facet zoom functionality in the ggplot package to look at any area of interest in a ggplot.

# How to do it...

We can highlight parts of a plot as follows:

+   Zoom in a particular numeric range:

```
library(rbioinfcookbook)
library(ggplot2)
library(ggforce)
allele_freqs | |
dplyr::filter(Chr == 1) | |
gplot() + 
aes(x = Pos, y = Allele_Freq, label = info) + 
geom_point(aes(colour = type)) + 
facet_grid(Chr - , scales = "free", space = "free") + 
scale_colour_manual(values = c("steelblue", "gray", "goldenrod", "red")) + 
facet_zoom(xlim = c(100000, 2000000))
```
