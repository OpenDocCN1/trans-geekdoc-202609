# Searching Gene and Protein Sequences for Domains and Motifs

whether a package contains PFAM domain information, how to extract it for specific genes of interest, and an alternative method for running a PFAM search if there isn't any pre-existing information.

# Getting ready

For this example, we'll need the org.Hs.db Bioconductor annotation remotely and a FASTA sequence file, which can be found in the rbiocinf package. To connect remotely to the hmmer service, we'll need the bio3d package. We will coincidentally use the fs and dplyr packages.

# How to do it...

Finding proteins with a PFAM database can be done by performing the following steps:

+   1. Load the database package and inspect the types of keys in the database:
```r
library(org.Hs.eg.db)
keytypes(org.Hs.eg.db)
```

+   2. Get a vector of keys:
```r
k <- head(keys(org.Hs.eg.db, keytype = "ENSEMBL", n = 3 )
```

+   3. Query the database:
```r
result <- select(org.Hs.eg.db, keys = k, keytype="ENSEMBL",
columns = c("PFAM")
result
```

+   4. Load the PFAM database to extract descriptions:
```r
library(PFAM.db)
descriptions <- PFAMDE
```

+   5. Get all the keys from the database:
```r
all_ids <- mappedkeys(descriptions)
```

+   6. Get all the descriptions from the IDs:
```r
id_description_mapping <- as.data.frame(descriptions[all_ids])
```

+   7. Join the descriptions to PFAM:
```r
dplyr::left_join(result, id_description_mapping, by = c("PFAM" = "ac")
```

Here, we added the necessary PFAM descriptions.
