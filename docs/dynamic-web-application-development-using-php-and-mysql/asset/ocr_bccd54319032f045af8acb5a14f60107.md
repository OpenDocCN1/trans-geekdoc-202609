Next, each of the thumbnail images is displayed within a division with an id “small”. Each thumbnail image has the file name 1s.jpg, 2s.jpg, ,3s.jpg . . . 11s.jpg:

```

<img src="graphics/1s.jpg" onmouseover="startJS(1);" alt="small picture"/>
<img src="graphics/2s.jpg" onmouseover="startJS(2);" alt="small picture"/>

<img src="graphics/4s.jpg" onmouseover="startJS(4);" alt="small picture"/>
```

When the mouse is moved over the image an ‘onmouseover’ event triggers a call to the JavaScript function startJS() passing it a numerical value corresponding to the image the mouse has moved over. A ‘div’ element with the id ‘big’ is used to display the zoomed image. Large images have the same file name as their corresponding small thumbnails except that the character ‘s’ is replaced with an ‘l’. Image ‘11.jpg’ is displayed initially:

```
<div id="big"><img src="graphics/11.jpg" width='600' alt="large picture"/></div>
```
