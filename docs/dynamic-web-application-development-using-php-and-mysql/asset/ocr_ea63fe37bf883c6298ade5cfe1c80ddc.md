# Guideline 2. Don't rely on color alone

If colored text or graphics are used to convey meaning you should ensure that the same meaning can be determined if the information is viewed without color. This ensures that the application is useable when viewed with a monochrome monitor. Furthermore, colors which are too similar in hue may prove difficult for individuals who suffer from color defects such as color blindness.
