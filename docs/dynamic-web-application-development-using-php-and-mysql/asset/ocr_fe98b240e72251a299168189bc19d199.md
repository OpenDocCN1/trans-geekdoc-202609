The script displays a textarea field of 30 columns by five rows:

```
```html
<p><textarea name='strAddress' rows='5' cols='30'></textarea></p>
```
```

The address entered into the field is accessed in the same way as with other form elements:

```
```php
$strAddress = $_POST["strAddress"];
```
