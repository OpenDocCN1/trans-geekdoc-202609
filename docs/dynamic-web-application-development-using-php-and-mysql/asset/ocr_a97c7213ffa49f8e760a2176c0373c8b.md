A ‘while’ loop fetches these purchases and displays when they were purchased. The purchase id key is stored in a variable $intPurId:

while ($arrPurRecords = mysql_fetch_array($dbPurRecords) ) {

Within the ‘while’ loop, another database query selects all purchaseProducts which match the purchase Id stored in $intPurId:

$dbProRecords = mysql_query("SELECT * FROM purchaseProducts
