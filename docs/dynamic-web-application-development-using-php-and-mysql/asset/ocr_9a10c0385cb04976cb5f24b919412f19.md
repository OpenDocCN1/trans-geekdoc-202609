**NOTE** You can only use one ‘else’ statement with an ‘if’ construct.

# The ‘elseif’ statement

The ‘elseif’ construct is a combination of ‘else’ and ‘if’. It operates in a similar way to the ‘else’ construct, in that it extends the ‘if’ construct to execute a different statement if the ‘if’ expression evaluates to false. However it differs in that it will execute the alternative expression only if the ‘elseif’ expression is true. The syntax for the ‘elseif’ construct is:

```
if ( expression1 )
    statement to be executed if expression1 is true
elseif ( expression2 )
    statement to be executed if expression2 is true
```
