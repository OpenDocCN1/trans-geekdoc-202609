# Guideline 4. Clarify natural language usage

You should ensure that, as part of the document header information, you identify the main language used within the web page. You should also indicate when this language changes within a web page thus enabling automatic text-to-speech tools, for example, to automatically switch to the new language seamlessly. Furthermore, all acronyms and abbreviations should be provided in full at least once. Table 19.5 illustrates the associated checkpoints for this guideline and their priority ratings.
