# SUMMARY

In this chapter, we began by explaining how to form a connection between a PHP script and a MySQL database management system. We explained how to select a particular database served by the management system and how to access the records stored in the tables within the database. In addition to examining how to read database records, we explained how to insert, delete and amend records to the database. We concluded the chapter by explaining how to check if a record exists, determine the number of records which conform to a selection and how to use the substring function to find partial record matches.
