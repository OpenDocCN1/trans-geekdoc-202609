# TABLE 8.8  String operators

| Operator | Name | Example | Result |
|---|---|---|---|
| `.` | Concatenate | `$a . $b` | Returns `$a` concatenated with `$b` |
| `.=` | Concatenate and assign | `$a .= $b` | Concatenates `$b` to the end of `$a` |

# TABLE 8.9  Increment and decrement operators

| Operator | Name | Example | Result |
|---|---|---|---|
| `++` | Pre-increment | `++$a` | Increments `$a` by one and then returns `$a` |
| `++` | Post-increment | `$a++` | Returns `$a` and then increments `$a` by one |
| `--` | Pre-decrement | `--$a` | Decrements `$a` by one and then returns `$a` |
| `--` | Post-decrement | `$a--` | Returns `$a` and then decrements `$a` by one |

The following script illustrates the differences between these operators:

```
<?php
// File: example8-15.php
$intA = 3;
echo "<p>$intA begins as " . $intA . "</p>";
echo '<p>$intA++ ' . $intA++ . " </p>";
echo '<p>$intA is now really ' . $intA . "</p>";
echo '<p>++$intA ' . ++$intA . "</p>";
echo '<p>$intA-- ' . $intA-- . "</p>";
echo '<p>$intA is now really ' . $intA . "</p>";
echo '<p>--$intA ' . --$intA . "</p>";
?>
```
