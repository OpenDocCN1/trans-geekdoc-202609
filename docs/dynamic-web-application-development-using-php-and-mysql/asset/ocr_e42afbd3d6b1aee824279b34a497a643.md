# SUMMARY

In this chapter, we introduced the main features of JavaScript syntax, including interacting with parts of the document object model (DOM); declaring variables, arrays and objects; performing arithmetic; concatenating strings; expressing conditions and controlling loops. We saw how it is possible to use the language to create client-side processes that can integrate small programs into the browser environment. We used a number of JavaScript object methods to, for example, generate random numbers and access date and time information. We looked at various ways of adding JavaScript code to a web page, including in the body or the head of a document or in a separate ‘js’ file, which makes it possible to reuse the same code, encapsulated in JavaScript functions, in different pages. Table 6.7 provides a summary of the JavaScript keywords, JavaScript object types and built-in objects that were introduced in this chapter. In the next chapter, we build on these foundations to see how JavaScript can be used in conjunction with the DOM, style sheets, and server-side processes to make the web client more interactive and dynamic.
