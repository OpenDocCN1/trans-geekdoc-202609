# # 3.1 实际问题中的一元一次方程

探究1 销售中的盈亏

某商店在某一时间以每件60元的价格卖出两件衣服，其中一件盈利25%，另一件亏损25%，卖这两件衣服总的是盈利还是亏损，或是不盈不亏？

销售的盈亏取决于什么？

1. 商品销售中的涉及哪些量？

2. 这些量之间有什么关系？

销售中的盈亏，其等量关系为：售价 = 进价 + 利润，利润 = 进价 × 利润率。

解：设盈利25%的那件衣服的进价是x元，亏损25%的那件衣服的进价是y元。

x + 0.25x = 60，解得 x = 48；

y - 0.25y = 60，解得 y = 80。

两件衣服的进价为 x + y = 128元，售价为 120元，进价大于售价，所以卖这两件衣服总的是亏损。
