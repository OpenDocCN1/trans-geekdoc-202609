# Assignment operators

The assignment operator is ‘=’. We have used this operator in our previous examples where we assign a value to a variable, for example:

```
`$intYear = 2005;`
```

Most people wrongly think of the assignment operator as meaning ‘equal to’, as variable $intYear is equal to 2005, however this is wrong. You should think of the assignment operator as meaning ‘assigned the value’, as variable $intYear is assigned the value 2005. In addition to the simple assignment operator there are also some combination operators which allow the combining of both arithmetic and assignment operations. Table 8.5 illustrates these assignment operators.

The following script illustrates the outputs obtained from using the above operators:

```
<?php
// File: example8-12.php
$intA = 5;
$intB = 4;

$intA += $intB;
echo "<p>5 + $intB = $intA</p>";
$intA = 5;
$intA -= $intB;
echo "<p>5 - $intB = $intA</p>";
$intA = 5;
$intA *= $intB;
echo "<p>5 * $intB = $intA</p>";
$intA = 5;
$intA /= $intB;
echo "<p>5 / $intB = $intA</p>";
$intA = 5;
$intA %= $intB;
echo "<p>5 % $intB = $intA</p>";
?>
```
