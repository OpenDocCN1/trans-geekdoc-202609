The following script illustrates how PHP can retain the data entered onto a form with the select and text elements:

```
```php
<?php
// File: example10-11.php
$booTitle = 0;
$booFirstname = 0;
$booSurname = 0;
$strTitle = "";
$strFirstname = "";
$strSurname = "";

if (isset($_POST["submit"])) {
    if($_POST["strTitle"] == "Select ...")
        $booTitle = 1;
    else
        $strTitle = $_POST["strTitle"];
    if($_POST["strFirstname"] == NULL)
        $booFirstname = 1;
    else
        $strFirstname = $_POST["strFirstname"];
    if($_POST["strSurname"] == NULL)
        $booSurname = 1;
    else
        $strSurname = $_POST["strSurname"];
