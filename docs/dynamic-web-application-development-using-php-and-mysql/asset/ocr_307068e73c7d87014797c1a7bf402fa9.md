# ## 9.1 The ‘if’ construct

The ‘if’ construct is one of the most powerful features of the PHP language and it allows for conditional execution of code statements. In other words, the ‘if’ construct evaluates an expression and if it is found to be true then the statement following the ‘if’ condition is executed. The structure of the ‘if’ construct is as follows:

```
if ( expression )
    statement to be executed if expression is true
```

Figure 9.2 illustrates the structure of the ‘if’ construct.

The following is a simple example of the use of the ‘if’ construct:

```
<?php
// File: example9-1.php

$intA = 5;
$intB = 3;

if ($intA > $intB)
    echo "<p>$intA is greater than $intB</p>";
?>
```
