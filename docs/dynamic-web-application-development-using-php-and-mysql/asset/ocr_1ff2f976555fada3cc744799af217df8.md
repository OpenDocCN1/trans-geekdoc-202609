# 15.4 Viewing records

# Viewing a whole record

Returning to our previous script where we were able to display a single field within a record, we should be able to deduce that we can display all the fields of the record by accessing each field like this:

```
<?php
// File: example15-5.php

require_once("database2.php");

$dbRecords = mysql_query("SELECT * FROM customers", $dbLocalhost)
    or die("Problem reading table: " . mysql_error() );

$strSurname = mysql_result($dbRecords, 0, "Surname");
$strTitle = mysql_result($dbRecords, 0, "Title");
$strFirstname = mysql_result($dbRecords, 0, "Firstname");
$intId = mysql_result($dbRecords, 0, "Id");

echo "<p>$intId $strTitle $strFirstname $strSurname</p>";
?>
```

The output from the above script is:

1 Mrs Lynne Smith

While this is useful what we may want to do is display all the records easily.
