It is worth having a closer look at the SQL statement which we have used in the above function. Figure 15.1 illustrates what the components of this SQL statement actually mean.

The mysql_query() function returns us a resource pointer to all the records which match the SQL statement we supplied. This could be zero, one or many records. What we need is a function which returns the contents of one record cell from the record set. This function is called mysql_result():

```
`fielddata = mysql_result (resourceRecords, row, field);`
```

The mysql_query() function requires three parameters. The first is the resource pointer to the records returned by the mysql_query() function. The second is the number indicating which record to return, with 0 being the first record, 1 the second, and so on. The third parameter is the name of the database field to return. The function returns the data stored in the field. Here is an example of the function:

```
`$strSurname = mysql_result($dbRecords, 0, "surname");`
```
