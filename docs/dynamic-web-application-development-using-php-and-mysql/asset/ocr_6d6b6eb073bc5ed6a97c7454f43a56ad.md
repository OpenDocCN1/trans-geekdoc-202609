Using the ‘break’ statement lets us do some more complex things with the ‘switch’ construct. For example, ‘if’ we leave some of the ‘case’ statements empty and include a strategically placed ‘break’ statement we can show the power of the ‘switch’ statement:

```
<?php
// File: example9-9.php

$intTotal = 3;

switch ($intTotal) {
case 0:
case 1:
case 2:
case 3:
case 4:
    echo "<p>$intTotal is less than or equal to four!</p>";
    break;
case 5:
    echo "<p>$intTotal is greater than four!</p>";
}
?>
```
