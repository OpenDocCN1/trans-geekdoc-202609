This foreach statement is similar to the previous example but in addition assigns the value of the current element’s index to the key. This is shown in the following script:

```
```php
<?php
// File: example11-11.php
$arrColors = array (0 => "Red", 2 => "Green", 3 => "Blue", 5 => "", 1 => "Yellow",
4 => "White");
foreach($arrColors as $intKey => $strColor)
    echo "<p>$intKey $strColor</p>";
?>
```
