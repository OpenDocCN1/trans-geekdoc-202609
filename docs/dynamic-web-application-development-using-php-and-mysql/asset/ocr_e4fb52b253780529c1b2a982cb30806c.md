```
if ($intA > $intB)
    echo "<p>$intA is greater than $intB</p>";
else
    echo "<p>$intA is less than or equal to $intB</p>";
?>
```

You can alter the values of $intA and $intB to prove that the ‘if–else’ construct works correctly.

| NOTE | The 'else' construct cannot be used independently of the 'if' construct. |

In the same way as the ‘if’ construct, the ‘if–else’ construct employs braces to group together multiple statements for conditional execution, for example:

```
<?php
// File: example9-5.php

$strColor="blue";

if ($strColor == "green") {
    echo "<p>The color is green</p>";
    echo "<p>Green is a nice color</p>";
    echo "<p>We have the color of grass</p>";
}
else {
    echo "<p>We don't know what colour we have</p>";
    echo "<p>Other than it is not green</p>";
}
?>
```
