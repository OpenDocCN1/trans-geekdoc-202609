All this looks well, until we submit the form and we get the output illustrated in Figure 11.12. What has happened to your array data? Well, unfortunately, you cannot pass arrays between forms in this way and the data is lost.

There is however a method we can use to get around this problem and that is by using two special functions called explode and implode.

The way to get around the fact that we cannot send arrays as form data elements is to convert them into something we can send. In this case, a string. The explode and implode functions can be used to convert an array to a string and a string to an array.

The format for the explode function is:
