# 2.10 Design patterns for web page structures

The design patterns we have looked at so far address the higher-level architecture of the system in terms of server-side components. In the final part of this chapter, we look at some page-design patterns that are relevant to the client. Like the patterns described previously, these patterns are reusable across many different web applications. We look at the following patterns:

+   - Site logo at top left
+   - Navigation bar
+   - Breadcrumbs
+   - Three-region layout
+   - Home page
+   - Site map
+   - Store content in the database

The main focus of these patterns is usability, making it easy for the user to navigate our web applications. These patterns all come from (Graham 2002).
