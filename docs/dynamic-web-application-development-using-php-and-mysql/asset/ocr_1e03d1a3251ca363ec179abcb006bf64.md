# INTRODUCTION

In Chapter 3 we concentrated on looking at some of the important structural elements in HTML. HTML also provides a range of elements and attributes that support the presentation of a document, including text styles and fonts, foreground and background colours, content alignment, and list and table formatting. Using this type of mark-up, however, mixes presentation with structure and content, making it hard to separately develop and maintain the presentation layer of a web application. A much better approach is to use cascading style sheets (CSS) to apply presentational formatting independent of the HTML mark-up. In this chapter, we explore the syntax and use of cascading style sheets and see how they can be applied to HTML pages.
