# ## 8.8 Variable types

Variable data is stored in the computer’s memory but the computer needs to know in what format the data should be stored as different types of data take up different amounts of space. The format of a piece of data is known as its data type and PHP supports eight primitive types, which are listed in Table 8.1.

We shall examine each of these types in turn and describe the data they can contain.

> > **NOTE**
> >
> > The type of a variable is actually determined by PHP at the run time of the script depending on how the variable is being used. Such programming languages are known as weakly typed. In other programming languages, the variable type is determined by the programmer and these are known as strongly typed programming languages.

| Description | Type |
|---|---|

| Compound Types | Array<br>Object |
