# The ‘else’ statement

Sometimes you may wish to execute a certain statement if a condition is met and another statement if it is not. This is accomplished using the ‘else’ statement which extends the ‘if’ construct. The structure of the ‘if-else’ construct is as follows:

```
if ( expression )
    statement to be executed if expression is true
else
    statement to be executed if expression is false
```

Figure 9.4 illustrates the ‘if-else’ construct.

The following is a simple example of the use of the ‘if-else’ construct:

```
<?php
// File: example9-4.php

$intA = 5;
$intB = 3;
```
