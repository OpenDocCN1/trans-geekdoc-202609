# Why do we need XMLSpy?

Browsers such as Internet Explorer can check if XML and DTD documents are well formed. Figure 1 shows Internet Explorer 7 displaying an error message about an XML document that is not well formed.

Most browsers do not, however, validate XML documents without special tools being added. In addition, browsers offer little editing support for XML documents. Therefore it can be much more productive to edit and process XML documents using a dedicated tool like XMLSpy, which can, among other things:

+   - Check if XML documents are well-formed
+   - Validate XML documents against DTD
+   - Validate XML documents against an XML Schema
+   - Perform XSLT transformations
+   - Display HTML / XHTML
