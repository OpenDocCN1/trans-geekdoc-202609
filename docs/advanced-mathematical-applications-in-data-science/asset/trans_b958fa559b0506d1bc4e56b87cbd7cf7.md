
近年来，图像信息检索方面的最新进展，特别是数学方法，对研究很有帮助 \[[7](#9789815124842-C4.html#r7), [8](#9789815124842-C4.html#r8)\]。一组图像之间的差异可以通过从图像中提取特征来识别。使用词袋模型分析图像是有效的方法之一。

它用‘视觉词’而不是像素值来描述图像。视觉词是一种广义的特征描述符 \[[9](#9789815124842-C4.html#r9)\]，最常见的是图像簇的平均值。词的总体出现次数表示为直方图。由于表达力不强，无法从直方图区分图像。与此类似，图像、数学计算和其他过程都是通过 Python 编程完成的。

# 直方图重加权 – TF – IDF 方法

为了从直方图中获得更好的相似度，可以使用一种称为直方图重加权的方法。这是通过 TF – IDF（词频 – 逆文档频率）加权实现的。术语“频率”本质上将直方图转换为长度单位。逆向地，个体维度（词）根据它们在所有图像中出现的频率赋予权重。直方图中的每个 bin 都会被重新加权，“无信息”项（*即，*在图像/处处频繁出现的特征）会被降权，从而增强罕见词的重要性。

# 成本矩阵生成

成本矩阵是所有可能的直方图比较的矩阵（每张图像与每张图像比较）。这是图像比较的有效方法之一。条目是直方图之间的距离。成本矩阵中的条目反映了相似度。欧几里得距离 \[[10](#9789815124842-C4.html#r10)\] 和余弦距离（1-余弦相似度）被推导出来，并且在相似图像和不相似图像之间观察到更高的成本分离。

# 结论

使用原始直方图和归一化直方图的图像相似度结果不理想。通过应用 TF-IDF 并使用余弦距离，可以有效地观察到对角线外的图像相似度。与欧几里得距离相比，余弦距离的差异更为明显。对 TF-IDF 重加权直方图进行进一步归一化，可以为欧几里得和余弦距离两者获得优化的结果水平。
