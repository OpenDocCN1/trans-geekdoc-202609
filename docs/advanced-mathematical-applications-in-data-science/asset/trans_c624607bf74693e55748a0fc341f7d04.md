# 应用 K-mean 聚类技术对印度温室气体排放的州级评估

**Nitin Jaglal Untwal^([1](#9789815124842-C11.html#aff1), [\*](#9789815124842-C11.html#aff1))**  
¹ 马哈拉施特拉理工学院，奥兰加巴德，印度

## Abstract

印度是一个幅员辽阔的国家，地理和人口密度存在差异。印度的污染日渐加剧。温室气体排放由于农业、工业、电力生产、交通运输、*etc.* 等各种活动而不断上升。二氧化碳（`CO[2]`）、一氧化碳（`CO`）和甲烷（`CH[4]`）是温室气体中的主要元素。温室气体排放对环境和健康造成各种威胁。印度各邦自独立以来一直在发展。各种活动都在上升。就工业和农业部门而言，各邦的发展并不平衡。工业增长的动力是马哈拉施特拉邦和古吉拉特邦。印度的人口密度也分散分布。各邦对温室气体排放的贡献不同，政府要针对控制温室气体排放制定分类政策是困难的。将各邦划分为不同类别将有助于根据各邦的温室气体排放及其排放的人均分析，为不同邦制定战略性政策和策略。人均温室气体排放量是通过将总排放量除以总人口计算得出的。在分析上述问题后，研究人员决定开展题为《应用 `K-mean` 聚类技术对印度温室气体排放进行州级评估》的研究，使用 `Python` 编程。研究分为五个步骤进行 - 特征提取与工程、数据提取、标准化和缩放、聚类识别、聚类形成。研究期为2020年。所选分析数据为不同印度各邦的年度州级数据。研究中使用的数据来自 `Kaggle` 数据库。研究结果 - `k-mean` 算法（使用 `Python` 编程的聚类分析）将印度各邦分为三个聚类。第一类包括印度的16个邦 *viz.* 阿鲁纳恰尔、阿萨姆、比哈尔、喜马偕尔邦、查谟和克什米尔、贾坎德、中央邦、曼尼普尔、梅加拉亚、米佐拉姆、奥里萨、拉贾斯坦、锡金、特里普拉、北方邦、 Uttarakhand。第二类包括印度的8个邦。*Viz* 安得拉邦、果阿、古吉拉特邦、卡纳塔克邦、喀拉拉邦、马哈拉施特拉邦、泰米尔纳德邦、西孟加拉邦。第三类包括印度的4个邦 *Viz* 哈里亚纳邦、那加兰邦、旁遮普邦、恰蒂斯加尔邦。温室气体排放的主要贡献者位于第三类。

温室气体排放的中等范围排放被归入第二类，最低范围温室气体排放邦被纳入第一类。

**Keywords:** 碳排放, 数据提取, 特征提取与工程, K-mean 聚类, Python 编程, 标准化与缩放.
