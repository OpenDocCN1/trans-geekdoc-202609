
# 引言

从我们的角度来看，学生在数据科学教育过程中应接触到作为专业数据科学家所需的工具和才能，以及数据科学的创造性方面。根据诺兰和坦普尔·朗的论点，统计学家缺乏计算思维技能，因此统计团队合作对他们而言具有挑战性。计算技能在当今以数据为驱动和技术为主的工作场所变得越来越重要，尤其是在计算机科学领域，而且这一趋势在未来只会持续下去。这意味着课程必须采用行业标准技术并展示其特定领域的最佳实践，才能被认为有效。参加实践性数据科学课程的学生必须展示对最常用的工具之一的专业知识，以及获取新工具的能力，并展示能向未来雇主体现其优势的有意义的工作 [[9](#9789815124842-C5.html#r9)]。

数据科学课程不应作为统计或编程课程的替代品，而应围绕数据分析的基本概念构建。不是替代统计或编程课程，由于时间限制，学生在统计课程中与杂乱数据集建立联系的能力可能会受阻，并且这些课程可能仅为教学和演示目的而使用理想化的数据集。在初级编程课程中，很难投入足够的时间进行数据操作和操作，因为理解语法和编程概念占用了课程的大部分内容。在报名参加《Data Science in Practice》之前，大多数学生已经完成了通常使用 Python 的入门级编程课程和基础统计课程。这种准备将有助于学生在数据科学课程中，课程中的示例和分析基于真实世界数据。拥有对数据驱动工作的限制和潜力的深刻理解，以及适用于处理真实数据的技术技能，将教学重点放在这种理解上可能是合适的 [[10](#9789815124842-C5.html#r10)]。

在我们的课程中，我们需要展示对多样化、异构数据集的一致使用，这是数据实践的重要组成部分。当完整的计算和统计框架就位时，学生有更多时间探索数据的背景。这将有助于学生更有效地学习。有了额外的时间，他们就能将数据从原始形式转换到分析所需的格式，这是每个数据科学家必备的能力。
