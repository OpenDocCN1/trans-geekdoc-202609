

# 利用机器学习进行药代动力学和 PK/PD 建模

药代动力学和药代动力学/药效学（PK/PD）建模是药物发现、开发、监管评估和批准中的基本方法。药代动力学/药效学建模对于临床试验设计、数据分析和剂量确定至关重要。

非室室分析缺乏结构模型假设，可产生宏观药代动力学参数（曲线下面积、平均驻留时间和驻留时间变异），这些参数定义了循环系统中药物浓度水平的时间变化 [[95](#9783111573861_008368.xhtml#b_9783111574288-006_ref_095)]。尽管如此，该方法在外推应用方面存在局限，例如纳入时间相关的药效学数据，且无法描述药代动力学数据的时间演变。

此外，生理学基础药代动力学建模（PBPK）利用血液循环和器官的解剖组成，能更精确地反映实际生理状况。然而，该方法仍依赖结构模型，且建模需要相当大量的数据。此外，它基于许多难以验证的假设 [[96](#9783111573861_008368.xhtml#b_9783111574288-006_ref_096)]。

存在多种基于结构的 PK/PD 模型，每种模型均取决于药物的作用机制、PK/PD 采样的可行性及其他因素。随着日益稳健的深度学习神经网络的发展，深度学习目前广泛应用于包括药物研究在内的众多领域。利用神经网络进行药代动力学（PK）和药代动力学/药效学（PK/PD）建模的兴趣日益浓厚 [[97](#9783111573861_008368.xhtml#b_9783111574288-006_ref_097)]。

研究人员利用长短期记忆（LSTM）网络评估基于间接反应模型的假设药物的 PK/PD 数据，证明该网络能熟练捕捉药代动力学/药效学（PK/PD）关系中的时间相关性。LSTM 网络被应用于检查用于 PK/PD 数据评估的数据 [[98](#9783111573861_008368.xhtml#b_9783111574288-006_ref_098)]。

## 用于 PK/PD 模型的新型深度学习技术

一种新型深度学习技术创建的 PK/PD 模型能够通过直接从数据中学习控制方程，模拟未知给药方案的效果并预测患者反应时间进程。该方法在两方面独具特色。

首先，深度学习模型的架构保证了剂量-浓度-效应药理学原则的保留。这意味着模型预设了一种因果关系：药物浓度由剂量驱动，效应动态随后由浓度驱动。

其次，网络架构的设置使给药数据通过两个不同的端口进入模型，确保模型除了能预测当前可用的治疗数据外，还能模拟患者的给药方案 [[99](#9783111573861_008368.xhtml#b_9783111574288-006_ref_099)]。

## 基于 ML 的 QSAR 与 PBPK 集成

定量构效关系（QSAR）模型用于预测 ADME 性质并分析药物和纳米颗粒复杂的药代动力学特征，已利用 ML 技术开发而成。此外，研究人员最初将支持向量机（一种著名的 ML 方法）作为 QSAR 研究中的前瞻性工具，用于预测有机化合物在各组织中的组织/血液分配系数（Kp）。

后续研究利用 ML 技术预测多种药理参数，包括个体的肠道吸收。研究人员通过将基于 ML 的 QSAR 模型与简化的 PBPK 模型相结合，开展了多项研究，评估人和动物的组织和血浆浓度，以及各种药代动力学参数（包括 AUC、Cmax 和 t1/2）[[100](#9783111573861_008368.xhtml#b_9783111574288-006_ref_100), [101](#9783111573861_008368.xhtml#b_9783111574288-006_ref_101)]。

同样，其他研究人员利用基于 ML/AI 的药代动力学/药效学建模程序 BIOiSIM 计算药代动力学参数，如 AUC、Cmax、Vd 和平均驻留时间。BIOiSIM 是一种 AI 生物仿真程序，利用具有代表基本器官的众多独立隔室为特征的 PBPK 模型。该模型结合现有的体内数据集，预测一级吸收速率常数 (h1)、Kp 和血浆比。随后执行了 PBPK 模型 [[101](#9783111573861_008368.xhtml#b_9783111574288-006_ref_101)]。

## XGBoost 在移植药代动力学中的应用

研究人员使用 XGBoost ML 算法计算肾移植受体中依维莫司的剂间 AUC。由于包含真实患者数据的训练数据集比其他免疫抑制剂的数据集更小，因此 ML 算法在患者数据、模拟数据和混合数据上进行训练。

随后，将估算值与 MAP-BE AUC 估算值进行比较，后者源自通过大量采样编制的、独立的肾移植受体数据库获得的梯形 AUC，以及 ISBA 专家系统使用的三点有限采样策略。因此，使用多种指标评估了不同规模的模拟训练数据集，以不精确度（即 RMSE）为主要参数 [[102](#9783111573861_008368.xhtml#b_9783111574288-006_ref_102)]。

在无患者数据的大量模拟数据上训练的 ML 算法获得了最佳结果。然而，RMSE 并不代表特定患者的确切误差；而是代表数据集内的不精确度。研究人员在有限的 PK 概况集上训练 PK 模型，在此过程中生成了 MAP-BE。然而，该模型并未经过独立验证。

同样，另一研究团队使用一个 PK 模型解释全血和外周血单核细胞中的 PK，其表现仅比在患者数据上训练的算法略好 [[103](#9783111573861_008368.xhtml#b_9783111574288-006_ref_103), [104](#9783111573861_008368.xhtml#b_9783111574288-006_ref_104)]。

尽管在大量数据上训练，XGBoost 算法的表现仅略优于之前的 MAP-BE。由于一小时时极高的峰值浓度，这些异常的平坦概况要么导致对非典型病例的低估，要么导致对典型病例的高估。有意预测广泛场景的建模方法推测能更好地处理这些场景。

要收集同等数量的真实患者数据，以提升 ML 算法并使一对药物达到同等精度和准确度，将花费很长时间 [[105](#9783111573861_008368.xhtml#b_9783111574288-006_ref_105), [106](#9783111573861_008368.xhtml#b_9783111574288-006_ref_106)]。

研究人员选择通过在训练数据集中结合患者和模拟概况，或完全依赖大量模拟，来增强 ML 作为一种可用于其他药物的测试。后一种策略被证明最为成功，因为它在外部验证数据集的整个 AUC 数值范围内产生了更优的结果 [[107](#9783111573861_008368.xhtml#b_9783111574288-006_ref_107)]。
