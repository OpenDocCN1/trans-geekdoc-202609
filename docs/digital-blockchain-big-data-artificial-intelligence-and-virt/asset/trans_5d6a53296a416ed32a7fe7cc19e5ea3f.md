

# 药品生产的良好生产规范 (GMP)

制药行业的一套强制性指南被称为药品生产良好生产规范 (GMP)，简称 GMP。制药制造商必须遵守 GMP，以保证药品的安全生产，维护可靠的制药设备工艺，并根据相关国家要求严格维护质量管理和验证体系。新药研发越来越依赖现代科学技术。人工智能是一项最先进的技术工具，正在显著推进并变革各个 GMP 领域。在 GMP 质量控制下生产的药品，需要进行多种质量评估，包括药物成分分析、微生物定量评价以及药理和毒理学检测。传统检测方法可能准确率低，且需要大量的人力和物力资源。利用深度学习和产品数据分析，AI 技术可以提高检测的效率和精度。为提高检测效果，可采用“图像识别”技术评估药品质量标准 [[39](#9783111573861_014526.xhtml#b_9783111574288-010_ref_039)]，并采用“自然语言处理”技术审查药品说明书。AI 技术在 GMP 质量控制中主要用于数据收集。它可以收集并汇编全面的生产数据，涵盖生产状态、药品检验数据和仪器数据，以建立准确完整的数据库。AI 技术可以利用机器学习 (ML) 等技术手段，对药品生产过程中产生的各类数据进行评估和改进，包括数据筛选、分类和分析。它实现了对生产环节的自动化监控。AI 技术可以迅速执行大量检验任务，并有效分析和比较检验结果，从而加快消除生产过程中的潜在质量问题 [[40](#9783111573861_014526.xhtml#b_9783111574288-010_ref_040)]。

人工智能可以完全实现药品生产全生命周期的自动化，从而减少人工介入的必要性。相反，传统的药物制造方法需要大量劳动力来管理生产操作。在理想情况下，遵守 GMP 管理规范意味着在既定参数和约束内实现自动化和信息化的最大程度融合，旨在替代人工动作和操作，从而实现批次控制和管理流程的完全自动化 [[41](#9783111573861_014526.xhtml#b_9783111574288-010_ref_041)]。在国内药品生产中，常见因药品生产各环节的误差导致药品质量出现差异。AI 还可以细致地监督和管理生产过程的每一步，以减少人工介入的需求。人工智能 (AI) 技术实时监控整个药品生产过程，以尽早发现潜在问题，并提高成品的安全性、有效性和质量 [[42](#9783111573861_014526.xhtml#b_9783111574288-010_ref_042)]。

## 10.3.2 良好临床实践 (GCP)

海量数据的可用性和卓越的算力正在推动 AI 的广泛应用，但也带来了需要解决的伦理和社会问题，以最大化优势并最小化风险。虽然在临床试验 (CT) 中应用机器学习 (ML) 的方式多种多样，包括患者招募、研究设计、终点定义和更精准的诊断，但对这些技术的评估正影响着监管机构 (RAs) 批准临床研究的工作 [[43](#9783111573861_014526.xhtml#b_9783111574288-010_ref_043)]。从监管角度来看，缺乏明确的指南和标准化协议给申请人和监管机构带来了不确定性 [[44](#9783111573861_014526.xhtml#b_9783111574288-010_ref_044)]，使得这些工具的定义变得复杂，因为根据其声明的预期用途，它们有时可用于临床试验，例如用于住院患者入组选择，以减少劳动密集型程序的相关成本，因此可能不被归类为医疗器械。尽管如此，由于 ML 工具软件提供的数据甚至被医生用于辅助治疗或诊断决策，从技术上讲，它应被视为医疗器械 [[45](#9783111573861_014526.xhtml#b_9783111574288-010_ref_045)]。研究人员开发了一个 ML 预测模型，以确定在临床试验环境中使用 AI 或 ML 系统时应考虑的最重要问题。训练模型的有效性取决于数据质量，特别是其代表性，这对任何 ML 算法的学习过程至关重要。通常需要三个数据集用于训练、模型优化和评估：训练集、验证集和测试集。初始样本数据集必须严格创建并适合其预期目的，涵盖接受 CT 扫描的特定患者队列的预后特征，以辅助 ML 预测模型的训练和验证 [[46](#9783111573861_014526.xhtml#b_9783111574288-010_ref_046)]。影响最大的问题组合领域凸显了数据在指导自适应算法方面的重要性。数据对评估过程至关重要，并与技术安全性和可靠性密切相关。软件的准确性关乎其做出精准预测的能力；错误的输出可能导致意外后果，例如建议一种临床疗效较差且不良反应更多的药物。用于形成最终临床试验研究结论的数据质量，最终决定了支撑工具开发阶段的临床试验所产生的证据强度，这也影响工具的技术完整性和安全性。性能指标通过分析风险和准确性来评估 ML 模型的预测功效 [[47](#9783111573861_014526.xhtml#b_9783111574288-010_ref_047)]。

可能存在不平等的数据集的代表性构成了另一个潜在的偏倚来源。利用这些数据集训练算法可能导致研究结果的高估或低估 [[48](#9783111573861_014526.xhtml#b_9783111574288-010_ref_048)]，产生预测准确性降低的有偏系统，在人群分组中建立或加剧偏见，违背公平标准。透明度可以增强临床试验的科学严谨性，而出版偏倚可能会削弱这种严谨性，出版偏倚是一个重大问题，即只披露有利的临床研究结果，可能会产生适合算法训练的数据。算法技术具有内在的不透明性，这使得创建算法的科学家难以彻底理解其生成的复杂输出背后的基本原理，也难以阐明所涉及的技术程序 [[49](#9783111573861_014526.xhtml#b_9783111574288-010_ref_049), [50](#9783111573861_014526.xhtml#b_9783111574288-010_ref_050)]。这种被称为“黑箱”的特性，使 AI 的可预测性降低，并增加了对可能失去人工监督的担忧，进而使 AI 的可信度降低。
