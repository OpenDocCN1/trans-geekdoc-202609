

## 6.2 计算药物发现技术

当代药物化学技术主要依赖严格的测试方案和循环方法论 [[11](#9783111573861_008368.xhtml#b_9783111574288-006_ref_011)]。这些方法评估多种潜在药理学物质，以识别具备必要特质的物质。然而，这些程序可能昂贵、劳动密集且产生不准确的结果 [[12](#9783111573861_008368.xhtml#b_9783111574288-006_ref_012)]。其局限性可能源于缺乏合适的测试物质，以及难以精准预测其在体内的行为 [[13](#9783111573861_008368.xhtml#b_9783111574288-006_ref_013)]。这些问题可通过各种人工智能（AI）算法解决，包括强化学习、进化算法、基于规则的系统，以及有监督和无监督学习方法。这些策略通常依赖于对提供众多应用的海量数据集的分析 [[13](#9783111573861_008368.xhtml#b_9783111574288-006_ref_013), [14](#9783111573861_008368.xhtml#b_9783111574288-006_ref_014), [15](#9783111573861_008368.xhtml#b_9783111574288-006_ref_015)]。与现有方法相比，这些算法能更精准、有效地预测新型治疗分子的安全性和有效性 [[16](#9783111573861_008368.xhtml#b_9783111574288-006_ref_016), [17](#9783111573861_008368.xhtml#b_9783111574288-006_ref_017)]。此外，AI驱动的算法可为药物开发确定新靶点，涵盖与疾病相关的特定蛋白质或遗传通路 [[18](#9783111573861_008368.xhtml#b_9783111574288-006_ref_018)]。超越传统方法增强药物发现，最终可能促成新型且更有效疗法的创造。通过实施机器学习（ML）和其他AI技术，可克服这些限制。ML算法能辨别人类研究者可能忽视的海量数据集中的模式和趋势。与传统技术相比，这有助于加快提出副作用更少的现代生物活性物质。最近，一个包含已知药物物质及其相关生物学过程的数据集被用于训练深度学习算法 [[19](#9783111573861_008368.xhtml#b_9783111574288-006_ref_015)]。随后，该程序在预测新化学物质的活性方面表现出了卓越的精度。通过利用已知有害和无毒物质的海量数据集训练ML算法，在降低潜在治疗分子毒性方面做出了重大贡献 [[20](#9783111573861_008368.xhtml#b_9783111574288-006_ref_020)]。此外，药物发现中AI的应用需要高质量数据集。技术和高通量测序的进步加速了许多免费开放获取药物发现数据库的建立。如[图 6.1](#9783111573861_008368.xhtml#b_9783111574288-006_fig_001)所示，这些数据库加速了药物发现流程，并助其步入大数据时代。目前，人工筛选的数据库如 `ChEMBL` 包含超过两百万种具有类药特性的化合物 [[21](#9783111573861_008368.xhtml#b_9783111574288-006_ref_021)]。

`ChEMBL` 收集沉积化合物的分子特性、毒性、靶点相互作用、代谢、消除、吸收、分布和排泄机制数据。`ChemDB` 是一个公开可用的数据库，提供理化性质（如可旋转键、分子质量和溶解速率）以及近 500 万种易获取小分子的信息 [[22](#9783111573861_008368.xhtml#b_9783111574288-006_ref_022)]。此外，`ChemDB` 包含多种化学信息学工具，包括 `Reaction Predictor`、`MOLpro`、`AquaSol` 和 `Smi2Depict`，有助于药物发现。`药物-基因相互作用数据库 (DGIdb)` 提供可能与药物相互作用的基因和基因产物信息 [[23](#9783111573861_008368.xhtml#b_9783111574288-006_ref_023)]。为查找药物-基因相互作用，用户可使用搜索字段模块输入药物或基因列表，或浏览各组中的基因。此外，`DGIdb` 可通过基于网络的界面 API 自动获取。`DrugBank` 是一个易于获取的参考药物数据库。目前收录了众多药物，以及关于药物类别、相互作用、靶点-药物关系和反应的大量知识。利用集成工具，用户可从 `DrugBank` 搜索、调研和检索文本、图像和结构数据。目前，它是全球药物筛选、设计和代谢预测最广泛使用的资源 [[24](#9783111573861_008368.xhtml#b_9783111574288-006_ref_024)]。这些平台整合面临的两大主要问题是管理AI使用的严格法规和预期的岗位流失。然而，这些技术旨在使任务更轻松，而非完全取代人类 [[25](#9783111573861_008368.xhtml#b_9783111574288-006_ref_025)]。除了使先导化合物识别快速且无误外，AI 还能识别相关的结构-活性关系（SAR）、推荐最佳化学结构、理解药物-靶点关系，并为这些药剂建议合成路线。在添加基础药物后，AI 可协助快速决策，并提供关键信息以将药物改进为合适的剂型。因此，可更快、更一致地批次间生产高质量产品。通过深入的市场分析和预测，AI 可确保行业内的最佳匹配与定价，并有望协助确定药剂在临床试验中的安全性和有效性。

通过分析与患者相关的基因组-环境暴露组属性，AI 可协助识别特定患者队列以参与 II 期和 III 期临床试验。它可通过更先进的监测方法，实现对入选参与者现有治疗靶点的监测 [[26](#9783111573861_008368.xhtml#b_9783111574288-006_ref_026), [27](#9783111573861_008368.xhtml#b_9783111574288-006_ref_027)]。辅助 AI 能力的利用，如预测性 ML 和替代预测算法，促进了分子的临床前评估和先导化合物的识别，从而增强了对指定患者群体中适合临床试验的先导分子的预测 [[27](#9783111573861_008368.xhtml#b_9783111574288-006_ref_027)]。患者脱落约占临床研究失败的三分之一，导致必须满足额外的入组要求才能完成试验，这增加了试验的经济和时间负担。通过密切的患者监督和支持，遵循正确的临床试验方案，可避免此类问题 [[28](#9783111573861_008368.xhtml#b_9783111574288-006_ref_028)]。在一项 II 期试验中，“`AiCure`” 发布了智能手机软件，追踪规律服药的精神分裂症患者。结果，患者依从频率略有上升，确保了临床试验的成功。
