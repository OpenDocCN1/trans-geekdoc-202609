+   **Early Detection of Security Threats**: The BDS detects potential security breaches early, reducing the time needed to investigate and respond to the threat [78].

+   **IPS/IDS**: Two critical elements in the ITS ecosystem are the IPS (intrusion prevention system) and IDS (intrusion detection system) [79]. An IDS security instrument monitors network data to store and warn managers of potentially harmful or suspicious behavior. It examines and contrasts network data with recognized fingerprints or patterns. The IDS alerts the supervisor or staff when an attack is found. On the other hand, an IPS detects attacks and takes action to prevent them. It uses the same techniques as an IDS to analyze network traffic, but, when it identifies an attack, it can block or quarantine the malicious traffic to prevent it from reaching its target. In the context of ITS, an IDS or IPS can help protect critical systems and data from cyber threats. These threats can come from various sources, including hackers, malware, and other malicious actors. By monitoring network traffic and blocking suspicious activity, an IDS or IPS can help prevent attacks that disrupt or compromise the functioning of the transportation system [80].
