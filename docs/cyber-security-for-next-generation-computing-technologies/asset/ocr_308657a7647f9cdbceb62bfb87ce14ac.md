# 8.4 INTRUSION DETECTION SYSTEM FOR IOT NETWORKS

An intrusion detection system working in an IoT system protects the network from intrusions and threats. It maintains the integrity, availability and confidentiality of the network [44]. IDS detects the network condition and alerts it in the form of alarms. There are four situations of IDS alerts i.e., true positive, true negative, false positive and false negative relating to real threat, normal scenario, false alert and misdetection [45, 46]. Figure 8.2 explains the classification of threat alerts in IDS.

Two main types of IDS can be implemented in the system: host-intrusion detection system (HIDS) and network-based intrusion detection system (NIDS). The HIDS is deployed on a single system and the metrics of the host environment to detect attacks [47]. A NIDS senses intrusions from network data packets [48].
