

## 针对智能交通系统的网络攻击

鉴于智能交通系统（ITS）在现代交通系统中发挥着关键作用，必须投资网络安全和开发，以提高这些系统的韧性。政府机构、私营公司和学术机构在内的利益相关者之间的协作，有助于应对 ITS 网络威胁的复杂性和不断演变的本质。
