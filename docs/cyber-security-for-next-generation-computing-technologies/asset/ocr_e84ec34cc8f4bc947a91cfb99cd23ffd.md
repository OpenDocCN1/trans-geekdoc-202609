+   Multifactor Authentication (MFA): MFA is the initial element of access control where users must provide multiple forms of authentication to access edge/fog applications. MFA helps not only to verify the users but also to track abnormal activities by clearly identifying the threat sources.
- Cloud Access Security Brokers (CASBs): Edge/fog systems interact with cloud computing to share collected and processed data or to receive tasks from the cloud to execute them. Securing cloud systems is a key edge/fog security network component [14]. Integrating a CASB between cloud consumer and provider helps enforce regulatory compliance, protect the data, identify the risk, and optimize cloud usage across applications and devices [15].n- Identity and Access Management (IAM): IAM solutions are important element of security strategy. It provides a centralized framework of technologies and policies for managing user identities and access privileges. It includes user provisioning, MFA, identity analytics, single sign-on establishment, zero-trust policy implementation, Using IAM with edge/fog systems can enforce strong access controls and reduce the risk of insider threats.

# 10.5.2 Data Encryption and Privacy

+   - Cryptography: Cryptography is crucial security control to secure communication and shared data. It helps to hide the content of information using a key that can be used for encryption at the sender level and for decryption at the receiver level [16]. It differs forms, such as symmetric and asymmetric encryption and hash functions. Integrating cryptography in edge/fog systems protects the data
- Data Loss Prevention (DLP): DLP is the measure of preventing unauthorized disclosure, destruction, or exfiltration of sensitive data such as personnel information or financial data. By implementing DLP practice within edge/fog computing systems, the sensed and processed data remains protected from breaches and other types of cyber attacks that could result in loss of sensitive data.
