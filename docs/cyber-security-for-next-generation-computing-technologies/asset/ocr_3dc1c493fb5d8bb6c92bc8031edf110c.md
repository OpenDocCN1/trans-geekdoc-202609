Whenever a study population is truly an intrusion and it is categorized as normal, this is known as a false negative [49, 50]. False negatives are undesirable since they indicate that an intrusion went undetected. The majority of intrusion detection systems are employed in a tiered manner. This implies that yet another layer may identify an intrusion if the first layer misses it.

The tiered strategy can provide different results. Its primary layer attempts to identify any anomalies as it can (while having a poor recall) before rewarding the information about which incidents have been found to further levels. This strategy indicates that a poor recall is acceptable. Depending on how the IDS will utilized, a machine-learning-based scoring system is employed.
