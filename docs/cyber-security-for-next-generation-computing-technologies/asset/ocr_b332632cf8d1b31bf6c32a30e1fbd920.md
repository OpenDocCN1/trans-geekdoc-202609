In this scenario, UAVs play the role of aerial node stations with their mobile sensors (MSN) for transmitting data [17]. In this way, the UAV collects some data through performance indicators for sensing, control, and localization based on real-time mobile aerial nodes. Thus they collect some data and send it to a particular location if the device moves from its final destination. They can retransmit data later to the particular device, which is admirable [16]. UAVs routinely work as a mobile relay, pinpointing collected information and updating targets for the collected information. They detect signal information by deploying RSSI (received signal indication) omnidirectional sensors on UAVs [13].
