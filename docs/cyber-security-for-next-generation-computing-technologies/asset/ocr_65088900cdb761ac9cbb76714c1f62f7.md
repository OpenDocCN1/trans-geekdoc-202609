# 9.6 INTRUSION DETECTION SYSTEM FOR IOT NETWORK

Information sharing is increased due to social media platforms; therefore, security need to be ensured. Cyber threats are usually launched to gain access of entire IoT network. Therefore, intrusion detection is designed to identify possible cyber attacks. There are four major types of IDS: network-IDS, hybrid-IDS, anomaly-IDS, and signature-IDS. Also, privacy is considered a major factor in smart cities. IDS is used to monitor and ensure reliable IoT operations. False alarms, accuracy, precision, recall, and F1-score can be improved using machine learning and deep learning classifiers [29–32].
