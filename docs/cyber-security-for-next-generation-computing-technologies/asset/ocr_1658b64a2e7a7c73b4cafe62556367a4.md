# 12.7 BLOCKCHAIN-BASED INTRUSION DETECTION SYSTEM FOR THE INTELLIGENT TRANSPORTATION SYSTEM

The key factors of security, privacy, and trustworthy environment in ITS infrastructure are a critical issue. Every person has a vehicle requirement. With the ITS in transportation sector, security is a more critical problem for users and authorities.

At the present, smart/intelligent transportation systems cooperate with blockchain technology and intrusion detection system. In intrusion detection systems, the intrusion security systems alert the concerned person before the attack happens.

Normally, intrusion detection systems are described in two classes:

+   1. Intrusion Detection System (NIDS): Close supervision and registration will allow this network to work freely with all the gadgets and other devices.

+   2. Host Intrusion Detection System (HIDS): In this way, only one computer works as a host, which manages and controls the monitoring of traffic data packets and works to save malicious attack data [61].

Blockchain is a digitized system network that works in a way similar to that of distributed levels. It is mostly applicable in accounts, banking, and ledger for transaction data. It cannot work on a signal entity or but works on the basis of cluster grouping and arrays. Working on logical consensus, it takes decisions with the help of previously stored data in the form of arrays. After checking those arrays, it generates opinions automatically in regular intervals over every transaction. In today's lifestyle, blockchain works efficiently in our daily tasks such as cryptocurrency, bitcoin, intrusion detection (cyber security), automation, modex application, etc. [62].
