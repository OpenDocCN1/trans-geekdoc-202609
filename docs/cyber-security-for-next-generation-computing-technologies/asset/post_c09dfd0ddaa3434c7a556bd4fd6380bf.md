# 1.6 CYBER SECURITY SOLUTIONS

Cyber security solutions are a collection of technologies, tools, and services designed to defend businesses from cyber attacks and stolen data, reputational harm, compliance fines, and other negative outcomes that can occur from such attacks. Tools are an integral part of cybersecurity in the security environment, which features a wide array of threats that are always evolving [45–47]. We'll take a look at three classes of security measures:

- Cloud Security: As businesses use the cloud, they are exposed to security concerns and may not be adequately managed by solutions developed on-premise. These security issues are addressed by cloud solutions such as cloud access brokers (CASB), serverless and container security solutions, et.

- Application Security: The majority of production applications have vulnerability, and some of these flaws can be used to exploit the organization's development. Integrating application security into DevOps workflows can identify and fix vulnerabilities before they are exploited in production.

- Internet of Things (IoT): IoT devices, which have centralized monitoring and management, can be very beneficial to a company, but frequently have security issues. Controlling access to devices and defending them from exploitation.

- Endpoint: Although defending endpoints from malware and other threats has always been crucial, remote work has made it more crucial. Security of the endpoint depends on defense against ransomware, phishing, and other threats.

- Mobile Security: As the usage of mobile devices for business becomes more common, criminals increasingly focus their attention on mobile platforms. Protection from mobile-specific risks like phishing, rogue apps, and connectivity to harmful networks is provided by mobile security solutions.

# Cyber Security for Next-Generation Computing

- Network Security: The majority of cyber attacks occur across networks, and by identifying and thwarting attacks before they can reach the organization's endpoints, their damage is completely eliminated. Organizations are attempting to secure their new infrastructure. The following next-generation security technologies have seen an increase in popularity as a result:

- Extended Detection and Response (XDR): XDR solutions address endpoint issues by a shift to hybrid workforce. By allowing a company to increase awareness across numerous attackers and boost productivity through the use of security automation and centralized monitoring and management, XDR systems provide proactive defense against cyber threats.

- The Secure Access Edge (SASE): SASE is intended to combine networking and security into a single cloud-based appliance. SASE optimizes traffic routing using software-defined WAN (SD-WAN) features (PoPs). Because these PoPs have full security stack, SASE can monitor and manage security across the organization's spread-out infrastructure.

- Zero Trust Network Access (ZTNA): ZTNA is an alternative to the traditional VPN. In contrast to VPN, which grants users full access to the corporate network, ZTNA employs zero trust principles and grants access to resources on a basis. A business can more securely support a remote workforce and defend itself against attempted exploitation of remote access solutions by deploying ZTNA, commonly referred to as software-defined perimeter (SDP).
