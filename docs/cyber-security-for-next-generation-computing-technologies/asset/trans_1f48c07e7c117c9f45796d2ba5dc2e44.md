## 13.7 结论与未来方向

最近，人工智能被广泛应用于许多领域。基于物联网的无人机识别是一个严重问题。本章节提供了入侵检测系统的对比分析。因此，使用 XGBoost、朴素贝叶斯、AdaBoost 和 GaussianNB 等机器学习算法在 UNSW-NB15 数据集上实现。使用 Python 完成了仿真。AdaBoost 的准确率更高。总体而言，XGBoost 的准确率为 98.2507%。未来，优化技术将提供解决方案。
