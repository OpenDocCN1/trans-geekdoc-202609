# 11.3.1 Examples of ITS Implementation

Adaptive traffic signal management systems can change the timing of traffic signals and enhance traffic flow using real-time traffic data [51, 52]. On the other hand, adaptive traffic management systems use real-time traffic data from numerous sources, including cameras, sensors, or GPS devices, to assess the current traffic conditions. The real-time timing of the traffic signals is modified using this data to improve traffic movement and ease congestion. For instance, if there is a lot of traffic on one road, the system can change the timing of the traffic signals to give that road more green while decreasing congestion for other roads with less traffic.
