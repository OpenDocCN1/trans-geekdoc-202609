# Cyber Attacks Against Intelligent Transportation Systems

The critical role of ITS in modern transportation systems, it is vital to invest in cyber security and development to improve the resilience of these systems. Collaboration among stakeholders, including government agencies, private companies, and academic institutions, can help address the complexity and evolving nature of cyber threats to ITS.
