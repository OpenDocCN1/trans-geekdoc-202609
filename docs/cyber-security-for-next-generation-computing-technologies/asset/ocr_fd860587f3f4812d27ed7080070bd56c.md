# 3.6.3 NSL-KDD DATASET

This dataset is considered the new version of the previous one. This dataset con-tain 22 different attack types, which are categorized into four major groups. It is comprised of the KDDTrain+ as the training set and the KDDTest+ and KDDTest-21 datasets as the testing set [75]. The latter is more challenging to class-ify due to its unbalanced representation of normal and attack records. However, the NSL-KDD still lacks up-to-date data, particularly for minority class samples. Despite this limitation, the dataset represents a significant improvement over its de-cessor and serves as valuable resource for network intrusion detection research.
