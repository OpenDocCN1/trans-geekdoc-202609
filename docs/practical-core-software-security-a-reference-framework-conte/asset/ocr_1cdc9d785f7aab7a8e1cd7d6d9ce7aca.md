# Typical SDLC Phases

# SDL Activities and Best Practices

| SDLC Phase | Activity ID | Category | Best Practices |
| :--- | :--- | :--- | :--- |
| Concept (1) | A1 | Security Assessment | - Software security team is looped in early<br>- Software security team hosts a discovery meeting<br>- Security team creates an SDL project plan<br>- States what further work will be done<br>- Privacy team creates a Privacy Impact Assessment (PIA) plan |
| Planning (2) | A2 | Architecture | - A2 Policy compliance analysis<br>- SDL policy assessment & scoping<br>- Threat modeling / architecture security analysis<br>- Open source selection<br>- (if needed) Privacy information gathering and analysis |
| Design & Development (3) | A3 | Design & Development | - A3 Policy compliance analysis<br>- Security test plan composition<br>- Static analysis<br>- Threat model updating<br>- Design security analysis & review<br>- Privacy implementation assessment |
| Readiness (4) | A4 | Design & Development | - A4 Policy compliance analysis<br>- Security test case execution<br>- Static analysis<br>- Dynamic analysis<br>- Fuzz testing<br>- Manual code review<br>- Privacy validation and remediation |
| Release & Launch (5) | A5 | Ship | - A5 Policy compliance analysis<br>- Vulnerability scan<br>- Penetration testing<br>- Open source licensing review<br>- Final security review<br>- Final privacy review |
