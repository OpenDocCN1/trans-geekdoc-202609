# # Chapter 7
Ship (A5): SDL Activities and Best Practices

# ## CHAPTER OVERVIEW

Now that you have reached the last phase of the software development life cycle (SDLC), you need to ensure that the software is secure and that privacy issues have been addressed to a level at which the software is acceptable for release and ready to ship. Software security and privacy requirements should have come from initial phases and been refined throughout the cycle. In this chapter, we will take you through the last stage of policy compliance review, followed by the final vulnerability scan, pre-release penetration testing, open-source licensing review, and the final security and privacy reviews.
