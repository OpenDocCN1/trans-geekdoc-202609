

# Introduction

在当前的数字化时代，大数据已成为众多领域（尤其是营销 ([Brewis et al., 2023a](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor796); [Cadden et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor798)）以及理解在线消费者行为 ([Chou et al., 2022](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor802); [Liu, 2021](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor812)）的根本性变革加速器。收集、分析和解读海量数据集的能力，为组织提供了深入了解消费习惯趋势 ([Kauffmann et al., 2020](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor807); [Wang et al., 2020](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor828))、期望以及战略性购买决策 ([Akram et al., 2022](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor791)) 的深刻洞察，使它们能够更有效地调整营销策略 ([Chou et al., 2022](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor802))。然而，尽管关于营销领域大数据的研究众多 ([Brewis et al., 2023a](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor796); [Chou et al., 2022](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor802))，但仍有多个问题未得到解答，特别是关于其在特定情况下（例如技术不断发展的摩洛哥市场）对满意度和在线购买行为的影响。

摩洛哥正逐步融合数字和技术工具，且人口日益互联，这使其成为研究大数据如何影响在线满意度和购买行为的理想环境。先前的研究 ([Roy et al., 2020](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor819); [Salonen et al., 2024](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor822)) 指出，大数据通过调整和个性化营销策略，有潜力显著改善消费者行为和满意度。然而，这些效应在摩洛哥语境下的程度仍大多未被分析。

这一观察凸显了在摩洛哥语境下研究大数据对在线满意度和购买行为影响的重要性。现有文献广泛涉及大数据对企业的技术层面和益处，但关于消费者感知、他们对个性化推荐的反应，以及这些因素如何影响其在线购买决策的深入研究却不足。因此，将开展一项定量研究，以提供大数据对在线购买行为影响的最新状态，重点关注摩洛哥市场。本研究旨在阐明大数据分析对摩洛哥快速数字化市场中客户满意度的影响，这一语境虽具有潜在洞察力，但仍未被充分探索。通过关注这一特定的地理和数字环境，研究旨在弥合大数据广泛能力与消费者满意度实际提升之间的差距，构建一个连贯的叙述，审视大数据在独特发展市场中所带来的益处与挑战。本研究还旨在分析大数据如何增强营销个性化，进而积极影响消费者行为和满意度。此外，它还将识别需要未来研究的领域，以更深入地理解这些机制。

本文将首先开展文献综述，阐述大数据的一般概念。接下来，我们将探讨大数据、满意度与消费者行为之间的相关性。在第二部分，我们将介绍所采用的方法论，明确研究背景以及数据收集和分析过程。第三，我们将讨论先前研究的结果与讨论，重点介绍所获得的发现。最后，我们将通过综合本研究的结果、理论与管理贡献、遇到的局限性以及未来研究方向来得出结论。

# 2 LITERATURE REVIEW

## 2.1 Big Data Analysis

大数据的版图不断扩大，现在涵盖了海量数据 ([Xiao et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor829))。为了在海量数据中导航并提取价值，公司越来越关注先进的大数据分析 (BDA) ([Cadden et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor798); [Saidali et al., 2019](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor821))。这一数据分析概念侧重于通过理解多个数据指标之间关系的复杂性来收集相关洞察。BDA 已成为数据科学的一个基本因素 ([Bouhtati, Alla, et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor794)，为组织整体性能提供了实质性改进。大数据概念随时间不断扩展。它在管理系统复杂性、确立其可信度以及增强其内容和适应不断变化的动态全球商业环境的能力方面至关重要 (Feng et al., 2024; [Gao et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor805))。BDA 的重要性在战略规划领域更进一步，使组织能够识别潜在风险和机遇，从而促进其运营采取更敏捷的方法 ([Brewis et al., 2023a](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor796); [Mukhopadhyay et al., 2024](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor816))。在营销领域，BDA 的影响更为深远 ([Brewis et al., 2023b](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor797); [Mukhopadhyay et al., 2024](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor816))。它使公司能够精确检测和理解消费者行为 ([Filieri et al., 2023](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor804))，个性化信息以满足特定消费者需求，提高客户忠诚度，并有效评估营销策略的投资回报率 ([Caracciolo et al., 2022](#979-8-3693-3172-9.ch013.bits-pdf.xhtml#_idTextAnchor799))。
