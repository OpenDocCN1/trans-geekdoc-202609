

# 雾计算是与物联网技术和应用框架兼容性最好的技术之一

Tange K. *et al* 提出了雾计算启用的身份验证 \[[12](#9789815051452-C1.html#r12)\] 以保护物联网网络。这可以通过使用雾节点作为身份验证系统，而不是任何第三方身份验证服务器要求来实现。雾节点满足物联网网络的所有要求，因为它轻量级、位于网络本地，从而导致通信开销极低且响应时间快。此外，雾节点可以充当网络的一部分，同时也可以用于第三方通信和数据传输，而不会出现任何安全漏洞问题。这还通过将部分身份验证控制权转移到雾节点来增强我们的网络，从而减少了轻量级物联网节点的计算量。在物联网安全中使用雾节点的一个开放挑战是出于安全目的隔离雾节点。与传统系统一样，安全措施非常差，在这些系统中，雾节点隔离是一项困难的任务，也是研究人员面临的开放挑战。

## 基于机器学习的物联网安全

物联网网络具有异构性，包含各种设备、不同种类的协议和算法，大规模部署，使用低功耗和低成本的通信在近距离内进行连接，且不涉及中央机构。它还应具有自组织和自愈特性，这些特性应以高安全性和智能性进行动态管理。对于这种受限网络，机器学习是最合适的技术之一。机器学习算法可以在任何外部干扰 \[[13](#9789815051452-C1.html#r13)\] 下自行训练。此类网络可以相应地适应，并基于运行时收集的动态数据进行未来预测。它可以响应随时间变化的特定问题。它可以用于检测威胁和恶意软件。例如，Google 使用 ML 来识别移动设备和终端中的潜在威胁。但 ML 并不是足够好的解决方案，因为存在误报和漏报，但我们仍然可以信任基于 ML 的强化学习或无监督学习技术 \[[14](#9789815051452-C1.html#r14)\]。基于 ML 的解决方案需要监控模型修改和错误预测。Hasan, M. *et al* 使用了各种机器学习算法进行异常和攻击检测，并比较了各种技术在准确率、召回率、精确率、F1 分数、*etc.* 等参数上的表现。他们使用了各种技术，如决策树、深度神经网络、人工神经网络、随机森林、支持向量机，并得出结论：随机森林技术是早期预测各种攻击的最佳方法。但他们只研究了经典方法，而不是集成方法。此外，他们尚未制定完整的框架。

## 基于边缘计算的物联网安全

物联网与边缘计算是一个高度研究的领域，因为它融合了云计算，而物联网与云计算从研究角度来看是当前技术。Wang, T. *et al.* \[[15](#9789815051452-C1.html#r15), [16](#9789815051452-C1.html#r16)\] 提出边缘网络在实现基于信任的消息传递框架以满足特殊服务要求方面非常可靠。他们得出结论，基于边缘的安全框架可以帮助增强基于云的物联网结构的安全性、效率和性能。Bhardwaj K. *et al.* \[[17](#9789815051452-C1.html#r17)\] 建议可以使用边缘节点来减少网络中的 DDoS 攻击。众所周知，在我们的物联网网络中，设备非常轻量级，计算能力低，因此容易受到 DDoS 攻击。这些攻击之所以成功，是因为我们的网络计算能力非常低。在基于边缘的网络中，为边缘节点提供了高计算能力，其计算能力可以用于抵御此类攻击。这导致此类攻击的早期检测，从而减少损失。他们的实验研究证明，检测速度提高 10 倍可以减少 82% 因 DDoS 攻击造成的互联网流量。边缘计算可以帮助解决安全漏洞问题、数据合规性问题、安全问题和带宽问题。数据泄露问题通过将数据保留在网络内部来解决。使用边缘网络，我们不需要将数据发送到外部世界，从而最大限度地降低数据泄露的可能性。此外，在许多国家，数据合规性法律规定数据不得移出网络，我们正在非常高效地使用边缘节点来维护这一点。安全问题是物联网设备的主要关注点之一，如果将数据传输到决策节点时出现哪怕一点延迟，可能会导致各种安全问题。例如，如果我们正在为可穿戴设备创建一个带有 SOS 按钮的女性安全应用程序，如果传输该数据时出现哪怕一点延迟，可能会导致各种危险。在物联网中，由于各种节能策略，我们无法将每个数据都传输到中央云节点。边缘节点通过在本地分析数据并仅以安全的方式传输关键数据来帮助我们减少通信开销，该方式通过位于物联网网络内外的边缘节点与中央计算云节点之间的点对点身份验证实现。

## 基于密码学/隐写术的物联网安全

密码学在物联网中并不是一种常用的技术，因为密码学算法过于复杂，无法在轻量级物联网节点上执行，但仍有一些学者尝试了这种方法。Henriques S. *et al.* 提出了一种同时使用非对称和对称密码学的身份验证方法，以保护物联网设备之间的通信。这导致了时间消耗的减少，尽管采用了非对称方法。每次都会取一个随机会话密钥，这提高了对称加密方法的安全性。这使得系统更具抗攻击性，并解决了会话密钥分发问题。可以通过使用更复杂的加密技术或使用哈希来进一步改进，但唯一的障碍是物联网节点的计算能力较低，无法执行高端加密算法。Sridhar S. *et al.* \[[18](#9789815051452-C1.html#r18)\] 提出了轻量级双重身份验证密码学方法。使用轻量级非对称密码学来在传感器节点和设备网关之间提供身份验证。传感器节点的唯一 ID 和设备网关的唯一 ID 被用于使用 AES 算法创建秘密密钥/数字证书。设备网关和云服务使用公钥加密数字签名进行相互身份验证。他们提出了一种双重身份验证方案，通过消除有故障和虚假的数据块来减少流量，从而提供了安全性，并通过减少带宽使用提高了性能。Khari M. *et al.* \[[19](#9789815051452-C1.html#r19)\] 研究了椭圆伽罗瓦密码学算法，该算法加密了来自各种医疗来源的机密数据。然后使用矩阵 XOR 编码隐写术技术，将其嵌入低复杂度图像中。它还使用自适应萤火虫算法优化块选择，以降低计算成本。使用这种技术，任何数据都可以使用图像层以高效的方式安全传输。
