

# BCT 在安全与医疗领域的应用

BCT 之所以能在安全领域发挥作用，是因为其去中心化、不可篡改等天然特性，如前所述，它已被证明能够抵御各种恶意攻击。BCT 能够提供隐私保护，因为所有交易都使用加密密钥保存，攻击者无法定位数据来源。区块中的时间戳不允许任何人在中间添加数据，从而突显了 BCT 的不可篡改性 \[[50](#9789815051452-C5.html#r50)\]。BCT 在数据传输方面也有益处。不会出现数据丢失，数据的整合性和安全性更高。添加数据需要网络中其他节点的验证，因此任何恶意软件都无法潜入 \[[51](#9789815051452-C5.html#r51)\]。

人们甚至可以考虑将 BCT 的核心思想应用于健康应用网络，其中收集的数据可以以非常安全、可靠且私密的方式向经过身份验证的医疗服务提供者生成重要警报。到目前为止很明显，各种智能 IoT 设备以互联网层的夹层形式被使用。从这些层中收集数据，进行分析，随后用于医疗服务提供者。由于 IoT 设备轻量且占用空间小，往往会留下非常微小的能量足迹。这种少量的能量不足以支持涉及安全或隐私的任务，因此 BCT 应运而生。IoT 有很多缺点，但其广泛使用往往有时会导致可扩展的方法，很多时候，这可能变得相当具有挑战性，因此部署 BCT 可能会成为一项非常有利可图的交易 \[[52](#9789815051452-C5.html#r52)\]。

2020 年无疑充满了惊喜和意想不到的情况，但世界在进步方面无疑被病毒 COVID-19 向后推了。这种病毒的前所未有的传播引发了各种挑战，尤其是在医疗领域，因此技术进步必须成为人类的救星，这些进步无非是 AI、BCT、ML 和 IoT 等新兴技术。从主旨演讲来看，欧洲议会研究服务处（EPRS）已将 BCT 发现为对抗 COVID-19 的关键新兴技术之一。在 BCT 所具备的所有关键特性中，当与 IoT 结合时，它可以大大进步，以克服这种病毒带来的所有考验。这一伞形范围可以扩展到各种应用，例如接触者追踪、患者信息共享、供应链管理、电子政务、灾害救援和保险、在线教育、各种自主服务、制造业、农业和食品分销 \[[53](#9789815051452-C5.html#r53)\]。

到目前为止，我们已经探讨了我们主题的三大要素在单一伞形下的可能结果或领域，但仍然过时的是数据的真实性和安全性，如果支持整个网络的系统或框架不是 BCT 具备的，这些问题仍将存在。此外，有害的是针对医疗系统的网络攻击和频繁攻击，导致毁灭性的数据丢失。因此，当整个数据由一个非常强大、不可篡改、不可攻破的系统处理时，它不仅对医疗部门或组织有帮助，而且系统现在将对患者的个人数据丢失负责。如果现在处理这个整个框架的系统以加密格式存储数据，即使系统以某种方式关闭或面临任何技术故障，数据仍然会受到保护并存储在安全的地方 \[[54](#9789815051452-C5.html#r54)\]。

在 2020 年，面临的挫折数不胜数，但如果问任何数字爱好者是什么导致了他们公司的数字化转型，一个简单的答案就是 COVID-19。各种智能应用程序的开发，如 Aarogya Setu、Kwarantannadomowa、Trace Together、LetsBeatCOVID、COVID Watch、`etc.`，受到 IoT 和 BCT 结合的启发，当然还有迄今讨论过的其他新兴技术，例如可靠的数据共享、患者监测以及检查提供给患者的费用，都可以简单地由在后台运行的 BCT 提供支持。此外，它还可以为用户提供透明度 \[[55](#9789815051452-C5.html#r55)\]。虽然这场大流行确实带来了几种限制，但它也为许多数字创新打开了大门。此外，在过去几年中，人们已经意识到即使检查占用率也可能导致错误，因此可以提出一个框架来保护从该占用率收集的数据。收集的数据可以进一步提供给相关利益相关者，以进行更多认知研究工作 \[[56](#9789815051452-C5.html#r56)\]。

考虑到当今的情况，医疗领域被认为非常复杂、重要且发展迅速，该领域投入了大量资金。COVID-19 就是一个突出的例子。毫无疑问，多媒体已经采取了复杂的形式，两者之间存在着巨大的共生关系，从改善患者与医疗服务提供者之间的互动质量，到使用各种智能对象通过在线方式以图像、文本和音频等多种形式传输患者数据 `via`。但如果我们非常仔细地看待整个画面，我们会注意到管理整个数据并不容易，因为它不仅存在存储问题，而且人力成本和安全风险都相当严峻。这些 IoT 设备中出现的威胁也是由各种入侵者发起的，可能导致患者数据泄露和滥用。为了克服上述所有问题，BCT 可以被有效部署，因为它不仅提供了一个安全的框架，而且在实时场景中保护整个控制系统。当整个结果被模拟时，在 BCT 首次部署中看到了高达 86% 的成功率峰值，涵盖了产品丢失比率、伪造攻击、虫洞攻击和概率性身份验证场景等各个方面 \[[57](#9789815051452-C5.html#r57)\]。

IoT 应用程序和医疗系统使用非常精细的互连设备生态系统来改善医疗设施。我们非常熟悉，患有慢性疾病的人比非慢性病患者更频繁地使用医疗服务，这导致与前者患者相关的记录创建了不可篡改的印记。尽管技术进步或多或少，但为这个生态系统建立一种通用编程语言或通用通信协议仍然难以捉摸。因此，提出了一种系统，确保具有改进互操作性的 IoT 系统也可以在该特定基础设施中保护和保证节点之间的机密性，从而将整个工作量交给 BCT 使整个系统更加高效 \[[58](#9789815051452-C5.html#r58)\]。表 [**4**](#9789815051452-C5.html#t4) 提供了以前整合区块链和 IoT 以解决医疗问题的研究比较。
