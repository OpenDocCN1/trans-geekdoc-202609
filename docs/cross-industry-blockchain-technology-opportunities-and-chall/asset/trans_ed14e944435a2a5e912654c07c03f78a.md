

# Project Ubin

Project Ubin 于 2016 年 11 月启动，由新加坡 PSP、MAS 及行业合作伙伴共同实施。这是一项旨在探索 DLT 及其在新加坡金融市场基础设施中适用性的新加坡中央银行数字货币计划 \[[68](#9789815051452-C2.html#r68)\]。MAS 是新加坡的金融监管机构和中央银行。MAS 管理和控制 MAS 电子支付系统 (MEPSC) 和新加坡的 RTGS 系统。MEPSC 是一种金融市场基础设施，用于无纸化新加坡政府证券 (SGS) 以及 MEPSC 成员的新加坡国内批发间银行支付结算 \[[69](#9789815051452-C2.html#r69)\]。Ubin 第一阶段实施了基于以太坊 DLT 平台的中央银行数字货币，用于国内批发间银行支付结算 \[[69](#9789815051452-C2.html#r69)\]。第二阶段在 Quorum、Fabric 和 Corda 上增加了额外功能，以解决第一阶段出现的结算功能和数据隐私挑战 \[[70](#9789815051452-C2.html#r70)\]。Ubin 第三阶段开发了跨不同 DLT 平台的银行间支付结算和证券 DvP 功能。Project Ubin 的最终目标是为基于分布式账本技术的新加坡元存托凭证或代币化新加坡元提供功能，并分析其对新加坡金融市场基础设施的影响。

## Project Stella

欧洲央行和日本银行启动了 Project Stella，以分析 DLT 在两个司法管辖区金融市场基础设施中的可行性 \[[71](#9789815051452-C2.html#r71)\]。欧元区货币政策由欧洲央行实施。在欧元区，TARGET2 系统（高价值银行间交易结算系统）用于货币政策操作 \[[72](#9789815051452-C2.html#r72)\]。TARGET2 系统由欧元体系拥有和运营，欧元体系包括欧盟成员国国家中央银行和欧洲央行 \[[73](#9789815051452-C2.html#r73)\]。日本货币政策由日本银行（日本中央银行）实施。它管理日本的批发 LVTS 和 BOJ-NET。Project Stella 使用多个 DLT 平台，并分三个阶段实施。在第一阶段，核心 RTGS 功能和中央银行数字货币在 Fabric DLT 平台上实施。Project Stella 第二阶段实施了 Corda、Fabric 和 Elements 上代币化证券结算的 DvP 功能 \[[74](#9789815051452-C2.html#r74)\]。Project Stella 第三阶段旨在利用 DLT 提高跨境交易效率 \[[75](#9789815051452-C2.html#r75)\]。Fabric DLT 平台用于实施 Project Stella。

## Project Khokha

Project Khokha 于 2018 年 1 月由普华永道、南非储备银行、ConsenSys 和七家南非 CMB 共同启动，旨在利用 DLT 进行南非国内批发间银行支付结算 \[[76](#9789815051452-C2.html#r76)\]。Project Khokha 的目标是建立一个基于 DLT 的 RTGS 系统，使用代币化兰特资产进行南非银行间支付结算。其原型采用了 Quorum DLT 平台。在南非，RTGS 系统被称为南非多选项结算系统 (SAMOS)。SARB 拥有并管理 SAMOS，SAMOS 用于银行间零售支付义务、高价值银行间支付和南非证券结算。SAMOS 有能力在 RTGS 框架下每天处理约 70,000 笔交易（批发银行间），并在系统故障和紧急操作情况下，具备在两小时内处理每日交易的能力 \[[76](#9789815051452-C2.html#r76)\]。

## Project INTHANON

泰国银行与 R3 及其他组织合作，于 2018 年 8 月启动了 Project Inthanon，以评估 DLT 对泰国金融市场基础设施的能力 \[[34](#9789815051452-C2.html#r34)\]。Project Inthanon 分为两个阶段。Inthanon 第一阶段开发了一个基于 DLT 的分布式 RTGS 原型，针对泰国国内批发间银行支付结算 \[[34](#9789815051452-C2.html#r34)\]。在 Project Inthanon 第二阶段，开发了一个证券结算平台，用于管理、发行和结算泰国银行发行的代币化现金资产和代币化债券。

# SUMMARY

本章解释了分布式账本技术 (DLT) 及其在金融领域的应用。本章详细介绍了基于区块链的数字账本技术及其工作原理。已研究和分析了现有工作，以利用银行和金融领域的数字账本技术。研究了中央银行推荐的数字货币，以便更好地理解其适用性。讨论了分布式账本技术在金融服务背景下的工作原理。已探讨了 DLT 的优势、风险和挑战。详细阐述了 DLT 潜在应用的详细分析，包括金融包容性、跨境汇款和支付、智能合约。已突出介绍了银行和金融领域当前的 DLT 实践。简而言之，本章解释了 DLT 与金融领域的各个方面，以便更好地理解其在银行和金融领域的适用性。
