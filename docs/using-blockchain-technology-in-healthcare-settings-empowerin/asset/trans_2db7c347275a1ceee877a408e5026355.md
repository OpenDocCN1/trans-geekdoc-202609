

# EHRs 概述

EHRs 是一种以数字形式记录患者医疗数据，并通过应用程序或在线方式向用户显示的系统，使用户在需要时能够随时更轻松、更快速地访问。EHRs 可以存储姓名、年龄、身体质量指数（BMI）、病史、实验室检测结果、过敏史、免疫状态等个人统计数据，以及更多信息。所有这些类型的数据都会通过患者创建的账户显示给患者，患者可以随时访问查看，没有任何限制。此外，这些数据还会显示给医生，用于用药和诊断目的 \[[1](#index_split_018.html#filepos910252)\]。

EHRs 可以提供多种优势，有助于改善医疗服务。EHRs 还为专业人员和患者提供了便捷的访问和高效的护理。此外，EHRs 的另一个好处是有助于消除和降低将数据插入数据库时的人为错误风险。同时，EHRs 可能帮助患者更好地理解自己的数据，并了解每个术语的含义，从而使他们能够追踪健康状况并获得改善健康的动力。与 EHRs 相关的另一个好处是，它们通过数据挖掘的帮助，为增强研究和数据分析做出了贡献。使用 EHR 数据更容易识别趋势和模式，这些趋势和模式有助于发现新的冥想或药物，或新的疾病类型 \[[2](#index_split_018.html#filepos910675)\]。

另一方面，EHRs 也可能涉及一些会影响患者的缺点。EHR 实施可能成本高昂，需要大量资金或投资者来启动这项技术，包括软件开发、硬件以及参与构建的人员薪资成本。此外，EHRs 可能会给患者和医疗服务提供者带来一些困难，因为这是一项新技术，医疗服务提供者可能没有时间来适应它。一些患者，尤其是老年人，可能难以使用 EHR 技术。EHRs 存储与患者医疗数据相关的敏感数据，可能包含一些私人数据，因此存在数据泄露以及数据安全和隐私问题的潜在风险 \[[3](#index_split_018.html#filepos911263)\]。

EHR 安全性将是每位研究者都力求实现的目标，因为这是需要尽快解决的挑战之一。解决或增强 EHR 的安全性可能有助于患者，并提升患者对最新技术的信任，从而更多地使用它。我们需要提高 EHR 系统安全性的另一个原因是，存在保护患者数据的法律和道德义务，有一项名为《健康保险可携性和责任法案》（HIPAA）的法律。确保 EHR 的安全性也意味着确保数据完整性，保护其免受未经授权的修改，并确保患者数据免遭窃取并出售给可能怀有不良意图的第三方。此外，保护患者医疗数据将防止身份盗窃和任何其他欺诈行为 \[[4](#index_split_018.html#filepos911722)\]。

区块链技术可以提供数据完整性，并确保数据仅由授权用户访问，且数据未发生任何修改。区块链还可以保护存储在网络某处的患者数据 \[[5](#index_split_018.html#filepos912105)\]。数据完整性可以通过不同的区块链机制和功能来实现，其中一些功能包括密码学、共识机制、智能合约、许可型和非许可型区块链以及哈希函数（参见 [图 11.1](#index_split_018.html#filepos828480)）。

区块链技术使用密码学，密码学是编写秘密代码的科学，除了发送者和接收者之外，任何人都无法理解，以确保数据的机密性。此外，区块链的另一个用途是智能合约，它可以确保并验证数据在传输过程中未发生变化。哈希函数也包含在区块链技术中，无论消息的大小如何，它始终生成固定大小的输出，作为函数的输入。哈希函数可以为患者数据以及数据完整性提供安全性 \[[6](#index_split_018.html#filepos912519)\]。

区块链技术及其一些功能可以集成到医疗保健中，并通过使用区块链的各种功能来增强 EHR 的安全性。例如，区块链可以促进医院之间数据的便捷增强，同时保持交换数据的安全性。区块链技术的加密功能可以提供患者医疗记录的数据机密性，并安全地存储它们，以确保数据安全和隐私 \[[7](#index_split_018.html#filepos913129)\]。

文献调查的目的是进行分析，并对其他研究者的解决方案以及他们使用的功能、函数、技术和方法进行全面研究，尤其是与区块链技术相关的内容，以增强 EHR 的安全性，因为这是对人类最重要的数据之一。通过创建和开发最佳解决方案，应对其他作者和研究人员使用区块链技术所面临的所有挑战，并增强电子健康记录的安全性，从而为改善医疗服务做出贡献。在调查了区块链领域研究者开发的解决方案后，我们将了解每个解决方案，然后建立使用区块链保护 EHR 并提升安全性和隐私性的解决方案 \[[8](#index_split_018.html#filepos913568)\]。

## 11.2 电子健康记录概述

EHRs 是一种将患者数据以数字化方式存储的方法，其中包含与患者相关的医疗信息部分，如用药史、过敏史、实验室检测结果，以及 BMI、年龄和姓名等个人信息。EHRs 的建立旨在方便在不同医疗地点之间安全且更便捷地共享患者数据，使医疗服务提供者能够访问数据、检查患者健康状况并提供诊断 \[[9](#index_split_018.html#filepos914001)\]。

EHRs 带来了多种好处。其中一些主要优势包括：

*   > 与传统的患者数据存储方法相比，效率和生产力得到提升。

*   > 减少手动插入数据的时间，从而降低人为错误和失误。

*   > 减少冗余，并改善不同医院之间共享数据的一致性。

*   > 降低支出成本，因为转向 EHRs 可能减少购买纸张的需求，并将支出集中在其他可能必要的资源上。

*   > 由于消除了人工手动输入记录，准确性将大幅提高。

*   > 使患者能够轻松访问自己的数据，并相应监测健康状况。

*   > 法律和法规合规性，包括为维护患者健康数据部分的安全性和隐私性而制定的不同法律。
