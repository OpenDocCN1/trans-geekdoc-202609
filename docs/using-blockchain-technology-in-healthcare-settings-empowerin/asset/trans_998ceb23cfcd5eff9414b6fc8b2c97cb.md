

# 医疗保健中的数据安全

数据安全是医疗保健领域的一大关切问题。大多数医疗保健组织过时的 IT 架构使其容易受到恶意软件和其他攻击的威胁。敏感的健康数据被集中存储。区块链技术可以通过更轻松地共享、处理、管理数据并最大限度地降低与数据相关的安全风险，帮助医疗保健行业实现数字化 \[[23](#index_split_014.html#filepos623987)\]。此外，医疗保健行业安全、可靠且安全地整合其可用的众多数据集所需的计算机程序、战略规划和基础设施的发展仍处于早期阶段。

# 区块链技术的基本理念

本节阐述了区块链技术的基本理念，以帮助读者更好地理解文章的其余部分。根据 \[[7](#index_split_014.html#filepos617720)\]，区块链考虑了几种数字账本，这些账本为了安全地存储数据，会同时复制到相关系统上的多个位置。分布式账本技术（DLT）的一个更具体的定义是区块链，它是同时在多个站点上维护的数据库。根据 \[[8](#index_split_014.html#filepos618097)\]，区块链中的每个数据块除了包含内容外，还有一个指向前一个数据块的指针。区块链是一个由链接数据块组成的网络，这些数据块通过指针在共享记录中连接，每个数据块都由哈希地址表示。

## 7.8.1 去中心化

与由单个个人监督的传统数据库不同，区块链是一个去中心化的网络，类似于带时间戳的记录表，并经过加密以防止欺骗和操纵。当我们谈论与区块链相关的去中心化时，我们指的是决策权从中央组织转移到去中心化网络。使这项技术如此重要的原因是其去中心化的存储架构，这改善了数据身份验证和系统安全性 \[[38](#index_split_014.html#filepos630478)\]。

每个块还包含交易数据、时间戳和前一个块的加密哈希。它还包含所有先前块和交易的历史记录，这些可以用于构建网络或链。对任何块的数据集进行任何更改都会触发一系列事件，最终可能导致整个区块链冻结。一旦区块链处理了数据，连接到网络的每台机器都会同时锁定，从而创建数据的不可逆记录。每个区块链系统都指定谁可以作为修改机构将块添加到网络以及如何操作 \[[28](#index_split_014.html#filepos626241)\]。一旦信息被放入数据库中的某个块，就无法编辑或修改数据。

## 7.8.2 信任与透明度

新块正确添加到系统后，所有参与者都将能够访问更新后的区块链。数据块不会被添加到区块链中；相反，如果它有缺陷，则会被销毁。参与者使用共识技术作为验证机制，以确认数据块是合法的。通过使用共识技术，参与者可以快速就数据块的有效性达成一致 \[[39](#index_split_014.html#filepos630892)\]。在区块链上，已被捕获和存储的数据对潜在用户可见，并会迅速更新。区块链的透明度可能使数据更难丢失或被篡改。

## 7.8.3 安全性与隐私性

区块链是一种保护块中数据和交易信息免受外部、内部、恶意或意外威胁的技术。利用 IT 和安全策略、工具及服务来识别和降低风险并为威胁提供相关解决方案是常见的做法。区块链隐私是指投资者或组织区别于其他数据并因此能够以可识别的方式进行通信的能力。它是指在不泄露私人信息的情况下进行交易的能力。用户还可以通过谨慎的自我披露来保持合规性 \[[40](#index_split_014.html#filepos631260)\]。

## 7.8.4 可用性与鲁棒性

区块链结构是安全的。由于其缺乏集中所有权以及网络中医疗数据的统一块存储，它没有单点故障 \[[41](#index_split_014.html#filepos631689)\]。在没有中央机构的情况下，多对一的流量被消除，所有参与节点的资源都用于确保灵活性和弹性。这种方法解决了单阶段故障的问题，并消除了延迟。

## 7.8.5 可验证性

区块链确保数据的准确性和完整性，即使在没有相应记录明文的情况下也可以进行验证。在医疗保健行业中，处理保险索赔和管理制药供应链需要验证记录时，此功能非常有用 \[[42](#index_split_014.html#filepos632090)\]。数字账本软件通过在区块链上的所有节点之间实现多次共享重复，使所有医疗保健数据都易于验证并可供所有网络用户使用。区块链会在预定的时间段后自动更新，以确保数据的完整性和文件同步。

# 7.9 医疗保健中的应用

## 7.9.1 区块链层方法

区块链、应用、共识、智能合约和交易构成了区块链各层的技术基础。这些组件被分为几组，对应于区块链生态系统。

## 7.9.2 数据管理

为了采用以患者为中心的策略来存储医疗记录，并确保与医疗记录处理要求（例如患者指定的授权策略）相关的患者隐私和安全性，已建立一个系统以促进 EHR 数据的安全、可靠管理、分发和汇总 \[[43](#index_split_014.html#filepos632502)\]。他们建议一种区块链技术，允许授权的 EHR 数据集成和共享。为了解决权限管理、数字版权管理、数据管理、数据完整性和数据共享问题，提出了 MedRec 系统用于医疗数据访问和权限管理。作者使用了三种不同类型的智能合约来管理大量的记录表示，即患者-提供者关系（PPR）合同、注册商合同（RC）和摘要合同（SC） \[[44](#index_split_014.html#filepos632926)\]。
