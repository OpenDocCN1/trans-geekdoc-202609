

# Zohrevand 和 Beznosov 的混合数据存储方案

Zohrevand 和 Beznosov \[[22](#index_split_009.html#filepos203369)\] 提出一种混合数据存储方案。他们提出一种混合解决方案，其中关键患者数据使用 IPFS 存储在链下，而基本元数据存储在链上。这确保了大文件不会使区块链臃肿，同时保持数据完整性和可追溯性。其优势在于高效的数据管理，但挑战包括确保链上和链下存储之间的数据同步一致。

# Ekblaw 等人的 MedRec 2.0

Ekblaw 等人 \[[15](#index_split_009.html#filepos200532)\] 介绍 MedRec 2.0。他们利用链下存储来存放患者记录，提高可扩展性。MedRec 2.0 的方法允许在链上引用医疗数据，而实际文件存储在链下。这最大限度地减少了区块链的存储负担，同时保持数据可用性。然而，管理链上引用与链下存储之间的数据同步和访问控制会带来复杂性。

# Kuo 等人的区块链混合架构

Kuo 等人 \[[23](#index_split_009.html#filepos203801)\] 提出区块链混合架构。他们的系统采用链下存储来存放医疗记录，提高可扩展性。患者数据被加密并存储在链下，而访问控制和权限通过区块链智能合约进行管理。这种方法解决了区块链可扩展性问题，同时确保数据机密性。不过，确保同步访问控制和数据可用性的潜在挑战需要谨慎考虑。

# Mohsin 等人的隐私保护 EHR 系统

Mohsin 等人 \[[24](#index_split_009.html#filepos204238)\] 提出一种隐私保护 EHR 系统。他们利用链下存储来存放加密的患者数据，确保只有授权方才能访问。链下存储支持高效的数据管理，同时保持患者隐私。然而，这种方法的潜在劣势在于解决加密链下数据与区块链上的访问控制机制之间的同步问题。

# Chen 等人的隐私与可扩展性探讨

Chen 等人 \[[25](#index_split_009.html#filepos204700)\] 探讨隐私和可扩展性。他们强调了像安全多方计算（SMPC）这样的链下解决方案，以在解决可扩展性问题的同时增强隐私。SMPC 允许在不暴露实际数据的情况下对加密数据进行计算，从而增强机密性和可扩展性。这种方法的优势在于有可能在计算过程中保护隐私，但将 SMPC 与区块链集成可能会引入集成复杂性。

在区块链支持的 EHR 系统中引入链下数据，成为优化可扩展性、隐私性和数据可访问性的关键考量。虽然链下存储提供了显著优势，但与数据同步、访问控制和系统复杂性相关的挑战需要精心规划，以确保区块链的优势与管理敏感且海量的患者信息的复杂性能够和谐统一。

# 2.6.5 监管合规

在不断发展的区块链支持的 EHR 领域，在利用去中心化技术优势的同时遵守严格的监管框架，引入了监管合规的挑战。区块链的透明性和不可篡改性与医疗数据的敏感性和受监管性质的交汇，需要仔细考虑，以确保患者隐私、数据安全和法律要求得到有效平衡。

# Pilkington 等人的区块链与 GDPR 兼容性研究

Pilkington 等人 \[[26](#index_split_009.html#filepos205030)\] 研究区块链与 GDPR 的兼容性。Pilkington 探讨了区块链与欧盟《通用数据保护条例》（GDPR）的兼容性。虽然区块链的透明性与 GDPR 的原则一致，但由于数据的永久性和“被遗忘权”，挑战随之而来。其优势在于促进透明性，但在区块链环境中解决 GDPR 的细微差别可能会带来挑战。

# Shaikh 等人的区块链与健康数据共享分析

Shaikh 等人 \[[27](#index_split_009.html#filepos205530)\] 分析区块链与健康数据共享。他们讨论了区块链在实现受控健康数据共享方面的潜力，同时解决 HIPAA 合规性问题。区块链的数据共享模型可以与以患者为中心的控制和隐私要求保持一致。然而，挑战包括在复杂的监管环境中集成区块链，并确保去中心化不会损害数据安全。

# Ouaddah 等人的区块链 EHR 与 GDPR 探讨

Ouaddah 等人 \[[28](#index_split_009.html#filepos206240)\] 探讨区块链 EHR 与 GDPR。他们提出了一种符合 GDPR 原则的基于区块链的 EHR 系统。患者通过智能合约控制数据访问，确保透明度和用户同意。其优势在于实现以患者为中心的数据共享，但将 GDPR 原则集成到智能合约逻辑中，并确保在不同司法管辖区合规，仍然是挑战。

# Yin 等人的患者同意与合规研究

Yin 等人 \[[16](#index_split_009.html#filepos200967)\] 强调患者同意与合规。他们的方法将患者同意与区块链相结合，确保符合 HIPAA 和 GDPR。智能合约管理同意和访问，增强患者控制权。其优势在于赋予患者权力，但挑战包括将复杂法规转化为可执行的智能合约，以及解决法规之间的潜在冲突。

# Yin 等人的 MedChain 隐私框架

Yin 等人 \[[29](#index_split_009.html#filepos206667)\] 提出 MedChain 的隐私框架。他们提出 MedChain 作为解决隐私问题和监管合规的方案。MedChain 采用基于属性的加密来符合数据保护法规。其优势在于在保持透明度的同时确保数据隐私，但潜在挑战包括向用户介绍合规机制，以及解决各种法规的复杂性。

*   > 区块链处理：区块链组件处理请求，并根据预定义规则和共识机制评估其有效性。
