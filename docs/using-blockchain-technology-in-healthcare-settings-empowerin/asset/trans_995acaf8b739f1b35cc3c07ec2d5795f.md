

# 区块链与物联网数据安全

区块链旨在在去中心化环境中提供数据可用性和防篡改能力。它不可更改，特别适用于改善物联网（IoT）数据的安全性、可用性和完整性，同时改善物联网应用 \[[1](#index_split_020.html#filepos1118709)\]。它是一种带有加密的分布式账本技术，可用于各种行业来创建防篡改的实时数据 \[[2](#index_split_020.html#filepos1119191), [3](#index_split_020.html#filepos1119653)\]。此外，该平台提供了一个可靠的物联网设备生态系统。

此外，物联网网络用于合适的任务；一些物联网设备的表现会优于其他设备。关键问题是被审查并找出哪些节点最合适。在正确的时间获得合适的节点并仔细选择它们，有助于减少与资源分配、网络寿命和数据采集可信度等相关的典型物联网不确定性 \[[4](#index_split_020.html#filepos1120112)\]。选择节点而不是优化节点数量和位置可能解决能源和路由问题 \[[5](#index_split_020.html#filepos1120561)\]。在此场景中，节点可以按顺序排列，并且在任何给定时间仅针对给定任务刺激一个子类别的节点。节点选择通过根据任务标准选择合适的节点子集来提高能源效率 \[[6](#index_split_020.html#filepos1120943)\]。此外，存在基于个体的选择（每个节点独立评估）和基于组的选择（将潜在集群作为一致单元评估并选择最优集）之间的选择。因此，评估集中于任务规范和约束 \[[7](#index_split_020.html#filepos1121386)\]。由于存在多种缺陷，特别是最新的选择技术不适合定位任务。因此，本研究利用区块链技术来增强系统的隐私和安全性。此外，引入边缘平台有可能提高系统效率、降低延迟并优化整体性能。在这方面，设计了一个优化模型，用于根据输入参数为特定任务选择合适的节点。研究人员的主要目标是最小化执行时间、功耗、响应时间和延迟，并最小化与卸载工作负载相关的处理成本。

# 资源分配与调度方法论

在这里，本研究的重点是基于线性优化模型的资源分配与调度方法论。线性规划（LPP）涉及一个单目标函数，需要在线性约束条件下最大化或最小化。但是，在实际应用中，LPP 对于不精确的目标函数和约束具有模糊的解。这种不精确性的性质可能是由于系数、常数和决策变量的随机性和/或模糊性引起的。因此，这些因素使系统难以处理。在这里，我们在调查中考虑了模糊不确定性。为了处理模糊性，我们可以应用模糊规划技术。因此，模糊规划与 LPP 相结合。

# 模糊线性规划问题

众多研究人员专注于模糊线性规划问题。同时，在 1970 年，\[[8](#index_split_020.html#filepos1121785)\] 在决策问题中提出了模糊线性规划的概念。然后，\[[9](#index_split_020.html#filepos1122139)\] 提出了处理模糊不确定性的优化问题的一般概念，而 \[[10](#index_split_020.html#filepos1122487)\] 在模糊参数存在的情况下制定了线性规划问题。一般来说，如果纳入模糊不确定性，我们会得到两种类型的 LPP。这些是模糊 LPP（目标函数模糊或约束模糊）和完全模糊 LPP（目标函数和约束均模糊）。

在这方面，许多研究人员提出了不同的方法来解决模糊线性规划问题。这里讨论了一些相关的研究工作。作者 \[[11](#index_split_020.html#filepos1122861), [12](#index_split_020.html#filepos1123241), [13](#index_split_020.html#filepos1123678), [14](#index_split_020.html#filepos1124042)\] 在模糊线性规划问题（FLPP）领域做出了贡献，并开发了许多方法来寻找最优解。在这方面，\[[14](#index_split_020.html#filepos1124042)\] 引入了完全模糊线性规划问题（FFLPP）。此外，作者 \[[15](#index_split_020.html#filepos1124432), [16](#index_split_020.html#filepos1124881), [17](#index_split_020.html#filepos1125272), [18](#index_split_020.html#filepos1125675), [19](#index_split_020.html#filepos1126098)\] 提出了几种方法，使用不同类型的模糊数来解决 FFLPP。鉴于此，研究人员提出了不同的方法来解决 FFLPP。这里讨论了一些相关的研究工作。在 \[[15](#index_split_020.html#filepos1124432)\] 中，作者使用词典法来解决 FFLPP。在 \[[18](#index_split_020.html#filepos1125675)\] 中，作者提出了一种方法来解决带有梯形模糊数的 FFLPP，而 \[[20](#index_split_020.html#filepos1126546)\] 使用了一种修改技术来解决带有三角模糊数的 FFLPP 以获得最优解。此外，\[[21](#index_split_020.html#filepos1126975)\] 提出了一种方法，使用排序函数来解决带有无限制模糊变量的 FFLPP 的非线性模型。此外，各种类型的模糊数被纳入调查。但也注意到，同一系统在不同场景下需要优化两个或多个目标函数。因此，有必要研究带有不确定性的多目标线性规划问题（MOLPP）。

经济学、社会科学、工程和医学领域中出现的许多复杂问题可以用带有不确定性的 MOLPP 来表述。最初，带有模糊参数的 MOLPP 是由 \[[22](#index_split_020.html#filepos1127415)\] 提出的。然后，\[[23](#index_split_020.html#filepos1127790), [24](#index_split_020.html#filepos1128176)\] 提出了一种方法来解决 MOLPP，以在模糊不确定性下找到最优解。在 \[[25](#index_split_020.html#filepos1128584)\] 中，作者针对带有模糊系数的 MOLPP，该系数可以通过参数表示转换为区间。此外，\[[26](#index_split_020.html#filepos1128943)\] 包含了基于切割的灵活约束，用于求解模糊多目标二次规划问题。此外，从最近的研究中发现，不确定性是由于在处理区间时出现的误差估计而产生的。有不同的方法来处理 MOLPP，以求解作为区间的目标函数系数和带有区间参数的问题 \[[27](#index_split_020.html#filepos1129407), [28](#index_split_020.html#filepos1129826)\]。在此背景下，\[[29](#index_split_020.html#filepos1130222)\] 提出了一种新型的区间类型三角模糊数与 MOLPP。
