

# 7.9.3 数据安全与隐私

一些作者通过实施基于区块链的安全医疗系统（SHS）架构，建立了一个安全且私密的医疗系统。本研究证实，在 SHS 中部署区块链技术可能有效解决传统 SHS 所面临的问题和障碍。此外，提出了该系统的架构。\[[48](#index_split_014.html#filepos634801)\] 提出并开发了一种基于区块链智能合约的物联网支持智能医疗设备及医疗系统的访问控制模型。此外，他们在私有以太坊区块链上构建了一个方案。

研究方法考虑了整个医疗系统。为了说明所选的分散式、以患者为中心的智能合约授权系统，给出了一个示例用例 \[[6](#index_split_014.html#filepos617312)\]。作者还建议一种主动的基于智能合约的分布式访问控制系统。

\[[26](#index_split_014.html#filepos625238)\] 描述了一种基于区块链的远程健康监测（RHM）系统。为了在不经过其他服务的情况下安全地将患者数据与医生通信，该研究利用 Tor 伪装的链外数据传输服务。基于多种威胁实例，文章对该方案的安全性进行了评估。\[[49](#index_split_014.html#filepos635161)\] 中描述的建议新型去中心化访问控制系统基于 Tangle，并让用户控制谁可以访问其资产。该程序验证工作，并使用自动化验证互联网安全协议和应用（AVISPA）工具进行检查，这些工具即使在攻击者存在时也能验证安全性。

# 7.10 结论

综上所述，区块链技术可能有助于解决医疗行业面临的一些当前问题。由于总账和与块相关的基础设施，区块链技术在医疗领域中研究最充分的应用包括安全性、完整性、去中心化、可用性和身份验证原则。这些应用具有最大的前景。医疗行业正努力跟上以智能、互联的物联网和传感设备为中心的快速发展的技术基础设施。虽然这些技术使医疗行业能够更轻松地在连接日益增长的世界中为患者服务，但攻击者也可以利用此类创新以及用户和流程行为中的缺陷来获取访问权限并复制信息，从而使医院交换记录变得更加困难。这可能导致数据过时，进而导致健康问题或不准确的诊断，甚至导致验证患者身份出现问题。本章声称，本研究提出了区块链技术在医疗领域应用的多个用例，并将涵盖未来在该领域具有潜在应用的技术。然而，目前缺乏足够的研究和原型实现来评估这些使用场景的效率。该分析还强调了创建基于区块链的医疗应用的当前最先进水平，以及该领域存在的差距和未来研究的潜在方向。
