# Abb. 422. Gelbe Pestwurz

Pestwurz (Petasites hybridus).

Die Pestwurz ist eine ausdauernde, 20 bis 30 cm hohe Pflanze aus der Familie der Korbblütler. Sie wächst bevorzugt an feuchten Standorten wie Ufern, Gräben und feuchten Wiesen.

Die auffälligen Blütenstände erscheinen im zeitigen Frühjahr noch vor dem Austreiben der Blätter. Die Blätter sind herzförmig bis nierenförmig und werden sehr groß. Die Pflanze wird auch als Heilpflanze geschätzt.

In der Volksheilkunde wurde die Pestwurz bei Husten, Krämpfen und Migräne eingesetzt. Heute findet sie auch Verwendung in der modernen Phytotherapie.
