建议的方法是开发一个事务跟踪流程图，追踪交易和数据类型通过各种服务器和网络。这应是对应用程序将如何工作的一种功能性和逻辑性视图——即交易将如何发生、哪些系统将参与交易管理，以及这些系统将在何处支持业务目标和组织的产品价值链。需要识别数据源和数据接口，并且需要对处理的信息进行分类。这样就可以表示完整的事务流程。（参见图 30.1。）
