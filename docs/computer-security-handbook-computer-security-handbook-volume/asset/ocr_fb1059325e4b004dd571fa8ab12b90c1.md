# LLM智能体上下文工程

LLM智能体上下文工程（Agent Context Engineering）

+   一、上下文工程背景
+   - 大模型上下文窗口限制
+   - 上下文长度对模型性能的影响

+   二、上下文工程概念
+   - 高效利用有限的上下文窗口
+   - 系统化管理输入信息的方法论

+   三、上下文管理技术
+   - 上下文压缩、截断、摘要
+   - 检索增强（RAG）与信息排序

+   四、上下文结构设计
+   - 层次化上下文组织
+   - 系统提示词与角色设定

+   五、上下文工程应用
+   - 智能问答与对话系统
+   - 复杂任务执行与多步骤推理
