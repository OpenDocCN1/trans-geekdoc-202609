# OpenStack Block Storage (Cinder) 从入门到精通

本文将以简洁有效的方法，带领读者学习OpenStack Block Storage（Cinder）的核心概念、架构体系及实践操作，包含从基础的安装配置到高级的常见故障排查方法。

# 1. Cinder 概述

Cinder是OpenStack中提供块存储服务的组件，它类似于传统的存储区域网络（SAN），为虚拟机提供持久化的块设备。

# 2. 核心组件

+   - cinder-api：接收外部API请求
+   - cinder-scheduler：负责卷的调度
+   - cinder-volume：管理卷的生命周期
+   - cinder-backup：提供备份功能
