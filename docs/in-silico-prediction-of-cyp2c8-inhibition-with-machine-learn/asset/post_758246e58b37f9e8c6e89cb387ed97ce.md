# 4. DISCUSSION

## 4.1. Comparison of Different Machine-Learning Algorithms

The built 45 binary classification models exhibited different predictive performance. To test whether the difference in performance reach the threshold of statistical significance, we used AUC as the criterion to perform analysis of variance on different types of models (Tables S3 and S4). The analysis results suggest that the performance of the different models has statistical significance. On this basis, we compared the built models from two aspects, machine-learning

algorithms and molecular fingerprint. In this section, we focus on the machine-learning algorithms.

Among the top five models, three of them were built using SVM and the other two were based on LR. This demonstrated that these two algorithms had better performance for predicting CYP2C8 inhibitors than other algorithms. The models built on KNN performed poorly. For example, the AUC values of the Gra-KNN and AP2D-KNN models rank lower, which are 0.77 and 0.76, respectively. Furthermore, the models based on SVM performed better than LR among different fingerprints. As shown in Figure 2, the AUC value of SVM is higher than that of LR when using the AP2D fingerprint.
