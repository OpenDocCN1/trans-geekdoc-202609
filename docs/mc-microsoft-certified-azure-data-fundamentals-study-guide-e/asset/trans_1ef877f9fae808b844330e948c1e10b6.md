# 评估测试答案

1. B. 数据处理的速度定义为按计划批处理或实时流式处理。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

2. D. Lambda 架构具有用于批处理数据的批处理层和服务层，以及用于流处理数据的速度层。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

3. C. 遵循 ACID 属性时，事务数据库必须确保事务持久，并且在数据库从故障重新联机后可用于查询。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

4. B. Azure Data Factory 可用于编排数据处理管道中的数据流。它可以安排不同转换活动发生的顺序，并允许用户合并错误处理逻辑。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

5. D. Azure Synapse Analytics 专用 SQL 池是一种关系数据库产品，遵循分布式多并行处理架构。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

6. A. 文档表示 NoSQL 数据库（如 Azure Cosmos DB 或 MongoDB）中的用户定义内容。表、索引和视图是关系数据库的核心组件。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

7. B. Azure Blob Storage 针对存储对象（例如图像和遥测数据）进行了优化。它也是分布式分析平台（例如 Azure Databricks 和 Azure HDInsight）使用的数据的最佳数据存储。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

8. D. ETL（提取、转换和加载）方法已用于构建商业智能解决方案多年。该方法涉及从源系统提取数据，将其转换以符合业务规则，并将其加载到用于分析的数据模型中。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

9. C. 将数据符合预定义架构称为架构即写入。相比之下，架构即读取是从存储位置读取数据时定义架构的过程。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

10. A. Azure Data Factory 映射数据流是一种图形工具，使数据工程师能够从一个或多个源系统提取数据，通过一系列不同的活动转换数据，然后将数据加载到目标数据存储中用于报告。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

11. C. 控制流用于强制执行数据移动和数据转换活动的正确处理顺序。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

12. A. Azure Synapse Analytics 无服务器 SQL 池是一种交互式服务，允许开发人员查询 ADLS 或 Azure Blob Storage 中的数据。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

13. B. 诊断分析使用历史数据来回答不同事件发生的原因，而指令性分析回答为实现特定目标应采取哪些措施。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

14. B. 柱形图显示分类数据的聚合。有关详细信息，请参阅 [第 1 章](#c01.xhtml)。

15. A. 列存储索引以列格式压缩数据，非常适合在执行聚合时进行的大规模数据扫描。有关详细信息，请参阅 [第 2 章](#c02.xhtml)。

16. C. 虚拟机是 Azure 中的基础设施即服务 (IaaS) 产品。这些产品允许组织将硬件基础设施管理卸载到 Azure，同时提供服务在本地环境中托管方式的镜像。Azure VM 上的 SQL Server 选项允许组织完全控制操作系统和数据库引擎，而无需托管任何硬件。有关详细信息，请参阅 [第 2 章](#c02.xhtml)。

17. B. Azure SQL 数据库是 Azure 中完全托管的 PaaS 关系数据库。硬件、操作系统和数据库引擎完全由 Microsoft 管理，使开发人员能够专注于应用程序开发，而无需花费时间实现备份管理、高可用性、灾难恢复和高级威胁防护等数据库功能。有关详细信息，请参阅 [第 2 章](#c02.xhtml)。
