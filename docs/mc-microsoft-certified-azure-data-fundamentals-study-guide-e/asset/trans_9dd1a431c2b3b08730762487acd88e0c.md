## 3. 选择 API

创建 Azure Cosmos DB 帐户的首要要求是选择最适合其将要服务的工作负载的 API。“选择 API”选项页面允许你从五个 API 中进行选择。[图 3.5](#c03.xhtml#c03-fig-0005) 是该页面的屏幕截图。就本示例而言，我们将选择 `Core (SQL)` API。

## 4. 配置“基本信息”选项卡

“创建 Azure Cosmos DB 帐户”页面包含六个选项卡，具有不同的配置选项，可根据你的需求定制 Azure Cosmos DB 帐户。让我们先探索“基本信息”选项卡中可用的选项。除了下面描述每个选项的列表外，你还可以在 [图 3.6](#c03.xhtml#c03-fig-0006) 中查看该选项卡的完成示例。

1. 选择将包含 Azure Cosmos DB 帐户的订阅和资源组。如果你尚未创建资源组，可以在此页面上创建一个新资源组。

2. 为 Azure Cosmos DB 帐户输入名称。

   ![图 3.5 选择 Azure Cosmos DB API。](images/c03f005.png)

   [图 3.5](#c03.xhtml#R_c03-fig-0005) 选择 Azure Cosmos DB API。

3. 为帐户选择主要 Azure 区域。

4. 选择是要为 Azure Cosmos DB 预配吞吐量，还是让 Azure Cosmos DB 使用无服务器来管理吞吐量。

5. 最后一个选项允许你选择是否要将免费层折扣应用于此 Azure Cosmos DB 帐户。这样你就可以在帐户中免费获得前 1000 RU/s 和 25 GB 存储空间。每个订阅只能为一个帐户启用此选项。

## 5. 配置“全局分发”选项卡

“全局分发”选项卡允许你为帐户启用异地冗余、多区域写入和可用性区域。这些选项也可以在部署后进行配置。

## 6. 配置“网络”选项卡

“网络”选项卡允许你为 Azure Cosmos DB 帐户配置网络访问和连接。网络配置有三个选项可供选择：`All networks`、`Public endpoint (selected network)` 和 `Private endpoint`。

1. `All networks` 允许来自任何网络的应用程序访问帐户。此选项将网络隔离作为数据安全组件从 Azure Cosmos DB 配置中删除。

2. `Public endpoint (selected network)` 将 Azure Cosmos DB 配置为使用防火墙，仅允许来自特定 IP 地址的访问。这包括来自 Azure 门户、创建 Azure Cosmos DB 帐户的计算机的 IP 地址，以及 Azure VNet 中一个或多个子网中的 IP 地址的访问。[图 3.7](#c03.xhtml#c03-fig-0007) 说明了此配置的示例。

3. `Private endpoint` 将 Azure VNet 中的 IP 地址附加到 Azure Cosmos DB 帐户，限制只能与 VNet 通信的应用程序访问。此选项还允许你从 Azure 门户和创建 Azure Cosmos DB 帐户的计算机的 IP 地址启用对帐户的访问。

   ![图 3.7 创建 Azure Cosmos DB 帐户：“网络”选项卡。](images/c03f007.png)

   [图 3.7](#c03.xhtml#R_c03-fig-0007) 创建 Azure Cosmos DB 帐户：“网络”选项卡。

## 7. 配置“备份策略”选项卡

“备份策略”选项卡允许你为存储在此 Azure Cosmos DB 帐户中的数据选择 `Periodic` 或 `Continuous` 备份策略。`Periodic` 设置允许你设置数据备份的时间间隔、保留率和区域冗余。`Continuous` 设置将在帐户发生更改后 100 秒内自动备份数据，包括对数据库、容器和项所做的更改。[图 3.8](#c03.xhtml#c03-fig-0008) 说明了 `Periodic` 备份策略配置的示例。

   ![图 3.8 创建 Azure Cosmos DB 帐户：“备份策略”选项卡。](images/c03f008.png)

   [图 3.8](#c03.xhtml#R_c03-fig-0008) 创建 Azure Cosmos DB 帐户：“备份策略”选项卡。

## 8. 配置“加密”选项卡

“加密”选项卡允许你选择数据加密是使用由 Azure 生成和管理的密钥，还是使用存储在 Azure Key Vault 中的自定义密钥。

## 9. 配置“标记”选项卡

“标记”选项卡允许你为 Azure Cosmos DB 帐户添加标记以进行成本管理。

## 10. 审阅 + 创建

最后，“审阅 + 创建”选项卡允许你审阅设计过程中所做的配置选择。如果你对为实例所做的选择感到满意，请单击“创建”按钮以开始预配 Azure Cosmos DB 帐户。

## 配置数据库和容器

部署 Azure Cosmos DB 帐户后，你可以开始添加数据库和容器来存储数据。你可以使用 Azure PowerShell、Azure CLI 和基础结构即代码模板添加这些对象。还有可用于构建 Azure Cosmos DB 对象的 .NET、Java、Node.js、Python 和 Xamarin SDK。就 DP-900 考试而言，让我们专注于使用 Azure 门户中的以下步骤配置这些对象：

1. 转到 Azure 门户中的 Azure Cosmos DB 页面，然后单击你最近创建的 Azure Cosmos DB 帐户。

2. 在 Azure Cosmos DB 边栏选项卡的左侧面板中，单击“数据资源管理器”。[图 3.9](#c03.xhtml#c03-fig-0009) 显示了此按钮的位置。

3. 数据资源管理器提供了一个基于 Web 的界面，用于与 Azure Cosmos DB 中的数据库、容器和项进行交互。欢迎页显示该帐户中的所有对象和数据，以及创建新任务（例如新数据库）的一些快速链接。可以在 [图 3.10](#c03.xhtml#c03-fig-0010) 中查看此页面。

4. 若要创建新数据库，请在“常见任务”下单击“新建数据库”。“新建数据库”页面为你提供了使用自动缩放或手动选项预配吞吐量的选项，以及如果使用手动选项所需的 RU/s 数量，或者如果使用自动缩放选项所需的最大数据库 RU/s 数量。[图 3.11](#c03.xhtml#c03-fig-0011) 是使用自动缩放选项且最大 RU/s 分配为 4000 的新数据库示例。

   ![图 3.9 Azure Cosmos DB 数据资源管理器按钮](images/c03f009.png)

   [图 3.9](#c03.xhtml#R_c03-fig-0009) Azure Cosmos DB 数据资源管理器按钮

   ![图 3.10 Azure Cosmos DB 数据资源管理器欢迎页](images/c03f010.png)

   [图 3.10](#c03.xhtml#R_c03-fig-0010) Azure Cosmos DB 数据资源管理器欢迎页

5. 若要为该数据库创建新容器，可以单击数据资源管理器页面左上角的“新建容器”按钮，也可以单击数据库名称旁边的省略号并选择 `New Container`。

6. “新建容器”页面为你提供了多个配置容器的选项。除了选择将托管容器的数据库外，你还可以为容器命名并设置分区键。此页面还允许你设置容器是使用专用吞吐量还是共享吞吐量。选中“为该容器预配专用吞吐量”复选框后，将为容器预配专用吞吐量。否则，容器将与数据库托管的其他容器共享吞吐量。[图 3.12](#c03.xhtml#c03-fig-0012) 显示了使用专用吞吐量的容器的配置。

7. 从此处，你可以开始通过数据资源管理器或应用程序向容器添加新项。

   [图 3.11](#c03.xhtml#R_c03-fig-0011) 新建数据库

   ![图 3.12 新建容器](images/c03f012.png)

   [图 3.12](#c03.xhtml#R_c03-fig-0012) 新建容器
