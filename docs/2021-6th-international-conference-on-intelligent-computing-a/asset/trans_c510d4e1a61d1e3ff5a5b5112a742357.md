

## C. 实验流程的建立

对于提取出的地质特征，可以使用多核学习（multiple kernel learning）作为回归方法来预测这些特征。在完成核学习训练后，井测数据可以作为模型的指标值。模型在目标上的误差可用于优化多核学习过程中的参数。

多核学习在选择输入特征方面具有较高的自由度。X 和 Y 坐标与核作为输入特征相关，所有输入特征均对应其他核特征。多核学习公式对应的模型所示：

```
$K(\tilde{x},\tilde{y}) = \mathbf{d} \cdot \mathbf{d} + e^{-\frac{(\tilde{x}-\tilde{y})^2}{2\sigma_1^2}} + \sum_{m=1}^{M} w_m e^{-\frac{(\tilde{x}-\tilde{y})^2}{2\sigma_m^2}}$
```

带有 X、Y 坐标上的参数 $a_i$（$x_1$ 和 $x_2$），所有输入特征对应其他核特征。多核学习通过 MKL 规则自动更新。它们被用于寻找井处的孔隙度测量值。

使用多尺度核方法，当输入数据非均匀分布或模型具有多尺度结构时，常数使得模型拟合更加灵活，使得多尺度核具有广泛的应用。

确定合成核学习方法后，下一个问题是优化合成核的参数。通常，合成核与支持向量方法结合，将目标投影到不同的优化问题中求解，例如 Boosting、半定规划、二次规划等方法。为了快速获得最优权重，这些算法有效地解决了多核学习过程。

本文使用了一种多尺度核学习算法 [10]，这是一种两层优化方法。第一层优化多核函数的权重，第二层求解支持向量回归问题。在权重空间中，可以使用梯度下降法。

## III. 提取地质特征与多核

### A. 地质特征提取

多核学习模型将处理和特征提取技术 [6] [11] 应用于地震数据，提取地震数据噪声的相关性并获取特征信息。

### B. 震波矢量特征

对于整体的一阶梯度 $z=f(x,y)$，梯度意味着函数在某点的导数沿该方向可以达到最大值，这可以表示为一个二维方向。通常，其在像素点处的导数可以用相邻像素之间的差值来近似。

每个像素的梯度通常定义为该像素与其像素梯度的最大值。使用一阶或二阶算子（卷积方法）获取原始图中像素的特征邻域，随后使用梯度算子对每个像素进行卷积。可以获得多个梯度算子。Sobel、Robson 和 Laplace 梯度也被用于此。

在油气勘探中，河道位置和边缘区域是重要的地质特征 [2]。地震属性的边界可以突出地震数据中变化剧烈的局部区域，并确定该区域埋藏的主要沉积体的边界。Laplace 梯度算子用于检测地震属性的边缘。

### D. 地物理参数的孔隙度预测

实验使用了多种组合特征来构建多核学习模型以预测孔隙度，包括使用不同输入方法的多核学习和单一支持向量回归核模型。模型的内部参数根据地震数据值和孔隙度值进行更新。

首先，我们使用地震数据（波阻抗）和坐标（X, Y）这两个输入特征构建多核学习模型，然后使用该模型预测孔隙度。可以看出，尽管使用地震数据和坐标分布的多核学习预测的孔隙度在井处存在一些异常点，且某些局部区域存在许多异常值，但这些无法通过地质结构和孔隙度值还原。

使用所有输入特征构建单一支持向量回归模型。除坐标以外的地质特征是从地震数据中提取的，代表了区域的静态地质解释。从上方看，多核模型与该小层的地下岩结构保持一致，存在许多具有相似孔隙度的小区域。这不符合实际储层物理参数的异质性，也违反了储层物理性质空间分布的自然规律。由于地质特征包含多尺度结构和更多异质信息，在高维空间中对模型进行的是线性回归。数据使用单一核进行映射，储层的多尺度结构将被汇总，无法准确反映数据的相关性和实际地质特征的准确性。

由于卷积处理提取地震数据的特征，数据的边缘信息可能会丢失，这对模型的整体预测产生影响。其次，多核模型中的参数没有经过优化，而是根据先验知识进行调整，这给最终模型带来了不确定性。特征的选择和聚类是人工完成的。本研究使用具有不同参数的基函数来提高能力。是否存在更好的核函数仍有待探索。

最后，我们构建了一个多核学习模型。我们从地震数据的多尺度表示（高斯平滑）中提取输入特征，然后使用具有强映射能力的高斯核从多个尺度提取特征。结果如图1所示。

在未来，机器学习在油气勘探和恢复中的应用可以使用多核学习或其他学习方法，对储层与其他变量的相关性进行深入分析和研究，形成机器学习应用于储层领域的完整理论，为油气田开发提供更精细的描述。
