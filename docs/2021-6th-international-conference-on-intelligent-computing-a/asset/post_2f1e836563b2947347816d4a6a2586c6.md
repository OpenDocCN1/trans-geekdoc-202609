## I. INTRODUCTION

Machine learning is a tool of research in many application fields. Its main idea is to obtain correlations between data to improve system performance. Machine learning focuses on how to extract hidden information from data, then produce a model or algorithm that can find this hidden information. Machine learning algorithms include such as support machines, decision trees, and Bayes classifiers.

The goal of machine learning is to obtain a model based on the training data and the actual target data. This model can estimate the relationship between input and output data, generally the dependency between input and output. By method of machine learning needs to, according to independent and dependent samples $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$, in a set of features calculation, then that nonlinear mapping can be performed implicit.

As a data-driven technology, machine learning is based on the principle that extracting dependencies from data is better than assuming some prior relationships. It will play a good role when the data dependencies are unclear or the model cannot be accurately described.

Mercer theorem: Let X be a compact set of $R^n$, $X\times X\to R$ is a continuous and symmetric function, if the integral of the function satisfies the positive definite condition in the Hilbert space

```
$\forall \ f(x,y) = \sum \lambda_i f_i(x)f_i(y)$
```

Then there must be a feature space F and a mapping $\varphi: X \to F$,

```
$k(x,y) = \varphi(x) \cdot \varphi(y)$
```

Mercer's theorem is a necessary condition for the kernel. In practical applications, the method used for learning models is to directly define the kernel, implying defining the feature space. At this time, we can use Mercer's theorem to test whether the kernel is valid. Or different kernels can be used.

Generally, the specific description of the target data is not known in advance, and it is difficult to define a kernel that matches the conditions. Then, the kernel function is selected and is often used based on non. Commonly used kernel functions include Polynomial kernel function, Radial basis kernel and Laplace kernel, can be used.

```
Linear kernel: $k(x_i,x_j) = x_i^T x_j$
```

```
Polynomial kernel function: $k(x_i,x_j) = (x_i^T x_j)^d$
```

Radial basis kernel:

```
$k(x_i,x_j) = \exp(-\frac{||x_i-x_j||^2}{2\sigma^2})$
```

Laplace kernel:

```
$k(x_i,x_j) = \exp(-\frac{||x_i-x_j||}{\sigma})$
```

Considering that the parameters of the kernel function can affect the complexity of the model and the modeling results, this paper adopts the basic kernel function and the Gauss kernel function, which has fewer parameters and can better solve nonlinear problems, as the kernel of the support vector.

### C. Basic of multiple kernel learning
