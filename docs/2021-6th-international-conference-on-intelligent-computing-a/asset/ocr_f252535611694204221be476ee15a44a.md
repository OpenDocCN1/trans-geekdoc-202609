**Abstract—** This paper describes the data-driven machine learning of the spatial distribution of geophysical parameters in petroleum and gas reservoirs. Multiple kernel learning is used to integrate multi-scale features, so that prior knowledge of the reservoir and seismic data can be efficiently combined. Geologic features can be extracted by clustering attributes from seismic data using machine learning technologies. Finally, the predicted values are used to adjust the model parameters, and the geological parameters of the reservoir are updated. The reservoir is reproduced using actual petroleum field data.

**Keywords—** vector regression; multiple kernel learning; reservoir modeling; feature extraction

The kernel function maps the input vector x to a high-dimensional feature space, making the non-linear mapping linearly inseparable into a linearly separable space, and uses a new learning method to solve the original regression problem. $x \to \phi(x)$

# I. INTRODUCTION

Machine learning is a tool of research in many application fields. Its main idea is to obtain correlations between data to improve system performance. Machine learning focuses on how to extract hidden information from data, then produce a model or algorithm that can find this hidden information. Machine learning algorithms include such as support machines, decision trees, and Bayes classifiers.

The goal of machine learning is to obtain a model based on the training data and the actual target data. This model can estimate the relationship between input and output data, generally the dependency between input and output. By method of machine learning needs to, according to independent and dependent samples $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$, in a set of features

As a data-driven technology, machine learning is based on the principle that extracting dependencies from data is better than assuming some prior relationships. It will play a good role when the data dependencies are unclear or the model cannot be accurately described.
