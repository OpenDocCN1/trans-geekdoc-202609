Although many geological features are used to construct a kernel support regression model, because geological features contain multi-scale structures and more heterogeneous information, linear regression is calculated for the model in a high-dimensional space. The data is mapped using a single kernel, multi-scale structures in reservoir will be compiled, and cannot accurately reflect the correlation of data and the accuracy of actual geological features.

Because the convolution processing extract features of seismic data, the information at the edge of the data may be lost, which has an impact on the overall prediction of the model. Secondly, the parameters in the multiple kernel model are not optimized, but adjusted according to prior knowledge, which brings uncertainty to the final model. The selection of features and clustering is done manually. This study uses a basis kernel function with different parameters to improve the ability. Whether there is a better kernel function remains to be explored.

Finally, we construct a multiple kernel learning model. We extract input features from the multi-scale representation of seismic data (Gaussian smoothing), and then use the Gaussian kernel with strong mapping capabilities, extract features from multiple scales. The result is shown in Figure 1.

In the future, the application of machine learning in gas and oil exploration and recovery can use multiple kernel learning or other learning methods to conduct in-depth analysis and research of the correlation of other variables in the petroleum reservoir, to form a complete theory of machine learning applied to the field of reservoir. Which provides a more refined description for petroleum and gas field development.

# IV. CONCLUSIONS

This paper discuss how to extract features of seismic data from petroleum exploration and reveals the reservoir geological information in implicit attributes. The use of multiple kernel learning can effectively utilize geological features and map them to reservoir models to integrate nonlinear or heterogeneous information in different scale spaces. For the prediction of porosity, multiple kernel learning is used to refine the correlation of the data from the geological features, combined with the porosity value of the target well in the logging data to predict the physical parameters of the reservoir.
