
# 2020 IEEE 智能计算系统最新进展 (RAICS)

**摘要** 标准 12 导联心电图（ECG）被心脏科医生广泛使用，但人工解释心电图可能非常耗时，并且取决于临床人员的技能。在这项工作中，提出了一种通过自动分析单导联心电图来检测心脏异常的方法，并在一个所有异常心律相似的综合数据集上进行了验证。所提方法将原始心电图信号作为卷积神经网络模型的直接输入。该数据集包含多种心脏状况，为了应对这种情况，利用了二分类策略，特别是使用了“孤对立”（one-against-all）分类器来补偿类别之间的不平衡。虽然数据集中的心电图信号长度可达 60 秒，但通过对信号进行自动处理，以较低的计算成本实现了相当的性能。使用所提方法，我们的方法实现了 0.8602 的得分和 0.8624 的 AUC。

在 R 间期研究心率变异性的技术、P、QRS 和 T 模式的分析 [6]、心律功率谱分析 [7] 以及基于熵的测量方法 [8]。然而，这些方法一直受到深度学习方法的监督。特别是卷积神经网络（CNN）已用于用于区分心电图信号 [9]，而不需要任何信号处理、特征提取和特征选择。

在这项工作中，单导联心电图信号被直接输入到一维卷积神经网络（CNN），用于在不进行预处理步骤的情况下检测心脏异常。长短期记忆网络（LSTM）是一种人工循环神经网络，特别适用于序列和数据序列分类。深度学习 LSTM 可以从过去的状态中进行学习和预测。在这项工作中，LSTM 与 CNN 用于多通道心电图信号的分类，如图所示。这允许网络共同学习特征表示以及特征之间的时间关系。

# I. 引言

心血管疾病（CVD）是全球首要死因。估计 2016 年有 1990 万人死于心血管疾病，占所有死亡人数的 31% [1]。在美国，心血管疾病是 2018 年 700 万人的死因（占所有死亡人数的 27%），并被认为是约 7 万人可避免的死因。

心血管疾病是心脏和循环系统的一组疾病。这包括诸如心律失常在内的各种异常情况。心脏异常的早期检测至关重要。心电图（ECG）是一种使用人体表面的电极记录心脏电活动的非侵入性方法。标准 12 导联心电图是诊断各种心脏疾病的广泛使用的工具。

然而，人工解释心电图是非常耗时的，并且取决于人员的技能 [5]。心电图信号的自动分析可以辅助心脏异常的诊断，心脏异常检测中的信号处理和机器学习技术引起了很大兴趣。

传统上，这通过使用各种信号处理、特征提取和特征选择来实现。

论文的其余部分结构如下：第二节描述了本工作中使用的数据集，以及 CNN-LSTM 分类方法和性能指标。实验结果在第三节给出，讨论和结论在第四节给出。

## A. 数据集

本工作使用的数据集包含 6,877 条 12 导联心电图信号记录，采样频率为 500 Hz [1]。这些记录来自 11 家医院，记录时长从 6 到 60 秒不等。此外，3,699 条记录来自男性受试者，其余来自女性受试者。

## B. 深度学习模型

在这项工作中，数据输入 1-D CNN，随后是 LSTM 层。数据集中心电图段的时长不同，但 CNN 要求是固定的。一些初步实验表明，将长度固定在 15 秒（7,500 个点）与固定在 60 秒（30,000 个点）的效果相似，使用 60 秒信号的显著缺点是计算成本。因此，所有信号长度通过零填充和裁剪固定在 15 秒。

图 2 提供了本工作使用的 CNN 体系概述。网络有五个卷积层，随后是批归一化层和修正线性单元（ReLU）。层中的滤波器数量分别为 15、10、10 和 4，每个步长为 1。每个卷积层的输出随后是大小为 1x1、1x10、1x1 和 1x3 的最大池化层，步长为 2。最后的池化层随后是 LSTM 层，然后是全连接和 softmax 层。dropout 层概率为 0.2，LSTM 层中的隐藏单元分布是不存在的。在这项工作中，末层使用交叉熵损失计算：

```
L = -\frac{1}{N} \sum_{i=1}^{N} c_i \log(y_i)
```

其中 `Y` 代表预测，`T` 训练目标，观测数，`K` 类别数，`c` 类权重。使用自适应估计（Adam）训练 CNN 模型。

```
\hat{m}_t = \frac{m_t}{1-\beta_1^t} \quad \hat{v}_t = \frac{v_t}{1-\beta_2^t}
```

分别，`\beta_1` 和 `\beta_2` 是超参数。模型的权重 `w` 随后更新为：

```
w_t = w_{t-1}-\eta\frac{m_t}{\sqrt{v_t+\epsilon}}
```

两个模型的输入完全相同，都是 12 导联心电信号记录。使用 CNN 模型，检测正常心律和右心律失常的平均值、F-score 和 AUC 分别达到 95.75%、0.7836 和 0.9947。在单个类别性能方面，检测 DLBBB 的最高达到 99.21%。设置初始学习率为 0.003，在 10 个周期内下降因子为 0.1。批量大小设为 128，并在 20 个 epoch 处停止训练。在检测 DLBBB 中，最高 F-score 为 0.9329，在检测 RRBBB 中 AUC 为 0.9902。检测 PAC 的结果为准确率 91.32%，AUC 0.9804 和 AUC 0.8388。

## C. 性能指标

所提方法的分类性能通过 10 折交叉验证使用准确率和 F-score（`F_1` 分）进行评估：

```
Accuracy = \frac{TP}{TP + FP + FN}
```

```
F-Score = \frac{2TP}{2TP + FP + FN}
```

同样，使用 CNN-LSTM 模型，平均 F-score 和 AUC 分别达到 96.16%、0.8026%。对于单个类别，检测 DLBBB 的准确率达到 99.11%，检测 RRBBB 的最高 F-score 为 0.9390，AUC 为 0.9990。检测 PAC 的准确率为 92.29%，(AUC) 为 0.9486，而 F-score 为 0.5876，其中 `TP` 是真阳性，`FP` 是假阳性，`FN` 是真阴性。
