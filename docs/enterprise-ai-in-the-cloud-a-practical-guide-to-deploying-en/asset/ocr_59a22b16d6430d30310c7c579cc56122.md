# Dealing with Missing Values

Missing values, such as missing sales data for some days, can result in your algorithms producing inaccurate results or failing. For missing values, either you can replace them with the imputation techniques, or you can simply remove the record. If you're using imputation techniques, you can fill the missing data with mean or median values, use the regression method, or use multiple imputation by chained equations (MICE) techniques.
