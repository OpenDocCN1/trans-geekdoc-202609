# ## AI Services

AWS provides high-level AI services, which are pretrained AI services that provide intelligent solutions for well-known use cases such as fraud detection, personalized recommendations, contact center intelligence, document processing, intelligent search, business metrics analysis, forecasting, quality control, cybersecurity, and so on.

These AI services can be incorporated into the applications and workflows and used to build end-to-end solutions in AWS.

> > NOTE AWS also provides prebuilt, industry-specific AI services, such as the industrial and healthcare industries.

# ## Amazon SageMaker

In the middle layer, AWS provides SageMaker. This tool is geared toward experts, such as data scientists and ML engineers, who can use it to execute the entire machine learning pipeline, all the way from data ingestion, labeling, data preparation, feature engineering, model building, model training, model tuning, model monitoring, and monitoring deployment.
