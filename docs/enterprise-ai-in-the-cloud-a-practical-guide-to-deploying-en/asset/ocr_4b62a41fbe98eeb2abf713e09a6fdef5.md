You can use logistic regression in the following situations:

| USE CASE REQUIREMENT | DESCRIPTION |
|---|---|
| Classification problems | When the outcome variable is binary, the outcome can be yes or no, true or false, and so on. In other words, it's a classification problem. |
| Large datasets | When the dataset is small, the model is likely to overfit. It is ideal for large datasets, as it can lend itself to computational efficiency and more statistical power to make more accurate predictions. |
| Interpretability | When you want the model to be interpretable, meaning you want to understand how the outcome is predicted based on the inputs. |
| Efficiency | When you want an efficient algorithm that can perform fast with fewer computational resources. |
