You can break that cycle down into the following phases:

+   > Defining the business goal
+   > Framing the problem as a machine-learning problem
+   > Processing the data (collection, preprocessing, and feature engineering)
+   > Building the model (testing, tuning, and evaluation)
+   > Deploying the model (inference and prediction)
+   > Monitoring the model

Note that these phases are not necessarily sequential and that there are feedback loops between some phases, such as problem definition and monitoring, data preparation and model building, and model development and model monitoring.
