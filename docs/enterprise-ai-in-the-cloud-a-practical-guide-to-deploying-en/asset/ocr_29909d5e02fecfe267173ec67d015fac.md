| AWS | AWS CloudTrail | > Tracks operations for AWS services.
> Stores logs in S3.
> Logs contain event name, user identity, event time, event source, and source IP address.
> Users can access logs directly from the AWS console.
> Integration with Splunk for downstream analysis.
> Tracks activities within the SageMaker instance.
> Good practice to create roles for each user for attribution during auditing. |
