# Use Case Example

The Google search engine is an excellent example of a trustworthy system. It has algorithms to ensure that results are shown based on the relevance of those websites to the search query. It also ranks the results and filters all the spam and malicious websites when presenting the results. It provides transparent and explainable results to the user regarding how it came up with those results. Google has also developed a set of ethical guidelines and principles and has explained to the users how they collect the data, protect, and use it by being transparent to the users. Google has built a reputation among users as a trustworthy search engine AI system.
