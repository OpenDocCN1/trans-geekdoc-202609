# # SYNCHRONIZING ARCHITECTURE AND CONFIGURATION ACROSS ENVIRONMENTS

You must ensure that the model performs consistently across multiple environments, such as development and production.

> NOTE Sometimes even a minor change in the architecture configuration can result in different inferences in different environments.

You must also ensure the model shows the same accuracy range across development, staging, and production environments. Any model that fails to show this level of accuracy should not be deployed in production. It becomes imperative as you scale your operations across multiple geographies and product lines.

# ## Ensuring Consistency in the Architecture

You can leverage infrastructure as code to ensure consistency in the architecture for both AWS and third-party components. Using AWS CloudFormation, you can manage the infrastructure as one unit and deploy them across multiple environments. It allows you to create, update, and delete an entire stack as one unit.
