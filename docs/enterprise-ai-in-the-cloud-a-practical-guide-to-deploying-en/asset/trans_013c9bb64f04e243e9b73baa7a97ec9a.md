

## 构建与购买决策

构建满足医疗保健 ML 平台需求的平台可能是一项艰巨的任务。您需要使用云提供商提供的最佳实践、开源和现成的服务和工具来定制整个堆栈。拥抱 MLOps 的自动化、监测和可扩展性对于实现平台目标至关重要。逻辑问题是是构建还是购买最佳实践解决方案。要有效回答这个问题，请执行以下练习中的任务。

## 实践练习：构建与购买 ML 平台

这是一项实践性体验式学习练习，允许团队成员基于公司需求对构建与购买 AI/ML 平台做出明智的决策。

使用表格，执行步骤以向您的领导团队提供关于构建与购买决策的建议。

| TASK NAME/DETAILS | ROLE | BUY | BUILD | DELIVERABLE/IMPORTANCE |
|---|---|---|---|---|
| **确定组织需求**<br>列出您的组织与 ML 平台相关的具体要求和约束。 | 业务分析师 | 请特别关注对定制和配置、集成性、供应商专业知识和支持的需求。同时考虑成本、可扩展性和安全要求。 | 考虑内部专业知识、成本、集成、可扩展性、培训需求以及对数据控制的需求等因素。 | ML 平台的组织需求全面列表 |
| **探索可用选项**<br>探索各种现成和开源的 ML 平台选项，并评估其优缺点。 | 数据科学家 | 评估功能、成本、社区支持、安全性和合规性等属性。还需考虑供应商支持和技能、易用性、可扩展性、集成能力、互操作性、培训和可升级性。 | 不适用 | 不同 ML 平台的比较分析报告 |
| **评估内部人才**<br>您的成功取决于支持任一场景的能力。 | 人力资源经理 | 您必须考虑供应商的 AI/ML 专业知识和支持。您需要一个更小的团队来实施和维护系统。评估您的内部技能和培训需求。 | 您需要 AI/ML 人才来构建、维护和运营平台，并且培训和开发需要大量投资。 | 关于内部人才现状和培训需求的报告 |
| **考虑互操作性**<br>确保所选的 AI/ML 服务和解决方案能与现有或计划中的系统无缝协作至关重要。 | IT 架构师 | 评估云提供商与其他系统的兼容性。通常，在其生态系统内集成更容易。存在供应商锁定的可能性。 | 您可以定制以确保与其他系统的最大兼容性，但这需要额外的资源和时间。 | 潜在 ML 平台互操作性评估报告 |
| **评估对平台的控制**<br>对于 AI/ML 平台，根据公司的特定需求，调整算法或更改架构的能力可能至关重要。 | IT 经理 | 对底层 AI/ML 算法和工具的控制有限，并且您可能需要依赖供应商的升级/发布周期来获取新功能。 | 您将对添加或修改功能等方面拥有更大的控制权。 | 不同选项提供的控制程度报告 |
| **探索开源支持**<br>开源工具提供更大的社区支持且更新频繁，因此值得考虑。 | 数据科学家 | 供应商可能不为开源 AI/ML 工具提供全面支持。有些工具可能仅与其专有工具配合使用。 | 您可以根据需要纳入尽可能多的开源组件，为您提供灵活性和创新速度。 | 各选项开源支持报告 |
| **估算上市时间**<br>您需要考虑在两种选项之间进行选择的时间紧迫性。 | 项目经理 | 由于预构建的 AI/ML 功能，您可以更快地部署，但仍可能需要定制和集成。 | 定制开发可能耗时，导致部署较慢。 | 各选项的预计时间表 |
| **评估成本**<br>在选择购买或构建时，您必须考虑初始成本和持续成本。 | 财务分析师 | 您会产生前期成本，可能伴有持续的许可或订阅费用。 | 可能存在高昂的前期开发成本，以及维护、升级和潜在修改的持续成本。 | 构建与购买的成本评估报告 |
| **审查功能要求**<br>您的选择将取决于您的特定业务和功能需求。 | 业务分析师 | 定制程度可能不高。可能无法满足所有特定要求。 | 通常可以满足大多数特定业务要求。 | 功能要求与可用选项一致性报告 |
| **审查可扩展性和灵活性**<br>随着业务增长，处理大量数据和复杂模型的需求也将增长。 | 数据工程师 | 供应商应能够扩展并适应您不断增长的数据和模型复杂性。 | 您可以从一开始就构建兼顾可扩展性的平台，并提供更大的灵活性。 | 各选项可扩展性和灵活性报告 |
| **评估供应商支持和升级**<br>AI/ML 领域在不断发展，这是从创新角度考虑的关键因素。 | IT 经理 | 供应商提供定期支持和更新，但您仍依赖于他们的更新周期。 | 您需要对支持和更新承担更大责任，这可能需要额外资源。 | 供应商支持和升级评估报告 |
| **分析安全性和合规性**<br>无论解决方案是购买还是构建，确保数据安全并满足法规合规性都至关重要。 | IT 安全官员 | AI/ML 云提供商应确保其解决方案符合 HIPAA 或 GDPR 等行业和法规合规标准。 | 您对合规流程拥有更大控制权，但这也意味着您需要在设计时考虑安全性和法规合规性，可能会增加复杂性。 | 各选项安全性和合规性报告 |
| **提出建议** | 项目负责人 | 就构建或购买 ML 平台提出建议 | | 构建或购买 ML 平台的建议报告 |

提示 在做出构建与购买决策时，请考虑人才、互操作性、控制、开源支持、上市时间、成本、功能要求、可扩展性、供应商支持和安全合规等因素。

## 在云提供商之间进行选择

在云提供商之间进行选择时，您需要考虑几个因素。以下练习可帮助您评估适当的标准。

## 实践练习：选择合适的云提供商

本实践练习的目的是帮助您全面了解不同云提供商（包括其优势和劣势），并为不同的 AI/ML 服务、平台和工具选择合适的云提供商或提供商组合，以最好地满足您公司的需求。

选择最佳云提供商所需的步骤如下：

| TASK | TASK OWNER | EVALUATION CRITERIA | DELIVERABLE |
| :--- | :--- | :--- | :--- |
| 识别云提供商。 | 团队负责人 | 列出您想要评估的云提供商的候选名单。 | 云提供商列表 |
| 评估对您的 AI 和 ML 项目至关重要的 AI/ML 服务和功能。 | 数据科学家 | 检查机器学习生命周期各个方面（例如数据处理、模型训练、测试、部署和监测）的 AI 和 ML 服务可用性。**提示：** 留意预构建模型、框架和开发工具的可用性。 | 各云提供商可用 AI/ML 服务和功能报告 |
| 审查可扩展性和性能，这对增长型企业至关重要。 | 数据工程师 | 评估可扩展性和性能（包括对分布式处理的支持），并比较其处理大量数据和高强度 ML 工作负载时的性能和延迟。 | 各云提供商的可扩展性和性能报告 |
| 审查数据管理和集成，在处理大型或敏感数据集时非常重要。 | 数据架构师 | 比较其在数据处理、标记和数据治理方面的支持，以及与行业特定数据集成的能力。 | 数据管理和集成能力报告 |
