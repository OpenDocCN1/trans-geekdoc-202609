+   > **Flexible and scalable:** This approach can provide flexibility and scalability of cloud deployment.
+   > **Greater control and security:** This approach can provide greater control and security through an on-prem deployment.

# # Blue/Green Deployment

Consider these characteristics of blue/green deployment.

+   > **Environment consistency:** In the blue/green deployment approach, you have two identical production environments running in parallel. You will continue the live traffic on the blue production environment, and the green environment will be used for the deployment. When a new version of the model is ready for deployment, you will deploy it first in the green environment to test it. Once it has been tested and found to be working fine, you will start directing the live traffic to the green environment. The blue environment will now become the backup.
