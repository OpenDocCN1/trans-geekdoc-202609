## 2.2 Python 版本

### ### 第一阶段

Python 在 1994 年 1 月的第一阶段开发并发布了其第一个版本，即 `Python 1.0`。函数式编程工具如 `reduce`、`filter`、`lambda` 和 `map` 是该版本实现的关键特性。`Python 1.2` 是 Rossum 先生仍在 `CWI` 工作时发布的最后更新。该版本于 1995 年出版。





1995 年，Van Rossum 先生在国家研究倡议公司（Company for National Research Initiatives）研究了他自己发明的语言 `Python`。他在那里发布了其他几个版本的 `Python`。随着 `Python 1.4` 的发布，`Python` 获得了一些自己新的且未知的特性。这些特性中，`Modula-3` 最常见。为了激发关键字参数的灵感，引入了 `Modula-3`。他们还通过 `Python 1.4` 中通过名称修饰（name mangling）实现了一种简单的数据隐藏形式。

Van Rossum 还引入了名为 `CP4E` 的“全民计算机编程”（Computer Programming for All）。他的目标是让普通人也能掌握编程，以及许多计算机编程语言所需的专业知识。`Python` 在这方面发挥了至关重要的作用。解释是 `Python` 拥有一种简单直观的语法。

## 3.1 Python 编译器

如果你有编程背景，需要知道编译器是一种用于代码翻译的应用程序，或者说是一种简单的软件，它能将你编写的代码从高阶计算机编程语言转换为机器语言，以便计算机能够理解。Python 有许多编译器，它们都有自己特定的计算机编程语言转换系统。许多程序员使用这些编译器来调试程序，或使代码具有可执行性，或为程序创建算法。

`PyCharm` 是大多数 Python 程序员在进行 Python 编程时最喜欢的 IDE 之一。

在本书的范围内，我们将讨论一些最好的编译器。

### NUITKA 编译器

`NUITKA` 是一个非常著名的 Python 编译器，用于编译和执行你的代码。`NUITKA` 将你编写的 Python 代码作为输入并进行编译和执行；它将你的代码转换为 C。在几乎每一个操作系统和平台上你都可以访问 `NUITKA`。`NUITKA` 定期更新，Windows、`MAC`、`UNIX` 以及其他操作系统变得非常用户友好。

`NUITKA` 的另一个特性是，你可以在未在工作站安装 Python 的情况下对其进行编码。

`NUITKA` 是一个基于 Python 的编译器，通常不支持任何其他语言。因此，对于 Python 开发，它拥有不同的功能和库。开发者还使用 `NUITKA` 来开发人工智能和信息科学程序。

### PYJS 编译器

许多专业级程序员和软件开发公司使用 `PYJS` 编译器作为 Python 的编译器。它是一种不同类型的编译器。它最广为人知的特性是它可以将 JavaScript 转换为你的 Python 代码。因为其在 Web 程序方面的独特特性，大多数网站开发者更倾向于这种编译器。

当我们谈论 `PYJS` 提供的独特特性时，`PYJS` 提供了运行时支持。这就是为什么 Web 开发者主要推荐将其用于 Web 应用程序和程序。它支持那些希望用 Python 编写代码并直接在网页浏览器上运行的人。`PYJS` 还会将你的 Python 代码解释为经过调试的 `JavaScript` 代码，这些代码可以在你指定的互联网浏览器上执行和运行。

此外，`PYJS` 是一个非常轻量级的编译器。此外，`PYJS` 还为运行时错误的调试提供了运行时支持。

### SKULPT 编译器

在你的网页浏览器中，`SKULPT` 编译器也可以直接执行编写的 Python 代码。你的 Python 代码变得更具执行性。在某个网站页面的博客中，`SKULPT` 最近被引入。要将你的 Python 代码转换为 HTML，也可以使用 `SKULPT`。你的代码还可以用 `JavaScript` 结构编译以供你的网页浏览器使用。

## 5.1 Python 变量

`Python` 标识符的另一个名称是“变量”。变量是一个指代机器或设备内存区域的术语。你不需要在 `Python` 中确定这些变量，因为 `Python` 是一种推断语言，足够智能对其变量进行排序。

此外，我们可以说 `Python` 变量是具有不同类型数据（如整数或字符）的内存位置。在 `Python` 中，变量是可更改和可操作的，因为它们使用了一组不同的操作。

无论如何，为了初始化，变量需要一个字母或下划线。建议使用小写字母作为变量名。两者在 `Python`、Sledge 和 Mallet 中都是特殊元素。

### 命名变量或标识符

标识符的情况是因素。为了构思程序中使用的字面系数和整数，使用了变量。对于 `Python`，以下是变量命名的标准。

*   字母或下划线 `_` 必须是标识符的核心字符。
*   除了核心字符外，每个字符可以是由 `"a-z"`、`"A-Z"` 排列的字母、下划线或 `"0-9"` 数字。
*   变量名不能包含任何空白区域或任何独特或不常用的字符，如 `! @, #`,百分，`^` 和 `*`。
*   变量名不能与 Python 程序语法中描述的词汇相似。
*   在 `Python` 中，区分大小写。
*   有效标识符实例：`n69`、`v`、`v69`。
*   无效标识符实例：`5a`、`v 69`、`x69`。

### 多变量赋值

在单一描述中，通常称为变量赋值，`Python` 帮助保留多个标识符的机会。它可以通过同时声明多个标识符的单一激励，或在不同时间将不同的属性分配给多个变量来实现。

打开 Python 控制台或 IDE 并编写声明变量的命令。


输出：对于输出，当你输入你的命令时

### 算术运算符

为了获得期望的结果，算术运算符被用于执行复杂的算术运算。在这种情况下，取两个操作数，并通过运算符在它们之间执行操作，从而产生某些期望的、唯一且绝对的值。

以下是 Python 中广泛使用且重要实用的算术运算符：

* 加法 `"+"`
* 减法 `"-"`
* 除法 `"/"`
* 乘法 `"*"`
* 取余 `"%"`

* 加法 `"+"`

该运算符用于两个操作数之间，执行加法或求和操作。

示例：
```
>>> n, v = 25, 25
>>> n + v
```
在这种情况下，你的控制台将打印
“50”

* 减法 `"-"`

该运算符取第一个操作数，并从第一个操作数减去第二个操作数。

示例：
```
>>> n, v = 25, 25
>>> n - v
```
在这种情况下，你的控制台将打印
“0”

* 除法 `"/"`

该运算符取第二个操作数并将第二个操作数除以第一个操作数，并根据你的性能给出商。

示例：
```
>>> n, v = 6, 2
>>> n / v
```
在这种情况下，你的控制台将打印
“3.0”

* 乘法 `"*"`

该运算符如前所述，在第一个操作数和第二个操作数之间执行乘法操作。

示例：
```
>>> n, v = 6, 3
>>> n * v
```
在这种情况下，你的控制台将打印
“18”

* 取余 `"%"`

该运算符负责除法服务，并接收余数作为你的产。

示例：
```
>>> c, w = 4, 2
>>> c % w
```
在这种情况下，你的控制台将打印
“0”

真：当你的第一个操作数大于或等于第二个操作数时，使用此运算符。

真：当且仅当两个值不等时，使用此运算符。

真：当你的第一个操作数大于第二个操作数时，使用此运算符。

### 为什么选择 AI 和 Python？

*   `内置库`：
    用于 Python 机器语言的 `Numpy`、`PyBrain` 以及用于高级计算的 `Scipy` 是这些库使得 `Python` 成为 AI 的正确语言。
*   `强大的社区`：
    全球的 `Python` 开发者通过论坛和指南提供支持和贡献，帮助编写代码。
*   `独立平台`：
    它通过极少的简单代码更改即可灵活地使用各种操作系统。
*   `OOPs 脚本和概念选择`：

*   `Pandas`：
    它为 `Python` 提供了易用的数据结构和计算方法，是一个开源库。

    这是一个 2D 绘图库，为出版生成高质量图像。
*   `AIMA`：

*   `PyDatalog`：
    这是一个 `Python` 逻辑编程引擎。
*   `Easy`：
    它被用于构建 AI 游戏的基础双玩家 `Python` 引擎。（例如：Negamax）（仅限法语）
*   `PyBrain`：
    一种简单但强大的机器学习算法，用于评估和比较预定义的环境。
*   `PyML`：
    双边 SVM 和其他内核方法系统。并支持 `Linux` 和 `Mac OS X`。
*   `Scikit-Learn`：
    最流行的机器学习库是一个非常强大的数据分析平台。
*   `MDP-Toolkit`：
    学习算法是管理且无人的，可以扩展到网络架构的使用。
*   `NLTK`：
    自然语言工具包用于语言数据和文档中的文本解释以及自然语言处理的研究与开发。
