# **Comparison with FINDER**

In work using DRL, the agent is trained to learn the strategy that maximizes disconnectivity across nodes. The DARN approach addresses this problem by using a value function with a deep neural network. The Q network estimates the expected reward of taking action a in state s. Here, the agent selects a selection of nodes to remove, and we use node vectors from multiplex representation as action embeddings. The state represents the current configuration of the multiplex network, where all nodes are neighbors of the unit state. The reward r is designed to quantify the impact of node removal on the network connectivity: measured rewards using the decrease in the size of the LMCC.

MultiDismantler builds on foundational ideas of FINDER. Both methods use a deep learning for network dismantling; also, they use techniques such as neural representation, reconstruction and loss for cost-action interaction. However, FINDER aims at finding the cost of removing the target connected component in a single network. MultiDismantler aims to solve radically different dismantling problems, they differ in key aspects. For example, MultiDismantler uses the GAN-based version of FINDER. MultiDismantler operates on a GNN, whereas FINDER targets with an advantage on a single-layer graph. For a detailed discussion on differences and similarities between MultiDismantler and FINDER, see Supplementary Section I.
