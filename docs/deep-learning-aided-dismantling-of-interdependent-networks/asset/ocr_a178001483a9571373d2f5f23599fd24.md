# Dismantling multilayer interdependent networks

**Problem formulation.** We consider a network consisting of two layers of interactions. Nodes in the two layers are one-interdependent. For simplicity but without loss of generality, we do not make a distinction between one layer and the other layer, as we treat them as if they all belong to the same set of nodes. We represent the network as $G = (V, E^1, E^2)$, where $|V|$ denoting the total number of nodes, and $E^l$ are the edges in layer $l = 1$. The generic element of the adjacency matrix of layer $l$ is $A^l_{ij} = 1$ if $(i, j) \in E^l$ and $A^l_{ij} = 0$ otherwise.

Large-scale connectivity of the network is quantified by the fraction of nodes belonging to the LMMC of our network. Let $P(S) = \frac{|S|}{|V|}$, where $|S|$ is the number of nodes in the LMMC and $|V|$ is the number of nodes in the initial LMMC. When all nodes are present in the network, $P(S) = 1$. If we remove nodes belonging to a subset $S \subset V$, if $S = \emptyset$, then $P(S) = 0$.

Network dismantling, often referred to as the dismantling problem, can be seen as a constrained optimization problem.

```
$S^*(C) = \arg \min_{S} P(S),$$
```

The constraint is imposed on the cost $C$ of removing elements from the set $S$. In this article, we consider three types of cost: (1) unit cost, (2) degree cost and (3) resource cost. In the unit-cost version, the cost function associated with the set $S$ is its size, so $C(S) = |S|$. The degree-cost version is defined as $C(S) = \sum_{v \in S} d_v$, where $d_v$ is the degree of node $v$ in the graph $G$. We denote $d_v^{(l)}$ as the degree of node $v$ in layer $l$, the sum over nodes $v$ in the set $S$, with the nodes in $S$ counted only once. In the random-cost version, the cost associated with each node $i$ is given by $F(i) = X_i$, where $X_i$ is extracted from a distribution with average 0.5 and variance 0.1, or the Poisson distribution with average value of 1.

An important aspect in the characterization of the optimization problem is the identification of the minimum-cost set of nodes that can lead to the disappearance of the multicast LMMC. Such define

```
$S^*(C) = \arg \min_{S: C(S) \leq C} P(S),
```

Essentially, only $S$ that reduce $P$ below the threshold value are considered solutions to the problem:

Approximating the multilayer network dismantling problem. All algorithms considered in this article construct approximate approaches to the dismantling problem sequentially, ensuring that the set proposed for the solution is built by adding one element at a time. With indicate, $f_1, f_2, \dots, f_n$, are the labels of the nodes added according to the order and then. We define $S_t = \{f_1, \dots, f_t\}$, the approximate solution of the algorithm when the set is composed of respectively elements. If $S_0 = \emptyset$ and $S_n = V$, we clearly have $P(S_t) \geq P(S_{t+1})$ and $F(S_t) \leq F(S_{t+1})$ for all $t=1, \dots, n$.

We evaluate the performance of an approximate algorithm by measuring the AUD,

```
$C = \frac{F(S)}{F(V)},$
```

Note that both AUDC and $C$ are defined in the initial [0, 1]. Also for metrics, low value indicate good performance of the dismantling problem, whereas values close to 1 denote poor performance.

We provide details about the encoder, decoder, and dismantling strategy used in Multilayer.

Encoder. The framework of the MGNN is shown in Figure 5. MGNN consists of an intralayer graph convolutional neural and layer attention module to aggregate information from different layers.

Initializing features in network embedding plays a crucial role in building a solid foundation and convergence. Drawing insight from the initialization method used in FINDER, MGNN utilizes a multilayer MLP to encode features

```
$H^{(l)} = \text{ReLU}(W_l X^{(l)}),$$
```

Where $X^{(l)}$ is the normalized degree of node $i$ in layer $l$ (defining the degree of a node by the maximum degree of a node in layer). $\text{ReLU}(\cdot)$ is the activation function, $W_l$ is a weight matrix and $\cdot$ denotes the l2 normalization.

Using the initialized features we apply the intralayer graph convolutional network to the node embeddings by iteratively aggregating information from the node's features and the representations of its.

```
$H^{(l)} = \text{ReLU}(W_l H^{(l-1)} + U_l \cdot \sum_{j \neq l} H^{(j-1)}),
```

In equation (l), $H^{(l)}$ represents the embedding of node $i$ in layer $l$ for the forward propagation step. It captures $h$ hidden information. $W_l$ and $U_l$ are weight matrices, and $N^{(l)}$ denotes the set of neighbor nodes in layer $l$. The final representation can be represented as $H^{(L)}$.
