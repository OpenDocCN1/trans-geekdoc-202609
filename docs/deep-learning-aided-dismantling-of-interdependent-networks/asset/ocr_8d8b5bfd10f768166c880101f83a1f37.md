To represent a network, we add a first virtual node (denoted) in each layer; all nodes are neighbors of the virtual node, but vice versa. With the MGNN model, we learn multi-layer node attention mechanism ($	heta_l$), MultiDisismant decodes multiple networks, including the embedding of virtual nodes as well as the final embedding of each node. Subsequently, the agent decodes the embeddings using MLPs ($\phi_l$) and layer attention attention mechanism ($\psi$) to compute the expected return ($Q$) value of each node, which reflects the

that can be achieved by removing a node under the current network nodes. The agent uses an e-greedy strategy to remove nodes (red nodes); with probability $1-e$, it selects the node with the highest Q value; otherwise, it removes a random node. Considering dependencies between layers in the network, a cascading failure occurs after an agent removes a node, leading to removal of more edges (blue lines). After node operation, the agent decodes and reconstructs the residual network. Once the network is completely dismantled, the agent collects information in the form of $(s_t, a, r, s_{t})$ and stores them in an experience buffer. The agent learns by randomly sampling batches from the experience buffer to update policies.
