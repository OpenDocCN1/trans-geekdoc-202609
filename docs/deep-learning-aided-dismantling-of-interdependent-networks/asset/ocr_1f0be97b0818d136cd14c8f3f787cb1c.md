# Other algorithms

Here we described other algorithms used in our experiments. For instance, layer denoising algorithms, we explain how they are constructed and utilized in multiple networks. These generalized algorithms also use a global score to reach the maximum of a centrality centered metric estimated on each individual layer. This heuristic approach was refined by as a generalization of the targeted-attack protocol from single layer to one-to-one networks. We stress, however, that merging scores into a global score: future work could leverage a deep learning approach to infer the appropriate rule of score aggregation to maximize the performance of the results.

# Code availability

HDA. We assign a score to each node $s_i = k_i^{(k)}$, and $k_i$ is the degree of node $i$; which nodes are sorted by degree. We remove the node with the highest degree. When nodes share identical degree, we randomly select one of them. Once a node is removed, the degrees of the remaining nodes are updated.

The code developed for this research is available at https://doi.org/10.2443/CC038603882 (ref. 51).

CL. We use the advantage version of CL. In each layer, the score assigned to each node $i$ is a function of the number of other nodes at distance $u$; a tunable parameter. For $u=0$, the metric reduces to HDA. We use $u=1$ in our experiments, to assign a score to each node which maximizes the total score of the network. When a node is removed from the network, the scores of the remaining nodes are updated. The implementation of theCl algorithm is available via GitHub at https://github.com/cmfit/Cl

MinSum. We use MinSum to identify the interconnected component by their dismantling scores. The position of node $i$ in the dismantling process of layer is represented by $s_i = m_i/w_i$; we assign a score to node $i$ and remove the node with the smallest score. For nodes with the same score, we randomly select one of them. The implementation of the MinSum algorithm is available via GitHub at https://github.com/abaysalzer/dismantling

FINDER. FINDER uses a DRL framework to identify critical nodes of single-layer networks. It estimates the expected node that is removed from layer $l$. In multiplex networks, we assign to each node the score $s_i = \max(k_i^{(l)})$ and we remove the node with the highest score. We used the well-trained FINDER version in the unit scenario. A function implementation of FINDER is available via GitHub at https://github.com/TianFrankY/FINDER. For other requirements, such as degree and removal constraints, we retained the FINDER model with the same training parameters for Multilayer analysis.

NIRM. NIRM uses both local and global searching mechanisms to find the critical nodes in each layer. The score of node $i$ is given by $s_i = \max(k_i^{(l)}, m_i)$; where $m_i$ is the score of node $i$ in layer $l$. For nodes with identical scores, we randomly select one of them.
