

# 涉及人类参与者、其数据或生物材料的研究

关于涉及人类参与者或人类数据研究的政策信息。另见关于性别、性别（身份/表现）、性取向以及种族、民族和种族主义的政策信息。

- 关于和性别的报告：无性别和性别
- 关于种族、族裔或其他社会相关分组的报告：无种族、族裔或其他社会相关分组
- 人口统计特征：无人口特征
- 招募：无招募参与者
- 伦理审查：伦理审查

请注意，稿件中必须提供有关研究方案批准的完整信息。
