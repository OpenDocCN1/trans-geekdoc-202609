移除节点的影响可能不是立即产生的，并可能对网络连通性产生延迟影响。我们应用的 $n$-步 DQN 使用重放缓冲区中的 $n$-步回报，通过考虑多步的累积奖励来更好地捕捉延迟效应。它聚合了层表示和层间特征，使用通过累积奖励计算出的目标 $Q$ 值形成最终的节点嵌入。潜在动作 $a$ 下下一个时间步的直接奖励表示为 $\max_{a'} Q(s', a')$。解码器框架评估时间 $t$ 处动作 $a$ 的预测奖励，表示为 $Q(s, a)$。$Q$-learning 损失旨在最小化预测 $Q$ 值与目标 $Q$ 值之间的差异

NIRM. NIRM 使用局部和全局搜索机制寻找每层中的关键节点。节点 $i$ 的得分由 $s_i = \max(k_i^{(l)}, m_i)$ 给出，其中 $m_i$ 是节点 $i$ 在层 $l$ 中的得分。当得分相同时，我们随机选择其中一个。NIRM 算法的代码可在 https://github.com/cmfit/Cl 获取

FINDER. FINDER 使用 DRL 框架识别单层网络的关键节点。它估计从层中移除的节点。在多层网络中，我们为每个节点分配 $s_i = \max(k_i^{(l)})$ 并移除度最高的节点。我们在单元场景中使用训练良好的 FINDER 版本。对于其他需求（如度和移除约束），我们保留了具有相同训练参数的 FINDER 模型。FINDER 的函数实现可通过 GitHub

MinSum. 我们使用 MinSum 通过拆解得分来识别连通组件。节点 $i$ 在层拆解过程中的位置由 $s_i = m_i/w_i$ 表示；我们为节点 $i$ 分配得分并移除得分最小的节点。当得分相同时，我们随机选择其中一个。MinSum 算法的实现可在 https://github.com/abaysalzer/dismantling 获取。
