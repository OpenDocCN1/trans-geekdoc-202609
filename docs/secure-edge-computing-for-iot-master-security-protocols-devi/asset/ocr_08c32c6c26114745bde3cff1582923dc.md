# Key Terms

# Internet of Things

Radio-frequency identification (RFID) technology; RFID enables objects to be uniquely identified and tracked.

# Internet Engineering Task Force

Message Queuing Telemetry Transport; It is a standard-based messaging protocol, or set of rules, used for machine-to-machine communication.

Constrained Application Protocol; It is a specialized web transfer protocol for use with constrained nodes and constrained networks in the Internet of Things.

ZigBee is an open, global, packet-based protocol designed to provide an easy-to-use architecture for secure, reliable, low-power wireless networks.

Magnetic resonance imaging (MRI); This is a medical imaging technique that uses a magnetic field and computer-generated radio waves to create detailed images of the organs and tissues in the body.
