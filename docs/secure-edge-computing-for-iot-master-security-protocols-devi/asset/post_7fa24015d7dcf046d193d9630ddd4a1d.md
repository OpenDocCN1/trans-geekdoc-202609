## Introduction to Edge Computing Networking

Edge networking refers to a distributed computing paradigm that brings computational resources closer to the data source or end-users, reducing latency and improving overall performance. In traditional cloud-based architectures, data travels to centralized data centers for processing, which can result in delays and inefficiencies, especially for real-time applications. Edge networking shifts this approach by placing computing power at the ‘edge’ of the network, which could be in proximity to IoT devices, mobile users, or data-producing sensors. This decentralization enables quicker data analysis, faster response times, and greater efficiency, making it suitable for applications like autonomous vehicles, industrial automation, and augmented reality.

## Fundamentals of Edge Computing Networking

Edge networking is often referred to as a collection of multiple technologies that support connectivity for edge locations, edge devices, and edge computing. Unlike traditional cloud computing, in which data is transmitted to centralized data centers for processing, edge networking involves deploying computational resources and data storage capabilities at the periphery of the network, right at the ‘edge’. This means that data processing occurs close to where the data is produced, such as in IoT devices, sensors, or mobile devices.

## Understanding Edge LAN

Edge LAN, or Edge Local Area Network, is an innovative networking concept that pushes the boundaries of traditional LAN setups. While traditional LANs have typically centralized data processing and storage in a single data center, Edge LAN distributes these resources closer to the edge of the network, where users and devices are located.

Figure 3.1: Edge LAN Network Architecture

The network edge LAN sits within your network just outside the network core. It includes converging locations such as regional data centers, next generation central offices (NGCOs), fixed wireline access points, wireless access base stations, and radio access networks (RANs).

The network edge can also include on-premises locations such as universal customer premises equipment (uCPE) devices, on which multiple workloads such as software-defined wide area network (SD-WAN) and enterprise applications can be hosted in a single edge-computing device.

### Key Features of Edge LAN

- Proximity to Users: Edge LAN systems are strategically placed at the edge of the network, reducing latency, and improving user experience. This proximity is especially critical for latency-sensitive applications such as augmented reality, virtual reality, and online gaming.
- Distributed Computing: Edge LAN incorporates distributed computing resources, enabling faster data processing and real-time analytics. This approach is ideal for applications that require immediate data insights, such as IoT devices and autonomous vehicles.
- Resilience and Redundancy: Edge LAN systems are designed for high availability and reliability. By decentralizing data storage and processing, they reduce the risk of network failures disrupting operations.
- Security: With sensitive data often being processed closer to the source, Edge LAN can enhance security by minimizing data exposure during transit. Additionally, advanced security measures can be implemented at the edge to protect against threats.
- Scalability: Edge LAN architecture is highly scalable, and thus able to accommodate the exponential growth of connected devices and the increasing demands of data-intensive applications.

## Understanding Edge WAN

Edge WAN, or Edge Wide Area Network, is another groundbreaking networking paradigm that complements Edge LAN by extending its benefits beyond local environments to the broader geographical scope of wide area networks.

![](img/31919f230142cc926c349c85b30fe4d2_163_0.png)

Figure 3.2: Edge WAN Network Architecture

### Key Features of Edge WAN

- Global Reach: Edge WAN leverages a distributed network of edge nodes located in multiple geographic locations, ensuring high-speed, low-latency connectivity across vast distances. This is vital for businesses with a global footprint.
- Dynamic Routing: Edge WAN employs intelligent, dynamic routing algorithms that adapt to changing network conditions, optimizing data traffic, and minimizing bottlenecks. This results in consistent performance and reduced downtime.
- Edge Cloud Integration: By seamlessly integrating with edge cloud services, Edge WAN enables businesses to access cloud resources with minimal latency, unlocking the full potential of cloud computing for remote offices and users.
- Application Prioritization: Edge WAN can prioritize critical applications and traffic, ensuring that mission-critical operations receive the necessary bandwidth and low latency required for optimal performance.
- Cost Efficiency: By reducing the need for extensive backhaul to centralized data centers, Edge WAN can help organizations save on bandwidth costs and reduce their carbon footprint.
