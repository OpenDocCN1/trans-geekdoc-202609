### 边缘计算简介

边缘计算是一种将计算和数据存储更靠近数据生成源头（如传感器、设备或其他数据生成实体）的范式。与传统的云计算不同，传统云计算中数据被传输到中央数据中心进行处理，边缘计算在网络“边缘”本地处理数据。这种方法最大限度地减少延迟，减少对大量数据传输的需求，并实现实时决策。边缘计算利用设备、服务器和网关的分布式网络高效处理数据处理任务，使其成为现代去中心化计算格局中的关键组成部分。
