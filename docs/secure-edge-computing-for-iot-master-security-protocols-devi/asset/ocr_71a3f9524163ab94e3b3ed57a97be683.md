# Quality of Service (QoS) at Edge

Quality of Service (QoS) refers to a set of technologies and mechanisms
that allow network administrators to control and prioritize network traffic.
It ensures that critical applications and services receive the necessary
bandwidth and resources to function optimally, even during times of
network congestion. QoS is instrumental in guaranteeing a consistent and
reliable user experience for applications such as video streaming, online
gaming, VoIP communication, and more.
