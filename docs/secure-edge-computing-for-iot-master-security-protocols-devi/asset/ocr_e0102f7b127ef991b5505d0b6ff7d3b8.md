# Federated Learning Architecture

Federated learning is a decentralized learning approach in which the model is trained across multiple edge devices or servers, while keeping the data localized. A central server coordinates the learning process by aggregating model updates from the edge devices, without actually accessing the raw data. This architecture allows for collaborative learning, without compromising data privacy. Edge devices perform model training using local data, and only the model updates (not the data) are transmitted to the central server. The central server aggregates these updates to improve the global model, which is then redistributed to the edge devices. This iterative process continues, resulting in a continually improving and globally relevant model.

Another significant architecture for edge-based data analytics and machine learning is the Edge Computing with AI-on-the-Edge architecture.
