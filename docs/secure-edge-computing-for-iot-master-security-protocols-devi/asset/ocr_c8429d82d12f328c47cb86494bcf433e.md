# Edge Routing Protocols

One of the essential components of an edge computing ecosystem are the network protocols that facilitate communication between devices, edge servers, and the cloud. In this series of pages, we will explore various edge computing network protocols that play a pivotal role in enabling the seamless operation of edge computing environments.

Message Queuing Telemetry Transport: MQTT, short for Message Queuing Telemetry Transport, is a lightweight and efficient messaging protocol that has gained immense popularity in the realm of edge computing, particularly in the Internet of Things (IoT) ecosystem. It is known for its low overhead, making it perfect for resource-constrained edge devices. MQTT operates on a publish-subscribe model, allowing devices to send and receive messages in a scalable and flexible manner. It is well-suited for scenarios where data needs to be transmitted between edge devices and edge servers, or even from edge to cloud, with minimal delay.

HTTP/HTTPS (Hypertext Transfer Protocol/Secure): This is commonly used for web-based communication between edge devices and servers, including RESTful APIs.
