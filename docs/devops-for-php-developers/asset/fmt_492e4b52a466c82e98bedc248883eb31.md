
# Create MySQL Configuration Files

Create a new task file `configure.yml` under `mysql/tasks` and a new template file `my.cnf.j2` under `mysql/templates`. The template will be used to modify the default `my.cnf` file that comes with Percona.

## `templates/my.cnf.j2`

```
[mysqld]
default-authentication-plugin={{ default_authentication_plugin }}

# Disabling symbolic-links is recommended to prevent assorted security risks
symbolic-links = 0

# Memory settings.
max_allowed_packet = {{ mysql_max_allowed_packet }}
sort_buffer_size = {{ mysql_sort_buffer_size }}
read_buffer_size = {{ mysql_read_buffer_size }}
key_buffer_size = {{ mysql_key_buffer_size }}
myisam_sort_buffer_size = {{ mysql_myisam_sort_buffer_size }}
read_rnd_buffer_size = {{ mysql_read_rnd_buffer_size }}
table_open_cache = {{ mysql_table_open_cache }}
max_connections = {{ mysql_max_connections }}
group_concat_max_len = {{ mysql_group_concat_max_len }}
thread_cache_size = {{ mysql_thread_cache_size }}
join_buffer_size = {{ mysql_join_buffer_size }}
tmp_table_size = {{ mysql_tmp_table_size }}
max_heap_table_size = {{ mysql_max_heap_table_size }}

# InnoDB settings.
innodb_file_per_table = {{ mysql_innodb_file_per_table }}
innodb_buffer_pool_size = {{ mysql_innodb_buffer_pool_size }}
innodb_log_file_size = {{ mysql_innodb_log_file_size }}
innodb_log_buffer_size = {{ mysql_innodb_log_buffer_size }}
innodb_flush_log_at_trx_commit = {{ mysql_innodb_flush_log_at_trx_commit }}
innodb_lock_wait_timeout = {{ mysql_innodb_lock_wait_timeout }}

!includedir /etc/mysql/conf.d/
!includedir /etc/mysql/mysql.conf.d/
```

Let's also add some default values for use with a server of about 512MB RAM.

Edit `mysql/defaults/main.yml` and add the following variables.

## `defaults/main.yml`

```yaml
---
# defaults file for mysql
# caching_sha2_password is the default but most clients are not supporting it
default_authentication_plugin: "mysql_native_password"

mysql_max_allowed_packet: "64M"
mysql_sort_buffer_size: "1M"
mysql_read_buffer_size: "1M"
mysql_key_buffer_size: "256M"
mysql_myisam_sort_buffer_size: "64M"
mysql_read_rnd_buffer_size: "4M"
mysql_table_open_cache: "256"
mysql_max_connections: "151"
mysql_group_concat_max_len: "1024"
mysql_thread_cache_size: "8"
mysql_join_buffer_size: "262144"
mysql_tmp_table_size: "16M"
mysql_max_heap_table_size: "16M"
mysql_innodb_file_per_table: "1"
mysql_innodb_buffer_pool_size: "256M"
mysql_innodb_log_file_size: "64M"
mysql_innodb_log_buffer_size: "8M"
mysql_innodb_flush_log_at_trx_commit: "1"
mysql_innodb_lock_wait_timeout: "50"
mysql_root_password: "t00r"
mysql_grant_users:
  - name: "devops"
    password: "devops"
    host: "localhost"
    privileges: "*.*:All" # '*.*:ALL,GRANT' generates a "root" user
```

We can now copy the template file over to our server and replace the existing one. Once we are done with the configurations, we shall restart the MySQL server using the handler we created. We shall also ensure that MySQL is started on system boot.

We'll also create extra MySQL users who will have the permissions we need. Add as many as required under the `mysql_grant_users` variable. Also set a sensible password for root via the role variables. Lastly, we shall perform the secure installation and remove the test database and the anonymous user.

## `mysql/tasks/configure.yml`

```yaml
---
# mysql/tasks/configure.yml
- name: Update MySQL Configuration
  template:
    src: my.cnf.j2
    dest: /etc/mysql/my.cnf
    owner: root
    group: root
    mode: "0644"
    force: true
  notify: restart mysql

- name: Enable MySQL on boot
  service:
    name: mysql
    state: started
    enabled: true

- name: Disallow remote root login
  command: 'mysql -NBe "{{ item }}"'
  with_items:
    - DELETE FROM mysql.user WHERE User='root' AND Host NOT IN ('localhost', '127.0.0.1', '::1')
  changed_when: false

- name: Get defined hosts for root
  command: mysql -NBe "SELECT Host FROM mysql.user WHERE User = 'root' ORDER BY (Host='localhost') ASC"
  register: mysql_hosts
  changed_when: false
  check_mode: false

- name: Update MySQL root password
  shell: mysql -u root -NBe 'ALTER USER "root"@"{{ item }}" IDENTIFIED WITH mysql_native_password BY "{{ mysql_root_password }}";'
  with_items: "{{ mysql_hosts.stdout_lines | default([]) }}"

- name: Set MySQL root configuration
  template:
    src: "root-my.cnf.j2"
    dest: "/root/.my.cnf"
    owner: root
    group: root
    mode: "0600"
    force: true

- name: Create additional users
  mysql_user:
    name: "{{ item.name }}"
    host: "{{ item.host }}"
    password: "{{ item.password }}"
    priv: "{{ item.privileges }}"
    state: present
  loop: "{{ mysql_grant_users | default([]) }}"
  no_log: true

- name: Get defined hosts for the anonymous user
  command: mysql -NBe 'SELECT Host FROM mysql.user WHERE User = ""'
  register: mysql_anonymous_hosts
  changed_when: false
  check_mode: false

- name: Remove anonymous MySQL users
  mysql_user:
    name: ""
    host: "{{ item }}"
    state: absent
  with_items: "{{ mysql_anonymous_hosts.stdout_lines | default([]) }}"

- name: Remove MySQL test database
  mysql_db:
    name: test
    state: absent
  notify: restart mysql
```

The task above references a `root-my.cnf.j2` template file which stores the credentials for the root MySQL user. Create the file under `templates` and use the content below.

## `templates/root-my.cnf.j2`

```
[client]
user="root"
password="{{ mysql_root_password }}"
```

All that’s left is to include the two sub-tasks into `mysql/tasks/main.yml`.

## `mysql/tasks/main.yml`

```yaml
---
# tasks file for mysql
- name: Handle Percona Installation
  import_tasks: percona.yml

- name: Configure the database engine
  import_tasks: configure.yml
```

That should take care of our MySQL server. You should be able to log in to MySQL with the set password, and the other created users should also be able to log in.

# The PHP Role

Setting up PHP is usually easy. Since we are using PHP 7.4, we have an option of using the Debian maintained version or Ondrej’s PPA, but since a lot of people like having the flexibility, let’s use the latter. We shall set up PHP, [Composer](https://getcomposer.org/), and configure modules like `opcache`.

## Installs Subtask

Add a new subtask `installs.yml` which will hold our installation of PHP and other required binaries. We shall compile some modules like `redis` from source. The list of packages to be installed will be defined in `php/defaults/main.yml`.

## `php/defaults/main.yml`

```yaml
---
# defaults file for php
php_version: "7.4"
php_packages:
  - php-pear
  - "php{{ php_version }}"
  - "php{{ php_version }}-cli"
  - "php{{ php_version }}-common"
  - "php{{ php_version }}-curl"
  - "php{{ php_version }}-dev"
  - "php{{ php_version }}-gd"
  - "php{{ php_version }}-json"
  - "php{{ php_version }}-mysql"
  - "php{{ php_version }}-opcache"
  - "php{{ php_version }}-readline"
  - "php{{ php_version }}-sqlite3"
  - "php{{ php_version }}-xml"
  - "php{{ php_version }}-bcmath"
  - "php{{ php_version }}-bz2"
  - "php{{ php_version }}-fpm"
  - "php{{ php_version }}-intl"
  - "php{{ php_version }}-mbstring"
  - "php{{ php_version }}-soap"
  - "php{{ php_version }}-xsl"
  - "php{{ php_version }}-zip"
  - "php{{ php_version }}-imagick"
  - imagemagick
  - libmcrypt-dev
php_pecl_install:
  - mcrypt
  - redis
```

Changing the playbook's `php_version` (defined in `site.yml`) will also change the modules that will be installed since we are using the variable as a reference in all our modules. You can add as many packages above as needed. Each project will have its own specification of extensions that will be needed. If image processing will not be required, the image processing extensions like `imagick` can be removed.

There are two extra packages sourced from PECL. In our case, `mcrypt` and `redis`. Update `php/tasks/installs.yml` subtask and add:

## `php/tasks/installs.yml`

```yaml
---
- name: Add Ondrej PPA
  apt_repository:
    repo: ppa:ondrej/php
    state: present
    update_cache: yes
    mode: "0666"
```
