# 信息评估程序：增强决策的 5 个步骤

你需要更深入的信息分析。通过理想的信息分析程序和资源，海量零散的数据将变成一个简单、清晰的决策阶段。为了提高你的信息评估技能并简化决策，请在数据评估过程中实施以下五项措施：

## 第 1 步：建立你的查询
在组织或业务信息评估中，你必须从理想的查询开始。问题必须是可化的、简洁且清晰的。安排你的查询，以对你的特定问题或机会筛选或排除潜在答案。例如，从一个明确的问题开始：一家政府承包商正面临价格不断上涨，已无法发布具有竞争力的合同建议。在解决这一业务问题的几个问题中，包括：公司可以在不损害质量的情况下减少员工吗？

## 第 2 步：建立的衡量优先级
这一步分为两个子步骤：a) 选择量化的内容，以及 b) 决定如何量化。

### A) 选择量化的内容
以该承包商实例为例，考虑你想要什么类型的信息来回答主问题。在这种情况下，你会想了解现有员工的数量和价格，以及他们花费在核心业务目标上的时间比例。在回答此查询时，你可能需要回答几个子问题（例如，员工目前是否未充分利用？如果是这样，哪些流程开发可以有所帮助？）。最后，在你关于衡量衡的选择上，务必包含利益相关者可能拥有的任何合理理解（例如，如果员工减少，公司如何应对需求激增？）。

### B) 选择如何量化它
思考你量化信息的方式同样重要，特别是在信息收集之前，因为你的衡量程序将支持或削败你未来的调查。此项衡量需要问的关键问题包括：

*   你的时间跨度是什么？（例如：年度价格对比季度价格）
*   你的衡量单位是什么？（例如：`USD` 对比 `euro`）
*   必须包含哪些变量？（例如：仅年薪，对比年薪和人员福利成本）

## 第 3 步：收集数据
在明确了查询并确定了衡量优先级后，现在是收集你自己的数据了。在收集和组织信息时，请记住这些重要要点：

*   在收集新信息之前，确定可以从现有来源或可用数据库中收集哪些数据。收集这些信息。
*   预先决定文档保存和命名系统，以协助所有任务人员进行协作。此程序可以节省时间并防止员工重复收集相同的数据。
*   如果你必须通过访谈或观察来收集数据，请先创建一个会议模板以确保一致性并节省时间。
*   将你收集的数据组织在日志中，并记录日期，并在过程中包含一些其他来源说明（如所做的任何数据归一化处理）。这将有助于你未来的决策。





## 衡量 4：分析数据

在收集完回答第 1 步查询所需的理想信息后，是时候进行深层次的信息分析了。首先，通过几种独特的方式处理你的信息，例如通过反复挖掘来发现相关性，或者简单地在 `excel` 中制作透视表。视图允许你根据不同的因素对信息进行过滤和排序，并允许你计算信息的平均值、最大值、最小值和标准差——只需确保防范统计信息分析中的那五大危险即可。

在控制信息的过程中，你可能会发现已经获取了所需的精确信息，但更有可能，你可能需要更新最初的查询或收集额外信息。无论如何，这种对趋势、相关性、变体以及离群值的原始调查，将帮助你集中精力评估信息，以更好地回答你的查询以及他人可能提出的其他问题。

在此期间，信息分析工具和应用程序非常有益。`Visio`、`Minitab` 和 `stata` 都是用于复杂统计数据评估的良好软件软件包。但通常情况下，在决策工具方面，没有什么可以比拟 `Microsoft excel`。如果你对 `excel` 完成信息分析的每个目的需要回顾甚至入门教程，我们建议这门哈佛商业评论课程。

## 衡量 5：过敏影响

在评估你的信息并可能进行额外研究后，现在是时候转化你的结果了。在转化你的调查时，请记住你永远无法建立一个绝对真实的理论：相反，可能只是不拒绝假设。这意味着无论你收集了多少信息，机会始终可能阻碍你自己的结果。

在转化你的信息结果时，请询问这些关键问题：

*   信息能回答你最初的问题吗？如何回答的？
*   信息能让你抵御任何良心质疑吗？如何做到的？（注：此处原文 conscience 可能为 challenge 之误，根据语境理解为质疑/挑战）
*   你的决策是否存在某些局限？是否存在任何你没有考虑到的角度？

如果对这些解释在所有这些问题和考虑下都能站住脚，那么你可能已经得到了成功的决定。剩下的唯一步骤是利用数据评估程序的结果来确定你的最佳策略。

通过在信息分析过程中遵循这五项衡量措施，你为你的企业或政府服务创造了更好的选择，因为你的决策有了经过稳健积累和检查的信息支持。通过训练，你的信息分析将变得更快、更精确——这意味着你创造了更好、更有理智的决策来有效地开展业务。

## 什么是数据分析？数据评估被描述为一种对信息进行清洗、更改和建模的过程，旨在发现对公司决策有帮助的信息。数据评估的目标是从数据中提取有用信息，并根据信息分析结果做出选择。我们在日常生活中做任何选择时，实际上都在考虑上一次发生了什么，或者通过选择特定的选项来预测将要发生什么。这只是对我们的未来或过去进行评估并得出结论。为此，我们收集过去的记忆或对未来的幻想。这本质上就是信息评估。数据分析师为公司职能做的相同的事情，被称为数据评估。

为了发展你的公司，甚至是提升自己的生活，有时你想做的就是评估！如果你的公司没有增长，你就必须回头承认错误并重新制定策略，不再重复这些错误。如果你的组织正在壮大，你就需要领先一步，让公司增长得更久。你所做的就是检查业务数据和业务流程。

## 信息分析种类：方法和手段
根据公司和技术的不同，存在许多数据分析方法。重要的数据评估类型包括：
* 文本诊断
* 统计分析
* 诊断分析
* 预测分析
* 规范性分析
* 文本分析

### 文本评估
文本评估也被称为数据挖掘。它是利用数据库或数据探索工具在海量数据集中寻找模式的过程。它用于将原始信息转换为业务细节。市场上有很多商业智能应用，用于做出战略性的业务决策。总来说，它提供了一种提取和分析信息、得出规律并最终对其信息进行解读的方法。

### 统计分析
统计分析通过仪表板之类的之前的信息来揭示“发生了什么？”统计分析包含信息的集合、评估、解释、演示和建模。它分析一组信息或样本信息。评估分为两类：描述性评估和推断性分析。

* **描述性分析**：分析完整信息或甚至是概述的数值数据样本。它揭示了连续数据的平均值和标准差，而对于信息数据则显示频率和百分比。
* **推断性分析**：从全面数据中调查样本。在这种分析中，通过选择不同的样本，可以从相同的信息中发现独特的结论。

### 诊断分析
诊断分析通过在统计分析的渗透中发现源头，来揭示“为什么会发生？”这种评估有助于发现信息的行为模式。当你的组织流程出现新问题时，你就能开始进行这项调查，以定位问题的类似模式。此外，它可能提供机会针对你的新问题使用类似的处方。

### 预测分析
预测分析利用之前的信息来揭示“什么极有可能发生”。最简单的例子类似于：如果去年我根据自己的储蓄买了两件衣服，而本季我的工资增加了一倍，那么我可以买四件衣服。然而，当然这没那么简单，因为你还需要考虑其他条件，例如本季衣服成本的上涨，或者比起衣服你更想得到一辆新自行车，或者你必须买房子！因此，这种评估根据现在或之前的数据对潜在影响进行预测。预测仅仅是一种估计。其准确性取决于你拥有多少全面的信息以及你挖掘得有多深。

### 规范性分析
规范性分析结合了之前所有分析的渗透，以找出针对当前问题或结论应该采取哪些行动。大多数数据驱动型都在使用规范性评估，因为描述性和预测分析不足以改进数据功能。根据现状和问题，他们检查信息并得出结论。

### 机器学习策略
应用被分为特定的类。这些是：
- `supervised learning`：这种方法在教育期间，将输入和输出连同注释一起提供给计算机。计算机预测的有效性可以被分析。主要目标是让机器学会如何将输入映射到输出。
- `unsupervised learning`：在这样的情况下，不提供此类指令，使得计算机仅根据输出产生结果。无监督学习主要应用于非结构化信息。它被用于复杂任务。它使用另一种被称为深度学习的方法来得出少数结论。
- `reinforcement learning`：这种学习使用三个组件，即代理、环境和动作。代理人将是感知其环境的人，以及代理人在环境中交互和采取行动的情况。强化学习的主要目标是找到可能的策略。

## 机器学习是如何工作的？
机器学习利用了与数据挖掘相似的流程。计算围绕目标函数 (id) 明确，将输入信号 (x) 映射到变量 (y)。这有时表示为：
```
y=f(x)
```
同样存在一个误差 e 对应输入 x。因此，通用形式是：
```
y=f(x) + e
```

## 机器学习的技术是什么？
机器学习利用了与数据挖掘相似的流程。计算围绕目标函数 (id) 明确，将输入信号 (x) 映射到变量 (y)。这有时表示为：

- `supervised learning`：这种方法在教育期间，将输入和输出连同注释一起提供给计算机。计算机预测的有效性可以被分析。主要目标是让机器学会如何将输入映射到输出。
- `unsupervised learning`：在这样的情况下，不提供此类指令，使得计算机仅根据输出产生结果。无监督学习主要应用于非结构化信息。它被用于复杂任务。它使用另一种被称为深度学习的方法来得出少数结论。
- `reinforcement learning`：这种学习使用三个组件，即代理、环境和动作。代理人将是感知其环境的人，以及代理人在环境中交互和采取行动的情况。强化学习的主要目标是找到可能的策略。

机器学习的应用广泛应用于以下领域：
- 分类（Classification）：将数据分配到不同的类别中。
- 回归（Regression）：预测连续的数值。
- 聚类（Clustering）：将相似的数据点分在起。
- 降维（Dimensionality Reduction）：减少数据的维度，同时保留重要信息。
- 异常检测（Anomaly Detection）：识别偏离正常行为的数据点。

from scipy.optimize import fmin_cg, fmin_bfgs

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

class syntheticdata():

class logisticregression():
    def __init__(self, x_train=None, y_train=None, x_test=None, y_test=None, alpha=1):

        self.set_data(x_train, y_train, x_test, y_test) # 设置数据

        """设置数据。"""
        self.x_train = x_train
        self.y_train = y_train
        self.x_evaluation = x_test
        self.y_test = y_test

    def negative_lik(self, betas):

        id = 0
        for i in range(self.n):

            id += - (self.y_train[i] * log(p) + (1 - self.y_train[i]) * log(1 - p))

        return predictions

*   **监督学习**：监督学习使用标记数据来训练算法。这种机器学习非常常见，用于根据历史数据预测结果。
*   **无监督学习**：无监督学习不使用标记数据。相反，它专注于发现数据内部的隐藏模式或结构。这通常用于聚类和关联。
*   **半监督学习**：半监督学习结合了监督和无监督学习的元素。它用于标记数据稀缺或获取昂贵，但未标记数据充足的情况。
*   **强化学习**：强化学习是机器学习的一种，代理通过在环境中执行操作以最大化奖励来学习做出决策。它基于试错法。

## 核心概念与应用
*   **自动化**：`ai` 可以自动执行重复任务，提高效率。
*   **智能系统**：`ai` 帮助创建能够适应新信息的系统。
*   **自然语言处理**：这允许 `ai` 理解并处理人类语言。

## 案例研究：谷歌搜索
谷歌搜索引擎现在是信息科学的一种商品。它利用 `predictive evaluation`（一种由 `artificial intelligence` 使用的方法）为消费者提供智能效果。例如，如果有人在谷歌搜索引擎上输入“greatest coats in NY”，`ai` 就会通过系统学习收集这些信息。今天，当个人在搜索工具“ideal location to purchase”中写下这两个短语时，`ai` 就会介入，正如规范性评估完成句子一样，正如“ideal spot to purchase coats in NY”，这是用户脑海中问题的一个非常可能的后缀。



准确来说，数据科学涵盖了人工智能，其中包含了机器学习。但机器学习涵盖了另一个不同的子技术——深度学习。然而，深度学习是一种机器学习，它与使用神经网络的方法有所不同，后者是在特定程度上激发大脑的意图，并利用数据中的三维阶梯来发现获益得多的模式。

如何提高系统学习能力？机器学习有多种方法可用，例如监督算法、半监督计算和无监督计算。

- A) `supervised algorithms` 利用已学习的内容以及建议，并使用良好且带有标签的图表来分析和预测未来。
- B) `semi-supervised algorithms` 需要标记的指令以及未标记的指令，这涉及到使用极少数标记数据的同时也使用大量的未标记数据。当获取的标记数据需要额外资金，而未标记数据不需要特殊的工具或技能时，这种方法非常受欢迎。
- C) `unsupervised algorithms` 在获得的数据未标记或未分类时通常会采用。该应用用于从未标记或甚至未分类的数据集中检测出隐藏的选项。

利用技术来获得关注。你是隐形的，你拥有多年的经验、丰富的技能和无与伦比的资历。你提交了又一次又申请，然后得到了一个电话来参加面试。这怎么可能呢？为什么没有人感兴趣呢？简单的事实是，有公司正在考虑你。根据你自己的资历，他们会立即雇佣你。问题是他们找不到你。你是隐形的。

“但这不符合逻辑，”你说。你注册了你的简历。你记录了自己的技能和经验。你突出了你所有优秀的资历。简历本身说明了这一点！这太棒了！或者真的如此吗？遗憾的是，并不是。招聘流程不像以前那样简单——或者说那么私密了。曾经，你会打印一份简历，它会直接发送给招聘经理，经理会检查它，即使感兴趣，也可以选一个参加面试。在当今技术驱动的招聘流程中，这种情况很少发生。

目前，通常情况下，如果你打印自己的简历，它会立即进入你的公司数据库。如果你使用在线方式，这通常会自动发生。即使你通过电子邮件发送一份报纸副本，你的简历也会被扫描、转换为文本（效果很差），并放入数据库中。从那时起，除非在数据库中被检索到，否则没有人能看到你的简历。这就是企业永远找不到你的主要原因。

当你的简历在扩展了特定数据库的浑浊深度之后，然后它仍然会浮出水面。这可能由于几个原因引起。如果你的字体或文档格式难以解释和转换为文本，那么数据库中的结果可能是单词和字母的杂乱无章。此外，如果你不使用合适的重点关键词和词汇，那么你的简历可能永远不会出现在搜索结果中。在任何情况下，你的简历几乎都会被丢弃，而不再被看到。

考虑机器人自动化申请如何启动了许多业务程序。让你的简历被关注的关键是要像这些系统一样思考。把自己当作一种方法——就像一个被赋予分析、分类和记录任务的机器人。考虑你的简历将如何被自动扫描、解释和搜索。不要假设它会触碰到人的手。然后想想可能失败的地方。会有什么可能会困扰这台机器吗？如果你提交的是格式化的文档文件或打印件，请考虑纯文本系统将如何解释它。不要使用难以扫描的样式字体。

此外，要保持文本的线性流。列和表格对于个人订阅者来说可能在视觉上有吸引力，但它们只会让解释器感到困惑。考虑到解释器不懂表格和列的概念，它只会读取文本序列——从左到右，从上到下。这可能会破坏发布和段落，使你的简历完全失效。此外，考虑数据库搜索引擎可能如何查看你的简历至关重要。通常，数据库会向其客户提供简单的关键词搜索。如果有人输入一个特定的关键词，数据库可能会搜索该术语——仅搜索该术语。遗憾的是，这种方法会忽略很多相关词。例如，搜索你的表达式 `telecom` 可能会完全漏掉包含 `telecommunications` 和 `telecom` 等单词的简历。由于由于，搜索者可能会忽略很多优秀的申请人。

在这一目标面前，数据库和搜索引擎不太可能适应某种写作风格，这通常意味着你必须适应它们。雇主正在考虑特定的关键词和术语，最好领先于目标。用所有针对你个人公司和技能集合的准确热门词汇更新你的简历。如果你不确定短语是否常见，请包含几个变体。如果你有特定的专业知识，请包含最常见的描述，然后附带细节。这将大大提高搜索数据库的人发现你的概率。

但你如何找到最好的关键词呢？最普通的方法是根据特定的职位发布量身定制你的简历。识别任务中列出的许多基本技能并将它们包含在简历中。这对于针对特定职位效果良好，但尽管如此，它限制了更广泛的搜索范围。

## 从源码编译 Python

偶尔，你的 Linux 发行版可能没有最新版本的 Python，或者你可能只想拥有创建最新、最强大模型的能力。这里是你想要选择从源码构建 Python 的步骤：

### 步骤 1：获取源代码

开始之前，你必须获取 Python 源代码。Python.org 使这非常简单。如果你访问下载页面，你会在最顶部看到 Python 3 的最新源码。（确保你没有获取到旧版 Python，即 Python 2。）

当你选择模型时，在页面的底部有一个文档部分。选择 gzipped 源码 tarball 并将其下载到你的机器上。如果你更喜欢命令行程序，可以轻松地使用 `wget` 将其获取到你的目录：

```bash
$ wget https://www.Python.org/ftp/Python/3.6.5/Python-3.6.5.tgz
```

### 步骤 2：准备系统

从头构建 Python 涉及一些特定于发行版的措施。每个步骤的目标在所有发行版上完全相同，但如果你的供应源不使用 `apt-get`，你可能需要根据你的情况进行解释：

*   在执行此类操作时，第一步是在开始之前升级你机器上的系统包。在 debian 上，这看起来就像是：
```bash
$ sudo apt-get upgrade
$ sudo apt-get update
```

*   接下来，我们希望确保机器拥有构建 Python 所需的工具。你会发现很多工具，你可能已经有了其中任何一个，但没关系。我将它们记录在一行命令行中，但你只需通过复制 `sudo apt-get set up -y` 部分将列表拆分为更短的控制：

*   **针对基于 apt 的程序（如 debian, ubuntu 和 mint）：**
```bash
$ sudo apt-get set up -y create build-essential libssl-dev zlib1g-dev libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm libncurses5-dev libncursesw5-dev xz-utils tk-dev
```

*   **针对基于 yum 的方法（如 centos）：**

### 可选：创建虚拟环境

查看下面的信息，但基础的 `venv` 命令用于在 Linux 平台上操作：

```bash

```

这将在 `tutorial_env` 子目录下创建一个新的虚拟环境，并配置当前 shell 使用它。创建“虚拟现实”可以让 Python 软件包安装在隔离的位置，而不是全局位置。假设你有一个应用程序需要版本 `foo`，而另一个程序需要版本 `two`。如何使用这些程序？如果你寻求安全地安装全局软件包，虚拟环境可能会对你有帮助。它们有特定的目录且不会与其他环境讨论。现在有两种常用的工具来生成虚拟环境：`venv` 在 Python 3.3 之后默认找到，并在 Python 3.4 之后支持在已环境中预安装 `pip` 和 `setuptools`。`virtualenv` 需要单独安装，但支持 Python 2.7+ 和 3.3+，并将 `pip`、`setuptools` 和 `wheel` 安装到生成的环境中（无论 Python 版本）。基本用法如下：

使用 `venv`:
```bash
Python3 -m venv origin/bin/activate
```

使用 `virtualenv`:
```bash
Virtualenv origin/bin/activate
```

在 unix shell 下使用，虚拟环境因素位于 shell 中而不是子进程（这随后失效）。在上述情况下，windows 用户**不要**使用 origin 命令，而应该这样直接从控制 shell 运行：

```cmd
\scripts\trigger
```

处理多个虚拟环境可能会变得麻烦，因此依赖管理提供了一个更高级的工具 `pipenv`，它会自动为你运行的任务和程序管理不同的虚拟环境。使用 `pip` 安装是你的推荐方法。下面我们将涵盖最常用的使用情况。

### 从 pypi 安装

`pip` 最常用的用法是通过需求指定符从 Python 包索引安装。标题后是可选的版本指定符。Pep 440 包含了目前支持的指定符的完整规范。以下是一些示例：

*   安装 `someproject` 的最新版本：
    ```bash
    pip install "someproject"
    ```
*   安装特定版本：
    ```bash
    pip install "someproject==1.4"
    ```
*   安装大于某个版本且小于另一个版本：
    ```bash
    pip install "someproject>1,<2"
    ```
*   安装与特定版本“兼容”的版本：
    ```bash
    pip install "someproject~1.4.2"
    ```

在这种情况下，这意味着安装任何 `==1.4.*` 版本且也是 `">1.4.2"` 的版本。

### 资源发行与 wheels

`pip` 可以从源码发行 (`sdist`) 或 wheels 安装，但如果 pypi 上两者都有，`pip` 可能偏于兼容的 wheel。Wheel 实际上是一种预构建的供应格式，与源码发行 (SDIST) 相比提供了更安装，特别是当项目包含编译的扩展时。如果 `pip` 没有找到可安装的 wheel，它将独立构建一个 wheel 并将其缓存以供以后安装，而不是在以后重新构建源码供应。

# 第五章：Python 如何工作以及它与 Java 或 C# 等语言的区别

## Python 与其他语言的对比

Python 可以与其他翻译语言如 `java`、`JavaScript`、`Perl`、`TCL` 甚至 `small talk` 进行比较。与 `c++`、`common lisp` 和 `scheme` 的比较也很有启发。在本节中，我将简要比较 Python 与这些每一种语言。这些比较仅关注语言本身的问题。但是，编程语言的选择可能受到额外的现实世界限制，如成本、可访问性、培训和之前的投入，以及心理因素。考虑到这些因素具有巨大的变数，在这种对比中花大量时间去考虑它们似乎是浪费时间。

### Java
`Python` 程序通常被认为运行比 `java` 应用更快，但此外它们增长所需的时间要少得多。`Python` 程序通常比等效的 `java` 应用短 3-5 倍。这种差距可以归于 `Python` 内置的高级信息类型及其自身的动态类型。例如，`Python` 开发者不需要浪费时间来声明参数的类型或因子，而 `Python` 强大的多态字典和列表类型（其丰富的语法支持直接构建在语言中）在几乎每个 `Python` 应用中都有。由于运行时类型，`Python` 的执行时间必须比 `javas` 更努力。例如，在评估表达式 `a+b` 时，它必须首先检查项 `a` 和 `b` 以发现它们的类型，这在编译时是未知的。然后它调用相应的改进功能，这可能是重载的用户自定义方法。

另一方面，`Java` 可以执行高效的整数或浮点访问，但需要对 `a` 和 `b` 进行变量声明，并且在大多数用户定义类的情况下不允许重载运算符。由于所有这些原因，`Python` 更适合作为一种“胶水”语言，而 `java` 则被描述为非侵入式执行语言。事实上，两者结合是一个极佳的组合。可以在 `java` 中开发组件并在 `Python` 中将其组合成程序；`Python` 也可以用于模拟部分内容，直到它们的布局可以在 `java` 实现中被“硬化”。为了鼓励这种进步，正在开发一种用 `java` 编写的 `Python` 实现，允许在 `java` 中调用 `Python` 代码，反之亦然。在这种执行中，`Python` 源代码可以翻译成 `java` 字节码（借助运行时库来确认 `Python` 的动态语义）。

### JavaScript
`Python` 的“基于对象”子集大约等同于 `JavaScript`。就像 `JavaScript` 一样（与 `java` 不同），`Python` 支持一种使用简单函数和因子而不参与类定义的编程风格。但对于 `JavaScript` 来说，这就是全部了。另一方面，`Python` 支持通过真正的面向对象编程方式组合规模更大的应用和更好的代码重用，在这种方式中，继承和类起着重要作用。

### Perl
`Python` 和 `Perl` 源于相似的历史（Unix 脚本，后者已过时），并且许多许多许多特征，但具有不同的教条。`Perl` 强调对共享面向应用型任务的支持，例如通过内置的正则表达式、文档扫描和文档生成特性。`Python` 强调对编程方法的支持，如信息结构布局和面向对象编程语言，这通过提供一种优美但不过神秘的符号，激励开发者编写可读（因此是易于维护的）代码。因此，`Python` 接近 `perl` 但很少在它的首个应用领域击败它；尽管如此，`Python` 的适用性远超 `perl` 的市场。

### TCL
与 `Python` ，`TCL` 可以作为应用扩展语言，也可以作为独立的编程语言。但 `TCL` 将所有数据存储为字符串，这在信息结构方面很弱，并且实现典型代码的速度比 `Python` 慢得多。`TCL` 还缺少编写大型应用程序所需的特性，例如：模块命名空间。因此，虽然使用 `TCL` 的“平均”大程序通常由用 `c` 或 `c++` 编写的特定 `TCL` 扩展组成，但等效的 `Python` 程序经常可以用“纯 Python”编写。显然，纯 Python 的增长速度比必须编写和调试 `c` 或 `c++` 元素快得多。有人说 `TCL` 的一个救救性特征是 `TK` 工具包。`Python` 接受了进入 `TK` 的接口，因为其常规组件库。`TCL` 8.0 通过提供带有受限数据类型服务的字节码编译器来处理速率问题，并提供了命名空间。但它仍然是一种非常笨拙的编程语言。

### Smalltalk

# 第八章：Python 的优势

## Python 的优点与缺点

Python 是全球各大品牌使用的语言。它的需求日益增长。Python 可以被 `google`、`yahoo`、`intel`、`IBM`、`cisco`、`hp`、`NASA` 以及列表中更大的公司使用。在这里我们将介绍 Python 的优点和缺点。

### Python 的优点

1. **易于理解**：Python 非常容易学习，不像与其他语言那样有复杂的语法和原理。即使你没有编程专业知识，也能轻松地上手 Python。可以说它是非常用户友好的。
2. **免费使用**：Python 免费使用并可以从其官方网站获取。你可以点击此处提供的链接（下载 Python 来下载 Python。Python 的源代码根据 `GPL`（通用许可证）向公众开放，你可以对其进行下载、修改、利用和传播。你可以完全自由使用 Python 执行你想完成的任何事情。
3. **移动性**：移植性是 Python 的主要优势。用户可以在多个不同的平台上运行 Python 程序。假设你在 `windows` 中编写了一个程序，并想在 `Linux` 或 `mac` 操作系统上运行该程序，你可以轻松地在 (`windows`、`mac`、`Linux`、`raspberry pi` 等）运行你的程序。你可以说 Python 是一种平台无关的编程语言。
4. **解释型**：Python 是翻译语言，因此不需要编译器来执行程序。Python 将代码转换为字节码以获得直接结果。翻译意味着代码是逐行执行的，使得调试更加简单。
5. **可扩展性**：这是 Python 一个非常重要的优点。首先，要了解 Python 中可扩展的意义，即它的开发方式允许包含新的功能和性能。它允许你通过不同语言编写的库来扩展 Python（主要是 `c` 或 `c++`，但通过 `c` 作为桥梁，你也可以预测其他提供 `c` 接口的语言）。
6. **丰富的库**：一旦你使用 Python，它拥有许多可以用于特定函数的库。你可以根据自己的需求或工作要求下载额外的库。有了这些库的支持，你不需要编写完整的代码，只需应用这些库并使用少量指令即可完成任务。Python 为浏览器、图像处理、数据库、电子邮件以及许多不同的功能提供了库。
7. **可嵌入性**：Python 的优秀特性之一是它是可嵌入的。例如，你可以将 YouTube 视频代码嵌入到你的 `html` 代码中。同样，也可以从另一种编程语言（如 `c++`）嵌入 Python 代码。凭借这一属性，Python 提供了将其代码像脚本一样整合另一种语言代码中的能力。
8. **面向对象**：Python 可以作为面向对象的语言使用，其中数据结构和函数结合在一个单元中。Python 从进化开始就支持面向对象和面向过程策略。面向对象的方法处理对象之间的交互，而面向过程的策略只处理目标。
9. **GUI 编程**：Python 提供了许多创建图形用户界面（GUI）的选项。Python 使用一个名为 `TKINTER` 的工具包，广泛用于 GUI 开发。通过使用 Python 和 `TKINTER`，你可以快速简单地制作 GUI 应用程序。
10. **数据库连接**：Python 支持开发不同项目所需的每种文档。开发者可以选择最合适的数据库来实现自己的项目。Python 支持的数据库示例包括 `mysql`、`postgresql`、`microsoft sql server`、`informix`、`interbase`、`oracle` 等。

## Python 的缺点

每种语言都有其局限性。开发者在开始任何新工作之前必须了解这些。我们已经明确了 Python 的所有优点，现在是时候介绍 Python 的缺点了。

1. **速度**：Python 是翻译的并且逐行执行代码，这使得它与 `c++` 相比较慢。如果速度不是工作的主要考虑因素，建议你使用 Python。
2. **不利于移动开发**：Python 是服务器端编程的顶级术语。然而，当我们谈论移动开发时，Python 并不太好。这就是你很少发现用 Python 开发的移动应用程序的重要原因。
3. **性能消耗**：Python 拥有一种非常灵活的数据结构。如果你的项目有内存限制，那么使用 Python 可能不是一个极佳的主意。
4. **数据库访问**：Python 在数据库访问方面存在问题。
5. **运行时错误**：Python 可能会导致运行时错误。
