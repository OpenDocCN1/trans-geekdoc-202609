
柜子内部的隐藏隔间让一名棋手能舒适地坐在里面，甚至沿着轨道滑动座位，从而让“土耳其机器人”的主人可以打开柜门，向怀疑者展示内部运转的各种齿轮和电线。棋子通过强力磁铁固定在棋盘上，这些磁铁还牵动着连接在柜子内微型棋盘上的绳索，让隐藏的棋手大师能看到局势并做出自己的走法。“土耳其机器人”的左臂能通过一系列杠杆移动，手能张合，让隐藏的棋手得以继续对弈。如果棋子摆放不当或从自动装置的手下被抢走，它会继续完成动作，然后由主人介入完成走法。后来，“土耳其机器人”还装上了发声装置，能高呼“将军！”，以增强效果。

国际象棋被证明是展示机器智能的热门游戏，1890年，西班牙发明家莱昂纳多·托雷斯·奎维多创造了一个简单的玩具，它能在“车王对王”残局中将死人类对手。这个玩具实际上只是一个电路、电线和一个开关，有时需要50步才能解决原本只需15-20步的局面，但它最终总是能获胜。从这种对玩具和棋盘的摆弄发展成为一门真正的科学，又花了70年时间。

1959年，麻省理工学院毕业生、对计算机情有独钟的亚瑟·塞缪尔开启了机器学习领域，这是一门专注于制造能够评估环境并相应改变行为以变得更高效的计算机的科学。在极其有限的内存和处理能力下，亚瑟让他的跳棋程序计算任意给定走法获胜的几率，然后让它与自己对弈数千次，直到优化并记录下尽可能多的走法。这就足够了，机器像人类一样学会了。

虽然塞缪尔的程序从未能超越业余水平，但这是机器学习诞生的第一个实例，且发生得惊人地清晰。机器学习科学家们的胃口被吊了起来，现在他们渴望更多。我们如何制造一个专业级的跳棋程序？那不可战胜的呢？麻烦就出在这里，因为计算机扩展性很差，仅仅希望将成百上千个相同的程序或设备堆叠在一起就能自动产生秩序，结果只会造成彻底的混乱，因为机器完全不知道如何将它们整合在一起。原始算力在那里，但缺少了某种东西——协调。

一个试图匹配人脑处理潜力的超级计算机集群，实际上需要一座10兆瓦发电厂的全部输出功率，其耗电量大致相当于一个典型美国家庭一年的用电量[[2]](#part0000_split_025.html#_ftn2)，即便如此，也无法保证机器真能产出任何有价值的东西。程序员们迅速意识到，一台能够学习的机器必须以某种方式模仿大脑的自然设计和灵活性。2009年，斯坦福大学的Kwabena Boahen制造了一个原型“神经网格”计算机，其晶体管有30%-90%的误触发率，但通过在所有噪声和随机信号中寻找共识，依然能产生一致的输出。那个版本的“神经网格”拥有百万个晶体管，相当于![](images/00001.jpeg)只老鼠大脑中的神经元数量[[3]](#part0000_split_025.html#_ftn3)。由于不知道如何让它们协同工作，科学家们专注于制造一台能在棋类游戏中击败人类的机器。

国际象棋程序早在1970年代就已出现，但算力的进步帮助它们比人类对手提前看到数百万种组合。回到起点，科学家们研究如何解决国际象棋，制造一台能随时看到所有走法的机器。问题是，随着格子的增加，问题变得呈指数级更复杂，直到1990年代才出现真正的挑战者，击败当时最优秀的棋手加里·卡斯帕罗夫。

1996年2月，IBM的“深蓝”国际象棋程序与加里进行了一场备受瞩目的6局较量，以2-4险败。次年举行重赛，升级后的算法速度翻倍，但加里无法保持心理稳定。在弃掉一局本可逼和的棋后，加里再未恢复，最终以1-2（3局和棋）告负。计算机对国际象棋的分析帮助我们理解了不同的开局和残局，推翻了许多延续几个世纪的国际象棋公理，但智能棋类游戏机很快又统治了另一个游戏——围棋。

围棋是一种强调战略思维的中国古老游戏，在19×19路的棋盘上进行，由两名玩家轮流落子（黑白棋子）。游戏目标是用自己的棋子包围对手的棋子，被包围的棋子随即从棋盘上移除。2014年，一个AI计算机程序设法击败了一位围棋专家，虽然是通过让子4子的优势，这促使研究人员大胆宣称将在10年内击败人类。

国际象棋和围棋的主要区别在于，后者拥有多得多的棋盘状态组合，因此需要呈指数级更多的计算能力。虽然“深蓝”能为棋盘状态赋值并提议最佳走法，但围棋需要更好的东西——蒙特卡洛树搜索。这种决策算法目前用于某些对手信息不完整的视频游戏（如扑克）中，以估算最有希望的行动方案，模拟其结果并从中学习。蒙特卡洛树搜索从程序为自己选择一个随机走法并尝试预测对手的最强走法开始，然后分支出自己的最强走法，以此类推。游戏越复杂，算法遍历所有可能走法所需的时间就越长，并在到达游戏结束时更新所有走法的胜率。

对人类棋手而言，擅长围棋与知道任意给定走法的价值无关，而是感知所有棋子的整体形势和位置。研究表明，大师级的围棋走法和策略看起来对称且赏心悦目，这正是几代棋迷着迷的原因。然而，程序被允许运行并收集所有可能走法的足够数据，最终通过自我对弈，直到变得足够强大以面对最顶尖的高手。

2016年1月，谷歌的AlphaGo（一个专家级围棋程序）完成了足够的迭代，最终面对现代围棋史上最强棋手李世石，以3-0获胜。观战的评论员指出李世石表现出极大的心理脆弱性，而AlphaGo下出了一盘完美的棋。这不足为奇，因为AlphaGo在训练和对弈过程中都运行在170张显卡和1200个CPU上，这需要铺设一根专用光纤电缆到两人对弈的房间[[4]](#part0000_split_025.html#_ftn4)，并使用了神经网络。
