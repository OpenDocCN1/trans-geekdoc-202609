# 9.2 Implementing an interface

As we just discussed, an interface is purely abstract. Its method does not have the body. We cannot create a value/object of an interface. The whole purpose of an interface is that some types will implement it. There is no keyword to implement an interface. Implementing an interface is implicit in Go. If a type has all the methods which are defined in an interface, then it implements that interface by default.
