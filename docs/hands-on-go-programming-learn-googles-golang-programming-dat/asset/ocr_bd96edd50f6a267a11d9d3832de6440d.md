# 5.9.1 Iterate over a slice using for loop

Let’s look at the following example:

# Program 5.12

```
```go
// Go program to iterate over slice using for loop

package main

import "fmt"

func main() {
// Creating a slice
my_slice := []string{"Golang", "program",
"to", "iterate", "over", "slice", "using", "for", "loop"}

// Iterate using for loop
for i := 0; i < len(my_slice); i++ {
fmt.Println(my_slice[i])
}
}
```
```

The following will be the output for the above program:

Golang
program
