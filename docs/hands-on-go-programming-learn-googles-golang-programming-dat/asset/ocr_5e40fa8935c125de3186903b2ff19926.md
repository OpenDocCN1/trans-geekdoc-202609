# 3.1.3_if...else_if...else_statement

The if...else if...else statement allows for combining multiple if... else statements.

**Syntax:**

```
if condition-1 {
// piece of code to be executed if condition-1 is true
} else if condition-2 {
// piece of code to be executed if condition-2 is true
} else {
// piece code to be executed if both condition1 and condition2 are false
}
```

The example given below will show the following output:

"**Capital of Maharashtra**" if x is "Mumbai"
"**City of Maharashtra**" if x is "Pune" and
"**Neither Pune nor Mumbai**" if x is other than "Pune" or
"**Mumbai**"
