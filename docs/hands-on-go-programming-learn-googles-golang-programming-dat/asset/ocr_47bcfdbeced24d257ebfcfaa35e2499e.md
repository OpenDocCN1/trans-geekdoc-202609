# 1.2 Constants

In Go, const is a keyword that introduces a name for a scalar value like 3.14159. Such values are called constants.

Type When a variable is declared without specifying an explicit type (either by using the := syntax or the var = expression syntax), the variable’s type is inferred from the value on the right-hand side.

Constants are declared with the const keyword and can be a numeric, string, Boolean, or character values.

Constants cannot be declared using the := syntax

E.g.: const Pi = 3.14
