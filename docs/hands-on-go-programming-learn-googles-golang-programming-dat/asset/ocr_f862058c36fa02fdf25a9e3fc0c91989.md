# 5.4 *Modifying a Slice*

Slices are reference types and they refer to an underlying array. Therefore, modifying an element of a slice will modify the corresponding elements in the referenced array, and the other slices that refer to the same array will also see those modifications.

# Program 5.7

```
```go
// Go program to modify a slice

package main

import "fmt"

func main() {
    a := []string{"One", "Two", "Three", "Four", "Five", "Six", "Seven"}

    slice1 := a[:]
    slice2 := a[3:]

    fmt.Println("***** Before Modifications *****")
    fmt.Println("Array =", a)
    fmt.Println("slice1 =", slice1)
    fmt.Println("slice2 =", slice2)
