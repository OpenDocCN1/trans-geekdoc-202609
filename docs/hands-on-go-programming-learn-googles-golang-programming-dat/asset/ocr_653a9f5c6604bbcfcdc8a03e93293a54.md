# 7.3 Zero value of structs

When a struct is defined, it is not explicitly initialized with any value. The fields of the struct are assigned their zero values by default.

# Program 7.3

// Golang program to explain zero value of a struct

```
package main

import (
"fmt"
)

type employee struct {
name string
age int
city string
}

func main() {
var emp1 employee //zero valued struct
fmt.Println("Employee1 details:", emp1)
}
```
