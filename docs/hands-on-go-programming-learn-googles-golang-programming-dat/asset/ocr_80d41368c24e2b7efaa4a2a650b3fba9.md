# ### 7.1 What are structs?

Structs are user-defined types that contains a collection of named fields and properties. A struct uses group related data to form a single unit. Golang can declare and create their data types by combining one or more types, including both built-in and user-defined types.

Structs are the only way to create concrete user-defined types in Golang. They improve modularity and allow them to create and pass complex data structures around the system.
