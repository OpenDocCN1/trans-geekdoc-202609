# 5.6 Comparison of slice

You can use the == operator in slice to check whether given slice is nil or not. Let’s look at the following example:

# Program 5.9

// Go program to check if slice is nil or not

```
package main

import "fmt"

func main() {
// creating slices
s1 := []int{1, 2, 3, 4, 5}
var s2 []int

// Check if slice is nil or not
fmt.Println(s1 == nil)
fmt.Println(s2 == nil)
}
```

The following will be output for the above program:

false
true
