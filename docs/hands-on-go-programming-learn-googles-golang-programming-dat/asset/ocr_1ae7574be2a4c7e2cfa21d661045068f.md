```go
package main

import "fmt"

type person struct {
	id int
	name string
}

func main() {
	p1 := &person{101, "XYZ"}
	modify(p1)
	fmt.Println("Person p1:", p1)
}

func modify(p1 *person) {
	p1.name = "NewXYZ"
}
```
```

The following will be the output for the above program:

```
```text
Person p1: &{101 NewXYZ}
```
```

In *Program* the modify function takes the pointer of the person struct as an argument. The modify function changes the name field from XYZ to NewXYZ. In the main function, we have created a pointer to the struct variable p1 and passed it to the modify function. When we print it prints the changed value of the name field.
