# 11.3.2.2 Iterating over the channel

We can iterate over the channel while reading the channel. There are two ways to iterate over the channel to read data. One way is that we can use the second returned value from the channel. We can use the infinite to iterate and break when the second value is false. The other way is that we can use the range cause.
