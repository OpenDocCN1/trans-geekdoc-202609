```
fmt.Println("Original Map:", my_map)

v1 := my_map[91]

fmt.Println("Value of key[91]:", v1)

}
```

The following will be the output for the above code:

```
Original Map: map[1:US 44:UK 86:China 91:India]

Value of key[93]:
Value of key[44]: UK
```
