# 11.3.3.2 Buffered channel

The buffered channels are those channels that are created with capacity. E.g.:

```
```go
ch := make(chan int, 5)
```
```

In the buffered channel, the write operation is blocked when the capacity/buffer of the channel is full. In the above statement, when five values are already there in the channel and when we try to send the 6th value, it will be blocked because there will be no space available.

The read operation is blocked when the channel is empty.
