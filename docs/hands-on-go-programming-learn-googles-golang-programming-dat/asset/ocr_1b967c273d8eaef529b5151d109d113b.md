# 7.6 Exported vs. unexported structs and struct fields

Any struct type that starts with a capital letter is exported and accessible from outside packages. Similarly, any struct field that starts with a capital letter is exported and any struct type that starts with a small letter is visible only inside the same package.

Consider the following package hierarchy of a Go program:

+   program
+   main
+   main.go
+   module
+   city.go
+   employee.go

You need to put the above folder structure and the Go programs in your GOPATH directories.
