# 3.2.3.4 Infinite loop

In Go, a for loop can work as an infinite loop if you omit the loop condition or use a true boolean. The example given below keeps on printing the Infinite Loop forever:

# Program 3.10

```
```go
// Go program to explain Infinite loop

package main

import (
"fmt"
"time"
)

func main() {
for true {
fmt.Println("Infinite Loop")
time.Sleep(time.Second)
}
}
```
```

The above program will show the following output:

**Infinite Loop**
