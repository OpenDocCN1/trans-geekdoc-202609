// Go program to explain Left shift AND assignment operator

package main

import (
"fmt"
)

func main() {
var a, b uint
a, b = 1, 1

for b = 1; b < 5; b++ {
fmt.Printf("%d << %d = %d \n", a, b, a<<b)
}
}
```
```

We will get the following output:

```
```text
1 << 1 = 2
1 << 2 = 4
1 << 3 = 8
1 << 4 = 16
