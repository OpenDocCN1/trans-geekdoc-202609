# 12.2.1 Panic and defer

Till now, we have seen that when a program panics, the program flow stops and prints a stack trace. We have also seen the defer function in Section The defer executes at the end of the function call. If there are any defer functions in the call stack, then all defer functions of all the functions in the call stack will be called before the program stops the execution.

The program given below has four functions: Each function has a deferred function. When the program panics in function it executes all the defer functions in reverse order and prints the output on the console before the program stops. Also, note that it does not print the last line of all the functions:
