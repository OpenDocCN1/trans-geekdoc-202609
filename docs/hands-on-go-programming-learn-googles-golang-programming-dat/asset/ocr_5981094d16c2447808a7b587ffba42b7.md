# 3.2.2 Nested for loops

Loops can be nested in Go as they can with other programming languages. A nested loop is a loop that occurs within another loop. These can be useful when you want a looped action performed on every element of a data set.

```
for {
[Action to be performed]
for {
[Action to be performed]
}
}
```
