# 5.3.2 Creating a slice from an array.

To create a slice from an array, we specify two indices, lower bound and upper bound separated by a colon. Let us suppose that you have an array and you want to obtain a slice from this array.

```
array_name[low:high]
```

The above expression selects a slice from a given array. The resulting slice includes all the elements starting from the index low to high but excludes the element at index high.
