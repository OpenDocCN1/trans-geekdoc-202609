# 6.1 What are Go maps?

A map is an unordered collection of key-value pairs. The keys are unique within a map but the values may not be. It is widely used because it provides fast lookups and values that can retrieved, updated, or deleted with the help of keys.

A map is also known as an associative array, a hash table, or a dictionary. Maps are used to look up a value by its associated key.
