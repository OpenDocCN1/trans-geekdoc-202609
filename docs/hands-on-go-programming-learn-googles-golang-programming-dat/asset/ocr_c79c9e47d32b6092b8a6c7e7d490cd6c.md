```
import "fmt"

func main() {
a := new(int)
*a = 15
fmt.Println(*a)
fmt.Println(a)
}
```

The following will be the output for the above program:

15
0xc000014058

The pointer variable can also be created using the var keyword.
The following statements create a pointer of type *int and the assigned address of x to the pointer:

```
x:= 15
var a *int
a = &x
```
