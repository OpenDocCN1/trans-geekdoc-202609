# 4.2.1 Using var keyword

An array is created using the var keyword of a type with the name, size, and elements.

**Syntax:**

**var array_name[length]Type**

For example, a var team [15]int can hold up to 15 scores using the indexes team[0] through Attempts to access an out of range index in the array will result in a compiler or runtime error.
