# 11.5 Select statement

The select statement is used when there are multiple goroutines that send data in multiple channels. We need to process values from all the channels concurrently. The syntax of the select statement is almost similar to the switch statement. There can be multiple cases within a select statement. Each case statement can have a channel operation. When a case statement can receive from the channel, then that case will be executed. Like the switch statement, the select can also have the default. When none of the cases receive from the channel, then the default section gets executed. The select statement is mostly used in the but it not necessary:
