# Program 1.6

```
```go
// Go program to explain Right shift AND assignment operator

package main

import (
"fmt"
)

func main() {
var a, b uint
a, b = 512, 1

for b = 1; b < 5; b++ {
fmt.Printf("%d >> %d = %d \\n", a, b, a>>b)
}
}
```
```

We will get the following output:

```
```text
512 >> 1 = 256
512 >> 2 = 128
512 >> 3 = 64
512 >> 4 = 32
```
