```
import "fmt"

// function to change the value of given variable
func replace(x *int) {
*x = 20
}

// main function
func main() {

var x int = 10
fmt.Printf("value of x before function call = %d", x)

// call by reference
replace(&x)
fmt.Printf("\nvalue of x after function call = %d", x)
}
```

The following will be the output for the above program:

**value of x before function call = 10**
**value of x after function call = 20**
