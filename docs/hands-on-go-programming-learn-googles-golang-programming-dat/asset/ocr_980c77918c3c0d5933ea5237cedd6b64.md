# Conclusion

A pointer variable can hold the address of another variable.

The ampersand can be used to access the memory address of the variable.

The asterisk can be used to access the value at the address.

The reflect package can be used to find the type of the pointer variable.

The pointer variable must be assigned with the address of another variable before the access value of the pointer variable, otherwise the code will panic.

The address of the int variable can only be assigned to the pointer variable type of The same is applicable to other types as well.

The only relational operator that can be used on the pointer variable is the equality operator.

We can create a pointer to the array but it is not recommended to use it. We should create a slice from an array and pass it to another function.
