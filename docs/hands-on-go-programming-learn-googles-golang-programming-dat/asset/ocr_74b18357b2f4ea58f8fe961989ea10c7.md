# 5.3.1 Creating a slice using a slice literal

A slice can be created using slice literal. This is shown as follows:

```
var s = []int{2, 4, 6, 8, 10}
```

When you create a slice using a slice literal, it first creates an array and then returns a slice reference to it as shown below:

# Program 5.1

// Go program to create a slice using slice literal

```
package main

import "fmt"

func main() {
// Create a slice using a slice literal
var s = []int{2, 4, 6, 8, 10}

fmt.Println("slice =", s)
}
```
