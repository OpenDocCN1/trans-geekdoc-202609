# ### 7.2 Declaring and initializing structs type

The declaration of struct starts with the keyword type, then a name for the new struct, and finally, the keyword Within the curly brackets, a series of data fields are specified with a name and their types.

You can initialize a variable of a struct type using a struct literal. You also need to pass the field values in the same order in which they are declared in the struct.

# **Syntax of structs:**

```
```text
type identifier struct{
field_1 data_type
field_2 data_type
}
```
```
