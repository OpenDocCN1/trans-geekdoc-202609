This means that modification has been done in the calling function which is visible in the caller function.

Note: It is not a good practice to send the address array to the function. We should create a slice from the array with the default indexes and pass the slice in the function.

When we create a slice from the array with default indexes, the start index will be zero and the last index will be the length of the array minus This means that it will create a slice with the whole array, and the underlying data structure of that slice will be an original array. Any modification to the slice will reflect in the original array.
