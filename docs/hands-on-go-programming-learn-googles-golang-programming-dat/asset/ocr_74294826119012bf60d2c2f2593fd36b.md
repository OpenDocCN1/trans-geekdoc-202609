# **Array a: [5 0 10 0 15]**

We can set a value at an index using the array[index] = value syntax and get a value with To access any element in the array, we need to use the a[index] syntax where a is an array variable. This is shown as follows:

# **Program 4.6**

```
```go
// Go program to set the value at a particular array index and access it

package main

import "fmt"

func main() {

var x [5]int
fmt.Println("Empty array:", x)

x[3] = 10 //value assigned at 3rd array index
fmt.Println("Array x:", x)
fmt.Println("Value assigned at 3rd array index:", x[3])
}
```
```

The following will be the output for the above program:

```
```text
Empty array: [0 0 0 0 0]
Array x: [0 0 0 10 0]
```
