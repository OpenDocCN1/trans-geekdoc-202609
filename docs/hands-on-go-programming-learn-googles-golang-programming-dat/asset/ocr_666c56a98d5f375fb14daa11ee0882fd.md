# ## 12.2 *Panic*

The unexpected runtime error stops the execution flow of the program abruptly. The most common examples of panic are divide by zero, index out of range, etc. When panic is encountered, the program terminates, deferred functions are called, and control goes to the caller. This process continues till the control reaches the first method of the goroutine call stack.

Finally, it prints the stack trace on the console:
