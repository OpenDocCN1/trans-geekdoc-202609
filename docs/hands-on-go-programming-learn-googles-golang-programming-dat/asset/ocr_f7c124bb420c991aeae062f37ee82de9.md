# ### *3.1.4 switch...case*

A switch statement is a multiway branch statement. It provides an efficient way of transferring the execution to different parts of a code based on the value of the expression. Switch statements express conditionals across many branches. The cases are evaluated from top to bottom, stopping when a case succeeds. If no case matches and there is a default case, its statements are executed.
