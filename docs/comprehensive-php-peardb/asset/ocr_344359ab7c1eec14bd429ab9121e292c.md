# DB_common::errorCode

♦ int errorCode( mixed $nativecode )

The errorCode() method converts a native DB error code to a PEAR::DB portable error code. This may be used in conjunction with the errorNative() method described in this section. The nativecode parameter may be a string or an integer.

Returns a portable DB error code.

```

<?php
require_once( 'DB.php' );

$oDB = DB::connect(
'mysql://bt_user:bt_pass@207.44.182.3/book_test',

$aPEARCode = $oDB->errorCode( $aErrCode );

print( 'PEAR Error Message: ' . $oDB->errorMessage( $aErrCode ) . '<br>' );

// but if there's an error, a DB_Error object
provides great information
if ( DB::isError( $oRows ) )
{
print( 'Error Message: ' . $oRows->message .

}
