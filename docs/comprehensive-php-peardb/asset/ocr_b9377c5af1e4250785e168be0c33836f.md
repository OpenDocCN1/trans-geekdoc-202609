# DB_common::getListOf

```
mixed getListOf( string $type )
```

The **getListOf()** method returns database-specific information and metadata based on the *type* parameter. The **getTables()** method described on page 105, for example, is a call to **getListOf()** where the *type* parameter is set to the string, ‘tables.’ The value of the *type* parameter is database specific.
