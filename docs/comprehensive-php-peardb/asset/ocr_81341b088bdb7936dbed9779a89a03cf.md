# Output 9: Output when setFetchMode is DB_FETCHMODE_ASSOC

The DB_FETCHMODE_ASSOC *fetchmode* causes the result array to be an associative array where the keys are the column names. Typically this is the preferred development method because the code itself becomes easier to read and therefore easier to maintain.

The DB_FETCHMODE_OBJECT *fetchmode* is very similar to the DB_FETCHMODE_ASSOC *fetchmode*. However, instead of each result being an associative array, each result is an object whose properties are the names of the columns.
