# DB_storage::setup

❖ `mixed setup( mixed $keyval )`

The **setup()** method is used to configure the current object based on the data in the row represented by the key(s) in *keyval*. The value of *keyval* is either an atomic value if the primary key of the table is a single column or an array of values if the primary key is multi-columnar.
