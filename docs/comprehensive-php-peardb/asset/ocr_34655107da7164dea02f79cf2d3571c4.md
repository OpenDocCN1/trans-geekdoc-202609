# Installing PEAR::DB

If you do not have the DB package installed, using the following command to install DB:

```
```bash
pear install DB
```
```

If you do not have the most current version of DB or if you need to check for an upgrade and install it, use:

```
```bash
pear upgrade DB
```
```

Note that the above will cause an upgrade to be installed if one exists. If you simply wish to check for upgrades, use the **pear list-all** or **pear list-upgrades** commands.

For the purposes of this document, it will be assumed that the version of PEAR::DB is 1.5.0RC2.
