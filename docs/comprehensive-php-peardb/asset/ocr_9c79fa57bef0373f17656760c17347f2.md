<?php
require_once( 'DB.php' );

$oDB = DB::connect(
'mysql://bt_user:bt_pass@207.44.182.3/book_test',
array( 'seqname_format' => 'seq_%s' ) );

$aFields = array( 'id', 'last_name',

'Schwendiman', 'Ryan', '123', '1', '1' );
$result = $oDB->execute( $oQuery, $aData );

'Schwendiman', 'Scott', '234', '1', '1' );

print( $result->getMessage() );

'Schwendiman', 'Taylor', '323', '1', '1' );
$result = $oDB->execute( $oQuery, $aData );

The example shown in Code Listing 12 illustrates the use of the autoPrepare() method. Rather than specifying a parameterized SQL query, as was illustrated in Code Listing 11, only the table name and field names need to be specified. The autoPrepare() method uses the table name, field names and a mode parameter to internally create and prepare an adequate SQL query for either INSERT or UPDATE.
