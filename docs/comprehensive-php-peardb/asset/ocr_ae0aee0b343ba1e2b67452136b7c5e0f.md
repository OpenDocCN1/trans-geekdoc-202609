The **getAssoc()** method returns the entire result set of a query as an associative array using the first column as the array key. If the result set contains more that two columns, the value of each element in the return array will be an array of values from columns 2 through *n*. If the result set contains only 2 columns, the value of each element in the return array will be a scalar value unless the *force_array* parameter is true. If the result set contains less than two columns, a DB_ERROR_TRUNCATED error is returned.
