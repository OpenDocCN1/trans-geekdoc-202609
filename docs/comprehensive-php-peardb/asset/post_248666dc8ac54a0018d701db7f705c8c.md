## Installing PEAR::DB

If you do not have the DB package installed, using the following command to install DB:

```bash
pear install DB
```

If you do not have the most current version of DB or if you need to check for an upgrade and install it, use:

```bash
pear upgrade DB
```

Note that the above will cause an upgrade to be installed if one exists. If you simply wish to check for upgrades, use the **pear list-all** or **pear list-upgrades** commands.

For the purposes of this document, it will be assumed that the version of PEAR::DB is 1.5.0RC2.

## Procedural DB Access

The code in the example below (Code Listing 3) illustrates the common procedural method for retrieving data from a MySQL database.

```php
<?php
// connect to MySQL DB
$link = mysql_pconnect( '207.44.182.3',
'bt_user','bt_pass' );
if ( $link != FALSE )
{
if ( mysql_select_db( 'book_test' ) )
{
/* Performing SQL query */
$query = "SELECT Employees.last_name as
emp_last_name, Employees.first_name as
emp_first_name, Employees.phone_ext as
emp_phone_ext, Departments.name as dept_name,
Employees_1.last_name as mgr_last_name,
Employees_1.first_name as mgr_first_name,
Employees_1.phone_ext as mgr_phone_ext FROM
(Departments INNER JOIN Employees ON Departments.id
= Employees.dept_id) LEFT JOIN Employees AS
Employees_1 ON Employees.mgr_id = Employees_1.id";
$result = mysql_query($query);
if ( $result != FALSE )
{
/* Printing results in HTML */
print '<table>';
while ( $line = mysql_fetch_array( $result,
MYSQL_ASSOC ) )
{
    print '<tr>';
    foreach ( $line as $col_value ) {
        print "<td>$col_value</td>";
    }
    print '</tr>';
}
print '</table>';
}
else
{
    print( 'Query failed: ' );
    print( mysql_error() );
    print( '<br>' );
}

/* Free resultset */
mysql_free_result($result);
}
else
{
    print( 'Unable to select database
<i>book_test</i>: ' );
    print( mysql_error() );
    print( '<br>' );
}

/* Closing connection */

}
else
{
    print( 'Unable to connect to database server: ' );
    print( mysql_error() );
    print( '<br>' );
}
?>
```

## Code Listing 3: Procedural DB Access

Experienced PHP developers will see the common elements in the code above. Line 3 is the call to establish a connection to the database server. On success, the code at line 6 selects the particular database. The SELECT query is issued to the database on line 11 and if it succeeds, line 17 begins a loop to retrieve all of the data from the result set and process it for HTML output. In the event of a failure at any point, the relevant failure information is displayed to the end user.
