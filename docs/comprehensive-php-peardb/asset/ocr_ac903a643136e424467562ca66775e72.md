# Code Listing 25: Using prepare() -- simple example

The example shown in Code Listing 25 illustrates the use of two of the placeholder characters, ‘?’ and ‘!’. The important difference in this example is that the second placeholder (the ‘!’) is used because the data is a MySQL function, NOW(), which specifies the date that the query runs on the server. If the ‘?’ placeholder had been used, the interpretation of the query would have been to try to insert the literal string, ‘NOW()’ into the database. In most cases, the ‘?’ placeholder is the most appropriate, but there are times when the ‘!’ placeholder is the only one that will achieve the desired results.
