# DB_common::getTables

◆ mixed getTables( void )

The getTables() method returns an array containing all of the tables in the current database.

```
```php
<?php
require_once( 'DB.php' );

$oDB = DB::connect(
'mysql://bt_user:bt_pass@207.44.182.3/book_test',
true );
if ( DB::isConnection( $oDB ) )
{
$result = $oDB->getTables();
if ( !DB::isError( $result ) )
{
print( '<pre>' );
var_dump( $result );
print( '</pre>' );
}

$oDB->disconnect();
}
?>
```
