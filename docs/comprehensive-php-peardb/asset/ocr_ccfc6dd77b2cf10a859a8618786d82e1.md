# DB_common::quote

✧ string quote ( string $string )

Returns a quoted string so it can be safely used in a query.

The quote() method safely quotes and escapes values based on the requirements of the particular back end database. The example code in Code Listing 17 illustrates the quote() method and the output in Output 7 shows how the various DB objects may provide different results.

```
<?php
require_once( 'DB.php' );

print( 'Quoting with mysql object<br>' );
$oDB = DB::connect(
'mysql://bt_user:bt_pass@207.44.182.3/book_test',
false );
if ( !DB::isError( $oDB ) )
{
print( $oDB->quote( ) . '<br>' );
print( $oDB->quote( 500 ) . '<br>' );
print( $oDB->quote( 'some text' ) . '<br>' );
print( $oDB->quote( "it's not on drive c:\
anywhere" ) . '<br>' );
$oDB->disconnect();
}
print( '<br><br>Quoting with ODBC object<br>' );
$oDB = DB::connect( 'odbc//book_test', true );
if ( !DB::isError( $oDB ) )
{
print( $oDB->quote( ) . '<br>' );
print( $oDB->quote( 500 ) . '<br>' );
print( $oDB->quote( 'some text' ) . '<br>' );
print( $oDB->quote( "it's not on drive c:\
anywhere" ) . '<br>' );
$oDB->disconnect();
}
?>
```
