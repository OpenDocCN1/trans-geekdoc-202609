
从结果来看，预测效果并不理想。编码器最后一时刻的输出被用作上下文向量（`context vector`）在编码器和解码器之间传递信息，这样单个向量就承担了编码整个句子的重任，可能无法包含完整信息。如果使用所有输出时刻的输出作为上下文变量，信息相对完整，但无法直接将所有输出时刻的变长编码器输出信息作为解码器每一时刻的输入。

后来引入的**注意力机制**使解码器网络能够在解码器自身输出的每一步“关注”编码器输出的不同部分，这可以解决这种变长解码器输出问题，并避免解码器隐藏状态向量的增加。

### 7.11.3 基于 Word2Vec 的 Seq2Seq 机器翻译

一个句子可以被视为字符序列，也可以被视为单词序列。作为字符序列时，句子的长度是作为单词序列时的数倍。序列越长，循环神经网络的梯度传递越困难，梯度爆炸和消失也越容易发生，因此在机器翻译中，句子被视为单词序列。然而，一种语言的单词数量通常非常庞大。如果使用独热编码量化每个词，其独热向量将非常巨大。当然，中文的字符是汉字，汉字数量也很大，独热向量同样会很大。因此，直接用独热向量量化单词存在两个明显问题：

*   浪费空间，表示一个单词的向量非常大，只有一个值为 1，其余均为 0
*   无法表达单词间的内在联系，如同义词、相关性等，语言的单词并非相互独立，它们之间往往存在一定的关联

在自然语言处理中，使用比独热编码更好的词向量化方法。这些方法统称为 **Word2Vec**（词量化/词向量化）。词量化可以看作是将单词从其词表所在的空间（独热向量空间）转换到低维空间，这类似于自编码器将高维向量映射到低维向量。词量化也是一种量化模型，它利用语料库（如一段文本）通过有监督机器学习方法训练单词，但因为它不需要对单词做任何标注，而是自行采样有监督训练样本，所以也有人称之为无监督学习。

#### 1. 词向量化 Word2Vec 的 skip-gram 方法

词量化（Word2vec）主要有两种方法：连续词袋模型（CBOW）和 skip-gram（跳字模型）。

这两种方法都通过一个类似自编码器的两层神经网络来学习单词的词向量，即将高维独热向量映射到低维隐向量。如图 8-55 所示，词表长度为 V，即有 V 个不同的单词，一个单词的独热向量 `x` 是长度为 `V` 的向量，经过权重矩阵 `W[V × N]` 后，因为 N 通常是远小于 V 的整数，所以用 `W[V × N]` 对 `x` 进行加权求和产生低维隐向量 `h[N] = x W[V × N]`，这个隐向量 `h[N]` 就是索引为 k 的单词的向量化表示。

图 8-55 CBOW 和 Skip-gram 词量化均使用两层加权神经网络来学习单词的量化表示

因为 `x` 是一个只有第 k 个分量为 1、其余为 0 的行向量，`x W[V × N]` 的结果就是矩阵的第 `k` 行，所以实际上不需要进行乘法运算，只需取出矩阵的第 k 行即可。Python 代码如下：

```
h = self.W[k,:]
```
