

## RMSprop 方法示例

```python
def gradient_descent_RMSprop(df, x, alpha=0.01, beta=0.9, iterations=100, epsilon=1e-8):
    history = [x]
    v = np.ones_like(x)
    for i in range(iterations):
        if np.max(np.abs(df(x))) < epsilon:
            print("The gradient is small enough!")
            break
        grad = df(x)
        v = beta * v + (1 - beta) * grad**2
        x = x - alpha * grad / (np.sqrt(v) + epsilon)
        history.append(x)
    return history
```

### 2.3.5 Adam 方法

除了像 RMSprop 方法那样存储过去梯度平方的指数衰减累积均值外，它还像动量法那样存储梯度的累积均值。动量法可以看作是一个球沿着斜坡滚下，但 Adam 方法表现得像一个带有摩擦力的球，因此更适合平坦的极小值。使用 `m[t]`、`v[t]` 表示过去梯度和梯度平方的移动平均：

$$
\begin{matrix} 
m_{t} & {= \beta_{1}m_{t - 1} + (1 - \beta_{1})g_{t}} \\ 
v_{t} & {= \beta_{2}v_{t - 1} + (1 - \beta_{2})g_{t}^{2}} \\ 
\end{matrix}
$$

它们相当于梯度的一阶和二阶动量，因为它们的初始值为 0，Adam 的作者观察到：当衰减率较小时，例如 `β[1]`、`β[2]` 接近 1 时，它们偏向于零，尤其是在迭代的早期阶段。为了修正这个问题，作者使用了以下修正公式：

$$
\begin{matrix} 
{\hat{m}}_{t} & {= \frac{m_{t}}{1 - \beta_{1}^{t}}} \\ 
{\hat{v}}_{t} & {= \frac{v_{t}}{1 - \beta_{2}^{t}}} \\ 
\end{matrix}
$$

基于此更新 `x`：

$$
\theta_{t + 1} = \theta_{t} - \frac{\eta}{\sqrt{{\hat{v}}_{t}} + \epsilon}{\hat{m}}_{t}
$$

```python
# https://towardsdatascience.com/adam-latest-trends-in-deep-learning-optimization-6be9a291375c
def gradient_descent_Adam(df, x, alpha=0.01, beta_1=0.9, beta_2=0.999, iterations=100, epsilon=1e-8):
    history = [x]
    m = np.zeros_like(x)
    v = np.zeros_like(x)
    for t in range(iterations):
        if np.max(np.abs(df(x))) < epsilon:
            print("The gradient is small enough!")
            break
        grad = df(x)
        m = beta_1 * m + (1 - beta_1) * grad
        v = beta_2 * v + (1 - beta_2) * grad**2
        
        # m_1 = m/(1-beta_1)
        # v_1 = v/(1-beta_2) 
        t = t + 1
        if True:
            m_1 = m / (1 - np.power(beta_1, t + 1))
            v_1 = v / (1 - np.power(beta_2, t + 1))
        else:
            m_1 = m / (1 - np.power(beta_1, t)) + (1 - beta_1) * grad / (1 - np.power(beta_1, t))
            v_1 = v / (1 - np.power(beta_2, t))
    
        x = x - alpha * m_1 / (np.sqrt(v_1) + epsilon)
        # print(x)
        history.append(x)
    return history
```

## 2.4 梯度验证

### 2.4.1 比较数值梯度与解析梯度

编写梯度下降算法代码时，最容易出错的是梯度计算不正确，导致算法无法收敛。因此，除了调整学习率外，还应检查梯度计算是否正确。为此，根据导数的定义，即导数是函数的变化率，可以用以下公式估计函数在点 `x` 处的导数（梯度）：

$$
\frac{\partial{f(x)}}{\partial x} = \lim_{\epsilon \to 0}\frac{f(x + \epsilon) - f(x - \epsilon)}{2\epsilon}
$$

即用公式右边的除法来近似 `f(x)` 在 `x` 处的导数（梯度）。如果 `ϵ` 足够小，该值的导数（梯度）应与左边的解析导数（梯度）足够接近。

因此，在使用梯度下降法训练模型之前，可以比较数值计算的梯度和解析梯度，以验证解析梯度计算是否正确。

例如，对于前面的二元函数 $f(x,y) = \frac{1}{16}x^{2} + 9y^{2}$，在梯度下降法中，通过以下代码计算函数在点 `x = (x[0], x[1])` 处的函数值和解析梯度。

```python
f = lambda x: (1/16)*x[0]**2 + 9*x[1]**2
df = lambda x: np.array(((1/8)*x[0], 18*x[1]))
```

点 `x = (x[0], x[1])` 处的数值梯度可按如下方式计算：

```python
df_approx = lambda x, eps: ((f([x[0]+eps, x[1]]) - f([x[0]-eps, x[1]])) / (2*eps), 
                            (f([x[0], x[1]+eps]) - f([x[0], x[1]-eps])) / (2*eps))
```

以下代码片段比较点 `x = [2., 3.]` 处解析梯度和数值梯度的误差：

```python
x = [2., 3.]
eps = 1e-8
grad = df(x)
grad_approx = df_approx(x, eps)
print(grad)
print(grad_approx)
print(abs(grad - grad_approx))
```

```
[ 0.25 54. ]
    (0.2500001983207767, 54.00000020472362)
    [1.98320777e-07 2.04723619e-07]
```

可以看出，只要计算数值梯度的微小增量 `eps` 足够小，该数值梯度就足够接近解析梯度，这正是导数的定义：数值梯度可以无限接近解析梯度。如果发现两者误差较大，则意味着解析梯度或函数值或数值梯度的计算可能有问题。大多数错误是解析梯度或函数值的计算问题。

在使用梯度下降法求最优解之前，应使用梯度验证方法，确保解析梯度和函数值的计算正确。在此基础上，调整梯度下降法的超参数，如学习率或动量参数。
