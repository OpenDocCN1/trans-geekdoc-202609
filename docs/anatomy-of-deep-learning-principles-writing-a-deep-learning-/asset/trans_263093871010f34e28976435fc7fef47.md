### 核心变量定义

```python
nRow, K2C = dx_row.shape[0], dx_row.shape[1]
C = K2C // (kH * kW)
N = nRow // (oH * oW)    # 样本数量
oSize = oH * oW
H = (oH - 1) * S + kH
W = (oW - 1) * S + kW
dx = np.zeros([N, C, H, W])
```

### row2im 函数实现（版本一）

```python
for i in range(oSize):
    row = dx_row[i::oSize, :]  # N 个行向量
    h_start = (i // oW) * S
    w_start = (i % oW) * S
    dx[:, :, h_start:h_start+kH, w_start:w_start+kW] += row.reshape((N, C, kH, kW))
    # np.reshape(row, (C, kH, kW))
return dx
```

### 原理说明

其中，`oSize = oH × oW` 表示 `ZZ` 的一个特征图的大小，也表示一个输入样本被分成的数据块数量。`oH` 和 `oW` 是数据块矩阵的高度和宽度。`i` 表示卷积核“从上到下，从左到右”滑动时对应的数据块编号。根据 `i`，下标为 `(i // oW), (i % oW)`，根据数据块下标和跨度 `S`，可以计算出该数据块在原始数据矩阵中的高度和宽度下标 `h_start, w_start`。这样，`dx_row` 的第 `i` 行就可以累加到这个位置。因为有 `N` 个样本，展平矩阵中相同样本相同位置的行位置相差 `oSize`，所以可以用 `dx_row[i::oSize, :]` 来获取所有 `N` 个样本在该位置的数据块梯度。原始数据梯度张量 `dx` 对应的位置是 `dx[:, :, h_start:h_start+kH, w_start:w_start+kW]`。

### row2im 函数实现（版本二）

```python
def row2im(dx_row, oH, oW, kH, kW, S):
    nRow, K2C = dx_row.shape[0], dx_row.shape[1]
    C = K2C // (kH * kW)
    N = nRow // (oH * oW)     # 样本数量
    oSize = oH * oW
    H = (oH - 1) * S + kH
    W = (oW - 1) * S + kW
    dx = np.zeros([N, C, H, W])
    for h in range(oH):
        hS = h * S
        hS_kH = hS + kH
        h_start = h * oW
        for w in range(oW):
            wS = w * S
            row = dx_row[h_start + w::oSize, :]
            dx[:, :, hS:hS_kH, wS:wS+kW] += row.reshape(N, C, kH, kW)
    return dx
```

### 卷积层反向传播函数

基于上述讨论，卷积层的反向传播代码如下：

```python
def conv_backward(dZ, K, oH, oW, kH, kW, S=1, P=0):
    # 将 dZ 展平为与 Z_row 形状相同的矩阵
    F = dZ.shape[1] # 将 (N,F,oH,oW) 转换为 (N,oH,oW,F)
    dZ_row = dZ.transpose(0, 2, 3, 1).reshape(-1, F)
    # 计算损失函数关于卷积核参数的梯度
    dK_col = np.dot(X_row.T, dZ_row) # X_row.T @ dZ_row
    dK_col = dK_col.transpose(1, 0)
    dK = dK_col.reshape(K.shape)
    db = np.sum(dZ, axis=(0, 2, 3))
    db = db.reshape(-1, F)
    K_col = K.reshape(K.shape[0], -1).transpose()
    dX_row = np.dot(dZ_row, K_col.T)
    dX_pad = row2im(dX_row, oH, oW, kH, kW, S)
    if P == 0:
        return dX_pad, dK, db
    return dX_pad[:, :, P:-P, P:-P], dK, db
```
