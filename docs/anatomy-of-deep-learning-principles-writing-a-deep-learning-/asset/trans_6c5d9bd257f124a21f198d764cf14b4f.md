上述 `train()` 函数使用训练集中的所有样本一起训练。通常使用批量梯度下降算法 `train_batch()`，即每次从训练集中取一部分样本进行训练。第 2.6 节定义的迭代器函数 `data_iter` 可用于此目的（代码在 Python 文件 `data_set.py` 中）。使用 `train_batch()` 重新训练：

```python
def data_iter(X, y, batch_size, shuffle=False):
    m = len(X)
    indices = list(range(m))
    if shuffle:  # shuffle 为 True 时打乱顺序
        np.random.shuffle(indices)
    for i in range(0, m - batch_size + 1, batch_size):
        batch_indices = np.array(indices[i: min(i + batch_size, m)])
        yield X.take(batch_indices, axis=0), y.take(batch_indices, axis=0)


def train_batch(nn, XX, YY, loss_function, epochs=10000, batch_size=50, learning_rate=1e-0, reg=1e-3, print_n=10):
    iter = 0
    for epoch in range(epochs):
        for X, y in data_iter(XX, YY, batch_size, True):
            f = nn.forward(X)
            loss, loss_grad = loss_function(f, y)
            loss += nn.reg_loss(reg)

            nn.backward(loss_grad, reg)

            nn.update_parameters(learning_rate)

            if iter % print_n == 0:
                print("iteration %d: loss %f" % (iter, loss))
            iter += 1
```

### 4.3.7 改进的通用神经网络框架：分离加权求和与激活函数

上述神经网络框架的 `Dense` 层包含加权求和和激活函数，`Dense` 类包含加权求和和激活函数的前向和反向计算。为增加灵活性，可将加权求和和激活函数分解为 2 个类分别表示，分别进行计算，以便将来添加新的激活函数。

`Layer` 类增加了成员变量 `params` 以保存模型参数，并增加了方法 `reg_loss_grad` 以将损失函数中正则项的梯度加到模型参数的梯度中。

`Dense` 类仅执行加权求和计算，其构造函数接受一个参数，根据不同的随机初始化方法随机初始化权重参数。`Dense` 类接受的单个数据特征不仅是向量，还可以是多通道二维图像。例如，彩色图像包含红、绿、蓝三个颜色通道，每个通道是一个二维数组，因此 `forward()` 和 `backward()` 方法均使用以下代码首先将多通道输入数据展平为一维向量。

```python
x1 = x.reshape(x.shape[0], np.prod(x.shape[1:]))  # Flatten multi-channel x
```
