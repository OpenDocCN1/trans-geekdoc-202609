上述读取股票数据的代码可以表示为一个函数：

```python
import pandas as pd

def read_stock(filename, normalize=True):    
    data = pd.read_csv(filename)
    data = data.iloc[:,1:6]
    data = data.values.astype(float)
    data = pd.DataFrame(data)   
    if normalize:
        data = data.apply(lambda x: (x - np.mean(x)) / (np.max(x) - np.min(x)))
    return data

data = read_stock('sp500.csv')
print(data[:3])
```

股票价格预测是指根据每天的历史股票数据（如开盘价、最高价、最低价、收盘价和交易量）来预测第二天的股票价格（如收盘价）。对于这种序列数据预测问题，每个时刻的数据 `x[t]` 包含开盘价、最高价、最低价、收盘价、交易量等数据特征。待预测的目标值 `y[t]` 是第二天股票的收盘价。

## 7.1.2 概率序列模型、语言模型

### 1. 概率序列模型

序列数据的预测问题有时不需要直接对序列数据与其目标值之间的函数关系进行建模，而是根据序列数据预测目标值的概率，即确定以下条件概率：

`y[t] ~ p(y[t] | x[1], … x[t])`

即根据时刻 `t` 之前的所有序列数据 `(x[1], x[2], ⋯, x[t])`，预测目标值 `y[t]` 的取值概率。通常目标值有很多个甚至无限个。预测问题就是确定可能的 `y[t]` 值作为目标值的各个概率。这种根据序列数据预测目标值概率的模型称为**概率序列模型**。对于自回归问题，该概率序列模型表示为：

`x[t] ~ p(x[t] | x[1], … x[t−1])`

### 2. 语言模型

自然语言处理的基础是建立语言模型。所谓语言模型，就是对句子出现的概率进行建模，即确定一个句子出现的概率。例如，“我是中国人”的概率显然大于“我是中国人”。句子是一系列单词，是单词的有序序列，例如“我是中国人”是由“我”、“是”、“中”、“国”、“人”五个词组成的有序序列（注：原文示例为四词，此处按中文分词逻辑调整为五词，保留原意）。假设句子 `S` 由单词 `w[1], w[2], w[3], ⋯, w[n]` 组成，句子 `S` 的概率用 `P(w[1], w[2], w[3], ⋯, w[n])` 表示。根据概率论，该概率可以表示为：

`P(w[1], w[2], w[3], ⋯, w[n]) = P(w[1]) * P(w[2]|w[1]) * P(w[3]|w[1], w[2]) * ⋯ * P(w[n]|w[1], w[2], ⋯, w[n−1])`

它是一系列单词出现的条件概率的乘积。`w[1]` 首先出现的概率是 `P(w[1])`，`w[1]` 出现时 `w[2]` 出现的概率是 `P(w[2]|w[1])`。在 `w[1], w[2]` 的情况下 `w[3]` 的概率是 `P(w[3]|w[1], w[2])`，在 `⋯, w[1], w[2], ⋯, w[n−1]` 的情况下 `w[n]` 的概率是 `P(w[n]|w[1], w[2], ⋯, w[n−1])`。

根据该公式 (7-3)，如果能知道这些条件概率，即在已知单词 `w[1], w[2], ⋯, w[i−1]` 的情况下，下一个单词 `w[i]` 出现的概率 `P(w[i]|w[1], w[2], ⋯, w[i−1])`，就可以知道由一系列单词组成的句子的概率。因此，语言模型就是根据现有的单词序列，预测下一个单词或词表中每个单词的概率。

## 7.1.3 自回归模型

对于当前时刻的预测目标是下一时刻数据的自回归问题，建立的预测模型称为**自回归模型**（**Auto regressive model**，简称 **AR** 模型）。该模型可以是概率序列模型，也可以是函数模型。如果 `x[t]` 依赖于 `x[1], ⋯, x[t−1]`，则自回归模型可以是函数模型 `f : (x[1], ⋯, x[t−1]) → y[t]` 或概率序列模型 `P(x[t] | x[1], ⋯, x[t−1])`。

如果真实数据 `x[t]` 仅依赖于前固定长度 `τ` 时刻的数据 `(x[t−τ], ⋯, x[t−1])`，则称该序列数据满足**马尔可夫**性质。这种自回归模型也称为**马尔可夫模型**。

最简单的自回归模型假设 `x[t−τ], … x[t−1]` 和 `x[t]` 满足线性关系：

`x[t] = a[0] + a[1]x[t−1] + ⋯ + a[τ]x[t−τ] + ϵ`

其中 `ϵ` 是采样的随机噪声（也称为白噪声）。

## 7.1.4 生成自回归数据

在研究序列模型时，我们可以使用股票价格、自然语言文本等实际序列数据，也可以通过模拟手段生成一些模拟序列数据用于序列模型研究。例如，以下代码通过结合正弦函数和余弦函数形成一个函数，然后对该函数曲线的 y 坐标值进行采样，形成序列数据：

```python
import numpy as np
import matplotlib.pyplot as plt

%matplotlib inline

def gen_seq_data_from_function(f, ts):
    return f(ts)

T = 5000
x = gen_seq_data_from_function(lambda ts: np.sin(ts*0.1) + np.cos(ts*0.2), np.arange(0, T))

plt.plot(x[:500])
plt.show()
```
