

## 学习曲线分析与模型复杂度

随着训练样本数量的增加，获得的模型损失值逐渐增大，因为样本数量大，模型拟合所有样本的难度增加。当样本数量增加到一定程度时，模型损失增加非常缓慢，表明增加样本数据对提升模型效果意义不大。

观察验证集的模型损失：当训练样本数量较小时，验证误差较大，说明拟合模型不够准确，模型泛化能力很弱，导致验证集损失较大。随着训练集样本数量增加，验证误差逐渐减小，表明模型泛化能力越来越好。当模型数量达到 10 时，继续增加训练样本数量不会继续改善验证误差。从该学习曲线可见，训练样本数量约为 10 时，继续增加样本不会进一步提升模型质量。因此可停止增加样本数量，即**早停法**（early stopping）。

对于该简单模型（1 次多项式假设函数），学习曲线帮助确定了训练集大小和最终模型，但因模型过于简单，训练误差和验证误差仍较大。改进方法是使用更复杂、表达力更强的函数（如 3 次多项式）作为假设函数，需人工添加两个特征 `x²`、`x³`。以下代码通过向仅有一个数据特征的 `x_train` 添加这 2 个特征，获得具有 3 个特征的训练集 `x_train_2`：

```python
x_train_2  =np.hstack((x_train,x_train**2,x_train**3))
train_means = x_train_2.mean(axis=0)
train_stdevs = np.std(x_train_2, axis=0, ddof=1)
x_train_2 = (x_train_2 - train_means) / train_stdevs
print(x_train_2[:3])
```
