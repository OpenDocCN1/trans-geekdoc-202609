## 8.3 Variational Autoencoders

### 8.3.1 What is a variational autoencoder?

Variational autoencoders (VAE) is a generative model method proposed by Kingma & Welling et al. (2013) and Rezende, Mohamed & Wierstr et al. (2014).

VAE is an enhancement to the traditional autoencoder (autoencoder, AE). Figure 8-12 is the working process of VAE:

Figure 8-12 Variational automatic autoencoder. The encoder outputs the parameters of the probability distribution. The hidden vector sampled according to the probability distribution is used as the input of the decoder. The decoder outputs data with the same shape as the encoder input data. Both The error as the loss function value.

Unlike AE, which maps a data (such as an image) to a fixed-length vector in a latent space, VAE maps data to a probability distribution (actually maps to a probability distribution parameter), such as mapping an image `x` to a Gaussian distribution parameter, such as outputting the mean parameter `μ` and variance parameter `σ²` of the Gaussian distribution.

If a hidden vector data point is randomly sampled from this probability distribution, according to the characteristics of the Gaussian distribution, this data point should be concentrated near this `μ`, such as the sampled data point `z = μ + σ² * ε`, where `ϵ` is a very small number. Each such sampling point `z` will be mapped to an image `x'` by the decoder, because these `z` are surrounded by `μ`, and these decoded `x'` are also `x` very similar images. That is, the continuous hidden vector `z` generates continuously changing data `x'`, which makes the data more structured in the hidden space, so that the hidden vector can be edited meaningfully, and the data can be changed and controlled according to the needs.

The encoder and decoder functions are determined by the parameters `ϕ`, `θ` of the neural network, and the output of the encoder neural network is the parameter of the probability density of the hidden vector `z` (assumed to be the parameters of the Gaussian distribution `μ`, `σ²`), that is, for each input `x`, the `q[ϕ](z|x)` output by the encoder is a parameter of the probability distribution, which means that `x` maps to different hidden variables The likelihood size (probability size) of `z`. The decoder function `p[θ](x|z)` indicates that the hidden variable `z` is mapped to an output with the same shape as the input `x`, and the output can also be a probability, such as `x` is 28 × 28 size handwritten digital image, where the value of each pixel is 1 or 0, then the output of the decoder `p[θ](x'|z)` is also a tensor of 28 × 28, which means Each position is the probability of the corresponding value (such as 1 or 0) of the input `x`.

### 8.3.2 Loss function

The loss of VAE includes: reconstruction loss and regularization term. The reconstruction loss describes the approximation between the output and the input, and can use the logarithmic loss or square difference loss of logistic regression. The regularization term makes the distribution of the latent variable `zz` as close as possible to the standard normal distribution.

Input a `xx` into the codec pipeline of VAE, the perfect reconstruction output is still `xx`, and the actual output is `xx'` as close as possible to `xx`. In order to reconstruct the input `xx` as much as possible, the probability that the output is `xx` should be the largest, that is, `p[θ](xx|zz)` should be the largest. If the output of the decoder in VAE is not the data itself but the probability `p[θ](xx|zz)` of different data `xx`, then the reconstruction loss corresponding to maximizing this probability is Minimize the logarithm of its negative maximum likelihood `−log(p[θ](xx|zz))`, plus a regular term, for a sample `xx^((i))`, its loss `l[i](θ, ϕ)` can be expressed as:

```
ℒ[i](θ, ϕ) = −𝔼[zz ∼ q[ϕ](zz|xx^((i)))] [log p[θ](xx^((i))|zz)] + 𝕂𝕃(q[ϕ](zz|xx^((i))) ∥ p(zz))
```

For a fixed `xx^((i))`, it can be mapped to a probability distribution `q[ϕ](z|xx^((i)))` random variable `zz`, and for each `zz`, the probability that its output is `xx^((i))` is `p[θ](pmbx^((i))|zz)`, the expected log probability `𝔼[zz ∼ q[ϕ](zz|xx^((i)))] [log p[θ](xx^((i))|zz)]` That is, the output of reconstruction is the expected logarithmic probability of `xx^((i))`, and the maximum probability of reconstructing `xx^((i))` is to maximize the expected logarithmic probability, that is Minimize this negative expected log probability `−𝔼[zz ∼ q[ϕ](zz|xx^((i)))] [log p[θ](xx^((i))|zz)]`.

The second term of the loss function is the regular term, using the Kullback-Leibler divergence to represent the distribution `q[ϕ](zz|xx[i])` of `zz` and the standard positive The distance between the state distribution `p(zz) = N(0, 1)` is to describe their similarity. Using this term as a regular term (penalty term) promotes the probability distribution of `zz` to be as close to the standard normal distribution as possible, just like restricting the weight parameters of the neural network to be as close to 0 as possible. On the one hand, any probability distribution can always be approximated by a multivariate normal distribution, and on the other hand, any normal distribution can also be converted into a standard normal distribution by transformation. Therefore, `zz` can be regarded as a standard normal distribution.

For m samples `xx^((i))`, the total loss function is the sum of each sample loss, ie `∑_{i=1}^{m} ℒ_i`.

From Gaussian distribution `𝒩[0](μ[0], Σ[0])` to Gaussian distribution `𝒩[1](μ[1], Σ[1])` (their covariance matrix `Σ[0]` and `Σ[1]` is a non-singular matrix) the Kullback–Leibler divergence is:

```
D_KL(N_0 ∥ N_1) = 1/2 { tr(Σ_1^{-1} Σ_0) + (μ_1 - μ_0)^T Σ_1^{-1} (μ_1 - μ_0) - k + ln(|Σ_1| / |Σ_0|) }
```

where k is the dimensionality of the vector space. KL divergence describes how similar 2 distributions are.

Assuming that the mean vector and covariance matrix of the Gaussian distribution of the hidden variable `zz` of the variational autoencoder are `μ(z)` and `Σ(z)`, then this distribution and the KL dispersion of the standard normal distribution Degree `D[KL][N(μ(z), Σ(z)) ∥ N(0, 1)]` can be expressed as:

```
D_KL[ N(μ(z), Σ(z)) ∥ N(0,1) ] = 1/2 ( tr(Σ(z)) + μ(z)^T μ(z) - k - log det(Σ(z)) )
```

The above k is the dimension of the Gaussian distribution.

`tr(Σ(z))` is the trace of the covariance matrix `Σ(z)`, which is the sum of the diagonal elements of `Σ(z)`. `det(Σ(z))` is the value of its determinant, and any multivariate Gaussian distribution can always be transformed into a Gaussian distribution whose covariance matrix is a diagonal matrix by a linear transformation of one variable, ie `Σ(z)` can be regarded as a diagonal matrix. Thus the above formula can be simplified as:

```
D_KL[ N(μ(z), Σ(z)) ∥ N(0,1) ] = 1/2 ( ∑_j σ_j^2 + ∑_j μ_j^2 - ∑_j 1 - log ∏_j σ_j^2 )
                                = 1/2 ( ∑_j σ_j^2 + ∑_j μ_j^2 - ∑_j 1 - ∑_j log σ_j^2 )
                                = 1/2 ∑_j ( σ_j^2 + μ_j^2 - 1 - log σ_j^2 )
                                = - 1/2 ∑_{j=1}^k (1 + log(σ_j^2) - (μ_j)^2 - (σ_j)^2)
```

Among them, `σ[j]²` is the jth diagonal element of the diagonal matrix `Σ(z)`. In practice, using `log σ[j]²` instead of `σ[j]²` is more stable in numerical calculation, because the logarithm `log` is more stable than the exponent `exp` and is not easy to overflow. Therefore, what the encoder outputs is actually not the variance itself `σ[j]²` but the logarithm of the variance, ie `log σ[j]²`.

### 8.3.3 Parameter resampling

A sample `xx^((i))` generates a probability distribution through the encoder, and the actual output is the mean value `μ` and `log σ²` of this probability distribution, how to get from this multi The variable Gaussian distribution gets a latent variable `zz`? Because only by inputting a hidden variable `zz` into the decoder, can an output of a decoder be obtained. This requires sampling this Gaussian distribution to get a sampled `zz`, which is then fed into the decoder. However, the sampling operation on the probability distribution cannot be differentiated (derivative). For this reason, a "**reparameterization trick**" is used in the paper to general Gaussian distribution The sampling of `zz ∼ N(μ, Σ)` is transformed into the sampling of the standard normal distribution `u ∼ N(0, 1)`, because between `zz` and `u` There is a simple linear transformation:

```
z = μ + Σ^{1/2} u
```

According to this transformation, as long as the standard normal distribution `u ∼ N(0, 1)` is sampled and a sampling value `ϵ` is obtained, the general normal distribution `z ∼ N(μ, Σ)` sampling:

```
z = μ + Σ^{1/2} ϵ = μ + σ ϵ = μ + (e^{1/2 log σ^2}) ϵ
```

Random sampling of the standard normal distribution `N(0, 1)` makes the random sampling operation no longer depend on `μ` and `log σ²`, so there is no need for derivatives about them, that is, `ϵ` does not depend on `μ` and `log σ²`, there is no need to find `ϵ` on their gradients.

### 8.3.4 Reverse Derivation

The reverse derivation includes the derivation of the reconstruction loss with respect to the model parameters and the derivation of the regularization term with respect to the encoder parameters. First, the reconstruction loss (such as the binary classification cross-entropy loss) is the same as the derivation process of the general neural network. Finally, the gradient of the reconstruction loss with respect to the sampling `z` can be obtained, set to `dz`. According to the above sampling process, the gradient `du` of `μ` is the same as `dz`, and `log σ²` is represented by the letter `E`, then the gradient `dE = dz × ϵ × (e^{1/2 E}) 1/2` of the reconstruction loss with respect to `log σ²`. Knowing `du`, `dE`, the model parameters of the encoder can be reversely derived. The process is also the same as the usual neural network reverse derivation.

The regular term, the KL loss, can be expressed in vector form:

```
- 1/2 np.sum(1 + E - (μ)^2 - e^E)
```

Its gradient `du`, `dE` about `μ`, `E` is:

```
du = μ
dE = - 1/2 (1 - e^E)
```
