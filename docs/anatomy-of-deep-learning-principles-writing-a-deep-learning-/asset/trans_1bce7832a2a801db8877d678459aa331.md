### 8.5.4 GAN 训练技巧

GAN 模型的训练非常困难。基于实践经验，人们总结了一些 GAN 训练的注意事项和技巧。

1.  归一化输入数据。如果图像数据的值被归一化到 -1 和 1 之间，生成器的最终输出激活函数使用 `tanh` 激活函数。
2.  修改损失函数，例如原始 GAN 论文中训练生成器使用的最小损失 `1-D(G(z))`，即 `min log(1-D(G(z)))`，建议将其改为最大化损失 `log(D(G(z)))`，即 `max log(D(G(z)))`。
3.  生成器的输入噪声从高斯分布采样，而不是均匀分布。
4.  对真实数据和生成的数据分别使用批量归一化（`BatchNorm`），不能对混合了真实和生成数据的数据进行批量归一化。
5.  避免稀疏梯度，例如避免产生稀疏梯度的激活函数或网络层，如 `relu` 和 `maxpool`。但建议使用 `Leakrelu`。
6.  使用软标签或噪声。训练判别器时，真实数据标签可以使用 0.7 到 1.2 之间的随机数代替 1，生成数据标签可以使用 0.0 到 0.3 之间的随机数代替 0，并偶尔翻转生成数据的标签，例如从 0 变为 1。
7.  使用 `Adam` 优化器，建议判别器使用 `SGD` 优化器，生成器使用 `Adam` 优化器。
8.  当 `D` 的损失趋向于 0 时，意味着 `D` 太强，且 `D` 的损失方差相对较大，这意味着无法收敛。当 `G` 的损失持续下降时，意味着 `G` 太强且容易崩溃噪声。在训练过程中，可以检查模型参数的梯度。如果绝对值超过 100，则意味着无法收敛。

## 8.6 GAN 损失函数及其概率解释

GAN 对抗神经网络的本质是通过对抗学习，使生成数据的分布和真实数据的分布尽可能一致，使两个分布之间的距离尽可能小。GAN 的损失函数本质上是两个分布相似度的度量：Kullback-Leibler 散度（KL 散度）和 Jensen-Shannon 散度（JS 散度）。

### 8.6.1 GAN 损失函数的全局最优解

GAN 的损失函数可以写成以下积分形式：

$$L(G, D) = \int_x [p_r(x)\log(D(x)) + p_g(x)\log(1 - D(x))]dx$$

其中，`p_r(x)` 和 `p_g(x)` 分别是真实数据和生成数据的分布，引入以下符号：

$$\tilde{x} = D(x), A = p_r(x), B = p_g(x)$$

将 `L(G, D)` 视为 $\tilde{x}$ 的函数，根据函数极值点的必要条件，其对 $\tilde{x}$ 的导数为 0。根据微积分，被积函数的导数几乎处处为 0，即 $\frac{\partial(p_r(x)\log(D(x)) + p_g(x)\log(1 - D(x)))}{\partial\tilde{x}} = 0$。令：

$$(p_r(x)\log(D(x)) + p_g(x)\log(1 - D(x))) = f(\tilde{x}) = A\log\tilde{x} + B\log(1 - \tilde{x})$$

则有：

$$\frac{df(\tilde{x})}{d\tilde{x}} = A\frac{1}{\tilde{x}} - B\frac{1}{1 - \tilde{x}} = \frac{A}{\tilde{x}} - \frac{B}{1 - \tilde{x}} = \frac{A - (A + B)\tilde{x}}{\tilde{x}(1 - \tilde{x})}$$

令 $\frac{df(\tilde{x})}{d\tilde{x}} = 0$，可得判别器损失函数 `L(G, D)` 的极值点为 $f(\tilde{x}^*)$，

$$D^*(x) = \tilde{x}^* = \frac{A}{A + B} = \frac{p_r(x)}{p_r(x) + p_g(x)} \in [0,1]$$

当生成器达到最优时，即生成数据的分布与真实数据的分布完全相同，即 `p_g = p_r`，此时判别器损失函数的极值点为 1/2。此时判别器损失函数 `L(G, D)` 的最优值为：

$$L(G, D^*) = \int_x (p_r(x)\log(D^*(x)) + p_g(x)\log(1 - D^*(x)))dx = \log\frac{1}{2}\int_x p_r(x)dx + \log\frac{1}{2}\int_x p_g(x)dx = -2\log 2$$

根据概率性质，其中 $\int_x p_r(x)dx$ 和 $\int_x p_g(x)dx$ 均为 1。

### 8.6.2 Kullback-Leibler 散度和 Jensen-Shannon 散度

通常有两种方法来度量两个分布是否相似：Kullback-Leibler 散度（简称 KL 散度）和 Jensen-Shannon 散度（简称 JS 散度）。

对于两个概率分布 `p`、`q`，它们的 Kullback-Leibler 散度为：

$$D_{KL}(p \parallel q) = \int_x p(x)\log\frac{p(x)}{q(x)}dx$$

KL 散度描述了概率分布 `p` 偏离 `q` 的程度。对于某个 `x`，如果 `p(x) = q(x)`，则 $\log\frac{p(x)}{q(x)} = \log 1 = 0$；如果 `p(x) \neq q(x)`，则 $\log\frac{p(x)}{q(x)} \neq 0$。当 `p` 和 `q` 处处相等时，`D_KL(p \parallel q) = 0`，否则可以证明 `D_KL(p \parallel q) > 0`。因此，当两个分布完全相同或几乎相同（几乎处处满足 `p(x) = q(x)`）时，KL 散度取得最小值 0。

例如，对于图 8-28 所示的 2 个离散概率分布：

![](EPUB/media/file196.png "fig:")
图 8-28 左右两图的离散概率分布分别为 (0.36, 0.48, 0.16) 和 (0.333, 0.333, 0.333)。

即 `p` 和 `q` 的概率分布分别为：(0.36, 0.48, 0.16) 和 (0.333, 0.333, 0.333)。它们的 KL 散度为：

$$D_{KL}(p \parallel q) = \sum_{x \in \mathcal{X}} p(x)\log(\frac{p(x)}{q(x)}) = 0.36\log\frac{0.36}{0.333} + 0.48\log\frac{0.48}{0.333} + 0.16\log\frac{0.16}{0.333} = 0.0863$$

$$D_{KL}(q \parallel p) = \sum_{x \in \mathcal{X}} q(x)\log(\frac{q(x)}{p(x)}) = 0.333\log\frac{0.333}{0.36} + 0.333\log\frac{0.333}{0.48} + 0.333\log\frac{0.333}{0.16} = 0.096358$$

KL 散度是不对称的，在度量两个同等重要分布的相似性时可能导致错误结果。
