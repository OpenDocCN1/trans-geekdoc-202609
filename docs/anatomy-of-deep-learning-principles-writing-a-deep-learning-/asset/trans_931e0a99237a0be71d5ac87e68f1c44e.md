

# 循环神经网络的状态与计算过程

## 状态变量的概念

对于输入值 `x`，`rf` 类的 `forward()` 方法在计算输出时，不仅依赖于 `x`，还依赖于上一次计算过程中保存的信息 `h`。因此，`f(2)` 和 `f(3)` 的输出及其执行顺序是相关的。`rf` 类中记录计算前中间结果的变量 `h` 称为**状态**。

与上述类类似，循环神经网络也有一个记录/记忆计算过程信息的变量 `h`。在循环神经网络中，该变量称为**隐藏状态（变量）**。在任意时刻 `t`，循环神经网络基于当前输入数据 `x^(⟨t⟩)` 和状态变量 `h^(⟨t−1⟩)`，计算当前时刻的输出 `f^(⟨t⟩)` 和状态 `h^(⟨t⟩)`。即循环神经网络表示的函数是一个 2 个输入、2 个输出的函数：`y, h = f(x, h)` 或 `y^(⟨t⟩), h^(⟨t⟩) = f(x^(⟨t⟩), h^(⟨t−1⟩))`。

时刻 `t` 的状态 `h^(⟨t⟩)` 将作为 `t+1` 时刻的输入参与 `t+1` 时刻的计算：`y^(⟨t+1⟩), h^(⟨t+1⟩) = f(x^(⟨t+1⟩), h^(⟨t⟩))`。

随时间变化的状态变量 `h^(⟨t⟩)` 存储/记忆了历史信息。基于该状态变量表示的历史信息和当前时刻的数据，可以做出更好的预测。

## 初始时刻与时间步计算示例

在初始时刻 `t=0`，状态变量 `h^(⟨−1⟩)` 是一个初始值为 0 的向量。对于上述 3 词语言模型，输入数据是单词 "good" 对应的特征向量 `x^(⟨0⟩) = (1,0,0)`，神经网络将计算当前输出 `y^(⟨0⟩)` 和状态变量 `h^(⟨0⟩)`：

`y^(⟨0⟩), h^(⟨0⟩) = f(x^(⟨0⟩), h^(⟨−1⟩))`

在时刻 `t=1`，输入数据为 `x^(⟨1⟩) = (0,1,0)` 以及前一状态 `h^(⟨0⟩)`，神经网络计算新的输出 `y^(⟨1⟩)` 和状态 `h^(⟨1⟩)`：

`y^(⟨1⟩), h^(⟨1⟩) = f(x^(⟨1⟩), h^(⟨0⟩))`

在时刻 `t=2`，输入数据为 `x^(⟨2⟩) = (0,0,1)` 以及前一状态 `h^(⟨1⟩)`，神经网络计算新的输出 `y^(⟨2⟩)` 和状态 `h^(⟨2⟩)`：

`y^(⟨2⟩), h^(⟨2⟩) = f(x^(⟨2⟩), h^(⟨1⟩))`

## 简单循环神经网络的数学公式

考虑最简单的只有一个神经元或一层神经元的循环神经网络，用 `x^(⟨t⟩), h^(⟨t⟩), f^(⟨t⟩)` 分别表示输入数据、状态变量和输出，循环神经网络的计算过程与只有一个神经元或一层神经元的普通神经网络几乎相同。

$$
\begin{matrix}
h^{\langle t \rangle} = g_{h}(h^{\langle t - 1 \rangle}W_{h} + x^{\langle t \rangle}W_{x} + b_{h}) \\
f^{\langle t \rangle} = g_{f}(h^{\langle t \rangle}W_{f} + b_{y})
\end{matrix}
$$

其中，`g_h`、`g_f` 分别是计算当前状态和输出的激活函数。

如果 `g_h` 是 tanh 函数，`g_y` 是 sigmoid 函数，计算过程可以用 Python 代码表示如下：

```python
class RNN:
    # ...

    def step(self, x):
        # update hidden state
        self.h = np.tanh(np.dot(self.h, self.W_hh) + np.dot(x, self.W_hx)) + self.b
        # Compute the output vector
        y = sigmoid(np.dot(self.h, self.W_hy) + self.b2)
        return y
```

## 时间序列数据的 RNN 计算过程

对于时间序列数据 `x^(⟨1⟩), x^(⟨2⟩), x^(⟨3⟩)`，RNN 计算这些数据的输出过程如下：

```python
rnn = RNN()
y1 = rnn.step(x1) # calculated the implicit h1 at the same time
y2 = rnn.step(x2) # Calculate the implicit h2 at the same time
y3 = rnn.step(x3) # calculated the implicit h3 at the same time
```
