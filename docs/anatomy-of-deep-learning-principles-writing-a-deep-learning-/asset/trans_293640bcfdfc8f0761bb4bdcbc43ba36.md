
梯度裁剪在一定程度上可以解决梯度爆炸问题，但无法解决梯度消失问题。

### 6.5.5 残差网络

梯度爆炸和消失是由网络层始终串联连接引起的。残差网络通过“跳跃”技术打破了这种逐层的网络结构。其思想是在原本相距较远的两个网络层之间建立短路连接。就像药品，如果经过多个管理部门和经销商层层加价后才到达患者手中，患者购买的最终价格可能非常昂贵。如果厂家直销，厂家直接将药品卖给患者，成本就是出厂价。

图 6-58 是常见的神经网络结构：

*x* = *a*^[0] → *a*^[1] → *a*^[2] ⋯ → *a*^[*i*−1] → *a*^[*i*] → *a*^[*i*+1] ⋯ → *a*^[*L*]

通常残差网络的跳跃连接非常规则，如图 6-58 所示为残差网络结构示意图：

图 6-58 残差网络结构示意图，上图为残差网络，下图为一般神经网络

由于存在短路连接，反向推导的梯度可以通过这个跳跃连接直接从弧尾层反馈到弧头层，使得梯度不会因为经过多个中间层而衰减或爆炸。残差网络由中国学者何恺明等人发明。作者发现只要在不同层之间建立这些跳跃连接，就可以训练更深的神经网络。借助残差网络结构，人们甚至可以轻松训练 1000 多层的神经网络。

这种残差网络具有周期性规律，可以看作由相同结构的**残差块**组成，如图 6-60 所示为一个残差块的结构：

图 6-60 残差块是残差网络的结构单元

该残差块由 2 个卷积块组成。每个卷积块先进行加权计算，再计算激活函数输出。在计算第二个卷积块的激活函数之前，该残差块将第一个卷积块的输入和第二个卷积块的加权和输出进行累加，然后通过激活函数输出。第一个卷积块的输入 *x* 经过该卷积块的加权和激活函数后输入到第二个卷积块，第二个卷积块的加权和 *F*(*x*) 与第一个卷积块的输入相加得到 *F*(*x*) + *x*，再输入到第二个卷积块的激活函数。该残差块所表示的函数 *x* → *F*(*x*) + *x* 是在原函数关系 *x* → *F*(*x*) 基础上加上了恒等函数 *x* → *x*。这将迫使 *x* → *F*(*x*) 尽可能接近 0，即将函数 *x* → *F*(*x*) 限制在一个较小的函数子空间内，这类似于正则化对权重函数范围的限制。此外，反向推导时，第二个卷积块输出的梯度通过这个恒等函数直接传递到第一个卷积块的输入，从而避免了梯度消失问题。因此，残差网络既具有防止梯度消失的功能，又具有防止函数过于复杂的正则化功能。

从结构上看，如果将残差块视为像卷积块一样的整体模块，残差神经网络与普通神经网络结构相同，即残差网络是由残差块首尾相连串联而成的结构。即残差网络可表示为：

*F*[1](*x*) + *x* = `ResBlock`[1] → *F*[2](*x*) + *x* = `ResBlock`[2] → ⋯ → *F*[*n*](*x*) + *x* = `ResBlock`[*n*]

其中 `ResBlock`[*i*] 表示一个残差块，普通神经网络可表示为：

*F*[1](*x*) = `convBlock`[1] → *F*[2](*x*) = `convBlock`[2] → ⋯ → *F*[*n*](*x*) = `convBlock`[*n*]

当然，一个残差块可能由多个卷积块组成，每个卷积块可能包含批归一化层、池化层、Dropout 层等，即可能包含几个甚至十几个各种网络层。

### 6.5.6 Google Inception 网络

由于特征图中特征位置的巨大差异和变化，为卷积操作选择正确的卷积核尺寸变得非常困难。对于不同问题，网络层卷积核的尺寸是 3×3 还是 5×5？较大的卷积核利于捕获更全局分布的信息，而较小的卷积核适合捕获更局部分布的信息。同样，对于池化层，选择池化窗口大小也是类似的问题。

Google Inception 网络的思想是让网络自动选择合适的卷积核尺寸或池化窗口尺寸。为实现这一目标，Inception 网络用 Inception 模块替换普通卷积层。将多个不同尺寸的卷积核（包括池化窗口）组合形成一个 Inception 模块。如图 6-61 所示：

图 6-61 Inception 网络结构

Inception 模块的每个卷积核接受相同的输入，并使用 "same" 卷积方式生成不同输出通道数的特征图。这些特征图拼接成最终的特征图。如果 1×1、3×3、5×5、7×7 输出的通道数分别为 96、16、32、64，则这些特征图合成为 96+16+32+64 通道的特征图作为输出。如图 6-62 所示：

图 6-62 Inception 模块

当然，Inception 模块也可以包含池化层。池化层会减小特征图尺寸。为生成与原特征图尺寸相同的池化输出特征图，采用带填充的 "same" 池化操作。

用 Inception 模块替换普通卷积层和池化层，可以通过训练自动学习合适的模型参数，从而自动选择合适的卷积核（池化窗口）尺寸。

上述 Inception 模块会导致模型参数量巨大。例如，输入为 28×28×192 的张量，32 个 5×5×192 卷积核的输出张量为 28×28×32，输出张量的每个元素由 5×5×192 的加权和计算得出，因此总共有 5×5×192×28×28×32 次乘法运算，共 120422400 次计算。

为减少计算量，可以在尺寸大于 1 的 3×3、5×5、7×7 这些卷积核之前插入一个输出通道数相对较少的 1×1 卷积核，如图 6-63 所示：

图 6-63 降维简化的 Inception 网络

如果 1×1 卷积核的输出通道数为 16，即 1×1×16，虽然中间插入了额外一层，但计算量可大幅减少。例如，在上述 5×5×32 中插入 1×1×16 后的计算量为：1×1×192×28×28×16 + 5×5×16×28×28×32 = 12443648。计算量减少了 10 倍。因为池化层总是产生与原输入相同通道数，为使池化层输出更少通道，对池化层则在其后添加这个 1×1 卷积核。

由这些 Inception 模块替换普通卷积和池化层组成的神经网络称为 **Inception 网络**。图 6-64 是著名的 googleNet，即 Inception v1 网络。基于 Inception v1，人们提出了一些改进的网络结构版本，如 Inception V2、V3 和 V4。甚至与残差网络结合。

### 6.5.7 Network in Network (NiN)

普通卷积层是输入的线性卷积操作，即对输入进行线性加权后通过非线性激活函数输出。其结构如图 a) 所示。Network in Network (NiN) “网络中的网络”用一个小网络替换这个单层线性卷积层，如图 6-65 b) 所示。

图 6-65 Network in Network (NiN) “网络中的网络”用小网络替换线性卷积层

除卷积层外，作者在这个小网络中增加了 2 层全连接层。作者认为可以增加网络卷积层的非线性能力。论文还使用**全局平均池化**替代传统全连接层，对每个特征图进行全局平均池化，使每个特征图只产生一个输出值。这能极大减少传统全连接层展平特征图导致的参数过多问题，并可避免模型过拟合。由于每个特征图值产生一个输出值，全局池化层的输入特征图数量必须与类别数一致。对于 10 个类别，特征图数量必须为 10。

图 6-66 Network in Network (NiN) 网络结构

在之前的神经网络中，假设样本之间相互独立，不同数据的输入输出相互独立。对于样本 (*x*^(*i*), *y*^(*i*))，*y*^(*i*) 的值仅取决于其输入 *x*^(*i*)，与其他样本如 (*x*^(*j*), *y*^(*j*)), *j* ≠ *i* 的输入输出无关。这种神经网络可称为“一对一”神经网络。

但也存在一些问题，数据之间存在序列关系。例如，视频由按时间顺序生成的图像组成，文本或句子是单词序列，音乐由一系列音符组成，蛋白质序列是氨基酸序列，股票曲线包含每个时刻的价格。孤立地判断或预测序列中的单个数据是不可靠的，例如孤立理解文章中的一个词或一段话毫无意义，从视频的某张图像孤立判断视频中物体的运动情况如“某图像中的汽车是静止、前进还是后退”都是不可行的。在机器翻译中，将句子中每个词单独处理，如 "how do you do?" 逐字翻译成 "how do you do it?" 显然行不通！

正如卷积神经网络能捕获数据样本特征间的空间相关性，**循环神经网络** (**Recurrent Neural Network**, **RNN**) 是针对序列（时序）关系的、用于**序列数据**的神经网络结构。循环神经网络是一种具有状态记忆的网络，能在时间维度上记忆历史信息，具体表现为：对于某一时刻 *t*，除了当前时刻的输入数据（元素）*x*[*t*] 外，还有时刻 *t* 之前的历史信息记忆隐藏状态 *h*[*t*−1]。因此，时刻 *t* 的输入包括当前数据输入 *x*[*t*] 和历史记忆状态 *h*[*t*−1]，时刻 *t* 的输出包括预测 *y*[*t*] 和新的历史记忆状态 *h*[*t*]。隐藏状态 *h*[*t*] 沿序列传播，理论上可包含之前所有时刻的历史信息。循环神经网络通过这种内部隐藏状态对前序历史信息的记忆来预测当前序列元素，从而对当前时刻做出更好的预测。

循环神经网络可用于数据间存在序列依赖的问题，如自然语言处理（机器翻译、文本生成、词性标注、文本情感分析）、语音处理（识别、合成）、音乐生成、蛋白质序列分析、视频理解分析、股票预测等。

## 7.1 序列问题与模型

数据间存在序列关系的预测问题是基于当前时刻之前的所有序列数据来预测当前时刻的目标值。例如，基于一只股票的所有历史信息预测当前时刻的股价。若用 *x*[*t*] 表示时刻 *t* 的数据特征，*y*[*t*] 表示想要预测的时刻 *t* 的目标值。像任何监督机器学习一样，序列数据的预测是学习一个映射或函数 *f* : (*x*[1], *x*[2], ⋯, *x*[*t*]) → *y*[*t*]，即根据 *t* 时刻之前所有时刻的数据特征 (*x*[1], *x*[2], ⋯, *x*[*t*]) 来预测 *t* 时刻的目标值 *y*[*t*]。

若 *x*[*t*] 和 *y*[*t*] 是同类数据，如 *x*[*t*] 是时刻 *t* 的股价，*y*[*t*] 是时刻 *t* 预测的目标价格，即 *t*+1 时刻的价格 *y*[*t*] = *x*[*t*+1]，则此类序列数据预测问题称为**自回归**问题。
