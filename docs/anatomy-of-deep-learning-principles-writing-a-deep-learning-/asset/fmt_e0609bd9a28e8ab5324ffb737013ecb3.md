
# 卷积神经网络

卷积神经网络是一种专门为图像设计的神经网络。卷积神经网络易于并行化，并能利用图形处理器 GPU 加速函数。2012 年，神经网络巨匠 Hinton 的学生 Alex Krizhevsky 等人采用基于 CUDA GPU 实现的卷积神经网络 AlexNet 一举夺得 ImageNet 竞赛冠军，这重新点燃了人们对神经网络技术研究的热情，开启了基于深层神经网络的深度学习。

卷积神经网络是深度学习中最令人兴奋的神经网络，已成为深度学习的核心。卷积神经网络彻底改变了计算机视觉研究。它们是计算机视觉领域的最佳选择，并持续在许多计算机任务中攻城略地，相关研究论文呈爆发式增长。除了计算机视觉领域，卷积神经网络还被扩展到具有一维序列结构的问题，如音频、文本和基因序列的时间序列分析。卷积神经网络还被扩展到数据为图结构的领域，并发展出了图神经网络等新的神经网络技术。

以下是一些典型的卷积神经网络应用：

*   在图像中检测、识别、定位和标记物体，例如识别图像中有哪些物体及其位置。著名应用包括人脸识别、目标检测和自动驾驶
*   语音识别、声音合成，例如自动将语音转换为文本、文本转换为语音、音乐等
*   用自然语言描述图像和视频
*   自动驾驶汽车中的道路、障碍物识别
*   分析视频游戏画面以指导智能体自动玩游戏
*   生成看起来逼真的图像。例如生成逼真的人脸、视频换脸（如著名的 DeepFake）

卷积神经网络是在全连接神经网络中添加了称为“**卷积层**”的网络层。卷积层的输入和输出直接是图像等多维张量，无需将其展平为一维张量。本章从最简单的一维张量卷积过渡到二维或多维张量卷积、池化等操作，然后介绍卷积层及其代码实现，最后介绍一些经典的现代卷积神经网络结构。

## 6.1 卷积

### 6.1.1 什么是卷积？

卷积是加权求和的推广。对于一组数字，如 `x[1]`、`x[2]`、`x[3]`、⋯、`x[n]`，算术平均数 $\frac{(x_{1} + x_{2} + x_{3} + \cdots + x_{n})}{n}$ 实际上使用相同的权重 $\frac{1}{n}$ 乘以每个数字并累加，以求出这组数字的平均值。也可以将每个数字 `x[i]` 与不同的权重 `w[i]` 相乘，然后累加：

`w[1] * x[1] + w[2] * x[2] + w[3] * x[4] + ⋯ + w[n] * x[n]`

将每个数字与不同权重相乘再累加称为**加权求和**。例如，前面回归中的 `x`、`x`、`w`、`w` 是权重 `w`、`w` 对特征 `x`、`x` 的加权求和。

如果权重之和为 1，即 `w[i]` 满足 $\sum\limits_{i = 1}^{n}w_{i} = 1$，这种特殊的加权求和称为**加权平均**。权重值也可以为负，例如公司的资产负债率、盈利能力比率等可以是负数或正数。

例如，要计算学生某门课程的成绩，可以给平时成绩、实验成绩和期末成绩赋予不同的比例，如分别为 0.2、0.3 和 0.5，然后使用 `(0.2*平时成绩 + 0.3*实验成绩 + 0.5*期末成绩)` 计算学生的总成绩。一组数字的加权求和是从这组数字中提取某个特征，如成绩的加权求和得到“总成绩”特征。

用少于元素数量的权重对一组数字加权，可以从这组数字中提取多个特征。例如，用 3 个权重 1.2、0.3、0.5 对以下数字组加权：

```
4 15 16  7 23 17 10  9  5  8
```

因为权重数量少于数值数量，这 3 个权重可以依次与这组数字中每 3 个相邻数字进行加权求和。首先将 3 个权重与前 3 个数字 (4, 15, 16) 对齐：

**图 6-1** 将权重向量 (1.2, 0.3, 0.5) 与前三个数字 (4, 15, 16) 对齐

得到加权求和：`4*1.2 + 15*0.3 + 16*0.5 = 17.3`

然后与后 3 个数字 (15, 16, 7) 对齐

**图 6-2** 将权重向量 (1.2, 0.3, 0.5) 与 (15, 16, 7) 对齐

得到加权求和：`15*1.2 + 16*0.3 + 7*0.5 = 26.3`

以此类推，最后得到 8 个加权求和：

**图 6-3** 将权重向量 (1.2, 0.3, 0.5) 与最后 3 个数字 (9, 5, 8) 对齐

这种用少于数据数量的权重，通过滑动窗口与数据对齐获得加权求和，从而得到一组新数据的过程，称为**卷积**。

对于长度为 n 的一维数组 `x = (x[0], x[1], x[2], ⋯, x[n-1])` 和长度为 K 的权重向量（也称为**卷积核**）`w = (w[0], w[1], w[2], ⋯, w[K-1])`，用卷积核的第一个元素 `w[0]` 与任意 `x[i]` 对齐，得到的加权求和（卷积值）为：

$z_{i} = \sum\limits_{k = 0}^{K - 1}w_{k}x_{i + k}$

如图 6-4 所示，

**图 6-4** 将权重向量 `w = (w[0], w[1], w[2], ⋯, w[K-1])` 与 `(x[i], x[i+1], x[i+2], ⋯, x[i+K])` 对齐得到加权求和 `z[i]`

当卷积核沿向量 `x` 的每个元素从 `x[0]` 滑动到 `x[n-K]` 时，会生成一系列卷积值，形成结果向量 `z = (z[0], z[1], z[2], ..., z[n-K])`，即结果向量的长度为 n-K+1。例如，输入数据长度为 5，卷积核宽度为 3，则结果卷积向量长度为 5-3+1 = 3，如下图 6-5 所示：

**图 6-5** 有效卷积：数据长度为 5，卷积核宽度为 3，结果卷积向量长度为 5-3+1 = 3

这种卷积方法称为“**有效卷积**”。上述求和可用 Python 代码表示为：

```python
K = w.size
z[i] = np.sum(x[i:i+K]*w)
```

以下代码实现了这种有效卷积操作：

```python
import numpy as np
np.random.seed(5)
x = np.random.randint(low=1, high=30, size=10, dtype='l')
print(x)

w = np.array([1.2, 0.3, 0.5])
n = x.size
K = w.size
z = np.zeros(n - K + 1)
for i in range(n - K + 1):
    z[i] = np.sum(x[i:i+K] * w)
print(w)
print(z)
```
