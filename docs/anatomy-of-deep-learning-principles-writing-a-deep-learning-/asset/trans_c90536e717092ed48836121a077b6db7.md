
因此，感知机函数通常可以写为 `f[w*w](x*x) = sign(x*x*w*w + b)`。

#### 2. 神经元

神经元是对多个输入值的线性加权和执行线性或非线性变换以产生一个或多个输出值的函数或向量值函数。神经元接受多个输入值，对它们执行加权求和，然后通过线性或非线性函数产生一个输出或多个输出值。在神经元中将加权和进行线性或非线性变换的函数称为激活函数。

神经元函数表示如下：

$a = g(\sum\limits_{j}W_{j}x_{j})$

其中 `x[j]` 是输入值，`w[j]` 是对应输入的权重，它们的加权和 $\sum\limits_{j}W_{j}x_{j}$ 通过激活函数 `g` 产生输出值 `a`。神经元通常用圆圈表示，如下图 4-9 所示。

图 4-9 对输入加权并通过激活函数产生输出的人工神经元

有时也会表达神经元的偏置，即神经元函数写为：

$a = g(\sum\limits_{j}W_{j}x_{j} + b)$

相应地，可以将其可视化为如下图 4-10 所示的带偏置的神经元：

神经元也常用下图 4-11 所示的更简化的圆圈表示：

表示该神经元接受 3 个输入 `x[1]`、`x[2]`、`x[3]`（以及一个对应偏置的固定输入特征值 1），并产生一个输出值 $f_{w,b}(x) = g(\sum\limits_{j = 1}^{3}W_{j}x_{j} + b)$

如果用 `W[0]` 表示 `b`，用 `x[0]` 表示 1，则可表示为 $f_{w}(x) = g(\sum\limits_{j = 0}^{3}W_{j}x_{j})$

不同的激活函数决定了神经元的不同功能。线性回归、逻辑回归和感知机都使用具有不同激活函数的神经元。线性回归的激活函数是恒等函数 `g(z) = z`，直接输出加权和；而逻辑回归使用非线性激活函数（sigmoid 函数 `σ(z)`）对加权和进行变换。感知机使用阶跃函数 `sign(z)` 对加权和进行变换。因此，神经元是线性回归、逻辑回归和感知机的泛化。Softmax 回归可视为输出多个值的神经元，即其激活函数是 `softmax()` 函数。神经元的激活函数也可以是其他各种非线性函数，如 tanh、ReLu 函数等。
