
因此，有：

$$
\begin{matrix} 
\frac{\partial\mathcal{L}}{\partial{W W_{,j}}} & {= \sum\limits_{i = 1}^{3}\frac{\partial\mathcal{L}}{\partial z_{i}}\frac{\partial z_{i}}{\partial{W W_{,j}}} = \frac{\partial\mathcal{L}}{\partial z_{j}}\frac{\partial z_{j}}{\partial{W W_{,j}}}} & {= (f_{j} - 1{(y==j)})x x} \\ 
\end{matrix}
$$

也就是说，对于每个 `j` = 1, 2, 3，有：

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,1}}} = (f_{1} - 1{(y==1)})x x
$$

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,2}}} = (f_{2} - 1{(y==2)})x x
$$

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,3}}} = (f_{3} - 1{(y==3)})x x
$$

注意：因为 `W W_{,1}` 是列向量，如果 `x x` 是行向量，则上述 $\frac{\partial\mathcal{L}}{\partial{W W_{,j}}}$ 也是行向量。如果想将 $\frac{\partial\mathcal{L}}{\partial{W W}}$ 写成与 `W W` 形状相同的矩阵形式，则：

$$
\begin{matrix} 
\frac{\partial\mathcal{L}}{\partial{W W}} & {= (\frac{\partial\mathcal{L}}{\partial{W W_{,1}}}^{T},\frac{\partial\mathcal{L}}{\partial{W W_{,j}}}^{T},\cdots,\frac{\partial\mathcal{L}}{\partial{W W_{,C}}}^{T})} \\ 
& {= {x x}^{T}(f_{1} - 1{(y==1)},f_{2} - 1{(y==2)},\cdots,f_{C} - 1{(y==C)})} \\ 
\end{matrix}
$$

如果使用独热向量来表示目标值（标签）`y y`，可以写成更简洁的公式：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {x x}^{T}{(f f - y y)}
$$

其中，假设 `x x`、`f f`、`y y` 均为行向量形式。这是一个与 `W W` 形状相同的矩阵。如果 C 是类别数，n 是数据特征数，则 `x x` 是 1 × n 向量，`x x`^(`T`) 是 n × 1 向量，`W W` 是 n × C 矩阵，因为 `z z` = `x x``W W`、`f f` = `softmax`(`z z`)，所以 `f f`、`y y` 是 1 × C 向量。因此，`x x`^(`T`)(`f f` − `y y`) 是 n × C 的矩阵。

对于矩阵

$$
\begin{matrix} 
{X = \begin{bmatrix} 
{x x^{(1)}} \\ 
{x x^{(2)}} \\ 
\vdots \\ 
{x x^{(i)}} \\ 
\vdots \\ 
{x x^{(m)}} \\ 
\end{bmatrix}} 
\end{matrix}
$$

`F F`、`Y Y` 是对应这些样本的预测值矩阵和目标值矩阵：

$$
\begin{matrix} 
{F = \begin{bmatrix} 
{f f^{(1)}} \\ 
{f f^{(2)}} \\ 
\vdots \\ 
{f f^{(i)}} \\ 
\vdots \\ 
{\mathbf{f}^{(m)}} \\ 
\end{bmatrix}} 
\end{matrix}
$$，
$$
\begin{matrix} 
{Y = \begin{bmatrix} 
{y y^{(1)}} \\ 
{y y^{(2)}} \\ 
\vdots \\ 
{\mathbf{y}^{(i)}} \\ 
\vdots \\ 
{y y^{(m)}} \\ 
\end{bmatrix}} 
\end{matrix}
$$。

则损失函数关于权重 `W W` 的梯度向量形式为：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {X X}^{T}{(F F - Y Y)}
$$

类似地，可以在 Softmax 回归的交叉熵损失中加入正则项。如果目标值用整数表示，损失函数变为：

$$
L(W W) = - \frac{1}{m}\sum\limits_{i = 1}^{m}\log(f_{y^{(i)}}^{(i)}) + \lambda \parallel W W \parallel^{2}
$$

如果目标值用独热向量表示，则损失函数变为：

$$
L(W W) = - \frac{1}{m}\sum\limits_{i = 1}^{m}y^{(i)}\cdot\log(f^{(i)}) + \lambda \parallel W \parallel^{2}
$$

则损失函数关于权重 `W W` 的梯度为：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {X X}^{T}{(F F - Y Y)} + 2\lambda W W
$$

根据梯度计算公式，很容易编写损失函数关于 `W W` 的梯度计算代码。在下面的代码中，假设 `X` 代表多样本的数据特征矩阵，`y` 代表目标值向量，`reg` 是正则化参数 `λ`，`loss_softmax()` 和 `gradient_softmax()` 分别计算损失函数的损失和关于 `W W` 的梯度：

```python
# def loss_gradient(W,X,y,lambda_):
def gradient_softmax(W,X,y,reg):
    m = len(X)
    Z = np.dot(X,W)
    
    I_i = np.zeros_like(Z)
    I_i[np.arange(len(Z)),y] = 1
    F = softmax(Z)
    # F = np.exp(Z) / np.exp(Z).sum(axis=-1,keepdims=True)
    grad = (1 / m) * np.dot(X.T, F - I_i)      # Z.shape[0]
    grad = grad + 2*reg*W
    return grad

def loss_softmax(W,X,y,reg):
    m = len(X)
    Z = np.dot(X,W) 
    Z_i_y_i = Z[np.arange(len(Z)),y]
    negtive_log_prob = - Z_i_y_i + np.log(np.sum(np.exp(Z),axis=-1))
    loss = np.mean(negtive_log_prob) + reg*np.sum(W*W)
    return loss  
```

```python
    nC = W.shape[1]          # 类别数
    # y_one_hot = np.eye(nC)[y[:,0]]

    Z = np.dot(X,W)           # Z 是加权和
    F = softmax(Z)            # F 是概率矩阵
    grad = (1 / m) * np.dot(X.T, (F - y_one_hot)) + 2*reg*W  # 计算该损失的梯度
    return grad  # 原文为 grade，推测为笔误已修正

def loss_softmax_onehot(W,X,y,reg):
    m = len(X) # 首先获取训练样本数
    nC = W.shape[1]
    # y_one_hot = np.eye(nC)[y[:,0]]

    # y_mat = oneHotIt(y)          # 将整数类别编码转换为独热向量形式
    Z = np.dot(X,W)               # Z 是加权和

    loss = (-1 / m) * np.sum(y_one_hot * np.log(F)) + (reg)*np.sum(W*W)
    return loss
```

```python
def gradient_descent_softmax(w,X, y, reg=0., alpha=0.01, iterations=100, gamma=0.8, epsilon=1e-8):
    X = np.hstack((np.ones((X.shape[0], 1), dtype=X.dtype), X))  # 增加一列特征 1 
    v = np.zeros_like(w)
    # losses = []
    w_history = [] 
    for i in range(0, iterations):
        gradient = gradient_softmax(w, X, y, reg)
        if np.max(np.abs(gradient)) < epsilon:
            print("gradient is small enough!")
            print("iterated num is :", i)
            break            
        
        w = w - (alpha * gradient)
        # v = gamma*v + alpha* gradient
        # w = w - v
        # losses.append(loss)
        w_history.append(w)
    return w_history
```
