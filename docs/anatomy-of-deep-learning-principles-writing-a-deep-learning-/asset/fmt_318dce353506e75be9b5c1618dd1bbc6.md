
# 梯度下降法的关键参数与优化策略

梯度下降法最重要的参数是学习率（通常用 `α` 或 `η` 表示）。对于特定的神经网络结构，过大或过小的学习率是影响算法能否收敛的最关键因素。可以通过尝试不同数量级的参数（如 `0.1`、`0.01`、`0.0001` 等），并结合可视化损失曲线或学习曲线来选择合适的学习率。

除了学习率，还应尝试不同的参数优化策略，如动量法、RMSprop、Adam 等著名的参数优化方法。这些优化方法也可能拥有类似学习率的超参数，可采用类似方法尝试选择合适的超参数。

对于批量梯度下降法，可考虑不同的批量大小，选择在时间效率和模型质量之间取得平衡的批量大小进行模型训练。

此外，一些特殊技术（如下文的 Dropout 技术）也可能拥有需要调整的超参数。参数调整（包括网络结构参数）是一项需要长期实践和经验积累的工作。同时也需要从网络上他人的神经网络参数调整经验和技巧中学习，以避免盲目探索。

## 5.3 批量归一化

数据的标准化预处理将数据的不同特征归一化为均值为 0、方差相同的标准分布，避免了大数值导致的数据溢出和不同尺度特征导致的“特征偏见”，使学习算法能以更高的学习率更快收敛。尽管如此，数据经过神经网络层的变换，尤其是随着层数加深，其分布越来越偏离标准正态分布。由于梯度的反向计算是梯度在不同层不断相乘的过程，若数值过大或过小，易导致梯度爆炸或消失，使训练愈发困难。

### 5.3.1 什么是批量归一化？

为解决此问题，有人提出**批量归一化**（Batch Normalization，简称 **BN**）来对网络层的中间输出进行归一化。某网络层的 BN 操作通常是对加权和进行归一化，再通过激活函数 `ϕ` 生成激活值，即它是插在加权操作和激活函数之间的操作。若某网络层的加权和运算为 `z = xW + b`，则在 BN 操作后执行激活函数输出激活值：

`ϕ(BN(z)) = ϕ(BN(xW + b))`

同前所述，将加权和视为单独一层（即全连接层），将激活函数视为单独的激活层。BN 操作可视为插在它们之间的单独批量归一化层（BN 层）。

仅将 `z` 归一化为 `𝒩(0, 1)` 的标准正态分布会限制模型的表达能力，因为无论前层如何变换，该层输出始终服从标准正态分布。BN 操作引入了代表均值和均方误差的可学习参数 `β` 和 `γ`，将归一化为 `𝒩(0, 1)` 的标准正态分布特征变换为正态分布 `𝒩(β, γ)`。因 `β` 和 `γ` 均为可学习参数，故避免了降低模型表达能力的问题。

BN 层接收全连接层输出的加权和 `z` 作为输入，计算这些 `z` 各特征的均值和方差，按均值和方差将 `z` 的各特征归一化为 `𝒩(0, 1)` 标准正态分布，再利用可学习参数 `β`、`γ` 将其变换为 `𝒩(β, γ)` 正态分布。

在无歧义时，用字母 `x` 代指需 BN 归一化的 `z`。对一组样本 `ℬ = x[1], x[2], ⋯, x[m]`，BN 归一化先计算该批样本的均值 `μ[ℬ]` 和方差 `σ[ℬ]`，再用可学习参数 `γ`、`β` 对其缩放和平移：

$$
\begin{matrix}
\mu_{B} & {= \frac{1}{m}\sum\limits_{i = 1}^{m}x_{i}} \\
\sigma_{B}^{2} & {= \frac{1}{m}\sum\limits_{i = 1}^{m}(x_{i} - \mu_{B})^{2}} \\
\hat{x_{i}} & {= \frac{x_{i} - \mu_{B}}{\sqrt{\sigma_{B}^{2} + \epsilon}}} \\
y_{i} & {= \gamma \odot x_{i} + \beta} \\
\end{matrix}
$$

若矩阵 `X` 每行代表一个数据，可用以下代码计算数据各特征的均值 `mean` 和方差 `var`：

```python
mean = X.mean(axis=0)
var = ((X - mean) ** 2).mean(axis=0)
```

即沿行方向计算均值和方差。当然也可用 numpy 的 `var()` 函数计算方差：

```python
var = np.var(X, axis=0)
```

此处假设每个数据 `x[i]` 为向量或一维数组，即 `X` 为二维数组或矩阵。后续将看到数据可能为多维数组（如多通道图像），无论 `x[i]` 是一维还是多维数组，其每个元素均视为一个特征。对多维数组的 `x[i]`，可用 numpy 的 `reshape()` 函数将其展平为一维数组（向量），使 `X` 仍为二维数组（矩阵）。以下代码可确保 `x[i]` 展平为一维向量：

```python
n_X = X.shape[0]
X_flat = X.ravel().reshape(n_X, -1)  # X_flat = X.reshape(n_X, -1)
```

以下为批量归一化的前向计算代码：

```python
n_X = X.shape[0]
X_flat = X.ravel().reshape(n_X, -1)
mu = np.mean(X_flat, axis=0)
var = np.var(X_flat, axis=0)
X_norm = (X_flat - mu) / np.sqrt(var + 1e-8)
out = gamma * X_norm + beta
return out.reshape(self.X_shape)
```

因神经网络训练通常采用批量梯度下降法，每次梯度下降用一小批样本更新模型参数。因此批量归一化不计算整个训练集样本的均值和均方误差，而是在训练过程中用一小批样本计算均值和均方误差，故名批量归一化。

预测时，数据的前向计算也需经 BN 层处理，但不需且不应再次进行 BN 操作。这要求使用训练过程中已确定的 BN 层均值、方差及参数（如 `β`、`γ`）进行变换。然而迭代过程中每步计算的均值和均方误差不同，预测所用的均值和方差不应仅依赖某一迭代步的结果。为此，可对所有迭代步的均值和均方误差求平均，通常用移动平均法计算移动均值和方差。

若用 `running_mu` 和 `running_var` 表示训练过程中均值和方差的移动平均，计算代码如下：

```python
running_mu = momentum * running_mu + (1 - momentum) * mu
running_var = momentum * running_var + (1 - momentum) * var
```
