
$$
\begin{matrix} 
W^{(l)} & = W^{(l)} - \alpha\frac{\partial\mathcal{L}}{\partial W^{(l)}} \\ 
b^{(l)} & = b^{(l)} - \alpha\frac{\partial \mathcal{L}}{\partial b^{(l)}} 
\end{matrix}
$$

### 4.3.2 网络层的代码实现

神经网络的前向计算和反向推导是逐层进行的。为了实现通用的神经网络框架，每个神经网络层可以用一个 `Layer` 类来表示。`Layer` 类代表一个抽象的神经网络层。除了初始化构造函数 `__init__()` 外，它主要包含 2 个方法：前向计算 `forward(self, x)` 接受输入 `x` 生成输出；反向推导 `backward(self, grad)` 接受反向传递的梯度 `grad`，`grad` 是损失函数关于其输出的梯度，来自下一层（对于最后一层，`grad` 是损失函数关于输出层输出的梯度）。`backward()` 计算该层相关参数的梯度（如累积和 `Z` 和权重参数 `W`）。

```python
class Layer:
    def __init__(self):
        pass
    def forward(self, x):        
        raise NotImplementedError
        
    def backward(self, grad):      
        raise NotImplementedError
```

在 `Layer` 类的基础上，可以定义派生类 `Dense` 来表示全连接层。所谓全连接层是指该层每个神经元都接受上一层所有的输入。`Dense` 类构造函数 `__init__()` 的参数 `input_units`、`output_units` 和 `activation` 分别代表输入大小、输出大小和激活函数。

**前向计算** `forward()` 函数根据输入 `x`、权重 `W` 和偏置 `b` 计算累积值 `Z`，然后输入激活函数 `g` 计算输出值 `A`。即：

$$Z^{[l]} = X W^{[l]} + b^{[l]} = A^{[l-1]} W^{[l]} + b^{[l]}$$

$$A^{[l]} = g^{[l]}(Z^{[l]})$$

**反向计算（反向推导）** 接受损失函数关于输出值 `A` 的梯度 $\frac{\partial L}{\partial A^{[l]}}$，计算损失函数关于 `W`、`b`、`x` 的梯度 $\frac{\partial L}{\partial Z^{[l]}}$、$\frac{\partial L}{\partial W^{[l]}}$、$\frac{\partial L}{\partial A^{[l-1]}}$。

因为代码中无法输入偏导数或梯度符号，用 `dA^{[l]}`、`dZ^{[l]}`、`dW^{[l]}`、`db^{[l]}` 分别表示 $\frac{\partial L}{\partial A^{[l]}}$、$\frac{\partial L}{\partial Z^{[l]}}$、$\frac{\partial L}{\partial W^{[l]}}$、$\frac{\partial L}{\partial b^{[l]}}$。

这些梯度的公式表达为：

$$dZ^{[l]} = dA^{[l]} \cdot g'(Z^{[l]})$$

$$dW^{[l]} = (A^{[l-1]})^T dZ^{[l]}$$

$$db^{[l]} = \texttt{np.sum}(dZ^{[l]}, \texttt{axis}=0, \texttt{keepdims}=\texttt{True})$$

$$dA^{[l-1]} = dZ^{[l]} (W^{[l]})^T$$

以下是网络层代码的实现：

```python
class Layer:
    def __init__(self):
        pass
    def forward(self, x):        
        raise NotImplementedError
        
    def backward(self, grad):      
        raise NotImplementedError

class Dense(Layer):
    def __init__(self, input_dim, out_dim, activation=None): 
        super().__init__()
        self.W = np.random.randn(input_dim, out_dim) * 0.01  # 0.01 * np.random.randn
        self.b = np.zeros((1, out_dim))  # np.zeros(out_dim)     
      
        self.activation = activation
        self.A = None
        
    def forward(self, x):
        # f(x) = xw+b
        self.x = x
        Z = np.matmul(x, self.W) + self.b
        self.A = self.g(Z)       
        return self.A
    
    def backward(self, dA_out):
        # backpropagation    
        A_in = self.x       
        dZ = self.dZ_(dA_out)
        
        self.dW = np.dot(A_in.T, dZ)
        self.db = np.sum(dZ, axis=0, keepdims=True)          
        dA_in = np.dot(dZ, np.transpose(self.W))    
        return dA_in
    
    def g(self, z):
        if self.activation == 'relu':
            return np.maximum(0, z)  
        elif self.activation == 'sigmoid':
            return 1 / (1 + np.exp(-z)) 
        else:
            return z
        
    def dZ_(self, dA_out):
        if self.activation == 'relu':
            grad_g_z = 1. * (self.A > 0)     # should actually be 1. * (self.Z > 0), but both are equivalent
            return np.multiply(dA_out, grad_g_z)
        elif self.activation == 'sigmoid':
            grad_g_z = self.A * (1 - self.A) 
            return np.multiply(dA_out, grad_g_z)
        else:
            return dA_out
```

### 4.3.3 网络层的梯度测试

只有确保神经网络的前向和反向推导正确，神经网络模型才能进一步训练。通过比较，如果两者误差很小，说明解析梯度的计算基本正确，可以放心进行下一步。

以下代码假设 `f` 是多元参数 `p` 的函数，即给定 `p` 可以计算函数值 `f(p)`。如果已知损失函数 $\mathcal{L}$ 关于 `f` 的梯度 $\frac{\partial \mathcal{L}}{\partial f}$，则可以在此基础上计算损失函数 $\mathcal{L}$ 关于 `p` 的梯度。即：

$$\frac{\partial \mathcal{L}}{\partial p} = \frac{\partial \mathcal{L}}{\partial f} \frac{\partial f}{\partial p}$$

用 `grad` 和 `df` 分别表示 $\frac{\partial \mathcal{L}}{\partial p}$、$\frac{\partial \mathcal{L}}{\partial f}$，即：

$$\texttt{grad} = \texttt{df} \frac{\partial f}{\partial p}$$

如果 `f` 包含多个输出值，即 $f(p) = (f_1(p), f_2(p), \dots, f_n(p))^T$ 是多元参数 `p` 的向量值函数，如果已知损失函数 $\mathcal{L}$ 关于 `f` 的梯度，也可以根据链式求导法则计算 $\mathcal{L}$ 关于 `p` 的梯度，即关于每个参数 $p_j$ 的偏导数：

$$\frac{\partial \mathcal{L}}{\partial p_j} = \sum_i \frac{\partial \mathcal{L}}{\partial f_i} \frac{\partial f_i}{\partial p} = \sum_i \texttt{df}_i \frac{\partial f_i}{\partial p_j}$$

在已知 $\frac{\partial \mathcal{L}}{\partial f_i}$ 的情况下，可以根据上式用数值求导求出 $\frac{\partial \mathcal{L}}{\partial p_j}$，即对 $\frac{\partial f_i}{\partial p_j}$ 进行数值求导：

$$\frac{\partial f_i}{\partial p_j} \simeq \frac{f_i(p_j + \epsilon) - f_i(p_j - \epsilon)}{2\epsilon}$$
