
# 卷积层的矩阵乘法实现

## 核心矩阵变换

```python
K.reshape(K.shape[0], -1).transpose()
```

其中，每一列对应一个卷积核。

对于一个样本数据，需要按“从上到下、从左到右”的顺序将其划分为 $o_H \times o_W$ 个三维数据块，并将每个数据块展平成行向量。如图 6-42 所示，假设只有一个样本，位置为 $(h, w)$ 的数据块可通过以下代码提取：

```python
patch = x[:, h*S: h*S+kH, w*S: w*S+kW]
```

将其重塑为行向量。若仅有一个样本（即 $N=1$），该行向量将被放入结果矩阵的第 `h*oW+w` 行：

```python
X_row[h*oW+w, :] = np.reshape(patch, -1)
```

因此，一个样本被展平为矩阵的 $o_H \times o_W$ 个行向量。若有 $N$ 个样本，则依次对每个样本执行上述展平操作，总共有 `oH*oW*N` 行。$N$ 个样本对应位置的数据块在展平矩阵中对应的行向量间隔为 $o_H \times o_W$，因此 $N$ 个样本的代码可写为：

```python
patch = x[:, :, h*S: h*S+kH, w*S: w*S+kW]  # 同时提取 N 个样本对应的数据块
oSize = oH * oW         # oSize 为单个样本的数据块总数
X_row[h*oW+w::oSize, :] = np.reshape(patch, (N, -1))
```

该代码先将 $N$ 个样本的数据块重塑为 `(N, -1)` 形状，再按步长 $o\_Size = o_H \times o_W$ 放入对应行。

## 完整实现：4D 张量转 2D 矩阵

```python
def im2row(x, kH, kW, S=1):
    N, C, H, W = x.shape
    oH = (H - kH) // S + 1
    oW = (W - kW) // S + 1
    row = np.empty((N * oH * oW, kH * kW * C))
    oSize = oH * oW
    for h in range(oH):
        hS = h * S
        hS_kH = hS + kH
        h_start = h * oW
        for w in range(oW):
            wS = w * S
            patch = x[:, :, hS:hS_kH, wS:wS+kW]
            row[h_start + w::oSize, :] = np.reshape(patch, (N, -1))
    return row
```

## 卷积运算的矩阵乘法表示

卷积层的卷积运算可表示为数据矩阵 `X_row` 与卷积核矩阵 `K_col` 的乘法，卷积结果矩阵 $Z = \texttt{np.dot}(X\_row, K\_col)$。$Z$ 的形状为行数 $N \times o_H \times o_W$，列数 $F$。将其重塑为 $(N, o_H, o_W, F)$，再将第 4 个轴（axis=3，即 $F$ 所在轴）移至第 2 个轴位置，变为形状为 $(N, F, o_H, o_W)$ 的张量：

```python
Z = Z.reshape(N, oH, oW, -1)
Z = Z.transpose(0, 3, 1, 2)
```

## 卷积前向传播完整实现

```python
def conv_forward(X, K, S=1, P=0):
    N, C, H, W = X.shape
    F, C, kH, kW = K.shape
    if P == 0:
        X_pad = X
    else:
        X_pad = np.pad(X, ((0, 0), (0, 0), (P, P), (P, P)), 'constant')
    X_row = im2row(X_pad, kH, kW, S)
    K_col = K.reshape(K.shape[0], -1).transpose()
    Z_row = np.dot(X_row, K_col)
    oH = (X_pad.shape[2] - kH) // S + 1
    oW = (X_pad.shape[3] - kW) // S + 1
    Z = Z_row.reshape(N, oH, oW, -1)
    Z = Z.transpose(0, 3, 1, 2)
    return Z
```
