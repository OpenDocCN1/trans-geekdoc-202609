## 分布分析方法

如何理解这组实数在实数空间 `R` 中的分布？或者说它们服从什么样的概率分布？可以将实数轴划分为许多小区间，统计落在每个小区间内的实数频数。只要数据量足够大，这个频数就能足够接近概率，从而了解这组实数在实数空间 `R` 中的概率分布。

下面的代码以直方图和曲线的形式展示了这组数据的近似概率频数分布：

```python
import numpy as np
from matplotlib import pyplot as plt

%matplotlib inline

def draw_hist(plt, x, bin_num=10):
    xmin, xmax = np.min(x), np.max(x)
    bins = np.linspace(xmin, xmax, bin_num)
    plt.hist(x, bins=bins, density=True, alpha=0.7)
    x2 = np.sort(x)  # 对实数进行排序
    p, _ = np.histogram(x2, bins, density=True)  # 计算 bins 中每个区间的频数 p
    p_x = np.linspace(xmin, xmax, len(p))
    plt.plot(p_x, p, 'b-', linewidth=2, label='real data')

draw_hist(plt, x, 26)
plt.show()
```

**Figure 8-1** 一组实数的统计直方图

通过直方图可以观察到，这组实数的分布接近高斯分布，高斯分布的中心点（均值）约为 `4.0`。也很容易计算出这组实数的标准差约为 `0.5`。

## 数据生成验证

实际上，这些实数确实是从均值为 `4`、方差为 `0.5` 的正态分布中采样得到的，生成代码如下：

```python
import numpy as np

np.random.seed(0)
mu = 4
sigma = 0.5
M = 10000
x = np.random.normal(mu, sigma, M)
print(x[:5])
np.save('real_values.npy', x)
```

输出结果：

```
[4.88202617 4.2000786  4.48936899 5.1204466  4.933779  ]
```

即这组实数 `{x^(i)}` 服从均值为 `4`、标准差为 `0.5` 的高斯分布。如 Figure 8-3 所示：
