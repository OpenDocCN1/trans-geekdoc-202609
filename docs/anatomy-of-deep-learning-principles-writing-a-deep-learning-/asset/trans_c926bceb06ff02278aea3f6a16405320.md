从这个反向计算图可以看出，*f*^′^(*x*) 来自两条路径的偏导数累积：一条是从 *u* 的反向推导，另一条是从 *v* 的反向推导，即 *f*^′^(*x*) = *f*^′^(*u*)*u*^′^(*x*) + *f*^′^(*v*)*v*^′^(*x*) = *f*^′^(*u*)，而 *f*^′^(*u*) 仅来自 *s* 的反向导数，即 *f*^′^(*u*) = *f*^′^(*s*)*s*^′^(*u*)，同理 *f*^′^(*v*) = *f*^′^(*t*)*t*^′^(*v*)。因此有：

*f*^′^(*x*) = *f*^′^(*s*)*s*^′^(*u*)*u*^′^(*x*) + *f*^′^(*t*)*t*^′^(*v*)*v*^′^(*x*)

也就是说，先求 *f*^′^(*s*)，再求 *s*^′^(*u*)，再求 *u*^′^(*x*)，就可以求出 *f*^′^(*s*)*s*^′^(*u*)*u*^′^(*x*)，即沿着正向计算的反方向计算导数，*f*^′^(*t*)*t*^′^(*v*)*v*^′^(*x*) 也是同样的反向推导过程。

已知 *f*^′^(*s*) = 1，*f*^′^(*t*) = 1，*s*^′^(*u*) = 2*u*，*t*^′^(*v*) = 2*v*，*u*^′^(*x*) = 2，*v*^′^(*x*) = 1，所以最终 *f*^′^(*x*) 为：

*f*^′^(*x*) = 1 × 2*u* × 2 + 1 × 2*v* × 1

# 前馈神经网络的前向计算

前馈神经网络由多层神经元组成，每层神经元接收上一层的输入 *a*^\[*l*−1\]，并利用神经元自身的模型参数 *w*^\[*l*\]、*b*^\[*l*\] 计算加权和 *z*^\[*l*\] = *a*^\[*l*−1\]*w*^\[*l*\] + *b*^\[*l*\]。然后通过激活函数 *g*^\[*l*−1\] 生成自身的输出 *a*^\[*l*\]，该输出作为下一层神经元的输入，使计算结果层层传递至输出层。输出层的输出与目标值计算某种损失 ℒ(*a*^\[*L*\]*, y*)。

对于上述 2 层神经网络，各层神经元的加权和 *z*^\[1\]、*z*^\[2\] 和输出值 *a*^\[1\]、*a*^\[2\] 可按以下顺序计算，最后计算损失函数值 ℒ(*a*^\[2\]*, y*)：

*z*^\[1\] = *W*^((1))*x* + *b*^\[1\] → *a*^\[1\] = *σ*(*z*^\[1\]) → *z*^\[2\] = *W*^\[2\]*a*^\[1\] + *b*^\[2\] → *a*^\[2\] = *σ*(*z*^\[2\]) → ℒ(*a*^\[2\]*, y*)

神经网络函数可视为其模型参数和中间变量的函数。计算损失函数对这些参数和变量的梯度（导数）过程，与计算任意复杂函数反向导数的过程相同。从最外层的损失函数开始，“由外向内”沿着神经网络函数值正向计算的反方向，依次计算这些中间变量和参数的梯度。

过程为：先求损失函数对输出层输出的梯度；若已得到损失函数对某层 *l* 输出的梯度，即 $\frac{\partial\mathcal{L}}{\partial a^{[l]}}$，根据该层各神经元的激活函数，可得该层神经元加权和 *z*^\[*l*\] 的梯度 $\frac{\partial\mathcal{L}}{\partial z^{[l]}}$（假设该层神经元激活函数为 *g*，即 $\frac{\partial\mathcal{L}}{\partial z^{[l]}} = g'(\frac{\partial\mathcal{L}}{\partial a^{[l]}})$）；根据公式 ()，在已知 $\frac{\partial\mathcal{L}}{\partial z^{[l]}}$ 的情况下，可求出损失函数对该层模型参数 *W*^\[*l*\] 和输入 *a*^\[*l*−1\] 的梯度 $\frac{\partial\mathcal{L}}{\partial W^{[l]}}$ 和 $\frac{\partial\mathcal{L}}{\partial a^{[l-1]}}$。

对于上述 2 层神经网络，反向推导过程如下：

$$
\frac{\partial\mathcal{L}}{\partial a^{[2]}} \rightarrow \frac{\partial\mathcal{L}}{\partial z^{[2]}} \rightarrow \left(\frac{\partial\mathcal{L}}{\partial W^{[2]}}, \frac{\partial\mathcal{L}}{\partial b^{[2]}}, \frac{\partial\mathcal{L}}{\partial a^{[1]}}\right) \rightarrow \frac{\partial\mathcal{L}}{\partial z^{[1]}} \rightarrow \left(\frac{\partial\mathcal{L}}{\partial W^{[1]}}, \frac{\partial\mathcal{L}}{\partial b^{[1]}}\right)
$$

模型各层中间变量和参数的损失函数梯度依赖于正向计算过程中的结果（如 *a*^\[*l*\]）。为避免重复计算这些值，可在正向计算过程中将这些结果存储在神经网络对应层中，反向推导时直接使用这些存储结果，从而避免连续重复计算，提高效率。从计算图角度看，这些中间结果可保存在计算图对应节点上。当前深度学习平台通过计算图表达神经网络的前向传播和反向推导过程，并在计算图对应节点上保存相关中间计算结果。

因此，计算图不仅能保证前向和反向计算的正确计算顺序，还能保存中间结果以提高计算效率。

## 4.2.3 损失函数对输出的梯度

反向推导首先计算损失函数对最终输出层输出的梯度，然后从输出层沿着前向传播的反方向，依次计算损失函数对各层中间变量和参数的梯度，直到输入层。

不同问题（回归、分类）的损失函数定义不同。下面讨论几种常见损失函数对输出层梯度的计算方法。

### 1. 二元交叉熵损失函数对输出的梯度

针对二分类问题，输出层为一个逻辑回归神经元，*z* 表示该神经元输入的加权和。该加权和通过 Sigmoid 函数产生 (0, 1) 之间的输出值 *a* = *σ*(*z*)，表示样本属于两类中某一类的概率（属于另一类的概率为 1 − *a*）。对于输出层，本书习惯用 *f* = *a* 表示输出值，即 *f* = *σ*(*z*)，用 *y* 表示取值为 1 或 0 的目标值。

根据 3.5 节，二分类的交叉熵损失 *L*(*f*, *y*) = −(*y* log(*f*) + (1 − *y*) log(1 − *f*)) 对 *f* 的导数为：

$$
\frac{\partial L}{\partial f} = - \left(\frac{y}{f} - \frac{1 - y}{1 - f}\right) = \frac{f - y}{f(1 - f)}
$$

而 *f* = *σ*(*z*) 对 *z* 的导数为：

$$
\frac{\partial f}{\partial z} = \sigma(z)(1 - \sigma(z)) = f(1 - f)
$$

因此，*L*(*f*, *y*) 对 *z* 的导数为：*f* − *y*。

对于二分类问题，多个样本的交叉熵为单个样本交叉熵的均值：

$$
L(F, Y) = \frac{1}{m}\sum_{i=1}^{m} L_i(y^{(i)}, f^{(i)}) = - \frac{1}{m}\sum_{i=1}^{m} \left[ y^{(i)}\log(f^{(i)}) + (1 - y^{(i)})\log(1 - f^{(i)}) \right]
$$
