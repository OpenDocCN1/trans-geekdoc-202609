## 7.11 序列到序列（seq2seq）模型

序列到序列（seq2seq）模型是 Google 提出的一种用于机器翻译的深度学习模型。该模型采用编码器-解码器结构，如图 7-50 所示。输入序列通过编码器循环神经网络生成一个上下文向量。该上下文可被视为输入序列的信息压缩或特征。此上下文向量被用作解码器初始时刻的隐藏状态输入。解码器初始时刻的输入通常是一个表示序列开始的常量。解码器基于每一时刻的状态和数据生成当前时刻的预测值和状态向量，该预测值被用作下一时刻的输入数据。解码器持续产生预测，直到遇到表示结束的预测或超过一定的时间步数。

图 7-50 序列到序列（seq2seq）模型的结构。输入（词）序列通过编码器循环神经网络生成 S 上下文向量，作为解码器的隐藏状态输入。解码器从初始输入（如特殊的起始词 SOS）开始，可产生一系列输出（词），直到结束词 EOS。

编码器和解码器均使用循环神经网络（RNN）来处理长度可变的序列输入和输出。输入序列被输入编码器以生成一个状态变量，也称为**上下文变量（内容向量）**。解码器将此上下文变量作为其初始时刻的输入状态变量，并可生成输出序列。例如，在机器翻译中，编码器接收一种语言的输入句子（词序列），解码器输出另一种语言的句子（词序列）。seq2seq 模型迅速扩展到了其他类似机器翻译的问题，如对话、图像描述、文本摘要、对联生成等。

### 机器翻译

机器翻译是将一种语言的句子（词序列）转换（翻译）为另一种语言的句子（词序列）。这种序列到序列的转换问题可以用由编码器和解码器组成的 Seq2Seq 模型来建模，如图 7-50 所示。编码器接受某一语言的句子（即词序列），该词序列长度可以任意。编码器 RNN 依次处理输入词序列的每个词，直到遇到结束词。编码器输出一个对输入句子进行编码的上下文向量。该上下文向量可以是最后一时刻的输出（如隐藏状态），也可以是每一时刻的输出（如隐藏状态）。

解码器接收此编码后的上下文和一个特殊的起始词，依次生成一系列词，直到遇到一个特殊的结束词。解码器的起始词和结束词是人为设定的词，例如分别使用 3 个英文字母 "SOS" 和 "EOS" 作为起始词和结束词。在机器翻译中，这种特殊的起始词和结束词通常在输入句子和翻译句子之后人为添加。

在训练阶段，编码器和解码器基于预测词序列与目标词序列的误差损失进行训练。在推理阶段，解码器每次从当前词预测并采样下一个词，直到输出最终的词序列。

### 7.11.1 Seq2Seq 模型的实现

Seq2Seq 模型由编码器和解码器两个循环神经网络组成。编码器除循环神经单元本身的隐藏状态外不输出任何信息，因此编码器主要就是循环神经网络单元本身。

最简单的编码器是一个输入数据序列（如词序列）并计算表示序列内容的上下文信息的循环神经网络。对于最简单的编码器，此上下文信息即为最后一时刻的隐藏状态。在每一时刻，它接受输入数据和上一时刻的隐藏状态，并计算当前时刻的隐藏状态作为当前时刻的输出。计算过程如图 7-51 左子图所示：

图 7-51 编码器接受当前时刻输入词的独热向量和上一时刻的隐藏状态，计算当前时刻的隐藏状态作为当前时刻的输出；解码器接受当前时刻输入词的独热向量和上一时刻的隐藏状态，计算当前时刻的隐藏状态，该隐藏状态通过一个线性层输出一个向量，表示词表中每个词作为下一个词的得分。

以下编码器 `EncoderRNN` 是一个 GRU 神经网络。它与之前的 GRU 类唯一的区别在于增加了一个辅助函数 `word2vec()`，用于将词索引序列 `word_indices_input` 转换为独热向量。`EncoderRNN` 是一个 GRU，因此其构造函数参数与 GRU 的参数相同。`input_size` 和 `hidden_size` 分别代表输入数据的长度和隐藏状态向量的长度。

```
from rnn import *

def one_hot(size, indices, expend=False):
    x = np.eye(size)[indices.reshape(-1)]
    if expend:
        x = np.expand_dims(x, axis=1)
    return x

class EncoderRNN(object):
    def __init__(self, input_size, hidden_size, num_layers=1):
        super(EncoderRNN, self).__init__()
        self.input_size, self.hidden_size = input_size, hidden_size
        self.num_layers = num_layers
        self.gru = GRU(input_size, hidden_size, num_layers)

    def word2vec(self, word_indices_input):
        return one_hot(self.input_size, word_indices_input, True)

    def forward(self, word_indices_input, hidden):
        # self.encode_input = one_hot(self.input_size, word_indices_input, True)
        self.encode_input = self.word2vec(word_indices_input)
        output, hidden = self.gru(self.encode_input, hidden)
        return output, hidden

    def __call__(self, word_indices_input, hidden):
        return self.forward(word_indices_input, hidden)

    def initHidden(self, batch_size=1):
        return np.zeros((self.num_layers, batch_size, self.hidden_size))

    def parameters(self):
        return self.gru.parameters()

    def backward(self, dhs):
        dinput, dhidden = self.gru.backward(dhs, self.encode_input)
```
