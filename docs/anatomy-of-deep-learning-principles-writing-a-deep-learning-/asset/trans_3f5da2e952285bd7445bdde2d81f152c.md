
然后梯度向量与增量向量的点积可以写成矩阵乘积的形式：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)Δx = Δxx^(T)∇ff(xx)^(T)`

如果梯度也写成列向量，梯度向量与增量向量的点积可以写成矩阵乘积：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)^(T)Δx = Δxx^(T)∇ff(xx)`

如果自变量写成行向量形式，梯度写成列向量形式，即：

`xx = (x[1], x[2], ⋯, x[n])`

`Δxx = (Δx[1], Δx[2], ⋯, Δx[n])`

```
∇f f(x x) = (∂f/∂x_1, ∂f/∂x_2, ⋯, ∂f/∂x_n)^T
```

但：

`f(xx + Δ) − f(xx) ≃ Δxx∇f(xx)`

如果梯度 `∇[x]ff(xx)`、`f(xx)`、`xx` 都写成行向量形式，则：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)Δx^(T) = Δxx∇ff(xx)^(T)`

对于多元函数 `f(xx)`，如果自变量 `xx` 写成矩阵形式，则 `f(xx)` 关于 `xx` 的梯度，虽然是一个向量，但有时写成与 `xx` 形状相同的矩阵形式，这样容易知道哪个偏导数对应哪个变量，即：

```
f'(x x) = dy/dx x = [ ∂y/∂x_11  ∂y/∂x_21  ⋯  ∂y/∂x_n1
                      ∂y/∂x_12  ∂y/∂x_22  ⋯  ∂y/∂x_n2
                      ⋮          ⋮          ⋱  ⋮
                      ∂y/∂x_1n  ∂y/∂x_2n  ⋯  ∂y/∂x_nn ]
```

将梯度、自变量、因变量写成行向量、列向量还是矩阵，完全取决于哪种形式更有利于你推导相关公式。如果 `xx` 写成矩阵形式且梯度写成矩阵形式，看起来会更一致。

### 示例 1

对于多元函数 `F(x, y, z) = x + 2y² + 3z³`，有：

`∇F(x, y, z) = (1, 4y, 9z²)`

在特定点 (2,3,4) 处的梯度为 `(1, 4 * 3, 9 * 4²) = (1, 12, 144)`。在此点附近，如果自变量有一个微小增量 `(Δx, Δy, Δz)`，则：

`F(2 + Δx, 3 + Δy, 4 + Δz) − F(2, 3, 4) ≃ 1 * Δx + 12 * Δy + 144 * Δz`

### 示例 2

假设 `y = w[1] * x[1] + w[2] * x[2] + ⋯ + w[n] * x[n] + b`，若 `y` 视为 `w = (w[1], w[2], …, w[n])` 的函数，则 `dy/dw = (x_1, x_2, ..., x_n)`；若 `y` 视为 `x = (x[1], x[2], …, x[n])` 的函数，则 `dy/dx = (w[1], w[2], …, w[n])`；若 `y` 视为 `b` 的函数，则 `dy/db = 1`。

如果 `ww` 写成列向量而 `xx` 写成行向量，则 `y = xxww`，若梯度写成行向量，则 `∂y/∂xx = ww^T`，`∂y/∂ww = xx`。

如果 `ww` 和 `xx` 都写成列向量形式，且梯度写成行向量形式，则 `y = ww^(T)xx = xx^(T)ww`，此时 `∂y/∂xx = ww^T`，`∂y/∂ww = xx^T`。

可以证明，导数的四则运算和链式法则对梯度也成立。设 f, g 为两个从 ℝ^(n) 到 ℝ 的实值函数，则：

#### 线性法则

`(αf + βg)'(x) = ∇(αf + βg)(x) = αf'(x) + βg'(x) = α∇f + β∇g(x)`

#### 乘积法则

`(fg)'(x) = ∇(fg)(x) = f'(x)g(x) + f(x)g'(x) = g(x)∇f(x) + f∇g(x)`

#### 链式法则

设 g 为从 ℝ^(n) 到 ℝ 的实值函数，f 为从 ℝ 到 ℝ 的实值函数，对某 `xx ∈ ℝ^(n)`，`g(xx)` 的值为 `z`，若 `xx` 为列向量且梯度为行向量形式，则有：

`(f ∘ g)'(xx) = ∇(f ∘ g)(xx) = f'(z)g'(xx) = f'(z)∇g(xx)`

若 `xx` 为行向量且梯度为列向量形式，则：

`(f ∘ g)'(xx) = ∇(f ∘ g)(xx) = g'(xx)f'(z) = ∇g(xx)f'(z)`

即两种不同形式的链式法则顺序恰好相反。

### 示例 3

若 `g((x_1, x_2)^T) = 3x_1 + 2x_2^3`，`f(z) = z²`，则 `(f ∘ g)((x_1, x_2)^T) = (3x_1 + 2x_2^3)^2`。所以：

`(f ∘ g)'(xx) = f'(z)∇g(x) = 2z * (3, 6x[2]²) = 2 * (3x[1] + 2x[2]³) * (3, 6x[2]²) = (18x[1] + 12x[2]³, 36x[1]x[2]² + 24x[2]⁵)`

若变量为行向量且梯度为列向量，`g(x[1], x[2]) = 3x[1] + 2x[2]³`，`f(z) = z²`，则 `(f ∘ g)(x[1], x[2]) = (3x[1] + 2x[2]³)²`。所以：

```
(f ∘ g)'(x x) = ∇g(x)f'(z) = [ 3
                                 6x_2^2 ] 2z = [ 3
                                                  6x_2^2 ] 2 * (3x_1 + 2x_2^3) = [ 18x_1 + 12x_2^3
                                                                                     36x_1x_2^2 + 24x_2^5 ]
```

### 示例 4

假设 `y`、`ŷ` 是 ℝ^(n) 中的两个向量，可以用它们欧氏距离的平方来定义这两个向量之间的误差（距离），例如用以下公式表示两个向量之间的误差 `E(y, ŷ)`：

```
E(y y, ŷ ŷ) = 1/2 ||y y - ŷ ŷ||_2^2 = 1/2((y_1 - ŷ_1)^2 + (y_2 - ŷ_2)^2 + ⋯ + (y_n - ŷ_n)^2)
```

`E(y y, ŷ ŷ)` 关于 `yy` 的梯度为 `(y y - ŷ ŷ)^T`。

### 1.3.7 向量值函数的导数与雅可比矩阵

如果有多个函数：

```
f_1: x → f_1(x)
f_2: x → f_2(x)
⋮
f_m: x → f_m(x)
```

它们可以写在一个列向量中：

```
f f(x) = [ f_1(x)
           f_2(x)
           ⋮
           f_m(x) ]
```

这些组合在一起的函数称为**向量值函数**。输入一个 `x`，每个函数产生一个函数值 `f[i](x)`，这些函数值构成上述右侧的向量。

例如，有 3 个函数：`f[1](x) = x²`，`f[2](x) = e^x`，`f[3](x) = ax`，它们构成一个向量值函数：

```
f f(x) = [ f_1(x)
           f_2(x)
           f_3(x) ] = [ x^2
                        e^x
                        ax ]
```

输入一个 `x` 值，如 3，产生 3 个值：`[ 9, e^3, 3a ]^T`

由 m 个一元函数组成的向量值函数是实数集 ℝ 到 ℝ^(m) 的映射（变换）`ff(x) : ℝ → ℝ^(m)`。如果在某点 `x`，每个函数 `f[i](x)` 关于 `x` 的导数存在，将这些导数汇集成一个向量，称为向量值函数关于自变量 `x` 的导数，可写作 `Dff(x)`：
