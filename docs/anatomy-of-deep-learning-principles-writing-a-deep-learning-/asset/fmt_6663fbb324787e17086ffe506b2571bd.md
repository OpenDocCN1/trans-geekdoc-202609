
#### 3. Gradient calculation formula in column vector form

If the samples, intermediate variables and their gradients are all in the form of column vectors, such as `x`, `a`^(\[1\]), `z`^(\[1\]), `b`^(\[1\]), `a`^(\[2\]), `z`^(\[2\]), `b`^(\[2\]) are all column vectors, and a row of `W`^(\[1\]), `W`^(\[2\]) corresponds to the ownership of a neuron value, namely:

`z`^(\[1\]) = `W`^(\[1\])`x` + `b`^(\[1\]) = `W`^(\[1\])`a`^(\[0\]) + `b`^(\[1\])  
`z`^(\[2\]) = `W`^(\[2\])`a`^(\[1\]) + `b`^(\[2\])

Then the corresponding formula can be deduced similarly:

**One-sample form:**

$$
\frac{\partial\mathcal{L}}{\partial W^{\lbrack 2\rbrack}} = \frac{\partial\mathcal{L}}{\partial z^{\lbrack 2\rbrack}}{z^{\lbrack 1\rbrack}}^{T} \quad\quad \frac{\partial\mathcal{L}}{\partial b^{\lbrack 2\rbrack}} = \frac{\partial\mathcal{L}}{\partial z^{\lbrack 2\rbrack}} \quad\quad \frac{\partial\mathcal{L}}{\partial a^{\lbrack 1\rbrack}} = {W^{\lbrack 2\rbrack}}^{T}\frac{\partial\mathcal{L}}{\partial z^{\lbrack 2\rbrack}}
$$

$$
\frac{\partial\mathcal{L}}{\partial z^{\lbrack 1\rbrack}} = \frac{\partial L}{\partial z^{\lbrack 1\rbrack}} \odot g^{\prime}(z^{\lbrack 1\rbrack}) \quad\quad \frac{\partial\mathcal{L}}{\partial W^{\lbrack 1\rbrack}} = \frac{\partial\mathcal{L}}{\partial z^{\lbrack 1\rbrack}}{z^{\lbrack 0\rbrack}}^{T} \quad\quad \frac{\partial\mathcal{L}}{\partial b^{\lbrack 1\rbrack}} = \frac{\partial\mathcal{L}}{\partial z^{\lbrack 1\rbrack}}
$$

**Multi-sample form:**

$$
\frac{\partial\mathcal{L}}{\partial W^{\lbrack 2\rbrack}} = \frac{\partial\mathcal{L}}{\partial Z^{\lbrack 2\rbrack}}{A^{\lbrack 1\rbrack}}^{T} \quad\quad \frac{\partial\mathcal{L}}{\partial b^{\lbrack 2\rbrack}} = np.sum(\frac{\partial\mathcal{L}}{\partial Z^{\lbrack 2\rbrack}}, axis = 1, keepdims = True) \quad\quad \frac{\partial\mathcal{L}}{\partial A^{\lbrack 1\rbrack}} = {W^{\lbrack 2\rbrack}}^{T}\frac{\partial\mathcal{L}}{\partial Z^{\lbrack 2\rbrack}}
$$

$$
\frac{\partial\mathcal{L}}{\partial Z^{\lbrack 1\rbrack}} = \frac{\partial L}{\partial A^{\lbrack 1\rbrack}} \odot g^{\prime}(Z^{\lbrack 1\rbrack}) \quad\quad \frac{\partial\mathcal{L}}{\partial W^{\lbrack 1\rbrack}} = \frac{\partial\mathcal{L}}{\partial Z^{\lbrack 1\rbrack}}{A^{\lbrack 0\rbrack}}^{T} \quad\quad \frac{\partial\mathcal{L}}{\partial b^{\lbrack 1\rbrack}} = np.sum(\frac{\partial\mathcal{L}}{\partial Z^{\lbrack 1\rbrack}}, axis = 1, keepdims = True)
$$

For a loss function that contains a regular term, the partial derivative of the regular term to each model parameter is also calculated when calculating the gradient. If the regular term is $\lambda \parallel W W^{2} \parallel = \lambda\sum\limits_{l}\sum\limits_{ij}{W W_{ij}^{\lbrack l\rbrack}}^{2}$, then the partial derivative of `W``W`[`i``j`]^(\[`l`\]) is 2`λ``W``W`[`i``j`]^(\[`l`\]), written in vector form is 2`λ``W``W`.

For the above 2-layer neural network, on the basis of forward calculation (that is, `A0` and `A1` in forward calculation are known), the following code gives the reverse derivation process (if the activation function of the first layer is Relu):


### 4.2.5 Python implementation of 2-layer neural network

A 2-layer neural network includes an input layer, a hidden layer, and an output layer. The `TwoLayerNN` class below represents such a 2-layer neural network model.

```python
from util import *

def dRelu(x):
    return 1 * (x > 0)

def max_abs(s):
    max_value = 0
    for x in s:
        max_value_ = np.max(np.abs(x))
        if max_value_ > max_value:
            max_value = max_value_
    return max_value

class TwoLayerNN:
    def __init__(self, input_units, hidden_units, output_units):
        # initialize parameters randomly
        n = input_units
        h = hidden_units
        K = output_units
      
        self.W1 = 0.01 * np.random.randn(n, h)
        self.b1 = np.zeros((1, h))
        self.W2 = 0.01 * np.random.randn(h, K)
        self.b2 = np.zeros((1, K))        
        
    def train(self, X, y, reg=0, iterations=10000, learning_rate=1e-0, epsilon=1e-8):
        m = X.shape[0]
        W1 = self.W1
        b1 = self.b1
        W2 = self.W2
        b2 = self.b2        
        
        for i in range(iterations):
            # forward evaluate class scores, [N x K]
            Z1 = np.dot(X, W1) + b1
            A1 = np.maximum(0, Z1)  # ReLU activation
            Z2 = np.dot(A1, W2) + b2
            
            data_loss = softmax_cross_entropy(Z2, y)
            reg_loss = reg * np.sum(W1 * W1) + reg * np.sum(W2 * W2)
            loss = data_loss + reg_loss
            
            if i % 1000 == 0:
                print("iteration %d: loss %f" % (i, loss))
    
            # backward 
            dZ2 = cross_entropy_grad(Z2, y)
            dW2 = np.dot(A1.T, dZ2) + 2 * reg * W2
            db2 = np.sum(dZ2, axis=0, keepdims=True)
            dA1 = np.dot(dZ2, W2.T)
            
            dA1[A1 <= 0] = 0
            dZ1 = dA1
            # dZ1 = dA1 * dReLU(A1)   
            # dZ1 = np.multiply(dA1, dRelu(A1))           
            dW1 = np.dot(X.T, dZ1) + 2 * reg * W1
            db1 = np.sum(dZ1, axis=0, keepdims=True)      
            
            if max_abs([dW2, db2, dW1, db1]) < epsilon:
                print("gradient is small enough at iter : ", i)
                break
          
            # perform a parameter update
            W1 += -learning_rate * dW1
            b1 += -learning_rate * db1
            W2 += -learning_rate * dW2
            b2 += -learning_rate * db2
            
        return W1, b1, W2, b2  
    
    def predict(self, X):
        Z1 = np.dot(X, W1) + b1
        A1 = np.maximum(0, Z1)  # ReLU activation
        Z2 = np.dot(A1, W2) + b2
        return Z2
```
