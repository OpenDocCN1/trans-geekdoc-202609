

## 8.4 生成对抗网络

**生成对抗网络**（Generative Adversarial Net，**GAN**）是 Ian Goodfellow 于 2014 年提出的一种生成模型，包含两个称为**判别器**和**生成器**的神经网络函数。判别器用于识别数据是真实数据还是伪造数据，生成器用于生成伪造数据。利用极大极小对抗博弈的方法，判别器和生成器通过持续对抗的过程提升各自的性能，就像博弈双方的相互对抗过程，一方总希望获得最大得分，而另一方总希望将对手的得分最小化。GAN 是深度学习兴起以来最令人兴奋、最具创造性的技术。深度学习三巨头之一、图灵奖得主 Yann LeCun 对 GAN 给予了高度评价：

> “生成对抗网络是过去十年机器学习领域最有趣的想法。”
> "Generative Adversarial Networks are the most interesting idea in machine learning of the past decade"

### 8.4.1 GAN 的原理

“生成对抗网络”字面上包含了 GAN 的三个方面：“生成”意味着它用于生成（制造）数据。例如，输入一个由一个或多个实数组成的向量，GAN 可以生成一张图像，如动漫头像、人脸图像或风景图像。它也可以生成一段乐谱、一段语音或一段文本。“对抗”意味着它通过对抗的方式提升生成数据的能力。对抗是一种熟悉的通过学习提升某种能力的手段。例如，运动员可以通过比赛或训练中的相互对抗不断提升能力。对抗通常是一个迭代过程。通过与对手反复对抗，我们不断改进和调整自己，希望最终战胜对手。“网络”指 GAN 的生成器函数用于生成数据，判别器函数用于识别数据的真伪，两者都使用神经网络函数。

GAN 的工作原理类似于造假过程：造假者希望制造（生成）赝品（钞票、书画、古董），而作为对手的鉴定者试图鉴别赝品的真伪（如银行职员或验钞机识别假钞、文物专家鉴别文物真伪）。造假者制造的赝品容易被鉴定者识破。随着造假者技术的不断提高，制造的赝品越来越难以识别。双方持续对抗。最终，当造假者制造的赝品无法被鉴定者识别时，双方的对抗达到平衡，造假者制造的赝品可以欺骗鉴定者。

造假者与鉴定者之间的这一对抗过程被称为“**极大极小博弈**”。鉴定者希望最大化辨别真伪的能力，而造假者希望最小化鉴定者辨别真伪的能力。当博弈达到均衡状态时，称为“**纳什均衡**”。

#### 1. 判别器与生成器

GAN 通过真实数据训练生成模型。GAN 包含 2 个函数（或神经网络）：

*   一个**生成器**函数（网络），从随机噪声（称为潜在变量）输入生成（制造）合成数据。
*   一个**判别器**函数（网络），它是一个二分类函数，用于识别数据是否为真实数据。

如图 8-22 所示，这是一个生成人脸图像的 GAN，其中生成器（`Generator`）和判别器（`Discriminator`）是由深度神经网络表示的两个函数。`Generator` 可以从带有噪声的随机向量生成一张人脸图像，`Discriminator` 是一个简单的二分类神经网络，输入一张人脸图像，输出该图像为真实人脸的概率。判别器同时接收真实人脸图像和生成器生成的假人脸图像，以训练其判别能力。

**图 8-22** 生成人脸的 GAN 模型，其中由神经网络表示的生成器从带有噪声的随机向量生成人脸图像，判别器 `Discriminator` 是一个简单的二分类神经网络，输入人脸图像，输出该图像为真实人脸的概率。

在 GAN 中，判别器和生成器都是由神经网络表示的函数，分别可用符号 `D(x|θ[D])` 和 `G(z|θ[G])` 表示，其中 `θ[D]`、`θ[G]` 分别是两个神经网络的模型参数。生成器 `G(z|θ[G])` 函数将噪声潜在变量 `z` 映射为数据 `G(z|θ[G])`，“判别器” `D(x|θ[D])` 用于判断 `x` 为真实数据的概率。

GAN 需要训练判别器和生成器两个神经网络函数，使判别器 `D` 尽可能正确识别真假数据，即真实数据的概率 `D(x)` 尽可能大，使生成数据被判断为真实数据的概率 `D(G(z))` 尽可能小。另一方面，也需要训练生成器 `G`，使生成器生成的数据尽可能欺骗判别器，甚至使判别器 `D` 以尽可能大的概率 `D(G(z))` 判断生成器生成的数据为真实。在 GAN 训练过程中，生成器和判别器通过这种相互对抗提升各自的功能，使最终判别器无法区分真实数据和生成器生成的假数据。

最初，生成器 `G` 生成的数据 `G(z|θ[G])` 的分布将与真实数据的潜在分布不一致，判别器 `D(x|θ[D])` 也未学到足够的识别真假数据的能力。GAN 使用对抗过程训练它们，交替训练判别器和生成器，即反复执行以下对抗训练：

*   **判别器训练**：判别器 `D` 接收一组真实数据 `x_real` 和来自生成器的假数据 `x_fake = G(z)` 作为样本。判别器函数应使真实数据的输出值 `D(x_real|θ[D])` 尽可能大（概率尽可能接近 1），使假数据的输出值 `D(x_fake|θ[D]) = D(G(z)|θ[D])` 尽可能小（概率接近 0）。因此，真实数据和假数据的样本标签分别为 1 和 0。训练过程与普通神经网络训练过程完全相同。
*   **生成器训练**：生成器 `G` 接收一组随机噪声 `z`，将其生成的数据即输出值 `G(z)` 输入判别器 `D`，希望尽可能欺骗判别器。即判别器的输出值 `D(G(z))` 尽可能大（概率接近 1）。

上述过程重复进行，直到判别器无法区分真实数据和假数据。用数学术语表述，即生成器生成的数据分布非常接近真实数据的分布。

如果真实数据是一些实数，这些实数服从某种分布，如正态分布。如图 8-23 所示，黑点代表这些实数对应的概率密度（分布）。假设只知道这些实数，而不知道其他真实分布，生成器可以通过将噪声潜在变量 `z` 映射到实数空间中的实数来生成一些实数 `x`。绿色实线表示这些生成实数的分布。生成实数的分布最初与真实实数的分布不一致。随着训练过程的不断迭代，生成数据 `G(z)` 的分布逐渐接近真实数据 `x` 的分布，判别器识别生成数据为真实数据的概率不断增加。最终，生成数据的分布与真实数据的分布几乎相同。此时，判别器无法再区分真实数据和生成数据，即无论真实还是生成数据，被判断为真实数据的概率都接近 0.5。

#### 2. 损失函数

判别器和生成器的目标不同。对于判别器，希望 `D(x)` 尽可能大，`D(G(z))` 尽可能小。对于生成器，希望 `D(G(z))` 尽可能大。类似于逻辑回归和多分类问题，为了提高计算的稳定性，通常用 `log(D(z))` 和 `log(D(G(z)))` 代替 `D(z)` 和 `D(G(z))`，并使用一批（多个）样本的平均损失（期望损失）来计算损失函数值。

若用 `p_z`、`p_r` 和 `p_g` 分别表示隐变量 `z`、真实数据 `x` 和生成数据 `G(z)` 的分布，判别器 `D` 期望真实数据 `x` 的 `log D(x)` 的期望（平均值）`𝔼[x∼p_r(x)][log D(x)]` 尽可能大，而从随机噪声变量 `z` 生成数据 `G(z)` 的 `log D(G(z))` 的期望（平均值）`𝔼[z∼p_z(z)][log D(G(z))]` 尽可能小，或 `𝔼[z∼p_z(z)][log(1 − D(G(z)))]` 尽可能大。因此，判别器期望 `𝔼[x∼p_r(x)][log D(x)] + 𝔼[z∼p_z(z)][log(1 − D(G(z)))]` 尽可能大：

```
max_D L_D(D,G) = 𝔼[x∼p_r(x)][log D(x)] + 𝔼[z∼p_z(z)][log(1 - D(G(z)))]
               = 𝔼[x∼p_r(x)][log D(x)] + 𝔼[x∼p_g(x)][log(1 - D(x))]
```

生成器 `G` 希望欺骗判别器 `D`，即希望 `𝔼[z∼p_z(z)][log(D(G(z)))]` 尽可能大，或 `𝔼[z∼p_z(z)][log(1 − D(G(z)))]` 尽可能小：

```
min_G L_G(D,G) = 𝔼[z∼p_z(z)][log(1 - D(G(z)))]
               = 𝔼[x∼p_g(x)][log(1 - D(x))]
```

生成器的最小化与真实数据的 `𝔼[x∼p_r(x)][log D(x)]` 无关，因此即使加上这一项也不影响该最小化：

```
min_G L_G(D,G) = 𝔼[x∼p_r(x)][log D(x)] + 𝔼[x∼p_g(x)][log(1 - D(x))]
```

因此，这两个损失函数可表示为统一的损失函数：

```
min_G max_D L(D,G) = 𝔼[x∼p_r(x)][log D(x)] + 𝔼[z∼p_z(z)][log(1 - D(G(z)))]
                   = 𝔼[x∼p_r(x)][log D(x)] + 𝔼[x∼p_g(x)][log(1 - D(x))]
```

即判别器 `D` 想要最大化该损失，而生成器 `G` 想要最小化该损失（对 `G` 而言，该损失函数的第一项与 `G` 无关）。即生成器和判别器都在玩一个“极大极小”对抗博弈。虽然写出了这个统一公式，但实际编程仍是优化 `max_D 𝔼[x∼p_r(x)][log D(x)] + 𝔼[z∼p_z(z)][log(1 - D(G(z)))]` 和 `min_G 𝔼[z∼p_z(z)][log(1 - D(G(z)))]`。根据实践经验，通常将 `min log(1 − D(G(z)))` 转换为 `max log(D(G(z)))`，或将 `max log(1 − D(G(z)))` 转换为 `min log(D(G(z)))`，更有利于训练的稳定性。

#### 3. 训练过程

GAN 的训练无非是 2 个普通神经网络的训练。GAN 交替训练判别器和生成器，即先训练判别器，再训练生成器，再训练判别器，再训练生成器，…… 其训练过程可用以下伪代码描述：

```
for Each iteration:
    Perform k iterative updates of the discriminator:
        Sample m real data samples x^(i) and generated data G(z^(i)) corresponding to m random noise z^(i), and mark their labels as 1 and 0 respectively
        Compute the gradient of the following loss function with respect to the model parameters;
        Update the model parameters of the discriminator using the gradient ascent method;

    Perform l iterative updates of the generator:
        Sample generated data G(z^(i)) corresponding to m random noise z^(i), and mark their labels as 1;
        Compute the gradient of the following loss function with respect to the model parameters;
        Update the model parameters of the generator using the gradient descent method;
```

在作者的原始论文中，每次对抗迭代中生成器的梯度更新次数仅执行一次，即 `l = 1`，判别器的迭代更新次数 `k` 作为可调超参数。通过调整 `k` 或 `l`，可以平衡判别器和生成器的训练程度，防止一方过度训练导致另一方变弱。像学习率、网络结构及其参数一样，它们是一些需要根据经验调整的超参数。这些参数的调整直接影响算法性能，而对抗性的 GAN 训练更加困难。

判别器和生成器需要对抗，但如果一方过强，另一方就会变弱。如何平衡两者的训练（即调整这些超参数）是 GAN 训练的难点。

### 8.4.2 GAN 训练过程的代码实现

GAN 的生成器和判别器是两个普通的神经网络函数。但其训练过程是一个对抗过程。在代码实现中，为了增加代码的可读性，上一节的 GAN 训练过程可以分解为 3 个独立的函数：

*   `D_train()` 函数负责判别器训练的每一次梯度更新。
*   `G_train()` 函数负责生成器训练的每一次梯度更新。
*   `GAN_train()` 函数代表整个 GAN 训练过程。

判别器是一个二分类神经网络函数，由真实数据和生成器生成的假数据进行训练。在判别器的训练中，真实数据的标签值为 1，假数据的标签值为 0。`D_train()` 函数基于这些真实数据和假数据样本计算二元交叉熵损失，并通过反向推导计算梯度，然后更新模型参数：

```
```
