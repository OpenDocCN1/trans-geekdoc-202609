

## 6.5 典型卷积神经网络结构

1989年，卷积神经网络结构（CNN）的发明者Yann LeCun利用反向传播（BP）算法训练多层神经网络以识别手写邮政编码。所用的神经网络于1994年被称为LeNet。虽然该论文并未提及卷积或卷积神经网络，仅指出使用5×5的相邻区域作为感受野。1998年，LeCun提出了著名的LeNet-5神经网络，标志着卷积神经网络的真正诞生。由于当时硬件条件的限制，卷积神经网络的训练极其消耗机器资源和时间。因此，CNN网络模型并未普及。

直到2012年，Alex Krizhevsky利用GPU实现了一个名为AlexNet的深度卷积神经网络，并赢得了ImageNet图像识别竞赛的冠军，以深度卷积神经网络为代表的深度学习才开始迅速发展。随后，提出了各种神经网络结构，如VGG、GoogLeNet、ResNet、Inception等。

### 6.5.1 LeNet-5

图6-55展示了LeNet-5的网络结构。一张32×32×1的图像经过六个步长为1、填充为0的5×5卷积核，生成6个尺寸为28×28的输出特征图；随后通过跨度为2、大小为2的平均池化操作，生成六个14×14的特征图，即图像的长宽减半。接着通过16个步长为1、填充为0的5×5卷积核，生成16个尺寸为10×10的输出特征图。再通过跨度为2、大小为2的平均池化操作，生成16个5×5的特征图。

![](EPUB/media/file138.png "fig:")  
图 6-55 LeNet网络结构

随后是全连接层，拥有120个神经元，每个神经元接收来自上一层16个5×5特征图（图像）共400个特征值，每个神经元产生一个输出值，120个神经元生成一个由120个输出组成的一维向量，输出给下一个拥有84个神经元的全连接层。拥有84个神经元的全连接层将其84个输出送入最终的输出层，若进行10分类，输出层将包含10个神经元，每个神经元输出样本属于对应类别的得分。这10个分类可通过softmax函数计算多类交叉熵损失并结合真实目标值来训练神经网络模型。

LeNet-5是卷积神经网络的经典结构。它采用“先卷积后池化”的模式，从多通道输入生成多通道输出并减小图像尺寸。如上例所示，单通道32×32×1经过一系列“卷积-池化”变换，最终生成16个5×5的特征图，最后再经过若干全连接层产生最终输出。

### 6.5.2 AlexNet

AlexNet是Alex Krizhevsky等人提出的一种CNN网络结构。它在2012年ImageNet图像分类竞赛中获得第一名，瞬间将top-5错误率降低了10个百分点以上。作者利用CUDA GPU实现了并行神经网络训练算法，使得在合理时间内训练深度神经网络成为可能。其网络结构如图6-56所示。

![](EPUB/media/file139.png "fig:")  
图 6-56 AlexNet网络结构

若输入为3通道彩色图像227×227×3，经过步长为4的96个11×11卷积核，生成96个55×55的特征图（55×55×96），因步长为4，图像缩小了4倍。随后经过跨度为2的3×3最大池化层，输出96个27×27的特征图（27×27×96），再执行步长为1、填充为2的256个5×5卷积核进行“同卷积”，生成256个27×27的特征图（27×27×256），再经过跨度为2的3×3最大池化层，输出256个13×13的特征图（13×13×256），接着用步长为1、填充为1的384个3×3卷积核执行“同卷积”，生成384个13×13的特征图（13×13×384），再进行一次相同的卷积操作。然后，用步长为1、填充为1的256个3×3卷积核执行“同卷积”，生成256个13×13的特征图（13×13×256）。再进行一次跨度为2的3×3最大池化，得到256个6×6的特征图（6×6×256）。将6×6×256展平为9216维向量，然后输出给4096个神经元的全连接层，随后是另一个4096个神经元的全连接层，最后是1000个神经元的全连接层，并经softmax函数输出样本属于1000个不同类别的概率。

AlexNet与LeNet非常相似，但其深度和规模远大于LeNet。LeNet约有60,000个参数，而AlexNet约有6000万个参数。AlexNet相较于LeNet网络最重要的改进是使用了Relu激活函数，避免了深度神经网络的“梯度消失”问题。另一个提升性能的改进是Dropout技术，即在某一隐藏层以一定概率让部分神经元的输出为0，不参与网络传播。每次迭代相当于定义一个不同的函数。这种正则化技术实际上利用更简单的网络函数组合来表示训练好的模型函数。此外，还提出了“局部响应归一化”，即对某一层特征图中某一位置所有通道的值进行归一化。但后来发现LRN作用不大。

AlexNet网络的成功使计算机视觉和人工智能界重新关注沉寂多年的神经网络，尤其是CNN深度卷积网络。深度可以变得更深，原理简单的深度神经网络能超越数学上复杂的人工智能技术。深度学习开始成为机器学习最重要的分支。现代人工智能主要指深度学习。

### 6.5.3 VGG

VGG-16网络是牛津大学视觉几何组（简称VGG）提出的一种简化卷积网络结构。其主要贡献在于证明了增加网络深度能在一定程度上提升网络的最终性能。一般卷积网络不同卷积层的卷积核大小不一，而VGG网络中所有卷积核大小相同，例如使用步长为1的3×3卷积核，池化层同理，使用步长为2的2×2最大池化核。因此，它简化了卷积神经网络的结构。只要VGG-16网络深度足够深，就能达到与复杂神经网络结构相当甚至更好的性能。VGG-16中的16表示神经网络中卷积层和全连接层共有16层。图6-57展示了VGG-16的卷积网络结构。

![](EPUB/media/file140.png "fig:")  
图 6-57 VGG网络结构

卷积核均为步长1的3×3，池化核均为步长2的2×2。但初始卷积层的输出通道数为64，后续卷积层的输出通道数按128、256、512的顺序翻倍。达到512后，后续卷积层的输出通道数不再增加，因为512个通道被认为已足够大。VGG网络结构非常规则，但所需数据量较大。后来提出了VGG-19，但VGG-19与VGG-16在性能上无差异。

### 6.5.4 深度神经网络的梯度爆炸与消失问题

极深的神经网络因梯度爆炸与消失问题而难以训练，因为梯度只能从后向前逐层传递，若一个数持续乘以绝对值小于1的数，该数将越来越接近0。设一数为`y`，连续乘以`c[i]`，最终变为`c[i] * ... * c[L] * y`，该值将趋近于0。同理，当一个数持续乘以绝对值大于1的数时，该数将越来越接近无穷大∞。

考虑一个简化的神经网络，其中神经元为`z = x * w`，若有L层，前向计算为：

```
x → z[1] = x * w[1] → z[2] = z[1] * w[2] = x * w[1] * w[2] → ⋯ → z[L] = z[L−1] * w[L] = x * w[1] * w[2] ⋯ * w[L]
```

若已知损失函数关于最后一层`z[L]`的梯度为`dz[L]`，则损失函数关于`z[L−1]`的梯度`dz[L−1] = w[L] * dz[L]`，关于`z[i]`的梯度`dz[i] = w[i+1] ⋯ w[L] * dz[L]`，损失函数关于`w[i]`的梯度`dw[i] = dz[i] * z[i−1] = w[i+1] ⋯ w[L] * dz[L] * z[i−1]`。

若`‖w[i]‖ < ρ < 1`，则随着`L−i`增大，`dz[i]`呈指数级衰减，`L−i`越大衰减越快，导致`dw[i]`的值可能变得极小，梯度过小使参数`w[i]`的更新近乎停滞，收敛变得极慢。同理，若`‖w[i]‖ > ρ > 1`，则随着`L−i`增大，`dz[i]`呈指数级增长，从而变得极大，导致参数更新剧烈震荡，无法收敛。

随着神经网络深度加深，梯度爆炸与衰减不可避免，使得深度神经网络训练极其困难。为防止梯度爆炸，可使用梯度裁剪技术L，即将梯度的绝对值限制在预定范围内。设`g`为梯度，`θ`为裁剪阈值，按以下公式裁剪梯度：

`min(θ / ‖g‖, 1) * g`

即将梯度值限制在`[-θ, θ]`范围内。
