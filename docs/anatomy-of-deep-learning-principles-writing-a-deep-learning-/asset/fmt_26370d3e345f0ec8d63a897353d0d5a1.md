
### 3.6.5 Calculate cross entropy loss by weighted sum

The weighted sum of a sample and the softmax function output of `z` is the probability `f`. Knowing the weighted sum `z` can calculate `f`, thus calculating the cross-entropy loss. The code below computes the cross-entropy loss over the weighted sum `Z` of multiple samples and their target class labels `y`:

```python
#https://deepnotes.io/softmax-crossentropy
def softmax(Z):
    A = np.exp(Z-np.max(Z,axis=1,keepdims=True))
    return A/np.sum(A,axis=1,keepdims=True)

def softmax_cross_entropy(Z,y):
    m = len(Z)
    F = softmax(Z)
    log_Fy = -np.log(F[range(m),y])
    return  np.sum(log_Fy) / m
```

Test the function with a set of `Z`:

```python
Z = np.array([[2,25,13],[54,3,11]])  #Each line corresponds to a sample
y = np.array([2,1])
softmax_cross_entropy(Z,y)
```

output:

```
31.500003072148047
```

If the target labels are in one-hot vector form, the following code computes the cross-entropy loss from the weighted sum:

```python
def softmax_cross_entropy_one_hot(Z, y):    
    F = softmax(Z)
    loss =  -np.sum(y*np.log(F),axis=1)
    return np.mean(loss)  
```

### 3.6.6 Gradient calculation of softmax regression

The goal of softmax regression is to find the `W` that minimizes the cross-entropy loss ℒ(`W`), and the solution algorithm is still the gradient descent method. For this, it is necessary to calculate the gradient of ℒ(`W`) with respect to `W`, that is, the partial derivative with respect to each `W[jk]`.

#### 1. The gradient of the cross-entropy loss on the weighted sum

Let a sample be (`x`, `y`), `f`(`x`) = `softmax`(`x``W`) can be regarded as `z` = (`z`[1], `z`[2], `z`[3]) = (`x``W`[, 1], `x``W`[, 2], `x``W`[, 3]) and `f`(`z`) = `softmax`(`z`) = `softmax`(`z`[1], `z`[2], `z`[3]) composite function.

Introduce auxiliary intermediate variable `a` = (`a`[1], `a`[2], `a`[3]) = (`e`^(`z`[1]), `e`^(`z`[2]), `e`^(`z`[3])). but

$f(z) = f(a) = \begin{pmatrix} f_{1}, & f_{2}, & f_{3} \end{pmatrix} = \begin{pmatrix} \frac{a_{1}}{a_{1} + a_{2} + a_{3}}, & \frac{a_{2}}{a_{1} + a_{2} + a_{3}}, & \frac{a_{3}}{a_{1} + a_{2} + a_{3}} \end{pmatrix}$

Let ℒ = −`log`(`f`[`y`]) = −(`log`(`a`[`y`]) − `log`(`a`[1] + `a`[2] + `a`[3]))

$$
\begin{matrix}
\frac{\partial\mathcal{L}}{\partial z_{i}} = - \frac{1}{a_{y}}\frac{\partial a_{y}}{\partial z_{i}} - \frac{1}{a_{1} + a_{2} + a_{3}}(\frac{\partial a_{1}}{\partial z_{i}} + \frac{\partial a_{2}}{\partial z_{i}} + \frac{\partial a_{3}}{\partial z_{i}}) \\
= - \frac{1}{a_{y}}\frac{\partial a_{y}}{\partial z_{i}} - \frac{1}{a_{1} + a_{2} + a_{3}}e^{z_{i}} \\
= - \frac{1}{a_{y}}1{(y==i)}e^{z_{y}} - \frac{1}{a_{1} + a_{2} + a_{3}}e^{z_{i}} \\
= - 1{(y==i)} + \frac{e^{z_{i}}}{\sum\limits_{1}^{3}e^{z_{i}}} = f_{i} - 1{(y==i)}
\end{matrix}
$$

Among them, the symbol `1`(`y` == `i`) indicates that the value is 1 when (`y` == `i`) is established, otherwise, the value is 0.

Therefore, the gradient of ℒ on `z` = (`z`[1], `z`[2], `z`[3]) is:

$\nabla_{z}\mathcal{L} = (\frac{\partial\mathcal{L}}{\partial z_{1}},\frac{\partial\mathcal{L}}{\partial z_{2}},\frac{\partial\mathcal{L}}{\partial z_{3}}) = (f_{1} - 1{(y==1)},f_{2} - 1{(y==2)},f_{3} - 1{(y==3)})$

If `y`=1, then:

∇[`z`]ℒ = (`f`[1] − 1, `f`[2], `f`[3])

That is to say, for any C classification problem, if the classification of a certain `y` is i, then:

∇[`z`]ℒ = (`f`[1], `f`[2], ⋯, `f`[`i`] − 1, ⋯, `f`[`C`]) = `f` − `I`[`i`]

The notation `I`[`i`] represents a one-hot vector whose i-th component is 1 and the other components are 0. If the target value of the sample `y` is represented by this one-hot vector, that is, `y` = `I`[`i`], then:

∇[`z`]ℒ = `f` − `y`

This and the linear regression loss $\frac{1}{2} \parallel f - y \parallel^{2}$ on the gradient of `f`, the logistic regression cross-entropy loss −(`y``log`(`f`) + (1 − `y`)`log`(1 − `f`)) on weighting and `z` are surprisingly consistent. But there is still a difference. Linear regression is the gradient of the loss function value about `f`, while logistic regression and softmax regression are about the weighted sum of `z` instead of `f`. The gradient is `f` − `y`, but the probability of logistic regression is calculated by `f` = `σ`(`z`), and the probability of softmax regression is calculated by `f` = `softmax`(`z`).

Therefore, for the vector `Z` constructed by multiple sample features, use ℒ to represent the total loss of all samples, then the gradient of ℒ on the weighted sum `Z` is:

∇[`Z`]ℒ = `F` − `I`[`i`]

or

∇[`Z`]ℒ = `F` − `Y`

This form is the same as the gradient of the weighted sum of the logistic regression loss function, and also the loss function $\frac{1}{2} \parallel F - Y \parallel^{2}$ of the linear regression about the output `F` is consistent.

According to formula (12), the code for calculating the gradient of cross entropy with respect to `Z` is as follows:

```python
def grad_softmax_crossentropy(Z,y):
    F = softmax(Z)
    I_i = np.zeros_like(Z)
    I_i[np.arange(len(Z)),y] = 1   
    return (F - I_i) / Z.shape[0]
```

```python
def grad_softmax_cross_entropy(Z,y):
    m = len(Z)
    F = softmax(Z) 
    F[range(m),y] -= 1
    return F/m  
```
