
### 6.3.3 Matrix multiplication for reverse derivation of 1D convolution

Let `x` = (`x`[0], `x`[1], `x`[2], `x`[3], `x`[4]), `K` = (`w`[0], `w`[1], `w`[2]), `x`[`row`], `K`[`col`] are `x` and `K` respectively. To flatten the matrix, the convolution can be marked as their product. Let the convolution result matrix be `z`[`row`], that is:

$$
\begin{matrix} 
{z\_{row} = \begin{bmatrix} z\_{0} \\ z\_{1} \\ z\_{2} \\ \end{bmatrix} = x\_{row}K\_{col} = \begin{bmatrix} x\_{0} & x\_{1} & x\_{2} \\ x\_{1} & x\_{2} & x\_{3} \\ x\_{2} & x\_{3} & x\_{4} \\ \end{bmatrix}\begin{bmatrix} w\_{0} \\ w\_{1} \\ w\_{2} \\ \end{bmatrix}} 
\end{matrix}
$$

The process of generating `z` from `x` is shown in Figure 6-43:

**Figure 6-43** A one-dimensional vector of length 5 and a convolution kernel of length 3 perform valid convolution to produce a convolution vector of length 3

If you know that the gradient of the loss function about `z` is `dz`, the corresponding matrix form is `dz`[`row`]. Then the gradient of `x`[`row`] and `K`[`col`] can be obtained from `dz` as:

`dx`[`row`] = `dz`[`row`] `K`[`col`]^(`T`)

`dK`[`col`] = `x`[`row`]^(`T`) `dz`[`row`]

For example, for `dx`[`row`]:

$$
\begin{matrix} 
{dx\_{row} = dz\_{row}K\_{col}^{T} = \begin{bmatrix} {dz\_{0}} \\ {dz\_{1}} \\ {dz\_{2}} \\ \end{bmatrix}\begin{bmatrix} w\_{0} & w\_{1} & w\_{2} \\ \end{bmatrix} = \begin{bmatrix} {dz\_{0}w\_{0}} & {dz\_{0}w\_{1}} & {dz\_{0}w\_{2}} \\ {dz\_{1}w\_{0}} & {dz\_{1}w\_{1}} & {dz\_{1}w\_{2}} \\ {dz\_{2}w\_{0}} & {dz\_{2}w\_{1}} & {dz\_{2}w\_{2}} \\ \end{bmatrix}} 
\end{matrix}
$$

This `dx`[`row`] is a flattened form of `dx`, each row of which is a gradient of an element `z`[`i`] of an output `ZZ` about its dependent data block. This data block and the convolution kernels have the same shape and size. As shown in Figure 6-44, the first row of `dx`[`row`] is the gradient of the output component `z`[0] with respect to the data block (`x`[0], `x`[1], `x`[2]) of `xx` on which it depends. That is, `dz`[0] contributes to `dx`[0], `dx`[1], and `dx`[2]: `dx`[0] = `dz`[0]`w`[0], `dx`[1] = `dz`[0]`w`[1], `dx`[2] = `dz`[0]`w`[2]

**Figure 6-44** `z`[0] depends on `x`[0], `x`[1], `x`[2], so `dz`[0] contributes to `dx`[0], `dx`[1], `dx`[2] or `dx`[0], `dx`[1], `dx`[2] all depend on `dz`[0]: `dx`[0] = `dz`[0]`w`[0], `dx`[1] = `dz`[0]`w`[1], `dx`[2] = `dz`[0]`w`[2]

In this example, an output component `z`[0] will contribute gradients to the gradients of the 3 input components that depend on the data block. Similarly, each of the other lines will also contribute to the gradient of the different input data blocks, as shown in Figure 6-45:

**Figure 6-45** Each `dz`[`i`] contributes to the gradient of the element `x`[`j`] of the data block on which `z`[`i`] depends

It can be seen that the forward calculation process of convolution is to calculate the weighted sum of the data blocks to obtain an output value `z`[`i`], while the reverse derivation is to assign the gradient of each `z`[`i`] to each element of its dependent data block on the gradient. The distribution process of reverse derivation is exactly the reverse process of the accumulation process of forward calculation.

Therefore, in order to get the gradient `dxx` of the loss function with respect to the input `xx`, `dx`[`row`] needs to be flattened into `xx`[`row`] according to the inverse process of `xx`. That is, each row is converted into a gradient of a data block. Because different data blocks are overlapping, these gradients are also overlapping. During the reverse flattening process, these overlapping gradients should be accumulated. As shown in Figure 6-45:

**Figure 6-46** The contribution of each `dz`[`i`] to the gradient of `z`[`i`] dependent data is added to the gradient of this data

According to the inverse process of the flattening process, the gradient of each line is accumulated to the position of its corresponding original data block, and the final `dxx` is obtained as:

`dx` = (`dz`[0]`w`[0], `dz`[0]`w`[1] + `dz`[1]`w`[0], `dz`[0]`w`[2] + `dz`[1]`w`[1] + `dz`[2]`w`[0], `dz`[1]`w`[2] + `dz`[2]`w`[1], `dz`[2]`w`[2])

Right now:

`dx`[`i` : `i` + `K`] += `dx`[`row`][`i`]

or:

`dx`[`i` : `i` + `K`] += `dz`[`i`] * `ww`

### 6.3.4 Matrix multiplication for reverse derivation of 2D convolution

Like the matrix multiplication of 1D convolution reverse derivation, the matrix multiplication of 2D convolution reverse derivation can be obtained, and the final input and convolution layer weight parameters of the convolution layer can be obtained from the gradient of the loss function with respect to the output of the convolution layer gradient.

Let `XX` be the input, `KK`, `bb` be the weight and bias of a convolutional layer, and the output tensor `ZZ` can be expressed as:

`Z` = `conv`(`XX`, `KK`) + `b`

Where `conv`(`XX`, `KK`) represents the convolution operation of the input `XX` with the weight of the convolution kernel `KK`. The convolution operation `conv`(`XX`, `KK`) can be expressed as a matrix product, namely:

`ZZ`[`row`] = `XX`[`row`] `KK`[`col`]

Where `XX`[`row`], `KK`[`col`], `ZZ`[`row`] are the inputs, weights and outputs flattened into matrix form.

If the gradient `dZ` of the loss function with respect to the output vector `Z` is known, according to formula (6-33), the gradient `db` of the loss function with respect to `b` is the same as the derivation of the previous fully connected layer, namely `db` = `np.sum`(`dZ`, `axis`=(0, 2, 3)). That is, the gradient of the offset `b`[`k`] corresponding to each channel is the accumulation of the gradient `dz`[`i`, `k`, `h`, `w`] of all pixel values of all samples.

According to formula (6-34), the same as the reverse derivation of the fully connected layer, the loss function can be obtained from the gradient `dZZ`[`row`] about the flattened `XX`[`row`], `KK`[`Gradientofcol`]:

`dXX`[`row`] = `dZZ`[`row`] `K`[`col`]^(`T`)

`dK`[`col`] = `X`[`row`]^(`T`) `dZZ`[`row`]

The calculation can be expressed as the following Python code:

```python
dK_col = np.dot(X_row.T, dZ_row) # X_row.T @ dZ_row
dX_row = np.dot(dZ_row, K_col.T)
```

Because `KK`[`col`] flattens `KK` into each column vector according to each channel, so as long as each column of `dK`[`col`] is reshaped into the same shape as `KK`, that is:

```python
dK_col = dK_col.transpose(1, 0)  # Transpose the channel axis F to the first axis
dK = dK_col.reshape(K.shape)     # Converted to the shape of K: (F, C, kH, kW)
```

That is, it is easy to reshape to the same shape as `KK` according to the flattening method of `KK`.

`dXX`[`row`] is a matrix of the same shape as the flattened matrix `XX`[`row`] of `XX`, each row of which represents a data block with the same shape as the convolution kernel (`C`, `oH`, `kW`). The data blocks represented by different rows of `XX`[`row`] may overlap in `XX`. Thus the different rows of `dXX`[`row`] represent the gradients of possibly overlapping data blocks. Therefore, when restoring `dXX`[`row`] to `dXX` according to the inverse process of the flattening process, these overlapping gradients need to be accumulated. This process is exactly the same as the previous 1D case.
