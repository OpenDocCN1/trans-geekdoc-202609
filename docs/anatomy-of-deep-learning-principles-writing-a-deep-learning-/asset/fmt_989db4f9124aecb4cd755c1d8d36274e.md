For compound functions, input a variable `x`, always calculate its function value along the compound process of the function "from inside to outside", that is, first calculate `g(x)`, and then calculate `f(g(x))`, and the process of calculating the derivative of the final function value `f(g(x))` with respect to the input `x` is reversed, first calculate `f'(g)`, and then calculate `g'(x)`, and then multiply the two together. That is to say, the derivation process is to find the derivative of each function in turn "from the outside to the inside".

For example, `sin(x²)` is a function composed of functions `f = sin(g)` and `g = x²`, therefore, its derivative:

`sin(x²)' = sin'(g) * g'(x) = sin'(g) * (x²)' = cos(g) * (2x) = 2x * cos(x²)`

Similarly, the derivative of the `σ(x)` function can be obtained:

$$
\begin{matrix}
\sigma'(x) & = (\frac{1}{1 + e^{-x}})' = \frac{1' * (1 + e^{-x}) - 1 * (1 + e^{-x})'}{(1 + e^{-x})^2} \\
& = \frac{- (1 + e^{-x})'}{(1 + e^{-x})^2} = \frac{- 0 - (e^{-x})'}{(1 + e^{-x})^2} = \frac{- (e^{-x})(-x)'}{(1 + e^{-x})^2} \\
& = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1 + e^{-x} - 1}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} - \frac{1}{(1 + e^{-x})^2} \\
& = \frac{1}{1 + e^{-x}}(1 - \frac{1}{1 + e^{-x}}) = \sigma(x)(1 - \sigma(x))
\end{matrix}
$$

The following code plots the function curve of `σ'(x)`:

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

def sigmoid(x):
    return 1/(1+np.exp(-x))

x = np.arange(-7, 7, 0.1)
y = sigmoid(x)
dy = sigmoid(x)*(1-sigmoid(x))

plt.plot(x, y)
plt.plot(x, dy)

plt.legend(['$\sigma(x)$','$\sigma\'(x)$'])
plt.xlabel('x')
plt.ylabel('y')
plt.show()
```

**Figure 1-29** Function curve of `σ(x)`, `σ'(x)`

It can be seen that the function curve of `σ'(x)` is a bell-shaped curve, for all `x`, `σ'(x) > 0`, and its derivative value is the largest at `x=0`. For `σ(0)(1 - σ(0)) = 0.5 * 0.5 = 0.25`, when `x` tends to infinity, the derivative value tends to 0. The magnitude of the derivative value shows how quickly the function value changes with the independent variable. Therefore, `σ(x)` changes the fastest at `x = 0`, and when it tends to infinity, the change of the function value becomes more and more slow.

The above four arithmetic rules and the chain derivation rule of compound functions can be easily proved according to the definition of derivatives. Interested readers can prove it by themselves or refer to calculus textbooks.

### 1.3.5 Calculation graph, forward calculation, backpropagation derivation

The process of constructing a function from a simple function through the four arithmetic and compound operations can be represented by the above-mentioned Figure 1-29, where the nodes in the figure represent the four arithmetic operations or compound operations. This figure also shows the process of inputting an argument `x` to this function to calculate the function value (function output). This graph is called **calculation graph**, and the process of calculating the output function value of an input variable according to the process of forming this graph is called **forward calculation**. It can be seen from the figure that the derivation process is exactly the reverse process of the forward calculation process, so it is called **backward calculation** or **backpropagation calculation**.

![](EPUB/media/file228.png)

**Figure 1-30** Schematic diagram of forward calculation (solid line) and reverse derivation calculation (dotted line)

As shown in Figure 1-30, the forward calculation process is obtained from `x` through the function `g` to get `g(x) = x²`, and then through the function `f` to get `f(g) = sin(g) = sin(x²)`.

`x → g → g(x) = x² → f → f(g) = sin(g) = sin(x²)`

The backpropagation derivation process is:

`f → f'(g) → f'(g) = sin'(g) = cos(g)`

`g → g'(x) → g'(x) = (x²)' = 2x`

`f'(x) = f'(g) * g'(x) = cos(g) * (x²)' = cos(g) * 2x = cos(x²) * 2x`

Backpropagation derivation is the core and most critical foundation of neural network (deep learning). If you understand reverse derivation, you can easily understand the algorithm principle of deep learning.

### 1.3.6 Partial derivatives and gradients of multivariable functions

Sometimes the independent variable `x` is a vector composed of multiple components instead of a single value, that is, `x = (x[1], x[2], ..., x[n])` contains multiple components `x[j]`. A function `f(x)` that maps such an independent variable `x` to a single numerical dependent variable is called a **multivariate function** and can be expressed as `f : ℝⁿ → ℝ`.

The derivative of `f(x)` with respect to each component `x[j]` of `x` is called the partial derivative, denoted as `∂f/∂xⱼ`, which reflects the rate of change of `f(x)` about this component `x[j]`.

`∂f/∂xⱼ = lim(Δxⱼ→0) [f(x₁,...,xⱼ + Δxⱼ,...,xₙ) - f(x₁,...,xⱼ,...,xₙ)] / Δxⱼ`

That is, the partial derivative is to treat other variables as constants and `x[j]` as a variable, so this function is a univariate function, and its derivative with respect to `x[j]` is called the partial derivative of the original function with respect to `x[j]`.

For example, if `f(x, y) = 2x + y²`, its argument contains 2 components `x` and `y`, this function is a multivariate function, and the argument `(x, y)` maps to the function value `f(x, y)`, that is, `f : (x, y) → (2x + y²)`. The partial derivatives of this function with respect to `x`, `y` are:

`∂f/∂x = ∂(2x + y²)/∂x = d(2x)/dx = 2`

`∂f/∂y = ∂(2x + y²)/∂y = d(y²)/dy = 2y`

The gradient of `f(x)` with respect to `x` `∇ₓf(x)` is a vector of partial derivatives of `f(x)` with respect to each component `x[j]` of `x`:

`∇ₓf(x) = df/dx = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

In the above example, `f(x, y) = 2x + y²` about the gradient of `(x, y)` `∇₍ₓ,ᵧ₎f(x, y) = (2, 2y)`. The gradient at a specific point `(2,3)` is `(2, 6)`.

Without causing confusion, the gradient of `f(x)` with respect to `x` `∇ₓf(x)` is often abbreviated as `∇f(x)`.

For a very small increment of `x` `Δx = (Δx[1], Δx[2], ..., Δx[n])`, the increment of `f(x)` `f(x + Δ) - f(x)` can be approximated as the dot product of gradient `∇f(x)` and `x` increment `Δx`.

`f(x + Δ) - f(x) ≃ ∇f(x) ⋅ Δx`

Usually, the gradient is written in the form of a row vector:

`∇ₓf(x) = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

And `f(x)`, `x` is written in the form of a column vector:

$$
\begin{matrix}
x = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}
\quad
\Delta x = \begin{bmatrix} \Delta x_1 \\ \Delta x_2 \\ \vdots \\ \Delta x_n \end{bmatrix}
\end{matrix}
$$
