

# Key Parameters and Optimization Strategies for Gradient Descent

The most important parameter in gradient descent is the **learning rate** (usually denoted by `α` or `η`). For a specific neural network architecture, an excessively large or small learning rate is the most critical factor affecting whether the algorithm can converge. One can try parameters of different orders of magnitude (e.g., `0.1`, `0.01`, `0.0001`, etc.) and select a suitable learning rate in conjunction with visualizing the loss curve or learning curve.

Besides the learning rate, one should also try different parameter optimization strategies, such as famous parameter optimization methods like **Momentum**, **RMSprop**, **Adam**, etc. These optimization methods may also have hyperparameters similar to the learning rate; similar methods can be used to try and select appropriate hyperparameters.

For **Batch Gradient Descent** (often referred to as Mini-batch Gradient Descent in this context), one can consider different batch sizes and select a batch size that balances time efficiency and model quality for model training.

Additionally, some special techniques (such as the **Dropout** technique mentioned later) may also have hyperparameters that need tuning. Parameter tuning (including network architecture parameters) is a task that requires long-term practice and experience accumulation. One also needs to learn from others' neural network parameter tuning experiences and tips online to avoid blind exploration.

## 5.3 Batch Normalization

Data standardization preprocessing normalizes different features of the data into a standard distribution with a mean of 0 and equal variance, avoiding data overflow caused by large values and "feature bias" caused by features of different scales, allowing the learning algorithm to converge faster with a higher learning rate. Despite this, as data undergoes transformations through neural network layers, especially as the number of layers deepens, its distribution deviates further and further from the standard normal distribution. Since the backpropagation calculation of gradients is a process of continuous multiplication of gradients across different layers, if the values are too large or too small, it easily leads to **gradient explosion** or **vanishing gradients**, making training increasingly difficult.

### 5.3.1 What is Batch Normalization?

To solve this problem, **Batch Normalization** (abbreviated as **BN**) was proposed to normalize the intermediate outputs of network layers. The BN operation of a certain network layer usually normalizes the weighted sum and then generates the activation value through the activation function `ϕ`; that is, it is an operation inserted between the weighted operation and the activation function. If the weighted sum operation of a certain network layer is `z = xW + b`, then after the BN operation, the activation function is executed to output the activation value:

`ϕ(BN(z)) = ϕ(BN(xW + b))`

As mentioned before, the weighted sum is regarded as a separate layer (i.e., a Fully Connected layer), and the activation function is regarded as a separate activation layer. The BN operation can be viewed as a separate Batch Normalization layer (BN layer) inserted between them.

Simply normalizing `z` to a standard normal distribution `𝒩(0, 1)` would limit the model's expressive power, because no matter how the previous layers transform, the output of this layer would always follow a standard normal distribution. The BN operation introduces learnable parameters `β` and `γ` representing the mean and mean squared error (variance), transforming the features normalized to the standard normal distribution `𝒩(0, 1)` into a normal distribution `𝒩(β, γ)`. Since both `β` and `γ` are learnable parameters, the problem of reducing the model's expressive power is avoided.

The BN layer takes the weighted sum `z` output by the fully connected layer as input, calculates the mean and variance of each feature of these `z`s, normalizes each feature of `z` to the standard normal distribution `𝒩(0, 1)` based on the mean and variance, and then uses the learnable parameters `β` and `γ` to transform it into a normal distribution `𝒩(β, γ)`.

When there is no ambiguity, the letter `x` is used to refer to the `z` that needs BN normalization. For a batch of samples `ℬ = x[1], x[2], ⋯, x[m]`, BN normalization first calculates the mean `μ[ℬ]` and variance `σ[ℬ]` of this batch of samples, and then scales and shifts them using the learnable parameters `γ` and `β`:

$$
\begin{matrix}
\mu_{B} & {= \frac{1}{m}\sum\limits_{i = 1}^{m}x_{i}} \\
\sigma_{B}^{2} & {= \frac{1}{m}\sum\limits_{i = 1}^{m}(x_{i} - \mu_{B})^{2}} \\
\hat{x_{i}} & {= \frac{x_{i} - \mu_{B}}{\sqrt{\sigma_{B}^{2} + \epsilon}}} \\
y_{i} & {= \gamma \odot x_{i} + \beta} \\
\end{matrix}
$$

If each row of matrix `X` represents a data point, the following code can be used to calculate the mean `mean` and variance `var` of each feature of the data:

```python
mean = X.mean(axis=0)
var = ((X - mean) ** 2).mean(axis=0)
```

That is, calculating the mean and variance along the row direction. Of course, numpy's `var()` function can also be used to calculate the variance:

```python
var = np.var(X, axis=0)
```

It is assumed here that each data point `x[i]` is a vector or a 1D array, i.e., `X` is a 2D array or matrix. Later we will see that data may be multi-dimensional arrays (e.g., multi-channel images). Whether `x[i]` is a 1D or multi-dimensional array, each of its elements is treated as a feature. For multi-dimensional `x[i]`, numpy's `reshape()` function can be used to flatten it into a 1D array (vector), so that `X` remains a 2D array (matrix). The following code ensures `x[i]` is flattened into a 1D vector:

```python
n_X = X.shape[0]
X_flat = X.ravel().reshape(n_X, -1)  # X_flat = X.reshape(n_X, -1)
```

The following is the forward computation code for batch normalization:

```python
n_X = X.shape[0]
X_flat = X.ravel().reshape(n_X, -1)
mu = np.mean(X_flat, axis=0)
var = np.var(X_flat, axis=0)
X_norm = (X_flat - mu) / np.sqrt(var + 1e-8)
out = gamma * X_norm + beta
return out.reshape(self.X_shape)
```

Since neural network training usually adopts **Mini-batch Gradient Descent** (often referred to as Batch Gradient Descent in context), each gradient descent step uses a small batch of samples to update model parameters. Therefore, batch normalization does not calculate the mean and mean squared error of the entire training set samples, but calculates the mean and mean squared error using a small batch of samples during the training process, hence the name **Batch Normalization**.

During prediction, the forward computation of data also needs to be processed by the BN layer, but it does not need and should not perform the BN operation again. This requires using the determined BN layer mean, variance, and parameters (such as `β`, `γ`) from the training process for transformation. However, the mean and mean squared error calculated at each iteration step during the iteration process are different; the mean and variance used for prediction should not rely solely on the result of a certain iteration step. For this, one can average the means and mean squared errors of all iteration steps, usually using the **Moving Average** method to calculate the moving mean and variance.

If `running_mu` and `running_var` represent the moving averages of the mean and variance during the training process, the calculation code is as follows:

```python
running_mu = momentum * running_mu + (1 - momentum) * mu
running_var = momentum * running_var + (1 - momentum) * var
```
