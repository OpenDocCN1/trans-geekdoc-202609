### 6.1.4 多输入通道与多输出通道

彩色图像通常至少包含 3 个通道（RGB 通道），每个通道都是一个二维矩阵。因此，3 通道彩色图像可视为三个二维矩阵的叠加，或一个三维数组（张量体）（或 3D 信号）。因此，要对彩色图像执行卷积运算，需为每个通道给定相应的卷积核。每个通道图像是一个 2D 信号，对应一个 2D 卷积核，所有通道的卷积核共同构成一个 3D 卷积核。

如图 6-25 所示，对于一个 2 通道彩色图像，使用一个 2 通道 3D 卷积核进行卷积运算，产生单通道输出图像：

图 6-25 对于 2 通道彩色图像，使用 2 通道 3D 卷积核进行卷积运算，生成单通道输出图像

使用 3D 卷积核 `w` 对 3D 张量 `X` 执行卷积运算以生成 2D 张量 `a`，其卷积计算公式为：

$a\_{i,j} = \sum\limits\_{d = 0}^{F\_{d} - 1}\sum\limits\_{m = 0}^{F\_{h} - 1}\sum\limits\_{n = 0}^{F\_{w} - 1}w\_{d,m,n}x\_{d,i + m,j + n}\qquad$

以下是 3D 卷积运算的代码实现：

```
def convolve3d(X, K, P=(0,0), S=(1,1)): 
    C, H, W = X.shape
    C, F_h, F_w = K.shape
    P_h, P_w = P[0], P[1]
    S_h, S_w = S[0], S[1]   
    h = (H + 2 * P_h - F_h) // S_h + 1
    w = (W + 2 * P_w - F_w) // S_w + 1
    Y = np.zeros((h, w))            # convolution output
    if P_h != 0 or P_w != 0:  
        X_padded = np.pad(X, [(0,0), (P_h, P_h), (P_w, P_w)], mode='constant')
    else:
        X_padded = X
    for i in range(h):     # Loop over every pixel of the image  
        hs = i * S_h
        for j in range(w):   
            ws = j * S_w
            # element-wise multiplication of the kernel and the image
            Y[i, j] = (K * X_padded[:, hs:hs+F_h, ws:ws+F_w]).sum()        
    return Y
```

可使用多个不同的 3D 卷积核生成多个不同的 2D 图像。如图 6-28 所示，使用两个 3 通道 3D 卷积核对 3 通道彩色图像执行卷积运算。每个 3 通道 3D 卷积核生成一张单通道图像，总共可生成 2 张单通道图像，或产生一个 2 通道输出图像。

图 6-28 使用 2 个 3D 卷积核进行图像卷积，产生 2 张输出图像

使用多个 3D 卷积核执行 3D 卷积运算可生成多通道输出图像，其计算公式如下：

$a\_{i^{\prime},j^{\prime},k^{\prime}} = \sum\limits\_{k = 0}^{F\_{k} - 1}\sum\limits\_{i = 0}^{F\_{h} - 1}\sum\limits\_{j = 0}^{F\_{w} - 1}w\_{i,j,k,k^{\prime}}x\_{i + i^{\prime},j + j^{\prime},k}\qquad$

其中，`k'` 代表不同的卷积核。

卷积运算实际上提取原始数据中的某种特征信息。因此，每个卷积核生成的输出通道或卷积图像也称为**特征图**（Feature map）。多个卷积核产生多个输出特征图。

### 6.1.5 池化

与卷积类似，**池化**也使用固定形状的窗口（称为**池化窗口**）对齐数据并计算数据窗口的输出值。不同于卷积对输入数据与卷积核的加权求和，池化直接计算数据池化窗口中元素的最大值或平均值。如图 6-29 所示，使用 3×3 窗口从输入二维（图像）矩阵的左上角开始“从上到下，从左向右”滑动，每滑动到一个位置，输出当前池化窗口对应数据窗口中元素的最大值，以生成最终的结果矩阵。此过程称为**最大池化**。

图 6-29 3×3 窗口对 6×6 矩阵（图像）执行池化，生成尺寸为 4×4 的结果图像

当然，也可计算池化窗口中的平均值作为输出值。此池化运算称为**平均池化**。平均池化的工作方式与最大池化类似，只是对数据窗口中的元素求平均而非取最大值。

与卷积运算一样，池化运算的窗口通常为正方形。上述池化运算的步长为 1，即每次移动一个像素。池化运算的步长通常与池化窗口的长度或宽度相同。

如图 6-30 所示，池化运算的窗口长度和步长均为 3，在 6×6 上执行池化运算，生成 2×2 的结果图像，而原始图像尺寸为 6×6。

图 6-30 3×3 池化窗口，步长为 3 对 6×6 执行池化运算，生成 2×2 的结果图像

池化的主要目标是缓解卷积运算对位置的过度敏感。池化层可保留原始图像的主要特征，步长大于 1 的池化运算可指数级缩小图像尺寸并生成更小的特征图，从而减少后续层的计算量并提高计算效率。

与使用卷积核卷积输入数据所有通道的卷积运算不同，池化通常对每个通道单独执行池化运算。因此，输出通道数与输入数据相同，如图 6-31 所示：若输入为 64 通道，输出也为 64 通道，即每个输入通道生成一个输出通道。

图 6-31 池化针对每个通道，池化运算不改变通道数

与卷积运算一样，池化运算不仅有步长，还会在池化前填充原始图像。类似于卷积运算，可编写以下代码对单通道输入数据 `X` 执行池化运算：

```
def pool2d(X, pool, stride=(1,1), padding=(0,0), mode='max'):
    pool_h, pool_w = pool
    S_h, S_w = stride
    P_h, P_w = padding
    # fill
    if P_h or P_w:
        X_padded = np.pad(X, [(P_h, P_h), (P_w, P_w)], mode='constant')
    else:
        X_padded = X
```
