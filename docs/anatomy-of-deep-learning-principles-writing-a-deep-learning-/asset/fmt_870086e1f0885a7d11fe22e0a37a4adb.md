### 3. Covariance, covariance matrix

For two vectors `a = (x[a], y[a])`, `b = (x[b], y[b])` on a two-dimensional plane, their dot product `a ⋅ b = x[a]x[b] + y[a]y[b]` characterizes their correlation. For example, `a = (1, 1)`, `b = (−1, 1)`, their dot product `a ⋅ b = 1 * 1 + (−1) * 1 = 0` indicates that they are perpendicular to each other, that is, irrelevant. For example, `a = (1, 1)`, `b = (1, 1)`, their dot product `a ⋅ b = 1 * 1 + 1 * 1 = 2`; these two vectors are the same vector that coincides, they are related. For example, `a = (1, 1)`, `b = (1, 0)`, their dot product `a ⋅ b = 1 * 1 + 1 * 0 = 1`; the angle between these two vectors is 45 degrees, and their degree of correlation is between the two degrees of correlation just now.

Generally, there are 2 vectors `x = (x[1], x[2], ⋯, x[n])`, `y = (y[1], y[2], ⋯, y[n])`; you can use their dot product `x ⋅ y = x[1]y[1] + x[2]y[2] + ⋯ + x[n]y[n]` to characterize their correlation.

Covariance is a measure of the correlation between two random variables. If two random variables `X`, `Y` take the value of `(x[1], x[2], ⋯, x[n])`, `y = (y[1], y[2], ⋯, y[n])`, the covariance `Cov(X,Y)` between them is defined as:

$$Cov(X,Y) = \frac{(x_{1} - \mu_{X})(y_{1} - \mu_{Y}) + (x_{2} - \mu_{X})(y_{2} - \mu_{Y}) + \cdots + (x_{n} - \mu_{X})(y_{n} - \mu_{Y})}{n}$$

That is to say, the dot product operation is performed on the values after they are subtracted from the expectation, and then averaged. This form is very similar to the variance of a single random variable:

$$Var(X) = \frac{(x_{1} - \mu_{X})(x_{1} - \mu_{X}) + (x_{2} - \mu_{X})(x_{2} - \mu_{X}) + \cdots + (x_{n} - \mu_{X})(x_{n} - \mu_{X})}{n}$$

But the meanings of the two are different. `Var(X)` describes the degree of divergence of the random variable from the expected value, and `Cov(X, Y)` describes the correlation between two random variables.

$$
\begin{matrix}
{\text{Cov}(X,Y)} & {= E[(X - E[X])(Y - E[Y])]} \\
\end{matrix}
$$

According to the desired linear law, the following derivation can be made:

$$
\begin{matrix}
{{Cov}(X,Y)} & {= E[(X - \mu_{X})(Y - \mu_{Y})]} \\
& {= E[XY - \mu_{X}Y - \mu_{Y}X + \mu_{x}\mu_{Y}]} \\
& {= E[XY] - \mu_{X}E[Y] - \mu_{Y}E[X] + \mu_{x}\mu_{Y}} \\
& {= E[XY] - \mu_{x}\mu_{Y} - \mu_{x}\mu_{Y} + \mu_{x}\mu_{Y}} \\
& {= E[XY] - \mu_{x}\mu_{Y}} \\
& {= E[XY] - E[X] E[Y]} \\
\end{matrix}
$$

In machine learning, a sample may have multiple features. For example, a house may contain features such as area, number of rooms, location, number of floors, etc. Each feature can be seen as a random variable, and some features may be related. The influence of the features on the machine learning algorithm will be mutually restrained, and eliminating the correlation between features or selecting low-correlation features will help improve the performance of the machine learning algorithm. Correlation analysis can be performed on these features to help select good features or transform the original data to eliminate the correlation between features.

If a sample has 3 features, their corresponding random variables are represented by `X1`, `X2`, and `X3` respectively, and the correlation between them can be analyzed by calculating the pairwise covariation between them. The covariant value between them can be expressed in the form of a matrix, called **covariance matrix**, usually represented by the symbol `∑`.

$$
\begin{matrix}
{\sum = \begin{pmatrix}
{Cov(X_{1},X_{1})} & {Cov(X_{1},X_{2})} & {Cov(X_{1},X_{3})} \\
{Cov(X_{2},X_{1})} & {Cov(X_{2},X_{2})} & {Cov(X_{2},X_{3})} \\
{Cov(X_{3},X_{1})} & {Cov(X_{3},X_{2})} & {Cov(X_{3},X_{3})} \\
\end{pmatrix}} \\
\end{matrix}
$$

This is a symmetric matrix. If all possible values of each random variable are lined up, these possible values of all random variables can be represented as a matrix:

`X = (X[1], X[2], X[3])`

If `X[i]` is a random variable with equal probability, the covariance matrix can be calculated as follows:

`X = X − E[X]`

`∑ = X^(T)X`

It can be calculated with the following python code:

```python
X = X - np.mean(X, axis=0)
np.dot(X.transpose(), X)
```

## 2.1 Necessary conditions for function extremum

The function `y = f(x)` obtains the **minimum value** at a certain point `x[0]`: it means that there is a certain positive number `ϵ`, so that for the interval `(x[0] − ϵ, x[0] + ϵ)` each x satisfies `f(x[0]) ≤ f(x)`. `x[0]` is called the **minimum point** of the function, and `f(x[0])` is called the **minimum value** of the function.

The function `y = f(x)` obtains the **maximum value** at a certain point `x[0]`: it means that there is a certain positive number `ϵ`, so that for the interval `(x[0] − ϵ, x[0] + ϵ)` each x satisfies `f(x) ≤ f(x[0])`. `x[0]` is called the **maximum point** of the function, and `f(x[0])` is called the **maximum value** of the function.

The minimum value and maximum value are collectively referred to as **extreme value**, and the minimum value point and maximum value point are collectively referred to as **extreme value point**.

If all x in the domain of the function `f(x)` satisfy `f(x[0]) ≤ f(x)`, then `x[0]` is called the **global minimum point** of the function, and `f(x[0])` is called the **global minimum value** of the function.

If all x in the domain of the function `f(x)` satisfy `f(x) ≤ f(x[0])`, then `x[0]` is called the **global maximum point** of the function, and `f(x[0])` is called the **global maximum value** of the function.

That is, the global minimum value is a minimum value of a global range, and the global maximum value is a maximum value of a global range. The global minimum and maximum values are collectively referred to as **Global Optimum**, and the global minimum and maximum points are collectively referred to as **Global Optimum Points**.

**Necessary conditions for function extremum**: If `x[0]` is the extremum point of function `f(x)`, and the function is derivable at `x[0]`, then `f'(x[0]) = 0` must be true. The derivative value at the extreme point must be 0.

For example, the previous function `f(x) = x²` obtains the minimum value at `x = 0` (of course it is also a global minimum value) and can be derived, so at `x = 0` its derivative value `f'(0) = 2 × 0 = 0` must be 0.
