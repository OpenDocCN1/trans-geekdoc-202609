

随机事件 A 的可能性用 0 到 1 之间的一个实数来表示，通常用符号 `P(A)` 表示，即 `0 <= P(A) <= 1`。显然 `P(∅) = 0`，`P(Ω) = 1`，概率为 0 和 1 的事件分别称为**不可能事件**和**必然事件**，所以 `∅` 和 `Ω` 分别是不可能事件和必然事件。

对于任意事件 A，显然：`∅ ⊆ A ⊆ Ω`。

**互斥事件**（也称**不相容事件**）：A 和 B 不能同时发生，即 A 和 B 没有公共样本点。即 `A ∩ B = ∅`。

**对立事件**：互斥事件的一种特殊情况，A 和 B 不能同时发生，但 A 和 B 必有一个发生。用集合语言表示：`A ∩ B = ∅`。且 `A ∪ B = Ω`。

**古典概型**（**古典概率**）：样本空间有限，且每个样本出现的概率相同。古典概率的事件概率 = 事件所包含的样本数 / 样本空间的样本总数。

例如，对于“投掷一个骰子”，样本空间的总数为 6，“出现的点数小于 3”只有 2 个样本点（点数 1 和点数 2）。因此，该事件（“出现的点数小于 3”）的概率 P = 2/6。

当然，对于一般的随机实验，每个样本点（基本事件）出现的概率通常不相等。如何知道一个事件发生的概率？通常采用统计方法来确定事件的概率，即重复多次随机实验，例如 n 次。在这些实验中，如果事件 A 发生了 k 次，则称事件 A 的频率为 k/n。不断进行这种重复随机实验，当 n 很大时，根据概率论中的大数定律，这个频率将趋近于真实的概率。即：

$$P(A) = \lim_{n \rightarrow \infty}\frac{k}{n}$$

例如，下面的代码用函数 `one_coin_test(n)` 模拟一次试验（n 次抛硬币）并返回其中正面朝上的频率。可以看出，随着 n 的增加，频率趋近于概率 0.5。

```
from random import randint
def one_coin_test(n):
    head_tails=[]
    for i in range(n):
        head_tails.append(randint(0,1))
    heads = head_tails.count(1)
    return heads/n

for n in range(10,50000,2000):
    print(one_coin_test(n),end=', ')
```

一个随机实验有许多可能的事件，每个事件都有一个概率。在数学上，这些事件的概率被定义为从事件到概率的一个映射。

假设样本空间 Ω 中所有可测事件的全体是 F，概率 P 是从 F 到实数区间 `[0,1]` 的一个映射，即 `P: F → [0, 1]`。该映射必须满足：

1.  **非负性**：`0 <= P(A) <= 1`
2.  **规范性**：`P(Ω) = 1`
3.  **可列可加性**：设 `A[1], A[2], ⋯` 为两两不相容事件，即对 `i ≠ j`，有 `A[i] ∩ A[j] = ∅`，`(i, j = 1, 2, ⋯)`，则 `P(A[1] ∪ A[2] ∪ ⋯) = P(A[1]) + P(A[2]) + ⋯`

### 1.4.2 条件概率、联合概率、全概率公式、贝叶斯公式

对于一个事件 A，`P(A)` 表示 A 发生的概率，称为**先验概率**。有时也要考虑条件概率，即在已知一个事件已经发生的条件下，另一个事件发生的概率。用 `P(B|A)` 表示在 A 已经发生的条件下 B 发生的概率。

举一个医学例子，用 A 表示“患有乙肝”，用 B 表示“表面抗体阳性”。即 `P(A)` 表示随机抽取一个人，“患乙肝”的概率是多少。`P(B)` 表示随机抽取一个人进行检查，他的表面抗体呈阳性的概率。

那么 `P(B|A)` 表示“在患有乙肝的情况下，表面抗体呈阳性的概率”。显然，先验概率 `P(B)` 和条件概率 `P(B|A)` 不相等，因为“任意一个人的表面抗原呈阳性”显然不同于“患有乙肝的人表现出抗原阳性”。后者的可能性应该更大。

联合概率 `P(A, B)` ：表示 (A, B) 同时发生的联合概率。也就是说，随机抽取一个人，同时出现“患乙肝，表面抗体阳性”的概率是多少。

联合概率 `P(A, B)` 有时也写作 `P(A ∩ B)`，表示 A 和 B 同时发生或其交集发生的概率。

条件概率可以用先验概率和联合概率来计算：

$$P(B|A) = \frac{P(A,B)}{P(A)}$$

$$P(A|B) = \frac{P(A,B)}{P(B)}$$

可以用“投掷骰子”来帮助理解这个公式。设 A 表示“点数大于 3”，B 表示“点数为偶数”，则 `(A, B)` 表示“点数大于 3 且为偶数”，`(B|A)` 表示“在点数大于 3 的条件下，点数为偶数”。

“点数大于 3 且为偶数”在样本点空间 {1, 2, 3, 4, 5, 6} 中只有 2 个样本点 {4,6}，所以：`P(A, B) = 2/6`

同理，“点数大于 3”的概率 `P(A) = 3/6`

“点数大于 3 时”的样本点空间集合为 {4, 5, 6}，即有 3 个样本点，其中偶数有 2 个 {4, 6}，因此，`P(B|A) = 2/3`

可以验证：

$$\frac{P(A,B)}{P(A)} = \frac{2/6}{3/6} = 2/3 = P(B|A)$$

联合概率也可以写成下面的形式（条件概率与先验概率的乘积）：

`P(A, B) = P(A)P(B|A) = P(B)P(A|B)`

这个公式可以推广到 n 个事件：

`P(A[1], A[2], ⋯, A[n]) = P(A[1])P(A[2]|A[1])P(A[3]|A[1], A[2])⋯P(A[n]|A[1], A[2], ⋯, A[n−1])`

当且仅当 `P(A, B) = P(A)P(B)` 时，两个事件是**独立**的。

等价于：`P(B|A) = P(B)` 或 `P(A|B) = P(A)`。

两个事件**互斥**，意味着这两个事件不能同时发生，例如抛硬币时“正面”和“反面”这两个事件就是互斥的。对于互斥事件 A 和 B，显然 A 和 B 同时发生的概率为 0，即 `P(A, B) = 0`。

对于集合 A、B，它们的交集和并集有关系 `A ∪ B = A + B − (A ∩ B)`，因此，如果两个事件 A、B 不互斥，`P(A ∪ B) = P(A) + P(B) − P(A, B)`，如图 1-32 所示。如果 A 和 B 互斥，`P(A ∪ B) = P(A) + P(B) − P(A, B) = P(A) + P(B)`。

`P(A[1] ∪ A[2] ∪ ⋯ ∪ A[n]) = P(A[1]) + P(A[2]) + ⋯ + P(A[n]) = 1`
