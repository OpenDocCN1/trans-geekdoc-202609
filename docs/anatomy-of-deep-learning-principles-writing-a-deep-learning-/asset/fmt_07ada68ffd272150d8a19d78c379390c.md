
## 二维卷积操作示例

以下代码首先根据卷积核的高度 `K_h` 和宽度 `K_w`，在图像的上、下、左、右分别填充 `(K_h-1)//2` 和 `(K_w-1)//2` 个像素，然后对填充后的图像进行卷积乘积运算。对应的 Python 代码如下：

```python
def convolve2d_same(X, K): 
    H, W = X.shape   
    K_h, K_w = K.shape
    P_h = (K_h)//2           # 左右边缘填充的宽度
    P_w = (K_w)//2           # 上下边缘填充的高度
    Y = np.zeros((H, W)) 
    X_padded = np.pad(X, [(P_h, P_h), (P_w, P_w)], mode='constant')    
    for i in range(Y.shape[0]):  
        for j in range(Y.shape[1]):
            Y[i, j] = (X_padded[i:i+K_h, j:j+K_w] * K).sum()     
    return Y
```

执行此 "same" 卷积操作会产生一个与原始图像矩阵形状和大小相同的结果矩阵。

`scipy` 库的 `scipy.signal` 模块有一个类似的函数 `convolve2d()`，可对图像执行二维卷积。它与我们自己实现的卷积不同之处在于，它首先将卷积图像左右翻转和上下翻转，然后再与卷积核的对应元素值进行累加求和。也就是说，它的卷积是通常所说的卷积运算。你可以对刚才的卷积核做水平翻转，然后执行 `convolve2d()` 函数，生成与上图相同的结果图像。

```python
import scipy.signal
kernel = np.flipud(np.fliplr(kernel)) # 翻转卷积核
edges = scipy.signal.convolve2d(image, kernel, 'same')
plt.imshow(edges, cmap=plt.cm.gray)
```

### 步长

上述卷积操作的**步长**为 1，即卷积核始终 "从上到下、从左到右" 逐像素移动，结果图像的大小接近原始图像。要生成较小尺寸的卷积图像（如原始图像一半大小的卷积图像），可以在水平和垂直方向滑动时每次滑动 2 个像素。即以步长为 2 的方式滑动卷积核进行卷积运算。**步长**有时也称为 "**Stride**"。

与一维信号卷积类似，对于高度和宽度分别为 `H` 和 `W` 的二维信号（如图像），设卷积核的高度和宽度为 `F_h` 和 `F_w`，上下、左右填充的元素数量为 `P_h`、`P_w`，上下、左右步长分别为 `S_h`、`S_w`，输出二维信号（图像）的高度和宽度为：

$$
\begin{matrix} 
{(H - F_h + P_h)/S_h + 1} \\ 
{(W - F_w + P_w)/S_w + 1} 
\end{matrix}
$$

如图 6-23 所示，对于 7x7 的输入图像，卷积核大小为 3x3，步长为 2，上下左右各填充 1。结果输出图像大小为 `((6+2-3)/2+1)x ((6+2-3)/2+1) = 3x3`。

Figure 6-23 步长为 2 的卷积

结合填充和步长的二维卷积运算 Python 代码如下：

```python
def convolve2d(X, K, pad=(0, 0), stride=(1, 1)): 
    H, W = X.shape   
    K_h, K_w = K.shape
    P_h, P_w = pad
    S_h, S_w = stride  
    h = (H - K_h + 2 * P_h) // S_h + 1
    w = (W - K_w + 2 * P_w) // S_w + 1    
    Y = np.zeros((h, w)) 
    if P_h != 0 or P_w != 0:
        X_padded = np.pad(X, [(P_h, P_h), (P_w, P_w)], mode='constant') 
    else:
        X_padded = X
    for i in range(Y.shape[0]):
        hs = i * S_h
        for j in range(Y.shape[1]):
            ws = j * S_w
            Y[i, j] = (X_padded[hs:hs+K_h, ws:ws+K_w] * K).sum()     
    return Y
```
