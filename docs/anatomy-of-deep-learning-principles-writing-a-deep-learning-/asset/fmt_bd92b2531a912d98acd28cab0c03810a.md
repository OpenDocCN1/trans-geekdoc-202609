This is a valid method of convolution, and finally produces a matrix of `4*4`.

If `x[i, j]` is used to represent the i-th row and j-column element of a two-dimensional matrix (such as an image matrix), and `w[m, n]` is used to represent the m-th row and n-column weight of the convolution kernel, Use `a[i, j]` to represent the i-th row and j-th column element of the result matrix, then the convolution operation formula of the two-dimensional matrix is as follows:

$a_{i,j} = \sum\limits_{m = 0}^{F_{h}}\sum\limits_{n = 0}^{F_{w}}w_{m,n}x_{i + m,j + n}\qquad$

That is, the convolution kernel window is aligned with the (i, j) position of the data matrix, and then weighted and summed with the corresponding data in the data window. For example, `a[1, 1]` in the example above is calculated as follows:

$$
\begin{matrix}
a_{1,1} & {= \sum\limits_{m = 0}^{F_{h}}\sum\limits_{n = 0}^{F_{w}}w_{m,n}x_{1 + m,1 + n}} \\
& {= w_{0,0}x_{1,1} + w_{0,1}x_{1,1 + 1} + w_{0,2}x_{1,1 + 2}} \\
& {\quad w_{1,0}x_{1 + 1,1} + w_{1,1}x_{1 + 1,1 + 1} + w_{1,2}x_{1 + 1,1 + 2}} \\
& {\quad w_{2,0}x_{1 + 2,1} + w_{2,1}x_{1 + 2,1 + 1} + w_{2,2}x_{1 + 2,1 + 2}} \\
& {= w_{0,0}x_{1,1} + w_{0,1}x_{1,2} + w_{0,2}x_{1,3}} \\
& {\quad w_{1,0}x_{2,1} + w_{1,1}x_{2,2} + w_{1,2}x_{2,3}} \\
& {\quad w_{2,0}x_{3,1} + w_{2,1}x_{3,2} + w_{2,2}x_{3,3}} \\
\end{matrix}
$$

Suppose the number of rows and columns of the data matrix X is h and w respectively, and the number of rows and columns of the convolution kernel K is `F[h]` and `F[w]` respectively, then the number of rows and columns of the result matrix generated by the "valid convolution" operation is `h - F[h] + 1` and `w - F[w] + 1`. The following is the code implementation of the "valid convolution" operation on a two-dimensional matrix (of an image):

```python
def convolve2d(X, K):
    h, w = K.shape
    Y = np.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i: i + h, j: j + w] * K).sum()
    return Y
```

Where X is the input two-dimensional matrix (image), K is the convolution kernel matrix, and Y is the result matrix (image). That is, the image window starting with `(i, j)` `X[i: i + h, j: j + w]` and the convolution kernel K perform element-wise product `X[i: i + h, j: j + w] * K` and sum up `X[i: i + h, j: j + w] * K.sum()`. When `(i, j)` slides along the image, a series of element values of the resulting matrix are obtained.

In order to generate an image of the same size as the original image, "same convolution" can also be used, that is, some 0 values are filled around the image. If the size of the weight matrix is `F[w] * F[h]`, the number of 0s `P[w]` filled in the left and right of the original image is `(F[w] - 1)/2`, and the number of 0s filled in the top and bottom `P[h]` It is `(F[h] - 1)/2`. Generally, the weight matrix is a square matrix with the same length and width. As shown in Figure 6-18. Use the 3x3 convolution kernel to perform the same convolution on the 6x6 matrix, fill the original matrix with (3-1)/2 0 values, and get a 6x6 matrix.

The above code creates a padded image `X_padded` according to the size of the padding. In fact, numpy also provides a ready-made `pad()` function that pads the front and back of each axis of the multidimensional array:

```python
np.pad(x, [(1, 0), (1, 2)], mode='constant', constant_values=0)
```

The second parameter `[(1, 0), (1, 2)]` indicates the number of pixels to be filled before and after each axis of the numpy array x, and the first tuple (1,0) indicates The front and rear of the first axis (the axis corresponding to axis=0) are filled with 1 and 0 pixels respectively, and the second tuple (1, 2) indicates that the front and rear of the second axis (the axis corresponding to axis=1) are filled with 1 and 2 respectively pixels. mode='constant' indicates that the filling is a constant value, and constant_values=0 indicates that the filling constant value is 0, and these two parameters can be omitted.
