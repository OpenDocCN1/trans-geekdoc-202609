## 最大范数约束

在梯度下降法中，特别是在深度学习中，随着层数的增加，由于反向推导是计算梯度的乘积，会导致梯度消失和梯度爆炸。最大范数约束可以防止梯度爆炸。即将即将更新的权重限制在一定范围内，也就是说，通过裁剪权重向量，使得某个范数（如 `L2` 范数）不超过某个值：`||w||2 < c`。`c` 的典型值为 3 或 4，一些研究报告称，这种对权重的最大范数约束可以提高算法的收敛性能。特别是在后面要学习的循环神经网络中，通常使用这种**最大范数约束**来防止梯度爆炸。

```python
import numpy as np

def max_norm_constraints(w, c, epsilon=1e-8):
    norms = np.sqrt(np.sum(np.square(w), keepdims=True))
    desired = np.clip(norms, 0, c)
    w *= (desired / (epsilon + norms))
    return w

w = np.random.randn(2, 5) * 10
print(w)
w = max_norm_constraints(w, 2)
print(w)
```

如果 `grads` 包含多个权重参数的梯度，以下代码可以将它们的梯度限制在 `[-c, c]` 范围内：

```python
import math

def grad_clipping(grads, c):
    norm = math.sqrt(sum((grad ** 2).sum() for grad in grads))
    if norm > c:
        ratio = c / norm
        for i in range(len(grads)):
            grads[i] *= ratio
```

## 5.4.2 Dropout

- [https://deepnotes.io/dropout](https://deepnotes.io/dropout)
- [https://stanford.edu/~shervine/teaching/cs-230/cheatsheet-deep-learning-tips-and-tricks](https://stanford.edu/~shervine/teaching/cs-230/cheatsheet-deep-learning-tips-and-tricks)

**Dropout**（英文意为“丢失”、“脱落”）是由 Srivastava 等人提出的一种正则化技术。在训练过程中，以一定的概率激活某些神经元（即输出激活值），而其他神经元处于非激活状态（即不输出激活值）。对于某一层神经元，Dropout 使用 0 到 1 之间的概率 `drop_p` 使某个神经元失活，即不产生输出，反之，该神经元以 `1 - drop_p` 的概率处于激活状态。如果该层有 100 个神经元，`drop_p = 0.2`，则从概率上讲，`100 * 0.2` 个将处于非激活状态，`100 * 0.8` 个将处于激活状态。`drop_p` 称为**丢弃率**，表示有多大概率神经元处于非激活状态。反之，`(1 - drop_p)` 称为**存活率**或**保留率**，表示有多大概率神经元处于激活状态。

**图 5-24 Dropout：每次前向和反向过程中随机使部分神经元失活**

如图 5-24 所示，左侧神经网络的所有神经元均被激活，右侧神经元使用 Dropout 进行激活。Dropout 通过使某些神经元失活来定义不同的神经网络函数。因为梯度下降训练过程的每次迭代都会随机使部分神经元失活，所以不同的迭代针对的是不同的函数。因此，神经网络不会过度依赖少数几个神经元，这相当于群体的决策不依赖少数人，而是每个人都有机会参与，从而防止因过度依赖少数人而产生的偏见。Dropout 类似于数据归一化的思想。如果数据未归一化，数值较大的某些特征将对学习算法产生过大影响，而其他特征影响甚微。Dropout 也类似于权重正则化的思想。权重正则化通过惩罚项使所有权重变小，防止少数权重过大。

以一定概率使某网络层 Dropout 会导致该网络层总输出期望变小。例如，该网络层原本的总输出期望为 `e`，Dropout 丢弃概率为 `drop_p`，则期望值将变为 `e * (1 - drop_p)`。为了避免影响后续层，使用 Dropout 的输出层中每个神经元的输出通常除以 `(1 - drop_p)`。即如果某神经元的激活函数输出值为 `a`，则修改为输出 `a / (1 - drop_p)`。

因为训练的每次迭代中，Dropout 随机丢弃不同的神经元，即每次迭代的神经网络函数不同。因此损失函数的含义不是很明确，不同迭代的损失是不同函数的损失，而不是同一函数的损失。最终训练得到的函数可以看作是这些不同迭代产生的不同函数的平均。通过多个不同函数模型的平均可以获得更好的模型，正如通过多数人的投票而不是少数人的投票可以获得更好的结果一样。这再次体现了基于统计学习的机器学习的基本思想。Dropout 通过多个函数的平均可以有效避免过拟合。

此外，Dropout 仅用于训练模型，训练后的模型函数应当是明确的。因此，最终训练得到的神经网络函数应当是由所有处于激活状态的神经元组成的函数。因此，在验证和测试模型时，不应再使用 Dropout。

Dropout 可以作用于任意隐藏网络层的输出。如果该网络层的输出为 `x`，Dropout 操作可表示为：

`x = D ⊙ x`

其中，`D` 是与 `x` 形状相同的数组，`D` 中每个元素的值为 1 或 0，表示对应神经元是否被激活。数组 `D` 是基于 Dropout 丢弃率或存活率计算的掩码数组。可使用以下代码执行 Dropout 操作：

```python
retain_p = 1 - drop_p
mask = (np.random.rand(*x.shape) < retain_p) / retain_p
x *= mask
```

其中，`drop_p`、`retain_p = 1 - drop_p` 分别为丢弃率和保留率，`mask` 为保持激活状态的掩码数组。

反向推导时，只需将损失函数关于 Dropout 输出的梯度 `dx_output` 乘以该掩码 `mask` 即可。

```python
dx = dx_output * self._mask
```

其中 `dx_output` 是反向传播进来的关于 `x` 的损失函数梯度。

Dropout 操作可以实现为一个独立的 Dropout 层，代码如下：

```python
from Layers import *

class Dropout(Layer):
    def __init__(self, drop_p):
        super().__init__()
        self.retain_p = 1 - drop_p

    def forward(self, x, training=True):
        retain_p = self.retain_p
        if training:
            self._mask = (np.random.rand(*x.shape) < retain_p) / retain_p
            out = x * self._mask
        else:
            out = x
        return out

    def backward(self, dx_output, training=True):
        dx = None
        if training:
            dx = dx_output * self._mask
        else:
            dx = dx_output
        return dx
```

其中 `x` 是 Dropout 层上一层的输出。对于输入 `X`，以下代码使用 `dropout.forward(X)` 计算 Dropout 的输入，反向推导时，使用 `dropout.backward(dx_output)` 从关于 `X` 的反向输入梯度获取 Dropout 后的反向梯度。
