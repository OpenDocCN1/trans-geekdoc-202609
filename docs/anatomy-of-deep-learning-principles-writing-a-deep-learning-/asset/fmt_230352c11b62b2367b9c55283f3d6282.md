
### 7.11.5 Attention mechanism

The content vector output by the encoder of the previous Seq2Seq model is usually the hidden state or output of the encoder at the last moment, which contains the encoding of the entire input sequence information. This content vector is passed to the decoder along the time dimension as the initial hidden state of the decoder. The processing at each moment of the decoder, that is to say, the decoder accepts the same content encoding of the input sequence of the encoder at each moment.

Using the hidden state or output at the last moment as the content vector may not be enough to contain the complete input sequence information, especially for long input sequences. From the effect of the previous Seq2Seq model, it can be seen that the longer the sequence, the worse the prediction effect. If all the hidden states at all times are concatenated into a content vector, it can contain enough complete input sequence information, but since the length of the input sequence changes, this content vector obviously cannot be directly used as the hidden state of the encoder, so it needs to be done. A transformation process turns it into a fixed-length vector. On the other hand, different parts of the input sequence have different effects on each moment of the decoder, and each moment of the decoder should have different degrees of attention to different parts of the input sequence. As shown in Figure 7-56, the input sequence is the sentence (word sequence) "knowledge is power", and the output target sequence is the sentence "knowledge is power". When the decoder is processing "knowledge", the word "knowledge" of the input sequence has a greater impact than the other two words "is" and "strength", and when dealing with "is", the "is" of the input sequence is more important. Therefore, when the decoder is making predictions, different words of the input sequence have different effects on different words of the output sequence.

Figure 7-56 Different parts of the input sequence have different predictive effects on the output sequence at different moments

**Attention (Attention) mechanism** means that the decoder dynamically selects the part of the input sequence that is most relevant to the current prediction at each moment. A weight vector can be calculated by comparing the input information of the decoder at the current moment (the hidden state at the previous moment and the data input at the current moment) with the output (or hidden state) of the encoder at all moments, and then use the weight vector weights the output content of the encoder at all moments to obtain a specific content context vector at the current moment, that is, the decoder has different encoder context vectors at different moments, and this context vector is used together with the hidden state and data input at that moment for computation at the current moment of the decoder.

The calculation of *i* at each moment of the cyclic neural network of the previous Seq2Seq decoder can be expressed as:

```
h[i] = RNN(h[i-1], x[i])
```

The calculation of *i* at each moment of the Seq2Seq decoder using the attention mechanism can be expressed as:

```
h[i] = RNN(h[i-1], x[i], c[i])
```

That is, at each moment, there is an additional content vector `c[i]` specific to that moment. This `c[i]` not only depends on `h[i-1], x[i]`, but also depends on the output (or hidden state) of the encoder at all moments. If the output of the encoder at all times is the hidden state `\overline{h}_t`, that is, `c[i]` depends on all `\overline{h}_t, t = 1,2,\cdots,T`, T is the last of the encoder time. At each moment *i*, the decoder is based on the output of the encoder `\overline{h} = {h_1,h_2,\cdots,h_T}` and the information at the moment of the decoder *i* (such as the input hidden state `h[i-1]`) First calculate a weight vector `\alpha[i] = (\alpha[i1], \alpha[i2], \cdots, \alpha[iT])`, use this weight vector `\alpha` to the output of the encoder `\overline{h}` is weighted and summed to get the content vector `c[i]` at the current moment, namely:

$c_i = \alpha_i \cdot \overline{h} = \alpha_{i1}\overline{h}_1 + \alpha_{i2}\overline{h}_2 + \cdots + \alpha_{iT}\overline{h}_T$

And $\quad\sum\limits_{j = 1}^{T}\alpha_{ij} = 1,\alpha_{ij} > 0$

That is, the input context vector `c[i]` of the decoder moment *i* is the weighted average of the output (or hidden state) `\overline{h}_j` of the encoder at all moments. And `\alpha[ij]` represents the weight of the *j*th output (or hidden state) `\overline{h}_j` of the encoder in the input context vector `c[i]`.

And these `\alpha[ij]` are calculated by the same set of so-called scores (also called **energy**) values `e[ij]`:

$\alpha_{ij} = \frac{exp^{e_{ij}}}{\sum\limits_{k = 1}^{T}exp^{e_{ik}}}$

Each `e[ij]` can be the input hidden state `h[i-1]` of the decoder time *i* and the `\overline{h}_j` of the encoder time *j* is calculated by a function a, namely:

$e_{ij} = a(h_{i - 1},\overline{h}_j)$

Of course, `e[ij]` can also rely on the data at the current moment to input `x[i]`. According to different functions a, the score has different calculation methods, as shown in Figure 7-57, `h[i-1]` and `\overline{h}_j` uses a neural network layer with only one neuron and an activation function of tanh as the calculation function of the score, namely:

$a(\mathbf{h}_{i - 1};\overline{\mathbf{h}}_j) = \tanh([\mathbf{h}_{i - 1};\overline{\mathbf{h}}_j]\mathbf{W}_a)$

![](EPUB/media/file172.png "fig:")
Figure 7-57 The score calculation function is a neural network layer with only one neuron and the activation function is tanh

Among them, the parameter **W[a]** is also a parameter that needs to be learned. The table below shows some common scoring methods:

| Name | Alignment score function | Citation |
| --- | --- | --- |
| Content-based attention | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \text{cosine}[\mathbf{h}_t, \boldsymbol{\overline{h}}_t]$ | [Graves2014](https://arxiv.org/abs/1410.5401) |
| Additive(*) | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{v}_a^{\top}\tanh(\mathbf{W}_a[\mathbf{h}_t;\overline{\mathbf{h}}_s])$ | [Bahdanau2015](https://arxiv.org/pdf/1409.0473.pdf) |
| Location-Base | `\alpha[t, i] = softmax(W[a]h[t])` | [Luong2015](https://arxiv.org/pdf/1508.04025.pdf) |
| General | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{h}_t^{\top}\mathbf{W}_a\overline{\mathbf{h}}_s$ | [Luong2015](https://arxiv.org/pdf/1508.04025.pdf) |
| Dot-Product | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{h}_t^{\top}\overline{\mathbf{h}}_t$ | [Luong2015](https://arxiv.org/pdf/1508.4025.pdf) |
| Scaled Dot-Product | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \frac{\mathbf{h}_t^{\top}\boldsymbol{\overline{h}}_s}{\sqrt{n}}$ | [Vaswani2017](http://papers.nips.cc/paper/7181-attention-is-all-you-need.pdf) |

Where `\overline{h}_s, h_t` represent the hidden state of the input sequence *s* and the output sequence *t* respectively, and `v[a], W[a]` are learnable weight parameter matrices. Note that although the hidden state `h[t]` of the decoder uses a unified symbol, the meanings in different papers are slightly different, some are `h[t]` at the current moment *t*, and some are actually `t-1` at the previous moment hidden state `h[t-1]`. For example, `h[t-1]` at the previous moment represented in the **Bahdanau attention** paper, and **Luong attention** is `h[t]` at the current moment.
