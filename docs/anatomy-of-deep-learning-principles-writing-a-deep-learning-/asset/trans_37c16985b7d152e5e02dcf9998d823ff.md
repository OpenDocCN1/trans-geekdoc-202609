```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

np.random.seed(100)

def gen_spiral_dataset(N=100, D=2, K=3):
    N = 100  # 每个类别的点数
    D = 2  # 维度
    K = 3  # 类别数
    X = np.zeros((N*K, D))  # 数据矩阵（每行 = 单个样本）
    y = np.zeros(N*K, dtype='uint8')  # 类别标签
    for j in range(K):
        ix = range(N*j, N*(j+1))
        r = np.linspace(0.0, 1, N)  # 半径
        t = np.linspace(j*4, (j+1)*4, N) + np.random.randn(N)*0.2  # 角度
        X[ix] = np.c_[r*np.sin(t), r*np.cos(t)]
        y[ix] = j
    return X, y

N = 100  # 每个类别的点数
D = 2  # 维度
K = 3  # 类别数

X_spiral, y_spiral = gen_spiral_dataset()
# 让我们可视化一下数据：
plt.scatter(X_spiral[:, 0], X_spiral[:, 1], c=y_spiral, s=20, cmap=plt.cm.spring)  # s=40, cmap=plt.cm.Spectral)
plt.show()
```

### 3.6.2 softmax 函数

`softmax` 函数是一个多元向量值函数，它接受多个（例如 3 个）输入值并产生相同数量（例如 3 个）的输出值。对于 3 个自变量（`z[1]`、`z[2]`、`z[3]`）的 `softmax(z[1], z[2], z[3])`，函数值是一个具有相同数量自变量的向量：

$$
\begin{matrix} 
{softmax(z_{1},z_{2},z_{3})} & {= (\frac{e^{z_{1}}}{(e^{z_{1}} + e^{z_{2}} + e^{z_{3}})}, \frac{e^{z_{2}}}{(e^{z_{1}} + e^{z_{2}} + e^{z_{3}})}, \frac{e^{z_{3}}}{(e^{z_{1}} + e^{z_{2}} + e^{z_{3}})})} \\ 
& {= (\frac{e^{z_{1}}}{\sum\limits_{1}^{3}e^{z_{i}}}, \frac{e^{z_{2}}}{\sum\limits_{1}^{3}e^{z_{i}}}, \frac{e^{z_{3}}}{\sum\limits_{1}^{3}e^{z_{i}}})} 
\end{matrix}
$$

显然，`softmax()` 函数输出向量的每个分量值都位于 `[0, 1]` 区间内，且所有分量值之和为 1，因此每个分量都可以被视为一个概率值。

下面的 `softmax()` 函数是计算 softmax 函数的代码：

```python
import numpy as np

def softmax(x):
    e_x = np.exp(x)
    return e_x / e_x.sum()
```

输入一个 3 维向量 `z`，`softmax` 函数输出一个 3 维向量，其每个分量代表一个概率，即这些分量的值在 `[0, 1]` 之间，且它们的和等于 1。

```python
z = [3.0, 1.0, 0.2]
softmax(z)
```

```
array([0.8360188, 0.11314284, 0.05083836])
```

注意：`softmax()` 作用于 `z = [3.0, 1.0, 0.2]`，得到的值 $softmax(z) = [\frac{e^{3.0}}{e^{3.0} + e^{1.0} + e^{0.2}}, \frac{e^{1.0}}{e^{3.0} + e^{1.0} + e^{0.2}}, \frac{e^{0.2}}{e^{3.0} + e^{1.0} + e^{0.2}}]$ 与 `z` 的值不是线性关系。

对于较大值的 `x`，`e^x` 将超出计算机可表示的数值范围，导致 `softmax()` 的值溢出，例如：

由于分数的分子分母同时除以一个数，分数值保持不变，即：

$$
\frac{e^{z_{j}}}{\sum\limits_{i}e^{z_{i}}} = \frac{e^{z_{j}}/e^{a}}{\sum\limits_{i}{e^{z_{i}}/e^{a}}} = \frac{e^{z_{j} - a}}{\sum\limits_{i}e^{z_{i} - a}}
$$

因此，可以先找出所有 `z[i]` 的最大值 `a`，然后用 `z[i] - a` 来计算 `softmax()` 函数的值。

```python
def softmax(x):   
    e_x = np.exp(x - np.max(x))
    return e_x / e_x.sum()

print(softmax(z))
z = [500, 1000]
softmax(z)
```

```
[0.1.]

array([7.12457641e-218, 1.00000000e+000])
```

上述代码适用于输入向量，如 `z = (z[1], z[2], z[3])`，它能用于由许多输入向量组成的矩阵（二维数组）吗？比如：

```python
z = np.array([[1, 2, 3], [6, 2, 4]])
softmax(z)
```

```
array([[0.00548473, 0.01490905, 0.04052699],
       [0.8140064 , 0.01490905, 0.11016379]])
```

对于输入向量 `[1, 2, 3]`，输出向量值为 `[0.00548473, 0.01490905, 0.04052699]`，这不满足概率的归一化条件，即 `0.00548473 + 0.01490905 + 0.04052699 != 1`。这是因为上述 `softmax()` 函数中的 `e_x.sum()` 对数组的所有元素求和。正确的做法是分别为每个样本计算其属于各个类别的概率，即为每个样本计算其 softmax 输出，求和应针对该样本的各个分量进行。此外，`max()` 函数只需计算该样本所有分量的最大值，而不需要整个数组的最大值（虽然也没有问题）。

为了同时为多个样本计算各自的 `softmax()` 函数值，应分别为每个样本计算 softmax 值向量。为此，将上述代码重写为：

```python
def softmax(x):   
    a = np.max(x, axis=-1, keepdims=True)  
    e_x = np.exp(x - a)
    return e_x / np.sum(e_x, axis=-1, keepdims=True)

softmax(z)
```

```
array([[0.09003057, 0.24472847, 0.66524096],
       [0.86681333, 0.01587624, 0.11731043]])
```

上述 numpy 函数 `np.max()` 和 `np.sum()` 的参数 `axis=1` 表示沿轴（列）执行相应的最大值（`max`）和求和（`sum`）操作。`keepdims=True` 表示不改变结果数组的维度，即结果数组与原数组具有相同的维度。

上述代码首先找出每个行向量的最大值，从每个行向量中减去其最大值并计算其指数值，最后按行计算 softmax 函数的值，每一行输入产生一个对应的输出向量来表示概率。上述代码可以进一步简化：

```python
def softmax(x):
    e_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e_x / np.sum(e_x, axis=-1, keepdims=True)

softmax(z)
```


一般来说，假设 `z = (z[1], z[2], ..., z[k], ..., z[C])`，用 `f(z)` 表示 `softmax(z)` 函数，则：

$$f_{i} = \frac{e^{z_{i}}}{\sum\limits_{k = 1}^{C}e^{z_{k}}}$$

其中，$\sum\limits_{i = 1}^{C}f_{i} = 1$。

为了防止计算溢出，可以让每个分量减去它们的最大值，即：

$$f_i = \frac{e^{z_i - max(z)}}{\sum_{k=1}^C e^{z_k - max(z)}}$$

为了求 `f(z) = softmax(z)` 关于 `z` 的梯度，引入中间变量 `a[i] = e^(z[i])`，$b = \sum\limits_{k = 1}^{C}e^{z_{k}}$，则：

$$f_{i} = \frac{a_{i}}{b}$$

将 `a[i]` 视为 `z[k]` 的函数，则有：

$$\frac{\partial a_{i}}{\partial z_{i}} = \frac{\partial e^{z_{i}}}{\partial z_{i}} = e^{z_{i}}$$  

$$\frac{\partial a_{i}}{\partial z_{j}} = \frac{\partial e^{z_{i}}}{\partial z_{j}} = 0$$

`b` 也是 `z[k]` 的函数。同样地，有：

$$\frac{\partial b}{\partial z_{i}} = \frac{\partial(\sum\limits_{k = 1}^{C}e^{z_{k}})}{\partial z_{i}} = e^{z_{i}}$$

根据除法求导法则，有：

$$\frac{\partial f_{i}}{\partial z_{i}} = \frac{\frac{\partial a_{i}}{\partial z_{i}} \cdot b - a_{i}\frac{\partial b}{\partial z_{i}}}{b^{2}} = \frac{a_{i}b - a_{i}a_{i}}{b^{2}} = \frac{a_{i}}{b}(1 - \frac{a_{i}}{b}) = f_{i}(1 - f_{i}) = f_{i} - f_{i}f_{i}$$
