
# 偏差-方差权衡

如果对于某个问题，自变量（特征）$x$ 和因变量（目标值）$y$ 之间存在函数关系 $f(x)$，但该函数未知，仅有一组实际数据样本 $\{x_i, y_i\}$。由于采样过程中的噪声，每个实际样本的 $x, y$ 并不严格满足该函数关系 $f(x)$，即实际目标值 $y$ 与 $f(x)$ 之间存在随机误差 $\epsilon$。通常认为该随机误差 $\epsilon$ 服从高斯分布 $\mathcal{N}(\mu, \sigma^2)$，即 $\epsilon = y - f(x) \sim \mathcal{N}(0, \sigma^2)$。因此，$y$ 与 $f(x)$ 的关系可表示为：

$$y = f(x) + \epsilon$$

即采样目标值 $y$ 与真实目标值 $f(x)$ 之间存在误差 $\epsilon$。

机器学习希望利用假设函数（如 $\hat{f}(x)$）来逼近真实的 $f(x)$。该假设通常通过最小化实际目标值 $y_i$ 与假设函数 $\hat{f}(x)$ 的预测目标值 $\hat{f}(x_i)$ 之间的误差 $(y_i - \hat{f}(x_i))^2$ 来求解。

对于假设函数模型 $\hat{f}(x_i)$，不同训练集和不同机器学习算法得到的具体函数 $\hat{f}(x_i)$ 皆不相同。

对于某一确定的 $x$，不同 $\hat{f}(x_i)$ 产生的误差 $(y_i - \hat{f}(x_i))^2$ 也不同。所有可能的 $\hat{f}(x_i)$ 该误差的平均值（期望）称为**期望误差**或**误差期望**，即 $E[(y - \hat{f}(x))^2]$。该期望误差可分解为以下三项：

$$E[(y - \hat{f}(x))^2] = (\text{Bias}[\hat{f}(x)])^2 + \text{Var}[\hat{f}(x)] + \sigma^2$$

其中：
*   $\text{Bias}[\hat{f}(x)] = E[\hat{f}(x)] - E[f(x)]$ 称为**偏差**，表示假设函数模型 $\hat{f}(x)$ 的预测值期望与真实值之间的偏离程度。
*   $\text{Var}[\hat{f}(x)] = E[\hat{f}(x)^2] - E[\hat{f}(x)]^2 = E(\hat{f}(x) - E[\hat{f}(x)])^2$ 称为**方差**，表示假设函数模型 $\hat{f}(x)$ 得到的不同预测值与其期望预测值的均方误差。

公式推导请参考 Wikipedia：
<https://en.wikipedia.org/wiki/Bias%E2%80%93variance_tradeoff>

## 示例：常数模型与线性模型的对比

假设待学习函数为 $f(x) = x + 2 \times \text{np.sin}(1.5 \times x)$，以下代码绘制函数曲线及从该函数采样的一组 $\{x_i, y_i\}$：

```python
import numpy as np
import math
import matplotlib.pyplot as plt
%matplotlib inline

np.random.seed(0)

f = lambda x: x + 2 * np.sin(1.5 * x)

def plot_f(pts=50):
    x = np.linspace(0, 10, pts)
    f_ = f(x)
    plt.plot(x, f_)

def sample_f(pts=8):
    x = np.random.uniform(0, 10, pts)
    f_val = x + 2 * np.sin(1.5 * x)
    y = f_val + np.random.normal(0, 0.5, pts)  # random noise
    return x, y

plot_f()
x, y = sample_f()
plt.scatter(x, y, s=30)  # , facecolors='none', edgecolors='r')
```

### 常数假设函数 $\hat{f}(x) = b$

若使用常数函数 $\hat{f}(x) = b$ 作为假设函数模型逼近 $f(x)$，对训练集中每个 $\{x_i, y_i\}, i=1,2,\dots,m$，$\hat{f}(x)=b$ 的预测值均为 $b$。最小化 $\sum_{i=1}^{m}{(b - y_i)}^2$，可得：

$$b = \frac{\sum_{i=1}^{m}y_i}{m} = \text{np.mean}(y_i)$$

不同训练集的样本不同，因此利用不同训练集得到的 $b$（即假设函数 $\hat{f}(x)=b$）也不同。所有不同训练集在某一点 $x$ 处得到的假设函数预测期望值与真实值之差为偏差，所有不同假设函数在该点预测值与预测期望值的均方误差为方差。

以下代码使用 50 个训练集训练得到 50 个假设函数，并计算这些假设函数在 $x=5$ 处的预测偏差与预测方差（注：代码中 `x = 18` 似为笔误，文中所述为 $x=5$，但输出结果对应 $x=18$ 处的计算）：

```python
train_set_num = 100

def plot_b(b):
    x = np.linspace(0, 10, pts)
    hat_f = [b for i in range(pts)]
    plt.plot(x, hat_f)

bs = []
for i in range(train_set_num):
    x, y = sample_f(20)
    plt.scatter(x, y)
    b = np.mean(y)
    bs.append(b)
    plot_b(b)

plot_f()
plt.show()

x = 18
f_true = f(x)
f_predict_mean = np.mean(bs)
print("real function value:", f_true)
print("Predicted expected value:", f_predict_mean)
print("Predicted deviation:", f_predict_mean - f_true)
print("Predicted variance:", np.std(bs))
```

### 线性假设函数 $\hat{f}(x) = wx + b$

若使用线性函数 $\hat{f}(x) = wx + b$ 作为假设函数，遵循相同流程，可得到相应的偏差与方差估计：

```python
ws = []
for i in range(train_set_num):
    x, y = sample_f(20)
    plt.scatter(x, y)
    X = np.hstack((np.ones((len(x), 1), dtype=x.dtype), x[:, None]))
```

## 结论

假设函数模型 $\hat{f}(x) = b$ 的偏差与方差分别为：`-14.564125266958722` 和 `0.7240080347500965`；假设函数模型 $\hat{f}(x) = wx + b$ 的偏差与方差分别为：`-11.944324952176219` 和 `10.868072850656494`。

简单模型往往不够复杂，无法完全逼近真实函数 $f(x)$，容易欠拟合，其偏差大于复杂模型。虽然复杂模型偏差较小，但因函数变化复杂，其预测值的变化也往往剧烈或发散，即方差较大。
