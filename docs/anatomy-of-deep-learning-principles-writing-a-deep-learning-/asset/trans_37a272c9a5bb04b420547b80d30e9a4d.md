```python
    xmin, xmax = np.min(x), np.max(x)
```

### 8.5.2 二维坐标点的 GAN 建模

一组实数中的每个样本都是一个实数，即只有一个特征。在本节中，使用二维平面上一组二维坐标点的样本作为真实数据，让生成器学习这些二维坐标点的概率分布。建模和训练过程与一维实数的 GAN 建模和训练相同。

#### 1. 真实数据：椭圆曲线上采样的坐标点

椭圆曲线上数据点的 x、y 坐标可以用参数方程表示为：

$$
\begin{matrix} 
x = cx + a\sin(\alpha) \\ 
y = cy + b\cos(\alpha) 
\end{matrix}
$$

其中（`cx`、`cy`）是椭圆的中心点，（`a`、`b`）是椭圆的长轴和短轴长度，`α` 是由椭圆中心点和点（`x`、`y`）组成的有向线段与 `x` 轴的夹角。以下函数 `sample_ellipse()` 可以在椭圆曲线上均匀采样一组坐标点：

```python
import numpy as np
import math

def sample_ellipse(m, a, b, cx=0, cy=0):
    alpha = np.random.uniform(0, 2*math.pi, m)
    x, y = cx + a*np.cos(alpha), cy + b*np.sin(alpha)
    x = x.reshape(m, 1)
    y = y.reshape(m, 1)
    return np.hstack((x, y))
```

根据上述椭圆采样函数，以下代码在椭圆中心（4,4）处采样长轴和短轴长度分别为 5 和 3 的 100 个坐标点，然后绘制这些坐标点：

```python
from matplotlib import pyplot as plt
%matplotlib inline

data = sample_ellipse(100, 5, 3, 4, 4)
plt.scatter(data[:, 0], data[:, 1])
plt.show()
```

#### 2. 真实数据迭代器、噪声迭代器

可以使用 `sample_ellipse()` 函数定义一个数据迭代器，从椭圆中采样一组坐标点：

```python
cx, cy, a, b = 5, 3, 4, 4

def data_iterator_ellipse(batch_size):
    while True:
        yield sample_ellipse(batch_size, cx, cy, a, b) #generate_real_samples(batch_size)

data_it = data_iterator_ellipse(batch_size)
x = next(data_it)
```
