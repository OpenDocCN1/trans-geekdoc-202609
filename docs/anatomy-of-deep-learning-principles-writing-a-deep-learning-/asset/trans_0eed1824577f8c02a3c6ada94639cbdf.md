

这个命题很容易证明。如果 `x[0]` 是函数 `f(x)` 的极值点，则存在一个区间 `(x[0] - ϵ, x[0] + ϵ)` 满足 `f(x[0]) ≤ f(x)`，所以 `f(x) - f(x[0]) ≥ 0`，而：

```
f'(x_0) = lim_{Δx → 0} Δy/Δx = lim_{Δx → 0} (f(x_0 + Δx) - f(x_0))/Δx = lim_{Δx → x_0} (f(x) - f(x_0))/(x - x_0)
```

当 x 从左、右两侧趋向于 `x[0]` 时，`Δx` 分别是负数和正数，而分子始终为正。从右侧 x 趋向于 `x[0]`，其极限值应 `≥ 0`。从左侧 x 趋向于 `x[0]`，其极限值应 `≤ 0`，且该极限存在，所以其值只能是 0。

根据极限公式，也可以找到一条规律。如果 `x[0]` 处的导数是正数，说明函数 `f(x)` 在该点附近单调递增，即如果 `x[1] < x[2]`，则 `f(x[1]) < f(x[2])`，即 `f(x)` 随 x 的增大而增大。或者如果 `Δx` 是正数，则 `Δy` 也是正数。例如，`y = f(x) = x²` 的导数是 `f'(x) = 2x`。当 x 大于 0 时，导数为正。因此，函数曲线单调递增；当 x 小于 0 时，导数均为负数，因此，函数曲线单调递减，即如果 `x[1] < x[2]`，反而 `f(x[1]) > f(x[2])`。

例如，函数 `f(x) = x³ - 3x² - 9x + 2`，令其导数 `f'(x) = 0`：

```
f'(x) = 0  ⇒  (x³ - 3x² - 9x + 2)' = 0  ⇒  3x² - 6x - 9 = 0  ⇒  x² - 2x - 3 = 0  ⇒  x[1] = -1, x[2] = 3
```

可以得到两个导数为 0 的点 `x[1] = -1`，`x[2] = 3`。该函数及其导函数 `f'(x)` 的单调变化如图 2-1 所示：

**图 2-1** `f'(x) > 0`，函数单调递增，`f'(x) < 0`，函数单调递减

在区间 `(-∞, -1]` 中，`f'(x)` 为正数，所以函数 `f(x)` 单调递增；在区间 `(-1, 3)` 中，`f'(x)` 为负数，所以函数 `f(x)` 单调递减；在区间 `[3, ∞)` 中，`f'(x)` 为正数，所以函数 `f(x)` 单调递增。

注意，上述命题只说明了函数极值点的必要条件，而非充分条件，也就是说，函数 `x[0]` 处的导数 `f'(x[0]) = 0` 并不意味着 `x[0]` 一定是极值点。例如，`f(x) = x³` 在 `x = 0` 处的导数 `f'(0)` 也是 0，但这一点不是函数的极值点。实际上，这是一条单调递增的曲线，如图 2-3 所示。

显然，函数极值的必要条件可以推广到多元函数，即对于多元函数 `f(x[1], x[2], ⋯, x[n])`，如果函数在某点 `x* = (x[1]*, x[2]*, ⋯, x[n]*)` 取得极值，且该点梯度存在（即所有偏导数存在），则该点的梯度必为 0（即各偏导数值均为 0）。即：

```
∂f(x_1, x_2, ⋯, x_n)/∂x_i |_{x*} = 0,  i = 1, 2, ⋯, n
```

## 2.2 梯度下降法

对于一元函数 `f(x)`，如果在某点 `x` 附近有一个微小变化 `Δx`，则 `f(x)` 的变化 `f(x + Δx) - f(x)` 可以用微分形式表示为：

`f(x + Δx) - f(x) ≃ f'(x)Δx`

即在 `x` 附近，如果 `Δx` 和 `f'(x)` 同号，则 `f'(x)Δx` 即 `f(x + Δx) - f(x)` 为正数。如果 `Δx` 和 `f'(x)` 异号，则 `f'(x)Δx` 即 `f(x + Δx) - f(x)` 为负数。如果 `Δx = -αf'(x)`（其中 `α` 为一个较小的正数），则 `f(x + Δx) - f(x) = -αf'(x)²` 为负数，即 `f(x + Δx)` 的值会比 `f(x)` 小。换句话说，`x` 沿着 `f'(x)` 的反方向 `-f'(x)` 移动 `Δx`，其函数值 `f(x + Δx)` 比原来的 `f(x)` 小。

如图 2.4 所示，函数 `f(x) = x² + 0.2` 在 `x = 1.5` 处的函数值 `f(x)` 为 2.45，导数值 `f'(x)` 为 3.0，为正数，指向 `f(x)` 定义域上 `x` 轴的正方向，即 x 轴，如图中长箭头所示。

![](EPUB/media/file24.png "fig:")

**图 2-4** `f'(1.5) = 3.0 > 0`，`Δx` 与 `f'(x)` 同号移动，函数值增大，反之函数值减小

令 `α = 0.15`，`Δx = -αf'(x) = -0.45`，沿着这个 `Δx` 移动 `x`（图中蓝色箭头方向）到 `x_new = x + Δx = 1.05`，得到新 `x = 1.05` 处的 `f(1.05)` 函数值为 1.3025，即图中曲线上蓝色点的 y 坐标值。因为 `Δx` 与 `f'(x)` 方向相反（一正一负），所以这个 `f(1.05)` 必定比原来的 `f(1.5)` 小。

就这样不断重复这个过程，即 `x` 沿着其导数 `f'(x)` 的反方向（`-f'(x)`）移动微小增量 `-αf'(x)`，就能到达新的 `x_new = x - αf'(x)`，这个新 `x_new` 的函数值 `f(x_new)` 必定比之前的函数值 `f(x)` 小。随着 `x` 接近最小值点的 `x` 值，导数 `f'(x)` 也接近 0（因为函数极值点 `x*` 的导数 `f(x*) = 0`），`x` 移动的增量 `Δx` 也越来越接近 0。

这就是**梯度下降法**的思想，即从一个初始 `x` 开始，用下面的公式不断更新 `x` 的值：

`x = x - αf'(x)`

对于当前的 `x`，沿着其负导数（梯度）方向（即 `-f'(x)`）移动 `x`，可以使 `f(x)` 不断变小。理想情况下，到达使 `f(x)` 最小的 `x`，此时 `f'(x) = 0`。再迭代更新 `x`，`x` 的值也不再变化。如图 2-5 所示，`x` 不断迭代更新，使其不断逼近极值点。
