```python
def getAccuracy(w, X, y):
    X = np.hstack((np.ones((X.shape[0], 1), dtype=X.dtype), X))
```

### 3.7.2 使用部分训练样本训练逻辑回归

训练集中的样本数量达到 50,000 个。使用整个训练集的样本进行训练，每次计算需要大量的资源和时间。为了提高训练效率，可以取出部分数据，例如使用 `batch=500` 个样本进行训练：

```python
batch = 500

alpha = 1e-2
iterations = 1000
reg = 1e-3

w_history = []

w = np.zeros([train_X.shape[1] + 1, len(np.unique(train_y))])
for i in range(5):
    s = i * batch
    X = train_X[s:s + batch, :]
    y = train_y[s:s + batch]
    w_history_batch = gradient_descent_softmax(w, X, y, reg, alpha, iterations)
    w = w_history_batch[-1]
    w_history.extend(w_history_batch)

print("w: ", w)
loss_history = compute_loss_history(w_history, X, y, reg)
print(loss_history[:-1:len(loss_history)//10])
```

分别计算模型函数在训练集、验证集和测试集上的准确率：

```python
print("Accuracy on the training set:", getAccuracy(w, train_X, train_y))

print("Accuracy on test set:", getAccuracy(w, test_X, test_y))
```

### 3.7.3 批量梯度下降法及其实现

如果训练集很大，使用整个训练集进行训练时，计算量会变得非常大。实际上，只要使用少量甚至一个样本，就可以计算损失函数的梯度并更新模型参数。因此，在实际问题中，通常从训练集中随机选取少量样本，利用这批样本对模型参数进行梯度更新。每次梯度更新可以使用不同的一批样本。这种梯度下降方法称为**批量梯度下降**（**mini batch gradient descent**）。为了保证训练集中的所有样本都能用于训练。
