
# 矩阵乘法与广播机制

## 矩阵乘法

如果矩阵 *A*[*m*×*n*] 的列数与矩阵 *B*[*n*×*l*] 的行数相同，则这两个矩阵可以相乘。它们的乘积 *A*[*m*×*n*]*B*[*n*×*l*] 将得到一个 *m*×*l* 大小的矩阵 *C*，其下标为 *i*, *j* 的元素 *c*[*i*, *j*] 是矩阵 *A* 的第 *i* 行向量与矩阵 *B* 的第 *j* 列向量的点积。即：

$$c_{ij} = \sum_{k=1}^{n}(a_{ik}b_{kj})$$

如图 1-16 所示：

![](EPUB/media/file219.png)

**图 1-16** 乘积矩阵中第 2 行第 1 列的元素是第一个矩阵第 2 行向量与第二个矩阵第 1 列向量的点积

两个向量的点积可以用矩阵乘法表示。设 *x* 和 *y* 为两个列向量，则：

*x* ⋅ *y* = *x*^(*T*)*y* = *y*^(*T*)*x*

若用 *A*[*i*, :] 表示矩阵 *A* 第 *i* 行的行向量，用 *B*[:, *j*] 表示矩阵 *B* 第 *j* 列的列向量，则 *c*[*i*, *j*] = *A*[*i*, :]*B*[:, *j*]。

向量是特殊的矩阵，因此矩阵与向量的乘积也属于矩阵乘法。例如，若 *A*[*m*×*n*] 乘以列向量 *x*[*n*×1]：

$$
A x = \begin{bmatrix} a_{1,:} \\ a_{2,:} \\ \vdots \\ a_{m,:} \end{bmatrix}x = \begin{bmatrix} a_{1,:}x \\ a_{2,:}x \\ \vdots \\ a_{m,:}x \end{bmatrix} = \begin{bmatrix} a_{11}x_{1} + a_{12}x_{2} + \cdots + a_{1n}x_{n} \\ a_{21}x_{1} + a_{22}x_{2} + \cdots + a_{2n}x_{n} \\ \vdots \\ a_{m1}x_{1} + a_{m2}x_{2} + \cdots + a_{mn}x_{n} \end{bmatrix}
$$

*A**x* 是一个列向量，其每个元素都是 *A* 的一行与 *x* 相乘（点积）的结果。

可以证明：

- 矩阵乘法满足结合律：(*A**B*)*C* = *A*(*B**C*)
- 矩阵乘法与加法满足分配律：*A*(*B* + *C*) = *A**B* + *A**C*

可以使用 NumPy 的 `dot()` 函数或 `ndarray` 的 `dot()` 方法来计算向量的点积和矩阵的乘积。NumPy 的 `dot()` 函数接受两个多维数组并执行多维数组的点积（乘法）运算。

```
numpy.dot(a, b, out=None)
```

如果指定了输出参数 `out`，则结果将输出到 `out` 中。

以下代码对比了逐元素乘法 `*` 与点积（乘法）的区别：

```
a = np.array([1, 3])
b = np.array([2, 5])
print("a*b:", a*b)
print("dot(a,b):", np.dot(a,b))         # 两个向量的点积是一个值（标量）
```

```
a*b: [ 2 15]
dot(a,b): 17
```

可以看出，两个向量的逐元素乘法结果仍是一个向量，而两个向量的点积是一个值（标量）。

矩阵与向量的乘法需要注意对应轴的元素数量是否一致，例如：

```
a = np.array([[1,2,3],[4,5,6]])
b = np.array([2,5])
c = np.array([2,5,3])
print("a.shape:", a.shape)
print("b.shape:", b.shape)
print("c.shape:", c.shape)
# print("dot(a,b):", np.dot(a,b))
print("dot(b,a):", np.dot(b,a))
print("dot(a,c):", np.dot(a,c))
```

```
a.shape: (2, 3)
b.shape: (2,)
c.shape: (3,)
dot(b,a): [22 29 36]
dot(a,c): [21 51]
```

`a` 是一个 (2, 3) 矩阵，`b` 是一个一维张量 (2,)。因为一维张量的乘积可以视为行向量或列向量，所以 `np.dot(b,a)` 等价于 (1,2) 矩阵与 (2,3) 矩阵的乘法。而 `np.dot(a,b)` 无法执行，因为无法进行 (2,3) 矩阵与 (1,2) 或 (2,1) 矩阵的乘法。但 `np.dot(a,c)` 可以执行，因为 `c` 的形状是 (3,)，`np.dot(a,c)` 等价于 (2,3) 矩阵与 (3,1) 矩阵的乘法。

对于一维向量和二维矩阵，`matmul()` 函数和运算符 `@` 也执行矩阵乘法，效果与 `np.dot()` 相同。

```
a = np.array([1, 3])
b = np.array([2, 5])
print("dot(a,b):", np.dot(a,b))
print("matmul(a,b):", np.matmul(a,b))
print("a@b:", a@b)

a = np.array([[1,2,3],[4,5,6]])
b = np.array([[2,5],[1,3],[4,5]])
print("a.shape:", a.shape)          # 2*3 矩阵
print("b.shape:", b.shape)          # 3*2 矩阵
print("dot(a,b):", np.dot(a,b))
print("matmul(a,b):", np.matmul(a,b))
print("a@b:", a@b)
```

```
dot(a,b): 17
matmul(a,b): 17
a@b: 17
a.shape: (2, 3)
b.shape: (3, 2)
dot(a,b): [[16 26]
 [37 65]]
matmul(a,b): [[16 26]
 [37 65]]
a@b: [[16 26]
 [37 65]]
```

## 4 广播机制

广播是一种强大的机制，它使 NumPy 能够对形状不同的数组执行算术运算。例如，我们可以用一个数字和一个数组进行运算。这相当于将这个数字变成一个与该数组大小相同的数组，然后进行逐元素运算。例如，下面的 `a+3` 等价于 `a + np.array([[3,3],[3,3]])`。如图 1-17 所示：

![](EPUB/media/file220.png)

**图 1-17** `a+3` 等价于 `a + np.array([[3,3],[3,3]])`

```
a = np.array([[1,2],[3,4]])
print(a)

print(a+3)
print(a + np.array([[3,3],[3,3]]))
```

```
[[1 2]
 [3 4]]
[[4 5]
 [6 7]]
[[4 5]
 [6 7]]
```

同样，数字与张量的减法、乘法、除法等也执行这种广播计算。

```
print(a*3)
print(a/3)
```

```
[[ 3  6]
 [ 9 12]]
[[0.33333333 0.66666667]
 [1.         1.33333333]]
```

同样，二维数组 `a` 也可以与以下一维数组 `b` 进行运算：

```
b = np.array([1,2])
print(a+b)
```

```
[[2 4]
 [4 6]]
```

在 `a+b` 中，因为 `b` 的轴 `axis=0` 只有 1 个元素（1 行），而 `a` 的轴 `axis=0` 有 2 个元素（2 行），`a+b` 等价于沿 `axis=0` 重复堆叠 `b` 成与 `a` 同样大小的数组，然后进行运算。如图 1-18 所示。

![](EPUB/media/file221.png)

**图 1-18** `a+b` 等价于沿 `axis=0` 重复堆叠 `b` 成与 `a` 同样大小的数组，然后相加

NumPy 的广播实际上并不执行上述的重复堆叠和重新计算过程，而是直接按照这一概念的计算过程进行广播计算。这节省了内存并提高了效率。

```
a = np.array([[1],[2],[3]])   # a 是形状为 (3,1) 的二维数组
b = np.array([4,5])           # b 是形状为 (2,) 的一维数组
print(a)
print(b)
print(a+b)
```

```
[[1]
 [2]
 [3]]
[4 5]
[[5 6]
 [6 7]
 [7 8]]
```

`a` 是形状为 `(3,1)` 的二维数组，`b` 是形状为 `(2,)` 的一维数组。一维数组可以视为形状为 `(2,1)` 的张量，也可以视为形状为 `(1,2)` 的张量。`a+b` 需要匹配 `a` 和 `b` 的形状，`(2,1)` 和 `(3,1)` 的第一个轴 (`axis=0`) 显然不匹配，所以 `b` 将被视为形状为 `(1,2)` 的张量，因为只有单个元素的轴可以匹配任意数量的轴。因此 `a+b` 是两个二维数组 `(3,1)` 和 `(1,2)` 的相加。元素数量为 1 的轴将被升级为具有相同数量元素的数组，即两个形状为 `(3,2)` 的二维数组，如图 1-19 所示，然后进行逐元素计算。也就是说，广播总是将轴上元素较少的扩展为与元素较多的相同大小。

![](EPUB/media/file222.png)

**图 1-19** 两个二维数组 (3,1) 和 (1,2) 的相加被升级为两个二维数组 (3,2) 的相加

两个数组进行运算时，广播的规则为：
