

### 7.11.5 注意力机制

上一节 Seq2Seq 模型编码器输出的内容向量通常是编码器最后时刻的隐藏状态或输出，它包含了整个输入序列信息的编码。这个内容向量沿着时间维度传递给解码器，作为解码器的初始隐藏状态。解码器每个时刻的处理，也就是说，解码器在每个时刻都接受编码器输入序列相同的内容编码。

使用最后时刻的隐藏状态或输出作为内容向量可能不足以包含完整的输入序列信息，特别是对于长输入序列。从上一节 Seq2Seq 模型的效果可以看出，序列越长，预测效果越差。如果将所有时刻的所有隐藏状态拼接成一个内容向量，它可以包含足够完整的输入序列信息，但由于输入序列的长度是变化的，这个内容向量显然不能直接作为编码器的隐藏状态使用，因此需要一个转换过程将其转变为定长向量。另一方面，输入序列的不同部分对解码器每个时刻的影响不同，解码器的每个时刻应该对输入序列的不同部分有不同程度的关注。如图 7-56 所示，输入序列是句子（词序列）"knowledge is power"，输出目标序列是句子 "knowledge is power"。当解码器处理 "knowledge" 时，输入序列中的单词 "knowledge" 比其他两个单词 "is" 和 "power" 影响更大，而处理 "is" 时，输入序列中的 "is" 更重要。因此，当解码器进行预测时，输入序列的不同单词对输出序列的不同单词有不同的影响。

![](EPUB/media/file171.png "fig:")
图 7-56 输入序列的不同部分在不同时刻对输出序列有不同的预测效果

**注意力机制** 是指解码器在每个时刻动态地选择与当前预测最相关的输入序列部分。可以通过将解码器当前时刻的输入信息（上一时刻的隐藏状态和当前时刻的数据输入）与编码器所有时刻的输出（或隐藏状态）进行比较来计算一个权重向量，然后用该权重向量加权编码器所有时刻的输出内容，以获得当前时刻特定的内容上下文向量，即解码器在不同时刻拥有不同的编码器上下文向量，并且该上下文向量与该时刻的隐藏状态和数据输入一起用于解码器当前时刻的计算。

上一节 Seq2Seq 解码器循环神经网络每个时刻 *i* 的计算可以表示为：

```
h[i] = RNN(h[i-1], x[i])
```

使用注意力机制的 Seq2Seq 解码器每个时刻 *i* 的计算可以表示为：

```
h[i] = RNN(h[i-1], x[i], c[i])
```

即每个时刻都有一个特定于该时刻的额外内容向量 `c[i]`。这个 `c[i]` 不仅取决于 `h[i-1], x[i]`，还取决于编码器所有时刻的输出（或隐藏状态）。如果编码器所有时刻的输出是隐藏状态 `\overline{h}_t`，即 `c[i]` 取决于所有 `\overline{h}_t, t = 1,2,\cdots,T`，T 是编码器的最后时刻。在每个时刻 *i*，解码器基于编码器的输出 `\overline{h} = {h_1,h_2,\cdots,h_T}` 和解码器时刻 *i* 的信息（如输入隐藏状态 `h[i-1]`）首先计算一个权重向量 `\alpha[i] = (\alpha[i1], \alpha[i2], \cdots, \alpha[iT])`，使用该权重向量 `\alpha` 对编码器的输出 `\overline{h}` 进行加权求和，得到当前时刻的内容向量 `c[i]`，即：

$c_i = \alpha_i \cdot \overline{h} = \alpha_{i1}\overline{h}_1 + \alpha_{i2}\overline{h}_2 + \cdots + \alpha_{iT}\overline{h}_T$

且 $\quad\sum\limits_{j = 1}^{T}\alpha_{ij} = 1,\alpha_{ij} > 0$

即解码器时刻 *i* 的输入上下文向量 `c[i]` 是编码器所有时刻输出（或隐藏状态）`\overline{h}_j` 的加权平均值。而 `\alpha[ij]` 表示编码器第 *j* 个输出（或隐藏状态）`\overline{h}_j` 在输入上下文向量 `c[i]` 中的权重。

这些 `\alpha[ij]` 由同一组所谓的分数（也称为**能量**）值 `e[ij]` 计算得出：

$\alpha_{ij} = \frac{exp^{e_{ij}}}{\sum\limits_{k = 1}^{T}exp^{e_{ik}}}$

每个 `e[ij]` 可以由解码器时刻 *i* 的输入隐藏状态 `h[i-1]` 和编码器时刻 *j* 的 `\overline{h}_j` 通过一个函数 a 计算得出，即：

$e_{ij} = a(h_{i - 1},\overline{h}_j)$

当然，`e[ij]` 也可以依赖于当前时刻的数据输入 `x[i]`。根据不同的函数 a，分数有不同的计算方法，如图 7-57 所示，`h[i-1]` 和 `\overline{h}_j` 使用一个只有一个神经元且激活函数为 tanh 的神经网络层作为分数的计算函数，即：

$a(\mathbf{h}_{i - 1};\overline{\mathbf{h}}_j) = \tanh([\mathbf{h}_{i - 1};\overline{\mathbf{h}}_j]\mathbf{W}_a)$

![](EPUB/media/file172.png "fig:")
图 7-57 分数计算函数是一个只有一个神经元且激活函数为 tanh 的神经网络层

其中，参数 **W[a]** 也是一个需要学习的参数。下表列出了一些常见的评分方法：

| 名称 | 对齐分数函数 | 引用 |
| --- | --- | --- |
| 基于内容的注意力 | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \text{cosine}[\mathbf{h}_t, \boldsymbol{\overline{h}}_t]$ | [Graves2014](https://arxiv.org/abs/1410.5401) |
| 加性(*) | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{v}_a^{\top}\tanh(\mathbf{W}_a[\mathbf{h}_t;\overline{\mathbf{h}}_s])$ | [Bahdanau2015](https://arxiv.org/pdf/1409.0473.pdf) |
| 基于位置 | `\alpha[t, i] = softmax(W[a]h[t])` | [Luong2015](https://arxiv.org/pdf/1508.04025.pdf) |
| 通用 | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{h}_t^{\top}\mathbf{W}_a\overline{\mathbf{h}}_s$ | [Luong2015](https://arxiv.org/pdf/1508.04025.pdf) |
| 点积 | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \mathbf{h}_t^{\top}\overline{\mathbf{h}}_t$ | [Luong2015](https://arxiv.org/pdf/1508.4025.pdf) |
| 缩放点积 | $\text{score}(\mathbf{h}_t,\overline{\mathbf{h}}_s,) = \frac{\mathbf{h}_t^{\top}\boldsymbol{\overline{h}}_s}{\sqrt{n}}$ | [Vaswani2017](http://papers.nips.cc/paper/7181-attention-is-all-you-need.pdf) |

其中 `\overline{h}_s, h_t` 分别代表输入序列 *s* 和输出序列 *t* 的隐藏状态，`v[a], W[a]` 是可学习的权重参数矩阵。注意虽然解码器的隐藏状态 `h[t]` 使用了统一符号，但不同论文中的含义略有不同，有的是当前时刻 *t* 的 `h[t]`，有的其实是上一时刻的隐藏状态 `h[t-1]`。例如，**Bahdanau attention** 论文中表示的是上一时刻的 `h[t-1]`，而 **Luong attention** 是当前时刻的 `h[t]`。

如图 7-58 所示，解码器在每个时刻使用这个动态计算的上下文与输入数据和上一时刻的隐藏状态一起进行计算。

![](EPUB/media/file173.png "fig:")
图 7-58 解码器在每个时刻计算动态权重，并用这些权重计算编码器所有时刻输出（或隐藏向量）的加权平均以获得上下文向量，用于解码器当前时刻的计算

[Luong et al](https://arxiv.org/abs/1508.04025) 还提出了**局部注意力**，它与常规的**全局**注意力不同之处在于：模型首先预测当前目标词在输入序列中的对齐位置，然后以该位置为中心、在一个窗口范围内计算上下文向量，如图 7-59 右图所示。

![](EPUB/media/file174.png)

图 7-59 全局注意力使用编码器的所有输出（隐藏状态）计算上下文向量，而局部注意力先找到目标位置对应的输入序列位置，然后以此位置为中心的窗口区域内编码器的所有输出（隐藏状态）计算上下文向量

如图 7-60 所示，解码器根据上一时刻的隐藏状态 `prev_hidden` 和编码器所有时刻的输出内容 `encoder_outputs` 计算一个注意力权重向量 `attn_weights`，然后用这个权重向量加权编码器的输出 `encoder_outputs` 得到一个注意力内容向量 `content`，接着将数据输入 `input` 的嵌入向量 `embedded` 通过一个全连接层 `combine` 组合，再经过 relu 激活函数，与 `pre_hidden` 一起输入到循环神经网络单元 `gru`，`gru` 的输出再经过一个全连接层 `out` 产生最终输出。

根据当前输入数据 `input` 和上一时刻的隐藏状态 `prev_hidden` 计算一个注意力权重向量 `attn`，然后与编码器的隐藏状态输出 `encoder_outputs` 加权得到 `attn_applied`，再将其与输入 `embedded` 组合成 `attn_combine`，经过激活函数变换后，作为循环神经网络单元（GRU）当前时刻的数据输入。

图 7-60 注意力机制的计算过程：利用输入和隐藏状态计算一个注意力权重，然后与编码器的输出加权求和。这个加权和作为新的输入数据输入到循环神经网络层产生最终输出。
