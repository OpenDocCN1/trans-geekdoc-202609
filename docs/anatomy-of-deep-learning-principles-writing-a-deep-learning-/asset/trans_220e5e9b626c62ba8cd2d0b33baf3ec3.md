对于复合函数，输入一个变量 `x`，总是沿着函数的复合过程“从内到外”计算其函数值，即先计算 `g(x)`，再计算 `f(g(x))`，而计算最终函数值 `f(g(x))` 对输入 `x` 的导数的过程则是相反的，先计算 `f'(g)`，再计算 `g'(x)`，然后将两者相乘。也就是说，求导过程是依次求出各个函数的导数“从外到内”。

例如，`sin(x²)` 是由函数 `f = sin(g)` 和 `g = x²` 复合而成的函数，因此，它的导数：

`sin(x²)' = sin'(g) * g'(x) = sin'(g) * (x²)' = cos(g) * (2x) = 2x * cos(x²)`

同理，可以得到 `σ(x)` 函数的导数：

$$
\begin{matrix}
\sigma'(x) & = (\frac{1}{1 + e^{-x}})' = \frac{1' * (1 + e^{-x}) - 1 * (1 + e^{-x})'}{(1 + e^{-x})^2} \\
& = \frac{- (1 + e^{-x})'}{(1 + e^{-x})^2} = \frac{- 0 - (e^{-x})'}{(1 + e^{-x})^2} = \frac{- (e^{-x})(-x)'}{(1 + e^{-x})^2} \\
& = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1 + e^{-x} - 1}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} - \frac{1}{(1 + e^{-x})^2} \\
& = \frac{1}{1 + e^{-x}}(1 - \frac{1}{1 + e^{-x}}) = \sigma(x)(1 - \sigma(x))
\end{matrix}
$$

下面的代码绘制 `σ'(x)` 的函数曲线：

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

def sigmoid(x):
    return 1/(1+np.exp(-x))

x = np.arange(-7, 7, 0.1)
y = sigmoid(x)
dy = sigmoid(x)*(1-sigmoid(x))

plt.plot(x, y)
plt.plot(x, dy)

plt.legend(['$\sigma(x)$','$\sigma\'(x)$'])
plt.xlabel('x')
plt.ylabel('y')
plt.show()
```

**图 1-29** `σ(x)`、`σ'(x)` 的函数曲线

可以看出，`σ'(x)` 的函数曲线是一个钟形曲线，对所有 `x`，`σ'(x) > 0`，且在 `x=0` 处导数值最大。因为 `σ(0)(1 - σ(0)) = 0.5 * 0.5 = 0.25`，当 `x` 趋向无穷大时，导数值趋向于 0。导数值的大小表明函数值随自变量变化的快慢。因此，`σ(x)` 在 `x = 0` 处变化最快，当趋向无穷大时，函数值的变化越来越慢。

根据导数的定义，上述四则运算法则和复合函数链式求导法则很容易证明。感兴趣的读者可以自行证明或参考微积分教材。

### 1.3.5 计算图、前向计算、反向传播求导

通过四则运算和复合运算从简单函数构造出一个函数的过程，可以用上述图 1-29 表示，图中的节点表示四则运算或复合运算。该图也展示了输入自变量 `x` 给该函数计算函数值（函数输出）的过程。这个图称为**计算图**，根据形成该图的过程计算输入变量的输出函数值的过程称为**前向计算**。从图中可以看出，求导过程正好是前向计算过程的逆过程，因此称为**后向计算**或**反向传播计算**。

![](EPUB/media/file228.png)

**图 1-30** 前向计算（实线）与反向求导计算（虚线）示意图

如图 1-30 所示，前向计算过程是从 `x` 经过函数 `g` 得到 `g(x) = x²`，再经过函数 `f` 得到 `f(g) = sin(g) = sin(x²)`。

`x → g → g(x) = x² → f → f(g) = sin(g) = sin(x²)`

反向传播求导过程为：

`f → f'(g) → f'(g) = sin'(g) = cos(g)`

`g → g'(x) → g'(x) = (x²)' = 2x`

`f'(x) = f'(g) * g'(x) = cos(g) * (x²)' = cos(g) * 2x = cos(x²) * 2x`

反向传播求导是神经网络（深度学习）的核心且最关键的基础。如果理解了反向求导，就能轻松理解深度学习的算法原理。

### 1.3.6 多元函数的偏导数与梯度

有时自变量 `x` 是由多个分量组成的向量，而不是单个值，即 `x = (x[1], x[2], ..., x[n])` 包含多个分量 `x[j]`。将这种自变量 `x` 映射为单个数值因变量的函数 `f(x)` 称为**多元函数**，可表示为 `f : ℝⁿ → ℝ`。

`f(x)` 对 `x` 的每个分量 `x[j]` 的导数称为偏导数，记作 `∂f/∂xⱼ`，它反映了 `f(x)` 关于该分量 `x[j]` 的变化率。

`∂f/∂xⱼ = lim(Δxⱼ→0) [f(x₁,...,xⱼ + Δxⱼ,...,xₙ) - f(x₁,...,xⱼ,...,xₙ)] / Δxⱼ`

也就是说，偏导数是将其他变量视为常数，将 `x[j]` 视为变量，这样该函数就是一元函数，它对 `x[j]` 的导数称为原函数对 `x[j]` 的偏导数。

例如，若 `f(x, y) = 2x + y²`，其自变量包含 2 个分量 `x` 和 `y`，该函数为多元函数，自变量 `(x, y)` 映射为函数值 `f(x, y)`，即 `f : (x, y) → (2x + y²)`。该函数对 `x`、`y` 的偏导数为：

`∂f/∂x = ∂(2x + y²)/∂x = d(2x)/dx = 2`

`∂f/∂y = ∂(2x + y²)/∂y = d(y²)/dy = 2y`

`f(x)` 对 `x` 的梯度 `∇ₓf(x)` 是 `f(x)` 对 `x` 的每个分量 `x[j]` 的偏导数组成的向量：

`∇ₓf(x) = df/dx = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

在上例中，`f(x, y) = 2x + y²` 关于 `(x, y)` 的梯度 `∇₍ₓ,ᵧ₎f(x, y) = (2, 2y)`。在特定点 `(2,3)` 处的梯度为 `(2, 6)`。

在不引起混淆的情况下，`f(x)` 对 `x` 的梯度 `∇ₓf(x)` 常简写为 `∇f(x)`。

对于 `x` 的一个微小增量 `Δx = (Δx[1], Δx[2], ..., Δx[n])`，`f(x)` 的增量 `f(x + Δ) - f(x)` 可近似为梯度 `∇f(x)` 与 `x` 的增量 `Δx` 的点积。

`f(x + Δ) - f(x) ≃ ∇f(x) ⋅ Δx`

通常，梯度写成行向量的形式：

`∇ₓf(x) = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

而 `f(x)`、`x` 写成列向量的形式：

$$
\begin{matrix}
x = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}
\quad
\Delta x = \begin{bmatrix} \Delta x_1 \\ \Delta x_2 \\ \vdots \\ \Delta x_n \end{bmatrix}
\end{matrix}
$$
