
# Python 内置数据结构与函数

## 内置函数 `range(n)`

Python 的内置函数 `range(n)` 是一个**迭代器对象**，它生成 0 到 n 之间的整数（不包括 n）。迭代器对象不是容器，但你也可以使用 `for` 来遍历该对象的元素。

```python
for e in range(6):  
    print(e, end=' ')
print()
```

```
0 1 2 3 4 5
```

可以通过遍历迭代器对象来创建列表对象：

```python
alist = [e**2 for e in range(6)]
print(alist)
```

```
[0, 1, 4, 9, 16, 25]
```

## 2. tuple (元组)

与列表类似，元组也是一组数据元素（对象）的有序序列，即每个元素也有唯一的下标。使用圆括号而非方括号来定义元组。例如：

```python
t = ('python', [2, 5], 37, 3.14, "https://hwdong.net")
print(type(t))
print(t[1:4])
print(t[-1:-4:-1])
```

```
<class 'tuple'>
([2, 5], 37, 3.14)
('https://hwdong.net', 3.14, 37)
```

列表中的元素可以被修改。

```python
print(alist)
alist[1] = 22
print(alist)
```

```
[0, 1, 4, 9, 16, 25]
[0, 22, 4, 9, 16, 25]
```

元组中的元素不能被修改，就像字符串中的元素不能被修改一样。

```python
t[1] = 22
```

```
TypeError: 'tuple' object does not support item assignment
```

**注意：** 与列表不同，使用 `()` 创建的是可迭代对象（生成器表达式）而不是元组对象，例如：

```python
nums = (x**2 for x in range(6))
print(nums) 
for e in nums:
    print(e, end=" ")
```

```
<generator object <genexpr> at 0x...>
0 1 4 9 16 25
```

这是因为元组对象不可修改，不可能通过每次生成一个值就逐渐添加到元组中来创建元组对象。

## 3. set (集合)

集合是一个无序且不包含重复元素的集合。集合是由一对花括号 `{}` 包围的、逗号分隔的元素组成。元素的类型可以不同。例如：

```python
s = {5, 5, 3.14, 2, 'python', 8}
print(type(s))
print(s)
```

```
<class 'set'>
{2, 3.14, 5, 8, 'python'}
```

可以使用 `add()` 和 `remove()` 函数向集合添加和删除一个元素。列表对象可以使用 `append()` 或 `insert()` 函数添加或插入元素；`pop()` 用于删除最后一个元素，`remove()` 用于删除第一个指定值的元素。

```python
s.add("hwdong")
print(s)
s.remove("hwdong")
print(s)
alist.append("hwdong")
print(alist)
alist.insert(2, "net")
print(alist)
alist.pop()
print(alist)
alist.remove("net")
print(alist)
```

```
{2, 3.14, 5, 8, 'hwdong', 'python'}
{2, 3.14, 5, 8, 'python'}
[0, 22, 4, 9, 16, 25, 'hwdong']
[0, 22, 'net', 4, 9, 16, 25, 'hwdong']
[0, 22, 'net', 4, 9, 16, 25]
[0, 22, 4, 9, 16, 25]
```

但像元组这样的不可变对象没有用于添加元素的 `append()` 或 `insert()` 等函数。以下代码是错误的：

```python
t.append("hwdong")
```

```
AttributeError: 'tuple' object has no attribute 'append'
```

可以使用 `{}` 推导式创建集合对象，例如：

```python
nums = {x**2 for x in range(6)}
print(nums) 
```

```
{0, 1, 4, 9, 16, 25}
```

## 4. dict (字典)

字典是“键值对”键值对的无序集合。每个元素以“键: 值”的形式存储。例如：

```python
d = {1: 'value', 'key': 2, 'hello': [4, 7]}
print(type(d))
print(d)
```

```
<class 'dict'>
{1: 'value', 'key': 2, 'hello': [4, 7]}
```

需要传递键（key，也称为关键字）来访问字典中对应键的元素值。例如：

```python
d['hello']
```

```
[4, 7]
```

如果某个键对应的元素不存在，则通过该键访问元素是非法的，例如：

```python
d[3]
```

```
KeyError: 3
```

但你可以给一个不存在的键赋值，这样一个“键值对”元素就会被添加到集合中。例如：

```python
d[3] = "python"
print(d)
print(d[3])
```

```
{1: 'value', 'key': 2, 'hello': [4, 7], 3: 'python'}
python
```

你可以定义一个表示学生信息并以姓名为键的字典对象：

```python
students = {
    "LiPing": [21, "Compu01", 15370203152],
    "ZhangWei": [20, "Compu02", 17331203312],
    "ZhaoSi": [22, "mecha03", 16908092516]
}
print(students)
print(students["ZhangWei"])
```

```
{'LiPing': [21, 'Jike 01', 15370203152], 'ZhangWei': [20, 'Jike 02', 17331203312], 'ZhaoSi': [22, 'Mechanical 03', 16908092516]}
[20, 'Jike 02', 17331203312]
```

可以通过 `for...in` 循环语句访问字典中的元素，例如：

```python
for name in students:
    info = students[name]
    print('{}\'s info: {} '.format(name, info))   
```

```
LiPing's info: [21, 'Jike 01', 15370203152]
ZhangWei's info: [20, 'Jike 02', 17331203312]
ZhaoSi's info: [22, 'Mechanical 03', 16908092516]
```

当然，也可以使用 `{}` 推导式创建字典对象，例如：

```python
points = {x: x**2 for x in range(6)}
print(points) 
```

```
{0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

## 1.1.6 函数

Python 通过关键字 `def` 定义函数，给一段程序块起一个名字，然后可以通过函数名调用并执行该函数块中的代码。例如：

```python
def hwdong():
    print("My youtube channel is: ", "hwdong")             # 调用内置函数 print()
    print("My station B number is: hw-dong")
    print("My blog is: https://hwdong-net.github.io")
```

调用该函数 `hwdong()`：

```python
hwdong()
print()            # 调用内置函数 print()
hwdong()
print()            # 调用内置函数 print()
hwdong()
```

```
My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io

My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io
    
My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io
```

函数可以有参数，这样在调用函数时，可以将相应的参数传递给该函数，例如下面的计算 `x**n` 的函数：

```python
def pow(x, n):    
    ret = 1
    for i in range(n): # 0, 1, 2, ..., n-1
        ret *= x # ret = ret * x
    return ret                     # "return ret" 返回函数的值
```

由关键字 `return` 表示的语句称为返回语句，函数执行到 `return` 时返回（结束函数执行），并可以返回一个值。

调用该函数可以将两个实参传递给函数的形参 `x` 和 `n`。例如：

```python
print(pow(3, 2))    # 3 传给 x，2 传给 n
print(pow(2, 4))
```

```
9
16
```

函数 `pow()` 调用的返回值被传递给函数 `print()` 以打印出返回值。

函数的参数可以有默认值。如果调用函数时未提供对应的参数，该参数将使用其默认值。

```python
def pow(x, n=2):   
    ret = 1
    for i in range(n):
        ret *= x
    return ret
```

该函数参数 `n` 的默认值为 2，即计算 `x**2`。调用该函数时，可以向形参 `n` 传递实参，也可以不传递。

```python
print(pow(3.5))     # 3.5 传给 x，n 的默认值为 2
print(pow(3.5, 3))
```
