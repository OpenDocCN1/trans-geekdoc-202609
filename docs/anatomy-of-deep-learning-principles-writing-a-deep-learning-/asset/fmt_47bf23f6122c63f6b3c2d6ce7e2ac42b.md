
Therefore, the gradient of the cross-entropy loss *L*(*FF*, *YY*) with respect to *zz* is:

$$
\frac{\partial L}{\partial FF} = \frac{1}{m}\frac{FF - YY}{FF(1 - FF)}
$$

$$
\frac{\partial FF}{\partial ZZ} = \sigma(ZZ)(1 - \sigma(ZZ)) = FF(1 - FF)
$$

$$
\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{\partial L}{\partial ff}\frac{\partial \pmbf}{\partial zz} = \frac{1}{m}(FF - YY)
$$

Right now:

$$
\begin{matrix}
FF = \begin{bmatrix} f^{(1)} \\ \vdots \\ f^{(i)} \\ \vdots \\ f^{(m)} \end{bmatrix} \quad\quad
YY = \begin{bmatrix} y^{(1)} \\ \vdots \\ y^{(i)} \\ \vdots \\ y^{(m)} \end{bmatrix} \quad\quad
\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{1}{m}\begin{bmatrix} f^{(1)} - y^{(1)} \\ \vdots \\ f^{(i)} - y^{(i)} \\ \vdots \\ f^{(m)} - y^{(m)} \end{bmatrix}
\end{matrix}
$$

It should be noted that: because each sample corresponds to a different *z*^((*i*)), the loss cross-entropy loss *L* should be derived separately for each *z*^((*i*)) instead of combining these. The derivatives add up. In addition, the vector multiplication and division in the above formula are all element-wise operations.

According to whether the output out of the neural network is the score represented by the weighted sum or the output probability of the *σ* function, the following calculation can be written to calculate the gradient of the weighted sum or output probability of the two-category cross-entropy loss.

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def binary_cross_entropy(f, y, epsilon=1e-8):
    # np.sum(y*np.log(f+epsilon)+ (1-y)*np.log(1-f+epsilon), axis=1)
    m = len(y)
    return - (1./m)*np.sum(np.multiply(y, np.log(f+epsilon)) \
                           + np.multiply((1 - y), np.log(1 - f+epsilon)))

def binary_cross_entropy_grad(out, y, sigmoid_out=True, epsilon=1e-8):
    if sigmoid_out:
        f = out
        grad = ((f-y)/(f*(1-f)+epsilon)) / (len(y))
    else:
        f = sigmoid(out)  # out is z
        grad = (f-y)/(len(y))

def binary_cross_entropy_loss_grad(out, y, sigmoid_out=True, epsilon=1e-8):
    if sigmoid_out:
        f = out
        grad = ((f-y)/(f*(1-f)+epsilon)) / (len(y))
    else:
        f = sigmoid(out)  # out is z
        grad = (f-y)/(len(y))
    loss = binary_cross_entropy(f, y, epsilon)
    return loss, grad
```

### 2. The gradient of the mean square error loss function on the output

For regression problems, the output layer is one or more linear regression neurons, that is, each neuron directly outputs the weighted sum *z*[*i*] of its input, and these values output by multiple neurons in the output layer form an output vector *zz* = (*z*[1], *z*[2], ..., *z*[*K*]) as the output of the entire output layer *ff* = *zz*. For K>1, the target value is a vector *yy* = (*y*[1], *y*[2], ..., *y*[*K*]) of the same size.

For a sample, the square of the Euclidean distance between the output vector *zz* and the target value vector *yy* can be used as the error ‖(*ff*^((*i*)) − *yy*^((*i*)))‖₂². In order to make the derivative (gradient) look more concise, it is usually multiplied by a constant, that is, $\frac{1}{2}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2}$ is used as the error. The gradient of this error with respect to *ff*^((*i*)) is *ff*^((*i*)) − *yy*^((*i*)).

If the dimension of the output value is K, then:

$$
\frac{1}{2}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2} = \frac{1}{2}\sum_{k=1}^{K}{(f_k^{(i)} - y_k^{(i)})}^{2}
$$

The gradient of the error about *f*^((*i*)) is (*f*[1]^((*i*)) − *y*[1]^((*i*)), *f*[1]^((*i*)) − *y*[2]^((*i*)), ⋯, *f*[*K*]^((*i*)) − *y*[*K*]^((*i*))) = *f*^((*i*)) − *y*^((*i*)).

For a matrix *FF*, *YY* composed of multiple samples, the mean square error $L(FF, YY) = \frac{1}{2m}\sum_{i=1}^{m}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2}$. The gradient of *FF* is $\frac{1}{m}(FF - YY)$. Because *FF* = *ZZ*, namely:

$$
\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{\partial \mathcal{L}}{\partial FF} = \frac{1}{m}(FF - YY)
$$

```python
def mse_loss_grad(f, y):
    m = len(f)
    loss = (1./m)*np.sum((f-y)**2)  # np.square(f-y))
    grad = (2./m)*(f-y)
    return loss, grad
```

### 3. The gradient of the multi-class cross entropy loss function on the output

For multi-classification problems, the neural network converts the output of the previous layer into a probability with intuitive meaning through the final softmax function, indicating the probability that the sample belongs to each sample. Since the neurons of softmax do not contain any model parameters, sometimes softmax is not used as the last layer of the neural network, but the previous layer is used as the last output layer of the neural network. No matter which scheme is adopted, the multi-class cross-entropy loss in softmax regression is usually calculated at the end. The latter scheme is usually adopted, that is, it is assumed that the output layer outputs scores instead of probabilities. The neurons of this output layer are linear regression neurons, and the weighted sum of their inputs is directly output as the activation value, that is, *f*[*i*] = *a*[*i*]^((*L*)) = *z*[*i*]^((*L*)) (assuming this is an L-layer neural network, the serial number of this output layer is L).

Let the output *zz* of the output layer generate an output *ff* through the softmax function, and then calculate the cross-entropy loss *L*(*ff*, *yy*) with the target value *yy*.

For multiple samples, the output of the output layer can be written as a matrix *ZZ* = (*zz*[1], ⋯, *zz*[*i*], ⋯, *zz*[*m*])^(*T*), and the output generated by the softmax function is also a representation Probability matrix *FF* = (*ff*, ⋯, *ff*[*i*], ⋯, *ff*[*m*])^(*T*). According to Section 3.6), if each target value *yy*[*i*] uses a vector represented by one-hot, then *YY* is also a matrix. At this time, the multi-classification cross-entropy loss *L*(*F*, *Y*) The gradient of *ZZ* is: $\frac{1}{m}(FF - YY)$.

If each target value *yy*[*i*] is an integer, representing the subscript of the category to which the sample belongs, then the gradient of the multi-category cross-entropy loss *L*(*F*, *Y*) on *ZZ* is: $\frac{1}{m}(FF - I_i I_i)$. Among them, each line of *I*[*i*]*I*[*i*] is a one-hot vector, which is to convert the integer corresponding to the sample into a one-hot vector, so *I*[*i*]*I*[*i*] is composed of *I*[*i*]*I*[*i*] and the above one-hot vector $\pmb{Y}$ is the same.

The following python code converts a target vector of integer values into a matrix of one-hot vectors:
