### 6.1.2 一维信号的卷积

卷积用于处理一维信号或二维图像等数据，可以去除数据中的噪声或获取数据中包含的某些特征。

例如，下面生成两组数字 `x` 和 `y`。`x` 是在 `[0, 2*π]` 上均匀分布的一组数字（100个），`y` 是对应正弦曲线 `sin(x)` 附近的数字（即 `y` 是正弦波的带噪采样）：

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

x = np.linspace(0, 2*np.pi, 100)
y = np.sin(x) + np.random.random(100) * 0.2
plt.plot(x, y)
plt.show()
```

图 6-10 正弦波的随机噪声采样

以下代码根据正态分布生成一组权重向量（卷积核）`w`：

```python
sigma = 1.6986436005760381
x_for_w = np.arange(-6, 6)
w = np.exp(-(x_for_w) ** 2 / (2 * sigma ** 2))
w /= sum(w)
print(x_for_w)
print(["%0.2f" % x for x in w])
plt.bar(x_for_w, w)
```


![](EPUB/media/file124.png "fig:")
图 6-11 根据正态分布采样的一组权重参数

该权重向量 `w` 的中间值较大，两侧值较小，所有权重值之和为 1。该权重向量 `w` 用于卷积 `y`：

```python
# w = np.array([0.1, 0.2, 0.5, 0.2, 0.1])
yhat = np.correlate(y, w, "same")
plt.plot(x, yhat, color='red')
```

![](EPUB/media/file125.png "fig:")
图 6-12 使用高斯分布的权重向量对原始正弦采样数据进行加权，起到平滑作用

该权重向量计算 `y` 中值的加权平均。当权重向量沿 `y` 滑动时，计算出的值 `yhat` 是滑动窗口中心点 `y` 及其周围 `y` 的平均权重。中心点 `y` 对应最大的权重值，离中心点越远的 `y` 对应的权重值越小。生成的向量相当于对原始数据进行平均或平滑处理。从图 6-12 可以看出，卷积后的数据点 `(x, yhat)` 对应的曲线变得更平滑，即原始数据 `y` 中的噪声在一定程度上被降低了。

### 6.1.3 二维卷积

各种电子设备的显示屏之所以能显示丰富多彩的文字和图像内容，是因为显示屏本身由一些像素组成，这些像素按行列排列形成一个矩形。在计算机中，任何图像都由像素矩阵表示。图像中的像素数量称为图像的**分辨率**。例如，图像分辨率 `1024 * 768` 表示图像矩形在宽度和高度方向上的像素数分别为 1024 和 768。计算机中由像素矩阵表示的这种图像称为**数字图像**。如图 6-13 所示，它是一幅分辨率为 `170 * 225` 的图像。

图 6-13 分辨率为 170 * 225 的蒙娜丽莎图像

数字图像中每个位置的像素包含表示颜色信息的数据。对于彩色图像，它可能包含红色（R）、绿色（G）、蓝色（B）和透明度（A）等多个值。对于黑白图像，它是一个表示亮度的值。这些值通常用字节（8位二进制）整数表示，即每个值的范围是 `[0, 255]`。黑白图像是此类整数的矩阵，而彩色图像可以看作是每种颜色对应的矩阵叠加而成，每种颜色的矩阵称为一个**通道**。例如，一幅图像由红色（R）、绿色（G）和蓝色（B）三幅彩色图像叠加而成。

图 6-14 彩色图像由 3 个通道的彩色图像叠加而成

当然，计算机数字图像也可以使用 `[0, 1]` 区间内的实数来表示像素值。以下代码使用 `skimage` 包的 `io` 模块将一幅彩色图像读入 numpy 多维数组 `img`，然后使用 `skimage.color` 模块的 `rgb2gray` 将彩色图像转换为黑白（灰度）图像，接着显示这两幅图像，并打印出中间部分一个 `5*5` 窗口的像素值。

```python
from skimage import io, transform
from skimage.color import rgb2gray
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

img = io.imread('image.jpg')
gray_img = rgb2gray(img)  # io.imread('./imgs/image.jpg', as_grey=True)

fig, axes = plt.subplots(1, 2, figsize=(8, 4))
ax = axes.ravel()

plt.subplot(1, 2, 1)
plt.imshow(img)
plt.subplot(1, 2, 2)
plt.imshow(gray_img, cmap='gray')

# img = io.imread('./imgs/lenna.png', as_grey=True)  # load the image as grayscale
# plt.imshow(img, cmap='gray')

print('image matrix size: ', img.shape)      # print the size of image
print('image matrix size: ', gray_img.shape)      # print the size of image

print('\n First 5 columns and rows of the color image matrix: \n', img[150:155, 110:115])
print('\n First 5 columns and rows of the gray image matrix: \n', gray_img[150:155, 110:115])
```

图 6-15 将彩色图像转换为黑白（灰度）图像

可以看出，彩色图像被读入一个三维 numpy 数组，numpy 数组的第三维代表彩色图像的三个颜色通道，即 RGB 通道。每个通道都是一个二维数组（矩阵）。因此，彩色图像可以看作是 3 个矩阵。`rgb2gray()` 函数将 3 通道彩色图像转换为单通道灰度图像，即一个二维数组（矩阵）。每个灰度像素的值由红色（R）、绿色（G）、蓝色（B）三色像素值的加权和计算得出。

$$ Y = 0.2125 R + 0.7154 G + 0.0721 B $$

从输出结果可以看出，RGB 颜色值将从 `[0, 255]` 区间的整数值转换为 `[0, 1]` 区间的实数值。

颜色值也可以从 `[0, 1]` 区间的实数值转换为 `[0, 255]` 区间的整数值。以下代码将灰度图像的像素值转换为 `[0, 255]` 区间的整数。

```python
gray_img2 = gray_img * 255
```
