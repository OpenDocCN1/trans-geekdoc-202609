Substituting Equation (8.3) into Equation (8.4), we obtain [151–153]

R(k)=∑_{n=0}^{N-1} x(n) e^{(2πi n ε)/N} e^{(-2πi n k)/N}+W(k)
= (1/N) ∑_{l=0}^{N-1} X(l) ∑_{n=0}^{N-1} e^{(2πi (l+ε -k))/N}+W(k)  (8.7)

where W(k) is the kth frequency domain sample of the noise. We can expand (1/N) ∑_{n=0}^{N-1} e^{(j2πn(l-ε -k))/N} using the geometric series as follows [151–153]:

(1/N) ∑_{n=0}^{N-1} e^{(j2πn(l-ε -k))/N}= (1/N) [1 - e^{j2π(l+ε -k)}]/[1 - e^{(j2π(l+ε -k))/N}]
= (1/N) e^{jπ(l+ε -k)(1-1/N)} sin(π(l -k + ε))/sin(π(l -k - ε)/N)  (8.8)

We obtain [151–153]

R(k)=∑_{l=0}^{N-1} X(l) S(l -k + ε)+W(k)  (8.9)

where S(l - k + ε) represents the complex coefficients for the interference components in the received signal. S(l - k + ε) is given by [151–153]

S(l -k + ε)= e^{jπ(l+ε -k)(1-1/N)} sin(π(l -k + ε))/[M sin(π(l -k - ε)/N)]  (8.10)
