Y(z)=1/2{X0(z)+X0(-z)}G0(z)+1/2{X1(z)+X1(-z)}G1(z)
=1/2 X(z){H0(z)G0(z)+H1(z)G1(z)}
+1/2 X(-z){H0(-z)G0(z)+H1(-z)G1(z)} (7.9)

The first PR condition requires aliasing cancellation and forces this term in X(-z) to be zero. Hence, {H0(-z)G0(z)+H1(-z)G1(z)}=0, which can be achieved if [142]

H1(z)=z^{-a}G0(-z) and G1(z)=z^{a}H0(-z) (7.10)
where a must be odd (usually a = ±1).

The second PR condition is that the transfer function from X(z) to Y(z) should be unity [142]:
