# 2.5 Features of Image Encryption Schemes

Unlike text messages, image data have their special features, such as high redundancy and high correlation among pixels. Also, they are usually huge in size. Together, these make traditional encryption methods difficult to apply and slow to process. Sometimes, image applications have their own requirements, like real-time processing, fidelity reservation, image format consistency, data compression for transmission, and so on.
