# 2.6 Conventional Symmetric Block Ciphers

This section gives a brief overview of the construction of some popular conventional encryption algorithms. Each of the following encryption algorithms is a symmetric block cipher algorithm. Symmetric means that the key used for encryption and decryption is the same; block means that the data (information) to be encrypted is divided into blocks of equal length [35–45].

# 2.6.1 Data Encryption Standard
