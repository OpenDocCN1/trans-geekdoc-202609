# 8.9.3 *The Hybrid Clipping-and-Companding Method*

The hybrid clipping-and-companding method comprises clipping followed by μ-law companding. By exploiting the clipping in the first step, the hybrid scheme can reduce the PAPR of OFDM signals with slight BER degradation. Moreover, the companding in the second step further reduces the PAPR of the OFDM signals. Consequently, we expect that the hybrid scheme effectively reduces the PAPR with slight BER degradation, while the complexity of the system is slightly increased.

A complete image transmission system with OFDM comprises a PAPR reduction stage and an error-correction coding stage to reduce the effect of PAPR reduction at the receiver. A convolutional code with rate 1/2, constraint length 7, and octal generator polynomial (133,171) is adopted in the simulation experiments.
