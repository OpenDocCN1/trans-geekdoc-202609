# 2.6.8 The Advanced Encryption Standard

The Advanced Encryption Standard (AES) is based on the Rijndael algorithm, which is an iterated block cipher algorithm with a variable block size and a variable key size. The block size and the key size can be independently 128, 192, or 256 bits.
