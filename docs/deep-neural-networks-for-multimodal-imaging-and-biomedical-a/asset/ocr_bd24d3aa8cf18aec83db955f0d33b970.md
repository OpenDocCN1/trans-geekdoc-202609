# HUMAN HEALTHCARE MONITORING SYSTEM

A lot of research activities are going on in the field of human health monitoring facilities and the globally considered parts are as follows: 1) type of sensor used 2) suitable wireless protocol to be employed for the transmission 3) considered health parameter to be monitored 4) Methodology to determine and extract the important features 5) development of light-weight, powerful and low-cost sensor modes 6) ability to get connected with the mobile devices 7) does not provide any difficulties for the system configuration and implementing them with the human body.
