# The Calculations for Parameters in CNN

The filter is slided / convolved across the input image, and a dot product is computed to give an activation map. The output size of activation map is computed by (N + 2P - F) / stride + 1, where N is the input size, P is padding, F is the filter size and the stride applied on the image. The output obtained can be overfitting, fit or under-fitting, where fit is assumed to be the better result.
