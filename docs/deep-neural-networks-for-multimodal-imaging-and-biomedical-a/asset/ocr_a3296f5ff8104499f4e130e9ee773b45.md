# # THE STRUCTURE OF CNN

ConvNet is built with one input and output layer; along with many HLs in between. HLs have a sequence of conv layers that convolve with a multiplication or dot product. RELU is used as the activation function, followed by add-ons conv layers namely pooling, fully connected and normalization, referred to as hidden layers because their inputs and outputs are masked by the activation function and final conv. This final conv involves back propagation to get more accurate weights at the end product in figure 10. An image is considered as an array of pixel values, each value lies amid the range value of 0-255 shown in figure 11.
