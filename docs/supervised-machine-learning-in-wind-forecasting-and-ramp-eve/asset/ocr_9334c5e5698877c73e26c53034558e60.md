$(y_1, y_2, \dots, y_i)$ denote the set representing the training output or response, where $i=1, 2, \dots, n$ and $y_i \in \mathbb{R}$.

# ## 4.2 $\varepsilon$-support vector regression

This type of SVR uses an $\varepsilon$-insensitive loss function that intuitively accounts for sparsity similar to SVR by ignoring errors less than $\varepsilon$.

$\varepsilon$-SVR aims to find the linear regressor

$$f(x) = w^T x + b \quad \text{with } w \in X, b \in \mathbb{R}, \quad (4.1)$$

for prediction, where $x \in X$ is the input set containing all the features, $w$ is the weight coefficient related to each input $x_i$, and $b$ is the bias term.

The objective is to find $f(x)$ with maximum deviation $\varepsilon$ from the respective feature sets while being as flat as possible. To achieve the flatness of the desired regressor, the square of the norm of weight vector $w$ needs to be minimized, and the SVR problem is structured in the form of a convex optimization problem [6] as

$$
\min \frac{1}{2} \| w \|^2 + C(e^T X + e^T \chi^*), \quad (4.2)
$$\n
**subject to** $y - w^T x - eb \le \varepsilon e + \chi, \chi \ge 0, \quad (4.3)$\n
$$
w^T x + eb - y \le \varepsilon e + \chi^*, \chi^* \ge 0,
$$

where $C$ is the regularization factor that reflects the trade-off between the flatness of regressor $f(x)$ and the maximum tolerable deviation $\varepsilon$. The value of $\varepsilon$ introduces a margin of tolerance where no penalty is imposed on the errors. The larger the $\varepsilon$, the larger the errors. The parameter $C$ controls the amount of influence of the error. The variables $\chi, \chi^*$ are the slack variables introduced as a soft margin to the tolerable error $\varepsilon$, and $e$ is the vector of ones of appropriate dimension $n \times 1$.

In machine learning regression the problem of overfitting persists, which results in less error in training phase and high error in testing phase. Commonly used regularization techniques include $\mathcal{L}_1$ and $\mathcal{L}_2$ regularization. Mathematically, these are expressed as

$$
\mathcal{L}_1: \arg \min_w \text{ loss function } + \lambda \sum_{i=1}^n |w_i|, \quad (4.4)
$$\n
$$
\mathcal{L}_2: \arg \min_w \text{ loss function } + \lambda \sum_{i=1}^n w_i^2. \quad (4.5)
$$
