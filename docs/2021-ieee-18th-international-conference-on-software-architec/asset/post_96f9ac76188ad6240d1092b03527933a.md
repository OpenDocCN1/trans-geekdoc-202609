
## Self-Adapting Model-Based SDSec For IoT Networks Using Machine Learning

Hrishikesh Narayanankutty
Dept. of Computer Science
Gran Sasso Science Institute
L'Aquila, Italy
hrishikesh.narayanankutty@gssi.it

Abstract—IoT networks today face a myriad of security vulnerabilities in their infrastructure due to its wide attack surface. Large-scale networks are increasingly adopting a Software-Defined Networking approach, it allows for simplified network control and management through network virtualization. Since traditional security mechanisms are incapable of handling virtualized environments, SDSec or Software-Defined Security is introduced as a solution to support virtualized infrastructure, specifically aimed at providing security solutions to SDN frameworks. To further aid large scale design and development of SDN frameworks, Model-Driven Engineering (MDE) has been proposed to be used at the design phase, since abstraction, automation and analysis are inherently key aspects of MDE. This provides an efficient approach to reducing large problems through models that abstract away the complex technicality of the total system. Making adaptations to these models to address security issues faced in IoT networks, largely reduces cost and improves efficiency. These models can be simulated, analysed and supports architecture model adaptation; model changes are then reflected back to the real system. We propose a model-driven security approach for SDSec networks that can self-adapt using machine learning to mitigate security threats. The overall design time changes can be monitored at run time through machine learning techniques (e.g. deep, reinforcement learning) for real time analysis. This approach can be tested in IoT simulation environments, for instance using the CAPS IoT modeling and simulation framework. Using self-adaptation of models and advanced machine learning for data analysis would ensure that the SDSec architecture adapts and improves over time. This largely reduces the overall attack surface to achieve improved end-to-end security in IoT environments. Index Terms—Model-Driven Engineering, SDN, SDSec, IoT, Self-Adaptation, Machine Learning, Security

## I. MOTIVATION

There are many industries and organizations in the world that use IoT for their software service and applications. Hence many platform implementations exist for these services [8]. Such a dynamic and heterogeneous environment is a prime target for hackers.

An IoT reference architecture commonly consists of the following layers - Perception Layer, Network Layer and Application Layer [8]. Security vulnerabilities can occur across any of the aforementioned IoT layers. Many of the security threats in an IoT infrastructure occur due to insufficient consideration of security requirements during the early design phase of an IoT system. The design decisions made are more focused on the functional and the non-functional requirements of the overall system [16]. Security issues faced by IoT can be divided into the following - generic threats and architecture layer threats.

Generic threats are as follows - Hardware Vulnerabilities [2], Social Engineering/User Awareness [14], Changes to Legislation [17] [4] and DoS/DDoS Attacks [6].

Architecture layer threats are listed in brief below [8]:

- Physical/Perception Layer - Eavesdropping, Battery drain attack, Hardware malfunction, Malignant data injection, Node cloning, etc.
- Network Layer - Collision attacks, Channel congestion attacks, battery exhaustion attack, Dos attacks, MITM, etc.
- Application Layer - Cross-site Scripting (XSS) attack, threats arising from weak application security, Injection attacks, etc.

Since majority of the attacks in IoT systems are DDoS attacks using compromised IoT devices [1], we focus primarily on security vulnerabilities in the IoT network layer. IoT networks must be capable of self-protection and self-adaptation to mitigate security threats. Self-adapting large scale systems using machine learning is heavily researched due to its complexity and magnitude [15]. These solutions are also proposed for network control in complex systems due to its inherent properties of manageability, dynamism, cost-effectiveness and adaptability by abstracting the underlying network architecture [5].

## II. CONTEXT

Software-Defined Networking (SDN) provides an orchestration for network management in IoT by enabling the underlying network control to be programmable. SDN works by decoupling the control plane from the data plane to facilitate efficient management and operation of the network using software programs [3]. An overview of SDN architecture [11] is presented in Fig. 1. Subsequently, SDSec is introduced as a support solution to SDN networks to combat security and works similar to SDN by providing a new way to design, deploy and manage security mechanisms by separating the forwarding and processing plane [9] from the security control loop for self-adaptation.

Traditional security mechanisms cannot detect activities from within virtualized environments and cannot handle threats arising from the new virtual network topology. These new threats include threats coming from the hypervisor and single point of failure of the SDN controller. The development of such SDN frameworks is highly complex and requires tools and methodologies to sufficiently explore the abstraction capabilities of SDN [7].

Abstracting such complex systems is one of strongest aspects of Model Driven Engineering (MDE). MDE is an approach that focuses on creating conceptual models of large systems that can be used to generate processes, structures, code etc. Advancements in this field show research being done in order to create a model-based design approach for the development of SDN applications using MDA and MDN paradigms [7], [11]. However, to the best of our knowledge, not much has been done with regards to model-based design of SDN frameworks specifically with emphasis towards security in IoT networks. The current open issue exists in developing large scale SDsec frameworks that can self-adapt to virtualized security threats at run time.

We propose a model-based approach to designing SDsec frameworks which can self-adapt using machine learning. Using a model-based approach allows us to perform design time changes to the model and reflect back these changes to the SDsec architecture at run time to mitigate security threats. This approach permits us to raise the abstraction level during the design phase of an SDN/SDSys framework providing many advantages coming from the adoption of MDE in this context [10].

We aim to achieve the aforementioned approach by first uniquely identifying classical threats from the virtualized threats in SDN networks. Existing SDN networks can then be analyzed to identify the attack vectors that are exploited in order to compromise the system. Changes to the underlying network topology often requires manual reconfiguration and respond actions of the underlying network controllers. This can be automated using a self-adaptive model using machine learning. Machine learning techniques (e.g., deep learning) are used to monitor network traffic and for data analysis to detect anomalies [13]. Results from such analysis can be used by the SDsec model to adapt accordingly, following the MAPE-K

An implementation of this adaptive SDsec model for real world deployment would be used to showcase its efficiency. CAPS is an architecture based cyber physical systems modeling tool that is used for the development of CPS ecosystems [12]. Addition of SDsec framework to this simulation tool can be used to test and simulate large scale IoT networks. Overall our approach would ensure that the SDsec framework improves over time and adapts to a dynamic network topology.
