These new threats include threats coming from the hypervisor and single point of failure of the SDN controller. The development of such SDN frameworks is highly complex and requires tools and methodologies to sufficiently explore the abstraction capabilities of SDN [7].

Abstracting such complex systems is one of strongest aspects of Model Driven Engineering (MDE). MDE is an approach that focuses on creating conceptual models of large systems that can be used to generate processes, structures, code etc. Advancements in this field show research being done in order to create a model-based design approach for the development of SDN applications using MDA and MDN paradigms [7], [11]. However, to the best of our knowledge, not much has been done with regards to model-based design of SDN frameworks specifically with emphasis towards security in IoT networks. The current open issue exists in developing large scale SDsec frameworks that can self-adapt to virtualized security threats at run time.

We propose a model-based approach to designing SDsec frameworks which can self-adapt using machine learning. Using a model-based approach allows us to perform design time changes to the model and reflect back these changes to the SDsec architecture at run time to mitigate security threats. This approach permits us to raise the abstraction level during the design phase of an SDN/SDSys framework providing many advantages coming from the adoption of MDE in this context [10].

We aim to achieve the aforementioned approach by first uniquely identifying classical threats from the virtualized threats in SDN networks. Existing SDN networks can then be analyzed to identify the attack vectors that are exploited in order to compromise the system. Changes to the underlying network topology often requires manual reconfiguration and respond actions of the underlying network controllers. This can be automated using a self-adaptive model using machine learning.
