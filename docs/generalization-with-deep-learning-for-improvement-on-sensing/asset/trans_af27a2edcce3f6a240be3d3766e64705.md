

无线信号在室内环境中覆盖，不仅提供通信功能，还具有传感功能，该功能在人工智能领域的发展推动下正吸引学术界和工业界研究人员的关注。WiFi 信号可以在传播过程中记录室内环境中发生的动态变化。[图1](#chap5.xhtml#fig1) 显示了 WiFi 信号在室内环境中的基本传播模型。在信号传播过程中，WiFi 信号会随着距离增加而面临信号衰减，并由于多径效应而具有时变特性。由一个发射器发送的 WiFi 信号通过多条路径传播到一个接收器，这些路径包括一条视距路径（`LoS` path）和若干反射路径。`LoS` path 表示接收器与发射器之间的最短距离。反射路径包含基于静态的反射路径和基于动态的反射路径。由墙壁、天花板和地板等静态物体引起的基于静态的反射路径在一段时间内在同一室内环境中具有稳定的距离和数量。动态物体改变传播路径的长度，称为基于动态的反射路径，可以精确描述物体的行为。研究机构利用粗粒度的 `RSSI` 和细粒度的 `CSI` 的 WiFi 测量，通过商用无线设备分析和估计人类行为。`RSSI` 和 `CSI` 的细节如下。

### 3.1.1 接收信号强度指示

`RSSI` 是来自多条传播路径的信号能量的总和，这些路径包括发射器与接收器之间的直达路径（`LoS` path），以及宏观视图中由墙壁、家具和人员引起的多条反射路径。商品化无线设备可以记录和提取 `RSSI` 数据，如路由器和智能手机。[图 2(a)](#chap5.xhtml#fig2) 显示了由一次高抛行为引起的三个天线的 `RSSI` 变化。`RSSI` 表示以分贝毫瓦（dBm）为单位的接收信号功率 [[5](#chap5.xhtml#fsr5)]:

## 3.2 CNN 和 LSTM

### 3.2.1 卷积神经网络

`CNN` 可以选择一组卷积核以最佳方式获得丰富的特征图，并自动提取空间特征来表示物体。`CNN` 的结构可分为多个学习阶段：卷积层、激活函数、池化层和全连接层 [[58](#chap5.xhtml#fsr58),[59](#chap5.xhtml#fsr59)]。卷积操作可以提取局部相关性的有用特征，使用一系列卷积核学习与任务相关的信息 [[60](#chap5.xhtml#fsr60)]。然后，卷积核的输出传递给激活函数，这将有助于学习抽象表示并在特征空间中嵌入非线性。非线性变换可以使用 `sigmoid`、`tanh`、`ReLU` 和 `ELU` 等多样化的激活函数来学习图像中的语义差异。池化层有助于压缩数据并使输入对几何变形具有鲁棒性 [[60](#chap5.xhtml#fsr60),[61](#chap5.xhtml#fsr61)]。最后，这些网络的输出由一个或多个全连接层处理，该层解释已读取的内容并将此内部表示映射到类别值。`CNN` 的重要属性是分层学习、自动特征提取、多任务处理和权重共享 [[62](#chap5.xhtml#fsr62)]。
