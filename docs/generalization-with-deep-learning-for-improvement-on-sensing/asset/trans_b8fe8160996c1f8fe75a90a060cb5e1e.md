

在无线通信中，信道状态信息反映了通信链路的信道特性。无线信号的传播受物理环境影响，导致由于信号的反射、衍射和散射而 CSI 发生变化 [[11](#chap4.xhtml#fsr11)]。
此外，现代 WiFi 模块在物理层采用正交频分复用（`OFDM`），并遵循 IEEE 802.11n/ac 标准，该标准允许多个发射和接收天线用于多输入多输出（`MIMO`）通信。这样，CSI 包含更多信息，用于描述每个发射机-接收机（`TX–RX`）对的通信链路状况。因此，CSI 揭示了无线信号的精细特征，结合了每个通信子载波上多径的时间延迟、幅度衰减和相位偏移的综合效应。与仅为多径信号叠加的 RSSI 相比，CSI 包含更多通信信息且具有更高的分辨率。在通信中，WiFi 信号可建模为频域中的信道脉冲响应 CIR *h*(*τ*)：

### 2.2 系统架构

从网卡中提取 CSI 需要特定的工具。对于商用现成（`COTS`）WiFi 接入点，有两类主要工具使用不同的硬件：

• **Intel 5300 NIC card:** Linux 802.11n CSI Tool 基于 Intel WiFi Wireless Link 5300 802.11n MIMO 收发器。该工具由定制修改的固件和面向 Linux 的开源驱动程序组成。在 20 MHz 或 40 MHZ 带宽下，它报告 30 个子载波组的信道矩阵。对于每个信道矩阵项，均分配一个复数，实部和虚部均为有符号 8 位分辨率。该工具已被广泛用于基于 CSI 的感知和定位。配备此网卡的常见设备包括迷你 PC 和笔记本电脑。

• **Atheros CSI Tool:** 它也是一个开源的 802.11n 测量工具，可实现从物理层提取 CSI、接收数据包负载和每个天线的 RSS。该工具建立在 `ath9k` 之上，`ath9k` 是支持 Atheros 802.11n PCI/PCI-E 芯片的 Linux 内核驱动程序。它理论上支持所有类型的 Atheros 802.11n WiFi 芯片组，如 `AR9590` 和 `QCA9558`，因此可从配备 Atheros 网卡的 WiFi 路由器中提取 CSI 数据。与 Intel 5300 NIC 工具不同，Atheros CSI Tool 在子载波级别提取完整的 CSI 数据，即 20MHz 下 56 个子载波，40 MHz 下 114 个子载波。子载波越多，CSI 分辨率越好。该工具已被研究用于进行占用检测 [[13](#chap4.xhtml#fsr13)]、人群计数 [[14](#chap4.xhtml#fsr14)]、活动识别 [[15](#chap4.xhtml#fsr15), [16](#chap4.xhtml#fsr16)]、手势识别 [[6](#chap4.xhtml#fsr6), [17](#chap4.xhtml#fsr17)] 和人员识别 [[18](#chap4.xhtml#fsr18)]。

这些工具有助于从网卡中提取 CSI 数据，一些基于 CSI 的感知平台也是在此基础上构建的 [[2](#chap4.xhtml#fsr2)]。在本章中，用于评估的 CSI 数据由 Atheros CSI Tool [[4](#chap4.xhtml#fsr4)] 在感知平台 [[2](#chap4.xhtml#fsr2)] 上采集。精细的 CSI 数据是精细手势识别的前提。

### 2.3 人体手势如何影响无线信号

当无线信号在室内环境中从发射机传播到接收机时，如 [Fig. 2](#chap4.xhtml#fig2) 所示，传播通常具有视距（`LOS`）路径和多条非视距（`NLOS`）路径。感知范围内任何人体活动，如行走和挥手，都可能影响这些传播路径，即通信链路，这由 CSI 数据反映并记录。自然地，主动运动对 CSI 数据的影响更大，而相对静止的运动仅导致轻微变化。直观上，我们可视化不同运动程度的 CSI 数据，并尝试找出一些规律模式。

#### 2.3.1 占用影响

最简单的情况是观察房间被占用或未被占用时 CSI 的变化。如 [Fig. 3](#chap4.xhtml#fig3) 所示，我们展示了使用一个 `TX–RX` 对、114 个子载波的七个时间戳的 CSI 幅度。值得注意的是，当人在 T3–T5 进入房间时，这些子载波的 CSI 幅度发生了很大变化。此外，当人在 T6 离开房间时，CSI 波形恢复到 T1 的状态。这些观察表明，利用 CSI 波形的相似性可以帮助判断房间是否被占用 [[13](#chap4.xhtml#fsr13)]。此外，我们可以推断多个子载波的 CSI 幅度描述了空间信息。直观上，CSI 记录了当前情况下通信链路的状态，任何改变传播路径的障碍物，如人体，都会导致 CSI 发生变化。
