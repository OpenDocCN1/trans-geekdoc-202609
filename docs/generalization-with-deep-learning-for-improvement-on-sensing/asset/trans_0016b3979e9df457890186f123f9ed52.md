

基于 WiFi 的感知利用 WiFi 信号变化来识别人类活动或更精细的占用信息 \[[2](#chap4.xhtml#fsr2)\]。当 WiFi 信号从发射器传播到接收器时，由于多径效应，信号的某些路径会受到人类活动的影响。这种信号变化反映在信道状态信息中，信道状态信息指的是通信链路的已知信道特性。CSI 数据由网络卡的特定工具提取，例如 Intel 5300 NIC \[[3](#chap4.xhtml#fsr3)\] 和 Atheros Tools \[[4](#chap4.xhtml#fsr4)\]。隐藏在 CSI 数据中的活动模式能够通过传统的统计学习或现代深度学习技术提取出来。因此，基于 WiFi 的感知技术由精确的 CSI 提取工具和先进的机器学习方法实现。

采用无线信号进行智能感知具有许多优势，尤其是在智能建筑中。首先，WiFi 接入点是室内环境中非常常见的基础设施。随着越来越多的智能电器配备 WiFi 模块进行通信，形成了许多 WiFi 通信链路，这为人类活动识别提供了大量 CSI 数据。利用现有基础设施具有成本效益。其次，与 IMU 相比，无线信号使感知无需设备，这对用户来说很方便。第三，与红外传感器和射频信号相比，CSI 数据包含高分辨率信号数据，通过类似图像的二维矩阵描绘空间和时间状态。因此，基于 WiFi 的感知可用于精细的人类活动识别、手势识别甚至呼吸检测。如 [Fig. 1](#chap4.xhtml#fig1) 所示，与其他侵入性和非侵入性感知方法相比，基于 WiFi 的感知方法更具成本效益，但具有较高的感知粒度。

如上所述，机器学习的开发提高了分类模型的性能，并使更精细的基于 WiFi 的感知应用成为可能。深度神经网络能够从 CSI 数据中自动提取鲁棒的表示并通过反向传播获得准确的分类器 \[[5](#chap4.xhtml#fsr5)\]。然而，为了处理实际场景中的无线信号，典型的深度模型仍然存在一些局限性。例如，深度网络需要大规模的标注训练数据，其收集耗时且劳动密集。如何解决缺乏足够训练数据的问题需要进一步研究。另一个例子是深度模型具有很强的拟合能力，但经常过拟合现有数据，导致泛化能力不令人满意。如何增强深度模型的适应性也仍然是一个挑战。

在本章中，我们介绍了一种基于 CSI 的手势识别方法，在真实场景中，当训练一次的深度模型部署到新环境时 \[[6](#chap4.xhtml#fsr6)\]。由于无线信号对环境变化非常敏感，在一个房间训练的深度模型通常由于两种情况之间的数据分布差异而无法在新房间中工作。在实际应用中，假设我们已在工厂收集了大量数据并获得了训练良好的模型，当我们在新环境中应用该模型，例如用户家中时，如何以少量工作量将模型适应新环境？如何提高系统在空间和时间动态下的可移植性和鲁棒性？本章介绍的方法依赖于域适应来解决这个问题。域适应是指将知识从标签丰富的源域转移到标签稀缺甚至未标记的目标域 \[[7](#chap4.xhtml#fsr7)\]。在我们的场景中，识别模型在一个房间中训练，即源域，并适应新房间，即目标域。

域适应在计算机视觉和神经语言处理中发挥着重要作用。由于训练数据集可能特定于域，例如仅由一个国家图像组成的数据集，域适应以无监督的方式将训练一次的模型适应新环境，例如其他国家。它通常最小化两个域数据的分布差异，或利用先进的对抗训练为分类器生成域不变特征空间 \[[8](#chap4.xhtml#fsr8)\]。在我们的场景中，我们引入了一种新颖的对抗域适应方法，仅使用新环境中的未标记数据来适应基于 CSI 的感知模型。通过对抗训练，作为特征提取器的深度神经网络可以自适应地从目标域提取鲁棒的 CSI 模式，从而带来显著改进 \[[6](#chap4.xhtml#fsr6)\]。

在后续章节中，我们首先从初步介绍开始，详细介绍 CSI 数据的特性、CSI 数据如何随人类活动变化以及哪些 WiFi 系统可用于感知。然后我们讨论用于基于 CSI 的手势识别的基本深度神经网络以及用于模型迁移的对抗域适应。进行了大量实验以证明该方法的优越性。在讨论了最近的深度学习方法如何与基于 WiFi 的感知集成后，我们在最后一小节总结了整章内容。

## 2. Preliminaries

在无线通信中，接收信号强度指示 RSSI 和信道状态信息 CSI 是物理层环境感知两种有用的信息。RSSI 是一个标量值，表示无线信号的信号强度，因此 RSSI 仅用于室内定位、占用检测或其他粗略活动识别。而 CSI 是更精细的数据，描述通信质量。Wang *et al*. 建立了 CSI 相位信息与物体移动速度之间的理论模型 \[[9](#chap4.xhtml#fsr9)\]，然后采用菲涅尔区的理论进行人体呼吸检测 \[[10](#chap4.xhtml#fsr10)\]。这些物理模型是可解释的，并启发我们基于它们开发识别方法。然而，在现实世界中，环境复杂且许多无关信号干扰感知信号，这阻碍了这些物理模型的可行性。与它们不同的是，为了在复杂情况下建模 CSI 模式，我们引入基于深度学习的数据驱动模型。因此，我们首先研究我们数据的特性——CSI 是什么以及 CSI 如何被提取。为了使用该深度学习模型，我们需要展示 CSI 模式如何与人类活动或手势相关联。
