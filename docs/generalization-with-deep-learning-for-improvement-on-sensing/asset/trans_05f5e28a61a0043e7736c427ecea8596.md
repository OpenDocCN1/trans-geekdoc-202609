### 2.2 使用 ConvNets 建模长期动态

建模长期时间动态在动作识别中起着重要作用。最近已对解决此问题做出了一些尝试 [[28](#chap2.xhtml#fsr28), [32](#chap2.xhtml#fsr32), [36](#chap2.xhtml#fsr36), [37](#chap2.xhtml#fsr37)]。例如，在文献 [[28](#chap2.xhtml#fsr28)] 中，使用动态模型如循环神经网络在特征序列上学习了长程时间依赖关系。虽然他们提出了结合 `ConvNets` 和 `RNNs` 的端到端模型，但时间动态仅使用高层感知进行建模，导致最终性能较差。在文献 [[36](#chap2.xhtml#fsr36)] 中提出了涉及 100 帧的光流的长期时间卷积。最近，Wang *et al*. [[32](#chap2.xhtml#fsr32)] 提出了一种网络模型，该模型从稀疏时间片段中获取分数共识，并在 `UCF-101` 和 `HMDB` 数据集上显示出改进的性能。大多数上述方法存在两个主要缺点：（i）时间信息仅通过在稀疏采样的时间片段上简单地评估网络来粗略建模；（ii）共识是在网络的顶层构建的（通常通过最终分数），忽略了深层 `ConvNet` 不同层中存在的低层特征之间的局部关系。

与这些方法不同，我们认为分层利用低层特征图之间的时间交互对于提高动作识别方法的性能很重要，并提出了一种新颖的方法，该方法采用长视频并从对多个片段应用同一滤波器产生的多个特征图中池化时间信息。当以分层方式进行时，我们捕获动作视频中存在的长程、高阶动态。我们的方法与文献 [[37](#chap2.xhtml#fsr37)] 中提出的分层秩池化方法有一些相似之处。然而，我们在多方面与文献 [[37](#chap2.xhtml#fsr37)] 存在显著差异。我们的方法使用应用于外观和光流通道的深度 `ConvNet` 架构，并且可以与任何通用目的聚合函数一起使用。我们在层次结构的每个层级中采用更深的 `ConvNets` 来学习高层感知和用于动作识别的判别信息，而文献 [[37](#chap2.xhtml#fsr37)] 中的方法使用浅层视频表示方法在时间上聚合信息。我们在 [Section 4](#chap2.xhtml#s4) 中展示的分层聚合特征导致了更优的结果。

### 3. 分层聚合 CNN 模型

[Figure 1](#chap2.xhtml#fig1) 给出了我们的 `HACNN` 模型的概述。层次结构由多个层级组成，其中每个层级由一个 `subConvNet`、一个聚合函数和一个正则化函数定义。在最低层级，模型从多个时间片段获取输入，通过共享相同参数的 `subConvNets` 处理它们，并为每个片段生成特征图。聚合函数池化多个时间片段中存在的判别特征，并在更少的特征图集合上进行整合。这在层次结构的每个层级重复。最终层产生每个动作标签的概率。

![figure](images/p36-1.jpg)

**Figure 1:**Illustration of HACNNs model. HACNN processes the video in a hierarchical manner. Input to HACNN consists of multiple disjoint snippets from an action video. At each level, the input video snippets or feature maps are processed via multiple parallel *subConvNets* (deep ConvNets that share the same parameters) followed by an aggregation and regularization function (*G* ![figure](images/in36-1.png) *R*). This produces feature maps for the next level of hierarchy. The output of our HACNN is a *C* dimensional vector of scores indicating the probability of belonging to a particular action class *c* ∈ {1,…, *C*}.

在本节中，我们介绍了本章的主要贡献。在 [Section 3.1](#chap2.xhtml#s3-1) 中，我们概述了 `HACNN` 模型。`HACNN` 的各个组件，即 `subConvNet`、聚合函数和正则化函数，分别在 [Sections 3.2](#chap2.xhtml#s3-2)–[3.4](#chap2.xhtml#s3-4) 中进行解释。学习 `HACNN` 模型参数的反向传播步骤在 [Section 3.5](#chap2.xhtml#s3-5) 中给出。
