

近期基于学习的调研可分为两类：一类 [[18](#chap5.xhtml#fsr18)–[20](#chap5.xhtml#fsr20)] 是从原始活动数据中提取有效特征，利用经典分类算法识别活动；另一类 [[21](#chap5.xhtml#fsr21)–[23](#chap5.xhtml#fsr23)] 是设计深度学习模型以捕捉原始活动数据的更有效信息，从而提高不同场景下人体活动识别的鲁棒性。 [Table 1](#chap5.xhtml#tab1) 列出了关于基于 WiFi 感知的相关研究在识别方法、测试人员/场景、活动类型、样本量和准确率方面的情况。

在单一室内环境中，研究 [[19](#chap5.xhtml#fsr19),[20](#chap5.xhtml#fsr20),[24](#chap5.xhtml#fsr24)] 使用分类算法可利用提取的时间域和频域特征对人体活动识别取得令人满意的结果，这些特征包含广泛使用的 CSI 幅度方差、CSI 相位差、信号熵、多普勒频移和频率分量。上述特征采用基于人工的方式，受研究者对采集活动数据的主观性限制。此外，在特定室内环境中针对特定个体训练的模型，在应用于预测另一室内环境中另一个体的活动时通常效果不佳。

为研究这两个问题，研究人员利用深度学习算法 [[25](#chap5.xhtml#fsr25)–[29](#chap5.xhtml#fsr29)]，该算法可以学习原始活动数据的时间域特征和空间信息以识别活动。例如，所提出的 `EI` 框架 [[25](#chap5.xhtml#fsr25)] 使用深度学习模型去除活动数据中包含的特定环境和个体的信息，并提取在不同个体、不同环境下采集的活动数据共有的环境/个体无关特征。

使用精密设备获得的高质量活动数据是上述研究的关键，然而，这一限制阻碍了基于 WiFi 的研究在室内环境中的广泛应用。所提出的基于衍射的感知模型 [[29](#chap5.xhtml#fsr29)] 定量确定个体运动的信号变化，并从信号传播模型角度解释相应的关系。

深度学习模型不仅捕捉到人体活动更丰富的 data representation，而且根据上述分析提高了基于 WiFi 的人体活动识别的准确率。我们希望设计一个深度学习模型以减少人体活动识别中个体间的准确率差异。与工作 [[25](#chap5.xhtml#fsr25)] 相比，我们关注个体而其关注环境。在技术层面，我们问题的难度更易，但该问题对于家庭级室内环境非常重要。我们不像之前的工作那样去除干扰因素，而是专注于利用时空模型保持个体稳定识别准确率的各种活动的共享特征。

解决该问题的挑战是如何选择和确定深度学习结构所需的问题，以对应时空特征学习。在本章中，我们提出了一种名为 `LCED` 的 `LSTM-CNN Encoder–Decoder` 模型，以减少人体活动识别中个体间的准确率差异。基于 `LSTM` 的编码器将 WiFi 信号的时间序列编码为固定维度的灰度表示。输入和输出长度不一致的问题以及时间学习依赖性问题得以解决。基于 `CNN` 的解码器将不同的灰度表示解码为活动的类别。`LCED` 模型的编码器和解码器联合训练，以最大化给定源标签的目标标签向量的条件概率。
