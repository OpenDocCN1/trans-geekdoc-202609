# 地球科学深度学习的展望

Gustau Camps-Valls

`http://isp.uv.es` and `@isp_uv_es`

**Abstract**

机器学习，特别是深度学习（DL），对许多科学领域产生了巨大影响。在过去十年中，先进的深度学习方法被开发并广泛应用于地球数据科学问题。分类和参数检索方面的应用产生了差异：方法非常准确，能够处理大量数据并有效地处理空间和时间数据结构。然而，仍有若干重要挑战需要解决。当前标准的深度架构在无监督方式下学习有用的地球特征表示方面存在困难，并且难以处理长程依赖，因此无法捕捉空间和时间上遥远的驱动过程，并且无法有效地处理非欧几里得空间。DL模型仍然晦涩且难以解释，而且与其他数据驱动技术一样，它们不一定学习到物理上有意义的，更重要的是因果关系。需要取得进展以应对任意信号结构和数据关系、物理合理性和可解释性。本章回顾了当前的方法并讨论了在所有这些方向上为地球科学开发新的DL方法的思路。

**Keywords:** deep learning, learning representations, hybrid machine learning, interpretability, causality, remote sensing, geoscience, Earth system science
