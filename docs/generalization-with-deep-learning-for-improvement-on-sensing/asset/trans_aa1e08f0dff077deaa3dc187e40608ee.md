#### 3.3 Motivation and solution
之前的工作利用机器学习算法和深度学习算法来提高人体活动识别的准确性。人体活动识别的准确性对于不同个体甚至同一室内环境中的同一个体都存在不稳定性。基于该问题，我们设计了一种基于 CNN 和 LSTM 的深度学习模型，以提高个体在人体活动识别上的准确性稳定性。注意，本章中我们强调的是关于人体活动识别准确性的个体间差异，而不是室内环境间的差异。

- 同一个体的准确性差异。同一活动的采集活动数据相对于信号模式在不同时间会因信号传播而略有变化。活动引起的信号模式的细微变化增加了该活动在人体识别准确性上的不稳定性。使用机器学习算法进行同一个人活动识别的准确性差异在 5% 到 10% 之间。类似研究 [[66](#chap5.xhtml#fsr66)] 利用深度学习算法将差异降低到 3% 到 7% 之间。该结果无法达到日常生活实际应用的需求。为了解决该问题，我们设计了 LSTM-CNN 编码器-解码器模型以减少活动识别准确性的泛化误差。与类似研究 [[66](#chap5.xhtml#fsr66)] 相比，我们增加了三层卷积层和两层全连接层，以从原始活动数据中学习更有效的信息。

- 不同个体之间的准确性差异。每个个体在执行活动过程中都有独特的行為习惯。行为习惯由速度、强度和人体特征组成。速度和强度因素影响信号模式在频率、信号变化速度和信号波动方面的表现，除信号变化趋势外。换句话说，识别不同个体执行相同活动的关键在于依赖信号变化的趋势。基于上述分析，我们设计了一种新颖的网络结构来实现时序数据中的全局特征，而非局部特征。

为了解决上述两个问题，基于 LSTM 的编码器和基于 CNN 的解码器构成了所提出的 LCED。类似研究 [[67](#chap5.xhtml#fsr67)] 开发了一种自编码器长短期循环卷积网络，其侧重于使用压缩的固有时间特征进行人体活动识别，但它忽略了数据的空间特征。考虑到 CSI 信号是空间和时间的叠加，我们使用 LSTM 来提取时间特征，它可以有效地提取长依赖关系并压缩数据。此外，我们还通过采用 CNN 来捕捉局部信息以利用空间特征用于模型学习，并且可以在一定程度上消除空间中障碍物反射的噪声。因此，结合空间和时间特征可以减少环境噪声以降低个体识别差异。本章中，我们主要设计了一种名为 LCED 的新颖神经网络模型，用于学习时序信号数据。LCED 模型由基于 LSTM 的编码器和基于 CNN 的解码器组成，以增强学习能力并减弱人体活动识别中个体间的准确性差异。

### 4. LCED Neural Network
为了提高多类活动在不同个体下的鲁棒性和通用性，我们提出了一种名为 LCED 的新颖编码器-解码器模型。LCED 模型的架构描述于 [Figure 4](#chap5.xhtml#fig4)，它包含 12 层，包括 LSTM 层、卷积层和全连接层。首先，原始信号数据被作为编码器的输入以提取固定的特征向量。然后，该向量被转换成语义图像。最后，CNN 提取并分类图像的空间特征。设计 LCED 模型的思想基于以下原则：(i) 根据 PCA 技术可视化，不同的活动在空间中具有不同的聚类，并且特征图像呈现产生活动间的多样化强度分布。(ii) LCED 的编码器部分能够学习时序表示并能够使用非线性变换将其编码为固定长度向量。更重要的是，与基于手工方式的原始方法相比，所提出的模型可以从原始信号中自动提取固定长度特征向量，能够自适应地提取特征并压缩对应于个体和活动差异的关键信息。(iii) 解码器部分基于 CNN，可以有效地基于空间分布捕捉图像的局部特征并具有更好的分类准确性。总的来说，所提出的模型由于自适应时空特征提取而具有更好的鲁棒性和更强的泛化能力。
