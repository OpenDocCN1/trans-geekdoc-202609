## 3.2 迈向非平稳扩展网络

深度学习方法传统上分为空间学习（例如，用于目标检测和分类的卷积神经网络）和序列学习（例如，预测和预报）。目前，对融合这两种方法产生了越来越大的兴趣。毕竟，地球数据可以被视为随时间演化的空间结构：天气预报或飓风追踪就是明显的例子。我们面临的是随时间演化的多维结构，例如 Reichstein *et al*. \[[5](#chap7.xhtml#fsr5)\] 中指出的有组织的降水对流和植被状态。研究开始将组合的卷积-循环深度网络应用于降水即时预报或极端天气预报等。例如，对大气和海洋传输、野火、土壤或冰运动以及植被动态的建模是时空动力学很重要的其他典型问题。这是 DL 擅长的自然场景；利用海量数据中的空间和/或时间规律。然而，当前方法仍需解决处理长程现象、非平稳和非欧几里得过程以及不确定性量化与误差传播的问题。

### 3.2.1 新架构和算法

即使空间和时间被一起考虑，模型所查看的邻域也相当有限。卷积和记忆单元在构造上是具有有限脉冲响应函数的滤波器。一方面，由于梯度消失/爆炸问题，循环和 LSTM 网络无法记住更长的句子和序列。目前有多种架构试图解决神经网络的近视问题。

一种有前景的架构将标准卷积网络与神经科学中的人类注意力机制相结合：所谓的 *attention deep learning networks* 可以查看驱动局部窗口中过程和激活的远距离区域的信息。注意力网络在分类问题中表现出色，其中目标的显著模式由远距离区域的活动触发。该思想也在自然语言处理领域得到发展，出现了名为 *transformers* \[[20](#chap7.xhtml#fsr20)\] 的网络，它们利用自注意力和聚焦的循环有效地解决了序列转导问题。Transformer 受限于查看有限范围，但最近所谓的 *reformers* 承诺打破长程依赖问题。

另一方面，也许更重要的是，在地球科学中，人们通常获取并处理的是网格化数据（要么是因为数据来自模型模拟，要么是通过 *ad hoc* 插值），但这往往只是为了方便而进行的理想化，因为原始数据是稀疏的、不连续的且不一定是平稳的。这些特殊性要求模型能够在非欧几里得域（如图和流形）上工作。定义在图和流形上的 DL 很复杂，主要是因为数据的非欧几里得特性使得基本运算（如卷积）的定义相当难以捉摸。几何 DL \[[21](#chap7.xhtml#fsr21)\] 将这些深度学习运算扩展到图上，但尚未被自然地用于处理地球系统科学问题中如此丰富的图/流形数据。

### 3.2.2 贝叶斯深度学习

从数据集中提取的特征被给出为点估计，并且没有捕捉到模型对其估计的置信度有多大。这与概率模型形成对比，概率模型允许对模型置信度进行推理，但通常计算成本很高。贝叶斯深度学习（BDL）最早在 1990 年代提出，并由 MacKay 和 Neal 深入研究，通过推断模型权重上的分布为深度学习模型提供概率解释。这些模型对过拟合具有鲁棒性，提供不确定性估计，并且可以从小到中等规模的数据集中学习。是的，在地球科学中，我们经常遇到小而稀疏（但高维）的数据问题，例如来自耗时、人员和采集难度大的地面实测活动的数据。

变分推断的最新进展也为深度网络的概率处理带来了巨大进步；这些方法不仅在数学上是坚实的，而且在计算上高效且实用。然而，这些模型在地球科学中尚未得到广泛应用，而鉴于不确定性传播和量化的相关性，它们本可以得到广泛采用。只有一些用于参数检索的深度高斯过程应用值得一提 \[[22](#chap7.xhtml#fsr22)\]。

## 3.3 混合建模：深度学习遇见物理

过程理解被编码在机制模型中，并传统上主导着我们的科学事业。实际上，物理建模和机器学习长期以来常被视为完全不同且不可调和的领域；科学家应坚持理论驱动或数据驱动的方法。然而，这些方法确实是互补的：物理方法在构造上可解释并允许超出观测空间的外推，而数据驱动方法对数据高度灵活且适应性强。它们的协同作用最近在地球科学中引起了关注。交互可以是多样的。我们坚信，地球科学中机器学习的进步以及观测和模拟能力为即将到来的地球科学提供了一个整合议程的机会，并且确实存在许多可能的方法。

### 3.3.1 改进参数化

物理模型需要设置参数，这些参数很少能从第一性原理（领域原理）推导出来。ML 和特别是 DL 可以学习此类参数化。例如，而不是在地球系统模型中对植物功能类型经验性（有时甚至任意地）分配植被参数，可以允许这些参数化通过 ML 从代理协变量中学习，从而允许一定的灵活性、适应性、动态性和上下文依赖性。

### 3.3.2 代理建模和仿真

在地球科学、气候科学和遥感中仿真模型正变得越来越流行。仿真器是 ML 模型，它们使用少量但具有代表性的模拟数据集来模仿正向物理模型。训练完成后，仿真器可以提供快速的正向模拟，这反过来又允许改进模型反演和参数化。然而，用 DL 模型替代物理模型需要先离线进行昂贵的评估，并且存在替代方案，即迭代地构建模型并选择适当的模拟。该主题与主动学习和贝叶斯优化相关，这可能进一步建模复杂代码，例如气候模型组件 \[[23](#chap7.xhtml#fsr23)\]。
