

我们的 HACNN 模型在层次结构中包含若干层级。每个层级都配备有一个独特的 subConvNet 函数。我们在每个层级选择 subConvNet 函数 `F` 时考虑深度 ConvNets，因为它们在计算机视觉问题中已被证明具有优越的性能。更具体地说，subConvNet 由多个卷积、`Relu`、池化和 Batch Normalization 层组成，并基于 Ref. [[27](#chap2.xhtml#fsr27)] 中提出的 BN-Inception 深度 ConvNet 设计。第一层的 subConvNet，`F[1]`，接收原始数据（`RGB` 或光流）作为输入，并通过若干个（`Convolution+Batch Normalization+ReLu` CBR）模块和池化层处理，随后是八层 inception 模块。中间层级的 subConvNets `F[l]`，`1 < l < L` 从低层获取判别性特征图并通过若干层 inception 模块进一步处理。层次结构最后一层的 `F[L]` 由一个全局池化层、一个 dropout 层组成，所有实验中 dropout 比率设为 0.8，随后是 `1 × 1` 卷积以给出最终预测。一般来说，具有更多层次结构层级可以对视频中的更长、更复杂的动态进行建模。然而，这也导致过拟合风险更高。我们经实验证实，具有三层层次结构可以获得令人满意的结果并优于当前最先进的方法。其他架构选择的比较研究可在实验 [Section 4](#chap2.xhtml#s4) 中找到。

### 3.3 聚合函数

通常，各种编码方法，如 BOW [[38](#chap2.xhtml#fsr38)]、Fisher vector [[39](#chap2.xhtml#fsr39)]、bilinear models [[40](#chap2.xhtml#fsr40)]、rank pooling [[37](#chap2.xhtml#fsr37)] 可集成到 HACNN 中。然而，它们以丢失丰富的空间信息为代价。在此，我们提出使用聚合函数从多个时间段汇聚信息，同时仍保留来自空间布局的结构信息。考虑从 subConvNet `F[l]` 获得的特征图集合 `f` = {`f[l,1]`, `f[l,2]`,…, `f[l,T]}`}，其大小为 `f ∈ R^(h[l]×w[l]×d[l])`，其中 `T[l]`、`h[l]`、`w[l]` 和 `d[l]` 分别表示层级 `l` 处特征图的时段数、高度、宽度和深度（滤波器数）。聚合函数 `G[l]` 以特征图 `f[l]` 为输入并将其编码为带段的新特征图集合。通过约束范围，我们期望学习到比 `f[l]` 更紧凑且更具判别性的表示。这也降低了整体计算复杂度。更正式地，聚合函数 `G` 可表述为
