

模式匹配方法寻找对应于某一类别的唯一信息并将唯一信息映射到待检测对象，以检测、识别和估计目标对象。早期研究使用模式匹配方法来识别人类行为 [[4](#chap5.xhtml#fsr4), [7](#chap5.xhtml#fsr7), [13](#chap5.xhtml#fsr13), [15](#chap5.xhtml#fsr15)–[17](#chap5.xhtml#fsr17), [41](#chap5.xhtml#fsr41)]。WiGest [[4](#chap5.xhtml#fsr4)] 从原始信号数据中提取三个基本原语（上升沿、停顿和下降沿），并将这三个原语转换为字符串序列：上升沿转换为正号，下降沿转换为负号，停顿转换为零。然后将提取的字符串序列与预定义的姿势模板进行比较以找到最佳匹配。WiSee [[13](#chap5.xhtml#fsr13)] 计算手势引起的反射信号的多普勒频移作为唯一模式以匹配一个手势，因为人类活动速度的变化不会改变正负频移的模式。递增的正多普勒频率对应于手势加速，递减的正多普勒频率对应于手势减速。对应于手势的多普勒频率剖面可能仅由正多普勒频移的模式组成、仅由负多普勒频移的模式组成以及同时包含正负多普勒频移的模式组成。吸烟是一种有节奏的复合行为，包含六个动作（拿起、举起、吸入、放下、吸气和呼气）按一定顺序进行，这使得吸烟行为有别于日常活动，如举起或放下手臂。基于该特性，Smokey 系统 [[17](#chap5.xhtml#fsr17)] 利用节奏/顺序信息来识别吸烟行为。

根据上述研究的分析，模式匹配方法的挑战在于找到并提取能够有效表示目标对象的唯一模式信息。然而，由于 WiFi 信号的时变特性、多径效应、频率选择性衰落，反射自人类活动的接收信号无法保持稳定条件。因此，找到并提取人类活动更有效的数据表示对于基于 WiFi 的人类活动识别是必要的。

### 2.2 基于学习的活动识别

基于学习的活动识别根据学习特性和数据规模要求分为浅层学习（分类算法）和深度学习。浅层学习算法以人工方式从原始活动数据中提取有效特征来训练模型，然后利用训练好的模型识别活动。深度学习算法可以自动学习原始活动数据的有效数据表示以检测、识别和估计人类活动。用于基于 WiFi 的活动识别的学习算法有决策树（DT）、朴素贝叶斯（NB）、动态时间规整（DTW）、随机森林（RF）、k 近邻（kNN）、支持向量机（SVM）、隐马尔可夫模型（HMM）、卷积神经网络（CNN）、循环神经网络（RNN）、长短期记忆网络（LSTM）和生成对抗网络（GANs） [[6](#chap5.xhtml#fsr6), [8](#chap5.xhtml#fsr8), [25](#chap5.xhtml#fsr25), [33](#chap5.xhtml#fsr33), [30](#chap5.xhtml#fsr30), [36](#chap5.xhtml#fsr36), [34](#chap5.xhtml#fsr34), [42](#chap5.xhtml#fsr42)]。WiFall 系统 [[6](#chap5.xhtml#fsr6)] 在时域中提取七个统计特征，使用单类 SVM 算法检测单次跌倒。所开发的 RT-Fall 系统 [[30](#chap5.xhtml#fsr30)] 考虑时频域的有效信息以检测和识别跌倒行为。由于 WiFi 信号的传播特性，使用浅层学习的基于 WiFi 的活动识别无法将设计的系统迁移到新个体和新环境。研究人员尝试利用深度学习模型的强大学习能力来提高活动识别的鲁棒性。几项研究 [[20](#chap5.xhtml#fsr20), [22](#chap5.xhtml#fsr22), [23](#chap5.xhtml#fsr23), [54](#chap5.xhtml#fsr54), [31](#chap5.xhtml#fsr31), [25](#chap5.xhtml#fsr25)] 探索如何选择神经网络结构来构建新型网络模型以实现鲁棒感知系统。这些新型深度模型帮助研究人员解决同时定位和活动识别 [[20](#chap5.xhtml#fsr20)]、增加样本规模 [[22](#chap5.xhtml#fsr22)]、利用无线信号构建人体骨架以穿墙感知物体 [[54](#chap5.xhtml#fsr54)]、提高从样本级到数据点级的感知粒度能力 [[31](#chap5.xhtml#fsr31)] 以及减弱室内环境差异 [[25](#chap5.xhtml#fsr25)]。此外，浅层学习算法与深度学习算法的结合作为一种新的学习视角吸引了多位研究人员的关注。例如，Shi 等人 [[26](#chap5.xhtml#fsr26)] 从 CSI 测量中提取代表性特征作为 DNN 的输入以准确识别每个个体。上述研究证明了使用深度学习模型的基于 WiFi 的人类活动识别优于模式匹配方法。

### 2.3 基于模型的活动识别

基于模型的人类活动识别是通过基于物理理论的理论模型 [[45](#chap5.xhtml#fsr45), [29](#chap5.xhtml#fsr29), [55](#chap5.xhtml#fsr55), [56](#chap5.xhtml#fsr56), [39](#chap5.xhtml#fsr39)] 或基于经验测量的统计模型 [[18](#chap5.xhtml#fsr18), [55](#chap5.xhtml#fsr55)] 来发现信号模式与活动之间的关系。WiFi 信号的理论模型包含菲涅尔区模型 [[45](#chap5.xhtml#fsr45), [29](#chap5.xhtml#fsr29)]、多径衰落 [[56](#chap5.xhtml#fsr56)] 和相位偏移 [[39](#chap5.xhtml#fsr39)]，可以分析人类行为的属性然后识别人类行为。通过在菲涅尔区内使用衍射模型和在菲涅尔区外使用反射模型，研究 [[29](#chap5.xhtml#fsr29)] 可以量化信号传播在距离、多径和动态水平方面的原理。然而，该研究仅解释了在稳定室内环境中简单行为引起的信号变化。对于基于经验测量的统计模型，它通过统计指标发现并确定数据变化规律。CARM 系统 [[18](#chap5.xhtml#fsr18)] 旨在基于经验测量构建统计模型以降低训练样本成本。它建立了 CSI-速度模型来估计 CSI 变化与人类运动速度之间的相关性，并建立了 CSI-活动模型来确定人体各部位运动速度与特定活动之间的关系。这两个模型可以推断并构建 CSI 变化与特定活动之间的统计模型。然而，统计模型需要高质量数据，而商用 WiFi 设备无法满足。

总之，浅层学习算法只能实现简单有效的信息以满足基本需求。深度学习模型可以挖掘更有效的信息以满足实际应用中 WiFi 感知的较高需求，然而，与浅层学习算法相比，其性能提升没有有效的解释。理论模型可以利用信号传播原理来理解和提取用于感知活动的关键信息，但需要精密设备和高质量数据。本章重点关注新型设计的深度学习模型以提高人类活动识别的鲁棒性和准确性。
