# **Algorithm 6** Contrastive Explanations Method (CEM).

```
**Input:** example \( (x_0, t_0) \), neural network model \( \mathcal{N} \), and (optionally \( (y > 0) \)) an autoencoder \( AE \)
1) Solve (19.1) and obtain
\( \delta^\text{neg} \leftarrow \text{argmin}_{\delta \in \mathcal{X}/x_0} c \cdot f_k^\text{neg}(x_0, \delta) + \beta \|\delta\|_1 + \|\delta\|_2^2 + \gamma \| x_0 + \delta - \text{AE}(x_0 + \delta) \|_2^2 \).
2) Solve (19.3) and obtain
\( \delta^\text{pos} \leftarrow \text{argmin}_{\delta \in \mathcal{X} \cap x_0} c \cdot f_k^\text{pos}(x_0, \delta) + \beta \|\delta\|_1 + \|\delta\|_2^2 + \gamma \|\delta - \text{AE}(\delta) \|_2^2 \).
**return** \( \delta^\text{pos} \) and \( \delta^\text{neg} \).
## Contrastive Explanation: Input \( x_0 \) is classified as class \( t_0 \) because features \( \delta^\text{pos} \) are present and because features \( \delta^\text{neg} \) are absent.
```

we aim at finding an interpretable perturbation \( \delta \in \mathcal{X} \cap x_0 \) such that after removing it from \( x_0 \), \( \text{arg max}_i[\text{Pred}(x_0)]_i = \text{arg max}_i[\text{Pred}(\delta)] \); that is, \( x_0 \) and \( \delta \) will have the same top-1 prediction class \( t_0 \), indicating that the removed perturbation \( \delta \) is representative of the model prediction on \( x_0 \). Similarly to finding pertinent negatives, we formulate finding pertinent positives as the following optimization problem:

```
\(\text{min}_{\delta \in \mathcal{X} \cap x_0} c \cdot f_k^\text{pos}(x_0, \delta) + \beta \|\delta\|_1 + \|\delta\|_2^2 + \gamma \|\delta - \text{AE}(\delta) \|_2^2,\) (19.3)
```

where the loss function \( f_k^\text{pos}(x_0, \delta) \) is defined as

```
\( f_k^\text{pos}(x_0, \delta) = \text{max}\{ \text{max}_{i \neq t_0}[\text{Pred}(\delta)]_i - [\text{Pred}(\delta)]_{t_0}, -\kappa \}.\) (19.4)
```

In other words, for any given confidence \( \kappa \geq 0 \), the loss function \( f_k^\text{pos} \) is minimized when \( [\text{Pred}(\delta)]_{t_0} \) is greater than \( \text{max}_{i \neq t_0} [\text{Pred}(\delta)]_i \) by at least \( \kappa \).

_Algorithmic details._ A projected fast iterative shrinkage-thresholding algorithm (FISTA) (Beck and Teboulle, 2009) is applied to solve problems (19.1) and (19.3). FISTA is an efficient solver for optimization problems involving \( \ell_1 \) regularization. Take pertinent negative as an example, assume \( \mathcal{X} = [-1, 1]^p \) and \( \mathcal{X}/x_0 = [0, 1]^p \), and let \( g(\delta) = f_k^\text{neg}(x_0, \delta) + \|\delta\|_2^2 + \gamma \| x_0 + \delta - \text{AE}(x_0 + \delta) \|_2^2 \) denote the objective function of (19.1) without the \( \ell_1 \) regularization term. Given the initial iterate \( \delta^{(0)} = \mathbf{0} \), projected FISTA iteratively updates the perturbation \( I \) times by

```
\(\delta^{(k+1)} = \Pi_{[0, 1]^p} \{ S_b(y^{(k)} - \alpha_k \nabla g(y^{(k)})) \},\) (19.5)
```

```
\( y^{(k+1)} = \Pi_{[0, 1]^p} \{ \delta^{(k+1)} + \frac{k}{k+3} (\delta^{(k+1)} - \delta^{(k)}) \},\) (19.6)
```
