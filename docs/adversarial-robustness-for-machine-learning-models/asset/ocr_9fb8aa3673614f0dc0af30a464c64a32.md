# 2.2 Formulating attack as constrained optimization

Given the original example x0, an adversarial attack aims to find an adversarial example x* = x0 + \Delta that can successfully achieve the attack goal (either targeted or untargeted attack) under the constraint that \Delta should be small. This can be formulated as a constrained optimization problem: we aim to find an adversarial example x that maximizes the "attack successfulness" (or minimizes the attacker’s loss function), whereas x is constrained to be close to the original example x0. This can be mathematically written as the following problem:

```
argmax_x g(x) s.t. x \in B(x_0), (2.1)
```

where g(x) measures the successfulness of the attack, and B(x0) is a small region around x0 indicating the feasible perturbation range.
