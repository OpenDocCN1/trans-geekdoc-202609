where \(\Pi_{[0,1]^p}\) denotes the vector projection onto the set \(\mathcal{X}/\boldsymbol{x}_0 = [0, 1]^p\), \(\alpha_k\) is the step size, \(\boldsymbol{y}^{(k)}\) is a slack variable accounting for momentum acceleration with \(\boldsymbol{y}^{(0)} = \boldsymbol{\delta}^{(0)}\), and \(S_\beta : \mathbb{R}^p \mapsto \mathbb{R}^p\) is an elementwise shrinkage-thresholding function defined as

\([S_\beta(\boldsymbol{z})]_i = \begin{cases} z_i - \beta & \text{if } z_i > \beta, \\ 0 & \text{if } |z_i| \le \beta, \\ z_i + \beta & \text{if } z_i < -\beta \end{cases} \quad (19.7)\)

for \(i \in \{1, \dots, p\}\). The final perturbation \(\delta^{(k^*)}\) for pertinent negative analysis is selected from the set \(\{\delta^{(k)}\}_{k=1}^l\) such that \(f_k^{neg}(\boldsymbol{x}_0, \delta^{(k)}) = 0\) and \(k^* = \arg \min_{k \in \{1, \dots, l\}} \beta \|\delta\|_1 + \|\delta\|_2^2\). A similar projected FISTA optimization approach is applied to pertinent positive analysis.

Eventually, as seen in Algorithm 6, both the pertinent negative \(\delta^{neg}\) and the pertinent positive \(\delta^{pos}\) obtained from the optimization methods are used to explain the model prediction. The last term in both (19.1) and (19.3) will be included only when an accurate autoencoder is available; otherwise, \(\gamma\) is set to zero.
