Given a semantic attack threat model, Semantify-NN designs the corresponding semantic perturbation layers (SP-layers) and inserts them to the input layer of the original network for verification. With SP-layers, Semantify-NN can use any \(\ell_p\)-norm-based verification method for verifying semantic perturbations.
