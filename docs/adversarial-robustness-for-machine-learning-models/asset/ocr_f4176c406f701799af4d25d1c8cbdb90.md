Spurred by that, the design of \(\mathbf{u}^{(k)} = (\mathbf{m}^{(k)}, \boldsymbol{\delta}^{(k)})\) can be cast as the following optimization problem:

where \(\hat{\mathbf{x}}(\mathbf{m}, \boldsymbol{\delta})\) was defined in (15.1), \(\lambda \ge 0\) is a regularization parameter that strikes a balance between the loss term \(\ell_{\text{atk}} + \bar{\ell}_{\text{atk}}\) and the sparsity of the trigger pattern \(\|\mathbf{m}\|_1\), and \(\mathcal{C} = \{\mathbf{0} \le \boldsymbol{\delta} \le 255, \mathbf{m} \in \{0, 1\}^n\}\) is the constraint set of optimization variables \(\mathbf{m}\) and \(\boldsymbol{\delta}\), where \([0, 255]\) is the range of the RGB pixel values.
