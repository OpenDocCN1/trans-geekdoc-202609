## 16.3 评估决策树集成的鲁棒性

接下来，我们讨论基于决策树的分类器的对抗鲁棒性，包括几种广泛使用的集成树模型，例如随机森林 (RF) 和梯度提升决策树 (GBDT) 模型。这些模型在许多数据挖掘任务中表现出显著性能，优于神经网络。
