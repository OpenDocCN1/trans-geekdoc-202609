Proof of Theorem 7. First, we decompose the target risk function as

```
\(\ell_{\mathcal{T}}(x_t + \delta^*, y_t) \stackrel{(a)}{=} \ell_{\mathcal{S}}(x_t + \delta^*, y_t) \quad (18.15)\)

\(\stackrel{(b)}{=} \|f_{\mathcal{S}}(x_t + \delta^*) - y_t\|_2 \quad (18.16)\)

\(\stackrel{(c)}{=} \|f_{\mathcal{S}}(x_t + \delta^*) - f_{\mathcal{S}}(x_t) + f_{\mathcal{S}}(x_t) - y_t\|_2 \quad (18.17)\)

\(\stackrel{(d)}{\le} \underbrace{\|f_{\mathcal{S}}(x_t + \delta^*) - f_{\mathcal{S}}(x_t)\|_2}_{A} + \underbrace{\|f_{\mathcal{S}}(x_t) - y_t\|_2}_{B}. \quad (18.18)\)
```

(a) is based on Assumption 3, (b) is based on the definition of risk function, (c) is by subtracting and adding the same term $f_{\mathcal{S}}(x_t)$, and (d) is based on the triangle inequality.

Note that by Assumption 1, $\mathbb{E}_{\mathcal{D}_{\mathcal{S}}} B = \mathbb{E}_{\mathcal{D}_{\mathcal{S}}} [\ell(x_t, y_t)] = \epsilon_{\mathcal{S}}$. Next, we proceed to bound $\mathbb{E}_{\mathcal{D}_{\mathcal{S}}, \mathcal{D}_{\mathcal{T}}} A \triangleq \mathbb{E}_{x_t \sim \mathcal{D}_{\mathcal{S}}, x_t \sim \mathcal{D}_{\mathcal{T}}} A$. Using Lemma 6, we have

```
\(\mathbb{E}_{\mathcal{D}_{\mathcal{S}}, \mathcal{D}_{\mathcal{T}}} A \le 2\sqrt{K} \cdot \mathcal{W}_1(\mu(z_{\mathcal{S}}(x_t + \delta^*)), \mu(z_{\mathcal{S}}(x_t)))_{x_t \sim \mathcal{D}_{\mathcal{T}}, x_t \sim \mathcal{D}_{\mathcal{S}}}. \quad (18.19)\)
```
