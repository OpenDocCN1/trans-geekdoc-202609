Unless specified otherwise, we evaluate the performance of the meta-learning schemes over 2400 random unseen 5-way 1-shot test tasks. We also note that RA under $\epsilon = 0$ becomes the standard accuracy (SA) evaluated using benign (unperturbed) test examples. It is clear from Fig. 17.1 that both R–MAML$_{out}$ and R–MAML$_{both}$ can yield significantly better RA than MAML with slightly worse SA. It is also expected that RA decreases as the attack power $\epsilon$ increases.
