Feldman. Hopfield told us that he had solved the convergence problem for a strongly interacting network. He had proved that a particular type of nonlinear network model, now called the “Hopfield net,” was guaranteed to converge to a stable state, called an “attractor” (figure 7.2; box 7.1).<sup>7</sup> (Highly nonlinear networks are prone to oscillate or exhibit even more chaotic behavior.) Furthermore, the weights in the network could be chosen so that the attractors were memories. The Hopfield net could thus be used to implement what was called a “content-addressable memory,” whereby a storied memory could be retrieved by starting with part of the memory and letting the network complete it. This is reminiscent of how we recall memories. If we see the face of someone we know, we can recall the person’s name and conversations we’ve had with that person.
