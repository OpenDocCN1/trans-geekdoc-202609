# An Introduction to Neuroscience

*The Deep Learning Revolution* only briefly touches on neuroscience, which is itself a vast field with a rapidly advancing scientific frontier. The part of neuroscience most relevant to deep learning is called “systems neuroscience.” If you want to learn more about the brain and neural networks, a good place to start is *The Computational Brain*, 2nd ed.
