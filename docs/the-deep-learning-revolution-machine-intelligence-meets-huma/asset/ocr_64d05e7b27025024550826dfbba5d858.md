**Figure 8.2** NETtalk feedforward network model. The seven groups of units on the bottom layer represent letters in a moving window through the text, one letter at a time. The goal of the network is to predict correctly the sound of the middle letter, which in this example is the hard “c” phoneme. Each unit on the input layer makes a connection with all of the hidden units, which in turn project to all of the units on the output layer. The backprop learning algorithm was used to train the weights using feedback from a teacher. The correct output pattern is compared with the output of the network, which in this case is the incorrect “k” phoneme. Errors are backpropagated to the weights on earlier layers.
