Question: Explain how a Decision Tree works in the context of Machine Learning.

Option 1: Based on entropy, splits data at each node

Option 2: Based on distance, groups data at each node

Option 3: Based on gradient, organizes data at each node

Option 4: Based on complexity, combines data at each node

Correct Response: 1

Explanation: A Decision Tree works by splitting the data into subsets based on feature values. This is done recursively at each node by selecting the feature that provides the best split according to a metric like entropy or Gini impurity. The process continues until specific criteria are met, creating a tree-like structure.

Question: What is the principle behind the Random Forest algorithm?

Option 2: Ensemble of trees, reduced variance

Option 3: Ensemble of trees, increased complexity

Option 4: Single decision tree, reduced bias

Correct Response: 2

Explanation: Random Forest is an ensemble learning method that operates by constructing multiple decision trees during training and outputs the mode of the classes for classification or the mean prediction of individual trees for regression. By combining many trees, it generally reduces overfitting and provides a more accurate prediction.

Option 1: Precision, Recall

Option 2: Accuracy, Recall

Option 3: Precision, Specificity

Explanation: The F1-Score is the harmonic mean of Precision and Recall. It gives equal weight to both these metrics, providing a balance between the ability to correctly identify positive cases and avoid false positives.
