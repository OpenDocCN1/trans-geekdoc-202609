

## 2. 车载单元（OBU）

基于 GPS 的跟踪系统几乎总是安装在任何车辆中，允许 RSU 和其他 OBU 监控共享的车辆详细信息。RCP、传感器、接口和读/写存储都是构成 OBU 的电子设备包的一部分。OBU 的主要责任是通过 IEEE 802.11p 无线连接连接到另一个 OBU。此外，汽车电池是 OBU 的主要电源，每辆车都包含用于监控位置和环境条件的传感器、事件数据记录器（`EDR`）和运动传感器，所有这些都有助于向 OBU 提供反馈 \[[4](#ch12.xhtml#ref12_4)\]。

## 3. 可信机构（TA）

它负责整个 VANET 方案，包括注册网络资源、提供操作指南和监督车辆使用。它还需要验证车辆身份验证、用户 ID 和 OBU ID，以确保 VANET 保护并防止任何车辆损坏。在发生任何恶意消息或异常活动的情况下，TA 将暴露 OBU ID 和信息 \[[5](#ch12.xhtml#ref12_5)\]。TA 系统还能够识别罪犯。

## 12.2 VANET 中的性能、隐私和安全问题

由于实现和设施多样，例如改进的交通质量、乘客安全和信息娱乐，VANET 已得到广泛研究。因此，车联万物（`V2X`）技术必须解决众多技术挑战，因为它们灵活性较差、能力较弱，并且提供低带宽和有限的计算能力。在 VANET 中，云计算被认为是满足这些要求的潜在解决方案。然而，传统的云计算可能无法满足下一代 VANET 标准对自动驾驶汽车的要求，这些要求包括高移动性、低延迟、实时实现和网络功能 \[[6](#ch12.xhtml#ref12_6)\]。

大多数 VANET 实现要么面向安全，要么面向非安全。在 VANET 中，安全应用程序用于提供与安全相关的信号，例如帮助道路车辆响应以避免危险状况和事件的警告。安全信息包括道路交通更新、交通拥堵、维护工作和紧急车辆警告。低延迟和高可靠性对于这些安全应用程序至关重要。另一方面，VANET 的非安全用途非常方便且有效。交通控制应用程序可以分为两类：保护和娱乐。在交通管理中，软件用于优化交通流量并减少路线上的拥堵。信息和娱乐技术用于为旅行者提供互联网连接，例如存储记录、下载视频和拨打电话。然而，在 VANET 中，准确且快速地传播重要事件记录（如事故报告）至关重要。虽然 VANET 可用于传播事件信息，但在车辆运动时，向特定位置提供及时且准确的信息具有挑战性。这是由于 DSRC 的传输范围相对较小以及 IEEE 802.11p 中基于竞争的载波侦听多路访问方案所致。MAC 竞争会导致重要消息延迟，这不利于 VANET。未能及时且精确地传播时间敏感信息可能会导致附近车辆遭受附带损害。最近，人们已经研究了蜂窝网络在为车载用户提供大覆盖范围和高数据速率的同时支持 VANET 服务的可行性 \[[7](#ch12.xhtml#ref12_7)\] ([Figure 12.2](#ch12.xhtml#fig12_2))。

相比之下，虽然单一无线通信技术（例如 DSRC 或蜂窝网络）可以在负载重、移动性高且网络拓扑复杂的区域支持某些 ITS 服务，但单一无线通信技术（例如 DSRC 或蜂窝网络）提供完整的 ITS 支持可能不可能。异构车载自组网可以是一种潜在媒介，通过结合蜂窝网络和 IEEE 802.11p，可以满足许多具有挑战性的连接标准。在 VANET 中，空间分离的车辆之间可以建立无缝数据通信 \[[1](#ch12.xhtml#ref12_1)\]。

传统上，VANET 技术不足以处理智能车辆数据（包括视频和传感器数据），这些数据可能会产生大量交通数据。需要在分布区域部署额外服务器，以捕获和处理大量即时交通信息。云计算方法结合 VANET 可能是这种用途的最佳选择。

最近的研究表明，移动用户现在正在使用云计算来执行本地难以或无法完成的复杂计算。已经进行了许多关于将云计算纳入 VANET 的研究，以进一步提升 VANET 的潜力。大多数车辆的上传和下载都使用时间和资源 \[[8](#ch12.xhtml#ref12_8)\]。目前，云存储无法满足城市地区车辆密度的位置识别、可访问性辅助和延迟标准。

## 12.3 基于 VANET 环境的挑战

由于 VANET 中的漏洞导致信息通信漏洞，VANET 容易受到攻击。为了确保车对车（`V2V`）和网络稳定性，VANET 安全系统必须满足特定要求。虽然所有网络都必须遵守相同的标准，但只有某些网络需要为 VANET 遵守这些标准。条件如下：

1. **身份验证：** VANET 应要求车辆相互进行身份验证，以便实现 `V2V` 通信。该方法可以涉及识别发送者的身份并验证发送者的真实性。

2. **可用性：** 在此上下文中，可用性是指 VANET 系统随时能够正常运行和操作的能力。与任何系统一样，响应时间是任何程序的重要考虑因素。

3. **隐私：** 在 VANET 中至关重要。车辆的名称和位置必须保密。

4. **完整性：** 它是指信任。在内容自由流动的情况下，不能有修改攻击。正是因为如此，知识才可靠。
