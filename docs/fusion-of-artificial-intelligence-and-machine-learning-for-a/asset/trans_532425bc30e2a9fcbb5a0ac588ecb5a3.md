

# 网络物理系统（CPS）

网络物理系统（CPS）是指新一代系统，其具有统一的能力和功能，能够与人类交互，并使虚拟世界与现实世界更加紧密。多年来，研究一直致力于寻找方法，以减轻人类感到疲劳且耗时的任务 \[[1](#ch4.xhtml#ref4_1)\]。CPS 不仅减少了人类的努力，还通过设备提供额外功能并提高效率。各行业和公司开发了各种系统，这些系统最适合当前的工作场景，即在工作量保持不变的情况下，工作提取量翻倍 \[[2](#ch4.xhtml#ref4_2)\]。先进系统和技术日益增加的复杂性挑战着我们，要求我们充分利用它们，并尽最大努力做好准备。构建下一代控制系统的需求现在已成为一种必然。CPS 需要工具和机制的结构化模型，以满足制造商和消费者的需求。计算机科学在现代技术领域取得了足够的进步，在未来的时期，我们期望它能实现多样化 \[[3](#ch4.xhtml#ref4_3)\]。CPS 将在各个领域发挥重要作用，帮助人类实现几年前不可能达到的高度 \[[4](#ch4.xhtml#ref4_4)\]。我们需要正确的理论和工具来准确实施 CPS，帮助我们获得成本效益高、可靠且高效的资源，从而更轻松、更快速地解决问题 \[[5](#ch4.xhtml#ref4_5)\]。开发 CPS 时需要注意的基本步骤包括设计、分析和验证所使用的组件、系统和软件架构，进行定期阶段检查以监控性能、效率、准确性和改进领域。CPS 研究仍处于早期阶段，对传感器设备、通信和网络设备、控制理论、数学计算、软件工程和计算机科学给予了孤立的关注。通过关注这些领域，我们可以提取出有史以来生产的最佳机械，这将有助于改善当前的生活水平、医疗保健以及影响我们日常生活的现代需求。CPS 领域的进步可以通过识别工业发展各个领域中的机遇、挑战和需求来加速 \[[6](#ch4.xhtml#ref4_6)\]。目标是构建兼容、节能、低维护，最重要的是高效的新技术。用户的安全也必须是一个关注点，设备或机械必须符合开发规则。

# 医疗领域的网络物理系统（CPS）

医疗领域的网络物理系统（CPS）是指医疗服务的关键网络。与目前医疗中使用的独立设备不同，这些设备监测或为个人建议治疗方案，CPS 很快将增强为能够同时监测多名患者并协助医护人员。这将涉及患者健康状况的连贯显示，将虚拟世界与现实世界结合起来。数据、药物、处方和基本详情将仅对授权人员轻松且安全地可访问 \[[7](#ch4.xhtml#ref4_7)\]。这一革命性趋势极大地影响了 CPS 领域。

# 安全可靠的医疗网络物理系统（MCPS）的开发

开发安全可靠的医疗网络物理系统（MCPS）需要完美的设计、架构、结构化规划以及验证和确认技术。由于该领域复杂性和规模的增加，基于模型的技术是必要的。MCPS 设计还涵盖整个场景中的通信和设备。MCPS 将在医疗领域开辟新的机遇，不仅在进步方面，而且在成本效益方面也是如此。然而，获得在患者治疗中使用 MCPS 的批准需要一种新的监管和管理程序。美国食品药品监督管理局（FDA）目前使用的基于流程的监管制度非常广泛、昂贵且复杂。[Figure 4.1](#ch4.xhtml#fig4_1) 说明了医疗组织的工作流程，并描绘了分析个人可信度的实际过程。

### 4.2.1 电子病历（EMR）

电子病历（EMR）是指用于自动读取生命体征的虚拟-物理接口的结构。该接口作为监测过程中耗时且容易出错的过程的解决方案。该接口的设计允许网络收集并将数据存储到 EMR 系统中。该设计的关键元素包括 EMR、一种称为数据处理器的软件适配器，以及基于硬件拓扑的生命体征读取站 \[[8](#ch4.xhtml#ref4_8)\]。该系统遵循三层架构，如 SDD 中所述，以解决虚拟-物理方法。这种方法确保对一个层中的组件所做的更改不会影响其他层中的组件 \[[9](#ch4.xhtml#ref4_9)\]。实施 EMR 带来多种好处。患者数据可以在特定时间线内跟踪，并可由授权的医疗贡献者访问。这有助于识别需要进行常规检查和预约的患者，以及监测他们的特定需求，例如疫苗接种和血压读数。EMR 的设计旨在支持组织为患者提供系统且准确的护理。

### 4.2.2 CPeSC3

由 Wang 等人提出，CPeSC3 的布局由三个主要组件组成：通信核心、计算核心、资源调度和管理核心。采用了云计算技术，具体指医疗保健应用。这里展示了一个医疗应用场景，该场景建立在实际测试平台上以供确认 \[[10](#ch4.xhtml#ref4_10)\]。CPeSC3 的优势包括增加功能并验证医生提供的治疗。它使医疗系统能够轻松监控大量数据，减少冗余，并及时提供高效服务。
