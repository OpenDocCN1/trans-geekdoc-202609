

AlexNet、VGG16 和 VGG19 CNN 模型被用于水稻田病害检测 \[[46](#ch9.xhtml#ref9_46)\]。训练了三种模型来分类四种水稻病害，即褐斑病、细菌性条斑病、矮缩病和稻瘟病。SVM 分类器用于检测这四种水稻病害。在本研究中，CNN 模型利用来自 5,932 张病害图像的特征提取器。在第二阶段，提取的特征被输入到 SVM 分类器中。AlexNet（特征层：fc8）和 ResNet50 结合 SVM 算法表现出优于其他算法的分类性能，F1-分数达到 98.38%。一个基于 CNN 的 DL 模型使用 10,000 张标记图像进行训练，用于检测木薯作物病害 \[[47](#ch9.xhtml#ref9_47)\]。图像使用自适应直方图均衡化技术进行处理。模型的准确率范围从 76.9% 到 99.30%。CNN 和 ANN 模型被用于植物病害检测 \[[48](#ch9.xhtml#ref9_48)\]。在田间条件下，不同位置或叶片角度下，CNN 特征提取与 ANN 分类的效果优于其他监督式 ML 模型。

## 9.6 使用 ML 和 DL 技术进行病害和杂草检测的影响因素

与实验室条件相比，露天田间成像是一项具有挑战性的任务。纹理和形状特征在分类问题上显示出了良好的效果，但其性能受高风速 \[[21](#ch9.xhtml#ref9_21)\]、重叠和高杂草密度等因素的影响。作物因素，包括叶片角度、叶片重叠 \[[26](#ch9.xhtml#ref9_26)\] 和叶片密度，也起着作用。叶片重叠和风速会影响分类器在真实田间条件下的性能。当叶片重叠或受虫害损坏时，计算形状特征变得困难。因此，将纹理特征与形状特征结合考虑可以提高 ML 模型的性能。光照强度在一天中会有所变化 \[[49](#ch9.xhtml#ref9_49)\]，风速是田间的一个主要问题。不受控制的室外光照会影响成像传感器的性能。分类模型的准确率和精确度受输入图像质量的影响。人工照明条件和防护布可以帮助保障成像传感器的性能 \[[21](#ch9.xhtml#ref9_21)\]。基于计算机视觉的 ML 和 DL 算法可以增强杂草检测和分类，而不会产生任何不利的环境影响。科学和技术的这些进步将使机器人在未来能够检测害虫并向患病植物喷洒杀虫剂。此外，机器人将能够以定点的方式喷洒除草剂，最大限度地减少除草剂的使用量。

## 9.7 使用机器学习 (ML) 和深度学习 (DL) 技术进行病害和杂草检测的优缺点

传统 ML 和 DL 基础分类的优点是它比传统扫描技术或人工分类技术更简单、更快速。传统 ML 基础分类或回归的主要优点是，与 DL 模型相比，训练模型所需的数据量较少。此外，ML 模型的训练时间更短，且不需要高性能 GPU 进行计算。DL 模型可以转换为 `TensorFlow Lite` 并部署在任何微控制器上，例如 `Raspberry Pi`。此外，可以将喷洒单元连接到微控制器上，以实现定点除草剂或杀虫剂喷洒。DL 的缺点是它需要大量数据集来开发 DL 模型。生成数据耗时，雨、云、光照和风等环境因素会影响数据采集过程。DL 模型计算密集，需要 `GPU` 和 `TPU`。
