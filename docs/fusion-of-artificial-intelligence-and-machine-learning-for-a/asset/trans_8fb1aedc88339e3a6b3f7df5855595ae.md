

# 6.2 方法与讨论

## 6.2.1 医疗领域中的机器学习（ML）

### 6.2.1.1 糖尿病视网膜疾病检测

糖尿病视网膜病变是影响视力的主要不可逆视网膜疾病之一 \[[12](#ch6.xhtml#ref6_12)\]。早期检测对于防止视力丧失至关重要。DR 的诊断是通过检测眼底图像中的渗出物来实现的，如 [图 6.1](#ch6.xhtml#fig6_1) 所示。DR 的分类和预测是使用集成 ML 算法（如 AdaBoost、NB、RF 和 SVM）来确定的 \[[13](#ch6.xhtml#ref6_13)\]。

![Figure 6.1 Diabetic retinopathy two-dimensional fundus image.](images/fig6_1_B.jpg)

[图 6.1 糖尿病视网膜病变二维眼底图像。](#ch6.xhtml#R_fig6_1)

OCT 图像用于有效分类糖尿病视网膜疾病，如糖尿病性黄斑水肿、DR 和 AMD ([图 6.2](#ch6.xhtml#fig6_2))。使用 DL 定制的 CNN OCT-NET 在 SD-OCT 公共数据集 SERI-CUBK 上实现了 93% 的精度和 0.99 的曲线下面积 \[[14](#ch6.xhtml#ref6_14)\]。

![Figure 6.2 OCT images of diabetic retinal diseases.](images/fig6_2_B.jpg)

[图 6.2 糖尿病视网膜疾病的 OCT 图像。](#ch6.xhtml#R_fig6_2)

糖尿病性黄斑水肿影响视网膜的视网膜下液（SRF）和 PME。使用结合空洞空间金字塔池化的深度神经网络来分割 DME 的 OCT 图像 \[[15](#ch6.xhtml#ref6_15)\]，而使用卷积网络进行基于渗出物的 DME 检测。应用 ML 决策树分类器来检测糖尿病性黄斑水肿肿块，性能指标为 92% 的准确率、89.8% 的灵敏度和 94.8% 的特异性 \[[16](#ch6.xhtml#ref6_16)\]。

### 6.2.1.2 乳腺癌诊断

乳腺癌一直是影响全球女性的常见疾病之一。根据世界卫生组织（WHO）的数据，2018 年约有 15% 的女性死于乳腺癌 \[[17](#ch6.xhtml#ref6_17)\]。早期检测对于防止死亡至关重要。ML 算法已被用于在乳腺 X 线摄影图像中检测乳腺癌 ([图 6.3](#ch6.xhtml#fig6_3))。CNN 与优化方法一起被用于分类病理图像数据集 \[[18](#ch6.xhtml#ref6_18)\]。分类器的性能是根据恶性肿瘤的识别来评估的，使用了归一化、权重正则化、浅 SoftMax 回归和浅逻辑回归（LR）等技术 \[[19](#ch6.xhtml#ref6_19)\]。

# 引言

近来，计算机辅助决策支持系统已实施机器学习（ML）方法，并已在多学科领域中实际应用。该系统学习生物医学数据集的重要特征，并基于新数据进行预测。ML 实现现在包括二维和三维图像。基于 ML 的算法能够预测事故和未来的安全措施以最大限度地减少事故。然而，这些方法是为特定的领先指标开发的，限制了它们的应用，因为对安全性能的影响在不同组织和项目之间有所不同。关于预测火灾事故的研究旨在鼓励实施针对性的安全控制并提高安全性能。精准农业的主要目标是提高作物产量。作物生长和产量取决于环境属性，如气候变量、土壤参数、灌溉、病虫害管理等。ML 算法和强大的分类器已被开发用于预测生物医学成像和信号、预测事故，以及在医疗、安全性能和农业领域预测作物生产力。

糖尿病视网膜病变是影响视力的主要不可逆视网膜疾病之一 \[[1](#ch6.xhtml#ref6_1)\]。早期检测对于防止视力丧失至关重要。DR 的诊断是通过识别眼底图像中的渗出物来实现的。DR 的分类预测是使用集成 ML 算法（如 AdaBoost、朴素贝叶斯（NB）、随机森林（RF）和支持向量机（SVM））来确定的 \[[2](#ch6.xhtml#ref6_2)\]。深度学习（DL）卷积神经网络（CNN），特别是 GoogLeNet 和 AlexNet ImageNet 模型，用于特征提取，并配合 SGD、Adam、AdaGrad、NAG 和 RMSprop 等求解器，以实现最高 74.5% 的准确率 \[[3](#ch6.xhtml#ref6_3)\]。光学相干断层扫描（OCT）图像被用于有效分类糖尿病视网膜疾病，包括糖尿病性黄斑水肿、DR 和年龄相关性黄斑变性（AMD）。基于 DL 的定制 CNN OCT-NET 在 SD-OCT 公共数据集 SERI-CUHK 上实现了 93% 的精度和 0.99 的曲线下面积 \[[4](#ch6.xhtml#ref6_4)\]。糖尿病性黄斑水肿影响视网膜的视网膜下液（SRF）和色素上皮剥离（PME）。结合空洞空间金字塔池化的深度神经网络用于 DME 的 OCT 图像分割 \[[5](#ch6.xhtml#ref6_5)\]，而卷积网络用于基于渗出物的 DME 检测 \[[6](#ch6.xhtml#ref6_6)\]。ML 决策树分类器用于检测糖尿病性黄斑水肿肿块，实现了 92% 的准确率、89.8% 的灵敏度和 94.8% 的特异性的性能指标 \[[7](#ch6.xhtml#ref6_7)\]。

使用 ML 计算需要大量数据来触发各种机械循环中的动态过程。通过这种方式，实施网络物理系统和物联网等创新原理，能够生成不同类型的本土知识，如大数据分析领域所观察到的那样。通常，数据遵循特定的生命周期（来源、收集、存储、处理、可视化、传输、应用）。但是，大多数情况下，将在后续步骤中处理的收集数据与整体环境中生成的噪声数据混合在一起，使得很难将原始数据集与噪声分离开来 \[[8](#ch6.xhtml#ref6_8)\]。

根据 Liakos 等人的统计报告 \[[9](#ch6.xhtml#ref6_9)\]，ML 模型被应用于农业的各种应用，例如作物产量预测（20%）、土壤管理（61%）和病虫害检测（22%）。在大多数情况下，基于机器的预测在许多方面获得了准确的预测。它还证明了大多数农业研究实施了人工神经网络模型（ANN）和 SVM 模型以做出更好的决策。很可能，ANN 模型用于作物改良、土壤和水资源管理的实施。当 ML 与传感器数据一起实施时，模型正在演变为人工智能（AI）系统，以提供有价值的洞察，帮助做出明智的决策，其最终目标是提高作物生产力。

ML 技术可用于土壤管理领域以提取土壤参数。它们还可以根据土壤湿度、天气条件和灌溉特征等因素来预测作物生长。因此，ML 方法有助于高效的自动灌溉 \[[10](#ch6.xhtml#ref6_10)\]。许多农民仍然遵循传统的作物发展系统，在降雨不足的情况下可能导致产量下降。为了提高作物生产力，已实施了具有混合算法的 ML 技术，取得了有希望的结果 \[[11](#ch6.xhtml#ref6_11)\]。本章概述了医学、安全管理和农业等各个领域中使用的 ML 模型。讨论重点在于这些模型如何有效地分类医学图像数据、在早期分析和预测火灾事故，以及识别和监测作物冠层特征、土壤湿度、病虫害。
