### 7.1.1 云计算的优点

1. **可扩展性：**云服务可快速调整计算资源的规模，以满足用户的各种需求。

2. **经济实惠：**云服务成本较低，因为硬件升级和维护责任由服务提供商处理。

3. **安全：**服务提供商提供各种安全的云服务，以确保我们在第三方环境中的数据安全，并维护严格的安全协议。

## 7.2 各种云计算模型

云计算支持的三种模型是：

* SaaS（软件即服务）；

* IaaS（基础设施即服务）；以及

* PaaS（平台即服务）。

每种云模型都有其自身的优势，以满足各种企业的需求。我们需要根据具体需求了解要求和优势（[图 7.2](#ch7.xhtml#fig7_2)）。

![Figure 7.2 Cloud services model.](images/fig7_2_B.jpg)

[图 7.2 云服务模型。](#ch7.xhtml#R_fig7_2)

1. **软件即服务（SaaS）：**它是一种提供快速访问各种基于云的 Web 应用程序的模型。服务提供商控制整个计算堆栈，可以通过任何 Web 浏览器轻松访问。运行在云上的各种应用程序可以按需付费使用，而一些应用程序也可免费访问，但功能有限。

在您组织现有的计算基础设施中，SaaS 不需要任何类型的安装或下载，因为应用程序维护和安装均由服务提供商处理。SaaS 的一些著名示例包括 Google G Suite 和 Dropbox（[图 7.3](#ch7.xhtml#fig7_3)）。

![Figure 7.3 Software-as-a-service (SaaS).](images/fig7_3_B.jpg)

[图 7.3 软件即服务（SaaS）。](#ch7.xhtml#R_fig7_3)

2. **平台即服务（PaaS）：**它为我们提供了一个平台，用于根据业务需求开发、测试和组织不同的应用程序。实施 PaaS 通过提供虚拟运行时环境，改变了企业软件开发的流程，使我们能够以灵活且方便的方式开发和测试应用程序。服务提供商还提供灵活的定价标准，允许我们根据需求选择服务器、存储和网络等资源。这些资源可以由公司本身或服务平台提供商管理。一些重要且著名的示例包括 Google App Engine 和 AWS Elastic Beanstalk（[图 7.4](#ch7.xhtml#fig7_4)）。

![Figure 7.4 Platform-as-a-service (PaaS).](images/fig7_4_B.jpg)

[图 7.4 平台即服务（PaaS）。](#ch7.xhtml#R_fig7_4)

3. **基础设施即服务（IaaS）：**服务提供商向我们提供云上各种计算资源的虚拟化。这些服务称为 IaaS。IaaS 云服务提供商向我们提供一整套计算基础设施，例如存储、服务器和网络硬件，以及维护和支持。企业可以在所需场所使用计算资源，而无需安装硬件。一些重要且著名的示例包括 Amazon Web Services 和 Microsoft Azure（[图 7.5](#ch7.xhtml#fig7_5)）。

![Figure 7.5 Infrastructure-as-a-service (IaaS).](images/fig7_5_B.jpg)

[图 7.5 基础设施即服务（IaaS）。](#ch7.xhtml#R_fig7_5)

### 7.2.1 SaaS 的优点

1. **投资较少：**SaaS 降低了购买基础设施、安装费用、计算硬件维护和升级成本等费用。

2. **可访问性：**SaaS 为我们提供了一个环境，允许我们使用任何设备（例如智能手机）从任何位置访问服务。这有助于消除与本地软件相关的限制。

3. **现成环境：**我们可以轻松快速地使用 SaaS 服务，这意味着它们在极短的时间内即可投入使用。您只需注册即可使用服务，并访问环境提供的快速且强大的计算资源。

SaaS 提供基于通信、内容分发和简化会议安排的服务。它最适合没有额外预算和资源投资于本地硬件的小型企业和行业。

### 7.2.2 IaaS 的优点

1. **降低成本：**这种云模型消除了对本地硬件的需求，从而降低了与硬件基础设施相关的成本。

2. **可扩展性增强：**它是最灵活的云计算模型，允许我们根据需求调整计算资源的规模。

3. **结构简单：**该模型可轻松部署服务器、处理、存储和网络等服务，以确保其随时可用。

IaaS 是最灵活的云模型，在 IT 硬件基础设施方面为我们提供了最佳选择。但是，它比 SaaS 或 PaaS 云模型更昂贵。

### 7.2.3 PaaS 的优点

1. **缩短开发时间：**这种云模型可以缩短开发时间，因为它提供了各种计算资源，例如服务器端组件，从而简化了流程。这使开发团队可以专注于开发部分。

2. **支持多种编程语言：**它提供了一个支持多种编程语言的平台，这对于软件开发公司很有用，可以轻松利用该环境为各种项目构建应用程序。

3. **支持团队协作：**无论项目团队成员身在何处，这种云模型都可以通过共同平台增强团队成员之间的协作。在有多个开发人员和多个服务提供商的情况下，这种云模型工作高效。它通过提供一种应用程序开发流程来支持创建定制应用程序，该流程可最大限度地降低总组织成本。PaaS 的一个重要缺点是它基于虚拟化技术，因此我们对数据处理的控制较少，且比 IaaS 云模型不够灵活。

## 7.3 云计算架构

云计算架构由许多松散耦合的云组件组成，包含三个部分（[图 7.6](#ch7.xhtml#fig7_6)）：

![Figure 7.6 Cloud computing architecture.](images/fig7_6_B.jpg)

[图 7.6 云计算架构。](#ch7.xhtml#R_fig7_6)

* 前端；

* 后端；以及

* 虚拟化。

互联网在连接云计算组件方面发挥着重要作用。以下是云计算架构的图形视图：

1. **前端：**它提供访问云计算平台所需的界面和应用程序。

2. **后端：**它包含提供云计算服务所需的所有资源，例如大型数据存储、虚拟机、应用程序、服务、服务器等。

3. **虚拟化：**云计算背后的重要原理是虚拟化。虚拟机监控程序是一种低级程序，充当虚拟机管理器，允许各种用户共享单个物理云资源实例。

4. **管理软件：**用于在云计算环境中维护和配置基础设施。

5. **部署软件：**用于在云上分发和集成各种应用程序。
