$\kappa(\mathbf{x}, \mathbf{x}') = (c + \mathbf{x}^top\mathbf{x}')^{d-1}$. A special case thereof is the linear kernel $\kappa(\mathbf{x}, \mathbf{x}') = \mathbf{x}^top\mathbf{x}'$. We will give more examples later.

From the formulation (8.12), it may seem as if we compute the inverse of $K(\mathbf{X}, \mathbf{X}) + nI$ every time we want to make a prediction. That is, however, not necessary it does not depend on the test input $\mathbf{x}_*$. It is therefore to introduce the $n$-dimensional

```
$$\tilde{\alpha} = \begin{bmatrix} \tilde{\alpha}_1 \ \tilde{\alpha}_2 \ \vdots \ \tilde{\alpha}_n \end{bmatrix} = \mathbf{y}^top(K(\mathbf{X}, \mathbf{X}) + nI)^{-1}$.
```

which allows us to rewrite kernel regression (8.12) as

```
$$\tilde{y}(\mathbf{x}_*) = \tilde{\alpha}^topK(\mathbf{X}, \mathbf{x}_*)$.
```

That is, instead of computing and storing a $d$-dimensional vector $\alpha$ as in standard linear regression, we now compute and store an $n$-dimensional vector $\tilde{\alpha}$. However we also need to store $X$, since we have to compute $K(\mathbf{X}, \mathbf{x}_*)$ for every prediction.

> Example 2: Linear regression with kernels

We consider the car stopping problem from Example 2.2, and apply kernel regression to it. We use $\ell = 0.1$ here and explore what happens when using different kernels.
In the first line of Figure 8.3, using the squared exponential kernel with $\ell = 1$ (blue line). We see that it does not really interpolate between the data points, but we do not pursue that any here.) If we select $\ell$ using cross validation, the red line gives a more sensible behavior. It is important to note that the regression tends to zero when interpolating beyond the range of the training data. In fact this is a general property of the squared exponential kernel; as well as many other kernels used. The reason for this is that the kernel $\kappa(\mathbf{x}, \mathbf{x}')$ decays continuously to zero as we points away from the range of the training data. (i.e. as the distance between $\mathbf{x}$ and $\mathbf{x}_*$ increases), this means that the predictions are based on extrapolation, and we extrapolate beyond the range of the training data the method will return to all elements of the kernel $K(\mathbf{X}, \mathbf{x}_*)$ close to zero (for a kernel with the appropriately property) and so will be the resulting prediction.

We have seen that to some extent, this follows a quadratic function. As we will discuss in Section 8.4, which of two kernels is better. In the right panel of Figure 8.3 we try using the squared exponential kernel (with $\ell = 3$) and the polynomial kernel of degree $d = 2$ (or $d = 3$) (dashed line). The result is a more flexible model than a quadratic function, but also (for this example) seems to extrapolate better than using the squared exponential kernel.

This can be understood by the polynomial kernel is not local (in the sense discussed above). It does not drop to zero for test data that are far from the data. It corresponds to a polynomial trend and the prediction will follow this trend when extrapolating. The reason for this is that the squared exponential component of the combined kernel will only be 'active' when interpolating. For extrapolation the combined kernel will only revert to using the polynomial component.
