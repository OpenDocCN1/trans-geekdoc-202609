Before proceeding, us pause for a moment and consider this expression. The transformation of õ a data point x is according to (10.31c) a linear transformation of x. However, this transformation depends on only the matrix $W_d$ and $b_d$. Consequently, there is no hope in uniquely identifying all parameters by (10.32). For instance, we can replace $W_d$ with $W_dT^T$, for any invertible $q \times q$ matrix $T$ and obtain an equivalent model. At best we can learn to learn the model $W_dW_e$ and $b_d$, but it is not possible to uniquely identifying $W_e, b_d$ from these expressions. Therefore, when performing PCA we wish to find one solution to (10.32), without necessarily characterizing all possible solutions. As we will see below, we will not just find any solution, but one that has a nice geometrical interpretation.

Based on this observation, we start by noting that there is redundancy in the "combined offset" vector $W_db+b_d$. Since $b_d$ is a free parameter, we can proceed without loss of generality $b_e = 0$. This means that the encoder mapping simplifies to $z = W_ex$. Next, plugging this into (10.32) it is possible to solve for $b_d$. Indeed, we follow a standard least squares argument$^{12}$, that the optimal value for $b_d$ is

```
$b_d = \sum_{i=1}^{n} (x_i - W_dW_ex_i) = (I - W_dW_e)X$
```

where $X = \sum_{i=1}^{n} x_i$ and $x_i$ is the mean of training data. For notational brevity we define the centered data $x_{0,i} = x_i - \bar{x}$ for $i=1,\dots,n$ by subtracting the mean from each data point. The objective (10.32) this simplifies to

```
$\tilde{W}_e, \tilde{W}_d = \arg \min_{W_e, W_d} \sum_{i=1}^{n} ||x_{0,i} - W_dW_ex_{0,i}\|^2$.
```

We note that the role of offset vectors in the auto-encoder is to center the data around its mean. In practice, we handle this as a pre-processing step and

> center the data by subtracting the mean from each data point.

We can then focus on how to solve the problem (10.34) for the matrices $W_e$ and $W_d$. As have seen previously in this book, working with linear models it is often convenient to center the data vectors into matrices and make use of tools from matrix algebra. This is also true when deriving the PCA solution to (10.3). We define the matrices of centered data and reconstructions as

```
$\mathbf{X}_0 = \begin{bmatrix} x_{0,1} \ x_{0,2} \ \vdots \ x_{0,n} \end{bmatrix} \quad \text{and} \quad \mathbf{\hat{X}}_0 = \begin{bmatrix} \hat{x}_{0,1} \ \hat{x}_{0,2} \ \vdots \ \hat{x}_{0,n} \end{bmatrix} \quad (10.36)
```

respectively, where matrices are of size $n \times p$. Here $\mathbf{\hat{X}}_0 = W_dW_e\mathbf{X}_0$ is the reconstruction of the $i$th data point. With this notation we can write the objective (10.34)

```
$\tilde{W}_e, \tilde{W}_d = \arg \min_{W_e, W_d} ||\mathbf{X}_0 - \mathbf{\hat{X}}_0||^2. \quad (10.37)
```

where $|||.||_F$ denotes the Frobenius norm$^{13}$ of a matrix and the dependence on $W_e$ and $W_d$ is implicit in the notation $\mathbf{X}_0$.

By the definition of this rank the reconstructed data points it follows that $\mathbf{\hat{X}}_0 = \mathbf{X}_0 W_e^T W_d^T$.
