# 7 Ensemble methods: Bagging and boosting

> **Time to reflect 7.2:** In AdaBoost, we use the exponential loss for the boosting ensemble. How come we end up training the individual ensemble members using a weighted misclassification loss (and not the weighted exponential loss)?

How the problem (7.11) is solved in practice depends on the choice of base classifier that we use, that is, on the restrictions that we put on the function $\hat{y}$ (for example a classification tree). However, solving (7.11) is almost our standard classification problem, except for the weights $w_e^{(b)}$. Training the ensemble member $b$ on a *weighted* classification problem is, for most base classifiers, straightforward.

With the $b^{th}$ member, $\hat{y}^{(b)}(\mathbf{x})$, has been trained for the weighted classification problem (7.11) it remains to learn its confidence $\alpha^{(b)}$. This is done by solving (7.7), which amounts to minimizing (7.10) once $\hat{y}$ has trained. By differentiating (7.10) with respect to $\alpha$ and setting the derivative to zero we get

```
$-\alpha e^{-\alpha}W + \alpha(e^{\alpha}-e^{-\alpha})W = 0 \Rightarrow W = (e^{2\alpha}+1) \Rightarrow \alpha = \frac{1}{2}\ln\left(\frac{W}{W_e}\right).$
```

Thus, by

```
$E_{train}^{(b)} = \frac{\text{def } W}{W} = \sum_{i=1}^{n} \frac{w_i^{(b)}}{w_i^{(b-1)}} \mathbb{I}(y_i \neq \hat{y}^{(b)}(\mathbf{x}_i)), \quad (7.12)$
```

to be the weighted misclassification error for the $b^{th}$ classifier, we can express the optimal value for

```
$$\alpha^{(b)} = \frac{1}{2}\ln\left(\frac{1-E_{train}^{(b)}}{E_{train}^{(b)}}ight), \quad (7.13)$
```

The fact that $\alpha^{(b)}$ depends on the training error of the $b^{th}$ ensemble member is natural, as mentioned above, we can interpret $\alpha^{(b)}$ as the confidence in this member's predictions. This completes the derivation of the AdaBoost algorithm, which is summarized in Method 7.2. In the algorithm we exploit the fact that the weights $(7.8)$ can be computed recursively by using the expression (7.6) in line 6 of the learning. Furthermore, we have added error normalization (line 7) which is convenient in practice and does not affect the derivation of the method above.
The derivation of AdaBoost assumes that all coefficients $\alpha^{(b)}$ are positive. To see this we note that $\alpha$ will be positive as long as the weighted training error for the $b^{th}$ classifier, $E_{train}^{(b)}$, is less than 0.5. That is, the classifier just has to be slightly better than a coin flip, which is always the case in practice (note that $E_{train}^{(b)}$ is the training error. Indeed, if $E_{train}^{(b)}>0.5$, then we could simply flip the sign of all predictions by $\hat{y}^{(b)}(\mathbf{x})$ to reduce the error below 0.5).
