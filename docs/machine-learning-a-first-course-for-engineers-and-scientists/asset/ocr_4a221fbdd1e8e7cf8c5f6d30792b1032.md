# Preparing for other kernel methods: the representer theorem

The formulation (8.14) is not only practical for implementation, it is also important for theoretical understanding. We can interpret (8.14) as a *dual formulation of linear regression*, where we have the *dual parameters $\alpha$ instead of the primal formulation (8.4)* with primal parameters $	heta$. Remember that $d$, the (possibly infinite) number of primal parameters in $	heta$, is a user design choice, whereas $n$, the number of dual parameters in $\alpha$, is the number of data points.
