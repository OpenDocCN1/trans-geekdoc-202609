Generative adversarial networks use this property for training the model, by comparing synthetic samples (generated by the model) with real samples from the training set {x, y}_{i=1}^n. The basic idea is to iteratively update the model θ with the objective of making the synthetic samples resemble the real ones as much as possible. If it is difficult to tell them apart, then we can conclude that the learned distribution is a good approximation of the true data distribution. To illustrate this, assume that we are working with datasets of images of some type, such as human faces. This is one of typical examples, where these models show remarkable capabilities. A generative model is then an image of p = wxh (width in pixels x height in pixels x three color channels), z is a Gaussian vector of dimension q, and the mapping f: R^q → R^wh this Gaussian generates and transforms it into the shape of an image. Going into details, such mappings can be constructed using deep neural networks in various ways, for instance upsampling layers and deconvolutions (inverse convolutions). These networks are reminiscent of convolutional neural networks (see Section 6.3) but go in the other direction—instead of taking an image as input and transforming it into a vector of probabilities, say we take a vector as input and transforming it into the shape of an image.

To learn a model p(x|θ) from the distribution of the observed data, we will play a type of game, which goes as follows. At the first iteration of the learning:

+   1. "Flip a coin", then set y = 1 with probability 0.5 and y = -1 with probability 0.5:
   - If y = 1, then generate a synthetic sample from the model x' ~ p(x|θ). That is, sample x' ~ N(0, I), and compute x = f(x').
   - If y = -1, pick a random sample from the training data set. That is, set x = x_i for some i sampled uniformly from {1, ..., n}.

+   2. Ask a critic to determine if the sample is real or fake. For instance, in the case of pictures of faces, would the critic look like a real face, or is it synthetically generated?

+   3. Use the critic's reply as a sign for updating the model parameters θ. Specifically, update the parameters with the goal of making the critic "confused", regardless of whether or not the sample is presented or real.

The first point is easy to implement, but when we get to the second point the procedure becomes abstract. What do we mean by "critic”? In a practical learning algorithm, a human-in-the-loop to judge the quality of the synthetic sample x' is of course not feasible. Instead, the idea behind generative adversarial networks is to learn an auxiliary classifier to generate the generative model, which takes the role of the critic in the game. Specifically, we use a binary classifier g_φ(x) which takes a data point (for an example of image as input) and outputs the probability that it is synthetically generated, that is

```
g_φ(x) = p(y = 1|x).
```

Here, n denotes the parameters of the auxiliary classifier, which differ from the parameters θ of the generative model.

The classifier is learned as usual to minimize its classification loss L,

```
φ = arg min_φ [L(y, g_φ(x'))].
```

where the expected value is with respect to the random variables y and x' generated by the process described above. Note that this becomes supervised binary classification problem, where the labels are are automatically generated as part of the "game". Indeed, these labels correspond to the flip of a fair coin, we can define the optimization problem

```
θ = arg min_θ [L(1, g_θ(x')) + L(-1, g_θ(x))].
```
