# Extending kernel regression into a Gaussian process

An alternative to obtain the Gaussian process construction, is to apply the kernel trick from Section 8.2 to Bayesian linear regression from (9.11). The connection between linear regression, Bayesian linear regression, kernel regression and the Gaussian process is summarized in Figure 9.7.
