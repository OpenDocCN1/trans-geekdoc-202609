This notation means that the symbol x is used for both the $p+1$ and the $p$ dimensional version of the input vector, or without the constant in the leading position, respectively. This is only a matter of book-keeping for handling the intercept term $	heta_0$. Which definition is used will be clear from context and carries no deeper meaning.

The linear regression model is a parametric function of the model (3.3). The parameters $	heta$ can take arbitrary values, and those we assign will control the input–output relationship described by the model. Learning of the model therefore amounts to finding suitable values for $	heta$ based on observed data. Before discussing how to do this, however, let us first look at how to use the model once it has been learned.

The goal in supervised machine learning is making predictions $\widehat{y}(\mathbf{x}^*)$ for new, unseen inputs $\mathbf{x}^* = [1, x_1^*, \dots x_p^*]^T$. Let us assume that we have already learned some parameter values $\hat{	heta}$ for the linear regression model. We use the symbol $\hat{}$ to indicate that $\hat{	heta}$ contains learned values of parameters. Since the noise $\varepsilon$ is random with zero mean and independent of all observed variables, we must replace $\varepsilon$ with $0$ in the prediction. That is, a prediction from the linear regression model takes the form

```
\widehat{y}(\mathbf{x}^*) = \hat{	heta}_0 + \hat{	heta}_1x_1^* + \hat{	heta}_2x_2 + \dots + \hat{	heta}_px_p^* = \hat{	heta}^T \mathbf{x}^*. \quad (3.4)
```

The noise $\varepsilon$ is often referred to as an irreducible error or aleatory uncertainty in the prediction. We illustrate the predictions made by a linear regression model in Figure 3.1.
