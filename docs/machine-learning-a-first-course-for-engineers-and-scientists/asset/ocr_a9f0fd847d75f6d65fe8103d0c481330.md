# 5.4 Parameter optimization

Many supervised learning methods, linear and logistic regression, involves one (or more) optimization problems, such as (3.12), (3.35) or (5.26). A machine learning engineer needs to be familiar with the main strategies for how to solve optimization problems fast. Starting in the optimization problems from linear and logistic regression, we will introduce the idea behind the optimization methods commonly used in machine learning. This section only gives a brief introduction to optimization theory and, for example, we will discuss unconstrained optimization problems.

Optimization is about finding the minimum or maximum of an objective function. Since the maximization problem can be formulated as minimization of the negative objective function, we can limit ourselves to minimization without loss of generality.

There are primarily two ways in which optimization is used in machine learning:

+   1. For training a model by minimizing the cost function with respect to the model parameters $	heta$. In this case the objective function corresponds to the cost function $J(	heta)$, and the optimization variables correspond to the model parameters.

+   2. For tuning hyperparameters, such as the regularization parameter $\lambda$. For instance, by using a hold-out validation dataset (Chapter 4) we can select $\lambda$ to minimize the hold-out validation error $E_{hold-out}$. In this case, the objective function is the validation error, and the optimization variables correspond to hyperparameters.

In the presentation we will use $	heta$ to denote a general optimization variable, but keep in mind that optimization can also be for selecting hyperparameters.

An important advantage of convex functions is that for convex optimization it is good advice to spend some extra effort to consider whether a non-convex optimization problem can be re-formulated into a convex problem (which sometimes, but not always, is possible). The most important property of a convex function, for this discussion, is that a convex function has a unique minimum, and no other minima. Examples of convex functions are the cost functions for logistic regression, linear regression and $L^1$-regularized linear regression. An example of non-convex functions is the cost function for a deep neural network. We illustrate by Example 5.3.
