```
$$\alpha^{(b)}, \tilde{Y}^{(b)} = \text{arg min}_{_{(\alpha, \tilde{y})} \sum_{i=1}^{n} L(y_i \cdot f^{(b-1)}(\mathbf{x}_i)) \eqno (7.7a)$$
$
$\ = \text{arg min}_{_{(\alpha, \tilde{y})} \sum_{i=1}^{n} \exp\left(-y_i \cdot (f^{(b-1)}(\mathbf{x}_i) + \alpha\tilde{y}(\mathbf{x}_i))\right) \eqno (7.7b)$$
$
$\ = \text{arg min}_{_{(\alpha, \tilde{y})} \sum_{i=1}^{n} \exp\left(-y_i \cdot f^{(b-1)}(\mathbf{x}_i) - y_i\alpha\tilde{y}(\mathbf{x}_i)\right) \eqno (7.7c)$
```

where the first equality we have used the definition of the exponential loss function (7.5) and the sequential structure of the boosted classifier (7.6). The last equality is by rewriting the convenience of the exponential loss appears, namely by the fact that $\exp(a+b) = \exp(a)\exp(b)$. This allows us to define the quantities

```
$W_i^{\text{def}} = \exp\left(-y_i \cdot f^{(b-1)}(\mathbf{x}_i)\right),\eqno (7.8)$
```

which can be interpreted as weights for the individual data points in the training dataset. Note that the weights $w_i^{(b)}$ are independent of $\tilde{y}$ and $\alpha$. That is, when learning $\tilde{y}^{(b)}(\mathbf{x})$ and its coefficient $\alpha^{(b)}$ by solving (7.7c) we can regard with respect to $w_i^{(b)}$ as constants. To solve (7.7) by rewriting the objective function

```
$$\sum_{i=1}^{n} w_i^{(b)} \exp\left(-y_i\alpha\tilde{y}(\mathbf{x}_i)\right) = e^{-\alpha} \sum_{i=1}^{n} w_i^{(b)}\{y_i = \tilde{y}(\mathbf{x}_i)\} + e^{\alpha} \sum_{i=1}^{n} w_i^{(b)}\{y_i \neq \tilde{y}(\mathbf{x}_i)\}\eqno (7.9)$
```

where we have used the indicator function to split the sum into two parts: the first ranking over all correctly data points classified by $\tilde{y}$ and the second ranking over all points classified by $\alpha$. Because $\tilde{Y}$ is the ensemble member we are learning at this. Furthermore, for notational simplicity we define $W^+$ and $W^-$ for the sum of weights of correctly classified and erroneously classified data points, respectively. Furthermore, let $W = W^+ + W^-$ be the total weight, $W = \sum_{i=1}^{n} w_i^{(b)}$. Minimizing (7.7) is done in two stages, first with respect to $\tilde{y}$ and then with respect to $\alpha$. This is possible since the minimizing argument in $\alpha$ turns out to be the actual value of $\alpha > 0$, another convenient effect of using the exponential loss function. To do this, we can write the function (7.9) as

```
$e^{-\alpha}W^+ + e^{\alpha}W^-\eqno (7.10)$
```

Since the total weight $W$ is independent of $\tilde{y}$ and since $e^{-\alpha} - e^{\alpha} > 0$ for any $\alpha > 0$, minimizing this expression with respect to $\tilde{y}$ is equivalent to minimizing with respect to $\alpha$, that is:

```
$$\alpha^{(b)} = \text{arg min}_{\alpha} \sum_{i=1}^{n} w_i^{(b)}\{y_i \neq \tilde{y}(\mathbf{x}_i)\}\eqno (7.11)$
```

In words, the $b^{th}$ ensemble member should be trained by minimizing the weighted missclassification loss, where each data point $(\mathbf{x}_i, y_i)$ is assigned a weight $w_i^{(b)}$. The intuition for these weights is, that iteration $b$, we should focus attention on the data points previously classified in order to "correct” the mistakes made by the ensemble of the first $b-1$ classifiers.
