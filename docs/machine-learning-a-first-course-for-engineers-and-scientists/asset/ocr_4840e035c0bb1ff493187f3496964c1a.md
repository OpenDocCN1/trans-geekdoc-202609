# Single number evaluation metric

In Section 4.5 we introduced additional metrics besides the misclassification rate such as precision, recall and F1-score for binary classifiers. There is no unique answer to which metric is the appropriate. What metric to pick is rather part of the problem definition. To improve the model quality and in a more automated fashion, it is advisable to choose on a single evaluation metric, especially if a team of engineers are working on the prediction.

The single number evaluation metric together with the validation data are what we can evaluate the model on the hold-out validation data (or by k-fold cross-validation) using the metric, allows us to speed up the iterations we can quickly see if a proposed change to the model improves the performance or not. This is important in order to manage an efficient workflow of trying out and rejecting new models.

That being, besides the single evaluation metric, it is useful to monitor other metrics as well to reveal the tradeoffs being made. For example, we might develop the model with different end users in mind who care about less different metrics, for practical reasons we might only use one model to accommodate them all. If we, based on these tradeoffs, realize that the single number evaluation metric we have chosen does not favor the properties we want a good model to have, how we change that.

# Baseline and achievable performance level

Before working with the machine learning problem is a good idea to establish some reference points for the performance level of the model. A baseline is a very simple model that serves as a lower expected level of the performance. A baseline can be for example randomly pick any value y from the mean of all values output as the prediction. A baseline for the regression problem is to take the training data and use in the training data and as the prediction. A corresponding baseline for a classification problem is to pick the most common class label in the training data and use for that prediction. For example if we have a binary classification problem with 70% of the training data belonging to one class 30% belonging to the other and we have chosen as our performance metric, the accuracy for that baseline is 70%. The baseline is a lower threshold on the performance. We know that the baseline has to be better than this.
