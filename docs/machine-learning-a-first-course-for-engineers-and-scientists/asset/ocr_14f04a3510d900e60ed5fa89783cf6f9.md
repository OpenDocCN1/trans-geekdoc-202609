By not using a constant learning rate, but instead decrease it gradually towards zero, the parameter updates will be smaller and smaller, and eventually converge. We start at t = 0 with a fairly high learning rate $\gamma^{(t)}$ (meaning that we take big steps) and then decay $\gamma^{(t)}$ as $t$ increases. Under regularity conditions of the cost function and with a learning rate following the Robbins-Monro conditions $\sum_{t=1}^{\infty} \gamma^{(t)} = \infty$ and $\sum_{t=1}^{\infty} (\gamma^{(t)})^2 < \infty$, the stochastic gradient descent can be converged to nearly a local minimum. The Robbins-Monro conditions are for example, fulfilled if using $\gamma^{(t)} = a/t^\alpha$. For many machine learning problems, however, it has been found that performance is obtained in practice by not letting $\gamma^{(t)} \to 0$, but to cut at some small value $\gamma_{\min} > 0$. This will cause stochastic gradient descent not to easily converge, and the Robbins-Monro conditions will not be fulfilled, but the algorithm will walk around indefinitely (until the algorithm is aborted by the user). For practical purposes this seemingly property usually does not cause any issue if $\gamma_{\min}$ is only small enough, and enough for setting the learning rate in practice is

```
$$\gamma^{(t)} = \gamma_{\min} + (\gamma_{\max} - \gamma_{\min})e^{-t}$
```

The learning rate $\gamma^{(t)}$ starts at $\gamma_{\max}$ and goes to $\gamma_{\min}$ as $t \to \infty$. How to pick the parameters $\gamma_{\min}$ and $\gamma_{\max}$. As a rule of thumb can be chosen as 1% of $\gamma_{\max}$. The parameter $	au$ depends on the dataset and the complexity of the problem, but could be chosen such that many epochs have passed before we reach $\gamma_{\min}$.
