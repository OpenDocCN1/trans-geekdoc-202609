# 3 Basic parametric models and a statistical perspective on learning

As linear regression, we have a model (3.29) which contains unknown parameters $	heta$. Logistic regression is also a parametric model, and we need to learn the parameters from training data. How can this done is the topic for the next section.

# Learning the logistic regression model by maximum likelihood

By using the function, we have transformed linear regression (a model for regression problems) into logistic regression (a model for classification problems). The price to pay is that we will not be able to use the convenient normal equations for learning $	heta$ (as we could for linear regression using the squared error), due to the nonlinearity of the logistic function.
In order to derive a principled way of learning $	heta$ in (3.29) from training data $\mathcal{T}=\{x_i, y_i\}_{i=1}^n$, we start with the maximum likelihood approach. From a maximum likelihood perspective, learning a classifier amounts solving

```
$$\bar{	heta} = \arg \max p(y|x; \theta) = \arg \max \sum_{i=1}^n \ln p(y_i|x_i; \theta).$\quad (3.30)$
```

where, by similar to linear regression (3.19), assuming that the data points are independent and we consider the likelihood of the likelihood function for numerical reasons. We have also added $	heta$ explicitly to the notation to emphasize the dependence on the model parameters. Remember that our model of $p(y|x;\theta)$ is $g(x;\theta)$, which gives

```
$$\ln p(y_i|x_i; \theta) = \begin{cases} \ln g(x_i; \theta) & \text{if } y_i = 1, \ \ln(1 - g(x_i; \theta)) & \text{if } y_i = -1.\end{cases} \quad (3.31)$
```

It is common to turn the maximization problem (3.30) into an equivalent minimization problem by using the negative-likelihood as cost function, $J(\theta) = -\frac{1}{n} \sum \ln p(y_i|x_i; \theta)$, that is

```
$J(\theta) = -\frac{1}{n} \sum_{i=1}^n \begin{cases} -\ln g(x_i; \theta) & \text{if } y_i = 1, \-\ln(1 - g(x_i; \theta)) & \text{if } y_i = -1.\end{cases} \quad (3.32)$
```

The loss function in the expression above is the cross-entropy loss. It is not specific to logistic regression, but can be used for any classifier that predicts class probabilities $g(x;\theta)$.

However, we will now consider specifically the logistic regression model, for which we can write out the cost function (3.32) in more detail. In so, the particular choice of labeling $\{-1, 1\}$ turns out to be convenient. For $y_i$ we can write

```
$g(x_i; \theta) = \frac{e^{\	heta x_i}}{1 + e^{\	heta x_i}}, \quad \frac{e^{\	heta x_i}}{1 + e^{\	heta x_i}}. \quad (3.3a)$
```

and for $y_i = -1$

```
$1 - g(x_i; \theta) = \frac{1}{1 + e^{\	heta x_i}}, \quad \frac{1}{1 + e^{\	heta x_i}}. \quad (3.3b)$
```

Here, we get the same expression in both cases and can write (3.32) compactly as

```
$J(\theta) = -frac{1}{n} \sum_{i=1}^n \frac{e^{\theta x_i}}{1 + e^{\theta x_i}} -\sum_{i=1}^n \frac{1}{1 + e^{\theta x_i}} = -\sum_{i=1}^n \ln [1 + e^{\	heta x_i}]. \quad (3.34)$
```
