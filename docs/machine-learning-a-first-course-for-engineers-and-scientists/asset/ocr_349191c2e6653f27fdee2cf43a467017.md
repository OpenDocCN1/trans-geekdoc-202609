the gradient of the cost function $\nabla_	heta J(\theta)$ exists for all $\theta$. As an example, the gradient of the cost function for logistic regression (3.34) is

```
$$\nabla_	heta J(\theta) = -\frac{1}{n}\sum_{i=1}^n \frac{1}{1+e^{\theta^T x_i}}x_i. \quad (5.30)$
```

Note $\nabla_	heta J(\theta)$ is a vector of the same dimension as $\theta$, which describes the direction in which $J(\theta)$ increases. Conversely, and more useful for us, $-\nabla_	heta J(\theta)$ describes the direction in which $J(\theta)$ decreases. That is, if we take a small step in the direction of the negative gradient, this will reduce the value of the cost function,

```
$J(\theta - \gamma\nabla_	heta J(\theta)) \le J(\theta) \quad (5.31)$
```

for some (possibly very small) $\gamma > 0$. If $J(\theta)$ is convex, the inequality in (5.31) is strict except at the minimum (where $\nabla_	heta J(\theta)$ is zero). This suggests that if we have $\theta^{(i)}$ and want to select $\theta^{(i+1)}$ such that $J(\theta^{(i+1)}) \le J(\theta^{(i)})$, we should

```
$update \theta^{(i+1)} = \theta^{(i)} - \gamma\nabla_	heta J(\theta^{(i)}) \quad (5.32)$
```

with some positive $\gamma > 0$. Repeating (5.32) gives the gradient descent Algorithm 5.1.

**Algorithm 5.1:** Gradient descent
**Input:** Objective function $J(\theta)$, initial $\theta^{(0)}$, learning rate $\gamma$
**Result:** $\hat{\theta}$
1 Set $\theta \leftarrow 0$
2 **while** $|\theta^{(t)} - \theta^{(t-1)}\|$ not small enough **do**
3 $\quad$ Update $\theta^{(t+1)} \leftarrow \theta^{(t)} - \gamma\nabla_	heta J(\theta^{(t)})$)$
4 $\quad$ Update $t \leftarrow t + 1$
5 **end**
6 **return** $\hat{\theta} \leftarrow \theta^{(t-1)}$
