
## 3.2 Classification and logistic regression

The loss function $L(\mathbf{x}_i, \theta)$ above, is a special case of the cross-entropy loss, is called the logistic loss (or sometimes binomial deviation). Learning a logistic regression model then amounts to solve

```
$$\hat{\theta} = \arg\min_{\theta} \sum_{i=1}^n \ln(1 + e^{-y_i\theta^T\mathbf{x}_i}).\quad (3.35)$$
```

Contrary to linear regression with squared error loss, the model (3.35) has no closed-form solution. Solving nonlinear optimization problems numerically is central to training of many machine learning models, not just logistic regression, and we will come back to this topic in Chapter 5. Now, however, it is enough to note that there exist efficient algorithms for solving (3.35) numerically for finding $\theta$.

- **Result:** Learned parameter vector $\hat{\theta}$

### Predictions and decision boundaries

So far, we have discussed logistic regression as a method for predicting class probabilities for a test input $\mathbf{x}_*$, by first learning $\theta$ from training data and thereafter computing $\mathbf{g}(\mathbf{x}_*)$, our model for $p(y=1|\mathbf{x}_*)$. However, we want to make a "hard" decision for the test input $\mathbf{x}_*$, that is, predicting $\hat{y}(\mathbf{x}_*)=-1$ or $1$ in binary classification, just like $k$-NN or decision trees. We have to add a final step to the logistic regression, where the predicted probabilities are turned into a class prediction. The most common approach is to let $\mathbf{g}(\mathbf{x}_*)$ be the most probable class. For binary classification, we can express this

```
$$\hat{y}(\mathbf{x}_*) = \begin{cases} 1 & \text{if } \mathbf{g}(\mathbf{x}_*) > 0 \\ -1 & \text{if } \mathbf{g}(\mathbf{x}_*) \le 0 \end{cases}.\quad (3.36)$$
```

with threshold $r=0.5$, which is illustrated in Figure 3.5. We now have everything in place for summarizing logistic regression in Method 3.2.

In some applications, it can be beneficial to explore different thresholds than $r=0.5$. It can be that if $\mathbf{g}(\mathbf{x}_*)=1$, then the model provides a correct description of the real-world class probabilities, then the choice of $r=0.5$ might yield the smallest number of misclassifications on average. The misclassification rate, however, is not the most important aspect of classifier. Many classification problems are asymmetric (it is more important to correctly predict some classes than others) or unbalanced (classes occur with different frequency). In a medical application, it can be important not to fail to predict the negative class (that is, a sick patient predicting being healthy)

This implicitly gives a prediction for $p(y=-1|x_*)$ as $1-g(x_*)$. To turn these probabilities into actual class predictions $\hat{y}(x_*)$ (which is either -1 or 1), the class which is modeled to have the highest probability can be taken as the prediction, as in Equation (3.36). The point where the prediction changes from one class to another is the decision boundary (plane). For such a problem, minimizing the misclassification rate might not lead to the desired performance. Furthermore, the medical diagnosis problem could be imbalanced if the disorder is very rare, meaning that the vast majority of the data points (falsely predict the positive class (by mistake predict a healthy patient as sick)) simply because the negative class is more common in the data. We will discuss how we can evaluate such situations systematically in Section 4.5. However, the decision threshold $r$ is a choice that the user has to make. The decision boundary for binary classification can be computed by solving the input space for which two classes are predicted to be equally probable. These points lie on the decision boundary. For binary regression, this

```
$$g(x_*) = 1 - g(x_*).\quad (3.37)$$
```

The equation $\theta^Tx = 0$ is a linear hyperplane. Hence, the decision boundaries in logistic regression always have the shape of a hyperplane. From the derivation above it can be noted that the sign of the expression $\theta^Tx$ determines if the positive or the negative class, we can compactly write

```
$$\hat{y}(x_*) = \text{sign}(\theta^T x_*).\quad (3.39)$$
```

In general we distinguish between different types of classifiers by the shape of their decision boundaries:
- A classifier whose decision boundaries are hyperplanes is a linear classifier.
- All other classifiers are nonlinear classifiers. Logistic regression is an example of a linear classifier, whereas k-NN and decision trees are nonlinear classifiers. Note that the term "linear" is used in a different sense for linear regression: linear regression is a model that is linear in its parameters, whereas a linear classifier is a model whose decision boundaries are linear.

The arguments and constructions as above can be generalized to the multiclass setting. Predicting according to the most probable class then computes the prediction

```
$$f(x) = \arg\max_m g_m(x)$$
```

As the binary case, it is possible to model this without an asymmetric or imbalanced problem. As for the decision boundaries, they will be given by a combination of $M-1$ (linear) hyperparameters for a multiclass regression model.

## Logistic regression for more than two classes

Logistic regression can be used for the multiclass problem when there are more than two classes, $M > 2$. There are several ways of generalizing logistic regression to this setting. We will follow one path using the softmax function which will be useful later when learning deep models in Chapter 6.

For binary problem, we use the logistic function to design a model for $g(x)$, a scalar- representing $p(y=1|x)$. For the multiclass problem we have to design a vector-valued function $g(x)$, whose elements are non-negative and sum to one. For purpose we use $M$ elements of (3.28), each $z_m$ with a different set of parameters $\theta_m, z_m = \theta_m x$. We stack all $z_m$ into a vector of logits $\mathbf{z} = [z_1 z_2 \dots z_M]$ and use the softmax function as a vector-valued generalization of the logistic function,

```
$$\text{softmax}(z) = \begin{pmatrix} e^{z_1} \\ e^{z_2} \\ \vdots \\ e^{z_M} \end{pmatrix} / \sum_{m=1}^M e^{z_m}$$
```

The argument $z$ to softmax is an $M$-dimensional vector, and it returns a vector of the same dimension. Consequently, the output of the softmax function always sums to 1, and each element is always $\ge 0$. Similarly to how we combined linear regression and the logistic function for the binary classification problem (3.29), we have now combined linear regression and the softmax function to model the class probabilities,

```
$$g(x) = \text{softmax}(z), \quad z = \begin{pmatrix} \theta_1^T x \\ \theta_2^T x \\ \vdots \\ \theta_M^T x \end{pmatrix}$$
```

Equivalently, we can write out the multiclass probabilities, that is the vector $g(x)$ as,

```
$$g_m(x) = \frac{e^{\theta_m^T x}}{\sum_{j=1}^M e^{\theta_j^T x}}, \quad m = 1, \dots, M.$$
```

This is the multiclass logistic regression model. Note that this construction uses $M$ user parameters $\theta_1, \dots, \theta_M$ (one for each class). As for binary regression, we can learn the number of parameters to grow with $M$. Using the maximum likelihood method, we use $\theta$ to denote all parameters, $\theta = (\theta_1, \dots, \theta_M)$. Since $g_m(x)$ is our model for $p(y=m|x)$, the cost function for the cross-entropy (using negative log-likelihood) for the multiclass problem is

```
J(\theta) = -\frac{1}{n} \sum_{i=1}^n -ln g_{y_i}(x_i; \theta).
```
