# 9.3 The Gaussian process

$x_1, \dots, x_n$ can be chosen arbitrarily from the continuous space on which it lives, the Gaussian process defines a distribution for **all** points in that space. For this definition to make sense, $\kappa(\mathbf{x},\mathbf{x}')$ has to be such that a positive semidefinite covariance matrix is obtained for any choice of $\{x_1, \dots, x_n\}$.

We will use the notation

```
$f \sim \mathcal{GP}(\mu, \kappa)$
```

to express that function $f(\mathbf{x})$ is distributed according to a Gaussian process with mean function $\mu(\mathbf{x})$ and covariance function $\kappa(\mathbf{x},\mathbf{x}')$. If we want to align $\{x_1, \dots, x_n\}$ to the pixels on the screen or the dots on the paper, and print the marginal distributions for each $\{x_1, \dots, x_n\}$, so that it appears as a continuous line to the eye (despite the fact that we can only observe the distribution in a finite, arbitrary, set of points).

As we observe the inputs in A, and let $f(\mathbf{x})$ denote the vector of observed outputs we assume for now that the observations are made without noise). We use the notation $\kappa(\mathbf{X}, \mathbf{X})$ and $\mathbf{K}(\mathbf{X}, \mathbf{X})$ as defined by (8.12) and (8.12c) to write the joint distribution between the observed values $f(\mathbf{X})$ and the test value $f(\mathbf{x})$

```
$p\left(\begin{array}{c}f(\mathbf{X})\f(\mathbf{x})\end{array}\right) = N\left(\begin{array}{c}f(\mathbf{X})\f(\mathbf{x})\end{array};\begin{array}{c}\\mu(\mathbf{X})\\mu(\mathbf{x})\end{array};\begin{array}{cc}\\kappa(\mathbf{X},\mathbf{X}) & \kappa(\mathbf{X},\\mathbf{x})\T\end{array}\right)$
```

Now, as we have observed $f(\mathbf{X})$, we use the expressions for the Gaussian process to write the distribution for $f(\mathbf{x})$ on the conditions of $f(\mathbf{X})$

```
$p(f(\mathbf{x})|f(\mathbf{X})) = $
```

```
$N(f(\mathbf{x});\mu(\mathbf{x}) +\mathbf{K}(\mathbf{x},\mathbf{X})\T\mathbf{K}(\mathbf{X},\mathbf{X})^{-1}(f(\mathbf{X})-\mu(\mathbf{X}))), \kappa(\mathbf{x},\mathbf{x}) - \mathbf{K}(\mathbf{x},\mathbf{X})\T\mathbf{K}(\mathbf{X},\mathbf{X})^{-1}\mathbf{K}(\mathbf{X},\mathbf{x}))$,
```

which is another distribution for any test input, $f(\mathbf{x})$. We have now introduced the somewhat abstract concept of a Gaussian process. In some subjects, such as signal processing, so-called white Gaussian processes are common. A white Gaussian process has a white covariance function

```
$\kappa(\mathbf{x},\mathbf{x}') = \begin{cases} 1 & \text{if } \mathbf{x}=\mathbf{x}'\\\0 & \text{otherwise} \end{cases}$
```

which implies that $f(\mathbf{x})$ is uncorrelated to $f(\mathbf{x}')$ unless $\mathbf{x}=\mathbf{x}'$. White Gaussian processes are less used in supervised machine learning, but we will instead have to look at how kernel ridge regression can be turned into a Gaussian process, where the mean function becomes zero and the covariance function becomes the kernel from Chapter 8.
