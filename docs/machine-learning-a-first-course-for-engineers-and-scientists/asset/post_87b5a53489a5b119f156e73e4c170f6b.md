
## 2.3 A rule-based method: Decision trees

To generalize this we still solve the optimization problem (2.6) to compute the split, but choose $Q_t$ in a different way which respects the categorical nature of a classification problem. To this end, we first introduce

```
$$\tilde{\ell}_{lm} = \frac{1}{n_t} \sum_{i\in R_t} \mathbb{i}\{y_i = m\}$
```

as the proportion of training observations in the $t$th region which belongs to the $m$ class. We can then define the *splitting criterion*, that is $Q_t$, based on these classes proportion. One alternative is the misclassification rate

```
$Q_t = 1 - \max_m \tilde{\ell}_{lm}. \quad (2.7a)
```

which is simply the proportion of data points in region $R_t$ which do not belong to the common class. Other splitting criteria are the *Gini index* and the entropy criterion,

```
$Q_t = - \sum_M \tilde{\ell}_{lm} \ln \tilde{\ell}_{lm}. \quad (2.7c)
```

In Example 2.6 we illustrate how to construct a classification tree using binary splitting and with the entropy as the splitting criterion.

We want to learn a classification tree by using the entropy criterion in (2.7) and growing the tree until there are no regions with more than five data points left.

**First split:** There are infinitely possible splits we can make, but all splits which give the same partition of the data points are equivalent. In practice we have many different splits to consider in this dataset. The data (dots) and possible splits (dashed lines) are visualized in Figure 2.8.

We consider all points in turn. We start with the split at $x_1 = 2.5$, which splits the input space into the two regions, $R_1 = x_1 < 2.5$ and $R_2 = x_1 \geq 2.5$. In region $R_1$ we have two blue points and one red, and so $n_1 = 3$ data points. The proportion of the two classes in $R_1$ will be $\eta_1 = 2/3$ and $\tilde{R}_1 = 1/3$. The entropy is calculated as

$Q_1 = - \tilde{R}_1 \ln(\tilde{R}_1) - \tilde{R}_{1R} \ln(\tilde{R}_{1R}) = -\frac{2}{3}\ln(\frac{2}{3}) - \frac{1}{3}\ln(\frac{1}{3}) = 0.64$.

In $R_2$ we have $n_2 = 7$ data points with proportions $\tilde{R}_{2B} = 3/7$ and $\tilde{R}_{2R} = 4/7$. The entropy for this regions will be

$Q_2 = - \tilde{R}_{2B} \ln(\tilde{R}_{2B}) - \tilde{R}_{2R} \ln(\tilde{R}_{2R}) = -\frac{3}{7}\ln(\frac{3}{7}) - \frac{4}{7}\ln(\frac{4}{7}) = 0.68$.

and inserted in (2.6) the total weighted entropy for this split is

$n_1Q_1 + n_2Q_2 = 3 \cdot 0.64 + 7 \cdot 0.68 = 6.69$.

When choosing between the different criteria, the misclassification rate sounds like a reasonable choice that is typically the reason we want the final model to do well. However, one drawback is that it does not favor pure nodes. Pure nodes mean nodes where most of the data points belong to a class. It is always an advantage to use pure nodes in the greedy process that we use to grow the tree, since it can lead to a total of splits. Both the entropy and the Gini index provide more purity native than misclassification rate.

This advantage can also be considered in Example 2.6. Consider the first split in this example. If we could use the misclassification rate as the splitting criterion, but the split $x_2 < 5.0$ as well as the split $x_3 < 3.0$ would provide a total misclassification of 0.2. However, the entropy criterion, provides a pure node $R_1$. If we were to grow the tree with the split $x_2 < 5.0$ the misclassification after the second split would be 0.2.
