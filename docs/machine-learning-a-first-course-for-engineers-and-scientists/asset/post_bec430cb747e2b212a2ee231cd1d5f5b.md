
## 7 Ensemble methods: Bagging and boosting

## 7.4 Gradient boosting

In a classification problem the outputs from the ensemble members does not have correspond to class predictions in general. Instead, there are two properties that distinguish boosting from other models.

- 1. The basic functions are learned from data and, specifically, each function (that is ensemble member) corresponds to a machine learning model itself—the base of the boosting procedure.
- 2. The basic functions and their coefficients are learned sequentially. That is, we add one component to the sum in (7.14) at each iteration and after $B$ iterations the learning algorithm terminates.

The goal when training an additive model is to select $(\alpha^{(b)}, f^{(b)}(X))_{b=1}^B$ such that the final $f^{(B)}(X)$ minimizes

$$ J(f) = \sum_{i=1}^n L(y_i, f(x_i)) \quad (7.15) $$

for some arbitrary loss function $L$, see Section 5.2. In a binary classification setting, choosing the logistic (or some other robust loss function) instead of the exponential loss results in a much less sensitive to outliers. Here define $f(X) = [f(x_1), \dots, f(x_n)]^T$ as the vector of values obtained by evaluating $f$ at the training data points. Since we do not have an explicit parametric form for $f(x)$, we consider $f$ to be a function of the model $f(x)$.

A consequence of the first point in the list above—that the basic functions are generic machine models—is that the objective (7.15) will lock a fixed minimum, and we then need to approximate some numerical solution. The sequential learning (second point) can be viewed as one way of handling this by using a "greedy" step-wise training. Connecting this to the AdaBoost algorithm, using the exponential loss is convex since it results in tractable expressions for each step of iteration training procedure. However, this is not strictly necessary. Indeed, by using arguments in numerical optimization, we can improve the model at each iteration as long as we move in the right direction. That, at iteration $b$ we introduce a new ensemble member with the objective of reducing the value of the cost function (7.15), without requiring that it is (greedily) minimized. This leads us to the idea of gradient boosting.

Consider the $b$th iteration of the training procedure. As before we use the sequential nature of the method to write

$$ f^{(b)}(X) = f^{(b-1)}(X) + \alpha^{(b)}f^{(b)}(X), \quad (7.16) $$

and the goal is to select $(\alpha^{(b)}, f^{(b)}(X))$ to reduce the value of the cost function (7.15). That is, we want to choose the $b$th ensemble member by

$$ J(f^{(b-1)}(X) + \alpha^{(b)}f^{(b)}(X)) \le J(f^{(b-1)}(X)). \quad (7.17) $$

Akin to the gradient descent algorithm (see Section 5.4), we do this by taking a step in the negative direction of the cost function. In the context of boosting we do not assume a specific form for the base function, but rather construct each ensemble member using a learnable model, such as a tree. What then, should we compute the gradient of the cost function with respect to? The idea behind gradient boosting, which allows us to address this, is to use a nonparametric approach and represent the model $f(x)$ by the values it assigns to the $n$ training data points. That is, we compute the gradient of the cost function directly with respect to the (vector of) function values $f(X)$. This is an $n$-dimensional gradient vector

$$ \frac{\partial J}{\partial f(X)} = \begin{pmatrix} \frac{\partial L(y_1, f(x_1))}{\partial f(x_1)} \\ \vdots \\ \frac{\partial L(y_n, f(x_n))}{\partial f(x_n)} \end{pmatrix} = n \begin{pmatrix} \frac{\partial L(y_1, f(x_1))}{\partial f(x_1)} \\ \vdots \\ \frac{\partial L(y_n, f(x_n))}{\partial f(x_n)} \end{pmatrix}, \quad (7.18) $$

where we have assumed that the loss function $L$ is differentiable. Hence, to satisfy (7.17) we should select $f^{(b)}(X) = -\nabla_f C(f^{(b-1)}(X))$ and then pick the coefficient $\alpha^{(b)}$—which takes the role of the step length in the gradient descent algorithm—in some way, by line search.

However, selecting the $b$ ensemble member $f^{(b)}(X)$ so that it exactly matches the negative gradient is typically not possible. The reason is that the ensemble members $\{f_i\}$ are restricted to some specific functional form, for instance the set of functions that can be generated by a tree-based model of certain depth. Neither is desirable in general, since exactly matching the gradient at all points could lead to overfitting. Ideally, we are not interested in fitting the training data as well as possible, but rather generalizing to new data.

### Method 7.3: a simple gradient boosting

When using trees as base models, optimizing $\alpha^{(b)}$ can be done jointly with $f^{(b)}$. Specifically, instead of first computing constants for terminal nodes of the tree (see Section 2.3) and multiplying these with a constant $\alpha^{(b)}$, we can solve one separate line search problem for each terminal node directly.

### Learn a simple classifier

**Data:** Training data $\{x_i\}_{i=1}^n$

**Result:** Boosted classifier $\hat{f}^{(B)}$

- 1. Initialize with simple classifier, $f^{(0)}(X) = 0$
- 2. For $b = 1, \dots, B$
- 3. Compute $d_i^{(b)} = -\frac{\partial L(y_i, f(x_i))}{\partial f(x_i)}|_{f=f^{(b-1)}(X)}$
- 4. Compute $\alpha^{(b)} = \arg\min_\alpha \sum_{i=1}^n L(y_i, f^{(b-1)}(x_i) + \alpha d_i^{(b)})$
- 5. Update the deed ensemble member $f^{(b)}(X)$

### Predict with the gradient boosting

**Data:** $B$ classifiers and input $x_*$

**Result:** Prediction $\hat{f}^{(B)}(x_*)$

- 1. Output $\hat{f}^{(B)}(x_*) = \sum_{b=1}^B \alpha^{(b)} f^{(b)}(x_*)$

> Time to reflect 7.4: We have described boosting algorithms as a greedy stepwise training of an additive model. Based on this interpretation, another approach for training these models is by coordinate ascent (see Section 5.4). That is, instead of adding a new component at each iteration of the training algorithm, stopping after B iterations, we can fix the number of components and cycle through them (updating one component at a time) until convergence. What are the possible drawbacks and benefits of this alternative training approach?

While presented for classification in Method 7.3, gradient boosting can also be used for regression with minor modifications. As mentioned above, gradient boosting requires that it is at least everywhere differentiable, so that it is possible to compute the gradient of the loss function. However, some implementations of gradient boosting require stronger conditions, such as second order differentiability. The logistic loss (see Section 5.2) in this respect a “safe choice” which is infinitely differentiable and strongly convex, while still enjoying good statistical properties. As a consequence, the logistic loss is one of the most commonly used loss functions in practice.
