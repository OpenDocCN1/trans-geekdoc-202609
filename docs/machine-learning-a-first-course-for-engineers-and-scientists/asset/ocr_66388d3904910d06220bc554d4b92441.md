Logistic regression, for example, can be brought into this form by simply using $f(x) = \theta^T x$, as shown in (3.39). More generally, for a nonlinear generalization of the logistic regression model where the probability of the positive class is modeled as in (5,3), the prediction (5.12) corresponds to the most likely class. Not all classifiers use a probabilistic interpretation, however, they can still be expressed in (5.12) for some underlying function $f(x)$.

The decision boundary for any classifier of the (5.12) is given by the values of $x$ for which $f(x) = 0$. To simplify our decision we assume that the data points fall exactly on the decision boundary (which always gives rise to ambiguity). This will imply that $\tilde{y}(x)$ as defined above is either -1 or +1. Based on the function $f(x)$, we say that

```
$$$the margin of a classifier for a data point (x, y) is y \cdot f(x).$$$$
```

It follows that if $y$ and $f(x)$ have the same sign, meaning that the classification is correct, then the margin is positive. Otherwise, if an incorrect classifier $y$ and $f(x)$ have different signs and the margin is negative. The margin is given as a measure of certainty in a prediction, data points with small margins in some sense (not necessarily Euclidean) are close to the decision boundary. The margin plays a similar role in logistic regression

We can now define loss functions for classification in the term, by assigning a small loss to positive margins (correct classifications) and a large loss to negative margins (misclassifications). We can, instance, re-formulate the loss (5.34) in terms of the margin

$$$L(y \cdot f(x)) = \exp(1 + \exp(-y \cdot f(x)))$$$$

where, in line with the linear logistic regression model corresponds to $f(x) = \theta^T x$. Analogously to the development of the logistic loss in Chapter 3, this is another way of writing the cross entropy (or negative log-likelihood) (5.11), assuming that the probability of the positive class is modeled after (5.3). However, from an alternative point of view we can consider (5.14) as a generic margin-based loss, without linking it to the probabilistic model (5.3). That is, we postulate a classifier according to (5.12) and learn the parameters of $f(x)$ by minimizing (5.14). This is of course equivalent to logistic regression, except for the fact that we have nearly lost the notion of a class probability estimate $g(x)$ and only have a "hard" prediction $\tilde{y}(x)$. However, we recover the class probability estimate when we discuss the misclassification loss in terms of the logistic loss. We can also re-formulate the loss in of

$$$L(y \cdot f(x)) = \begin{cases} 1 & y \cdot f(x) < 0 \ 0 & \text{otherwise.} \end{cases}$$$$
