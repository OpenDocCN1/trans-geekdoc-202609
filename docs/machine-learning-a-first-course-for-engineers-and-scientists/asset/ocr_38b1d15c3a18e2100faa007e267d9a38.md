In Figure 9.4 and 9.5 we illustrated the marginals for a finite-dimensional multivariate Gaussian random variable. However, we are dealing with the Gaussian process, which is a stochastic process on a continuous space.

The extension of the Gaussian distribution (defined on a finite set) to the Gaussian process (on a continuous space) is achieved by replacing the index $\{1, 2, 3, 4, 5, 6\}$ in Figure 9.5 by a varying values on a continuous space, for example the real line. We then have to replace the random variables $f_1, f_2, \dots, f_n$ with a random function (that is, a stochastic process) $f$ which can be evaluated at any $x$ in space. Furthermore, in the multivariate distribution $\mu$ is a vector with $q$ components, and $\Sigma$ is a $q 	imes q$ matrix. Instead of having a hyperparameter for each element in this mean and covariance matrix, in the Gaussian process we replace $\mu$ by a mean function $\mu(x)$ which we can insert any $x$, and the covariance matrix $\Sigma$ is replaced by a covariance function $k(x, x')$ which we can insert any $x$ and $x'$. This mean and covariance function can we parametrize with few hyperparameters. In these functions we can enforce properties that we want the Gaussian process to obey, for example that two functions $f(x_1)$ and $f(x_2)$ should be more correlated if $x_1$ and $x_2$ are closer to each other, than if they are far apart.

The Gaussian property holds. For any finite set of points $(x_1, \dots, x_n)$, we have

```
$p \begin{pmatrix} f(x_1) \ \vdots \ f(x_n) \end{pmatrix} = \mathcal{N} \left( \begin{pmatrix} \mu(x_1) \ \vdots \ \mu(x_n) \end{pmatrix}, egin{pmatrix} k(x_1, x_1) & \dots & k(x_1, x_n) \ \vdots & \ddots & \vdots \ k(x_n, x_1) & \dots & k(x_n, x_n) \end{pmatrix} ight) \quad (9.18)$
```

then $f$ is a Gaussian process.

That is, with a Gaussian process and any choice of $\{x_1, \dots, x_n\}$, the vector values of $[f(x_1), \dots, f(x_n)]$ has a multivariate Gaussian distribution, just like the one in Figure 9.5.
