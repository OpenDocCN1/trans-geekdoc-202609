# 9 The Bayesian approach and Gaussian processes

The expected value of $z$ is $E[z] = \mu$ and the variance of $z_1$ is $var(z_1) = E[(z_1 - E[z_1])^2] = \sigma_1^2$, and similarly for $z_2, \dots, z_q$. Moreover the covariance between $z_1$ and $z_2$ is $cov(z_1, z_2) = E[(z_1 - E[z_1])(z_2 - E[z_2])] = \sigma_{12} = \sigma_{21}$, and similarly for any other pair of $z_i, z_j$. All these properties can be derived from the probability density function of the multivariate Gaussian distribution, which

```
$N(z; \mu, \Sigma) = (2\pi)^{-d/2} \det(\Sigma)^{-1/2} \exp(-\frac{1}{2}(z-\mu)^T\Sigma^{-1}(z-\mu)).$$
```

If all off-diagonal elements of $\Sigma$ are zero, the elements of $z$ are just independent Gaussian random variables. However, if some off-diagonal element, say $\sigma_{ij}$ ($i \neq j$), is nonzero then there is a correlation between $z_i$ and $z_j$. The correlation means that $z_i$ carries information also about $z_j$, and vice versa. Some important results on the multivariate Gaussian distribution can be manipulated in Appendix 9A.

# Linear regression with the Bayesian approach

We will now use the Bayesian approach to the linear regression model. We will spend some effort on mapping the elements of linear regression from Chapter 3 to the Bayesian terminology, and thereafter derive the solution.

From Chapter 3 we have the linear regression model is

```
$y = f(x) + \varepsilon, \quad f(x) = \theta^T x, \quad \varepsilon \sim N(0, \sigma^2).$$
```

which equivalently can be written as

```
$p(y|\theta) = N(y|\theta^T x, \sigma^2).$$
```

This is an expression for one data point $y$, and for the vector of all data outputs $y$ we can write

```
$p(y|\theta) = \prod_{i=1}^n p(y_i|\theta, x_i, \sigma^2) = \prod_{i=1}^n N(y_i|\theta^T x_i, \sigma^2 i).$$
```

where in the last case we used the notation $X$ from (3.5) and that an $n$-dimensional Gaussian random vector with a diagonal covariance matrix is equal to $n$ scalar random variables. In the Bayesian approach there is also a need for a prior $p(\theta)$ for the unknown parameters $	heta$. In Bayesian linear regression the prior is often chosen as a Gaussian with mean $\mu_0$ and covariance $\Sigma_0$.

```
$p(\theta) = N(\theta; \mu_0, \Sigma_0).$$
```

with, for example, $\Sigma_0 = I\sigma_0^2$. The reason for this is frankly that it simplifies calculations, much like the squared error simplifies the computations for plain linear regression. The next step is to compute the posterior. It is possible to derive it using Bayes' theorem, but since $p(y|\theta)$ as well as $p(\theta)$ are multivariate Gaussian distributions, Corollary 9.1 in Appendix 9.A directly gives us that

```
$p(\theta|y) = N(\theta; \mu_n, \Sigma_n).$$
```

```
$\mu_n = \Sigma_n (\frac{1}{\sigma_0^2}\mu_0 + X^T y).$$
```

```
$\Sigma_n = (\frac{1}{\sigma_0^2}I + X^T X)^{-1}.$$
```
