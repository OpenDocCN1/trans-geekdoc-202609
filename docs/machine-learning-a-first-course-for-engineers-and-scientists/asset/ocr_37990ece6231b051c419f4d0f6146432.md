# 10.4 Representation learning and dimensionality reduction

A deep generative model x = f_θ(z) defines a relationship between the observed data point x and some latent representation z of the same data point. The word latent (hidden), here refers to the fact that z is not directly observed, but it nevertheless carries useful information about the data. Given the mapping f (which, once it has been, knowing the latent variable z is enough to reconstruct the data point x, by simply computing x = f_θ(z). The variable z is also commonly referred to as a (latent) code, and the mapping as a decoder, which we use to reconstruct the data.

Much of contemporary machine learning, and in particular deep learning, with intricate dependencies between the coordinates x_i, i=1,...,p. Put differently, in the "raw data space", each coordinate x_i might not carry useful information, but when we put them together we meaningful patterns across x we wish to learn. The typical example is (again) when x corresponds to an image, and the coordinates x_i the individual pixel values. One-by-one pixel values are not very informative about the contents of the image, but processed jointly (as an image), deep neural networks can learn to recognize features, classify objects, design images, and solve many non-trivial tasks. Similar examples are found, in natural language processing where x_i might correspond to a character in a text, but not until we put all characters together x that the semantic meaning of the text can be understood.

With these examples, it can be argued that the success of deep learning is due to its capability of

> learning a useful representation of high-dimensional data.

For supervised learning of neural networks, as discussed in Chapter 6, the representation learning is often implicit and takes place alongside the learning of a classification or regression model. There is no clear-cut definition of what we mean by a latent representation in such cases. However, we can think about the first choice of layers in a deep network as being responsible for learning an informative representation of the raw data,¹⁰ which is then used by the latter part of the network to solve the specific (for example, regression or classification) task at the end.

In this contrast with deep generative models, as pointed out above, the latent representation is an explicit part of the model. However, the possibility of learning a representation directly from data is not unique to generative models. In this section we will introduce a method for unsupervised learning referred to as an auto-encoder. The autoencoder is used for dimensionality reduction by mapping the data to a lower-dimensional latent code. We will then derive a statistical method from PCA and show how this can be viewed as a special case of an auto-encoder which is restricted to linear.

# Auto-encoders

For many high-dimensional problems it is reasonable to assume that the effective dimensionality of data is smaller than the observed dimension. That is, most of the information in the p-dimensional variable x can be retained even if we compress the data into a q-dimensional representation z with q < p. For instance, in the context of generative adversarial networks (see Section 10.3) we argued that the latent variable z can be of much lower dimension than x, if the model is used to generate high-resolution images. In such a case the effective dimension of the generated samples for a fixed model f_θ is q, irrespective of the observed (dimension) of x.¹¹¹
