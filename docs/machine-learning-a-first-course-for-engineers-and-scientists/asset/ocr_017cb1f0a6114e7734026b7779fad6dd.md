One could induce some manual work by first selecting a coarse grid to get an initial guess, and thereafter refine the grid only around the promising candidates. In practice, the problem has more than one dimension, and could also be beneficial to select the grid points randomly instead of using an equally spaced linear or logarithmic grid.

The manual procedure of choosing a grid method, however, become quite tedious, and one could wish for an automated method. That is, in fact, possible by treating the grid point selection as a machine learning problem. If we consider the method in which we use a regression method to learn a model for the objective function then that model can, in turn, be used to answer questions on where to evaluate the objective function, andby selecting the next grid point. A concrete method built from this is the Gaussian process optimization method, which uses Gaussian processes (Chapter 9) for learning a model of the objective function.
