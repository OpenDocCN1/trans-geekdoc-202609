## Input normalization

A important practical aspect when using $p=2$ input variables $x = [x_1, x_2]^T$ is the importance of normalization of the input data. Imagine a training dataset with values of $x_1$ in the much larger range [100, 1100] and the values for $x_2$ in the smaller range [0, 1]. It could be that $x_1$ and $x_2$ are measured in different units. The Euclidean distance between a test point $x$, and a training point $x_i$ is $\|x - x_i\|_2$. This expression will be dominated by the first term $(x_1 - x_{i,1})^2$, the second term $(x_2 - x_{i,2})^2$ tends to have a much smaller effect, simply due to the different magnitude of $x_1$ and $x_2$. ## 2.3 A rule-based method: Decision trees

The decision tree partitions the input space into regions, which is a piecewise constant function of the input. The rules are organized in a graph in Figure 2.6 which is referred to as a binary tree. To use this tree to predict a label we start at the top, referred to as the root of the tree. If the condition is met the tree proceeds down to the leaves. If the condition is not met at the root, that is, if $x_2 < 3.0$, we proceed down the left branch otherwise the right branch. For each new internal node of the tree, we check the rule associated with that node and pick the left or right branch. We continue and work our way until we reach the end of a path, called a leaf node. Each final node corresponds to a constant prediction $\tilde{y}(\mathbf{x*})$, one of the two classes Red or Blue.

The decision tree partitions the input space into axis-aligned "boxes", as shown in Figure 2.7. By increasing the depth of the tree (the number of steps from the root to the leaves), the partition can be made finer and finer thereby describing more complicated functions of the input variable.
