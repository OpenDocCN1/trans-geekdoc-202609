# 5.3 Regularization

We will now take a closer look at regularization, which was briefly introduced in Section 3.3 as a useful tool for avoiding overfitting if the model was too flexible, such as a polynomial of high degree. We have also discussed thoroughly in Chapter 4 the need for tuning the model flexibility, which effectively is the purpose of regularization. Finding the right level of flexibility, and avoiding overfitting, is very important in practice.

The idea of regularization in a parametric model is to ‘keep the parameters $	heta$ small unless the data convinces us otherwise’, or alternative ‘if a model with small values of the parameters $	heta$ fits the data almost well as a model with larger values, the one with small parameter values should be preferred’. There are, however, many ways to implement this and we distinguish between explicit regularization and implicit regularization. We will first discuss explicit regularization, which amounts to modifying the cost function, and in so-called $L^2$ and $L^1$ regularization.

# $L^2$ regularization

The $L^2$ regularization (also known as Tikhonov regularization, ridge regression and weight decay) decays by adding an extra penalty term $||	heta||^2$ to the cost function. Linear regression with squared error loss and $L^2$ regularization, as an example, amounts to solve

```
$$\hat{	heta} = \arg\min_{\theta ||\mathbf{X}\theta - y||^2 + \lambda ||\theta||^2.$
```

By choosing the regularization parameter $\lambda > 0$, a trade-off between the cost function (fitting the data well) and the regularization term (keeping the parameters $	heta$ close to zero) is made. In the setting $\lambda = 0$ we recover the least squares problems (3.12), whereas $\lambda \to \infty$ will force all parameters $	heta$ to 0. A good choice of $\lambda$ is usually somewhere in between, depending on the actual problem, and can be selected using cross-validation.

It is actually possible to derive a version of the normal equations for (5.23),

```
$$\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1}}\hat{	heta} = \mathbf{X}^T\mathbf{y}.$
```

where $I_{p+1}$ is the identity matrix of size $(p+1) \times (p+1)$. For $\lambda > 0$, the matrix $\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1}$ is always invertible, and we have the closed solution

```
$$\hat{	heta} = (\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1})^{-1}\mathbf{X}^T\mathbf{y}.$
```

This also reveals another reason for using regularization in linear regression, if $\mathbf{X}^T\mathbf{X}$ is not invertible, then the ordinary equations (3.13) have no unique solution $\hat{	heta}$, whereas the $L^2$-regularized version always has the unique solution (5.25) if $\lambda > 0$.

# $L^1$ regularization

With $L^1$ regularization (also known LASSO, for Absolute Least Shrinkage and Selection Operator), the penalty term $|\theta||$ is added to the cost function. Here $|\theta|| = |\theta_0| + |\theta_1| + \dots + |\theta_p|$. The $L^1$ regularized cost function for linear regression (with squared error loss) becomes

```
$$\hat{	heta} = \arg\min_{\theta ||\mathbf{X}\theta - y||^2 + \lambda ||\theta||.$
```

Contrary to linear regression with $L^2$ regularization (3.48), there is no closed-form solution available for (5.26), where we will see in Section 5.4, it is possible to design an efficient numerical algorithm for solving (5.26).
