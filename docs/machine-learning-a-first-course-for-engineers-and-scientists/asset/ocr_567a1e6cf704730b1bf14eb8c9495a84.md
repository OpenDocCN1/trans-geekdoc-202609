What is less obvious is that there are other loss functions that are also strictly proper, as we will see next. To make the presentation more concrete we will focus on the case of binary classification for the remainder of this section. In binary classification the conditional distribution $p(y|x)$ takes a practically simple form, since it is completely characterized by a single number, namely the probability of the positive class, $p(y=1|x)$.

We proceed by stating the asymptotic minimizer for some of the loss functions presented above. Developing the asymptotic minimizer is often a straightforward calculation, but for brevity we do not include the derivations. Starting with the binary cross-entropy (5.11), its asymptotic minimizer can be shown to be $g^*(x)=p(y=1|x)$. In other words, when $n\to\infty$ the loss (5.11) is minimized when $g(x)$ is equal to the true conditional class probability. This is in agreement with the discussion above, since binary cross-entropy is just another name for the negative log-likelihood.

Turning to the loss (5.17) the asymptotic minimizer is

```
$f^*(x)=\begin{cases}1 & \text{if } p(y=1|x) > 0.5.\-1 & \text{if } p(y=1|x) < 0.5.\end{cases}$
```

This is a non-invertible transformation of $p(y=1|x)$, which means it is not possible to recover $p(y=1|x)$ from the asymptotic minimizer $f^*(x)$. This implies that a classifier learned using hinge loss (such as support vector machines, Section 8.5) is not predict conditional class probabilities.

The squared loss (5.18), on the other hand, is a strictly proper loss function, since its asymptotic minimizer is $f^*(x)=2p(y=1|x)-1$. This also holds for the Huberized square loss (5.19). Recalling our recursion discussion, that by squaring the loss we make it strictly proper, but at the same time we impact robustness. However, the “Huberization” (replacing the quadratic with a linear for for margins) improves the robustness while keeping the property of strictly proper.

We have seen some (but not all) the loss functions are strictly proper, meaning they could potentially predict conditional class probabilities. However, this is only under the assumption that the model is sufficiently flexible that $g(x)$ or $f(x)$ can actually take the shape of the asymptotic minimizer.
