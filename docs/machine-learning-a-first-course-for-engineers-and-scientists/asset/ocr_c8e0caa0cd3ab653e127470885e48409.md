# ### Variance reduction by averaging

By running the bootstrap (Algorithm 7.1) repeated $B$ times we obtain $B$ identically distributed bootstrapped datasets $\tilde{\mathcal{T}}^{(b)}$. We can then use suched datasets to train an ensemble of $B$ base models. We thereafter average their predictions

$\tilde{y}_{bag}(x_*) = \frac{1}{B} \sum_{b=1}^{B} \tilde{y}^{(b)}(x_*) \quad \text{or} \quad \hat{g}_{bag}(x_*) = \frac{1}{B} \sum_{b=1}^{B} \hat{g}^{(b)}(x_*), \quad (7.1)

on whether we are performing regression (predicting an output $\tilde{y}_{bag}(x_*)$) or classification (predicting class probabilities $\hat{g}(X)$). The linear assumption ensures that each base classifier is a vector of class probabilities. If this is not the case, we can instead obtain a "hard" classifier by taking a majority vote over all ensemble members. Note that it is better to take a plain average across the ensemble (each member is weighted equally) in (7.1) due to the fact that all ensemble members are constructed in such way, that is, are identically distributed.

In (7.1), $\tilde{y}^{(1)}(x_*), \dots, \tilde{y}^{(B)}(x_*)$ and $\hat{g}^{(1)}(x_*), \dots, \hat{g}^{(B)}(x_*)$ denote the predictions from the individual ensemble members. The averaged prediction, $\tilde{y}_{bag}(x_*)$ or $\hat{g}_{bag}(x_*)$, is the final prediction from bagging. We may-stabilize this by Method 7.1.
