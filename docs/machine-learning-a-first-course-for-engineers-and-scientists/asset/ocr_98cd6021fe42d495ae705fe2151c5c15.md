Remember that a good value of $\gamma$ is very much relative to the shape of the cost function; $\gamma=0.3$ might be too small (or high) for a different $J(\theta)$.

In practice we do not know $\gamma$, which determines how the $	heta$-step is at each iteration. It is possible to formulate the selection of $\gamma$ as an internal optimization problem that is solved at each iteration, a so-called line-search problem. This will result in a different value for $\gamma$ at each iteration of the algorithm. Here we will consider a simpler solution where we leave the choice of $\gamma$ to the user, or more specifically view it as a hyperparameter. In such cases, it is referred to as the learning rate or step-size. Note that the gradient $
abla_theta J(\theta)$ will decrease and eventually approach 0 at a stationary point (possibly, but not necessarily, a minimum), so Algorithm 5.1 may converge if $\gamma$ is kept constant. This is in contrast to what we later discuss when we introduce the stochastic gradient algorithm.
The choice of learning rate is very important. Some situations with too small, too high and a good choice of learning rate are shown in Figure 5.7. With the intuition from these figures, we advise to monitor $J(\theta^{(t)})$ during the optimization,

+   - decrease the learning rate $\gamma$ if the cost function values $J(\theta^{(t)})$ are gone or oscillating widely (as in Figure 5.7b),
- increase the learning rate $\gamma$ if the cost function values $J(\theta^{(t)})$ are fairly constant and only slowly decreasing (as in Figure 5.7a).

No general convergence guarantees can be given for gradient descent, basically because a bad learning rate $\gamma$ may break the method. However, with the "right" choice of $\gamma$, the value of $J(\theta)$ will decrease for each iteration (as suggested by (5.31)) until a point with zero gradient is found, that is, stationary. A stationary point is, however, not necessarily a minimum, but can be a maximum or a saddle-point of the objective function. In practice one typically monitors the value of $J(\theta)$ and terminate the algorithm when it does not decrease anymore, and hope it has reached a minimum.
in non-convex problems with multiple local minima, we cannot expect gradient descent to find the global minimum. The initialization is critical for determining which stationary (or global) point is found, it therefore be a good practice (if time and computational resources permit) to run the optimization multiple times with different initializations. For highly non-convex problems such as training a deep neural network (Chapter 6) when we cannot afford to run the training, we employ method-specific heuristics and tricks to find a good initialization.
