## Multiple channels

The networks presented in Figure 6.10 and 6.12 have only 10 parameters each. Even though this parameterization comes with several advantages, one filter is not sufficient to encode all interesting properties of the images in our data. With their own set of parameters. To extend the method, we add multiple filters, each with the same convolution operation as explained in Section 6.3. Hence, each of hidden units in a CNN is organized into a so-called tensor with the dimensions (rows × columns × channels). In Figure 6.14, the first layer of input has four channels and the last consequently has channels $6 \times 6 \times 4$.

When we continue to stack layers, filters not only on one channel but on all the channels in the previous layer. This is displayed in the second of Figure 6.14. As a consequence, each filter is a tensor of dimension (rows × columns × channels). For example, each filter in the second convolutional layer in Figure 6.14 is of size $3 \times 3 \times 4$. If we collect all filter parameters in one weight tensor, $W$, that will be of dimension (rows × columns × input channels). In the second convolutional layer in Figure 6.14, the corresponding weight matrix $W^{(2)}$ is a tensor of $3 \times 3 \times 4$. With multiple filters in each layer, each of them can be sensitive to different features in the image, such as edges, lines or circles enabling a representation of the features in our training data.

The convolutional layer with input channels and output channels can mathematically be described as

```python
$q_{ij}^{(l)} = \frac{1}{F_1 F_2 C} \sum_{m=1}^{F_1} \sum_{n=1}^{F_2} \sum_{k=1}^{C} q_{(i-m+1, j-n+1, k)}^{(l-1)}, \quad (6.32)$
```

## Full CNN architecture

A full CNN architecture consists of multiple convolutional layers. For predictive tasks, we decrease the number of rows and columns in the hidden layers as we proceed through the network, but instead increase the number of channels to enable the network to encode more high level features. After a few convolutional layers we usually end the network with one or more dense layers. For an image classification task, we use a softmax layer at the very end to get outputs in the range [0,1]. The function when training a CNN will be the same as in the regression and classification networks explained earlier, depending on which type of problem we have.
