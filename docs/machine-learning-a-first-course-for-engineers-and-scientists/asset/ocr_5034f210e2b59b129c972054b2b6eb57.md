Analogously to the derivation of kernel ridge regression in (8.12), we are now ready to apply the kernel trick and replace all instances of $\phi(x)\phi(x)'$ with a kernel $k(x,x')$. With same notation in (8.12), we get

```
$m_* = K(\mathbf{x}_*, \mathbf{X})\top(\sigma^2 I + K(\mathbf{X}, \mathbf{X}))^{-1}\mathbf{y}_\quad (9.25a)
```

```
$\sigma_* = k(\mathbf{x}_*, \mathbf{x}_*) - K(\mathbf{x}_*, \mathbf{X})\top(\sigma^2 I + K(\mathbf{X}, \mathbf{X}))^{-1}K(\mathbf{X}, \mathbf{x}_*)\quadquad (9.25b)
```

The posterior predictive is defined by (9.23a) and (9.25b) the Gaussian process model again, identical to (9.21) if $\mu(\mathbf{x}_*) = 0$ and $\sigma^* = 0$. The reason for $\mu(\mathbf{x}_*)=0$ is that this derivation starts with $\mu_0=0$. When we derived (9.21) we assumed that we observed $f(\mathbf{x})$ (rather than $y_*, f(\mathbf{x}) = f(\mathbf{x}) + \epsilon$), which is the reason why $\sigma=0$ in (9.21). The Gaussian process is a version of Bayesian linear regression, much kernel ridge is a kernel version of (regularized) linear regression, as illustrated in Figure 9.7. In order to see the connection to kernel ridge, note that (9.25a) is identical to (8.14) with $\sigma^2=\lambda n$. It is, also important to note the difference in that there is no counterpart to (9.25b) for kernel ridge regression, simply because kernel regression does not predict a probability distribution.

The fact that the kernel plays the role of a covariance function in the Gaussian process gives us another interpretation of the kernel in Section 8.4, the kernel $k(x,x')$ determines how strong the correlation between $f(x)$ and $f(x')$ is assumed.

> **Time to reflect 9.1:** Verify that you retrieve Bayesian linear regression when using the linear kernel (8.23) in the Gaussian process. Why is that?

It is not common to write out the addition of $\sigma^2I$ to the Gram matrix $K(\mathbf{X}, \mathbf{X})$, but instead add a white noise kernel (9.22) multiplied with $\sigma^2$ to the original kernel, $\tilde{k}(x,x') = k(x,x') + \sigma^2\delta(x,x')$. We then replace $\sigma^2 I + K(\mathbf{X}, \mathbf{X})$ with $\tilde{K}(\mathbf{X}, \mathbf{X})$, where $\tilde{K}$ is built using $\tilde{k}(x,x')$. Then, (9.25) simplifies to

```
$m_* = K(\mathbf{x}_*, \mathbf{X})\top\tilde{K}(\mathbf{X}, \mathbf{X})^{-1}\mathbf{y}.\quad (9.26a)
```

```
$\sigma_* = k(\mathbf{x}_*, \mathbf{x}_*) - K(\mathbf{x}_*, \mathbf{X})\top\tilde{K}(\mathbf{X}, \mathbf{X})^{-1}\tilde{K}(\mathbf{X}, \mathbf{x}_*) - \sigma^2.\quadquad (9.26b)
```
