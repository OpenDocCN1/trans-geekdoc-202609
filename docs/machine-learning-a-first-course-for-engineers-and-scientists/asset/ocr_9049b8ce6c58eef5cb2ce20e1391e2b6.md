# 8.2 Kernel ridge regression

A kernel κ(x, x') (is in this book) takes two arguments x and x' from the same space, and returns a scalar. Throughout this book, we limit ourselves to kernels that are real-valued and symmetric, that is, κ(x, x') = κ(x', x) ℝ for all x and x'. Equation (8.10), for example, is such a kernel. And more generally the inner product of two nonlinear transformations is an kernel

```
κ(x, x') = ϕ(x)ᵀ ϕ(x'). (8.11)
```

The important point at this stage is that ϕ(x) only appears in the linear regression model (8.7) via inner products, we do not have to design a d-dimensional vector ϕ(x) and derive its inner product. Instead, we can just choose a kernel κ(x, x') directly which is the kernel trick.

+   If x enters as ϕ(x)ᵀ ϕ(x') only, we can choose a kernel κ(x, x') instead of choosing ϕ(x).

To be clear with what we mean in practice, we write (8.7) as (8.12):

```
ŷ(x*) = y*ᵀ (K(x*, x*) + nλI)⁻¹ K(x, x*). (8.12a)
```

```
K(X, X) = [ κ(x1, x1) κ(x1, x2) ... κ(x1, xn); κ(x2, x1) κ(x2, x2) ... κ(x2, xn); ...; κ(xn, x1) κ(xn, x2) ... κ(xn, xn) ] (8.12b)
K(X, x*) = [ κ(x1, x*); κ(x2, x*); ...; κ(xn, x*) ] (8.12c)
```

These equations described linear L²-regularization using a kernel κ(x, x'). Since L²-regularization is also called ridge regression, we refer to (8.12) as kernel ridge regression. The n × n matrix(X, X) is obtained by evaluating the kernel at all pairs of training inputs and is called the Gram matrix. We initially argued that linear regression with infinite-dimensional nonlinear transformation vector ϕ(x) is equivalent to that. The choice of kernel is now to select a kernel κ(x, x') instead of ϕ(x). In practice, choosing κ(x, x') is much less tedious than choosing ϕ(x), as we can compute (8.12a).

Another point in principle is the requirement that K(X, X) + nλI exists. We are therefore safe if we restrict ourselves to kernels for which the Gram matrix K(X, X) is always positive semidefinite. Such kernels are called positive semidefinite kernels. The use of kernel ridge regression chooses a positive semidefinite kernel κ(x, x'), and therefore does not have to select or compute ϕ(x). A corresponding ϕ(x) always exists for a positive semidefinite kernel commonly used in practice. One positive semidefinite kernel is the squared exponential kernel (also known as the RBF, exponentiated or Gaussian kernel)

```
κ(x, x') = exp(||x - x'||² / 2ℓ²)) (8.13)
```

where the hyperparameter λ > 0 is a design choice left to the user, for example by chosen variation of a positive semidefinite kernel known as the polynomial kernel

> ³Confusing enough, such kernels are called positive definite in some texts.
