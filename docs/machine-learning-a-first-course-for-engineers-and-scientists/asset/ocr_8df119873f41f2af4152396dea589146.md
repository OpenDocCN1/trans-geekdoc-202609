# 3.1 Linear regression

When using the squared error loss for a linear regression model over $\mathcal{T}$, we thus need to solve the problem

```
$$\hat{\theta} = \arg min_{\theta} \frac{1}{n}\sum_{i=1}^n (\theta^T\mathbf{x}_i - y_i)^2 = \arg min_{\theta} ||\mathbf{X}\theta - \mathbf{y}||_2^.$
```

From a linear algebra point of view, this can be seen as finding the closest vector to $\mathbf{y}$ (in an Euclidean sense) to the subspace of $\mathbb{R}^n$ spanned by the columns of $\mathbf{X}$. The solution is the orthogonal projection of $\mathbf{y}$ onto this subspace, and the corresponding $\hat{	heta}$ can be shown (see Section 3.A) to fulfill

```
$$\mathbf{X}^T\hat{\theta} = \mathbf{X}^T\mathbf{y}.$$
```

Equation (3.13) is often referred to as the normal equations, and which gives the solution to the squares problem (3.12). If $\mathbf{X}^T\mathbf{X}$ is invertible, then the $\hat{	heta}$ has the closed-form expression

```
$$\hat{\theta} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}.$$
```

The fact that this closed-form solution exists is, and probably the reason for why the linear regression with squared error loss is extremely common in practice. Other functions lead to optimization problems that often lack closed-form solutions., and we summarize it as Method 3.1 and illustrate by Example 3.2.

> **Time to reflect 3.2:** If the columns of $\mathbf{X}$ are linearly independent and $p = n-1$, $\mathbf{X}$ spans the entire $\mathbb{R}^n$.
