In Figure 9.4 and 9.5 we illustrated the marginals for a finite-dimensional multivariate Gaussian variable. However, we are dealing with the Gaussian process, which is a stochastic process on a continuous space. The extension of the Gaussian distribution (defined on a finite set) to the Gaussian process (on a continuous space) is achieved by replacing the index $\{1, 2, 3, 4, 5, 6\}$ in Figure 9.5 by varying values on a continuous space, for example the real line. We then have to replace the random variables $f_1, f_2, \dots, f_n$ with a random function (that is, stochastic process) $f$ which can be evaluated at any $x$ in space. Furthermore, in the multivariate distribution $\mu$ is a vector with $q$ components, and $\Sigma$ is a $q \times q$ matrix. Instead of having a hyperparameter for each element in this mean and covariance matrix, in the Gaussian process we replace $\mu$ by a mean function $\mu(x)$ which can insert any $x$, and the covariance matrix $\Sigma$ is replaced by a covariance function $k(x, x')$ which can insert any $x$ and $x'$. This mean and covariance function can we parametrize with few hyperparameters. In these functions we can enforce properties that we want the Gaussian process to obey, for example that two functions $f(x_1)$ and $f(x_2)$ should be more correlated if $x_1$ and $x_2$ are closer to each other than if they are apart. The Gaussian property holds for any finite set of points $(x_1, \dots, x_n)$, we have

$p \begin{pmatrix} f(x_1) \\ \vdots \\ f(x_n) \end{pmatrix} = \mathcal{N} \left( \begin{pmatrix} \mu(x_1) \\ \vdots \\ \mu(x_n) \end{pmatrix}, \begin{pmatrix} k(x_1, x_1) & \dots & k(x_1, x_n) \\ \vdots & \vdots \\ k(x_n, x_1) & \dots & k(x_n, x_n) \end{pmatrix} \right)$ (9.18)

That is, with a Gaussian process and any choice of $\{x_1, \dots, x_n\}$, the vector values of $[f(x_1), \dots, f(x_n)]$ has a multivariate Gaussian distribution, just like the one in Figure 9.5.

$x_1, \dots, x_n$ can be chosen arbitrarily from the continuous space on which it lives, the Gaussian process defines a distribution for **all** points in that space. For this definition to make sense, $\kappa(\mathbf{x},\mathbf{x}')$ has to be such that a positive semidefinite covariance matrix is obtained for any choice of $\{x_1, \dots, x_n\}$. We will use the notation

$f \sim \mathcal{GP}(\mu, \kappa)$

to express that function $f(\mathbf{x})$ is distributed according to a Gaussian process with mean function $\mu(\mathbf{x})$ and covariance function $\kappa(\mathbf{x},\mathbf{x}')$. We can also consider the Gaussian process on observations $\{f(\mathbf{x}),\mathbf{x}_i\}_{i=1}^n$, the Gaussian counterpart to Figure 9.3, 9.4b and 9.5b. As we observe the inputs and let $f(\mathbf{x})$ denote the vector of observed outputs (we assume for now that the observations are made without noise). We use the notation $\kappa(\mathbf{X}, \mathbf{X})$ and $\mathbf{K}(\mathbf{X}, \mathbf{X})$ as defined by (8.12) and (8.12c) to write the joint distribution between the observed values $f(\mathbf{X})$ and the test value $f(\mathbf{x})$

$p\left(\begin{array}{c}f(\mathbf{X}) \\ f(\mathbf{x}) \end{array}\right) = N\left(\begin{array}{c}f(\mathbf{X}) \\ f(\mathbf{x}) \end{array};\begin{array}{c}\mu(\mathbf{X}) \\ \mu(\mathbf{x}) \end{array};\begin{array}{cc}\kappa(\mathbf{X},\mathbf{X}) & \kappa(\mathbf{X},\mathbf{x})\mathsf{T}\end{array}\right)$

Now, as we have observed $f(\mathbf{X})$, we use the expressions for the Gaussian process to write the distribution for $f(\mathbf{x})$ on the conditions of $f(\mathbf{X})$

$p(f(\mathbf{x})|f(\mathbf{X})) = $

$N(f(\mathbf{x});\mu(\mathbf{x}) +\mathbf{K}(\mathbf{x},\mathbf{X})\mathsf{T}\mathbf{K}(\mathbf{X},\mathbf{X})^{-1}(f(\mathbf{X})-\mu(\mathbf{X}))), \kappa(\mathbf{x},\mathbf{x}) - \mathbf{K}(\mathbf{x},\mathbf{X})\mathsf{T}\mathbf{K}(\mathbf{X},\mathbf{X})^{-1}\mathbf{K}(\mathbf{X},\mathbf{x}))$,
