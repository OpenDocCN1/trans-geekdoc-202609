## 2.2 A distance-based method: k-NN

It is now time to encounter our first machine learning method. We will start with the relatively simple k-nearest neighbors (k-NN) method, which can be used for regression and classification. Remember that the setting is that we have training data $\{(x_{i}, y_{i})\}_{i=1}^{n}$ which consists of $n$ points with input $x_{i}$ and output $y_{i}$. We then want to construct a prediction $f(x)^{*}$ for what we believe is the output $y^{*}$, for a new $x^{*}$ which we have not seen previously.

### The k-nearest neighbors method

Most supervised learning methods are built on the intuition that if the test data point $x^{*}$ is close to training data point $x_{i}$, then the prediction $f(x)^{*}$ should be close to $y_{i}$. This is a general idea, but one simple to implement it in practice is the following: first, compute the Euclidean distance between the test input and all training inputs, $\|x - x_{i}\|$; for $i = 1, \dots, n$; find the data point $x_{i}$ with the shortest distance to $x^{*}$ and use its output as the prediction, $f(x)^{*} = y_{i}$.

This simple prediction method is referred to as 1-nearest neighbor. It is not complicated, but for most machine learning methods of interest it is so simplistic. We can rarely say for certain what the output value will be. Mathematically, we then handle this by declaring $y$ as a random variable. That is, we consider the data as noisy, meaning it is affected by random errors referred to as noise. From this perspective, the shortcoming of 1-neighbor is that the prediction relies only on one data point from the training data.

To improve the 1-nearest neighbor method we can extend it to use a set of $k$ nearest neighbors instead. Normally we define the set $N_{k}(x) = \{x_{i} : x_{i} \text{ is one of the } k \text{ nearest training points closest to } x\}$ and aggregate the information from them to make the prediction. For regression we take the average of all $y_{i}$ for $x_{i} \in N_{k}(x)$ and for classification we take the majority vote. We illustrate the k-nearest neighbors (k-NN) method by Example 2.3 and summarize by Method 2.

Method that explain using data predictions are made are called nonparametric, which is in contrast with parametric methods, where the prediction is given by some function (model), governed by a fixed number of parameters. The training data used is to learn the parameters in an initial training phase, but once the model has learned the data can be discarded as it is used only when making predictions. We will introduce parametric modeling in Chapter 3.

> The Euclidean distance between a test point $x^{*}$ and a training data point $x_{i}$ is $\|x - x_{i}\| = \sqrt{(x_{1}-x_{i,1})^{2} + \dots + (x_{d}-x_{i,d})^{2}}$.

> Ties can be handled in different ways, by a coin-flip, or by returning all the vote to the user who needs to decide what to do with it.

## Supervised learning: a first approach

Data: Training data $\{x_i, y_i\}_{i=1}^n$ and test input $x_*$.
Result: Predicted output $\hat{y}(x_*)$

1. Compute the distances $\|x_i - x_*\|$ for all training data points $i = 1, \dots, n$
2. Let $N_* = \{i : x_i \text{ is one of the data points closest to } x_*\}$
3. Compute the prediction $\hat{y}(x_*)$ as:

$$\hat{y}(x_*) = \begin{cases} \text{Average}(y_j : j \in N_*) & \text{(Regression problems)}\\\text{MajorityVote}(y_j : j \in N_*) & \text{(Classification problems)}\end{cases}$$

### Example 2.3: Predicting colors with k-NN

We consider a binary classification problem ($M=2$). We are given a training dataset with $n=6$ observations of $p=2$ input variables $x_1, x_2$ and one categorical output $y$, the color Red or Blue.

| i | x1 | x2 | y |
|---|---|---|---|
| 1 | -1 | 3 | Red |
| 2 | 2 | 1 | Blue |
| 3 | -2 | 2 | Red |
| 4 | -1 | 2 | Blue |
| 5 | -1 | 0 | Red |
| 6 | 6 | 1 | Blue |

We are interested in predicting the output for $x_*=[2,1]^T$. For this purpose we will explore two different k-NN classifiers, using $k=1$ and using $k=3$. First, we compute the Euclidean distance $\|x_i - x_*\|$ between each training data point $x_i$ (red and blue) and then sort them in ascending order.

| i | $\|x_i - x_*\|$ | y |
|---|---|---|
| 6 | $\sqrt{1}$ | Red |
| 2 | $\sqrt{2}$ | Blue |
| 4 | $\sqrt{4}$ | Blue |
| 1 | $\sqrt{5}$ | Red |
| 5 | $\sqrt{8}$ | Blue |
| 3 | $\sqrt{9}$ | Red |

Since the closest training point to $x_*$ is $i=6$, it means that for $k=1$, we get the prediction $\hat{y}(x_*)=Blue$. For $k=3$, the neighbors are $i=6$ (Red), $i=2$ (Blue), and $i=4$ (Blue). Taking a majority vote among these three training points, Blue wins with 2 votes against Red, so our prediction becomes $\hat{y}(x_*)=Blue$. ### Decision boundaries for a classifier

In Example 2.3 we only computed a prediction for a single test point $x_*$. That prediction might indeed be the ultimate goal of the application, but use it to visualize and understand a classifier we can also study its decision boundary, which illustrates the prediction for all possible test inputs. It is a general concept for classifiers, not only k-NN, but it is only possible to visualize easily when the dimension of $x$ $p=2$.

### Choosing $k$

The number of neighbors that are considered when making a prediction of k-NN is an important choice the user has to make. Since $k$ is not learned by k-NN itself, but a design choice to the user, we refer to it as a *hyperparameter*. Throughout the book we will use the term hyperparameter for similar tuning parameters for other methods.

The choice of the hyperparameter $k$ has a big impact on the predictions made by k-NN. To understand the impact of $k$, we study how the decision boundary changes as $k$ changes in Figure 2.5, where k-NN is applied to the classification Example 2.1 and the car stopping Example 2.2, with $k=1$ as well as $k=20$.

With $k=1$ all data points will be correctly predicted and the model is adapted to the exact $x$ and $y$ values of the data. In the classification problem there are instance small green (Bob Dylan) regions within the red areas that are most likely misleading when it to accurately predict the artist of a new song. In order to make good predictions it would probably be to instead predict red (the Beetles) for a new song in the entire middle-left region where the majority of data points in that area are red. For the regression $k=1$ gives a very shaky that that is not an actual effect, but that the prediction is adapted to the noise in the data.
