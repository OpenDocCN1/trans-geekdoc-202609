where $f_\theta$ and $h_\theta$ are two arbitrary (linear or nonlinear) real-valued regression functions parameterized by $\theta$ (hence, following the notation above, $h_\theta(x) = (f_\theta(x))^2$). The exponential function is used to ensure that the variance is always positive without explicitly constraining $h(x)$. The two functions can be learned simultaneously by minimizing the negative log-likelihood over training data. In this case the problem does not simplify to squared error, despite the fact that the likelihood is Gaussian, since we need to capture the dependence on variance. Precisely the negative log-likelihood becomes,

$$
L(y,\theta) = -\ln N(f_\theta(\mathbf{x}), \exp(h_\theta(\mathbf{x})))^2 \propto h_\theta(\mathbf{x}) + \frac{(y-f_\theta(\mathbf{x}))^2}{\exp(h_\theta(\mathbf{x}))} + \text{const}.
$$

Once the parameters have been learned, the resulting model is capable of predicting a different mean and a different variance for the output $y$, depending on the value of input $x$. Other situations that could be modeled using direct likelihood in a similar way include multimodality and truncated data. As long as the model is flexible, the negative log-likelihood can be used to learn the model in systematic way.

### Strictly proper loss functions and asymptotic minimizers

As mentioned earlier the minimizer of a loss function is an important theoretical concept for understanding its properties. The asymptotic minimizer is the model which minimizes the cost when the number of training data $n \to \infty$ (hence the name asymptotic). To formalize this, assume the model is expressed in terms of a function $f(x)$. As we have seen this captures not mean but also variance. The asymptotic minimizer $f^*(x)$ of a loss function $L(y, f(x))$ is defined as the function that minimizes the expected

$$
f^*(x) = \arg\min_f \mathbb{E}[L(y, f(x))|x]
$$

There are couple of things to note about this expression. First, we stated that the asymptotic minimizer is obtained as the solution to the objective as $n \to \infty$, but this has been replaced by expected value. This is motivated by the law of large numbers stipulating that the cost will converge to the expected loss and the latter is more convenient to analyze mathematically. Note the expected value is taken with respect to true data distribution $p(y|x)$, as we observed in Chapter 4. Second, when we allow any function $f(x)$, the minimization in (5.1) is not with respect to finite dimensional model parameter $\theta$, but rather respect to the function $f(x)$ itself. For this reason, abstract definition is that we want to derive the asymptotic minimizer as a property of the loss function itself, not of particular combination of loss and model class.

The expected value is biased with both inputs $x$ and outputs $y$. However, by the law of total expectation we can write $\mathbb{E}[L(y, f(x))] = \mathbb{E}[\mathbb{E}[L(y, f(x))|x]]$ where the inner expectation is over conditionally $(y)$ on $x$ and the outer expectation is over $x$. Now, since $f(x)$ is free to be any function, this property is related to heteroskedasticity (in contrast to the squared regression model (5.2) which is homoskedastic, that is the same output variance for all possible inputs).

minimizing the total expectation is equivalent to minimizing the expectation pointwise for each value of $x$. Therefore, we can replace (5.1) with

$$
f^*(x) = \arg\min_f \mathbb{E}[L(y, f(x))|x] \quad (5.2)
$$

where the minimization is now done independently for any fixed value of $x$. By computing the asymptotic minimizer of a loss function, we obtain information about the expected behavior or properties of a model that is learned using this loss function. Although the asymptotic minimizer is an idealized theoretical concept (assuming finite data and infinite reflectivity), it reveals in sense, what the training algorithm strives to achieve when minimizing a particular loss.

The concept is useful for understanding both regression and classification losses. A few notable examples in the setting are the squared error and the absolute error. For the former, the asymptotic minimizer can be shown to be equal to the conditional mean, $f^*(x)=\mathbb{E}[y|x]$. Thus, a regression trained using squared error will strive to predict accurately according to the true data under the conditional distribution $p(y|x)$ (although this is limited by the flexibility of the loss model and the class of uncertain training data). For the absolute error the asymptotic minimizer is given by the conditional median, $f^*(x)=\text{Median}[y|x]$. This is less sensitive to the tail of $p(y|x)$ than the conditional mean, providing another interpretation of the improved robustness of the absolute error.

Related to the concept of asymptotic minimizers is the nature of a strictly proper loss function. A loss is said to be strictly proper if its minimizer is (i) unique and (ii) in one-to-one correspondence with the true conditional distribution $p(y|x)$. But, for a strictly proper loss function we can express $p(y|x)$ in terms of the asymptotic minimizer $f^*(x)$. Such a loss will strive to recover the probabilistic characteristic of the input-output relationship.
