# Example 5.7: Early stopping with logistic regression for the machine classification example

We consider again the machine classification problem from Example 2.1. We apply multi-class logistic regression, and to evaluate the point of this example, we apply 20 degree polynomial input transformation. Logistic regression is learned using a Newton-type numerical optimization algorithm (Section 5.4). We can therefore apply early stopping to it. For this purpose we set aside hold-out validation data and monitor how $E_{hold-out}$ (with misclassification error) evolves as the optimization proceeds.
