Note that we use the training data labels $y$, as index values to select the correct conditional probability for the loss function. then the $i$-th term of the sum is the negative logarithm of the $y_i$,th element of vector $g(x; \theta)$. We illustrate the meaning of this in Example 3.4.

Inserting the model (3.43) into the loss function gives the cost function to optimize when learning multiclass regression.

```
$J(\theta) = \frac{1}{n} \sum_{i=1}^{n} -\theta_{y_i}^T x_i + \ln \sum_{j=1}^{M} e^{\theta_j^T x_i}; \quad (3.45)$
```

We apply this to the music classification problem in Example 3.6.

> **Example 3.4:** The cross-entropy loss for multiclass problems

Considering the following (very small) data with $n=6$ points, $p=2$ input dimensions and $M=3$ classes, which we want to use for learning a multiclass classifier:

$X = \begin{pmatrix} 0.20 & 0.86 \\ 0.41 & 0.18 \\ 0.96 & -1.84 \\ -0.25 & 1.57 \\ -0.82 & -1.53 \\ -0.31 & 0.58 \end{pmatrix}, \quad y = \begin{pmatrix} 1 \\ 2 \\ 3 \\ 1 \\ 2 \\ 3 \end{pmatrix}$

Multiclass regression with softmax (or any other multiclass classifier which predicts a vector of conditional class probabilities) returns a 3-dimensional probability vector $g(x;\theta)$ for any $x$ and $\theta$. If we take the logarithms of the transpose of all vectors $g(x_i;\theta)$ for $i=1, \dots, 6$, we obtain the matrix

```
$G = \begin{pmatrix} \ln g_1(x_1;\theta) & \ln g_2(x_1;\theta) & \ln g_3(x_1;\theta) \\ \ln g_1(x_2;\theta) & \ln g_2(x_2;\theta) & \ln g_3(x_2;\theta) \\ \ln g_1(x_3;\theta) & \ln g_2(x_3;\theta) & \ln g_3(x_3;\theta) \\ \ln g_1(x_4;\theta) & \ln g_2(x_4;\theta) & \ln g_3(x_4;\theta) \\ \ln g_1(x_5;\theta) & \ln g_2(x_5;\theta) & \ln g_3(x_5;\theta) \\ \ln g_1(x_6;\theta) & \ln g_2(x_6;\theta) & \ln g_3(x_6;\theta) \end{pmatrix}$
```

Computing the multiclass cross-entropy cost (3.44) now simply amounts to taking the average of all circled elements, the element in row $i$ is given by the training label $y_i$. Training the model amounts to finding $\theta$ such that this negated average is minimized.

## 3.3 Polynomial regression and regularization

> **Time to reflect 3.3:** Can you derive (3.32) as a special case of (3.44)?
Hint: think of the binary classifier as a special case of the multiclass classifier with $g(x) = \frac{g(x)}{1 - g(x)}$

> **Time to reflect 3.4:** The softmax-based logistic regression is actually over-parameterized, in the sense that we can construct an equivalent model with fewer parameters. This is often not a problem in practice, but compare the multiclass model (3.42) for case M=2 with binary logistic regression (3.29) and see if you can spot the over-parametrization!

In comparison to k-NN and decision trees studied in Chapter 2, linear and logistic regression might appear to be rigid and non-flexible models with their straight lines (such as Figures 3.1 and 3.5). However, both models are able to adapt to the training data if the input dimension p is large in relation to the number of data points $n$.

A common way of increasing the input dimension in linear and logistic regression, which we discuss thoroughly in Chapter 8, is to make a nonlinear transformation of the input. A simple nonlinear transformation is to replace a one-dimensional input with itself raised to different powers, which makes the linear regression model a polynomial

```
y = \theta_0 + \theta_1x + \theta_2x^2 + \theta_3x^3 + \dots + \varepsilon.
```

This is called polynomial regression. The same polynomial expansion can be applied also to the expression for logistic regression. If we let $x_1 = x$, $x_2 = x^2$ and $x_3 = x^3$, this is a linear model (3.32) with input $x = [1, x^2, x^3]$, but we have “lifted” the input from being one-dimensional ($p=1$) to three-dimensional ($p=3$). Using nonlinear transformations can be very useful in practice, but it effectively increases $p$ and we can easily end up overfitting to the noise—rather than interesting patterns—in the training data, as in this example.

> **Example 3.5:** Stopping distances with polynomial regression

We return to Example 2.2, but this time we added the squared sum as an input and thereby use a 2nd order polynomial in linear regression. This gives the new parameters (compared to Example 3.1)

| X: | 4.0 | 4.0 |
|---|---|---|
| 1 | 16.0 | 8.0 |
| 4.9 | 24.0 | 8.0 |
| 5 | 25.0 | 8.0 |
| 19.6 | 1568.2 | 134.0 |
| 39.7 | 1576.1 | 11.0 |

One way to avoid issues when augmenting the input with nonlinear transformation is to carefully select which inputs (transforms) to include. There are various strategies for this, by adding instances one at a time (forward) or by starting with a large number of inputs and gradually reducing the ones that are considered (backward). Different models can be evaluated and compared using cross-validation, as we discuss in Chapter 4. See also Chapter 11 where we discuss input selection.

An alternative approach to implicit selection can be used to mitigate overfitting regularization. The idea of regularization can be described as 'keeping the parameters θ small unless the data reveals otherwise', or alternatively 'if a model with small parameter values fits the data as well as a model with larger parameter values, the one with small parameter values should be preferred'. In conclusion 3.7.
