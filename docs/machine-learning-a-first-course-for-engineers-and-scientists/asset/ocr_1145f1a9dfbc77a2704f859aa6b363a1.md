# Transfer learning

Transfer learning is yet another technique that allows to exploit information from more data than the dataset we have. In transfer learning we use the knowledge from a model that has been trained on a different task with a different dataset and then apply that in solving a different, but slightly related, problem.

Transfer learning is especially common for sequential model structures such as the neural networks introduced in Chapter 6. Consider an application where we want to detect whether a type of skin cancer is malignant or for this task we have 100,000 labeled images of skin cancer. We call this Task A. Instead of training the full neural network from scratch on skin data, we can reuse an already pretrained network from another image classification task (Task B), which preferably has been trained on a much larger dataset. Using the weights from the model trained for Task B and only train the last few layers for the data for Task A. The procedure is also displayed in Figure 11.6. The intuition is that the layers closer to the input acquaint tasks that are generic for all types of images, such as extracting lines, edges and corners in the image, whereas the layers closer to the output are more specific to the particular problem.

In order for transfer learning to be we need the two tasks to have the same type of input (in the example above, images of the same domain). Further, for transfer learning to be an attractive option, the task we transfer from should have been trained on substantially more data than the task we transfer.
