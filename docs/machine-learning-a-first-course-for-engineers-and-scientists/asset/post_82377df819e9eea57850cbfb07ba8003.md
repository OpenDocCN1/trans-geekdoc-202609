### A representation of beliefs

The main feature of the Bayesian approach is its use of probability distributions. We interpret those distributions as *beliefs* in the following sense: The prior $p(\theta)$ represents our beliefs about $	heta$, that is, before any data has been observed. The likelihood, encoded as $p(y|\theta)$, defines how $y$ relates to the parameter $	heta$. Using Bayes's theorem (9.1) we *update* the belief about $	heta$ to the posterior $p(\theta|y)$ which also takes the observed data into account. In an everyday language, these beliefs could be represent uncertain about $	heta$ before and after observing the data $y$ respectively.

An interesting and relevant consequence is that the Bayesian approach is less prone to overfitting, using a maximum-likelihood based method. In maximum-likelihood we obtain a single value $\hat{	heta}$ and use that to make our prediction to $p(y|\hat{	heta})$. In the Bayesian approach we obtain an entire distribution $p(\theta|y)$ representing different hypothesis of value for our model parameters. We account for all of these hypothesis by the marginalization in (9.3) to compute the posterior. In particular in case of small datasets, the "uncertainty" from the (presumably) limited information in $y$, under the assumed conditions.

The posterior $p(\theta|y)$ is a combination of the prior belief $p(\theta)$ and the information about $	heta$ carried by $y$. Without a meaningful likelihood $p(\theta)$, the posterior $p(\theta|y)$ is not meaningful either. In some applications it can be hard to make a choice of $p(\theta)$ that is not influenced by the experience of the machine learning engineer, which is sometimes emphasized by saying that $p(\theta)$ and therefore a subjective belief. This means to reflect that the result is not independent of the data $p(y)$ represents the solution we designed. Also, without the likelihood, no matter if the Bayesian approach is used or not, often chosen by the personal experience of the machine learning engineer, meaning that machine learning arrives in that sensitive objective.

An advantage of the Bayesian approach is that we can work in a sequential fashion, that is, one data point after the other. Say that we have two sets of data, $y_1$ and $y_2$. Starting with a prior $p(\theta)$ we can condition on $y_1$ by computing $p(\theta|y_1)$ using Bayes' theorem (9.1). If thereafter we wanted to condition on all data, $y_1, y_2$, as as $p(\theta|y_1,y_2)$, we do not have to start over again. We can instead replace the prior $p(\theta)$ with $p(\theta|y_1)$ in Bayes' theorem to compute $p(\theta|y_1,y_2)$. In a sense, the "old posterior" becomes the "new" prior when data arrives sequentially.

### The marginal likelihood as a model selection tool

When using the Bayesian approach there are some hyperparameters in the likelihood or prior, say $\eta$, that need to be chosen. It is an option to use a "hyper'-prior $p(\eta)$ and compute the posterior also for the hyperparameters, $p(\eta \mid y)$ is the full Bayesian solution, but sometimes that is too computationally challenging.

> $^1$Remember that $p(y|\theta)$ was also used for the maximum likelihood perspective; one example of $p(y|\theta)$ is linear regression (3.17-38).

A more pragmatic approach is to select $\hat{\eta}$ using cross-validation instead. It is perfectly possible to use cross-validation, the Bayesian approach also comes as an alternative for selecting hyperparameters $\eta$ by maximizing the marginal likelihood $\ell(\eta)$ as

$$\hat{\eta} = \arg\max p_{\eta}(y). (9.4)$$

where we have added an index $\eta$ to emphasize the fact that $p(y)$ depends on $\eta$. This approach is sometimes referred to as *empirical Bayes*. Choosing hyperparameters $\eta$ is, in a sense, a selection of likelihood (and prior), and we can consider the marginal likelihood as a tool for selecting likelihood. Maximizing the marginal likelihood is, however, not equal to using cross-validation (the obtained value might differ), and unlike cross-validation the marginal likelihood does not give an estimate of $E_{new}$. In many situations, it is relatively easy to compute (and maximize) the marginal likelihood, employing a full cross-validation procedure.

In the previous section we argued that the Bayesian approach was less prone to overfitting than others. However, maximizing the marginal likelihood is, in a sense, a of maximum likelihood approach, and may carry a risk of overfitting when maximizing the marginal likelihood. To some extent that may be the case, the key point is that learning one (at most, a few) hyperparameters $\eta$ with maximum (marginal) likelihood typically does not cause any severe overfitting, but there are rarely overfitting when learning a straight line with linear regression. In other words, we can usually "afford" to learn one or a few (hyper)parameters by maximizing the (marginal) likelihood: overfitting becomes a potential issue when learning a larger number of (hyper)parameters.

## 9.2 Bayesian linear regression

As a first example of the Bayesian approach, we will apply it to linear regression. In itself Bayesian linear regression is not the most versatile method, but just like ordinary regression it is a good starting point and introduces the main concepts. It is possible to extend in various directions. It opens up for the perhaps more interesting Gaussian process model. Before we work out the details of the Bayesian approach applied to linear regression, we will repeat some facts about the Gaussian distribution that will be useful.

### The multivariate Gaussian distribution

A central mathematical object for Bayesian linear regression (and later also the Gaussian process) is the multivariate Gaussian distribution. We assume that the reader already has familiarity with multivariate random variables, or equivalently random vectors, and repeat only the most important properties of the multivariate Gaussian distribution here.

Let $z$ denote a $q$-dimensional multivariate Gaussian random vector. The multivariate Gaussian distribution is parameterized by a mean $\mu$ and a $q \times q$ covariance matrix $\Sigma$. We write $z \sim \mathcal{N}(\mu, \Sigma)$. The probability density function is

$$p(z) = (2\pi)^{-d/2} \det(\Sigma)^{-1/2} \exp(-\frac{1}{2}(z-\mu)^T\Sigma^{-1}(z-\mu))$$

If all off-diagonal elements of $\Sigma$ are zero, an $n$-dimensional Gaussian random vector is equal to $n$ scalar random variables.
