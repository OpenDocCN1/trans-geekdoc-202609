# Deep neural network

The two-layer neural network is a useful model on its own, and a lot of research and analysis has been done for it. However, the real descriptive power of a neural network is realized when we stack multiple layers of generalized linear regression models, and thereby achieve a *deep neural network*. Deep networks can manage complicated relationships (such as the one between image and class), and are one of the state-of-the-art methods in machine learning as today.

We enumerate the layers with index $l\in\{1,...,L\}$ where $L$ is the number of the layers. *Each layer* is parametrized with a weight matrix $\mathbf{W}^{(l)}$ and an offset vector $\mathbf{b}^{(l)}$ for the two-layer case. For example, $\mathbf{W}^{(1)}$ and $\mathbf{b}^{(1)}$ belong to layer $l=1$, $\mathbf{W}^{(2)}$ and $\mathbf{b}^{(2)}$ belong to layer $l=2$ and so forth. We also have multiple *layers of hidden units* denoted by $\mathbf{q}^{(l)} = [q_1^{(l)},q_{U_l}^{(l)}]^T$, where the dimensions $U_1,...,U_{L-1}$ can be different from the various layers.

Each layer maps the output of the first layer of hidden units $\mathbf{q}^{(1)}$ is the input to the second layer, the output of the second layer $\mathbf{q}^{(2)}$ (the second layer of hidden units) is the input to the third layer, etc. By stacking multiple layers we have constructed a deep neural network. A deep network of $L$ layers can be mathematically described as

```
$$\mathbf{q}^{(1)} = h(\mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)})$$\n$\mathbf{q}^{(2)} = h(\mathbf{W}^{(2)}\mathbf{q}^{(1)} + \mathbf{b}^{(2)})$$\n$:$$\n$\mathbf{q}^{(L-1)} = h(\mathbf{W}^{(L-1)}\mathbf{q}^{(L-2)} + \mathbf{b}^{(L-1)})$$\n$\hat{\mathbf{y}} = W(\mathbf{W}^{(L)}\mathbf{q}^{(L-1)} + \mathbf{b}^{(L)})$ $
```

A graphical representation of this model is provided in Figure 6.4. The expression (6.11) for a deep neural network can be compared with the expression (6.8) for a two-layer neural network.

The weight matrix for the first layer $l=1$ has dimension $U_1 \times p$ and the corresponding offset $\mathbf{b}^{(1)}$ has dimension $U_1$. Since the output is in the last layer the weight matrix $\mathbf{W}^{(L)}$ has dimension $1 \times U_{L-1}$. For all intermediate layers $l=2,...,L-1$, $\mathbf{W}^{(l)}$ has dimension $U_l \times U_{l-1}$ and the corresponding offset vector $\mathbf{U}^{(l)}$. The number of inputs $p$ are given by the problem, but the number of layers $L$ and the dimensions $U_1,U_2,...$ are user design choices that determine the flexibility of the model.
