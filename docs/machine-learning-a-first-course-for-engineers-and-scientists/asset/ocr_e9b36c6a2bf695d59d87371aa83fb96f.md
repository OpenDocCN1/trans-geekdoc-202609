Both plots summarizes the performance of a classifier for all decision thresholds (*r* see (3.36)), but the ROC curve is most relevant for balanced problems, whereas the precision-recall curve is more informative for imbalanced problems.

A compact summary of the ROC curve is the area *under the ROC*, ROC-AUC. From Figure 4.13a, we conclude that a perfect classifier has ROC-AUC = 1, a classifier which only assigns random guesses ROC-AUC = 0.5. The ROC-AUC is thus summarizing the performance of a classifier for all possible values of the decision threshold in a single number

# **The $F_β$ score and precision-recall curve**

Many classification problems have particular characteristics, that when they are imbalanced, or asymmetric, or both. We say that a problem is

+   (i) imbalanced if the majority of the data points belongs to one class, typically the negative class $y = -1$. This imbalance implies a (useless) classifier that always predicts $\hat{y}(x) = -1$ will score very well in terms of misclassification (4.1a).
(ii) asymmetric if a false negative is considered more severe than a false positive, or versa. That asymmetry is not taken into account in the misclassification rate (4.1a).
