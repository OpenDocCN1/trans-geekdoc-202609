### 8.5 Support vector classification

We have spent some time deriving two kernel versions of linear regression: kernel ridge regression and support vector regression. We will now focus on classification. Unfortunately the derivations become more technically inclined than for kernel regression, and we have placed the derivations in the chapter appendix. However, the intuition carries over from regression, as well as the main ideas of the dual formulation, the kernel trick and the change of loss function.

It is possible to derive a kernel of logistic regression with $L^2$-regularization. The derivation can be made by replacing $x$ with $\phi(x)$, and then use the representer to derive its dual formulation and apply the kernel trick. Since kernel logistic regression is rarely used in practice, we will instead go straight to support vector classification. As the name says, support vector classification is the counterpart of support vector regression. Both support vector regression and classification are SVMs which both have sparse dual parameters.

We consider the binary classification problem $y \in \{-1,1\}$, and start with the margin formulation (see (5.12) in Chapter 5 of the logistic regression

```
$$\widehat{Y}(\mathbf{x}_s) = \sign(\theta^T\phi(\mathbf{x}_s)).$$
```

If we were to learn $\theta$ using the logistic loss (5.14), we would obtain logistic regression with a nonlinear feature transformation $\phi(x)$, from which kernel regression would eventually work out. However, inspired by support vector regression, we will instead use that of the hinge loss (5.17),

```
$$L(\mathbf{x}, y, \theta) = \begin{cases} 1 - y\theta^T\phi(\mathbf{x}) & \text{if } y\theta^T\phi(\mathbf{x}) < 1 \\0, & \text{otherwise} \end{cases}.$$
```

From 5.2, it is not immediately clear what advantages the hinge loss has over the logistic loss. Analytically to the $\epsilon$-insensitive loss, the advantage of the hinge loss carries over when we look at the dual formulation $a$ of the primal formulation with $\theta$. Before introducing a dual formulation we first have to find the primal. With $L^2$-regularization, which with (8.33) gives the primal formulation

```
$$\widehat{\alpha} = \arg\min_{\alpha} \sum_{n=1}^m \max\{0, 1 - y_n\theta^T\phi(\mathbf{x}_n)\} + \lambda|\alpha|_2^2.$$
```

The primal formulation does not work without the kernel trick, since the feature vector does not show up as $\phi(x)^T\phi(x)$. By using optimization theory and constructing the Lagrangian (the details are found in Appendix 8.B), we can arrive at the dual formulation$^1$ of (8.34),

```
$$\widehat{\alpha} = \arg\min_{\alpha} \frac{1}{2}\alpha^T\mathbf{K}(\mathbf{X},\mathbf{X}) - \alpha^T\mathbf{y},$$
```

```
$$\text{subject to } |\alpha| \le \frac{1}{2n} \text{ and } 0 \le \alpha_i y_i.$$
```

with

```
$$\widehat{Y}(\mathbf{x}_s) = \sign(\widehat{\alpha}^T\mathbf{K}(\mathbf{X},\mathbf{x}_s)).$$
```

instead of (8.32). Note that we also have to made use of kernel trick by replacing $\phi(x)^T\phi(x)$ with $\kappa(x,x')$ in (8.35a) and (8.35b). As in support vector regression, adding an offset term $\theta_0$ to (8.32) corresponds to enforcing an additional constraint $\sum_{i=1}^m \alpha_i = 0$ in (8.35).

### 8.5 Support vector classification

Because of the representer theorem, the formula (8.35c) should come as no surprise to us, since it simply corresponds to inserting (8.16) into (8.32). However, the representer theorem tells us that its dual formulation: the (8.35a)-(8.35b) does not follow automatically from the representer theorem requires its own derivation.

The most interesting property of the constrained optimization problem (8.35) is that its solution $\alpha$ turns out to be sparse. This is exactly the same phenomena with support vector regression, and the strength of this method, which (8.35) is called SVM, is support vector classification. The model has the full flexibility of a kernel method, and yet the prediction (8.35c) only explicitly depends on a subset of the training data (the support vectors). It is however important to realize that all training data points are needed when solving (8.35). We summarize by Method 8.3.

The support vector property is due to the fact that the loss function is exactly equal to zero when the margin (Chapter 5) is $\ge1$. In the dual formulation, the parameter $\alpha_i$ becomes nonzero only if the margin point $i\le1$, which makes $\alpha$ sparse. It can be shown that this corresponds to data points being either on the "wrong side" of the decision boundary or within the decision boundary in the feature space $\Phi(x)$. We illustrate this by Example 8.5.

### Method 8.3: Support vector classification.

In the SVM literature it is common to use an equivalent formula with $C = \frac{1}{2gamma}$ or $C = \frac{1}{2nl}$ as regularization hyperparameter. There also exists a slightly different formulation using another hyperparameter $v$ as effectively, as regularization hyperparameter. These primal and dual problems become more involved, and we do not include them here, but $v$ has somewhat natural interpretation as it bounds the number of support vectors. To distinguish between the different versions, (8.35) is commonly referred to as C-support vector and the other as $v$-support vector classification. A correspondence ‘v-SVR’ also exists for support vector regression.

As a consequence of the hinge loss, as discussed in Chapter 5, support vector classification does not provide probability estimates $(\mathbf{x})$ but only a ‘hard’ classification $\hat{y}(\mathbf{x}_*)$. For support vector classification $\hat{\alpha}(\mathbf{X}, \mathbf{y})$, is not possible to interpret it as a class probability estimate, as an alternative is to use the squared loss or hinge function which allows for a probability interpretation of the margin. Since all these functions are exactly zero for margins $\ge 1$, they retain the support vector property with a sparse $\alpha$. By using a different function than the hinge loss we obtain a different optimization problem and a different solution to the one described above.

The support vector classifier is most formed as a solution to the binary classification problem. The generalization to the multiclass problem is unfortunately not straightforward, as it requires a multiclass generalization of the loss function, as discussed in Chapter 5. In practice it is possible to construct a multiclass classifier from binary ones using either the one-versus-one or the one-versus-rest strategy-see page 87).
