> Example 6.2: Classification of hand-written digits - first attempt

We consider the example of classifying hand-written digits introduced in Example 6.1. Based on the data presented we train the two methods mentioned in each of: a logistic regression model (or a two-layer neural network).
We use stochastic gradient descent in Algorithm 5.3 with the learning rate y=0.5 and a mini-batch size of n=100. Since there are 600 training data points in total, each epoch is completed after 600/100 iterations. We run the algorithm for 15 epochs, i..900 iterations.
As explained earlier, at each iteration of the cost function is evaluated for the current mini-batch of the training data. The value for this cost is illustrated in the left part of Figure 6.7 and 6.8. In addition, we also calculate the misclassification rate for the 100 data points in the current mini-batch. This is illustrated in the right part of Figure 6.7 and 6.8. Since the current mini-batch of 100 randomly selected training data, the performance fluctuates on which mini-batch that is considered.
However, the important is how we perform on data which has not been used during training. Therefore, at each 100th iteration we also evaluate the cost function and the misclassification error on the whole validation dataset of 1000 data points.
