By not using a constant learning rate, but instead decrease it gradually towards zero, the parameter updates will be smaller and smaller, and eventually converge. We start at $t = 0$ with a fairly high learning rate $\gamma^{(t)}$ (meaning that we take big steps) and then decay $\gamma^{(t)}$ as $t$ increases. Under regularity conditions of the cost function and with a learning rate following the Robbins-Monro conditions $\sum_{t=1}^{\infty} \gamma^{(t)} = \infty$ and $\sum_{t=1}^{\infty} (\gamma^{(t)})^2 < \infty$, the stochastic gradient descent can be converged to nearly a local minimum. The Robbins-Monro conditions are for example, fulfilled if using $\gamma^{(t)} = a/t^\alpha$. For many machine learning problems, however, it has been found that performance is obtained in practice by not letting $\gamma^{(t)} \to 0$, but to cut at some small value $\gamma_{\min} > 0$. This will cause stochastic gradient descent not to easily converge, and the Robbins-Monro conditions will not be fulfilled, but the algorithm will walk around indefinitely (until the algorithm is aborted by the user). For practical purposes this seemingly property usually does not cause any issue if $\gamma_{\min}$ is only small enough, and enough for setting the learning rate in practice is

$$\gamma^{(t)} = \gamma_{\min} + (\gamma_{\max} - \gamma_{\min})e^{-t}$$

The learning rate $\gamma^{(t)}$ starts at $\gamma_{\max}$ and goes to $\gamma_{\min}$ as $t \to \infty$. How to pick the parameters $\gamma_{\min}$ and $\gamma_{\max}$? As a rule of thumb can be chosen as 1% of $\gamma_{\max}$. The parameter $\tau$ depends on the dataset and the complexity of the problem, but could be chosen such that many epochs have passed before we reach $\gamma_{\min}$. The strategy to pick $\gamma_{\max}$ can be done by monitoring the cost function as for standard gradient descent in Figure 5.7.

## 5.6 Hyperparameter optimization

## Stochastic second order gradient methods

The idea of improving the stochastic gradient method by exploiting second order information is natural in settings involving ill-conditioning and significant nonlinearity. At the same time this will add complexity and computational time to the algorithm, which needs to be traded off in the design of these algorithms.

A popular and natural strand of algorithms are those sorting under the name stochastic quasi-Newton methods. As mentioned above, the idea underlying deterministic quasi-Newton methods is to compute approximation of the Hessian using information in the gradients. For large-scale problems we make use of a receding history of gradients. These ideas can be employed also in the stochastic setting, albeit with new algorithms as the result.

## Adaptive methods

The idea of using gradients from earlier steps is also exploited in the adaptive methods. By considering different ways of combining the gradients from earlier steps into suitable learning rates

$$\gamma_t = \gamma(\nabla J_t, \nabla J_{t-1}, \dots, \nabla J_0)$$

and search directions

$$d_t = d(\nabla J_t, \nabla J_{t-1}, \dots, \nabla J_0)$$

we obtain different members of this family of methods. In the basic stochastic gradient $d_t$, only depends on the current gradient $\nabla J_t$. The resulting update rule for the adaptive stochastic gradient methods is

$$\theta_{(t+1)} = \theta_{(t)} - \gamma_t d_t$$

The most popular member of this class of methods uses one of exponential moving average, where recent gradients have higher weights over older gradients. Let $\beta_1 < 1$ and $\beta_2 < 1$ denote the exponential weights for the search direction and the learning rate, respectively. The ADAM optimizer updates the search direction and the learning rate according

$$d_t = (1 - \beta_1) \sum_{i=1}^{t} \beta_1^{t-i} \nabla J_i$$

$$\gamma_t = \frac{\eta}{\sqrt{t}} (1 - \beta_2) \text{diag}(\sum_{i=1}^{t} \beta_2^{t-i} ||\nabla J_i||^2)^{1/2}$$

Both of the tuning parameters $\beta_1$ and $\beta_2$ are typically set to be close to 1 and common values like $\beta_1 = 0.9, \beta_2 = 0.999$. The setting is too small that small will effectively result in an exponential forgetting of the past information and remove—often very valuable—memory effect inherent in this method.

The first member of this adaptive family is called ADAGRAD which makes use of the current gradient as its search direction $d_t = \nabla J_t$ and a learning rate with memory, where all components are equally important,

$$\gamma_t = \frac{\eta}{\sqrt{\sum_{i=1}^{t} ||\nabla J_i||^2}}$$

Besides the hyperparameters of a model, there are quite also a set that have to be optimized. Writing down an explicit form of $E_{out}$ as a function of $\lambda$ can be quite tedious, not to mention $E_{out}$, $\theta$ for a given value of $\lambda$. The simplest way to solve such an optimization problem is to "try different values, and pick the one that works". This is the idea of grid search and its likes. Although simple, grid search can be computationally expensive, in particular if the parameter vector has a high dimension. As an example, having a grid with a resolution of 10 points per dimension for a 5-dimensional parameter requires $10^5 = 100,000$ evaluations of the objective function. Some hyperparameters (for $k$ in k-NN, Chapter 2) are integers, and sometimes it is feasible to simply try all reasonable integer values in grid search.

**Algorithm 5.4** Grid search for regularization parameter $\lambda$
**Input:** $(x_i, y_i)_{i=1}^{n_v}$ validation data $(x_j, y_j)_{j=1}^{n_v}$
**Result:** $\hat{\lambda}$
1. for $\lambda = 10^{-3}, 10^{-7}, \dots, 10^{-10}$ (as an example) do
2. Learn $\theta$ with regularization parameter $\lambda$ from training data
3. Compute error on validation data $E_{val}(\lambda) \leftarrow \frac{1}{n_v} \sum_{j=1}^{n_v} (\hat{y}(x_j; \theta) - y_j)^2$
4. end
5 return $\hat{\lambda}$ as $\arg\min_{\lambda} E_{val}(\lambda)$
