
## 6.5 Further reading

Although the first conceptual ideas of neural networks date back to the 1940s (McCulloch and Pitts 1943), they had their first main successes in the late 1980s and early 1990s with the so-called backpropagation algorithm. At that stage, neural networks could, for example, be used to classify handwritten digits from low-resolution images (LeCun, Boser, et al. 1989). However, the early 90s neural networks were largely forgotten; it was widely believed they could not be used for any challenging problems in computer vision and speech recognition. In these areas, neural networks could not compete with hand-crafted solutions based on domain prior knowledge.

This situation has changed dramatically since the late 2000s with the deep learning. Progress in software, hardware and algorithm parallelization made possible to address more complicated problems, which were unthinkable only a couple of decades ago. For example, in image recognition, these deep models are now the dominant methods of use and they reach human or super-human performance on some specific tasks. An accessible introduction and overview of deep learning is by LeCun, Bengio, et. (2015), and via the textbook by Goodfellow, Bengio, et al. (2016).

## 6.6 Derivation of the backpropagation equations

To derive the backpropagation equations (6.27), consider the non-vectorized version of layer 1.

```
\begin{cases} z_j^{(l)} = \sum_k W_{jk}^{(l)}q_k^{(l-1)} + b_j^{(l)} \ q_j^{(l)} = h(z_j^{(l)}) \end{cases} \quad \forall j=1, \dots,U^{(l)}. \quad (6.35)
```

Assume we want to compute the derivatives of the cost function with respect to the parameters $W_{jk}^{(l)}$ and $b_j^{(l)}$. Note that the cost function $J(\theta)$ depends on both $W_{jk}^{(l)}$ and $b_j^{(l)}$ only through the hidden unit $z_j^{(l)}$ and not of the other units in that. We can use the chain rule to calculate or write

```
\frac{\partial J}{\partial b_j^{(l)}}\frac{\partial J}{\partial z_j^{(l)}}\frac{\partial z_j^{(l)}}{\partial b_j^{(l)}} = \frac{\partial J}{\partial W_{jk}^{(l)}}\frac{\partial J}{\partial z_j^{(l)}}\frac{\partial z_j^{(l)}}{\partial W_{jk}^{(l)}} = \frac{\partial J}{\partial q_k^{(l-1)}}\frac{\partial J}{\partial z_j^{(l)}}\frac{\partial z_j^{(l)}}{\partial q_k^{(l-1)}} = \quad \forall j=1, \dots,U^{(l)}}, \quad (6.36)
```

the partial derivatives of $J(\theta)$ with respect to $W_{jk}^{(l)}$ and $b_j^{(l)}$ can be directly derived from (6.35).

Similarly, we can use the chain rule to compute the partial derivative of $J(\theta)$ with respect to the post-activation hidden units $q_j^{(l-1)}$ for layer $l-1$. $J(\theta)$ depends on $q_k^{(l-1)}$ so we get

```
\frac{\partial J}{\partial q_k^{(l-1)}} = \sum_j \frac{\partial J}{\partial z_j^{(l)}}\frac{\partial z_j^{(l)}}{\partial q_k^{(l-1)}} \quad \forall k=1, \dots,U^{(l-1)}}, \quad (6.37)
```

Finally, we can also use the chain rule to express

```
\frac{\partial J}{\partial z_j^{(l)}} = \frac{\partial J}{\partial q_j^{(l)}}\frac{\partial q_j^{(l)}}{\partial z_j^{(l)}} \quad \forall j=1, \dots,U^{(l)}, \quad (6.38)
```

where $h'$ is the derivative of the activation function. With the vectorized notation for $dW, db, dz$ and $dq$ introduced in (6.22) and (6.25), we get that Equation (6.38) gives (6.27a), Equation (6.37) gives (6.27b), and Equation (6.36) gives (6.27c)-(6.27d).

## Ensemble methods: Bagging and boosting

In the preceding chapters we have seen several examples of different machine learning models, from k-NN to deep neural networks. In this chapter we will introduce a new way of constructing models, by combining multiple instances of some basic model. We refer to this as an ensemble of base models, and the resulting methods are consequently referred to as ensemble methods. The key idea behind ensemble is the "wisdom of crowds"; by training each model in a slightly different way they can all contribute to learning the input-output relationship. Specifically, to obtain a prediction from an ensemble, we use a (weighted) average or majority vote to obtain the final prediction.

As discussed in Chapter 4, the central concept in machine learning is variance-trade-off. Roughly speaking, the more flexible the model, the lower its bias. Highly flexible models are sometimes prone to overfitting, which is high variance. We can decrease the variance by using more shallow trees, but that would on the other hand increase the bias. Instead, we lower the variance (without increasing the bias) by using bagging with base models.

## Example 7.1: Using bagging for a regression problem

Consider the data (black dots) and the function (dashed line) in Figure 7.1. We want to predict $x_a$ (the empty circle). For this problem we can use a regression tree grown until each leaf node is pure, as shown below. We can visually confirm that the prediction is better (blue dot and circle are close to each other) for bagging than the single regression tree (lower left in Figure 7.1).

The rationale behind bagging follows as: Because of the noise in the training data, we may think of the prediction $\hat{y}(x_a)$ (the blue dot) as a random variable. In bagging, we learn an ensemble of models (upper right in Figure 7.1), where each base model is trained on a "version" of the data obtained using bootstrap. We may therefore think of each base model to be a different realization of the random variable $\hat{y}(x_a)$. The average of realizations of a random variable has a lower variance than the random variable itself, which means that by taking the average (lower right in Figure 7.1) of all base models we obtain a prediction with less variance than the base model. Since the base model itself has low bias, the aggregated prediction will have low bias and low variance.
