This appendix contains some results on the multivariate Gaussian distribution that are essential for Bayesian linear regression and the Gaussian process. Figure 9.15 summarizes how they relate to each other.

**Figure 9.15:** A graphical summary of how Theorem 9.2–9.4 and Corollary 9.1–9.2 relate to each other. In results, $z_a$ and $z_b$ are multivariate Gaussian random variables.

**Theorem 9.2 (Marginalization)** Partition the Gaussian random vector $z \sim N(\mu, \Sigma)$ according to

```
z = \begin{pmatrix} z_a \\ z_b \end{pmatrix}, \quad \mu = \begin{pmatrix} \mu_a \\ \mu_b \end{pmatrix}, \quad \Sigma = \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \\ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix}. (9.28)
```

The marginal distribution $p(z_a)$ is then given by

```
p(z_a) = N(z_a, \mu_a, \Sigma_{aa}). (9.29)
```

**Theorem 9.3 (Conditioning)** Partition the Gaussian random vector $z \sim N(\mu, \Sigma)$ according to

```
z = \begin{pmatrix} z_a \\ z_b \end{pmatrix}, \quad \mu = \begin{pmatrix} \mu_a \\ \mu_b \end{pmatrix}, \quad \Sigma = \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \\ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix}. (9.30)
```

The conditional distribution $p(z_a | z_b)$ is then given by

```
p(z_a | z_b) = N(z_a, \mu_{a|b}, \Sigma_{aa|b}). (9.31a)
```

where

```
\mu_{a|b} = \mu_a - \Sigma_{ab}\Sigma_{bb}^{-1}(z_b - \mu_b), (9.31b)
\Sigma_{aa|b} = \Sigma_{aa} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}. (9.31c)
```

**Theorem 9.4 (Affine transformation)** Assume that $z_a$ as well as $z_b | z_a$ are Gaussian distributed according to

```
p(z_a) = N(z_a, \mu_a, \Sigma_a). (9.32a)
p(z_b | z_a) = N(z_b; \mathbf{A}z_a + \mathbf{b}, \Sigma_{b|a}). (9.32b)
```

# 10 Generative models and learning from unlabeled data

The models introduced so far in this book are so-called discriminative models, also referred to as conditional models. These models are designed to learn from data to predict the output on a given input. However, they distinguish between inputs in terms of their outputs. In the first half of this chapter we will introduce another paradigm, so-called generative modeling. Generative models are also learned from data, but their scope is wider. In contrast to discriminative models, which only describe the distribution of the output for a given input, a generative model describes the joint distribution of inputs and outputs. Having access to probabilistic model for input allows, for instance, to simulate data. However, perhaps more importantly, it can be used to reason whether or not a certain input is typical, and it can be used to find patterns among variables. Generative modeling is therefore a natural way to use unsupervised learning, which we will do in the second half.

Specifically, a generative model aims to describe the distribution $p(x, y)$; that is, it provides a probabilistic description of how both input and output are generated. To emphasize that it contains some parameters that we will learn from data, we should write $p(x, y)$. To use a generative model for predicting the value of $y$ for a given input, we will make this idea concrete by considering a rather simple, such as Gaussian mixture model (GMM). The GMM can be used for different purposes: trained in a supervised way to see how classification occurs, or used in semi-supervised learning (where y are missing) and unsupervised learning (where y is not present). In the latter case, the GMM can be used for the clustering problem, which groups similar x together.

We will extend the idea of generative models beyond the Gaussian case by describing generative models that use deep neural networks: normalizing flows and adversarial networks. Both are capable of learning the distribution of high-dimensional data with complicated dependencies in an unsupervised way.

Generative models bridge the gap between supervised and unsupervised machine learning. We therefore end this chapter by introducing (non-generative) methods for unsupervised representation learning: autoencoder and principal component analysis (PCA), which are both useful for learning a low-dimensional representation of high-dimensional data.

# 10.1 The Gaussian mixture model

We will introduce a generative model, the GMM, which will derive several methods for different purposes. We assume that $x$ is numerical and $y$ is a categorical variable, that is a situation similar to classification. The GMM attempts to model $p(x, y)$, the joint distribution between $x$ and $y$. This is a more ambitious goal than the classifiers encountered in previous chapters, that only attempt to model the conditional distribution $p(y|x)$, since $p(y|x)$ can be derived from $p(x, y)$ but not vice versa.

# The Gaussian mixture model

The Gaussian mixture model makes use of the factorization of the joint density function

```
p(x,y) = p(x|y)p(y), \quad (10.1a)
```

The second factor is the marginal distribution of $y$. Since $y$ is categorical, and takes values in the set $\{1, \dots, M\}$, this is given by a categorical distribution with $M$ parameters $\{\pi_m\}_{m=1}^M$ as

```
p(y=1) = \pi_1, \dots, p(y=M) = \pi_M. \quad (10.1b)
```

The first factor in (10.1a) is the class-conditional distribution of the input $x$ for a certain class $y$. In a classification setting it is natural to assume that these distributions are different for different classes $y$. Indeed, if it is possible to predict the class $y$ based on the information in $x$, then the characteristics (that is, the distribution) should depend on $y$. However, to complete the model we need to make additional assumptions on these class-conditional distributions. The basic assumption for a GMM is that $p(x|y)$ is a Gaussian distribution

```
p(x|y) = N(x|\mu_y, \Sigma_y). \quad (10.1c)
```

with class-dependent mean $\mu_y$ and covariance matrix $\Sigma_y$. In words the model (10.1) starts with a categorical distribution over $y$, and for each possible value of $y$, it assumes a Gaussian distribution for $x$. Considering the marginal distribution $p(x)$, as we do in Figure 10, the model corresponds to a mixture of Gaussians (one component for each class of $y$), hence the name. Altogether (10.1) is a generative model for how $(x,y)$ is generated. As the models build up on simplifying assumptions, and most central to the GMM is the Gaussian assumption for the class-conditional distributions over $x$ (10.1c).

In the supervised setting, the GMM will lead to classifiers that are easy to learn (no numerical optimization is needed) and turn out to be useful in practice when the data does not obey the Gaussian assumption (10.1c perfectly). These classifiers are (for historical reasons) called linear and quadratic discriminant analysis, LDA and QDA. However, the GMM can also be used for unsupervised learning, as well as learning from partially labeled data (the output label $y$ is missing for some of the training data points) in a semi-supervised setting.

# Supervised learning of the GMM

Like any other learning model the GMM (10.1) is learned from training data. The unknown parameters to be learned are $\theta = \{\mu_m, \Sigma_m\}_{m=1}^M$.
