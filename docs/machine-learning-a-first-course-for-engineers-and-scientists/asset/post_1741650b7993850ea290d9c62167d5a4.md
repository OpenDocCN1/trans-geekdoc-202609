## Vectorization over units

The two-layer network model in (6.6) can be written more compactly using matrix notation, where the parameters in each layer are stored in a weight matrix **W** and an offset vector **b**

```
$\mathbf{q}^{(1)} = \begin{bmatrix} W_{11}^{(1)} & W_{p1}^{(1)} \\ \vdots & \vdots \\ W_{U1}^{(1)} & W_{pU}^{(1)} \end{bmatrix}^T \mathbf{x} + \begin{bmatrix} b_1^{(1)} \\ \vdots \\ b_U^{(1)} \end{bmatrix} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}, \quad \mathbf{b}^{(2)} = [\mathbf{b}^{(2)}].\quad (6.7)
```

The full model can then be written where we have stacked the components in **x** and **q** = $[x_1, \dots, x_p]^T$ and **q** = $[q_1, \dots, q_U]^T$. Note that the activation function $h$ in (6.8) acts element-wise on the input vector, and results in an output vector of the same dimension. The two weight matrices and the two offset vectors are the parameters of the model, which can be written as

```
$\boldsymbol{\theta} = [\text{vec}(\mathbf{W}^{(1)})^T, \mathbf{b}^{(1)})^T, \text{vec}(\mathbf{W}^{(2)})^T, \mathbf{b}^{(2)})^T].\quad (6.9)
```

> The word "bias" is used for the offset in neural network literature, but this is really just a model parameter and not a bias in the statistical. To avoid confusion we refer it as an offset.

### Deep neural network

The two-layer neural network is a useful model on its own, and a lot of research and analysis has been done for it. However, the real descriptive power of a neural network is realized when we stack multiple layers of generalized linear regression models, and thereby achieve a *deep neural network*. Deep networks can manage complicated relationships (such as the one between image and class), and are one of the state-of-the-art methods in machine learning as of today.

We enumerate the layers with index $l\in\{1,...,L\}$ where $L$ is the number of the layers. *Each layer* is parametrized with a weight matrix $\mathbf{W}^{(l)}$ and an offset vector $\mathbf{b}^{(l)}$ for the two-layer case. For example, $\mathbf{W}^{(1)}$ and $\mathbf{b}^{(1)}$ belong to layer $l=1$, $\mathbf{W}^{(2)}$ and $\mathbf{b}^{(2)}$ belong to layer $l=2$ and so forth. We also have multiple *layers of hidden units* denoted by $\mathbf{q}^{(l)} = [q_1^{(l)},q_{U_l}^{(l)}]^T$, where the dimensions $U_1,...,U_{L-1}$ can be different from the various layers.

Each layer maps the output of the first layer of hidden units $\mathbf{q}^{(1)}$ is the input to the second layer, the output of the second layer $\mathbf{q}^{(2)}$ (the second layer of hidden units) is the input to the third layer, etc. By stacking multiple layers we have constructed a deep neural network. A deep network of $L$ layers can be mathematically described as

```
$$\mathbf{q}^{(1)} = h(\mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)})$$
$$\mathbf{q}^{(2)} = h(\mathbf{W}^{(2)}\mathbf{q}^{(1)} + \mathbf{b}^{(2)})$$
$$$$
$$\mathbf{q}^{(L-1)} = h(\mathbf{W}^{(L-1)}\mathbf{q}^{(L-2)} + \mathbf{b}^{(L-1)})$$
$$\hat{\mathbf{y}} = h(\mathbf{W}^{(L)}\mathbf{q}^{(L-1)} + \mathbf{b}^{(L)})$$
```

A graphical representation of this model is provided in Figure 6.4. The expression (6.11) for a deep neural network can be compared with the expression (6.8) for a two-layer neural network.

The weight matrix for the first layer $l=1$ has dimension $U_1 \times p$ and the corresponding offset $\mathbf{b}^{(1)}$ has dimension $U_1$. Since the output is in the last layer the weight matrix $\mathbf{W}^{(L)}$ has dimension $1 \times U_{L-1}$. For all intermediate layers $l=2,...,L-1$, $\mathbf{W}^{(l)}$ has dimension $U_l \times U_{L-1}$ and the corresponding offset vector $\mathbf{b}^{(l)}$. The number of inputs $p$ are given by the problem, but the number of layers $L$ and the dimensions $U_1,U_2,...$ are user design choices that determine the flexibility of the model.

## Vectorization over data points

During the training neural network model are used to compute the predicted output, not only for one input but for several samples $\{\mathbf{x}_i\}_{i=1}^n$. For example, for the two-layer neural network presented in Section 6.1 we have

```
$$\mathbf{q}_i^{(1)} = h(\mathbf{W}^{(1)T}\mathbf{x}_i + \mathbf{b}^{(1)})$$
$$\hat{\mathbf{y}}_i = h(\mathbf{W}^{(2)T}\mathbf{q}_i^{(1)} + \mathbf{b}^{(2)}) \quad i=1,...,n.$$
