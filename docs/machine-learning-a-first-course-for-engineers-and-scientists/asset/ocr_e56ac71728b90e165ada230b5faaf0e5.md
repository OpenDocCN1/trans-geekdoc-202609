# Example 7.6: AdaBoost and bagging for a binary classification example

Consider the same binary classification problem as in Example 7.4. We now compare how AdaBoost and bagging on this problem, when using trees of depth one (decision stumps). It should be noted that this comparison is made to illustrate the difference between methods. In practice, we would typically not use bagging with shallow trees.

The decision boundaries for each method with $B = 1, 5, 20$ and 100 ensemble members are shown in Figure 7.8. Despite using weak ensemble members, AdaBoost adapts well to the data. This is in contrast to bagging, where the decision boundary does not become more flexible despite using ensemble members. In other words, AdaBoost reduces the variance of the base model, whereas bagging has no effect on the bias.

We also numerically compute $\hat{E}_{new}$ for this problem, as a function of $B$, which is shown in the bottom of Figure 7.8. $\hat{E}_{new}$ depends on both the bias and the variance. As discussed, the main effect of bagging is variance reduction, which does not help since the base model is already quite low-variance (high-bias). Boosting, on the other hand, reduces bias, which has a much bigger effect in this case. Furthermore, bagging does not overfit as $B \to \infty$, but boosting does.
