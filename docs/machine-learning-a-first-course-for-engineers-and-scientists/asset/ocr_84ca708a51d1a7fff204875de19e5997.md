# 9.4 Practical aspects of the Gaussian process

# Example 9.3: Car stopping distances

We consider the car stopping distance problem from Example 2.2. We have already discussed the application of the other methods kernel ridge regression and support vector regression in Examples 8.2 and 8.3, respectively, both in Chapter 8. We use the results in the previous examples looked reasonable, we use the same kernel and hyperparameters again, meaning that we have

```
$$\hat{k}(x,x') = \exp(-\frac{|x-x'|^2}{2\ell^2}) + (1+xx')\sigma^2[x=x'])$
```

with $\ell=3$ and $\sigma^2=\lambda$ (with $\lambda=0.01$ and $n=62$ data points). However, we also have the option to introduce yet another parameter $\zeta^2$ as $\hat{\zeta}^2(x,x')$. In the top part of Figure 9.14 we use $\zeta^2=2^2$ and $\zeta^2=40^2$ to illustrate the functional impact that $\zeta^2$ has on the posterior predictive. (Note that only the variance, and the mean, is not affected by $\zeta^2$. This can be confirmed by the fact that $\zeta^2$ cancels algebraically in (9.26a) but not in (9.26b).

![](bbox=[0.139, 0.335, 0.821, 0.473])

$\zeta^2 = 12^2$

![](bbox=[0.239, 0.503, 0.735, 0.696])

To select $\zeta^2$ we therefore maximize the marginal likelihood with respect to it, which gives us $\zeta^2=12^2$, as shown in the bottom of Figure 9.14. It indeed seems to have a very reasonable variance ("uncertainty") in the posterior predictive distribution.
