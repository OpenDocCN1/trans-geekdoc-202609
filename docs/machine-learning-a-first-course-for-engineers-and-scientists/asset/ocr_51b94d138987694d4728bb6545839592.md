# Example 7.1: Using bagging for a regression problem

Consider the data (black dots) that are drawn from a function (dashed line) plus noise in Figure ??. As always in supervised machine learning, we want to learn a model from the data which is to predict new data points. Being able to predict new data points with means, among other things, that the model should predict the dotted line at $x_a$ (the empty blue circle).
For this problem we can use this regression method. Here, using a regression tree which is grown until each leaf node is pure the prediction is shown to the lower left in Figure 7.1 (blue line and dot). This is a typical low-high-variance model, and the overfitting to the training data is apparent from the figure. We could decrease its variance, and hence the overfitting, by using a more shallow tree, but that would on the other hand increase the bias. Instead, we lower the variance (without increasing the bias) by using bagging with the regression tree as base model.

The rationale behind bagging follows as: Because of the noise in the training data, we may think of the prediction $\hat{y}(x_a)$ (the blue dot) as a random variable. In bagging, we learn an ensemble of models (upper right in Figure 7.1), where each base model is trained on a "version" of the training data obtained using bootstrap. We may therefore think of each base model to be a different realization of the random variable $\hat{y}(x_a)$. The average of realizations of a random variable has a lower variance than the random variable itself, which means that by taking the average (lower right in Figure 7.1) of all base models we obtain a prediction with less variance than the base model itself. That is, the bagged regression (lower right) has lower variance than a single prediction (lower left in Figure 7.1). Since the base model itself has low bias, the aggregated prediction will have low bias and low variance. We can visually confirm that the prediction is better (blue dot and circle are close to each other) for bagging than the single regression tree.
