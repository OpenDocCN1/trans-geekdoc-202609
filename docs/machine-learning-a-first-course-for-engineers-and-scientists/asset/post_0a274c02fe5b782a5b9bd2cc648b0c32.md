
## 7.1 Bagging

### The bootstrap

As outlined in Example 7.1, the idea of bagging is to average over multiple base models, each learned from a different training dataset. We first have to construct different training datasets. In the best of worlds we would collect multiple datasets, but most often we cannot do that and instead we have to make the most out of the limited data available. For this purpose, the bootstrap is useful.

The bootstrap is a method for creating multiple datasets (of size $n$) out of one dataset (also of the real-world data generating process, in the sense that if $i$ were to collect more training data, the data points would likely be similar to the training data points already contained in $\mathcal{T}$). We can argue that randomly picking data points from $\mathcal{T}$ is a reasonable way to simulate a "new" training dataset. In statistical terms, instead of sampling from the population (collecting more data), we sample from available training data which is assumed to be a good representation of the population.

The bootstrap is stated in Algorithm 7.1 and illustrated in Example 7.2 below. Note that the sampling is done with replacement, meaning that the resulting bootstrapped dataset may contain multiple copies of some of the original training data points, whereas other data points are not included at all.

#### Algorithm 7.1: The bootstrap.

```
Data: Training dataset $\mathcal{T} = \{\mathbf{x}_i, y_i\}_{i=1}^n$
Result: Bootstrapped dataset $\hat{\mathcal{T}} = \{\hat{\mathbf{x}}_i, \hat{y}_i\}_{i=1}^n$
1 for $i = 1, \dots, n$ do
2   Sample $t$ uniformly from the set of integers $\{1, \dots, n\}$
3   $\hat{\mathbf{x}}_i = \mathbf{x}_t$ and $\hat{y}_i = y_t$
4 end
```

### ### Variance reduction by averaging

By running the bootstrap (Algorithm 7.1) repeated $B$ times we obtain $B$ identically distributed bootstrapped datasets $\tilde{\mathcal{T}}^{(b)}$. We can then use these datasets to train an ensemble of $B$ base models. We thereafter average their predictions $\tilde{y}_{bag}(x_*) = \frac{1}{B} \sum_{b=1}^{B} \tilde{y}^{(b)}(x_*) \quad \text{or} \quad \hat{g}_{bag}(x_*) = \frac{1}{B} \sum_{b=1}^{B} \hat{g}^{(b)}(x_*), \quad (7.1)$ on whether we are performing regression (predicting an output $\tilde{y}_{bag}(x_*)$) or classification (predicting class probabilities $\hat{g}(x_*)$). If this is not the case, we can instead obtain a "hard" classifier by taking majority vote over all members. Note that it is better to take a plain average across the ensemble (each member weighted equally) due to the fact that all members are identically distributed. In (7.1), $\tilde{y}^{(1)}(x_*), \dots, \tilde{y}^{(B)}(x_*)$ and $\hat{g}^{(1)}(x_*), \dots, \hat{g}^{(B)}(x_*)$ denote the predictions from the individual members. The averaged prediction, $\tilde{y}_{bag}(x_*)$ or $\hat{g}_{bag}(x_*)$, is the final prediction from bagging. We may stabilize this by Method 7.1. For classification, the prediction could alternatively be decided by majority vote among the members, but that typically degrades the performance slightly compared to the averaged class probabilities.

#### Method 7.1 Bagging

**Learn all base models**
**Data:** Training dataset $\mathcal{T} = \{\mathbf{x}_i, y_i\}_{i=1}^n$
**Result:** $B$ base models
```
1 for $b = 1, \dots, B$ do
2   Algorithm 7.1 to obtain a bootstrapped training dataset $\mathcal{T}^{(b)}$
3   Learn a model from $\mathcal{T}^{(b)}$
4 end
5 Obtain $\tilde{y}_{bag}(x_*)$ or $\hat{g}_{bag}(x_*)$ by averaging (7.1).
```

**Predict with base models**
**Data:** $B$ base models and test input $\mathbf{x}_*$
**Result:** A prediction $\tilde{y}_{bag}(x_*)$ or $\hat{g}_{bag}(x_*)$
```
1 for $b = 1, \dots, B$ do
2   Use base model $b$ to predict $\hat{y}^{(b)}(x_*)$ or $\hat{g}^{(b)}(x_*)$
3 end
4 Obtain $\tilde{y}_{bag}(x_*)$ or $\hat{g}_{bag}(x_*)$ by averaging (7.1).
```

We now give some more details on the variance reduction that happens in (7.1), which is the entire point of bagging. We average on regression, but the intuition works also for classification.

First make a basic observation regarding random variables, namely that averaging reduces variance. To formalize this, let $z_1, \dots, z_B$ be identically distributed (but possibly dependent) random variables with mean $\mathbb{E}[z_b] = \mu$ and variance $\text{Var}[z_b] = \sigma^2$ for $b=1, \dots, B$. Furthermore, assume that the average correlation between any pair of $B$ variables is $\rho$. Then, computing the mean and the variance of the average of $B$ variables we get:

> $\mathbb{E}\left[\frac{1}{B}\sum_{b=1}^B z_b\right] = \mu.\quad (7.2a)$

> $\text{Var}\left[\frac{1}{B}\sum_{b=1}^B z_b\right] = \frac{1-\rho}{B}\sigma^2+\rho\sigma^2.\quad (7.2b)$

The first equation (7.2a) tells us that the mean is unaltered by averaging a number of identically distributed random variables. The second equation (7.2b) tells us that the variance is reduced by averaging if the correlation $\rho < 1$. The first term in the variance (7.2b) can be arbitrarily small by increasing $B$, whereas the second term is only determined by the correlation $\rho$ and variance $\sigma^2$. To make a connection between bagging and (7.2), consider the predictions $\hat{y}^{(b)}(\mathbf{x}_)$ from the base models as random variables. All base models, and their predictions, are identically distributed but correlated. By averaging them from the same data $\mathcal{T}$ (via the bootstrap), we decrease the variance, according to (7.2b). If we only use $B$ large, the achieved variance reduction is limited by the correlation $\rho$. Experience has shown that if $B$ is small enough, the computational complexity of bagging (compared to using only one base model) pays off in terms of decreased variance. To summarize, averaging the identically distributed predictions from several base models each with a low bias, the bias remains low (according to (7.2a)) and the variance is reduced (according to (7.2b)).
