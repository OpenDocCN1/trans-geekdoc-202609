# 1 Introduction

Machine learning is about learning, reasoning, and acting on data. This is done by constructing computer programs that process the data, extract useful information, make predictions regarding unknown properties, and suggest actions to take or decisions to make. What turns analysis into machine learning, is that the process is automated and the computer program is learnt from data. From this that generic computer programs are used, which are adapted to application-specific circumstances by automatically adjusting the settings of the program based on so-called, training data. It can be said that machine learning is quite arbitrary what the data represents, and we can design general methods that are useful for a wide range of practical applications in different domains. We will illustrate this a range of examples below.

The "generic computer program" referred above corresponds to a mathematical model of the data. That is, when we develop and describe different machine learning methods, we do this using the language of mathematics. The mathematical model describes the observed data and the properties of the interest (such as predictions, actions, variables, etc.). Hence, the model is a compact representation of the data, that in a mathematical form, captures the properties of the phenomenon we are studying. Which method to use is typically guided by the machine learning engineer's insights generated when using the available data and the practitioner's general understanding of the problem. When implementing the method in practice, this mathematical model is translated into code that can be executed on a computer. However, to understand what the computer program actually does, it is also important to understand the underlying mathematics.

As mentioned above, the model (or computer program) is learnt based on the available training data. This is accomplished by using a learning algorithm which is capable of automatically adjusting the settings, or parameters, of the model to agree with the data. In summary, the three cornerstones of machine learning are:

- 1. The data
- 2. The mathematical model
- 3. The learning algorithm

In this introductory chapter we will give a taste of machine learning cornerstones with a few examples. They come from different application domains and have different properties, but nevertheless, they can all be addressed using similar techniques from machine learning. We also give advice on how to proceed through the rest of the book and, at the end, provide references to good books on machine learning for the interested reader who wants to dig further into this topic.

## 1.1 Machine learning exemplified

Machine learning is a multifaceted subject. We give a brief and high-level description of what it entails above, but this will become much more concrete as we proceed throughout this book and introduce specific methods and techniques for solving various machine learning problems. However, by digging into the details we try to give an intuitive answer to the question "What is machine learning?", by discussing a few applications where it can (and has) been used.

We start with an example to relate to medicine, precisely cardiology.

## Example 1.1: Automatically diagnosing heart abnormalities

The leading cause of death is conditions that affect heart and blood vessels, collectively referred to cardiovascular diseases. Heart problems often influence the electrical activity of the heart, which can be measured using electrodes attached to the body. The electrical signals are reported in an electrocardiograms (ECG). In Figure 1.1 we show examples of (parts of) the measured signals from three different hearts. The measurements from a healthy heart (top), a heart suffering from atrial fibrillation (middle), and a heart suffering from right bundle branch block (bottom). Atrial fibrillation makes the heart beat without order making it hard for the heart to pump blood in a normal way. Right bundle branch block corresponds to a delay or blockage in the electrical pathways of the heart.

By analyzing the ECG signal, a cardiologist gains valuable information about the condition of the heart, which can be used to diagnose the patient and plan the treatment.

To improve the diagnostic accuracy, as well as save time for the cardiologists, we can ask ourselves if this process can be automated to some extent. That is, can we construct a computer program which reads the ECG, analyzes the data, and returns a prediction regarding the normality or abnormality? Such models, capable of accurately interpreting an ECG in an automated fashion, will find applications globally, but most in low- and middle-income countries. An important reason for this is that the population in these countries do not have easy and direct access to highly cardiologists. Furthermore, cardiovascular diseases in these countries are related to more than 25% of deaths.

The key challenge in building such a program is that it is far from obvious computations that are needed to turn the raw ECG into a prediction about the heart condition. Even if an experienced cardiologist would try to translate the cardiologist's experience into a software developer patterns in the data to look for, this task would be extremely challenging.

To handle this difficulty, a machine learning approach is used to learn the patterns from examples. Specifically, instead of asking the cardiologist to set a set of rules for how to classify an ECG as normal or abnormal, we use labels corresponding to the underlying heart condition. This is a much easier (possibly tedious) for the cardiologists to communicate their experience and encode it in a way which is understandable.

The task of the learning is then to automatically adapt the computer program so that its predictions agree with the cardiologist's labels on the labeled training data. The hope is, if it succeeds on the training data (which we already know), then it is possible to use the predictions made by the program on previously unseen data (where we do not know the answer) well.

This is the approach taken by Ribeno et al. (2020) who developed a machine learning model for ECG diagnosis.
