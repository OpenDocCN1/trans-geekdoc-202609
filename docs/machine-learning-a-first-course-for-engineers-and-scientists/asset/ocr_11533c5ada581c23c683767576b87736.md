# 10 Generative models and learning from unlabeled data

The models introduced so far in this book are so-called discriminative models, also referred to as conditional models. These models are designed to learn from data to predict the output conditionally on a given input. However, they distinguish (or discriminate between) inputs only in terms of their corresponding outputs. In the first half of this chapter we will introduce another modeling paradigm, so-called generative modeling. Generative models are also learned from data, but their scope is wider. In contrast to discriminative models, which only describe the distribution of the output for a given input, a generative model describes the joint distribution of inputs and outputs. Having access to a probabilistic model for input allows, for instance, to simulate data from the model. However, perhaps more importantly, it can be used to give a generative model a “deeper understanding” of the data. For instance, it can be used to reason about whether or not a certain input is typical, and it can be used to find patterns among input variables in the absence of corresponding output values. Generative modeling is therefore a natural way to use unsupervised learning, which we will do in the second half of this chapter.

Specifically, a generative model aims to describe the distribution p(x, y). That is, it provides a probabilistic description of how both input and output are generated. We should write p(x, y; θ) to emphasize that it contains some parameters that we will learn from data, but to note that we use p(x, y). To use a generative model for predicting the value of y for a given input x, we use probability theory. We will make this idea concrete by considering a rather simple, such as Gaussian mixture model (GMM). The GMM can be used for different purposes: for example, trained in a supervised way, to see how the generative GMM naturally occurs as a linear or quadratic discriminant, or used in semi-supervised learning (where y are partially missing) and unsupervised learning (where y is not at present; there is only x and no y as well). In the latter case, the GMM can be used for the so-called clustering problem, which groups similar x-y clusters together.

We will extend the idea of generative models beyond the Gaussian case, by describing generative models that use deep neural networks (Chapter 6) for modeling p(x). Specifically, we will discuss two such methods: normalizing flows and generative adversarial networks. Both are capable of learning the distribution of high-dimensional data with complicated dependencies in an unsupervised way, which is based only on observed x-values.

Generative models bridge the gap between supervised and unsupervised machine learning, but not all methods for unsupervised learning come from generative models. We therefore end this chapter by introducing (non-generative) methods for unsupervised representation learning. Specifically, we introduce the nonlinear auto-encoder and linear counterpart, principal component analysis (PCA), which are both useful for learning a low-dimensional representation of high-dimensional data.
