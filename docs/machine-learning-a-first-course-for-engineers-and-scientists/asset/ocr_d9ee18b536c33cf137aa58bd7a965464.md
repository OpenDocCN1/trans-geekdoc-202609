# 8 Nonlinear input transformations and kernels

The push-through matrix identity senses that $A(A^	op+I)^{-1} = (AA^	op+I)^{-1}A$ holds for any matrix $A$. By using it in (8.6), we can rewrite $\widetilde{Y}(\mathbf{x}_*)$

```
$\widetilde{Y}(\mathbf{x}_*) = \frac{\mathbf{y}^	op\Phi(\mathbf{x})}{n} (\Phi(\mathbf{x})^	op\Phi(\mathbf{x}) + n\mathbf{I})^{-1}\Phi(\mathbf{x})^	op\phi(\mathbf{x}_*) \quad (8.7)$
```

It appears in (8.7) as if we compute $\phi(\mathbf{x}_*)$ without having to deal with any $d$-dimensional vectors or matrices, or if the matrix multiplication $\Phi(\mathbf{x})\Phi(\mathbf{x})^	op$ and $\Phi(\mathbf{x})^	op\phi(\mathbf{x})$ in (8.7) can be computed. Let us have a closer look at this:

```
$$\Phi(\mathbf{x})Phi(\mathbf{x})^	op = \begin{bmatrix} \phi(x_1)^	op\phi(x_1) & \phi(x_1)^	op\phi(x_2) & \dots \ \phi(x_2)^	op\phi(x_1) & \phi(x_2)^	op\phi(x_2) & \dots \ \vdots & \vdots & \vdots \ \phi(x_n)^	op\phi(x_1) & \phi(x_n)^	op\phi(x_2) & \dots \end{bmatrix} \quad \text{and} \quad \begin{bmatrix} \phi(x_1)^	op\phi(x_n) \ \phi(x_2)^	op\phi(x_n) \ \vdots \ \phi(x_n)^	op\phi(x_n) \end{bmatrix} \end{ \end{matrix} \quad (8.8)$
```

Remember that $\phi(\mathbf{x})^	op\phi(\mathbf{x}')$ is an inner product between the $d$-dimensional vectors $\phi(\mathbf{x})$ and $\phi(\mathbf{x}')$. The key insight is to note that the transformed inputs $\phi(\mathbf{x})$ enter into (8.7) only as inner products $\phi(\mathbf{x})^	op\phi(\mathbf{x}')$, where each inner product is scalar. That is, if we are able to compute the inner product $\phi(\mathbf{x})^	op\phi(\mathbf{x}')$ directly, without first computing the $d$-dimensional $\phi(\mathbf{x})$, we have reached our goal.

As a concrete illustration, let us simplify consider polynomials. With $p=1$, meaning $x$ is a scalar, and $x$ is a polynomial of order $(d=4)$ with the second and third term scaled by $\sqrt{3}$, we have

```
$$\phi(\mathbf{x})^	op\phi(\mathbf{x}') = [ \begin{bmatrix} 1 & \sqrt{3}x & \sqrt{3}x^2 & \sqrt{3}x^3 \end{bmatrix}^\top \begin{bmatrix} 1 \ \sqrt{3}x' \ \sqrt{3}(x')^2 \ \sqrt{3}(x')^3 \end{bmatrix} = 1 + 3xx' + 3x^2(x')^2 + x^3(x')^3 = (1+xx')^3 ] \quad (8.10)$
```

It can be shown that if $\phi(\mathbf{x})$ is (a re-scaled) polynomial of order $d-1$, then $\phi(\mathbf{x})^	op\phi(\mathbf{x}') = (1+xx')^d$. The point we make is that instead of first computing the $d$-dimensional vectors $\phi(\mathbf{x})$ and $\phi(\mathbf{x}')$ and thereafter computing their inner product, we could evaluate the expression $(1+xx')^d$ directly. With a second or third order polynomial this might not make much of a difference, but the computational saving in a situation where it is of interest to use $d$ in the hundreds or thousands.

The main point we are saying is that if we make the choice of $\phi(\mathbf{x})$ such that the inner product $\phi(\mathbf{x})^	op\phi(\mathbf{x}')$ can be computed without computing $\phi(\mathbf{x})$, we let be possible to define inner products between infinite-dimensional vectors, there is nothing preventing us from learning.

The scaling $\sqrt{3}$ can be compensated with an inverse scaling of the second and third element in $	heta$.
