consider learning a model for classifying images of skin lesions to be either benign or malignant, to be used in a medical support system. The training inputs $x$, will correspond to the images of skin and it is easy to acquire a large number of such images. To annotate the training data with labels $y_l$, we need to determine whether or not these lesions are malignant which requires a (possibly expensive) medical examination by a dermatologist.

The simplest solution to the semi-supervised problem is to discard the $n_u$ unlabeled data, this is a pragmatic, but possibly very useful if the number of labeled points $n_l$ is only a small fraction of the total number of data points $n$. We illustrate this with Figure 10.5, which depicts a semi-supervised problem where we learned a poor GMM by only using the few $n_l$ labeled data points.

The idea behind semi-supervised learning is to exploit the information available in the unlabeled data points, hopefully end up with a better model in the end. There are many ways in which this can be approached, but one principle is to make use of a generative model. Remember that a generative model is a model of the joint distribution $p(x, y)$, which can be factorized as $p(x, y) = p(y)p(y|x)$. Since the marginal distribution of the inputs $p(x)$ is a part of the model, it seems plausible that the unlabeled points $\{x_j\}_{j=1}^{n_u}$ can be useful when learning the model.

Intuitively, the unlabeled inputs can be used to find groups (or clusters) of values with properties that can be assumed to belong to the same class. Looking at Figure 10.5 again, by considering the unlabeled data points (gray) it is reasonable to assume that the two clusters of points correspond to the two classes (red and blue, respectively). As we will see, by including this information we can obtain better estimates of the class-conditional distributions $p(x|y)$ and thereby obtain a better classifier.

We will now turn to the technical details of how to learn the GMM in this semi-supervised setting. Similarly to above we use the maximum likelihood approach, meaning that we maximize the likelihood of the observed data. To the supervised case, however, the observed data contains both labeled and unlabeled instances, as that would be like to

$$\theta = \arg\max_{\theta} p(\{x_i, y_i\}_{i=1}^{n_l}, \{x_j\}_{j=1}^{n_u} | \theta)$$

Unfortunately this problem has no closed-form solution for the GMM. We will discuss the reason for this intractability in more detail in Section 10.2, where we revisit the same problem in the fully unsupervised setting. Intuitively, we will conclude that it is not possible to compute the model parameters as in (10.3), because we do not know which the unlabeled data points belong to. Hence,

computing the mean vector for the $m$th class in (10.3b), for instance, we do not know which data points should be included in the sum.

However, a possible way around this is to first learn a GMM, which is then used to predict the missing values $\{y_i\}_{i=1}^n$, and thereafter these predictions are used to update the model. Doing this iteratively in the following algorithm:

- (i) Learn the GMM from the $n$ labeled input-output pairs $(x_i, y_i)_{i=1}^n$,
- (ii) Use the GMM to predict (as a QDA classifier) the missing outputs to $\{x_i\}_{i=n+1}^n$,
- (iii) Update the GMM using the predicted outputs from (ii),
then repeat until convergence.

At first light this looks an *ad hoc* procedure and it is far from obvious that it could be anything else. It turns out that it is a widely used statistical tool referred to the expectation-maximization (EM) algorithm. We study the EM algorithm and its validity in more detail in Section 10.2. We simply note that, when applied to the maximum likelihood procedure (10.9), it boils down to the procedure outlined above, as we pay attention to a few important details: From step (ii) we return the predicted class probabilities $p(y=m|x,\hat{\theta})$, and in step (iii) we make use of the predicted probabilities by introducing the notation

$w_i(m) = \begin{cases} p(y=m|x,\hat{\theta}) & \text{if } y_i \text{ is missing} 1 & \text{if } y_i = m \\ 0 & \text{otherwise} \end{cases}$

and update the parameters as

$\hat{\mu}_m = \frac{1}{\sum_{i=1}^n w_i(m)},$

$\hat{\Sigma}_m = \frac{1}{\sum_{i=1}^n w_i(m)} \sum_{i=1}^n w_i(m)(x_i - \hat{\mu}_m)(x_i - \hat{\mu}_m)^T.$

Note that we use the current parameter estimate $\hat{\theta}$ in step (ii), which is then updated in step (iii), so we go back to (i) for the next iteration the class probabilities will be computed using a new value of $\hat{\theta}$. When computing the parameters for class $m$ according to (10.10), the unlabeled data points counts proportionally to the current estimates of the classes that they belong to. Note that this is a generalization of the supervised case, (10.3) is a special case of (10.10) when no labels $y_i$ are available. With these modifications it can be shown (Section 10.2) that the procedure discussed above converges to a stationary point of (10.9) in the semi-supervised setting. We summarize the procedure as Method 10.2, and illustrate it in Figure 10.6 by applying it to the semi-supervised data introduced in Figure 10.5.

We have devised a way to handle semi-supervised classification problems using the GMM, and thus in the semi-supervised setting when some output $y_i$ are from the training data.
