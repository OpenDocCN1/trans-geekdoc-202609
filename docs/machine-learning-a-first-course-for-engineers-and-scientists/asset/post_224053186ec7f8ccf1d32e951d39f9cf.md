**Figure 6.6:** A computational graph of the backpropagation algorithm. We start with the input in the upper left and propagate forward and evaluate the cost. Along the way we cache the values for the hidden units $q^{(l)}$ and $z$. We propagate the gradients $dq^{(l)}$ and $dz^{(l)}$ backwards and compute the gradients for the parameters $W^{(l)}, b^{(l)}$. The equations behind this computational graph are given in (6.24), (6.26) and (6.27).

$dz^{(L)}$, the gradient of the cost function with respect to the hidden units in the last layer. This obviously depends on our choice of loss function (6.24). If we have a regression problem and the squared error, we get

```
$dz^{(L)} = \frac{\partial J}{\partial z^{(L)}} = (y-z^{(L)}) \cdot -2=-2(y-z^{(L)})$
```

For a multiclass classification, we use the cross-entropy loss (6.20), and we get

```
$dz^{(L)} = \frac{\partial J}{\partial z^{(L)}} = \frac{\partial J}{\partial a^{(L)}} \cdot (a^{(L)}+\ln\sum_{k=1}^{M} e^{z^{(k)}})=-y^{(j)}-\sum_{k=1}^{M} e^{z^{(k)}}$
```

The backpropagation now proceeds with the following recommendations

```
$dz^{(l)} = dq^{(l)} \cdot h'(z^{(l)})$
```

```
$dq^{(l)} = W^{(l+1)T} dz^{(l+1)}$
```

where $\cdot$ denotes the element-wise product and $h'(z)$ is the derivative of the activation function $h(z)$. Similar to the notation in (6.24), $h'(z)$ acts element-wise on the vector $z$. Note that the first line in (6.27a) is not correct for layer $L$ that layer does not have an activation function, see (6.24c). With $dz^{(l)}$, we can compute the gradients of $W^{(l)}$ and $b^{(l)}$

```
$W^{(l)} = dq^{(l)} q^{(l-1)T}$
```

```
$b^{(l)} = dz^{(l)}$
```

All equations for the backward pass (6.27) can be derived from the chain rule of calculus, for further details see Appendix 6.a. A computational graph of the backpropagation algorithm is summarized in Figure 6.6.

So far we have only considered for one data pass $(x,y)$. However, we want to compute the cost function $J(\theta)$ and its gradients $dW^{(l)}$ and $db^{(l)}$ for the mini-batch $\{X_i, Y_i\}_{i=1}^{n_b+1}$ — Therefore, we run the equations (6.24), (6.26), and (6.27) for all data points in the current mini-batch and aggregate their results for $J$, $dW^{(I)}$ and $db^{(I)}$. To do this in a computationally efficient manner, we process all $n_b$ data points in the mini-batch simultaneously by stacking them as matrices as we do in (6.14) where each row represents one data point.

```
$Q = \begin{bmatrix} q_1^T \ \vdots \ q_{n_b}^T \end{bmatrix}, \quad Z = \begin{bmatrix} z_1^T \ \vdots \ z_{n_b}^T \end{bmatrix}, \quad dQ = \begin{bmatrix} dq_1^T \ \vdots \ dq_{n_b}^T \end{bmatrix}, \quad dZ = \begin{bmatrix} dz_1^T \ \vdots \ dz_{n_b}^T \end{bmatrix} \quad (6.28)$
```

The complete algorithm is then summarized in Algorithm 6.1.

**Algorithm 6. Backpropagation**
**Input:** Parameters $\theta = \{W^{(I)}, b^{(I)}\}_I$, activation function $h$ and data $X, y$, with $n_b$ rows, where each row corresponds to one data point in the current mini-batch.
**Output:** $J(\theta)$, $\nabla_\theta J(\theta)$ of the current mini-batch
**1** Forward propagation
**2** Set $Q^{(I)} \leftarrow X$
**3** for $l = 1, \dots, L$
**4** $Z^{(I)} = Q^{(I)}W^{(l)T} + b^{(l)T}$
**5** $Q^{(I)} = h(Z^{(I)})$ *Do not execute this line for last layer $l = L$*
**6** end
**7** Evaluate cost function
**8** if Regression problem then
**9** $J(\theta) = \frac{1}{n_b} \sum_{i=1}^{n_b} (Y_i - Z_i^{(L)})^2$
**10** $dZ^{(L)} = -2(Y_i - Z^{(L)})$
**11** else if Classification problem then
**12** $J(\theta) = \frac{1}{n_b} \sum_{i=1}^{n_b} (-Z_{ij}^{(L)} + \ln(\sum_{j=1}^{C_L} \exp(Z_{ij}^{(L)}))$
**13** $dZ_{ij}^{(L)} = -Y_{ij} + \frac{\exp(Z_{ij}^{(L)})}{\sum_{k=1}^{C_L} \exp(Z_{ik}^{(L)})}$ $\forall i, j$
**14** Backward propagation
**15** for $l = L, \dots, 1$
**16** $dZ^{(I)} = dQ^{(I)} \odot h'(Z^{(I)})$
**17** $dQ^{(l-1)} = dZ^{(I)}W^{(l)T}$
**18** $dW^{(l)} = \frac{1}{n_b} Q^{(I)T dZ^{(I)}$
**19** $db^{(l)} = \frac{1}{n_b} \sum_{i=1}^{n_b} dZ_{ij}^{(l)}$ $\forall j$
**20** end
**21** $\nabla_\theta J(\theta) = [vec(dW^{(1)})^T, db^{(1)}, \dots, vec(dW^{(L)})^T, db^{(L)}]$
**22** return $\nabla_\theta J(\theta)$

# Initialization

Most of the previous problems (such as logistic regression) that we have encountered have been convex. This means we can guarantee global convergence regardless of initialization $\theta_0$ we use. In contrast, cost functions for neural networks are non-convex. This means that training is sensitive to the value of the initial parameters. Typically, we initialize all parameters to random numbers to enable the hidden units to encode different aspects of the data. If the ReLU activation functions used, the biases are typically initialized to a small positive value that operates in the non-negative range of ReLU.

One might want to consider normalizing the logits $Z_{ij}^{(L)} \leftarrow -max Z_{ij}^{(L)}$ before computing the cost to avoid potential overflow using $\exp(Z_{ij}^{(L)})$. Note that normalization does not change the value of the cost function.
