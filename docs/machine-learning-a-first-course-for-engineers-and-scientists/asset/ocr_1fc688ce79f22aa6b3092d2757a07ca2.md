Comparing with this in the supervised setting (10.2b), when all labels $[y_i]_{i=1}^n$ are known, we note that the two expressions are very similar. The only difference is the indicator function $I(y=m)$ in (10.2b) is replaced by the weight $w_i(m)$ in (10.15). In words, instead of making a hard cluster assignment of each data point based on a given class, we make a soft cluster assignment based on the probabilities that data point belongs to the different clusters.

We will not go into the details, but it is hard not to believe that maximizing (10.15) with respect to $	heta$—what we do in the M-step of the algorithm—gives a solution similar to the supervised setting, but where the training data points are weighted by $w_i(m)$. Analogously to (10.10), the M-step becomes

```
$$\hat{\pi}_m = \sum_{i=1}^{n} w_i(m), \quad (10.16a)
```

```
$$\hat{\mu}_m = \sum_{i=1}^{n} w_i(m) \mathbf{x}_i, \quad (10.16b)
```

```
$$\hat{\Sigma}_m = \sum_{i=1}^{n} w_i(m) (\mathbf{x}_i - \hat{\mu}_m)(\mathbf{x}_i - \hat{\mu}_m)^\top. \quad (10.16c)
```

There are important details about learning the GMM in the unsupervised setting which deserve some attention. First, the number of clusters (that is, number of Gaussian components in the mixture) $M$ must be specified in order to run the algorithm. This hyperparameter choice in more detail below. Second, since there are only unlabeled data points, the indexation of the $M$ Gaussian components becomes arbitrary. Put differently, all permutations of the class labels will have the same likelihood. 10.7 shows that the colors (red and blue) are interchangeable, and are reason for why we use this particular likelihood that we initialize the cluster in the upper part and in the lower part of the space.

The EM algorithm is only guaranteed to converge to a stationary point, which means that a poor initialization can result in convergence to a local optimal. In the semi-supervised setting we could use the labeled training data point as to initialize the method, but this is not possible in a fully unsupervised setting. Hence, initialization becomes an important detail to consider. A pragmatic approach is to run Method 10.3 multiple times with random initializations.

Finally, there is a issue with the maximum likelihood problem (10.12) that we have to sweep under the rug. Without constraints on the parameters $\theta$ the unsupervised maximum likelihood problem for a GMM is ill-posed, in the sense that the likelihood is unbounded. The problem is that the value of Gaussian probability density function becomes larger and the (co-)variance approaches zero. For any $M \geq 2$, the GMM in principle is able to find to attain this likelihood. This is possible by focusing one of the clusters on a single data point; by shrinking the (co-)variance towards zero the likelihood of this particular data point goes to infinity. The remaining $M-1$ clusters then have to cover the remaining $n-1$ data points so that their likelihood are bounded around zero. In practice, the EM algorithm will

> used in the semi-supervised setting as well, but only if there are a or few data points of each class.
