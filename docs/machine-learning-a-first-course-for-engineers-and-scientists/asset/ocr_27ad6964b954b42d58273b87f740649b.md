The challenge is that the observed data-likelihood is not readily available, due to the presence of the latent variables $y$ in the model specification. Evaluating the log-likelihood requires marginalizing over those variables. In the EM algorithm we address this challenge by alternating computing an *expected log-likelihood* and *maximizing* this expected to update the model parameters.

Let $	heta$ denote the current estimate of $	heta$ at some intermediate iteration of Method 10.3. This can be any arbitrary parameter configuration (for instance corresponding to the initialization at the first iteration). Then, one iteration of the EM algorithm consists of the following two steps:

> $(E) \quad \text{Compute } Q(\theta) \stackrel{	ext{def}}{=} \ln p(X, y \mid \theta \mid X, \tilde{	heta})$\$
$(M) \quad \text{Update } \tilde{	heta} \leftarrow \arg \max Q(\theta)$.$

The algorithm alternates between two steps until convergence. It can be shown that the observed data log-likelihood increases at each iteration of the procedure, unless it has reached a stationary point (where the gradient of the log-likelihood is zero). Hence, it is a monotonic optimization algorithm for solving for (10.12).

To see that this procedure boils down to Method 10.3 for the GMM model, we start by expanding the E-step. The expected likelihood is computed with respect to the conditional distribution $p(y \mid X, 	heta)$. This represents the probabilistic belief regarding the cluster assignment for all data points, given the current parameter configuration $	ilde{	heta}$. In a Bayesian framework, it is the posterior distribution over the latent variables $y$, conditioned on the observed data $X$. We thus have

> $Q(\theta) = \mathbb{E}_{y}[\ln p(X, y \mid \theta \mid X, \tilde{	heta})] = \sum_{\gamma} \ln (N(X \mid \mu_{\gamma}, \Sigma_{\gamma})) + p(y \mid X, \tilde{	heta})). \quad (10.13)

The first expression in the sum is referred to as the *complete data log-likelihood*. It is the log-likelihood that we would have, if the latent variables were here observed. Since it involves both the observed data and the latent variables (which is, "complete data"), it is readily available from:

> $\ln p(X, y \mid \theta) = \sum_{i=1}^n \ln p(x_i, y_i \mid \theta) = \sum_{i=1}^n \ln (N(x_i \mid \mu_{\gamma_i}, \Sigma_{\gamma_i}) + \ln \pi_{y_i}). \quad (10.14)
