**Figure 6.6:** A computational graph of the backpropagation algorithm. We start with the input in the upper left and propagate forward and evaluate the cost. Along the way we cache the values for the hidden units $q^{(l)}$ and $z$. We propagate the gradients $dq^{(l)}$ and $dz^{(l)}$ backwards and compute the gradients for the parameters $W^{(l)}, b^{(l)}$. The equations behind this computational graph are given in (6.24), (6.26) and (6.27).

$dz^{(L)}$, the gradient of the cost function with respect to the hidden units in the last layer. This obviously depends on our choice of loss function (6.24). If we have a regression problem and the squared error, we get

```
$dz^{(L)} = \frac{\partial J}{\partial z^{(L)}} = (y-z^{(L)}) \cdot -2=-2(y-z^{(L)})$
```

For a multiclass classification, we use the cross-entropy loss (6.20), and we get

```
$dz^{(L)} = \frac{\partial J}{\partial z^{(L)}} = \frac{\partial J}{\partial a^{(L)}} \cdot (a^{(L)}+\ln\sum_{k=1}^{M} e^{z^{(k)}})=-y^{(j)}-\sum_{k=1}^{M} e^{z^{(k)}}$
```

The backpropagation now proceeds with the following recommendations

```
$dz^{(l)} = dq^{(l)} \cdot h'(z^{(l)})$
```

```
$dq^{(l)} = W^{(l+1)T} dz^{(l+1)}$
```

where $\cdot$ denotes the element-wise product and $h'(z)$ is the derivative of the activation function $h(z)$. Similar to the notation in (6.24), $h'(z)$ acts element-wise on the vector $z$. Note that the first line in (6.27a) is not correct for layer $L$ that layer does not have an activation function, see (6.24c). With $dz^{(l)}$, we can compute the gradients of $W^{(l)}$ and $b^{(l)}$

```
$W^{(l)} = dq^{(l)} q^{(l-1)T}$
```

```
$b^{(l)} = dz^{(l)}$
```

All equations for the backward pass (6.27) can be derived from the chain rule of calculus, for further details see Appendix 6.a. A computational graph of the backpropagation algorithm is summarized in Figure 6.6.
