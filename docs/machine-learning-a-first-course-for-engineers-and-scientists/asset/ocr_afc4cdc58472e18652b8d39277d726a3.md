# 8.6 Further reading

It is not necessary to use kernels in support classification. It is perfectly possible to use the linear kernel k(x, x') = xᵀ or any other kernel corresponding to a finite dimension φ(x) in (8.35). That would indeed limit the flexibility of the classifier; the linear kernels limit the classifier to linear decision boundaries, as illustrated in Example 8.5. The possible benefit, however, of not making use of kernels is that it suffices to implement and solve the primal (and not the dual) formulation (8.34), since α is of finite dimension. The support vector property would still be present, but much less since α is not explicitly computed. If using only the primal formulation the representer is not needed, and one could also reduce the L²-regularization with any other regularization method.

# 8.A The representer theorem

We give a lightly simplified version of the representer theorem by Schölkopf, Herbruch, et al. (2001) adapted to our notation and methodology, without reducing the kernel Hilbert space measure. It is stated in a regression-like setting, when y(x) = θᵀφ(x), and we discuss how it also applies to classification.

**Theorem 8.1 (The representer theorem)** *y(x) = θᵀφ(x) with nonlinear feature transformations φ(x) and θ to be learned from training data (xᵢ, yᵢ)ⁱ=¹ⁿ (The dimensionality of θ and φ does not have to be finite). Furthermore, let L(y, y') be any arbitrary function and h : [0, ∞] → R a strictly increasing function. Then minimize each over the regularized cost*

```
\sum_{i=1}^{n} L(y_i, θᵀφ(x_i)) + h(||φ(x_i)||^2) \quad (8.36)
```

can be written as θ = Φ(X)ᵀα (or equivalently, y(x) = K(x, X)α) with n-dimensional vector α.

**Proof.** For a given X, α can be decomposed into one part Φ(X)ᵀα that lies in the span of Φ(X) and one part v orthogonal to it, that is, θ = Φ(X)ᵀα + v with v being orthogonal to all rows φ(xᵢ).

For xᵢ, in (xᵢ, yᵢ)ⁱ=¹ⁿ it holds that

```
\tilde{y}(x_i) = θᵀφ(x_i) = (Φ(X)ᵀα + v)ᵀφ(x_i) = αᵀΦ(X)φ(x_i) + vᵀφ(x_i) = 0 \quad (8.37)
```

The first term in (8.36) is independent of v. Concerning the second term in (8.36) we have

```
h(||φ(x_i)||^2) = h(||Φ(X)ᵀα + v||^2) = h(||Φ(X)ᵀα||^2 + ||v||^2) ≥ h(||Φ(X)ᵀα||^2). \quad (8.38)
```

where the second inequality follows because h is increasing with respect to v. The equation (8.38) implies that the minimum of (8.36) is found for v = 0, which follows the theorem.
