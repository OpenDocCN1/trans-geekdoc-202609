# 6.3 Convolutional neural networks

Convolutional neural networks (CNN) are a special kind of neural networks originally tailored for tasks where the input data is a grid-like structure. In this text we focus on images, where its pixels resides on a 2D grid. Images are also the most common type of input data where CNNs are applied. However, CNNs can be used for any input data, also in 1D (e.g. audio wavelet data) and 3D (volumetric data e.g. CT scans or video data). We will focus on grayscale images, but the approach can easily extended to color images as needed.

# Data representation of an image

Digital images consist of pixels ordered in a matrix. Each pixel can be represented as a range from 0 (total absence, black) to 1 (total presence, white) and values between 0 and 1 represent different shades of gray. In Figure 6.9 this is illustrated for an image with 6 × 6 pixels. In an image classification problem, an image is the input x and the pixels in the image are the input variables $x_{1,1}, x_{1,2}, \dots, x_{6,6}$. The two indices $j$ and $k$ determine the position of the pixel in the image, as illustrated in Figure 6.9.

If we put all inputs representing the pixels in a layer as we did in Example 6.1 and Example 6.2, by doing that, a lot of the structure in the hidden layer will be lost. For example, when we know that two pixels close to other typically have more in common than two pixels apart. This information would be destroyed by such a vectorization. In contrast, CNN preserve this information by representing the input variables as well the hidden layers as matrices. The core component in a CNN is the convolutional layer, which will be explained next.

# The convolutional layer

Following the input layer, we use a hidden layer with as many units as there are input variables. For the image with 6 × 6 pixels we consequently have 6 × 6 = 36 hidden units. We choose to order the hidden units in a 6 × 6 matrix, the same manner as we did for the input variables, see Figure 6.10a.
The neural layers presented in earlier sections (like the one in Figure 6.3) have dense layers. This means that each input variable is connected to all units in the subsequent layer, and each connection has an associate weight $W_{ij}$ associated to it. These layers have empirically found to provide too much flexibility for images and we might not be able to capture the patterns of real importance, and hence not generalize and perform well on unseen data. Instead, a convolutional layer exploits the structure in images to find a more efficiently parametrized model. In contrast to a dense layer, a convolutional layer leverages two important aspects - sparse connections and parameter sharing - to achieve such a parametrization.
