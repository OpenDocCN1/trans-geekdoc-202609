Unfortunately, in practical cases we can never compute $E_{new}$ to assess how well we are doing. The reason is $p(x, y)$—which we do not know in practice—is part of the definition of $E_{new}$. However, $E_{new}$ is a too important quantity to be abandoned just we cannot compute it. Instead, we will spend some time effort on estimating $E_{new}$ from data, as well as analyzing $E_{new}$ to better understand how we can decrease it.

We emphasize that $E_{new}$ is a property of a trained model and specific machine learning problem. # 4.2 Estimating $E_{new}$

There are multiple reasons why a machine engineer is interested to be in $E_{new}$, such as:

+   - judging if the performance is satisfying (whether $E_{new}$ is small enough), or if more work should be put into the solution and more training data should be collected,
- choosing different methods,
- choosing hyperparameters (as $k$ in k-NN, the regularization parameter in ridge regression, or the number of hidden layers in deep learning) to minimize $E_{new}$,
- reporting the expected performance to the customer.

As discussed above, we cannot unfortunately compute $E_{new}$ in any practical situation. We will then explore various ways of estimating $E_{new}$, which will lead to a very useful concept as cross-validation.

$E_{train} \neq E_{new}$: We cannot estimate $E_{new}$ from training data

We have both introduced the expected data error, $E_{new}$, and the training error $E_{train}$. In contrast to $E_{new}$, we can always compute $E_{train}$.

We assume for now that $T$ consists of samples (data points) from $p(x, y)$. This means that the training data is have been collected under similar circumstances as the ones learned will be used, which is a common assumption.

When an expected value, such as in the definition of $E_{new}$ in (4,2), cannot be computed in closed form, one is option to approximate the expected value by a sample average. Effectively this means that we can approximate the integral (expected value) by a finite sum. The question is if $E_{new}$ can

```
$E_{new} = \int E(Y(x; T), y) p(x, y) dx dy \approx \frac{1}{n} \sum_{i=1}^{n} E(Y(x_i; T), y_i) = E_{train}$.
```

Put differently: Can we perform a method well when faced with new, previously unseen, data, as is it on training data?
The answer is uncertain, **no**.
