To the left is the Gaussian model of $p(x|y=m)$, parameterized by $\hat{\mu}_m$ and $\hat{\sigma}_m$ (since $p=1$, we will only have a scalar variance $\sigma_m^2$, instead of a covariance matrix $\Sigma_m$). To the right of $p(y)$ is is, parameterized by $\hat{\pi}_m$. All parameters are learned from training data, not shown in the figure. By computing the conditional distribution (10.4) the generative model is 'warped' into $p(y=m|x)$, shown in the bottom. The decision boundaries are shown as vertical dotted lines in the plot (assuming that we classify $x$ based on the most probable class).

consider learning a model for classifying images of skin lesions to be either benign or malignant, to be used in a medical support system. The training inputs $x$, will correspond to the images of skin and it is easy to acquire a large number of such images. To annotate the training data with labels $y_l$, we need to determine whether or not these lesions are malignant which requires a (possibly expensive) medical examination by a dermatologist.

The simplest solution to the semi-supervised problem is to discard the $n_u$ unlabeled data, this is a pragmatic, but possibly very useful if the number of labeled points $n_l$ is only a small fraction of the total number of data points $n$. We illustrate this with Figure 10.5, which depicts a semi-supervised problem where we learned a poor GMM by only using the few $n_l$ labeled data points.

The idea behind semi-supervised learning is to exploit the information available in the unlabeled data points, hopefully end up with a better model in the end. There are many ways in which this can be approached, but one principle is to make use of a generative model. Remember that a generative model is a model of the joint distribution $p(x, y)$, which can be factorized as $p(x, y) = p(y)p(y|x)$. Since the marginal distribution of the inputs $p(x)$ is a part of the model, it seems plausible that the unlabeled points $\{x_j\}_{j=1}^{n_u}$ can be useful when learning the model.
