### Example 3.1: Car stopping distances

We continue Example 2.2 and learn a linear regression model for the car stopping data. We start by forming the matrices **X** and **y**. Since we have only one input and one output, both $x_i$ and $y_i$ are scalar.

```
$$\mathbf{X} = \begin{bmatrix} 4.0 \\ 4.9 \\ 5.0 \\ 5.1 \\ \vdots \\ 39.6 \\ 39.7 \end{bmatrix}, \quad \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \\ \vdots \end{bmatrix}, \quad \mathbf{y} = \begin{bmatrix} 4.0 \\ 8.0 \\ 8.0 \\ 4.0 \\ 2.0 \\ \vdots \\ 134.0 \\ 110.0 \end{bmatrix}$$ \quad (3.6)
```

Altogether we can use this vector and matrix notation to describe the linear regression model for all training data points $x_i, i=1,\dots,n$, in one equation as a matrix multiplication

```
$$\mathbf{y} = \mathbf{X}\theta + \mathbf{\epsilon}. \quad (3.7)
```

where $\epsilon$ is a vector of errors/noise terms. We can also define a vector of predicted outputs for the training data $\tilde{\mathbf{y}} = [\tilde{y}(x_1), \tilde{y}(x_2), \dots, \tilde{y}(x_n)]^T$ which also allows a compact matrix formulation

```
$$\tilde{\mathbf{y}} = \mathbf{X}\theta. \quad (3.8)
```

Note that $\mathbf{y}$ is a vector of recorded training data values, $\tilde{\mathbf{y}}$ is a vector whose entries are functions of $\theta$. Learning the unknown parameters $\theta$ amounts to finding values such that $\tilde{\mathbf{y}}$ is similar to $\mathbf{y}$. That is, the predictions by the model should fit the training data well. There are multiple ways to define what 'similar' or 'well' actually means, but it amounts to finding $\theta$ such that $\mathbf{y} - \tilde{\mathbf{y}}$ is small. We will approach this by formulating a loss function, which gives a mathematical meaning to 'fitting the data'. We will thereafter interpret the loss function from a statistical perspective, understanding by selecting the value of $\theta$ that makes the observed data $\mathbf{y}$ as likely as possible with respect to the model—the so-called maximum likelihood solution. In Chapter 9, we will also introduce a conceptually different way to learn $\theta$.

**Figure 3.2:** A graphical explanation of the squared error loss function: the goal is to choose the model (blue line) such that the sum of the squares (light red) of each error $\epsilon$ is minimized. That is, the blue line is be chosen so that the amount of red color is minimized. This motivates the name least squares. The black dots, the training data, are fixed.

### Loss functions and cost functions

A principled way to define the learning problem is to introduce a loss function $L(\hat{y}, y)$ which measures how close the model's prediction $\hat{y}$ is to the observed data $y$. If the model fits the data well, so that $\hat{y} \equiv y$, then the loss function should take a small value, and vice versa. Based on the chosen loss function we also define the *cost function* as the average loss over the training data. Learning a model amounts to finding the parameter values that minimize the cost

```
$$\hat{\theta} = \arg \min_{i=1}^{n} L(\hat{y}(x_i; \theta), y_i). \quad (3.9)
```

Note that each term in the expression above corresponds to evaluating the loss function for the prediction $\hat{y}(x_i; \theta)$, given by (3.4), for the training point index $i$ and the true output value $y$ at that point. To emphasize that the prediction depends on the parameters $\theta$, we have included $\hat{y}$ as an argument for $y$ to ensure clarity. The $\arg \min$ means the *value of $\theta$ for which the cost function attains the minimum*. The relationship between loss and cost functions (3.9) is general for all cost functions in this book.

### Least squares and the normal equations

For regression, a commonly used loss function is the *squared error* loss

```
$L(\hat{y}(x; \theta), y) = (\hat{y}(x) - y)^2. \quad (3.10)$
```

This loss function is 0 if $\hat{y}(x) = y$, and grows fast (quadratically) as the difference between $y$ and $\hat{y}(x) = \theta^T x$. The corresponding cost function for the linear regression model (3.7) can be written with matrix notation

```
$J(\theta) = \frac{1}{n} \sum_{i=1}^{n}(\hat{y}(x_i; \theta) - y_i)^2 = \frac{1}{n} ||\hat{y} - y||_2^2 = \frac{1}{n} ||X\theta - y||_2^2. \quad (3.11)$
```

Note that $||\cdot||_2$ denotes the Euclidean vector norm, and $||\cdot||_2^2$ is its square. Due to the square, this particular cost function is commonly referred to as least squares. It is illustrated in Figure 3.2.

### 3.1 Linear regression

When using the squared error loss for a linear regression model over $\mathcal{T}$, we need to solve

```
$$\hat{\theta} = \arg \min_{\theta} \frac{1}{n} \sum_{i=1}^{n}(\hat{y}(x_i; \theta) - y_i)^2.
```

From a linear algebra point of view, this can be seen as finding the projection of $\mathbf{y}$ onto the subspace spanned by the columns of $\mathbf{X}$. The normal equations (3.13) often lead to 

```
$$\tilde{\mathbf{y}} = \mathbf{X}\theta. \quad (3.8)
```

The fact that this has a closed-form solution exists if $\mathbf{X}^T\mathbf{X}$ is invertible. If it is not, we use numerical methods.

### The maximum likelihood perspective

To get another perspective of the squared error loss we will reinterpret the least squares method as a maximum likelihood solution. The ‘likelihood’ refers to the statistical concept of likelihood function, and maximizing the likelihood function amounts to finding the value of $\theta$ that makes observing $y$ as likely as possible. That is, instead of arbitrarily selecting a loss function, what we need is the problem

```
$$\hat{\theta} = \arg \max p(y|\mathbf{X};\theta). \quad (3.15)
```

Here $p(y|\mathbf{X};\theta)$ is the probability density of all outputs $y$ in the training data, given all inputs $\mathbf{X}$ and parameters $\theta$. This determines what ‘likely’ means, which we need to specify in more detail. A common assumption is that the noise term $\epsilon$ is a stochastic variable with a certain distribution. A Gaussian distribution (also known as a normal distribution) with mean zero and variance $\sigma_{\epsilon}^2$.

```
$$\epsilon \sim N(0,\sigma_{\epsilon}^2). \quad (3.16)
```

This implies that the $n$ observed data points are independent, and $p(y|\mathbf{X})$ factors as

$p(y|\mathbf{X};\theta) = \prod_{i=1}^n p(y_i|x_i;\theta). \quad (3.17)$

Considering the linear regression model from (3.3), $y = \theta^T\mathbf{x} + \epsilon$, with the Gaussian noise assumption (3.16) we have

$p(y_i|x_i;\theta) = N(y_i;\theta^Tx_i,\sigma_{\epsilon}^2). \quad (3.18)$

Recall that we want to maximize the likelihood with respect to $\theta$. For numerical methods, it is usually better to work with the logarithm of $p(y|\mathbf{X};\theta)$.

$ln p(y|\mathbf{X};\theta) = \sum_{i=1}^n \ln p(y_i|x_i;\theta). \quad (3.19)$
