# Example 8.1: Nonlinear transformations for classification

Consider the data for a binary classification problem in the left panel of Figure 8.2 with x = [x₁, x₂] with a blue and a red class. By only looking at the data, we can conclude that a linear classifier would not be able to perform well on this problem.

![](bbox=[0.138, 0.545, 0.86, 0.712])

By adding the nonlinear transformation x₁x₂ as a feature, such as ϕ(x) = [x₁, x₂, x₁x₂] we get the situation in the right panel of Figure 8.2. With this relatively simple introduction of an extra feature, the problem now appears to be much better suited for a linear classifier, since the data can be separated relatively well by the sketched plane. The conclusion here is that for increasing the capacity of otherwise simple methods is to introduce nonlinear feature transformations.

Polynomials are only one of (infinitely) many possible choices of features ϕ(x). One should take care when using polynomials higher than second order, because of their behavior outside the range where the data is often more useful (recall Figure 8.1b).
