# # The Bayesian approach and Gaussian processes

So far, learning a parametric model has amounted to finding a parameter value $\hat{	heta}$ that best fits the training data. With the Bayesian approach (also called the probabilistic approach) learning amounts to instead finding the distribution of parameter values $	heta$ conditioned on the observed training data $\mathcal{T}$, is $p(	heta|\mathcal{T})$. With the Bayesian approach also the prediction is a distribution $p(y_*|x_*)$, instead of a single value. Before we enter the details, let us say that on a theoretical (or even philosophical) level the Bayesian approach is rather different from what we have previously seen in this book. It opens up for a family of new, versatile and practically useful methods, and the extra effort required to understand this somewhat different approach pays off and provides another perspective on supervised machine learning. As the Bayesian approach makes repeated use of probability distribution, it is also natural that this chapter will be heavier on the probability theory side compared to the rest of the book.

We will start this chapter by first giving a general introduction to the Bayesian idea. We thereafter go back to basics and apply the Bayesian approach to linear regression, which we will further extend to the non-parametric Gaussian process model.

# ## 9.1 The Bayesian idea

In the Bayesian approach $\theta$ of any model are consistently treated as being random variables. As consequence, in this chapter we will use the term model with a very specific meaning. A model, in this chapter, refers to the joint distribution over all outputs $y$ and parameters $	heta$ given all inputs $X$, that is $p(y,\theta|X)$. To the notation we will consistently omit $X$ in the conditioning we motivate this by the fact that we can only observe $y$, and not $X$, and simply write $p(y,\theta)$.

Learning in the Bayesian settings amounts to computing the distribution of $\theta$ conditional on training data $\mathcal{T}=\{x_i, y_i\}_{i=1}^n = \{X, y\}$. Since we observe $X$, we denote this as $p(	heta|y)$. The computation of $p(	heta|y)$ is done by laws of probabilities. First, we use the rule of conditioning to factorize the joint distribution into the two factors $p(y,\theta) = p(y|\theta)p(\theta)$. Using the rule of conditioning once more, conditioning on $y$ uses Bayes' theorem,

```
$p(\theta|y) = \frac{p(y|\theta)p(\theta)}{p(y)}, \quad (9.1)$
```

which is why this is called the Bayesian approach. The left hand of (9.1) is the sought distribution $p(\theta|y)$. The right side of (9.1) contains several elements: $p(y|\theta)$ is the distribution of the observations in various models, and $p(\theta)$ is the distribution of $	heta$ before any observations are made (that is, not on training data). By nature $p(y)$ cannot be computed, but by laws of probability, it can be rewritten as

```
$p(y) = \int p(y|\theta)p(\theta)d\theta, \quad (9.2)$
```

which is an integral, that at least, can be computed. In other words, learning a parametric model (in the Bayesian framework) amounts to conditioning $\theta$ on $y$, that is, $p(\theta|y)$. After being learned, a model can be used to compute predictions. This is a matter of computing a distribution $p(y_*|x_*)$ (rather than a point prediction) for a test input $x_*$, since $\theta$ is a random variable connected to $p(\theta|y)$ via the marginalization

```
$p(y_*|x_*) = \int p(y_*|\theta)p(\theta|y)d\theta. \quad (9.3)$
```
