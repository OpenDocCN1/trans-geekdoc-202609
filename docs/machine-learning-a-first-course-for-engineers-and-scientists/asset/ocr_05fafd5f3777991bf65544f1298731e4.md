# Algorithm 5.2: Trust-region Newton's method

```
**Input:** Objective function $J(\theta)$, initial $	heta^{(0)}$, trust region radius $D$
**Result:** $	heta$
**1** $t \leftarrow 0$
**2** while $|\theta^{(t)} - \theta^{(t-1)}|$ not small enough do
**3** Compute $v \leftarrow -[\nabla^2 J(\theta^{(t)})]^{-1} [\nabla J(\theta^{(t)})]$
**4** Compute $\eta \leftarrow \text{max}(\|v\|, D)$
**5** Update $\theta^{(t+1)} \leftarrow \theta^{(t)} + \eta v$
**6** Update $t \leftarrow t + 1$
**8** return $\theta^{(t-1)}$
```

different ways to approximate the inverse of the Hessian matrix $[\nabla^2 J(\theta)]^{-1}$ in (5.35). This class includes, among other, the Broyden method and the BFGS method (an abbreviation of Broyden, Fletcher, Goldfar and Shanno). A further approximation of the latter, called limited-memory BFGS or L-BFGS, has proven to be another good choice for the logistic regression problem.

We first apply Newton's method to the cost functions from Example 5.3 and show the result in Figure 5.10. Since the convex cost (left) function also happens to be close to a quadratic function, the Newton's method works well, for both initializations, in only two iterations. We also apply the trust-region Newton's method to both problems and show the result in Figure 5.11. Note that the first step direction is identical to the non-truncated version above, but the steps are limited to stay within the trust region (a circle of radius 2). This prevents the severe divergence for the non-convex case, and all cases converge nicely. Indeed, the convex cost (left) requires more iterations than for the non-truncated version, but that is a price we have to pay in order to have a robust method which also works for the non-convex case to the right.
