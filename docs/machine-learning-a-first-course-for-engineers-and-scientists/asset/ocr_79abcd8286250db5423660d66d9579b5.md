# Example 3.1: Car stopping distances

We continue Example 2.2 and learn a linear regression model for the car stopping data. We start by forming the matrices **X** and **y**. Since we have only one input and one output, both $x_i$ and $y_i$ are scalar.

```
$$\mathbf{X} = \begin{bmatrix} 4.0 \ 4.9 \ 5.0 \ 5.1 \ \vdots \ 39.6 \ 39.7 \end{bmatrix}, \quad \theta = \begin{bmatrix} \theta_0 \ \theta_1 \ \vdots \end{bmatrix}, \quad \mathbf{y} = \begin{bmatrix} 4.0 \ 8.0 \ 8.0 \ 4.0 \ 2.0 \ \vdots \ 134.0 \ 110.0 \end{bmatrix}$$ \quad (3.6)$
```

Altogether we can use this vector and matrix notation to describe the linear regression model for all training data points $x_i, i=1,\dots,n$, in one equation as a matrix multiplication

```
$$\mathbf{y} = \mathbf{X}\theta + \mathbf{\epsilon}.$$ \quad (3.7)$
```

where $\epsilon$ is a vector of errors/noise terms. Weover can also define a vector of predicted outputs for the training data $\tilde{\mathbf{y}} = [\tilde{y}(x_1),,\tilde{y}(x_2)\dots\tilde{y}(x_n)]^T$ which also allows a compact matrix formulation

```
$$\tilde{\mathbf{y}} = \mathbf{X}\theta.$$$ \quad (3.8)$
```

Note that $\mathbf{y}$ is a vector of recorded training data values, $\tilde{\mathbf{y}}$ is a vector whose entries are functions of $\theta$. Learning the unknown parameters $\theta$ amounts to finding values such that $\tilde{\mathbf{y}}$ is similar to. That is, the predictions by the model should fit the training data well. There are multiple ways to define what 'similar' or 'well' actually means, but it amounts to finding $\theta$ such that $\mathbf{y}-	ilde{\mathbf{y}}$ is small. We will approach this by formulating a loss function, which gives a mathematical meaning to 'fitting the data'. We will thereafter interpret the loss function from a statistical perspective, understanding by selecting the value of $\theta$ that makes the observed data $\mathbf{y}$ as likely as possible with respect to the model—the so-called maximum likelihood solution. In Chapter 9, we will also introduce a conceptually different way to learn $\theta$.
