# 8.2 Kernel ridge regression

A carefully engineered transformation $\Phi(x)$ in linear regression, or any other method for that, may indeed perform well for a specific machine learning problem. However, we would like $\Phi(x)$ to contain a lot of transformations that could be of interest for most problems, in order to obtain a general off-the-shelf method. We will therefore explore the idea of choosing $d$ really big, much bigger than the number of data points $n$, and eventually let $d 	o \infty$. The derivation will be done using $L^2$-regularization, but we will see later that the idea is also applicable to other models.

# Re-forming linear regression

First of all we have to use some kind of regression if we are going to increase $d$ in linear regression, in order to avoid overfitting when $d > n$. For reasons we will discuss later how to use $L^2$-regularization. The equation for $L^2$-regularized regression is

```
$$\hat{\mathbf{	heta}} = \arg \min_{\mathbf{	heta}} \frac{1}{2} \sum_{n=1}^{n} (\mathbf{	heta}^T \Phi(\mathbf{x}_n) - y_n)^2 + \lambda ||\mathbf{	heta}||^2 = (\Phi(\mathbf{x})^T \Phi(\mathbf{x}) + n\lambda I)^{-1} \Phi(\mathbf{x})^T \mathbf{y},$
```

We have not fixed the nonlinear transformations $\Phi(x)$ to anything specific, but we are preparing for choosing $d > n$ of these transformations. The downside of choosing $d$, the dimension of $\Phi(x)$, is large that we also have to learn parameters when training. In linear regression, we will firstly learn and store the $d$-dimensional vector $\mathbf{	heta}$, and thereafter we use it for computing a prediction

```
$$\hat{\mathbf{y}}(\mathbf{x}_*) = \mathbf{	heta}^T \Phi(\mathbf{x}_*)$.$
```

To be able to choose $d$ really large, eventually even $d \to \infty$, we have to reformulate the model without that there are no computations or storage that deals with $d$. The first step is to realize that the prediction $\hat{\mathbf{y}}$ can be written as

```
$$\hat{\mathbf{y}}(\mathbf{x}_*) = (\Phi(\mathbf{x})^T \Phi(\mathbf{x}) + n\lambda I)^{-1} \Phi(\mathbf{x})^T \mathbf{y})^T \Phi(\mathbf{x}_*)$$
$\underbrace{\hat{\mathbf{y}}(\mathbf{x}_*)}_{1\times1} = \underbrace{\mathbf{	heta}}_{d\times1}\underbrace{(\Phi(\mathbf{x})^T \Phi(\mathbf{x}) + n\lambda I)^{-1}}_{d\times d}\underbrace{\Phi(\mathbf{x}_*)}_{1\times d}$
```

With the underbraces provides the sizes of the corresponding vectors and matrices. This expression for $\hat{\mathbf{y}}(\mathbf{x}_*)$ means we could, for each test input $\mathbf{x}_*$, compute the $n$-dimension vector $\Phi(\mathbf{x})^T \Phi(\mathbf{x}) + n\lambda I)^{-1}\mathbf{	heta}$. By doing so, we avoid storing a $d$-dimensional vector. But this would require the inversion of a $d \times d$ matrix. We therefore have more work to do before we have a useful method where we can select $d$ arbitrarily large.
