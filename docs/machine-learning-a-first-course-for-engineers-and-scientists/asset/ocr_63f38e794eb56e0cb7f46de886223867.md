In many applications the number of inputs p is large, or put differently, the input x is a high-dimensional vector. # Numerical and categorical variables

The variables contained in our data (input as well as output) can be of two types, numerical or categorical. A numerical variable has a natural ordering. We can say that one instance of a numerical variable is larger or smaller than another instance of the same variable. A numerical variable could be represented by a continuous real number, but it also be discrete, such as an integer. Categorical variables, on the other hand, are discrete and they lack a natural ordering. In this book we assume that any categorical variable can take only a finite number of different values. A few examples are given in Table 2.1.

Table 2.1: Examples of numerical and categorical variables.
| Variable type | Example | Handled as |
|---|---|--|
| Number (continuous) | 32.23 km/h, 12.50 km/h, 42.85 km/h | Numerical |
| Number (discrete) with natural ordering | 0 children, 1 child | Numerical |
| Number (discrete) without natural ordering | 1 = Sweden, 2 = Denmark, 3 = Norway | Categorical |
| Text string | Hello, Welcome | Categorical

The distinction between numerical and categorical is somewhat arbitrary. We for instance argue that having no children is qualitatively different from having children, and use the categorical variable "children": yes/no, instead of "0, 1 or 2". It is therefore a decision for the machine learner whether a certain variable is to be considered numerical or categorical The notion of categorical applies to both the output variable y and to the p elements $x_j$ of the input vector $x = [x_1 x_2 \dots x_p]^T$. All p input variables do not have to be of the same type. It is perfectly fine (and common in practice) to have a mix of numerical and categorical inputs.

# Classification and regression

We distinguish between supervised machine learning problems by the type of the output.

> Regression means that the output is numerical, and classification means that the output is categorical.

The reason for this distinction is that regression and classification problems have somewhat different properties, and different methods are used for solving them.
Note that the p input variables $x = [x_1 x_2 \dots x_p]^T$ can be either numerical or categorical for both regression and classification problems. It is only the type of output that determines whether a problem is a regression or a classification problem. A method for solving such classification is called a classifier.
