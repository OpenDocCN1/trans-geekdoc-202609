**Figure 4.2:** Illustration of k-fold cross-validation. The data is split in k batches of similar sizes. When looping over $\ell = 1, 2, ..., k$, batch $\ell$ is held out as validation data, and the model is trained on $k-1$ data batches. Each time, the trained model is used to compute the average error $E^{(\ell)}$ for the validation data. The final model is trained using all available data, and the estimate $E_{new}$ for model $E_{k-fold}$ is the average of all $E^{(\ell)}$.

**Be aware:** For the same reason as the hold-out validation data approach, it is important to always split the data randomly for cross-validation to work! A simple solution is to first randomly shuffle the entire dataset, and thereafter split it into batches

We usually talk about training (or learning) as a procedure that is executed once. However, in $k$-fold cross-validation it is repeated (or $k+1$ times). A special case is $k=n$ which is called leave-one-out cross-validation. For methods such as linear regression, the actual training (solving the normal equations) is usually done within milliseconds on modern computers, and doing it extra $n$ times might not be a problem in practice. If the training is computationally demanding (as for deep neural networks, for instance), it becomes a rather cumbersome procedure, and a choice like $k=10$ might be more feasible. If there is much data available, it is also an option to use the computationally less demanding hold-out validation.

# Using a test dataset

A very important use of $E_{k-fold}$ (or $E_{hold-out}$) is to choose between methods and different types of hyperparameters such that $E_{k-fold}$ (or $E_{hold-out}$) becomes as small as possible. Typical hyperparameters to choose in this way are $k$-NN, tree depth or regularization parameters. However, much like we cannot use the training error $E_{train}$ to estimate the new data error $E_{new}$, selecting methods and hyperparameters based on $E_{k-fold}$ (or $E_{hold-out}$) will invalidate it. If hyperparameters are selected to minimize $E_{k-fold}$ there is a risk of overfitting to the validation data, If it is important to have a good estimate of $E_{new}$, it is to first set aside another hold-out dataset, which we refer to as a *test* set. This set should be used only once (after selecting methods and hyperparameters) to estimate $E_{new}$ for the final model.
