# 5 Learning parametric models

In this chapter we elaborate on the concept of parametric modeling. We start by generalizing the notion of a parametric model and outline basic principles for learning these models from data. The chapter resolves around three central concepts, namely loss functions, regularization and optimization. We have touched upon all of them already, mostly in connection to the parametric models in Chapter 3, and logistic regression. These topics are central for every supervised machine learning methods, in fact even beyond parametric models, and deserve a more elaborate discussion.

# 5.1 Principles of parametric modeling

In Chapter 3 we introduced two basic parametric models for regression and classification, linear regression and logistic regression. We briefly discussed how generalized linear models could be used to handle different types of data. The concept of parametric modeling is however not restricted to these cases. We start this chapter by introducing a general framework for parametric modeling, and discuss basic principles for learning these models from data.

# Nonlinear parametric functions

Consider the regression model (3.1), repeated here for convenience:

> $y = f_{\theta}(x) + \epsilon.$

We have introduced an explicit dependency on the parameters $\theta$ in notation to emphasize that the equation above should be viewed as *model* of the true input-output relationship. To turn this model into a linear case, that could be trained using least squares with a closed form solution, we made such assumptions in Chapter 3. First, the function $f$ was assumed to be linear in the model parameters, $f_{\theta}(x)=	heta^Tx$. Second, the term $\epsilon$ was assumed to be Gaussian, $\epsilon \sim N(0, \sigma^2)$. The latter assertion is sometimes implicit, but as we saw in Chapter 3 it makes the maximum likelihood formulation equivalent to least squares.

Both of these assumptions can be relaxed. Based on the expression above, the perhaps most obvious generalization is to allow the function $f_0$ to be some arbitrary nonlinear function. Since we still need the function to learn from training data we require it to be adaptable. Similarly to the linear case, this can be accomplished by letting the function depend on some parameters $\theta$ that control the shape of the function. Different values of the model parameters will result in different functions $f_{\theta}(\cdot)$. Learning the model allows finding a suitable value for the parameter vector $\theta$, such that the function accurately accurately describes the true input-output relationship. In mathematical terms, we say that we have a family of functions

> $$f_{\theta}(\cdot) : \theta \in \Theta$$
