
## 4.3 The training error–generalization gap decomposition of $E_{new}$

optimal trade-off, in terms of $E_{new}$, is often obtained when neither the generalization gap nor the training error $E_{train}$ is zero. Thus, by monitoring $E_{train}$ and estimating $E_{new}$ with cross-validation we also get the following advice:

- If $E_{hold-out} \approx E_{train}$ (small generalization gap; possibly underfitting), it might be beneficial to increase the model flexibility by loosening the regularization, increasing the model order (more parameters to learn), etc.
- If $E_{train}$ is close to zero and $E_{hold-out}$ is not (possibly overfitting), it might be beneficial to decrease the model flexibility by tightening the regularization, decreasing the order (fewer parameters to learn), etc.

## Shortcomings of the model complexity scale

When having only one hyperparameter to choose, the situation sketched in Figure 4.3 is often a relevant picture. However, when having multiple hyperparameters (or even competing methods) to choose, it is important to realize that the one-dimensional model complexity scale in Figure 4.3 does not make justice for the space of all possible choices. For a given problem, one method can have a smaller generalization gap than another method without having a larger training error. Some methods are simply better for certain problems. The one-dimensional complexity scale can be particularly misleading for intricate deep learning models, but as we illustrate in Example 4.2 it is not sufficient for the relatively simple problem of jointly choosing the degree of polynomial regression (higher degree means more flexibility) and regularization parameter (more regularization means less flexibility).

## 4 Understanding, evaluating and improving the performance

### Example 4.2: Training and generalization gap for a regression problem

To illustrate how the training error and generalization gap behave, we consider a simulated problem so that we can compute $\hat{E}_{new}$. We let $n=10$ data points generated as $x \sim \mathcal{U}[-5, 10]$, $y=\min(0.1x^2, 3) + \varepsilon$, and $\varepsilon \sim N(0,1)$, considering the following regression methods:

- Linear regression with $L^2$ regularization
- Linear regression with a quadratic polynomial and $L^2$ regularization
- Linear regression with a third order polynomial and $L^2$ regularization
- Regression tree
- Random forest (Chapter 7) with 10 regression trees

For each of these methods, we try different values of the hyperparameters (regularization parameter and tree depth, respectively), compute $\hat{E}_{train}$ and the generalization gap.

For each method that minimizes $\hat{E}_{new}$ is the value which is closest (in the 1-norm sense) to the origin, since $\hat{E}_{new} = \hat{E}_{train}$ + generalization gap. Having decided on a certain model, and having only one hyperparameter to free, corresponds to the situation in Figure 4.3.

However, when we compare the different methods, a more complicated situation is revealed that when illustrated by the one-dimensional model complexity scale, the second (red) to the third order polynomial (green) linear regression: for some values of the regularization parameter, the training error decreases without increasing the generalization gap. This main takeaway is that these relationships are quite intricate, problem-dependent and impossible to describe using the simplified picture in Figure 4.3. ## 4.4 The bias-variance decomposition of $E_{new}$

We will now introduce decomposition of $E_{new}$ into a squared (bias) and a variance term, as well as an unavoidable component of irreducible noise. This decomposition is somewhat abstract than the training-generalization gap, which provides some additional insights into $E_{new}$ and how different models behave.

Let us make a short reminder of the general concepts of bias and variance. Consider an experiment with an unknown constant $z_0$, which we would like to estimate. For our help in estimating $z_0$ we have a random variable $z$. For example, of $z_0$ as the (true position) of an object, and of $z$ as being noisy GPS measurements of point. Since $z$ is a random variable, it has mean $E[z]$ which we denote by $\bar{z}$. We now define

Bias: $\hat{z} - z_0$

Variance: $E[(z - \bar{z})^2] = E[(\hat{z} - \bar{z})^2]$. (4.12b)

The variance describes how much the error varies each time we perform it (the amount of noise in the GPS measurements), the bias describes the systematic error in $z$ that remains no how many times we repeat the experiment (a possible shift or offset in the GPS measurements). If we consider the expected error between $z$ and $z_0$ as a metric of how good the estimator $z$, we can re-write it in terms of variance and the squared bias,

$E[(z - z_0)^2] = E[(z - \bar{z}) + (\bar{z} - z_0)]^2 = E[(z - \bar{z})^2] + 2E[(z - \bar{z})(\bar{z} - z_0)] + (\bar{z} - z_0)^2$, (4.13)
variance bias

In words, the average error between $z$ and $z_0$ is the sum of the squared bias and the variance. A small bias or little variance in the estimator is not enough, but both aspects are important.
