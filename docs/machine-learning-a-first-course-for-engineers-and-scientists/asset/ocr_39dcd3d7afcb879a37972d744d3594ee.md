# 8.3 Support vector regression

We do not give the full derivation here (it is similar to the derivation of support vector classification in Appendix 8.B), but as it turns the dual formulation becomes

```
$$\widehat{y}(\mathbf{x}_*) = \widetilde{\alpha}^T K(\mathbf{X}, \mathbf{x}_*), \quad (8.19a)$$
```

where $\widetilde{\alpha}$ is the solution to the optimization problem

```
$$\widetilde{\alpha} = \arg\min_{\alpha} \frac{1}{2}\alpha^T K(\mathbf{X},\mathbf{X})\alpha - \alpha^T\mathbf{y} + \epsilon|\alpha\|, \quad (8.19b)$$
```

```
$$\text{subject to } |\alpha| \le \frac{1}{2n\lambda}. \quad (8.19c)$$
```

Note that (8.19a) is identical to the corresponding expression for kernel ridge regression (8.14b). This is a consequence of the representer theorem. The only difference to kernel ridge regression is how the dual parameters $oldsymbol{\alpha}$ are learned: by numerically solving the optimization problem (8.19b) instead of using the closed-form solution (8.14a).

The $\epsilon$-insensitive loss function could be used for any regression model but it is particularly interesting in this kernel context that the dual parameter $oldsymbol{\alpha}$ becomes sparse (meaning that only some elements are non-zero). Remember that $oldsymbol{\alpha}$ has one entry per training data point. This implies that the prediction (8.19a) depends only on *some* of the training data points, namely whose corresponding $\alpha_i$ is non-zero, the so-called *support vectors*. In fact it can be shown that the support vectors are the data points for which the loss function is non-zero, that is, $|\widehat{y}(x) - y_i| \ge \epsilon$. That is, a larger $\epsilon$ results in fewer support vectors, and vice versa. This effect can also be understood by interpreting $\epsilon$ as a regularization parameter in a $L^1$ penalty in the dual formulation (8.19b). (The number of support vectors is, however, also affected by $\lambda$, since $\lambda$ influences the shape of $\widehat{y}(\mathbf{x})$.) We illustrate this in Figure 8.3.
