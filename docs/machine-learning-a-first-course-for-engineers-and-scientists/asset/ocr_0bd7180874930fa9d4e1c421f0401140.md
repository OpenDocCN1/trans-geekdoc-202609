# Connection to linear regression

The main feature of the Bayesian approach is that it provides a full distribution $p(\theta|y)$ over the parameters $	heta$, rather than a single point estimate $\hat{	heta}$. There is, also an interesting connection between the Bayesian approach and regression. We will make this concrete by considering the posterior $p(\theta|y)$ from Bayesian regression and the point estimate $\hat{	heta}_2$ from $L^2$-regularized linear regression with squared error. We then extract the *maximum a posteriori* (MAP) point estimate $\hat{	heta}_{MAP}$ from the posterior $p(\theta|y)$. The MAP estimate is the value of $	heta$ for which the posterior reaches its maximum,

```
$$\hat{	heta}_{MAP} = \arg_{\max\theta} p(\theta|y) = \arg_{\max\theta} p(y|\theta)p(\theta) = \arg_{\max\theta} [ln p(y|\theta) + ln p(\theta)]$$ \quad (9.13)
```

where the second equality follows from the fact that $p(\theta|y) \propto p(y|\theta)p(\theta)$ and that $p(y)$ does not depend on $\theta$. Here that $L^2$-regularized linear regression can be understood using the cost function (3.48),

```
$$\hat{	heta}_2 = \arg_{\max\theta} [ln p(y|\theta) + \lambda ||\theta||^2]$$ \quad (9.14)
```

with regularization parameter $\lambda$. When comparing (9.14) to (9.13), we see that if $p(\theta) \propto e^{-|\theta||^2}$, the MAP estimate is indeed the case for some value of $	heta$ in (9.9). This connection between MAP estimates and maximum likelihood estimates holds that regularization is proportional to the log of the prior. If, for example, we chose to use a Laplace prior, the MAP estimate would be identical to $L^1$ regularization. In general there are many regularization methods that can be interpreted as choosing a prior. This connection to regularization explains why the Bayesian approach is prone to overfitting.

It is important to note that the connection between the Bayesian approach and the use of regularization does not imply that the two approaches are equivalent. The main point with the Bayesian approach is still to provide a distribution is constructed for $\theta$, not of just a point estimate $\theta$.
