# k-means clustering

Before leaving this section we will introduce an alternative clustering method as $k$-means. This algorithm is in many ways similar to the GMM for clustering discussed above, but derived from a different approach and lacks the generative interpretation of the GMM. The $k$ in $k$-means refers to the number of clusters, so given our notation we perhaps refers to it as $M$-means. However, the $k$-means is so well established that we keep it as the name of the method, to agree with the mathematical approach we note $M$ number of clusters. The difference between the GMM and $k$-means is that in the former we model cluster assignments probabilistically, whereas in the latter we make "hard" cluster assignments. That is, we can partition the training data $\{\mathbf{x}_i\}_{i=1}^M$ into distinct clusters $R_1, ..., R_M$, where each data point $\mathbf{x}_i$ should be a member of exactly one cluster $R_m$. k-means clustering then amounts to selecting the clusters so that the sum of squared Euclidean distances within each cluster is minimized.

```
$$\arg \min_{R_1, ..., R_M} \sum_{m=1}^M \sum_{\mathbf{x} \in R_m} ||\mathbf{x} - \hat{\mu}_m||^2 \quad (10.17)$
```

where $|R_m|$ is the number of data points in cluster $R_m$. The intention of (10.17) is to select the clusters such that all points within each cluster are as close as possible. It is shown that the problem (10.17) is equivalent to solving the cluster centers such that the distance to the clusters, summed over all data points, is minimized,

```
$$\arg \min_{R_1, ..., R_M} \sum_{m=1}^M \sum_{\mathbf{x} \in R_m} ||\mathbf{x} - \hat{\mu}_m||_2^2 \quad (10.18)$
```

Here $\hat{\mu}_m$ is the cluster center, which is the mean of all the data points $\mathbf{x} \in R_m$. Unfortunately (10.17) and (10.18) are combinatorial problems, meaning that we can not expect to solve them exactly if the number of data points $n$ is large. However, an approximate solutions can be found by:

+   (i) Set the cluster centers $\hat{\mu}_m$ to some initial values,
(ii) Determine which cluster $R_m$ that each $\mathbf{x}_i$ belongs to, is find the cluster center $\hat{\mu}_m$ that is closest to $\mathbf{x}_i$, for $i=1, ..., n$,
(iii) Update the cluster centers $\hat{\mu}_m$ as the average of all $\mathbf{x}$ that belongs to $R_m$.

and then iterate it until (ii) and (iii) converge. This procedure is an instance of Lloyd's algorithm, but it is often called "the k-means algorithm". Comparing this with the EM method in Method 10.3 we see a clear difference. The EM method uses a soft cluster assignment based on the estimated probabilities, whereas $k$-means makes a hard cluster assignment in part (ii). Another difference is that $k$-means measures similarity between data points using Euclidean distance, whereas the EM method uses the GMM model to capture the covariance of the clusters into account.$^6$

Similarly to the EM algorithm, Lloyd's algorithm will converge to a stationary point of the objective (10.18), but it is not guaranteed to find the global optimum. It is common to run it multiple times, with each different initialization in step (i), and pick the result of the run for which the objective (10.17)/(10.18) attains the smallest value.
