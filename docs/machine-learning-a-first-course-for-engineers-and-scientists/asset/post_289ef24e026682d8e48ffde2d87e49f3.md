
## 5.2 Loss functions and likelihood-based models

Negative log-likelihood is strictly proper should not come as surprise that it is tightly linked to the statistical properties of the data. What is less obvious is that there are other loss functions that are also proper, as we will see next. To make the presentation more concrete we will focus on the case of binary classification for the remainder of this section. In binary classification the conditional distribution $p(y|x)$ takes a practically simple form, since it is completely characterized by a single number, namely the probability of the positive class, $p(y=1|x)$.

Returning to margin-based loss functions discussed above, recall that any loss function can be used to train a classifier, which can then be used for making predictions. However, when choosing a loss function for classification it is therefore to consider its minimizer. In turn, this will reveal whether or not the loss function is strictly proper. We proceed by stating the minimizer for some of the loss functions presented above. Developing the minimizer is often a straightforward calculation, but for brevity we do not include the derivations. Starting with binary cross-entropy (5.1), its asymptotic minimizer can be shown to be $g^*(x)=p(y=1|x)$. In other words, when $n\to\infty$ the loss (5.1) is minimized when $g(x)$ is equal to the true conditional probability. This is in agreement with the discussion above, since binary cross-entropy is just another name for negative log-likelihood.

Turning to hinge loss (5.2) the asymptotic minimizer is

$$f^*(x)=\begin{cases}1 & \text{if } p(y|x) > 0.5.\\-1 & \text{if } p(y|x) < 0.5.\end{cases}$$

This is a non-invertible transformation of $p(y|x)$, which means it is not possible to recover $p(y|x)$ from the minimizer $f^*(x)$. This implies that a classifier learned using hinge loss (such as support vector machines, Section 8.5) is not predict class probabilities. The squared loss (5.3), on the other hand, is a strictly proper loss function, since its asymptotic minimizer is $f^*(x)=p(y=1|x)$. This also holds for Huberized square loss (5.4). Recalling our discussion, that by squaring the loss we make it proper, but at the same time we impact robustness. However, the “Huberization” (replacing the quadratic with a linear for margins) improves the robustness while keeping the property of strictly proper.

We have seen some (but not all) the loss functions are proper, meaning they could potentially predict class probabilities. However, this is only under the assumption that the model is sufficiently flexible that $g(x)$ or $f(x)$ can actually take the shape of the minimizer. This is possibly problematic; for recall that $f(x)$ is a linear function in logistic regression, whereas $p(y=1|x)$ can be almost arbitrarily complicated in real world applications.

## 5 Learning parametric models

It is therefore not sufficient to use a proper loss function in order to accurately predict class probabilities, but our model also has to be flexible enough. This discussion is only valid in the limit $n \to \infty$. However, in practice $n$ is finite, and we may ask how large $n$ has to be for a flexible enough model to at least approximately learn the minimizer. Unfortunately, we cannot give any numbers, but following the same principles as the overfitting discussion in Chapter 4, the more flexible the model the larger $n$ is required. If it is not large enough, the predicted conditional probabilities tend to "overfit" to the training data. In summary, using a proper loss function will encourage the training procedure to learn a model that is faithful to the true statistical properties of the data, but in itself it is not enough to guarantee that these properties are well described by the model.

In many practical application, having access to reliable uncertainty estimates regarding a model's predictions, not only in terms of accuracy or expected errors, but also in terms of its statistical properties. In such cases it is thus important to validate the model, not only in terms of accuracy or expected errors. One approach is to evaluate the so-called *calibration* of the model, which however is beyond the scope of this book.

## 5.3 Regularization

We will now take a closer look at regularization, which was briefly introduced in Section 3.3 as a useful tool for avoiding overfitting if the model was too flexible, such as a polynomial of high degree. We have also discussed thoroughly in Chapter 4 the need for tuning the model flexibility, which effectively is the purpose of regularization. Finding the right level of flexibility, and avoiding overfitting, is very important in practice.

The idea of regularization in a parametric model is to ‘keep the parameters $\theta$ small unless the data convinces us otherwise’, or alternative ‘if a model with small values of the parameters $\theta$ fits the data well, then larger values should be preferred’. There are, however, many ways to implement this and we distinguish between explicit and implicit regularization. We will first discuss explicit regularization, which amounts to modifying the cost function, and so-called $L^2$ and $L^1$ regularization.

### $L^2$ regularization

The $L^2$ regularization (also known as Tikhonov regularization, ridge regression and weight decay) decays by adding an extra penalty term $\lambda ||\theta||^2$ to the cost function. Linear regression with squared error loss and $L^2$ regularization, as an example, amounts to solve

$$\hat{	theta} = \arg\min_{\theta} ||\mathbf{X}\theta - y||^2 + \lambda ||\theta||^2.$$

By choosing the regularization parameter $\lambda > 0$, a trade-off between the cost function (fitting the data well) and the regularization term (keeping the parameters $\theta$ close to zero) is made. In the setting $\lambda = 0$ we recover the least squares problems (3.12), whereas $\lambda \to \infty$ will force all parameters $\theta$ to 0. A good choice of $\lambda$ is usually somewhere between, depending on the actual problem, and can be selected using cross-validation.

It is actually possible to derive a version of the normal equations for (5.23),

$$\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1}\hat{\theta} = \mathbf{X}^T\mathbf{y}.$$

where $I_{p+1}$ is the identity matrix of size $(p+1) \times (p+1)$. For $\lambda > 0$, the matrix $\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1}$ is always invertible, and we have the closed solution

$$\hat{\theta} = (\mathbf{X}^T\mathbf{X} + n\lambda I_{p+1})^{-1}\mathbf{X}^T\mathbf{y}.$$

This also reveals another reason for using regularization in linear regression, if $\mathbf{X}^T\mathbf{X}$ is not invertible, then the ordinary equations (3.13) have no unique solution $\hat{\theta}$, whereas the $L^2$-regularized version always has the unique solution (5.25) if $\lambda > 0$.

### $L^1$ regularization

With $L^1$ regularization (also known LASSO, for Absolute Shrinkage and Selection Operator), the penalty term $|\theta||$ is added to the cost function. Here $|\theta|| = |\theta_0| + |\theta_1| + \dots + |\theta_p|$. The $L^1$ regularized cost function for linear regression (with squared error loss) becomes

$$\hat{\theta} = \arg\min_{\theta} ||\mathbf{X}\theta - y||^2 + \lambda ||\theta||.$$

Contrary to linear regression with $L^2$ regularization (3.48), there is no closed-form solution available for (5.26), where we will see in Section 5.4, it is possible to design an efficient numerical algorithm for solving (5.26).
