# The Gaussian mixture model

The Gaussian mixture model makes use of the factorization

```
p(x,y) = p(x|y)p(y), \quad (10.1a)
```

of the joint probability density function. The second factor is the marginal distribution of $y$. Since $y$ is categorical, and takes values in the set $\{1, \dots, M\}$, this is given by a categorical distribution with $M$ parameters $\{\pi_m\}_{m=1}^M$ as

```
p(y=1) = \pi_1$,
```

:

```
p(y=M) = \pi_M. (10.1b)
```

The first factor in (10.1a) is the class-conditional distribution of the input $x$ for a certain class $y$. In a classification setting it is natural to assume that these distributions are different for different classes $y$. Indeed, if it is possible to predict the class $y$ based on the information in $x$, then the characteristics (that is, the distribution) should depend on $y$. However, to complete the model we need to make additional assumptions on these class-conditional distributions. The basic assumption for a GMM is that $p(x|y)$ is a Gaussian distribution

```
p(x|y) = N(x|\mu_y, \Sigma_y). \quad (10.1c)
```

with class-dependent mean $\mu_y$ and covariance matrix $\Sigma_y$. In words the model (10.1) starts with a categorical distribution over $y$, and for each possible value of $y$, it assumes a Gaussian distribution for $x$. Considering the marginal distribution $p(x)$, as we do in Figure 10, the model corresponds to a mixture of Gaussians (one component for each class of $y$), hence the name. Altogether (10.1) is a generative model for how $(x,y)$ is generated. As the models build up on simplifying assumptions, and most central to the GMM is the Gaussian assumption for the class-conditional distributions over $x$ (10.1c).

In the supervised setting, the GMM will lead to classifiers that are easy to learn (no numerical optimization is needed) and turn out to be useful in practice when the data does not obey the Gaussian assumption (10.1c perfectly). These classifiers are (for historical reasons) called linear and quadratic discriminant analysis, LDA and QDA. However, the GMM can also be used for unsupervised unsupervised, as well as learning from partially labeled data (the output label $y$ is missing for some of the training data points) in a semi-supervised setting.

# Supervised learning of the GMM

Like any other learning model the GMM (10.1) is learned from training data. The unknown parameters to be learned are $\theta = {{\mu_m, \Sigma_m\}_{m=1}^M$. We start with the supervised setting, meaning that the training data contains $x$ and corresponding outputs $(y)$, so that $\mathcal{S} = \{x_i, y_i\}_{i=1}^n$ (which has been the case for all other methods in this book so far).

Mathematically we learn the GMM by maximizing the log-likelihood of the training data

```
\theta = argmax \ln p({x_i, y_i\}_{i=1}^n | \theta|). \quad (10.2a)
```
