# The maximum likelihood perspective

To get another perspective of the squared error loss we will reinterpret the least squares method as a maximum likelihood solution. The ‘likelihood’ refers to the statistical concept of the likelihood function, and maximizing the likelihood function amounts to finding the value of $	heta$ that makes observing $y$ as likely as possible. That is, instead of (whatever arbitrarily selecting a likelihood function, what we need is the problem

$$\hat{	heta} = \arg \max p(y|\mathbf{X};\theta). \quad (3.15)$

Here $p(y|\mathbf{X};\theta)$ is the probability density of all observed outputs $y$ in the training data, given all inputs $\mathbf{X}$ and parameters $	heta$. This determines what ‘likely’ means, which we need to specify it in more detail. A common assumption is that the noise term $\epsilon$ is a stochastic variable with a certain distribution. A Gaussian distribution (also known as a normal distribution) with mean zero and variance $\sigma_{\epsilon}^2$.

$$\epsilon \sim N(0,\sigma_{\epsilon}^2). \quad (3.16)$

This implies that the $n$ observed data points are independent, and $p(y|\mathbf{X})$ factors as

$p(y|\mathbf{X};\theta) = \prod_{i=1}^n p(y_i|x_i;\theta). \quad (3.17)$

Considering the linear regression model from (3.3), $y = \theta^T\mathbf{x} + \epsilon$, with the Gaussian noise assumption (3.16) we have

$p(y_i|x_i;\theta) = N(y_i;\theta^T\x_i,\sigma_{\epsilon}^2). \quad (3.18)$

Recall that we want to maximize the likelihood with respect to $	heta$. For numerical methods, it is usually better to work with the logarithm of $p(y|\mathbf{X};\theta)$.

$ln p(y|\mathbf{X};\theta) = \sum_{i=1}^n \ln p(y_i|x_i;\theta). \quad (3.19)$
