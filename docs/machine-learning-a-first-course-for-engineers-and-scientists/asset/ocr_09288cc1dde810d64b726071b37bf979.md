# Strictly proper loss functions and asymptotic minimizers

As mentioned earlier the asymptotic minimizer of a loss function is an important theoretical concept for understanding its properties. The asymptotic minimizer is the model which minimizes the cost when the number of training data $n \to \infty$ (hence the name asymptotic). To formalize this, assume that the model is expressed in terms of a function $f(x)$. As we have seen this captures not nothing, but also through the margin mechanism. The asymptotic minimizer $f^*(x)$ of a loss function $L(y, f(x))$ is defined as the function that minimizes the expected

```
$$f^*(x) = \arg\min_f \mathbb{E}[L(y, f(x))]$
```

There are couple of things to note about this expression. First, we stated that the asymptotic minimizer is obtained as the solution to the objective (5.4) as $n \to \infty$, but this has been replaced by an expected value. This is motivated by the law of large numbers stipulating that the cost (5.4) will converge to the expected lost as $n$ grows, and the latter is more convenient to analyze mathematically. Note the expected value is taken with respect to a true data distribution probability $p(y,x)$, analog to how we observed the new data in Chapter 4. Second, when we allow any function $f(x)$. Consequently, the minimization in (5.21) is not with respect to a finite dimensional model parameter $\theta$, but rather respect to the function $f(x)$ itself. For this reason, abstract definition is that that we want to derive the asymptotic minimizer as a property of the loss function itself, not of a particular combination of loss and model class.

The expected value is biased with both inputs x and outputs y. However, by the law of total expectation we can write $\mathbb{E}[L(y, f(x))] = \mathbb{E}[\mathbb{E}[L(y, f(x))|x]]$ where the inner expectation is over conditionally $(y)$ on $x$ and the outer expectation is over $x$.
