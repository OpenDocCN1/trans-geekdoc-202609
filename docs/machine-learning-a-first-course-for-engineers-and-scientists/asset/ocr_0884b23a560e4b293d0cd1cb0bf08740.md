That is, we seek to minimize a cost function defined as an average of (some-chosen) loss $L$ evaluated on the training data. In some special cases (such as linear regression with squared loss) we can compute the solution to this optimization problem exactly. However, in most cases, and in particular when working with nonlinear models, this is not possible and we need to resort to numerical optimization. We will discuss algorithms in detail in Section 5.4, but it is useful to note already that these optimizations are often iterative. That is, the algorithm runs many iterations and each iteration the current approximate solution to the optimization problem (5.4) is updated into new (hopefully) better solution. This could lead to a computational trade-off. The longer we run the better solution we expect to find, but at the cost of a longer training time.

Finding the value of $\theta$ such that the model fits the training data as well is a natural idea. However, as we discussed in the previous chapter the ultimate goal of machine learning is not to fit the training data as well, but rather to find a model that can generalize to new data, not used for the training model. Put differently, the problem that we are actually interested in solving is not (5.4) but rather

```
$$\hat{	heta} = \arg\min_{\theta} E_{new}(\theta) \quad (5.5)$
```

where $E_{new}(\theta) = \mathbb{E}_{*}[E(y_*, f_{\theta}(x_*))]$ is is the expected error data (or error function $E$ of interest); see Chapter 4. The issue is that the expected error data is unknown to us. The "true" data distribution is not available and we cannot compute the expected error with respect to new data, nor can we optimize the objective (5.5) explicitly. However, this insight is of practical importance, because means that

> the training objective is a proxy for the actual objective of interest, (5.5).

This view of the training objective has implications for how we approach the optimization problem (5.4) in practice. We make the following observations.

**Optimization accuracy vs. statistical accuracy:** The cost function $J(\theta)$ is computed based on the training data and is subject to the noise in the data. It is viewed as a random approximation of the "true" expected (obtained as $n \to \infty$). It is not means to optimize $J(\theta)$ with greater accuracy than the statistical error in the estimate. This is particularly relevant in situations when we need to spend a lot of computational effort to obtain a very accurate solution to the optimization problem. This is unnecessary as long as the result is within the statistical accuracy of the estimate. In practice it is difficult to determine whether the statistical accuracy is enough (and we will not elaborate on methods that can be used for estimating in this), but this trade-off between optimization accuracy and statistical accuracy is still useful to have in the back of the mind.

**Loss function # error function** As discussed in Chapter 4 we can use an error function $E$ for evaluating the performance of a model which is different from the loss function $L$ during training. In words, when the training we minimize an objective which is different from the one that we are actually interested in. This might seem counter-intuitive, but based on the proxy view of the training objective it makes perfect sense and, in fact, provides the machine learner with additional flexibility in designing a useful training objective. There are many reasons why we might want to use a loss function that is different from the error function. It can result in a model which is expected to generalize.
