# ### The supervised learning problem

+   - x input
- y output
- $x_*$ test input
- $y_*$ test output
- $\hat{y}(x_*)$ a prediction of $y_*$
- $\epsilon$ noise
- $n$ number of data points in training data
- $\mathcal{T}$ training data $\{x_i, y_i\}_{i=1}^n
- $L$ cost function

# ### Supervised methods

+   - $	heta$ parameters to be learned from training data
- $g(x)$ model of $p(y|x)$ (most classification methods)
- $\lambda$ regularization parameter
- $\phi$ link function (generalized linear models)
- $h$ activation function (neural networks)
- $W$ weight matrix (neural networks)
- $b$ offset vector (neural networks)
- $\gamma$ learning rate
- $B$ number of members in an ensemble method
- $\kappa$ kernel
- $\phi$ nonlinear feature transformation (kernel methods)
- $d$ dimension of $\phi$, number (kernel methods)
