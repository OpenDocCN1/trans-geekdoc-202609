# Supervised learning: a first approach

Data: Training data $\{x_i, y_i\}_{i=1}^n$ and test input $x_*$.\nResult: Predicted output $\hat{y}(x_*)$

+   1 Compute the distances $\|x_i - x_*\|$ for all training data points $i = 1, \dots, n$
2 Let $N_* = \{i : x_i 	ext{ is one of the data points closest to } x_*\}$
3 Compute the prediction $\hat{y}(x_*)$ as

```
$$\hat{y}(x_*) = \begin{cases} \text{Average}(y_j : j \in N_*) & \text{(Regression problems)}\ntext{MajorityVote}(y_j : j \in N_*) & \text{(Classification problems)}\end{cases}$
```

# Example 2.3: Predicting colors with k-NN

We consider a binary classification problem ($M=2$). We are given a training dataset with $n=6$ observations of $p=2$ input variables $x_1, x_2$ and one categorical output $y$, the color Red or Blue.

| i | x1 | x2 | y |
|---|---|---||
| 1 | -1 | 3 | Red |
| 2 | 2 | 1 | Blue |
| 3 | -2 | 2 | Red |
| 4 | -1 | 2 | Blue |
| 5 | -1 | 0 | Red |
| 6 | 6 | 1 | Blue |

and we are interested in predicting the output for $x_*=[2,1]^T$. For this purpose we will explore two different k-NN classifiers, using $k=1$ and using $k=3$.\nFirst, we compute the Euclidean distance $\|x_i - x_*\|$ between each training data point $x_i$ (red and blue dots) and then sort them in ascending order.

| i | $\|x_i - x_*\|$ | y |
|---|---|---|
| 6 | $\sqrt{1}$ | Red |
| 2 | $\sqrt{2}$ | Blue |
| 4 | $\sqrt{4}$ | Blue |
| 1 | $\sqrt{5}$ | Red |
| 5 | $\sqrt{8}$ | Blue |
| 3 | $\sqrt{9}$ | Red |

![](bbox=[0.532, 0.574, 0.765, 0.733])

Since the closest training point to $x_*$ is $i=6$, it means that for $k=1$, we get the prediction $\hat{y}(x_*)=Blue$. For $k=3$, the 3 neighbors are $i=6$ (Red), $i=2$ (Blue), and $i=4$ (Blue). Taking a majority vote among these three training data points, Blue wins with 2 votes against Red, so our prediction becomes $\hat{y}(x_*)=Blue$. In figure:ecknn1, 1 is represented by the inner circle and 3 is by the outer circle.
