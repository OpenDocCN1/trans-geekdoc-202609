To handle this situation we use a heuristic algorithm known as recursive splitting for learning the tree. The recursive means that we will determine the splitting rules one after the other, starting with the first split at the root and then build the tree from top to bottom. Algorithm is *greedy*, in that we construct one split at a time, without having the complete tree “mind”. That is, by determining the splitting rule at the root, the objective is to obtain a model that explains the data as well as after a single split, without taking into consideration that additional splits may be needed before reaching the final model. When we have decided on the first split of the input space (corresponding to the root of the tree), this split is kept fixed and we continue in a similar way for the two resulting half-spaces (corresponding to the two branches of the tree),

To see in detail how one step of this algorithm works, consider the setting when we are about to do before very first split of the root. Here, we want to select one of the input variables $x_1,...,x_p$ and a corresponding point $s$ which divides the input space into two half-spaces,

```
$R_1(j,s) = {x|x_j < s}\quadquad\text{and}\quadquadR_2(j,s) = {x|x_j \geq s}\quadquad(2.4)$
```

Note that the regions depend on the index $j$ of the splitting variable as well as the value of the cut point, which is why we write them as functions of $j$ and $s$. This is also the case for the predictions associated with the two regions,

```
$$\hat{y}_1(j,s) = \text{Average}(y_i : x_i \in R_1(j,s))\quad\text{and}\quadquad\hat{y}_2(j,s) = \text{Average}(y_i : x_i \in R_2(j,s))$
```

since in averages averages range over different data points depending on the regions. For each training data point $(x_i, y_i)$ we can compute a prediction error by first determining which region the data falls into and then computing the difference between $y_i$ and the constant prediction associated with that region. This total error can be written as

```
$$\sum_{i \in R_1(j,s)} (y_i - \hat{y}_1(j,s))^2 + \sum_{i \in R_2(j,s)} (y_i - \hat{y}_2(j,s))^2.\quad\quad(2.5)$
```

The square is to ensure that the prediction above is non-negative and that both positive and negative errors are counted equally. The squared error is a *loss function* for measuring the closeness of a prediction and the training data, but we will discuss the choice of loss function in more detail in later chapters.

To find the optimal split we select for $j$ and $s$ to minimize the squared error (2). This minimization problem can be solved by easily looping through all possible values for $j=1,...,p$. For each $j$ we can search through the number of possible splits, and pick the pair $(j,s)$ for which the expression is minimized. As pointed out, when we have found the optimal split at the root, this split is fixed. We then repeat the process in the same way for the left and right branch independently. In principle, we can continue this until there is only a single training data point in each region, is, until $L=1$. A fully grown tree will result in predictions that exactly match the training data, and the resulting model is similar to $k$-NN with $k=1$. As pointed out, this will likely result in an overfitted model that generalizes poorly to noisy training data. To mitigate this, it is common to stop the growth of the tree at an early stage using stopping criterion, for instance by deciding on $L$ beforehand, limiting the maximum depth (number of splits in any branch) or adding a constraint on the number of data points associated with each leaf. Forced to have more training data points in each leaf will result in an averaging effect, similarly to increasing the value of $k$ in the $k$-NN method. Using such a stopping criterion means that the value of $L$ is not set manually, but determined adaptively based on the result of the learning procedure.
