Another explanation for why generative models can be useful in the semi-supervised setting is that it provides a richer description of the data generating process than a discriminative model, making it easier to leverage information contained in the unlabeled data. A discriminative model of $p(\mathbf{y} \mid \mathbf{x})$ encodes information like 'if x then y...', but it does not contain explicit logic for the labels themselves. The generative model, on the other hand, contains additional assumptions on $p(\mathbf{x} \mid \mathbf{y})$, that can be useful when handling the semi-supervised problem. For instance, the GMM encodes the information that all inputs belonging to a class should have a Gaussian distribution and thereby belong to a *cluster*. The parameters are then inferred from these clusters in (10.10), where both labeled and unlabeled data points contribute. This assumption is the key for Method 10.2 to work in practice, especially in such a challenging situation as in Figure 10.5 where the vast majority of the data points are unlabeled.

The generative paradigm provides a robust approach for modeling both labeled and unlabeled data. The downside, however, is that it requires additional assumptions on the data distribution and the result can be misleading if these assumptions are not fulfilled. Furthermore, in many contemporary learning scenarios the input x is extremely high-dimensional and it then can be difficult to design/or learn a model for it. For instance, assuming that an image is represented by pixels in a x (very high-dimensional) Gaussian distribution is not going to capture the characteristics of natural images in a good way. We will return to this in Section 10.3 where we discuss how generative models of such high-dimensional and complex data can be constructed using neural networks.
