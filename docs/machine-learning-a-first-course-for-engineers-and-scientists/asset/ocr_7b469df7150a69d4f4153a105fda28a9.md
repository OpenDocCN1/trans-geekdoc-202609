# 3 Basic parametric models and a statistical perspective on learning

# A calculus approach

Let

$V(\theta) = ||\mathbf{X}\theta-\mathbf{y}||_2^2 = (\mathbf{X}\theta-\mathbf{y})^	op (\mathbf{X}\theta-\mathbf{y}) = \mathbf{y}^	op\mathbf{y}-2\mathbf{y}^	op\mathbf{X}\theta+\theta^	op\mathbf{X}^	op\mathbf{X}\theta$, (3.52)

and differentiate $V(\theta)$ with respect to the vector $\theta$,

$$\frac{\partial}{\partial\theta}V(\theta) = -2\mathbf{X}^	op\mathbf{y}+2\mathbf{X}^	op\mathbf{X}\theta$, (3.53)

Since $V(\theta)$ is a positive quadratic form, it must be attained at $\theta_0$ where $V(\theta_0)=0$, which characterizes the solution $\theta_0$ as

$$\nabla V(\	heta) = 0 \Rightarrow -2\mathbf{X}^	op\mathbf{y}+2\mathbf{X}^	op\mathbf{X}\theta=0 \Rightarrow\mathbf{X}^	op\mathbf{X}\theta=\mathbf{X}^	op\mathbf{y}$, (3.54)

which is the normal equations.

# A linear algebra approach

Denote the $p+1$ columns of $\mathbf{X}$ as $\mathbf{c}_j, j=1,...,p+1$. We first show that $||\mathbf{X}\theta-\mathbf{y}||_2$ is minimized by $\theta$ such that $\mathbf{X}\theta$ is the orthogonal projection of $\mathbf{y}$ onto the (sub)space spanned by the columns $\mathbf{c}_j$ of $\mathbf{X}$, and then show that the orthogonal projection is found by the normal equations.

Let us decompose $\mathbf{y}$ as $\mathbf{y}_|+\mathbf{y}_\perp$, where $\mathbf{y}_\perp$ is orthogonal to the (sub)space spanned by all columns $\mathbf{c}_j$, and $\mathbf{y}_||$ is in the (sub)space spanned by all columns $\mathbf{c}_j$. Since $\mathbf{y}_\perp$ is orthogonal to both $\mathbf{y}$ and $\mathbf{X}\theta$, it follows that

$||\mathbf{X}\theta-\mathbf{y}||_2 = ||\mathbf{X}\theta-\mathbf{y}_|||_2 = ||(\mathbf{X}\theta-\mathbf{y}_|)||_2 \ge ||\mathbf{y}_\perp||_2$. (3.55)

and the triangle inequality allows us

$||\mathbf{X}\theta-\mathbf{y}||_2 = ||\mathbf{X}\theta-\mathbf{y}_|||_2 \le ||\mathbf{y}_||_2+||\mathbf{X}\theta-\mathbf{y}_|||_2$. (3.56)

This implies that if we choose $\theta$ such that $\mathbf{X}\theta=\mathbf{y}_||$, the criterion $||\mathbf{X}\theta-\mathbf{y}||_2$ must have reached its minimum. Our, solution $\theta$ must be orthogonal to the (sub)space spanned by all columns $\mathbf{c}_i$, meaning

$(\mathbf{X}^	op\mathbf{	heta})^	op\mathbf{c}_j=0, j=1,...,p+1$ (3.57)

(remember that two vectors $\mathbf{u},\mathbf{v}$ are defined, orthogonal if their scalar product, $\mathbf{u}^	op\mathbf{v}$, is 0). Since the columns $\mathbf{c}_j$ form the matrix $\mathbf{X}$, we can write this compactly

$(\mathbf{X}^	op\mathbf{	heta})^	op\mathbf{X}=0$, (3.58)

where the right hand side is the $p+1$-dimensional vector zero. This equivalently be written as

$$\mathbf{X}^	op\mathbf{	heta}=\mathbf{X}^	op\mathbf{y}$,

which is the normal equations.
