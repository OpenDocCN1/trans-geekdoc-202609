> Example 3.6: Poisson regression

A simple model for count data is to use a Poisson likelihood. The Poisson distribution is supported on the natural numbers (including 0) and has mass function

```
$Poi(y;\lambda) = \frac{\lambda^y e^{-\lambda}}{y!}, \quad y=0, 1, 2, \dots$$
```

The so called rate parameter $\lambda$ controls the scale of the distribution and also its mean value, $\mathbb{E}[y] = \lambda$. To use this likelihood in a regression model for count data we can let $\lambda$ depend on the input variable $x$ and the model parameters $\theta$ through a linear regression $z = \theta^T\mathbf{x}$. However, the rate parameter $\lambda$ is restricted to be positive. To ensure that this constraint is satisfied, we model $\lambda$ according to

```
$$\lambda = \exp(\	heta^T\mathbf{x})$
```

The exponential function maps the output from the linear regression component to the positive real line, resulting in a valid rate parameter for any $x$ and $\theta$. Thus, we get the model

```
$p(y|\mathbf{x};\theta) = Pois(y;\exp(\\theta^T\mathbf{x}))$$
```

referred to a Poisson regression model.

In this Poisson regression we can write the conditional mean of the output as

```
$\mathbb{E}[y|\mathbf{x};\theta] = \phi^{-1}(z), \quad \text{where} \quad z = \theta^T\mathbf{x}$$
```

and $\phi(\mu) = \text{def}\log(\mu)$. The idea of avoiding an explicit link between the linear regression term and the conditional mean of the output is what makes this follows the generic framework of generalized linear models. Specifically, a generalized linear model consists of:

+   1. A choice of distribution $p(y|\mathbf{x};\theta)$ from the exponential family of distributions.
2. A linear regression $z = \theta^T\mathbf{x}$.
3. A strictly increasing, continuous, link function $\phi$, such that $\mathbb{E}[y|\mathbf{x};\theta] = \phi^{-1}(z)$.

By convention, we map the linear regression through the inverse of the link function to obtain the mean of the output. Equivalently, if $\mu$ denotes the mean of $p(y|\mathbf{x};\theta)$ we can express the model as $\phi(\mu) = \theta^T\mathbf{x}$.nDifferent choices of distributions and link functions allow for regression with different properties. In fact, at here we have already seen another example of a generalized linear model, namely Poisson regression. In binary logistic regression the output distribution $p(y|\mathbf{x};\theta)$ is a Bernoulli distribution, the is computed as $z = \theta^T\mathbf{x}$ and the link function is given by inversion (a more flexible model for count data than Poisson regression) and exponential regression (for non-negative real-valued outputs). Thus the generalized linear model framework can be used to model output variables with many different properties, and allows us to describe these models in a common language.
