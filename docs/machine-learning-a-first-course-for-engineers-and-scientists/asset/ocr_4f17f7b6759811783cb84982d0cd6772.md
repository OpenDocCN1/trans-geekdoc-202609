# User aspects of machine learning

With simpler model, like the ones in Chapter 2-3, it can come some de-degree possible for an engineer to inspect the learned model and explain the "reasoning" behind it for a non-expert. For the more complicated models it can be a harder task.

There are however methods on the research forefront, and the situation may look different in the future. A related topic is that of so-called adversarial examples, which essentially amounts to finding an input x' which is as close as possible to x but gives another prediction. In the image classification setting, it can be for example the problem of having a picture of a car being predicted as a dog by changing a few pixels.

# Worst case guarantees

In the view of this, a supervised machine learning model is good if it fits some E_now. It is, however, to remember that E_now is a statistical claim, under the assumption that the training/or test data remains the quality that the model will find once it is put in production. And even if non-trivial assumption is satisfied, there are no claims about how badly the model will predict in the worst cases. This is indeed a shortcoming of supervised machine learning, and potentially also a show-stopper for some applications.

Simpler and more interpretable models, like logistic regression and trees for example, can be inspected manually in order to reduce the "worst case" that could happen. By looking at the leaf nodes in a regression tree, as an example, it is possible to give an interval to which all predictions belong. With more complicated models, like random forests and deep learning, it is very hard to give any worst case guarantees about how inaccurate the model can be in its predictions faced with some particular input. However, an extensive testing scheme might reveal some of the potential issues.

# 11.6 Further reading

User aspects of machine learning is a fairly under-explored area both in academic research publications and in standard textbooks on machine learning. Two exceptions are Ng (2019) and Burkov (2020) from which parts of this chapter has been inspired. Connected to data augmentation, see further in Shorten and Khoshgoftaar (2019) for a review of different data augmentation techniques for images.

Some of the research on "understanding" why a certain prediction was made by a machine learning method is summarized by Guidotti et al. (2018).
