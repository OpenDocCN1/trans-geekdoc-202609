# 2.3 A rule-based method: Decision trees

The k-NN method results in a prediction $\tilde{y}(\mathbf{x*})$ that is a piecewise constant function of the input $\mathbf{x*}$. That is, the method partitions the input space into regions and each region is associated with a certain (constant) prediction. For k-NN, these regions are given implicitly by the k-neighborhood of each possible test input. An alternative approach, which we will study in this section, is to come up with a set of rules that defines the regions. For instance, using the music data in Example 2.1, a simple set of high-level rules for a classifier could be: inputs to the result in Figure 2.1 which are classified as green (Bob Dylan), in the left as red (The Beatles), and in the upper part as blue (Kiss). We will now see how such rules can be learned from the training data.

The rule-based models we described are hereafter referred to as decision trees. The reason is that the rules used to define the model in a graph structure referred to as a binary tree, decision tree effectively divides the input space into multiple regions and each region contains a constant value for the prediction $\tilde{y}(\mathbf{x*})$. We illustrate this with an example.

Example 2.5: Predicting colors with a decision tree

We consider a classification with two numerical variables $\mathbf{x} = [x_1, x_2]^T$ and one categorical output, $y$, the color Red or Blue. We do not have any training data and therefore how to learn the tree, but only an already existing decision tree can be used to predict $y(\mathbf{x*})$.

The rules defining the model are organized in a graph in Figure 2.6 which is referred to as a binary tree. To use this tree to predict a label for $\mathbf{x*} = [x_1, x_2]^T$ we start at the top, referred to as the root of the tree. If the condition is met the tree proceeds down from the root to the leaves at the bottom. If the condition is not met at the root, that is, if $x_2 < 3.0$, then we proceed down the left branch otherwise the right branch. For each new internal node of the tree, we check the rule associated with that node and pick the left or right branch accordingly. We continue and work our way until we reach the end of a path, called a leaf node. Each final node corresponds to a constant prediction $\tilde{y}(\mathbf{x*})$, one of the two classes Red or Blue.

A classification. At each internal node a rule of the form $x_i < x_i*$ indicates the left branch from that split and the right branch then corresponds to $x_i \ge x_i*$. This tree has two internal nodes (including the root) and two leaf nodes.

A region partition, where each region corresponds to a leaf node in the tree. Each border corresponds to a split in the tree. Each region is colored with the prediction corresponding to that region, and the boundary between red and blue is the decision boundary.

The decision tree partitions the input space into axis-aligned "boxes", as shown in Figure 2.7. By increasing the depth of the tree (the number of steps from the root to the leaves), the partition can be made finer and finer thereby describing more complicated functions of the input variable. A pseudocode for testing an input with the tree in Figure 2.6 would look like

```
if x_2 < 3.0
    return Blue
else
    return Red
```
