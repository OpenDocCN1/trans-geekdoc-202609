# 4 Understanding, evaluating and improving the performance

With a slight variation of (4.13) to also include the zero-mean noise $\varepsilon$ (which is independent of $\widetilde{y}(\mathbf{x};\mathcal{T})$), we can rewrite the expression inside the expected value $\mathbb{E}_*$, in (4.17) as

```
$$\mathbb{E}_* \left[ (\widetilde{y}(\mathbf{x};\mathcal{T}) - f_0(\mathbf{x})) - \varepsilon)^2 \right] = (\widetilde{f}(\mathbf{x}) - f_0(\mathbf{x}))^2 + \mathbb{E}_* \left[ (\widetilde{f}(\mathbf{x};\mathcal{T}) - \widetilde{f}(\mathbf{x}))^2 \right] + \varepsilon^2$. (4.18)
```

This is (4.13) applied to supervised learning. In $\widehat{E}_{new}$, we are interested in decomposing, we also have the expectation over the new data points $\mathbf{x}_*$. By incorporating that expected value in the expression, we can decompose $\widehat{E}_{new}$ as

```
$$\widehat{E}_{new} = \mathbb{E}_* \left[ (\widetilde{f}(\mathbf{x}) - f_0(\mathbf{x}))^2 \right] + \mathbb{E}_* \left[ (\widetilde{f}(\mathbf{x};\mathcal{T}) - \widetilde{f}(\mathbf{x}))^2 \right] + \sigma^2$. (4.19)$
```

The squared bias term $\mathbb{E}_*[(\widetilde{f}(\mathbf{x}) - f_0(\mathbf{x}))^2]$ describes how much the trained model $\widetilde{f}(\mathbf{x})$ differs from the $f_0(\mathbf{x})$, averaged over all possible data points $\mathbfmathbf{x}_*$. In a similar fashion the variance term $\mathbb{E}_*|\widetilde{f}(\mathbf{x};\mathcal{T}) - \widetilde{f}(\mathbf{x})|^2$ describes how much the model is trained on a different dataset. For the bias term to be small, the model has to be flexible enough that $\widetilde{f}(\mathbf{x})$ can be close to $f_0(\mathbf{x})$, at regions where $p(\mathbf{x})$ is large. If the variance term is small, the model is not very sensitive to exactly which data points happened to be in the training data, and vice versa. The irreducible error $\sigma^2$ is simply an effect of the assumption (4.14)—it is not possible to predict $\varepsilon$ since it is a random error independent of all other variables. There is not so much to say about the bias and variance terms.

# What affects the bias and variance

We have not properly defined model complexity, but we can actually use the bias and variance concept to get a more concrete narrative: high complexity means low bias and high variance, as illustrated by Figure 4.8.

This resonates with the intuition. The more flexible the model is, the more it will adapt to the training data $\mathcal{T}$not only to the interesting patterns, but also to the actual data points and noise that happened to be in $\mathcal{T}$. That is exactly what is described by the variance term. On the other hand, a model with low flexibility can be too rigid to capture the true relationship $f_0(\mathbf{x})$ between inputs and outputs well. This effect is described by the squared bias term.
