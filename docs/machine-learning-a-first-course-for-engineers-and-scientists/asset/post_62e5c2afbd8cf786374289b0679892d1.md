Kernel ridge regression, as we just derived, is our first method for regression, which is a useful method on its own. We will now extend kernel regression into support vector regression by replacing the loss function. First, however, take a step back and make an interesting observation that suggests the so-called representer theorem, which will be useful later in this.

## Preparing for other kernel methods: the representer theorem

The formulation (8.14) is not only practical for implementation, it is also important for theoretical understanding. We can interpret (8.14) as a *dual formulation of linear regression*, where we have the *dual parameters $\alpha$ instead of the primal formulation (8.4)* with primal parameters $\theta$. Remember that $d$, the (possibly infinite) number of primal parameters in $\theta$, is a user design choice, whereas $n$, the number of dual parameters in $\alpha$, is the number of data points.

## 8 Nonlinear input transformations and kernels

By comparing (8.14b) and (8.5), we have that

$$\widetilde{Y}(x_*) = \bar{\theta}^T \phi(x_*) = \bar{\alpha}^T \frac{\Phi(X)\phi(x_*)}{K(X,x_*)} \quad (8.15)$$

for all $x_*$, which suggests that

$$\bar{\theta} = \Phi(X)^T \bar{\alpha}. \quad (8.16)$$

This relationship between the primal parameters $\theta$ and the dual parameters $\alpha$ is not specific for kernel regression, (8.16) is the consequence of a general result called the representer theorem.
In essence the representer theorem tells us that if $\widetilde{Y}(x) = \theta^T \phi(x)$, the equation (8.16) holds when $\theta$ is learned using (any) loss function and $L^2$-regularization. A full treatment is beyond the scope of this chapter, but we give a complete statement of the theorem in Section 8A. An implication of the representer theorem is that $L^2$-regularization is crucial in order to obtain kernel ridge regression (8.14). The representer theorem is a cornerstone for most kernel methods, since it tells us that we can express some models in terms of dual parameters $\alpha$ (of finite length $n$) and a kernel $\kappa(x,x')$ instead of the primal parameters $\theta$ (possibly of infinite length $d$) and a nonlinear feature transformation $\phi(x)$, just like we do in linear regression (8.14).

## Support vector regression

From a model perspective the support vector regression is another of the off-the-shelf kernel method for regression. This new loss function has an interesting effect in that the dual vector $\bar{\alpha}$ in support vector regression becomes sparse, meaning that several elements of $\bar{\alpha}$ are exactly zero. Recall that with one data point, the data points connecting the non-zero elements of $\bar{\alpha}$ are referred to as support vectors, and the prediction $\widetilde{Y}(x_*)$ will depend only on these (in contrast to kernel ridge regression (8.14b), where all training data are needed to compute $\widetilde{Y}(x_*)$). This support vector regression example of a so-called support vector machine (SVM), a family of methods with sparse dual vector parameters.

The loss we use for support vector regression is the $\epsilon$-insensitive loss

$$L(Y, \widetilde{Y}) = \begin{cases} 0 & \text{if } |y - \widetilde{y}| < \epsilon, \ |y - \widetilde{y}| - \epsilon & \text{otherwise},\ \end{cases} \quad (8.17)$$

or equivalently $L(Y, \widetilde{Y}) = \max\{0, |y - \widetilde{y}| - \epsilon\}$, which was introduced in (5.9) in Chapter 5. The parameter $\epsilon$ is a user design choice. In its primal formulation, support vector regression also makes use of linear regression model

$$\widetilde{Y}(x_*) = \bar{\theta}^T \phi(x_*). \quad (8.18a)$$

but instead of the least square function in (8.4), we now have

$$\bar{\theta} = \arg\min_{\theta} \sum_{i=1}^n \max\{0, |y_i - \theta^T \phi(x_i)| - \epsilon\} + \lambda\|\theta\|_2^2. \quad (8.18b)$$

With kernel ridge regression, we reformulate the primal formulation (8.18) into a dual formulation with $\alpha$ instead of $\theta$ and the kernel-trick. For the dual formulation, we cannot repeat the closed-form derivation along (8.4–8.14) since there is no closed-form solution for $\theta$. Instead we use optimization theory, introduce slack variables and construct the Lagrangian of (8.18).

## 8.3 Support vector regression

We do not give the full derivation (it is similar to the derivation of support vector classification in Appendix 8B), but as it turns the dual formulation becomes

$$\widehat{y}(\mathbf{x}_*) = \widetilde{\alpha}^T K(\mathbf{X}, \mathbf{x}_*), \quad (8.19a)$$

where $\widetilde{\alpha}$ is the solution to the optimization problem

$$\widetilde{\alpha} = \arg\min_{\alpha} \frac{1}{2}\alpha^T K(\mathbf{X},\mathbf{X})\alpha - \alpha^T\mathbf{y} + \epsilon\|\alpha\|_1, \quad (8.19b)$$

$$\text{subject to } \|\alpha\| \le \frac{1}{2\lambda}. \quad (8.19c)$$

Note that (8.19a) is identical to the corresponding expression for kernel ridge regression (8.14b). This is a consequence of the representer theorem. The only difference to kernel ridge regression is how the dual parameters $\alpha$ are learned: by numerically solving the optimization problem (8.19b) instead of using the closed-form solution (8.14a).

The $\epsilon$-insensitive loss function could be used for any regression model but it is particularly interesting in this context that the dual parameter $\alpha$ becomes sparse (meaning that only some elements are non-zero). Remember that $\alpha$ has one entry per training point. This implies that the prediction (8.19a) depends only on *some* of the training points, namely whose $\alpha_i$ is non-zero, the so-called *support vectors*. In fact it can be shown that the support vectors are the data points for which the loss function is non-zero, that is $|\widehat{y}(x) - y_i| \ge \epsilon$. That is, a larger $\epsilon$ results in fewer support vectors, and vice versa. This effect can also be understood by interpreting $\epsilon$ as a regularization parameter in a $L^1$ penalty in the dual formulation (8.19b). (The number of support vectors is, however, also affected by $\lambda$, since $\lambda$ influences the shape of $\widehat{y}(\mathbf{x})$.) We illustrate this in Figure 8.3.

All training data is used during training (that is, solving (8.19b)) but when making predictions (using (8.19a)) only the support vectors contribute. This can significantly reduce the computational burden. The larger $\epsilon$ chosen by the user, the fewer support vectors and fewer computations needed when making predictions. It can therefore be said that $\alpha$ has a regularizing effect, in the sense that the more/fewer support vectors that are used the more/less complicated model. We summarize support vector regression in Method 8.2.
