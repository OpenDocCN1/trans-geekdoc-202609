In this section we will build on the classification setting considered also the called clustering problem. Clustering is one example of unsupervised learning. It amounts to finding groups of similar values in the data space, and associating these with a discrete set of clusters. From a mathematical and methodological point of view, clustering is intimately related to classification. Indeed, we assign a discrete index to each cluster and then say that all values in the $m$th cluster are of $x = m$. The difference between classification and clustering is that we wish to learn for the clusters based solely on the $x$ values, without any labels. Still, as we show below, one way to address this problem is to use the same GMM and EM algorithm as has been used in the context of semi-supervised learning above.

From a more conceptual point of view there are some differences between classification and clustering. In classification we well know what the different classes correspond to. They are typically specified as part of the problem formulation and the objective is to build a predictive classifier. On the other hand, it is handled in a more exploratory way. We might expect that there are data points with similar features and the objective is to group them into clusters, to obtain a better understanding of the data. However, the clusters might not correspond to any interpretable classes. Moreover, the nature of clusters is typically unknown and left to the user to decide.

We start by adapting the GMM to the unsupervised setting, turning it into a clustering method. We will discuss the GMM algorithm in bit more detail, as well as highlight some subtleties that differ between the semi-supervised and unsupervised setting. Next, we present the k-means algorithm, which is an alternative clustering method, and discuss similarities between this method and the GMM.

# Unsupervised learning of the Gaussian mixture model

The GMM (10.1) is a joint model for $x$ and $y$, given by

```
$p(\mathbf{x}, y) = p(\mathbf{x}|y)p(y) = N(\mathbf{x}|\boldsymbol{\mu}_y, \boldsymbol{\Sigma}_y)\pi_y$.
```

To obtain a model only for $x$ we can marginalize $y$ as $p(\mathbf{x}) = \sum_y p(\mathbf{x}, y)$. From the marginalization this implies that we consider $y$ as a latent variable, that exists in the data containing only $\{\mathbf{x}_i\}_{i=1}^n$. Intuitively, we learn the GMM from unlabeled training data to figure out which $\mathbf{x}$ values come from which class-conditional distribution $p(\mathbf{x}|y)$, based on their similarity. That is, we need to learn the latent variables $\{y_i\}_{i=1}^n$ from the data and then use this knowledge to fit the model parameters. Once this is done, the learned class-conditional distributions $p(\mathbf{x}|y=m)$ for $m=1,...,M$ define $M$ clusters in the data.

Conveniently we have a tool to learn the GMM from data. Method 10.2, which we derived for the semi-supervised case, also works for completely unlabeled data $\{\mathbf{x}_i\}_{i=1}^n$. We just need to replace the initialization (1) with random choice of initial $(\hat{\boldsymbol{\mu}}_m, \hat{\boldsymbol{\Sigma}}_m)_{m=1}^M$. We repeat the algorithm with these minor modifications in Method 10.2 for convenience.

Method 10.3 corresponds to the EM algorithm applied to the unsupervised maximum likelihood problem

```
$\hat{\theta} = \arg\max_{\theta} p(\{\mathbf{x}_i\}_{i=1}^n|\theta)$.
```

To show that this is indeed, and that the suggested procedure is a well grounded way of addressing the maximum likelihood problem (10.2), we will now take a closer at the EM algorithm itself.

The EM algorithm is a general tool for solving maximum likelihood problems in probabilistic models with latent variables, that models containing both observed and unbound variables. The current latent variables are $\{y_i\}_{i=1}^n$ where $y_i \in \{1,...,M\}$ is the cluster index for data point $\mathbf{x}_i$.
