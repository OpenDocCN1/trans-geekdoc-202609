# 8.4 Kernel theory

Somewhere related to the squared exponential as we have the function of Matérn

```
$$\kappa(\mathbf{x}, \mathbf{x}') = \frac{2^{1-\nu}}{\Gamma(\nu)} \left(\frac{\sqrt{2\nu}||\mathbf{x}-\mathbf{x}'||_2}{\ell}\right)^\nu k_{\nu}\left(\frac{\sqrt{2\nu}||\mathbf{x}-\mathbf{x}'||_2}{\ell}\right),$$ \quad (8.26)
```

with hyperparameters $\nu>0$ and $\ell>0$, the latter is a type of smoothness parameter. Here $\Gamma$ is the Gamma function, and $
u$ is a modified Bessel function of the second kind. All Matérn kernels are positive semidefinite. In particular the cases where $\nu=\frac{1}{2}$ and $\frac{3}{2}$, where (8.26) simplifies to

```
$$\nu = \frac{1}{2} \Rightarrow \kappa(\mathbf{x}, \mathbf{x}') = \exp\left(-\frac{||\mathbf{x}-\mathbf{x}'||_2^2}{\ell}\right),$$ \quad (8.27)
```

```
$$\nu = \frac{3}{2} \Rightarrow \kappa(\mathbf{x}, \mathbf{x}') = (1 + \frac{||\mathbf{x}-\mathbf{x}'||_2^2}{\ell}) \exp\left(-\frac{\sqrt{3}||\mathbf{x}-\mathbf{x}'||_2^2}{\ell}\right),$$ \quad (8.28)
```

```
$$\nu = \frac{5}{2} \Rightarrow \kappa(\mathbf{x}, \mathbf{x}') = (1 + \frac{||\mathbf{x}-\mathbf{x}'||_2^2}{\ell} + \frac{5||\mathbf{x}-\mathbf{x}'||_2^4}{3\ell^2}) \exp\left(-\frac{\sqrt{5}||\mathbf{x}-\mathbf{x}'||_2^2}{\ell}\right),$$ \quad (8.29)
```

The Matérn kernel is also known as the exponential kernel. Here it can furthermore be noted that the Matérn kernel (8.26) equals the squared exponential (8.25) when $\ell \to \infty$.

As a final example of a positive definite kernel, the rational quadratic kernel

```
$$\kappa(\mathbf{x}, \mathbf{x}') = (1 + \frac{||\mathbf{x}-\mathbf{x}'||_2^2}{2\alpha^2})^{-\alpha},$ \quad (8.30)
```

with hyperparameters $\ell>0$ and $\alpha>0$. The squared exponential, rational and quadratic kernel are all examples of stationary kernels, since they are functions of $\mathbf{x}-\mathbf{x}'$. In fact they are all isotropic kernels, since they are only functions of $||\mathbf{x}-\mathbf{x}'||_2$. The linear kernel is neither isotropic nor stationary.

Going back to the discussion in connection (8.21), positive semidefinite kernels are a subset of all kernels, since for we know that theoretical properties holds. However, a kernel is potentially useful as long as we can compute a prediction using it, regardless of its theoretical properties. (At least historically) popular for SVMs where not positive semidefinite is the sigmoid kernel

```
$$\kappa(\mathbf{x}, \mathbf{x}') = \tanh(a\mathbf{x}^T\mathbf{x}' + b).$$ \quad (8.31)
```

where $a>0$ and $b<0$ are hyperparameters. The kernel is not positive definite

It is possible to construct kernels by modifying or combining existing ones. In particular there are a set of operations that preserve the positive semidefinite property: if $\kappa(\mathbf{x}, \mathbf{x}')$ is a positive semidefinite kernel, then so are $\kappa_1(\mathbf{x}, \mathbf{x}') + \kappa_2(\mathbf{x}, \mathbf{x}')$ (addition) as well as $\kappa_1(\mathbf{x}, \mathbf{x}')\times\kappa_2(\mathbf{x}, \mathbf{x}')$ (multiplication).

Most kernels have a few hyperparameters that are left to the user. Like much choice can give valuable help in choosing between different kernels, kernel regression can also help choosing hyperparameters with grid search in Chapter 5.
