## Extending kernel regression into a Gaussian process

An alternative to obtain the Gaussian process construction, is to apply the kernel trick from Section 8.2 to Bayesian linear regression from (9.11). The connection between linear regression, Bayesian linear regression, kernel regression and the Gaussian process is summarized in Figure 9.7. This will essentially lead back to (9.21), with the kernel being the covariance function $k(x,x')$ and the mean function $\mu(x)=0$.

Let us now repeat the posterior predictive for Bayesian linear regression (9.11), with however two changes. The first change is that we assume the mean and covariance for $\theta$ is $\boldsymbol{\mu}_0 = \mathbf{0}$ and $\Sigma = \mathbf{I}$. This assumption is not strictly needed for our purposes, but it simplifies the expressions. The second change is that in Section 8.1 nonlinear feature transformations $\boldsymbol{\Phi}(x)$ of the input variable $x$ in the linear regression model. We replace $\mathbf{X}$ with $\mathbf{\Phi}(X)$ in the notation. Allogether

$$p(f(x_*)|y) = N(f(x_*)|m_*, s_*^2), \quad (9.23a)$$

$$m_* = \boldsymbol{\Phi}(x_*)^T (\sigma^2 \mathbf{I} + \boldsymbol{\Phi}(X)^T \boldsymbol{\Phi}(X))^{-1} \boldsymbol{\Phi}(X)^T \mathbf{y}, \quad (9.23b)$$

$$s_* = \boldsymbol{\Phi}(x_*)^T (\mathbf{I} + \frac{1}{\sigma^2} \boldsymbol{\Phi}(X)^T \boldsymbol{\Phi}(X))^{-1} \boldsymbol{\Phi}(x_*). \quad (9.23c)$$

In a similar fashion to the derivation of kernel regression, we use the push-through matrix identity $\mathbf{A}(\mathbf{A}^T\mathbf{A} + \mathbf{I})^{-1} = (\mathbf{A}^T + \mathbf{I})^{-1}\mathbf{A}^T$ to rewrite $m_*$ with the aim to have only entering through inner products,

$$m_* = \boldsymbol{\Phi}(x_*)^T \boldsymbol{\Phi}(X)^T (\sigma^2 \mathbf{I} + \boldsymbol{\Phi}(X)^T \boldsymbol{\Phi}(X))^{-1} \mathbf{y}. \quad (9.24a)$$

To re-write $s_*$ in a similar fashion, we use the matrix inversion lemma $(\mathbf{IU}-\mathbf{V})^{-1} = \mathbf{U}-\mathbf{U}(\mathbf{I}+\mathbf{VU})^{-1}\mathbf{V}$ (which holds for matrices $\mathbf{U}$ and $\mathbf{V}$ of compatible dimensions),

$$s_* = \boldsymbol{\Phi}(x_*)^T \boldsymbol{\Phi}(X)^T - \boldsymbol{\Phi}(x_*)^T \boldsymbol{\Phi}(X)^T (\sigma^2 \mathbf{I} + \boldsymbol{\Phi}(X)^T \boldsymbol{\Phi}(X))^{-1} \boldsymbol{\Phi}(x_*). \quad (9.24b)$$

## 9.3 The Gaussian process

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_190_0.png)

**Figure 9.7:** A graphical summary of the connections between linear regression, Bayesian linear regression, kernel ridge regression and the Gaussian process.

Analogously to the derivation of kernel ridge regression in (8.12), we are now ready to apply the kernel trick and replace all instances of $\phi(x)\phi(x)'$ with a kernel $k(x,x')$. With same notation in (8.12), we get

$$m_* = K(\mathbf{x}_*, \mathbf{X})^T(\sigma^2 I + K(\mathbf{X}, \mathbf{X}))^{-1}\mathbf{y} \quad (9.25a)$$

$$\sigma_* = k(\mathbf{x}_*, \mathbf{x}_*) - K(\mathbf{x}_*, \mathbf{X})^T(\sigma^2 I + K(\mathbf{X}, \mathbf{X}))^{-1}K(\mathbf{X}, \mathbf{x}_*) \quad (9.25b)$$

The posterior predictive is defined by (9.23a) and (9.25b) the Gaussian process model, identical to (9.21) if $\mu(\mathbf{x}_*) = 0$ and $\sigma = 0$. The reason for $\mu(\mathbf{x}_)=0$ is that this derivation starts with $\mu_0=0$. When we derived (9.21) we assumed that we observed $f(\mathbf{x})$ (rather than $y = f(\mathbf{x}) + \epsilon$), which is the reason why $\sigma=0$ in (9.21). The Gaussian process is a version of Bayesian linear regression, kernel ridge is a version of (regularized) linear regression, as illustrated in Figure 9.7. In order to see the connection to kernel ridge, note that (9.25a) is identical to (8.14) with $\sigma^2=\lambda$. It is also important to note the difference in that there is no counterpart to (9.25b) for kernel regression, simply kernel regression does not predict a probability distribution.

The fact that the kernel plays the role of covariance function in the Gaussian process gives us another interpretation of the kernel in Section 8.4, the kernel $k(x,x')$ determines how strong the correlation between $f(x)$ and $f(x')$ is.

**Time to reflect 9.1:** Verify that you retrieve Bayesian linear regression when using the linear kernel (8.23) in the Gaussian process. Why is that it is not common to write out the addition of $\sigma^2I$ to the Gram matrix $K(\mathbf{X}, \mathbf{X})$, but instead add a white noise kernel (9.22) multiplied with $\sigma^2$ to the original kernel, $\tilde{k}(x,x') = k(x,x') + \sigma^2\delta(x,x')$. We then replace $\sigma^2 I + K(\mathbf{X}, \mathbf{X})$ with $\tilde{K}(\mathbf{X}, \mathbf{X})$, where $\tilde{K}$ is built using $\tilde{k}(x,x')$. Then, (9.25) simplifies to

$$m_* = K(\mathbf{x}_*, \mathbf{X})^T\tilde{K}(\mathbf{X}, \mathbf{X})^{-1}\mathbf{y} \quad (9.26a)$$

$$\sigma_* = k(\mathbf{x}_*, \mathbf{x}_*) - K(\mathbf{x}_*, \mathbf{X})^T\tilde{K}(\mathbf{X}, \mathbf{X})^{-1}\tilde{K}(\mathbf{X}, \mathbf{x}_*) - \sigma^2 \quad (9.26b)$$

## Method 9.2: Gaussian process regression.

### A nonparametric distribution over functions

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_191_0.png)

(a) The training data $\{x_i, y_i\}_{i=1}^n$ of a regression process is given to us.

(b) The underlying assumption when we regression is that there exists *some function* $f$, which describes the data $y_i = f(x_i) + e$. It is unknown, but the purpose of regression (no matter method is used) is to determine $f$.

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_191_1.png)

(c) The Gaussian process defines a distribution over $f$. We can condition on training data (that is, learning) and access for any input, say $x_*$ and $\mathbf{x}_*$. Then we make a prediction for $x_*$ and $\mathbf{x}_*$. The Gaussian process gives us a Gaussian distribution for $f(x_*)$ and $f(\mathbf{x}_*)$, illustrated by solid red lines. That distribution is heavily influenced by the choice of kernel, which is a design choice in the Gaussian process.

**Figure 9.8:** The Gaussian process defines a distribution over functions, which we can condition on training data and access in arbitrary points (such as $x_*$ and $\mathbf{x}_*$) to compute predictions.

As a supervised learning method we use the Gaussian process for making predictions, that is, computing the posterior predictive $p(f_*|\mathbf{y})$ or $p(y_*|\mathbf{y})$. However, unlike most other methods which only deliver a point predictive $\tilde{y}(\mathbf{x}_*)$, the posterior is a distribution. If we can compute the posterior predictive for any $\mathbf{x}_*$, the Gaussian process actually defines a *distribution over functions*, which we illustrate in Figure 9.8.

If we could derive a connection between Bayesian linear regression and L2 regularized regression, we also see a similar connection between the Gaussian process and kernel ridge regression. If we only consider the mean $m_*$ of the posterior, we recover kernel ridge regression. To take full advantage of the Bayesian perspective, we have to consider also the posterior predictive variance $s_*$.
