# Introduction

Classification is a supervised machine learning task which involves predicting a certain class, label, for each data point. Specifically, for classification problems there are only a finite number of possible output values. In the ECG example, the classes correspond to the type of heart condition. For instance, the classes could be 'normal' or 'abnormal', in which case we refer to it as a binary classification (only two classes). More generally, we can design a model for classifying each signal as either 'normal', or assign it to one of a predetermined set of abnormalities. We then face a (more ambitious) multi-class classification problem.

Classification is not the only type of supervised machine learning that we can utilize. Specifically, we will also study another type of problem referred to as regression. Regression differs from classification in that the output ( is, the quantity we want the model to predict) is a numerical value. We illustrate this with an example from material science.

# Example 1.2: Formation of crystals

Much of our technology is driven by the discovery of new materials with unique properties. Indeed, technologies such as touch sensors and batteries for electric vehicles have emerged due to advances in material science. Materials discovery was largely done through experiments, but this has been time consuming and costly, which limited the number of new materials that could be found. Over the past few decades, computational methods have therefore played an increasingly important role. The basic idea behind computational material science is to create a large number of hypothetical materials, and then to experimentally synthesize the most promising candidates.

Crystalline solids (or, crystals) are a central type of inorganic materials. In a crystal, the atoms are arranged in a highly ordered microscopic structure. To understand the properties of such materials, it is not enough to know the proportion of each element in the material, but we also need to know how elements (or atoms) are arranged into a crystal. A basic property of interest when considering a hypothetical material is to determine its formation energy—which is the energy that needs to form the form from the individual elements. Nature strives for finding a minimum energy configuration; if a certain structure is predicted to have a formation energy that is significantly larger than that alternative crystals composed of the same elements, then it is unlikely that it can be synthesized in a practical way.

A classical method (having gone since the 60s) can be used for computing the formation energy of a structure, namely, density functional theory (DFT). The DFT method, which is based on quantum mechanical modeling, was the first real breakthrough in computational material science, enabling high throughput screening for materials discovery. That said, the DFT method is computationally heavy and even with modern supercomputers, only a small fraction of potentially interesting materials have been analyzed.

To handle this limitation, much interest has risen to using machine learning for materials discovery, with the potential of resolving a scale regression problem. By training a machine learning model to, predict the formation energy—but in a fraction of the time—a much larger range of candidate materials can be investigated.

As a concrete example, Fischer et al. (2018) used a machine learning method referred to as kernel regression (see Chapter 8) to predict the formation energy of 2 million, so-called, elellite crystals. The machine learning model is a program that takes a crystal as input (a description of the properties and elemental types of the atoms in the crystal), and is asked to return a prediction of the formation energy. To train the model, 10,000 crystals were randomly selected and then trained using DFT. The model was then trained to predict formation energies as closely as possible with the DFT output—99.5% of the essentials. Among these, 128 new structures were found to have a favorable energy, thereby potentially stable in nature.

Comparing the two examples discussed above we can make some interesting observations. As pointed out, that the ECG model is asked to predict a certain class (say, normal or abnormal), whereas the materials discovery model is asked to predict a numerical value (the formation energy of a crystal). These are the main types of predictions that we study in this book, referred to as classification and regression, respectively.
