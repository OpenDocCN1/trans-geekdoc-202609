Some methods are able to handle missing data to some extent (which we have not discussed in this book), but under restrictive assumptions. Such an example is that the data is “completely missing at random”, meaning that the data is missing uncorrelated to what value it would have, and other features and the output would have had, had not been missing. Assumptions like these are very strong and rarely in practice, and the performance can be severely degraded if those assumptions are not fulfilled.

# Feature selection

When working with a supervised machine learning model, the question whether all available input variables/features contribute to the performance is often relevant. Removing the feature is indeed a type of regularization that can reduce overfitting and improve the performance, and the data collection can be simplified if a single variable do not have to be collected. Selecting the best features is an important task for the machine learning

The connection between regularization and feature selection becomes clear by considering L¹ regularization. Since the main feature of L¹ regularization is that the learned parameter vector is sparse, it effectively removes the influence of certain features. By using a model where L¹ regularization is possible, we can study θ to see which features we simply remove from the dataset. However, if we cannot use L¹ regularization, we can investigate a more manual approach to feature selection.

Remember that our overall goal is to obtain a small new error E, for which most methods estimate using cross-validation. We can therefore use cross-validation to tell whether we gain or lose, by including a feature in x. Depending on the amount of data, evaluating all possible combinations of removed features might not be a good idea, due to computational costs or the risk of overfitting. Here, some rules of thumb that give us some guidance for which features we should investigate can contribute to the performance or not.

To get a feeling for the different features, we can look at the correlation between each feature and the output, and get quite about which features might be more informative about the output. If there is little correlation between a feature and the output, it is possibly a useless feature and we could investigate if we can remove them. However, looking at only one feature at a time can be misleading and there exists cases where this would lead to the wrong conclusion, for example in Example 8.1.

Another approach is to explore if there are redundant features, with the reasoning that having two features that (essentially) contain the same information will lead to an increased variance compared to having only one feature with the same information. Based on this argument one may look at the pairwise correlation between features, and investigate removing features that have high correlation to other features. This approach is somewhat related to PCA (Chapter 10).
