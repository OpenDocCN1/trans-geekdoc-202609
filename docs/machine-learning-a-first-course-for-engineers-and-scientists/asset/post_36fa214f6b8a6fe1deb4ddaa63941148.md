The softmax function maps the output of the final layer $z = [z_1, ..., z_M]^T$ to $g = [g_1, ..., g_M]^T$ where $g_m$ is a model of the class $p(y_m|x)$. Note that the softmax function does not work as a classifier with different probabilities, it merely acts as a transformation of the output into the modeled class probabilities. The outputs of the softmax function will be in the interval $g_m \in [0, 1]$ and sum to $\sum_{m=1} g_m=1$, otherwise they could not be interpreted as probabilities. Since the output has dimension $M$, the layer of the weight matrix $W^{(L)}$ has dimension $M \times U_{L-1}$, and the offset vector $b^{(L)}$ has dimension $M$.

> **Example 6.1: Classification of hand-written digits - problem formulation**

We use the so-called MNIST dataset, which is one of the most well studied datasets in machine learning and image processing. Each data point consists of a $28 \times 28$ pixel grayscale image of the hand-written digit. The digit is size-normalized and centered within a fixed-sized image. Each image is labeled with the digit $0, 1, \dots, 8$, or 9 and it is depicted. In Figure 6.5, a base of 20 points from this dataset is displayed:

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_117_0.png)

In this classification we consider the image as our input $x = [x_1, ..., x_n]^T$. Each input variable $x_i$ corresponds to a pixel in the image. We have $n = 28 \times 28 = 784$ input variables which we flatten into one vector. The value of $x_i$ represents the intensity of that pixel. The intensity-value is within the interval $[0, 1]$, where $x_i=0$ corresponds to a black pixel and $x_i=1$ to a white pixel. The output is class $y_i \in \{0, ..., 9\}$. We mean in total have 10 classes representing the digits. Based on a set of training data $(x_i, y_i)_i$ with images and labels, the goal is to find a good model for the class probabilities:

```
$p(y=m|x) \eqno m=0, ..., 9,$
```

In other words, the probability that an unseen $x$ belongs to the $M=10$ classes. Assume that we would like to use logistic regression to solve this problem with a softmax. That is identical to a neural network with just one layer, that (6.16) $L=1$. The parameters of that model would be:

```
$W^{(1)} \in \mathbb{R}^{784 \times 10} \qquad b^{(1)} \in \mathbb{R}^{10}$,
```

which gives in total $784+10=794$ parameters. Assume that we would like to extend this model to a two-layer neural network with $U=200$ hidden units. That would require two of weight matrices and offset vectors:

```
$W^{(1)} \in \mathbb{R}^{784 \times 200} \qquad b^{(1)} \in \mathbb{R}^{200}, \qquad W^{(2)} \in \mathbb{R}^{200 \times 10} \qquad b^{(2)} \in \mathbb{R}^{10}$,
```

which is a model of $784 \times 200+200+200 \times 10=159000$ parameters. In the next section we will learn how to fit all of these parameters to the training data.

## 6.2 Training a neural network

A neural network is a parametric model and it is trained by the techniques explained in Chapter 5. The parameters in the model are all weight matrices and offset vectors:

```
$\theta = [\text{vec}(W^{(1)})^T \ b^{(1)T} \ \dots \ \text{vec}(W^{(L)})^T \ b^{(L)T}]^T \quad (6.17)$
```

To find values for the parameters $\theta$ we solve an optimization problem of the form:

```
$\hat{\theta} = \arg\min J(\theta) \quad \text{where } J(\theta) = \frac{1}{n} \sum_{i=1}^{n} L(x_i, y_i, \theta). \quad (6.18)$
```

We denote $J(\theta)$ as the cost function and $L(x_i, y_i, \theta)$ as the loss function. The functional form of the loss depends on the task, mainly if it is a regression problem or a classification problem. For regression problems, we typically use the squared error (6.5) as did in linear regression:

```
$\L(x, y, \theta) = (y - f(x))^2, \quad (6.19)$
```

where $f(x; \theta)$ is the output of the neural network. For multiclass classification we analogously use the cross-entropy loss function (3.44) as did for multiclass logistic regression:

```
$\L(x, y, \theta) = -\ln g_y(f(x; \theta)) = -z_y + \ln \sum_{j=1}^{M} e^{z_j}, \quad (6.20)$
```

where $z_j = f_j(x; \theta)$ is the $j$-th output of the last layer before the softmax function $g(z)$. Similar to the method used in (3.44), we use training data $y$ as index to select the correct label for the loss function. Note that both linear and logistic regression can be seen as special cases of neural networks where we have only one layer. Following the discussion in Section 5.2 we could use another loss that suits our needs. These optimization problems cannot be solved in closed form, numerical optimization has to be used. In numerical optimization the parameters are updated in an iterative manner. In deep learning we use various versions of gradient descent:

- Pick an initialization $\theta_0$.
- Update the parameters $\theta_{t+1} = \theta_t - \gamma\nabla_{\theta}(\theta_t)$ for $t = 0, 1, \dots$
- Terminate when some criterion is fulfilled, and take the last $\theta_T$.

Solving the optimization problem (6.18) has two main challenges:

- **Computational challenge 1 - n is large.** The first computational challenge is the big data problem. For many deep learning the number of data points $n$ is very large we cannot afford to compute the exact gradient $\nabla_{\theta}J(\theta)$ at each iteration. In each iteration, we compute an approximation of this gradient by only considering a random subset of the training data, we refer to as a mini-batch. This optimization procedure is called stochastic gradient descent and is further explained in Section 5.5.
- **Computational challenge 2 - dim(theta) is large.** The second computational challenge is that the number of parameters $dim(\theta)$ is very large for deep learning problems. To efficiently compute the gradient $\nabla_{\theta}J(\theta)$ we use the chain rule of calculus and reuse derivatives. This is called backpropagation.

### Backpropagation

The backpropagation algorithm is an important ingredient in all training procedures of neural networks. As outlined above, it is not a complete training algorithm in the sense that it takes data and trains a model. Backpropagation is an algorithm that efficiently computes the cost function and the gradient with respect to all parameters in the neural network. The cost function and its gradient are used in gradient descent algorithms explained in Section 5.5. The parameters in this model are weight matrices and offset vectors. Hence, at each iteration in our gradient search (6.21), we need to find the gradient of the cost function with respect to all elements in these matrices and vectors. To summarize, we want:

```
$dW^{(l)} = \nabla_{W^{(l)}}J(\theta) = \begin{pmatrix} \frac{\partial J}{\partial w^{(l)}_{11}} & \frac{\partial J}{\partial w^{(l)}_{1n}} \\ \vdots & \vdots \\ \frac{\partial J}{\partial w^{(l)}_{m1}} & \frac{\partial J}{\partial w^{(l)}_{mn}} \end{pmatrix} \quad \text{and} \quad db^{(l)} = \nabla_{b^{(l)}}J(\theta) = \begin{pmatrix} \frac{\partial J}{\partial b^{(l)}_{1}} \\ \vdots \\ \frac{\partial J}{\partial b^{(l)}_{m}} \end{pmatrix} \quad (6.22)$
```

for all $l=1, \dots, L$. Note that the cost function $J(\theta)$ here includes the losses in the current mini-batch. When these gradients are computed, we can update the weight matrices and offset vectors:

```
$W^{(l)} = W^{(l)} - \gamma dW^{(l)}, \quad b^{(l)} = b^{(l)} - \gamma db^{(l)} \quad (6.23)$
```

To compute all these gradients efficiently, backpropagation exploits the structure of the model by naively computing derivatives with respect to each layer separately. To do that, backpropagation uses the chain rule of calculus. First, we describe how backpropagation works for a single data point $(x, y)$. In Algorithm 6.1 we later generalize this to multiple data points. The backpropagation algorithm consists of two steps: the forward propagation and the backpropagation. In the forward propagation we simply evaluate the cost function using the neural network presented in Section 6.1. With the input $x$ and evaluating each layer sequentially from one to the last layer $L$, we propagate forward:

```
$q^{(0)} = x, \ z^{(l)} = W^{(l)}q^{(l-1)} + b^{(l)}, \ q^{(l)} = h(z^{(l)}), \ z^{(L)} = W^{(L)}q^{(L-1)} + b^{(L)}, \ J(\theta) = (y - z^{(L)})^2, \quad \text{if regression problem,} \ J(\theta) = -\ln \sum_{j=1}^{M} e^{z^{(L)}_j} \quad \text{if classification problem.} \quad (6.24a) (6.24b) (6.24c) (6.24d)
```

Since we consider only one data point, the cost function $J(\theta)$ will include only one term. When it comes to backpropagation we need to introduce some additional notation, namely the gradient of the cost with respect to the hidden units $z^{(l)}$ and $q^{(l)}$ given by:

```
$dz^{(l)} = \nabla_{z^{(l)}}J(\theta) \quad \text{and} \quad dq^{(l)} = \nabla_{q^{(l)}}J(\theta) \quad (6.25)$
```

In the backpropagation we compute the gradients $dz^{(l)}$ and $dq^{(l)}$ for all layers. We do that recursively in the opposite direction to what we did in the forward propagation, i.e. starting from the last layer $L$ to propagate back to the first layer.
