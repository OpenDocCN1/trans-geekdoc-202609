## 3.A Derivation of the normal equations

The normal equations (3.13)

```
$$\mathbf{X}^T\mathbf{X}\hat{\theta} = \mathbf{X}^T\mathbf{y}. $$
```

can be derived from (3.12) (the scaling $\frac{1}{n}$ does not affect the minimizing argument)

```
$$\hat{\theta} = \arg \min_{\theta} ||\mathbf{X}\theta - \mathbf{y}||_2^2. $$
```

in different ways. We will present one based on (matrix) calculus and one based on geometry and linear algebra.

No matter (3.13) is derived, if $\mathbf{X}^T\mathbf{X}$ is invertible, it (uniquely) gives

```
$$\hat{\theta} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}. $$
```

If $\mathbf{X}^T\mathbf{X}$ is not invertible, (3.13) has infinitely many solutions, which are all equal solutions to the problem (3.12).

## 3 Basic parametric models and a statistical perspective on learning

### A calculus approach

Let

$V(\theta) = ||\mathbf{X}\theta-\mathbf{y}||_2^2 = (\mathbf{X}\theta-\mathbf{y})^T (\mathbf{X}\theta-\mathbf{y}) = \mathbf{y}^T\mathbf{y}-2\mathbf{y}^T\mathbf{X}\theta+\theta^T\mathbf{X}^T\mathbf{X}\theta$, (3.52),

and differentiate $V(\theta)$ with respect to the vector $\theta$,

$$\frac{\partial}{\partial\theta}V(\theta) = -2\mathbf{X}^T\mathbf{y}+2\mathbf{X}^T\mathbf{X}\theta, (3.53),$$

Since $V(\theta)$ is a positive quadratic form, it must be attained at $\theta_0$ where $V(\theta_0)=0$, which characterizes the solution $\theta_0$ as

$$\nabla V(\theta) = 0 \Rightarrow -2\mathbf{X}^T\mathbf{y}+2\mathbf{X}^T\mathbf{X}\theta=0 \Rightarrow\mathbf{X}^T\mathbf{X}\theta=\mathbf{X}^T\mathbf{y}, (3.54),$$

which is the normal equations.

### A linear algebra approach

Denote the $p+1$ columns of $\mathbf{X}$ as $\mathbf{c}_j, j=1,...,p+1$. We first show that $||\mathbf{X}\theta-\mathbf{y}||_2$ is minimized by $\theta$ such that $\mathbf{X}\theta$ is the orthogonal projection of $\mathbf{y}$ onto the (sub)space spanned by the columns $\mathbf{c}_j$ of $\mathbf{X}$, and then show that the orthogonal projection is found by the normal equations.

Let us decompose $\mathbf{y}$ as $\mathbf{y}+\mathbf{y}_\perp$, where $\mathbf{y}_\perp$ is orthogonal to the (sub)space spanned by all columns $\mathbf{c}_j$, and $\mathbf{y}$ is in the (sub)space spanned by all columns $\mathbf{c}_j$. Since $\mathbf{y}_\perp$ is orthogonal to both $\mathbf{y}$ and $\mathbf{X}\theta$, it follows that

$||\mathbf{X}\theta-\mathbf{y}||_2 = ||\mathbf{X}\theta-\mathbf{y}||_2 \ge ||\mathbf{y}_\perp||_2$. (3.55)

and the triangle inequality allows

$||\mathbf{X}\theta-\mathbf{y}||_2 \le ||\mathbf{y}||_2$. (3.56)

This implies that if we choose $\theta$ such that $\mathbf{X}\theta=\mathbf{y}$, the criterion $||\mathbf{X}\theta-\mathbf{y}||_2$ must have reached its minimum. Our $\theta$ must be orthogonal to the (sub)space spanned by all columns $c_j$, meaning

$(\mathbf{X}\theta)^T\mathbf{c}_j=0, j=1,...,p+1$ (3.57)

(remember that two vectors $\mathbf{u},\mathbf{v}$ are orthogonal if their scalar product $\mathbf{u}^T\mathbf{v}$, is 0). Since columns $c_j$ form the matrix $\mathbf{X}$, we can write this compactly

$\mathbf{X}^T\theta=0$, (3.58)

where the right hand side is the $p+1$-dimensional vector zero. This equivalently written as

$$\mathbf{X}^T\theta=\mathbf{y},$$

which is the normal equations.

## 4 Understanding, evaluating and improving the performance

We have so far encountered four different methods for supervised learning, and more are to come in later chapters. We always learn the models by adapting them to training data, and hope that the models thereby give us good predictions also when faced with new, unseen data. But can we really expect that to work? This is a very important question for the practical usefulness of machine learning. In this chapter we will discuss this in a rather general sense, before diving into more advanced in later. By doing so we will unveil some interesting concepts, and also discover practical tools for evaluating, improving, and choosing between different supervised learning methods.

### 4.1 Expected new error $E_{new}$: performance in production

We start by introducing concepts and notation. First, we define an error function $E(\tilde{y}, y)$ which encodes the performance of classification or regression. The error function compares a prediction $\tilde{y}(x)$ to a measured data point $y$, and returns a value (possibly zero) if $\tilde{y}(x)$ is a good prediction of $y$, and a larger value otherwise. Similarly to how we use different loss functions when training a model, we can consider different error functions, depending on what properties of the prediction are most important for the analysis at hand. However, unless otherwise stated, our default choices are misclassification and squared error, respectively:

- Misclassification:
```
$E(\tilde{y}, y) \triangleq \mathbb{I}(\tilde{y} \neq y) = \begin{cases} 0 & \text{if } \tilde{y} = y \\ 1 & \text{if } \tilde{y} \neq y \end{cases} \quad (4.1a)$
```

- Squared error:
```
$E(\tilde{y}, y) \triangleq (\tilde{y} - y)^2 \quad (4.1b)$
```

When we compare the average performance (4.1a), we usually refer to it as the *misclassification rate* (or 1 minus the accuracy) as *accuracy*. The accuracy rate is a natural quantity to consider in classification, for unbalanced or asymmetric problems others might be more important, as we discuss in Section 4.5.

The error function $E(\tilde{y}, y)$ has similarities to a loss function $L(\tilde{y}, y)$. However, we use them differently: A loss is used when learning (or, evaluating, training) a model, whereas we use the error function to *analyze performance* of an already learned model. There are many reasons for choosing $E(\tilde{y}, y)$ and $L(\tilde{y}, y)$, which will come back to soon.

In the end, supervised machine learning helps decide which methods perform well when faced with an endless stream of new, unseen data. Imagine for all real-time recordings of streets that have to be processed by a vision system in a self-driving car it to a customer, or all patients having to be classified by a medical diagnosis system once it is implemented in clinical practice. The performance on unseen data in mathematical terms means either the average error the classifier is right, or how well the regression method predicts. To be able to describe the endless stream of new data, we introduce a *distribution over data $x$*. In many other cases, we consider the output $y$ as a random variable where the input $x$ is fixed. In this chapter, however, we have to think of the input $x$ as a random variable with a probability distribution.
