# Backpropagation

The backpropagation algorithm is an important ingredient in all training procedures of neural networks. As outlined above, it is not a complete training algorithm in the sense that it takes data and trains a model. Backpropagation is an algorithm that efficiently computes the cost function and the gradient with respect to all the parameters in a neural network. The cost function and its gradient are used in the stochastic gradient descent algorithms explained in Section 5.5.

The parameters in this model are weight matrices and offset vectors. Hence, at each iteration in our gradient based search (6.21), we need to find the gradient of the cost function with respect to all elements in these matrices and vectors. To summarize, we want to

```
$$\begin{aligned} dW^{(l)} &= \nabla_{W^{(l)}}J(\theta) = \begin{pmatrix} \frac{\partial J}{\partial w^{(l)}_{11}} & & \frac{\partial J}{\partial w^{(l)}_{1n}} \ \vdots & & \ \vdots \ \frac{\partial J}{\partial w^{(l)}_{m1}} & & \frac{\partial J}{\partial w^{(l)}_{mn}} \end{pmatrix} \quad \text{and} \quad db^{(l)} &= \nabla_{b^{(l)}}J(\theta) = \begin{pmatrix} \frac{\partial J}{\partial b^{(l)}_{1}} \ \vdots \ \frac{\partial J}{\partial b^{(l)}_{m}} \end{pmatrix} \end{aligned}$$ (6.22)
```

for all $l=1, \dots, L$. Note that the cost function $J(\theta)$ here includes the losses in the current mini-batch. When these gradients are computed, we can update the weight matrices and offset vectors

```
$$\begin{aligned} W^{(l)} &= W^{(l)} - \gamma dW^{(l)}, \ b^{(l)} &= b^{(l)} - \gamma db^{(l)} \end{aligned}$$$ (6.23a) (6.23b)
```

To compute all these gradients efficiently, backpropagation exploits the structure of the model by naively computing the derivatives with respect to each layer separately. To do that, backpropagation uses the chain rule of calculus.
First, we describe how backpropagation works for a single data point (x, y). In Algorithm 6.1 we later generalize this to multiple data points. The backpropagation algorithm consists of two steps: the forward propagation and the backpropagation. In the forward propagation we simply evaluate the cost function using the neural network we presented in Section 6.1. With the input x and evaluate each layer sequentially from one to the last layer $L$, we propagate forward:

```
$$\begin{aligned} q^{(0)} &= x, \ z^{(l)} &= W^{(l)}q^{(l-1)} + b^{(l)}, \ q^{(l)} &= h(z^{(l)}), \ z^{(L)} &= W^{(L)}q^{(L-1)} + b^{(L)}, \ J(\theta) &= (y - z^{(L)})^2, \quad \text{if regression problem,} \ J(\theta) &= -\ln \sum_{j=1}^{M} e^{z^{(L)}_j} \quad \text{if classification problem.} \end{aligned}$$$ (6.24a) (6.24b) (6.24c) (6.24d)
```

Since, we consider only one data point, the cost function $J(\theta)$ will include only one term.
When it comes to backpropagation we need to introduce some additional notation, namely the gradient of the cost with respect to the hidden units $z^{(l)}$ and $q^{(l)}$ given by

```
$$\begin{aligned} dz^{(l)} &= \nabla_{z^{(l)}}J(\theta) \ \quad \text{and} \quad dq^{(l)} &= \nabla_{q^{(l)}}J(\theta) \end{aligned}$$$ (6.25)
```

In the backpropagation we compute the gradients $dz^{(l)}$ and $dq^{(l)}$ for all layers. We do that recursively in the opposite direction to what we did in the forward propagation, i.e. starting from the last layer $L$ to propagate back to the first layer.
