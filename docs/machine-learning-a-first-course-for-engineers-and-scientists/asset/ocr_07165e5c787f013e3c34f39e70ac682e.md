The models (10.19) and (10.20) are equivalent, we have not yet accomplished anything with this reformation. The latter forms us a non-linear generalization. Specifically, we can model the distribution of $x$ as the transformation of a Gaussian random variable,

```
$p_{	heta}(z) = N(z|0, I)$,$\n$x = f_{	heta}(z)$,
```

for some parametric function $f_{	heta}$. Note that we saw from a Gaussian, the implied distribution of $x$ is going to be non-Gaussian due to the nonlinear transformation. Indeed, we can model arbitrarily complex distributions in this way considering complex and flexible nonlinear transformations.
The challenge with this approach is how to learn parameters from data. Following the maximum likelihood approach we would like to solve

```
$$\hat{\theta} = \arg max p(\{x_i\}|\theta) = \arg max \sum_{i=1}^n \ln p(x_i|\theta)$
```

Hence, we still need to *evaluate* the likelihood of $x$ to learn the parameters, but this likelihood is not explicitly given in the model specification (10.21).

To make progress, we will start by making the assumption that $f_{	heta}: \mathbb{R}^p \to \mathbb{R}^p$ is an invertible function, with inverse $h_{	heta}(x) = f_{	heta}^{-1}(x) = z$. Note that this $z$ is of the same dimension as $x$. Under this assumption, we can use the change of variables formula for probability density functions to write,

```
$p(x|\theta) = |\nabla h_{	heta}(x)| p_z(h_{	heta}(x))$,
```

where

```
$\nabla h_{	heta}(x) = \begin{pmatrix} \frac{\partial h_{	heta}(x)}{\partial x_1} & \dots & \frac{\partial h_{	heta}(x)}{\partial x_p} \ \vdots & \ddots & \vdots \ \frac{\partial h_{	heta}(x)}{\partial x_1} & \dots & \frac{\partial h_{	heta}(x)}{\partial x_p} \end{pmatrix}$,
```

is the $p \times p$ matrix of all partial derivatives of $h_{	heta}(x)$, referred to as the Jacobian matrix, and $|
abla h_{	heta}(x)|$ is the absolute value of its determinant.
Plugging this expression into the maximum likelihood problem (10.22) we can then learn the model as:

```
$$\hat{\theta} = \arg max \sum_{i=1}^n \ln |\nabla h_{	heta}(x_i)| + \ln p_z(h_{	heta}(x_i))$,
```

where both terms of the loss are given by the model specification (10.21). This provides us with a practical approach for learning the transformation-based generative model from data, although we make the following observations:

+   1. The inverse mapping $h_{	heta}(x) = f_{	heta}^{-1}(x)$ needs to be explicitly available, as it is part of the loss function.

+   2. The Jacobian determinant $|\nabla h_{	heta}(x)|$ needs to be tractable. In the general case, the computational cost associated with (practical algorithms) for computing the determinant of a $p \times p$ matrix scales cubically with $p$. For high-dimensional problems, this results in a prohibitively large computational bottleneck, unless the Jacobian has some special structure that can be exploited for faster computation.
