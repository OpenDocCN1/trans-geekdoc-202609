# 2.3 A rule-based method: Decision trees

To generalize this we still solve the optimization problem (2.6) to compute the split, but choose $Q_t$ in a different way which respects the categorical nature of a classification problem. To this end, we first introduce

```
$$\tilde{\ell}_{lm} = \frac{1}{n_t} \sum_{i\in R_t} \mathbb{i}\{y_i = m\}$
```

as the proportion of training observations in the $t$th region which belongs to the $m$ class. We can then define the *splitting criterion*, that is $Q_t$, based on these classes proportion. One alternative is the misclassification rate

```
$Q_t = 1 - \max_m \tilde{\ell}_{lm}. \quad (2.7a)
```

which is simply the proportion of data points in region $R_t$ which do not belong to the common class. Other splitting criteria are the *Gini index*

and the entropy criterion,

```
$Q_t = - \sum_M \tilde{\ell}_{lm} \ln \tilde{\ell}_{lm}. \quad (2.7c)
```

In Example 2.6 we illustrate how to construct a classification tree using binary splitting and with the entropy as the splitting criterion.
