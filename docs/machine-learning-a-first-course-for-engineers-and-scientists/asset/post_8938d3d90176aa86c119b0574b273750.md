It is not necessary to use kernels in support classification. It is perfectly possible to use the linear kernel $k(x, x') = x^T$ or any other kernel corresponding to a finite dimension $\phi(x)$ in (8.35). That would indeed limit the flexibility of the classifier; the linear kernels limit the classifier to linear decision boundaries, as illustrated in Example 8.5. The possible benefit, however, of not making use of kernels is that it suffices to implement and solve the primal (and not the dual) formulation (8.34), since $\alpha$ is of finite dimension. The support vector property would still be present, but much less since $\alpha$ is not explicitly computed. If using only the primal formulation the representer is not needed, and one could also reduce the $L^2$-regularization with any other regularization method.

## 8.A The representer theorem

We give a lightly simplified version of the representer theorem by Schölkopf, Herbruch, et al. (2001) adapted to our notation and methodology, without reducing the kernel Hilbert space measure. It is stated in a regression-like setting, when $y(x) = \theta^T\phi(x)$, and we discuss how it also applies to classification.

**Theorem 8.1 (The representer theorem)** *$y(x) = \theta^T\phi(x)$ with nonlinear feature transformations $\phi(x)$ and $\theta$ to be learned from training data $(x_i, y_i)_{i=1}^n$ (The dimensionality of $\theta$ and $\phi$ does not have to be finite). Furthermore, let $L(y, y')$ be any arbitrary function and $h : [0, \infty] \to \mathbb{R}$ a strictly increasing function. Then minimize each over the regularized cost*

$$\sum_{i=1}^{n} L(y_i, \theta^T\phi(x_i)) + h(||\phi(x_i)||^2) \quad (8.36)$$

can be written as $\theta = \Phi(X)^T\alpha$ (or equivalently, $y(x) = K(x, X)\alpha$) with $n$-dimensional vector $\alpha$.

**Proof.** For a given $X$, $\alpha$ can be decomposed into one part $\Phi(X)^T\alpha$ that lies in the span of $\Phi(X)$ and one part $v$ orthogonal to it, that is, $\theta = \Phi(X)^T\alpha + v$ with $v$ being orthogonal to all rows $\phi(x_i)$.

For $x_i$, in $(x_i, y_i)_{i=1}^n$ it holds that

$$\tilde{y}(x_i) = \theta^T\phi(x_i) = (\Phi(X)^T\alpha + v)^T\phi(x_i) = \alpha^T\Phi(X)\phi(x_i) + v^T\phi(x_i) = 0 \quad (8.37)$$

The first term in (8.36) is independent of $v$. Concerning the second term in (8.36) we have

$$h(||\phi(x_i)||^2) = h(||\Phi(X)^T\alpha + v||^2) = h(||\Phi(X)^T\alpha||^2 + ||v||^2) \ge h(||\Phi(X)^T\alpha||^2). \quad (8.38)$$

where the second inequality follows because $h$ is increasing with respect to $v$. The equation (8.38) implies that the minimum of (8.36) is found for $v = 0$, which follows the theorem.

## 8 Nonlinear input transformations and kernels

The assumption that the model is linear in both parameters and features, $\theta^T \phi(\mathbf{x})$, is indeed crucial for Theorem 8.1. That is not an issue when we consider models of linear regression type. Not all models are possible to formulate as linear, but logistic regression can be treated as the so-called log-odds $\theta^T \phi(\mathbf{x}) = \ln\left(\frac{p(\mathbf{x})}{1-p(\mathbf{x})}\right)$, and the representer theorem is furthermore applicable to it. Furthermore support vector classification is also a linear model if we consider the function $c(\mathbf{x}) = e^{\theta^T \phi(\mathbf{x})}$ rather than the predicted label $\hat{y}(\mathbf{x})$.

## 8.B Derivation of support vector classification

We will derive (8.35) from (8.34), by first reintroducing it into an equivalent formulation using slack variables $\xi = [\xi_1 \dots \xi_n]^T$,

$$\min_{\theta} \frac{1}{n} \sum_{i=1}^n \max(0, 1-y_i\theta^T \phi(x_i)) + \lambda||\theta||^2 \quad (8.39a)$$
subject to $$\xi_i \ge 1-y_i\theta^T \phi(x_i), \quad (8.39b)$$
$$\xi_i \ge 0. \quad (8.39c)$$

The Lagrangian for (8.39) is then

$$L(\theta, \xi, \gamma) = \frac{1}{n} \sum_{i=1}^n \xi_i^2 + \lambda||\theta||^2 - \sum_{i=1}^n \beta_i(y_i+\theta^T \phi(x_i)) - \sum_{i=1}^n \gamma_i\xi_i \quad (8.40)$$

with Lagrange multipliers $\beta_i \ge 0$ and $\gamma_i \ge 0$. According to Lagrange duality, instead of solving (8.34) we can minimize (8.40) with respect to $\theta$ and maximize it with respect to $\beta$ and $\gamma$. Two necessary conditions for optimality of (8.40) are

$$\frac{\partial L}{\partial \theta}(\theta, \xi, \gamma) = 0, \quad (8.41a)$$
$$\frac{\partial L}{\partial \xi}(\theta, \xi, \gamma) = 0. \quad (8.41b)$$

In more detail (8.41a) gives using that $|\theta||^2 = \theta^T \theta$, and hence $\frac{\partial}{\partial \theta}|\theta||^2=2\theta$

$$\theta = \frac{1}{2\lambda} \sum_{i=1}^n y_i\beta_i\phi(x_i), \quad (8.41c)$$

and (8.41b) gives

$$\gamma_i = \frac{1}{n}\beta_i, \quad (8.41d)$$

Inserting (8.41c) and (8.41d) into (8.40) and scaling it with $\frac{1}{2}$, we seek to maximize

$$\bar{L}(\beta) = \sum_{i=1}^n \frac{1}{2\lambda}y_i\beta_i^2 - \sum_{i,j=1}^n \frac{1}{4\lambda^2}\beta_i\beta_j y_iy_j\phi^T(\mathbf{x}_j). \quad (8.42)$$

(8.42) we have the constraint $0 \le \beta_i \le \frac{1}{n}$, where the upper bound on $\beta_i$ comes from (8.41d) and the fact that $y_i \ge 0$. With $\alpha_i = \frac{y_i\beta_i}{2}$, we see (if noting that $y_i=1$ since $y_i \in \{-1, 1\}$) that maximizing (8.42) is equivalent to solving

$$\min_{\alpha} \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i\alpha_j\phi^T(\mathbf{x}_i) - \sum_{i=1}^n y_i\alpha_i \quad (8.43)$$

or, using a matrix notation,

$$\min_{\alpha} \frac{1}{2}\alpha^T K(\mathbf{X},\mathbf{X})\alpha - \alpha^T\mathbf{y}. \quad (8.44)$$

Finally noting that (8.41c) we have

$$sign(\theta^T\phi(\mathbf{x}_*)) = sign\left(\frac{1}{2\lambda}\sum_{i=1}^n y_i\beta_i\phi^T(\mathbf{x}_*)\right) = sign(\alpha^T K(\mathbf{X},\mathbf{x}_*)). \quad (8.45)$$

and we have arrived at (8.35).

## The Bayesian approach and Gaussian processes

So far, learning a parametric model has amounted to finding a parameter value $\hat{\theta}$ that best fits the training data. With the Bayesian approach (also called the probabilistic approach) learning amounts to instead finding the distribution of parameter values $\theta$ conditioned on the observed training data $\mathcal{T}$, is $p(\theta|\mathcal{T})$. With the Bayesian approach also the prediction is a distribution $p(y_*|x_*)$, instead of a single value. Before we enter the details, let us say that on a theoretical (or even philosophical) level the Bayesian approach is rather different from what we have previously seen in this book. It opens up for a family of new, versatile and practically useful methods, and the extra effort required to understand this somewhat different approach pays off and provides another perspective on machine learning. As the Bayesian approach makes this chapter heavier on the probability theory side.

## 9.1 The Bayesian idea

In the Bayesian approach, $\theta$ are consistently treated as random variables. Learning in the Bayesian settings amounts to computing the distribution of $\theta$ on training data $\mathcal{T}=\{x_i, y_i\}_{i=1}^n$. Since we observe $y$, not $X$, we denote this as $p(\theta|y)$. First, we use the rule of conditioning to factorize the joint distribution into two factors $p(y,\theta) = p(y|\theta)p(\theta)$. Using the rule of conditioning once more, conditioning on $y$ uses Bayes' theorem,

$$p(\theta|y) = \frac{p(y|\theta)p(\theta)}{p(y)}, \quad (9.1)$$

which is why this is called the Bayesian approach. The left hand of (9.1) is the sought distribution $p(\theta|y)$. The right side of (9.1) contains several elements: $p(y|\theta)$ is the distribution of observations in various models, and $p(\theta)$ is the distribution of $\theta$ before any observations are made (that is, not on training data). By nature $p(y)$ cannot be computed, but by laws of probability, it can be rewritten as

$$p(y) = \int p(y|\theta)p(\theta)d\theta, \quad (9.2)$$

In other words, learning a parametric model (in the Bayesian framework) amounts to conditioning $\theta$ on $y$, that is, $p(\theta|y)$. After being learned, a model can be used to compute predictions. This is a matter of computing a distribution $p(y_*|x_*)$ (rather than a point prediction) for a test input $x_*$, since $\theta$ is a random variable connected to $p(\theta|y)$ via the marginalization

$$p(y_*|x_*) = \int p(y_*|\theta)p(\theta|y)d\theta. \quad (9.3)$$

We will start this chapter by giving a general introduction to the Bayesian idea, which we will further extend to non-parametric Gaussian process.
