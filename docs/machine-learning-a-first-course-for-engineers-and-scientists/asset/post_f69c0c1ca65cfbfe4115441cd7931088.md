
## 4.4 The bias-variance decomposition of $E_{new}$

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_70_0.png)

**Figure 4.8:** The bias-variance decomposition of $E_{new}$, instead of the training error-generalization decomposition in Figure 4.3. Low model complexity means high bias. The more complicated the model, the more it adapts to (noise) in the training data, and the higher the variance. The irreducible error is independent of the particular choice of model and is therefore constant. The problem of achieving a small $E_{new}$ by selecting a suitable model complexity level is often called the bias–variance tradeoff.

![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_70_1.png)

**Figure 4.9:** The typical relationship between bias, variance and the size $n$ of the training dataset. The bias is (approximately) constant, whereas the variance decreases as the size of the training dataset increases. This figure can be compared with Figure 4.6.

The squared bias is more of a property of the model than that of the training dataset, and we may think$^4$ of the bias term as independent highly with $n$. The variance, on the other hand, varies highly with $n$. $E_{new}$ typically decreases as $n$ increases, and the reduction in $E_{new}$ is largely because of the reduction in variance. Intuitively, the more data, the more information we have about the parameters, resulting in a smaller variance. This is summarized by Figure 4.9, which can be compared to Figure 4.6.

> $4$This is not exactly true. The average model $f$ might be different if all datasets (which we average over) contain $n=2$ or $n=100000$ data points, but we neglect that effect here.

## 4 Understanding, evaluating and improving the performance

### Example 4.3: The bias–variance tradeoff for $L^2$ regularized linear regression

Let us consider a simulated regression example. We let $p(x,y)$ follow from $x \sim \mathcal{U}[0,1]$

```
$y = 5 - 2x + \varepsilon, \quad \varepsilon \sim N(0,1), \quad (4.20)
```

We let the training data of size $n = 10$ data points. We now try to model the data using linear regression with a 4th order polynomial

```
$y = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3 + \beta_4x^4 + \varepsilon. \quad (4.21)
```

Since (4.20) is a case of (4.21) and the error corresponds to Gaussian noise, we have zero bias for this model if we train it using squared error loss. However, learning 5 parameters from only 10 data points leads to very high variance, which is why trade the model with squared error loss and $L^2$ regularization, which will decrease the variance (but increase the bias). The more regularization (bigger $\lambda$), the less bias and variance.

Since in this example we can run the experiment multiple times and estimate the bias and variance terms (since we can simulate as training and test data as needed). We plot them in Figure 4.10 using the same style as Figures 4.3 and 4.8 (note the reversed x-axis: $\lambda$ corresponds to a higher complexity). For this problem the optimal value of $\lambda$ would have been about 0.7 since $E_{new}$ attains its minimum. Finding this $\lambda$ is a typical estimate of the bias-variance tradeoff.

### Connections between bias, variance and the generalization gap

The bias and variance are well defined properties, but often intangible in practice since they are defined in terms of $\mathbf{p}(x,y)$. In practice, we mostly have an estimate of the generalization gap (for example as $E_{hold-out}-E_{train}$), whereas the bias and variance requires additional tools for being estimated$^5$. It is therefore interesting to explore what $E_{train}$ the generalization gap says about the bias and variance.

Consider the regression problem. As the squared error is used both as error function and function that gleams during training. We can then write

```
$$\sigma^2 + \beta^2 = \mathbb{E}_* [(f(\mathbf{x}^*) - \mathbf{y}^*)^2] = \frac{1}{n} \sum_{i=1}^n (f(\mathbf{x}_i) - \mathbf{y}_i)^2 = \frac{1}{n} \sum_{i=1}^n (\hat{f}(\mathbf{x}_i;\mathcal{T}) - \mathbf{y}_i)^2 = \mathbb{E}_{train}. \quad (4.22)
```

## 4.4 The bias-variance decomposition of $E_{new}$

In the approximate equality, we approximate the expected value by a sample average using the training data points. If furthermore assuming that $\hat{y}$ can be $f$, with the above assumption of having the squared error loss and function of $\hat{y}$ finding the global minimum, we have the inequality in the next step. Remembering that $E_{new} = \sigma^2 + \text{bias}^2 + \text{variance}$, and allowing ourselves to write $E_{new} - E_{train} = generalization gap$, we have

```
$generalization gap \ge variance, \quad (4.23a)$
$E_{train} \ge \text{bias}^2 + \sigma^2. \quad (4.23b)$
```

The assumptions in this derivation are not met in practice, but it gives us some rough idea. For $E_{new}$ is obtained. As we discussed, the choice of method is crucial for $E_{new}$. The one-dimensional scale in Figure 4.8 and the notion of bias-variance tradeoff is a simplified picture; decreased bias does not always increased variance, and vice versa. However, to contrast the decomposition of $E_{new}$ into training error and generalization gap, the bias and variance decomposition can show why $E_{new}$ decreases for different methods: sometimes, the superiority of one method over other can be attributed to either a lower bias or a lower variance.

A sample (and useless) way to increase the variance without decreasing the bias in linear regression, is to first alter the parameters using normal equations and then add zero-mean noise to them. The error does not affect the bias, but increases the variance and leaves the average model $\hat{f}$ unchanged. This would be pointless in practice since it increases $E_{new}$, but it illustrates the fact that increased variance does not automatically leads to decrease bias.

A much useful way of dealing with bias and variance is the meta-method called bagging, discussed in Chapter 7. It makes several copies (an ensemble) of a base model, each trained on a slightly different version of the training dataset. By bagging over many base models, it reduces the variance, but the bias remains unchanged. By bagging the base model, the variance is decreased without significantly increasing the bias, often resulting in a decrease in $E_{new}$.

To conclude, the world is more complex than the one-dimensional model complexity used in Figure 4.3 and 4.8, which we illustrate by Example 4.4.
