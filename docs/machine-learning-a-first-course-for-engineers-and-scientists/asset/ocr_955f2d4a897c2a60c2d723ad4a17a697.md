kinetics. The model is given by

```
y = \frac{\theta_1 x}{\theta_2 + x} = f_{	heta}(x)
```

where $y$ corresponds to a reaction rate and $x$ a substrate concentration. The model is parameterized by the maximum reaction rate $	heta_1 > 0$ and the so called Michaelis constant of the enzyme $	heta_2 > 0$. $f_{	heta}(x)$ depends linearly on the parameter $	heta_2$ appearing in the denominator.
Typically the model is written as a deterministic relationship between the noise term $\epsilon$, but here we include the noise as an error term for our statistical regression framework.

In the example the parameters $	heta_1$ and $	heta_2$ have physical interpretations and are restricted to be positive. Thus, $\Theta$ represents the positive quadrant in $\mathbb{R}^2$. However in learning we typically learn "black box" which is adapted to fit the training data as well. For simplicity we will assume $\Theta = \mathbb{R}^d$, meaning $	heta$ is a $d$-dimensional vector of real-valued parameters. The archetype of such black-box models are neural networks, which we will discuss in detail in Chapter 6. If we need to restrict a parameter value in some way, to be positive, then this can be achieved by a suitable transformation of that parameter. For instance, in the Michaelis-Menten equation we can replace $	heta_1$ and $	heta_2$ with $\exp(\theta_1)$ and $\exp(\theta_2)$, respectively, where the parameters are allowed to take arbitrary real values.

Note that the likelihood corresponding to the model (5.1) is governed by the noise term $\epsilon$. As long as we stick with the assumption that the noise is additive and Gaussian with mean zero and variance $\sigma_{\epsilon}^2$, we obtain a Gaussian likelihood function

```
$p(y|\mathbf{x};\theta) = N(f_{	heta}(\mathbf{x}), \sigma_{\epsilon}^2). \quad (5.2)
```

The only difference between this expression and the likelihood used in the linear regression model (3.18) is that the mean of the Gaussian distribution is now given by the arbitrary nonlinear function $f_{	heta}(\mathbf{x})$.
Nonlinear classification models can be constructed in a very similar way, as a generalization of the logistic regression model (3.29). In binary logistic regression we compute the logit $z=\theta^T\mathbf{x}$. The probability of the positive class, is $p(y=1|\mathbf{x})$ obtained by mapping the logit value through the logistic function, $h(z)=\sigma(z)$. To turn this into a nonlinear classification model we can replace the expression for the logit with $z=f_{	heta}(\mathbf{x})$ for some arbitrary real-valued nonlinear function $f_{	heta}$. Hence, the logistic regression model becomes

```
$g(z) = \frac{e^{z}}{1+e^{z}}. \quad (5.3)
```

Analogously, we can construct a multiclass classifier by generalizing the multiclass logistic regression model (3.42). That, we compute a vector of logits $z=[z_1, z_2, ..., z_M]^T$ according to $z=f_{	heta}(\mathbf{x})$ where $f_{	heta}$ is some arbitrary function that maps to an $M$-dimensional real-valued vector $\mathbf{x}$. Propagating this logit vector through the softmax function results in a nonlinear model for the conditional class probabilities, $p_{	heta}(\mathbf{x})=\softmax(f_{	heta}(\mathbf{x}))$. We will return to nonlinear classification models of this form in Chapter 6, where we use neural networks to construct the function $f_{	heta}$.
