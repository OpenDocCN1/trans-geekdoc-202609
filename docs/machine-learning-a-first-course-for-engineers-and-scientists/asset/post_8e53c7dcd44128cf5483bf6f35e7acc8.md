
## 3.1 Linear regression

Since the logarithm is a monotonically increasing function, maximizing the log-likelihood (3.19) is equivalent to maximizing the likelihood itself. Pushing (3.18) and (3.19) together, we get

```
$$\ln p(\mathbf{y} | \mathbf{X}; \boldsymbol{\theta}) = -\frac{n}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(\theta^T\mathbf{x}_i - y_i)^2.$$$ (3.20)
```

Removing terms and factors independent of $\boldsymbol{\theta}$ does not change the argument, and we see that we can rewrite (3.15) as

```
$$\hat{\boldsymbol{\theta}} = \arg\max p(\mathbf{y} | \mathbf{X}; \boldsymbol{\theta}) = \arg\max \sum_{i=1}^{n}(\theta^T\mathbf{x}_i - y_i)^2 = \arg\min \frac{1}{2}\sum_{i=1}^{n}(\theta^T\mathbf{x}_i - y_i)^2.$$$ (3.21)
```

This is indeed linear regression with the least squares cost (the cost function implied by the squared loss function (3.10)). Hence, using the squared error loss is equivalent to assuming a Gaussian noise distribution in the maximum likelihood formulation. Other assumptions on $\varepsilon$ leads to other loss functions, as we will discuss in Chapter 5.

## Categorical input variables

The regression problem is characterized by a numerical output $y$, and inputs $x$ of arbitrary type. We have, however, only discussed the case of numerical inputs so far. To see how to handle categorical inputs in the linear regression model, assume that we have an input variable that only takes two different values. We refer to these values as A and B. We can create a dummy variable $x$ as

```
$x = \begin{cases} 0 & \text{if A},\1 & \text{if B},\end{cases}$$$ (3.22)
```

and use this in any supervised machine learning method as if it was numerical. For linear regression, this effectively gives us a model which looks like

```
$y = \theta_0 + \theta_1x + \varepsilon = \begin{cases} \theta_0 + \varepsilon & \text{if A},\theta_0 + \theta_1 + \varepsilon & \text{if B}.\end{cases}.$$$ (3.23)
```

The model allows us to learn and predict different values depending on whether the input is A or B. If the categorical variables take more than two values, let us say A, B, C, and D, we can make a so-called one-hot encoding by constructing a four-dimensional vector

```
$$\mathbf{x} = [x_A, x_B, x_C, x_D]^T$$$ (3.24)
```

where $x_A = 1$ if A, $x_B = 1$ if B, and so on. That is, only one element of $\mathbf{x}$ will be 1, the rest are 0. Again, this construction can be used for any supervised machine learning, and is not restricted to linear regression.

## 3 Basic parametric models and a statistical perspective on learning

## 3.2 Classification and logistic regression

After presenting a parametric method for solving the regression problem, we now turn our attention to classification. As we will see, with a modification of the linear regression model we can apply it to the classification problem as we will, however at the cost of most not being able to use the convenient normal equations. Instead we have to resort to numerical optimization for learning the parameters of the model.

### A statistical view of the classification problem

Supervised machine learning amounts to predicting the output from the input. With a statistical perspective, classification amounts to predicting the conditional class probabilities

```
p(y = m|x) (3.25)
```

where $y$ is the output (1, 2, . . . or M) and $x$ is the input. In words, $p(y = m|x)$ describes the probability for class $m$ given that we know the input $x$. Talking about $p(y|x)$ implies we think about the class label $y$ as a random variable. Why? Because we choose to model the real world, from where data originates, as a certain amount of randomness (like the error $\varepsilon$ in regression). Let illustrate with an example.

> **Example 3: Describing behavior using probabilities**
> We want to construct a model that can predict preferences ($y = y$, the categorical output) for population groups ($x=$ the input). However then we have to face the fact that not everyone in a certain population group will vote for the same party. We can then predict $y$ as a random variable which follows a probability distribution. If we know the vote count in the group of 45 year old women ($x = x$) is 13% for the certain party, 39% for the turquoise party and 48% for the purple party (here we have M=3), we could describe it as:
> $p(y = cerise party | x = 45 year old women) = 0.13,$
> $p(y = turquoise party | x = 45 year old women) = 0.39,$
> $p(y = purple party | x = 45 year old women) = 0.48.$

In this way, the probabilities $p(y|x)$ describe the non-trivial fact that

- (a) all 45 year old women do not vote for the same party,
- (b) the choice of party does not appear to be completely random among 45 year old women; the purple party is the most popular, and the cerise party is the least popular.

Thus, it is useful to have a classifier which predicts not only a class $y$ (one party), but a distribution over classes. We now aim to construct a classifier which can predict not only classes but also the class probabilities $p(y|x)$. For binary classification problems (M=2, and $y$ is either 1 or -1), we learn a model $g(x)$

```
$p(y = 1 | x)$ is modeled by $g(x)$. (3.26a)
```

By the laws of it, it holds that $p(y = 1|x) + p(y = -1|x) = 1$, which means

```
$p(y = -1 | x)$ is modeled by $1 - g(x)$. (3.26b)
```

Since $g(x)$ is a model for a probability, it is natural that $0 \le g(x) \le 1$ for any $y$. We will see how this constraint can be enforced.

> We use the notation $p(y|x)$ to denote probabilities (y is discrete) or as densities (continuous).

For the multiclass problem, instead let the classifier return a vector-valued function $g(x)$, where

```
$$\begin{aligned} p(y=1|x) &= g_1(x) \\ p(y=2|x) &= g_2(x) \\ \vdots &= g(x) \\ p(y=M|x) &= g_M(x) \end{aligned}$$$ (3.27)
```

In words, each element $g_m(x)$ corresponds to the conditional probability $p(y=m|x)$. Since $g$ models a probability vector, we require that each $g_m(x) \ge 0$ and $\|g(x)\|_1 = 1$ for any $x$.

## The logistic regression model for binary classification

We will now introduce the logistic regression model, which is one possible method of modeling class probabilities. Logistic regression can be viewed as a linearization of the regression model so that it fits the classification (instead of the problem). We wish to learn a function $g(x)$ that approximates the probability of the class. To this end, we start with the logistic regression model which, with no noise term, is given by

```
$z = \theta_0 + \theta_1x_1 + \theta_2x_2 + \dots + \theta_px_p = \theta^Tx.$ (3.28)
```

This is a mapping which takes $x$ and returns $z$, which in this context is called *logit*. $z$ takes values on the entire real line, whereas we need a function that returns a value in the interval $[0, 1]$. The key idea of logistic regression is to 'squeeze' $z$ from (3.28) to the interval $[0, 1]$ by using the function $h(z) = \frac{e^z}{1+e^z}$, see Figure 3.4. This results in

```
$g(x) = \frac{e^z}{1+e^z}.$$ (3.29a)
```

which is restricted to $[0, 1]$ and can be interpreted as a probability. This (3.29a) is the logistic regression model for $p(y=1|x)$.

```
$1-g(x) = 1-\frac{e^z}{1+e^z} = \frac{e^{-z}}{1+e^{-z}}.$ (3.29b)
```

In a nutshell, the logistic regression model is linear regression appended with the logistic function. This is for the somewhat confusing name but that logistic regression is a method for classification. The reason for why there is no noise term $\varepsilon$ in (3.28), as we had in the linear regression model, is that the randomness in classification is statistically modeled by the class probability construction $p(y=m|x)$ of additive noise $\varepsilon$.

## 3 Basic parametric models and a statistical perspective on learning

As linear regression, we have a model (3.29) which contains unknown parameters $\theta$. Logistic regression is also a parametric model, and we need to learn the parameters from training data. How this can be done is the topic for the next section.

## Learning the logistic regression model by maximum likelihood

By using the function, we have transformed linear regression (a model for regression problems) into logistic regression (a model for classification problems). The price to pay is that we will not be able to use the convenient normal equations for learning $\theta$ (as we could for linear regression using the squared error), due to the nonlinearity of the logistic function. In order to derive a principled way of learning $\theta$ in (3.29) from training data $\mathcal{T}=\{x_i, y_i\}_{i=1}^n$, we start with the maximum likelihood approach. From a maximum likelihood perspective, learning a classifier amounts to solving

```
$$\hat{\theta} = \arg \max p(y|x; \theta) = \arg \max \sum_{i=1}^n \ln p(y_i|x_i; \theta).$$$ (3.30)
```

where, similar to linear regression (3.19), assuming that the data points are independent and we consider the likelihood of the function for numerical reasons. We have also added $\theta$ explicitly to the notation to emphasize the dependence on the model parameters. Remember that our model of $p(y|x;\theta)$ is $g(x;\theta)$, which gives

```
$$\ln p(y_i|x_i; \theta) = \begin{cases} \ln g(x_i; \theta) & \text{if } y_i = 1, \ln(1 - g(x_i; \theta)) & \text{if } y_i = -1.\end{cases}$$$ (3.31)
```

It is common to turn the maximization problem (3.30) into an equivalent minimization problem by using the negative-likelihood as cost function, $J(\theta) = -\frac{1}{n} \sum \ln p(y_i|x_i; \theta)$, that is

```
$J(\theta) = -\frac{1}{n} \sum_{i=1}^n \begin{cases} -\ln g(x_i; \theta) & \text{if } y_i = 1, -\ln(1 - g(x_i; \theta)) & \text{if } y_i = -1.\end{cases}.$$ (3.32)
```

The loss function in the expression above is the cross-entropy loss. It is not specific to logistic regression, but can be used for any classifier that predicts class probabilities $g(x;\theta)$.

However, we will now consider specifically the logistic regression model, for which we can write out the cost function (3.32) in more detail. In so, the particular choice of labeling $\{-1, 1\}$ turns out to be convenient. For $y_i$ we can write

```
$g(x_i; \theta) = \frac{e^{\theta x_i}}{1 + e^{\theta x_i}}, \frac{e^{\theta x_i}}{1 + e^{\theta x_i}}.$$ (3.3a)
```

and for $y_i = -1$

```
$1 - g(x_i; \theta) = \frac{1}{1 + e^{\theta x_i}}, \frac{1}{1 + e^{\theta x_i}}.$$ (3.3b)
```

Here, we get the same expression in both cases and can write (3.32) compactly as

```
$J(\theta) = -\frac{1}{n} \sum_{i=1}^n \frac{e^{\theta x_i}}{1 + e^{\theta x_i}} -\sum_{i=1}^n \frac{1}{1 + e^{\theta x_i}} = -\sum_{i=1}^n \ln [1 + e^{\theta x_i}].$ (3.34)
```
