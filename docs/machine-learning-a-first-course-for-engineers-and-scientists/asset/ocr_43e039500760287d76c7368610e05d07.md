question: Can we make a mapping that goes in the other direction? That is, an encoder mapping $z = h_	heta(x)$ which takes a data point $x$ (lower-dimensional) latent representation.

For generative adversarial networks is far from trivial, $f_	heta$ in general is a very complicated non-invertible function and there is no simple way of reversing this mapping. For normalizing, that we also discussed in Section 10.3, reversing the decoder mapping is in fact possible, since for these models we assumed that $f_	heta$ has an inverse $h_	heta = f_	heta^{-1}$. However, this requires restrictions on the model and in particular that dimensions of $x$ and $z$ are same. Hence, such mappings are not useful for dimensionality reduction.

In an auto-encoder we tackle this by relaxing the requirement that $h_	heta$ is an exact inverse of $f_	heta$. Instead, we learn the encoder and decoder mappings via the objective that $f_	heta(h_	heta(x)) = x$, enforcing the dimensionality reduction through the model architecture. Specially, we assume that:

+   Encoder $h_	heta: \mathcal{R}^p ightarrow \mathcal{R}^q$ maps a data point to a latent representation,
Decoder $f_	heta: \mathcal{R}^q ightarrow \mathcal{R}^p$ maps a latent representation back to a point in data.

Important, the dimension of the latent representation is expected to be smaller than $p$. Often, the encoder and decoder parameters functions are constructed separately and they are allowed to depend on different parameters. However, for brevity we group both the encoder and decoder parameters into the identity parameter $	heta$.

If we take a data point $x$, we can compress its latent representation using the encoder as $z = h_	heta(x)$. If we feed this representation through the decoder, we obtain a reconstruction $\hat{x} = f_	heta(z)$ of the data point. In general, this will not be identical to $x$, because we have forced the encoder to compress the data into a lower-dimensional representation in the first step. This will typically result in a loss of information that the decoder is unable to compensate for. However, we can never traverse the model to approximate the identity mapping as closely as possible by minimizing the reconstruction error over the training data. For instance, using the squared error we learn the training objective,

```
$$\min_	heta \sum_{i=1}^n \|x_i - f_	heta(h_	heta(x_i))\|^2$$
```

It is important that $q < p$ for this method to be interesting, otherwise we would just end up learning an identity mapping. However, when $q$ is smaller than $p$, then it will encourage the encoder to compress the data into a lower dimensional vector, while retaining much of the actual information as possible to enable accurate reconstruction. In other words, the encoder is forced to learn a useful representation of data.

When using networks to parameterize the encoder and decoder mappings, the autoencoder can also be viewed as a neural network, with a “bottleneck layer” in the middle to represent the latent code. We illustrate this in Figure 10.10.

One issue when using encoders is the risk of memorizing the training data. To illustrate this, assume that $q=1$ so that we have a scalar latent code $z$. For any realistic problem, this might be insufficient to represent the actual content in complex data like $x$. However, the auto-encoder could learn to map any data point $x_i$ to the value $z_i=i$, and then learn to reconstruct the data point exactly based on this unique identifier. This will never happen exactly in practice, but we can still suffer to some extent from this memorization effect. The model might learn more from the training data in the parameter vector $	heta$, which helps us to minimize the reconstruction error, instead of learning a useful and generalizable representation. This is a potential issue when the model is very flexible (high-dimensional $	heta$) so that it has the capacity of memorizing the data.

Various extensions to the basic auto-encoder have been proposed in the literature, among other things, combat memorization. Regularization is one approach. For instance, it is possible to learn a probabilistic prior on the distribution of the latent representation, effectively bridging the gap between auto-encoders and generative models.
