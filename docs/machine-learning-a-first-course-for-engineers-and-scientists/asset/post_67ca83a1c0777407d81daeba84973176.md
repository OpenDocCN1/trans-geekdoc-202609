## 10 Generative models and learning from unlabeled data

### Learn the GMM

**Data:** Partially labeled training data $\mathcal{T} = \{{\mathbf{x}_i, \mathbf{y}_i\}_{i=1}^n, \{\mathbf{x}_j\}_{j=n+1}^m\}$ with output classes $m=1, \dots, M$

**Result:** Gaussian mixture model

1. Compute $\tilde{\theta} = \{\tilde{\mu}_m, \tilde{\Sigma}_m\}_{m=1}^M$ according to (10.3), using only the labeled data $\{\mathbf{x}_i, \mathbf{y}_i\}_{i=1}^n$
2. repeat
   3. For each $\mathbf{x}$ in $\{\mathbf{x}_i\}_{i=n+1}^m$, compute the prediction $p(\mathbf{y} \mid \mathbf{x}, \theta)$ using (10.5) with current parameter estimates $\tilde{\theta}$
   4. Update the parameter estimates $\theta \leftarrow \{\tilde{\mu}_m, \tilde{\Sigma}_m\}_{m=1}^M$ according to (10.10)
5. until convergence

### Method 10.2: Semi-supervised learning of the GMM

This method provides a coherent framework for reasoning about missing labels. Indeed, we have developed a method for the semi-supervised setting which is a direct generalization of the supervised method. In the next section we will take this step further and apply the same procedure to the fully unsupervised case (by assuming that *all* labels are missing). In all cases the method is numerically solving the maximum likelihood problem.

Another explanation for why generative models can be useful in the semi-supervised setting is that it provides a richer description of the data than a discriminative model. A discriminative model of $p(\mathbf{y} \mid \mathbf{x})$ encodes information like 'if $\mathbf{x}$ then $y$', but it does not contain explicit logic for the labels. The generative model, on the other hand, contains additional assumptions on $p(\mathbf{x})$, that can be useful when handling the semi-supervised problem. For instance, the GMM encodes the information that inputs belonging to a class should have a Gaussian distribution and thereby belong to a cluster. The parameters are then inferred from these clusters where both labeled and unlabeled data points contribute.

The generative paradigm provides a robust approach for modeling both labeled and unlabeled data. The downside, however, is that it requires assumptions on the data distribution and the result can be misleading if these assumptions are not fulfilled. Furthermore, in many scenarios the input $\mathbf{x}$ is extremely high-dimensional and it then can be difficult to design a model for it. For instance, assuming that an image is represented by pixels a Gaussian distribution is not a good way. We will return to this in Section 10.3 where we discuss how generative models of such high-dimensional data can be constructed using neural networks.

### Cluster analysis

In supervised learning the objective is to learn a model for input-output relationship based on examples where training data consists of both inputs and (labeled) outputs. However, we saw above that it is possible to relax the assumption that all inputs are labeled. In semi-supervised learning we mix labeled and unlabeled data and learn a model which makes use of both sources of information. In unsupervised learning we take one step further and assume that all data points are unlabeled. Given data $\mathcal{T} = \{\mathbf{x}_i\}_{i=1}^n$, the objective is to build a model that can be used to reason about key properties of the data (or rather the generating process). From the perspective of generative modeling, we wish to build a model of the distribution $p(\mathbf{x})$.

In this section we will build on the clustering problem considered as unsupervised learning. Clustering amounts to finding groups of similar values in the data space and associating these with a discrete set of clusters. From a mathematical and methodological point of view, clustering is intimately related to classification. Indeed, we assign a discrete index to each cluster and then say all values in the $m$th cluster are $y = m$. The difference between classification and clustering is that we wish to learn the clusters based solely on the $\mathbf{x}$ values without any labels. Still, as we show below, one way to address this problem is to use the same GMM and EM algorithm as has been used in the context of semi-supervised learning.

From a more conceptual point of view there are some differences between classification and clustering. In classification we well know what the different classes correspond to; they are typically specified as part of the problem formulation and the objective is to build a predictive classifier. On the other hand it is handled in a more exploratory way. We might expect that there are data points with similar features and the objective is to group them into clusters to obtain a better understanding of the data. However, the clusters might not correspond to interpretable classes. Moreover, the nature of clusters is typically unknown and left to the user to decide.

We start by adapting the GMM to the unsupervised setting, turning it into a clustering method. We will discuss the GMM algorithm in bit more detail as well as highlight some subtleties that differ between the semi-supervised and unsupervised setting. Next, we present the k-means algorithm, which is an alternative clustering method, and discuss similarities between this method and the GMM.

### Unsupervised learning of the Gaussian mixture model

The GMM (10.1) is a joint model for $\mathbf{x}$ and $y$, given by:

$p(\mathbf{x}, y) = p(\mathbf{x}|y)p(y) = N(\mathbf{x}|\boldsymbol{\mu}_y, \boldsymbol{\Sigma}_y)\pi_y$.

To obtain a model only for $\mathbf{x}$ we can marginalize $y$ as $p(\mathbf{x}) = \sum_y p(\mathbf{x}, y)$. From the marginalization this implies that we consider $y$ as a latent variable that exists in the data containing only $\{\mathbf{x}_i\}_{i=1}^n$. Intuitively, we learn the GMM from unlabeled training data to figure out which $\mathbf{x}$ values come from which class-conditional distribution $p(\mathbf{x}|y)$ based on their similarity. That is, we need to learn the latent variables $\{y_i\}_{i=1}^n$ from the data and then use this knowledge to fit the model parameters. Once this is done, the learned class-conditional distributions $p(\mathbf{x}|y=m)$ for $m=1,...,M$ define $M$ clusters in the data.

Conveniently we have a tool to learn the GMM from data. Method 10.2, which we derived for the semi-supervised case, also works for completely unlabeled data $\{\mathbf{x}_i\}_{i=1}^n$. We just need to replace the initialization (1) with random choice of initial $(\hat{\boldsymbol{\mu}}_m, \hat{\boldsymbol{\Sigma}}_m)_{m=1}^M$. We repeat the algorithm with these minor modifications in Method 10.2 for convenience.

Method 10.3 corresponds to the EM algorithm applied to the unsupervised maximum likelihood problem:

$\hat{\theta} = \arg\max_{\theta} p(\{\mathbf{x}_i\}_{i=1}^n|\theta)$.

To show that this is indeed and that the suggested procedure is a well grounded way of addressing the maximum likelihood problem (10.2), we will now take a closer at the EM algorithm itself.

The EM algorithm is a general tool for solving maximum likelihood problems in probabilistic models with latent variables, that models containing both observed and unbound variables. The current latent variables are $\{y_i\}_{i=1}^n$ where $y_i \in \{1,...,M\}$ is the cluster index for data point $\mathbf{x}_i$.
