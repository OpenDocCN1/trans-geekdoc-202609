# 6.5 Further reading

Although the first conceptual ideas of neural networks date back to the 1940s (McCulloch and Pitts 1943), they had their first main successes in the late 1980s and early 1990s with the so-called backpropagation algorithm. At that stage, neural networks could, for example, be used to classify handwritten digits from low-resolution images (LeCun, Boser, et al. 1989). However, the early 90s neural networks were largely forgotten it was widely believed they could not be used for any challenging problems in computer vision and speech recognition. In these areas, neural networks could not compete with hand-crafted solutions based on domain prior knowledge.

This situation has changed dramatically since the late 2000s with the deep learning. Progress in software, hardware and algorithm parallelization made possible to address more complicated problems, which were unthinkable only a couple of decades ago. For example, in image recognition, these deep models are now the dominant methods of use and they reach human or super-human performance on some specific tasks. An accessible introduction and overview of deep learning is by LeCun, Bengio, et. (2015), and via the textbook by Goodfellow, Bengio, et al. (2016).

# 6.6 Derivation of the backpropagation equations

To derive the backpropagation equations (6.27), consider the non-vectorized version of layer 1.

```
\begin{cases} z_j^{(l)} = \sum_k W_{jk}^{(l)}q_k^{(l-1)} + b_j^{(l)} \ q_j^{(l)} = h(z_j^{(l)}) \end{cases} \quad \forall j=1, \dots,U^{(l)}. \quad (6.35)
```

Assume we want to compute the derivatives of the cost function with respect to the parameters $W_{jk}^{(l)}$ and $b_j^{(l)}$. Note that the cost function $J(\theta)$ depends on both $W_{jk}^{(l)}$ and $b_j^{(l)}$ only through the hidden unit $z_j^{(l)}$ and not of the other units in that. We can use the chain rule to calculate or write

```
\frac{\partial J}{\partial b_j^{(l)}}rac{\partial J}{\partial z_j^{(l)}}rac{\partial z_j^{(l)}}{\partial b_j^{(l)}} = \frac{\partial J}{\partial W_{jk}^{(l)}}rac{\partial J}{\partial z_j^{(l)}}rac{\partial z_j^{(l)}}{\partial W_{jk}^{(l)}} = \frac{\partial J}{\partial q_k^{(l-1)}}rac{\partial J}{\partial z_j^{(l)}}rac{\partial z_j^{(l)}}{\partial q_k^{(l-1)}} = \quad \forall j=1, \dots,U^{(l)}}, \quad (6.36)
```

the partial derivatives of $J(\theta)$ with respect to $W_{jk}^{(l)}$ and $b_j^{(l)}$ can be directly derived from (6.35).

Similarly, we can use the chain rule to compute the partial derivative of $J(\theta)$ with respect to the post-activation hidden units $q_j^{(l-1)}$ for layer $l-1$. $J(\theta)$ depends on $q_k^{(l-1)}$ so we get

```
\frac{\partial J}{\partial q_k^{(l-1)}} = \sum_j \frac{\partial J}{\partial z_j^{(l)}}rac{\partial z_j^{(l)}}{\partial q_k^{(l-1)}} \quad \forall k=1, \dots,U^{(l-1)}}, \quad (6.37)
```

Finally, we can also use the chain rule to express

```
\frac{\partial J}{\partial z_j^{(l)}} = \frac{\partial J}{\partial q_j^{(l)}}rac{\partial q_j^{(l)}}{\partial z_j^{(l)}} \quad \forall j=1, \dots,U^{(l)}, \quad (6.38)
```

where $h'$ is the derivative of the activation function. With the vectorized notation for $dW, db, dz$ and $dq$ introduced in (6.22) and (6.25), we get that Equation (6.38) gives (6.27a), Equation (6.37) gives (6.27b), and Equation (6.36) gives (6.27c)-(6.27d).
