To start with, the confusion matrix offers a great opportunity to explicitly inspect the false negatives and positives in a more explicit fashion. however, sometimes it be useful to summarize the performance into a single number. For that purpose the misclassification rate is not very helpful; in severely imbalanced problem it can for instance a useless classifier that predicts always -1 or over realistically used.

For imbalanced problems where the negative class y = -1 is the most common class, the $F_1$ score is therefore preferable over the misclassification rate (or accuracy). The $F_1$ score summarizes the precision and recall by their harmonic mean.

```
$F_1 = \frac{2 \text{ precision - recall}}{\text{precision + recall}} \quad (4.24)
```

which is a number between zero and one).
For asymmetric, however, the $F_1$ score is not sufficient since it does not weigh in the preference of having one type of error considered more than the other. For that purpose a generalization of the $F_1$ score, namely the $F_eta$ score, can be used. The $F_\beta$ score weight together precision and recall by considering recall $\beta$ times as important.

```
$F_\beta = \frac{(1 + \beta^2) \text{ precision - recall}}{\text{precision + recall}} \quad (4.25)
```

Much like the misclassification rate might be misleading for imbalanced problems, the ROC curve might also be misleading for such problems. The precision-recall curve can (for imbalanced problems where y = -1 is the most common class) be better. As the name suggests, precision-recall curve plots the (TP*, a large value is) the recall (TP/P, a large value is) for all values of $r \in [0, 1]$, which can make the ROC curve perfect for the perfect classifiers using it. The precision-recall curve for random gives a horizontal line at the level $P/n$, as shown in 4.13b.
Also for the precision-recall curve can define area under the precision-recall curve, PR-AUC. The best is PR-AUC, and a classifier that only makes random has PR-AUC close to $P/n$. We summarize this by an example of an imbalanced and asymmetric problem in medicine. The evaluation of real-world problems, which are often both imbalanced and asymmetric, is a challenging topic with certain details that are discussed in Chapter 12.

We consider the problem of thyroid diseases, using datasets provided by UCI Machine Learning Repository (Dhehra and Karanisikidu 2010). The dataset is split into training and hold-out validation sets, with 3722 and 3478 data points respectively. The problem is imbalanced because of the normal class. Hence, the random classifier that always predicts normal will obtain misclassification rate of around 7%.
