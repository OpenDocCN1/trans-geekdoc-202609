# Second order gradient methods

We can think of gradient descent as descending $J(\theta)$ with a first order Taylor expansion around $	heta^{(t)}$, that is, a hyper-plane. The next parameter $	heta^{(t+1)}$ is selected by taking a step in the steepest direction of the (hyper)-plane. Let us see what happens if we use a second order Taylor expansion,

```
$J(\theta) \approx J(\theta^{(t)}) + \mathbf{v}^T \nabla J(\theta^{(t)}) + \frac{1}{2} \mathbf{v}^T \nabla^2 J(\theta^{(t)}) \mathbf{v}. \quad (5.33)$
```

where $\mathbf{v}$ is a vector of the same dimension as $	heta$. This expression does not only contain the gradient of the cost function $
abla J(\theta)$, but also the Hessian of the cost function $
abla^2 J(\theta)$. Remember that we are searching for the minimum of $s(\theta, \mathbf{v})$. We will compute this by iteratively minimizing the second order approximation $s(\theta, \mathbf{v})$. If the Hessian $\nabla^2 J(\theta)$ is positive definite, then the minimum of $s(\theta, \mathbf{v})$ with respect to $\mathbf{v}$ is observed where the derivative of $s(\theta, \mathbf{v})$ is,

```
$$\frac{\partial}{\partial \mathbf{v}} s(\theta, \mathbf{v}) = \nabla J(\theta) + [\nabla^2 J(\theta)]^{-1}\mathbf{v} = 0 \Rightarrow \mathbf{v} = -[\nabla^2 J(\theta)]^{-1}\nabla J(\theta). \quad (5.34)$
```

This suggests that

```
$$\theta^{(t+1)} = \theta^{(t)} - [\nabla^2 J(\theta^{(t)})]^{-1}\nabla J(\theta^{(t)}). \quad (5.35)$
```

Newton's method is for minimization. Unfortunately, no general convergence are guaranteed for Newton's method either. Yet it can be much faster than gradient descent. In fact, if the cost $J(\theta)$ is a quadratic function in $	heta$ then (5.33) is exact and Newton's method (5.35) will find the optimum in only one iteration! Quadratic objective functions are, however, rare in machine learning$^{1}$. It is not guaranteed that the Hessian $\nabla^2 J(\theta)$ is always positive definite in practice, which may make use of the potentially valuable second order information difficult. To make use of the potentially valuable second order information, we have to introduce some modification of Newton's method. There are multiple options, and we will look at so-called trust regions.

We derived Newton's method using the second Taylor expansion (5.33) as a method for how $J$ behaves around $	heta^{(t)}$. We should not trust the Taylor expansion to be a good model for all values of $	heta$, but only in the vicinity of $\theta$. One natural restriction is to trust the second order Taylor expansion (5.33) only within a radius $D$ around $	heta^{(t)}$, which we refer to as our trust region. This suggests that we could make a Newton step (5.35) of the parameters, unless the step is longer than $D$, in which case we decide the step to leap near local minimum. In the next iteration, the trust region is moved to center around the updated $	heta^{(t+1)}$, and another step is taken from there. We express this as

```
$$\theta^{(t+1)} = \theta^{(t)} - \eta [\nabla^2 J(\theta^{(t)})]^{-1}\nabla J(\theta^{(t)}). \quad (5.36)$
```

where $\eta = 1$ is chosen so that $|\theta^{(t+1)} - \theta^{(t)}| \le D$. The trust region $D$ can be updated and adapted as the optimization proceeds, but for simplicity we will consider $D$ to be a user choice (like the learning rate for gradient descent).
