By computing the asymptotic minimizer of a loss function, we obtain information about the expected
behavior or properties of a model that is learned using this loss function. Although the asymptotic
mizer is an idealized theoretical concept (assuming finite data and infinite reflectivity), it reveals, in
sense, what the training algorithm strives to achieve when minimizing a particular loss.

The concept is useful for understanding both regression and classification losses. A few notable
examples in the setting are the squared error and the absolute
erless. For the former, the asymptotic minimizer can be shown to be equal to the
conditional mean, $f^*(x)=\mathbb{E}[y|x]$. Thus, a regression trained using squared error will strive
to predict accurately according to the true data under the data conditional distribution $p(y|x)$ (although
this is limited by the flexibility of the loss model and the class of uncertain
training data). For the absolute error the asymptotic minimizer is given by the conditional mean,
$f^*(x)=\text{Median}[y|x]$. This is less sensitive to the tail of $p(y|x)$ than the conditional mean,
providing another interpretation of the improved robustness of the absolute error.

Related to the concept of asymptotic minimizers is the nature of a strictly proper loss function. A
loss is said to be strictly proper if its minimizer is (i) unique and (ii) in one-to-one
correspondence with the true conditional distribution $p(y|x)$. But, for a strictly proper loss
function we can express $p(y|x)$ in terms of the asymptotic minimizer f^*(x)$. Such a loss will
strive to recover the probabilistic characteristic of the input-output relationship.
This is a probabilistic interpretation of the model, in the sense that we express $p(y|x)$ in
terms of the model f^*(x), which is not always obvious. One case stands out in this is the
maximum likelihood requires a likelihood-based model
since corresponding to the true conditional distribution. As we have discussed above,
the negative log-likelihood loss is a very generic loss function (it is applicable to regression, classification,
and many other types of problems). We can complement this by the theoretical statement that

> the negative log-likelihood loss is strictly proper.

Note that this applies to any type of problem where the negative log-likelihood loss can be used. As noted
above, the concept of a loss function being strictly proper is related to its asymptotic minimizer, which
turn is derived under the assumption of infinite reflectivity and finite data. Here what our claim above
says that if the likelihood-based model is flexible enough to describe the true conditional distribution
p(y|x), the optimal solution to minimize the likelihood as $n \to \infty$ is to learn this true
distribution.
