However, selecting the b ensemble member $f^{(b)}(X)$ so that it exactly matches the negative gradient is typically not possible. The reason is that the ensemble members $\{f_i\}$ are restricted to some specific functional form, for instance the set of functions that can be generated by a tree-based model of certain depth. Neither is desirable in general, since exactly matching the gradient at all training points could easily lead to overfitting. Ideally, we are not interested in finding a model that fits the training data as well as possible, but rather one generalizes to new data. Restricting our attention to a class of functions that generalize beyond the observed training data is a key requirement.

To proceed we define the b ensemble member $f^{(b)}(X)$ as a machine learning method, with the training objective that its predictions on the training data points (that is, the vector $f^{(b)}(X)$) are close to the negative gradient (7.18). Closeness can be evaluated by any distance function, such as the squared distance. This corresponds to solving a regression problem where the target values are the elements of the gradient, and the loss function (for example squared loss) determines how we measure closeness. Noted, even when the actual problem under study is classification, the values in (7.18) will be real-valued in general.

Having the b ensemble member it remains to compute the coefficient $\alpha^{(b)}$. As pointed out above, this corresponds to the step size (or learning rate) in gradient descent. In the simplest version of gradient descent it is a tuning parameter left to the user. However, it can also be found by solving a line-search optimization problem at each iteration. For gradient boosting, it is most often handled in the layer. By multiplying the optimal $\alpha^{(b)}$ with a constant $<1 a regularizing effect is obtained which has proven useful in practice. We summarize gradient boosting by Method 7.3.

# Learn a simple gradient classifier

**Data:** Training data $\mathcal{X} = \{x_i\}_{i=1}^n$, step size multiplier $\gamma < 1$.

**Result:** A boosted classifier $\hat{f}^{(B)}(X)$

+   1. Initialize with a simple classifier, $f^{(0)}(X) = \arg\min_f \sum_{i=1}^n L(y_i, f)$
2. For $b = 1, \dots, B$
3. Compute the gradient function $f^{(b)}(X)$ of the loss function $L(f)$ by $d_i^{(b)} = -\frac{\partial L(y_i, f)}{\partial f}|_{f=f^{(b-1)}(x_i)}, i=1^n$
4. Learn a regression model $f^{(b)}(X)$ from the input-output data $\{x_i, d_i^{(b)}\}_{i=1}^n$
5. Compute $\alpha^{(b)} = \arg\min_\alpha \sum_{i=1}^n L(y_i, f^{(b-1)}(x_i) + \alpha f^{(b)}(x_i))$n6. Update the boosted model $f^{(b)}(X) = f^{(b-1)}(X) + \alpha^{(b)} f^{(b)}(X)$n7. end

# Predict with the gradient boosting classifier

**Data:** $B$ classifiers and input test $x_*$.

**Result:** Prediction $\hat{f}^{(B)}(x_*)$

+   1. Output $\hat{f}^{(B)}(x_*) = \sum_{b=1}^B \alpha^{(b)} f^{(b)}(x_*)$.
