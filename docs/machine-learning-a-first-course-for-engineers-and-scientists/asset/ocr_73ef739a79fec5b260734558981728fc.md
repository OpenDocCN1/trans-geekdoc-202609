**Semi-supervised learning of the Gaussian mixture model

We have so discussed how the GMM can be in the supervised setting, that is, from training data that contains both input and output values (that is, classes). We will now have a look at the semi-supervised model where some output values $y_i$ are missing in the training data. The input values $\mathbf{x}_i$ for which we are are unlabeled data points. We will denote the total number of training data points $n$, out of which $n_l$ are labeled input-output pairs $\{\mathbf{x}_i, y_i\}_{i=1}^{n_l}$ and the remaining $n_u$ unlabeled data points $\{\mathbf{x}_j\}_{j=n_l+1}^n$, where $n = n_l + n_u$. All in us have the training data $\mathcal{T} = \{\mathbf{x}_i, y_i\}_{i=1}^{n_l}$. For not purposes we have, without loss of generality, order that only $n_l$ points are labeled, and the remaining $n_u$ are unlabeled.
