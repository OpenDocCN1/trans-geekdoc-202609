# Likelihood-based models and the maximum likelihood approach

The maximum likelihood approach is a generic way of constructing a loss function based on a statistical model of the observed data. In general, maximizing the data likelihood is equivalent to minimizing a cost function based on the negative-log likelihood,

```
J(\theta) = -\frac{1}{n} \sum_{i=1}^{n} \ln p(y_i|\theta);
```

Hence, in all cases where we have a probabilistic model of the conditional distribution $p(y|x)$ the negative loglikelihood is a plausible loss function. For classification problems this takes a particularly simple form since $p(y|x)$ corresponds to a probability value over the $M$ classes and the negative loglikelihood is then equivalent to the cross-entropy loss (3.44) (or (3.32) in the case of binary classification).

Also in the regression case there is a duality between common loss functions and the maximum likelihood approach, as we prove afterwards. For instance, in a regression model with additive noise as $\epsilon \sim N(0, \sigma^2)$, the squared error loss is equivalent to the absolute error loss with an implicit assumption of Laplace distribution if we assume a Gaussian distribution, $\epsilon \sim \mathcal{L}(0, \sigma^2)$. This perspective allows one to understand the fact that the absolute error is less robust (less sensitive to outliers) than the squared error loss, since the Laplace distribution encodes sporadic noise values (that, is, outliers) as more probable, compared to the Gaussian distribution.

Using the maximum likelihood approach, other assumptions about noise or insights into its distribution can be incorporated in a similar way to the regression model (5.1). For instance, if we believe the distribution is non-symmetric, then the probability of observing a large positive error is skewed by a noise distribution. Using the negative log likelihood is then a systematic way of incorporating this skewness in the training objective.

Relaxing the Gaussian assumption in (5.1) gives additional flexibility to the model. However, the noise is still assumed to be additive and independent of the input $x$. The real power of the likelihood approach for designing a loss function comes when these basic assumptions are dropped. For instance, in Section 3 we introduced linear models as a way to handle outputs with specific properties such as count (that, $y$ takes in the set of natural numbers 0, 1, 2, ...). In such situations build we often start from a specific form of the likelihood $p(y|x)$, which is chosen to capture the key properties of the distribution (for instance, having support only on the natural numbers). Hence, the likelihood becomes an integral part of the model and this approach lends itself naturally to training by maximum likelihood.

In generalized models (see Section 3.4) the likelihood is parameterized in a very particular way, but when working with nonparametric models this is not strictly necessary. A more direct approach to (nonlinear) likelihood-based parametric modeling is to

> model the conditional distribution $p(y|x)$ as a function parameterized by $\theta$

More specifically, if we have assumed a certain form for the likelihood (like a Gaussian, a Poisson, or some other distribution) its shape will be controlled by some parameters (such as the mean and the variance of a Gaussian, or the rate of a Poisson distribution, not to be confused with $	heta$). The idea is then to construct a parametric model $f(x)$, such that the output of this is a vector of parameters controlling the shape of the distribution $p(y|x)$.
