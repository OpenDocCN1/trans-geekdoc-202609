Based on this observation and the learning objective (10.37), the PCA problem can be formulated as:

```
Find the best rank $q$ approximation $	ilde{X}_0$ of the centered data matrix $X_0$. (10.38)
```

It turns out that this matrix approximation has a well-known solution, given by the Eckart–Young–Mirsky theorem. The theorem is based on a powerful tool from matrix algebra, matrix factorization technique known as singular value decomposition (SVD). Applying SVD to the centered data matrix $X_0$ results in the

```
$X_0 = U\Sigma V^T$. (10.39)
```

Here, $\Sigma$ is an $n 	imes p$ rectangular diagonal matrix of form

```
$$\Sigma = \begin{pmatrix} \sigma_1 & 0 & \dots & 0 \ 0 & \sigma_2 & \dots & 0 \ \vdots & \vdots & \ddots & \vdots \ 0 & 0 & \dots & \sigma_p \ 0 & 0 & \dots & 0 \ \vdots & \vdots & \vdots & \vdots \ 0 & 0 & \dots & 0 \end{pmatrix}$ (10.40)
```

The values $\sigma_j$ are positive real numbers, referred to the *singular values* of the matrix. They are ordered so that $\sigma_1 \geq \sigma_2 \geq \dots \geq \sigma_p > 0$. In general, the number of non-zero singular values of a matrix is equal to its rank, but since we have assumed that $X_0$ is of full rank $p$, all singular values are positive. The matrix $U$ is an $n 	imes n$ orthogonal matrix, meaning that its columns are orthogonal vectors of length $n$. Similarly, $V$ is an orthogonal matrix of size $p 	imes q$.

Using the SVD, the Eckart–Young–Mirsky theorem states that the $best^{th}$ rank $q$ approximation of the matrix $X_0$ is obtained by truncating the SVD to keep only the $q$ largest values. Specifically, using a block matrix notation we write

```
$U = [U_1 \ U_2], \quad \Sigma = \begin{pmatrix} \Sigma_1 & 0 \ 0 & \Sigma_2 \end{pmatrix}, \quad V = [V_1 \ V_2]$. (10.41)
```

where $U_1$ is $n 	imes q$ (corresponding to the first $q$ columns of $U$), $V_1$ is $p 	imes q$ (first $q$ columns of $V$), and $\Sigma_1$ is $q 	imes q$ (with the $q$ largest values on the diagonal). The best rank $q$ approximation of $X_0$ is then obtained by replacing $\Sigma_2$ by zero, resulting in

```
$\tilde{X}_0 = U_1\Sigma_1V_1^T$. (10.42)
```

It remains to connect that this approximation $W_e$ and $W_d$ define the linear-encoder. Specifically, from the definition of reconstructed data points it must hold that $X_0 = X_0W_eW_d^T$ and we need to find matrices $W_e$ and $W_d$ so that this expression agrees to (10.42), the best approximation according to the Eckart–Young–Mirsky theorem. It turns out that this connection is readily available from the SVD. Indeed, choosing $W_e = V_1$ and $W_d = U_1$ has us the desired result:

```
$X_0W_eW_d^T = [U_1 \ U_2] \begin{pmatrix} \Sigma_1 & 0 \ 0 & \Sigma_2 \end{pmatrix} [V_1 \ V_2]^T = U_1\Sigma_1V_1^T$. (10.43)
```

where we used the fact that $V$ is orthogonal so that $V_1^TV_1 = I$ and $V_2^TV_1 = 0$.
