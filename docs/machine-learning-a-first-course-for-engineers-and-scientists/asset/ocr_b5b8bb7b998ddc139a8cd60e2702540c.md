# # Supervised learning: a first approach

In this chapter we will introduce the supervised machine learning problem, as well as two basic learning methods for solving it. The methods we will introduce are called k-NN and decision trees. These two methods are relatively simple and we will derive them from intuitive guides. Still, these methods are useful in their right and are therefore a good place to start. Understanding their inner workings, advantages and shortcomings also lays a good foundation for the more advanced methods that are come in later chapters.

# ## 2.1 Supervised machine learning

In supervised machine learning we have some training data that contains examples of how input variable x relates to an output. By using some mathematical model or method, which we adapt to the training data, our goal is to predict the output y for a new, previously unseen, test data for which only x is known. We usually say that we learn (or train) a model from the training data, and that process involves computations implemented in a computer.

# ## Learning from labeled data

In most supervised machine learning applications, the relation between x and y is difficult to describe explicitly. It may be too cumbersome to fully unravel from application domain knowledge, or even unknown. The problem can therefore not be solved by writing a traditional computer program that takes x as inputs and returns y from a set of results. The supervised machine learning approach is instead to learn the relation between x and y from data, which contains examples of observed pairs of input and output values. In other values, supervised machine learning learns from examples.

The data used for learning is training data, and it has consist of supervised-output data points (samples), in total of n them. We will compactly denote the training data as F' = {xᵢ, yᵢ}ᵢ=¹ⁿ. Each data point in the training data provides a snapshot of how y depends on x, and the goal of supervised machine learning is to squeeze as much information as possible out of F'. In this book we will only consider problems where the individual data points are assumed to be (probabilistically) independent. The exclusion, for example, in time series analysis is when there is interest to model the relation between x and yₜᵢ.

The fact that the training data contains not only input xᵢ, but also output yᵢ, is the reason for the "supervised" machine learning. We may say that each input x is accompanied by a label yᵢ, or that we have labeled data. For some applications, it is only a matter of recording x and y. In other applications, the output y is to by labeling the training data inputs by a domain. For instance, to construct a training dataset for the cardiovascular disease application in Chapter 1, a cardiologist would need to look at all training data inputs (ECG signals) and label them by assigning to the variable y, to correspond to the heart condition that is seen in the signal. The learning process is thus "supervised" by the domain expert.
