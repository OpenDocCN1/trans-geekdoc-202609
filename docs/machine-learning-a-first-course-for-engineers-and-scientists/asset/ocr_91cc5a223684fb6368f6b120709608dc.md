# 7.3 Boosting and AdaBoost

# Learn an AdaBoost classifier

**Data:** Training data $\mathcal{T} = \{\mathbf{x}_i, \mathbf{y}_i\}_{i=1}^n$
**Result:** weak classifiers

+   1 Assign weights $w^{(1)} = 1/n$ to all data points.
2 for $b = 1, \dots, B$ do
3 Train a weak classifier $\hat{y}^{(b)}(\mathbf{x})$ on the weighted data $\{\mathbf{x}_i, \mathbf{y}_i, w^{(b)}_i\}_{i=1}^n,
4 Compute $\hat{y}_{train}^{(b)} = \sum_i^n w^{(b)}_i \mathbb{I}(\mathbf{y}_i 
eq \hat{y}^{(b)}(\mathbf{x}_i)).
5 Compute $\alpha^{(b)} = 0.5 \ln((1 - \hat{y}_{train}^{(b)}) / \hat{y}_{train}^{(b)}),
6 Compute $w^{(b+1)}_i = w^{(b)}_i \exp(-\alpha^{(b)}\hat{y}^{(b)}(\mathbf{x}_i)), i=1, \dots, n.
7 Set $w^{(b+1)}_i \leftarrow w^{(b+1)}_i / \sum_j w^{(b+1)}_j$ for $i=1, \dots, n.
8 end

# Predict with the AdaBoost classifier

**Data:** weak classifiers with confidence values $\{\hat{y}^{(b)}(\mathbf{x}), \alpha^{(b)}\}_{b=1}^B$ and test input $\mathbf{x}_*$.
**Result:** Prediction $\hat{y}_{boost}^{(B)}(\mathbf{x}_*)$

+   1 Output $\hat{y}_{boost}^{(B)}(\mathbf{x}_*) = 	ext{sign}\{\sum_{b=1}^B \alpha^{(b)}\hat{y}^{(b)}(\mathbf{x}_*)\}$.
