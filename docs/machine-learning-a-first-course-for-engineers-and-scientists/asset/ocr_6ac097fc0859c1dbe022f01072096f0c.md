# # 4 Understanding, evaluating and improving the performance

We have so far encountered four different methods for supervised machine learning, and more are to come in later chapters. We always learn the models by adapting them to training data, and hope that the models thereby give us good predictions also when faced with new, previously unseen, data. But can we really expect that to work? This is a very important question for the practical usefulness of machine learning. In this chapter we will discuss this in a rather general sense, before diving into more advanced methods in later chapters. By doing so we will unveil some interesting concepts, and also discover practical tools for evaluating, improving, and choosing between different supervised machine learning methods.

# ## 4.1 Expected new data error $E_{new}$: performance in production

We start by introducing concepts and notation. First, we define an error function $E(	ilde{y}, y)$ which encodes the performance of classification or regression. The error function compares a prediction $	ilde{y}(x)$ to a measured data point $y$, and returns a value (possibly zero) if $	ilde{y}(x)$ is a good prediction of $y$, and a larger value otherwise. Similarly to how we use different loss functions when training a model, we can consider different error functions, depending on what properties of the prediction that are most important for the analysis at hand. However, unless otherwise stated, our default choices are misclassification and squared error, respectively:

+   - Misclassification:

```
$E(\tilde{y}, y) \triangleq \mathbb{I}(\tilde{y} \neq y) = \begin{cases} 0 & \text{if } \tilde{y} = y \ 1 & \text{if } \tilde{y} \neq y \end{cases} \quad (4.1a)$
```

+   - Squared error:

```
$E(\tilde{y}, y) \triangleq (\tilde{y} - y)^2 \quad (4.1b)$
```

When we compare the average performance (4.1a), we usually refer to it as the *misclassification rate* (or 1 minus the accuracy) as *accuracy*. The accuracy rate is a natural quantity to consider in classification, for unbalanced or asymmetric problems others might be more important, as we discuss in Section 4.5.

The error function $E(\tilde{y}, y)$ has similarities to a loss function $L(\tilde{y}, y)$. However, we use them differently: A loss is used when learning (or, evaluating, training) a model, whereas we use the error function to *analyze performance* of an already learned model. There are many reasons for choosing $E(\tilde{y}, y)$ and $L(\tilde{y}, y)$, which will come back to soon.

In the end, supervised machine learning helps decide which methods perform well when faced with an endless stream of new, unseen data. Imagine for all real-time recordings of streets that have to be processed by a vision system in a self-driving car it is to a customer, or all patients having to be classified by a medical diagnosis system once it is implemented in clinical practice. The performance on unseen data in mathematical terms means either the average error the classifier is right, or how well the regression method predicts. To be able to describe the endless stream of new data, we introduce a *distribution over data x$*. In many other cases, we consider the output $y$ as a random variable where the input $x$ is fixed. In this chapter, however, we have to think of the input $x$ as a random variable with a probability distribution. In any real-world machine learning scenario $p(x, y)$ it will be extremely complicated and practically impossible to write. Well nevertheless use $p(x, y)$
