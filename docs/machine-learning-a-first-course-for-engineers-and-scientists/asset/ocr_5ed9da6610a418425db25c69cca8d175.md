# A representation of beliefs

The main feature of the Bayesian approach is its use of probability distributions. We interpret those distributions as *beliefs* in the following sense: The prior $p(\theta)$ represents our beliefs about $	heta$, that is, before any data has been observed. The likelihood, encoded as $p(y|\theta)$, defines how $y$ relates to the parameter $	heta$. Using Bayes's theorem (9.1) we *update* the belief about $	heta$ to the posterior $p(\theta|y)$ which also takes the observed data into account. In an everyday language, these beliefs could be represent uncertain about $	heta$ before and after observing the data $y$ respectively.

An interesting and relevant consequence is that the Bayesian approach is less prone to overfitting, using a maximum-likelihood based method. In maximum-likelihood we obtain a single value $\hat{	heta}$ and use that to make our prediction to $p(y|\hat{	heta})$. In the Bayesian approach we obtain an entire distribution $p(\theta|y)$ representing different hypothesis of value for our model parameters. We account for all of these hypothesis by the marginalization in (9.3) to compute the posterior. In particular in case of small datasets, the "uncertainty" from the (presumably) limited information in $y$, under the assumed conditions.

The posterior $p(\theta|y)$ is a combination of the prior belief $p(\theta)$ and the information about $	heta$ carried by $y$. Without a meaningful likelihood $p(\theta)$, the posterior $p(\theta|y)$ is not meaningful either. In some applications it can be hard to make a choice of $p(\theta)$ that is not influenced by the experience of the machine learning engineer, which is sometimes emphasized by saying that $p(\theta)$ and therefore a subjective belief. This means to reflect that the result is not independent of the data $p(y)$ represents the solution we designed. Also, without the likelihood, no matter if the Bayesian approach is used or not, often chosen by the personal experience of the machine learning engineer, meaning that machine learning arrives in that sensitive objective.

An advantage of the Bayesian approach is that we can work in a sequential fashion, that is, one data point after the other. Say that we have two sets of data, $y_1$ and $y_2$. Starting with a prior $p(\theta)$ we can condition on $y_1$ by computing $p(\theta|y_1)$ using Bayes' theorem (9.1). If thereafter we wanted to condition on all data, $y_1, y_2$, as as $p(\theta|y_1,y_2)$, we do not have to start over again. We can instead replace the prior $p(\theta)$ with $p(\theta|y_1)$ in Bayes' theorem to compute $p(\theta|y_1,y_2)$. In a sense, the "old posterior" becomes the "new" prior when data arrives sequentially.
