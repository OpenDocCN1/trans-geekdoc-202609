# ## Convolutional layer with strides

In the convolutional layer presented above we have equally many hidden units as we have pixels in the image. When we add more layers we want to reduce the number of hidden units and only store the most important information from the previous layers. One way of doing this is by applying the filter to every two pixels. If we filter every two pixels both row-wise and column-wise, the hidden units will only half as many rows and half as many columns. For a $6	imes6$ image we get $3	imes3$ hidden units. This is illustrated in Figure 6.12.
The stride controls how many pixels the filter shifts by both row- and column-wise. In Figure 6.12 the stride is $s=2$ because it moves two pixels row and column-wise. Note that the convolutional layer in Figure 6.12 still requires 10 parameters, just as the original layer. Mathematically, the convolutional layer can be expressed as

```
$$q_{i,j} = \sum_{k=1}^{F} \sum_{l=1}^{F} x_{(i-1)s+k,(j-1)s+l}W_{k,l}$$
```

Specifically this is equal to (6.29) if we used $s=1$ in the equation above.

# ## Pooling layer

Another way of summarizing the information in previous layers is achieved by **pooling**. A pooling layer acts as an additional layer after the convolutional layer. Similar to the convolutional layer, it depends on a region of pixels. However, contrast to convolutional layers, the pooling layer does not have any extra trainable parameters. In pooling layers we also use strides to condense the information, meaning that region is shifted by $s>1$ pixels. Two common versions of pooling are average pooling and max pooling. In average pooling, average of the units in the region is computed. Mathematically, this means

```
$$\hat{q} = \frac{1}{F^2} \sum_{k=1}^{F} \sum_{l=1}^{F} q_{(i-1)s+k,(j-1)s+l}$$
```
