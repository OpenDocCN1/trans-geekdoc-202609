
## 7.3 Boosting and AdaBoost

### Learn an AdaBoost classifier

**Data:** Training data $\mathcal{T} = \{\mathbf{x}_i, \mathbf{y}_i\}_{i=1}^n$
**Result:** weak classifiers

1. Assign weights $w^{(1)} = 1/n$ to all data points.
2. for $b = 1, \dots, B$ do
   - Train a weak classifier $\hat{y}^{(b)}(\mathbf{x})$ on the weighted data $\{\mathbf{x}_i, \mathbf{y}_i, w^{(b)}_i\}_{i=1}^n$,
   - Compute $\hat{y}_{train}^{(b)} = \sum_{i=1}^n w^{(b)}_i \mathbb{I}(\mathbf{y}_i \neq \hat{y}^{(b)}(\mathbf{x}))$,
   - Compute $\alpha^{(b)} = 0.5 \ln((1 - \hat{y}_{train}^{(b)}) / \hat{y}_{train}^{(b)})$,
   - Compute $w^{(b+1)}_i = w^{(b)}_i \exp(-\alpha^{(b)} \hat{y}^{(b)}(\mathbf{x}_i))$ for $i=1, \dots, n$,
   - Set $w^{(b+1)}_i \leftarrow w^{(b+1)}_i / \sum_{j=1}^n w^{(b+1)}_j$ for $i=1, \dots, n$.
3. end

### Predict with the AdaBoost classifier

**Data:** weak classifiers with confidence values $\{\hat{y}^{(b)}(\mathbf{x}), \alpha^{(b)}\}_{b=1}^B$ and test input $\mathbf{x}_*$
**Result:** Prediction $\hat{y}_{boost}^{(B)}(\mathbf{x}_)$

1. Output $\hat{y}_{boost}^{(B)}(\mathbf{x}_*) = \text{sign}\{\sum_{b=1}^B \alpha^{(b)}\hat{y}^{(b)}(\mathbf{x}_)\}$

### Design choices for AdaBoost

AdaBoost, and in fact any boosting algorithm, has two important design choices: (i) which base classifier to use, and (ii) how many iterations $B$ to run the boosting algorithm. As previously pointed out, we can use essentially any classification method as base classifier. The most common choice in practice is to use a shallow tree, or even a decision stump (a tree of depth one; see Example 7.5). This choice is guided by the fact that boosting reduces efficiently, and we can learn good models despite a very weak (high-bias) base model. Since shallow trees can be trained quickly, they are a good default choice. Practical experience shows that trees with a handful of terminal nodes work well as base models, but trees of depth one (only $M=2$ terminal nodes in binary classification) are perhaps more commonly used. In fact, using deep classifiers (high-variance models) as base classifiers deteriorates performance.

The base models are learned sequentially in boosting, each iteration aiming at reducing the errors by the current model. As an effect, the boosting model becomes more and more different from bagging, where increased $B$ occurs slowly and using too many base models can result in overfitting; however, it has been observed in practice that overfitting often occurs slowly and the performance tends to be rather sensitive to the choice of $B$. Nevertheless, it is a good practice to select $B$ in some systematic way, for instance using early stopping during training. Another unfortunate aspect of the sequential nature of boosting is that it is not possible to parallelize the learning process.

## 7.4 Ensemble methods: Bagging and Gradient boosting

It has been seen in practice that AdaBoost performs well when there is noise in the data. However, as the data becomes noisier, the performance can deteriorate. This is not an artifact of the method but rather, to lay the foundation for more general algorithms, a very useful—and common—way of constructing a function approximator is using an additive model of the form:

```
f^B(X) = \sum_{b=1}^B a^{(b)}f^{(b)}(X) \quad (7.14)
```

where $a^{(b)}$ are real-valued coefficients and $f^{(b)}(X)$ are some basis functions. For a regression problem, $f^{(b)}$ can be used directly as the model. For a classification problem it can be thresholded by a sign function to obtain a hard classification, or transformed into a probability by passing through a logistic function. This is also the reason for why we use $f$ instead of $y$ in the notation.

Comparing (7.14) with (7.4) is clear that AdaBoost follows this additive form, where the learners (ensemble members) are the basis functions and their confidence scores are the coefficients. However, we have seen in fact other examples of additive models as well.

In the method discussed above we have assumed that each base classifier outputs a class prediction, $\hat{y}(x) \in \{-1, 1\}$. To mitigate this and construct more robust algorithms we can consider some other loss function. As discussed in Section 5.2, it is possible to use neural networks as base classifiers. In Chapter 6 we introduced the neural network model, and by outputting the expression for a two-layer regression network it can be seen that its an additive model.
