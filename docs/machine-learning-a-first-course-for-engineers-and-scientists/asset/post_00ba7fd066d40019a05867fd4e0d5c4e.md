![](img/9c84a60f9e70ea0bf5c7c51ae709df3e_204_0.png)

**Figure 10.1:** The GMM is a generative model, and we think about the inputs x as random and assume that they have a certain distribution. The GMM assumes that p(x|y) has a Gaussian distribution for each y. In this figure x is two-dimensional and two classes (red and blue). The left panel shows data with this nature. The right panel shows, for each value of y, the contour lines of the Gaussians p(x|y) that are learned from the data using (10.3).

Note, that due to the generative nature of the model, it is based on the joint likelihood of both inputs and the outputs. It follows from the model definition (10.1) that the log-likelihood is given by

```
$$\ln p(\{x_i, y_i\}_{i=1}^n|\theta) = \sum_{i=1}^n \ln p(x_i|y_i, \theta) + \ln p(y_i|\theta)$$
$$\= \sum_{m=1}^M \sum_{i=1}^{n_m} \ln N(x_i|\mu_m, \Sigma_m) + \ln \pi_m ,$\quad$(10.2b)
```

where the indicator function $I(y_i=m)$ effectively separates the log-likelihood into $M$ independent sums, for each class, depending on the class labels of the training data points.

The optimization problem (10.2) turns out to have a closed form solution. Starting with the marginal class probabilities $(\pi_m)_{m=1}^M$ we get

```
$$\tilde{\pi}_m = \frac{n_m}{n},$\quad$(10.3a)
```

where $n_m$ is the number of training data points in class m. Consequently, $\sum n_m = n$ and $\sum \tilde{\pi}_m = 1$. This simply states that the probability of a certain class y=m, without having any additional information, is estimated as the probability of this class in the training data.

Furthermore, the mean vector $\mu_m$ of each class is estimated as

```
$$\tilde{\mu}_m = \frac{1}{n_m} \sum_{i:y_i=m} x_i,$\quad$(10.3b)
```

the empirical mean among all training data points of class m. Similarly, the covariance matrix $\Sigma_m$ for each class $m=1,...,M$, is estimated as

```
$$\tilde{\Sigma}_m = \frac{1}{n_m} \sum_{i:y_i=m} (x_i - \tilde{\mu}_m)(x_i - \tilde{\mu}_m)^T.,$\quad$(10.3c)
```

The expressions (10.3b)-(10.3c) learn a Gaussian distribution for $\mathbf{x}$ for each class such that the mean and variance fit the data, so-called moment-matching. Now we can compute the parameters $\theta$ no matter the data actually comes from a Gaussian distribution or

The two options are not mathematically equivalent, but for machine learning purposes the practical difference is often minor.

### Predicting output labels for new inputs: discriminant analysis

We have so described the generative GMM $p(x,y)$, where $x$ is numerical and $y$ is categorical, and how to learn the unknown parameters in $p(x,y)$ from training data. We will now see how this can be used as a classifier for supervised machine learning.

The key insight for using a generative model $p(x|y)$ to make predictions is to realize that the output $y$ for a known value $x$ amounts to computing the conditional $p(y|x)$. From probability theory we have

```
$p(y|x) = \frac{p(x,y)}{p(x)} = \frac{p(x,y)}{\sum_{j=1}^M p(x,j)}$
```

The left side $p(y|x)$ is the predictive distribution, whereas all expressions on the right side are defined by the generative GMM (10.1). We therefore get the classifier

```
$p(y=m|x) = \frac{\pi_m \mathcal{N}(x|\hat{\mu}_m, \hat{\Sigma}_m)}{\sum_{j=1}^M \pi_j \mathcal{N}(x|\hat{\mu}_j, \hat{\Sigma}_j)}$
```

As usual, we can obtain "hard” predictions by selecting the class which is predicted to be the probable,

```
$\hat{y}_* = \arg\max_m p(y=m|x)$
```

and compute decision boundaries. Taking the logarithm (which does not change the maximizing argument) and noting only that the numerator in (10.5) depends on $m$ we can equivalently write this

```
$\hat{y}_* = \arg\max_m [\ln \pi_m + \ln \mathcal{N}(x|\hat{\mu}_m, \hat{\Sigma}_m)]$
```

Since the logarithm of the Gaussian probability density is a quadratic in $x$, the decision boundary for this classifier is quadratic and the method is referred to as discriminant analysis (QDA). We summarize this by Method 10.1 and 10.3, and in Figure 10.2 we see the decision boundary when the GMM is turned into a QDA classifier.

The QDA method arises naturally from GMM. However, if we make an additional simplification about the model we obtain an well-known and commonly used classifier, referred to as linear analysis (LDA). The additional assumption is that the covariance matrix is equal for all classes, is $\Sigma_1 = \Sigma_2 = ... = \Sigma_M$ in (10.1). With this restriction we have a single covariance matrix to learn and it is replaced by

```
$\hat{\Sigma} = \frac{1}{n} \sum_{i=1}^n (x_i - \hat{\mu}_m)(x_i - \hat{\mu}_m)^T$
```

### Semi-supervised learning of the Gaussian mixture model

We have so discussed how the GMM can be in the supervised setting, that is, from training data that contains both input and output values (that is, classes). We will now have a look at the semi-supervised model where some output values $y_i$ are missing in the training data. The input values $\mathbf{x}_i$ for which we are unlabeled data points. We will denote the total number of training data points $n$, out of which $n_l$ are labeled input-output pairs $\{\mathbf{x}_i, y_i\}_{i=1}^{n_l}$ and the remaining $n_u$ unlabeled data points $\{\mathbf{x}_j\}_{j=n_l+1}^n$, where $n = n_l + n_u$. All in us have the training data $\mathcal{T} = \{\mathbf{x}_i, y_i\}_{i=1}^{n_l}$. For not purposes we have, without loss of generality, order that only $n_l$ points are labeled, and the remaining $n_u$ are unlabeled.
