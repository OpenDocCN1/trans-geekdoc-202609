The question remains though, is it (as Nix and Wylie claim) possible to identify the personality of individuals using this learning methods outlined above? To be clear, David Summer (2018) looked again some of the data, for 17,952 US-based Facebook users, which was publicly available for research in the MyPersonality data set (Koski et al. 2016). This analysis first replicated the principal component and regression approach called in (Youyou et al. 2015). This assigns scores to neuroticism as measured from regression on ‘likes’, which we denote $F_i$, for personality test, which we denote $T_i$.

Building on the method in Section 12.2 for measuring performance by comparing individuals (i.e. AUC), we picked pairs of individuals $i$, and $j$, at random and calculate

$p(F_i > F_j, T_i > T_j) + p(F_i < F_j, T_i < T_j). \quad (12.10)

In other words, we calculate the probability that the same individual scores higher in both Facebook measured neuroticism and personality test measured. For the MyPersonality data set this score is 0.6 (David Summer 2018). This accuracy of 60% can be compared to a baseline of 50% for random predictions. The quality of the data used by Cambridge Analytica was much lower than in the scientific study. Thus Nix’s (and Wylie’s) claims gave a misleading picture of what a ‘personality’ algorithm can achieve.

There were many ethical concerns about how Cambridge Analytica stored and used personal data. In terms of performance, the biggest concern was that it could be described — both by proponents and detractors — in a way overstated. The fact that neuroticism can be fitted by a regression model does not make it high accuracy, targeted predictions by individuals. These concerns go much further than Cambridge Analytica. Indeed, companies use machine learning and AI buzzwords to make sure that the performance is reported properly, in terms that are easily understandable.
