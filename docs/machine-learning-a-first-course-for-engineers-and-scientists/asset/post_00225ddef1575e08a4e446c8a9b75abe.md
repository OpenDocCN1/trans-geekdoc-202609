
## 6 Neural networks and deep learning

### 6.4 Dropout

Like all models presented in this course, neural networks can suffer from overfitting if we have a too flexible model in relation to the complexity of the data. One way to reduce the variance, and by also reduce the risk of overfitting, is by training not one model, but multiple models and average their predictions. This is the main idea behind bagging, which we present in more detail in Chapter 7. To set the terminology, we say that we train an ensemble of models, and which we will refer to as an ensemble member.

Bagging is also applicable to neural networks. However, it comes with some practical problems; a large neural network usually takes some time to train and it has many parameters to store. To train not one, but an ensemble of large neural networks would thus be very costly, in terms of runtime and memory. Dropout is a bagging-like technique that allows us to combine many neural networks without needing to train them separately. The trick is to let the different models share parameters with each other, which reduces the computational cost and memory requirement.

### Ensemble of sub-networks

Consider a neural network like the one in 6.18a. In a dropout we construct the equivalent to an ensemble member by randomly removing some of the units. We say that we drop the units, when a unit is removed, we remove all of its incoming and outgoing connections. With this procedure we obtain a sub-network that only contains a subset of the units and parameters present in the original network. Two sub-networks are depicted in Figure 6.1b.

Mathematically we can write this as using a mask $m^{(l-1)} = m^{(l-1)}$ for each layer, with which we element-wise multiply the hidden units $q^{(l-1)}$ and then feed the masked units $q^{(l-1)}$ to the next layer:

```
$m^{(l-1)} = \begin{cases} 1 & \text{with probability } r \\ 0 & \text{with probability } 1-r, \end{cases} \quad \text{for all } j=1, \dots, U_{l-1}.\ \quad (6.33a)$
q^{(l-1)} = m^{(l-1)} \odot q^{(l-1)}, \quad (6.33b)$
q^{(l)} = h(W^{(l)}q^{(l-1)} + b^{(l)}). \quad (6.33c)$
```

The probability $r$ of keeping a unit is a hyperparameter set by the user. We can choose to apply dropout to all layers or some of them and also use different probabilities $r$ for different layers. We can also apply dropout to the input variables as shown in Figure 6.18b. However, we do not apply dropout to the output units. Since all sub-networks stem from the very same original network, the different sub-networks share some parameters with each other. For example, in Figure 6.18b the weight $W_{55}^{(l)}$ is present in both sub-networks. The fact that they share parameters with each other allows us to train the ensemble of sub-networks in an efficient manner.

**Figure 6.19:** The network used for prediction after trained with dropout. All units and links are present (no dropout) but the weights going out from a certain unit are multiplied by the probability that unit being included during training. This compensates for the fact that they were dropped during training. Here all units have been kept with probability $r$ during training (and consequently dropped with probability $1-r$).

### Training with dropout

To train we use stochastic gradient descent described in Algorithm 5.3. Each gradient mini-batch of data is used to compute an approximation of the gradient, as normally in stochastic gradient descent. However, instead of computing the gradient for the full network, we generate a random sub-network by randomly dropping units as described above. We compute the gradient for that sub-network and then do a gradient step. This step only updates the parameters in the sub-network. The parameters that are associated with the dropped units do not affect the output of that sub-network and are left untouched. In the next step we use another mini-batch of data, remove another randomly selected collection of units and update the parameters in that sub-network. We proceed in this method until some terminal condition is fulfilled.

### Prediction at test time

After we have trained the sub-networks, we want to make a prediction on an unseen input data $\mathbf{x}$. If this was an ensemble method we would evaluate all sub-networks and their averages. Since each unit can be in or out, there are $2^U$ sub-networks where $U$ is the total number of units in the network. Hence, due to this large number, evaluating all of them would be infeasible. However, there is a simple trick to achieve the same result. Instead of evaluating all sub-networks we simply evaluate the full network all the parameters. Compensate for the fact that the model was trained with dropout, we multiply each estimated parameter going out from a unit with the probability that unit being kept during training. This ensures that the expected value of the input to the next unit is the same during training and testing. If we are keeping a unit with probability $r$, then we multiply the following weight $\mathbf{W}^{(l)}$ with $r$, with that

```
$$\begin{aligned} \mathbf{W}^{(l)} &= r\mathbf{W}^{(l)} \\ \mathbf{q}^{(l)} &= h(\mathbf{q}^{(l-1)} + b^{(l)}). \end{aligned}$$
```

This is also illustrated in Figure 6.19 where we keep a unit with probability $r$ in all layers during training. This adjustment of the weights can be done just once after we are done training and then use these adjusted weights as usual during all predictions.

This procedure of averaging the average over all ensemble members has been shown to work well in practice even though there is not yet some theoretical argument for the accuracy of this approximation.

### Dropout as bagging

As already pointed out, dropout has similarities with the ensemble method called bagging. If you have already learned about bagging in Chapter 7, there are a few important differences to point out:

- In bagging all models are independent in the sense that they have their own parameters.
- In bagging each model is trained until convergence. In most of the $2^U$ sub-networks are not trained at all (they have not been sampled), and those who have been trained have most likely trained for one gradient step.
- Similar to bagging, in dropout we train each model on a dataset that has been randomly selected. However, in bagging we usually do on a bootstrapped version of the whole dataset.

Even though dropout differs from bagging in some aspects it empirically shown to enjoy similar properties as bagging that avoiding overfitting and reducing the variance of the model.

### Dropout as a regularization method

As a way to reduce the variance and overfitting, dropout can be seen as a regularization method. There are plenty of other methods for neural networks including explicit regularization (like $L^1$ and $L^2$ regularization, see Chapter 5), early stopping (the training is stopped before the parameters have converged, see Chapter 5) and various sparse representations (for examples CNNs can be a regularization method where most parameters are forced to zero), just to mention few. In fact, a good practice of designing a neural network is to extend the network until it overfits, then a bit more and finally add a regularization like dropout to that overfitting.
