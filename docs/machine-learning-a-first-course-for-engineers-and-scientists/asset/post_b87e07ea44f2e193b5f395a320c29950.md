## Learn the GMM

**Data:** Unlabeled training data $\mathcal{T} = \{x_i\}_{i=1}^n$, number of clusters $M$.
**Result:** Gaussian mixture model

1. Initialize $\hat{\theta} = \{\pi_m, \mu_m, \Sigma_m\}_{m=1}^M$
2. repeat
   3. For each $x \in \{x_i\}_{i=1}^n$, compute the prediction $p(y \mid x)$ according to (10.5) with the current parameter estimates $\hat{\theta}$.
   4. Update the parameter estimates $\hat{\theta} = \{\pi_m, \mu_m, \Sigma_m\}_{m=1}^M$ according to (10.6)
5. until convergence

## Method 10.3: Unsupervised learning of the GMM

For notational brevity we stack these latent indices into an $n \times M$ matrix $X$. The challenge is that the observed data-likelihood is not readily available, due to the presence of latent variables $y$ in the model specification. Evaluating the log-likelihood requires marginalizing over those variables. In the EM algorithm we address this challenge by alternating computing an *expected log-likelihood* and *maximizing* this to update the model.

Let $\hat{\theta}$ denote the current estimate of $\theta$ at some intermediate iteration (for instance corresponding to the initialization at the first iteration). Then one iteration of the EM algorithm consists of the following two steps:

- (E) Compute $Q(\theta) \stackrel{\text{def}}{=} E[\ln p(X, y \mid \theta)]$
- (M) Update $\hat{\theta} \leftarrow \arg \max Q(\theta)$

The algorithm alternates between two steps until convergence. It can be shown that the observed data-likelihood increases at each iteration of the procedure, unless it has reached a stationary point (where the gradient of the log-likelihood is zero). Hence it is a monotonic optimization algorithm for solving (10.2).

To see that this procedure boils down to Method 10.3 for the GMM model, we start by expanding the E-step. The expected likelihood is computed with respect to the conditional distribution $p(y \mid X, \hat{\theta})$. This represents the probabilistic belief regarding the cluster assignment for all data points, given the current parameter configuration $\hat{\theta}$. In a Bayesian framework, it is the posterior distribution over the latent variables $y$, conditioned on the observed data $X$. We thus have

$$Q(\theta) = \mathbb{E}_{y}[\ln p(X, y \mid \theta)] = \sum_{\gamma} \ln (N(X \mid \mu_{\gamma}, \Sigma_{\gamma})) p(y \mid X, \hat{\theta}) \quad (10.13)$$

The first expression in the sum is referred to as the *complete data log-likelihood*. It is the log-likelihood that we would have if the latent variables were observed. Since it involves both the observed data and the latent variables (which is "complete data"), it is readily available from:

$$\ln p(X, y \mid \theta) = \sum_{i=1}^n \ln p(x_i, y_i \mid \theta) = \sum_{i=1}^n \ln (N(x_i \mid \mu_{y_i}, \Sigma_{y_i}) + \ln \pi_{y_i}) \quad (10.14)$$

Each term depends only on one of the latent variables.

## 10.2 Cluster analysis

From the expression for the complete data-likelihood in (10.13) we get

$$Q(\theta) = \sum_{i=1}^n \sum_{m=1}^M w_i(m) \left[ \ln N(\mathbf{x}_i \mid \mu_{y_i}, \Sigma_{y_i}) + \ln \pi_{y_i} \right] \quad (10.15)$$

where $w_i(m) = p(y=m \mid \mathbf{x}_i, \theta)$ is the probability that the data point $\mathbf{x}_i$ belongs to cluster $m$, computed on the current parameter estimates $\hat{\theta}$.

Comparing with this in the supervised setting (10.2b), when all labels $[y_i]_{i=1}^n$ are known, we note that the two expressions are very similar. The only difference is that the indicator function $I(y=m)$ in (10.2b) is replaced by the weight $w_i(m)$ in (10.15). In words, instead of making a hard cluster assignment of each data point based on a given class, we make a soft cluster assignment based on the probabilities that data point belongs to the different clusters.

We will not go into the details, but it is hard not to believe that maximizing (10.15) with respect to $\theta$—what we do in the M-step of the algorithm—gives a solution similar to the supervised setting, but where the training data points are weighted by $w_i(m)$. Analogously to (10.2), the M-step becomes

$$\hat{\pi}_m = \frac{1}{n} \sum_{i=1}^n w_i(m) \quad (10.16a)$$

$$\hat{\mu}_m = \frac{\sum_{i=1}^n w_i(m) \mathbf{x}_i}{\sum_{i=1}^n w_i(m)} \quad (10.16b)$$

$$\hat{\Sigma}_m = \frac{\sum_{i=1}^n w_i(m) (\mathbf{x}_i - \hat{\mu}_m)(\mathbf{x}_i - \hat{\mu}_m)^\top}{\sum_{i=1}^n w_i(m)} \quad (10.16c)$$

Putting this together we conclude that one iteration of the EM algorithm indeed corresponds to one iteration of Method 10.3. We illustrate the method in Figure 10.7. There are important details about learning the GMM in the unsupervised setting which deserve some attention. First, the number of clusters (that is, number of Gaussian components in the mixture) $M$ must be specified in order to run the algorithm. Second, since there are only unlabeled data points, the indexing of $M$ clusters becomes arbitrary; differently, all permutations of the labels will have the same likelihood. 10.7 shows that the colors (red and blue) are interchangeable and are a reason for why we initialize the cluster in the upper part and the lower part of the space.

The EM algorithm is only guaranteed to converge to a stationary point, which means that a poor initialization can result in convergence to a local optimum. In the semi-supervised setting we could use the labeled data points to initialize the method, but this is not possible in a fully unsupervised setting. Hence initialization becomes an important detail. A pragmatic approach is to run it multiple times with random initializations.

Finally, there is an issue with the maximum likelihood problem (10.2) that we have to address. Without constraints on the parameters $\theta$ the unsupervised maximum likelihood problem for GMM is ill-posed in the sense that the likelihood is unbounded. The problem is that the value of Gaussian probability density function becomes larger and the variance approaches zero. For any $M \geq 2$, the GMM in principle is able to find this likelihood by focusing one of the clusters on a single data point; by shrinking the variance towards zero the likelihood of this particular data point goes to infinity. The remaining $M-1$ clusters then have to cover the remaining $n-1$ data points so that their likelihood are bounded. In practice, the EM algorithm will be used in the semi-supervised setting as well, but only if there are few data points of each class.

Before leaving this section we will introduce an alternative clustering method as $k$-means. This algorithm is in many ways similar to the GMM for clustering above, but derived from a different approach and lacks the generative interpretation of the GMM. The $k$ in $k$-means refers to the number of clusters, so given our notation we perhaps refers to it as $M$-means. However, $k$-means is so well established that we keep it as the name of the method; to agree with the mathematical approach we note $M$ number of clusters. The difference between the GMM and $k$-means is that in the former we model cluster assignments probabilistically, whereas in the latter we make "hard" cluster assignments. That is, we can partition the training data $\{\mathbf{x}_i\}_{i=1}^n$ into distinct clusters $R_1, ..., R_M$, where each data point $\mathbf{x}_i$ should be a member of exactly one cluster $R_m$. $k$-means clustering then amounts to selecting the clusters so that the sum of squared Euclidean distances within each cluster is minimized.

$$\arg \min_{R_1, ..., R_M} \sum_{m=1}^M \sum_{\mathbf{x} \in R_m} ||\mathbf{x} - \hat{\mu}_m||^2 \quad (10.17)$$

where $|R_m|$ is the number of data points in cluster $R_m$. The intention of (10.17) is to select the clusters such that all points within each cluster are as close as possible. It is shown that the problem (10.17) is equivalent to solving the cluster centers such that the distance to the clusters, summed over all data points, is minimized,

Here $\hat{\mu}_m$ is the cluster center, which is the mean of all $\mathbf{x} \in R_m$. Unfortunately (10.17) and (10.18) are combinatorial problems, meaning that we can not expect to solve exactly if the number of data points $n$ is large.
