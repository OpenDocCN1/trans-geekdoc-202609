# The Bayesian approach and Gaussian processes

# 9.3 The Gaussian process

We introduced the Bayesian approach as the idea of considering unknown parameters $\theta$ as random variables, and consequently learning a posterior distribution $p(	heta|y)$ instead of a single value $\theta$. However, the Bayesian idea not only apply to models with parameters, but also to nonparametric models. We will now introduce the Gaussian process, instead of considering parameters $\theta$ being random variables we effectively consider an entire function $f(x)$ as a stochastic process, and compute the posterior $p(f|x)y$. The Gaussian process is an interesting and commonly used Bayesian nonparametric model. In nutshell it is the Bayesian approach applied to kernel regression (Chapter 8). We will present the Gaussian process as a method for handling regression problems, but it is possible to use it for classification problems (similar to how linear regression can be modified to logistic regression).

In this section we will introduce the fundamentals of the Gaussian process, and in Section 9.4 describe how it can be used as a supervised learning method. We will first discuss what a Gaussian process is and thereafter how we can construct a Gaussian process that connects to kernel regression from Section 8.2.

# What is a Gaussian process?

A Gaussian process is a specific type of stochastic process. A stochastic process, in turn, is a generalization of a random variable. Most commonly we think about a stochastic process as some random quantity that evolves over time. Mathematically this corresponds to a collection of random variables $\{z(t) : t \in \mathbb{R}\}$ indexed by time $t$. That is, for each point $t$, the value of the process $z(t)$ is a random variable. Furthermore, often we assume that at different times, $z(t)$ and $z(t')$ are correlated and the correlation depends on the time difference. More abstractly, we can view $z(t)$ as a random function, where the function is to the index $t$. With this interpretation it is possible to generalize the concept of stochastic process to random functions with arbitrary inputs, $f(x)$ where $x \in \mathcal{X}$ denotes the input variable in the input space. Similarly, this means that the value $f(x)$ for any $x$ is a random variable, and that the function $f(x)$ and $f(x')$ for inputs $x$ and $x'$ are dependent. As we will see later, the dependencies can be used to control certain properties of the function. For instance, if we want the function to smooth (slowly), then the function values $f(x)$ and $f(x')$ be highly correlated if $x$ is close to $x'$. The Gaussian generalization opens up using random functions for unknown functions (such as a regression function) in a Bayesian setting.

To introduce the Gaussian process as a random function, we will start by making the simplifying assumption that the input variable $x$ is discrete and can take only few different values, $x_1,\dots , x_q$. Hence, the function $f(x)$ is completely characterized by the $q$-dimensional vector $f = [f_1 \dots , f_q]^T = [f(x_1)\dots , f(x_q)]^T$. We can model $f$ as a random function by assigning a joint distribution to this vector $f$. In the Gaussian process model, this is the multivariate distribution,

```
$p(f) = \mathcal{N}(f|\mu, \Sigma),
```
