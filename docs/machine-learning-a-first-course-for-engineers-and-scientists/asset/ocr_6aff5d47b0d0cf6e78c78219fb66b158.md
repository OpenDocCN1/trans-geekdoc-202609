# 9.A The multivariate Gaussian distribution

This appendix contains some results on the multivariate Gaussian distribution that are essential for Bayesian linear regression and the Gaussian process. Figure 9.15 summarizes how they relate to each other.

![](bbox=[0.183, 0.219, 0.796, 0.442])

**Figure 9.15:** A graphical summary of how Theorem 9.2–9.4 and Corollary 9.1–9.2 relate to each other. In results, $z_a$ and $z_b$ are multivariate Gaussian random variables.

**Theorem 9.2 (Marginalization)** Partition the Gaussian random vector $z \sim N(\mu, \Sigma)$ according to

```
z = \begin{pmatrix} z_a \ z_b \end{pmatrix}, \quad \mu = \begin{pmatrix} \mu_a \ \mu_b \end{pmatrix}, \quad \Sigma = \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix}. (9.28)
```

The marginal distribution $p(z_a)$ is then given by

```
p(z_a) = N(z_a, \mu_a, \Sigma_{aa}). (9.29)
```

**Theorem 9.3 (Conditioning)** Partition the Gaussian random vector $z \sim N(\mu, \Sigma)$ according to

```
z = \begin{pmatrix} z_a \ z_b \end{pmatrix}, \quad \mu = \begin{pmatrix} \mu_a \ \mu_b \end{pmatrix}, \quad \Sigma = \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix}. (9.30)
```

The conditional distribution $p(z_a | z_b)$ is then given by

```
p(z_a | z_b) = N(z_a, \mu_{a|b}, \Sigma_{aa|b}). (9.31a)
```

where

```
\mu_{a|b} = \mu_a - \Sigma_{ab}\Sigma_{bb}^{-1}(z_b - \mu_b), (9.31b)
\Sigma_{aa|b} = \Sigma_{aa} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}. (9.31c)
```

**Theorem 9.4 (Affine transformation)** Assume that $z_a$ as well as $z_b | z_a$ are Gaussian distributed according to

```
p(z_a) = N(z_a, \mu_a, \Sigma_a). (9.32a)
p(z_b | z_a) = N(z_b; \mathbf{A}z_a + \mathbf{b}, \Sigma_{b|a}). (9.32b)
```
