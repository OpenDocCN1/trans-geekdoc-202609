The softmax function maps the output of the final layer $z = [z_1, ..., z_M]^T$ to $g = [g_1, ..., g_M]^T$ where $g_m$ is a model of the class $p(y_m|x)$. Note that the softmax function does not work as a classifier with different probabilities, it merely acts as a transformation of the output into the modeled class probabilities. The outputs of the softmax function will be in the interval $g_m \in [0, 1]$ and sum to $\sum_{m=1} g_m=1$, otherwise they could not be interpreted as probabilities. Since the output has dimension $M$, the layer of the weight matrix $W^{(L)}$ has dimension $M 	imes U_{L-1}$, and the offset vector $b^{(L)}$ has dimension $M$.

> **Example 6.1: Classification of hand-written digits - problem formulation

We the so-called MNIST dataset, which is one of the most well studied datasets in machine learning and image processing. Each data point consists of a $28 \times 28$ pixel grayscale image of the hand-written digit. The digit is size-normalized and centered within a fixed-sized image. Each image is labeled with the digit $0, 1, \dots, 8$, or 9 and it is depicted. In Figure 6.5, a base of 20 points from this dataset is displayed:

![](bbox=[0.118, 0.452, 0.882, 0.532])

In this classification we consider the image as our input $x = [x_1, ..., x_n]^T$. Each input variable $x_i$ corresponds to a pixel in the image. We have $n = 28 \times 28 = 784$ input variables which we flatten into one vector. The value of $x_i$ represents the intensity of that pixel. The intensity-value is within the interval $[0, 1]$, where $x_i=0$ corresponds to a black pixel and $x_i=1$ to a white pixel. The output is class $y_i \in \{0, ..., 9\}$. We mean in total have 10 classes representing the digits. Based on a set of training data $(x_i, y_i)_i$ with images and labels, the goal is to find a good model for the class probabilities

```
$p(y=m|x) \eqno m=0, ..., 9,$
```

other words, the probability that an unseen x belongs to the $M=10$ classes. Assume that we would like to use logistic regression to solve this problem with a softmax. That is identical to a neural network with just one layer, that (6.16) $L=1$. The parameters of that model would be

```
$W^{(1)} \in \mathbb{R}^{784 \times 10} \qquad b^{(1)} \in \mathbb{R}^{10}$,
```

which gives in total $784+10=7950$ parameters. Assume that we would like to extend this model to a two-layer neural network with $U=200$ hidden units. That would require two of weight matrices and offset vectors

```
$W^{(1)} \in \mathbb{R}^{784 \times 200} \qquad b^{(1)} \in \mathbb{R}^{200}, \qquad W^{(2)} \in \mathbb{R}^{200 \times 10} \qquad b^{(2)} \in \mathbb{R}^{10}$,
```

which is a model of $784 \times 200+200+200 \times 10=159000$ parameters. In the next section we will learn how to fit all of these parameters to the training data.
