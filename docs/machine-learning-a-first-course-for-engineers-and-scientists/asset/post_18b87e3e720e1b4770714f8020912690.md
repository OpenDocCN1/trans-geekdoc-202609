
## 5 Learning parametric models

As $L^2$ regularization, the regularization parameter $\lambda$ is to be chosen by the user, and has a similar meaning: $\lambda=0$ gives the least squares solution and $\lambda\to\infty$ gives $\theta=0$. Between these extremes, however, $L^1$ and $L^2$ give different solutions. Whereas $L^2$ pushes all parameters towards small (but not exactly zero), $L^1$ tends to favor sparse solutions where only a few of the parameters are non-zero, and the rest are zero. Thus, $L^1$ regularization can effectively 'switch off' some (by setting the regularization parameter $\theta_i$ to zero) and it can therefore be used as an input (or feature) selection method.

## General explicit regularization

The $L^1$ and $L^2$ regularization are two common examples of what we refer to as explicit regularization since they are both formulated as modifications of the cost function. They suggest a general pattern on how explicit regularization can be formulated,

$$\hat{\theta} = \arg\min_{\theta} J(\theta;\mathbf{x,y}) + \lambda R(\theta). \quad (5.27)$$

This expression contains three important elements:

- (i) the cost function

In this view, that explicit regularization modifies the properties of fitting to the training data (minimizing $E_{train}$) into something else, which happily minimizes $E_{new}$. The actual design of the regularization term $R(\theta)$ can be in many ways. As a combination of the $L^1$ and $L^2$ terms, one option is $R(\theta) = ||\theta||_1 + ||\theta||^2$, which is often referred to as elastic regularization. Regardless of the exact expression of the regularization term, its purpose is to encourage small parameter values and thereby decrease the flexibility of the model, which may improve the performance and lower $E_{new}$.

## 5.3 Regularization

Any supervised machine learning method that is trained by minimizing a cost function can be regularized as (5.27). There are, however, alternative ways to achieve a similar effect without explicitly modifying the cost function. One example of implicit regularization is early stopping. Early stopping is applicable to any method that is trained using iterative numerical optimization, which is the topic of the next section. It may appear counter-intuitively to prematurely abort an optimization procedure, before it has reached the minimum of the cost function. Although it has proven useful in practice and early stopping has shown to be of a practical importance to avoid overfitting for some models, most notably deep learning (Chapter 6). Early stopping can be implemented by setting some hold-out validation data and computing $E_{hold-out}$ for $t$ after each iteration $t$ of the numerical optimization. It is typically observed that $E_{hold-out}$ decreases until it reaches a value monotonically. The optimization is then aborted at the point when $E_{hold-out}$ reached its minimum, as we will illustrate later in Example 5.

Early stopping is a commonly used implicit regularization technique, but not the only one. Another technique with a regularizing effect is dropout for neural networks, which we discuss in Chapter 6, and data augmentation, which we discuss in Chapter 11. For decision trees the splitting criteria can be seen as a type of implicit regularization. It has also argued that the randomness of the stochastic gradient optimization algorithm in itself also has the effect of implicit regularization.

## 5.4 Parameter optimization

Many supervised learning methods, linear and logistic regression, involves one (or more) optimization problems, such as (3.12), (3.35) or (5.26). A machine learning engineer needs to be familiar with the main strategies for how to solve optimization problems fast. Starting in the optimization problems from linear and logistic regression, we will introduce the idea behind the optimization methods commonly used in machine learning. This section only gives a brief introduction to optimization theory and, for example, we will discuss unconstrained optimization problems.

Optimization is about finding the minimum or maximum of an objective function. Since the maximization problem can be formulated as minimization of the negative objective function, we can limit ourselves to minimization without loss.

There are primarily two ways in which optimization is used:

- 1. For training a model by minimizing the cost function with respect to $\theta$.
- 2. For tuning hyperparameters, such as $\lambda$.

In the presentation we will use $\theta$ to denote a general variable. An important advantage of convex functions is that any local minimum is also the global minimum.

## Optimization using closed-form

For linear regression with squared error, training the model amounts to solving (3.12)

$$\tilde{\theta} = \arg \min_{\theta} \frac{1}{n}|\mathbf{X}\theta - \mathbf{y}||^2$$

As we have discussed, and also proved in Appendix 3.A, the solution (3.14) to this problem can (under the assumption that $\mathbf{X}^TX$ is invertible) be derived if we spend some time to efficiently implement (3.14), for example using the Cholesky or QR factorization, we can use that every time we want to train a linear model with squared error.

If we want to use the $L^1$-regularized version, we have to solve (5.26)

$$\tilde{\theta} = \arg \min_{\theta} |\mathbf{X}\theta - \mathbf{y}||^2 + \lambda|\theta|$$

This problem cannot be solved analytically. Instead we have to use computer power to solve it, by constructing an iterative procedure for seeking the solution. With a certain choice of such an optimization algorithm, we can make use of analytical expressions along the line, which turns out to be an efficient way of solving it. Remember that $\theta$ is a vector containing $p+1$ parameters that we want to learn from the training data. As it turns out, if we seek the minimum for only one of these parameters, as $\theta_j$, while keeping the other parameters fixed, we can find out

$$\arg \min_{\theta_j} |\mathbf{X}\theta - \mathbf{y}||^2 + \lambda|\theta| = \sign(t)(|r_j| - \lambda), \text{where } t = \sum_{i=1}^{n} x_{ij}(y_i) - \sum_{k \neq j} x_{ik}\theta_k. \quad (5.28)$$
