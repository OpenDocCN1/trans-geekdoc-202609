To prepare for a concise mathematical notation, we use integers 1,2,...,M to denote the classes if M > 2. The ordering of these is arbitrary, and does not imply any ordering of the classes. When there are M = 2 classes, we have the special case of binary classification. In binary classification we use the labels -1 and 1 (instead of 0). Occasionally we also use the equivalent negative and positive labels. The only reason for using a different convention for binary classification is that it makes a more compact mathematical notation for some of the undefined functions in deep learning. # Example 2.1: Classifying

Suppose we want to say that a band is "homogenous", where the user records and the app answers by telling him if the style is either the Beatles, Kiss or Bob Dylan. At the heart of this fictitious app there has to be machinery that takes an audio recording as input and returns an artist name. If we first collect some recordings from the same genre (where we know which artist is below with labeled data, we could use supervised machine learning to learn the characteristics of their different styles and therefore predict the artist of the new user-provided song. In the supervised machine learning terminology, the artist name (The Beatles, Kiss or Bob Dylan) is the output y. In this problem we are facing a classification problem.

One of the important decisions for a machine learning engineer is a detailed specification of what the input is. If we use raw audio information as input, that would give a very high-dimensional x (which unless an audio-specific machine learning method is used would likely require an unrealistic amount of data in order to be successful). As input features we could use the length of the recording to represent the "perceptual" energy of the song. The length of the song is easy to measure. Since it is quite easy to do for different songs we take the actual length (in seconds) to get values in the same range for all songs. Such feature transformations are commonly used in practice to make the input data more

The energy of a song is a bit tricky and the exact definition may be ambiguous, leave that to the audio experts and use a piece of software that they have written for this purpose without bothering about it. As long as the software returns a number for any recording that is fed to it (and always returns the same number for the same recording) we can use it as an input to a machine learning method.
