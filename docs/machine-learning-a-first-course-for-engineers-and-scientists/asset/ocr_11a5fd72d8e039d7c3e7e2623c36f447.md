In problems where the training data is expensive, it is common to increase the training using more or less artificial techniques. Such techniques can be to duplicate the data and add noise to the duplicated versions, to simulate data, or to use data from a different but related problem, as we discuss in detail in Chapter 11. With such techniques (which indeed can be very successful), in the worst case (if the artificial training data is poor), $T$ is no longer drawn from $p(x,y)$, and we cannot expect the model to learn anything useful. It can be very useful to have a good estimate of $E_{new}$ if used during training, but a reliable estimate of $E_{new}$ can only be achieved from data we know are drawn from $p(x,y)$ (that is, collected under "product-like" circumstances). If the training is extended, it is extra effort to set aside a test dataset before that extension is done.
The error evaluation on the test dataset could be called "test error". To avoid confusion we do not use the term "test error" since it is used (ambiguously) as a name for the error on the test dataset as well as another name for $E_{new}$.

# 4.3 The training error-generalization decomposition of $E_{new}$

Designing a method with small $E_{new}$ is a central goal in supervised machine learning, and cross-validation helps in estimating $E_{new}$. However we can gain insights and better understand the behavior of supervised machine learning methods by analyzing $E_{new}$ mathematically. To be able to reason we introduce another abstraction, namely the training-data averaged versions of $E_{new}$ and $E_{train}$. To make the notation explicit, we write $E_{new}(T)$ and $E_{train}(T)$ to emphasize that both they are functions of some training dataset $T$. Let us not forget

```
$$\hat{E}_{new} \triangleq E_{new}(T)$,$\n$\hat{E}_{train} \triangleq E_{train}(T)$.$
```

Here, $\hat{E}$ denotes the expected value with respect to the training dataset $T = \{x_i, y_i\}_{i=1}^n$ (of a fixed size, assuming that this consists of independent draws from $p(x,y)$). Thus $E_{new}$ is the average if we de train the model multiple times on different training datasets, all of size $n$, and similarly for $E_{train}$. The point of introducing these two is that it is easier to reason about the average between $E_{new}$ and $E_{train}$ than the errors $E_{new}$ and $E_{train}$ obtained when the model is trained on one specific training dataset $T$.
