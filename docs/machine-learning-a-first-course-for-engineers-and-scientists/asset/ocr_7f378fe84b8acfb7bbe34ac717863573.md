# Input normalization

A important practical aspect when using $p=2$ input variables $x = [x_1, x_2]^T$ is the importance of normalization of the input data. Imagine a training dataset with values of $x_1$ in the much larger range [100, 1100] and the values for $x_2$ in the smaller range [0, 1]. It could be that $x_1$ and $x_2$ are measured in different units. The Euclidean distance between a test point $x$, and a training point $x_i$ is $\|x - x_i\|_2$. This expression will be dominated by the first term $(x_1 - x_{i,1})^2$, the second term $(x_2 - x_{i,2})^2$ tends to have a much smaller effect, simply due to the different magnitude of $x_1$ and $x_2$. That is, the difference leads $x_1$ to be considered more important than $x_2$ by $k$-NN.

To avoid this effect we can re-scale the inputs. One option, in the mentioned example, it could be to subtract 100 from $x_1$ and thereafter divide by 1000 and $x_1^{new} = \frac{x_1-100}{1000}$ such that $x_1$ and both are in the range [0, 1]. More generality, this normalization for the input data can be written

```
$x_{ij}^{new} = \frac{x_{ij}-min(x_{ij})}{max(x_{ij})-min(x_{ij})} \quad j=1,\dots,,p, \quad i=1,\dots,,n, \quad (2.1)
```

Another common way of normalization (sometimes scaling) is by using the mean and standard deviation in the training data:

```
$x_{ij}^{new} = \frac{x_{ij}-ar{x}_j}{\sigma_j} \quad j=1,\dots,,p, \quad i=1,\dots,,n_s, \quad (2.2)
```

It is crucial for $k$-NN to scale each input (normalization that was done in Figure 2.5), but it is a good practice to apply this when using other methods, or hence for numerical stability. It is however important to compute the scaling factors $(ar{x}_j, \sigma_j)$ using training data and then applying scaling to future test data. Failing this, we might lead to wrong conclusions on how the model will perform on prediction (not yet seen) data.
