# 3.2 Classification and logistic regression

The loss function $L(\mathbf{x}_i, \theta)$ above, is a special case of the cross-entropy loss, is called the logistic loss (or sometimes binomial deviation). Learning a logistic regression model then amounts to solve

```
$$\hat{\theta} = \arg\min_{\theta} \sum_{i=1}^n \ln(1 + e^{-y_i\theta^T\mathbf{x}_i}).\quad (3.35)$
```

Contrary to linear regression with squared error loss, the model (3.35) has no closed-form solution. Solving nonlinear optimization problems numerically is central to training of many machine learning models, not just logistic regression, and we will come back to this topic in Chapter 5. Now, however, it is enough to note that there exist efficient algorithms for solving (3.35) numerically for finding $\theta$.

# Predictions and decision boundaries

So far, we have discussed logistic regression as a method for predicting class probabilities for a test input $\mathbf{x}_*$, by first learning $\theta$ from training data and thereafter computing $\mathbf{g}(\mathbf{x}_*)$, our model for $p(y=1|\mathbf{x}_*)$. However, we want to make a "hard" decision for the test input $\mathbf{x}_*$, that is, predicting $\hat{y}(\mathbf{x}_*)=-1$ or $1$ in binary classification, just like $k$-NN or decision trees. We have to add a final step to the logistic regression, where the predicted probabilities are turned into a class prediction. The most common approach is to let $\mathbf{g}(\mathbf{x}_*)$ be the most probable class. For binary classification, we can express this

```
$$\hat{y}(\mathbf{x}_*) = \begin{cases} 1 & \text{if } \mathbf{g}(\mathbf{x}_*) > 0 \ -1 & \text{if } \mathbf{g}(\mathbf{x}_*) \le 0 \end{cases}.\quad (3.36)$
```

It can be that if $\mathbf{g}(\mathbf{x}_*)=1$, then the model provides a correct description of the real-world class probabilities, then the choice of $r=0.5$ might yield the smallest number of misclassifications on average. The misclassification rate, however, is not the most important aspect of classifier. Many classification problems are asymmetric (it is more important to correctly predict some classes than others) or unbalanced (classes occur with different frequency). In a medical application, it can be important not to fail to predict the negative class (that is, a sick patient predicting being healthy)
