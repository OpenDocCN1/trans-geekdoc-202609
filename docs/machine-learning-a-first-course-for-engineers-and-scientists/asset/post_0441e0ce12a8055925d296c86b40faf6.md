# Learning a regression tree

We will start by discussing how to learn (or, equivalently), a decision tree for a regression problem. The classification problem is conceptually similar and will be explained later.

As mentioned above, the prediction $\hat{Y}(x_*)$ from a regression tree is a piecewise function of the input $x_*$. We can write this mathematically as,

> $\hat{Y}(x_*) = \sum_{l=1}^{L} \hat{Y}_l \mathbb{I}(x_* \in R_l), \quad (2.3)$

where $L$ is the number of leaves in the regression tree, $R_l$ is the $l$-th leaf, and $\hat{Y}_l$ is the constant prediction for the $l$-th node. Note that the constant setting $\hat{Y}_l$ is a numerical value, and we will consider it to be a real for simplicity. In the equation above we have used the indicator function, $\mathbb{I}(x \in R_l) = 1$ if $x \in R_l$ and $0$ otherwise.

Learning from the data requires finding suitable values for the parameters defining the function (2.3), namely the regions $R_l$ and the constant predictions $\hat{Y}_l, l=1,\dots,L$, as well as the size of the tree. If we start by assuming the shape of the tree, the partition $(L, \{R_l\}_{l=1}^L)$ is known, then we can compute the predictions $\{\hat{Y}_l\}_{l=1}^L$ in a natural way, simply as the average of the training data points falling in each region:

> $\hat{Y}_l = \text{Average}(y_i : x_i \in R_l)$

To find the shape of the tree, the regions $R_l$, requires a bit more work. The basic idea is to select the regions so that the tree fits the training data. This means that the outputs from the tree should match the training data accurately. Unfortunately, even when restricting ourselves to simple regions like the “boxes” obtained by a decision tree, the tree fitting the training data turns out to be computationally expensive. The problem is that combinatorial explosion in the number of ways in which we can partition the input space. Searching through all possible trees is not possible unless the tree size is so small that it is practically useless.

# 2.3 A rule-based method: Decision trees

To handle this situation we use a heuristic algorithm known as recursive splitting for learning the tree. The recursive means that we will determine the splitting rules one after the other, starting with the first split at the root and then build the tree from top to bottom. Algorithm is *greedy*, in that we construct one split at a time, without having the complete tree “mind”. That is, by determining the splitting rule at the root, the objective is to obtain a model that explains the data as well as after a single split, without taking into consideration that additional splits may be needed before reaching the final model. When we have decided on the first split of the input space (corresponding to the root of the tree), this split is kept fixed and we continue in a similar way for the two resulting half-spaces (corresponding to the two branches of the tree),

To see in detail how one step of this algorithm works, consider the setting when we are about to do before very first split of the root. Here, we want to select one of the input variables $x_1,...,x_p$ and a corresponding point $s$ which divides the input space into two half-spaces,

```
$R_1(j,s) = {x|x_j < s}\quadquad\text{and}\quadquadR_2(j,s) = {x|x_j \geq s}\quadquad(2.4)$
```

Note that the regions depend on the index $j$ of the splitting variable as well as the value of cut point, which is why we write them as functions of $j$ and $s$. This is also the case for the predictions associated with the two regions,

```
$$\hat{y}_1(j,s) = \text{Average}(y_i : x_i \in R_1(j,s))\quad\text{and}\quad\hat{y}_2(j,s) = \text{Average}(y_i : x_i \in R_2(j,s))$$
```

For each training data point $(x_i, y_i)$ we can compute a prediction error by determining which region the data falls into and then computing the difference between $y_i$ and the constant prediction associated with that region. This total error can be written as

```
$$\sum_{i \in R_1(j,s)} (y_i - \hat{y}_1(j,s))^2 + \sum_{i \in R_2(j,s)} (y_i - \hat{y}_2(j,s))^2.\\quad(2.5)$$
```

The square is to ensure that the prediction above is non-negative and that both positive and negative errors are counted equally. The squared error is a *loss function* for measuring the closeness of a prediction and the training data, but we will discuss the choice of loss function in later chapters.

To find the optimal split we select $j$ and $s$ to minimize the squared error. This minimization problem can be solved by easily looping through all possible values for $j=1,...,p$. For each $j$ we search through possible splits and pick the pair $(j,s)$ for which expression is minimized. As pointed out, when we have found the optimal split at the root, this split is fixed. We then repeat the process in the same way for the left and right branch independently. Each branch corresponding to a half-space is split by minimizing the squared error over all training points which follows that: In principle, we can continue this until there is only a single training point in each region, $L=1$. A fully grown tree will result in predictions that exactly match the training data, and the resulting model is similar to k-NN. Using a stopping criterion means that the value of $L$ is not set manually, but determined adaptively based on the result of the learning procedure. A high-level summary of the method is given in Method 2. Note that in Method 2 includes a recursive call, where in recursion we grow one branch of the tree

Learn a decision tree using recursive splitting
**Data:** Training data $\mathcal{T} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$
**Result:** Decision tree with regions $R_1, \dots, R_L$ and corresponding predictions $\widehat{y}_1, \dots, \widehat{y}_L$

```
1 Let $R$ denote the whole space
2 Compute the regions $(R_1, \dots, R_L) = \text{Split}(R,T)$
3 Compute the predictions $\widehat{y}_t$ for $t = 1, \dots, L$

$$\widehat{y}_t = \begin{cases} \text{Average}\{y_i : \mathbf{x}_i \in R_t\} & \text{(Regression problems)}\\text{MajorityVote}\{y_i : \mathbf{x}_i \in R_t\} & \text{(Classification problems)}\end{cases}$$
```

```
4 Function Split(R,T):
5 if stopping criterion fulfilled
6 return R
7 else
8 Go through all possible splits $x_j < s$ for all input variables $j = 1, \dots, p.
9 Pick the pair $(j, s)$ that minimizes (2.5) for regression/classification problems.
10 Split region $R$ into $R_1$ and $R_2$ according to (2.4).
11 Split data $T$ into $\mathcal{T}_1$ and $\mathcal{T}_2$ accordingly.
12 return Split($R_1, \mathcal{T}_1$), Split($R_2, \mathcal{T}_2$)
14 end
```

Predict from a decision tree
**Data:** Decision tree with regions $R_1,\dots, R_L$, training data $\mathcal{T} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$, test point $\mathbf{x}_*$.
**Result:** Predicted output $\widehat{y}(x_*)$

```
1 Find the region $R_t$ which $\mathbf{x}_*$ belongs to.
2 Return the prediction $\widehat{y}(x_*) = \widehat{y}_t$.
```
