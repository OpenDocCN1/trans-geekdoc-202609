When choosing between the different criteria, the misclassification rate sounds like a reasonable choice that is typically the reason we want the final model to do well. However, one drawback is that it does not favor pure nodes. Pure nodes mean nodes where most of the data points belong to a class. It is always an advantage to use pure nodes in the greedy process that we use to grow the tree, since it can lead to a total of splits. Both the entropy and the Gini index provide more purity native than misclassification rate.

This advantage can also be considered in Example 2.6. Consider the first split in this example. If we could use the misclassification rate as the splitting criterion, but the split x₂ < 5.0 as well as the split x₃ < 3.0 would provide a total misclassification rate of 0.2. However, the entropy criterion, provides a pure node R₁. If we would go to grow the tree with the split x₂ < 5.0 the misclassification after the second split would be 0.2. If we were to grow the tree until no data points are misclassified we would need three splits or five splits if we used the entropy criterion or the misclassification rate and started with the split at x₂ < 5.0.

To generalize this discussion, consider a problem with two classes where we denote the proportion of the first class as π₁=r and the proportion of the second class as π₂=1-r, (2.7) each of them is expressed as

```
Misclassification rate: Qt = 1 - max(r, 1-r),
Gini index: Qt = 2r(1-r),
Entropy: Qt = -rln(r) - (1-r)ln(1-r).
```

These functions are shown in Figure 2.10. All criteria are similar in that they show zero error if all data points belong to either of the two classes. However, the Gini index and entropy have a higher loss if all data are equally divided between the two classes. In other words, the gain of having a pure node (to close to 0 or 1) is higher for the Gini index and the entropy than for the misclassification rate. As a consequence the Gini index and the entropy both tend to favor making a smaller loss, which can make a good combination with the greedy nature of recursive binary splitting.
