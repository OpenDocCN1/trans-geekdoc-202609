**Data:** Training data $\mathcal{T} = \{(\mathbf{x}_i, y_i)\i=1}^n$
**Result:** Decision tree with regions $R_1, \dots, R_L$ and corresponding predictions $\widehat{y}_1, \dots, \widehat{y}_L$

```
1 Let $R$ denote the whole input space
2 Compute the regions $(R_1, \dots, R_L) = \text{Split}(R,T)
3 Compute the predictions $\widehat{y}_t$ for $t = 1, \dots, L$

$$\widehat{y}_t = \begin{cases} \text{Average}\{y_i : \mathbf{x}_i \in R_t\} & \text{(Regression problems)}\\ntext{MajorityVote}\{y_i : \mathbf{x}_i \in R_t\} & \text{(Classification problems)}\end{cases}$$
```
