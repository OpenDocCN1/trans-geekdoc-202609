# Full CNN architecture

A full CNN architecture consists of multiple convolutional layers. For predictive tasks, we decrease the number of rows and columns in the hidden layers as we proceed through the network, but instead increase the number of channels to enable the network to encode more high level features. After a few convolutional layers we usually end the network with one or more dense layers. For an image classification task, we use a softmax layer at the very end to get outputs in the range [0,1]. The function when training a CNN will be the same as in the regression and classification networks explained earlier, depending on which type of problem we have. > Example 6.3: Classification of hand-written digits - convolutional neural network

In the previous models explained in Example 6.1 and 6.2 we placed the 28 x 28 pixels of each image into a vector with 784 elements. With this action, we did not exploit the information that neighboring pixels are more likely to be correlated than pixels further apart.
