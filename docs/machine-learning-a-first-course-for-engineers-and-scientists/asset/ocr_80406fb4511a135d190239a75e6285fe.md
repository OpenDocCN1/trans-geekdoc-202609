Furthermore, kernel-NN allows us to use k-NN for data where the Euclidean distance has not
natural sense. As we have a kernel which acts on the input space, we can apply kernel k-NN
even if the Euclidean distance is not defined for that type. We can then apply kernel-NN to
data that is neither numerical nor categorical, such as text snippets, which is illustrated by Example 4.

# Example 4: Kernel-NN for interpreting words

This example illustrates how k-NN can be applied to explain text, where the Euclidean distance has no
meaning and standard k-NN cannot be applied. In this example, input is single words (or
more technically), then we use the so-called Levenshtein distance to construct a kernel.
The Levenshtein distance is the number of single-character edits to transform one word into
another. It takes two strings and returns a non-negative integer, which is zero only if the two strings are
equal. It fulfills the properties of a metric on the space of character strings, and we can then
use it in the example using a squared exponential to construct a kernel $\kappa(x, x') = \exp(-\frac{LD(x, x')^2}{2\sigma^2})$ (where
LD is the Levenshtein distance), where $\sigma=5$.

In this small example, we consider a training dataset of 10 adjectives (each labeled
$(y_i)$ Positive or Negative). We will now use k-NN with our kernel k-NN (the kernel
defined to predict whether "horendous" is a positive or negative word). The first
column shows the Levenshtein distance LD between each labeled word ($x_i$)
 "horendous". The right column shows the value of the right hand side of (8.20), which is
value that k-NN uses to determine how close two data points are.

| Word | Meaning | Levenshtein dist. to $x_i$ | $\kappa(x_i, x_j) + \kappa(x_j, x_i) - 2\kappa(x_i, x_j)$ |
|---|---|---|--|
| Awesome | Positive | 8 | 1.44 |
| Excellent | Positive | 10 | 0.7 |
| Spotless | Positive | 9 | 1.60 |
| Terrific | Positive | 8 | 1.44 |
| Tremendous | Positive | 4 | 0.55 |
| Awful | Negative | 6 | 1.60 |
| Dreadful | Negative | 6 | 1.03 |
| Horrific | Negative | 6 | 1.03 |
| Outrageous | Negative | 6 | 1.03 |
| Terrible | Negative | 8 | 1.44 |

Inspecting the result, the column shows that horendous is the positive tremendous. Thus, if
we use $k=1$ the kernel concludes that horendous is a positive word. However, the second and third
closest words are all negative (dreadful, awful), and with $k=2$ or 4 the conclusion
becomes that horendous is a negative word (which also happens to be correct in case).

The purpose of this example is to illustrate how a kernel allows a basic method such as k-NN to be used
of a problem where the input has a more intricate structure than just being numerical. For the particular
ap of predicting word semantics, the character-by-character similarity is clearly oversimplified
approach and more elaborate learning methods need exists.
