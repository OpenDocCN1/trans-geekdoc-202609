## Conclusions on kernels for regression

With ridge regression and support vector regression we have been dealing with the interplay between three different concepts, each of them on interest. To clarify this, we repeat them in an ordered list:

- 1. We have the primal and dual formulation of a model. The primal formulation expresses the model in terms of $\theta$ (fixed size $d$), where the dual formulation uses $\alpha$ (one $\alpha_i$ per data point $i$, hence $\alpha$ has size $n$ no matter what $d$ happens to be). Both formulations are mathematically equivalent, or less useful in practice depending on whether $d > n$ or $n > d$.
- 2. We have kernels $(x, x')$ which allows to let $d \to \infty$ without explicitly formulating an infinite vector of nonlinear transformations $\Phi(x)$. This is practically useful when using the dual formulation with $\alpha$, since $d$ is the dimension of $\theta$.
- 3. We have used different losses. Kernel ridge regression makes use of squared error loss, whereas support vector regression uses the $\epsilon$-insensitive loss. The $\epsilon$-insensitive loss is particularly interesting in the dual formulation, since it gives sparse $\alpha$. (We will later use the hinge loss for support vector classification in Section 8.5, which has a similar effect.)

## 8.4 Kernel theory

We have defined a kernel as being a function mapping from the same space, and returning a scalar. We have also suggested that we can restrict ourselves to positive semidefinite kernels, and presented two practically useful algorithms—kernel ridge regression and support vector regression. Before we continue and support support vector classification, we will discuss more about the kernel concept, and also give a flavor of the theory behind it. To make the discussion more concrete, let us start by introducing the kernel method, namely kernel version of $k$-NN.

## Introducing k-NN

As know from Chapter 2, $k$-NN constructs the prediction for $\mathbf{x}_*$ by taking the average or a majority among $k$ nearest neighbors $\mathbf{x}$. In its standard formulation, "nearest" is defined by the Euclidean distance. Since the Euclidean distance is always positive, we can consider the squared distance which can be written in terms of the linear kernel $\kappa(\mathbf{x}, \mathbf{x}')$

```
$\|\mathbf{x} - \mathbf{x}'\|^2 = (\mathbf{x} - \mathbf{x}') \cdot (\mathbf{x} - \mathbf{x}') = \kappa(\mathbf{x}, \mathbf{x}) + \kappa(\mathbf{x}', \mathbf{x}') - 2\kappa(\mathbf{x}, \mathbf{x}') = (\mathbf{x} \cdot \mathbf{x}) + (\mathbf{x}' \cdot \mathbf{x}') - 2(\mathbf{x} \cdot \mathbf{x}')$.
```

To generalize the $k$-NN algorithm we will allow the linear kernel to be replaced by any, say, positive semidefinite kernel $\kappa(\mathbf{x}, \mathbf{x}')$ in (8.20). Kernel $k$-NN works as standard $k$-NN, but determines proximity between the data points using the right side of (8.20) with a user-chosen kernel $\kappa(x, x')$ instead of the left side of (8.20).

## 8 Nonlinear transformations and kernels

For many (but not all) kernels, it holds that $\kappa(x, x) = \kappa(x', x')$ = constant for $x$ and $x'$, suggesting the most interesting part of the right side of (8.20) is the term $-2\kappa(x, x')$. Thus, if $\kappa(x, x')$ a large value, the two data points $x$ and $x'$ are considered to be close, and versa. Thus, the kernel determines how any two data points are.

Furthermore, kernel-NN allows us to use k-NN for data where the Euclidean distance has not a natural sense. As we have a kernel which acts on the input space, we can apply kernel k-NN even if the Euclidean distance is not defined for that type. We can then apply kernel-NN to data that is neither numerical nor categorical, such as text snippets, which is illustrated by Example 4.

### Example 4: Kernel-NN for interpreting words

This example illustrates how k-NN can be applied to explain text, where the Euclidean distance has no meaning and standard k-NN cannot be applied. In this example, input is single words (or more technically), then we use the so-called Levenshtein distance to construct a kernel. The Levenshtein distance is the number of single-character edits to transform one word into another. It takes two strings and returns a non-negative integer, which is zero only if the two strings are equal. It fulfills the properties of a metric on the space of character strings, and we can then use it in the example using a squared exponential to construct a kernel $\kappa(x, x') = \exp(-\frac{LD(x, x')^2}{2\sigma^2})$ (where LD is the Levenshtein distance), where $\sigma=5$.

In this small example, we consider a training dataset of 10 adjectives (each labeled $(y_i)$ Positive or Negative). We will now use k-NN with our kernel k-NN (the kernel defined to predict whether "horendous" is a positive or negative word). The first column shows the Levenshtein distance LD between each labeled word ($x_i$) "horendous". The right column shows the value of the right hand side of (8.20), which is a value that k-NN uses to determine how close two data points are.

| Word | Meaning | Levenshtein dist. to $x_i$ | $\kappa(x_i, x_j) + \kappa(x_j, x_i) - 2\kappa(x_i, x_j)$ |
|---|---|---|---|
| Awesome | Positive | 8 | 1.44 |
| Excellent | Positive | 10 | 0.7 |
| Spotless | Positive | 9 | 1.60 |
| Terrific | Positive | 8 | 1.44 |
| Tremendous | Positive | 4 | 0.55 |
| Awful | Negative | 6 | 1.60 |
| Dreadful | Negative | 6 | 1.03 |
| Horrific | Negative | 6 | 1.03 |
| Outrageous | Negative | 6 | 1.03 |
| Terrible | Negative | 8 | 1.44 |

Inspecting the result, the column shows that horendous is the positive tremendous. Thus, if we use $k=1$ the kernel concludes that horendous is a positive word. However, the second and third closest words are all negative (dreadful, awful), and with $k=2$ or 4 the conclusion becomes that horendous is a negative word (which also happens to be correct).

The purpose of this example is to illustrate how a kernel allows a basic method such as k-NN to be used of a problem where the input has a more intricate structure than just being numerical.
