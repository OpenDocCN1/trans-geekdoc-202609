## 3.4 Generalized linear models

In this chapter we have introduced two parametric models for regression and classification, linear regression and logistic regression. The latter was presented as a way of adapting linear regression to the categorical nature of the output encountered in a classification problem. This was done by passing the linear regression through a nonlinear (in this case logistic) function, allowing us to interpret the output as a probability.

The same principle can be generalized to adapt the linear model other properties of the output and is referred to as generalized linear models. In the discussion we have focused on two specific problems containing two types of output data, real-valued regression ($y \in \mathbb{R}$) and classification ($y \in \{1,...,M\}$). These are most common instances of supervised regression problems and, indeed, they will be central to discuss of the methods and methods presented in this book.

In various applications we might encounter data with other output, not well described by either of the two standards. For instance, imagine the output corresponds to the count of earthquakes in a certain area during a fixed time, the number of people with a specific illness in a certain region, or the number of patients presented to a certain test. In such cases $y$ is a count taking one of the values $0, 1,...,$ (formally $y \in \mathbb{N}$), count data, being numerical in nature, is not well described by a linear regression of the form (3.2). The reason is that the linear regression model is not restricted to discrete values, neither whether to be non-negative, however we know that this is the case for the actual output $y$ that we are trying to predict. Neither this scenario fits a classification setting, where $y$ is numerical (that the values can be ordered) or there is no upper limit on how large $y$ can be.

To address this issue we extend our use of parametric models to encompass various probability distribution that can be used to model the conditional distribution $p(y|\mathbf{x})$. The first step is to choose a suitable form for the conditional distribution. This is part of the model design, guided by the properties of the data. Specifically, we select a distribution with support corresponding to that of the data (such as the natural numbers). Naturally, we still want to allow the distribution to depend on the input variable $\mathbf{x}$—modeling the relationship between the input and output variables is the fundamental task of supervised learning after all. However, this can be accomplished by first computing

a linear regression $z = \theta^T\mathbf{x}$, and then letting the conditional distribution $p(y|\mathbf{x};\theta)$ depend on $z$ in some appropriate way. We illustrate with an example.

### Example 3.6: Poisson regression

A simple model for count data is to use a Poisson likelihood. The Poisson distribution is supported on the natural numbers (including 0) and has mass function

```
$Poi(y;\lambda) = \frac{\lambda^y e^{-\lambda}}{y!}, \quad y=0, 1, 2, \dots$$
```

The so called rate parameter $\lambda$ controls the scale of the distribution and also its mean value, $\mathbb{E}[y] = \lambda$. To use this likelihood in a regression model for count data we can let $\lambda$ depend on the input variable $x$ and the model parameters $\theta$ through a linear regression $z = \theta^T\mathbf{x}$. However, the rate parameter $\lambda$ is restricted to be positive. To ensure that this constraint is satisfied, we model $\lambda$ according to

```
$$\lambda = \exp(\theta^T\mathbf{x})$
```

The exponential function maps the output from the linear regression component to the positive real line, resulting in a valid rate parameter for any $x$ and $\theta$. Thus, we get the model

```
$p(y|\mathbf{x};\theta) = Pois(y;\exp(\theta^T\mathbf{x}))$
```

referred to a Poisson regression model.

In this Poisson regression we can write the conditional mean of the output as

```
$\mathbb{E}[y|\mathbf{x};\theta] = \phi^{-1}(z), \quad \text{where} \quad z = \theta^T\mathbf{x}$
```

and $\phi(\mu) = \log(\mu)$. The idea of avoiding an explicit link between the linear regression term and the conditional mean of the output is what makes this follows the generic framework of generalized linear models. Specifically, a generalized linear model consists of:

- 1. A choice of distribution $p(y|\mathbf{x};\theta)$ from the exponential family of distributions.
- 2. A linear regression $z = \theta^T\mathbf{x}$.
- 3. A strictly increasing, continuous, link function $\phi$, such that $\mathbb{E}[y|\mathbf{x};\theta] = \phi^{-1}(z)$.

By convention, we map the linear regression through the inverse of the link function to obtain the mean of the output. Equivalently, if $\mu$ denotes the mean of $p(y|\mathbf{x};\theta)$ we can express the model as $\phi(\mu) = \theta^T\mathbf{x}$.

Different choices of distributions and link functions allow for regression with different properties. In fact, at we have already seen another example of a generalized linear model, namely Poisson regression. In binary logistic regression the output distribution $p(y|\mathbf{x};\theta)$ is a Bernoulli distribution, the is computed as $z = \theta^T\mathbf{x}$ and the link function is given by inversion (a more flexible model for count data than Poisson regression) and exponential regression (for non-negative real-valued outputs). Thus the generalized linear model framework can be used to model output variables with many different properties, and allows us to describe these models in a common language.
