+   * Use a **more flexible model** that is able to fit the training data better. This can be change a hyperparameter in the model we are considering, for example decreasing $k$ in $k$-NN or changing the model to a more flexible one, for example replacing a linear regression model by a deep neural network.
* **Extend the set of input variables.** If we suspect there are more input variables that carry information, we might want to extend the data with these input variables.
* **Use less regularization.** For course is only possible if regularization is used at all.
* **Train the model longer.** For models that are trained iteratively we can reduce $E_{train}$ by training longer.

It is usually a balance between reducing the training error and the generalization gap and measures to decrease one of them might result in an increase of the other. This balance act is also related to the bias-variance tradeoff discussed in Appendix 4.3.
We summarize the above discussion in Figure 11.2. Fortunately, evaluating $E_{train}$ and $E_{hold-out}$ is cheap. We only have to evaluate the model on the training data and the validation data, respectively. It gives us good advice on what actions to take. Besides what action to execute next, this also tells us what not to do. If $E_{train} \gg E_{hold-out} - E_{train}$, collecting more training data will likely not help. Furthermore, if $E_{train} \ll E_{hold-out} - E_{train}$, a more flexible model will likely not help.

# Learning curves

Of the different methods used to reduce the generalization gap, collecting more training data is the simplest and most reliable strategy. In contrast to the other techniques, collecting and labeling data is far more costly than consuming. Before collecting more data, we would like to tell how much improvement we can expect. Learning curves can give us such indication.
In a learning curve we train models and evaluate $E_{train}$ and $E_{hold-out}$ using different sizes of the training data. For example, we can train different models with $10\%$, $20\%$, $30\%$, $\dots$ of the available training data and plot $E_{train}$ and $E_{hold-out}$ with the amount of training data. By extrapolating these plots, we can get an indication of the improvement on the generalization gap we can get by collecting more data.
