# 8 Nonlinear transformations and kernels

First, it holds that a kernel $\kappa(x, x')$ is defined as an inner product between feature vector $\phi(x)$, as in (8.21), is always positive semidefinite. It can be, for example, shown by the equivalent definition of positive semidefinite $\mathbf{v}^T \mathbf{K} \mathbf{v} \geq 0$ for any vector $\mathbf{v} = [v_1 \dots v_n]^T$. By using (8.2b), the definition of matrix multiplication (first equality) and property of the inner product (second equality below) we can indent

```
$$\mathbf{v}^T \mathbf{K} \mathbf{v} = \sum_{i=1}^n \sum_{j=1}^n v_i \phi(x_i)^T \phi(x_j) v_j = \sum_{i=1}^n v_i \phi(x_i)^T \sum_{j=1}^n v_j \phi(x_j) \geq 0. (8.22)
```

Less trivial than the other holds that, for any positive semidefinite $\kappa(x,x')$ there exists a feature vector $\phi(x)$ such that $\kappa(x,x')$ can be written as an inner product (8.21). Technically it can be shown that for any positive semidefinite kernel $\kappa(x,x')$ it is possible to construct a function map, more specifically a Hilbert space, which is spanned by a feature vector $\phi(x)$ by which 8.21 holds. The dimensionality of the Hilbert space, and also the dimension of $\phi(x)$, can be infinite.

Given a kernel $\kappa(x,x')$ there are many ways to construct a Hilbert space spanned by $\phi(x)$, and we will only mention some others. One alternative is the so-called reproducing kernel map. The reproducing kernel map is obtained by one argument, say that, $\kappa(x,x')$ fixed and $x'$ span the Hilbert space with an inner product $\langle \cdot, \cdot \rangle$ such that $\langle \kappa(x,'), x' \rangle = \kappa(x,x')$ This inner product has a reproducing property, and alternatively the so-called Mercer kernel method which constructs the Hilbert space using an integral operator which is related to the kernel.

A given Hilbert space uniquely defines a kernel, but for a given kernel there exist multiple Hilbert spaces which corresponds to it. In fact this means that a kernel $\kappa(x,x')$ representing the feature vector $\phi(x)$ is not unique, in fact not its dimensionality. A simple example consider the linear kernel $\kappa(x,x') = \mathbf{x}^T \mathbf{x}'$, which can be expressed as an inner product between $\phi(x) = \mathbf{x}$ (one-dimensional $\phi(x)$) or as an inner product between $\phi(x) = \frac{1}{\sqrt{2}} [1, x^T]^T$ (two-dimensional $\phi(x)$).

# ### Examples of kernels

We will give a list of some commonly used kernels, which we have introduced above. These examples are only for the case when $x$ is a numeric value. For other types of input (such as in Example 8.4), we refer to the more specific application literature. We start with some positive semidefinite kernels, where the linear kernel is the simplest one

```
$$\kappa(x,x') = \mathbf{x}^T \mathbf{x}'. (8.23)
```

A generalization thereof, still positive semidefinite, the polynomial kernel

```
$$\kappa(x,x') = (c + \mathbf{x}^T \mathbf{x}')^{d-1}. (8.24)
```

with hyperparameter $c \geq 0$ and order $d-1$ (integer). The polynomial kernel corresponds to a finite-dimensional feature vector $\phi(x)$ of monomials up to order $d-1$. The polynomial kernel does not necessarily encapsulate anything that could not be achieved by implementing the primal formulation and formulation of $\phi(x)$ explicitly. This other positive semidefinite kernel below, on the other hand,

infines infinite-dimensional feature vector $\phi(x)$.

We have previously mentioned the squared exponential kernel,

```
$$\kappa(x,x') = \exp(-\frac{\|x-x'\\|^2}{2^2}). (8.25)
```

with hyperparameter $\ell > 0$ (usually lengthscale). As we see in Example 8.2, this kernel has of a "local" nature compared to the polynomial kernel $\kappa(x,x') \to 0$ as $\|x-x'\| \to \infty$. This property makes sense in many problems, and perhaps the reason why it is the most commonly used kernel.
