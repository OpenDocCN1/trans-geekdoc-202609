# Logistic regression for more than two classes

Logistic regression can be used for the multiclass problem when there are more than two classes, $M > 2$. There are several ways of generalizing logistic regression to this setting. We will follow one path using the softmax function which will be useful later when learning deep models in Chapter 6.

For binary problem, we use the logistic function to design a model for $g(x)$, a scalar-valued representing $p(y=1|x)$. For the multiclass problem we have to design a vector-valued function $g(x)$, whose elements are non-negative and sum to one. For purpose we use $M$ elements of (3.28), each $z_m$ each with a different set of parameters $	heta_m, z_m = 	heta_m x$. We stack all $z_m$ into a vector of logits $\mathbf{z} = [z_1 \ z_2 \dots z_M]$ and use the softmax function as a vector-valued generalization of the logistic function,

```
softmax(z) = \begin{pmatrix} e^{z_1} \ e^{z_2} \ \vdots \ e^{z_M} \end{pmatrix} / \sum_{m=1}^M e^{z_m}
```

The argument z to softmax is an $M$-dimensional vector, and it returns a vector of the same dimension. Consequently, the output of the softmax function always sums to 1, and each element is always $\ge 0$. Similarly to how we combined linear regression and the logistic function for the binary classification problem (3.29), we have now combined linear regression and the softmax function to model the class probabilities,

```
g(x) = softmax(z), \quad z = \begin{pmatrix} \theta_1^T x \ \theta_2^T x \ \vdots \ \theta_M^T x \end{pmatrix}
```

Equivalently, we can write out the multiclass probabilities, that is the vector $g(x)$ as,

```
g_m(x) = \frac{e^{\theta_m^T x}}{\sum_{j=1}^M e^{\theta_j^T x}}, \quad m = 1, \dots, M.
```

This is the multiclass logistic regression model. Note that this construction uses $M$ user parameters $	heta_1, \dots, \theta_M$ (one for each class). As for binary regression, we can learn the number of parameters to grow with $M$. Using the maximum likelihood method, we use $\theta$ to denote all parameters, $\theta = (\theta_1, \dots, \theta_M)$. Since $g_m(x)$ is our model for $p(y=m|x)$, the cost function for the cross-entropy (using negative log-likelihood) for the multiclass problem is

```
J(\theta) = -\frac{1}{n} \sum_{i=1}^n -ln g_{y_i}(x_i; \theta).
```
