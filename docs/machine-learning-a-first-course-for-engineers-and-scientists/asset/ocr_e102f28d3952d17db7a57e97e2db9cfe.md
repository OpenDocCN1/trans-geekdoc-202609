# A statistical view of the classification problem

Supervised machine learning amounts to predicting the output from the input. With a statistical perspective, classification amounts to predicting the conditional class probabilities

```
p(y = m|x) (3.25)
```

where y is the output (1, 2, . . . or M) and x is the input.³ In words, p(y = m|x) describes the probability for class m given that we know the input x. Talking about p(y|x) implies we think about the class label y as a random variable. Why? Because we choose to model the real world, from where data originates, as a certain amount of randomness (like the error e in regression). Let illustrate with an example.

> Example 3: Describing behavior using probabilities
We want to construct a model that can predict preferences (y = y, the categorical output) for population groups (x = the input). However then we have to face the fact that not everyone in a certain population group will vote for the same party. We can then predict of y as a random variable which follows a probability distribution. If we know the vote count in the group of 45 year old women (x = x) is 13% for the certain party, 39% for the turquoise party and 48% for the purple party (here we have M=3), we could describe it as
p(y = cerise party | x = 45 year old women) = 0.13,
p(y = turquoise party | x = 45 year old women) = 0.39,
p(y = purple party | x = 45 year old women) = 0.48.

In this way, the probabilities p(y|x) describe the non-trivial fact that

+   (a) all 45 year old women do not vote for the same party,
(b) the choice of party does not appear to be completely random among 45 year old women either; the\purple party is the most popular, and the cerise party is the least popular.

Thus, it is useful to have a classifier which predicts not only a class y (one party), but a distribution over classes p(y|x).

We now aim to construct a classifier which can not predict classes, but also the class probabilities p(y|x). For binary classification problems (M=2, and y is either 1 or -1), we learn a model g(x)

```
p(y = 1 | x) is modeled by g(x). (3.26a)
```

By the laws of it, it holds that p(y = 1|x) + p(y = -1|x) = 1, which means that

```
p(y = -1 | x) is modeled by 1 - g(x). (3.26b)
```

Since g(x) is a model for a probability, it is natural that 0 ≤ g(x) ≤ 1 for any y. We will see how this constraint can be enforced below.

> ³We use the notation p(y|x) to denote probabilities (y is discrete) or as densities (continuous).
