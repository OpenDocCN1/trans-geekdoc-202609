# **Method 10.5: Principal component analysis**

This section details the derivation of PCA. We summarize the procedure in Method 10.5.
It is interesting to note that the algorithm allows down to simply SVD to the centered data matrix $\mathbf{X}_0$, and this operation is independent of the choice of $q$. Here, in contrast with nonlinear autoencoders$^{15}$ we do not have to decide on the $q$ of latent representation beforehand. Instead, we decide for all possible values of $q$ from a simple SVD factorization. In fact, the orthogonal matrix $\mathbf{V}$ corresponds to a change-of-basis in $\mathbb{R}^p$. By defining a transformed matrix

```
$$\mathbf{Z}_0 = \frac{\mathbf{X}_0\mathbf{V}}{\sqrt{np}}_{n \times p} \quad (10.44)$
```

we have not lost any information in this transformation since $\mathbf{V}$ is invertible.
The columns of $\mathbf{V}$ represent the basis vectors of the new basis. From ordered in terms of importance, that is, the auto-encoder of dimension $q$ is given by the first $q$ columns, or basis vectors. We refer to these as the *principal axes* of $\mathbf{X}_0$, for arbitrary dimension $q < p$, meaning we can obtain the best low-dimensional representation of $q$ by simply picking the first $q$ columns of the transformed data matrix $\mathbf{Z}_0$. The coordinates of the data in this reduced space are the values in $\mathbf{Z}_0$, which are entered as the principal components (or scores). We also observe that we can obtain the principal components directly from the SVD since $\mathbf{Z}_0 = \mathbf{X}_0\mathbf{V} = \mathbf{U\Sigma\mathbf{V}^	op}\mathbf{V} = \mathbf{U\Sigma}$. We illustrate the PCA method in Figure 10.11 (left and right panel).

> Time limit 10.2: We have defined the principal components in terms of the centered data. However, we can also compute the non-principal components in the same way as $\mathbf{Z}' = \mathbf{ZV}$ (note that $\mathbf{Z}$ is still computed from the SVD of the centered data matrix). How is $Z$ related to $\mathbf{Z}_0$? How does this relate to the encoder mapping $\mathbf{z} = \mathbf{w}(\mathbf{x})$ that we derive later from?

At the beginning of this section we note that tight link between PCA and the covariance of the data. Indeed, an intuitive view of PCA is that it finds the directions in $\mathbb{R}^p$ along which the data vary. Specifically, the first principal axis is the direction with the largest variance. The second principal axis is the direction with the second largest variance, under the constraint that it should be orthogonal to the first axis and so on. This can be seen in Figure 10.11 where the principal axes are aligned with the directions of largest variance of the data.

To formalize this, note the (sample) variance of data is given by

```
$$\frac{1}{n}\sum_{i=1}^n(\mathbf{x}_i-\bar{\mathbf{x}})^	op(\mathbf{x}_i-\bar{\mathbf{x}}) = \frac{1}{n}\mathbf{X}_0^	op\mathbf{X}_0 = \frac{1}{n}\mathbf{U\Sigma^2\mathbf{U}^	op} = \frac{1}{n}\mathbf{V\Lambda\V}^	op \quad (10.45)$
```
