# 8.B Derivation of support vector classification

(8.42) we have the constraint $0 \le \beta_i \le \frac{1}{n}$, where the upper bound on $b_i$ comes from (8.41d) and the fact that $y_i \ge 0$. With $\alpha_i = \frac{y_i\beta_i}{2}$, we see (if noting that $y_i = 1/y_i$ since $y_i \in \{-1, 1\}$) that maximizing (8.42) is equivalent to solving

```
$minimize_{\alpha} \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i\alpha_j\phi^T(\mathbf{x}_i) - - \sum_{i=1}^n y_i\alpha_i \quad (8.43)$
```

or, using a matrix notation,

```
$minimize_{\alpha} \frac{1}{2}\alpha^T K(\mathbf{X},\mathbf{X})\alpha - \alpha^T\mathbf{y}. \quad (8.44)$
```

Finally noting that (8.41c) we have

```
$sign(\theta^T\phi(\mathbf{x}_*)) = sign(\frac{1}{2l}\sum_{i=1}^n y_i\beta_i\phi^T(\mathbf{x}_*)) = sign(\alpha^T K(\mathbf{X},\mathbf{x}_*)). \quad (8.45)$
```

and we have arrived at (8.35).
