Following the example, we get an indication on what improvement we can expect by tackling these issues. These numbers should be considered as the maximal possible improvement. To prioritize which aspect to focus on, we should also consider what strategies are available for improving them, how much progress we expect to make applying these strategies and how much effort we have to fix these issues.

For example, to improve the performance on tilted images we could try to extend the training data by augmenting it with more tilted images. This strategy could be investigated without much extra effort by augmenting the training data with tilted versions of the training data that we have already. Since, this could be applied fairly quickly and have maximal performance of 3%, it seems to be good to try out.

To improve the performance of pedestrians with safety reflectors, one approach would be to collect more images in dag conditions of pedestrians with safety reflectors. This obviously requires some manual work and can be questioned if it is worth the effort since would only give improvement of at most 1%. However, for this application we also argue that 1% is of extra importance.

Regarding the mislabeled data, the actions to improve on this issue is to manually go through data and correct these labels. In the example above we may say it is not worth the effort of getting an improvement of 1.5%. However, assume that we have improved the model with other actions to an accuracy of 98.0% on validation data and that still 1.5% of the total error is due to mislabeled data, this issue is no quite relevant if we want to improve the model further. Remember, the purpose of the validation data is to choose between different models. This purpose is degraded when the majority of the reported error on validation is due to incorrectly labeled data rather than the actual performance of the model.

There are two levels of ambitions for correcting the labels:

+   1. Go through all data points in the validation/test data and correct the labels.
2. Go through all data points, in comparison to approach 2, is the less amount of work it requires.

The advantage of approach 1, in comparison is the less amount of work it requires. Assume, that we have a 98% ~ 1% split of training-test data. Then there is 50 times less data to compare in approach 2. Unlabeling the mislabeled is systematic, correcting the labels in the training data does not necessarily pay off. Also, noting that correcting only in test and validation data does not necessarily increase the performance of model in production, but it will give us a more fair estimate of the actual performance of the model.

Applying the cleaning data to validation and test data, as suggested in approach 1, will result in the training data coming from a slightly different distribution than the validation data as well.
