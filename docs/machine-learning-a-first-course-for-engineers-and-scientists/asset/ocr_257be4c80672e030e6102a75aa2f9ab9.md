Example 4.2: Training and generalization gap for a regression problem

To illustrate how the training error and generalization gap behave, we consider a simulated problem so that we can compute $\hat{E}_{new}$. We let $n=10$ data points generated as $x \sim \mathcal{U}[-5, 10]$, $y=\min(0.1x^2, 3) + \varepsilon$, and $\varepsilon \sim N(0,1)$, considering the following regression methods:

+   - Linear regression with $L^2$ regularization
- Linear regression with a quadratic polynomial and $L^2$ regularization
- Linear regression with a third order polynomial and $L^2$ regularization
- Regression tree
- Random forest (Chapter 7) with 10 regression trees

For each of these methods, we try different values of the hyperparameters (regularization parameter and tree depth, respectively), compute $\hat{E}_{train}$ and the generalization gap.

For each method that minimizes $\hat{E}_{new}$ is the value which is closest (in the 1-norm sense) to the origin, since $\hat{E}_{new} = \hat{E}_{train}$ + generalization gap. Having decided on a certain model, and having only one hyperparameter to free, corresponds to the situation in Figure 4.3.

However, when we compare the different methods, a more complicated situation is revealed that when illustrated by the one-dimensional model complexity scale, the second (red) to the third order polynomial (green) linear regression: for some values of the regularization parameter, the training error decreases without increasing the generalization gap. Similarly, the generalization gap is small while the training error is large for the regression tree with a maximum depth of 2. This main takeaway is that these relationships are quite intricate, problem-dependent and impossible to describe using the simplified picture in Figure 4.3. However, as we shall see, the picture becomes somewhat clearer when we next introduce another decomposition of $\hat{E}_{new}$, the bias-variance decomposition, in particular Article 4.4.

In any real problem we cannot plot a such as in Example 4.2. This is only possible for simulated examples where we have full control over the data generating process. In particular instead we have to make a decision based on the much less information available. It is good to choose models that are well known for a specific type of data and use experience from similar problems. We can also use cross-validation for selecting between different models and choosing hyperparameters. Despite the simplified picture, the under- and over-fitting from Figure 4.3 can be very helpful when deciding on what method or hyperparameter value to explore with cross-validation.
