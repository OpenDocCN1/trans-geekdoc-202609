## 2.2. Random forest

Random forest (RF) models were constructed from the same dataset using 10-fold cross-validation (Chen et al., 2020). As an ensemble learning built upon DT, RF handles multiple classifications and regression tasks. Each DT or tree of RF was generated using the method (i) the original data was sampled a number of times (ii) at each step with bootstrap and each node of the tree was selected by the first best segmentation algorithm (iii) each tree was generated by aggregating a random set of features (iv) and left tree based on the best classification performance. With classifier models, RF is usually more accurate than other classifiers.

The RF model provides two importance of variables, i.e. mean accuracy decrease and mean Gin, for the ranking of variables. Mean accuracy decrease (MDI) measures the importance of a variable by calculating the change in the model accuracy when this variable is removed while mean Gin (MDI).

## 2.3. Evaluation of model performance

A 10-fold cross-validation was used to evaluate the accuracy of the DT and RF models. The data was divided into k independent subsets, D1/D2/D3/.../DK (k=10), and in each step (k-1) subsets of data were used to train and the remaining subset was used for verification, and the average value of k test results were finally finalized. The performance of each model was evaluated using precision (PR), recall (RE), accuracy (AC) and F-measured from the following equations TP, FN, TN and FP represent the values of true positive, false negative, true negative and false positive respectively (Deshmukh et al., 2016).

PR = TP / (TP + FP) Eq.(1)

RE = TN / (TN + FN) Eq.(2)

F-measured = 2 * TP * TN / (TP + FP + FN) Eq.(3)

Values of these metrics indicate the prediction capabilities of the model where a higher value indicates a better model, and a value of 1 indicates high performance (Chen et al., 2018). In the case of biological data, classification models showed >70% are accurate for classification. Additionally, receiver operating characteristic (ROC) analysis was used in the evaluation of performance in the prediction ability. The ROC curve is plotted by drawing all combinations of FP and TP rates, which is obtained by calculating the area under the curve (AUC). AUC > 0.9 is “excellent”, (0.9 ≥ AUC ≥ 0.8) is “good”, (0.8 > AUC ≥ 0.7) is “fair” (0.8 > 0.7)
