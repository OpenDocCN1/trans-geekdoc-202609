#  2. Methodology

# 2.1. Data acquisition and harmonization

A literature search of photoshesized AGNs with cytotoxicity was performed using various public databases (e.g., PubMed, Scopus, Web of Science, Elsevier, Springer, Wiley-Blackwell, Taylor & Francis and Research, from December 23 to October 4, 2020) and different combinations of (e.g., silver nanoparticles, AGNs + + cytotoxicity, AGNs + nanoparticles + toxicity). This initial analysis resulted in 876 reviewed original articles between 2003 and 2020. After removal of replicates and AGNs synthesized by non-biological methods (e.g., microorganisms, minerals), or without cytotoxicity or nanomaterial characterization, 178 publications meeting the following criteria were: i) AGNs synthesized by extracts of plants that can be attributed to a certain species; ii) cytotoxicity assay with time and expose dose but not restricted to the indicator of cell viability; iii) nanoparticles includes particle size (by TEM examination) and Zeta potential; which each has been reported more than once. The remaining AGNP-synthesizing plants that are most commonly reported in the literature, i.e. Cosaceae, Labiatae, Leguminaceae, Liliaceae, Rosaceae, Solanaceae, Theaceae and Verbenaceae, were selected

# 2.2. Machine learning

# 2.2.1. Design

Decision tree (DT) models were constructed using C4.5 algorithm of WEKA 3 data tool for the binary classification reported by Labauty et al. (2019). The data prepared for machine learning file was in csv format, with 690 data points and p corresponds to different features. In this work, two combinations of features were developed: DT1 used input set with 7 features (particle size, extraction solvent, expose dose, Zeta potential, Normal cell type and exposure time) and DT2 were based on the selection of 8 features (the 7 features used for DT1 and plus an additional feature of family). Each model produced classifiers that classify some feature with the label of cell viability (0 or 1). The subtree and the desired classifiers are supposed to have higher accuracy than the baseline classifier.
