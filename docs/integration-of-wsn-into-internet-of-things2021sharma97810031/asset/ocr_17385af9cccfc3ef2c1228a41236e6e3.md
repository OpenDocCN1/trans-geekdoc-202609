# TABLE 2.5 (Continued) Summary of WSN Attacks, Strategies, Effects, and Countermeasures

| Attacks | Strategy | Effects | Affected Layer | Solution |
| :--- | :--- | :--- | :--- | :--- |
| Unfairness | Tampering with MAC properties | Disrupt the WSN; partial DoS attack; Performance hampered | Datalink layer | Usage of small frames with small time frames |
| Interrogation | Abuses flow control signals; exploits MAC protocol | (RTS/CTS) is compromised | Datalink layer | Limit the RTS message; antireplay protection; an improved authentication mechanism |
| Sybil Attack | Compromises single nodes; many fake nodes creation | Control over the network; malicious nodes can create multiple identities | Datalink layer/network layer | Two-way authentication; unique shared symmetric keys; three-way handshakes, monitoring, flexible routing, egress filtering |
| Sinkhole | Sinkhole to the center of all the nodes | Capture traffic toward the affected node | Network layer | Geo-routing protocol |
| Hello flood | Send Hello packets to all senor nodes; high range radio transmission; laptop class attacks | Malicious node creation | Network layer | Increased authentication measures |
| Node capture | Gaining illicit access to the node | Active or passive control over the network | Network layer | Enhanced routing protocol; rate limiter |
| Selective forwarding | Blackhole node creation | Malicious node refuses to forward the message and drops it | Network layer | Multipath routing protocol |
| Wormhole attacks | Tunnel message passes through a low delay link | Link up two nodes; can create sinkhole; difficult to detect | Network layer | Tight time synchronization in nodal communication; using the shortest route |
