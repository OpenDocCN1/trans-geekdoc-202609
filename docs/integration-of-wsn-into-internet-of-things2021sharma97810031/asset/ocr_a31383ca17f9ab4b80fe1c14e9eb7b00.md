# 11.4.6 ACTUATORS

Sensors are essential in IoT. Similarly, actuators are also an important element of IoT. Both are opposite to each other. That is, sensors sense a signal to perform any action, while actuators act upon it. Sensors are always in an active position for detecting any change in the environment, while actuators wait for any alarming trigger to take any action.

To understand the need of sensors and actuators, we can go through an example of a smart air-conditioning system, where we can see that when the sensor senses that there is no person in the area, the actuator will act to stop the flow of air. Based on industry requirements, many applications demand actuators to perform turn-on and turn-off functions along with sensors to improve the result of the application at an advanced level.

# 11.4.7 PROTOCOLS

Protocols are always necessary for a communication system. Without protocols, the reliability, accuracy, security, and efficiency cannot be measured. Standard protocols play a crucial role in IoT; in other words, we can say “protocols are the set of rules and regulations through which a system can manage and control communication function to achieve its objective”.

Protocols help multiple physical objects of IoT to get connected and to transfer and exchange data with security and safety from one end to the other, so the key responsibility of protocols is to provide an effortless platform for communication using some secret language that allows two and more physical objects to connect with security.

For multiple Web and application-level services, the choice of selection of protocols depends on different functions, such as the speed of data transmission from one end to the other, the range of communication, the power consumption level, and operation efficiency. To measure all such factors, we have different types of communication protocols in IoT, for example, Bluetooth, Wi-Fi, Zigbee, and MQTT. The role of these protocols is to provide smooth communication with security and efficiency at every level of data transmission and data exchange in IoT.
