
### 12.3.1.11 Rank Attack

In RPL, the rank value rises from the root node to the child node. On modifying the rank value, an intruder can use a child node to improve some metric or select parents and to attract the huge traffic moving toward the root. The variability in the rank attack is formed on the existing attack span (discontinuous or continuous) and update or no update of DODAG Information Object (DIO) data in four different types and are assessed versus the network QoS parameters and into the RPL environment. Rank attack can have some consequences such as generation of a loop without any kind of detection, generation of a path that is unoptimized, presence of optimized paths in the topology that are not used at all, reduced delivery packet proportion with a small variation in the end-to-end delays when the number of attackers grows and the topology nearby the harmful node is furthermore supposed to be changed. More control overheads are created if the routing data are flooded in the DIO, then their neighbors also ought to flood their topology. Also, to defend rank attack version number and rank authentication (VeRA), this is the latest security service that prevents the mischievous node from reducing the rank values for the motive of attack. VeRA helps by preventing to publish an illegitimately reduced rank by producing hash chain, applying a random number that is decided by the root node. The newly produced hash chain is just a rank. Therefore, the intruder is unable to change the rank value because to change a rank value previous hash chain value is required.

## 12.3.2 Passive Attack

Passive attacks include eavesdropping and monitoring where the user is anonymous and the communication in IoT is not disturbed. Such attacks are used to collect user’s data in the absence of their permission and use these data to its maximum so as to gain the access to their secured and private data. Traffic analysis and eavesdropping are two important ways for a passive attack to take place via an IoT network. Also, the IoT device can be used as a sensor for the collection and misuse of some sensitive data and location of a user [29,30].

### 12.3.2.1 Passive Information Gathering (Eavesdropping)

IoT devices like AI speakers make use of audio sensors for receiving and dialing voice commands and some other attributes. When a harmful application is installed in an IoT device, it makes it feasible to eavesdrop for extracting and recording information and content of the conversation with the help of an audio sensor [31,32]. Voice assistant and soundcomber are typical attacks used for the implementation of eavesdropping. In this case, a harmful application secretly records a user’s conversation by the use of an IoT device sensor. Users are defenseless to the attack due to its recording application that runs in the background of the device. For example, when having a conversation with a financial company like a credit card company or bank, the user can be exposed to such threats if they disclose their personal data like social security or credit card number. A malware can be used as a voice assistant application which can be helpful for different harmful activities, for example, Wi-Fi and SMS transmission and voice command duplication. It can be handled through Wi-Fi and SMS external control channel. Li et al. [33] proposed a novel scheme of eavesdropping. With the use of unique features of eavesdropping, the complicated problem of mixed-integer nonlinear programming can be converted into a concave optimization problem by applying Lagrange multiplier method. Due to the inability of the proposed scheme of eavesdropping, when there is insufficient power of legitimate monitor for eavesdropping, then heuristic algorithm is applied to achieve a trade-off between the eavesdropping ratio and eavesdropping energy efficiency.

### 12.3.2.2 Node Outage

Node outage is a condition when a node halts the work. It might be malicious if the sufferer node and the principal node are the same for the network. This attack takes place when a node ceases to work properly to perform its regular functionality. For example, if a cluster head of a heterogeneous network does not accomplish its regular functionality, it makes the WSN protocols to be powerful enough for the negative impacts of such node outages to be overcome, by providing different routes for network paths or/and by electing new cluster heads.

### 12.3.2.3 Traffic Analysis

Traffic analysis is considered a major threat in a network. The intruder can infer a packet's content by analyzing the network traffic patterns, even if it is encrypted. Attacks like traffic analysis can exploit the susceptibilities in an encrypted smartphone communication to figure out the websites that are being viewed by a user. The nature of a web application can make it vulnerable to an attack. There are two parts of a web application: server side and client side. In this structure, the web applications need the packets to be exchanged across the network. The exchanged packet flow is enclosed with the network and it can be seized by a sniffer. If the network traffic is unencrypted, then it makes it easier to classify and identify the traffic by reading the content in the packet. Although the task is not that simple, it is still attainable when the traffic is encrypted. An intruder can infer packet content and find network traffic patterns by taking advantage of side-channel leaks with the state-of-the-art cryptographic techniques even though it is encrypted. Traffic feature consists of data related to secret payload like number of packets, length, and timing which are noticeable, and such information can be released by monitoring traffic. Therefore, these features provide a unique characteristic to the traffic.

## 12.4 ML FOR IIoT

In this section, ML techniques are presented that help in early-stage detection of attacks that take place in an IIoT system. Moreover, adequate solutions are provided for the IIoT systems by applying the various ML algorithms.

### 12.4.1 TECHNIQUES OF ML

It includes unsupervised techniques, reinforcement learning (RL), and supervised techniques. These techniques can be used to find the smart attacks that are present in the devices of IoT and can also help to build a secure policy of defense. Unsupervised and supervised learning techniques basically concentrate on the data analysis queries whereas RL is used for decision-making and comparison problems. This type of choice and categorization of ML technique mainly rely on the nature of the provided data. When the category of output and input data is acknowledged, supervised learning can be put to use. Therefore, the system is trained to map the inputs for the necessary outputs. Regression and classification are types of supervised learning techniques where regression works with classification and continuous work with discrete outputs. Hussain et al. [34] proposed an in-depth and systematic study of ML- and DL-based mechanisms on resource management in IoT and cellular wireless network.

### 12.4.1.1 Supervised Learning

It is one of the main learning methods in ML in which the product is distributed on the basis of a learning algorithm in which trained dataset is used as input. Supervised learning can be classified as regression learning and classification. Classification learning is a type of supervised algorithm of ML in which the product is fixed and a discrete value/category is given as [yes, no] or [false, true], etc. Following subsections demonstrate different kinds of classification learning such as random forest (RF), Bayesian theorem, association, k-nearest neighbor (KNN), and support vector machine (SVM). Supervised learning can be done when some specified targets are determined to be reached from some specific sets of inputs. In this sort of learning, first the data is labeled and then trained with the labeled data. It helps to automatically identify rules from the valid datasets, define various classes, and predict the elements that belong to that given class.

### 12.4.1.1.1 Support Vector Machine

This algorithm is applied to study the data that use classification and regression analysis. SVM makes a plane among two classes known as hyperplane. The main purpose of hyperplane is increasing the distance to its maximum from all the classes, which differentiates all the classes with less error on large margin [35]. When the hyperplane is nonlinear after an analysis, then SVM makes use of the kernel feature which adds some new features to make it linear. On some occasions, it is a bit difficult to utilize the optimal function in SVM. However, the excessive accuracy level of SVM makes it appropriate for the IoT security applications such as intrusion detection [36,37], smart grid attacks [38], etc.

### 12.4.1.1.2 k-Nearest Neighbor Algorithm

In supervised learning, KNN is referred to as a nonparametric statistical procedure which makes use of the Euclidean distance [39]. Also, the average value in KNN of an unknown node is determined, which is k-nearest neighbor, by using Euclidean distance [40]. For example, if a node is misplaced, then the average value of the nearest neighbor can be used to predict it. The produced value is not that accurate but somehow helps to find a possibly missing node. This method is usually applied in IoT for malware detection, anomaly detection, and intrusion detection.
