From this review of the literature, it is possible to note that substantial work has been done in evaluating the efficiency of these algorithms, mainly for Cortex devices and some hardware instances. Nonetheless, the WSN ecosystem is heterogeneous, and only a handful of devices are equipped with a Cortex processor, as can be observed in Table 5.6.

Runtime is a key metric for evaluating the performance of cryptographic algorithms. In the context of lightweight cryptography, lengthier delays represent greater energy expenditures. Some constrained devices are powered by batteries and must adhere to tight energy budgets. In most of these systems, the processing power is also limited, and if the security application takes too long to run, the device might not be able to perform its intended task in real time. The literature survey provided shows that most realizations of PQC have latencies surpassing a million cycles. If this is coupled with the low operational frequencies of some WSN devices, these security algorithms become borderline unusable.

In the context of general-purpose cryptography, modern computers might not have any trouble to allocate the thousands of bits required to store the keys for most PQC algorithms. In contrast, some constrained devices (for which lightweight cryptography is required) would find it difficult to sustain these overheads. Multiple challenges ought to be addressed before PQC is of practical use for WSN motes and similar
