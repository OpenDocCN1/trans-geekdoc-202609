
## 15.3.1 A THREE-FACTOR ANONYMOUS AUTHENTICATION PROTOCOL FOR WSN-BASED IOT TECHNOLOGY

The emergence of "smart devices" showed the relevance of technology that could be used in the diagnosis and physiological and biomedical data monitoring. This has largely been attributed to growing wireless technology and the use of relatively simple technologies such as RFID for remote sensing and control. Although to make sensors wearable, unobtrusive, and energy-efficient, a balance between high-end complex authentication protocols and privacy of the data is often made. In previous research conducted in 2009, a way for authentication in WSNs involving the use of smart cards was developed, and this sparked the development of further protocols and mechanisms for user authentication [14]. Later, the research came under scrutiny for several weaknesses such as mutual authentication, key agreement, and user anonymity and suffered from attacks such as gateway bypassing, sensor node capture, and DoS attacks. This quest to achieve authentication in WSNs in IoT environments was carried forward by the development of a two-factor authentication system using the elliptic curve cryptosystem which provided better security than traditional crypto-mechanisms that drew less on the computational resources of sensor nodes. However, the issue of mutual authentication, key agreement, and user anonymity persisted [15]. The two-factor authentication system was then upgraded by Shi et al. [16] in 2013 only to be found that the system was prone to unknown key-share attacks and stolen smart card attacks. Further developments in this field led to the development of user authentication systems by temporal credentials which were criticized for offline password guessing, modification, and impersonation attacks [17]. The later improved version of Xue's authentication scheme was found to be prone to user impersonation and tracking attacks [18, 19]. To counter all these challenges, Jiang et al. [20] suggested an untraceable user authentication scheme using ECC. All these efforts to improve user authentication while optimizing computational resource consumption had a scope of improvement. A few of the major challenges faced were clock synchronization and session-specific information attacks, imperfect alignment with IoT environments, and lack of wrong password detection and password change mechanisms.

These challenges are solved by the proposed three-factor anonymous user authentication protocol. The protocol exploits fingerprint identification by the fuzzy commitment scheme, which is one of the most widely used biometric authentication methods. Unlike Jiang's proposed authentication scheme that allowed three phases in authentication, the three-factor authentication scheme allows for four phases, inclusive of sensor registration, user registration, login, authentication, and password change, hence keeping the benefits of the earlier proposed model. The proposed model suggests the use of a random number method to ensure the freshness of exchanged messages and avoids the use of time stamp; this ensured that messages being sent belong to the current session only. It also ensures that the user's anonymity is ensured in the mechanism by ensuring that no communication message contains the user's identity. Further, to ensure that the adversary is unable to trace different sessions of the user from the exchanged messages via a public channel, different random numbers are generated for each session, which makes login request messages of one session different from the other. This anonymity feature is similarly used for sensor nodes. Besides all these benefits, the mechanism is highly efficient in password change. Further, unlike other authentication mechanisms, the use of a trusted party between the user and sensor nodes for transferring sensory data also ensures the life cycle of sensor nodes is increased along with reducing the expenditure of energy on communication.

So, with all the mentioned benefits of the given protocol, it can reduce the risk of impersonation or forgery attacks, stolen smart card attacks, specific session information attacks, insider attacks, and replay attacks with time stamp along with bolstering user anonymity, untraceability, and effective unauthorized log-in detection. It also introduces the concept of key agreement and mutual authentication while maintaining efficient communication and computational expenditure on low-powered devices.

## 15.3.2 GEOGRAPHIC OPPORTUNISTIC ROUTING BASED ON SELECTIVE AUTHENTICATION AGAINST DOS ATTACKS

The healthcare industry in the past two decades has witnessed multiple technological strides being made that have helped reduce the onus of inculcating expensive physiological data testing done in laboratories to be made by an unobtrusive, pervasive system of wearable sensors. These wearable systems of devices have made physiological monitoring of users and, hence, the diagnosis of ailments and diseases easier for medical staff in a more quantifiable and comprehensive manner. However, with these growing devices that rely heavily on wireless communication, the issue of privacy and security gained traction. Depending on the various forms of shortcomings of these systems, those with malicious intent have found multiple ways to attack and to lay hands on sensitive data procured by these devices. One of the foremost forms of attack is the DoS (denial of service) attack.

One of the most pivotal reasons attributed to the success of WSNs in the healthcare industry is wireless data delivery. However, until recently, the data delivery system was based on primordial multi-path routing strategies. The data transmission hence became susceptible, which was prone to link failures owing to signal fading or interferences. This led to the development of opportunistic routing where the path of data packets was not predetermined, but multiple data forwarders are allowed to overhear the packet transmission due to their shared network. Then, the data are routed by prioritizing the packet as directed by the sender of the data packet. This is further channeled through multiple data forwarders, and therefore, data delivery occurs uninterrupted as long as one data forwarder relays the information successfully. This is known to have minimal transmission contentions as arising in the multi-path routing method and improved performance. The routing method used in opportunistic routing is further coupled with geographic routing as it utilizes the dynamic nature of the WSNs and does not use a single established route or node for transmission, but rather uses multiple paths.

However, the DoS attacks are further aggravated in opportunistic routing since the attackers send invalid data with illegitimate signatures to nodes to disrupt normal operations, and opportunistic routing reliably delivers these invalid data to the receiver. Therefore, a security authentication system that validates the legitimate data packets and checks whether they are modified or tampered with before transmission is necessary. However, this security transmission system would not be free from challenges. First, the computational cost and time required to validate every data packet would mean that the data transmission is delayed. Secondly, it would result in shifting prioritization of data in nodes from transmission to verification, which would incur further costs in the resources of nodes. Thirdly, the transmission of data packets carrying the information regarding the removal of duplicate data to reduce redundant verification at each node would mean increased data with each packet. These challenges can be overcome using a lightweight authentication mechanism that would mitigate DoS attacks and share the verification scheme between data forwarders and relayers.

Selective authentication-based geographic opportunistic routing is important to counter all mentioned challenges and create a reliable and secure network. This routing mechanism utilizes statistical state information of wireless networks to build an SSI-based trust model. Along with a secure routing mechanism, it uses an entropy-based selective authentication algorithm that works on performing signatures to increase data integrity. This associates the high-entropy signatures with uncertain states and the low-entropy signatures with certain states, thereby utilizing this parameter for authentication and reducing the computational burden. Further, inculcating a verification scheme employs "verification message" and "warning push" in which the "verification message" helps to reduce the burden on forwarding nodes to perform redundant verification, thereby, restoring priorities to data transmission. The "warning push" is used to isolate the adversaries by communicating the verification information of invalid signatures. By extensive comparison, the aforementioned selective authentication-based geographic opportunistic routing can block 80% of invalid data and save 50% of computational resources. This scheme is found to be a very effective defense against future DoS attacks even in prevalent wireless networks [21].
