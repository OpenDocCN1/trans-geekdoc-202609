# 5.2 LIGHTWEIGHT CRYPTOGRAPHY

Ensuring the security of any piece of information implies upholding a set of characteristics deemed necessary to guard the interests of the owner of these data. The most important of these services include:

+   - Confidentiality: Only authorized parties can access the data.
+   - Integrity and Authentication: Data cannot be modified by unauthorized parties, and the data source can be verified.
+   - Availability: Data are available to the authorized parties at any given time.

Malicious actors work against these services. During the transmission of data, an attacker can eavesdrop on the communication channel, modify the messages, forge messages, or disturb the data flow. All these actions can have negative effects on the communication between the parties. In order to thwart these threats, the parties can make use of cryptographic solutions for providing one or more security functions.

Most of these algorithms such as ciphers and media access control (MAC) functions require the parties to share a common piece of information-denominated key. These keys grant the user with network access by being recognized as an authorized user of the channel. The establishment of these common pieces of data is on itself a critical security service for networked environments. Providing constrained devices with security services, mainly by means of cryptography, is not an easy task. Implementing cryptographic procedures implies burdening the underlying system with security overheads. Lightweight cryptography has surged as a possible solution for this problem. To date, lightweight cryptographic realizations mostly consist of ciphers and hash functions, which aim at providing confidentiality, integrity, and authentication for constrained devices. These primitives are critical for creating affordable security solutions on WSNs and similar IoT domains. However, lightweight versions of more complex mechanisms, such as the ones required for safe-guarding network access, have been rarely studied.

Public-key cryptography (PKC), also called asymmetric cryptography, is critical for providing networks with services that would otherwise be difficult to achieve in a secure way. Key establishment protocols, authentication protocols, and digital signatures are the most popular algorithms in this field. In this group, systems based on elliptic curve cryptography (ECC) have been considered as the most practical asymmetric solution for constrained devices. The strength of ECC relies on the difficulty of finding discrete logarithms over elliptic curve groups: the discrete logarithm problem over elliptic curve groups (ECDLP). The hardness of this problem, compared with contemporary alternatives such as the integer factoring problem and the discrete logarithm problem over multiplicative groups, allows for using smaller key pairs in ECC, which derives in higher efficiency for these algorithms.
