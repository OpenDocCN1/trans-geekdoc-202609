As data are sent as packets, the authentication mechanism can be applied at the packet level. On the other hand, replay packets can also be secured with antireplay protection to counter this attack. This can be defended by using a combination of both.

Deluge attack: This is also known as a reprogramming attack. It attacks the programming codes of the nodes. In the case of remote maintenance, the attacker can gain access to the node and control a small to considerable portion of the network by reprogramming the nodes. Better administrative authentication and increased security at entry points into the nodal software would defend against deluge attacks. A secure communication scheme using a secure protocol and secure coding can be used to counter this type of attack.
