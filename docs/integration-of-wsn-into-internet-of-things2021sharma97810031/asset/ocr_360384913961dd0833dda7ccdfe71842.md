# 9.2.2 RESEARCH ON POWER QUALITY

In Ref [21], a harmonic estimation technique was proposed for implementation in
a low-cost digital signal processor (DSP), which addresses a new technique for the
harmonic estimation (amplitude and phase) with reduced computational complexity
for implementation in a DSP. The technique uses the demodulation of the signal
followed by filtering. As a result, harmonic estimations in 1/2, 1, and 2 cycles of
the fundamental component were obtained. Results obtained with synthetic elec-
trical signals and real (measured) signals indicate that the proposed technique is quite
interesting for implementation in a low-cost DSP. The suitability of the technique for
implementation on a finite precision is assessed using the DSP TMS320F2812.

In [22], a system for detecting and classifying disturbances in the quality of elec-
trical energy (QEE) was presented, which is based on the decomposition of the volt-
age signal into two new signals, referring to the fundamental component and the
error signal. Then, it uses eighth-order statistics to extract representative parameters
from each class to simplify the detection and classification algorithm. As a detector,
an algorithm based on Bayes’ theory was used, and to implement the classification
algorithm, an artificial neural network was used. The system was tested in simula-
tions for six classes of disturbances, presenting an overall efficiency close to 100%
for such disturbances.
