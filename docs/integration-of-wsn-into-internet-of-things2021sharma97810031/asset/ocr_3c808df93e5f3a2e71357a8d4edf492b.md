+   - Unified: the framework can be fitted into any system, even an existing system with ease as the requirements for this are simple.
+   - Scalable: the framework can be scaled up or down as per need.
+   - Best of Constraint Devices: the solutions described by the framework are resource-efficient, therefore best of resource-scarce and devices with constraints.
+   - Solution for Each Layer: the framework provides solutions for every layer of the CPS architecture.
