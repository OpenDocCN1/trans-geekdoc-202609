### 11.7.2 Multi-Service Layer

The key responsibility of this layer is to maintain the various application process, data management services, and data analytics by adopting filtering techniques over a huge amount of data and perform data mining rules for analysis and decision-making for smart IoT applications. The primary duty of this layer is to design rules and standards for business and process control. Such rules help IoT for managing interoperability among different objects and technologies for doing IoT operations smartly. Take, for example, a GPRS-based traffic control application, where the system is always ready to perform analytics over traffic raw data based on the current situation to provide the best decision for selecting the route on time. Similarly, in the case of some medical emergency, the IoT system smartly reacts with the emergency indication for alarming hospital staff to aware about the patient's condition for treatment behind this analysis multi-service layer uses rules engine, analytical decision tools, logical programming for enabling IoT system interactive and more responsive.

### 11.7.3 Network Layer

The key responsibility of the network layer is to provide an effortless communication service platform for the IoT system. This layer takes care of transport medium and management of data connection with privacy and security contribution. Sensors produce a huge amount of data that need a robust communication medium (wired or wireless) with efficient processing and transport rate. IoT communication domains are not limited to a specific area. IoT supports heterogeneous kinds of network domains that consider private, public, and hybrid categories of communication network to serve better in any scenario requiring various communication protocols that can support machine-to-machine as well as low- or high-range communication in a real-time application environment. The following are the features of this layer:

- It ensures the best transport medium for communication throughout the process of communication.
- It ensures medium security and privacy.
- It controls and maintains latency, bandwidth, and data processing rate as required.
- It supports public, private, and hybrid models of network for communication.
- It supports and integrates different technologies with heterogeneous configuration to work together.

### 11.7.4 Sensor Layer

This is the lowest layer among all layers. The sensor layer takes care of the collection of smart devices with integrated sensors to get access to, control, and process smart IoT services efficiently. Sensors have a predefined programming that allows any device to get connected with any object either physically or virtually according to the need and structure of communication. The primary role of sensors is to collect all the contextual information from the environment where it exists; therefore, in IoT, various types of sensors are used for different tasks. According to the programming of the sensor, we can take various measurements such as temperature, pollution in air, humidity in the atmosphere, and water quality [9,10]. As per the need of application, some of the sensors may also have memory for the storage of measurements for the purpose of comparison, future research, and other scientific operations. The best feature of sensors is that they can record any measurement, and after collecting the measurement, it can converted into signals, so the receiving devices can get it in a proper way. Sometimes, applications need a group of sensors to perform any operation. In that case, many sensors are grouped together for any specific purpose, for example, body measurement sensors for observing real-time health condition and home appliance sensors for accessing, monitoring, and controlling smart home devices from some remote location.
