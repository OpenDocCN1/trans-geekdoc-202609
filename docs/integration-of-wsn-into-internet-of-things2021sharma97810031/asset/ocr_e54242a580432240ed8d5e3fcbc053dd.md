However, for WSN motes, longer processing times imply higher energy expenditures. Processors are generally optimized to finish a task and go into hibernation; hence, it is desirable to complete this task in a short time. Let us consider the Cortex-M3 and Cortex-M4 32-bit processors as a case study. The former was released in 2004 and used in WSN motes such as the Preon32 and the OpenMote. The later, released in 2010, has been employed as a popular benchmarking platform for PQC algorithms as it can be observed in Table 5.5. The shortest latency results for the Cortex-M4 were reported in [39] for the Round5 key encapsulation mechanism, totaling 982,000 cycles for a full key exchange. In contrast, a performance-oriented realization of ephemeral ECDH with 128-bit classical security from [49] requires a latency of 729,900 cycles on the Cortex-M4 processor (using the FourQ elliptic curve and clocked at 8 MHz). While the performance estimates are close if we account for the frequency variations, the ECC solution requires 80 bytes for key storage whereas the PQC alternative uses 1,348 bytes, almost 17 times as much. Summarizing, high-end WSN motes could deliver similar performance and energy results if they were updated to implement the faster PQC algorithms, but they would need to assign significantly more memory to cryptographic tasks.

# ## 5.5.2 PROMOTING THE BASE STATION AS UNIQUE IOT GATEWAY

WSNs are heterogeneous in nature, yet there is a common piece of equipment that can be found in any deployment of these technologies: a base station (BS). This element, which generally takes the role of a personal area network (PAN) coordinator and general collector in classical WSNs, is a device endowed with higher processing capabilities and storage than the actual sensor nodes.

These BSs have conventionally been used as the access point for the users to the harvested data. Following this approach, some WSNs could chose to have the BS as the single element fully merged into the IoT ecosystem, whereas the leaf nodes are left outside of the grid. Hence, the motes would not be concerned with the potential costs of future quantum-safe IoT standards.

On first sight this appears to be an acceptable compromise. But we must consider that the leaf nodes would not be able to rely on conventional PKC for creating secure channels, which might open the WSN to a wide range of threats. Second, not providing the motes with internet access would affect the quality of service for the user as the data would first need to be routed to the single access point. This is also detrimental to modern WSN paradigms such as Edge and Fog computing. Lastly, if the BS is the single internet access point of the WSN, this provides attackers with a clear attack target for compromising the operability of the WSN.
