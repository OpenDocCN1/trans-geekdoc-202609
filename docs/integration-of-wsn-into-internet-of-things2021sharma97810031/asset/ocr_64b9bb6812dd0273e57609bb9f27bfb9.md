# 6.1 INTRODUCTION

Wireless network embraces nodes that are having a self-organized property and are arranged in a sudden fashion. Mobile ad hoc network (MANET) is a type of infra-structure-less network under the category of wireless networks that do not need any fixed infrastructure for communication [1].
