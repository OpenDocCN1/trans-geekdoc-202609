AES, originally named as Rijndael, represents today the most commonly used encryption algorithm. It was developed by two Belgian cryptographers Vincent Rijmen and Joan Daemen. ### 4.3.2 Artificial Neural Networks

ANN, commonly referred to as neural networks, represent one of the most commonly used AI algorithms as they are successfully applied to a variety of problems (Patterson, 1998). They consist of input and output layers as well as an arbitrary number of hidden layers between the input and output layers. Those layers consist of artificial neurons that represent the basic building blocks of every neural network. Furthermore, artificial neurons consist of input synapses with attached weights, summing functions with applied bias, and activation functions (Schalko, 1997). During the training of the neural network, weights and biases get updated according to the data and desired outcomes. During the training process, they are slightly updated with every iteration until they reach satisfying values and thus produce the desired outcome results. To achieve training capabilities, a few more techniques and algorithms are used, which will be explained below (Schalko, 1997). Besides weights and biases, the summing function sums all values from synapses that are modified by weights and then adds a bias value to the summed value. Then, the summed value is propagated to the activation function of the neuron that adds nonlinearity to the data in the network (Karlik and Olgac, 2011). By this, more complex functions could be optimized, besides simple linear functions. Some examples of activation functions are Sigmoid, TanH, ReLU and Leaky ReLU. For neural networks to work, besides their initial structure, they have additional algorithms and rules to adapt to a specific problem: gradient descent with a cost function, forward propagation, and backpropagation.

To update weights and biases is an important neural network training progress. Also, to use that value properly, other algorithms need to know how to utilize that value to resume the training in the right direction. For this to be operative, we use a gradient descent and cost (or loss) function.

Therefore, cost function provides a value that tells how good the current step is in the neural network. Gradient descent (Mandic, 2004) uses that value and tries to minimize it and works as follows: It tries to find the global minimum of the complex function (given as a given problem to solve) by iterating step-by-step to the global (or sometimes local) minimum. To know in which direction to take the next step, the gradient first needs to be calculated (the equation presents the commonly used cross-entropy cost function to calculate the gradient):

```
f'(w,b)=-\frac{1}{m} \sum_{i=1}^{m} y^{(i)} \log(\hat{y}^{(i)}) + \left(1 - y^{(i)}\right) \log\left(1 - \hat{y}^{(i)}\right)
```

where \(\hat{y}\) is given by

```
\(\hat{y} = \sigma \left( w^T x + b \right)\)
```

and \(\sigma\) by

```
\(\sigma \left( z \right) = \frac{1}{1 + e^{-z}}\)
```

where \(\sigma\) represents the sigmoid function, which, in this case, is also used to calculate the needed gradient. It maps every given value to the range [0, 1] to avoid many problems that can occur when too big values appear in the network (e.g. exploding gradients). The given equations represent only a single iteration of the network. To optimize the neural network, this process needs to be repeated in many iterations. In the end, weights and biases are updated using the gradients:

```
\(w := w - \alpha \frac{dJ(w, b)}{dw}\)
```

```
\(b := b - \alpha \frac{dJ(w, b)}{db}\)
```

where \(\alpha\) represents the learning rate and \(\frac{dJ(w, b)}{dw}\) or \(\frac{dJ(w, b)}{db}\) is the derivative that is calculated during the updating process. These updates are made during the back-propagation phase, which will be explained in more detail.

Forward propagation is pretty simple: it propagates values from the input of the network, throughout the hidden layers, to the final output layer (Agatonovic-Kustrin and Beresford, 2000). During forward propagation, values from the input of the network are modified using weights, biases, and neuron functions to map the input to the desired output value. Forward propagation is also used during the production when network parameters are frozen, and the network is ready for real-world usage. Lastly, backpropagation is the most important element of the neural network (Agatonovic-Kustrin and Beresford, 2000). Its responsibility is to correctly update weights and biases throughout the network. This is done by calculating the error rate after forward propagating, and using that error rate to update weights and biases.

This process is done using the chain (Ambrosio and Maso, 1990). It works by calculating the derivatives of nested equations:

$$f(x) = A(B(C(x)))$$ (4.6)

We can calculate derivatives of the chain rule equation (4.6) by:

$$\frac{df}{dx} = \frac{dA}{dB} \frac{dB}{dC}$$ (4.7)

or in another form such as

$$f' = A'(B(C(x)))B'(C(x))C'(x)$$ (4.8)

As such, the chain rule can be applied to any size of nested functions in the back-propagation algorithm. Furthermore, as the chain rule is used to calculate derivatives during backpropagation, the next step is to determine how much each weight and bias will be modified throughout each iteration. First of all, the error rate of the final layer is calculated as

$$\delta_i^m = g_o'(a_i^m)(\hat{y}_d - y_d)$$ (4.9)

This error is then propagated throughout every hidden layer until the first input layer:

$$\delta_j^k = g'(a_j^k) \sum_{l=1}^{r_{k+1}} w_{jl}^{k+1} \delta_l^{k+1}$$ (4.10)

This function is called for every hidden layer in the network. Then, the evaluation of error partial derivatives relative to every weight value:

$$\frac{\partial E_d}{\partial w_{ij}^k} = \delta_j^k o_i^{k-1}$$ (4.11)

Afterwards, all gradients for every input–output (x, y) pair are combined to get the global gradient for all pairs:

$$\frac{\partial E(X,\theta)}{\partial w_{ij}^k} = \frac{1}{N} \sum_{d=1}^N \frac{\partial}{\partial w_{ij}^k} \left( \frac{1}{2} (\hat{y}_d - y_d)^2 \right) = \frac{1}{N} \sum_{d=1}^N \frac{\partial E_d}{\partial w_{ij}^k}$$ (4.12)

And at the end, weights are updated relative to the learning rates of the gradient descent:

$$\Delta w_{ij}^k = -\alpha \frac{\partial E(X,\theta)}{\partial w_{ij}^k}$$ (4.13)

Weights are updated with every iteration until the gradient descent reaches a global minimum of the function. This is the core process of the proposed methodology, and by this, it can find mutual information between the cypher messages and secret keys.

## 4.4 RESEARCH METHODOLOGY

Alongside the development of new algorithms, as well as upgrading the old ones, it is a must to develop techniques to prove the security of new or upgraded algorithms. The methodology presented in this chapter represents a new approach to examine the security of cryptographic algorithms. Precisely, the goal of the proposed methodology is to determine the information mutual to the encrypted message and the secret key. Encrypted messages and secret keys contain a lot of information that is presented as a long series of bits. Because these series contain a lot of information, it is almost impossible today to find the correlation between them using the classical programming approach. Therefore, the proposed methodology exploits AI algorithm-automatization capabilities (in this case, neural networks) to discover relationships between the encrypted messages and secret keys.

To determine the dependency between the cyphertext and key, an algorithm searches many cypher messages encrypted by the same key. During this process, it tries to find patterns by which the algorithm encrypts the message with a single secret key. To make this possible, the algorithm is trained on a bunch of cipher key pairs, where all keys are grouped by the first bit of the key. Training on this structure of data, the algorithm tries to find patterns and to determine the first bit of the secret key. If it succeeds, it becomes proof that an encryption algorithm produces cyphers with a certain pattern that is correlated to the secret key. As a result, it shows that the encryption algorithm is not secure, which means that it is not ready for use in real-world problems.

The real power of this approach is that no one needs to define the type of pattern to be searched. The AI algorithm does everything by itself. It makes this methodology easily applicable to any encryption algorithm in no time.
