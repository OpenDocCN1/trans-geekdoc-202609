The IoT structure has a lot in common with CPS. However, IoT is more restrictive in forms of connection than the CPS as IoT only connects to devices, whereas CPS has vaster interactions with the physical world as well. The architecture, as illustrated in Figure 10.5, consists of five layers stacked on each other. The functions of the layers are described in Table 10.3 [29].

# TABLE 10.3
Description of CPS architecture

| Layer | Description |
|---|---|
| Configuration | Provides with feedback from cyberspace to physical space and control for supervisors or the machine for self-configuration. Acts like a resilience control system that is used to apply corrective and preventive decisions. |
| Cognition | Generates reports and gives a well-managed monitoring system. The monitoring systems are then used to provide expert users with information to support decision-making abilities. |
| Cyber | Acts as a central hub of information that is being pushed in from every connected device. These data are used for interpreting the data and providing analytics for self-comparisons among the fleet of machines. |
| Conversion | Infers meaningful information from the data received. The system needs to compute a vast amount of data to come to a near-perfect conclusion. Researchers have developed algorithms for estimating the remaining useful life of the devices which can be calculated to bring self-awareness to the devices. |
| Connection | Responsible for having smart connections to everything such as devices on a network and physical objects as well. The CPS application might obtain data by sensors or controllers of Enterprise Resource Planning (ERP), Manufacturing Execution System (MES), Supply Chain Management (SCM), and Capability Maturity Model (CMM) [29]. |
