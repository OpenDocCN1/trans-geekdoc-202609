# 8.2.3 TECHNOLOGIES AND TOOLS

The technologies that find their applications in power grids incorporate the use of big data. Some of these technologies are discussed in the subsections below.

+   - IoT: Smart home appliances, transport, community facilities, etc. constitute the data that are derived from the IoT. Energy productivity, consistency, and grid security are applications that enjoy benefits that are made accessible by IoT, which are possible due to the rising number of progressions happening in this field. IoT has characteristics that are very similar to those of the big data in terms of their data generation and the type of data being generated [28, 29].
+   - Cloud Computing: The storing and processing of big data should be done with low cost while being analyzed fast, effectively, and consistently. The use of this technology ensures that big data can be developed to change IT substructure, make valuable conclusions regarding businesses, and also solve the problems of storing and processing by applying parallel cloud computing.
+   - Further Used Technologies: Network functions virtualization is a network technology that can transfer the majority of the data by providing malleable resource division and optimization possibilities. The reaction of the information processing in real time is very critical to microgrid applications. The storm is one such application that embodies the same.
+   - Hadoop: This includes applications in searching for a network, analysis on clickstream, filtering of spam, etc. Cloud view uses Hadoop to analyze the data generated by a machine with the framework of cloud computing. Hadoop includes a file system that is distributed and stores data and an execution engine that processes the data.
+   - Data Centers: This is a platform for bulk data storage, which also provides a lot of services such as data attainments, establishments, and supervisions. Constructing a center with desired qualities (proficiency, dependability, expandability, etc.) can help provide infrastructure to previous services, which in turn decreases cost and energy emissions.
