## 2.2 BACKGROUND OF WIRELESS SENSOR NETWORKS

Sensors are different from other devices because of their physical appearance, connectivity, and protocols needed to set up the network, scalability, connectivity, and usability. This part of the study contains an overview of the WSN characteristics, sensor attributes, requirements, types of WSNs, and different layers.

### 2.2.1 CHARACTERISTICS

Characteristics have made WSNs unique. These are briefly described below [16]:

- Low-Powered Nodes: Sensor nodes are low powered (small battery powered). These devices are implemented in areas that are not conventional, along with their traditional usage at home and industry. Low power ensures the smaller size and low cost.

- Wireless: The nodes are connected wirelessly with each other. The structure is ad hoc (no fixed structure) in nature. The nodes can operate independently and are supposed to maintain minimal faults. On the other hand, this specific characteristic can be the cause of potential vulnerability because of its variable network structure.

- Efficient: Sensor nodes are cheap. Depending on the nature of implementation, the number of nodes in a wireless network varies (typically a few to thousands). If the nodes are too expensive, the initial setup cost might be higher. Moreover, the replacement cost for damaged nodes will be significantly elevated. The cost-efficient nature, both in installation and for maintenance, is another reason for its widespread usage and acceptance.

- Communication Protocols: In a traditional network, the nodes are mobile devices, laptops, or computers, etc. These nodes are given an internet protocol (IP) address to be identified and communicated inside the system. Their protocol stack is also different. On the other hand, in the case of WSNs, the structure is ad hoc, and they cannot be assigned any specific IP. So, these types of systems need some particular protocols to communicate with each other and with the primary node. Several standards have also been developed for WSNs. These sensors establish a communication protocol for the network.

- Deployment Environments: Sensors are usually deployed in unconventional, risky, and surveillance environments due to their small, low-powered, cost-efficient nature. Becoming connected wirelessly has added more advantages. Their implementation in the military was one of their first practical uses. Later, the usage increased. Nowadays, it is used in disastrous and hostile environments.

- Memory: Sensors are equipped with minimal memory. This memory stores the initially collected data. Sometimes, sensors are implemented in remote and harsh areas where constant communication is severed. Communication occurs at regular intervals. In that case, the sensors need to store a minimal amount of data for those specific intervals. Moreover, for connection errors, sometimes data transfer might get delayed. So, storage is needed in this case also.

- Processing Capability: Wireless sensor nodes are equipped with minimal processing capability. This minimal processing power preprocesses the data in the nodes before sending them.

### 2.2.2 WIRELESS SENSOR NETWORK COMPONENTS

Wireless sensor nodes collect data from the environment. Nodes communicate among them multihop hopping and send the data to the base station (BS). The BS is connected to the internet. It connects the sensor nodes with the external network. Commands can be sent through the BS, and the nodes can be manipulated according to the need. Sensor network components comprise of the following:

- Sensing Unit: This includes a group of nodes and analogue-to-digital converter (ADC). It collects data from the environment around the sensor where it is installed and converts the analogue data using the ADC and sends them to the processing unit [17,18].

- Processing Unit: The processing unit comprises the processor and the storage unit. The processor determines how to communicate with the other nodes and data processing. For the processor, several components like microprocessors, microcontrollers, and FPGA (Field-Programmable Gate Array) can be used. Nowadays, microcontrollers also support storage (non-volatile), which is used for the memory of the node. On the other hand, despite several disadvantages, FPGAs can be used for the processing unit also through reprogramming.

- Transceiver: For this part, several things are considered. Available schemes and their characteristics are shown in Table 2.1 [4].

- Power Unit: All the components mentioned above are connected to the power unit. Hence, the power unit is critical. Given the smaller size of the node, it is much more challenging and may be considered as one of its weaknesses. Several technologies are in place to power the nodes. In this case, both rechargeable and nonrechargeable techniques may be considered according to the application environment. In some cases, at present, power units in the node are recharged using solar power or vibration. Moreover, the power-saving mode is also available in the nodes [19].
