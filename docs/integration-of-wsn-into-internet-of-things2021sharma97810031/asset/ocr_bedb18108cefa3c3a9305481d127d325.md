# 5.4 POST-QUANTUM CRYPTOGRAPHY

Quantum computers that are capable of breaking modern security standards are not available yet, but it is estimated that they might appear by 2030 [28]. One can think that there is still time to migrate from current solutions to quantum-resistant alternatives. However, a vey feasible scenario implies that a malicious actor can start storing our, today secure, communications and eventually gain access to the data when a large-enough quantum computer is eventually created.

Cryptographic algorithms that are believed to be secure in the foreseeable post-quantum world are said to pertain to PQC. As reviewed in Tables 5.2 and 5.3, whereas symmetric standards will have to be updated, asymmetric cryptography will need to be redesigned for resisting quantum attacks.
