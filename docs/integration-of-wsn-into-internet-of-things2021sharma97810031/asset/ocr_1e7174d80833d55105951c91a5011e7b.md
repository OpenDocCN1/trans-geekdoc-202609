Only the correct receiver will be able to decipher the correct code using his/her private key and the sender’s public key. Digital signatures are the cyber-counterparts of hand-written signatures backed up by very hard algorithms. They can be decoded only by the receiver with the use of their own private key and the sender’s public key.
