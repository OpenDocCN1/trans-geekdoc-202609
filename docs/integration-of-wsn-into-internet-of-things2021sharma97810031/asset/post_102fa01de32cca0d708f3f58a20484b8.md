## 6.4 OPTIMIZATION TECHNIQUES

The routing protocols suffer from a number of limitations: the network’s complexity increases on increasing the number of nodes, link failures, etc. Therefore, different optimization techniques were used to find the shortest path between the sources and their destination. The two optimization techniques discussed are ACO and swarm intelligence-based optimization.

### 6.4.1 ACO TECHNIQUE

This optimization technique resolves the issue of routing in MANETs. The algorithm works in a manner similar to how a number of ants follow the routes that are used by the other ants. They do not search for other paths rather travel on the same path saving time. The utilization of ACO in MANETs has favorable features. It is formed on demand. It is a path between the source and destination breakdown, and it uses instantly accessible possible paths. For what ant moves in networks node to node and keeps in track of all the information about the nodes that are being visited. During data transfer, first the path is searched, and if it is freely available, then data are sent, otherwise packet is stored in buffer and for what ant leaves in order to search for the destination. In order to seek the shortest path, the ant uses a chemical substance referred as pheromone from their place to the food supply. Routes that have a high probability of secretion are traversed by other ants. The same concept is applied in routing to find the best-suitable shortest path between the source and destination. In

### 6.4.2 SWARM INTELLIGENCE-BASED OPTIMIZATION TECHNIQUE

Gunes et al. [56] have suggested ant colony-based routing for MANETs. It contains the following phases: the fault tolerance, discovery of route, and maintaining route. Zulfiqar Ali et al. [57] suggested methods for routing with evolutionary programming, neural networks, ACO, and particle swarm optimization. The following parameters are used for evaluating performances such as the selection of minimal path, consumption of energy sources, and overhead. Toqeer Mahmood et al. [58] gave an improved idea by analyzing network delays for dynamic routing in MANETs. Optimization techniques use ant-based strategies for calculating the shortest path among multiple alternatives with minimum cost, which is employed as input for particle swarm optimization techniques. The following steps take place during this process: the selection of random particles for minimum solution, initialization of position and velocity, and minimum distance of node selection by comparing it with all neighboring nodes.

## 6.5 PERFORMANCE OF DIFFERENT ROUTING PROTOCOLS

Different routing protocols like AODV, DSDV, and DSR are simulated over the network simulator. Several parameters are being used in the simulation process. Omnidirectional antenna is used that has an axis from where radio wave power is radiated symmetrically. Queue tail is of 50. Different types of queues can be used such as priority queue and drop tail. By default, drop tail is used, which is a queue management algorithm used by network schedulers to decide when to discard the entry of new packets in the queue. This queue drops the packets when it is filled to its maximum capacity, until free space is available to accommodate newly arriving packets in the queue. Constant bit rate is used for the communication of traffic at constant bit rate; where there is time synchronization between the traffic source and destination. Nodes have been deployed over an area of 500 m ×500 m and varied to 20, 40, 60, 80, 100 nodes. The topology is designed based on multihop communication. The time duration of simulation is 100 seconds. The simulation parameters used and their values in network simulators are displayed in Table 6.3.

| S. No. | Parameters | Values |
|---|---|---|
| 1 | Simulation area | 500×500 |
| 2 | Number of nodes | 20,40,60,80,100 |
| 3 | Length of queue | 50 |
| 4 | Traffic type | Constant bit rate |
| 5 | Simulation time | 100 seconds |
| 6 | Antenna used | Omnidirectional |
| 7 | Type of queue | Drop tail |
| 8 | Routing protocols | AODV, DSDV, DSR |

The performance of different routing protocols has been evaluated using ns2 simulator. Two performance metrics has been taken into consideration: throughput and end-to-end delay.

- Throughput: Between two nodes, the number of information packets transferred per unit of time.
- End-to-End Delay: It is calculated as average time taken for a packet to move from the starting node to the ending node.
