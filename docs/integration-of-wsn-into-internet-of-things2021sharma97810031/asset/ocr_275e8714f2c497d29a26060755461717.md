That is, M appears as a fake identity of Z for U. So, if U wants to send data to Z, it will be forwarded to M,which is a malicious identity of Z.

Wormhole Attacks: In this attack, tunnel messages pass from one part of a network to another part of the network over a low delay link. Then, the message goes out of bounds to the attacker. Although different from black hole attacks, wormhole attacks are on a similar plane. Wormhole attacks can threaten a WSN that is encrypted and adopts authentication. It can also transform into a sinkhole if the attacker can alter routing information on their end of the wormhole to lure in data by making other routes appear costlier. Wormholes are challenging to detect and could be added with Sybil attacks of selective forwarding [68,69]. Optimum time synchronization in nodal communications and a geographically shortest route can be used to counter the attack. A minimum hop routing algorithm might help counter this attack [70].

# 2.3.3.4 Transport Layer Attacks and their Countermeasures

Flooding: In this attack, the infected node repeatedly tries to connect with different nodes. For connection creation, a node needs some resources such as bandwidth and power. If a flooding attack attacks a node, the resources are exhausted due to repetitive connection creation requests. Flooding attacks can be prevented through a client-side puzzle that deters attacking entities. More so, placing a limit for connections from each node prevents exhaustion caused by flooding attacks. Various resource optimization algorithms can also be used as a countermeasure against this attack [71].

Desynchronization Attacks: Synced communication between nodes is at the heart of WSNs. Attackers may attempt to destabilize this by transmitting missed frame signals between two nodes, thereby causing garbage communication and energy wastage. The attacker sends a missed frame message to one or both ends to transfer it to the whole network. The network falls in a loop to synchronize the recovery protocol and drains energy. Transmission of control messages to test synchronization between nodes, packet encryption, and packet-wise authentication can resolve this threat. In addition, for the missed frame, the number of repetitive requests can be limited to prevent it.

# 2.3.3.5 Application Layer Attacks and Countermeasures

Overwhelm Attack: Attacker tries to overwhelm network nodes to pass large amounts of data to the BS. As a result, the network bandwidth and energy drains away. The perpetrator may attempt to generate overwhelming sensor stimuli for nodes in a WSN, thereby leading to an enormous amount of false BS traffic. For this reason, the energy is drained.

To efficiently counter the attack, a rate limiter can be used along with data aggregators. Moreover, fine-tuning the sensor nodes can be a useful strategy. The tuning should include designing the node’s instruction set so that it reacts to only the effective and authentic stimuli.

Path-Based DoS Attack: As this is a DoS type of attack, the attacker will try to make the devices unavailable. As in this attack, the connection path between the nodes and the BS is unavailable. The attacker targets the leaf nodes and injects replayed packets. Due to repetitive injection, the path to the BS becomes occupied, and all the other nodes cannot connect the base.
