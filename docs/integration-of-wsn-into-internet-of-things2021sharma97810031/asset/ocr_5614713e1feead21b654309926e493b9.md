# 12.4.1.1 Supervised Learning

It is one of the main learning methods in ML in which the product is distributed on
the basis of a learning algorithm in which trained dataset is used as input. Supervised
learning can be classified as regression learning and classification. Classification
learning is a type of supervised algorithm of ML in which the product is fixed and
a discrete value/category is given as [yes, no] or [false, true], etc. Following subsec-
tions demonstrate different kinds of classification learning such as random forest
(RF), Bayesian theorem, association, k-nearest neighbor (KNN), and support vector
machine (SVM). Supervised learning can be done when some specified targets are
determined to be reached from some specific sets of inputs. In this sort of learning,
first the data is labeled and then trained with the labeled data. It helps to automati-
cally identify rules from the valid datasets, define various classes, and predict the
elements that belong to that given class.

# 12.4.1.1.1 Support Vector Machine

This algorithm is applied to study the data that use classification and regression
analysis. SVM makes a plane among two classes known as hyperplane. The main
purpose of hyperplane is increasing the distance to its maximum from all the classes,
which differentiates all the classes with less error on large margin [35]. When the
hyperplane is nonlinear after an analysis, then SVM makes use of the kernel feature
which adds some new features to make it linear. On some occasions, it is a bit diffi-
cult to utilize the optimal function in SVM. However, the excessive accuracy level of
SVM makes it appropriate for the IoT security applications such as intrusion detec-
tion [36,37], smart grid attacks [38], etc.

# 12.4.1.1.2 k-Nearest Neighbor Algorithm

In supervised learning, KNN is referred to as a nonparametric statistical procedure
which makes use of the Euclidian distance [39]. Also, the average value in KNN of
an unknown node is determined, which is k-nearest neighbor, by using Euclidian
distance [40]. For example, if a node is misplaced, then the average value of the near-
est neighbor can be used to predict it. The produced value is not that accurate but
somehow helps to find a possibly missing node. This method is usually applied in IoT
for malware detection, anomaly detection, and intrusion detection.
