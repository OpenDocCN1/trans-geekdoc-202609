# ## 2.3.3.3 Network Layer Attacks and Countermeasures

Sinkhole: This attack tries to capture almost all the traffic toward the affected node. This type of attack makes one node the “sinkhole,” that is, pulls in all transmissions on the channel toward it and disrupts the network. Networks are particularly vulnerable to sinkholes for specific patterns in the communication links. If the routing topology involves simply advertised information like end-to-end reliability estimate or other fields, then proper verification is not possible to prevent such attacks.

An effective and potential countermeasure can be using the geo-routing protocol. The routing system is modified to allow geo-routing, and thus directing the traffic through physical locations of nodes to prevent misdirecting signals into sinkholes [62–64].

Hello Flood: Hello packets are required in some protocols so that the neighboring node can identify it. An attacker uses a laptop class device to send these types of packets to all sensor nodes. When adjacent nodes believe the affected node, they send data packets to an imaginary identity. “Hello flood” attacker nodes will falsely appear to be in short-range, and attackers may also make it appear to be in a low-cost route. They can be defined as a single-way broadcast wormhole. Localized information-dependent WSNs are particularly vulnerable to hello flood attacks.
