# ## 6.3.1 COMPARATIVE REVIEW OF ROUTING PROTOCOLS

The merits and demerits of routing protocols are represented in Table 6.1.

+   i. AODV: AODV has an additional feature over DSDV by minimizing the number of broadcast messages that are created based on demands. When any node needs to transmit information, then it broadcasts route request (RREQ) packets in all directions. This continues until packets reach their destination. Intermediate broadcast packets are received. This is done to establish a reverse path by maintaining the values in their routing tables. If multiple copies are received, they are being discarded. Whenever a route is not available for destination, RREQ packets are flooded throughout the network [48]. RREQ packets contain the address of initial point, address of final end point, request ID, destination sequence number, hop count, and source number [49]. If a node already receives a packet will same parameters it is being discarded. A route reply (RREP) message is transmitted to the starting node if there is a valid path.
