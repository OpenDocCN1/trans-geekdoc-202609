# 6.4 OPTIMIZATION TECHNIQUES

The routing protocols suffer from a number of limitations: the network’s complexity increases on increasing the number of nodes, link failures, etc. Therefore, different optimization techniques were used to find the shortest path between the sources and their destination. The two optimization techniques discussed are ACO and swarm intelligence-based optimization.

# 6.4.1 ACO TECHNIQUE

This optimization technique resolves the issue of routing in MANETs. The algorithm works in a manner similar to how a number of ants follow the routes that are used by the other ants. They do not search for other paths rather travel on the same path saving time. The utilization of ACO in MANETs has favorable features. It is formed on demand. It is a path between the source and destination breakdown, and it uses instantly accessible possible paths. For what ant moves in networks node to node and keeps in track of all the information about the nodes that are being visited. During data transfer, first the path is searched, and if it is freely available, then data are sent, otherwise packet is stored in buffer and for what ant leaves in order to search for the destination. In order to seek the shortest path, the ant uses a chemical substance referred as pheromone from their place to the food supply.
