# TABLE 10.6
Attacks and Preventions for CPS

| Layer | Attacks | Solutions |
| :--- | :--- | :--- |
| Configuration | Insider attacks, unauthorized access, disinformation, distraction, and confusion [35] | Utilize proper authorization and PoLPs. There should be a regular check on the user's privilege and what they have access to. |
| Cognition | Disruption of operation, behavior manipulation, and data and policy corruption | Integrity verification of the data. Usage of cryptographic function could also help in the prevention of the attacks. |
| Cyber | Compromised middleware, data manipulation, etc. | Received data should be encrypted and the integrity of the data should be checked. There should be a proper use of cryptographic functions for encryption such as E2EE and key negotiation. Mutual authentication should also be implemented. |
| Conversion | Corruption of data | Same precautions as stated for the cyber layer should be taken into consideration. However, it should be noted that the application may differ. |
| Connection | Physical destruction of network, eavesdropping, and interruption of communication | There should be standard protocols for connection establishments. The connecting nodes should be the first authentication via either a mutual authentication mechanism or some other suitable technique. |
