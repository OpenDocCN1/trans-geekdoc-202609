# 12.4.1.2.1 Principle Component Analysis

It is also called the technique of feature reduction that helps to convert a vast dataset
into minor ones but has the equal data as the larger set. Hence, PCA reduces the com-
plication in a system. A strong security protocol can be provided by the association of
PCA with other ML methods. Zhao et al. [53] proposed a model which uses classifier
algorithms and PCA such as SoftMax regression and KNN to give a well-organized
system. It is an algorithm of unsupervised ML and is a multivariate technique used
for compression of data. Also, it helps in dimensionality reduction for big datasets
and helps in extraction of required information in the form of the set comprised of
orthogonal variables called “principle components.” Such components are arranged
in ascending order of the variance where the first component is linked with the last-
ing high data variance. The components with less variance are discarded.

# 12.4.1.2.2 k-Mean Clustering

This method uses small groups to classify the data samples as clusters. It is a com-
mon algorithm which uses clustering methods. Few easy rules to apply this tech-
nique are as follows: (i) First, transform the dataset into different clusters where
every cluster has a k-centroid (centroid) and finding the k-centroid for each cluster
is the main target. (ii) Choose a node from each of the clusters and link it with the
closest centroid and continue implementing it till all the nodes are approached. This
learning technique is especially useful in smart cities for finding an appropriate
region for living purpose. k-Mean algorithm is also helpful in systems of IoT when
the labeled data are not needed. However, this algorithm is inefficient in compari-
son to the supervised learning. Usually k-mean clustering is applied in detection of
Sybil attack [54].

# 12.4.1.2.3 Reinforcement Learning

It permits a system to learn by communicating with the environment by conducting
the actions required to increase the total feedback [55]. The feedback is considered
as a reward that is determined by the result of a given task. In RL, no predetermined
actions are present for a given task, whereas the machine makes use of a trial-and-error
method. By the use of this method, an agent can easily implement and identify the
most suitable method with its experience to obtain the best available reward. Most of
the devices of IoT (for example, air conditioner, electric glass, and sensors) use RL for
making changes with respect to their environment. Also, RL techniques are applied
for the protection of IoT devices, as well as Q-learning, post-decision state (PDS),
Dyna-Q, and deep Q-network (DQN) for the detection of different IoT attacks and to
give them required security protocols to the devices. Also, PDS and DQN can protect
the system from malware detection and jamming attacks, respectively.
