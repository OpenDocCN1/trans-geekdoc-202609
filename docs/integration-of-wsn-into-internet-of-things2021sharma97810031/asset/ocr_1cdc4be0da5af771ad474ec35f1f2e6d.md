# 15.3.1 A THREE-FACTOR ANONYMOUS AUTHENTICATION PROTOCOL FOR WSN-BASED IOT TECHNOLOGY

The emergence of “smart devices” showed the relevance of technology that could be used in the diagnosis and physiological and biomedical data monitoring. This has largely been attributed to growing wireless technology and the use of relatively simple technologies such as RFID for remote sensing and control. Although to make sensors wearable, unobtrusive, and energy-efficient, a balance between high-end complex authentication protocols and privacy of the data is often made. In previous research conducted in 2009, a way for authentication in WSNs involving the use of smart cards was developed, and this sparked the development of further protocols and mechanisms for user authentication [14]. Later, the research came under scrutiny for several weaknesses such as mutual authentication, key agreement, and user anonymity and suffered from attacks such as gateway bypassing, sensor node capture, and DoS attacks. This quest to achieve authentication in WSNs in IoT environments was carried forward by the development of a two-factor authentication system using the elliptic curve cryptosystem which provided better security than traditional crypto-mechanisms that drew less on the computational resources of sensor nodes. However, the issue of mutual authentication, key agreement, and user anonymity persisted [15]. The two-factor authentication system was then upgraded by Shi et al. [16] in 2013 only to be found that the system was prone to unknown key-share attacks and stolen smart card attacks. Further developments in this field led to the development of user authentication systems by temporal credentials which were criticized for offline password guessing, modification, and impersonation attacks [17]. The later improved version of Xue’s authentication scheme was found to be prone to user impersonation and tracking attacks [18, 19]. To counter all these challenges, Jiang et al. [20] suggested an untraceable user authentication scheme using ECC. All these efforts to improve user authentication while optimizing computational resource consumption had a scope of improvement. A few of the major challenges faced were clock synchronization and session-specific information attacks, imperfect alignment with IoT environments, and lack of wrong password detection and password change mechanisms.

These challenges are solved by the proposed three-factor anonymous user authentication protocol. The protocol exploits fingerprint identification by the fuzzy commitment scheme, which is one of the most widely used biometric authentication methods. Unlike Jiang’s proposed authentication scheme that allowed three phases in authentication, the three-factor authentication scheme allows for four phases, inclusive of sensor registration, user registration, login, authentication, and password change, hence keeping the benefits of the earlier proposed model. The proposed model suggests the use of a random number method to ensure the freshness of exchanged messages and avoids the use of time stamp; this ensured that messages being sent belong to the current session only. It also ensures that the user’s anonymity is ensured in the mechanism by ensuring that no communication message contains the user’s identity.
