# 12.4.1.1.3 Random Forest

It is an important technique of ML and utilizes some decision trees (DTs) so as to produce an algorithm to have a strong and precise approximation model for outputs. Many trees are trained randomly and developed for some specified action which is the main outcome of the model. RF is used for DDoS attack decision [41], unauthorized identification of IoT devices [42], and anomaly detection [43] in attacks of network surface. Preceding literature proves that RF provides preferable results in detection of DDoS attack on KNN, artificial neural network (ANN), and SVM. Although RF is not quite helpful in the real-time applications, it requires more training sets to build DTs that can help in identifying the sudden unauthorized intrusions.

It is a method of supervised learning that acts as a tree and has leaves and branches. They are applied to figure out the provided samples on the basis of their present values. However, this technique has some drawbacks like it needs big space for storing the data because of its vast construction. Wang et al. # 12.4.1.1.5 Neural Network

Neural Network (NN) is created on the basis of the structure of human brain in which neurons are used. NN uses ML techniques which help to handle nonlinear and complicated problems [45]. In NN algorithm, there are two network categories that are interconnected and hierarchical, which are based on the neuron’s various functional layers (usually input, output, and hidden layers). NN technique enhances the performance and decreases the network response time of the systems in IoT. Moreover, NN is computationally complicated and is quite hard for implementation in a distributed system of IoT. It is an algorithm of supervised learning that usually uses a chain to build a cascaded chain of decision for resolving complicated problems [46]. It builds a network with some specific number of inputs for triggering the outputs. Different kinds of neural networks can be used in the literature, for example, convolutional neural networks, recurrent neural networks, and multilayer perceptron [47–49]. Chen et al. [50] proposed ANN that is based on the ML algorithms and are also used to solve different problems of wireless networking. It also presented the holistic tutorial on ML techniques based on ANN development to fulfill the requirements of wireless network.
