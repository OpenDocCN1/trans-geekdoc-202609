# ## 2.2.4 WIRELESS SENSOR NETWORK LAYERS

The open systems interconnection (OSI) reference model is one of the popular systems for defining layers in networks [30]. WSNs have also adopted this standard. WSN layers are briefly described below [31]:

# ### 2.2.4.1 Application layer

This layer deals with system behavior while interacting. It also facilitates designers and developers for preparing a programming model. Industrial automation applications provide safety through regular and rigorous monitoring [32]. In this layer, message-passing communication is used. Moreover, early-stage memory access is performed along with synchronization, storage, and complex channel requirements [33]. The lower layer must be appropriately designed and configured to get the most use of the system. Various properties of data and the operational and environmental lifetimes are dealt with in this layer [34].

# ### 2.2.4.2 Transport Layer

This layer uses logical link addresses and transducers. It is responsible for transmitting messages end to end. The goal is congestion and flow control, fair allocation of bandwidth, reliability, packet-loss recovery, energy efficiency, and application support. There are many transport protocols, but they cannot be compared as each of them is tested in different simulation environments [35]. Illicit congestion detection can potentially degrade network throughput. This is related to data buffering. It fixes the buffer size by making it smaller to optimum capacity. Along with this task, synchronization needed is also performed for this purpose [36]. End-to-end reliability imposes strict energy requirements. There is a lack of reliable transport protocol in low-power and lossy networks. For this reason, the use of user datagram protocol (UDP) and retransmission control mechanisms at the application layer is an essential trade-off between energy cost and reliability [37]. Some well-known protocols in this layer are

+   - sensor transmission control protocol (STCP)
+   - price-oriented reliable transport protocol (PORT)
+   - pump slow fetch quick (PSFQ)

# ### 2.2.4.3 Network Layer

The major functionalities of this network are establishing routing communications. As there is no traditional IP address that belongs to a sensor device, the WSN does not follow conventional routing techniques to develop communications. That is why several routing protocols and standards are involved in this layer [29,38]. A network administrator must set up the routes and the frequency hopping. The network protocol of the ZigBee standard does not support the use of redundant paths. So, the redundant routes can also be used in radios that are compliant with the IEEE 802.15.4 standard.
