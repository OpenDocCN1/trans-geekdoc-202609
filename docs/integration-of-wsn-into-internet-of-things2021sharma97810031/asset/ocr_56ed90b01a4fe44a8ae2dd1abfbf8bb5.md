A neighbor cell list (NCL) is required when a BS is installed to arrange the new cells. First, the type of antenna, the locations of the cells (candidate), and the angle for directional cells are taken into account. Then, the cells that show the least amount of distance and most capacities for a load of traffic are selected and promoted as self-configuration. Self-optimization for current cells: with the help of a network management system, the data collected are processed with a key performance indicator (KPI) statistical measurement to check whether the handover was effective or not. Through the data collected, the cells with a value less than a preset amount are excluded from the NCL list, and the cells that have a value higher than the preset are considered for that slot.

KPIs are elemental to gaining an overall better performance experience. Kiran et al. [99] proposed utilization of the user data (alarms, entries, and updates in the database) and network data. The main aim of this study is to provide feasible alternatives to the problems that arise when allocation of the radio resources to radio access network users is done. This is mainly carried out using BDA through recognizing the network and user behavior. First, the processing of data is done, which is obtained from the core and other cellular network sides. By comparing the levels of cellular KPIs to the preset value, binary values are developed on a regular interval. Then, the same process on a subscriber level is carried out. Finally, a pattern that is binary in nature is generated on a request. This creates a matrix that is updated and incorporated with various data according to their updating. This is done by then passing the data through PRB (pseudo random binary), which uses fuzzy binary pattern matching algorithm.
