# ## 2.2.3 TYPES OF WIRELESS SENSOR NETWORKS

WSNs are used in various applications [20] and are deployed in multidisciplinary environments. According to the deployment nature, applicability, and functions, they may be categorized as follows (Table 2.2):

+   - Terrestrial wireless sensor networks
+   - Underground wireless sensor networks
+   - Underwater wireless sensor networks
+   - Multimedia wireless sensor networks
+   - Mobile wireless sensor networks

### TABLE 2.2
### Types of WSNs and Their Characteristics and Challenges

| Name | Node feature | Characteristics | Challenges | References |
| :--- | :--- | :--- | :--- | :--- |
| Terrestrial | 100–1,000 nodes; ad hoc (random) or preplanned (grid placement) deployment; cheap; massive deployment (high density) | Multihop routing; short transmission | Reliable communication; power issue; need auxiliary power/ solar power | [21–23] |
| Underground | Buried underground; sink nodes needed; expensive | Sink nodes ensure reliable communication | Underground communication; power issue; battery power; efficient communication protocol | [24,25] |
| Underwater | Deployed underwater with vehicles; fewer nodes needed; expensive; less density deployment | Data communication is done using acoustic wave signals | Limited bandwidth; propagation delay; faded signal; harsh environment; autonomous fixing needed; power issue | [26,27] |
| Multimedia | Cheap; camera, microphone, etc.; preplanned deployment | Monitoring; tracking; video; audio; transmission and coverage | High bandwidth demand; high power quality of service | [28] |
| Mobile | Movable nodes; collection nodes; autonomous reposition from static placement | Autonomous movement; military arena, e.g., border security; localization; target tracking; monitoring; static node characteristics; decision-making | Power consumption; quality of service | [29] |
