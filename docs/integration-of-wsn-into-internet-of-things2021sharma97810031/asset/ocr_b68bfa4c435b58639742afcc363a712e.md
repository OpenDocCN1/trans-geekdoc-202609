Node Capture: This type of attack is performed by gaining access to the node. This node can be used to acquire illegitimate privilege of the network such as information retrieval and active or passive control over the network. So, if the perpetrator can gain access to a single node, they can effectively expand control over the entire WSN.

Selective Forwarding: Also known as the black hole attack, this type of attack is primarily carried out by making a node act like a “black hole,” where data get in, but do not get out [67]. WSNs are mainly multihop networks. So, the system is made to transmit messages from node to node. But if sometimes malicious nodes refuse to forward the message and drop it, which creates a black hole. This means nodes will receive and then drop transmission of other nodes, and the WSN loses data. The malicious nodes can also drop only some data while forwarding others, still causing data loss. To counter this issue, a protocol-based approach can be used. Multipath routing will reduce the shared link, and hence, the implicit receipt of information can be reduced.

Sybil Attack: Though the same type of attack is present in the data link layer, the in-network layer, the effect is different. A malicious node can create multiple identities for the other nodes. It creates multipath and separation among the nodes in the network. To counter this issue, each node should have a unique shared symmetric key with the BS.
