# 12.3.1.4 Jamming Attack

Jamming uses intentional radio interferences to cause harm to the wireless communications by keeping the communication medium busy, due to which whenever the wireless medium is busy the transmitter backs off. Jamming attacks mostly take place at the physical layer but cross-layer attacks are also possible sometimes. Proceeding transmissions in the wireless network by sharing undesirable signals to IoT devices creates some difficulties for users because of the consistently busy network [26]. Also, this attack somewhat corrupts the execution of IoT devices by utilizing extra memory, bandwidth, energy, etc.

# 12.3.1.5 Man-in-the-Middle Attack

In this man-in-the-middle attack, the invader can eavesdrop on the message and also attempts to trade off the information between the two nodes and makes the nodes believe that they are communicating directly. For example, some malicious commands may be sent by the intruder to the actuators, shamming to share faulty response by sensors to the PLC or to be the PLC. Also, the invader can manipulate or discard messages. Valid syntax is used by these types of attacks; therefore, rule-based IDs cannot identify it from the message format. Such attacks can be prevented by encryption techniques. Hence, the man-in-the-middle intruder or an attacker poses to be in the communication system while the attacker is directly connected with another user device. The attackers or the intruders can effortlessly cease conveyance of a message by misleading and presenting forged data so as to handle the original data and intercept the information by eavesdropping.

# 12.3.1.6 Selective Forwarding Attack

In selective forwarding attack, the communication system functions as a node that permits leaving few packets of data in the course of transmission. Due to this, a hole is created in the network. It is quite difficult to avoid and identify this attack. This attack occurs by carefully choosing the packets to be forwarded. With the help of this attack, it is easier for DoS attack to be launched. This attack’s main goal is to filter any protocol and disrupt routing paths. In routing protocol for low-power and lossy networks (RPL), the intruder can share all the control messages of RPL and release the remaining traffic. Creating a dynamic path or disjoint path between the children and parent can be a solution to this attack. In another solution, the attacker would not be able to pinpoint the traffic flow by using the encryption method. Heartbeat protocol, which is usually required for the revelation of any kind of disturbance in the network topology, is also required for protection against the selective forwarding attack. For the detection of IDs, solution of this attack provides end-to-end adaptation of algorithm packet loss. Such attacks should be removed and detected.
