
### 12.4.1.1.3 Random Forest

### 12.4.1.1.5 Neural Network

Neural Network (NN) is created on the basis of the structure of human brain in which neurons are used. NN uses ML techniques which help to handle nonlinear and complicated problems [45]. ### 12.4.1.2 Unsupervised Learning

In this type of learning, no output data are provided for the given input variable. The data are mostly unlabeled when trying to collect the similarities of the dataset. On this basis, they are classified into various groups called clusters. The subsection mainly focuses on the following categories of unsupervised learning which also have k-means clustering technique and principal component analysis (PCA). In unsupervised learning, only the inputs without the desired targets are provided by the environment. It does not need any labeled data; hence, it can be investigated based on the Comparison between the unlabeled data and then the data are classified into groups. In unsupervised learning [51, 52], explicit labels linked with training dataset are not present. Its main purpose is to make inferences from input data and model the underlying or the hidden data to understand the data. One of the main examples of unsupervised algorithm is clustering.

### 12.4.1.2.1 Principal Component Analysis

It is also called the technique of feature reduction that helps to convert a vast dataset into minor ones but has the equal data as the larger set. Hence, PCA reduces the complication in a system. A strong security protocol can be provided by the association of PCA with other ML methods. Zhao et al. [53] proposed a model which uses classifier algorithms and PCA such as SoftMax regression and KNN to give a well-organized system. It is an algorithm of unsupervised ML and is a multivariate technique used for compression of data. Also, it helps in dimensionality reduction for big datasets and helps in extraction of required information in the form of the set comprised of orthogonal variables called “principal components.” Such components are arranged in ascending order of the variance where the first component is linked with the lasting high data variance. The components with less variance are discarded.

### 12.4.1.2.2 k-Means Clustering

This method uses small groups to classify the data samples as clusters. It is a common algorithm which uses clustering methods. Few easy rules to apply this technique are as follows:
- First, transform the dataset into different clusters where every cluster has a k-centroid (centroid) and finding the k-centroid for each cluster is the main target.
- Choose a node from each of the clusters and link it with the closest centroid and continue implementing it till all the nodes are approached.

This learning technique is especially useful in smart cities for finding an appropriate region for living purpose. k-Mean algorithm is also helpful in systems of IoT when the labeled data are not needed. However, this algorithm is inefficient in comparison to the supervised learning. Usually k-mean clustering is applied in detection of Sybil attack [54].

### 12.4.1.2.3 Reinforcement Learning

It permits a system to learn by communicating with the environment by conducting the actions required to increase the total feedback [55]. The feedback is considered as a reward that is determined by the result of a given task. In RL, no predetermined actions are present for a given task, whereas the machine makes use of a trial-and-error method. By the use of this method, an agent can easily implement and identify the most suitable method with its experience to obtain the best available reward. Most of the devices of IoT (for example, air conditioner, electric glass, and sensors) use RL for making changes with respect to their environment. Also, RL techniques are applied for the protection of IoT devices, as well as Q-learning, post-decision state (PDS), Dyna-Q, and deep Q-network (DQN) for the detection of different IoT attacks and to give them required security protocols to the devices. Also, PDS and DQN can protect the system from malware detection and jamming attacks, respectively.

### 12.5.1 Efficient Data Management Schemes

Broad adaptation of IoT’s heterogeneous devices causes a radical increase in the volume of data. Actuators and sensors integrated with industrial devices produce increased high-velocity-sensed data streams. Then, the data sensed stored on different devices of IIoT, cloud servers, edge servers/local gateway are applied for future and real-time decision-making. Storage, availability, transmission, and processing are difficult tasks that need big efforts. Therefore, it requires efficient data management models to handle such challenges. Such data-management models must be efficient enough to handle the large amount of generated raw data by heterogeneous devices of IIoT. These models must issue services for data management, secure and reliable data storage, high-speed processing, and fast retrieval of data flow. It is a major research concern for the future to handle the challenges in IoT applications, engaging frameworks and mechanisms to collect, manage, and store data that are generated in IoT processes. Also, analyzing tools might also help in analyzing the generated data for enhancing the performance, production of various applications, and better industrial decisions.
