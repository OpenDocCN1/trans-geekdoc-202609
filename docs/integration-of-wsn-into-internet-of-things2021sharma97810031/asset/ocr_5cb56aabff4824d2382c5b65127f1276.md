Therefore, a security authentication system that validates the legitimate data packets and checks whether they are modified or tampered with before transmission is necessary. However, this security transmission system would not be free from challenges. First, the computational cost and time required to validate every data packet would mean that the data transmission is delayed. Secondly, it would result in shifting prioritization of data in nodes from transmission to verification, which would incur further costs in the resources of nodes. Thirdly, the transmission of data packets carrying the information regarding the removal of duplicate data to reduce redundant verification at each node would mean increased data with each packet. These challenges can be overcome using a lightweight authentication mechanism that would mitigate DoS attacks and share the verification scheme between data forwarders and relayers.

Selective authentication-based geographic opportunistic routing is important to counter all mentioned challenges and create a reliable and secure network. This routing mechanism utilizes statistical state information of wireless networks to build an SSI-based trust model. Along with a secure routing mechanism, it uses an entropy-based selective authentication algorithm that works on performing signatures to increase data integrity. This associates the high-entropy signatures with uncertain states and the low-entropy signatures with certain states, thereby utilizing this parameter for authentication and reducing the computational burden. Further, inculcating a verification scheme employs “verification message” and “warning push” in which the “verification message” helps to reduce the burden on forwarding nodes to perform redundant verification, thereby, restoring priorities to data transmission. The “warning push” is used to isolate the adversaries by communicating the verification information of invalid signatures. By extensive comparison, the aforementioned selective authentication-based geographic opportunistic routing can block 80% of invalid data and save 50% of computational resources. This scheme is found to be a very effective defense against future DoS attacks even in prevalent wireless networks [21].
