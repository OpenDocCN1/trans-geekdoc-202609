## 15.3.3.2 Network Layer

An anomaly detection protocol is an IDS protocol for the detection of blackhole and packet dropping attacks on each node and has been proven to be effective. Similarly, the REWARD scheme not only detects the blackhole attacks but also provides a routing algorithm upon detection of a blackhole. The routes are changed for continuous normal operation. Another common and cost-effective method is using mesh topology, which is generally more preferred over star or tree topology against blackhole attacks [24].

A popular watchdog based intrusion detection system [25] is effective in detecting blackholes and warding off selective forwarding attacks. In clustered WSNs, sensor nodes are capable of intrusion detection by looking at their neighbors and communicating the same with the head of the cluster using probability to detect misbehavior. On the other hand, ActiveTrust uses multiple detection routes to detect blackhole attacks [26]. By using multiple detection routes, the adversary exposes itself using multiple attacks in different nodes and thus procuring information by ActiveTrust to avoid such paths. Similarly, the use of the coordinator node has the responsibility of authentication process, node failures, and blackhole detection. Thus, upon detection, the identified node is cut off from the network.

Another attack that frequently happens on the network layer is hello flooding. To ward off this kind of attack, one of the two solutions is to force every node to authenticate its neighboring node using a trusted base station. In such a case, if the node protocol continues to send messages in both directions between the nodes, the hello flood attacks are prevented since the protocol ensures the bidirectionality of the link. Another proposed solution includes two steps: first, bidirectional verification to detect hello floods, and then, using multi-path multi-base stations to avoid the hello floods [27]. Using symmetric key cryptography in micro-timed streaming loss tolerant authentication (μTESLA) protocol that falls within the SPINS protocol set provides authentic broadcasting, and therefore, reducing packet overhead is also being employed these days [28]. Furthermore, to prevent selective forwarding attacks, two approaches are used:

- Detecting nodes used for selective forwarding
- Preparing resilient routing schemes that can deliver packets even while under attack

For the detection of selective forwarding attacks, one of the methods used is acknowledgments. However, nowadays, the failure of this approach is that even the compromised nodes can generate acknowledgment messages even as they are dropped. Therefore, the use of multi-path routing can be effective against selective forwarding and blackhole attacks.

## 15.3.3.3 Transport Layer

To defend the communication against de-synchronization is to authenticate every packet being transferred and the presence of the entire control field in the transport protocol header. This mechanism works under the assumption that the attacker cannot authenticate and the communication would detect the discrepancies and ignore malicious packets. As proposed earlier, the use of puzzles is a great defense against flooding attacks. To connect to the base station, every client or node has to solve the puzzle beforehand. The dedicated base station has the responsibility of creating as well as disseminating them across the network for the client to solve.

## 15.3.3.4 Application Layer

The biggest challenge to application layer security and privacy is session-based hijacking attacks, and the countermeasure that has recently been promoted is a light-weight authentication protocol as described in Ref. [29]. Similarly, another common solution offered is datagram transport layer security (DTLS), which is an application layer variation of transport layer protocol (TLS). But one of the biggest drawbacks of the DTLS is the heavy computation needs of the algorithm that might be effective against CoAP exploit but highly expensive and may cause message fragmentation. Another attack that is the nemesis of security solutions is the DoS attack [30]. In particular, path-based DoS attacks require that the protocol detects replayed messages. This is done using a lightweight method employing one-way hash chains. Similarly, to prevent the infusion of false information in the system, “statistical en-route filtering” has been proposed that provides a method to curb false information upon detection using a collective secret by consensus [31].

## 15.4 APPLICATIONS AND RELATED WORKS OF WSNs AND THE IoT IN THE HEALTHCARE AND MEDICAL INDUSTRY

In the quest to make the healthcare monitoring systems more accurate, technology-driven for better diagnostic results, and more home-centric, the recent developments in technology have contributed to boosting the use of wireless sensing technology. This technology has been a boon to the elderly and disabled patients, especially those who face the difficulty of visiting hospitals for regular checkups and cannot afford expensive in-house care. Based on the type of applications, the following are the main categories: daily vital activity tracking, medical status and medicine intake tracking, movement tracking, and location tracking applications. These applications would be discussed further in the following section.

### 15.4.1 DAILY VITAL ACTIVITY TRACKING APPLICATIONS

The need for tracking activity of elderly and cognitively disabled technology has been the precursor for the development of daily vital activity tracking applications. These applications exploit location sensors and pressure sensors to track the daily activities of the patients. Therefore, different applications track different activities depending on the type of patient being observed.

A proposal to use a location-aware, activity recognition approach that inculcated wireless sensors into daily household objects as ambient-intelligence compliant objects (AICOs) has been used [32]. The effectiveness of the approach can be assessed by the fact that it successfully tracked multiple activities being done by the patient simultaneously, such as listening to music while studying. The foremost challenge of this approach is the integration of sensors/objects into household objects such that it does not affect the interaction of the patient with the user. This approach was first prototyped using a piezoelectric pad under the mat as floor AICO. Another great application is CareNet Display [33]. This is a digital liquid crystal display picture frame that allowed caregivers to interact with the display by touching icons on the screen. The screen displayed the picture of the user or the patient along with the seven-event icons that gave information about the daily activities of the patient as well as healthcare situations such as seizures or falls. The information about all these activities is tracked using the sensor network placed around the elder and allows the different activities to select information to be displayed by the user and ensure the privacy of the data of the user.

Similarly, the caregiver’s assistant system [34] is used for monitoring the daily activities of the elderly. This system operates by the interaction between the RFID tags worn by the patient and by equipping the household objects with RFID tags. This allows for real-time location-based tracking of the patient such that data collected from these inexpensive sensors can then be analyzed by analyzing the fluctuations from the ADL baseline. The above-mentioned technology highlights the importance of RFID tags that have been extensively used to track daily activities. The primary reason for this extensive use is that they are battery-less, technologically matured, highly available, and inexpensive in nature.
