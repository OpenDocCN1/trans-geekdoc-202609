
ACO technique resolves the issue of routing in MANETs. The algorithm works in a manner similar to how a number of ants follow the routes that are used by the other ants [37]. They do not search for other paths rather travel on the same path saving time. The utilization of ACO in MANETs has favorable features. It is formed on demand. It is a path between the initial and final end point breakdown, and it uses instantly accessible possible paths. As an ant moves in networks node to node and keeps in track of all the information about the nodes that are being visited [38].

During data transfer, first the path is searched and if it is freely available, then data are sent, otherwise packet is stored in buffer, and an ant leaves in order to search for the destination. In order to seek the shortest path, the ant uses a chemical substance referred to as pheromone from their place to the food supply. Routes that have a high probability of secretion are traversed by other ants [39]. The same concept is applied in routing to find the best-suitable minimal path between the sender and the receiver. In a similar manner, ACO is used in routing to have highly optimized results. ACO is based on the rule of ant colonies. In order to find an optimal solution, several methods are used. For the bio-propelled algorithm rule in MANETs, neighboring nodes transmit artificial ants. ACO is a survivable and reliable routing rule [40].

## 6.3 ROUTING PROTOCOL IN MANETs

Routing protocols specify how communication takes place between the routers, sharing information that helps them to select the best-possible route between the two nodes [41]. It determines the choice of route. Routers contain information about the network directly attached to it. Routing protocols share this information with neighboring nodes and then in the network [42]. This helps to know about the topology of the network. The main characteristics of routing protocols are avoidance of loops in routing, selection of preferred routes, hop cost information, scalability, reliability, routing convergence time, etc. [43]. In order to overcome ad hoc network limitations such as maximum power consumption and low bandwidth in high error rates, different types of algorithms were introduced. In this chapter, we are considering two different types of protocols such as proactive and reactive. Proactive algorithms are known as table-driven routing protocols. Reactive algorithms are algorithms where sources are initiated on demand [44]. Examples include AODV and DSR.
