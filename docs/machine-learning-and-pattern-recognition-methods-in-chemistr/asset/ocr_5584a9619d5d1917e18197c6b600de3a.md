The chemical behavior of pH indicators in the micellar aqueous solution can be described by the partition model, which solute is distributed between aqueous and micellar pseudo-phase (Fig. 4.10). The distribution constants and spectral profiles of different forms of indicators were obtained using the nonlinear fitting algorithm. The chemical model and spectral profiles are required to predict optimum for pH sensors.

There are two possible designs for three indicators: one design be an array of the mixture of three indicators in aqueous solution and mixture in micellar pseudo-phase, while another design is an array of six sensor elements, i.e., three aqueous solutions and three micellar solutions. Fig. 4.11 depicts the two different designs of indicators, and the analysis results are summarized in Table 4.2.

The analytical sensitivity for the array of two mixtures is 1.36; this value for the array of six sensor elements is 0.62, while the sensitivity value is higher for this design, because it depends on the number of the wavelengths and it is not a suitable criterion for the comparison purpose. According to the analytical sensitivity values, the mixture of indicators has higher analytical sensitivity in comparison with the array. So based on this information, the array of mixtures in the aqueous and micellar phase is an optimum sensor.
