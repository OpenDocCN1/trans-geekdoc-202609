Pooling layer: the main goal of this layer is to increase the field of view by using a downsampling operation. The pooling layer is typically placed after a convolution layer. Two common types of this layer are the max-pooling layer and the average pooling layer. In the max-pooling layer, the maximum value of the local filter is taken, and in the average pooling layer, the average value of the local filter is computed. It should be noted that the pooling layer has no learnable parameters.

By stacking the convolutional layers, the field of view is increased; however, in this case, many learnable filters are defined. By utilizing the pooling layer, we could increase the field of view without defining new parameters.

Normalization layer: this layer normalizes the output of the previous layer before feeding into the next layer. There are two common normalization layers, namely, batch normalization layer (Ioffe & Szegedy, 2015) and layer normalization (Ba, Kiros, Hinton, 2016). Both of these adaptive normalize the layer and have their own mean and variance. In the batch normalization layer, a mean and variance are computed over the minibatch, while in the normalization layer, the mean and variance are computed from the sum of the inputs to the neurons in a layer on a single training case. It causes normalization layer, unlike batch normalization, to perform the same computation in both training and tests.

Dropout layer: this layer is designed such that it helps the model prevent overfitting (Srivastava, Hinton, Krizhevsky, Sutskever, & Salakhutdinov, 2014). It leads the model to have more generalization power. This layer has no learnable parameters. This layer sets randomly selected elements of the input to zero, and the remaining ones are transferred to the output without change.
