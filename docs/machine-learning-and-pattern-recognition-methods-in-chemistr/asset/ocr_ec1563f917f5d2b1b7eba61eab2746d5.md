+   - Soft non-negativity constraints

Soft non-negativity constraints were applied in the systematic grid search algorithm for calculating soft constrained AFSs (Lakeh et al., 2020). In this algorithm, the estimated concentration and spectral profiles were required to be greater than noise estimates $\xi_i$ and $	ilde{\xi}_i$, respectively.

```
$c > -	ilde{\xi}_i, s > -	ilde{\xi}_i \quad (1.14)$
```

In the above equation, the application of $\xi_i$ and $	ilde{\xi}_i$, instead of zero allows small deviations from the non-negativity constraints in zero-concentration or zero-spectral regions of the resolved profiles. The noise estimates $(\xi_i, 	ilde{\xi}_i)$ were calculated for each concentration and spectral profile individually since the experimental noise propagates into the resolved profiles in different amounts. The first step to calculate the noise estimates was to smooth each individual profile in every iteration of the grid search algorithm. This means that only the amount of noise propagation may be different from one profile to another, but it may differ from one cycle of the grid search to another. The smoothing was done using a binomial filter with the order equal to 5% of the profile length. In the next step, the difference between the unsmoothed and the smoothed profiles was smoothed. A second residual was calculated by taking the difference between the smoothed residual and the smoothed residual. The second residual is assumed to contain only random deviations. The noise level of each individual profile, $\xi_i$ or $	ilde{\xi}_i$, was estimated as 6 times the median absolute deviation $(6 \times \text{MAD})$ of this second residual. The feasible transformations, $\mathbf{T}$, are those that produce concentration and spectral values greater than the corresponding noise levels. The compliance of each species profile with the soft non-negativity constraints was examined in every iteration of the algorithm.

```
$\delta_c = \sum_{i=1}^{n_c} \sum_{j=1}^{3} (C_{ij} < -\tilde{\xi}_{ij})^2$ and $\delta_s = \sum_{i=1}^{n_s} \sum_{j=1}^{3} (S_{ij} < -\tilde{\xi}_{ij})^2, \delta = \delta_c + \delta_s \quad (1.15)$
```

The parameter $\delta$ is a control parameter that can be used to evaluate the fulfillment of the soft non-negativity constraints. In cases of no deviations from the non-negativity constraints, $\delta$ is equal to zero.
