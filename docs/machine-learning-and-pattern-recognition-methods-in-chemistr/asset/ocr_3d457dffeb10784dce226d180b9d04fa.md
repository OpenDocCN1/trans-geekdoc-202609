# 1. Introduction

Python is a popular programming language, which is created by Guido van Rossum (Van Rossum & Drake Jr, 1995a, 1995b) and released for the first time in 1991 as Python 0.9.0. Python for the first time is created as a successor to the ABC programming language in the late 1980s. Python is an interpreted object-oriented high-level general-purpose programming language. From 1991 until now, 27 versions are released. The latest version of python is python 3.10, which is released on October 4, 2021 (Salgado, 2021).

Python is popular, and in many cases, it is the first choice of programming language for users. This popularity has many reasons, and some of these reasons are mentioned in the following:

+   1. Python is easy to learn because its syntax is simple and commands are designed so that it is an English-like language. Also, python is so flexible and lets developers sort any of applications that they want.

+   2. Python has an active support community. It helps users (beginners to experts) to access many sources of documentation and tutorials. This property helps the community to grow much better. Also, python uses as a popular programming language in the academic community.

+   3. One of the other reasons is that python provides many libraries and frameworks for many research areas. Hence, it is suitable for researchers to form a diverse community. Also, python provides many useful libraries for data science machine learning and cloud computing. Since these research areas get more attention in recent years, these python libraries receive more attention from users.

+   4. Python programming language is supported by big companies like Amazon web services, Facebook, and Google. It leads the python package to grow faster.
