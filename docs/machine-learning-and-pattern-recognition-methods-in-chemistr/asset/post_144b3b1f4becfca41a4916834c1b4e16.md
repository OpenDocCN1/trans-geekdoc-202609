## 3.2 Regression

In this section, the linear regression algorithm is investigated. In regression, the output space Y is continuous. In linear regression, the predictor function (i.e., $h$) is defined as follows:

```
$h(\phi(x);\theta) = \sum_{i} \phi_i, \theta_i \quad (3.5)$
```

As it is shown, the predictor function is a sum of the linear weighted of the obtained features from $\phi(x)$. Also, in linear regression algorithm, the loss function is defined as follows:

```
$L(\theta; \{(x^{(i)}, y^{(i)}\}_{i=1}^N) = \sum_{i} ||y^{(i)} - h(\phi(x^{(i)});\theta)||^2 \quad = \sum_{i} ||y^{(i)} - \tilde{y}^{(i)}||^2 \quad (3.6)$
```

where it is the sum of a squared error loss function. To evaluate the linear regression algorithm, it is applied to the ESOL dataset, which is a standard regression dataset with 1128 compounds that estimate the solubility of molecular structures (Delaney, 2004). To implement the linear regression algorithm on the ESOL dataset, we have utilized the scikit-learn package (i.e., sklearn package), which is a free Python package for machine learning. The class sklearn.linear_model.LinearRegression creates an object that fits a linear regression model on the given training sample. The overall python code of this is given in Appendix 1. To evaluate how the learned regression approach performs well on the unseen data, the evaluation measures should be used. In regression, two common evaluation measures are mean squared error (MSE) and $r^2$. MSE computes the squared sum of the residual between the actual value and the predicted value. $r^2$ is a measure that computes how the regression model fits the real data. The obtained results are shown in Table 3.1. As it is shown, the learned model performs well on training data, but does not work on the test data. This situation happens frequently with machine learning, which is called overfitting. To cope with this challenge in machine learning, regularization term is added to the loss function, which controls the size of the parameter vector, and it prevents the parameter vector from becoming large. Hence, the loss function is changed as follows:

```
$L\left(\theta;\left\{x^{(i)}, y^{(i)}\right\}_{i=1}^{N}\right)=\sum_{i=1}^{N}\|\left|y^{(i)}-h\left(x^{(i)}\right);\theta\right\|^2=\lambda\sum_{j}\left|\theta_{j}\right\|^q\quad(3.7)$
```

$\lambda$ is a regularization coefficient. If $q$ is set to one, then it is known as Lasso, and if $q$ is set to two, it is known as Ridge loss. The class **sklearn.linear_model.Ridge** and **sklearn.linear_model.Lasso**, create an object that fits a ridge regression and a lasso regression model on the training samples. The obtained results utilizing Ridge regression and Lasso regression on the ESOL dataset are shown in Table 3.1. As it is shown, both of these approaches prevent overfitting and perform better on the ESOL dataset compared to the simple linear regression approach.

To visualize the learned model, 1024 features of each sample are mapped to one dimension using the PCA algorithm. The obtained models on the ESOL dataset using three versions of the linear regression (simple linear regression, linear regression with Ridge regularization, and linear regression with Lasso regularization) are shown in Fig. 3.3. ## 3.4 Logistic regression

Logistic regression is a common binary classifier that aims in discriminating samples between two classes by a hyperplane (see Fig. 3.4), which is called a separator hyperplane. Samples are assigned to their corresponding classes based on which side of the separator hyperplane is placed. It should be noted that the multiclass version of the logistic regression also exists. In logistic regression, the loss function is defined based on binary cross-entropy, which is as follows:

```
$L\left(\theta;\{x^{(i)}, y^{(i)}\}_{i=1}^N\right) = \sum_i y^{(i)} \log\left(h\left(x^{(i)}\);\theta\right)\right) + \left(1-y^{(i)}\right) \log\left(1-h\left(x^{(i)}\);\theta\right)\right) \quad (3.8)$
```

where $h(\phi(x^{(i)});\theta)$ is defined as follows:

```
$h(\phi(x^{(i)});\theta) = \sigma\left(\theta^T \phi(x^{(i)})\right) = \frac{1}{1+\exp(-\theta^T \phi(x^{(i)}))} \quad (3.9)$
```

In fact, $h(\phi(x^{(i)});\theta)$ encodes the probability of assigning sample $x^{(i)}$ to class one. It should be noted that since $h(\phi(x^{(i)});\theta)$ returns a value between

## 3.5 SVM

Support vector machine (SVM) is a popular classification algorithm that searches for a separator hyperplane that maximizes the distance of each data point from the separator. The distance between the separator and the closest data point is called margin. Fig. 3.5 shows the obtained separator hyperplane, and it is shown that the distance of the separator hyperplane from the nearest data points is maximum.

SVM formulations are given in two forms: (1) the primal form and (2) the dual form. In the primal form, the SVM loss function is defined as follows:
