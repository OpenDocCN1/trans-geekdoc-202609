(Amigo et al., 2015). The sample is then assigned to the class it has the highest-probability of belonging to (Marini, 2010).

# 1.6.3 Validation

The validation parameters used in a classification model are sensitivity, specificity, and error rate, all of which are generally expressed in percentages. These parameters are based on the number of true positives (TP), false positives (FP), true negatives (TN), and false negatives (FN) during the internal cross-validation or external validation (Amigo et al., 2015).

```
$Sensitivity = \frac{TP}{TP + FN}\nSpecificity = \frac{TN}{FP + TN} \quad (5.3)\nError rate = 1 - \frac{(Sensitivity + Specificity)}{2}$$
```

Sensitivity refers to the ability of the model to confirm that a sample belongs to the class to it has been assigned, and is the ability of the model to confirm that a sample does not belong to the classes to which it has not been assigned (Amigo et al., 2015).

# 1.7 Objectives of this book chapter

Despite the aforementioned promising benefits of NIR-HSI, there are important analytical concerns that require a deep understanding of the interactions between NIR radiation, microplastics, and the matrices in which microplastics are located. These concerns beg a series of questions:

+   - Signal interference: Will the spectrum of the microplastic be the same as the spectrum of pure plastic? If so, to what extent can the signal of a microplastic be differentiated from the signals of the surrounding elements?

+   - Scattering: Will the spectrum of a pixel containing microplastic be affected by the scattering promoted by the surrounding elements? If so, to what extent will this change the microplastic spectrum relative to the spectrum of pure plastic?

+   - Spatial resolution: What is the smallest spatial level at which we can be confident that the microplastic signal will still be visible?

+   - Spectral resolution: Is there a combination of wavelengths in the spectra that remain selective for the microplastic?
