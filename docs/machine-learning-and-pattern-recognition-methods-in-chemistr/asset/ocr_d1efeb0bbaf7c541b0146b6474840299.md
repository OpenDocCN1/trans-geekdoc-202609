This experiment shows how the balancing technique (in imbalanced data) and kernel function impact the final result.

To take into account this issue, in-class **sklearn.svm.SVC**, an argument “class_weight” is considered, which could be set manually or be set to “balanced.” In this experiment, it is set to “balanced.” The Python code of this experiment is given in Appendix. The obtained results are given in Table 3.3. As it is shown, a reliable model is learned using the balancing technique. In Table 3.3, the number of support vectors is also reported. A learned model with a low number of support vectors gets the better value in all three evaluation measures. It should be noted that a model with a large number of support vectors means that all training samples are placed on or between margins.
