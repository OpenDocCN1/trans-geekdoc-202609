Classifiers belong to the pattern recognition methodologies, which can either be unsupervised, when they do not need any priori information about class-membership of samples, or supervised, when a training set of objects, whose actual class-belonging is known, is needed. In particular, classification techniques fall within the latter category of methods, for more information on unsupervised approaches the reader is addressed to [Albalate & Minkowski, 2013].

Classification methods can be divided into two main families: discriminant and class-modeling approaches (Cocchi, Biancolillo, & Marini, 2018). The main difference between these two categories lies in the hyperspace of samples is divided into regions associated with the various classes. Applying discriminant approaches, the entire sample space is divided in many regions as the number of classes present in the investigated data set. Fig. 2.1 depicts how the sample hyperspace is divided when a three-class problem is solved by a discriminant (left plot) or a class-modeling (right plot) approach. In the former case, training samples belong to class A, class B, and class C, and the sample space is divided into three regions. As a consequence, each object will be uniquely assigned to the class-region it falls into. On the other hand, using class-modeling methods (right plot), each category is individually modeled, with the consequence that class-regions overlap and/or not cover all the samples' space. A direct consequence of this is that some individuals fall in one class-region and they will be assigned to that class, some other could fall in an overlapping region, and they will be accepted by more than one class-model (confused samples), and eventually, some individuals will be rejected by all the class-models (i.e., they fall outside any class-region) and being labeled as outliers for all the categories.

# 2.1 Linear discriminant analysis (LDA)

One of the first, but still widely used, discriminant linear analysis is proposed by Fisher (1936). LDA is a discriminant parametric approach seeking the linear hyperplanes which allow dividing the samples' space in an appropriate number of regions. As a parametric approach, it lays on the Bayes' rule, and it is based on two main postulations:

+   Each investigated individual should be assigned to the class it is most probable it belongs to

+   Within each category, observations are normally distributed
