To design a classic neural network, its structure including the number of layers, neurons in each layer, and the activation functions of each layer should be determined. Then, its loss function and the optimizer approach of the loss function are defined. Assume, we use the neural network for a regression problem. In this case, the architecture contains the input layer, two hidden layers with the Rel activation, and one output layer with a linear activation function. Also, the loss function is mean squared error and the optimizer is stochastic gradient descent (SGD). To implement this network, the Keras package with Tensorflow backend is utilized.
