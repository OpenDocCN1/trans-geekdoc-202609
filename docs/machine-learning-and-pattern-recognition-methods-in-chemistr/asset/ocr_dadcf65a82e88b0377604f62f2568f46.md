Once the coefficients have been estimated using the training data, they can be used to predict the value of the response on any new sample, $\hat{y}_{new}$, according to:

$\hat{y}_{new}^T = \mathbf{x}_{new}^T \mathbf{b} \quad (2.10)$

where $\mathbf{x}_{new}^T$ is the row vector containing the experimental profile of the new sample.
So far we have considered the case when only a single response has to be modeled; however, there can be cases where the number of dependent variables is higher than one and the approach so far can be easily generalized to deal with problems involving a multivariate $Y$.

This is accomplished by expressing each of them as a linear function of the independent variables by means of its own set of regression coefficients:

$\mathbf{y}_k = \hat{\mathbf{y}}_k + \mathbf{e}_k = \mathbf{X} \mathbf{b}_k + \mathbf{e}_k \quad (2.11)$

where the subscript $k$ indicates that the model refers to the $k$th dependent variable (whose true and predicted values are collected in the vectors $\mathbf{y}_k$ and $\hat{\mathbf{y}}_k$, respectively).
By gathering all the predicted and true responses as columns of the matrices $\hat{\mathbf{Y}}$ and $\mathbf{Y}$

$\hat{\mathbf{Y}} = [\hat{\mathbf{y}}_1 \quad \hat{\mathbf{y}}_2 \quad \dots \quad \hat{\mathbf{y}}_k \quad \dots \quad \hat{\mathbf{y}}_K] \quad (2.12)$

$\mathbf{Y} = [\mathbf{y}_1 \quad \mathbf{y}_2 \quad \dots \quad \mathbf{y}_k \quad \dots \quad \mathbf{y}_K] \quad (2.13)$

the residuals as columns of the matrix $\mathbf{E}$

$\mathbf{E} = [\mathbf{e}_1 \quad \mathbf{e}_2 \quad \dots \quad \mathbf{e}_k \quad \dots \quad \mathbf{e}_K] \quad (2.14)$

and the regression coefficients in the matrix $\mathbf{B}$

$\mathbf{B} = [\mathbf{b}_1 \quad \mathbf{b}_2 \quad \dots \quad \mathbf{b}_k \quad \dots \quad \mathbf{b}_K] \quad (2.15)$

Equation (2.11) can be globally rewritten for all the dependent variables as:

$\hat{\mathbf{Y}} + \mathbf{E} = \mathbf{XB} + \mathbf{E} \quad (2.16)$
