## Multivariate predictive modeling and validation

The assumption (1) derives from Bayes' rule and is common among parametric classifiers. It means that, considering a sample vector $\mathbf{x}_i$, the probability $i$th object belongs to a class $g$ is given by the posterior probability $p(g|\mathbf{x}_i)$, which is proportional to the likelihood $p(\mathbf{x}_i|g)$ and the priori probability $p_0(g)$. What discriminates parametric classifiers from one and another is the likelihood is estimated. In LDA, this is in agreement with Eq. (2.35):

```
$p(\mathbf{x}_i|g) = \frac{1}{(2\pi)^{M/2}|S|} e^{-0.5(\mathbf{x}_i-\bar{\mathbf{x}}_g)^T S^{-1}(\mathbf{x}_i-\bar{\mathbf{x}}_g)} \quad (2.35)$
```

where $M$ is the number of measured variables, $S$ is the pooled variance/covariance matrix (calculated as $\sum_{g=1}^G (n_g-1)S_g$) where $S_g$ is the variance/covariance matrix of the $g$th class and $G$ is the total number of classes, $n_g$ and $N$ are the number of samples in the $g$th class and the total number of individuals, respectively, and $\bar{\mathbf{x}}_g$ is the centroid of the considered category.

For the easiest classification problem possible, i.e., when only two categories ($A$ and $B$) are considered, the sample space is divided into two class-regions by the individual boundary defined by Eq. (2.36):

```
$p(A|\mathbf{x}_i) = p(B|\mathbf{x}_i) \quad (2.36)$
```

Meaning that a borderline sample has the same posterior probability of belonging to class A or class B. It follows that the objects satisfying $p(A|\mathbf{x}_i) > p(B|\mathbf{x}_i)$ will be assigned to class A, while for which $p(B|\mathbf{x}_i) > p(A|\mathbf{x}_i)$, belong to class B.

For each category, it is possible to estimate classification probability functions $\phi_g(\mathbf{x})$. In fact, taking the logarithm of Eq. (2.35), $\phi_A(\mathbf{x})$ and $\phi_B(\mathbf{x})$ will correspond to:

```
$\phi(\mathbf{x}) = \ln p(A|\mathbf{x}) = \ln \frac{\Gamma}{(2\pi)^{M/2}|S|} + \ln p_0(A) - 0.5\mathbf{x}^T S^{-1}\mathbf{x} + \mathbf{x}_A^T S^{-1}\mathbf{x} -0.5\mathbf{x}_A^T S^{-1}\mathbf{x}_A \quad \quad (2.37)$
```

```
$\phi_B(\mathbf{x}) = \ln p(B|\mathbf{x}) = \ln \frac{\Gamma}{(2\pi)^{M/2}|S|} + \ln p_0(B) - 0.5\mathbf{x}^T S^{-1}\mathbf{x} + \mathbf{x}_B^T S^{-1}\mathbf{x} -0.5\mathbf{x}_B^T S^{-1}\mathbf{x}_B \quad \quad (2.38)$
```

where $\Gamma$ is a normalization factor, ensuring that the probabilities sum up to 1.

By equating the two expressions and rearranging, it can be shown that the boundary can be estimated as:

```
$$\ln \frac{\Gamma_{P_0}(A)}{\Gamma_{P_0}(B)} - 0.5(\bar{\mathbf{x}}_A - \bar{\mathbf{x}}_B)^T \mathbf{S}^{-1}(\bar{\mathbf{x}}_A - \bar{\mathbf{x}}_B) + (\bar{\mathbf{x}}_A - \bar{\mathbf{x}}_B)^T \mathbf{S}^{-1}\mathbf{x}=0$ (2.39)$
```

Finally, including all constant terms in $w_0$ and the coefficients of the linear combinations in $\mathbf{w}$, the equation defining the class-boundary can be expressed as:

```
$w_0 + \mathbf{w}^T \mathbf{x} = 0$ (2.40)$
```

This latter equation unveils that LDA is a projection method seeking for the directions which maximize the distance between the class-centroids (*inter-class variability*) and minimize the within-variability in each category (intra-class variability). In the LDA context, these directions (i.e., latent variables) are also known as *canonical variances* (Krzanowski, 2000).

The same reasoning can also be extended for the solution of multi-class problems; for $G>2$, a sample is predicted as belonging to one category only if its posterior probability of belonging to that class is higher than the probability of belonging to any other:

```
$p(H|\mathbf{x}) > p(I|\mathbf{x}) \quad \forall I=1...G, H \neq I$ (2.41)$
```

Boundaries can be defined similarly as before, by pairs of classes:

```
$$\ln \frac{\Gamma_{P_0}(H)}{\Gamma_{P_0}(I)} - 0.5(\bar{\mathbf{x}}_H - \bar{\mathbf{x}}_I)^T \mathbf{S}^{-1}(\bar{\mathbf{x}}_H - \bar{\mathbf{x}}_I) + (\bar{\mathbf{x}}_H - \bar{\mathbf{x}}_I)^T \mathbf{S}^{-1}\mathbf{x}=0$$
$$\forall I=1...G, H \neq I$ (2.42)$
```

As previously stated, canonical variances represent the direction which allows maximizing the ratio between the inter- and the intra-class variability. In the multi-class case, it is necessary to define between-group variance/covariance matrix $\mathbf{S}_b$:

```
$$\mathbf{S}_b = \frac{1}{G} \sum_{g=1}^G (\bar{\mathbf{x}}_g - \bar{\mathbf{x}})^T (\bar{\mathbf{x}}_g - \bar{\mathbf{x}})^T$ (2.43)$
```

Once $\mathbf{S}_b$ has been defined for all categories, the solution of the eigenvalue problem:

```
$$\mathbf{S}^{-1} \mathbf{S}_b \mathbf{w}_i = \lambda_i \mathbf{w}_i$ (2.44)$$
```

allows the estimation of the canonical variances ($w_i$). Eq. (2.44) clearly shows the main disadvantage of LDA, i.e., the fact S is an invertible matrix. This condition is rarely met, in particular working with instrumental data because it requires the number of objects to be higher than the number of variables; nevertheless efficient alternatives have been proposed. One of the possible solutions conceived to overcome invertibility issues associated with LDA is to include a feature reduction step prior to the application of this classifier. This can be achieved by selective method (for instance, stepwise procedure). Another alternative is the application of methods based on latent variables (for example, PCA), which compress the information into a restricted set of orthogonal features and make the calculation of LDA boundaries possible. Eventually, PLS-DA exploits a further strategy; the classification problem is transformed into a regression one, which can be solved by PLS (Barker & Rayens, 2003; Sjöström, Wold, & Söderström, 1986; Stähle & Wold, 1987). This transition is made possible by the introduction of a dummy Y, i.e., a Y-response which codes the class membership of training samples. The codification is easy: each sample is represented by row vectors made of zeros except for the column corresponding to its class. For a three-class case, samples belonging to class A, class B, and class C can be represented by the row vectors $Y_A^T = [1 0 0]$ and $Y_B^T = [0 1 0]$, respectively.

Once Y is created, the general regression equation (Eq. 2.6) can be solved by PLS and the calibration model build. This step includes the estimation of the regression coefficient matrix B, which allows the prediction of unknown samples. In this case, new observations can be collected in a novel data matrix $X_{new}$ and the response matrix $\hat{Y}_{new}$ estimated (as already described in Section 1.3) by:

```
$$\hat{Y}_{new} = X_{new} B \quad (2.45)$$
```

Contrarily to the target responses Y, the predicted $\hat{Y}$ are not binary, but of continuous variables, and a classification rule has to be defined in order to predict the class membership of new samples. On this regard, different solutions have been proposed (Indahl, Martens, & Næs, 2007; Pérez, Ferré, & Boqué, 2009). Here, it should be pointed out that, for the two-class case, due to the symmetry of the discriminant classification (if a sample is not class A, then it necessarily becomes class B), the dummy matrix Y becomes a dummy vector $y$: the target response becomes either 1 if the sample belongs to the first class, or 0 if it belongs to the second. Then, classification is accomplished by setting a threshold $\hat{y}_{thr}$ to the values of the predicted response $\hat{y}_{new}$ so that if $\hat{y}_{new} > \hat{y}_{thr}$ the sample is predicted as class 1; otherwise if $\hat{y}_{new} < \hat{y}_{thr}$ it is predicted as class 2. Accordingly, a value of $\hat{y}_{thr} = 0.5$ is often used, but more efficient approaches for the estimation of the best value of $\hat{y}_{thr}$ are discussed in the literature. When more than two classes are involved, the most natural and straightforward approach for implementing classification based on the predicted responses $\hat{Y}_{new}$ is as follows: Each sample is predicted to belong to the class corresponding to the predicted response with the highest value. For instance, taking into the matrix:

```
$\hat{Y}_{New} = \begin{bmatrix} \hat{y}_1^T \\ \hat{y}_2^T \\ \hat{y}_3^T \end{bmatrix} = \begin{bmatrix} 0.4 & -0.2 & 1.2 \\ 0.3 & 0.9 & 0.4 \\ 1.1 & 0.2 & -0.3 \end{bmatrix} \quad (2.46)$
```

The first sample, based on the predicted response $\hat{y}_1^T$, will be predicted as belonging to class C, because the element of $\hat{y}_1^T$ with the highest value (1.2) is in the third column; the second individual will be assigned to class B, because the highest value of its predicted response $\hat{y}_2^T$ (0.9) is in the second column; the third sample will be predicted as belonging to class A, because the highest value of its predicted response $\hat{y}_3^T$ (1.1) is in the first column.
