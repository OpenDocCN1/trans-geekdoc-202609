Data:
$D$: Dataset
$q_\phi(\mathbf{z}|\mathbf{x})$: Inference model
$p_\theta(\mathbf{x}, \mathbf{z})$: Generative model

Result:
$\theta, \phi$: Learned parameters
$(\theta, \phi) \leftarrow$ Initialize parameters
while SGD not converged
$M \sim \mathcal{D}$ (Random minibatch of data)
$\epsilon \sim p(\epsilon)$ (Random noise for each datapoint in $M$)
Compute $L_{\theta,\phi}(\mathcal{M}, \epsilon)$ and its gradients $\nabla_{\theta,\phi} \tilde{L}_{\theta,\phi}(\mathcal{M}, \epsilon)$
Update $\theta, \phi$ using SGD optimizer
end

**Fig. 6.8** Stochastic optimization of ELBO. This is a doubly stochastic optimization procedure.

In case of continuous latent variables, we can use a reparameterization trick for computing unbiased estimator for $\nabla_\phi \mathcal{L}_\phi(\mathbf{x})$. This stochastic estimate allows us to optimize the ELBO using SGD (see Fig. 6.8).

For continuous latent variables and a differentiable encoder and generative model, the ELBO can be straightforwardly differentiated w.r.t. both $\phi$ and $\theta$ through a change of variables, also the reparameterization trick (Kingma & Welche, 2013; Rezende, Mohamed, & Wierstra, 2014).

First, we express the random variable $\mathbf{z} \sim q_\phi(\mathbf{x})$ as some differentiable (and invertible) transformation of another random variable $\epsilon$, given $\mathbf{z}$ and $\phi$:

$$\mathbf{z} = \mathbf{g}(\epsilon, \phi, \mathbf{x}) \quad (6.26)$$

where the distribution of random variable $\epsilon$ is independent of $\mathbf{x}$ or $\phi$.
Such a change of variable, expectations can be rewritten in terms of $\epsilon$,

$$\mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})} [f(\mathbf{z})] = \mathbb{E}_{p(\epsilon)} [f(\mathbf{z})] \quad (6.27)$$

where $\mathbf{z}=\mathbf{g}(\epsilon, \phi, \mathbf{x})$ and the expectation and gradient operators commute, and we can perform a simple Monte Carlo estimator:

$$\nabla_\phi \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})} [f(\mathbf{z})] = \nabla_\phi \mathbb{E}_{p(\epsilon)} [f(\mathbf{z})] = \mathbb{E}_{p(\epsilon)} [\nabla_\phi f(\mathbf{z})] \cong \nabla_\phi f(\mathbf{z}) \quad (6.28)$$

where $\mathbf{z}=\mathbf{g}(\phi, \mathbf{x}, \epsilon)$ with noise sample $\epsilon \sim p(\epsilon)$. See Fig. 6.9 for an illustration.

**Fig. 6.9** Reparameterization trick. Change of variables helps computing gradients.

Under the reparameterization, we can replace an expectation w.r.t. $q_{\phi}(\mathbf{z}|\mathbf{x})$ with one $p(\epsilon)$. The ELBO can be rewritten as:

$$\mathcal{L}_{\theta,\phi}(\mathbf{x}) = \mathbb{E}_{q_{\phi}(\mathbf{z}|\mathbf{x})}[\log p(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x})] = \mathbb{E}_{p(\epsilon)}[\log p(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x})] \quad (6.29)$$

where $z=g(\epsilon, \phi, \mathbf{x})$.
As a result, we can form a simple Monte Carlo estimator $\widetilde{\mathcal{L}}_{\theta,\phi}(\mathbf{x})$ for the individual-datapoint ELBO where we use a single noise sample $\epsilon$ from $p(\epsilon)$:

$$\epsilon \sim p(\epsilon) \quad (6.30)$$
$$z = g(\phi, \mathbf{x}, \epsilon) \quad (6.31)$$
$$\widetilde{\mathcal{L}}_{\theta,\phi}(\mathbf{x}) = \log p_{\theta}(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x}) \quad (6.32)$$

The resulting gradient $\nabla\mathcal{L}_{\theta,\phi}(\mathbf{x})$ is used to optimize the ELBO using minibatch SGD. Detailed explanation, more examples, and pros and cons of VAE can be found in Kingma (2017).

Under the reparameterization, we can replace an expectation w.r.t. $q_{\phi}(\mathbf{z}|\mathbf{x})$ with one $p(\epsilon)$. The ELBO can be rewritten as:

$$\mathcal{L}_{\theta,\phi}(\mathbf{x}) = \mathbb{E}_{q_{\phi}(\mathbf{z}|\mathbf{x})}[\log p(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x})] = \mathbb{E}_{p(\epsilon)}[\log p(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x})] \quad (6.29)$$

where $z=g(\epsilon, \phi, \mathbf{x})$.
As a result, we can form a simple Monte Carlo estimator $\widetilde{\mathcal{L}}_{\theta,\phi}(\mathbf{x})$ for the individual-datapoint ELBO where we use a single noise sample $\epsilon$ from $p(\epsilon)$:

$$\epsilon \sim p(\epsilon) \quad (6.30)$$
$$z = g(\phi, \mathbf{x}, \epsilon) \quad (6.31)$$
$$\widetilde{\mathcal{L}}_{\theta,\phi}(\mathbf{x}) = \log p_{\theta}(\mathbf{x}, \mathbf{z}) - \log q_{\phi}(\mathbf{z}|\mathbf{x}) \quad (6.32)$$

The resulting gradient $\nabla\mathcal{L}_{\theta,\phi}(\mathbf{x})$ is used to optimize the ELBO using minibatch SGD. Detailed explanation, more examples, and pros and cons of VAE can be found in Kingma (2017).

### 2.1 De novo molecular design

One of the most exciting fields in computational chemistry is the design and discovery of new molecules with desirable chemical and pharmaceutical properties from scratch, the so-called de novo molecular design. Variational autoencoder models can be used to explore the space of chemical molecules. The inference network is used to map the space of chemical molecules into a continuous space so that mathematical operations can be performed on objects in this space.
