# 3.2 Regression

In this section, the linear regression algorithm is investigated. In regression, the output space Y is continuous. In linear regression, the predictor function (i.e., $h$) is defined as follows:

```
$h(\phi(x);\theta) = \sum_{i} \phi_i, \theta_i \quad (3.5)$
```

As it is shown, the predictor function is a sum of the linear weighted of the obtained features from $\phi(x)$. Also, in linear regression algorithm, the loss function is defined as follows:

```
$L(\theta; \{(x^{(i)}, y^{(i)})\\}_{i=1}^N) = \sum_{i} ||y^{(i)} - h(\phi(x^{(i)});\theta)||^2 \$
\quad = \sum_{i} ||y^{(i)} - \tilde{y}^{(i)}\||^2 \quad (3.6)$
```

where it is the sum of a squared error loss function. To evaluate the linear regression algorithm, it is applied to the ESOL dataset, which is a standard regression dataset with 1128 compounds that estimate the solubility of molecular structures (Delaney, 2004). To implement the linear regression algorithm on the ESOL dataset, we have utilized the scikit-learn package (i.e., sklearn package), which is a free Python package for machine learning. The class sklearn.linear_model.LinearRegression creates an object that fits a linear regression model on the given training sample. The overall python code of this is given in Appendix 1.
