## 1. Introduction

In pattern recognition, the goal is to identify patterns and regularities of data with minimal intervention (Bishop, 2006). Finding the patterns and regularities is done using machine learning algorithms. In other words, pattern recognition is the engine learning backbone in computer science. Machine learning algorithms map the input data to the output, and they consist of two main steps: the training step and the inference step. In the training step, the training data is utilized to learn a model, and in the inference step, the learned model is used to map unseen data to the output space. Machine learning algorithms are divided into four categories from the view of the available training data: (1) unsupervised learning, (2) semi-supervised learning, (3) weakly supervised learning, and (4) unsupervised learning. In supervised learning, all the training data are fully annotated (labeled) as compared to unsupervised learning in which none of the training data is labeled. In semi-supervised learning, some portion of training data is unlabeled. If the whole training data is not fully labeled (i.e., partially labeled), then it is weakly supervised learning. In this chapter, we focus on supervised learning and each section.

The feature extraction step takes the raw data as input and maps it to feature vector, which is given as:

$$\varphi = \phi(x)$$

where $\phi$ is the feature extractor function. In the prediction task, the obtained feature vector is obtained as input and maps it to the output space, which is denoted as follows:

$$\hat{y} = h(\phi(x); \theta)$$

where $h$ is a predictor (hypothesize) function and $\theta$ is the set of parameters that model the predictor function. Now, there is a set of unknown parameters which should be obtained during the learning stage. To obtain the parameters, the loss function or cost function should be defined. Loss function represents the cost associated with the specific value of parameters, which are defined:

$$L(\theta) = \sum_{i} l(y_i, \hat{y}_i)$$

where $l(.,.)$ computes the predicted output ($\hat{y}$) is close or far from the real output value ($y$). By optimizing the loss function, the optimal value for the parameter is obtained, which is given as follows:

$$\theta^* = \text{argmin} L(\theta)$$

In this chapter, the machine learning algorithms are divided into two categories based on how the feature extraction step is done: classic approaches and deep learning-based approaches. In the following, first, feature extraction prediction task steps are explained in detail, and then, classic approaches and deep learning-based approaches are given.

## 3. Task prediction

In this section, task prediction is explained. The obtained feature descriptor of the input from the previous step is fed as input into the task prediction. In a machine learning problem, a task is a type of prediction or inference which is asked in the problem. Each problem could have many types of tasks. Based on the literature, we have divided tasks into four categories:(1) regression, (2) classification, (3) ranking, and (4) structural output prediction. Regression assigns a continuous label to each sample. For example, in compound-target prediction, a real binding affinity value is assigned to a pair of compound and protein targets, which states the strength of the binding interaction of a biomolecule target (e.g., protein, enzyme, or DNA) with the ligand of the compound. In classification, a discrete label is assigned to each input, which states the class label of the input data. The classification task is divided into two categories: binary classification and multiclass classification. In binary classification, the number of classes is two, and in multiclass classification, the number of classes is more than two. Prediction of drug-likeness is an example of binary classification in the input drug compound is divided into drug-like/non-drug-like class labels. Ranking assigns a partial order for each item by giving a numerical or ordinal score, which states the relative degree of each item match. Gerdes et al. (2021) utilize omics data to assign a numerical score to lists of drugs based on their antiproliferative efficacy in the cancer cell. In the structural output prediction task, a structured object is predicted as output compared to classification and regression, which produce, respectively, scalar discrete or real values as an output. For example, protein 3D structure prediction (Jumper et al., 2021) takes the protein sequence as input, then we focus on the regression 3D structure and classification tasks.
