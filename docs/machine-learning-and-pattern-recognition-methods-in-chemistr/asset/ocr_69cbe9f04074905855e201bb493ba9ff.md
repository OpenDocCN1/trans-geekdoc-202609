+   * Closure constraints
Soft constraints can be implemented by the P-ALS algorithm using least-squares penalty functions and equality constraints. Augmenting the initial or intermediate estimate of $\mathbf{S}^{\	op}$ with the constraint matrix, $\mathbf{H} = [1, 1, \dots, 1]$, and $\mathbf{y}$ with the constrained value, $\mathbf{g} = [1]$, and considering an adjustable penalty function, $\lambda$, gives results with all species concentration profiles equal to or approximately one. For chemical reactions where a weighted sum of species concentrations is constant, e.g., in the following consecutive reaction $(2A \rightarrow B)$, the constraint matrix would be different (e.g., $H=[1/2 2 1]$ and $g=[1]$ for the consecutive reaction). The previous example is used again to illustrate the implementation of constraints and also to illustrate the fact that different constraints can be applied in P-ALS in one step. Soft closure and non-negativity constraints can be implemented simultaneously with a penalty weighting function $\lambda = 1$, giving the results shown below with $\mathbf{b}_{\mathbf{P-ALS}}=0.9799$.

+   * Unimodality constraints
Soft unimodality constraints can also be applied by the P-ALS algorithm via penalty functions and equality constraints. In the first step, constrained least-squares problem is solved for all rows of $\mathbf{C}$. Each resulting concentration profile, $\mathbf{c}_{i,*}$, is checked to find the global peak maximum. Inspecting the concentration values in both forward and backward directions from the global maximum should confirm no secondary local maxima.
