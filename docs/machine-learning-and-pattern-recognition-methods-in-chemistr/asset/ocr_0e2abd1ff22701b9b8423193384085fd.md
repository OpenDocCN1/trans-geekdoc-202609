# 1.2 Principal component regression (PCR)

In principal component regression (Jolliffe, 1982), as the name suggests, scores along the principal components are used as predictors instead of the originally measured experimental data. Jolliffe, 2002 are orthogonal directions in the X-space providing the best-dimensional approximation of the original data in the least-squares sense. Their direction cosines in the variable space (also called *loadings*) are collected in the matrix **P**, so that the corresponding scores (sample coordinates) **T** are given by:

```
T = XP (2.18)
```

with **X** being the predictor matrix.
The scores matrix **T** is then used to build the MLR model instead of the original matrix **X**:

```
Y = Ŷ + E = T CPR + E (2.19)
```

where the matrix of regression coefficients for the MLR model built on PCA scores was indicated as $C_{PCR}$ to avoid confusion. Consistently with what was described in Section 1.1, the optimal values of $C_{PCR}$ are given by:

```
C_{PCR} = (TᵀT)⁻¹ Tᵀ Y (2.20)
```

PCR is then simply a two-step modeling procedure when first principal components are extracted from the X and then the scores these components are used to build a MLR model to predict the Y response(s). Anyway, since PCA scores are calculated directly from the experimental matrix through linear projection, Eq. (2.19) can be rewritten in terms of the original variables:

```
Y = Ŷ + E = T C_{PCR} + E = XP C_{PCR} + E = X B_{PCR} + E (2.21)
```

where, analogously to what discussed in Eq. (2.16), $B_{PCR}$ (=P $C_{PCR}$) is the matrix of regression coefficients relating Y to X.
