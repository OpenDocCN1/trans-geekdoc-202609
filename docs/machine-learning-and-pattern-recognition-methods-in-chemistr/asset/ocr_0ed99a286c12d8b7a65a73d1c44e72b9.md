$K(..)$ denotes the kernel function that encodes the similarity between two samples. The kernel function tries to transform the input data into another space where data is separated by a hyperplane in this space. There are many common types of kernel functions like polynomial kernel, homogenous kernel function, and Gaussian RBF kernel function. In Eq. (3.12), each sample has a corresponding $\alpha_i$ and the equation states that samples are incorporated in the formation of the separator line. In other words, only samples with nonzero corresponding $\alpha$ value are used in the separator formation and these samples are called support vectors (see Fig. 3.5).

To implement the SVM algorithm on the Tox21 dataset, we have utilized the scikit-learn package. The sklearn.SVC creates an object that fits a support vector machine model on the training sample. To evaluate the SVM algorithm, we have applied it to the Tox21 dataset. Two different experiments are done. In the first experiment, it is applied to the NR-AR-LBD task of the Tox21 dataset, which is an imbalanced dataset, since it contains 238 active samples and 6664 inactive samples. In this section, three evaluation measures (namely, accuracy, F1 measure, and AUC-ROC) are also used. In this experiment, the kernel function is set to two different values: “rbf” (Gaussian random basis function) and “poly” (polynomial with degree three). This experiment is designed to show how the balancing technique (in imbalanced data) and kernel impact the final result. The obtained results are shown in Table 3.3. As it is shown, SVM achieves high accuracy but the F1–measure is 0. It means SVM produces inactive labels for all samples. This challenge is because of the imbalance of the dataset. To cope with this challenge, a weight is assigned to each class label. In other words, a large weight is assigned to a class with a low number of samples. Hence, incorrectly classified samples associated with this class label impose a large penalty in the loss function.
