## 1.10 Learning and inference problem

In probabilistic modeling, it is common to present some latent (hidden) variables. Latent variables, by their name suggest, are not observed in the dataset. We represent these variables with letter $z$. So, the directed probabilistic graphical model should factorize $p_{\theta}(\mathbf{x}, \mathbf{z})$. For computing probability distribution over $\mathbf{x}$, using marginalization, we have:

$p_{\theta}(\mathbf{x}) = \int p(\mathbf{x}|\mathbf{z})d\mathbf{z} \quad (6.11)$

For example, if $\mathbf{z}$ is discrete multinomial and $p_{\theta}(\mathbf{x}|\mathbf{z})$ is normal distribution, then $p_{\theta}(\mathbf{x})$ is a mixture of Gaussian distributions. Usually, the latent variable model $p_{\theta}(\mathbf{x}, \mathbf{z})$, whose distributions are parameterized by neural networks, is called deep latent variable model (DLVM). We also use this term. This model can be conditioned (e.g., $p_{\theta}(\mathbf{x}, \mathbf{z}|\mathbf{y})$). One interesting feature of DLVMs is that it is possible to model $p_{\theta}(\mathbf{x})$ using simple factors (conditional distributions). As an example, suppose latent variables with Gaussian and $\mathbf{x}|\mathbf{z}$ with Bernoulli distributions:

$p_{\theta}(\mathbf{z}) = \mathcal{N}(\mathbf{z}; \mathbf{0}, \mathbf{I}) \quad (6.12)$

Maximum-likelihood estimation can be applied for determining proper model parameters. Though, commonly computing $p_{\theta}(\mathbf{x})$ is intractable. The reason is that the integral in above has no analytic or efficient approximation necessary. So, we cannot differentiate it w.r.t. its parameters and run gradient-based optimization algorithm. In the equation $p_{\theta}(\mathbf{x}) = \frac{p_{\theta}(\mathbf{x},\mathbf{z})}{p_{\theta}(\mathbf{z})}$ computing joint probability distribution, $p_{\theta}(\mathbf{x},\mathbf{z})$, is efficient. Therefore though posterior, $p_{\theta}(\mathbf{z}|\mathbf{x})$, and marginal probability, $p_{\theta}(\mathbf{x})$, are tractable. There are some approximate inference techniques for computing $p_{\theta}(\mathbf{z}|\mathbf{x})$ and $p_{\theta}(\mathbf{x})$, but they are not scalable. For example, they need a de-datoint optimization loop or the posterior approximation is not precise. So, the main question is:

How to perform a scalable and efficient approximate posterior or maximum-likelihood estimation inference in deep latent variable models?

## 1.11 Efficient variational inference

The strategy for handling intractability problems in DLVM inference and learning is based on first-order gradients w.r.t parameters and latent variables. Then, backpropagation is efficient for finding solutions to this optimization problem.

Variational autoencoder (VAE) framework combines an encoder neural net for inference with a decoder neural net for generative modeling. Approximate solutions for this model will be found by optimizing an objective function. The objective function is a lower bound for the log-likelihood parameters.
