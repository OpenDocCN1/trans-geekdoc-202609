# 2.1 Data-based uniqueness

Data-based uniqueness condition can be defined as the following theorem in two equivalent forms in general, i.e., the theorem is formulated in such a way that is independent of the number of the components.

# 2.1.1 Data-based uniqueness theorem (Rajkó et al., 2015)

Form 1: If the Borgen plot (or its generalization for arbitrary dimensions) contains a point belonging to the coincidence of vertices of the inner and outer polygon (inner and outer polyhedrons), and, as result, this point will be the matching vertices of the two Borgen triangles (all Borgen simplices), then the point signs the unique solution for the component.

Form 2: If a component has a selective window in one direction/way/mode and considering the other direction/way/mode, this component has a sub-window in which the contribution of this component is zero while all interfering components appear inside this window, then the component can be uniquely decomposed in this second direction/way/mode.
