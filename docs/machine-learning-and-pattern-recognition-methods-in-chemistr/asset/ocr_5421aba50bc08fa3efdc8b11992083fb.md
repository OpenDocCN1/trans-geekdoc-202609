+   Software implementation of P-ALS GUIPRO is the name of a Matlab program that makes the implementation of P-ALS algorithm in a graphical user interface possible. This program has NWAY P-ALS options for applying different constraints on augmented matrices. The user can perform PCA, select the number of PCA factors, and perform SMCR on the spectroscopic data loaded from Matlab files or tab-separated data from EXCEL spreadsheets. Preprocessing can significantly improve the results of P-ALS analysis. Many different options are possible for preprocessing on data, including subranges for analysis, removing outliers by inspecting PCA scatter plots, correcting baseline shifts, and normalization of spectra. Before NWAY P-ALS analysis, the preprocessing should be done on each matrix of the augmented data individually, and the resultant matrices should be saved using the computed pretreatment options. In the GUIPRO environment, up to 10 preprocessed individual matrices (submatrices) can be loaded. To start the NWAY P-ALS algorithm, initial guesses of the augmented concentration profiles are needed. Several procedures can be applied for making the initial estimates, using the needle search technique or the evolving factor analysis (EFA).
