# 3.4 Classification

Following the failure to locate the ABS microparticle using PCA, classification techniques were attempted. Classification models sort samples into classes based on their similarity to the measured characteristics of a training set of objects in the hyperspace (Marini, 2010). Recent publications used SIMCA and PLS-DA as a technique to detect and characterize microplastics with SWIR and FTIR spectroscopy (Da Silva et al., 2020; Serrano et al., 2018; Vidal & Pasquini, 2021).

The results of both models (SNV and first-derative preprocessing) are shown in Table 5.3. Three PCs for the ABS class and four PCs for the sand class were used to build the SIMCA model. PLS-DA models were both built using one single latent variant (LV).

These results clearly indicate the high spectral difference between the sand and the ABS. As shown further in this document, this is not a good indication of the performance of the model when pixels from the image are analyzed.
