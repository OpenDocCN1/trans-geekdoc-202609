To implement a random forest algorithm in Python, scikit-learn package could be used. The class sklearn.ensemble.RandomForestClassifier creates an object that fits a random forest classifier model on the given training samples. This class has many parameters like "n_estimator" denotes the number of trees in a forest, "criterion" denotes the measure to select the next feature to split, and "max_depth" denotes the maximum depth of each decision tree.

To evaluate random forest on Tox21, a similar experiment the two previous sections is designed and is applied on three randomly selected tasks of Tox21. The obtained results are shown in Table 3.5. As it is shown, random forest, like SVM, performs better than NR-AR-LBD tasks than on the other tasks.
