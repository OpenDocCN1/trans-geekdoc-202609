In order for the validation to be effective, the use of new data instead of the training samples is of the highest importance. Indeed, since the model parameters are often optimized to minimize the error on the training observation, by using the same data for model validation, one would obtain over-optimistic results by definition. On the other hand, the test set should be chosen to reflect as closely as possible all the possible sources of variability that one would expect in the routine application of the model, i.e., on future developments. In this context, when collecting a completely new set of samples is not possible, a solution is represented by the possibility of splitting all the available data into training and test sets, possibly not randomly through the use of algorithms which guarantee that the two sets span as effectively as the possible space [e.g., KennardStone (Kennard & Stone, 1969) or Duplex (Snee, 1977)].

When the number of samples is limited, resampling strategies, like cross-validation (CV), can also be employed. In cross-validation, the whole data set is divided into a specified number of cancelation groups, which, in turn, are used as validation sets, while the remaining individuals constitute the training set. CV has the advantage that any sample is predicted by a model which was built on a set that doesn't include it; on the other hand, since training and test sets are never completely independent from one another, the results that are obtained in general be be too optimistic. Anyway, cross-validation, when applied to the training samples only, can be fruitfully exploited in the model selection stage, for instance, when the optimal values of some metaparameters, e.g., the number of components, should be identified. In that case, one can compare the performances, in CV, of the competing model and then select the value of the metaparameter(s)leading to the best performances. Once the optimal model has been selected, validation of its performances on a completely external test is anyway recommended.
