Known-value constraints about the contribution or signal of a chemical species can be applied as known-value constraints in SMCR methods. Implementing soft-value constraints in the grid search method (Lakeh et al., 2020), in each cycle of the algorithm, profiles with prior information available are scaled according to the true values. The scaling step is important because the ratio of known-values, and their intensity, is important when comparing the estimated and true values. In the next step, the percent relative error between the estimated and true values should be calculated as a criterion for accepting the estimated profile as a feasible solution.

```
RE = 100 \times \sqrt{rac{\sum(v_t - v_i')^2}{\sum v_i'^^2}} \quad (1.16)
```

In the above equation, RE is the percent relative error, $v_t$ is the true value, and $v_i$ are the calculated or estimated values in each cycle of the grid search algorithm. Feasible solutions are found at grid points where their percent error is less than a predefined constant, e.g., 1%. This predefined constant controls the range of the accepted deviations from the known-values.
