# Soft constraints in curve resolution problems

1. An initial estimate of concentration profiles, $\mathbf{C}_0$, or pure spectra, $\mathbf{S}_0$, is selected by any number of popular methods.

2. Row-wise least-squares penalty functions are used to fit the initial unconstrained $\mathbf{C}_0$ or $\mathbf{S}_0$ producing better “constrained” estimates.

+   Given some initial or intermediate estimate of $\mathbf{C}$, find every row of $\mathbf{S}$ (or every column of $\mathbf{S}^T$) that minimizes $||\mathbf{a}_{\cdot j} - \mathbf{Cs}_j^T||$ based on the constraints imposed on that row as $\mathbf{s}_j^T = g_{j,:}$, where $g_{j,:}$ specifies the constraint goals for spectra (more about later). On this procedure, each row of $\mathbf{S}$ is estimated individually using least-squares penalty functions.

+   Given some initial or intermediate estimate of $\mathbf{S}^T$, find every row of $\mathbf{C}$ (or every column of $\mathbf{C}^T$) that minimizes $||\mathbf{a}_{i\cdot} - \mathbf{Sc}_i||$ based on the constraints imposed on that row as $c_{i\cdot} = g_{i\cdot}$, where $g_{i\cdot}$ specifies the constraint goals for concentration profiles.

3. The constrained alternating least-squares steps are repeated until no further refinement in the estimated concentration and spectra can be observed or maximum number of iterations is achieved.

+   * Equality constraints

Soft equality constraints can be applied for both row-wise P-ALS least-squares penalty functions. The P-ALS subproblems (2a and 2b) using penalty functions. can be generalized to the form of $\mathbf{y} = \mathbf{Xb}$. The least-squares problem can be solved for $\mathbf{b}$ using the equality-constrained weighting method (Van Benthem, Keenan & Haaland, 2002) by augmenting $\mathbf{y}$ with the vector of constrained values ($\mathbf{g}$) and $\mathbf{X}$ with a constraint matrix ($\mathbf{H}$) consisting of only one and zero values. The zero elements in the constraint matrix specify which species are not constrained. The model is shown in Eq. (1.3).

```
$$\begin{bmatrix} \mathbf{y} \ \lambda\mathbf{g} \end{bmatrix} \cong \begin{bmatrix} \mathbf{X} \ \lambda\mathbf{H} \end{bmatrix} \mathbf{b} \quad (1.3)$
```

When imposing equality constraints with desired $\mathbf{g}$ values of spectral profiles, for every $j$, $\mathbf{y}$ would be the $j$th column of $(\mathbf{a}_{\cdot j})$, $\mathbf{X}$ would be the initial or intermediate estimate of $\mathbf{C}$, and $\mathbf{b}$ would be the $j$th row of spectral profiles ($\mathbf{s}_j^T$). If reference data is available for concentrations and $\mathbf{g}$ contains the desired values, for every $i$, $\mathbf{y}$ would be the $i$th row of transposed data $(\mathbf{a}_{i\cdot})$, $\mathbf{X}$ would be the initial or intermediate estimate of $\mathbf{S}$, and $\mathbf{b}$ would be the $i$th row of the transposed concentration profiles ($\mathbf{c}_{i\cdot}^T$).
