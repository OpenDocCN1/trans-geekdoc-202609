When we want to model a time series, the system's behavior should be dependent on past events, so the model should have some memory. RNN architectures provide a mechanism for memorizing valuable information across sequences. In these models, there is a recurrent formula that updates the system state at each time step.

Historically, recurrent neural nets had a significant obstacle in the training process. When the network's output is fed back to the input, vanishing gradient problem occurs. Long-term memory (LSTM) (Hochreiter & Schmidhuber, 1997) network was a solution for this problem. This architecture uses a gating mechanism for managing this.

In natural language processing, RNNs are widely used (Bengio, Daucharme, Vincent, & Janvin, 2003; Socher, Huang, Pennin, Manning, & Ng, 2011). Also, in the machine translation problem, a sequence-to-sequence (Seq2Seq) model was used (Kohlbrenner et al., 2017).

In this model, the main idea is to train an encoder that learns a continuous representation of words and sentences. Representations represent the semantic and syntactic structure of source language as much as feasible.
