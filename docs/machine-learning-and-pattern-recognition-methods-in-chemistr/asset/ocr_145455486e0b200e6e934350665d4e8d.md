# 1.5 Denoising autoencoder

The idea of adding noise to the dataset was probably first introduced by Lecun (1987) and Soulie, Gallinari, Le Cun, and Thiria (1987). It was then used in convolutional and recurrent neural networks. Finally, Vincent et al. (2010) proposed a way to use this approach for training autoencoders.
The denoising autoencoder is trained to detect and eliminate noises. So noise is added to the instances, and the network learns how to reconstruct the noise-free input samples, and in this process, the most robust and crucial features are extracted. The input in this case is a corrupted version $	ilde{x} \in \mathbb{R}^n$ of $x$.
The loss function takes the following form:

$L(x, g(f(\tilde{x}))) \quad (6.2)$

where $g(f(\tilde{x}))$ is the decoder output, and $f(\tilde{x})$ is the encoder output encoded from the corrupted input $	ilde{x}$ (see Fig. 6.4).
