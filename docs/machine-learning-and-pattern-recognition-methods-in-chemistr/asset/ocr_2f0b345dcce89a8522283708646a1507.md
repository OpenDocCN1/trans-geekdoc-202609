be defined in order to predict the class-membership of new samples. On this regard, different solutions have been proposed (Indahl, Martens, & Næs, 2007; Pérez, Ferré, & Boqué, 2009). Here, it should be pointed out that, for the two-class case, due to the symmetry of the discriminant classification (if a sample is not class A, then it necessarily becomes class B), the dummy matrix Y becomes a dummy vector $y$ : the target response becomes either 1, if the sample belongs to the first class, or 0 if it belongs to the second. Then, classification is accomplished by setting a threshold $\hat{y}_{thr}$ to the values of the predicted response $\hat{y}_{new}$ so that if $\hat{y}_{new} > \hat{y}_{thr}$ the sample is predicted as class 1; otherwise if $\hat{y}_{new} < \hat{y}_{thr}$ it is predicted as class 2. Accordingly, a value of $\hat{y}_{thr} = 0.5$ is often used, but more efficient approaches for the estimation of the best value of $\hat{y}_{thr}$ are discussed in the literature. When more than two classes are involved, the most natural and straightforward approach for implementing classification based on the predicted responses $\hat{Y}_{new}$ is as follows. Each sample is predicted to belong to the class corresponding to the predicted response with the highest value. For instance, taking into the matrix:

```
$\hat{Y}_{New} = \begin{bmatrix} \hat{y}_1^T \ \hat{y}_2^T \ \hat{y}_3^T \end{bmatrix} = \begin{bmatrix} 0.4 & -0.2 & 1.2 \ 0.3 & 0.9 & 0.4 \ 1.1 & 0.2 & -0.3 \end{bmatrix} \quad (2.46)$
```

The first sample, based on the predicted response $\hat{y}_1^T$, will be predicted as belonging to class C, because the element of $\hat{y}_1^T$ with the highest value (1.2) is in the third column; the second individual will be assigned to class B, because the highest value of its predicted response $\hat{y}_2^T$ (0.9) is in the second column; the third sample will be predicted as belonging to class A, because the highest value of its predicted response $\hat{y}_3^T$ (1.1) is in the first column. As anticipated before, other approaches have been proposed in the literature to build classification decision rules based on the predicted response in PLS-DA. One of the most commonly used approaches is to LDA directly on the predicted responses or on the PLS scores (Indahl et al., 2007).
