# Multivariate predictive modeling and validation

```
$B_{MLR}=\left(\mathbf{X}^{T}\mathbf{X}\right)^{-1} \mathbf{X}^{T}\mathbf{Y}\quad(2.17)$
```

Since each of the columns of the matrix corresponds to the regression coefficients for the prediction of the corresponding column in the matrix **Y**, Eq. (2.17) indicates that, as far as MLR is concerned, there is absolutely no difference, when dealing with a multivariate response, modeling all the Ys simultaneously or to consider one dependent variable at a time: in both cases, the corresponding set of coefficients would anyway be the same.

In the context of multivariate linear regression, the use of MLR has several advantages. First of all, estimation of the optimal set of model coefficients is based on a clear loss function, which represents the straightforward generalization of the least-squares criterion to the case of more than one predictor. Moreover, its mathematical structure is such that no additional parameters or metaparameters be tuned in a model selection stage are involved, which translates to the fact that once the X-Y training pairs are identified, the solution is univocal. On the other hand, model calculation requires the inversion of the matrix $\mathbf{X}^{T}\mathbf{X}$, which can represent a severe limitation in many practical situations. Indeed, conditions commonly met when dealing with chemical data, such as having a lower number of training samples than measured variables and/or a high correlation among the predictors, lead to the impossibility of inverting the matrix $\mathbf{X}^{T}\mathbf{X}$, which becomes illconditioned. This translates to the fact that unless some variable selection strategy is adopted (sometimes also coupled with orthogonalization approaches), MLR is seldom applied to chemical data as.

A solution to the limitations discussed above is represented by the use of abstract (latent) variables, instead of the experimentally measured ones, as since the chemical data are highly correlated, it is possible to exploit such correlation to achieve a substantial reduction in the dimensionality of the problem through data projection onto a low-dimensional subspace of highly informative orthogonal orthogonal directions in the multivariate space (latent variables or components). The coordinates of the sample along this new set of directions (which are often referred to as *scores*) can be used as predictors to build regression models. In particular, due to their orthogonality, scores on the different components are completely uncorrelated among one another. Moreover, the number of relevant components is usually lower than the number of training samples, allowing to overcome the limitations related to ill-conditioning of the predictor matrix.
