This is a directed probabilistic graphical model or Bayesian network. A flexible way to parameterize such distributions is with neural networks. The input for this neural network is the vector of parent variables and the output is parameters $\boldsymbol{\mu}$ of probability distribution over child variable $\mathbf{x}$:

$\boldsymbol{\mu} = NeuralNet(Pa(\mathbf{x})) \quad (6.9)$

$p_{	heta}(\mathbf{x}|Pa(\mathbf{x})) = p_{	heta}(\mathbf{x}|\boldsymbol{\mu}) \quad (6.10)$

# 1.10 Learning and inference problem

In probabilistic modeling, it is common to present some latent (hidden) variables. Latent variables, by their name suggest, are not observed in the dataset. We represent these variables with letter $z$. So, the directed probabilistic graphical model should factorize $p_{	heta}(\mathbf{x}, \mathbf{z})$. For computing probability distribution over $\mathbf{x}$, using marginalization, we have:

$p_{	heta}(\mathbf{x}) = \int p(\mathbf{x}|\mathbf{z})dz\mathbf{z} \quad (6.11)$

For example, if $\mathbf{z}$ is discrete multinomial and $p_{	heta}(\mathbf{x}|\mathbf{z})$ is normal distribution, then $p_{	heta}(\mathbf{x})$ is a mixture of Gaussian distributions. Usually, the latent variable model $p_{	heta}(\mathbf{x}, \mathbf{z})$, whose distributions are parameterized by neural networks, is called deep latent variable model (DLVM). We also use this term. This model can be conditioned (e.g., $p_{	heta}(\mathbf{x}, \mathbf{z}|\mathbf{y})$). One interesting feature of DLVMs is that it is possible to model $p_{	heta}(\mathbf{x})$ using simple factors (conditional distributions). As an example, suppose latent variables with Gaussian and $\mathbf{x}|\mathbf{z}$ with Bernoulli distributions:

$p_{	heta}(\mathbf{z}) = \mathcal{N}(\mathbf{z}; \mathbf{0}, \mathbf{I}) \quad (6.12)$
