# 3. Task prediction

In this section, task prediction is explained. The obtained feature descriptor of the input from the previous step is fed as input into the task prediction. In a machine learning problem, a task is a type of prediction or inference which is being asked in the problem. Each problem could have many types of tasks. Based on the literature, we have divided tasks into four categories:(1) regression, (2) classification, (3) ranking, and (4) structural output prediction. Regression assigns a continuous label to each sample. For example, in compound-target prediction, a real binding affinity value is assigned to a pair of compound and protein targets, which states the strength of the binding interaction of a biomolecule target (e.g., protein, enzyme, or DNA) with the ligand of the compound. In classification, a discrete label is assigned to each input, which states the class label of the input data. The classification task is divided into two categories: binary classification and multiclass classification. In binary classification, the number of classes is two, and in multiclass classification, the number of classes is more than two. Prediction of drug-likeness is an example of binary classification in the input drug compound is divided into drug-like/non-drug-like class labels. Ranking assigns a partial order for each item by giving a numerical or ordinal score, which states the relative degree of each item match. Gerdes et al. (2021) utilize omics data to assign a numerical score to lists of drugs based on their antiproliferative efficacy in the cancer cell. In the structural output prediction task, a structured object is predicted as output compared to classification and regression, which produce, respectively, scalar discrete or real values as an output. For example, protein 3D structure prediction (Jumper et al., 2021) takes the protein sequence as input, then we focus on the regression 3D structure and classification tasks.
