# Multivariate predictive modeling and validation

The assumption (1) derives from Bayes' rule and is common among parametric classifiers. It means that, considering a sample vector $\mathbf{x}_i$, the probability $i$th object belongs to a class $g$ is given by the posterior probability $p(g|mathbf{x}_i)$, which is proportional to the likelihood $p(\mathbf{x}_i|g)$ and the priori probability $p_0(g)$. What discriminates parametric classifiers from one and another is the likelihood is estimated. In LDA, this is in agreement with Eq. (2.35):

```
$p(\mathbf{x}_i|g) = \frac{1}{(2\pi)^{M/2}|S|} e^{-0.5(\mathbf{x}_i-ar{\mathbf{x}}_g)^T S^{-1}(\mathbf{x}_i-ar{\mathbf{x}}_g)} \quad (2.35)$
```

where $M$ is the number of measured variables, $S$ is the pooled variance/covariance matrix (calculated as $\sum_{g=1}^G (n_g-1)S_g$) where $S_g$ is the variance/covariance matrix of the $g$th class and $G$ is the total number of classes, $n_g$ and $N$ are the number of samples in the $g$th class and the total number of individuals, respectively, and $ar{\mathbf{x}}_g$ is the centroid of the considered category.

For the easiest classification problem possible, i.e., when only two categories ($A$ and $B$) are considered, the sample space is divided into two class-regions by the individual boundary defined by Eq. (2.36):

```
$p(A|\mathbf{x}_i) = p(B|\mathbf{x}_i) \quad (2.36)$
```

Meaning that a borderline sample has the same posterior probability of belonging to class A or class B. It follows that the objects satisfying $p(A|\mathbf{x}_i) > p(B|\mathbf{x}_i)$ will be assigned to class A, while for which $p(B|\mathbf{x}_i) > p(A|\mathbf{x}_i)$, belong to class B.

For each category, it is possible to estimate classification probability functions $\phi_g(\mathbf{x})$. In fact, taking the logarithm of Eq. (2.35), $\phi_A(\mathbf{x})$ and $\phi_B(\mathbf{x})$ will correspond to:

```
$\phi(\mathbf{x}) = \ln p(A|mathbf{x}) \\n = \ln \frac{\Gamma}{(2\pi)^{M/2}|S|} + \ln p_0(A) - 0.5\mathbf{x}^T S^{-1}\mathbf{x} + \mathbf{x}_A^T S^{-1}\mathbf{x} \\n -0.5\mathbf{x}_A^T S^{-1}\mathbf{x}_A \quad \quad (2.37)$
```

```
$\phi_B(\mathbf{x}) = \ln p(B|mathbf{x}) \\n = \ln \frac{\Gamma}{(2\pi)^{M/2}|S|} + \ln p_0(B) - 0.5\mathbf{x}^T S^{-1}\mathbf{x} + \mathbf{x}_B^T S^{-1}\mathbf{x} \\n -0.5\mathbf{x}_B^T S^{-1}\mathbf{x}_B \quad \quad (2.38)$
```

where $\Gamma$ is a normalization factor, ensuring that the probabilities sum up to 1.
