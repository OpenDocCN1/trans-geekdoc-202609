# 1.4 Chemometrics

Given the overwhelming amount of spectral and spatial information produced, advanced machine learning methods [a.k.a. chemometrics (Massart, 1997)] are required to glean meaningful from the quantities of data produced by the instruments used in analytical chemistry. In the context of microplastic studies, classification strategies are the most used chemometric methodologies (Da Silva, Murphy, Amigo, Stedmon, & Strand, 2020).

# 1.5 Principal component analysis

Principal component analysis (PCA) is an unsupervised exploratory chemometric tool. That is to say, it explores variation within the multivariate datasets, but it is not a method of classification. Applied correctly, PCA can provide an overview of multivariate data, shed light on the interrelated of variables and samples, and quantify patterns (Bro & Smilde, 2014). More specifically, PCA attempts to decrease the dimensionality of complex data sets by finding orthogonal directions in the multivariate space of describing the maximum variance as:

```
D = TP^T + E
```

Using the hyperspectral image in Fig. 5.1 as an example, D is the unfolded matrix with dimensions of XY × λ, containing the data for XY pixels and λ variables. T, the score vector or scores, has dimensions of (XY × R), and P, the loading vector or loads, has dimensions of (λ × R), where R refers to the number of principal components (Da Silva et al., 2020). E is the residual vector (Bro & Smilde, 2014).
