# 2.2 Multi-way penalating least-squares (P-ALS) algorithm

Multi-way P-ALS or NWAY P-ALS was proposed as an extension to the P-ALS approach, incorporating all advantages of that method, as well as the second-order advantage for species common to two or more experiments. The multi-way ALS procedure can be described as simply unfolding the multi-way array to matrix and then performing the standard P-ALS approach. A detailed description of the multi-way P-ALS approach is given below.

A three-way array $A$ of the size $I \times J \times K$ can be matricized as a concatenated two-way array (matrix) in three different directions, that is, a row-wise augmented matrix $A_r$ $(JK \times I)$, a column-wise concatenated matrix $A_c$ $(IK \times J)$, and a tube-wise augmented matrix $A_t$ $(IJ \times K)$. Fig. 1.2 represents different ways of matricizing a three-way array. In typical spectroscopic applications, and also in this chapter, it is supposed that the rows of arrays represent the mixture spectra, the columns represent the variables variables (e.g., wavelengths), and the tubes represent different experiments. Considering this assumption, the column-wise augmentation of the measurement matrices keeps the variables intact, so the information in the variables would not be wiped out.

The bilinear decomposition of the column-wise augmented, concentration matrix $\mathbf{C}_c (IK \times N)$ and a spectral matrix $\mathbf{S}^T (N \times J)$ considering $N$ chemical spectroscopic active species are present. In the multi-way P-ALS procedure, starting with initial estimates of $\mathbf{C}_{c0}$ or $\mathbf{S}_0$, row-wise least-squares penalty functions are used to fit the uncertain profiles alternatively to the constrained estimates. Steps 2a and 2b of the P-ALS algorithm can be modified for multi-way P-ALS analysis as shown below.

+   a. Given some initial or intermediate estimate of $\mathbf{C}_c$, find every row of $\mathbf{S}$ (or every column of $\mathbf{S}^T$) that minimizes $|\mathbf{a}_{c,j} - \mathbf{C}_{s^T,j}\|$ based on the constraints imposed on that row as $s^T_{i,j} = g_j$, where $g_j$ specifies the constraint goals for spectra.
