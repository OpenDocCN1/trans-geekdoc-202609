+   - Non-negativity constraints

Soft-negativity constraints can be applied by a simple modification of steps 2a and 2b of P-ALS algorithm. For imposing soft-negativity constraints, in the first step, the unconstrained least-squares problem is solved, resulting in the coefficients vector (b). For any negative coefficients, $b_n$, an equality constraint is set $(b_i = 0)$. These equality constraints are imposed using the penalty functions described in the previous section. The penalty value can be tuned for applying hard or soft non-negativity constraints. If hard constraints are desired, larger penalty weights should be used for the P-ALS solution to the result that would be obtained from NNLS (Lawson & Hanson, 1995) or FNNLS (Bro & De Jong, 1997; Bro & Sidropopoulos, 1998). An example is given below to illustrate the implementation of non-negativity constraints by P-ALS algorithm.

$\mathbf{y} = \mathbf{X} = \begin{bmatrix} 0.1656 & 0.6892 & 0.2290 \ 0.6020 & 0.7048 & 0.9133 \ 0.2630 & 0.4505 & 0.1532 \ 0.6541 & 0.0838 & 0.8258 \end{bmatrix} \mathbf{b} = \begin{bmatrix} -0.0827 \ 0.6528 \ 0.3708 \end{bmatrix}$

Considering that the first coefficient is negative, $b_1 = -0.0827$, a soft non-negativity constraint can be imposed as shown below using penalty weighting function $\lambda=1$ and equality constraints, $b_{	ext{P-ALS}(\lambda)} = [-0.0023, 0.6503, 0.3143]$. Harder non-negativity constraints can be applied using $\lambda=10$, which gives the coefficient vector $b_{	ext{P-ALS}(10)} = [-2 	imes 10^{-5}, 0.6503, 0.3117]$, and if hard non-negativity constraints are desired, a larger penalty weight $\lambda=100$ can be used, which results in $b_{	ext{P-ALS}(100)} = [-2 	imes 10^{-7}, 0.6503, 0.3117]$. It is worth noting that the solution of non-negative least-squares method (NNLS) $\mathbf{b}_{	ext{NNLS}} = [0, 0.6503, 0.3117]$ compares favorably to the solution obtained with $\lambda=100$. For other examples illustrating the implementation of non-negativity constraints with the P-ALS algorithm, refer to the original paper (Gemperline & Cash, 2003).
