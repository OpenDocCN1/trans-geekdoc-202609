# 4. Conclusion

In this chapter, multivariate machine learning algorithms are practically investigated. To do so, these algorithms, based on the feature extraction step, are divided into two categories: the classic approaches and the deep learning-based approaches. In both of these categories, regression and classification tasks are studied. In regression, the introduced approaches are applied to the ESOL dataset. Three regression methods are investigated: linear regression, neural network, and convolutional neural network. To compare how these methods perform on the ESOL dataset, the obtained results of these methods of the regression task are summarized in Table 3.10. The results show that CNN with ridge regularization performs better than the other comparable methods. It should be noted that the high r² value with a low MSE value is acceptable.

The classification task is also investigated. To this end, three classic approaches (namely, logistic regression, SVM, and random forest) and two deep learning-based approaches (namely, neural network and convolutional neural network) are studied.
