# 3.5 SVM

Support vector machine (SVM) is a popular classification algorithm that searches for a separator hyperplane that maximizes the distance of each data point from the separator. The distance between the separator and the closest data point is called margin. Fig. 3.5 shows the obtained separator hyperplane, and it is shown that the distance of the separator hyperplane from the nearest data points is maximum.

SVM formulations are given in two forms: (1) the primal form and (2) the dual form. In the primal form, the SVM loss function is defined as follows:

```
$\min_{w,b} \frac{1}{2}||w||^2\ns s \cdot y^{(i)} (w^T x^{(i)} + b) \geq 1, \quad i = 1, ..., m$
```
