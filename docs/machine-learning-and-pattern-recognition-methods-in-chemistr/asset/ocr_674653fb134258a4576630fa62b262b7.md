Two parts of convolutional networks are convolutional and sub-sampling layers. Usually, these layers are followed by a fully connected layer. Feature maps are extracted from raw input representation. Parameters in this type of operation are shared across the entire input tensor (or matrix). There is another mechanism, called pooling, that reduces the dimensionality of the feature map. Pooling maps values in small regions to a single value (e.g., maximum or average value). This is considered as one CNN layer. It is possible to use more layers to increase the complexity of the model. Multiple CNN layers help high-level features detection. Usually, there is a fully connected layer at the end of the network (Kazak, 2019).

In classification or regression, the fully connected layer helps to train a predictive model using high-level features extracted through CNN layers. However, in unsupervised learning, up-sampling layers are applied to reconstruct the input tensor (Kazak, 2019).

Typical use of convolutional autoencoder is feature extraction. However, it is common to use for pretraining convolutional neural networks (Kohlbrenner, Hofmann, Ahmmed, & Kashe, 2017) (see Fig. 6.5).
