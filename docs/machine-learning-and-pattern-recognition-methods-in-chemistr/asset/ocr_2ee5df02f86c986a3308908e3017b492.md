# ### 1. Introduction

Self-modeling curve resolution (SMCR) (Lawton & Sylvestre, 1971) describes a set of powerful tools for estimating the pure component spectra and composition of profiles from the spectroscopic data matrices. The only requirement of this mathematical resolution is the bilarity of the chemical data, meaning that the total response at one particular wavelength should be the sum over all the contributions of each spectroscopically active constituent according to Beer-Lambert Law. At a constant optical path length, the Beer-Lambert law can be described by Eq. (1.1):

```
$A_{\lambda} = s_{\lambda1}c_1 + s_{\lambda2}c_2 + \dots + s_{\lambda m}c_m = \sum_{j=1}^{m} s_{\lambda j}c_j$ (1.1)
```

where $A_{\lambda}$ is the absorbance at wavelength $\lambda$, $s_j$ is the molar absorbivity of the active components in mol L$^{-1}$ cm$^{-1}$, and $c$ is the concentration in mol L$^{-1}$. Eq. (1.1) can be written as the absorbance for wavelength every sample if complete spectra are taken over several samples. This system of equations allows the application of a matrix notation shown in Eq. (1.2):

```
$A = CS^T + E$ (1.2)
```

where $A$ $(ns \times n\lambda)$ is the matrix of absorbance that consists of absorption spectra measured at $n\lambda$ wavelengths from $ns$ samples. Columns of matrix $C$ $(ns \times nc)$ contain the pure concentration profiles, and rows of matrix $S$ contain the pure spectra of the absorbing species. $E$ $(ns \times n\lambda)$ is the matrix of residuals and contains the measurement errors.
