# ## 1. What is an autoencoder?

An autoencoder is a two-part machine. The first part, the *encoder*, is a function $f$ (deterministic or stochastic) that maps input $x$ to output $z$. So, $z=f(x)$. In this chapter, we call $z$ as latent representation or *code*. The second part, the *decoder*, is a function $g$ (also deterministic or stochastic) that maps input $z$ to output $r$. Therefore, $r=g(z)$. We want $g(f(x))$ to be as similar as possible to input $x$. In other words, $g$ attempts to reconstruct $x$, from input $z$. Applying some restrictions on $f$ and $g$, we prevent copying and so the machine is forced to find the most relevant features (Goodfellow, Bengio, & Courville, 2016). Theoretically speaking, $f$ and $g$ can be from an arbitrary functional family, by *neural networks* (e.g., feed-forward neural networks) are of most interest. Different types of autoencoders have been proposed, which we will review in the following subsections.

In this type of autoencoders, the latent space dimensions are less than the input space dimensions, and they are generally used to reduce dimensionality, feature extraction, and compression.
