
$$f_{eq}(\alpha, \beta, P) = \sum_{j=1}^{J} \max \left(S_{ij} - \vartheta S_{ij}^{given}\right)^2 \quad (1.10)$$

$$\vartheta = \frac{\sum_{j=1}^{J} S_{ij}^{given}}{\sum_{j=1}^{J}(S_{ij}^{given})^2} \quad (1.11)$$

- Total cost function

When several soft constraints are desired to be applied, the total cost function can be defined as the weighted sum of all the objective functions that are needed. If the four constraints from the previous sections are considered, then the total cost function can be described as follows:

$$f(\alpha, \beta, P) = f_{non-neg}(\alpha, \beta, P) + \gamma_{um}f_{um}(\alpha, \beta, \omega) + \gamma_{do}(\alpha, \beta, \delta) + \gamma_{eq}f_{eq}(\alpha, \beta, \theta) \quad (1.12)$$

where $\gamma_{um}, \gamma_{do}, \gamma_{eq}$ are the weights that can vary between zero and one. As shown before, each pair of $(\alpha, \beta)$ defines a certain point of the AFS if $\min f(\alpha, \beta, P)$ is less than a control parameter.

$$f(\alpha, \beta, P) = \min_{P}(\alpha, \beta, P) \le \varepsilon_{f} \quad (1.13)$$

The value of the control parameter, $\varepsilon_{f} > 0$, should be chosen with caution especially for noisy experimental data. The control parameter for each constraint $(\varepsilon, \omega, \delta, \text{ and } \theta)$ should be selected based on the acceptable amount of noise and deviations from the ideal resources. Details on the impact of the tunable parameters and the way to compute them are explained briefly in Sawall et al. (2015).

## 2.3 Grid search algorithm for applying soft constraints

The grid method was proposed for numerically approximating the area of feasible solutions (AFs) for 2-, 3-, and 4-component systems (Golshan, Abdollahi, & Maeder, 2011; Golshan et al., 2013; Vosough, Mason, Tauler, Jalali-Heravi, & Maeder, 2006). The most informative part of the AFS is its boundary, which is a contiguous polygon, a simplex algorithm was employed to define the border and thus the complete AFS. The grid search algorithm can deal with noisy data sets and different restrictions coming from prior information of the system. In addition, this algorithm can be applied for studying the effect of various soft constraints on the range of feasible solutions. To our knowledge, soft non-negativity, soft known-value, and soft trilinearity constraints have been employed using the grid search method.

- Soft non-negativity constraints

Soft non-negativity constraints were applied in the systematic grid search algorithm for calculating soft constrained AFSs (Lakeh et al., 2020). In this algorithm, the estimated concentration and spectral profiles were required to be greater than noise estimates $\xi_i$ and $\tilde{\xi}_i$, respectively.

$$c > -\tilde{\xi}_i, s > -\tilde{\xi}_i \quad (1.14)$$

In the above equation, the application of $\xi_i$ and $\tilde{\xi}_i$, instead of zero allows small deviations from the non-negativity constraints in zero-concentration or zero-spectral regions of the resolved profiles. The noise estimates $(\xi_i, \tilde{\xi}_i)$ were calculated for each concentration and spectral profile individually since the experimental noise propagates into the resolved profiles in different amounts. The first step to calculate the noise estimates was to smooth each individual profile in every iteration of the grid search algorithm. This means that only the amount of noise propagation may be different from one profile to another, but it may differ from one cycle of the grid search to another. The smoothing was done using a binomial filter with the order equal to 5% of the profile length. In the next step, the difference between the unsmoothed and the smoothed profiles was smoothed. A second residual was calculated by taking the difference between the smoothed residual and the smoothed residual. The second residual is assumed to contain only random deviations. The noise level of each individual profile, $\xi_i$ or $\tilde{\xi}_i$, was estimated as 6 times the median absolute deviation $(6 \times \text{MAD})$ of this second residual. The feasible transformations, $\mathbf{T}$, are those that produce concentration and spectral values greater than the corresponding noise levels. The compliance of each species profile with the soft non-negativity constraints was examined in every iteration of the algorithm.

$$\delta_c = \sum_{i=1}^{n_c} \sum_{j=1}^{3} (C_{ij} < -\tilde{\xi}_{ij})^2 \text{ and } \delta_s = \sum_{i=1}^{n_s} \sum_{j=1}^{3} (S_{ij} < -\tilde{\xi}_{ij})^2, \delta = \delta_c + \delta_s \quad (1.15)$$

The parameter $\delta$ is a control parameter that can be used to evaluate the fulfillment of the soft non-negativity constraints. In cases of no deviations from the non-negativity constraints, $\delta$ is equal to zero.
