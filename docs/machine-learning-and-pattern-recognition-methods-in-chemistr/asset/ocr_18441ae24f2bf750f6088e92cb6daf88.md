the column vector **b**. By taking advantage of matrix notation, Eq. (2.5) for the whole training set can be written as:

```
$y = \widehat{y} + e = Xb + e \quad (2.6)$
```

where the rows of the **X** matrix correspond to the experimental profiles of the different samples:

```
$\mathbf{X} = \begin{pmatrix} x_1^T \ x_2^T \ \vdots \ x_i^T \ \vdots \ x_N^T \end{pmatrix} \quad (2.7)$
```

the true and predicted values of the residuals constitute the elements of the column vectors **y** and $\widehat{y}$, respectively, while the residuals are collected in the vector **e**.

# 1.1 Multiple linear regression (MLR)

When the ordinary least-squares approach is used to estimate the regression coefficients based on the training data, the corresponding technique is often referred to as multiple linear regression (MLR). In particular, the optimal value of the elements of **b** is sought as the one leading to the minimum approximation error on the training data (defined as the sum of squares of the residuals $E = \sum_{i=1}^N e_i^2$), as mathematically expressed by:

```
$$\argmin_b \sum_{i=1}^N e_i^2 = \argmin_b \{e^T e\} = \argmin_b \{(y - Xb)^T (y - Xb)} \quad (2.8)$
```

Solution to the condition expressed by Eq. (2.8) is obtained by differentiating $E$ with respect to the elements of **b** and setting all the partial derivatives to zero. The corresponding values of the regression coefficients are:

```
$b_{MLR} = (X^T X)^{-1} X^T y \quad (2.9)$
```

where the subscript MLR was added to highlight the values of the coefficients for the linear model are those estimated with this technique.
