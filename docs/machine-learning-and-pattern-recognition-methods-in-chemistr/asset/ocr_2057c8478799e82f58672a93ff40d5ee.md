+   - Unimodality constraints

Unimodality constraints are applied when the concentration profile of a chemical species has only one local minimum. In experimental conditions where measurement noise is present, small deviations from unimodality may be seen. A soft unimodality cost function can tolerate small descents or ascents against the main trend of the function using a control parameter $\omega\ge0$. When all the columns of the estimated matrix, $C$, are unimodal, the unimodality cost function, $f_{un}$ will be equal to zero. In such cases, the control parameter can be set to zero. If the absolute value of the deviations from the unimodality constraints is larger than $\omega$, the cost function will have a positive value to the sum of squares of all the deviation values. For more information about the unimodality cost function, please refer to Sawall et al. (2015).

+   - Closure constraints
Soft constraints can be applied in cases that small deviations from the principle of balance is acceptable, meaning that the sum of all rows of estimated **C** should be approximately constant. The deviations from the closure constraints are controlled using a parameter $\delta\ge0$. The target function for closure constraints in the polygon inflation algorithm is defined as shown below (Sawall et al., 2015).

```
$f_{db}(a,\beta,P) = \sum_{i=1}^{l} \max \left( 1 - C(i, \: \begin{matrix} x \ y \ z \end{matrix} \right) - \delta, 0 \right) \quad (1.8)$
```
