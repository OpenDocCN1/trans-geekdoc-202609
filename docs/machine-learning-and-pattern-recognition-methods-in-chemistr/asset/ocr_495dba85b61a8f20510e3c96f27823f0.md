# 1.9 Probabilistic modeling and neural networks

If the probability distribution over model variables be available, then studying behaviors are mainly accessible. We represent model variables with the letter $x$. So, the main goal in probabilistic modeling is finding $p(x)$, the joint probability distribution of model variables. Furthermore, we introduce a process that is applicable for approximating $p^*(x)$, with $p_0(x)$ such that:

$p_0(x) \approx p^* (x)$

Also, it is common to approximate a conditional probability distribution. For example, in supervised learning (e.g., classification and regression), $x$ is the model's input, and we want to predict $y$, the model's output. From a probabilistic point of view, we want to approximate $p(y|x)$.

After taking this probabilistic framework, the next step is introducing a functional parameter for parameterizing the probability distributions. In variational autoencoders, the choice is neural networks. Generally, a neural network is a vector function, NeuralNet($.$). For instance, in image classification, if we represent the image with the letter $x$ and the class label with the letter $y$, then

$p = NeuralNet(x)$
