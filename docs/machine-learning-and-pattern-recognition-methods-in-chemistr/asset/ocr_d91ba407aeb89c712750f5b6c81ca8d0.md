# 2.2 Feature extraction in virtual metrology

In semiconductor manufacturing, one of the most extensively employed data–driven applications is virtual metrology, where a costly or unmeasurable variable is estimated by means of cheap and easy to obtain measures that are already available in the system. Maggipinto, Masiero, Beghi, and Susto (2018) present a deep learning method for unsupervised feature extraction based on convolutional autoencoders. The proposed method is tested on a real dataset for etch rate estimation.
