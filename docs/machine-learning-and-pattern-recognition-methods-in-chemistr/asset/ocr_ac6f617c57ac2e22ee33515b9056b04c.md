Because sand has greater surface roughness the extensive scattering of the sand is an surprising result. Given that sand is a heterogeneous multicomponent solid matrix with its own NIR fin-gerprint, there is the potential for interference from the sand in the pixels that contain the ABS microparticle (Amigo & Santos, 2020). Because the sand was burned in an oven at 450°C, there is no trace of organic matter. As such, any interference from the sand would likely arise from silicates and carbonates or many other plausible components that might be found in a complex multicomponent matrix–like sand.
