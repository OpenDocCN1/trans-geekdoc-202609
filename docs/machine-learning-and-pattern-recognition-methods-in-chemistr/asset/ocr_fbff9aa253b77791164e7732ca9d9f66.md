# 3.4 Logistic regression

Logistic regression is a common binary classifier that aims in discriminating samples between two classes by a hyperplane (see Fig. 3.4), which is called a separator hyperplane. Samples are assigned to their corresponding classes based on which side of the separator hyperplane is placed. It should be noted that the multiclass version of the logistic regression also exists.

In logistic regression, the loss function is defined based on the binary cross-entropy, which is as follows:

```
$L\left(\theta;{x^{(i)}, y^{(i)}\}_{i=1}^N\right) = \sum_i y^{(i)} \log\left(h\left(\phi(x^{(i)});\theta\right)\right) + \left(1-y^{(i)}ight) \log\left(1-h\left(\phi(x^{(i)});\theta\right)\right) \quad (3.8)$
```

where $h(\phi(x^{(i)});\theta)$ is defined as follows:

```
$h(\phi(x^{(i)});\theta) = \alpha\left(\theta^T \phi(x^{(i)})\right) = \frac{1}{1+\exp\-\theta^T \phi(x^{(i)}))}} \quad (3.9)$
```
