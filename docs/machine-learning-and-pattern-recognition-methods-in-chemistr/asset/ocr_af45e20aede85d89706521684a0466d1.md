# 1.6 Classification

In contrast with exploratory techniques such as PCA, classification refers to supervised multivariate analytical methods that are designed to sort samples into classes based on a series of measurements or theoretical values (Marini, 2010). These measurements or theoretical values define the classes, groups, of objects, and can be referred to as training sets (Marini, 2010). A validation step (internal cross-validation or external validation) is necessary to ensure the reliability of a model (Amigo, 2020).

Two of the primary categories of classification techniques are pure classification (discriminant) techniques, wherein the focus is on differences between samples of different classes, and class-modeling techniques, wherein the focus is on the similarities among samples of the same class (Marini, 2010). This introduction will focus on linear classification methods, but it is worth commenting that non-linear classification methods (e.g., artificial neural networks and k-means clustering) are also used to a certain extent.

# 1.6.1 SIMCA

Soft independent modeling by class analogy (SIMCA) is a classification method based on the use of principal component models to describe each of the classes (Marini, 2010). Each class in a training set is a quantitatively defined group of objects. The model for each class (e.g., Category 1) is then described by a set number, $A$, of principal components, according to:

```
$D_1 = T_A P_A^T + E$
```

where $D_1$ is the submatrix of the full data set containing only the samples of Category 1. $T_A$ and $P_A$ are the matrices composed of the first $A$ scores and loading vectors, respectively, and $E$ is the residuals (Marini, 2010).

# 1.6.2 PLS-DA

As its name implies, partial least-squares discriminant analysis (PLS-DA) is a discriminant classification technique based on partial-squares (PLS) algorithm. In the case of hyperspectral imaging, PLS-DA treats each pixel as if it were a sample and assigns it to a class by the regression model developed from the training set.
