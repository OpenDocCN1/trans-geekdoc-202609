In the following, as an example, we take the example of molecular property prediction to better explain concepts and algorithms. In molecular property prediction, the input is a small molecule compound where some of these are shown in Fig. 3.2. The goal is to build machine learning algorithms that take these small-molecule compounds as input and map them to the drug's activity prediction. In drug molecule property prediction, small-molecule compounds (as) could be described using a non-data-driven small-molecule description algorithms, which include connectivity fingerprint (ECFP) (Rogers & Hahn, 2010), ToxPrint (Yang et al., 2015), and molecular access system (MACCS) (Durant, Leland, Henry, & Nourse, 2002), ECFP is a topological molecular descriptor in which features are extracted by means of circular atom neighborhoods. MACCS is a m-bit 2D structure fingerprint where each encodes the presence of a specific substructure in the molecule (Durant et al., 2002). The ToxPrint utilizes a library of more than 700 chemotypes in which each molecule is represented by substructures associated with toxic effects, and it is important for toxicity predictions.

As compared to non-data-driven-based descriptors, in data-driven-based algorithms, the representation for each molecule is learned automatically.
