## 3.7 Deep learning-based models

In this section, deep learning-based models, both feature extraction and task prediction tasks are investigated. In these methods, features are done automatically. In other words, for each input sample, based on the task, a custom feature vector is learned. To this end, in the following, the first classic neural network is explained, and then the convolutional neural network is explained practically.

Hinton, Osindero, and Teh (2006) introduced an approach for deep belief nets with a learning algorithm given. One of the most important contributions of their work was the unsupervised learning of each hidden layer. After this step, a whole network is learned by utilizing supervised knowledge. Actually, in Hinton et al. (2006), features are automatically learned. It gives rise to deep learning to automatically learn features from input data hierarchically. In recent years, more deep learning-based networks are introduced.

## 3.9 Convolutional neural network

In this section, convolutional neural networks, also called ConvNets, are investigated. ConvNets were first introduced by LeCun et al. (1989) in the 1980s. Then, the first ConvNet is introduced, which recognizes digits. However, CNNs do not get attention for several years due to their high computational complexity and low power of computer resources in that decade. Krizhevsky, Sutskever, and Hinton (2012) introduced a CNN for image classification called AlexNet, which achieves high accuracy in ImageNet Large Scale Recognition Challenge compared to other approaches. It causes CNNs to be revisited, and a new field of research called deep learning gets more attention.

CNN is a network that commonly consists of four types of layers: convolutional layer, pooling layer, normalization layer, and dropout layer. In the following, each of these layers is explained, and then a practical example of how to use CNN in drug molecule property prediction is explained.

Convolutional layer: this layer is based on the convolutional operator in signal processing. The input of this layer could be a 1D, 2D, or 3D signal. Each layer has $n$ filters, and the size of the filters is determined by the input, which is 1D, 2D, or 3D signal. It should be noted that the content of the filters are parameters during the training. In this layer, the filter is slid over the input to do these operations. For 1D signal, sliding is done in one direction; for 2D signal, sliding is done in two directions, and so on (see Fig. 3.5). The convolutional layer extracts structured features.

Pooling layer: the main goal of this layer is to increase the field of view using downsampling operation. The pooling layer is typically placed after a convolution layer. Two common types of this layer are the max-pooling layer and the average pooling layer. In the max-pooling layer, the maximum value of the local filter is taken, and in the average pooling layer, the average value of the local filter is computed. It should be noted that the pooling layer has no learnable parameters.

Normalization layer: this layer normalizes the output of the previous layer before feeding into the next layer. There are two common normalization layers, namely batch normalization (Ioffe & Szegedy, 2015) and layer normalization (Ba, Kiros, Hinton, 2016). Both of these adaptive normalize the layer and have their own mean and variance. In the batch normalization layer, a mean and variance are computed over the minibatch, while in the normalization layer, the mean and variance are computed from the sum of the inputs to the neurons in a layer.

Dropout layer: this layer is designed such that it helps the model prevent overfitting (Srivastava, Hinton, Krizhevsky, Sutskever, & Salakhutdinov, 2014). This layer sets randomly selected elements of the input to zero, and the remaining ones are transferred to the output without change. This layer has no learnable parameters.
