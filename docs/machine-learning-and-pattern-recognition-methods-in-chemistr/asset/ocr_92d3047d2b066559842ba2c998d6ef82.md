By equating the two expressions and rearranging, it can be shown that the boundary can be estimated as:

```
$$\ln \frac{\Gamma_{P_0}(A)}{\Gamma_{P_0}(B)} - 0.5(\bar{\mathbf{x}}_A - \bar{\mathbf{x}}_B)^T \mathbf{S}^{-1}(ar{\mathbf{x}}_A - \bar{\mathbf{x}}_B) + (ar{\mathbf{x}}_A - \bar{\mathbf{x}}_B)^T \mathbf{S}^{-1}\mathbf{x}=0$ (2.39)$
```

Finally, including all constant terms in $w_0$ and the coefficients of the linear combinations in $\mathbf{w}$, the equation defining the class-boundary can be expressed as:

```
$w_0 + \mathbf{w}^T \mathbf{x} = 0$ (2.40)$
```

This latter equation unveils that LDA is a projection method seeking for the directions which maximize the distance between the class-centroids (*inter-class variability*) and minimize the within-variability in each category (intra-class variability). In the LDA context, these directions (i.e., latent variables) are also known as *canonical variances* (Krzanowski, 2000).

The same reasoning can also be extended for the solution of multi-class problems; for $G>2$, a sample is predicted as belonging to one category only if its posterior probability of belonging to that class is higher than the probability of belonging to any other:

```
$p(H|\mathbf{x}) > p(I|\mathbf{x}) \quad \forall I=1...G, H \neq I$ (2.41)$
```

Boundaries can be defined similarly as before, by pairs of classes:

```
$$\ln \frac{\Gamma_{P_0}(H)}{\Gamma_{P_0}(I)} - 0.5(\bar{\mathbf{x}}_H - \bar{\mathbf{x}}_I)^T \mathbf{S}^{-1}(ar{\mathbf{x}}_H - \bar{\mathbf{x}}_I) + (ar{\mathbf{x}}_H - \bar{\mathbf{x}}_I)^T \mathbf{S}^{-1}\mathbf{x}=0$\n$$$\forall I=1...G, H \neq I$ (2.42)$
```

As previously stated, canonical variances represent the direction which allows maximizing the ratio between the inter- and the intra-class variability.

In the multi-class, case is necessary to define a between-group variance/covariance matrix $\mathbf{S}_b$ :

```
$$\mathbf{S}_b = \frac{1}{G} \sum_{g=1}^G (\bar{\mathbf{x}}_g - \bar{\mathbf{x}})^T (\bar{\mathbf{x}}_g - \bar{\mathbf{x}})^T$ (2.43)$
```

Once $\mathbf{S}_b$ has been defined for all categories, the solution of the eigenvalue problem:

```
$$\mathbf{S}^{-1} \mathbf{S}_b \mathbf{w}_i = \lambda_i \mathbf{w}_i$ (2.44)$
```

allows the estimation of the canonical variances ($w_i$).
