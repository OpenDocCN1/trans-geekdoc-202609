# 7.2 Partial least-squares

Partial least-squares (PLS) is a well-known technique of regression. This technique is used when the number of correlated independent variables is high. It is widely noted that, in this case, the ordinary least square is failed. This situation is so common in chemometrics; hence, it is widely used in this research area. In this section, an example for PLS is given. In this example, physicochemical properties of protein tertiary dataset are utilized. This dataset is available in the machine learning repository. In the following, a python code is written to fix the PLS model on this dataset.

In the first step, the necessary libraries should be imported as follows:

```
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import scale
from sklearn.model_selection import selection
from sklearn.model_selection import RepeatedKFold
from sklearn.cross_decomposition import PLSRegression
```

The “pandas” library is used to read the data since the file is saved in “csv” format. Also, the “RepeatedKFold” class is imported since the model is evaluated by k-fold cross-validation and the “model_selection” class is imported to select the best model.

Next, the data should be read. To use this data, we need to download and read it. This part of code is given in the following:

```
data_url = "https://archive.ics.uci.edu/ml/machine-learning-databases/00265/CASP.csv"
raw_df = pd.read_csv(data_url, header=None)
data = raw_df.values[1::, 1:10]
data = data.astype(np.float)
target = raw_df.values[1::, 0]
target = target.astype(np.float)
```

Next, the PLS model fits into the data. In this case, there are nine predictors (namely, total surface area, non-polar exposed area, fractional area of the exposed non-polar part of the residue, molecular mass-weighted exposed area, average deviation from the standard area of residue, Euclidean distance, secondary structure penalty, and spatial distribution constraints) and one observable variable (i.e., size of the residue). In other words, the “data” variable is a 45,730 × 9 matrix and the “target” variable is a 45,730 × 1 matrix where 45,730 is the number of instances.
