- Unimodality constraints are applied when the concentration profile of a species has only one local minimum. In experimental conditions where measurement noise is present, small deviations from unimodality may be seen against the main trend using a control parameter $\omega\ge0$. When all the columns of the estimated matrix, **C**, are unimodal, the unimodality cost function, $f_{un}$ will be equal to zero. In such cases, the control parameter can be set to zero. If the absolute value of the deviations from unimodality is larger than $\omega$, the cost function will have a positive value to the sum of squares of all deviation.
