```
$[D_1; D_2; D_3; \dots; D_k] = [C_1; C_2; C_3; \dots; C_k] \mathbf{A}^T + [E_1; E_2; E_3; \dots; E_k] = \mathbf{C}_{aug} \mathbf{A}^T + \mathbf{E}_{aug}
(7.6)
```

A column-wise augmented concentration matrix, i.e., $[C_1; C_2; C_3; \dots; C_k]$, is obtained to describe the concentration changes in the individual data matrices. $\mathbf{A}^T$ contains spectral profiles of all constituents in all sub-matrices and $\mathbf{E}_{aug}$ is the residual matrix. Eq. (7.6) shows the augmentation of K matrices with the same size of $I \times J$. $[D_1; D_2; D_3; \dots; D_k] = \mathbf{D}_{aug} \mathbf{A}^T$ has rows and columns. Considering the fact that $\mathbf{C}$, $\mathbf{A}$, and $\mathbf{C}$ are the component matrices related to the three modes, each of $D_k$ can be formulated as:

```
$D_k = \mathbf{C}_{diag}(C_k(k, :))\mathbf{A}^T, k = 1, \dots, k.
(7.7)
```

The outer product of the respective component matrices, $\mathbf{C}$ and $\mathbf{A}^T$ in the column and row space of $D_k$ with proper intensities, will generate each $D_k$ matrix. The $\mathbf{C}_l(k,:)$ matrix contains total concentration values of each component in the kth data set. Equation is a well-known representation of a series of matrices with the trilinearity properties. The abstract space of the $\mathbf{D}_{aug}$ can be estimated by the application of the SVD to the data matrix (r is the number of abstract factors in the $D_{aug}$):

```
$\mathbf{D}_{aug} = \mathbf{U}_{aug} S_{aug} \mathbf{V}_{aug}^T + \mathbf{E}_{aug} = \mathbf{X}_{aug} \mathbf{V}_{aug}^T + \mathbf{E}'_{aug} = \mathbf{U}_{aug} \mathbf{Y}_{aug}^T + \mathbf{E}''_{aug}
(7.8)
```

If $E_{aug}$ is almost as the $E_{aug}'$ the subspace spanned by the truncated $\mathbf{U}_{aug}$ is a good estimation of the subspace spanned by the $\mathbf{C}_{aug}$ ($\mathbf{C}_{aug}=\mathbf{U}_{aug}S$), the subspace spanned by the truncated matrix is a good estimation of the subspace spanned by the $\mathbf{A}^T$ ($\mathbf{A}=\mathbf{T}^{-1} \mathbf{X}_{aug}}$). $\mathbf{T}$ and $\mathbf{T}^{-1}$, as the transformation matrices, generate $\mathbf{C}_{aug}$ and $\mathbf{A}^T$ by the combination of the $\mathbf{U}_{aug}$ and $\mathbf{V}_{aug}'$ respectively.

As a result of the bilinear structure of, $\mathbf{V}_{aug}$ and $\mathbf{U}_{aug}'$ spaces have a mutual duality relationship. Thus, each point in the column space of a data has a dual hyperplane in its row space, and vice versa. This mathematical relation provides an efficient tool to transfer the information of one space to its dual space. Consequently, in a powerful approach of unique solution or uniqueness, the condition is almost studied and visualized.

## Machine learning and pattern recognition methods in chemistry

When trilinearity is inserted into the ALS iterative procedure, profiles of the same component in the different parts of $C_{aug}$ matrix are forced to have the same shape in each iteration of the ALS and only differ with a scaling factor. Trilinearity can be implemented as follows:

- (1) Selecting the column with $C_{aug}$ ($c_{aug}^f, f=1\dots F$).
- (2) $c_{aug}^f$ with the size of $IK \times 1$ was reshaped to a matrix with the size of $I \times K$.

```
$C_{Mat}^f = \text{reshape}(c_{aug}^f)$
```

where $C_{Mat}^f$ is a matricized form of $c_{aug}^f$ and reshape is the MATLAB command.

- (3) SVD was applied on $C_{Mat}^f$.

```
$[u \ v] = \text{svd}(C_{Mat}^f), f = 1\dots F$.
```

- (4) Using the first principal component, $\hat{C}_{Mat}^f$ is reconstructed.

```
$$\hat{C}_{Mat}^f = u_1 \sigma_1 v_1^T$.
```

- (5) $\hat{C}_{Mat}^f$ was unfolded to a matrix with the size of $IK \times 1$.

The aforementioned steps ensure the idea of parallel profiling profiles.
These steps are necessary to explain the uniqueness property of trilinearity constraint by the duality concept:

First, SVD should be employed for defining the basis vectors of row and column space of $D_K$:

```
$D_k = U_k S_k V_k^T + E_k = X_k V_k^T + U_k Y_k^T, k = 1,\dots,K (7.9)
```

In this section, $t_1$ is a vector containing the coordinates of a point in the column space of $D_1$, whose correspondence to the column space of all sub-matrices of $D_{aug}$ and $c_1$ is a profile correspondence to $t_1$, which belongs to all sub-matrices. Hence, based on the non-negativity constraint, it is possible to define the dual hyperplane of $t_1$ in the V-space of $D_1$ by the following equation ($z_1$ is general variable representing coordinates of an arbitrary point in dual hyperplane):

```
$t_1 S_1^{-1} z_1 = 0 (7.10)
```

## Uniqueness in resolving multivariate data

In the next step, the coordination of $c_1$, $t_i$, in the column space of other sub-matrices must be calculated:

```
$t_i = c_1 U_i, i=2,3,\dots,K (7.11)
```

Afterward, the complementary subspace of $c_1$ in all sub-matrices can be calculated based on dual concept:

```
$t_1 S_1^{-1} z_1 = 0 (7.12)
```

The $z_i$ represents the coordinates of an arbitrary point on the defined hyperplane in the V-space of $D_i$. There is $K$ hyperplane for sub-matrices of the augmented matrix, and their intersection defines a total hyperplane in the row space of $D_{aug}$. The dual point of the total hyperplane in the column space of $D_{aug}$ can generate the trilinear plane, while selected initial $t_1$ is correct. Thus, all hyperplanes in the row space of sub-matrices must be transformed to the row space of $D_{aug}$ by linear transformation. $T_k$ is a transformation matrix:

```
$T_k = V_k^{-1}, k=1,2,\dots,K (7.13)
```

Based on linear algebra, coordinate-wise representations of vectors basis set can be transformed to equivalent representations of another set. This transformation is called change of base. Therefore, it is necessary to transform $r_K$ arbitrary points of each hyperplane in $V_K$ to the row space of $D_{aug}$ by transformation matrices ($r_K$ is rank of $K$ sub-matrix):

```
$Z'_K = Z_K T_K (7.14)
```

$Z_K$ and $Z'_K$ are the coordination of arbitrary points in $V_K$ and $V_{aug}$ before and after transformation, respectively. Thereafter, the total hyperplane (coefficients) should be calculated by $\sum_{k=1}^K r_k$ points $(Z'_K)$.

As a simple example, $x+2y+3z=0$ is a hyperplane with coefficients $[1, 2, 3]$ (intercept is zero). In order to find the coefficients of the plane, it is necessary to look for a vector orthogonal to the plane. $[x, y, z]$ are the coordinates of any arbitrary point on the plane. Regardless of the dimension of the hyperplane, Null operator in MATLAB can be implemented to calculate the coordinates of the hyperplane.

Hence, $t_{aug}$ contains coefficients of the total hyperplane of all components in the row space of the augmented data, and $Z_{aug}$ is the coordination of any arbitrary point on a hyperplane:

```
$t_{aug} Z_{aug} = 0 (7.15)
```

Based on the duality concept, this hyperplane sets a point $t_{aug} S_{aug}$ in the column space of the augmented data matrix. As a consequence, linear combination of columns of $U_{aug}$ with coordination of the point $(t_{aug} S_{aug})$, can generate $C_{aug}$.

```
$C_{aug} = t_{aug} S_{aug} U_{aug} (7.16)
```

By converting this column vector with $k$ parts to a matrix with $k$ columns, $C_{aug}$ can be calculated:

```
$C_{aug} = [C_{aug,1}, C_{aug,2}, \dots, C_{aug,K}] (7.17)
```

Due to the trilinear nature of $C_{aug}$, the second eigenvalue of the metricized $C_{aug}$ should be zero. A non-zero value for the singular value shows the non-linearity of $C_{aug}$. In summary, the calculated $c_1$ (based on $l_1$) is projected to the column space of all sub-matrices and complementary subspace is calculated based on these projections. Trilinear constraint, which works based on the proportionality property, can produce the unique solution. If $c_1$ belongs to the column space of all sub-matrices, the second eigenvalue of $C_{aug}$ should be close to zero; otherwise, $c_1$ does not belong to all sub-matrices.

## 4. Nonexistence information

Information on the absence of a chemical species in part of the presence region of components is introduced by several constraints in literature, and this information is used to reduce the range of feasible solutions. Dataset analysis, chemical information related to the presence/absence of each component in the matrices aligning together is considered as the correspondence of species (Abdullahi & Sajjadi, 2010). It can be said that applying this constraint is, in fact, equivalent to applying a zero concentration region for species not present in each data matrix (Tavakkoli et al., 2018).
