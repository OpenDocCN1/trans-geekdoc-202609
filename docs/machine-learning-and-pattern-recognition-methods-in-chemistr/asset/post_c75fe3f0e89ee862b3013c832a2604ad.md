- Non-negativity constraints

Soft-negativity constraints can be applied by a simple modification of steps 2a and 2b of P-ALS algorithm. For imposing soft-negativity constraints, in the first step, the unconstrained least-squares problem is solved, resulting in the coefficients vector $(\mathbf{b})$. For any negative coefficients, $b_n$, an equality constraint is set $(b_i = 0)$. These equality constraints are imposed using the penalty functions described in the previous section. The penalty value can be tuned for applying hard or soft non-negativity constraints. If hard constraints are desired, larger penalty weights should be used for the P-ALS solution to the result that would be obtained from NNLS (Lawson & Hanson, 1995) or FNNLS (Bro & De Jong, 1997; Bro & Sidropopoulos, 1998). An example is given below to illustrate the implementation of non-negativity constraints by P-ALS algorithm.

$\mathbf{y} = \mathbf{X} = \begin{bmatrix} 0.1656 & 0.6892 & 0.2290 \\ 0.6020 & 0.7048 & 0.9133 \\ 0.2630 & 0.4505 & 0.1532 \\ 0.6541 & 0.0838 & 0.8258 \end{bmatrix} \mathbf{b} = \begin{bmatrix} -0.0827 \\ 0.6528 \\ 0.3708 \end{bmatrix}$

Considering that the first coefficient is negative, $b_1 = -0.0827$, a soft non-negativity constraint can be imposed as shown below using penalty weighting function $\lambda=1$ and equality constraints, $b_{\text{P-ALS}(\lambda)} = [-0.0023, 0.6503, 0.3143]$. Harder non-negativity constraints can be applied using $\lambda=10$, which gives the coefficient vector $b_{\text{P-ALS}(10)} = [-2 \times 10^{-5}, 0.6503, 0.3117]$, and if hard non-negativity constraints are desired, a larger penalty weight $\lambda=100$ can be used, which results in $b_{\text{P-ALS}(100)} = [-2 \times 10^{-7}, 0.6503, 0.3117]$. It is worth noting that the solution of non-negative least-squares method (NNLS) $\mathbf{b}_{\text{NNLS}} = [0, 0.6503, 0.3117]$ compares favorably to the solution obtained with $\lambda=100$. For other examples illustrating the implementation of non-negativity constraints with the P-ALS algorithm, refer to the original paper (Gemperline & Cash, 2003).

- Closure constraints

Soft constraints can be implemented by the P-ALS algorithm using least-squares penalty functions and equality constraints. Augmenting the initial or intermediate estimate of $\mathbf{S}^{\text{op}}$ with the constraint matrix, $\mathbf{H} = [1, 1, \dots, 1]$, and $\mathbf{y}$ with the constrained value, $\mathbf{g} = [1]$, and considering an adjustable penalty function, $\lambda$, gives results with all species concentration profiles equal to or approximately one. For chemical reactions where a weighted sum of species concentrations is constant, e.g., in the following consecutive reaction $(2A \rightarrow B)$, the constraint matrix would be different (e.g., $H=[1/2, 2, 1]$ and $g=[1]$ for the consecutive reaction). The previous example is used again to illustrate the implementation of constraints and also to illustrate the fact that different constraints can be applied in P-ALS in one step. Soft closure and non-negativity constraints can be implemented simultaneously with a penalty weighting function $\lambda = 1$, giving the results shown below with $\mathbf{b}_{\mathbf{P-ALS}}=0.9799$.

- Unimodality constraints

Soft unimodality constraints can also be applied by the P-ALS algorithm via penalty functions and equality constraints. In the first step, constrained least-squares problem is solved for all rows of $\mathbf{C}$. Each resulting concentration profile, $\mathbf{c}_i$, is checked to find the global maximum. Inspecting the concentration values in both forward and backward directions should confirm no local maxima. For example, if $\epsilon_{i,j} < \epsilon_{i+1,j}$ in forward direction, and if $\ell_i < \ell_{i-1},j$ in backward direction, local maximums are present. In such cases, unimodality constraints must be implemented by setting $g_{i+1} = \ell_i$, or $g_{i-1} = \ell_i$. For an example of illustrating the implementation of unimodality constraints in the P-ALS algorithm, refer to the original paper (Gemperline & Cash, 2003).

## 2.2 Multi-way least-squares (P-ALS) algorithm

Multi-way P-ALS or NWAY-ALS was proposed as an extension to the P-ALS approach, incorporating all advantages of that method, as well as the second-order advantage for species to two or more experiments. The multi-way ALS procedure can be described as simply unfolding the multi-way array to matrix and then performing the standard P-ALS approach. A detailed description of multi-way P-ALS approach is given below.

A three-way array $A$ of the size $I \times J \times K$ can be matricized as a two-way array (matrix) in three different directions, that is, a row-wise augmented matrix $A_r (JK \times I)$, a column-wise augmented matrix $A_c (IK \times J)$, and a tube-wise augmented matrix $A_t (IJ \times K)$. Fig. 1.2 represents different ways of matricizing a three-way array. In typical spectroscopic applications, and also in this chapter, it is supposed that the rows of arrays represent the mixture spectra, the columns represent the variables (e.g., wavelengths), and the tubes represent different experiments. Considering this assumption, the column-wise augmentation of the measurement matrices keeps the variables intact, so the information in the variables would not be wiped out.

The bilinear decomposition of the column-wise augmented concentration matrix $\mathbf{C}_c (IK \times N)$ and a spectral matrix $\mathbf{S}^T (N \times J)$ considering $N$ chemical active species are present. In the multi-way P-ALS procedure, starting with initial estimates of $\mathbf{C}_0$ or $\mathbf{S}_0$, row-wise least-squares penalty functions are used to fit the profiles alternatively to the constrained estimates. Steps 2a and 2b of the P-ALS algorithm can be modified for multi-way P-ALS analysis as shown below.

- a. Given some initial or intermediate estimate of $\mathbf{C}_c$, find every row of $\mathbf{S}$ (or every column of $\mathbf{S}^T$) that minimizes $\|\mathbf{a}_{c,j} - \mathbf{C}_{s^T,j}\|$ based on the constraints imposed on that row as $s^T_{i,j} = g_j$, where $g_j$ specifies the constraint goals for spectra.
