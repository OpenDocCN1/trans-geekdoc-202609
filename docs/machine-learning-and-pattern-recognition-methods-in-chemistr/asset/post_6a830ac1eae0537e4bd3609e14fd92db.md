## 3.6 Random forest

Random forest is a state-of-the-art machine learning method which in many research areas achieves comparable performance with other methods. Random forest is an ensemble learning method for regression, classification, and other tasks in which diverse trees as base predictors are generated. The final decision is made using diverse voting (in classification), average prediction of each tree (in regression), or other fusion techniques. The decision tree is a tree-like structure in which each internal node makes a decision about a feature that is effective in the task prediction process. Also, a class label is assigned to each leaf node. To classify an unseen input, the tree is traversed from root to leaf features to assign an output to it.

In the decision tree, there are two main challenges: how to split nodes and how to find the best trees. It is shown that learning the simplest tree is an NP-complete problem (Hya & Rivest, 1973). To this end, a greedy heuristic is used to construct a decision tree. At first, the algorithm is started from an empty decision tree, and then the next best feature is selected to split using some measures like information gain (Quinlan, 1986), Gini impurity, or variance reduction (Breiman, Friedman, Olshen, & Stone, 1984). This procedure is iterated until the tree is constructed. Now, there are many variants of the decision tree algorithm like ID3, C4.5, and CART algorithm (Mitchell, 1997).

To implement a random forest algorithm in Python, scikit-learn package could be used. The class sklearn.ensemble.RandomForestClassifier creates an object that fits a random forest classifier model on the given training samples. This class has many parameters like "n_estimator" denotes the number of trees in a forest, "criterion" denotes the measure to select the next feature to split, and "max_depth" denotes the maximum depth of each decision tree.

As it is shown, random forest, like SVM, performs better than NR-AR-LBD tasks than on the other tasks.
