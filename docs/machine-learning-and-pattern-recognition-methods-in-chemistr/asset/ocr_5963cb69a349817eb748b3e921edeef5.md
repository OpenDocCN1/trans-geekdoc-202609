The number of PLS components should be determined. To this end, for the different number of PLS components, the PLS model is fit, and then its MSE is computed. To do so, the following part of the code is used:

```
cv = RepeatedKFold(n_splits=5)
mse=[]
for i in np.arange(1, 9):
 pls = PLSRegression(n_components=i)
 score = -1*model_selection.cross_val_score(pls, scale(data),
 target, cv=cv, scoring='neg_mean_squared_error').mean()
 mse.append(score)
#plot number of PLS components vs. MSE
plt.plot(mse)
plt.xlabel('Number of PLS Components')
plt.ylabel('MSE')
```

As is shown, when the number of PLS components is set to a value greater than three, the model gets the lowest mean-squared error.
