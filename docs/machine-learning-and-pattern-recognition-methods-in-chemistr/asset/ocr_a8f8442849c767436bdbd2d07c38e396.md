# 6. Hard models constraint

In evolving systems where concentration changes over time according to chemical kinetics or chemical equilibria (the-so called hard modeling) can be used in a powerful way to calculate concentration profiles by imposing the mathematical functions of the chemical model as constraints. These kinds of constraints generally reduce the range of feasible solutions and often result in unique solutions for components that can be described with a proper physical-chemical model, provided the initial conditions are precisely known (Beyramysultan et al., 2014).
