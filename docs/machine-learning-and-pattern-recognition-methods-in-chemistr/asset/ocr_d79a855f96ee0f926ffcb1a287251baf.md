The inference network is used to map the space of chemical molecules into a continuous space so that mathematical operations can be performed on objects in this space. The generative network can also be used to produce unseen chemical molecules. The basic idea can be seen in Fig. 6.10. Blaschke, Olivecrona, Engkvist, Bajaroth, and Chen (2018) have used the variational autoencoder to develop a model for generating chemical molecules. They used three CNN layers followed by two fully connected layers as an encoder. The output of the encoder layer is interpreted as the mean and variance of a Gaussian distribution. A random point is sampled using these parameters and as input for the decoder. The decoder uses a fully connected layer by three layers of RNNs, built using GRU cells (Chung et al., 2014). The GRU layer defines the probability distribution over all possible outputs at each position in the output sequence. In the training mode, the input of the last layer is a concatenation of the output of the previous layer and token from the target SMILES (in the training set). In contrast, in the generation mode, the input of the last layer is a concatenation of the output of the previous layer and the sampled token from the previous GRU cell. This method is called teacher forcing (Williams & Zipser, 1989) and is known to increase the performance on long text generation. The network architecture is shown in Fig. 6.11.

They used Bayesian Optimization (BO) (Snoek, Larochelle, & Adams, 2012) in latent space to find molecules with desirable properties. For this purpose, they applied an objective function that estimates the probability of being active against a specific target protein. Gaussian process (Rasmussen & Williams, 2005) models with 100 starting points have been developed to predict the score of each molecule using the latent space representation. The desired points identified in the latent space are then mapped to the representation using the decoder network. This process has been repeated 500 times to find the best answers.
