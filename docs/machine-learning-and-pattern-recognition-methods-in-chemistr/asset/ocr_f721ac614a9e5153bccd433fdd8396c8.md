# Tuning the apparent thermodynamic parameters of chemical systems

![](bbox=[0.395, 0.095, 0.604, 0.19])

**Fig. 4.2** The basic equilibrium A+B=C. The basic equilibrium A+B=C, with two auxiliary equilibrium interactions between the interferent I and the equilibrium species A and C.

In addition to the initial equilibrium, there are now two additional interactions of I with A and with C:

```
$K_{A,I} = \frac{[A,I]}{[A][I]} (4.3)
```

```
$K_{C,I} = \frac{[C,I]}{[C][I]} (4.4)
```

The apparent equilibrium reaction and its constant $K'_C$ are defined as:

```
$A' + B \equiv C' K'_C = \frac{[C']}{[A'][B]} (4.5)
```

The hypothetical components $A'$ and $C'$ are defined as the sum over all species containing component A or C.

```
$[A'] = [A] + [A.I] (4.6)
```

And:

```
$[C'] = [C] + [C.I] (4.7)
```

Thus, in the presence of the side reaction(s), the relationship between the hypothetical components $A'$ and $C'$ and the real species of the system can be defined by combining Eqs. (4.5)–(4.7):

```
$K'_C = \frac{[C] + [C.I]}{([A] + [A.I])[B]}$
```

Next, Eqs. (4.3) and (4.4) are used to replace [A.I] and [C.I]

```
$K'_C = \frac{[C] + K_{C,I}[C][I]}{([A] + K_{A,I}[A][B])}
```

Rewriting results in

```
$K'_C = \frac{[C]}{[B][A]} \times \frac{1 + K_{C,I}[I]}{1 + K_{A,I}[I]}$
```
