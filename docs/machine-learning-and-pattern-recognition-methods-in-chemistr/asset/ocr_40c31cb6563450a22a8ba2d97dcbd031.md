# 4. pyMCR

Camp Jr (2019) has introduced a python library for multivariate curve res-
olution with alternating regression, which is called pyMCR. This
software library, written in Python, enables users to perform multivariate
curve resolution (MCR) analysis, which lets users choose the error functions
for minimization, constraints, and regressors.

# 5. DeepChem

DeepChem is an open-source framework, which is first created by Bharath
Ramsdumar at Stanford University. Now, it is developed by a group of devel-
opers; however, anyone could join and contribute. This project uses Tensor-
Flow create deep learning models. It is developed to facilitate the researchers
develop new deep learning-based algorithms in drug discovery, biology, and
life science. DeepChem provides many useful APIs to develop algorithms.
These APIs include (1) data (for handling data) and (2) features: extract features
from input data to feed into machine learning models. DeepChem provides
both data-driven approaches like graph convolution feature and non-
data-driven approaches like CircularFingerprint, PubChemFingerprint,
Mol2Fingerprint, and RDKDescriptors. (3) Scikit-learn models,
(4) Keras models, (5) PyTorch models, (6) Transformers: provide transformer
object to adapt the mechanism of attention by weighting each part of the input
data to emphasize the important parts, (7) hyperparameter tuning, and (8) rein-
forcement learning: reinforcement learning is a powerful technique in machine
