The final decision is made using diverse voting (in classification), on average prediction of each tree (in regression), or other fusion techniques. The decision tree is a tree-like structure in which each internal node makes a decision about a feature that is effective in the task prediction process. Also, a class label is assigned to each leaf node. To classify an unseen input, the tree is traversed from root to leaf input features to assign an output to it.

In the decision tree, there are two main challenges: how to split nodes and how to find the best trees. It is shown that learning the simplest tree is an NP-complete problem (Hyafil & Rivest, 1973). To this end, a greedy heuristic is used to construct a decision tree. At first, the algorithm is started from an empty decision tree, and then the next best feature is selected to split using some measures like information gain (Quinlan, 1986), Gini impurity, or variance reduction (Breiman, Friedman, Olshen, & Stone, 1984).
