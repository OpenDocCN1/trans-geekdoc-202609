CNN is a network that commonly consists of four types of layers: convolutional layer, pooling layer, normalization layer, and dropout layer. In the following, each of these layers is explained, and then a practical example of how to use CNN in drug molecule property prediction is explained.

Convolutional layer: this layer is based on the convolutional operator in signal processing. The input of this layer could be 1D, 2D, or 3D signal. Each layer has $n$ filters, and the size of the filters is determined by the input, which is 1D, 2D, or 3D signal. It should be noted that the content of the filters are parameters during the training, the procedure should be learned. In this layer, the filter is placed in the center of each element of the input signal and the content of the filter and the input signal are element-wise multiplied. Then, the filter is slid over the input signal to do these operations on all elements. The direction of the sliding is dependent on the input signal. For 1D signal, sliding is done only in one direction, for 2D signal, sliding is done in two directions, and so on (see Fig. 3.5). The convolutional layer semantically extracts the structured local features. By stacking the convolutional layers, mid-level and high-level features could be extracted.
