Regression methods deal with modeling real-valued (quantitative) responses. In their simplest version, they postulate the functional relationship between the response(s) and the independent variables (predictors) is a linear one. Assuming the case of a single dependent variable y and x is a J-dimensional vector

```
x = [x_1 x_2 ... x_j ... x_J] (2.2)
```

can be expressed as:

```
y = ŷ + e = b_0 + b_1 x_1 + b_2 x_2 + ... + b_j x_j + ... + b_j x_j + e (2.3)
```

where ŷ is the approximation (predicted value) of the response provided by the linear function, which is univocally determined by the values of the coefficients b_1, b_2, ... by and of the intercept b_0 . On the other hand, e indicates the residual, i.e., the difference between the true and predicted value of the response. Here, it should be stressed that if centering between both x and y is assumed, the intercept becomes zero, in the remainder of the text, it will not be included in the models, i.e.,

```
ŷ = b_1 x_1 + b_2 x_2 + ... + b_j x_j + ... + b_j x_j (2.4)
```

As preliminarily introduced above, model building corresponds to estimating the values of the coefficients b_1, b_2, ... b_j given the training data, i.e., exploiting the fact that there is a set of observations for not only the x, but also the y is known. The aim of predictive modeling is to obtain accurate approximations of the dependent variable(s), in the majority of the cases, the definition of the optimal value of the coefficients involves some minimization of the residuals (least-squares criterion).
