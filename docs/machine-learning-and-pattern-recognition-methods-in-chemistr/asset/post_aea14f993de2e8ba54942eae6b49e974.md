# Multivariate predictive modeling and validation

^aDepartment of Physical and Chemical Sciences, University of L'Aquila, Coppito, Italy

Many problems in chemistry involve the prediction of one or more qualitative or quantitative properties based on the experimental data (Martens & Naes, 1991). Examples of such problems involve, instance, the possibility of predicting protein or lipid content in food matrices by NIR spectra or of diagnosing the onset of a disease through the MS or NMR analysis of serum samples. In the former case, the property to be predicted is of quantitative value, while in the latter, it is discrete (qualitative). This chapter presents the chemometric strategies most used to formulate predictive models, i.e., models that relate one or more dependent variables Y (qualitative or quantitative) to a set of independent variables X.

Irrespective of its specific characteristics, building a predictive model requires only that a relation between the X and the Y exists also, operationally, a reasonable mathematical formulation be postulated to express (or at least approximate) this relation:

```
$y = f(\mathbf{x})$
```

Here, it should be stressed that since the exact form of the function $f(\mathbf{x})$ is unknown, it has to be empirically estimated by making use of known data to approximate the functional relation in Eq. (2.1). Such estimation relies on the availability of a sufficient number of samples (which constitute the so-called training set), for which the values of both $\mathbf{x}$ and $y$ are known. Operationally, model building is accomplished by defining an explicit mathematical formulation of the function $f(\mathbf{x})$, which is expressed in terms of some adjustable parameters (model coefficients), whose values are estimated based on the training data. While these concepts are equally valid for all kinds of predictive models, the techniques used for dealing with quantitative (regression) or qualitative (classification) responses related to the nature of the dependent variable(s) and will be discussed individually in the remainder of this chapter.

# 1. Regression

Regression methods deal with modeling real-valued (quantitative) responses. In their simplest version, they postulate the functional relationship between the response(s) and the independent variables (predictors) is a linear one. Assuming the case of a single dependent variable y and x is a J-dimensional vector

```
x = [x_1 x_2 ... x_j ... x_J] (2.2)
```

can be expressed as:

```
y = ŷ + e = b_0 + b_1 x_1 + b_2 x_2 + ... + b_j x_j + ... + b_j x_j + e (2.3)
```

where ŷ is the predicted value of the response, e is the difference between the true and predicted value. Here, it should be stressed that if centering both x and y is assumed, the intercept becomes zero.

```
ŷ = b_1 x_1 + b_2 x_2 + ... + b_j x_j + ... + b_j x_j + e (2.4)
```

As previously introduced, model building corresponds to defining an explicit mathematical formulation of the function $f(\mathbf{x})$, which is expressed in terms of some adjustable parameters (model coefficients), whose values are estimated based on the training data. # 1.1 Multiple linear regression (MLR)

When the ordinary least-squares approach is used to estimate the regression coefficients based on the training data, the corresponding technique is often referred to as multiple linear regression (MLR). In particular, the optimal value of the elements of **b** is sought as the one leading to the minimum approximation error on the training data (defined as the sum of squares of the residuals $E = \sum_{i=1}^N e_i^2$), as mathematically expressed by:

```
$$\argmin_b \sum_{i=1}^N e_i^2 = \argmin_b \{e^T e\} = \argmin_b \{(y - Xb)^T (y - Xb)\} \quad (2.8)$
```

Solution to the condition expressed by Eq. (2.8) is obtained by differentiating $E$ with respect to the elements of **b** and setting all the partial derivatives to zero. The corresponding values of the regression coefficients are:

```
$b_{MLR} = (X^T X)^{-1} X^T y \quad (2.9)$
```
