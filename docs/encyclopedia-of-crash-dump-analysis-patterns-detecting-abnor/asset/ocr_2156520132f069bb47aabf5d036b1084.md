# Physical Memory

Sometimes there is not enough physical memory, and a system experiences the so-called **disk** or **page file thrashing** trying to resolve page faults. This can be seen in some memory dumps coming from frozen environments showing signs of double traps in running threads, the first trap is a normal memory access fault (shown in bold) and the second is forced NMI bugcheck115 to save a memory dump (shown in bold italics):
