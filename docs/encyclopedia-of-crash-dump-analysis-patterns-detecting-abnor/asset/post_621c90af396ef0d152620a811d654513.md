Now the address 0x40010024 happens to be completely invalid, and we have an access violation and the crash dump.

## Comments

Sometimes changes in physical memory size may also affect process behavior. Other examples include an application running under a user mode debugger which affects a different type of runtime heap used.

## Clone Dump

With the possibility of process cloning (reflection) starting from Windows 7 it is possible to get memory snapshots (Clone Dump) from a process clone (similar to fork API in Unix). The procdump[13] tool has -r switch for that purpose. We checked this with x64 Windows 7 notepad.exe. We got two memory dumps: one is a clone with this stack trace:
