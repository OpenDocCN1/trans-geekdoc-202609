## 注释

如果我们拥有非常多数量的此类进程（尤其是当它们未体现为某个父进程句柄泄漏时），可能需要为 _Proc_ 池标记启用对象引用跟踪。请参阅 WinDbg 帮助中的 **!obtrace** 示例。还有 **引用泄漏** 模式（第 830 页）。

如果父进程 ID 已不存在，我们可以转储所有进程的句柄表并搜索我们的进程对象：

```
!handle 0 3 0 Process
```
