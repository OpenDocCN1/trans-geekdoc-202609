双释放错误会导致**动态内存损坏**模式（第 307 页）。之所以**双释放**值得拥有自己的模式名称，是因为调试运行时库甚至操作系统本身都能检测到此类错误并立即保存崩溃转储。

对于某些堆实现，双释放操作不会导致立即的堆损坏和后续崩溃。例如，如果我们连续分配 3 个块，然后释放中间的块两次，则不会发生崩溃，因为第二次释放调用能够检测到该块已被释放且不执行任何操作。以下程序会无限循环且从不崩溃：

```
#include "stdafx.h"
#include <windows.h>

int __tmain(int argc, _TCHAR* argv[])
{
    while (true)
    {
        puts("Allocate: p1");
        void *p1 = malloc(100);
        puts("Allocate: p2");
        void *p2 = malloc(100);
        puts("Allocate: p3");
        void *p3 = malloc(100);

        puts("Free: p2");
        free(p2);
        puts("Double-Free: p2");
        free(p2);
        puts("Free: p1");
        free(p1);
        puts("Free: p3");
        free(p3);

        Sleep(100);
    }

    return 0;
}
```
