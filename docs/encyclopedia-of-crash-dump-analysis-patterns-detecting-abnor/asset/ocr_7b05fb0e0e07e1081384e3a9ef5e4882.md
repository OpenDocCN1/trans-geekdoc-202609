# Place Trace

Most Execution Residue (page 365) traces in memory dumps are not explicitly temporal (see Special and General Trace and Log Analysis170) but may be ordered by some space coordinate, such as memory addresses or page frame numbers. Furthermore, virtual space can be further subdivided into places such as modules, and physical space may be restructured into places such as processes. Simple space trace of some data value can be constructed using Value References (page 1057) analysis pattern.
