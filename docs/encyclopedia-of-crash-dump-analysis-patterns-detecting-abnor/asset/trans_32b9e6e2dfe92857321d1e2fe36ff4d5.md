

## Mac OS X

此模式是在 *加速 Mac OS X 内核转储分析* 培训中介绍的。基本上，它是一个未等待或未挂起的线程（大多数线程都处于等待或挂起状态）。但是，从内存转储中无法在转储生成时确定它是否是 **尖峰线程**（第 885 页）（除非我们有一组内存快照，并且在每个快照中都有相同或类似的回溯），并且我们没有任何 **旁注文本**（第 780 页）带有线程的 CPU 消耗统计信息。例如，在一个内核转储中，我们有以下线程：
