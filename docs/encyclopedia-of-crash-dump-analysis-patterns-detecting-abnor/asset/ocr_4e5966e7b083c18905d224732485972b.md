# Injected Symbols

This pattern can be used to add missing symbols when we have **Reduced Symbolic Information** (page 829) like it was done previously in this old case study 103. For example, TestWER104 module was compiled with static MFC and CRT libraries and its private PDB file contains all necessary symbols including MSG structure.
