# Windows

We already introduced **Active Thread** (page 63) pattern variant for Mac OS X. Here we provide an example for Windows. Unless we have **Evental Dumps** (page 328), **Active Threads** in Windows are usually threads from **Busy System** (page 99) or **Spiking Threads** (page 888), and, therefore, represent an abnormal behavior since most threads are waiting or calling some API. For **Evental Dumps** they may be just normal threads:
