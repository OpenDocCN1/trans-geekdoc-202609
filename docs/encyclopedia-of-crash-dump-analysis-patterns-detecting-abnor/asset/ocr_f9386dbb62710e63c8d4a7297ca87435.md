# Message Hooks

In addition to hooking functions via code patching, there is another function pre- and post-processing done via windows message hooking13 mechanism that we call **Message Hooks** pattern to differentiate it from **Hooked Functions** pattern (page 488). In some cases, message hooking becomes a source of aberrant software behavior including spikes, hangs, and crashes. We can identify such residue looking at the problem thread raw stack:
