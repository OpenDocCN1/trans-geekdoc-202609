# # Hooking Level

In addition to **Hooked Functions** (page 484) pattern, we should also pay attention a number of patched functions. Often value-added hooksware<sup>97</sup> (see also **Hooksware** patterns, page 1175) has configuration options that fine-tune hooking behavior.
