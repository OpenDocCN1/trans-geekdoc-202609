## Windows

## Database

某些故障排除和调试技术涉及在内存的某个区域中保存名为堆栈跟踪数据库的每个 *堆栈跟踪*（第 926 页），这些跟踪会导致特定操作，例如内存分配或打开资源句柄。典型模式用法示例包括进程堆 *内存泄漏*（第 650 页），因 *句柄泄漏*（第 416 页）导致的 *内存不足*（第 526 页）。此类数据库中的典型条目由函数调用期间保存的返回地址组成（可能是 *截断的堆栈跟踪*，第 1015 页）：
