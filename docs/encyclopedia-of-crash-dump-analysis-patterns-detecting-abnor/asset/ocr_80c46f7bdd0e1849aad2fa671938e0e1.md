vfbasics and vrfcore modules are Application Verifier DLLs that possibly translate an invalid handle exception to a breakpoint exception and, therefore, trigger the launch of a postmortem debugger from an unhandled exception filter. Application Verifier version (x64 or x86) must match the application platform (64-bit or 32-bit)120.
