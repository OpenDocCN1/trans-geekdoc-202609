# Message Box

Other suspicious threads in crash dumps are GUI threads executing message box code. Usually, message boxes are displayed to show some error, and we can see it by dumping the second and the third _MessageBox_ parameters:

```
int MessageBox(
  HWND hWnd,
  LPCTSTR lpText,
  LPCTSTR lpCaption,
  UINT uType);
```

Sometimes message boxes block processes as shown in the example illustrating **Coupled Processes** pattern (page 149). Other threads might point to possibly “hang” sessions and processes in memory dumps coming from terminal services environments. This is another example of the collective **Blocked Thread** pattern (page 82).

Let’s look at one example where message box pointed to the right troubleshooting direction. A user process was reported hanging from time to time. However, it was not specified which one.
