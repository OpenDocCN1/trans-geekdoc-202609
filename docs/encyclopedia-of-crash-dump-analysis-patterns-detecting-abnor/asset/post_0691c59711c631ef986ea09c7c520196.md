## Evental Dumps

One of the customers of Software Diagnostics Services 66 submitted memory dumps saved by DebugDiag 67 to accompany software logs for the analysis of sudden process exit. We didn’t request such memory dumps and initially dismissed them. However, during software log analysis we decided to look at Adjoint Spaces 68 to see whether there was some additional information in stack traces. We found out that those dumps were saved on each thread exit event. Since other threads were either waiting or Active Threads (page 63), their analysis gave clues of process behavior before process exit. For example, we found ALPC Wait Chain (page 1097) to Coupled Process (page 149). The latter prompted us to analyze Coupled Activities 69 in the software log and diagnose the possible problem there. Since saving memory dumps on thread creation and exit can be a useful technique we decided to add Evental Dumps memory analysis pattern to our pattern catalog.
