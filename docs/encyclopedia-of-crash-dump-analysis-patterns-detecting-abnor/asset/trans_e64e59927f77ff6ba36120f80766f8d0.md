NULL指针是用户空间指针的一个特殊类。通常，其值在0x00000000 - 0x0000FFFF范围内。我们可以看到它们在诸如下列指令中被使用：

```
mov esi, dword ptr [ecx+0x10]
```

其中ecx的值为0x00000000，我们尝试访问位于0x00000010内存地址处的值。

当我们得到一个崩溃转储，并看到无效指针模式时，下一步是解释指针值，这应该有助于理解导致崩溃的可能步骤。
