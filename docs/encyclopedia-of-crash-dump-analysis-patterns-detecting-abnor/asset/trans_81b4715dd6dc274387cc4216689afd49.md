## 活锁

通常，当两个线程在获取和释放资源时循环但没有进展时，我们会看到**活锁**模式。下面是选定 WinDbg 输出中的这些迹象：

- **高争用**模式（第 1168 页）或上下文切换计数
- 用户和 / 内核模式下 CPU 时间增加（**激增线程**，第 888 页）
- 至少有一个**活锁**线程被调度执行
- 一个**活锁**线程具有异常优先级提升
- 两个**活锁**线程的相同线程**堆栈跟踪**（第 926 页）具有类似统计信息，如花费时间和上下文切换计数
