## 无效句柄

### 一般

无效句柄异常 (0xC0000008) 在崩溃转储中经常出现。它是由于向 CloseHandle 函数和其他 Win32 API 传递了无效句柄值，或者在手动检查句柄或返回状态的有效性并通过 RaiseException 或内部通过 RtlRaiseStatus 引发相同异常时导致的（软件异常，第 875 页）。

例如，临界区是使用事件实现的，无效的事件句柄可能导致此异常：

