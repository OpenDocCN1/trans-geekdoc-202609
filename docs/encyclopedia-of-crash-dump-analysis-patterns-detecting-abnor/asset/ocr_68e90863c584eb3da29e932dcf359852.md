Sometimes we have threads that wait for a response from another machine (for example, via RPC). For most of the time, Coupled Processes pattern (page 149) covers that if we assume that processes in that pattern are not restricted to the same machine. However, sometimes we have threads that provide hints for dependency on another machine through their data, and that could also involve additional threads from different processes to accomplish the task. Here we need another pattern that we call Coupled Machines.
