## 消息框

崩溃转储中其他可疑的线程是执行消息框代码的 GUI 线程。通常，会显示消息框来显示某些错误，我们可以通过转储第二个和第三个 _MessageBox_ 参数来查看它：

```
int MessageBox(
  HWND hWnd,
  LPCTSTR lpText,
  LPCTSTR lpCaption,
  UINT uType);
```

有时候消息框会阻塞进程，如说明**耦合进程**模式（第 149 页）的示例所示。其他线程可能指向来自终端服务环境的内存转储中可能“挂起”的会话和进程。这是集体**阻塞线程**模式（第 82 页）的另一个示例。
