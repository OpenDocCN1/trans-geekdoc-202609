# Busy System

If there are no CPU-bound threads in a system, then most of the time processors are looping in the so-called idle thread where they are halted waiting for an interrupt to occur (HLT instruction11). When an interrupt occurs, they process a DPC list and then do thread scheduling if necessary as evident from the stack trace and its functions disassembly below. If we have a memory dump, one of running threads would be the one that called KeBugCheck(Ex) function.
