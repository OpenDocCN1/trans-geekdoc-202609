# Stowed

We do not write a special pattern for individual stowed exceptions (0xC000027B, an application-internal exception) because we consider them examples of Mixed Exceptions, page 688 (for example, as Managed Code Exceptions, page 617, enveloped by unmanaged code Software Exception, page 875, see stowed exception examples146). However, we introduce a variant of Multiple Exceptions analysis patterns for them because the default analysis WinDbg command (!analyze -v) only shows the first exception or error message stored in the array of stowed exception information structures.
