The cause of system PTE allocation failures might be the incorrect value of SystemPages registry key that needs to be adjusted as explained in the following TechNet article: The number of free page table entries is low, which can cause system instability116.

Another cause would be /3GB boot option on x86 systems especially used for hosting terminal sessions. This case is explained in the following blog post which also shows how to detect /3GB kernel and complete memory dumps: Consequences of running 3GB and PAE together117.

In our case, the system was booted with /3GB:
