# No Data Types

Sometimes we don’t have symbols (**No Component Symbols** pattern, page 734) or have only a restricted set. For example, in a base OS we have data types:

```
0:016> dt ntdll!*
ntdll!LIST_ENTRY64
ntdll!LIST_ENTRY32
ntdll!_KUSER_SHARED_DATA
ntdll!_KSYSTEM_TIME
ntdll!_KSYSTEM_TIME
ntdll!_NT_PRODUCT_TYPE
[...]
```
