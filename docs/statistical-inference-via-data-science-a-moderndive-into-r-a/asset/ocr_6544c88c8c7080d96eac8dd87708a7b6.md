# 10 Inference for Regression

This is an optimization problem and to solve it analytically requires calculus and the topic goes beyond the scope of this book. We provide a sketch of the solution here for those familiar with the method: using the expression above we find the partial derivative with respect to $eta_0$ and equate that expression to zero, the partial derivative with respect to $\beta_1$ and equate that expression to zero, and use those two equations to solve for $\hat{eta}_0$ and $\hat{eta}_1$. The solutions are the regression coefficients introduced in Section 5.1: $\hat{eta}_0$ is the estimator of $eta_0$ and $\hat{eta}_1$ is the estimator of $eta_1$. They are called the least squares estimators and their mathematical expressions are:

```
$b_1 = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} \quad b_0 = \bar{y} - b_1 \cdot \bar{x}.$
```

Furthermore, as *estimator* for the standard deviation of $\epsilon_i$ is given by

```
$s = \sqrt{\frac{\sum_{i=1}^n [y_i - (b_0 + b_1 \cdot x_i)]^2}{n-2}} = \sqrt{\frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{n-2}}
```

These equivalent calculations are done in R when using the lm() function. old_faithful_2024 we get:

```
# Fit regression model:
model_1 <- lm(waiting ~ duration, data = old_faithful_2024)

# Get the coefficients and standard deviation for the model
coef(model_1)
sigma(model_1)
```
