# 1.3.1 Package installation

> Note about RStudio Server or RStudio Cloud: If your instructor has provided you with a link and access to RStudio Server or RStudio Cloud, you might not need to install packages, as they might be preinstalled for you your instructor. Being said, it is still a good idea to know this process for later on when you are not using RStudio Server or Cloud, but rather RStudio Desktop on your computer.

There are two ways to install an R package: Let’s install the ggplot2 package the easy way first as shown in Figure 1.5. In the panes of RStudio:

+   a) Click on the “Packages” tab.
b) Click on “Install” next to Update.
c) Click the type of the package under “Packages (separate multiple with space or comma):” In this case, use ggplot2.
d) Click “Install.”
