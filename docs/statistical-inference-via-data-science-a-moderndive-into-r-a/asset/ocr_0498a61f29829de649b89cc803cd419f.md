standard deviation are given by $p_1$ and $\sigma_1 = \sqrt{p_1(1-p_1)}$ and for the almonds'

sqrt{p_2(1-p_2)}.

The expected value and standard error of the difference, $ar{X}_1 - ar{X}_2$, is given by $p_1 - p_2$
and

```
$$\sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}},$$

```
$$\bar{X}_1 - \bar{X}_2 \sim Normal \left(p_1 - p_2, \sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}}\right)$$$
