We do this, however, we review a linear regression with only one categorical explanatory variable. Recall in Subsection 5.2.2 we fit a regression model for each country life expectancy as a function of the corresponding continent. We produce the corresponding analysis here, now using the fertility rate as the response variable and the income group as the categorical explanatory variable. We'll use slightly different notation than what was done previously to make the model more general.

A linear model with a categorical explanatory variable is a one-factor model where factor refers to the categorical explanatory variable and the categories are also factor vectors. We represent the categories using indicator functions or dummy variables. In our UN data example, The variable has four categories or levels: Low income, Lower middle income, Upper middle income, and High income. The corresponding dummy variables are needed:

```
$D_1 = \begin{cases} 1 & \text{if the UN member state has low income} \ 0 & \text{otherwise} \end{cases}
nD_2 = \begin{cases} 1 & \text{if the UN member state has lower middle income} \ 0 & \text{otherwise} \end{cases}
D_3 = \begin{cases} 1 & \text{if the UN member state has high middle income} \ 0 & \text{otherwise} \end{cases}
D_4 = \begin{cases} 1 & \text{if the UN member state has high income} \ 0 & \text{otherwise} \end{cases}$
```

So, for example, if a UN member state has *Low income*, its dummy variables are $D_1 = 1$ and $D_2 = D_3 = D_4 = 0$. Similarly, if another UN member state has *high middle income*, then its dummy variables would be $D_1 = D_2 = D_4 = 0$ and $D_3 = 1$. Using dummy variables, the mathematical formulation of the linear regression for our example is:

```
$\hat{y} = \text{fert rate} = b_0 + b_2D_2 + b_3D_3 + b_4D_4$
```

or if we want to express it in terms of the ith observation in our dataset, we can include the ith subscript:

```
$\hat{y}_i = \text{fert rate} = b_0 + b_2D_{2i} + b_3D_{3i} + b_4D_{4i}$
```

Recall that the coefficient $b_0$ represents the intercept and the coefficients offset the appropriate category. The dummy variables, $D_2, D_3$, and $D_4$ take the values of zero or one depending on the corresponding category of any given country. Also observe that $D_1$ does not appear in the model. The reason for this is entirely mathematical: if the model would contain an intercept and all the dummy variables, the model would be over-specified, it would contain one redundant explanatory variable. The solution is to drop one of the variables.
