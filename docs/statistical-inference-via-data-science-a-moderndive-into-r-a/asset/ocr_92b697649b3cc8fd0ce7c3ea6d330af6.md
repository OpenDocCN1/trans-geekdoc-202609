Typing out these summary statistic functions in summarize() would be long and tedious. Instead, we use the convenient tidy_summary() function from the modelndrive package.

This function takes a data frame, summarizes it, and returns commonly used summary statistics in tidy format. We take our UN_data_ch5 data frame, select() only the outcome and exploratory variables fert_rate and life_exp, and pipe them into the tidy_summary function:

```
UN_data_ch5 |>
select(fert_rate, life_exp) |>
tidy_summary()
```

| column | group type | min | Q1 | mean | median | Q3 | max | sd |
|---|---|---|---|---|---|---|---|---||
| fert_rate | 181 | numeric | 1.1 | 1.6 | 2.5 | 2.0 | 3.2 | 6.6 | 1.15 |
| life_exp | 181 | numeric | 53.6 | 69.4 | 73.6 | 75.1 | 78.3 | 86.4 | 6.80 |

We can also do this directly by providing which columns we'd like a summary of inside the tidy_summary() function:

```
UN_data_ch5 |>
tidy_summary(columns = c(fert_rate, life_exp))
```

| column | group type | min | Q1 | mean | median | Q3 | max | sd |
|---|---|---|---|---|---|---|---|---||
| fert_rate | 181 | numeric | 1.1 | 1.6 | 2.5 | 2.0 | 3.2 | 6.6 | 1.15 |
| life_exp | 181 | numeric | 53.6 | 69.4 | 73.6 | 75.1 | 78.3 | 86.4 | 6.80 |

Both return the same results for the numerical variables fert_rate and life_exp:

+   * column: the name of the column being summarized
