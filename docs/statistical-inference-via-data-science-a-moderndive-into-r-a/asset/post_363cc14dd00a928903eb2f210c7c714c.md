### 11.2.2 Exploratory data analysis: Part II

Let's continue our EDA by creating multivariate visualizations. Unlike the univariate histograms and barplot in the earlier Figures 11.3, 11.4, and 11.5, multivariate visualizations show relationships between more than one variable. This is an important step of an EDA to perform since the goal of modeling is to explore relationships between variables.

Since our model involves a numerical outcome, and a categorical explanatory variable, we are in a similar regression modeling situation as in Section 6.1 where we studied the UN members dataset. Recall in that case the numerical outcome was fertility, the numerical explanatory variable was life expectancy, and the categorical explanatory variable was income group.

We have two choices of models we can fit: either (1) an interaction model where the regression line for each condition level will have a different slope and a different intercept or (2) a parallel slopes model where the regression line for each condition level have same slope but different intercepts.

Recall from Subsection 6.1.3 that the geom_parallel_slopes() function is a special purpose function that Eugeni Chvasnovki created and included in the modderive package, since the geom\_smooth() method in the ggplot2 package does not have a convenient way to plot parallel slopes. We plotted resulting models in Figure 11.6, with the interaction model on the left.

```r
# Plot interaction model
ggplot(house_prices, aes(x = log10_size, y = log10_price, col = condition)) +
  geom_point(alpha = 0.05) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(y = "log10 price", x = "log10 size", title = "House prices in Seattle")

# Plot parallel slopes model
ggplot(house_prices, aes(x = log10_size, y = log10_price, col = condition)) +
  geom_point(alpha = 0.05) +
  geom_parallel_slopes(se = FALSE) +
  labs(y = "log10 price", x = "log10 size", title = "House prices in Seattle")
```

In both cases, we see there positive relationship between house price and size, meaning as houses are larger in size, they tend to be more expensive. Furthermore, in ![](img/445742518041017e8f0f11b0c3190d9_470_0.png) **FIGURE 11.6:** Interaction and parallel slopes models. both plots seems that houses of condition 5 tend to be the most expensive for house sizes as evidenced by the fact that the line for condition 5 is highest, followed by conditions 4 and 3. As conditions 1 and 2, this pattern’t as clear. Recall from the univariate barplot in Figure 11.3, there are only a few houses of condition 1 or 2. Let's also show a faceted version of the interaction model in Figure 11.7. It is much more apparent how few houses are condition 1 or 2.

Which exploratory visualization of the interaction model is better, the one in the left-hand plot of Figure 11.6 or the faceted version in Figure 11.7? There is no universal answer. You need to make a choice depending on what you want to convey, and discussing both as an option. Which of the two models in Figure 11.6 is “better”? The interaction model in the left-hand plot or the parallel slopes model in the right-hand plot? With model selection, we should favor more complex models if the additional complexity is warranted. In this case, the more complex model is the interaction model since it considers five intercepts and five slopes total. This is in contrast to the parallel slopes model which considers five intercepts but only one common slope.

The additional complexity of the interaction model warranted? Looking at the left-hand plot in Figure 11.6, we're of the opinion that it is, as evidenced by the slight crossing pattern to some of the lines. Therefore, we will focus on the rest of this analysis only on the interaction model. This visual approach is somewhat subjective, however feel free to disagree! What are the different slopes and different intercepts for the interaction model? We can get these values from the regression table. Our two-step process for getting the regression table:
