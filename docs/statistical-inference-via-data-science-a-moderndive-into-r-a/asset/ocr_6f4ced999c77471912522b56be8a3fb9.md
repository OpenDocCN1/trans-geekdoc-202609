# 9 Hypothesis Testing

# 2. hypothesize the null

We set the null hypothesis $H_0: \mu_a - \mu_r = 0$ using the hypothesis() function. Since we have two samples, action and romance movies, we set null to "independence" as we described in Section 9.4.

```
movies_sample | |
specify(formula = rating ~ genre) |nhypothesize(null = "independence")
```

Response: rating (numeric)

# 3. generate replicates

After we set the null hypothesis, we generate "shuffled" replicates assuming the null hypothesis is true by repeating the shuffling/permutation exercise you performed in Section 9.2.

We will repeat this resampling without replacement of type = "permute" a total of reps = 1000 times. Feel free to run the code below to check out what the generate() produces.

```
movies_sample | |
specify(formula = rating ~ genre) |nhypothesize(null = "independence") |
generate(reps = 1000, type = "permute") | |
View()
```
