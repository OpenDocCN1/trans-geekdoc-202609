
# $\tilde{y} = b_0 + b_{02}D_2 + b_{03}D_3 + b_{04}D_4 + b_1x.$

Observe that the dummy variables only affect the intercept now, and the slope is fully described by $b_1$ for any income group. In the UN data, a *high income* country, with $D_4 = 1$ and the other dummy variables equal to zero, will be represented by

$\tilde{y} = (b_0 + b_{04}) + b_1x.$

To find the coefficients for regression in R, the formula used $y \sim x1 + x2$ where $x1$ and $x2$ are the variable names in the dataset and represent the main effects. Observe that the term $x1:x2$ representing the interaction is no longer included. R would limit both $x1$ and $x2$ to be either explanatory or numerical; therefore, we should always check that the variable format is appropriate for the regression we want to run. Here is the code for the UN example data:

```
# Fit regression model:
model_int <- lm(fert_rate ~ life_exp + income, data = UN_data_ch6)

# Get the coefficients of the model
```

## 6.2 Two numerical variables

We now consider a model with two numerical explanatory variables. This allows us to explore whether the effect of one variable depends on the level of another, which is the definition of an interaction.

$y = b_0 + b_1x_1 + b_2x_2 + b_3x_1x_2$

In this model, $b_1$ is the effect of $x_1$ when $x_2$ is zero, and $b_2$ is the effect of $x_2$ when $x_1$ is zero. The term $b_3$ represents the interaction effect.

We load the data and create a new data frame credit_ch.

```r
library(tidyverse)
```

We can visualize the relationship between Balance and R using:

```r
ggplot(credit_ch, aes(x = Balance, y = R)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm")
```

The relationship appears linear, but there is some scatter. Let's look at the relationship between Age and R:

```r
ggplot(credit_ch, aes(x = Age, y = R)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm")
```

Again, the relationship appears linear. Now let's check for interaction between Balance and Age:

```r
ggplot(credit_ch, aes(x = Balance, y = R, color = factor(Age))) +
  geom_point(alpha = 0.5)
  geom_smooth(method = "lm")
```

The slopes differ for different ages, suggesting an interaction between Age and Balance. Let's fit an interaction model:

```r
model_int <- lm(R ~ Balance * Age, data = credit_ch)
coef(model_int)
```

The interaction term `Balance:Age` is negative and statistically significant. Let's check the residuals:

```r
plot(model_int)
```

The residuals show some evidence of heteroscedasticity, as the variance increases with Balance. We can try a log transformation of Balance:

```r
model_log <- lm(R ~ log(Balance) * Age, data = credit_ch)
plot(model_log)
```

The residuals now look better. We'll use the final model:

```r
summary(model_log)
```
