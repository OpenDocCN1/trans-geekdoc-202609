In Figure 10.6 we show the residual plot (right plot) alongside the scatterplot for duration waiting (left plot). Note how the residuals on the left plot are determined by the vertical distance between the observed response and the linear regression. On the right plot (residuals), we have removed the effect of the linear regression and the effect of the residuals is seen as the distance from each point to the zero line (y-axis). Using these residuals plot, it is easier to spot patterns or trends that may be in conflict with the assumptions of the model, as we describe below.

In what follows we show how the residual plot can be used to determine whether the linear model assumptions are met.

Linearity of relationship

We want to check the association between the response $y_i$ and the explanatory variable $x_i$ is linear. We expect, due to the error term in the model, that the scatterplot of residuals against fitted values shows some random variation, but the variation should not be systematic in any direction and the trend should not show non-linear patterns.

A scatterplot of residuals against fitted values showing no patterns but simply a cloud of points that seems randomly assigned in every direction with the residuals' variation (y-axis) as much for any fitted values (x-axis) and points located as much above as below the zero line is called a *null plot*. Plots of residuals against fitted values or regressors are *null plots* do not show any evidence against the assumptions of the model. In other words, if we want our linear model to be adequate, we hope to see *null* points when plotting residuals against fitted values.

This is largely for the Old Faithful geyser with the residuals against the fitted values (waiting,hat) shown in the right-plot of Figure 10.6. The residual plot is not a *null* plot as it appears there are clusters of points as opposed to a complete random assignment, but there are not clear systematic trends in any direction or the appearance of a non-linear relationship. So, based on this plot, we believe that the data does not violate the assumption of linearity.
