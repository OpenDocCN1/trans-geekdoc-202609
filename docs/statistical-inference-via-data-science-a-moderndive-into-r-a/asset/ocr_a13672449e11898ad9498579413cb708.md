# 2. glimpse():

The second way we'll cover is to explore a data frame is using the glimpse() function included in the dplyr package. Thus, you can use only the glimpse() function after you've loaded the dplyr package by running library(dplyr). This function provides us with an alternative perspective for exploring a data frame than the view():

```
glimpse(flights)

```
