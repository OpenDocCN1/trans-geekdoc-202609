Observe in the viewer that the first 50 rows of replicate are equal to 1, the next 50 rows of replicate are equal to 2, and so on. The first 50 rows correspond to the first sample of 50 balls while the next 50 rows correspond to the second sample of 50 balls. This pattern continues for all reps = 33 replicates, and thus virtual_samples has 33 · 50 = 1650 rows.

Using virtual_samples we find the proportion of red balls for each replicate. We use the dplyr verbs as before. In particular, we add group_by() of the replicate variable. Recall from Section 3.4 that by assigning the grouping variable "meta-data" before summarize(), we perform the calculations needed for each replicate separately. The other line of code, as explained in the case of one sample, calculates the sample proportion of red balls. A preview of the first 10 rows is presented below:

```
virtual_prop_red <- virtual_samples |>
group_by(replicate) |>
sumize(prop_red = mean(color == "red"))
```
