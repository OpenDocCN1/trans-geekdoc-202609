# 8 Estimation, Confidence Intervals, and Bootstrapping

The total number of almonds in the bowl is 5,000. The population mean is

```
$$\mu = \sum_{i=1}^{5000} x_i = 3.645,$
```

and the population standard deviation, pop_sd(), from moderndev, is defined as

```
$$\sigma = \sqrt{\frac{\sum_{i=1}^{5000}(x_i - \mu)^2}{5000}} = 0.392.$
```

We keep those numbers for future reference to determine how well our methods of estimation are doing, recall that in real-life situations we do not have access to the population values and the population mean \mu is unknown. All we have the information from one random sample. In our example, we assume that all we know the almonds_sample_100 object stored in moderndev. Its ID variable shows the almond count from the bowl and its corresponding weight. Using this sample we calculate some statistics:

```
almonds_sample_100 |>
summarize(mean_weight = mean(weight),
sd_weight = sd(weight),
sample_size = n())
```

```
# A tibble: 1 x4
replicate mean_weight sd_weight sample_size
<int> <dbl <dbl <int>
1 1 3.682 0.362199 100
```
