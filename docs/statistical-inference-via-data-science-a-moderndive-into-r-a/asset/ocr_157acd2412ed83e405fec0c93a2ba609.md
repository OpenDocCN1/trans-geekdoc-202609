# 2.8 SNG#5: Barplots

Compare the barplots in Figures 2.19 and 2.20. They are identical because they reflect counts of the same few fruits. However, depending on how our categorical data is represented, either "pre-counted" or not, we must use a different geom layer. When the categorical variable whose distribution you want to visualize

+   - Is not pre-counted in your data frame, we use geom_bar().
- Is pre-counted in your data frame, we use geom_col() with the y-position aesthetic mapped to the variable that has the counts.

Let's now go back to the flights data frame in the nycflights3 package and visualize the distribution of the categorical variable carrier. In other words, we visualize the number of domestic flights out of New York City each airline company flew in 2023. From Subsection 1.4.3 we first explored the flights data frame, where each row corresponds to a flight. In other words, the flights data frame is more like the fruits_counted data data frame because the flights have not been pre-counted by carrier. Then we should use geom_bar() instead of geom_col() to create a barplot. Much like a geom_histogram(), there is only one variable in the aes() aesthetic mapping: the variable carrier bars that touches bar graphs have white space between the bars going from left to right.

```
ggplot(data = flights, mapping = aes(x = carrier)) + 
ge geom_bar())
```

Alternatively, say you had a data frame where the number of flights for each carrier was pre-counted as in Table 2.3.

In order to create a barplot visualizing the distribution of the categorical variable carrier in this case, we would now use geom_col() instead of geom_bar(), with an additional y = number in the aesthetic mapping on top of the x = carrier. The resulting barplot would be identical to Figure 2.21.
