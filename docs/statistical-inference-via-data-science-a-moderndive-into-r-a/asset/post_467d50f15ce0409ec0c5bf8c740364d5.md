## Introduction for students

This book assumes no prerequisites: no algebra, no calculus, and no prior programming/coding experience. This is intended to be a gentle introduction to the practice of analyzing data and answering questions using data the way data scientists, statisticians, data journalists, and other researchers would.

You'll get started with data in Chapter 1 where you'll learn about the difference between R and RStudio, start coding in R, install and load your first R packages, and explore your first dataset: atomic departure flights from a New City airport in 2023. You'll cover the following three portions of this book (Parts 2 and 4 are combined into a single portion):

- 1. Data science with tidyverse. You'll assemble your data science toolbox using tidyverse packages. In particular, you'll
    - Chapter 2: Visualize data using the ggplot2 package.
    - Chapter 3: Wrangle data using the dplyr package.
    - Chapter 4: Learn about the concept of “tidy” as a standardized data input and output format for all packages in the tidyverse. Furthermore, you'll learn how to import spreadsheet files into R using the readr package.
- 2. Statistical/data modeling with moderndive. Using these data science tools and helper functions from the moderndive package, you'll fit your first data models. In particular, you'll:
    - Chapter 5: Discover basic regression models with only one explanatory variable.
    - Chapter 6: Examine multiple regression models with more than explanatory variable.
- 3. Statistical inference with infer. Once again using your newly acquired data science tools, you'll unpack statistical inference using the infer package. In particular, you:
    - Chapter 7: Learn about the role that sampling variability plays in statistical inference and the role that sample size plays in this sampling variability.
    - Chapter 8: Construct confidence intervals using bootstrapping.
    - Chapter 9: Conduct hypothesis tests using permutation.
- 4. Statistical/data modeling moderndive (revisited): Armed with your understanding of statistical inference, you'll revisit and review the models you've constructed in Ch.5 and Ch.6. In particular, you:
    - Chapter 10: Interpret confidence intervals and hypothesis tests in a regression setting.

We will end with a discussion on what it means to “tell your story with data” in Chapter 11 by presenting example studies.3.

## What we hope you will learn from this book

We hope by the end of this book, you'll have learned how to:

1. Use R and the tidyverse suite of R packages for data science.
2. Fit your models to data, using a method known as linear regression.
3. Perform statistical inference using sampling, confidence intervals, and hypothesis tests.
4. Tell your story with data using these tools.

What do we mean by data stories? We mean any analysis involving data with careful visuals and thoughtful discussion. Further discussions on data stories can be found in the blog post “Tell a Meaning Story With Data.”4

Over the course of this book, you will develop your “data science toolbox,” equipping yourself with tools such as data visualization, data formatting, data wrangling, and statistical/data modeling using regression.

## Data/science pipeline

You might think of statistics as just being a bunch of numbers. We commonly hear the phrase “statistician” when listening to broadcasts of sports events. Statistics (in particular, data analysis), in addition to describing numbers like those used with baseball averages, plays a vital role in all the scenes.

You'll commonly hear the phrase “statistically significant” thrown around in the media. You'll see articles that say “Science now shows chocolate is good for you.” Underning these claims is data analysis. By the end, you'll be able to better understand whether these claims should be trusted or whether we should be wary. Inside data analysis are many sub-fields we will discuss throughout this book (though not necessarily in this order):

- data collection
- data wrangling
- data visualization
- statistical modeling
- inference
- correlation and regression
- data communication/storytelling

We will begin by digging into the Understand portion of the cycle with data visualization, then with a discussion on what is meant by tidy data and data wrangling, and then conclude by talking about interpreting and discussing the results of our models via Communication. These steps are vital to any statistical analysis. But, why should you care about statistics?
