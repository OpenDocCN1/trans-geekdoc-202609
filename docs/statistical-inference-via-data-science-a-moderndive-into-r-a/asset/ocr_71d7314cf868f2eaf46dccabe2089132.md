# 8.2 Estimation with the bootstrap

Observe Figure 8.12 that while the general shapes of both distributions are roughly similar, they are not identical. This is the typical behavior of bootstrap samples. They are samples that have been determined from the original sample, but because replacement is used before each observation is attained, some values often appear more than once while others do not appear at all.

# Many bootstrap samples: resampling multiple times

In this section, we take full advantage of resampling with replacement by taking many bootstrap samples and relevant information, such as the variability of their sample means. We can start by using the R syntax we used before, this time for 35 replications.

```
bootstrap_samples_35 <- almonds_sample_100 |>
rep_sample_n(size = 100, replace = TRUE, reps = 35)
bootstrap_samples_35
```

The syntax is the same as before, but this time we set reps = 35 to get bootstrap samples. The resulting data frame, bootstrap_samples, has 35 · 100 = 3500 rows corresponding to 35 resamples of 100 almonds' weights. Let's now compute the resulting 35 sample means using the same dplyr code as we did in the previous section:

```
boot_means <- bootstrap_samples_35 |>
sumize(mean_weight = mean(weight))
```
