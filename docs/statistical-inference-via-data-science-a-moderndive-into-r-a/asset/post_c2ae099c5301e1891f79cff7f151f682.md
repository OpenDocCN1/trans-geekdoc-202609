### 1.4.3 Exploring data frames

There are many ways to get a feel for the data contained in a data frame such as flights. We present three functions that take as “argument” (their input) a data frame and a fourth method for exploring one column of a data frame:

- Using the view() function, which brings up RStudio's built-in data viewer.
- Using the glimpse() function, which is included in the dplyr package.
- Using the relationship() function, which is included in the knitr package.
- Using the $ extraction operator, which is used to view a single variable.

#### View():

Run View(flights) in your console in RStudio, either by typing it or cutting-and-pasting it into the console pane. Explore this data frame in the resulting pop up viewer. Get used to the habit of viewing any data frames you encounter. Note the uppercase v in View(). R is case-sensitive, so you'll get an error message if you run view(flights) instead of View(flights).

By running View(flights), we can explore the different variables listed in the columns. Observe that there are many different types of variables. Some of the variables distance, day, and arr_delay are what we will call quantitative variables. These variables are numerical in nature. Other variables are categorical.

If you look at the leftmost column of the View(flights) output, you'll see a column of numbers. These are the row numbers of the dataset. Glancing across a row with the same number, say row 5, you can get an idea of what each row represents. This allows you to identify what object is being described in a given row by taking note of values of the columns in that specific row. This is often called the observational unit. The observational unit in this example is an individual departing from New York City in 2023. You can identify the observational unit by determining what “thing” is measured by each of variables. We'll tell more about observational units.

Observe glimpse() will give you the first few entries of each variable row after the variable name. In addition, the data type (see Subsection 1.2.1) of the variable is given immediately after each variable's name <>. Here, “integer” and “double”, which are computing terminology for numerical values. “Double” take up twice the size to store on a computer compared to integers.

In contrast, chr refers to “character,” which is computer terminology for text data. In most forms, text data, such as the carrier or origin of a flight, are categorical variables. The time_hour variable is another data type dttm. These types of variables represent date and time combinations. However, we may not work with dates and times in this book; we will leave this topic for other data science books like Data Science: A First Introduction by Tiffany-Anne Timbers, Melissa Lee, and Trevor Campbell.

#### 3. kable():

The final way to explore the entirety of a data frame is using the kable() function from the knitr package. Let's explore the different carrier codes for all the airlines in our dataset two ways. Run both of these lines of code in the console:

```
airlines
kable(airlines)
```

At first glance, it may not appear that there is much difference in the outputs. However, when using tools for producing reproducible reports as R Markdown, the latter code produces output that is much more legible and reader-friendly. You'll see us this reader-friendly style in many places in the book when we want to print a data frame as a nice table.

#### 4. $ operator

Lastly, the $ operator allows us to extract and explore a single variable within a data frame. For example, run the following in your console:

```
airlines$name
```

We used the $ operator to extract only the name variable and return it as a vector of length 16. We'll only be exploring data frames using the $ operator, instead favoring the view() and glimpse() functions.
