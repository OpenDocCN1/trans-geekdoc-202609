## 8.4 Case study: is yawning contagious?

First, let's compute the 95% confidence interval for $P_{seed}-P_{control}$ using the percentile method, in other words, by identifying the 2.5th and 97.5th percentiles which include the middle 95% of values. Recall that this method does not require the bootstrap distribution to be normally shaped.

```r
bootstrap_distribution_yawning |>
get_confidence_interval(type = "percentile", level = 0.95)
```

Second, since the bootstrap distribution is roughly bell-shaped, we can construct a confidence interval using the standard error method as well. Recall that to construct a confidence interval using the standard error method, we need to specify the center of the interval using the point_estimate argument. In our case, we need to set it to be the difference in sample proportions of 4.4% that the Mythbusters observed.

We can also use the entire workflow to compute this value by excluding the generate1000 bootstrap replicates step. In other words, do not generate replicates, but use only the original sample data. We can achieve this by commenting out the line, telling R to ignore it:


### 8.4.4 Interpreting the confidence interval

Given that both confidence intervals are quite similar, let's focus our interpretation to only the percentile method confidence interval of (-0.238, 0.302). The precise statistical interpretation of a 95% confidence interval is: if this construction procedure is repeated 100 times, then we expect about 95 of the confidence intervals to capture

## 8.5 Summary and final remarks

the true value of $p_{seed}-p_{control}$. In other words, if we gathered 100 samples of $n = 50$ participants from a similar pool of people and constructed 100 confidence intervals each based on each of the 100 samples, about 95 of them will contain the true value of $p_{seed}-p_{control}$ while not given. Given that this is a little winded, we use the shorthand interpretation: we are 95% “confident” that the true difference in proportions $p_{seed}-p_{control}$ is between (-0.238, 0.302).

There is one value of particular interest that this 95% confidence interval contains: zero. If $p_{seed}-p_{control}$ were equal to 0, then there would be no difference in proportion yawning between the two. This would suggest that there is no associated effect of being exposed to a yawning recruiter on whether you yawn yourself.

In our case, since the 95% confidence interval includes 0, we cannot conclusively say either proportion is larger. Of our 1000 bootstrap replicates, about 95% would contain the true value of $p_{seed}-p_{control}$.
