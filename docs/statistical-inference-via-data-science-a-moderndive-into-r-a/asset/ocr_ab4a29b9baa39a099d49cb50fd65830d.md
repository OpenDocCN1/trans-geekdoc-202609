# 10.5 Theory-based inference for multiple linear regression

In this section, we introduce some of the conceptual framework needed to understand inference in multiple linear regression. We illustrate this framework using the coffee example and the R function get_regression_table() introduced in Subsection 10.2.5.

Inference for multiple linear regression is a natural extension of inference for simple linear regression. Recall that the i-th observation is given by

> $y_i = eta_0 + eta_1 \cdot x_{i1} + \cdots + \beta_p x_{ip} + \epsilon_i.$

We assume again that the error term is normally distributed with an expected value (mean) equal to zero and a standard deviation equal to $\sigma$:

> $\epsilon_i \sim \text{Normal}(0, \sigma).$

Since the error term is the only random element in the linear model, the response $y_i$ results from a constant

> $\beta_0 + \beta_1 \cdot x_{i1} + \cdots + \beta_p x_{ip}$

and a random variable: the error term $\epsilon_i$. Using properties of the normal distribution, the expected value, and the variance (and standard deviation), it can be shown that $y_i$ is also normally distributed with mean equal to $eta_0 + \beta_1 \cdot x_{i1} + \cdots + \beta_p x_{ip}$ and standard deviation equal to $\sigma$:

> $y_i \sim \text{Normal}(\beta_0 + \beta_1 \cdot x_{i1} + \cdots + \beta_p x_{ip}, \sigma)$
