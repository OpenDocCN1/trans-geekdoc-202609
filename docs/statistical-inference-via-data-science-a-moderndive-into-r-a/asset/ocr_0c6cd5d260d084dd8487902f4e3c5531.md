Now let’s unpack the resulting histogram in Figure 2.10. Observe that values above 30 mph are rather rare. However, because of the large number of bins, it’s hard to get a sense for which range of wind speeds is spanned by each bin; everything is one giant amorphous blob. Let’s add white vertical borders demarcating the bins by adding a color = "white" argument to geom_histogram() and ignore the warning about setting the number of bins to a better value:

```
ggplot(data = weather, mapping = aes(x = wind_speed)) +
geom_histogram(color = "white")
```

**FIGURE 2.11:** Histogram of hourly wind speeds at three NYC airports with borders.

We now have an easier time associating ranges of wind speeds to each of the bins in Figure 2.11. We can also vary the color of the bars by setting the fill argument. For example, we can set the bin colors to "blue steel" by setting fill = "steelblue":

```
ggplot(data = weather, mapping = aes(x = wind_speed)) +
geom_histogram(color = "white", fill = "steelblue")
```
