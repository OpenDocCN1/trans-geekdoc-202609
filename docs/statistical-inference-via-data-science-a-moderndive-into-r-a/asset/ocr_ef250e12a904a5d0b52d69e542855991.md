# # Connect and contribute

If you would like to connect with ModernDive, check out the following links:

+   * To receive periodic updates on ModernDive (roughly every 6 months), please sign up for our mailing list^{13}.\n* To find us on social media, we're on X (formerly Twitter) at https://x.com/ModernRnDive.

If you would like to contribute to ModernDive, there are many ways! We would love your help and feedback to make this book as great as possible! For example, if you find any errors, typos, or areas for improvement, please post an issue on your GitHub issues^{14}. If you are familiar with GitHub and would like to contribute, see the “About this book” section.
