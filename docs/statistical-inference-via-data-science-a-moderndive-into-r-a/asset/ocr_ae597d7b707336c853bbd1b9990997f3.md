# Hypothesis tests for the partial slopes

We can now conduct hypothesis tests for the partial slopes in multiple linear regression. We can use the permutation test to test the null hypothesis $H_0 : \beta_i = 0$ versus the alternative hypothesis $H_A : \beta_i 
eq 0$ for each of the partial slopes. Let's use a significance level of $\alpha = 0.05$. We can visualize the $p$-values in the distribution by comparing them to the observed test statistics. We do this by adding a shade_p_value()

```
visualize(null_distribution_mlr) +
shade_p_value(obs_stat = observed_fit, direction="two-sided")
```
