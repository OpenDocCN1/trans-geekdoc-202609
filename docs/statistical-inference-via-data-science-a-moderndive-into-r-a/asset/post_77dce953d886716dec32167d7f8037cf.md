```
$life \exp = b_0 + b_{Asia} \cdot \mathbb{1}_{Asia}(x) + b_{Europe} \cdot \mathbb{1}_{Europe}(x)
+ b_{North America} \cdot \mathbb{1}_{North America}(x) + b_{Oceania} \cdot \mathbb{1}_{Oceania}(x)
+ b_{South America} \cdot \mathbb{1}_{South America}(x)
= 66.31 + 8.64 \cdot \mathbb{1}_{Asia}(x) + 13.6 \cdot \mathbb{1}_{Europe}(x)
+ 9.98 \cdot \mathbb{1}_{North America}(x) + 8.11 \cdot \mathbb{1}_{Oceania}(x)
+ 8.92 \cdot \mathbb{1}_{South America}(x)
= 66.31 + 8.64 \cdot 13.6 + 9.98 \cdot 0.81 \cdot 0.81 \cdot 8.92
= 66.31 + 8.64
= 74.95$
```

which is the mean life expectancy for countries in Asia of 74.9 years in Table 5.7. Note the "offset from the baseline for comparison" is +8.6 years.

do one more. We are considering a country in South America. In this case, the only indicator $\mathbb{1}_{South America}(x)$ for South America will be one, while the others will be zero, and thus:

```
$life \exp = b_0 + b_{Asia} \cdot \mathbb{1}_{Asia}(x) + b_{Europe} \cdot \mathbb{1}_{Europe}(x)
+ b_{North America} \cdot \mathbb{1}_{North America}(x) + b_{Oceania} \cdot \mathbb{1}_{Oceania}(x)
+ b_{South America} \cdot \mathbb{1}_{South America}(x)
= 66.31 + 8.64 \cdot \mathbb{1}_{Asia}(x) + 13.6 \cdot \mathbb{1}_{Europe}(x)
+ 9.98 \cdot \mathbb{1}_{North America}(x) + 8.11 \cdot \mathbb{1}_{Oceania}(x) + 8.92 \cdot \mathbb{1}_{South America}(x)
= 66.31 + 8.64 \cdot 0 + 13.6 \cdot 0 + 9.98 \cdot 0 + 8.92 \cdot 1
= 66.31 + 8.92
= 75.23$
```

which is the mean life expectancy for South American countries of 75.23 years in Table 5.7. The "offset from the baseline for comparison" is +8.9 years.

We generalize this idea. If we fit a regression model using a categorical explanatory variable $x$ with $k$ possible countries, the regression will return an intercept and $k-1$ "offsets." In our case, since there are $k=6$ continents, the regression model returns an intercept corresponding to the baseline for comparison group of Africa and $k-1=5$ offsets corresponding to Asia, Europe, North America, Oceania, and South America.

Understanding a regression table output when you are using a categorical explanatory variable is a topic new to regression many often struggle with. The real remedy for these struggles is practice, practice, practice. However, once you become familiar with how to use regression models using categorical explanatory variables, you'll be able to incorporate many new variables into your models, given the large amount of world's data that is categorical.

### 5.2.3 Observed/fitted values and residuals

Recall in Subsection 5.1.3, we defined the following three concepts:

1. Observed values $y$, or the observed value of the outcome variable
2. Fitted values $\hat{y}$, or the value on the regression line for a given $x$ value
3. Residuals $y - \hat{y}$, or the error between the observed value and the fitted value

We obtained these values and other values using the `get_regression_points()` function from the `modndrive` package. This time, however, we add an argument ID = "country": this is telling the function to use the variable country in gapminder(2022) as an `identification variable` in the output. This will help contextualize our analysis matching values to countries.

```r
regression_points <- get_regression_points(life_exp_model, ID = "country")

```

## 5.3 Topics

### 5.3.1 Correlation is not necessarily causation

Throughout this chapter we have been cautious when interpreting regression coefficients. We always discussed the "associated" effect of an explanatory variable on an outcome variable y. For example, our statement from Subsection 5.1.2 "for every increase of 1 unit in life_exp, there is an associated decrease of 0.137 units of fert_rate." We include the "associated" to be extra careful not to suggest that we are making a causal statement. While life_exp is negatively correlated with fert_rate, we can’t necessarily make any statements about causal effect without more information.

Here is another example: a not-so-great medical doctor goes through medical records and finds that patients who slept with their shoes on tended to wake up more with headaches. So this doctor declares, "Sleeping with shoes causes headaches!"

However, there is a good chance that if someone is sleeping with their shoes on, it is potentially because they are intoxicated by alcohol. Furthermore, higher levels of drinking leads to more hangovers, and more headaches. The amount of alcohol consumption here is what’s known as a confounding variable variable. It "lurks" behind the scenes, confounding the causal relationship (if any) of "sleeping with shoes on" with "waking up with a headache."
