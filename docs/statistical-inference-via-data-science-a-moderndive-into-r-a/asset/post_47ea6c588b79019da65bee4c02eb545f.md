For ease of exposition we refer to each chocolate-covered almond simply as an almond. We are now interested in the average weight in grams of all the almonds in the bowl; this is the population average weight or population mean weight.

### 7.4.1 The population mean weight of almonds in the bowl

The population of interest is given by all the almonds in the bowl. The bowl is represented virtually by the data frame `almonds_bowl` included in the modernrive package. The first ten rows are shown here for illustration purposes:

```
almonds_tibble: 5,000 x 2
ID weight

3 3 3.2
4 4 3.1
5 5 4.1

10 10 3.4
# i 4,990 more rows
```

The first variable `ID` represents a virtual ID number given to each almond, and the variable `weight` contains the weight in grams for each almond in the bowl. The population mean weight of almonds, a parameter can be calculated in R using again the dplyr wrangling verbs presented in Chapter 3. In particular, inside the function `summarize()` the use of the `mean()`, `sd()`, and `n()` functions for the mean weight, the weight's standard deviation, and the number of almonds in the bowl:

```r
almonds_bowl |>
  summarize(mean_weight = mean(weight),
         sd_weight = sd(weight),
         length = n())
```

```
# A tibble: 1 x 3
mean_weight sd_weight <dbl> <int>
1 3.64 0.392 5000
```

We have 5000 almonds, the population mean weight is 3.64 grams, and the weight's standard deviation is 0.392 grams. We used R to compute the mean and standard deviation, but we could have used the formulas instead. If we call $x_1$ the first almond in the bowl, $x_2$ the second, and so on is given by

$$\mu = \sum_{i=1}^{5000} x_i = 3.64.$$

and the standard deviation is given by

$$\sigma = \sqrt_{i=1}^{5000} \frac{(x_i - \mu)^2}{5000} = 0.392.$$

The Greek letters $\mu$ and $\sigma$ are used to represent the population mean and population standard deviation (parameters of interest). In addition, since we know the information of the entire bowl, we can draw the distribution of weights of the entire population (bowl) using a histogram:

```r
ggplot(almonds_bowl, aes(x = weight)) +
  geom_histogram(binwidth = 0.1, color = "white")
```

> As explained earlier, this function produces the sample standard deviation, which divides the sum of square deviations by $n-1$ instead of $n$, but for a list of 5000 observations the difference is not relevant, for practical purposes.

### 7.4.2 Manual sampling and sample means

If we randomly select one almond from the bowl, we could determine its weight using a scale, as shown in Figure 7.20:

![](img/445742518041017e8f01f11b0c3190d9_253_1.png)

FIGURE 7.20: One almond on a scale.

Let's now take a random sample of 25 almonds, as shown in Figure 7.21, and determine the sample average weight, or sample mean weight, in grams.

![](img/445742518041017e8f01f11b0c3190d9_254_0.png)

FIGURE 7.21: A random sample of 25 almonds on a scale.

Since the total weight is 88.6 grams, as shown in Figure 7.21, the sample mean weight will be $88.6/25 = 3.544$. The `almonds_sample` data frame contains the information of this sample. Here, we present the weight of the first 10 almonds in the sample:

```r
almonds_sample <- almonds_bowl |>
  rep_slice_sample(n = 25, reps = 1)
```

The `almonds_sample` data frame in the modernrive package contains $n=25$ rows corresponding to each almond shown in Figure 7.21. The first variable `replicate` indicates this is the first and only sample. The second variable `ID` gives an identification to each almond. The third column `weight` gives the correct weight for each almond in grams as a numeric value, also known as double. The distribution of the weights of these 25 are shown in the histogram in Figure 7.22.

```r
ggplot(almonds_sample, aes(x = weight)) + 
  geom_histogram(binwidth = 0.1, color = "white")
```

![](img/445742518041017e8f01f11b0c3190d9_255_0.png)

FIGURE 7.22: Distribution of weight for a sample of 25 almonds.

The weights in this sample range from 2.9 to 4.4 grams. There is not an obvious pattern in the distribution of this sample. We now compute the sample mean using our data-wrangling tools from Chapter 3:

```r
almonds_sample |>
  summarize(mean_weight = mean(weight))
```

```
# A tibble: 1 x 2
replicate mean_weight
<int> <dbl>
1 3.67
```

The sample mean weight was not too far from the population mean of 3.64 grams. The difference between the statistic (sample mean weight) and the parameter (population mean weight) was due to sampling variation.
