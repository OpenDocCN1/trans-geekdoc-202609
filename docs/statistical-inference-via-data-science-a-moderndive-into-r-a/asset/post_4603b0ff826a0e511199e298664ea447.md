### 6.1 One numerical and one categorical explanatory variable

We are ready to create visualizations, the last of our exploratory analysis. Given that the outcome variable `fert_rate` and explanatory variable `life_exp` are both numerical, we can create a scatterplot to display their relationship. But this time we incorporate the categorical variable by mapping it to the color aesthetic, creating a colored scatterplot.

```r
ggplot(UN_data_ch6, aes(x = life_exp, y = fert_rate, color = income)) +
  geom_point() +
  labs(x = "Life Expectancy", y = "Fertility Rate", color = "Income group") +
  geom_smooth(method = "lm", se = FALSE)
```

**FIGURE 6.1: Colored scatterplot of life expectancy and fertility rate.**

In the resulting Figure 6.1, observe that `ggplot()` assigns a default color scheme to the points and the lines associated with the four levels of income: Low income, Lower middle income, Upper middle income, and High income. Furthermore, the `geom_smooth(method = "lm", se = FALSE)` layer automatically fits a regression line for each group. We can see some interesting trends. First, observe that we get a different line for each income group. Second, the slopes for all the income groups are negative. Third, the slope for the High income group is clearly less steep than the slopes for all other groups. So, the changes in fertility rate due to life expectancy are dependent on the level of income of a given country. Fourth, observe that high-income countries have, in general, high life expectancy and low fertility rates.

### 6.1.2 Model with interactions

We can represent the four regression lines in Figure 6.1 as a multiple regression model with interactions. To do this, however, we review a linear regression with one categorical explanatory variable. Recall in Subsection 5.2.2 we fit a regression model for country life expectancy as a function of the corresponding continent. We produce the corresponding analysis here now using the fertility rate as the response variable and the income group as the categorical explanatory variable. We'll use slightly different notation than what was done previously to make the model more general.

A linear model with a categorical explanatory variable is a one-factor model where factor refers to the categorical explanatory variable and the categories are also factor vectors. We represent the categories using indicator functions or dummy variables. In our UN data example, the variable has four categories or levels: Low income, Lower middle income, Upper middle income, and High income. The corresponding dummy variables are needed:

$$
D_1 = \begin{cases} 1 & \text{if the UN member state has low income} \\ 0 & \text{otherwise} \end{cases}
D_2 = \begin{cases} 1 & \text{if the UN member state has lower middle income} \\ 0 & \text{otherwise} \end{cases}
D_3 = \begin{cases} 1 & \text{if the UN member state has high middle income} \\ 0 & \text{otherwise} \end{cases}
D_4 = \begin{cases} 1 & \text{if the UN member state has high income} \\ 0 & \text{otherwise} \end{cases}
$$

So, for example, if a UN member state has *Low income*, its dummy variables are $D_1 = 1$ and $D_2 = D_3 = D_4 = 0$. Similarly, if another UN member state has *high middle income*, then its dummy variables would be $D_1 = D_2 = D_4 = 0$ and $D_3 = 1$. Using dummy variables, the mathematical formulation of the linear regression for our example is:

$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 D_2 + \beta_3 D_3 + \beta_4 D_4$$

where $x$ is the numerical explanatory variable and $D_i$ are the dummy variables for the categorical levels (with Low income as the reference level). The coefficients of the model are:

$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 D_2 + \beta_3 D_3 + \beta_4 D_4$$

The coefficients of the model are:
- $\beta_0$ is the intercept for the reference group (Low income).
- $\beta_1$ is the slope of $x$ for the reference group.
- $\beta_2, \beta_3, \beta_4$ are the differences in the intercept for each group compared to the reference group.
- $\beta_5, \beta_6, \beta_7$ are the differences in the slope of $x$ for each group compared to the reference group (interactions).

If we include interactions, the model becomes:

$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 D_2 + \beta_3 D_3 + \beta_4 D_4 + \beta_5 (x \cdot D_2) + \beta_6 (x \cdot D_3) + \beta_7 (x \cdot D_4)$$

In this model, the slope of $x$ depends on the category:
- For Low income: $\beta_1$
- For Lower middle income: $\beta_1 + \beta_5$
- For Upper middle income: $\beta_1 + \beta_6$
- For High income: $\beta_1 + \beta_7$
