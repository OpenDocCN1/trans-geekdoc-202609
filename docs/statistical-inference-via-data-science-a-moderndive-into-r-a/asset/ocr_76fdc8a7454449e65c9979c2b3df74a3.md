Let’s now switch gears and learn about the concept of “tidy” data format with a motivating example from the fiftheight package. The fiftivirtyeight package (Kim et al., 2021) provides access to the datasets used in many articles published by the data journalism website, FiveTightyEight.com³. For a complete list of all 128 datasets included in the fiftyeight package, check out the package by going to: https://fivethirtyeight-r.netlify.app/articles/fivethirtyeight.html.

After reading the help file by running `?drinks`, you’ll see that drinks is a data frame containing results from a survey of the average number of servings of beer, spirits, and wine consumed in 193 countries. This data was originally reported on FiftyEight in Mona Chalabi’s article: “Dear Mona Followup: Where Do People Drink The Most Beer, and Wine Spirits?”⁴

Let’s apply some of the data-wrangling verbs we learned in Chapter 3 on the drinks frame:

+   1. filter() to consider only 4 countries: the United States, China, Italy, and Saudi Arabia, then
2. select() all columns except total_litres_of_alcohol by using the sign -, then
3. rename(beer_servings, spirit_servings, and wine_servings to beer, spirit, and wine, respectively.
