### 10.2.1 Conceptual framework

We start by reviewing the assumptions of the linear model. We continue using the old_faithful_2024 to illustrate some of this framework. Recall that we have a random sample of $n = 114$ observations. Since we assume a linear relationship between the duration of an eruption and the waiting time to the next, we can extract the linear relationship for the $i$th observation with $y_i = \beta_0 + \beta_1 \cdot x_i$ for $i = 1, \dots, n$. Observe that $x_i$ is the duration of the $i$th eruption in the sample, and $\beta_0$ and $\beta_1$ are the population parameters that are considered constant. The error term $\epsilon_i$ is a random variable that represents how different the observed response $y_i$ is from the expected response $\beta_0 + \beta_1 \cdot x_i$.

We can illustrate the role of the error term using two observations from our old_faithful_2024 dataset. We assume for now that the linear model is appropriate and truly represents the relationship between duration and waiting times.
