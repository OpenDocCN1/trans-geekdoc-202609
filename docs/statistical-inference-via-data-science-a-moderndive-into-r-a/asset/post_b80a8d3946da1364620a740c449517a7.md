This test is called an ANOVA test or an $F$-test, because the distribution of the test statistics follows an $F$ distribution. The way it works is that the test compares the sum of squared residuals of both the full and reduced models and determines whether the difference between these models was large enough to suggest that the full model is needed.

To get the result of this test in R, use the R function `anova()` and enter the reduced model followed by the full model Table 10.14 providing information for this test.

```
anova(mod_mult_2, mod_mult_1)
```

# TABLE 10.14: ANOVA test for model comparison

| Res.Df | RSS | Df | Sum of Sq | F | Pr(>F) |
|---|---|---|---|---|---|
| 204 | 149.9 | | | | |
| 203 | 55.1 | 1 | 94.8 | 350 | 0 |

The test statistic is given in the second row for the column F. The test statistic $F=349.6$ and the associated $p$-value is near zero. In conclusion, we reject the null hypothesis and conclude that the full model was needed.

The ANOVA test can be used to test more than one regressor at a time. This is useful when you have factors (categorical variables) in your model, as all the factor levels should be tested simultaneously. We use our example again, this making the full model with factor continent_of_origin all to three numerical regressors, and the reduced model is the model without continent_of_origin. These models have been computed already in mod_mult and mod_mult_1, respectively. The ANOVA test is performed as follows with the output given in Table 10.15:

```
anova(mod_mult_1, mod_mult)
```

# TABLE 10.15: ANOVA test for second model comparison

| Res.Df | RSS | Df | Sum of Sq | F | Pr(>F) |
|---|---|---|---|---|---|
| 203 | 51.1 | 3 | 37.2 | 4.83 | 0.003 |

Observe in this output that the degrees of freedom are 3, because we are testing three coefficients at the same time, $\beta_0$, $\beta_1$, and $\beta_2$. When we are testing for

# 10.5.5 Model fit and diagnostics

As we did for linear regression we use the residuals to determine the fit of the model and whether some of the assumptions are met. In particular we continue using the plot of residuals against the fitted values and if no violations present the plot should be close to a null plot. While most of the treatment and interpretations are similar to those presented for linear regression, when the plot of residuals against fitted values is not a null plot we know that there is violation of one or more of the assumptions of the model. It is no longer clear what the reason for this is, but at least one assumption is not met. On the other hand, if the residuals against fitted values appears to be close to a null plot, none of the assumptions have been broken and we can proceed with the use of this model.

```
# Fit regression model:
mod_mult_final <- lm(total_points ~ aroma + flavor + continent_of_origin)
# Fitted values and residuals:
fit_and_res_mult <- broom(mod_mult_final)
```

```
g1 <- ggplot(fit_and_res_mult, aes(x = .fitted, y = .residual)) + 
  geom_point() +

g2 <- ggplot(fit_and_res_mult, aes(x = .fitted, y = .residual)) + 
  geom_qq() +
```
