## 6.2 Two explanatory variables

Since debt, credit_limit, and income are numerical, and more importantly, the associations between the response and explanatory variables appear to be linear or close to linear, we can also calculate the correlation coefficient between any two of these variables. Recall that the correlation coefficient is appropriate if the association between variables is linear. One way to do this is by using the cor() command as seen in Subsection 5.1.1, for each explanatory variable with the response debt:

```r
credit_ch6 |> debt ~ credit_limit
credit_ch6 |> debt ~ income
```

Alternatively, using the select() and cor() command, we can find all correlations simultaneously by returning a correlation matrix as shown in Table 6.8. This matrix shows the correlation coefficient for any pair of variables in the appropriate row/column combination.

```r
credit_ch6 |> select(credit_limit, income) |> cor()
```

### TABLE 6.8: Correlation coefficients between credit debt, limit, and income

| | debt | credit_limit | income |
|---|---|---|---|
| debt | 1.000 | 0.862 | 0.464 |
| credit_limit | 0.862 | 1.000 | 0.792 |
| income | 0.464 | 0.792 | 1.000 |

Let's look at some findings in the correlation matrix:

- The diagonal values are all 1 because, based on the definition of the correlation coefficient, the correlation of a variable with itself is always 1. This indicates a strong and positive linear relationship: the greater the credit limit, the larger the credit debt, on average.
- The correlation between debt and credit_limit is 0.862. This indicates a strong relationship.
- The correlation between debt and income is 0.464. The linear relationship is positive albeit somewhat weak. In other words, higher income is only weakly associated with higher debt.
- Observe also that the correlation coefficient between the two explanatory variables, credit_limit and income, is 0.792.

## 6 Multiple Regression

A useful property of the correlation coefficient is that it is invariant to linear transformations; this means that the correlation between two variables $x$ and $y$, will be the same as the correlation between $(a \cdot x + b)$ and $y$ for any constants $a$ and $b$. To illustrate this, observe that the correlation between income in thousands of dollars and credit card debt was 0.464. If we now find the correlation income, by multiplying by 1000, and credit card debt we get:

```r
credit_ch6 |> debt ~ 1000 * income
```

```
# tibble: 1 x 1
  cor
<dbl>
1 0.464
```

The correlation is exactly the same.

## 6.2.2 Multiple regression with two numerical regressors

As shown in Figure 6.6, the linear regression with two numerical regressors produces the 'best-fitting' plane. We start with the coefficients of the regression where we retrieve them using the lm() function:

```r
model <- lm(debt ~ credit_limit + income, data = credit_ch6)
coef(model)
```

We present these results in the following table:

| | Coefficients | Values |
|---|---|---|
| Intercept | b0 | -385.179 |
| credit_limit | b1 | 0.263 |
| income | b2 | -7.663 |

The intercept is -385.179. The coefficient for credit_limit is 0.263. For one unit increase of credit limit, credit debt increases, on average, by 0.263. Similarly, the slope of income is -7.66. For one unit increase of income ($1000 in actual income), there is an associated decrease of $7.66 in credit debt. Putting these results together, the equation of the regression plane is:

$\hat{y} = b_0 + b_1 \cdot x_1 + b_2 \cdot x_2 = -385.179 + 0.263 \cdot x_1 - 7.663 \cdot x_2$
