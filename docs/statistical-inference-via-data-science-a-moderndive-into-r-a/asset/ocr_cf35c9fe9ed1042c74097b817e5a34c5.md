# $\tilde{y} = b_0 + b_{02}D_2 + b_{03}D_3 + b_{04}D_4 + b_1x.$

Observe that the dummy variables only affect the intercept now, and the slope is fully described by $b_1$ for any income group. In the UN data, a *high income* country, with $D_4 = 1$ and the other dummy variables equal to zero, will be represented by

$\tilde{y} = (b_0 + b_{04}) + b_1x.$

To find the coefficients for regression in R, the formula used $y \sim x1 + x2$ where $x1$ and $x2$ are the variable names in the dataset and represent the main effects. Observe that the term $x1:x2$ representing the interaction is no longer included. R would limit both $x1$ and $x2$ to be either explanatory or numerical; therefore, we should always check that the variable format is appropriate for the regression we want to run. Here is the code for the UN example data:

```
# Fit regression model:
model_int <- lm(fert_rate ~ life_exp + income, data = UN_data_ch6)

# Get the coefficients of the model
coef(model_no_int)
```

Assuming that this model is correct, for any UN member state, every additional year of life expectancy reduces the average fertility rate by 0.101 units, regardless of the income level of the member state.
