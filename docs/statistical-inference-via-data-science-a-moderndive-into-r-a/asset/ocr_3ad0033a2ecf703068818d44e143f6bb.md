# 10.1.4 The method of least squares

If the association of these variables is linear or approximately linear, we can apply the linear model described in Subsection 10.1.2 to each observation in the sample:

```
$$y_1 = \beta_0 + \beta_1 \cdot x_1 + \epsilon_1$\n$y_2 = \beta_0 + \beta_1 \cdot x_2 + \epsilon_2$\n$\vdots$\n$\vdots$\n$y_n = \beta_0 + \beta_1 \cdot x_n + \epsilon_n$
```

We want to be able to use this model to describe the relationship between the explanatory variable and the response, but the parameters $eta_0$ and $eta_1$ are unknown to us. We estimate these parameters using the random sample by applying the *least-squares* method introduced in Section 5.1. We compute the estimators for the intercept $(eta_0)$ and slope $(eta_1)$ that minimize the *sum of squared residuals*:

```
$$\sum_{i=1}^{n} [y_i - (\beta_0 + \beta_1 \cdot x_i)]^2$
```
