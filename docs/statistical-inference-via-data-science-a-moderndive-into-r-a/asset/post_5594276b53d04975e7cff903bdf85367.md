## 2.7.2 Summary

Side-by-side boxplots provide us with a way to compare the distribution of a numerical variable across multiple values of another variable. One can see where the median falls across the different groups by comparing the solid lines in the center of the boxes.

## 2.8 Barplots

To study the spread of a numerical variable within one of the boxes, look at both the length of the box and also how far the whiskers extend from either end of the box. Outliers are even more easily identified when looking at a boxplot than looking at a histogram as they are marked with distinct points.

Both histograms and boxplots are tools to visualize the distribution of numerical variables. Another commonly desired task is to visualize the distribution of a categorical variable. This is a simpler task, as we are simply counting different categories within a categorical variable, also known as the levels of the categorical variable. Of the best way to visualize these different counts, also known as frequencies, is with barplots (also called barcharts).

One complication, however, is how your data is represented. Is the categorical variable of interest "pre-counted" or not? For example, run the following code that creates two data frames representing a collection of fruit: 3 apples and 2 oranges.

```r
fruits <- tibble(fruit = c("apple", "apple", "orange", "apple", "orange"))
fruits_counted <- tibble(
  fruit = c("apple", "orange"),
  number = c(3, 2))
```

We see both the fruits and fruits_counted data frames represent the same collection of fruit. Whereas fruits lists the fruit individually...

```r
# A tibble: 5 x 1
  fruit
<chr>
1 apple
2 apple
3 orange
4 apple
5 orange
```

...fruits_counted has a variable count which represent the "pre-counted" values of each fruit.

```text
# A tibble: 2 x 2
  fruit  number
<chr> <dbl>
1 apple      3
2 orange     2
```

Depending on how your categorical data is represented, you'll need to add a different geometric layer to your ggplot() to create a barplot, as we now explore.

## 2.8.1 Barplots via geom_bar or geom_col

Let's generate barplots using these two different representations of the same basket of fruit: 3 apples and 2 oranges. Using the fruits data frame where all fruits are listed individually in rows, we map the fruit variable to the x-position and add a geom_bar() layer.

```r
ggplot(data = fruits, aes(x = fruit)) + geom_bar()
```
![](img/44574251804117e8f0f11b0c3190d9_84_0.png)
FIGURE: Barplot when counts are not pre-counted.

However, using the fruits_counted data frame where the fruits have been "pre-counted," we again map the fruit variable to the x-position, but here we also map the count variable to the y-position, and add a geom_col() layer instead.

```r
ggplot(data = fruits_counted, aes(x = fruit, y = number)) + geom_col()
```
![](img/44574251804117e8f0f11b0c3190d9_84_1.png)
FIGURE: Barplot when counts are pre-counted.

Compare the barplots in Figures 19 and 20. They are identical because they reflect counts of the same fruits. However, depending on how our categorical data is represented, either "pre-counted" or not, we must use a different geom layer. When the categorical variable whose distribution you want to visualize:

- Is not pre-counted in your data frame, we use geom_bar().
- Is pre-counted in your data frame, we use geom_col() with the y-position mapped to the variable that has the counts.

Let's now go back to the flights data frame and visualize the distribution of the categorical variable carrier each airline flew in 2023. In other words, the flights data frame is more like the fruits_counted data frame because the flights have not been pre-counted. Then we should use geom_bar() instead of geom_col() to create a barplot. Much like a histogram(), there is only one variable in the aes() mapping: the carrier bars that have white space between the bars going from left to right.

```r
ggplot(data = flights, aes(x = carrier)) + geom_bar()
```

## 2.8.2 Must avoid pie charts!

One of the most common plots used to visualize the distribution of categorical data is the pie chart. While they may seem harmless enough, pie charts actually present a problem in humans that are unable to judge angles well.

As Naomi Robbins describes in her book, Creating More Effective Graphs (Robbins, 2013), we overestimate angles greater than 90 degrees and underestimate angles less than 90 degrees. In other words, it is difficult for us to determine the relative size of one piece of the pie compared to another.
