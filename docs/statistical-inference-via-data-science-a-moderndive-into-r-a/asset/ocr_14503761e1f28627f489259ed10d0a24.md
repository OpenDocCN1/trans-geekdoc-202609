Each slope in a multiple linear regression is considered a partial slope and represents the marginal or additional contribution of a regressor when it is added to a model that already contains other regressors. This partial slope is particularly different than the slope we may find in a simple linear regression for the same regressor. The reason is that, typically, regressors are correlated, so when one regressor is part of a model, indirectly it's also explaining the part of other regressor. When the second regressor is added to the model, it helps explain only changes in the response that were not already accounted for by the first regressor. For example, the slope for credit_limit is $0.264. Keeping income fixed to value, for an additional increase of credit limit debt increases, on average, by $0.264. Similarly, the slope of income is -$7.66. For one unit increase of income ($1000 in actual income), there is an associated decrease of $7.66 in credit debt, on average.

Putting these results together, the equation of the regression plane that gives us fitted values $\hat{y}$ is:

```
$\hat{y} = b_0 + b_1 \cdot x_1 + b_2 \cdot x_2 = -335.179 + 0.263 \cdot x_1 - 7.663 \cdot x_2$
```

where $x_1$ represents credit limit and $x_2$ income.

To illustrate the role of partial slopes further, observe that the right plot in Figure 6.5 shows the relationship between debt and income in isolation, a positive relationship, so the slope of income is positive.
