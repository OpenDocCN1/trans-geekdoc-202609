The linear model is appropriate, we can interpret these coefficients as we did in Subsections 6.1.2 and 6.2.2. Recall that the numerical regressors' coefficients ($b_1, b_2$, and $b_3$) are partial slopes, representing the extra effect (or additional effect) of increasing the regressor by one unit while keeping the other regressors fixed to some value. For example, *mod_mult*, for a given observation we increase the flavor score by one, keeping all the other regressors fixed to level, total_cup_points would increase by 4.32 units. This interpretation is valid for the linear regression model *mod_mult*. If we decide to change the regressors, add or remove others, the model changes and the partial slope for flavor will be different in magnitude and meaning; do not forget that the partial slope is the additional contribution of flavor added to a model that includes all the other regressors for that particular model.

In addition, *mod_mult* is a model without interactions, similar to the model described in Subsection 6.1.3. The coefficients for factor levels of continent_of_origin ($b_{02}, b_{03}$, and $b_{04}$) affect only the intercept of the model, based on the category of the observation. Recall that the factor levels, in order, are Africa, Asia, North America, and South America. For example, if the fifth observation's origin is South America ($D_{04} = 1$ and $D_{02} = D_{03} = 0$), the regression formula is given by

```
$\hat{y}_5 = b_0 + b_1x_{51} + b_2x_{52} + b_3x_{53} + b_{02}D_{52} + b_{03}D_{53} + b_{04}D_{54}$
$= b_0 + b_1x_{51} + b_2x_{52} + b_3x_{53} + b_{02} \cdot 0 + b_{03} \cdot 0 + b_{04} \cdot 1$\n$= (b_0 + b_1x_{51} + b_2x_{52} + b_3x_{53})$
```

and the regression intercept for this observation is estimated to be

```
$b_0 + b_{04} = 37.32 + (-0.48) = 36.84$.
```
