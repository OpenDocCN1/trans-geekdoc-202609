When we bootstrap this data, we are potentially pulling the subject's readings multiple times. Thus, we use the entries of "seed" for group and "no" together in a new row in a bootstrap sample. This is further seen by exploring the sample_n() function in dplyr on this smaller 6-row data frame comprised of head(mythbusters.yawn). The sample_n() function can perform this bootstrapping procedure and is similar to the rep_sample_n() function in infer, except that it is not repeated, but rather performs one sample with or without replacement.

```
first_six_rows >
sample_n(size = 6, replace = TRUE)
```

```
# A tibble: 6 x 3
subj group yawn
<int> <chr>
1 6 control no
2 1 seed yes
3 2 control yes
4 6 control no
5 4 seed yes
6 4 seed yes
```

We see that in this bootstrap sample generated from the first six rows of mythbusters.yawn, we have some rows repeated. The same is true when we perform the generate() step in infer as done in what follows. Using this fact, we generate 1000 replicas, or in other words, we bootstrap resample the 50 participants with replacement 1000 times.

```
mythbusters_yawn >
specify(formula = yarn ~ group, success = "yes") >
ggenerate(reps = 1000, type = "bootstrap")
```
