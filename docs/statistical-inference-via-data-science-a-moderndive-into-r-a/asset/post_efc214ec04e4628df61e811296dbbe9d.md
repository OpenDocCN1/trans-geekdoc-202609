# About this book

This book was written using RStudio's bookdown^{29} package by Yihui Xie(Xie, 2024). This package simplifies the publishing of books by having all content written in R Markdown^{30}. The bookdown/R code for all versions of ModernDive is available on GitHub:

- Latest online version: The most up-to-date release:
  - Version 2.0 released on March 20, 2025 (source code^{31})
  - Available at https://moderndive.com/v2/
- Second print edition: The CRC Press edition is what we are reading! It corresponds to Version 2.0. We welcomed Dr. Arturo Valdivia as a co-author for his edition. His deep knowledge of statistics and superb teaching experience have been invaluable in improving the book. Here is a summary of what was updated from v1.0 to v2.0 (first print edition to second edition). Additional information about changes over the book time are available on our GitHub page here^{32}
- Updated Datasets and Code: We replaced datasets (promotions, events, and pennies) with new ones (un_member_states_2024, specify_sample, and almonds). We adopted the nyflights^{23} package instead of nyflights^{13} and introduced the base R pipe (|>) of the tidypipe (%>). We also incorporated envoy_flights and early_january_2023_weather in the moderndive package.
- Content Reorganization: We restructured sections in Chapters 7 and Chapter 10 for improved readability. We moved “Model Selection” from Chapter 6 to Chapter 10 and split it into two sections as suggestions.

# Versions of R packages

If you'd like your output on your computer to match exactly with the output presented throughout the book, you may want to use the exact versions of the packages we used. You can find a full listing of these packages and their versions below. This likely won't be relevant for novices, but we included it for reproducibility.

If you are seeing different results than is in the book, we recommend installing the exact version of the packages we used. This can be done by first installing the remotes package via install.packages("remotes"). Then, use install_version() replacing the package argument with the package name in quotes and the version argument with the particular version number to install, such as

```r
remotes::install_version(package = "moderndive", version = "0.6.1")
```
