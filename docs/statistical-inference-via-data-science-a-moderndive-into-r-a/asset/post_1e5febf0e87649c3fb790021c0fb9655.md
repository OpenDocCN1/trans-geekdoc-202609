### 11.2.4 Making predictions

Say you're a realtor and someone calls you how much their home will sell for. They tell you it's condition = 5 and is sized 1900 square feet. What do you tell them? Let's use the interaction model to make this prediction visually in Figure 11.8. The predicted $\log_{10}(price)$ of this house is marked with a black dot. This is where the two lines intersect:
- The regression line for condition = 5
- vertical dashed line at $\log_{10}(size) = 3.28$, since our predictor variable is the transformed footage of $\log_{10}(1900) = 3.28$.

Eyeballing, it seems the predicted $\log_{10}(price)$ seems to be around 5.75. Let’s now find the exact value for the prediction using the equation of the regression line for condition = 5:
```
2.45 + 1 * log10(1900)
```
5.73 is very close to our earlier prediction of 5.75. But wait! Is our prediction for the price of this house $5.75? No, because we want a prediction in dollar units, we need to un-log this by taking a power of 10:
```
10^(2.45 + 1 * log10(1900))
```
535493. Our predicted price for condition 5 and size 1900 square feet is $535,493.

### 11.2.5 Inference for multiple linear regression

Next, we build a null distribution of the partial slopes using the generate() function and the fit() function, setting hypothesize(null = "independence") which will shuffle the values of the response variable log10_price.

```
null_distribution_housing <- house_prices |
  specify(log10_price ~ log10_size * condition) |
  hypothesize(null = "independence") |
  generate(reps = 1000, type = "permute") |>
  fit()
```
We visualize this null distribution and shade the observed fit values to see if they are statistically significant.

```
visualize(null_distribution_housing) +
  shade_p_value(obs_stat = observed_fit_coefficients, direction = "two-sided")
```
