This function is an example of what is known in computer programming as a wrapper function. It takes other pre-existing functions and "wraps" them into a single function that hides its inner workings. This concept is illustrated in Figure 5.5.

All you need to worry about is what the inputs look like and what the outputs look like; you leave all other details "under the hood of the car." In our regression modeling example, the get_regression_points() function takes a saved lm(m) regression model as input and returns a data frame of the regression predictions as output. If you are interested in learning more about the get_regression_points() function's inner workings, check out Subsection 5.3.3.
