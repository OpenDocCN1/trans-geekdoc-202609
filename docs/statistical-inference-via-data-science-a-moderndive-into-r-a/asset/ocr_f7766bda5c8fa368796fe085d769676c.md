# 10 Inference for Regression

The t-test statistic is

```
$t = \frac{b_2-0}{SE(b_2)} = \frac{4.28-0}{0.23} = 18.7$$
```

and using this test statistic, the associated p-value is near zero and R only shows the output as zero. We have enough evidence to reject the null hypothesis that $\beta_2=0$. Recall when we reject the null hypothesis we say that the result was statistically significant, and we have enough evidence to conclude the alternative hypothesis $(\beta_2 \neq 0)$. This implies that changes in flavor provide information about the total_cup_points when flavor is added to a model that already contains aroma and moisture_percentage.

Table 10.13 provides information for all the coefficients. In particular, that the test for $\beta_1$ (aroma) is also statistically significant but the test for $\beta_2$ (moisture_percentage) is not (p-value=0.62). For the latter, the conclusion is that there is no statistical evidence (to reject the null hypothesis that this partial slope is zero). We have not found evidence that adding moisture_percentage to a model that already includes aroma and flavor helps explaining changes in the response total_cup_points. We can remove the moisture_percentage regressor from the model.

# 10.5.4 Hypothesis test for model comparison

There is another hypothesis test that can be performed for multiple linear regression, a test that compares models, one with a given set of regressors the full model and the other with only a subset of those regressors called the reduced model.

Using the coffee_data example, suppose that the model is:

```
$Y = \beta_0 + \beta_1 \cdot X_1 + \beta_2 \cdot X_2 + \beta_3 \cdot X_3 + \epsilon$$
```

where $\beta_1, \beta_2$, and $\beta_3$ are the parameters for the partial slopes of aroma, flavor, and moisture_percentage, respectively. The multiple linear regression outcome using the coffee_data dataset is stored in the object mod_mult_1. The reduced model does not contain the regressor and is given by

```
$Y = \beta_0 + \beta_1 \cdot X_1 + \beta_3 \cdot X_3 + \epsilon$$
```

The multiple linear regression output using this model is stored in the object mod_mult_2. The hypothesis test for comparing the full and reduced models is written as:

```
$H_0 : Y = \beta_0 + \beta_1 \cdot X_1 + \beta_2 \cdot X_2 + \epsilon$$
```

```
$H_A : Y = \beta_0 + \beta_1 \cdot X_1 + \beta_2 \cdot X_2 + \beta_3 \cdot X_3 + \epsilon$$
```
