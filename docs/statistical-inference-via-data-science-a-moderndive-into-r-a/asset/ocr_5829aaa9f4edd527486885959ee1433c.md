We can use a histogram to visualize the distribution of the residuals:

```
ggplot(fitted_and_residuals, aes(residual)) + 
geom_histogram(binwidth = 10, color = "white")
```

We can also use a quantile-to-quantile plot or QQ-plot. The QQ-plot creates a scatterplot of the quantiles (or percentiles) of the residuals against the quantiles of a normal distribution. If the residuals follow approximately a normal distribution, the scatter-plot would be a straight line of 45 degrees. To draw a QQ-plot for the Old Faithful geyser eruptions example, we use the fitted_and_residuals data frame that contains the residuals of the regression, ggplot() with aes(sample = residual) and the geom_qq() function for drawing the QQ-plot. We also include the geom_qq_line() to add a 45-degree line for comparison:

```
fitted_and_residuals | |
geggplot(aes(sample = residual)) + 
geom_qq() +
geom_qq_line()
```
