```
guat_dem_tidy <- guat_dem |>
pivot_longer(names_to = "year",
values_to = "democracy_score",
cols = "-country",
names_transform = list(year = as.integer))

guat_dem_tidy
```

We set the arguments to pivot_longer() as follows:

+   1. `names_to` is the name of the variable in the "tidy" data frame that will contain the column names of the original data. We observe how we set `names_to = "year"`. In the resulting `guat_dem_tidy`, the column contains the years where Guatemala's democracy scores were measured.
2. `values_to` is the name of the variable in the "tidy" data frame that contains the values of the original data. We observe how we set `values_to = "democracy_score"`. In the resulting `guat_dem_tidy`, the column `democracy_score` contains the `1 x 9` democracy scores as numeric values.
3. The third argument is the columns you want to tidy or don't want to "tidy". We set this to `cols = -country` indicating not not to tidy the country variable in `guat_dem` and rather only variables 1952 through 1992.
4. The last argument of `names_transform` tells R what type of variable year should be set to. Without specifying that it is an integer as we've done, `pivot_longer()` will set it to a character value by default.

Now we create the time-series plot in Figure 4.5 to visualize how democracy scores in Guatemala have changed from 1952 to 1992 using a `geom_line()`. Furthermore, we'll use the `labs()` function in `ggplot2` package to add informative labels to all the `aes()` attributes of our plot, in this case the x and y positions.
