To close out our discussion on the mutate() function to create new variables, note that we can create multiple variables at once in the same mutate() code. Furthermore, within the same mutate() code we can refer to new variables we just created. For example, consider the mutate() code Hadley Wickham and Garrett Grolemund in Chapter 5 of R for Data Science (Grolemund and Wickham, 2017):

```
flights <- flights |>
mmutate(
  gain = dep_delay - arr_delay,
  hours = air_time / 60,
  gain_per_hour = gain / hours
)
```
