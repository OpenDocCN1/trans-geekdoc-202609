# 11.3.2 US births in 1999

The US_births_1994_2003 data frame in the fifteight package provides information about the number of births in the United States between 1994 and 2003. For more information on this data including a link to the original article on FiveThirtyEight.com, check out the help file by running ?us_births_1994_2003 in the console.

It's always a good idea to preview your data, by using RStudio's spreadsheet view() function or using glimpse() from the dplyr package:

```
glimpse(US_births_1994_2003)
```

We'll focus on the number of births for each date, but for births that occurred in 1999. Recall from Section 3.2 we can do this using the filter() function from the dplyr package:

```
US_births_1999 <- US_births_1994_2003 |> 
filter(year == 1999)
```
