Here are some questions you can ask yourself at this stage of an EDA: Which variables are numerical? Which are categorical? For the categorical variables, the other variables we'll be using in our regression model, what other variables do you think would be useful in predicting house price?

Observe, with the raw data that while the condition variable has values through 5, these are saved in R fct as "factors". Recall this is one of R's ways of treating categorical variables. You should think of these as “labels” 1 through 5 and not numerical values through 5.

Let's now perform the second step in an EDA: computing summary statistics. Recall from Section 3.3 that summary statistics are single numerical values that summarize a large number of values. Examples of summary statistics include the mean, median, the standard deviation, and various percentiles.

Let's use the convenient tidy_summary() function from the moderndrive package we first used in Subsection 6.1.1, being sure to only select() the variables of interest for our model:

```
house_prices |>
select(price, sqft_living, condition) |>
tidy_summary()
```
