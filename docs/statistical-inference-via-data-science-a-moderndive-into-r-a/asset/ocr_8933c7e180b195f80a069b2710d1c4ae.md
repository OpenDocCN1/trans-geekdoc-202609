# 10.5.3 Hypothesis test for a single coefficient

The hypothesis test for one coefficient, say $\beta_1$ in the model, is similar to the one for simple linear regression. The general formula for a two-sided test is

$H_0: \beta_1 = B$ with $\beta_0, \beta_2, \dots, \beta_p$ given arbitrary.
$H_A: \beta_1 \neq B$ with $\beta_0, \beta_2, \dots, \beta_p$ given and arbitrary.

where $B$ is the hypothesized value for $\beta_1$. We make emphasis in stating that $\beta_0, \beta_2, \dots, \beta_p$ are given arbitrary to acknowledge that the test only matters in the context of the appropriate model. Also notice, that we can perform a test not only for $\beta_1$ but for any other parameter.

As did for linear regression, the most commonly used is the one where we check if $\beta_j = 0$ for any $j=0, 1, \dots, p$. For $\beta_1$ the two-sided test would be:

$H_0: \beta_1 = 0$ with $\beta_0, \beta_2, \dots, \beta_p$ given and arbitrary
$H_A: \beta_1 \neq 0$ with $\beta_0, \beta_2, \dots, \beta_p$ given and arbitrary

In linear regression, testing for $\beta_1 = 0$ was testing to determine if there was a linear relationship between the response and the only regressor. Now, testing for $\beta_1=0$ is testing whether the corresponding regressor should be part of a linear model that already contains all the others.

This test can be performed with any of the partial slopes. For example, we use the coffee example and model mod_mult_1 (the model with only three numerical regressors) and perform a test for $\beta_2$ (the population partial slope for regressor flavor). The hypotheses are:

$H_0: \beta_2 = 0$ with $\beta_0, \beta_1, \beta_3, \beta_2, \beta_{03}, \beta_{04}$ given and arbitrary.
$H_A: \beta_2 \neq 0$ with $\beta_0, \beta_1, \beta_3, \beta_2, \beta_{03}, \beta_{04}$ given and arbitrary.
