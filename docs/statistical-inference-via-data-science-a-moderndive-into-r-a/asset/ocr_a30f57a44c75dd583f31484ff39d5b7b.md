# 10.4 The multiple linear regression model

$\hat{y}_i = b_0 + b_1x_{i1} + b_2x_{i2} + b_3x_{i3} + b_{02}D_{i2} + b_{03}D_{i3} + b_{04}D_{i4}$

the variance estimator

$s^2 = \sum_{i=1}^n [y_i - (b_0 + b_1x_{i1} + b_2x_{i2} + b_3x_{i3} + b_{02}D_{i2} + b_{03}D_{i3} + b_{04}D_{i4})]^2 \\ n-7$

$s = \sqrt{\frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{n-7}}$

and the standard deviation estimator

When we think about the least-square estimators as random variables that depend on the random sample taken, the properties of these estimators are a direct extension of the properties presented for the simple linear case:

+   - The least-square estimators are unbiased estimators of the parameters of the model. For example, if we choose $\beta_1$ (the estimator for the partial slope for *alcohol*), then the expected value is equal to the parameter, $E(b_1) = \beta_1$. This means that for some random samples the estimated value $b_1$ will be greater than $\beta_1$, and for others than $\beta_1$; but, on average, $b_1$ will be equal to $\beta_1$.
- The least-square estimators are linear combinations of the observed responses $y_1, y_2, ..., y_n$. For $b_3$, for example, there are known constants $c_1, c_2, ..., c_n$ such that $b_3 = \sum_{i=1}^n c_iy_i$.

When using the lm() function, all the necessary calculations are done in R. For coffee example, we get:

```
# Fit regression model:
mod_mult <- lm(
  total_cup_points ~ aroma + flavor + moisture_percentage +
  continent_of_origin,
  data = coffee_data
)

# Get the coefficients of the model
coef(mod_mult)

# Get the standard deviation of the model
sigma(mod_mult)
```
