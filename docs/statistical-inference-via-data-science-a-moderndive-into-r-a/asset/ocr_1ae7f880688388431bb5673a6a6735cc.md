Observe that drinks_smaller has three separate variables beer, spirit, and wine. In order to use the ggplot() function to recreate the barplot in Figure 4.2 however, we need a single variable type with three possible values: beer, spirit, and wine. We could then map this variable type to the fill aesthetic of our plot. In other words, to recreate the barplot in Figure 4.2, our data frame would have to look like this:

drinks_smaller_tidy


Observe that drinks_smaller and drinks_smaller_tidy are both rectangular in shape and contain the same 12 numerical values (3 alcohol types by 4 countries), they are formatted differently. drinks_smaller is formatted in what's known as "wide"⁵, whereas drinks_smaller_tidy is formatted in what's known as "long/narrow"⁶ format.

In the context of data science in R, long/narrow format is also known as "tidy" format. In order to use the ggplot2 and dplyr packages for data visualization and data wrangling, your input data frames must be in "tidy" format. Thus, all non-'tidy" data must be converted to "tidy" format. Before we convert non-"tidy" data frames like drinks_smaller to "tidy" data frames like drinks_smaller_tidy, let's define "tidy" data.
