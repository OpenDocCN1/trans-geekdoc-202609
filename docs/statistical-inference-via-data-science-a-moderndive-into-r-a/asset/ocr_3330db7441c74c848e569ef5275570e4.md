# 6.2.3 Observed/fitted values and residuals

As shown in Subsection 6.1.4 for the UN member states example, we find the fitted values and residuals for our credit card debt regression model. The fitted values for the credit card debt (debt) are computed using the equation for the regression plane:

```
$\hat{y} = -385.179 + 0.263 \cdot x_1 - 7.663 \cdot x_2$
```

where $x_1$ is credit_limit and $x_2$ is income. The residuals are the difference between the observed credit card debt and the fitted credit card debt, $y - \hat{y}$, for each observation in the data set. In R, we find the values, debt\_hat, and residuals, residual, using the regression\_points() function. In Table 6.9 we present the first 10 rows of output. Remember that the coordinates of the points in our 3D scatterplot in Figure 6.6 can be found in the income, credit\_limit, and debt columns.

```
get_regression_points(debt_model)
```
