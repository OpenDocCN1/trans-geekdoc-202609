Let's re-visit the n() counting summary function we briefly introduced previously. Recall that the n() function counts rows. This is opposed to the sum() summary function that returns the sum of a numerical variable. For example, suppose we'd like to count how many flights departed of the three airports in New York City:

```
by_origin <- flights |>
group_by(origin) |>
summarize(count = n())
```
