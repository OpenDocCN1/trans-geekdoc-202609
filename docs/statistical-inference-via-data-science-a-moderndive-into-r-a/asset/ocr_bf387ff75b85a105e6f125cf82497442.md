7 Sampling

Let's now take a random sample of 25 almonds, as shown in Figure 7.21, and determine the sample average weight, or sample mean weight, in grams.

![](bbox=[0.303, 0.139, 0.696, 0.413])

FIGURE 7.21: A random sample of 25 almonds on a scale.

Since the total weight is 88.6 grams, as shown in Figure 7.21, the sample mean weight will be 88.6/25 = 3.544. The modernrive package contains the information of this sample in the almonds_sample data frame. Here, we present the weight of the first 10 almonds in the sample:

```
almonds_sample <- almonds_bowl |
rep_slice_sample(n = 25, reps = 1)
almonds_sample
```

The almonds_sample data frame in the modernrive package contains n = 25 rows corresponding to each almond in the sample shown in Figure 7.21. The first variable replicate indicates this is the first and only replicate since it is a single sample. The second variable ID gives an identification to the particular almond. The third column weight gives the correct weight for each almond in grams as a numeric value, also known as a double (dbl).

The distribution of the weights of these 25 are shown in the histogram in Figure 7.22.

```
ggplot(almonds_sample, aes(x = weight)) + 
geom_histogram(binwidth = 0.1, color = "white")
```
