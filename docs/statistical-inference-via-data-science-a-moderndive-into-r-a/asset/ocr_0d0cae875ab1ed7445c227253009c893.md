# ANOVA

ANOVA, or analysis of variance, is a statistical technique used to compare the means of three or more groups by seeing if there is a statistically significant difference between multiple groups. ANOVA can be represented in the regression framework by dummy variables to represent the genres. Lets say we wanted to compare the popularity (numeric) values in the spotify_by_genre data frame from the modernverse package across the genres of "country,"hip-hop," and "rock." We use the slice_sample() function after narrowing in our selected collections and filtered rows of interest to see what a few rows of this data look like.

```
spotify_for_anova <- spotify_by_genre |>
select(artists, track_name, popularity, track_genre) |>
filter(track_genre %in%c("country", "hip-hop", "rock"))
```

```
spotify_for_anova |>
lice_sample(n = 5)
```
