The correlation coefficient can be computed using the `get_correlation()` function in the `tidyverse` package. In this case, the inputs to the function are two numerical variables for which we want to calculate the correlation coefficient.

We put the name of the outcome variable on the left-hand side of the ~ “tilde” sign, while putting the name of the explanatory variable on the right-hand side. This is known as R’s formula notation. We will use this “formula” syntax with regression later in this chapter.

```r
UN_data_ch5 |>
get_correlation(formula = fert_rate ~ life_exp)
```

```r
# A tibble: 1 x 1
cor
<dbl>
1 -0.812
```

An alternative way to compute correlation is to use the `cor()` summary function within a `summarize()`:

```r
UN_data_ch5 |>
summarize(correlation = cor(fert_rate, life_exp))
```

In our case, the correlation coefficient of -0.812 indicates that the relationship between fertility rate and life expectancy is “moderately negative.” There is a certain amount of subjectivity in interpreting correlation coefficients, especially those that are not close to the extreme values of -1, 0, and 1. The method = "lm" argument sets the line to be a "linear model." The se = FALSE argument suppresses standard error uncertainty bars. We will define the concept of standard error later in Section 7.3.4.

The line in the resulting Figure 5.3 is called a “regression line.” The regression line is a visual summary of the relationship between two numerical variables, in our case the outcome variable *fert_rate* and the explanatory variable *life_exp*. The negative slope of the blue line is consistent with our early observed correlation coefficient of -0.812 suggesting that there is a negative relationship between these two variables: as a country’s population has higher life expectancy it tends to have a lower fertility rate. We’ll see later, however, while the correlation coefficient and the slope of a regression line always have the same sign (positive or negative), they typically do not have the same value.

Furthermore, a regression line is “best-fitting” in that it minimizes some mathematical criteria. We present these mathematical criteria in Subsection 5.3.2, but we suggest you read this subsection only after first reading the rest of this section on regression with one numerical explanatory variable.

## 5.2 Linear Regression 160

We can obtain the values of $b_0$ and the slope for $life\_exp$ by two steps:

- We first "fit" the linear model using `lm()` and save it in demographics_model.
- We get the coefficients by applying `coef()`.

```r
# Fit regression model:
demographics_model <- lm(fert_rate ~ life_exp,
                          data = UN_data_ch5)

# Get regression coefficients
coef(demographics_model)
```

The coefficients are $b_0 = 12.599$ and the slope $b_1 = -0.137$. Thus the equation of the line in 5.3 follows:

$$\hat{y} = b_0 + b_1 \cdot x$$
$$fertility\_rate = 12.599 + (-0.137) \cdot life\_expectancy$$

The intercept $b_0 = 12.599$ is the average fertility rate $\hat{y} = fertility\_rate$ for countries that have a $life\_exp$ of 0. In graphical terms, where the line intersects the $y$ axis for $x = 0$. However, that while the intercept of the line has a $life\_exp$ of 0 is impossible. Furthermore, looking at the scatterplot with the regression line in 5.3, no countries have a life expectancy anywhere near 0.

Of interest is the slope $b_1 = b_{life\_expectancy}$ for $life\_exp$ of -0.137. This measures the relationship between the fertility rate and life expectancy variables. Note that the sign is negative, suggesting a negative relationship between these two variables. This means countries with higher life expectancies tend to have lower fertility rates. Recall from earlier that the correlation coefficient is -0.812. They both have the same negative sign, but a different value.
