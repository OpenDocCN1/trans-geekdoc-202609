Much like when adding layers to a ggplot() using the + sign, you form a single chain of data wrangling operations by combining verb-named functions into a single sequence using the pipe operator |. Furthermore, much like the + sign has to come at the end of lines when constructing plots, the pipe operator | has to come at the end of lines as well.

Keep in mind, there are many more advanced data-wrangling functions than just the six listed in the introduction to this chapter; you'll see some examples of these in Section 3.8.
