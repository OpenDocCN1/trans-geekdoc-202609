Constructing a bootstrap sample: resampling once

We start by constructing one bootstrap sample of 100 almonds from the original sample of 100 almonds. These are the steps needed to perform this task manually:

**Step 1:** Place the original sample of 100 almonds into a bag or hat.

**Step 2:** Mix the bag contents, draw one almond, weigh it, and record the weight as seen in Figure 8.10.

![](img/445742518041017e8f01f11b0c3190d9_295_0.png)

**FIGURE 8.10:** Step 2: Weighing one almond at random.

**Step 3:** Put the almond back into the bag! In other words, replace it as seen in Figure 8.11.

![](img/445742518041017e8f01f11b0c3190d9_296_0.png)

**FIGURE 8.11:** Step 3: Replacing almond.

**Step 4:** Repeat Steps 2 and 3 a total of 99 more times, resulting in 100 weights.

These steps describe *resampling with replacement*, and the resulting sample is called a *bootstrap sample*. This procedure results in some almonds chosen more than once and others not being chosen at all. Resampling with replacement induces *sampling variation*, every bootstrap sample can be different than any other.

This activity can be performed manually following the steps described above. We can also take advantage of the R code we have introduced in Chapter 7 and do this virtually. The data frame `almonds_sample_100` contains the random sample of almonds taken from the population. We show selected rows from this sample.

```

ungroup() |>
select(-replicate)

We use `ungroup()` and select the variable `replicate` from the `almonds_sample_100` as this variable may create clutter when resampling. We can now create a bootstrap sample of size 100 by resampling with replacement once.

```
boot_sample <- almonds_sample_100
resample_sample(size = 100, replace = TRUE, reps = 1)
```

We have used this type of R syntax many times in Chapter 7. We first select the data frame `almonds_sample_100` that contains the almonds' weights in the original sample. We then perform resampling with replacement once: we resample using `resample_sample()`, a sample of size 100 by setting `size = 100`, with replacement by adding the argument `replace = TRUE`, and one time by setting `reps = 1`. The object `boot_sample` is a bootstrap sample of 100 almonds' weights gained from the original sample of 100 almonds' weights. We show the first rows of `boot_sample`:

## 8.2 Estimation with the bootstrap

This histogram highlights the variation of the sample mean means. Since we have used only 35 bootstrap samples, the histogram looks a little coarse. To improve our perception of this variation, we find 1000 bootstrap samples and their sample means:

```
# Retrieve 1000 bootstrap samples
bootstrap_samples <- almonds_sample_100 |>
resample_sample(size = 100, replace = TRUE, reps = 1000)

# Compute sample means from the bootstrap samples
boot_means <- bootstrap_samples |
summarize(mean_weight = mean(weight))
```

We can combine these two operations into one single chain of pipe (|) operators:

```

resample_sample(size = 100, replace = TRUE, reps = 1000) |
summarize(mean_weight = mean(weight))
