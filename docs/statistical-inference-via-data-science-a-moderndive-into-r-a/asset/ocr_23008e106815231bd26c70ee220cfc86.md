# 252 8 Estimation, Confidence Intervals, and Bootstrapping

Observe how the t density curve in dashed (t with 10 degrees of freedom) gets closer
to the standard normal density curve, or z-curve, in solid, then the t curve in dotted
(t with 2 degrees of freedom). The greater the number of degrees of freedom, the closer
t t density is from the z curve. This change makes our calculations slightly different.

Using that knowledge, the calculation for our specific example shows that 95% of
sample means are within 1.98 standard errors from the population mean weight.
number of standard errors needed is not that different from before, 1.98 versus 1.96,
because the degrees of freedom are fairly alike.

Using this information, we can construct the 95% confidence interval based entirely
on our sample information and using the sample mean and sample standard deviation.
We calculate those values again for almonds_sample_100:

```
almonds_sample_100 |>
summarize(sample_mean = mean(weight), sample_sd = sd(weight))
```

```
# A tibble: 1 x 3
replicate sample_mean sample_sd
<int> <dbl> <dbl>
1 3.682 0.362199
```

Observe that the sample standard deviation is s = 0.362 which is not different
from the population standard deviation of σ = 0.392. We again center the confidence
interval at the observed mean but now extend the interval by 1.98 standard
errors to each side. The lower and upper bounds of this confidence interval are:

> $(\bar{x} - 1.98\\sqrt{n}, \bar{x} + 1.98\\sqrt{n}) = (3.682 - 1.98 \cdot\frac{0.362}{\sqrt{100}}, 3.682 + 1.98 \cdot\frac{0.362}{\sqrt{100}}) = (3.498, 3.846))

We can also compute these lower and upper bounds:

```
almonds_sample_100 |>
summize(sample_mean = mean(weight), sample_sd = sd(weight),
lower_bound = mean(weight) - 1.98*sd(weight)/sqrt(length),
upper_bound = mean(weight) + 1.98*sd(weight)/sqrt(length))
```

```
# A tibble: 1 x 5
replicate sample_mean sample_sd lower_bound upper_bound
<int> <dbl> <dbl> <dbl>
1 1 3.682 0.362199 3.75372
```
