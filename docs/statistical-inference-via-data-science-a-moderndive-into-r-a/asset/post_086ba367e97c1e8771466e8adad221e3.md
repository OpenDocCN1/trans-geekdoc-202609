### Bootstrap distribution for the partial slopes

We will now construct the bootstrap distribution for the partial slopes using the infer workflow. Just like in Section 10.3.1, we are now resampling entire rows of values. We construct the bootstrap distribution for the fitted partial slopes using our full sample of 207 coffees:

1. `specify()` the variables of interest in `coffee_data` with the formula: `total_points ~ aroma + flavor + moisture_percentage + continent_of_origin`.
2. `generate()` replicas by using bootstrap resampling with replacement from the original sample of 207 coffees. We generate `reps = 1000` replicates using `type = "bootstrap"` for a total of 207 * 1000 = 207,000 rows.

```r
coffee_data |>
  specify(
    total_points ~ continent_of_origin + aroma + flavor +
    moisture_percentage
  ) |>
  generate(reps = 1000, type = "bootstrap")
```

## 10.6 Simulation-based inference for multiple linear regression

### Confidence intervals for the partial slopes

As we did in Section 10.3.1, we can construct 95% confidence intervals for the partial slopes. Here, we focus on using the percentile-based method with the `get_confidence_interval()` function and `type = "percentile"` to construct these intervals.

```r
confidence_intervals_mlr <- boot_distribution_mlr |>
  get_confidence_interval(
    level = 0.95,
    type = "percentile",
    point_estimate = observed_fit
  )
confidence_intervals_mlr
```

## 10.6 Simulation-based inference for multiple linear regression

### Hypothesis tests for the partial slopes

We can also conduct hypothesis tests for the partial slopes in multiple regression. We use the permutation test to the null hypothesis $H_0: \beta_i = 0$ versus the alternative $H_A: \beta_i \neq 0$ for each of the partial slopes. We can also compute the null distribution by shuffling the response variable across `coffee_data` for the regressors `continent_of_origin`, aroma, flavor, and moisture. This is similar to the bootstrap distribution, but we use `type = "permute"` and set the random seed to 24. 

```r
set.seed(24)
null_distribution_mlr <- coffee_quality |>
  specify(
    total_cup_points ~ continent_of_origin + aroma + flavor +
    moisture_percentage
  ) |>
  generate(reps = 1000, type = "permute") |>
  fit()
```
