Using random variables, we now let $X_1$ to be the random variable thatepresents the weight of the first almond before it has been selected, $X_2$ the weight
of the second almond. These are random variables because they can take
possible almond weight value from the bowl. After the first trial is completed,
t value of $X_1$ is realized as the weight in grams of the first almond selected. We
represent this value by we can write $X_1 = x_1$, After the second trial is completed, $X_2 = x_2$,nwhere $x_2$ is the observed almond weight, and so on. Since our experiment is
to perform 25 trials and then find the average of them, this average or mean, before
the trials are carried out, can also be expressed as a random variable:

```
$\overline{X} = \frac{X_1 + X_2 + \dots + X_{25}}{25}$
```

Observe that $\overline{X}$ is the average, or mean, of these 25 trials. This is why $\overline{X}
is called the sample mean. Recall that dealing with proportions, the trials
Bernoulli trials, represented only with zeros or ones. In this context, sample
proportions are a special case of sample means. The trials we use now are not
restricted to zeros and ones, and the sample means are no longer sample proportions.
