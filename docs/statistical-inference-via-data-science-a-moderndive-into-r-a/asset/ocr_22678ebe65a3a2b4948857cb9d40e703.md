# 8.2 Estimation with the bootstrap

This histogram highlights the variation of the sample mean means. Since we have used only 35 bootstrap samples, the histogram looks a little coarse. To improve our perception of this variation, we find 1000 bootstrap samples and their sample means:

```
# Retrieve 1000 bootstrap samples
bootstrap_samples <- almonds_sample_100 |
rep_sample_n(size = 100, replace = TRUE, reps = 1000)

# Compute sample means from the bootstrap samples
boot_means <- bootstrap_samples |
summarize(mean_weight = mean(weight))
```

We can combine these two operations into one single chain of pipe (|) operators:

```
boot_means <- almonds_sample_100 |
rep_sample_n(size = 100, replace = TRUE, reps = 1000) |
summarize(mean_weight = mean(weight))
boot_means
```
