
# SUMMARY

- Network coding is a technique used in computer networks to enhance the efficiency and reliability of data transmission. Traditionally, data packets are forwarded through network nodes individually, leading to potential inefficiencies and redundant transmissions.

- The key advantage of network coding lies in its ability to increase data throughput and optimize network utilization. By combining data at intermediate nodes, network coding reduces the number of transmissions required, leading to improved efficiency and reduced congestion.

- Network coding finds particular relevance in large-scale, distributed networks, such as peer-to-peer networks, wireless mesh networks, and content delivery networks. In these scenarios, network coding can significantly enhance data dissemination and control of overall network performance.

- In traditional routing networks, packets are cached and forwarded downstream. If a routing node receives two packets from sources it forwards one after another, and queues the others in the meantime, even if both are headed for the same destination.

- Network coding is based on a simple, yet far-reaching idea. In a packet network, rather than simply routing packets, intermediate nodes may compute and transmit functions of the packets that they receive.

- In order to intrinsically fix the problem with RLNC detailed above, where receivers that get an insufficient number of packets cannot recover the original packets, triangular network coding. The triangular pattern based packet coding scheme is performed in two stages.

- Interference is often treated as a destructive phenomenon in wireless communication networks today. When multiple transmitters send waves to their respective receivers, a receiver may receive signals from its transmitter as well as from other transmitters at the same time.

- Video on demand can be considered as a specialized form of file download where the pieces of the downloaded file have to arrive in order and must be decoded in real time, taking into account some small delay.

- Network coding is coding at a node in a network with error-free links. This distinguishes the function of network coding from that of channel coding for noisy links; we can similarly distinguish the function of network coding from that of source coding by considering the former in the context of independent source processes.
