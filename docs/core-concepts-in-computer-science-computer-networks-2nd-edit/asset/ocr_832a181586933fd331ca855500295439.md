The 802.1X standard can be implemented with different EAP types, including EAP-MD5 (defined in

RFC 2284 and supporting only one-way authentication without key exchange for Ethernet LANs and EAP-TLS (defined in RFC 2716, supporting fast reconnect, mutual authentication and key management via certificate authentication). Currently a new generation of EAP methods are being developed within the IETF, focused on addressing wireless authentication and key management issues. These methods support additional security features such as cryptographic protection of the EAP conversation, identity protection, secure ciphuite negotiation, tunneling of other EAP methods, etc. For the latest developments on the status of each specification, the reader is encouraged to refer to the IEEE 802.11 standards web site.

# CORE CONCEPT:
WIRELESS PERSONAL AREA NETWORKS

![](bbox=[0.102, 0.325, 0.37, 0.442])

A WPAN (wireless personal area network) is a personal area network - a network for interconnecting devices centered around an individual person’s workspace - in which the connections are wireless. Typically, a wireless personal area network uses some technology that permits communication within 10 meters - in other words, a very short range.

A wireless personal area network (WPAN) is a type of communication network that enables connectivity among personal devices within a limited geographic area. It allows individuals to connect and exchange data seamlessly between various devices, such as smartphones, laptops, tablets, smartwatches, and other portable gadgets. The primary objective of a WPAN is to create a small-scale network that facilitates data transfer and communication without the need for physical wires or cables.

WPANs are designed to cover a limited range, typically spanning from a few meters to a tens of meters, making them suitable for personal and localized applications. Bluetooth and Zigbee are common technologies used for establishing WPAN connections. Bluetooth, being widely adopted, allows devices to communicate in close proximity, making it ideal for applications like hands-free calling, wireless audio streaming, and file sharing between smartphones and other compatible devices.

Zigbee, on the other hand, is more commonly in home automation and Internet of Things (IoT) applications. It is well-suited for low-power devices that need to communicate with a central hub or gateway. Zigbee WPANs can efficiently manage a large number of devices, enabling smart homes and smart buildings, where appliances, sensors, and other IoT devices can interact and share data.
