# MULTIPLE CHOICE QUESTIONS

1. Which layer of the OSI model is responsible for framing and error detection in data transmission?

+   a. Network Layer
b. Data Link Layer
c. Physical Layer
d. Transport Layer

2. What is the main purpose of the Media Access Control (MAC) sublayer in the Data Link Layer?

+   a. Framing data packets
b. Error detection and correction
c. Controlling access to the physical medium
d. Routing data packets between networks

3. Which of the following is NOT a common function of the Logical Link Control (LLC) sublayer?

+   a. Framing data packets
b. Addressing devices on the network
c. Error detection and correction
d. Flow control

4. In Ethernet networks, what is the standard size of the MAC address (Media Access Control address)?

+   a. 24 bits
b. 32 bits
c. 48 bits
d. 64 bits

5. Which protocol is commonly used for point-to-point communication and provides error detection but not error correction?

+   a. HDLC (High-Level Data Link Protocol)
b. PPP (Point-to-Point Protocol)
c. ARP (Address Resolution Protocol)
d. SLIP (Serial Line Internet Protocol)

# Answers

1. (b) 2. (c) 3. (a) 4. (c) 5. (b)
