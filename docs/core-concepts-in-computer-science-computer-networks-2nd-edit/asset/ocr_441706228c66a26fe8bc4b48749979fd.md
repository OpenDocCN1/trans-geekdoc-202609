+   - Time Division Multiplexing (TDM): It is a digital multiplexing technique for combining several low-rate channels into one high-rate one. TDM is a digital process that allows several connections to share the high bandwidth of a link Instead of sharing a portion of the bandwidth as in FDM, time connection occupies a portion of time in the link. Digital data from different sources are combined into one timeshared link. However, this does not mean that the sources cannot produce analog data; analog data can be sampled, changed to digital data, and then multiplexed by using TDM.

# Types of TDM

Types of TDM are as follows:

+   - Synchronous TDM: In synchronous TDM, a round of data units from each input connection is collected into a frame. If one has N connections, a frame is divided into N time slots and one slot is allocated for each unit, one for each input link. If the duration of the input unit is T, the duration of each slot is Tin and the duration of each frame is T. The data rate of the output link must be N times the data rate of a connection to guarantee the flow of data. Time slots are grouped into frames. A frame consists of one complete cycle of time, with one slot dedicated to each sending device. In a system with N input lines, each frame has N slots, with each slot allocated to carrying data from a specific input line.
