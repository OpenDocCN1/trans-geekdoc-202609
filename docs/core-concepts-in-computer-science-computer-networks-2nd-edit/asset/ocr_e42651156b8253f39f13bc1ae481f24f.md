The first mobile to be considered a smartphone was designed by IBM in 1992. Given the name of Simon, the device made an appearance at COMEX that year, and was offered to the public up to that time had only been available on desktop and laptop computers were included in the functionality. Simon included a calculator, simple note pad, the ability to send and receive faxes, and an email component. In short order, the device provided a few games for the user to enjoy, as well as a handy world clock that allowed the user to view current times in major cities around the world.
