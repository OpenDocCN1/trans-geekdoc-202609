# Protocol 6

This protocol employs the selective reject technique. The protocol does not discard good frames because an earlier frame was damaged or lost provided that these good frames fall within the receiving window.

Associated with each outstanding frame is a timer. When the transmitter is notified of any error), that only one frame is retransmitted, not all the outstanding frames, as in protocol 5.

In this protocol, the receiver's window size is fixed, the maximum of which is (MaxSeq+1)/2. The maximum number is then chosen to ensure that there will not be an overlapping between the new window and the previous window.
