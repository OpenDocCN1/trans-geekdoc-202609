# Statistical Time-Division Multiplexing

Communication channel or simply refers either to a physical transmission medium such as a logical connection over a wire, or to a multiplexed medium such as a radio channel in telecommunications and computer networking.

Statistical time-division multiplexing is used to transmit various types of data concurrently across a single transmission cable. This is often used for managing data transmitted via LAN or WAN. The data is simultaneously transmitted from the input devices that are connected to the network including printers, fax machines, and computers. This type of multiplexing is also used in telephone switch board settings to manage the calls. Statistical TDM is similar to dynamic bandwidth allocation, in this type of time-division multiplexing, a communication channel is divided into an arbitrary number of data streams.
