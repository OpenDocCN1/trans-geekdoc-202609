

# 蓝牙概述

如今的自组织网络基于蓝牙技术。蓝牙是一种短距离数字无线电的开放标准。它被誉为一种低成本、低功耗、外型的技术，提供了一种按需创建小型无线网络的机制。蓝牙被认为是一种无线局域网（PAN）技术，为语音和数据提供快速可靠的传输。无绳蓝牙设备将消除电缆的需求，并为现有网络提供桥梁。

蓝牙可将任何设备连接到任何其他设备。例如 PDA 与手机之间的连接。蓝牙的目标是在办公室或家庭等小型环境中将不同的设备（PDA、手机手机、打印机、传真机等）无线连接起来。根据该技术的领先倡导者的说法，蓝牙是一种最终将——

- 消除固定设备与移动设备之间的电线和电缆
- 促进数据和语音通信
- 提供自组织网络的可能性并实现个人设备间的同步性。

蓝牙设计用于在免许可的 ISM（工业、科学、医学应用）频段运行，该频段在全球大部分地区可用，但在某些地区有所差异。蓝牙的特性总结在表 3 中。支持蓝牙的设备会自动找到彼此，但与其他设备建立连接和形成网络需要用户操作。

与所有的自组织网络一样，蓝牙网络拓扑结构是在临时和随机的基础上建立的。蓝牙网络的一个特征是网络设备之间维持的主从关系。多达八个蓝牙设备可以以主从关系连接在一起，被称为“微网”（piconet）。在微网中，其中一个设备被指定为网络主设备（master）；主设备负责控制和设置网络（包括定义网络的跳频序列）。蓝牙微网中的设备在相同的信道上运行，并遵循相同的跳频序列。每个网络只能有一个设备充当主设备；一个网络中的从设备可以作为其他网络的主设备，从而创建网络链。这一系列微网被称为“散点网络”（scatter-networks），允许多个设备在较远距离上进行互联。这种关系还允许在任何会话期间可能变化的动态拓扑结构：当设备靠近或远离网络中的主设备时，拓扑结构以及即时网络中设备的关系就会随之改变。

蓝牙网络中的移动路由器控制这些网络不断变化的网络拓扑结构。路由器还控制能够支持直接链路的设备之间的数据流。当设备以随机方式移动时，这些网络必须重新配置以处理动态拓扑结构。它们采用的路由协议利用蓝牙建立和维护这些切换的网络。

蓝牙收发器工作在 2.4 GHz ISM 频段，该频段与 WLAN 设备和其他符合 IEEE 802.11 标准的设备相似。蓝牙收发器使用高斯频率键控 (GFSK) 调制，采用跳频 (FH) 扩频系统，在 79 个频率上以准随机方式每秒跳变 1,600 次。蓝牙网络的理论最大带宽为 1 Mbps。然而，在现实中，由于通信开销，网络无法支持这样的数据速率。第二代蓝牙技术预计将提供 2 Mbps 的最大带宽。

蓝牙网络可以支持一个带有最多三个同步语音通道的异步数据信道，或一个同时传输异步数据和同步语音的信道。

蓝牙使用了分组交换技术和电路交换技术的结合。在蓝牙中使用分组交换的优势是，它允许设备通过同一条数据路径路由多个信息包。由于这种方法不会消耗数据路径上的所有资源，远程设备更容易在整个散点网络中维护数据流。

# 简史

蓝牙的原始架构师是以 10 世纪丹麦国王哈拉尔德·蓝牙（Harald Bluetooth）命名的爱立信通信公司（Ericsson Communication）。1998 年，IBM、英特尔、诺基亚和东芝成立了蓝牙 SIG，它是该规范的制定机构。SIG 起初是作为监控无线技术发展以及创建全球性开放标准的手段。如今，有超过 2,000 个组织加入了蓝牙 SIG，其中包括电信和计算行业的领导者，他们推动了蓝牙的发展和推广。蓝牙最初主要设计作为无线通信的电缆替代方案。然而，成员们计划开发广泛的蓝牙设备以增强无线连接。预计的设备范围包括手机、PDA、笔记本电脑、调制解调器、寻呼机、笔记本电脑、摄像头、电脑传真机和打印机。蓝牙现在由 1999 年形成的 IEEE 802.15 个人区域网（PAN）工作组进行标准化。蓝牙 SIG 网站提供了指向其他信息的链接。IEEE 网站提供了 IEEE 802.15 工作组的更新。该工作组负责开发短距离无线网络（或 WPAN）的个人区域网络共识标准。

# 频率与速率

蓝牙的设计者与 802.11 WLAN 标准的设计者一样，将蓝牙设计在免许可的 2.4 GHz–2.4835 GHz 频段运行。由于许多其他技术也在此频段运行，蓝牙使用跳频扩频 (FHSS) 技术来解决干扰问题。该 FHSS 方案使用 79 个不同的通道，每秒跳变 1,600 次。一个信道使用 625 微秒，然后按照准随机顺序跳到另一个信道进行 625 微秒的传输；此过程持续进行。如前所述，ISM 频段因其在全球可用且无需许可而在无线通信中变得流行。
