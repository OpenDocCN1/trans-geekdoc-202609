# MULTIPLE CHOICE QUESTIONS

+   1. Network coding is a technique used in:
na. Error correction
b. Data compression
sc. Data encryption
d. Data transmission

+   2. In network coding, a node combines multiple incoming data packets to create:
a. Redundant packets
b. Encrypted packets
sc. Composite packets
d. Unique packets

+   3. Network coding is particularly beneficial in which type of networks:
a. Small local networks
b. Point-to-point networks
sc. Large-scale, distributed networks
d. Cellular networks

+   4. The key advantage of network coding is:
a. Improved network security
b. Reduced latency in data transmission
sc. Increased data throughput
d. Extended range of wireless networks

+   5. Which type of network coding allows intermediate nodes to combine data packets from different sources:
a. Random linear network coding
b. Deterministic network coding
sc. Incremental network coding
d. Opportunistic network coding

# Answers

1. (d)    2. (c)    3. (d)    4. (c)    5. (d)
