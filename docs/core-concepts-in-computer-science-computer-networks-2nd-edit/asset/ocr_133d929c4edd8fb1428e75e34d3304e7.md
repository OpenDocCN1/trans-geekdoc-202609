# Dynamic WEP

Before an attacker can access to a WEP protected network, he needs to capture a large quantity of data packets to crack the shared secret key. If the wireless network did not change the shared secret key every time the attacker could enough data packets to crack the secret key, it will make it much harder to crack the secret key. Therefore, a way to prevent a possible secret recovery without making any other vulnerability is by changing the shared secret key frequently. Using the current WEP mechanism could be very troublesome because it does not include any automatic key rotation system that could support this

# WPA (Wi-Fi Protected Access)

WPA is a solution released by the Wi Fi Alliance while a definitive security protocol is standardized. This security protocol is based on 802.11i, the next 802.11 wireless network security protocol standard. WPA consists of three main components: TKIP, 802.1x, and MIC. Each component was designed and implemented to address specifics 802.11 weakness Important security improvements were implemented, such as hierarchy that protects and practically nullifies the exposure WPA main key from attacks and implementing 802.1ix protocol for access control to the network. Using key hierarchy means that WPA does not directly use the main key to encrypt, instead the main key (Pairwise Master Key) is used to generate other temporal keys as session keys, group keys, etc; and recursively the session key is used to generate the per-packet encryption key. The IV is also expanded from 24 bits to 48 bits long and assigning it another role as a sequence counter for avoiding replay attacks. Improvement in packet protection is made by implementing a specially designed cryptographically protected hashing function using the CRC32 linear function.
