Because advances in the art allow regular increases in the complexity of PLDs, the size of the programmable interconnect array must also be increased to achieve the desired PLD complexity.

A Programmable Logic Device (PLD) is a digital integrated circuit that can be programmed to perform specific logic functions or tasks. It is a versatile semiconductor used in digital electronics and is capable of being reconfigured or configured after manufacturing.

Unfortunately, a significant amount of power and die is consumed in the programmable elements of the programmable interconnect array. Additionally, the programmable interconnect array introduces a significant speed limit due to capacitive loading by the programmable elements therein. Thus, increasing the size of the programmable interconnect array leads to higher power consumption and lower PLD speed. Thus, as larger PLDs are designed, the programmable elements themselves become an increasingly critical, limiting factor.

One problem with this PLD is that multiplexer 101 requires a discrete control signal for each multiplexer connection. While this arrangement is acceptable for PLD designs that only require a small number of multiplexers, PLD designs require a larger number of multiplexers also require a larger number of control signals. For example, multiplexers are typically arranged in arrays that have 450 multiplexer connections (126 input×3 connections per input line (which includes both input and feedback connections)+36 ground connections+36 UIM connections). A typical PLD may have up to six such multiplexers, therefore requiring 2700 multiplexer connections, which in turn necessitate 2700 control signals through which a PLD is unexpectedly complex.

Conventional multiplexers allow only two entry points for any multiplexer input line to any multiplexer output line. In other words, each input line in a prior multiplexer is connectable to 2 output lines. If a specific user design requires several input signals must be routed into a function block (which includes multiplexer 101, AND array 102 and macro cells 103), it becomes exceedingly difficult to route signals through the multiplexer successfully. If routing through the multiplexer is impossible, then multiplexer input signals, typically under control of the programming software that is used to configure the PLD, must be switched to different lines.
