Cellular networks are networks where the last link is wireless. The network is distributed over land area cells, each served by at least one fixed-location transceiver, but more normally three cells or base transceiver stations.

After handoffs, congestion avoidance probes the capacity of the new link. With other wireless losses though, retransmissions are sufficient for recovery. Since end-to-end retransmissions are slow, TCP connections can be split using pivot routers connected to both wireless and wired links. End-to-end connections are decomposed into separate TCP schemes for the wired and wireless parts of the path. Another protocol optimized for error recovery may be substituted over the wireless links. Split schemes violate TCP semantics, as acknowledgments may reach the sender before data packets reach their destination. To preserve TCP semantics, acknowledgments must be delayed, reducing throughput. Pivot points face significant overhead, as packets undergo TCP processing twice, and considerable connection state is maintained there.

# Link Layer Solutions

In CC systems this is achieved by non-transparent mode RLPs. Another solution is to perform local error recovery (a link layer task) at the IP level, in Snoop TCP. Snoop tracks TCP data and acknowledgments by maintaining state of each connection traversing a pivot point. Snoop caches unacknowledged TCP packets and uses the loss indications conveyed by duplicate acknowledgments, plus local timers, to transparently retransmit lost data. It hides duplicate acknowledgments indicating wireless losses from the TCP sender, preventing redundant TCP recovery. Snoop exploits the information in TCP packets to avoid layer control overhead. It outperforms split TCP schemes, and it also avoids conflicting local and TCP retransmissions by suppressing duplicate acknowledgments. Snoop requires the TCP receiver to be located right after the pivot point. If a wireless host is sending data to a remote receiver, TCP acknowledgments are returned too late for efficient recovery, and they may even signify congestion losses. CC system RLPs avoid the layering violations of Snoop, which examines TCP headers at the IP level, but may retransmit data in parallel with TCP. This occurs rarely with fully reliable RLPs and is prevented by abandon recovery after several failed attempts. Link layer schemes operate at the local level with low round trip delays that allow recovery, in contrast to TCP modifications. Their main limitation is that they offer a single level of recovery, which may not be appropriate for higher layer protocols and applications.

# Wireless System Evolution and TCP

The trend for CC systems is to provide increased speeds and better support for packet data services. The highest data rates will be offered in small areas, or microcells, where user densities are higher. The High Speed Circuit Switched Data (HCSCD) system is a GSM extension providing bit rates of up to 56 Kbps by reserving multiple TDMA slots for each data circuit. The General Packet Radio Service (GPRS) is a packet switched GSM extension. GPRS provides bit rates of up to 171 Kbps via dynamic TDMA slot reservation. Current implementations provide 20-40 Kbps of user throughput. Experiments show that Internet packet loss rates are around 2%. The third generation European CC system, UMTS, is based on wideband CDMA, supporting both circuit and packet switched modes, at various bit rates. Phase one includes services similar to GPRS, providing bit rates of up to 384 Kbps, with promises up to 2 Mbps in mobile areas. In the USA, the GSM EDGE/S-136 system will provide bit rates of 270-722 Kbps, or over 20 Mbps in mobile areas.

Many short (in room) systems, or Personal Area Networks (PANs), have been designed for low bit rates, such as Bluetooth, a FH frequency spectrum system providing bit rates of 400-700 Kbps. Bluetooth should provide TCP performance for low end WLANs, where there are serious problems concerning its radio link level interoperability with IEEE 802.11. The IEEE 802.15 project specifies a PAN standard based on Bluetooth is working on this issue. For very high speeds, the Local Multipoint Distribution System (LMDS) will offer broadband fixed wireless internet access using the 28 or 40 GHz frequency bands. LMDS is a Wireless Local Loop (WLL) system providing 1-2 GHz of bandwidth to fixed hosts. LMDS uses powerful link layer FEC schemes, and we have found that it can reliably carry TCP traffic.

# IP Networks

The Internet protocol (IP) is the primary network protocol used on the Internet, developed in the 1970s. On the Internet and many other networks, IP is used to identify devices on a network. Each device is assigned a unique IP address, which is used to route data packets to the correct destination. There are two main versions of IP addresses in use: IPv4, which uses a 32-bit address, and IPv6, which uses a 128-bit address. IPv4 was designed when the number of connected devices was expected to be small, but its growth, IPv6 was developed to provide a much larger address space.
