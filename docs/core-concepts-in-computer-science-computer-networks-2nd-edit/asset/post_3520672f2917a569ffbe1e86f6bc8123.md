# INTRODUCTION

Network software and standardization are two essential aspects of computer networking that play crucial roles in seamless communication and interoperability among devices and systems. Both concepts are fundamental in establishing reliable, efficient, and scalable networks that meet the diverse communication needs of the modern world.

Network software refers to the collection of programs, protocols, and applications that enable the functioning and management of computer networks. It plays a critical role in facilitating data transfer, resource sharing, and communication between devices within a network. Network software encompasses various layers of the networking stack, from the physical layer that deals with the transmission of raw data bits, to the application layer that provides user-friendly interfaces and services.

In addition to communication protocols, network software also includes network management tools, security applications, and monitoring utilities that ensure the network operates efficiently, securely, and with minimal downtime. Network administrators use these software tools to configure devices, monitor network performance, and troubleshoot issues as they arise.

Network standardization involves the development and implementation of agreed-upon rules, protocols, and conventions that ensure uniformity, compatibility, and interoperability across different network devices and systems. Standardization is essential because it allows devices from various manufacturers to communicate effectively, regardless of their origin or underlying technology.

Moreover, network standardization fosters innovation by providing a common foundation for the development of new networking technologies and applications. It also simplifies network management and troubleshooting, as standardized protocols and interfaces are well-documented and widely understood within the industry.

# CORE CONCEPT: THE OSI MODEL

OSI (Open Systems Interconnection) is a reference model for how applications communicate over a network. A reference model is a conceptual framework for understanding relationships. The purpose of the OSI reference model is to guide vendors and developers so the digital communication products and software programs they create can operate, and to facilitate a clear framework that describes the functions of a networking or telecommunication system.

International standards organization/open system interconnection (ISO/OSI) model is a standard reference model for communication between two ends in a network. It can be helpful to have a basic understanding of how the network works in order to troubleshoot future problems.

It would be difficult to overstate the importance of the OSI model. Virtually all networking vendors and users understand how important it is that network computing products adhere to and fully support the networking standards this model has generated. When a vendor's products adheres to the ISO model has generated, connecting those products to other vendors' products is relatively simple. Conversely, the further a vendor departs from those standards, the more difficult it becomes to connect that vendor's products to those of other vendors.

In addition, if a vendor were to depart from the communication standards the model has engendered, software development efforts would be very difficult because the vendor would have to build every part of all necessary software, rather than being able to build on the existing work of other vendors.

The first two problems give rise to a third significant problem for vendors: a vendor's products become less marketable as they become more difficult to connect with other vendors' products.

Thus, the ISO model defines a networking framework for implementing protocols according to layers. Each layer is functionally independent of the others, but provides services to the layer above and it receives services from the layer below.

The layers are in two groups. The upper layers are used whenever a message passes from or to a user. The lower layers are used when any message passes through the host computer. Messages intended for this computer pass to the upper layers but are not passed to another host.

# Layers of OSI Model

Layers of OSI model are as follows:

- Application layer

# Application Layer

The application layer enables the user, whether human or software, to access the network. It provides user interfaces and support for services such as electronic mail, remote file access and transfer, shared database management, and other types of distributed information services.

Specific services provided by the application layer include as:

- Network Virtual: A network virtual terminal is a software version of a physical terminal and allows a user to log on to a remote host. To do so, the application creates a software emulation of a terminal at the remote host. The user's computer talks to the software terminal, which, in turn, talks to the host, and vice. The remote host believes it is communicating with one of its terminals and allows one to log on.
- File Transfer, Access, and Management (FTAM): This application allows a user to access files in a remote computer (to make changes or read data), to retrieve files from a remote computer; and to manage or control files in a remote computer.
- Mail Services: This application provides the basis for e-mail forwarding and storage.
- Directory Services: This application provides distributed database sources and access for global information about various objects and services.

# Presentation Layer

The presentation layer is where received data is converted into a format that the application is destined for. The work done at this layer is best understood as a translation job. For example, data is often encrypted at the presentation layer before being passed to the other layers for sending. When data is received, it will be decrypted and passed on to the application it is intended for in the format that is expected.

Specific responsibilities of the presentation layer include:

- Translation: The processes (running programs) in two systems are usually exchanging information in the form of character strings, numbers, and so on. Because different computers use different encoding systems, the presentation layer is responsible for interoperability between these different encoding methods. The presentation layer at the sender changes the information from its sender-dependent format into a common format. The presentation layer at the receiving machine changes the common format into its receiver-dependent format.
- Encryption: To carry sensitive information, a system must be able to assure privacy. Encryption means the sender transforms the original information to another form and sends the resulting message out over the network. Decryption reverses the original process to transform the message back to its original format.
- Compression: Data compression reduces the number of bits to be transmitted. Data compression becomes particularly important in the transmission of multimedia such as text, audio, and video.
