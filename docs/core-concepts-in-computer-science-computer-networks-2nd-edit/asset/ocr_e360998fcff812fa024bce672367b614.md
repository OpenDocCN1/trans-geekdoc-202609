The transport stream clock should go with the data so TS input port and TS output port should be configured as follows for chaining:

+   * TS Output: Clock Direction: generate
* TS Output: Frame size: 188 Byte
* TS Output: Clock rate
* TS Input Mode: External click

The transport stream clock rate should be the sum of all TS sources connected to the multiplexer plus a safety margin of approximately 10%. Let one assumes that a Midi Mux with four connected encoders, each set to a data rate of 4,000 Kbit/s. This gives a total data rate of 16,000 Kbit/s for this Midi Mux's TS output. With the safety margin, one should set the TS Output Clock rate to 18,000 Kbit/s. The next Midi Mux in the chain receives this stream at one of its TS inputs and adds another three services from encoders connected to the other three TS inputs again with 4,000 Kbit/s. This gives us 7 times 4,000 Kbit/s at the output of this Midi Mux. With the safety margin, one sets the TS output to 32,000 Kbit/s.

# Digital Demultiplexers

Demultiplexer means one to many. A demultiplexer is a circuit with one input and many outputs. By applying control signal, one can steer any input to the output. Few types of demultiplexer are 1-to-2, 1-to-4, 1-to-8 and 1to 16 demultiplexer.
