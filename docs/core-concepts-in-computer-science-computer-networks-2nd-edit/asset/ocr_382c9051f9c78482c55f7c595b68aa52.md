distributed manner. A real life example is BitTorrent, the original, and still the most popular protocol for P2P downloading. In BitTorrent, the file is evenly divided into h pieces. Each node obtains pieces of the file from its neighbors, until the node obtains all h pieces and can leave the network. After a node obtains a new piece, it announces this acquisition to its neighbors, so that every node knows which pieces every neighbor has. Nodes typically request a rarest block, is, a block that is least common among all of the node's neighbors. Without network coding, each node would have to decide which blocks to download solely on the information it could glean from its neighbor nodes. This could lead to inefficient downloading blocks, since blocks that are rare when considering the entire network. With network coding, however, since coded blocks are aggregates, all coded blocks are almost equally useful to any node and as there is no need to locate and request rarest blocks in the network. This prevents an information bottleneck and decreases the file downloading time.

# Video on Demand, Live Media Broadcast, and Instant Messaging (IM)

Video on demand can be considered as a specialized form of file download where the pieces of the downloaded file have to arrive in order and be decoded in real time, taking into account some small delay. Network coding can be applied in this case by breaking the file into chunks, which can be downloaded sequentially. A similar technique can be used with live media broadcast. Early decoding can be used to further reduce delay. Instant messaging is also similar to live broadcast, but with a lower bit rate, since only text is being sent. Text messages are also more often sent in clumps or bursts, and have a less strict delay constraint. However IM frequently includes larger messages as images and audio clips. Flooding, which is usually used for IM in P2P networks, is inefficient when used on larger files. Network coding can be applied in all of these cases to improve efficiency in overlay networks.
