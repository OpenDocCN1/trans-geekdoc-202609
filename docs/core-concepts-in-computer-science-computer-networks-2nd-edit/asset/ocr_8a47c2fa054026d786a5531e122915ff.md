# MULTIPLE CHOICE QUESTIONS

+   1. Which of the following is a key security concern in wireless networks?
a. Data encryption
b. Physical access control
c. Data center management
d. Printer configuration

+   2. Which security protocol provides a secure method for connecting to a wireless network?
a. WEP (Wired Equivalent Privacy)
b. WPA (Wi-Fi Protected Access)
c. MAC (Media Access Control)
d. DNS (Domain Name System)

+   3. What is the primary purpose of a firewall in a wireless network?
a. To amplify the wireless signal
b. To prevent unauthorized access to the network
c. To manage the network's IP addresses
d. To enable Bluetooth connectivity

+   4. What is a “Man-in-the-Middle” attack in the context of wireless network security?
a. A hacker gaining physical access to the wireless router
b. A hacker eavesdropping on wireless network communications
c. A hacker intercepting and altering data between two parties
d. A hacker stealing Wi-Fi passwords from nearby devices

+   5. Which security measure helps to hide the network's SSID (Service Set Identifier) from being visible to nearby devices?
a. VPN (Virtual Private Network)
b. NAT (Network Address Translation)
c. SSID broadcast disable
d. MAC filtering

# Answers

1. (a)    2. (b)    3. (b)    4. (c)    5. (c)
