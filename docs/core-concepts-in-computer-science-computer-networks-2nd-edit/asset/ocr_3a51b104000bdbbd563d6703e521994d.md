+   The Information Transfer (I) PDU: It carries out a numbered information transfer in Type 2 operations.

+   The Supervisory (S) PDU: It carries out acknowledgement, retransmits requests and suspends of I PDUs in Type 2 operations.

+   The Unnumbered (U) PDU: It carries out some control functions and un-sequenced information transfer in Type 1 operations.

# Subnetwork Access Protocol (SNAP)

SNAP refers to a protocol used in computer networking to provide a standard method for encapsulating higher-layer network protocols within a data link frame.

There is the special case of sub network access protocol (SNAP) where the DSAP and SSAP are set to AA and the control field set to 03. Then, immediately after the control fields there are three bytes set aside for the organizational unique identifier (OUI) and then two bytes for the Protocol Identifier (PID).

The SAP is generally used for the 802.x compliant protocols; however, the idea of SNAP is to allow non-IEEE compliant protocols to become pseudo-compliant without a major re-write of code for network drivers. An OUI of 00-00 indicates that the frame is an Ethernet frame rather than an 802.3 frame that is not assigned to any particular vendor. This is useful for when the frame crosses different media. On coming out the other side it will be rebuilt as an Ethernet frame rather than something else.
