This is far less computationally intensive and gives triangular coding the bandwidth performance of LNC, affording the computation cost of XOR coding.

# Opportunistic Network Coding

In ONC, the sensor nodes can snap on all transmissions in their neighborhood and store the overhead data packets, whether they are intended for them or not. As such, the sensor nodes know the overhead and routed packets that each neighboring node possesses, and can perform network coding operations based on this information. Each node has its own queue of received uncoded packets $p_1,p_2,...,pn$, whose destinations, determined by their packet headers and the node's routing table, are $r_1,r_2,...,rn$. The node then dequeues the first packet, $p_j$, and while making sure of all next recipients can immediately decode the resulting combination, steps through the greedy to add packets for combination. A recipient can immediately decode a combined packet if it knows all one coded packet. For example, a combined packet $p_i+p_j+p_k+p_l$ is valid if $r_i$ knows $p_i$, $r_j$ knows $p_j$, and $r_k$ knows $p_k$ and $p_l$.
