# MULTIPLE CHOICE QUESTIONS

+   1. What is the primary function of the Physical Layer in data communication?
aa. Error detection and correction
b. Data routing and switching
c. Data encoding and signaling
d. Protocol definition

+   2. Which of the following defines the characteristics of the physical medium used for data transmission in the Physical Layer?
aa. Transport layer
b. Network layer
c. Data link layer
d. Physical layer

+   3. What is the purpose of bit synchronization in the Physical Layer?
a. To compress data for efficient transmission
b. To align the sender and receiver clocks
c. To detect and correct errors in data
d. To route data packets to their destinations

+   4. Which network topology is often associated with the Physical Layer in terms of physical connections between devices?
a. Star topology
b. Mesh topology
c. Ring topology
d. Bus topology

+   5. Which type of signals are used for data transmission in the Physical Layer?
a. Digital signals
b. Analog signals
c. Modulated signals
d. Encrypted signals

# Answers

1. (c) 2. (d) 3. (b) 4. (d) 5. (a)
