# MULTIPLE CHOICE QUESTIONS

1. Which of the following network topologies offers the highest level of fault tolerance and redundancy?

+   a. Bus
b. Star
c. Ring
d. Mesh

2. What is the primary function of a router in a computer network?

+   a. To connect devices within a local area network (LAN)
b. To connect multiple LANs to create a wide area network (WAN)
c. To connect devices to the internet
d. To connect devices via wireless mesh technology

3. Which network protocol is commonly used for secure communication over the internet, ensuring data encryption and authentication?

+   a. HTTP
b. FTP
c. TCP
d. SSL/TLS

4. Which network device operates at the Data Link Layer (Layer 2) of the OSI model and connects multiple devices in a LAN, using MAC addresses for data forwarding?

+   a. Hub
b. Switch
c. Router
d. Repeater

5. In a client-server network architecture, which of the following is responsible for storing and managing shared resources such as files, databases, and applications?

+   a. Client
b. Server
c. Switch
d. Router

# Answers

+   1. (d) 2. (b) 3. (d) 4. (b) 5. (b)
