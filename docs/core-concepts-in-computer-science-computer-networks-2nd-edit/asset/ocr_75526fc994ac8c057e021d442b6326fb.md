# SUMMARY

+   - A computer network is a system that connects two or more computing devices for transmitting and sharing information. Computing devices include everything from a mobile phone to a server.

+   - Computer networking is the branch of computer science that deals with the ideation, architecture, creation, maintenance, and security of computer networks. It is a combination of computer science, computer engineering, and telecommunication.

+   - Computer networks are intricate systems that facilitate the seamless exchange of data and resources among connected devices. Their nature is characterized by interconnectedness, communication protocols, scalability, and the ability to share information across various geographic locations.

+   - A computer network is interconnection of various computer systems located at different places. In computer network two or more computers are linked together with a medium and data communication devices for the purpose of communicating data and sharing resources.

+   - A computer network facilitates interpersonal communications allowing users to communicate efficiently and easily via various means: email, instant messaging, online chat, telephone, video telephone calls, and video conferencing.

+   - Computer networks have significantly transformed the landscape of education, the way knowledge is accessed, disseminated, and shared.

+   - A broadcast network is a type of computer network that employs a broadcasting method to transmit data from one sender to multiple receivers. In this network model, data packets are broadcasted over the network, and all connected devices receive the transmitted data.

+   - Point-to-point networks consist of many connections between individual pairs of machines. To go from the source to the destination, a packet on this type of network may have to visit one or more intermediate machines.

+   - Point-to-point networks, also known as P2P networks, are a type of computer network where a direct connection is established between two devices, enabling communication between them. These networks have distinct characteristics that set them apart from other network topologies.
