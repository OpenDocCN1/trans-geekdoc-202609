# Wireless Networks

Wireless network is a network set up by using radio signal frequency to communicate among computers and other network devices. Sometimes it is also referred to as WiFi network or WLAN. This network is getting popular nowadays due easy to setup feature and no cabling involved. You can connect computers anywhere in your home without the need for wires.

![](bbox=[0.196, 0.526, 0.812, 0.735])

Here is simple explanation of how it works, let say you have 2 computers each equipped with wireless adapter and you set up wireless router. When the computer send out the data, the binary data will be encoded to radio frequency and transmitted via wireless router. The receiving computer will then decode the signal back to binary data.

It does not matter you are using broadband/DSL modem to access internet, both ways will work with wireless network. If you heard about wireless hotspot that location is equipped with wireless devices for you and others to join the network.
