# 3.1. Model performance

The descriptors MACCS, ECFP and FCF are denoted as M, E and F, respectively. Based on feature, machine learning models for predicting adsorption using five traditional algorithms: random forest (RT), gradient boosting decision tree (GBRT), extreme support vector machine (SVM). The performance of these models is evaluated via grid search methods, in Table S2. As shown in Fig.a, the R² values of the features are relatively low, with the GBM algorithm achieving the highest R². In Fig.b, we compare the GBR model with the DNN model based on M. The results indicate that the DNN achieved an R² of 0.82, significantly higher than the R² of GBR. This demonstrates the superior prediction capabilities of deep learning algorithms. Subsequently, DNN models are established using E and F as features respectively.

Before constructing the model, the Pearson correlation between the features M, E and F is calculated. As shown in Fig.4c, the lowest correlation is observed between M and E, suggesting that the combination of M and E may have a complementary effect, leading to higher predictive accuracy of hybrid fingerprint model.

As illustrated in Fig. 4d, taking the hybrid fingerprint model named ME-DNN as an example, we is established to connect different types of molecular fingerprints. All types of fingerprints are trained simultaneously, they remain independent of being in different neural layers, which is advantageous for learning to organize feature information and weights. Among the four types of hybrid features, the ME-DNN model achieved the highest R² of 0.85 and the lowest MSE of 0.007. Due to the significantly increased dimensionality of the hybrid fingerprint, the predictive accuracy is improved compared to models based on individual M, E and F fingerprints, it is better than ME-DNN.
