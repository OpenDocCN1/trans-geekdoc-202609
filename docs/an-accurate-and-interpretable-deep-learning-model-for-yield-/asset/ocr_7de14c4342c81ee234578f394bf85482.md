# 2.2. Deep learning

In this study the deep learning of fully connected neural network (DNN) is employed because it offers a flexible minimal time and adjustable architecture, which is easy to interpret by proxy models. DNN models typically consist of input, hidden, and output layers. The input vectors comprise experimental parameters and features, hyperparameters such as the number of hidden layers are selected via grid search methods, detailed in Table S1 and Fig.-S7. Within the hidden layers, the rectified linear (ReLU) serves as the activation function.

Given that this focuses on predicting yield, from 0 to 1, ReLU in the output layer may lead to negative values. To address this, a new function called Rus, based on ReLU, is developed for the output layer.
