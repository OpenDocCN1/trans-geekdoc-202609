## 2.4. 模型评估

在本研究中，我们利用了温度 (T)、压力、反应时间以及指纹等输入参数。输出参数是 CO2 环加反应组的产率。数据集被分为训练集和测试集。训练集包含 481 个数据点，而测试集包含剩余的 50 个点。在集合上训练模型后，模型对训练集和测试集进行预测。计算预测值与原始数据之间的误差以得到准确率。为了评估 ML 模型在 CO2 环加反应中的性能，使用了 $R^2$ 和均方误差 (MSE)。

```
phi_i(x_i) + \phi_1(x_i) + ... + \phi_n(x_i) = f(x_i) - \bar{y}
```

其中 $\phi_i(x_i)$ 表示特征对预测准确性的影响。$y_i$ 是真实值，$\hat{y}_i$ 是该样本的预测值。如果 $\phi_i(x_i) > 0$，说明该特征增强了预测，表现为正影响；相反，如果 $\phi_i(x_i) < 0$，则它降低了预测，表现为负向影响。每个特征的 SHAP 值代表了其在预测中的数值贡献。

```
R^2 = 1 - \frac{\sum_{i=1}^N (y_i - \hat{y}_i)^2}{\sum_{i=1}^N (y_i - \bar{y})^2}
```

```
MSE = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2
```

```
Y = \frac{1}{N} \sum_{i=1}^N y_i
```

对于整个模型，所有样本的目标变量的平均值 $Y$ 遵循以下方程：

```
Y = \frac{1}{N} \sum_{i=1}^N y_i
```
