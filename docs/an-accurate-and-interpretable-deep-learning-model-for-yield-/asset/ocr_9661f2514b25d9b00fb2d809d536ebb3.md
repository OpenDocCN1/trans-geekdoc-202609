SHapley exPlanations (SHAP) is a Python package designed to explain the performance of machine learning models. Derived from cooperative game theory, SHAP treats all features as contributors, establishing an additive explanation model. Unlike traditional "feature importance" methods which only explain the importance of features, SHAP can also explain how features influence prediction accuracy. For each predicted sample, the model generates a prediction value, and the SHAP value represents the numerical contribution of each feature in the prediction. # 2.4. Model evaluation

In this study, we utilize input parameters such as temperature (T), pressure, reaction time, and fingerprints. The output parameter is the yield of CO2 cycloaddition reaction sets. The dataset is divided into a training set and a test set. The training set contains 481 data points, while the test set contains the remaining 50 points. Following training models on the set, the model predicts for both training and test set. Error is calculated between predicted and original data to yield model accuracy. To assess the ML model' performance in CO2 cycloaddition reaction, statistical parameters including $R^2$ and mean squared error (MSE) are used as evaluation criteria.

```
$y_i = \phi_0 + \phi_1(x_i) + \phi_2(x_i) + ... + \phi_n(x_i)$
```

where $\phi_i(x_i)$ denotes the SHAP value of the ith feature of the final predicted value $y_i$. If $\phi_i(x_i) > 0$, it indicates that this feature enhances the prediction, showing a positive effect. Conversely, if $\phi_i(x_i) < 0$, it shows that the feature decreases the prediction, manifesting a negative effect. The [SHAP value] for each feature can reflect the overall importance of that feature as shown in the following equation:

```
$R^2 = 1 - \frac{\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{N}(y_i - \bar{y})^2}$
```

```
$MSE = \frac{\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{N_p}$
```

```
$Y_j = \frac{\sum_{i=1}^{N}|\phi_j(x_i)|}{N_f}$
```

In formula (3) and (4), $y_i$ is the actual output (experimental property), $\hat{y}_i$ is the predicted output of the model, and $N_p$ is the number of data points in the analyzed set. MSE is always greater than 0, measuring the average squared difference between predicted and actual values. The closer MSE is 0, the better the model's performance, indicating closeness to actual values. $R^2$ ranges from 0 to 1. It represents the proportion of the variance in the dependent variable that is predictable from the independent variables.
