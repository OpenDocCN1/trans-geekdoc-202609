# 3.2. Model interpretation

After constructing the model, the SHAP method is used to interpret the ME-NN model. As depicted in Fig. 5, the top ten features in the ME-NN model, reaction time, temperature, catalyst amount, and CO2 pressure exhibit the highest influence on yield, characterized by significant mean absolute SHAP values across features. In this plot, represent feature red colors indicate smaller values. It can be observed that for reaction time, temperature, catalyst amount, and CO2 pressure, feature values generally correlate with larger SHAP values. This pattern indicates that longer time, higher temperatures, increased catalyst amount, and higher pressures contribute to yields.
