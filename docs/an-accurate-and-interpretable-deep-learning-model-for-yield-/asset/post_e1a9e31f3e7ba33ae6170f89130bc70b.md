SHapley exPlanations (SHAP) is a Python package designed to explain the performance of machine learning models. Derived from cooperative game theory, SHAP treats all features as contributors, establishing an additive explanation model. Unlike traditional "feature importance" methods which only explain the importance of features, SHAP can also explain how features influence prediction accuracy. For each predicted sample, the model generates a prediction value, and the SHAP value represents the numerical contribution of each feature in the prediction. ## 2.4. Model evaluation

In this study, we utilize input parameters such as temperature (T), pressure, reaction time, and fingerprints. The output parameter is the yield of CO2 cycloaddition reaction sets. The dataset is divided into a training set and a test set. The training set contains 481 data points, while the test set contains the remaining 50 points. Following training models on the set, the model predicts for both training and test set. Error is calculated between predicted and original data to yield accuracy. To assess the ML model' performance in CO2 cycloaddition reaction, statistical parameters including $R^2$ and mean squared error (MSE) are used as criteria.

```
$y_i = \phi_0 + \phi_1(x_i) + \phi_2(x_i) + ... + \phi_n(x_i)$
```

where $\phi_i(x_i)$ denotes the SHAP value of the ith feature of the final predicted value $y_i$. If $\phi_i(x_i) > 0$, it indicates that this feature enhances the prediction, showing a positive effect. Conversely, if $\phi_i(x_i) < 0$, it shows that the feature decreases the prediction, manifesting a negative effect. The SHAP value for each feature can reflect the overall importance of that feature as shown in the following equation:

```
$R^2 = 1 - \frac{\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{N}(y_i - \bar{y})^2}
```

```
$MSE = \frac{\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}{N_p}
```

```
$Y_j = \frac{\sum_{i=1}^{N}|\phi_j(x_i)|}{N_p}
```

In formula (3) and (4), $y_i$ is the actual output (experimental property), $\hat{y}_i$ is the predicted output of the model, and $N_p$ is the number of data points in the set. MSE is always greater than 0, measuring the average squared difference between predicted and actual values. The closer MSE is 0, the better the model's performance. $R^2$ ranges from 0 to 1. It represents the proportion of the variance in the dependent variable that is predictable from the independent variables. A value closer to 1 indicates better model performance in explaining variability in the data.

## 2.6 DFT analysis

DFT is employed to calculate the energy barrier of the CO2 cycloaddition reaction. Since the B3PW91 method has been proved to work well the computation of ionic liquid catalyzed CO2 conversion, the geometries of reactants, products, intermediates states are estimated at B3PW91/631G(d,p). At the same level, the vibration frequencies of all stationary points are calculated to prove whether each structure is a stable point (without frequency) or a transition state (only imaginary frequency). Based on the transition state, we obtained the intrinsic reaction coordinate to prove that the optimized transition state connects the reactants and products. Based on these optimized states, the energy is refined using the polarized charge density model (PCM), M06/631G(d,p) with the solvent effect. All the DFT calculations are performed with Gaussian 09.

### 3.1. Model performance

The descriptors MACCS, ECFP and FCF are denoted as M, E and F, respectively. Based on feature, machine learning models for predicting adsorption using five traditional algorithms: random forest (RT), gradient boosting decision tree (GBRT), extreme support vector machine (SVM). The performance of these models is evaluated via grid search methods, in Table S2. As shown in Fig.a, the $R^2$ values of the features are relatively low, with the GBM algorithm achieving the highest $R^2$. In Fig.b, we compare the GBR model with the DNN model based on M. Subsequently, DNN models are established using E and F as features respectively.

As illustrated in Fig. 4d, taking the hybrid fingerprint model named ME-DNN as an example, we is established to connect different types of molecular fingerprints. All types of fingerprints are trained simultaneously, they remain independent of being in different neural layers, which is advantageous for learning to organize feature information and weights. Among the four types of hybrid features, the ME-DNN model achieved the highest $R^2$ of 0.85 and the lowest MSE of 0.007. Due to the significantly increased dimensionality of the hybrid fingerprint, the predictive accuracy is improved compared to models based on individual M, E and F fingerprints, it is better than ME-DNN.
