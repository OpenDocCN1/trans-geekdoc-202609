
# 课程总结

在课程的第一部分，我们讨论了机器学习的实际含义，介绍了机器学习中使用的一些最常见术语和概念，并确定了机器学习项目中涉及的常见组件。

我们了解到，机器学习涉及使用训练好的模型从数据中生成预测并检测模式。我们深入幕后，了解了实际发生的过程。我们还分解了机器学习中涉及的不同步骤或任务。

我们通过三个机器学习示例演示了每种方法如何解决现实世界的问题。

*   **监督学习任务**：使用机器学习根据地块大小和卧室数量预测您所在社区的房价。
*   **无监督学习任务**：使用机器学习根据书籍描述文本中的描述性词汇，在书籍数据集中找到有趣的书籍集合。
*   **深度神经网络应用**：使用深度神经网络从视频和图像中检测实验室中的化学泄漏。
