#### 术语

*   **词袋**：一种用于从文本中提取特征的技术。它统计单词在文档（语料库）中出现的次数，然后将该信息转换为数据集。
*   **数据向量化**：一种将非数值数据转换为数值格式的过程，以便机器学习模型使用。
*   **轮廓系数**：一个从 -1 到 1 的分数，用于描述建模过程中发现的簇。接近零的分数表示簇重叠，小于零的分数表示数据点被分配到了错误的簇。接近 1 的分数表示成功识别出了离散的非重叠簇。
*   **停用词**：自然语言处理工具在构建数据集时移除的一组单词。没有一份被所有自然语言处理工具通用的通用停用词列表。

## 示例三：从视频中检测溢出

在前两个示例中，我们使用了线性模型和 k-means 等经典方法来解决机器学习任务。在本示例中，我们将使用一种更现代的模型类型。

> **注意**：本示例使用神经网络。神经网络的工作算法超出了本课程的范围。不过，了解机器学习如何应用于这种情况仍然很有价值。

### 第一步：定义问题

想象你经营一家提供专业现场清洁服务的公司。一位客户——一家工业化工厂——需要对溢出物和其他健康隐患做出快速反应。你意识到，如果能利用工厂的监控系统自动检测溢出物，就能更快地调动清洁团队。

机器学习可能是解决此问题的宝贵工具。

*   包含溢出物
*   不包含溢出物

#### 第二步：构建数据集

*   **收集**

*   **探索与清洗**
    *   你浏览所有照片，确保溢出物清晰地在镜头内。有可用的 Python 工具和其他技术来提高图像质量，如果你确定需要迭代，稍后可以使用它们。

*   **划分数据**
    *   你将图像数据划分为训练数据集和测试数据集。

### 第三步：模型训练

传统上，解决此问题需要在底层像素之上手工设计特征（例如，图像中显著边缘和角点的位置），然后在这些特征上训练模型。

如今，深度神经网络是解决此类问题最常用的工具。许多深度神经网络模型的结构旨在学习底层像素之上的特征，因此你无需手工设计它们。你将有机会在下一课中深入了解这一点，因此我们目前保持在高层级。

#### CNN（卷积神经网络）

神经网络超出了本课程的范围，但你可以将它们视为一组连接在一起的非常简单的模型。这些简单的模型称为神经元，这些模型之间的连接是称为权重的可训练模型参数。

卷积神经网络是一种特殊类型的神经网络，特别擅长处理图像。

### 第四步：模型评估

正如你在上一个示例中所见，有许多不同的统计指标可用于评估模型。随着你在机器学习方面积累更多经验，你将学会如何研究哪些指标能帮助你最有效地评估模型。以下是常用指标列表：

| 准确率 | 假阳性率 | 精确率 |
| :--- | :--- | :--- |
| 混淆矩阵 | 假阴性率 | 召回率 |
| F1 分数 | 对数损失 | ROC 曲线 |
|  | 负预测值 | 特异性 |

在本例这种情况下，准确率可能不是最佳的评估机制。

为什么？你意识到模型几乎一直会看到“不包含溢出物”这一类别，因此任何大部分时间只预测“无溢出”的模型看起来准确率都会很高。

你真正关心的是一种极少漏报真实溢出的评估工具。

经过一些网络搜索，你意识到这是一个常见问题，且精确率和召回率将会有效。你可以把精确率理解为回答“在所有溢出预测中，有多少是正确的？”，把召回率理解为回答“在所有实际溢出中，我们检测到了多少？”。

人工评估发挥着重要作用。你不确定模拟溢出与实际溢出相比是否足够真实。为了更好地了解模型在实际溢出上的表现，你从历史记录中寻找更多示例。这使你能够确认模型表现令人满意。
