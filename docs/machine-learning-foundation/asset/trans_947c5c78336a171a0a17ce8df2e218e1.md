# 第三步：模型训练

## 划分数据集

模型训练的第一步是随机划分数据集。这使你能在训练期间保留部分数据隐藏，以便在将模型投入生产前使用这些数据来评估模型。具体来说，这是为了针对偏差-方差权衡进行测试。如果你有兴趣了解更多，请参阅“扩展学习与阅读”部分。

划分数据集将为你提供两组数据：

*   **训练数据集**：用于训练模型的数据。你的大部分数据将放在这里。许多开发者估计约占 80%。
*   **测试数据集**：训练期间从模型中保留的数据，用于测试模型对新数据的泛化能力。

## 模型训练术语

模型训练算法会迭代地更新模型的参数，以最小化某个损失函数。

让我们定义这两个术语：

*   **模型参数**：模型参数是训练算法可以更新以改变模型行为的设置或配置。根据上下文，你还会听到其他更具体的术语来描述模型参数，例如**权重**和**偏置**。**权重**是随着模型学习而变化的值，更多地特指神经网络。
*   **损失函数**：损失函数用于量化模型距离目标的程度。例如，如果你试图根据当天的天气预测刨冰的销量，你会关心预测尽可能准确。因此，你可以将损失函数定义为“模型预测的刨冰销量与正确销量之间的平均距离”。你可以在刨冰示例中看到这是两个紫点之间的差异。

## 综合运用

端到端的训练过程如下：

*   将训练数据输入模型。
*   根据结果计算损失函数。
*   朝着减少损失的方向更新模型参数。

你将持续循环执行这些步骤，直到达到预定义的停止条件。这可能基于训练时间、训练周期数，甚至是更智能或更具应用感知的机制。

## 专家建议

训练模型时请记住以下建议。

*   从业者通常使用已包含模型和模型训练算法可用实现的机器学习框架。你可以从头实现这些，但除非你在开发新模型或算法，否则可能不需要这样做。
*   从业者使用一个称为**模型选择**的过程来确定使用哪个模型或模型。成熟模型的列表在不断增长，即使是经验丰富的机器学习从业者，在用机器学习解决问题时也可能会尝试许多不同类型的模型。
*   **超参数** 是模型上的设置，它们在训练期间不会改变，但会影响模型训练的速度或可靠性，例如模型应识别的聚类数量。
*   做好迭代的准备。

用机器学习进行务实的问题解决很少是一门精确的科学，你可能对数据或问题有假设，但最终证明是错误的。不要气馁。相反，要养成尝试新事物、衡量成功并跨迭代比较结果的习惯。

### 线性模型

线性模型是入门课程中最常见的模型之一，它通过线性函数（想想 `y = mx + b` 或 x-y 图表上的直线）简单地描述一组输入数字和一组输出数字之间的关系。

分类任务通常使用密切相关的逻辑模型，它增加了一个额外的变换，将线性函数的输出映射到范围 `[0, 1]`，解释为“属于目标类的概率”。线性模型训练速度快，并能为你提供一个极好的基线，以便与更复杂的模型进行比较。虽然更复杂的模型获得了大量媒体关注，但对于大多数新问题，建议考虑从简单模型开始。

### 树模型

树模型可能是入门课程中第二常见的模型类型。它们通过构建极其庞大的嵌套 if/else 代码块结构来学习分类或回归，在每个 if/else 代码块处将世界分割成不同的区域。训练过程确定这些分割的确切位置以及分配给每个叶子区域的值。

例如，如果你试图确定光传感器处于阳光下还是阴影中，你可能会训练一个深度为 1 的树，其最终学习到的配置可能如下所示：

```
if (sensor_value > 0.698), then return 1; else return 0;
```

基于树的模型 `XGBoost` 常被用作此类模型的开箱即用实现，并包含此处未讨论的增强功能。尝试使用树模型快速获得基线，然后再转向更复杂的模型。

### 深度学习模型

深度学习极其流行且强大，是一种基于人脑功能概念模型的现代方法。模型（也称为神经网络）由神经元集合（非常简单的计算单元）组成，这些神经元通过权重（表示允许多少信息从一个神经元流向下一个神经元的数学表示）连接在一起。训练过程涉及为每个权重寻找数值。
