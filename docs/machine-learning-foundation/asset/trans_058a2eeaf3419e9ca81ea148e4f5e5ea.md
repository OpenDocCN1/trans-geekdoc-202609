### 步骤二：构建数据集

### 步骤三：模型训练

正式训练前需划分数据。标准做法是将 80% 数据置于训练集，20% 置于测试集。

#### 线性模型选择

如前图所示，占地面积与房屋价值呈正相关。这种关系足够简单，可用线性模型表示。

单输入变量的线性模型可表示为一条线，两个变量为一个平面，两个以上变量则为超平面。其直觉（恒定斜率的线）不变。

#### 使用 Python 库

Python `scikit-learn` 库提供工具处理模型训练算法的实现。

### 步骤四：评估

回归场景中常用评估指标为均方根误差（`RMS` / `RMSE`）。数学细节超出本课范围，但可将 `RMS` 粗略理解为测试集上的“平均误差”，故期望该值越低越好。

计算测试集中数据点的模型预测值与真实值之间的均方根误差。具体计算超出本课范围，但理解其高层流程很有帮助。

#### 结果解读

通常模型改进会带来更好的 `RMS` 结果，但可能仍难判断具体数值的优劣。

许多机器学习工程师会手动统计偏离阈值（如本房价问题中的 $50,000）的预测数量，以辅助判断和验证模型准确性。

### 术语表

*   **连续值**：可能取值范围无限的浮点数。与分类值或离散值（仅取有限可能值）相对。
*   **超平面**：包含两个以上平面的数学曲面术语。
*   **平面**：可用直线连接两点的平坦数学曲面（如一张纸）。

## 示例二：图书流派探索

本视频演示如何将机器学习流程应用于无监督学习任务，利用图书描述文本识别不同微流派。

### 步骤一：定义问题

![](Images/image00097.jpeg)

基于图书描述中共同词汇的出现情况，寻找相似图书的聚类。

你在图书推荐公司从事编辑工作，欲撰写年度最大图书趋势文章。你认为存在“微流派”趋势，并确信可利用图书描述文本识别这些微流派。

通过一种名为聚类的无监督机器学习技术，可验证你的假设：图书描述文本可用于识别这些“隐藏”的微流派。

本课前文介绍了无监督学习概念。当数据未标记时，此类机器学习任务尤为有用。

![](Images/image00098.jpeg)

### 步骤二：构建数据集

为验证假设，收集当年出版的 800 本言情小说的描述文本。

#### 数据探索、清洗与预处理

项目中认为大小写和动词时态不影响结果，故使用处理人类语言的 Python 库移除大写并统一动词时态。同时移除标点及无实际意义的词（如 'a'、'the'），机器学习界称这些为**停用词**。

训练模型前需进行数据预处理——**数据向量化**，将文本转为数字。

将图书描述文本转换为下图所示的**词袋表示**，使其可被机器学习模型理解。

词袋表示的工作原理超出本课程范围，详见本节底部“扩展阅读”。

![](Images/image00099.jpeg)

### 步骤三：训练模型

现可开始训练模型。

选用常见聚类模型 **k-means**。该模型中，可调整参数 `k` 为模型尝试寻找的聚类数量。

数据未标记：不知可能存在多少微流派。故使用不同 `k` 值多次训练模型。

这意味着什么？下图展示 `k=2` 和 `k=3` 时的示例。

![](Images/image00100.jpeg)

模型评估阶段计划使用指标寻找最适合的 `k` 值。

### 步骤四：模型评估

机器学习中有大量统计指标或方法评估模型。本用例中，**轮廓系数** 是良好选择。该指标描述模型对数据聚类的效果。通过绘制轮廓系数（如下图）寻找最优聚类数，发现 `k=19` 时为最优值。

![](Images/image00101.jpeg)

机器学习从业者常人工评估模型发现。

你发现一个聚类包含大量可归类为“超自然青春言情”的图书。该趋势业内已知，故对你的机器学习方法有一定信心。虽不知每个聚类是否都如此内聚，但决定使用该模型看能否发现可供撰写文章的有趣内容。
