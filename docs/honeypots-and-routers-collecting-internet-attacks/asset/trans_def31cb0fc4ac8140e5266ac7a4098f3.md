
# 扫描与枚举

扫描和枚举是属于黑客攻击第二阶段（即扫描阶段）的两种技术；感到困惑吗？令人惊讶的是，黑客行业为某个攻击阶段和该阶段使用的一种技术选用了同一个词，这主要是因为枚举与扫描非常相似。然而，枚举的目标是发现用户名、机器名、共享资源、服务及其他类似实体。另一方面，扫描旨在发现活跃的网络主机及这些主机上的开放端口，因此也被称为*网络扫描*。

# 3 入侵与漏洞

**HABIB-UR REHMAN**

由于大部分物理基础设施公开可访问且由用户共享，保障通信及其内容的安全是计算机网络中的一项重要关注点。这一事实使得我们在[第 2 章](#07_Chapter02.xhtml)中描述的所有安全目标都发挥了作用。此外，我们在[第 1 章](#06_Chapter01.xhtml)中回顾了，用于在端主机之间传递消息的大多数协议都是公开的。因此，每个人都知道传输消息时将执行的动作序列，并可能利用这些知识攻击正在进行的通信。这绝不意味着计算机网络中没有任何安全可言；协议已演进以克服此类缺陷。然而，计算机网络（尤其是互联网）的服务模型是以一种无法消除所有弱点的方式开发或演进的。

入侵者利用系统的漏洞发起攻击；这使得系统管理员和合法用户极其有必要充分了解这些漏洞。如果设计和配置不当，网络、主机以及运行在主机上的应用程序都可能被滥用。本章旨在突出这三个层面的此类问题。我们试图编制一份已知常见攻击的综合清单。

## 3.1 网络与协议漏洞

公开协议及其漏洞确实是计算机网络中攻击的最大来源。本节讨论超文本标记语言 (HTTP) 等协议上可能发生的常见攻击。

### 3.1.2 HTTP 隧道

隧道技术是计算机网络中的一个重要概念，即将一种协议的数据包封装在另一种协议的数据包内。当隐藏/内层数据包的协议不被底层网络支持时，通常会采用这种方法；这可能是由于管理限制、协议不兼容或设备限制。隧道技术增加了网络的效用，因为它即使在存在不兼容的情况下也能实现通信。例如，通过建立端到端的 IPv4 隧道，或根据需求建立较少跳数的隧道，可以在通过不支持 IPv6 的设备（部分或全部）连接的端主机之间共享 IPv6 数据报。隧道技术可在任何层或协议上执行。然而，HTTP 隧道是一个主要关注点，因为 HTTP 消息极少被过滤或阻断^([^(11)](#fn11))
