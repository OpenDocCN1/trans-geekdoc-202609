## 4.3 Core Attributes of Cloud Computing

- **Elasticity:** With the varying and increasing data, evolution of technology, and business, organizations have to provision and de-provision resources and software services at a faster pace without hampering business. Cloud has the ability to achieve elasticity in a multi-tenant model [7].

- **On-Demand:** Customers can avail any number of resources and services required on-demand at any point of time from anywhere by connecting through the internet. Both the adding and removing of resources and services are on-demand without paying any extra charges for it [10].

- **Provider Pooled Computing Resources:** The cloud provider acquires and maintains all computing hardware on which cloud services run. It gives a guaranteed uptime to the cloud user for the services they acquire, as mentioned in the agreement they signed.

- **Metered Service Usage:** The cloud provides a flexible subscription method to the customer for the services they consume. The cloud provides a metered service method where it provides transparency to users regarding the consumption of resources and the billing amount at any point of time with a well-designed representative model. This model helps users track the proper utilization of their money on cloud services. The following are the benefits of metered service:
    - Automatic workload ensures no fee has to be paid during idle time without releasing the services.
    - It creates alerts and notifies users if service consumption exceeds the limit set by the user. This helps users not to track the consumption every time and focus on business.
    - This service also provides suggestions to redesign the resource allocation in case of improper usage of resources and unused storage spaces.

- **Broad Network Access:** Cloud services can be accessed from any type of device, such as desktops, laptops, mobile phones, and tablets, just by connecting through the internet, regardless of the geographical location of use [11].

- **Easy Maintenance:** Servers are auto-maintained, meaning they are maintained by the cloud provider without impacting the uptime for the users. Also, upgrades are auto-updated and make services more efficient.

- **Multi-Business:** Due to distributed networking and virtualization properties, cloud computing is efficient in parallel processing and resource sharing. This enables the cloud to operate effortlessly across multiple business lines without duplicating environments. Figure 4.2 shows the characteristics of cloud computing.

## 4.4 Cloud Computing Models

To understand cloud computing in a better way, different models have been defined based on resource physical distribution and service principles. There are two major models defined [6]:

- Cloud Deployment Model
- Cloud Service Model

### 4.4.1 Cloud Deployment Model

Based on cloud infrastructure setup, NIST has broadly defined the deployment model into four sub-categories: public cloud, private cloud, hybrid cloud, and community cloud. These models are defined keeping into consideration the ownership of the cloud infrastructure between the cloud provider and the user. Before moving the business process into the cloud, organizations have to evaluate different parameters such as existing infrastructure, ownership of the infrastructure, cost involvement during the transition, and future continuity with cloud computing. Figure 4.3 elaborates the cloud deployment model.

- **Public Cloud:** This kind of cloud service is an open service and available to the public and all organizations for use. The cloud provider holds the sole ownership of the cloud and is mostly preferred for generic non-critical applications, email services, and file sharing applications. The actual physical location of the infrastructure is hidden from all users, though users can select different geographical locations for their services to operate [13].

- **Private Cloud:** A private cloud is a deployment in the premises or off the premises of the organization, and the cloud will be managed by the various teams in the organization or a dedicated third-party cloud provider. The infrastructure is solely dedicated to the owner organization and will fulfill the requirements of the same organization. Setting up and maintaining a private cloud requires huge investment and time. A private cloud is best suited when privacy and security are the most concerning factors. It is generally preferred for organizations working on critical applications and government agencies such as defense and intelligence departments.

- **Hybrid Cloud:** As not all operations of an organization are critical, the organization can set up a hybrid cloud by deploying both private cloud and public cloud. A hybrid cloud reduces the cost of the infrastructure. Also, the organization can get the benefit of both clouds: getting security and privacy through the private cloud for critical operations and flexibility from the public cloud for non-critical applications [9].

- **Community Cloud:** This model supports computer resource sharing among a community over the cloud; for example, universities cooperating with each other for certain fields of research and police departments within a country sharing information over the community cloud. The access to the cloud is restricted within the members of the community [21].

### 4.4.2 Cloud Service Model

There are basically three types of cloud service models: IaaS, PaaS, and SaaS, available in the cloud based on the types of services available. Refer to Figure 4.4 for the cloud service model architecture.

- **IaaS (Infrastructure as a Service):** In this model, the cloud provider sets up and manages all the IT infrastructures and creates an abstract layer for the users to use all the underlying hardware without impacting performance and hiding their physical presence [9].
    - It basically includes the hardware services provided by the vendors who have already configured all the required hardware such as virtual machines, storage, and network components. Users have to subscribe and use only the required or allocated hardware components over the network without bothering about its underlying setups.
    - It makes the IT manager’s task easier.
    - It is available to any device on the network.
    - Rapidly provision and de-provisioning new computer resources can be done without impacting the other IT services.
    - Computing infrastructure is not required locally as the user has to work above the abstraction layer.
    - Less local square footage for IT resources is required for the organization that sets up the infrastructure on IaaS.
    - Less local energy consumption as infrastructure setup has to be set by the cloud provider.
    - It offers the most complex services for easy use.

- **PaaS (Platform as a Service):** It is basically an accessing system where all the required applications are running, forming an environment where software development can be done without bothering about the compatibility of underlying installed applications. Platform applications include web servers, database servers, and application servers along with development software that helps users to build their own applications over the available platform framework [13].
    - It basically reduces IT developer’s workload.
    - It enables the design of custom applications.
    - It can be available to any device on the network.
    - Rapidly provisioning and de-provisioning of new and existing applications and required resources can be done.
    - Server infrastructure is not required.
    - It has faster time to market as the user has to focus on business rather than underlying platform setup and upgrade.
    - It is available on an on-demand basis and can be easily commissioned when not required.
    - It eliminates wasted time due to IT acquisition.
    - It also simplifies the process of creating, testing, and updating applications.

- **SaaS (Software as a Service):** It helps organizations not to build all the required software but rather access the already built or available software by other expert organizations, so that they need not have to purchase, install, update, or maintain the software [15]. They only have to subscribe and use it over the internet.
