Once data has been created, it may move freely among any stages in the life cycle. However, data security must be ensured during all the stages during a life cycle. Based on the data state during the stages, the stages may be classified in the following three stages.

+   - Data in use: data generation, data use, data destruction
- Data in transit: data share, data transfer
- Data in rest: data storage, data archival

(Note: Data destruction can be considered as its own stage; however, for convenience, we can put it under data in use.)
