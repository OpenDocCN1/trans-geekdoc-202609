# RC5

It is a symmetric encryption algorithm. It has a variable block (32, 64, and 128 bits) size, but usually, it is 128 bit block. Also, it has 12 rounds. The general structure is again that of the feistel cipher. The RC5 algorithm is used for encryption of data in cloud computing. It can also be used in data transmission to ensure the security of the day during transfer. We can then be sure that the transmission of data will be encrypted. Even if the data is stolen during transmission, there is no related key that can be used to crack it easily.
