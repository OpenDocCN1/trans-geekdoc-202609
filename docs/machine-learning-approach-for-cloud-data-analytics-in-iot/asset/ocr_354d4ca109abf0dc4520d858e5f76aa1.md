$DCT$ of the task $\mathrm{X}_{i}$ is defined as the summation of communication time of immediate successor tasks $\mathrm{X}_{j}$ of $\mathrm{X}_{i}$ at each level. It can be expressed [21] as

```
$$\begin{array}{rl}\ DCT(\mathrm{X}_{i})= & \left\{\begin{array}{cl}\sum_{j=1}^{s}\ CT(\mathrm{X}_{i},\mathrm{X}_{j}), & i<j \quad\ if\ \mathrm{X}_{i} \neq \mathrm{X}_{exit}\\ 0 & \quad\ if\ \mathrm{X}_{i}=\mathrm{X}_{exit}\end{array}\right.\end{array}$$
```

where $s$ is the total number of tasks in next level.

An example of $DCT$ of the tasks of $\mathrm{DAG}_{1}$ is given in Figure 9.5. $\mathrm{X}_{1}$ has five successor tasks $\mathrm{X}_{2}, \mathrm{X}_{3}, \mathrm{X}_{4}, \mathrm{X}_{5}$, and $\mathrm{X}_{6}$ and the summation of the communication time $CT$ between $\mathrm{X}_{1}$ and all its successor tasks is 64. Similarly, $DCT$ computation for rest tasks at each level is shown in Table 9.8.

$PTR$ of the tasks $\mathrm{X}_{i}$ is the greatest rank of immediate predecessors $\mathrm{X}_{j}$ of $\mathrm{X}_{j}$ and it can be computed[21] as follows:

```
$$\begin{array}{rl}\ PTR(\mathrm{X}_{i})= & \left\{\begin{array}{cl}\max_{\mathrm{T}_{j} \in PRE(\mathrm{T}_{i})}\ \{RANK(\mathrm{X}_{j})\} & \ if\ \mathrm{X}_{i} \neq \mathrm{X}_{entry}\\ 0 & \quad\ if\ \mathrm{X}_{i}=\mathrm{X}_{entry}\end{array}\right.\end{array}$$
```

where $PRE$ is immediate predecessor tasks $\mathrm{X}_{i}$ of $\mathrm{X}_{j}$

$RANK$ of task $\mathrm{X}_{i}$ is computed based on AET, DCT, and PTR of the task. It is computed as follows:

```
$$RANK(\mathrm{X}_{i})=Round\{AET(\mathrm{X}_{i})+DCT(\mathrm{X}_{i})+PTR(\mathrm{X}_{i})\}$$
```
