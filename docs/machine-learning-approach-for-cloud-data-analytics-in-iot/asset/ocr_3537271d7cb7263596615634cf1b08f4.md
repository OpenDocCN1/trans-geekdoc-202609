# DSA

The DSA is a technique for the exchange of digital signatures which is used for the authentication of messages. It is based on the ELGamal scheme and uses a discrete logarithm problem implementing the properties of algebraic properties of modular exponentiation. DSA was introduced by the NIST (National Institute of Standards and Technology) to detect the unauthorized changes made to the data sent by the source to the receiver. It also has a public and private key required to solve the problem. It also helps avoid non repudiation of message as the transmission must be signed by the public key.
