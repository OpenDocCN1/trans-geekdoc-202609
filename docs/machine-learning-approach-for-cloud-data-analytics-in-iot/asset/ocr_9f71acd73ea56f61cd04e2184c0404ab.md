# 9.2 Workflow Model

A workflow model is used to denoted an application program and it is depicted by Directed Acyclic Graph (DAG) and formally defined by $W_G$ = $(T, E, W)$, where

$T$ = ${\mathrm{X}_1, {\mathrm{X}_2, {\mathrm{X}_3},...,{\mathrm{X}_n}\}$ is fixed number of nth tasks.

$E$ = ${\mathrm{e}_i, \mathrm{e}(\mathrm{X}_i, \mathrm{X}_j)\}$ is edges between any two task $\mathrm{X}_i$ and $\mathrm{X}_j$

$W$ = ${{(X_i, X_j) | X_i, X \in T}\}$ is data transfer time of the edges two task $\mathrm{X}_i$ and $\mathrm{X}_j$

The dependency between tasks should be maintained which is called precedence constraint. Every DAG has an entry and exit task. An entry task $X_i$ of given DAG is defined as pred($X_i$) = $\Phi$ which means no any parent tasks of $X_i$. Similarly, an exit task succ($X_i$) = $\Phi$ having no any children tasks.
