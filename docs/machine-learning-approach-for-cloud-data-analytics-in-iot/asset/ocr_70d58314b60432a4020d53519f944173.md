# 10.2.3.1.3 MapReduce Algorithms

All major data mining algorithms such as Support Vector Machines
(SVMs) [48], K-means [49], C4.5 [50], and Apriori [51] have been recon-
figured in MapReduce over the past few years. Chu et al. (2007) showed
that MapReduce shows a linear acceleration with an increasing number
of processors in a variety of learning algorithms such as Naive Bayes, newly
built networks, and probabilistic clustering expectation-maximization.
