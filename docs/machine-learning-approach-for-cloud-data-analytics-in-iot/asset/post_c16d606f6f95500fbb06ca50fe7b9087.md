
$C^{\text{Path}}$ is the length of path from entry task to exit task where length is the longest. This attribute is expressed [13] as follows:

$$C^{\text{Path}} = \max_{\text{path} \in \text{DAG}_i} \{ \text{length(path)} \}$$
$$\text{length(path)} = \sum_{X_i \in X} \text{AECT}(X_i) + \sum_{X_i, X_j \in E} C^{\text{Time}}(X_i, X_j)$$

where:

- *AECT($X_i$)* [20] is the Average Estimated Computation Time of task $X_i$ and it can be computed as:
  $$\text{AECT}(X_i) = \frac{\sum_{j=1}^m \text{ECT}_{i,j}}{m}, \quad \textit{where } m \text{ is total number of VMs.}$$
- *$C^{\text{Time}}(X_i, X_j)$* is the Communication time between the tasks $X_i$ and $X_j$.
- $E$ is a finite set of edges of DAG.
- $X$ is a finite set of tasks of DAG.

$U^{\text{Rank}}(X_i)$ is the longest path from $X_i$ to $X_{\text{exit}}$ tasks and it includes the execution time of $T_i$. Upward Rank is also called *Bottom Level (B-Level)*. $U^{\text{Rank}}(X_i)$ is expressed as follows:

$$U^{\text{Rank}}(X_i) = \begin{cases} \text{AET}(X_i) + \max_{X_j \in \text{SUC}(X_i)} (CT_{i,j} + U^{\text{Rank}}(X_j)) & \text{if } X_i \neq X_{\text{exit}} \\ \text{AET}(X_{\text{exit}}) & \text{if } X_i = X_{\text{exit}} \end{cases}$$

where:

- $X_i$ is the tasks of the given DAG.
- $X_{\text{exit}}$ is the last task of the given DAG.
- $CT_{i,j}$ is the Communication Time Between the tasks $X_i$ and $X_j$.
- SUC is a finite set of immediate successor of $X_i$.
- AET is the Average Execution Time of the task $X_i$ and it can be expressed by:
  $$\text{AET}(X_i) = \frac{\sum_{j=1}^m \text{ECT}_{i,j}}{m}$$

### 9.7.4 Performance Effective Task Scheduling (PETS) Algorithm

PETS [21] algorithm is worked in three phases such as sorting of task level, prioritization of task, and VM selection.

#### First Phase: Sorting of Task Level

This phase is used to find levels with their respective tasks and it is traversed from top to bottom of the given DAG. Each level consists of multiple tasks which are independent and these tasks would be sorted and grouped as appeared in their level. For example, task level sorting of the given DAG as shown in Figure 9.5 is divided into four levels. Level_1 consists of entry task $X_1$, Level_2 consists of intermediate tasks $X_2, X_3, X_4, X_5, X_6$, and so on for the other two levels. Sorting of task level is shown in Table 9.6.

#### Second Phase: Prioritization of Task

This phase is used to compute the priority and assign to the tasks of the given DAG$_{1}$. There are three attributes [21] that are designed to compute the priority of the tasks and the attributes are average execution time (AET), data communication time (DCT), and predecessor task rank (PTR). Details of these attributes are given below:

$DCT$ of the task $\mathrm{X}_{i}$ is defined as the summation of communication time of immediate successor tasks $\mathrm{X}_{j}$ of $\mathrm{X}_{i}$ at each level. It can be expressed [21] as:

$$

$PTR$ of the tasks $\mathrm{X}_{i}$ is the greatest rank of immediate predecessors $\mathrm{X}_{j}$ of $\mathrm{X}_{i}$ and it can be computed [21] as follows:

$$
PTR(\mathrm{X}_{i})= \left\{\begin{array}{cl}\max_{\mathrm{T}_{j} \in PRE(\mathrm{T}_{i})}\ \{RANK(\mathrm{X}_{j})\} & \text{if } \mathrm{X}_{i} \neq \mathrm{X}_{entry}\\ 0 & \text{if } \mathrm{X}_{i}=\mathrm{X}_{entry}\end{array}\right.
$$

where $PRE$ is immediate predecessor tasks of $\mathrm{X}_{i}$.

$RANK$ of task $\mathrm{X}_{i}$ is computed based on AET, DCT, and PTR of the task. It is computed as follows:

$$RANK(\mathrm{X}_{i})=Round\{AET(\mathrm{X}_{i})+DCT(\mathrm{X}_{i})+PTR(\mathrm{X}_{i})\}$$

#### Third Phase: VM Selection

After the computed the priority of the tasks of the given DAG${}_{1}$, it would be sorted for scheduling in cloud server's virtual machines.

This phase decides the selection of a particular virtual machine as per minimum *EST* and *EFT* attributes. Details of *EST* and *EFT* attributes are as below:

Earliest Start Time EST [26, 27] is defined as follows:

$$
EST(X_{i},VM_{j})
=
\left\{
\begin{array}{ll}
0 & \quad if \ X_{i} \in X_{entry} \\
\max_{X_{j} \in pred(X_{i})}\{EFT(X_{j},VM_{j}) + MET(X_{i}) + CT_{i,j}\} & otherwise
\end{array}
\right\}
$$

Minimum Execution Time MET [22, 26, 27] is defined as follows:

$$
MET(X_{i}) = \min\{ECT(X_{i}, VM_{j})\}
$$
