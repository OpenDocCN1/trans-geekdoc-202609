# # Mysql/Maraidb – Advanced Learning

**Joins:** MYSQL JOINS are used to retrieve data from multiple tables. In most real world MySQL usage, you will often need to get data from multiple tables in a single query. So to access data from different tables, that may relate to each other, we use the JOIN clause in MySQL

There are three types of MySQL joins:

+   - INNER JOIN (Simple join)
+   - LEFT OUTER JOIN (LEFT JOIN)
+   - RIGHT OUTER JOIN (RIGHT JOIN)

![](bbox=[0.124, 0.481, 0.633, 0.756])

**INNER JOIN OR Simple join:** The MYSQL INNER JOIN is used to return all rows from the tables where the join condition is satisfied. It is the default join also. So in simple words it can be used to retrieve common records / rows from the multiple tables.
