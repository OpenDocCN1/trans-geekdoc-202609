+   3. Using Query String / URL Rewriting
+   4. Using Hidden form field

# Form Methods

**The GET Method**: The GET method sends information separated by the ? Operator.

**Example:** http://www.xyz.com/home.html?city=Gurgaon

Please note that t he GET method is restricted to send upto 1024 characters (1024 bytes) only. You should not use GET method if you have password or other confidential information to be proceeding over the server.

GET can't be used to send binary data, like im ages or word documents, to the server.

The PHP provides $_GET associative array or super global variable to access the data sent using GET method.
