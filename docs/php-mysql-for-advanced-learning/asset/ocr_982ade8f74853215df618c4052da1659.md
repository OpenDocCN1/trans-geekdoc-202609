But when you are running the same code over and over would produce the same result. So what is the benefit of using Loop in that case?

Basically a loop contains a variable that changes slightly each time.

In PHP several types of Loops are-

+   - For Loop
+   - For Each Loop
+   - Do while Loop
+   - While Loop

# The For Loop

PHP for loop can be used to traverse set of code for the specified number of times. For example if you want to repeat something ten or twenty times.

It should be used if number of iteration or repetition is known otherwise I recommend you to use while loop.

# For Loop Syntax

```
for (Initialization; Condition; Progressive)
{
    //set of statements to be executed;
}
```

# Parameters Explanation:

Initialization: Initialize the loop counter value
