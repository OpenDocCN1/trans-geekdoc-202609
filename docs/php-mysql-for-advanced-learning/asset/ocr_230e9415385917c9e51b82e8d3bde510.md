# **The md5( ) Function:**

Used to calculate the md5 hash of a string value. This could be used where you want to convert your password from plain text to hash code to prevent the use of unauthorized users.

# Example

```
```php
<?php
echo md5('password123');
?>
```
```

# Output

9f161034ee4de758baf4de09c4eb1a75

# **The trim() function :**

_the Trim() is used to remove white spaces and predefined characters from a both the sides of a string.

# Syntax

trim(string,charlist)

# Example

```
```php
<?php
$txt = "Webs Jyoti";
echo trim($txt,"Weti");
?>
```
```

# Output

bs Jyo
