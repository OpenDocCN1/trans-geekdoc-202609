# The str_replace() function

This can be used where you just want to swap out words or a set of characters in a string and replace them with something else.

# Example:

```
```php
<?php

$oldstr = "The cat is black";

$newstr = str_replace("black", "white", $oldstr);

echo $newstr;

?>
```
```

Output: The cat is white
