# Example: Using Traits in PHP

```
<?php
Trait A
{
public function hello()
{
    echo "Hello This is Trait A";
}
}
Trait B
{
public function test()
{
    echo "Hello This is Trait B";
}
}
class MyClass
{
    use A, B; // Calling Traits A and B in the class
}
$obj = new MyClass();
$obj-> hello();
$obj-> test(); // Calling function test
?>
```
