# table-responsive

Is used to create a responsive table. The table will then scroll horizontally on small devices.

# table-striped

Is used to adds zebra-stripes to a table.

# table-bordered

Is used to adds borders on the table.

# table-hover

Is used to enables a hover state on table rows i.e. a gray background color will automatically on mouse over.

# table- condensed

Is used to makes a table more compact by reducing padding in half.
