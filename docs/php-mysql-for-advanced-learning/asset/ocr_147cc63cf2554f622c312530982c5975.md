# ksort for displaying in ASC by Key (names or first key string) the same krsort for DESC

```
echo "<br> KSort <br>";

$emp = array("Hirdesh"=>"12", "Amit"=>"54", "Laxmi"=>"50",
"Rahim"=>"87");

ksort($emp);

foreach($emp as $x => $code)
{
    echo "Name=" . $x . ", Emp Code=" . $code . "<br>";
}
```
