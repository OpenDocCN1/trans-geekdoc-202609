# Static Methods and properties in PHP

The static methods are widely used to create Helper and Utility functions (Example autoloading) which gives you more ability to organize and recall your functions. Static functions in PHP can be called directly (Using Resolution Operator ::) without creating the object of the class. The static keyword is used to define static function in PHP.

# Example

```
class A
{
static function fn()
{
echo "This is a Static Function";
}
}
echo A::fn(); // Calling function without creating object
```

Please note if there's no visibility mode or access specifier (Public Private or Protected) is declared then the visibility mode will be *public* by default.

Static methods also can accessed from a methods in the same class using the **self** keyword and :: (Resolution Operator)
