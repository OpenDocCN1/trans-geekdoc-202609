# Customizing Your Installation

The main configuration file for PHP is php.ini; it can be found in the root directory of XAMPP like c:\xampp\apache\php.ini

# Some major settings available in php.ini-

<u>short_open_tag</u>: Allows short tags to be parsed (<? and ?>

<u>output_buffering</u>: Allows header lines to be sent after HTML has already been sent to the server. The default is “Off,”

<u>max_execution_time</u>: Sets the limit for how long a script can take to run or execute

<u>max_input_time</u> Sets the limit for how long a script can take to parse the data.

<u>memory_limit</u> Sets the limit for how much memory a script can use to run in MB.

<u>file_uploads</u>: Enables Web site visitors to upload files to your server.

<u>upload_max_filesize</u>: Sets the limit for how large an uploaded file may be, in MB.
