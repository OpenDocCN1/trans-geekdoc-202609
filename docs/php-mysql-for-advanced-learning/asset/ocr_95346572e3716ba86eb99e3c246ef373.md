# Logical Operators:

Logical operators are used to combine multiple statements and to test if the condition met to true / false.

Following are the logical operators:

+   - And or && - All conditions must be true
+   - Or || - at least one should be true
+   - Xor- One side or other must be true but not both
+   - == comparison operator

*Please note = is assignment operator while == is comparison operator in PHP.
