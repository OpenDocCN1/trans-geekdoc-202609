# # Switch Case Statement in PHP

The switch statement is similar to a series of if statements on the same expression.

Switch Case checks a variable for different cases or values. If anyone of the case becomes true then the respective case is executed and the program ignores all other cases.

For example when you have call to a customer care, in the very beginning you have some recorded messages like “for billing support press 1, for technical support press 2, to go back to main menu press 9 and so on...” how this concept work?

It is just an example of Switch case where each key is bind with some selective operations.
