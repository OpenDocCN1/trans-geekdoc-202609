# Working with MYSQL / Maraidb Database

Before implementing Mysql with PHP lets explore the basic concepts of database and table through MYSQL Console.

+   - Open XAMPP Control Panel and start Apache and MYSQL\Mariadb services
+   - Open Command prompt (type cmd on run option) and copy paste your MYSQL/Mariadb path using cd command like cd C:\xampp\mysql\bin
+   - To open MYSQL environment type mysql.exe –u root
+     (Here root is the username of your Mysql database . If your Mysql contain password then type mysql.exe –u root –p mypassword)
+   - Once your MYSQL welcome screen is open then you may start working with Mysql / maridb environment.
