# 3.3 Stacked Generalization

Stacked Generalization (a.k.a Stacking) is a powerful ensemble learning method proposed by Wolpert (1992). The method consists of training a set of powerful base learners (first-level learners) and then combining their outputs by stacking to form a new train set. The base learners' outputs correspond to their predictions and optionally, the class probabilities of those predictions. The predictions of the base learners are known as the meta-features. Then, those meta-features along their true labels $y$ are used to build a new train set that is used to train a meta-learner. The rationale behind this is that the predictions themselves contain information that can be used by the meta-learner.

The procedure to train a Stacking model is as follows:

+   1. Define a set of first-level-learners $\mathcal{L}$ and a meta-learner.
2. Train the first-level-learners $\mathcal{L}$ with training data $D$.
3. Predict the classes of $D$ with each learner in $\mathcal{L}$. Each learner produces a predictions vector $p_i$ with $|D|$ elements.
4. Build a matrix $M_{D\times|L|}$ by column binding (stacking) the prediction vectors. Then, add the true labels $y$ to generate the new train set $D'$.
5. Train the meta-learner with $D'$.
6. Output the final stacking model $\mathcal{S} : < \mathcal{L}, \text{meta-learner} >$.

Figure 3.5 shows the procedure to generate the new training data $D'$ used to train the meta-learner.

Note that steps 2 and 3 can lead to overfitting the predictions are made with the same data used to train the models. To avoid this, steps 2 and 3 are usually performed using k-fold cross-validation. After $D'$ has been generated, the learners in $\mathcal{L}$ are retrained using all data in $D$.

Ting and Witten (1999) showed that the performance can increase by adding confidence information about the predictions. For example, the probabilities produced by the first-level learners. Most classifiers can output probabilities.

At prediction time, each first-level learner predicts the class, and optionally, the class probabilities of a given instance. These predictions are used to form a feature vector (meta-features) that is fed to the meta-learner to obtain the final prediction. Usually, first-level learners are high performing classifiers such as Random Forests, Support Vector Machines, Neural Networks, etc. The meta-learner should also be a powerful classifier.
