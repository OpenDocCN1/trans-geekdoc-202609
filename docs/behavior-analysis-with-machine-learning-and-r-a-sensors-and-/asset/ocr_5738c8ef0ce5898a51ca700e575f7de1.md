we know the mean value, the dataset is divided into train and test sets (c). Without realizing, we *mean* is subtracted from each element in the train and test sets (c). We have transferred information from the train set to the test set! But, did this happen? Well, the *mean* parameter was computed using information from the **entire** dataset. Then, *mean* parameter was used on the test set but it was calculated using data points that also belong to that same test set!

Figure 5.13 shows how to correctly do the preprocessing to avoid information injection. The dataset is first split (a). Then, the *mean* parameter is calculated only with data points from the train set. Finally, the *mean* parameter is subtracted from both sets. Here, the mean contains information from the train set.

In the previous example, we assumed that the dataset was split into one train and one test set only. The same idea applies when performing $k$-fold cross-validation. In each of the $k$ iterations, the preprocessing parameters need to be learned only from the train split.
