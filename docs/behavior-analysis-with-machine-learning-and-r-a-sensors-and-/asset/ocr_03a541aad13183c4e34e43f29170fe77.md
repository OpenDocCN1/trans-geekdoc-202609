# 4.10 Automated EDA

Most of the time, doing EDA involves more or less the same steps: print summary statistics, generate boxplots, visualize distributions, look for missing values, etc. If your data is stored as a data frame, all those tasks require almost the same code for any dataset. To speed up this process, some packages have been developed. They provide convenient functions to explore the data and generate automatic reports.
