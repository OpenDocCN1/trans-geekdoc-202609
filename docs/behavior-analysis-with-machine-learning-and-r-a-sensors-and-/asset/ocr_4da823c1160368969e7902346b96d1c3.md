+   3. The weights need to be initialized at random. Let's assume the single weight is 'ran-\u2019dom\u2019' initialized with $w = 2$.

Now we use gradient descent to iteratively update the weight. Remember that the updating rule is:

```
$w = w - \alpha\frac{\partial L(w)}{\partial w} \quad (8.11)$
```

The partial derivative of the loss function with respect to $w$ is:

```
$$\frac{\partial L(w)}{\partial w} = 2x(xw - y) \quad (8.12)$
```

If we substitute the derivative in the updating rule we get:

```
$w = w - \alpha2x(xw - y) \quad (8.13)$
```

We already know that $\alpha = 0.05$, the input value is $x = 3$, the output is $y = 1.5$ and the initial weight is $w = 2$. We can start updating $w$. Figure 8.14 shows the initial state (iteration 0) and 3 additional iterations. In the initial state, $w = 2$ and with that weight the loss is $0.025$. In iteration 1, the weight is updated and now its value is $0.65$. With this new weight, the loss is $0.2025$. There was a substantial reduction in the error! After three iterations we see that the final weight is $w = 0.501$ and the loss is very close to zero.
