The following snippet shows how to convert the matrix into an rules transactions object. Before the conversion, the package arules needs to be loaded. Then the transactions are saved in a file transactions.RData.

```
library(arules)

# Convert into a transactions object.
transactions <- as(M, "transactions")

# Save transactions file.
save(transactions, file="transactions.RData")
```

Now that the database is in the required format we can start the analysis. The crimes_rules script has the code to perform the analysis. First, the transactions that we generated be loaded:

```
library(arules)
library(arulesViz)

# Load preprocessed data.
load("transactions.RData")
```
