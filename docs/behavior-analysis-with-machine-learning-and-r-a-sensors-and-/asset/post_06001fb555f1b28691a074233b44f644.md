It is zero when there is no uncertainty and when there is complete uncertainty. The entropy of a discrete variable $X$ with values $x_1 \dots x_n$ and probability mass function $P(X)$ is:

```
$H(X) = -\sum_{i=1}^{n} P(x_i)logP(x_i) \quad (2.8)$
```

Take for example a fair coin with probability of heads and tails = 0.5 each. The entropy for that coin is:

```
$H(X) = -(0.5)log(0.5) + (0.5)log(0.5) = 1$
```

Since we do not know what will be the result when we drop the coin, the entropy is maximum. Now consider the extreme case when the coin is biased that the probability of heads is 1 and the probability of tails is 0. The entropy in this case is:

```
$H(X) = -(1)log(1) + (0)log(0) = 0$
```

If we know that the result is always going to be, then there is no uncertainty when the coin is dropped. The entropy of $p$ positive examples and $n$ negative examples is:

```
$H(p, n) = -\frac{p}{p+n}log(\frac{p}{p+n}) + (\frac{n}{p+n})log(\frac{n}{p+n}) \quad (2.9)$
```

Thus, the entropies for the three possible values of $Price$ are:

```
$H_{price=low}(4,0) = -\frac{4}{4+0}log(\frac{4}{4+0}) + (\frac{0}{4+0})log(\frac{0}{4+0}) = 0$
$H_{price=medium}(2,4) = -\frac{2}{2+4}log(\frac{2}{2+4}) + (\frac{4}{2+4})log(\frac{4}{2+4}) = 0.918$
$H_{price=high}(0,2) = -\frac{0}{0+2}log(\frac{0}{0+2}) + (\frac{2}{0+2})log(\frac{2}{0+2}) = 0$
```

The average of those three can be calculated by taking into account the number of corresponding instances for each value and the total number of instances:

```
$meanH(price) = (4/12)(0) + (6/12)(0.918) + (2/12)(0) = 0.459$
```

Before deciding to split on $Price$ the entropy of the entire dataset is 1 since there are positive and negative examples:

Nowadays, most smartphones with a tri-axial accelerometer sensor. This sensor measures inertial forces from the $x$, $y$, and $z$ axes. This information can be used to capture movement patterns from the sensor and automate the monitoring of the type of physical activity being performed.

In this section, we will use decision trees to automatically classify physical activities from acceleration data. We will use the SMARTPHONE ACTIVITIES dataset that contains acceleration records that were collected with a smartphone. This dataset is WISDM2 and was made by Kwaspis et al. (2010). The dataset has 6 different features: ‘walking’, ‘jogging’, ‘walking upstairs’, ‘walking downstairs’, ‘sitting’ and ‘standing’. The data was collected by 36 volunteers with an Android phone located in their pant's pocket with a sampling rate of $20Hz$ (1 sample every 50 milliseconds).

The dataset contains two types of files. One with the raw accelerometer data and the other after feature extraction.
