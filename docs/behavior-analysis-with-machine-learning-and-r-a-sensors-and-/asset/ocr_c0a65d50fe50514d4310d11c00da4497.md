+   1. Compute a distance matrix $D'$ from $C$.
2. Move the coordinates $C$ such that the distances of $D'$ get closer to the original ones in $D$.
3. Repeat from step 2 until the difference between $D'$ and $D$ cannot be reduced any further or some predefined maximum number of iterations.

The script `iterativeMDS.R` implements this algorithm (`iterativeMDS()` function) which is based on the implementation from (Segaran, 2007). Its first argument $D$ is a distance matrix, the second argument `maxit` is the total number of iterations and the last argument `lr` controls how fast the points are moved in each iteration. The script also shows how to apply the method to the `eurodist` dataset which consists of distances between European cities. Figure 4.7 shows the initial coordinates of the cities. Figure 4.8 shows the result after 30 iterations. Finally, Figure 4.9 shows the final result. By only knowing the distance matrix, the algorithm was able to find a visual mapping that closely resembles the real positions.
