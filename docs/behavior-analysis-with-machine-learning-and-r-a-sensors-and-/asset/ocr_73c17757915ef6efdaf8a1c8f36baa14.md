df1 <- data.frame(label=rep("class1", n1),

# Generate random values for class2.
x2 <- rnorm(mean=1.5, sd=0.5, n=n2)
y2 <- rnorm(mean=1.5, sd=1, n=n2)
df2 <- data.frame(label=rep("class2", n2),
                x=x2, y=y2, stringsAsFactors = T)

# This is our imbalanced dataset.
imbalancedDf <- rbind(df1, df2)

```
# Print class counts.
summary(imbalancedDf$class2)
#> class1 class2
#> 200 15
```

If we want to exactly balance the class counts we will pick 185 instances of type `class2`. We can use the well known sample() function to pick 185 points from data frame df2 (which contains only instances of `class2`) and stored them in `new.points`. Notice the replace = T parameter. This instructs the function to be allowed to pick repeated elements. Then, the new data points are appended to the imbalanced data set which now becomes balanced.

```
# Generate new points from the minority class.
new.points <- df2[sample(nrow(df2), size = 185, replace = T)],
```

```
# Add new points to the imbalanced dataset and save the
# result in balancedDf.
balancedDf <- rbind(imbalancedDf, new.points)
```

```
# Print class counts.
summary(balancedDf$class2)
#> class1 class2
#> 200 200
```
