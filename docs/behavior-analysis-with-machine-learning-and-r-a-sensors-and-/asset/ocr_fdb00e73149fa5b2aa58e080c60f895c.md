# 2.6.2 Uniform Classifier

This is another type of dummy classifier. One predicts classes at random with equal probability and can be implemented as follows.

```
# Define the dummy classifier's train function
uniform.train <- function(data){

# Get the unique classes.
unique.classes <- unique(data$class)

return(unique.classes)
}

# Define the dummy classifier's predict function.
uniform.predict <- function(params, data){

# Sample classes uniformly.
return(sample(unique.classes, size = nrow(data), replace = T))
}

```

At prediction time, it just picks a random label for each instance in the test set. This model achieved an accuracy of only 49% using the same dataset, but it was able to identify more of the ‘Upstairs’ classes.
