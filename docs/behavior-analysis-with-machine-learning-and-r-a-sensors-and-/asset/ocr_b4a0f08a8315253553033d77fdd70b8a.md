The outer loop is run until the algorithm converges or until a predefined number of iterations is reached. Each iteration is also an **epoch**. Each weight is updated with the rule: $w_i = w_i - \alpha \frac{\partial L(W)}{\partial w_i}$. The derivative part will give us the direction and magnitude. The $\alpha$ is called the **learning rate** and it controls how 'fast' we move. A learning rate is a constant defined by the user, thus it is a **hyperparameter**.
