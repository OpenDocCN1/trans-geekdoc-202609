Originally, the missing values are encoded as NaN but in order to use the simputation package functions, we need them as NA. First, NaNs are replaced with NA. The first argument of impute_lm is a data frame and the second argument is a formula. We discard the first 4 variables of the data frame because the left hand of the formula (everything before the symbol) specifies the variables we want to impute. The right-hand side specifies the variables used to build the linear models. The '+' indicates that we want to use all variables while the '-' is used to specify variables that we do not want to include. The vignettes^1 of the package contain more detailed examples.

> The mean, median, etc and the predictive models for missing values should be trained using only data from the train set to avoid information injection.
