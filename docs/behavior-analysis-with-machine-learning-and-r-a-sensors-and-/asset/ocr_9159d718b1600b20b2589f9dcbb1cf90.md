```
colMeans(byClass,c("Recall", "Specificity", "Precision", "F1")
# Recall Specificity Precision F1

```

# 2.2.1 Confusion Matrix

As briefly introduced in the previous section, the confusion matrix provides a nice way to understand the model's predictions and spot where it makes mistakes. Figure 2.4 shows a confusion matrix for the binary case. The columns represent the true classes and the rows predicted classes. The P stands for the positive cases and the N for the negative ones. Each entry in the matrix corresponds to the TP, TN, FP, and FN. The TP and TN are the correct classifications whereas the FN and FP are the misclassifications.
