Monotonicity. This constraint allows ‘time to flow’ only from left to right. That is, we can not go back in time.

```
$\phi_x(k+1) \geq \phi_x(k)$
$\phi_y(k+1) \geq \phi_y(k)$
```

Local constraints. For example, allow jumps of at most 1 step.

```
$\phi_x(k+1) - \phi_x(k) \leq 1$\n$\phi_y(k+1) - \phi_y(k) \leq 1$
```

Also, it is possible to apply global constraints, other local constraints, and apply different weights to slopes the three described above are the most common. For a comprehensive list of constraints, please see (Rabiner and Juang, 1993).
