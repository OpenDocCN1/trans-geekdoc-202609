One important thing to note is that computing the posterior may cause a loss numeric precision specifically, when there are many features. This is because multiplying the likelihoods for each feature (equation (2.13)) and those likelihoods are small numbers. One way to fix this is to use logarithms. In naive.bayes.predict() we can change accum.prob <- params$priors[c] with accum.prob <- log(params$priors[c]) and accum.prob <- accum.prob * tmp with accum.prob <- accum.prob + log(tmp). If you try those changes you should get the same result as before.
