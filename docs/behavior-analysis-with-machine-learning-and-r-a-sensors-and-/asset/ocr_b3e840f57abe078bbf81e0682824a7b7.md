One thing about this index is that it can be visually interpreted. To generate a silhouette plot, use the plot() function and pass the object returned by silhouette().

```
plot(si, cex.names=0.6, col = 1:4,
     main = "Silhouette plot, k=4",
     border=NA)
```

Figure 6.8 shows the silhouette plot when k = 4. The horizontal lines represent the individual silhouette indices. In this plot, all of them are positive.
