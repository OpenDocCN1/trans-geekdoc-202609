From the perspective of one unit that receives inputs from the previous hidden layer with dropout, approximately half of its incoming connections will be gone (if $p = 0.5$). See Figure 8.24.

Dropout has the effect of making units not to rely on any single incoming connection, this makes the whole network able to compensate for the lack of connections by learning alternative paths. In practice and for many applications, this can result in a more robust model. A side effect of applying dropout is that the expected value of the activation function of a unit will be diminished because half of the previous activations will be 0. Recall the output of a neuron is computed as:

```
$f(\mathbf{x}) = g(\mathbf{w} \cdot \mathbf{x} + b)$
```

where $\mathbf{x}$ contains the input values from the previous layer, $\mathbf{w}$ the corresponding weights and $g()$ is the activation function. With dropout, approximately half of the values of $\mathbf{x}$ will be 0. To compensate for that, the input values need to be scaled, in this case, by a factor of 2.

```
$f(\mathbf{x}) = g(\mathbf{w} \cdot 2\mathbf{x} + b)$
```
