Each node in a tree represents partial or final decisions based on a single feature. If a node is a leaf, it leads to a final decision. A leaf is simply a terminal node, i.e. it has no children nodes. Given a feature vector representing an instance, the predicted class is obtained by testing the feature values and following the tree path until a leaf is reached. Figure 2.6 shows an example decision tree and a query instance with an unknown class. To get the final decision, features are evaluated starting at the root. In this *number_wheels* is 4 in the query instance the weight is 2300 and we take the right path. Now, we need to evaluate *weight*. This the test is false since the final class is *truck*. Usually, small trees are preferred (small depth) because they are easier to visualize and interpret and are less prone to overfitting. The example tree has a depth of 2. The number of wheels had been 2 instead of 4, testing the *weight* feature would not have been necessary.
