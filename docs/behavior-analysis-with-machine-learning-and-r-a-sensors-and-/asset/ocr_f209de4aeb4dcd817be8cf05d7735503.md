Figure 18.17 shows the output of the fit() function in RStudio. In the console, the training, mean squared error, and mean absolute error are printed during each epoch. In the viewer panes, plots of the same metrics are shown. Here, we can see that the loss is nicely decreasing over time. The loss at epoch 30 should be something close to 0.

The information saved in the history variable can be plotted with plot(history). This will generate plots for the loss, MSE, and MAE.

> These can be slightly different every time the training is run due to random weight initializations made by the back end.

Once the model is trained, we can perform inference on new data points with the predict_on_batch() function. Here we are passing three data points.
