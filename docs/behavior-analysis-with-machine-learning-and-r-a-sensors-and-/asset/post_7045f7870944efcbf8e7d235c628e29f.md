A trajectory is composed of 7 pieces of information:

-1. frame.number: Frame number in original video.
2. bounding.box.x: Bounding box leftmost edge.
3. bounding.box.y: Bounding box topmost edge.
4. bounding.box.w: Bounding box width.
5. bounding.box.h: Bounding box height.
6. class: 1=normal, 2=rare.
7. classDescription: 'normal' or abnormal.

The bounding boxes are the coordinates for each of the captured video frames. Figure 10.5 shows an example of a fish and its bounding box. Note that the dataset does not contain the images but only the bounding boxes' information.

## 10.2.2 Preprocessing and Feature Extraction

Now that we have explored and visualized the data, we can begin with the preprocessing and feature extraction. As previously mentioned, the database contains bounding boxes but we want to use the center of the boxes to define the trajectories. The following code snippet (from extract_features.R) shows how the center of a box can be computed.

```r
# Make times start at 0.
times <- trj$frame.number - trj$frame.number[1]
```

```r
tmp <- data.frame(x.coord, y_coord, time=times)
```

The x and y coordinates of the center points from a given trajectory trj for all frame times will be stored in x.coord and y.coord. The next line 'shifts' the frame numbers so they all start in 0 (to simplify preprocessing). Finally we store the coordinates and frame times in a temporal data frame for further preprocessing.

![](img/91c149cc24c3e5af2971580c9dda9d8b_338_0.png)

Figure 10.7: First trajectory of the database.

At this point we will use the trajr package (McLean and Volponi, 2018) which includes functions to plot and perform operations on trajectories. The TrajFromCoords() function can be used to create a trajectory object from a data frame. Note that the data frame needs to have a predefined order. That is why we first stored the x coordinates then the y coordinates and finally the time in the tmp data frame.

```r
tmp.trj <- TrajFromCoords(tmp, fps = 1)
```

The temporal data frame is passed as the first argument and the frames per second is set to 1. Now we can plot the tmp.trj object.

```r
plot(tmp.trj)
```

From Figure 10.7 we can see that there are big time gaps between points. This is because some time frames are missing. If we print the first rows of the trajectory and look at the time we can see that for example, steps 4, 5, 6 are missing.

```r
head(tmp.trj)
# x y time displacement polar displacement
```

From continuing, it would be a good idea to try to fill those gaps. The function TrajResample() does exactly that by applying linear interpolation along the trajectory.

```r
resampled <- TrajResample(tmp, 1)
```

If we plot the resampled trajectory we will see how the missing points were filled. Now we are almost ready to start detecting anomalies. Remember that Isolation Trees work by partitions. Thus, we need to convert the trajectories into a feature vector. To do that, we extract features from the trajectories based on speed and acceleration. The TrajDerivatives() function computes the speed and acceleration between pairs of points.

```r
derivs <- TrajDerivatives(resampled)

# Print first speeds.
head(derivs$speed)
# [1] 3.640055 2.000000 5.500000 8.225342 8.225342

# Print accelerations.
head(derivs$acceleration)
# [1] -1.640055 -3.500000 -2.725342 0.000000 0.000000
```

![](img/91c149cc24c3e5af2971580c9dda9d8b_340_0.png)

Figure 10.8: The original trajectory (circles) and after filling the gaps with linear interpolation (crosses). The number of resulting speeds and accelerations are $n-1$ and $n-2$ respectively where $n$ is the number of time steps in the trajectory. When training an Isolation Forest, all feature vectors need to be of the same length; however, the trajectories in the database have different number steps. In order to have fixed-length feature vectors, we will compute the mean, standard deviation, min, and max from both the speeds and accelerations. Finally, we will assemble the data frame along the trajectory and the label ('normal' or 'abnormal').

```r
f.meanSpeed <- mean(derivs$speed)
f.sdSpeed <- sd(derivs$speed)
f.minSpeed <- min(derivs$speed)
f.maxSpeed <- max(derivs$speed)
f.meanAcc <- mean(derivs$acceleration)
f.sdAcc <- sd(derivs$acceleration)
f.minAcc <- min(derivs$acceleration)
f.maxAcc <- max(derivs$acceleration)
```

```r
features <- data.frame(id=paste0("id", 1), label=trj$classDescription[1],
                      f.meanSpeed, f.sdSpeed, f.minSpeed, f.maxSpeed,
                      f.meanAcc, f.sdAcc, f.minAcc, f.maxAcc)
```
