$f(x) = y$

$f$ is a function that maps input data $x$ (for example images) to an output $y$ (types of fruits). Usually, an algorithm will try to learn the best model $f$ given data consisting of $n$ pairs $(x, y)$ of examples. During learning, the algorithm has access to the expected output/label $y$ for each input $x$. At inference time, that is, when we want to make predictions for new examples, we can use the learned model $f$ and feed it with a new $x$ to obtain the corresponding predicted value $y$.

- **Semi-supervised learning.** This is the case when the certainty of the labels is 100% but not all training data are labeled. Usually, this scenario considers the case when only a very small portion of the data is labeled. That is, the dataset contains pairs of examples of the form $(x,y)$ but also examples where $y$ is missing $(x)$. In supervised learning, both $x$ and $y$ must be present. On the other hand, semi-supervised algorithms can learn even if some examples are missing the expected output $y$. This is a common situation in real life since labeling data can be expensive and time-consuming. In the fruits example, someone needs to tag every training image manually before training a model. Semi-supervised learning methods try to extract information also from the unlabeled data to improve the models. Examples of semi-supervised learning methods are self-learning, co-training, tri-training, etc. (Triguero et al., 2013).

- **Partially-supervised learning.** This is a generalization that encompasses supervised and semi-supervised learning. Here, the examples have uncertain (soft) labels. For example, the label of a fruit image instead of being an "orange" or "pear" could be a vector [0.7, 0.3] where the first element is the probability that the image corresponds to the orange and the second element is the probability that it is a pear. Maybe the image was not clear, and these are the beliefs of the person tagging it as probabilities. Examples of models that can be used for partially-supervised learning are mixture models with belief functions (Côme et al., 2009) and neural networks.

- **Unsupervised learning.** This is the extreme case when no of the training examples have a label. That is, the dataset only has pairs (x, ?). Now might be wondering: If there are no labels, is it possible to extract information from these data? The answer is yes. If you have fruit images with no labels what you could try to do is to automatically group them into meaningful categories/groups. The categories could be the types of fruits themselves, i.e., forming groups in images within the same category belong to the same type. In the examples, we could infer the types by visually inspecting the images, but in many cases, visual inspection is difficult and the formed groups may not have an easy interpretation, but still, they can be useful and can be used as a preprocessing step (like in vector quantization). These type of algorithms find groups (hierarchical groups in some cases) **clustering methods.** Examples of clustering methods are k-means, k-methods, and hierarchical clustering. Clustering algorithms are not the only unsupervised learning methods. Association rules, word embeddings, and autoencoders are examples of other unsupervised learning methods. Some people disagree that word embeddings and autoencoders are not fully unsupervised but for practical purposes, this categorization is not relevant.

Additionally, there is another type of machine learning **Reinforcement Learning (RL)** which has substantial differences from the previous ones. This type of learning does not rely on example data as the previous ones but on stimuli from the agent's environment. At any given point in time, an agent can perform an action which will lead to a new state where a *reward* is collected. The aim is to learn the sequence of actions that maximize the reward. This type of learning is not covered in this book.¹

This book will mainly cover supervised learning problems and more specifically, classification problems. For example, given a set of wearable sensor readings, we want to predict contextual information about a given user such as location, current activity, mood, and so on. Unsupervised learning methods (clustering and association rules) will be covered in chapter 6.

### 1.3.2 Variable Types

When working with machine learning algorithms, the following are the most used types. Here, when I talk about variable types, I do not refer to programming-specific data types (int, boolean, string) but to more general types regardless of the implementation for each language.

- **Categorical/Nominal**: These variables take values from a discrete set of possible values (categories). For example, the categorical variable color can take the values "red", "green", "black", and so on. Categorical variables do not have an ordering.
- **Numeric**: Real values such as height, weight, price, etc.
- **Integer**: Integer variables such as number of rooms, age, number of floors, etc.
- **Ordinal**: Similar to categorical variables, these take their values from a set of discrete values, but they do have an ordering. For example, low < medium < high.

### 1.3.3 Predictive Models

In machine learning terminology, a predictive model is a model that takes some input and produces an output. Classifiers and Regressor are predictive models. I will use the terms classifier/model and regressor/model interchangeably.
