# 前言

得益于传感器和机器学习的发展，自动行为监测技术正成为日常生活的一部分。行为的自动分析和理解已应用于多个领域，包括医疗保健、体育、营销、生态、安全和心理学等。本书提供了使用 R 语言应用机器学习方法的实用介绍。本书不假设读者具备任何机器学习知识。你应该熟悉 R 的基础，并且具备高中水平的数学知识会有帮助。
