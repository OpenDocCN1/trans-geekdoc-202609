# 2.5 Dynamic Time Warping

![](bbox=[0.078, 0.396, 0.143, 0.426])

In the previous activity recognition example, we used the extracted features represented as feature vectors to train the classifiers instead of using the raw data. This can lead to temporal loss. In the previous example, we could classify the activities with reasonable accuracy since the extracted features were able to retain enough information from the raw data. However, in some cases, the need to retain temporal information is crucial. For example, in hand signature recognition, the need to check if a query signature matches one of the signatures from a database. The signatures need to have an almost exact match to authenticate a user, i.e, they need to look very similar. If we represent each signature as a feature vector, it can turn out that two signatures have similar feature vectors even though they look completely different. For example, Figure 2.16 shows four datasets. They look different but they have the same correlation of 0.816³

To avoid this potential issue, we can also include time-dependent information into our models by keeping the order of the data points. Another issue is that time series belong to the same class will have some differences. Every time the same person signs a document the signature will vary a bit. In the same way, when we pronounce a word, sometimes we emphasize certain letters or at different speeds. Figure 2.17 shows two versions of the sentence "very good". In the second one (bottom) the speaker emphasizes the "c" and as a result, the two sentences are not aligned in anymore but they have the same meaning.

If we wanted to compare two sequences we could use the well Euclidean distance. However the two sequences may not be aligned in time, the result could be misleading.
