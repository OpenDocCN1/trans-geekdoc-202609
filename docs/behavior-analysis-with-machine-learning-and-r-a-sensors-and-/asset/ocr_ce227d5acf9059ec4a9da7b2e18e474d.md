# Citing this Book

If you found this book useful, you can consider citing it like this:

Garcia-Ceja, Enrique. "Behavior Analysis with Machine Learning and R:
A Sensors and Data Driven Approach", 2020. http://behavior.enriquegc.com

BibTeX:

```
@book{GarciaCejaBook,
  title = {Behavior Analysis with Machine Learning and {R}:
  A Sensors and Data Driven Approach},
  author = {Enrique Garcia-Ceja},
  year = {2020},
  note = {\url{http://behavior.enriquegc.com}}
}
```
