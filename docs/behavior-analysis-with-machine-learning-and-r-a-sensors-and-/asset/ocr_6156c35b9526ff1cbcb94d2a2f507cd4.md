Be aware that when computing the cross-entropy with equation (8.17) order matters. The first element should be the predicted scores y' and the second element should be the true-one encoded vector y. We don't want to apply a log function to a vector with values of 0. Most of the time, the predicted scores y' will be different from 0 that's why we prefer to apply the log function to them. In the very rare case when the predicted scores have zeros, we can add a small number. In practice, this is taken care of by the backend (e.g., TensorFlow).

In this example, we will train a neural network with Keras to classify dataset hand gestures based on muscle electrical activity. The ELECTROMYOGRAPHY dataset will be used here. The electrical activity was recorded with an electromyography (EMG) sensor as an armband. The data were collected and made available by Yashunk (2019). The armband has 8 sensors which are placed on the skin surface and measure electrical activity from the right forearm at a sampling rate of 200 Hz. A video of the device can be found here: https://youtube.be/iu5-G6DPptkk

The first 64 columns are electrical measurements. 8 consecutive readings for each of the 8 sensors. The objective is to use the first 64 variables to predict the class.
