The most common smoothing method for timeseries is the simple moving average. With this method, the first element of the resulting smoothed series is computed by taking the average of the elements within a window of predefined size. The window's position starts at the first element of the original series. The second element is computed in the same way after moving the window position to the right. Figure 5.6 shows this procedure on a series with 5 elements and a window size of 3. After the third iteration, it is not possible to move the window one more step to the right while 3 elements since the end of the time series has been reached. Because of this, the smoothed series will have some missing values at the end. Specifically, it will have $w-1$ fewer elements where $w$ is the window size. A simple solution is to compute the average of the elements covered by the window even if they are less than the window size.

In the previous example average is taken from the elements to the right of the pointer. There is a variation called centered moving average in which the center point of the window has the same elements to the left and right (Figure 5.7). Note that with this version of

In the preprocessing.R script the function movingAvg() implements the simple moving average procedure. In the following code that the output vector will have the same size as the original but the last elements will contain NA values when the window can not be moved to the right.

```
movingAvg <- function(x, w = 5){
# Applies moving average to x with a window of size w.
n <- length(x) # Total number of points.
smoothedX <- rep(NA, n)

for(i in 1:(n-w+1)){
  smoothedX[i] <- mean(x[i:(i+w-1)])
}

return(smoothedX)
}
```

Figure 5.8 shows the result after plotting the original vector and the smoothed one. Here, we can see that many of the small peaks are not present anywhere in the smoothed version. The window size is a parameter that needs to be defined by the user. If it is too large some important information may be lost from the signal.

One of the disadvantages of this method is that the arithmetic mean is sensitive to noise. Instead of computing the mean, one can use the median which is more robust against outlier values. There also exist other methods (not covered here) such as weighted moving average and exponential moving average³ which assign more importance to data points closer the central point in the window. Smoothing a signal before feature extraction is a common practice and is used to remove some noise.
