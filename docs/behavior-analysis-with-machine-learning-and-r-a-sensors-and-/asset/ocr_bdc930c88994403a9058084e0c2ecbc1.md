The SMILE.list.txt points to the names of pictures in jpg format but we have them in ppm format so jpg extension is replaced by ppm with the gsub() function. The images in ppm format, we can use the pixmap library (Bivand et al., 2011) to read and plot them. The print() function can be used to display the image properties. Here, that are RGB images of 64x64 pixels.

```
library(pixmap)
```
