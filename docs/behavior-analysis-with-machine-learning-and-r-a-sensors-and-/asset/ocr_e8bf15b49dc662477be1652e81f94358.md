```
library(\dtw")

# Sequences from the example
query <- c(2,2,2,4,4,3)
ref <- c(2,2,3,3,2)

# Find dtw distance.
alignment <- dtw(query, ref, step = symmetric = T)
```

The keep.internals = T keeps the input data so it can be accessed later, e.g., for plotting. The cost matrix and final distance can be accessed from the resulting object.
