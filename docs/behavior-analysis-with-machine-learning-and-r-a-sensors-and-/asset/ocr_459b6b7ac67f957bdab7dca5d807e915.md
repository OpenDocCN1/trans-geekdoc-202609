When running the examples, it is assumed that the working directory is the same as the actual script. For example, if you want to try indoor_classification.R, and that script is located at C:/Predicting Behavior with Classification Models/ then, your working directory should be C:/Predicting Behavior with Classification Models/. In Windows, and if RStudio is not already opened, when you double-click an R script, RStudio will be launched (if it is set as the default) and the working directory will be set.

You can check your current working directory by getwd() and you can set your working directory with setwd(). Alternatively, in RStudio, you can set your working directory in the menu bar by 'Session' - 'Set Working Directory' -> 'To Source Location'.

# A.3 Running Shiny Apps

Shiny apps¹ are interactive applications written in R. This book includes shiny apps that demonstrate some of the concepts. Shiny apps file names will start with the prefix shiny_ followed by the specific file name. Some have an .Rmd extension while others have an .R extension. Regardless of the extension, they run in the same way. Before running shiny apps, make sure you have installed the packages shiny and shinydashboard.

```
install.packages("shiny")ninstall.packages("shinydashboard")
```
