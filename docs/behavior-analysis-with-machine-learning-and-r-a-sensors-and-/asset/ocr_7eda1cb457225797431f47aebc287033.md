```
set.seed(1234)
clusters <- kmeans(normdf, 7)
si <- silhouette(clusters$cluster, dist(normdf))
plot(si, cex.names=0.6, col = 1,
   main = "Silhouette plot, k=7",
   border=NA)
```

Here, cluster 2 and 4 have data points with negative indices and the overall score is 0.26. This suggests that k = 4 produces more coherent clusters compared to k = 7.
