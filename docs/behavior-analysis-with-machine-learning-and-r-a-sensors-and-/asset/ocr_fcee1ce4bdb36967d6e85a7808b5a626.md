# Original v.s. Smoothed timeseries.

![](bbox=[0.153, 0.122, 0.846, 0.347])

Figure 5.8: Original time series and smoothed version using a moving average window of size 21

GOATS data set.

```
datapath <- "../Sheep/S1.csv"
df <- read.csv(datapath)

# Only select a subset of the whole series.
defsegment <- df[$timestamp_ms < 6000,]
x <- dfsegment$ax

# Compute simple moving average with a window of size 21.
smoothed <- movingAvg(x, w = 21)
```

Figure 5.8 shows the result after plotting the original vector and the smoothed one. Here, we can see that many of the small peaks are not present anywhere in the smoothed version. The window size is a parameter that needs to be defined by the user. If it is too large some important information may be lost from the signal.

One of the disadvantages of this method is that the arithmetic mean is sensitive to noise. Instead of computing the mean, one can use the median which is more robust against outlier values. There also exist other methods (not covered here) such as weighted moving average and exponential moving average³ which assign more importance to data points closer
