The main question when building a tree which feature should be at the root (top). One answer this question, you may need to grow the tree by adding another feature (node) as one of the root's children. To decide which feature to add you need to answer the first question: “What feature should be at the root of this subtree?”. This is a recursive definition! The tree keeps growing until you reach a leaf node, there are no more features to select, or you have reached a predefined depth.

For the *cinema* dataset we need to find the best variable to be placed at root. Let's suppose we choose between *Price* and *Comedy*. Figure 2.8 shows these two possibilities.
