Now we define the predict function which takes as its first argument the learned parameters and second argument the test set on which we want to make predictions. The predict only consists of the name of a class.

```
# Define the dummy classifier's predict function.
most.frequent.class.predict <- function(params, data(){

# Return the same label for as many rows as there are in data.
return(rep(params, nrows(data)))

}
```

The only thing the predict function does is return the params argument that contains the class name repeated n times. Where n is the number of rows in the test data frame.

Let's try our functions. The dataset has already been split into 50% for training and 50% for testing. We first train the dummy model using the train set. Then, the learned parameter is printed.

```

```

