# 10.2.4 ROC curve and AUC

The receiver operating characteristic curve we also known as ROC curve is a plot that depicts the sensitivity and the false positive rate (FPR) as behave the detection threshold varies. The sensitivity/recall can be calculated by dividing the true positives by the number of positives TP/P (see chapter 2). The FPR = FP/N where FP are the false positives and N are the total number of negative examples (the normal trajectories). The FPR is also known as the probability of false alarm. Ideally, we want a model that has a high sensitivity and a low FPR.
