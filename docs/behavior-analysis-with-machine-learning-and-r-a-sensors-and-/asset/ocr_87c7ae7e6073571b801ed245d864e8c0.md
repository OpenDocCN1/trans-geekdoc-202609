# 8.1.4 Learning the Parameters

We have seen forward propagation based on the input values to compute the output of the network. In the previous examples, we assumed that the network's parameters (weights and biases) were already learned. In practice, you most likely be using libraries to build and train neural networks. Later in this chapter, I will show you how to use TensorFlow and Keras within R. Before, I will show you how networks' parameters are learned and how we can code and train a very simple network from scratch.

Back to the problem, the objective is to find the parameters' values based on training data such that the predicted result for any input data point is as close as possible to the true value. In other words, we need to find the parameters' values that reduce the network's prediction error.
