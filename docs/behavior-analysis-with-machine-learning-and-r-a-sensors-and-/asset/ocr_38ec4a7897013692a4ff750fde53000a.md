The most common activity turned out to be ‘Walking’ with 2081 instances. It seems that the volunteers were a bit sporty since ‘Jogging’ is the second frequent activity. One thing to note is there are some big differences here. For example, ‘Walking’ v. ‘Standing’. Those differences in class counts can have an impact on training classification models. This is because classifiers try to minimize the overall error regarding the performance of individual classes, thus they tend to prioritize the majority classes. This is called the class imbalance problem. This occurs when there are many instances of some classes
