Now, you can change the training set to make the network learn a different arithmetic operation!
In the previous example, we considered a very simple neural network consisting of a single unit. In this case, the partial derivative with respect to the single weight was calculated directly. For bigger networks with more layers and activations, the final output becomes a composition of functions. That is, the activation values of a layer depend on its weights which are also affected by the previous layer's l−1 and so on. The derivatives (gradients) can be computed using the chain rule f(x)' = f'(x) · g'(x). This can be performed efficiently by an algorithm known as backpropagation.
