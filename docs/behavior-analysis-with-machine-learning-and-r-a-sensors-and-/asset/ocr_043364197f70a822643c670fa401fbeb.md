# 1.6.1 K-fold Cross-Validation Example

Now, let's see how k-fold cross-validation can be implemented to test our classifier. I will choose a k = 5. This means that 5 independent sets are going to be generated and 5 iterations will be run.

```
# Number of folds
k <- 5

set.seed(123)

# Generate random folds.
folds <- sample(k, size = nrow(dataset), replace = TRUE

# Print how many instances ended up in each fold.
table(folds)
# 1 2 3 4 5
# 21 20 23 17 19
```

Again, we use the sample() function. This time we want to select random integers between 1 and k. The total number of integers will be equal to the total of instances n in the entire dataset. Note that we set replace = TRUE since k < n we need to pick repeated numbers. Each number will represent the fold to which each instance belongs to. As before, we need to make sure that each instance belongs only to one of the sets. Here, we are guaranteeing that by assigning each instance a single fold. We can use the table() function to print how many instances ended up in each fold. Here, we see that the folds will contain between 17 and 23 instances.
