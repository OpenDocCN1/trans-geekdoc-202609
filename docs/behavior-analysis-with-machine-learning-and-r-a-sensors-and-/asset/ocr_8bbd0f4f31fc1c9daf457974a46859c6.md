# 8.4.2 Dropout

Dropout is another technique used to reduce overfitting proposed by Srivastava et al. (2014). It consists of 'dropping' some of the units from a hidden layer for each sample during training. In theory, it can also be applied to input and output layers but that is not very common The incoming and outgoing connections of a dropped unit are discarded. Figure 8.23 shows an example of applying dropout to a network. In b), the middle unit was removed from the network in c), the top and bottom units were removed.
