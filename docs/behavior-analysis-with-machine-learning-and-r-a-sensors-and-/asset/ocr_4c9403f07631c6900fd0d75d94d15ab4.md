This is because we divided the data into a train and test sets. We need to extract the features from both sets by setting the train parameter accordingly.

The second step consists of clustering the extracted feature vectors. this step is only performed on the train set. The function clusterSimpleActivities() implements this. The feature vectors are grouped into 15 groups. This can be changed by setting constantsbandSize <= 15 to some other value. The function stores all feature vectors from all files in a single data frame and runs k-means. Finally, the centroids are saved in the file clustering/centroids.txt inside the train directory.

The next step is to label each feature vector by assigning assignActivitiesToCluster() to its closest centroid. The function reads from the text file and for each simple activity in the test set it finds the closest centroid using the Euclidean distance. The label (integer from 1 to 15) of the closest centroid is assigned and the results are saved in the labeled_activities/ directory. Each file contains the assigned labels (integers) for the corresponding feature vectors file in the simple_activities/ directory. Thus, if a file inside simple_activities/ has 100 feature vectors, then its corresponding file in labeled_activities/ should have 100 labels.

In the last step, the function convertHistogram() will generate the bag of words from the labeled activities. The BoW are stored as histograms (encoded as vectors) with each representing a label and its corresponding counts. In this case, the labels are w1..w15. The w stands for and was only appended for clarity to show that this is a label. This function will convert the counts into percentages (normalization) in case we want to perform classification, that is, the percentage of each word (simple activity) occurred during the entire complex activity. The resulting histograms/histograms.csv file contains the BoW as one histogram per row. Per complex activity. The first column is the complex activity's label in text format.

Figures 7.16 and 7.17 show the histogram for 'working' and 'exercising'. The x-axis shows the labels of the simple activities and the y-axis their relative frequencies.

Here we can see that the 'working' activity is composed mainly by the simple activities w1, w3, and w12. The exercising activity is composed mainly of w15 and w14 which perhaps are high-intensity movements like jogging or running.
