# Probability density function of normal distribution.

```
f <- function(x, m, s){
(1 / (sqrt(2*pi)*s) * exp(-(x-m)^2) / (2 * s^2))
}
```

It's first x is the input value. The second argument m is the mean and the last argument s is the standard deviation. For illustration purposes we are defining this function manually but remember that this pdf is already implemented with the dnorm() function.
