The outer loop is run until the algorithm converges or until a predefined number of iterations is reached. Each iteration is also an **epoch**. Each weight is updated with the rule: $w_i = w_i - \alpha \frac{\partial L(W)}{\partial w_i}$. The derivative part will give us the direction and magnitude. The $\alpha$ is called the **learning rate** and it controls how 'fast' we move. A learning rate is a constant defined by the user, thus it is a **hyperparameter**. A high learning rate can cause the algorithm to miss the local minima and the loss can start to increase. A small rate will cause the algorithm to take more time to converge. Let's see how gradient descent works with a step by step example. Consider a very simple neural network consisting of an input layer with one input feature and an output layer with one unit. To make even simpler, the activation function of the output unit is the identity function $f(x) = x$. Assume that we training data have a single data point. Figure 8.13 shows the simple network and the training data. The training data point only has one input variable $(x)$ and an output $(y)$. We want to train this network so that it can make predictions on new data points. The training point has a feature of $x = 3$ and the expected output is $y = 1.5$. For this particular training point, it ensures that the output is equal to the input divided by 2. Thus, based on this single training data point the network should learn how to divide any other input by 2.

Before we start the training we need to define 3 things:

- 1. The loss function. This is a regression problem so we can use the MSE. Since there is a single data point our loss function becomes $L(w) = (y'-y)^2$. Here, $y$ is the ground truth value and $y'$ is the predicted value. We know how to make predictions using forward propagation. In this case, it is the product between the input value and the single weight, and the activation function has no effect (it returns the same value as its input). We can rewrite the loss function as $L(w) = (xw-y)^2$.

- 2. We need to define a learning rate. For now, we can set it to an $\alpha = 0.05$.

![](img/91c149cc24c3e5af2971580c9dda9d8b_256_0.png)

a) Simple neural network

b) Training data with only a single point

Figure 8.13: a) A simple neural network consisting of one unit. b) The training data with only one row.

- 3. The weights need to be initialized at random. Let's assume the single weight is 'random' initialized with $w = 2$.

Now we use gradient descent to iteratively update the weight. Remember that the updating rule is:

```
$w = w - \alpha\frac{\partial L(w)}{\partial w} \quad (8.11)$
```

The partial derivative of the loss function with respect to $w$ is:

```
$$\frac{\partial L(w)}{\partial w} = 2x(xw - y) \quad (8.12)$$
```

If we substitute the derivative in the updating rule we get:

```
$w = w - \alpha2x(xw - y) \quad (8.13)$
```

We already know that $\alpha = 0.05$, the input value is $x = 3$, the output is $y = 1.5$ and the initial weight is $w = 2$. We can start updating $w$. Figure 8.14 shows the initial state (iteration 0) and 3 additional iterations. In the initial state, $w = 2$ and with that weight the loss is $0.025$. In iteration 1, $w$ is updated and now its value is $0.65$. With this new weight, the loss is $0.0025$. There was a substantial reduction in error! After three iterations we see that the final weight is $w = 0.501$ and the loss is very close to zero.

Now, we can start doing predictions with our very simple network! To do so, we use forward propagation on the new input using the learned weight $w = 0.501$.

8.15 shows the predictions on new data points that were never seen by the network. Even though the predictions are not perfect, they are very close to the expected value (division by 2) considering that the network is very simple and was only trained with a single data point and only 3 epochs!

If the training set has more than one data point, then we need to compute the derivative of each point and accumulate them (the derivative of a sum is equal to the sum of derivatives). In the previous example, the update rule becomes:

$$w = w - \alpha \sum_{i=1}^{N} 2x_i(w - y) \quad (8.14)$$

This means before updating a weight, first we need to compute the derivative for each point and add them. This needs to be done for every parameter in the network. Thus, each **epoch** is a pass through all training points and all parameters.

In the previous section, we went step by step to train a neural network with a single unit and a single data point. Here, we will see how we can implement simple network in R when we have more training data. The code can be found in the script gradient_descent.R.

This code implements the same network as the previous example. That is, one input input, no bias, and activation function $f(x) = x$. We are creating a sample training set with 3 points. Again, the output is the input divided by 2.

```r
train_set <- data.frame(x = c(3.0,4.0,1.0,0), y = c(1.5, 2.0, 0.5))
# Print the train set.
print(train_set)
# x y
# 1 3 1.5
# 2 4 2.0
# 3 1 0.5
```

Then we need to implement 3 functions: forward propagation, the loss function, and the derivative of the loss function.

```r
# Forward propagation w*x
fp <- function(w, x){
  return(w * x)
}
```

```r
# Loss function (y - y')^2
loss <- function(w, x, y){
  predicted <- fp(w, x) # This is y'
  return(y - predicted)^2
}
```

```r
# Derivative of the loss function. 2x(xw - y)
derivative <- function(w, x, y){
  return(2.0 * x * ((x * w) - y))
}
```

Now we are set to implement the gradient.descent() function. The first parameter is the train set, the second parameter is the learning rate alpha and the last parameter is the number of epochs. The initial weight is initialized to 'random' number (selected manually for the example). The function returns the final learned weight.

```r
# Gradient descent.
gradient.descent <- function(train_set, lr = 0.01, epochs = 5){

  w = -2.5 # Initialize weight at 'random'

  for(i in 1:epochs){
    derivative.sum <- 0.0
    loss.sum <- 0.0

    # Iterate each data point in train_set.
    for(j in 1:nrow(train_set)){
      point <- train_set[j,]

      derivative.sum <- derivative.sum + derivative(w, point$x, point$y)
      loss.sum <- loss.sum + loss(w, point$x, point$y)
    }

    # Update weight.
    w <- w - lr * derivative.sum

    # mean squared error (MSE)
    mse <- loss.sum / nrow(train_set)

    print(paste0("epoch: ", i, ", loss: ", 
      formatC(mse, digits = 8, format = "f"),
      " w = ", formatC(w, digits = 5, format = "f"))))
  }

  return(w))
}
```
