By default, ntree = 500. Among other things, you can control how many random features are sampled at each split with the mtry argument. By default, for classification mtry = floor(sqrt(ncol(x))) and for regression mtry = max(ncol(x)/3), 1).

The following code will perform 5-fold cross-validation with the activities dataset-ready stored in df and print the results. The complete code can be found in the script randomForest_activities.R.

```
set.seed(1234)

k <- 5

folds <- sample(k, size = nrow(df), replace = TRUE)

# Variable to store ground truth classes.
groundTruth <- NULL

# Variable to store the classifier's predictions.
predictions <- NULL

for(i in 1:k){

trainSet <- df[which(folds != i), ]
testSet <- df[which(folds == i), ]

rf <- randomForest(class = ., trainSet, ntree = 10)
foldPredictions <- predict(rf, testSet)

predictions <- c(predictions, as.character(foldPredictions))

groundTruth <- c(groundTruth, as.character(testSet$class))
}

cm <- confusionMatrix(as.factor(predictions), as.factor(groundTruth))

# Print accuracy
cm$overall["Accuracy"]
#>Accuracy
```
