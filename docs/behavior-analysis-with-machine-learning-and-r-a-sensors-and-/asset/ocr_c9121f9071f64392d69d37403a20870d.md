where $H(x)$ is the harmonic number and is estimated by $\ln(x) + 0.577215649$ (Euler-Mascheroni constant).

A practical 'trick' that Isolation Forests use *sub-sampling without replacement*. That is, instead of using the entire training, an independent random sample of size $p$ is used to build each tree. The sub-sampling reduces the swamping and masking effects. The former occurs when normal instances are too close to anomalies and thus, marked as anomalies. The latter refers to the presence of too many anomalies close together. This increases the number of partitions needed to isolate each anomaly point.

Figure 10.3 (left) shows a set of 4000 normal instances and 100 anomalous instances clustered in the same region. The right plot shows how it looks after sampling 256 instances from the total. Here, we can see that the anomalous points are more clearly separated from the normal ones.

Previously, I mentioned that trees are grown until a predefined maximum height is reached. The authors suggest to set this maximum height to $l=\lceil\log_2(p)\rceil$ which approximates the average tree height. Remember that $p$ is the sampling size. Since anomalous instances are closer to the root, we can expect normal instances to be in the lower sections of the tree, thus, there is no need to grow the entire tree and we can limit its height.

The only two parameters of the algorithm are the number of trees and the sampling size $p$. The authors recommend a default sampling size of 256 and 100.

At training time, the ensemble of trees are generated using the train data. It is not necessary that the train data contains anomalous instances.
