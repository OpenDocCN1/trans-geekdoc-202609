This method has several advantages including its efficiency in time and memory usage. Another advantage is at training time it does not require to have examples of the anomalous cases but if available, they can be incorporated as well. This method is based on trees, another thing about it is that it does not require to scale the features.

This method is based on the observation that anomalies are ‘few and different’ which makes them easier to isolate. This method builds an ensemble of trees where each tree is called Isolation Tree. Each Isolation Tree partitions the features until every instance is isolated (it’s at a leaf node). Since anomalies are easier to isolate they will be closer to the root of the tree. An instance is marked as an anomaly if it has a short path length to the root across all Isolation Trees.

A tree is generated recursively by randomly selecting a feature and then selecting a partition point between the maximum and minimum value of that feature. Each partition corresponds to a split point in tree. The procedure terminates when all instances are isolated. The number of partitions that were required to isolate a point corresponds to the path length of that point to the root of the tree.

Figure 10.1 shows a sets of points with only 1 feature (x axis). One of the anomalous points is highlighted as a red triangle. One of the normal points is marked as a blue solid circle.

If we want to isolate the anomalous instance we can randomly and recursively choose partition points (red vertical lines) until the instance is encapsulated in its partition. In this example, it took 4 partitions to isolate the anomalous instance, thus, the path length of this instance to the root of the tree is 4. The partitions were located at 0.51, 1.6, 1.7, and 1.8.

## Average path lengths

The code to reproduce this example is in the script example_isolate_point.R. If we look at the highlighted normal instance we can see that it took 8 partitions to isolate it.

Instead of generating a single tree, we can generate an ensemble of n trees and average their path lengths. Figure 10.2 shows the average path length from the previous normal and anomalous instances as the number of trees in the ensemble is increased.

After 200 trees, the average path length of the normal instance starts to converge to 8.7 and the path length of the anomalous one converges to 3.1. This shows that anomalies have shorter path lengths on average.

In practice, an Isolation Tree is recursively grown until a predefined maximum height is reached (more on this later), or when all instances are isolated, or all instances in a partition have the same values. Once all Isolation Trees in the ensemble (Isolation Forest) are generated, the instances can be sorted according to their average path length to the root. Then, instances with shorter path lengths can be marked as anomalies.

Instead of directly using the average path lengths for deciding whether or not an instance is an anomaly, the authors of the method proposed an anomaly score that is between 0 and 1. The reason for this, is that this score is easier to interpret since it's normalized. The closer the anomaly score is to 1 the more likely the instance is anomaly. Instances with anomaly scores << 0.5 can be marked as normal. The anomaly score for an instance x can be computed with the formula:

```
$s(x) = 2^{-\frac{E(h(x))}{c(n)}}$ \quad (10.1)
```

where $h(x)$ is the path length of $x$ to the root of a given tree and $E(h(x))$ is the average of the path lengths of $x$ across all trees. $n$ is the number of instances in the train set and $c(n)$ is the average path length of an unsuccessful search in a binary search tree:

```
$c(n) = 2H(n-1) - (2(n-1)/n) \quad (10.2)
```

where $H(x)$ is the harmonic number and is estimated by $\ln(x) + 0.577215649$ (Euler-Mascheroni constant).

A practical 'trick' that Isolation Forests use *sub-sampling without replacement*. That is, instead of using the entire training, an independent random sample of size $p$ is used to build each tree. The sub-sampling reduces the swamping and masking effects. The former occurs when normal instances are too close to anomalies and thus, marked as anomalies. The latter refers to the presence of too many anomalies close together. This increases the number of partitions needed to isolate each anomaly point.

Figure 10.3 (left) shows a set of 4000 normal instances and 100 anomalous instances clustered in the same region. The right plot shows after sampling, we can see the anomalies are clearly separated from the normal ones. Previously, I mentioned that trees are grown until a predefined maximum height. The authors suggest this height to $\lceil\log_2(p)\rceil$ which approximates the average path length. $p$ is the sampling size. In training time, the ensemble of trees are generated using the train data. At test time, instances are passed through all trees and an anomaly score is computed for each. Instances with anomaly score greater than some threshold are marked as anomalies. The optimal threshold can be estimated using Area Under Curve analysis which will be covered in the following sections. The authors recommend a default sampling size of 256. ## 10.2 Detecting Fish Behaviors

In marine biology, the analysis of fish behavior is essential since it can be used to detect environmental changes produced by pollution, climate change, etc. Fish behaviors can be characterized by their trajectories, that is, how they move within the environment. A **trajectory** is the path that an object follows through space and time.

Capturing fish trajectories is a challenging task specially in unconstrained underwater conditions. Frankly, the Fish4Knowledge project has developed fish analysis tools and methods to ease the task. They have processed enormous amounts of video streaming data and have extracted fish information including trajectories. They have made the fish trajectories dataset publicly available (Beyan and Fisher, 2013).

The FISH TRAJECTORIES dataset contains 3102 trajectories belonging to the Dascyllus retatus fish (see Figure 10.4) observed in the Taiwanese coral reef. Each trajectory is labeled as 'normal' or 'abnormal'. The trajectories were extracted from underwater video and are stored as coordinates over time. Our main task will be to detect the abnormal trajectories using an Isolation Forest before that, we are going to explore, visualize, and pre-process the dataset.
