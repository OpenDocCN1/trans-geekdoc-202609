First, we read the dataset from the csv file and store it in the data frame df. To make things easier, the data frame is converted into a list of lists using the auxiliary function wifiScansToList() which is defined in the script indoor_auxiliary.R. Next we print the number of instances in the dataset, that is, the number of lists in the dataset list. The dataset contains 365 instances. The 365 was a coincidence, the data was not collected every day during one year but the same day. Next, we extract the first instance with dataset[[1]]. Here, we can see that each instance has three pieces of information. The class (location), a unique id (scanid), and a set of access points stored in a data frame. The first instance has two access points with MAC addresses 1 and 2. There is also information about the signal strength, though, one will not be used.

Since we would expect that similar locations have similar MAC addresses and locations that are far away from each other have we need a distance measure that captures this notion of similarity. In this case, we cannot use the Euclidean distance on MAC addresses. Even though they were encoded as integer values, they do not represent magnitudes but unique identifiers. Each instance is composed of a set of n MAC addresses stored in the accessPoints data frame. To compute the distance between two instances (two sets) we can use the Jaccard distance.
