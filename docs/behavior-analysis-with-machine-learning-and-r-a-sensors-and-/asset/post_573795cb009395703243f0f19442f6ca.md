## 2.5 Dynamic Time Warping

![](img/91c149cc24c3e5af2971580c9dda9d8b_86_0.png)

In the previous activity recognition example, we used the extracted features represented as feature vectors to train the classifiers instead of using the raw data. This can lead to temporal loss. In the previous example, we could classify the activities with reasonable accuracy since the extracted features were able to retain enough information from the raw data. However, in some cases, the need to retain temporal information is crucial. For example, in hand signature recognition, the need to check if a query signature matches one of the signatures from a database. The signatures need to have an almost exact match to authenticate a user, i.e., they need to look very similar. If we represent each signature as a feature vector, it can turn out that two signatures have similar vectors even though they look different. For example, Figure 2.16 shows four datasets. They look different but they have the same correlation of 0.86. To avoid this potential issue, we can also include time-dependent information into our models by keeping the order of data points. Another issue is that time series belong to the same class will have some differences. In the same way, when we pronounce a word, sometimes we emphasize certain letters or at different speeds. Figure 2.17 shows two versions of the sentence "very good". If we wanted to compare two sequences we could use Euclidean distance. However the two sequences may not be aligned in time, the result could be misleading.

To account for this “time-shift” effect in time series we can use Dynamic Time Warping (Sakoe et al., 1990) when comparing two time series. DTW is a method that:

- Finds an optimal match between two given time-dependent sequences.
- Computes the dissimilarity between the sequences.
- Finds the optimal deformation of one sequences onto the other.

Another advantage of DTW is that the time series do not need to be of the same length. Suppose we have two time series, a *query* and *reference* we want to compare:

The first thing to note is that both sequences differ in length. Figure 2.18 shows a plot with the two sequences. The *query* is the solid line. It can see that the *query* seems to be shifted to the right one position with respect to the *reference*. The plot also shows the resulting alignment after applying the DTW algorithm (dashed lines between the sequences). The resulting distance between the sequences is 3. In the following, we will see how the problem can be formalized and the steps to compute final distance. Don't worry if you find the math notation a bit difficult to grasp. A step by step example will follow which should help to explain how the method works.

The problem of aligning two sequences can be formalized as follows (Rabiner and Juang, 1993). Let *X* and *Y* be two sequences:

$X = (x_1, x_2, \dots, x_{T_x})$
$Y = (y_1, y_2, \dots, y_{T_y})$

$x_i$ and $y_i$ are vectors. In the previous example, the vectors only have one element since the sequences are 1-dimensional but DTW also works with multidimensional sequences. $T_x$ and $T_y$ are the sequences' lengths.

$d(i_x, i_y)$ be the *dissimilarity* (distance) between vectors $x_i$ and $y_i$ (e.g., Euclidean distance). Then, $\phi_x$ and $\phi_y$ are the warping functions that relate $i_x$ and $i_y$ to a common axis $k$:

$i_x = \phi_x(k), k = 1, 2, \dots, T$
$i_y = \phi_y(k), k = 1, 2, \dots, T.$

The total dissimilarity between the two sequences:

$d_{\phi}(X, Y) = \sum_{k=1}^{T} d(\phi_x(k), \phi_y(k))$

The aim is to find the warping function $\phi$ that minimizes the total dissimilarity:

$\min_{\phi} d_{\phi}(X, Y)$

The solution can be efficiently computed using dynamic programming. Usually, when solving this minimization problem, some constraints are applied:

- **Endpoint constraints.** This constraint makes sure that the first and last elements of each sequence are connected.

$\phi_x(1) = 1, \phi_y(1) = 1$
$\phi_x(T) = T_x, \phi_y(T) = T_y$
