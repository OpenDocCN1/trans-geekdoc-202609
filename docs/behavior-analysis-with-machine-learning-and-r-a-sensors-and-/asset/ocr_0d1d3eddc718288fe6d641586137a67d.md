The local cost matrix is the same as one in Figure 2.19 but in rotated form. The resulting object also has the dynamic programming table which can be plotted along with the resulting backtracking.

```
ccm <- alignment$costMatrix
image(x = 1:nrow(ccm), y = 1:ncol(ccm),
      ccm, xlab = "Q", ylab = "R"
text(row(ccm), col(ccm), label = ccm)
lines(alignment$index1, alignment$index2)
```
