
# 总体而言，本章旨在提供关于健康监测系统所涉及的网络安全风险的见解，以及在保护个人健康信息方面数据隐私和安全的重要性。

数字监测系统（如HES）最重要的创新在于日益被接受数字健康服务渗透个人的私人空间并规管健康受助者的生活。这一趋势表明，未来更多人将愿意分享个人数据以便从数字健康系统中获益。数字健康工具正日益流行，用于监测生命体征、药物、生育、睡眠、体能、心理健康及其他健康指标，并有望在未来变得更加功能化。健康监测过程不仅局限于私人项目，还将由国家专业化。例如，德国开发的 Datenspende-App 收集用户健身追踪器的一般运动和健身数据，并将其发送至罗伯特·科赫研究所（RKI）进行分析。与疫情期间的接触追踪设备不同，该应用不追踪接触，而是寻找与脉搏率、睡眠节律和活动水平异常相关的数据，这些异常可能提示急性呼吸道疾病（如 COVID-19）的存在。此类由国家主导的健康监测实践在未来可能更加普遍。这类基于移动设备的应用程序，可能是我们未来将遇到的先进数字健康服务的第一步，它们包含正负面案例，为健康组织在网络安全、数据准确性以及隐私尊重方面提供基础设施。
