
# 1. 选举选民统计

2020年11月3日，早期选民人数超过1.5亿，是总统选举中最重要的选民之一。选民投出的选票被反复计数（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。当1.5亿美国人前往投票站参加美国总统选举时，安全官员24/7确保网络攻击、虚假信息和误导性宣传活动不会干扰公民的投票权。俄罗斯、伊朗和中国黑客发起攻击，企图影响选举（`[Ng, 2020](#978-1-6684-9018-1.ch011.xhtml#r29)`）。选民以现场投票、邮寄选票和邮寄方式投出选票；然而，欺诈事件极为罕见。邮寄选票被特朗普政府视为欺诈，据称被否决。

此外，特朗普未找到支持邮寄选票欺诈指控的证据（`[Ng, 2020](#978-1-6684-9018-1.ch011.xhtml#r29)`）。选举官员保护了美国选民的选票以及俄罗斯和伊朗试图阻止人们投票的虚假信息（`[Ng, 2020](#978-1-6684-9018-1.ch011.xhtml#r29)`）。外部行动者多次尝试在一个后勤复杂的选举中干扰选举。联邦当局对在选举期间未遭受重大破坏性活动或网络攻击感到谨慎乐观。然而，来源警告称，未来几天仍可能发生干扰（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。作为证据，美国官员宣称，全国记录到大规模投票率，这体现了机构领导的决心以及美国人对保障其选票和选举有效性的信心（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。

2020年11月3日，早期选民人数超过1.5亿，是任何总统选举中最大的之一（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。选民投出选票，选举官员反复计数选票。外部人员多次尝试在一个后勤复杂的选举中干扰选举（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。作为证据，美国官员宣称，全国记录到巨大的投票率，这体现了机构领导的决心以及美国人对保障其选票和选举有效性的信心（`[Ewing, 2020](#978-1-6684-9018-1.ch011.xhtml#r16)`）。

# 2. 选举官员和声明

2020年11月17日，CISA负责人克里斯·克莱斯（Chris Krebs）因表示选举安全有序且拒绝关闭选举欺诈指控而被特朗普总统解雇。克莱斯称，他没有在密歇根州发现选民欺诈证据（`[Ng, 2020](#978-1-6684-9018-1.ch011.xhtml#r29)`）。克莱斯早期警告俄罗斯避免干预，驳斥毫无根据的选民欺诈指控，而特朗普因未在总统选举中发现欺诈而解雇了他（`[Ng, 2020](#978-1-6684-9018-1.ch011.xhtml#r29)`）。

选举基础设施政府协调委员会（GCC）执行委员会成员、网络安全和基础设施安全局（CISA）助理局长鲍勃·科尔斯基（Bob Kolasky），美国选举援助委员会主席本杰明·霍尔兰德（Benjamin Hovland），国家州务卿协会（NASS）主席玛吉·托勒斯·奥利弗（Maggie Toulouse Oliver），国家州选举管理局（NASED）主席洛里·奥吉诺（Lori Augino），佛罗里达州埃斯坎比亚县（Escambia County）选举监督员大卫·斯塔福德（David Stafford），以及选举基础设施部协调委员会（SCC）成员包括联合投票解决方案（Unisyn Voting Solutions）主席布赖恩·黑克（Brian Hancock），哈特互动（Hart InterCivic）副主席山姆·德黑默（Sam Derheimer），选举系统与软件（Election Systems & Software）克里斯·瓦林申（Chris Wlaschin），电子登记信息中心（Electronic Registration Information Center）埃里卡·哈斯（Ericka Haas），以及民主工作（Democracy Works）玛丽亚·毕巴尼（Maria Bianchi）发布了以下声明：

2020年11月3日的选举是美国历史上最安全的一次。选举官员在全国范围内审查并双重检查了整个选举过程，然后才最终确认结果。当州出现选举结果紧凑时，许多州会重新计票。2020年总统大选中所有即时结果的条件都有纸质记录，每一票都可以在必要时重新计数，这为安全和韧性提供了额外好处。此过程可识别并纠正任何错误或失误。有证据表明，任何投票系统若删除了或丢失了选票、更改了选票或被破坏，均可被发现。其他安全措施如选前测试、州对投票设备的认证，以及美国选举援助委员会（EAC）对投票设备的认证，进一步增强了2020年所使用投票系统的信心。与此同时，关于选举过程的许多毫无依据的指控和误导性信息机会颇多，这无疑是对选举安全和完整性的最高信心。当您有疑问时，请向选举官员咨询，他们是值得信赖的声音，负责管理选举。（`[Cybersecurity and Infrastructure Security Agency, 2020](#978-1-6684-9018-1.ch011.xhtml#r14)`，第1页）

# 3. 选举人团概览

选举人票决定了总统选举的胜负

根据人口普查，各州分配选举人票。每个州的选举人票数等于其在联邦国会代表团中的参议员和众议员人数——两名参议员加上相当于其众议院选区数量的选票（`[Chowdhury, 2020](#978-1-6684-9018-1.ch011.xhtml#r11)`）。选举人团由538名选举人组成，选举总统需要获得至少270张选举人票。每个州的选举人数等于其在国会代表团中的成员数量：每位众议院议员一名，加上两名参议员。截至2020年12月，有15个州和哥伦比亚特区通过普选方式选出了选举人，这些州共拥有196张选举人票，占选举人团的36%，占270张所需票数的73%（`[Chowdhury, 2020](#978-1-6684-9018-1.ch011.xhtml#r11)`）。当选总统乔·拜登在选举人团确认其胜选后发表讲话，称：“人民的意志获胜。再次，法律的权威、我们的宪法以及美国人民的意志在美利坚合众国获胜、经受考验、受到威胁、证明了其韧性、真实性和力量。”拜登指出，他与副总统竞选搭档卡玛拉·哈里斯获得的选票数是美国历史上任何选票组合中最高的（`[Chowdhury, 2020](#978-1-6684-9018-1.ch011.xhtml#r11)`）。

# 4. 选举人团结果认证

据CNN的统计，在夏威夷檀香山，50个州和哥伦比亚特区已认证其总统选举结果，随着选举人团过程的推进，选举人会议即将举行（`[Stark & Cohen, 2020](#978-1-6684-9018-1.ch011.xhtml#r37)`）。西弗吉尼亚是最后之一认证总统选举结果的州，正式宣布唐纳德·特朗普有权获得该州的五张选举人票（`[Montellaro, 2020](#978-1-6684-9018-1.ch011.xhtml#r27)`）。在夏威夷檀香山，选举人在会议上为乔·拜登总统当选人投了四票。夏威夷是美国宪法中这一神秘过程的最后一步，标志着选举人团过程的结束。最终选举人团结果为拜登306票，特朗普232票。拜登在夏威夷以约64%对34%的比例击败了特朗普（`[Cohen & Cohen, 2020](#978-1-6684-9018-1.ch011.xhtml#r13)`）
