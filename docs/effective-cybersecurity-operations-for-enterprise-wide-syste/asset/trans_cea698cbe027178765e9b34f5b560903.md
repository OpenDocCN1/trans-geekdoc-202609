
在本案例中，存在多个漏洞：旧操作系统、用户之间共享密码、电脑之间共享密码、单因素认证以及缺乏防火墙。然而，只有两项因素导致了事件集合，即用户和电脑之间共享密码以及单因素认证，如[表 4](#978-1-6684-9018-1.ch009.xhtml#t4)所示。已停止支持的 Windows 7 电脑是操作系统漏洞，且很可能是硬件漏洞。如果这些设备安装了远程访问软件且使用共享密码，事件也可能发生在 Windows 11、Mac 或 Linux 设备上。缺乏防火墙是一个明显的问题，但与操作系统一样，它未直接导致此事件集合。如果该电脑需要远程访问，则需要为其配置防火墙例外以允许连接。因此，旧电脑和缺乏防火墙是替代事件集合的组成部分，如[表 5](#978-1-6684-9018-1.ch009.xhtml#t5)所示。

部署事件集合和等效性

这些数据泄露列表说明了事件集合和等效性在威胁行为者 compromising 网络目标中的作用。此外，对于提到的每个事件，都有多种替代攻击方法和工具可以被使用和利用。网络防御者可以在其网络监控中使用等效性，并改变网络安全思维，强调网络安全是每个人的工作。这可能是像在每个子网部署蜜罐（honey pots）来生成网络侦察的早期警报（[Landry & Koger, 2023b](#978-1-6684-9018-1.ch009.xhtml#r53)）那么简单。

防范在深度（defense in depth），虽然被广泛研究和实施，但一直未能充分保护网络和数据存储。因此，组织应转向零信任网络架构（ZTNA）。ZTNA 不是一种技术，而是一种通过安全设计（security by design）重新审视保护方式的新方法（[Landry & Koger, 2023a](#978-1-6684-9018-1.ch009.xhtml#r52)）。ZTNA 需要了解网络中每一台设备，以及它如何被用于良好和恶劣活动。设备的双重用途与等效性及网络安全操作中的捆绑（bundles）相吻合。例如，虽然老旧设备可以提供访问历史数据的连接，但同一老旧基础设施也可能被威胁行为者用于在网络中发起攻击。因此，如果组织确实需要 Windows 7 计算机，配置捆绑时需要其他保护机制，例如外部防火墙或将其与网络隔离。正是这些项的组合构成了 Windows 7 计算机的安全捆绑。

如云计算、基础设施即服务（infrastructure as code）、区块链和物联网（IoT）等新技术，也必须在发生泄露前或事件发生后纳入安全捆绑中考虑。主要考量是，糟糕的网络架构、弱访问控制和未记录的流程是本地环境的绝对问题。将这些问题迁移到混合或完全云端实现并不能解决问题，只是将问题转移到其他位置。不过，这改变了事件集合，带来与本地环境不同的新问题。

面向未来的研究方向

研究等效性和网络安全配置的机会众多。下面，将等效性在网络安全操作中的讨论沿五个维度展开：利益相关者、网络安全操作捆绑、终端用户、网络和威胁环境（参见[表 6](#978-1-6684-9018-1.ch009.xhtml#t6)以获取这些维度的摘要）。在这些维度中，每个都提供了一组主题和一套在个人、企业和社区三个层面的网络安全活动示例。个人层面包括人们在处理系统、网络和数据时所做的与系统相关的决策和活动。顶层设计和实施网络安全政策与控制的方法特征化了企业层面的决策和活动。企业层面的一个例子是采用特定防火墙或迁移到云服务提供商。

相反，社区层面体现了自下而上的方法，例如开源社区、黑客社区以及构成我们生活和工作环境的社区。这些实体（个人、企业、社区）在网络安全方面的关注点不同，因此其采用实现网络安全等效性的方法也不同。下面分别详细讨论这些维度。

利益相关者

动机、机会和手段（[Grabosky, 2001](#978-1-6684-9018-1.ch009.xhtml#r38)）的概念在网络安全文献中被广泛用于分析网络犯罪趋势的增长。同样的动机、机会和手段的概念可用于分析个人、企业和社区如何在配置其网络安全解决方案空间时采用等效性。考虑利益相关者的动机，这些动机可以被用来最大化等效配置网络安全解决方案的效果。在个人层面，考虑一个用户因短暂无法登录工作账户而将工作文件发送到个人邮箱并在此处工作的情况。这种行为的动机显然是正当的，工作仍然完成，但网络边界出现了漏洞。

在企业层面，组织拥有不同的资源组合，这使它们在维护和改进系统和网络安全方面的优势不平等。缺乏内部网络安全专业知识和资源的组织会使用托管安全服务提供商（MSSP）或云解决方案服务，从而获得外部资源以实现等效网络安全解决方案。在社区层面，考虑一个开源软件代码社区，它通过代码审查、漏洞奖励计划、黑客马拉松等机制以分布式方式提高代码库的效率。在这些情况下，采用网络安全解决方案的动机各不相同，从而导致网络安全操作的等效性。
