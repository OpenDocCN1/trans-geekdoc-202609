
-   [研究人员分析了参与者对大学为保护其人力资源免受社会工程攻击而实施的若干常见措施的行为，这些措施包括实施强密码策略、阻止免费软件网站、鼓励学生和员工启用两步验证以及为不同应用程序使用不同密码。然而，从[Table 6](#978-1-6684-9018-1.ch012.xhtml#t6)中数据的分析显示，大多数参与者认为大学提出的这些措施是不必要的或重要性不大，这由高模式值5显示，表明大多数参与者认为这些措施是不必要的。

# 评估贫乏网络安全知识和技能差距对大学社会工程攻击的贡献

# 分析通过提高学生和员工网络安全知识和技能来减少社会工程攻击的必要措施

[Table 8](#978-1-6684-9018-1.ch012.xhtml#t8) 可以推断出，大多数受访者不了解浏览器安全，而在处理社会工程攻击时，这非常关键。从之前的结果可以看出，存在浏览器安全、密码管理、恶意软件使用、事件报告系统以及明确网络安全角色和责任方面的知识差距，这主要是由于教育和意识不足，从而影响了员工和学生在发生网络攻击时及时、适当地检测、响应和恢复的能力。

# 表9. 关于改进网络安全知识和技能发展措施的感知

[Table 9](#978-1-6684-9018-1.ch012.xhtml#t9) 显示，在分析参与者关于大学如何改进其网络安全知识和技能的回应后，我们发现平均值在1到2之间，表明大多数参与者强烈同意本节提出的措施。他们同意，培训和意识提升可以增强他们识别、保护、检测、响应和从网络攻击中恢复的能力。他们还同意，通过培训网络安全概念和意识，可以减少因网络安全知识和技能不足而导致的人为漏洞。

参与者还强烈相信，在正确的教育下，他们可以获得必要的网络安全知识和技能，从而构建一个能够保护其大学网络空间的高效工作队伍。值得注意的是，参与者也强烈同意年龄在学习新网络安全概念的能力中起作用，因此有必要在参与者开始与网络空间互动时尽早进行意识提升和教育，使他们从小就培养这些技能，并理解其行为在保护其他关键资产中的重要作用。

[Table 10](#978-1-6684-9018-1.ch012.xhtml#t10) 显示了参与者关于大学可以采取哪些措施来改进网络安全知识和技能发展的回应。通过观察平均值在1到2之间，我们可以得出结论，大多数受访者强烈同意在招聘阶段评估网络安全知识和技能、在所有学生必须修读的强制性入门计算机课程中纳入网络安全内容，以及他们获得的网络安全知识和技能将有助于减少人为漏洞，从而降低他们无意中暴露关键信息系统或不知情参与网络犯罪的可能性。
