# Lemma 39.

Let a Boolean ℳ-embedding 𝔈, an 𝔈-gradation tree T with |T| > 1, and a nonempty member σ of T be given. Set i = ρ_T^{-1}(σ). Let ν be such that σ ends in (∨,ν) or (∧,ν). For all ℳ ∈ 𝔈(ρ_T(i+1)) \ 𝔈(ρ_T(i-1)), ℳ ∈ 𝔈(ρ_T(i)) iff ℳ ∈ 𝔈(ν).

Proof. The result is straightforward if 𝔈(ρ_T(i+1)) = 𝔈(ρ_T(i-1)), so suppose otherwise. The proof is by induction on the size of 𝔈-gradation trees. The result is straightforward for 𝔈-gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all 𝔈-gradation trees of size between 2 and k. Let T be an 𝔈-gradation tree of size k+1. Let σ ∈ T and 𝔈-gradation tree T' be such that T = T' ∪ {σ}. Let σ' ∈ T' be such that σ is of the form σ'·((∧,ν)) or σ'·((∨,ν)). We consider both cases in turn. Set i = ρ_{T'}^{-1}(σ'). Note that σ' is not empty, so we can write σ' as ((𝔛_0, v_0),..., (𝔛_n, v_n)), n ∈ ℕ, and i < |T'|.

# Case 1 σ = σ'·((∧,ν)).

+   - Assume that 𝔛_0,...,𝔛_n are all ∧, so i = 1. Obviously, for all ℳ ∈ 𝔈(σ'), ℳ ∈ 𝔈( v̂ ) iff ℳ ∈ 𝔈(ν).
+   - Otherwise, i > 1 and there exists a nonzero m ≤ n such that ((𝔛_m, v_m),..., (𝔛_n, v_n)) is of the form ((∨, v_m))·((∧, v_{m+1}),..., (∧, v_n)). Let τ denote ((𝔛_0, v_0),..., (𝔛_{m-1}, v_{m-1})). By Proposition 32, ρ_{T'}^{-1}(τ) = i - 1. Note that 𝔈(v_m ∧ v_{m+1} ∧ ⋯ ∧ v_n ∧ ν) = 𝔈(v_m ∧ v_{m+1} ∧ ⋯ ∧ v_n) ∩ 𝔈(ν).
