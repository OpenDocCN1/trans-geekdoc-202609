# Property 31.

Let n ∈ ℕ and C ∈ ℭ with |C| = n + 1 be given. Write C as {S0, …, Sn} where for all i < n, Si ⊂ Si+1.

+   - Set E1 = ((S0,S1),…,(S0,Sn)) and G1 = (C,E1).
+   - Set E2 = ((Sn,Sn-1),…,(S1,S0)) and G2 = (C,E2).

Both G1 and G2 are 2^ℳ-gradation graphs that determine unique gradation trees T1 and T2, respectively. Moreover, C is equal to both {σ̂ | σ ∈ T1} and {σ̂ | σ ∈ T2}.

# Proposition 32.

Let a gradation tree T with |T| > 1 and let σ ∈ T be given.

+   - If σ is the longest sequence of the form ((∧, v0),…,(∧, vn)), n ∈ ℕ, then ρ_T^{-1}(σ) equals 1.
+   - Assume that T contains a sequence of the form σ · ((∧, v)), and let τ be the (unique) longest sequence of the form ((∧, v0),(∨, v1),…,(∨, vn)), n ∈ ℕ, such that σ · τ is in T. Then ρ_T^{-1}(τ) equals ρ_T^{-1}(σ) − 1.
+   - Suppose that none of the previous conditions applies. We can write σ as ((𝔛0, v0),…,(𝔛n, vn)), n > 1, and there exists a (unique) nonzero m ≤ n such that ((𝔛m, vm),…,(𝔛n, vn)) is of the form ((∨, vm)) · ((∧, vm+1),…,(∧, vn)). Then denoting ((𝔛0, v0),…,(𝔛m−1, vm−1)) by τ, ρ_T^{-1}(τ) equals ρ_T^{-1}(σ) − 1.

# Proof.

The proof is by induction on the size of gradation trees. The result is straightforward for gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all gradation trees of size between 2 and k. Let T be a gradation tree of size k+1. Let σ ∈ T and gradation tree T′ be such that T = T′ ∪ {σ}. Let σ′ ∈ T′ be such that σ is of the form σ′ · ((∧, v)) or σ′ · ((∨, v)). We consider both cases in turn. Set i = ρ_{T′}^{-1}(σ′). Note that σ′ is not empty, so we can write σ′ as ((𝔛0, v0),…,(𝔛n, vn)), n ∈ ℕ, and i < |T′|.

# Case 1 σ = σ′ · ((∧, v)).

+   - Assume that 𝔛0,…,𝔛n are all ∧. Then i = 1, and as the result holds for T′, we infer that T′s standard enumeration is (σj)1 ≤ j ≤ |T| where σ1 = σ and for all j ∈ {2,…,|T|}, σj = ρ_{T′}(j − 1).
+   - Otherwise, i > 0 and there exists m ≤ n such that ((𝔛m, vm),…,(𝔛n, vn)) is of the form ((∨, vm)) · ((∧, vm+1),…,(∧, vn)). Let τ denote ((𝔛0, v0),…,(𝔛m−1, vm−1)). By inductive hypothesis, ρ_{T′}^{-1}(τ) = ρ_{T′}^{-1}(σ′) − 1. From this and the fact that the result holds for T′, we infer that T′s standard enumeration is (σj)1 ≤ j ≤ |T| where σi = σ, σj = ρ_{T′}(i) for all j ∈ {1,…,i − 1}, and σj = ρ_{T′}(j − 1) for all j ∈ {i + 1,…,|T|}.
