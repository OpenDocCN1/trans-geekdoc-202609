## Proposition 59. Suppose that 𝔞 consists of n atoms p1,…,pn, n ∈ ℕ\{0}, and 𝔐 is the set of all interpretations.

- Some classifying 𝔞-gradation graph with n + 1 nodes and n(n+1)/2 edges recognises ⊕_{1≤i≤n} p_i.
- For all classifying 𝔞^∧-gradation trees T that recognise ⊕_{1≤i≤n} p_i, |T| ≥ 2^n.

Proof. Set φ0 = ∧∅ and V = {p_i | i < n}. Let E be the set of all pairs of the form (p_i, p_j), 0 ≤ i < j ≤ n. Obviously, if ℛ is a presentation of (V,E) then for all i, j, k ≤ n with i < j < k, (i,j) occurs before (i,k) in ℛ. Using that observation, it is easy to verify that (V,E), which has n + 1 nodes and n(n+1)/2 edges, is a parity-based, negative by default classifying 𝔞-gradation graph that recognises ⊕_{1≤i≤n} p_i. Let (T,ℓ) be a classifying 𝔞^∧-gradation tree that recognises ⊕_{1≤i≤n} p_i. Recall from Notation 36 the definition of σ||_T for all σ ∈ T. In a related way, map each σ ∈ T to S_σ, defined as follows. Set S_∅ = ∅. Let a nonempty σ ∈ T be given, and write σ as ((𝔞0, v0),…, (𝔞n, vn)), n ∈ ℕ. Set X = {vn} ∪ {vi | i < n, 𝔞_{i+1} = ∧}.

Let X' be the set of atoms in X. Define S_σ as the set of members of 𝔞 that either belong to X', or that are conjuncts in some of the conjunctions in X \ X'. Suppose for a contradiction that there exists S ⊆ 𝔞 with S ≠ S_σ for all σ ∈ T. Let 𝔐 be the interpretation such that for all p ∈ 𝔞, 𝔐 ⊨ p iff p ∈ S. We infer from Proposition 40 that there exists σ ∈ T with 𝔐 ⊨ σ ||_T. Obviously, S_σ ⊂ S. Moreover, it is easy to verify that for all S' ⊆ S with S_σ ⊆ S', if 𝔐' is the interpretation such that for all p ∈ 𝔞, 𝔐' ⊨ p iff p ∈ S', then 𝔐' ⊨ σ ||_T, hence ℓ⟨𝔐'⟩ = ℓ⟨𝔐⟩, in contradiction with the assumption that (T, ℓ) recognises ⊕_{1 ≤ i ≤ n} p_i. Therefore, since there are 2^n many subsets of 𝔞, T must have at least 2^n many elements.

## Proposition 61.

For all positive formulas φ that are satisfiable in 𝔐, there exists an end-based classifying 𝔞-gradation tree that recognises φ.

Proof. Let a positive formula φ be satisfiable in 𝔐. Let (necessarily nonzero) n ∈ ℕ be least and let D₀, …, Dₙ₋₁ be ⊆-minimal sets of atoms such that φ is logically equivalent in 𝔐 to ∨_{m<n} ∧ D_m. Without loss of generality, suppose that

𝓐 = ⋃_{m<n} D_m. Set |𝓐| = k. Let (ξ_i)_{i<k} be an enumeration of 𝓐. Inductively define for all i < k a finite set S_i of literals as follows. Let i < k be given, and assume that S_j has been defined for all j < i. Define S_i as the ⊆-minimal set that satisfies the following condition. Let X be a ⊆-maximal member of ⋃_{j<i} X_j.

- for all j < i, if ξ_j ∈ D_m then ξ_j ∈ X;
- ξ_i ∈ D_m.

Then S_i contains X ∪ {ξ_i}. If that is the case, suppose that there exists m' < n such that:

- for all j < i, if ξ_j ∈ D_{m'} then ξ_j ∈ X;
- D_{m'} ∩ {ξ_{i+1},...,ξ_{k-1}} ≠ ∅;
- ξ_i ∉ D_{m'}.

Then S_i also contains X ∪ {¬ξ_i}.

Let U be the set of finite sequences of the form (i_0,...,i_p) with 0 ≤ p < k and 0 ≤ i_0 < ... < i_p < k for which there exists a (necessarily unique) member X of ⋃_{i<k} S_i such that for all i < k, i ∈ {i_0,...,i_p} iff ξ_i ∈ X. Now define an 𝓐-gradation tree T as the ⊆ smallest set of finite sequences of atoms such that T contains the empty sequence and for all σ ∈ T, the following holds. By construction, σ can be written as ((𝔛_1, ξ_{i1}),..., (𝔛_p, ξ_{ip})) with 0 ≤ p ≤ k, 𝔛_i ∈ {∨,∧} for all 0 < i ≤ p, and (i_1,...,i_p) ∈ U.

- Suppose that there exists m < k either with p being equal to 0 or with p ≠ 0 and m > i_p, such that (i_1,...,i_p,m) ∈ U. Then choose the smallest such integer m and add σ·((∧, ξ_m)) to T.
- Suppose that p ≠ 0 and there exists m < k such that m > i_p and (i_1,...,i_{p-1},m) ∈ U. Then choose the smallest such integer m and add ((𝔛_1, ξ_{i1}),..., (𝔛_{p-1}, ξ_{i_{p-1}}), (∨, ξ_m)) to T.

Note that there exists a one-to-one mapping F from ⋃_{i<k} S_i into T (as well as a one-to-one mapping from U into T). Let S be the set of all ⊆-maximal members of ⋃_{i<k} S_i.

- Let us prove that Mod_𝓐(φ) = ⋃_{X∈S} Mod_𝓐(X). First note that the following holds.
1. For all i < k and X ∈ S_i, there exists m < n such that for all j ≤ i, ξ_j ∈ X iff ξ_j ∈ D_m.
2. For all i < k and m < n, there exists X ∈ S_i such that for all j ≤ i, ξ_j ∈ X iff ξ_j ∈ D_m.
3. For all i < k, m < n and members of S_i of the form X ∪ {ξ_i} such that
   - for all j < i, ξ_j ∈ X iff ξ_j ∈ D_m, and
   - X ∪ {¬ξ_i} is not in S_i,
   Mod_𝓐(X ∪ {ξ_i}) ∩ Mod_𝓐(D_m) = Mod_𝓐(X) ∩ Mod_𝓐(D_m).

Applying (2) to i = k − 1, we infer that ⋃_{X∈S} Mod_𝔞(X) ⊆ Mod_𝔞(φ). It is easy to derive from (1) and (3) that Mod_𝔞(φ) ⊆ ⋃_{X∈S} Mod_𝔞(X). Hence Mod_𝔞(φ) = ⋃_{X∈S} Mod_𝔞(X) as claimed. Observe that {F(X) | X ∈ S} is the set of all σ ∈ T such that T contains no element of the form σ · ((∧,∨)). So in order to complete the proof of the proposition, it suffices to check that for all X ∈ ⋃_{i<k} S_i, Mod_𝓐(X) \ Mod_𝓐(φ) ≠ ∅. But that follows easily from (1) together with the minimality assumptions on n and D0, …, D_{k−1}.
