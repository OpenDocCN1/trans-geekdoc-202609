Applying (2) to i = k − 1, we infer that ⋃_{X∈S} Mod_𝔞(X) ⊆ Mod_𝔞(φ). It is easy to derive from (1) and (3) that Mod_𝔞(φ) ⊆ ⋃_{X∈S} Mod_𝔞(X). Hence Mod_𝔞(φ) = ⋃_{X∈S} Mod_𝔞(X) as claimed. Observe that {F(X) | X ∈ S} is the set of all σ ∈ T such that T contains no element of the form σ · ((∧,∨)). So in order to complete the proof of the proposition, it suffices to check that for all X ∈ ⋃_{i<k} S_i, Mod_𝔞(X) \ Mod_𝔞(φ) ≠ ∅. But that follows easily from (1) together with the minimality assumptions on n and D0, …, D_{k−1}.
