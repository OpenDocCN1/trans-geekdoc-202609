
## Lemma 27. Let a gradation tree and distinct members σ and τ of T be given.

- If σ is of the form τ·((∧, v))·τ′ then σ ≤ τ.
- If τ is of the form σ·((∨, v))·σ′ then σ ≤ τ.
- If there exists a sequence γ such that σ and τ are of the form γ·((∧, v))·σ′ and γ·((∨, v))·τ′, respectively, then σ ≤ τ.

### Proof.
In the first case, if τ is the empty sequence then obviously, σ̂ ≤ τ̂. We examine the rest of the first case and the last two cases.

- Suppose that σ is of the form τ·((∧, v))·τ′ and τ ≠ (). Write σ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n > 0, and let i < n be such that τ is ((𝔛₀,𝔳₀),..., (𝔛ᵢ,𝔳ᵢ)). For all j ≤ i, let τⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ᵢ,𝔳ᵢ)) and let σⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ)). Note that σ̂ᵢ ≤ 𝔳ᵢ. It is immediately verified by induction, letting j decrease from i down to 0, that for all j ≤ i, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.
- Suppose that τ is of the form σ·((∨, v))·σ′. So σ ≠ (). Write τ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n > 0, and let i < n be such that σ is ((𝔛₀,𝔳₀),..., (𝔛ᵢ,𝔳ᵢ)). For all j ≤ i, let σⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ᵢ,𝔳ᵢ)) and let τⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ)). Note that 𝔳ᵢ ≤ τ̂ᵢ. It is immediately verified by induction, letting j decrease from i down to 0, that for all j ≤ i, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.
- Suppose that there exists a sequence γ such that σ and τ are of the form γ·((∧, v))·σ′ and γ·((∨, v))·τ′, respectively. So γ ≠ (). Write γ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n ∈ ℕ. For all j ≤ n, set σⱼ = ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ))·((∧, v))·σ′ and τⱼ = ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ))·((∨, v))·τ′. It is immediately verified by induction that for all j ≤ n, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.

This completes the proof of the lemma.

The proposition is an immediate consequence of Lemma 27.

## Proposition 32.

Let a gradation tree T with |T| > 1 and let σ ∈ T be given.

- If σ is the longest sequence of the form ((∧, v0),…,(∧, vn)), n ∈ ℕ, then ρ_T^{-1}(σ) equals 1.
- Assume that T contains a sequence of the form σ · ((∧, v)), and let τ be the (unique) longest sequence of the form ((∧, v0),(∨, v1),…,(∨, vn)), n ∈ ℕ, such that σ · τ is in T. Then ρ_T^{-1}(τ) equals ρ_T^{-1}(σ) − 1.
- Suppose that none of the previous conditions applies. We can write σ as ((𝔛0, v0),…,(𝔛n, vn)), n > 1, and there exists a (unique) nonzero m ≤ n such that ((𝔛m, vm),…,(𝔛n, vn)) is of the form ((∨, vm)) · ((∧, vm+1),…,(∧, vn)). Then denoting ((𝔛0, v0),…,(𝔛m−1, vm−1)) by τ, ρ_T^{-1}(τ) equals ρ_T^{-1}(σ) − 1.

### Proof.
The proof is by induction on the size of gradation trees. The result is straightforward for gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all gradation trees of size between 2 and k. Let T be a gradation tree of size k+1. Let σ ∈ T and gradation tree T′ be such that T = T′ ∪ {σ}. Let σ′ ∈ T′ be such that σ is of the form σ′ · ((∧, v)) or σ′ · ((∨, v)). We consider both cases in turn. Set i = ρ_{T′}^{-1}(σ′). Note that σ′ is not empty, so we can write σ′ as ((𝔛0, v0),…,(𝔛n, vn)), n ∈ ℕ, and i < |T′|.

### Case 1 σ = σ′ · ((∧, v)).
- Assume that 𝔛0,…,𝔛n are all ∧. Then i = 1, and as the result holds for T′, we infer that T′s standard enumeration is (σj)1 ≤ j ≤ |T| where σ1 = σ and for all j ∈ {2,…,|T|}, σj = ρ_{T′}(j − 1).
- Otherwise, i > 0 and there exists m ≤ n such that ((𝔛m, vm),…,(𝔛n, vn)) is of the form ((∨, vm)) · ((∧, vm+1),…,(∧, vn)). Let τ denote ((𝔛0, v0),…,(𝔛m−1, vm−1)). By inductive hypothesis, ρ_{T′}^{-1}(τ) = ρ_{T′}^{-1}(σ′) − 1. From this and the fact that the result holds for T′, we infer that T′s standard enumeration is (σj)1 ≤ j ≤ |T| where σi = σ, σj = ρ_{T′}(i) for all j ∈ {1,…,i − 1}, and σj = ρ_{T′}(j − 1) for all j ∈ {i + 1,…,|T|}.

Case 2 σ = σ′·((∨,ν)). There exists m ≤ n such that (((𝔛_m,ν_m),…,(𝔛_n,ν_n)) is of the form (((∧,ν_m))·((∨,ν_{m+1}),…,(∨,ν_n))). Let ((𝔛_0,ν_0),…,(𝔛_{m-1},ν_{m-1})) be denoted by τ. By inductive hypothesis, ρ_T^{-1}(τ) = ρ_{T'}^{-1}(σ') + 1. From this and the fact that the result holds for T', we infer that T's standard enumeration is (σ_j)_{1 ≤ j ≤ |T|} where σ_{i+1} = σ, σ_j = ρ_{T'}(i) for all j ∈ {1,…,i}, and σ_j = ρ_{T'}(j − 1) for all j ∈ {i+2,…,|T|}.

This completes the proof of the proposition.

Let an interpretation 𝔐, an 𝔐-embedding ℰ and an ℰ-gradation tree T be given. Let i in {1,…,|T|} be least with the following property: if σ is the (unique) member of T such that ρ_T(i) = σ, then 𝔐 ∈ ℰ(σ̂). Let C denotes {ℰ(τ̂) | τ ∈ T}. Then ℰ(σ̂) is min_C(𝔐), as defined in Notation 4.

Let an 𝔐-embedding ℰ and an ℰ-gradation tree T be given. In order to use T and label a case, one needs to evaluate σ̂ for various σ ∈ T and identify the unique σ ∈ T such that σ̂ evaluates to True and ρ_T^{-1}(σ) is minimal for the case under consideration. This can be done by first evaluating the member σ of T for which ρ_T^{-1}(σ) = 1, then possibly the member σ of T for which ρ_T^{-1}(σ) = 2... Or it could be done by binary search by first evaluating the member σ of T for which ρ_T^{-1}(σ) = ⌊|T|/2⌋. As ℰ is Boolean, we can work with T's individual conditions, starting at T's root and making our way along some initial segment of some branch. Indeed, we can work with negations of conditions, and the evaluation of a case can proceed in the way it is standardly done in RDR: being at a node N whose condition evaluates to True, consider in turn the nodes N1, ..., Nk such that N1 is N's exception and for all i ∈ {1,...,k-1}, N_{i+1} is N_i's alternative, move to N1 if the condition at N1 evaluates to True, move to N2 if the condition at N1 evaluates to False but the condition at N2 evaluates to True, ..., and stay at N if the conditions at all of N1, ..., Nk all evaluate to False. We next turn our attention to Boolean gradation trees, with Notation 36 mapping each σ ∈ T to an element of the underlying Boolean algebra, σ||_T, meant to capture the standard RDR evaluation of a case. The notation is then illustrated and exemplified, before we establish a lemma thanks to which we can prove Proposition 40, thereby verifying that σ||_T indeed serves its intended purpose.

## Notation 36.

Let a Boolean 𝔐-embedding ℰ and an ℰ-gradation tree T be given. Map each σ ∈ T to σ||_T, defined as follows. Let τ be the longest sequence of the form ((∧, 𝔴0), (∨, 𝔴1), ..., (∨, 𝔴m)), m ∈ ℕ, with σ·τ ∈ T. If σ is empty then define σ||_T as ∧_{i≤m} 𝔴̅i. Otherwise, write σ as ((s0, 𝔴0), ..., (sn, 𝔴n)), n ∈ ℕ, and define σ||_T as

𝔴_n ∧ ⋀_{i<n, s_{i+1}=∧} 𝔴_i ∧ ⋀_{i<n, s_{i+1}=∨} 𝔴̅_i ∧ ⋀_{i≤m} 𝔴̅_i.
