Also, note that

+   - $\sigma\parallel_T$ is defined as $\tau\parallel_{T'} \wedge \mathfrak{v}$;
+   - $\tau\parallel_T$ is defined as $\tau\parallel_{T'} \wedge \bar{\mathfrak{v}}$.

From all this and the fact that the result holds for $T'$, we infer easily with the help of Proposition 32 and Corollary 34 that the result holds for $T$.

# 7.5 NORMAL FORMS

Let a gradation tree $T$ and a member $\sigma$ of $T$ be given. Defined as it is, $\hat{\sigma}$ can have $\vee$s within $\wedge$s within $\vee$s within $\wedge$s... all the more so that $\sigma$ is longer and has more “direction changes”. This is in contrast to the flat structure of disjunctive or conjunctive normal forms, that limit embedding depth to 2 (disjunctions within conjunctions, or conjunctions within conjunctions). Notation 41 captures the natural way to convert $\hat{\sigma}$ to disjunctive and conjunctive normal forms. Corollary 44 characterises the disjunctive and conjunctive normal forms that can be expressed as formulas of the form $\hat{\sigma}$.

+   - Write $\sigma$ as
+   $((\wedge,\mathfrak{v}_0^0),\dots,(\wedge,\mathfrak{v}_0^{p_0}), (\vee,\mathfrak{v}_1),\dots,(\vee,\mathfrak{v}_{n_0}),(\wedge,\mathfrak{v}_1^0),\dots,(\wedge,\mathfrak{v}_1^{p_1}),
