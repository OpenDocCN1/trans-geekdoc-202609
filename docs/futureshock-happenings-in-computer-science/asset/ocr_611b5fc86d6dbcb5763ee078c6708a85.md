+   - In Corollary 44, DNF(σ) is written as ∨_{i≤3} ∧_{v∈E_i} (D_i ∪ {v}) where:
+     - D0 = {v0^0, v0^1} and E0 = {v0^2, v1, v2};
+     - D1 = D0 ∪ {v3} and E1 = {v0^1};
+     - D2 = D1 ∪ {v4, v2^0, v2^1} and E2 = {v2^2, v5};
+     - D3 = D2 ∪ {v6} and E1 = {v3^0}.
+   - In Corollary 44, CNF(σ) is written as ∧_{i≤3} ∨_{v∈E_i} (D_i ∪ {v}) where:
+     - D0 = ∅ and E0 = {v1, v2};
+     - D1 = D0 ∪ {v3, v0^0, v0^1} and E1 = {v0^2};
+     - D2 = D1 ∪ {v4} and E2 = {v1^0, v5, v6};
+     - D3 = D2 ∪ {v7, v2^0} and E3 = {v2^1, v8}.

**Property 46.** For all gradation trees T and nonempty σ ∈ T, σ̂ ∈ DNF(σ).

# 7.6 LABELLED GRADATION TREES AND GRAPHS

Given an RDR tree and a case, evaluation of the conditions of some of the nodes of the tree, using a rich enough description of the case, eventually points to a specific node in the tree. That node is meant to be associated with a useful piece of information about the case and reveal something interesting and not known about it. The information can be 1 or 0 as a way to classify the case and let the user know whether it has a particular property. It can be the name of a class the case belongs to. Here we focus on the former, so on binary classification, and leave it to the reader to generalise the setting to multiclass classification.

**Definition 47.** Given a gradation tree T or a gradation graph G, a classifier for T or G is a mapping whose domain is T or Paths(G), respectively, and whose codomain is {0,1}.

**Definition 48.** A classifying gradation tree or graph is a pair of the form (S,ℓ) where S is a gradation tree or graph, respectively, and ℓ is a classifier for S.

**Notation 49.** Given an ℳ-embedding ℰ, a classifying ℰ-gradation tree (T,ℓ) and ℳ ∈ ℳ, we let ℓ⟨ℳ⟩ denote ℓ(ρ_T(i)) for the least i ∈ {1,…,|T|} such that ℳ ∈ ℰ(ρ_T(i)).

We now formalise how a classifying gradation tree or graph S yields a classification.

**Definition 50.** A classifying gradation tree (T,ℓ) is said to recognise a formula φ iff for all ℳ ∈ ℳ, ℓ⟨ℳ⟩ = 1 iff ℳ ⊨ φ.

**Definition 51.** A classifying gradation graphs ℱ is said to recognise a formula φ iff the classifying gradation tree associated with ℱ recognise φ.
