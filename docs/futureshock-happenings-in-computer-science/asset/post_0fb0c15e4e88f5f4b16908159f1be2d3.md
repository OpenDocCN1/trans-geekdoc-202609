## 7.6 LABELLED GRADATION TREES AND GRAPHS

Given an RDR tree and a case, evaluation of the conditions of some of the nodes of the tree, using a rich enough description of the case, eventually points to a specific node in the tree. That node is meant to be associated with a useful piece of information about the case and reveal something interesting and not known about it. The information can be 1 or 0 as a way to classify the case and let the user know whether it has a particular property. It can be the name of a class the case belongs to. Here we focus on the former, so on binary classification, and leave it to the reader to generalise the setting to multiclass classification.

### Definition 47.

Given a gradation tree T or a gradation graph G, a classifier for T or G is a mapping whose domain is T or Paths(G), respectively, and whose codomain is {0,1}.

### Definition 48.

A classifying gradation tree or graph is a pair of the form (S,ℓ) where S is a gradation tree or graph, respectively, and ℓ is a classifier for S.

### Notation 49.

Given an ℳ-embedding ℰ, a classifying ℰ-gradation tree (T,ℓ) and ℳ ∈ ℳ, we let ℓ⟨ℳ⟩ denote ℓ(ρ_T(i)) for the least i ∈ {1,…,|T|} such that ℳ ∈ ℰ(ρ_T(i)).

We now formalise how a classifying gradation tree or graph S yields a classification.

### Definition 50.

A classifying gradation tree (T,ℓ) is said to recognise a formula φ iff for all ℳ ∈ ℳ, ℓ⟨ℳ⟩ = 1 iff ℳ ⊨ φ.

### Definition 51.

A classifying gradation graph ℱ is said to recognise a formula φ iff the classifying gradation tree associated with ℱ recognises φ.

We will more closely study two special kinds of classifiers. The first kind of classifier corresponds to switching classification between “in the class” and “not in the class” at every exception, starting with one or the other, e.g.: by default, the case is in the class, except if this condition, the first one from this sequence of alternatives, holds, in which case the case is not in the class, except if this condition, the first one from this sequence of alternatives, holds, in which case the case is in the class… This is related to the notion of mind change bound [8], developed in the paradigm of formal learning theory [7], even though in the simpler framework developed here, there is no need for infinite ordinals…

### Definition 52.

Let a classifying gradation tree (T,ℓ) be given. If ℓ⁻¹(1) is the set of all σ ∈ T that contain an even number of pairs of the form (∧,∨) or the set of all σ ∈ T that contain an odd number of pairs of the form (∧,∨), then we say that (T,ℓ) is parity-based, positive by default in the first case, negative by default in the second case.

Let a classifying gradation graph (G,ℓ) be given. If ℓ⁻¹(1) is the set of all σ ∈ Paths(G) of odd length or the set of all σ ∈ Paths(G) of even length, then we say that (G,ℓ) is parity-based, positive by default in the first case, negative by default in the second case.

### Property 53.

Let a classifying gradation graph 𝓖 be given. Then 𝓖 is parity-based iff the classifying gradation tree 𝓕 that is determined by 𝓖 is parity-based. Moreover, if 𝓖 is parity based then 𝓖 is positive by default or negative by default iff 𝓕 is positive by default or negative by default, respectively.

The second kind of classifier corresponds to classifying a case as being in the class if and only if evaluation stops at a node that has no exception, that is, at a node where evaluation cannot possibly proceed any further.

### Definition 54.

A classifying gradation tree (T,ℓ) is said to be end-based iff ℓ⁻¹(1) is the set of all σ ∈ T such that T contains no element of the form σ·((∧,∨)).

A classifying gradation graph (G,ℓ) is said to be end-based iff ℓ⁻¹(1) is the set of members of Paths(G) that have no proper extension in Paths(G).

### Proposition 57.

*There exists an 𝔞-gradation tree T such that for all formulas φ, there exists a classifier ℓ for T such that (T,ℓ) recognises φ.*

*Proof.* Set |𝔞| = k. Let (ξ_i)_{i<k} be an enumeration of 𝔞. Inductively define for all i < k a finite set S_i of literals as follows. Let i < k be given, and assume that S_j has been defined for all j < i. Define S_i as the set of all sets of the form X ∪ {ξ_i} and all sets of the form X ∪ {¬ξ_i} such that:

- X is a ⊆-maximal member of ∪_{j<i} S_j;
- ∅ ⊂ Mod_𝔐 (X ∪ {ξ_i}) ⊂ Mod_𝔐 (X).

Let S be the set of all ⊆-maximal members of ∪_{i<k} S_i. Let U be the set of finite sequences of the form (i1,…,ip) with 0 ≤ p < k and 0 ≤ i1 < … < ip < k for which there exists a (necessarily unique) member X of S such that for all i < k, i ∈ {i1,…,ip} iff ξ_i ∈ X. Now define an 𝔞-gradation tree T as the ⊆ smallest set of finite sequences of atoms such that T contains the empty sequence and for all σ ∈ T, the following holds. By construction, σ can be written as ((𝔞1,ξ_{i1}),…,(𝔞p,ξ_{ip})) with 0 ≤ p ≤ k, 𝔞_i ∈ {∨,∧} for all nonzero i ≤ p, and (i1,…,ip) ∈ U.

- Suppose that there exists m < k either with p being equal to 0 or with p ≠ 0 and m > i_p, such that (i1,…,ip,m) ∈ U. Then choose the smallest such integer m and add σ · ((∧,ξ_m)) to T.

- Suppose that $p \neq 0$ and there exists $m < k$ such that $m > i_p$ and $(i_1,\dots,i_{p-1},m) \in U$. Then choose the smallest such integer $m$ and add $((\chi_1,\xi_{i_1}),\dots,(\chi_{p-1},\xi_{i_{p-1}}),(\vee,\xi_m))$ to $T$.

Note that there exists a one-to-one mapping $F$ from $S$ into $T$ (as well as a one-to-one mapping from $U$ into $T$). Clearly, $\{\text{Mod}_{\mathscr{M}}(X) \mid X \in S\}$ is a partition of $\mathscr{M}$. Also, it is easily verified that for all $\sigma \in T$, $\sigma\mid_T = \wedge F^{-1}(\sigma)$. Let $\varphi$ be a formula. Let $\ell$ be the classifier for $T$ such that for all $\sigma \in T$, $\ell(\sigma)=1$ iff there exists $\mathfrak{M} \in \mathscr{M}$ with $\mathfrak{M} \models \varphi$ and $\mathfrak{M} \in F^{-1}(\sigma)$. We immediately conclude from Proposition 40 together with the previous observations that $(T,\ell)$ recognises $\varphi$, thereby completing the proof of the proposition.
