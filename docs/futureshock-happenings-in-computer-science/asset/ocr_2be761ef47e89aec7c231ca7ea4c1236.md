𝓐 = ⋃_{m<n} D_m. Set |𝓐| = k. Let (ξ_i)_{i<k} be an enumeration of 𝓐. Inductively define for all i < k a finite set S_i of literals as follows. Let i < k be given, and assume that S_j has been defined for all j < i. Define S_i as the ⊆-minimal set that satisfies the following condition. Let X be a ⊆-maximal member of ⋃_{j<i} X_j.

+   - for all j < i, if ξ_j ∈ D_m then ξ_j ∈ X;
+   - ξ_i ∈ D_m.

Then S_i contains X ∪ {ξ_i}. If that is the case, suppose that there exists m' < n such that:

+   - for all j < i, if ξ_j ∈ D_{m'} then ξ_j ∈ X;
+   - D_{m'} ∩ {ξ_{i+1},...,ξ_{k-1}} ≠ ∅;
+   - ξ_i ∉ D_{m'}.

Then S_i also contains X ∪ {¬ξ_i}.

Let U be the set of finite sequences of the form (i_0,...,i_p) with 0 ≤ p < k and 0 ≤ i_0 < ... < i_p < k for which there exists a (necessarily unique) member X of ⋃_{i<k} S_i such that for all i < k, i ∈ {i_0,...,i_p} iff ξ_i ∈ X. Now define an 𝓐-gradation tree T as the ⊆ smallest set of finite sequences of atoms such that T contains the empty sequence and for all σ ∈ T, the following holds. By construction, σ can be written as ((𝔛_1, ξ_{i1}),..., (𝔛_p, ξ_{ip})) with 0 ≤ p ≤ k, 𝔛_i ∈ {∨,∧} for all 0 < i ≤ p, and (i_1,...,i_p) ∈ U.

+   - Suppose that there exists m < k either with p being equal to 0 or with p ≠ 0 and m > i_p, such that (i_1,...,i_p,m) ∈ U. Then choose the smallest such integer m and add σ·((∧, ξ_m)) to T.
+   - Suppose that p ≠ 0 and there exists m < k such that m > i_p and (i_1,...,i_{p-1},m) ∈ U. Then choose the smallest such integer m and add ((𝔛_1, ξ_{i1}),..., (𝔛_{p-1}, ξ_{i_{p-1}}), (∨, ξ_m)) to T.

Note that there exists a one-to-one mapping F from ⋃_{i<k} S_i into T (as well as a one-to-one mapping from U into T). Let S be the set of all ⊆-maximal members of ⋃_{i<k} S_i.

+   Let us prove that Mod_𝓐(φ) = ⋃_{X∈S} Mod_𝓐(X). First note that the following holds.
+   1. For all i < k and X ∈ S_i, there exists m < n such that for all j ≤ i, ξ_j ∈ X iff ξ_j ∈ D_m.
+   2. For all i < k and m < n, there exists X ∈ S_i such that for all j ≤ i, ξ_j ∈ X iff ξ_j ∈ D_m.
+   3. For all i < k, m < n and members of S_i of the form X ∪ {ξ_i} such that
+      - for all j < i, ξ_j ∈ X iff ξ_j ∈ D_m, and
+      - X ∪ {¬ξ_i} is not in S_i,
+      Mod_𝓐(X ∪ {ξ_i}) ∩ Mod_𝓐(D_m) = Mod_𝓐(X) ∩ Mod_𝓐(D_m).
