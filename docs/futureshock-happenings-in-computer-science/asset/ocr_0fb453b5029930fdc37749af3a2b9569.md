# Lemma 27. Let a gradation tree and distinct members σ and τ of T be given.

+   - If σ is of the form τ·((∧,∨))·τ′ then σ ≤ τ.
+   - If τ is of the form σ·((∨,∨))·σ′ then σ ≤ τ.
+   - If there exists a sequence γ such that σ and τ are of the form γ·((∧,∨))·σ′ and γ·((∨,∨))·τ′, respectively, then σ ≤ τ.

Proof. In the first case, if τ is the empty sequence then obviously, σ̂ ≤ τ̂. We examine the rest of the first case and the last two cases.

+   - Suppose that σ is of the form τ·((∧,∨))·τ′ and τ ≠ (). Write σ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n > 0, and let i < n be such that τ is ((𝔛₀,𝔳₀),..., (𝔛ᵢ,𝔳ᵢ)). For all j ≤ i, let τⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ᵢ,𝔳ᵢ)) and let σⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ)). Note that σ̂ᵢ ≤ 𝔳ᵢ. It is immediately verified by induction, letting j decrease from i down to 0, that for all j ≤ i, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.
+   - Suppose that τ is of the form σ·((∨,∨))·σ′. So σ ≠ (). Write τ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n > 0, and let i < n be such that σ is ((𝔛₀,𝔳₀),..., (𝔛ᵢ,𝔳ᵢ)). For all j ≤ i, let σⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ᵢ,𝔳ᵢ)) and let τⱼ denote ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ)). Note that 𝔳ᵢ ≤ τ̂ᵢ. It is immediately verified by induction, letting j decrease from i down to 0, that for all j ≤ i, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.
+   - Suppose that there exists a sequence γ such that σ and τ are of the form γ·((∧,∨))·σ′ and γ·((∨,∨))·τ′, respectively. So γ ≠ (). Write γ as ((𝔛₀,𝔳₀),..., (𝔛ₙ,𝔳ₙ)), n ∈ ℕ. For all j ≤ n, set σⱼ = ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ))·((∧,∨))·σ′ and τⱼ = ((𝔛ⱼ,𝔳ⱼ),..., (𝔛ₙ,𝔳ₙ))·((∨,∨))·τ′. It is immediately verified by induction that for all j ≤ n, σ̂ⱼ ≤ τ̂ⱼ. In particular, σ̂ ≤ τ̂.

This completes the proof of the lemma.

# Proposition 28. For all gradation trees T and i, j ∈ {1,...,|T|}, if i ≤ j then ρ_T(i) ≤ ρ_T(j).

Proof. The proposition is an immediate consequence of Lemma 27.

# Proposition 29. Given an ℳ-embedding ℰ and an ℰ-gradation tree T, {ℰ(σ̂) | σ ∈ T} is a chain for inclusion.

Proof. The proposition is an immediate consequence of Lemma 27 and the fact that ℰ is monotone.
