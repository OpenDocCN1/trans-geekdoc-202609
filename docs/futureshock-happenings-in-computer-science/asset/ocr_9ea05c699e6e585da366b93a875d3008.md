Let ℳ ∈ ℰ(ρ_T'(i+1)) \ ℰ(ρ_T'(i-1)) be given.

+   - If ℳ ∈ ℰ(v) then since ℳ ∈ ℰ(\widehat{σ'}), ℳ ∈ ℰ(\widehat{σ}).
+   - If ℳ ∉ ℰ(v) then since ℳ ∉ ℰ(\widehat{σ}), ℳ ∉ ℰ(\widehat{σ}).

# Case 2 σ = σ'·((∨,v)). There exists m ≤ n such that ((𝔛_m, v_m),…,(𝔛_n, v_n)) is of the form ((∧, v_m))·((∨, v_{m+1}),…,(∨, v_n)). Let τ denote ((𝔛_0, v_0),…,(𝔛_{m-1}, v_{m-1})).

By Corollary 34, ρ_T'^{-1}(τ) = i + 1. Note that

ℰ(v_m ∨ v_{m+1} ∨ ⋯ ∨ v_n ∨ v) = ℰ(v_m ∨ v_{m+1} ∨ ⋯ ∨ v_n) ∪ ℰ(v).

Let ℳ ∈ ℰ(ρ_T'(i+1)) \ ℰ(ρ_T'(i-1)) be given.

+   - If ℳ ∈ ℰ(v) then since ℳ ∈ ℰ(\widehat{σ}), ℳ ∈ ℰ(\widehat{σ}).
+   - If ℳ ∉ ℰ(v) then since and ℳ ∉ ℰ(\widehat{σ'}), ℳ ∉ ℰ(\widehat{σ}).

From all this and the fact that the result holds for T', we infer easily with the help of Proposition 32 and Corollary 34 that the result holds for T.

# Proposition 40. For all Boolean ℳ-embeddings ℰ, ℰ-gradation trees T and σ ∈ T,

ℰ(σ||_T) = ℰ(\widehat{σ}) \ ℰ(ρ_T(ρ_T^{-1}(σ) - 1)).

Proof. The proof is by induction on the size of ℰ-gradation trees. The result is straightforward for ℰ-gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all ℰ-gradation trees of size between 2 and k. Let T be an ℰ-gradation tree of size k + 1. Let σ ∈ T and ℰ-gradation tree T' be such that T = T' ∪ {σ}. Let σ' ∈ T' be such that σ is of the form σ'·((∧,v)) or σ'·((∨,v)). We consider both cases in turn. Set i = ρ_{T'}^{-1}(σ').

# Case 1 σ = σ'·((∧,v)).

+   - Writing σ' as ((𝔛_0, v_0),…,(𝔛_n, v_n)), n ∈ ℕ, assume that 𝔛_0,…,𝔛_n are all ∧, so i = 1. Clearly,
+   - ℰ(σ||_{T'} ∧ v) = ℰ(\widehat{σ});
+   - ℰ(σ||_{T'} ∧ \bar{v}) = ℰ(σ') \ ℰ(\widehat{σ}).
