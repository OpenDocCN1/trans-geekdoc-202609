## Lemma 39.

Let a Boolean ℳ-embedding 𝔈, an 𝔈-gradation tree T with |T| > 1, and a nonempty member σ of T be given. Set i = ρ_T^{-1}(σ). Let ν be such that σ ends in (∨,ν) or (∧,ν). For all ℳ ∈ 𝔈(ρ_T(i+1)) \ 𝔈(ρ_T(i-1)), ℳ ∈ 𝔈(ρ_T(i)) iff ℳ ∈ 𝔈(ν).

Proof. The result is straightforward if 𝔈(ρ_T(i+1)) = 𝔈(ρ_T(i-1)), so suppose otherwise. The proof is by induction on the size of 𝔈-gradation trees. The result is straightforward for 𝔈-gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all 𝔈-gradation trees of size between 2 and k. Let T be an 𝔈-gradation tree of size k+1. Let σ ∈ T and 𝔈-gradation tree T' be such that T = T' ∪ {σ}. Let σ' ∈ T' be such that σ is of the form σ'·((∧,ν)) or σ'·((∨,ν)). We consider both cases in turn. Set i = ρ_{T'}^{-1}(σ'). Note that σ' is not empty, so we can write σ' as ((𝔛_0, v_0),..., (𝔛_n, v_n)), n ∈ ℕ, and i < |T'|.

### Case 1 σ = σ'·((∧,ν)).

- Assume that 𝔛_0,...,𝔛_n are all ∧, so i = 1. Obviously, for all ℳ ∈ 𝔈(σ'), ℳ ∈ 𝔈(\widehat{σ'}) iff ℳ ∈ 𝔈(ν).
- Otherwise, i > 1 and there exists a nonzero m ≤ n such that ((𝔛_m, v_m),..., (𝔛_n, v_n)) is of the form ((∨, v_m))·((∧, v_{m+1}),..., (∧, v_n)). Let τ denote ((𝔛_0, v_0),..., (𝔛_{m-1}, v_{m-1})). By Proposition 32, ρ_{T'}^{-1}(τ) = i - 1. Note that 𝔈(v_m ∧ v_{m+1} ∧ ⋯ ∧ v_n ∧ ν) = 𝔈(v_m ∧ v_{m+1} ∧ ⋯ ∧ v_n) ∩ 𝔈(ν).

Let ℳ ∈ 𝔈(ρ_T'(i+1)) \ 𝔈(ρ_T'(i-1)) be given.

- If ℳ ∈ 𝔈(ν) then since ℳ ∈ 𝔈(\widehat{σ'}), ℳ ∈ 𝔈(\widehat{σ}).
- If ℳ ∉ 𝔈(ν) then since ℳ ∉ 𝔈(\widehat{σ'}), ℳ ∉ 𝔈(\widehat{σ}).

### Case 2 σ = σ'·((∨,v)). There exists m ≤ n such that ((𝔛_m, v_m),…,(𝔛_n, v_n)) is of the form ((∧, v_m))·((∨, v_{m+1}),…,(∨, v_n)). Let τ denote ((𝔛_0, v_0),…,(𝔛_{m-1}, v_{m-1})).

By Corollary 34, ρ_T'^{-1}(τ) = i + 1. Note that

𝔈(v_m ∨ v_{m+1} ∨ ⋯ ∨ v_n ∨ v) = 𝔈(v_m ∨ v_{m+1} ∨ ⋯ ∨ v_n) ∪ 𝔈(v).

Let ℳ ∈ 𝔈(ρ_T'(i+1)) \ 𝔈(ρ_T'(i-1)) be given.

- If ℳ ∈ 𝔈(v) then since ℳ ∈ 𝔈(\widehat{σ'}), ℳ ∈ 𝔈(\widehat{σ}).
- If ℳ ∉ 𝔈(v) then since ℳ ∉ 𝔈(\widehat{σ'}), ℳ ∉ 𝔈(\widehat{σ}).

From all this and the fact that the result holds for T', we infer easily with the help of Proposition 32 and Corollary 34 that the result holds for T.

## Proposition 40. For all Boolean ℳ-embeddings 𝔈, 𝔈-gradation trees T and σ ∈ T,

𝔈(σ||_T) = 𝔈(\widehat{σ}) \ 𝔈(ρ_T(ρ_T^{-1}(σ) - 1)).

Proof. The proof is by induction on the size of 𝔈-gradation trees. The result is straightforward for 𝔈-gradation trees of size 2. Let k ≥ 2 be given, and assume that the result holds for all 𝔈-gradation trees of size between 2 and k. Let T be an 𝔈-gradation tree of size k + 1. Let σ ∈ T and 𝔈-gradation tree T' be such that T = T' ∪ {σ}. Let σ' ∈ T' be such that σ is of the form σ'·((∧,v)) or σ'·((∨,v)). We consider both cases in turn. Set i = ρ_{T'}^{-1}(σ').

### Case 1 σ = σ'·((∧,v)).

- Writing σ' as ((𝔛_0, v_0),…,(𝔛_n, v_n)), n ∈ ℕ, assume that 𝔛_0,…,𝔛_n are all ∧, so i = 1. Clearly,
- 𝔈(σ||_{T'} ∧ v) = 𝔈(\widehat{σ});
- 𝔈(σ||_{T'} ∧ \bar{v}) = 𝔈(σ') \ 𝔈(\widehat{σ}).

Also, note that

- $\sigma\parallel_T$ is defined as $\tau\parallel_{T'} \wedge \mathfrak{v}$;
- $\tau\parallel_T$ is defined as $\tau\parallel_{T'} \wedge \bar{\mathfrak{v}}$.

From all this and the fact that the result holds for $T'$, we infer easily with the help of Proposition 32 and Corollary 34 that the result holds for $T$.

## 7.5 NORMAL FORMS

Let a gradation tree $T$ and a member $\sigma$ of $T$ be given. Defined as it is, $\hat{\sigma}$ can have $\vee$s within $\wedge$s within $\vee$s within $\wedge$s... all the more so that $\sigma$ is longer and has more “direction changes”. This is in contrast to the flat structure of disjunctive or conjunctive normal forms, that limit embedding depth to 2 (disjunctions within conjunctions, or conjunctions within conjunctions). Notation 41 captures the natural way to convert $\hat{\sigma}$ to disjunctive and conjunctive normal forms. Corollary 44 characterises the disjunctive and conjunctive normal forms that can be expressed as formulas of the form $\hat{\sigma}$.

## Notation 41.

Let a gradation tree $T$ be given. Let both $\mathrm{DNF}(\sigma)$ and $\mathrm{CNF}(\sigma)$ denote $\wedge\varnothing$. Associate each nonempty member $\sigma$ of $T$ with two collections of sets as follows.

- Write $\sigma$ as
$((\wedge,\mathfrak{v}_0^0),\dots,(\wedge,\mathfrak{v}_0^{p_0}), (\vee,\mathfrak{v}_1),\dots,(\vee,\mathfrak{v}_{n_0}),(\wedge,\mathfrak{v}_1^0),\dots,(\wedge,\mathfrak{v}_1^{p_1}),$
$(\vee,\mathfrak{v}_{n_0+1}),\dots\vee,\mathfrak{v}_{n_0+n_1}),\dots,$
$\dots,(\wedge,\mathfrak{v}_k^0),\dots,(\wedge,\mathfrak{v}_k^{p_k}),(\vee,\mathfrak{v}_{\Sigma_{j<k}n_j+1}),\dots,(\vee,\mathfrak{v}_{\Sigma_{j\le k}n_j}))$
with $k,p_0,\dots,p_k,n_k\in\mathbb{N}$ and $n_0,\dots,n_{k-1}\in\mathbb{N}\setminus\{0\}$. Given $i\le\Sigma_{j<k}n_j$, set $C_i=\{\mathfrak{v}_0^0\}$ and do the following.
- For all $j\le k$, if $n_0+\cdots+n_{j-1}\le i$ then add $\mathfrak{v}_j^0,\dots,\mathfrak{v}_j^{p_j-1}$ to $C_i$.
- If there exists a (unique) nonzero $j<k$ with $n_0+\cdots+n_{j-1}=i$ then add $\mathfrak{v}_j^{p_j}$ to $C_i$.
- If $j\le k$ is largest with $n_0+\cdots+n_j\le i$, and either if $j<k$ or if $j=k$ and $n_k\ne0$, then add $\mathfrak{v}_{n_0},\dots,\mathfrak{v}_{n_j}$ to $C_i$.
- Write $\sigma$ as
$((\wedge,\mathfrak{v}_1),\dots,(\wedge,\mathfrak{v}_{p_0}),(\vee,\mathfrak{v}_0^0),\dots,(\vee,\mathfrak{v}_0^{n_0}),$
$(\wedge,\mathfrak{v}_{p_0+1}),\dots,(\wedge,\mathfrak{v}_{p_0+p_1}),(\vee,\mathfrak{v}_1^0),\dots,(\vee,\mathfrak{v}_1^{n_1}),\dots,$
$\dots,(\wedge,\mathfrak{v}_{\Sigma_{j<k}p_j+1}),\dots,(\wedge,\mathfrak{v}_{\Sigma_{j\le k}p_j}),(\vee,\mathfrak{v}_k^1),\dots,(\vee,\mathfrak{v}_k^{n_k}))$
with $k,n_k\in\mathbb{N}$ and $p_0,\dots,p_k,n_0,\dots,n_{k-1}\in\mathbb{N}\setminus\{0\}$. Given $0<i\le\Sigma_{j<k}p_j$, set $D_i=\{\mathfrak{v}_1\}$ and do the following.
- For all $j\le k$, if $p_0+\cdots+p_j\le i$ then add $\mathfrak{v}_j^0,\dots,\mathfrak{v}_j^{n_j-1}$ to $D_i$.

- If there exists a (unique) $j \le k$ with $p_0 + \cdots + p_j = i$ then add $\mathfrak{v}_j^{n_j}$ to $D_i$.
- If $j \le k$ is largest with $p_0 + \cdots + p_j \le i$, then add $\mathfrak{v}_{p_0}, \dots, \mathfrak{v}_{p_j}$ to $D_i$.

We let DNF$(\sigma)$ denote $\bigvee_{i\le\Sigma_{j\le k} n_j} \bigwedge C_i$, and CNF$(\sigma)$ denote $\bigvee_{1\le i\le\Sigma_{j\le k} p_j} \bigwedge D_i$.

## Proposition 42. For all gradation trees $T$ and members $\sigma$ of $T$, $\hat\sigma$ is equal to both DNF$(\sigma)$ and CNF$(\sigma)$.

Proof. This is easily verified by induction on the length of the members of $T$, using the fact that a Boolean algebra is distributive.
