Proof. Without loss of generality, assume that all atoms occur in φ. Let φ* denote φ if for every ⊆-maximal set D of literals such that Mod_A(D ∪ {φ}) ≠ ∅, D contains at least one atom; otherwise, let φ* denote ¬φ. Let X be the set of all ⊆-maximal sets D of literals such that Mod_A(D ∪ {φ*}) ≠ ∅. For all D ∈ X, let D+ be the set of atoms in D. Set |A| = k. Let (ξ_i)_{i<k} be an enumeration of A. Set |X| = n. Let (D_m)_{m<n} be an enumeration of X such that for all m,m' < n, if D_m^+ ⊃ D_{m'}^+ then m < m'. Inductively define for all m < n a set X_m of sets of atoms. Let m < n be given, and assume that X_{m'} has been defined for all m' < m. Let X_m consist of:

+   - D_m^+;
+   - every set of the form D_m^+ ∪ {ξ_i}, i < k, that does not include any member of ∪_{m'<m} X_{m'}.

Now define an A^∧-gradation tree T as the ⊆-smallest set of finite sequences of members of A^∧ closed under sequences such that for all m < n, the following holds. Let p denote |X_m| − 1.
