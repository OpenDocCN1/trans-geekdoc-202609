# Proposition 59. Suppose that 𝔞 consists of n atoms p1,…,pn, n ∈ ℕ\{0}, and 𝔐 is the set of all interpretations.

+   - Some classifying 𝔞-gradation graph with n + 1 nodes and n(n+1)/2 edges recognises ⊕_{1≤i≤n} p_i.
+   - For all classifying 𝔞^∧-gradation trees T that recognise ⊕_{1≤i≤n} p_i, |T| ≥ 2^n.

Proof. Set φ0 = ∧∅ and V = {p_i | i < n}. Let E be the set of all pairs of the form (p_i, p_j), 0 ≤ i < j ≤ n. Obviously, if ℛ is a presentation of (V,E) then for all i, j, k ≤ n with i < j < k, (i,j) occurs before (i,k) in ℛ. Using that observation, it is easy to verify that (V,E), which has n + 1 nodes and n(n+1)/2 edges, is a parity-based, negative by default classifying 𝔞-gradation graph that recognises ⊕_{1≤i≤n} p_i. Let (T,ℓ) be a classifying 𝔞^∧-gradation tree that recognises ⊕_{1≤i≤n} p_i. Recall from Notation 36 the definition of σ||_T for all σ ∈ T. In a related way, map each σ ∈ T to S_σ, defined as follows. Set S_∅ = ∅. Let a nonempty σ ∈ T be given, and write σ as ((𝔞0, v0),…, (𝔞n, vn)), n ∈ ℕ. Set X = {vn} ∪ {vi | i < n, 𝔞_{i+1} = ∧}.
