Notation 24. Given a gradation tree T, we denote by ρ_T the mapping of domain {1,...,|T|} that maps each i ∈ dom(ρ_T) to the i-th member of T w.r.t. the total strict order on T defined in Lemma 21. We sometimes tacitly assume that dom(ρ_T) is rather {0,...,|T|}, in which case ρ_T(0)=0.

Definition 25. Given a gradation tree T, we refer to (ρ_T(i))_{1≤i≤|T|} as T's standard enumeration.
