# III. PROPOSED METHOD

# A. Spatial-Temporal Signal Model in the Single-Pitch Case

To present the proposed method clearly, we first focus on the problem of parameter estimation in the single-pitch case, that is where P = 1 in the signal model (1). In the signal model (1), for P = 1, the received array data can be written as x_r(n) = s_r(n) + q_r(n), n = 0,1,…,N−1, s_r(n) = Σ_{l=1}^L α_l e^{jω l n + φ l r} (3) In this case, only a pair of unknown parameters (ω, φ) is estimated from the observed signal. Based on the above model, a spatio-temporal matrix signal model is first defined as follows X(n) = S(n) + Q(n), n = 0,1,…,N−M, (4) where X(n) = [ x0(n) … x0(n+M−1); ⋮ ⋱ ⋮; x_{R−1}(n) … x_{R−1}(n+M−1) ], (5) and S(n) and Q(n) are defined similar to X(n). In addition, M is a given positive integer, which is smaller than N and satisfies MR > L. The signal matrix of interest S(n) can be rewritten by (3) as S(n) = Σ_{l=1}^L β_l(n) a_s(lφ) a_t^T(lω), (6) where β_l(n) = α_l e^{j l ω n}, (7) a_s(φ) = [1 e^{jφ} … e^{j(R−1)φ}]^T, (8) a_t(ω) = [1 e^{jω} … e^{j(M−1)ω}]^T. (9) Define a new vector model x(n) by stacking the columns of X(n) as x(n) = vec{X(n)} = s(n) + q(n) = A z(n) + q(n), (10) and hence we have s(n) = vec{S(n)} (11) q(n) = vec{Q(n)} (12) A = [a(ω,φ),…,a(Lω,Lφ)], (13) a(lω,lφ) = a_t(lω) ⊗ a_s(lφ), (14) z(n) = [α1 e^{jω n},…,α_L e^{j L ω n}]^T. (15) Based on the data model (10), a nonlinear least squares method for DOA and pitch estimation in the case of single pitch was recently reported in [36], where the 2-D search computation

as well as relatively fine candidate grids for the unknown parameters are required to obtain accurate DOA and pitch estimates, which thus results in a high computational load. In this following Section III-B, a lower-complexity ESPRIT-based method is derived based on the spatio-temporal model in the subsection, and a generalization of the proposed method to the multi-pitch case is suggested in the Section III-C.

B. Joint Estimation of DOA and Pitch in the Single-pitch Case: Multichannel Single-pitch ESPRIT (MSP-ESPRIT) For n = 0,1,…,N−M, one first defines the following matrix with x(n), Y_{RM×(N−M+1)} = [x(0)x(1)…x(N−M)] = A[z(0)…z(N−M)] + [q(0)…q(N−M)] (16) Under the condition of full column rank of matrix A, one can obtain the signal subspace from the singular-value decomposition (SVD) or equivalent eigenvalue decompositions of the covariance matrix of Y. The signal subspace matrix U_s is then composed of the L singular vector associated with the largest singular values of Y. It is well-known that the signal subspace spanned by the column vectors of U_s is the same subspace as all the column vectors in matrix A; therefore, there exists a unique nonsingular matrix T such that U_s = A T. Using the inherent structure of a_t(ω) and a_s(φ), the shift invariance property of A can be found so that the classic ESPRIT method [19] is exploited to estimate the DOA and pitch parameters, respectively. In so doing, we first define the following four selection matrices W1 = [I_{M−1}; 0_{1×(M−1)}] ⊗ I_R, W2 = [0_{1×(M−1)}; I_{M−1}] ⊗ I_R, W3 = I_M ⊗ [I_{R−1}; 0_{1×(R−1)}], W4 = I_M ⊗ [0_{1×(R−1)}; I_{R−1}], where 0 is the vector of zeros. The submatrices A_i of A are further defined by the above selection matrix W_i as A_i = W_i^T A, i = 1,2,3,4.
