
Sie sind auch eine Klasse von Modellen, die den Begriff »Neural Network« voll und ganz verdienen. Das Design der CNNs wurde ursprünglich von der Arbeitsweise des visuellen Cortex bei Katzen inspiriert. (Seit der Entstehung von Deep Learning haben Katzen darin eine zentrale Rolle gespielt.) In Untersuchungen ab den 1950er-Jahren bis in die 1980er wurde gezeigt, dass das Sehen durch eine Reihe von Schichten verarbeitet wird. Jedes Neuron in der ersten Schicht nimmt Eingaben aus einer kleinen Region des Sichtfelds an (seinem `rezeptiven Feld`). Unterschiedliche Neuronen sind darauf spezialisiert, bestimmte lokale Muster oder Merkmale wie vertikale oder horizontale Linien zu erkennen. Zellen in der zweiten Ebene nehmen Eingaben von lokalen Zellclustern der ersten Ebene auf und kombinieren deren Signale, um kompliziertere Muster über ein größeres Empfangsfeld zu erfassen. Jede Schicht kann als neue Darstellung des Originalbilds betrachtet werden, die in Form größerer und abstrakterer Muster als in der vorhergehenden Schicht beschrieben wird.

CNNs spiegeln dieses Design wider und senden ein Eingabebild durch eine Reihe von Ebenen. So gesehen sind sie wie MLPs, aber die Struktur jeder Ebene ist sehr unterschiedlich. MLPs verwenden `vollständig verbundene Schichten`. Jedes Element des Ausgabevektors hängt von einem Element im Eingabevektor ab. CNNs dagegen verwenden `Konvolutionsschichten`, die die räumliche Lokalität ausnutzen. Jedes Ausgabeelement entspricht einem kleinen Bereich des Bilds und hängt nur von den Eingabewerten in diesem Bereich ab. Das reduziert die Anzahl der Parameter, die jede Ebene definieren, erheblich. In der Tat wird davon ausgegangen, dass die meisten Elemente der Gewichtsmatrix `M[i]` 0 sind, da jedes Element der Ausgabe nur von einer kleinen Anzahl von Eingabeelementen abhängt.

Konvolutionsschichten gehen noch einen Schritt weiter: Sie nehmen an, dass die Parameter für `jeden lokalen Bereich des Bilds` gleich sind. Verwendet eine Ebene einen Parametersatz, um horizontale Linien an einer Stelle im Bild zu erkennen, nutzt sie dieselben Parameter auch, um horizontale Linien an allen anderen Stellen im Bild zu erkennen. Dadurch ist die Anzahl der Parameter für die Schicht unabhängig von der Größe des Bilds. Es muss nur ein einzelner `Convolution-Kernel` gelernt werden, der definiert, wie Ausgabemerkmale aus einem beliebigen lokalen Bereich des Bilds berechnet werden. Dieser lokale Bereich ist oft sehr klein, etwa 5 × 5 Pixel. In diesem Fall beträgt die Anzahl der zu lernenden Parameter nur das 25-Fache der Anzahl der Ausgabemerkmale für jede Region. Das ist winzig im Vergleich zu der Anzahl in einer vollständig verbundenen Schicht. Dadurch sind CNNs viel einfacher zu trainieren und weniger anfällig für Overfitting als MLPs.

### Recurrent Neural Networks

`Recurrent Neural Networks` (abgekürzt RNNs) sind anders. Üblicherweise werden sie zur Verarbeitung von Daten verwendet, die aus einer Abfolge von Elementen bestehen: Wörter einer Textdatei, Basen eines DNA-Moleküls usw. Die Elemente der Abfolge werden einzeln in die Eingabe des Netzes eingespeist. Dann macht das Netz jedoch etwas völlig anderes: Die Ausgabe jeder Ebene wird im nächsten Schritt in die eigene Eingabe zurückgeführt! Dadurch haben RNNs eine Art Gedächtnis. Wird ein Element (Wort, DNA-Base usw.) der Abfolge dem Netz zugeführt, hängt die Eingabe jeder Schicht von diesem Element ab und von den aller vorherigen Elemente (siehe [Abbildung 2-4](#Chapter02_9783960103516.xhtml#abb2-4)).

![image](Images/p22-1.png)

*Abbildung 2-4: Ein Recurrent Neural Network. Jedes Element (x[1], x[2], ...) der Abfolge wird als Eingabe zugeführt. Die Ausgabe (y[1], y[2], …) hängt von der Eingabe und der RNN-Ausgabe des vorhergehenden Schritts ab*.

Somit besteht die Eingabe einer rückgekoppelten Ebene aus zwei Teilen: der normalen Eingabe (d.h. der Ausgabe der vorhergehenden Ebene im Netz) und der rückgekoppelten Eingabe (die der eigenen Ausgabe des vorhergehenden Schritts entspricht). Die neue Ausgabe wird anhand dieser beiden Eingaben ermittelt. Theoretisch könnte eine vollständig verbundene Ebene verwendet werden, praktisch funktioniert das aber nicht sonderlich gut. Wissenschaftler haben andere Ebenentypen entwickelt, die in RNNs viel besser funktionieren. Zwei der beliebtesten sind das `Gated Recurrent Unit` (GRU) und das `Long Short-Term Memory` (LSTM). Kümmern Sie sich vorerst nicht um die Details, sondern merken Sie sich nur: Wenn Sie ein RNN erstellen, sollte es aus einer der genannten Ebenenarten zusammengesetzt sein.

Die Fähigkeit, Erinnerungen zu haben, unterscheidet RNNs grundlegend von anderen Modellen, die wir vorgestellt haben. Mit einem CNN oder MLP wird nur ein Wert in das Netz eingelesen und ein anderer ausgelesen. Die Ausgabe wird vollständig von der Eingabe bestimmt. Nicht so beim RNN. Das Modell hat eigene interne Zustände, die aus den Ausgaben aller Ebenen des letzten Schritts zusammengesetzt sind. Jedes Mal, wenn eine Eingabe in das Modell erfolgt, hängt die Ausgabe nicht nur vom Eingabewert ab, sondern auch vom internen Zustand. Das macht RNNs sehr mächtig und für sehr viele verschiedene Anwendungen einsetzbar.
