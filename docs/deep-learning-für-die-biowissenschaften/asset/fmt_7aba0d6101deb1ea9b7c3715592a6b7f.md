
Zuerst laden wir die zugehörigen Daten. Diese sind in einer Textdatei enthalten, bei der jede Zeile einer Probe unseres Datensatzes entspricht (der 101-Basenabschnitt des Chromosoms 22). Jede Zeile enthält die Proben-ID, gefolgt von einer Zahl, die angibt, wie einfach dieser Bereich in HepG2-Zellen zugänglich ist. Wir lesen ihn ein in ein Python-Dictionary:

```

    fields = line.split()
    span_accessibility[fields[0]] = float(fields[1])
```

Wir wählen fast das gleiche Modell wie im vorangegangenen Abschnitt mit nur zwei kleinen Änderungen. Zuerst benötigen wir eine weitere Eingabe für die Zugänglichkeitswerte, die aus einer Zahl je Probe besteht:

```
accessibility = layers.Feature(shape=(None, 1))
```

Als Nächstes beziehen wir den Zugänglichkeitswert in die Berechnung ein. Hierfür gibt es verschiedene Möglichkeiten. In diesem Beispiel verwenden wir eine besonders einfache Methode. Im vorherigen Abschnitt haben wir die Ausgabe der letzten Konvolutionsebene abgeflacht und diese dann als Eingabe für einen Dense-Layer verwendet, der das Ergebnis berechnet hat.

```
logits = layers.Dense(out_channels=1, in_layers=layers.Flatten(prev))
```

Hier tun wir dasselbe und fügen dann noch die Zugänglichkeit der Konvolutionsebene hinzu:

```
prev = layers.Concat([layers.Flatten(prev), accessibility])
logits = layers.Dense(out_channels=1, in_layers=prev)
```

Das Modell ist fertig! Jetzt wird es trainiert.

An diesem Punkt gibt es ein Problem: Unser Modell hat zwei verschiedene Feature-Ebenen! Bisher hatten unsere Modelle genau eine Feature-Ebene, eine Label-Ebene und möglicherweise noch eine Gewichte-Ebene. Trainiert wurden sie durch den Aufruf von `fit(dataset)`, der automatisch die richtigen Daten mit jeder Ebene verbunden hat: X des Datensatzes für die Features, y für die Labels und w für die Gewichte. Dies kann jedoch nicht funktionieren, wenn das Modell mehrere Features aufweist.

Mithilfe einer erweiterten Funktion von DeepChem lässt sich das Problem jedoch beheben. Anstatt einen Datensatz an das Modell zu übergeben, können wir eine Generatorfunktion in Python schreiben, die über Batches iteriert. Jedes Batch wird durch ein Dictionary dargestellt, dessen Schlüssel die Eingabeebenen sind und dessen Werte die NumPy-Arrays sind, die für sie verwendet werden sollen:

```
def generate_batches(dataset, epochs):
    for epoch in range(epochs):
        for X, y, w, ids in dataset.iterbatches(batch_size=1000, pad_batches=True):
            yield {
                features: X,
                accessibility: np.array([span_accessibility[id] for id in ids]),
                labels: y,
                weights: w
            }
```

Beachten Sie, wie der Datensatz für uns die Iteration der Batches übernimmt. Es liefert die Daten für jedes Batch, aus denen wir die für das Modell erforderlichen Eingaben erstellen können.

Das Training und die Auswertung erfolgen wie gehabt. Wir ersetzen nur den Datensatz durch einen Generator:

```
for i in range(20):
    model.fit_generator(generate_batches(train, 10))
    print(model.evaluate_generator(generate_batches(train, 1), [metric], labels=[labels], weights=[weights]))
    print(model.evaluate_generator(generate_batches(valid, 1), [metric], labels=[labels], weights=[weights]))
```

### RNA-Interferenz

Für das letzte Beispiel wenden wir uns der RNA zu. Ähnlich wie DNA handelt es sich hierbei um ein Polymer, das aus vier sich wiederholenden Einheiten besteht, die Basen genannt werden. Genau genommen sind drei der vier Basen fast identisch mit ihren DNA-Versionen und unterscheiden sich nur durch ein zusätzliches Sauerstoffatom. Die vierte Base ist etwas anders. Anstelle von Thymin (T) hat RNA eine Base namens Uracil (U). Wird eine DNA-Sequenz in RNA transkribiert, wird jedes T durch ein U ersetzt.

Die Basen G und C sind *komplementär*, daher haben sie eine starke Tendenz zur Bindung untereinander. Ebenso sind die Basen A und T (oder U) komplementär. Liegen zwei DNA- oder RNA-Stränge vor und jede Base eines Strangs ist komplementär zur entsprechenden Base im anderen Strang, halten die beiden Stränge zusammen. Diese Tatsache spielt eine Schlüsselrolle in vielen biologischen Prozessen, einschließlich der Transkription und Translation sowie der DNA-Replikation bei der Zellteilung.

Das ist auch von zentraler Bedeutung für die *RNA-Interferenz*. Dieses Phänomen wurde erst in den 1990er-Jahren entdeckt und führte zu einem Nobelpreis in 2006. Ein kurzes Stück RNA, dessen Sequenz komplementär zu einem Teil einer Boten-RNA ist, kann an diese mRNA binden. Wenn das geschieht, wird die mRNA »zum Schweigen gebracht«, und es wird verhindert, dass sie in ein Protein übersetzt wird. Das Molekül, das die Stummschaltung durchführt, wird als kurze interferierende RNA (siRNA) bezeichnet.

Der Prozess beinhaltet jedoch noch viel mehr. RNA-Interferenz ist ein komplexer biologischer Mechanismus, nicht nur ein Nebenprodukt zweier isolierter RNA-Stränge, die zufällig zusammenkleben. Es beginnt mit der siRNA-Bindung an eine Sammlung von Proteinen, die als *RNA-induced Silencing Complex* (RISC) bezeichnet werden. Der RISC nutzt die siRNA als Vorlage, um passende mRNAs in der Zelle zu finden und abzubauen. Dies dient sowohl als Mechanismus zur Regulation der Genexpression als auch zur Virenabwehr.

Des Weiteren ist er ein leistungsfähiges Instrument in der Biologie und der Medizin. Jedes gewünschte Gen kann damit vorübergehend »ausgeschaltet« werden. Es kann zur Behandlung von Krankheiten verwendet werden oder um zu untersuchen, was passiert, wenn ein Gen deaktiviert ist. Es muss nur die zu blockierende mRNA identifiziert, davon ein kurzer Abschnitt gewählt und ein siRNA-Molekül mit der komplementären Sequenz erstellt werden.

Natürlich ist es nicht ganz so einfach. Man kann nicht einfach irgendeinen Abschnitt der mRNA zufällig auswählen, da (natürlich!) RNA-Moleküle nicht nur abstrakte Muster aus vier Buchstaben sind. Es sind Objekte mit individuellen Eigenschaften, und diese Eigenschaften hängen von der Sequenz ab. Einige RNA-Moleküle sind stabiler als andere. Einige binden ihre komplementären Sequenzen stärker als andere. Einige falten sich in Formen, die es RISC erschweren, daran zu binden. Somit funktionieren einige siRNA-Sequenzen besser als andere, und wenn Sie die RNA-Interferenz als Werkzeug verwenden möchten, müssen Sie wissen, wie Sie eine gute auswählen können!

Biologen haben viele Heuristiken zur Auswahl von siRNA-Sequenzen entwickelt. Zum Beispiel sollte die allererste Base entweder ein A oder ein G sein, G- und C-Basen sollten zwischen 30 % und 50 % der Sequenz ausmachen usw. Diese Faustformeln sind hilfreich, aber vielleicht kann Machine Learning das besser.

Wir trainieren unser Modell anhand einer Bibliothek von 2.431 siRNA-Molekülen, die jeweils 21 Basen lang sind.^([1](#Footnote_9783960103516.xhtml#ch6fn1)) Jedes davon wurde experimentell getestet und mit einem Wert zwischen 0 und 1 gekennzeichnet, der anzeigt, wie effektiv es sein Zielgen stummschaltet. Kleine Werte deuten auf unwirksame Moleküle hin, während höhere Werte auf wirksamere hinweisen. Das Modell verwendet die Sequenz als Eingabe und versucht, die Wirksamkeit vorherzusagen.
