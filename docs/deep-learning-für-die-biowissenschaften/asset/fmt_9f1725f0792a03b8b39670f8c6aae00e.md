#### Die Zellzählung

Eine einfache Aufgabe ist das Zählen der Zellen in einem vorliegenden Bild. Sie fragen sich vermutlich, weshalb das eine interessante Aufgabe ist. Für etliche biologische Experimente kann es sehr nützlich sein, die Anzahl der Zellen zu kennen, die nach einem erfolgten Eingriff überleben. Beispielsweise stammen die Zellen aus einer Krebszelllinie, und beim Eingriff handelt es sich um eine Anti-Krebs-Therapie. Ein erfolgreicher Eingriff würde die Anzahl der lebenden Krebszellen verringern, daher wäre es hilfreich, ein Deep-Learning-System zu haben, mit dem die Anzahl dieser Zellen ohne menschliches Zutun ermittelt werden kann.

##### Was ist eine Zelllinie?

In der Biologie ist es oftmals nützlich, Zellen eines bestimmten Typs zu untersuchen. Der erste Schritt bei der Durchführung eines Experiments, das gegen eine Sammlung von Zellen gerichtet ist, besteht darin, ausreichend solcher Zellen zur Verfügung zu haben. Bei Zelllinien handelt es sich um Zellen, die aus einer Quelle kultiviert wurden und die unter Laborbedingungen unbegrenzt wachsen können.

Zelllinien wurden in einer Vielzahl biologischer Publikationen verwendet, aber es gibt oft ernsthafte Bedenken hinsichtlich der Wissenschaft, die mit ihnen betrieben wird. Zunächst einmal kann das Entfernen einer Zelle aus ihrer natürlichen Umgebung ihre Biologie grundlegend verändern. Die Hinweise verdichten sich, dass die Umgebung einer Zelle ihre Reaktion auf Reize wesentlich beeinflussen kann.

Noch schwerwiegender ist, dass Zelllinien häufig verunreinigt sind. Zellen einer Zelllinie können Zellen einer anderen Zelllinie verunreinigen, sodass die Ergebnisse einer »Brustkrebs«-Zelllinie dem Forscher in Wahrheit überhaupt nichts über Brustkrebs aussagen!

Aus diesen Gründen sind Studien an Zelllinien häufig mit Vorsicht zu genießen, und die Ergebnisse sollten mit Tests an Tieren oder Menschen bestätigt werden. Nichtsdestotrotz bieten Zelllinienstudien einen einfachen Einstieg in die biologische Forschung und sind nach wie vor allgegenwärtig.

Wie [Abbildung 7-12](#Chapter07_9783960103516.xhtml#abb7-12) zeigt, können sich die Bildbedingungen in der Zellmikroskopie erheblich von Standard-Bildbedingungen unterscheiden. Daher ist nicht sofort ersichtlich, dass Verfahren wie `Convolutional Neural Networks` an Aufgaben wie die Zellzählung angepasst werden können. Glücklicherweise haben bedeutende experimentelle Arbeiten gezeigt, dass `Convolutional Networks` sehr gut mit Mikroskopiedatensätzen lernen können.

Bevor die Datensätze in `DeepChem` geladen werden können, müssen Sie sie zunächst lokal abspeichern. Der `BBBC005`-Datensatz, den wir für diese Aufgabe verwenden werden, ist relativ groß (knapp 2 GByte). Stellen Sie daher sicher, dass Ihr Rechner ausreichend Speicherplatz zur Verfügung hat:

Sobald der Datensatz heruntergeladen ist, kann er mithilfe von `ImageLoader` in `DeepChem` geladen werden:

```
image_dir = 'BBBC005_v1_images'
files = []
labels = []
for f in os.listdir(image_dir):
    if f.endswith('.TIF'):
        files.append(os.path.join(image_dir, f))
        labels.append(int(re.findall('_C(.*?)_', f)[0]))
loader = dc.data.ImageLoader()
dataset = loader.featurize(files, np.array(labels))
```

Dieser Code durchsucht das heruntergeladene Bilderverzeichnis und ruft die einzelnen Bilder ab. Die Labels sind in den Dateinamen enthalten, daher verwenden wir einen regulären Ausdruck, um die Anzahl der Zellen jedes Bilds zu extrahieren. Wir nutzen `ImageLoader`, um dies in einen `DeepChem`-Datensatz umzuwandeln.

Als Nächstes teilen wir diesen Datensatz in je einen Trainings-, Validierungs- und Testdatensatz auf:

```
splitter = dc.splits.RandomSplitter()
train_dataset, valid_dataset, test_dataset = splitter.train_valid_test_split(
    dataset, seed=123)
```

Nun können wir das Modell definieren. Wir erstellen ein einfaches Konvolutionsmodell mit einem vollständig verbundenen Layer am Ende:

```
learning_rate = dc.models.tensorgraph.optimizers.ExponentialDecay(0.001, 0.9, 250)
model = dc.models.TensorGraph(learning_rate=learning_rate, model_dir='model')
features = layers.Feature(shape=(None, 520, 696))
labels = layers.Label(shape=(None,))
prev_layer = features
for num_outputs in [16, 32, 64, 128, 256]:
    prev_layer = layers.Conv2D(num_outputs, kernel_size=5, stride=2, in_layers=prev_layer)
output = layers.Dense(1, in_layers=layers.Flatten(prev_layer))
model.add_output(output)
loss = layers.ReduceSum(layers.L2Loss(in_layers=(output, labels)))
model.set_loss(loss)
```
