

# 深度学习在生命科学中的进展与应用

在本章中，我们已经指出了许多基于将深度学习应用于生物和医学图像分析的进展。这些实验中研究的许多现象太小，无法用肉眼观察。为了获得深度学习方法所需的图像，我们必须使用显微镜。[第 7 章](#Chapter07_9783960103516.xhtml#ch7)概述了无数种形式的显微镜，从我们从学校就熟知的简单光学显微镜，到能够拍摄原子分辨率图像的高度发达的仪器。此外，还指出了当前方法的一些局限性，并提供了获取用于深度学习模型图像的实验流程信息。

## 医学诊断

一个非常有前景的领域是将深度学习应用于医学诊断。医学极其复杂，没有任何医生能将所有可用的医学知识融会贯通。在理想情况下，机器学习模型可以处理医学文献并协助医生进行诊断。虽然我们尚未达到那一步，但我们正走在正确的道路上。[第 8 章](#Chapter08_9783960103516.xhtml#ch8)从机器学习在诊断中的历史讲起，并勾勒了从手工编码规则向医学结果统计分析的过渡。正如在许多其他主题中提到的，一个重要组成部分是将医学信息表示为机器学习程序可处理的格式。本章介绍了电子病历，并指出了涉及这些记录的一些问题。医学图像通常非常复杂，即使对于经验丰富的专家来说，这些图像的评估和解读也很困难。在这些情况下，深度学习可以通过对图像进行分类和识别关键特征来扩展人类的能力。[第 8 章](#Chapter08_9783960103516.xhtml#ch8)以一系列示例作为结尾，展示了深度学习如何在各个领域被用于分析医学图像。

## 药物发现与生成模型

如前所述，机器学习是寻找新药物的重要组成部分。科学家应用深度学习来评估药物分子与蛋白质之间的相互作用。这些相互作用可以引发生物学反应，从而对患者产生治疗效果。我们迄今为止讨论的模型是*判别模型*。基于分子的一系列特性，模型预测另一个特性。这些预测需要一个输入分子，它可以来自现有分子数据库或科学家的想象。如果我们不必依赖现有的或想象出来的分子，而是拥有一个能够「发明」新分子的计算机程序，那会怎样？[第 9 章](#Chapter09_9783960103516.xhtml#ch9)介绍了深度学习的另一种方法，即*生成模型*。生成模型首先在可用分子上训练，随后用于生成新分子。生成这些分子的深度学习程序也可以受到其他预测新分子活性的模型的影响。

## 可解释性与模型准确性

到目前为止，我们将深度学习模型视为「黑箱」。模型接收输入数据并生成预测，但没有任何关于预测是如何或为什么产生的解释。这种预测在许多情况下可能是次优的。如果我们有一个用于诊断的深度学习模型，通常希望了解诊断背后的原因。对诊断原因的解释能给医生对预测更多的信心，也会影响治疗决策。深度学习的一个历史遗留问题是，尽管模型通常可靠，但难以解释。目前正在开发一些技术，旨在让用户了解哪些因素导致了预测。[第 10 章](#Chapter10_9783960103516.xhtml#ch10)概述了其中一些实现人类理解预测模型的技术。预测模型的另一个重要方面是预测的准确性。了解模型的准确性有助于我们确定可以在多大程度上依赖该模型。由于机器学习可能用于挽救生命的诊断，因此理解模型准确性至关重要。在[第 10 章](#Chapter10_9783960103516.xhtml#ch10)的最后一部分，我们概述了一些用于评估模型准确性的技术。

## 案例研究：使用 DeepChem 进行虚拟筛选

在[第 11 章](#Chapter11_9783960103516.xhtml#ch11)中，我们将展示一个使用 DeepChem 的真实案例研究。在该示例中，我们使用一种称为「虚拟筛选」的程序来识别发现新药物的可能起点。新药发现是一个复杂的过程，通常始于一种称为*筛选*的技术。通过筛选可以识别出可优化并最终生成药物的分子。筛选可以通过实验进行，即在微型生物测试（也称为分析）中测试数百万个分子，或者使用计算机进行虚拟筛选。虚拟筛选利用已知药物或其他生物活性分子来训练机器学习模型。然后使用该模型来预测大量分子的活性。得益于机器学习方法的高速度，通常可以在几天内处理数亿个分子。

# 第 2 章：深度学习简介

本章将向您介绍深度学习的基本原理。如果您已经拥有一定的深度学习经验，可以浏览本章然后继续下一章。如果您经验较少，应仔细阅读本章，因为其中包含的知识对于理解本书其余部分至关重要。

在我们将要处理的大多数任务中，我们的工作是创建一个数学公式：

```
**y** = *f*(**x**)
```

请注意，`**x**` 和 `**y**` 是粗体。这意味着它们是向量。一个函数可以有许多输入值，可能成千上万甚至数百万，并产生许多输出值。以下是一些函数示例：

*   `**x**` 包含图像中所有像素的颜色。如果图像中描绘了一只猫，`*f*(**x**)` 结果为 1，否则为 0。
