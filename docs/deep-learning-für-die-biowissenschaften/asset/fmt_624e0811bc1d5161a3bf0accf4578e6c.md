
Beachten Sie, dass wir `L2Loss` verwenden, um unser Modell als Regression zu trainieren. Auch wenn es sich bei der Anzahl der Zellen um ganze Zahlen handelt, gibt es keine Obergrenze für die Anzahl der Zellen, die in einem Bild enthalten sind.

Das Trainieren dieses Modells erfordert einen gewissen Rechenaufwand (dazu gleich mehr). Daher empfehlen wir, zunächst unser vortrainiertes Modell zu verwenden. Dieses Modell ist gebrauchsfertig, um Prognosen zu erstellen. Anweisungen zum Herunterladen des vorab trainierten Modells befindet sich im dem Buch zugehörigen Code-Repository (*[https://github.com/deepchem/DeepLearningLifeSciences](https://github.com/deepchem/DeepLearningLifeSciences)*). Sobald es heruntergeladen ist, können Sie die vortrainierten Gewichte in das Modell laden:

```
model.restore()
```

Lassen Sie uns dieses vortrainierte Modell einmal ausprobieren. Zuerst berechnen wir den durchschnittlichen Vorhersagefehler in unserem Testdatensatz für unsere Aufgabe der Zellzählung:

```
y_pred = model.predict(test_dataset).flatten()

print(np.sqrt(np.mean((y_pred-test_dataset.y)**2)))
```

Welche Genauigkeit erhalten Sie nach der Ausführung des Modells?

Wie können Sie dieses Modell nun selbst trainieren? Sie können es anpassen, indem Sie es für 50 Epochen trainieren:

```
model.fit(train_dataset, nb_epoch=50)
```

Diese Aufgabe erfordert einiges an Rechenleistung. Bei einer guten GPU sollte der Vorgang in etwa einer Stunde abgeschlossen sein. Es ist eventuell nicht möglich dieses Modell auf einem CPU-System zu trainieren.

## Zellsegmentierung

Bei der Zellsegmentierung werden Mikroskopaufnahmen von Zellen mit Anmerkungen versehen, die angeben, wo Zellen bzw. Hintergrund gezeigt wird. Warum ist das nützlich? Sollten Sie sich an unsere vorangegangene Beschreibung von grampositiven und gramnegativen Bakterien erinnern, erraten Sie vermutlich, warum sich ein automatisiertes System zur Trennung der beiden Bakterienarten lohnen könnte. Ähnliche Probleme treten durchgehend in der Zellmikroskopie auf (und auf anderen Gebieten der Bildgebung, wie wir in [Kapitel 8](#Chapter08_9783960103516.xhtml#ch8) sehen werden).

Segmentierungsmasken bieten eine wesentlich bessere Auflösung und ermöglichen eine genauere Analyse als das Zählen der Zellen. Beispielsweise könnte es nützlich sein, zu wissen, wie groß der Anteil einer Platte ist, die mit Zellen bedeckt ist. Solche Analysen sind einfach durchzuführen, wenn eine Segmentierungsmaske zur Verfügung steht. In [Abbildung 7-13](#Chapter07_9783960103516.xhtml#abb7-13) wird eine Segmentierungsmaske dargestellt, die aus einem synthetischen Datensatz stammt.

![image](Images/p121-01.jpg)

Die Segmentierung verlangt jedoch wesentlich mehr von einem Machine-Learning-Modell als nur Zählen. Um zelluläre von nicht zellulären Regionen akkurat unterscheiden zu können, muss das Lernen präziser erfolgen. Aus diesem Grund ist es nicht verwunderlich, dass es immer noch schwieriger ist, Segmentierungsansätze im Machine Learning zum Laufen zu bringen, als dies beim einfachen Zählen der Zellen der Fall ist. ### Implementierung der Zellsegmentierung in DeepChem

In diesem Abschnitt werden wir ein zellulares Segmentierungsmodell auf dem gleichen BBBC005-Datensatz trainieren, den wir zuvor für das Zählen der Zellen verwendet haben. Es gibt jedoch einen entscheidenden Unterschied. Bei der Aufgabe der Zellzählung hat jedes Bild eine Anzahl als Label. Bei der zellularen Segmentierung jedoch ist jedes Label selbst ein Bild. Das bedeutet, dass es sich beim zellularen Segmentierungsmodell eher um eine »Bildumwandlung« als ein einfaches Klassifizierungs- oder Regressionsmodell handelt. Wir beginnen mit dem Download dieses Datensatzes. Hierfür verwenden wir folgende Befehle, um die Segmentierungsmasken von der BBBC-Webseite aufzurufen:

```
wget https://data.broadinstitute.org/bbbc/BBBC005/BBBC005_v1_ground_truth.zip

unzip BBBC005_v1_ground_truth.zip
```

Der ground-truth-Datensatz hat eine Größe von etwa 10 MByte und sollte daher einfacher herunterzuladen sein als der vollständige BBBC005-Datensatz. Als Nächstes laden wir diesen Datensatz in DeepChem. Glücklicherweise ist `ImageLoader` so aufgebaut, dass Datensätze zur Bildsegmentierung ohne großen zusätzlichen Aufwand verarbeitet werden können:

```
image_dir = 'BBBC005_v1_images'

label_dir = 'BBBC005_v1_ground_truth'

rows = ('A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I', 'J', 'K', 'L',
'M', 'N', 'O', 'P')

blurs = (1, 4, 7, 10, 14, 17, 20, 23, 26, 29, 32, 35, 39, 42, 45, 48)

files = []
labels = []

for f in os.listdir(label_dir):
    if f.endswith('.TIF'):
        for row, blur in zip(rows, blurs):
            fname = f.replace('_F1', '_F%d'%blur).replace('_A', '_%s'%row)
            files.append(os.path.join(image_dir, fname))
            labels.append(os.path.join(label_dir, f))

loader = dc.data.ImageLoader()
dataset = loader.featurize(files, labels)
```

Nachdem die Datensätze geladen und verarbeitet sind, können wir das Deep-Learning-Modell erstellen. Wie gehabt, teilen wir diesen Datensatz in jeweils einen Trainings-, einen Validierungs- und einen Testdatensatz:

```
splitter = dc.splits.RandomSplitter()
train_dataset, valid_dataset, test_dataset = splitter.train_valid_test_split(
dataset, seed=123)
```

Welches Modell können wir für die Bildsegmentierung verwenden? Es reicht nicht, ein einfaches Convolutional Neural Network einzusetzen, da unsere Ausgabe ebenfalls ein Bild wird (die Segmentierungsmaske). Glücklicherweise gibt es Arbeiten, die sich mit geeigneten Modellen für diese Aufgabe befasst haben. Das `U-Net`-Modell verwendet eine gestapelte Reihe von Konvolutionen, um das Originalbild schrittweise »herunterzurechnen« und dann wieder »hochzurechnen«, wie in [Abbildung 7-14](#Chapter07_9783960103516.xhtml#abb7-14) dargestellt. Dieses Modell eignet sich gut für die Bildsegmentierung.
