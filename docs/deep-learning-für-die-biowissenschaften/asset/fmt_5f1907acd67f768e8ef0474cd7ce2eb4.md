
Das Ergebnis ist 0.162, was bedeutet, dass ungefähr 16 % der inaktiven Moleküle geladen sind. Das liegt daran, dass die beiden Datensätze nicht einheitlich erstellt wurden. Wir können das Problem beheben, indem wir die chemischen Strukturen der inaktiven Moleküle so abändern, dass ihre Ladung neutralisiert wird. Das lässt sich leicht mit der `NeutraliseCharges()`\-Funktion aus dem RDKit Cookbook (*[https://www.rdkit.org/docs/Cookbook.html](https://www.rdkit.org/docs/Cookbook.html)*) bewerkstelligen:

```
from neutralize import NeutraliseCharges
```

Wir erstellen nun ein neues DataFrame, das die SMILES-Strings, IDs und Labels der inaktiven Moleküle enthält:

```
revised_decoy_df = decoy_df[["SMILES","ID","label"]].copy()
```

Mithilfe dieses neuen DataFrame können wir die ursprünglichen SMILES-Strings durch die SMILES-Strings der neutralen Formen der Moleküle ersetzen. Die Funktion `NeutraliseCharges` gibt zwei Werte zurück. Der erste enthält den SMILES-String für die neutrale Form des Moleküls, und der zweite ist eine Boole’sche Variable, die angibt, ob das Molekül geändert wurde. Da wir lediglich den SMILES-String benötigen, verwenden wir nur das erste Element des von `NeutraliseCharges` zurückgegebenen Tupels.

```
revised_decoy_df["SMILES"] = [NeutraliseCharges(x)[0] for x in revised_decoy_df["SMILES"]]
```

## Trainieren eines Vorhersagemodells

Nachdem unsere Daten nun formatiert sind, können wir sie verwenden, um ein Graph-Convolution-Modell zu trainieren. Zunächst importieren wir die benötigten Bibliotheken. Zwar wurden einige dieser Bibliotheken bereits im ersten Abschnitt importiert, aber wenn wir mit dem Einlesen der *csv*\-Datei beginnen wollen, benötigen wir alle:

```
import deepchem as dc # DeepChem-Bibliothek
from deepchem.models import GraphConvModel # Graph Convolution
import numpy as np # NumPy für numerische Operationen
import sys # Fehlerbehandlung
import pandas as pd # Handhabung von Daten
import seaborn as sns # Seaborn-Bibliothek zur grafischen Darstellung
from rdkit.Chem import PandasTools # chemische Strukturen in Pandas
```

Im nächsten Schritt definieren wir eine Funktion zum Erstellen eines `GraphConvModel`. Für unser Beispiel benötigen wir ein Modell zur Klassifizierung. Da wir unser Modell später auf einem anderen Datensatz anwenden wollen, sollten wir ein Verzeichnis erstellen, in dem das Modell abgespeichert wird. Ändern Sie den Pfad (`model_dir`) entsprechend Ihrem Dateisystem ab:

```
def generate_graph_conv_model():
    batch_size = 128
    model = GraphConvModel(1, batch_size=batch_size, mode='classification', model_dir="/tmp/mk01/model_dir")
    return model
```

Wir benötigen nun die *csv*\-Datei, die wir im letzten Abschnitt erstellt haben:

```
dataset_file = "dude_erk2_mk01.CSV"
tasks = ["is_active"]
featurizer = dc.feat.ConvMolFeaturizer()
loader = dc.data.CSVLoader(tasks=tasks, smiles_field="SMILES", featurizer=featurizer)
dataset = loader.featurize(dataset_file, shard_size=8192)
```

Jetzt können wir das Modell bauen. Wir teilen den eingelesenen Datensatz in jeweils einen Trainings- und einen Validierungsdatensatz, um unser Modell bewerten zu können. Wir verwenden hierfür `RandomSplitter` (DeepChem bietet mehrere Möglichkeiten zum Aufsplitten der Daten, wie den `ScaffoldSplitter`, der die Daten anhand des chemischen Aufbaus der Moleküle teilt, und den `ButinaSplitter`, der die Daten zunächst clustert und sie dann so aufteilt, dass Trainings- und Validierungsdatensatz unterschiedliche Cluster enthalten):

```
splitter = dc.splits.RandomSplitter()
```

Durch die Aufteilung des Datensatzes können wir das Modell auf dem Trainingsdatensatz trainieren und anschließend auf dem Validierungsdatensatz prüfen. Um unser Modell bewerten zu können, benötigen wir geeignete Metriken. In unserem Beispiel sind die Daten unbalanciert: Es gibt eine kleine Anzahl aktiver und eine große Anzahl inaktiver Moleküle. Deshalb benötigen wir eine Metrik, die mit unbalancierten Daten umgehen kann. Eine solche Metrik ist der Matthews-Korrelationskoeffizient (MCC):

```
metrics = [
    dc.metrics.Metric(dc.metrics.matthews_corrcoef, np.mean, mode="classification")
]
```

Um die Leistung unseres Modells zu bewerten, führen wir eine zehnfache Kreuzvalidierung durch, bei der wir ein Modell auf den Trainingsdaten trainieren und anschließend auf den Validierungsdaten validieren:

```
training_score_list = []
validation_score_list = []
transformers = []
cv_folds = 10

for i in range(0, cv_folds):
    model = generate_graph_conv_model()
    res = splitter.train_valid_test_split(dataset)
    train_dataset, valid_dataset, test_dataset = res
    model.fit(train_dataset)
    train_scores = model.evaluate(train_dataset, metrics, transformers)
    training_score_list.append(train_scores["mean-matthews_corrcoef"])
    validation_scores = model.evaluate(valid_dataset, metrics, transformers)
    validation_score_list.append(validation_scores["mean-matthews_corrcoef"])

print(training_score_list)
print(validation_score_list)
```

Um die Performance zu visualisieren, verwenden wir Boxplots (siehe [Abbildung 11-5](#Chapter11_9783960103516.xhtml#abb11-5)):

```
sns.boxplot(
    ["training"] * cv_folds + ["validation"] * cv_folds,
    training_score_list + validation_score_list
)
```
