
In diesem Kapitel führen wir Sie durch ein praktisches Beispiel eines virtuellen Screening-Workflows für ein LBVS. Wir werden den Code besprechen, der zum Ausführen benötigt wird, sowie den Denkprozess hinter den Entscheidungen, die während der Analyse getroffen werden. Wir werden Moleküle verwenden, von denen bekannt ist, dass sie an ein bestimmtes Protein binden, sowie Moleküle, von denen angenommen wird, dass sie nicht binden, um ein Convolutional Neural Network zu trainieren, das neue Moleküle, die an das Protein binden können, identifizieren soll.

### Vorbereiten des Datensatzes

Als Erstes erstellen wir ein Graph-Convolution-Modell, um vorherzusagen, ob ein Molekül das Protein ERK2 hemmt. Dieses Protein, auch bekannt als Mitogen-aktivierte Proteinkinase 1 oder MAPK1, spielt eine wichtige Rolle bei den Signalwegen, die das Zellwachstum regulieren. ERK2 ist an der Entstehung mehrerer Krebsarten beteiligt, und in klinischen Studien werden derzeit ERK2-Inhibitoren als mögliche Therapien bei nicht kleinzelligem Lungenkrebs und bei Hautmelanomen getestet.

Unser Modell soll in der Lage sein, ERK2-Wirkstoffe von solchen ohne Wirkstoff zu unterscheiden. Die aktiven (active) und inaktiven (decoy) Moleküle stammen aus der DUD-E-Datenbank (*[http://dud.docking.org/](http://dud.docking.org/)*), mit der Vorhersagemodelle getestet werden können. In der Praxis würden wir die aktiven und inaktiven Moleküle aus der wissenschaftlichen Literatur oder einer Datenbank wie der ChEMBL-Datenbank (*[https://www.ebi.ac.uk/chembl/](https://www.ebi.ac.uk/chembl/)*) des *European Bioinformatics Institute* (EBI) beziehen. Um das beste Modell zu erhalten, möchten wir inaktive Moleküle mit ähnlichen Eigenschaften wie die aktiven Moleküle haben. Angenommen, die inaktiven Moleküle hätten ein niedrigeres Gewicht als die aktiven, dann würde unser Modell vermutlich nur lernen, Moleküle mit niedrigem Gewicht von Molekülen mit hohem Gewicht zu unterscheiden. Ein solches Modell hätte in der Praxis nur einen sehr begrenzten Nutzen.

Damit wir die Daten besser verstehen, betrachten wir einige berechnete Eigenschaften unserer aktiven und inaktiven Moleküle. Um ein zuverlässiges Modell erstellen zu können, müssen wir sicherstellen, dass die Eigenschaften der beiden Molekülgruppen ähnlich sind.

Zuerst importieren wir die benötigten Libraries:

```
from rdkit import Chem # RDKit-Bibliothek mit chemischen Funktionen
from rdkit.Chem import Draw # Zeichnen chemischer Strukturen
import pandas as pd # Handhaben von Daten
from rdkit.Chem import PandasTools # Bearbeiten chemischer Daten
from rdkit.Chem import Descriptors # Berechnen molekularer Deskriptoren
from rdkit.Chem import rdmolops # weitere molekulare Eigenschaften
import seaborn as sns # Erstellen von Graphen
```

In unserem Beispiel werden Moleküle als SMILES-Strings dargestellt. Weitere Informationen zu SMILES finden Sie in [Kapitel 4](#Chapter04_9783960103516.xhtml#ch4). Wir lesen eine SMILES-Datei in ein Pandas-DataFrame und fügen dem DataFrame ein RDKit-Molekül hinzu. Obwohl die SMILES-Datei technisch gesehen keine *csv*-Datei ist, kann sie von der Pandas-Funktion `read_CSV()` gelesen werden, solange der Delimiter angegeben wird, der in diesem Fall ein Leerzeichen ist:

```
active_df = pd.read_CSV("mk01/actives_final.ism",header=None,sep=" ")
active_rows,active_cols = active_df.shape
active_df.columns = ["SMILES","ID","ChEMBL_ID"]
active_df["label"] = ["Active"]*active_rows
PandasTools.AddMoleculeColumnToFrame(active_df,"SMILES","Mol")
```

Als Nächstes definieren wir eine Funktion, um die berechneten Eigenschaften einem DataFrame hinzuzufügen:

```
def add_property_columns_to_df(df_in):
    df_in["mw"] = [Descriptors.MolWt(mol) for mol in df_in.Mol]
    df_in["logP"] = [Descriptors.MolLogP(mol) for mol in df_in.Mol]
    df_in["charge"] = [rdmolops.GetFormalCharge(mol) for mol in df_in.Mol]
```

Mithilfe dieser Funktion können wir das Molekulargewicht, LogP und die Formalladung der Moleküle berechnen. Diese Eigenschaften bestimmen die Größe eines Moleküls, seine Fähigkeit, sich in Wasser von einer öligen Substanz (Octanol) zu trennen, und ob das Molekül positiv oder negativ geladen ist. Liegen uns die Ergebnisse der Berechnungen vor, können wir die Verteilungen der Eigenschaften für aktive und inaktive Moleküle miteinander vergleichen:

```
add_property_columns_to_df(active_df)
```

Wir betrachten die ersten Zeilen im DataFrame, um sicherzustellen, dass der Inhalt mit dem der Eingabedatei übereinstimmt (siehe [Tabelle 11-1](#Chapter11_9783960103516.xhtml#ch11tab1)):

Das Gleiche führen wir auch für die inaktiven Moleküle durch:

```
decoy_df = pd.read_CSV("mk01/decoys_final.ism",header=None,sep=" ")
decoy_df.columns = ["SMILES","ID"]
decoy_rows, decoy_cols = decoy_df.shape
decoy_df["label"] = ["Decoy"]*decoy_rows
PandasTools.AddMoleculeColumnToFrame(decoy_df,"SMILES","Mol")
add_property_columns_to_df(decoy_df)
```

Um das Modell zu erstellen, benötigen wir ein DataFrame, das die aktiven und inaktiven Moleküle enthält. Wir verwenden die Pandas-Funktion `append`, um die beiden DataFrames zu kombinieren, und erstellen ein neues DataFrame namens `tmp_df`:

```
tmp_df = active_df.append(decoy_df)
```

Um die Eigenschaften der aktiven und inaktiven Moleküle zu vergleichen, verwenden wir den Violinenplot. Ein Violinenplot ist eine Variante des Boxplots. Der Violinenplot zeigt eine gespiegelte, horizontale Ansicht einer Häufigkeitsverteilung. Im Idealfall sehen wir ähnliche Verteilungen für die aktiven und inaktiven Moleküle. Die Ergebnisse sind in [Abbildung 11-1](#Chapter11_9783960103516.xhtml#abb11-1) dargestellt:

```
sns.violinplot(tmp_df["label"],tmp_df["mw"])
```

Hier sehen wir einen deutlichen Unterschied. Alle aktiven Moleküle sind neutral und haben jeweils die Ladung 0, während einige der inaktiven Moleküle Ladungen von +1 oder –1 haben. Als Nächstes prüfen wir, welcher Anteil der inaktiven Moleküle geladen ist. Hierfür erstellen wir ein neues DataFrame, das nur die geladenen Moleküle enthält:

```
charged = decoy_df[decoy_df["charge"] != 0]
```

Mit `shape` können wir uns die Anzahl der Zeilen und Spalten eines DataFrame anzeigen lassen. Somit erhalten wir mit `shape[0]` die Anzahl der Zeilen. Wir teilen die Anzahl der Zeilen des DataFrame, das die geladenen Moleküle enthält, durch die Zeilenanzahl des DataFrame, das alle inaktiven Moleküle enthält:

```
charged.shape[0]/decoy_df.shape[0]
```
