# Merkmale entwickeln im PDBBind-Datensatz

Zunächst erstellen wir ein `RdkitGridFeaturizer`-Objekt, das wir inspizieren können:

```python
import deepchem as dc

grid_featurizer = dc.feat.RdkitGridFeaturizer(
    voxel_width=2.0,
    feature_types=['hbond', 'salt_bridge', 'pi_stack',
                   'cation_pi', 'ecfp', 'splif'],
    sanitize=True, flatten=True)
```

Es werden mehrere Optionen verwendet, die wir uns kurz genauer anschauen. Die Option `sanitize=True` fordert den Featurizer auf, zu versuchen, alle Strukturen zu bereinigen. Wie Sie sich erinnern, erwähnten wir bereits, dass Strukturen häufig fehlerhaft sind. Dieser Reinigungsschritt versucht, alle offensichtlichen Fehler zu beheben, die er erkennt. Die Option `flatten=True` fordert den Featurizer auf, einen eindimensionalen Merkmalsvektor für jede Eingabestruktur auszugeben.

Mit der Option `feature_types` werden die Arten der biophysikalischen und chemischen Merkmale festgelegt, die `RdkitGridFeaturizer` in den Eingabestrukturen zu erkennen versucht. Beachten Sie, dass viele chemische Bindungen vorliegen, die wir weiter oben in diesem Kapitel besprochen haben: Wasserstoffbrücken, Ionenbrücken usw. Zu guter Letzt setzt die Option `voxel_width=2.0` die Größe der Voxel, aus denen sich das Gitter zusammensetzt, auf 2 Angström. Der `RdkitGridFeaturizer` wandelt ein Protein in eine voxelisierte Darstellung um, um nützliche Merkmale zu extrahieren. Für jeden räumlichen Gitterpunkt werden biophysikalische Merkmale gezählt, und ein lokaler Fingerabdruckvektor wird berechnet. Der `RdkitGridFeaturizer` berechnet zwei verschiedene Fingerabdrücke, den `ECFP` und den `SPLIF`.

## Voxelisierung

Was ist Voxelisierung? Allgemein gesagt, ist ein Voxel die 3-D-Entsprechung eines Pixels (siehe Abbildung 5-11). So wie pixelbasierte Darstellungen von Bildern für die Handhabung von Bilddaten sehr nützlich sein können, können voxelbasierte Darstellungen für das Arbeiten mit 3-D-Daten von entscheidender Bedeutung sein.

![Abbildung 5-11: Voxelisierte Darstellung einer Kugel. Jedes Voxel stellt einen räumlichen Eingabewürfel dar.](Images/p79-1.png)

Jetzt können wir den PDBBind-Datensatz laden. Hierfür benötigen wir den soeben definierten Featurizer nicht wirklich, `MoleculeNet` wird sich für uns darum kümmern. Wenn wir die Option `featurizer="grid"` beim Laden des Datensatzes verwenden, führt es automatisch eine Grid Featurization durch:

```python
tasks, datasets, transformers = dc.molnet.load_pdbbind(
    featurizer="grid", split="random", subset="core")

train_dataset, valid_dataset, test_dataset = datasets
```

Mit oben stehendem Code haben wir die »Core«-Teilgruppe von PDBBind geladen und Merkmale erstellt. Auf einem schnellen Rechner sollte der Code innerhalb von zehn Minuten ausgeführt sein. Das Featurizing der »Refined«-Teilgruppe dauert auf einem modernen Server mehrere Stunden.

Da uns die Daten nun vorliegen, können wir mit dem Erstellen einiger Machine-Learning-Modelle beginnen. Zuerst trainieren wir ein klassisches Modell namens *Random Forest*:

```python
from sklearn.ensemble import RandomForestRegressor

sklearn_model = RandomForestRegressor(n_estimators=100)
model = dc.models.SklearnModel(sklearn_model)
model.fit(train_dataset)
```

Alternativ werden wir auch versuchen, ein neuronales Netzwerk zu erstellen, um die Protein-Ligand-Bindung vorherzusagen. Wir können die Klasse `dc.models.MultitaskRegressor` nutzen, um ein MLP mit zwei verborgenen Ebenen zu erstellen. Die Breite der Hidden-Layer setzen wir auf 2.000 bzw. 1.000 und verwenden 50 % Drop-out, um ein Overfitting zu reduzieren:

```python
n_features = train_dataset.X.shape[1]

model = dc.models.MultitaskRegressor(
    n_tasks=len(pdbbind_tasks),
    n_features=n_features,
    layer_sizes=[2000, 1000],
    dropouts=0.5,
    learning_rate=0.0003)

model.fit(train_dataset, nb_epoch=250)
```

## Baseline-Modelle

Deep-Learning-Modelle sind manchmal schwierig zu optimieren. Selbst erfahrenen Anwendern unterlaufen Fehler beim Einstellen eines solchen Modells. Aus diesem Grund ist es wichtig, ein stabileres Baseline-Modell zu erstellen, auch wenn es eventuell eine geringere Performance aufweist.

Random Forests sind eine gute Wahl als Baseline. Sie bieten häufig eine starke Leistung bei Lernaufgaben mit relativ geringen Abstimmungswerten. Ein Random-Forest-Klassifizierer erstellt viele »Entscheidungsbaum«-Klassifizierer, wobei jeder nur eine zufällige Teilmenge der verfügbaren Merkmale verwendet und die einzelnen Entscheidungen dieser Klassifizierer dann über eine Mehrheitsabstimmung kombiniert.

`Scikit-learn` ist ein unentbehrliches Paket für das Erstellen einfacher Machine-Learning-Baselines. In diesem Kapitel erstellen wir mit `scikit-learn` ein Baseline-Modell und kennzeichnen Komplexe mit dem `RdkitGridFeaturizer` als Eingaben für Random Forests.

Jetzt, da wir ein trainiertes Modell haben, können wir seine Genauigkeit prüfen. Um die Genauigkeit des Modells beurteilen zu können, müssen wir zunächst eine geeignete Metrik definieren. Wir wählen den Pearson R²-Score. Hierbei handelt es sich um eine Zahl zwischen –1 und 1, wobei 0 keine Korrelation zwischen dem wahren und dem vorhergesagten Label angibt und 1 eine perfekte Korrelation anzeigt:

```python
metric = dc.metrics.Metric(dc.metrics.pearson_r2_score)
```

Nun können wir die Genauigkeit der Modelle in den Trainings- und Testdatensätzen gemäß dieser Metrik bewerten. Der Code ist für beide Modelle identisch:

```python
print("Evaluating model")
train_scores = model.evaluate(train_dataset, [metric], transformers)
test_scores = model.evaluate(test_dataset, [metric], transformers)

print("Train scores")
print(train_scores)
print("Test scores")
print(test_scores)
```
