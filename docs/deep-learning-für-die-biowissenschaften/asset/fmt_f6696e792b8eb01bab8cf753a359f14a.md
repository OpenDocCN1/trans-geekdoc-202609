
# Diabetische Retinopathie

Bei der diabetischen Retinopathie handelt es sich um eine Erkrankung, bei der die Gesundheit der Augen durch Diabetes geschädigt wird. Insbesondere in den Entwicklungsländern ist das eine der Hauptursachen für Blindheit. Der `Fundus` (Augenhintergrund) ist der innere Bereich des Auges, der der Linse gegenüberliegt. Zur Diagnose einer diabetischen Retinopathie betrachtet der Arzt eine Aufnahme des Augenhintergrunds des Patienten und beschriftet diese manuell. Viel Arbeit wurde in »Netzhautaufnahmen« gesteckt, bei der Methoden zur Erfassung von `Fundus`-Bildern entwickelt wurden (siehe [Abbildung 8-6](#Chapter08_9783960103516.xhtml#abb8-6)).

Bei der diabetischen Retinopathie besteht die Herausforderung darin, einen Algorithmus zu entwerfen, mit dem der Krankheitsverlauf eines Patienten anhand einer `Fundus`-Aufnahme bestimmt werden kann. Derzeit werden solche Vorhersagen von qualifizierten Ärzten oder technischem Personal getroffen. Wäre ein Machine-Learning-System in der Lage, den Krankheitsverlauf eines Patienten anhand der `Fundus`-Bilder genau vorherzusagen? Für den Patienten würde das eine kostengünstige Methode bieten, ihr Risiko zu verstehen, die sie nutzen könnten, bevor sie sich an einen teureren Facharzt wenden.

Des Weiteren enthalten `Fundus`-Aufnahmen im Gegensatz zu EHR-Daten nur wenige vertrauliche Informationen des Patienten, sodass große Datensätze mit `Fundus`-Bildern einfacher gewonnen werden können. Aus diesen Gründen wurde eine Reihe von Machine-Learning-Studien und -Wettbewerben mit Datensätzen zur diabetischen Retinopathie durchgeführt. Kaggle rief einen Wettbewerb (*[https://www.kaggle.com/c/diabetic-retinopathy-detection](https://www.kaggle.com/c/diabetic-retinopathy-detection)*) aus, der darauf abzielte, gute Modelle für die Retinopathie bei Diabetikern zu erstellen, und stellte einen Datensatz mit hochauflösenden `Fundus`-Bildern zusammen. Im verbleibenden Abschnitt lernen Sie, wie Sie mit DeepChem einen Klassifikator für die diabetische Retinopathie im *Diabetic Retinopathy*-(DR-)Datensatz von Kaggle erstellen.

> **Wo befindet sich der DR-Datensatz von Kaggle?**
> Die Bedingungen der Kaggle-Challenge verbieten es uns, die Daten auf den DeepChem-Servern bereitzustellen. Aus diesem Grund müssen Sie die Daten direkt von der Kaggle-Webseite herunterladen. Wenn Sie sich bei Kaggle registrieren, können Sie anschließend den Datensatz über deren API herunterladen. Der komplette Datensatz ist ziemlich groß (80 GByte). Sollte Ihre Internetverbindung den vollständigen Download nicht zulassen, können Sie auch nur einen Teil der Daten herunterladen.
>
> Weitere Informationen zum Download des Datensatzes finden Sie in dem mit diesem Buch verknüpften GitHub-Repository (*[https://github.com/deepchem/DeepLearningLifeSciences](https://github.com/deepchem/DeepLearningLifeSciences)*). Die Funktionen zum Laden der Bilder erfordern, dass die Trainingsdaten in einer bestimmten Verzeichnisstruktur aufgebaut sind. Details zu diesem Verzeichnisformat finden Sie ebenfalls im GitHub-Repository.

Der erste Schritt besteht darin, die Rohdaten vorzuverarbeiten und zu laden. Wir beschneiden jedes Bild und behalten nur das mittlere Quadrat, das die Netzhaut enthält. Anschließend ändern wir die Größe dieses mittleren Quadrats auf 512 × 512.

> **Umgang mit hochauflösenden Bildern**
> Viele Bilddatensätze in der Medizin und der Wissenschaft enthalten sehr hochauflösende Bilder. Auch wenn es verlockend ist, die Deep-Learning-Modelle direkt auf diesen hochauflösenden Bildern zu trainieren, ist das in der Regel eine rechenintensive Aufgabe. Ein Problem liegt darin, dass die meisten modernen GPUs nur über begrenzten Arbeitsspeicher verfügen. Das bedeutet, dass das Trainieren von Modellen mit sehr hoher Auflösung mit Standardhardware kaum möglich ist. Darüber hinaus erwarten die meisten Bildverarbeitungssysteme (vorerst), dass ihre Eingaben eine bestimmte Form haben. Aus diesem Grund müssen die hochaufgelösten Bilder zugeschnitten werden.
>
> Glücklicherweise beeinträchtigt das Zuschneiden und Ändern der Größe von Bildern kaum die Leistung der Machine-Learning-Modelle. Es ist ebenfalls üblich, aus jedem Quellbild automatisch eine Reihe von verfremdeten Bildern zu generieren. Für diese Fallstudie haben wir einige Standard-Augmentationen an den Bildern durchgeführt. Wir empfehlen Ihnen, sich mit dem Augmentationscode vertraut zu machen, da er sich als nützlich für Ihre eigenen Projekte erweisen kann.

Die Kerndaten sind in einer Reihe von Verzeichnissen auf der Festplatte abgelegt. Wir verwenden DeepChems `ImageLoader`-Klasse, um diese Bilder von der Festplatte zu laden. Bei Interesse können Sie sich den Lade- und Vorverarbeitungscode im Detail ansehen. Wir haben ihn in eine praktische Hilfsfunktion verpackt. Diese Funktion erstellt auch direkt je einen Trainings-, einen Validierungs- und einen Testdatensatz:

```
train, valid, test = load_images_DR(split='random', seed=123)
```

Nun, da wir die Daten haben, erstellen wir ein Convolutional Neural Network, um mit diesen Daten zu lernen. Der Aufbau ähnelt anderen Architekturen, die Sie in diesem Buch bereits gesehen haben. Daher wird er hier nicht erneut ausgeführt. Hier der Aufruf des Objekt-Wrappers für das zugrunde liegende CNN:

```
# Definieren und Erstellen des Modells

model = DRModel(
    n_init_kernel=32,
    batch_size=32,
    learning_rate=1e-5,
    augment=True,
    model_dir='./test_model'
)
```

Dieser Code definiert ein Convolutional Neural Network für diabetische Retinopathie in DeepChem. Wie wir später noch sehen werden, erfordert das Training dieses Modells große Rechenleistung. Für einen ersten Überblick empfehlen wir Ihnen deshalb, unser vortrainiertes Modell von der DeepChem-Webseite herunterzuladen. Wir haben dieses Modell bereits auf dem vollständigen Kaggle-DR-Datensatz trainiert und die Gewichte abgespeichert. Folgende Befehle können Sie zum Herunterladen und Speichern des Modells verwenden (beachten Sie, dass der erste Befehl in einer einzelnen Zeile und ohne Leerzeichen vor dem »/« eingegeben werden sollte):

```
wget https://s3-us-west-1.amazonaws.com/deepchem.io/featurized_datasets/DR_model.tar.gz
mv DR_model.tar.gz test_model/
cd test_model
tar -zxvf DR_model.tar.gz
cd ..
```

Anschließend können Sie die trainierten Gewichte des Modells wie folgt wiederherstellen:

```
model.build()
model.restore(checkpoint="./test_model/model-84384")
```

Wir stellen einen bestimmten vorab trainierten »Kontrollpunkt« dieses Modells wieder her. Weitere Informationen zum Wiederherstellungsprozess und zu den dafür verwendeten Skripten finden Sie in dem mit diesem Buch verknüpften Code-Repository. Auf dem vortrainierten Modell können wir einige einfache Statistiken berechnen:

```
metrics = [
    dc.metrics.Metric(DRAccuracy, mode='classification'),
    dc.metrics.Metric(QuadWeightedKappa, mode='classification')
]
```

Es gibt eine Reihe von Metriken, die zur Bewertung von Modellen für die diabetische Retinopathie nützlich sind. Hier verwenden wir `DRAccuracy`, bei der es sich um die Modellgenauigkeit handelt (Prozentsatz der korrekten Labels), und Cohens Kappa, mit der die Übereinstimmung zwischen zwei Klassifizierern gemessen wird. Dies ist sinnvoll, da es sich bei der Lernaufgabe der diabetischen Retinopathie um ein mehrschichtiges Lernproblem handelt.

Mit unseren Metriken bewerten wir nun das vortrainierte Modell auf dem Testdatensatz:

```
model.evaluate(test, metrics)
```
