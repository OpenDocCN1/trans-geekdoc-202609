### Vorbereiten eines Datensatzes für die Vorhersage

Nachdem wir unser Vorhersagemodell erstellt haben, können wir es auf neue Daten anwenden. Vielfach wird ein Vorhersagemodell aufgrund von Literaturrecherchen erstellt, und dieses Modell wird dann auf Moleküle angewendet, die man screenen möchte. Die zu screenenden Moleküle könnten aus einer internen Datenbank stammen oder aus einem im Handel erhältlichen Datensatz. Als Beispiel verwenden wir unser erstelltes Vorhersagemodell, um eine kleine Stichprobe von 100.000 Molekülen aus der ZINC-Datenbank, einer Sammlung von mehr als einer Milliarde im Handel erhältlichen Molekülen, zu screenen.

Ein mögliches Problem bei der Durchführung eines virtuellen Screenings sind Moleküle, die störend auf biologische Assays wirken. In den letzten 25 Jahren haben viele Forschergruppen Regeln entwickelt, um potenziell problematische Moleküle zu identifizieren. Mehrere dieser Regeln, die als SMILES-Strings codiert sind, wurden von der Gruppe gesammelt, die auch die ChEMBL-Datenbank pflegt. Diese Regeln wurden durch das Python-Skript `rd_filters.py` zur Verfügung gestellt. Wir verwenden `rd_filters.py`, um potenziell problematische Moleküle in unserer Stichprobe von 100.000 Molekülen aus der ZINC-Datenbank zu identifizieren.

Das Skript `rd_filters.py` und zugehörige Dateien stehen in unserem GitHub-Repository ([https://github.com/deepchem/DeepLearningLifeSciences](https://github.com/deepchem/DeepLearningLifeSciences)) zur Verfügung.

Die verfügbaren Optionen und Argumente für das Skript erhalten Sie nach Aufruf von `-h`.

```
rd_filters.py -h
```

```

rd_filters.py $ filter --in INPUT_FILE --prefix PREFIX [--rules RULES_FILE_NAME]
[--alerts ALERT_FILE_NAME][--np NUM_CORES]
rd_filters.py $ template --out TEMPLATE_FILE [--rules RULES_FILE_NAME]

Options:
--in INPUT_FILE input file name
--prefix PREFIX prefix for output file names
--rules RULES_FILE_NAME name of the rules JSON file

--np NUM_CORES the number of cpu cores to use (default is all)
--out TEMPLATE_FILE parameter template file name
```

Um das Skript auf unsere Eingabedatei namens `zinc_100k.smi` anzuwenden, geben Sie den Dateinamen und ein Präfix für die Ausgabedateien an. `filter` ruft das Skript im Filtermodus auf und identifiziert potenziell problematische Moleküle. `--prefix` gibt an, dass der Name der Ausgabedatei mit dem Präfix `zinc` beginnt.

```
rd_filters.py filter --in zinc_100k.smi --prefix zinc
```
