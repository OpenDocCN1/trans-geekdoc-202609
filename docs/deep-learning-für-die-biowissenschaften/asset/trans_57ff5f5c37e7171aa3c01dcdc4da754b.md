

### 深度放射学

放射学是利用医学扫描诊断疾病的科学。医生使用各种不同的扫描，例如 MRI 扫描、超声波、X 光片和 CT 扫描。对于每种程序，挑战在于根据生成的扫描诊断患者的状况。这一挑战似乎非常适合卷积模型。正如我们在前几章所见，深度学习方法可以从图像数据中学习复杂函数。现代放射学的很大一部分（至少是机械性组成部分）在于对复杂医学图像进行分类和处理。扫描在医学中已使用很长时间（有关早期 X 光片的示例，请参见[图 8-4](#Chapter08_9783960103516.xhtml#abb8-4)）。

在本节中，我们将介绍几种扫描类型以及定性相似的深度学习应用。所有应用都始于一个足够大的扫描数据集，用于训练卷积神经网络（参见[图 8-3](#Chapter08_9783960103516.xhtml#abb8-3)）。该模型通常是普通的 VGG 或 ResNet 模型，有时但会对基本结构进行一些更改。根据朴素统计，训练好的模型通常显示出针对相应任务的强大性能。

![image](Images/p134-01.png)

*图 8-3：此图展示了一些常见的卷积模型（VGG-19、ResNet-34，数字表示应用的卷积层数）。这些架构是用于医学图像任务的常用模型。*

这些结果可能导致了过高的期望。一些高层 AI 科学家，首当其冲的是 Geoff Hinton，曾指出放射学领域的深度学习将发展到这样一个地步：很快培养新放射科医生将不再值得。^([7](#Footnote_9783960103516.xhtml#ch8fn7)) 真是这样吗？最近，一系列深度学习系统实现了类人表现。然而，这些结果应持保留态度，且不应忘记这些系统通常很敏感。

我们认为，一对一取代医生的风险仍然很低，但存在系统性取代的风险。这是什么意思？新创公司正在研究新的商业模式，其中深度学习系统执行大部分扫描分析，仅涉及少数医生。

#### X 光片和 CT 扫描

X 光检查——严格来说是 X 线摄影——利用 X 射线查看体内内部结构（参见[图 8-4](#Chapter08_9783960103516.xhtml#abb8-4)）。计算机断层扫描（CT）是 X 光片的一种变体，其中 X 射线源和探测器围绕待成像物体旋转，从而实现 3-D 成像。

![image](Images/p136-01.png)

*图 8-4：第一张医学 X 光片。Wilhelm Röntgen 为其妻子 Anna Bertha Ludwig 的手拍摄了这张照片。自这张首张照片以来，X 线科学已取得长足进步，借助深度学习，它可以走得更远！*

一个普遍的误解是 X 光片只能成像骨骼等“硬”物体。这是不正确的。CT 扫描常规用于大脑等组织的成像（参见[图 8-5](#Chapter08_9783960103516.xhtml#abb8-5)），X 光扫描仪常用于机场安检对旅客进行透视。乳腺 X 线摄影也使用低能 X 射线扫描乳腺组织。

![image](Images/p136-02.png)

*图 8-5：从下至上的一个人脑 CT 扫描。请注意 CT 如何能很好地呈现 3-D 信息。（来源：Wikimedia，[https://commons.wikimedia.org/wiki/File:Computed\_tomography\_of\_human\_brain\_-\_large.png](https://commons.wikimedia.org/wiki/File:Computed_tomography_of_human_brain_-_large.png))*

值得注意的是，所有 X 光扫描均已知与癌症有关。因此，共同目标是通过限制所需扫描数量，将患者的辐射暴露降至最低。这尤其影响 CT 检查，患者必须长时间暴露于辐射下以收集足够数据。开发了多种信号处理算法以减少所需扫描数量。一些近期论文利用深度学习进一步最小化 CT 所需的扫描数量。

目前，深度学习在该领域主要仍用于扫描分类。例如，卷积神经网络已被用于根据大脑 CT 扫描对阿尔茨海默病的进展进行分类。^([8](#Footnote_9783960103516.xhtml#ch8fn8)) 其他论文称能通过胸部 X 光片以近乎医生的准确度诊断肺炎。^([9](#Footnote_9783960103516.xhtml#ch8fn9)) 同样，深度学习也被用于实现乳腺 X 光片分类的高准确度。^([10](#Footnote_9783960103516.xhtml#ch8fn10))

| ![image](Images/insert.jpg) | | **达到人类准确度很难！** 当论文声称所提出的系统达到近乎人类的准确度时，这意味着什么？通常，作者选择一个指标（如 ROC AUC），一组无关医生致力于用标注标记选定的测试数据集。然后将模型在该测试数据集上的准确度与“平均”医生的准确度进行比较（通常为医生评分的平均值或中位数）。 |
| --- | --- | --- |
| | | 这是一个相当复杂的过程，很多地方可能出错。首先，所选指标可能起作用。因此，好的分析会考虑不同指标，以确保结论经得起潜在变异的考验。 |
