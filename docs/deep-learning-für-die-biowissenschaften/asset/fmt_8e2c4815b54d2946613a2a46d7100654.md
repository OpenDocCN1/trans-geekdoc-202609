Das DataFrame hat sechs Spalten:

- **SMILES**: SMILES-String für jedes Molekül.
- **NAME**: Der NAME des Moleküls, wie er in der Eingabedatei aufgeführt ist.
- **FILTER**: Der Grund, aus dem das Molekül abgelehnt wurde, oder OK, wenn das Molekül den Filter passiert hat.
- **MW**: Das Molekulargewicht des Moleküls. Standardmäßig werden Moleküle mit einem Gewicht von mehr als 500 verworfen.
- **LogP**: Der berechnete Octanol/Wasser-Verteilungskoeffizient des Moleküls. Standardmäßig werden Moleküle mit einem LogP von mehr als fünf aussortiert.
- **HBD**: Die Anzahl der Spender von Wasserstoffbindungen. Standardmäßig werden Moleküle mit mehr als fünf Spendern verworfen.

Mithilfe der Klasse `Counter` aus der Python `collections`-Bibliothek können wir ermitteln, welche Filter für das Entfernen der meisten Moleküle verantwortlich waren (siehe [Tabelle 11-5](#Chapter11_9783960103516.xhtml#ch11tab5)):

```python
from collections import Counter

count_list = list(Counter(df.FILTER).items())
count_df = pd.DataFrame(count_list, columns=["Rule", "Count"])
count_df.sort_values("Count", inplace=True, ascending=False)
count_df.head()
```

Die erste Zeile in der Tabelle mit der Bezeichnung OK gibt die Anzahl der Moleküle an, die alle Filter passiert haben. Dies trifft auf 69.156 der Moleküle unserer Eingabe zu. Die meisten Moleküle (19.330) wurden aussortiert, weil sie eine 1,2-Diketongruppe enthielten. Derartige Moleküle können mit Proteinresten wie Serin und Cystein reagieren und kovalente Bindungen eingehen. Das SMARTS-Muster zur Identifizierung dieser Moleküle finden wir, indem wir in der Datei `filter_collection.CSV`, die eine Ausgabe von `rd_filters.py` ist, nach der Zeichenfolge `Filter41_12_dicarbonyl` suchen. Das SMARTS-Muster lautet `*C(=O)C(=O)*` und bedeutet:

- irgendein Atom, das gebunden ist an
- Kohlenstoff-Kohlenstoff-Sauerstoff, das gebunden ist an
- Kohlenstoff-Kohlenstoff-Sauerstoff, das gebunden ist an
- irgendein Atom

Um sicherzustellen, dass alles wie erwartet funktioniert, schauen wir uns die Daten an. Dazu verwenden wir die Option `highlightAtomLists` der RDKit-Funktion `MolsToGridImage()`, um die 1,2-Diketonfunktionalität hervorzuheben (siehe [Abbildung 11-9](#Chapter11_9783960103516.xhtml#abb11-9)):

```python
from rdkit import Chem
from rdkit.Chem import Draw

mol_list = [Chem.MolFromSmiles(x) for x in smiles_list]
dicarbonyl = Chem.MolFromSmarts('*C(=O)C(=O)*')
match_list = [mol.GetSubstructMatch(dicarbonyl) for mol in mol_list]

Draw.MolsToGridImage(mol_list,
                     highlightAtomLists=match_list,
                     molsPerRow=5)
```

Wie wir an der Abbildung erkennen können, weisen die Moleküle tatsächlich Diketongruppen auf. Auf diese Weise könnten wir auch die anderen Filter auswerten. Wir geben uns jedoch mit den Ergebnissen der Filterung zufrieden und wenden uns als Nächstes der Anwendung unseres Modells zu. Wir haben die problematischen Moleküle aus unserem Datensatz entfernt, den wir für das virtuelle Screening nutzen wollen. Die verbliebenen Moleküle, die sich in der Datei `zinc.smi` befinden, werden wir im nächsten Schritt dieser Übung verwenden.

# Ein Vorhersagemodell anwenden

Das von uns erstellte `GraphConvModel` kann nun zum Durchsuchen von Molekülen verwendet werden. Die Anwendung des Modells erfolgt in mehreren Schritten:

1.  Laden des Modells von der Festplatte.
2.  Erstellen eines Featurizers.
3.  Lesen und Entwickeln von Merkmalen der Moleküle, die das Modell durchlaufen sollen.
4.  Untersuchen der Vorhersagescores.
5.  Überprüfen der chemischen Strukturen der am häufigsten vorhergesagten Moleküle.
6.  Clustern der ausgewählten Moleküle.
7.  Übergabe der gewählten Moleküle aus jedem Cluster an eine `csv`-Datei.

Zunächst importieren wir die benötigten Bibliotheken:

```python
import deepchem as dc # DeepChem-Bibliothek
import pandas as pd # Pandas zur Handhabung von Daten
from rdkit.Chem import PandasTools, Draw # Chemie in Pandas
from rdkit import DataStructs # zur Handhabung von Fingerprints
from rdkit.ML.Cluster import Butina # Clustern von Molekülen
from rdkit.Chem import rdMolDescriptors as rdmd # Deskriptoren
import seaborn as sns # grafische Darstellung
```

Dann laden wir das von uns erstellte Modell:

```python
model = dc.models.TensorGraph.load_from_dir("/tmp/mk01/model_dir")
```

Um Vorhersagen aus unserem Modell zu generieren, müssen wir zuerst die Merkmale der Moleküle erzeugen, die wir zum Erstellen der Vorhersagen verwenden möchten. Hierfür instanziieren wir einen DeepChem-`ConvMolFeaturizer`:

```python
featurizer = dc.feat.ConvMolFeaturizer()
```

Um die Merkmale der Moleküle zu entwickeln, müssen wir unsere SMILES-Datei in eine `csv`-Datei umwandeln. Zum Erstellen eines DeepChem-Featurizers benötigen wir eine Spalte für den Aktivitätsstatus. Wir fügen eine solche hinzu und erstellen die `csv`-Datei:

```python
df = pd.read_CSV("zinc.smi", sep=" ", header=None)
df.columns = ["SMILES", "Name"]
rows, cols = df.shape

# Eine Dummy-Spalte hinzufügen, um den Featurizer zufriedenzustellen
df["Val"] = [0] * rows
```


Beachten Sie, dass die Spalte `Val` nur ein Platzhalter ist, um den DeepChem-Featurizer zufriedenzustellen. Da das DataFrame gut aussieht, geben wir es in eine `csv`-Datei aus, die wir als Eingabe für DeepChem nutzen werden. Wir verwenden `index=False`, um zu verhindern, dass Pandas die Zeilennummer als erste Spalte mit ausgibt:

```python
infile_name = "zinc_filtered.CSV"
df.to_CSV(infile_name, index=False)
```

Mit DeepChem können wir diese `csv`-Datei mit einem Loader lesen und die Merkmale der Moleküle erzeugen, die wir vorhersagen möchten:

```python
loader = dc.data.CSVLoader(tasks=['Val'],
                           smiles_field="SMILES",
                           featurizer=featurizer)
dataset = loader.featurize(infile_name, shard_size=8192)
```

Nun können die Moleküle zur Vorhersage verwendet werden:

```python
pred = model.predict(dataset)
```

Der Einfachheit halber erstellen wir ein Pandas-DataFrame für die Vorhersagen:

```python
pred_df = pd.DataFrame([x.flatten() for x in pred],
                       columns=["Neg", "Pos"])
```

Der Verteilungsplot, der in der Seaborn-Bibliothek enthalten ist, gibt einen Überblick über die Verteilung der Scores. Leider gibt es beim virtuellen Screening keine klaren Regeln für den Score, ab dem ein Molekül als aktiv gilt. Die beste Strategie ist häufig, die Verteilung der Scores zu untersuchen und die Moleküle mit den höchsten Scores auszuwählen. Wenn wir [Abbildung 11-10](#Chapter11_9783960103516.xhtml#abb11-10) betrachten, sehen wir, dass nur wenige Moleküle einen Score von mehr als 0.3 haben. Wir verwenden diesen Wert als vorläufigen Cut-off für Moleküle, die wir experimentell genauer untersuchen könnten.

Wir können das DataFrame mit den Scores dem DataFrame mit den SMILES-Strings hinzufügen. Das gibt uns die Möglichkeit, die chemischen Strukturen der Moleküle mit den höchsten Scores zu betrachten:

```python
combo_df = df.join(pred_df, how="outer")
combo_df.sort_values("Pos", inplace=True, ascending=False)
```
