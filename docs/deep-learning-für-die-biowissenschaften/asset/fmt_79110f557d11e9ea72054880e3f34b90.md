
## Codebeispiel: Training eines VAE zur Molekülgenerierung

Als Nächstes schauen wir uns ein Codebeispiel an. Wir werden ein VAE trainieren, um neue Moleküle zu erzeugen. Genauer gesagt, wird es SMILES-Strings ausgeben. Dieses Ausgabeformat hat unterschiedliche Vor- und Nachteile gegenüber anderen Darstellungen, die wir besprochen haben. Einerseits ist die Arbeit mit SMILES-Strings sehr einfach. Jeder ist nur eine Folge von Zeichen aus einem festgelegten Alphabet. Das erlaubt uns, ein sehr einfaches Modell zu verwenden, um sie zu verarbeiten. Andererseits müssen SMILES-Strings einer komplexen Grammatik entsprechen. Lernt das Modell nicht alle Feinheiten der Grammatik, sind die meisten von ihm erzeugten Strings ungültig und entsprechen keinem Molekül.

### Laden der Trainingsdaten

Zunächst benötigen wir eine Sammlung von SMILES-Strings, mit denen das Modell trainiert werden kann. Zum Glück bietet uns MoleculeNet eine große Auswahl. In diesem Beispiel verwenden wir den MUV-Datensatz. Der Trainingsdatensatz enthält 74.469 Moleküle unterschiedlicher Größe und Struktur. Wir werden ihn zunächst laden:

```python
import deepchem as dc

tasks, datasets, transformers = dc.molnet.load_muv()

train_dataset, valid_dataset, test_dataset = datasets

train_smiles = train_dataset.ids
```

### Definition des Vokabulars

Anschließend definieren wir das Vokabular, mit dem unser Modell arbeiten wird. Welche Zeichen (oder »Tokens«) sind in einem SMILES-String erlaubt? Wie lang dürfen die Strings sein? Wir können sie anhand der Trainingsdaten ermitteln, indem wir eine sortierte Liste aller Zeichen erstellen, die in einem Trainingsmolekül vorkommen:

```python
tokens = set()

for s in train_smiles:
    tokens = tokens.union(set(s))

tokens = sorted(list(tokens))

max_length = max(len(s) for s in train_smiles)
```

### Erstellung des Modells

Im nächsten Schritt erstellen wir das Modell. Welchen Aufbau sollen wir für Encoder und Decoder wählen? Das ist ein nach wie vor aktives Forschungsgebiet. Verschiedene Publikationen, in denen unterschiedliche Modelle vorgeschlagen wurden, sind erschienen. In diesem Beispiel nutzen wir DeepChems `AspuruGuzikAutoEncoder`-Klasse, die ein bestimmtes veröffentlichtes Modell implementiert. Als Encoder wird ein Convolutional Neural Network und als Decoder ein Recurrent Network verwendet. Wenn Sie an den Details interessiert sind, können Sie sich die Veröffentlichung ([https://arxiv.org/abs/1610.02415](https://arxiv.org/abs/1610.02415)) durchlesen. Um dem Beispiel folgen zu können, ist das jedoch nicht erforderlich. Beachten Sie auch, dass wir `ExponentialDecay` für die Lernrate verwenden. Die Rate wird anfänglich auf `0.001` eingestellt und nach jeder Epoche um ein kleines Stück (multipliziert mit `0.95`) verringert. Das trägt dazu bei, dass die Optimierung reibungsloser verläuft:

```python
from deepchem.models.tensorgraph.optimizers import Adam, ExponentialDecay
from deepchem.models.tensorgraph.models.seqtoseq import AspuruGuzikAutoEncoder

model = AspuruGuzikAutoEncoder(tokens, max_length, model_dir='vae')

batches_per_epoch = len(train_smiles) / model.batch_size

learning_rate = ExponentialDecay(0.001, 0.95, batches_per_epoch)

model.set_optimizer(Adam(learning_rate=learning_rate))
```

### Training des Modells

Als Nächstes trainieren wir das Modell. Anstelle der Standardmethode `fit()`, die `Dataset` einsetzt, stellt `AspuruGuzikAutoEncoder` seine eigene `fit_sequences()`-Methode zur Verfügung. Ein Python-Generatorobjekt wird benötigt, das Abfolgen von Tokens erzeugt (in unserem Fall SMILES-Strings). Wir trainieren 50 Epochen lang:

```python
def generate_sequences(epochs):
    for i in range(epochs):
        for s in train_smiles:
            yield (s, s)

model.fit_sequences(generate_sequences(50))
```

### Generierung neuer Moleküle

Nun sollte das Modell in der Lage sein, völlig neue Moleküle zu erzeugen. Wir müssen nur zufällige Latenzvektoren auswählen und sie durch den Decoder leiten. Wir erstellen ein Batch mit einer Größe von 1.000 Vektoren mit einer Länge von 196 (das entspricht der Größe des Latent Space des Modells).

Wie bereits erwähnt, sind nicht alle Ausgaben gültige SMILES-Strings. Tatsächlich ist es nur ein kleiner Teil davon. Glücklicherweise können wir RDKit verwenden, um die ungültigen herauszufiltern:

```python
import numpy as np
from rdkit import Chem

predictions = model.predict_from_embeddings(np.random.normal(size=(1000, 196)))

molecules = []

for p in predictions:
    smiles = ''.join(p)
    if Chem.MolFromSmiles(smiles) is not None:
        molecules.append(smiles)

for m in molecules:
    print(m)
```

Der erste Schritt unserer Analyse besteht darin, die Moleküle zu untersuchen, um festzustellen, ob es welche gibt, die wir verwerfen möchten. Wir können einige der Funktionen in RDKit, das in DeepChem enthalten ist, verwenden, um die Moleküle zu untersuchen, die durch diese Strings dargestellt werden. Um die Strings bewerten zu können, müssen wir sie zuerst in Molekülobjekte konvertieren. Das erreichen wir mit folgender List Comprehension:

```python
molecules = [Chem.MolFromSmiles(x) for x in smiles_list]
```

Ein Faktor, der uns interessieren könnte, ist die Molekülgröße. Es ist unwahrscheinlich, dass Moleküle mit weniger als 10 Atomen eine ausreichende Interaktionsenergie erzeugen, um in einem biologischen Assay ein messbares Signal zu erzeugen. Umgekehrt sind Moleküle mit mehr als 50 Atomen möglicherweise nicht in der Lage, sich in Wasser aufzulösen, und könnten bei biologischen Assays andere Probleme verursachen. Eine grobe Schätzung der Molekülgröße erhalten wir, indem wir die Anzahl der Nichtwasserstoffatome in jedem Molekül berechnen. Der folgende Code erstellt eine Liste der Atomanzahl jedes Moleküls. Der Einfachheit halber sortieren wir das Array so, dass wir die Verteilung besser verstehen können (hätten wir eine längere Liste von Molekülen, würden wir wahrscheinlich ein Histogramm für die Verteilung erstellen):

```python
print(sorted([x.GetNumAtoms() for x in molecules]))
```

Das sind die Ergebnisse:

```
[3, 8, 9, 10, 11, 11, 12, 12, 13, 14, 14, 14, 15,
16, 16, 16, 17, 17, 17, 17, 18, 19, 19, 20, 20, 22, 24, 69, 80]
```

Wie Sie sehen können, gibt es vier sehr kleine und zwei sehr große Moleküle. Wir können eine andere List Comprehension verwenden, um Moleküle mit 10 oder weniger als 50 Atomen zu entfernen:

```python
good_mol_list = [x for x in molecules if x.GetNumAtoms() > 10
and x.GetNumAtoms() < 50]

print(len(good_mol_list))
# 23
```

Diese List Comprehension reduziert unsere bisherige Liste von 29 auf 23 Moleküle.
