
我们可以在[第15章](#ch15.xhtml#chapter15)中描述的访问控制架构之上构建推理控制器。[图18.19](#ch18.xhtml#fig18_19a)展示了这样一个推理控制器。推理引擎本质上是控制访问并通过推理处理未授权访问的策略引擎。社交媒体数据表示为RDF图，而策略和知识可以使用SWRL、RDF和OWL的组合来指定。当用户发起查询（例如使用SPARQL）时，策略引擎会检查知识库（可能包含溯源数据、策略）并修改查询。修改后的查询针对基于RDF的社交媒体数据库执行。前几节中的大部分讨论以及推理控制器的实现均适用于基于RDF的社交媒体数据。

最近，用于表示和推理知识的知识图谱概念变得非常流行。正如[[FENS2020](#ch18.xhtml#ref18_11)]所述：“自Google首创以来，知识图谱已成为一个近期无处不在使用的术语，但尚无公认的明确定义。”知识图谱本质上是从20世纪70年代和80年代的语义网络和概念图演变而来的。它们将语义网络和概念图与语义网和本体方面的最新成果相结合。这些知识图谱捕获知识，并利用内置的各种推理技术对知识进行推理。

就安全性和隐私而言，挑战在于：能否聚合不同的知识图谱并推断出高度机密或私密信息？我们在20世纪90年代初利用语义网络和概念图进行了大量研究并开发了工具来解决这一问题[[THUR1991](#ch18.xhtml#ref18_34)]。也就是说，我们使用这些网络和图来表示知识，随后应用推理技术来确定是否可以推断出敏感信息。当时我们的大部分工作集中在逻辑推理上，例如如果A蕴含B，B蕴含C，且C是敏感的，那么A是否应该敏感？如果知识分类不正确，则旨在通知应用设计师可能存在通过推理导致的潜在安全违规。

虽然20世纪70年代和80年代的表示和推理技术有限，但随着语义网和本体的出现，加上传统的知识表示和推理方案（如语义网络），造就了强大的知识图谱。因此，我们的挑战是表示知识并对其进行推理，以确定是否可能存在安全和隐私违规。更多细节见[[THUR2020](#ch18.xhtml#ref18_37)]。

## 18.11 总结与展望

在本章中，我们首先描述了一个基于语义网溯源图运行的推理控制器的设计，该控制器保护重要的溯源信息免受未授权用户的访问。由于[第19章](#ch19.xhtml#chapter19)和[第20章](#ch20.xhtml#chapter20)中讨论的社交网络也由语义网技术表示，我们开发的技术适用于此类社交媒体数据。关于构建推理控制器以保护数据机密性的早期工作在20世纪80年代末和90年代初有所描述；然而，这些工作主要集中在多级安全数据库领域，且支持的推理能力有限。通过使用语义网技术，我们目前的工作在更复杂的推理和策略表示技术方面较先前的工作有了实质性改进。我们使用RDF作为数据模型，因为它支持具有不同数据模式的多数据库的互操作性。此外，我们用语义网规则和约束来表达策略和规则，并使用语义网软件工具对数据项及其之间的关系进行分类。

接下来，我们讨论了通过查询修改进行推理控制。查询修改也称为查询重写。在这种方法中，推理控制器接受用户查询，并根据策略修改查询，向查询返回清洗后的结果。我们提供了关于关系数据查询修改的背景信息，以及修改SPARQL查询的各个方面。虽然从关系查询转向SPARQL查询是迈向下一代推理控制器处理推理的第一步，但我们的最终目标是使用采用机器学习方法的复杂基于逻辑的推理器来处理查询。这样我们就能处理比本书讨论的更多推理策略。如前所述，随着推理策略变得更加复杂，我们需要牢记查询处理技术的可扩展性。也就是说，虽然数据管理系统应仅发布授权的响应，但用户将要求满足性能需求。因此，开发可扩展的推理控制器是我们的主要目标之一。

在本章中，我们描述了用于数据溯源的推理控制器的实现。推理控制器采用模块化方法构建，因此非常灵活，大多数模块均可由另一个应用模块扩展或替换。例如，应用用户可以替换处理高级策略解析为低级策略对象的策略解析器模块。这种替换将允许应用用户继续使用其业务策略，而独立于我们的溯源推理控制器软件实现。本质上，我们在实现推理控制器时遵循了“即插即用”方法。我们在实现中尽可能多地使用了开源产品。我们为溯源数据推理控制实现的技术可应用于使用语义网技术表示的社交媒体数据。

这种实现是针对下一代推理控制器的首创。我们已从20世纪80年代和90年代的关系数据库方法迁移到基于语义网的方法。语义网技术的推理能力使这种方法更加强大。我们的下一步是将此推理控制器适配为用RDF表示的知识图谱和社交图谱。我们还在研究使用机器学习技术的更强大推理策略。此外，我们需要考虑溯源数据未授权泄露的风险。另外，我们可以将推理策略建模为博弈，其中参与者是推理控制器和系统用户（也可能是对手）。也就是说，双方进行博弈，每方的目标都是获胜。本质上，推理控制器会试图防止任何未授权信息落入对手手中，而对手将试图从系统中提取尽可能多的信息。
