# 6 面向恶意可执行文件的数据科学

DOI: [10.1201/9781003081845-11](https://doi.org/10.1201/9781003081845-11)

## 6.1 简介

恶意代码对计算机和计算机社会构成巨大威胁。各种恶意代码在野外肆虐。其中一些具有移动性，如蠕虫，通过互联网传播，给全球数百万台计算机造成损害。其他类型的恶意代码是静态的，如病毒，但有时比其移动对应物更致命。恶意代码编写者通常利用软件漏洞攻击主机。研究人员设计了许多技术来应对这些攻击。不幸的是，研究人员在检测和预防攻击方面越成功，野外出现的恶意代码就越复杂。因此，恶意代码编写者与研究人员之间的斗争实际上是永无止境的。

防病毒社区检测恶意代码的一种流行技术是“特征检测”。该技术将可执行文件与称为 `signature` 的唯一标志性字符串或字节模式进行匹配，后者用作特定恶意代码的标识符。尽管特征检测技术被广泛使用，但它们对 `zero-day` 攻击（新恶意代码）、`polymorphic` 攻击（同一二进制文件的不同加密）或 `metamorphic` 攻击（实现相同功能的不同代码）无效。因此，迫切需要快速、自动化且高效的检测技术，且这些技术能抵御上述攻击。因此，开发了许多自动化系统 [[GOLB2004](#ch06.xhtml#ref6_5), [KOLT2004](#ch06.xhtml#ref6_8), [NEWM2002](#ch06.xhtml#ref6_15), [NEWS2005](#ch06.xhtml#ref6_16)]。

在本章中，我们描述了我们新颖的 `hybrid feature retrieval` (HFR) 模型，该模型可以高效地检测恶意可执行文件 [[MASU2007a](#ch06.xhtml#ref6_11), [MASU2007b](#ch06.xhtml#ref6_12)]。接下来，我们描述了我们用于检测恶意可执行文件的数据挖掘工具。它利用基于 `n`-gram 分析的特征提取技术。我们首先讨论如何从可执行文件中提取二进制 `n`-gram 特征，然后展示如何使用信息增益选择最佳特征。我们还讨论了与 `n`-gram 提取和选择相关的内存和可扩展性问题，以及我们如何解决它。然后我们描述了如何提取汇编特征和动态链接库 (DLL) 调用特征。最后，我们描述了如何结合这三种特征，并使用这些特征训练分类器。
