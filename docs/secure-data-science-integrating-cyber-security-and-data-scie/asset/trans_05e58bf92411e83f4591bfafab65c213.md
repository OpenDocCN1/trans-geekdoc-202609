# 11 基于相关向量机集成的对抗学习

DOI: [10.1201/9781003081845-19](https://doi.org/10.1201/9781003081845-19)

## 11.1 简介

正如[第10章](#ch10.xhtml#chapter10)所述，许多学习任务（如垃圾邮件过滤和信用卡欺诈检测）面临着试图逃避检测的主动对手。对于涉及主动对手的学习问题，建模对手的攻击策略并开发鲁棒的学习模型以缓解攻击至关重要。对抗学习的大量研究在问题定义中考虑的约束类型上各不相同。无约束对手的假设是不切实际的，因为对数据及其类别成员资格的任意修改可能导致高达 100% 的最坏情况错误率 [[AUER1998](#ch11.xhtml#ref11_1), [KEAR1993](#ch11.xhtml#ref11_11)]。因此，大多数近期研究聚焦于有约束的对手。

在有约束对手的假设下，主要研究成果可进一步划分为博弈论解决方案和非博弈论解决方案。对于实践者而言，困难在于为手头的问题选择最合适的方法。在博弈论框架下开发的解决方案几乎总是假设一个理性博弈。此外，假设每个参与者都拥有关于对手的一定知识量。同样，非博弈论方法通常对对手的知识、损坏数据的分布以及可用计算资源做出假设。在实践中，对手很少是最优的，且他们拥有的知识和资源难以评估。对于分类问题，常见的假设是数据独立同分布。当存在主动对手修改数据以影响预测时，这一假设极易被违反。当数据以不可预测的方式持续被修改时，训练数据永远不足以诱导出一个准确的分类器。积极的一面是，在训练时我们可以探索特征空间，找到对手在特征空间中移动数据以影响分类器的最有效方向。一旦找到这样的方向，我们就可以通过应对这些潜在移动来改进分类器。

虽然在[第10章](#ch10.xhtml#chapter10)中我们讨论了对抗支持向量机学习，但本章讨论的学习模型是*相关向量机*（RVM）。与支持向量机方法类似，RVM [[TIPP2001](#ch11.xhtml#ref11_16)] 是一种稀疏线性参数化模型。它建立在稀疏模型的贝叶斯框架之上。与支持向量机引入惩罚项以避免模型参数过拟合不同，相关向量机模型以一组超参数的形式引入了权重的先验分布，每个超参数独立地与一个权重相关联。超参数的极大值（对应零权重）意味着输入无关。与剩余非零权重相关联的训练数据点被称为*相关向量*。相关向量机通常比 SVM 使用少得多的核函数。

在本章中，我们提出了一种用于对抗学习的稀疏相关向量机集成。该方法的基本思想是为输入空间中每个维度 `d[i]` 学习一个单独的核参数 `η[i]`。这些参数连同权重及其相关的超参数一起从数据中迭代估计。在每次迭代中更新核参数，使得正类（恶意）数据点的似然度最小化。这实质上将对抗攻击建模为对手被授予了访问学习算法内部状态的权限。我们不使用固定的核参数，而是在学习算法更新相关向量机的权重和权重先验时，搜索能够模拟最坏情况攻击的核参数。我们学习 `M` 个这样的模型并将它们组合起来形成最终假设。

我们的主要贡献包括：

*   将稀疏贝叶斯相关向量机模型扩展以应对对抗攻击；
*   开发了一种核参数拟合技术，以在 RVM 框架内建模对抗攻击。

个性化核参数的使用已被证明对基于核的学习有益 [TIPP2001]；然而，这是首次将其应用于对抗学习。

## 11.2 相关工作

关于恶意噪声率和学习准确性的界限，有若干理论结论。Kearns 和 Li [KEAR1993] 证明了样本中可容忍的恶意错误率的理论上界。他们假设对手可以生成性质未知且不可预测的恶意错误。Bshouty 等人 [[BSHO1999](#ch11.xhtml#ref11_4)] 引入了一种 PAC 学习模型的变体，用于在存在恶意噪声的情况下进行学习。他们证明了当样本噪声率为 `η` 时，没有任何学习算法能以低于 `2η` 的准确度学习非平凡概念类。Auer 和 Cesa-Bianchi [AUER1998] 提出了一种用于处理损坏数据的在线学习模型。他们扩展了“闭包算法”，并证明了学习任意交换闭合概念类的最坏情况错误界。Lowed 和 Meek [[LOWD2005](#ch11.xhtml#ref11_14)] 提出了一种寻找具有最小对抗成本实例的算法。他们将该算法称为对抗分类器逆向工程（ACRE）算法。对抗学习问题已在博弈论框架内得到广泛研究。Dalvi 等人 [[DALVI2004](#ch11.xhtml#ref11_5)] 将学习问题视为两个成本敏感对手之间的博弈。对手总是采取最优策略。给定一个成本函数，他们的算法预测使条件效用最大化的类别。Kantarcioglu 等人 [[KANT2011](#ch11.xhtml#ref11_10)] 提出了一种模拟退火和遗传算法，用于搜索纳什均衡以选择最优属性集。他们假设双方都知道对方的收益函数。关于如何博弈纳什策略的改进类似工作也已被提出 [[BRÜC2009](#ch11.xhtml#ref11_2), [LIU2010](#ch11.xhtml#ref11_13)]。Brückner 和 Scheffer [[BRÜC2011](#ch11.xhtml#ref11_3)] 通过假设对手总是理性行事，提出了一种最优博弈。他们的算法不要求唯一均衡。
