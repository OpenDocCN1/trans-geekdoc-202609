# 前言

## 背景

信息系统技术的最新发展导致各个业务领域的许多应用实现了计算机化。数据已成为许多组织的关键资源，因此，高效访问数据、共享数据、从数据中提取信息并利用这些信息已成为迫切需求。因此，人们不仅致力于整合分散在多个站点的各种数据源，而且从这些数据库中以模式和趋势的形式提取信息并进行数据分析也变得愈发重要。这些数据源可能是由数据库管理系统管理的数据库，也可能是来自多个数据源、存储在数据仓库中的数据。

20 世纪 90 年代中期万维网 (WWW) 的出现，导致对有效管理数据、信息和知识的需求进一步激增。在此期间，服务范式应运而生，现已演变为将计算基础设施、软件、数据库和应用程序作为服务提供。这些能力催生了云计算的概念。过去五年来，云计算的发展呈爆发式增长，如今我们已有多家公司提供基础设施、软件和应用程序计算平台即服务。

随着对数据和信息管理需求的增加，维护数据库、应用程序和信息系统的安全性也变得至关重要。数据、信息、应用程序、Web 和云必须免受未经授权的访问以及恶意破坏。保护此类系统的方法被称为网络安全。

数据管理与分析、Web 服务、云计算和网络安全的重大发展，已演变为一个称为大数据管理与分析 (BDMA) 以及大数据安全与隐私 (BDSP) 的领域。美国劳工统计局 (BLS) 将*大数据*定义为无法用常规统计方法分析的大型数据集合。这些数据集可以代表数值、文本和多媒体数据。大数据通常用五个 V 来定义：容量、速度、多样性、真实性和价值。BDMA 需要处理海量的结构化和非结构化数据，这些数据以高速到达。通过利用大数据，我们可以在网络安全和医疗保健等几个关键领域取得突破，从而提高生产力和盈利能力。不仅大数据系统必须得到保护，大数据分析还必须应用于网络安全应用，例如内部威胁检测。

利用统计推理和机器学习管理和分析海量数据，催生了一个称为*数据科学*的领域。也就是说，数据科学将大数据管理与统计学和机器学习相结合。数据科学技术已应用于医疗保健、金融、市场营销和网络安全等许多领域。另一方面，数据科学技术可能遭到恶意进程的攻击。也就是说，虽然数据科学可用于解决内部威胁检测等网络安全问题，但数据科学技术本身必须是安全的。这催生了一个称为*安全数据科学*的领域。本书将重点关注安全数据科学的各个方面。特别是，本书将讨论安全数据科学的基础技术（如数据科学和网络安全），以及数据科学在网络安全中的应用、数据科学的安全防护，以及安全数据科学中的一些新兴方向（包括数据隐私）。
