
在略有不同的研究途径中，人们提出了稳健学习技术来处理分类时噪声 [[DEKE2008](#ch11.xhtml#ref11_6), [DEKE2010](#ch11.xhtml#ref11_7), [LANC2002](#ch11.xhtml#ref11_12), [TEO2007](#ch11.xhtml#ref11_15)]。Globerson 和 Roweis [[GLOB2006](#ch11.xhtml#ref11_9)] 研究了分类时特征删除问题。他们提出了一种 SVM 算法，在预定义约束下构建最优分类器。El Ghaoui 等人 [[GHAO2003](#ch11.xhtml#ref11_8)] 提出了一种针对由超矩形界定的训练数据的极大极小策略。他们将给定区间内数据的最坏情况损失最小化。

Zhou 等人 [[ZHOU2012a](#ch11.xhtml#ref11_17)] 提出了两种攻击模型，并推导出了相应的最优学习策略。他们构建了一个凸优化问题，其中约束基于所提出的攻击模型定义在样本空间上。他们证明，其对抗 SVM 模型比标准 SVM 和单类 SVM 模型更能抵御对抗攻击。

## 11.3 相关向量机

给定一组 *N* 个训练数据 (*x*[*i*], *y*[*i*])，*i* = 1, …, *N*，其中 *x*[*i*] ∈ ℝ^*d* 为 *d* 维数据点，*y*[*i*] ∈ {0, 1} 为标签，输入空间上的函数 *h*(*x*) 通过以下线性加权形式推断：

*h*(*x*; *w*) = *w*^*T**φ*(*x*)

其中 *φ*(*x*) 表示基函数，且

*φ*(*x*) = [1, *K*(*x*, *x*[1]), *K*(*x*, *x*[2]), …, *K*(*x*, *x*[*N*])]

其中 *K*(*x*, *x*[*i*]) 为核函数。对于二分类问题，给定输入 *x* 的类别成员资格的后验概率为：

```
p(y | w) = ∏_{i=1}^N g(h(x_i; w))^{y_i} [1 - g(h(x_i; w))]^{1 - y_i}  (11.1)
```

其中 *g*(*t*) 为应用于 *t* 的 Sigmoid 函数 *g*(*t*) = 1 / (1 + *e*^(−*t*))。

由于权重参数的数量与训练样本一样多，模型会遭受过拟合。为避免过拟合，在权重上定义了零均值高斯先验，每个先验由其自身的超参数 *α* 控制。因此，

```
p(w | α) = ∏_{i=0}^N N(w_i | 0, α_i^{-1})
```

其中 *α*[*i*] 为 *w*[*i*] 的超参数。为每个权重分配单独的超参数相当于一个正则化惩罚项。当超参数取值很大（通常趋近无穷大）时，正则化效应变得极大，以至于相应的权重参数迅速收敛到零，从而可以剪除相应的基函数。当超参数取值很小时，先验对其调节的权重参数影响极小，因此相应的基函数 *φ*[*k*](*x*) 即为相关特征，其所中心的样本 *x*[*k*] 被选为相关向量。

由于权重后验 *p*(*w* | *y*, *α*) 和边际似然 *p*(*y* | *α*) 无法解析计算，Tipping [[TIPP2001](#ch11.xhtml#ref11_16)] 采用拉普拉斯近似方法，迭代估计以均值 $\bar{w}$ 为中心的高斯分布对 *p*(*w* | *y*, *α*) 的近似后验协方差。随后利用均值和协方差来优化超参数 *α*。详情请参阅其著作 [[TIPP2001](#ch11.xhtml#ref11_16)]。

在相关向量机的贝叶斯框架内，我们引入另一组参数，直接对输入空间中每个维度上两个向量的差异进行加权。在下一节中，我们将讨论利用单独的核参数来建模对抗攻击。

## 11.4 核参数拟合

### 11.4.1 我们的方法

RVM 训练过程迭代更新权重向量 *w* 和超参数向量 *α*。设想在每次迭代中，对手都有机会修改训练数据，特别是正类（恶意）训练数据，使其能够跨越当前迭代推断出的决策边界。对手修改数据的最佳策略是什么？如果对手可以自由地向有利于自己的方向移动每个数据点，他会遵循使正类实例被错误分类的可能性增加最大的方向。在讨论搜索该方向的技术之前，我们先讨论核及其输入尺度参数。

### 11.4.2 核参数向量

考虑 RBF 核

*K*(*x*[*i*], *x*[*j*]) = exp(−*η*‖(*x*[*i*] − *x*[*j*])‖²)

其中 *η* = (*η*[1], …, *η*[*d*]) 为 *d* 个参数的向量，*η*[*k*] 为第 *k* 个参数，位于第 *k* 个输入维度的平方距离 (*x*[*ik*] − *x*[*jk*])² 之前。通常只有一个核参数，其值通常通过交叉验证确定。我们使用单独的核参数，以便在每个维度中建模对抗性数据修改。例如，当对手修改第 *k* 维使得 *x*[*ik*] ≈ *x*[*jk*] 时，令 *η*[*k*] ≈ 0 可达到相同效果。因此，通过调整输入第 *k* 维的核参数，我们可以在输入空间和特征空间中建模对抗攻击。随后我们可以更新权重参数及相应的超参数以对抗攻击。

下面展示典型的 RBF 核和我们使用的 RBF 核。

典型 RBF 核

*K*(*x*[*i*], *x*[*j*]) = exp(−*η*‖(*x*[*i*] − *x*[*j*])‖²)

我们使用的 RBF 核为：

```
η = (η_1, …, η_d)
K(x_i, x_j) = exp(-‖η · (x_i - x_j)‖²)
```

即，

```
K(x_i, x_j) = exp(-∑_{k=1}^d η_k · (x_ik - x_jk)²)
```

```
log(p(t | w)) = ∑_{i=1}^N [y_i log(σ_i) + (1 - y_i)(1 - log(σ_i))]  (11.2)
```

其中 *σ*[*i*] = *g*(*h*(*x*[*i*]; *w*)) 为 Sigmoid 函数的输出。令 ℒ = log(*p*(*t* | *w*)) = ℒ[+] + ℒ[−]，其中

```
ℒ_+ = ∑_{i=1}^N y_i log(σ_i)  and  ℒ_- = ∑_{i=1}^N (1 - y_i)(1 - log(σ_i)).
```
