

# 数据库系统发展概况

根据 1990 年美国国家科学基金会（NSF）研讨会发布的 Lagunita 报告（参见 [[SILB90](#appendix.xhtml#refAppendixA_8)] 和 [[KIM90](#appendix.xhtml#refAppendixA_5)]），关系数据库系统、事务处理以及分布式（关系）数据库系统被列为成熟技术。此外，厂商正在推销面向对象数据库系统，并演示不同数据库系统之间的互操作性。报告指出，随着应用日益复杂，需要更复杂的数据库系统。而且，由于许多组织现在使用数据库系统，在许多情况下类型各异，因此需要集成这些数据库系统。尽管相关工作已开始，商业产品也已上市，但仍有若干问题有待解决。因此，20 世纪 90 年代初数据库系统研究者面临的挑战主要集中在两个领域：下一代数据库系统和异构数据库系统。

## 下一代数据库系统

下一代数据库系统包括面向对象数据库系统、函数式数据库系统、用于增强数据库系统功能性能的特殊并行架构、高性能数据库系统、实时数据库系统、科学数据库系统、时态数据库系统、处理不完整和不确定信息的数据库系统以及智能数据库系统（有时也称为逻辑或演绎数据库系统）。理想情况下，数据库系统应提供高性能事务处理支持、建模复杂应用、表示新型数据并进行智能推理。虽然 20 世纪 80 年代末和 90 年代初取得了显著进展，但在开发出这样的数据库系统之前仍有大量工作要做。

## 异构数据库系统

过去十年间，异构数据库系统受到了相当大的关注 [[MARC1990](#appendix.xhtml#refAppendixA_6)]。主要问题包括处理不同的数据模型、不同的查询处理策略、不同的事务处理算法和不同的查询语言。是否应为整个系统提供统一视图，还是各个系统的用户维护自己对整个系统的视图？这些问题尚未得到令人满意的解答。人们预想，异构数据库管理系统的完整解决方案还需一代人的时间。在研究致力于寻找此类解决方案的同时，也应开展工作以处理有限形式的异构性，以满足客户需求。另一种受到关注的数据库系统是联邦数据库系统。注意，有人将异构数据库系统和联邦数据库系统这两个术语交替使用。虽然异构数据库系统可以是联邦的一部分，但联邦也可以包含同构数据库系统。

Web 用户的爆发式增长以及界面技术的发展，给数据管理研究者带来了更多挑战。NSF 于 1995 年赞助了第二次研讨会，确定了多项新兴技术，这些技术在我们步入 21 世纪时显得至关重要 [[WIDO1996](#appendix.xhtml#refAppendixA_23)]。这些技术包括数字图书馆、超大型数据库管理、数据管理问题、多媒体数据库、数据仓库、数据挖掘、协作计算环境的数据管理以及安全与隐私。20 世纪 90 年代另一项重大发展是对象-关系系统的开发。此类系统结合了面向对象数据库系统和关系数据库系统的优势。此外，许多公司现在专注于将其数据管理产品与 Web 技术集成。最后，许多组织越来越需要将部分遗留数据库和应用迁移到更新的架构和系统，如客户端-服务器架构和关系数据库系统。我们认为，数据管理系统的发展没有止境。随着新技术的开发，数据管理研究和开发将迎来新机遇。

数据管理技术的全貌如 [图 A.2](#appendix.xhtml#figNaN_2a) 所示。如图所示，传统技术包括数据库设计、事务处理和基准测试。然后是基于数据模型的数据库系统，如关系型和面向对象型。数据库系统可能依赖于其提供的特性，如安全性和实时性。这些数据库系统可能是关系型或面向对象型。还有基于多站点或多处理器的数据库系统，如分布式和异构数据库系统、并行系统以及正在迁移的系统。最后是新兴技术，如数据仓库与挖掘、协作和 Web。任何关于数据管理系统的综合性文本都应涵盖所有这些技术。我们选择了一些相关技术并将其置于一个框架中。该框架在 [A.5 节](#appendix.xhtml#secNaN_5) 中描述。

## A.3 现状、愿景与问题

数据管理系统已取得显著进展。然而，正如 [图 A.3](#appendix.xhtml#figNaN_3a) 所示，许多技术仍是独立的。例如，多媒体系统尚未与数据仓库和挖掘技术成功集成。最终目标是集成多种技术，使准确的数据和信息能在适当时刻产生，并及时分发给用户。我们对数据和信息管理的愿景如 [图 A.4](#appendix.xhtml#figNaN_4a) 所示。

文献 [THUR1997] 讨论的工作解决了实现这一愿景所需的许多挑战。特别是讨论了异构数据库的集成以及用于互操作性的分布式对象技术的使用。虽然在互操作性的系统方面已取得很大进展，但语义问题仍是一大挑战。不同数据库具有不同的表示。此外，同一数据实体在不同站点可能有不同的解释。解决这些语义差异，并从异构且可能包含多媒体的数据源中提取有用信息，是主要挑战。

## A.4 数据管理系统框架

对于可演化、可互操作的数据管理系统的成功开发，异构数据库系统集成是主要组成部分。然而，还有其他技术必须相互成功集成，以开发高效访问和共享数据以及从数据中提取信息的技术。为促进数据管理系统的开发，以满足医疗、金融、制造和军事等各个领域应用的需求，我们提出了一个框架，可视为数据管理系统的参考模型。必须集成该框架中的各个组件，以开发支持各种应用的数据管理系统。
