
特征集（如 `HFS`、`BFS`）中的每个特征均为二元特征，即其值为 1 或 0。若某实例（即可执行文件）包含该特征，则其值为 1；否则为 0。针对每个训练（或测试）实例，我们计算一个特征向量，该向量是由相应特征集的特征值组成的位向量。例如，若要计算特定实例 `I` 对应 `BFS` 的特征向量 `V[BFS]`，则对 `BFS` 中的每个特征 `f` 在 `I` 中进行搜索。若在 `I` 中找到 `f`，则将 `V[BFS][f]`（即对应 `f` 的位）置为 1；否则置为 0。通过这种方式，我们设置/重置特征向量中的每一位。这些特征向量供分类器用于训练/测试。

我们应用 `SVM`、`朴素贝叶斯 (NB)`、提升决策树及其他分类器执行分类任务。`SVM` 可执行线性或非线性分类。Vladimir Vapnik 提出的线性分类器创建一个超平面，以最大间隔将数据点分为两类。最大间隔超平面将训练样本分为两个子集，使超平面与其最近数据点之间的距离最大化。非线性 `SVM` [[BOSE2003](#ch06.xhtml#ref6_1)] 通过将核技巧应用于最大间隔超平面来实现。特征空间被转换到更高维的空间，在该空间中找到最大间隔超平面。决策树在每个内部节点包含属性测试，在每个叶节点包含决策。它通过从根节点到决策节点执行属性测试来对实例进行分类。决策树是一种基于规则的分类器，意味着我们可以从树中获得人类可读的分类规则。`J48` 是 `C4.5` 决策树算法的实现。`C4.5` 是 Quinlan 发明的 `ID3` 算法的扩展。一种称为 `AdaBoost` 的提升技术通过根据分类性能为每个分类器分配权重来组合多个分类器。算法首先为所有训练样本分配相等的权重，并从该训练数据获得一个模型。然后增加每个误分类样本的权重，并从新的训练数据获得另一个模型。此过程迭代指定次数。分类时，将这些模型中的每一个应用于测试数据，并执行加权投票以确定测试实例的类别。我们在 `NB` 和 `J48` 上使用 `AdaBoost.M1` 算法 [[FREU1996](#ch06.xhtml#ref6_3)]。我们仅报告 `SVM` 和提升 `J48` 的结果，因为它们效果最好。应注意，我们对这两种分类器没有任何偏好。我们将在下一节讨论实验结果。

## 6.4 评估与结果

### 6.4.1 实验

我们设计实验在两个不同的数据集上运行。每个数据集具有不同规模和分布的良性与恶意可执行文件。我们使用 [[MASU2011](#ch06.xhtml#ref6_13)] 中解释的技术生成各类 `n`-gram 特征（如 `BFS`、`AFS`、`DFS`）。注意 `BFS` 对应 [KOLT2004] 方法提取的特征。我们还按照 [MASU2011] 中解释的模型生成 `DAF` 和 `HFS`。我们应用三折交叉验证，使用 `SVM`、决策树、`朴素贝叶斯`、`贝叶斯网络` 和提升决策树等分类器测试各特征集的准确率。在这些分类器中，`SVM` 和提升决策树取得最佳结果，已在 [MASU2011] 中报告。因篇幅限制，我们不报告其他分类器的结果。此外，我们计算平均准确率、假阳性率和假阴性率，以及接收者操作特征 (`ROC`) 图（使用 [FAWC2003] 中的技术）。我们还对比 `HFS` 和 `BFS` 的运行时间及性能/成本权衡。

### 6.4.2 数据集

我们有两个非不相交数据集。第一个数据集（`dataset1`）包含 1,435 个可执行文件，其中 597 个为良性，838 个为恶意。第二个数据集（`dataset2`）包含 2,452 个可执行文件，其中 1,370 个为良性，1,082 个为恶意。因此，`dataset1` 的分布为良性 = 41.6%，恶意 = 58.4%；`dataset2` 的分布为良性 = 55.9%，恶意 = 44.1%。特意选择此分布是为了在不同场景下评估特征集的性能。我们从不同的 Windows XP 和 Windows 2000 机器收集良性可执行文件，从 [[VX-Heavens](#ch06.xhtml#ref6_21)] 收集恶意可执行文件，后者包含大量恶意可执行文件。良性可执行文件包含 Windows 安装文件夹（如 `C:\Windows`）中的各种应用程序，以及默认程序安装目录（如 `C:\Program Files`）中的其他可执行文件。恶意可执行文件包含病毒、蠕虫、特洛伊木马和后门。两种情况下我们均仅选择 Win32 可移植可执行文件 [Windows P.E.]。我们未来希望尝试 `ELF` 可执行文件。

### 6.4.3 实验设置

我们的实现基于 `Java` 和 `JDK 1.5` 开发。我们使用 `libSVM` 库 [[LIBSVM](#ch06.xhtml#ref6_10)] 运行 `SVM`，使用 `Weka ML` 工具箱 [[WEKA](#ch06.xhtml#ref6_22)] 运行提升决策树及其他分类器。对于 `SVM`，我们运行带多项式核的 `C-SVC`；设置 `gamma = 0.1`，`epsilon = 1.0E-12`。对于提升决策树，我们在 `C4.5` 决策树算法（称为 `J48`）上运行十次 `AdaBoost` 算法迭代。

我们将参数 `S`（选定特征数）设为 500，因为实验表明这是最佳值。大多数实验在两台机器上运行：一台配备 4GB 内存和 2GHz 时钟频率的 Sun Solaris 机器，一台配备 2GB 内存和 1.8GHz 时钟频率的 `LINUX` 机器。报告的运行时间基于后者。所有机器可执行文件的反汇编和十六进制转储仅执行一次，生成的文件被存储。随后我们在存储的文件上运行实验。
