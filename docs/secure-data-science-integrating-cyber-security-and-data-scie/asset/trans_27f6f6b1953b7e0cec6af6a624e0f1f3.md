根据性质 7.1（分离性），新颖类别必须到达未用空间。此外，新颖类别的实例之间必须存在强内聚性（例如接近性）。因此，我们的方法遵循以下两个基本原则：跟踪决策树中每个叶节点的已用空间，以及寻找落入未用空间中的测试实例之间的强内聚性。

## 7.3.2 新颖类别检测

我们遵循两个基本步骤进行新颖类别检测。首先，训练分类器，以创建并保存已用空间的清单（[第 7.2 节](#ch07.xhtml#sec7_2) 中描述）。这是通过聚类并将聚类摘要保存为“伪点”来完成的。其次，利用这些伪点检测测试数据中的异常值，如果异常值之间存在强内聚性，则宣告发现新颖类别。

### 7.3.2.1 训练期间保存已用空间清单

创建清单的总体思路是对训练数据进行聚类，并将聚类质心和其他有用信息保存为伪点。这些伪点用于跟踪已用空间。这种聚类的具体方式可能因基学习器而异。例如，对于决策树，聚类在树的每个叶节点处进行，因为我们需要分别跟踪每个叶节点的已用空间。对于 [第 7.2 节](#ch07.xhtml#sec7_2) 中讨论的 K-NN 分类器，则利用已有的伪点来存储清单。

值得注意的是，`K`-均值聚类似乎是保存决策边界和计算异常值的最佳选择。基于密度的聚类也可用于检测异常值，但存在若干问题。首先，我们必须在叶节点保存所有原始数据点以应用聚类。其次，聚类过程将耗费平方时间，而 `K`-均值仅需线性时间。最后，我们必须为每个待测试的数据块运行聚类算法。然而，`K`-均值算法中参数 `K` 的选择对总体结果有一定影响，这将在实验结果中讨论。

#### 7.3.2.1.1 聚类

我们为每个数据块构建总共 `K` 个聚类。对于 K-NN，我们利用使用该方法全局创建的现有聚类。对于决策树，聚类在每个叶节点局部进行，具体如下。假设 `S` 为数据块大小。在决策树训练期间，当我们到达叶节点 `l[i]` 时，在该叶节点构建 `k[i] = (t[i]/S)*K` 个聚类，其中 `t[i]` 表示最终落入叶节点 `l[i]` 的训练实例数量。

#### 7.3.2.1.2 存储聚类摘要信息

对于每个聚类，我们在内存中存储以下摘要信息：(i) `权重`，`w`：定义为聚类中点的总数。(ii) `质心`，`ζ`。(iii) `半径`，`R`：定义为质心与属于该聚类的数据点之间的最大距离。(iv) `平均距离`，`μ[d]`：每个点到聚类质心的平均距离。聚类 `H[i]` 的聚类摘要今后将被称为“伪点” `ψ[i]`。因此，`w(ψ[i])` 表示伪点 `ψ[i]` 的权重。计算完聚类摘要后，丢弃原始数据。令 `ψ[j]` 为分类器 `L[j]` 在内存中存储的所有伪点的集合。

### 7.3.2.2 异常值检测与过滤

每个伪点 `ψ[i]` 对应特征空间中的一个超球体，其中心为 `ζ(ψ[i])`，半径为 `R(ψ[i])`。因此，伪点“记忆”了已用空间。我们用伪点 `ψ[i]` 的“区域”或 `RE(ψ[i])` 表示其覆盖的特征空间部分。因此，所有伪点覆盖区域的并集即为所有已用空间的并集，这为分类器 `L[j]` 形成了一个决策边界 `B(L[j]) = ∪ ψ[i]∈ψ[j] RE(ψ[i])`。现在，我们可以定义异常值了。

**定义 7.2：(R异常值)** *设 x 为测试点，`ψ[min]` 为质心离 x 最近的伪点。若 x 在 `RE(ψ[min])` 之外，即其到 `ζ(ψ[min])` 的距离大于 `R(ψ[min])`，则 x 为 R异常值（即原始异常值）。*

换句话说，位于分类器 `L[j]` 的决策边界 `B(L[j])` 之外的任意点 `x` 均为该分类器的 `R异常值`。对于 K-NN，通过针对所有伪点测试 `x` 来全局检测 `R异常值`。对于决策树，`x` 仅针对其所属叶节点存储的伪点进行测试。

#### 7.3.2.2.1 过滤

根据 [定义 7.3](#ch07.xhtml#def7_3)，测试实例可能因以下一个或多个原因被错误地视为 `R异常值`：(i) 测试实例属于现有类别，但它是噪声。(ii) 发生了概念漂移，导致现有类别的决策边界发生了偏移。(iii) 决策树使用的训练数据不足。因此，预测的决策边界与实际边界不符。

由于这些原因，需要对异常值进行过滤，以确保属于现有类别的异常值不会被最终判定为新类别实例。过滤过程如下：如果一个测试实例对集成中的 `所有` 分类器都是 `R异常值`，则将其视为过滤后的异常值。所有其他 `R异常值` 均被过滤掉。

**定义 7.3：(F异常值)** *若测试实例对所有分类器均为 R异常值，则该实例为 F异常值（即过滤后的异常值）。L[i]*

直观上，成为 `F异常值` 是属于新类别的必要条件。因为，假设实例 `x` 不是集成中某个分类器 `L[i]` 的 `R异常值`。则 `x` 必定在决策边界 `B(L[i])` 内部。因此，它违反了性质 7.1（分离性），不可能属于新类别。虽然成为 `F异常值` 是必要条件，但并不充分，因为它不保证性质 7.1（内聚性）。因此，我们进入下一步，验证 `F异常值` 是否同时满足内聚性和分离性。

### 7.3.2.3 检测新颖类别

我们对 `F异常值` 执行若干计算以检测新类别的到来。首先讨论这些计算的一般概念，随后描述如何高效地执行这些计算。对于每个 `F异常值`，我们按如下方式定义 `λ[c]`-邻域（[定义 7.4](#ch07.xhtml#def7_4)）：

**定义 7.4：(λ[c]-邻域)** *F异常值 x 的 `λ[c]`-邻域是属于类别 c 的 x 的 N 个最近邻的集合。*
