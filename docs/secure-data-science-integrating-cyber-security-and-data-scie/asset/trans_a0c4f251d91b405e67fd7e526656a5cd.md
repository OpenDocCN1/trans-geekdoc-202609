
总之，大数据管理与分析技术包括扩展当前的数据管理与挖掘技术以处理海量数据，以及开发新方法，其中包括用于维护和分析大型网络数据的图数据管理与挖掘技术。

## 5.2.3 安全与隐私

海量数据的收集、存储、处理和保留引发了严重的安全与隐私考量。各种法规正被提出以应对大数据，确保个人隐私不被侵犯。例如，即使从数据中移除了个人身份信息，当数据与其他数据结合时，个人仍可能被识别。这实质上是数据安全研究人员在过去四十年里一直在探索的推理与聚合问题。随着大数据的管理，由于现在存在来自不同来源且与各种个人相关的数据，这一问题变得更加严重。

在某些情况下，法规反而可能导致隐私泄露。例如，收集的数据（如电子邮件数据）必须保留一定时期（通常为五年）。只要保存此类数据，就存在隐私泄露的可能性。过多的法规也可能扼杀创新。例如，如果法规要求原始数据必须原样保存，不得处理，或不得基于数据构建模型，那么企业就无法通过创新方式分析数据以提升业务。这会导致创新受阻。

因此，在处理大数据时确保安全与隐私的主要挑战之一，是制定一种兼顾法规与分析的平衡方法。即：组织如何在开展有用分析的同时，仍能确保个人隐私？已开发出许多用于隐私保护数据挖掘、隐私保护数据集成和隐私保护信息检索的技术。挑战在于将这些技术扩展以处理海量的、通常是网络化的数据。

大数据管理与分析的另一个安全挑战是保障基础设施安全。已开发的许多技术，包括 `Hadoop`、`MapReduce`、`Hive`、`Cassandra`、`PigLatin`、`Mahout` 和 `Storm`，都缺乏足够的安全防护。问题在于：如何在确保高性能计算的同时保障这些技术的安全？

接下来，大数据管理策略（如访问方法、索引和查询处理）必须是安全的。那么问题来了：如何整合针对结构化、半结构化、非结构化和图数据等不同类型数据的策略？由于大数据可能源于众多数据源的结合，如何确保数据质量？

最后，必须在大数据安全的背景下审视安全、隐私、完整性、数据质量和信任策略的整个领域。什么是适合大数据的适当策略？如何在不影响性能的情况下处理这些策略？如何使这些策略保持一致且完整？

本节列出了关于大数据安全与隐私的一些挑战。我们需要一个全面的研究计划来识别挑战并为 `BDSP` 开发解决方案。安全不能是事后诸葛亮。也就是说，我们不能在开发每一种大数据技术时才将安全融入其中。我们需要一个全面的战略，以便在技术开发过程中融入安全。我们还需要在组织采用大数据技术之前，确定要强制执行的适当策略和法规类型。这意味着来自多个学科的研究人员必须通力合作，确定问题所在并探索解决方案。这些学科包括网络安全与隐私、高性能计算、数据管理与分析、网络科学和策略管理。

虽然上述讨论的挑战涉及保障大数据安全和确保个人隐私，但大数据管理与分析技术可用于解决安全问题。例如，组织可以将身份管理、邮件过滤和入侵检测等活动外包给云。这是因为此类应用正在收集海量数据，且这些数据必须被分析。云数据管理只是大数据管理的一个例子。问题在于：大数据管理与分析技术的发展如何用于解决安全问题？这些问题包括恶意软件检测、内部威胁检测、入侵检测和垃圾邮件过滤。另一个新兴挑战是：如果大数据分析技术遭受攻击会怎样？这也包括回答诸如：如果数据科学（也包括机器学习和人工智能）技术遭受攻击会怎样等问题。从医疗保健到交通、金融、零售等许多行业都依赖数据科学技术。如果数据科学技术遭受攻击，人们就无法依赖其结果。我们将在下一节讨论这些方面及更多内容。

### 5.3.2 大数据安全与隐私理念

正如 Bertino [[BERT2014](#ch05.xhtml#ref5_2)] 所讨论的，技术进步和新颖应用（如传感器、网络物理系统、智能移动设备、云系统、数据分析和社交网络）使得捕获并快速处理分析海量数据成为可能，从中可提取对安全相关任务至关重要的信息。在网络安全领域，此类任务包括用户认证、访问控制、异常检测、用户监控和内部威胁防护 [[BERT2012](#ch05.xhtml#ref5_1)]。通过分析和整合互联网和 Web 上收集的数据，可以识别个人之间的联系和关系，这反过来可能有助于国土保护。通过收集和挖掘用户出行和疾病爆发的相关数据，可以预测疾病在地理区域内的传播。这些只是几个例子；当然还有许多其他领域，数据技术可在增强安全方面发挥重要作用。
