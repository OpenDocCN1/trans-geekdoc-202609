

# 16 基于访问控制的云端可信信息共享

DOI: [10.1201/9781003081845-27](https://doi.org/10.1201/9781003081845-27)

## 16.1 简介

云计算的出现以及向软件即服务（`SaaS`）范式的持续转变，使得云端作为服务的可信信息共享（`AIS`）需求日益增长。2011年4月，美国国家安全局（NSA）首席信息官（CIO）Lonny Anderson 在描述该机构专注于采用“以云为中心”的方法与其他机构共享信息时，表达了这一需求的紧迫性 [[NSA2011]](#ch16.xhtml#ref16_46)。同样，美国国防部（DoD）也一直在采纳云计算范式，以更高效、经济、灵活和可扩展的方式，实现其“提供信息力量，通过敏捷企业确保任务成功，并在信息环境中拥有机动自由”的愿景 [[DoD]](#ch16.xhtml#ref16_22)、[[DoD2007]](#ch16.xhtml#ref16_23)。此外，医疗和金融等大多数行业也迫切需要在云端安全且及时地共享信息。

云计算范式能够安全高效地共享大量数据。此外，`云计算`的出现以及向 `SaaS` 范式的持续转变，使得云端作为服务的 `AIS` 需求日益增长。为满足联盟组织以云为中心的 `AIS` 需求，迫切需要开发一个在云端运行的 `AIS` 框架。

尽管近年来已开发出许多基于策略的信息共享 `AIS` 工具 [[AWAD2010]](#ch16.xhtml#ref16_5)、[[FINI2009]](#ch16.xhtml#ref16_25)、[[THUR2008]](#ch16.xhtml#ref16_57)、[[RAO2008]](#ch16.xhtml#ref16_48)（这些工具基于控制对数据的访问），但据我们所知，这些工具均不在云端和大数据环境中运行，因此无法提供支持大量用户（如涉及包含文本、图像和视频的海量数据的社交媒体用户）所需的可扩展性。我们开发的用于支持基于云的 `AIS` 的原型系统，应用了以云为中心的查询引擎（例如第15章讨论的 `SPARQL` 查询优化器 [Chapter 15](#ch15.xhtml#chapter15)），利用基于令牌的策略引擎或强制执行用 `XACML` 表达的策略的引擎 [[THUR2010]](#ch16.xhtml#ref16_58)、[[THUR2011]](#ch16.xhtml#ref16_59)，在关系数据库和语义Web数据库中查询大量数据。虽然这比之前的工作有了显著改进（并让我们深入了解了基于云的解决方案的实现），但仍存在一些局限性。首先，基于 `XACML` 的策略规范表达能力不足，无法支持医疗和国防等 `AIS` 应用所需的许多复杂策略。其次，为满足关键任务的可扩展性和效率要求，策略引擎需要在云端运行。例如，虽然第15章 [Chapter 15](#ch15.xhtml#chapter15) 讨论的策略引擎托管在云端，但它们并未充分利用云提供的所有特性。
