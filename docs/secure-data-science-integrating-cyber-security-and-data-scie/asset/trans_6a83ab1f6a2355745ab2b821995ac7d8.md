

## 对比实验：原始数据分布重构方法

为进行对比，我们报告了使用原始数据分布重构方法获得的数据挖掘结果。我们将两种著名的重构技术应用于扰动数据集。

第一种技术是 Agrawal 等人提出的基于贝叶斯推断估计（BE）的方法 [AGRA2000]。第二种技术是 Kargupta 等人提出的基于主成分分析（PCA）的方法 [KARG2003]。算法细节请参考原始文献。我们在五个数据集上应用了这两种技术：首先重构原始分布，然后利用该估计分布构建数据挖掘模型。

我们执行了三种不同的测试来比较数据挖掘准确率：
1. 在重构的测试数据上测试分类器；
2. 在原始测试数据上测试分类器；
3. 在扰动测试数据上测试分类器。

数据挖掘模型的预测准确率如 [表 12.5](#ch12.xhtml#table12_5a) 和 [表 12.6](#ch12.xhtml#table12_6a) 所示。作为对比，[表 12.4](#ch12.xhtml#table12_4a) 显示了直接从扰动数据集获得的数据挖掘准确率。

实验结果表明，这两种重构技术均无法产生优秀的数据挖掘模型。这并不令人意外，因为总体而言，在有限数据上估计数据分布是一个非常困难的问题。如果将原始数据分布重构阶段作为隐私保护数据挖掘的中间步骤，我们可能并不总能获得良好的性能结果。在文献 [LIU2007] 中，作者研究了三个不同的真实数据集，基于重构的方法在所有这些数据集上均失败了。这些结果支持我们寻找从扰动数据中直接执行隐私保护数据挖掘方法的动机。

## 12.7.4 PPDTC4.5 分类器准确率

使用前文描述的数据集，我们进行了不同的实验。在原始训练数据集上应用 WEKA [WITT2005] C4.5 算法构建决策树，并对原始测试数据集进行分类，可获得 83.40% 的准确率。[表 12.4](#ch12.xhtml#table12_4a) 显示了直接在扰动数据集上应用数据挖掘工具的准确率。[表 12.7](#ch12.xhtml#table12_7a) 显示了我们提出的 PPDTC4.5 算法的数据挖掘准确率。

我们可以看到，当在这五个数据集上使用我们提出的 PPDTC4.5 阈值方法构建决策树并在原始数据集上分类时：Data 1 和 Data 2 的准确率高于在扰动数据上分类的准确率；Data 5 相当；Data 3 和 Data 4 较低。原因在于信噪比（SNR）值在此起关键作用。[表 12.1](#ch12.xhtml#table12_1a) 显示了具有不同 SNR 值的扰动数据集。当 SNR 小于 1.0 时，意味着噪声数据的方差 `σ^2` 大于实际数据的方差 `σ^2`。换句话说，Data 3 和 Data 4 引入了更多噪声。我们的算法在 SNR 值大于 1.0 时取得良好结果。当阈值方法构建的决策树分类器不适合对扰动数据集进行分类时，是因为我们的算法估计分裂点并划分训练数据，就像原始数据那样。

### 表 12.7 提出的 PPDTC4.5 数据挖掘准确率

| 我们提出的 PPDTC4.5 分类器准确率 (%) | | | | | | |
| --- | --- | --- | --- | --- | --- | --- |
| 数据集 | | Data 1 | Data 2 | Data 3 | Data 4 | Data 5 |
| **PPDTC4.5 阈值方法** | | | | | | |
| 在原始数据上测试 | | 80.74 | 79.69 | 76.63 | 77.02 | 80.29 |
| 在扰动数据上测试 | | 76.09 | 76.14 | 74.41 | 76.03 | 80.52 |
| **PPDTC4.5 随机路径选择方法** | | | | | | |
| 在原始数据上测试 | | 78.72 | 77.21 | 77.67 | 78.01 | 80.31 |
| 在扰动数据上测试 | | 78.40 | 77.77 | 77.30 | 77.06 | 80.32 |

为了构建对扰动数据进行分类的分类器，我们使用概率作为权重寻找最佳分裂点，并使用随机路径选择来划分训练数据，但目前分类器准确率与直接应用 WEKA C4.5 算法相比并未显著提高。原因在于在划分训练数据集和对测试数据集分类时，随机路径选择方法不能很好地约束随机噪声 `R`。未来，我们希望找到一种更好的方法来约束 `R` 值，以构建更适合对扰动数据进行分类的分类器。

正如我们在实验结果中所见，与直接将数据挖掘技术应用于扰动数据集获得的结果相比，我们提出的 PPDTC4.5 分类器可能无法获得非常令人振奋的高准确率。但与基于重构的方法相比，我们的方法取得了非常好的结果。我们想表达的观点是：避免求解困难的分布问题，而是将数据挖掘函数映射为构建隐私保护数据挖掘方法。这是一个有前景的方向。此外，我们的实验结果还表明，当有海量数据集可用时，白噪声不再能阻止数据挖掘工具提取模式。因此，当数据集足够大时，直接挖掘扰动数据集也是一种好的方法。
