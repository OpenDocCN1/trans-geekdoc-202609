# 3 数据挖掘与安全

DOI: [10.1201/9781003081845-5](https://doi.org/10.1201/9781003081845-5)

## 3.1 简介

数据挖掘（以及机器学习）可被视为数据科学的一个关键方面。我们在多个项目中针对入侵检测系统和社交媒体系统等各种应用，使用了数据挖掘和分析技术。例如，在我们之前的著作 [THUR2016](#ch03.xhtml#ref3_23) 中，我们讨论了基于位置的数据挖掘算法，可提取各种社交媒体（如Twitter）用户的位置。这些算法可扩展以提取其他人口统计数据。我们之前的研究还开发了用于情感分析以及网络安全应用的数据挖掘工具。例如，在我们之前的一本书中，我们讨论了用于恶意软件检测的数据挖掘工具 [MASU2011](#ch03.xhtml#ref3_14)。在本章中，我们提供关于通用数据挖掘技术及其在网络安全中的应用的一些背景信息，以便读者能够了解该领域。此外，我们还将讨论针对数据挖掘技术的攻击方面以及隐私考量。

数据挖掘结果（也称为任务）包括分类、聚类、形成关联以及检测异常。我们的工具主要专注于分类作为结果，并开发了分类工具。分类问题也称为监督学习，即模型从一组带标签的示例中学习，然后向模型呈现一个标签未知的新示例进行预测。

已有许多预测模型被使用，如马尔可夫模型、决策树、人工神经网络（ANN）、支持向量机（SVM）、关联规则挖掘（ARM）等。这些模型各有优劣。然而，所有这些技术存在一个共同的弱点，即无法适用于所有应用。不存在这种理想或完美分类器的原因是，这些技术最初都是为在特定假设下解决特定问题而设计的。

在本章中，我们讨论常用的数据挖掘技术。具体而言，我们介绍马尔可夫模型、SVM、ANN、ARM、多分类问题以及图像分类（这是图像挖掘的一个方面）。在我们的研究与开发中，我们设计了混合模型，以提高数据挖掘算法在入侵检测、社交媒体分析、WWW预测和图像分类等各种应用中的预测准确性 [AWAD2009](#ch03.xhtml#ref3_4)。

数据挖掘在安全领域有许多应用，包括国家安全（如监控）和网络安全（如恶意软件检测）。国家安全面临的威胁包括攻击建筑物、破坏关键基础设施，如电网和电信系统 [BOLZ2005](#ch03.xhtml#ref3_6)。数据挖掘技术正被研究用于发现可疑人员是谁以及谁有能力实施恐怖活动 [THUR2003](#ch03.xhtml#ref3_20)。网络安全涉及保护计算机和网络系统免受特洛伊木马和病毒导致的破坏。数据挖掘也被应用于提供入侵和恶意软件检测及审计等解决方案 [MASU2011](#ch03.xhtml#ref3_14)。在本章中，我们将重点关注用于网络安全应用的数据挖掘。

本章的组织结构如下。在 [第3.2节](#ch03.xhtml#sec3_2) 中，我们提供数据挖掘的概述。我们从 [第3.2.1节](#ch03.xhtml#sec3_002_001) 中数据挖掘任务的讨论开始，然后提供我们在工作中使用的一些数据挖掘技术的细节。其中一些技术也用于本书的 [第二部分](#part_02.xhtml#part2) 和 [第三部分](#part_03.xhtml#part3)（如支持向量机、决策树）。特别是，我们讨论各种数据挖掘技术，如SVM、马尔可夫模型、ARM和决策树，这些将在 [第3.2.2节](#ch03.xhtml#sec3_002_002) 至 [第3.2.6节](#ch03.xhtml#sec3_002_006) 中描述。在 [第3.3节](#ch03.xhtml#sec3_3) 中，我们将讨论用于网络安全应用的数据挖掘。特别是，我们将讨论网络威胁以及数据挖掘检测此类威胁的应用。针对数据挖掘技术的攻击以及数据挖掘的隐私影响将在第3.3.4节中讨论。[第3.4节](#ch03.xhtml#sec3_4) 总结本章。[图3.1](#ch03.xhtml#fig3_1a) 说明了本章的概念。

## 3.2 数据挖掘技术

### 3.2.1 概述

在讨论数据挖掘技术之前，我们先概述一些数据挖掘任务（也称为数据挖掘结果）。然后我们将讨论这些技术。一般来说，数据挖掘任务可分为两类：预测性和描述性。预测性任务本质上预测某个项目是否属于某个类。描述性任务总体上从示例中提取模式。最突出的预测性任务之一是分类。在某些情况下，其他任务（如异常检测）可归结为预测性任务，即判断特定情况是否为异常。描述性任务总体上包括建立关联和形成聚类。因此，分类、异常检测、建立关联和形成聚类也被认为是数据挖掘任务。
