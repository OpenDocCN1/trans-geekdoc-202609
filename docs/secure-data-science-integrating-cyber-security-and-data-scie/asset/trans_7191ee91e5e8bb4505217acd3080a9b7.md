
# 19.5 总结与展望

物联网在交通运输行业具有重大影响。自动驾驶汽车旨在改善日常活动，例如包裹投递、交通优化和货物运输。自动驾驶汽车不仅限于地面车辆，还包括具有广泛应用的航空和海上车辆。由自动驾驶汽车集合组成的物联网系统被称为交通运输物联网系统。虽然此类物联网系统管理大量传感器数据，但其中大部分数据也被发送到云端进行离线分析。尽管自动驾驶汽车及其对交通运输行业可能带来的改进潜力巨大，但安全和隐私问题提出了新的挑战，随着我们不断前进，这些挑战需要得到解决。此外，人工智能技术对于此类物联网系统能够智能地管理自动驾驶汽车也变得至关重要。本章讨论了用于基于云的交通运输物联网系统的人工智能与安全。

本章讨论了关于自动驾驶汽车的交通运输物联网系统的特征，以及此类系统的安全和隐私问题。接下来，我们讨论如何整合人工智能与安全。基于云的交通运输物联网系统也进行了讨论。最后，我们讨论了如何将人工智能、安全与云与交通运输物联网系统相整合。

我们仅触及了保障交通运输物联网系统安全的表面。我们必须了解各种类型的攻击轨迹/手法，并开发机器学习技术来检测和预防攻击。我们还必须研究如何应对针对机器学习技术的攻击，而这些技术是开发智能交通运输物联网系统所必需的。最后，我们需要确定要发送到安全云端以进行分析的数据类型。
