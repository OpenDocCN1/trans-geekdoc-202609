# 作者简介

**Dr. Bhavani Thuraisingham**（巴瓦尼·图赖辛汉博士）是德克萨斯大学达拉斯分校（UTD）计算机科学Founders Chair教授，也是UTD网络安全研究与教育研究所的创始执行主任（2004–2021）。她目前的研究集中在网络安全、云计算和数据科学的融合。加入UTD之前，她在MITRE公司工作了16年，其中包括担任美国国家科学基金会（NSF）项目主任的三年经历。在MITRE之前，她在商业界工作了六年，包括在霍尼韦尔公司。她拥有开发商业产品以及将技术转移到作业系统的经验。她是ACM、IEEE、AAAS和NAI的会士，并荣获IEEE和ACM的众多奖项。更多关于她工作的详情请访问 [http://www.utdallas.edu/~bxt043000/](http://www.utdallas.edu/~bxt043000/)。

**Dr. Murat Kantarcioglu**（穆拉特·坎塔尔奇奥卢博士）是UTD计算机科学Ashbel Smith教授兼数据安全与隐私主任。他毕业于普渡大学计算机科学专业，获博士学位。Kantarcioglu博士是IEEE和AAAS会士、ACM杰出科学家，曾荣获包括IEEE智能与安全信息学技术成就奖和AMIA Homer R.奖在内的多项殊荣。他也是NSF CAREER奖获得者。他目前的研究兴趣包括对抗机器学习和数据隐私。更多关于他工作的详情请访问 [http://www.utdallas.edu/~muratk/](http://www.utdallas.edu/~muratk/)。

**Dr. Latifur Khan**（拉蒂富尔·汗博士）是UTD计算机科学教授兼大数据分析主任。他还是Women in Data Science中心的联合主任。他毕业于南加州大学计算机科学专业，获博士学位。Khan博士是IEEE会士、ACM杰出科学家，曾荣获包括IEEE智能与安全信息学技术成就奖和IEEE大数据安全与隐私高级研究奖在内的多项殊荣。他还是英国IET和BCS的会士。他的研究重点是大数据管理与分析以及用于网络安全的机器学习。更多关于他工作的详情请访问 [http://www.utdallas.edu/~lkhan/](http://www.utdallas.edu/~lkhan/)。
