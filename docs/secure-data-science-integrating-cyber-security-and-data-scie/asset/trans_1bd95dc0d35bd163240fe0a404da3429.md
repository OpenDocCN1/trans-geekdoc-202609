
# 书籍系列概述

我们为 CRC Press 编写了两套关于数据管理/数据挖掘和数据安全的丛书。第一套丛书包含十本书。

- **Book #1** (*Data Management Systems: Evolution and Interoperation*) 侧重于数据管理的通用方面，同时也涉及互操作性和迁移。
- **Book #2** (*Data Mining: Technologies, Techniques, Tools, and Trends*) 探讨了数据挖掘。它实质上详细阐述了 Book #1 的 [Chapter 9](#ch09.xhtml#chapter9)。
- **Book #3** (*Web Data Management and Electronic Commerce*) 探讨了 Web 数据库技术，并将电子商务作为一个应用领域进行了讨论。它实质上详细阐述了 Book #1 的 [Chapter 10](#ch10.xhtml#chapter10)。
- **Book #4** (*Managing and Mining Multimedia Databases*) 同时涉及多媒体数据库管理和多媒体数据挖掘。它详细阐述了 Book #1 的 [Chapter 6](#ch06.xhtml#chapter6)（多媒体数据库管理）和 Book #2 的 [Chapter 11](#ch11.xhtml#chapter11)（多媒体数据挖掘）。
- **Book #5** (XML, Databases and the Semantic Web) 描述了与数据管理相关的 XML 技术。它详细阐述了 Book #3 的 [Chapter 11](#ch11.xhtml#chapter11)。
- **Book #6** (*Web Data Mining Technologies and Their Applications in Business Intelligence and Counter-Terrorism*) 详细阐述了 Book #3 的 [Chapter 9](#ch09.xhtml#chapter9)。
- **Book #7** (*Database and Applications Security: Integrating Information Security and Data Management*) 考察了前几本书中讨论的各项技术的安全性。它侧重于数据库和应用安全领域的技术发展。它实质上是信息安全与数据库技术的融合。
- **Book #8** (*Building Trustworthy Semantic Webs*) 将安全性应用于语义 Web 技术，并详细阐述了 Book #7 的 Chapter 25。
- **Book #9** (*Secure Semantic Service-Oriented Systems*) 是 Book #8 的 [Chapter 16](#ch16.xhtml#chapter16) 的详细阐述。
- **Book #10** (*Building and Securing the Cloud*) 是 Book #9 的 [Chapters 5](#ch05.xhtml#chapter5) 和 25 的详细阐述。

我们的第二套丛书包含六本书。

- **Book #1** 关于 *Design and Implementation of Data Mining Tools*。
- **Book #2** 关于 *Design and Implementation of Data Mining Tools for Malware Detection*。
- **Book #3** 关于 *Secure Data Provenance and Inference Control with Semantic Web*。
- **Book #4** 关于 *Analyzing and Securing Social Media*。
- **Book #5** 关于 *Big Data Analytics with Applications in Insider Threat Detection*。
- **Book #6**（即本书）关于 *Secure Data Science: Integrating Cyber Security and Data Science*。

对于这一系列，我们将与学生合作的实践成果转化为书籍。我们文本之间的关系将在本书的 Appendix 中进行说明。

# 本书组织结构

本书分为四部分，每部分描述与安全数据科学相关的技术的某个方面。本书的主要重点将放在用于网络安全的数据科学以及数据科学的安全防护上。此外，我们还将讨论我们开发的一些实验系统，并提供所涉及的一些挑战。

本书分为四部分，每部分描述与数据科学和网络安全相关的技术的某个方面。

- **[Part I](#part_01.xhtml#part1)** 由四章组成，将描述安全数据科学的支撑技术，包括数据安全与隐私、用于网络安全的数据挖掘、云计算和语义 Web 以及大数据安全与隐私。这些支撑技术为安全数据科学提供了背景信息。
- **[Part II](#part_02.xhtml#part2)** 由四章组成，详细概述了我们为网络安全开发的数据科学技术。特别是，将讨论用于恶意软件分析的可扩展数据科学技术和用于内部威胁检测的流分析。
- **[Part III](#part_03.xhtml#part3)** 由五章组成，将讨论增强安全性和隐私的数据科学，包括针对数据科学的攻击、对抗性机器学习以及隐私感知的基于策略的数据管理。我们还将讨论我们的工作如何应用于特定应用，即 COVID-19 大流行。
- **[Part IV](#part_04.xhtml#part4)** 讨论访问控制与数据科学，由五章组成。它描述了安全云查询处理、基于策略的信息共享、基于语义 Web 的社交媒体数据访问控制框架、基于语义 Web 的大数据推理控制器。我们还将讨论我们的一些工作如何应用于诸如智能交通系统之类的应用。

# 数据、信息与知识

一般来说，数据管理包括管理数据库、互操作性、迁移、仓储和挖掘。例如，Web 上的数据必须被管理和挖掘以提取信息、模式和趋势。数据可以存在于文件、关系数据库或其他类型的数据库中，如多媒体数据库。数据可以是结构化的，也可以是非结构化的。我们在本书中反复使用术语 data、data management、database systems 和 database management systems。我们在本书的 Appendix 中详细阐述这些术语。

我们将数据管理系统定义为管理数据、从数据中提取有意义的信息并利用提取的信息的系统。因此，数据管理系统包括数据库系统、数据仓库和数据挖掘系统。数据可以是结构化数据（如关系数据库中的数据），也可以是非结构化数据（如文本、语音、图像和视频）。

过去曾有大量讨论试图区分 data、information 和 knowledge。在我们之前的一些关于数据管理和挖掘的书中，我们并未试图澄清这些术语。我们只是简单地说明 data 可能只是比特和字节，也可能向用户传达一些有意义的 information。然而，随着 Web 的出现，以及对数据、信息和知识管理作为独立领域的兴趣日益增加，在本书中我们采取了不同的方法，尽可能区分这些术语。

对我们而言：

- **Data** 通常是一些值，如数字、整数和字符串。
- **Information** 是在 data 关联了某种含义或语义时获得的，例如“John's salary is 20K”。
- **Knowledge** 是通过阅读和学习获得的，结果是理解 data 和 information 并采取行动。也就是说，当某人脑海中关于 data 和 information 的不确定性被消除时，data 和 information 就转化为了 knowledge。

应注意，很难给出 data、information 和 knowledge 的严格定义。有时我们也会交替使用这些术语。本书 [Appendix](#appendix.xhtml#ST5) 中讨论的数据管理框架有助于阐明其中一些差异。为了与我们之前书籍中的术语保持一致，我们还将区分 database systems 和 database management systems。**Database management system** 是管理包含持久数据的数据库的组件。**Database system** 由数据库和数据库管理系统两部分组成。
