

## Hamsa 和 Polygraph

Hamsa 和 Polygraph [[LI2006](#ch08.xhtml#ref8_23), [NEWS2005](#ch08.xhtml#ref8_29)] 应用一种简单的数据挖掘形式，利用二进制 `n`-gram 作为特征自动生成蠕虫签名。如果一组 `n`-gram 仅出现在恶意二进制文件（即正样本）中，而从未出现在良性二进制文件中，这两种方法都会将其识别为蠕虫签名。这在两个重要方面不同于前文讨论的传统数据挖掘方法（包括我们的方法）：

1. Polygraph 和 Hamsa 将注意力局限于仅出现在恶意样本池中的 `n`-gram，而传统数据挖掘技术也会考虑出现在良性样本池中的 `n`-gram 以提高分类准确性。
2. Polygraph 和 Hamsa 将签名匹配定义为一组 `n`-gram 的简单存在，而传统数据挖掘方法构建分类模型，基于特征的存在与缺失来匹配样本。

因此，传统数据挖掘方法泛化了 Polygraph 和 Hamsa 的方法，相应地增强了能力。

## 恶意软件检测的动态性质

几乎所有过去的工作都将恶意软件检测问题视为一个静态数据分类问题，即分类模型使用固定的训练数据进行训练。然而，新型恶意软件的快速涌现以及恶意软件作者采用的新混淆策略，给该问题引入了一个动态成分，这违背了静态范式。因此，我们认为，有效的恶意软件检测必须越来越多地被视为一个数据流分类问题，以跟上攻击的步伐。

## 数据流分类技术

许多现有的数据流分类技术针对表现出概念漂移的无限长数据流 [[AGGA2006](#ch08.xhtml#ref8_1), FAN2004, [GAO2007](#ch08.xhtml#ref8_14), [HASH2009](#ch08.xhtml#ref8_18), [HULT2001](#ch08.xhtml#ref8_19), KOLT2005, WANG2003, [YANG2005](#ch08.xhtml#ref8_39), [ZHAO2009](#ch08.xhtml#ref8_41)]。所有这些技术都采用单遍增量更新方法，但在增量更新机制上有所不同。大多数可分为两大类：单模型增量方法和混合批量增量方法。

### 单模型增量更新

单模型增量更新涉及随每个新训练实例动态更新单个模型。例如，决策树模型可以随传入数据增量更新 [HULT2001]。

### 混合批量增量方法

相比之下，混合批量增量方法使用传统的批量学习技术，从一批训练数据构建每个模型。随着概念漂移，旧模型会定期被新模型替换 [[BIFE2009](#ch08.xhtml#ref8_5), FAN2004, GAO2007, WANG2003, YANG2005]。一些混合方法使用单个模型对未标记数据进行分类（例如 [YANG2005] 和 [[CHEN2008](#ch08.xhtml#ref8_7)]），而另一些则使用模型集成（例如 [WANG2003] 和 [SCHO2005]）。混合方法的优势在于模型更新通常比单模型方法简单得多；例如，集成中的分类器可以简单地被移除或替换。然而，通过增量更新集成内的分类器来结合这两种方法的其他技术可能更复杂 [KOLT2005]。

### 准确率加权分类器集成 (AWE)

*准确率加权分类器集成* (AWE) [[SCHO2005](#ch08.xhtml#ref8_33), [WANG2003](#ch08.xhtml#ref8_37)] 是一种重要的混合增量更新集成分类器类别，它使用加权多数投票进行分类。这些方法将数据流划分为等大小的块，每个块用于训练一个分类模型。由 `K` 个此类模型组成的集成对未标记数据进行分类。每当一个新数据块被标记，就会从该块训练一个新分类器。该分类器替换集成中现有的分类器之一。替换牺牲者的选择是通过在最新训练块上评估每个分类器的准确率来决定的。这些集成方法的优势在于它们比持续更新的单模型构建得更高效，并且比其单模型对应物观察到更高的准确率 [[TUME1996](#ch08.xhtml#ref8_36)]。

## 我们的集成方法

我们的集成方法与 AWE 关系最密切，但存在许多显著差异：

1. 我们对训练数据应用多分区，从该训练数据构建 `v` 个分类器。
2. 训练数据由 `r` 个连续数据块组成（即多块方法），而不是单个块。我们在理论和实证上都证明了，这两项增强——即多分区和多块——显著降低了集成分类错误率。
3. 当我们更新集成时，集成中的 `v` 个分类器被 `v` 个新训练的分类器替换。被替换的 `v` 个分类器可能来自不同的块；因此，尽管来自某个块的某些分类器可能已被移除，但来自该块的其他分类器可能仍保留在集成中。这与 AWE 不同，在 AWE 中，移除一个分类器意味着完全移除从整个块获得的知识。我们的替换策略也有助于降低错误率。
4. 我们使用简单多数投票而非加权投票，正如 [GAO2007] 所示，这更适合数据流。

因此，我们的多分区、多块集成方法是 AWE 实现形式的更泛化和高效的形式。

## 先前工作的扩展

我们的工作扩展了我们先前发表的工作 [[MASU2009](#ch08.xhtml#ref8_26)]。大多数现有的数据流分类技术，包括我们之前的工作，都假设数据流中数据点的特征空间是固定的。然而，在某些情况下（如文本数据），这一假设不成立。例如，当特征是单词时，特征空间无法在流开始时完全确定，因为新单词频繁出现。此外，这个庞大的词汇表中很大一部分可能具有低判别力，因此最好从特征空间中省略。因此，为每个数据点选择候选特征的子集更有效且高效。这种特征选择必须随着更新、更具判别力的候选特征出现和旧特征过时而增量进行。因此，特征提取和选择应成为数据流分类不可或缺的一部分。在本章中，我们描述了使用云计算框架 [DEAN2008, ZHAO2009] 设计和实现一种高效且可扩展的特征提取和选择技术。该方法超越了我们之前的工作，因为它考虑了特征空间无法预先确定时数据流分类中发生的真实挑战。这促进了我们技术在大型不断演变的数据集中检测真实恶意可执行文件的应用，表明它能够随着恶意软件实例随时间演变而检测出更新的恶意软件变种。

## 8.4 系统的设计与实现

### 8.4.1 集成构建与更新

我们的*扩展、多分区、多块* (EMPC) 集成学习方法维护一个集成 `A` = {`A1`, `A2`, …, `AKv`}，包含最近的、最好的 `Kv` 个分类器。每当一个新数据块 `Dn` 到达时，它使用集成 `A` 测试该数据块。一旦块 `Dn` 被标记，集成就会更新。分类过程使用简单多数投票。
