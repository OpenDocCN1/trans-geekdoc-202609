
我们坚信，计算的未来在于云计算，数据的未来在于数据科学。云计算和数据科学将在众多领域得到应用，以提供可扩展的数据分析解决方案。结合机器学习，它们不仅将提供可扩展的数据分析解决方案，还将提供能够从经验中学习并进行预测的技术。挑战在于如何将各种服务和组件整合在一起，构建可扩展且安全的数据科学与机器学习系统。此外，在确保个人隐私的前提下安全管理海量数据的系统，将成为未来几十年我们面临的主要挑战之一。

## 2.1 简介

正如我们在 [第 1 章](#ch01.xhtml#chapter1) 中所述，安全数据科学技术将大数据/数据科学技术与安全技术相结合。在本章中，我们将讨论安全技术。具体而言，我们将讨论数据安全与隐私以及网络安全的各个方面。数据科学技术的某个方面，如数据挖掘技术以及云和语义 Web 技术，将在 [第 3 章](#ch03.xhtml#chapter3) 和 [第 4 章](#ch04.xhtml#chapter4) 中讨论。大数据安全与隐私问题将在 [第 5 章](#ch05.xhtml#chapter5) 中讨论。

由于本书的大部分讨论涉及大数据分析/数据科学与安全，我们将为数据管理系统的安全提供一个相当全面的概述。具体而言，我们将讨论安全策略以及在数据库系统中强制执行这些策略。我们的重点将放在自主安全策略上。我们还将讨论数据隐私方面。关于安全数据管理的更多细节，请参阅 [[FERR2000](#ch02.xhtml#ref2_9)] 和 [[THUR2005a](#ch02.xhtml#ref2_23)]。

最流行的自主安全策略是访问控制策略。访问控制策略在 1960 年代针对操作系统进行了研究，随后在 1970 年代针对数据库系统进行了研究。两个著名的数据库系统 `System R` 和 `INGRES` 是最早研究数据库系统访问控制的系统（参见 [[GRIF1976](#ch02.xhtml#ref2_10)] 和 [[STON1974](#ch02.xhtml#ref2_17)]）。从那时起，报告了几种访问控制策略的变体，包括基于角色的访问控制和基于属性的访问控制 [[NIST](#ch02.xhtml#ref2_12)]。其他自主策略还包括管理策略。我们还将在自主策略下讨论标识和认证。请注意，本章的大部分讨论将集中在关系数据库系统的自主安全上。许多原则也适用于其他系统，如对象数据库系统、分布式/联邦数据库系统和云数据管理系统（参见例如 [[THUR1994](#ch02.xhtml#ref2_21)]）。

在设计安全系统之前，必须回答的第一个问题是：系统要强制执行什么安全策略？安全策略本质上是一组强制执行安全的规则。安全策略包括强制安全策略和自主安全策略。强制安全策略是指性质上“强制”且由系统强制执行的策略。自主安全策略是由管理员或数据所有者指定的策略。强制安全策略是非自主安全策略的一部分。基于角色的访问控制策略也被视为非自主安全策略 [[SAND1996](#ch02.xhtml#ref2_15)]。

策略执行是指强制执行策略的机制。例如，在 1970 年代，`System R` 和 `INGRES` 等关系数据库系统产品开发了查询修改机制等技术用于策略执行（参见例如 [GRIF1976] 和 [STON1974]）。查询语言 `SQL`（结构化查询语言）已被扩展以指定安全策略和访问控制规则。最近，`XML`（可扩展标记语言）和 `RDF`（资源描述框架）等语言也被扩展以指定安全策略（参见例如 [[BERT2002](#ch02.xhtml#ref2_4)] 和 [[CARM2004](#ch02.xhtml#ref2_6)]）。我们还将讨论数据管理中的隐私顾虑以及隐私增强的数据管理技术。我们还包含了关于隐私增强数据挖掘的讨论。

本章的组织结构如下。在 [第 2.2 节](#ch02.xhtml#sec2_2) 中，我们介绍自主安全，包括数据库系统的访问控制和授权模型。我们还将讨论基于角色的访问控制系统。在 [第 2.3 节](#ch02.xhtml#sec2_3) 中，我们将讨论强制执行自主安全的方法，包括查询修改的讨论。我们还将概述各种商业产品。数据隐私考量将在 [第 2.4 节](#ch02.xhtml#sec2_4) 中讨论。[第 2.5 节](#ch02.xhtml#sec2_5) 总结本章。[图 2.1](#ch02.xhtml#fig2_1a) 说明了本章讨论的概念。我们假设读者具备一些数据管理知识。关于该主题的更多细节，请参阅 [[DATE1990](#ch02.xhtml#ref2_7)] 和 [[THUR1997](#ch02.xhtml#ref2_22)] 等文献。
