
在此模型中，对手可将恶意数据移动到域中的任意位置。对手所需的唯一知识是每个特征的有效取值范围。

设 `x[j]^(max)` 和 `x[j]^(min)` 分别为数据点 `x[i]` 的第 `j` 个特征——`x[ij]`——所能取得的最大值和最小值。就所有实际目的而言，我们假设 `x[j]^(max)` 和 `x[j]^(min)` 都是有界的。例如，对于高斯分布，它们可设为 0.01 和 0.99 分位数。由此产生的范围将覆盖大多数数据点并丢弃少数极端值。攻击随后被限制为以下形式：

`C[f](x[j]^(min) − x[ij]) ≤ δ[ij] ≤ C[f](x[j]^(max) − x[ij]), ∀j ∈ [1, d]`，

其中 `C[f] ∈ [0,1]` 控制攻击的激进程度。`C[f] = 0` 表示无攻击，而 `C[f] = 1` 对应允许数据移动范围最宽的最激进攻击。更正式地，自由范围攻击模型可定义如下：

```
arg min_{w,b,ξ_i,t_i,u_i,v_i} 1/2 ||w||^2 + C Σ_i ξ_i
s.t. ξ_i ≥ 0
     ξ_i ≥ 1 - y_i · (w · x_i + b) + t_i
     t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
     u_i - v_i = 1/2 (1 + y_i) w
     u_i ≥ 0
     v_i ≥ 0
```

此攻击模型的巨大优势在于，就数据修改而言，它足够通用以涵盖所有可能的攻击场景。当与学习模型配对时，该组合将针对最严重的攻击产生良好性能。然而，当存在轻微攻击时，学习模型会变得过于“多疑”，其性能也会相应下降。接下来，我们提出一种更现实的攻击模型，其中显著的数据篡改会受到惩罚。

### 10.4.2.2 受限攻击

在此模型中，对手可将恶意数据移动得更接近目标点。设 `x[i]` 为对手旨在篡改的恶意数据点。设 `x[i]^(t)`（一个 `d` 维向量）为对手希望将 `x[i]` 推向的潜在目标。对手根据其对良性数据分布的估计来选择 `x[i]^(t)`。理想情况下，对手会为每个 `x[i]` 优化 `x[i]^(t)`，以最小化篡改成本并最大化可达成的目标。最优选择 `x[i]^(t)` 是理想的，但通常需要大量关于特征空间的知识，有时还需要了解学习算法的内部运作 [DALV2004]。更现实的是，对手可将 `x[i]^(t)` 设为良性数据的估计质心、从观测到的良性数据中采样的数据点，或从估计的良性数据分布生成的人工数据点。请注意，若对手对良性数据知之甚少，`x^(t)` 可能是个粗略猜测；若对手知晓训练数据的确切构成，则可能是非常准确的。

在大多数情况下，对手无法按意愿将 `x[i]` 改为 `x[i]^(t)`，因为 `x[i]` 可能会失去太多恶意效用。因此，对于 `d` 维特征空间中的每个属性 `j`，我们假设对手添加

`δ[ij] to x[ij]`

其中

`|δ[ij]| ≤ |x[ij]^(t) − x[ij]|, ∀ j ∈ d`。

此外，我们对属性 `j` 的位移量设定上界如下：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ (1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)^2,`

其中 `C[δ] ∈ [0, 1]` 为常数，建模因移动 `δ[ij]` 导致的恶意效用损失。此攻击模型基于 `x[ij]` 与 `x[ij]^(t)` 彼此相距多远，规定了对手可将 `x[ij]` 向 `x[ij]^(t)` 推多远。

项

`1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)`

为 `δ[ij]` 最多可占 `x[ij]^(t) − x[ij]` 的百分比。当 `C[δ]` 固定时，`x[ij]` 越接近 `x[ij]^(t)`，按百分比计 `x[ij]` 被允许向 `x[ij]^(t)` 移动得越多。反之亦然。`x[ij]` 与 `x[ij]^(t)` 相距越远，`|δ[ij]|` 将越小。例如，当 `x[ij]` 和 `x[ij]^(t)` 位于原点两侧（即一正一负）时，若 `C[δ] = 1`，则不允许任何移动（即 `δ[ij] = 0`）。此模型在伪装数据恶意性与保留其恶意效用之间取得平衡。`(x[ij]^(t) − x[ij]), δ[ij] ≥ 0` 确保 `δ[ij]` 与 `x[ij]^(t) − x[ij]` 同向移动。`C[δ]` 与数据修改后的恶意效用损失相关。`C[δ]` 设定对手为突破决策边界愿牺牲多少恶意效用。较大的 `C[δ]` 意味着较小的恶意效用损失，而较小的 `C[δ]` 建模更大的恶意效用损失。因此，较大的 `C[δ]` 导致攻击较不激进，而较小的 `C[δ]` 导致攻击更激进。

如[图 10.3(a)](#ch10.xhtml#fig10_3a)所示，此攻击模型对良好分离的数据效果极佳。当两类数据均靠近分离边界时（如图 10.3(b) 所示），略微改变属性值即足以将数据推过边界。请注意，两图中的 `X` 和 `Y` 轴均为特征（如图 10.2 所示）。此外，图 10.3(a) 中 `X` 和 `Y` 轴范围为 −0.2 至 0.2，而图 10.3(a) 中 `X` 轴范围为 −0.25 至 0.25，`Y` 轴范围为 −0.3 至 0.3（详见 [ZHOU2012]）。在这种情况下，即使 `C[δ]` 设为 1，上述模型的攻击与所需相比仍过于激进。我们虽可允许 `C[δ] > 1` 以进一步降低攻击激进度，但为求简洁和更直接的控制，我们改为直接对 `|x[ij]^(t) − x[ij]|` 应用折扣因子 `C[ξ]` 以建模攻击的严重程度：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ C_ξ (1 - |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)^2,`

其中 `C[ξ] ∈ [0, 1]`。较大的 `C[ξ]` 产生更大量的数据移动，较小的 `C[ξ]` 设定更窄的数据移动限制。结合这两种情况，*受限攻击*模型如下：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ C_ξ (1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)^2.`
