

## 3.4 总结与展望

在本章中，我们首先概述了各种数据挖掘任务和技术，然后讨论了我们在工作中使用的一些技术。这些包括 `ANN`、`SVM`、决策树和 `ARM`。我们利用这些技术的组合，结合文献中的其他技术以及我们自己的技术，开发了用于超大型数据库的数据分析技术。其中一些技术在[第二部分](#part_02.xhtml#part2)、[第三部分](#part_03.xhtml#part3)和[第四部分](#part_04.xhtml#part4)中得到应用（例如决策树、`SVM`）。

已经设计和开发了大量数据挖掘技术，其中许多正被用于商业工具中。其中几种技术是基本分类、聚类和关联规则挖掘技术的变体。今天面临的主要挑战之一是确定适用于各种应用的适当技术。我们仍然需要更多的基准测试和性能研究。此外，这些技术应减少误报和漏报。

接下来，我们提供了用于网络安全应用的数据挖掘概述。特别是，我们讨论了对计算机和网络的威胁，并描述了数据挖掘在检测此类威胁和攻击方面的应用。最后，我们讨论了针对数据挖掘的安全和隐私攻击，例如，我们讨论了针对数据挖掘技术的攻击以及我们如何调整它们以应对威胁。我们还讨论了因数据挖掘而产生的隐私问题，并讨论了诸如隐私感知数据挖掘之类的解决方案。

数据挖掘、网络安全和隐私是一个非常活跃的研究领域。包括链接分析和关联规则挖掘在内的各种数据挖掘技术正被探索用于检测异常模式。由于数据挖掘，用户现在可以进行各种关联分析。此外，在过去的十年里，正在收集海量数据。我们需要大数据分析技术来检测潜在的安全违规。这也引发了隐私担忧。更多关于隐私的细节可参阅 [THUR2002](#ch03.xhtml#ref3_19)。最近，对抗性数据挖掘/机器学习受到了极大关注。本书的大部分内容基于与网络安全和隐私相关的数据挖掘/机器学习。
