

# 附录 A：数据管理系统

数据管理系统演进与互操作的一个关键组成部分是异构数据库系统的互操作性。关于数据库系统间互操作性的研究工作自 20 世纪 70 年代末以来就已有报道。然而，直到最近我们才看到异构数据库系统在商业开发方面的进展。主要数据库系统供应商现在正在提供其产品与其他系统之间的互操作性。此外，许多数据库系统供应商正朝着一种称为**客户端-服务器架构**的架构迁移，这种架构促进了分布式数据管理能力。除了不同数据库系统和客户端-服务器环境之间的互操作性工作外，研究工作还致力于处理自治和联邦环境。

值得注意的是，自 1997 年我们出版第一本书以来的 24 年里，技术已经发生了演变。随着万维网的出现，数据的重要性开始被认识到。在过去的 24 年里，越来越大量的数据被收集、存储、处理和分析。虽然当时的挑战是管理 PB 级数据库，这被称为“大规模数据问题”，但现在已经演变为 ZB 级甚至 EB 级数据库，这被称为“大数据问题”。此外，虽然机器学习技术过去用于处理所谓的“玩具问题”，但现在用于处理“现实世界问题”。这是由于硬件的巨大进步、对数据理解的深入以及更复杂的学习技术，特别是在所谓的“深度学习”领域。因此，只要组织（商业、学术、政府）收集和分析数据，大数据分析就会长期存在。这也意味着我们必须确保在数据生命周期的所有阶段都强制执行安全和隐私策略。我们在本书中解决了其中一些挑战。

本附录的组织结构如下。由于数据库系统是数据管理系统的关键组成部分，我们首先提供数据库系统发展的概述。这些发展在[A.2 节](#appendix.xhtml#secNaN_2)中讨论。然后我们在[A.3 节](#appendix.xhtml#secNaN_3)中提供数据管理系统的愿景。我们的数据管理系统框架在[A.4 节](#appendix.xhtml#secNaN_4)中讨论。请注意，数据挖掘、数据仓库以及 Web 数据管理是该框架的组成部分。基于我们框架并通过特定实例化构建信息系统的内容在[A.5 节](#appendix.xhtml#secNaN_5)中讨论。应注意，[A.2 节](#appendix.xhtml#secNaN_2)至[A.5 节](#appendix.xhtml#secNaN_5)摘自我们的第一本书，并在我们随后的每本书中复制。我们为 CRC Press 撰写的各文本之间的关系在[A.6 节](#appendix.xhtml#secNaN_6)中讨论。[A.7 节](#appendix.xhtml#secNaN_7)总结了本附录。

## A.2 数据库系统的发展

[图 A.1](#appendix.xhtml#figNaN_1a) 概述了数据库系统技术的发展。虽然 20 世纪 60 年代的早期工作集中在基于网状和层次数据模型开发产品，但数据库系统的大部分发展发生在 Codd 发表描述关系模型的开创性论文[[CODD1970](#appendix.xhtml#refAppendixA_3)]之后（另见[[DATE1990](#appendix.xhtml#refAppendixA_4)]）。20 世纪 70 年代初开展了关系数据库系统的研究和开发工作，并在整个 70 年代开发了多个原型。值得注意的工作包括 IBM（国际商业机器公司）的 `System R` 和加州大学伯克利分校的 `INGRES`。20 世纪 80 年代，许多关系数据库系统产品投入市场（其中著名的有 Oracle 公司、Sybase 公司、Informix 公司、INGRES 公司、IBM、数字设备公司和惠普公司的产品）。20 世纪 90 年代，其他供应商的产品也相继出现（例如微软公司）。事实上，迄今为止已有大量关系数据库系统产品上市。然而，Codd 指出，许多作为关系系统销售的系统并非真正的关系系统（参见例如 [DATE1990](#appendix.xhtml#refAppendixA_4) 中的讨论）。随后，他讨论了一个系统要被认定为关系数据库系统必须满足的各种标准。虽然早期工作关注数据模型、范式理论、查询处理和优化策略、查询语言、访问策略和索引等问题，但后来重点转向支持多用户环境。特别是开发了并发控制和恢复技术。也提供了对事务处理的支持。

关系数据库系统和事务管理的研究在 20 世纪 70 年代中期后继之以分布式数据库系统的研究。20 世纪 70 年代末也开始了多项分布式数据库系统原型开发工作。其中值得注意的包括 IBM 的 `System R*`、霍尼韦尔公司的 `DDTS`（分布式数据库测试平台系统）、CCA（美国计算机公司）的 `SDD-I` 和 `Multibase`，以及 SDC（系统开发公司）的 `Mermaid`。此外，许多这类系统（例如 `DDTS`、`Multibase`、`Mermaid`）在异构环境中运行。20 世纪 90 年代初，几家数据库系统供应商（如 Oracle 公司、Sybase 公司、Informix 公司）为其系统提供了数据分发能力。大多数分布式关系数据库系统产品基于**客户端-服务器架构**。其理念是让供应商 A 的客户端与供应商 B 的服务器数据库系统通信。换句话说，**客户端-服务器计算范式**促进了异构计算环境。关系和非关系商业数据库系统之间的互操作性也是可能的。数据库系统社区也参与了标准化工作。标准化工作中值得注意的包括 ANSI/SPARC 三级模式架构、数据字典系统的 `IRDS`（信息资源字典系统）标准、关系查询语言 `SQL`（结构化查询语言）以及用于远程数据库访问的 `RDA`（远程数据库访问）协议。

数据库技术的另一个重大发展是面向对象数据库管理系统的出现。20 世纪 80 年代中期开始了此类系统的主动开发工作，现在已有商业产品可用（其中著名的包括 Object Design 公司、Ontos 公司、Gemstone Systems 公司、Versant Object Technology 公司的产品）。人们认为，多媒体、办公信息系统、CAD/CAM、过程控制和软件工程等新一代应用有不同的需求。此类应用利用复杂的数据结构。同时也希望编程语言与数据模型之间有更紧密的集成。面向对象数据库系统满足了这些新一代应用的大部分需求[[CATT1991](#appendix.xhtml#refAppendixA_2)]。
