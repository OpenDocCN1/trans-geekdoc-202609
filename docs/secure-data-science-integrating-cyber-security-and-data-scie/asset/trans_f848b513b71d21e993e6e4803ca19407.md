# 8 基于云的恶意软件检测数据科学

DOI: [10.1201/9781003081845-13](https://doi.org/10.1201/9781003081845-13)

## 8.1 简介

恶意软件是每年许多成功网络攻击的有力手段，包括数据和身份窃取、系统和数据破坏以及拒绝服务；因此，它对许多个人和组织构成了重大的安全威胁。恶意软件包括病毒、蠕虫、特洛伊木马、定时/逻辑炸弹、僵尸网络和间谍软件。研究人员设计了许多技术来应对这些攻击；然而，研究人员在检测和预防攻击方面越成功，野外出现的恶意代码就越复杂。因此，恶意软件作者与恶意软件防御者之间的军备竞赛持续升级。杀毒社区用于检测恶意代码的一种流行技术是*特征检测*。该技术将不受信任的可执行文件与被称为*特征*的唯一标志性字符串或字节模式进行匹配，该特征用作特定恶意代码的标识符。尽管特征检测技术被广泛使用，但它们对零日攻击（新恶意代码）、多态攻击（同一二进制文件的不同加密）或变形攻击（实现相同功能的不同代码）无效 [[CRAN2005](#ch08.xhtml#ref8_9)]。因此，迫切需要快速、自动化且高效的检测技术，且这些技术需对上述攻击具有鲁棒性。

在[第 6 章](#ch06.xhtml#chapter6)中，我们讨论了用于恶意软件检测的数据挖掘工具。本章描述了一种专门用于自动生成特征以防御某些恶意软件攻击的数据挖掘技术。由于恶意软件检测工具需要近实时性能，我们在云端开发了数据挖掘工具。也就是说，本章的主要目的是展示如何利用云等大数据技术来提升恶意软件检测技术的性能和可扩展性。我们在本章剩余部分详细描述了该基于云工具的设计与实现。

本章结构安排如下：[第 8.2 节](#ch08.xhtml#sec8_2)讨论恶意软件检测。[第 8.3 节](#ch08.xhtml#sec8_3)讨论相关工作。[第 8.4 节](#ch08.xhtml#sec8_4)讨论分类算法并从分析上证明其有效性。[第 8.5 节](#ch08.xhtml#sec8_5)接着描述利用云计算进行恶意软件检测的特征提取与选择技术，[第 8.6 节](#ch08.xhtml#sec8_6)讨论数据收集、实验设置、评估技术和结果。[第 8.7 节](#ch08.xhtml#sec8_7)讨论与我们方法相关的若干问题，最后，[第 8.8 节](#ch08.xhtml#sec8_8)总结我们的结论。[图 8.1](#ch08.xhtml#fig8_1a)阐释了本章的概念。

## 8.2 恶意软件检测

### 8.2.1 作为数据流分类问题的恶意软件检测

使用数据挖掘进行恶意软件检测的问题 [[KOLT2004](#ch08.xhtml#ref8_20), [MASU2008a](#ch08.xhtml#ref8_24), [SCHU2001](#ch08.xhtml#ref8_34)] 涉及将每个可执行文件分类为*良性*或*恶意*。大多数过去的工作将该问题视为静态数据分类问题，即使用固定的训练数据训练分类模型。然而，恶意软件演变和创新的不断加快的速度不太适合静态训练。持续演变的恶意软件检测最好视为*数据流*分类问题。在此范式中，数据流是一个可执行文件序列，其中每个数据点是一个可执行文件。该流是*无限长度*的。它还观察到*概念漂移*，因为攻击者不断开发新技术以逃避检测，从而改变恶意代码的特征。同样，良性可执行文件的特征也随着编译器和操作系统的演变而变化。

数据流分类是数据挖掘社区的一个主要活跃研究领域，需要克服至少三个挑战：首先，在无限长度、概念漂移的流中存储和维护潜在的无界历史数据用于训练是不可行的 [[ZHAN2009](#ch08.xhtml#ref8_40)]。其次，分类模型必须持续适应以应对概念漂移。第三，如果数据流中数据点没有预定义的特征空间，则随着流的演变，必须选择并提取具有高区分能力的新特征，我们称之为*特征演化*。

前两个问题的解决方案是相关的。概念漂移要求细化假设以适应新概念；必须从训练集中丢弃大部分旧数据。因此，挖掘概念漂移数据流的主要问题之一是选择足以学习演变概念的训练实例。解决第三个问题需要一个持续进行的特征选择过程，因为随着概念的演变，新的、更强大的特征可能会出现，而旧特征可能变得不再占主导地位。如果特征空间很大，那么特征提取和选择的运行时间和内存需求将成为数据流分类系统的瓶颈。

解决概念漂移的一种方法是选择并存储与当前概念最一致的训练数据 [[FAN2004](#ch08.xhtml#ref8_12)]。其他方法，如极快决策树 (VFDT) [[DOMI2000](#ch08.xhtml#ref8_11)]，在新数据出现时更新现有的分类模型。然而，过去的工作表明，集成技术通常对处理意外变化和概念漂移更具鲁棒性 [[KOLT2005](#ch08.xhtml#ref8_21), [SCHO2005](#ch08.xhtml#ref8_33), [WANG2003](#ch08.xhtml#ref8_38)]。这些技术维护一个分类器集合，并在新数据出现时更新该集合。

我们设计并开发了一种多划分、多块集成分类算法，该算法推广了现有的集成方法。与现有的单划分、单块集成方法相比，这种推广在真实世界数据流测试中显著提高了分类准确率。我们方法中的集成由 `Kv` 个分类器组成，其中 `K` 是常数，`v` 是划分数量，稍后将解释。

我们的方法将数据流划分为大小相等的块。块的大小选择为使每个块中的所有数据都能放入主内存。每个块在标记后，用于训练分类器。每当一个新的数据块被标记时，集成按如下方式更新。我们取最近标记的 `r` 个连续数据块，将这 `r` 个块划分为 `v` 个分区，并用每个分区训练一个分类器。因此，使用 `r` 个连续块训练了 `v` 个分类器。然后，我们从新训练的 `v` 个分类器和现有的 `Kv` 个分类器中，根据准确率选择最好的 `Kv` 个分类器来更新集成。因此，集成中分类器的总数保持不变。因此，我们的方法由划分数量 `v`、块数量 `r` 和集成大小 `K` 这三个参数决定。
