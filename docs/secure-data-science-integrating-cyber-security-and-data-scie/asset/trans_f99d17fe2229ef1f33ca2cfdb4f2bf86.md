
上述方法可能不太适用于序列数据 [[PARV2012a](#ch09.xhtml#ref9_69), [PARV2012b](#ch09.xhtml#ref9_70)]。对于序列数据，我们的方法维护一个由多个无监督基于流的序列学习（USSL）模型组成的集成 [PARV2012a]。在学习过程中，我们将用户操作或命令中的重复序列模式存储在一个称为量化字典的模型中。特别是，由于在流中频繁出现而具有较高权重的较长模式会被纳入字典。在这种情况下，集成是`K`个量化字典类型模型的集合。当新数据到达或被收集时，我们会从这个新数据集生成一个新的量化字典模型。我们将采用所有模型的多数投票来发现该新数据集中的异常模式序列。如果新字典在集成中表现优于其他模型，我们将更新集成，并从集成中丢弃最不准确的模型。因此，随着流的演变，集成始终保持模型的时效性，在合法和非法行为随时间演变的情况下保持较高的检测准确率。我们的测试数据由不同经验水平的多个用户的实时记录命令序列以及一个概念漂移框架组成，以进一步展示该方法的实用性。

本章描述了我们利用流数据挖掘进行内部威胁检测的方法，适用于非序列和序列数据。在[第 9.2 节](#ch09.xhtml#sec9_2)中，我们提供了内部威胁和流挖掘的综述。我们还讨论了大数据/数据科学技术的可扩展性问题。非序列流数据的内部威胁在[第 9.3 节](#ch09.xhtml#sec9_3)中讨论。序列流数据的内部威胁在[第 9.4 节](#ch09.xhtml#sec9_4)中讨论（[图 9.1](#ch09.xhtml#fig9_1a)）。[第 9.5 节](#ch09.xhtml#sec9_5)总结了本章。更详细的讨论见 [[THUR2017](#ch09.xhtml#ref9_83)]。

## 9.2 内部威胁与流挖掘综述

### 9.2.1 内部威胁检测

内部威胁检测工作应用了来自入侵检测和外部威胁检测的思想 [[MAXI2003](#ch09.xhtml#ref9_61), [SCHO2001](#ch09.xhtml#ref9_75), [SCHU2002](#ch09.xhtml#ref9_76), [WANG2003](#ch09.xhtml#ref9_85)]。有监督学习方法收集包含正常和异常行为记录的系统调用跟踪日志 [[FORR1996](#ch09.xhtml#ref9_29), [GAO2004](#ch09.xhtml#ref9_30), [HOFM1998](#ch09.xhtml#ref9_34), [NGUY2003](#ch09.xhtml#ref9_63)]，从收集的数据中提取 `n`-gram 特征，并使用提取的特征训练分类器。文本分类方法将每个系统调用视为词袋模型中的一个词 [[LIAO2002](#ch09.xhtml#ref9_47)]。系统调用的各种属性，包括参数、对象路径、返回值和错误状态，已在各种有监督学习方法中被作为特征利用 [[KRUG2003](#ch09.xhtml#ref9_46), [TAND2003](#ch09.xhtml#ref9_82)]。

混合高阶马尔可夫链模型通过基于用户命令序列识别特定用户的`签名行为`来检测异常 [[JU2001](#ch09.xhtml#ref9_39)]。概率异常检测（PAD）算法 [[STOL2005](#ch09.xhtml#ref9_80)] 是一种用于异常检测的通用算法（在 Windows 环境中），它假设异常或噪声在训练数据中是罕见事件。伪装检测被一些人争论。多种检测方法被应用于 70 个用户的“截断” UNIX Shell 命令数据集 [SCHO2001]。命令是使用 UNIX acct 审计机制收集的。对于每个用户，在一段时间内收集了若干命令。检测方法由多步马尔可夫模型和贝叶斯与马尔可夫方法的组合进行监督。有人认为该数据集不适合伪装检测任务 [MAXI2003]。有人指出，不同用户的数据收集周期差异很大（从几天到几个月不等）。此外，命令并非按输入顺序记录。相反，当应用程序终止审计机制时，它们被合并了。这导致了对严格序列数据进行可能错误分析的不幸后果。因此，在本提议的工作中，我们未考虑该数据集。这些方法与我们的有监督方法不同，因为这些学习方法本质上是静态的，不会从不断演变的流中学习。换句话说，数据的流特性未被进一步探索。因此，静态学习性能可能会随时间下降。另一方面，我们的有监督方法将从不断演变的数据流中学习。我们提出的工作基于有监督学习，通过从不断演变的流中学习，能够很好地处理动态数据或流数据。在异常检测中，使用了一类 SVM 算法 [STOL2005]。OCSVM 通过在正常数据上训练建立模型，然后根据与该正常训练数据的几何偏差将测试数据分类为良性或异常。对于伪装检测，一类 SVM 训练与二类训练同样有效 [STOL2005]。已针对使用二进制特征和基于频率特征的 SVM 进行了研究。具有二进制特征的一类 SVM 算法表现最好。

递归挖掘已被提出用于发现频繁模式 [[SZYM2004](#ch09.xhtml#ref9_81)]。在模式被唯一符号编码并用这种新编码重写所有序列后，一类 SVM 分类器被用于伪装检测。据我们所知，没有工作将这种 OCSVM 扩展到流领域。尽管我们的方法依赖于 OCSVM，但它已扩展到流领域，以便能够应对变化 [PARV2011b, PARV2013]。据我们所知，也有工作探索了用于内部威胁检测的无监督学习，但仅限于静态流 [[ESKI2002](#ch09.xhtml#ref9_27), [LIU2005](#ch09.xhtml#ref9_48)]。基于静态图的异常检测（GBAD）方法 [COOK2000, COOK2007, EBER2007, [YAN2002](#ch09.xhtml#ref9_88)] 将威胁和非威胁数据表示为图，并应用无监督学习来检测异常。`最小描述长度`（MDL）方法已被应用于 GBAD，用于电子邮件、手机通信、业务流程和网络犯罪数据集 [[KOWA2008](#ch09.xhtml#ref9_45), [STAN1996](#ch09.xhtml#ref9_79)]。我们的工作建立在 GBAD 和 MDL 之上，以支持动态、不断演变的流 [PARV2011a, PARV2013]。

流挖掘是数据挖掘研究中一个相对较新的类别，适用于连续数据流 [[FAN2004](#ch09.xhtml#ref9_28)]。在这样的设置中，有监督和无监督学习都必须具有自适应性，以应对特征随时间变化的数据。主要有两种自适应方法：`增量学习` [[DAVI1998](#ch09.xhtml#ref9_19), [DOMI2001](#ch09.xhtml#ref9_23)] 和 `基于集成的学习` [FAN2004, MASU2010a, MASU2011a]。以往的工作表明，基于集成的方法更为有效，从而激发了我们的方法。
