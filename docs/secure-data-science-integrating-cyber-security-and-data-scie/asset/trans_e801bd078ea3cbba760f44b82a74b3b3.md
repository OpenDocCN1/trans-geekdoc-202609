

# 保护隐私的决策树分类

在本章中，我们重点关注在隐私保护数据挖掘中广泛使用的扰动方法。它与之前的几种技术不同之处在于，我们直接从扰动数据构建数据挖掘模型，而不试图将通用数据分布重构作为中间步骤。在我们的解决方案中，我们修改数据挖掘算法，使其能直接用于扰动数据。换句话说，我们直接从扰动训练数据集构建原始数据集的分类器。

更确切地说，我们描述了一种修改后的 `C4.5` [[QUIN1993](#ch12.xhtml#ref12_15)] 决策树分类器，它可以处理扰动后的数值连续属性。我们的保护隐私决策树 `C4.5` (`PPDTC4.5`) 分类器使用扰动训练数据，并构建一个可用于对原始或扰动数据集进行分类的决策树模型。我们的实验表明，当用于对原始数据集进行分类时，我们的 `PPDTC4.5` 分类器能获得高度的准确性。我们选择决策树进行此项研究，是因为许多先前的方法都集中在隐私保护关联规则挖掘上。此外，我们在隐私保护决策树方面的努力，是开发决策树隐私感知方法这一更大规模工作的一部分 [LIU2009]。

本章组织结构如下：[第 12.2 节](#ch12.xhtml#sec12_2) 介绍相关工作。[第 12.3 节](#ch12.xhtml#sec12_3) 介绍我们工作中用于度量隐私的隐私度量体系。[第 12.4 节](#ch12.xhtml#sec12_4) 展示决策树的构建。[第 12.5 节](#ch12.xhtml#sec12_5) 描述如何从扰动数据集构建朴素贝叶斯模型。在 [第 12.6 节](#ch12.xhtml#sec12_6) 中，我们详细解释我们的 `PPDTC4.5`。[第 12.7 节](#ch12.xhtml#sec12_7) 展示我们的实验结果。在 [第 12.8 节](#ch12.xhtml#sec12_8) 中，我们通过对未来工作的讨论进行总结。

## 12.2 相关工作与动机

隐私保护数据挖掘的先前工作解决了两个问题。其中之一旨在通过扰动数据值来保护客户隐私 [AGRA2000]。在该方案中，引入随机噪声数据以扭曲敏感值，并利用随机数据的分布生成一个接近原始数据分布但不泄露原始数据值的新数据分布。估计的原始数据分布用于重构数据，并将分类器和关联规则等数据挖掘技术应用于重构后的数据集。后来，该方法的改进基于扭曲数据收紧了对原始值的估计 [AGRA2000]。数据扭曲方法也已应用于布尔值的研究工作中 [[DU2003](#ch12.xhtml#ref12_6), [EVFI2002](#ch12.xhtml#ref12_7), [RIZV2002](#ch12.xhtml#ref12_17)]。扰动方法及其隐私保护受到批评，因为某些方法可能从重构步骤中推导出私人信息 [[KARG2003](#ch12.xhtml#ref12_9)]。

不同于 [AGRA2000] 中最初的噪声加法方法，已提出许多独特的扰动方法。一个重要类别是乘法扰动方法。从数据几何属性的角度来看，用随机噪声矩阵乘以原始数据值相当于旋转原始数据矩阵，因此也称为基于旋转的扰动。在 [[CHEN2005](#ch12.xhtml#ref12_4)] 中，作者给出了“旋转不变分类器”的可靠证明，表明某些数据挖掘工具可直接应用于基于旋转扰动的数据。在后来的工作 [[LIU2006](#ch12.xhtml#ref12_11)] 中，Liu 等人提出了乘法随机投影，提供了更强的隐私保护。还有一些其他有趣的技术，如基于凝聚的方法 [AGRA2000]、矩阵分解 [[XU2006](#ch12.xhtml#ref12_23)] 等。正如 [[LIU2007](#ch12.xhtml#ref12_12)] 所指出的，这些近期关于基于扰动方法的研究工作直接将数据挖掘技术应用于扰动数据，跳过了重构步骤。选择合适的数据挖掘技术取决于引入噪声的方法。据我们所知，只有少数工作专注于映射或修改数据挖掘技术以满足扰动数据的需求。

另一种方法使用密码学工具构建数据挖掘模型。例如，在 [[LIND2000](#ch12.xhtml#ref12_10)] 中，目标是在训练集分布在两方之间的情况下安全地构建 `ID3` 决策树。利用密码学技术给出了不同的解决方案来解决不同的数据挖掘问题（例如 [[CLIF2002](#ch12.xhtml#ref12_5), [KANT2004](#ch12.xhtml#ref12_8), [VAID2003](#ch12.xhtml#ref12_21)])。这种方法将隐私保护数据挖掘视为安全多方计算的一个特例，不仅旨在保护个人隐私，还试图防止除最终结果外的任何信息泄露。但当参与方数量变大时，通信和计算成本会呈指数级增长。

我们的方法是一种修改后的 `C4.5` 决策树算法 [QUIN1993]，并采用噪声加法方法。我们的方法适用于许多参与方希望执行数据挖掘，但每方仅拥有少量数据的场景。为了获得全局数据挖掘模式，各方必须共享其数据，但每方都有其隐私和安全顾虑。我们的方法正是针对这种情况的解决方案。在我们的方法中，每方根据预设随机噪声的分布扰动其数据，并将扰动后的数据发送给数据挖掘者。数据挖掘者收集各方的扰动数据集，并知晓用于扰动数据的分布。基于这些信息，数据挖掘者构建一个分类器，并将该分类器返回给每个参与方。然后每方可使用此分类器对其数据进行分类。在这种情况下，每方仅知晓自己的数据和分类器，而不知晓其他方的任何数据。数据挖掘者仅能访问扰动数据和噪声数据的分布。这样，隐私得以保护，且每方的通信和计算成本被最小化。

## 12.3 隐私度量

在 [[AGRA2001](#ch12.xhtml#ref12_3)] 的工作中，Agrawal 和 Aggarwal 基于微分熵提出了一种隐私度量。我们在此简要重述其思想。随机变量 `A` 的微分熵 `h(A)` 定义如下：

```
h(A) = −∫[Ω[A]] f[A](a) log[2] f[A](a) da  (12.1)
```

其中 `ΩA` 是 `A` 的定义域。

实际上，`h(A)` 是统计学中 `A` 值固有不确定性的度量。基于此，Agrawal 和 Aggarwal [AGRA2001] 提出了随机变量 `A` 固有的隐私度量 `Π(A)`。

```
Π(A) = 2^(h(A))  (12.2)
```

例如，在 0 和 `a` 之间均匀分布的随机变量 `U` 具有隐私度：

```
Π(U) = 2^(log[2](a)) = a.
```

因此，如果 `Π(A)` = 1，则 `A` 具有与在长度为 1 的区间上均匀分布的随机变量同等的隐私度。此外，如果

```
f[B](x) = 2 f[A](2x),
```

则 `B` 提供的隐私度仅为 `A` 的一半。这很容易说明：在 [0, 1] 上均匀分布的随机变量，其隐私度仅为在 [0, 2] 上均匀分布的随机变量的一半。在 [AGRA2001] 中，Agrawal 和 Aggarwal 还定义了条件隐私和信息损失。更多细节请参考原始文献 [AGRA2001]。我们在工作中选择此隐私度量来量化实验中的隐私。
