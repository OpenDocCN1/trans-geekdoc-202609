

# 20.4 我们何去何从？

本书聚焦于安全数据科学。它探讨了面向网络安全的数据科学，以及安全和隐私增强的数据科学。我们还讨论了在安全数据科学领域开发的一些实验系统。如果我们要在这一极其重要的领域取得进展，就需要继续研究和开发工作。问题是我们该何去何从？

首先，有意在该领域工作的人员必须具备良好的支撑技术知识，包括云计算、数据管理与分析、语义网和安全。例如，理解构成数据分析的技术及其如何扩展以处理海量数据非常重要。

其次，由于该领域正在迅速扩展且有许多新发展，读者必须跟上这些发展，包括阅读有关商业产品和原型以及新兴系统的资料。最后，我们鼓励读者试用这些产品，并开发分析和安全工具。这是熟悉特定领域的最佳方式。也就是说，动手解决实际问题并提供解决方案，以获得更好的理解。开发人员应熟悉 `Hadoop`、`MapReduce`、`HBase`、`Storm` 和 `Spark` 等技术，以及包括各类网络攻击和隐私考量在内的安全技术。云计算将继续对处理海量数据以及包括社交媒体数据系统在内的许多大数据系统的处理产生重大影响，因此云安全将是一个重要方面。最后，数据科学是一个广泛的术语，包含数据挖掘、数据管理、统计学，也包括机器学习中的学习技术。因此，我们需要纳入深度学习等一些新兴技术，并将其与网络安全相结合。本书讨论的技术有许多应用，涉及医疗保健、流行病学、金融、零售和营销等领域。

我们需要联邦和地方政府资助机构提供研发支持。美国国家科学基金会、国家安全局、美国陆军、海军、空军、国防高级研究计划局、情报高级研究计划活动局和国土安全部等机构正在为安全和机器学习研究提供资金。我们还需要商业公司投入研发资金，以便在工业研究方面取得进展，并能将研究成果转化为商业产品。我们还需要与国际研究界合作，解决问题并推动标准制定，这些标准不仅关乎国家利益，也关乎国际利益。总之，我们需要公共/私营/学术界的合作伙伴关系，在安全数据科学这一极其重要的领域开发突破性技术。

# 附录：数据管理系统——发展与趋势

## A.1 简介

本附录的主要目的是为我们编写的数据管理、数据挖掘和数据安全系列丛书设定背景。我们的系列丛书始于 1997 年的《数据管理系统演化与互操作》[[THUR1997](#appendix.xhtml#refAppendixA_9)]。后续书籍均从此第一本书演变而来。本附录旨在提供数据管理系统的概览，并展示该领域多年来是如何演变的：从数据到信息，再到知识，现在则是大数据。然后我们将讨论我们编写的书籍之间的关系。

正如我们系列丛书所述，信息系统技术的发展导致各个业务领域的许多应用实现了计算机化。数据已成为许多组织的关键资源，因此，高效访问数据、共享数据、从数据中提取信息以及利用信息，已成为迫切需求。因此，人们做出了多方面的努力，以整合分散在多个站点的各种数据源。这些数据源可能是由数据库管理系统管理的数据库，也可能只是文件。为了提供多数据源和系统之间的互操作性，正在开发各种工具。这些工具使用户能够以高效透明的方式访问其他系统。

我们将数据管理系统定义为管理数据、从数据中提取有意义信息并利用所提取信息的系统。因此，数据管理系统包括数据库系统、数据仓库和数据挖掘系统。数据可以是结构化数据，如关系数据库中的数据；也可以是非结构化数据，如文本、语音、图像和视频。过去曾有大量讨论以区分数据、信息和知识。我们不试图澄清这些术语。就我们的目的而言，数据可以只是比特和字节，也可以向用户传达某些有意义的信息。然而，我们将区分数据库系统和数据库管理系统。数据库管理系统是管理包含持久数据的数据库的组件。数据库系统由数据库和数据库管理系统两部分组成。
