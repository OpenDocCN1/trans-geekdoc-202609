
# 17.2 相关工作

过去关于 OSN 安全的研究主要集中在隐私保护技术上，旨在允许在不损害 OSN 成员隐私的前提下对社交网络数据进行统计分析（关于该主题的讨论请参见 [[CARM2008](#ch17.xhtml#ref17_4), [CARM2009a](#ch17.xhtml#ref17_5), [CARM2009b](#ch17.xhtml#ref17_6), [CARM2011](#ch17.xhtml#ref17_8)]）。相比之下，OSN 的访问控制是一个相对较新的研究领域。据我们所知，针对在线社交网络的访问控制机制，仅有 [[KRUK2006](#ch17.xhtml#ref17_12)]、[[ALI2007](#ch17.xhtml#ref17_1)] 和 [CARM2009b] 等提案。D-FOAF 系统 [KRUK2006] 主要是一种基于 Friend of a Friend (FOAF) 即“朋友的朋友”本体的社交网络分布式身份管理系统，其中访问权限和信任委托管理作为额外服务提供。在 D-FOAF 中，关系与信任级别相关联，该级别表示参与给定关系的用户之间存在的 `friendship`（友谊/好友关系）程度。尽管 [KRUK2006] 仅讨论了对应于 FOAF 词汇表 [[BRIC2007](#ch17.xhtml#ref17_3)] 中 `foaf:knows` RDF 属性所建模的通用关系，但另一篇 D-FOAF 相关论文 [CHOI20I0] 也考虑了多种关系类型的情况。就访问权限而言，它们通过连接请求者与资源所有者的路径的最小信任级别和最大长度来表示授权用户。在 [ALI2007] 中，作者采用了一种多级安全方法，其中信任是确定用户和资源安全级别的唯一参数。在 [CARM2009a] 中，提出了一种半去中心化的自主访问控制模型及相关的执行机制，用于 OSN 中的受控信息共享。该模型允许为在线资源指定访问规则，其中授权用户通过网络中节点间存在的关系类型、深度和信任级别来表示。

与现有方法相比，我们利用语义 Web 技术来表示用户、资源和动作之间更丰富的关系形式。例如，我们能够表示利用关系层级的访问控制规则，并通过使用 OWL 推理工具，可以推断出“密友”也是“朋友”，因此任何“朋友”可访问的内容，“密友”也可访问。此外，通过修改底层的 SNKB，我们提出的解决方案可轻松适应截然不同的在线社交网络。关于所提框架与 [CARM2009b] 中访问控制机制差异的进一步讨论，请参见 [第 17.4 节](#ch17.xhtml#sec17_4)。

语义 Web 技术最近已被用于为不同于 OSN 的领域开发各种策略和访问控制语言。例如，在 [[TONT2003](#ch17.xhtml#ref17_15)] 中，作者比较了用于分布式基于代理系统的各种策略语言，这些语言定义了授权和义务策略。在 [FINI2008] 中，OWL 被用于表达基于角色的访问控制策略。在 [[YAGU2005](#ch17.xhtml#ref17_18)] 中，作者提出了一种语义访问控制模型，该模型将授权和访问控制管理职责分离，为具有异构安全需求的分布式动态系统提供解决方案。这些先前的工作均未涉及与在线社交网络相关的访问控制问题。在现有工作中，[[ELAH2008](#ch17.xhtml#ref17_9)] 与我们的提案最为相似。与 [ELAH2008] 相比，我们提供了一个丰富得多的 OWL 本体，用于建模在线社交网络的各个方面。此外，我们提出了依赖于各用户间信任关系的授权、管理和过滤策略。

# 17.3 利用语义 Web 技术建模社交网络

## 17.3.1 关系类型

最近，资源描述框架 (RDF) 和 Web 本体语言 (OWL) 等语义 Web 技术已被用于建模社交网络数据 [[MIKA2007](#ch17.xhtml#ref17_13)]。尽管本章的目标不是提出用于建模在线社交网络数据的新语义方法，但为了完整起见，我们想简要概述当前的方法，并指出其他也可由语义技术建模的社交网络信息。在我们的讨论中，我们将以 Facebook 为贯穿示例。同时，我们要强调的是，我们的讨论可轻松扩展到其他社交网络框架。

一般来说，我们确定了五类可由语义技术建模的社交网络数据。它们如下：（1）个人信息；（2）人际关系；（3）社交网络资源；（4）用户与资源之间的关系；以及（5）可在社交网络中执行的动作。在下文中，我们将讨论如何表示这些社交网络数据。在随后的小节中，我们将讨论上述四种关系中每一种的建模方面。

## 17.3.2 建模个人信息

Facebook 等 OSN 上提供的部分个人信息可通过 Friend-of-a-Friend (FOAF) 本体 [BRIC2007] 进行建模。FOAF 是一种基于 OWL 的格式，用于表示个人信息和个人的社交网络。FOAF 提供了各种类和属性来描述社交网络数据，如基本个人信息、在线账户、项目、群组、文档和图像。然而，这些基本机制不足以捕获所有可用信息。例如，没有 FOAF 构造来捕获 `lookingFor` 的含义（例如，John Smith 正在寻找友谊）。得益于 RDF/OWL 语言的可扩展性，这很容易解决。例如，考虑以下使用以 RDF/OWL 语言编写的新 Facebook 本体来捕获 Facebook Profile Id 为 999999 的个人相关信息的案例。在该示例中，我们假设“fb”本体具有一个名为 `lookingFor` 的属性来捕获所需信息。

```
@prefix rdf: <http://www.w3.org/1599/02/22-rdf-syntax-ns>.
@prefix foaf: <http://xmlns.com/foaf/0.1/>.
@prefix fb: <http://example.org/facebook>.
<http://www.facebook.com/profile.php?id=999999999>
foaf:name "John Smith".
<http://www.facebook.com/profile.php?id=999999999>
fb:lookingFor "Friendship".
```

正如该示例所示，现有本体（如 FOAF）可轻松扩展以捕获在线社交网络上可用的个人信息。
