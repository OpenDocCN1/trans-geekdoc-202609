

# 安全增强型数据科学：对抗性 SVM 学习

在本章中，我们开始讨论安全增强型数据科学。特别是，我们将讨论数据科学技术如何适应以应对网络攻击。我们将重点关注的具体数据科学技术是 `SVM`（支持向量机）。

正如 [第 3 章](#ch03.xhtml#chapter3) 所述，入侵检测和垃圾邮件过滤等学习任务面临对抗性攻击。对抗性利用给现有的学习范式带来了额外的挑战。在当前数据和未来数据共享相同属性这一假设下（这对传统方法至关重要），无法实现学习模型对未来数据的泛化。在存在主动对抗者的情况下，用于学习系统训练的数据不太可能代表系统将来会观察到的未来数据。这种差异不仅仅是简单的随机噪声，大多数学习算法在设计时已经考虑到了这一点。通常导致这些学习算法失效的是有针对性的攻击，旨在通过伪装原本会被检测到的恶意数据，使学习系统失去作用。现有的学习算法无法轻易调整以应对这类攻击，因为在攻击会在多大程度上影响样本空间的结构方面存在极大的不确定性。尽管在训练时给定了恶意数据的样本量和分布，我们仍需要对恶意数据会发生多大变化做出合理的推测，因为复杂的攻击者会迅速适应以逃避检测。需要将能够预言对手为突破系统会走多远的攻击模型纳入学习算法，以构建鲁棒的决策面。在本章中，我们提出了两种攻击模型，它们涵盖了*广泛的攻击范围*，并根据对手的动机进行了定制。每种攻击模型都对对手已知的信息做出了简单且现实的假设。随后，推导出了针对这些攻击模型的最优 `SVM` 学习策略。更多细节请参阅 [[ZHOU2012](#ch10.xhtml#ref10_27)]。

一些早期工作为对抗性学习中的问题奠定了重要的理论基础 [[DALVI2004](#ch10.xhtml#ref10_4), [KEAR1993](#ch10.xhtml#ref10_13), [LOWD2005b](#ch10.xhtml#ref10_19)]。然而，早期工作通常做出强假设，例如拥有无限的计算资源，以及双方都完全了解对方。有些提出的攻击模型可能不允许对任意特征集进行更改 [LOWD2005b]。在安全应用中，一些现有研究主要探索在特定应用领域中击败学习算法的实用方法 [[LOWD2005a](#ch10.xhtml#ref10_18), [PERD2006](#ch10.xhtml#ref10_22), [WITT2004](#ch10.xhtml#ref10_26)]。同时，各种学习策略被提出以修复学习算法中特定于应用的弱点 [[LI2006](#ch10.xhtml#ref10_15), [NEWS2005](#ch10.xhtml#ref10_21), [WANG2006](#ch10.xhtml#ref10_25)]，但结果却为未来的攻击打开了新的大门 [[FOGL2006](#ch10.xhtml#ref10_7), PERD2006]。关于恶意软件攻击的对抗性机器学习的最新综述见 [[MAIO2019](#ch10.xhtml#ref10_20)]。主要挑战依然在于攻击者不断利用学习系统未知的弱点。无论学习系统的设计看起来多么完善，总存在它无法检测到的“盲点”，随着双方技术实力的发展，威胁不断升级。威胁通常分为两类，一类旨在将恶意内容混过基于学习的检测机制，另一类试图通过提高假阳性和假阴性率来破坏学习系统的可信度 [[BARR2006](#ch10.xhtml#ref10_1)]。两者之间的灰色地带鲜有研究。在本工作中，我们不再局限于处理特定于应用的攻击和解决学习算法的特定弱点。

我们的主要贡献在于以下三个方面：

*   我们开发了一种学习策略，用于求解一个通用的凸优化问题，其中约束的强度与攻击的强度相关联。
*   我们推导了针对对手的最优支持向量机学习模型，该对手的攻击策略是在通用且合理的假设下定义的。
*   我们研究了在两种不同的攻击模型中，不同参数值下所得最优解的性能如何变化。实证结果表明，我们提出的对抗性 `SVM` 学习算法对各种程度的攻击都相当鲁棒。

## 10.2 相关工作

Kearns 和 Li [KEAR1993] 给出了在存在恶意错误的情况下学习可容忍的恶意错误率的理论上界。他们假设对手拥有无限的计算资源。此外，他们假设对手知晓目标概念、目标分布以及学习算法的内部状态。他们证明了容错不必以效率或简洁性为代价，并且带有恶意错误的学习与标准优化问题之间存在紧密联系。

Dalvi 等人 [DALVI2004] 为存在最优对手的学习问题提出了一个博弈论框架。他们将问题定义为两个成本敏感对手之间的博弈：一个 `Naive Bayes`（朴素贝叶斯）分类器和一个采取最优策略的对手。他们假设双方的所有参数对彼此都是已知的，且对手知晓分类器的确切形式。他们提出的对抗感知算法根据最大化条件效用的类别进行预测。寻找最优解仍然计算密集，这在博弈论中是典型的。

Lowd 和 Meek [LOWD2005b] 指出假设对手完全了解分类器是不现实的。相反，他们建议对手可以通过向分类器发送查询来确认任意实例的成员资格。他们还假设对手拥有样本空间上的对抗性成本函数，该函数将样本映射为成本值。这一假设本质上意味着对手需要了解整个特征空间才能发起最优攻击。他们提出了一种对抗性分类器逆向工程（`ACRE`）算法，用于学习给定学习算法的漏洞。
