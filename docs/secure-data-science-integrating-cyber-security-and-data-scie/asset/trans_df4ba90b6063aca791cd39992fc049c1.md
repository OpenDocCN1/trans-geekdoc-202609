
在基于访问控制的安全云查询处理（[第15章](#ch15.xhtml#chapter15)）中，我们讨论了大数据系统的访问控制模型。未来的方向包括改进查询优化，以及利用 Hadoop/MapReduce 框架来提升性能。我们还需要研究改进的索引技术以增强性能。在以云为中心的可靠信息共享（[第16章](#ch16.xhtml#chapter16)）中，我们讨论了如何在云中安全地共享信息。我们需要通过实现更复杂的策略以及实现分布式版本 CAISS++ 来增强系统。我们还需要对策略的执行进行形式化分析。

在社交媒体系统的访问控制（[第17章](#ch17.xhtml#chapter17)）中，我们讨论了使用语义 Web 技术表示的社交媒体系统的访问控制模型。我们打算通过支持灵活的管理员策略来扩展这项工作。在我们的框架中，根据所支持的本体，社交网络的资源可能与不同的用户相关联。为了实施访问控制，框架必须决定如何将指定的访问控制策略组合在一起。因此，框架的一个首要重要扩展将是支持多种策略集成策略。在大数据系统的推理控制（[第18章](#ch18.xhtml#chapter18)）中，我们讨论了大数据系统推理控制器的设计与实现。我们的下一步是将推理控制器适配为基于 RDF 表示的知识图谱和社交图谱。我们还在研究利用机器学习技术的更强大的推理策略。

最后，在[第19章](#ch19.xhtml#chapter19)中，我们讨论了基于云的交通互联网系统的 AI 与安全。特别是，我们讨论了交通互联网系统关于自动驾驶汽车（AV）的特性，并描述了此类系统的安全与隐私问题。我们还展示了如何将 AI 与安全集成到此类系统中。也讨论了基于云的交通互联网系统。最后，我们讨论了如何将 AI、安全与云与交通互联网系统集成。我们仅触及了保障交通互联网系统安全的表面。我们必须了解各种类型的轨迹/攻击路径，并开发机器学习技术来检测和防范攻击。我们还必须研究如何应对针对开发智能交通互联网系统所需的机器学习技术的攻击。最后，我们需要确定要发送哪些类型的数据到安全云以进行分析。

# 20 总结与展望

DOI: [10.1201/9781003081845-32](https://doi.org/10.1201/9781003081845-32)

## 20.1 本章简介

本章标志着《安全数据科学：融合网络安全与数据科学》的结束。我们讨论了多个方面，包括用于网络安全问题的数据科学（如恶意软件分析和内部威胁检测）、用于应对网络攻击的对抗性机器学习、隐私感知数据科学，以及数据科学系统的访问控制。实验系统是我们在德克萨斯大学达拉斯分校开发的系统，包括基于访问控制的安全云查询处理、基于云的可靠信息共享系统、被视为数据科学应用的安全且私密的社交媒体应用，以及大数据系统的推理控制。我们还讨论了安全数据科学的几个发展方向。

本章的组织结构如下。在[第20.2节](#ch20.xhtml#sec20_2)中，我们给出了本书的总结。该总结取自各章的总结与展望部分。在[第20.3节](#ch20.xhtml#sec20_3)中，我们讨论安全数据科学的发展方向。在[第20.4节](#ch20.xhtml#sec20_4)中，我们提出关于后续研究方向的建议。
