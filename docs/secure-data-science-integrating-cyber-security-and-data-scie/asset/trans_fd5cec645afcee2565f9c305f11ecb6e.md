

# 未来工作与参考文献

## 未来工作

未来，我们希望在多个方向上拓展我们的工作。首先，我们希望提取并利用行为特征进行恶意软件检测。这是因为针对二进制模式的混淆可能通过多态性和变形性实现，但恶意软件很难混淆其行为模式。我们希望向特征集中添加更多特征，例如可执行文件的行为特征。这是因为二进制特征容易受到多态和变形恶意软件的混淆攻击，但混淆行为模式将会很困难。

我们还希望通过应用云计算/大数据框架进行特征提取和选择任务，来增强我们方法的可扩展性。这样特征提取和分类将更具可扩展性。云计算为获取更多 CPU 算力和大得多的磁盘空间提供了一种廉价替代方案，可用于大幅加快特征提取和选择过程。此外，我们也有兴趣从可执行文件中提取行为特征，以克服多态恶意软件进行二进制混淆所带来的问题。

# 7 用于恶意软件检测的流分析

DOI: [10.1201/9781003081845-12](https://doi.org/10.1201/9781003081845-12)

## 7.1 简介

对于数据挖掘/数据科学界而言，挖掘/分析不断增长的流式数据是一大挑战。流数据分类存在三个主要问题。首先，存储并使用所有历史数据进行训练是不切实际的，因为这将需要无限的存储空间和运行时间。其次，数据中可能存在概念漂移，即数据的潜在概念可能随时间变化。第三，新类别可能在流中演变出现。文献中有许多现有解决方案解决前两个问题，例如单模型增量学习算法 [[CHEN2008](#ch07.xhtml#ref7_1), [HULT2001](#ch07.xhtml#ref7_2), [YANG2005](#ch07.xhtml#ref7_11)] 和集成分类器 [[KOLT2005](#ch07.xhtml#ref7_3), [MASU2008a](#ch07.xhtml#ref7_5), [WANG2003](#ch07.xhtml#ref7_10)]。然而，大多数现有技术无法检测流中的新类别。另一方面，我们的方法能同时处理概念漂移并检测新类别。

传统分类器只能正确分类那些它们已接受过训练的类别的实例。当新类别出现在流中时，属于该类别的所有实例都会被错误分类，直到该新类别被专家人工识别，并利用该类别的标记实例训练出新模型为止。我们的方法通过在传统分类器中融入新类别检测器来解决这一问题，从而无需人工干预即可识别新类别的出现。所提出的新类别检测技术可使各领域的许多应用受益，例如网络入侵检测和信用卡欺诈检测。例如，在入侵检测问题中，当发生一种新型入侵时，我们不仅要能检测出这是一次入侵，还要能识别出这是一种新型入侵。有了入侵类型信息，人工专家就能更深入地分析入侵、寻找补救措施、提前设置警报，并使系统更加安全。
