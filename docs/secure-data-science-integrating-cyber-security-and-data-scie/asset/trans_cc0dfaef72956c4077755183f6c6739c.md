# 13 面向隐私感知量化自我数据管理框架

## 13.1 简介

虽然[第一部分](#part_01.xhtml#part1)讨论了安全数据科学的基础技术，[第二部分](#part_02.xhtml#part2)讨论了面向网络安全的数据科学，但[第三部分](#part_03.xhtml#part3)侧重于安全且隐私感知的数据科学。具体而言，虽然[第10章](#ch10.xhtml#chapter10)和[第11章](#ch11.xhtml#chapter11)讨论了针对数据科学技术的攻击，但[第12章](#ch12.xhtml#chapter12)侧重于隐私保护数据科学。在本章（即[第13章](#ch13.xhtml#chapter13)）中，我们将讨论如何强制执行策略，以构建一个面向量化自我应用的隐私感知框架。这项工作直接源于大数据安全与隐私研讨会关于隐私增强型大数据管理与分析的建议。特别是，我们关注在移动设备上收集的海量信息的隐私保护。

智能手机等移动设备已成为拥有数十亿用户的普及计算平台。智能手机应用下载量稳步上升，其中包括大量用于监测个人数据的应用，如健康、饮食摄入、运动和睡眠模式等。随着*量化自我*（*QS*）运动的最近兴起，可穿戴设备和智能手机应用收集的个人数据正被分析，以指导用户改善其健康或个人生活习惯。这些数据还通过基于云的服务与其他服务提供商（如零售商）共享，为用户带来潜在利益（如健康产品信息）。但此类数据收集和共享往往在用户不知情的情况下进行，存在个人数据可能被用于不当目的的严重风险。例如，监测血糖水平的设备收集的数据可能被保险公司用来拒绝为用户甚至用户的血亲提供承保。如果数据收集者能够将财务和健康相关数据与推文、Facebook 活动及购买模式聚合，此类隐私侵犯很容易失控。这可能导致针对数据收集者的诉讼，并给个人带来心理和生理上的痛苦。为了应对这些日益严峻的挑战，我们迫切需要用于QS应用隐私保护的工具和技术。

我们的工作受[第13.2节](#ch13.xhtml#sec13_2)中讨论的示例和场景驱动，旨在解决该问题。具体而言，我们的目标是开发新型移动和基于云的数据存储架构，并结合创新的加密协议、访问控制技术、隐私增强技术、信息泄露分析和可用性分析，以安全地存储、处理和共享隐私敏感的QS数据，而不侵犯个人隐私。特别是，我们的目标是开发一个隐私感知的QS数据管理框架，控制QS数据的整个生命周期，并包含以下组件：(i) 隐私感知数据收集，(ii) 隐私感知数据存储与访问，以及 (iii) 隐私感知数据分析/挖掘与共享。本章的组织结构如下：[第13.2节](#ch13.xhtml#sec13_2)描述我们的方法。[第13.3节](#ch13.xhtml#sec13_3)描述框架的高层设计；[第13.4节](#ch13.xhtml#sec13_4)讨论新颖的方向，如信息共享的行为方面、形式化框架的开发方面，以及我们将此类框架应用于其他应用（如智能交通系统）的工作。[第13.5节](#ch13.xhtml#sec13_5)总结本章。[图13.1](#ch13.xhtml#fig13_1a)展示了本章讨论的这些概念。更多详情请见\[[THUR2018](#ch13.xhtml#ref13_73)\]。

## 13.2 隐私感知量化自我数据管理框架

### 13.2.1 动机场景

海量数据正被收集、存储和分析，用于各种商业和营销目的。虽然此类数据分析对许多应用至关重要，但也可能侵犯个人隐私。本章描述了设计隐私感知数据管理框架以收集、存储和分析数据所涉及的问题。我们还讨论了数据共享的行为方面，以及基于重写规则、涵盖隐私感知数据管理框架的形式化框架方面。
