
此处混合模型的最佳准确率出现在 `n` = 6 时，为 97.4%，且在所有特征集中最高。平均而言，HFS 的准确率比 BFS 高 1.68%，比 AFS 高 11.36%。AFS 的准确率始终最低。导致这种表现不佳的一个可能原因是 AFS 仅考虑可执行文件的 CODE 部分。因此，AFS 会遗漏 ABEP 或 DATA 部分所携带的任何区分模式，导致提取的特征性能较差。此外，当 `n` >= 10 时，AFS 的准确率大幅下降。这是因为较长的指令序列在任一类可执行文件（恶意/良性）中都较为罕见，所以这些序列的区分能力较弱。另一方面，BFS 考虑了可执行文件的所有部分，从而实现了更高的准确率。最后，HFS 同时考虑了 DLL 调用、BFS 和 DAF。因此，HFS 的性能优于 BFS。

### 6.4.4.1.2 数据集2

此处 HFS 与 BFS 准确率之间的差异大于数据集1。HFS 的平均准确率比 BFS 高 4.2%。AFS 的准确率再次垫底。值得注意的是，在数据集2中，HFS 相对于 BFS（和 AFS）的性能有所提升。由此可得出两个重要结论。首先，数据集2 比数据集1 大得多，拥有更多样化的样本集。在此 HFS 表现优于数据集1，而 BFS 表现劣于数据集1。这意味着在多样化且更大的实例集合中，HFS 比 BFS 更稳健。因此，HFS 在大规模、多样化的可执行文件语料库中比 BFS 更适用。其次，数据集2 的良性可执行文件多于恶意文件，而数据集1 的良性文件较少。数据集2 的这种分布更符合现实世界的情况，即良性可执行文件的数量多于恶意文件。这意味着在包含更多良性可执行文件的数据集这一现实场景中，HFS 很可能比 BFS 表现更好。

### 6.4.4.1.3 统计显著性检验
