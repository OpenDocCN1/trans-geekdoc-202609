
可以对元数据强制执行约束。例如，可以授予和撤销用户对元数据关系的访问权限。元数据的自主安全约束的处理方式与数据的处理方式相同。其他数据库功能包括存储管理。存储管理中的问题包括开发适当的访问方法和索引策略。需要考察安全约束对存储管理功能的影响。也就是说，能否根据约束对关系进行分区，并以一种可以高效访问关系的方式存储它们？我们需要为数据库系统开发安全索引技术。关于地理空间信息系统安全索引的一些工作见于 [[ATLU2004](#ch02.xhtml#ref2_2)]。对数据库进行审计是为了确定是否发生了任何安全违规。此外，视图已被用于出于安全目的授予个人访问权限。我们需要针对审计和视图管理的高效技术。

在本节中，我们已经考察了安全对某些数据库功能的影响，包括查询管理、事务处理、元数据管理和存储管理。我们还需要研究安全对其他功能的影响，例如完整性约束处理和容错计算。[图 2.11](#ch02.xhtml#fig2_11a) 说明了安全对数据库功能的影响。应当注意，本节中的一些讨论已扩展至大数据管理。详情见 [[THUR2017](#ch02.xhtml#ref2_26)]。

## 2.4 数据隐私

数据隐私关乎保护个人的敏感信息。虽然提出了不同的隐私定义，但最常见的定义是：由个人决定发布关于他或她的哪些信息。虽然数据隐私已被研究数十年，特别是统计数据库方面，但随着万维网的出现以及将数据挖掘应用于反恐应用的努力，过去 15 年来人们对该主题的兴趣日益增加。关于在隐私与安全需求之间取得平衡的研究已有大量报道。首个关于隐私保护数据挖掘的工作见于 [[AGRA2000](#ch02.xhtml#ref2_1)]。自 2000 年代初以来，该主题的其他一些工作相继出现 [[KANT2004](#ch02.xhtml#ref2_11)]。此外，将隐私问题视为推理问题的一种变体进行研究，见于 [[THUR2005b](#ch02.xhtml#ref2_24)]。

随着大数据技术的发展，人们对数据隐私产生了极大的兴趣。例如，美国国家科学基金会于 2014 年 9 月举办了大数据安全与隐私研讨会，结果见于 [[NSF2014](#ch02.xhtml#ref2_13)]。随着数据分析等技术的进步，以及决策制定者、律师、社会科学家和计算机科学家对数据隐私的关注，我们可以期待在保护个人隐私以及确保其安全方面取得重大进展。

## 2.5 总结与展望

在本章中，我们提供了数据库系统中自主安全策略的概述。我们从访问控制策略（包括授权策略和基于角色的访问控制）的讨论开始。然后我们讨论了管理策略。我们简要讨论了标识和认证。我们还讨论了审计问题以及用于安全的视图。接下来，我们讨论了策略实施。我们还讨论了用于指定策略的 SQL 扩展，并提供了查询修改的概述。

仍有大量工作有待完成。例如，在基于角色的访问控制和基于属性的访问控制方面，针对云和物联网等新兴技术，仍需做大量工作。我们需要管理策略来管理 Web 环境中的多方事务。我们还需要生物识别技术来认证用户。数字身份正成为一个重要的研究领域，特别是结合云系统时。

安全策略实施是一个将随着新技术出现而持续演进的主题。我们已从关系型发展到面向对象、多媒体、基于 Web、基于云的数据管理系统。每个系统都有一些独特的功能，这些功能被纳入安全策略中。为各种系统实施策略将继续成为主要焦点。我们还需要对策略的一致性和完整性进行研究。策略可视化可能有助于实现这一目标。云和大数据中的策略管理是一个活跃的研究领域。我们的工作包括访问控制以及云中的基于策略的信息共享。我们在云中安全策略实施方面开发的实验系统见于 [第 IV 部分](#part_04.xhtml#part4)。
