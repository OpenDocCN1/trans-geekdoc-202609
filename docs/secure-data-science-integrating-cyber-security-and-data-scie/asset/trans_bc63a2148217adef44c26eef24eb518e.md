

我们的方法并不假设流中出现的新数据点会立即被标记。相反，它会推迟集成更新过程，直到最新数据块中数据点的标签变得可用。在此期间，新的未标记数据继续使用当前集成进行分类。因此，该方法非常适合那些分类错误会促使专家用户或其他来源提供修正标签的应用场景。例如，考虑在线信用卡欺诈检测问题。当一笔新的信用卡交易发生时，其类别（`fraud` 或 `authentic`）会使用当前集成进行预测。假设一笔欺诈交易被误分类为 `authentic`。当客户收到银行对账单时，他会识别出该错误并向机构报告。通过这种方式，数据点的实际标签被获取，集成也随之相应更新。

## 8.2.2 用于恶意软件检测的云计算

如果数据点的特征空间不是固定的，分类问题的一个子问题就是提取和选择描述每个数据点的特征。与先前的工作（例如 [KOLT2004](#ch08.xhtml#ref8_10)）一样，我们使用二进制 `n`-gram 作为恶意软件检测的特征。然而，由于可能的 `n`-gram 总数大得令人望而却步，我们审慎地选择具有最大判别力的 `n`-gram。这一选择过程是持续进行的；随着流的推进，会出现较新的 `n`-gram 来主导较旧的 `n`-gram。这些较新的 `n`-gram 会在我们的模型中替换旧的 `n`-gram，以识别特定时期的最佳特征。

对于大型数据集，特征提取和选择过程的朴素实现在时间和存储方面都可能非常密集。例如，我们之前的工作 [MASU2008a](#ch08.xhtml#ref8_10) 从仅 3,500 个可执行文件的语料库中提取了大约 2.5 亿个 `n`-gram。由于并非所有这些特征都能存储在主内存中，该特征提取过程需要大量的虚拟内存（伴随相关的性能开销）。在一台配备四核处理器和 12GB 内存的机器上，提取和选择大约需要两小时的计算时间和数 GB 的磁盘空间。尽管使用的是纯静态数据集；当数据集是动态流时，提取和选择必须反复进行，从而导致主要瓶颈。在本章中，我们考虑了一个大得多的包含 10.5 万个可执行文件的数据集，我们之前的方法对此显得力不从心。

因此，我们设计并开发了一种可扩展的特征选择和提取解决方案，该方案利用云计算框架 [[DEAN2008](#ch08.xhtml#ref8_10)]。我们表明，取决于集群节点的可用性，特征提取和选择的运行时间可以缩短 `m` 倍，其中 `m` 是云集群中的节点数。这些节点是使用廉价商用硬件的机器。因此，该解决方案也具有成本效益，因为不需要高端计算机器。

## 8.2.3 我们的贡献

因此，我们的贡献可以总结如下。我们设计并开发了一种广义的多分区、多数据块集成技术，与现有的单分区、单数据块集成方法相比，显著降低了预期分类误差。理论分析证明了该方法的有效性。随后，我们将恶意软件检测问题表述为数据流分类问题，并指出了传统恶意代码检测技术相对于我们的数据挖掘方法的缺陷。

我们利用云计算框架，设计并开发了一种可扩展且具有成本效益的解决方案来解决这一问题。最后，我们将该技术应用于合成生成的数据、真实僵尸网络流量和真实恶意可执行文件，其检测准确率优于其他流数据分类技术。结果表明，我们的集成技术构成了一个基于数据流分类的强大入侵检测工具。

## 8.3 相关工作

我们的工作与恶意软件检测和流挖掘均相关。本节将讨论这两方面。传统的 `signature-based`（基于特征码）恶意软件检测器通过扫描不受信任的二进制文件中的区分性字节序列或 `features`（特征）来识别恶意软件。恶意软件特有的特征被维护在一个 `signature database`（特征码数据库）中，随着新恶意软件的发现和分析，该数据库必须持续更新。传统上，特征码数据库是由人工专家在新恶意软件出现并被分析时手动推导、更新和传播的。然而，过去十年中新恶意软件出现率的不断攀升，以及自我变异的多态恶意软件的出现，使得手动特征码更新变得不那么切合实际。这促使了用于恶意软件检测的自动化数据挖掘技术的发展（例如 [HAML2009](#ch08.xhtml#ref8_17)、[KOLT2004](#ch08.xhtml#ref8_10)、[MASU2008a](#ch08.xhtml#ref8_10)、[SCHU2001](#ch08.xhtml#ref8_10)），这些技术能够自动推断先前未见过的恶意软件的特征码。

基于数据挖掘的方法分析可执行文件的内容，如果在可执行文件中发现（或未发现）特定的特征组合，则将其分类为恶意软件。这些恶意软件检测器首先经过训练，以便它们能够泛化恶意和良性可执行文件之间的区别，从而检测未来的恶意软件实例。训练过程涉及使用这些特征进行特征提取和模型构建。基于数据挖掘的恶意软件检测器主要在特征提取方式和用于构建模型的机器学习技术上有所不同。这些技术的性能在很大程度上取决于所提取特征的质量。

在 [SCHU2001](#ch08.xhtml#ref8_10) 报告的工作中，作者从 Windows PE 可执行文件的头部提取 DLL（动态链接库）调用信息（使用 `GNU binutils`）和字符串（使用 `GNU strings`），以及从可执行文件内容中提取 2 字节序列。DLL 调用、字符串和字节被用作特征来训练模型。模型使用两种不同的机器学习技术进行训练，即 RIPPER [[COHE1996](#ch08.xhtml#ref8_8)] 和朴素贝叶斯（NB）[[MICH1994](#ch08.xhtml#ref8_28)]，以比较它们的相对性能。在 [KOLT2004](#ch08.xhtml#ref8_10) 中，作者从可执行文件中提取二进制 `n`-gram 特征，并将其应用于不同的分类方法，如 `k`-近邻（KNN）[[AHA1991](#ch08.xhtml#ref8_2)]、NB、支持向量机（SVM）[[BOSE1992](#ch08.xhtml#ref8_6)]、决策树 [[QUIN2003](#ch08.xhtml#ref8_30)] 和 Boosting [[FREU1996](#ch08.xhtml#ref8_13)]。Boosting 与各种其他学习算法结合使用以获得改进的模型（例如，Boosting 决策树）。我们之前关于基于数据挖掘的恶意软件检测的工作 [MASU2008a](#ch08.xhtml#ref8_10) 从可执行文件中提取二进制 `n`-gram，从反汇编的可执行文件中提取汇编指令序列，并从程序头中提取 DLL 调用信息。该工作中使用的分类模型包括 SVM、决策树、NB、Boosting 决策树和 Boosting NB。
