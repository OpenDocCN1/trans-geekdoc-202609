
我们将随机路径选择算法纳入其中，主要是为了比较目的，同时也为未来的工作提供一些方向，即构建决策树分类器来对扰动数据集进行分类。我们认为，通过对随机变量 `R` 的紧界进行适当改进，可以提高随机路径选择算法的性能。

目标是从扰动数据构建一个决策树模型，该模型能够准确地对原始数据集或扰动数据集进行分类。在我们的场景中，由于添加了噪声，我们不知道原始的 `x[j]` 值。相反，我们观察到 `w[j] = x[j] + R`，其中 `R` 是随机噪声，且我们知道其分布。显然，对于属性 `A[i]` 的分裂点 `t`，如果我们知道 `x[j]` 的值，我们将使用以下规则将实例分裂到 `S[1]` 和 `S[2]` 中：

```
split(x_j, t) = { S_1, if x_j ≤ t; S_2, if x_j > t } (12.9)
```

由于我们不知道 `x[j]` 的值，因此只能计算给定分裂点 `t` 和 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。注意 `Pr{w[j] ∈ S[1]} = Pr{w[j] − R ≤ t} = Pr{w[j] − t ≤ R}`。由于我们知道 `R` 的累积分布函数，因此可以轻松计算该概率。令 `p[S1](w[j]|t)` 为给定分裂点 `t` 和 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。类似地，定义 `p[S2](w[j]|t) = 1 − p[S1](w[j]|t)`。一般来说，令 `p[S](w[j]|t)` 为 `w[j]` 属于集合 `S` 的概率。现在，我们不再根据公式 (12.9) 进行分裂，而是可以使用 `p[S](w[j]|t)` 值来估计最佳分裂点，并对 `w[j]` 进行划分，就像原始数据 `x[j]` 会被划分那样。

## 12.6.2 使用阈值的分裂准则

我们可以为每个 `w[j]` 值计算给定分裂点 `t` 下的概率 `p[S1](w[j]|t)`。该 `p[S1](w[j]|t)` 值表示 `w[j] ∈ S[1]` 的可能性。我们可以设定一个阈值，并统计具有类标签 `C[j]` 且 `p[S1](w[j])` 值大于该阈值的 `w[j]` 的数量。这可以用以下方程形式表示：

```
freq'(C_j, S_i) = Σ_{w_j ∈ S_i} ( I_{w_j ∈ C_j}, p_{Si}(w_j) > threshold ) (12.10)
```

在上述方程中，我们通过使用 `p[S1](w[j])` 来计算类值的频率。`I[wj∈Cj]` 是一个指示函数，如果 `w[j]` 具有类标签 `C[j]`，则返回 1。公式 (12.3) 变为如下形式：

```
Info(S) = - Σ_{j=1}^k ( freq'(C_j, S) / |S| ) × log_2( freq'(C_j, S) / |S| ) (12.11)
```

使用上述公式 (12.11)，加上公式 (12.4)、(12.5)、(12.6) 和 (12.7)，我们可以通过最大化 `gainRatio` 来找到数值连续属性的最佳分裂属性和最佳分裂点。

## 12.6.3 通过阈值分裂训练数据

训练数据的分裂准则是直观的。

```
splitThreshold(w_j, t) = { S_1, if p_{S_1}(w_j | t) > threshold; S_2, if p_{S_1}(w_j | t) ≤ threshold } (12.12)
```

请注意，条件 `p[S1](w[j]|t) > threshold` 等价于条件 `p[S2](w[j]|t) ≤ (1 − threshold)`，反之亦然。例如，条件 `pS1(wj|t) > 0.2` 等价于条件 `pS2(wj|t) ≤ 0.8`。伪代码如 [Algorithm 12.1](#ch12.xhtml#alg12_1) 所示。

使用阈值方法看似是一种简单的方法，但设置能够导致成功分类器的适当阈值并非易事。根据定义，`p[S1](w[j]|t)` 是给定分裂点 `t` 和 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。当给定分裂点 `t` 和扰动实例 `w[j]` 时，唯一的不确定性就是随机噪声 `R`。换句话说，阈值的选择与随机噪声的分布有关。在我们的实验中，我们对随机噪声均使用了均匀分布和高斯分布。这两种分布的阈值不同。对于高斯分布，当阈值设置为 0.30 时，分类器给出较高的准确率；对于均匀分布，当阈值设置为 0.50 时，分类器给出较高的准确率。实验结果将在下一节讨论。

决定阈值的另一个好方法是保持其灵活性，就像 C4.5 算法为数值连续属性寻找最佳分裂点 `t` 那样。这将带来良好的结果，但会增加计算成本。

## 12.6.4 对原始实例进行分类

使用前两小节描述的算法，我们选择实际属于原始数据的分裂属性和分裂点。我们还根据对原始值的估计对扰动训练数据进行划分。这样我们就可以为原始数据构建一个决策树分类器。然后，当我们用它对原始数据进行分类时，只需根据属性值是小于还是大于某个属性分裂点来进行分类。对原始数据进行分类的伪代码如 [Algorithm 12.2](#ch12.xhtml#alg12_2) 所示。

## 12.6.5 分裂准则

使用概率作为权重，我们利用 `p[S1](w[j]|t)` 和 `p[S2](w[j]|t)` 值作为权重重写所有方程，如下所示：

```
freq''(C_j, S_i, S) = Σ_{w_j ∈ S} ( I_{w_j ∈ C_j} × p_{S_i}(w_j) ) (12.13)
```

在上述方程中，我们通过使用 `p[S1](w[j])` 作为权重来计算类值的频率。`I[wj∈Cj]` 是一个指示函数，如果 `w[j]` 具有类标签 `C[j]`，则返回 1。为了归一化，我们需要计算总权重之和（即所有 `p[S1](w[j])` 值之和）

```
w(S_i, S) = Σ_{w_j ∈ S} ( p_{S_i}(w_j) ) (12.14)
```

现在，利用上述两个定义，我们准备好使用 `p[S1](w[j])` 值重新定义条件熵。

```
Prob(S_i, S) = freq''(C_j, S_i, S) / |w(S_i, S)| (12.15)
Info'(S_i, S) = - Σ_{j=1}^k Prob(S_i, S) × log_2( Prob(S_i, S) ) (12.16)
Prob(S_i, S) = freq''(C_j, S_i, S) / |w(S_i, S)| (12.17)
Info'(S_i, S) = - Σ_{j=1}^k Prob(S_i, S) × log_2( Prob(S_i, S) ) (12.18)
```

类似地，我们需要更新选择属性 `A` 及分裂点 `t` 时的信息增益。

```
Info'_Test_A(S) = Σ_{i=1}^2 ( |w(S_i, S)| / |S| ) × Info'(S_i, S) (12.19)
```

此外，在计算 `splitInfo` 时，我们需要使用 `w(S_i, S)`。

```
splitInfo'(Test_A) = - Σ_{i=1}^n ( |w(S_i, S)| / |S| ) × log_2( |w(S_i, S)| / |S| ) (12.20)
```

现在，我们可以将上述修改后的定义插入原始测试中，以选择分裂点和属性。
