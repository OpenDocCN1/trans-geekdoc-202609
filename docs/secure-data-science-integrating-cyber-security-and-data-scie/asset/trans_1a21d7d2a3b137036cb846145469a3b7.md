

# 数据挖掘任务与对抗学习

当对手通过修改恶意数据以逃避检测来发起攻击时，数据挖掘任务变得更加复杂。主要挑战在于找到一种对不可预测的恶意数据分布不敏感的鲁棒学习模型。在本章中，我们提出了一种用于对抗学习的稀疏相关向量机集成。我们工作的创新之处在于使用个性化的核参数在模型训练期间对潜在的对抗攻击进行建模。我们允许核参数向最小化正类数据似然的方向漂移。这一步骤与学习相关向量机的权重和权重先验交织进行。我们的实证结果表明，此类相关向量机模型的集成对对抗攻击更具鲁棒性。

我们提出了一种稀疏贝叶斯对抗学习模型。该算法设置个体核参数，通过最小化训练集中正实例的对数似然，在特征空间中对对抗攻击进行建模。在这种设置下训练的学习模型对包括极具侵略性攻击在内的各类攻击更具鲁棒性。一个开放性问题是发现一种能同时高效更新核参数和学习参数的方法。该解决方案将有助于在样本空间中找到针对最坏情况攻击的最优学习模型。

# 12 隐私保护决策树

DOI: [10.1201/9781003081845-20](https://doi.org/10.1201/9781003081845-20)

## 12.1 简介

虽然[第 10 章](#ch10.xhtml#chapter10)和[第 11 章](#ch11.xhtml#chapter11)侧重于安全感知数据科学，但本章我们将讨论隐私感知数据科学。特别是，我们以决策树为例讨论隐私保护数据挖掘。数据挖掘技术（现已演变为机器学习和数据科学技术）被用于从海量数据中推导模式 [[THUR1998](#ch12.xhtml#ref12_18)]。然而，此类技术可能会提取出先前已知的“金块”。这些“金块”可能会侵犯个人隐私 [[THUR2002](#ch12.xhtml#ref12_19)]。由于与隐私相关的担忧日益增加，已经开发出各种隐私保护数据挖掘技术来解决不同的隐私问题 [[THUR2005](#ch12.xhtml#ref12_20)]。这些技术包括隐私保护关联规则挖掘技术和隐私保护决策树 [[AGRA2000](#ch12.xhtml#ref12_2), [AGGA2004](#ch12.xhtml#ref12_1), [LIU2009](#ch12.xhtml#ref12_13)]。隐私保护数据挖掘的理念是对数据进行随机化和/或扰动，然后再进行数据挖掘。这样敏感数据就能保持私密性。[图 12.1](#ch12.xhtml#fig12_1a) 说明了隐私保护数据挖掘背后的理念。

![图 12.1 隐私保护数据挖掘。](images/fig12_1.jpg)

[图 12.1 隐私保护数据挖掘。](#ch12.xhtml#Ffig12_1)

正如[第 3 章](#ch03.xhtml#chapter3)所述，隐私保护数据挖掘技术通常在各种假设下运行并采用不同的方法。之前的工作主要分为两类：(1) 基于扰动和随机化的方法，以及 (2) 基于安全多方计算的方法。对于基于扰动的方法，数据会被扰动，以便保持敏感数据的私密性。对于随机化方法，会向数据中引入随机值。对于基于安全多方计算的方法，理念是每一方加密其秘密。隐私保护数据挖掘在加密的秘密上进行。最终结果会透露给各方。然而，每一方的秘密仅为该方所知。

早期的扰动和随机化方法包含一个重构原始数据分布的步骤。该领域较新的研究采用不同的数据扭曲方法或修改数据挖掘技术，使其更适合扰动场景。采用加密工具构建数据挖掘模型的安全多方计算方法面临着高昂的通信和计算成本，尤其是在参与计算的参与方数量较大时。
