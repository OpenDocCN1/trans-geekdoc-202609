

# 9.3.2 无监督分类和基于集成的更新

[算法 9.1](#ch09.xhtml#alg9_1) 总结了无监督分类和基于集成的更新算法。第 3-4 行从最近的数据块构建一个新模型并暂时将其添加到集成中。接下来，第 5-13 行将集成中的每个模型应用于测试图 *t*，以检测可能的异常。我们对每个模型使用三种 GBAD 变体（P、MDL 和 MPS），本节将讨论每一种。最后，第 14-30 行通过丢弃与加权多数意见分歧最大的模型来更新集成。如果多个模型具有最多的分歧，则任意丢弃一个表现最差的模型。请注意，未使用真实标签。然而，模型的多数投票充当了所谓的“真实标签”。加权多数意见在第 15 行使用以下公式计算：

```
WA(E,a) = \frac{\sum_{\{ i|M_{i} \in E,a \in A_{M_{i}}\}}\lambda^{\ell - i}}{\sum_{\{ i|M_{i} \in E\}}\lambda^{\ell - i}}
```
(9.1)

其中 *M[i]* ∈ *E* 是集成 *E* 中从数据块 *i* 训练得到的模型，*AM[i]* 是模型 *M[i]* 报告的异常集合，*λ* ∈ \[0, 1\] 是一个常数*衰减因子* \[[CHEN2009](#ch09.xhtml#ref9_14)\]，而 *ℓ* 是最近数据块的索引。因此，模型 *M[i]* 的投票获得权重 *λ*[−*i*]，最近构建的模型获得权重 *λ*[0] = 1，从前一个数据块训练的模型获得权重 *λ*[1]（如果它仍存在于集成中），以此类推。当 *λ* < 1 时，这会使最近模型的投票权重高于潜在过时模型的投票权重。然后在第 15 行将加权平均值 *WA*(*E, a*) 四舍五入到最接近的整数（0 或 1），以获得加权多数投票。例如，在图 9.2 中，模型 *M*[1]、 *M*[3] 和 *M*[7] 对输入样本 *x* 分别投出正票、正票和负票。如果 *ℓ* = 7 是最近的数据块，则这些投票的权重分别为 *λ*[6]、 *λ*[4] 和 1。因此加权平均值为 *WA*(*E, x*) = (*λ*[6] + *λ*[4])*/*(*λ*[6] + *λ*[4] + 1)。如果 *λ* ≤ 0.86，在这种情况下负面多数意见获胜；然而，如果 *λ* ≥ 0.87，较新模型的投票将超过两个较旧的异议意见，结果为正分类。因此，参数 *λ* 可被调整以平衡大量旧信息与少量新信息的重要性。我们的方法利用 GBAD 先前迭代的结果来识别后续数据块中的异常。也就是说，在之前的 GBAD 迭代中发现的规范子结构可能会在每个模型中持续存在。这使得每个模型能够考虑自模型引入集成以来的所有数据，而不仅仅是当前数据块的数据。当数据流发生概念漂移时，这可能是一个显著优势，因为集成可以识别在整个数据流或大量数据块中具有规范性的模式，但这些模式在当前数据块中可能不存在。因此，即使恶意行为不频繁，内部人员仍可被检测到。

### 9.3.3 用于监督学习的集成

[算法 9.2](#ch09.xhtml#alg9_2) 展示了我们监督算法的基本构建模块。在这里，我们首先介绍如何更新模型。[算法 9.2](#ch09.xhtml#alg9_2) 的输入如下：*D*[*u*] 是最近标记的数据块（最近的训练数据块），*A* 是集成。第 3-4 行计算每个模型在 *D*[*u*] 上的预测误差。第 6 行使用 OCSVM 在 *D*[*u*] 上构建一个新模型。第 7 行产生 *K* + 1 个模型。第 8 行丢弃预测误差最大的模型，保留 *K* 个最佳模型。[算法 9.3](#ch09.xhtml#alg9_3) 侧重于集成测试。集成 *A* 和最新的未标记实例数据块 *D*[*u*] 将作为输入。第 3 行使用最新的未标记数据块执行特征提取和选择。第 4-9 行将获取从 *D*[*u*] 提取的每个特征并进行异常预测。第 6-7 行使用每个模型预测特定特征的异常状态。最后，第 9 行基于结果的多数投票预测异常。

我们的集成方法利用 OCSVM 先前迭代的结果来识别后续数据块中的异常。这允许考虑的不仅仅是当前正在分析的数据。之前 OCSVM 迭代中发现的模型也会被分析，而不仅仅是当前数据集块的模型。集成以这种方式处理执行，因为在之前数据块中识别出的模式可能在整个数据流或大量数据块中具有规范性，但在当前执行数据块中不具有规范性。因此，即使恶意行为不频繁，内部人员也将被检测到。重要的是要注意，我们始终保持集成大小固定。因此，在最近数据块上表现最差的过时模型将被新模型取代。

重要的是要注意，集成的大小随时间保持固定。表现不佳的过时模型将被更适合当前概念的、表现更好的新模型所取代。即使数据流中的总数据量可能是无界的，这也能使每一轮分类保持可处理。

在一个数据块中，使用单类支持向量机 (OCSVM) \[MANE2002\] 构建模型。OCSVM 方法首先将训练数据映射到高维特征空间（通过核函数）。接下来，算法迭代地寻找能最好地将训练数据与原点分开的最大间隔超平面。OCSVM 可被视为常规的二类 SVM。这里第一类包含所有训练数据，第二类是原点。因此，超平面（或线性决策边界）对应于分类规则：

```
f(x) = w · x + b
```
(9.2)

其中 *w* 是法向量，*b* 是偏置项。OCSVM 求解一个优化问题以找到具有最大几何间隔的规则。该分类规则将用于为测试样本 *x* 分配标签。如果 *f* (*x*) *<* 0，我们将 *x* 标记为异常，否则标记为正常。实际上，超平面到原点的距离最大化与被超平面与原点分隔的区域所包含的训练数据点数量之间存在权衡。

### 9.3.4 无监督学习

[算法 9.3](#ch09.xhtml#alg9_3) 使用三种基于图的异常检测 (GBAD) \[COOK2000, COOK2007, EBER2007, YAN2002\] 变体，利用每个模型推断潜在异常。GBAD 是一种基于图的方法，通过搜索三个因素来发现数据中的异常：顶点和边的修改、插入和删除。每个唯一因素运行自己的算法，该算法寻找一个规范子结构，并尝试找到与发现的规范子结构相似但不完全相同的子结构。规范子结构是指顶点和边的重复子图，当其合并为单个顶点时，能最大程度地压缩整个图。[图 9.3](#ch09.xhtml#fig9_3a) 中的矩形标识了所描绘图的一个规范子结构示例。

![图 9.3 具有规范子结构（框出）和异常（阴影）的图。](images/fig9_3.jpg)

[图 9.3 具有规范子结构（框出）和异常（阴影）的图。](#ch09.xhtml#Ffig9_3)

我们的实现使用 SUBDUE \[[KETK2005](#ch09.xhtml#ref9_41)\] 来寻找规范子结构。最佳规范子结构可以被描述为具有最小描述长度 (MDL) 的子结构：

```
L(S,G) = DL(G|S) + DL(S)
```
(9.3)

其中 *G* 是整个图，*S* 是被分析的子结构，*DL*(*G* □ *S*) 是 *G* 被 *S* 压缩后的描述长度，而 *DL*(*S*) 是被分析的子结构的描述长度。描述长度 *DL*(*G*) 是描述图 *G* 所需的最小比特数 \[[EBER2011](#ch09.xhtml#ref9_26)\]。
