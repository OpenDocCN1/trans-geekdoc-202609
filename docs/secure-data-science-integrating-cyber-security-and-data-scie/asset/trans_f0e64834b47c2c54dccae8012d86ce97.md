

# 使用语义 Web 技术进行推理控制

推理是从前提形成结论的过程。如果用户从收到的合法响应中得出未经授权的结论，则该过程是有害的。这个问题被称为推理问题。推理控制器是防止用户得出未经授权结论的设备。我们过去曾广泛研究推理问题。具体而言，我们定义了各种类型的推理策略，并开发了处理某些类型推理策略的推理控制器 [[THUR1993](#ch18.xhtml#ref18_35)]。

关于构建推理控制器以保护数据机密性的早期工作描述于 20 世纪 80 年代末和 90 年代初 [[THUR1987](#ch18.xhtml#ref18_32), [THUR1993](#ch18.xhtml#ref18_35)]；然而，这些工作主要集中在多级安全数据库领域，且支持的推理能力有限。通过使用语义 Web 技术，我们目前的工作在更复杂的推理和策略表示技术方面，较先前的工作有了实质性改进 [[THUR2014](#ch18.xhtml#ref18_36)]。我们使用 `资源描述框架 (RDF)` 作为数据模型，它支持具有不同数据模式的多数据库的互操作性。此外，我们使用语义 Web 规则和约束来表示策略和规则，并使用语义 Web 软件工具（如 `Pellet`、`Jena` 和 `Protégé`）对数据项及其之间的关系进行分类 [[SIRI2007](#ch18.xhtml#ref18_30), [CARR2004](#ch18.xhtml#ref18_5), [KNUB2004](#ch18.xhtml#ref18_19)]。

我们的工作重点在于对溯源数据进行分类和保护，溯源数据是一种元数据，它记录了感兴趣的单个数据项的来源，以及数据操纵操作和时间信息等其他相关信息 [THUR2014]。虽然可以使用任何数据格式来表示溯源，但有时使用有向图布局来可视化其结构会更容易。因此，我们将溯源数据称为有向图，因为有向图结构除了流行之外，在语义 Web 环境的数据建模方面还有许多优势。语义 Web 通过使用形式语义，扩展了 `RDF` 图数据模型，使其具备推理能力。在我们的工作中，我们利用语义 Web 的推理能力来支持推理控制器的推理策略。此外，我们还提出了几种新的查询修改（即重写）技术，可用于在溯源图上强制执行安全策略。

在本章中，我们将讨论采用围绕语义 Web 技术构建的推理策略和技术的推理控制，这些技术可用于社交媒体中的推理控制。我们的工作重点是针对表示为 `RDF` 图的溯源数据的推理控制。由于社交网络数据也可以建模为 `RDF` 图，因此我们的方法可适配于社交网络数据。我们还提供了推理控制器的详细实现。值得注意的是，访问控制是我们推理控制工作的核心。也就是说，我们不仅防止直接访问未经授权的数据，还防止通过推理间接访问未经授权的数据。

## 18.2 推理控制器的设计

### 18.2.1 架构

推理问题的不可解性已在 [[THUR1990](#ch18.xhtml#ref18_33)] 中得到证明。其复杂性仍是一个开放问题。虽然有必要分析推理问题的复杂性类，但大量研究仍围绕基于传统数据库的实现展开。然而，由于溯源具有逻辑图结构，它也可以用图数据模型表示和存储；因此，它不局限于任何特定的数据格式。尽管我们在该设计中的重点是构建基于溯源图表示的推理控制器，但我们的推理控制器也可用于保护传统数据库的情况。此外，使用 `RDF` 数据模型不会给我们的实现带来过多限制，因为其他数据格式均可由 `RDF` 数据模型良好支持。此外，[[BIZE2003](#ch18.xhtml#ref18_2)] 中讨论的工具等可将关系数据转换为 `RDF` 数据。

我们的架构接收用户的输入查询，并返回一组经过用户定义的策略约束修剪后的响应。我们假设用户可以与我们的系统交互以获取传统数据和溯源数据。然而，由于我们的重点是保护溯源，我们将更多地关注推理控制器和溯源数据层的设计。

在我们的设计中，我们假设可用信息分为两部分：实际数据和溯源。数据和溯源均表示为 `RDF` 图。读者应注意，我们不对实际信息的存储方式做任何假设。用户可能将数据和溯源存储在两个不同的三元组存储中，也可能存储在同一个存储中。用户应用程序可以提交查询以访问数据及其关联的溯源，反之亦然。[图 18.2](#ch18.xhtml#fig18_2a) 展示了我们的设计以及基于溯源数据的推理控制器原型实现中的一些模块。我们现在介绍图 18.2 中的模块。

#### 18.2.1.1 用户界面管理器

用户界面管理器负责处理用户请求、认证用户并向用户提供合适的响应。界面管理器还提供了一个抽象层，允许用户与系统交互。因此，用户可以向该层提交数据查询或溯源查询。用户界面管理器还确定查询应针对传统数据还是溯源数据进行评估。

#### 18.2.1.2 策略管理器

策略管理器负责确保查询用户有权使用系统。它根据用户的查询和相关的查询结果评估策略，以确保不会向未经授权的用户发布机密信息。策略管理器可以针对传统数据或溯源数据强制执行策略。每种数据类型可能有自己的策略管理器；例如，传统数据的存储格式可能与溯源数据不同。因此，我们可能需要每个策略管理器的不同实现。
