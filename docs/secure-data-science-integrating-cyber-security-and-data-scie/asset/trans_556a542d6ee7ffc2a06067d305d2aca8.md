

# COVID-19 大流行：数据科学、隐私与公民自由

COVID-19 大流行是自西班牙流感（据推测起源于堪萨斯州）以来一个世纪中最严重的一次。自那时起，世界经历了许多战争，包括第二次世界大战等，其他大流行如 SARS 和猪流感，恐怖袭击如美国的 9/11 和英国的 7/7，以及卡特里娜和玛丽亚等飓风。但从未有过像现在这样，因 COVID-19 导致整个世界都陷入恐惧之中。这是一场噩梦，令一个世纪以来发生在我们身上的一切其他事情都相形见绌。我们不敢外出，生怕感染病毒并因此丧命，然而日夜宅家又让我们坐立不安、抑郁和/或焦虑。

此案中唯一的亮点是技术。得益于技术，我们得以居家办公。`ZOOM`、`WebEx`、`Blue Jean` 和 `Teams` 等视频会议技术极大地帮助我们不仅参加项目会议，还能参与会议和专题讨论，以及与家人朋友社交。正是技术让我们保持了理智。与此同时，技术，尤其是数据科学和人工智能（`DS/AI`），正帮助检测并可能预防 COVID-19 的传播。此外，`DS/AI` 还协助疫苗研发，这是解决大流行的终极方案。虽然 `DS/AI` 在大流行期间帮助人类生存，但也存在问题。这是因为数据收集、数据存储、数据分析和数据共享是大流行解决方案的核心。但这种数据密集型活动也可能导致严重的隐私侵犯。也就是说，如果个人数据落入坏人之手，就会侵犯个人隐私，进而造成巨大危害，如被保险公司列入黑名单或被对手勒索。虽然隐私对个人至关重要，但医护人员必须收集尽可能多的信息来治疗 COVID-19 患者。因此，我们需要在安全与隐私之间取得平衡。

本章探讨利用 `DS/AI` 检测和预防 COVID-19，同时探讨如何保护个人隐私。它在 9/11 袭击与 COVID-19 大流行之间划出了相似之处。早在 2002 年，我们发表了一篇题为“数据挖掘、国家安全、隐私与公民自由”的论文，论证了反恐需要数据挖掘，同时也讨论了数据隐私带来的侵犯问题 [THUR2002a]。今天，我们面临着与 COVID-19 大流行类似的局面。

## 14.2 数据挖掘、国家安全、隐私与公民自由

我们开展了将数据挖掘应用于反恐问题的研究 [THUR2003]。同时，我们也调查了数据挖掘的隐私影响 [[THUR2005](#ch14.xhtml#ref14_15)]。为理解国家安全与大流行之间的相似性，我们将回顾 [THUR2002a] 中的一些讨论。虽然从技术角度看有许多相似之处，但从社会角度看也存在一些差异。

数据挖掘是对大量数据提出查询并提取通常未知的知识块的过程 [[THUR1998](#ch14.xhtml#ref14_8)]。随着大数据技术的出现，数据挖掘已演变为数据科学，而现在随着机器学习的突出，它被视为 AI 的一部分。尽管如此，数据挖掘在 9/11 后获得了极大的关注，当时人们极有兴趣收集各种个人数据并应用数据挖掘技术，以判断他们是否从事恐怖活动。例如，系统会结合个人的所有关联及其行为模式，来判断该人是否可疑。

这在隐私倡导者和 ACLU（美国公民自由联盟）中引起了极大担忧。隐私倡导者非常担心数据挖掘可能产生的假阳性，导致无辜者被贴上恐怖分子的标签。也有人担心数据挖掘带来虚假的安全感，以及以国家安全之名牺牲公民自由是否值得。

随后，关于结合数据挖掘与隐私的研究活跃开展，隐私保护数据挖掘领域的首篇论文发表 [[AGRA2000](#ch14.xhtml#ref14_1)]。其思路是向数据中引入扰动和随机化，然后进行数据挖掘，同时确保最终结果不变。这样，个人数据值就能对想获取个人数据的对手隐藏起来。初始工作集中在隐私保护关联规则挖掘，随后演进为解决包括决策树在内的各类数据挖掘技术 [[LIU2009](#ch14.xhtml#ref14_6)]。

关于数据挖掘、国家安全和隐私进行了许多辩论和专题讨论 [[THUR2002b](#ch14.xhtml#ref14_10), [THUR2002c](#ch14.xhtml#ref14_11), [THUR2002d](#ch14.xhtml#ref14_12), [THUR2002e](#ch14.xhtml#ref14_13)]。我们需要在数据挖掘、国家安全和隐私之间做出权衡，且政策应指导数据挖掘过程。更多细节将在后续章节及 [[THUR2015](#ch14.xhtml#ref14_16)] 中给出。

## 14.3 用于 COVID-19 检测与预测的数据科学

在过去十年中，数据挖掘结合统计学和大数据已演变为数据科学。同时，机器学习作为一个领域迅猛发展，导致 AI 获得极大关注。我们将交替使用数据科学和机器学习这两个术语，而 AI 超越机器学习，还包括规划和推理等。
