

# 流分析用于新颖类别检测

在本章中，我们将讨论什么是流分析（我们也将其称为流挖掘），并讨论一种用于检测新颖类别的方法。我们将描述检测新颖类别的算法和系统架构。我们给出新颖类别和现有类别的定义。然后我们陈述新颖类别检测算法所依据的假设。我们通过一个例子说明*新颖类别*的概念，并介绍几个术语，如“已用”空间和“未用”空间。然后我们讨论新颖类别检测过程中的三个主要部分，它们是：(i) 在训练期间保存*已用*空间的清单，(ii) 异常值检测和过滤，以及 (iii) 计算异常值之间的内聚性并将异常值与训练数据分离。我们还将展示如何通过使用聚类进行原始数据缩减来使该技术变得高效。

最后，我们在多个合成和真实数据集上评估我们提出的方法，并报告四个数据集的结果。其中我们报告结果的两个数据集是合成的，另外两个是真实的基准数据集。第一个合成数据集仅模拟概念漂移。我们使用该数据集进行评估，以表明我们的方法能够正确区分概念漂移和新颖类别。第二个合成数据集同时模拟概念漂移和概念演化。我们使用的两个基准数据集是 KDD Cup 1999 入侵检测数据集和森林覆盖类型数据集，两者在数据流分类文献中均被广泛使用。每个合成和真实数据集均包含大于或等于 250,000 个数据点。

我们将结果与两种基线技术进行比较。对于每个数据集和每种基线技术，我们报告总体错误率、被误分类为现有类别的新颖实例百分比，以及被误分类为新颖类别的现有类别实例百分比。此外，我们还报告每种基线技术在每个数据集上的运行时间。在所有数据集上，我们的方法在分类准确率和误检率方面均优于基线技术。我们的方法在运行时间方面也优于基线技术。以下各节将详细讨论结果。

## 7.2 流挖掘

### 7.2.1 架构

我们提出了一种创新的方法来检测新颖类别。它在几个方面不同于传统的新颖性（或异常/离群值）检测技术。首先，传统的新颖性检测技术[[MARK2003](#ch07.xhtml#ref7_4)、[ROBE2000](#ch07.xhtml#ref7_7)、[YEUN2002](#ch07.xhtml#ref7_13)] 通过假设或建立正常数据模型，并简单地将偏离“正常”点的数据点识别为离群值/异常值来工作。但我们的目标不仅是检测单个数据点是否偏离正常性，还要发现一组离群值之间是否存在强关联。其次，传统的新颖性检测器可以被视为“单类”模型，它仅区分正常和异常数据，但无法区分两种不同类型的异常。但我们的模型是“多类”模型，意味着它可以区分不同类别的数据，同时可以检测新颖类别数据的存在，这是传统分类器与新颖性检测器的独特结合。

我们的技术通过自适应集成分类方法处理概念漂移，该方法维护一个包含 `M` 个分类器的集成 `L`，用于对未标记数据进行分类。数据流被划分为大小相等的块，以便每个块可以容纳在内存中并在线处理。一旦数据块被标记，我们立即从中训练一个分类模型。如果有必要，新训练的模型将替换集成中的现有模型之一。因此，集成不断演化，反映流中最新的概念。

我们新颖类别检测技术的核心概念是每个类别必须具有一个重要属性：属于同一类别的数据点应该彼此更接近（内聚性），并且应该远离属于其他类别的数据点（分离性）。每当一个新的数据块出现时，我们首先检测那些与训练数据*良好分离*的测试实例（即离群值）。然后应用过滤以移除可能由概念漂移导致的离群值。最后，如果我们在这些过滤后的离群值中发现强内聚性，我们就宣布发现了一个新颖类别。当新颖类别的真实标签到达并使用标记实例训练新模型时，现有集成将用该模型进行更新。因此，模型集成不断地通过新类别得到丰富。我们的架构如[图 7.2](#ch07.xhtml#fig7_2a)所示。

![图 7.2 架构。](images/fig7_2.jpg)

[图 7.2 架构。](#ch07.xhtml#Ffig7_2)

我们假设数据流被划分为大小相等的块。该系统的核心是一个包含 `M` 个分类器的集成 `L`：`{L[1], …, L[M]}`。当一个新的未标记数据块到达时，集成被用于检测该块中的新颖类别。如果检测到新颖类别，则识别出属于该新颖类别的实例并相应地进行标记。该块中所有其他实例，即未被识别为新颖类别的实例，使用多数投票进行分类。一旦数据块被标记，它就被用来训练一个分类器，该分类器替换集成中的现有分类器之一。在训练期间，我们创建*已用*空间的清单。

我们有几项贡献。首先，我们提供了对新颖类别特征的详细理解，并提出了一种新技术，该技术可以在数据流存在概念漂移的情况下检测新颖类别。其次，我们建立了一个框架，用于将新颖类别检测机制融入传统分类器中。最后，我们将该技术应用于合成和真实世界数据，获得了比最先进的流分类算法好得多的结果。
