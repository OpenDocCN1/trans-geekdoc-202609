# 14 数据科学、COVID-19 大流行、隐私与公民自由

DOI: [10.1201/9781003081845-22](https://doi.org/10.1201/9781003081845-22)

## 14.1 简介

虽然前两章讨论了更通用应用的安全和隐私问题，但本章侧重于一个特定应用，即一般医疗保健，特别是 COVID-19 大流行。在许多方面，我们将 COVID-19 大流行相关的安全和隐私问题与 9/11 恐怖袭击和反恐怖主义进行了类比。在 2000 年代初期，我们的工作侧重于将数据挖掘应用于反恐怖主义以及可能发生的隐私侵犯 [[THUR2002a](#ch14.xhtml#ref14_9), [THUR2003](#ch14.xhtml#ref14_14)]。在本章中，我们探讨针对 COVID-19 大流行的此类问题。主要原因之一是，虽然恐怖主义在 2000 年代初期是最重要的公共安全关注点之一，但 COVID-19 大流行是 2020 年代初期最重要的公共安全关注点。
