
# 对抗学习模型

对抗学习问题通常被建模为两个对手之间博弈的游戏。Brückner 和 Scheffer 将对抗预测问题建模为 Stackelberg 博弈 [[BRUC2011](#ch10.xhtml#ref10_3)]。为保证最优性，该模型假设对手行为理性。然而，它并不要求存在唯一均衡。Kantarcioglu 等人 [[KANT2011](#ch10.xhtml#ref10_12)] 将该问题视为序贯 Stackelberg 博弈。他们假设双方玩家都知道彼此的收益函数。他们使用模拟退火算法和遗传算法来搜索纳什均衡。随后，该均衡被用于选择能带来良好均衡性能的最优属性集。提出了采用纳什策略的改进模型 [[BRUC2009](#ch10.xhtml#ref10_2), [LIU2010](#ch10.xhtml#ref10_17)]。

其他博弈论模型采用零和极大极小策略。Globerson 和 Roweis [[GLOB2006](#ch10.xhtml#ref10_9)] 考虑了测试时某些特征可能缺失的问题。这与对抗学习相关，因为对手可能会简单地删除恶意数据中权重较高的特征，以增加其逃避检测的机会。他们开发了一个博弈论框架，在该框架中构建的分类器在最坏情况下是最优的。他们的思路是防止对任何单一特征分配过大的权重。他们使用支持向量机模型，当最多可删除 *K* 个特征时，该模型能最优地最小化合页损失。El Ghaoui 等人 [[GHAO2003](#ch10.xhtml#ref10_8)] 将极大极小模型应用于由超矩形界定的训练数据。他们的模型最小化给定区间内数据的最坏情况损失。针对处理分类时噪声的其他鲁棒学习算法也被提出 [[DEKE2008](#ch10.xhtml#ref10_5), [DEKE2010](#ch10.xhtml#ref10_6), [LANC2002](#ch10.xhtml#ref10_14), [TEO2007](#ch10.xhtml#ref10_23)]。

我们的工作在几个方面与现有工作不同。首先，我们不对任一方玩家已知的信息做强假设。其次，我们将广域攻击和定向攻击均纳入 SVM 学习框架中进行考量。最后，我们研究了极大极小解在广泛参数范围内面对攻击时的鲁棒性。

## 10.3 我们的方法

虽然我们方法的细节将在本章后面讨论，但本节将提供我们方法的概述。我们方法背后的思想是：对手试图尽可能多地了解我们所使用的数据以及模型。基于对手所学到的知识，它将试图挫败我们的模型，使自己不被捕获。因此，采用 SVM 方法时，对手试图将尽可能多的实例推向“良性”类别。这样，我们的模型就会将一些恶意实例视为良性实例。为了对抗对手的这种行为，我们尝试移动 SVM 分界线。我们在考虑多种因素后这样做，详见 [10.3 节](#ch10.xhtml#sec10_3) 和 [10.4 节](#ch10.xhtml#sec10_4)。此外，移动分界线的方式取决于我们所考虑的攻击模型。当我们移动分界线时，一些伪装成良性实例的恶意实例将显露为恶性实例。

在后续章节中，我们将介绍攻击模型以及基于 SVM 的学习模型的关键点。更多细节请见 [ZHOU2012]。我们讨论两种攻击模型：自由范围攻击模型和受限攻击模型。在自由范围攻击模型中，对手可以将恶意数据移动到特征空间中的任意位置。在受限攻击模型中，对手只能将恶意数据移动得更接近目标点。

## 10.4 问题与攻击

### 10.4.1 问题定义

用以下符号表示样本集：

```
{(x[i], y[i]) ∈ (X, Y)}[i = 1]^(n), where x[i] is the i^(th) sample and y[i] ∈ {−1, 1} is its label, X ⊆ ℝ^(d)
```

是一个 *d* 维特征空间，*n* 是样本总数。我们考虑一个对抗学习问题，其中对手修改恶意数据以逃避检测，从而达到其预谋目标。对手有自由仅通过向 `x[i] | y[i] = 1` 添加非零位移向量 *δi*，沿任意方向移动恶意数据（*y[i] = 1*）。也就是说，目标是学习一个假设 *H*，使其能抵御通过添加非零位移向量 *δ* 来修改恶意数据的对抗攻击。例如，在垃圾邮件过滤中，对手可能向垃圾邮件添加正常词汇以击败垃圾邮件过滤器。另一方面，对手将无法修改合法邮件。

我们不对对手对学习系统的了解做具体假设。相反，我们仅假设修改恶意数据存在权衡或成本。例如，对手常采用的一种实用策略是，在特征空间中将恶意数据移动到尽可能接近良性数据频繁出现的位置。然而，对手只能在不完全丧失恶意数据效用的前提下修改其位置。如果对手在特征空间中将数据点移离其自身类别太远，可能不得不牺牲原始数据点的大量恶意效用。例如，在信用卡欺诈检测问题中，攻击者可能选择用被盗信用卡消费“合适”的金额来模仿合法购买。这样做会让攻击者损失一些潜在利润。

### 10.4.2 对抗攻击模型

我们提出两种攻击模型：*自由范围* 和 *受限*，每种模型都对对手已知信息的程度做出了简单且现实的假设。这两种模型在以下方面的含义不同：(i) 对手对良性数据的了解程度，以及 (ii) 因修改恶意数据而导致的效用损失。*自由范围* 攻击模型假设对手有自由将数据移动到特征空间中的任意位置。*受限* 攻击模型是一种更保守的攻击模型。该模型基于这样的直觉构建：对手不愿让数据点在特征空间中偏离其原始位置太远。原因是较大的位移往往意味着恶意效用的损失。
