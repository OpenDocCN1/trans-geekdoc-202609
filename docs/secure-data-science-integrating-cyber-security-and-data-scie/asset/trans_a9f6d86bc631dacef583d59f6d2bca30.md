

## 11.4.4 训练问题

在训练过程中，我们需要迭代更新三个参数：权重 `w`、超参数 `α` 和核参数向量 `η`。更新这些参数的一种方法是同时优化 `w|α` 和 `η`。这使我们能够找到最优解，但计算量会很大。另一种方法是交替更新 `w`/`α` 和 `η`。对于每一个 (`w`，)，我们基于对数似然的梯度搜索 `Δη` 的几个步骤，并通过向 `η` 添加 `τ · Δη` 来更新它，其中 `τ` > 0 为动量。这种方法可能无法得到期望的解，但效率更高。在本章中，我们采用局部更新方法。我们训练多个对抗 RVM 模型，并选择满足 `u`[+] < `ρ` · `u`[−] 的 `M` 个模型，其中 `u`[+] 表示预测正训练实例的不确定性，`u`[−] 表示预测负训练实例的不确定性，`ρ` ∈ (0, 1] 为正常数。比率

```
ρ = u₊ / u₋,
```

越小，决策边界距离正训练样本越远。也就是说，当集成中的分类器数量少于 `M` 时，通过学习 `w`/`α` 和 `η` 来训练一个对抗 RVM 分类器 `h`[i]；然后如果满足

```
u₊ < ρ · u₋
```

则将 `h`[i] 加入集成。

不确定性 `u`[+] 和 `u`[−] 分别在正、负训练数据上按如下方式估计：

```
u₊ = (Σᵢ yᵢ · (1 - h(xᵢ; w))) / Σᵢ yᵢ          (11.4)
```

```
u₋ = (Σᵢ (1 - yᵢ) · h(xᵢ; w)) / Σᵢ (1 - yᵢ)    (11.5)
```

其中

```
Σᵢ yᵢ
```

为正训练实例的总数，

```
Σᵢ (1 - yᵢ)
```

为负训练实例的数量。我们选择 `M` 个这样的模型并将它们组合起来，通过多数表决进行最终预测。

### 11.4.5 对抗 RVM 学习算法

我们现在介绍对抗 RVM 学习算法，即 `AD-RVM`。给定一组训练数据，我们首先初始化 `α` 的值并用它来更新权重向量 `w`；接下来，在给定 `w` 和 `α` 的情况下更新核参数向量 `η`；最后更新超参数 `α`。该过程迭代预定义的最大轮数。我们训练多个此类分类器，并选择满足 `ρ u`[+] < `u`[−] 的 `M` 个分类器组成集成。详细算法见 [算法 11.1](#ch11.xhtml#alg11_1)。

## 11.5 实验结果

### 11.5.1 数据集

我们在实验中使用了一个人工数据集和两个真实数据集。我们通过将正测试实例移向随机选择的负实例并加上局部随机噪声，来建模分类时的攻击。针对测试数据的攻击旨在以日益增加的难度级别挑战所有学习模型。难度通过攻击因子 `f`[attack] 来控制。更具体地说，

```
xᵢⱼ⁺ = xᵢⱼ⁺ + f[attack] · (xᵢⱼ⁻ - xᵢⱼ⁺) + ε    (11.6)
```

其中 `ε` 为局部随机噪声。注意 `f`[attack] = 1 模拟了最坏情况的攻击，即正数据点在局部随机噪声范围内任意接近负数据点。[图 11.3](#ch11.xhtml#fig11_3a) 示出了 `f`[attack] = 0.3 时的攻击情况。

![图 11.3 攻击因子 = 0.3。白点：负数据，黑点：攻击前的正数据，黑色“+”：攻击后的正数据。](images/fig11_3.jpg)

[图 11.3 攻击因子 = 0.3。白点：负数据，黑点：攻击前的正数据，黑色“+”：攻击后的正数据。](#ch11.xhtml#Ffig11_3)

我们在三个数据集上对比了四种学习模型：`AD-RVM`、`RVM`、`SVM` 和 `One-class SVM`。所有报告的结果均为 10 次随机运行的平均值。

