## 6.5 大数据分析

前几节讨论了用于恶意软件检测的数据挖掘技术。特别是我们讨论了针对恶意可执行文件的数据挖掘。在现实世界中，待分析的网络安全数据量可能是巨大的。也就是说，待分析的数据量可能达到 EB 级别。因此，传统的数据挖掘技术可能无法扩展以处理超大数据集。我们需要大数据分析技术来处理如此海量的数据。

[图 6.7](#ch06.xhtml#fig6_7a) 展示了大数据分析技术在网络安全应用中的使用。我们本质上描述了一种三层架构。具体而言，我们使用大数据管理系统（如 `HBase`、`Cassandra` 和 `CouchDB`）作为中间层，以存储海量数据。这些数据管理系统托管在大数据基础设施上，如 `Hadoop`、`MapReduce` 和 `Spark`。分析技术（如 `SVM`（支持向量机）和神经网络）在大数据基础设施上实现。这样，分析过程就可以扩展以处理超大数据集。

## 6.6 总结与展望

在本工作中，我们设计并开发了一种基于数据挖掘的恶意代码检测模型。我们的技术从可执行文件中提取三个不同层级的特征，即二进制层级、汇编层级和 `API` 函数调用层级。这些特征随后经历特征选择阶段，以减少特征集中的噪声和冗余，并生成一个规模可控的特征集。然后使用这些特征集为每个训练数据构建特征向量。接着使用训练数据训练一个分类模型。该分类模型对未来实例（即可执行文件）进行分类，以检测它们是良性还是恶意。

我们展示了如何高效地从训练数据中提取特征。我们还展示了如何利用磁盘访问实现可扩展性。我们解释了特征提取和特征选择的算法，并分析了它们的时间复杂度。最后，我们展示了如何组合特征集并构建特征向量。我们应用了不同的机器学习技术，如 `SVM`、`J48` 和 `AdaBoost` 来构建分类模型。在下一章中，我们将展示我们的方法在不同数据集上与几种基线技术相比的表现。

我们还描述了在两个不同数据集上对我们的方法和其他几种基线技术进行的实验。我们比较了每种基线技术的分类准确率和运行时间。我们证明了我们的方法在分类准确率上优于其他基线技术，且没有主要的性能下降。我们还分析了不同分类技术和不同数据集上的结果变化，并解释了这些变化。总体而言，我们的方法优于其他基线，不仅因为更高的分类准确率，还因为其可扩展性和效率。
