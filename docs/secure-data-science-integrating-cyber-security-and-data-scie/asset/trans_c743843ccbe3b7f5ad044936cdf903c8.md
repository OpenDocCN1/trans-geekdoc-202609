正如近期关于社交网络安全的研究所示，保护社交网络中的资源要求我们修订传统的访问控制模型和机制。然而，目前提出的方法仅关注访问控制策略，即调节对 OSN 资源访问的问题。我们认为这还不够，因为社交网络场景的复杂性要求定义除标准访问控制策略之外的进一步安全策略。在本节中，我们概述了我们框架支持的安全策略。

### 17.4.2 访问控制策略

该框架支持访问控制策略，以调节 OSN 参与者如何访问资源。特别地，支持的访问控制策略是基于我们之前的工作 [CARM2009b] 定义的。在这里，授权用户是根据网络中节点间现有关系的类型、深度和信任级别来表示的。例如，访问控制策略可以规定：被授权访问给定资源的 OSN 参与者仅限于那些与资源所有者具有直接或间接友谊关系的人，前提是该关系具有给定的信任值。然而，所提框架支持的访问控制策略相较于 [CARM2009b] 中提出的策略有一些显著改进。这些改进主要归因于我们的访问控制策略是根据 [17.3 节](#ch17.xhtml#sec17_3) 中描述的 SNKB 定义的。这意味着访问控制策略的对象、主体和权限是通过利用资源、用户和动作的语义建模来定义的。特别地，正如将在 [17.5 节](#ch17.xhtml#sec17_5) 中解释的那样，访问控制策略被定义为基于表示 [17.3 节](#ch17.xhtml#sec17_3) 中引入概念的本体的规则。因此，我们不再是针对 OSN 的每个单个参与者和资源指定访问控制策略，而是能够直接在 OSN 语义概念上指定访问控制策略。确实，可以通过简单地将 `Photo` 类指定为受保护对象，来规定一个通用的访问控制策略，即照片只能由朋友访问。因此，该访问控制策略将应用于 `Photo` 类的所有实例，即所有照片，从而极大地简化了策略管理。在语义概念上指定访问控制策略的另一个好处是，可以利用概念上定义的层次结构自动传播访问控制策略。例如，就资源而言，如果 `Photo` 已被定义为具有一些子类，比如 `PrivatePhoto` 和 `HolidaysPhoto`，则前述访问控制策略可以自动应用于属于 `Photo` 任何子类的所有实例。访问控制策略也可以沿其他维度传播，即根据其他 OSN 概念本体中指定的层次结构（例如，关系类型和动作的本体）。例如，如果支持的关系本体为友谊关系定义了一个层次结构，则前述访问控制策略将传播到资源所有者拥有任何类型友谊关系的所有 OSN 参与者。如果动作本体定义了动作的层次结构，也会出现类似的传播。注意，在 [CARM2009b] 中，授权主体也是基于用户关系而非列出特定实例（即人员 ID）来定义的。然而，在那项工作中策略传播是不可能的，因为没有在资源、关系和动作上定义层次结构。此外，本章提出的语义建模使我们能够不仅根据用户应与资源所有者具有的关系（如 [CARM2009b] 中那样），还根据他们应与资源具有的关系来指定授权用户。因此，例如，可以指定一个访问控制策略，声明所有被标记在某张照片上的 OSN 参与者都被授权访问该照片。在 [CARM2009b] 以及所有其他现有的 OSN 模型中，指定这种访问控制策略的唯一方法是为每个被标记在照片上的 OSN 参与者显式指定一个不同的访问控制策略。

### 17.4.3 过滤策略

在 OSN 中，用户可以发布内容非常异构的信息，范围从家庭照片到成人导向内容。从这个意义上说，OSN 中出现的访问控制问题类似于我们在 Web 中遇到的问题，即不适当信息的可用性可能对某些用户（例如年轻人）有害。为了保护用户免受不适当或不想要的内容侵害，我们引入了*过滤策略*，通过它可以指定当给定用户浏览社交网络页面时，哪些数据必须被过滤掉。通过过滤策略，例如可以规定：从用户 Alice 获取的 OSN 页面中，必须移除所有非由 Alice 的直接朋友发布的视频。与访问控制策略类似，过滤策略被定义为基于表示 [17.3 节](#ch17.xhtml#sec17_3) 中引入概念的本体的规则（参见 [17.5 节](#ch17.xhtml#sec17_5)）。这意味着在过滤策略的情况下也可以进行策略传播。过滤策略的另一个相关方面与指定策略的用户（即授予者）有关。确实，在我们的框架中，过滤策略可以通过两种不同的方式指定。根据第一种方式，过滤策略由用户指定，以声明她不想访问哪些信息，即从她获取的 OSN 页面中必须过滤掉哪些数据。因此，在这种情况下，授予者和策略适用的用户（即目标用户）是同一个。这些策略陈述了用户关于想要访问的内容的偏好，因此被称为*过滤偏好*。然而，我们也支持目标用户和授予者不同的过滤策略的指定。这种过滤策略使授予者能够指定目标用户获取的 SN 页面必须如何被过滤。通过这些过滤策略，授予者可以*监督*目标用户可以访问的内容。在这种情况下，我们将过滤策略称为*受监督过滤策略*。这在像 OSN 这样的开放环境中代表了一个极其有用的功能。例如，父母可以指定一个受监督过滤策略，声明她的孩子不得访问那些未被父母自己信任的用户发布的视频。稍后将更清楚地看到，语义技术极大地促进了此类策略的指定。
