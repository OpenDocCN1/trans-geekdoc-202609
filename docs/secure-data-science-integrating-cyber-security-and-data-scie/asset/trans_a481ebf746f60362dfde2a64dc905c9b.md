
# 15.5.6 MapReduce Join 执行

在本节中，我们将讨论如何利用 Hadoop 的 MapReduce 框架实现回答 SPARQL 查询所需的连接操作。`算法 15.1` 确定了回答一个查询所需的作业数量。它返回一个有序的作业集合。每个作业都有关联的输入信息。我们 MapReduce 框架的作业处理组件按有序集合中出现的顺序运行这些作业。一个作业的输出文件是下一个作业的输入文件。最后一个作业的输出文件包含查询的答案。

## 列表 7：LUBM 查询 2

```
SELECT ?X, ?Y, ?Z WHERE {
?X rdf:type ub:GraduateStudent.
?Y rdf:type ub:University.
?Z rdf:type ub:Department.
?X ub:memberOf ?Z.
?Z ub:subOrganizationOf ?Y.
?X ub:undergraduateDegreeFrom ?Y }
```

`列表 7` 展示了 LUBM 查询 2，我们将用它来说明我们如何使用 map 和 reduce 方法进行连接。该查询有六个三元组模式，并在变量 `X`、`Y` 和 `Z` 上存在九个连接。

我们的输入选择算法选择文件 `type_GraduateStudent`、`type_University`、`type_Department`、所有具有前缀 `memberOf` 的文件、所有具有前缀 `subOrganizationOf` 的文件，以及所有具有前缀 `underGraduateDegreeFrom` 的文件，作为回答查询所需作业的输入。

查询计划包含两个作业。在作业 1 中，第 2、5、7 行的三元组模式在 `X` 上连接，第 3、6 行的三元组模式在 `Y` 上连接。在作业 2 中，第 4 行的三元组模式与前两个连接的输出在 `Z` 上连接，同时作业 1 的连接输出在 `Y` 上连接。

作业 1 的输入文件包括 `type_GraduateStudent`、`type_University`、所有具有前缀 `memberOf` 的文件、所有具有前缀 `subOrganizationOf` 的文件，以及所有具有前缀 `underGraduateDegreeFrom` 的文件。在 map 阶段，我们首先对输入值（实际上是输入文件的一行）进行分词。然后，我们检查输入文件名，如果输入来自 `type_GraduateStudent`，我们输出一个键值对，其键为带有前缀 `X#` 的主语 URI，值为标志字符串 `GS#`。该值作为标志，指示该键的类型为 GraduateStudent。主语 URI 是分词器返回的第一个标记。同样，对于来自文件 `type_University` 的输入，输出一个键值对，其键为带有前缀 `Y#` 的主语 URI，值为标志字符串 `U#`。如果输入来自任何具有前缀 `memberOf` 的文件，我们通过分词器从输入行中检索主语和宾语，并输出一个键值对，其键为带有前缀 `X#` 的主语 URI，值为带有前缀 `MO#` 的宾语值。对于来自具有前缀 `subOrganizationOf` 的文件的输入，我们输出键值对，将带有前缀 `Y#` 的宾语作为键，带有前缀 `SO#` 的主语作为值。对于来自具有前缀 `underGraduateDegreeFrom` 的文件的输入，我们输出键值对，将带有前缀 `X#` 的主语 URI 作为键，带有前缀 `UDF#` 的宾语值作为值。因此，我们根据连接的变量将主语或宾语作为 map 输出键。这就是为什么对于具有前缀 `subOrganizationOf` 的文件中的三元组，将宾语作为键的原因，因为连接变量 `Y` 在第 6 行的三元组模式中是宾语。对于所有其他输入，主语被作为键，因为连接变量 `X` 和 `Y` 在第 2、3、5 和 7 行的三元组模式中是主语。

在 reduce 阶段，Hadoop 将单个键的所有值分组，并为每个键提供该键和一个值集合的迭代器。通过查看前缀，我们可以立即判断它是 `X` 的值还是 `Y` 的值，这归功于我们使用的前缀。无论哪种情况，我们都使用相同的键输出一个键值对，并将所有值连接起来形成一个字符串值。因此，在此 reduce 阶段之后，`X` 上的连接已完成，`Y` 上的连接部分完成。

作业 2 的输入文件是 `type_Department` 文件和作业 1 的输出文件 `job1.out`。与作业 1 的 map 阶段类似，在作业 2 的 map 阶段，我们也对输入值（实际上是输入文件的一行）进行分词。然后，我们检查输入文件名，如果输入来自 `type_Department`，我们输出一个键值对，其键为带有前缀 `Z#` 的主语 URI，值为标志字符串 `D#`。如果输入来自 `job1.out`，我们查找带有前缀 `Z#` 的值。我们将该值作为输出键，并将其余值连接成一个字符串作为输出值。基本上，我们将 `Z#` 值作为键以便在 `Z` 上进行连接。

在 reduce 阶段，我们知道键是 `Z` 的值。值集合包含两类字符串。一类包含 `X` 值（即研究生的 URI）以及他们获得本科学位的 `Y` 值。`Z` 值（即键）可能是也可能不是 `Y` 值的 `subOrganizationOf`。另一类字符串仅包含 `Y` 值（即大学），`Z` 值是这些大学的子组织。我们遍历值集合，然后根据 `Y` 值连接这两类元组。从连接输出中，我们找到包含 `X`、`Y` 和 `Z` 值的结果元组。
