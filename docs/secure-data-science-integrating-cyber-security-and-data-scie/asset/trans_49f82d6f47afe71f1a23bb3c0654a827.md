

### 4.3.1 云部署与服务模型

正如[[CLOUD]](#ch04.xhtml#ref4_21)所述，云计算以服务的形式提供计算，而在传统计算中，计算是以产品的形式提供的。因此，用户根据按需付费模型为服务付费。云提供的服务可能包括硬件服务、系统服务、数据服务和存储服务。云用户无需知道软件和数据位于何处；也就是说，云提供的软件和数据服务对用户是透明的。NIST 将云计算定义为[[NIST]](#ch04.xhtml#ref4_51)：

> 云计算是一种模型，用于实现普遍、便捷、按需的网络访问，进入可配置的计算资源共享池（例如网络、服务器、存储、应用和服务），这些资源能够以最少的管理工作量或服务提供商交互迅速地供给和释放。

云模型由多种部署模型和服务模型组成。下文将描述这些模型。

#### 4.3.1.1 云部署模型

云计算有多种部署模型。这些包括公有云、社区云、混合云和私有云。在公有云中，服务提供商通常通过万维网（WWW）提供可供公众访问的服务。此类云可能提供免费服务或按需付费服务。在社区云中，一组组织聚在一起开发云。这些组织可能有共同目标，以提供安全性和容错性等特性。成本由这些组织分担。此外，云可能由这些组织托管，也可能由第三方托管。私有云是专门为某个组织开发的云基础设施。这可以由该组织托管，也可以由第三方托管。混合云由公有云和私有云的组合构成。这样，在混合云中，组织可将私有云用于高度敏感的服务，而将公有云用于不太敏感的服务，并利用万维网（WWW）提供的优势。Kantarcioglu 及其同事指出，混合云是未来的部署模型[[KHAD2012a]](#ch04.xhtml#ref4_41)。[图 4.3](#ch04.xhtml#fig4_3a) 展示了云部署模型。

#### 4.3.1.2 服务模型

如前所述，云计算提供多种服务。这些包括基础设施即服务（IaaS）、平台即服务（PaaS）、软件即服务（SaaS）和数据即服务（DaaS）。在 IaaS 中，云为公众或组织提供一组硬件和网络供使用。用户安装操作系统和软件来运行应用程序。用户将根据其用于计算的资源利用情况进行计费。在 PaaS 中，云提供商将向用户提供系统软件，如操作系统和执行环境。用户将在云提供的硬件和软件基础设施上加载并运行应用程序。在 SaaS 中，云提供商将为用户提供应用程序以供运行。这些应用程序可能是计费应用、税务计算应用和销售工具。云用户通过云客户端访问这些应用程序。在 DaaS 的情况下，云向云用户提供数据。数据可能存储在由云用户访问的数据中心中。请注意，虽然 DaaS 过去用于表示桌面即服务，但最近它更多地表示数据即服务。[图 4.4](#ch04.xhtml#fig4_4a) 展示了服务模型。

### 4.3.2 虚拟化

虚拟化本质上意味着创建虚拟而非实际的事物。它可以是硬件、软件、内存和数据。关于计算领域的虚拟化概念已存在数十年。早在 20 世纪 60 年代，虚拟内存的概念就已被引入。这种虚拟内存给应用程序一种错觉，即拥有连续的工作内存。开发了映射机制，将虚拟内存映射到实际物理内存。

硬件虚拟化是云计算中的一个基本概念。这本质上是在运行着操作系统的真实计算机上创建托管的虚拟机。这意味着，虽然实际机器可能运行着 Windows 操作系统，但通过虚拟化，它可以为用户提供一台 Linux 机器。实际机器称为宿主机，而虚拟机称为客户机。“虚拟机监视器”一词，也称为管理程序，是指在宿主计算机上运行虚拟机的软件。

其他类型的虚拟化包括操作系统（OS）级虚拟化、存储虚拟化、数据虚拟化和数据库虚拟化。在操作系统级虚拟化中，在单个操作系统内创建多个虚拟环境。在存储虚拟化中，逻辑存储从物理存储中抽象出来。在数据虚拟化中，数据从底层数据库中抽象出来。在网络虚拟化中，创建虚拟网络。[图 4.5](#ch04.xhtml#fig4_5a) 展示了各种类型的虚拟化。

![图 4.5 虚拟化类型。](images/fig4_5.jpg)

[图 4.5 虚拟化类型。](#ch04.xhtml#Ffig4_5)

如前所述，云计算的核心在于管理程序或虚拟机监视器的概念。硬件虚拟化技术允许多个操作系统（称为客户机）在宿主计算机上并发运行。这些多个操作系统共享虚拟化的硬件资源。管理程序并非新术语；它最早用于 20 世纪 60 年代中期的 IBM 360/65 机器中。管理程序有不同类型；在一种类型中，管理程序运行在宿主硬件上并管理客户操作系统。流行的虚拟机 VMware 和 XEN 都基于此模型。在另一种模型中，管理程序运行在传统操作系统环境中。虚拟机也被整合到嵌入式系统和移动电话中。嵌入式管理程序具有实时处理能力。虚拟化的一些细节见[[VIRT]](#ch04.xhtml#ref4_70)。

### 4.3.3 云存储与数据管理

在云存储模型中，服务提供商在数据中心为客户存储海量数据。需要存储空间的人将从作为托管公司的服务提供商处租用存储。数据的实际位置对用户透明。呈现给用户的是虚拟化存储；存储管理器将虚拟存储与实际存储映射，并为客户管理数据资源。单个对象（例如客户的整个视频数据库）可能存储在多个位置。每个位置可能存储多个客户的对象。[图 4.6](#ch04.xhtml#fig4_6a) 展示了云存储管理。

![图 4.6 云存储管理。](images/fig4_6.jpg)

[图 4.6 云存储管理。](#ch04.xhtml#Ffig4_6)

虚拟化云存储有许多优势。用户无需购买昂贵的存储设备。数据可放置在云中的任何位置。维护工作（如备份和恢复）由云提供。目标是让用户能快速访问云。然而，由于数据所有者无法完全控制其数据，因此在云中存储数据存在严重的安全顾虑。
