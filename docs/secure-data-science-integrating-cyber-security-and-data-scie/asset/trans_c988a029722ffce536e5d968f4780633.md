
# NoSQL 数据库

NoSQL 数据库是一个统称，本质上指非关系型数据库设计或面向 Web 的可扩展性。它被称为非关系型高性能数据库。NoSQL 数据库的数据模型可能包括图、文档结构和键值对。可以认为，20 世纪 60 年代开发的数据库（如 IBM 的 IMS）以及基于网状数据模型的数据库属于 NoSQL 数据库。然而，20 世纪 90 年代开发的其他面向对象数据模型为 21 世纪 2000 年代 NoSQL 数据库的发展铺平了道路。NoSQL 数据库与旧式的层次型、网状型和对象型数据库的不同之处在于，NoSQL 数据库在设计时就考虑到了 Web 环境。也就是说，目标是在 Web 上快速访问海量数据。

最流行的 NoSQL 数据库模型是键值对。虽然关系型数据库由一组关系组成，其中每个关系包含一组属性，这些属性被标记并包含在模式中。NoSQL 数据库拥有包含两列的表：键和值。键可以是任何内容，例如人名或股票指数。然而，值可以是属性的集合，例如股票名称、股票价值以及其他信息，如是否购买该股票，如果购买，推荐的数量是多少。因此，无需执行多次连接即可检索与某只股票相关的所有信息。本节将讨论一些流行的 NoSQL 数据库（例如 MongoDB 和 HBase）。关于 NoSQL 数据库的详细讨论，请参阅 `[[NOSQ](#ch04.xhtml#ref4_52)]`。更多细节也见于 `[[CATT2011](#ch04.xhtml#ref4_18)]`。

## 4.2.2.4 Google BigTable

BigTable 是运行在 Google 文件系统 (GFS) 之上的早期 NoSQL 数据库之一。它现在作为云端服务提供。BigTable 将行键、列和时间戳映射在一起，形成一个字节数组。也就是说，它本质上是一个基于键值对模型的 NoSQL 数据库。它被设计用于处理 PB 级数据。当数据量过大时，它会使用压缩算法。BigTable 中的每个表都有许多维度，并可能被划分为所谓的“片”以配合 GFS 工作。BigTable 被许多应用程序使用，包括 Google 的 YouTube、Google Maps、Google Earth 和 Gmail。关于 BigTable 的更多细节见于 `[[BIGT](#ch04.xhtml#ref4_14)]`。

## 4.2.2.5 Apache HBase

HBase 是一个开源的非关系型分布式数据库，是为 Hadoop/MapReduce 平台开发的第一个表。也就是说，HBase 是一个基于面向列的键值数据存储模型的 NoSQL 数据库。它用 Java 实现。查询作为 MapReduce 作业执行。它在一定程度上类似于 Google 的 BigTable，并对内存存储使用压缩。HBase 具有可扩展性，可处理数十亿行和数百万列。它还集成了不同格式的多数据存储，并便于稀疏数据的存储。关于 HBase 的更多细节见于 `[[HBAS](#ch04.xhtml#ref4_31)]`。

## 4.2.2.6 MongoDB

MongoDB 是一种 NoSQL 数据库。它是一个跨平台的开源分布式数据库。它被用于存储和管理文档。也就是说，它主要是一个面向文档的数据库。文档以类 JSON 格式存储 `[[CROC2006](#ch04.xhtml#ref4_24)]`。它支持字段查询和范围查询，以及基于正则表达式的搜索。它支持数据复制和负载均衡，后者通过水平扩展实现。数据的批处理以及聚合操作可通过 MapReduce 进行。MongoDB 的更多细节见于 `[[MONG](#ch04.xhtml#ref4_50)]` 和 `[[CHOD2010](#ch04.xhtml#ref4_20)]`。

## 4.2.2.7 Apache Cassandra

Cassandra 是一种 NoSQL 分布式数据库 `[[HEWI2010](#ch04.xhtml#ref4_32)]`。它最初在 Facebook 开发，用于支持 Facebook 应用程序，随后成为 Apache 基金会的开源软件项目。其设计初衷是消除单点故障。它支持跨越多数据中心的集群。集群中的所有节点执行相同的功能。因此，实际上不存在单点故障。它支持复制，具有高度可扩展性。它还具备容错能力，并与 Hadoop 集成，支持 MapReduce。Cassandra 支持的查询语言是 Cassandra 查询语言 (CQL)，这是 SQL 的一种替代方案。也可以通过 Java、C++ 和 Python 等程序访问。Cassandra 的更多细节见于 `[[CASS](#ch04.xhtml#ref4_17)]`。

## 4.2.2.8 Apache CouchDB

正如 `[[COUC](#ch04.xhtml#ref4_23)]` 所述，CouchDB 通过实现 Couch 复制协议来访问数据。该协议已被从集群到 Web 再到移动电话的众多平台实现。它是一个 NoSQL 数据库，用一种名为 Erlang 的并发语言实现。它使用 JavaScript 对象表示法 (JSON) 存储数据，并使用 JavaScript 作为查询语言。关于 CouchDB 的更多细节见于 `[[COUC](#ch04.xhtml#ref4_23)]` 和 `[[ANDE2010](#ch04.xhtml#ref4_7)]`。

## 4.2.2.9 Oracle NoSQL 数据库

Oracle 是主要的关系型数据库供应商之一，自 20 世纪 70 年代末以来一直销售关系型数据库产品。他们在 20 世纪 90 年代提供了对象关系型数据库产品，最近推出了 NoSQL 数据库。该 NoSQL 数据库基于键值对模型。每行有一个唯一键，并具有一个任意长度的值，由应用程序解释。Oracle NoSQL 数据库是一个无共享系统，分布在集群中所谓的多个分片上。数据在分片内的存储节点间复制以保证可用性。数据可通过 Java、C、Python 编写的程序以及 RESTful Web 服务访问。关于 Oracle NoSQL 数据库的更多细节见于 `[[ORAC](#ch04.xhtml#ref4_53)]`。

## 4.2.2.10 Weka

Weka 是一个开源软件产品，实现了一系列数据挖掘技术，从关联规则挖掘到分类再到聚类。它由新西兰的怀卡托大学设计、开发和维护。Weka 3 是 Weka 的一个版本，可对大数据集进行操作。虽然早期版本的 Weka 需要将整个数据集加载到内存中以执行分类等操作，但大数据版本执行增量加载和分类。Weka 3 还支持带有 Map 和 Reduce 任务的分布式数据挖掘。它还为 Hadoop 和 Spark 提供了封装器。关于 Weka 的更多细节见于 `[[WEKA](#ch04.xhtml#ref4_72)]`。

## 4.2.2.11 Apache Mahout

Apache Mahout 提供了一个环境，用于实现一系列机器学习系统。这些系统具有可扩展性，并构建在 Hadoop 之上。机器学习算法包括分类和聚类。机器学习算法的指令被转换为 MapReduce 作业并在 Hadoop 上执行。Mahout 提供 Java 库，用于实现机器学习算法中涉及的数学和统计技术。目标是让机器学习算法在超大数据集上运行。总之，正如 `[[MAHO](#ch04.xhtml#ref4_47)]` 所述，Mahout 提供以下三大功能：“(i) 一个简单且可扩展的编程环境和框架，用于构建可扩展算法；(ii) 适用于 Scala + Apache Spark、H2O 和 Apache Flink 的各种预制算法；(iii) Samsara，一个具有类 R 语法的向量数学实验环境，可大规模运行。” 关于 Mahout 的更多细节见于 `[[MAHO](#ch04.xhtml#ref4_47)]`。
