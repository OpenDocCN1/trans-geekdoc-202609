

# 10.5 对抗性 SVM 学习

我们现在针对上一节讨论的两种攻击模型，分别提出一种对抗性支持向量机模型（AD-SVM）。我们假设对手无法修改无害数据。请注意，该假设可以放宽，以建模无害数据也可能被篡改的情况。

## 10.5.1 针对自由范围攻击模型的 AD-SVM

我们首先考虑自由范围攻击模型。合页损失模型如下：

```
h(w, b, x_i) = {
    max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +   if y_i = 1
    ⌊1 + (w · x_i + b)⌋ +                   if y_i = -1
}
s.t.    δ_i ≺ C_f (x^max - x_i)
        δ_i ≻ C_f (x^min - x_i)
```

其中 `δ_i` 是 `x_i` 的位移向量，`≺`、`≻` 表示分量级不等式。

遵循标准 SVM 风险公式，我们得到：

```
arg min_{w,b}  Σ_{i|y_i=1} max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +
               Σ_{i|y_i=-1} ⌊1 + (w · x_i + b)⌋ +
               μ ||w||^2
```

合并正负实例的情况，这等价于：

```
arg min_{w,b}  Σ_i max_δ_i ⌊1 - y_i(w · x_i + b) - ½(1 + y_i)w · δ_i⌋ +
               μ ||w||^2
```

请注意，当选择 `δ_i` 以最小化其对间隔的贡献时，即可获得 `x_i` 的最坏情况合页损失，即：

```
f_i = min_δ_i ½(1 + y_i)w · δ_i
s.t.    δ_i ≺ C_f (x^max - x_i)
        δ_i ≻ C_f (x^min - x_i)
```

其中 `δ_i` 是 `x_i` 的位移向量，`≺`、`≻` 表示分量级不等式。

这是一个关于 `w` 和 `δ_i` 的不相交双线性问题。在这里，我们关心的是在给定 `w` 的情况下，发现 `δ_i` 的最优赋值。我们可以将双线性问题归约为关于 `u_i ∈ ℝ^d`、`v_i ∈ ℝ^d` 的以下非对称对偶问题，其中 `d` 是特征空间的维度：

```
g_i = max - Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
或
g_i = min Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
s.t.    (u_i - v_i) = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
s.t.    (u_i - v_i) = 1(1 + y_i)w
```

SVM 风险最小化问题可重写如下：

```
arg min_{w,b,t_i,u_i,v_i}  ½||w||^2 + C Σ_i ⌊1 - y_i · (w · x_i + b) + t_i⌋ +
s.t.    t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
        u_i - v_i = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
```

通过添加松弛变量和线性约束以消除合页损失的非可微性，我们可以将问题重写如下：

```
arg min_{w,b,ξ_i,t_i,u_i,v_i}  ½||w||^2 + C Σ_i ξ_i
s.t.    ξ_i ≥ 0
        ξ_i ≥ 1 - y_i · (w · x_i + b) + t_i
        t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
        u_i - v_i = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
```

## 10.5.2 针对受限攻击模型的 AD-SVM

对于受限攻击模型，我们修改合页损失模型，并遵循相同步骤求解：

```
h(w, b, x_i) = {
    max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +   if y_i = 1
    ⌊1 + (w · x_i + b)⌋ +                   if y_i = -1
}
s.t.
(x_i^t - x_i) ∘ δ_i ≺ C_ξ (1 - C_δ |x_i^t - x_i| / (|x_i| + x_i^t)) ∘ (x_i^t - x_i)^∘2
(x_i^t - x_i) ∘ δ_i ≻ 0
```

其中 `δ_i` 表示对 `x_i` 的修改，`≺` 为分量级不等式，`∘` 表示分量级运算。

通过求解以下最小化问题，可获得最坏情况合页损失：

```
f_i = min_δ_i ½(1 + y_i)w · δ_i
s.t.    (x_i^t - x_i) ∘ δ_i ≺ C_ξ (1 - C_δ |x_i^t - x_i| / (|x_i| + |x_i^t|)) ∘ (x_i^t - x_i)^∘2
        (x_i^t - x_i) ∘ δ_i ≻ 0
```
