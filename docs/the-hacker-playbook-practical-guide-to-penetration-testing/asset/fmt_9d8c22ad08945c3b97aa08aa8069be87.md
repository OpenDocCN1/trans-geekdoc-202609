## 推荐工具

### Burp Suite
[http://portswigger.net/burp/](http://portswigger.net/burp/) - Web 应用扫描器和手动 Web 应用测试工具（强烈推荐）

- 这是必买工具。该工具有许多不同的优势且处于积极维护状态。价格约为 $300。如果买不起 Burp，可以使用 OWASP ZAP 扫描器 [https://www.owasp.org/index.php/OWASP_Zed_Attack_Proxy_Project](https://www.owasp.org/index.php/OWASP_Zed_Attack_Proxy_Project)，它拥有许多相同功能且也在积极维护。本书所有示例均使用 Burp Suite Pro，因为我发现它是极其有效的工具。

![Kali Linux](images/00011.jpeg)

Kali 是一个 Linux 渗透测试发行版（简称“distro”），包含大量渗透测试常用工具。这在安全社区可能被视为当前标准，许多人基于此框架构建工具。我同意 Kali 确实包含我通常使用的许多工具，但我添加了一些自己的工具。某些二进制文件（如 *Windows Credential Editor* (WCE)）可能已在 Kali 发行版中，但我倾向于下载最新版本。我还会尝试将修改过的用于绕过 AV 的二进制文件放在单独文件夹中，以免被覆盖。

还有许多其他优秀的发行版。推荐查看 **Pentoo** ([http://www.pentoo.ch/](http://www.pentoo.ch/))。现在开始深入了解 Kali 发行版。

## Kali 配置

攻击主机有多种设置方式，但我希望你能复现本书所有示例。继续之前，请尝试按以下设置配置主机。请记住工具会定期更新，你可能需要对这些设置或配置进行微调。

可从 [http://www.kali.org/downloads/](http://www.kali.org/downloads/) 下载 Kali 发行版。强烈建议下载 VMware 镜像 ([http://www.offensive-security.com/kali-llnux-vmware-arm-image-download/](http://www.offensive-security.com/kali-llnux-vmware-arm-image-download/)) 并下载 VMPlayer/VirtualBox。文件为 gz 压缩且 tar 归档，请务必先解压再加载 vmx 文件。

### Kali VM 启动后：

1.  使用用户名 `root` 和默认密码 `toor` 登录
2.  打开终端
3.  **修改密码**
    - 务必修改 root 密码，尤其是启用 SSH 服务时。
    - 执行 `passwd`
4.  **更新镜像**
    - `apt-get update`
    - `apt-get dist-upgrade`
5.  **配置 Metasploit 数据库**
    - 这是为了配置 Metasploit 使用数据库存储结果和索引模块。
    - `service postgresql start`
    - `service metasploit start`
6.  **可选：启用 Metasploit 日志**
    - 列为可选是因为日志会变得很大，但你可以记录 Metasploit 命令行界面 (CLI) 的每条命令和结果。这对于批量攻击/查询或客户要求日志时非常有用。
    - `echo "spool /root/msf_console.log" > /root/.msf4/msfconsole.rc`
    - 日志将存储在 `/root/msf_console.log`
7.  **安装 Discover Scripts（原 Backtrack-scripts）**
    - Discover 用于被动枚举
    - `cd /opt/`
    - `git clone https://github.com/leebaird/discover.git`
    - `cd discover/`
    - `./setup.sh`
8.  **安装 Smbexec**
    - Smbexec 用于从域控制器获取哈希和反向 Shell
    - `cd /opt/`
    - `git clone https://github.com/brav0hax/smbexec.git`
    - `cd smbexec`
    - `./install.sh`
      - 选择选项 1
    - 安装至 `/opt`
    - `./install.sh`
      - 选择选项 4
9.  **安装 Veil**
    - Veil 用于创建基于 Python 的 Meterpreter 可执行文件
    - `cd /opt/`
    - `git clone https://github.com/veil-evasion/Veil.git`
    - `cd ./Veil/setup`
    - `./setup.sh`
10. **下载 WCE**
    - Windows Credential Editor (WCE) 用于从内存提取密码
    - `cd ~/Desktop`
    - `wget http://www.ampliasecurity.com/research/wce_v1_41beta_universal.zip`
    - `unzip -d ./wce wce_v1_41beta_universal.zip`
11. **下载 Mimikatz**
    - Mimikatz 用于从内存提取密码
    - `cd ~/Desktop`
    - `wget http://blog.gentilkiwi.com/downloads/mimikatz_trunk.zip`
    - `unzip -d ./mimikatz mimikatz_trunk.zip`
12. **保存自定义密码列表**
    - 用于破解哈希的密码列表
    - `cd ~/Desktop`
    - `mkdir ./password_list && cd ./password_list`
    - 通过浏览器下载大型密码列表并保存至 `./password_list`: [https://mega.co.nz/#!3VZiEJ4L!TitrTiiwygI2I_7V2bRWBH6rOqlcJ14tSjss2qR5dqo](https://mega.co.nz/#!3VZiEJ4L!TitrTiiwygI2I_7V2bRWBH6rOqlcJ14tSjss2qR5dqo)
    - `gzip -d crackstation-human-only.txt.gz`
    - `wget http://downloads.skullsecurity.org/passwords/rockyou.txt.bz2`
    - `bzip2 -d rockyou.txt.bz2`
13. `cd ~/Desktop`
14. **下载 Burp**: [http://portswigger.net/burp/proxy.html](http://portswigger.net/burp/proxy.html)。强烈建议购买专业版，其 $300 价格物超所值。
15. **设置 PeepingTom**
    - PeepingTom 用于网页快照
    - `cd /opt/`
    - `git clone https://bitbucket.org/LaNMaSteR53/peepingtom.git`
    - `cd ./peepingtom/`
    - `wget https://gist.github.com/nopslider/5984316/raw/423b02c53d225fe8dfb4e2df9a20bc800cc78e2c/gnmap.pl`
    - `wget https://phantomjs.googlecode.com/files/phantomjs-1.9.2-linux-i686.tar.bz2`
    - `tar xvjf phantomjs-1.9.2-linux-i686.tar.bz2`
    - `cp ./phantomjs-1.9.2-linux-i686/bin/phantomjs .`
16. **添加 Nmap 脚本**
    - `banner-plus.nse` 用于更快扫描和更智能识别
    - `cd /usr/share/nmap/scripts/`
    - `wget https://raw.github.com/hdm/scan-tools/master/nse/banner-plus.nse`
17. **安装 PowerSploit**
    - PowerSploit 是用于后渗透的 PowerShell 脚本
    - `cd /opt/`
