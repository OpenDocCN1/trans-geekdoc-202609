
# 客户反馈与持续成长指南

## 客户反馈

本节最后要强调的是确保从客户那里获取反馈。图表适合管理层查看，但技术人员希望看到大量重现漏洞利用的步骤和程序。同时，将所有原始扫描结果、原始 Burp 结果移交给客户也很重要，我通常还会提供一个 Excel 文件，其中包含发现的漏洞和漏洞的简单列表。Excel 文件使 IT 团队能够轻松勾选哪些发现已修复，哪些仍然有效。

如果你想在渗透测试人员中脱颖而出，尝试寻找方法将自己与其他人区分开来。如果你为大公司做渗透测试，还可以提供一份简单的 OSINT（开源情报）报告，描述从互联网上可以公开发现什么和谁。

## 持续成长路径

最常被问到的问题之一是“接下来该去哪里？”如何在安全行业持续变强，如何提升？所以我尝试为读者提供一份选项清单。我将这部分细分为：主要参会会议、辅助成长的培训课程、技术与非技术书籍阅读、靶场框架、夺旗赛（CTF）活动，以及跟进新闻资讯。

![](images/00253.jpeg)

### 主要安全会议

我从参加主要安全会议开始，因为这是结识他人、了解行业动态的绝佳场所。参会选择非常多，你可以在 InfoSecEvents 找到更完整的列表：[http://bit.ly/1cVISnz.I’ll](http://bit.ly/1cVISnz.I’ll)。以下是我亲身经历推荐的会议及简介：

*   **DefCon** ([http://www.defcon.org/](http://www.defcon.org/)) - 拉斯维加斯举办，费用低于 $200。这是最大的黑客大会，必参加。
*   **DerbyCon** ([https://www.derbycon.com/](http://www.derbycon.com/)) - 肯塔基州举办，费用低于 $200。我最喜欢的部分演讲来自 DerbyCon。
*   **BlackHat** ([http://www.blackhat.com/](http://www.blackhat.com/)) - 拉斯维加斯举办，费用极高。演讲嘉宾阵容强大，更面向企业员工。
*   **Bsides** ([http://www.securitybsides.com/](http://www.securitybsides.com/)) - 通常免费。全国各地都有 Bsides 大会，找到你附近的那场！
*   **ToorCon** ([http://toorcon.net/](http://toorcon.net/)) - 圣地亚哥举办，这是小型会议之一，能结识很多新朋友，大家都很友好。
*   **CanSec** ([http://cansecwest.com/](http://cansecwest.com/)) - 我只参加过 CanSecWest，价格不菲，但技术演讲质量一直很高。
*   **Shmoocon** ([http://www.shmoocon.org/](http://www.shmoocon.org/)) - 东海岸最大的会议之一，费用低于 $200。我最喜欢的会议之一。
*   **OWASP AppSec** ([https://www.owasp.org/index.php/Category:OWASP_AppSec_Conference](http://www.owasp.org/index.php/Category:OWASP_AppSec_Conference)) - 价格低廉且有趣，专注于 Web 应用安全。如果你是 OWASP 会员，费用低于 $100。
*   **Lethal** ([http://www.meetup.com/LETHAL/](http://www.meetup.com/LETHAL/)) - 当然要推荐一下我的小组。虽然不是会议，但我们有每月聚会并邀请演讲者。不仅免费，而且小组规模小，方便你参与并结识志同道合的人。

### 培训课程

如果你想在某个安全领域快速入门，培训课程最有帮助。鉴于课程众多，以下是一些推荐：

*   **BlackHat** - 费用极高，但不仅课程种类多，而且由业内顶尖专家授课。
*   **DerbyCon** - 肯塔基州举办，价格合理，在会议期间进行。
*   **SANS** ([http://www.sans.org](http://www.sans.org)) - 费用极高，但它们是行业标准。
*   **Offensive Security** ([http://www.offensive-security.com/](http://www.offensive-security.com/)) - 价格合理，我强烈推荐参加 Offensive Security 的在线课程。你将获得大量实战经验，但需要投入大量时间。

### 书籍推荐

还有许多好书值得一读。我无法列出所有，但以下这些令我印象深刻——顺序不分先后。你可能会问，为什么要关注恶意软件分析这类书籍？简单的答案是：不同安全领域（取证、恶意软件分析、应急响应、渗透测试）相互交织。要成为优秀的渗透测试员，你必须了解它们。你得知道如何清除痕迹、什么可能阻止你攻破目标、以及防御者是如何思考的。

### 夺旗赛（CTF）挑战

如果你打算以此为职业，甚至只是出于兴趣，你真的需要参与不同的 CTF 挑战。试着找几个朋友，或者找到你当地的安全小组一起尝试这些挑战。这不仅能测试你的技能和对攻击的理解，还能让你更好地与业内人士建立联系。花 3 天 3 夜攻克挑战，大概是你能体验到的最有成就感的事情之一。

访问 [https://ctftime.org/](http://ctftime.org/) 查找下一场 CTF 的时间地点。如果你在洛杉矶地区，欢迎访问 [www.meetup.com/lethal](http://www.meetup.com/lethal) 加入我们的战队！
