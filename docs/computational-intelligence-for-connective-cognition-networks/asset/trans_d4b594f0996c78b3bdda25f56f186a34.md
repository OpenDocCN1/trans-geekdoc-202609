# 第4章：无人机或UAV上的机器学习安全

**Meenal Jain and Kirti Aggarwal**

DOI: [10.1201/9781003569619-4](http://doi.org/10.1201/9781003569619-4)

## 4.1 简介

### 4.1.1 无人机的工作原理

#### 4.1.1.1 无人机的网络基础设施

为了实现成功的通信、控制和数据传输，无人驾驶飞行器（UAV）或无人机依赖一系列网络基础设施组件。理解这些基础设施组件对于理解无人机操作的复杂性至关重要：

1.  **通信链路：**
    *   **射频（RF）链路：** 无人机通常使用射频链路，如2.4 GHz和5.8 GHz，这些频段常用于控制和遥测。
    *   **Wi-Fi：** 消费级无人机经常利用Wi-Fi连接在无人机与遥控器或智能手机应用程序之间进行通信。
    *   **蜂窝网络：** 商用和企业级无人机配备蜂窝连接，允许进行扩展范围通信、数据传输和实时视频流传输。
    *   **卫星通信：** 在偏远或海上区域，无人机可能依赖卫星通信来保持连接，确保全球覆盖。

2.  **数据链路：** 无人机提供多种数据类型，如照片、视频、传感器读数和遥测数据。有线和无线数据连接均用于在无人机和地面系统之间传输数据。

3.  **GPS接收器：** 大多数无人机包含GPS接收器，允许它们检测其特定位置并确保正确导航。GPS数据是无人机网络架构的基本组成部分，可实现安全高效的飞行。

4.  **遥测系统：** 遥测系统将关于无人机状态的实时数据发送给地面控制站，包括高度、速度、电池电量和传感器读数。该信息对于跟踪和管理无人机性能至关重要。

5.  **遥控器：** 操作员使用遥控器或发射器向无人机传达控制命令。这些控制器通过射频或Wi-Fi连接与无人机通信。

这些众多组件构成了无人机的网络骨干，使它们能够在各种应用中高效执行任务。基础设施要素的选择取决于诸如无人机功能、范围要求、操作环境和监管限制等因素。理解这一基础设施对于理解无人机操作背景下可能涉及的安全问题和潜在漏洞至关重要。

无人机容易受到各种恶意攻击，如数据窃听、GPS欺骗、射频干扰和未授权访问。这凸显了采取广泛安全措施以保护无人机及其携带的私密信息的迫切需求。无人机网络架构通常包含加密、认证、入侵检测系统和网络监控等安全功能，以防止未授权访问和数据窃听。

### 4.1.2 对抗攻击

在机器学习（ML）安全这一复杂领域中，已经开发出各种各样的算法，每一种都专门设计用于寻找和利用模型中的缺陷。这些算法主要集中在令人兴奋的对抗攻击领域，该领域探索并操纵机器学习模型的根基。

1.  **L-BFGS算法：** L-BFGS方法是一种激进的优化方法。它是一种白盒攻击方法。L-BFGS通过反复改进输入数据上的扰动以优化模型的损失来生成对抗样本。这种方法虽然有效，但计算量要求高。

2.  **快速梯度符号法（FGSM）：** FGSM是一种既快速又高效的白盒攻击算法。它通过沿着损失函数相对于输入的梯度方向执行单步操作来修改输入数据。尽管FGSM能快速生成对抗案例，但并不总能达到较高的成功率。
