# 第9章 视觉深度伪造检测方法综述

Nikhil Rathoure, R. K. Pateriya, Deepak Singh Tomar, Ankit Vidyarthi, Nitesh Bharot, and Priyanka Verma

DOI: [10.1201/9781003569619-9](http://doi.org/10.1201/9781003569619-9)

## 9.1 简介

随着深度学习技术的最新进展，超逼真媒体生成与操纵的世界经历了前所未有的增长，其带来的影响巨大且深远。

过去几年中，互联网上AI生成内容的使用大幅增加。特别是在COVID-19大流行期间及之后，公众对数字媒体的依赖呈指数级增长，人们在虚拟世界中花费的时间越来越多。随着对数字媒体依赖的增加，通过虚假媒体传播的错误信息也显著增加。互联网上错误信息最大的来源之一是“深度伪造”，其名称源于“深度学习”和“伪造”，指代由深度学习方法合成和/或操纵的媒体。深度伪造是极易欺骗人类的超逼真音频、视频或图像。就其潜在的网络犯罪用途而言，深度伪造是近年来最令人烦恼的AI应用之一，并被称为最严重的AI犯罪威胁[[1]](#ch19.xhtml#r273)。

通过深度伪造传播错误信息造成的损害包括财务资源损失、心理/精神健康危害，以及公司/名人/政客声誉和信任的受损，这些往往难以挽回，导致信任危机、混乱和社会动荡。根据Sumsub的一份报告[[2]](#ch19.xhtml#r274)，从2023年第一季度到2024年第一季度，全球深度伪造事件同比增长了245%，在2024年举行或计划举行选举的国家中增长更是呈多倍数。报告称印度(+280%)、美国(+303%)、墨西哥(+500%)、印度尼西亚(+1550%)和韩国(+1625%)的深度伪造事件同比激增。随着数字媒体在我们个人和职业生活中渗透率的不断提高，深度伪造的规模和传播范围使其成为当今事实上的错误信息工具。因此，深度伪造检测领域引起了各行业、学术界和政府研究人员的关注。因此，分析深度伪造及相关的生成方法进展和检测方法发展变得尤为重要。在本综述中，我们将重点关注视觉深度伪造检测方法。
