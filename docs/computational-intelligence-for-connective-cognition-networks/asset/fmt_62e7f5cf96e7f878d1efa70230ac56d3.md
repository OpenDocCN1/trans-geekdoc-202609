## 8.7 Evaluation metrics

To make sure the classification or prediction model is behaving correctly and achieving the goal, a set of checklists will be applied to it to perform the measurement which is known as evaluation metrics. The performance and efficacy of classifiers can be assessed using evaluation metrics [[60](#ch18.xhtml#r263)]. Several factors need to be considered when choosing the correct evaluation metric such as less complexity and less computational cost, the issue of multiclass problems, informativeness, distinctiveness, and discriminable [[61](#ch18.xhtml#r264)]. To ensure a classification model has high efficiency and high performance, it needs to make sure the predicted outcome is the same as the true outcome. The problem discussed in this paper is a binary classification problem. The evaluation metric applied for binary classification problems is the confusion metric which also belongs to the threshold types of evaluation metrics [[61](#ch18.xhtml#r264)].

### 8.7.1 Confusion metric

The confusion metric is presented in a tabular format. It contains information about the actual and predicted class that is done by a classification model. There are four types of indicators in the confusion metric which are True Positive (TP), True Negative (TN), False Positive (FP), and False Negative (FN) [[61](#ch18.xhtml#r264)].

The confusion metric provides the visualization to the researchers on the indicators so they can take further action on improving the classification model if necessary. [Figure 8.5](#ch18.xhtml#f49) shows how a confusion metric of random forest classifier. The `x`-axis and `y`-axis signify predicted values and real values, respectively. The darker the color in the box of the confusion metric, the higher the values.

### 8.7.2 Accuracy

The range of accuracy scores is between 0 and 1. In general, the accuracy score calculated the percentage of exact predictions over the total number of samples that are assessed [[61](#ch18.xhtml#r264)]. The equation is listed below:

$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} \tag{8.3}$$

### 8.7.3 Precision, Recall, and F-Measure

Accuracy score is not a great evaluation metric to judge the performance of a classification model, as it provides a less distinctive value [[61](#ch18.xhtml#r264)]. The accuracy score might not be accurate when the dataset is imbalanced. To overcome the limitation of the accuracy score, we can calculate the precision score of the classification model. The concept of calculating a precision score is using the sample that is precisely predicted from the entire predicted samples in a positive class [[61](#ch18.xhtml#r264)]. Different from precision, the recall score can also be used to calculate the number of positive classes that are correctly classified out of all positive examples in the dataset. The harmonic mean of precision and recall is the f-measure (F1 score). Joshi [[62](#ch18.xhtml#r265)] has mentioned that although the f-measure is less popular being used as the performance metric; however, it performs better than the accuracy score when come to optimizing the classifier for binary classification problems. The range of f-measure can be between 0 and 1. The formulas for computing these measures are listed below:

$$\text{Precision}(p) = \frac{\text{TP}}{\text{TP} + \text{FP}} \tag{8.4}$$

$$\text{Recall}(r) = \frac{\text{TP}}{\text{TP} + \text{FN}} \tag{8.5}$$

$$F\text{-measure} = \frac{2 \cdot p \cdot r}{p + r} \tag{8.6}$$
