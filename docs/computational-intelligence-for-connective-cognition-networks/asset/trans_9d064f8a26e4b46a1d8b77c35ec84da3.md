# 第 2 章 量子网络范式

Preety Aneja

DOI: [10.1201/9781003569619-2](http://doi.org/10.1201/9781003569619-2)

## 2.1 简介

我们的宇宙在微观层面展现出迷人的行为，自然界中有许多现象难以解释。我们是否思考过为什么量子计算机的性能优于典型计算机？它拥有哪些独特特性？所有这些问题的答案都隐藏在对自然基本原理的理解之中。被称为量子力学的物理学分支（[Konishi and Paffuti 2009](#ch12.xhtml#r054)）解释了微观层面粒子的行为和动力学。

随着量子力学研究和进步的迅速发展，量子计算机、量子网络，乃至量子互联网的存在已成为可能。量子计算相较于传统或经典计算具有显著优势。量子计算利用量子力学的基本概念，如纠缠、叠加态等（Wineland 2013），与传统计算方法相比，在解决物流、药物设计、银行业务、统计科学、安全通信等复杂问题方面具有显著优势。量子计算机的实现仅得益于量子软件设计、量子硬件研究、量子算法创造等方面的显著发展。

经典计算机中的信息基本单位是二进制数字。每个二进制数字只能处于两种状态，即 0 或 1。另一方面，量子计算机中量子信息的基本单位是量子比特。量子比特可以在各种物理系统中制备，例如原子的电子能级、光子的光学自由度、电子或原子核的自旋态等（[Bennett and DiVincenzo 2000](#ch12.xhtml#r030); [Bouwmeester and Zeilinger 2000](#ch12.xhtml#r032)）。量子比特的特性通常基于粒子的物理属性，例如电子的自旋，因此其表现形式多种多样。众所周知，电子可以具有向上自旋或向下自旋，但在量子力学中，电子存在于同时具有两个方向自旋的状态的概率是存在的。这一概念被称为量子力学中的两态叠加。根据经典物理学，这一概念听起来与我们的普遍观察相悖。然而，粒子表现出的这种奇特行为在各方面都将大有裨益。例如，量子比特能存储比传统比特多得多的信息。经典比特只能取值 0 和 1。用两个比特，存在四种可能的组合：00、01、10 或 11。而在量子计算中，由于叠加特性，量子比特可以同时取值 0 和 1。因此，两个量子比特可以同时存在所有四种组合（00、01、10、11）。量子计算中的这一特性极大地增加了量子比特存储的信息量。
