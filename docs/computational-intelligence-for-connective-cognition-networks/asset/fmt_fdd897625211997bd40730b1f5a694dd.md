
The lecture preparation material, for all the 274 queries, generated using template-based prompting were incorporated in a dataset called as the demonstration dataset.

## 10.4 Prompt techniques

There are several prompting techniques in large language models that are considered essential for successfully directing the model to generate the intended results. In our study, we have incorporated few shots, zero shots, and template-based prompting techniques.

### 10.4.1 Template-based prompting

Template-based prompting is a method used in natural language processing (NLP) where predefined templates or structures are provided to guide the generation of text. In the context of our study, template-based prompting has been used to craft different types of prompts tailored to different query types. The prompt consists of pointers defining the various headings a professor would expect in a lecture preparation material, thus guiding `ChatGPT-3.5` in defining the structure of the lecture preparation material. The task of `ChatGPT-3.5` is to fill in the content under these headings from its known knowledge. The various headings defined by the pointers in the prompt are as follows:

*   **Topic**: The pointer extracts the topic from the query on which the lecture preparation material should be generated.
*   **Objectives**: The pointer for this heading is to write objectives for the topic.
*   **Theory**: The pointer provides an elaborate theory on the topic present in the query.
*   **Code implementation**: Provides coding implementation of the topic and even though not specified in the prompt. All the codes are in python language in the output. For programming question queries, this heading asks for various ways a programming problem can be solved. For example, Knapsack problem can be solved using greedy algorithm and dynamic programming. The explanation and complexity analysis of each approach is also asked, as shown in [Figure 10.2](#ch20.xhtml#f72).

    ![Figure 10.2 Template for each query type.⏎](html/images/9781032942346_C010_002.jpg)

    **Figure 10.2** Template for each query type.[⏎](#ch20.xhtml#f72b)

*   **Explanation of the code**: Provides proper explanation of the code written in code implementation section.
*   **Complexity analysis**: this pointer details the time and space complexity of the code written in the code implementation section.
*   **Beginner Programming Problem**: The pointer for this heading asks `ChatGPT-3.5` to provide a beginner level programming question on the topic asked in the query. This exists only for single topic prompts.
*   **The application of the topic**: The pointer for this heading asks `ChatGPT-3.5` to provide application of the topic in real life.
*   **Conclusion**: The pointer for this heading asks `ChatGPT-3.5` to provide a conclusion of all that that has been discussed in the material above.
*   **Short quiz**: The pointer for this heading asks `ChatGPT-3.5` to provide a short quiz along with answers on the topic and what has been discussed in the lecture material.
*   **References**: The pointer for this heading asks `ChatGPT-3.5` to provide references to study the topic further. It is also mentioned to give links which are properly working.

### 10.4.2 Zero-shot prompting

In this prompting, `ChatGPT-3.5` generates lecture preparation material for the given query without any additional illustrations. As shown in [Figure 10.3](#ch20.xhtml#f73), the zero-shot prompt [[18](#ch20.xhtml#r359)] consist of the query enclosed within triple backticks and a brief instruction guiding the model to generate lecture preparation material for the mentioned. Zero-shot prompting, even though offers simplicity and flexibility, can lead to distinct responses depending on the interpretation of the model interpretation of the query and the complexity of the requested topic, which is not helpful in the problem area this study targets wherein a proper and consistent structure is required.

### 10.4.3 Few-shot prompting

In this prompting, `ChatGPT-3.5` is provided with a few instances of queries and their respective lecture preparation material extracted from the demonstration dataset, referred to as “shots,” to boost the accuracy and relevance of response. As shown in [Figure 10.4](#ch20.xhtml#f74), the few-shot prompt [[19](#ch20.xhtml#r360)] consist of the query, natural language instructing the model to use the demonstrations to understand the structure and shots which may or may not be related to the topic, providing additional context and guidance for the model to generate a material on similar lines. Leveraging these instances, the model obtains a better understanding of what is expected and can generate more customized and thorough responses. The model learns from these examples, leading to more focused and informative outputs as compared to zero-shot prompting.

### 10.4.4 Gemini pro with RAG for ranking

Gemini Pro is an advanced natural language processing tool and, in this study, it has been given the task of determining the ranking of lecture preparation material generated using each prompting technique for each query on the basis of the content quality using the context consisting of data related to the topic asked in the query retrieved using retrieval augmented generation (RAG). According to the Google, DeepMind report titled ‘Gemini: A Family of Highly Capable Multimodal Models’ [[20](#ch20.xhtml#r361)], the pretraining dataset for Gemini included programming data which makes it a suitable choice for a content evaluator of computer science related material. Further it states that during training of Gemini models, a sequence length of 32,786 tokens were used, and it was observed that they effectively utilize their context length. The report also explored the performance of Gemini models for handling complex prompts, that is, prompts with multiple instructions and the per-instruction accuracy of Gemini Pro was 77.8 ± 2.0% making it adequate for the evaluation phase of this study as the prompt for Gemini Pro consists of the query and its respective lecture materials generated using each prompt techniques as discussed above, a context retrieved using RAG, which is explained in Section 10.4.4.1, natural language instructing the model to analyze and rank the content of lecture material generated by each prompting technique based on the context provided, resulting in a lengthy and a complex prompt as shown in [Figure 10.5](#ch20.xhtml#f75).
