## 8.7 评估指标

为确保分类或预测模型表现正确并达到目标，将应用一组检查清单对其进行度量，这被称为评估指标。分类器的性能和功效可使用评估指标进行评估 [[60](#ch18.xhtml#r263)]。选择正确的评估指标时需考虑多个因素，如复杂度较低和计算成本较低、多类问题、信息量、独特性和可区分性 [[61](#ch18.xhtml#r264)]。为确保分类模型具有高效率和高性能，需确保预测结果与真实结果相同。本文讨论的问题是一个二分类问题。应用于二分类问题的评估指标是混淆矩阵，它也属于阈值类型的评估指标 [[61](#ch18.xhtml#r264)]。

### 8.7.1 混淆矩阵

混淆矩阵以表格形式呈现。它包含分类模型执行的实际类别和预测类别的信息。混淆矩阵中有四类指标，即真正例 (TP)、真反例 (TN)、假正例 (FP) 和假反例 (FN) [[61](#ch18.xhtml#r264)]。

混淆矩阵为研究人员提供指标的可视化，以便他们在必要时采取进一步行动改进分类模型。[图 8.5](#ch18.xhtml#f49) 展示了随机森林分类器的混淆矩阵示例。`x` 轴和 `y` 轴分别代表预测值和真实值。混淆矩阵方框中颜色越深，数值越高。

### 8.7.2 准确率

准确率得分的范围在 0 和 1 之间。通常，准确率得分计算的是精确预测的百分比占评估样本总数的比例 [[61](#ch18.xhtml#r264)]。公式如下：

$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} \tag{8.3}$$

### 8.7.3 精确率、召回率和 F 值

准确率得分并非评判分类模型性能的绝佳评估指标，因为它提供的区分度较低 [[61](#ch18.xhtml#r264)]。当数据集不平衡时，准确率得分可能不准确。为克服准确率得分的局限性，我们可以计算分类模型的精确率得分。计算精确率得分的概念是使用整个正类预测样本中精确预测的样本 [[61](#ch18.xhtml#r264)]。与精确率不同，召回率得分也可用于计算数据集中所有正例里被正确分类的正类数量。精确率和召回率的调和平均数即为 F 值 (F1 分数)。Joshi [[62](#ch18.xhtml#r265)] 提到，尽管 F 值作为性能指标不太常用；然而，在针对二分类问题优化分类器时，其表现优于准确率得分。F 值的范围可在 0 和 1 之间。计算这些指标的公式如下：

$$\text{Precision}(p) = \frac{\text{TP}}{\text{TP} + \text{FP}} \tag{8.4}$$

$$\text{Recall}(r) = \frac{\text{TP}}{\text{TP} + \text{FN}} \tag{8.5}$$

$$F\text{-measure} = \frac{2 \cdot p \cdot r}{p + r} \tag{8.6}$$
