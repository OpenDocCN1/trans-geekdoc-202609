
Relu activation is used in all the layers except for the last layer. Binary cross entropy loss is used as a loss function and for optimization, Adam is used for hyperparameter tuning across multiple epochs.

### 7.4.2.3 BiLSTM

The proposed architecture is composed of an embedding layer, a spatial dropout layer, and a single Bi-LSTM layer. We have used word embeddings of 128 dimensions as the input layer for generating features of sparse input documents. To avoid overfitting, we have used spatial dropout of 1-dimension with a 40% dropping rate. We have further implemented a Bi-LSTM layer along with a further dropout rate of 20%. The learning parameters utilize the grid search technique for optimization. The Bi-LSTM layer utilizes 196 neurons as input. This choice of 196 neurons was selected after performing a grid search by selecting a neuron range from 32 to 256 neuron sizes and selecting the one that gives good performance without overfitting. The final output layer utilizes the Softmax function for classifying multiple languages based on probabilities. Categorical cross entropy is used as a loss function. Adam is used for hyperparameter tuning as it has given good performance over other hyperparameter tuning algorithms. The output dense layer consists of three neurons for each of the classes. ## 7.5 Conclusion

Multilingual PDF document classification is an important problem that needs to be addressed owing to the ever-increasing size of electronic documents. This paper uses and compares different algorithms for the classification of multilingual documents. The Bi-LSTM algorithm produced accuracies consistently higher than other conventional algorithms like DNN and LSTM. The advantage of using Bi-LSTM is its ability to learn context in both directions, which makes it more accurate than LSTM. Also, Bi-LSTM requires very low computational requirements; hence, it is used in this work. The proposed model has shown the best accuracy with an accuracy of 98.7%. In the future, we can comparatively analyze results over much newer models keeping in mind low computing requirements.
