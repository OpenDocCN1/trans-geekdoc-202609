
# 接收者操作特征曲线 (ROC)

接收者操作特征曲线 (ROC) 已被广泛用作评估医学诊断系统的性能度量 [[63](#ch18.xhtml#r266)]。根据 Park 等人 [[64](#ch18.xhtml#r267)] 的研究，ROC 表现为一个由两个关键组成部分构成的图表，即灵敏度（或真阳性率）和特异度（或假阳性率），并且它能够将信号与噪声区分开来。在 ROC 图中，灵敏度分别绘制在 *y* 轴上，特异度绘制在 *x* 轴上。ROC 图能清晰地展示假阳性率与真阳性率之间的关系。ROC 曲线的延伸——ROC 曲线下面积 (AUC) 已被证明是总结检验功效的有用指标 [[65](#ch18.xhtml#r268)]。Mandrekar [[65](#ch18.xhtml#r268)] 还提到，AUC 的取值范围为 0 到 1，其中 0 表示检测完全不准确，1 表示检测完全准确。一般来说，当 AUC 大于 0.5 时，分类器很有可能将正类值与负类值区分开来。然而，也存在 AUC 值等于 0.5 的情况，此时 ROC 曲线在图中呈现为对角线。在这种情况下，分类器将不具备区分正类和负类的能力。

# 8.8 实验结果

在此，我们提供实验结果的详细信息。

## RQ1：基线分类器的性能如何？

**动机：** 我们致力于利用不同类型的特征构建假新闻检测模型。了解在不使用任何外部特征提取的情况下，假新闻检测模型的表现如何具有重要意义。因此，在本 RQ 中，我们利用新闻文章的标题和内容构建了基线分类器。

**方法：** 我们使用文本数据，即新闻文章的词形还原后的标题和内容来构建基线分类器。然后，在训练 `RF` 分类器模型之前，我们使用 `TfidfVectorizer` 对数据集进行向量化。对于 `LSTM` 分类器，我们对文本数据进行分词并将其输入嵌入层，然后再进入 `LSTM` 层。在本实验中，我们为 `RF` 使用 100 个 n_estimators，为 `LSTM` 使用 10 个 epochs。

**结果：** [图 8.6](#ch18.xhtml#f50) 和 [表 8.11](#ch18.xhtml#t23) 展示了本 RQ 的结果。我们分别获得了 `RF` 和 `LSTM` 分类器 60.7% 和 78.4% 的准确率值，以及分别为 `RF` 和 `LSTM` 分类器 79.2% 和 41.1% 的 F 值（请参阅表 8.10）。这些结果表明，基线分类器在假新闻检测方面给出了非常低的准确率和 F 值，因此有必要改进这些模型。基线分类器在假新闻检测任务中表现不佳，`RF` 和 `LSTM` 分类器的准确率分别为 60.7% 和 78.4%。`LSTM` 分类器的性能在准确率和 F 值方面均远低于 `RF` 分类器。

## RQ 2：与基线分类器相比，所提出的模型（即 FNDetector）的性能如何？

**动机：** 在本 RQ 中，我们研究了所提出的 `FNDetector` 模型的性能。为了构建该模型，我们结合了不同类型的特征。此外，我们从新闻文章的标题和内容中提取了特征。本 RQ 将有助于深入了解 `FNDetector` 模型的有效性。

**方法：** 为了回答本 RQ，我们使用 `RF` 和 `LSTM` 分类器训练 `FNDetector` 模型，以构建 `FNDetector` 模型的两个变体，即 `FNDetector[RF]` 和 `FNDetector[LSTM]`。我们在测试数据集上测试了这两个模型的性能并计算了各种指标。我们还将这两个模型与基线分类器进行了比较。

**结果：** [表 8.12](#ch18.xhtml#t24) 和 [图 8.7](#ch18.xhtml#f51) 展示了 `FNDetector[RF]` 和 `FNDetector[LSTM]` 模型的预测结果。[表 8.12](#ch18.xhtml#t24) 显示，`FNDetector[RF]` 的准确率为 88.2%，F 值为 88.5%，而 `FNDetector[LSTM]` 的准确率为 78.4%，F 值为 81.3%。[图 8.8](#ch18.xhtml#f52) 和 [图 8.10](#ch18.xhtml#f54) 展示了基线分类器与 `FNDetector` 分类器性能的比较。[图 8.9](#ch18.xhtml#f53) 和 [图 8.10](#ch18.xhtml#f54) 显示，`FNDetector[RF]` 和 `FNDetector[LSTM]` 模型在准确率和 F 值方面均优于基线分类器。我们计算了改进幅度，并以柱状图的形式展示结果（请参阅 [图 8.10](#ch18.xhtml#f54) 和 [图 8.11](#ch18.xhtml#f55)）。我们注意到，使用 `FNDetector[RF]` 模型，准确率提高了 9.8%，F 值提高了 9.3%；使用 `FNDetector[LSTM]` 模型，准确率提高了 17.7%，F 值提高了 40.2%。这些结果表明，特征提取是创建假新闻模型的重要步骤。从结果中我们可以得出结论，特征提取对于随机森林和 `LSTM` 分类器的假新闻模型构建均有用。我们在准确率方面分别获得了 9.8%（`FNDetector[RF]`）和 17.7%（`FNDetector[LSTM]`）的提升，在 F 值方面分别获得了 9.3%（`FNDetector[RF]`）和 40.2%（`FNDetector[LSTM]`）的提升。
