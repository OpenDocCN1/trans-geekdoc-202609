

# 朴素贝叶斯（NB）算法

朴素贝叶斯（NB）算法是一种基于贝叶斯定理的概率分类算法。朴素贝叶斯的假设包括特征独立性，即特征在预测分类结果时互不相互作用 [[16](#ch17.xhtml#r183)]。NB 分类器是一种监督学习算法，可使用少量数据高效训练。由于变量或特征被假定为相互独立，因此只需计算每个类变量的方差，而无需计算整个协方差矩阵的值。朴素贝叶斯算法在性能方面表现卓越，因为它也能在有限数据上进行训练 [[17](#ch17.xhtml#r184)–[21](#ch17.xhtml#r188)]。公式 (7.1) 描述了下面的贝叶斯法则。

```
$P\left( {c_{i}~\text{|}~D} \right) = \frac{P\left( c_{i} \right)P\text{(}D~\text{|}~c_{i})}{P\left( D \right)}$ (7.1)
```

其中 $P\left( C_{i} \right) = P(C = c_{i}) = \frac{N_{i}}{N}$

其中 `P(C[i])` 是数据集中类别 `C[i]` 的训练样本数（即 `N[i]`）占数据集总样本数（即 `N`）的比率

尽管朴素贝叶斯基于不同特征之间相互独立这一不切实际的假设，但它在许多分类任务中仍能提供合理的性能。它简单且易于实现。因此，研究人员已将其用于不同的任务 [[22](#ch17.xhtml#r189), [23](#ch17.xhtml#r190)]。在 [[24](#ch17.xhtml#r191)] 中，朴素贝叶斯分类器表现非常出色，此时模型计算出的概率并不重要。它被用于不同的分类应用，如电子邮件中的垃圾邮件过滤 [[25](#ch17.xhtml#r192)]、垃圾邮件分类和网页内容分类。

## 7.2.2 长短期记忆模型

长短期记忆（LSTM）在 [[26](#ch17.xhtml#r193)] 中被提出，过去已被证明在学习序列方面比标准循环神经网络（RNN）强大得多。RNN 本质上是在多个时间步上展开的神经网络，因此可以处理时间序列和句子等序列数据。每个时间步都具有隐藏状态，处理来自前一个隐藏状态和当前输入的输入。RNN 的缺点是梯度消失和梯度爆炸。LSTM [[26](#ch17.xhtml#r193)] 的转移函数按公式 (7.2)–(7.7) 定义：

```
i[t] = σ(W[i].[h[t−1],x[t]]+b[i]) (7.2)
f[t] = σ(W[f].[h[t−1],x[t]]+b[f]) (7.3)
o[t] = σ(W[o].[h[t−1],x[t]]+b[o]) (7.4)
c[t] = f[t]⊙ c[t−1] + i[t] ⊙ q[t] (7.5)
h[t] = o[t] ⊙ tanh(c[t]) (7.6)
```

在上述公式中，⊙ 表示逐元素乘法运算。符号说明：当前时间步 `x[t]`、旧隐藏状态 `h[t-1]`、输入门 `i[t]`、遗忘门 `f[t]` 和输出门 `o[t]`。权重用 `W[o]`、`W[q]` 和 `W[i]` 表示，它们是针对不同门的可训练参数。前一个和当前的记忆单元分别用 `c[t-1]` 和 `c[t]` 表示。当前隐藏状态 `h[t]` 使用 `c[t]` 进行修改，并由这些门共同决定。[图 7.1](#ch17.xhtml#f40) 描绘了 LSTM 单元图。

## 7.2.3 双向长短期记忆（Bi-LSTM）模型

双向 LSTM（Bi-LSTM）模型有助于提取更多上下文信息 [[27](#ch17.xhtml#r194)]。数据处理在反向和正向方向上同时进行 [[28](#ch17.xhtml#r195)]，并使用求和统计量合并 LSTM 输出 [[29](#ch17.xhtml#r196)]。

Bi-LSTM 模型作为将序列数据分类为多个类别的最先进模型，已被广泛用于语音识别 [[30](#ch17.xhtml#r197), [31](#ch17.xhtml#r198), [32](#ch17.xhtml#r199), [33](#ch17.xhtml#r200), [34](#ch17.xhtml#r201)]。PDF 文档页面中的文本也是单词序列，且存在多类标准，因为文档需被分类到相应的语言类别中。因此，本文将 Bi-LSTM 模型应用于分类任务。

# 7.3 方法论

## 7.3.1 数据集描述

数据集包含来自三种语言的 PDF 文件，即英语、斯洛伐克语和捷克语。对句子执行数据清洗和预处理。使用 `Count Vectorizer` 对序列集进行编码。数据集划分为：80% 的数据用于训练，剩余 20% 用于测试。此外，使用交叉验证以避免对单个样本集过拟合。数据训练 100 个周期，该数值通过网格搜索方法选定。[表 7.1](#ch17.xhtml#t9) 显示了数据集详情。

## 7.3.2 特征提取

在开始分析之前，首先从 PDF 文档文件中提取文本。如果页面以光栅图像形式存在，则使用 `Tesseract OCR` 系统从文档页面提取内容 [[15](#ch17.xhtml#r182)]。提取后，文本通过文档分类引擎，详见第 7.3.3 节。

## 7.3.3 文档分类引擎

文档分类引擎可协助人工将不同语言的文档分离到不同文件夹中。如果文档未正确标记，这可防止文档丢失，并加快这些文档用于适当应用的过程。所提出的分类引擎还可摄取并分类以图像形式包含数据的 PDF 文档。文档分类引擎作为先决条件，对文档进行分类，以利用从各种 PDF 文档中提取信息。

[图 7.2](#ch17.xhtml#f41) 描绘了执行分类的方法论步骤。首先进行预处理，包括使用 Python 中的 `NLTK` 库移除停用词。进一步在数据集中执行缺失值处理、插值和词干提取。随后进行特征选择。

![Figure 7.2 Methodological steps.](html/images/9781032942346_C007_002.jpg)
