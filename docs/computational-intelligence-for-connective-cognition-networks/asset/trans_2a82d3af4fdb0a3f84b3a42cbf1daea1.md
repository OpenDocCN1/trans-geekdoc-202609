

另一项研究工作介绍了一项举措，旨在通过将大语言模型应用于美国一所大型公立大学的在线高等教育课程中，来融合生成式 AI。所实施的 LLM 从讲座视频中提取丰富的元数据，将讲座分割为连贯的单元，提取所授主题的关键定义、示例和程序性知识。甚至还利用 LLM 生成了测试学生对所授主题理解程度的问题。这篇研究论文概述了多个研究方向，旨在探索 LLM 在在线教育中的全部潜力 [[13](#ch20.xhtml#r354)]。在测验生成方面，Meißner 等人引入了 EvalQuiz，利用 LLM 在软件工程教育中自动生成自我评估测验 [[1](#ch20.xhtml#r342)]。传统的测验创建是一个耗时的过程，需要专业知识和人工审核问题。EvalQuiz 旨在通过利用 LLM（特别是 GPT-4）根据讲座材料自动生成测验，以减轻这一负担。该过程包含几个阶段：主题建模与关键词提取、提示工程与问题生成、测验组装与验证，以及评估。讲座材料经过处理以提取相关关键词并为 LLM 生成提示。随后对生成的测验进行组装和验证，确保符合指定格式。最后，对测验质量进行评估，考量相关性、正确性和原创性等因素 [[1](#ch20.xhtml#r342)]。Kolagar 等人 [[14](#ch20.xhtml#r355)] 为人文学科学生开发了一款个性化讲座摘要工具 HumSum。HumSum 通过场景驱动的调查收集用户偏好，以指导工具的实现。利用 Streamlit 作为用户界面，并结合 Langchain 的 map reduce 功能与 OpenAI 的 GPT-4 模型，在不收集用户个人数据的前提下实现了有效的摘要生成 [[14](#ch20.xhtml#r355)]。一篇发表在会议上的调查论文讨论了大语言模型在教育领域的具体应用 [[15](#ch20.xhtml#r356)]。它深入探讨了教育领域涉及的各方利益相关者，包括教师、学生、家长、教育机构、政府和社会，重点阐述了他们在教育生态系统中的角色与互动。手稿简要介绍了 LLM 在教育领域的多种应用，并探讨了 LLM 在教育中的未来影响，以应对构建一个智能教育更加个性化、多元化和数字化增强的图景所面临的挑战 [[15](#ch20.xhtml#r356)]。Leiker 及其团队在提示工程和人工监督的指导下，利用 LLM 进行课程创建实验 [[11](#ch20.xhtml#r352)]。他们细致地考察了在成人教育、培训和技能提升的异步课程创建中使用 LLM 的优势与障碍。尽管 LLM 在获取和综合海量人类知识方面潜力巨大，但关于其准确性和可靠性的顾虑依然存在。因此，该研究主张采取平衡的方法，建议引入人工监督以确保生成输出的质量和清晰度 [[11](#ch20.xhtml#r352)]。该领域的另一个研究方向是面向对话式辅导系统，如 Ruffle&Riley [[16](#ch20.xhtml#r357)]。该系统实现了面向“通过教学学习”交互的脚本编写和编排自动化，LLM 代理以自由对话的形式吸引用户参与。一项将 Ruffle&Riley 与较简单的问答聊天机器人和阅读活动进行对比的用户研究显示，后测分数无显著差异，但用户在理解、记忆、帮助性和连贯性方面对 Ruffle&Riley 的评价更高 [[16](#ch20.xhtml#r357)]。Jauhiainen 和 Guerra 的研究聚焦于生成式 AI 在小学教育中的应用。这项理论研究针对两所不同学校四至六年级、8-14 岁的 110 名学生，他们作为测试讲座的参与者 [[12](#ch20.xhtml#r353)]。研究结果证明了利用 ChatGPT-3.5 个性化学习材料以满足不同知识水平学生的知识和学习技能的可行性。重要的是，绝大多数学生表示喜欢经过生成式 AI 修改的材料，这表明生成式 AI 有潜力支持学校教育中的动机学习和技能发展 [[12](#ch20.xhtml#r353)]。

所研究的论文通常用于理论学科，而利用基于模板的提示技术，借助大语言模型为编程学科教授生成讲座准备材料，仍是一个未解决且鲜有探索的问题。

## 10.3 讲座准备与生成流程

该方法论涉及使用基于模板的提示技术 [[17](#ch20.xhtml#r358)]，借助 ChatGPT-3.5 为两门重要的计算机科学基础学科——数据结构与算法（DSA）和面向对象程序设计系统（OOPS）——生成讲座准备材料。探索了教授可用于生成和使用讲座准备材料的七类查询。随后，将这些查询连同针对各查询类型、定义生成材料结构的固定模板一起输入 ChatGPT-3.5。进而，从该查询池中抽取 50 个查询，在 ChatGPT-3.5 上分别采用零样本提示 [[18](#ch20.xhtml#r359)] 和少样本提示 [[19](#ch20.xhtml#r360)] 生成讲座准备材料。针对各自的查询，使用每种提示技术生成的材料，分别基于结构和内容质量，通过 Gemini Pro 和基于规则的评估进行打分和排名，随后进行人工评估。所提方法论的框架已在[图 10.1](#ch20.xhtml#f71)中可视化。

所考虑的五类查询如下：

*   **单主题查询（ST）：** 包含 138 个查询，旨在提供单一主题的讲座准备材料，例如 `Arrays`、`Linked Lists`、`Stack` 等。
*   **主题组合查询（TC）：** 包含 70 个查询，旨在提供主题组合的讲座材料，例如，为主题 B 解释主题 A，或在主题 C 中为主题 B 解释主题 A，或讨论主题 B 中的主题 A，或向主题 B 说明主题 A，即 `give lecture preparation material on implementing stacks using linked list`（提供使用链表实现栈的讲座准备材料）。
*   **对比查询（CQ）：** 包含 11 个查询，旨在编排各类算法/技术/方法的对比讲座材料，如主要查询。例如，`Provide lecture preparation material comparing various sorting techniques like selection sort, bubble sort or insertion sort`（提供对比选择排序、冒泡排序或插入排序等各类排序技术的讲座准备材料）。
*   **编程问题查询（PQ）：** 包含 48 个查询，旨在提供编程问题的讲座材料。例如，`Share lecture preparation material on the programming problem fractional`（分享关于编程问题 fractional 的讲座准备材料）。
*   **OOPs 与复杂度查询（OCQ）：** 包含 7 个查询，旨在提供 OOPs 和复杂度相关主题的讲座材料。例如，`Share lecture preparation material on inheritance`（分享关于继承的讲座准备材料）。
