

### 8.4.6 基于情感的特征

情感分析被发现通过提取情感、态度和观点等要素，有助于从在线社交媒体中识别可疑账户 [[45](#ch18.xhtml#r248)]。当与其他提取的特征结合时，它在假新闻检测中也被证明很有用 [[26](#ch18.xhtml#r229)]。之所以会出现这种情况，是因为假新闻往往偏向于某一类情绪。当人们体验到积极或中性情绪时，他们更倾向于相信某项声明是“真实的”；而当他们体验到消极情绪时，可能会变得更加怀疑 [[46](#ch18.xhtml#r249)]。

情感极性是情感分析中的重要要素之一。它有助于确定所陈述情感的倾向。例如，它可以帮助识别文本是从陈述中表达为消极、中性还是积极情感。在本项目中，我们使用自然语言工具包（`NLTK`）中的情感分析器提取极性得分作为特征之一 [[47](#ch18.xhtml#r250)]。该包中有四种不同的得分：积极、消极、中性和复合得分。每种得分的极性得分范围均为 −1 到 +1，且积极、消极和中性得分之和将等于 1。复合得分是积极、消极和中性得分的总和，范围从极度消极 (−1) 到极度积极 (+1)。文本越积极，复合得分越接近 +1。我们提取了 8 个基于情感的特征。[表 8.5](#ch18.xhtml#t17) 显示了基于情感的特征的详细信息。

**表 8.5** 提取的基于情感的特征详情[⏎](#ch18.xhtml#t17b)

| 特征名称 | 数据类型 | 描述 |
| --- | --- | --- |
| `neg content` | N | 正文中的消极情感计数。 |
| `neg title` | N | 标题中的消极情感计数。 |
| `pos content` | N | 正文中的积极情感计数。 |
| `pos title` | N | 标题中的积极情感计数。 |
| `neu content` | N | 正文中的中性情感计数。 |
| `neu title` | N | 标题中的中性情感计数。 |
| `compound content` | N | 正文中情感的复合得分。 |
| `compound title` | N | 标题中情感的复合得分。 |

注：N，数值型。

### 8.4.7 基于命名实体识别（NER）的特征

NER 是一种用于识别和分类文档中出现的指定实体的过程。根据 Shelar 等人 [[48](#ch18.xhtml#r251)] 的研究，NER 工具通常会扫描整个文本文档，并对实体进行分类，如地点、组织、日期、重要人物等。它通过为每个文本文档使用已知的相关标签，按定义的层级对文章进行分类，从而实现轻松的内容发现。借助 NER 方法，我们可以识别实体之间的关系以及新闻或文章的真实性。例如，当选举发生时，假新闻往往会将重要人物的名字作为标题来吸引公众。在本工作中，我们使用来自 `spaCy` 库的训练模型 “en_core_web_sm”（一个英语管道，包含词汇、句法和实体，基于书面网络文本文档如评论、新闻和博客进行训练）。[表 8.6](#ch18.xhtml#t18) 显示了训练模型中 NER 方法的命名实体示例。来自 [[3](#ch18.xhtml#r206)] 的一项研究表明，大多数假新闻与政治新闻有关，因为在 2012 年和 2016 年美国总统大选期间，Twitter 上的虚假信息或政治谣言激增。这促使我们在开发假新闻检测模型时，重点关注与政治新闻更相关的实体，如组织（`ORG`）、重要人物（`PERSON`）、地理政治实体（`GPE`）和货币（`MONEY`）。我们提取了八个 NER 特征。[表 8.7](#ch18.xhtml#t19) 显示了所有提取的基于 NER 的特征的详细信息。

### 8.4.8 文本特征

我们在 `FNDetector` 模型中也使用了文本特征。我们使用了词形还原的标题（带词性标注）和词形还原的正文（带词性标注）（参考 [表 8.8](#ch18.xhtml#t20)）。然而，由于文本特征不能直接输入分类器，我们对 `RF` 分类器使用了词频-逆文档频率（`TF-IDF`），对 `LSTM` 分类器使用了分词器。以下是关于 `TF-IDF` 和分词器的更多细节。

**TF-IDF**：根据 Qaiser 和 Ali [[49](#ch18.xhtml#r252)] 的研究，词频（`TF`）是指特定术语在文档中出现的次数。要计算特定术语的逆文档频率，可以使用以下公式：

```
TF = 词语出现次数 / 文档总词数
```
(8.1)

例如：如果一篇 2000 词的文档包含 5 次 “library” 一词。该词 “library” 的 `TF` 将为 5/2000，即 0.0025。所有术语在文档中都起着重要作用。逆文档频率（`IDF`）旨在为特定术语分配权重。`IDF` 算法为文档中不常见的术语分配较高的权重，为常见术语分配较低的权重。要计算特定术语的 `IDF`，可以使用以下公式：

```
逆文档频率 (IDF) = log_e(文档总数 / 包含该术语的文档数)
```
(8.2)
