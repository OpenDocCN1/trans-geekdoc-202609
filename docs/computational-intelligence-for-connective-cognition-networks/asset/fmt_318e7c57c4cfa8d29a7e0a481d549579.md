## RQ 5: What is the effect on the performance of FNDetector model by changing parameters of RF and LSTM classifiers?

### Motivation

The parameters of an algorithm play an important role as they can impact the performance of an algorithm. It's critical to adjust an algorithm's settings in order to build a high-accuracy model. In this RQ, we will present what is the effect on the performance of the `FNDetector` model by changing the parameters of `RF` and `LSTM` classifiers. We also compute the time it requires to train the models as well as the time required to make the predictions. We believe that time can be an important factor in choosing the appropriate classifier in resource-constrained applications like mobile devices.

### Approach

To answer the RQ, we perform several experiments with the `FNDetector` model using `RF` and `LSTM` variants. We create a total of seven variants of the `FNDetector` model, three using `FNDetector[RF]` and four using `FNDetector[LSTM]`. For `FNDetector[RF]`, we tested the performance of the model for three different values of the estimator, i.e., 50, 100, and 150. For `FNDetector[LSTM]`, we tested the performance of the model by changing epochs and batch size. We use 2 different epochs, i.e., 5 and 10 epochs, and 2 different batch sizes, i.e., 128 and 256 respectively. [Table 8.20](#ch18.xhtml#t32) shows the parameters and values that we use to perform the experiments.

The time required to train the model and generate a prediction was then calculated. We compute the time it takes to build the model using the training dataset for both `FNDetector[RF]` and `FNDetector[LSTM]` classifiers for different parameters (number of estimators (for `RF` classifier) and epoch & batch size (for `LSTM` classifier)) as discussed above.
