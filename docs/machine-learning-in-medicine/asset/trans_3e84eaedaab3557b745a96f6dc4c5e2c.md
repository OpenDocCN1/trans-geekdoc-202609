
计算累积分布函数（CDF）

PDF 的积分用于生成 CDF。（随机变量 *X* 的 CDF *F*[X] 通过其 PDF *f*[X] 使用 `$F_{X}\left( x \\right) = \\int\\limits\_{- \\infty}^{x}f_{X}\\left( t \\right)dt$` 计算。）CDF 显示血管在小于或等于代表每个切片中平均血管直径的直径值时，累计概率的总和。CDF 在上限为 1 的情况下显示 PDF 的累计分布。CDF 线越快接近 1，说明血管直径相对于 CDF 线较慢接近 1 的情况更小。此现象在结果部分有所说明。

### [13.2.3 统计分析](#C20_chapter13.xhtml#rsecc013_3_3)

统计分析使用 R 软件（版本 3.3）进行。采用混合效应线性模型检验 MRA 数据与临床血压（BP）测量的关系。将脑切片分为上部（位于 Willis 环上方）和下部（位于 Willis 环下方）两个区域，以评估其与临床血压读数的相关性。Willis 环位于大脑底部，是颅内脑血管动脉起始并逐渐分支的部位 \[[5](#C20_chapter13.xhtml#ref13_5)\]. 血压测量被合并为一个值，即估计均压 MAP = (2 × DBP + SBP)/3，该值作为模型的协变量。模型还包含患者年龄、性别以及每位患者的随机截距。因变量为每个区域内血管树的欧氏距离图的平均值。（分别为上下区域拟合了两个独立模型。）固定效应的统计显著性通过似然比卡方测试确定。

### [13.2.4 3D 脑血管重建](#C20_chapter13.xhtml#rsecc013_3_4)

采用一种能够通过去除任何不需要的分割体素的生长树模型，并结合平滑算法，以基于分割切片生成 3D 模型 \[[23](#C20_chapter13.xhtml#ref13_23)\]。下图展示了生成的血管系统的示例可视化和插图，位于结果部分。
