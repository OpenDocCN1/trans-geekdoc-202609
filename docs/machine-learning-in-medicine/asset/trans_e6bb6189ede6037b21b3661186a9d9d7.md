
与人工智能在各个领域的迅猛发展相吻合，基于机器学习的检测技术已被发现与传统的半自动诊断系统相结合。在Ref. \[[5](#C15_chapter8.xhtml#ref8_5)\]中，典型的例子是构建了一个基于19频道EEG系统的管道，用于AD和MCI检测。广泛探索了该领域常用的各类特征，包括传统频率带的相对功率、中位频、个体α频率、光谱熵、Lempel–Ziv复杂度、中心趋势测度、样本熵、模糊熵和自动互信息。采用快速相关滤波器（fast correlation-based filter）进行特征选择，最终保留了个体α频率、δ频段的相对功率以及样本熵用于分类。对三种传统分类器——线性判别分析（LDA）、二次判别分析以及多层感知器人工神经网络（MLP）进行了测试，结果表明MLP在三者中表现最佳。借助ML技术，该完全自动化系统通过标准灵敏度和特异度进行了评估：在判断受试者是否健康时，HC相对于AD和MCI的灵敏度为82.35%，阳性预测值为84.85%；在判断受试者不患AD时，特异度为79.41%，负性预测值为84.38%。值得注意的是，尽管研究中涉及三类，实际上系统仍在进行二类分类，这可能表明三类识别场景目前仍是一项相当困难的任务。众所周知，MCI是AD的前临床阶段，其与AD和HC的症状区分往往相当模糊。

基于ML技术的AD检测性能显著提升。同样使用19频道EEG系统，Ref. \[[6](#C15_chapter8.xhtml#ref8_6)\]的工作比Ref. \[[5](#C15_chapter8.xhtml#ref8_5)\]提升了10%以上。数据采集时，受试者（20例AD，32例HC）处于不同状态：低血压、清醒、困倦、警觉，以及眼闭合与眼开的时段。研究探索了三种特征：Tzallis熵（TsEn）、Higuchi分形尺寸（HFD）和Lempel–Ziv复杂度（LZC），其中LZC表现最佳，并使用SVM分类器：实现了100%灵敏度、92.31%特异度以及95%识别准确率。

与测量单个振幅 \[[3](#C15_chapter8.xhtml#ref8_3)\]不同，机器学习辅助的AD诊断更关注信号间的功能连接。Ref. \[[7](#C15_chapter8.xhtml#ref8_7)\]提出的方法在使用16频道EEG设备时，通过非线性支持向量机（SVM）实现了98.9%的高平均识别率。该方法开发了一种新的指标——许可偏差指数（PDI），用于衡量两个电极间信号的耦合强度。作为功能连接相关指标，PDI与信号耦合强度呈反相关。实验中，14例AD和14例HC参与，采用单因素方差分析进行统计检验。将局部PDI特征与全局复杂度测度——图指数复杂度（GIC）相结合，系统性能得到显著提升：准确率提升了6%以上。报告的AD识别率是1000次随机测试的平均值。值得注意的是，这些识别率是基于每类仅14名参与者的相对较小样本得出的，新提出的指标的稳健性仍需在更大的人群中验证。

更具挑战性的任务是预测MCI向AD的转换。这种转换往往仅在大脑的部分区域出现，因此源定位至关重要。在Ref. \[[8](#C15_chapter8.xhtml#ref8_8)\]中，研究人员提出了一种有趣的方法，无需进行传统的源重建算法即可定位感兴趣的来源：基于假设，远距离电极站点之间不同频率功率的同步增加与降低不太可能由同一共同来源产生，且 trial‑by‑trial 的负相关性使得这种情况难以实现。他们报告灵敏度为95%，特异度为80%。特别值得注意的是，这是一项关于MCI向AD转换的纵向研究，25名表现出胼胝性失忆的MCI患者中，15人在3年内发展为AD。分类对象为11名老年对照者。

2015年，Ref. \[[9](#C15_chapter8.xhtml#ref8_9)\]进行了早期的ML辅助MCI诊断尝试。该项目结合了使用同一306通道Vectorview系统采集的多个MEG数据库，最终获得102例MCI和82例HC的数据。计算了各频段的互信息作为特征，包括θ（4–8 Hz）、α（8–12 Hz）、β（12–30 Hz）、γ（30–45 Hz）以及宽带（2–45 Hz）。经评估多种分类器并对参数进行优化，包括随机森林、贝叶斯网络、C4.5决策树、k近邻、逻辑回归和支持向量机。采用Bootstrapping进行交叉验证。优化后的结果为灵敏度100%、特异度69%、分类准确率83%。这些使用MEG的首次结果相当有前景，尤其考虑到参与人数相对较多。

如前所述，EEG用于AD检测已取得相当好的性能 \[[7](#C15_chapter8.xhtml#ref8_7)\]，而EEG用于MCI检测往往不够有效 \[[8](#C15_chapter8.xhtml#ref8_8)\]，可能是由于EEG系统的电极数量相对较少。相反，MEG凭借更大的传感器数量可能缓解这一问题。例如，研究人员利用148通道MEG系统成功区分MCI和HC，成功率达98.4% \[[10](#C15_chapter8.xhtml#ref8_10)\]。参与者（18例MCI，19例HC）在数据采集时进行字母记忆任务。采用完整经验模态分解（CEEMD）进行特征提取，随后利用 permutation entropy 分析计算非线性动力学度量。增强概率神经网络（EPNN）被用于分类。得益于CEEMD，该方法在非平稳信号（如E/MEG）处理中表现出色，其相关变换在其他EEG应用中也被证明有效 \[[11](#C15_chapter8.xhtml#ref8_11)\]。
