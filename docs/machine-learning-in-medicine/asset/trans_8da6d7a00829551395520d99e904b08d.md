
平均累积分割算法的灵敏度为 0.997 ± 0.008，特异性为 0.9998 ± 0.001。这种高精度的表现表明，使用手动输入来初始化自动分割具有明显的好处。单独使用手动分割在实际医疗环境中过于耗时，而仅使用自动分割方法则无法提供足够的准确性来划分和量化直径小于 10 μm 的脑小动脉（arteriolar）血管。所提议的分割算法结合了手动分割的精度与自动化、时间更节约的优势，能够在保持高精度的同时，最大程度地减少所需的时间和努力。

我们方法的高灵敏度和特异度能够准确地将血管与周围脑组织区分，从而实现脑血管变化的量化。PDF 显示了从第 0 天到第 700 天血管直径的总体变化。在 Willis 环（circle of Willis）下方，PDF 与系统血压（BP）之间存在统计学相关性（*P* = 0.0007），表明血压升高（即 CPP 增加）与平均血管直径下降及 PDF 减小相关。BP 和 MAP 测量与大多数患者在 Willis 环下方的非侵入性平均 PDF 直径测量相吻合良好。由于已假设脑部变化会在系统性高血压出现之前发生 \[[9](#C20_chapter13.xhtml#ref13_9),[10](#C20_chapter13.xhtml#ref13_10),[26](#C20_chapter13.xhtml#ref13_26)\]，我们的方法可能成为一种工具，用于在结合其他方法（如认知测试）的情况下，及早开展或优化系统性高血压（HBP）的管理。该发现很重要，因为它表明血压升高导致的血管重塑在诊断性必然性高血压（essential hypertension）出现之前就已经发生。本研究中选取的个体明确具有前高血压的血压值，该方法可用于确定脑血管重塑与脑小血管病变之间的关系，而脑小血管病变在高级高血压中已知会伴随中风和痴呆的风险 \[[27](#C20_chapter13.xhtml#ref13_27),[28](#C20_chapter13.xhtml#ref13_28)\]。PDF 与 MAP 的相关性与患者性别无关。 Willis 环上方血管的 PDF 差异在统计学上与年龄相关，表明老年患者的脑血管可能出现收缩，这可能使其中风风险更高。

在患者 C 和 D 中，CDF 的变化未能与 MAP 的变化相关，这可能提示脑血流自调功能受损，可能是由于脑血管重塑所致 \[[5](#C20_chapter13.xhtml#ref13_5),[26](#C20_chapter13.xhtml#ref13_26)\]。这三维脑血管重建显示在第 0 天至第 700 天之间存在显著的血管变化。这些结果可能表明，仅凭系统血压来开具药物治疗可能无法提供最佳的医疗管理。CDF 与 MAP 之间的相关性缺失可能提示血管改变以及脑血管不良事件的更高风险，这需要更频繁的监测和/或优化医疗管理，即使系统血压和 MAP 正常。结合 BP 与 CDF 的变化可能有助于降低不良事件的发生率。

所提方法采用 MRA，直接可视化整体脑血管解剖结构，并且对小血管的分辨率高于多普勒超声，后者主要评估血流或在其视野内单一或少数血管的特性。MRA 是获取小脑血管准确三维结构所必需的成像方式。常规使用所提 MRA 方法进行筛查成本较高。其临床重要性在于难治性高血压（treatment‑resistant hypertension），该病症目前仍缺乏深入理解 \[[29](#C20_chapter13.xhtml#ref13_29)\]。最近一项研究提供了令人信服的数据，表明此类患者可能存在血管异常（如 Willis 环畸形），而我们的技术可以轻易检测到 \[[30](#C20_chapter13.xhtml#ref13_30)\]。其他研究也提出，此类高血压可能是因脑血管受脑干血压调节区域的压迫所致 \[[31](#C20_chapter13.xhtml#ref13_31)\]。这些异常一旦被发现，就能指导临床治疗，而目前的药物剂量尚未解决这些问题。此外，有家族史或临床史导致高血压风险升高的患者，也可以通过本方法进行筛查，以在疾病发病前检测血管变化并管理高血压，尽管检测血管变化和管理高血压的成本较高。

分割算法及血管和 BP 变化（CDF 与 PDF）指标并不局限于脑血管，这些方法同样可用于量化其他对血压敏感的器官（如肾脏）的血管变化。

## [13.5 Limitations](#C20_chapter13.xhtml#rsecc013_6)

尽管我们的分割算法在自动分割方法上有显著提升，但仍受到 MRI 机器分辨率的限制。CDF 直径（[Figure 13.5](#C20_chapter13.xhtml#f13_5)）从 0.5 mm 开始，因为距离图计算是基于血管边缘的半径，而 MRA 成像的每像素代表 0.25 mm。低于 0.5 mm 的数值无法被准确表示，导致血管直径小于 10 μm（在 Willis 环上方）的统计分析精度下降。

研究期间，受试者使用了多种非处方药物和保健品，这些药物引起的血压变化应当很小。不过，仍需要更大的样本量来确定其与高血压进展之间的 definitive 关系。虽然假设升高的 CPP 会在系统性高血压之前出现，但必然性高血压的成因仍是多因素的拼图，尚未完全阐明。尽管存在这些局限性，我们的方法仍对理解与高血压相关的脑病理具有重要意义，无论该病理是先于临床高血压出现，还是随之而来。
