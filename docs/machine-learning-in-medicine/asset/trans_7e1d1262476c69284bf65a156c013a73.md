
# 研究结构的体积特征的绝对值（均值和标准差），发现这些特征既不能用于**侧化**，也不能用于**左/右侧化**，无论是**海马萎缩（HS-P）**患者还是**非海马萎缩（HS-N）**患者。相反，由 **Eq. (6.3)** 计算得到的**归一化体积特征**在**海马**上显示出**HS-P**组内左右侧患者之间**不存在重叠**。因此，**海马萎缩**的归一化体积特征能够在 **HS-P** 患者中**100%** 精确地侧化 **mTLE**。然而，**归一化体积特征**并未能够**完全区分 HS-N** 组内的左右侧患者。

总体而言，研究各结构萎缩与**癫痫侧性**之间的关系的结果表明，**归一化体积特征**——包括**海马**、**杏仁核**和**丘脑**——**单独**无法**唯一确定**癫痫侧性的**侧**。 

在 **Ref. [61](#C13_chapter6.xhtml#ref6_61)** 中，基于多结构体积特征的 **mTLE** 侧位化采用了 **Eq. (6.4)** 中简化的 **logistic probability function**。68 名患者的参数估计和位置结果如 **[Figure 6.4a](#C13_chapter6.xhtml#f6_4)** 所示。判别阈值被设定为 **logistic probability function** 等于 **0.5**：

$${Pr\\left\\lbrack L \\middle| \\operatorname\\left\\lbrack {f\_{1},\\operatorname{}f\_{2},\\operatorname{}f\_{3}} \\right\\rbrack \\right\\rbrack = \\frac{e^{\\beta\_{0}^{L} + \\beta\_{1}^{L}f\_{1} + \\beta\_{2}^{L}f\_{2} + \\beta\_{3}^{L}f\_{3}}}{1 + e^{\\beta\_{0}^{L} + \\beta\_{1}^{L}f\_{1} + \\beta\_{2}^{L}f\_{2} + \\beta\_{3}^{L}f\_{3}}} = 0.5}\\mspace{54mu}\\operatorname{(6.5)}$$

这导致在三维特征空间中出现一个**平面**，即 **β*[0]^(*L*) + β*[1]^(*L*)*f*[1] + β*[2]^(*L*)*f*[2] + β*[3]^(*L*)*f*[3] = 0**。该平面可以在二维特征空间中投影，例如 **海马–杏仁核** 和 **海马–丘脑** 空间。 **[Figure 6.4b](#C13_chapter6.xhtml#f6_4)** 展示了三维特征空间中左、右 **TLE** 患者的散点图以及决策平面。为了更好地说明，决策平面在对应的二维特征空间中投影，分别在 **[Figure 6.4c](#C13_chapter6.xhtml#f6_4)** 和 **[d](#C13_chapter6.xhtml#f6_4)**。

## [6.4 Discussion](#C13_chapter6.xhtml#rsecc006_4)

在本章中，我们回顾了旨在**开发结构生物标志物**以**侧化 mTLE** 的研究。其目标是通过**提取、选择和修改结构性和纹理特征**，来**诊断癫痫**或**侧位化 mTLE 患者**。

在 **Study I** 中，采用**线性判别器**利用 **FLAIR** 和**体积特征**区分**右侧**与**左侧** mTLE。海马的 **FLAIR 均值信号强度** 和 **标准差** 组合能够**有效**区分 mTLE 患者的**侧向**（**准确率 98%**），而**海马体积特征**仅能达到 **83%** 的准确率。该准确率是在**不存在双侧患者**且**未考虑对照组**的情况下获得的。当使用对照组来确定不确定的边界时，准确率下降至 **75%**（详情请参见 **[Table 6.1](#C13_chapter6.xhtml#t6_1)**）。基于本研究提供的证据，我们得出结论：**海马 FLAIR 强度的不对称性（均值和标准差）** 可能为**海马萎缩（HS）**及**癫痫侧向**提供**额外生物标志物**，除了**海马体积不对称**之外。

除了海马的均值和标准差外，本研究还提取了 **四种传统纹理特征**（**共现矩阵、运行长度矩阵、绝对梯度、直方图**）来研究 **FLAIR 强度** 的纹理特征。由 **Eq. (6.1)** 定义的**小波变换能量特征**能够以 **94%** 的准确率正确分类**单侧海马萎缩**为**右侧**和**左侧** mTLE，这表明**小波基特征提取**具备用于 mTLE 侧位化的能力。关于本研究可能引发的三个问题：(1) **样本量小**（36 名患者，20 左侧、16 右侧），(2) **未将双侧病例作为额外类别**，(3) **依赖于分割准确性**。

在 **Study II** \[[37](#C13_chapter6.xhtml#ref6_37)\]，当**海马萎缩不存在**时，采用**杏仁核 FLAIR 强度特征**进行侧位化。仅使用杏仁核特征时，**侧向**的**准确率仅为 29%**；而使用**海马**的类似特征则可达到 **70%** 的准确率。值得注意的是，**22%** 的**无法**以**信心**侧位化的**海马 FLAIR** 案例，能够**信心**地使用**杏仁核 FLAIR** 特征进行侧位化，这可能是**以往报告** \[[64](#C13_chapter6.xhtml#ref6_64)\] 的有力证据。此外，结果表明**自动化杏仁核分割**足以满足本研究需求，所有**错误侧位**的患者均落在**不确定边界**内。由于本研究使用的数据来自不同扫描仪（1.5T 和 3T），若**未校正 FLAIR 图像的强度不均匀**，扫描仪差异可能会影响结果。

与 **Study I** 类似，本研究**未考虑双侧病例**，因为重点在于**Engel Ia 结果**的患者。这意味着**前一研究缺乏双侧类别**的局限性仍未得到解决，而另外两项局限性已得到适当处理。该研究的另一局限性是**未探讨与 mTLE 相关的杏仁核体积变化**。
