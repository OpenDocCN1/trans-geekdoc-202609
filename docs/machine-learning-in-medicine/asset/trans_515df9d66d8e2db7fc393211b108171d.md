
数据增强在过去几年中被广泛研究，以进一步提升机器学习的能力。数据增强包括改变一张图像的某些方面，使神经网络暴露于现实世界中常见的变异性。在眼科领域，一项研究专门探讨了数据增强对神经网络性能的影响 \[[18](#C10_chapter3.xhtml#ref3_18)\]。将OCT图像输入神经网络，模型被期望能够区分五种不同的OCT情况：– 急性黄斑变性、中间性黄斑下血肿、糖尿病视网膜病变、黄斑裂孔和正常。本分析中使用的具体数据增强技术包括旋转、宽度和高度剪切、水平翻转以及高斯噪声。在高斯噪声数据增强中，噪声根据高斯分布添加到图像上，导致模型高频特征的失真。将这些数据增强技术加入后，AUC提高了6%（从0.91提升至0.97），平均灵敏度、特异度、阳性预测值（PPV）和阴性预测值（NPV）均有所增加。数据增强是提升CNN性能的有力工具，未来的研究很可能专注于精细调整这些技术，以确定哪些技术对性能最有益，以及哪种技术组合能带来最佳整体效果。

## [3.6 Machine Learning for Predicting Survival/Prognosis](#C10_chapter3.xhtml#rsecc003_6)

尽管机器学习在眼科领域的整合主要集中在图像分析上，但也有研究探讨了机器学习的其他应用。例如，Damato等人研究了人工神经网络在治疗脉络膜肉瘤患者后估计生存概率的应用 \[[19](#C10_chapter3.xhtml#ref3_19)\]。年龄、性别、最大基底肿瘤直径、巩膜体受累、眼外扩展、肿瘤细胞类型、闭合环、分裂率以及染色体3单体缺失的存在等患者特征被神经网络用于生成生存曲线。特征和风险因素分别以及组合进行了分析。研究发现，高恶性度肿瘤中最具预测性的因素是基底肿瘤直径。此外，组合分析表明，将细胞遗传学和病理数据纳入模型后，某些因素（如巩膜体受累和眼外扩展）的重要性下降。在医疗领域，通过机器学习发现多个风险因素之间的相互作用以预测生存，是其显著优势之一。

## [3.7 Conclusion](#C10_chapter3.xhtml#rsecc003_7)

机器学习在诊断糖尿病视网膜病变和年龄相关性黄斑变性（AMD）方面取得了显著进展。近年来，它也被用于其他眼科疾病，包括青光眼、白内障和早产儿视网膜病变等。基于AUC、灵敏度和特异度等统计指标，神经网络在检测这些疾病过程中表现出色。眼科机器学习的下一阶段可能包括纳入多个种族/民族的眼底和OCT图像，以更好地考虑不同种族间的变异性。此外，由于机器学习在二元分类中的成功，未来的研究很可能专注于使用神经网络对多种疾病过程进行预测。2018年，FDA批准了人工智能用于糖尿病视网膜病变的检测，随着深度学习模型的持续改进，其在真实医疗环境中的采用预计将继续增长。此外，除了图像检测外，机器学习在识别眼科疾病严重程度的风险因素方面也已被证明具有价值。
