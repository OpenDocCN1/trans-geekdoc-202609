
与传统数值方法相比，CNN 由于细胞的集体和同步计算活动，为热剂量建模中的生物热传递方程求解提供了一种快速的方法。非线性生物热传递动力学通过非线性细胞动力学建模，以细胞的局部交互和全局传播方式在时间上演化。通过根据不同组织/肿瘤材料在不同区域的特性设置细胞参数的不同值，实现了软组织热异质性的适应。与 CNN 传统应用领域（主要用于图像处理）相比，所提出的 CNN 被设计为将生物热传递机制纳入，以高效、有效地计算软组织温度场，并支持热消融癌症治疗的计算机辅助操作。

热剂量（公式 4.1）的计算表明，热剂量受组织热暴露历史的影响，该历史与组织温度和加热时间相关。由于生物热传递方程的变异由热源控制，而热源是由各种热模式诱导的，热剂量可通过操作者通过仪器功率和加热时间来控制。相同材料点的热剂量可通过（1）高功率短时加热或（2）低功率长时加热实现；然而，热剂量分布（如在 `[Figures 4.8](#C11_chapter4.xhtml#f4_8)` 和 `[4.13](#C11_chapter4.xhtml#f4_13)`）在（1）和（2）之间可能不同，因为在长加热期间，热扩散和血液灌注的影响会更显著，而在短加热期间这些影响较小。此外，需注意组织加热是一个随温度变化的材料属性和物理形状动态变化的过程，补偿这些变化可提高热剂量计算的精度 `[[62](#C11_chapter4.xhtml#ref4_62)]`，同时考虑组织变形（如器官运动 `[[63](#C11_chapter4.xhtml#ref4_63)]` 以及热膨胀与收缩的影响）也能进一步提高精度。

虽然微创热模式（如 RFA 和 MWA）在治疗肝癌和提供比肝切除更安全的选择方面有效，但它们也存在局限性。例如，RFA 的主要并发症率约为 4%，死亡率 ≤1% `[[64](#C11_chapter4.xhtml#ref4_64)]`。大多数并发症（如肠穿孔或胆道损伤）源于肝脏相邻器官组织的热损伤，尤其是在亚肝肿瘤和靠近门脉、胆囊的肿瘤中 `[[65](#C11_chapter4.xhtml#ref4_65)]`。虽然经 intra‑operative RFA 可避免这些并发症，但该方式更具侵入性，可能导致额外并发症和副作用。此外，位于大血管周围的肿瘤因血流的热吸走效应难以完全消融，限制了达到所需高温的能力。实验研究 `[[66](#C11_chapter4.xhtml#ref4_66),[67](#C11_chapter4.xhtml#ref4_67)]` 表明，若使用高能强度和短加热时间（≤ 2 秒）诱导热源，则该问题较不明显，因为加热迅速，受热扩散和血液灌注的影响较小。

如 `[Section 4.4.2](#C11_chapter4.xhtml#secc004_6_2)` 所述，与 RFA 和 MWA 相比，焦热消融（HIFU）具有非侵入性的优势，但需要精确跟踪器官运动，以同步 HIFU 传感器的焦点区域与目标肿瘤，从而准确诱导所需的热损伤 `[[68](#C11_chapter4.xhtml#ref4_68)]`。由于肝脏的生理运动主要由呼吸周期引起 `[[69](#C11_chapter4.xhtml#ref4_69)]`，其次是心脏运动和肠道运动，目标肿瘤会持续移动和变形，这使得精确、有效地进行 HIFU 能量沉积变得困难。因此，近期的研究重点转向连续目标跟踪技术，能够在运动周期中锁定超声束，实现连续能量沉积。实时磁共振成像（MRI）和诊断超声已被证明是可行的跟踪模态 `[[70](#C11_chapter4.xhtml#ref4_70),[71](#C11_chapter4.xhtml#ref4_71)]`。此外，由于器官运动导致的软组织变形 `[[72](#C11_chapter4.xhtml#ref4_72),[73](#C11_chapter4.xhtml#ref4_73)]`，在计算热剂量时必须考虑，需基于组织变形后的状态来计算热剂量，以确保在组织变形下热剂量的准确计算 `[[74](#C11_chapter4.xhtml#ref4_74)]`。

## [4.6 Conclusion](#C11_chapter4.xhtml#rsecc004_8)

本文提出了一种基于 CNN 的方法，用于快速计算和分析软组织温度及热剂量，以支持肝肿瘤的热消融治疗。为避免复杂且昂贵的数值非线性求解程序，本文将非线性生物热传递方程表述为 CNN 中细胞的非线性集体和同步局部与全局活动，从而得到嵌入生物热传递机制的神经网络模型，适用于 2D 和 3D 规则及不规则网格，实现快速的温度计算，支持计算机辅助热消融治疗。本文通过临床相关的场景 —  — 在患者特异性 HIFU 治疗中对肝癌进行热剂量建模，展示了 CNN 模型的应用。
