## [13.1 Introduction](#C20_chapter13.xhtml#rsecc013_2)

高血压（HBP）影响约三分之二的美国成年人。HBP是导致或显著促进410,000名成年人每年死亡率的主要原因，并伴随约460亿美元的医疗费用 \[[1](#C20_chapter13.xhtml#ref13_1)\]。HBP的主要原因及升高的脑灌注压力（CPP）的主要原因包括慢性压力 \[[2](#C20_chapter13.xhtml#ref13_2)\]，钠摄入量增加 \[[3](#C20_chapter13.xhtml#ref13_3)\]，以及肾功能问题 \[[4](#C20_chapter13.xhtml#ref13_4)\]。CPP是脑部灌注压力，取决于局部血管阻力和脑自调节。脑血管在长期升高的CPP下会发生结构变化，并扰乱脑血管调节机制。显著地，高CPP会导致脑血管的肥大和营养性重塑 \[[5](#C20_chapter13.xhtml#ref13_5)\]。在肥大性重塑中，由于升高的CPP，脑血管壁变厚，腔隙缩小。在营养性重塑中，平滑肌细胞的重新排列使得血管的总体质量和壁厚保持不变，而腔隙减小。这些脑血管改变被认为是中风、脑病灶、脑缺血损伤、痴呆和认知障碍的重要促成因素 \[[5](#C20_chapter13.xhtml#ref13_5), [6](#C20_chapter13.xhtml#ref13_6), [7](#C20_chapter13.xhtml#ref13_7)\]。

目前，HBP在使用血压计测量的系统血压大于140/90 mmHg时被诊断并进行医疗管理。然而，血压计测量无法量化脑血管结构变化，这些变化可能增加脑不良事件的风险。许多研究最近得出结论，脑血管结构的变化以及CPP的变化可能在系统血压升高之前就已经出现，而不是长期暴露于高血压导致的脑血管损伤 \[[8](#C20_chapter13.xhtml#ref13_8), [9](#C20_chapter13.xhtml#ref13_9), [10](#C20_chapter13.xhtml#ref13_10), [11](#C20_chapter13.xhtml#ref13_11)\]。因此，能够计算脑血管系统的变化，有助于识别和分层面临不利脑事件风险的人群。这可以在系统高血压出现之前，结合其他认知测试，进行早期干预，并优化高血压患者的医疗管理。
