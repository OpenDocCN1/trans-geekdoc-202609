
一种非侵入性的方法，在肾移植早期常用于评估肾移植物的状态，即扩散加权磁共振成像（DW-MRI）。该方法具有优势，因为它同时包含被检测软组织的解剖学和功能信息 \[[5](#C21_chapter14.xhtml#ref14_5)\]，并且避免使用造影剂，因为造影剂可能具有毒性。许多研究通过获取皮质表观扩散系数（CADC）或髓质 ADC（MADC）来测试 DW-MRI 的功能，取得了多种结果 \[[6](#C21_chapter14.xhtml#ref14_6)\]。然而，Abou-El-Ghar 等人的研究在 DW-MRI 中实现了成功的区分 \[[7](#C21_chapter14.xhtml#ref14_7)\]。他们的实验包括 21 例急性肾移植功能受损患者，其中 10 例为 TMR，7 例为 ATN，4 例为 IT 类排斥。他们还定义了一个位于肾脏单一横断面中部的感兴趣区域（ROI），涵盖整个肾实质并悬挂肾窦。如果某区域呈现更高信号强度或异常局部区域，则会获取另一 ROIs。显然，ATN 患者的 ADC 值呈异质性，因为它们是从三个不同组别计算得出的，形成马赛克样式，呈虎斑状。此外，在低 *b*-值下，扩散与血流在影响 ADC 值方面起主要作用；而在高 *b*-值下，血流对 ADC 值的影响不大。Eisenberg 等人的研究建议可通过手动放置单个 ROI 来覆盖肾移植物的大面积区域 \[[8](#C21_chapter14.xhtml#ref14_8)\]。随后，上、中、下髓质极的单个 ROI 合并，分别得到全髓质 ROI 和全髓质 ROI。五例患者中，四例出现急性排斥，剩余一例为 ATN。计算了标准差和均值等指标。该研究的问题在于缺乏出现移植功能障碍的患者，这导致 AR 与 ATN 患者之间的趋势不足以形成明显区分。其他研究 \[[9](#C21_chapter14.xhtml#ref14_9),[10](#C21_chapter14.xhtml#ref14_10)\] 表明，急性排斥（AR）中肾血流显著下降主要归因于灌注 MRI。然而，文献 \[[7](#C21_chapter14.xhtml#ref14_7),[8](#C21_chapter14.xhtml#ref14_8)\] 结论指出，水扩散和血流水平与 AR 肾移植物直接相关，但仅水扩散与 ATN 患者相关。

此外，BOLD MRI（血氧水平依赖 MRI）也被用于肾排斥研究。BOLD MRI 利用氧化血红蛋白的扩散血流来研究肾脏功能，具体而言，通过 apparent relation rate（ARR）参数计算去氧血红蛋白的含量 \[[6](#C21_chapter14.xhtml#ref14_6)\]。尽管髓质数值有所差异，多项研究指出 ATN 肾的髓质 ARR 高于 AR 肾 \[[6](#C21_chapter14.xhtml#ref14_6),[10](#C21_chapter14.xhtml#ref14_10), [11](#C21_chapter14.xhtml#ref14_11), [12](#C21_chapter14.xhtml#ref14_12)\]。文献 \[[11](#C21_chapter14.xhtml#ref14_11)\] 进一步指出，ATN 肾的皮质 ARR 高于 AR 肾。总体趋势是 ARR 值更高。但所有实验均存在局限性：手动二维 ROI 划分肾脏时出现主观划分误差，未考虑整体肾运动，未能在高低 *b*-值下融合 ADC，亦仅通过统计方法在特定 *b*-值间区分。

上述研究均未将 MRI 成像与临床生物标志物相结合，无法构建包含计算机辅助诊断的早期急性排斥（AR）识别系统。因此，需要一个能够克服这些局限的系统。我们的工作是一个完全自动化的早期急性排斥评估系统，如 [Figure 14.1](#C21_chapter14.xhtml#f14_1) 所示。该系统能够自动分割整个肾脏，从而能够处理任何运动。此外，系统可在 DW-MRI 分割得到的低 *b* 与高 *b* ADC 值上实现堆叠自编码器融合。在 [Section 14.3](#C21_chapter14.xhtml#secc014_3) 中，新开发的 CAD 系统的有希望的结果被展示。结果表明，该系统确实是一种非侵入性的诊断工具。

## [14.2 Methods](#C21_chapter14.xhtml#rsecc014_2)

为了评估肾移植物的状态，开发了一种精确的 Renal-CAD 算法（见 [Figure 14.1](#C21_chapter14.xhtml#f14_1)）。该系统必须包含若干步骤以得到最终评估。首先，需使用 DW-MRI 将肾脏从其余组织中分割出来。随后，在 [Section 14.2.2](#C21_chapter14.xhtml#secc014_2_2) 中，对肾的体素级 ADC 映射进行累积分布函数（CDFs）的提取或计算。最后，根据 ATN 肾的状态分配 TMR，以检验所提 CAD 系统是否为成功的诊断手段。

### [14.2.1 Preprocessing/Segmenting Kidneys](#C21_chapter14.xhtml#rsecc014_2_1)

从对 MR 图像进行偏置校正（bias correction）起步 \[[13](#C21_chapter14.xhtml#ref14_13)\]，随后对校正后的 MR 图像应用强度直方图均匀化，以降低噪声效应和偏置异构性。关于肾脏运动，采用 B-样条非刚性注册以降低主体间变异，使用平方差（SSD）作为度量。随后，采用 level sets 方法获得精确的 3D 肾脏分割 \[[15](#C21_chapter14.xhtml#ref14_15)\]。为了进行精确的肾脏分析，需在区域统计中加入考虑局部外观、形状和空间 MRI 特征的引导力，这些特征来自肾脏及背景区域。该引导力通过联合马尔可夫-盖布斯随机场（MGRF）图模型（joint Markov–Gibbs random field, MGRF）合并，具体包括局部外观 \[[17](#C21_chapter14.xhtml#ref14_17),[18](#C21_chapter14.xhtml#ref14_18)\]、形状以及空间 DW-MRI 特征（如在 [Figure 14.2](#C21_chapter14.xhtml#f14_2) 所示）。更多细节请参阅 Ref. \[[15](#C21_chapter14.xhtml#ref14_15),[19](#C21_chapter14.xhtml#ref14_19)\]。

### [14.2.2 Diffusion Features Extraction](#C21_chapter14.xhtml#rsecc014_2_2)

在肾脏分割完成后，必须从图像中提取具有歧视性的生理特征，以区分 ATN 与 ARTR 类型的 TMR。利用 Le Bihan 的 ADC 定义，下式计算排斥状态：

ADC[*p*] = (1/*b*[0] − *b*)ln (*g*[*b*] : *p*/*g*[0] : *p*） = ((ln*g*[*b*]−ln*g*[0]:*p*)/(*b*[0]−*b*))

为便于解释，[*p*] 表示在离散笛卡尔坐标（*x*、*y*、*z*）处的体素。[*g*[0] 与 *g*[*b*] 分别是采用 *b*[0] 与给定不同 *b*-值拍摄的分割 DW-MRI 图像。
