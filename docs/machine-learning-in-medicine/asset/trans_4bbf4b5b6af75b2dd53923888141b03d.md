## [1.1 Introduction/History](#C08_chapter1.xhtml#rsecc001_1)

当人们想到医疗领域的机器学习和人工智能时，最直观的想法是它们在放射学中的应用，用于通过胸部X光片/计算机断层扫描来诊断病理，以及在皮肤科中利用皮肤图像诊断病理。这些都是合理的应用，因为我们期望通过观察大量正常和病理图像，机器/神经网络能够辨识出定义每种病理的关键特征，并利用这些特征在未见图像中预测病理。上述应用也是首选，因为在这些领域已经取得了显著进展。例如，2019年5月，Google开发了一个深度学习算法用于通过计算机断层扫描检测肺癌。该深度学习模型的ROC曲线下面积达到94.4%，并且在诊断时超越了六位放射科医生，同时将假阳性率降低了11%，假阴性率降低了5% \[[1](#C08_chapter1.xhtml#ref1_1)\]。
