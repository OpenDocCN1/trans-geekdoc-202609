
-   [滑动窗口方法](https://wiki.example.org/feynmans_learning_method)受到`Ref. \[[20](#C17_chapter10.xhtml#ref10_20)\]`启发，用于将日常生活序列分割为时间片段。 (2) 时间片段被映射到如`Ref. \[[20](#C17_chapter10.xhtml#ref10_20)\]`所述的特征上。 (3) 然后，使用三种变体的`RNNs`，即`Vanilla`、`GRU`和`LSTM`以及`CNNs`来建模和分类活动。 (4) 最后，这些分类器用于根据分类混淆概率标记异常行为。

顺序传感器读数的顺序很重要，以考虑空间信息。我们使用滑动窗口方法将数据分割为活动实例。我们采用与`Ref. \[[20](#C17_chapter10.xhtml#ref10_20)\]`相同的滑动窗口方法，提取传感器读数片段，这些片段作为`RNNs`和`CNNs`的输入。窗口大小基于时间而非传感器事件数量（一个传感器读数元组称为传感器事件）。可以使用不同的时间窗口，例如1分钟切片、60秒切片等。如果使用1分钟窗口，则提取该分钟内的所有传感器读数。这些窗口随后映射为如下所述的特定表示。

### [10.5.1 传感器数据表示](#C17_chapter10.xhtml#rsecc010_5_1)

原始传感器读数使用滑动窗口映射为以下三种表示。

*   **`Binary`**：在该特征中，时间窗口内激活的传感器被赋值为1，未激活的传感器被赋值为0。

*   **`Change-point`**：在该特征中，如果在时间窗口内传感器从开到关或从关到开，则赋值为1，否则如果其状态保持不变则赋值为0。

*   **`Last-fired`**：在该特征中，仅有一个传感器被赋值为1，表示在时间窗口内最后被激活的传感器。

### [10.5.2 异常行为检测](#C17_chapter10.xhtml#rsecc010_5_2)

异常行为的检测如下：`RNNs`和`CNNs`使用训练集进行训练，然后将测试实例输入这些模型进行分类。分类置信度分数用于判断测试实例是正常还是异常活动。为此，使用每个类别训练实例的置信度分数的平均值作为阈值来决定异常。

在下一节中，将使用`Kasteren`数据集来评估`RNNs`，而`Aruba`数据集将用于测试`CNNs`的能力以及它们与`LSTM` RNNs的组合。

### [10.5.3 实验](#C17_chapter10.xhtml#rsecc010_5_3)

在本研究中，使用`Theano` \[[66](#C17_chapter10.xhtml#ref10_66)\]和`Keras`库 \[[65](#C17_chapter10.xhtml#ref10_65)\]的`RNN`和`CNN`实现。训练和测试实例的批量大小为20，选择`Adam`优化器。`RNNs`和`CNNs`与传统的机器学习方法如`SVM`（WEKA默认参数实现）、`NB`、`HMM`、`HSMM`和`CRF`（`Ref. \[[20](#C17_chapter10.xhtml#ref10_20)\]`实现）进行比较。

选择的评估指标为`precision`、`recall`、`F-measure`和`accuracy`（见公式10.1–10.4），用于测试拟议方法在活动识别方面的成功。下面列出的缩写用法：`TP`：真阳性，`TT`：真标签总数，`TI`：推断标签，`N`：数据集中的类别数，`Total`：数据集中实例的总数。

$${\\text{Precision} = {1/N}\\left( {\\sum\\limits\_{i = 1}^{N}{{TPi}/{TIi}}\\operatorname{}} \\right)}\\mspace{54mu}\\operatorname{(10.1)}$$  

$${\\text{Recall} = {1/N}\\left( {\\sum\\limits\_{i = 1}^{N}{{TPi}/{TTi}}\\operatorname{}} \\right)}\\mspace{54mu}\\operatorname{(10.2)}$$  

F-measure=2 × Precision × Recall/(Precision+Recall)   (10.3)   

$${\\text{Accuracy} = \\sum\\limits\_{i = 1}^{N}{{TPi}/\\text{Total}}}\\mspace{54mu}\\operatorname{(10.4)}$$  

敏感性（真阳性率）和特异性（真阴性率）指标（公式10.5和10.6）用于评估拟议方法在异常行为检测方面的成功。真阳性率（TPR）反映检测真实异常行为的能力，而真阴性率（TNR）测量识别正常行为的能力。

Sensitivity = TP/(TP+FN)   (10.5)   

Specificity = TN/(TN+FP)   (10.6)
