
-   [分割算法的应用并非仅限于肿瘤学情境。在颞叶癫痫（TLE）患者中，常见的发现是海马硬化 \[[24](#C19_chapter12.xhtml#ref12_24)\]。这些患者特别适合接受手术治疗（60% 无痫发作率），通常通过切除受影响的脑区进行 \[[25](#C19_chapter12.xhtml#ref12_25)\]。然而，没有海马硬化的患者手术成功率较低，因此临床上有用区分这两种颞叶癫痫亚型。为此，Keihaninejad 及其同事 \[[26](#C19_chapter12.xhtml#ref12_26)\] 使用机器学习对颞叶癫痫进行 MRI 分割与分类。分割后，作者采用 SVM 算法实现 TLE 与与海马硬化无关的 TLE 分类准确率分别为 96% 和 86%。类似的分割与分类工作在略有不同条件下（如基于额外海马外发现检测 TLE）也已开展 \[[27](#C19_chapter12.xhtml#ref12_27),[28](#C19_chapter12.xhtml#ref12_28)\]。

在脊柱领域，利用机器学习的诊断性出版物数量相较于颅内病变的研究较少，但用于脊髓病变诊断的机器学习文献正在快速增长并已取得重要进展。Jamaludin 及其同事 \[[29](#C19_chapter12.xhtml#ref12_29)\] 开发了一个模型，用超过 12,000 张椎体和椎间盘图像标记椎体与椎间盘。随后，他们构建了卷积神经网络，用于预测椎间盘退化程度（依据 Pfirrmann 分级）。最终，算法与人类对 Pfirrmann 评分的预测一致率分别为 70.1% 和 70.4%，两者相近。其他关于脊柱畸形（尤其是特发性脊柱侧弯）的研究也已开展，用于脊柱畸形的分类与分级 \[[30](#C19_chapter12.xhtml#ref12_30)\]。

在脊髓损伤（SCI）领域，Tay 及其同事 \[[31](#C19_chapter12.xhtml#ref12_31)\] 构建了基于扩散张量成像（DTI）的机器学习算法，用于判断轴位图像是否存在 SCI。关键特征为半向异性，它作为组织结构完整性的代理。具体而言，半向异性在 DTI 中用于描述图像中水的扩散及组织取向 \[[32](#C19_chapter12.xhtml#ref12_32)\]。作者在标记脊髓后，使用 SVM 和 k 最近邻模型对 DTI 图像进行受伤或正常的分类，半向异性作为预测变量。算法实现了 0.952 的特异性和 0.912 的灵敏度。

神经外科是唯一结合大量器官特异性术中监测模式的外科专科，这些模式包括术中成像、电生理监测和神经生理监测，用于确保手术成功。由于神经外科在每次手术中既依赖手工技巧，也依赖快速的诊断能力，因此将机器学习引入术中情境十分适合。

帕金森病是一种运动障碍，源于基底节中黑质中多巴胺神经元的退化 \[[33](#C19_chapter12.xhtml#ref12_33)\]。帕金森病的药物治疗通过增强多巴胺活性来缓解症状 \[[34](#C19_chapter12.xhtml#ref12_34)\]。然而，对于医学治疗无效的患者，深脑刺激（DBS）于基底节结构（如下丛节，STN）的手术干预是选项 \[[34](#C19_chapter12.xhtml#ref12_34),[35](#C19_chapter12.xhtml#ref12_35)\]。在该手术中，微电极记录仪通过大脑进行穿刺以映射相关脑结构并理想地定位 STN。Taghva 使用隐马尔可夫模型判断微电极在 DBS 过程中是否位于 STN，基于实际手术中使用的模拟脑解剖结构 \[[36](#C19_chapter12.xhtml#ref12_36),[37](#C19_chapter12.xhtml#ref12_37)\]。模型在分类模拟微电极位置时实现了 98%–99% 的准确率，且在判断微电极是否位于 STN 时的特异性和敏感度均超过 95%。虽然经验丰富的 DBS 外科医生通常能够识别 STN，但该算法可辅助其识别，并可能推广至帕金森病的新靶点。

颅内压（ICP）监测，尤其是在创伤性脑损伤患者中，是神经外科医生手中的重要工具 \[[38](#C19_chapter12.xhtml#ref12_38)\]。在术中情境下，ICP 监测被认为具有重要的治疗和预后意义 \[[39](#C19_chapter12.xhtml#ref12_39)\]。ICP 形态因此具有重要的诊断价值，尤其是在术中应用时。Nucci 及其同事 \[[40](#C19_chapter12.xhtml#ref12_40)\] 开发了人工神经网络以检测和分类脑脊液压力波形。以专家审查者的诊断为“地面真理”，神经网络在分类脑脊液压力波时实现了 88.3% 的准确率。理论上，这些结果可推广至术中场景，帮助神经外科医生快速解读 ICP。

脊柱手术常伴随脊髓受损风险，因此术中电生理监测可帮助外科医生识别并预防潜在的神经功能缺损。Somatosensory evoked potentials（SEPs）常用于评估脊髓的电生理状态 \[[41](#C19_chapter12.xhtml#ref12_41),[42](#C19_chapter12.xhtml#ref12_42)\]。然而，各种手术和麻醉因素会干扰 SEP 读数，且人类专家对 SEP 的解读可能存在 inter-rater 差异 \[[43](#C19_chapter12.xhtml#ref12_43)\]。为解决这些问题，Fan 及其同事 \[[44](#C19_chapter12.xhtml#ref12_44)\] 构建了最小二乘支持向量回归模型以构建 SEP 基线；该基线相较于名义基线在成功的 SEP 监测和防止脊髓损伤误警报方面表现更佳。
