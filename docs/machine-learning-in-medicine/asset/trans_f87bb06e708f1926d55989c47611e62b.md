
为确定 LCDG 模型，采用包含期望对数似然的标准，即 \[[16](#C20_chapter13.xhtml#ref13_16)\]。假设一个三维 MRA 图像由 `***X***` = (`***X***`[s]: *s* = 1,…, *S*) 表示，其中包含 *S* 个共注册的二维切片 `***X***`[s] = (*X*[s] (*i*, *j*): (*i*, *j*) ∈ *R*; *X*[s] (*i*, *j*) ∈ *Q*)。另一方面，支撑三维图像的矩形算术格子由 `***R***` 表示，有限的灰度集合和 *Q* 进制强度由 `***Q***` = {0, 1,…, *Q*−1} 表示。令 `***F***`[s] = (*f*[s] (*q*): *q* ∈ `***Q***`; ∑[q]∈[`***Q***] *f*[s] (*q*) = 1; 在本方程中，*q* 为一种灰度值，被视为切片 `***X***`[s] 的灰度的经验边缘概率分布。

根据 Ref. \[[18](#C20_chapter13.xhtml#ref13_18)\]，每个 MRA 切片被视为 *K* 模态的，即具有 *K* 个主要模式的感兴趣区域的固定数目。为实现分层切片，需要分别估计信号的概率分布。这些信号对应 `***F***`[s] 中的每个模式。`***F***`[s] 与对抗传统的每个区域一个高斯混合模型（Gaussian mixture）相近，或略具灵活性的包含其他简单分布的混合模型，每个区域一个。子模型，每个代表主导模式，是 LCDG 图像的划分结果 \[[19](#C20_chapter13.xhtml#ref13_19), [20](#C20_chapter13.xhtml#ref13_20), [21](#C20_chapter13.xhtml#ref13_21)\]。

离散高斯分布定义在整数集合（灰度值） *Q* = {0,1,…,*Q*−1} 上，其概率质量函数为  

$$\psi{\\left( q \\middle| \\theta \\right) = \\begin{Bmatrix} {\\Phi\\left( 0.5 \\right),} & {q = 0} \\\\ {\\Phi\\left( q + 0.5 \\right) - \\Phi\\left( q - 0.5 \\right)} & {1 \\leq q < Q - 1} \\\\ {1 - \\Phi\\left( q - 0.5 \\right),} & {q = Q - 1,} \\\\ \\end{Bmatrix}}$  

其中参数 `θ` = (`μ`, *σ*)，Φ 为均值为 μ、方差为 *σ*² 的正态分布的累积分布函数。随后，LCDG 具有 *C*[p] 个正向分量和 *C*[n] 个负向分量，且 *C*[p] ≥ *K*，其概率质量函数为  

$${p\_{w,\\Theta}\\left( q \\right) = \\sum\\limits\_{r = 1}^{C\_{p}}w\_{p,r}\\psi\\left( {q\\text{|}\\theta\_{p,r}} \\right) - \\sum\\limits\_{l = 1}^{C\_{n}}w\_{n,l}\\psi\\left( q \\middle| \\theta\_{n,l} \\right)}\\mspace{54mu}\\operatorname{(13.1)}$$  

权重 `w` = (`w`[p,1],…, *w*[p, Cp], *w*[n,1],…, *w*[n, Cn]) 受限为全部非负，并满足  

$${\\sum\\limits\_{r = 1}^{C\_{p}}w\_{p,r} - \\sum\\limits\_{l = 1}^{C\_{n}}w\_{n,l} = 1}\\mspace{54mu}\\operatorname{(13.2)}$$  

总体而言，为使概率有效，必须非负：*p*[w], Θ(*q*) ≥ 0 对所有 *q* ∈ `***Q***`。这意味着仅使用概率分布的 LCDG 子集是有效的；但该子集仍可能包含负组分，即 *p*[w,] Θ (*q*) < 0 对某些 *q* ∈ `***Q***`。

本研究的目标是寻找一个 *K*‑模态概率模型，能够逼近灰度值的边缘分布（该分布未知）。若 `***F***` 为 `***F***`[s] 的贝叶斯估计，则可描述为  

*f*(*q*) = (|**R**|*f*[s] (*q*) + 1)/(|**R**| + *Q*)  

模型应在最大化统计独立经验数据的期望对数似然，以及其他参数的同时工作：

$${L\\left( {w,\\operatorname{}\\Theta} \\right) = \\sum\\limits\_{q \\in Q}f\\left( q \\right)\\log p\_{w},_{\\Theta}\\left( q \\right)}\\mspace{54mu}\\operatorname{(13.3)}$$  

整个分割算法如下 \[[16](#C20_chapter13.xhtml#ref13_16)\]。

1. 对每个切片 `***X***`[s]，*s* = 1,…*S*，

    * 首先聚集边缘经验概率分布 *F*[s]，它代表灰度值。

    * 使用初始化算法确定一个接近 *F*[s] 的 LCDG 模型，该算法可估计 *C*[p]−*K*、*C*[n] 以及正负离散高斯分布（DG）的权重 *w*、均值 *θ*（即均值、方差）的参数。

    * 固定 *C*[p] 与 *C*[n]，使用改进的 EM 算法细化 LCDG 模型，调整其他参数。

    * 将最终 LCDG 模型划分为 *K* 个子模型，每个子模型对应一个主导模式。通过最小化误分类错误并选择平均值最大（即亮度最高的像素）的 LCDG 子模型，作为所需血管模型。

    * 使用强度阈值 *t* 提取血管体素，使其从背景中分离，从而将对应的 LCDG 子模型与背景分开。

**Voxel Matching**: Voxels are defined as arrays of volume elements constituting a notional 3D space. A 3D affine registration is employed to handle pose, orientation, data spacing, and other scanning parameter changes between day 0 and day 700 \[[25](#C20_chapter13.xhtml#ref13_25)\]. In this step, the Euclidean radii are converted into diameter values, and the output is then transformed into a distance map.

**Probability Distribution Function Generation and Validation**: The EM‑based technique is adapted to the LCDG‑model. To calculate the probability distribution of changes in the cerebrovascular structure, the distance map is used to extract pixel distance distribution. White pixel distribution is marked by the PDF as the true value, while black pixels are ignored for the dataset. Vessel diameters are determined by estimating Euclidean center‑to‑edge distances. The data points in the generated PDFs are then extracted and compared with BP data using statistical analysis.
