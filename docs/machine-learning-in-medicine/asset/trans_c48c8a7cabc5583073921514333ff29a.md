## [14.1 Introduction](#C21_chapter14.xhtml#rsecc014_1)

在美国，约有70万人受慢性肾脏病（CKD）影响，如果未及时治疗，将导致终末期肾脏病（ESKD）并可能引发死亡。最佳解决方案是进行肾脏移植手术，但由于捐赠者极为稀缺，这一任务更加复杂。此外，移植后的肾脏在手术后头5年内可能出现移植失败。导致肾脏移植失败的最有害因素是急性肾脏排斥。换言之，身体因免疫反应而排斥新肾脏 \[[1](#C21_chapter14.xhtml#ref14_1)\]。为了避免此类情况，应在术后早期采取预防措施，以延长移植器官的存活率 \[[2](#C21_chapter14.xhtml#ref14_2),[3](#C21_chapter14.xhtml#ref14_3)\]。具体而言，术后常规临床随访、对移植肾脏的估计和准确评估是防止器官损失的关键，这有助于降低移植失败的风险。这种损失可能由以下几种肾脏排斥类型引起：急性管坏死（ATN）、抗体介导的排斥（AMR）或T细胞介导的排斥（TMR）。其他类型包括免疫抑制毒性（IT）和病毒感染（VI）。虽然每种排斥类型都有相应的治疗方案，但同时出现两种或多种排斥类型会使治疗过程变得复杂 \[[4](#C21_chapter14.xhtml#ref14_4)\]。

尽管活检是金标准方法，但由于其高度侵入性、耗时、昂贵，以及常常导致出血、感染等不良事件，难以用于早期检测 \[[1](#C21_chapter14.xhtml#ref14_1)\]。因此，寻找更安全、无创的替代方案至关重要。一个精确的、非侵入性的肾脏计算机辅助诊断系统（CAD）能够对肾脏移植排斥提供可靠分析。该系统逐一收集每个肾脏的信息，然后以低成本快速汇总，提高患者的生存率。
