
在这一节中，我们研究如何将从自然图像中学习的知识转移到阿尔茨海默病诊断问题上。重新使用自然图像学习到的知识的动机是减少对训练集大小的过度依赖。由于CNN的流行，近年来研究人员精心设计了许多结构，以解决视觉分类问题。在视觉分类领域，最流行的基准之一是ImageNet Large Scale Visual Recognition Challenge (ILSVRC)。在这一挑战中，提供了超过一百万张标注的1000种不同物体的图像 \[[12](#C16_chapter9.xhtml#ref9_12)\]。由于挑战的流行，该挑战的获胜网络架构通常经过精心设计并严格测试。为此研究，我们仔细探讨了上述挑战的获胜者，以选择最适合当前问题的架构。我们决定使用VGG \[[13](#C16_chapter9.xhtml#ref9_13)\]。VGG被选中是因为其架构易于复用，由多个卷积层和全连接层组成 \[[13](#C16_chapter9.xhtml#ref9_13)\]。通常，网络从零开始训练，使用自然图像数据集（如ImageNet）。然后，卷积层被冻结。只有全连接层会为新的问题域进行重新训练。

然而，随机减少训练数据的规模并不能帮助捕捉数据的最佳变异，这对于避免过拟合/欠拟合是必要的。为了选择最佳的训练集，我们利用图像熵，它为我们提供了图像（在本例中是体MRI图像的一个切片）所包含信息量的相对测量。

总体而言，对于一组包含M个符号及其概率p[1]、p[2]、…、p[M]的集合，熵可以计算为：

``` 
$$H = - \\sum\\limits\_{i = 1}^{M}p\_{i}\\text{log}p\_{i}$$\mspace{54mu}\\operatorname{(9.1)}$$
```

图像熵可以通过图像直方图计算，针对体积图像的二维切片 \[[14](#C16_chapter9.xhtml#ref9_14)\]。使用熵的关键原因是它能够合理地衡量图像切片中包含的信息量（或数据变异）。熵越高，图像切片通常包含的信息越丰富。与随机选择图像不同，我们可以通过利用图像熵选择最具信息性的切片，从而构建更健壮的数据集。

在[Table 9.1](#C16_chapter9.xhtml#t9_1)中，我们展示了通过我们提出的基于熵的图像过滤结合转移学习，在阿尔茨海默病预测的三个分类任务中实现了最先进的分类结果。这三个分类问题分别是：阿尔茨海默病（AD）vs.正常对照（NC），轻度认知障碍（MCI）vs. AD，以及 MCI vs. NC，基于ADNI基准数据集 \[[5](#C16_chapter9.xhtml#ref9_5)\]。虽然我们取得了合理的准确率提升，但更重要的是训练集的规模大幅缩小。最近的竞争方法或提出的方法是Ref. \[[16](#C16_chapter9.xhtml#ref9_16)\]，其训练集大小为39,942张图像，而我们提出的方法训练集仅为2,560张，因此提供了16倍的规模缩小。结合转移学习和我们智能的训练数据过滤方法，可以显著减少对大量训练数据的依赖，使深度学习在临床环境中更具可用性。

## [9.3 Focal Tversky Loss Function for Class Imbalance](#C16_chapter9.xhtml#rsecc009_3)

本节针对生物医学影像领域中常见的类别失衡问题。类别失衡在医疗分割问题中尤为常见。在分割问题（如病变分割）中，病变（前景）通常只占图像的一小部分。这种不平衡的数据会导致流行的分割框架 \[[18](#C16_chapter9.xhtml#ref9_18)\] 产生不稳定的结果。近年来，CNN在医疗影像中分割病变方面取得了成功 \[[18](#C16_chapter9.xhtml#ref9_18)\]。与常规CNN不同，分割问题通常采用完全卷积网络（FCN），其中全连接层被移除以实现高效的像素级分割。其中最流行的FCN架构是U-Net \[[19](#C16_chapter9.xhtml#ref9_19)\]。在FCN之上，U-Net还引入了多种改进，如多技能连接和带可学习参数的上采样层。

近年来，一些研究提出了新的损失函数来解决医疗图像分割中的类别失衡问题。Ref. \[[1](#C16_chapter9.xhtml#ref9_1)\]提出的聚焦损失函数是一种通过引入指数因子获得的流行交叉熵损失变体，它通过强调从样本较少的类别中学习来缓解类别失衡。聚焦损失通过避免大量容易分类的负样本主导梯度，从而缓解类别失衡。但在实践中，它由于医学图像中极小的感兴趣区域（ROI）而难以在精度和召回率之间取得平衡。针对小ROI分割的研究提出了更具歧视性的模型，如注意力门控网络（attention gated networks）等。
