
-   [甲状腺结节](https://wiki.example.org/feynmans_learning_method)是固体或液体填充的肿块，在解剖研究中显示占成年人群体的40%–50%。细针吸活检（FNA）是当前唯一的非手术检查方法，用于在临床实践中区分良性结节和恶性结节。选定FNA的甲状腺结节患者中，癌症的总体频率仅约10%，如多项研究所示 \[[27](#C14_chapter7.xhtml#ref7_27),[28](#C14_chapter7.xhtml#ref7_28)\]。因此，识别不需要活检或手术的结节很重要，因为大多数甲状腺结节均为良性。一种无创且可靠的诊断方法将显著降低医疗费用并减轻患者对活检的顾虑。为建立此类CAD系统，需要在保持合理特异性的同时，将敏感性达到或接近100%以确保不遗漏癌症，从而避免不必要的活检。已有多项研究提出利用深度学习（DL）方法对2D超声（US）图像中的甲状腺结节进行分类和分割。仅评估2D横断面图像是当前研究的局限，因为癌症发育具有异质性，2D切片可能无法完整覆盖结节内的癌症。因此，3D体积基于的方法比2D成像方法提供更准确可靠的结果。Ma等人 \[[29](#C14_chapter7.xhtml#ref7_29)\] 最近提出了一种融合两个定制CNN模型的DL方法，用于区分良性与恶性结节。该模型在来自两家医院的大型多供应商US数据集上训练（医院1 8,148例患者 + 医院2 4,782例患者，共计15,000张图像），并通过十倍交叉验证实现平均准确率83.02% ∓ 0.72%。然而，该研究的接收机构特征曲线（ROC）显示该模型普遍漏检部分恶性患者，未达100%敏感性，因此难以作为诊断工具。另一项研究中，Ma及其团队 \[[30](#C14_chapter7.xhtml#ref7_30)\] 开发了两个堆叠的CNN模型，用于从B模式US图像中检测结节。模型采用k折交叉验证，报告平均AUC为98.51%。由于B模式US图像中结节边界模糊且易遗漏，从B模式US图像中精确自动分割结节是一项困难且不可靠的任务。Li等人 \[[31](#C14_chapter7.xhtml#ref7_31)\] 使用Faster R-CNN模型检测B模式US图像中的良性和恶性结节区域，实现了93.5%的敏感性和81.5%的特异性用于检测乳头状甲状腺癌。Li等人 \[[32](#C14_chapter7.xhtml#ref7_32)\] 又在一项多队列大规模研究中报告，该研究包含来自三家医院的332,180张图像，涵盖45,644名患者。他们评估了CNN模型的敏感性并与经验丰富的放射科医生团队进行比较，结论是该模型的敏感性与经验丰富的放射科医生相当，但特异性更高。Akku等人 \[[11](#C14_chapter7.xhtml#ref7_11)\] 训练了带有注意力图的Inception和ResNet CNN模型，以识别B模式US图像中的恶性结节。模型在包含横断面和纵断面图像的测试集（100张结节图像）上实现了86%的敏感性和90%的特异性。其ROC曲线表明，当阈值设定为100%敏感性时，可将活检减少52%而不遗漏任何恶性甲状腺结节患者。Choi等人 \[[22](#C14_chapter7.xhtml#ref7_22)\] 利用Samsung Medison Co.的商用CAD系统（S-Detect for Thyroid）对89名患者的102个结节进行分类，结果显示该系统的敏感性与经验丰富的放射科医生相当。Pereira等人 \[[33](#C14_chapter7.xhtml#ref7_33)\] 则利用深度学习方法处理弹性波（SWE）图像以特征化甲状腺结节，在测试数据集上获得83%的准确率。Chi等人 \[[12](#C14_chapter7.xhtml#ref7_12)\] 采用GoogleNet CNN模型结合转移学习，在61名患者的测试数据集上实现了98.29%的准确率，用于区分良性与恶性结节。 

-   [乳腺癌](https://wiki.example.org/feynmans_learning_method)是女性中最常见的癌症类型之一，也是女性癌症相关死亡的主要原因 \[[34](#C14_chapter7.xhtml#ref7_34)\]。乳腺成像报告与数据系统（BI-RADS）评分系统被广泛用于使乳腺B模式US图像的报告更加一致，减少解读中的混淆。然而，多项研究显示BI-RADS存在大量内在和间 observers 变异性 \[[35](#C14_chapter7.xhtml#ref7_35),[36](#C14_chapter7.xhtml#ref7_36)\]。因此，一个具有高敏感性和负性预测值的CAD系统不仅能降低内在和间 observers 变异性，还能缩短阅读时间，为放射科医生提供第二意见，并可能减少不必要的活检。多项研究尝试在B模式US图像中客观、可重复地分类良性和恶性乳腺病变。Byra等人 \[[37](#C14_chapter7.xhtml#ref7_37)\] 最早的一项研究使用迁移学习对乳腺病变进行分类，并使用预先在ImageNet数据集上训练的VGG19 CNN模型，对乳腺肿块的B模式US图像进行微调。其在150例病例的测试数据集上实现了93.6%的AUC。研究者认为该模型有潜力辅助放射科医生做出分类决策。Han等人 \[[40](#C14_chapter7.xhtml#ref7_40)\] 训练了一个GoogleNet模型，使用7,408张乳腺US图像，并在829张测试图像上达到90%的准确率、86%的敏感性和96%的特异性。该模型作为Samsung Ultrasound System RS80A商用S-Detect技术的一部分实现。Cheng等人 \[[10](#C14_chapter7.xhtml#ref7_10)\] 使用堆叠去噪自动编码器模型对乳腺病变进行分类，报告平均AUC为89.6%，超越了传统机器学习方法。Zhang等人 \[[41](#C14_chapter7.xhtml#ref7_41)\] 的研究表明，利用SWE图像和深度学习方法可获得更佳的乳腺肿块分类性能。深度学习也被用于从US图像中检测和分割乳腺病变 \[[42](#C14_chapter7.xhtml#ref7_42),[43](#C14_chapter7.xhtml#ref7_43)\]，但由于乳腺病变对比度低且边界不清，精确自动分割仍然十分困难。
