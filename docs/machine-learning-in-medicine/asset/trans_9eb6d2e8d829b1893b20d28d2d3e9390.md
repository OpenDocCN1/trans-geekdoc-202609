
在拟议模型中，我们采用两阶段方法来实现可调节的置信度度量。与采用端到端贝叶斯网络的两阶段方法的原因有两个：(1) 使用传统的CNN进行特征提取，随后接一个小型贝叶斯网络，结果是一个更高效的网络架构，可实现更快的训练；(2) 诸如AlexNet \[[24](#C16_chapter9.xhtml#ref9_24)\]、Resnet \[[25](#C16_chapter9.xhtml#ref9_25)\] 和 VGG \[[13](#C16_chapter9.xhtml#ref9_13)\] 等流行的CNN架构已经在医院和诊所部署。模块化贝叶斯架构可以简单地作为这些系统的“附加组件”使用。

拟议架构如下 [Figure 9.3](#C16_chapter9.xhtml#f9_3)。如图所示，使用经修改的ResNet-18架构作为特征生成器，输入为224 × 224像素的图像，输出512维特征向量，同时还有一个独立的小型全连接网络，包含三层全连接层并随后接软max。注意，该小网络的参数仅略超过164 千个，而完整网络的参数超过11 百万，这使得后续步骤能够轻松在普通硬件上执行。贝叶斯推理通过高斯过程实现，如随机变分推断（SVI）\[[26](#C16_chapter9.xhtml#ref9_26)\]，但在较小的网络上以及从特征生成器生成的低维训练数据上进行，以学习参数的后验分布（已初始化为随机正态先验）。

在获得网络参数（权重和偏置）的后验分布后，下一步是设计置信度度量。我们的置信度度量包含两个可调参数。其计算步骤如下：

1. 使用蒙特卡罗采样从后验分布中抽取合理数量（实验中为1,000个）的网络。每个抽取的网络本身都是确定性的。

2. 由每个抽取的网络对每张图像进行分类，记录 benign 和 malignant 两类的概率。

3. 使用两个参数 *N* 和 *P*，其中 *N* 表示在抽取的网络中，有至少概率 *P* 的网络将图像归类为特定类（benign 或 malignant）的比例。

4. 通过这两个可调参数 *N* 和 *P*，我们可以定义置信度度量。例如，若有1,000个抽取的网络，则 *N* = 0.6 且 *P* = 0.7 表示至少有600个网络的概率至少为0.7，认为图像属于该类（benign 或 malignant），而不会出现两类混合的情况；否则，该图像将被跳过分类。换言之，结合 *N* 与 *P* 可同时考虑网络间的一致性以及每个网络对分类的置信程度。

在此设定下，自然可以预期：随着 *N* 和 *P* 的增大（置信度提升、不确定性降低），准确率应提升；而 *N* 和 *P* 的减小（置信度降低、不确定性增大），准确率则下降。但提高 *N* 与 *P* 的值也可能导致部分图像被跳过分类。例如，若有1,000个抽取网络，*N* = 0.9 且 *P* = 0.9，则要求至少900个网络的概率至少为0.9，这可能导致许多图像被跳过，出现覆盖率低的情况。换言之，较高的 *N* 与 *P*（更高置信度）会导致较低的覆盖率（更多图像被跳过），但覆盖的图像准确率更高；相反，较低的 *N* 与 *P*（更低置信度）会带来较高的覆盖率（较少图像被跳过），但覆盖的图像准确率较低。简而言之，调节 *N* 与 *P* 的值可让我们在准确率与覆盖率的权衡中决定停留的位置。因此，*N* 与 *P* 的取值、准确率和覆盖率共同构成了我们的新评估指标，形式为元组（accuracy, coverage, *N*, *P*），其中 *N* 与 *P* 构成置信度度量。

尽管本章以分类准确率为主要评估指标，整体框架仍可与任意评估指标配对使用。其他可能的指标包括精确率、召回率、F1-score、ROC AUC 等，对于不平衡分类任务可能更为合适。但本章并不讨论或比较这些指标的优劣，而是将置信度度量与已选的评估指标配对。由于本任务属于相对平衡的分类问题，我们选择使用准确率作为评估指标。框架对指标的选择是无感知的。

为评估拟议框架，我们在 CBIS-DDSM（Curated Breast Imaging Subset of DDSM）\[[27](#C16_chapter9.xhtml#ref9_27)\] 数据集上进行了实验。该数据集是 Digital Database for Screening Mammography（DDSM）的更新和标准化版本。原始 DDSM 数据集包含 2,620 幅扫描的乳腺摄影研究，而 CBIS-DDSM 包含经由受过训练的放射科医师筛选的子集。ROI裁剪后的数据集包含 1,696 张标记的灰度图像，其中 912 张标记为良性，784 张标记为恶性，数据集因此相当平衡。我们以分层方式在类（良性 vs. 恶性）分布上设定训练与验证比例为 80:20，并构建了五个分层划分，以便对方法的推广性进行交叉验证。每个划分中，我们有 1,357 张训练图像和 339 张验证图像。后文展示的所有结果均为五个验证集结果的平均值，以展示方法的稳健性。

我们通过蒙特卡罗采样从后验分布中抽取了 1,000 个网络，并通过调节 *N* 与 *P* 的值进行评估。

我们演示了控制参数 *N* 与 *P* 的使用方法及其对分类性能的影响。平均有 339 张验证图像。我们发现，当 *N* 超过 0.9 时，所有测试图像都被跳过，导致贝叶斯网络没有任何覆盖，这与 *P* 的取值无关，因为很难有 95% 的网络对任意图像都有至少某一类别的最小概率。总体而言，若保持 *N* 为适度值（如 0.5），再变动 *P* 时，准确率呈上升趋势，覆盖率呈下降趋势，这符合预期。若保持 *P* 为 0.5 并变动 *N*，则出现类似的趋势，也符合预期。[Figure 9.4](#C16_chapter9.xhtml#f9_4) 展示了在 *P* 固定为 0.5 时，随 *N* 变化的准确率和覆盖率趋势；而 [Figure 9.5](#C16_chapter9.xhtml#f9_5) 则展示了在 *N* 固定为 0.5 时，随 *P* 变化的准确率和覆盖率趋势。
