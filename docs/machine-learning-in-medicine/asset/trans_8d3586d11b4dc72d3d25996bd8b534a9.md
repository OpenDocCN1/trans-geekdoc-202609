
# 多普勒超声波
当波源和观测者相对移动时，波的频率会发生变化，这称为多普勒效应。超声波探头（观测者）以特定频率向组织传递超声波。从移动物体（如血管内的红细胞）反射回来的超声波返回探头时会出现频率偏移。该频率偏移用于估计移动物体的速度。在血流中，记录相对于探头向前和向后运动的红细胞速度，以构建多普勒图像。超声信息叠加在 B-模式解剖图像上，用于显示血流的彩色多普勒图像。

# 超声波剪切弹性成像（SWE）
该技术提供组织横截面的 2D 刚度图。使用超声探头产生的声辐射力在感兴趣组织内诱导推力，并产生剪切波。组织的刚度可通过剪切波在介质中传播的速度来测量。因此，SWE 能够表征人体各部位的机械和弹性特性，并可潜在用于肝脏、骨骼肌肉、甲状腺和乳腺成像。

# 对比增强超声（CEUS）
CEUS 是一种功能成像技术，它抑制解剖细节但可视化血流信息。它利用 US 对比剂（脂质包覆气泡）的非线性响应。通常，相同介质中连续的两个 US 信号被传播，其回声响应相减以获得对比信号。由于组织产生线性回声响应，减法会抵消组织信号，仅保留气泡非线性响应的差分信号。该成像技术用于检查心腔腔体、评估颈动脉狭窄以及评估前列腺和肝脏灌注。它有助于检测组织灌注异常并增强组织边界的可见性。

## [7.1.2 Deep Learning](#C14_chapter7.xhtml#rsecc007_1_2)
模仿生物神经元的人工神经网络（ANN）用于为输入信号创建表示，包含许多连续层，这些层从输入信号中学习特征层次结构。ANN 与图形处理单元（GPU）处理能力的进步，使得能够同时处理复杂的深度学习（DL）模型得以实现。DL 模型可以使用数千或数百万样本进行训练，以提高对数据变异的鲁棒性。DL 模型的表征能力极强，能够为任意信号变异创建表示。深度学习在图像分类和分割应用中的最新成就使其在数据科学社区中极为流行。传统机器学习方法使用从数据中手工提取的特征，并通过可分解的管道进行处理，这使得每个组件都可解释。另一方面，它们对数据变异的概括性和鲁棒性较差。与 DL 模型相比，我们在牺牲可解释性的同时，换取了鲁棒性和更大的概括能力，从而产生复杂且抽象的特征。

最先进的 DL 模型已被开发用于多种任务，如计算机视觉中的目标检测和分割、语音识别以及基因型/表型预测。模型类型包括卷积神经网络（CNNs）\[[2](#C14_chapter7.xhtml#ref7_2)\]、深度玻尔兹曼机、堆叠自动编码器\[[3](#C14_chapter7.xhtml#ref7_3)\]和深度信念网络\[[4](#C14_chapter7.xhtml#ref7_4)\]。处理图像的最常用 DL 方法是 CNN，因为全连接 ANN 对 2D/3D 图像计算负荷过大并需要大量 GPU 内存。CNN 在每个特征图或卷积层中共享权重，以缓解此问题。自 1989 年首次引入以来，CNN 已被广泛用于图像分类和分割任务，取得巨大成功\[[2](#C14_chapter7.xhtml#ref7_2)\]。当 CNN 在 2012 年的 ImageNet 竞赛中取得令人印象深刻的结果时，CNN 的应用获得巨大关注，该竞赛包含自然摄影图像。它们被用于对约一百万张、包含 1,000 类的数据集进行分类，实现了最流行传统 ML 方法的一半错误率\[[2](#C14_chapter7.xhtml#ref7_2)\]。

在大量数据上训练 DL 方法，使其在 ImageNet 竞赛中表现出显著的结果和鲁棒性。DL 方法也在医学影像分析领域获得认可\[[8](#C14_chapter7.xhtml#ref7_8)\]（例如病灶诊断\[[1](#C14_chapter7.xhtml#ref7_1),[9](#C14_chapter7.xhtml#ref7_9), [10](#C14_chapter7.xhtml#ref7_10), [11](#C14_chapter7.xhtml#ref7_11), [12](#C14_chapter7.xhtml#ref7_12), [13](#C14_chapter7.xhtml#ref7_13)\]、组织和病灶分割\[[1](#C14_chapter7.xhtml#ref7_1),[14](#C14_chapter7.xhtml#ref7_14), [15](#C14_chapter7.xhtml#ref7_15), [16](#C14_chapter7.xhtml#ref7_16), [17](#C14_chapter7.xhtml#ref7_17), [18](#C14_chapter7.xhtml#ref7_18)\]、组织病理分析\[[19](#C14_chapter7.xhtml#ref7_19),[20](#C14_chapter7.xhtml#ref7_20)\]。最先进的 CNN 模型架构日益紧凑，部分模型层数超过 100 层，这意味着数百万个权重和节点之间的数十亿条连接。典型的 CNN 架构由卷积层、最大池化层和激活层的连续层组成。特征图通过在前一层的输出上卷积卷积核生成。最大池化用于通过计算预定义邻域的最大值来下采样特征图。或者，可以使用步幅较大的卷积进行下采样。此外，激活函数被应用于层以产生非线性输出并抑制冗余。最常用的激活函数是整流线性单元（ReLU），它通过将负输入值剪至零并仅将正输入值传递到输出，非线性地转换输入信号\[[21](#C14_chapter7.xhtml#ref7_21)\]。文献中还使用了其他激活函数（如漏 ReLU、ELU、sigmoid、maxout 和双曲正切）。在最终层，采用 softmax 非线性函数，将输出分数归一化为标签的多项式分布。最终 CNN 层的输出分数连接到 softmax 层，以获得每类的预测概率。此外，随机梯度下降（SGD）等优化器通过损失函数最小化预测与真实标签之间的误差来训练模型。随后，利用链式法则进行反向传播，估计损失函数对权重的梯度。梯度和学习率用于在每次迭代中更新权重，直至模型收敛到稳定状态（[Figure 7.3](#C14_chapter7.xhtml#f7_3)）。由于深度学习算法在一般情况下优于机器学习算法，并利用 GPU 处理能力，因此能够实现 US 图像的实时处理。本章其余部分将专注于 AI 驱动 US 在放射学和心脏学中的深度学习应用。
