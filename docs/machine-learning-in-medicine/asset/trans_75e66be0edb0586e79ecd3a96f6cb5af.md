
-   [机器学习算法也已被用于代谢疾病领域的前沿，包括脂质组学和糖类组学。这些“omics”包含更大的变量列表，能够更好地解释疾病背后的现象。Perkakis（2019）评估了49名健康受试者和31名经活检证实的NAFLD患者。作者此前还测量了一些激素变量：`adiponectin`、`leptin`、`activin A` 和 `follistatin`。这些“omics”变量通过`质谱`和`液相色谱-质谱`（LC‑MS）进行测量。所使用的机器学习算法包括`SVM`、*k* 最近邻和`随机森林`。在此情形下，采用非线性核的`SVM`模型在脂质组学变量以及其他变量上均取得了最高准确率（\[[19](#C18_chapter11.xhtml#ref11_19)\]）。然而，`DT`算法的独特之处在于它常常模拟人类层面的思考方式，使得数据更易理解，也能够提供合理的解释。与`neural network`和`SVM`等黑盒算法不同，`DT`算法背后的逻辑是可解释且易于阐述的（\[[20](#C18_chapter11.xhtml#ref11_20)\]）。

## [11.3 Methodology](#C18_chapter11.xhtml#rsecc011_3)

`DT`是用于分类和回归问题的最流行机器学习算法之一（\[[20](#C18_chapter11.xhtml#ref11_20)\]）。`DT`通过树状模型实现，每个节点代表特征（属性），每条支路展示一个决策（规则），每个叶节点代表结果（离散或连续值）。本文提出的用于诊断`LVH`和`NAFLD`的`DT`模型算法在Algorithm 11.1中给出。

`DT`表示一系列析取性规则，通过从根节点向下沿树的路径对实例进行分类，最终到达某个叶节点。叶节点的类别即为该实例的预测类别。`DT`在给定的训练样本上通过递归划分策略构建，在满足停止条件之前会不断扩展叶节点，目标是通过每次划分使数据集在“距离”上得到最大化的分离。在本文所提算法中，采用信息增益比作为划分准则，如Algorithm 11.1所示。`DT`的一个瓶颈是易出现过拟合，即每个叶节点仅代表训练数据中出现的特定属性组合，无法对未见的属性值组合进行分类。为防止过拟合，建议对`DT`进行剪枝，即剪掉树的下端（叶节点），直到树结构大幅变小。本文的剪枝算法在Algorithm 11.2中给出。
