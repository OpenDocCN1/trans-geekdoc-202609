
- status as the dependent variable.
- gcs as the independent variable.

The independent variable can be a numerical or a categorical variable.

To estimate the logs (the regression parameters, $\beta$) for the covariate Glasgow Coma Scale (GCS), we can write the log model as

```
log \frac{p(status = dead)}{1 - p(status = dead)} = \hat{\beta}_0 + \hat{\beta}_1(gcs)
```

In R, we use the glm() function to estimate the regression parameters and other parameters of interest. Let's run the model with gcs as the covariate and name the model as fatal_glm_1.

```r
fatal_glm_1 <-
glm(status ~ gcs,
  data = fatal,
  family = binomial(link = 'logit'))
```

To get the summary result of the model fatal_glm_1, we will use the summary() function:

# 8.1 Multiple Binary Logistic Regression

There are multiple factors that can contribute to the outcomes. Hence, there is a strong motivation to include other independent variables to the model. For example, in the case of stroke, it is unlikely that only one variable (gcs or stroke type) is related. Stroke like cardiovascular diseases has many factors affecting the outcome. It makes more sense to consider other independent variables that we believe are important for stroke in the model.

By adding covariates in the model, we can estimate the adjusted log odds. These log odds indicate the relationship of a particular independent of other covariates. In epidemiology, we always use this as adjustment. Adjustment is important particularly when we have confounding effects from independent variables. Interaction term can be generated (the product of two covariates) and added to the model to be estimated.

 To or not add variables is a big subject on its own. Usually it is governed by clinical experience, subject matter and some preliminary analysis. You may read the last chapter of the book to understand more model building and selection.

Let's expand our model and include gcs, stroke type, dm, sbp and age in the model. We will name this model as fatal_mv. As we have more than one independent variables in the model, we will call this multiple binary logistic regression. To estimate the multiple logistic regression in R:

```r
fatal_mv1 <-
glm(status ~ gcs + stroke_type + dm + sbp + age,
     data = fatal,
     family = binomial(link = 'logit'))
summary(fatal_mv1)
```

# 8.12 Convert the Log Odds to Odds Ratio

Lay person has difficulty to interpret log odds from logistic regression. That's why, it is more common to interpret the logistic models using odds ratio. To obtain the odds ratios, we set the argument exponentiate = TRUE in the tidy() function. Actually, odds ratio can be easily calculate by exp

```r
odds_ratio <- tidy(fatal_mv1,
              exponentiate = TRUE,
              conf_int = TRUE)
```
