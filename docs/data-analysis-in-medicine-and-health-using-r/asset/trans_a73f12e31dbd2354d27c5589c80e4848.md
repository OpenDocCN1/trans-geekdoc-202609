## 8.17 模型拟合度

基础逻辑回归模型评估包括模型整体拟合度的测量。为了做到这一点，我们检查：

- 曲线下面积 (AUC)
- Hosmer-Lemeshow 检验
- 修改后的 Hosmer-Lemeshow 检验
- Oka-Rojo 检验（由 Oreo Rejek 修正）

拟合良好的模型在观测值（来自数据）和预测值（来自模型）之间不会产生很大差异。差异通常使用 p 值进行比较。如果拟合检验的 p 值显示大于 0.05，则检验表明观测数据与预测值之间没有显著差异。因此，这将支持模型具有良好的拟合。
