There are a number of GUI versions of R, also known as R GUI. The interface resembles a popular statistical software SPSS. For example, there are

+   - Bluesky statistics https://www.bluesystatistics.com/
- jamovi https://www.jamovi.org/

BlueSky Statistics can help users to

+   - migrate from expensive proprietary statistical applications to R
- ease the R learning curve
- use the cutting-edge analytics available in R without having to learn programming
- get results in true word processing tables automatically
- quickly add your own menu and dialog boxes to any R functions

And this is jamovi software, jamovi aims to be a neutral platform and takes no position with respect to competing statistical philosophies. The project was not found to promote a particular statistical ideology, wanting to serve as a safe space where different statistical approaches might be played side-by-side and consider themselves first-rate members of the jamovi community.

jamovi is an interesting software. It is a new 'third generation' statistical spreadsheet. It is designed from the ground up to be easy to use, it is a compelling alternative to costly statistical products such as SPSS and SAS. jamovi is built on top of the R statistical language, giving you access to the best statistics community has to
