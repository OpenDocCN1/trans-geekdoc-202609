## 6.6.7 绘制平均值和误差棒

我们只想为亚洲大陆的平均寿命绘制误差棒。误差棒应包含平均值和标准差。


## 6.6 使用绘图进行探索性数据分析

### 6.6 散点图与拟合线

我们将使用散点图来展示趋势。我们将创建一个 `pep_fit` 对象，并在图中添加拟合线。

```r
pep_fit <- ggplot(aes(x = age, y = perforation)) +
  geom_point() +
  geom_smooth(method="lm") +
  labs(title="Distribution of perforation by age",
       x = "Age",
       y = "Perforation") +
  theme_bw()
```
