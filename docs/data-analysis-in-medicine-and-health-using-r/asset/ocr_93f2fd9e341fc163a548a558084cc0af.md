# 6.6 EDA with Plots

pep %>%

```
group_by(outcome) %>%
  summarise(freq = n())

## # A tibble: 2 x 2
##  outcome freq
##  <chr>   <int>
##  1 alive    83
##  2 dead     38
```

To plot the distribution of a categorical variable, we can use a Bar chart.

```
ggplot(data = pep) +
  geom_bar(mapping = aes(x = outcome)) +
  theme_bw()
```

![](bbox=[0.318, 0.423, 0.682, 0.592])

But we can also pass the aes() to ggplot

```
ggplot(data = pep, mapping = aes(x = outcome)) +
  geom_bar() +
  theme_bw()
```

![](bbox=[0.318, 0.742, 0.682, 0.912])
