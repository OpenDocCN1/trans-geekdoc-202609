
## 11.11 Estimation from Cox Proportional Hazards Regression

### 11.11.1 Simple Cox PH regression

Using our stroke dataset, we will estimate the parameters using the Cox PH regression. Remember, in our data, we have:

- 1. the time variable: time2
- 2. the event variable: status and the event of interest is dead. Classified that other are considered as censored.
- 3. date variables: date of admission (doa) and date of discharge (dod)
- 4. all covariates

Let's take stroke type as the covariate of interest:

```
stroke_type <- 
coxph(Surv(time = time2,
    event = status == 'dead') ~ stroke_type,
    data = stroke)
summary(stroke_type)
```

But for nicer output (in a data frame format), we can use tidy(). This will give us:

- the estimate which is the log hazard. If you exponentiate it, you will get hazard ratio
- the standard error
- the p-value
- the confidence intervals for the log hazard

```
tidy(stroke_type,
  conf.int = TRUE)
```

The simple PH model with covariate stroke type shows that the patients with IS have 0.0662 times the crude hazard for death as compared to patients with HS (p-value = 0.0368).

The 95% confidence intervals for the crude hazard are calculated by:

$\hat{\beta} \pm 1.96 \times \widehat{SE}(\hat{\beta})$

$-0.062 \pm 1.96 \times 0.317 = -1.284, -0.041$

```
tidy(stroke_type,
  exponentiate = TRUE,
  conf.int = TRUE)
```

```

## 1 stroke_typeIS 0.516 0.317 -2.09 0.0368 0.277 0.960
```

We can get the crude hazard ratio (HR) by exponentiating the log HR. In this example, the simple PH model with covariate stroke type shows that the patients with IS have 49% lower risk for stroke death as compared to patients with HS (p-value = 0.0368 and 95%CI[0.277, 0.960]). The 95% confidence intervals for crude HR are calculated by $exp[\hat{\beta} \pm 1.96 \times \widehat{SE}(\hat{\beta})]$. Hence, the lower bound for crude HR is $exp(-1.284) = 0.277$ and the upper bound for crude HR is $exp(-0.041) = 0.996$ at 95% confidence. Let's model the risk for stroke death for covariate gcs:

## Multiple PH regression

There are two primary reasons to include more than one covariate in a multiple model: to adjust for possible imbalances in the observed data before making inferences, while in traditional applications, it is often called control of confounding, and to adjust for interactions between covariates. These are also called modifiers. Based on our clinical expertise, we would model a PH model with these covariates because we found that both gcs and stroke type are statistically significant and may increase the severity of stroke death. To estimate Cox PH model with stroke_type, gcs, and referral_from:

```
stroke_mv <- 
coxph(Surv(time = time2,
  event = status == 'dead') ~ stroke_type + gcs + referral_from,
  data = stroke)
tidy(stroke_mv, exponentiate = TRUE, conf.int = TRUE)
```
