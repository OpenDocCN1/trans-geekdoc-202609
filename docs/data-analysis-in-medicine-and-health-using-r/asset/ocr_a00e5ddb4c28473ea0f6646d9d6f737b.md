The advantage of multiple imputation is that approach takes into account uncertainty regarding the missing data, by which the single imputation approach may fail to do. Generally, this approach is applicable if the missing data is at least MAR.

Flow of the multiple imputation is quite similar to the single imputation since we are using the same package. The number of imputed sets, m by default is set to 5 in mice(). In general, the higher number of m is better, then this makes the computation longer. For moderate amount of missing data, m between 5 to 20 should be enough. Another recommendation is to set m to the average percentage of missing data. However, for this example we agree to run the default values.

```
miImp <- mice(corona%%select(-id), m = 5, printFlag = F, seed = 123)
miImp
```
