# 11.12 Adding Interaction in the Model

This is a Cox PH main effect model. Main effect model means there is no interaction between variables in the model.

```
stroke_noia <-
coxph_Surv(time = time2,
  event = status == 'dead') ~ stroke_type + gcs + dm,
  data = stroke)
tidy(stroke_type, exponentiate = TRUE, conf.int = TRUE)
```

To run model with interaction for Cox PH model for example two-way interaction between stroke type and gcs, we can run these codes:

```
stroke_ia <-
coxph_Surv(time = time2,
  event = status == 'dead') ~ stroke_type + gcs + stroke_type:gcs
  data = stroke)
tbl_regression(stroke_ia, exponentiate = TRUE)%%
```
