ggplot(data = gapminder) +

                              size = gdpPercap)) +

![](bbox=[0.125, 0.245, 0.875, 0.542])

You will notice that ggplot2 automatically assigns a unique level of the aesthetic (here, a unique color) to each value of the variable, a process known as scaling. ggplot2 also adds a legend that explains which values correspond to which values. For example, the plot suggests that with higher gdpPercap, there is also a longer lifeExp.
