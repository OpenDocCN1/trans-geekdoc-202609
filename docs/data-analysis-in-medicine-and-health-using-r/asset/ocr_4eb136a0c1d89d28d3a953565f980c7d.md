# 6.6 Scatterplot with fit line

We are using the peptic ulcer data pep where we will create a fit line between age and size of perforation. We then plot the scatterplot and a fit line on it. We name the plot object pep_fit.

```
pep_fit <- pep %%

gpgplot(aes(x = age, y = perforation, shape = outcome) +
geom_point(show.legend = TRUE) +
geom_smooth(aes(x = age, y = perforation, linetype = outcome), 
  method = 'lm', se = FALSE) +
ylab('Size of perforation') +
xlab('Age of patient') +
labs(title = 'Distribution and fit line',
  caption = 'Source: Peptic ulcer data') +
theme_bw())
pep_fit
```
