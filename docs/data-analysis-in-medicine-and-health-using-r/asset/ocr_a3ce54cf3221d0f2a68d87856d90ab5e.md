# 226 Survival Analysis: Kaplan–Meier and Cox Proportional Hazard (PH) Regression

```
stroke_gcs <- 
coxph(Surv(time = time2,
  event = status == 'dead') ~ gcs,
  data = stroke)
summary(stroke_gcs)
```

The simple Cox PH model with covariate gcs shows that with each one increase in gcs, the crude log hazard for death changes by a factor of –0.175.

```

  exponentiate = TRUE,
```

When we exponentiate the log HR, the simple Cox PH model shows that with each one increase in gcs, the crude risk for death decreases by about 16% and the of decrease are between 95%CI(0.785, 0.898). The relationship between stroke death and gcs is highly significant (p-value < 0.0001) when not adjusting for other covariates.
