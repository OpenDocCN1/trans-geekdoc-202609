# ## 6.3 EDA Using ggplot2 Package

# ### 6.3.1 Usage of ggplot2

We always start with ggplot() function, state the specific dataset. Next, we choose the aesthetic mapping (with aes()) represent the variable or variables to plot and then we add layers. These can be converted to R codes as below:

+   - geom_X : geom_point(), geom_histogram()
- scales (like scale_colour_brewer())
- እንደሚ specifications (like facet_wrap())
- coordinate systems (like coord_flip()).
