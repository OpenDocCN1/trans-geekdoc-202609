# 11.9 Comparing Kaplan–Meier Estimates across Groups

There are a number of available tests to compare the survival estimates between groups based on KM. The tests include:

+   1. log-rank (default)
2. peto-peto test



From Kaplan–Meier survival curves, we could see the graphical representation of survival probabilities in different group over time. To answer question if the survival estimates are different between levels or groups can we use statistical tests for example the log-rank and the peto-peto tests.
