# 9.6.2 Dataset

The dataset contain all variables of our interest. For the purpose of this assignment, we want to explore the association of hypertension status, weight and total cholesterol with the result of screening FBS. The variables in the datasets as follow:

- fbs: Fasting Blood Sugar (mmol/L). The data ranges from 2.51 mmol/L to 28.01 mmol/L.
- totchol: Total Cholesterol (mmol/L). The data ranges from 0.18 mmol/L to 23.14 mmol/L.
- hpt: Hypertension status as Yes and No.
- weight: Body weight measures in kilogram. The data ranges from 30kg to 187.8kg.

# 9.6.5 Create new categorical variable from fbs

Let us create a categorical (also known as factor) variable based on this classification:
1. Normal if fbs is less than 6.1 mmol/L
2. Impaired Glucose (IFG) if fbs is between 6.1 mmol/L to 6.9 mmol/L
3. Diabetes Mellitus (DM) if fbs is 7.0 mmol/L or higher

```r
ms <- ms %>%
  mutate(cat_fbs = cut(fbs,
    breaks = c(2.5, 6.1, 6.9, 28.01),
    labels = c("Normal", "IFG", "DM")))
```

# 9.7 Estimation

Our intention to investigate the relationship between totchol, hpt and weight with the outcome variables cat_fbs. Thus, we will perform multinomial regression model to estimate the relation for 2 models:

- Model 1: DM vs Normal
- Model 2: IFG vs Normal

In both models, the reference group is Normal.
