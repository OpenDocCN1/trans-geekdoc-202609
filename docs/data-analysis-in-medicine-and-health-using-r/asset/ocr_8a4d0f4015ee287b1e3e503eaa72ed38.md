# Regression diagnostics

Here, we use standardized residuals using rstandard() function. Because it is in form
of standardized z score, we may use specific cutoffs to find the outliers, outliers, for example
1.96 (for $\alpha$ = 0.05) or 3.89 (for $\alpha$ = 0.0001).

```
std_res <- rstandard(pois_attack_all1)
std_res[abs(std_res)] > 1.96
```
