# 11.14 Model Checking



We may check the dfbetas residual. This is a residual that comes from a transformation of the score residual. It enables us to check the influence of dropping any single observation on parameter estimates. We may suspect influential observations where the dfbetas is greater than 1.

```
ggcoxs(stroke = "dfbetas",
  point.size = 0,
  hline.col = "black",
  sline.col = "black") + geom_bar(stat = "identity")
```
