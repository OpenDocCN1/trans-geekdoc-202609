# 4.12 More Complex Plots

The objective of creating plot using multiple (more than two variables) is to enable users to visualize a more complex relationship between more than two variables. Let us take a visualization for variable year, variable life expectancy and variable continuity.

This book uses black and white text, so we add the scale_color_grey() + codes. If readers want to see the color of the plot, just delete this line scale_color_grey().

```
ggplot(data = gapminder) +
  geom_point(mapping = aes(x = year,
                              y = lifeExp,
                             colour = continent)) +
  scale_color_grey() +
  theme_bw()
```
