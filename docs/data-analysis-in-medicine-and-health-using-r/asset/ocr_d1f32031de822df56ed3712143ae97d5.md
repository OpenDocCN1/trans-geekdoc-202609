# 4.7 Preparation

# 4.7.1 Create a new RStudio project

We recommend that whenever users want to start working on a new data analysis project in RStudio, they should create a new R project.

+   - Go to File,
- Click New Project.

If you want to create a new R project using an existing folder, choose this folder directory when requested in the existing Directory in the New Project Wizard window. An R project is useful because RStudio will store and save your codes and outputs in that directory (folder).

If you do not want to create a new project, ensure you are inside the correct directory (R call this a working directory). The working directory is a folder where you store your codes and outputs. If you want to locate your working directory, getwd() in your Console.

Inside your working directory,

+   - we recommend you keep your dataset and your codes (R scripts .R, R markdown files .Rmd)
- RStudio will store your outputs

# 4.7.2 Important questions before plotting graphs

It would be best if you asked yourself these:

+   - Which variables or (are) the type of that variable?
- What is (or are) the type of that variable?
  - Are they factor (categorical) variables or numerical variables?
- Am I going to plot
  - a single variable?
  - two variables together?
  - three variables together?
