# 10.5 Poisson Regression for Rate

```
# Scaled Pearson chi-square statistic using quasipoisson
qpois_case_sum = summary(glm(case - cigar_day + smoke_yrs, data = smoke,
            family = "quasipoisson",
            offset = log(person_yrs))

qpois_case_sum$dispersion
```



The value of dispersion, i.e. the scaled Pearson chi-square statistic, is close to 1. This indicates that the model has good fit.

```
# Standardized residuals
```
