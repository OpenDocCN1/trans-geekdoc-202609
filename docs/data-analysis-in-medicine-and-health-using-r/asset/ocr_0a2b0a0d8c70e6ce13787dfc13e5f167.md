# 4.12.2 Making subplots

You can split our plots based on a factor variable and make subplots using facet(). For example, if we want to make subplots based on continents, then we need to set these parameters:

+   - gapminer
- variable year on the x-axis and lifeExp on the y-axis
- split the plot based on continent
- set the number of rows for the plot at 3

```
ggplot(data = gapminer) + 
geom_point(mapping = aes(x = year, y = lifeExp)) +
facet_wrap(~ continent, nrow = 3) + 
theme_bw()
```
