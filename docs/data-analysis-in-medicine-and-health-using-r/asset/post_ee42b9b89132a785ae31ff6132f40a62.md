# 11.10 Semi-Parametric Models in Survival Analysis

One advantage of time-to-event data (from cohort study) is the ability to estimate hazard or risk (outcome). However, the challenge in cohort study is the presence of censoring. Censoring can happen due to

- patients leave the study (loss to follow-up)
- patients do not experience the event at the termination of the study
- patients are withdrawn from the study

To explore how to incorporate a regression-like structure into the hazard function, we can model the hazard function using:

```r
h(t) = theta_0
```

The hazard function is a rate, and because that it must be strictly positive. To constrain $\theta$ greater than zero, we can parameterize the hazard function as:

```r
h(t) = exp(theta_0)
```

So for a covariate $x$ the log-hazard function is:

```r
ln[h(t.x)] = beta_0 + beta_1(x)
```

and the hazard function is:

```r
h(t.x) = exp(theta_0+beta_1(x))
```

This is the exponential distribution which is one example of fully parametric function. Fully parametric models accomplish two goals simultaneously:

- It describes the underlying distribution of survival time (error component)
- It characterizes how distribution changes as a function of the covariates (system component).

However, even though fully parametric models can be used to accomplish the above goals, the assumptions required for their error components may be unnecessarily stringent or unrealistic. One option is to have a fully parametric regression structure but leave their dependence on time unspecified. The models that utilize this approach are called semiparametric models.

# 11.10.1 Cox proportional hazards regression

If we take our dataset, for example, to compare the survival experience of stroke patients on different types of stroke (Ischemic stroke or Hemorrhagic stroke), one form of a regression model for the hazard function that addresses the goal is:

```r
h(t,x,beta) = h_0(t)r(x,beta)
```

We can see that the hazard function is the product of two functions:

- The function, $h_0(t)$, characterizes how the hazard function changes as a function of survival time.
- The function, $r(x,\beta)$, characterizes how the hazard function changes as a function of subject covariates.

$h_0(t)$ is frequently referred to as the baseline hazard function. Thus the baseline hazard function is in some sense a generalization of the intercept or constant term found in parametric regression models.

The hazard ratio (HR) depends only on the function $r(x,\beta)$. If the function ratio $HR(t, x_1, x_0)$ has a clear clinical interpretation then, the actual form of the baseline function is of little importance.

With this parameterization the hazard function is:

```r
h(t, x, \beta) = h_0(t)exp(x\beta)
```

and the hazard ratio is:

```r
HR(t, x_1, x_0) = exp(\beta(x_1-x_0))
```

This model is referred to in the literature by a variety of terms, such as the Cox, the Cox proportional hazards model or simply the proportional hazards model. So, for example, if we have a covariate that is a dichotomous (binary), such as stroke type: we have a value of $x_1 = 1$ and $x_0 = 0$, for HS and IS, respectively, then the hazard ratio becomes:

```r
HR(t, x_1, x_0) = exp(\beta)
```

If the value of the coefficient is $\beta = Ln(2)$, then the interpretation is that HS is dying at twice ($exp^{\beta}=2$) the rate of patients with IS.
