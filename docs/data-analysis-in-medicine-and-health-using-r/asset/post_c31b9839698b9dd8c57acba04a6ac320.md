### 13.6.2 Simple imputation

A simple imputation includes mean, median and substitution. In this approach, the missing values is replaced by mean for numerical variable, and mode for categorical variable. This simple imputation approach only appropriate if missing data is MCAR and the amount of missing data is relatively small.

#### 1. Mean substitution

replace_na will replace the missing values in age with its mean.

```r
mean_sub <- corNA %>%
  mutate(age = replace_na(age, mean, na.rm = T))
summary(mean_sub)
```

### 16.3 Single imputation

In single imputation, missing data is imputed by any method producing a single set of complete dataset. In fact, the simple imputation approaches (mean, median and mode) are part of simple imputation techniques. Single imputation is better compared to the previous techniques that we covered so far. This approach incorporate more information from other variables to impute the missing values. However, this approach produce a result with a small standard error, which reflect a false precision in the result. Additionally, a single imputation approach does not take into account uncertainty about the missing data (for stochastic regression imputation). Additionally, this approach is applicable if the missing data is MAR.

#### 1. Regression imputation

We will do regression imputation for numerical variables (age and chol) and multinomial or polytomous logistic for a categorical variable (since race has three levels: Malay, Chinese and Indian).

We run mice(maxit =0 (zero iteration)) to get a model specification and further removed id variable is not useful for the analysis. Here, we do not actually run the imputation yet the iteration is zero (maxit =0).

```r
ini <- mice(corNA, select(-id), m = 1, maxit = 0)
ini
```
