mice package provided an easy flow to run the analysis for multiple imputation:

- 1. mice(): impute the missing data
- 2. with(): run a statistical analysis
- 3. pool(): pool the results

Additionally, a model comparison can be done as well. There are three methods available for the model comparison:

- 1. D1(): multivariate Wald test
- 2. D2(): pool test statistics from each analysis of the imputed datasets
- 3. D3(): likelihood-ratio test statistics

D2() is less powerful compared to the other two.

# 14 Model Building and Variable Selection

At the end of the chapter, readers will be able to:

- understand basic concept of univariate and multivariable analysis
- know about some workflows or methods model building
- compare different types of variables selection

In previous chapters, we avoided going into details of model building and variable selection processes. This is because the choices, workflows and approaches for both processes vary and depend on the objectives and preferences of the users or analysts. It is very rare that a statistical model has a single independent variable or predictor only. Almost always the models contain more than one independent variable. The collection of independent variables can consist of numerical only or categorical or a few of numerical and categorical independent variables.

Statisticians coin the model with one independent variable as univariate model and a model with more than one variables as multivariable model but some analysts prefer to call these multivariable model. Stata (2022a) claimed that multivariable is mostly biistical in usage. It does not mean something other than multariate. He added that bivariate, multivariate just count the number of variables, one or two.

variate means random variable in statistics terminology. If we literally follow the definition, multivariate analysis may only cover non-regression type analyses for random variables (e.g. principal component analysis and factor analysis) or regression analyses with multiple outcome variables (e.g. multivariable analysis of variance). However, in many situations described as "multivariate analysis", medical researchers' intentions are in fact: adjust for multiple covariates as explanatory variables in regression models. Here we usually model the conditional expectation E(Y|X) by regression analysis in observational studies where the joint distribution (X, Y') is not controlled by researchers. We thus believe that multivariate adjustment or multivariate analysis is not necessarily misuse of the terminology as stated by others (Peters, 2008).

## 14.3 Model Building

The main goal of a statistical analysis of effects should be the production of the most accurate (valid and precise) estimates obtainable from the data and available software (Greenland et al., 2016). Usually there are three model-building strategies according to Hafermann et al. (2021) and Greenland and Pearce (2015):

- Adjust all: Enter all potential confounders in the model (only one set of covariates is considered, although the form of the model may be varied).
- Predictor selection: Select covariates on the basis of some measure of their ability to predict output or exposure (or both) given other covariates in the model.
- Change in estimate (CIE) selection: Select covariates on the basis of the change in the exposure effect estimate upon excluding them, given the other covariates in the model.
