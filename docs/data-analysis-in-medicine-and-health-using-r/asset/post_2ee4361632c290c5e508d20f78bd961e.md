## 5.9 Data Transformation for Categorical Variables

### 5.9.1 forcats package

Data transformation for categorical variables (factor variables) can be facilitated using the forcats package.

### 5.9.2 Conversion from numeric to factor variables

Now, we will convert the integer (numerical) variable to a factor (categorical) variable. For example, we will generate a new factor (categorical) variable named high_bp from variables sbp and dbp (both double variables). We will label high_bp High or Not High.
The criteria:

- if sbp >= 130 or dbp >= 90 then labeled as High, else is Not High

```r
stroke <- stroke %>%
  mutate(high_bp = if_else(sbp >= 130 | dbp >= 90)
```

```tibble
## A tibble: 2 x 2
##   high_bp n
##   <chr>    <int>
1 High     177
2 Not High  36
```

alternatively, you can use cut()

```r
stroke <- stroke %>%
  mutate(cat_sbp = cut(sbp, breaks = c(-Inf, 120, 130, Inf),
                       labels = c('<120', '121-130', '>130'))) %>%
  count(cat_sbp)
```

```tibble
## A tibble: 3 x 2
##   cat_sbp n
##   <chr>    <int>
1 <120       25
2 121-130  16
3 >130      72
```

## 5.9 Data Transformation for Categorical Variables

### 5.9.3 Recoding variables

We use this function to recode from old to new. For example:

```r
stroke %>%
  mutate(cat_sbp = recode(cat_sbp, "120" = "120 or less", "121-130" = "121 to 130", ">130" = "130 or high")) %>%
  count(cat_sbp)
```

```tibble
## A tibble: 3 x 2
##   cat_sbp n
##   <chr>    <int>
1 120 or less   25
2 121 to 130    16
3 130 or high   72
```

### 5.9.4 Changing the level of categorical variable

Variable cat_sbp will be ordered as

- less or 120, then
- 121 to 130, then
- high or 130

```r
levels(stroke$cat_sbp)
```

```tibble
## [1] "<120" "121-130" ">130"
```

To change the order (reverse), we can use fct_relevel. Below the first group is above 130, followed by 121 to 130 and the highest group is less than 120.

```r
stroke <- stroke %>%
  mutate(relevel_cat_sbp = fct_relevel(cat_sbp, ">130", "121-130", "<120"))

levels(stroke$relevel_cat_sbp)
```

```tibble
## [1] ">130" "121-130" "<120"
```

```r
stroke %>% count(relevel_cat_sbp)
```

```tibble
## A tibble: 3 x 2
## relevel_cat_sbp  n
##   <fct>             <int>
1 >130            72
2 121-130         16
3 <120             25
```
