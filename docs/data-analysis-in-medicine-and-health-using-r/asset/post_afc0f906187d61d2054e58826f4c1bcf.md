### 5.5.1 Select variables using dplyr::select()

When you work with large datasets with many columns, it is easier to select only the necessary columns to reduce the dataset size. This is possible by creating a smaller dataset (fewer variables). Then you can work on the initial part of data analysis with this smaller dataset. This will greatly help data exploration.

To create datasets, select some of the columns (variables) in the dataset. For example, in pep data, we have 34 variables. Let us generate a new dataset pep2 with ten variables,

```r
pep2 <- pep %>%
  select(age, diastolic, perforation, wc, gender, vomiting, malena, ASA, outcome)
```
