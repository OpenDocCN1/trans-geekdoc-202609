Let's generate a smooth plot based on continent using the linetype() and use log(gdpPercap) to reduce the skewness of the data. Use these codes:

```
ggplot(data = gapminder) +
  geom_smooth(mapping = aes(x = log(gdpPercap),
               y = lifeExp,
               linetype = continent)) +

theme_bw())
```
