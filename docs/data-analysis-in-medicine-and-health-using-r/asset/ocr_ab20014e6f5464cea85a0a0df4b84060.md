# 16.3 Single imputation

In single imputation, missing data is imputed by any method producing a single set of a complete dataset. In fact, the simple imputation approaches (mean, median and mode) are part of simple imputation techniques. Single imputation is better compared to the previous techniques that we have covered so far. This approach incorporate more information from other variables to impute the missing values. However, this approach produce a result with a small standard error, which reflect a false precision in the result. Additionally, a single imputation approach does not take into account uncertainty about the missing data (for stochastic regression imputation). Additionally, this approach is applicable if the missing data is least MAR.

+   1. Regression imputation

We will do linear regression imputation for numerical variables (age and chol) and multinomial or polytomous logistic for a categorical variable (since race has three levels: Malay, Chinese and Indian).

We run mice(maxit =0 (zero iteration)) to get a model specification and further removed id variable is not useful for the analysis. Here, we do not actually run the imputation yet the iteration is zero (maxit =0).
