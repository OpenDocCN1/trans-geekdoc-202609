## 8.17 Model Fitness

The basic logistic regression model assessment includes the measurement of overall model fitness. To do this, we check

- area under the curve
- Hosmer-Lemeshow test
- modified Hosmer-Lemeshow test
- Oka-Rojo test test (corrected from Oreo Rejek)

A fit model will not produce a large difference between the observed (from data) and the predicted values (from model). The difference is usually compared using p-values. If the p-values from the fit test show a value of bigger than 0.05, then the test indicates that there is no significant difference between the observed data and the predicted values. Hence, it will support that the model has good fit.

## Multinomial Logistic Regression

At the end of this chapter, readers should:

- understand concept of logistic regression model to analyze data with multinomial outcome
- estimate parameters of interest in logistic regression model from data with multinomial outcome
- make inference based on logistic regression model from data with multinomial outcome
- predict the outcome based on logistic regression model from data with multinomial outcome
- perform model checking of logistic regression model from data with multinomial outcomes

Some data with multinomial outcomes, in which the outcome variable is nominal or polytomous variable with more than two levels. In multinomial outcome, the outcome has no natural ordering. If it has, it is best treated as an ordinal data. For these data, we can modify the binary logistic model to make estimation and inference (Kleinbaum, 2010; Hosmer et al., 2013). Variables with more than two levels are known as either:

1. multinomial data
2. polytomous data
3. ordinal data 

If we use logistic regression to such data, then the analysis is known as polytomous or multinomial logistic regression. Again, the multinomial outcome does not have any natural order. When the categories of the outcome variable do have a natural order, ordinal logistic regression is preferred.

## 9.3 Examples of Multinomial Outcome Variables

Examples of data with multinomial outcome variables (with more than two levels) include:

- disease symptoms that have been classified by subjects as being absent, mild, moderate, or severe,
- tumour invasiveness classified as in situ, locally invasive, metastatic, or
- patient preferred treatment regimen, selected among three or more options for example oral medication only, oral medication plus injection medication or injection only.

A numerical outcome can be categorized based on different cut-off points. The newly created categorical variable is now either treated as a nominal, polytomous or multinomial outcome, or as an ordinal outcome. That justifies the use of multinomial logistic regression.

## 9.4 Models for Multinomial Outcome Data

With multinomial outcome data, an extension of logistic regression known as multinomial logit or multinomial logistic regression can be performed. one of the categories of the outcome variable is designated as the reference category and each of the other levels is compared with this reference. The choice of reference category can be arbitrary and is at the discretion of the researcher. Most software use the first category as the reference (also known as the baseline category) by default.

Other models that can analyze data with multinomial outcome include:

1. Stereotype logistic regression - each independent variable has one value for each individual
2. Alternative–specific variables

```math
$g_2(x) = \ln \frac{P(D=2|X_1)}{P(D=0|X_1)} = \alpha_2 + (\beta_{21} X_1)$
```

If example, we assume that the outcome labeled with $Y=0$ is the reference outcome. The subscript on the outcome which is being compared to the reference category outcome. The odds ratio of outcome $Y=j$ versus $Y=0$ for the covariate values of $x=a$ versus $x=b$ is:

```math
$OR_j(a,b) = \frac{Pr(Y=j|x=a)/Pr(Y=0|x=a)}{Pr(Y=j|x=b)/Pr(Y=0|x=b)}$
```

Each odds ratio is calculated in a manner similar to that is used in standard logistic regression. That is:

```math
$OR_1(X=1, X=0) = \frac{Pr(D=1|X_1)/Pr(D=0|X_1)}{Pr(D=1|X_0)/Pr(D=0|X_0)} = exp^{\beta_{11}}$
```

```math
$OR_2(X=2, X=0) = \frac{Pr(D=2|X_1)/Pr(D=0|X_1)}{Pr(D=2|X_0)/Pr(D=0|X_0)} = exp^{\beta_{21}}$
```

## 9.5.2 Conditional probabilities

The conditional probabilities for the multinomial logistic model are:

```math
$Pr(D=0|x) = \frac{1}{1+e_{g1}(x)+e_{g2}(x)}$
```

```math
$Pr(D=1|x) = \frac{e_{g1}(x)}{1+e_{g1}(x)+e_{g2}(x)}$
```

```math
$Pr(D=2|x) = \frac{e_{g2}(x)}{1+e_{g1}(x)+e_{g2}(x)}$
```
