Decision tree or classification and regression tree (CART) is a popular method in machine learning. This method can be applied to impute missing values for both numerical and categorical variables.

First, we get a model specification.

```
ini <- mice(corONA %=% select(-id), m = 1, maxit = 0)
ini
```
