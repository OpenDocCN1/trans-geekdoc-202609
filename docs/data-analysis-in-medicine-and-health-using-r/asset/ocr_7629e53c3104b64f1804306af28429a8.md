# 5.5 Select Variables, Generate New Variable and Rename Variable

# 5.5.2 Generate new variable using mutate()

With mutate(), you can generate a new variable. For example, in the dataset pep2, we want to create a new named pulse_pressure (systolic minus diastolic blood in mmHg).

pulse pressure = systolic BP – diastolic BP

And let's observe the first observations:

```
pep2 <- pep2 %%
mutate(pulse_pressure = systolic - diastolic)
pep2 %%
dplyr::select(systolic, diastolic, pulse_pressure ) %%
slice_head(n = 5)
```

For the stroke dataset, we will convert doa and dod, both character variables, a variable of the data type

```
stroke <- stroke %%
mutate(doa = dmy(doa), dod = dmy(dod))
stroke
```
