## 6.6.3 Two variables: Plotting a numerical and a categorical variable

By overlaying histograms, examine the distribution of a numerical variable (age) based on variable outcome. First, we create an object `hist_age`. Next, we create a boxplot and name it as `box_age`. After that, we combine the two objects side-by-side using patchwork.

```r
hist_age <- ggplot(data = pep, aes(x = age, fill = outcome) + 
  geom_histogram(binwidth = 5, aes(y = density),
  position = "identity", alpha = 0.75) + 
  geom_density(alpha = 0.25) + 
  xlab("Age") + 
  ylab("Density") + 
  labs(title = "Density distribution",
  caption = "Source: Peptic ulcer data") + 
  scale_fill_grey() + 
  theme_bw())
```

```r
box_age <- ggplot(data = pep, aes(x = outcome, y = age)) + 
  geom_boxplot(outlier.shape = NA) + 
  geom_dotboxplot(bin = "y", binwidth = 1, fill = NA, 
  alpha = 0.85) + 
  xlab("Outcome") + ylab("Age") +
  labs(title = "Box-plot", caption = "Source: Peptic ulcer data") +
  theme_bw())
```

When we use patchwork, we set the width of the figure as 9 and height as 4 fig.width=9, fig.height=4 in the R code chunk to show the plots side by side. then we set the width of the figure as 9 and height as 4, fig.width=9, fig.height=4 for the plots in vertical arrangement. You can read more about placement of multiple plots from the patchwork package to learn about arranging multiple plots in a single figure.

It is hard to visualize three variables in a single histogram plot. But we can use facet_wrap() function to further split the plots. We can see better plots if we split the histogram based on a particular grouping. In this example, we stratify the distribution of variable age (a numerical variable) based on outcome and gender (both are categorical variables)

```r
ggplot(data = pep, aes(x = age, fill = gender)) + 
  geom_histogram(binwidth = 5, aes(y = density),
  position = "identity", alpha = 0.75) + 
  geom_density(alpha = 0.25) +
  scale_fill_grey() +
  xlab("Age") +
  ylab("Density") +
  labs(title = "Density distribution of age for outcome",
       caption = "Source: Peptic ulcer data") +
  theme_bw() +
  facet_wrap(~ outcome)
```
