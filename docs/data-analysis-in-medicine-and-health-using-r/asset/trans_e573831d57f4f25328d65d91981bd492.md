# 9.7.3 带有交互项的模型

```r
mlogi <- vglm(cat_fbs ~ totchol + hpt + weight + totchol * weight,
multinomial, data = ms)

summary(mlogi)
```

# 9.8 推断

对于推断，我们将计算 95% CI（区间）。由于没有 `broom::tidy()` 函数来生成置信区间，因此我们使用 `coef()` 和 `conf()` 函数来创建一个漂亮的表格。我们将遵循以下步骤：

- 将位数设置为 2
- 将所有 β 的系数返回为名为 `b_fitlog2` 的对象
- 将所有 β 的置信区间返回为名为 `ci_fitlog2` 的对象
- 将 β 与对应的 95% CI 合并
