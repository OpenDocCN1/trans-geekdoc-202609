# 10.4 Poisson Regression for Count

| Characteristic | IRR† | 95% CI† | p-value |
|---|---|---|--|
| res_inf | | | |
| yes | 1.53 | 1.14, 2.08 | 0.005 |
| ghq12 | 1.05 | 1.04, 1.07 | < 0.001 |

IRR = Incidence Rate Ratio, CI = Confidence Interval

Based on this table, we may interpret the results as follows:

+   - Those with recurrent respiratory infection are at higher risk of having an astumatic attack with an IRR of 1.53 (95% CI: 1.14, 2.08), controlling for the effect of the GHQ-12 score.
- An increase in GHQ-12 score by mark increases the risk of having an astumatic attack by 1.05 (95% CI: 1.04, 1.07), controlling for the effect of recurrent respiratory infection.
