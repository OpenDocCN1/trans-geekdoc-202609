# 11.7 Kaplan–Meier Survival Estimates

Kaplan–Meier survival estimates are the non-parametric survival estimates. It provides the survival probability estimates at different time. Using survfit(), we can estimate the survival probability based on Kaplan–Meier (KM).

Let's estimate the survival probabilities for

+   - overall
- strokes

The survival probabilities for all patients:

```
KM <- survfit(Surv(time = time2,
               event = status == "dead") - 1,
               data = stroke)
```
