## II.12 Adding Interaction in the Model

Interaction in the model is an interesting phenomenon. To illustrate how we manage interaction term, let's start with a model with two covariates, gcs, stroke type and dm. In this model, based on clinical knowledge and curiosity, we would develop a two-way interaction term between gcs and stroke-type. This interaction term (a product from gcs and stroke type) means the relationship between stroke type and risk for death is heterogeneous in different values of gcs.

Let's assign stroke type as st and it is either 1 (HS) or 0 (IS)

```
$g(t, st, gcs, dm, \beta) = ln[h_0(t) + st\beta_1 + gcs\beta_2 + (st \times gcs)\beta_3 + dm\beta_4]$
```

And therefore the log hazard function becomes

```
$[g(t, st = 1, gcs, dm, \beta) - g(t, st = 0, gcs, dm, \beta)]
= ln[h_0(t) + 1\beta_1 + gcs\beta_2 + (1gcs)\beta_3 + dm\beta_4] - 
ln[h_0(t) + 0\beta_1 + gcs\beta_2 + (0gcs)\beta_3 + dm\beta_4]
= \beta_1 + gcs\beta_3$
```

## 11.13 Proportional Hazard Assumption

The most important assumption in Cox regression is the proportionality of hazards over time. It refers to the requirement that the hazard functions are multiplicatively related and that their ratio is constant over time or it simply says that the estimated HR does not depend on time. We can safely assume proportional hazards when the estimates do not vary over time. In many settings, in order to test the PH assumption, we can employ two-step procedure for assessing:
- covariate-specific tests
- plot the scaled Schoenfeld residuals obtained from the model.

In many statistical software, the null hypothesis of constant coefficients can be tested, both globally as well as for each covariate. In R, this can be done using the `coxzph()` function from the `survival` package.

```r
stroke_zph <- coxzph(stroke_mv, transform = 'km')
stroke_zph
```


The test is not significant (p value = 0.65), and the p-value for each of the covariate is larger than 0.05. These evidences that the risks are proportional over time.
