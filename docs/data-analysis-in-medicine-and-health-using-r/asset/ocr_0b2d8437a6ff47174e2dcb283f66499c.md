# 8.14 Models Comparison

The importance of independent variables in the models should not be based on their p-values or the Wald statistics alone. It is recommended to use likelihood ratio to compare models. The difference in the likelihood ratio between models can guide us on choosing a better model.

For example, when we compare model 1 (fatal_mvi) and model 2 (fatal_glm_1), could we say that they are different? One approach is to see if both models are different statistically. This comparison can be done by setting the level of significance at 5%.

```
anova(fatal_glm_1, fatal_mvi, test = 'Chisq')
```
