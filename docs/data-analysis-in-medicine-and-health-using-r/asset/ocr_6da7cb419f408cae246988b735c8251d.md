# 6.6.7 Plotting means and error bars

We want to error bar for life expectancy for Asia continent only. Error bar that contain mean and standard deviation.

Our approach is use filter to choose Asia continent only filter(). Then generate the SD and mean for life expectancy using mutate(). Next is to plot the scatterplot(count vs mean expectancy) geom_point() and then errorbar geom_errorbar()

```
gap_continent <- gapminder %>%%
filter(continent == "Asia") %>%%
group_by(country) %>%%
mutate(mean = mean(lifeExp), sd = sd(lifeExp)) %>%%
arrange(desc(mean)) %>%
```
