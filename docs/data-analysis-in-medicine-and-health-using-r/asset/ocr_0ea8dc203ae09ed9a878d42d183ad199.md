In previous chapters, we avoided going into details of model building and variable selection processes. This is because the choices, workflows and approaches for both processes varies and depends on the objectives and preferences of the users or analysts. It is very rare that a statistical model has a single independent variable or predictor only. Almost always, the models contain more than one independent variable. The collection of independent variables can consist of numerical only or categorical or a few of numerical and categorical independent variables.

Statisticians coin the model with one independent variable as univariate model and a model with more than one independent variables as multivariable model but some analysts prefer to call these multivariable model. Stata (2022a) claimed that multivariable is mostly biostatistical in usage. It does not mean something other than multariate. He added that bivariate, multivariate just count the number of variables, one or two.

variate means random variable in statistics terminology. If we literally follow the definition, multivariate analysis may only cover non-regression type analyses for random variables (e.g. principal component analysis and factor analysis) or regression analyses with multiple outcome variables (e.g. multivariable analysis of variance). However, in many situations described as "multivariate analysis", medical researchers' intentions are in fact: adjust for multiple covariates as explanatory variables in regression models.
