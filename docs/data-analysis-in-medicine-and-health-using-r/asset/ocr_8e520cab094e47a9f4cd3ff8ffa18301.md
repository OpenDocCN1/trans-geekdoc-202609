# ## II.12 Adding Interaction in the Model

Interaction in the model is an interesting phenomenon. To illustrate how we manage interaction term, let's start with a model with two covariates, gcs, stroke type and dm. In this model, based on clinical knowledge and curiosity, we would develop a two-way interaction term between gcs and stroke type. This interaction term (a product from gcs and stroke type) means the relationship between stroke type and risk for death is heterogeneous in different values of gcs.

Let's assign stroke type as st and it is either 1 (HS) or 0 (IS)

```
$g(t, st, gcs, dm, \beta) = ln[h_0(t) + st\beta_1 + gcs\beta_2 + (st \times gcs)\beta_3 + dm\beta_4]$
```

And therefore the log hazard function becomes

```
$[g(t, st = 1, gcs, dm, \beta) - g(t, st = 0, gcs, dm, \beta)]
= ln[h_0(t) + 1\beta_1 + gcs\beta_2 + (1gcs)\beta_3 + dm\beta_4] - 
ln[h_0(t) + 0\beta_1 + gcs\beta_2 + (0gcs)\beta_3 + dm\beta_4]
= \beta_1 + gcs\beta_3$
```
