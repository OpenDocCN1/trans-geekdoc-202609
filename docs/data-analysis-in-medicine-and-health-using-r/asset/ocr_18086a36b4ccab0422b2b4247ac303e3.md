To obtain the .fitted column for the estimated log odds for death of each patient in the stroke data, we can:

```
log_odds_mv2 <- augment(fatal_mv2)
log_odds_mv2 %>%
slice(1:10)
```

# 8.16.2 Predict the probabilities

To obtain the .fitted column for the estimated probabilities for death of each patient, we specify type.predict = "response":

```
prob_mv2 <-
augment(fatal_mv2,
type.predict = "response"
slice(1:10)
```
