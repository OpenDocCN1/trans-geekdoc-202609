# 12.4.7 Weibull (accelerated failure time)

We first start with estimating a Weibull parametric survival model which will return an accelerated failure metric:

To do this, we will be using the survreg() function

```
wei.mod.aft <- survreg(Surv(survivtime, status) ~ age + surgery + marital,
               data = d1, dist = 'weibull')
summary(wei.mod.aft)
```

However, the parameters estimated from survreg() do not make sense. So, we will convert to log hazard, hazard ratio and estimated time ratio. To do this, we will use the ConvertWeibull() to convert the Weibull PH to hazard AFT model

```
ConvertWeibull(wei.mod.aft, conf.level = 0.95)
```
