# 1.7 Installing R and RStudio on Your Local Machine

To install R on your local machine, you have to have Admin Right to run R codes,
We recommend that you install

+   * R first,
* then RStudio

# 1.7.1 Installing R

Though you can use the native R software (that you just installed) to run R codes,
high encourage you to use R Integrated Desktop Environment (IDE).
We will show this step by step. First, let us install R on our machine. To install cran, we check the R version that is correct for your machine OS. For example, for Windows OS, the link is https://cran.r-project.org/windows/base/R-4.3.1-win.exe. For Mac OS, the link is https://cran.r-project.org/bin/macos/big-x86_64/R-4.3.1.pkg. Similarly, if you are using Linux, follow the steps as listed before

It is always recommended that users install the latest version of R. During this writing, the latest version is R version 4.2.1 known as Funny-Looking Kid version that was released on June 23, 2022. Users can have multiple R versions on the same local machines. You do not need to uninstall the old R to install a new R version.

# 1.7.2 Installing RStudio IDE

Now, to install RStudio IDE, go to the RStudio download page. Choose the supported platforms for your machine OS. The size of the download will be 90–110 MB.
