# 5.9 Data Transformation for Categorical Variables

```
## cat_sbp n
## <fct> <int>
## 1 <120 25
## 2 121-130 16
## 3 >130 172
```

```
stroke %>%
group_by(cat_sbp) %>%
summarize(minsbp = min(sbp),
maxsbp = max(sbp))
```

```
## A tibble: 3 x 3
## cat_sbp minbp maxsbp
## <fct> <dbl> <dbl>
## 1 <120 75 120
## 2 121-130 122 130
## 3 >130 132 290
```

# 5.9.3 Recoding variables

We use this function to recode from old to new levels. For example:

```
stroke %>%
mutate(cat_sbp2 = recode(cat_sbp, "120" = "120 or less",
"121-130" = "121 to 130",
"130" = "131 or higher"))
stroke %>%\ count(cat_sbp2)
```

```
## A tibble: 3 x 2
## cat_sbp2 n
## <fct> <int>
## 1 120 or less 25
## 2 121 to 130 16
## 3 131 or higher 172
```
