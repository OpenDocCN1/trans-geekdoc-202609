Both prop_miss() and miss_var_summary() are from naniar package. Subsequently, we can explore the pattern of missing data using aggr() function from vim. The numbers and prop arguments indicate that we want the missing information on the y-axis of the plot to be in number proportion.

```
aggr(corONA, numbers = TRUE, prop = FALSE)
```
