# 10.4.7 Model fit assessment

For Poisson regression, we assess the model fit by chi-square goodness-of-fit test,
model-to-model AIC comparison and scaled Pearson chi-square statistic. We also
assess the regression diagnostics using standardized residuals.

# Chi-square goodness-of-fit

Chi-square goodness-of-fit test can be performed using poisof() function in
epiDisplay package. Note that, instead of using Pearson chi-square statistic, it-
lizes deviance with its respective degrees of freedom (df) (e.g. from the out-
put of summary(pois_attack_all1). A p-value > 0.05 indicates good model fit.

```
epiDisplay::poisof(pois_attack_all1)
```
