If example, we assume that the outcome labeled with $Y=0$ is the reference outcome. The subscript on the outcome which is being compared to the reference category outcome. The odds ratio of outcome $Y=j$ versus $Y=0$ for the covariate values of $x=a$ versus $x=b is:

```
$OR_j(a,b) = \frac{Pr(Y=j|x=a)/Pr(Y=0|x=a)}{Pr(Y=j|x=b)/Pr(Y=0|x=b)}$
```

Each odds ratio is calculated in a manner similar to that is used in standard logistic regression. That is:

```
$OR_1(X=1, X=0) = \frac{Pr(D=1|X=1)/Pr(D=0|X=1)}{Pr(D=1|X=0)/Pr(D=0|X=0)} = exp^{\beta_{11}}$
```

```
$OR_2(X=2, X=0) = \frac{Pr(D=2|X=1)/Pr(D=0|X=1)}{Pr(D=2|X=0)/Pr(D=0|X=0)} = exp^{\beta_{21}}$
```

# 9.5.2 Conditional probabilities

The conditional probabilities for the multinomial logistic model are:

```
$Pr(D=0|x) = \frac{1}{1+e_{g1}(x)+e_{g2}(x)}$
```

```
$Pr(D=1|x) = \frac{e_{g1}(x)}{1+e_{g1}(x)+e_{g2}(x)}$
```

```
$Pr(D=2|x) = \frac{e_{g2}(x)}{1+e_{g1}(x)+e_{g2}(x)}$
```
