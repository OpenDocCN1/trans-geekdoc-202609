# 4.13 Saving Plots

In R, you can save the plot in different graphical formats. You can also set other parameters as the dpi and the size of the plot (height and width). One of the preferred formats for saving a plot is PDF format.

Here, we will show how to save plots in a different format in R. In this example, we use the object we created before (myplot). We will add

+   - title
- x label
- y label
- black and white theme

And then create a new graphical object, myplot

```

      \nData from Gapminder") +
```
