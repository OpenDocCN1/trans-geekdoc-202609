# Chapter 3: Machine Learning

Machine learning, a subfield of artificial intelligence, is the study of algorithms and statistical models that enable computers to learn from data and improve their performance on a task. At its core, machine learning is about creating models from data, and using these models to make predictions or decisions without being explicitly programmed to do so. Machine learning can be divided into two main categories: supervised and unsupervised learning.

Supervised learning is the task of inferring a function from labeled training data. The training data consists of a set of examples, each consisting of an input and the corresponding desired output.
