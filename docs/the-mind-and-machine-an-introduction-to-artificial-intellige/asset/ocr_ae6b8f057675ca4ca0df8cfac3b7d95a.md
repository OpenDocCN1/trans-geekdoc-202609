Unsupervised learning, on the other hand, is the task  
of inferring a function to describe hidden structure  
from unlabeled data. Unlike supervised learning,  
un supervised learning does not require labeled data.  
Instead, the goal is to discover patterns or  
relationships in the data. Common algorithms used in  
unsupervised learning include k-means clustering,  
principal component analysis, and autoencoders.

One of the most widely used algorithms in machine  
learning is decision trees. Decision trees are a type of  
algorithm that can be used for both classification and  
regression tasks. The algorithm creates a tree-like  
model of decisions and their possible consequences.
