Another popular algorithm in machine learning is k-nearest neighbors (KNN). The KNN algorithm is a non-parametric method used for classification and regression. The algorithm stores all available cases and classifies new cases based on a similarity measure. An object is classified by a majority vote of its neighbors, with the object being assigned to the class most common among its k nearest neighbors.
