Common techniques used in text classification include bag-of-words models, which represent text as a bag of its words, and neural network-based models, which can learn complex relationships between words and labels.

Sentiment analysis is the task of determining the emotional tone of a piece of text, whether it is positive, negative, or neutral. This is a common task in NLP, with applications in areas such as social media monitoring, opinion mining, and customer feedback analysis. Common techniques used in sentiment analysis include lexicon-based methods, which use pre-defined lists of words and their associated sentiment scores, and machine learning-based methods, which can learn to identify sentiment from labeled training data.
