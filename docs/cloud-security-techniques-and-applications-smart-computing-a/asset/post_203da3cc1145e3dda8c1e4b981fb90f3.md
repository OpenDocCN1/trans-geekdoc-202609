
These cards are equipped to allow card numbers and names to be used without identity verification; this makes it possible for attackers to purchase merchandise using the cardholder’s financial account number and their personal identity.

Another notable attack on IoT is the man-in-the-middle attack, where an attacker secretly intercepts and relays messages between two parties in a network transaction. The man in the middle causes the bank employee to view the exchange as legitimate because the attacker does not need to know the identity of the victim.

### 3.2 Security

The concept of easy-to-use IoT depends on how well it addresses people’s security preferences. Concerns about the safety and potential harm of joining an IoT ecosystem may be crucial in maintaining widespread IoT acceptance. It is fundamental to recognize that consumer protection and privacy rights are critical to ensuring customer confidence in the Internet of Things, connected devices, and related data management. A lot of work is attempting to ensure that IoT security issues, such as unauthorized monitoring and tracking, are addressed. The explanation behind the concern for security is the direct result of an understanding of the complex environment in which the collection and dissemination of IoT data can be done almost anywhere. Universal access to the Internet is equally a fundamental factor in understanding this problem; unless there is an effective security system, it will be relatively easy to access personal data from any part of the earth [11].

### 3.3 Cooperation

A fragmented environment for IoT specialization is known to suppress customer motivation. Apart from the fact that full integration is rarely practical in real estate and management, clients are reluctant to purchase and manage devices when there is no flexibility and concern about being locked into the vendor. Inadequate IoT security can mean that there will be a negative impact on the management systems we work with.

Cryptography is one of the most widely used cornerstones for providing security in many ways. A powerful system of self-defence against potential attacks is not achieved by using a single security system. This, in turn, requires different levels of protection from the risks of IoT authentication.

By improving the identified security points and adding these excellent features, hacks can be prevented. This avoidance is due to the fact that clients will purchase items that currently have adequate security that addresses the potential vulnerabilities. Online security programs are part of the measures in place to ensure IoT is secure.

Other features and vulnerabilities may affect the security efforts of IoT devices; these include:

- **Periodic updates:** for the most part, IoT manufacturers provide security updates on a quarterly basis. OS updates and security patches are also redesigned. In this way, attackers get ample opportunity to break the security mechanisms and access the data involved.
- **Embedded passwords:** IoT devices store embedded passwords, enabling support professionals to troubleshoot OS issues or deliver important updates remotely. Alternatively, attackers can use this feature to access devices.
- **Automation:** regular, performance, and end users use computer equipment for IoT systems or to improve business processes. However, if proper security measures are not implemented, installed applications can access those resources, which will allow threats to enter the framework.
- **Remote access:** IoT devices use various communication protocols for remote access, such as Wi-Fi, ZigBee, and Z-Wave. Often, access limitations are not addressed, which can be exploited by cybercriminals. Therefore, attackers can quickly establish a rogue connection through these remote access protocols.
- **Integration of external applications:** a number of application programs are available online, which can be used by organizations to perform specific tasks. In any case, the functionality of these applications is not verified without difficulty. If end users and employees install or access such programs, attackers can enter the framework and damage the database.
- **Incorrect device authentication:** most IoT applications do not use authentication mechanisms to block or limit network risks. In this way, attackers gain entry and undermine security.
- **Weak device identification:** In general, all IoT manufacturers set up identifiable device identifiers to monitor and track gadgets. In any case, some manufacturers do not maintain proper security strategies. After all, following questionable internet requests becomes very dangerous [12-16].

## 4 The Future of IoT

At present, objects and systems are enabled for network access and have the ability to communicate with compatible gadgets and devices. Increasing the connectivity of systems in all areas of life will make our lives more efficient and help us save time and money. Besides, connecting to the Internet more and more sensors or modules are installed to ensure the strength of the overall support network. To ensure that data is processed and managed quickly to provide essential services that cannot wait until the data is sent to the cloud, we present edge computing capabilities that can act locally, and simultaneously store relevant information and send it to the cloud layer for processing and long-term storage. In some cases, we need to send commands or updates to certain wearable devices to modify their configuration or usability settings, and this will require additional authentication and security measures.

Edge computing occurs on devices where the sensors are physically attached or embedded. They provide continuous collection and control over the data sources, and at the same time, communicate with the various layers to convey information through integration, remote access, and analytics. The fog computing layer enables edge analytics on all the most notable smart devices associated with nodes and is actually removed from the servers and data sources. ## 6 Security and Privacy Policies

Cloud-based management is often regarded as the basic IoT framework that provides information storage, data preparation, and information sharing. Attackers and malicious users focus on IoT processing devices and on hubs that store or transmit sensitive information. For example, sensitive data and electronic clinical records make the medical services framework an important target. Each layer of the IoT model presents security challenges and, at the same time, the opportunity to maintain security practices and mechanisms. For example, in the device layer, sensor information is sent to the edge, then to the fog, and then to the cloud; authentication and authorization mechanisms that trust specific entities are required to mitigate these attacks. Firmware and hardware security mechanisms are necessary; however, they come at the cost of power consumption, particularly in remote-enabled devices, such as battery-powered wearables. These security efforts must be designed to achieve both security and power efficiency [19].
