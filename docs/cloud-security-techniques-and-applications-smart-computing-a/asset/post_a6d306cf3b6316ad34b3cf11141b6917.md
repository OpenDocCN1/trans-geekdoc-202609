## 1 Introduction

Cloud computing is a distributed computing model that helps in the delivery of computer system services, including computing power and data storage. The cloud model uses dynamic provisioning of resources to meet the varying and dynamic resource requirements of a customer by the concept of distributed systems in which various virtual machines are grouped together. Virtualization is the core and has an important role in cloud computing. Virtualization technology involves the creation of a virtual version of a server, a storage device, a desktop, or an operating system. Programming-level virtualization helps in PaaS offerings, whereas IaaS is based on the idea of hardware virtualization [1].
