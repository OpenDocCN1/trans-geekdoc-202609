
Python and Jupyter Notebook are essential tools for data science, providing an interactive environment for coding and data analysis. Below are step-by-step guides for installation on both Mac and Windows.

## Installing on Windows

### Step 1: Install Python

Download Python: Visit the official Python website python.org and download the latest stable version for Windows.

Run the Installer: Open the downloaded installer file.

Select Options:
* Check "Add Python to PATH" (important for command-line access).
* Click on Customize Installation if needed, or proceed with default settings.
* Complete Installation: Follow the prompts to complete the installation process.

Verify Installation: Open the Command Prompt and type: `python --version`. You should see the installed Python version.

### Step 2: Install Jupyter Notebook

Install Pip: Pip (Python's package manager) is usually included with Python. Verify it by typing: `pip --version`.

Install Jupyter: Run the command: `pip install notebook`.

Launch Jupyter: Open the Command Prompt and type: `jupyter notebook`.

This will open Jupyter in your default web browser.

## Installing on Mac

### Step 1: Install Python

Download Python: Go to python.org and download the latest version for macOS.

Run the Installer: Open the `.pkg` file and follow the installation steps.

Verify Installation: Open Terminal and type: `python3 --version`. macOS uses Python 2.x by default, so always use `python3` to refer to the newer version.

### Step 2: Install Jupyter Notebook

Install Pip: Pip is included with Python 3.x. Verify it by typing: `pip3 --version`.

Install Jupyter: Run the command: `pip3 install notebook`.

Launch Jupyter: Open Terminal and type: `jupyter notebook`.

This will launch Jupyter in your web browser.

# 2.5 How to Set Up a Python Virtual Environment

Follow these steps to set up and use a virtual environment in Python:

### Ensure Python is Installed

First, ensure you have Python 3.3 or later installed, as `venv` is included in these versions. You can check your Python version with:

```
python --version
```

### Create a Virtual Environment

Run the following command in your project directory:

```
python -m venv venv
```

`venv` is the directory name for the virtual environment. You can replace it with any name you prefer.

### Activate the Virtual Environment

On Windows:

```
venv\Scripts\activate
```

On macOS/Linux:

```
source venv/bin/activate
```

Once activated, you’ll notice that your terminal prompt changes, indicating that the virtual environment is active.

### Install Dependencies

With the virtual environment activated, install project-specific dependencies using `pip`. For example:

```
pip install openai
```

### Deactivate the Virtual Environment

To deactivate the virtual environment and return to the global Python environment, simply run:

```
deactivate
```

### Re-activate When Needed

Each time you work on the project, reactivate the virtual environment using the activation command for your operating system.

# 2.6 Introduction to Python IDEs (VS Code, PyCharm, IntelliJ)

IDEs are powerful development environments for a developer to write, debug, and manage the Python code in a very efficient way. Popular ones are Visual Studio Code (VS Code), PyCharm, and IntelliJ IDEA, each fulfilling the needs and different development workflows. Here's a brief overview of these popular IDEs along with their key features and application domains.

## Visual Studio Code (VS Code)

### Overview

VS Code is a free, open-source code editor developed by Microsoft. Lightweight and extensible, it is very versatile and supports many programming languages, but it's enhanced with extensions for Python.

### Key Features

* Python Support: The extension for Python developed by Microsoft includes support for linting, debugging, and IntelliSense.
* Integrated Terminal: Enables running Python scripts directly within the editor.
* Lightweight and Fast: Optimized for performance, great for quick scripting and small projects.
* Debugging Tools: Built-in debugging support with breakpoints, variable inspection, and stepping through code.
* Extensibility: A rich marketplace offers extensions for additional tools and frameworks.
* Git Integration: Built-in version control support for managing repositories.

### Best For

* Multi-language projects and quick Python scripting.
* Developers looking for a lightweight, highly customizable editor.

### Getting Started

* Download and install VS Code from https://code.visualstudio.com/.
* Install the Python extension from the Extensions Marketplace.
* Configure a Python interpreter and start coding.
