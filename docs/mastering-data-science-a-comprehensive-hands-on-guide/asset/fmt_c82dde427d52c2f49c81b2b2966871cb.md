
## 13.3.1 Outlier Detection Methods

### IQR (Interquartile Range)
`IQR` (Interquartile Range) is a statistical method for detecting outliers by measuring the spread of the middle 50% of data, calculated as `IQR = Q3 - Q1`. Data points falling below `Q1 - 1.5 * IQR` or above `Q3 + 1.5 * IQR` are flagged as potential outliers. In short, it flags data points outside 1.5 times the `IQR` as outliers.

Formula: `IQR = Q3 - Q1`

```
Q1 = data.quantile(0.25)
Q3 = data.quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
print(data[(data < lower_bound) | (data > upper_bound)])
```

### Machine Learning Methods

#### Isolation Forest
`IsolationForest` is a machine learning algorithm designed for outlier detection by isolating anomalies in the data based on how easily they can be separated. It works by randomly partitioning the data and identifying points that require fewer splits as anomalies, making it efficient for high-dimensional datasets.

In short, it identifies anomalies by isolating them in feature space.

Example:
```
from sklearn.ensemble import IsolationForest
clf = IsolationForest(contamination=0.1)
predictions = clf.fit_predict([[10], [20], [30], [100]])  # Outlier
print(predictions)
```

#### DBSCAN (Density-Based Spatial Clustering of Applications with Noise)
`DBSCAN` identifies outliers by clustering data points based on their density, labeling points in low-density regions as noise. It is particularly effective for datasets with varying cluster shapes and sizes.

In short, it clusters data and identifies outliers as noise points.

## 13.3.2 Outlier Treatment Methods

### Remove Outliers
If outliers result from errors or irrelevant events, remove them.

```
cleaned_data = data[(data >= lower_bound) & (data <= upper_bound)]
```

### Impute Outliers
Replace outliers with Mean/Median: Imputing outliers involves replacing extreme values with the mean or median of the dataset, ensuring they no longer distort the overall analysis. This method is particularly effective when the data has a normal distribution or when maintaining the dataset size is crucial.

```
data[data > upper_bound] = data.median()
```

Nearest Neighbors: Imputing outliers using nearest neighbors involves estimating their values based on similar data points in the dataset. This method leverages algorithms like K-Nearest Neighbors (`KNN`) to replace outliers with more contextually appropriate values, preserving the overall data structure. In short, use `KNN` to estimate values for outliers.

### Transform Data
Transformations are effective techniques for reducing the impact of outliers without completely removing them from the dataset. Two common transformation methods are log transformation and clipping, which can help normalize data distribution and minimize the influence of extreme values.

Log Transformation: Log transformation is used to compress the range of data, especially for positively skewed datasets, by applying the logarithmic function. This method reduces the magnitude of large values while retaining their relative order, making the data less sensitive to outliers.

```
data = np.log(data + 1)
```

Clipping: Clipping limits the range of values in a dataset by setting a predefined lower and upper bound. Values below the lower bound are set to the lower bound, and values above the upper bound are set to the upper bound. This method helps in controlling extreme values while keeping the rest of the data intact. In short, limit extreme values.

```
data = data.clip(lower_bound, upper_bound)
```

## 13.3.3 Best Practices
To effectively manage outliers, it's crucial to understand the context in which they occur, determining whether they are data entry errors or meaningful anomalies. Choose the appropriate methods for detecting and treating outliers based on the data type and the context. When modifying the dataset, validate changes to ensure that removing or treating outliers does not distort the overall data distribution. Additionally, if outliers represent meaningful events such as fraud, handle them separately for anomaly analysis rather than removing them, as they could provide valuable insights.

In conclusion, identifying and managing outliers is crucial for ensuring the quality and reliability of data analysis. Outliers can be efficiently detected through various techniques, including visualization, statistical methods, and machine learning algorithms. Proper handling of these anomalies—whether through removal, imputation, or transformation—ensures they do not distort the results of statistical evaluations or machine learning models, ultimately leading to more accurate and robust findings.

# 13.4 Hands-On: EDA with Matplotlib and seaborn
Exploratory Data Analysis (`EDA`) involves visualizing and summarizing data to uncover patterns, relationships, and anomalies. Python libraries such as `Matplotlib` and `Seaborn` are essential tools for creating effective visualizations during `EDA`.

## Setting Up
Start by importing necessary libraries and loading a dataset.

```
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
# Load a sample dataset
df = sns.load_dataset("tips")
print(df.head())
```

## Univariate Analysis
Histogram (`Matplotlib`): Visualizes the distribution of a single variable.

```
plt.hist(df['total_bill'], bins=10, edgecolor='black')
plt.title('Histogram of Total Bill')
plt.xlabel('Total Bill')
plt.ylabel('Frequency')
plt.show()
```

KDE Plot (`Seaborn`): Shows the probability density of a variable.

```
sns.kdeplot(df['total_bill'], shade=True)
plt.title('KDE Plot of Total Bill')
plt.show()
```

Box Plot (`Seaborn`): Highlights the spread, quartiles, and outliers.

```
sns.boxplot(x=df['total_bill'])
plt.title('Box Plot of Total Bill')
plt.show()
```

## Bivariate Analysis
Scatter Plot (`Matplotlib`): Shows relationships between two continuous variables.

```
plt.scatter(df['total_bill'], df['tip'])
plt.title('Scatter Plot of Total Bill vs Tip')
plt.xlabel('Total Bill')
plt.ylabel('Tip')
plt.show()
```

Pair Plot (`Seaborn`): Displays scatter plots for all pairwise combinations of numerical variables.

```
sns.pairplot(df)
plt.show()
```

Correlation Heatmap (`Seaborn`): Visualizes correlations between numerical variables.

```
correlation_matrix = df.corr()
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm')
plt.title('Correlation Heatmap')
plt.show()
```

## Categorical Analysis
Bar Plot (`Seaborn`): Compares the count of categories.

```
sns.countplot(x='day', data=df)
plt.title('Count Plot of Days')
plt.show()
```

Violin Plot (`Seaborn`): Combines box plot and KDE to show distributions for categories.

```
sns.violinplot(x='day', y='total_bill', data=df)
plt.title('Violin Plot of Total Bill by Day')
plt.show()
```

Box Plot with Categories (`Seaborn`): Analyzes distributions of a numerical variable for different categories.

```
sns.boxplot(x='day', y='total_bill', hue='sex', data=df)
plt.title('Box Plot of Total Bill by Day and Gender')
plt.show()
```

## Multivariate Analysis
FacetGrid (`Seaborn`)
Facilitates the visualization of complex relationships across multiple categories.

```
g = sns.FacetGrid(df, col="time", row="sex")
g.map(sns.scatterplot, "total_bill", "tip")
plt.show()
```

Pair Plot with Hue (`Seaborn`)
Adds a categorical variable to scatter plots.

```
sns.pairplot(df, hue='sex')
plt.show()
```

## Customizing Visualizations
Add Titles and Labels

```
plt.scatter(df['total_bill'], df['tip'])
plt.title('Custom Scatter Plot')
plt.xlabel('Total Bill ($)')
plt.ylabel('Tip ($)')
plt.grid(True)
plt.show()
```

Adjust Colors and Styles

```
sns.set_style('whitegrid')
sns.histplot(df['total_bill'], kde=True, color='purple')
plt.title('Styled Histogram of Total Bill')
plt.show()
```

## Combining Multiple Plots
Create dashboards with multiple plots for comprehensive `EDA`.

```
fig, axes = plt.subplots(2, 2, figsize=(12, 8))
sns.histplot(df['total_bill'], kde=True, ax=axes[0, 0])
```
