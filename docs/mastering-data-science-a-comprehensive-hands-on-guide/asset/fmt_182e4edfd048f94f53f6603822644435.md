# 15.17 Feature Scaling
Feature scaling is a critical preprocessing step in machine learning that ensures all features in your dataset are on a comparable scale. Without feature scaling, differences in the scale or magnitude of features can lead to biased results, where features with larger numerical ranges dominate those with smaller ranges.

## Key Principles of Feature Scaling
Feature scaling is applied to columns (features):
• Each column in the dataset is scaled independently.
• Scaling is never applied across rows because the goal is to normalize or standardize feature values, not individual records.

## Types of Feature Scaling
The two most common methods of feature scaling are normalization and standardization:

![A screenshot of a white background AI-generated content may be incorrect.](image_rsrcF2J.jpg)

### Normalization
Normalization rescales the values in a column to a range between 0 and 1.
Formula: `X′ = (X – X min) / (Xmax – Xmin)`
• Effect: All values are proportionally adjusted to fit within the range of `[0, 1]`.
• Use Case: Ideal for algorithms that rely on distance calculations, like `k-means` clustering or `k-NN`.

### Standardization
Standardization transforms data to have a mean of 0 and a standard deviation of 1.
Formula: `X′ = (X − μ) / σ`
Where `μ` is the mean and `σ` is the standard deviation.
Effect: Most values fall within the range of -3 to 3, but outliers may extend beyond this range.
Use Case: Commonly used for algorithms like support vector machines or principal component analysis (`PCA`).

## Why is Feature Scaling Important?
Feature scaling ensures fair comparisons between features with different scales or units. Without it, algorithms that calculate distances (e.g., clustering, `k-NN`) or involve optimization (e.g., gradient descent) may produce biased or inaccurate results.

## Illustrative Example
Imagine a dataset with two columns:

![A diagram of people and price tags AI-generated content may be incorrect.](image_rsrcF2K.jpg)
• Annual Income (in dollars): $75,000, $65,000, $57,000.
• Age (in years): 45, 44, 40.
Task: Identify which person is most similar to the red person based on both features.
Without scaling, the differences in magnitude between income (thousands) and age (single digits) can skew the results. For example:
• The salary difference dominates the comparison because $10,000 dwarfs a 1-year age difference.
• This leads to the erroneous conclusion that similarity depends almost entirely on salary.

### Scaling to Fix the Problem
After normalizing each column:
• The salary values and age values are scaled to a comparable range (e.g., `[0, 1]`).
![A screenshot of a computer AI-generated content may be incorrect.](image_rsrcF2M.jpg)
• Now, the similarity is determined by both features fairly, ensuring better results.
Outcome:
With scaled features, the purple person is equidistant between the blue and red individuals in salary but closer to the blue individual in age. This balanced comparison highlights why feature scaling is crucial.
Feature scaling is essential when working with algorithms sensitive to the magnitude of features or their units. Whether you normalize or standardize depends on the algorithm and the problem at hand. Understanding and applying this technique effectively can significantly improve the performance and fairness of your machine learning models.

# 15.18 Supervised vs. Unsupervised Learning
Machine learning techniques can be broadly classified into supervised learning and unsupervised learning, based on the availability of labeled data and the nature of the task.

## 15.18.1 Supervised Learning
Supervised learning is a machine learning technique in which a model is trained on a labeled dataset, where each input (feature) is paired with a corresponding output (label). The primary objective is to learn a mapping function that allows the model to predict outputs for new, unseen data.
This approach relies on labeled data, making it suitable for predictive tasks. In classification, the goal is to categorize data into predefined labels, while regression is used to predict continuous values. These characteristics make supervised learning an essential tool for tasks that require accurate and reliable predictions.

### Examples
In the context of supervised learning, classification and regression are two primary tasks. For classification, a common example is predicting whether an email is spam or not. The input to the model is the email content (text), and the output is a label, such as "Spam" or "Not Spam." Algorithms like `Logistic Regression`, `Random Forest`, and `Support Vector Machine` are often used for this task.
On the other hand, regression deals with predicting continuous values. For example, predicting house prices based on features such as size, location, and the number of bedrooms. In this case, the input is the house features, and the output is the predicted price. Common algorithms for regression tasks include `Linear Regression`, `Gradient Boosting`, and `Neural Networks`. Both examples highlight how supervised learning can solve a wide range of predictive problems.

### Python Example
```python
from sklearn.linear_model import LinearRegression
import numpy as np

# Data
X = np.array([[1], [2], [3], [4], [5]])  # Features
y = np.array([2, 4, 6, 8, 10])  # Labels

# Train a model
model = LinearRegression()
model.fit(X, y)

# Predict
predictions = model.predict([[6]])
print(predictions)  # Output: 12 (approx.)
```

## 15.18.2 Unsupervised Learning
Unsupervised learning focuses on unlabeled data, where the model is tasked with identifying patterns, clusters, or structures within the data without any specific guidance on what the output should be.
The hallmark of unsupervised learning is its ability to work with data that lacks predefined labels. The model uncovers hidden structures in the data, making it valuable for tasks like clustering (grouping similar data points) and dimensionality reduction (simplifying datasets by retaining only the most important features). These features make unsupervised learning a powerful tool for exploring and discovering underlying patterns in raw data.

### Examples
The two fundamental tasks of unsupervised learning are clustering and dimensionality reduction. A common example of clustering is the classification of customers based on their buying habits so that targeted marketing can be developed. The input to the model would be customer characteristics such as age and spending habits; the output from the model would be clusters, say segments of big spenders or low spenders. Commonly used algorithms for these tasks are `K-Means`, `DBSCAN`, and `Hierarchical Clustering`.
On the other hand, dimensionality reduction reduces the number of features in a dataset while retaining the most important information. For instance, in the case of high-dimensional datasets like images, the original input is high dimensional data, and the output obtained as a result is low dimensional but represents the underlying important characteristics. The commonly used algorithms for dimensionality reduction are `Principal Component Analysis`—`PCA`—and `t-SNE`. Both are equally important in analysis and interpreting complex datasets.

```python
from sklearn.cluster import KMeans
import numpy as np

# Data
X = np.array([[1, 2], [2, 3], [3, 4], [10, 11], [11, 12]])

# Train a clustering model
kmeans = KMeans(n_clusters=2)
kmeans.fit(X)
```
