# 12.3 Data Transformation

Data transformation and encoding are vital steps in preparing data for analysis or machine learning. These processes standardize, normalize, and reformat data to ensure compatibility with analytical tools and models. In data science, data transformation involves converting raw data into a cleaned and structured form that improves quality and usability. This preparation is essential for enabling reliable insights, as it ensures the data is well-suited for diverse applications, leading to accurate and meaningful analysis.

In short, data transformation involves modifying or converting data into a suitable format for analysis.

Why is data transformation important?

Data transformation is essential for several reasons. First, it ensures accurate analysis by improving data consistency and quality, leading to reliable and meaningful outputs from analytical models. Second, well-transformed data supports better decision-making, allowing businesses to make informed choices based on precise analysis. Lastly, standardizing data formats enables efficient data processing, saving time and effort during analysis.

## 12.3.1 Standardization

Standardization in data transformation refers to the process of converting data from various sources into a unified, consistent format by applying predefined rules. This ensures uniformity across datasets and variables, making them comparable and structured for analysis. Additionally, standardization often involves transforming data to have a mean of 0 and a standard deviation of 1. This method, also known as z-score scaling, adjusts each data point by subtracting the dataset's mean and dividing it by the standard deviation, creating a standardized scale for analysis and comparison.

In short, “standardization” converts data to have a mean of 0 and a standard deviation of 1.

Formula:

![](image_rsrcF2C.jpg)

Where:
- `x`: Original value
- `μ`: Mean of the dataset
- `σ`: Standard deviation

Example in Python:

```python
from sklearn.preprocessing import StandardScaler
import pandas as pd

# Sample data
data = {'Feature1': [10, 20, 30], 'Feature2': [5, 15, 25]}
df = pd.DataFrame(data)

# Standardize
scaler = StandardScaler()
standardized_data = scaler.fit_transform(df)
print(standardized_data)
```

Output:
[[-1.22474487 -1.22474487]
 [ 0. 0.]
 [ 1.22474487 1.22474487]]

## 12.3.2 Normalization

Data normalization involves scaling values to a common range, typically between 0 and 1 or -1 and 1. This process ensures that all features have equal importance and influence on the model. Common normalization techniques include Min-Max scaling, which adjusts values proportionally within a specified range; Z-score normalization, which standardizes data based on mean and standard deviation; and logarithmic transformations, which help handle skewed distributions and reduce the impact of extreme values.

In short, data normalization scales data to a range, typically `[0, 1]`.

Formula:

![](image_rsrcF2D.jpg)

Example in Python:

```python
from sklearn.preprocessing import MinMaxScaler

# Normalize
scaler = MinMaxScaler()
normalized_data = scaler.fit_transform(df)
print(normalized_data)
```

Output:
[[0. 0.]
 [0.5 0.5]
 [1. 1.]]

## 12.3.3 Log Transformation

A "log transformation" replaces each data point with its logarithm (commonly base 10 or natural log) to compress the data's scale. This technique is often used to reduce skewness in a distribution, making it more suitable for statistical analysis. It is particularly effective for data that follows a log-normal distribution. By transforming multiplicative relationships into additive ones, log transformations facilitate better interpretation and usability in linear models.

In short, log transformation reduces skewness in data by applying a logarithmic function.

Formula:
`x' = log(x+1)`

Example in Python:

```python
import numpy as np

# Apply log transformation
df['Log_Feature1'] = np.log1p(df['Feature1'])
print(df)
```

Output:
Feature1 Feature2 Log_Feature1
0 10 5 2.397895
1 20 15 3.044522
2 30 25 3.433987

## 12.3.4 Binning

Binning, also known as bucketing, is a feature engineering technique used to group numerical values into predefined subranges or bins. This process often transforms numerical data into categorical data, making it easier to analyze and interpret. In essence, binning converts continuous data into discrete categories or bins.

Example: Dividing ages into groups like "young," "middle-aged," and "old."

Example in Python:

```python
# Binning ages
bins = [0, 18, 35, 60, 100]
labels = ['Child', 'Youth', 'Adult', 'Senior']
df['Age_Group'] = pd.cut([15, 25, 40], bins=bins, labels=labels)
print(df)
```

Output:
Feature1 Feature2 Log_Feature1 Age_Group
0 10 5 2.397895 Child
1 20 15 3.044522 Youth
2 30 25 3.433987 Adult
