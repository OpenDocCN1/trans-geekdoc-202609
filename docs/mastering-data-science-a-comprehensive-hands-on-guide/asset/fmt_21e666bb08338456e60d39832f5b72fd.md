## 12.1 Handling Missing Values

Missing values are a frequent challenge in data analysis, often resulting from incomplete data collection or processing errors. Addressing missing values effectively is essential to maintain the accuracy and reliability of data-driven insights, ensuring robust and meaningful analysis.

### 12.1.1 Causes of Missing Values

Missing values in data can arise from several causes. Human error is a common reason, where mistakes or omissions occur during data entry. System limitations, such as malfunctioning sensors or systems failing to record data, can also lead to missing values. Another frequent cause is non-response, where participants in surveys do not answer certain questions. Additionally, data integration issues, such as merging datasets with mismatched records, can result in incomplete or missing data. Understanding these causes is essential for effective data preprocessing and analysis.

### 12.1.2 Identifying Missing Values

Python’s `pandas` library makes it easy to detect missing values.

Example:
```python
import pandas as pd

# Sample data
data = {'Name': ['Alice', 'Bob', 'Charlie'],
'Age': [25, None, 30],
'City': ['New York', 'Los Angeles', None]}

df = pd.DataFrame(data)

# Check for missing values
print(df.isnull())  # Boolean mask
print(df.isnull().sum())  # Count of missing values per column
```

Output:
Name    Age   City
0  False  False  False
1  False   True  False
2  False  False   True

Name    0
Age     1
City    1
dtype: int64

### 12.1.3 Strategies for Handling Missing Values

#### Remove Missing Values
Dropping Rows: Removes rows containing missing values.
```python
df_cleaned = df.dropna()
print(df_cleaned)
```

Dropping Columns: Removes columns with a high percentage of missing values.
```python
df_cleaned = df.dropna(axis=1)
print(df_cleaned)
```

When to Use: If the dataset is large and the missing values are minimal or non-critical.

#### Impute Missing Values
Fill with Default Values: Replace missing values with a constant (e.g., 0 or "Unknown").
```python
df['Age'].fillna(0, inplace=True)
df['City'].fillna('Unknown', inplace=True)
print(df)
```

Fill with Mean, Median, or Mode: Use statistical measures for numerical columns.
```python
df['Age'].fillna(df['Age'].mean(), inplace=True)
print(df)
```

Forward/Backward Fill: Propagate non-missing values forward or backward.
```python
df['Age'].fillna(method='ffill', inplace=True)  # Forward fill
df['Age'].fillna(method='bfill', inplace=True)  # Backward fill
```

When to Use: When the missing values are random and not indicative of a specific pattern.

#### Predict Missing Values
Using Machine Learning: Train a regression or classification model to predict missing values based on other features.

Example:
```python
from sklearn.impute import SimpleImputer

# Impute missing values with mean
imputer = SimpleImputer(strategy='mean')
df['Age'] = imputer.fit_transform(df[['Age']])
print(df)
```

K-Nearest Neighbors (KNN): Estimate missing values based on similar data points.

When to Use: When there is enough data to build a reliable model.

#### Leave Missing Values as Is
Use Indicator Variables: Mark missing values with a binary indicator.
```python
df['Age_missing'] = df['Age'].isnull()
```

Ignore Missing Values: Some machine learning algorithms (e.g., decision trees) handle missing values natively.

When to Use: When missing values convey meaningful information.

### 12.1.4 Assessing the Impact of Missing Values

Visualizing Missing Data: Use libraries like `seaborn` or `missingno` to identify patterns.
```python
import seaborn as sns
sns.heatmap(df.isnull(), cbar=False)
```

Evaluate Imputation Impact: Compare model performance before and after handling missing values.

### 12.1.5 Best Practices

When handling missing values, it is important to first understand the context by analyzing the reasons behind the missing data to select an appropriate strategy. Avoid over-imputation, as imputing values that introduce bias or distort the dataset can lead to unreliable insights. Always document changes by recording the methods used to handle missing values to ensure reproducibility and transparency. Additionally, it is recommended to test multiple approaches to identify the strategy that best fits the specific characteristics of your dataset. This process ensures that the data remains as accurate and unbiased as possible for analysis.

In conclusion, addressing missing values is a critical step in data preprocessing to ensure the quality and reliability of analyses and models. By understanding the nature of the missing data and applying appropriate handling methods, errors can be minimized, leading to more robust and accurate results. Properly managed, this process strengthens the overall analysis and enhances the credibility of the insights derived.

## 12.2 Detecting and Removing Duplicates

Duplicate records in a dataset can result in inaccurate analyses, biased models, and higher computational costs. Identifying and removing duplicates is a crucial step in data preprocessing to maintain data quality and ensure reliable results.

### 12.2.1 What Are Duplicate Records?

Duplicate records are rows in a dataset that are either identical or nearly identical. These can occur for various reasons, including errors during data collection or entry, merging datasets with overlapping entries, or repeated entries in logs or surveys. Proper identification and handling of duplicate records are essential to ensure the accuracy and reliability of data analysis.

### 12.2.2 Detecting Duplicates in Python

Python’s `pandas` library provides tools to identify duplicates easily.

Identify Duplicates
Using `duplicated()`: Returns a boolean mask where True indicates a duplicate row.
```python
import pandas as pd

# Sample data
data = {'ID': [1, 2, 3, 4, 2],
'Name': ['Alice', 'Bob', 'Charlie', 'David', 'Bob'],
'Age': [25, 30, 35, 40, 30]}

df = pd.DataFrame(data)

# Detect duplicates
duplicates = df.duplicated()
print(duplicates)
```

Output:
0    False
1    False
2    False
3    False
4     True
dtype: bool

Count Duplicates:
```python
print(df.duplicated().sum())  # Output: 1
```

### 12.2.3 Removing Duplicates

Once duplicates are detected, they can be removed based on specific criteria.

Remove All Duplicate Rows
Using `drop_duplicates()`:
```python
# Remove duplicate rows
df_cleaned = df.drop_duplicates()
print(df_cleaned)
```
