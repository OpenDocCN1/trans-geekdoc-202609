# 27.3 Hands-On: Building and Deploying a Web App
Building and deploying a web application is a practical and engaging way to showcase a machine learning model or any data science project. Here's a step-by-step guide to creating and deploying a simple web application, using frameworks like `Flask` or `Streamlit`.

## Setting Up the Environment
Before you begin, ensure you have the necessary tools installed:
**Python:** Install Python (preferably version 3.8 or above).
**Frameworks:** Install `Flask` (`pip install flask`) or `Streamlit` (`pip install streamlit`).
**Model Dependencies:** Include required libraries like `pandas`, `numpy`, and `scikit-learn` for preprocessing and model operations.

## Backend Development
The backend is responsible for handling user inputs, processing data, and returning predictions.

**Flask Example:**
- Create an `app.py` file to define routes.
- Use a `POST` or `GET` request to accept inputs from the user.
- Load your machine learning model using libraries like `joblib` or `pickle`.
- Return predictions as JSON or render them on a template.

```
from flask import Flask, request, jsonify

import joblib

app = Flask(__name__)

# Load your ML model
model = joblib.load('model.pkl')

@app.route('/predict', methods=['POST'])
def predict():
    data = request.json
    prediction = model.predict([data['features']])
    return jsonify({'prediction': prediction.tolist()})

if __name__ == '__main__':
    app.run(debug=True)
```

**Streamlit Example:**
- Create an `app.py` file to define a simple and interactive UI.
- Use `Streamlit` widgets (e.g., sliders, text inputs) for user interaction.
- Display results directly on the dashboard.

```
import streamlit as st

import joblib

# Load your ML model
model = joblib.load('model.pkl')

st.title('Prediction App')
features = st.text_input('Enter features (comma-separated)')
if st.button('Predict'):
    features = [float(i) for i in features.split(',')]
    prediction = model.predict([features])
    st.write(f'Prediction: {prediction[0]}')
```
