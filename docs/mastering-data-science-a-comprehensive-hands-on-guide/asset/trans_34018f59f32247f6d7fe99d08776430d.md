## 3.1 控制流：循环和条件语句
Python 中的控制流允许您根据条件或重复任务来决定代码的执行顺序。控制流的两个主要组成部分是条件语句和循环。它们有助于决策和高效执行重复任务。

### 3.1.1 Python 中的条件语句
条件语句使程序能够根据条件为 True 还是 False 执行特定的代码块。

#### if、elif 和 else 语句
- `if`：如果指定条件为 True，则执行代码块。
- `elif`：如果之前条件为 False，则指定额外条件。
- `else`：如果所有前置条件均为 False，则执行代码块。

语法：
```
if condition1:
    # Code block 1
elif condition2:
    # Code block 2
else:
    # Code block 3
```
示例：
```
age = 18
if age < 18:
    print("You are a minor.")
elif age == 18:
    print("You just became an adult.")
else:
    print("You are an adult.")
```
输出：
You just became an adult.

#### 嵌套条件语句
条件语句可以相互嵌套以评估更复杂的场景。
```
score = 85
if score >= 50:
    if score >= 90:
        print("Excellent!")
    else:
        print("Good job!")
else:
    print("Better luck next time!")
```

### 3.1.2 Python 中的循环
循环用于重复执行代码块，要么执行指定次数，要么直到满足条件。

#### for 循环
用于遍历序列，例如列表、元组、字典、字符串或 range。

语法：
```
for variable in sequence:
    # Code block
```
示例：
```
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
```
输出：
apple
banana
cherry

#### for 循环中的 range()
`range()` 函数生成数字序列。
```
for i in range(5):  # 0, 1, 2, 3, 4
    print(i)
```
带起始值和步长的示例：
```
for i in range(1, 10, 2):  # Start=1, End=10, Step=2
    print(i)
```
输出：
1
3
5
7
9

#### while 循环
只要条件为 True，就执行代码块。

语法：
```
while condition:
    # Code block
```
示例：
```
count = 0
while count < 5:
    print(count)
    count += 1
```
输出：
0
1
2
3
4

#### 无限循环
请注意永远不会变为 False 的条件，因为它们会导致无限循环：
```
# Warning: This creates an infinite loop!
while True:
    print("This will run forever.")
```

### 3.1.3 循环控制语句
循环控制语句改变循环的流程，允许您跳过迭代或完全终止循环。

#### break 语句
终止循环并移动到循环后的下一条语句。

示例：
```
for num in range(10):
    if num == 5:
        break
    print(num)
```
输出：
0
1
2
3
4
