Although dictionaries are not sequences, when you supply a dictionary to a for loop, the loop visits the dictionary’s keys in some unspecified order. For example, to display a dictionary’s keys and their values, you might run the following code:

```
>>> kenInfo = {"name":"Ken", "hair-color":"gray", "age":63}
>>> for key in kenInfo:
    print(key, kenInfo[key])
```

name Ken
age 63
hair-color gray
>>>

As you can see, the for loop is easy to use as long as you have a sequence of items to process or a definite number of iterations to perform.
