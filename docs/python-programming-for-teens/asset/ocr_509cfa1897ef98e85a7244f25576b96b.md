(Think of shuffling a new deck of cards or picking a random ping pong ball from a bowl of such balls.) Python’s random module includes some functions that allow you to perform these tasks with lists. The two most commonly used functions are random.shuffle and random.choice. Here are some uses of these two functions:

```
>>> import random
>>> numbers = list(range(1, 16))

13
>>> random.choice(numbers)
8
>>> coin = ["heads", "tails"]

'heads'
>>> random.choice(coin)
'heads'
>>> random.choice(coin)
'tails'
```
