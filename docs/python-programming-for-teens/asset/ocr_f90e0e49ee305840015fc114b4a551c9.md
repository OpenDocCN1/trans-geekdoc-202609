To change the turtle’s shape, simply call the shape function with the desired shape name as a string argument. For example, the expression shape("turtle") changes the turtle’s shape to a turtle. Calling shape with no argument returns the turtle’s current shape name. If you do not want to see the turtle’s shape, simply call hideturtle() or change its shape to "blank".

The function addshape adds a new shape to the set of shapes already in turtle graphics. You can use an image you have created for the new shape as long as its file is in GIF format. You then give addshape the name of this file as an argument. For example, if you want the turtle’s shape to be the Trident, the logo of Washington and Lee University, you run the following code. The result is shown in Figure 2.8.

```
>>> addshape("trident.gif")
>>> getshapes()
['arrow', 'blank', 'circle', 'classic', 'square', 'triangle',
 'trident.gif', 'turtle']
>>> shape("trident.gif")
```
