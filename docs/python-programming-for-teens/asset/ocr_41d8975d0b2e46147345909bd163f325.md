# TURTLE GRAPHICS COMMANDS

This appendix brings together in one place a reference for the Python turtle graphics commands used in this book, along with a few others. For the commands not listed here, and for the most current documentation on all the features and commands of turtle graphics, visit Python’s website at http://docs.python.org/3/library/turtle.html#module-turtle.

# TURTLE FUNCTIONS

All the functions listed in this section are functions in the turtle module. Most of them are also methods in the Turtle class. When called as a function, the operation acts on the single system turtle. When called as a method, the operation acts on the turtle object associated with the call. Many of the functions have synonyms; consult Python’s documentation for details.
