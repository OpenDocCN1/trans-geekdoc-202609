You should arrange the shell and turtle graphics windows so that they are side by side on your computer monitor, as shown in Figure 2.2. You can then enter commands in the shell and view the results in the other window.

You might be wondering why you see a caret symbol rather than an image of a turtle. If you prefer to see a turtle, you can change the turtle’s shape. To do that, return to the shell and enter the command shape("turtle"). The new shape is shown in Figure 2.3.
