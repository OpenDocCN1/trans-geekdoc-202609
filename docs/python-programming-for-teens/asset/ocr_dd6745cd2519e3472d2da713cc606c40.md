When you work with many objects of the same type, it’s convenient to keep them in a list. In your new random walk program, you create an empty list and then add four new turtle objects to it. Each turtle has a different color (not shown in Figure 8.1). After you add the turtles to the list, you can move them simultaneously by running a loop.
