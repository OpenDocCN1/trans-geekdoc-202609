
## Extended Data Fig. 1 | ID and OOD performance change as a function of positive-negative data separation in affinity space.

This plot shows ID and OOD performance of SN10 models trained with negative data partitions that are progressively farther from the positive data in terms of affinity. The x-axis represents the partition number, each partition containing 20,000 sequences, where a higher partition number indicates a set of sequences with lower affinity to the target antigen. Partitions 0–10 correspond to “weak” negatives, while partitions 11–25 correspond to “non-binders”, a dashed vertical line marks the separation between them. A graphical explanation of negative data partitions is provided at the bottom of the figure. The y-axis displays ID and OOD performance. The brown line shows ID performance. The other lines (blue, red, and yellow) represent OOD performance on tasks used in the main figures (Fig. 2a). The blue line shows OOD performance on the “vs Non-binder” task and is defined only for partitions corresponding to the ‘weak’ negatives (before the dashed line). The yellow line represents OOD performance on the “vs Weak” task and is defined only for partitions corresponding to the ‘non-binder’ negatives (after the dashed vertical line). Each model was trained with single seed and data split.
