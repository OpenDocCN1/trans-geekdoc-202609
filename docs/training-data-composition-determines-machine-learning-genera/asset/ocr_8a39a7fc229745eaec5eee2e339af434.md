Deep mutational scanning methods allow the creation of positive and negative datasets that are close in sequence and affinity 56,68,69 and provide information on epistatic interactions 51. Our work shows that deep mutational scanning datasets will be crucial for teaching sequence-to-function maps to ML models, where very small sequence differences can have large functional effects (Supplementary Fig. 2).

Our findings, although derived from sequence-based immune receptor–antigen interactions, have broader relevance for other biological ML tasks that involve binary classification and rely on difficult-to-define negatives, such as small-molecule drug discovery and transcriptomics-based phenotyping. The key message can be generalized conceptually: training with hard negatives (those similar to positives in the feature or label space) promotes OOD generalization and biologically meaningful rule learning. Our results suggest that using compounds with low but measurable activity (for example, weak inhibitors) as negatives could yield models that generalize better to unseen compounds and avoid overfitting to overly simplistic decision boundaries. Similarly, when predicting the phenotype from transcriptomic signatures, constructing negative sets from phenotypically close conditions could create more biologically grounded and robust classifiers. In general, increasing the difficulty of the classification task, by reducing the margin between classes in training, encourages ML models to learn more nuanced and transferable rules. We believe this is a broadly applicable principle in biologically grounded ML, warranting further domain-specific validation.

# Methods

# Synthetic antibody-antigen binding dataset generated using Absolut!

We used a semi-synthetic dataset of antibody–antigen binding, as generated previously 27,45. Briefly, this dataset comprises real-world antigen and antibody (CDRH3) proteins with antibody sequences from mouse repertoires 70 and with the antigens’ three-dimensional structures sourced from the Protein Data Bank and transformed into a three-dimensional lattice format. The authors of these datasets applied an exhaustive docking method to evaluate the binding of discretized rigid antigens with flexible CDRH3s of length 11 from the antibody side. The result included the acquisition of binding energy values, binding positions that minimize free energy, and the identification of interacting amino acids between antigens (epitope) and CDRH3s (paratope). Each antigen was associated with a set of 11-mers derived from CDRH3s and ranked according to their binding energy. Those in the lowest first percentile, with an average of 51,814.7 sequences, were labelled as high-affinity binders (or simply ‘binders’). The first to fifth percentile, averaging 205,069.3 sequences, were labelled as weak-affinity binders. Finally, the highest ninety-fifth percentile, with an average of 391,498.8 sequences, were labelled as non-binders. This labelling scheme aligns with the methodology used in ref. 27. For our study, we used antibody binding data from ten antigens, with Protein Data Bank IDs of 3VRL, 1NSN, 3RAJ, 5E94, 1HOD, 1WEJ, 1ADQ, 1FBI, 2YPV and 1OB1.

# Prediction tasks and training and testing datasets

We used balanced CDRH3 datasets (30k antibody sequences for training (15k positive class and 15k negative class) and 10k antibody sequences for testing (5k positive class and 5k negative class)), which varied by the positive class antigen and the negative dataset type (Table 1). The positive class of the dataset consisted of binder sequences, that is, sequences having binding energies between zero and first percentiles.

The negative class of each dataset was built depending on the binding prediction task type, as follows:

+   - ‘vs I’: sequences that are binders for another antigen but not the positive class antigen.
+   - ‘vs 9’: sequences that bind to one of the nine other antigens and do not bind to the positive class antigen, represented in equal proportions. To illustrate, in the training set of a total of 15,000 sequences, each of the nine antigens has approximately 1,666 (±1) associated sequences (~15,000/9).
+   - ‘vs weak’: sequences that bind the positive class antigen, but with binding energies in the first to fifth percentile.
+   - ‘vs non-binder’: sequences with binding energies in the >fifth percentile for the positive class antigen.

We generated replicates to ensure the reproducibility of the experiments. Specifically, six different train–test splits were generated for each prediction task and positive antigen. For one of the splits, we trained and evaluated the model four times with various seeds, thereby controlling for the randomness in model initialization and training. The positive class of the datasets is kept constant across the tasks and in each replicate experiment. For example, the positive class data in 1ADQ binder ‘vs weak’ is the same as the positive class data in 1ADQ binder ‘vs 9’. The sequences corresponding to each positive and negative dataset were randomly sampled to achieve the previously mentioned dataset sizes. Throughout our work, we used negative controls by randomly shuffling the class labels of sequences for each task. The prediction performance was evaluated on hold-out testing datasets using accuracy metrics, calculated as the number of correct predictions divided by the total number of predictions. The OOD performance was evaluated by calculating the performance on the testing sets of other tasks, for example, ‘vs 9’ performance on a ‘vs weak’ testing set. The OOD estimations were performed over the same set of replicates as in the ID case.

# ML model architecture, training and evaluation

We trained a simple neural network, previously 27 and henceforth called SN10 (ref. 27), for binding prediction tasks using CDRH3 sequences. The sequences, each consisting of 11 amino acids, are one-hot encoded, resulting in a dimensionality of 220. The neural network architecture consisted of 220 neurons in the input layer, 10 neurons in the hidden layer (rectified linear unit as activation) and 1 output neuron (sigmoidal activation). For training, after exploration of the parameter space, we used binary cross-entropy loss with the Adam optimizer with a batch size of 64, a learning rate of 0.001 and a momentum of 0.9, with no weight decay. We trained the models for 50 epochs and inspected the loss curves, which did not show signs of overfitting (Supplementary Fig. 3f). To further enhance the model’s performance, we implemented the technique of stochastic weight averaging 71,72, which involves averaging multiple sets of weights obtained during the training process to reduce the variance and improve the generalization performance of the model. We apply stochastic weight averaging after epoch 3/50, using the stochastic weight averaging implementation available in PyTorch v.1.12.1 (ref. 73). An LR-based model was further implemented for binary classification as a baseline for comparison. The model was trained and evaluated on the same datasets using one-hot-encoded CDRH3 sequences, as previously described for SN10 (ref. 27). We tested additional, more complex architectures in the process of evaluating the use SN10 as the main model of our study. The transformer model architecture consisted of an encoder with a dimensionality of 24, a vocabulary size of 30, 4 attention heads, and a single feed-forward layer with a dimensionality of 128. It incorporated a 0.1 dropout rate and used a rectified linear unit as the activation function.
