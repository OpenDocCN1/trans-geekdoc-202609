The influence of negative datasets for antibody binding prediction has been studied not only at the sequence level but also structurally, using simulated27 and experimental data25. Here we explored the impact of training set composition on prediction accuracy and generalizability, with an emphasis on the discovery of binding rules (Fig. 1b). We define the learning of binding rules as the identification of sequence-level binding energies and residue-level contributions to binding (energies).

The binding of immune receptors to their corresponding antigen is mainly determined by sequentially diverse complementarity-determining regions (CDRs)32,33. In particular, the CDR3 regions present in the heavy chain (CDRH3) of antibodies or beta chain (CDR3β) of TCRs contribute substantially to immune receptor–antigen binding32–34. Therefore, in the current study, CDRH3 regions were used as a proxy for full-length immune receptor sequences to train the ML models. Existing state-of-the-art immune receptor–antigen binding databases contain <10⁴ data points35–40 with known sequence/structures but, mostly, without the binding affinity. To address this gap, synthetic data have emerged as a viable solution to benchmark ML methodologies14,41,42. Synthetic data enable unconstrained access to ground-truth data, enabling an arbitrary composition of training datasets and thus, a more controlled analysis of generalization and rule discovery. We previously developed the antibody–antigen binding simulation framework Absolut!27, which enables the large-scale generation of synthetic antibody–antigen complex structures annotated with affinity. In earlier works, it was shown that the accuracy-based rankings of ML methods trained on experimental data are preserved when the same methods are trained on data generated by Absolut!, for both sequence- and structure-based prediction tasks43–45.

In this work, we used the Absolut! framework27 to generate synthetic training datasets with varying negative data compositions, reflecting common practices in immune receptor–antigen prediction (Fig. 1c). We trained ML models on these datasets and assessed how training data composition affects both generalization and biological rule recovery (Fig. 1d,e). Rule recovery was performed using explainability methods46–48, which aim to uncover the reasoning behind model predictions by identifying data features that most influence the output. We validated our findings using a large-scale experimental dataset of HER2 affinity-labelled antibody sequences from ref. 49. Our results show that both generalization and biological rule discovery depend critically on the training dataset composition – including the choice of negative examples (Fig. 1f).

# Results

# Training dataset sequence composition influences prediction performance in ID and OOD binary classification tasks

ML setup on synthetic and experimental data. We first investigated how the composition of negative data affects the performance and generalization of antibody–antigen binding predictors in supervised binary classification. Using the Absolut!27 framework, we simulated the binding of a large set of CDRH3 sequences to ten antigens. For each antigen, we defined four classification tasks (Table 1 and Fig. 2a), all sharing the same positive data (top 1% affinity sequences) but having a different type of negative: (1) 'vs non-binder' (bottom 95%), (2) 'vs weak' (1%–5% range), (3) 'vs 1' (top 1% binders to another antigen) and (4) 'vs 9' (top 1% binders to any of the nine other antigens). Each dataset contained 20,000 positive and 20,000 negative sequences, with 10,000 of each held out for testing. ML tasks were named according to the antigen and dataset type.

We trained a simple fully connected neural network with ten hidden neurons (SN10) to allow explainability. To ensure robustness, we repeated training with multiple random train–test splits and weight initializations, and monitored performance on the validation set to avoid overfitting (Supplementary Fig. 3f). This architecture and procedure were used by default for all analyses involving the SN10 model. We also compared SN10 with logistic regression (LR) and transformer models (Supplementary Fig. 3c,e and Supplementary Table 4), which showed no performance advantage, consistent with previous findings in similar settings27.

Finally, we replicated the in-distribution (ID) and out-of-distribution (OOD) performance analyses using an experimental dataset of 24,790 CDRH3 sequences labelled with binding affinity to the antigen HER2 previously published in ref. 49, which mirrors the structure of the synthetic data.

# ID prediction accuracy is a function of training dataset composition.

To assess the models’ ability to learn generalizable rules, we evaluated their performance on ID testing sets that matched the training data distribution (Fig. 2a). In this setting, models achieved high median accuracies across all tasks (>0.85), with a clear performance trend: highest on 'vs non-binder' (range: 0.97–1.00; median: 0.99), followed by 'vs 1' (0.94–1.00; median: 0.98) and 'vs 9' (0.91–0.98; median: 0.94), and lowest on 'vs weak' (0.85–0.98; median: 0.92; Fig. 2b), identifying 'vs weak' as the most challenging task.
