The techniques employed to predict the estimated position of an object will influence the accuracy of the estimated real position of the same. There have been many algorithms that have been implemented to estimate the position of the object. Starting from traditional methods that use polynomial regression as a propagation model to using K-Nearest Neighbours and machine learning. With the traditional method, RSS received was processed using weighted sum to get the coordinates of the objects and using a polynomial regression model to get distance. Both were determined using RSS signals from 3 advertisement channels of each beacon. Then both results filtered using outlier detection to clean the outcome, by combining fingerprinting with polynomial regression model distance into combined distance. This filtered result will be handled using extended Kalman filtering utilizing filtered distance from first outlier detection. Results from extended Kalman filtering will be filtered again using outlier detection to remove false measurement. This result is then processed again with extended Kalman filtering into an estimated position that will be compared with the radio map to get the real position. This method is using distance-based measurement which gives high error and reduced accuracy due to the filter [5]. Later, researchers have implemented CNN architecture by processing the fingerprinting data into image data and using this image data to train the CNNs. This method however requires huge datasets and numbers ANs to feed to the CNN [4].

In this paper a new technique for RSSI based fingerprinting and an improved fingerprinting data augmentation technique has been proposed. This method is highly recommended when the ANs are minimal and not in large scale. To give highly accurate localization even with less data, the employed RSSI-based augmentation technique is utilized, which is robust, unique and simple to implement, which is dependent on only RSSI values collected at each grid of the location to produce augmented output. The RSSI value present at the target grid is arbitrarily selected and written in the new output. The robustness lies in the fact that the pattern of augmented output matches with the input RSSI pattern of the target grid. The following shows how the rest of the paper is organized.
