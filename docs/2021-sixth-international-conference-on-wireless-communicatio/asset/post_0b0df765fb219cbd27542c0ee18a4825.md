## III. PROPOSED METHOD

The general architecture is depicted in Fig. 3. Initially, the UN senses RSSI values from BLE ANs. The positioning method that we use in our proposed framework is Fingerprinting. There are huge fluctuations in the RSSI values received from the ANs, depicted in Fig. 2. The proposed system, which simplifies indoor localization even with such colossal fluctuations, comprises two parts: Offline/Training stage and Online/Execution stage. In the Offline phase, when the data of the ANs is collected and the location coordinate is also recorded, the UN records these parameters to the local database. In the Online phase, the data is initially pre-processed which is augmented eventually. The augmented data set is appropriate enough to feed it to the different classifiers for comparison. The method which produces the highest accuracy scores is chosen to estimate the user position or the grid.

### A. Fingerprinting technique

The technique proposed, fingerprinting, divides the area of interest into a specific number of rectangular cells. The received signal power radio-signal parameter is measured for each cell using a tag node and an anchor node. These received signals are then organized as a random map in a similar fashion to a portrayal of signal strength distribution during the first phase also known as the training phase. Following the training phase the position inference is realized and the received power measurements are observed once again and this is the ensuing stage. These power measurements are then mapped with the location information that was obtained in the training stage. Finally by utilizing data association techniques and estimations the position of the target object is narrowed down to the cell it is in. This process allows the fingerprinting technique discrete estimations of the objects location. Theoretically, the distance and size of these rectangular cells can be reduced to the point where measurements provide a continuous observation rather than a discrete one. However, in this case, the difference in the signal strength between two neighbor points will turn out to be a lot more smaller than the typical indoor signal variations which makes the estimation of the correct point practically inconceivable. For the same reason, when the fingerprinting locations are picked, there is a significant tradeoff between the fingerprinting position granularity and the likelihood of successful location estimation which should be mulled over. It is likewise worth mentioning that the fingerprinting and scene analysis techniques are very susceptible to changes of the environment even though they can provide accurate localization estimations. ### B. Experimental Setup

The proposed indoor positioning system was tested in an indoor environment in Novitate Engineering Solutions, Chennai, India. In this setup, four BLE ANs were placed on the same plane and were not to be covered by other structures. The BLE module used in this setup is the DWM1001 by Decawave. The locations where the ANs A, B, C and D were placed in the closed environment can be seen in the Fig. 1. The positions where the ANs were placed was initially decided by triangulation method, but was later discarded because of high noise and interference. Later, by trial and error method and physical verification, the ANs were placed at the depicted positions. To ensure the reliability of the signal, the broadcast interval of beacons was set to 1 ms and the minimum distance between two adjacent beacons was 4 feet. The experimental area (100 square feet) was divided into evenly distributed grid points, the two adjacent grids were 1 feet apart. We collect data for 16 grids in the experimental area with the help of a line follower robot. Another BLE transceiver module i.e., the user node/tag is mounted on the line follower robot. The robot collects the RSSI values from the 4 ANs when it is stationary and right in the center of each grid. Minimum 58 and maximum 65 values were collected from each node at every grid. Thus, the entire radio map data set contains 1180 rows.

## IV. RESULTS

### A. Training of Classifiers

Classification is a type of supervised learning that aims to categorize a given set of data into various classes. In this case the classifiers were implemented to categorize the location of the user node based on the RSSI values. The classifiers used were:

-   **Random Forest**: Random Forest is an ensemble method used for classification that operates by designing a network of decision trees at training time and yields the mode of the classes from individual trees.
-   **XGBoost**: XGBoost is a decision-tree-based ensemble algorithm. It employs a gradient-boosting-framework for learning during the training phase.
-   **Decision Trees**: They are an instance of a supervised machine learning algorithm and can be explained using two major elements, leaves and nodes. Nodes are the places the where data is split based on conditions and leaves are final decisions of the algorithm.
-   **KNN**: The k-nearest-neighbours is a supervised machine learning algorithm which categorizes a datapoint depending on the nearest neighbouring datapoints.
-   **SVC**: The support vector machine algorithm is utilized to output and optimize hyperplanes that characterizes given information based on their features.

Jupyter notebooks were utilized on both the datasets, raw and augmented, and the datasets were split into test and train in a 75:25 ratio. The final results for each classifier were compared using metrics such as Accuracy, Error, F1 score, Recall.
