# 摘要

大型发电机是电力高技术设备，被视为电力系统的核心，也是国内外发电设备的发展目标。此外，其安全评价引起国际学术界和工程界的广泛关注。因此，本文采用基于模糊集的云安全评价模型，对负序条件下发电机的电磁损耗和发热进行评价。该模型根据云安全联盟和云平台服务模型建立了两个安全评价体系，并采用多级模糊评价进行安全评估。研究发现，该模型为云安全服务商的构建、从事云安全评估的第三方机构的定量评估以及云用户的云安全平台提供了重要的参考。

条件，发电机

# 引言

目前，云计算已得到广泛应用，云计算行业的发展也暴露了许多安全问题[1]。然而，目前为止还没有被业界广泛认可和遵循的国际安全标准。云安全联盟（CSA）作为一个国际云安全组织，于2009年在RSA会议上成立，旨在促进云计算环境下的最佳安全实践，并通过云计算安全提供安全框架。CSA已获得业广泛认可。2013年，云安全联盟顶级威胁工作组和领域专家小组进行了一项调查，识别了针对安全的威胁。这些威胁包括数据丢失、数据账户访问或服务流的风险、不安全的接口和API以及服务独立性的定义等云服务问题。国内外研究人员大多侧重于影响云安全的因素的分析与预防，但缺乏云安全的质量评价标准。因此，建立云安全及其相应的评价体系对于云安全而言是一项挑战。

随着发电机的发展，电磁和热负荷随之增加。这可能导致局部过热、异常下降或对电力系统安全造成威胁[3,4]。对当前的负载和热量进行研究非常有价值，这可能会增加负序容量并降低电压，导致发电机转子功率以及大型发电机的非对称运行特性。转子负序加热问题一直是大型发电机设计和分析中的一个主要问题。因此，云计算无疑是负序条件下大规模计算最有效的技术方法之一。

# 2 负序电磁损耗与发热的云计算

## 4.1 基于 CSA 的云安全层次模型综合评价

通过对基于 CSA 的安全层次模型的评价频率分布表调查数据进行归一化，可以获得云架构、云治理和云运营指标单因素评价矩阵。

```
$R_1 = [0.10, 0.70, 0.20, 0.10]

```

```
$R_2 = [0.20, 0.40, 0.20, 0.20]
0.10, 0.30, 0.40, 0.20
0.10, 0.20, 0.50, 0.10
```

```
$R_3 = [0.20, 0.50, 0.10, 0.20]
0, 0.20, 0.30, 0.10
0.10, 0.30, 0.50, 0.20
```

分别使用模型 $M(\wedge, \vee)$ 进行一级评价，得到模糊综合评价集：
B1=$A31 \wedge R_1=(0.10, 0.60, 0.20, 0.20)，
B2=$A32 \wedge R_2=(0.12, 0.24, 0.43, 0.21)$以及其归一化结果 (0.11, 0.23, 0.41, 0.24)；
B3=$A33 \wedge R_3=(0.16, 0.25, 0.41, 0.22)$以及其归一化结果 (0.15, 0.24, 0.39, 0.21)。

从上述一级综合评价 B1、B2 和 B3 中，得到二级综合评价为：

| | | | |
|---|---|---|---|
| $B_1$ | 0 | 0.60 | 0.20 |
| $B_2$ | 0.11 | 0.23 | 0.41 |
| $B_3$ | 0.15 | 0.24 | 0.39 |

然后，通过三级评价得到 $B = B_1 \vee B_2 \vee B_3=(0.13, 0.27, 0.53, 0.29)$，归一化后为 (0.11, 0.21, 0.50, 0.13)。根据原理，电磁负序状态。
