
To evaluate the security level of the crypto-stego image NPCR is found as shown in [`Equation (7)`](#ch37.xhtml#math37_7) where it indicates pixel change rate of original image from retrieved image. In [`Equation (8)`](#ch37.xhtml#math37_8) `I[0]` indicates the original X-ray image and `I[1]` is the retrieved X-ray image.

(7)  

```math
\\text{NPCR} = \\frac{\\sum\\_{x = 1,y = 1}^{\\text{n},\\text{m}}\\text{D}(\\text{x},\\text{y})}{\\text{n} \\times \\text{m}} \\times 100\\text{\\%}
```  

(8)  

```math
D(x,y) = \\left\\{ \\begin{array}{l} {0,\\, if\\, I\_{0}(x,y) = I\_{1}(x,y)} \\\\ {1,\\, if\\, I\_{0}(x,y)! = I\_{1}(x,y)} \\\\ \\end{array} \\right.
```  

### Universal average changed intensity (UACI)

UACI is represented with the help of [`equation (9)`](#ch37.xhtml#math37_9).

(9)  

```math
UACI = \\frac{\\sum\\_{x = 1,y = 1}^{N,M}\\left| {I\_{0}(x,y) - I\_{1}(x,y)} \\right|}{(N \\times M) \\times 255}
```  

### Entropy

Entropy is represented with the help of [`Equation (10)`](#ch37.xhtml#math37_10).

(10)  

```math
H(U) = \\sum\\limits\_{i = 0}^{255}p(u\_{i})\\log\_{2}p(u\_{i})
```  

### Bit error rate (BER)

BER is represented with the help of [`Equation (11)`](#ch37.xhtml#math37_11).

(11)  

```math
BER = \\frac{\\sum\_{i}I(i) - SI(i)}{I.}
```  

### Mean absolute percentage error (MAPE)

MAPE is represented in the [`Equation (12)`](#ch37.xhtml#math37_12).

(12)  

```math
MAPE = \\frac{1}{L}\\sum\\limits\_{i = 1}^{L}\\left( \\frac{\\left| I(i) - SI(i) \\right|}{I} \\right) \\times 100\\text{\\%}
```  

### Signal to noise ratio (SNR)

SNR is represented in the [`Equation (13)`](#ch37.xhtml#math37_13).

(13)  

```math
SNR = 10\\log\_{10}\\frac{\\sum\_{i = 1}^{L}\\left( {I(i) - SI(i)} \\right)^{2}}{\\sum\_{i = 1}^{L}\\left( {I(i)} \\right)^{2}}
```  

### Compression ratio (CR)

As shown in [`Equation (14)`](#ch37.xhtml#math37_14) it is the size of the original image in bytes divided by restored image in bytes.

(14)  

```math
CR = \\frac{Sizeof(I)}{Sizeof(SI)}
```  

### Kullback-Leibler divergence (KLD)

KLD is represented in the [`Equation (15)`](#ch37.xhtml#math37_15).

(15)  

```math
KLD(p\_{or},p\_{tr}) = \\int^{}p\_{or}(x)\\log\\frac{p\_{tr}(x)}{p\_{or}(x)}dx
```
