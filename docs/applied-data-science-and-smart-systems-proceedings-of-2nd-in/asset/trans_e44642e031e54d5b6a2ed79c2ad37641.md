
λ 表示电荷在漏极附近的电场穿透到通道的距离。将 *µ* 替换为 *µ[eff]* 并将方程 (6) 乘以 FCLM 后，漏电流的表达式被修改为

(11)  

``` 
$$\\begin{matrix} & {I\_{DS} = \\mu\_{of}\\frac{8\\pi\\varepsilon\_{DI}}{L}V\_{T}^{2} \\times} \\\\ & {\\left\\lceil {2(q\_{iS} - q\_{iD}) + \\frac{\\eta}{2}(q\_{SS}^{2} - q\_{DD}^{2}) - \\ln(\\frac{1 + q\_{SS}}{1 + q\_{iD}})} \\right\\rceil \\times FCLM} \\\\ \\end{matrix}$$  
```  

在短通道器件中，内在通道电阻的降低使得串联电阻 (*R[SD]*) 成为总电阻的重要部分。串联电阻通过降低供电压降低了器件的驱动能力。提取的 *R[SD]* 已通过以下方程纳入上述方程中

(12)  

``` 
*V*[*D**S*] = *V*[*D**S*] − (*I*[*D**S**]*R*[*S**D**])  
```  

(13)  

``` 
$$V\_{GS} = V\_{GS} - \\left( \\frac{I\_{DS}R\_{SD}}{2} \\right)$$  
```  

*V’[GS]* 和 *V’[DS]* 分别表示内在栅极电压和漏极电压。在加入串联电阻后，上述方程 (7–11) 通过将栅极和漏极电压替换为内在电压（方程 12 和 13）进行修改。将上述方程代入电荷载流量和漏电流的表达式中，得到新的漏电流表达式。

从上述方程可以看出，供电压是漏电流的函数。因此，我们采用迭代程序来计算供电压和漏电流（Kumar 等，2016, 2017）。

迭代过程如 [Figure 6.3](#ch6.xhtml#fig6_3) 所示的流程图所示。步骤如下：最初假设漏电流为零。然后，使用方程 (11) 在第 1 次迭代中计算 *I[DS]*，其中 *V’[GS]* 和 *V’[DS]* 由 (12) 和 (13) 给出（此时 *I[DS]* = 0）。随后，利用 *I*[DS] 的值在前一步得到，计算出新的 *V’[GS]* 和 *V’[DS]*（使用 (12) 和 (13)）。在第二次迭代中，将前一步得到的 *V’[GS]*、 *V’[DS]* 以及 *I*[DS] 代入，得到新的 *I*[DS] 值。该过程重复，直到 *I*[DS] 连续的值保持不变。
