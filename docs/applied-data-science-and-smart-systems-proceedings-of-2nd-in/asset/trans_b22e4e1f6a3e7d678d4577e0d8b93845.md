
OCT 是一种非侵入性的医学成像技术，利用光波捕获生物组织的高分辨率横截面图像。它在眼科中主要用于观察和分析视网膜及其他眼部结构，同时也应用于心脏学和皮肤学。OCT 基于干涉原理工作，光束被分为两条路径：参考路径和样本路径。参考光束照射到镜子上，而样本光束照射到正在分析的组织上。随后，来自两个方向的光波在照射组织后会返回仪器。

在眼科中，OCT 特别有价值于视网膜的可视化以及识别各种视网膜疾病，如黄斑变性、糖尿病视网膜病变和青光眼。它能够评估视网膜层的厚度、完整性以及病理改变，从而辅助诊断、制定治疗方案并监测这些疾病的进展。

OCT 还用于其他医学专科。在心脏学中，它可以提供血管的细致成像，并识别冠状动脉中的动脉粥样斑块。在皮肤学中，OCT 有助于可视化和评估皮肤病变，并指导活检操作。OCT 的主要优势之一是其高分辨率成像能力，能够以微米级精度观察细小的组织结构。然而，OCT 也存在局限性，主要受限于光波的穿透深度，因此主要用于成像表层组织。显微层面的医学图像用于评估组织的微小结构。活检用于获取组织样本进行检测，随后使用染色剂暴露组织中细胞特征。对比染料用于提升图像的色彩、可见度和对比度。

## Data augmentation

深度学习（DL）神经网络的实现取决于合适数据的便利性。数据增强（Data augmentation）包括对样本进行合理的变换（如翻转、旋转、镜像），并在灰度值上进行增强，是聚集训练数据集最常用的方法。数据增强的效率在非临床研究中被评估，结果表明经典增强方法可使数据规模增加最高达 7% ([Fotenos et al., 2005](#ch36.xhtml#ref36_40); [Golan et al., 2016](#ch36.xhtml#ref36_41); [Milletari et al., 2017](#ch36.xhtml#ref36_42))。当真实数据稀缺时，会使用多种数据增强程序从现有数据集生成更多训练样本。这些增强技术在保持类别不变的前提下改变图像，常见方法包括：

1. 图像平移：沿单一方向（水平或垂直）移动像素，不改变图像整体尺寸；
2. 图像翻转：水平和垂直翻转图像，相当于撤回行和列的像素；
3. 图像旋转：将图像从 0 旋转至 360 度；
4. 对比度调整：改变图像的亮度水平，以便模型在测试时能够适应此类差异；
5. 图像缩放：通过添加新的边界像素或使用插值，随机放大或缩小图像。

大多数增强技术会使用最近邻填充、边界像素复制、平均值或插值等方式，既删除少量现有像素，又加入新像素。前四种方法被称为“刚性”数据增强策略，因为数据形状保持不变。第五种方法保持垂直和水平放大比例相同；若比例不同，图像会在单一方向上出现拉伸（图像拉伸）。这些增强技术的目标是提升深度神经网络的泛化能力，避免欠拟合和过拟合。通常在网络训练阶段会自动应用这些策略。此外，还可以通过迁移学习——从同一或其他行业已成功实现的模型中转移知识——来进一步提升性能。迁移学习受网络结构、医学影像模态以及数据集规模的影响 ([Perez et al., 2017](#ch36.xhtml#ref36_43))。

## Quantitative analysis

客观分析在评估分割算法的有效性方面发挥关键作用。分割系统通过公认的基准进行评估，从而能够与文献中最近发表的方法进行比较。所选的评估指标受多种因素影响，包括系统的具体实现。这些指标衡量准确性、处理时间、内存使用以及计算复杂度等不同方面 ([Shie et al., 2015](#ch36.xhtml#ref36_44))。[表 36.2](#ch36.xhtml#tab36_2) 提供了用于评估深度学习模型分割性能的各种缩写（TP、FP、FN、TN）的定义：

[Table 36.2 DL segmentation performance parameter](#ch36.xhtml#R_tab36_2)

| Category || 实际疾病 || 实际无疾病 |
| --- | --- | --- |
| 预测疾病 || 真阳性（TP） || 假阳性（FP） |
| 预测无疾病 || 假阴性（FN） || 真阴性（TN） |

### 精确度（Accuracy）

最基础的性能指标是整体像素精度，也称为整体像素精确度。它用于判断患者是否患病或健康。

(2)  

$$Accuracy = \\frac{Correctly\\ Predicted\\ Pixels}{Total\\ No.of\\ Image\\ Pixels} = \\frac{TP + TN}{TP + FP + FN + TN}$$  

### 精确率/特异性（Precision/specificity）

精确率表示自动分割结果中与真实疾病像素相符的受影响像素比例。精确率是评估分割性能的重要指标，尤其在易出现过度分割的场景中。准确测量健康情况的能力被称为特异性 ([Lalkhen et al., 2008](#ch36.xhtml#ref36_45))。

(3)  

$$Precision = \\frac{Correctiy\\ Predicted\\ Disease\\ Pixels}{Total\\ No.of\\ Predicted\\ Disease\\ Pixels} = \\frac{TP}{TP + FP}$$  

### DSC（DICE 相似系数）

DSC 优于总像素精度，因为它同时考虑每个类别的误报和漏报，能够更公平地评估分割质量。DSC 被认为更具价值，因为它不仅衡量已正确识别的像素数量，还衡量分割边界的精确度 ([Van et al., 2009](#ch36.xhtml#ref36_46))。此处的 S 代表分割。

(4)  

$$DICE = \\frac{2 \\times TP}{2 \\times TP + FP + FN}$$  

### 灵敏度/召回率（Sensitivity/recall）

灵敏度指的是准确测量疾病病例的能力。它是指根据程序化分割，精确预测了地面真实中疾病像素的比例。

(5)  

$$Sensitivity = \\frac{TP}{TP + FN}$$  

### Jaccard 相似系数（JSI）

JSI（交叉比系数）是预测分割区域与地面事实分割区域的交集占并集的比例。

(6)  

$$JSI = \\frac{TP}{TP + FP + FN}$$  

从上述公式可以看出，JSI 与 DSC 有区别。

(7)  

$$JSI = \\frac{DSC}{2 - DSC}$$  
$$DSC = \\frac{2JSI}{1 + JSI}$$  

### 阴性预测值（NPV）
