### 评估指标

在雾计算中，延迟是指从过程开始到完成之间经过的时间量。对于许多应用而言，降低延迟是关键目标，因为它会显著影响雾计算系统的整体性能。延迟在 [Equation (4)](#ch35.xhtml#math35_4) 中计算如下。

(4)  

*L**a**t**e**n**c**y* *E**q**u**a**t**i**o**n*(*L*) = *P* + *R*  

*P* 表示处理时间；*R* 表示网络延迟。

*P* 可通过将处理率 *R*（processing rate）乘以任务的处理时间 *T* 来估计：

(5)  

*P* = *R* × *T*  

网络延迟可通过加入传输时间 (*T[t]*) 与传播时间 (*T[p]*) 来分析：

(6)  

*N* = *T*[*t*] + *T*[*p*]  

传输时间可以通过传输速率 (*R[t]*) 与任务大小 (*S*) 的乘积来计算：

(7)  

``` 
$$T\_{t} = \\frac{S}{R\_{t}}$$  
```  

当传播速度 (*S*) 与距离 (*d*) 相乘时，可得到传播时间。
