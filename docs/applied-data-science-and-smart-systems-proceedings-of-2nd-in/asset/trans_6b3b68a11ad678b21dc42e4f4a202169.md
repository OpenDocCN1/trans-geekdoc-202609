
与其他多门极结构相比，具有栅极全周（GAA）结构的金属氧化物半导体场效应晶体管（MOSFETs）能更好地抵抗短通道效应（SCEs），因为门极能够有效控制通道内的电位，从而有效地控制电位。将 GAA 引入 JL 设备可以进一步提升器件特性（Colinge 等，2010；[Duarte 等，2011](#ch6.xhtml#ref6_6)；[Yu，2014](#ch6.xhtml#ref6_26)）。因此，当前研究重点放在 GAA JLT 上。

文献中有大量关于长通道 GAA JLT 漏极电流建模的报告（[Duarte 等，2011](#ch6.xhtml#ref6_6)；[Yu，2014](#ch6.xhtml#ref6_26)）。然而，短通道器件的建模仅由少数研究者报道（Hu 等，2014；Jiang 等，2014；[Sehra 等，2020](#ch6.xhtml#ref6_18)；Raut 和 Nanda，2022；Smaani 等，2022）。本文开发了一种短通道 GAA JLT 的漏极电流模型，这是一个近期的研究方向（Chaujar 等，2023；Kumar 等，2023；Kumari 等，2023；Smaani 等，2023）。我们在模型中加入了源/漏串联电阻。该模型基于之前的基于结的 GAA MOSFET 紧凑模型（[Tsormpatzoglou 等，2009](#ch6.xhtml#ref6_24)）。源/漏串联电阻是建模 SC 设备的关键因素，因为在该类设备中，串联电阻占总电阻的相当比例，必须在器件建模中予以考虑。模型通过实验数据和仿真数据进行验证。还获得了串联电阻变化对漏极电流特性的影响。

## II. 理论细节

GAA 结构因门极能够对通道提供卓越的控制，从而具有优越的短通道特性。由于 JLTs 不存在结，因此不需要掺杂浓度梯度，从而消除了与结相关的问题。这些器件在与 GAA 架构结合时，也被报道能够提供改进的驱动电流和亚阈值特性。[Figure 6.1](#ch6.xhtml#fig6_1) 展示了此类 JL GAA MOSFET 的横截面。

### 器件物理

JLTs 被描述为在整个区域均匀强度掺杂的器件，这意味着掺杂剂的类型和浓度在整个结上保持一致。对于 n 型器件，使用 p+ 多晶硅作为门极材料，n+ 多晶硅用于 p 型器件。这导致工作函数约 1 eV 的差异，从而使通道出现耗尽。为使通道脱耗，必须施加门极偏压。GAA JLT 的工作原理如下。

当不施加门极电压（\(V[G]\)）时，通道完全耗尽，S 与 D 之间的电流极低，此时晶体管处于 OFF 状态，即处于亚阈值工作区。此时价带完全填满，导带为空。当门极电压等于器件的阈值电压（\(V[TH]\)）时，在通道中心附近形成一条非耗尽的薄中性路径，电流开始沿此路径流动。随着门极电压的增大，该路径被拉宽，电流随之增加。能带图中可以看到正载荷在价带中的浓度降低。当门极电压等于设备的平带电压（\(V[FB]\)）时，形成完整的中性通道，达到平带条件，导体和价带变得平坦，此时器件处于 ON 状态。进一步提高门极电压，在表面形成积聚层，负载流体被积聚，从而产生表面电流，与体电流一起流动。[Figure 6.2](#ch6.xhtml#fig6_2) 展示了 GAA JLT 在不同工作区域的能带图以及器件示意图。

对于 n 型半导体，在圆坐标系中，Poisson 方程可表示为

(1)  

$$\\frac{\\partial^{2}\\phi}{\\partial r^{2}} + \\frac{1}{r}\\frac{\\partial\\phi}{\\partial r} = \\frac{- q}{\\varepsilon\_{si}}\\left\\lbrack {\\frac{n\_{i}^{2}}{N\_{d}}(e^{\\frac{- (\\phi - V)}{V\_{T}}} + 1) - N\_{d}(e^{\\frac{(\\phi - V)}{V\_{T}}} - 1)} \\right\\rbrack$$  

其中，\(\\phi\) 表示电位，\(r\) 表示径向方向，\(V\) 为施加电压，\(N[d]\) 为源、漏和通道中掺杂浓度的总量，\(V[T]\) 为热电压，\(\\varepsilon[Si]\) 为硅的介电常数。

在忽略耗尽电荷密度、仅考虑移动载流子密度的情况下，上式可简化为（[Trevisoli 等，2012](#ch6.xhtml#ref6_23)）

(2)  

$$\\frac{\\partial^{2}\\phi}{\\partial r^{2}} + \\frac{1}{r}\\frac{\\partial\\phi}{\\partial r} = \\frac{q}{\\varepsilon\_{s}}N\_{d}\\left( e^{\\frac{(\\phi - V)}{V\_{T}}} \\right)$$  

GAA MOSFET 的边界条件可表示为（Jimenez 等，2004）

(3)  

$$\\begin{matrix} & {\\frac{d\\phi}{dr}(r = 0) = 0} \\\\ & {\\phi(r = R) = \\phi\_{s}} \\\\ \\end{matrix}$$  

通道缩短对阈值电压的影响体现在 \(\\Delta V[TH]\)，可表示为（[Tsormpatzoglou 等，2009](#ch6.xhtml#ref6_24)）

(4)  

Δ*V*[*TH*] = *V*[*TH*,L] - *V*[*TH*,S]  

其中 *V*[*TH*,L] 和 *V*[*TH*,S] 分别为长通道（[Duarte 等，2011](#ch6.xhtml#ref6_6)）和短通道（Chiang，2012）阈值电压。

考虑漂移-扩散模型的漏极电流表达式为

(5)  

$$I\_{ds} = 2\\pi\\mu V\_{T}\\frac{R}{L}\\int\\limits\_{V_{i}}^{V_{4}}Q\_{S}(V)dV$$  

在上式中，\(q[i]\) = \(Q[i](V)/(4\\varepsilon[si]kT/qt[si])\)，表示正常化片态电荷密度，\(Q[i]\) 表示反演电荷密度，\(V\) 从源电压到漏电压变化。

对上式进行积分后，得到漏极电流表达式：

(6)  

$$I\_{DS} = \\mu\\frac{8\\pi\\varepsilon\_{si}}{L}V\_{T}{}^{2}\\left\\lceil {2(q\_{is} - q\_{iD}) + \\frac{\\eta}{2}(q\_{is}{}^{2} - q\_{DD}{}^{2}) - \\ln(\\frac{1 + q\_{Ss}}{1 + q\_{DD}})} \\right\\rceil$$  

移动性可以表示为（Gaubert 等，2010）

(7)  

$$\\mu\_{eff} = \\mu\_{0}\\frac{{(V\_{GS} - V\_{TH})}^{\\alpha}}{1 + \\theta\_{1}(V\_{GS} - V\_{TH}) + \\theta\_{2}{(V\_{GS} - V\_{TH})}^{2}}$$  

其中，\(\\alpha\) 描述库仑散射，\(\\theta[1]\) 代表声子散射，\(\\theta[2]\) 代表表面粗糙散射。\(V[GS]\) 为门极到源极电压，\(\\mu[0]\) 为低场迁移率。此外，我们使用了 FCLM 因子来考虑通道长度调制效应，FCLM 可表示为

(8)  

$$FCLM = 1 + \\left( \\frac{\\lambda\_{0}}{L} \\right)^{A}\\left( \\frac{V\_{Def}}{V\_{Geff} - V\_{TH}} \\right)^{B}$$  

其中指数 \(A = 0.9 - (\\lambda[0]/L)\)，\(B = 0.8(1+ (\\lambda[0]/L))\)。

(9)  

$$V\_{oeff} = (V\_{TH} + 0.15) + (V\_{Os} - V\_{TH} - 0.15)\\tanh\\left( \\frac{V\_{QS}}{V\_{TH} + 0.15} \\right)^{2}$$  

(10)  

$$V\_{Deff} = V\_{DS}\\tanh\\left( \\frac{1.4V\_{DS}}{V\_{oeff}} \\right)^{2}$$
