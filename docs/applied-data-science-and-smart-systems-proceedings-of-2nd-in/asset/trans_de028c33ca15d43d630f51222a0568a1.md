
Twitter 是自 2019 年 10 月以来分析科罗纳病毒疫情期间多个因素的重要数据来源之一。基于 400 万条推文的详细分析发现，反对疫苗（anti-vaccine）和支持疫苗（pro-vaccine）的推文数量是关键参数（Yousefinaghani Samira 等，2021）。同样，利用 4200 万条推文分析了乌克兰经济紧张和战争的关键指标，这也凸显了战争对全球美元价值和原油价值的影响（Polyzos，2022）（`#ch25.xhtml#ref25_8`））。Twitter 数据质量标准实践是进一步分析过程和正确结果的关键因素（`#Salvatore et al., 2021`）（`#ch25.xhtml#ref25_9`））。Feng Yunhe 等（2023）提供了聊天机器人（chat-GPT）对流媒体的影响，并基于 Twitter 和 Reddit 等社交媒体平台进行实时分析，重点关注响应时间。Reddit 论坛数据用于收集疫情爆发期间学生对基础设施变更的需求（`#Feng et al., 2023`）（`#ch25.xhtml#ref25_10`））。此外，学生的心理健康参数也通过 Twitter 和 Reddit 平台评估与贷款债务相关（`#Sinha et al., 2023`）（`#ch25.xhtml#ref25_12`））。Reddit 帖子主要用于主题建模，因为用户在子论坛中发布评论（`#Bonifazi et al., 2023`）（`#ch25.xhtml#ref25_13`））。纽约时报文章被用于评估全球疫情后经济衰退的状况。`[Barhanpurkar 等的研究（2023）](#ch25.xhtml#ref25_15)`，作者在该研究中进行了情感分析、实体识别和主题建模。情感分析和 NLP 处理技术用于从《纽约时报》文章中获取关于新冠疫情爆发的洞察（`#Tunca et al., 2023`）（`#ch25.xhtml#ref25_16`））。在`[Table 25.1](#ch25.xhtml#tab25_1)`中，不同研究展示了 Twitter、Reddit 和纽约时报的使用情况，体现了数据应用的广泛领域。

## Proposed methodology

在`[Figure 25.1](#ch25.xhtml#fig25_1)`中，描述了研究期间使用的研究方法。在数据收集和存储的初始步骤中，数据来自三个来源：Twitter API 的推文、Reddit API 的子论坛评论以及 New York Times Archive API 的文章和标题。流媒体数据存储在 MySQL 数据库中，使用 MySQL Connector。数据收集和存储完成后，进行数据清洗步骤，以准备数据用于 NLP 操作。去标点、分词和词干化等技术用于精炼数据。在数据可视化和分析阶段，处理后的数据最终用于生成关于衰退状况、经济危机和通货膨胀指标的洞察。用于生成洞察的方法包括时间序列分析、内存使用分析、词云分析、词频分析以及情感分析。时间序列分析用于识别数据中的趋势和周期性模式，关注数据随时间变化的特性。此外，内存使用分析通过确保计算资源的可扩展性来优化数据处理工作流。词云分析同时可视化数据的主要主题，词频分析则揭示增长趋势。因此，词云分析和词频分析是大规模文本数据的关键词分析步骤。
