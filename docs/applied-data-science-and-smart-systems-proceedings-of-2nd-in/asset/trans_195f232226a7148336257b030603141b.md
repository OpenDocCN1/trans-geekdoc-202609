
-   [分析移动边缘服务器的负载是将任务卸载到边缘服务器之前的必要步骤，包括是否进行卸载以及，如果进行，卸载到哪个边缘服务器。分析移动边缘服务器的负载是为了响应上述问题。任务/数据卸载决策至关重要，因为它预计会对用户应用的 QoS 产生直接影响，包括因卸载机制导致的延迟（Yeongjin [Kim et al., 2018](#ch18.xhtml#ref18_3)）。当大量用户设备通过同一无线网络使用同一服务器时，若服务器承受巨大压力，可能导致显著的处理延迟以及部分进程的停止（Fengxian [Guo et al., 2018](#ch18.xhtml#ref18_4)）。MEC 概念的推理架构被用于获取云端计算应用。通过在网络节点部署多个信息中心，智能手机用户将更易于接入。网络终端可以参考多种位置，包括室内 Wi‑Fi 以及 3G/4G。在当今世界，计算卸载（CO）既讨论提升智能手机性能，也讨论在保证能源节约的同时实现此目标（Abbas [Kiani et al., 2018](#ch18.xhtml#ref18_6)）。尽管满足延迟前提条件，MEC 仍允许边缘侧执行计算密集型应用，而不是用户设备。此外，物联网用户将在后续参与以用户为中心的 5G 网络中的感知与处理任务（Liang [Huang et al., 2019](#ch18.xhtml#ref18_7); [Thakur et al., 2021](#ch18.xhtml#ref18_10)）。实际上，使用 MEC 卸载计算过程会导致无线网络用于传输数据。如果许多应用站点强制将处理资源全部卸载到边缘节点，无线连接可能会严重拥堵，从而极大减慢 MEC（Gagandeep [Kaur et al., 2021](#ch18.xhtml#ref18_8)）。因此，需要一个统一的管理系统来管理 CO 并伴随的无线资源分配，以便从计算卸载中获益（Khadija [Akherfi et al., 2016](#ch18.xhtml#ref18_2)）。在第 2 节中，本文描述了 MEC 中的任务卸载研究。第 3 节介绍了任务卸载系统模型，包括本地计算、边缘计算以及深度 Q 学习方法。第 4 节阐述了不同任务卸载技术的结果和图表。最后在第 5 节给出结论。

-   [在 (Khadija [Akherfi et al., 2016](#ch18.xhtml#ref18_2)) 中，研究了众多边缘计算范式及其在快节奏领域中学术界和产业界面临的各种困难。作者提出了包括基于中间件的设计并采用优化卸载机制在内的多种方案，这些方案有望改进现有框架，并通过节约能源、加快响应时间以及降低执行成本来为移动云计算（MCC）用户提供更有效、更具适应性的解决方案。]

-   [Ke [Zhang et al. (2016](#ch18.xhtml#ref18_9)) 提出了一种能源高效计算卸载（EECO）方法，该方法同时优化卸载决策和无线资源分配，从而在 5G 异构网络的延迟约束下最小化系统能耗。]

-   [为容量受限的回程无线网络提出了能源高效缓存（EEC）技术，旨在在满足计算延迟成本限制的同时降低功耗（Zhaohui Luo et al., 2019; [Gera et al., 2021](#ch18.xhtml#ref18_5)）。数值结果表明，延迟效率提升了 20%。该方法可能非常接近理想答案，远优于最可能的结果，即近似上限。]

-   [利用两个经过时间优化的顺序决策模型以及最优停止理论，作者 (Ibrahim [Alghamdi et al., 2019](#ch18.xhtml#ref18_12)) 解决了从哪里以及何时进行卸载的问题。通过使用真实世界数据集进行性能评估，并将其与基准确定性和随机模型进行对比。结果表明，在单用户及竞争用户的情形下，我们的方法能够优化这些决策。]

-   [Kai [Peng et al. (2019](#ch18.xhtml#ref18_13)) 研究了在 MEC 中针对工作流应用（MCOWA）的多目标计算卸载方法，该方法在满足工作流应用截止期限的前提下，寻找最佳的应用方案。大量实验评估展示了所提策略的有效性和效率。]

-   [在 MEC 无线网络中，提出了一种基于软件定义网络（SDN）的计算卸载解决方案。基于强化学习，作者评估了考虑激励和惩罚的能源保全问题的解决方案（Nahida Kiran et al., 2020）。]

-   [提出了一种基于深度强化学习的分布式卸载方法，使移动设备能够以分布式方式自行决定卸载。仿真结果表明，该技术在与多个基准方法相比时，可降低丢弃任务的比例和平均延迟（Ming [Tang et al., 2020](#ch18.xhtml#ref18_15)）。此外，还提出了一种适用于多用户、多信道和多服务器场景的多层卸载优化框架。从边缘用户的视角，使用能耗和延迟参数进行卸载决策，并提出了一种多目标决策技术以降低边缘客户端的能耗和延迟（Nanliang [Shan et al., 2020](#ch18.xhtml#ref18_16)）。]

### B. 边缘计算模型

[content]
Let’s assume that N numbers of UEs are anticipating tasks to be off‑loaded and executed on edge server since local server does not have enough power resources. The task queue contains every single task. When the Q value function is modified based on reward and state, the task queue is supposed to update each time.
