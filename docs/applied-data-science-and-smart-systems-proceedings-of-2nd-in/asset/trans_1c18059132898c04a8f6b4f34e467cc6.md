
云计算系统的结构和特征统称为云计算架构。它通常涉及多层抽象层和各种硬件与软件组件，如下文所述。

物理基础设施层– 该层由物理服务器、存储设备、网络设备和数据中心组成，为云计算提供基础。

虚拟化层– 该层能够生成并跟踪虚拟机（VMs）以及虚拟资源，如虚拟 CPU、内存和存储。它允许多个 VM 在最大化硬件资源使用的同时运行。

平台层– 开发者可在此层设计和部署软件，而无需关注底层基础设施的管理。该层包含应用开发、测试、部署和可扩展性工具。

应用层– 通过互联网向终端用户提供的应用和服务包含在此层。它包括云计算服务。

管理层– 该层提供监控、管理和保护云计算环境的工具和服务。它包括用于管理 VM、存储、网络、安全性以及合规性服务的工具。

## DDoS 攻击及其分类

多种安全攻击可能威胁云计算环境的安全。诸如 DDoS 之类的攻击对云计算基础设施构成严重安全风险。DDoS 攻击利用多台计算机或其他设备向目标系统发送大量请求或流量，导致系统过载并使授权用户无法访问。基于云服务依赖互联网与用户及其他服务连接，云端服务特别易受 DDoS 攻击，因为流量洪峰和网络拥塞更容易发生。组织应考虑采用防火墙、入侵检测与防御系统等强有力的安全措施，以及内容分发网络（CDN）来防御云端 DDoS 攻击。同时，组织应定期监控网络流量，并准备快速应对任何已发起或确认的 DDoS 攻击。攻击者可能使用虚拟机、计算机、笔记本或僵尸（zombies）参与此类攻击，这些设备都带有远程控制。多台计算机可用于发起威胁性攻击，即 DDoS（[Abusaimeh etal., 2020](#ch30.xhtml#ref30_1)）([Figure 30.2](#ch30.xhtml#fig30_2))。

## DDoS 攻击的分类

DDoS 攻击因其能够轻易在互联网上传播而难以阻止或识别（[Kesavamoorthy etal., 2020](#ch30.xhtml#ref30_3)）。根据威胁类型，可将 DDoS 分为若干类别，例如针对低速请求的攻击：受感染机器发送的请求数量少于正常用户，但会在会话速率上波动。在每秒请求较少的情况下，被入侵的计算机会以较高的速率发送请求，但会话速率低于常规，且会随机变化（Kumar etal., 2016）。DDoS 的两大类别为：第一类，攻击者使用消耗大量带宽的 DDoS 手段，淹没网络设备、带宽分配和通信通道，并以大量数据包的形式进行洪水攻击；第二类，应用层 DDoS 攻击中，攻击者劫持受害计算机的计算资源，阻止其处理真实的交易和请求，利用服务、应用以及网络通信协议（如 TCP、HTTP）的行为进行攻击。

## 基于攻击流量特征的分类

### 体积型攻击

体积型攻击是最常见的 DDoS 类型，旨在通过大量流量占据网络或服务器，通常利用僵尸网络（由被 compromised 设备组成的网络）生成高流量。

### 协议型攻击

- **TCP SYN 洪水** – 利用 TCP 协议的三次握手过程耗尽服务器资源，阻止合法流量到达服务器。
- **DNS** – 域名必须在云端环境中通过域名系统（DNS）转换为 IP 地址。DDoS 攻击会影响 DNS 基础设施，进而影响云服务的可达性。常见例子包括 DNS 查询洪水或 DNS 放大攻击，它们会使 DNS 服务器过载或耗尽资源。
- **ICMP 洪水** – 利用 Internet Control Message Protocol（ICMP）的漏洞，向目标网络或服务器发送大量数据包。
- **UDP 洪水** – 与体积型攻击类似，但针对 UDP 协议，UDP 常用于视频流、在线游戏等实时应用。

### 应用层洪水攻击

- **HTTP 洪水** – 大量 HTTP 请求导致 web 服务器过载。此类攻击常利用伪造技术（[Dong etal., 2019](#ch30.xhtml#ref30_5)）。
- **SIP 洪水攻击** – 当用于通信时，VoIP 使用 SIP 进行呼叫信令。SIP 电话可因信令消息过多而无法处理合法请求（[Dong etal., 2019](#ch30.xhtml#ref30_5)）。
- **反射/放大攻击** – 反射 DDoS（DRDoS）攻击在应用层使用 TCP、UDP 或二者组合（Kshirsagar etal., 2021）。攻击者向目标系统请求易受放大流量影响的服务器，导致目标系统因放大流量崩溃。TCP 类 DDoS 包括利用 Microsoft SQL Server（MSSQL）和简单服务发现协议（SSDP）的攻击；字符生成协议（CharGen）和简单文件传输协议（TFTP）则是 UDP 类攻击的例子（Kshirsagar etal., 2021）。
- **CGI 请求攻击** – 攻击者大量发送 CGI 请求，耗尽受害者计算机的 CPU 资源，导致其无法响应请求（[Dong etal., 2019](#ch30.xhtml#ref30_5)）。
- **Slowloris 攻击** – 利用 Web 服务器软件漏洞，发送大量慢速的 HTTP 请求，消耗服务器资源。
- **Fraggle 攻击** – 发送大量 UDP 流量到交换机的传输组织，类似于使用 ICMP 的 Smurf 攻击（[Mohmand etal., 2022](#ch30.xhtml#ref30_8)）。
