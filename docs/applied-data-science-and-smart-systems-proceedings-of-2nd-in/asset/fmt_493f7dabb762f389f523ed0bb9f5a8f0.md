## Related work

Many real-world images exhibit intensity heterogeneity. It’s widespread in medical images like X-rays and MRIs (MR) ([Vovk et al., 2007](#ch42.xhtml#ref42_30)). Radiofrequency coils or acquisition processes generate inhomogeneity un-MR images. The intensity of the same tissue changes with time. In CT and ultrasound pictures, non-uniform beam attenuation generates similar issues. A new RSF model ([Brox et al., 2009](#ch42.xhtml#ref42_31)) investigated the effect of intensity heterogeneity on segmentation. The RSF model makes use of locally fluctuating data that fluctuate geographically ([Zhi et al., 2015](#ch42.xhtml#ref42_16); [Koshki et al., 2021](#ch42.xhtml#ref42_14)). This is because the RSF model may effectively segment using local area information, namely the local intensity mean. Some recent suggestions deal with intensity inhomogeneity in the same way that the RSF model does. However, some approaches need setup, which limits their applicability.
