
The deep learning models are based on the large dataset processing. The tasks are hidden in the number of layers of network which is able to provide higher accuracy during the recognition process. Deep learning is a successor of machine learning, which includes multiple layers with learning algorithms. This allows the deep learning method to learn hierarchical features from the data. Therefore, deep learning has substituted the conventional feature extraction approach in several areas involving speech, computer vision, and natural language processing (Yin, Zhang, and Liu, 2021). The pre-trained models provide better accuracy than conventional methods, so researchers use these deep learning models in biometric areas. The researchers have brought deep learning into the biometric field, due to its strong capability with feature representation. The new network models and the pre-trained models are developed/tested on different datasets.

Deep learning methods were applied to finger veins for recognition. However, they did not provide good results because the system was trained and tested on non‑publicly available datasets (Radzi and Bakhteri, 2016; R. Arya et. al., 2021). While features were extracted from raw images, some information gets lost due to various factors. To improve robustness, the author applied a fully connected CNN model to recover the lost pattern of the finger vein and achieve good verification performance (Zoph and Le, 2017). CNN models are complex and not lightweight compared to other techniques. Researchers have developed lightweight models for vein recognition (Hong, Lee, and Park, 2017). Traditional image segmentation methods have been combined with CNN to improve recognition performance. Labels for vein pixel information were automatically assigned by the system. The CNN model was trained and tested to predict pixel information for finger veins. A special CNN module was developed to find missing pixels in segmented images (IEEE and IEEE, 2017). A CNN‑and‑supervised discrete hashing finger vein identification process was proposed to overcome the problem, decreasing template size up to 250 bytes and surging matching speed (P. [Sharma et al., 2018](#ch5.xhtml#ref5_30)). Outmoded finger vein identification methods can be cracked by hackers because the template used is plain data (Qin and El‑yacoubi, 2017). The author proposed FVR‑DLRP to secure revocable and efficient finger vein template generation. Most traditional finger vein recognition systems suffer from shading and misalignment issues. Extracting features from images is a complicated, complex process in deep CNN (Y. Liu et al., 2018). To improve these problems, researchers proposed a robust CNN model with an error rate of 0.396, collected on a high‑quality dataset (Hong, Lee, and Park, 2017). All publicly available finger vein datasets contain small image collections.

Although the CNN model used for finger veins achieved higher accuracy, it faces training‑process problems (W. Liu et al., 2017). The CNN model is successfully applied for finger vein identification (Simonyan, 2019). A lightweight convolutional neural network (CNN) was proposed to address small training‑dataset issues by using a similarity‑measure network (Qin and El‑yacoubi, 2018). A dense net was proposed for finger vein recognition (FVR), which removes noise from images and combines two or more images for recognition and feature extraction. The system has high computational cost (Song, Kim, and Park, 2019). Although all methods were tested on publicly available datasets, they still fail in practical use. A depth‑based separate CNN model was developed to overcome this problem; it is simple but has weaknesses in recognizing less‑defined image features (Tang et al., 2019). CNN‑CO was based on a local descriptor for pre‑training the ImageNet model. Practically, this system outperformed all conventional systems (Y. U. [Lu, 2019](#ch5.xhtml#ref5_22)). A finger‑vein‑based authentication model was proposed using a lightweight Siamese network; when images were collected, feature information was lost. GCNet and multi‑scale features were used to solve the problem. The system was tested on three publicly available datasets, but the feature extraction module needs improvement by adjusting CNN width and cardinality (Fang, Ma, and Li, 2023). Training and testing parameters are complex due to the hidden neural‑network structure. Although the result was 99.98 %, a lightweight model for FVR is needed (Wang and Shi, 2022). Double‑weighted group sparse representation classification was developed for FVR; it has lower accuracy than other models and takes a long time to solve the sparse coefficient because all training samples are based on a dictionary matrix. Optimization of dictionary selection is needed to improve performance (Fang et al., 2022). Finger vein recognition was performed using oval PDCNN, an advanced version of PDKs, which provided the best performance; the first ten layers came from MobileNet and the remaining layers from SqueezeNet, allowing the network to be compressed for higher performance ([Li et al., 2023](#ch5.xhtml#ref5_7)).

The CNN models have improved recognition performance for FVR, but this advancement requires enhancements to the feature extraction module and defense against security attacks; CNN models are not lightweight.

### Security of FVR system

In the present time, the security of each system is at major risk of losing information and digital assets protected by various security mechanisms. Certain considerations should be kept in mind before choosing bio‑information for any application to enhance security. First, all phases of technology used in the application must be safe regarding data privacy and protection. Although biometric technology faces various security attacks, it is considered a secure real‑world system.

### Template protection for finger vein

Template protection generates precise or related information from images via feature extraction (Kumar, 2019). This unique precise information distinguishes different individuals. The template scheme is divided into two categories: (a) Bio‑cryptosystem (Kaur, Kumar, and Singh, 2023), which combines cryptographic keying methods with biometric schemes; and (b) cancellable templates ([Manisha, 2020](#ch5.xhtml#ref5_25)). In this field, a person’s biometric template is distorted so the original data is unavailable to intruders while identity recognition remains possible. Template generation in CNN models for higher FVR accuracy can be performed (Yin, Zhang, and Liu, 2021). Template generation is shown in [Figure 5.2](#ch5.xhtml#fig5_2). Security for finger‑vein templates is provided by a password‑based key derivation function that derives the key named FVR‑DLRP. Even if the password is cracked, the information remains; however, this system has lower accuracy in terms of false‑acceptance rate (FAR), leading to FAR attacks and lower genuine‑acceptance rate (GAR) (Y. Liu et al., 2018).
