

# 计算机网络和网络设备

计算机网络是当今大多数企业的重要组成部分。无论该企业是小型家庭办公室还是跨国组织，计算机网络通常都能降低共享资源的成本和时间，并提高业务效率。了解计算机网络的运作方式对于理解如何保护此类网络环境至关重要。

在网络的语境下，术语[拓扑](#30_glossary.xhtml#gloss502)是指通信网络元素的顺序和排列。拓扑常被描述为：如果打开屋顶，你能清晰地看到下面所有的计算机和外设连接在一起，计算机网络看起来就会像那样。计算机和网络外设的连接方式决定了网络上可使用哪些通信方法、需要什么硬件，以及是否存在冗余。

显然，从屋顶俯视建筑物内部并不容易，但你可以创建网络图和网络拓扑图，帮助理解现有的连接和通信路径。这些图表是排查网络问题和故障的重要工具，因为你预期发现的情况与网络实际配置方式之间的差异，往往就是需要解决或纠正的问题。

在继续介绍配置网络的各种拓扑选项之前，先定义网络中常见的不同类型的设备和设施是合乎逻辑的，这有助于使网络拓扑更易于理解。

## 网络设备的类型

计算机和服务器（包括刀片服务器和专用计算机）通常位于网络上，但为了效率、隔离或安全，还有许多其他设备被使用。

[集线器](#30_glossary.xhtml#gloss227)是一种汇聚或收集其他计算机和设备的线缆及连接的设备。通常，一台服务器支持不止几台计算机，这将要求每台计算机单独连接到服务器。大多数服务器并未配备足够的单独端口来适应这种类型的连接。集线器只需收集单独的物理线缆，并提供一个到服务器的单一连接（**[图 3-1](#12_chapter03_02.xhtml#fig3-1)**），从而限制物理布线并简化连接。简单的汇聚集线器通常被视为[哑集线器](#30_glossary.xhtml#gloss150)或[无源集线器](#30_glossary.xhtml#gloss335)，因为盒子内部没有逻辑或电源——它只是线缆的汇聚点。

![FIGURE 3-1 A hub on a simple local area network.](Images/9781284183658_CH03_FIGF01.png)

**图 3-1** 简单局域网上的集线器。

[打线块](#30_glossary.xhtml#gloss382)，也称为[打线面板](#30_glossary.xhtml#gloss381)，是集线器的一个例子，尽管它的形状不像传统的无源集线器。集线器是开放系统互联（OSI）第 1 层（物理层）设备，因为它将线缆物理连接到一个设备中。集线器是不加区分的，由于设备的直通行为，会发生许多数据冲突。进入入站端口的流量会被发送到连接到该设备的所有其他端口，无论数据是否打算发往该端口和连接的设备，这会产生额外的流量并占用带宽。

另一种类型的集线器是[智能集线器](#30_glossary.xhtml#gloss465)或[有源集线器](#30_glossary.xhtml#gloss5)。这种集线器内置了一些智能。这是市场上最常见的集线器，并且通常在产品命名规范中不包含“智能”或“有源”。这些设备的其他常用术语包括[汇聚器](#30_glossary.xhtml#gloss95)和[中继器](#30_glossary.xhtml#gloss400)。使用这些术语是因为这种类型的集线器通常在信号进入设备时对其进行汇聚，并且可以在信号离开设备时通过中继过程增强信号。

历史上，智能集线器包含一些简单的管理软件，使网络管理员能够执行基本命令并获取关于网络性能的统计数据，例如吞吐量度量、正常运行时间百分比、路由表条目以及其他用于故障排除和基准测试的有价值信息。许多相同的度量可以从网络上的各种服务器和设备执行。然而，因为集线器是一个汇聚点，通常由用户执行的信息汇聚由智能集线器代为完成。

[中继器](#30_glossary.xhtml#gloss400)是一种集线器，它通过逐位过程重建接收到的信号。它不放大数据；而是重建数据以传递它。此功能是必要的，因为网络电缆的长线段或无线设备之间的距离，其自然结果是信号可能变弱或退化。中继器通过以更强的信号强度提供新重构的数据包来防止数据丢失，以便它能继续通过网络到达目的地。有源集线器延长了设备或网络段之间的可用距离。

[交换机](#30_glossary.xhtml#gloss487)是一种第 2 层（数据链路层）设备，它使用介质访问控制（MAC）地址来区分流量。典型的交换机如**[图 3-2](#12_chapter03_02.xhtml#fig3-2)**所示。MAC 地址是在联邦通信委员会（FCC）指导下由制造商分配的唯一硬件标识号。网络上的每个节点都有一个网络接口控制器（NIC），它拥有唯一的 MAC 地址。因为交换机通过查看 MAC 地址来确定每个数据包的去向，所以不会发生冲突；数据包仅发送给预期的目标（如果存在）。如果目标地址不存在，数据包将被丢弃。交换机通常用于大型网络。它们成为网络中的一个连接点，因为它们在发送数据包给预期接收设备时会切换到正确的端口。交换机可以执行一些错误检查并丢弃任何检测到错误的数据包。

![FIGURE 3-2 A switch. ¶ © Vtls/Shutterstock](Images/9781284183658_CH03_FIGF02.png)

**图 3-2** 交换机。 ¶ © Vtls/Shutterstock

交换机通过硬件提供网络分段。跨越交换机，临时专用的电子通信路径连接会话的端点（如客户端和服务器）。这种交换路径防止了冲突。此外，交换机允许你通过通信利用网络连接的全部潜在吞吐容量，而不是像集线器那样因冲突而浪费 40% 或更多。请参见**[图 3-3](#12_chapter03_02.xhtml#fig3-3)**。

![FIGURE 3-3 An example of switch deployment.](Images/9781284183658_CH03_FIGF03.png)

**图 3-3** 交换机部署示例。

一旦你检查此过程如何发生，就可以将交换机的这一基本功能视为一种安全优势。交换机在 OSI 模型的第 2 层，即数据链路层运行，MAC 地址在此定义和使用。交换机通过使用以太网帧中的源和目标 MAC 地址来管理流量。以太网帧是数据链路层（第 2 层）的一个逻辑数据集构造，由来自网络层（第 3 层）的有效载荷加上以太网帧头和帧尾组成（**[图 3-4](#12_chapter03_02.xhtml#fig3-4)**）。
