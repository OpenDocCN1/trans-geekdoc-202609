
# 核心安全目标

[机密性](#30_glossary.xhtml#gloss96)是指防止未经授权的访问，同时为授权用户提供无阻碍的资源访问。机密性确保数据不会被有意或无意地泄露给任何没有正当知情需求的人。职位描述定义了一个人的知情需求。如果一项任务不需要访问特定资源，则该人员不需要访问该资源的权限。

[完整性](#30_glossary.xhtml#gloss243)是指防止未经授权的更改，同时允许授权用户执行授权的更改。完整性确保数据在内部和外部都保持一致。一致的数据不会随时间改变，并与现实世界保持同步。完整性还可防止意外事故和黑客通过[恶意代码](#30_glossary.xhtml#gloss289)或带有恶意意图编写的软件进行的修改。

[可用性](#30_glossary.xhtml#gloss40)是指防止[停机](#30_glossary.xhtml#gloss148)、数据丢失和访问受阻，同时提供持续的正常运行时间、保护数据并支持授权用户访问资源。可用性确保用户能够及时访问适当的资源以完成工作。例如，可用性确保 Web 资源可访问，从而避免销售损失。

[认证](#30_glossary.xhtml#gloss35)是在授予对安全区域的访问权限之前，对用户身份进行的证明或验证。这可以发生在网络中，也可以发生在物理的现实世界中。虽然最常见的认证形式是密码，但密码可能会被意外共享或窃取，尤其是当被写下来时。多因素认证是大多数网络管理员首选的安全登录方法，因为它需要多重身份证明。

[授权](#30_glossary.xhtml#gloss39)是控制用户被允许和不被允许执行的操作。授权由组织的安全架构决定，该架构可能侧重于自主访问控制 (DAC)、强制访问控制 (MAC) 或基于角色的访问控制 (RBAC)。授权基于知情需求和用户的职位描述来限制访问。授权也称为[访问控制](#30_glossary.xhtml#gloss2)。

[不可抵赖性](#30_glossary.xhtml#gloss322)是一项安全原则，它防止用户否认曾执行过某项操作。例如，不可抵赖性可防止发送方否认曾发送过某条消息。公钥密码学通常提供不可抵赖性服务。

[隐私](#30_glossary.xhtml#gloss362)保护个人身份信息或敏感数据的机密性、完整性和可用性。私人数据可以包括财务记录或医疗信息。隐私防止对用户和员工进行未经授权的监视和监控。

维护和保护这些安全目标可能是一项挑战。与大多数困难任务一样，将安全分解为更简单或更小的组件将有助于您理解并最终实现这一目标。为了支持安全目标，您需要知道确切要保护什么。

## 您试图保护什么？

在安全领域，您想要保护的事物称为资产。[资产](#30_glossary.xhtml#gloss28)是指用于开展业务的任何事物。员工为完成任务所需的任何对象、计算机、程序、数据片段或其他逻辑或物理组件都是资产。

资产不必昂贵、复杂或庞大。事实上，许多资产成本相对较低、司空见惯且大小不一。但无论特性如何，资产都需要保护。无论出于何种原因，当资产不可用时，员工就无法完成工作。

对于大多数组织而言，无论大小，最关心的资产包括业务和个人数据。如果这些信息丢失、损坏或被盗，将导致严重后果。企业可能倒闭。个人可能遭受经济损失。身份可能被盗用。生活可能被毁。

是什么导致了这些问题？什么违反了网络安全？答案包括意外事故、无知和黑客。意外事故会发生，包括硬件故障和自然灾害。培训不足等于无知。即使初衷良好的员工，如果不了解正确程序或缺乏必要技能，也可能破坏系统。过度劳累和匆忙行事的人员会忽视可能导致资产泄露或丢失的问题。恶意黑客可针对网络发起攻击和[漏洞利用](#30_glossary.xhtml#gloss166)，意图获取访问权限或单纯造成破坏。

### 典型 IT 基础设施的七大域

IT 基础设施的任何方面都存在风险，也没有任何方面能免疫于黑客的审视。[风险](#30_glossary.xhtml#gloss410)是指威胁利用[漏洞](#30_glossary.xhtml#gloss539)的可能性。在设计和实施网络安全时，您需要分析典型 IT 基础设施的七个[域](#30_glossary.xhtml#gloss145)（**图 1-2**](#10_chapter01_02.xhtml#fig1-2)）中的每一个，以发现潜在的漏洞和弱点。安全措施必须详细、聚焦且详尽。您必须考虑每一种可能的攻击途径；评估风险；如果风险足够大，则应用[对策](#30_glossary.xhtml#gloss104)。未能做到这一点将为黑客留下一条开放路径。黑客只需发现您防线中的一处裂缝，就能开始瓦解整个网络的安全性。

典型 IT 基础设施的七大域各有独特的方面，需要安全改进。以下各节描述了与这七大域相关的重要基础网络安全问题。

#### 用户域

该域指实际用户，无论他们是员工、顾问、承包商还是其他第三方用户。任何访问和使用组织 IT 基础设施的用户，在被授予访问组织 IT 资源和基础设施的权限之前，必须阅读并签署可接受使用策略 (AUP)。该域还应关注培训、强认证、细粒度授权和详细审计。此外，添加到其他域的许多保护措施也为用户域提供了额外的保护，并防范来自用户域的威胁。

社会工程学是黑客针对人的攻击。这种攻击试图通过巧妙的措辞、撒谎、误导、关系操纵、恐惧、心理诡计和骗术来愚弄人们。社会工程学攻击的后果可能包括用户泄露私人信息，或在计算机上执行导致网络安全降低的操作。

#### 工作站域

该域指最终用户的桌面设备，如台式计算机、笔记本电脑、网络电话 (VoIP) 或其他终端设备。工作站设备通常需要安全对策，如防病毒、反间谍软件和漏洞软件补丁管理，以维护设备的完整性。

工作站、客户端或独立家庭系统都可能成为目标。这类主机通常比局域网服务器安全性更低。这并非有意为之，因为大多数安全措施侧重于基础设施的核心组件，而非那些看似处于边缘的组件。很多时候，工作站上的安全措施陈旧、过期，或安装和配置不当。系统加固、通信保护和工作站定位对安全至关重要。
