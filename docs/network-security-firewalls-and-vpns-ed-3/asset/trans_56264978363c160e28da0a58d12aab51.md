## 什么是网络安全？

[网络安全](#30_glossary.xhtml#gloss315)是对计算机网络上通信的不受欢迎的入侵、使用或破坏进行控制。这包括监控滥用行为、查找协议错误、阻止未经批准的传输，以及及时准确地响应问题。网络安全还关乎支持组织使命和目标所必需的基本通信、避免未经批准的资源使用，以及确保遍历网络的信息的完整性。

网络安全包含防止未经授权的访问和操作的要素，同时支持理想的活动，例如访问客户记录或管理库存。要高效、具有成本效益且透明地做到这一点很难。高效的网络安全为用户提供对[资源](#30_glossary.xhtml#gloss403)的快速便捷访问。具有成本效益的网络安全控制用户对资源和服务的访问，前提是风险足以证明控制成本的合理性。透明的网络安全通过强制执行组织的网络安全策略来支持组织的使命和目标，而不会给执行合法任务的有效用户带来不必要的步骤或延迟。

计算机网络技术的变革和改进速度比以往任何时候都快。无线连接现在已成为大多数组织和个人的现实选择。恶意黑客越来越擅长利用一切可用手段窃取身份、知识产权和金钱。

如今，许多组织在保护其资产上花费的时间、金钱和精力，比在网络初始安装期间还要多。[威胁](#30_glossary.xhtml#gloss499)（无论是内部还是外部）都可能导致灾难性的系统故障或妥协。此类安全漏洞甚至可能导致公司倒闭。没有网络安全，许多企业和个人将无法高效工作。

网络安全必须支持员工的工作，同时防范妥协、保持高性能并将成本降至最低。这极具挑战性；但通过适当的规划和执行，许多组织已成功完成了这项任务。

网络安全始于信任。

### 什么是信任？

[信任](#30_glossary.xhtml#gloss516)是你对他人将以你的最佳利益行事这一期望的信心。在计算机和网络中，信任是指相信其他用户将按照组织的安全规则、企业使命和愿景行事。你相信他们不会试图破坏网络及其资源的稳定性、隐私或完整性。信任是认为他人值得信赖的信念。

不幸的是，有时人们会违背你的信任。他们可能因意外、疏忽或不知情（甚至不知道存在这种期望）而这样做。在其他情况下，他们会故意违背信任。因为这些人可能是内部人员，也可能是外部黑客，所以很难知道该信任谁。

那么，如何回答“谁是值得信赖的？”这个问题呢？你首先要认识到信任是基于过去的经验和行为的。相互了解的人之间通常可以建立信任。信任陌生人既不容易也不合乎需要。然而，一旦你定义了一套规则且所有人都同意遵守这些规则，你就建立了有条件的信任。随着时间的推移，随着人们表现出他们愿意遵守规则并符合行为期望，你可以认为他们是值得信赖的。

信任也可以来自第三方方式。如果一个值得信赖的第三方了解各方实体，并声明双方都值得信赖，那么你就可以将有条件的信任扩展到各个实体。随着时间的推移，某人的行为会显示最初的有条件信任是否当之无愧。

归根结底，网络安全基于信任。组织假定其员工以及所有计算机和网络设备都是值得信赖的。但并非所有信任都一定相同。你可以（而且可能应该）在不同级别或层级的信任下运作。拥有较高信任级别的人员可被分配更大的权限和特权。在网络术语中，[权限](#30_glossary.xhtml#gloss341)是访问资产的授权，[特权](#30_glossary.xhtml#gloss366)是在网络上被授予的能力。如果有人或某物违背了你的信任，你就移除违规者对安全环境的访问。例如，组织会解雇不值得信赖的员工或更换有缺陷的操作系统。

第三方信任系统的一个常见例子是使用公共证书颁发机构颁发的数字证书。如**图 1-1**所示，用户与 Web 电子商务[服务器](#30_glossary.xhtml#gloss449)进行通信。用户最初不知道 Web 服务器是否真的是它声称的那样，或者是否有人正在“欺骗”其身份。一旦用户检查了证书颁发机构颁发给 Web 服务器的数字证书，用户就可以信任该网站的身份是有效的。之所以会发生这种情况，是因为用户和网站都有一个共同的、值得信赖的第三方，且双方都认识该第三方。

### 谁——或什么——是值得信赖的？

确定谁或什么是值得信赖的，是每个组织持续进行的活动，无论是全球性企业还是家庭家庭网络。在这两种情况下，你都有条件地向他人提供信任。这种有条件的信任会随着时间的推移而变化，基于是遵守还是违反了期望和规定的行为。

如果程序导致问题，它就会失去你的信任，你会将其从系统中移除。同样，如果用户违反安全规定，该人员就会失去你的信任，你可能会撤销其访问特权。当员工遵守规则时，你的信任会增加，如果因额外的工作职责或需求而必要，特权可能会增加。同样，当互联网站点未造成危害时，你会认为它值得信赖并允许访问该站点。

回顾一下，信任是主观的、暂时的，且会随时间变化。你可以基于第三方的声誉提供信任。当他人违反规则时，你会撤回信任。信任源于过去的行为，并可基于未来的行为而增长。

在网络安全中，信任是复杂的。在没有适当背景调查的情况下向员工延伸信任可能会造成毁灭性后果。网络的安全性取决于其最薄弱的环节。你需要审查网络的各个方面，包括软件、硬件、配置、通信模式、内容和用户，以维护网络安全。否则，你将无法实现组织的安全目标。

### 什么是安全目标？

[安全目标](#30_glossary.xhtml#gloss441)是组织通过其安全工作努力实现的目标。通常，组织认可三个主要安全目标：

*   机密性/隐私
*   完整性/不可抵赖性
*   可用性/正常运行时间
