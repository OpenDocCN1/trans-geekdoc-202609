
VPN 可以使用两种主要类型的封装加密。它们被称为隧道模式和传输模式加密。

隧道模式加密保护原始 IP 数据包的整个头部和有效载荷。加密后的数据包成为带有新 IP 头部的新 IP 数据包的有效载荷。这种加密形式确保了通信原始端点的身份在流量穿越安全链路时保持机密。隧道模式加密通常用于连接网络站点的 VPN 或提供安全远程访问的 VPN。

传输模式加密仅保护原始 IP 数据包的有效载荷。加密后的有效载荷保留其原始 IP 头部。这种加密形式仅保护有效载荷，而不保护端点的身份。传输模式加密有助于 VPN 将各个计算机连接在一起。

### 加密与 VPN 之间的关系

加密与安全 VPN 几乎是不可分割的。安全 VPN 之所以存在，是因为流量被加密了，但某些可信 VPN 可能使用加密，也可能不使用。要充分理解和领会 VPN 的运作，你需要对加密有合理的了解。

加密只是密码学这一更大主题的一个方面。[密码学](#30_glossary.xhtml#gloss107)是改变信息的艺术与科学，使其不易被未授权的第三方识别或理解。密码学通过一组互补且可逆的过程发生：加密和解密。加密是将称为明文的原始可用数据转换为称为[密文](#30_glossary.xhtml#gloss78)的不可用混乱形式的过程。[解密](#30_glossary.xhtml#gloss116)是将密文转换回明文的过程。安全通信产品必须同时提供加密和解密。

现代密码学基于算法。[算法](#30_glossary.xhtml#gloss12)是一组规则和过程，通常具有数学性质，用于定义加密和解密过程如何运作。算法通常非常复杂。许多算法是公开已知的，任何人都可以调查和分析算法的优势和劣势。

### 技术提示

不到 10 年前，64 位被认为是强加密。如今，128 位是可被视为强加密的最小对称密钥长度；在许多情况下，预期使用 256 位。密钥长度翻倍是否意味着比之前的密钥长度更强？实际上，虽然 128 位密钥的长度是 64 位密钥的两倍（即位数翻倍），但 128 位密钥创建的密钥空间远不止是 64 位密钥的两倍，256 位密钥也远不止是 128 位密钥的两倍。每当密钥长度的二进制数增加一位，可能的密钥空间大小就会翻倍。128 位密钥创建的密钥空间是 64 位密钥的 `2^64` 倍，即 `1.8 × 10^19` 倍。

加密算法使用密钥。加密密钥是一个唯一且秘密的数字，用于控制算法执行的加密和解密过程。密钥是一个非常大的二进制数，以其位长度来衡量或定义。密钥的位长度是组成密钥的二进制位数。例如，128 位的密钥长度为 128 个二进制位。

算法密钥的位长度定义了该算法的[密钥空间](#30_glossary.xhtml#gloss271)。密钥空间是可用于该特定算法的有效密钥范围。使用密钥长度特定二进制位数创建的任何密钥都是该算法密钥空间的一部分。此密钥空间包括从全零密钥到全一密钥之间的每一个数字（请记住，这是二进制代码，数字只有 0 和 1）。这意味着具有 128 位密钥长度的算法有 `2^128` 个可用密钥。`2^128` 的十进制形式超过 `3.4 × 10^38`。

在密码学领域内运作的算法主要有三种类型：对称、非对称和哈希。

#### 对称密码学

[对称密码学](#30_glossary.xhtml#gloss488)基于使用单个共享密钥的算法。记住对称密码学所用密钥类型的常用方法是记住“对称”的同义词：相同。加密和解密数据必须使用相同的密钥，并且该密钥必须与同一会话的所有通信伙伴共享。

与非对称密码学相比，对称密码学非常快，在相似的密钥长度和消息大小下，通常快 10,000 倍。一般来说，对称密钥的长度越长，产生的加密越强。大多数算法只有一个或少数几个密钥长度选项，因此选择具有较长密钥的算法通常能确保更强的加密。小于 128 位的密钥被认为较弱，128 到 256 位的密钥被认为较强，超过 256 位的密钥被认为非常强。这就是为什么当你选择对称密码学产品时，应该只使用采用 128 位或更长密钥的解决方案。

选择强算法不仅仅涉及密钥长度；你还需要考虑其他问题，例如随机数的使用、雪崩效应的使用以及对逆向工程攻击的抵抗力。随机数是指序列不易被假设或推导出模式的数字。[雪崩效应](#30_glossary.xhtml#gloss41)与哈希相关，指微小的变化在输出哈希中引起巨大的效应。大多数弱算法一旦公开发布就会被迅速破解，因此大多数消费者不需要过多关注算法的细节，而应寻找支持更长密钥的算法。一般规则（虽然略过了某些细节）是密钥越长越好。有关密码学、算法选择及算法内部工作原理的更多信息，请参阅《Schneier’s Cryptography Classics Library》或《Introduction to Modern Cryptography》。

### ![](Images/Note.png)注意

[带外通信](#30_glossary.xhtml#gloss331)是指通过不同的通道或方式进行通信。它也可以指发生在现有通信之外、时间上分离的通信流。为了成功进行密钥交换，此过程通常发生在使用该密钥的其余通信之前。

对称密码学提供的安全服务是机密性。具有合理长度密钥的对称加密可防止未授权的第三方访问或查看通信内容或存储的数据文件。对称密码学保护存储设备上的文件以及传输中的数据。事实上，由于其强度和效率，对称密码学是保护任何大小的存储数据或传输数据的首选方法。

对称密码学算法或系统的示例包括 `DES`、`3DES`、`AES`、`CAST`、`RC4`、`RC5`、`RC6`、`RC7`、`IDEA`、`Twofish` 和 `Blowfish`。
