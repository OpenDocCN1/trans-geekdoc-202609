
# 硬件故障与物理威胁

## 硬盘故障

导致意外停机最常见的原因之一是硬盘故障。硬盘是极少数具有移动部件的常见计算机组件之一。虽然光驱、磁带驱动器、鼠标和键盘也有移动部件，但这些设备的使用寿命似乎比硬盘长得多。硬盘故障可能毫无征兆地发生，也可能有合理的预警。预警通常表现为驱动器在开始故障时发出的研磨声、尖啸声或咔哒声。这些噪音清楚地表明设备的可用寿命即将结束，应立即更换。

针对硬盘故障以及硬件故障的最佳防御措施是做好准备。做好准备包括：定期进行一致的备份，最好使用独立磁盘冗余阵列（`RAID`）；执行常规清洁和维护；并备有备件以应对不可避免的故障。避免停机和可用性损失的另一种方法是在设备故障前更换设备。大多数设备都有[平均故障时间（MTTF）](#30_glossary.xhtml#gloss294)或[平均故障间隔时间（MTBF）](#30_glossary.xhtml#gloss293)，可用于确定故障的统计可能性。在该周期到期前更换设备是一种良好的做法。虽然您会在实际故障发生前很久就更换某些设备，但这种技术能让统计数据站在您这边。虽然计划内停机成本高昂，但它比计划外停机的成本要低。[固态硬盘（SSD）](#30_glossary.xhtml#gloss472)消除了与硬盘驱动器相关的许多问题，但硬件的初始成本更高。

## 热量威胁

另一个物理威胁是热量。过高的温度会损坏计算机设备。经历严重温度循环（如极热到极冷）的系统可能会发生芯片位移，或材料翘曲和开裂。[芯片位移](#30_glossary.xhtml#gloss76)是由温度变化导致金属膨胀和收缩引起的。严重的温度循环甚至可能断裂焊接连接。关于晚上或周末关闭计算机还是让设备保持运行状态的传统争论，涉及这些温度变化的影响。运行中的计算机处于其最佳工作温度。

## 静电放电与其他物理风险

干燥环境产生的[静电放电（SED）](#30_glossary.xhtml#gloss482)可破坏大多数电路。因摩擦尖锐金属边缘或粗糙表面（如混凝土砖墙）导致的电线磨损，可能引起短路。空气湿度过大或液体溢出导致的潮湿，对电气设备总是有害的。过度振动会损坏计算机设备。振动——由附近的大型施工、火车、地铁和飞机的定期经过，甚至车间或制造车间的叉车和大型设备引起——会随时间造成损坏。跌落设备、撞倒设备、重物砸在设备上等造成的任何明显物理损坏，都可能导致设备损坏。通过合理的预防措施、常识以及对电子设备的正确操作、保养和存储，可以消除或显著降低大多数物理风险和威胁。

## 故意电磁干扰 (IEMI)

其中一种风险是[故意电磁干扰（IEMI）](#30_glossary.xhtml#gloss244)，即通过故意放电损坏或摧毁电子设备，范围涵盖从手机、视频监控到计算机和服务器。记录显示 IEMI 放电距离可达两英里，且不会对生物造成损害。虽然 IEMI 和相关技术已被军方使用多年，但 IEMI 刚刚成为计算机安全的威胁。

## 盗窃

最后一个物理威胁是盗窃。物理设施防护应确保 IT 基础设施不受未经授权的外部人员（或内部人员）携带存储设备或其他关键组件离开的威胁。窃取设备的黑客可以花费任意长的时间尝试获取访问权限。

## 自然灾害

大自然力量强大且不可预测。各种严重天气事件都可能损坏或摧毁 IT 基础设施。了解您所在地区常见的严重天气类型将提示采取正确的预防措施，如特殊保险、结构加固、防雷保护、浪涌保护器、排水泵等。无论潜在灾害是什么，保护数据的最佳方式是将可靠的定期备份存储在安全的异地设施中。

## 意外事故

事故难免发生。只要有人为因素介入，事情就会出错。墨菲定律指出：“任何可能出错的事，终将出错。”为事故做好准备可以显著减轻其发生时的影响，或有助于避免事故。

IT 基础设施是一个庞大、复杂但脆弱的系统，完全掌握在人类手中。关键位置或关键时刻的意外损坏可能造成毁灭性后果。事故包括：液体洒在设备上、被线缆绊倒、拔错电源线或数据线、触发大楼断路器、触发水喷淋系统、撞倒计算机、过早关闭系统、安装错误驱动程序等。

针对事故的最佳预防和保护措施是备份、配置文档和培训。通过对员工活动进行一些常识性调整，更密切地关注其执行的活动，并留意不稳定的情况，可以避免许多“常见”事故。培训员工在事故或紧急情况下该怎么做，能显著增加成功恢复的几率。

# 恶意代码

恶意软件是恶意软件的简称。恶意软件是黑客编写的用于造成伤害和破坏的不道德代码。恶意软件通过无数种方式获取系统访问权限，通常未经用户同意或用户不知情。这种计算机污染物最常见的传播媒介是便携式存储设备和互联网通信，如电子邮件或社交媒体。存在各种各样的恶意软件，包括病毒、蠕虫、特洛伊木马、键盘记录器、间谍软件、广告软件、根套件、逻辑炸弹、陷阱门、后门、拨号器、URL 注入器和其他漏洞利用代码。独特恶意代码示例的数量令人震惊。最近对恶意软件攻击的研究估计，潜在的唯一[签名](#30_glossary.xhtml#gloss455)（用于检测和识别特定恶意软件的代码字符串，很像指纹）的数量高达数十亿。这比赛门铁克在不到 10 年前记录的 1700 多万个唯一签名有了巨大增长。

## 病毒

就像生物病毒一样，计算机[病毒](#30_glossary.xhtml#gloss535)需要一个宿主对象来感染。大多数病毒感染文件，如可执行文件、设备驱动程序、动态链接库（`DLL`）、系统文件；有时甚至感染文档、音频、视频和图像文件。某些病毒感染存储设备的引导扇区，包括硬盘和 USB 驱动器。病毒通过用户的操作传播。当用户打开受感染的文件时，病毒会传播到其他文件。当用户将受感染的文件发送到其他系统时，病毒也会随之传播。

## 蠕虫

与病毒从文件传播到文件不同，[蠕虫](#30_glossary.xhtml#gloss555)是从系统传播到系统。因为传播不需要人工交互，这些文件可以（并且确实）比病毒传播得快得多。如今，几乎所有被描述为病毒的威胁实际上都是蠕虫。黑客针对特定系统缺陷设计蠕虫。蠕虫扫描其他系统寻找此缺陷，然后利用该缺陷访问另一个受害系统。一旦寄生在另一个系统上，蠕虫通过重复该过程将自身传播开来。蠕虫在跨网络主机繁殖传播时，可作为载体投放其他形式的恶意代码。
