
# 防火墙堡垒主机操作系统与监控日志

防火墙设备的堡垒主机操作系统仅支持防火墙功能。ISP 连接设备的堡垒主机操作系统支持防火墙服务和连接服务。无线接入点的堡垒主机操作系统支持防火墙服务、有线连接服务、无线连接服务，以及可能的其他服务（如 `802.1x`）。

通用操作系统包括 `Windows`、`Linux`、`Mac OS`、`UNIX` 等。这些操作系统支持各种用途和功能，包括充当客户端或服务器主机操作系统。当用作堡垒主机操作系统时，每个系统都必须经过加固和锁定。否则，不安全的主机操作系统会使防火墙提供的安全性毫无价值。如果攻击者能使防火墙主机崩溃或绕过防火墙过滤，则防火墙无法提供有效的安全防护。

可以对通用操作系统进行合理加固以用作堡垒主机操作系统，但这需要具体且详细的修改。大多数软件防火墙产品都包含一份执行操作系统加固的指南，以提高堡垒主机的安全性，并减少可能导致防火墙被攻破的漏洞和后门。

某些防火墙包含预加固版本的通用操作系统作为堡垒主机操作系统。许多基于 `Linux` 的防火墙（如 `pfSense`）即属此类。

使用通用操作系统作为堡垒主机操作系统的好处是此类操作系统广泛可用。其中一些（主要是 `Linux` 变体）是免费的。此外，您可以利用现有的通用操作系统知识和技能来管理堡垒主机。但请记住，通用操作系统遭受攻击的范围更广，新漏洞利用的风险较高。

专有操作系统作为堡垒主机操作系统的优势在于已知攻击较少，未来漏洞利用的风险较低。然而，专有操作系统可能与环境中的其他操作系统有显著差异，可能要求系统管理员学习全新的系统，以便正确且安全地管理防火墙。此外，大多数专有操作系统仅在堡垒主机硬件上正式发布。这使得获取更加困难，且在大多数情况下成本更高（至少与免费开源替代方案相比）。

## 监控与日志记录

[监控](#30_glossary.xhtml#gloss304)和[日志记录](#30_glossary.xhtml#gloss283)是对发生在防火墙上或穿越防火墙的事件和流量进行观察和记录。理论上，您可以记录穿越防火墙的每个数据包；然而，这通常不切实际，因为所需的存储空间将非常巨大。某些产品可以维护记录流量的滑动窗口，利用数 TB 存储涵盖数小时的通信。然而，这些设备用于高级安全管理，超出了本章范围。

防火墙监控和日志记录旨在记录发生在防火墙上或穿越防火墙的事件（**图 7-6**）。您可以使用多种日志记录方法。您可以记录所有内容，也可以仅记录看似重要的事件。通常，您会随着时间推移通过实际经验微调日志记录。大多数安全专业人员建议初期捕获所有内容。稍后，在确定特定类型的信息、流量或事件不具备取证、证据或历史价值后，您可以调整日志记录并减少记录量。

防火墙日志记录可确保已定义的过滤器或规则充分且按预期运行。通过监控穿越防火墙过滤方案的流量，您可以发现防火墙本应阻止但因未定义有效规则（或规则定义不当）而放行的流量。

> **注意**
>
> 能够在滑动周期内记录所有流量的设备示例是 `Solera DS` 系列网络取证设备（归 `Symantec` 所有）。有关此类高级网络监控产品的更多信息，请访问 `Symantec` 网站：[https://www.symantec.com/products/network-forensics-security-analytics](https://www.symantec.com/products/network-forensics-security-analytics)。

通常，应记录防火墙允许的每个连接，以及每个被丢弃或阻止的数据包。这种“记录并监控一切”的立场可确保无事漏网，且未来对日志文件内容的调查将揭示完整数据。您稍后随时可以丢弃多余和不必要的数据，但无法恢复实际事件发生期间未记录的重要数据。

防火墙日志记录可以在防火墙上进行，也可以卸载到专用日志系统。无论哪种情况，防火墙都会收集您要记录的事件和/或数据包。区别在于信息是存入防火墙本地的日志文件，还是通过网络连接传输到专用日志服务器。

一个著名且广泛使用的[集中式日志系统](#30_glossary.xhtml#gloss72)是 `syslog`。[Syslog](#30_glossary.xhtml#gloss490) 是一种将日志消息从客户端设备（此处为防火墙）转发到集中式服务器的标准。`Linux` 和 `Unix` 系统已支持 `syslog` 功能数十年。`Windows 7` 之前的 `Windows` 系统需要第三方产品才能与 `syslog` 服务交互。大多数网络设备（包括防火墙、交换机、代理等）原生支持 `syslog`（即无需第三方介质即可使用）。

防火墙日志记录：

*   为流量和趋势分析以及增长预测创建活动历史记录
*   跟踪使用级别和时间，用于负载均衡、计费，甚至向用户回收费用
*   发现新的攻击方法或技术，尤其是基于网络数据包操纵的技术
*   检测入侵或安全突破尝试
*   创建可用于起诉的合法可采纳证据

防火墙记录所有事件的日志会产生大量记录信息。请始终跟踪可用剩余存储容量，以确保有足够空间存储新的记录事件。随着当前存储设备接近容量上限，请备份记录并将其移至长期归档存储。在未来的调查中，您永远不知道需要回溯多远才能发现安全漏洞的证据。您组织的书面保留策略应定义日志保留时长。

除了应对存储需求外，您还需要能够分析记录的数据。日志文件分析对大多数人来说通常不是一件令人兴奋的事情。它漫长而乏味，甚至令人费解地枯燥。幸运的是，不断发展的自动化分析工具领域可以减少日志文件调查的时间和负担。第一手知识、理解和经验始终是解读和理解防火墙日志内容的最佳工具。

渗透您的网络后，大多数经验丰富的黑客采取的最后步骤之一是清除其活动的所有证据。他们通常通过删除日志文件或使用专用工具对日志文件进行精准编辑来实现。例如，`SolarWinds Event Log Consolidator` 是一种编辑 `Windows` 日志文件的工具，它仅删除匹配关键字（如 IP 地址或用户名）的条目。为应对这一潜在威胁，请使用[一次写入多次读取 (WORM)](#30_glossary.xhtml#gloss557) 存储设备保存所有日志文件。采用 `WORM` 意味着日志可写入一次，随后可多次进行只读访问。入侵者无法编辑写入 `WORM` 设备的数据。
