

# 恶意软件类型详解

## 特洛伊木马

[特洛伊木马](#30_glossary.xhtml#gloss515)实际上是一种分发或投递机制，而非某种特定类型的恶意软件。在特洛伊战争期间，希腊人建造了一个巨大的中空木马；将战士藏在里面；把木马雕像送给特洛伊人；并假装离开该地区。特洛伊人将木马拖入城堡，当希腊战士从藏身处冲出时，他们在一夜之间遭到屠杀。该概念指嵌入在看似良性的载体或宿主程序中的恶意载荷，即用户想要的程序——如游戏或视频片段——并有意下载或复制。然后，当宿主程序运行游戏或视频片段时，恶意软件便被投递了。

特洛伊木马的诡计在于愚弄某人（一种社会工程学攻击），使其接受特洛伊木马程序为安全程序。通过在内部嵌入恶意软件，任何程序都可以被转换为特洛伊木马，就像通过添加有毒物质，任何食物都可以被毒害一样。事实上，黑客拥有专门设计用于构建特洛伊木马的工具，称为[封装器](#30_glossary.xhtml#gloss556)或特洛伊木马构建工具包。

## 键盘记录器

[键盘记录器](#30_glossary.xhtml#gloss272)记录用户的键盘活动。黑客可以通过多种技术（包括蠕虫或特洛伊木马）将软件键盘记录器植入受害者的系统。一旦系统被感染，键盘记录器会定期通过电子邮件、文件传输协议 (FTP) 或[即时通讯 (IM)](#30_glossary.xhtml#gloss240) 将按键日志传输给发起攻击的黑客。硬件键盘记录器攻击可通过键盘线缆实施。这些很难被检测到，因为设备非常小；虽然通常连接在键盘线缆上，但它通常位于桌面下方或计算机背后，用户通常不会去查看那些地方。

## 垃圾邮件与网络钓鱼

垃圾邮件常被用于实施[网络钓鱼](#30_glossary.xhtml#gloss343)攻击，邮件看起来合法或诱人，即使从未被请求过，导致接收者点击它，从而将恶意软件释放到他们的计算机系统中。

## 间谍软件

[间谍软件](#30_glossary.xhtml#gloss477)是键盘记录技术的进阶，用于监控和记录许多其他用户活动。间谍软件差异很大，但可以收集已启动应用程序列表、访问过的 URL、发送和接收的电子邮件、发送和接收的聊天记录、所有打开过的文件名、网络活动记录、定期屏幕截图，甚至麦克风录音或网络摄像头图像。

## 广告软件

[广告软件](#30_glossary.xhtml#gloss8)渗透广告。间谍软件和广告软件通常以共生方式关联在一起，因为从间谍软件了解到的目标信息有助于选择广告软件将推送给用户的材料。广告软件可以通过弹窗、电子邮件消息，或在浏览器显示网站时替换现有的合法广告来推送广告。

## Rootkit

[Rootkit](#30_glossary.xhtml#gloss418)是一种恶意伪装，充当黑客想要在计算机上隐藏的任何事物的隐形护盾。Rootkit 的作用类似于设备驱动程序，并将自身定位在内核（操作系统的核心程序）和硬件之间。从那里，Rootkit 可以选择性地隐藏存储设备上的文件，并使内存中的活动进程无法被操作系统查看、访问或检测到。Rootkit 隐藏其他形式的恶意软件或黑客工具，除了隐身能力外，还可以包含其他恶意软件功能。

## 逻辑炸弹

[逻辑炸弹](#30_glossary.xhtml#gloss284)是一种电子地雷。一旦黑客在系统中植入逻辑炸弹，它将保持休眠状态，直到触发事件发生。触发器可能是特定的时间和日期、程序的启动、特定关键字的输入，或访问特定的 URL。一旦触发发生，逻辑炸弹就会向毫无防备的用户释放其恶意事件。

## 后门/陷阱门

陷阱门和后门恶意软件是同一类恶意软件的两个术语。[后门](#30_glossary.xhtml#gloss42)或[陷阱门](#30_glossary.xhtml#gloss513)程序为黑客打开一条访问路径，以便轻松进入受损系统。后门恶意软件通常通过特洛伊木马方式投递。与勒索软件或蠕虫等恶意软件不同，特洛伊木马的恶意部分保持隐藏至关重要。该访问权限可能是创建一个黑客定义了凭据的新用户账户；一个流氓 Web、Telnet 或 Secure Shell (SSH) 服务器，赋予黑客远程命令提示符访问权限；或一个能完全远程控制受害者机器的来源（有时仅通过在 Windows 主机上开启远程桌面即可）。许多其他可能的陷阱门或后门操作都能授予外部黑客访问权限。

## 拨号器

[拨号器](#30_glossary.xhtml#gloss131)是一种流氓程序，可在预定义号码上自动拨号调制解调器。有时此过程会自动向受害者系统下载额外的恶意软件，或从受害者处上传窃取的数据。在其他情况下，拨号器会从受害者系统拨打付费电话号码，以产生巨额长途费。如果用户通常通过拨号链路连接互联网，拨号器可能会拨打流氓代理站点，而不是互联网服务提供商 (ISP)。该站点将充当中间人，随后窃听所有通信。

## URL 注入器

[URL 注入器](#30_glossary.xhtml#gloss529)替换 HTTP GET 请求中的 URL 为替代地址。这些被注入的 URL 会导致浏览器显示的网页与用户点击请求的网页不同。这些被替换的网页可能展示广告站点、产生流量以伪造搜索引擎优化 (SEO)，或导向欺骗性站点。

## 漏洞利用代码

漏洞利用代码是旨在利用编程、时序、通信或存储缺陷的任何形式的恶意软件。黑客通常将漏洞利用代码嵌入其他形式的恶意软件中，以协助感染和分发。漏洞利用代码也独立存在，通常作为黑客用于发动攻击、造成破坏和执行入侵的工具。

## 恶意软件传播与移动代码

恶意软件通过与合法、良性数据相同的通信通道传播。区别在于黑客设计恶意软件是为了造成困扰和破坏。恶意软件传播的一个不断增长的风险领域是移动代码。[移动代码](#30_glossary.xhtml#gloss300)是黑客编写的软件，旨在通过通信网络（如互联网和移动电话网络）轻松分发。黑客设计移动代码以下载到宿主，然后在宿主上执行。在移动代码的幌子下，恶意软件的传播速度比以往任何时候都快。普通大众——甚至 IT 专业人员——都需要提高警惕，采取适当预防措施，并使用反恶意软件应用程序。

## 高级持续性威胁

#### Advanced Persistent Threat

多年来，公众甚至许多知识渊博的安全专业人员习惯将每种类型的恶意软件都称为病毒。现在，将每种类型的恶意软件都称为[高级持续性威胁 (APT)](#30_glossary.xhtml#gloss7) 也变得同样普遍。尽管 APT 的发生率急剧增加，但它们仍只占攻击的一小部分。确实，APT 代表了下一代恶意软件，因为该威胁会悄无声息地驻留在目标机器上，直到被激活（因此称为“持续性”）。然而，APT 具有高度针对性，其目标情报通常从其他类型的攻动中获取，范围从网络钓鱼到社会工程学。历史上，大多数攻击都是机会主义攻击，寻找最薄弱的系统进行入侵：最容易得手的目标。随着我们看到从经济动机攻击向国家资助的间谍活动和黑客行动主义（即政治动机的黑客行为）转变，可以预见，我们将继续看到针对性攻击（如 APT）的增长。
