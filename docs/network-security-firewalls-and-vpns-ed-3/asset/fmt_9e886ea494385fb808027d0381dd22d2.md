# CHAPTER 1 ASSESSMENT

1.  Which of the following best describes the principle of least privilege?
    1.  Allow the user to have access to only the items on their payment plan
    2.  Allow the user to access items only during their normal scheduled work hours
    3.  Develop a patch only after the exploit has been discovered and publicized
    4.  Allow the user access to only what is essential for their job responsibilities

2.  Which of the following best describes the concept of risk?
    1.  The unsecured content on a network that may be used to gain access to the network
    2.  The surface that is exposed when a network is live that hackers can use for access
    3.  The solution that incorporates the best solution for a particular network
    4.  The likelihood that a threat will take advantage of vulnerability on the network

3.  What is the most important characteristic of an effective security goal?
    1.  It is inexpensive.
    2.  It is possible with currently deployed technologies.
    3.  It is written down.
    4.  It is approved by all personnel.

4.  Which of the following is true of network security?
    1.  Use of a framework ensures success in securing a network.
    2.  Network security includes elements preventing unwanted access and action.
    3.  It is easy to apply the latest fixes to any network setup.
    4.  Network security can often be ensured with no monetary outlay.

5.  What is the primary security concern with wireless connections?
    1.  Redundancy
    2.  Signal range
    3.  Support for IPv6
    4.  Connection speed

6.  What does Van Eck phreaking allow?
    1.  Attackers to encrypt the hard drive of a device until a ransom is paid
    2.  Submission of enough packets that a denial of service attack persists
    3.  Attackers to eavesdrop on electronic devices from a device
    4.  Limitation of access to any physical device on the network

7.  Which of the following best describes the concept of hardening?
    1.  The removal of items from the cloud to physical storage locations
    2.  The allowance of users to access networks through their own devices
    3.  The process of securing or locking down a host against threats and attacks
    4.  The removal of unnecessary software from workgroup computers and devices

8.  Which of the following best describes network availability?
    1.  Protection against unauthorized changes while allowing authorized changes
    2.  Protection against unnecessary costs while allowing reasonable expenditures
    3.  Protection against downtime while supporting authorized access to resources
    4.  Protection against unauthorized access while providing authorized access

9.  For what type of threat are there no current defenses?
    1.  Zero-day
    2.  Malicious code
    3.  Unauthorized software
    4.  Hardware failure

10.  Which of the following best describes nonrepudiation?
     1.  It prevents a user from being able to deny having performed an action.
     2.  It controls what users are allowed to do and not allowed to do.
     3.  It is proof of a user’s identity prior to granting access to a secured area.
     4.  It ensures that malicious code is not rampant on a corporate network.
