

### 技术提示

请牢记 `deny by default/allow by exception`（默认拒绝/例外允许）的安全立场。防火墙是一种过滤设备，有助于支持这一立场。

网络安全管理员使用“防火墙”一词来指代允许某些流量但拒绝其他流量的设备或服务。这与建筑物的防火墙不同，后者只有在防火墙失效时才允许火势蔓延。在网络安全中，防火墙允许被认为安全的流量通过——或者至少授权流量通过，而无需整个防火墙失效。此外，如果防火墙确实发生故障，它会进入一种称为 `fail-safe` 或 `fail-secure` 的安全状态。这意味着当防火墙离线、锁定或冻结，或以其他方式出现问题时，防火墙会停止所有流量，而不是允许所有流量通过。

网关是访问受控空间的入口或出口。网关很重要，因为通常有大量流量通过网关。因此，在网络网关处部署防火墙是安全设计的一个方面。如果网关已存在于网络基础设施中，那么在此处部署防火墙是显而易见的安全改进。如此部署的防火墙会拦截并验证跨越该网关点的所有流量。

防火墙常部署的其他位置包括位于前面（即公共互联网一侧）、后面（数据中心内部）或负载均衡系统中——它们通常被称为[负载均衡器](#30_glossary.xhtml#gloss279)。负载均衡器的命名相当贴切，因为这些设备的功能正是如此：它们接收进入一组服务器的负载，并根据各种因素确保负载在服务器之间或之中保持平衡。这是流量的汇聚点，是强制执行策略的理想位置，而这正是通过防火墙来完成的。

如果网络仍处于设计阶段，网络设计师可能会出于安全考虑，选择在网络布局中创建一个网关。然而，在这种情况下，该汇聚点被称为[瓶颈点](#30_glossary.xhtml#gloss77)，而不是网关。如果网关是访问其他资源区域的接入点，那么瓶颈点就是一种专门的网关，它将流量集中到单一的集中通道，以简化过滤过程。

你也可以将防火墙视为一种流量控制设备。网络安全的很大一部分只不过是控制流量。授权流量通过数字十字路口，而未经授权、不需要的、异常的或明显恶意的流量被阻断。知道如何区分流量的差异通常很困难，需要你依赖精心设计的规则。

现代防火墙最基本和最初的形式是[筛选路由器](#30_glossary.xhtml#gloss431)。路由器根据目标地址分析流量。通往目标的最佳可用路由决定了转发决策。然而，筛选路由器增加了额外的规则，可根据目标或源地址丢弃流量。一旦过滤扩展到地址协议甚至端口，筛选路由器就成为了基本的静态包过滤防火墙。

除了防火墙之外，[透明代理](#30_glossary.xhtml#gloss509)（也称为[直通代理](#30_glossary.xhtml#gloss238））还可以协助过滤来自网络外部的请求。透明代理通常安装在防火墙（防范互联网入侵）和 Web 服务器之间。代理是代表其他事物的事物。在这种情况下，它是一台服务器，代表 Web 服务器并初始表现得就像是 Web 服务器本身。当针对 Web 服务器的请求进来时，如果符合防火墙规则，就会传递给代理。收到请求后，Web 服务器代理要么处理该请求，要么将请求传递给实际的 Web 服务器。这在 Web 服务器和网络其余部分之间提供了一个缓冲区。

除了过滤功能，防火墙还可以提供路由功能，这是从其路由器血统中继承下来的。多宿主防火墙可以根据过滤结果，授予流量访问一个或另一个接口或[段](#30_glossary.xhtml#gloss446)的权限。私有局域网（LAN）的流量可以遍历一个段，而目标为非军事区（DMZ）的流量可以遵循另一个段（参见[图 5-1](#15_chapter05_01.xhtml#fig5-1)）。防火墙是你网络这条高速公路上高效、必要的交通控制设备。

防火墙的关键功能是保护你的网络免受外部攻击。计算机网络的某些威胁被称为病毒并非偶然；外部威胁似乎在不断变化和演变。一些攻击专门针对你的网络或组织。其他攻击则是无目标的、随机的。相反，这些攻击针对的是恰好具有特定漏洞的任何主机。恶意代码持续感染并攻破无防护的计算机系统。洪水攻击试图中断及时的互联网通信。这些只是你组织网络面临的外部威胁中的一部分。

无论将其标记为资源访问的网关，还是控制安全的瓶颈点，结果都是一样的。部署在网关处的防火墙为所有流量提供过滤服务。瓶颈点为资源提供经过过滤的访问。正如一位睿智的诗人曾说：“好篱笆造就好邻居。”同样，良好的网关和位置得当的防火墙造就安全的网络。

理解这些定义和区别只是理解防火墙的开始。

#### 防火墙无法做到的事

如果使用得当，防火墙能为外部威胁提供可靠且一致的安全防护。然而，防火墙有其局限性，只是完整安全策略的一部分。仅靠防火墙本身，无法保护网络免受所有威胁。

防火墙是网络安全的重要组成部分，但它不是网络安全的全部。不要犯下部署了防火墙却忽视其他安全管理活动的错误。防火墙只是解决网络安全这个大型复杂拼图中的一块。防火墙无法包揽一切。

##### 认证服务器

防火墙主要用于网络流量过滤。它不是认证系统。防火墙的设计初衷不是检查登录凭据、比对生物识别扫描，甚至不是确认数字证书的有效性。这些是认证服务的功能，通常托管在域控制器或主网络服务器上。

话虽如此，你可能会发现有必要让防火墙在授予资源访问权限或允许会话之前进行认证。某些防火墙可以具有提供防火墙托管认证服务的增强功能。然而，在许多情况下，更好的解决方案是让防火墙将该任务卸载给专用的认证服务器或服务，例如 [802.1x](#30_glossary.xhtml#gloss1)、[公钥基础设施 (PKI)](#30_glossary.xhtml#gloss379) 或目录服务。大多数安全专家不建议使用防火墙来认证用户，或者至少不建议将其作为网络目录服务或集中式认证解决方案的替代品。
