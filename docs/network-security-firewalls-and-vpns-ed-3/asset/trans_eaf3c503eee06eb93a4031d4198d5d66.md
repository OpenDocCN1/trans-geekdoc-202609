

# 加密货币与黑客动机

## 勒索软件中的加密货币

加密货币是一种电子货币，其存在形式是存储在参与者系统上的数学公式，汇率会波动。黑客会将赎金要求列为“4 个比特币”或其他金额，受害者则按当前汇率购买加密货币。如果黑客想要惩罚受害者或纠正自认为的不公，有些赎金会通过向慈善组织捐款的方式支付。

## 黑客动机

### 挑战与技能提升

对许多黑客而言，寻找新漏洞、开发新攻击代码或发现新的安全漏洞是一项令人兴奋的挑战。[漏洞](#30_glossary.xhtml#gloss56)是指任何成功绕过网络防御的尝试，例如“突破”边界。一些黑客攻击目标的原因，正如一些人攀登高山——因为它就在那里，因为他们能做到，因为他们想征服它。一些黑客不断寻找更新、更困难的目标，以提升技能并增加挑战难度。

### 权力与支配

展示攻破目标的能力，尤其是当目标具有相当安全性时，是黑客证明自己比防御者更强大的一种方式。如果你能控制某样东西，你就拥有对它的权力。如果黑客能远程控制你的计算机，那么黑客就拥有对你计算机的权力；在某些方面，黑客也拥有对你的权力。黑客有时进行黑客攻击是为了提升形象、满足自我。如果他们能发动成功的攻击，就是在展示对目标的支配力。

### 刺激与风险

黑客攻击可以带来刺激感。想象一下寻宝者在别人私有领地上的感受。权力、挑战、风险和潜在的追捕，加上发现潜在有价值资产的组合，对某些黑客来说是一种刺激。逃脱惩罚的快感激励许多黑客在弄清如何成功入侵网络后继续发动攻击。

一些黑客享受攻击网络的纯粹风险。与任何犯罪一样，被抓获的风险始终存在。目标网络可能部署了[蜜罐](#30_glossary.xhtml#gloss218)、入侵检测系统 (IDS)、入侵防御系统 (IPS)、防火墙和其他技术防御，黑客需要探测并规避这些防御。安全专业人员时刻致力于发现新的攻击技术并识别黑客身份。因此，每一次攻击都让黑客面临被抓获和起诉的风险。

### 无聊与娱乐

一些黑客诉诸黑客攻击，试图寻求娱乐或摆脱无聊。一次成功的系统入侵通常会引发响应，往往是一场有趣的“猫鼠游戏”。针对勒索软件攻击，黑客还处于强势地位：受害者必须遵从黑客的要求，否则无法恢复访问权限。

### 同伴压力与地位

黑客和其他人一样，也有同伴和社交群体。同伴压力可能成为融入群体、炫耀或向群体展示忠诚的强大动力，尤其是对于处于黑客社区低层或低等级的人员。新手或缺乏经验的黑客会感到受到鼓励去实施攻击，以维持其在同伴群体中的成员资格。一些攻击是作为入会仪式或成人礼，让潜在的黑客组织成员成为正式成员。黑客攻击可以帮助黑客获得或维持地位。一些黑客试图制造媒体新闻，让自己的名字出现在新闻中。其他攻击则是为了在当前和未来的目标中植入恐惧并强迫其顺从。

### 黑客行动主义

认为某公司不是良好的本地或全球公民的黑客可能会实施[黑客行动主义](#30_glossary.xhtml#gloss202)，即通过黑客手段纠正社会不公，或为该公司或特定个人自认为的错误进行报复。这类黑客可能会窃取数据，但通常会将经济利益捐赠给被认为值得的事业，或致力于纠正引发黑客行为的错误的事业。这类黑客更难抓捕，因为资金通常会立即转给第三方非营利组织，而该组织并不雇佣或赞助黑客。没有“顺藤摸瓜”追踪资金的机会来抓捕个人，这与黑客保留黑客所得的情况不同。

## 黑客类型

黑客主要分为三类：娱乐型、机会型和专业型：

### 娱乐型黑客

[娱乐型黑客](#30_glossary.xhtml#gloss387)是那些喜欢学习和探索的人，尤其是在计算技术方面。然而，他们可能会在何时使用新获得的技能上做出错误选择。将未经批准的软件从家里带入公司、在公司网络上进行实验，或仅仅是尝试一个漏洞利用代码看看是否有效，这些都是娱乐型黑客的潜在行为。一些黑客可能没有充分考虑到他们的爱好可能带来危险，且其行为可能违反公司安全策略。例如，[脚本小子](#30_glossary.xhtml#gloss432)是依赖他人编写的预存程序或代码的黑客。这类黑客只需指点点击工具即可运行脚本，可能并不完全理解这些行为的后果。

### 机会型黑客

[机会型黑客](#30_glossary.xhtml#gloss328)胆小谨慎，不太可能主动发起攻击。无论出于何种原因，他们都不愿刻意策划和发动入侵。然而，如果出现了可以轻松实施且极少有被发现或承担后果风险的攻击机会，机会型黑客可能会利用这个稍纵即逝的良机。此时可能是某人碰巧加班，成为大楼里最后一名员工。机会可能是消防演习将其他人都赶出了设施，或随机停电导致半数员工回家。甚至可能只是因为他们注意到某个办公室的门开着，且无人看管。

### 专业型黑客

[专业型黑客](#30_glossary.xhtml#gloss368)是以攻破 IT 基础设施为唯一职业目标的罪犯。无论是作为个人运营、提供雇佣黑客服务、作为犯罪组织成员运作，还是进行国家资助的攻击，专业黑客都将时间和精力集中在实施最佳安全攻击上。当人们花费数年时间在一个主要领域学习和实践时，他们能开发出足以匹敌所有防御的专业知识和技能。完美的不可攻破安全解决方案不存在。专业黑客拥有时间、耐力、技能、耐心和后盾，能持续对目标发动攻击直到成功。他们对网络的威胁，正如白蚁对木质建筑。你可以威慑它们；大多数时间能将它们挡在外面。但它们始终在附近伺机而动，一旦你松懈片刻，就会啃噬地基。

## 结论

黑客实施攻击的原因多种多样，此列表可能并不详尽。无论其动机如何，他们都被驱使去从事不道德的活动。你可能无法完全理解黑客的心态，但尝试理解很重要，这样你才能更好地预判黑客可能如何攻击你的网络。

# 黑客青睐的目标

在安全领域，你想要保护的东西称为资产。资产是指用于通过计算机网络开展业务的任何事物。员工完成任务所需的任何对象、计算机、程序、数据片段或其他逻辑或物理组件都是资产。

攻击者最常针对哪些有价值的资产？每个黑客都不同，就像任何亚文化中的个体成员一样。虽然许多人认同什么是有价值的，例如金钱和访问权限，但其他人可能更倾向于将公司财务、秘密配方、病历、信用报告、法庭记录、会计日志等作为其首选目标。例如，为什么有些人收集玩具，而其他人收集汽车、汽水瓶或打扑克的狗的图片？
