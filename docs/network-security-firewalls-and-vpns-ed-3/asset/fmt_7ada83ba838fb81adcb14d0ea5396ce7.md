
# 术语表

## S

### 单因素认证
仅使用单一验证要素来证明主体身份。被认为比多因素认证弱得多。

### 单次损失期望值 (SLE)
针对特定资产和特定威胁，单次事件的损失潜力计算。SLE 计算是风险评估的一部分。`SLE = AV × EF`。

### 单点故障
系统或网络基础设施中作为流程发生的主要或唯一路径的任何要素。此类要素受损可能导致系统故障。网络设计应通过引入冗余和纵深防御来避免单点故障。

### 单点登录 (SSO)
一种网络安全服务，允许用户通过单次客户端登录过程对整个域进行认证。所有域成员均接受此单一认证。本地授权用于控制对单个资源的访问。由于不需要为每个单独的服务器进行多次登录，这种单一认证可以更复杂。

### 站点到站点 VPN
用于连接网络的 VPN。也称为 LAN-to-LAN VPN 和 WAN VPN。

### 磁盘松散空间
分配给已存储文件的最后一个簇中未使用的部分。它可能包含先前存储在该位置的文件残留。黑客可劫持松散空间以创建隐藏存储区。

### 演示软件
行业术语，指在供应商的 PowerPoint 幻灯片中出现，但尚未在其任何产品中提供的产品；有时也称为“蒸汽软件”。

### 智能集线器
*参见* 有源集线器

### 嗅探器
一种捕获网络通信以进行调查和分析的软件工具或硬件设备。也称为包分析器、网络分析器和协议分析器。

### 社会工程学
通过操纵人员执行任务或泄露违反安全规定的信息的技艺。社会工程学依赖于讲述令人信服的谎言来操纵人员，或利用受害者乐于助人的心理。

### 套接字
IP 地址与端口号的组合，作为完整地址。

### 软件防火墙
安装在客户端或服务器上的主机防火墙。

### 软件 VPN
由软件而非硬件构建的 VPN。软件 VPN 可能是操作系统的一项功能，也可能是第三方应用程序。

### SOHO (小型办公室/家庭办公室)
由小型企业、家庭企业或仅仅是家庭网络部署的任何小型网络、工作组或客户端/服务器。

### 固态硬盘 (SSD)
一种通过移动和恢复驱动器上的数据，消除了与磁性驱动器相关的许多问题的驱动器。

### 源路由网桥
一种网桥类型，其路由基于发现帧的使用，该帧遍历网络以确定到达目的地的可能路径。

### 垃圾邮件
不需要且通常未经请求的消息。垃圾邮件在技术上不属于恶意软件，但通过巨大的数量可能对 IT 基础设施产生严重的负面影响。估计各异，但垃圾邮件可能占所有电子邮件的 95%（这意味着每封合法邮件对应多达 19 封无关的垃圾邮件）。

### 分隧道
一种 VPN 连接，允许在同一连接上同时访问安全的 VPN 链路和非安全的互联网访问。

### 欺骗
信息的伪造。欺骗通常是试图隐藏用户的真实身份或通信的真实来源。

### 间谍软件
键盘记录技术的进阶，用于监控和记录许多其他用户活动。间谍软件差异很大，但它可以收集已启动应用程序列表、访问的 URL、发送和接收的电子邮件、发送和接收的聊天记录、所有打开文件的名称。它还可以记录网络活动、定期捕获屏幕截图，甚至录制麦克风或摄像头的内容。可与广告软件关联。

### SQL 注入
一种网站/应用程序攻击形式，黑客提交 SQL 表达式以导致认证绕过、数据提取、信息植入或访问命令 Shell。

### 星型拓扑
一种网络布局，每个设备都有独立的电缆连接。

### 状态
客户端与资源服务器之间的逻辑连接。可能存在于 OSI 模型的第 3、4 或 5 层。也称为会话或电路。

### 状态检测
自动跟踪会话或状态以允许入站响应先前出站请求的过程。也称为动态包过滤。

### 静电放电 (SED)
一种突发的、瞬时的电流，通常具有高电压和低电流，在两个物体之间流动。通常由低湿度环境引起。人体、聚酯和塑料容易积累静电。SED 可能损坏大多数计算机组件。

### 静态 NAT
跨 NAT 服务的静态编码转换路径。也称为端口转发和反向代理。

### 静态包过滤
使用静态或固定规则集过滤网络流量的方法。规则可侧重于源或目的 IP 地址、源或目的端口号、IP 头协议字段值、ICMP 类型、分片标志和 IP 选项。因此静态包过滤主要关注网络层（第 3 层），但也可包含传输层（第 4 层）要素。静态包过滤关注头部内容，不检查数据包或段的负载。

### 子网划分
一种逻辑网络技术，将 IP 地址分解为更小的子集，从而扩展可用 IP 地址池或允许网络分段。

### 沉没成本
已在项目、事件或设备上花费的时间、金钱和精力。在经济学中，沉没成本与未来决策无关。但在情感上，人们常以沉没成本作为继续失败流程或程序的合理化理由。

### 交换机
一种通过硬件提供网络分段的设备。在交换机上，会在会话端点（如客户端和服务器）之间创建临时专用电子通信路径。这种交换路径可防止冲突。此外，交换机允许通信利用网络连接的全部潜在吞吐容量，而不是像集线器那样因冲突浪费 40% 或更多带宽。

### 对称密码学
基于使用单一共享密钥算法的密码学。相同的密钥用于加密和解密数据，且同一会话的所有通信伙伴必须共享相同的密钥。

### 同步动态随机存取存储器 (SDRAM)
具有同步接口的动态随机存取存储器 (DRAM)。传统上，DRAM 具有异步接口，意味着它尽可能快地响应控制输入的变化。SDRAM 具有同步接口，意味着它在响应控制输入前等待时钟信号，因此与计算机的系统总线同步。

### Syslog
一种将消息从客户端设备转发到集中式服务器的标准。

### 系统网络架构 (SNA)
IBM 开发的一种遗留网络协议，常用于支持大型机之间的通信。大多已被 TCP/IP 取代。

## T

### 有形成本与价值
直接与预算资金相关的成本或价值。可包括但不限于：采购、许可、维护、管理、行政、支持、公用事业、培训、故障排除、硬件、软件、更新/升级等。

### 电信公司
电信公司或企业的简称。用于指代销售或租赁 WAN 连接服务的任何公司，无论有线还是无线。

### 远程办公
从家庭、远程或移动位置工作，同时连接到雇主的私有网络的行为，通常使用 VPN。
