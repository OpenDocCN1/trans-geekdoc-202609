# 第 1 章 评估

1.  以下哪项最能描述最小权限原则？
    1.  允许用户仅访问其付费计划上的项目
    2.  允许用户仅在其正常预定工作时间内访问项目
    3.  仅在漏洞利用被发现并公开后才开发补丁
    4.  允许用户仅访问其工作职责所必需的内容

2.  以下哪项最能描述风险的概念？
    1.  网络上未受保护的内容，可能被用于获取网络访问权限
    2.  网络上线时暴露的攻击面，黑客可利用其进行访问
    3.  结合了特定网络最佳解决方案的解决方案
    4.  威胁利用网络上漏洞的可能性

3.  有效安全目标最重要的特征是什么？
    1.  成本低廉。
    2.  可用当前部署的技术实现。
    3.  书面记录下来。
    4.  经所有人员批准。

4.  以下关于网络安全的陈述哪项是正确的？
    1.  使用框架可确保网络安全防护成功。
    2.  网络安全包含防止未经授权的访问和操作的要素。
    3.  将最新修复程序应用到任何网络设置中很容易。
    4.  网络安全通常无需资金投入即可保障。

5.  无线连接的主要安全顾虑是什么？
    1.  冗余
    2.  信号范围
    3.  对 IPv6 的支持
    4.  连接速度

6.  Van Eck 窃听允许什么？
    1.  攻击者加密设备的硬盘，直到支付赎金为止
    2.  提交足够多的数据包，使拒绝服务攻击持续存在
    3.  攻击者从一台设备上窃听电子设备
    4.  限制对网络上任何物理设备的访问

7.  以下哪项最能描述加固的概念？
    1.  将项目从云端移除至物理存储位置
    2.  允许用户通过自己的设备访问网络
    3.  保护或锁定主机以抵御威胁和攻击的过程
    4.  从工作组计算机和设备中移除不必要的软件

8.  以下哪项最能描述网络可用性？
    1.  防止未经授权的更改，同时允许授权更改
    2.  防止不必要的成本，同时允许合理的支出
    3.  防止停机，同时支持对资源的授权访问
    4.  防止未经授权的访问，同时提供授权访问

9.  对哪类威胁目前没有防御措施？
    1.  零日
    2.  恶意代码
    3.  未经授权的软件
    4.  硬件故障

10. 以下哪项最能描述不可否认性？
     1.  它防止用户否认曾执行过某项操作。
     2.  它控制用户被允许做什么和不被允许做什么。
     3.  它是在授予用户进入安全区域访问权限前对用户身份的证明。
     4.  它确保恶意代码不在企业网络上泛滥。
