

# 网络拓扑

## 环形拓扑

[环形拓扑](#30_glossary.xhtml#gloss409)使用一种闭合的布线方案；也就是说，它将电缆/网络的一端连接到另一端以形成一个环（参见[**图 3-10**](#12_chapter03_03.xhtml#fig3-10)）。每台计算机或设备连接到两个设备，每侧各一个。这种拓扑需要一种称为[令牌](#30_glossary.xhtml#gloss501)的特殊数据包，类似于童年游戏中的“接力棒”，只有持有接力棒的人才能通信。令牌的使用是这种拓扑常被称为“令牌环”的原因。因为这种网络方案使用令牌来控制对网络电缆的访问以进行通信和传输，所以它比其他物理拓扑遇到的数据冲突问题更少；然而，当网络上的多个设备尝试同时通信时，它仍然会经历速度变慢的情况。当网络上有大量节点时，环形网络通常使用中继器。

![图 3-10 环形拓扑。](Images/9781284183658_CH03_FIGF10.png)

**图 3-10** 环形拓扑。

如果环形网络是[单向的](#30_glossary.xhtml#gloss523)，这意味着令牌仅沿环单向移动，则可能会出现延迟。在令牌按顺序移动到环上的下一个设备之前，网络上的每台计算机和设备都会被轮询（询问或查询）是否有数据包要发送。

[双向](#30_glossary.xhtml#gloss49)环要求每个设备有两个连接，并提供单向令牌环网络中不可用的冗余。这种类型的环为令牌在任一方向上移动提供了完整的布线设置。这意味着它实际上不是一个双向环；它是两个独立的环，每个环朝不同的方向。

本质上，环形网络在相反方向上实现了两次。由于增加了第二个网络，等待时间不一定减半，但它比单环是一个更快的通信系统。成本是许多类型环形网络的阻碍因素，故障排除更加复杂，因为管理员必须首先确定哪个网络正在经历问题。

双向环的优点包括由于整个网络的复制而带来的冗余。然而，如果一台计算机宕机，整个网络有可能在两个方向上都宕机。由于跨两个环网络的负载均衡，速度潜在地得到了改善，但如果网络处于满负荷状态，用户仍然会感觉缓慢。令牌在每个网络上也不是直接相对的。令牌通过轮询过程工作。轮询每个设备以确定是否有通信数据包要跨网络发送。如果没有，令牌移动到环中的下一个设备。如果有数据包要发送，该设备发送这些数据包，然后令牌按顺序移动到下一个设备。根据发送的数据量，系统运行速度可能比预期慢。

## 星形拓扑

[星形拓扑](#30_glossary.xhtml#gloss479)（如[**图 3-11**](#12_chapter03_03.xhtml#fig3-11)所示）提供了一层总线或环形拓扑中不存在的性能保护。网络设计为每个设备提供一根独立的电缆。这种配置通常比总线或环形拓扑使用更多的布线，但它受益于每个布线段的独占使用。如果一个段被破坏，通常不会导致整个网络瘫痪。因为通往每个设备的电缆与其他设备隔离，所以它提供了针对元件损坏的冗余。但它并不为所有设备提供完全冗余，因为受影响的设备在问题解决之前将无法连接到网络。

![图 3-11 星形拓扑。](Images/9781284183658_CH03_FIGF11.png)

**图 3-11** 星形拓扑。

这种设计的常见视觉形象是一个圆圈，从中心向四周设备发出线条。这使得图像类似于车轮的辐条或派的轮廓切片。在应用中，“辐条”不需要延伸到所有侧面。常见的形状更像乌贼，服务器和集线器在顶部，触须状的电缆垂下到每个设备。无论哪种方式，中央“集线器”和通往每个设备的隔离电缆的存在都标识了该拓扑，即使物理设计与星号几乎没有相似之处。星形拓扑比总线拓扑更具容错性，因为每根有线线路的独立性允许一个或多个设备失去连接；其余设备保持与网络其余部分的连接。

## 网状拓扑

[网状拓扑](#30_glossary.xhtml#gloss296)是有线拓扑中冗余性最高的，因为该设计为设备提供隔离，并在网络段不再运行以允许通信时提供冗余。网状拓扑可以以两种形式实施：全连接和部分连接。在全连接网状网络中（[**图 3-12**](#12_chapter03_03.xhtml#fig3-12)），所有设备都连接到所有其他设备。这基本上意味着网络上的每个设备前面都有一个集线器来促进和简化连接。

![图 3-12 全网状拓扑。](Images/9781284183658_CH03_FIGF12.png)

**图 3-12** 全网状拓扑。

一种更常见且成本较低的方法是部分连接网状网络（[**图 3-13**](#12_chapter03_03.xhtml#fig3-13)），其中所有高需求、资源密集型设备具有冗余连接，但并非每个设备都连接到每个其他设备。在这种网状拓扑的应用中，每个区域的所有服务器和主系统都有冗余。例如，在一所提供在线课程的学校中，主服务器之间将具有冗余线路，托管在线课堂环境的在线学习管理系统（LMS）将连接到其他几个服务器和设备。如果一条通往互联网的路径不可访问，将会有其他路径，因此课堂环境仍可供学生使用。这在企业的关键任务领域和军事中很常见，因为通信对生存至关重要。

![图 3-13 部分网状拓扑与全网状拓扑的对比。](Images/9781284183658_CH03_FIGF13.png)

**图 3-13** 部分网状拓扑与全网状拓扑的对比。

## 无线拓扑

[无线拓扑](#30_glossary.xhtml#gloss553)有点名不副实。在无线安装中，几乎没有电线，因为设备使用空气作为通信数据包交换的介质。某些区域可能存在一些布线，这些区域需要额外的冗余，以便有线和无线在一种方法无法正常工作时提供替代方案。无线网络拓扑中至少有一个无线路由器。这是允许互连和访问互联网的连接点。参见[**图 3-14**](#12_chapter03_03.xhtml#fig3-14)。
