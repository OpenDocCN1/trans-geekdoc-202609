
# 交换机、路由器与网桥

## 交换机工作流程

交换机采用四个主要程序，分别标记为“学习”“转发”“丢弃”和“泛洪”。

- **学习**：从帧头的源位置收集 MAC 地址。源 MAC 地址与接收该帧的端口编号一起存入映射表。
- **转发**：当帧的目的 MAC 地址出现在映射表中时发生转发。该表指导交换机从最初发现该 MAC 地址的端口发送帧。
- **丢弃**：如果帧要去往映射表指示的目的端口，而该端口正是接收帧的端口，则丢弃该帧。交换机无需将帧再传回其来源的网段。
- **泛洪**：如果目的 MAC 不在映射表中，交换机将回退到泛洪——即从每个端口发送帧——以确保帧有最大机会到达目的地。

通过监控交换机活动——具体来说，观察映射表的构建和修改以及帧头中 MAC 地址的变化——可以检测错误和恶意流量。智能或多层交换机或外部入侵检测系统（`IDS`）/入侵防御系统（`IPS`）服务可执行此安全监控功能。

当交换机程序失效时，网络将受损。这可能意味着吞吐量降低、导致拒绝服务（`DoS`）的阻塞，或允许黑客尝试修改或窃听的流量重定向。幸运的是，此类攻击在产生大量异常网络流量方面是“吵闹”的，使得使用基本安全传感器更容易检测。仅这一优势就是使用交换机而非集线器的重要理由。

## 路由器

[路由器](#30_glossary.xhtml#gloss421) 是一种有线或无线设备，使用第 3 层（网络层）Internet 协议（`IP`）地址工作（参见 [**图 3-5**](#12_chapter03_02.xhtml#fig3-5)）。这些地址用于标识和移动发往 Internet 并从 Internet 接收的数据包。路由器通常位于网络的不同段之间，允许段间连接并将流量从一个段路由到目标段。路由器有若干合并端口，以及一个连接到 Internet 或最终连接到 Internet 的网段的端口。合并的路由器端口接收多个数据流并将它们合并以发送到网络的各个部分。路由器最常用于连接网络或网段，以简化数据包传输过程。

### 注意

[嗅探器](#30_glossary.xhtml#gloss466)，也称为数据包分析器、网络分析器和协议分析器，是一种捕获网络通信以进行调查和分析的软件实用程序或硬件设备。为帮助防止基础设施级攻击，请确保路由器使用身份验证来交换路由数据，并防止未经授权的物理访问。

路由器的主要目的是沿当前已知最佳可用路径将流量导向其既定目的地（参见 [**图 3-6**](#12_chapter03_02.xhtml#fig3-6)）。`RIP`、`OSPF`、`IGRP`、`EIGRP`、`BGP` 等路由协议根据各种度量动态管理路由选择。路通过引导流量走首选路由（而非在逻辑或物理上可能不那么安全的路由）来支持安全性。如果黑客能诱骗路由器改变传输路径，网络流量可能会遍历黑客放置了嗅探器的网段。

![图 3-6 路由网络部署示例。](Images/9781284183658_CH03_FIGF06.png)

**图 3-6** 路由网络部署示例。

尽管在某些情况下交换机和路由器可互换使用，但最常见的做法是：在 Internet 连接前放置路由器，在不同计算机群组之间的连接处使用交换机。路由器过去比交换机慢，但现在已不再如此。近期上市的产品提供与交换机相同的速度和性能。

## 网桥

[网桥](#30_glossary.xhtml#gloss58) 是一种第 2 层（数据链路层）设备。该设备的作用类似智能集线器或中继器，但包含基于 MAC 地址过滤数据包的能力，允许在使用相同通信协议的两个局域网（`LAN`）之间建立连接。与集线器、路由器和交换机不同，网桥只有两个端口，因为该设备仅连接两个 LAN。

网桥通过在网络间创建路径或路由来连接网络，仅当通信的目的地实际位于网桥对面的对向网络上时才使用该路径。一个类比是：一座城市被河流一分为二。当该城市的人想访问河流同侧的地点时，无需过桥即可到达。

网桥也是如此。网桥的工作方式与交换机类似，它们使用几个基本程序来管理流量。当你需要一个简单的“仅在需要时使用”的链路，而不需要路由器、交换机或防火墙的复杂性时，可使用网桥连接网络、网段或子网。

网桥使用学习、转发和丢弃过程。通过这些过程，只有发往对向网络上目的地的流量才会穿越网桥到达该网络。所有发往接收端同侧目的地的流量将被丢弃，因为该流量已在正确的网络上。参见 [**图 3-7**](#12_chapter03_02.xhtml#fig3-7)。除协议外，网桥还可连接基础设施大多数方面存在差异的网络。这包括不同的拓扑、电缆类型、传输速度，甚至有线与无线。

![图 3-7 MAC 层网桥部署示例。](Images/9781284183658_CH03_FIGF07.png)

**图 3-7** MAC 层网桥部署示例。

你可以使用网桥检测交换机所能检测的同类流量滥用。此外，网桥和交换机都可对 MAC 地址实施过滤。此处可使用黑名单或白名单概念：允许除黑名单/阻止列表上的流量外的所有流量，或阻止除白名单/允许列表上的流量外的所有流量。

你可以安排在路由器、交换机和网桥上[记录](#30_glossary.xhtml#gloss282)活动。你应定期查看流量日志，通常与防火墙和 `IDS`/`IPS` 日志保持相同的时间表。你将在这些通常不被视为安全设备的常见网络设备中发现滥用、入侵、拒绝服务、网络消耗、未经授权的流量模式等迹象。在大型网络中，最好拥有自动化监控解决方案，因为日志根据网络上发生的操作实时生成。跟上新条目和异常可能非常困难。

存在两种类型的网桥：透明网桥和源路由网桥。在[透明网桥](#30_glossary.xhtml#gloss508)中，连接的 LAN 以及每个 LAN 上的单个设备都不知道网络上有网桥。它通常无缝工作，因此对实际用户或设备是透明的。这对网络管理是一大益处，因为每个 LAN 上的设备无需配置即可识别网桥。
