
## 中间人攻击技术

*   **ARP 欺骗**—地址解析协议（`ARP`）是一种非认证的广播查询服务，它请求使用特定 IP 的系统提供媒体访问控制（`MAC`）地址。如果运行 [ARP 欺骗](#30_glossary.xhtml#gloss27) 工具的黑客在真实响应返回之前向请求者发送虚假响应，则发送者将使用虚假的 MAC 地址。后续帧将发送到流氓 MAC 地址，该地址由黑客的计算机使用。由于 `ARP` 协议是第 2 层且不可路由，因此 `ARP` 欺骗必须发生在子网内。

*   **MAC 欺骗**—黑客的计算机使用服务器的 MAC 地址；当服务器被淹没时，黑客的系统会接收原本发往预期服务器的流量。与上述 `ARP` 类似，[MAC 欺骗](#30_glossary.xhtml#gloss288) 必须发生在子网内。

*   **DNS 投毒**—要执行 [DNS 投毒](#30_glossary.xhtml#gloss143)，黑客会攻破域名系统（`DNS`）服务器并植入虚假的 FQDN 到 IP 映射记录。`DNS` 源会向后续的用户查询提供虚假数据。

*   **DNS 欺骗**—`DNS` 是一种非认证的查询服务，它请求将 FQDN 解析为其相关的 IP 地址。托管流氓 [DNS 欺骗](#30_glossary.xhtml#gloss144) 工具的黑客可以发回虚假的 DNS 响应。

*   **ICMP 重定向**—在有多个路由器的子网上，[ICMP 重定向](#30_glossary.xhtml#gloss230) 可能导致主机更改其路由表。这种攻击可能会将流量重定向到不同于默认、预期或最优路由的路径上。

*   **代理操纵**—要执行 [代理操纵](#30_glossary.xhtml#gloss373)，黑客会重新配置客户端的代理配置。服务请求会发送到充当中间人（`MitM`）代理的黑客系统。

*   **流氓 DHCP**—[流氓 DHCP](#30_glossary.xhtml#gloss415) 是一个虚假的动态主机配置协议（`DHCP`）服务器，它可以为唯一子网提供 IP 地址配置租约并定义默认网关，因为黑客的计算机充当 `MitM` 路由器/代理。

*   **流氓接入点**—要创建 [流氓接入点](#30_glossary.xhtml#gloss413)，黑客会配置一个类似于真实授权接入点的流氓无线接入点，诱骗用户连接，从而充当 `MitM` 代理。

### 技术提示

当使用 [非认证查询服务](#30_glossary.xhtml#gloss320) 时，它不会确认收到的任何响应的来源或有效性。因此，如果您收到伪造、欺骗或流氓响应，系统会将其视为真实并结束查询会话。如果真实响应到达，系统会将其作为无效或杂散数据包拒绝，因为它将不再与任何打开的查询会话对应。

针对 `MitM` 攻击的防御措施包括监控常见网络滥用或异常网络活动的 `IDS` 和 `IPS` 解决方案。此外，强多因素认证和相互认证可以降低 `MitM` 攻击的成功率。

## 隐蔽信道

[隐蔽信道](#30_glossary.xhtml#gloss105) 是隐藏的、未知的、独特的、非典型的信息传输路径。该信道之所以隐蔽，是因为它是未知且不可见的。黑客利用隐蔽信道进行秘密通信，通常用于泄露数据（传输数据）离开安全环境，例如气隙系统。隐蔽信道是不安全的传输路径。如果该路径被知晓，它将成为公开信道，并可能被阻止、过滤或以其他方式保护。

隐蔽信道主要有两种形式：时序信道和存储信道。时序信道通过定时和同步的活动传递信息。时序隐蔽信道的几个潜在示例包括：

*   闪烁灯光以摩斯码分发信息
*   操纵风扇转速，使较高和较低音调的噪音产生二进制传输
*   节流互联网链路上的带宽消耗，使得在特定间隔内，利用率测量值读取低于 60% 为 0、高于 60% 为 1，从而进行二进制通信。这会导致较低的波特率（数据传输速率），这对于用户凭证等小通信流仍然有效，但不适用于大量数据包，如数据库。

存储隐蔽信道通过不可见或未被发现的存储位置传递信息。存储隐蔽信道的几个潜在示例包括：

*   使用硬盘的 [未分区空间](#30_glossary.xhtml#gloss527) 通过十六进制编辑器写入数据存储数据
*   使用板载固件闪存芯片存储数据
*   使用 `NTFS` 的备用数据流隐藏文件
*   使用硬盘的 [松散空间](#30_glossary.xhtml#gloss463) 存储数据

针对隐蔽信道的最佳防御措施包括 `IDS` 和 `IPS`，以及对 IT 基础设施的所有方面进行彻底监控，以发现任何类型的异常或异常事件。预测隐蔽信道很困难，因为就其本质而言，它们是未知且不可见的。

## 黑客如何劫持松散空间

硬盘包含称为扇区的段。[扇区](#30_glossary.xhtml#gloss433) 是驱动器中最小的固定大小存储块，大小为 512 字节。当文件系统应用于 [分区](#30_glossary.xhtml#gloss334) 时，会由一个或多个扇区创建 [簇](#30_glossary.xhtml#gloss87)。松散空间是存储文件仅部分消耗的最后一个簇的未使用部分。簇与扇区的比率通常在 1:1 到 1:128 之间，对应 512 字节到 64 KB 的簇。

文件系统具有分配给簇的固定最大地址数量。较大的驱动器拥有与较小驱动器相同数量的簇，但簇更大。这有点像鞋子：儿童鞋一双一盒，成人鞋也是一双一盒，但装成人鞋的盒子更大。簇是最小的可消耗存储空间元素，只能包含单个文件的数据。标准文件系统格式中没有原生机制寻址亚簇划分。

当文件写入驱动器时，它会消耗包含文件所有数据所需的尽可能多的簇。除包含文件的最后一个簇外，所有簇都被填满。仅当文件大小恰好是簇大小的整数倍时（这不太常见），最后一个簇才会被完全消耗。最后一个簇的未使用部分称为松散空间（**图 2-11**）。松散空间实际上是不可用的、浪费的存储空间。

黑客开发了特殊的文件操作工具，可以定位并劫持松散空间，并利用它在硬盘上创建隐藏卷。这些卷几乎不可能被检测到，因为它们不被存储设备的文件系统包含、引用或寻址。相反，松散空间驱动器之所以存在，仅仅是因为特殊软件可以寻址亚簇存储位置。松散空间驱动器软件独立于操作系统和文件系统运行。

### 技术提示

Web 服务器，或至少网站，以至少四种不同的架构部署选项出现在互联网上：反向代理、非军事区（`DMZ`）、托管和主机托管。反向代理使用静态网络地址转换（`NAT`）映射或端口转发，允许外部访问者发起与内部服务器的通信。这是最差的安全选择，因为如果 Web 服务器被攻破，可能会授予黑客对整个内部网的访问权限。
