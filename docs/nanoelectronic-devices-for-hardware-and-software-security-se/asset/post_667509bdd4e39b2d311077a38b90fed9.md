The inherent process variations in memristors can be used to create PUFs called NanoPUFs [12], which have three main sections:

- i. A memristor-based crossbar.
- ii. The challenge (Input) circuit: They enable the application of an input to the decoders. A memristor is selected by the challenge circuit through the column and row decoders. A particular column is selected by the column decoder and then connected to the load resistance ($R_{load}$). A voltage of $V_{dd}$ magnitude is applied to a particular row by the row decoder. At the same time, the rest of the columns and rows standing float.
- iii. The response circuit: This gathers the response for a challenge from the crossbar. The response circuit consists of a current comparator and load resistance ($R_{load}$). The comparator compares $I_{out}$ (the current which is flowing out of the column) with $I_{ref}$ (the reference current). The response bit is 0 when $I_{out}$ is less than $I_{ref}$, else the logic is 1.

## 5.8.2 Nanoelectronic Public Unclonable Functions (NanoPUFs)

While the simulation models of PUFs are hidden from an attacker, the simulation models of a PFAF are public. However, if an attacker tries to simulate the PPUF, the simulation time would be very large – could even several years – as compared to PUF primitive, whose simulation time could be just a few nanoseconds.

To further enhance security, a 2-layer security protocol can be implemented by NanoPPUFs [13], like key exchange, authentication, time stamping, and bet commitment. Memristor-based nanoelectronic devices are best to implement NanoPPUFs. A NanoPPUF uses memristor properties like bidirectionality, process variations, and the complex simulation behavior of memristors and its crossbar models and polyaminoes, which are geometrical structures formed by joining more than one independent blocks.

The NanoPPUF has five main parts, which are:

- 1. Crossbar.
- 2. Challenge and characterization circuit.
- 3. Refresh and characterization circuit.
- 4. Controller circuit.
- 5. Response circuit.

Every cross-point in the crossbar is composed of the memristor.

## 5.8.3 Memristor-Based True Random Number Generators (NanoTRNGs)

Random number generators (RNGs) can be used to create session keys for establishing secure communication channels; hence, they are considered to be important security primitives. Types of memristors can be utilized for generating random numbers [14]. In random number devices, the electrons that are trapped in the insulation layer will randomly create an impact on the current that flows in the filament channel. When a high voltage (3 V) is applied to the memristor-based RNG device, the current that flows will be very large to be affected by the trapped electrons. On the other hand, a low voltage (1.2 V) is applied, the filament shrinks down in width and the current that flows in the filament is greatly impacted by the trapped electrons. As number of electrons that are trapped in the insulation layer is greater, the nature of the output current will also be random.

Advantages: NanoTRNGs have high density, consume power, and have more randomness in their physical properties, they are superior to their CMOS counterparts.

## 5.8.4 Memristor-Based Unique Signatures (MUS)

Some nanoelectronic devices based on memristors can generate unique signatures for the hardware by utilizing two distinct features of memristors [15], which are:

- 1. Inherent process variations that are nonuniform and irreducible during fabrication.
- 2. Forming process to make memristors functional.

For random generation, a memristor-based unique signature (MUS) utilizes a pair of nonpolar memristors that are connected in series. Here the generation of a bit is a function of the position of the filament with low resistance [15]. Thus, a random can be generated through multiple instances of random bit generators. Being nonvolatile, these signatures can be used for the purpose of hardware identification. This type of embedded hardware identification can be used to block electronics fraud.

## 5.8.5 Tamper Detection Circuits Based on Memristors

Tamper detection means the identification of unauthorized use of hardware. Memories that are tamper-evident make sure the stored data remains confidential and also disclose if there is any read attempt. The properties in memristor-based devices such as device formation, nonvolatility, and run-time drift can be used to detect tampering, particularly manufacture-time and run-time detection. Compared to CMOS devices, which require system-level techniques to enable detection, resulting in high power and performance overhead, memristor-based devices use inherent properties properties.

The device-forming step in memristors is used to differentiate between an uninformed device and a formed one. For instance, a circuit comprising a set of memristors could be used for data encryption in a secure microprocessor. Any unauthorized or authorized user would first have to form these devices before obtaining any information. The tamper detection of a circuit can be done using techniques that can also be used to verify the authenticity of the IC received from an unreliable fabrication unit. In this technique, a first known value is written onto the memristors; the value is read back; then the complimentary value of the known value is written onto the memristors. After this, the next value is read back; and the results are compared. If both the read values are the same, then this would indicate that the formation step did not occur, and it would not be possible to write onto the memristors. On the other hand, if the read values are different, it implies that the forming step in memristors has occurred, indicating a likely tampering.

### 5.8.5.1 Manufacture-Time Tamper Detection

Unauthorized memory reads based on memristors can be traced by monitoring the related memory drift. An attacker, to hide an unauthorized read, can restore the memristance to its original value. For this, the attacker applies a read pulse of some magnitude and width but of opposite polarity, to undo the device. The memory read operation is changed so that the attacker cannot change the memristance value back to the original.
