# 7.8.3 Identification and Authentication

If there is a PUF with N challenges on the IC, the IC classification can be done on the basis of this PUF. This recognition mechanism presents presenting the input challenges to the PUF first and then loading the answers in a secure archive, then challenging the PUF at authentication time and comparing recent responses to those challenge-response matching. But is a limited lifetime of this authentication protocol, which is based on challenge-response matching. Reason for this difficulty is during the enrollment phase, only a small number of challenges can be measured and stored in the memory. Using more advanced key-based encrypted verification protocols (e.g., zero-knowledge protocols) will overcome this restriction. Such a system may be used to generate a genuinely unclonable RFID tag [47].

# 7.8.4 Secure Key Storage

Most cryptographic algorithms used in computer devices (e.g., encryption, authentication, etc.) necessitate that a key is generated and stored beforehand and acts like the root of trust. Typically, the key generation part is performed entirely, and the device's memory is used for storage.

PUF technology offers another tactic to storage and generation of the key in which root key is constructed by combining the responses of the PUF circuit. This eliminates the necessity of on-chip memory storage of the generated key and enhances security to counter the attacks. Further, it avoids the requirement of management of the keys by the manufacturers [6].
