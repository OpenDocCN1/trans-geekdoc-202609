# ### 3.7.1 Subthreshold Slope

The subthreshold slope is basically the variation in the gate biasing dropping the tunneling current by the factor 10. The drive characteristics below the subthreshold voltage ($V_t$) are known as the subthreshold regime. Ideally, the MOS device should have zero subthreshold slope, that is, below the subthreshold voltage, the device current must be zero, which in fact can never be attained. In reality, there is always some current flowing below the threshold voltage. The SS is an important parameter for evaluating the subthreshold properties of MOSFET devices on the short-channel nanoscale regime. It provides for how many volts the gate bias could be induced to increase the currentthreshold by 10 times and is provided by [42].

```
$SS = \left(\frac{\partial log V_d}{\partial V_g}\right)^{-1} \quad (3.7)$
```

# ### 3.7.2 Drain Induced Barrier Lowering

Drain induced barrier lowering (DIBL) mainly predicts the $V_t$ effect on subthreshold characteristics. Due to a large amount of drain bias, the source–channel barrier will be reduced. The DBIL basically occurs in the short channel devices in which the device is controlled by both the gate biasing and the drain biasing. It can be measured by lateral shifting of transfer curves in the subthreshold region, where change in threshold voltage ($\Delta V_t$) is divided by $V_{dd}$ variation of two curves [43].

```
$DIBL = \frac{\Delta V_t}{\Delta V_{dd}} \quad (3.8)$
```

# ### 3.7.3 Cut-Off Frequency

When evaluating the devices for analog use, cut-off frequency ($f_t$) is the significant parameter. The value of the cut-off frequency occurs when the current gain is unity. It is given by equation 3.9, where $g_m$ represents the transconductance and the total capacitance of the device is $C_T$ [44].

```
$f_t = \frac{g_m}{2\pi C_T} \quad (3.9)$
```

# ### 3.7.4 Transconductance ($g_m$)

Transconductance ($g_m$) is the reciprocal of resistance and is defined by equation 3.10. It is the electrical characteristic that relates the current through a device's output to the voltage at the device's input [45].

```
$g_m = \frac{\Delta I_d}{\Delta V_{gs}} \quad (3.10)$
```

# ### 3.7.5 Early Voltage ($V_{EA}$)

Early voltage ($V_{EA}$): This parameter effectively converts the DC power into the AC frequency with the performance gain, and the term is given by equation 3.11. It is the main figure of merit for the analogy application [46].

```
$V_{EA} = \frac{I_d}{g_d} \quad (3.11)$
```
