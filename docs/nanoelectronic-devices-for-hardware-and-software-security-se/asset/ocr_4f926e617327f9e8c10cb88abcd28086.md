```
$$\frac{\sqrt{\alpha}e^{j\phi_1}}{\sqrt{(1-\alpha)}e^{j\phi_2}}}t = \frac{O_1}{O_2}$ \quad (9.26)$
```

# 9.2.6 Receiver

Optical sensitivity is measured based on the test conditions, and it assumes direction detection with negligible ASE noise. The sensitivity of the receiver depends on the pulse shape of the transmitted signal, post detection filter, and noise power.

The Q-factor calculated at the output of receiver satisfies equation 9.27, when shot noise and receiver noise is available.

```
$$\tilde{P}_R = \frac{Q^2}{2\eta}hG^{-\frac{w_0}{r_0^2}}-\frac{Q}{G_i}hv\frac{\sigma_b}{q_0}$ \quad (9.27)$
```

Where $r_0$ is calculated from $r(0)$, with the sampling time-instant equal to $t_w$. The approximation used in performance metrics includes pattern noise, sensitivity not closer to the quantum limit, Gaussian electrical noise, and negligible intersymbol interference.
