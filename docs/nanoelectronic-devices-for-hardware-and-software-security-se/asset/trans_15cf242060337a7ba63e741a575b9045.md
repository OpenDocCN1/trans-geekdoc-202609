## 8.5.6 Shaohao Xie 方案

## 8.6 结论

医疗数据是机密的，需要保护。本章解释了医疗物联网的安全。首先，本章介绍了医疗物联网及其特征。其次，本章解释了其漏洞。结论是，除非使用硬件组件建立强大的基础，否则物联网设备无法完全安全。这种硬件木马会在网络中触发并迅速损坏设备。物联网将成为未来生活的一部分。制造商、顾问或第三方来源需要采取步骤或程序来确保用户隐私。
