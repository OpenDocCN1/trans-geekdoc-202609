# 1.7.5 Tunnel Field Effect Transistors

Tunnel field effect transistors are also called TFETs. They have the capability to outperform MOSFETs for low power applications. The structure, working, and features of TFET are discussed in the next section.

# 1.8 PHYSICALLY DOPED TFET

# 1.8.1 Theory
