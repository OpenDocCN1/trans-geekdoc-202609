# 11.4.1 Encoder Circuit

As shown in Figure 11.5, the encoder is a digital electronic circuit whose inputs are decimal digits, and the outputs are coded input representation. Table 11.1 displays the circuit's facts table. Just one of the input lines is kept high at one time, and the corresponding binary code is stored in the output pins. Hence an N encoder is made up of 2 input lines and N output lines. A 4 to 2 encoder, for example, has four inputs (i.e., A0, A1, A2, and A3), and two output bits (i.e., F1, F0).
