* The encoder circuits are constructed using universal logic gates such as NAND and NOR gates, which were previously proposed in [7]. The design of the universal gate (UG) requires new-layer information, which makes it distinct from majority voting. Unlike majority voting, this gate design has a new layer block in the middle that is set to either +1 or -1 polarization. Polarization +I is given to the new layer to create a NAND gate, and -I to create a NOR gate, as shown in Figure 11.4.
