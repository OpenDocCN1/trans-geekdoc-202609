The honeycomb patch antenna length and width is estimated using the following equations:

$$The patch width $W = \frac{C_0}{2f_0\sqrt{\epsilon_r +1}} \quad (12.1)$

$$The patch length $L = \frac{C_0}{2f_0\sqrt{\epsilon_r}} \quad (12.2)$

The extension of the length can be done using the following equation:

$$\Delta L = 0.412h(\frac{\epsilon_{ref}} + 0.3)(\frac{W}{h} + 0.264) - (\frac{\epsilon_{ref}} - 0.258)(\frac{W}{h} + 0.8) \quad (12.3)$
