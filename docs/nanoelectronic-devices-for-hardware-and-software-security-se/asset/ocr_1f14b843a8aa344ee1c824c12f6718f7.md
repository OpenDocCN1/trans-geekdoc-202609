# 9.3.2.3 Quadrature PSK (QPSK) Modulator

QPSK is a type of PSK technique with four states and uses four equispaced points on the constellation diagram. QPSK supports increased data rate by encoding two bits per symbol. Input data $b_i(t) = b_0, b_1, b_2, \dots$ is divided into two data streams: in-phase data, $b_i(t)$ and quadrature data, $b_q(t)$:

$b_i(t) = b_0, b_2, \dots$

$b_q(t) = b_1, b_3, b_5, \dots$

$b_i(t)$ and $b_q(t)$ each possess half of the bit rate with respect to $b_i(t)$.

Corresponding QPSK waveform, $S(t)$, is given as

$S(t) = \frac{1}{\sqrt{2}} b_i(t) \cos(2\pi ft_t + \frac{\pi}{4}) + \frac{1}{\sqrt{2}} b_q(t) \sin(2\pi ft_t + \frac{\pi}{4})$

With trigonometric identities,

$S(t) = \cos(2\pi ft_t + \theta(t))$
