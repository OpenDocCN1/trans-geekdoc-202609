To further enhance security, a 2-layer security protocol can be implemented by NanoPPUFs [13], like key exchange, authentication, time stamping, and bet commitment. Memristor-based nanoelectronic devices are best to implement NanoPPUFs. A NanoPPUF uses memristor properties like bidirectionality, process variations, and the complex simulation behavior of memristors and its crossbar models and polyaminoes, which are geometrical structures formed by joining more than one independent blocks.

# 5.8.3 Memristor-Based True Random Number Generators (NanoTRNGs)

Random number generators (RNGs) can be used to create session keys for establishing secure communication channels; hence, they are considered to be important security primitives. types of memristors can be utilized for generating random numbers [14]. In random number devices, the electrons that are trapped in the insulation layer will randomly create an impact on the current that flows in the filament channel. When a high voltage (3 V) is applied to the memristor-based RNG device, the current that flows will be very large to be affected by the trapped electrons. On the other hand, a low voltage (1.2 V) is applied, the filament shrinks down in width and the current that flows in the filament is greatly impacted by the trapped electrons. As number of electrons that are trapped in the insulation layer is greater, the nature of the output current will also be random. Advantages: NanoTRNGs have high density, consume power, and have more randomness in their physical properties, they are superior to their CMOS counterparts.
