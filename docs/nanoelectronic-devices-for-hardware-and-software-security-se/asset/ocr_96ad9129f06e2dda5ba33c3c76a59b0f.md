# 6.5.2 Operation of Memristor-Based Forensics

The memristance value changes when logic ‘1 is applied and has no change when logic 0 is applied. The number of logic 1 of a particular input determines the amount of drift in the memristance. The memristance drift leads to change in memristance value; if the final memristance value of the memristor is known, the number of 1s in inputs can be estimated. For example, if the memristance value of memristors is 2 M, the magnitude and width of input pulses to be 1.1 V and 2 ns, respectively, the value of $M_A$, $M_B$, and $M_C$ will be 2.12 M, 2.25 M, and 2.25 M, respectively, and these values can be used to evaluate around millions of 1s applied to the inputs. This process of estimation is referred to as forensic analysis [45].
