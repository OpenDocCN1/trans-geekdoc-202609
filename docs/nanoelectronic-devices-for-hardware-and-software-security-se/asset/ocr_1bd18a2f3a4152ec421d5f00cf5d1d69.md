# 102 Nanoelectronic Devices for Security

metal-oxide-semiconductor (CMOS) technology had been developed, but with new emerging technologies, opportunities arise for advancement of the concept of hardware security. With the help of nanoelectronic devices, high speed and low power consuming miniaturized computational systems can be fabricated are more rugged, unlike CMOS devices. For example, memristive technology is promising for safe handling of secret keys, which is relatively difficult for CMOS technologies. In recent years, it has been recognized that memristors can be used for hardware security applications.

There are three fundamental elements in electronics, resistors, capacitors, and inductors, which can be used for defining four fundamental variables of the electrical circuit, namely current (I), charge (q), voltage (V), and magnetic flux (φ). The relation between voltage and current is defined by resistors. Similarly, capacitors define the relation between voltage and charge, and the relation between current and magnetic flux is defined by inductors. However, no element could define the relation of charge and magnetic flux. In 1971, Professor Chua [1] proposed another basic circuit element and called it the "memristor", which relates charge with flux and is mathematically as dq = Mdq.

The definition of the fourth fundamental element of the electrical circuit in terms of mathematical equation is stated in Table 5.1, where M is memristance of memristor and the magnetic flux of the device (φ) is a function of charge (q) passing through the memristor. Since v = dq/dt and i = dq/dt, the ratio of dv and dq can be replaced with the current and equations given by M(q) = (dv/dt)/(dq/dt). Thus, v = M(q) × i(t). Thus, qualitatively, Chua's fourth fundamental circuit element would have an electrical resistance that depends on the amount of charge (q) flowing through its terminals. It would also exhibit memory of the last applied voltage level, or the charge passed through it. Its resistance value be retained even when the power supply is disconnected. Chua introduced this new device as a memristor, a combination of the words memristor and resistor.

Chua suggested the following symbol for memristor, which has now been accepted as the standard one (Figure 5.1).

Table 5.1 Relation between i, v, q, φ
| SR. NO. | DEFINITION | UNIT | RELATION |
|---|---|---|---| |
| 1. | Resistance (R) | Ohms | dv = Rdi |
| 2. | Inductance (L) | Henry | dq = Ldi |
| 3. | Capacitance (C) | Farads | dq = Cq |
| 4. | Current (i) | Amperes | dq = id |
| 5. | Voltage (v) | Volts | dq = vdt |
| 6. | Memristance (M) | Ohms | dq = Mdq |
