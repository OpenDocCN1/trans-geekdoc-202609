## 8.1 INTRODUCTION

RFID technology includes memory functions and radio frequency interface with the address. It has a security mode that enables data exchange with reader facility attachable tags by using magnetic fields [1]. The development in future generation devices mostly depends on the Internet of nanoelectronic Devices for Security and RFID technology. RFID is considered a core subject for the Internet of things and has many applications as automatic toll payments, theft detection, vehicle tracking, infant protection, medical shops identification, patient monitoring and medicine management, blood transfusion, and nursing home identification, et [2]. The privacy issues that need to be addressed in medical hospitals and health colleges have already deployed RFID systems. The algorithms, as crucial encryption in symmetric and asymmetric schemes, are proposed, and they use hash functions [3]. For the maintenance of such algorithms, high-security back-end servers are required. This server contains information about objects, keys, and tags. Such knowledge leads to the leakage of many confidential messages, and these tags also leave private information. The reader tags are more vulnerable to attacks when the server is malicious; the commands will execute, which leads to different authentication results of the particular user tag. The protocol is to ensure data integrity, which is guarded by malicious server attacks [5].

The IoT plays an essential role in physical devices containing sensors, RFID, et. the embedded technology is the core of IoT, which communicates with all external environments [6]. The ITU (International Telecommunication Union) pointed out there are five core technologies to realize the Internet. They are sensor group, RFID technology, intelligent embedded technology, nanotechnology, and an ultra-light authentication protocol proposed using RFID. It depends on bit operations, and suffers from vulnerability [7][8].

The RFID technology has been replaced by code identification technology in recent times. RFID has three main components, that is readers, tags, and a server [9]. RFID has an inbuilt transport that processes the information with an antenna help and communication with the readers. The RFID server communicates with an inbuilt antenna. Once the signal is received, the data information is authenticated for further processing. The reader emits an interrogation signal through an antenna, which helps to identify multiple tags. The signal will also play a crucial role in determining, further processing, and retrieving information [10]. The interfacing between layers and the reader is always insecure, but the interfacing between the RFID server and reader interface is secure and fixed. These insecure communication channels have many privacy problems. Hacking or frequent attacks will always happen in this insecure channel. Spoofing, eaves, de-synchronization, and counterfe are the most frequent attacks. The authentication protocols help to solve the drawbacks in RFID technology [11].

The RFID authentication protocols are proposed based on symmetric-key cryptography. Still, this suffers from storage space and scalability problems [12], leading to the elliptic curve cryptography topic, where the solution for these issues is explained briefly. This elliptic curve cryptography-based authentication protocols prevents cloning attacks and also offer good privacy [13]. The modified elliptic curve cryptography-based RFID authentication protocols suffer from tag masquerade attack, location tracking, cloning of tag, and server attacks [14].

The security in medication for patients is an issue nowadays. Many researchers propose RFID group Some of the proposed protocols suffer from denial of service (DoS) attacks, relay attacks, and impersonation attacks [15]. The inpatient-based RFID security system is intended to increase medication safety for patients in hospitals. This protocol cannot prevent the DoS attacks, and coordinating hospital staff can modify the details. New RFID tamper-resistant resistance access control protocols [16], this novel protocol is also suffering from traceability and impersonation attacks. Then RFID-based mutual authentication protocols [17] for health care environments are offered, and these also suffer from traceability attacks.

Public key cryptography is developing in recent times, and elliptic curve cryptography is receiving tremendous attention. This technology has a small key size, takes less space, and has a high degree of execution. The first RFID authentication protocol was proposed using ECC in 2006 [18]. But how this protocol suffers from privacy laws is explained [19]. The authors in [20] propose a secure ECC authentication protocol that withstands various attacks [20]. Still, it suffers from fundamental compromise problems, and hackers can get information about the private tag key [21]. The authors introduced the new, improved protocol in [22] to overcome the fundamental compromise problem.
