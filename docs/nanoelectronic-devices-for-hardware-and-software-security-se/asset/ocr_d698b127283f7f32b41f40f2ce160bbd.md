Using equations 2.7 and 2.10, the tunneling probability is simplified [19]:

```
$T(E_X, E_T) \simeq \exp - 2 \int_{x_1}^{x_2} \frac{m^*}{\hbar^2} \left[ \frac{E_G}{2} + \frac{E_G E_T}{2} \right] q \in E_G^{1/2} (1-y^2)^{1/2} dy \quad (2.11)$
```

By solving the integration and rearranging the terms:

```
$T(E_X, E_T) \simeq \exp \left[ \frac{\pi m^{*1/2} E_G^{3/2}}{2\sqrt{2q}\hbar} \right] \exp \left[ \frac{\sqrt{2\pi} m^{*1/2} E_G^{1/2}}{2q\hbar} \right] = T_o, \exp \left[ \frac{E_T}{E_o} \right] \quad (2.12)$
```

where, $E_o = \frac{\sqrt{2}q}{\pi m^{*1/2} E_G^{1/2}}$

# 2.3.3 Calculations of the BTBT Current and Generation Rate

By utilizing equation 2.12, the differential tunneling current density ($dJ$) could be derived as follows [19]:

```
$dJ = q |\frac{1}{\hbar} \frac{\partial E_X}{\partial k_X}| \frac{2}{(2\pi)^2} dk_X dk_Z T(E_X, E_T)(f_v - f_c) \quad (2.13)$
```

$q$ denotes the charge, the second term is the velocity in k-space, the third term determines the amount of states/volume in k-space, the fourth term indicates the probability of tunneling, and the last term denotes the occupancy of states.

The velocities of the injected electrons were represented as group velocity of the valence band electron waves [18]. Equation 2.13 could be furthermore generalized by implying that the valence band is entirely electron-filled, as well as the conduction band is vacant in the following manner, transverse momentum $(k_y, k_z)$ can indeed be interpreted as a transverse wave vector, $k_T$ [14].

```
$k_T^2 = k_y^2 + k_z^2 \quad (2.14)$
```

```
$dk_y dk_z = 2\pi k_T dk_T \quad (2.15)$
```

The transverse dispersion relation can be utilized to shift the coordinates via momentum to energy space [14]:

```
$E_T = \frac{\hbar^2 k_T^2}{2m^*} \quad (2.16)$
```

```
$2\pi k_T dk_T = \frac{2\pi m^*}{\hbar^2} dE_T \quad (2.17)$
```
