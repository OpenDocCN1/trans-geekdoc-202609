# 8.5.5 K. Fan Scheme

| SYMBOL | INTERPRETATION |
|---|---|
| TID, RID | The private ID of the tag and reader |
| $N_o, N_t, N_s$ | Random numbers generated by the reader, tag, and the $n^{th}$ session key |
| $K, K1, k2$ | The subkeys in $K1 = k2||k1$ |
| $Ev(z), od(z)$ | Even and odd number of the string |
| $IDX_i, IDC_i$ | The $n^{th}$ session index value and index content |
| PRNG() | The pseudorandom number generation |
| $p_i(), \pi_i()$ | Permutation functions |
| $Cro(x,y)$ | Cross functions |
| $Rot(x,y)$ | Circular shift operations on the strings x and y |
| $MRotK(x,y)$ | Modular rotate function
