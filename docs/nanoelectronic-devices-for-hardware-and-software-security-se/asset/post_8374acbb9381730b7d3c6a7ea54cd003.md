## 9.2.2 Bit Sequence Generator

A pseudorandom sequence generator is used to produce maximal length pseudorandom binary sequences. The general PRBS pattern is represented as $2^n-1$, Where $n$ indicates the length of the shift register used in creating the pattern. The pattern included all possible combinations of required $n$ number of input binary bits, ones, and zeros, other than null value pattern.

## 9.2.3 Modulator

Classifications of various types of digital modulation techniques are given in Figure 9.2, and phase modulators are considered for the proposed design for its ability to support the higher data rate requirement of optical systems.

### 9.2.3.1 Phase Shift Keying (PSK) Modulator

PSK uses two phases separated by $180^\circ$, it is also called binary phase shift keying (BPSK). The constellation points for PSK are positioned at $0^\circ$ and $180^\circ$ on the real axis, so it handles the highest distortion level and hence the most robust out of all PSKs. But could modulate only one bit per symbol and sets limitation over high data rate handling.

The BPSK general equation is given as

$$s_n(t)=\sqrt{\frac{2E_b}{T_b}}\cos(2\pi ft+\pi(1-n));n=0,1 \quad (9.13)$$

Which results in two phases given as

$$s_n(t)=\sqrt{\frac{2E_b}{T_b}}\cos(2\pi ft+\pi)=-\sqrt{\frac{2E_b}{T_b}}\cos(2\pi ft); \text{for bit 0} \quad (9.14)$$

## 9.2.2.3 Quadrature PSK (QPSK) Modulator

QPSK is a type of PSK technique with four states and uses four equispaced points on the constellation diagram. QPSK supports increased data rate by encoding two bits per symbol. Input data $b_i(t) = b_0, b_1, b_2, \dots$ is divided into two data streams: in-phase data, $b_i(t)$ and quadrature data, $b_q(t)$:

$b_i(t) = b_0, b_2, \dots$

$b_q(t) = b_1, b_3, b_5, \dots$

$b_i(t)$ and $b_q(t)$ each possess half of the bit rate with respect to $b_i(t)$.

Corresponding QPSK waveform, $S(t)$, is given as

$$S(t) = \frac{1}{\sqrt{2}} b_i(t) \cos(2\pi ft_t + \frac{\pi}{4}) + \frac{1}{\sqrt{2}} b_q(t) \sin(2\pi ft_t + \frac{\pi}{4})$$

With trigonometric identities,

$$S(t) = \cos(2\pi ft_t + \theta(t))$$

Differential encoding of in-phase and quadrature data is required before phase modulation in DPS modulation, the output depends on current and previous $a_k, b_k$, and $I_{k-1}, Q_{k-1}$, respectively, and the corresponding truth table is given in Table 9.2.

## 9.2.4 DPS Modulator

DPS follows PSK format, where the optical input stream is produced by modulating phase of input. Phase difference is applied to the carrier in accordance with consecutive bits, that is phase shift is applied only when previous value is 1; otherwise no shift will be applied to produce DPS data.

## 9.2.6 Receiver

Optical sensitivity is measured based on test conditions, and assumes detection with negligible ASE noise. The sensitivity of the receiver depends on pulse shape of transmitted signal, post detection filter, and noise power. The Q-factor calculated at the output of receiver satisfies equation 9.27 when shot noise and receiver noise is available.

$$\tilde{P}_R = \frac{Q^2}{2\eta}hG^{-\frac{w_0}{r_0^2}}-\frac{Q}{G_i}hv\frac{\sigma_b}{q_0} \quad (9.27)$$

Where $r_0$ is calculated from $r(0)$, with sampling time equal to $t_w$. The approximation used in performance metrics includes pattern noise, sensitivity closer to the quantum limit, Gaussian electrical noise, and negligible intersymbol interference.
