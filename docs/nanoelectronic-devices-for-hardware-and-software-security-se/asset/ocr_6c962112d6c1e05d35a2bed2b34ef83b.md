# 6.4 MEMRISTOR-BASED TAMPER DETECTION CIRCUIT

The unauthorized access to target hardware or its unauthorized usage is termed as tampering, and the ability of the device to sense such unauthorized activities is defined as tamper detection. A device that has a tamper detection circuit along with a defense circuit to respond to such practices keeps the stored data safe and confidential. Memory devices using memristors are tamper proof due to their nonvolatility and resistance drifting characteristics.

# 6.4.1 The Architecture of Tamper Detection Circuit

A memristor-based memory device designed in a crossbar pattern is similar to that shown in Figure 6.3. In these memristors, the HRS represents logic 0, and LRS represents logic 1, respectively. The two operations write read are given as follows:

Write operation: Apply V_{RESET} (logic 0) and V_{SET} to corresponding rows, and 0 V to the corresponding columns.

Read operation: A small amplitude pulse is applied as a read voltage to the corresponding row. The output current and reference current are compared with each other; logic 1 is read if the output current is larger than the reference current, and logic 0 is read if the output current is smaller than the reference current. In the memristor-based devices, if memristance drift occurs during the read operation, generally two steps of the read operation are utilized. In a bipolar memristor, the same magnitude and duration pulse followed by the negative pulse is the ideal read pattern, which creates a zero change in memristance.

Tampering of the device can be done at two times; first, it is possible that the manufacturer is not trustworthy and that the delivered device is used or tampered with by the manufacturer. Second, the device may be tampered with by an outside attacker during the run time [38]. To prevent such activities, the two types of tamper detection are (1) manufacture-time tamper detection and (2) run-time tamper detection.
