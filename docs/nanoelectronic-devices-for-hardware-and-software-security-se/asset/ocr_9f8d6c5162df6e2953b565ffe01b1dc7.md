# 13.7.2 Directional Coupler

This component is used widely in measurement instruments, and it is used to test the coupling between two transmission lines. In this work, we have targeted a directional coupler with three differing coupling coefficients, 7, 10, and 13 dB. An iris-based configuration is implemented to control the flow of EM energy between primary and secondary waveguides. The base-line of the design is a rectangular waveguide with WR-2.2 configuration.
