# 6.1 INTRODUCTION

The memristors are the fourth fundamental and volatile electrical two-terminal devices. These behave as nonlinear resistors with memory, hence named memristors [1]. Memristors are axially defined by a relationship between electric charge and magnetic flux [1, 2]. It is known to be flux controlled or charge controlled, depending on whether this relationship can be expressed as a single-valued function of the flux-linkage ($\phi$) or charge ($q$). The voltage developed across charge-controlled memristors are given

```
$v(t) = M(q(t))i(t)$ (6.1)
```

Where $M$ is memristance, measured in ohms.

```
$M(\phi) = \phi(q)/dq$ (6.2)
```

Similarly, the charge-controlled memristors are given by

```
$i(t) = W(\phi(t))v(t)$ (6.3)
```

Where $W(\phi)$ is inductance, measured in mhos.

```
$W(phi) = dq(\phi)/d\phi$ (6.4)
```

The memristors can behave as simple resistors at any instance for high-frequency range, while resistance and inductance rely on the past of memristors [1, 2].
