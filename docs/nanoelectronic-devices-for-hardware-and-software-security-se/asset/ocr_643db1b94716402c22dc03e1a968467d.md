The naming conventions and abbreviations used for different Au-doping configurations are as follows: (i) center-doped AGeNR (C-AGeNR), (ii) center-doped ZGeNR (C-ZGeNR), (iii) edge-doped ZGeNR (E-ZGeNR), and (iv) near-edge doped ZGeNR (NE-ZGeNR).

```
$E_{FE} = -\frac{pE_{Ge} - qE_{Au} - rE_{H}}{p+q+r}$\quad(4.5)
```

Here, $E_{Ge}, E_{Au},$ and $E_{H}$ represent the total energy of the doped AGeNR or ZGeNR configurations, Ge-, Au-, H atoms (in their isolated form). Also, $p,q,r$ indicates the total number of Ge-, Au-, H atoms, respectively. The calculated formation energy ($E_{FE}$) of the doped AGeNR and ZGeNR cases are tabulated in Table 4.3.

ZGeNR is a strong function of doping site (particular in the case of ZGeNR). From tabulated results of $E_{FE}$ in Table 4.3, it is evident that $E_{FE-ZGeNR} = -3.46$ eV, ZGeNR outperforms others in terms of stability, with others following the order E-ZGeNR < C-ZGeNR < NE-ZGeNR. Further, based on the values of the bandgap listed in the table, it can be said that all doped configurations exhibit metallic behavior, making them suitable for interconnect applications.

To examine the performance of these doped structures as interconnects, we again use the same performance metric as $R_Q, L_Q, C_Q$. Based on the two-probe analysis and the equations listed earlier, we again calculated the parameters for these doped configurations. These are listed in Table 4.4.
