# 9.2.3 DQPSK Modulator

Differential encoding of in-phase and quadrature data is required before phase modulation in DPS modulation, the output depends on the current and previous stages $a_k, b_k$, and $I_{k-1}, Q_{k-1}$, respectively, and the corresponding truth table is given in Table 9.2.

```
$I_k = (a_k \oplus b_k) \cdot (a_k \oplus I_{k-1}) + (a_k \oplus b_k) \cdot (b_k \oplus Q_{k-1})$ \quad (9.22)$
```

```
$Q_k = (a_k \oplus b_k) \cdot (b_k \oplus Q_{k-1}) + (a_k \oplus b_k) \cdot (a_k \oplus I_{k-1})$ \quad (9.23)$
```

# 9.2.4 DPS Modulator

DPS follows PSK format definition, where the optical input stream is produced by the modulating phase of the input. Phase difference is applied to the carrier in accordance with consecutive data bits, which is the information part of DPSK; that is, phase shift is applied only when the previous value is 1; otherwise, no shift will be applied to produce DPSK encoded data.

# 9.2.4 Coupler

Each port of coupler gets optical inputs and couples the signals together; the coupler model is described in equation 9.24, where A A is the amplitude of the complex optical field:

```
$\begin{bmatrix} A_{01} \ A_{02} \end{bmatrix} = \begin{bmatrix} \sqrt{1-\alpha} & j\sqrt{\alpha} \ j\sqrt{\alpha} & \sqrt{1-\alpha} \end{bmatrix} [A_1]$ \quad (9.24)$
```

# 9.2.5 Combiner

The combiner is used to combine both the given inputs, and the coupler model is described in equations 9.24 and 9.25, where $\alpha, \varphi_1, \varphi_2$ are input power ratio coefficient, phase shift for input 1 and 2, output signal and $2^{th}$ input, and output signal, respectively

```
$o = I_1 \sqrt{\alpha} e^{j\varphi_1} + I_2 \sqrt{(1-\alpha)} e^{j\varphi_2}$ \quad (9.25)$
```
