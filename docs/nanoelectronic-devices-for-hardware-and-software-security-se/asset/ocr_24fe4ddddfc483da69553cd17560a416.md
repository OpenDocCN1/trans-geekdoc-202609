In metal-oxide memristors, resistive switching occurs when conductive filaments are formed and ruptured in the active layer. When conductive filaments are formed, the device switches from “OFF” to “ON” state, creating a low-resistance state (LRS) and when filaments are ruptured the device switches from “ON” to “OFF” state and create creating high-resistance state (HRS), as shown in Figure (5.6).
