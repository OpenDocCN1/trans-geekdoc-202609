# TABLE 8.1 List of Symbols Used in Chunhua Jin Scheme

| n and q | Both are large prime numbers |
| P | A generator with order n |
| F(q) | A finite field |
| E | An elliptic curve defined over a finite field F(q) by the equation $y^2 = x^3 + ax + b$, where $a,b$ belongs to F(q) |

| $S_R, P_R$ | Private/public key of the tag reader, where $P_R = S_R$, belongs to Zn |

| $H_1, H_2$ | Secure hash functions |
