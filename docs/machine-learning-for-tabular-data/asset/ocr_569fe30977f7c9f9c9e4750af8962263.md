Using linear models, statistical standardization, for better convergence using regularization or generalized linear models, and feature transformation, for better fitting nonlinearities, are usually the standard.

In 7.13, we define all the necessary feature transformations and ensemble them in a Scikit-learn's ColumnTransformer, which will be part of the pipeline that also contains the machine learning model of our choice. It is also to note that we take steps in defining the column transformers to handle unknown categories and missing values that may unexpectedly appear at time. Our strategy for one-hot encoding is to ignore unknown categories. For ordinal encoding, the value assigned to the parameter unknown_value, which is by default np.nan, will be used to encode unknown categories. This means an XGBoost model will deal with such situations as missing cases using the most frequent split. Other machine learning algorithms might instead break such occurrences, which is an advantage of XGBoost. For the target encoder, the target mean is substituted for unknown categories.
