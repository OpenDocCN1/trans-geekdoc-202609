# 1.1 什么是表格数据？

就本书而言，表格数据简单是指按行和列组织的数据。一组表格数据可以被称为表格数据集或表格。行中的条目与共同的数据点或观测值相关。每行与其他行之间是独立的，并且完全描述了一个特定状态。列代表该数据点的属性，它们通常被称为变量（一个更具统计学的术语）或特征（机器学习中常用的术语）。列中的所有条目具有共同的数据类型，例如整数、字符串或浮点数。表格中的列通常具有共同类型。

- 图像
- 视频
