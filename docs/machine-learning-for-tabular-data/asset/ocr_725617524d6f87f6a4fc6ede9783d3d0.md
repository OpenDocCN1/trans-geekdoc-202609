# Introduction to tree-based methods

Originally devised by Leo Breiman and Adele Cutler (https://mnb.bz/0QIqp), though commercially produced, the algorithm has been open-sourced—hence the different names of its implementations. Random forests offer up even more possibilities, apart before predictions, you can use the algorithm to determine feature importance and measure the degree of similarity of the cases in a dataset.

In the example in listing 5.4, we test how random forests would work on our classification problem with the Airbnb dataset. From the algorithm, there are no differences from our standard data processing when deciding trees. One-hot encoding categorical features into binaries, and numeric features are left as they are.
