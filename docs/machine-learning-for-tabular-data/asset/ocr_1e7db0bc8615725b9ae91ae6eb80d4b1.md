# 11.2.3 Granting the service account access to the Compute Engine default service account

When you start your project in Google Cloud, a Compute Engine default service account was created. This account has an address like PROJECT_NUMBER-compute@developer.googleapisaccount.com. For more details on the Compute Engine default service account, see the documentation (https://mng.bz/dXdn).

We need to give the service account that we set up in the preceding sections access to the Compute Engine default service account to run the ML pipeline. Follow these steps to set up this access to the Compute Engine default service account:

+   - In the Service accounts page, click the copy icon beside the email address for the service account you just created (you will need this in the next step) and click the email address of the Compute Engine default service account, as shown in figure 11.9.
