# SVMs 469

The strong points of SVMs are their robust handling of overfitting, noise in data, and outliers and how they can successfully handle datasets that include numerous multicolinear features. Applying various nonlinear approaches to data, SVMs don't require the transformations (such as polynomial expansion) we have seen for logistic regression. However, they can use domain-based feature engineering like all other machine learning algorithms.

On the weak side, SVM optimization is complex and be feasible only for a limited number of examples. Moreover, they are best fit for binary predictions and for just class prediction; they are not a probabilistic algorithm, and you need to wrap them with another algorithm for calibration (such as logistic regression) to extract properties from them. That renders SVMs valid only for a limited range of risk estimation.

In our example, we repay our problem with Airbnb data using a basic classification SVM with a radial basis function kernel, an approach capable of automatically modeling nonlinear relationships between the provided features.
