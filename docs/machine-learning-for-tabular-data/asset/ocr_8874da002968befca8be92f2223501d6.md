The .isna method will help you keep track of the NaN values in your features. As discussed, with a large number of missing values may conceal some interesting predictive pattern and may be turned into binary indicator variables. You can use the MissingIndicator in Scikit-learn for this purpose: https://mgn.bz/dXO. Additionally, depending on your predictive algorithm, you always have to deal with missing values, whether there are many or just a few handfuls. If you use a deep learning solution, you must imput the missing values with a numeric value. Usually, you use the mean, median, or mode as a replacement for missing values. Still, sophisticated treatments are also based on iterative estimates of the best value to use as a substitute. An example is the IterativeImputer in Scikit-learn: https://mgn.bz/rKad

It is helpful to remember that imputing the missing values with the zero value is a good strategy for neural networks and generalized linear models when your features are standardized and divide by the standard deviation: in such case, the zero value corresponds to the mean for all the numeric features. The same goals for most machine learning algorithms but the approach is different for most advanced gradient boosting implementations, such as XGBoost and LightGBM. Such algorithms can appropriately treat missing data without any further intervention on your side.

Sometimes conventional numbers (such as -999) are used in tabular datasets. If you know that a certain value points out to a missing value, you have to modify your command to consider such situation:

