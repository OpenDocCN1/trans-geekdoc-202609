# 8.3.2 Comparing the TabNet solution with the Keras solution

We have seen three deep learning solutions to the Airbnb NYC listing price prediction: the Keras solution, the fastai solution, and the TabNet solution. In this section we will compare the Keras solution with the TabNet solution and review the pros and cons of each.

The Keras and the TabNet solution are interesting to compare because they demonstrate some of the strengths and weaknesses of their underlying frameworks, TensorFlow and PyTorch. The Keras solution benefits from the summary() state that gives a compact list of layers that make up the model. PyTorch lacks this elegant feature, the TabNet solution is also benefiting that. Keras, on the other hand, does not provide built-in control for the training process, so have to define callbacks to ensure that you end up with the optimal model from the training run at the end of the run and you don't waste resources epochs when the model has stopped improving. PyTorch, on the other hand, incorporates early stopping and saving of the optimal model by default, the TabNet solution doesn't need to include code to explicitly define callbacks to the training process.
