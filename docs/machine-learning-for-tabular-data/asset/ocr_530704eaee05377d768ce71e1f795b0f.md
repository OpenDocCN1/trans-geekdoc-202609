# CHAPTER 4 Classical algorithms for tabular data

We prepared two binary targets, target_mean and target_median, and a multiclass target with five distinct classes based on percentiles for classification purposes.
in particular, it is important to notice that our target_median is a binary balanced target. Hence, we can safely use accuracy as a good performance measurement. As a test, you get an almost equal number of cases for the positive and negative classes if you try to count the values:

```
target_median.value_counts()
```

You get the result

```
0 24472
1 24423
```

Instead, if you are trying the same on the target_mean target variable, you get

```
target_mean.value_counts()
```

You will obtain a distribution that is imbalanced toward the negative cases; that is, there are more cases below the mean because of the skewed distribution we previously observed:

```
0 34016
1 14879
```

In this case, when evaluating the results of a machine learning classifier, we prefer to use metrics like the Receiver Operating Characteristic Area Under Curve (ROC-AUC) or Average Precision—quite sensible for ordering. Finally, as for the multiclass target, counting the cases for each one of the five classes reveals that they are also balanced in distribution:

```
target_multiclass.value_counts()
```

This command returns the result of

```
0 10063
1 9835
2 9804
3 10809
4 8384
```

As for the regression target, target_regression is the original target without transformations. However, we use subsets of it and accordingly transform them based on the machine learning algorithm we will demonstrate.
