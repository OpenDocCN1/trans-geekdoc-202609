# 6.2.2 Shadow features and Boruta

Boruta is a smart procedure for determining whether a feature is relevant in a machine learning problem by relying on the internal parameters of the model, such as coefficients in linear models or importance values based on gain, as in decision trees and their ensembles. It was first published in “Feature Selection with the Boruta Package” by Miron B. Kura and Witold R. Rudnicki (Journal of Statistical Software 36 (2010): 1-13); for a copy of the article, see https://www.jstatsoft.org/article/view/v0361.
Boruta, innovative, presents a few advantages over stability selection. It can be used with decision tree-based ensembles. To measure the relevance of a feature, as in stability selection, we look for non-zero coefficients. In Boruta, we count the times when the feature exceeds the highest importance obtained by shadow features. We call them them. Shadow features are random versions of the features (basically shuffled features), given that they are random, should attain any importance just by chance. If any feature cannot exceed the maximum importance of a shadow feature, it cannot be considered more predictive than any random sequence of values.

A threshold for selection, usually a minimum of occurrences of non-zero coefficients in stability selection, is given in Boruta by the number of its translates into a binomial distribution. A significance threshold for retaining or dropping a feature test according to the distribution if the number of hits can prove that the feature is consistently better than any random construct.
