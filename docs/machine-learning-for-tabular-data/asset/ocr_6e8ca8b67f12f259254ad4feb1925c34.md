Creates an Ordinal Encoder with handling of unknown categories and the unknown value by np.nan

> Creates a One-Hot Encoder with the option to handle unknown categories by ignoring them during encoding

```
onehot_encoder = OneHotEncoder(handle_unknown='ignore')
ordinal_encoder = OrdinalEncoder(handle_unknown='use_encoded_value',
unknown_value=np.nan)
```

```
target_encoder = TargetEncoder(
cols=target_encoding,
handle_unknown="value"
smooth=0.5)
```

> Creates a TargetEncoder object, handling unknown values by encoding them using the mean value and applying a smoother with a parameter of 0.5

```
column_transform = ColumnTransformer(
  ['onehot_encoder', onehot_encoder, ordinal_encoding),
  ['ordinal_encoder', ordinal_encoder, ordinal_encoding),
  ['target_encoder', target_encoder, target_encoding),
  ['numeric', 'passthrough', numeric),
  ['binary', 'passthrough', binary]),
  remainder='drop',
  verbose_names_out=True,
  sparse_threshold=0.0)
```

> A Column Transformer object applying the specified encoders to the respective columns

> Drops columns that are not specified in the transformer

> Ensures that the transformed data is kept as dense arrays

> Keeps verbose feature names for transformed columns

After having the code list, we can immediately testing the data we have and checking the transformed column names:

```
Xt = column_transform.fit_transform(X, y)
```
