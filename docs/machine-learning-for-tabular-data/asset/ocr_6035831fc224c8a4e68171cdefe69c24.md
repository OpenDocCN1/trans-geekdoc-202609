# 5.5.3 Applying early stopping to LightGBM

LightGBM supports early stopping, and the parameters to control it are similar to those used in the XGBoost implementation. In the example in listing 5.17, we use LightGBM for training and have the algorithm assess performance during training using a test set. If there is no improvement in performance on the test set for 100 iterations, the algorithm halts the training process. It selects the round of iterations that achieved the highest performance on the test set so far.
