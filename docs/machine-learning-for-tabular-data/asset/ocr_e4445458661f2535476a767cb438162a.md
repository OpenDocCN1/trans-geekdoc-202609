The train data is split into multiple batches, and each batch is proposed for learning to the stochastic descent (SGD) algorithm. SGD is not a stand-alone algorithm but an optimization procedure for linear models, optimizing the weights by iteratively learning from small batches of the data or even just examples alone. It is based on the gradient descent optimization procedure and is also used in deep learning. Gradient descent starts with an initial guess for the model weights and computes the error. The next step involves computing the gradient of the error, which is obtained by taking the negative of the vector that contains the partial derivatives of the error with respect to the model weights. Since the gradient can be interpreted as taking the steepest descent on an error surface, a common example for gradient descent is to figure it as descending from high in the mountains to the lowest valley by taking the steepest path downward. The "mountains" in this analogy represent the error surface, and the "lowest valley" represents the minimum of the error function. Figure 4.12 visually this process by the progressive descent from a random high to the lowest point in a bowl-shaped error curve.

Besides angle, it is important to remember that the gradient determines how the weights should be adjusted to reduce the error at each step. Through repeated iterations, the error can be minimized by adjusting the model's weights. However, the weights updated can significantly affect the outcome. If the updates are too large the algorithm may overly wide steps, potentially causing the model to overshoot the target and climb the error curve. In the worst-case scenario, this can result in a continuous worsening of the error, with no possibility of recovery. Conversely, taking smaller steps is generally safer but computationally burdensome. The size of such steps is decided by the learning rate, a parameter that regulates how updates are done.
