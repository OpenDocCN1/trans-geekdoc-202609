The deep learning libraries provide capabilities specifically for dealing with tabular data. Two details to note about tabular data libraries are

+   - Tabular data libraries may be supported for both TensorFlow and PyTorch. TabNet is an example of a library that is supported for both low-level deep learning frameworks.
- fastai is a general-purpose, high-level API as well as a tabular data library. fastai fits into both because it abstracts some of the complexity of PyTorch to make it easier to build and train models on a variety of data types (including image and text) and also has facilities aimed specifically for tabular data (for example, automatically handling basic operations for categorical features in datasets).
