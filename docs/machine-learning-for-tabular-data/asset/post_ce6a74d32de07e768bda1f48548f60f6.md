# SVMs 469

The strong points of SVMs are their robust handling of overfitting, noise in data, and outliers and how they can successfully handle datasets that include numerous multicolinear features. Applying various nonlinear approaches to data, SVMs don't require the transformations (such as polynomial expansion) we have seen for logistic regression. However, they can use domain-based feature engineering like all other machine learning algorithms.

On the weak side, SVM optimization is complex and be feasible only for a limited number of examples. Moreover, they are best fit for binary predictions and for just class prediction; they are not a probabilistic algorithm, and you need to wrap them with another algorithm for calibration (such as logistic regression) to extract properties from them. That renders SVMs valid only for a limited range of risk estimation.

In our example, we repay our problem with Airbnb data using a basic classification SVM with a radial basis function kernel, an approach capable of automatically modeling nonlinear relationships between the provided features.

## B.3 Using GPUs for machine learning

Due to the rapid rise of deep learning in the data science field, GPUs are widespread and accessible for local and cloud computing. Earlier, you only heard about GPUs in 3D gaming, graphic processing rendering, and animation. Since they are cheap and apt at fast matrix multiplication tasks, academics and practitioners have rapidly picked up GPUs for neural network computations. RAPIDS, developed by NVIDIA (one of the top manufacturers of GPUs), is a set of packages for doing the full spectrum of data science, not just deep learning, on GPUs. The RAPIDS packages promise to help in all phases of a machine learning pipeline, to end. That's a game changer for many classical machine learning algorithms, especially for the SVMs, the most credible choice for complex tasks involving noisy, outlying observations and datasets (having a large set of features, especially if multiclass or sparse ones). In the RAPIDS packages (table B.1), all commands have adopted existing APIs the user, there is no need to relearn how the wheel works.

**Table B.1** Rapids packages

| Rapids package | Task | API mimicked |
|---|---|---|
| cuPy | Array operations | NumPy |
| cuDF | Data processing | pandas |
| cuML | Machine learning | Scikit-learn |
