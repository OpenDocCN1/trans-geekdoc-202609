A VIF is, therefore, more extensive in scope than a coefficient, which is a bivariate analysis, analysis between two variables at a time. Instead, the VIF tries to reduce the power of a feature with respect to all the others. VIF are useful in terms of highlighting potentially less contributing features. Still, they not reveal what feature is related to others or which must be removed. The higher the VIF value, which starts from 1 and goes to infinity, the more multicollinearity the considered feature. In our example, since higher VIF values indicate a less unique contribution of the feature, we can quickly sort that the first and last features of the dataset are more problematic:

```

1.24 1.63 1.28 1.45 1.23 1.15 1.16 18.86 16.79 15.39 16.45 17.82
```

However, you need using the one-by-one comparison by correlation analysis to determine which features you can narrow down the problem. By using a threshold set to 0.99, you will find out only identical features. By setting the lower bar to 0.90 or 0.95, you will reveal features whose contribution is minimal:

```
feature 0 and 20 have r=0.963
feature 1 and 21 have r=0.963
feature 2 and 22 have r=0.947
feature 3 and 23 have r=0.958
feature 4 and 24 have r=0.964
```

At this point, it is up to you to evaluate what feature to keep between highly collinear lines. In any case, even if you have to decide what features to drop based on collinearity, selecting features based on quality is what you consider to later treat only with useful features. Generally speaking, when facing multiple errors that cannot be corrected, as recording or measurement errors, a high volume of missing data, and outliers, a feature should be kept only if it shows an interesting and unique association with the target.

# Irrelevant features

The same goes for irrelevant features, which may little sense for your problem and have little or no association with the target. At this stage, you just need to rule out improbable features that you do not apport any information to your problem based on domain knowledge or simple statistical univariate tests, such as correlation or chi-square analysis, as we will demonstrate in the latter part of this chapter.

Selecting features has been widely used to reduce computing requirements during training, help in having a more interpretable model, and improve predictive performance on data since irrelevant features create false signals and disturbances to machine learning algorithms, both classic and neural networks.
