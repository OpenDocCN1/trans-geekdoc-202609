Generally, probabilities output by GBDTs are correct, and they rarely require probabilistic calibration, which is a post-processing step used to adjust predicted probabilities to improve their accuracy and reliability in applications such as medical diagnosis, (disease detection), fraud detection, or credit risk assessment.

In our code implementation, we allow passing any parameter for the DecisionTreeRegressor as https://mnz.b/9VQQs), though the most useful are the ones related to the complexity of the tree development, as max_depth, and min_samples_leaf, the minimum number of samples needed to split an internal node or to be a leaf, respectively.

The role of each tree regressor is to provide a w vector containing the corrections to be summed with the previous estimates being weighted by the learning rate. Each w depends on the previous one because it is a tree regressor trained on the gradients to correct the estimates to match the true classification. The chained vectors resemble a sequence of gradient corrections—at first large, then finer and finer, converging towards an optimal prediction. Gradient descent is perfectly similar to the gradient optimization procedure we introduced in chapter 4. In addition, by changing the cost function on which you base your gradients' computation, you can ask the GBDT to optimize for different losses.
