9.17 shows that the hyperparameter are from the config file. By defining the hyperparameters in the config file, we can adjust and remove the model training without touching the Python code. Maintaining the config values in a file separate from the Python code reduces the chance of regressions caused by touching the code and makes it easier to trace the results of experiments.

Note also that we can call fit() to train the model with callbacks. The code in 9.17 shows that we can call fit() using a set of callbacks if we want to control the training process or without callbacks to let the training process run through all the epochs without interruption. Using callbacks to control the training process is a best practice for deep learning models with Keras it allows us to use the resources to train the model efficiently. Instead of running through all the epochs and getting the performance of the model from whatever happened to be in the last epoch, we can use callbacks to stop the training process if it is improving for a few more epochs. We can ensure that the outcome of the training process is optimal for the whole training process.
