```
print(f'blended result for R-squared: {r2:.3f}')

```

The code in line 12 combines results for XGBoost and fastai according to the blending values in blend_list. Note that these blending values are not optimized to find the absolute optimum--we are simply using a set of fixed blending values to get a general sense of the effect of blending results. Also, note that we are evaluating the results using out-of-fold predictions. Nevertheless, by combining the predictions from XGBoost and fastai according to the proportions specified by blend_list, we can see the effect of enrolling the two approaches across a range of values.

These figures may be a bit hard to interpret, so let's see what they look like in the form of a chart. Figure 12.3 shows the results for R-squared, RMSE, and MAE for a range of blending between the XGBoost and fastai models.

As 12.3 shows, we get the optimal results for R-squared evaluation when we use a 50/50 blend of the predictions from the XGBoost and fastai models. For error-based measures, RMSE and MAE, we obtain a better result weighting more XGBoost than fastai; however, if we use a 50/50 blend, we would obtain only slightly worse scores. The worst results are when we use 100% of prediction from fastai, as we would expect from the results we got from each model in isolation, but it is interesting to notice that using only XGBoost is always worse than blending it with the other solution using 75/25 or 50/50 share.
