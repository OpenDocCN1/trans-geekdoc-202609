XGBoost has other concept improvements: the traditional splitting algorithm
denoted by exact the value of the tree_method parameter. The Weighted
Quantile Sketch, which referred to as in the XGBoost API, is an exclusive feature
unique to XGBoost. This split-finding technique utilizes approximations and harnesses
information derived from gradient statistics. By employing quantiles, the quantiles are weighted to
prior selecting candidates capable of mitigating high gradients, reducing signi-\cant prediction errors.

Weighted Quantile Sketch using histograms is now available as tree_method="hist',
which, since the 2.0.0 release, is the default method. In contrast, the approx
method generates a new set of bins for each iteration, the hist method reuses
bins over multiple iterations.

Another feature of the algorithm is related to data storage in DMatrices. The most
consuming-time part of training learning is sorting. To reduce the sorting cost, we
propose storing the data in-memory units: a block. This also linearly scanning over
t presorted entries and parallelizing, giving us an efficient algorithm for split
finding.

After the successful histogram aggregation implementation in LightGBM, XGBoost
adopt it. Histogram aggregation is also the main feature of HistGradientBoosting,
The Scikit-learn histogram-based gradient boosting we will present after LightGBM.
