# CHAPTER 3 Machine learning vs. deep learning

The Airbnb NYC dataset has characteristics that make it a good choice for comparing approaches to solving tabular data problems:

+   - It has a convenient size. With 49,000 records, it is big enough to be interesting not so huge that it requires special "big data" tools like Spark to handle it.

+   - It has a good number of columns for a comparison between machine learning and deep learning. As we will find out in subsequent chapters, a dataset with only three or four columns would immediately favor a classic machine learning approach. A dataset with hundreds of columns would be difficult to examine.

+   - The Airbnb NYC dataset has a "just right" number of columns—enough to give deep learning a chance to shine but not so many that the dataset is difficult for a human to comprehend.

+   - Because the dataset has a reasonable number of rows and columns, it is easy to take a quick look at it in a spreadsheet, which means we don't have to write Python code every time we want to answer a question about the dataset. A spreadsheet, when you sort, filter, and count aspects of the dataset quickly and advantage of scripting for Excel or Google Sheets to do a more detailed investigation. The Airbnb NYC dataset is amenable to being examined in a spreadsheet, which means it can be examined with minimal effort.

+   - The dataset includes an interesting range of column types, including several kinds of continuous columns (minimum_nights is integer values, price and reviews_per_month are point values, and latitude and longitude are geospatial values), categorical columns (neighborhood_group, neighborhood, room_type), and free-form text columns (name and host_name).

+   - The dataset has some warts—where there are missing values in some of the columns—but it is not so messy that it requires massive cleanup before it is used to train a model. This makes it convenient to build an application around this dataset without getting too disturbed by cleanup.

+   - It is open sourced and based on real data from a real business. As we will see in subsequent chapters of this book, one of the challenges of exploring machine learning and deep learning with tabular data is the scarcity of substantial tabular datasets that represent real business problems. The Airbnb dataset is a rare example of a nontrivial tabular dataset that contains information from a working business.

+   - With this dataset, the target for the model is price: In our case, we are deriving a target based on price—namely whether a given list will have a price that is above or below the median price for the listings in the dataset.
