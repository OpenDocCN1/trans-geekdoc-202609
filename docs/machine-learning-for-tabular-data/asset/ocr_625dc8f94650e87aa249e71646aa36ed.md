“Do Tree-Based Models Still Outperform Deep Learning on Tabular Data?” by Leo Grinzstein, Edouard Oyallard, and Gael Varoaux (Thirty-sixth Conference on Neural Information Processing Systems Datasets and Benchmarks Track, 2022; https://hal.science/hal-0372855v2/document) is a recent study that to shed light on the different performances of deep learning architectures and gradient-boosting decision trees. The study shows that tree-based methods outperform deep learning methods (even modern architectures) in achieving good predictions on tabular data. The authors explicitly focus on the heterogeneity of columns that tabular data from datasets with exclusively continuous features (we could refer to them as homogeneous datasets) and define a standard benchmark using 45 open datasets. They considered only about 10,000 samples, consisting of columns of different types, including numerical features with different units and categorical features, because that considered the typical situation with tabular datasets.

Various deep learning models, including multilayer perceptrons (MLPs), ResNets, SAINT, and FTTransformer, were tried, but tree-based methods were found to have performance with every hyperparameter tuning. When considering only numerical features, tree-based methods outperformed deep learning methods. This advantage became more pronounced when considering fitting time, although the hardware used (including GPUs) also influenced the results. The gap between the two methods was narrower on large datasets, which are not typical for tabular data.

The authors also investigated the features of tabular data that explain the performance difference between tree-based and deep learning methods. They found smoothing the outcome in feature space narrowed the gap deep architectures struggle with irregular patterns, whereas smoothness does not affect tree models. Removing uninformative features narrowed the gap for MLP-like neural architectures. However, it was only after applying random rotations to the data that deep architectures outperformed tree models.

Random rotations refer to applying a random rotation matrix to the input features of a dataset before feeding it into a machine learning model. This rotation matrix is square matrix that preserves the length of vectors and the angles between them, ensuring that the rotated data remains equivalent to the original data. Random rotations are used in machine learning for various purposes, including the diversity of ensembles, improving the robustness of models, and addressing rotation invariance in tasks such as computer vision and machine learning for quantum chemistry.
