# CHAPTER 2 Exploring tabular datasets

It is not unusual to look for outside data to start a project when you don't have similar data available in your systems or to experiment with some idea or machine learning. For instance, let's pretend you need to find external credit scoring for your project to build a model from scratch based on external data. Credit scoring is a computed quantification of person's or business's creditworthiness. Building a credit scoring model helps you run your business successfully, such as mortgages, auto loans, credit cards, and private loans, where you have to offer, extend, or deny credit. Credit can be used for risk-based pricing—that is, for setting a price for credit, given the risks of not repaying.

Looking, for instance, credit scoring as you would on the Google search engine will open up a panel on the left side of the browser listing a series of datasets that could satisfy your query. You can filter the results by recency of the data, format, license (to be addressed if you want to make commercial use of the data), costs, and category of interest. On the right panel, a description of the key characteristics of the chosen dataset appear, with a link allowing you to access the original repository where the data is stored and documented. To download the data, follow the instructions on each landing page you are pointed to.

To our know, Google Dataset Search is the best tool for finding the data you need or are looking. In addition, we would like to point out another resource available by Google through Kaggle to data science competitions that was acquired by Google in 2017. As you will surely notice, the search engine returns datasets hosted on the Kaggle platform using Google Dataset Search. After from offering a competition platform, Kaggle offers a data hosting service called Kaggle datasets, found at https://www.kaggle.com/datasets.

Kaggle Datasets is a service offered to platform users, allowing them to download data freely (sometimes they open-source) in exchange for points and rank in the gamified Kaggle system. The gaming formulation also pushes for data to be uploaded. Hence, you will find the latest data around, and you can expect them to be updated. The result is an impressive collection of data that is not all that is easy to find elsewhere, ranging from economic statistics to transaction collections that are helpful in building recommender systems from scratch. Depending on the engagement of the Kaggle user who that of the community, you may find documentation, data analysis, machine learning models, and discussion associated with the data.

If you find what you are looking for, you can download the Kaggle Dataset directly, using the download button shown in figure 2.4, after registering with the website. Registering also allows you to install and use the kaggle-api command (https://github.com/Kaggle/kaggle-api) to download datasets from the shell. For instance, after installing it, you can download the German Credit Risk data by the

```
kaggle datasets download -d uciml/german-credit
```
