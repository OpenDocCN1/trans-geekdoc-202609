## 7.2.4 Building a model

First, we choose an XGBoost regressor, trying to incorporate some of the insights gained from our EDA and baseline model inspections. We will see gamma objective function, commonly used in regression problems for modeling positive variables that are right-skewed. Gamma is particularly useful when the target variable is always positive, and it includes many small values and a few larger values, as it handles distribution well.

In addition, our baseline model has shown signs of underfitting not linearities properly; we decide on a max depth of most six for the decision trees composing the boosted ensemble, thus allowing for an adequate number of splits to handle most similar data characteristics. In the following listing, arranged similarly as the previous linear baseline, we use an XGBoost regressor and test its out-of-fold cross-validation predictions.

### 7.1 First XGBoost model

```python
from sklearn.model_selection import cross_validate
from sklearn.metrics import r2_score, mean_squared_error, mean_absolute_error
from xgboost import XGBRegressor

xgb = XGBRegressor(booster='gtree',
                  objective='reg:gamma',
                  n_estimators=300,
                  max_depth=6)

cv_splits = cv_split(
    x, y=['neighbourhood_more_than_30']
)
y_pred_cv = cross_val_predict(
    xgb, xt, cv=cv_splits
)
prediction_range = y_pred_cv.min() - y_pred_cv.max()
print(f'prediction range: [{prediction_range}]')

r2 = r2_score(y, y_pred_cv)
rmse = np.sqrt(mean_squared_error(y, y_pred_cv))
mae = mean_absolute_error(y, y_pred_cv)

print(f'R-squared: {r2:.3f}')
print(f'RMSE: {rmse:.3f}')
print(f'MAE: {mae:.3f}')

plt.scatter(y.min(), y.max()), [y.min(), y.max()], 'r--', label='Ideal Fit')
plt.axhline(0, color='orange', linestyle='--', label='Zero Line')
plt.xlabel('Actual')
plt.ylabel('Predicted')
plt.title('XGBoost - Fitted Results')
plt.legend()
plt.show()
```

This time, the prediction range is strictly in the positive range, as we expected. The MAE is almost half of those of the baseline model and the R-squared score almost 0.7, is a reasonably good result showing how the model is now able to intercept most of the variance in the target:
