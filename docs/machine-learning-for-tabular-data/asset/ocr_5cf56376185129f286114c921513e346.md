Validate the upload by making -ml_pipeline your current directory and using the ls command to ensure that the JSON service account key is now in this directory:

```
cd -/ml_pipeline
ls
```

Set the environment variable GOOGLE_APPLICATION_CREDENTIALS to the fully qualified filename of the service account key JSON file. replace the fully qualified filename with for your own service account key file:

```
export GOOGLE_APPLICATION_CREDENTIALS=
/home/ryannamark2023/ml_pipeline/
first-project-ml-tabular-039ff1f20a8.json
```

Confirm the value of the GOOGLE_APPLICATION_CREDENTIALS environment variable with the following command and validate that it is set to the fully qualified path of your service account key file:

```
echo $GOOGLE_APPLICATION_CREDENTIALS
```
