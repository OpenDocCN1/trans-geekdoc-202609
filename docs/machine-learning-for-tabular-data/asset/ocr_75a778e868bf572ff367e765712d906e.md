Listing 8.2 Import statements for the fastai solution
| pip install -Uqq fastbook | Installs the libraries for using fastai in a jupyter notebook |
| import fastbook | |
| from fastbook import * | Imports the libraries for using fastai in a jupyter notebook |
| from fastai.tabular import * | Imports the libraries for working with tabular datasets in fastai |

With these libraries imported as shown in 8.2, you have the libraries required to run a fastai data application in a Jupyter notebook.
