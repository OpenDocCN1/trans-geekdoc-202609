In 7.15, we define a function that can help us check for outliers. For each predictor, this function prints the coefficient and the resulting multiplication of the coefficient with the value of the feature for that case, making explicit the contributions of each feature to the prediction.

# Listing 7.15 Inspection of the coefficients

```
def report_case(model, data, feature_names, case_name):
    case_values = data[case_name] * model.coef_
    coef_values = case_values
    for feature_name, case_values, coef_values in zip(feature_names, case_values, coef_values):
        print(f"{feature_name:50s}: " + 
              f"{case_values:10.2f} = " + 
              f"{coef_values:0.2f}")
        print("-" * 80)
        print("*" * 66 + f"{np.sum(coef_values):+0.2f}")
```

> Extract the feature values for the specified case number from the data array

> Calculates the coefficient values for each feature by multiplying its value with the corresponding coefficient from the model

> Loops and prints through the feature names, their values, and corresponding values

> Prints the sum of the calculated coefficient values for the case
