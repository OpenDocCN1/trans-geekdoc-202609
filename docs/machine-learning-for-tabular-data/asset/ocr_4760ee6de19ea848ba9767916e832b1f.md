# 5.4 Using XGBoost

XGBoost gained traction after being successful in a Kaggle competition, the Higgs
Boson Machine Learning Challenge (https://www.kaggle.com/c/hig-boson), which
has been proposed in the composition for a fast and accurate solution
in comparison to Scikit-learn's gradient boosting. XGBoost has been adopted
successfully used in many other data science competitions, proving its effectiveness\and the usefulness of Kaggle competitions as a good place to introduce innovations
Keras is another example of an innovation that
widely adopted in Kaggle competitions. At the time of writing, the
XGBoost package has been updated and reached the milestone of version 2.0.3, which
is the version we have used in this book.

Initially conceived as a research project by Tianqi Chen, later further developed with
t contribution of Carlos Guistrin, XGBoost, is a gradient boosting framework avail-
able as open-source software. It is noticeable that to other initiatives, such as
LightGBM, sponsored by Microsoft, and Yggdrill Decision Forests (see https://-
bz/VY6) that Kaggle sponsors, XGBoost remained completely independent, main-
tained by the Distributed (Deep) Machine Learning Community (dmlc
github.io).

Over time, the framework has undergone significant enhancements and now pro-\vides advantages for distributed processing and parallelism, which\ables it to operate on large-scale datasets. While, XGBoost has also gained wide
adoption, and it is currently available in several programming languages, including
C/C++, Python, and R. Moreover, this framework is supported on multiple data-science
platforms, such as H2O ai and Apache Spark.

As a data science user, you will immediately notice key characteristics of the
framework, including

+   - The ability to handle various input data types
- Support for customized objective and evaluation functions
- Automatic handling of missing values
