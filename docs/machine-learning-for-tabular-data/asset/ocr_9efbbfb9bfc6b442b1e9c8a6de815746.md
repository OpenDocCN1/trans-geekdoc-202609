Note that the illustration doesn't contain any jargon or assume that the reader has any background in machine learning. The point of the decision tree is evident. This decision tree is a gross simplification, and there are important technical differences between a simple decision tree like this and a model that uses gradient boosting, XGBoost, for example, uses multiple decision trees, so this illustration by would not be sufficient to explain an XGBoost model. Nevertheless, it shows that, for some classic machine learning algorithms, it's possible to give intuition about how the algorithms work without forcing the nonspecialists to learn technical details about them.
