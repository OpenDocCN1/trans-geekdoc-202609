The distribution shown in figure 4.1 is extremely skewed to the right, with many outlying values being the plotted values up to 10,000. However, before 2,000, it is hard to distinguish any bar depicting such frequencies. This becomes even more evident by plotting a boxplot, which is a very useful tool when one wants to visualize the core part of the distribution of a variable. A boxplot for a variable is a plot where the key measurements of the distribution are depicted as a box with "whiskers": two lines outside the box that stretch to the expected limits of the variables' distribution. The box is delimited by the interquartile range (IQR), determined by the 25th and 75th percentiles, and split into two by the line of the median. The whiskers stretch up and down to 1.5 times the IQR. Everything above or below the edges is considered an outlier: an unusual or unexpected value. Let's plot a boxplot for the price variable, using a built-in method in pandas DataFrame, the boxplot method (see 4.2):

A long queue of outliers elongates from the upper limit of the upper extremity of the boxplot. This is an evident case of a skewed distribution. It is common practice to add a constant to offset the values into the positive number field for handling values of zero and below. ## 4.2.2 Pipelines preparation

We will use the previously seen Pipeline and ColumnTransformer classes from Scikit-learn to prepare the pipelines. In a building blocks approach, we first create the different operations to be applied to data types that characterize features.

The following code defines three procedures that will be reused multiple times:

- Categorical one-hot encoding—Categorical features are transformed into binary ones. If a value has never been seen, it will be ignored.
- Numeric pass-through—Numeric features are imputed using zero.
- Numeric standardization—After imputing missing values, numeric features are rescaled by subtracting their mean and dividing by their standard deviation.

The code defining these procedures is shown in the following list:

| List 4.2 Setting building blocks for tabular learning pipelines |
| :--- |

| sklearn.compose import ColumnTransformer |
| sklearn.preprocessing import OneHotEncoder |
| sklearn.preprocessing import OrdinalEncoder |
| sklearn.impute import SimpleImputer |
| sklearn.preprocessing import StandardScaler |

```python
categorical_onehot_encoding = OneHotEncoder(
    handle_unknown='ignore')
numeric_passsthrough = SimpleImputer(
    strategy='constant', fill_value=0)
numeric_standardization = Pipeline(
    ('imputation', SimpleImputer(strategy='median')),
    ('standardization', StandardScaler())
))
```

> Converts categorical features into one-hot format

> Replaces numeric values with zero

> Pipeline replaces missing values and standardizes the features
