# Digging Deeper

From the searches on Google Scholar and arXiv, it's clear that only a tiny proportion of the research published in deep learning deals with tabular data.

To summarize, we can conclude the following points about research on deep learning with tabular data:

+   - There are more publications that support deep learning with tabular data than there are publications that argue deep learning with tabular data.
- Several research papers on deep learning with tabular data include libraries that implement the approach described in the paper. So far, none of these libraries emerged as a clear favorite for data scientists who are interested in deep learning with tabular data.
- Of all the research done on deep learning, dealing with deep learning and tabular data makes only a tiny fraction.

With these conclusions, it's clear that neither machine learning nor deep learning is the unambiguous winner in the area of research. In the argument for and against deep learning with tabular data, when it comes to research, the jury is still out.
