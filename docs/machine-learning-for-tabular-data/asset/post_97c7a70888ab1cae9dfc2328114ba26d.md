
# Machine Learning

Ryan · Massaron · Foreword by Antonio Gulli

Machine learning can accelerate everyday business chores like account reconciliation, demand forecasting, and customer service automation—not to mention more exotic challenges like fraud detection, predictive maintenance, and personalized marketing.

> Explores the exciting potential of generative AI in tabular data analysis, showcasing its applications in synthetic data generation, feature engineering, and model interpretation.”—Gus Martin

> An invaluable, hands-on resource to learn practical machine learning techniques without getting lost in complex theory.”—Dmitry Efimov, Amazon

Machine Learning for Tabular Data provides ML techniques to upgrade every stage of the business analysis pipeline. In it, you will explore examples using XGBoost and Keras to predict short-term rental prices, deploying a local model with Python and Flask, and streamlining workflows using large language models (LLMs). Along the way, you'll learn to make your models both powerful and more explainable.

> Equips you with the knowledge to tackle any tabular data problem. Luca and Ryan have done a great job covering this field.”—Bojan Tunguz, Tabular.AI

# What's Inside

* XGBoost
* Apply deep learning to tabular data
* Deploy models locally and in the cloud
* Build pipelines to train and maintain models

> Helps unlock the full potential of machine learning for tabular data, enabling you to choose the best approach for your scenario.”—Shotaru Ishihara, Nikkei Inc.

For readers experienced with Python and the basics of machine learning.
