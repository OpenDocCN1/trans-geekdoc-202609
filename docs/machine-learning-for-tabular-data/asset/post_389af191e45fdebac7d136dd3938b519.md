## 11.2.4 Introduction to Cloud Shell

So far, all the actions that we have taken in Google Cloud have been in the Console UI. Google Cloud also includes the Cloud Shell, which is a self-contained instance that lets you run command line commands to interact with Google Cloud. In addition to the command line interface, you can use the Cloud Shell Editor to edit files in the Cloud Shell filesystem. With Cloud Shell, you get the function of a local Linux instance combined with the convenience of a web-based environment that is integrated with Google Cloud resources. Cloud Shell is particularly well-suited for prototyping and working through tutorials. We will use the Cloud Shell in the next steps of setting up the ML pipeline. For additional details about Cloud Shell, see the: https://cloud.google.com/shell.

To start the Cloud Shell, click on the Activate Cloud Shell icon at the top of the Google Cloud Console, as shown in figure 11.12.

![](img/def89cc476fa39f4c54bd34e78d91674_429_0.png)

When you click on the Activate Cloud Shell icon, the Cloud Shell terminates at the bottom of the console with your home directory as the current directory, as shown in figure 11.13.

![](img/def89cc476fa39f4c54bd34e78d91674_429_1.png)

You can run commands directly in the Cloud Shell Terminal, including standard Linux commands and Google Cloud-specific commands. You can click Open Editor to edit files in the Cloud Shell file system, as shown in figure 11.10.

## 11.2.5 Uploading the service account key

In this section, we will use the Cloud Shell to upload the service account key:

- In Cloud Shell, set your home directory as the current directory, create a new directory called ml_pipeline, and then set that as your current directory:

```bash
cd ~
mkdir ml_pipeline
```

To upload the service account key, select the three dots in the Cloud Shell and then select Upload, as shown in figure 11.2.

![](img/def89cc476fa39f4c54bd34e78d91674_430_0.png)

In the Upload page, update the Destination to be the ml_pipeline directory in your home, select the service account JSON file that you downloaded in 11.1.

Validate the upload by using the following command to ensure the service account key is now in this directory:

```bash
ls
```

Set the environment variable GOOGLE_CREDENTIALS to the fully qualified path of the service account key:

```bash
export GOOGLE_CREDENTIALS=/home/ml_pipeline/first-project-ml-tabular.json
```

Confirm the value of the GOOGLE_CREDENTIALS environment variable with the following command:

```bash
echo $GOOGLE_CREDENTIALS
```
