VAEs consist of an encoder and a decoder. Their function is to compress input data using the encoder to a state called the latent space, where the data information is highly compressed. Subsequently, the decoder decodes the data with high fidelity and reconstructs the original data. The underlying idea is that if the compression-decompression process is effective, the latent space encapsulates the core distributional information of the data, enabling the generation of new data. The architecture of VAEs is designed so that inputs are captured by the encoder and passed through a sequence of layers, which may consist of the same number of neurons or a decreasing number, reaching a layer representing the latent space. This layer serves as the starting point for the decoder.

How these deep learning approaches generate good data is proven by how data science competition platform like Kaggle uses synthetic data for its competitions. Due to the lack of tabular competitions, Kaggle has recently launched a series of competitions based on synthetic data that don't have anything to do from traditional ones based on curated data. The Tabular Playground Series has been a feature of Kaggle for the last two years and continues to do this (https://www.kaggle.com/competitions).

In 2.5, we use the sdv package to generate 10,000 additional examples from the original German Credit Risk dataset, made of 1,000 samples that we presented in the previous section. To install the sdv package on your system, use the following shell command:

```
pip install sdv
```

The sdv package, from an MIT initiative, is a set of open-source tools devised to help individuals and enterprises generate synthetic data starting from some original. Such tools use classical statistical methods, such as the Gaussian copulas which can reproduce the distribution of multiple variables simultaneously, and deep learning. The deep learning tools are based on GANs and VAEs. In our example, we found that a VAE architecture can be better and easily mimic the data at hand. You can find more information about the sdv package on the GitHub hub of the project (https://github.com/sdv-dev/sdv) or by reading the reference paper illustrating the method: Neha Patki, Roy Wedge, Kalyan Veeramachaneni, "The Synthetic Data Vault," IEEE DSAA 2016 (https://mng.bz/ga4V).
