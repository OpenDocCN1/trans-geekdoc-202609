The stacks we explored in this chapter, plus TensorFlow with Keras, a well-rounded set of options:

+   - TensorFlow with Keras is a rock-solid stack with a huge community of users. For just about any problem that you encounter with this stack, you can be that somebody else has hit the problem and posted a solution. The stack works flawlessly in Colab, so doing initial investigation is easy. TensorFlow with Keras is commonly used in production for all kinds of applications. On the downside, Keras does not have built-in support for tabular data, so you need to be prepared to write some custom code to tackle tabular data problems.
- PyTorch with fastai is designed to be easy to get started with, and it works flawlessly in Colab, so you can expect to prototype deep learning with tabular data
