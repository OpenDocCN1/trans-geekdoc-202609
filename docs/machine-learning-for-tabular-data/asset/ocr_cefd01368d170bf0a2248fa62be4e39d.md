Gradient boosting is based on decision trees, which are a form of analogy search because, as an algorithm, trees splits your dataset into parts where the features tend to be similar in values between themselves and map to similar outputs. The gradient part of the algorithm intelligently as multiple trees together for a better prediction, although it doesn't change the basic way in which decision trees behave. Deep learning, on the other hand, is purely on the principle of differentiation and nonlinear transformations, where the algorithm looks for the best weights to combine the transformed inputs.

These two different approaches result in quite different estimations whose errors tend to partially cancel each other out because they are strongly uncorrelated, in similar fashion to what actually happens in a random forest algorithm when we average the results of uncorrelated decision trees. This conclusion matches our experience comparing the results of gradient boosting and deep learning on the Tokyo Airbnb problem. The ensemble of the XGBoost model with the fastai model produced the best results, as shown in figure 12.3.
