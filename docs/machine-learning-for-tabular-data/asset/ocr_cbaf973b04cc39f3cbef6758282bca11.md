# Internet data

Now that we have created a plan for acquiring and assembling your data from various data sources such as relational databases, DWHs, and data lakes, we need to provide you with guidance on where to find additional sources of information on the internet. These sources will help you apply the deep learning and machine learning algorithms on different datasets or benchmark your models. In other words, we will help you locate online resources that you can use to increase and enhance the data you have acquired.

Concerning where to look for sources, there are specialized websites where tabular data is collected and utilized by researchers and practitioners. The best example is the UCI Learning Repository (https://archive.ics.uci.edu/). The machine learning community has used this for educational purposes and research on machine learning algorithms. We can also quote OpenML (https://www.openml.org/), the repository used by Scikit-learn, as a source for its examples. It is supported by the Open Machine Learning Foundation, a nonprofit whose mission is to make machine learning simple, accessible, and collaborative. It is also sponsored by private companies, such as Amazon, and universities. In both cases—UCI and OpenML—you can download each dataset following the instructions provided or by directly accessing the URL of itself. When use datasets from these sources, we will provide the Python code snippet to download the data directly to you.

Apart from these open repositories, many other websites offer a shorter selection of open data—provided freely for academic, scientific, or even commercial use (but you have to check the license they carry with). Governments, the scientific community, and sometimes private companies grant data to the public. You can get lucky and find free repository for your work by consulting the Harvard University Dataverse repository at https://dataverse.harvard.edu/ or by browsing the Dataset subreddit https://www.reddit.com/datasets/.
