However, before rushing to test transformation, it is important to verify if the obtained PDP average curve represents that feature's behavior under all circumstances. You can verify that using individual conditional expectation (ICE) plots. ICE plots are the significant components of the PDP curve. You can obtain ICE plots with a slight change in the previous code.

# Listing 6.6 ICE plots

```
import matplotlib.pyplot as plt
from sklearn.inspection import PartialDependenceDisplay

fig, axes = plt.subplots(rows=2, ncols=2, figsize=(8, 4))
fig.subplots_adjust(hspace=0.4, wspace=0.2)

PartialDependenceDisplay.from_estimator(model_pipeline,
    X_data,
    kind='both',
    subsample=30,
    features=['minimum_nights',
    'number_of_reviews',
    'calculated_host_listings',
    'availability_365'],
    count',
    ax=axes)

for ax in axes.flatten():
    ax.axhline(y=0.5, color='red', linestyle='--')
    ax.legend().set_visible(False)

plt.show()
```

> Creates a partial dependence plot showing individual and average effects

After running the PDP average curve, you may see the results, as shown in figure 6.3. You can see the same curve as before, represented with a dashed line, and a sample of 30 curves taken randomly from the sample. You can verify that the sampled curves are clustered together, approximately reproducing the shape of the average curve. In that case, you have a confirmation that the average PDP curve is representative of the behavior of the feature with respect to the target. Otherwise, as in our case, example if the curve appears different and dispersed, the other features somewhat mediate the feature's relationship because of collinearity or interactions, and you cannot benefit much from transforming the feature.

> Uses a random of 30% of data for plotting efficiency
