If you decide to use a deep learning solution for a tabular data problem, of
tfour we explored so far, which one should you use? Here is our overall advice:

+   - If you are new to deep learning and are primarily interested in exploring a solu-
out without immediately implement the solution in production,
fastai is the best choice. It is the simplest stack to use, and it has a big enough
community that you are not likely to be stuck with a problem that nobody
seen before. Fastai includes many convenience features to make it easy to work
tabular data, so you can rapidly prototype your solution. However, if you
need to move your solution rapidly to production, fastai is probably not your best
choice because it is not commonly used in production.
- If you are already comfortable with deep learning and you need to get an applic-
ation into production, we recommend the Keras stack. First, TensorFlow, the low-\level component of the stack, is the deep learning framework that is most
commonly in industry. Second, Keras has a huge user community. While Keras
does not have native support for tabular data the same way that fastai does,
Keras is high-level enough to lend itself to tabular data problems.

This advice may change as more people use deep learning with tabular data. One of
the other stacks, as TabNet on PyTorch, could mature and become the default
choice for deep learning with tabular data. However, looking at the current state of the
art, we recommend fastai for beginners and explorers Keras for people who are
more experienced and need to proceed to production rapidly.
