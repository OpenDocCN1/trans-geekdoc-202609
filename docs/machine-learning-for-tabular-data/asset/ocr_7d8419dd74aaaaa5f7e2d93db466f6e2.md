The algorithm optimizes a proxy function, to increase the algorithm's performance. Of course, the surrogate function is updated by the feedback from the objective function of the machine learning model under optimization. However, the Bayesian optimization's decisions are solely based on the surrogate function.

In particular, it is another that alternates exploration with exploitation: the acquisition function reports how much exploring a combination of parameters is promising and how much is uncertain, based on the surrogate function. Exploration implies trying combinations of the parameters that have never been tried, and this happens when there is much uncertainty, and then consequently, in areas of the search space that need at least be to improve the surrogate function. On the contrary, exploitation ensures that the algorithm can improve performance when trying a set of hyperparameters.

As the "Bayesian" in the names, and from our brief description of how the Bayesian optimization works under the hood, the process is influenced by prior expectations and subsequently corrected by posterior observations in a fine-tuning cycle. Usually, the surrogate function in all of this is nothing more a model of our model. Usually, Gaussian processes are chosen as a model for the surrogate function. Still, there are alternatives, such as using tree algorithms such as forests or structured Parzen estimators, which are a multivariate distribution capable of describing the behavior of the hyperparameters in our model. Packages like Scikit-optimize (https://scikit-optimize.github/) or KerasTuner (https://keras.io/keras_tuner/) are Gaussian, with Scikit-optimize also capable of using tree ensembles and KerasTuner using bandits, as well. Optuna, an optimization framework developed by Preferred Networks, a Japanese research and development company, use tree-structured Parzen estimators. Initially released in May 2019 as an open-source project, Optuna is particularly popular in the Python machine learning community due to its simplicity, versatility, and integration with popular machine learning libraries such as TensorFlow, PyTorch, and Scikit-learn.

In our example, we use Optuna to improve our XGBoost classifier. When using Optuna, you just set up a study and define its running parameters, as the number of trials, and define the parameter if you want to minimize or maximize your objective function. Behind the scenes, the heavy lifting is done by the objective function, which you define and return an evaluation. The objective function expects just as an input parameter, which Optuna provides. By the trial parameter, you define the values of the hyperparameters to test. Then, you just test them because it is up to you inside the objective function to decide if to apply a cross-validation, a simple test on a sample, or anything else.
