# Predicting Airbnb prices in New York City

| Cohn | Description | Type |
|---|---|---|
| id | unique identifier for the host | numeric ID |
| name | name of the host | free-form text |
| host_id | unique identifier for the person who is the host | numeric ID |
| neighborhood_group | borough of New York City where the host is located | categorical |
| neighborhood | neighbourhood where the host is located (a subdivision of the neighborhood) | categorical |
| latitude | latitude of the listing | continuous - geospatial |
| longitude | longitude of the listing | continuous - geospatial |
| room_type | the accommodation provided by the listing | continuous - floating point |
| price | cost of the stay | continuous - integer |
| minimum | minimum number of nights that the listing can be booked | continuous - integer |
| number_reviews | number of reviews that the listing has received | continuous - integer |
| last_review | date the last review was published | Date |
| reviews_per_month | average number of reviews per month that have been published | continuous - floating point |
| calculated_host_listings_count | total number of listings that the same has as this host | continuous - integer |
| availability_365 | number of days that the listing is available | continuous - integer |
