From 10.5 we can see the main actions taken by the load-selections() JavaScript function:

+   - For continuous fields, the default value. This is the value that appears in the field when the page is initially loaded and passed along to the Flask server model if the user doesn't change it.
- For categorical fields, define the values from which the user can select and update the field's selection list with. In home.html, these values are defined in a hard-coded list. In a more robust web application, these values would be maintained in a control file separate from the code to make it easier to maintain the values and reduce the chance of adding registers to the code.
