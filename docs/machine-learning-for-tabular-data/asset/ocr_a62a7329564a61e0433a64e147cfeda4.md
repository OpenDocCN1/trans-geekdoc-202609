# Prints the resulting
Cramer's V

Returns the score, the p-value,
drees of freedom, and the expected
table based on marginal correlation

In the code, by the chi-square score and the table itself, we call the Cramer-V
function to get a 0.855 value for Cramer's V comparing MPG and the year of
model. Cramer's V is a reciprocal measure to identify features with a similar role in
prediction. Unidirectional measures, Cramer's V is sensitive to feature swapping.
This property allows for identifying highly correlated features that can be removed
from the analysis. A very high positive or negative correlation between features may
indicate redundancy, and one of the two features can be dropped.
