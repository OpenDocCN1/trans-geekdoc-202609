However, before applying transformations, you need to understand your data. Linearities and nonlinearities, even if there is no relationship with the target, can be easily spotted after fitting your training data by a partial dependence plot (PDP). This model-agnostic chart explains how features and targets are related through the model you have trained.

PDPs display how the target output changes based on specific input features ignoring the effects of other features. In other words, it shows the average expected prediction if we set a value on all the data points of the specific input feature we are examining. Assumption underlying the analysis is the input we represent by a PDP is independent of other features. Under such conditions, the PDP represents how the input directly affects the target. However, this assumption is violated in practice, meaning that the input feature we are examining is usually completely independent of the other features. As a result, the PDP typically shows how the target value changes as we vary the input feature, while also reflecting the effects of other features in the model.

In listing 6.5, we explore PDPs' possible usage and limitations. Given an XGBoost model trained on our Airbnb dataset, we demonstrate how our target changes regarding our numeric features, trying to spot any nonlinearities or other characteristics of the modeled data.
