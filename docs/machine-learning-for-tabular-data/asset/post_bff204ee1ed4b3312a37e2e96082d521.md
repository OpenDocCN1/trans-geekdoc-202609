# 7.1.5 Exploring and fixing your data

The next step after having assembled all the predictors into a single dataset is to explore it to detect any problems, such as missing data or extreme values, that may affect the performance of machine learning algorithm. Therefore, our first action is to check for any missing data with the following:

```python
X.isna().sum()
```

The resulting list points out there are three features with some missing data:

| days_since_last_review | 1252 |
| reviews_per_month | 1252 |
| score | 238 |

As discussed in chapter 2 and then in the previous chapter, it is crucial in the presence of missing data to investigate why there are values and if they could be deemed completely random, at random, or not random. In this specific case, missing values are not all, but they depend on the fact that there are enough reviews to compute a score. In fact, by inspecting how many accommodations are without reviews, you will notice how the number of cases matches:

```python
(X.number_of_reviews==0).sum()
```

As anticipated, the result is 1252, matching the number of missing values. In this case, it is better to refrain from using the capabilities of XGBoost and other GBDT methods because its behavior will mimic an average distribution. A common strategy is to use a negative number at the boundaries of the existing distribution if we are representing counts or positive values. A quick check can ensure us if there are prerequisites for such strategy:

```python
X["days_since_last_review", "reviews_per_month", "score"].describe()
```

As a result, the minimum value is always greater than zero for all three features. We can simply replace the missing values using -1 (we cannot use zero because the minimum value is zero for days_since_review), which will work as a solution for a linear model (it is at the lower of the distributions) and for tree-based ensembles (it will split on that feature):

```python
X.fillna(-1, inplace=True)
```

By inspecting the values outside the whiskers of the plots, represented as empty points, we immediately notice that almost all the distributions have heavy tails on the right, with values much larger than the mean value. For distance-based features, such extreme values may sound reasonable because of the extension of Tokyo’s metropolitan area, as features such as minimum night and number_of_reviews, extreme values may represent outliers far from the core of the distribution. We could use winsorizing to solve such problem, using a solution we proposed in chapter 2. This data transformation replaces extreme values in a dataset with less extreme values to reduce the influence of outliers on statistical analysis and modeling.

In Listing 7.9, using the winsorize function from the Scipy package, we winsorize the 0.1% of the upper part of the distribution of the minimum_nights feature. All values above the 0.999 percentile will be changed to the value of the 0.999 percentile, thus removing extreme values.
