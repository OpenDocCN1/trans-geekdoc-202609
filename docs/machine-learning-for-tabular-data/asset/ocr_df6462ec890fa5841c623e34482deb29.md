# 3.1.3 A deep learning solution using Keras

Before digging deeper into the details of the Airbnb dataset and the code used in the solutions, let's put the Keras solution into context of its software stack. Figure 3.4 shows the stack for the Keras solution to the Airbnb price prediction problem.

| Airbnb NYC solution |
|---||
| Low-level framework | TensorFlow |
| High-level API | Keras |
| Custom code | get_model() function that defines the Keras layers in the model for each column type |

> Figure 3.4 The stack for the Airbnb NYC solution shown in figure 3.4.

In chapter 8 we will go into more detail about the stack layers shown. For now, we can observe that Keras is the high-level deep learning API that we use to implement the deep learning solution to the Airbnb problem that we will examine in this chapter. There are two low-level deep learning frameworks, and the learning solution we will examine in this chapter depends on the TensorFlow low-level framework because that is the framework on which Keras is built.
