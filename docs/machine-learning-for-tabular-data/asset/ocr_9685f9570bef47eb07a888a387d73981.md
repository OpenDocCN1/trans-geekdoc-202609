Many of these tasks can extend to the work of a data scientist or a data engineer. LLMs can support the user in activities such as feature engineering, coding functions, and visualization instructions (for instance, using commands from the matplotlib package), providing analytical advice, helping interpret results, and synthesizing collectively for charts and reports. One notable application of LLMs in tabular data is automating textual data-related tasks. When dealing with textual fields, they can engineer new features by summarizing, categorizing, and identifying keys. They can also develop the code to process the same text in Python, for instance, by creating functions or figuring out the correct expression for text processing.

Besides supporting the user and being a useful assistant, LLMs can also play a more direct and active role in analytics. Recent applications for ChatGPT (the Advanced Data Analytics API) also provide data analysis in CSV format, followed by other related tasks, including summarizing, preprocessing, analysis, and report generation. At each step, the tool can provide the Python code to execute and obtain visualizations in charts and tables. With MediTab, TableGPT (https://arxiv.org/pdf/2307.08674.pdf) is a new framework that utilizes LLMs to enhance human interaction with tabular data. It enables users to interact with tables using commands expressed in natural language and perform various tasks such as question answering, data manipulation, data visualization, report generation, and automated prediction. MediTab (https://arxiv.org/pdf/2305.12081.pdf), instead, works on medical data by consolidating tabular samples, aligning out-domain data with the target task, and expanding the training data. Faced with prediction tasks on tabular data, it demonstrated demonstrated performance over classical machine learning algorithms as XGBoost.

Generally speaking, LLMs offer no comparable performance in prediction tasks on tabular data, as demonstrated by the TABLET (https://arxiv.org/pdf/2304.13188.pdf). In assessing LLMs' performance relative to fully supervised models, the compared Flan-T5 1b and ChatGPT at 4-shot examples outperformed XGB. The XGBoost model, when applied to all the data, achieved an F1 score of 0.94 on the prediction tasks. In contrast, ChatGPT achieved a score of 0.66, and Flan-T5 1b achieved a score of 0.66. This analysis highlights that there is still a significant margin for improvement in predictive tasks for LLMs involving tabular data with multimodal types (text and numbers) and that tools continue to excel in executing instructions, particularly when working with textual inputs and producing textual outputs.
