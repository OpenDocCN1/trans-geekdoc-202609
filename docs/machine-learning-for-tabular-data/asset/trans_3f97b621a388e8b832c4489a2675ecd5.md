在列表 7.9 中，使用 Scipy 包中的 winsorize 函数，我们对 minimum_nights 特征分布的上部 0.1% 进行缩尾处理。超过 0.999 分位数的所有值将被更改为 0.999 分位数的值，从而消除了极端值。
