Being on the lookout for errors in data, it is now time, to examine closely the categorical features, the numeric ones too. Here, boxplots and histograms represent category counts, and the focus is widened from single features (the so-called univariate approach) to more features together. You value in the features of an example may appear erroneous re se. Still, if all values are taken together, you may realize that their combination is highly unlikely, if not the result of some error. You starting the distributions by boxplots. A boxplot, also called a box and whiskers plot, the key characteristics of a distribution using the boundaries of a box: you can see the first quartile (Q1) and the third quartile (Q3) as the top and bottom sides of the box (the median, Q2, is represented inside the box). Its whiskers represent the farthest points in directions, not exceeding Q5 + 1.5 × IQR (as a reminder, IQR is the difference between Q3 and Q1). Outlying observations beyond such boundaries are plotted as separate points, and you can immediately spot if there are present and how many there are. Since a boxplot scales to the unit measures of the features you represent, if you are are to compare multiple boxplots with the numeric features for your distributions, you need first to standardize them by subtracting the mean and divide by their standard deviation:

```
standardized = ((data[numeric_feats] - data[numeric_feats].mean()) / data[numeric_feats].std())
standardized.boxplot(column=numeric_feats, figsize=(12, 4))
```
