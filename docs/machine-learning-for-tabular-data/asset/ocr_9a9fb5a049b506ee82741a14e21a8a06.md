Once completed, the examples from the synthetic data resemble the sample from the original data, but if you need more formal proof, you must resort to an adversarial validation evaluation, where a machine learning algorithm is challenged to distinguish between the original and generated data. One machine learning algorithm is more at detecting even subtle patterns in data; hence, it can be confused when distinguishing between original and generated data, the generated data is assumed to be of good quality.
