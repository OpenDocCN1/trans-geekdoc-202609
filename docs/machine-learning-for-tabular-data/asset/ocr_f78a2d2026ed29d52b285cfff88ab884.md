# Listing 9.6 Function to clean up the Price column

```
def clean_up_price_col(df):
    df.dropna(subset=['Price'], inplace=True)
    df['Price'] =
    df['Price'].apply(lambda x:
        remove_currency_symbol('RM ', x))
    df['Price'] =
    pd.to_numeric(df['Price'],
        str.replace(',', '', errors='coerce')
    return df
```

![](bbox=[0.583, 0.566, 0.891, 0.693])

As shown in 9.6, the clean_up_price_col() function removes rows with Price values. The rationale for removing these (as opposed to replacing missing values with placeholder) is that Price is the target for our model; hence doesn't work to keep rows where such a value is missing. The output of the clean_up_price_col() function is a dataframe with valid numeric values in all rows for the Price column.
