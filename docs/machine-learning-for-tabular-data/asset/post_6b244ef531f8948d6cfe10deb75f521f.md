# 8.2.2 Comparing the fastai solution with the Keras solution

We have seen two deep learning solutions to the Airbnb NYC listing prediction problem: the Keras solution and the fastai solution. In this section, we'll compare the two solutions and revisit the pros and cons of each.

Fastai and Keras solutions make interesting comparison points because they are very different. The Keras solution contains a lot of custom code, and all the details are evident. The fastai framework infers details about the model from the dataset and makes assumptions about the defaults to use so that there aren't many parameters that we need to specify to get a working model. The benefit of this is that the fastai code is much more compact than the Keras code. In particular, the Keras solution has multiple lines of code to specify the pipeline and the details of the layers that make up the model. In fastai, we get the pipeline for free by simply specifying the transformations we applied to the input data (as shown in 8.6), and we don't need to specify the layers that make up the model.
