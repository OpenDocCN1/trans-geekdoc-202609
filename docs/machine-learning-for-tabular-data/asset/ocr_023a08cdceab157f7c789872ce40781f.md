Thelinear booster promotes a sum of chained linear models. Since a sum of linear combinations is linear, you end up with a coefficient for each feature you have used, similar to a linear model. You can access the coefficients using the .coef method. It is a different way to fit a GBDT with an emphasis on interpretability since the model can be reduced to a linear combination, from the one you could directly fit because of using a different approach for complexity penalization and optimization.
The most notable difference is that you cannot interpret the coefficients as you would if a linear regression or a generalized linear model produced them. Furthermore, the interpretation of the intercept generated by the glinear booster from classifier linear models as it is influenced by both the learning rate and the initial estimate

The dart booster is different because it combines the optimization based gradient descent with a similar approach, the technique used in deep learning. Presented by a UC Berkeley researcher and a Microsoft researcher in the paper “DART: Dropouts Meet Multiple Additive Regression Trees” by Rashid Koralai Vinayak and Ran Gil-Bachrach (Artificial Intelligence and Statistics. PMLR, 2015), DART focuses on overfitting due to the dependence of each tree's estimates on the previous nodes. The researchers then take the idea of dropout from deep learning, where a dropout mask randomly and partially blocked a neural network layer. The neural network cannot always rely on signals in a particular layer to determine the next layer’s weights. In DART, the gradients are not calculated up to the sum of the residuals from all previously built trees. Still, the algorithm at each iteration randomly selects a subset of the trees and scales their leaves by a factor of 1/k, where k is the number of trees that were dropped.

The glinear and the dart are the only alternative boosters available. For instance, there is no booster to mix random forests (as is for GBM implementation, LightGBM). Although a random forest booster is not supported by XGBClassifier and XGBression, you can obtain a similar result by playing with XGBoost parameters and functions:

+   - Use the num_parallel_tree parameter and set it to a number above 1. At each step of the optimization, the gradients are estimated not from a single decision tree but from a bagged ensemble of decision trees, creating a boosted random forest model. In some instances, this approach may provide better results than the gradient boosting approach because it will reduce the variance of the estimates at the expense of an increased computational cost.

+   - Use the XGBClassifier or XGBRegressor, two classes from XGBoost implement a random forest approach. These classes are still experimental.
