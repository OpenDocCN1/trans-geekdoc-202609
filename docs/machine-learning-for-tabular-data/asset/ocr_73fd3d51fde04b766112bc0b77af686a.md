# 11.2.2 Creating a service account

The ML pipeline uses a service account to authenticate the service account used to run the ML pipeline.
To create a service account key, follow these steps:

+   1. In the Service accounts page, click on the email address for the service account that you just created, as shown in figure 11.6.

Service accounts for project 'first-project-ml-tabular'
A service account represents a Google Cloud identity, such as code running on Compute Engine VMs, App Engine apps, or syst accounts.

Organization policies can be used to secure service accounts and block risky service account features, such as IAM Grants, entirely. Learn more about service account organization policies.
