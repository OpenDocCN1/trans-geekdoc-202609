With 53 non-zero coefficients, the number of working coefficients has halved. By increasing the alpha parameter of the Lasso call, we can obtain an even sharper reduction of used coefficients, albeit at the price of a higher computation time. There's a sweet spot after which prediction purposes, you have a higher L1 penalty doesn't improve the prediction results. For find the correct alpha by trial and error or using convenient automatic functions as LassoCV (https://mng.bz/1XOv) or RidgeCV (https://mng.bz/Pdn9) that will do the experimentation for you.
