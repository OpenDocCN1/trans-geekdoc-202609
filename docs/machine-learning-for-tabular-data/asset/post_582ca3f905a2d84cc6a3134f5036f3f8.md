Using callbacks to control the training process is a best practice for deep learning models with Keras it allows us to use the resources to train the model efficiently. Instead of running through all the epochs and getting the performance of the model from whatever happened to be in the last epoch, we can use callbacks to stop the training process if it is improving for a few more epochs. We can ensure that the outcome of the training process is optimal for the whole training process.

# 9.4.1 Cross-validation in the training process

In chapter 4 we highlighted cross-validation (that is, segmenting the dataset and repeatedly training the model on different subsets of the data with different holds to validate the model) as a best practice for classic machine learning approaches. Do we need to worry about cross-validation for deep learning with tabular data? The short answer is "no." In Keras, by default, when we do repeated runs with proportions of the dataset specified to use for training, validation, and testing, the subsets of the dataset that get put in each category are randomized, so we will get the benefits of cross-validation with Keras if we repeated training runs (https://mng.bz/jpPz).
