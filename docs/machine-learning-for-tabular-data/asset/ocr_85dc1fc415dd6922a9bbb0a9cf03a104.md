# Building and optimizing your model

After running the code, we obtain the evaluation results, and we can immediately notice some predictions are negative. Since a linear regression is not bounded in its predictions, the mean absolute error (MAE) is quite high (over 12000 Yen), and the R squared, a typical measure of fitting how much of the variance of the target is captured by the model, just a modest 0.32:

```
prediction range: -34929.50241836217 - 13649.60736257263
R-squared: 0.320
RMSE: 17197.323
MAE: 12568.371
```

Clearly, the fitting of the model is not particularly impressive, and we can get a confirmation as shown in Figure 7.11, where we represent the scatterplot of the cross-validation predictions on the y-axis against the expected target values on the x-axis. Apart from a few negative predictions at the start of the target distribution, we can also notice how the predictions depart from the ideal dashed line, showing a flat trend, and how there are a few outlying predictions.
