
# Machine learning vs. deep learning

This chapter covers

- A comparison of machine learning and deep learning as methods to tackle tabular data problems
- A comparison of machine learning and deep learning in terms of simplicity
- A comparison of machine learning and deep learning in terms of transparency
- A comparison of machine learning and deep learning in terms of efficacy

There’s an open debate in the data science community about the best machine learning approach for tabular data. Some assert that classic machine learning techniques, such as gradient boosting using tools like XGBoost or LightGBM, are superior for most tabular data problems. Others advocate for including deep learning in your analysis toolkit. In this chapter, we’ll examine these two approaches using concrete examples:

- Predict the price of Airbnb New York City listings. In this example, we use a real-world of Airbnb listings to train models that predict whether a new listing will have a price above or below the average listing price. We'll use this example to examine simplicity, transparency, and efficacy.

- Predict the length of time property in a local real estate market is on market before it is sold. In this example, we use a contrived real estate dataset to illustrate the explainability aspect of transparency.

We will focus on three criteria that are of particular value in interpreting scientific and business data:

- Simplicity—The simpler solution in terms of the code for the application and the code API of the framework, the better.

- Transparency—A solution that is interpretable and can be explained easily to a business stakeholder is better.

- Efficacy—The solution that provides the best results and takes less time to train and implement is preferable. Also, research interest can lead to more effective results as new approaches are discovered.

## 3.1 Predicting Airbnb prices in New York City

To compare the similarity of machine learning and deep learning, we will contrast two solutions to a particular tabular data classification problem: predicting whether a New York City Airbnb listing has a price that is greater than or less the average price for Airbnb listings in that market. The two solutions we will compare are

- Machine learning—Represented by a solution that uses XGBoost, popular gradient-based approach.

- Deep learning—Represented by a solution that uses the Keras functional API.

We will compare the deep complexity of these solutions and review how these two solutions tell us about the overall question of the relative simplicity of machine learning and deep learning approaches.

# CHAPTER 3 Machine learning vs. deep learning

The Airbnb NYC dataset has characteristics that make it a good choice for comparing approaches:

- It has a convenient size. With 49,000 records, it is big enough to be interesting not so huge that it requires "big data" tools like Spark to handle it.

- It has a good number of columns for a comparison between machine learning and deep learning. As we will find out in subsequent chapters, a dataset with only three or four columns would immediately favor a machine learning approach. A dataset with hundreds of columns would be difficult to examine.

- The Airbnb NYC dataset has a "just right" number of columns—enough to give deep learning a chance to shine but not so many that the dataset is difficult for a human to comprehend.

- Because the dataset has a reasonable number of rows and columns, it is easy to take a quick look at it in a spreadsheet, which means we don't have to write Python code every time we want to answer a question about the dataset. A spreadsheet is amenable to being examined with it.

- The dataset includes an interesting range of column types, including several kinds of continuous columns (minimum_nights is integer values, price and reviews_per_month are point values, and latitude and longitude are geospatial values), categorical columns (neighborhood_group, neighborhood, room_type), and free-form text columns (name and host_name).

- The dataset has some warts—where there are missing values in some of the columns—but it is not so messy that it requires massive cleanup before it is used to train a model. This makes it convenient to build an application around this dataset without getting too disturbed by cleanup.

- It is open sourced and based on real data from a real business. One of the challenges of exploring machine learning and deep learning with tabular data is the scarcity of substantial tabular datasets that represent real business problems. The Airbnb dataset is a rare example of a nontrivial tabular dataset that contains information from a working business.

- With this dataset, the target for the model is price: In our case, we are deriving a target based on price—namely whether a given listing will have a price that is above or below the median price for the listings in the dataset.
