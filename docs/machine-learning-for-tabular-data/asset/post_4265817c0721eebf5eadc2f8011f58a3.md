model_args = ['--config_bucket', config['config_bucket_path']]

- Create a CustomTrainingJob object that specifies the location of the training script script_path, the prebuilt image used for training container_uri, and any additional Python libraries that need to be installed in the training container requirements, as shown in the following listing.

### Listing 11.5 Creating a CustomTrainingJob object

```python
def create_job(config):
    model_display_name = '{}-'.format(config['ENDPOINT_NAME'], TIMESTAMP)
    job = aiplatform.CustomTrainingJob(
        display_name='{}'.format(config['model_display_name']),
        script_path=config['script_path'],
        container_uri=config['train_image'],
        staging_bucket=config['staging_path'],
        requirements=config['gcs_path'],
        model_serving_container_image=
    ).deploy(config['deploy_image'])
    return job
```
Sets the pretrained Vertex AI container to run the training script
Defines the list of any additional requirements to be installed in the container to use for prediction

### Listing 11.6 Running the job

```python
def run_job(job, ds, model_args, config):
    model_display_name = \
        '{}-'.format(config['ENDPOINT_NAME'], TIMESTAMP)
    model = job.run(
        dataset=ds,
        training_fraction_split=,
        validation_fraction_split=config['validation_fraction_split'],
        test_fraction_split=config['test_fraction_split'],
        model_display_name=model_display_name,
        args=model_args,
        machine_type=config['machine_type']
    )
    return model
```
Associates the job with the managed dataset
Sets proportions of the dataset to use for training, validation, and testing
Sets the argument list (which contains the URI for the testing script config file)

- Create an endpoint and deploy the model trained in the training script to that endpoint.

### Listing 11.7 Deploying the trained model to an endpoint

```python
def deploy_model(model, config):
    endpoints = aiplatform.Endpoint.list(
        filter=display_name="{}".format(config['ENDPOINT_NAME']),
        order_by='create_time desc',
        project=config['project_id'],
        location=config['region']
    )
    endpoint = aiplatform.Endpoint.create(
        display_name=config['ENDPOINT_NAME'],
        project=config['project_id'],
        location=config['region']
    )
    model.deploy(
        endpoint=endpoint,
        traffic_split={"0": 100},
        machine_type=config['machine_type_deploy'],
        min_replica_count=1,
        max_replica_count=1
    )
```
Sets characteristics of the endpoint
Creates the endpoint
Deploys the model to the endpoint

- The following is the main function of the pipeline script that invokes the functions to run the pipeline.

### Listing 11.8 Main function of the pipeline script

```python
start_time = time.time()
config = get_pipeline_config('pipeline_config.yml')
model_args = ['--config_bucket', config['config_bucket_path']]
job = create_job(config,
    dataset_path=f'{config['project_id']}/'
    '/locations/{config['region']}/'
    '/datasets/{config['dataset_id']}'),
ds = aiplatform.TabularDataset(dataset_path)
model = run(job, ds, model_args, config)
if config['deploy_model']:
    deploy_model(model, config)
print("pipeline completed")
```
Sets characteristics of the endpoint
Creates the endpoint
Deploys the model to the endpoint

To run the pipeline script, do the following:

- Clone https://github.com/lmassaron/on_data in a new directory in Cloud Shell and make it current.

- Update the pipeline config file to ensure that project_id and region match your project, dataset_id matches your managed dataset, staging_path matches your staging path, and config_bucket_path matches the location in Cloud Storage, where you copied the training script config file, as shown in figure 11.33.

```

region : 'us-central1'
dataset_id : '29031a547263119872' # locations

config_bucket_path : 'gs://third-project-ml-tabular-bucket/training_scripts/model_training_config.yml'
```

- In the root directory where you cloned the repo, enter the following command:

```bash
python pipeline_script.py
```

Note that running the entire pipeline script can take 10 minutes or more. If the script fails, you will get a message that includes a link to the log file containing diagnostic messages about your training. If the script succeeds, the output will end with the pipeline completed.
