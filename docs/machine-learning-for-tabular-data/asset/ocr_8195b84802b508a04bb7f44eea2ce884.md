# 10.1.4 The show-prediction.html page

Now that we have looked at the Flask server module and home.html, there is one more component of the web deployment to examine: show-prediction.html. This page displays the prediction that the model makes for the property that the user entered in home.html and has a button that takes the user back to home.html, where they enter values for another property.
