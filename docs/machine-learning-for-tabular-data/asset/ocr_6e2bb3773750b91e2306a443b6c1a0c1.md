- linear_ for L1 and L2 penalties—better for smaller datasets, limited to one-
versus-rest schemas for multiclass problems.
- newton-cg for L2
- newton-cholesky for L2 or no penalty.
- sag for no penalty—ideal for large datasets. It requires standardized fea-
tures (or all with similar scale/standard deviation).
- saga for penalty, L1, L2, elasticnet (a mix of L1 and L2) penalties—ideal for
large datasets, it requires standardized features (or all with similar scale/
standard deviation).
