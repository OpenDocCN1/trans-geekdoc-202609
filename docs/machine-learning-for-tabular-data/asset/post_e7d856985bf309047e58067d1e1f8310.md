What's the difference between the response you get from the tuned model and the untuned foundation model? With the tuned model, you get all the capability of the foundation model along appropriate responses for the medical transcript classification case.

If you examine the dataset that we used to tune the foundation model the URI gs://cloud-samples-data/vertex-ai/model-evaluation/peft-train_sample.json you will notice that it is, in fact, a tabular dataset with two columns: one containing medical transcription notes and the other containing a category for the notes, such as "cardiovascular / pulmonary," "pediatric," or "pain management." So far in this book, we have examined how generative AI can be applied to the workflow for machine learning on tabular data. The example used in the log experiment demonstrates a different kind of relationship between tabular data and generative AI: tabular data being a detailed examination of this subject is beyond the scope of this book, but we think that the role of tabular data in generative workflows is an undersearched area that could yield significant benefits.

In this section, we have seen how we can use Gemini for Google Cloud's generative AI to answer questions about ML pipelines, generate some of the code to create one, explain the code that makes an ML pipeline

- A service account needs to be created, so the service account key needs to be uploaded to the directory where you run the pipeline script.
- The dataset that will be used to train the model in the pipeline needs to be uploaded to a Google Cloud Storage bucket. This bucket location needs to be defined as a Vertex AI dataset that will be used as an argument to the Vertex AI SDK in the pipeline script.
- The training code from the notebook that we ran in Colab in chapter 9 needs to be adapted to run in a container. For example, the training script needs to be updated to use the Cloud Storage locations for the config file, the training data, and the location where the trained model should be saved.
- The pipeline script invokes a series of functions from the Vertex AI SDK to create the container training script runs in, to run the training script, and to deploy the trained model to a Vertex AI endpoint.
