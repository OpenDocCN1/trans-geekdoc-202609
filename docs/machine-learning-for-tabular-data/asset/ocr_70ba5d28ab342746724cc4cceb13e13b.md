When the number of cases or the available features are many, the faster the LightGBM take a long time to train a model on such data. At training time, you can come long waits by reducing the cases and features by smaller values of the parameter subsample for limiting the cases involved in building each decision tree and the parameter colsample_bytree for limiting the number of features considered at tree splitting time.
