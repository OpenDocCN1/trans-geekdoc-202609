# 5.2.2 Extrapolating with gradient boosting

In our implementation from scratch of GBDT, we can visualize how the model fits by predicting the same training set. The visualization shown in figure 5.6, created by the code snippet in listing 5.8, is a normalized density histogram. In a normalized density histogram, the height of each bar represents the relative frequency of data points falling within a specific bin, and the total area under the histogram becomes 1. The result depicts a distribution of values predominantly polarized to the extremities of 0-1 boundaries, a model quite decisive in classifying the examples.
