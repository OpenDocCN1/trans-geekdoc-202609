# What makes tabular data different?

Here, contrary to structured tabular data problems, you don't have anything near the typical matrix-shaped format but different files or instances containing a multitude of information in an unordered way. Before deep learning revolutionized the unstructured data, unstructured data that we used for a predictive model had to be brought back into a structured data format by carefully creating well-defined and specific features (a procedure called engineering). For the type of unstructured data problems, researchers and practitioners took years to find the best features to be extracted from the data to feed a machine learning model and then obtain satisfactory predictive results.

Thanks to their representative power, deep learning models can handle all the necessary transformations to turn unstructured data into a viable prediction, and end-to-end fashion, from input to solution. Given this background, you might expect deep learning to be more effective on tabular data, but this has not been the case up.

There are, in truth, various reasons that can explain the challenge that deep learning faces with tabular data. The first reason involves the actual directions of academic research and private investment in new technologies and methodologies. As mentioned, in fact, researchers spent time and effort finding the best way to turn unstructured into structured data to fit the machine learning paradigm of the time. Nowadays some efforts are on advancing deep learning, particularly on unstructured data as it is easily available in public repositories and more "uniform" than tabular data, thus bringing more research success.

Image repositories such as ImageNet (https://imagenet.org/index.php) and open text corpora such as Wikipedia or the Commonl's web archive (https://commoncrawl.org/) are easily available to both researchers and practitioners to train or refine their deep learning models. As tabular data, there is no equivalent in terms of a common open-source data repository. On the contrary, tabular data is dispersed into a multitude of private databases, each one showing a higher degree of variability than unstructured data because each database has its own data collection rules and structure of features.

In addition to the fact that open-source tabular datasets representing real-world business problems are generally harder to find, you must also consider a second reason. Open-source tabular datasets are usually smaller in size and often quite different from the data that is owned privately by businesses and governments. Consequently, the lack of data usually causes neural networks to underperform. In addition, there is no golden rule to benchmark one's progress using a particular kind of data is limited to a specific problem in the vast domain of tabular data problems. For any researcher, it is much more challenging to generalize best practices starting from a tabular dataset, or even a limited choice of them, than to do the same using images, audio, or texts that are universally available and accepted as a reference benchmark.
