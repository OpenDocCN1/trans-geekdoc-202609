# CHAPTER 6 Advanced feature processing methods

To handle missing values in the predictors, an initial imputation step is performed using a simple method or another imputation estimate. Then, through multiple iterations, the imputation process refines the estimates by incorporating the results from the imputing models. This iterative process continues until the imputed values reach a state of stability, where further iterations do not lead to significant changes. Multivariate imputation is implemented in Scikit-learn by IterativeImputer (https://mng.bz/MDZQ). Inspired by the RICE mice (Multivariate Imputation by Chained Equations: https://mn.bz/aveJ), it allows for multivariate imputation and multiple imputations, a common approach in statistics and social sciences where instead of a single imputed value, you get a distribution of plausible replacements. Multiple imputations are possible with IterativeImputer running it multiple times with a random seed each time.

However, multivariate imputation is the favored choice in data science tabular applications because it allows building models based on simple but precise estimations. In our example, we use the Airbnb NYC dataset's continuous features and remove 5% of the data, mimicking an MCAR random. Afterward, we run a SimpleImputer, replacing missing values with a mean and an IterativeImputer. Finally, by using the mean error (MAE), the features reconstructed by each method match the original values.
