## 7.2.2 Preparing your pipeline

A second preparatory step is to define a pipeline for transforming our predictors in the most appropriate way for running generally with all classic machine learning algorithms, not just gradient boosting. Ideally, it would be better to have multiple pipelines based on how each model deals with the different features. For instance, in our pipeline, we are going to ordinarily encode a code of categorical features, and such encoding, for tree-based models, doesn't work properly with linear models. However, having unique pipelines can lead to better performance, and it can also become a maintenance nightmare. The human effort required to create and manage multiple pipelines may outweigh the marginal gains achieved by customizing each pipeline for specific models. Therefore it is better to decide on multiple pipelines if you have evidence that it is worth it.

In 7.13, we define all the necessary feature transformations and ensemble them in a Scikit-learn's ColumnTransformer, which will be part of the pipeline that also contains the machine learning model of our choice. It is also to note that we take steps in defining the column transformers to handle unknown categories and missing values that may unexpectedly appear at time. Our strategy for one-hot encoding is to ignore unknown categories. For ordinal encoding, the value assigned to the parameter unknown_value, which is by default np.nan, will be used to encode unknown categories. This means an XGBoost model will deal with such situations as missing cases using the most frequent split. Other machine learning algorithms might instead break such occurrences, which is an advantage of XGBoost. For the target encoder, the target mean is substituted for unknown categories. # Listing 7.13 Defining column transformations

```python
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline

```

Creates an Ordinal Encoder with handling of unknown categories and the unknown value by np.nan

```python
onehot_encoder = OneHotEncoder(handle_unknown='ignore')
ordinal_encoder = OrdinalEncoder(handle_unknown='encoded_value', unknown_value=np.nan)
```

```python
target_encoder = TargetEncoder(
    cols=target_encoding,
    handle_unknown="value",
    smooth=0.5
)
```

> Creates a TargetEncoder object, handling unknown values by encoding them the mean value and applying a smoother with a parameter of 0.5

```python
column_transform = ColumnTransformer(
    ('onehot_encoder', onehot_encoder, ordinal_encoding),
    ('ordinal_encoder', ordinal_encoder, ordinal_encoding),
    ('target_encoder', target_encoder, target_encoding),
    ('numeric', 'passthrough', numeric),
    ('binary', 'passthrough', binary),
    remainder='drop',
    verbose_names_out=True,
    sparse_threshold=0.0
)
```

> A Column Transformer object applying the specified encoders to the respective columns

> Drops columns that are not specified in the transformer

> Keeps verbose feature names for transformed columns
