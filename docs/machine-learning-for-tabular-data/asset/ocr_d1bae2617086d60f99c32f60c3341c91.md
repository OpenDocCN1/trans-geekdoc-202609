With Cloud Shell, you get the function of a local Linux instance combined with the convenience of a web-based environment that is integrated with Google Cloud resources. Cloud Shell is particularly well-suited for prototyping and working through tutorials. We will use the Cloud Shell in the next steps of setting up the ML pipeline. For additional details about Cloud Shell, see the: https://cloud.google.com/shell.

To start the Cloud Shell, click on the Activate Cloud Shell icon at the top of the Google Cloud Console, as shown in figure 11.12.

![](bbox=[0.19, 0.3, 0.89, 0.363])

When you click on the Activate Cloud Shell icon, the Cloud Shell terminates at the bottom of the console with your home directory as the current directory, as shown in figure 11.13.

![](bbox=[0.19, 0.495, 0.89, 0.78])

You can run commands directly in the Cloud Shell Terminal, including standard Linux commands and Google Cloud-specific commands. You can click Open Editor to edit files in the Cloud Shell file system, as shown in figure 11.14. To get back to the Cloud Shell Terminal, click on Terminal.
