# 5.5 Introduction to LightGBM

LightGBM was introduced in a 2017 paper titled "LightGBM: A Highly Efficient Gradient Boosting Tree" by Guolin Ke and his team at Microsoft (https://mng.bz/AQtz). The package reached the 4.3 version, which we tested in this book. According to the authors, the term "light" in LightGBM highlights the algorithm's faster training and lower memory usage than traditional gradient boosting trees. The paper demonstrated effectiveness through experiments on multiple public datasets, the algorithm's efficiency and its ability to speed up the training process of conventional gradient boosting trees while maintaining almost the same accuracy. LightGBM made available as open-source software on GitHub (https://github.com/microsoft/LightGBM/), quickly gaining popularity among scientists and machine learning practitioners.

On paper, LightGBM shares many characteristics similar to those of XGBoost, as support for missing values, native handling of categorical variables, GPU training, networked parallel training, and monotonicity constraints. We will tell you more about all that in the next chapter. In addition, LightGBM also supports sparse data. However, its major advantage lies in its speed, as it is significantly faster than XGBoost on various tasks. The Kaggle community quickly took notice of LightGBM and began incorporating it into their competitions alongside the always-popular XGBoost. In mlcontents.com, a website that tracks the data science scene, in 2022 LightGBM became the preferred tool over competition winners, surpassing XGBoost in popularity. An impressive 25% of reported solutions for tabular problems were based on LightGBM. While LightGBM has comparable success across data science practitioners, XGBoost remains more popular. For example, the XGBoost repository has more GitHub stars than the LightGBM repository.

LightGBM is a cross-platform machine learning library available for Windows, Linux, and MacOS. It can be installed using various tools, such as pip or conda, from source code (see the complete installation guide at https://mng.bz/ZIEP). Its usage syntax is similar to Scikit-learn, making it easy for users who are familiar with Scikit-learn to transition to LightGBM. When optimizing gradient descent, LightGBM follows the footsteps of XGBoost by utilizing the Newton-aphaph update, which involves dividing the gradient by the Hessian matrix. Guolin Ke's answer on GitHub confirms (see https://github.com/microsoft/LightGBM/issues/5223).
