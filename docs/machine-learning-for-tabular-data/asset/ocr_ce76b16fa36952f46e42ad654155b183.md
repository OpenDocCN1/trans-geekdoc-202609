The dataset is read from the web by requests.get() and then turned into a string buffer.

pd.read_fwf reads a table of fixed-width formatted lines into a DataFrame.

The Auto MPG data is stored in a fixed-width file, where values are on the same line, separated by a certain number of spaces or a tab. The return carriage at the end of the rows signals the end of an example. The following is a sample of text file that the request library returns us from the UCI Machine Learning repository:

```
18.0 307.0 130.0 3504.0 12.0 70 "chevrolet chevelle malibu"
15.0 350.0 165.0 3693.1 11.5 70 "buick skylark 320"
18.0 318.0 150.0 3436.1 11.0 70 "plymouth satellite"
31.0 4. 119.0 82.0 2720.0 19.4 82. "chevy s-10"
```

This explains why we must use a fixed-width reader such as pandas read_fwf and spec-if character where each value starts and end. More importantly, you can find other datasets as CSV files. If the same data had stored in CSV format, it would look like the following:

```
"mpg","cylinders","displacement","horsepower","weight","acceleration"
model_year,"origin","car_name"
18.0,307.0,130.0,3504.0,12.0,70.0,"chevrolet chevelle malibu"
15.0,350.0,165.0,3693.1,11.5,70.0,"buick skylark 320"
18.0,318.0,150.0,3436.1,11.0,70.0,"chevy s-10"
```

In CSV values, the features are not placed in rows; they vary in position but not in order of sequence, and you find them separated because of a special character as a separator. In our example, this is the comma. Please also notice that textual data, such as strings or dates, is often delimited between quotes to avoid confusion if the text contains the separator.

In such a case, you have to use the pandas read_csv reader, which can handle CSV files. Depending on the situation, your data may be stored as a JSON file or an XML file, but there are readers for all formats in pandas (see table 2.2).
