# Exercising the deep learning model

On the left side of 9.18, we have the list of features used to train the model as we would be specified in the config file, including the Weeks on the market feature. The right is an extract from a Kuala Lumpur real estate listing. If we want to be able to use the trained model to find values for all the features on the left in the right.

As shown by the numbers in 9.18, for most of the features we will use to train the model, however, there are two features that we can't get the values from the real estate listing:

+   - Car Parks—This particular listing mentions covered parking for the building overall but does not include information about parking spaces for this particular unit. For the sake of a quick test, we can assume that the value of Car Parks for this listing is 0.

+   - Weeks on the market—The listing does not include the number of weeks it was on the market before it was sold we won't know this value until after the listing has sold. We cannot include Weeks on the market in the training process.

Now that we have explained why it's important to exercise the trained model on a handful of real data points, we will review the code for exercising the model in the next subsection.
