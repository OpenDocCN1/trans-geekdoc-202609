
- Pipeline (https://mng.bz/LyX8)
- ColumnTransformer (https://mng.bz/BXM8)
- FeatureUnion (https://mng.bz/DX20)

The Pipeline command allows you to create a sequence of Scikit-learn classes that results in a series of transformations of the data, and it can end up with predictions. In this way, you can integrate any model with the transformations it requires for the data and deal with all the involved parameters at once—those of transformations and of the model itself. The Pipeline command is the core command to move across tabular data from source to predictions in the Scikit-learn package. To set it, at instantiation, you just need to provide a list of tuples, each containing the name of the step in the pipeline and the Scikit-learn class or model to be executed. Once instantiated, you can follow it using the common API specifications of Scikit-learn (fit/predict). The Pipeline will execute all the predefined steps in sequence, naturally, you can inspect, and tune the single steps of the pipeline sequence for better results and performance, but you can handle the pipeline as a single macro command.

However, columns may have different types and require quite different transformation sequences, or you may have devised two ways to process your data that you would like to combine. ColumnTransformer and FeatureUnion are Scikit-learn commands that can help you apply a certain transformation or pipeline of transformations only on certain columns (which you can define by their name or position in the columns sequence). The command takes a list of tuples, as the Pipeline command, but it requires a name for the transformation, a Scikit-learn class for executing it, and a list of column names or indices to which the transformation should be applied. Since it is a transformative command, its ideal usage is inside a pipeline, where its transformations can be part of the data feeding of a model. FeatureUnion, instead, is just a way to concatenate the results of two distinct pipelines. You may achieve the same result with a simple NumPy command such as `np.hstack` (https://mng.bz/IkJD). However, using FeatureUnion you have the advantage that the command can fit into a Scikit-learn pipeline and hence automatically used as part of the data feeding to the model.

The modularity of operations and API consistency offered by Scikit-learn and its Pipeline will allow you to create complex data transformations to be handled as a single command, making your code highly readable, compact, and easily maintainable. We will create a series of transforming sequences in Scikit-learn that will allow us to demonstrate how Scikit-learn and its pipeline functions are the right choices for tackling tabular data problems. We will also point out how you can easily switch between the different options for machine learning with tabular data thanks to a well-defined pipeline.
