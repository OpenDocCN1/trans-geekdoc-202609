关于人工智能和深度机器学习在自动驾驶等系统中的应用，存在大量讨论，但这些技术真正蓬勃发展的主要领域是网络安全。这些技术开始利用人类的思维和行为方式，但以更少受人类偏见影响、反应速度更快的方式进行。目前的主要局限性是缺乏人类的推理能力。例如，自动驾驶汽车的传感器可能能够检测到球滚入马路，并采取避让行动，但它无法推断孩子可能踢了球并正在追逐它。传感器可能检测到紧随其后的车辆，因此避让行动可能导致车辆偏离车道撞向冲出马路的孩子，而不是紧急刹车。

不过，“即时推理”的能力并不遥远，一旦将其纳入网络安全、深度机器学习以及我们称之为目标导向的代理中，我们将看到信息和网络安全软件实现智能决策。关于人们习惯于使用的系统，以及技术变得“更聪明”时我们对它们的依赖增加的问题，也值得关注。例如，2019 年波音 737 Max 飞机坠毁事件中，用于防止飞机失速的传感器数据与软件交互 malfunction，导致飞机多次将机头向下推，迫使驾驶员与飞机争夺控制权。[^(10)](#9781284211658_CH01_08.xhtml#c1-bib0010)

最后，还有一个与人类信息过载（通常称为认知过载）相关的著名问题。技术在提供更多信息方面持续改进，但与此同时，人们在应对所有数据方面的效能会下降。认知过载在关键事件中可能产生毁灭性影响，因为在压力巨大、需要准确把握数千个时效性变量的情况下，人员必须同时考虑众多变量的关联（集成任务）以及单个变量的状态（聚焦任务），以便及时做出决策并采取适当行动。[^(11)](#9781284211658_CH01_08.xhtml#c1-bib0011) 如果你曾目睹过典型的控制室（如网络运营中心 [Figure 1.3](#9781284211658_CH01_03.xhtml#c1-fig0003)）中的屏幕和仪表盘，你会立刻明白——“眨眼灯”是操作人员常用的称呼。

### 1.3.2 Information and Cybersecurity Basic Concepts

信息和网络安全威胁形式多样，但也具有共同属性。在此之前，让我们先介绍一些定义和概念。首先，威胁被定义为对自身或他人的心理（如袭击）、物理（如电池）或社会（如盗窃）侵害或损害的预期。弱点是系统（计算机、网络或其他基础设施）的一种弱点——无论是故意的还是无意的——这会使系统面临被 compromise（妥协）。妥协可能是故意的攻击（如黑客）造成的，也可能是自然灾害导致的。 exploit 是利用弱点的攻击。exploits 拥有攻击面、向量和架构。攻击面表示攻击可能发生的地点，如路由器或运行在计算机上的软件程序。攻击向量是攻击者利用攻击面的路径或手段，包括其在过程中所采取的行动和反制。攻击架构是攻击的类型，如拦截通信或修改文件。

一旦发生 exploit，我们希望遏制它、从中恢复，并进行回顾（retrospective），通过取证分析（forensic analysis）找出原因，以便通过 remediation（整改）防止其再次发生；有时还需要通过特殊手段保存证据以用于起诉，确保证据未被篡改。攻击分为两类：被动攻击和主动攻击。被动攻击收集信息且难以被发现（例如中间人拦截并透传），而某些主动攻击易于被发现但难以防范，例如分布式拒绝服务攻击（DDoS）。我们稍后会详细讨论这些内容。

| Man-in-the-Middle | 一种攻击类型，攻击者设置通信拦截器以进行各种被动或主动攻击。 |
| --- | --- |
| Passive Attack | 设计用于在不被发现的情况下窃取信息的攻击。 |
| Active Attack | 设计用于对目标造成损害或 disruption（干扰）的攻击。 |
| Retrospective | 关键参与者讨论发生了什么、由谁、何时发生，以及如何防止其再次发生的活动。 |

那么，让我们先谈谈我们试图保护的内容。考虑一家典型公司中包含的敏感信息，如员工绩效评估或社会安全号码。它们可能用于存储健康记录以用于保险目的，也可能存储税务信息和金融账户信息。有人可能冒用你的身份，如果随后被捕，还会冒充你——于是你将留下 arrest record（ arrest 记录），即使它不是你！

此外，随着互联网 increasingly 连接所谓的物联网（IoT）设备，问题只会变得更糟。IoT 设备如智能手机、无人驾驶飞行器或无人机、自动驾驶汽车等，都在增加网络安全的复杂性。它们都依赖于互联网和网络应用。有人可能会入侵你的汽车，或指令你的智能设备在你度假期间将烤箱温度调至 500 度并保持 50 小时。防止这一切发生的责任在于你（以及类似你的人）！
