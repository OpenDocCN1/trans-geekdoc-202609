
-   [隐蔽通道]在俄罗斯大使馆被发现，当它们注意到在特定间隔时的电力尖峰，这似乎正在向在大使馆服务器骨干上植入的机器人传输指令。因此，隐蔽通道是一种不受安全机制控制的通道，或者已经被妥协的通道。

-   例如，Loki隧道攻击利用ICMP协议在ICMP报文头部写入数据。这使得攻击者能够通过隐蔽通道与系统进行通信。因此，当前常见的安全实践是阻止防火墙中的入站ICMP数据包。

-   存在多种隐蔽通道类型，但主要有**时间**和**存储**两种。在隐蔽时间通道中，一个进程通过调制其使用系统资源的方式（例如大使馆的电力信号）来传递信息。这种调制可以通过按特定顺序访问硬盘驱动服务，或在特定间隔中增加CPU利用率来形成模式，类似于摩斯电码。恶意传感器或软件应用会监听这些模式，每个模式可能是执行不同攻击或监视行为的指令。

-   隐蔽存储通道是指进程将数据写入已被妥协的存储位置，或通过网络连接将信息发送到非法进程。

-   **后门**是开发者或基础设施工程师创建的系统入口，如上文所述。有时这些后门在测试阶段用于隔离功能和错误，从而绕过通常会隐藏错误的安全措施。尽管大多数组织禁止创建后门，但它们仍常见于较旧的软件版本中，这些版本在迁移到生产环境前未被发现。因此，在DevSecOps冲刺期间进行代码和代码覆盖率审查非常重要。

-   **非对称**和**异步**攻击是攻击架构的分类。在非对称攻击中，攻击者利用一个漏洞，其结果与所付出的努力不成比例。例如，在2020年COVID-19大流行期间，恶意脚本在Twitter和其他社交媒体平台上传播了虚假新闻，导致公众恐慌和超市货架空货，原因是囤积行为。此类脚本可能由国家行为者或单个个人创建，并具有广泛影响。

-   异步攻击利用操作系统执行进程的方式。如果攻击者能够注入代码（例如通过文件替换或运行时注入），就可以改变系统行为。常见的此类攻击向量是**时间检查/时间使用**（time-to-check/time-to-use）。当应用程序或系统启动时，它会解析并执行配置文件。时间检查/时间使用攻击会在解析和执行之间替换配置文件或文件内容。另一种向量是创建**竞争条件**（race condition），使得执行顺序的指令发生冲突。

-   这类攻击的大部分结果是恶意软件导致的。

-   **溢出攻击**针对有限资源进行数据过载。溢出攻击有多种类型；如前所述，我们提到了**缓冲区溢出**及其发生方式。缓冲区溢出是一种攻击，其中向系统缓冲区写入的数据超过了其能够缓存的量。当程序在缓冲区末尾写入数据时，程序的内存寻址可能会被改变。这本身可能导致系统崩溃，也可能导致插入恶意代码，用于破坏数据或获取管理员权限。例如，被攻击的程序接收的数据超过其能够存储的范围，导致缓冲区溢出并迫使系统执行攻击代码。

-   **恶意软件**通常是导致计算机设备溢出的罪魁祸首。恶意软件可能从动态链接库、程序中包含的外部模块、第三方或开源软件、点击电子邮件中的链接等渠道获取。溢出也可能来自网络连接，攻击者通过洪lood网络端口、洪lood数据包过滤防火墙或其他网络设施来进行攻击。静态和动态代码分析器擅长在软件中查找溢出攻击代码，病毒和恶意软件扫描器相对较好地发现通过恶意链接或网站安装的溢出恶意软件，而监控系统通常擅长发出网络溢出攻击的警报。然而，网络溢出攻击难以防止，其防御措施通常依赖于高可用性和冗余系统来处理这些攻击。恶意软件设计用于损坏或干扰主机系统。恶意软件种类繁多，使用不同的攻击策略，主要分为**破坏**和**盗取**两类。恶意软件的分类包括蠕虫、病毒、特洛伊木马和远程控制系统。

-   **蠕虫**是自行传播的程序，通常无需用户交互即可执行破坏，因为蠕虫会通过网络将自身复制到其他计算机，并利用被 compromized 系统攻击其他系统。脚本和宏（如Microsoft Word中的模板，例如normal.dot）可以被蠕虫利用。例如，Netsky-PWin32蠕虫通过使用Windows网络API、MAPI函数以及Microsoft Outlook等电子邮件客户端传播。该蠕虫在消息中嵌入恶意代码，并附加到发出的邮件上。

-   **病毒**是附加到可执行指令的恶意代码，例如Microsoft Office安装程序。病毒有多种子类别，通常出现在.exe、.dll或.com文件中，也可能嵌入图片、PDF或ZIP文件。其他病毒感染Windows注册表并创建恶意可执行文件之间的链接。一些病毒读取电子邮件分发列表（如Microsoft Outlook）并将其用于将自身分发到其他机器，如W95/Babylonia病毒所做。病毒通常具有复制和通过进程间通信传播的能力。一些病毒成为内存驻留，在程序运行时感染其他程序；另一些则主动寻找其他文件进行感染。

-   **特洛伊木马**是看似合法但实际上包含恶意代码的程序。它们可能通过网站下载，或与跟踪Cookie配合使用，或在目标系统上安装并下载其他恶意软件，或开辟通信通道将目标系统的信息传输给攻击者系统。某些特洛伊木马使用键盘记录器发送受害者的按键。特洛伊木马和病毒可能在程序中植入逻辑或定时炸弹，并在满足特定条件（如日期）时触发。例如，troj/Cimuz-U（也称为Trojan-PSW.Win32.Agent.eo间谍软件）通过感染邮件或链接加载自身，将其安装到Windows注册表中，然后打开端口以传输从受害者系统窃取的信息。它还能从互联网下载其他恶意应用程序，并在目标主机上留下其他已感染文件。
