
# 情境前提研究表明，大量企业缺乏实施自动化信息和系统安全技术的基础设施和/或专业知识，因而在很大程度上依赖于酌情控制。<sup>[44](#9781284211658_CH09_09.xhtml#c9-bib0044)</sup> 在其他情况下，则是因为技术和标准不兼容而根本无法实施。例如，商务差旅人员有时需要在现场重新配置笔记本电脑，以便它们能够访问 Wi‑Fi 网络通信。由于这种灵活性的需求，无法为员工可能遇到的所有网络创建集中化的自动化解决方案。并购或全球扩张等情形也会导致分布式组织边界之间出现截然不同甚至不兼容的技术和做法。在这些情况下，人们往往需要调整可配置的安全机制，以便能够访问各种系统，这通常意味着必须将系统安全配置到最低共同标准。简单的例子是，必须不断根据个人所需的网页访问类型调整浏览器隐私设置。

# 组织文化前提研究认为组织具有子文化，研究显示组织文化的一个要素是认为组织内的人和流程可以“工程化”并自动化，以 predictable 方式运行，或者则是更混乱且自我组织的。认为组织可以工程化的文化观称为机械性，而认为组织更具自我组织性的观称为有机性。在研究组织成功或失败的因素时，早期的 Burns 与 Stalker 工作描述了定义有机组织和机械组织的特征。<sup>[45](#9781284211658_CH09_09.xhtml#c9-bib0045)</sup> 他们将有机组织描述为灵活、适应性强，组织决策权限下放至组织中最适当的层级。机械组织则被描述为拥有严格、僵硬的权威层级结构。他们认为机械组织在成长过程中会变得脆弱，最终因无法适应而失败。与网络安全相关，有机组织倾向于提供更多员工协作与 incident 信息交流的支持，并且在应对动态威胁时更具适应性。机械组织则倾向于建立僵硬的组织结构，不利于不同组织单元之间的协作，且在面对新颖或动态攻击时难以应对。

# 技术前提研究指出，在某些情况下，完全规模的网络安全自动化可能需要被规避。例如，部分组织的系统工程师会将防火墙配置为阻止 promiscuous connections，并禁止自动安全更新，迫使个人自行保护其系统。<sup>[41](#9781284211658_CH09_09.xhtml#c9-bib0041)</sup> 此外，某些软件需要使用 Microsoft ActiveX 控件或其他进程间通信，这迫使安全管理员降低集中防御姿态，而防病毒软件虽可能在服务器上传附件或邮件前激活，但并非所有系统都支持该功能，且在许多安全情境下参数必须个性化。

## 9.3.4 遗漏行为的管理

行为主义关注我们所观察到的关于人的行为，而法律则关注“意图”的概念，执法部门在评估犯罪时会考虑能力、动机和机会。在组织中，管理者必须关注人们的行为，而不能试图诊断或治疗心理因素，否则可能招致法律风险。然而，行为并非孤立存在，正如我们之前所示，推断动机、意图以及前因同样适用于管理者可能采取的治疗或干预措施。例如，事故性的负面行为通常与故意的负面行为处理方式不同。正如前文所述，由于人们的行为是安全漏洞的核心，人们常被称作“最弱环节”。管理者拥有多种行为选项来应对安全遗漏，但选择最佳选项取决于遗漏的前因——即遗漏的原因，以及安全遗漏的类型。

### 9.3.4.1 应对 unintentional omission

如果员工对安全威胁缺乏认知，则需要使其知晓。虽然这似乎显而易见，但大量研究<sup>[36](#9781284211658_CH09_09.xhtml#c9-bib0036)</sup> 表明，许多公司管理者未能做到这一点，部分原因是新威胁不断出现。即便人们已知晓威胁，除非他们被针对特定威胁进行动员，否则可能产生麻木情绪。有时人们会忽视或禁用安全措施，除非它们被视为侵入性或无效，且只有在持续处于对严重即将到来的威胁的警觉状态时才会改变。

需要理解的是， attempts to make people aware of security threats and heighten their vigilance 会随时间衰减并最终失效，尤其是当尝试过于模糊时。例如，美国国土安全部使用的颜色编码威胁等级技术，以及在代码黄（提升） versus 代码橙（高） versus 代码红（严重）威胁等级下，是否会选择在飞机上飞行。研究显示，人们对黄色和橙色等级并无区分，且在威胁等级提升时往往不知如何应对。<sup>[47](#9781284211658_CH09_09.xhtml#c9-bib0047)</sup> 此外，超过一定程度后，人们不再相信威胁的真实性，会对其置疑——即使威胁真实且可能发生。与此同时，当人们感知到威胁时，其行为会依据其愿意接受的风险量而定，这称为风险 homeostasis。风险 homeostasis 是一种“认知平衡”，源自对潜在损害严重程度的感知，如维修的财务成本。<sup>[48](#9781284211658_CH09_09.xhtml#c9-bib0048)</sup> 因此，人们会根据风险程度调整行为。

感知的威胁严重程度以及相应的风险接受行为基于以下前提：(1) 人们对“生命”“自由”“财产”具有某种无形价值；(2) 他们有一个接受、容忍、偏好、欲望或选择的风险阈值；(3) 该“目标风险”在采取安全或不安全行为的备选方案时，取决于感知的收益或好处与成本的权衡；(4) 这决定了人们在采取预防措施或完全回避威胁之前，会暴露于多大程度的威胁或危害。<sup>[49](#9781284211658_CH09_09.xhtml#c9-bib0049)</sup>
