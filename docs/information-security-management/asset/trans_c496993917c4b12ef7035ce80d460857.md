
我们将首先通过使用更为常规和最常见的系统、服务器、应用程序和配置来阐述这里的风险——我们称之为基础设施。你的银行、医生、机动车管理局、大学、药店、在线商家，几乎所有组织都存储你的个人信息。更不用说像 Facebook 和 Twitter 这样的公司提供应用程序编程接口 (API)，供第三方挖掘你的个人社交媒体数据用于其自身目的——所有这些数据都以文档、数据库、文本和编程文件的形式存储在某些网络系统中。我们需要能够保护存储的信息、传输中的信息、信息的准确性、对外部资源的访问以及对内部服务的访问等。

此外，每当你连接到服务器，无论是 CNN.com 还是 Weather.com，服务器都会收集一些你的元数据。当你连接到服务器时，你与多个网络协议层建立网络连接，服务器从中窃取信息，例如你的地理位置、浏览器类型和版本、Cookie，有时甚至是环境变量和其他元数据，然后将这些信息存储在日志文件和长期存储设备中。伪造或伪装 Internet 协议 (IP) 地址很少能真正隐藏或保护客户端，一旦客户端计算机与服务器之间的网络套接字建立后。

### 1.4.1 Key Information and Cybersecurity Concepts

我们将通过分段我们迄今为止介绍的关键概念来结束本章，以便为你组织学习提供框架。首先，重要的是认识到内部威胁与外部威胁之间存在相似之处，但也存在重要差异。我们针对这些威胁所采取的对策和缓解措施往往截然不同。大量的网络安全文献主要关注外部威胁。外部威胁包括从好奇心驱动的偶发攻击，到国家行为体的有组织努力，旨在 compromise 系统、窃取或毁灭信息，或通过勒索软件勒索金钱。然而，内部人员已经突破了我们对外部人员设置的许多障碍，因此他们往往带来细微但同样严重的风险。他们往往知道重要文件和文档的存放位置、如何访问数据库、哪些关键系统存在，以及用于保护这些资产的对策——包括这些对策的缺陷或脆弱性。

鉴于这些特点，外部和内部攻击者的攻击面和攻击向量往往有所不同（[Figure 1.4](#9781284211658_CH01_04.xhtml#c1-fig0004)）。典型的网络配置会包含防火墙，或者更可能是一组防火墙以及所谓的非军事区（DMZ）。DMZ 是一个逻辑边界，用于分隔公共或互联网访问与组织内部资源。攻击者必须 somehow 突破或渗透这一边界才能达到其目标。外部攻击通常遵循可预测的模式。[^(13)](#9781284211658_CH01_08.xhtml#c1-bib0013)

外部攻击可能以足迹收集（footprinting）开始——一种利用技术确定目标网络基础设施的技术，例如公司使用的 IP 地址。随后，攻击者可能会扫描这些基础设施，寻找网络服务（端口）、协议、软件以及软件版本、安全补丁和修订级别，以便了解可被利用的漏洞。然后他们可能会进行枚举，找出特定服务允许的连接和参数。一旦获得这些信息，他们通常会尝试渗透目标系统，并在随后努力掩盖攻击痕迹，即尽可能删除攻击发生的证据以及攻击者的身份。
