
一种可能对任何公司构成主要网络威胁的来源是其员工，如本章开头的情景所示。问题的部分在于实际问题——保护基础设施的安全态势必须放松，以便有效执行常规组织功能。本章开头的情景还揭示了另一个后果：内部对手通过发布公司人员资料及其电子邮件联系信息，促成了针对公司不慎的员工的网络钓鱼和预设社交工程攻击。发布敏感信息这一简单行为是网络钓鱼和预设等社交工程攻击激增的原因之一。人们有时会因在社交媒体（如 Facebook）上过度分享而不慎做出此类行为。

我们倾向于认为他人可信，尤其是公司的员工，如格雷德威尔的《对陌生人说话》中所言，他指出人们在面对他人陈述时通常“默认为真”。我们在实践中希望“信任但验证”。验证包括监控员工的电子活动、确保最小权限并防止权限提升、实施认证技术与方法、记录与审计活动、以及加密等其他控制措施——我们将在后续内容中进一步介绍这些措施。

#### 3.1.1.1 缺乏专业精神和恶意程序员

缺乏专业精神的程序员并非技术上的对手，但他们通过有意或无意地创建可被利用的漏洞而造成损害，其中一些漏洞被称为后门。后门是软件中的捷径，通常用于绕过安全措施，以便简化编码或测试功能。有时缺乏专业精神的程序员只是粗心大意，例如忘记正确配置数字访问管理策略。恶意程序员则是有意留下后门或植入其他恶意软件（如逻辑炸弹）的一方。这些内部人员通常与外部人员合谋，以策划和协调攻击。这些问题正是渗透测试人员（亦称 pen testers、白帽黑客）扫描系统漏洞的主要原因，他们可能是代表公司进行非正式或正式的合规性测试，也可能是出于公共利益自行进行扫描。

### 3.1.2 黑客活动主义者

黑客活动主义者是一种独特的对手，其通常意图通过为政治或社会动机进行网络攻击来造成损害。与内部人员不同，他们的动机一般不是经济利益，而是希望通过破坏或获得曝光来实现目标。他们不太在意隐藏痕迹，因为希望世界知晓执行攻击的匿名或团体名称。因此，他们最倾向于使用网站篡改和分布式拒绝服务（DDoS）攻击。匿名（Anonymous）是该类别中著名的对抗性组织。Anonymous 是一个去中心化的成员群体，其使命是 destabilize 或毁灭任何其认为对社会有害的目标或其附属机构。

由于其去中心化的特性，追踪成员并确认 Anonymous 是否真正是攻击的幕后主使，还是有人冒充该组织的拷贝猎手，都很困难。但他们共同的一个特点是愿意对他们认为“腐败”或与自身利益相悖的大型公司、政府或实体发起强有力的攻击。例如，操作报复（Operation Payback）[⁷](#9781284211658_CH03_08.xhtml#c3-bib0007) 是一项针对互联网盗版反对者的有针对性的行动，它通过对多家企业和政府实体（包括 RIAA、MPAA 和 PayPal）发起持续一年以上的 DDoS 攻击，造成数百万美元的网络设备损失，导致网络设备 literally 烧毁，扰乱数字交易系统，并窃取受版权保护的材料。

#### 3.1.2.1 “独狼”黑客

黑客已有数十年历史，长期以来，这一群体主要出于好奇心而非恶意行为。然而，越来越多的黑客不再仅仅为了尝试而进行活动，而是有明确意图造成损害。所谓“独狼”黑客通常指代一小群高度技术化、希望展示自身能力的精英。许多新兴的独狼黑客缺乏像黑客活动主义者那样的政治或社会动机，他们倾向于使用不同的 exploit。与通过 DDoS 或网站篡改来制造破坏不同，他们通常致力于窃取信息或利用漏洞获取金钱，例如窃取数据并在暗网上出售，或结合勒索软件与挖矿软件进行攻击。由于缺乏国家赞助 adversary 的资源，他们更倾向于使用开源工具并寻找快速获胜的策略，而不是像国家赞助 adversary 那样采取长期博弈。例如，在 Capital One 数据泄露事件[⁸](#9781284211658_CH03_08.xhtml#c3-bib0008) 中，独狼使用开源扫描工具发现公司防火墙在 AWS 上的配置漏洞，随后利用该漏洞进行信息外泄。幸运的是，该 adversary 在社交媒体上炫耀此举后被捕获，但这种情况并非常态。

### 3.1.3 国家赞助行为者

国家赞助行为者是指由政府资助、针对其他政府或企业实体进行恶意行为的对手，无论是进行间谍活动（窃听）还是开展全面的间谍和公开网络攻击。这些对手技术娴熟且危险，通常拥有足够的资金造成大规模破坏，并且擅长掩盖痕迹。后者这一点至关重要，因为当公司被入侵时，调查会试图弄清楚做了什么以及攻击来源。国家赞助 adversary 可以通过多层代理隐藏身份，使其极难追踪，攻击也难以防止。

例如，我们可以阻止一系列发送恶意数据包的 IP 地址，但如果这些 IP 地址不断变化，或 adversary 使用合法 IP 范围伪装攻击，我们该如何保护系统？常见的做法是向尽可能多的公司发送数据包探测，制造网络流量噪声，通常在完整 DDoS 之前保持在触发“电路断路”防御措施的临界点以下。这种噪声是有意为之，用于制造分散注意力的烟雾弹，而实际攻击则在背后进行。这类似于走私毒品的行动，犯罪分子会派遣代理人（走狗）被捕，以此掩盖真正的货物顺利通过繁忙或被压力过大的检查点。安全专业人员常说，如果 30 分钟内没有任何噪声，那更令人担忧，因为此时检测系统很可能已被 compromise 或失效，而非噪声停止。噪声永不停止！
