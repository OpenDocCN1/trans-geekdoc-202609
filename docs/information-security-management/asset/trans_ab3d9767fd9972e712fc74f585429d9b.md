| Command Injection || 命令注入是恶意用户通过执行操作系统命令的漏洞。此类攻击还可能伴随工具，例如 HAK-5 的 BASH Bunny，它可以在受害者的电脑上隐蔽安装 shell。当应用程序以不安全的方式将用户提供的数据（如表单、Cookie、HTTP 头）传递给系统命令时，命令注入攻击得以实现。

| Session Fixation and Session Hijacking || 会话固定是一种漏洞，表现为应用程序在从预登录状态切换到后登录状态时未能正确更新会话令牌。由于此弱点，CHAP 身份验证协议被弃用。预登录会话令牌不应在后登录时使用，否则攻击者可能窃取合法用户的已验证会话。当用户会话被盗时，称为会话劫持。

| XXE Injection || XML 外部实体（XXE）注入是一种漏洞，攻击者可针对配置不当的 XML 解析器（通常是 SAX 或 DOM）进行攻击。恶意的外部实体引用可导致攻击者未经授权读取运行在服务器上的 XML 解析器所能访问的敏感文件，也可用于制造拒绝服务（DoS）攻击。

| Persistent XSS || 持久性 XSS 是一种漏洞，攻击者诱骗 Web 应用将攻击者提供的脚本代码存储下来，然后该代码会被送给其他用户浏览该应用。攻击者提供的脚本在其他用户的客户端系统上运行。该漏洞广泛存在，影响那些使用未经验证的用户输入生成未编码的应用输出的 Web 应用。

| Reflected XSS || 与持久性 XSS 不同，反射型跨站脚本（XSS）中攻击者提供的脚本代码不会被存储在应用程序内部。相反，攻击者会创建一个恶意请求，使应用返回一个包含攻击者提供脚本代码的单一 HTTP 响应。要成功，攻击者需要受害者点击一个精心制作的链接。

| DOM XSS || 基于文档对象模型（DOM）的 XSS 是一种攻击，攻击者通过修改受害者浏览器的 DOM 环境来执行 payload，使客户端代码的行为与预期不同。换句话说，HTTP 响应本身（即页面）并未改变，但页面中的客户端代码因被注入到 DOM 环境中的恶意修改而执行不同。

| Directory Path Traversal || 这是一种漏洞，允许攻击者访问超出 Web 根目录的目录和文件。它出现在应用程序因用户提供的输入而进行不安全的文件引用时。经典例子是利用 ../（点点斜杠）序列及其变体操纵文件路径，从而访问服务器文件系统中的任意文件和目录，如源代码、密码文件或其他敏感数据。

| Yielding Raw Errors || 当程序员未能妥善处理输入错误并返回经过脱敏处理的页面时，会出现直接抛出原始错误。原始信息可能会向攻击者泄露重要信息，例如使用的数据库类型和 SQL 版本、以及承载请求的 Web 服务器类型和版本（如 Apache）。你可能见过类似“Ooops, Error 500” 的页面，伴随其他信息甚至 SQL 语句；这正是此类情况的例子。

| Authentication Credentials in URLs || 当程序员使用 URL 重写或编码来管理会话或传递身份验证凭证时，会出现此漏洞。将信息暴露在 URL 中并用于控制，使其易受篡改。

| Insecure Logging || 不安全的日志记录是一种漏洞，表现为应用程序被配置为将敏感数据（如个人可识别信息、支付卡信息或身份验证凭证）写入日志文件。此外，如果应用程序未能正确验证用户提供的输入并将其存储在日志中，攻击者可能篡改日志文件本身。
