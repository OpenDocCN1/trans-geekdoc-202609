

第三，NFT 面临的最大障碍是此类“数字资产”周围的法律不确定性。事实上，许多消费者可能根本不知道自己在买什么。NFT 是虚拟货币吗？还是 NFT 是虚拟货币的凭证？更重要的是，NFT 是证券吗？（2021 年 5 月，美国的 NFT 参与者向 SEC 提交了规则制定请愿书，寻求 SEC 发布概念发布以消除监管不确定性。）这些都是任何主要数字经济体的立法机构从未回答过的问题。加密资产和 NFT 的无监管性质可能会吓退潜在的参与者和投资者。

正如本章前面所述，大多数非同质化代币是一个元数据文件，该文件使用一种作品进行编码，该作品可能受版权保护，也可能不受保护，甚至可能是公共领域的作品。任何可以数字化的东西都可以变成 NFT；原始作品仅在创建 tokenID 和合约地址的唯一组合的第一步过程中才需要。因此，原则上 NFT 与版权关系甚微。NFT 所有权并不直观。

此处的关键问题在于，围绕买家购买 NFT 时获得的权利，往往存在广泛的困惑。一些买家认为他们获得了底层艺术品及其所有附带权利。然而，实际上，他们只是购买了与作品相关的元数据，而不是作品本身。部分困惑可能源于购买 NFT 所花费的巨额资金。当生成艺术作品能以超过 100 万美元的价格售出时，人们很容易假设购买者获得的不仅仅是一串艺术价值存疑的数字和字母。（参见 [Box: NFT Skybound](#c05.xhtml#head-2-40)。）

此外，当现有艺术品的 NFT 标出数百万美元的价格时，不太懂技术的人往往会认为售出的是作品本身，但事实并非如此。可以理解的是，很难理解 NFT 买家花费如此巨资购买的仅相当于一个元数据文件，且该文件与此类艺术品的版权没有任何关联，但这正是大多数 NFT 的真实情况。因此，普通用户需要清楚地认识到，购买 NFT 的主要理由与任何“收藏品”相同：拥有非流动性资产带来的潜在投资回报，以及拥有来自受人钦佩的艺术家、品牌、运动队等的独特事物所带来的愉悦感。除非条款允许，否则买家只能有限地在公共平台上分享创意作品，或复制并提供给他人。

现在，如果我们回到本章开头，在艺术与技术协同演化的背景下审视这一 NFT 现象，我们可能会发现 NFT 经济非常类似于传统的艺术资助赞助模式。但 NFT 可能会*好得多*。

历史上，赞助制涉及富有的赞助人直接资助个别艺术家，这类似于艺术家从富有的 NFT 投资者那里获得一笔大额一次性付款。赞助资助的缺点是艺术家沦为赞助人的俘虏，即社会中极少数的精英阶层。此外，虽然艺术界有一项拥有艺术品并将其借给博物馆（并适当署名）供公众欣赏的悠久传统，但大量由赞助人资助的艺术品被存放在私人仓储设施中作为私人收藏，极少甚至从未公开展示。

如今，NFT 提供了赞助制的益处，却没有其公认的成本。富人可以继续支持艺术并享受拥有权的体验。数字艺术家不再像文艺复兴时期的艺术家那样依赖佛罗伦萨的一个小型富人圈子，而是可以轻松触达全球范围内的赞助人群体。艺术品的所有权可以（通过区块链以加密方式证明）向赞助人想要以其无可挑剔的品味给谁留下印象的人展示。但同时，艺术品本身仍然对公众免费开放欣赏。这看起来像是旧的赞助经济，让创作者能将其作品金融化，但同时又让作品保持开放获取，供任何人观看、观赏或聆听。（[Figure 5.4](#c05.xhtml#c05-fig-0004) 中的 Phase 1。）

这对创作者经济意义重大，NFT 买卖双方可以在区块链上而非数据聚合平台上决定市场出清价格，创造新的资产变现形式。例如，在音乐人眼中，目前的音乐产业模式已然崩塌。问题始于 Napster 时代，早于 Apple 出现并决定一首 MP3 值 99 美分。但凭什么由 Apple 决定音乐值多少钱？此外，流媒体对大多数音乐人来说是不可持续的，因为收入倾向于按比例分配。据《滚石》报道，在 Spotify 等平台上，90% 的流媒体播放量流向了前 1% 的艺术家。在按比例分配模型中，这 1% 的人最终获得了这些平台决定留给艺术家的资金的 90%。

现在，音频 NFT 正开始解决这些问题。艺术家可以随心所欲地为音乐定价，因为 NFT 为音乐人提供了通往粉丝的直接链接，摆脱了超出其控制范围的平台（和唱片公司）。例如，Kings of Leon 最近宣布计划以 NFT 形式发行专辑，艺术家可以将 NFT 与现实世界的福利捆绑。据《滚石》报道，最独家的 NFT 将包含一张“金票”，因此代币持有者有保证“在每次巡演中获得 Kings of Leon 演唱会的四张前排座位，终身有效。”（[Figure 5.4](#c05.xhtml#c05-fig-0004) 中的 Phase 2。）

此外，NFT 本身也在演变。2022 年初，收藏品和数字艺术占以太坊上 NFT 销售额的 75% 以上。相比之下，The Sandbox 等虚拟世界和 Axie Infinity 等游戏中的 NFT 销售额占以太坊累计销售额的不足 25%。然而，正如将在 [Chapter 6](#c06.xhtml) 中讨论的那样，随着视频游戏市场的蓬勃发展，基于区块链的游戏和虚拟世界对 NFT 的需求正在飙升，特别是当 NFT 收藏品开始在各种游戏中展现更多效用时。（[Figure 5.4](#c05.xhtml#c05-fig-0004) 中的 Phase 3 和 4。）

总之，2022 年的 NFT 正从数字艺术扩展到众多应用领域。随着公众对 NFT 感到适应，话题转向了进一步的虚拟化机遇。在元宇宙中，万物皆可且将拥有其 NFT，NFT 提供了一个流动性市场，消费者可以在其中投资不同的数字资产并进行点对点交易。

最终，NFT 将模糊消费（如游戏娱乐）与投资（如玩赚）之间的界限。NFT 与元宇宙的结合可能开启全功能经济的可能性，从而吸引更大的用户群，这将在下一章通过游戏行业进行阐述。
