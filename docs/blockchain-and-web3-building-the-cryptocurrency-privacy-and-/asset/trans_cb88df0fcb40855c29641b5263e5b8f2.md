

# 世界银行的批判立场

世界银行的反应同样具有批判性。2021年，当萨尔瓦多向该金融机构寻求协助以实施比特币作为法定货币时，世界银行拒绝了其请求。2021年6月BBC的一份报告援引世界银行的话称，其对“比特币挖矿的透明度和环境影响表示担忧”。世界银行提出的问题与萨尔瓦多比特币合法化面临的另一项风险不谋而合：加密货币挖矿。

萨尔瓦多也被称为“火山之国”，因其比特币合法化倡议，其火山可能获得另一种用途。根据BBC的一份报告，2021年11月，布克尔总统宣布计划“在一座火山（Conchagua火山）脚下建设一座比特币城市，利用比特币为该项目融资”。布克尔指出，该城市将利用Conchagua火山的地热能为比特币挖矿提供动力。萨尔瓦多能否在不严重破坏Conchagua火山周边环境的情况下实施加密货币挖矿计划，目前难以预测，国际观察机构如世界银行正焦急地等待着结果。

# 全球央行的回应：CBDC

此外，主要经济体的政府并没有坐视加密货币崛起而袖手旁观。全球央行通常是一个保守的堡垒，如今也在开拓新领域。随着更多经济活动转移到线上（尤其是在新冠疫情冲击之后），实体现金处于劣势，许多央行正在推出自己的数字货币——央行数字货币（CBDC）。2021年国际清算银行（BIS）对央行的一项调查发现，86%的央行正在积极研究CBDC的潜力，60%正在尝试该技术，14%正在部署试点项目。

# 总结：双线货币战争

总之，现在断言加密货币将成为未来元宇宙中的“默认货币”还为时过早（参见[图9.2](#c09.xhtml#c09-fig-0002)）。加密货币生态系统必须在两条战线上进行货币战争。一方面，是对抗包括国家CBDC在内的政府金融体制，它们与加密货币争夺元宇宙中的交易地位，以及限制加密资产使用和交易的加密货币法规。

# 中国在2022年冬奥会上的e-CNY推广

如今，中国和美国正在广泛领域竞争并提升其技术能力。美中技术战争的前沿在于谁将主导区块链和加密货币行业。

尽管中国打击了加密货币（详见下一节），关闭了所有国内加密货币交易所并禁止了所有ICO（首次代币发行），但政府承认区块链技术本身是一项革命性发展。在2019年10月的一次演讲中，中国国家主席习近平宣布区块链将在“下一轮技术创新和产业变革中发挥重要作用”。这标志着首位主要世界领导人对这项备受炒作但仍未被证实的分布式账本技术（DLT）给予如此强有力的背书。（相比之下，大多数西方政府一直持谨慎态度。）

习近平主席呼吁将区块链作为国家创新的重点，其演讲详细阐述了中国政府将如何支持区块链的研究、开发和标准化。中国在全球央行数字货币（CBDC）竞争中的领先地位便是典型例证。与比特币等建立在“去中心化”热情之上的加密货币不同，中国的CBDC（由中国人民银行（`PBOC`）称为`e-CNY`，`CNY`是中国货币人民币的英文同义词）运行在中心化数据库上；尽管如此，`e-CNY`采用区块链和密码学构建，并融合了区块链的关键概念，如点对点支付、可追溯性和防篡改性（参见[图9.3](#c09.xhtml#c09-fig-0003)）。

![图9.3 DCEP是如何设计的？ ¶ 来源：媒体报道，2020年4月](images/c09f003.png)

**[图9.3](#c09.xhtml#R_c09-fig-0003) DCEP是如何设计的？** ¶ 来源：媒体报道，2020年4月

`e-CNY`的时间线始于比特币和其他加密货币发展数年之后（参见[图9.4](#c09.xhtml#c09-fig-0004)）。`PBOC`在数字货币上的首次公开努力发生在2010年5月首笔比特币交易四年后，形式是成立内部数字货币研究小组。从2017年起，`PBOC`加速了其努力，先于2017年1月成立数字货币研究所，随后在2017年12月呼吁中国商业银行和支付机构在数字货币方面开展合作。`e-CNY`测试的进一步加速被普遍视为对Facebook 2019年宣布拟推出`Libra`（Facebook计划中的基于区块链的数字货币，详见本章后文讨论）的反应。

![图9.4 中国数字人民币时间线](images/c09f004.png)

**[图9.4](#c09.xhtml#R_c09-fig-0004) 中国数字人民币时间线**

大规模测试于2020年在众多主要城市展开，正值新冠疫情期间。在这些试点地区，`e-CNY`已正式纳入城市货币体系，自2020年5月起，部分公职人员以数字货币形式领取工资。人们可以在商业银行的手机App中创建`e-CNY`钱包，并使用国家数字货币支付交通、教育、医疗及其他消费品和服务。例如，中国的星巴克、麦当劳和赛百味连锁店被列入央行数字货币测试企业名单。

`e-CNY`的快速发展只是中国致力于数字化转型的必然结果。过去几年，移动支付在中国迅速增长，成为主导支付形式。（参考马尧2016年著作***《中国移动经济：最大且增长最快的信息消费爆发中的机遇》***。）自2020年以来，中国稳步扩大数字人民币试点项目（同时也在打击加密货币；详见下一节讨论），这得益于该国电商和社交网络平台等互联网产业的快速发展，提供了无数应用场景。

2021年7月，`PBOC`发布白皮书，详细阐述了数字人民币（亦称`e-CNY`）的当前运作机制，这是其计划的首次全面披露。白皮书的发布可能标志着数字货币“2C”（面向个人）零售支付测试阶段接近尾声。数字人民币钱包支持多种功能，包括扫码支付、充值和转账。根据白皮书，截至2021年6月，试点参与者累计消费345亿数字人民币（约合53亿美元）。用途包括缴纳水电费、餐饮、交通、购物和政府服务。2022年1月，`e-CNY`钱包正式上线仅一周，即成为苹果和小米应用商店下载量最大的应用。
