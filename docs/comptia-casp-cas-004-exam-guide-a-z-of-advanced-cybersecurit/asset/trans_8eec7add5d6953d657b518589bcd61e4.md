

# 性能

产品或技术响应或执行其预期目标的方式或效率被称为性能。公司应确定应在每台设备上以及整个企业整体上维持的性能级别。所安装的任何安全解决方案都应满足已定义的性能标准。性能标准应同时考虑当前和未来的需求。例如，如果公司想要安装一台身份验证服务器，其选择的解决方案既应满足公司当前的身份验证需求，也应满足未来的身份验证需求。部署一个提供比所需更高性能的解决方案，将使该解决方案的使用寿命超出预期。

# 延迟

延迟是指处理网络数据所需的时间。低延迟网络连接具有相对较短的延迟周期，而高延迟网络连接则具有非常大的延迟（请参阅[图 5.4](#c05.xhtml#fig5_4)）。许多安全措施都有可能增加延迟。例如，路由器分析和转发数据需要一定的时间。在路由器上配置额外的规则通常会增加延迟，从而导致更长的延迟。由于对网络延迟的不利影响，组织可能会选择不使用某些安全措施。审计就是一个对延迟和性能产生负面影响的安全解决方案的绝佳示例。启用审计后，它会在特定活动发生时记录日志。记录这些操作可能会影响延迟和性能。请参阅[图 5.4](#c05.xhtml#fig5_4)，该图说明了网络延迟：

# 可扩展性

可扩展性是设备或安全解决动的一项特性，它指明了其应对不断增长的工作负载并正常运行的能力。时间因素常被用来描述可扩展性。为了确定可扩展性，有必要评估现有和未来的需求。可扩展性也指系统根据不断变化的需求进行扩展的能力。请参阅[图 5.5](#c05.xhtml#fig5_5)，该图说明了不可扩展的设置：

![](images/Image24202.jpg)

**图 5.5：** 不可扩展设置

为了提高性能，可扩展系统可以被扩大、负载均衡或集群化。假设一家公司需要设置一台新的 Web 服务器。系统管理员找到一台旧系统，可将其转换为新的 Web 服务器。在评估组织需求后，得出结论认为该 Web 服务器将满足组织当前的需求。然而，它将无法满足六个月后的预估需求。如果升级费用不高得令人望而却步，升级服务器以提高可扩展性可能是一种选择。应将更新成本和新的可扩展性值与全新系统的成本和可扩展性进行比较。请参阅[图 5.6](#c05.xhtml#fig5_6)，该图说明了可扩展设置：

# 能力

解决方案能够执行的活动称为其能力。例如，**入侵检测系统** (**IDS**) 检测入侵，而**入侵预防系统** (**IPS**) 防止入侵。应了解解决方案执行其功能的机制，以及组织不需要的任何解决方案功能。通常，安全解决方案以更高的成本提供更多功能。

# 易用性

使安全系统或设备更易于使用，并使其更紧密地贴合组织目标和需求，被称为易用性。确保组织员工能够采用和管理新的安全系统至关重要。在计算**投资回报率** (**ROI**) 和总拥有成本时，所有员工培训支出都必须计入解决方案的成本中 (TCO)。由于易用性原因，即使是最优秀的安全系统也可能被排除在备选方案之外。

# 可维护性

安全系统或设备必须更新的频率，以及执行更新所需的时间长度，被称为可维护性。这包括打补丁、清理日志和更新软件。在评估可维护性时，组织应检查需要多少维护、完成维护需要多长时间以及通常执行维护的频率。任何预期的未来变更也应纳入维护考量中。

# 可用性

计算机系统可供使用的时间长度，以百分比表示，称为可用性。在确定可用性时，经常使用**最大可接受停机时间** (**MTD**)、**平均修复时间** (**MTTR**) 和**平均故障间隔时间** (**MTBF**) 这些术语，如[图 5.7](#c05.xhtml#fig5_7) 所示。为了通过 CASP 考试，您必须能够判断何时安装新设备或技术以提高数据可用性。请考虑以下场景：

假设一家小型企业使用单台主机托管多台虚拟化客户端服务器。该组织正考虑添加一台新主机以形成集群。尽管新主机的硬件和操作系统将与原主机不同，但底层虚拟化技术将保持兼容。两台主机将使用共享的 iSCSI 存储解决方案。得益于 iSCSI 存储解决方案，客户数据将更易访问。评估可用性的最佳方法是查看安全系统中最有可能发生故障的组件。了解解决方案将不可用多长时间、修复需要多长时间以及故障间隔多长时间，这些都是评估可用性的关键因素。请参阅[图 5.7](#c05.xhtml#fig5_7)，该图说明了系统停机可用性：

# 可恢复性

失败的安全解决方案或设备能否在特定时间范围内，利用既定实践和程序恢复到正常运行状态的可能性，称为**可恢复性**。在评估可恢复性时，经常使用**恢复时间目标** (**RTO**)、**工作恢复时间** (**WRT**) 和**恢复点目标** (**RPO**) 这些术语。评估可恢复性的最佳方法是研究如果需要对安全解决方案或设备进行部分或完全恢复，将需要执行哪些活动。在不同安全系统或设备之间做决定时，了解恢复需要多长时间至关重要。

# 成本/效益分析
