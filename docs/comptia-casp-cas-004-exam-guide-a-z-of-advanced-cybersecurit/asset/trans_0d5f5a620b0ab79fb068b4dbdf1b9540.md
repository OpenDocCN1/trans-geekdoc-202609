# 虚拟化安全

服务器虚拟化已成为降低数据中心物理占地面积的重要方面。其优势包括：

* 降低数据中心的整体电力消耗
* 动态分配内存和 CPU 资源给服务器
* 通过在主服务器故障时快速启动副本服务器来提供高可用性

然而，在虚拟网络中，必须在物理环境中处理的大多数相同安全漏洞也必须得到解决。虚拟机 (VM) 是虚拟环境中操作系统的实例。宿主系统可以支持大量虚拟机。虚拟机的资源（CPU、内存和磁盘）由管理程序分配，如[图 10.5](#c10.xhtml#fig10_5) 所示。请记住，在任何虚拟环境中，物理服务器上托管的每台虚拟服务器都必须配置其自己的安全方法。这些技术包括防病毒和反恶意软件，以及虚拟机上所有软件的最新服务包和安全更新。此外，请记住，所有虚拟服务器共享实际设备的资源。当虚拟化托管在 Linux 机器上时，必须安装在宿主机上的任何敏感应用程序都应放置在 `chroot` 环境中。在基于 UNIX 的操作系统上，`chroot` 是一项改变当前正在运行的进程及其子进程的根目录的操作。在这样一个改变后的环境中运行的程序无法命名（因此也无法访问）分配的目录树之外的文件。[图 10.5](#c10.xhtml#fig10_5) 展示了虚拟机架构：

管理程序分为两类（有关不同类型的管理程序，请参阅[图 10.6](#c10.xhtml#fig10_6)）。让我们看看它们之间的区别，如下所示：

# 基于容器

基于容器的虚拟化，通常称为操作系统虚拟化，是一种现代虚拟化方法。这种类型的服务器虚拟化利用内核支持多个独立用户空间实例的能力。容器、虚拟专用服务器和虚拟环境都是用来描述这些实例的术语。在这种方法中，管理程序被操作系统级虚拟化取代，操作系统的内核允许多个独立的用户区域或容器。虚拟机不是操作系统的完整实例，而是同一操作系统的一个子集。基于容器的虚拟化广泛用于 Linux 系统，商业产品 Virtuozzo 和免费开源的 OpenVZ 项目即为示例。

# 超融合基础设施

融合基础设施是指供应商将所有存储、网络和计算设备组合到一个物理盒子中，从而简化数据中心部署（[图 10.7](#c10.xhtml#fig10_7)）。它为这些资源提供单一管理界面。Dell 系统管理系统即属于此类示例。超融合无需任何硬件修改，即可通过软件实现这种集成。它还利用了虚拟化。它连接多种服务，并允许通过单一界面进行管理。虽然这种技术通过简单添加额外硬件（而不考虑供应商）即可实现增长，但企业会在一定程度上依赖单一超融合供应商的解决方案。[图 10.7](#c10.xhtml#fig10_7) 展示了超融合基础设施：

虚拟桌面基础设施 (VDI) 是在虚拟环境中运行桌面操作系统的集中式服务器。用户从服务器访问并执行桌面。

# 安全飞地和安全卷

安全飞地和安全卷的目的都是减少使用过程中关键时效数据以未加密状态存在的时间长度。安全飞地是处理已加密数据的处理器。这意味着即使拥有对虚拟环境底层硬件访问权限的个人也无法访问数据。Windows Azure 支持安全飞地，安全处理器阻止主处理器访问数据。安全卷以另一种方式实现这一目的。卸载并隐藏安全卷，直到需要时为止。之后，将其挂载并解密。修改完成后，磁盘被加密并卸载。

# 云增强安全服务

云计算如今风靡一时，大家都争相将数据“上云”。然而，这样做引发了安全担忧。您的数据物理位置在哪里？它是否与其他人的数据混合在一起？它安全吗？将数据的安全托付给他人令人恐惧。以下章节将探讨云安全问题。

# 哈希匹配

一种称为哈希匹配或哈希欺骗的过程已被用于从云基础设施窃取数据。对云供应商 Dropbox 的攻击就是该漏洞的一个典型例子。作为数据去重过程的一部分，Dropbox 使用哈希来标识用户存储在云中的数据块。当用户连接时，这些哈希值（源自数据并用于唯一标识数据的值）被用来确定数据是否已更改，从而指示是否需要同步进程。攻击中使用了欺骗性哈希来访问其他客户的任意数据片段。
