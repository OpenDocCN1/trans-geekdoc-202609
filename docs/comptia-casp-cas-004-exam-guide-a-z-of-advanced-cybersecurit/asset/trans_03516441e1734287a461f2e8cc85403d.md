

# 安全评估工具

## 密码破解工具：John the Ripper

John the Ripper 是另一个密码破解工具的例子。它能识别薄弱的 UNIX 密码，但也支持各种其他平台的哈希值。John the Ripper 有三个版本——免费的官方版本、社区改进版本（包含大量贡献的补丁但质量保证较少）和廉价的专业版。如果你在强制执行强密码或复杂密码方面遇到困难，并需要发现网络上的弱密码，你可以使用密码破解工具来确定哪些密码薄弱，并可能将其破解。如果评估密码安全性是时效性的，请将密码文件保存到你更强大的 PC 之一（集群效果更佳），并在那个平台上执行密码破解工具。这样，你就能利用额外资源更快地完成审计。

## 命令行工具

在 Windows 和 Linux/UNIX 中都有许多本地命令行实用程序可用于进行安全评估。虽然它们不如一些自动化工具用户友好，但由于其灵活性，它们受到该领域许多经验丰富人士的青睐，因为它们确实需要更多的知识和背景。以下几节将讨论几个与安全相关的命令行工具。

### Netstat

在基于 TCP/IP 的系统上，`netstat`（网络状态）命令用于查看哪些端口正在监听。`-a` 选项显示所有端口，而 `/?` 显示可用的其他选项。（可能因操作系统而异。）当不带任何开关运行程序时，将显示当前连接，如 [图 13.15](#c13.xhtml#fig13_15) 所示。`netstat` 可以帮助你弄清哪些端口是开放的，以及哪些服务/协议正在使用它们。这些开放端口可能会使主机的安全面临风险。请参考 [图 13.15](#c13.xhtml#fig13_15) 中的 `netstat` 输出：

![](images/Image28207.jpg)

**图 13.15：** netstat 输出

`netstat` 输出的每一行列出源 IP 地址和端口号、目标 IP 地址或主机名以及连接状态。可能的状态如下：

*   `LISTEN`：表示等待来自任何远程 TCP 连接和端口的连接请求。
*   `SYN-SENT`：表示发送了连接请求后，等待匹配的连接请求。
*   `SYN-RECEIVED`：表示在接收并发送了连接请求后，等待确认的连接请求确认。
*   `ESTABLISHED`：表示打开连接，接收到的数据可传递给用户。这是连接数据传输阶段的正常状态。
*   `FIN-WAIT-1`：表示等待来自远程 TCP 连接的连接终止请求，或先前发送的连接终止请求的确认。
*   `FIN-WAIT-2`：表示等待来自远程 TCP 连接的连接终止请求。
*   `CLOSE-WAIT`：表示等待来自本地用户的连接终止请求。
*   `CLOSING`：表示等待来自远程 TCP 连接的连接终止请求确认。
*   `LAST-ACK`：表示等待先前发送给远程 TCP 连接的连接终止请求的确认（其中包括对其连接终止请求的确认）。

### Ping

`ping` 命令使用 ICMP 协议验证两个设备之间的连接。TCP/IP 协议的 `ping` 命令是最有用的命令之一。它向另一个系统发送一系列数据包，该系统会以自己的响应进行回应。在排查远程主机的困难时，`ping` 命令可能非常有益。`ping` 命令显示主机是否可达以及主机响应需要多长时间。局域网上的时间显示为小于 10 毫秒。然而，在广域网上，此数字可能显著更高。当使用 `-a` 参数时，`ping` 还会尝试解析与 IP 地址关联的主机名。成功的 `ping` 如 [图 13.16](#c13.xhtml#fig13_16) 所示：

![](images/Image28214.jpg)

**图 13.16：** 成功的 Ping

[图 13.17](#c13.xhtml#fig13_17) 显示了不成功的 `ping`。在这种情况下，请求超时，通常意味着主机已关闭或已从网络断开。当无法到达目标时，将显示错误代码。请参考 [图 13.7](#c13.xhtml#fig13_7) 中失败的 `ping`：

![](images/Image28224.jpg)

**图 13.17：** 失败的 Ping

这些代码中最常见的如下：

*   `Destination unreachable`：这表示 IP 数据报无法转发。这还包括一个错误代码（数字），指示更多细节——例如，没有路由表条目，或目标可达但未响应 ARP。
*   `Request timed out`：这表示数据报的 TTL 被超越。这意味着你甚至没有收到路由器的响应。如果路由器配置为不响应 ICMP，则可能发生这种情况，这并不罕见。这就是 [图 13.17](#c13.xhtml#fig13_17) 中的情况。

虽然使用其他工具（如 `Nmap`）有更简单的方法来做这件事，但你可以通过创建一个简单的批处理文件来执行 ping 扫描，如下所示：

```
for /l %i in(1,1,254) do ping -n 1 -w 100 <first three octets of host network>.%i
```

例如，要扫描 192.168.1.0 网络，可以使用以下命令：

```
for /l %i in(1,1,254) do ping -n 1 -w 100 192.168.1.%i
```

### Tracert/Traceroute

`traceroute` 命令（在 Linux 和 UNIX 中）用于追踪数据包通过网络的旅程。其最有用的目的是确定数据包在网络中何处丢失。它显示数据包经过的每一跳（路由器）以及所需的时间。[图 13.18](#c13.xhtml#fig13_18) 部分显示了到 [www.nascar.com](http://www.nascar.com) 的追踪路由。此命令也可用于记录到目标的路由，并从 `Nmap` (`Zenmap`) 内部以可视化方式显示；图形结果通常比命令行输出更容易解释。每一行表示一跳，或通信通过的网络（即路由器）。很多时候，这些路由无法完全绘制，因为在目标所在网络的边缘 ICMP 被阻断。请参考 [图 13.18](#c13.xhtml#fig13_18)，其中演示了 `tracert` 输出：

### Ipconfig/Ifconfig

`ipconfig` 命令用于查看设备的 IP 配置，并且当与特定开关或参数结合使用时，可用于释放和续租从 DHCP 服务器获得的 IP 地址租约，以及刷新 DNS 解析器缓存。其最常见的用途是查看当前配置。[图 13.19](#c13.xhtml#fig13_19) 显示了其带 `/all` 开关的执行情况，结果显示了关于 IP 配置的大量信息：
