

# DNS 收集

DNS 收集是获取组织 DNS 记录以用于网络映射的过程。DNS 收集最容易通过非法区域传输来完成。然而，在 Windows 上使用 `tracert` 工具或在 UNIX 上使用 `traceroute` 实用程序，是敌对用户可能检索到少量记录的一种方法。这些工具追踪数据包从其源头到目的地的旅程。`tracert` 的跳数列表或数据包经过的路由器列表中的最后几个设备，通常位于组织网络内部。如果 `tracert` 显示了这些设备的名称，黑客就可以访问它们。`tracert` 输出如 [图 12.6](#c12.xhtml#fig12_6) 所示。在本例中，`tracert` 能够解析出一些路由器的名称，但不是最后两个。最后几跳经常会超时，因为目标网络运营商将路由器配置为忽略 ICMP 数据包。请参阅显示此内容的 [图 12.6](#c12.xhtml#fig12_6)：

另一种 DNS 收集方法是说服组织的 DNS 服务器将区域传输给攻击者。虽然这过去相当简单，但如果组织选择指定可通过其完成区域传输的 DNS 服务器，现在就会变得稍微复杂一些。在尝试从未经授权的 DNS 服务器进行 DNS 区域传输之前，您应该仔细检查是否已完成此步骤。[图 12.7](#c12.xhtml#fig12_7) 显示了来自 Microsoft DNS 服务器的对话框；您可以在 DNS 服务器属性的“区域传输”选项卡上定义仅允许发生区域传输的服务器：

`nslookup` 命令是一个用于诊断和测试 DNS 服务器的命令行实用程序。它有两种操作模式——`interactive`（交互式）和 `noninteractive`（非交互式）。`interactive` 模式允许您在不退出 `nslookup` 模式的情况下，查询名称的 IP 地址或 IP 地址的名称。当只需要返回单条数据时，`noninteractive` 模式是理想选择。作为针对域的 `nslookup` 示例，请参阅 [图 12.8](#c12.xhtml#fig12_8)。如果存在，`nslookup` 会找到本地系统设置使用的 DNS 服务器的 IP 地址和名称，然后返回到 `> 提示符`。您可以在此提示符下输入 IP 地址或名称，系统将尝试将 IP 地址解析为名称或将名称解析为 IP 地址。[图 12.8](#c12.xhtml#fig12_8) 显示了此内容：

# 搜索引擎

搜索引擎（如 Google、Yahoo 和 Bing）可用于获取侦察信息。使用基于复杂运算符的搜索，通过搜索引擎定位可利用的目标和敏感数据，称为**搜索引擎黑客技术**。一些对黑客友好的搜索引擎示例如下：

*   `Shodan`
*   `IVRE`
*   `ZoonEye`
*   `Censys`
*   `Test Types`

虽然维护网络安全似乎是一项艰巨的任务，但有几种技术可协助您。不幸的是，每种具有合法应用的工具也可能被用于邪恶目的。黑客使用这些工具来识别、渗透和管理网络，但您可以使用它们来防止攻击成功。以下部分介绍一些最常见的评估工具。

# 渗透测试

渗透测试（也称为笔试）是一种模拟对系统、网络或应用程序进行攻击的安全测试类型。其重要性源于其发现可能被忽视的安全缺陷的能力。它与漏洞测试不同，因为它试图利用问题而不仅仅是发现问题。没有什么比因缺陷导致敏感数据泄露更能引起人们对软件缺陷的关注了。从这些测试中获得的最有用的知识之一，是发现单独行动时无害，但结合使用时会导致安全问题的单一操作。当使用像 `Metasploit` 或 `Canvas` 这样的框架时，这些测试可以变得更有效。

渗透测试应定期进行，频率由网络上信息的敏感度决定。[图 12.9](#c12.xhtml#fig12_9) 展示了 `Retina` 的一个示例，这是一种可与渗透测试工具 `Metasploit` 结合使用的漏洞工具。在此输出中，测试发现了八个主要缺陷（由向上指的箭头指示）——终端服务中的加密不足、六个 Oracle 漏洞，以及一个与计算机上的虚拟化软件 `Oracle VirtualBox` 相关的漏洞。[图 12.9](#c12.xhtml#fig12_9) 显示了 `Retina` 渗透测试器：

## 执行渗透测试的步骤

执行渗透测试的步骤如下：

**步骤 1**：记录目标系统或设备的信息。

**步骤 2**：收集针对目标系统或设备的攻击方法信息。

**步骤 3**：识别目标系统或设备的已知漏洞。

**步骤 4**：对目标系统或设备执行攻击以获取用户和特权访问。

**步骤 5**：记录渗透测试的结果并向管理层报告发现，同时提供补救措施建议。

## 渗透测试策略

应同时进行内部和外部测试。内部测试在网络内部进行，而外部测试在网络外部进行，针对公开暴露的服务器和设备。渗透测试策略取决于组织既定的测试目标。作为 CASP 候选人，您应该熟悉以下策略：

*   **盲测**：测试团队对网络系统和设备知之甚少，仅获得公开可访问的信息来执行测试。公司的安全人员知道攻击迫在眉睫。此测试要求测试团队付出额外的工作。
*   **双盲测试**：此测试类似于盲测，不同之处在于组织的安全人员不知道即将发生的攻击。此测试通常需要测试团队和公司安全团队的共同努力。
*   **目标测试**：测试团队和组织的安全团队都获得关于网络和将要进行的测试类型的尽可能多的信息。这是最容易执行的测试类型，但它不能提供公司安全状况的完整图景。

## 渗透测试类别

�透透测试还根据提供给测试团队的数据量进行分类。以下是您应该熟悉的主要类别：

*   **零知识测试**：测试团队不获得关于公司网络的任何信息。测试团队可以利用任何可用的方法来收集关于组织网络的信息。这也称为封闭测试或黑盒测试。
*   **部分知识测试**：测试团队获得关于公司网络的公开信息。为此类测试可以建立边界。
*   **完全知识测试**：测试团队获得对组织网络所有信息的访问权限。此测试侧重于可以执行的攻击类型。

# 黑盒

渗透测试可根据需要收集的数据量分为多种类型。在黑盒测试中，也称为**零知识测试**，测试团队不获得关于组织网络的任何信息。测试团队可以使用其可用的任何工具来收集关于组织网络的知识。这也称为封闭测试。
