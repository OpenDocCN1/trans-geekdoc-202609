

## 威胁情报集成

为了在攻击者前面保持领先，企业需要了解威胁的演变。复杂的对手和**高级持续性威胁 (APT)** 能够快速且隐蔽地行动，安全团队需要最新且准确的情报，以确保防御措施能够自动且精准地调整。威胁情报集成解决方案应融入自动化，以调查所有事件并在几分钟内（而非几小时）获取知识。它应直接从端点生成自定义**失陷指标 (IoC)**，从而针对未来的攻击实现主动防御。同时也应包含人为因素，由专家安全研究人员、威胁分析师、文化专家和语言学家组成，他们能在各种背景下理解新出现的威胁。

## 端点检测与响应

**端点检测与响应 (EDR)** 是一种主动的端点安全方法，旨在补充现有防御。这种先进的端点方法将安全从被动的威胁应对转变为能够在威胁到达组织之前检测并阻止威胁。它专注于有效威胁防护的三个基本要素：自动化、适应性和持续监控。EDR 产品示例如下：

- FireEye Endpoint Security
- Carbon Black Cb Response
- Guidance EnCase Endpoint Security
- Cybereason Enterprise Protection
- Symantec Endpoint Protection
- RSA NetWitness Endpoint

EDR 系统的优势在于提供持续监控。劣势在于软件对资源的占用可能会影响设备性能。

## 补丁管理

软件补丁是供应商发布的更新，用于修复运行在网络设备上的操作系统、应用程序和固件版本中的功能问题或关闭安全漏洞。为确保所有设备都安装了最新补丁，应部署一套正式系统，确保所有系统在非生产环境中经过彻底测试后接收最新更新。供应商无法预见变更可能对网络中业务关键系统产生的所有可能影响。确保补丁不对运营产生不利影响是企业的责任。 *[图 7.5](#c07.xhtml#fig7_5)* 说明了补丁管理：

供应商通常提供多种类型的补丁，如下所示：

- **热修复**：热修复是解决安全问题的更新，如果其解决的问题与系统相关，应立即应用。
- **更新**：更新解决的是功能问题而非安全问题。
- **服务包**：服务包包含自操作系统发布以来的所有更新和热修复。

## 手动补丁管理

虽然手动补丁管理比自动化系统（将在下一节讨论）需要更多的管理工作，但仍可通过以下步骤实施：

**步骤 1**：确定补丁的优先级。

**步骤 2**：部署前测试补丁，确保其正常工作且不会导致系统或安全问题。

**步骤 3**：在生产环境中安装补丁。

**步骤 4**：补丁部署后，确保其正常工作。

## 自动化补丁管理

大多数组织通过集中式更新解决方案（如 **Windows Server Update Services (WSUS)**）来管理补丁。借助此类服务，组织可以以受控且自动化的方式部署更新。WSUS 服务器下载更新，并从 WSUS 服务器本地应用。组策略也用于此场景中，以配置存放更新的服务器位置。脚本也可用于自动化补丁流程。与使用自动化工具相比，这可能提供更大的灵活性和流程控制。不过，这可能需要更深入的脚本编写知识。在某些情况下，地理位置分散的服务器可用于提供脚本中引用的补丁。此时，必须设置适当的复制，以确保所有补丁在所有补丁服务器上均可用。Windows PowerShell 命令越来越多地被用于自动化 Windows 功能。在 Linux 环境中，则使用 Linux Shell 脚本实现此目的。 *[图 7.6](#c07.xhtml#fig7_6)* 说明了自动化补丁管理流程：

## 数据丢失防护

数据泄露是指敏感数据有意或无意地泄露给未授权人员。**数据丢失防护 (DLP)** 是一系列监控和保护业务数据免受未授权访问的技术和工具的集合。实施 DLP 技术后，它会在三个位置保护数据——授权人员使用中、传输中（通过内部网传输）或静止中（在文件服务器或数据库中）。例如，数据丢失防护软件可以阻止用户复制数据并将其移出公司网络。所有数据丢失防护软件的核心是内容检查，即软件在数据于网络中移动时检查数据片段，评估包含它们的文件类型，并确定数据是否位于应在的位置以及是否用于其预期用途。意外泄露或恶意活动都可能使敏感数据陷入危险，这也是为什么 DLP 安全对于需要保护数据资产的组织至关重要。 *[图 7.7](#c07.xhtml#fig7_7)* 说明了在组织中实施 DLP 的收益：

## DLP 如何工作？

DLP 软件基于内容检查，它使用一系列方法来捕获策略违规，如下所示：

1.  首先，内容检查基于由数据丢失防护软件检测到的基于规则的表达式，并导致后续动作。一个典型例子是 16 位信用卡号。组织可以创建规则，规定如果您尝试通过电子邮件发送信用卡号（以 4、5 或 6 开头），特别是包含 3 位安全码和有效期，DLP 软件将阻止邮件发送或自动加密。
2.  接下来是精确文件匹配。这会识别正在使用中、传输中或静止中、其内容与已索引文件完全匹配的文件。这也称为**数据指纹识别**。
3.  第三是 DLP 解决方案中使用概念/词汇分析的内容分析。此级别的分析使用字典编译或其他列表和规则来识别不需要的行为，例如特定的互联网搜索，或与网络外部人员共享商业机密。
4.  最后，内容分析可结合复杂的统计分析技术。统计方法利用机器学习来保护特定信息。当机器学会数据应有的样子时，它会持续寻找不匹配给定模式的异常数据。
