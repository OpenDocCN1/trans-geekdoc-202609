# Distributed systems interconnection protocol

Distributed systems interconnection protocol (DSiP) forms simultaneous communication channels between the remote end and the control room: if one communication channel is down, other channels will continue operating. DSiP makes communication reliable and unbreakable by using various physical communication methods in parallel.
