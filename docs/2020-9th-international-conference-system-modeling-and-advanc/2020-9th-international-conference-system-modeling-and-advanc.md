**摘要—** 社交媒体上误导性新闻报道的泛滥对人类可能产生负面影响，这带来了巨大的挑战。现有的词汇变体特征无法检测伪造新闻。大多数研究使用包含有限训练数据的小型数据集。在本文中，我们评估了机器学习和深度学习技术。LIAR 是一个主要的数据集，包含来自不同来源（包括社交媒体）的 12836 条短笔记。与现有的先进算法相比，提出的框架在准确率方面有了显著提高。

**关键词—** 虚假新闻、机器学习、自然语言处理、LSTM。

## I. 引言

如今是一个数据时代。社交媒体每天产生海量数据。因此，生成的内容可能是虚假信息或谣言。这可能是故意的也可能是无意的。在现实生活中检测虚假新闻是一项极具挑战性的任务。通常，我们可以将虚假新闻定义为“一种故意且可证实的虚假文章[19]”。虚假新闻有多种形式，如误导信息、骗局、讽刺和偏见新闻。人们在数字平台上根据自己的信仰分享新闻。检测虚假新闻很困难，因为它们的编写初衷是为了欺骗人们。

虚假新闻有多种定义。文献[8]的作者将虚假新闻定义为“一种故意且可证实的虚假文章”。虚假新闻有多种类型，如讽刺、点击诱、偏见内容、虚构新闻、宣传和骗局等。虚假新闻可以被分为不同的种类，如虚假新闻、虚假视频、伪造图像等。此外，这些虚假故事需要被处理。这个问题存在深网上，像一个需要维护的火山。这并不容易，因为需要大量的研发。2020年底，有超过2180伊朗人饮用甲醇，结果导致900人进入重症监护室（ICU），296人死亡[9]。互联网上存在的巨大数据可能成为此类虚假新闻逃避检测和隔离的避风港。

在这工作中，提出的模型使用词袋模型（Bag of words）和tf-idf从LIAR数据集中提取特征。我们使用新闻内容作为主要特征，但也考虑了用于状态和亲和关系的个人信息。我们提出了一个重要性标签：从“真实的”、“月度的”、“半真的”到“虚假的”、“几乎真实的”，以构建虚假数据集。我们还添加了POS和全局嵌入（Globe embedding），以确保现有结果使用我们的各种类别，包括深度学习（DL）模型：LSTM、CNN和朴素贝叶斯，以及机器学习模型。通过使用LIAR[10]数据集，我们将准确率提高了3%。

### B. 机器学习模型

机器学习模型用于识别虚假新闻并提供有用的结果。文献[12]将机器学习技术用于虚假新闻分类任务。在工作中，对于特征提取，我们使用TF-idf并考虑单字（unigram）、双字词（bigram）以及它们之间的关系。TF-idf用于预测单词的重要性。它通过以下公式计算：

```
tf_{ij} = \frac{f_{ij}}{\sum f_{ik}}
```

其中 tf 是 i 在 j 中出现的次数。

total number of words in the document)

其中 N 是文档总数，df 是包含术语 t 的文档数。

```

### C. 朴贝叶斯算法

这是一种基于特征独立假设的概率分类器。它应用了贝叶斯定理。论文 [13] 也采用了机器学习方法进行隐蔽检测。他们应用了贝叶斯分类器，将新闻的每条声明视为一个独立的特征。

我们在下文中应用了贝叶斯定理：

```
P(c|x) = \frac{P(x|c)P(c)}{P(x)}
```

其中 c 是类别，x 是描述向量。

P(c|x) 是事件 x 的后验概率，P(c) 是 c 的先验概率。

### D. 线性 SVM 分类器

支持向量分类器使用直线或超平面将数据划分为类别，以解决分类或回归问题。其数学描述为：

```
$y = f(x) = \sum(w_ix_i)$
```

在这里，x 是坐标，w 是决定直线斜率的参数。

### E. 逻辑回归

我们将逻辑回归用于预测后续事件。它是一种分类算法。当因变量为分类变量时，使用逻辑回归。

```
$P = \frac{1}{1+e^{-(w^Tx+b)}}$
```

在这里，P 是 i 的发生概率，e 是自然对数的底，b 和 m 是模型参数。

通过使用比率

```
$\frac{P}{1-P} = \exp(w^Tx+b)$
```

(P) 值始终处于 0 到 1 之间；在某些情况下，几率范围可以从 0 到无穷大。几率定义为发生事件概率与不发生事件概率的比值。

### F. 随机森林

随机森林是一种使用集成学习创建森林的监督算法。该算法可以应用于分类、回归等领域。该算法在大数据集上表现良好。

```
$ft_i = \frac{1}{n} \sum_{j=1}^{n} f_{ij}$
```

```
$norm_i = \frac{1}{n} \sum_{j=1}^{n} f_{ij}$
```

```
$RFT_i = \sqrt{\sum (ft_i - norm_i)^2}$
```

### G. 决策树分类器

决策树可用于执行分类或回归任务。它在利用机器学习和深度学习技术的虚假新闻检测的分类和数值数据方面表现良好。在我们的实验中，我们使用的 Gini 纯度达到了 94% 的准确率。

Gini 用于计算观察值分类不准确的概率。Gini 用以下数学符号表示：

```
$G(z) = P(i) \log P(i) + (1-P(i)) \log(1-P(i))$
```

其中 P(i) 代表训练数据中分类的概率。

### H. 深度学习模型

深度学习被用于自动提取显著特征。论文 [14] 采用了深度学习技术进行立场检测。他们采用 RNN 模型提取特征。Bi-LSTM 取得了最佳结果。未来，情感分析可以进一步提升性能。论文 [15] 也应用了深度学习技术来区分词汇之间的合成关系和语义关系。他们得出深度学习模型在大数据集上表现良好。作者在论文 [16] 中提出了一种用于虚假新闻检测的新模型 CNN。他们使用了显式特征和潜在特征，未来可以采用更多特征来增强模型性能。作者 [18] 使用 CNN 和 LSTM 计算新闻的可靠性。实验使用了带有嵌入文本和标题的视觉特征。

#### I. LSTM

这是一种神经网络，当上下文变得可靠以预测未来结果时使用。RNN 将输出作为具有若干层的下一层。在这里，输出取决于上下文（例如在任何故事下），并且需要了解这些。RNN 在多个领域发挥作用，如预测词、视频字幕、股市预测、序列预测、情感分析和分类。

在 RNN 的情况下，反向传播过程中梯度可能会消失或爆炸。在梯度爆炸的情况下，权重可能会减小。为了克服这些限制，使用了 LSTM。LSTM 不读取所有输入，LSTM 使用上下文进行记忆。GRU 是 LSTM 的一种特殊类型，没有记忆功能。图 2 展示了使用 GRU 的 LSTM 架构。这里 x 是输入层，y 是输出层。第9届系统建模与研究趋势国际会议，2020年12月4日，工程科学学院，Mahaveer University, Moradabad, India

# IV. 提出的框架

对于预处理，我们使用 NLTK 库来管理停用词和词干提取。我们应用 snowball stemmer 将句子转换为词根形式。我们还去除了标点、符号，只保留字母。将数据集转换为小写。使用 `duplicate()` 函数删除数据中的重复行。根据实验结果，提出的数据集被分为 80:20 的训练和测试比例。

我们合并了训练和验证数据集进行实验。在工作中，使用 NLTK POS 标记器对内容的每个词分配标签。POS 标记后，每个词被分配了一个标签。未出现在新闻内容的 POS 标记被变为零向量。我们的工作使用了 300 维全局嵌入。在传递双向 LSTM 和 CNN 之前，嵌入按字母顺序排序。
