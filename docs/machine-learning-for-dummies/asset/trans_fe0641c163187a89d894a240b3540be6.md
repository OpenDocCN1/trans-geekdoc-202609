

感知器的天然专长是二元分类。然而，你可以使用更多模型（针对每个类别猜测一个模型，这种训练策略称为一对其余或 OVA）来预测多个类别。除了分类之外，感知器无法提供更多信息。例如，你无法使用它来估计预测准确的概率。从数学角度来看，感知器试图最小化以下误差函数公式，但它仅针对被误分类的示例（换句话说，其符号与正确类别不符的示例）：

该公式是[第 8 章](#c08.xhtml)中定义的代价函数的一个示例，仅涉及矩阵 `X` 中在当前 `w` 集合下被分配了误分类符号的示例。要理解该公式的功能，你必须考虑只有两个类别。第一个类别的示例在响应向量 `y` 时表示为 +1 值，而另一个类别的示例相应地编码为 –1。该公式选取每个被误分类的示例，并依次将其特征与向量 `w` 相乘，然后加上偏置。

由于括号内被误分类的示例 `X` 与权重向量 `w` 的乘法是向量乘法，你应该转置示例的特征向量 `x`，以便与 `w` 相乘的结果是一个数字。这是[第 7 章](#c07.xhtml)中介绍的矩阵乘法的一个方面。

![Remember](images/remember.png)乘以两个向量相当于使用第二个向量中的值作为权重，对第一个向量中的值进行加权求和。因此，如果 `x[i]` 有五个特征，而向量 `w` 有五个系数，则它们相乘的结果是所有五个特征的和，每个特征首先乘以其各自的系数。矩阵乘法使公式中的表达更加紧凑，但归根结底，该操作与加权平均值并无不同。

在得到向量乘法的结果后，你将偏置值相加，并将所有内容乘以你本应预测的值（第一个类别为 +1，第二个类别为 –1）。由于你只处理被误分类的示例，该操作的结果始终为负数，因为两个符号不匹配的值相乘始终为负数。

最后，在对所有被误分类的示例运行相同的计算后，你将所有结果汇总并求和。结果是一个负数，由于前面所示误差公式开头的负号（相当于将所有内容乘以 –1）而变为正数。随着感知器错误数量的增加，结果的大小也会增大。

通过仔细观察结果，你会发现该公式的设计非常巧妙（尽管远非罗森布拉特所期望的奇迹）。错误数量越少，输出越小。当没有误分类时，求和结果变为零。通过将公式置于这种形式，你告诉计算机尝试实现完美分类并永不放弃。其理念是，当它找到向量 `w` 的正确值且没有任何预测错误时，剩下要做的就是应用以下公式：

![math](images/eq10002.png)<m:math display="block" overflow="scroll" xmlns:m="http://www.w3.org/1998/Math/MathML"><m:mrow><m:mover accent="true"><m:mi>y</m:mi><m:mo>&#770;</m:mo></m:mover><m:mo>=</m:mo><m:mtext>&#8201;</m:mtext><m:mi>s</m:mi><m:mi>i</m:mi><m:mi>g</m:mi><m:mi>n</m:mi><m:mfenced open="(" close=")"><m:mrow><m:mrow><m:mi>X</m:mi><m:mi>w</m:mi><m:mo>+</m:mo><m:mi>q</m:mi></m:mrow></m:mrow></m:mfenced></m:mrow></m:math>

运行该公式将输出一个预测向量（`y-hat`），包含一系列 +1 和 –1 值，对应于预期的类别。

## 遇到非线性可分限度

感知器计算的秘密在于算法如何更新向量 `w` 的值。此类更新通过随机选择一个被误分类的示例（称其为 `x[t]`），并使用简单的加权加法更改 `w` 向量来实现：

![math](images/eq10003.png)<m:math display="block" overflow="scroll" xmlns:m="http://www.w3.org/1998/Math/MathML"><m:mrow><m:mi>w</m:mi><m:mo>=</m:mo><m:mtext>&#8201;</m:mtext><m:mi>w</m:mi><m:mo>+</m:mo><m:mi>&#951;</m:mi><m:mo>\*</m:mo><m:mfenced open="(" close=")"><m:mrow><m:mrow><m:msub><m:mrow><m:mi>x</m:mi></m:mrow><m:mrow><m:mi>t</m:mi></m:mrow></m:msub><m:mo>\*</m:mo><m:msub><m:mrow><m:mi>y</m:mi></m:mrow><m:mrow><m:mi>t</m:mi></m:mrow></m:msub></m:mrow></m:mrow></m:mfenced></m:mrow></m:math>

希腊字母 eta（`η`）是 `学习率`。它是 0 到 1 之间的浮点数。当你将此值设置为接近零时，可以限制公式过度更新向量 `w` 的能力，而将值设置为接近一则使更新过程完全影响 `w` 向量的值。设置不同的学习率可以加快或减慢学习过程。许多其他算法也使用这种策略，较低的 eta 用于通过减少更新后 `w` 值的突然跳跃来改进优化过程。权衡是，在得到最终结果之前，你需要等待更长时间。

更新策略提供了关于使用感知器学习类别时发生情况的直觉。如果你想象示例投影到笛卡尔平面上，感知器只不过是一条试图将正类与负类分开的直线。正如你可能从线性代数中回忆的那样，所有以 `y = x*b+a` 形式表达的内容实际上都是平面上的一条直线。

最初，当 `w` 设置为零或随机值时，分离线只是平面上无数可能直线中的一条，如[图 10-1](#c10.xhtml#c10-fig-0001)所示。更新阶段通过迫使分离线更接近误分类点来对其进行定义。使用多次迭代来定义错误，将分离线放置在两个类别的确切边界上。

![FIGURE 10-1: 感知器跨越两个类别的分离线。](images/9781119724018-fg1001.png)

[图 10-1:](#c10.xhtml#rc10-fig-0001) 感知器跨越两个类别的分离线。

尽管这是一个非常聪明的算法，但感知器很快就暴露了其局限性。除了仅使用定量特征就能猜测两个类别之外，它还有一个重要局限：如果两个类别由于混合而没有边界，算法就无法找到解决方案，并会无限地自我更新。

![Remember](images/remember.png)如果你无法用任何直线或平面将分布在两个或多个维度上的两个类别分开，那么它们就是 `非线性可分`的。克服数据的非线性可分性是机器学习必须完成的挑战之一，以便在基于真实数据（而非仅为学术目的创建的人工数据）的复杂问题上取得有效效果。
