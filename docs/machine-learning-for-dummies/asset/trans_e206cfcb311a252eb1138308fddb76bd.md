数学是非常出色的。它可以使用一些简单的符号来描述现实世界的大部分内容，并且是机器学习的核心，因为任何学习算法都有能力表示某种数学表达式。有些算法，例如线性回归，明确地使用特定的数学表达式来表示响应（例如，房子的价格）与一组预测信息（例如市场信息、房屋位置、房地产面积等）之间的关系。

![Remember](images/remember.png)线性回归提供了一种易于理解的表达式，但它并不适合所有问题，因为并非所有问题都能以线性回归的方式来表示。其他一些复杂的算法，例如决策树（下一章的主题），使用明确的数学表达式来呈现相当复杂，但它们非常灵活，可以轻松近似大量表达式，因此可以解决更广泛的问题。

![Remember](images/remember.png)鉴于其对响应映射的简单性，算法可能会倾向于系统性地高估或低估复杂数据背后的真实规则。在这种情况下，算法受到偏差误差的影响。偏差误差是简单算法的特征，这些算法无法表达复杂的数学表达式，因此在某些情况下无法正确映射特征与目标变量之间的关系。

## 牢记模型复杂性

正如表达式的简单性是一个问题一样，自动求助于映射非常复杂的表达式并不总能提供解决方案。事实上，你不知道所需响应映射的真实复杂性（例如，它是适合直线还是曲线）。因此，正如简单性可能导致不合适的响应（请参阅 [图 9-1](#c09.xhtml#c09-fig-0001)），也有可能使用过于复杂的映射来表示数据中的复杂性。

复杂映射的问题在于它有许多术语和参数——在某些极端情况下，你的算法可能拥有的参数比数据中的示例还要多。因为你必须指定所有参数，算法就开始在数据中记忆一切——不仅记忆信号（重要的数据），还记忆

* 随机噪声

* 错误

* 不太具体的样本特征

在某些情况下，算法甚至可以记忆示例。但是，除非你正在处理一个具有有限简单特征且不同值很少的问题，否则鉴于数据集中所有可用特征的可能组合数量巨大，你极不可能遇到两次相同的示例。

当发生记忆时，你可能会产生一切运行良好的错觉，因为你的机器学习算法似乎很好地拟合了样本内数据。但是，当你开始在样本外数据上使用算法，并注意到它在预测中产生错误，并且这些错误在你用略有不同的方法从同一数据重新学习时会发生很大变化时，问题可能会迅速显现。`Overfitting` 发生在你的算法从数据中学习得太多，以至于映射出不存在的曲线形状和规则时，如 [图 9-2](#c09.xhtml#c09-fig-0002) 所示。程序或训练数据的任何微小变化都会产生反复无常的预测。

![FIGURE 9-2: A K-Nearest Neighbor model correctly fitting the problem on the left panel and becoming too complex while trying to map a curve function on the right panel.](images/9781119724018-fg0902.png)

[图 9-2：](#c09.xhtml#rc09-fig-0002) K-最近邻模型在左侧面板中正确拟合问题，而在右侧面板中试图映射曲线函数时变得过于复杂。

## 保持解决方案的平衡

为了创建出色的解决方案，机器学习模型在简单性（意味着更高的偏差）和复杂性（产生更高的估计方差）之间进行权衡。如果你打算获得最佳的预测性能，你确实需要找到一个中间的解决方案，通过了解哪种方法效果更好，你可以通过在数据上进行试错来实现。因为数据决定了预测问题最合适的解决方案，你既没有万能药，也没有解决所有机器学习难题的简单重复性解决方案。
