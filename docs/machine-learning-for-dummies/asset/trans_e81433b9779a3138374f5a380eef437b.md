### 使用 Google Colab 功能

Google Colab 通过菜单系统提供多种功能。其中一项功能是硬件加速，它出现在本章后面的“[使用硬件加速](#c06.xhtml#c06-sec-0031)”部分中。本部分中的功能均出现在“工具”菜单上。

“工具”⇒“命令面板”选项显示可执行的命令列表，如 [图 6-1](#c06.xhtml#c06-fig-0001) 所示。请注意，其中一些命令还带有快捷键，例如 Ctrl+Alt+M 用于向单元格添加注释。所有这些命令都可帮助您执行与笔记本内容相关的任务，例如添加表单。

![FIGURE 6-1: 使用 Colab 命令可轻松配置您的笔记本。](images/9781119724018-fg0601.png)

[FIGURE 6-1:](#c06.xhtml#rc06-fig-0001) 使用 Colab 命令可轻松配置您的笔记本。

“工具”⇒“设置”选项显示设置对话框，如 [图 6-2](#c06.xhtml#c06-fig-0002) 所示。四个设置选项卡执行以下任务：

*   `Site:` 配置站点的工作方式。最有趣的设置是主题。选择“自适应”可让 Colab 根据光照条件选择界面颜色。您还可以在此选项卡上配置显示和访问设置。

*   `Editor:` 决定文本在屏幕上的显示方式以及界面的工作方式。例如，如果需要，可以将按键绑定设置为与 Vim 相同。您还可以选择字体大小、每个缩进级别的空格数以及大量其他设置。

*   `Colab Pro:` 为 Colab Pro 提供广告，它确实能带来一些显著优势，例如更快的 GPU、更长的运行时间和更多内存——所有这些都能让您在更短的时间内完成更多工作。

*   `Miscellaneous:` 包含有趣的设置。您可以从三种视觉效果中选择：使用“功率级”设置添加雷电；让柯基犬在显示器顶部跑过；让小猫在显示器顶部跑过。您可以任意组合这些视觉效果。

![FIGURE 6-2: 设置对话框可帮助您配置 Colab IDE。](images/9781119724018-fg0602.png)

[FIGURE 6-2:](#c06.xhtml#rc06-fig-0002) 设置对话框可帮助您配置 Colab IDE。

您可能不喜欢默认的键盘快捷键。选择“工具”⇒“键盘快捷键”时，您会看到键盘首选项对话框，如 [图 6-3](#c06.xhtml#c06-fig-0003) 所示，您可以在其中自定义键盘快捷键以满足您的需求。如果看到“设置快捷键”，则表示该命令当前没有快捷键，因此如果需要，您可以添加一个。以下是使用快捷键的方法：

*   要添加或更改快捷键，请将光标放在命令旁边的框中，然后按下要用于该命令的快捷键。

*   要删除快捷键，请按 Delete。

![FIGURE 6-3: 自定义快捷键以加快命令访问速度。](images/9781119724018-fg0603.png)

[FIGURE 6-3:](#c06.xhtml#rc06-fig-0003) 自定义快捷键以加快命令访问速度。

## 获取 Google 帐户

在使用 Colab 执行任何重要任务之前，您必须拥有一个 Google 帐户。您可以使用同一个帐户用于各种用途，而不仅仅是开发。例如，Google 帐户可让您访问 Google Docs ([`https://www.google.com/docs/about/`](https://www.google.com/docs/about/))，这是一个类似于 Office 365 的在线文档管理系统。

### 创建帐户

要创建 Google 帐户，只需导航至 [`https://account.google.com/`](https://account.google.com/) 并单击“创建帐户”链接。此页面还包含关于 Google 帐户可提供的内容的大量信息。单击“创建您的 Google 帐户”后，您将看到 [图 6-5](#c06.xhtml#c06-fig-0005) 所示的页面。帐户创建过程包含多个页面。您只需在每个页面上提供所需信息并单击“下一步”。

![FIGURE 6-5: 按照提示创建您的 Google 帐户。](images/9781119724018-fg0605.png)

[FIGURE 6-5:](#c06.xhtml#rc06-fig-0005) 按照提示创建您的 Google 帐户。

### 登录

创建并验证帐户后，您可以登录。在有效使用 Colab 之前，您必须登录您的帐户。这是因为 Colab 依赖于您的 Google Drive 来执行某些任务。您也可以将笔记本存储在其他位置，例如 GitHub，但拥有 Google 帐户可确保一切按计划运行。要登录您的帐户，请导航至 [`https://accounts.google.com/`](https://accounts.google.com/)，提供您的电子邮件地址和密码，然后单击“下一步”。您将看到登录页面，如 [图 6-6](#c06.xhtml#c06-fig-0006) 所示。

![FIGURE 6-6: 登录页面可让您访问所有常规功能，包括您的云端硬盘。](images/9781119724018-fg0606.png)

[FIGURE 6-6:](#c06.xhtml#rc06-fig-0006) 登录页面可让您访问所有常规功能，包括您的云端硬盘。

## 使用笔记本

与 Jupyter Notebook 类似，笔记本构成了与 Colab 交互的基础。事实上，如前所述，Colab 是基于笔记本构建的。当您将鼠标悬停在 [`https://colab.research.google.com/notebooks/welcome.ipynb`](https://colab.research.google.com/notebooks/welcome.ipynb) 欢迎页面的某些部分时，您会看到通过添加代码或文本条目（您可根据需要用作笔记）与页面交互的机会。这些条目是活动的，因此您可以与它们交互。您还可以移动单元格并将生成的材料复制到您的 Google Drive。当然，尽管与欢迎页面交互既出人意料又有趣，但本章的真正目的是演示如何与 Colab 笔记本交互。以下部分描述了如何使用 Colab 执行基本的笔记本相关任务。

### 创建新笔记本

要创建新笔记本，请选择“文件”⇒“新建笔记本”。您将看到一个新的 Python 3 笔记本，如 [图 6-7](#c06.xhtml#c06-fig-0007) 所示。新笔记本看起来与 Notebook 中的类似，但并不完全相同。但是，所有相同的功能都存在。（Colab 的最新版本不支持 Python 2，因此您无法将其与 Python 2 一起使用。）
