### 打开现有笔记本

你可以打开本地存储、Google Drive 或 GitHub 上的现有笔记本。你也可以打开任何 Colab 示例，或上传你可以访问的来源中的文件，例如系统上的网络驱动器。在所有情况下，你都从选择 File ⇒   Open Notebook 开始。你会看到如 [图 6-8](#c06.xhtml#c06-fig-0008) 所示的对话框。

默认视图显示你最近打开的所有文件，无论位置如何。文件按字母顺序排列。你可以通过在 Filter Notebooks 字段中键入字符串来筛选显示的项目数量。顶部还有其他用于打开笔记本的选项。

![Tip](images/tip.png)即使你未登录，仍然可以访问 Colab 示例项目。这些项目可以帮助你了解 Colab，但不会允许你对自己的项目进行任何操作。即便如此，你仍然可以在不先登录 Google 的情况下尝试使用 Colab。以下部分将更详细地讨论这些选项。

#### 使用 Google Drive 打开现有笔记本

Google Drive 是 Colab 中许多操作的默认位置，你始终可以将其作为目标选择。使用 Drive 时，你会看到类似于 [图 6-8](#c06.xhtml#c06-fig-0008) 中所示的文件列表。要打开特定文件，请在对话框中单击其链接。该文件将在浏览器的当前选项卡中打开。

#### 使用 GitHub 打开现有笔记本

使用 GitHub 时，你最初需要提供在线源代码的位置，如 [图 6-9](#c06.xhtml#c06-fig-0009) 所示。该位置必须指向公共项目；你不能使用 Colab 访问私有项目。

建立与 GitHub 的连接后，你会看到两个列表：仓库（与特定项目相关的代码容器）和分支（代码的特定实现）。选择仓库和分支后，将显示可加载到 Colab 的笔记本文件列表。只需单击所需链接，它就会像使用 Google Drive 一样加载。

#### 使用本地存储打开现有笔记本

如果你想使用本书的可下载源代码，或者任何本地源代码，请选择对话框中的 Upload 选项卡。中央有一个单独的按钮，Choose File。单击此按钮将打开浏览器的文件打开对话框。你找到要上传的文件，就像通常打开任何文件一样。

![FIGURE 6-9: When using GitHub, you must provide the location of the source code.](images/9781119724018-fg0609.png)

[FIGURE 6-9:](#c06.xhtml#rc06-fig-0009) 使用 GitHub 时，必须提供源代码的位置。

![Remember](images/remember.png)选择文件并单击 Open 会将文件上传到 Google Drive。如果你对文件进行更改，这些更改会显示在 Google Drive 上，而不是本地驱动器上。根据你的浏览器，你通常会看到一个新窗口打开并加载代码。但是，你也可能只看到一条成功消息，在这种情况下，你现在必须使用与使用 Google Drive 时相同的技术打开文件。在某些情况下，你的浏览器会询问你是否要离开当前页面。你应该告诉浏览器这样做。

![Tip](images/tip.png)File ⇒   Upload Notebook 命令也会将文件上传到 Google Drive。事实上，上传笔记本就像上传任何其他类型的文件一样，你会看到相同的对话框。如果你想上传其他类型的文件，使用 File ⇒   Upload Notebook 命令可能更快。

### 保存笔记本

Colab 提供了大量保存笔记本的选项。但是，这些选项均不适用于你的本地驱动器。将本地驱动器上的内容上传到 Google Drive 或 GitHub 后，Colab 会在云端而不是本地驱动器上管理内容。要将更新保存到本地驱动器，你必须使用本章后面“[下载笔记本](#c06.xhtml#c06-sec-0022)”部分中找到的技术下载文件。以下部分将回顾用于保存笔记本的基于云的选项。

#### 使用 Drive 保存笔记本

存储数据的默认位置是 Google Drive。当你选择 File ⇒   Save 时，你创建的内容将进入 Google Drive 的根目录。如果你想将内容保存到不同的文件夹，则需要在 Google Drive 中选择该文件夹 ([`https://drive.google.com/`](https://drive.google.com/))。

![Remember](images/remember.png)当你执行保存操作时，Colab 会跟踪项目的版本。但是，随着这些修订版本的老化，Colab 会将其删除。要保存不会老化的版本，请使用 File ⇒   Save and Pin Revision 命令。要查看项目的修订版本，请选择 File ⇒   Revision History。你会看到如 [图 6-11](#c06.xhtml#c06-fig-0011) 所示的输出。请注意，条目已固定。你也可以通过在 History 列表中选择条目来固定条目。修订历史还会显示修改日期、修订者以及生成文件的大小。你可以使用此列表恢复以前的修订版本或将修订版本下载到本地驱动器。

![FIGURE 6-11: Colab maintains a history of the revisions for your project.](images/9781119724018-fg0611.png)

[FIGURE 6-11:](#c06.xhtml#rc06-fig-0011) Colab 会维护项目的修订版本历史记录。

你还可以通过选择 File ⇒   Save a Copy In Drive 来保存项目的副本。副本名称中会包含单词 `Copy`。当然，你稍后可以重命名它。Colab 会将副本存储在当前的 Google Drive 文件夹中。

#### 使用 GitHub 保存笔记本

GitHub 为保存内容提供了 Google Drive 的替代方案。它提供了一种有组织的方法来共享代码，以便进行讨论、审查和分发。你可以在 [`https://github.com/`](https://github.com/) 找到 GitHub。
