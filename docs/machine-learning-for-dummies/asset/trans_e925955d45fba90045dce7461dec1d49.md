### 创建文本单元格

文本单元格的工作方式与 Notebook 中的标记单元格非常相似。但是，[图 6-17](#c06.xhtml#c06-fig-0017) 显示，你在使用图形界面格式化文本时会获得额外的帮助。标记是相同的，但你可以选择让 GUI 帮助你创建标记。例如，在这种情况下，要为标题创建 # 符号，你需要单击列表中首先出现的双 T 图标。再次单击双 T 图标将提高标题级别。右侧显示了文本在笔记本中的显示效果。

![FIGURE 6-17: 使用 GUI 使文本格式化更加容易。](images/9781119724018-fg0617.png)

[FIGURE 6-17:](#c06.xhtml#rc06-fig-0017) 使用 GUI 使文本格式化更加容易。

注意文本单元格右侧的菜单。此菜单包含许多与代码单元格相同的选项。例如，你可以创建一个链接列表，以帮助人们通过索引访问笔记本的特定部分。与 Notebook 不同，你不能执行文本单元格来解析其中包含的标记。

### 创建特殊单元格

Colab 提供的特殊单元格是文本单元格的变体。这些特殊单元格（你可以通过“插入”菜单选项访问它们）可加快所需单元格的创建速度。以下各节将描述每种特殊单元格类型。

#### 使用标题

当你选择“插入”⇒“节标题单元格”时，你会看到在当前选定单元格下方创建了一个新单元格，其中包含相应的标题级别 1 条目。你可以通过单击双 T 图标来提高标题级别。GUI 与[图 6-17](#c06.xhtml#c06-fig-0017) 中的界面相同，因此你拥有所有标准的文本格式化功能。

#### 使用目录

Colab 的一个有趣的新增功能是为你的笔记本自动生成目录。要使用此功能，请单击窗口左侧的“目录”图标。[图 6-18](#c06.xhtml#c06-fig-0018) 显示了此特定示例的输出。

目录包含你在代码中提供的每个标题的一个标题。标题会根据级别自动组织，因此你可以看到代码的层次结构。单击标题会自动带你到达代码中的该位置。

![FIGURE 6-18: 目录使 Notebook 信息更易于访问。](images/9781119724018-fg0618.png)

[FIGURE 6-18:](#c06.xhtml#rc06-fig-0018) 目录使 Notebook 信息更易于访问。

### 编辑单元格

Colab 和 Notebook 都有“编辑”菜单，包含你所期望的选项，例如剪切、复制和粘贴单元格的功能。这两款产品还有一些有趣的差异。例如，Notebook 允许你拆分和合并单元格。Colab 包含一个选项，可作为切换开关显示或隐藏代码。这些差异使每款产品略有不同，但并不会真正改变你使用它们来创建和修改 Python 代码的能力。

### 移动单元格

你在 Notebook 中用于移动单元格的相同技术也适用于 Colab。唯一的区别是 Colab 完全依赖工具栏按钮；Notebook 在“编辑”菜单中也有单元格移动选项。

## 使用硬件加速

你的 Colab 代码在 Google 服务器上执行。你的计算设备所做的只是托管一个显示代码及其结果的浏览器。因此，除非你选择在本地执行代码，否则计算设备上的任何特殊硬件都会被忽略。

![Tip](images/tip.png) 幸运的是，在使用 Colab 时，你还有另一个选择。选择“编辑”⇒“笔记本设置”以显示笔记本设置对话框，如[图 6-19](#c06.xhtml#c06-fig-0019)所示。此对话框允许你通过添加图形处理单元 (GPU) 或张量处理单元 (TPU) 来选择代码的硬件加速级别。文章 [`https://medium.com/deep-learning-turkey/google-colab-free-gpu-tutorial-e113627b9f5d`](https://medium.com/deep-learning-turkey/google-colab-free-gpu-tutorial-e113627b9f5d) 提供了有关此功能工作原理的更多详细信息。

![FIGURE 6-19: 硬件加速加快代码执行速度。](images/9781119724018-fg0619.png)

[FIGURE 6-19:](#c06.xhtml#rc06-fig-0019) 硬件加速加快代码执行速度。

![Warning](images/warning.png) GPU 或 TPU 的可用性并不是邀请你使用 Colab 运行大型计算。内容 [`https://research.google.com/colaboratory/faq.html#gpu-availability`](https://research.google.com/colaboratory/faq.html#gpu-availability) 告诉你 Colab 硬件加速的限制（包括在你需要时可能无法使用）。

笔记本设置对话框还允许你选择是否在保存笔记本时包含单元格输出。鉴于在大多数情况下你将笔记本存储在云端，并且将大文件加载到浏览器中可能很耗时，因此删除单元格输出可让你更快地重新启动会话。当然，权衡是你现在必须重新生成所需的所有输出。

## 查看你的笔记本

笔记本左侧边距有一系列四个图标，如[图 6-7](#c06.xhtml#c06-fig-0007)所示。单击其中任何图标都会显示一个窗格，其中包含显示有关你的笔记本的各种信息的选项卡。例如，单击第一个图标会显示目录窗格。你也可以从“查看”菜单中选择要查看的特定信息。要关闭此窗格，请单击窗格右上角的 `X`。以下各节将描述每种信息。

### 显示目录

选择“查看”⇒“目录”以查看笔记本的目录，如[图 6-18](#c06.xhtml#c06-fig-0018)所示。单击任何条目都会带你到达笔记本的该部分。窗格底部有一个“+ 节”按钮。单击此按钮可在当前选定单元格下方创建一个新标题单元格。

### 获取笔记本信息

当你选择“查看”⇒“笔记本信息”时，你会在浏览器中看到一个对话框打开，如[图 6-20](#c06.xhtml#c06-fig-0020)所示。此窗格包含笔记本大小、设置和所有者。请注意，显示还会告诉你笔记本的最大大小。

![FIGURE 6-20: 笔记本信息包括大小和设置。](images/9781119724018-fg0620.png)

[FIGURE 6-20:](#c06.xhtml#rc06-fig-0020) 笔记本信息包括大小和设置。

笔记本信息对话框还包含一个“修改笔记本设置”链接，该链接会显示笔记本设置对话框，在该对话框中，你可以选择运行时类型以及笔记本是否依赖硬件加速，如前面本章“[使用硬件加速](#c06.xhtml#c06-sec-0031)”节中所述。

### 检查代码执行

Colab 在你执行代码时会跟踪代码。选择“查看”⇒“已执行的代码历史记录”以显示窗口右侧窗格中的“执行”选项卡，如[图 6-21](#c06.xhtml#c06-fig-0021)所示。请注意，“已执行的代码”选项卡中条目关联的编号可能与关联单元格的编号不匹配。此外，每次唯一的代码执行都会接收一个单独的编号。

![FIGURE 6-21: Colab 跟踪你执行哪些代码以及执行顺序。](images/9781119724018-fg0621.png)
