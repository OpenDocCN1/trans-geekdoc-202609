

当非线性可分性问题受到审查，且从业者开始对感知器失去兴趣时，专家们迅速推测，可以通过创建一个新的特征空间（通过将原始特征重新组合为新特征）来解决问题，使得先前不可分的类别变得可分。因此，感知器的表现将如之前一样出色。不幸的是，创建新的特征空间是一项挑战，因为它需要目前公众只能部分获得的计算能力。创建新特征空间是一个高级话题，本书在后面研究更复杂算法（如神经网络和支持向量机）的学习策略时会讨论。

近年来，得益于大数据，该算法重新受到关注：事实上，感知器不需要处理内存中的所有数据，而是可以通过单个样本进行良好工作（仅在误分类情况使其必要时更新其系数向量）。因此，它是在线学习的完美算法，例如使用小批量甚至一次仅一个样本来从大数据中学习。

## 生长贪婪分类树

决策树有着悠久的历史。此类算法的第一个算法可追溯到20世纪70年代，但如果考虑实验和最初的原始研究，决策树的使用可以追溯到更早（它们与感知器一样古老）。作为符号主义部落的核心算法，决策树因其直观的方法而长期受欢迎。其输出易于转换为规则，因此人类很容易理解。它们也极其易于使用且功能多样。所有这些特性使它们成为一种有效且吸引人的无脑模型，相对于那些需要对输入数据矩阵进行复杂数学变换或对其超参数进行极其精确调整的模型而言。

### 通过拆分数据预测结果

以观察样本作为起点，算法通过将输入矩阵划分为越来越小的分区，直到过程触发停止规则，从而重新追溯生成输出类别（或在回归问题中处理时的数值）的规则。这种从特殊到一般规则的重新追溯是人类逆向演绎的典型特征，如逻辑和哲学所讨论。在机器学习背景下，这种逆向推理是通过在所有可能的训练样本拆分方式中进行搜索，并以贪婪的方式决定使用能最大化结果分区统计量的拆分来实现的。

![Remember](images/remember.png)当算法在优化过程的每一步都总是选择能最大化当前结果的移动，而不考虑后续步骤可能发生的情况时，该算法就是 `greedy` 的。换句话说，算法试图最大化当前步骤，而不向前看以实现全局优化。

划分的发生是为了强制执行一个简单的原则：初始数据的每个分区都必须使预测目标结果更容易，其特征是类别（或数值）的分布比原始样本更不同且更有利。算法通过拆分数据来创建分区。它首先评估特征，然后评估特征中的值，以确定能带来特殊统计量最大改进的数据拆分，该统计量在决策树中扮演成本函数的角色。

许多统计量决定如何在决策树中进行拆分。它们都遵循这样的理念：当拆分使预测更安全时，拆分必须优于原始样本或另一个可能的拆分。其中最常用的测量包括

*   Gini impurity

*   Information gain

*   Variance reduction (for regression problems)

这些测量的操作类似，因此本章专注于信息增益，因为它是最直观的测量，并以最简单的方式传达决策树如何检测某个拆分的预测能力增强（或风险降低）。Ross Quinlan在20世纪70年代基于信息增益创建了决策树算法 `ID3`，并且由于其最近升级的版本 `C4.5`，它仍然非常流行。信息增益依赖于 `informative entropy` 的公式，这是一个描述消息中包含的信息预期值的通用公式：

在公式中，`p` 是类别的概率（范围为0到1），`log[2]` 是以2为底的对数。从一个你想要分类两个概率相同的类别（50/50分布）的样本开始，最大可能的熵是

```
Entropy = -0.5*log2(0.5) -0.5*log2(0.5) = 1.0
```

然而，当决策树算法检测到一个可以将数据集拆分为两个分区的特征，其中两个类别的分布为40/60时，平均信息熵会减小：

```
Entropy = -0.4*log2(0.4) -0.6*log2(0.6) = 0.97
```

注意所有类别的熵之和。使用40/60拆分，总和小于理论最大值1（熵减小）。将熵视为数据混乱程度的度量：混乱越少，秩序越多，猜测正确类别就越容易。在第一次拆分后，算法尝试使用相同的减少熵的逻辑进一步拆分获得的分区。它逐步拆分任何后续数据分区，直到无法再进行拆分，因为子样本是单个示例，或者因为它已满足停止规则。

![Remember](images/remember.png)`Stopping rules` 是树扩展的限制。这些规则通过考虑分区的三个方面来工作：初始分区大小、结果分区大小以及拆分可实现的信息增益。停止规则很重要，因为决策树算法近似了大量函数；然而，噪声和数据错误很容易影响该算法。因此，取决于样本，结果估计的不稳定性和方差会影响决策树预测。
