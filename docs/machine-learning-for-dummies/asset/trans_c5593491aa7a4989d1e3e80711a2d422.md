

# 代价函数与机器学习优化

当问题涉及预测谁可能因某种疾病而生病时，你需要那些能够高概率识别出具有相同特征且后来确实生病的人群的算法。根据疾病的严重程度，你可能更倾向于算法错误地选择一些不会生病的人，而不愿错过那些确实会生病的人。

代价函数是推动机器学习应用成功的核心因素。它对学习过程的重要性不亚于*表示*（近似某些数学函数的能力）和*优化*（机器学习算法如何设置其内部参数）。大多数算法优化其自身的代价函数，你别无选择，只能按原样应用它们。某些算法允许你在若干可能的函数中进行选择，提供更多灵活性。当算法在优化过程中直接使用代价函数时，该代价函数在内部使用。鉴于算法设计为与特定代价函数协同工作，优化目标可能与你期望的目标不同。在这种情况下，你使用外部代价函数来衡量结果，为了术语清晰，你将其称为*误差函数*或*损失函数*（如果需要最小化）或*评分函数*（如果需要最大化）。

![Tip](images/tip.png)关于你的目标，良好的做法是定义解决问题效果最好的代价函数，然后找出哪些算法在优化它方面效果最好，以定义你想要测试的假设空间。当你使用不允许所需代价函数的算法时，你仍可以通过固定其超参数（算法运行所需提供的参数）并根据代价函数选择输入特征，来间接影响其优化过程以适应你偏好的代价函数。最后，当你收集了所有算法的结果后，使用你选择的代价函数对其进行评估，然后决定算法、超参数和特征的哪种组合最适合解决你的问题。

当算法从数据中学习时，代价函数通过指出对做出更好预测最有益的内部参数变化来指导优化过程。随着代价函数响应迭代地改善，优化过程持续进行。当响应停滞或恶化时，就该停止调整算法参数了，因为算法不太可能从那里获得更好的预测结果。当算法在新数据上工作并进行预测时，代价函数帮助你评估它是否正常工作并确实有效。

![Remember](images/remember.png)决定代价函数是机器学习中一项被低估的活动。这是一项基本任务，因为它决定了算法在学习阶段的行为以及它如何处理你想要解决的问题。永远不要依赖默认选项，而应始终问自己你希望使用机器学习实现什么，并检查哪种代价函数能最好地代表这种成就。

![Tip](images/tip.png)在 [Part 4](#p04.xhtml) 中，你将了解一些机器学习算法，并在 [Part 5](#p05.xhtml) 中看到如何将理论应用于实际问题，介绍用于评分文本和情感的分类问题。如果你需要选择代价函数，机器学习解释和示例介绍了一系列用于回归和分类的误差函数，包括均方根误差、对数损失、准确率、精确率、召回率和曲线下面积（AUC）。（如果这些术语现在不清楚，不用担心；它们将在 [Parts 4](#p04.xhtml) 和 [5](#p05.xhtml) 中详细解释。）

## 降低优化曲线

梯度下降算法完美地展示了机器学习的工作原理。它总结了迄今在本书中表达的概念，因为你可以使用直观的视觉示例来理解它，而不仅仅是数学公式。此外，尽管它只是许多可能方法之一，梯度下降是一种广泛使用的方法，应用于本书中介绍的一系列机器学习算法，例如线性模型、神经网络和梯度提升机。

梯度下降通过从随机解开始，在给定一组输入（由特征和响应组成的数据矩阵）时找出解决方案。然后它利用代价函数的反馈进行多次迭代，用逐渐改善初始随机解并降低误差的值更改其参数。尽管优化可能需要大量迭代才能达到良好的映射，但它依赖于在每次迭代中最改善响应代价函数的变化。[Figure 8-3](#c08.xhtml#c08-fig-0003) 展示了一个复杂优化过程的示例，包含一些局部最小值（山谷中间的最低点）和一个过程可能陷入的地方（因为鞍点处的平坦表面），无法继续下降。

![FIGURE 8-3: A plotting of parameter data against the output of the cost function.](images/9781119724018-fg0803.png)

[FIGURE 8-3:](#c08.xhtml#rc08-fig-0003) A plotting of parameter data against the output of the cost function.

根据 [Figure 8-3](#c08.xhtml#c08-fig-0003)，你可以将优化过程可视化为在雾天在高山中行走，参数是下降到山谷的不同路径。梯度下降优化在每一步都会发生。在每次迭代中，算法选择减少误差最多的路径，无论采取什么方向。其理念是，如果步长不太大（导致算法跳过目标），始终沿着最陡峭的方向行进将找到最低点。

不幸的是，找到最低点并不总是发生，因为算法可能会到达中间山谷，造成它已到达目标的错觉。但是，在大多数情况下，梯度下降引导机器学习算法发现成功映射问题的正确假设。[Figure 8-4](#c08.xhtml#c08-fig-0004) 展示了不同起点如何产生影响。起点 A 通向局部最小值，而不远处的起点 B 则设法到达全局最小值。

![FIGURE 8-4: Visualizing the effect of starting point on outcome.](images/9781119724018-fg0804.png)

[FIGURE 8-4:](#c08.xhtml#rc08-fig-0004) Visualizing the effect of starting point on outcome.

![Tip](images/tip.png)在优化过程中，你可以区分不同的优化结果。你可以有一个全局最小值，它是代价函数的真正最小误差，也可以有许多局部最小值——看似产生最小误差但实际上并非如此的解决方案（算法陷入的中间山谷）。作为补救措施，鉴于优化过程的随机初始化，多次运行优化是良好的做法。这意味着尝试不同的下降路径序列，不要陷入同一个局部最小值。

## 使用大数据进行优化

机学习归结为一个优化问题，即在给定某个代价函数的情况下寻找全局最小值。因此，使用所有可用数据进行优化显然是一种优势，因为在每次迭代中，它允许你相对于所有数据找到最佳的学习参数修正。这就是大多数机器学习算法倾向于使用所有可用数据，并希望数据在计算机内存中可访问的原因。
