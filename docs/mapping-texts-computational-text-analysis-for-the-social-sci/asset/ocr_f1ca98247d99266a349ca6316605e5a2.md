# Weighting the TCM

This raw frequency matrix is not the best measure of word relatedness for two reasons. First, the matrix is very sparse (lots of zeros). Second, some words are commonplace but not very discriminative, such as “the” and “of.” We’ll learn *statistically* whether a given context word is *particularly informative* about the target word.

We can address this by weighting the TCM by pointwise mutual information (PMI).23 PMI measures whether events x and y co-occur more than they occur independently. PMI ranges from negative to positive infinity, but negative values are typically not relevant for our cases.24 Therefore, it is standard practice to replace all negative values with zero to get *positive* pointwise mutual information, PPMI (Jurafsky and Martin 2000:109).25
