ASCII characters, replace contractions with their full word variants, remove capitalization, remove punctuation, remove numbers, remove excess whitespace, and then lemmatize with a dictionary look-up procedure (i.e., no POS-tagging) with Měchura's English lemma-token dictionary (the default dictionary in `lexicon` which `lemmatize_strings()` uses),<sup>12</sup>

```
data("corpus_envsociology", package = "text2map.corpora")

df_env <- corpus_envsociology |>
  mutate(text = replace_curly_quote(abstract),
         text = stri_trans_general(text,
                                   id = "Any-Latin; Latin-ASCII"),
         text = replace_contraction(text),
         text = gsub("\\\\Ws\\\\W|", "", text),
         text = tolower(text),
         text = gsub("[[:punct:]]+", " ", text),
         text = gsub("[[:digit:]]+", " ", text),
         text = gsub("\\\\s+", " ", text)) |>
  mutate(lemma = lemmatize_strings(text))
```

Now we can estimate our model. This process can take some time, even with a corpus as small as this one. The authors determined that a 25-topic solution was best, so we’ll do the same.<sup>14</sup> We’ll set `verbose` to `FALSE` so that we don’t see every expectation step (“E-step”) and maximization step (“M-step”).
