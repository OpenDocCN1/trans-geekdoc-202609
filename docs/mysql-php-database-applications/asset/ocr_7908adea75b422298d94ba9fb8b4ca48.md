The preceding code uses the uniqeid() and md5() functions to create a string that is very random. There's little for a hacker to latch onto in trying to figure out how the string is constructed. md5() will create a string that is 32 characters long, but that can be a bit unwieldy. So we're using substr() to limit the string to eight characters.
