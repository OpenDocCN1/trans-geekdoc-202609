```
select state, sum(contribution) as 'Total',
avg(contribution) as 'Average',
min(contribution) as 'Minimum',
max(contribution) as 'Maximum'
from contributions
group by state;
```

# group by OPTIONS

Most relational databases require that fields listed in the select clause be used in the group by predicate. But MySQL gives you a second option: You can group a subset of the columns listed. For instance, if you want to find out the number of people in one city and get a look at a sample ZIP code from that city, you could run the following:

```
select city, zip, count(*) from users group by city;
```

The query would return a listing of cities, the number of entries for each city, and one sample ZIP code. These results are quite different from those from the following query:

```
select city, zip, count(*) from users group by city, zip;
```
