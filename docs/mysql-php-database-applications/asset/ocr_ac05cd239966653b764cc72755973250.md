Notice the height() and width() methods. These are good examples of methods that answer questions, rather than perform actions. An AlertBox doesn't even have a width or height property; instead, the methods return hard-coded values. But code that uses an AlertBox object doesn't have to care at all about any of that. It knows that it can call $object->height() to find out how tall it is and $object->width() to find out how wide, and that's all it needs.
