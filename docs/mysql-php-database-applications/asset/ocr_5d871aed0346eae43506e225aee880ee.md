# THE OPERATING SYSTEM

Many operating systems are out there. Windows 98/2000/CE/XP and Macintosh OS are probably the most popular. But that's hardly the end of it. Circumstances might have forced you to work with some obscure OS for the past few years. You might even be under the impression that your OS is the best thing going. That's fine. But if you're planning on spending a lot of time on the Web and on running applications, you're best off getting to know either Windows NT/2000 or some version of Unix. These two account for well over 90 percent of all the servers on the Web. It is probably easier for you to learn a little NT/2000/XP or Unix than it is to convince everybody else that the AS/400 is the way to go.
