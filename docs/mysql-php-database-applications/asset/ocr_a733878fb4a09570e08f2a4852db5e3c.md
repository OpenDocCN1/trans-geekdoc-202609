We want to be able to update the income field of the income table to the sum of the donations acquired by each person. As before, we can do this by deleting the current records in the income table and then creating new ones. Or, we can just use replace, as in the following code:

```
replace income (id, income)
     select id, sum(amount) from donations group by id
:
```

Table 3-11 shows the results.

# TABLE 3-11 THE INCOME TABLE

| Id | income | salary |
|---|---|---|
| 1 | 15000 | NULL |
| 2 | 42000 | NULL |
| 3 | 1028.15 | NULL |
| 4 | 30000 | NULL |

Notice that we've lost the data from our salary column. The trouble is that we are not allowed to include the table we are replacing into the select statement. To change some fields and keep others, we have to create a temporary table storing the current values in income and join it to donations in the replace statement. How much better that is than a delete and an insert is a matter of taste. Remember, replace follows the same syntax as insert. There is no where in replace.
