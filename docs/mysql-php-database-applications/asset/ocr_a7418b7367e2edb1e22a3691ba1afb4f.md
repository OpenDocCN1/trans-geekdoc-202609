If you're the type that's really into statistics, you can use this table to figure out what percentage from each city feels comfortable indicating its age. First, you need a count of all the entries from each specific city and state; following that you need a count of all the non-null values in the age field.

```
select city, state, count(*), count(age) from user_ages group by state, city;
```
