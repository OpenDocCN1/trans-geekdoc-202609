# # String handling functions

In creating Web-based applications, string handling and manipulation are among the most critical tasks of the language you work with. Text cleanup and validation are extremely important, and good Web middleware will make working with text relatively easy. PHP excels in this department: It contains built-in functions that cover most anything you'd want to do to text.

In fact, far more string handling functions exist than we could cover here. At the time this book was written, 88 string handling functions were listed on http:// www.php.net/manual/en/ref.strings.php. In this book we can cover only a portion of these. We will cover all the string handling functions we used in the course of creating the applications in Parts III and IV, and we will cover some other notable functions that we didn't have the opportunity to use.
