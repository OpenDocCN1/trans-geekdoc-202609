# What do we need to prevent?

The major issue in this application is ensuring that users do only what they are permitted to do, and absolutely no more. To do this, the application makes use of MySQL administrative privileges.

All the previous applications have a simple header file that calls a function with which to log in to the database. Each file ends up using the same my_connect() call, with the same username and password. But that won't work here because different users need different levels of access.
