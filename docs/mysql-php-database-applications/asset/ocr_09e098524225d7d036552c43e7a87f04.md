# Apache References

Apache will likely be your Web server, and when you are new to it, it can be tricky. Apache.org (www.apache.org) is the home site for the Apache Software Foundation, which is now working on many interesting projects. In particular, some very cool things are happening in the XML space. Apache can be opaque when you first come to it, but when you grow accustomed to using its documentation, you will see that it really isn't very difficult to work with.
