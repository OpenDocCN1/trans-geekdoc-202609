When you look at it as two queries, the results make sense. We recommend that you stick to updating a single table at a time for the sake of clarity if nothing else, unless you have a good reason to do otherwise.

Note that this syntax is not standard ANSI SQL syntax. This matters primarily for the portability of your application; it's a good reason to isolate the code that actually performs updates.
