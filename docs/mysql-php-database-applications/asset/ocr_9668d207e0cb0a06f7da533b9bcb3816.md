**begin(), commit(), and rollback()** These are the methods actually called by other methods in the child class. To prevent any more queries from being executed, the rollback() method issues a fatal error after rolling back the transaction.

```
function begin()
{
    self::transaction(self::ON);
}
```

```
function commit()
{

}
```

```
function rollback($error=NULL)
{
    self::transaction(self::OFF,'rollback');
    if ($error === NULL && isset($this) && isset($this->error))
        $error = $this->error;
    if ($error)
        user_error($error, E_USER_ERROR);
}
```
