Some unusual stuff goes on with LEAST, most of it having to do with casting arguments into alternate forms before comparison. Here are some examples of the behavior of this function:

+   * LEAST(22, 2.2) returns 2.2.
+   * LEAST(now(), 'a') returns the current date/time as a string.
+   * LEAST(now(), 50000000000000) returns the current date as a number.
+   * LEAST('a', 10) returns 0.
+   * LEAST('a', '10') returns 10.
+   * LEAST(2.2, '22') returns 2.2.

```
mysql> select least(2,7,9,1);
+-----------------+
| least(2,7,9,1) |
+-----------------+
| 1             |
+-----------------+
1 row in set (0.00 sec)
```

# ## GREATEST

GREATEST returns the largest (maximum-valued) argument. In MySQL versions prior to 3.22.5, you can use MAX() instead of GREATEST. Type conversion and casting works in the same way it does with LEAST, discussed previously.

```
GREATEST(X,Y,...)
RETURNS: type of X
```

```
mysql> select greatest(2,7,9,1);
+-----------------+
| greatest(2,7,9,1) |
+-----------------+
| 9             |
+-----------------+
1 row in set (0.00 sec)
```

# ## DEGREES

This function returns the argument X, converted from radians to degrees:

```
DEGREES(X)
RETURNS: float
```
