# floor()

```
float floor (float value)
```

Given a floating-point variable, floor() rounds down any fractional amount and returns the highest integer value less than or equal to the value of the variable.

# constant()

```
mixed constant (string constantname)
```

This function simply returns the value of a defined constant.

# define()

```
bool define (string name, mixed value [, bool case_insensitive])
```

This function defines a constant with a specified name and value. If the third argument is set to TRUE the constant will be defined as case-insensitive.

# get_defined_constants()

```
array get_defined_constants (void)
```

This function returns an array containing the names and values of all the currently defined constants.
