In the context of a database application, variable variables might be used to create a series of variables against which you compare other variables. In the following example, $firstrow is an associative array:

```
```php
$firstrow = array ("firstname"=>"jay", "lastname"=>"greenspan");
foreach ($firstrow as $field => $value)
{
    $field = "first_{$field}";
    $$field = $value;
}
echo $first_firstname, " ", $first_lastname;
```
