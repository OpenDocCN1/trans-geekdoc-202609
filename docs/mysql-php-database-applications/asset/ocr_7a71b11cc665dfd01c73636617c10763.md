To make a connection to MySQL on the local machine, make sure that the Port item is blank and that the username, host (localhost), and password are appropriate. At this point you'll be presented with a screen, like the one shown in Figure 2-5, that offers several options.

If you're using OS X, we recommend that you download the free demo and work through each of the options on this screen. You'll find that most anything you want to do with MySQL you can accomplish with this software. At that point you may decide that it's worth the $99 for a version of MacSQL Lite.
