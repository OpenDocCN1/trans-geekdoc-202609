This is a shorthand way of saying:

```
select * from users where lastchanged >= 20020626999999 and
lastchanged <= 20020626335959;
```

Remember that the default timestamp column type stores dates in the form YYYYMMDDHHMMSS, so to get all entries for a single day you need to start your range at midnight (00:00:00) and end it at 11:59:59 p.m. (23:59:59).

You can also use between on text strings. If you wish to list all the last names that start with the letters A through G, the following query would work. Note that it will not include names that start with A.

```
select * from users where lname between 'a' and 'g';
```
