Now, to show off the goods. After opening an HTML table to contain the headlines, we create some variables pointing at the topic image directory on the Slashdot site and a local image directory on our own server. What we’re going to do is copy the files from their site to ours. Since the images are based on general topics, the same ones are reused frequently. The first time we see each one, we make a local copy, and thereafter, that’s what gets displayed on our pages. It’s faster for us, and cheaper for them.
