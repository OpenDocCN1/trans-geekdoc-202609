# LOG

This function returns the natural logarithm of X. If you want the log of a number X to some arbitrary base B, use the formula LOG(X)/LOG(B).

```
LOG(X)
RETURNS: float
```

# LOG10

LOG10 returns the base-10 logarithm of X:

```
LOG10(X)
RETURNS: float
```

# POW

This function returns the value of X raised to the power of Y:

```
POW(X,Y)
RETURNS: float
```

# SQRT

This function returns the non-negative square root of X:

```
SQRT(X)
RETURNS: float
```

# PI

This function returns an approximation of pi:

```
PI()
RETURNS: float
```

By default, only five decimal places of precision are returned. Additional precision can be gained by adding the result of PI() to 0, formatted as a floating point number with many decimal places:

```
SELECT PI() + 0.0000000000
```
