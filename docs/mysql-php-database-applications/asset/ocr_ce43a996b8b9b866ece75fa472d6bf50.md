if (!$topic_id)
{

	$query = 'select topic_id, name from topics where topic_id = root_id';

}
```

The query in the preceding snippet gets all the root-level topics. The while... loop directly following prints each topic as an HTML anchor, something like <a href="index.php?topic_id=1">Topic name</a>. When it's finished, it returns from the function.

```
while (list($r_topic_id,$r_name) = mysql_fetch_row($result))
{
	// print the name of each topic as
	// a link to this script, passing in
	// the topic_id
	print paragraph(anchor_tag(
		'index.php?topic_id='. $r_topic_id
		. $r_name
		));
	}
	mysql_free_result($result);
	return;
}
