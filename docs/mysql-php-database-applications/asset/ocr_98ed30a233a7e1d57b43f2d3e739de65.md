If you wanted to find the authors of a great book on MySQL and PHP and their dream spouses, you would have to join these tables on the fantasy_spouse_id field. (Don't worry if you don't understand the exact syntax, it will be covered in the next chapter.)

```
SELECT * FROM contacts, desired_spouse
WHERE contacts.fantasy_spouse_id =
desired_spouse.fantasy_spouse_id;
```

This statement works fine for Jay, but there's going to be a problem for Brad because he's a happy bachelor and his fantasy_spouse_id field is null. He will not show up in the result set even though the goal of the query is to get all the people in the contacts table and the associated fantasy spouses, if the retrieved contacts have them.
