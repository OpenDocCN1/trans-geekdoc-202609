**checkbox_field()** The only thing that may be of interest about this function is how we decide if a checkbox is to be checked by default. We can do this by adding an argument called `$match`. If `$match` equals either the value of the field or the label (unless you tell it not to match the label by setting `label_match` to FALSE), the field will be checked when displayed. The `radio_field()` function works the same way.
