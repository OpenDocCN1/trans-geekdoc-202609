Hodges, Andrew, Alan Turing: The Enigma, Simon and Schuster, New York, 1983. Hodges, able to relate to Turing on many levels, is an ideal biographer. Like Turing, Hodges is a mathematician, a homosexual, an atheist, and British. More mathematical detail is provided in this biography than one could fairly expect from anything written by a non-mathematician. If you want to learn more about Turing’s life and work, start here. The 2014 film The Imitation Game71 was based on this book, but it introduced many errors that Hodges would never have made.
