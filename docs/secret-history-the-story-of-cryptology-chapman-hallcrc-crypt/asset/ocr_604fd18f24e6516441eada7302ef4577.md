Thus, we’ll fail to have a unique solution whenever the equation \(C_2 - C_1 = (M_2 - M_1)a\) fails to have a unique solution. If \(M_2 - M_1\) has an inverse modulo 26 (something we can multiply by to get 1 modulo 26), then there will be a unique solution for \(a\), namely \(a = (M_2 - M_1)^{-1}(C_2 - C_1)\), where \((M_2 - M_1)^{-1}\) denotes the inverse of \(M_2 - M_1\).

In Example 1, \(M_2 - M_1\) was 1, which is invertible mod 26. However, for Example 2, \(M_2 - M_1\) was 22, which is not invertible mod 26 (there is no number in the mod 26 table that 22 can be multiplied by to get 1).
