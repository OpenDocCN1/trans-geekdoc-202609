# In saturation mutagenesis

To compute the importance scores of all nucleotides in a sequence and identify key regulatory elements that may significantly affect gene expression, we performed in saturation mutagenesis (ISM) on the 500 bp upstream sequence of HBG1. For each, we conducted three passes of NwaCE, mutating the reference nucleotide to alternative each pass. For each, we computed the alternative accessibility prediction to the reference nucleotide to compute the difference in accessibility for each cell. We normalized the ISM scores for the four nucleotides (A/T/C/G) at each position, ensuring that the scores summed to zero. The normalized ISM score for the reference nucleotide at position was taken as the importance score, reflecting its contribution to accessibility. By visualizing the importance scores for each base in the 500 bp upstream sequence of HBG1 and scanning the sequence with FIMO, we identified several motifs previously reported, such as the CCAAT box and TAL1 motif.

# Evaluation of NwaCE in predicting lineage specific cRE

We selected the top optimal sequences from the cell-type specific CRE generated by CODA platform (Malinois7). Specifically, we used sequences generated by the FastSeqProt algorithm, which exhibited the highest cell-type specificity quantified by the MinGap metric. For each of the three cell types, KS6, HepG2, and SK-N-SH, we selected the top 10 sequences with the highest MinGap values. We directly input these selected sequences to the NwaCE model, and predicted their accessibility in Erythroid, Hepatocyte, and Neural lineages. Expected lineage specificity was observed in 29 out of 30 input sequences (Table S7).

# QUANTIFICATION AND STATISTICAL ANALYSIS

Statistical analysis was performed using R (v. 4.3.1) and Python (v. 3.8). Comparisons were conducted using the unpaired Wilcox rank-sum test, while paired sample comparisons were performed with paired Student's t-tests. Correlations were computed using Spearman's rho or Pearson's r analysis. All statistical tests were two-tailed, and a p value < 0.05 was considered statistically significant. Significances are indicated as follows: *p < 0.05; **p < 0.01; ***p < 0.001; ****p < 0.0001. For all boxplots, the middle line and the box represent the 25th percentile, 75th percentile, and whiskers correspond to 1.5 times the interquartile range. qPCR analysis of gene editing results, error bars correspond to standard deviation from three replicates.
