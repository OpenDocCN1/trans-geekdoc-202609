# Cell Resource

The mouse embryo cREs were categorized into two classes: broad and narrow cREs, as described previously. We generated regions by tiling the cREs (500bp with 100bp step size) using the "tools makewindows -b IU -s 100" command. For each region, we extracted the sequences from the forward strand and input into the mouse model to predict accessibility.

# Cross-species prediction of homologous gene chromatin accessibility

To validate the generalization ability of the model, we utilized the predicted mouse model to predict the chromatin accessibility on homologous genes of HGB1, mouse Hb-b and human HGB1. The sequences 500bp upstream of the target gene TSS were extracted using "bedseq gefasta" and input as a forward propagation to get the predicted accessibility levels. Furthermore, he predicted accessibility compared to experimental accessibility and RNA expression profiles. The experimental accessibility was characterized by the gene sequences by ACCh on scATAC-seq data. And the RNA expression was measured using normalized count of scRNA-seq data.

# Regulatory sequence motif identification

We selected 55,397 cREs, with each length of 500bp located within 1000bp upstream of the TSS. We performed forward passes and extracted predictions from the NextSeq Nvace model to predict regulatory sequence to embedding. Dimensional reduction and clustering of the 55,397 ~ 1,024 embeddings were implemented using the "scipy" python package (v1.9.3) with default parameters. Regulatory sequences were then classified into classes. For each class, GO ontology enrichment and the top five terms were visualized in heatmap.

# Fine-mapped prediction and validation

We used 361 fine-noncoding risk variants as identified by Zhang et al.¹¹ For each variant, we predicted a 500bp sequence centered on the target base, with 9 additional sequences containing random mutations. Two forward passes were performed using Nvace model for both the mutant and reference sequences. We computed the difference in predicted model output for each mutant relation to reference: (mutant)-(reference) across all loci.

# Causal non-coding QTL prediction and validation

We used non-coding QTLs using human gene discovery, as reported by D. Cooper. To ensure precise identification of our variant analysis, we focused exclusively on heterozygous humans. Homozygous alleles were excluded due to potential additive damage effects. For each QTL located within the promoter region of the target gene, the promoter sequences 500bp upstream of the TSS for HGB1, Hb-b and F9 were extracted as reference sequences. Metrics were computed using insertion base analysis at the location within the 500bp sequence, corresponding variants with a random mutation. Two forward passes were then performed performed using Nvace model for both the mutant and reference sequences. We computed the difference in predicted model output for each mutant relation to reference: (mutant)-(reference) in erythroid cell (HGB1, Hb-b) and hematopoietic (F9).

# Functional prediction of synthetic mutagenesis

We performed silico analysis and predicted the variant effect using gold standard data from adenine-base (ABE) references. We then refined the prediction using Biostart, to fine-tune Nvace model trained on female mouse model of hematopoietic lineages. With a 500bp sequence centered around each ABE target (chr1:G4526781), we included the fixed mutant and reference sequences. We computed the difference in predicted model output for each mutant relation to reference. Using Pearson correlation coefficient (P) and accuracy (ACC), we confirmed the capacity of Nvace model for prediction of synthetic effect at single base-pair. Inefficient RNA targets were measured by excluding signals between the 1st and 3rd quantiles of observed changes (z-score HGB1 linear functional effect >>2 and <1.2). The result showed that the correlation between predicted effect of each ABE sequence from Nvace and the experimental phenotype is 0.9, and the prediction accuracy (ACC) is 1. The top 10% effective mutations were predicted and shown in Figure 3.
