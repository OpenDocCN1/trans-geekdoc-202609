## Bulk CUT&tag data analysis

### Identification and validation of nCREs

The mouse ENCREs (mm10, Reg19) were downloaded from ENCODE: https://seqenh.org/ncre/. The nCREs relative to axolotl were identified by using OverlapsPeaks from ChIPpeak R package with arguments "minmapover=100"; To validate the reliability of nCREs using ATATAC-seq data, we compared the nCREs with peaks by H3K4me3 and CTCF. CUT&tag data was calculated using "macs3 calpeak" in narrow mode for H3K4me3 and CTCF, for model for H3K9me3. For samples not covered in ENCODE, the adrenal gland and pituitary gland, the nCREs marking markers of specific cell types in the tissue were extracted. Then we compared the new nCREs with CUT&tag data of adrenal gland and pituitary gland, calculating the fractions of overlapping regions.

### Motif enrichment in cross species

To investigate the functional aspects of various nCREs, motif enrichment analyses were conducted for three categories: nCREs at TSSs, nCREs at promoters (<1kb), and at distal regions (2-3kb). The nCREs annotated by Homer were computed by ChIPpeakseeker to match nCREs at TSSs and nCREs at promoters (<1kb) using the argument "distanceTSS". Then the matchMotif using the motifrichr R package (v1.22.0) was used to match motifs for HOMER The enrichment score of each motif is represented by the weighted average of scores across all nCREs, with a score of 0 assigned to nCREs lacking a proper motif.

## Quantifying motif cross species conservation

To investigate regulatory patterns, we conducted the analyses at the lineage level. Motif discovery was performed using findMotif.Genome from HOMER (v11.1, https://genome.com/avrigiguez/HOMER/) with arguments "scale-300 to 4" for nCREs in each lineage of species. For each lineage, using R (version 5.3.3) in two pairs of the species with similar motif pattern. A motif with a weight meeting the cutoff of 0.01 was considered "matched". For each motif in a particular species, we tabulated the number of nCREs with a matched motif, identifying the conservation degree. We compared all pairs of species.

## Identification and enrichment of substantial elements

We identified species-unique (UA) elements using UCSC Liftoools defined as elements that could not be made from other species' to the genome reference. For species with UCSC Chain assemblies, such as zebrafish and chicken, we coordinated the coordinates of nCREs to mouse genome reference (mm10) using the minimum match rate of 0.10 for cross-species conversion. For gecko, we generated custom chain files and applied the sample procedure. Elements that failed to align mouse genome were defined as UA elements. To investigate their functional relevance, we identified UA elements in specific cell types or tissues by intersecting cell-specific cCREs, using a minimum length of 100 bp. For elements associated with species-specific tissues, such as zebrafish and salamanders, we linked them to the nearest gene using ChIPpeakseeker, generating sets for dense Gene Ontology enrichment analysis using ClusterProfiler (default parameters, value threshold=0.03)

## Identification of axolotl-specific regulatory programs by cross-species regulatory element

We extracted the gene score matrix from the ArchID object for each species, followed by aggregation of stromal cell-type average scores with subsequent base-2 logarithmic transformation. Orthologous gene identification employed species-optimized approaches; (1) BioMart (Ensemble Release 11) for mouse and zebrafish homologs; (2) OrthoFinder v5.0.1 (default parameters, DIAMOND algorithm for chicken, and axolotl). This integrated pipeline identified 4,970 conserved genes across all species. Genes exhibiting high (gene score) > 0.5 in 1 stromal subtype were retained for downstream analyses. Cell-type-based matrices were constructed using hierarchical clustering framework (v1.02). Gene Ontology (GO) enrichment analysis performed on axolotl-specific gene modules showing high chromatin accessibility using theProfiler package.

## Axolotl regeneration analysis

To identify specific CCREs and potential gene regulatory networks utilizing the unique regenerative power of the axolotl limb, we used a list of axolotl limb-related genes from Drovarski et al. 102. We identified the cCREs within 500 bp upstream and downstream of these genes using limb-related-cCREs. The overlap between limb regeneration-related cCREs and all uncovered cCREs was determined using the Ranges package (v3.6). To investigate the function of motifs among these regeneration-related cCREs, we used the HOMER novo motif discovery tool (v1.22) and matched motifs from the HOMER collection (homer.ucsd.edu/human/custom.motifs). Motif scores were calculated using the weighted average of motifs across all cCREs, with a score of 0 assigned to cCREs lacking a particular motif.

## scATAC preprocessing for deep learning

For each species, we selected high-quality peaks and called peaks based on cluster nucleations using MACACS2; extending peaks by 25 bp either side to a final width of 500 bp. Our dataset contains approximately 50,000 cells, and the raw data were converted into a peak-by-peak binary matrix. Peaks containing more than 1% of cells were assigned to positives. Negatively, we considered inaccessible in all types. For deep learning we split data into training, validation, and test sets.

## Model Architecture

### A 2 Convolutional Layer
Consisting of 128 filters with a size of 71, sequentially followed by batch normalization, Rectified Linear Unit (ReLU), and max-pooling layers.

### A ResBlock Module
Comprising 4 layers, each with a size of (3, 4, 6, 9). Each block consists of two convolution layers, two batch normalization, and two ReLU layers.

### A Dense Bottleneck Layer
Integrating 324 features for representations, followed by a batch normalization and a dropout layer with a dropout rate of 0.2.

### A final Layer
Concluding the architecture with a layer using the same number of units as used. Predicting continuous accessibility probability for each cell using sigmoid activation.

This meticulously crafted architecture represents a thoughtful combination of convolutional, residual, and dense layers, allowing NWACave to effectively capture patterns within the DNA sequences. The model's final layer employs an activation function, facilitating the generation of predictions regarding the accessibility of peaks at the single-cell level.

## Training approach

We used a binary cross-entropy loss (BCE Loss) as the objective function during training to control the disparity between prediction and its target value. We utilized the learning rate of 1e-3 and implemented an early stopping mechanism, no decrease for 10 epochs to mitigate the risk of overfitting. A batch size of 100 was used for training, and model parameters were tuned using the Adam optimizer. All models were implemented using PyTorch^{109} (https://pytorch.org), and the Anaconda distribution of Python and trained on a computer cluster equipped with NVIDIA GTX10880 GPUs. The computational time varied depending on the characteristics of the datasets and the GPU devices employed in the training, ensuring efficient and effective method.
