# Clustering and annotations

For each species, we used a two-round clustering strategy. The first round of clustering was performed on overall cells of the list to identify the types of cell markers. The major cell types were annotated and assigned to different lineages (epithelial, hematopoietic, immune, muscle, neural, stromal and support). Next, we performed the second round of clustering for cells with high heterogeneity; endothelial, epithelial, immune, neural, stromal and for all species to refer to zebrafish. We used the 'clusters' function and then generated a two-dimensional representation of the data using the 'ADUMAP' function. Next, we identified differentially accessible markers for each cluster using the 'geneMarkers' function with the gene score. Annotation of the clusters was based on the accessibility score and cell type specific tissue information.
