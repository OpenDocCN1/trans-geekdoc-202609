Quality control and doublet removal

We constructed genome annotation files for species other than mouse. For axolotl, the annotation file is derived from sequenced FASTA and GTP files (Figure: https://github.com/0df50ba9f64b24af9). The processed files were converted to arrow files using ArchR (v1.0.1, https://github.com/GenomicsLab/ArchR),² with a TileMatrix and a GeneScoreMatrix added to each allele. For example, the TileMatrix with 5 bp bin size was generated for axolotl and 500 bp bin for other species. We applied cell barcode selection and doublet inference for each file. Given different sequencing and doublet tissues, we calculated the TSS enrichment score anding for different tissues to identify barcodes representing cells (Table S3), UM unique mapped reads where UF is duplicated. Doublets were identified and filtered using ArchR ‘selection’ and ‘FilterDuplicates’.

# Double-strand capture rate and doublet capture rate

10,000 barcodes in the BAM file of the mouse cerebellum. The BAM file of these barcodes were converted to the BEDPE file and sorted. Top cells were selected for analysis. For the double-strand capture rate evaluation, two fragments share the same chromosome, start, and end site, while there were 1 read aligned to positive or negative strand. The simultaneous framework and the double-reverse capturing rate was calculated as double-strand capture fragments formed by the totals. To calculate the double-capture rate for each locus, we retained a unique fragment for each locus in individual. We assigned overlapping fragments to the same cell in each cell, and the number of overlapping fragments with the number of total fragments. This inserts randomly and removes most of the fragments. A 1 percent double-doublet capture rate would suggest a reasonable amplification efficiency.

# Benchmarking scATAC methods

To evaluate the efficiency of molecule recovery, we analyzed the recovery rate for either forward or reverse fragment in IUATAC can be set as x, the chance to recover both the forward and reverse fragment should be x². We analyzed a sample of 500 cells, examining the fragments from both forward and reverse strand to determine the percentage of sampling capturing events. This metric reflects the proportion of reads detected the DNA loci from both strands. We calculated the percentage of total molecule recovery for each cell. The open locus recovery rate here there are four copies of DNA for each locus.

We benchmark IUATAC using various scATAC methods to systematically evaluate performance. The data of scATAC methods were obtained from the following sources: https://www.genomics.com/dataset/human-mouse-cortex-scatac-v1-1-human-chromosome-1 (10x-scATAC-v1)

For TSS enrichment score, we calculated the score for each cell. We randomly sampled 30000 cells for s-ATAC, which only (800 cells) to call peak effect on calling, ranking, and calculated the number of UF, FR, the number of total peaks and DA peaks, the number of reads in peaks and promoters. To evaluate quality, clustering was performed on the integration of sampled brain data datasets from IUATAC and other scATAC methods (Table S2). The accessible features (500 bp bin) were selected using a threshold based on values for each cell. Based on the features, the similarity of each cell was calculated (cosine) from R package and visualized using Seurat. The analysis was performed for different cells.

For atlas-level datasets, we compared the doublets rate (https://www.ncbi.nlm.nih.gov/geo/query/acc=GSE164482 (scATAC-seq, adult human), https://www.ncbi.nlm.nih.gov/geo/query/acc=GSE119683 (scATAC-seq, fetal human), https://www.ncbi.nlm.nih.gov/geo/query/acc=GSE232272 (ATAC-seq), https://tabula-mouse-pancreas-datasets.dbzioob.org/(scRNA, mouse), and UM and TSS enrichment were used as metrics for the scATAC method, and total number of molecules was the metric for all.
