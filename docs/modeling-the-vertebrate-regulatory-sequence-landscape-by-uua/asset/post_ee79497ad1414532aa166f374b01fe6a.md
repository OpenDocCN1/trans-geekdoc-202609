# Clustering and annotations

For each species, we used a two-round clustering strategy. The first round of clustering was performed on overall cells of the list to identify types of cell markers. The major cell types were annotated and assigned to different lineages (epithelial, immune, muscle, neural, stromal). Next, we performed the second round of clustering for cells with high heterogeneity; endothelial, immune, neural, stromal and all species to refer to zebrafish. We used the 'clusters' function and then generated a two-dimensional representation of the data using the 'UMAP' function. Next, we identified differentially accessible markers for each cluster using the 'genes' function. Annotation of the clusters was based on accessibility score and cell type specific information.

# Identifying CREs at global and lineage level

To identify CREs in diverse species, we aggregated the fragments from the upstream processing. Fragments with a quality score below 30 were filtered and not deduplicated, resulting in a collection of unique fragments. Further alignment based on diverse databases, yielding a merged fragment in BED format for calling. We used MACS3 (v3.0.0 beta 3, https://github.com/macs3-project/MACS) with the macs2-command. This was executed for each cell type and lineage with the following parameters: "-1 global" -g BEDPE -q 0.01 --mins 5 GLOBAL_ATAC_subset -B --callpeaks" for the mouse. For each lineage of species, a distinct barcode list was generated, and then called using the same parameters as the global level. We built CCREs in a narrowPeak format, containing the ranges of accessible regions, peak sum counts and p-values and q-values.
