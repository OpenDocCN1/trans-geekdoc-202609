*Let $γ$ stand for the number of half-integer spin states, and given the prior knowledge that both states are equally probable:*

```
$\quad P(\gamma=2|\gamma \geq 1)$
```

```
$= \frac{P(\gamma=2, \gamma \geq 1)}{P(\gamma \geq 1)}$ (3.33)
```


```
$P(B)=P(B|A)*P(A)+P(B|\overline{A})*P(\overline{A})$ (3.35)
```

```
$\quad =[0.95*0.01]+[0.05*0.99]=0.059$
```
