
## 3.3.3 Hereditary Disease Detection

TABLE 3.1: Probability values of hereditary-disease detection.

| Parameter | Description |
| :--- | :--- |
| $P(B|A) = 0.95$ | The probability that the test will yield a positive result [B] if hereditary-disease is present [A] (probability of detection). |
| $P(\overline{B}|A) = 1 - 0.95 = 0.05$ | The probability that the test will yield a negative result [$\overline{B}$] if hereditary-disease is present [A]. |
| $P(B|\overline{A}) = 0.05$ | The probability that the test will yield a positive result [B] if hereditary-disease is NOT present [$\overline{A}$] (probability of false alarm). |

### SOL-45 (CH.SOL-3.16)

We first enumerate the probabilities one by one:

$P(\mathit{Dercum}\mid \mathit{female}) = 0.05,\tag{3.36}$

$P(\mathit{Dercum}\mid \mathit{male}) = 0.0025,\tag{3.37}$

$P(\mathit{male}) = P(\mathit{female}) = 0.5.\tag{3.38}$

We are asked to find $P(\mathit{female}\mid\mathit{Dercum})$. Using Bayes Rule:

$P(\mathit{female}\mid\mathit{Dercum}) = \dfrac{P(\mathit{Dercum}\mid\mathit{female})P(\mathit{female})}{P(\mathit{Dercum})}.\tag{3.39}$

However, we are missing the term $P(\mathit{Dercum})$. To find it, we apply the Law of Total Probability:

$\begin{aligned} P(\mathit{Dercum}) & = P(\mathit{Dercum}\mid \mathit{female})P(\mathit{female}) \\
& + P(\mathit{Dercum}\mid \mathit{male})P(\mathit{male}) \\
& = 0.05 \cdot 0.5 + 0.0025 \cdot 0.5 \\
& = 0.02625. \end{aligned}$

And finally, returning to eq. (3.39):

$P(\mathit{female}\mid\mathit{Dercum}) = \dfrac{0.05 \cdot 0.5}{0.02625} \approx 0.9524\tag{3.40}$

*Note: How could this result be reached with one mathematical equation?*

### SOL-48 (CH.SOL-3.19)

In order to solve this problem, we introduce the following events:

1. **RUS**: a Russian sleeper agent is speaking.
2. **AM**: an American is speaking.
3. **L**: the TTS system generates an “l”.

We are asked to find the value of $P(\textit{RUS}|L)$. Using Bayes Theorem we can write:

$P(\textit{RUS}|L)=\frac{P(L|\textit{RUS})P(\textit{RUS})}{P(L)}.$ (3.44)

We were told that the Russians consist of 1/5 of the attendees at the gathering, therefore:

$P(\textit{RUS})=\frac{1}{5}.$ (3.45)

Additionally, because “v-o-k-s-a-l” has a single l out of a total of six letters:

$P(L|\textit{RUS})=\frac{1}{6}.$ (3.46)

Additionally, because “V-a-u-x-h-a-l-l” has two l’s out of a total of eight letters:

$P(L|AM)=\frac{2}{8}$ (3.47)

An application of the Law of Total Probability yields:

$\begin{gathered} P(L)=P(AM)P(L|AM)+P(RUS)P(L|RUS)\\ =\left(\frac{4}{5}\right)\left(\frac{2}{8}\right)+\left(\frac{1}{5}\right)\left(\frac{1}{6}\right)=\frac{7}{30} \tag{3.48}\end{gathered}$

Using Bayes Theorem we can write:

$P(RUS|L)=\frac{\frac{1}{5}\left(\frac{1}{6}\right)}{\frac{7}{30}}=\frac{1}{7}$ (3.49)

### SOL-49 (CH.SOL-3.20)

We are given that:

$P(X \text{ is erroneously received as } Z) = 1/7$.

Using Bayes Theorem we can write:

$\begin{aligned} P(Z_{trans}|Z_{received}) &= \frac{P(Z_{received}|Z_{trans})P(Z_{trans})}{P(Z_{received})} \tag{3.50} \end{aligned}$

An application of the Law of Total Probability yields:

$\begin{aligned} P(Z_{received}) &= P(Z_{received}|Z_{trans})P(Z_{trans}) \\ &+P(Z_{received}|X_{trans})P(X_{trans}) \\ &=\frac{7}{8}\cdot\frac{3}{7}+\frac{1}{8}\cdot\frac{4}{7} \\ &=\frac{3}{8}+\frac{4}{56}=\frac{25}{56} \end{aligned}$

So, using Bayes Rule, we have that:

$$\begin{aligned} P(Z_{trans}|Z_{received}) &= \frac{P(Z_{received}|Z_{trans})P(Z_{trans})}{P(Z_{received})} \\ &= \frac{\frac{7}{8} \frac{2}{7}}{\frac{25}{56}} \\ &= \frac{21}{25} = 0.84 . \end{aligned}\tag{3.51}$$

## 3.3.4 Maximum Likelihood Estimation

### SOL-50 (CH.SOL-3.21)

For the set of i.i.d samples $X_{1}$, $\cdots$, $X_{n}$, the likelihood function is the product of the probability functions:

$$\begin{aligned} L(p) &= p(X_{1}=x_{1};p)p(X_{2}=x_{2};p)\cdots p(X_{n}=x_{n};p) \\ &= \prod_{i=1}^{n}\binom{n}{x_{i}}p^{x_{i}}(1-p)^{n-x_{i}} . \end{aligned}\tag{3.52}$$

*Note: What is the distribution of $X^{n}$ when $X$ is a Bernoulli distributed random variable?*

### SOL-51 (CH.SOL-3.22)

The maximum likelihood estimator (MLE) of $p$ is the value of all possible $p$ values that maximizes $L(p)$. Namely, the $p$ value that renders the set of measurements $X_{1}$, $\cdots$, $X_{n}$ as the most likely. Formally:

$$\hat{p}=arg\,max_{0\leq p\leq 1}L(p)\tag{3.53}$$

*Note: The curious student is highly encouraged to derive $\hat{p}$ from $L(p)$. Notice that $L(p)$ can be extremely simplified.*

### SOL-52 (CH.SOL-3.23)

The log-likelihood is the logarithm of the likelihood function. Intuitively, maximizing the likelihood function $L(\gamma)$ is equivalent to maximizing $\ln L(\gamma)$ in terms of finding the MLE $\hat{\gamma}$, since $\ln$ is a monotonically increasing function. Often, we maximize $\ln(f(\gamma))$ instead of $f(\gamma)$. A common example is when $L(\gamma)$ is comprised of normally distributed random variables. Formally, if $X_{1}, \cdots, X_{n}$ are i.i.d. each with probability mass function (PMF) of $f_{X_{i}}(x_{i} | \gamma)$, then:

$f(\gamma)=\prod_{i=1}^{n} f_{X_{i}}\left(x_{i} | \gamma\right),$ (3.54)

$\ln(f(\gamma))=\sum_{i=1}^{n} \ln f_{X_{i}}\left(x_{i} | \gamma\right).$ (3.55)

### SOL-53 (CH.SOL-3.24)

The general procedure for finding the MLE, given that the likelihood function is differentiable, is as follows:

1. Start by differentiating the log-likelihood function $\ln\left(L(\gamma)\right)$ with respect to a parameter of interest $\gamma$.
2. Equate the result to zero.
3. Solve the equation to find $\hat{\gamma}$ that holds:
   $$\frac{\partial \ln L\left(\hat{\gamma} | x_{1}, \cdots x_{n}\right)}{\partial \gamma}=0 \tag{3.56}$$
4. Compute the second derivative to verify that you indeed have a maximum rather than a minimum.

### SOL-54 (CH.SOL-3.25)

The first derivative of the log-likelihood function is commonly known as the Fisher score function, and is defined as:

$$\mathbf{u}(\gamma)=\frac{\partial\ln L(\gamma \mid x_{1},\cdots x_{n})}{\partial\gamma} \tag{3.57}$$

## 3.3.5 Fisher Information

### SOL-55 (CH.SOL-3.26)

**Fisher information** is the term used to describe the expected value of the second derivatives (the curvature) of the log-likelihood function, and is defined by:

$$\mathbf{I}(\gamma)= -E\left[\frac{\partial^{2}\ln L(\gamma \mid x_{1},\cdots x_{n})}{\partial\gamma^{2}}\right] \tag{3.58}$$

### SOL-56 (CH.SOL-3.27)

1. **Given $L(\gamma)$:**
   $$\ln L(\gamma)= \ln \Big( \binom{n}{y} \Big)+y \ln (\gamma)+ (n - y) \ln (1 - \gamma). \tag{3.59}$$
2. **To find the gradient, we differentiate once:**
   $$g(\gamma)= \frac{d}{d\gamma} \ln L(\gamma) = \frac{y}{\gamma} - \frac{n-y}{1-\gamma} \tag{3.60}$$
3. **The Hessian is generated by deriving $g(\gamma)$:**
   $$H(\gamma)= -\frac{y}{\gamma^2} - \frac{n-y}{(1-\gamma)^2} \tag{3.61}$$
4. **The Fisher information is calculated as follows:**
   $$I(\gamma) = -E[H(\gamma)] = \frac{n}{\gamma(1-\gamma)} \tag{3.62}$$
