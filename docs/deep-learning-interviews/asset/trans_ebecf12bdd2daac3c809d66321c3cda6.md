
# 8.1 引言

是 Alex Krizhevsky 首先证明了卷积神经网络（CNN）可以在 ImageNet 大规模视觉识别挑战赛中得到有效训练。CNN 自动提供了一定程度的平移不变性，并假设我们希望通过数据驱动的方式学习滤波器，以此作为描述输入特征的手段。CNN 被应用于许多计算机视觉、成像和计算机图形学任务，参见文献 [24]、[23]、[15] 和 [5]。此外，它们变得极其流行，新的架构和算法不断涌现。
