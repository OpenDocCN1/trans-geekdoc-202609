The Bayes formulae reads:

```
$$P(A|B)=\frac{P(B|A)P(A)}{P(B|A)P(A)+P(B|A^c)P(A^c)},\tag{3.23}$$
```

where P($A^{c}$) is the complementary probability of P($A$). The interpretation of the elements in Bayes formulae is as follows:

```
$$posterior\ probability=\frac{\underline{likelihood\ of\ the\ data}\times\underbrace{prior\ probability}_{\text{normalization\ constant}}.\tag{3.24}$$
```
