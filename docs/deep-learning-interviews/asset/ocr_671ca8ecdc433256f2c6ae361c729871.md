HE extraction of an n-dimensional feature vector (FV) or an embedding from one (or more) layers of a pre-trained CNN, is termed feature extraction (FE). Usually, FE works by first removing the last fully connected (FC) layer from a CNN and then treating the remaining layers of the CNN as a fixed FE.
