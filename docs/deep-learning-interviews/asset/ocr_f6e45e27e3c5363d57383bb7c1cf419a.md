*Formally, mutual information attempts to measure how correlated two variables are with each other:*

```
*I(X;Y) = \sum_{x,y} P(x,y) \log \frac{P(x,y)}{P(x)P(y)}*  (4.21)

*= E [ \log \frac{1}{P(x)} + \log \frac{1}{P(y)} - \log \frac{1}{P(x,y)} ]*

*= H(X) + H(Y) - H(X,Y).*
```

*Regarding the question at hand, given two distributions f*\textsubscript{1} *and f*\textsubscript{2} *and their joint distribution f, the mutual information of f*\textsubscript{1} *and f*\textsubscript{2} *is defined as I(f*\textsubscript{1},f*\textsubscript{2} *) = H(f, f*\textsubscript{1} *f*\textsubscript{2} *). If the two distributions are independent, i.e. f=f*\textsubscript{1} *\cdot f*\textsubscript{2} *, the mutual information will vanish. This concept has been widely used as a similarity measure in image analysis .*
