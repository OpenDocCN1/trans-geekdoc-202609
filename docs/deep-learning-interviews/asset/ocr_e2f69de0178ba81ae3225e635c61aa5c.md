$$\begin{aligned}h_\boldsymbol{\beta}(\mathbf{x}) &= g(\boldsymbol{\beta}^T \mathbf{x}) = \frac{1}{1 + e^{-\boldsymbol{\beta}^T \mathbf{x}}}\\ &= P(\mathbf{y} = 1|\mathbf{x}; \boldsymbol{\beta}),\end{aligned}$$

(2.3)

where $y$ holds the hypothesis value .
