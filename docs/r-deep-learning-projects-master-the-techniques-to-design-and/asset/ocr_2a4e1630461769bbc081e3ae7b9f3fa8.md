+   - Adding Lasso (L1) or/and Ridge (L2) penalty, which prevents model coefficients
+   from fitting so perfectly that overfitting arises.
+   - Reducing the complexity of network architecture. Recall that in the last chapter,
+   we mentioned that adding hidden layers will not help boost the model
+   performance but increase chances of overfitting.
