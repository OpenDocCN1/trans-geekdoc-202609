# About the reviewer

**Davor Ložić** is an engineer who works mostly on software architecture and distributed systems. He found R by doing a lot of fun predictions with data from distributed systems and user events, and continues using it for statistical modeling. He is also a professor at the University of Zagreb, where he teaches software architecture and distributed database systems. Davor, along with his cat, Dora, is working on technical reviews of Packt books and is happy with every new release.
