As usual we resort to gradient descent, an iterative optimization algorithm, to solve for the optimal $w$. In each iteration, $w$ moves a step that is proportional to the negative derivative $\Delta w$ of the objective function at the current point. That is, $w:=w-\eta\Delta w$, where $\eta$ is the learning rate. Each column $\Delta w_k$ of $\Delta w$ can be computed as:

\(\Delta w_k = \frac{\partial}{\partial w_j}J(w) = -\sum_{i=1}^m[x^{(i)}(1\{y^{(i)} = k\} - P(y^{(i)} = k \mid x^{(i)}, W))]\)

The well trained model, the optimal $w$ will be used to classify a new sample $x'$ by:

\(y' = \text{argmax}_k \frac{\exp(w_k x')}{\sum_{j=1}^{j=K}\exp(w_j x')} = \text{argmax}_k (w_k x')\)

Armed with the mechanics of the multinomial logistic regression we just reviewed, we can then apply it as the first solution to our digit classification project.
