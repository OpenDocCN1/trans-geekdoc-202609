General protocols used in computing:

CoAP: This is the brain-child of the IET Constrained RESTful Environments (CoRE) working group. It is an application layer protocol. On top of HTTP functionalities, this transfer protocol works on Representative State Transfer (REST).
AMQP: Application layer protocol is an open standard in TCP which is used for message exchange. AMQP provides three guarantees for message delivery, which include exactly once, at-most-once, and at-least once delivery.
MQTT: MQTT is made up of three components: publisher, broker, and subscriber. It is a connection protocol, which is used to connect various edge devices like edge network, embedded devices, middleware, and edge services.\IoT communication: machine-to-machine, Web of Things, Internet of Things models include: publish-subscribe, request-response, et. Communication patterns include notifications, telemetry, and status.
