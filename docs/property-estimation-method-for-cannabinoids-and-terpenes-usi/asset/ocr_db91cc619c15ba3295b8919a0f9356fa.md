see in the left part of the Table 1, the ensemble models outperform the results that we have obtained in the single scenario. Indeed, we achieved coefficient of determination around 0.8 for the FNN ensemble with MSE loss function. The prediction for the test dataset can be seen in Fig.1b. Here, we observed not only a better accuracy in the predictions, but also, acquired new information about the uncertainty of those estimations. One of the main analysis that we can get from the ensemble models, is there is a huge variance for chemical groups with melting points around 10-100 Celsius degrees, basically because of the few dataset in this range. Also, we can argue that few models in the ensemble is not good enough, and it requires more single FNN for yield better results in terms of variability. These additional remarks along with the use of models which provide uncertainties as Bayesian Neural Networks Hortúa et al. (2020) or Gaussian Processes are tools that we are proposing for a future work.
