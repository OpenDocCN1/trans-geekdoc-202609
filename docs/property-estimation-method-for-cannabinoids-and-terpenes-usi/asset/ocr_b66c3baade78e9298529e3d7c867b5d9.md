Table 2 summarizes the predictions for the studied cannabinoids, not previously used by the algorithm. Standart deviations are also reported. As shown: i) qualitatively speaking the model is able to predict positive and negatives melting points, however, it still need a lot of improvement in compounds such as cannabidiol one of the most important in the current processes ii) obtained standard deviations are very high indicating that a pre-treatment process is certainly necessary to improve the model.

# 4. Discussion and Conclusions

In this paper, we have explored several machine learning techniques for estimating the melting point in chemical compounds. We contrasted two approaches: one of trained single NN based on FNN and Convolutional layers, along with ensembles of those single NN. We have found that these ensembles outperform uncertainties in its predictions. The best model in this paper comes from the ensemble of FNN trained with MSE loss function, reaching R=0.88. Even if the result is good enough and promising, we observed that the variance for the model is high so far. This effect could be associated with either a noisy dataset or because of few instances in the dataset for some temperature ranges. In order to overcome this, we suggest for a future work, a strong reprocessing method before feeding the data into the NN model, and the use of more robust techniques such as Bayesian Network in order to get the aleatory and epistemic uncertainties which give a clearer picture about the huge variability in the predictions. Finally, we are currently working on improving the accuracy of this model as well as determining the thermodynamic properties of interest in cannabis.
