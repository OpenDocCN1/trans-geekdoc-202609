# 2.1. Software architecture

This study basically examines UAV navigation in 3D environment. This navigation process was basically compared using two different approaches. Distributed deep reinforcement learning and deep reinforcement learning approaches train an agent for one drone to follow another. As a result of the training, the following drone aims to successfully follow at a certain altitude by positioning itself according to the followed drone. For this purpose, reinforcement learning and PPO algorithm are used to together. RAY framework was preferred as distributed architecture. The workers in the training environment perform the action evaluated by the deep neural network. The reward and status values received from the environment as a result of the action are evaluated by the PPO architecture. According to the rewards and punishments received as a result of these actions, the agent learns the environment and acts accordingly. In this study, training takes place with a maximum of 4 workers, depending on the processor. This number can increase even more when GPU is used. These workers learn the environment independently of each other and transmit the results to a common learner. Thus, a faster and more successful training is provided in a unit of time. In the non-distributed model, a single agent performs the actions in the environment.
