### 2.2.2. Proximal policy optimization (PPO)

PPO is a gradient-based reinforcement learning method. This method aims to optimize the objective function using stochastic gradient descent. During the training phase, the PPO agent estimates the probabilities for each action that might take place and randomly selects the action based on this value. Similar to the Trust Region Policy Optimization (TRPO) objective function, Eq. (2) defines the odds ratio between the new policy and the old policy.

\(r(\theta) = \frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)}\) (2)

The objective function of TRPO can be updated as in Eq. (3).

\(j(\theta)^{TRPO} = E \left[ r(\theta) \hat{A}_{old}(s, a) \right]\) (3)

Without some constraints, this objective function can cause instability or slow convergence rate. The PPO uses the policy rate (\(r(\theta)\)), which is about 1 without complex restrictions. This range is set from 1-\(\varepsilon\) to 1+\(\varepsilon\) thanks to the \(\varepsilon\) hyper parameter, which is set to 0.2 by default. After these adjustments, the objective function of PPO can be written as Eq. (4).

\(f^{CLIP}(\theta)\)
\(= \mathbb{E} \left[ \min \left( r(\theta) \hat{A}_{old}(s, a), \text{clip} \left( r(\theta), 1 - \varepsilon, 1 + \varepsilon \right) \hat{A}_{old}(s, a) \right) \right]\) (4)

In Eq. (4), the clip function determines the policy ratio with values between [1-\(\varepsilon\), 1+\(\varepsilon\)]. Since the PPO objective function takes the minimum value between the original and clipped values, it prevents bias toward a negative action.

### 2.2.3. Reward function

During the tracking process, only the x y z position and yaw angle of the drone approaching the target are adjusted. The flight controller automatically adjusts the roll and pitch angle to follow the target, moving the fighter to the next set point. Unless the drone moves forward, the roll and pitch remain zero and the drone maintains its position. In the LeaderFollower environment, the reward function consists of the rewards earned by the follower drone by following the altitude of the tracked drone. The reward function is shown in Eq. (5).

\(r_0 = -\|[0, 0, 0.6] - x_0\| \frac{2}{2}, \quad r_1 = -0.6 \left( z_1 - z_0 \right)^2\) (5)
