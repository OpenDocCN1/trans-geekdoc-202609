### 2.2.1. Distributed deep reinforcement learning

In RL theory, unlike other machine learning methods, no prior knowledge is given. The aim is to maximize the rewards for future actions by using the experiences gained after exploring the environment. There are two basic elements in RL, the agent and the environment. Two distinctive features of RL; trial and error search and delayed reward feature [25].

**Agent:** A learner and decision maker in an environment. Sometimes the agent can be a drone performing a task or a robot learning to stand.

**Environment:** The world created for an agent to learn something. This can sometimes be the exact environment observed by the agent, such as in arcade games. Sometimes it can be a partially observed environment, such as a camera image.

The agent and the environment interact at each t time period. At each step t, the agent receives a representation of the environment st ∈ S, and chooses an action from the set A(S). One step later, the agent receives a numerical reward (rt ∈ R) as a result of the interaction and sets a new state (st+1) [26]. In Fig. 3, the operation of the DRL is visualized.

Deep Reinforcement Learning (DRL) is basically the same as RL. However, the main difference is that it uses deep learning algorithms instead of experience tables for action choices. The best example of this is the Atari games developed by Google DeepMind. Especially in the fields of computer vision, voice recognition, and robotics, where great strides have been made in recent years, large datasets need to be trained. Normally the estimation of the value function can be represented in a tabular form.

However, the large continuous state spaces that occur in real-world problems slow down the training considerably. In this case, the problem is solved using neural networks [27]. The aim of the agent is to make the neural network closer to the optimal action-value function by maximizing the cumulative reward, as shown in Eq. (1).

```
Q' (s, a) = max_\pi E { R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots | s_t = s, a_t = a, \pi }
```

With the developments in machine learning, especially in the field of robotics, DRL had to improve itself. Distributed RL has succeeded in increasing the pace of learning by distributing learning among many workers. In addition, environmental knowledge learned per unit time also increases. Gorilla is one of the pioneering architectures in this field. After Gorilla, current distributed architectures such as A3C, IMPALA, APE-X, D4PG have been used. In this architecture, the goal is to gain experience using multiple actors to update the weights [8]. All used actors can access a trained system at the same time. Distributed Deep Reinforcement learning architecture is described in algorithm 1 and algorithm 2 [28].
