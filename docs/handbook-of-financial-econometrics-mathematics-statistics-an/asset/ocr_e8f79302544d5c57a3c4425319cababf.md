# 110.2 Integral Equation for Φ

For notational convenience, from now on, we will write $X_t = X_0 + X_t^c - Z_t$ with $X_t^c - c t + \sigma W_t$. For any constant $x \in R$, write $\hat{x} = \frac{x}{\sigma}$, and $J_k$ denotes the $k$th epoch time of the compound Poisson process $Z$ with interarrival time $S_k$, that is $J_k = \sum_{j=1}^k S_j$. Furthermore, if $G_1,\ldots,G_n$ are random variables on $R$, we write $F_{G_1,\ldots,G_n}$ for their joint distribution. We preserve $F$ for the distribution of $-\log(1+U_j)$.

We use an integral-equation technique to take a first look at the function $\Phi$/ to begin with, write

$$\{\tau(T) < T\} = A \cup B \cup C \cup D, \tag{110.8}$$

where

+   - $A = [J_1 > T \ge \tau(T)]$
+     (No jump up to maturity and default is caused by diffusion),
+   - $B = [T > J_1 \ge \tau(T)]$
+     (Jump occurs up to maturity and default occurs before $J_1$),
+   - $C = [T > \tau(T) = J_1]$
+     (Jump occurs up to maturity and default occurs at $J_1$),
+   - $D = [T > \tau(T) > J_1]$
+     (Jump occurs up to maturity and default occurs after $J_1$).

Note that $\{A, B, C, D\}$ is a partition of $\{\tau(T) \le T\}$. With these, we define $G_A(x,T)=E_x[\psi(X_{\tau(T)});A]$ and similarly for $G_B$, $G_C$ and $G_D$. Before stating our results, we recall some facts about the joint distribution of Brownian motion with drift and its maximum process. For details and proofs, see Shreve (2003).

**Theorem 110.1.** *Let $\alpha \in R, T > 0, W(t,\alpha)=\alpha t+W(t)$ and $M(T;\alpha)=Max_{0\le t\le T}W(t;\alpha)$. Then the joint density of $M(T;\alpha)$ and $W(t;\alpha)$ is given by*

$f_{M(T;\alpha),W(T;\alpha)}(m,w)=\begin{cases}\frac{2(2m-w)}{T\sqrt{2\pi T}}e^{\alpha w-\frac12\alpha^2T-\frac1{2T}(2m-w)^2}, & w \le m,\ m \ge 0,\\0, & \text{otherwise}\end{cases}\tag{110.9}$
