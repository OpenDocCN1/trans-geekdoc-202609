## 6.2 Model
### 6.2.1 ARIMA-GARCH model
According to Box and Tiao (1975), the ARMA model of TAIEX could be set up as follows: $ln P_t = φ_1 ln P_{t−1} + ⋯ + φ_p ln P_{t−p} + ε_t + θ_1 ε_{t−1} + ⋯ + θ_q ε_{t−q}$, where $p$ is the order of autoregression, $q$ is the order of moving average, $φ_1, ⋯, φ_p$ are the parameters of autoregression, $θ_1, ⋯, θ_q$ are the parameters of moving average, $ε_t$ is the residuals at term $t$. This model can also be represented as ARMA(p, q). The model can also be represented by using lag symbols, the model can be represented as $(1 − φ_1L^1 − ⋯ − φ_pL^p) ln P_t = (1 + θ_1L^1 − ⋯ − θ_qL^q)ε_t$, where $L$ is the lag symbol. The model can finally be represented as $φ_p(L)ln P_t = θ_q(L)ε_t$.

According to Dickey and Fuller (1979), when the series is not stationary, we need to take the appropriate difference with the series, the series is called ARIMA(p, d, q), the model can be represented as $φ_p(L)Δ^d ln P_t = θ_q(L)ε_t$, where d is the order of differencing.

According to Hansen and Lunde (2005), the residuals test is inconsistent which means the residuals demonstrated the problem of heteroskedasticity. The model improvement is necessary. The GARCH model would work. The model is $σ^2_{ε,t} = a_0 + a_1σ^2_{ε,t−1} + ⋯ + a_pσ^2_{ε,t−p} + ε_t + b_1ε^2_{t−1} + ⋯ + b_qε^2_{t−q}$, that represents GARCH(p, q). According to Jeon and Taylor (2016), Mohammadi (2017), the model could be applied to forecasting issues.

### 6.2.2 Intervention model and outlier detection
Fox (1972) indicates that the outlier could affect the ARIMA model. There are four types of outliers:

- 1. **Additive outlier (AO)**
This type of outlier means that the event affects only one period, the intervention model could be set up as: $∇^d ln P_t = \frac{θ_q}{φ_p} ε_t + v_A I_t(T)$, where $v_A$ is a parameter, and $I_t(T)$ is a dummy variable set as
$$I_t(T) = \begin{cases} 1, & t = T \\ 0, & t ≠ T. \end{cases}$$

- 2. **Innovational Outlier (IO)**
This type of outlier means that each period will be affected from $T$, the intervention model could be set up as: $∇^d ln P_t = \frac{θ_q}{φ_p}[ε_t + v_I I_t(T)]$, where

model could be represented as:

$$\Delta^{d}\ln P_{t}=\sum_{i=1}^{n}\beta_{i}\Delta^{d}\ln X+v_{A}I_{1t}(T)+v_{I}I_{2t}(T)$$ $$\quad+\frac{1}{1-L}v_{L}I_{3t}(T)+\frac{1}{1-\delta L}v_{C}I_{4t}(T)+\frac{\theta_{q}(L)}{\phi_{p}(L)}\varepsilon_{t},$$

where

$$I_{1t}(T)=\begin{cases}1 & t=T\\0 & t\neq T\end{cases},\; I_{2t}(T)=\begin{cases}1 & t\ge T\\0 & t<T\end{cases}=I_{3t}(T)=I_{4t}(T).$$

### 6.2.4 Combination forecasting model
According to Granger and Ramanathan (1984) and Lin et al. (2015), the combination forecasting model of TAIEX, there are two ways to set up the model. One is simple average way, the other one is minimum error way. The simple average combination forecasting model could be represented as: ln \hat{P}^C = ω₁ ln \hat{P}^{M1} + ω₂ ln \hat{P}^{M2} + ⋯ + ω_k ln \hat{P}^{Mk}, where k is the number of models, and ω₁, ω₂, …, ω_k are the weight of each model, and in this model the weight is calculated by average (ω₁ + ω₂ + ⋯ + ω_k)/k. The minimum error combination forecasting model could be represented as: ln \hat{P}^C = ω₁ ln \hat{P}^{M1} + ω₂ ln \hat{P}^{M2} + ⋯ + ω_k ln \hat{P}^{Mk} + ε, and in this model the weight is calculated by simple regression method.

## 6.3 Empirical Analysis
Let P be the TAIEX, D be the INDU (Dow Jones Industrial Average Index), E be the exchange rate, and C be the consumer price index. In order to eliminate the inconsistency of the data unit, natural logarithms in the series TAIEX, INDU, exchange rate, and consumer price index are taken and expressed as ln P, ln D, ln E, ln C. To establish the prediction model for the TAIEX, the researchers used the time-series data from the Directorate-General of Budget, Accounting and Statistics, Executive Yuan, R.O.C.,³ and Taiwan Economic Journal.⁴ The data periods from January 1991 to January 2012 yielded 258 months of data.
