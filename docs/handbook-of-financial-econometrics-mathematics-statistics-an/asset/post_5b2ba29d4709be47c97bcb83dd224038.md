## Abstract

This study proposes a Bayesian test for a test portfolio p’s mean–variance efficiency that takes into account the sampling errors associated with the ex post Sharpe ratio ŜR of the test portfolio p. The test is based on the Bayes factor that compares the joint likelihoods under the null hypothesis H0 and the alternative H1, respectively. Using historical monthly return data of 10 industrial portfolios and a test portfolio, namely, the CRSP value-weighted index, from January 1941 to December 1973 and January 1980 to December 2012, the power function of the proposed Bayesian test is compared to the conditional multivariate F-test by Gibbons, Ross and Shanken (1989) and the Bayesian test by Shanken (1987). In an independent simulation study, the performance of the proposed Bayesian test is also demonstrated.

### 93.1 Introduction

The central assertion of CAPM is that the market portfolio p is mean–variance efficient in that its return has the minimum variance given its expected return and the maximum expected return given its variance (e.g., see Sharpe, 1964; Lintner, 1965). In the traditional empirical approach, the test of a market portfolio p’s efficiency is performed within a predefined set of N risky assets that determines the mean–variance efficient frontier (e.g., see Black et al., 1972; Fama and MacBeth, 1973). In the presence of a riskless asset, the mean–variance efficient property is equivalent to the joint restriction that all the intercepts of the N time-series regression models, in which the N risky assets’ excess returns are regressed on the market portfolio p’s excess returns, are zeros (e.g., see Roll, 1977; Roll and Ross, 1994).

Various tests are developed to test the null hypothesis that all the intercepts of the N time-series regression models are zeros. For example, a set of N univariate t tests on the N intercepts are adopted (e.g., see Black et al., 1972; Fama and MacBeth, 1973). However, two deficiencies are associated with a set of N univariate t-tests. First, it is less likely the N univariate t-tests will be significant simultaneously, so the results are difficult to summarize (e.g., see Black, Jensen, and Scholes, 1972). Second, the N separate univariate t-tests ignore cross-sectional dependence between the excess returns of the N risky assets.

Instead of the N univariate t tests, multivariate tests were developed (e.g., see Gibbons, 1982; Jobson and Korkie, 1985; Shanken, 1985; Gibbons et al., 1989; MacKinlay, 1987; MacKinlay and Richardson, 1991). Among these, the multivariate F-test by Gibbons, Ross and Shanken (1989) has become the standard. Tests in the Bayesian framework were developed by Shanken (1987) and Kandel et al. (1995) that is based on the ratio ρ = SR/SR* between the ex ante Sharpe ratio SR of the test portfolio p and the ex ante maximum Sharpe ratio SR* attainable by the N risky assets and the test portfolio p. However, either the multivariate F-test by Gibbons, Ross and Shanken (1989), or the Bayesian tests by Shanken (1987), the test statistics depends on the ex post Sharpe ratio ŜR of the test portfolio p. Therefore, the powers of these tests depend on the precision of the ex post Sharpe ratio ŜR. However, the ex post Sharpe ratio ŜR is calculated empirically based on the test portfolio p’s historical excess returns R1, . . . , RT that are subject to measurement errors. In case the ex post Sharpe ratio ŜR overestimates the ex ante Sharpe ratio SR, the power of the test decreases. For this reason, the measurement errors associated with the ex post Sharpe ratio ŜR need to be taken into consideration.

This study develops a Bayesian test of a test portfolio p’s mean–variance efficiency. In contrast to the previous mean–variance efficiency tests, the measurement errors associated with test portfolio p’s ex post Sharpe ratio ŜR is taken into consideration using the derived asymptotic distribution of ŜR under stationary and ergodic excess returns (Christie, 2005; Opdyke, 2007). The proposed Bayesian test is based on the Bayes factor B10 that compares the joint likelihoods under the null hypothesis H0 and the alternative hypothesis H1, respectively (e.g., see Kass and Raftery, 1995). Therefore, the proposed Bayesian test is unconditional and the power of the proposed Bayesian test is independent of the measurement errors associated with the ex post Sharpe ratio ŜR.

The paper is organized as follows. In Section 93.2, the multivariate F-test of a portfolio p’s efficiency by Gibbons et al. (1989) is reviewed. In Section 93.3, Bayesian tests from the previous literature are reviewed. An unconditional Bayesian test based on the Bayes factor is developed. An empirical study that uses monthly return data of 10 industrial portfolios and a test portfolio, namely, the CRSP value-weighted index, from January 1941 to December 1973 and January 1980 to December 2012, respectively, is given in Section 93.4. An independent simulation study is also given. The performance of the proposed Bayesian test is compared to the conditional F-test of Gibbons, Ross, and Shanken (1989) and Shanken’s Bayesian test (Shanken, 1987). Section 93.5 concludes.

### 93.2 Testing Portfolio Efficiency in Multivariate Framework

Suppose there exists a risk-free asset and a set of N risky assets that determines the mean–variance efficient frontier. Let r_t = (r_{1t},...,r_{Nt}) be the excess returns of the N risky assets at time t for 1 ≤ t ≤ T. Consider a test portfolio p with time-t excess return R_t for 1 ≤ t ≤ T. Here, it is assumed the excess returns R_t and r_t are linearly independent. For the i^{th} risky asset, 1 ≤ i ≤ N, consider the time-series regression model

r_{it} = α_i + β_i R_t + ε_{it},  (93.1)

where r_{it} is the excess return of asset i at time t, 1 ≤ i ≤ N, 1 ≤ t ≤ T. For all time t, 1 ≤ t ≤ T, the cross-sectional disturbances ε_t = (ε_{1t},...,ε_{Nt}) ~ MN(0,Σ) are multivariate normally distributed with mean zeros and a non-singular N × N covariance matrix Σ. In addition, the time series of the random vectors of disturbances ε_1,...,ε_T are i.i.d. This assumption implies the time series of the i^{th} risky asset's disturbances ε_{i1},...,ε_{iT} are i.i.d. normally distributed, where 1 ≤ i ≤ N.

Under the CAPM framework, the test portfolio p coincides with the tangent portfolio on the mean–variance efficient frontier if and only if the N intercepts α_1,...,α_N are zeros (e.g., see Black et al., 1972). Thus, the test of portfolio p's efficiency is equivalent to test the null hypothesis

H_0 : α = 0

versus the alternative hypothesis H_1: α ≠ 0, where α = (α_1, ..., α_N) are the intercepts of the N time-series regression models in (93.1). In Black et al. (1972) and Fama and MacBeth (1973), N univariate t tests are developed to test the null hypothesis that the N intercepts α_1, ..., α_N are zeros, respectively. However, two deficiencies are associated with the N univariate t tests. First, it is less likely the N univariate t tests will be significant simultaneously, so the results are difficult to summarize (e.g., see Black et al., 1972). Second, and the most important, the N separate univariate t tests ignore cross-sectional dependence between the excess returns of the N risky assets.
