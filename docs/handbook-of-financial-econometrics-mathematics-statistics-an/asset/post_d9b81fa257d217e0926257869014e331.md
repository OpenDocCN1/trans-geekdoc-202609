
we get the system of linear equations

$$\sum_{i=1}^{m+1} Q_i = g(0),$$
$$\sum_{i=1}^{m+1} \frac{Q_i \eta_j}{\rho_i + \eta_j} = \int_{-\infty}^0 g(y)\eta_j e^{\eta_j y} dy, \quad 1 \le j \le m. \tag{41.48}$$

The following proposition confirms our conjecture.

## Proposition 41.4.2: If $Q$ satisfies (41.48) for some bounded Borel-measurable function $g$, then

$$\Phi(x) = E_x[e^{-r\tau} g(X_\tau)] = \sum_{i=1}^{m+1} Q_i e^{\rho_i x}, \text{ for } x \ge 0. \tag{41.49}$$

**Proof.** Please refer to Appendix 41A.

In fact, the coefficient matrix of equations (41.48) is invertible. Hence, we can write $Q$ in a general matrix form. Instead of the matrix form, we exploit the technique in Dufresne and Gerber (1989) to get an explicit formula for $Q$.

## Theorem 41.4.3: Assume that $X$ satisfies (41.45) and $f_{(+) }(y)$ is given by (41.46). Then, for any bounded Borel function $g : R_- \to R$, we have $\Phi = E_x[e^{-r\tau} g(X_\tau)] = \sum_{i=1}^{m+1} Q_i e^{\rho_i x}$ on $R_+$, where, for $1 \le h \le m + 1$,

$$Q_h = \frac{1}{\rho_h \prod_{i=1, i \ne h}^{m+1} (-\rho_h + \rho_i)} \sum_{j=1}^{m+1} R_j \left( \prod_{k=1}^{m+1} (\eta_j + \rho_k) \right) \prod_{i=1, i \ne j}^{m+1} \frac{-\rho_h - \eta_i}{\eta_j - \eta_i} \tag{41.50}$$

and
$$R_j = g(0) - \int_0^{\infty} g(-y)\eta_j e^{-\eta_j y} dy. \tag{41.51}$$
Here we set $\eta_{m+1}=0.$

**Proof.** Clearly, the system (41.48) is equivalent to the system of linear equations
$$\sum_{i=1}^{m+1} \frac{Q_i \rho_i}{\rho_i + \eta_j} = R_j, \ 1 \le j \le m + 1, \tag{41.52}$$

where the $R_j$ are given by (41.51). Since the system (41.48) admits at most one solution, so does (41.52).

## An ODE Approach for the Expected Discounted Penalty

Consider the rational function

H(x) = \sum_{j=1}^{m+1} R_j \prod_{k=1}^{m+1} \frac{\eta_j + \rho_k}{x + \rho_k} \prod_{i=1,i \neq j}^{m+1} \frac{x - \eta_i}{\eta_j - \eta_i}. (41.53)

Note that, for each summand in (41.53), the numerator is a polynomial of degree m, and the denominator is a polynomial of degree m + 1. By the principle of partial fraction decomposition, there exist constants D_h, 1 ≤ h ≤ m + 1, such that

\sum_{j=1}^{m+1} R_j \prod_{k=1}^{m+1} \frac{\eta_j + \rho_k}{x + \rho_k} \prod_{i=1,i \neq j}^{m+1} \frac{x - \eta_i}{\eta_j - \eta_i} = H(x) = \prod_{i=1}^{m+1} \frac{D_i \rho_i}{\rho_i + x}. (41.54)

By multiplying both sides of (41.54) by x + ρ_h and then setting x = -ρ_h, we get that D_h is given by the right-hand side of (41.50). On the other hand, since \prod_{i=1,i \neq h}^{m+1} \frac{\eta_h - \eta_i}{\eta_j - \eta_i}=0 for h ≠ j,

\sum_{i=1}^{m+1} \frac{D_i \rho_i}{\rho_i + \eta_h} = H(\eta_h) = R_h \prod_{k=1}^{m+1} \frac{\eta_h + \rho_k}{\eta_h + \rho_k} \prod_{i=1,i \neq h}^{m+1} \frac{\eta_h - \eta_i}{\eta_h - \eta_i} = R_h , 1 ≤ h ≤ m+1.

That is, D is a solution to (41.52). Since the solution to (41.52) is unique and (41.48) and (41.52) are equivalent, Q = D is the unique solution of (41.48). By Proposition 41.4.2, we have Φ ≡ \sum_{i=1}^{m+1} Q_i e^{\rho_i x} on R_+ .

Remark 41.4.5: We consider some special g.

(1) Assume that g ≡ 1_{(-∞,y)} for some y ≤ 0. Then R_j = e^{-η_j y} for 1 ≤ j ≤ m and R_{m+1} = 0. Hence,

E_x[e^{-r τ}1_{X_\tau<y}] = \sum_{h=1}^{m+1} \left[ \frac{-1}{\rho_h \prod_{l=1,l \neq h}^{m+1} (-\rho_h + \rho_l)} \times \sum_{j=1}^{m+1} e^{\eta_j y} \left( \prod_{k=1}^{m+1} (\eta_j + \rho_k) \prod_{i=1,i \neq h}^{m+1} \frac{-\rho_h - \eta_i}{\eta_j - \eta_i} \right) \right] e^{\rho_h x}.

(2) Assume that g ≡ 1_{[0]}. Then R_j = 1 for all j. Hence,

E[e^{-r τ}1_{[0]}(X_τ)] = \sum_{h=1}^{m+1} \left[ \frac{1}{\rho_h \prod_{l=1,l \neq h}^{m+1} (-\rho_h + \rho_l)} \times \sum_{j=1}^{m+1} \left( \prod_{k=1}^{m+1} (\eta_j + \rho_k) \prod_{i=1,i \neq h}^{m+1} \frac{-\rho_h - \eta_i}{\eta_j - \eta_i} \right) \right] e^{\rho_h x}. (Cf. [20])

## Example 41.4.7 (Option pricing).

A first-touch digital is a digital contract paying $1 when and if a prespecified event occurs. Consider the first-touch digital, or touch-and-out option, which pays $1 if the stock price $S$

falls below the level $H$ from above. If the stock price turns out to stay above the level $H$ up to the expiration time $T>0$, the claim expires worthless. It can be interpreted as an American-put-like option with a digital payoff. Since a payoff is the same for all levels of the stock price below the barrier, it is clearly optimal to exercise the option once the level $H$ is crossed. We consider a general framework. Let $S$ be the price process of a security satisfying $S=He^X$ under a risk-neutral probability measure, where $X$ is given by (41.45), and $H>0$ is given constant threshold. Assume the existence of a constant risk-free rate $r>0$. Consider a derivative with maturity $T$ on this security whose payoff structure is given by

- 1. A bounded function $k(S_{\tau_H})$ at the time $\tau_H\le T$, where $\tau_H=\inf\{t;S_t\le H\}$,
- 2. A constant payment $A$ at the time $T$ if $S$ does not cross the boundary $H$ till maturity.

Let $x=\log(S_0/H)$, $g(y)=k(He^y)$ for $y\le0$, and $\tau=\inf\{t;X_t\le0\}$ as usual. Then by the risk-neutral pricing formula the risk-neutral price of this derivative is given by

$$V(S_0,T)=E_x\left[e^{-r\tau}g(X_\tau)\mathbf{1}_{[\tau\le T]}\right]+E_x\left[e^{-rT}A\mathbf{1}_{[\tau>T]}\right]$$
$$=E_x\left[e^{-r\tau}g(X_\tau)\mathbf{1}_{[\tau\le T]}\right]+e^{-rT}A\left(1-P_x[\tau\le T]\right). \tag{41.59}$$

To find the unknown quantities $E_x[e^{-r\tau}g(X_\tau)\mathbf{1}_{[\tau\le T]}]$ and $P_x[\tau\le T]$, we take their Laplace transforms with respect to time $T$. By Fubini's theorem, for every $\beta>0$,

$$\int_0^\infty e^{-\beta T}E_x\left[e^{-r\tau}g(X_\tau)\mathbf{1}_{[\tau\le T]}\right]dT=\frac{1}{\beta}E_x\left[e^{-(r+\beta)\tau}g(X_\tau)\right]. \tag{41.60}$$

and

$$\int_0^\infty e^{-\beta T}P_x[\tau\le T]dT=\frac{1}{\beta}E_x\left[e^{-\beta\tau}\right]. \tag{41.61}$$

The right-hand sides of both equations can be written explicitly using Theorem 41.4.3. Hence, we have an expression for the value $V(S_0,T)$ up to a Fourier transform.
