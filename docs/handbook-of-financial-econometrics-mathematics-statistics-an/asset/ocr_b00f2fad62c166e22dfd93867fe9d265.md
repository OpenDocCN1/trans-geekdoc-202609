The variance chosen was the minimum variance of the portfolio associated with E(R_p) = 0.0082. Actually, any variance might have realistically been chosen as long as it exceeded the minimum-risk portfolio variance. Table 80A.4 lists various W11 and W12 values for given levels of W2 and Var(R_p). In addition, Table 80A.4 presents the value of b² and 4ac to check whether or not the root is a real number. It should be noted that all possible variances are higher than the minimum-risk portfolio variance. Data from Table 80A.4 are used to draw three iso-variance ellipses, as indicated in Figures 80A.2 and 80A.3.
