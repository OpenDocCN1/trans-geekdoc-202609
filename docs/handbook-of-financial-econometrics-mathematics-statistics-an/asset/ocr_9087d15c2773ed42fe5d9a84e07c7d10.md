Since $S(t) = \exp[-\Lambda(t)]$, the estimator for the cumulative hazard function is

```
\hat{\Lambda}(t) = -\log \hat{S}(t) = -\log \prod_{i\leq t} \left( \frac{n_i - d_i}{n_i} \right) = - \sum_{i\leq t} \log \left( \frac{n_i - d_i}{n_i} \right).
```

Because log(1 + x) = x for small x, so above equation can be expressed as

```
\hat{\Lambda}(t) = \sum_{i\leq t} \frac{d_i}{n_i}.
```

The variance of Nelson–Aalen estimator is estimated by

```
var [\hat{\Lambda}(t)] = \sum_{i\leq t} \frac{d_i}{n_i^2}.
```

The plot of the Nelson–Aalen estimator illustrates the hazard rate. A comparison between multiple Nelson–Aalen estimators provides a visual examination on the difference of different hazard types. We will discuss it in a later section.
