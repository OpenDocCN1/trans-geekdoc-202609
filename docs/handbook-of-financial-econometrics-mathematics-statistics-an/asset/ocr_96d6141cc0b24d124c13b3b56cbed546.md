# 3. Transactions in June, 2013

| Input Variables | Description |
|---|---|
| CREDIT_LMT_CRT | The maximum credit limit |
| LATEDAYS | The average number of days that the client's credit card payments have passed the due date |
| UNPAID_DAYS | The average number of days that previous transactions have remained unpaid |
| BALANCE_ROT | The current balance of credit card revolving payment |
| BALANCE_CSH | The current balance of cash withdrawal |
| GRACE_PERIOD | The remaining number of days that the bank gives the credit card holder to pay off the new balance without paying finance charges. The time window starts from the end of June, 2013 to the next payment due date. |
| INSTALL_LIM_ACT | The available installment limits. It equals the installment limit plus the installment paid¹⁴ |
| CASH_LIM | The limit of cash withdrawal |

14 The actual amount of installment limit could exceed the installment limit provided by the bank for the customer. This happens when the customer made some payments, so those funds become available for borrowing again.
