# Part I:

This part illustrates how to solve a simultaneous equation system by using the matrix inversion method, given simultaneous equations as follows:

3x₁ + 2x₂ + 4x₃ = 32,
2x₁ + 3x₃ = 19,
4x₁ + 2x₂ + 3x₃ = 29.

The simultaneous equations can be written as the matrix forms:

\begin{bmatrix}3 & 2 & 4\\2 & 0 & 3\\4 & 2 & 3\end{bmatrix}_{A}\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}_{X}=\begin{bmatrix}32\\19\\29\end{bmatrix}_{K}

Then we can obtain the elements of matrix X by multiplying the inverse matrix A⁻¹ and the matrix K. In the following part, we will illustrate the calculation of the inverse matrix in Excel.
