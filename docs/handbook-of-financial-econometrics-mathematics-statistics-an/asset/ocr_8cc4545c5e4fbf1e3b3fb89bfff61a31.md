Under the assumption of logarithmic utility function to solve the general equilibrium model,

```
$u(c_t) = a \ln(c_t).$ (122.50)
```

Using the fact that $u'(c_t)=a/c_t$ and the market-clearing condition $c_t = d_t$, the demand for consumption goods equals the net supply to the consumers of the multi-purpose good, the share pricing equation (122.39) yields

```
$p_t = E_t \sum_{i=1}^{\infty} \rho^i d_{t+i} = [\rho/(1-\rho)]d_t.$ (122.51)
```

Under the logarithmic form of the utility function, $p_t$ does not depend on future dividends. From equation (122.48) for share prices and (122.51) to define returns,

```
$R_{t+1} = (1/\rho)(d_{t+1}/d_t).$ (122.52)
```

Equations (122.46), (122.47), (122.48), and (122.52) characterize the dynamic path for $d_t$, $k_t$, $y_t$, and $R_t$. Where investment is proportional to output, then yields $k_{t+1}=\alpha\beta y_t$, which implies from equation (122.46) that $d_t=(1-\alpha\beta)y_t$. Therefore, equation (122.39) becomes

```
$R_{t+1} = (1/\rho)(y_{t+1}/y_t),$ (122.53)
```

then substituting equation (122.53) into (122.4) verifies that the posited solution is correct. Since future output depends on current investment, it can be predicted from current observations. The solution $k_{t+1}=\alpha\beta y_t$ implies that

```
$y_{t+1}=\theta_{t+1}\gamma^{\beta^t} y_t^{\alpha},$ (122.54)
```
