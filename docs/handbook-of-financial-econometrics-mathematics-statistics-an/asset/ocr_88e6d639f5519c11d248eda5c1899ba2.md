# A. Partial least squares regression

PLS attempts to extract factors from the **X** matrix that are associated with predicting *y* (i.e., $f s i_{t+j}$). Let $\Delta F_{t1}, \Delta F_{t2}, \dots, \Delta F_{tR}$ represent $R < N$ linear combinations of our original predictor variables. That is,

$\Delta F_{tr} = \sum_{i=1}^{N} w^{*}_{ir} X_{ti}$

where $t = 1,2,\dots,T$ and $\Delta F_{tr}$ ($r = 1,\dots,R$) are called **X**-scores$^1$ and constants. They are estimated as linear combinations of the original predictors $X_{ti}$ with the weights, $w^{*}_{tr}$. The **X**-scores have the following two properties:

+   (1) The matrix **X** can be decomposed as **X**= $\Delta\mathbf{F}\mathbf{P}' + \mathbf{E}$, where $\Delta\mathbf{F}$ is a matrix whose columns are the **X**-scores, and **P** is a matrix whose columns are called the **X**-loadings. In other words, **X**-scores are multiplied by the loadings $p_{ri}$, which can provide good summaries of **X**, so that the residuals of X, $e_{ti}$, are small enough:
+   
+   $X_{ti} = \sum_{r=1}^{R} \Delta F_{tr} p_{ri} + e_{ti}$.
+   
+   (2) $f s i_{t+j}$ is modeled using linear regression on the **X**-scores$^2$, so that the **X**-scores are predictors of $f s i_{t+j}$:
+   
+   $f s i_{t+j} = \sum_{r=1}^{R} c_r \Delta F_{tr} + \xi_{t+j}$
