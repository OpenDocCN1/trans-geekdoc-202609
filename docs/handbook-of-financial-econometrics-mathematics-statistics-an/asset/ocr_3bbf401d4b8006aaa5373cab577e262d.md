# 85.7 Applications of the Log-Normal Distribution in Option Pricing

To derive the Black-Scholes formula, it is assumed that there are no transaction costs, no margin requirements, and no taxes; that all shares are infinitely divisible; and that continuous trading can be accomplished. It is also assumed that the economy is risk neutral and the stock price follows a log-normal distribution. Denote the current stock price by $S$ and the stock price at the end of $j$th period by $S_j$.

Then $\frac{S_j}{S_{j-1}}=\exp[K_j]$ is a random variable with a log-normal distribution, where $K_j$ is the rate of return in $j$th period and is a random variable with normal distribution. Let $K_t$ have the expected value $\mu_k$ and variance $\sigma_k^2$ for each $j$. Then $K_1+K_2+\ldots+K_t$ is a normal random variable with expected value $t\mu_k$ and variance $t\sigma_k^2$. Thus, we can define the expected value (mean) of $\frac{S_t}{S}=\exp[K_1+K_2+\ldots+K_t]$ as

$E\left(\frac{S_t}{S}\right)=\exp\left[t\mu_k+\frac{t\sigma_k^2}{2}\right].\tag{85.52}$

Under the assumption of a risk-neutral investor, the expected return $E(\frac{S_t}{S})$ is assumed to be $\exp(rt)$ (where $r$ is the riskless rate of interest). In other words,

$\mu_k=r-\frac{\sigma_k^2}{2}.\tag{85.53}$
