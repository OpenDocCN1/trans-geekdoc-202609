= e^{-rτ}(1 - N(d₂)) + \frac{1}{σ_s\sqrt{2π τ}} e^{-\frac{d₂²}{2}} \left(\frac{S_t}{X}\right) - \frac{1}{σ_s\sqrt{2π τ}} e^{-\frac{d₂²}{2}} \left(\frac{S_t}{X}\right)

= e^{-rτ} N(-d₂).

For a European call option on a dividend-paying stock, the sensitivity can be shown as

$$\frac{\partial C_t}{\partial X} = -e^{-rτ} N(d_2).\tag{86.31}$$

The derivation of (86.31) is

$$\frac{\partial C_t}{\partial X} = S_t e^{-qτ} \frac{\partial N(d_1)}{\partial X} - e^{-rτ} N(d_2) - X e^{-rτ} \frac{\partial N(d_2)}{\partial X}$$
$$= S_t e^{-qτ} \frac{\partial N(d_1)}{\partial d_1} \frac{\partial d_1}{\partial X} - e^{-rτ} N(d_2) - X e^{-rτ} \frac{\partial N(d_2)}{\partial d_2} \frac{\partial d_2}{\partial X}$$
$$= S_t e^{-qτ} \frac{1}{\sqrt{2π}} e^{-\frac{d_2^2}{2}} \cdot \frac{1}{σ_s\sqrt{τ}} \cdot \left(-\frac{1}{X}\right) - e^{-rτ} N(d_2)$$
$$- X e^{-rτ} \left(\frac{1}{\sqrt{2π}} e^{-\frac{d_2^2}{2}} \cdot \frac{S_t}{X} \cdot e^{(r-q)τ}\right) \frac{1}{σ_s\sqrt{τ}} \cdot \left(-\frac{1}{X}\right)$$
$$= \frac{1}{σ_s\sqrt{2π τ}} e^{-\frac{d_2^2}{2}} \left(-\frac{S_t e^{-qτ}}{X}\right) - e^{-rτ} N(d_2) - \frac{1}{σ_s\sqrt{2π τ}} e^{-\frac{d_2^2}{2}} \left(-\frac{S_t e^{-qτ}}{X}\right).$$
$$= -e^{-rτ} N(d_2).$$

For a European put option on a dividend-paying stock, the sensitivity can be shown as

$$\frac{\partial P_t}{\partial X} = e^{-rτ} N(-d_2).\tag{86.32}$$

The derivation of (86.32) is

$$\frac{\partial P_t}{\partial X} = e^{-rτ} N(-d_2) + X e^{-rτ} \frac{\partial N(-d_2)}{\partial X} - S_t e^{-qτ} \frac{\partial N(-d_1)}{\partial X}$$
$$= e^{-rτ} (1 - N(d_2)) + X e^{-rτ} \frac{\partial (1 - N(d_2))}{\partial d_2} \frac{\partial d_2}{\partial X}$$
$$- S_t e^{-qτ} \frac{\partial (1 - N(d_1))}{\partial d_1} \frac{\partial d_1}{\partial X}$$
