# Table 35.1: Attributes and indicators in determining the capital structure.

| Attributes | Indicators |
|---|---|
| Asset structure | Intangible asset/total assets (INT_TA) |
|  | Inventory plus gross plant and equipment /total assets (IGP_TA) |
| Non-debt tax shield | Investment tax credits/total assets (ITC_TA) |
|  | Depreciation/total assets (D_TA) |
|  | Non-debt tax shields/total assets (NDT_TA) |
| Growth | Capital expenditures/total asset (CE_TA) |
|  | The growth of total assets (GTA) |
|  | Research and development/sales (RD_S) |
| Uniqueness | Research and development/sales (RD_S) |
|  | Selling expense/sales (SE_S) |
|  | Quit rates (QR) |
| Industry Classification | SIC code (IDUM) |
| Size | Natural logarithm of sales (LnS) |
| Volatility | The standard deviation of the percentage change in operating income (SIGOI) |
| Profitability | Operating income/sales (OI_S) |
|  | Operating income/total assets (OI_TA) |
| Capital Structure | Long-term debt/market value of equity (LT_MVE) |
|  | Short-term debt/market value of equity (ST_MVE) |
|  | Convertible debt/market value of equity (C_MVE) |
|  | Long-term debt/book value of equity (LT_BVE) |
|  | Short-term debt/book value of equity (ST_BVE) |
|  | Convertible debt/book value of equity (C_BVE) |

Notes: This table presents attributes that may affect a firm's capital structure as suggested by Titman and Wessel (1988). Attributes include capital structure, asset structure, non-debt tax shield, growth, uniqueness, industry classification, size, volatility, and profitability. Indicators of attributes, observable variables, are also presented. The parentheses in indicators are the notations used in the LISREL system.

Specifically, we introduce the ratio of research and development to total assets as an indicator of growth, the quit rates as an indicator of industry classification, the coefficients of variation of ROA, ROE and the operating income as indicators of volatility, and ratios of long-term debt, short-term debt and convertible debt to total assets as indicators of the capital structure. Moreover, we introduce an additional financial rating attribute, including Altman's z-score, the S&P domestic long-term issuer credit rating, and the S&P investment credit rating. We then use the confirmatory factor analysis (CFA) approach to test whether observed variables can effectively measure attributes.
