represented as follows:

```
Δ^d ln P_t = v1(L) I1t + v2(L) I2t + v3(L) I3t + v4(L) I4t + (1 + θ) ε_t,
I1t = { 0  t ≠ Nov. 1993
        1  t = Nov. 1993 },
I2t = { 0  t < June 1997
        1  t ≥ July 1997 },
I3t = { 0  t ≠ Nov. 2001
        1  t = Nov. 2001 },
I4t = { 0  t < June 2007
        1  t ≥ July 2007 },
ε_t ~ N(0, σ²_{ε,t}),
σ²_{ε,t} = a0 + a1 σ²_{ε,t-1} - b1 ε_{t-1},   (6.1)
```

where v1(L),..., v4(L) are the impulse response function and I1t,..., I4t are the binary variables.

According to the estimation results shown in Table 6.4, after integrating intervention analysis into the model, the residuals were consistent with white noise; therefore, the TAIEX model constructed by using the intervention analysis integrated into ARIMA-GARCH model can be represented as follows:

```
Δ^d ln P_t = 0.333 I1t - 0.03 I2t + 0.234 I3t - 0.026 I4t + ε_t + 0.065 ε_{t-1},
ε_t ~ N(0, σ²_{ε,t}),
σ²_{ε,t} = 0.001 + 0.165 σ²_{ε,t-1} + 0.814 ε_{t-1}.   (6.2)
```

As shown in Model (2), the external events of November 1993 and November 2001 produced a positive effect on the TAIEX; whereas, July 1997 and July 2007 produced a negative effect. The model was preliminarily determined to operate in the following situations:

+   (1) With the increase in Taiwan’s Securities and Exchange Commission foreign direct investment to 200 million USD in November 1993 and the acceptance of Taiwan’s application for membership in the World Trade Organization, positive changes occurred in the TAIEX.
+   (2) With the Asian financial crisis of July 1997 and the subprime mortgage crisis of July 2007, negative changes occurred in the TAIEX.
