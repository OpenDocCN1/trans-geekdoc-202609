Thus, given the above information, our objective is to determine the values for y1,i, y2,i, y3,i and xj,i for each time interval that minimizes the total discounted costs over the entire planning horizon. This problem can be solved in two ways. One can draw a tree diagram that delineates each possible path from one time period to the next until the end of the planning horizon, and then calculate the discounted total cost associated with each path. In this example, however, more than 5,000 paths are possible, which makes the tree diagram analysis impractical.¹ Another possibility to solving such an optimization problem is to use a method such as the method of conjugate gradients by Fletcher and Reeves (1964).² Briefly stated, the algorithm is as follows:

+   1. Arbitrarily choose a vector \overline{\mathbf{X}}_0 which serves as an initial guess for the vector \overline{\mathbf{X}} that optimizes the function.
+   2. Find \overline{g}_0 = g(\overline{\mathbf{X}}_0), the gradient vector of the objective function at \overline{\mathbf{X}}_0. Let \overline{P}_0 = -\overline{g}_0 be the initial search direction.
+   3. Let \overline{\mathbf{X}}_{i+1} = the position of the minimum of the objective function f(x) on the line through \overline{x}_i in the initial direction of \overline{p}_i.
+   4. If ||\overline{\mathbf{X}}_{i+1} - \overline{\mathbf{X}}_i|| is less than \varepsilon, a small number, terminate the process. The optimum is \overline{\mathbf{X}}_{i+1}. If ||\overline{\mathbf{X}}_{i+1} - \overline{\mathbf{X}}_i|| > \varepsilon, go to the next step.
+   5. Find \overline{g}_{i+1} = \overline{g}(\overline{\mathbf{X}}_{i+1}), the gradient vector at \overline{\mathbf{X}}_{i+1}. Calculate \beta_i = \frac{g_{i+1}^{(T)}(g_{i+1})}{g_i^{(T)}(g_i)} where T represents the transpose of the vector.
+   6. Now \overline{p}_{i+1} = -\overline{g}_{i+1} + \beta_i \overline{p}_i is the new search direction. Go to step (3) and repeat to step (6).

Note that step (3) is a simple one-dimensional optimization problem that can be solved by such methods as the Golden section method or quadratic interpolation, etc. (Belegunda and Chandrupatla, 2011; Fox, 1971; Pozrikidis, 1999; Wilde and Beightler, 1967).
