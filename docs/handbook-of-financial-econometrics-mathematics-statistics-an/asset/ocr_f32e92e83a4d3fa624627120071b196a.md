# 118.4.3 Local polynomial regression

Define Y_i = {Y_i1, Y_i2, ..., Y_iJ}' and Y = {Y_1', ..., Y_n'}', and, analogously, define X_i, X and u_i, u. In addition, define f_i = {f(X_i1), ..., f(X_nJ)}'. In this section, we focus on a univariate case in order keep notations concise, but estimators discussed here can be easily extended to higher dimensional models. The covariance structure of the observations on individual i is var(Y_i|X_i) = Σ = {σ_jk}_{j,k=1}^J where σ_jj = σ_ε^2 + σ_α^2 and σ_jk = σ_α^2 for j ≠ k.

The standard local polynomial regression aims at the pth polynomial expansion of the regression function at a local point, f(x) = G_p(X - x)'β, where G_p(v) = {1, v, ..., v^p}' and β = {β_0, ..., β_p}' is a vector of Taylor expansion parameters. Let h denote the bandwidth and K(·) a symmetric kernel density function. Define K_h(v) = h^{-1}K(v/h) and G_ip(x) = {G_p(X_i1 - x), G_p(X_i2 - x), ..., G_p(X_iJ - x)}. Martins-Filho and Yao (2009) suggest, in local polynomial regression, one can ignore the covariance structure without losing efficiency, i.e., m(x) can be estimated by β̂_0 where β̃ = {β̃_0, β̃_1, ..., β̃_p}' minimizes the weighted sum of squared residuals,

```
min_{tilde beta} sum_{i=1}^n (Y_i - [G_{ip}(x)]' tilde beta)' K_{ih}(x) (Y_i - [G_{ip}(x)]' tilde beta), (118.3)
```

where K_{ih}(x) = diag{K_h(x_{ij} - x)}_{j=1}^J is known as the kernel function. The kernel function K(·) determines the weight that observation i receives in estimating the value of y at target point x. There are many choices for the kernel function, including a Gaussian density function, and a tri-cube kernel function. These functions generally share the common feature of declining weights as distance increases. In general, the choice of kernel weight function has little effect on the results.

By limiting the Taylor expansion to degree of one, the local polynomial regression estimator as described in equation (118.3) can be simplified to local linear regression, also known as standard weighted least squares estimation with one regression to each target point. Denote G_{i1} = (1, X_i)', then one can define weighted least squares estimator as

```
hat beta(x) = e_1' [ sum_{i=1}^n G_{i1} K_{ih} [G_{i1}]' ]^{-1} sum_{i=1}^n G_{i1} K_{ih} Y_i, (118.4)
```

which can be calculated as the vector of coefficients from a regression of w_{it} Y_{it} on w_{it} and w_{it} X_{it}, where w_{it} = [K((X_{it} - x)/h)]^{1/2}.
