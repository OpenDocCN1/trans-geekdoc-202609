Finally, the authors propose and implement maximum likelihood estimation techniques to obtain parameters for the joint system of unobservable (latent) state variables and observable (macroeconomic) state variables. The authors note the need in being able to find good initial conditions in order to achieve convergence of their algorithm as it is a highly nonlinear system. Indeed, they propose a very specific algorithm that is arguably path-dependent. Although model estimation did yield cross-sectional model fits that were remarkably close to the actual data, a researcher attempting to estimate the model with no initial hunch regarding starting conditions for the maximum likelihood estimation algorithm would find estimating this model to be frustrating, time consuming, and computationally burdensome.

Collin-Dufresne, Goldstein, and Jones (2008) develop a representation of affine models that allows state variables to be estimated using PCA in a manner that is similar to the “inversion” method described above. Instead of assuming three bonds are measured perfectly, the authors take the state variables to be the first three principal components of the yield curve and assume these are measured without error. In order to employ maximum likelihood estimation of the model in the ℚ-measure, the researcher would take additional N yields to be measured with error. Since it is specified in the ℚ-measure, one can only produce in-sample cross-sectional model fits with this method as time-series information and the 𝕡-measure are needed to be able to provide out-of-sample predictions of yield curve behavior.

Arguably, the major advance in this literature has been the development of the Joslin, Singleton, and Zhu (2011a) normalization (hereafter, JSZ) in which factors are taken to be portfolios of yields. JSZ apply invariant transformations (e.g., see Dai and Singleton, 2000) to the process involving the latent factors written as a vector autoregressive specification of the first order to one which is expressed in terms of a portfolio of bond yields (such as the first three principal components). Joslin, Le, and Singleton (2013a) (hereafter, JLS) provide an extension to the JSZ framework that accounts for macroeconomic dynamics in addition to being able to describe the evolution of the factors as bond portfolios. One of the main estimation advantages of the JSZ (and by extension JLS) framework is that the majority of the parameters can be estimated via linear regressions and this greatly simplifies the computational burden of the estimation and time for completion for locating the global optimum of the maximum likelihood function describing the dynamics of the model.
