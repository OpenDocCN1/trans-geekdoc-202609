From the matrix calculation of Index Model, we can get the optimal weights from multiplying $A^{-1}$ and $K$.

$$\begin{bmatrix}X_1\\X_2\\X_3\\X_4\\\lambda_1\\\lambda_2\end{bmatrix}=\begin{bmatrix}-2\sigma_1^2&0&0&0&1&\beta_1\\0&-2\sigma_2^2&0&0&1&\beta_2\\0&0&-2\sigma_3^2&0&1&\beta_3\\0&0&0&-2\sigma_4^2&0&-1\\1&1&1&0&0&0\\\beta_1&\beta_2&\beta_3&-1&0&0\end{bmatrix}^{-1}\begin{bmatrix}-\Phi\alpha_1\\-\Phi\alpha_2\\-\Phi\alpha_3\\-\Phi\alpha_4\\1\\0\end{bmatrix}$$

$W$ denotes the weight vector, $A^{-1}$ denotes the inverse matrix, and $K$ denotes the right-hand-side vector.

Select a range from A175 to A180, type “=MMULT(A167:F172,H167:H172)” and press “Ctrl+Shift+Enter,” then we can get the optimal weight matrix $W$. The average return on optimal portfolio and the variance of optimal portfolio are calculated by the functions $\sum_{i=1}^{3}X_iR_i$ and $\sum_{i=1}^{3}\sum_{j=1}^{3}X_iX_j\operatorname{Cov}(R_i,R_j)$.
