# 58.4 VAR System with a Long Memory Property

As stated earlier, current studies of the downside risk–return relation pay insufficient attention to the impact of the long memory inherent in downside risk. The rationale for why we model downside risk as a long memory process stems from the tight connection between downside risk and volatility. As noted by Engle (2011), accurately estimating downside risk greatly depends on the prediction (or process) of volatility. The current literature has demonstrated that both realized volatility and risk-neutral volatility exhibit a long memory process (Bandi and Perron, 2006; Bollerslev et al., 2013; Christensen and Nielsen, 2007). It is natural to infer that the long memory property is embedded in the VaR estimation (Caporin, 2008; Kinateder and Wagner, 2014). Recognizing the importance of long memory for downside risk predictions and risk management, we explore the possibility that if the long-lasting effects of downside shocks on required excess returns are ignored, the parametric risk–return relations may be misspecified.

# 58.4.1 Long memory models

From an empirical perspective, long memory is shown to have a high degree of persistence in the observed data. In the time domain, long memory manifests itself as a hyperbolically decaying autocorrelation function. Granger and Ding (1996) demonstrate that long memory can arise from aggregation, time-changing coefficient models, and possibly nonlinear models. Banerjee and Urga (2005), Granger and Hyung (2004), Perron and Qu (2010) argue that the presence of structural breaks and regime switching can generate spurious long memory behavior. A short memory process is sometimes contaminated by occasional level shifts, and therefore, its autocovariance function exhibits a slow rate of decay, akin to a long memory process. Allowing for the joint occurrence of long memory and structural breaks, we apply the local Whittle test developed by Qu (2011) to test whether there is a spurious long memory in the estimates of downside risk.
