# 6.4.1 Simple average combination forecasting method

Combining the intervention analysis integrated into the ARIMA-GARCH model, ECM, and the intervention analysis integrated into transfer function model with the equal weight 0.333, the combination forecasting model is as follows:

$$\ln \hat{P}_c^s = 0.333 \ln \hat{P}_{t+i}^A + 0.333 \ln \hat{P}_{t+i}^E + 0.333 \ln \hat{P}_{t+i}^T, \tag{6.5}$$

where $\hat{P}_c^s$ is the value of the simple average combination forecasting method, $\hat{P}_{t+i}^A$ is the predicted value of the ARIMA-GARCH integrated into the intervention analysis model at $t + i$, and $\hat{P}_{t+i}^E$ is the predicted value of ECM at $t + i$, and $\hat{P}_{t+i}^T$ is the predicted value of the intervention analysis integrated into the transfer function model at $t + i$.
