# 46.3 Technical Preliminaries

In this chapter, we shall use discrete-state random variables and stochastic processes using the following notation (for simplicity, we assume that all mathematical objects exist and are well defined). The indicator function 1_A(x) of set A equals 1 if x ∈ A, and equals 0 if x ∉ A; similarly, the complementary indicator function is 1̄_A(x) = 1 − 1_A(x). For any random variable X, we denote its cumulative distribution function (cdf) by F_X(x) = Pr{X ≤ x} and its density by f_X(x); for a discrete-state X, the density is the probability mass function (pmf) f_X(x) = Pr{X = x}, while for a continuous-state X, it is the probability density function (pdf) f_X(x) = d/dx F_X(x).

Next, we clarify the two fundamental concepts that underpin the ERA approach: equilibrium and rate. In this chapter, we shall use the term equilibrium interchangeably with the terms stationary, invariant and steady state. Recall that a system is said to be in equilibrium if the probability law (distribution) of its state process is time invariant.² Stochastic systems may or may not have an equilibrium regime, but if they do, they might have multiple ones depending on their initial state distribution; if they evolve into equilibrium, such systems are said to have a conditional long-run distribution, obtained as a limiting equilibrium distribution. Mathematically, many stochastic systems converge to equilibrium (in distribution) as time tends to infinity regardless of the initial state distribution, in which case they are said to have a (unique) long-run distribution.
