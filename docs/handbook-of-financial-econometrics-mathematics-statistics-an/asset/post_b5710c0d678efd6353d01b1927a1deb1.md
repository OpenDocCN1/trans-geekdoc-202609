
## Case 2: A > 1.

In this case, we search for an integer H in the range {0, …, B} that maximizes φ(A − H, H). To this end, consider three subcases.

### Case 2.1: π_C(0) ≥ (γ−α)/β.

Then by Lemma 46.6, Δφ(A − H, H) is strictly decreasing in H with Δφ(A − 1, 1) ≤ 0 by equation (46.27), implying H* = 0 and G* = A.

### Case 2.2: π_C(0) < (γ−α)/β and there exists a minimal H′ ∈ {1, …, B}, such that Δφ(A − H′, H′) ≤ 0.

Then, H* = H′ − 1 by Lemma 46.6.

### Case 2.3: π_C(0) < (γ−α)/β and there does not exist H′ ∈ {1, …, B}, such that Δφ(A − H′, H′) ≤ 0.

Then, the maximum is obtained at the boundary where H* = B.

Finally, the first line of equation (46.28) follows by combining Cases 1 and 2.1, while the second line of equation (46.28) follows by combining Cases 2.2 and 2.3.

Theorem 46.4 comports with intuition concerning some special cases. For example, if the cost rate of investment capital, γ, exceeds the total cost rate of credit, α + β, then intuition suggests that the firm should allocate available funds to credit up to its allowed limit. Indeed, since γ > α + β implies (γ−α)/β > 1 ≥ Σ_{k=0}^{H−1} π_C(k) ≥ π_C(0), Theorem 46.4 shows that the maximal net profit rate, φ*, is attained at H* = B and G* = A − B. On the other hand, if the cost rate of investment capital, γ, does not exceed the fixed cost rate of credit, α, then intuition suggests that the firm should allocate all available funds to its own capital investment and none to credit. Indeed, since γ ≤ α implies π_C(0) > 0 ≥ (γ−α)/β, Theorem 46.4 shows that φ* is attained at H* = 0 and G* = A.

## 46.6.1.2 Optimization problem (B)

In this case, optimizing φ calls for a search on the decision variables triplet (S, G, H). However, the search can be structured to speed it up by reusing computed values of π as follows.

### Algorithm 46.2: (Search Procedure for the Optimal Net Profit Rate)

- 1. For each pair of S and A, compute π either analytically using Theorem 46.1 or numerically using Algorithm 46.1.
- 2. Given each π, derive the optimal values of G* and H* from Theorem 46.4. The corresponding value of φ is optimal for each given pair, (S, A).
- 3. Find the maximal value of φ over all pairs (S, A).

## 46.6.2 *Equilibrium rate of return*

The *equilibrium rate of return* is a function of the parameter triplet $(S, G, H)$, defined by

$$\rho(S,G,H)=\frac{\phi(S,G,H)}{G}$$ $$=\lambda[1-\pi_I(0)]\frac{\omega}{G}-\eta\frac{\sum_{n=1}^{S} n\pi_I(n)}{G}-\gamma-\alpha\frac{H}{G}$$ $$-\beta\frac{\sum_{k=0}^{H-1}(H-k)\pi_C(k)}{G}. \tag{46.30}$$

The interpretations of the terms on the right-hand side of equation (46.30) are analogous to their counterparts in equation (46.24).

Recall that the firm’s capital investment is $G>0$ PEMUs. Assume the minimal rate of return desired by investors is $\delta>0$. The investors may have better investment options if the rate of return is not higher than $\delta$. Therefore, one need only search the solution space of $(S,A)$ that gives rise to $\rho \ge \delta$. From equation (46.30) we have

$$\lambda[1-\pi_I(0)]\omega-\eta\sum_{n=1}^{S} n\pi_I(n)-\gamma G-\alpha H-\beta\sum_{k=0}^{H-1}(H-k)\pi_C(k)\ge\delta G$$ $$\Rightarrow \lambda\omega \ge (\gamma+\delta)G+\alpha H \ge \min\{\delta+\gamma,\alpha\}(G+H). \tag{46.31}$$

Consequently, the following bounds on $S$ and $A$ serve to reduce the search space:

$$S \le A = G + H \le \frac{\lambda\omega}{\min\{\delta+\gamma,\alpha\}}. \tag{46.32}$$

## 46.6.2.1 *Optimization problem (A)*

The treatment of this optimization problem is similar to its counterpart in Section 46.6.1.

**Lemma 46.7:** *The function $\Delta\rho(G,H)=\rho(G,H)-\rho(G+1,H-1)$ is given by* $$\Delta\rho(G,H)=\frac{\lambda[1-\pi_I(0)]\omega-\eta\sum_{n=1}^{S} n\pi_I(n)-\alpha A-\beta\sum_{k=0}^{H-1}(A-k)\pi_C(k)}{G(G+1)}, \tag{46.33}$$ *for any $A \ge 2$ and $1 \le H \le \mathcal{B}$, where $\rho(G,H)$ is the equilibrium rate of return defined in equation (46.30), given $S,A,\lambda,\mu,\nu,\omega,\eta,\gamma,\alpha,\beta,\ell$, and* $$\mathcal{B}=\min\left\{A-1,\left\lfloor\frac{\ell}{\ell+1}A\right\rfloor\right\}.$$

If there exists an integer 1 ≤ H' ≤ ℬ such that Δρ(A − H', H') ≤ 0, then Δρ(G, H) is strictly decreasing in H for H' ≤ H ≤ ℬ.

Proof. Similar to the proof of Lemma 46.6, we have for A ≥ 2 and 1 ≤ H ≤ ℬ,

Δρ(G, H) = ρ(G, H) − ρ(G + 1, H − 1) = [λ[1 − π_I(0)] ω/G − η Σ_{n=1}^S n π_I(n)/G − γ − α H/G − β Σ_{k=0}^{H−1} (H − k) π_C(k)/G] − [λ[1 − π_I(0)] ω/(G+1) − η Σ_{n=1}^S n π_I(n)/(G+1) − γ − α (H−1)/(G+1) − β Σ_{k=0}^{H−2} (H − k −1) π_C(k)/(G+1)] = [λ[1 − π_I(0)] ω − η Σ_{n=1}^S n π_I(n) − α A − β Σ_{k=0}^{H−1} (A − k) π_C(k)] / [G(G+1)].

If there exists an H' ∈ {1, …, ℬ} such that Δρ(A − H', H') ≤ 0, then it follows that Δρ(G, H) is strictly decreasing in H for H' ≤ H ≤ ℬ, since π_C(k) > 0 for 0 ≤ k ≤ A and G decreases as H increases.

## Theorem 46.5:

Given inventory base stock level S, rate parameters λ, μ, ν, and financial parameters ω, η, γ, α, β, ℓ, let G and H be any capital investment and credit limit parameters, respectively, such that their sum A = G+H is constant. Then, the equilibrium rate of return ρ of equation (46.30) is maximized at (G*, H*), where

H* = { 0, if A = 1 or π_C(0) ≥ [λ[1 − π_I(0)] ω − η Σ_{n=1}^S n π_I(n)]/(β A) − α/β ; max{ H : 1 ≤ H ≤ ℬ, Σ_{k=0}^{H−1} (A − k) π_C(k) < 1/β [ λ[1 − π_I(0)] ω − η Σ_{n=1}^S n π_I(n) − α A ] } , otherwise } (46.34) and G* = A − H* , (46.35) where ℬ = min { A − 1, ⌊ ℓ/(ℓ+1) A ⌋ } .

Proof. Similar to the proof of Theorem 46.4, we consider the following cases:

Case 1: A = 1. Then clearly H* = 0 and G* = A − H* = 1.

Case 2: A > 1. In this case, we search for an integer H in the range {0, …, B} that maximizes ρ(A−H, H). To this end, consider three sub-cases.

### Case 2.1:

π_C(0) ≥ [λ[1 − π_I(0)]ω − η Σ_{n=1}^S n π_I(n)] / (β A) − α/β.

Then by Lemma 46.7, Δρ(A−H, H) is strictly decreasing in H with Δρ(A−1,1) ≤ 0 by equation (46.33), implying H* = 0 and G* = A.

### Case 2.2:

π_C(0) < [λ[1 − π_I(0)]ω − η Σ_{n=1}^S n π_I(n)] / (β A) − α/β

and there exists a minimal H′ ∈ {1, …, B}, such that Δρ(A − H′, H′) ≤ 0. Then H* = H′ − 1 by Lemma 46.7.

### Case 2.3:

π_C(0) < [λ[1 − π_I(0)]ω − η Σ_{n=1}^S n π_I(n)] / (β A) − α/β

and there does not exist H′ ∈ {1, …, B}, such that Δρ(A − H′, H′) ≤ 0. Then, the maximum is obtained at the boundary where H* = B.

Finally, the first line of equation (46.34) follows by combining Cases 1 and 2.1, while the second line of equation (46.34) follows by combining Cases 2.2 and 2.3.

Theorem 46.5 implies that if A ≥ λ ω / α, then the firm’s rate of return is maximized by allocating all available funds to its own capital investment and none to credit (i.e., H* = 0 and G* = A).
