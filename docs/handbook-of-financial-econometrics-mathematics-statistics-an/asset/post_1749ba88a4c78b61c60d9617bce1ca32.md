We expand f(β̂, r̄) in a Taylor series around the expected values E(β̂) = β and E(r̄) = E(r) up to quadratic terms in the errors u and v and get

```
f(β̂, r̄) = f(β, E(r)) + (∇_β f) · u + (∇_r f) · v
+ ½ { u' H_ββ u + u' H_βr v + v' H_rβ u + v' H_rr v } + ⋯
```

with the Hessian matrix H_ββ containing the second-order derivatives with respect to β̂, H_βr and H_rβ containing the mixed derivatives and H_rr containing the second-order derivatives with respect to r̄. However, since f(β̂, r̄) is linear in r̄, this last term vanishes, H_rr = 0. Taking the expected value E[f(β̂, r̄)] not only the first-order terms vanish as well, but due to the independence of the errors u and v also both terms with mixed derivatives vanish. Since the errors u are (multivariate) normally distributed the Taylor series converges if the errors are sufficiently small, i.e., if the variance of the errors u is small compared to the variance of the true parameters β. We cut off the series after the second-order term and get

```
E[f(β̂, r̄)] ≈ f(β, E(r)) + ½ E[u' H_ββ u].
```

For the second term, we have to find the second-order derivatives in the Hessian matrix $\boldsymbol{H}_{\hat{\beta}\hat{\beta}}$. The derivative of $f(\hat{\boldsymbol{\beta}}, \tilde{\mathbf{r}})$ with respect to $\hat{\beta}_i$ is

$$\frac{\partial f}{\partial \hat{\beta}_i} = \frac{1}{\boldsymbol{\beta}'\boldsymbol{\beta}} \tilde{r}_i - 2\frac{\hat{\boldsymbol{\beta}}'\tilde{\mathbf{r}}}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}\hat{\beta}_i.$$

The second order derivative of $f(\hat{\boldsymbol{\beta}}, \tilde{\mathbf{r}})$ with respect to $\hat{\beta}_i$ and $\hat{\beta}_j$ is

$$\frac{\partial f}{\partial \hat{\beta}_i \partial \hat{\beta}_j} = -2\frac{\hat{\boldsymbol{\beta}}'\tilde{\mathbf{r}}}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}\delta_{ij} - \frac{2}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}(\hat{\beta}_j\tilde{r}_i + \hat{\beta}_i\tilde{r}_j) + \frac{8\hat{\boldsymbol{\beta}}'\tilde{\mathbf{r}}}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}\frac{\hat{\beta}_i\hat{\beta}_j}{\boldsymbol{\beta}'\boldsymbol{\beta}},$$

where $\delta_{ij}=1$ if $i=j$ and zero otherwise. Evaluating the second-order derivatives at the point $\hat{\boldsymbol{\beta}}=\boldsymbol{\beta}$ and $\tilde{\mathbf{r}}=E(\mathbf{r})$, we find the matrix elements of the Hessian matrix:

$$\{\boldsymbol{H}_{\hat{\beta}\hat{\beta}}\}_{ij} = \left.\frac{\partial^2 f}{\partial \hat{\beta}_i \partial \hat{\beta}_j}\right|_{\substack{\hat{\beta}=\beta \\ \tilde{\mathbf{r}}=E(\mathbf{r})}} = -2\gamma_1\frac{\delta_{ij}}{\boldsymbol{\beta}'\boldsymbol{\beta}} + 4\gamma_1\frac{(\beta_i-\bar{\beta})(\beta_j-\bar{\beta})}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2},$$

where we used $E(r_i)-\overline{E(r)} = \gamma_1(\beta_i-\bar{\beta})$ and $\boldsymbol{\beta}'E(\mathbf{r})/\boldsymbol{\beta}'\boldsymbol{\beta} = \gamma_1$. In matrix notation, we can write

$$\boldsymbol{H}_{\hat{\beta}\hat{\beta}} = -2\gamma_1\frac{1}{\boldsymbol{\beta}'\boldsymbol{\beta}}\mathbf{I} + 4\gamma_1\frac{1}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}\boldsymbol{\beta}\boldsymbol{\beta}',$$

where $\mathbf{I}$ is the identity matrix and $\boldsymbol{\beta}\boldsymbol{\beta}'$ is the matrix created by multiplication of the column vector $\boldsymbol{\beta}$ with the row vector $\boldsymbol{\beta}'$ (outer product).

We finally arrive at the approximation of the expected value of the slope estimator:

$$E[\hat{\gamma}_1] \approx \gamma_1\left(1 - \frac{E[\mathbf{u}'\mathbf{u}]}{\boldsymbol{\beta}'\boldsymbol{\beta}} + 2\frac{\boldsymbol{\beta}'E[\mathbf{u}\mathbf{u}']\boldsymbol{\beta}}{(\boldsymbol{\beta}'\boldsymbol{\beta})^2}\right).$$

Note that in the second term, we used the fact that we can rearrange

$$\mathbf{u}'\boldsymbol{\beta}\boldsymbol{\beta}'\mathbf{u} = \sum_{ij}(\beta_i-\bar{\beta})(\beta_j-\bar{\beta})(u_i-\bar{u})(u_j-\bar{u}) = \boldsymbol{\beta}'\mathbf{u}\mathbf{u}'\boldsymbol{\beta}.$$

The expected value $E[\mathbf{u}'\mathbf{u}]$ is a scalar:

$$E[\mathbf{u}'\mathbf{u}] = E\left[\sum_{i=1}^N (u_i-\bar{u})^2\right] = E\left[\frac{N-1}{N}\sum_{i=1}^N u_i^2 - \frac{1}{N}\sum_{\substack{i,j=1 \\ i\neq j}}^N u_i u_j\right]$$

The variance of the measurement errors is

$$\sigma_u^2 = \frac{1}{T\sigma_f^2}\left\{\frac{1}{N}\sum_{i=1}^N \sigma^2 - \frac{1}{N(N-1)}\sum_{\substack{i,j=1\\i\neq j}}^N \rho\sigma^2\right\} = \frac{1}{T\sigma_f^2}\sigma^2(1-\rho).$$

To evaluate the Rayleigh quotient (98.11), we first write the covariance matrix of the measurement errors (98.5) as

$$\Sigma_u = \frac{1}{T\sigma_f^2}\Sigma = \frac{1}{T\sigma_f^2}\{\sigma^2\mathbf{I} + \rho\sigma^2(\mathbf{J}-\mathbf{I})\},$$

where $\mathbf{I}$ is the identity matrix and $\mathbf{J}$ is the matrix of ones. Since $\boldsymbol{\beta} = (\beta_1 - \bar\beta, \dots, \beta_N - \bar\beta)$ is a centered vector, we have $\boldsymbol{\beta}'\mathbf{J}\boldsymbol{\beta}=0$ and hence,

$$\boldsymbol{\beta}'\Sigma_u\boldsymbol{\beta} = \frac{\sigma^2\boldsymbol{\beta}'\boldsymbol{\beta}}{T\sigma_f^2}\{1-\rho\},$$

so that the Rayleigh quotient (98.11) becomes

$$W_\Sigma = \frac{\boldsymbol{\beta}'\Sigma_u\boldsymbol{\beta}}{\boldsymbol{\beta}'\boldsymbol{\beta}} = \frac{1}{T\sigma_f^2}\sigma^2(1-\rho).$$

Finally, plugging in the above-derived expressions for $\sigma_u^2$ and $W_\Sigma$ into (98.12), we get the following for the relative bias of the slope estimator:

$$\frac{E(\hat\gamma_1)-\gamma_1}{\gamma_1} \approx -\frac{\sigma_u^2}{\sigma_\beta^2} + \frac{2}{(N-1)}\frac{W_\Sigma}{\sigma_\beta^2} = -\frac{1}{T\sigma_f^2}\frac{\sigma^2(1-\rho)}{\sigma_\beta^2}\left\{1 - \frac{2}{(N-1)}\right\}.$$

## Appendix 98C: Expansion of the Slope Estimator of Richardson and Wu

Here, we expand the expression for the bias in the slope estimator (98.16) as given by Richardson and Wu (1970) to lowest order in the ratio of the measurement error $\sigma^2/T\sigma_f^2$ (the noise) to the variance of the true parameters $\sigma_\beta^2$ (the signal). Keeping in (98.16) only terms up to order $1/(N-1)$, we have

$$\frac{E(\hat\gamma_1)-\gamma_1}{\gamma_1} \approx -\frac{1}{1+\tau}\left[1 - \frac{2}{N-1}\frac{\tau^2}{(1+\tau)^2}\right],$$

where $1/\tau = \sigma^2/(T\sigma_f^2\sigma_\beta^2)$. To expand this expression in orders of $1/\tau$, we first rewrite it:

$$\frac{E(\hat\gamma_1)-\gamma_1}{\gamma_1} \approx -\frac{1}{\tau}\cdot\frac{1}{1+1/\tau}\left[1 - \frac{2}{N-1}\frac{1}{(1+1/\tau)^2}\right].$$

Keeping only terms of lowest order in 1/τ yields

$$\frac{E(\hat{\gamma}_1)-\gamma_1}{\gamma_1} \approx -\frac{1}{\tau}\left[1-\frac{2}{N-1}\right] = -\frac{\sigma^2}{T\sigma_f^2\sigma_\beta^2}\left[1-\frac{2}{N-1}\right],$$

which exactly reproduces our equation (98.15).

## Appendix 98D: From Idiosyncratic Errors to Measurement Errors

Here, we give the details of the derivation of the covariance matrix of the measurement errors (98.5). The OLS slope estimator $\hat{\beta}_i$ of the time-series regression (98.2) can be written, cf. (98.4):

$$\hat{\beta}_i = \beta_i + u_i,$$

with the measurement error term

$$u_i = \frac{\sum_t f_t \varepsilon_{it} - \frac{1}{T}\sum_t f_t \sum_t \varepsilon_{it}}{\sum_t f_t^2 - \frac{1}{T}(\sum_t f_t)^2},$$

where the summations are over times $t = 1, \dots, T$. Since the expected value of the idiosyncratic errors $\varepsilon_{it}$ is zero and idiosyncratic errors and factors are assumed to be uncorrelated, it is immediately obvious that, given the factors $f_t$, the expected value of the measurement errors $u_i$ is zero, so that we have $E(u_i)=0$ and $\mathrm{Cov}(u_i, u_j)=E(u_i u_j)$.

We expand as follows:

$$u_i u_j = \frac{(\sum_t f_t \varepsilon_{it} - \frac{1}{T}\sum_t f_t \sum_t \varepsilon_{it})(\sum_t f_t \varepsilon_{jt} - \frac{1}{T}\sum_t f_t \sum_t \varepsilon_{jt})}{(\sum_t f_t^2 - \frac{1}{T}(\sum_t f_t)^2)^2}$$

Given the factors $f_t$, the only random variables in this expression are the residuals $\varepsilon_{it}$. In addition, according to our assumption (98.3), the residuals are i.i.d. over time with covariance structure:

$$E(\varepsilon_{it}\varepsilon_{jt'}) = \begin{cases} \sigma_{ij} & \text{if } t = t' \\ 0 & \text{otherwise.} \end{cases}$$
