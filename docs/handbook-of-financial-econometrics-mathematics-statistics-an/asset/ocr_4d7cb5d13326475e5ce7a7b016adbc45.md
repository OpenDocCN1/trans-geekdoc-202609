It is clear that the LS results, ĉ_i = 1.472 + 0.823 y_i, are very different from the IV results (see Table 28.6 with the DWH statistics for an easy comparison), and if the instruments are valid (i.e., correlated with the explanatory variable but not with the error), the IV estimator will provide consistent parameter estimates. A number of variations of a test for contemporaneous correlation can now be carried out.

In order to use LS to estimate the model, we specify X independent of e. If X is not independent of e we use IV to obtain consistent parameter estimates. The specific null and alternative hypotheses are

H_LS : X is independent of e.
H_IV : X is not independent of e.
