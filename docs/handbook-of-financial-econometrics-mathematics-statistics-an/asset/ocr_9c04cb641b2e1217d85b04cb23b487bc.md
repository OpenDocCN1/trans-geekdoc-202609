The solution procedure systematically identifies a fuzzy optimal selection of possible transfer prices that cannot only reach the best-compromised value for the multiple criteria, but also use the best price range according to the multiple decision makers’ preferences. In comparison with the AHP approach of Kwak et al. (1996), the fuzzy set approach does not have to elicit weights of importance for both multiple criteria and multiple DMs’ preferences. Furthermore, the fuzzy set approach is easier for a firm to apply because it can be implemented by using any available commercial computer software that solves linear programming problems. Fuzzy set theory has been applied in several business contexts. For example, Wu and Tsai (2014) applied fuzzy goal programming for index portfolios. They propose imprecise goals of decision makers in the real world can be reflected better with a fuzzy set theory. Stango and Zinman (2011) applied a fuzzy set in lending context and Yan (2011) also applied a fuzzy set for reward sharing in a bargaining model.

# # 54.2 Existing Transfer Pricing Methods

Generally, transfer pricing problems can be determined based on three factors: (i) is there a similar product available in the market? If so, the best transfer price is market-based pricing. If not, cost or negotiated pricing should be used; (ii) is the variable cost of the seller less than the market price? If not, the seller does not operate efficiently, and the buyer should buy from outside; and (iii) is the selling unit operating at full capacity? If not, the selling division should provide for the internal buyer and the transfer price should fall somewhere between variable cost and market price from top management’s points of view. These guidelines generally provide motivation for divisional managers as well as overall company strategic perspectives.
