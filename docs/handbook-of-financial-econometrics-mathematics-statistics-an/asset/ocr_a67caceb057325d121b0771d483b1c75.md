$$P = C + X e^{-rT} - S e^{-qT}. \tag{106.63}$$

Let $X e^{-rT} = K$ and let $S e^{-qT} = S'$, then we have following equation:

$$P = C + K - S'. \tag{106.64}$$

Substituting equation (106.60) into equation (106.64), we obtain following equation:

$$P = (K - S')/2 + \frac{\ln(S'/K)}{\sigma\sqrt{2\pi T}}\big[(S' - K)(1 + [\ln(S'/K)/4]^2) - \ln(S'/K)(S' + K)/4\big] + \frac{\sigma\sqrt{T}}{2\sqrt{2\pi}} \times [S' + K - \ln(S'/K)(S' - K)/4]. \tag{106.65}$$

Equation (106.65) is also a quadratic equation of $\sigma\sqrt{T}$ and can be rewritten as

$$\sigma^2 T[8(S' + K) - 2(S' - K)\ln(S'/K)] - 8\sigma\sqrt{T}\sqrt{2\pi}(2P - K + S') + \ln(S'/K)[(S' - K)(16 + (\ln(S'/K))^2) - 4(S' + K)\ln(S'/K)] = 0. \tag{106.66}$$

Solving $\sigma\sqrt{T}$ from equation (106.66) yields

$$\sigma\sqrt{T} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}, \tag{106.67}$$

where $a = 8(S' + K) - 2(S' - K)\ln(S'/K)$, $b = -8\sqrt{2\pi}(2P - K + S')$, $c = \ln(S'/K)[(S' - K)(16 + \ln(S'/K)^2)] - 4(S' + K)\ln(S'/K)$.

We rearrange equation (106.61) in terms of $S'$, then we obtain equation (106.68):

$$[8\sigma^2 T + 8\sigma\sqrt{2\pi T} + 2\sigma^2 T \ln K - 16 \ln K - 4(\ln K)^2 - (\ln K)^3]S' + [2\sigma^2 T K - 16K + 8K \ln K - 3K(\ln K)^2]\ln S' + [16 - 2\sigma^2 T + 8 \ln K + 3(\ln K)^2]S'\ln S' + (3K \ln K - 4K)(\ln S')^2 - (3 \ln K + 4)S'(\ln S')^2 - K(\ln S')^3 + S'(\ln S')^3 = 16C\sigma\sqrt{2\pi T} + 8\sigma\sqrt{2\pi T}K - 8\sigma^2 T K + 2\sigma^2 T K \ln K - 16K \ln K + 4K(\ln K)^2 - K(\ln K)^3. \tag{106.68}$$

Equation (106.68) can be used to estimate $S'$ if we have the information of the other five variables. The solution of $S'$ can only be obtained by the trial-and-error method.
