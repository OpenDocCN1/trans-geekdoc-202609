= -\left( x\sqrt{npq} + x^2 q - \frac12 x^2 q - \frac{x^3 p^{-\frac12} q^{\frac32}}{2\sqrt{n}} + \frac{x^3 p^{-\frac12} q^{\frac32}}{3\sqrt{n}} \right) 
- \left( -x\sqrt{npq} + x^2 p - \frac12 x^2 q + \frac{x^3 p^{\frac32} q^{-\frac12}}{2\sqrt{n}} - \frac{x^3 p^{\frac32} q^{-\frac12}}{3\sqrt{n}} \right) + o(x^3)
= -\frac12 x^2(p+q) - \frac{1}{6\sqrt{npq}} x^3(p^2 - q^2) + o(x^3). \tag{102A.7}

Since we have $p + q = 1$ when we ignore the higher order of $x$, equation (102A.7) can be simply approximated to

-\frac12 x^2 - \frac{1}{6\sqrt{npq}} x^3(p - q). \tag{102A.8}

Then we replace equation (102A.8) in the exponential function in equation (102A.5), we obtain

\binom{n}{k} p^k q^{n-k} \simeq \frac{1}{\sqrt{2\pi pq}} \exp\left[ -\frac12 x^2 - \frac{1}{6\sqrt{npq}} x^3(p - q) \right]. \tag{102A.9}

Although term $-\frac{1}{6\sqrt{npq}}x^3(p-q) \to 0$ as $n \to \infty$, the term $-\frac{1}{6\sqrt{npq}}x^3(p-q)$ will be exactly zero if and only if $p = q$. Under this condition, $\binom{n}{k}p^k q^{n-k} \simeq \frac{1}{\sqrt{2\pi pq}} \exp(-\frac12 x^2) = \frac{1}{\sqrt{2\pi pq}} \exp[-(k-np)^2/(2npq)]$. Thus, it is shown that the best fit between the binomial and normal distribution occurs when $p = q = \frac12$.

If $p \neq q$, then there exists an additional term $-\frac{1}{6\sqrt{npq}}x^3(p - q)$. It is obvious that $\sqrt{pq} = \sqrt{p(1-p)}$ will reach maximum if and only if $p = q = \frac12$. Therefore, when $n$ is fixed, if the difference between $p$ and $q$ becomes larger, the absolute value of an additional term $-\frac{1}{6\sqrt{npq}}x^3(p - q)$ will be larger. This implies that the magnitude of absolute value of the difference between $p$ and $q$ is an important factor to make the approximation to normal distribution less precise.
