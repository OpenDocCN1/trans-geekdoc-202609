E_x[e^{-r(t∧τ)} φ(X_{τ∧t})] = φ(x). in Appendix 41A, we also prove that

E_x[e^{-r τ∧} φ(X_{τ∧t})] = E_x[∫_0^{τ∧t} e^{-ru} (L - r) φ(X_u) du] + φ(x). (41.11)

From these we get

E_x[∫_0^{τ∧t} e^{-ru} (L - r) φ(X_u) du] = 0. (41.12)

On the other hand, by Lemma 41.2.3,

E_x[ sup_{u<t<τ} | s e^{-ru} (L - r) φ(X_u) - (L - r) φ(X_0) | ] → 0, t ↓ 0+. (41.13)

Therefore, by (41.13), we obtain

|(L - r) φ(x)| = | 1/t E_x[ ∫_0^{τ∧t} e^{-ru} (L - r) φ(X_u) du ] - (L - r) φ(x) | ≤ E_x[ sup_{u<t<τ} | s e^{-ru} (L - r) φ(X_u) - (L - r) φ(X_0) | ] + | (L - r) φ(x) E_x[ t - τ∧t ] / t |.

Note that τ > 0 P_x-a.s. and hence t - τ∧t = 0 for all sufficiently small t. Since further 0 ≤ (t - τ∧t)/t ≤ 2, we have E_x[ (t - τ∧t)/t ] → 0 and t → 0+. Together with (41.13) and the last inequality, we establish that

|(L - r) φ(x)| ≤ lim sup_{t→0+} | 1/t E_x[ ∫_0^{τ∧t} e^{-ru} (L - r) φ(X_u) du ] - (L - r) φ(x) | = 0.

The proof is complete.
