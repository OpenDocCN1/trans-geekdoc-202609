where |Σ| is the determinant of Σ and ξ = (ξ₁, …, ξₙ)′. Note that ξᵢ is the uᵢ quantile of the standard normal random variable Xᵢ:

$$u_i = P(X_i < \xi_i), \quad X_i \sim N(0,1), \quad i = 1,\dots,n. \tag{73.8}$$

An elliptical copula is a function of (u₁, …, uₙ) and not a function of (ξ₁, …, ξₙ). Due to this, the elliptical copulas are considered as implicit copulas. Since ξ = (φ⁻¹(u₁), …, φ⁻¹(uₙ)), elliptical copulas are built by using inversion method. Using this method, the bivariate Gaussian copula function is given by

$$c(u_1, u_2;\varrho) = (1 - \varrho^2)^{-(1/2)} \exp\left(-\frac{\varrho^2 \xi_1^2 - 2\varrho \xi_1 \xi_2 + \varrho^2 \xi_2^2}{2(1 - \varrho^2)}\right), \tag{73.9}$$

where ρ is the correlation coefficient between the two variables (see Appendix 73B for details).

The Student’s t copula is derived from the multivariate (tᵥ) and univariate (tᵥ) Student’s t-distribution functions with v degrees of freedom:

$$C_v(u_1, \dots, u_n; \Sigma) = t_v\big(t_v^{-1}(u_1), \dots, t_v^{-1}(u_n)\big). \tag{73.10}$$

The bivariate Student’s t copula density function is

$$c(u_1, u_2;\varrho) = K(1 - \varrho^2)^{-(1/2)} \big[1 + v^{-1}(1 - \varrho^2)^{-1}(\xi_1^2 - 2\varrho \xi_1 \xi_2 + \xi_2^2)\big]^{-(v+2)/2} \cdot \big[(1 + v^{-1}\xi_1^2)(1 + v^{-1}\xi_2^2)\big]^{(v+1)/2}, \tag{73.11}$$

where ξ₁ = tᵥ⁻¹(u₁) and ξ₂ = tᵥ⁻¹(u₂) are realizations of the Student’s t variables, and K is a constant, K = Γ(v/2)·Γ((v+1)/2)⁻²·Γ((v+2)/2) (see Appendix 73B for details).
