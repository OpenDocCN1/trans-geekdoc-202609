In FDA, a set of $r$ linear combinations of the observable variables $\boldsymbol{X} = (X_1, \dots, X_p)'$, or discriminant functions $D_1 = \boldsymbol{\theta}_1' \boldsymbol{X}, \dots, D_r = \boldsymbol{\theta}_r' \boldsymbol{X}, r \le \min(K-1,p)$, where the coefficient vectors $\boldsymbol{\theta}_1 = \Sigma^{-1/2} \boldsymbol{\xi}_1, \dots, \boldsymbol{\theta}_r = \Sigma^{-1/2} \boldsymbol{\xi}_r$ are determined sequentially as follows. Given the first $i-1$ coefficient vectors $\boldsymbol{\theta}_1, \dots, \boldsymbol{\theta}_{i-1}, i \le r$, the $i$th coefficient vector $\boldsymbol{\theta}_i$ is obtained by choosing $\boldsymbol{\xi}_i$ that maximizes the ratio comparing the variability between the groups to that within the groups subject to the constraints $\boldsymbol{\xi}_i' \boldsymbol{\xi}_i = 1$ and $\boldsymbol{\xi}_i' \boldsymbol{\xi}_j = 0$ for all $j < i$. That is, the vector $\boldsymbol{\xi}_i$ maximizes the objective function

$g_1(\boldsymbol{\xi}_i) = \boldsymbol{\xi}_i' A \boldsymbol{\xi}_i, \qquad (57.1)$

subject to the constraints $\boldsymbol{\xi}_i' \boldsymbol{\xi}_i = 1$ and $\boldsymbol{\xi}_i' \boldsymbol{\xi}_j = 0$ for all $j < i$, where the $p \times p$ positive-definite matrix

$A = \Sigma^{-1/2} \left( \sum_{j=1}^K w_j (\boldsymbol{\mu}_j - \bar{\boldsymbol{\mu}})(\boldsymbol{\mu}_j - \bar{\boldsymbol{\mu}})' \right)^{-1/2} \Sigma, \qquad (57.2)$

Here, $\bar{\boldsymbol{\mu}} = \sum_{i=1}^K w_i \boldsymbol{\mu}_i$ is the overall mean and $\Sigma$ is the common $p \times p$ variance-covariance matrix of the $K$ populations. ## 57.2.2 Principal component analysis: Maximization of explanatory power

Principal component analysis (e.g., see Johnson and Wichern, 2002) is employed for dimensionality reduction, i.e., for transforming a number $p$ of possibly correlated observable variables $\boldsymbol{X} = (X_1, \dots, X_p)'$ into a smaller number $u$, $u < p$, of uncorrelated variables $Y_1, \dots, Y_u$ called principal components to account for as much variability, or the explanatory power, as possible. Like FDA, a set of linear combinations of the observable variables $\boldsymbol{X}$, or principal components $Y_1 = \varphi_1' \boldsymbol{X}, \dots, Y_u = \varphi_u' \boldsymbol{X}$, are determined sequentially that given the first $i-1$ principal components, $i \le u$, the $i$th principal component $Y_i$ is determined by choosing $\boldsymbol{\varphi}_i$ that maximizes the

explanatory power, or the variance, of $Y_i$, i.e.,

$$\operatorname{var}(Y_i) = \varphi'_i \Xi \varphi_i, \tag{57.3}$$

subject to the constraints $\varphi'_i \varphi_j = 0$ for all $j < i$ and $\varphi'_i \varphi_i = 1$, where $\Xi$ is the overall variance–covariance matrix

$$\Xi = \Sigma + \sum_{i=1}^{K} w_i (\boldsymbol{\mu}_i - \bar{\boldsymbol{\mu}})(\boldsymbol{\mu}_i - \bar{\boldsymbol{\mu}})'.$$

To be compatible with FDA, the constraints $\varphi'_i \varphi_j = 0$ for all $j < i$ and $\varphi'_i \varphi_i = 1$ are relaxed and let $\varphi_i = \Sigma^{-1/2} \xi_i$, $i \le u$, where the vector $\xi_i$ satisfies the constraints that $\xi'_i \xi_i = 1$ and $\xi'_i \xi_j = 0$ for all $j < i$. The explanatory power of $Y_i$ in (57.3) becomes

$$\operatorname{var}(Y_i) = \xi'_i \Sigma^{-1/2} \Xi \Sigma^{-1/2} \xi_i. \tag{57.4}$$

As the norm $\varphi'_i \varphi_i = \xi'_i \Sigma^{-1} \xi_i$ is not restricted to one, to be compatible with (57.3) where the maximization is restricted to the domain $\{\varphi_i : \varphi'_i \varphi_i = 1\}$, we consider an objective function $g_2$ that represents the normalized explanatory power of $Y_i$ as follows:

$$g_2(\xi_i) = \frac{\xi'_i \Sigma^{-1/2} \Xi \Sigma^{-1/2} \xi_i}{\xi'_i \Sigma^{-1} \xi_i}. \tag{57.5}$$

## 57.2.3 Two conflicting objectives

Suppose the first $i-1$ linear discriminant component's $M_1 = \xi'_1 \Sigma^{-1/2} \boldsymbol{X}, \dots,$ $M_{i-1} = \xi'_{i-1} \Sigma^{-1/2} \boldsymbol{X}$ are determined, the $i$th linear discriminant function $M_i = \xi'_i \Sigma^{-1/2} \boldsymbol{X}$ is extracted so that its discriminant as well as explanatory power are as large as possible subject to the constraints $\xi'_i \xi_i = 1$ and $\xi'_i \xi_j = 0$ for all $j < i$. That is, the $i$th linear discriminant function $M_i = \xi'_i \Sigma^{-1/2} X$ is extracted so that the two objective functions $g_1(\xi_i)$ and $g_2(\xi_i)$ in (57.1) and (57.5), respectively, can be maximized simultaneously subject to the constraints $\xi'_i \xi_i = 1$ and $\xi'_i \xi_j = 0$ for all $j < i$. ## 57.3 Hybrid of Principal Component and Fisher’s Discriminant Analysis Using Goal Programming

The goal programming (GP) technique, a multi-objective optimization approach, introduced by Charnes et al., (1955), was later developed in the seminal works by Lee (1972), Ignizio (1976), Ignizio et al. (1994, 2003), and Romero (1991). The large number of goal programming applications in many diverse fields are accounted by Jones and Tamiz (2002). Depending on the nature of the problem, several classes of goal programming can be obtained, including weighted goal programming, lexicographic goal programming, and MINIMAX goal programming (e.g., see Ignizio and Romero, 2003; Tamiz and Jones, 1996; Tamiz et al., 1998). In case a balance between the levels of satisfaction of goals is desired, the MINIMAX goal programming technique by Flavell (1976) is adopted. In this study, as a balance between sufficient discriminant power as well as explanatory power is desired, the MINIMAX goal programming technique is considered.
