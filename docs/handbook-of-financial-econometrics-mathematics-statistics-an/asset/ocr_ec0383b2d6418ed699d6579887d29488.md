2   $\frac{dL}{dW_2}=0,$
$\vdots$      $\vdots$
$n$   $\frac{dL}{dW_n}=0.$

From Appendix 82A, the $n$ simultaneous equations used to solve $H_i$ are

$\bar{R}_1 - R_f = H_1\sigma_1^2 + H_2\sigma_{12} + H_3\sigma_{13} + \cdots + H_n\sigma_{1n},$ 
$\bar{R}_2 - R_f = H_1\sigma_{12} + H_2\sigma_2^2 + H_3\sigma_{23} + \cdots + H_n\sigma_{2n},$ 
$\vdots$ 
$\bar{R}_m - R_f = H_1\sigma_{1n} + H_2\sigma_{2n} + H_3\sigma_{3n} + \cdots + H_n\sigma_n^2,$  (82.6a)

where

$H_i = kW_i \quad (i = 1,2,\ldots,n),$ 
$k = -\dfrac{\bar{R}_p - R_f}{\sigma_p^2}.$

$H_S$ is proportional to the optimum portfolio weight $W_i$ ($i = 1,2,\ldots,n$) by a constant factor $K$. To determine the optimum weight $W_i$, $H_i$ is first solved from the set of equations indicated in equation (82.6). Having done so, $H_i$ must be called to calculate $W_i$, as indicated in equation (82.7).

$W_i = \dfrac{H_i}{\sum_{i=1}^n H_i}.$  (82.7)

If there are only three securities, then equation (82.6a) reduces to

$\bar{R}_1 - R_f = H_1\sigma_1^2 + H_2\sigma_{12} + H_3\sigma_{13},$ 
$\bar{R}_2 - R_f = H_1\sigma_{12} + H_2\sigma_2^2 + H_3\sigma_{23},$ 
$\bar{R}_3 - R_f = H_1\sigma_{13} + H_2\sigma_{23} + H_3\sigma_3^2.$  (82.6b)
