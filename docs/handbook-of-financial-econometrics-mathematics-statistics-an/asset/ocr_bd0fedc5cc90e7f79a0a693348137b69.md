As their model incorporates several different components, it is estimated in several steps each of which we explain in the following. The first step involves the extraction of the macroeconomic variables and these are obtained from PCA in the following manner. We gather data on two groups of measures; inflation and real economic activity. We include in the first group CPI, the PPI of finished goods, and spot commodity prices. The second group of variables includes the index of help wanted advertising in newspapers, unemployment rate, the growth rate of employment, and the growth rate of industrial production. Then, we compute the first principal component from each of these two groups for inclusion as our macroeconomic variables, and so this means that $K_1 = 2$ in the estimation of this method. This vector is assumed to follow a Gaussian vector autoregressive process of order $p$:

$F_t = \Phi_0 + \Phi_1 F_{t-1} + \cdots + \Phi_p F_{t-p} + \theta u_t. \quad (61.4)$

In equation (61.4), $u_t \sim N(0,I)$. In order to simplify the estimation of the vector autoregressive process describing the state variables, the authors make a number of additional assumptions. We briefly describe them in the following. We use $x_t$ to describe the state of the economy and define it as a K by one vector, where, $K = K_1 p + K_2$, so with the assumption of three latent variables ($K_2 = 3$) and that we use p = 12 lags of real activity and inflation ($K_1 = 2$), $x_t$ is a 27 dimensional vector ($K = 2^*12 + 3 = 27$). Then, we partition $x_t$ into current and the 11 (p - 1) past lags of macroeconomic variables along with only contemporaneous latent factors and write $x_t = (x_t^{0T}, x_t^{uT})$ as

$x_t = \mu + \Phi x_{t-1} + \Sigma \varepsilon_t. \quad (61.5)$

We estimate the above Gaussian VAR dynamics by assuming independence across the error processes associated with macroeconomic variables $u_t^o$ and latent factors $u_t^u$, respectively, so that $\varepsilon_t = (u_t^{oT}, 0, \ldots, 0, u_t^{uT})^T$. In this system, $\mu$ is fixed to be a K-dimensional vector of zeros (please see the bottom of Table 6 on page 765 for detail) and $\Phi$ is a K $\times$ K matrix with the upper left $K_1 p \times K_1 p$ block containing coefficients corresponding to the macro factors and the lower-right $K_2 \times K_2$ corner is for the estimates of the latent factor coefficients. The remaining entries are zeros. Within this system above, we estimate the following bivariate process for the macro factors,

$f_t^o = \rho_1 f_{t-1}^o + \cdots + \rho_{12} f_{t-12}^o + \Omega u_t^o. \quad (61.6)$
