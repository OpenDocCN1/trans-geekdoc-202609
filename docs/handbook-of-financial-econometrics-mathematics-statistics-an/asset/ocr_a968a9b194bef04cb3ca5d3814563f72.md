Nevertheless, it is unrealistic to describe the asset price dynamics driven by a diffusion or jump-diffusion process with a continuous or piece-wise continuous sample path where the sum of absolute price movements during a finite time period is infinite. For this reason, a purely jump process in which the sum of absolute price movements during a finite time period is finite is considered in the literature.

# 70.2.1 GARCH-jump with autoregressive conditional jump intensity: GARJI model

Chan and Maheu (2002) proposed the GARCH-jump model with autoregressive conditional jump intensity (GARJI), in which the conditional variance of log-return innovations is divided into two separate components that are described by two conditionally independent autoregressive processes in a discrete-time setting. Let the trading period be partitioned into T subintervals (0, 1], (1, 2], ..., (T − 1, T], and ℱ_{t−1} be the information set at time t − 1. Consider the log-return Y_t = ln[S(t)/S(t − 1)], t = 1, ..., T, which is modeled as

```
Y_t = μ + ε_t. (70.1)
```

The innovation ε_t = ε_{1,t} + ε_{2,t} is decomposed to two independent components, ε_{1,t} and ε_{2,t} corresponding to the normal and the unusual price movements, respectively. Suppose the first innovation component is

```
ε_{1,t} | ℱ_{t−1} ~ N(0, σ_t), (70.2)
```

where the conditional variance σ_t^2 follows a GARCH process

```
σ_t^2 = a_0 + a (ε_{t−1} − c)^2 + b σ_{t−1}^2, (70.3)
```

where ε_{t−1} is the time t − 1 innovation. The parameterization in (70.3) is a simplification of that of Maheu (2002, 2004), which allows not only for the asymmetric responses to good versus bad news, but also to the ex post expected number of jumps during (t − 2, t − 1] given the information set ℱ_{t−1}. The second component ε_{2,t}, termed as the jump innovation, is the discrepancy between the total size of the n_t jumps and the expected total jump size θ λ_t during (t − 1, t]

```
ε_{2,t} = Σ_{j=1}^{n_t} U_{t,j} − θ λ_t,
```
