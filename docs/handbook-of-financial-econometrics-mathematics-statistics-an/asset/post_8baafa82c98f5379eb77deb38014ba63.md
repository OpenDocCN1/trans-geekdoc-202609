## 28.3 The Durbin–Wu–Hausman (DWH) Test

The DWH test is based on vectors of contrasts. In general, consider two estimators providing parameter vectors $\hat\theta$ and $\tilde\theta$ and testing

$H_0: \ \text{plim}\left(\hat\theta - \tilde\theta\right)=0 \ \text{versus}\ H_A: \ \text{plim}\left(\hat\theta - \tilde\theta\right)\neq0.$

If the difference between the root-$T$ consistent estimators is root-$T$ consistent under the null hypothesis, then it converges in distribution, with mean $\mathbf{0}$ and a limit normal distribution

$\sqrt{T}\left(\hat\theta - \tilde\theta\right) \xrightarrow{d} N\left[\mathbf{0}, \Omega\left(\hat\theta - \tilde\theta\right)\right],$

where $\Omega\left(\hat\theta - \tilde\theta\right)$ is the contrast in variance–covariance matrices in the limiting distribution. The DWH test statistic is then given by

$m = \left(\hat\theta - \tilde\theta\right)'\left(\frac{\Omega\left(\hat\theta - \tilde\theta\right)}{T}\right)^{-1}\left(\hat\theta - \tilde\theta\right) \sim \chi^2(q). \quad (28.1)$

That is, $m$ is asymptotically distributed $\chi^2(q)$ under the null, where $q$ is the number of parameters (associated with potential endogenous variables) being compared across the two models considered. The null hypothesis is rejected at significance level $\alpha$ if $m > \chi^2_{\alpha}(q)$.

In the context of instrumental variables, for example, if the original $X$ variables are valid instruments (i.e., they are not correlated with the contemporaneous error), then the LS estimator is consistent and preferred to the IV estimator with other valid instruments. Since both would then have the same probability limit, both provide consistent parameter estimates so the preference between the estimators is then based on the efficiency of the parameter standard errors.

In general, to carry out the test we need a consistent estimate of

$\Omega\left(\tilde\theta - \hat\theta\right) = \text{var}\left[\hat\theta\right] + \text{var}\left[\tilde\theta\right] - 2\text{cov}\left[\hat\theta, \tilde\theta\right]. \quad (28.2)$

Unfortunately, the last quantity on the right-hand-side of this expression can be difficult to compute. However, if the estimator $\tilde{\theta}$ in the null hypothesis model is efficient, then $\operatorname{var}[\hat{\theta}]=\operatorname{cov}[\hat{\theta},\tilde{\theta}]$, leading to $\Omega(\tilde{\theta}-\hat{\theta})=\operatorname{var}[\tilde{\theta}]-\operatorname{var}[\hat{\theta}]$ (Hausman, 1978; Hausman and Taylor, 1981; Holly, 1982). The DWH statistic then simplifies to

$$m=(\tilde{\theta}-\hat{\theta})'\left(\operatorname{var}[\tilde{\theta}]-\operatorname{var}[\hat{\theta}]\right)^{-1}(\tilde{\theta}-\hat{\theta})\sim\chi^2(q),\tag{28.3}$$

which requires the estimated asymptotic variance matrices of the parameter estimates, but not the covariance between them, so it is relatively easy to calculate.

If there is only one potentially endogenous variable in the model, $\theta_j$, then the test statistic becomes

$$m_j=(\hat{\theta}_j-\tilde{\theta}_j)^2\left(SE^2_{\tilde{\theta}_j}-SE^2_{\hat{\theta}_j}\right)^{-1}\sim\chi^2(1),\tag{28.4}$$

where $SE_i$ represents the respective parameter standard errors.

## 28.4 Implementing the DWH Test

To implement the DWH test, construct two estimators for the parameter vector $\beta$, $\hat{\beta}_0$ and $\hat{\beta}_A$ such that

- $\hat{\beta}_0$ is consistent and efficient under $H_0$, but not consistent under $H_A$.
- $\hat{\beta}_A$ is consistent under both $H_0$ and $H_A$, but not efficient under $H_0$.

This test can be used whenever there are two estimators so characterized. For example,

$$\hat{\beta}_0=(X'BX)^{-1}X'BY,\tag{28.5}$$

and

$$\hat{\beta}_A=(X'AX)^{-1}X'AY,\tag{28.6}$$

where A and B are $T\times T$ matrices with rank $\geq K$ such that the above conditions hold for the estimators. Compute the vector of contrasts in parameters

$$\begin{aligned}
\hat{\beta}_A-\hat{\beta}_0&=(X'AX)^{-1}X'AY-(X'BX)^{-1}X'BY,\\
&=(X'AX)^{-1}X'A\left[I-X(X'BX)^{-1}X'B\left((X'AX)^{-1}X'A\right)\right]Y.
\end{aligned}\tag{28.7}$$

To illustrate, consider the classical linear in parameters model

**Y** = **X**β + **e**  (28.8)

where
**Y** = (Y₁,…,Y_N)' is a N × 1 vector,
**X** = (**X**₁,…, **X**_N)' = N × K matrix with at least one X_i correlated with e_i (contemporaneous correlation),
β = (β₁,…,β_K)' is a K × 1 vector,
**e** = (e₁,…,e_N)' is a N × 1 vector, and
**e** ∼ IID (0,σ²).

Since we are considering OLS, **B** is specified as a T × T identity matrix in (28.5), so β̂_OLS = (**X**'**X**)⁻¹ **X**'**Y**.

Let H₀ denote the null hypothesis of no misspecification, and H_A denote the alternative hypothesis of a particular form of misspecification.

In order to use OLS on model (28.8) and obtain unbiased parameter estimates, we specify **X** independent of **e**, so the specific null and alternative hypotheses are

H₀ : **X** is independent of **e**.
H_A : **X** is not independent of **e**.

To implement the DWH test to compare OLS to an alternative estimator, compute the vector of contrasts in the respective parameters

β̂_A − β̂_OLS = (**X**'**A** **X**)⁻¹ **X**'**A** **Y** − (**X**'**X**)⁻¹ **X**'**Y** = (**X**'**A** **X**)⁻¹ **X**'**A** **M**_X **Y**,  (28.9)

where **M**_X = **I** − **P**_X and **P**_X = **I** − **X**(**X**'**X**)⁻¹ **X**' are a T × T symmetric and idempotent projection matrices. That is,

- for some T × L matrix **Z**, **M**_Z **X** is the T × K matrix of residuals from the regression of each column of **X** on **Z**, and
- **P**_Z **X** is the T × K matrix of predicted values from regressing each column of **X** on **Z**.

The choice of **A** depends on the problem under consideration, e.g.,

- **A** = **P**_Z ⇒ β̂_A is 2SLS estimate of β using **Z** as instrumental variables.
- **A** = **M**_D ⇒ β̂_A is the panel data FE estimator.

To see the latter, define D as a NT × N matrix of dummy variables such that the element in the row corresponding to observation it, for i = 1, …, N and t = 1, …, T, and column j, for j = 1, …, N, is equal to 1 if i = j and 0 otherwise. Let MD denote the projection matrix I – D(D'D)−1D'. The fixed effects estimator is then

β̂_FE = ((M_D X)'(M_D X))^{-1}(M_D X)'(M_D y) = (X'M_D X)^{-1}X'M_D y.
(28.10)

More detail on the FE estimator is presented in Section 28.10, below. The vector of contrasts for comparing FE and OLS is then

β̂_FE − β̂_OLS = (X'M_D X)^{-1}X'M_D Y − (X'X)^{-1}X'Y
= (X'M_D X)^{-1}X'M_D[I−X(X'X)^{-1}X']Y
= (X'M_D X)^{-1}X'M_D M_X Y.
(28.11)

If the specified model (28.8) is correct then, from the vector of contrasts (28.9),

p lim (β̂_A − β̂_OLS) = 0.
(28.12)

Since (X′AX)^{-1} is a K × K matrix of full rank, the vector of contrasts will have a p lim = 0 whenever

p lim (X'AM_X Y / T) = 0.
(28.13)

For comparing OLS to 2SLS, partition X as [X_1 X_2] where X_1 = K × q submatrix of potentially endogenous variables, and X_2 = K × (K − q) submatrix of exogenous variables. Suppose we have a set of instruments

Z = [Z^* X_2],
(28.14)

where Z is T × L matrix of identifying instruments, (L ≥ K) ⇒ A = P_Z, and Z^* is the matrix of instrumental variables excluding those contained in X_2. Recall, we want to determine if

p lim (X'P_Z M_X Y / T) = 0.
(28.15)

Since some columns of $\mathbf{X}'\mathbf{P}_Z\mathbf{M}_X$ will be identical to $\mathbf{0}$ (because $\mathbf{Z}$ and $\mathbf{X}$ have $\mathbf{X}_2$ in common), we can restrict our attention to

$$\operatorname{plim}\left(\frac{\mathbf{X}'\mathbf{P}_Z\mathbf{M}_X\mathbf{Y}}{T}\right)=\operatorname{plim}\left(\frac{\hat{\mathbf{X}}'\mathbf{M}_X\mathbf{Y}}{T}\right)=0. \tag{28.16}$$

So in many applications, this test can then be carried out by using an $F$-test on the $q$ vector of parameters, $\delta$, in the artificial regression

$$\mathbf{Y}=\mathbf{X}\boldsymbol{\beta}+\hat{\mathbf{X}}_1\boldsymbol{\delta}+\text{residuals}, \tag{28.17}$$

where $\hat{\mathbf{X}}_1$ are the predicted values obtained by regressing $\mathbf{X}_1$ on $\mathbf{Z}$, i.e., $\hat{\mathbf{X}}_1=\mathbf{Z}(\mathbf{Z}'\mathbf{Z})^{-1}\mathbf{Z}'\mathbf{X}_1=\mathbf{P}_Z\mathbf{X}_1$. Equation (28.17) is the unrestricted model for the $F$-test and (28.8) is the restricted model, so

$$F=\frac{(\mathrm{ESS}_R-\mathrm{ESS}_U)/q}{\mathrm{ESS}_U/(T-K-q)}. \tag{28.18}$$

can be treated as an $F(q,T-K-q)$ random variable under $H_0$ since $qF\sim\chi_q^2$. See Davidson and MacKinnon (1989) and MacKinnon (1992) for additional detail, they show that most of these tests can be carried out using artificial regressions.

## 28.5  Robust DWH Test

The efficiency of the estimator requirement in the null hypothesis above can be relaxed. For example, if there is a reason to use robust standard errors then the estimator is not fully efficient, so the form of the DWH test above is not applicable. If the estimator in the null hypothesis is not efficient, direct estimation using auxiliary regressions (Davidson and MacKinnon, 1989; MacKinnon, 1992) or the paired bootstrap (Cameron and Trivedi, 2005) can be used to estimate the $\operatorname{var}(\hat{\theta}-\tilde{\theta})$, in particular the last term on the right-hand-side of (28.2).
