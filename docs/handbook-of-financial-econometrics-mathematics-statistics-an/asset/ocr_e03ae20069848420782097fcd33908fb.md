The interest rate for a deposit of one month was 5.14875% on that particular day. The only missing piece of information is the instantaneous variance of the stock price.

Several different techniques have been suggested for estimating the instantaneous variance. In this regard, the work of Latané and Rendleman (1976) must be mentioned; they derive standard deviations of continuous price-relative returns that are implied in actual call-option prices on the assumption that investors behave as if they price options according to the Black–Scholes model. In the example, the implicit variance is calculated by using the actual October 20, call price of an IBM option with an exercise price of $120 to solve for an estimate of the instantaneous variance. More specifically, a numerical search is used to approximate the standard derivation implied by the Black–Scholes formula with these parameters: stock price S = 116.67, exercise price X = 120, time to expiration T = 30/365 = 0.0822, riskless rate r = 0.0514875, and call-option price C = 2.00. The approximated implicit standard deviation is found to be σ = 23.82%. A simple spreadsheet like Excel for example can be used to calculate this “implied volatility”, using the “solver” or the “goal seek” tool. That way, one can simply write the Black–Scholes formula and set as “changing variable” the volatility, so that the “target variable” — the calculated option price — becomes equal to its market price.

After the clarifications are made, the example is this: given S = 116.67, X = 115, T = 0.0822, r = 0.0514875, and σ = 23.82%, we use equation (27.37) to compute C. Using equations (27.38) and (27.39) we calculate

$d_1 = \frac{\ln(116.67/115) + \left(0.0514875 + \frac{0.2382^2}{2}\right) \cdot 0.0822}{0.2382 \cdot \sqrt{0.0822}} = 0.30722,$

$d_2 = \frac{\ln(116.67/115) + \left(0.0514875 - \frac{0.2382^2}{2}\right) \cdot 0.0822}{0.2382 \cdot \sqrt{0.0822}} = 0.238922.$

Using the Excel function Normsdist ($d_i$) we can calculate the cumulative standardized normal distribution. Thus we calculate for the call option premium,

$C = 116.67 \cdot N(0.30722) - 115 \cdot \exp(-0.0514875 \cdot 0.0822) \cdot N(0.238922) = 4.34.$

The calculated call-option price of $4.34 is between the actual bid — offer for the call price of $4.30–$4.50 reported in Bloomberg.
