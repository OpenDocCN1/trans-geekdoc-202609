# Asymptotic Distributions for Sample Means:

Given the limiting distribution of “\bar{x}_n” as

$$\sqrt{n}(\bar{x}_n - \mu) \xrightarrow{d} N[0, \sigma^2]. \tag{115.8}$$

We divide by “\sqrt{n}” and add “\mu” and write the asymptotic distribution as

$$\bar{x}_n \xrightarrow{a} N[\mu, \sigma^2/n] \quad \text{or} \quad \bar{x}_n \sim AN[\mu, \sigma^2/n]. \tag{115.9}$$

This allows us to state that: $p\lim(\bar{x}_n) = \mu$ and $a\operatorname{var}(\bar{x}_n) = \sigma^2/n$.

Thus even though the variance of “\bar{x}_n” goes to zero we have its approximate variance when “$n$” is large but finite. We describe “\bar{x}_n” as being “asymptotically normally distributed” with “asymptotic variance” $\sigma^2/n$.

# 115.3.3 Cramer's theorem

Cramer's theorem will be very useful for later discussion. Suppose that $\eta_n = H_n \psi_n$ where “$\psi_n$” is a $n \times 1$ vector of random variables with a limiting (multivariate) normal distribution with mean “$\mu$” and variance “$\Omega$”, and “$H_n$” is an $m \times n$ matrix with the property:

$$p\lim H_n = H, \tag{115.10}$$

$$\text{Then } \eta_n \xrightarrow{d} N(H\mu, H\Omega H'). \tag{115.11}$$

Thus we can find the limiting distribution of the product of these variables without knowing the distribution of “$H_n$”, all we need is its $plim$.

# 115.3.4 The Mann–Wald theorem

This is the last bit of large-sample theory we will need. Let “$X_n$” be the matrix of data on the regressors with sample size “$n$”, and assume that

$$p\lim \left( \frac{X_n' X_n}{n} \right) = Q. \tag{115.12}$$

Note that $(X_n' X_n)$ grows without limit, which is why we divide by “$n$”. Even so, if “$X_n$” were to grow fast enough, the limit might not converge — so this is an assumption and not a condition that is always true. What this means is that the variance–covariance matrix of the regressors is finite.
