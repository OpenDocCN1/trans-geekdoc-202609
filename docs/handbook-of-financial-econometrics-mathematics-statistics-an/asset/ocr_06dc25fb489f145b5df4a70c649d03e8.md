variable is derived as follows:

$$\nabla_{u_i} \Lambda = (X \times_1 u_i^T \times_2 v_j^T \times_3 w_k^T - a_{ijk}) X \times_2 v_j^T \times_3 w_k^T$$ $$+ \lambda_1 (u_i F - x_i) F^T + \lambda_2 (L_Z U)_i + \lambda_3 u_i,$$ $$\nabla_{v_j} \Lambda = (X \times_1 u_i^T \times_2 v_j^T \times_3 w_k^T - a_{ijk}) X \times_1 u_i^T \times_3 w_k^T + \lambda_3 v_j,$$ $$\nabla_{w_k} \Lambda = (X \times_1 u_i^T \times_2 v_j^T \times_3 w_k^T - a_{ijk}) X \times_1 u_i^T \times_2 v_j^T + \lambda_3 w_k,$$ $$\nabla_C \Lambda = (X \times_1 u_i^T \times_2 v_j^T \times_3 w_k^T - a_{ijk}) u_i \circ v_j \circ w_k + \lambda_3 C,$$ $$\nabla_F \Lambda = \lambda_1 u_i^T (u_i F - x_i) + \lambda_2 F.$$

The detailed algorithm of the learning process is shown in Algorithm 2.

# Algorithm 2 Coupled Matrix and Tensor Factorization

**Input:** Tensor $A$, matrices $X$, $Z$, an error threshold $\varepsilon$
**Output:** Low rank matrices $U$, $V$, $W$, $F$, core tensor $X$

+   1: Set $\eta$ as step size of gradient descent, iteration time
+   2: Initialize $U \in P^{N \times R_1}$, $V \in P^{M \times R_2}$, $W \in P^{L \times R_3}$, $F \in P^{R_1 \times K}$, $Z \in P^{N \times N}$ and core tensor $X \in P^{R_1 \times R_2 \times R_3}$ with small random values, $t = 0$
+   3: $d_{ii} = \sum_i z_{ij}$
+   4: $L_Z = D - Z$
+   5: for each $a_{ijk} \neq 0$ do
+   6: Get $\nabla_{u_i} \Lambda$, $\nabla_{v_j} \Lambda$, $\nabla_{w_k} \Lambda$, $\nabla_X \Lambda$, $\nabla_\Phi \Lambda$
+   7: $u_i^{t+1} = u_i^t - \eta \nabla_{u_i^t} \Lambda$
+   8: $v_j^{t+1} = v_j^t - \eta \nabla_{v_j^t} \Lambda$
+   9: $w_k^{t+1} = w_k^t - \eta \nabla_{w_k^t} \Lambda$
+   10: $X^{t+1} = X^t - \eta \nabla_{X^t} \Lambda$
+   11: $\Phi^{t+1} = \Phi^t - \eta \nabla_{\Phi^t} \Lambda$
+   12: end for
+   13: while $(Loss^t - Loss^{t-1} > \varepsilon)$ do
+   14: Do steps 5 – 12 iteratively
+   15: $t = t + 1$
+   16: end while
+   17: return $U,V,W$ and $F$
