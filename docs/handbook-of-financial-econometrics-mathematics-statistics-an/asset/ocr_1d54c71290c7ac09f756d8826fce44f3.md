To achieve narrower bounds, one can require additional assumptions. For example, in addition to investors preferring more wealth to less, Ritchken (1985) assumes that investors are risk-averse and there exists a set of ex ante consensus probabilities for the states:

e_i = π_i d_i,    i = 1, 2, 3, …, n,    (7.15)

where d_i is the state discount factor that is non-increase with respect to wealth and π_i is ex ante consensus probabilities that state i occurs. The bounds of a European call option are then obtained by solving the following linear programming problem:

Minimize (or Maximize) C_0 = Σ_{i=1}^n c_i π_i d_i,
subject to Σ_{i=1}^n s_i π_i d_i = S_0 and Σ_{i=1}^n π_i d_i = B_0
with d_1 ≥ d_2 ≥ d_3 ≥ … ≥ d_n ≥ 0,    (7.16)

where e_i is the current price of a pure state i security that pays out $1 at maturity date if state i occurs; s_i is the value of the underlying security in state i; c_i is the value of a European call option in state i; d_i is the state discount factor that is non-increase with respect to wealth; π_i is ex ante consensus probabilities that state i occurs; S_0 and B_0 are current values of the underlying security and a portfolio containing all state securities, respectively.

Following Ritchken (1985), Ritchken and Kuo (1988) propose the application of the single-period linear-programming option model to handle multiple periods. Ritchken and Kuo (1988) obtain identical upper bounds and tighter lower bounds than Ritchken (1985). Ritchken and Kuo (1989) further consider the additional preference restrictions on the investors with third-order or above stochastic dominance criteria. They also apply a decreasing absolute risk aversion (DARA) dominance rule in a state preference context. With the two restrictions, the closed form analytical solutions for the option bounds are not obtained, but a simple numerical example is presented.
