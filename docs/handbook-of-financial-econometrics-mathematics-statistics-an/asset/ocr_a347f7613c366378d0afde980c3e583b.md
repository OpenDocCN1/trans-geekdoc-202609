To see the latter, define D as a NT × N matrix of dummy variables such that the element in the row corresponding to observation it, for i = 1, …, N and t = 1, …, T, and column j, for j = 1, …, N, is equal to 1 if i = j and 0 otherwise. Let MD denote the projection matrix I – D(D'D)−1D'. The fixed effects estimator is then

```
β̂_FE = ((M_D X)'(M_D X))^{-1}(M_D X)'(M_D y) = (X'M_D X)^{-1}X'M_D y.
(28.10)
```

More detail on the FE estimator is presented in Section 28.10, below. The vector of contrasts for comparing FE and OLS is then

```
β̂_FE − β̂_OLS = (X'M_D X)^{-1}X'M_D Y − (X'X)^{-1}X'Y
= (X'M_D X)^{-1}X'M_D[I−X(X'X)^{-1}X']Y
= (X'M_D X)^{-1}X'M_D M_X Y.
(28.11)
```

If the specified model (28.8) is correct then, from the vector of contrasts (28.9),

```
p lim (β̂_A − β̂_OLS) = 0.
(28.12)
```

Since (X′AX)^{-1} is a K × K matrix of full rank, the vector of contrasts will have a p lim = 0 whenever

```
p lim (X'AM_X Y / T) = 0.
(28.13)
```

For comparing OLS to 2SLS, partition X as [X_1 X_2] where X_1 = K × q submatrix of potentially endogenous variables, and X_2 = K × (K − q) submatrix of exogenous variables. Suppose we have a set of instruments

```
Z = [Z^* X_2],
(28.14)
```

where Z is T × L matrix of identifying instruments, (L ≥ K) ⇒ A = P_Z, and Z^* is the matrix of instrumental variables excluding those contained in X_2. Recall, we want to determine if

```
p lim (X'P_Z M_X Y / T) = 0.
(28.15)
```
