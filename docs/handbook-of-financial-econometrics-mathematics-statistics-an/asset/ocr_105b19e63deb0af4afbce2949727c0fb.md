So far, it looks like an equal number m of trading strategies are required to trade every selected asset. Actually it is not necessary because m here only means the maximum number of trading strategies applied on any of the selected assets, because when the actual number of trading strategies for a given asset is less than m, the weight for the non-existent trading strategies can be simply set to zero. Therefore, without loss of generality, we can assume the use of an equal number of trading strategies for each selected asset.

# The Intelligent Portfolio:

Substituting formula (43.2) into (43.1), the return of investment R_t of the multi-asset multi-strategy portfolio as a whole can be expressed as R_t = sum_{i=1}^n w_i R_it = sum_{i=1}^n ( w_i sum_{j=1}^m w_ij R_ijt ). (43.3)

We shall call a portfolio as expressed by formula (43.1) an asset portfolio, and a portfolio as expressed by formula (43.2) a (trading) strategy portfolio. Note that both the asset portfolios and the strategy portfolios so constructed are long-only portfolios; but each trading strategy S_ij, i = 1,2,L,n; j = 1,2,L,m, in any strategy portfolio is long-short. Logically this structure of two-level long-only portfolios — the asset portfolio and the strategy portfolios — with long-short trading strategies can realize all the functions of any long-short asset portfolio. We shall call such a structure of an asset portfolio and its strategy portfolios with long-short trading strategies as defined by formulas (43.1)-(43.3) an intelligent portfolio. Note the concept and mathematical structure of the intelligent portfolio are of generality, and the traditional multi-asset portfolio is a subclass. Let m = 1, i.e., only one trading strategy is loaded onto each asset, and the simplest instance of this strategy is the Buy-and-Hold (B&H), then the portfolio return in formula (43.3) is reduced to R_t = sum_{i=1}^n w_i R_it = sum_{i=1}^n w_i P_it / P_i0.
