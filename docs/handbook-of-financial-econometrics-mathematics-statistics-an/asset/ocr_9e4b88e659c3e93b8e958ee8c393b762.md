The proportional odds model assumes $O_i(t) = \psi O_0(t)$ for all $t$, where $O_0$ denotes the baseline odds function. By incorporating the covariates, the model can be expressed as

$O_i(t) = O_0(t) \exp(\beta^{T} \mathbf{x}_i)$

where $\beta$ is the unknown regression parameters and $O_0$ is an unspecified baseline odds function. For any two individuals, $i$ and $j$, the ratio of their odds can drop out of the baseline hazard function because they are canceled out:

$\frac{O_i(t)}{O_j(t)} = \frac{O_0(t) \exp(\beta^{T} \mathbf{x}_i)}{O_0(t) \exp(\beta^{T} \mathbf{x}_j)} = \exp[\beta^{T} (\mathbf{x}_i - \mathbf{x}_j)]$.

Similar to the Cox PH model, the ratio of the odds does not depend on time $t$. Sometimes, the proportional odds model is also called the Cox PH model for discrete time data. The proportional odds model can be estimated by a standard maximum likelihood method through the traditional logistical regression model.

Now we apply the proportional odds model to the same firm data used in parametric regression models and Cox PH model. Before using the logistical regression model to estimate proportional odds model, we need to expand the original data from one record per firm to multiple year records per firm.

```
data firmsc;
  set firms;
  do year = 1 to dury;
    if year=dury and status = 1 then event=1;
      else event=0;
      output;
  end;
run;

proc logistic data=firmsc;
  model event(desc)=age ad rd debt;
run;
```
