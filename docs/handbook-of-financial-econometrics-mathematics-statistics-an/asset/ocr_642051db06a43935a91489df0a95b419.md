# 120.3.1.3 Nelson–Aalen estimator

The Nelson–Aalen estimator estimates the cumulative hazard function in the same fashion as the Kaplan–Meier estimator. It was initially proposed by Nelson (1972) and later mathematically formalized and justified by Aalen (1978).
