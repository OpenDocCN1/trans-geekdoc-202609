We also use effective size and betweenness centrality as alternative measures of structural hole in the regression analysis. Effective size of i is i's network size (the number of direct connections) subtracted by i's redundancy in the network. It estimates the extent to which contact j is redundant with other contacts of node i and can be calculated as the following:

$$ES_i = \sum_{j}[1 - \sum_{q} p_{iq} m_{jq}], \quad q \neq i, j, \tag{31.2}$$

where $p_{iq}$ is the proportion of $i$'s connection with $q$ as a ratio of all its connections. And $m_{jq}$ is $j$'s interaction with $q$ divided by $j$'s strongest relationship with anyone (this is always 1 if $j$ has tie to $q$ and 0 otherwise). The sum of the product $p_{iq} m_{jq}$ measures the portion of $i$'s relation with $j$ that is redundant to $i$'s relation with other primary contacts.

To illustrate the idea of effective size in Figure 31.1, we add an edge between node B and C. With an added edge, there is a redundant path of node A to node C: A → B → C and a redundant path of node A to node B: A → C → B. The redundant path from A to B and from A to C are both $\frac{1}{3} * 1 = \frac{1}{3}$, and thus the effective size of node A is $3 - 2/3 = 7/3$. Effective size measures the non-redundant elements of the network and nodes occupy more structural holes when they have a larger effective size.

Betweenness is a centrality measure using the idea of a “shortest paths”. For every pair of nodes in a network, there exists at least one shortest path. The betweenness centrality for each node is the number of these shortest paths that pass through that node as a ratio of the total number of shortest paths. The betweenness centrality of node $i$ is calculated as the following:

$$\text{betweenness}_i = \sum_{s \neq i \neq t} \frac{\sigma_{st}(i)}{\sigma_{st}}, \tag{31.3}$$
