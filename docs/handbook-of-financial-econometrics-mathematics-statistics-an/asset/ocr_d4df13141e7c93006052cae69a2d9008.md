Let \epsilon > 0 and find M > x such that \int_{(-\infty,x-M-1]\cap[x+M-1,\infty)} dF(z) < \epsilon.
Then, for all y > 0 such that |x - y| \le 1/2,

\left| \int \Phi(y - z)dF(z) - \int \Phi(x - z)dF(z) \right| \le 2\|g\|_{\infty}\epsilon + \left| \int_y^{y+M} g(y - z)dF(z) - \int_x^{x+M} g(x - z)dF(z) \right| + \left| \int_{y-M}^y \Phi(y - z)dF(z) - \int_{x-M}^x \Phi(x - z)dF(z) \right| \le 2\|g\|_{\infty}\epsilon + \left| \int_{-M}^0 g(z)[f(y - z) - f(x - z)]dz \right| + \left| \int_0^M \Phi(z)[f(y - z) - f(x - z)]dz \right|,

where f is the density function for F. Since g and \Phi are bounded and f is continuous on R \ {0}, by dominated convergence, we have

\limsup_{y\to x} \left| \int \Phi(y - z)dF(z) - \int \Phi(x - z)dF(z) \right| \le 2\|g\|_{\infty}\epsilon.

Since \epsilon > 0 is arbitrary, the proof is completed.

To prove (41.10), we need the following lemmas and Dynkin's formula.

# **Lemma 41.A.1** For every bounded Borel-measurable function g on R_−, there exists a sequence of uniformly bounded functions (g_n) in C^2_0(R_−) such that g_n → g Lebesgue-s.e. on R_− and g_n(0) = g(0) for all n.

**Proof.** Write dm for Lebesgue measure on R. Let h be a normal density, and set dG(y) = h(y)dm. Then, by the strict positivity of h, dG, and dm are equivalent.

Fix \epsilon > 0, by dominated convergence, we can find N large enough such that \int_{-\infty}^0 |1_{[-N,0]} g - g| dG < \epsilon. Also, since g1_{[-N,0]} is bounded and in L_1(R, dm), a modification of the proof of Theorem 41.2.4 in (Stein and Shakarchi (2005), Chapter 2), shows that we can find a sequence of uniformly bounded C^2_0(R_)-functions (g'_n) such that g'_n → g1_{[-N,0]} dm-a.e. since dG and dm are equivalent, g'_n → g1_{[-N,0]} dG-a.e. Hence, by dominated convergence, we can pick n large such that \int |g'_n - g1_{[-N,0]}| dG < \epsilon. We have obtained that \int_{-\infty}^0 |g'_n - g| dG < 2\epsilon. And this implies that there exists a sequence of C^2_0(R_)-functions (g_n) such that g_n → g dm-a.e. on R_−. In addition, it is clear that we can pick (g_n) to be uniformly bounded.
