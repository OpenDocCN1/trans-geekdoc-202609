By definition, \(S(0) = 1\), \(S(\infty) = 0\), and \(S\) does not increase in \(t\) (it usually decreases in \(t\)). The survival function measures the probability of surviving at time \(t\) if a subject is alive at the origin of time (\(t = 0\)), and the probability is decreasing in time. The most commonly used methods to estimate the survivor function are Kaplan–Meier estimator and life-table estimator, which we discuss later in the chapter.

The probability density function (pdf) of \(T\) is defined as

\[f(t) = \frac{dF(t)}{dt} = -\frac{dS(t)}{dt}.\]

Accordingly, the hazard function is defined as

\[\lambda(t) = \lim_{\Delta t \to 0} \frac{\Pr(t \leq T < t + \Delta t | T \geq t)}{\Delta t}.\]

Note that the hazard function is not a probability; instead, it is an instantaneous risk that an event will happen at time \(t\). The hazard function is often interpreted as the expected number of events in a one-unit interval of time, so it is also called the hazard rate. The reciprocal of the hazard rate is sometimes called the Mills ratio (Mills 1926), which gives the expected length of time until an event happens.

The relationship between the survivor function, the pdf and the hazard function is expressed as

\[\lambda(t) = \frac{f(t)}{S(t)}.\]

The formula can also be expressed as

\[\lambda(t) = -\frac{d}{dt} \log S(t),\]
or

\[S(t) = \exp \left[ -\int_0^t \lambda(u) \, du \right].\]

Let the cumulative hazard function be denoted by \(\Lambda(t) = \int_0^t \lambda(u) \, du\), the survivor function and the pdf can be rewritten as

\[S(t) = \exp[-\Lambda(t)],\]
and

\[f(t) = \lambda(t) \exp [-\Lambda(t)].\]

The most commonly used estimation of cumulative hazard function is Nelson–Aalen estimator, which is an alternative to the Kaplan–Meier estimator.
