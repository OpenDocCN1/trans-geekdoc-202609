Using the symmetry σ_ij = σ_ji and the abbreviation T σ_f^2 := ∑ f_t^2 - T^{-1} (∑ f_t)^2, we get

$$E(u_i u_j) = \frac{σ_{ij}∑_t f_t^2 - \frac{1}{T}(σ_{ij}+σ_{ji})(∑_t f_t)^2 + \frac{1}{T}σ_{ij}(∑_t f_t)^2}{(∑_t f_t^2 - \frac{1}{T}(∑_t f_t)^2)^2}$$ $$= \frac{σ_{ij}}{T σ_f^2}.$$

# Appendix 98E: Independence of the Errors in the Slope Estimate and the Sample Mean

Consider a time series of returns r_it generated by the market model (98.2). The deviation of the sample average of returns from its true expected value is

$$v_j := \bar{r}_j - E(r_j) = \frac{1}{T}β_j \sum_t (f_t - E(f_t)) + \frac{1}{T} \sum_t ε_{jt}.$$

The deviation of the slope estimate from its true value is (cf. Appendix 98D)

$$u_i = \frac{∑_t f_t ε_{it} - \frac{1}{T}∑_t f_t ∑_t ε_{it}}{∑_t f_t^2 - \frac{1}{T}(∑_t f_t)^2}.$$

By assumption, the expected value of the idiosyncratic errors ε_it is zero so that the expected value of both deviations is zero as well, hence Cov(u_i, v_j) = E(u_i v_j). Furthermore, in E(u_i v_j), all terms linear in ε_it vanish. Given the factors, we have

$$E(u_i v_j) = \frac{\frac{1}{T}∑_{t,t'} f_t E(ε_{it} ε_{jt'}) - \frac{1}{T^2}∑_t f_t ∑_{t,t'} E(ε_{it} ε_{jt'})}{∑_t f_t^2 - \frac{1}{T}(∑_t f_t)^2}.$$ Using the fact that E(ε_{it} ε_{jt'}) = σ_{ij} if t = t' and zero otherwise, the expression simplifies to $$E(u_i v_j) = \frac{\frac{1}{T}σ_{ij}∑_t f_t - \frac{1}{T}σ_{ij}∑_t f_t}{∑_t f_t^2 - \frac{1}{T}(∑_t f_t)^2} = 0,$$ thus showing that the deviations u_i and v_j are uncorrelated.
