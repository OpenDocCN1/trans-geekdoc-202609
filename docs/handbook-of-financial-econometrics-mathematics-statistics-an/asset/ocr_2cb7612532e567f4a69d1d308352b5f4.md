The most famous option pricing model is the Black-Scholes option pricing model which can be used to price European options.

The Black-Scholes model for a European call option is

$$C = S N(d_1) - X e^{-rT} N(d_2), \qquad (102.16)$$

where

$d_1 = \frac{\ln(\frac{S}{X}) + (r + \frac{\sigma^2}{2})T}{\sigma\sqrt{T}}$; $d_2 = d_1 - \sigma\sqrt{T}$;
$C$ = call price; $S$ = stock price; $X$ = exercise price; $r$ = risk-free interest rate;
$T$ = time to maturity of option in years; $N(\cdot)$ = standard normal distribution; $\sigma$ = stock volatility.

This model can be used to price call option and the put option can be derived from the following put-call parity:

$$P = C + X e^{-rT} - S, \qquad (102.17)$$

where $P$ = put price, other notations are identical to those defined in equation (102.16).

# 102.3 Relationship Between Binomial OPM and Black-Scholes OPM

When comparing the parameters in both models, we will find that, the binomial model has an Increase Factor ($u$), a Decrease Factor ($d$), and $n$-period parameters that the Black-Scholes model does not have. While the Black-Scholes model has distinct parameters, $\sigma$ and $T$ do not appear in binomial model. The parameters between the two models have the links, and can be translated from one to another. The derivations are as follows (Hull 2014).

As we discussed in Section 102.2, in binomial OPM setting, the stock price $S$ goes up with a probability $p$ to arrive $uS$, and goes down with a probability $1 - p$ to arrive $dS$. The expected stock price is $puS + (1 - p)d$.

Assume each step is of length $\Delta t$, where $\Delta t = \frac{T}{n}$. As $n \to \infty$, $\Delta t \to 0$. The expected return on a stock (in the real world) is supposed to be $r$ (continuously compounding). Therefore, within this small period of time, the expected price should be $e^{r\Delta t}S$.
