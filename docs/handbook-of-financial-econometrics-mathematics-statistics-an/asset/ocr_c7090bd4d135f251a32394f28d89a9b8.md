which can be represented by minimizing the following cost:

$$g(C_i, C_{i-1}) = (P_i - P_{i-1})^2.\tag{18.22}$$

Given a set of true labels Y, we then define the following objective function to aggregate all the costs, that is,

$$J(\mathbf{w}_m, \mathbf{w}_d, \mathbf{w}_s, \boldsymbol{\theta}) = \frac{\beta}{n} \sum_{\Gamma \in \Sigma} f(\Gamma, Y, \mathbf{w}_m, \mathbf{w}_d, \mathbf{w}_s, \boldsymbol{\theta})$$ 
$$\quad + \frac{1}{n} \sum_{C_i, C_{i-1} \in \Gamma; \Gamma \in \Sigma} \frac{1}{t} \sum_{i=1}^{t} g(C_i, C_{i-1}, \mathbf{w}_m, \mathbf{w}_d, \mathbf{w}_s, \boldsymbol{\theta})$$ 
$$\quad + \frac{1}{n} \sum_{\mathbf{x}_{ij} \in \Xi_i; \Xi_i \in G; G \in S} \frac{1}{t} \sum_{i=1}^{t} \frac{1}{n_i} \sum_{j=1}^{n_i} h(\mathbf{x}_{ij}, \mathbf{w}_m)$$ 
$$\quad + \lambda_m R(\mathbf{w}_m) + \lambda_d R(\mathbf{w}_d) + \lambda_s R(\mathbf{w}_s) + \lambda_\theta R(\boldsymbol{\theta}),\tag{18.23}$$

where $f(\Gamma, Y, \mathbf{w}_m, \mathbf{w}_d, \mathbf{w}_s, \boldsymbol{\theta}) = -I(Y = 1) \log \Pi - I(Y = -1) \log(1 - \Pi)$ is the log-likelihood function representing the difference between the predicted label and the true label. Here $I(\cdot)$ is the indicator function.

$h(\mathbf{x}_{ij}, \mathbf{w}_m) = \max(0, m_0 - \operatorname{sgn}(p_{ij} - p_0) \mathbf{w}_m^T \mathbf{x}_{ij})$ represents the instance-level cost. Here, sgn is the sign function; $m_0$ is a crucial margin parameter used to separate the positive and negative instances from the hyper line in the feature space; $p_0$ is a threshold parameter to determine the positiveness of an instance.

$R(\mathbf{w}_m)$, $R(\mathbf{w}_d)$, $R(\mathbf{w}_s)$ and $R(\boldsymbol{\theta})$ are regularization terms, and $\beta$ and $\lambda$ are constants that control the function.

# 18.4.3.3 Model learning

The model learning goal is to estimate the parameters $\mathbf{w}_m$, $\mathbf{w}_d$, $\mathbf{w}_s$ and $\boldsymbol{\theta}$ to minimize the cost shown in equation (18.23). We randomly choose a set $(\Gamma, Y)$ from $\Sigma$, and use the online stochastic gradient decent optimization. The gradient of $J(\mathbf{w}_m)$ with respect to $\mathbf{w}_m$ can be calculated as

$$\nabla J(\mathbf{w}_m) = \frac{\partial J(\mathbf{w}_m)}{\partial \mathbf{w}_m} = - \frac{Y - \Pi}{\Pi(1 - \Pi)} \frac{\beta}{t} \sum_{i=1}^{t} \frac{\theta_0}{n_i} \sum_{j=1}^{n_i} p_{ij}(1 - p_{ij}) \mathbf{x}_{ij}$$ 
$$\quad + \frac{1}{t} \sum_{i=1}^{t} 2(P_i - P_{i-1}) \frac{\theta_0}{n_i} \sum_{j=1}^{n_i} p_{ij}(1 - p_{ij}) \mathbf{x}_{ij}$$
