## 104.2.1 Mean–variance model

The objective function incorporates the short selling portion of the portfolio and trading costs in the minimization of portfolio variance. Let σ_ij be the covariance between r_i and r_j; w_j be the portfolio weight for asset j and can be decomposed into weights of long position (+) and short position (−), w_j = w_j^+ − w_j^−; p_j's be the transaction costs of buying, selling, short selling, and repurchasing the short-sale, respectively; k be the initial margin requirement for short selling; w_j^+ be the total proportion of security j invested at portfolio rebalancing; and w_j^− be the total weight of security j sold by investors at portfolio rebalancing. With each rebalancing, l_j^+ is the buying weight of security j; l_j^− is the short-selling weight of security j; s_j^+ is the short-selling weight of security j; and s_j^− is the repurchasing weight of security j. With the required return (E), the MV model that incorporates the transaction costs, lower bounds of weights, the optimization of short-sale weights is

Min ∑_{i=1}^n ∑_{j=1}^n σ_{ij}(w_i^+ − w_i^−)(w_j^+ − w_j^−) + ∑_{j=1}^n w_j^−
+ (∑_{j=1}^n p1 l_j^+ + p2 l_j^− + p3 s_j^+ + p4 s_j^−),   (104.1)
s.t. ∑_{j=1}^n \bar{r}_j (w_j^+ − w_j^−) ≥ E,   (104.2)
$$\sum_{j=1}^n (w_j^+ + k w_j^- + p_1 l_j^+ + p_2 l_j^- + p_3 s_j^+ + p_4 s_j^-) = 1, \quad (104.3)$$
$$w_j^+ = w_{j,0}^+ + l_j^+ - l_j^-, \quad j = 1,2,\dots,n, \quad (104.4)$$
$$w_j^- = w_{j,0}^- + s_j^+ - s_j^-, \quad j = 1,2,\dots,n, \quad (104.5)$$
$$0.01 u_j \le w_j^+ \le u_j, \quad j = 1,2,\dots,n, \quad (104.6)$$
$$0.01 v_j \le w_j^- \le v_j, \quad j = 1,2,\dots,n, \quad (104.7)$$
$$u_j + v_j \le 1, \quad j = 1,2,\dots,n, \quad (104.8)$$
$$u_j, v_j \in \{0,1\}, \quad j = 1,2,\dots,n, \quad (104.9)$$

where $p_c$’s are the transaction costs of buying ($p_1$), selling ($p_2$), short sales ($p_3$), and repurchasing of short-sales ($p_4$) asset $j$, respectively; $k$ is the initial margin requirement for short selling; $w_j^+$ is the total proportion of security $j$ invested at portfolio rebalancing; $w_j^-$ is the total weight of security $j$ sold by investors at portfolio rebalancing; $w_{j,0}^+$ is the long position weight of security $j$ prior to portfolio rebalancing; and $w_{j,0}^-$ is the short position weight of security $j$ prior to portfolio rebalancing. With each rebalancing, $l_j^+$ is the buying weight of security $j$; $l_j^-$ is the short-selling weight of security $j$; $s_j^+$ is the short-selling weight of security $j$; and $s_j^-$ is the repurchasing weight of security $j$. The binary variables $u_j$ and $v_j$ are used to indicate the long- and short-selling position and to model the upper bounds of the weight. We set 1% as the minimal threshold to invest in one asset. This value can be adjusted accordingly.

Regarding the equations in the model, equation (104.2) specifies the budget allocated to buying and short selling; (104.3) shows the long position after rebalancing; (104.4) represents the short-selling position after rebalancing; and (104.5) and (104.6) define the upper and lower bounds of the total weights of each security of long position and that of short-selling position, respectively. The definition of the binary variables in equations (104.8) and (104.9) ensures that long and short positions do not happen simultaneously.

## 104.2.2 Mean–absolute deviation model

The mean-absolute deviation (MAD) model by Chang (2005) and Konno and Yamazaki (1991) is modified. The absolute deviation can be split into the upside and downside deviations, $|\sum_{j=1}^n (r_{jt} - E(R_j)) w_j| = d_t = d_t^+ + d_t^-$,

d_t^+ ≥ 0, and d_t^- ≥ 0, and one will have ∑_{j=1}^n (r_{jt} - E(R_j)) w_j = d_t^+ - d_t^- . The objective function in the MAD model can be linearized as

Min 1/T ∑_{t=1}^T d_t  (104.10)
s.t. d_t + ∑_{j=1}^n (r_{jt} - E(R_j)) w_j ≥ 0,  t = 1, ..., T,  (104.11)
d_t - ∑_{j=1}^n (r_{jt} - E(R_j)) w_j ≥ 0,  t = 1, ..., T,  (104.12)

and Eqs. (104.2)-(104.9), where T is the ending period and r_{jt} is the return on security j in period t. The MAD model is suitable to model a portfolio of a large number of assets since it does not need to solve quadratic programming.

## 104.2.3 Linearized value-at-risk model

The Value-at-Risk (VaR) approach has been widely applied by financial institutions to control the downside loss. To assure the global optimums, we apply a linearized VaR model of Yu, Chiou, and Mu (2015) to construct and rebalance portfolios. This model is an improvement of Lin (2009) and Benati and Rizzi (2007) and is to avoid multiple solutions. Specifically,

Max δ r^{VaR} + (1 - δ) ( -1/T ∑_{t=1}^T (A_t^+ + A_t^-) ) + ( - ∑_{j=1}^n (p1 l_j^+ + p2 l_j^- + p3 s_j^+ + p4 s_j^-) ),  (104.13)
s.t. x_t = ∑_{j=1}^n w_j r_{jt},  t = 1, ..., T,  (104.14)
x_t ≥ r^{Min} + A_t^+ - A_t^- - r^{Min} y_t,  t = 1, ..., T,  (104.15)
A_t^+ ≤ r^{VaR+},  t = 1, ..., T,  (104.16)
A_t^+ ≥ r^{VaR+} - U(1 - y_t),  t = 1, ..., T,  (104.17)
A_t^- ≤ r^{VaR-},  t = 1, ..., T,  (104.18)
$A_t^- \ge r^{\text{VaR}-} - U(1 - y_t), \quad t = 1, \dots, T, \tag{104.19}$
$A_t^+, A_t^- \ge 0, \quad t = 1, \dots, T, \tag{104.20}$
$r^{\text{VaR}} = r^{\text{VaR}+} - r^{\text{VaR}-}, \tag{104.21}$
$r^{\text{VaR}+}, r^{\text{VaR}-} \ge 0, \tag{104.22}$
$\sum_{t=1}^{T} \frac{1}{T}(1 - y_t) \le \alpha^{\text{VaR}}, \tag{104.23}$
$y_t \in \{0,1\}, \quad t = 1, \dots, T, \tag{104.24}$

and Eqs. (104.2)-(104.9), where the return threshold $r^{\text{VaR}} = r^{\text{VaR}+} - r^{\text{VaR}-}$. If $r^{\text{VaR}} > 0$, then $r^{\text{VaR}+} > 0$ and $r^{\text{VaR}-} = 0$. If $r^{\text{VaR}} < 0$, then $r^{\text{VaR}+} = 0$ and $r^{\text{VaR}-} > 0$. If $r^{\text{VaR}} = 0$, then $r^{\text{VaR}+} = 0$ and $r^{\text{VaR}-} = 0$. Let $x_t$ be the portfolio return on day $t$, $r^{\text{Min}}$ be the minimal return of investing assets among $T$ days, $y_t$ be a binary variable indicating whether the portfolio return greater than $r^{\text{Min}}$ or $r^{\text{VaR}}$ on day $t$, and $\alpha^{\text{VaR}}$ be the confidence level of return distribution. We have $A_t = r^{\text{VaR}} y_t = (r^{\text{VaR}+} - r^{\text{VaR}-}) y_t = r^{\text{VaR}+} y_t - r^{\text{VaR}-} y_t = A_t^+ - A_t^-.$

## 104.2.4 Conditional value-at-risk model

We modify Rockafellar and Uryasev (2000) by transforming the objectives, the portfolio variance and short-selling weights, into a linear function. The VaR bears some undesirable mathematical characteristics such as a lack of sub-additivity and convexity. These characters will drive the volatility of the sum of a portfolio to be larger than the sum of the variances of the individual assets. This attribute may discourage diversification as it presents an increase in portfolio risk. To improve the above issues, Rockafellar, Uryasev, and Zabarankin (2006) suggest CVaR model. Ogryczak and Ruszczynski (2002) suggest that VaR criterion is equivalent to the first-order stochastic dominance while Ma and Wong (2010) show that CVaR is equivalent to the second-order stochastic dominance. Our model is

s.t. $\eta_t \ge -\sum_{j=1}^{n} r_{jt}(w_j^+ - w_j^-) - \xi, \quad t = 1, \dots, T, \tag{104.26}$
$\eta_t \ge 0, \quad t = 1, \dots, T, \tag{104.27}$
