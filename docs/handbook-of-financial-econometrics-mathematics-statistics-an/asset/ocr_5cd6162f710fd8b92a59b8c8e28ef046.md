We estimate the model for all countries jointly with unbalanced panel data ordinary least squares (OLS) but account for cross-sectional dependence by clustering the standard error across country indices. The full set of independent variables is shown in Table 13.2. The variables included, in general, are highly correlated and thus an estimation of the full model creates a large amount of insignificant independent variables and generates noise to the results. We apply general-to-specific algorithm (see Bekaert et al., 2011; Bekaert et al., 2012; Hendry and Krolzig, 2005) to reduce the number of variables that explain the variation of diversification benefit. This algorithm includes multiple steps to eliminate variables with coefficients that are insignificant. In detail, we estimate models (13.11) and (13.12) with all independent variables and then eliminate the least statistically significant variables that do not reach 15% of significance level. We set up a high significance level to be conservative in retaining potentially important variables. We continue estimating the model and excluding the individual variables while simultaneously testing whether already excluded variables should be included. Considering the results displayed in Table 13.5, a one-period lag is included in all regressions to control the autoregressive property of diversifying gains.
