# 6A.1  *Principals of turning point method*

The Turning point method obeys the following four concepts, if \(P_t<P_{t-1}>P_{t-2}\) then represent as peak turning point (PTP); if \(P_t>P_{t-1}<P_{t-2}\) then represent as trough turning point (TTP); if \(P_t>P_{t-1}>P_{t-2}\) then represent as upward no turning point (UNTP); if \(P_t<P_{t-1}<P_{t-2}\) then represent as downward no turning point (DNTP).
