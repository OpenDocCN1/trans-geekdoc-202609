Unfortunately, the last quantity on the right-hand-side of this expression can be difficult to compute. However, if the estimator $\tilde{\theta}$ in the null hypothesis model is efficient, then $\operatorname{var}[\hat{\theta}]=\operatorname{cov}[\hat{\theta},\tilde{\theta}]$, leading to $\Omega(\tilde{\theta}-\hat{\theta})=\operatorname{var}[\tilde{\theta}]-\operatorname{var}[\hat{\theta}]$ (Hausman, 1978; Hausman and Taylor, 1981; Holly, 1982). The DWH statistic then simplifies to

$$m=(\tilde{\theta}-\hat{\theta})'\left(\operatorname{var}[\tilde{\theta}]-\operatorname{var}[\hat{\theta}]\right)^{-1}(\tilde{\theta}-\hat{\theta})\sim\chi^2(q),\tag{28.3}$$

which requires the estimated asymptotic variance matrices of the parameter estimates, but not the covariance between them, so it is relatively easy to calculate.

If there is only one potentially endogenous variable in the model, $\theta_j$, then the test statistic becomes

$$m_j=(\hat{\theta}_j-\tilde{\theta}_j)^2\left(SE^2_{\tilde{\theta}_j}-SE^2_{\hat{\theta}_j}\right)^{-1}\sim\chi^2(1),\tag{28.4}$$

where $SE_i$ represents the respective parameter standard errors.

# 28.4 Implementing the DWH Test

To implement the DWH test, construct two estimators for the parameter vector $\beta$, $\hat{\beta}_0$ and $\hat{\beta}_A$ such that

+   - $\hat{\beta}_0$ is consistent and efficient under $H_0$, but not consistent under $H_A$.
+   - $\hat{\beta}_A$ is consistent under both $H_0$ and $H_A$, but not efficient under $H_0$.

This test can be used whenever there are two estimators so characterized. For example,

$$\hat{\beta}_0=(X'BX)^{-1}X'BY,\tag{28.5}$$

and

$$\hat{\beta}_A=(X'AX)^{-1}X'AY,\tag{28.6}$$

where A and B are $T\times T$ matrices with rank $\geq K$ such that the above conditions hold for the estimators. Compute the vector of contrasts in parameters

$$\begin{aligned}
\hat{\beta}_A-\hat{\beta}_0&=(X'AX)^{-1}X'AY-(X'BX)^{-1}X'BY,\\
&=(X'AX)^{-1}X'A\left[I-X(X'BX)^{-1}X'B\left((X'AX)^{-1}X'A\right)\right]Y.
\end{aligned}\tag{28.7}$$
