Achievement function: Min δ

s.t.  (57.8)

$\frac{g_1^{\max} - g_1(\xi)}{(g_1^{\max} - g_1^{\min})} \le \delta$ and $\frac{g_2^{\max} - g_2(\xi)}{(g_2^{\max} - g_2^{\min})} \le \delta$  (57.9)

Constraints: $\boldsymbol{\xi}'\boldsymbol{\xi} = 1$ and $\delta \ge 0$,

where $\boldsymbol{\xi}$ is the decision variable, and the four values $g_1^{\max} = g_1(\boldsymbol{\xi}_1^*)$, $g_2^{\min} = g_2(\boldsymbol{\xi}_1^*)$; $g_2^{\max} = g_2(\boldsymbol{\xi}_2^*)$, $g_1^{\min} = g_1(\boldsymbol{\xi}_2^*)$, $\boldsymbol{\xi}_1^*$ and $\boldsymbol{\xi}_2^*$ are the optimal solutions for objectives $g_1$ and $g_2$, respectively. Recall in Lemma 57.2.3, the objective function $g_1$ is maximized at the eigenvector $\boldsymbol{\xi}_1^* = \boldsymbol{v}_1$ corresponding to the largest eigenvalue $\lambda_1^*$ of $W_1$ in (57.6). The objective function $g_2$, according to Lemma 57.2.4, is maximized at the normalized vector $\boldsymbol{\xi}_2^* = [\alpha\boldsymbol{v}_1 + (1 - \alpha)\boldsymbol{u}_1]/\|\alpha\boldsymbol{v}_1 + (1 - \alpha)\boldsymbol{u}_1\|$ for some $0 \le \alpha \le 1$, where $\boldsymbol{u}_1$ is eigenvector that corresponds to the largest eigenvalue $\lambda_1$ of $W_2$ in (57.7).

To obtain Pareto efficient solution of the MINIMAX goal programming (57.8)–(57.9), the hyper-ellipse method described by Fadel and Li (2002), which is based on approximating the bi-objective Pareto set in the objective space, is used. The procedure of the hyper-ellipse method is as follows:

**Step 1:** Let $P_1 = (g_1^{\max}, g_2^{\min})$ and $P_2 = (g_1^{\min}, g_2^{\max})$;

**Step 2:** In addition to $P_1$ and $P_2$, the third point $P_3 = (g_1(\xi_3^*), g_2(\xi_3^*))$ is chosen, where $\xi_3^*$ maximized $w g_1 + (1 - w) g_2$ for a suitable weight $0 < w < 1$. Using the three points above, a hyper-ellipse is constructed to approximate the Pareto set as follows

$\left( \frac{g_1^{\max} - g_1}{g_1^{\max} - g_1^{\min}} \right)^{\nu} + \left( \frac{g_2^{\max} - g_2}{g_2^{\max} - g_2^{\min}} \right)^{\nu} = 1,$  (57.10)

where the exponent $\nu > 0$ is determined iteratively. Once the approximated Pareto set is obtained, a target Pareto point $Q = (g_1^*, g_2^*)$ on the approximated Pareto set is determined according to (57.10) so the maximal deviation $\delta$ in (57.8) can be minimized

$\left( \frac{g_1^{\max} - g_1^*}{g_1^{\max} - g_1^{\min}} \right)^{\nu} = \left( \frac{g_2^{\max} - g_2^*}{g_2^{\max} - g_2^{\min}} \right)^{\nu} = \frac{1}{2}.$  (57.11)

That is,

$$g_1^* = g_1^{\max} - \left(\frac{1}{2}\right)^{1/\nu}\left(g_1^{\max} - g_1^{\min}\right)$$

$$g_2^* = g_2^{\max} - \left(\frac{1}{2}\right)^{1/\nu}\left(g_2^{\max} - g_2^{\min}\right). \tag{57.12}$$

Once the target Pareto point $Q$ is determined, the MINIMAX goal programming is solved by finding $\xi^*$ subject to the constraint $\xi^{*\prime}\xi^* = 1$ and the distance $(Q, P^*)$, where $P^* = (g_1(\xi^*), g_2(\xi^*))$, is minimized.

## 57.4 Empirical Analysis

In this section, four different multivariate credit-scoring models are compared with each other, they are: (1) Principal component (PC) analysis; (2) Fisher’s discriminant analysis (FDA); (3) Stepwise discriminant (SDA) analysis by Pinches and Mingo (1973), and (4) Hybrid of principal component and Fisher’s discriminant analysis (HDA) using goal attainment programming (GP) approach. The rating data employed is from Pinches and Mingo (1973), in which a total of 132 industrial corporate bonds rated B, Ba, Baa, A, Aa based on Moody’s ratings from January 1, 1967 to December 31, 1968 are available for analysis. The basic types of the thirty-five financial variables collected are related to the legal status, one and five-year average financial variables, and coefficients of variation on these financial variables. Logarithm transformations were applied to part of the variables if necessary.
