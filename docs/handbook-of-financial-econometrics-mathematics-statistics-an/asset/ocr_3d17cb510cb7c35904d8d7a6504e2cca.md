By solving using the identity-matrix technique, the weights for the three securities can be obtained as follows:

$W_{\text{IBM}} = -0.8541,$
$W_{\text{JNJ}} = 0.7769,$
$W_{\text{JPM}} = 1.0772.$

We use the following relationship to rescale these weights so that the second constraint for the sum of the absolute values of the weights to equal one is satisfied:

$W_{|A|} = \frac{|A|}{|A| + |B| + |C|}$ (80.19)

The rescaled absolute weights are

$W_{\text{IBM}} = \frac{0.8541}{0.8541 + 0.7769 + 1.0772} = 0.3154$
$W_{\text{JNJ}} = \frac{0.7769}{0.8541 + 0.7769 + 1.0772} = 0.2869$
$W_{\text{JPM}} = \frac{1.0772}{0.8541 + 0.7769 + 1.0772} = 0.3978$

and
$W_{\text{IBM}} + W_{\text{JNJ}} + W_{\text{JPM}} = 1.$

The return on this portfolio is $\bar{R}_P = 0.3154 \times -0.0013 + 0.2869 \times 0.0079 + 0.3978 \times 0.0137 = 0.0073.$

The variance
$\sigma_P^2 = (0.3154)^2 \times 0.0226 + (0.2869)^2 \times 0.0404 + (0.3978)^2 \times 0.0581$
$\quad + 2 \times 0.3154 \times 0.2869 \times 0.0003 + 2 \times 0.3154 \times 0.3978 \times 0.0007 + 2 \times 0.2869 \times 0.3978 \times 0.0009 = 0.0152.$
