The GARCH(p,q) model is then able to trace some important stylized facts of financial time series such as the absence of the autocorrelation of returns, the autocorrelations of squared returns, volatility clustering and fat-tail distributions. This model gave tremendous influence on the areas of financial data analysis and financial risk management. It is well known that a simple GARCH(1,1) model will often fit real financial data in practice.

# 123.2.2 Asymmetric volatility models

# 123.2.2.1 GJR(p,q) model

Glosten, Jagannathan and Runkle (1993) (GJR) extended the GARCH(p,q) model to allow for the asymmetry impact of past positive and negative values on current volatility as follows:

h_t = ω + Σ_{i=1}^{q} (α_{i1} + α_{i2} J_{t-i}^-) ε_{t-i}^2 + Σ_{j=1}^{p} β_j h_{t-j}. (123.8)

where J_{t-i}^- = 1 if ε_{t-i} < 0, J_{t-i}^- = 0 otherwise, and ω > 0, α_{i1}, α_{i2} and β_j ≥ 0 (i = 1,...,q; j = 1,...,p). Negative returns tend to increase volatility more than positive returns if α_{i2} > 0. Consider, for example, a simple model of p = q = 1. Then, we have

h_t = ω + (α_{11} + α_{12}) ε_{t-1}^2 + β_1 h_{t-1}, ω > 0, α_{11} ≥ 0, α_{12} > 0, β_1 ≥ 0 if ε_{t-1} < 0, (123.9)

and h_t = ω + α_{11} ε_{t-1}^2 + β_1 h_{t-1}, ω > 0, α_{11} ≥ 0, β_1 ≥ 0 if ε_{t-1} ≥ 0. (123.10)
