# Case 2: A > 1.

In this case, we search for an integer H in the range {0, …, B} that maximizes φ(A − H, H). To this end, consider three subcases.

# Case 2.1: π_C(0) ≥ (γ−α)/β.

Then by Lemma 46.6, Δφ(A − H, H) is strictly decreasing in H with Δφ(A − 1, 1) ≤ 0 by equation (46.27), implying H* = 0 and G* = A.

# Case 2.2: π_C(0) < (γ−α)/β and there exists a minimal H′ ∈ {1, …, B}, such that Δφ(A − H′, H′) ≤ 0.

Then, H* = H′ − 1 by Lemma 46.6.

# Case 2.3: π_C(0) < (γ−α)/β and there does not exist H′ ∈ {1, …, B}, such that Δφ(A − H′, H′) ≤ 0.

Then, the maximum is obtained at the boundary where H* = B.

Finally, the first line of equation (46.28) follows by combining Cases 1 and 2.1, while the second line of equation (46.28) follows by combining Cases 2.2 and 2.3.

Theorem 46.4 comports with intuition concerning some special cases. For example, if the cost rate of investment capital, γ, exceeds the total cost rate of credit, α + β, then intuition suggests that the firm should allocate available funds to credit up to its allowed limit. Indeed, since γ > α + β implies (γ−α)/β > 1 ≥ Σ_{k=0}^{H−1} π_C(k) ≥ π_C(0), Theorem 46.4 shows that the maximal net profit rate, φ*, is attained at H* = B and G* = A − B. On the other hand, if the cost rate of investment capital, γ, does not exceed the fixed cost rate of credit, α, then intuition suggests that the firm should allocate all available funds to its own capital investment and none to credit. Indeed, since γ ≤ α implies π_C(0) > 0 ≥ (γ−α)/β, Theorem 46.4 shows that φ* is attained at H* = 0 and G* = A.

# 46.6.1.2 Optimization problem (B)

In this case, optimizing φ calls for a search on the decision variables triplet (S, G, H). However, the search can be structured to speed it up by reusing computed values of π as follows.

# Algorithm 46.2: (Search Procedure for the Optimal Net Profit Rate)

+   1. For each pair of S and A, compute π either analytically using Theorem 46.1 or numerically using Algorithm 46.1.
+   2. Given each π, derive the optimal values of G* and H* from Theorem 46.4. The corresponding value of φ is optimal for each given pair, (S, A).
