In general, the timing option value increases substantially as the number of transactions doubles.<sup>8</sup> For example, compared to the results for Scenario II in Table 128.10, the timing option value increases from 6.5% to 8.3% for 15-year bonds when interest rate volatility is 1% and coupon rate is 8%. The increase in timing option value is not as high for other tax scenarios.
