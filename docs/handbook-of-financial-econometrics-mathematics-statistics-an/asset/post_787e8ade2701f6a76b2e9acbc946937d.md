While a value of zero is reasonable for (μ_g^+)^2 / σ_g^2, it is not acceptable for ψ² because ψ is the slope of the asymptote to the minimum variance frontier and should be strictly positive. In this regard, we resort to Bayes method. Assume that ψ is located within the interval [0, Ψ] and the prior distribution is g(ψ), we take the expected value of posterior distribution as our Bayes estimator.

\hat ψ²_Bayes = { E[ ψ | \hat ψ² ] }² = { ∫_a^Ψ ψ f( ψ | \hat ψ² ) dψ }

= { ∫_a^Ψ ψ f( \hat ψ² | ψ ) g(ψ) dψ / ∫_a^Ψ f( \hat ψ² | ψ ) g(ψ) dψ }, (74.12)

where f( \hat ψ² | ψ ) is conditional distribution of \hat ψ² on ψ. f( \hat ψ² | ψ ) has an explicit form because \hat ψ² is non-central F-distributed.

The first source is from finite sample distribution of \hat{\psi}^2. The maximum value of raw estimate \hat{\psi}^2 over five years’ periods is 3.4789 on the European market during July 1990 and December 2017 (Table 74.3). Since \hat{\psi}^2 is non-central F distributed with non-centrality parameter T\psi^2, the 99% confidence interval of \psi for \hat{\psi}^2 = 3.4789 is [0.68,1.89] when T = 60 and N = 25. The second source is from the unbiased estimates \hat{\psi}^2_u with large samples. The data is from the US market as it has T = 1,098 monthly returns from July 1926 to December 2017. We use bootstrap technique to estimate the maximum value. We find that the maximum value of \hat{\psi}^2_u is 0.172603 by value-weighted returns, 0.192328 by equal weighted return. Thus, in the case of N = 25, using an upper bound of \Psi = 2.0 is a rather prudent assumption. We have noticed that \psi is related to N. For a larger N, investors can spread risk across more assets and achieve larger \psi. Here, we consider only the case that N is no larger than 25 because the 25 size and book-to-market portfolios are commonly used as testing portfolios in the asset pricing literature.

We assume asset return multivariate normally distributed and use simulation to evaluate bias and RMSE of six estimators. The true values of parameters are assumed to be estimates of \hat{\psi}^2_u, \hat{\mu}_g, \hat{\sigma}^2_{gu} by value-weighted monthly returns on the US market from July 1926 to December 2017: \psi^2 = 0.043037, \mu_g = 0.007426, \sigma^2_g = 0.001962 and S^2 = 0.071148. For the case of T = 60, which corresponds to five-year observations of monthly data, the raw maximum Sharpe ratio \hat{S}^2 is a rather rough estimate of squared maximum Sharpe ratio. Its bias and RMSE are more than 10 times of the true value.

But there is more than 30% chance of negative values making this estimator very unattractive. \hat{S}^2_{less_biased+} truncates negative estimates to zero but it is still not reasonable.
