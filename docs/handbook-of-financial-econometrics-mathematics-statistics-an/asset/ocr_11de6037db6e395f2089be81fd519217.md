The form of the panel threshold regression model is as shown in equations (22.4) and (22.5), or as specified in the following equation (22.6):

```
y_{i,t} = \mu_i + \beta_1 x_{i,t} + e_{i,t} \quad q_{i,t} < \gamma, \tag{22.4}

y_{i,t} = \mu_i + \beta_2 x_{i,t} + e_{i,t} \quad q_{i,t} \ge \gamma, \tag{22.5}

y_{i,t} = \mu_i + \beta_1 x_{i,t} I(q_{i,t} < \gamma) + \beta_2 x_{i,t} I(q_{i,t} \ge \gamma) + e_{i,t}, \tag{22.6}
```

where y_{i,t} is the dependent variable, a vector of regressors x_{i,t}. The threshold variable q_{i,t} may be an element of x_{i,t} and is used to split the sample into two groups with a threshold value of γ. I(·) is an indicator function assumes the value of 1 when the description in () is true, and zero otherwise. It is apparent that the slope coefficients β's depend on the given threshold value γ. It is thus important to determine whether the threshold effect is statistically significant. Thus, we present the hypothesis of no threshold effect as

```
H_0: \beta_1 = \beta_2.
```

Under the null hypothesis, the threshold γ is not identified, so the classical tests have nonstandard distributions (Hansen, 1999). Hansen (1996) developed the bootstrap procedure to simulate the asymptotic distribution of the likelihood ratio test based on equation (22.7). The asymptotic distribution of F_1 is nonstandard and dominates the χ_k^2 distribution. Hansen (1996) shows that a bootstrap procedure attains the first-order asymptotic distribution, so p-values are asymptotically valid.

```
F_1 = \frac{S_0 - S_1(\hat{\gamma})}{\hat{\sigma}^2}, \tag{22.7}
```

where S_0 is the sum of the squared error function of the null hypothesis, and S_1 is the sum of the squared error function of the alternative hypothesis. If the threshold effect is significant, then we test if the estimated \hat{γ} is consistent for the true value of the threshold γ. Hansen (1999) proposed the likelihood ratio statistic to form the confidence interval for γ, as in equation (22.8):

```
LR_1(\gamma) = \frac{S_1(\gamma) - S_1(\hat{\gamma})}{\hat{\sigma}^2}, \tag{22.8}
```

where S_1(γ) is the sum of the squared error function of the true value of the threshold γ, and S_1(\hat{γ}) is the sum of the squared error function of the estimated \hat{γ}. There is a single threshold in equation (22.6); in some applications
