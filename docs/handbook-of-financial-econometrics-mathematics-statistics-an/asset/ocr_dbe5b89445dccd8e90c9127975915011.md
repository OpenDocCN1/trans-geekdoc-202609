Sharpe’s argument, for when w_i = 0, it is possible to equate the slope of the curve iMi′ with the CML, thus obtaining an expression for the return on any risky security i. At equilibrium when w_i = 0, the slope along the iMi′ curve will be equal to

∂E(R_p)/∂σ(R_p) = [∂E(R_p)/∂w_i]/[∂σ(R_p)/∂w_i] = [E(R_i) − E(R_m)] / [(σ_im − σ_m²)/σ_m]. (79.7)

The slope of the CML at point M is

[E(R_m) − R_f]/σ_m. (79.8)

Setting equation (79.7) equal to equation (79.8) and rearranging the terms to solve for E(R_i) gives the equation for the SML or CAPM:

E(R_i) = R_f + [E(R_m) − R_f] σ_im/σ_m². (79.9)

This represents the return on any risky asset i. At equilibrium, every risky asset will be priced so that it lies along the SML. It should be noted that the term σ_im/σ_m² represents the beta coefficient for the regression of R_i versus R_m so that equation (9.9) can be rewritten as E(R_i) = R_f + [E(R_m) − R_f] β_i, (79.10) which is the formula for the CAPM.
