
## The Jump Behavior of a Foreign Exchange Market

The first equation in equation (52.1) is the observation (level) equation, and the second is the state (transition) equation. At a given time \(t\), the observation equation implies that the change in the exchange rate follows a normal distribution with mean \(d\) and variance \(h_{t-1}\). The state equation, by contrast, describes how the state variable \(h_t\) evolves over time. The variance for the next period is serially correlated with that of the current period. The covariance matrix of \(\varepsilon_t\) and \(u_t\) is

\[
\mathrm{var}(e_t) \equiv \Sigma \equiv \begin{pmatrix} 1 & \rho\sigma_v \\ \rho\sigma_v & \sigma_v^2 \end{pmatrix},
\]

where \(e_t \equiv (\varepsilon_t, u_t)'\).

If there is an asymmetric relationship in the time series, the rise or fall of the observation equation will affect the realization of the state variable and the correlation coefficient will not be zero. The correlation coefficient between the residuals of the observation and state equations is a measure of the leverage effect. In some financial time series, the leverage effect plays a significant role. For example, the leverage effect in the US stock market index is about \(-0.3\) to \(-0.5\) (Jacquier et al. 2004).

If we add a jump component to the observation equation, the model becomes

\[
\begin{aligned}
r_t &= d + \sqrt{h_{t-1}}\varepsilon_t + \xi_t^r J_t^r,\\
h_t &= \alpha + \delta h_{t-1} + \sqrt{h_{t-1}}u_t.
\end{aligned}
\tag{52.2}
\]

We refer to this as the SVJ. The jump component \(\xi_t^r J_t^r\) is a product of \(J_t^r\), which controls whether the jump occurs, and \(\xi_t^r\), which controls the size of the jump. The jump event variable \(J_t^r\) follows a Bernoulli distribution, with \(\Pr(J_t^r = 1) = \lambda_r\). The jump size variable \(\xi_t^r\) is normally distributed with mean \(u_r\) and variance \(\sigma_r^2\).

Moving one step further, we can add a jump component to the state equation as well. If the jump in the level and state equations is independent, we arrive at an SV model with independent jumps in the level and state equations (SVIJ). The SVIJ model can be written as follows:

\[
\begin{aligned}
r_t &= d + \sqrt{h_{t-1}}\varepsilon_t + \xi_t^r J_t^r,\\
h_t &= \alpha + \delta h_{t-1} + \sqrt{h_{t-1}}u_t + \xi_t^v J_t^v.
\end{aligned}
\tag{52.3}
\]

The jump event variable in the state equation \(J_t^v\) also follows a Bernoulli distribution, with \(\Pr(J_t^v = 1) = \lambda_v\). To ensure positive jump sizes in the state equation, \(\xi_t^v\) follows an exponential distribution with mean \(u_v\). With jump components in both the level and state equations, the SVIJ is the most flexible model.

An alternative setting has jumps in the level and state equations that happen simultaneously; this is called the SV model with contemporaneous jump in the level and state equations (SVCJ). In this setting, \(J_t^r = J_t^v\), and the jump size in the level and state equations has a correlation coefficient \(\rho_J\). Specifically, we can express the relations between jump sizes as

\[
\xi_t^v \sim \exp(u_v), \qquad
\xi_t^r \mid \xi_t^v \sim N(u_r + \rho_J \xi_t^v, \sigma_r^2).
\]

In our study, the log SV is also used for comparison. The model can be expressed as follows:

\[
r_t = d + \sqrt{h_t}\varepsilon_t, \qquad
\ln h_t = \alpha + \delta \ln h_{t-1} + u_t.
\]

The covariance matrix of \((\varepsilon_t, u_t)'\) is the same as that of the square root SV model. The difference lies in the state equation. To ensure that volatility is positive, the log SV model uses log to transform the equation. The log transformation also makes the state equation more flexible. A detailed discussion on the subject can be found in Jacquier et al. (2004).

### 52.2.2 The prior and posterior distributions

We adopted MCMC for model inference. MCMC is a simulation-based model inference approach that requires conditional posterior of parameters to function. Since SVJ, SVIJ, and SVCJ have similar structures, the following discussion will focus only on the SVIJ model. A similar discussion can be found in Eraker et al. (2003). Readers are referred to Johannes and Polson (2010) for a more comprehensive coverage of applying MCMC to continuous time financial time series models.

The parameters that need to be estimated are

\[
\theta = (d, \alpha, \delta, \rho, \sigma_v, u_v, u_r, \sigma_r^2, \lambda_r, \lambda_v)'
\]

plus the volatility of each period

\[
h = (h_1, h_2, \dots, h_T)'
\]

and jump-related latent variables, including

\[
J_r = (J_1^r, J_2^r, \dots, J_T^r)', \quad
J_v = (J_1^v, J_2^v, \dots, J_T^v)', \quad
\xi_r = (\xi_1^r, \xi_2^r, \dots, \xi_T^r)', \quad
\xi_v = (\xi_1^v, \xi_2^v, \dots, \xi_T^v)'.
\]

To derive the conditional posterior of parameters, we can take the jump status \(J_r, J_v, \xi_r, \xi_v\) as given and rearrange the model as

\[
\begin{aligned}
\tilde r_t &\equiv r_t - \xi_t^r J_t^r = d + \sqrt{h_{t-1}}\varepsilon_t,\\
\tilde h_t &\equiv h_t - \xi_t^v J_t^v = \alpha + \delta h_{t-1} + \sqrt{h_{t-1}}u_t.
\end{aligned}
\tag{52.4}
\]

Thus, we have

\[
\left( \begin{array}{c} \dfrac{\tilde r_t - d}{\sqrt{h_{t-1}}} \\[6pt] \dfrac{\tilde h_t - \alpha - \delta h_{t-1}}{\sqrt{h_{t-1}}} \end{array} \;\middle|\; \theta, h_{t-1}, \xi_t^r, \xi_t^v, J_t^r, J_t^v \right)
\sim N\left( \begin{pmatrix}0\\0\end{pmatrix}, \Sigma \right).
\]

Applying the change of variable technique, we get

\[
p(\tilde r_t, \tilde h_t \mid \theta, h_{t-1}, \xi_t^r, \xi_t^v, J_t^r, J_t^v)
\propto h_{t-1}^{-1}
p\left( \frac{\tilde r_t - d}{\sqrt{h_{t-1}}}, \frac{\tilde h_t - \alpha - \delta h_{t-1}}{\sqrt{h_{t-1}}} \;\middle|\; \theta, h_{t-1}, \xi_t^r, \xi_t^v, J_t^r, J_t^v \right).
\]

Let \(\tilde r = \{\tilde r_1, \tilde r_2, \dots, \tilde r_T\}\), \(\tilde h = \{\tilde h_1, \tilde h_2, \dots, \tilde h_T\}\); then

\[
\begin{aligned}
p(\tilde r, \tilde h \mid \theta, \xi^r, \xi^v, J)
&= p(\tilde r_1, \tilde h_1 \mid \bullet, h_0) p(\tilde r_2, \tilde h_2 \mid \bullet, h_1) \cdots p(\tilde r_T, \tilde h_T \mid \bullet, h_{T-1})\\
&\propto \prod_{t=1}^T p\left( \frac{\tilde r_t - d}{\sqrt{h_{t-1}}}, \frac{\tilde h_t - \alpha - \delta h_{t-1}}{\sqrt{h_{t-1}}} \;\middle|\; \bullet, h_{t-1} \right)\\
&\propto \prod_{t=1}^T |\Sigma|^{-1/2} e^{-\frac12 \operatorname{tr}(e_t \Sigma^{-1} e_t')}\\
&\propto |\Sigma|^{-T/2} e^{-\frac12 \operatorname{tr}(\Sigma^{-1} A)},
\end{aligned}
\]

where \(A = \sum_{t=1}^T e_t e_t'\).

To facilitate the estimation of the covariance matrix \(\Sigma\), we transform from \((\rho, \sigma_v)\) to \((\psi, \Omega)\) representation. That is,

\[
\Sigma = \begin{pmatrix} 1 & \rho \sigma_v \\ \rho \sigma_v & \sigma_v^2 \end{pmatrix}
= \begin{pmatrix} 1 & \psi \\ \psi & \psi^2 + \Omega \end{pmatrix}.
\]

Since \(|\Sigma| = \Omega\), we have

\[
\Sigma^{-1} = \frac{1}{\Omega} \begin{pmatrix} \psi^2 & -\psi \\ -\psi & 1 \end{pmatrix} + \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}
\equiv \frac{C}{\Omega} + \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}.
\]

Letting \(a_{ij}\) be the element at the \(ij\) position in matrix \(A\), we have

\[
\operatorname{tr}(\Sigma^{-1} A) = \frac{\operatorname{tr}(C A)}{\Omega} + a_{11}.
\]

As a result,

\[
p(\psi, \Omega \mid \tilde r, \tilde h, d, \alpha, \delta)
\propto \frac{1}{\Omega^{T/2}} e^{-\frac{\operatorname{tr}(C A)}{2\Omega}} \mathrm{pri}(\psi, \Omega)
\propto \frac{1}{\Omega^{T/2}} e^{-\frac{a_{22.1} + (\psi - \hat\psi)^2 a_{11}}{2\Omega}} \mathrm{pri}(\psi, \Omega),
\tag{52.5}
\]

where \(a_{22.1} = a_{22} - \frac{a_{12}^2}{a_{11}}\), \(\hat\psi = \frac{a_{12}}{a_{11}}\).

We assume a normal prior for \(\psi\) and an inverse gamma for \(\Omega\); that is,

\[
\mathrm{pri}(\psi, \Omega) = \mathrm{pri}(\psi \mid \Omega) \mathrm{pri}(\Omega)
\propto \exp\left( -\frac{(\psi - \psi_0)^2}{2\Omega / p_0} \right) \Omega^{-(v_0+1)} \exp\left( -\frac{\lambda_0}{\Omega} \right).
\]

Combining the last equation with equation (52.5), we get the posterior

\[
p(\psi, \Omega \mid \tilde r, \tilde h, d, \alpha, \delta)
= p(\psi \mid \Omega, \tilde r, \tilde h, d, \alpha, \delta) p(\Omega \mid \tilde r, \tilde h, d, \alpha, \delta)
\]

\[
\begin{aligned}
&\propto p(\tilde r, \tilde h \mid \psi, \Omega, d, \alpha, \delta) \mathrm{pri}(\psi \mid \Omega) \mathrm{pri}(\Omega)\\
&\propto \frac{1}{\Omega^{T/2}}
\exp\left( -\frac{a_{22.1} + (\psi - \hat\psi)^2 a_{11}}{2\Omega} \right)
\exp\left( -\frac{(\psi - \psi_0)^2}{2\Omega / p_0} \right)
\Omega^{-(v_0+1)}
\exp\left( -\frac{\lambda_0}{\Omega} \right)\\
&\propto
\exp\left( -\frac{(\psi - \tilde\psi)^2}{2\Omega / (p_0 + a_{11})} \right)
\Omega^{-(v_0 + T/2 + 1)}
\exp\left( -\frac{\lambda_0 + a_{22.1}/2}{\Omega} \right),
\end{aligned}
\]

where

\[
\tilde\psi = \frac{a_{11} \hat\psi + p_0 \psi_0}{a_{11} + p_0}.
\]

The result can be summarized as follows.

**Prior distribution:**

\[
\mathrm{pri}(\Omega) \sim IG(v_0, \lambda_0), \qquad
\mathrm{pri}(\psi \mid \Omega) \sim N(\psi_0, \Omega / p_0).
\]

**Posterior:**

\[
p(\Omega \mid \tilde r, \tilde h, d, \alpha, \delta) \sim IG(v_0 + T/2, \lambda_0 + a_{22.1}/2),
\]

\[
p(\psi \mid \Omega, \tilde r, \tilde h, d, \alpha, \delta) \sim N\left(\tilde\psi, \Omega / (a_{11} + p_0)\right).
\]

The posterior of \(\alpha\) and \(\delta\) follows standard time series estimation. We impose normal prior for \((\alpha, \delta)\); that is, \((\alpha, \delta)' \sim N(\beta_0, \Sigma_{\beta_0})\), where \(\beta_0\) is a \(2\times1\) vector and \(\Sigma_{\beta_0}\) is a \(2\times2\) matrix. Since \(\varepsilon_t\) and \(u_t\) are correlated, we have the following relation:

\[
u_t = \sigma_v \rho \varepsilon_t + b_{2,t}, \qquad b_{2,t} \sim N(0, (1-\rho^2)\sigma_v^2).
\]

Let

\[
y_h = \left( \frac{\tilde h_2}{\sqrt{h_1}} - \rho\sigma_v \varepsilon_2, \;
\frac{\tilde h_3}{\sqrt{h_2}} - \rho\sigma_v \varepsilon_3, \;
\ldots, \;
\frac{\tilde h_T}{\sqrt{h_{T-1}}} - \rho\sigma_v \varepsilon_T \right)'
\]

and \(x_h = (x_{h,1}, x_{h,2}, \ldots, x_{h,T-1})'\), where

\[
x_{h,t} = \left( \frac{1}{\sqrt{h_t}}, \frac{h_t}{\sqrt{h_t}} \right)'.
\]
