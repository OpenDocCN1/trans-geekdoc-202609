The multiplicative rule of matrices and vectors is used to show that equation (77.2b''') is indeed equal to equation (77.2b''). The rule for matrix multiplication requires “row-column multiplication”.

In order for any two matrices to be multiplied together, the number of columns in one must be equal to the number of rows in another. For example,

A = [2 1 0]_(1×3),  B = [[2, 0],[0, 3],[-1, 0]]_(3×2)

These two matrices can be multiplied together. An element in the ith row and jth column of the product AB is obtained by multiplying the ith row of A by the jth column of B. Therefore,

AB = [2 1 0] [[2,0],[0,3],[-1,0]] = [4 3].

We obtained the first element of AB from (2×2)+(1×0)+(-1×0)=4. To know how this is done for equation (77.2b'''), see the following steps:
