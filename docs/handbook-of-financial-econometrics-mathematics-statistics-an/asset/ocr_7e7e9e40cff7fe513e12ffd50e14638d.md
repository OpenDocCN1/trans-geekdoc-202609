⁶ This constraint ensures that the “uses-equals-sources” identity will hold for the estimated equations. First of all, we know that $\sum_i\iota_{ij}=1$, since

$$\iota_{ij}=\begin{cases}1-b_{ij}&\text{for }i=j,\\-b_{ij}&\text{for }i\ne j.\end{cases}$$

Therefore,

$$\sum_i\iota_{ij}=1_i-\sum_i b_{ij}=1-0=1.$$

In addition, it can be shown that $X^*_{i,t}=Y_t$. To show this, it is necessary only to show that

$$\sum_j\iota_{jk}=\begin{cases}0&\text{for all }k\ne4,\\1&\text{for all }k=4.\end{cases}$$

Note that $\iota_{ik}=\sum_j a_{ij}\iota_{jk}$. Since we have constrained
