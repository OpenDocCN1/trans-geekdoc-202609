# 112A.5 Non-normalized data

For non-normalized data, we used an original data directly from the sources without any modifications. The same data are being used for running time-series regressions. As the literature in NN suggested, using non-normalized data generated a bigger errors with high standard deviations as shown in the Table 112.5.
