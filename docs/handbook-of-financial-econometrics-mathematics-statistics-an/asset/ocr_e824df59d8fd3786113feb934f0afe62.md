Opler and Titman (2002) point out, the short-term borrowing ability of the firm at any time interval may be severely limited because of volatile earnings, restricted credit, or excessive short-term borrowing relative to long-term borrowing.

# 49.3.3 The objective function

Having written down all the cost factors for the interval i, we can now write the total cost T_i for the interval i as follows:

T_i = G_i + I_i + U_i + P_i + F_i + C_i + H_i + L_i
= σ_i(g_c + g_i Y_{1,i}) + Σ_{k=0}^{i} (Y_{1,k} + Y_{3,k}) s_i + θ_i(η + ω Y_{2,i})
+ μ_i{Z_{des,i} - (E_i - Y_{3,i})}·p_{di}
+ δ_i(α + β X_{N0+i,i}) + Σ_{j=1}^{N'} c_j X_{j,i} + Σ_{j=1}^{N'} (X_{j,i-1}·e_{j,i}·ε_{j,i} + ρ_i(D_i - B_i)).
(49.14)

The indicator parameter for the penalty cost, P_i, is

μ_i = 1   if Σ_{k=0}^{i} (Y_{3,k} - Y_{2,k}) + E_i > Z_{des,i}
= 0   otherwise.

Also,

μ_i = 0   if (E_i - Y_{3,i}) > Z_{des,i}.

In addition, the indicator parameter for the call premiums on bonds paid, H_i, is as follows

ε_{j,i} = 1   if X_{j,i} = 0
= 0   otherwise.

# 49.3.4 Discounting of total cost, T, in the interval i to its present value

If we define d_c as an appropriate discounting rate, then the discounted total cost, T'_i, is

T'_i = T_i / (1 + d_c)^i.
(49.15)

If the discount rate, d_c, is non-stationary over time, then

T'_i = T_i / Π_{k=1}^{i} (1 + d_k).
(49.16)
