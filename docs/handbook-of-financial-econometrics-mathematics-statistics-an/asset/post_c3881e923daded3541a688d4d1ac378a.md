
Recall the shape parameter ν_t controls the arrival rate of jumps of large sizes. To allow for the volatility clustering effect, this study assumes the shape parameter ν_t follows a nonlinear asymmetric NGARCH (p, q) process, p = q = 1, that depends on the previous return innovation ε_{t-1} and the shape parameter ν_{t-1}, respectively, as follows:

ν_t = a_0 + a(ε_{t-1} - c√{ν_{t-1}})^2 + bν_{t-1},  t ≥ 1.  (70.11)

for some c > 0. The time-varying parameter φ_t in (70.8) satisfies

φ_t = ν_t ln(1 - θ - σ²/2).  (70.12)

### Lemma 70.2.1. The unconditional skewness and kurtosis of log-return Y_t are

Skewness(Y_t) = [(2θ³ + 3θσ²)E(ν_t) + 3θ(θ² + σ²)Var(ν_t) + θ³E[(ν_t - E(ν_t))³]] / [[(θ² + σ²)E(ν_t) + θ²Var(ν_t)]^{3/2}],  (70.13)

Kurtosis(Y_t) = [(6θ²σ² + 3σ⁴)E(ν_t²) + (3σ⁴ + 6θ⁴ + 12θ²σ²)E(ν_t) + Q] / [[(θ² + σ²)E(ν_t) + θ²Var(ν_t)]²],  (70.14)

where Q = 6θ²(θ² + σ²){E(ν_t³) + E³(ν_t) - 2E(ν_t)E(ν_t²)} + 4(2θ⁴ + 3θ²σ²)Var(ν_t) + θ⁴E[(ν_t - E(ν_t))⁴].

Proof. See Appendix 70A.

The skewness and kurtosis of log-return Y_t depend on the drift θ, the volatility σ, and the first four moments of the shape parameter ν_t. Particularly, the sign of the skewness depends on that of the drift parameter θ. The following presents a closed-form solution for the unconditional mean of the shape parameter ν_t under restricted NGARCH parameters α = (a₀, a, b, c) in (70.11).

## 70.3 Monte Carlo EM & Metropolis Algorithm

The problem with the estimation of the VG NGARCH model (70.8)-(70.12) is that the random time-changes g₁, …, g_T are unobservable. To resolve the

problem, one possible solution is to consider the Monte Carlo EM algorithm to estimate the parameters Θ = (θ, σ, ν₁, α)′, where α = (a₀, a, b, c) are the NGARCH parameters in (70.11). To perform the Monte Carlo EM algorithm, at each iteration of the algorithm, a set of N samples of the unobservable random time-changes g₁, …, g_N, where g_s = (g_{s1}, …, g_{sT}), 1 ≤ s ≤ N, are drawn from the posterior distribution p(g|Y; Θ_{i−1}) (e.g., see Wei et al., 1990; McCulloch, 1997). However, no available random number generators can be used to sample the random time-changes g₁, …, g_N from the posterior distribution p(g|Y; Θ_{i−1}). Therefore, the independent Metropolis chain approach is considered to generate a random sample from the target distribution p(g|Y; Θ_{i−1}) (Metropolis et al., 1953; Hastings, 1970). In the following lemma, the posterior distribution p(g|Y; Θ_{i−1}) is derived.

### Lemma 70.3.1. The posterior distribution p(g|Y; Θ) for the random time-changes g = (g₁, …, g_T)′ is proportional to

$$p(g|Y;Θ) ∝ ∏_{t=1}^T exp{−κ g_t − δ_t / g_t + (ν_t − 1.5) log(g_t)}, \tag{70.15}$$
where ν_t is the time t-shape parameter, the coefficient κ = θ² / 2σ² + 1 and
$$δ_t = \frac{(Y_t − \bar{Y} − φ_t)^2}{2σ²}. \tag{70.16}$$

Proof. See Appendix 70C.

In the independent Metropolis chain algorithm, a chain of size L is generated as follows: at the nth step of the chain, if the chain is at a point X_n = x, a candidate value y is sampled from a proposal transition density f(y) for the next location X_{n+1}. The candidate X_{n+1} = y is accepted with probability
$$b(x, y) = \min\left\{ \frac{π(y) f(x)}{π(x) f(y)}, 1 \right\}.$$

An independent uniform random variate U is generated, if U < b(x, y), then X_{n+1} = y; otherwise, the step is rejected and the chain remains at X_{n+1} = x. After L such steps, where L is sufficiently large, a realization can be obtained from the target distribution.

Based on Lemma 70.3.1, the proposal transition density f of the target distribution, i.e., the posterior distribution p(g|Y; Θ), is chosen to be the distribution of T independent gamma random variables with shape parameters ν₁ − 0.5, …, ν_T − 0.5, respectively, and scale parameters 1/κ. Specifically,

the proposal transition density

$$f ∝ \prod_{t=1}^{T} \exp\left(-\kappa g_t + (\nu_t - 1.5)\log(g_t)\right). \quad (70.17)$$

The steps of the Metropolis chain algorithm are outlined as follows:

- (a) For $n = 1$ to $L$,
- (a.1) A random sample $\boldsymbol{g} = (g_1, \dots, g_T)'$ is drawn from the proposal transition density $\boldsymbol{f}$,
- (a.2) A random variate $U \sim Uniform(0,1)$ is generated, if $U < b$, then $\boldsymbol{g}_n = \boldsymbol{g}$, otherwise, $\boldsymbol{g}_n = \boldsymbol{g}_{n-1}$, where
  $$b = \min\left\{\exp\left(-\sum_{t=1}^{T}\left(\frac{\delta_t}{g_t} - \frac{\delta_t}{g_{t,n-1}}\right)\right),1\right\}.$$
- (b) $\boldsymbol{g}_L$ is one realization from the target distribution $p(\boldsymbol{g}|\boldsymbol{Y}; \Theta)$.

As the two models are non-nested, their goodness-of-fit is measured using the following three criteria: Akaike information criteria (AIC), Schwarz criteria (SC), and Hannan–Quinn criteria (HQ). The three criteria are calculated as follows:

AIC = −2ℓ/T + 2k/T; SC = −2ℓ/T + k log(T)/T;
HQ = −2ℓ/T + 2k log(log(T))/T, (70.19)

where k is the number of parameters and T is the sample size. The model that minimizes these information criteria values has the best fit.
