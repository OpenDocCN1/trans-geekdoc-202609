## 76.5.4.2 Bidder announcement returns

This section presents the empirical evidence for bidder announcement returns with respect to the use of financial advisors. The empirical analysis is the same as the analysis for target firms. As shown in Table 76.5, the results show that bidders on average obtain gains around the announcement date, but experience losses during the post-announcement period. For example, bidders obtain 3.16% cumulative abnormal returns for a 3-day (−1,+1) event window, but experience up to −13.15% cumulative abnormal returns over a 361-day (0,+360) post-announcement event window.

Taking into account the use of financial advisors, the evidence indicates that bidders hired by financial advisors on average earn lower announcement returns around the announcement date relative to those without using financial advisors. The evidence shows that bidders obtain 2.38% and 3.53% cumulative abnormal returns over a 3-day (−1,+1) event window for those with and without using financial advisors, respectively.

## 76.5.5 Cross-sectional regression analysis

This section runs OLS regression analysis to explore the relationship between different types of financial advisors and announcement returns for targets and bidders. If different types of financial advisors have more ability to advise the deals, it can be expected that firms can earn higher announcement returns. The dependent variables are cumulative abnormal returns for targets and bidders. While prior studies have reported the importance of deal and firm specific characteristics on firm performance, the regression analysis also controls for these characteristics. This enables the current study to further explore the determinants that can influence the announcement returns in M&As. The variables include cash payment, friendly deals, relatedness, market-to-book ratio, ROA and ln(total assets). In addition, prior studies reported that bidder announcement returns can differ when acquiring private targets. Bidder regression analysis also controls for private targets in the regression analysis. This allows the current study to further explore what factors can influence bidder announcement returns. To explore the relationship between different types of financial advisors and announcement returns precisely, I delete the top and bottom 1% of the sample for 3-day (−1,+1) and 271-day (0,+270) cumulative abnormal returns. This can reduce to obtain biased coefficients that are influenced by outliers.
