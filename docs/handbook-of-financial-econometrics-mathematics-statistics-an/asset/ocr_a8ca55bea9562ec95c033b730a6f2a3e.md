x̃_i's are normally distributed, then Anderson (2003) and others show that i is normally distributed. If x̄_i, σ_i² are the mean and the variance for x̃_i, respectively, and ρ_ij is the correlation coefficient between x̃_i and x̃_j, then the mean and variance of z̃ can be defined as

z̄ = Σ_{i=1}^m a_i x̄_i  (77.2a)

σ_z² = Σ_{i=1}^m a_i² σ_i² + 2 Σ_{i>j} Σ a_i a_j ρ_ij σ_i σ_j  (77.2b)

where the symbol Σ Σ_{i>j} denotes summation over all possible pairs of i and j values in the range from 1 through m, with the restriction that i is at least one greater than j. If i = 2, then

σ_z² = a_1² σ_1² + a_2² σ_2² + 2 a_1 a_2 ρ_12 σ_1 σ_2   (ρ_12 σ_1 σ_2 = σ_12).  (77.2b')

If i = 3, then σ_z² = a_1² σ_1² + a_2² σ_2² + a_3² σ_3² + 2 a_1 a_2 ρ_12 σ_1 σ_2 + 2 a_1 a_3 ρ_32 σ_1 σ_32 + 2 a_3 a_2 ρ_23 σ_3 σ_2.  (77.2b'')

# 77.2.2 Vectors, matrices, and their operations

In estimating financial z-scores, we need time-series ratio data in order to estimate the coefficients a_1, a_2, ..., a_m. Under this circumstance, the X_i's (i = 1, 2, ..., m) are vectors. If the current ratio (X_1) and the leverage ratio (X_2) are the only two ratios to be used in estimating z, then time-series financial ratio data can be written in terms of vectors as X_1 = [X_11; X_12; ⋮; X_1n] and X_2 = [X_21; X_22; ⋮; X_2n], where X_ij represents the ratio i in time period j. Vector X_1 and vector X_2 can be used to formulate a matrix of the ratios used in computing the financial z-score as follows: X = [[X_11, X_12]; [X_12, X_22]; [⋮, ⋮]; [X_1n, X_n2]].
