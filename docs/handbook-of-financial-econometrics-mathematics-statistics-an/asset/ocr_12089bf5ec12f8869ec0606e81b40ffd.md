We can apply invariant transformations to the system given in equations (61.18)-(61.20) (e.g., see Dai and Singleton, 2000 and Joslin, Singleton, Zhu, 2011a), to replace the original risk factors with portfolios of yields with weights obtained from the application of PCA PC_t (we define it below), and the Q-distribution (risk-neutral) of PC_t can be fully characterized by Θ_PC^Q = (κ_∞^Q, λ^Q, Σ_PC). The parameters of the P-distribution (historical) are (κ_OPC^P, κ_1PC^P Σ_PC). We can write this system as

ΔPC_t = κ_OPC^P + κ_1PC^P PC_{t-1} + Σ_PC ε_t^P. (61.25)
ΔPC_t = κ_OPC^Q + κ_1PC^Q PC_{t-1} + Σ_PC ε_t^Q. (61.26)
r_t = ρ_OPC + ρ_1PC PC_t. (61.27)

In equations (61.25)-(61.27), (κ_OPC^Q, κ_1PC^Q, ρ_OPC, ρ_1PC) are analytical (i.e., closed-form) functions of (κ_∞^Q, λ^Q, Σ_PC) owing to the invariant transformations. If we define PC_t = w y_t, then using equation (61.22),
