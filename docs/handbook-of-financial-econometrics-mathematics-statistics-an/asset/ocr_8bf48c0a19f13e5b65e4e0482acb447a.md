# A Comparative Static Analysis Approach to Derive Greek Letters

For a European put option on a non-dividend stock, delta can be shown as

Δ = N(d₁) - 1.

(86.6)

The derivation of equation (86.6) is

Δ = ∂Pₜ/∂Sₜ = X e^{-rτ} ∂N(-d₂)/∂Sₜ - N(-d₁) - Sₜ ∂N(-d₁)/∂Sₜ
= X e^{-rτ} ∂(1 - N(d₂))/∂d₂ · ∂d₂/∂Sₜ - (1 - N(d₁)) - Sₜ ∂(1 - N(d₁))/∂d₁ · ∂d₁/∂Sₜ
= -X e^{-rτ} (1/√(2π)) e^{-d₂²/2} · (Sₜ/X) · (1/(Sₜ σₛ √τ)) - (1 - N(d₁))
+ Sₜ (1/√(2π)) e^{-d₁²/2} · (1/(Sₜ σₛ √τ))
= -Sₜ (1/(Sₜ σₛ √(2πτ))) e^{-d₂²/2} - N(d₁) - 1 + Sₜ (1/(Sₜ σₛ √(2πτ))) e^{-d₁²/2}
= N(d₁) - 1.

If the underlying asset is a dividend-paying stock providing a dividend yield at rate q, Black-Scholes formulas for the prices of a European call option on a dividend-paying stock and a European put option on a dividend-paying stock are

Cₜ = Sₜ e^{-qτ} N(d₁) - X e^{-rτ} N(d₂),

and

Pₜ = X e^{-rτ} N(-d₂) - Sₜ e^{-qτ} N(-d₁),

where

d₁ = [ln(Sₜ/X) + (r - q + σₛ²/2)τ] / (σₛ √τ),

d₂ = [ln(Sₜ/X) + (r - q - σₛ²/2)τ] / (σₛ √τ) = d₁ - σₛ √τ.
