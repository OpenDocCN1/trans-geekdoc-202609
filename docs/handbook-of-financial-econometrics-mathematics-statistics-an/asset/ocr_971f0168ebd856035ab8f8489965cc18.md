Schroder (1989) expressed the CEV call option pricing formula in terms of the non-central Chi-square distribution:

When β < 2,

C = S_t Q(2y; 2 + 2/(2 - β), 2x) - e^{-rt} K(1 - Q(2x; 2 + 2/(2 - β), 2y)). (51.9)

When β > 2,

C = S_t Q(2x; 2 + 2/(2 - β), 2y) - e^{-rt} K(1 - Q(2y; 2 + 2/(2 - β), 2x)). (51.10)

Q(z; v, k) is a complementary non-central Chi-square distribution function with z, v, and k being the evaluation point of the integral, degree of freedom, and non-centrality, respectively, where

k = 2r / [δ²(2 - β)(e^{r(2-β)τ} - 1)]
x = k S_t^{2-β} e^{r(2-β)τ}
y = k K^{2-β}

The complementary non-central Chi-square distribution function can be expressed as an infinite double sum of gamma functions as follows⁸:

Q(2z; 2v, 2k) = 1 - Σ_{n=1}^{∞} g(n + v, z) Σ_{i=1}^{n} g(i, k). (51.11)

Schroder also presented a simple iterative algorithm to compute the infinite sum as follows:

+   (1) Initializing the following variables:

gA = e^{-z} z^{v} / Γ(1 + v)
gB = e^{-k}
Sg = gB
R = 1 - gA · Sg
where gA = g(1 + v, z) and gB = g(1, k).
