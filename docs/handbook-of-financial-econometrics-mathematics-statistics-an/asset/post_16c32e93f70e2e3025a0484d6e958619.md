
Based on equation (114.25), we can infinitely substitute the lagged firm return, and find out that the coefficient for the market return can be expressed as β_i2 (1 + β_i1 + β_i1² + β_i1³ + ⋯). And thus, provided that β_i1 is significantly different from 0, we can define the long run multiplier as follows:

LRM = β_i2 / (1 − β_i1). (114.31)

If β_i1 is not significantly different from 0 or violates the constraint by falling in the interval (−1,0], then LRM is β_i2.
