where $\bar h_t = (h_{11,t},\dots,h_{nn,t})'$, and $\bar \varepsilon_t = (\varepsilon_{1,t}^2,\dots,\varepsilon_{n,t}^2)'$ are $n \times 1$ vectors. If all elements of parameters $\omega$, $A_i$, $B_j$ are positive, and a correlation matrix $R$ is chosen positive definite, then the conditional covariance matrix is guaranteed positive definiteness. The parameters in this model are $\theta = (\mu,\Gamma_1,\dots,\Gamma_k;\omega,A_1,\dots,A_q;B_1,\dots,B_p;R)$. The number of parameters in equation (123.34) are $s = n + n^2(p+q) + \tfrac12 n(n-1)$. As a special case, if all $A_i$, $B_j$ are diagonal matrices, equation (123.34) reduces to

$h_{ii,t}=\omega_i+\sum_{j=1}^{q}\alpha_{ij}\varepsilon_{i,t-j}^2+\sum_{j=1}^{p}\beta_{ij}h_{ii,t-j};\quad i=1,\dots,n.\qquad(123.35)$

In equation (123.35), $h_{ii,t}$ depends on only the past values of itself and those of $\varepsilon_{i,t}^2$, but not the past values of the other $j$th variables ($j\neq i$). The CCC-GARCH$(p,q)$ model is simple and easy to handle. However, it is limited in its practical application since the assumption of constant correlation is unrealistic for most purposes.

Table 123.1 illustrates the number of parameters required for formulating the covariance $(H_t)$ in the various models. As shown, the VEC-GARCH model quickly increases as $n$ becomes large, while the diagonal CCC-GARCH remains relatively small even if the size of model $(n)$ is large.

# 123.3.2 Estimation of the CCC-GARCH(p,q) model

We can obtain the QMLE of the CCC-GARCH$(p,q)$ model in an analogous method to that in Section 123.2.3. The (negative) quasi log-likelihood function is apart from constant terms

$l_T(\theta)=l(\theta;Y_1,\dots,Y_T)=\frac12\sum_{t=1}^{T}l_t,\qquad(123.36)$

where $l_t=\log\det(\tilde H_t)+\tilde\varepsilon_t' H_t^{-1}\tilde\varepsilon_t,$

$\tilde\varepsilon_t=\tilde\varepsilon_t(\theta)=Y_t-\mu-\sum_{i=1}^{k}\Gamma_i Y_{t-i},\qquad(123.37)$

$\tilde H_t=\tilde H_t(\theta)=\tilde D_t R\tilde D_t$ where $\tilde D_t=\operatorname{diag}(\tilde h_{11,t}^{1/2},\dots,\tilde h_{nn,t}^{1/2}),\qquad(123.38)$

$\tilde h_t=\tilde h_t(\theta)=\omega+\sum_{i=1}^{q}A_i\tilde\varepsilon_{t-i}+\sum_{j=1}^{p}B_j\tilde h_{t-j},\qquad(123.39)$
