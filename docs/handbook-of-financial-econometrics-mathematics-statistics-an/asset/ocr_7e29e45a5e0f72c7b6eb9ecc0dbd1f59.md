# 80.3.1 Portfolio combinations

For each of the combinations of individual securities and inefficient portfolios in Figure 80.6, there is a corresponding portfolio along the efficient frontier that either has a higher return given the same risk or a lower risk given the same return. However, points on the efficient frontier do not dominate one another. While point Y has considerably higher return than point V, it also has considerably higher risk. The optimal portfolio along the efficient frontier is not unique with this model and depends upon the risk/return trade-off utility function of each investor.
