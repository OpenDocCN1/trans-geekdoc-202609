
Note that the baseline hazard function is canceled out in the HR, so there is no need to specify the baseline hazard function, which is a major advantage of the Cox PH model. Because $\beta^T x_i$ is still used for estimating the regression parameters, the Cox PH model is a semi-parametric model.

The HR does not reflect a time unit of the study. Because the hazard rate (hazard function) is an instantaneous risk that an event happens at time $t$, the HR can be simply interpreted as a relationship between the instantaneous hazards in two groups over the whole study time period.

## 120.5.2 Partial likelihood estimation

We still assume that there are $n$ independent individuals, and for each individual $i$, the data consist of three parts: the observed time $Y_i$, the event indicator $\delta_i$ and explanatory variables vector $\mathbf{x}_i$. The partial likelihood function can be written as

$$PL(\beta)=\prod_{i=1}^{n}\left[\frac{\exp(\beta^T\mathbf{x}_i)}{\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j)}\right]^{\delta_i}$$

in which $\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j)$ includes all individuals who are still at risk at the survival time $t_i$. Accordingly, the log-partial likelihood is

$$pl(\beta)=\sum_{i=1}^{n}\delta_i\left[\beta^T\mathbf{x}_i-\log\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j)\right].$$

The score function and the Fisher information matrix function of the log-partial likelihood are

$$U(\beta)=\frac{\partial pl(\beta)}{\partial\beta}=\sum_{i=1}^{n}\left[\delta_i\mathbf{x}_i-\frac{\sum_{t_j\ge t_i}\mathbf{x}_j\exp(\beta^T\mathbf{x}_j)}{\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j)}\right],$$

$$I(\beta)=-\frac{\partial^2 pl(\beta)}{\partial\beta\partial\beta^T}=\sum_{i=1}^{n}\left[\frac{\sum_{t_j\ge t_i}\mathbf{x}_j\mathbf{x}_j^T\exp(\beta^T\mathbf{x}_j)}{\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j)}-\frac{\sum_{t_j\ge t_i}\mathbf{x}_j\exp(\beta^T\mathbf{x}_j)\sum_{t_j\ge t_i}\mathbf{x}_j^T\exp(\beta^T\mathbf{x}_j)}{(\sum_{t_j\ge t_i}\exp(\beta^T\mathbf{x}_j))^2}\right].$$

Similar to parametric regression models, the Wald statistics, the score statistics and the likelihood ratio statistics are commonly used test statistics for semi-parametric models.

## 120.5.3 Tied data

The partial likelihood estimation might be invalid if two or more events occur at the same time, which is quite common for data with annual frequencies. The common remedies to handle tied survival time are Breslow's approximation and Efron's approximation. These methods usually take some computational time because they are based on the exact methods. Alternatively, we can consider the survival time as discrete. For example, the underlying continuous survival time can only be observed in certain intervals, which are commonly referred to as grouped time data or discrete time data. We will discuss it in a later section.

To apply the Cox PH model, we use the same data used in the parametric regression models. We use the following SAS code to estimate the Cox PH model using Efron's approximation to deal with ties.

```
proc phreg data=firms;
model dury*status(0) = age ad rd debt / ties=efron;
run;
```

### Cox PH model with Efron's approximation

| Parameter | Estimate | P-value |
|----------|----------|---------|
| age | -0.0856 | <0.0001 |
| ad | -0.2279 | 0.3938 |
| rd | -0.0344 | 0.5374 |
| debt | 0.0891 | 0.8655 |

It is not surprising that parameter estimates between parametric models and the Cox PH model are very similar. The age of the firm at t = 0 (age) is the only coefficient that is statistically significantly different from zero, while all other three covariates (i.e., advertising expense, R&D expenses and debt ratio) are not. The economic significance of the coefficient age from the Cox PH model can be obtained by calculating the hazard ratio, i.e., exp(−0.0856) = 0.918, which means the hazard of a firm being delisted or merged decreases 8.2% for a one-year increase in firm age. Similar calculations can be made to help interpret the coefficients for *ad*, *rd* and *debt*.

Note that the sign of the parameter estimates in the Cox PH model is opposite to that in the parametric regression models. The former estimates the hazard ratio, which indicates the occurrence of negative events, so the lower the better; while the parametric regression models estimate the survival time, so the longer the better.

## 120.5.4 Time-dependent covariates

Another advantage of the Cox PH models is that it can fit time-dependent covariates in the model. In previous examples using the firm data, all covariates, *age*, *ad*, *rd* and *debt* are time-independent, which means they are covariates measured at the baseline (*t* = 0). It is possible that the age of a firm when it was delisted or merged is of more interest to researchers. Further, advertising expenses, R&D expenses and debt ratios can vary by year, which means these covariates can also be time-dependent. The Cox PH model can be used to estimate time-dependent covariates. When we apply it to a data based on time-dependent covariates, we get results that are similar to those based on time-independent covariates. The data handling and model estimation require the counting process formation, and results will not be shown in this chapter. Interested readers could refer to Andersen and Gill (1982) and Kalbfleisch and Prentice (2002).

## 120.6 Other Applications

### 120.6.1 Discrete time data

The previous section introduces Breslow’s approximation or Efron’s approximation to handle tied survival time that is assumed to be continuous. If there are many cases of tied survival time, we can consider the survival time as discrete. If the underlying continuous survival time can only be observed in certain intervals, the data are commonly referred to as grouped time data or discrete time data.

Define the probability of an individual *i* experiencing an event at time *t* as $P_{it}$ and $P_{i0}=1$. The odds that an individual *i* has an event at time *t* given that the individual did not already have an event is given by $$O_{it}= \frac{P_{it}}{1-P_{it}}.$$

The proportional odds model assumes $O_i(t) = \psi O_0(t)$ for all $t$, where $O_0$ denotes the baseline odds function. By incorporating the covariates, the model can be expressed as

$O_i(t) = O_0(t) \exp(\beta^{T} \mathbf{x}_i)$

where $\beta$ is the unknown regression parameters and $O_0$ is an unspecified baseline odds function. For any two individuals, $i$ and $j$, the ratio of their odds can drop out of the baseline hazard function because they are canceled out:

$\frac{O_i(t)}{O_j(t)} = \frac{O_0(t) \exp(\beta^{T} \mathbf{x}_i)}{O_0(t) \exp(\beta^{T} \mathbf{x}_j)} = \exp[\beta^{T} (\mathbf{x}_i - \mathbf{x}_j)]$.

Similar to the Cox PH model, the ratio of the odds does not depend on time $t$. Sometimes, the proportional odds model is also called the Cox PH model for discrete time data. The proportional odds model can be estimated by a standard maximum likelihood method through the traditional logistic regression model.

Now we apply the proportional odds model to the same firm data used in parametric regression models and Cox PH model. Before using the logistic regression model to estimate proportional odds model, we need to expand the original data from one record per firm to multiple year records per firm.

```
data firmsc;
  set firms;
  do year = 1 to dury;
    if year=dury and status = 1 then event=1;
      else event=0;
      output;
  end;
run;

proc logistic data=firmsc;
  model event(desc)=age ad rd debt;
run;
```

The output of the parameter estimation is the following:

**Proportional odds model**

| Parameter | Estimate | P-value |
|-----------|----------|---------|
| *age* | -0.1151 | <0.0001 |
| *ad* | -0.2698 | 0.3168 |
| *rd* | -0.0475 | 0.4402 |
| *debt* | 0.1342 | 0.8252 |

It is not surprising that the results between the Cox PH model and proportional odds model are similar. The interpretation of parameter estimates from the two models is similar too. Instead of calculating the hazard ratio, the economic significance of the coefficients from the proportional odds model can be obtained by calculating the odds ratio. For example, the odds ratio of age is exp(-0.1151) = 0.891, which means the odds of a firm being delisted or merged decreases 10.9% for a one-year increase in firm age. Similar to earlier results, all other three covariates (i.e., advertising expense, R&D expenses and debt ratio) are not statistically significant.

Note that covariates are measured at the time of drastic price decline, and do not vary in time. For an example exploring the impact of the changes in the annual observations of covariates, please refer to Shumway (2001) who estimates a discrete-time hazard model with time-varying covariates.

### 120.6.2 Competing risks

In survival data, an event could be of different types instead of the same type. For example, the death in an oncology trial might be due to cancer progression, or clinical disease progression, or other adverse events. The different risks (or different event types) to which an individual is exposed is referred to as competing risks. More details are discussed by Cox and Oakes (1984) and Lawless (2002).

In competing risks analysis, it is often assumed that survival times are independent across different types and the event types are mutually exclusive to one another; that is, if one type of event happens, then none of other types of event can be observed.
