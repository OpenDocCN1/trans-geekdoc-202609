## Appendix 100A Modeling of the Price Process

In Section 100.2.3, equation (100.16) is derived from equation (100.15) under the assumption that all countries’ index series follow a random walk process. Thus, before further discussion, we should test the order of integration of these price series. From Hamilton (1994), we know that two widely used unit root tests are the Dickey–Fuller (DF) and the augmented Dickey–Fuller (ADF) tests. The former can be represented as follows: $P_t = \mu + \gamma P_{t-1} + \varepsilon_t$, and the latter can be written as follows: $\Delta P_t = \mu + \gamma P_{t-1} + \delta_1 \Delta P_{t-1} + \delta_2 \Delta P_{t-2} + \cdots + \delta_p \Delta P_{t-p} + \varepsilon_t$.

Similarly, in the US stock markets, the Phillips–Perron test is used to check whether the value-weighted price of market portfolio follows a random walk process. The results of the tests for each index are summarized in Table 100A.1. It seems that one cannot reject the hypothesis that all indices follow a random walk process since, for example, the null hypothesis of unit root in level cannot be rejected for all indices but are all rejected if one assumes there is a unit root in the first-order difference of the price for each portfolio. This result is consistent with most studies that find that the financial price series follow a random walk process.

## Appendix 100B Identification of the Simultaneous Equation System

Note that, given G is non-singular, Π = −G⁻¹H in equation (100.19) can be written as follows:

AW = 0, (100B.1)

where

A = [G H] = ( g11 g12 … g1n h11 h12 … h1n ; g21 g22 … g2n h21 h22 … h2n ; ⋮ ⋮ ⋱ ⋮ ⋮ ⋮ ⋱ ⋮ ; gn1 gn2 … gnn hn1 hn2 … hnn )

W = [Π I_n]' = ( π11 π12 … π1n 1 0 … 0 ; π21 π22 … π2n 0 1 … 0 ; ⋮ ⋮ ⋱ ⋮ ⋮ ⋮ ⋱ ⋮ ; πn1 πn2 … πnn 0 0 … 1 )

That is, A is the matrix of all structure coefficients in the model with dimension of (n × 2n), and W is a (2n × n) matrix. The first equation in (100B.1) can be expressed as

A1W = 0, (100B.2)

where A1 is the first row of A, i.e., A1 = [g11 g12 … g1n h11 h12 … h1n].

Since the elements of Π can be consistently estimated, and In is the identity matrix, equation (100B.2) contains 2n unknowns in terms of π’s. Thus, there should be n restrictions on the parameters to solve equation (100B.2) uniquely. First, one can try to impose normalization rule by setting g11 equal to 1 to reduce one restriction. As a result, there are at least n − 1 independent restrictions needed in order to solve (100B.2).
