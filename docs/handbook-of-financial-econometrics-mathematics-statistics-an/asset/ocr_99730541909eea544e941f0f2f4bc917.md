# 81.4 Summary

This chapter has discussed the essentials of single- and multiple-index models. The theoretical underpinnings of the theories have been explored and numerical examples have been provided. An efficient boundary has been derived under the guidelines of the model and the quantitative analysis of the related parameters has been studied. It has been shown that both single-index and multi-index models can be used to simplify the Markowitz model for portfolio section; remember, however, that the MIM is much more complicated than the single-index model.
