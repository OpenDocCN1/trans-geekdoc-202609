+   - Shocks affecting all cross-sections i = 1, …, N at a particular t imply correlation between e_it and e_jt ∀ i ≠ j.
+   - ⇒ LS inefficient, inconsistent estimate of the covariance matrix.

If E(e_it|X_it) ≠ 0 then LS is inconsistent (e.g., if X_it contains lagged dependent variables and e_it are autocorrelated).

# 28.9 Error Component Models

The two most popular modeling approaches for panel data specify the error term in (28.22) to be composed of separate shocks, e.g.,

e_it = u_t + v_i + ε_it, (28.23)

where u_t are unobserved effects for time t, v_i affects all cross-sectional observations i, and ε_it is the common error that affects observation it.

It is generally assumed that the u_t, v_i and ε_it are independent across all t, i, and it, respectively.

# 28.10 Fixed Effects (FE) Models

In estimating the model, the u_t and v_i are specified as either FE or RE.

+   - **Fixed Effects (FE)**: parameters to be estimated, can be estimated using dummy variables (the so-called LSDV estimator) or by group mean differencing and LS.
+   - **Random Effects (RE)**: the e_it covariance matrix is specified as functions of the variances of the u_t, v_i, and ε_it. FGLS, ML or GMM estimators can be used for estimation.

Joint hypothesis tests of the effects can be carried out with an F-test (for the FE model) or Wald, LR, or LM test (RE model). A Durbin, Wu, Hausman test can be used to choose between the FE and RE specifications of the model.
