# Appendix 124A Theoretical Models

| References | Theoretical models | Summary |
|---|---|---|
| Bertrand, Duflo, and Mullainathan (2004) | $Y_{igt}=A_t + B_g + X_{gt}eta + Z_{igt}\gamma_{gt} + v_{gt} + u_{igt}$ | This chapter introduces the model that can be used for DID analyses in a setting with multiple groups and periods. The coefficient(s) of $\beta$ is(are) the DID estimator(s), capturing the treatment effect. |
| Greene (2008) | $\Delta y_i = \theta + (\Delta X_i)'\beta + u_i$ | This chapter uses the first-difference model to conduct DID analyses. The treatment effect would be the constant, $\theta$, in the model. |
| Wooldridge (2016) | $Y = \beta_0 + \beta_1 dT + \beta_2 dB + \delta_1 dT^* dB + e$ | This chapter explains the model that can used for DID analyses in the simplest setting: two groups and two periods. The treatment effect can be estimated by the coefficient on the interaction term, $\delta_1$. |

| Card and Krueger (1994) | $\Delta E_i = a + b \Delta X_i + c NJ_i + \varepsilon_i$ | This chapter uses the first-difference method to estimate the effect of minimum wage legislation on average employment in New Jersey in 1992.
