U occurs:

$U_i = N_1 N_2 + \frac{N_i(N_i + 1)}{2} - \sum R_i,$ (105.2)

with $R_i$ is the sum of ranks within each advocacy group and $N_i$ the sample size of each of the five advocacy groups, e.g., the number of values from the first sample is $N_1$.

After running the U-test with SPSS the output shows the test statistic U and again also the $p$-value. If the sample has an extent which is covered by the two-tailed Mann–Whitney table, then an examination of significance is possibly based on these critical values. Otherwise, a large sample approximation has to be performed where a $z$-score is calculated and evaluated against the normal distribution. The last case applies on the advocacy group analysis in this study so a comparison between an asymptotic significance against the desired significance threshold offers information concerning the significance.¹⁴
