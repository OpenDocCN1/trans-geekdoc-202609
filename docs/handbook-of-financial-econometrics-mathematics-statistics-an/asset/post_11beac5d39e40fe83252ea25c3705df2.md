of CDGJ begins with the following approximation for the yield curve

$$y(t, \tau) \approx \sum_{i=1}^{3} f_k(\tau) P_k(t) = f_1(\tau)P_1(t) + f_2(\tau)P_2(t) + f_3(\tau)P_3(t). \quad (61.31)$$

In this approximation, $P_k(t)$ is the time-$t$ realization of the $k$th principal component and $f_k(\tau)$ is the factor loading obtained from PCA as a function of $\tau$. The derivative of this yield curve function for the $n$th order is given by

$$\frac{\partial^n y(t, \tau)}{\partial \tau^n} \approx \sum_{i=1}^{3} \frac{\partial^n f_k(\tau)}{\partial \tau^n} P_k(t) = \frac{\partial^n f_1(\tau)}{\partial \tau^n} P_1(t) + \frac{\partial^n f_2(\tau)}{\partial \tau^n} P_2(t) + \frac{\partial^n f_3(\tau)}{\partial \tau^n} P_3(t).$$

To construct the nth order derivative of the factor loading function, CDGJ (2008) employ a linear polynomial to approximate $f_1(\tau)$, a quadratic for $f_2(\tau)$, and a cubic for $f_3(\tau)$. Then, they run a regression of $f_1(\tau)$ on a constant and a vector that is linear in $\tau = \{1,3,6,9,12\}$ months and evaluate the derivative at $\tau = 0$ for each day in the sample. Next, they run a regression of $f_2(\tau)$ on a constant and a vector that is linear in $\tau = \{1,3,6,9,12\}$ months and then one that is quadratic in the same vector and evaluate the derivative at $\tau = 0$ for each day in the sample. Finally, they run a regression of $f_3(\tau)$ on a constant and a vector that is linear in $\tau = \{1,3,6,9,12\}$ months, one that is quadratic in it, and one that is cubic in it, and evaluate the derivative at $\tau = 0$ for each day in the sample. The resulting coefficients are used to construct the first and second derivatives of the yield curve at short maturities. The above approximate expression for the yield curve will be used to form the level of the yield curve. We begin by defining the state vector with the following $\mathbb{Q}$ dynamics:

$$dx_i = m_i^{\mathbb{Q}}(\{x\})dt + \sum_{k=1}^{N} \sigma_{ik}(\{x\})dz_k^{\mathbb{Q}}. \quad (61.32)$$

Then, we assume that the spot rate is given as a general function of the aforementioned state vector $r \equiv r(\{x\})$. Through the usage of Ito's Lemma and shorthand notations $m_i^{\mathbb{Q}} = m_i^{\mathbb{Q}}(\{x\})$ and $\sigma_{ik} = \sigma_{ik}(\{x\})$, we can write
the dynamics of r(t)

$$dr = \sum_{i=1}^N \frac{\partial r}{\partial x_i} \left[ m_i^{\mathbb{Q}} dt + \sum_{k=1}^N \sigma_{ik} dz_k^{\mathbb{Q}} \right] + \frac{1}{2} \sum_{i,j,k=1}^N \frac{\partial^2 r}{\partial x_i \partial x_j} \sigma_{ik} \sigma_{jk} dt$$ $$= \sum_{i=1}^N \frac{\partial r}{\partial x_i} m_i^{\mathbb{Q}} + \sum_{i=1}^N \frac{\partial r}{\partial x_i} \sum_{k=1}^N \sigma_{ik} dz_k^{\mathbb{Q}} + \frac{1}{2} \sum_{i,j,k=1}^N \frac{\partial^2 r}{\partial x_i \partial x_j} \sigma_{ik} \sigma_{jk} dt$$ $$= \left[ \sum_{i=1}^N \frac{\partial r}{\partial x_i} m_i^{\mathbb{Q}} + \frac{1}{2} \sum_{i,j,k=1}^N \frac{\partial^2 r}{\partial x_i \partial x_j} \sigma_{ik} \sigma_{jk} \right] dt + \sum_{i=1}^N \frac{\partial r}{\partial x_i} \sum_{k=1}^N \sigma_{ik} dz_k^{\mathbb{Q}}. \tag{61.33}$$

$$\mu_{1t} = \frac{1}{dt} E_t^{\mathbb{Q}} (dr) = \sum_{i=1}^N \frac{\partial r}{\partial x_i} m_i^{\mathbb{Q}} + \frac{1}{2} \sum_{i,j,k=1}^N \frac{\partial^2 r}{\partial x_i \partial x_j} \sigma_{ik} \sigma_{jk}. \tag{61.34}$$

We can apply the Ito formula one more time to see that

$$\mu_{2t} = \frac{1}{dt} E_t^{\mathbb{Q}} (d\mu_{1t}) = \sum_{i=1}^N \frac{\partial \mu_1}{\partial x_i} m_i^{\mathbb{Q}} + \frac{1}{2} \sum_{i,j,k=1}^N \frac{\partial^2 \mu_1}{\partial x_i \partial x_j} \sigma_{ik} \sigma_{jk}. \tag{61.35}$$

$$V(t) = \frac{1}{dt} \operatorname{Var}_t^{\mathbb{Q}}[dr] = \frac{1}{dt} \left[ E_t^{\mathbb{Q}}[dr^2] - \left(E_t^{\mathbb{Q}}[dr]\right)^2 \right]. \tag{61.36}$$
