# Step II.

To ensure the positive definiteness of Σ(β), we employ Zou et al.’s (2017) Algorithm 1 to obtain the constrained OLS (OLS+) estimator $\hat{β}_{p,OLS+} = \arg\min_{β∈ℬ} D_p(β)$. Note that one can use $\hat{β}_{p,OLS}$ as the initial value in this iterative algorithm.

# Step III.

Obtain the unconstrained FGLS estimator $\hat{β}_{p,FGLS}$ by minimizing $\tilde{D}_p(β) := \text{vec}^T(YY^T - Σ(β)) (\hat{Σ}^{-1} ⊗ \hat{Σ}^{-1})\text{vec}(YY^T - Σ(β)), \quad (113.5)$ where $\hat{Σ}^{-1} = Σ^{-1}(\hat{β}_{p,OLS+})$ is a consistent estimator of $Σ^{-1}$, $⊗$ represents the Kronecker product of two matrices, and $\text{vec}(G)$ denotes the vectorization for any generic matrix $G$. After simple algebraic simplification, (113.5) can be re-expressed as $\tilde{D}_p(β) := \|\hat{Σ}^{-1/2} YY^T \hat{Σ}^{-1/2} - \hat{Σ}^{-1/2} Σ(β) \hat{Σ}^{-1/2}\|_F^2. \quad (113.6)$ Then consider the following transformations $\tilde{Y} = \hat{Σ}^{-1/2} Y, \tilde{W}_k = \hat{Σ}^{-1/2} W_k \hat{Σ}^{-1/2}, \text{and } \tilde{Σ}(β) = \sum_{k=0}^m β_k \tilde{W}_k.$ It can be demonstrated that the unconstrained FGLS estimator $\hat{β}_{p,FGLS}$, obtained from the objective function (113.5) via $\{Y, Σ(β)\}$ is the same as the unconstrained OLS estimator, $\hat{β}_{p,OLS}$, obtained from the objective function (113.3) via the transformed $\{\tilde{Y}, \tilde{Σ}(β)\}$.

# Step IV.

To ensure the positive definiteness, the resulting constrained FGLS (FGLS+) estimator, $\hat{β}_{p,FGLS+} = \arg\min_{β∈ℬ} \tilde{D}_p(β)$ obtained from the objective function (113.5) via $\{Y, Σ(β)\}$ is the same as the constrained OLS estimator, $\hat{β}_{p,OLS+}$, obtained from the objective function (113.3) via the transformed $\{\tilde{Y}, \tilde{Σ}(β)\}$. Note that one can use $\hat{β}_{p,FGLS}$ as the initial value in the iterative algorithm. Instead of the constrained FGLS estimator, Zou et al. (2017) proposed the maximum likelihood estimation (MLE) approach. Specifically, under the assumption that $Y$ follows a multivariate normal distribution with mean 0 and covariance $Σ(β) = \text{cov}(Y)$, the maximum likelihood estimator $\hat{β}_{p,MLE}$ can be obtained by maximizing the following log-likelihood function, $\ell_p(β) = -\frac{p}{2} \log(2π) - \frac{1}{2} \sum_{j=1}^p \log λ_j(Σ(β)) - \frac{1}{2} Y^T Σ^{-1}(β) Y, \quad (113.7)$ where $λ_j(Σ(β))$ are the $j$th largest eigenvalues of $Σ(β)$ for $j = 1, …, p$.
