Table 13.9 shows the changes in diversification benefits when independent variable changes in a size of one standard deviation. We perform this analysis on the value with short-sales restriction with diversity of 10 to be consistent with the tests in Tables 13.6 to 13.8. The results from using other diversities are qualitatively similar. Consistent with the regression analysis in previous sections, relative Sharpe ratio is the most important factor for both measures of diversification benefit. For an increase in the risk-adjusted premium (δ) relative Sharpe ratio is followed by adjusted R², volume, default risk premium, and T-bond yield. Turnover, exchange rate risk, GDP growth, and P/E are the least important. For a decrease in risk (ε), relative Sharpe ratio is followed by volume, WPI growth, default risk premium, and adjusted R² whereas turnover, exchange rate risk, GDP growth and number of listed companies have the weakest effect on a decrease in risk.
