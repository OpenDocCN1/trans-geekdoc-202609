### 64.2.2 The Kalman filter

Given the time series of observable vector $y_t$, $t = \{0,1,\dots,T\}$, the latent state vector $x_t$ can be filtered by the Kalman filter (KF) (Kalman, 1960). Let $x_{t|\tau}$ denote the best linear mean-squared estimate of $x_t$. Given all observed data up to time $\tau$, we obtain $x_{t|\tau}$ and its covariance matrix via the following algorithm:

- 1. Predict the mean of state vector $x_{t|t-1} = H x_{t-1|t-1}$;
- 2. Predict the covariance matrix of state vector $\Sigma_{t|t-1,x} = H \Sigma_{t-1|t-1,x} H' + W W'$;
- 3. Predict the covariance matrix of observable vector $\Sigma_{t|t-1,y} = G \Sigma_{t|t-1,x} G' + V V'$;
- 4. Predict the covariance matrix of state and observable vectors $\Sigma_{t|t-1,xy} = \Sigma_{t|t-1,x} G'$;
- 5. Compute the Kalman gain $K_t = \Sigma_{t|t-1,xy} \Sigma_{t|t-1,y}^{-1}$;
- 6. Update the mean of state variable $x_{t|t} = x_{t|t-1} + K_t (y_t - G x_{t|t-1})$; and
- 7. Update the covariance matrix of state variable $\Sigma_{t|t,x} = \Sigma_{t|t-1,x} - \Sigma_{t|t-1,x} G' \Sigma_{t|t-1,y}^{-1} G \Sigma_{t|t-1,x}$.

Here, $x_{t|t-1}$ and $\Sigma_{t|t-1,x} = E[(x_t - x_{t|t-1})(x_t - x_{t|t-1})']$ are predicted mean and covariance matrix of state vector $x_t$, while $x_{t|t}$ and $\Sigma_{t|t,x} = E[(x_t - x_{t|t})(x_t - x_{t|t})']$ are the updated mean and covariance matrix of state vector $x_t$.

### 64.3.2 The extended Kalman filter

The extended Kalman filter (EKF) relies on a first-order Taylor expansion of the transition equation around x_{t-1} and the measurement equation around the predicted state vector x_{t|t-1}. The above system can then be written as follows:

x_t = H_{t-1} x_{t-1} + W w_t,

y_t = G_t x_t + V v_t.

### 64.3.3 The unscented Kalman filter

Unlike the EKF, the unscented Kalman filter (UKF) uses the exact nonlinear functions and does not linearize the equations. Instead, the UKF approximates the conditional distribution of x_{t|t-1} and using the scaled unscented transformation (Julier, 2000), which can be defined as a method for computing the statistics for a nonlinear transformation of a random variable. Julier and Uhlmann (2004) prove that such an approximation is accurate to the third order for Gaussian states and to the second order for non-Gaussian states. Because the approximation does not require computation of the Jacobian or Hessian matrices, the computational burden associated with the UKF is comparable to that of the EKF. The algorithm is as follows:

- 1. Perform the state prediction:
  - (1) Draw sigma points χ_{t-1} = [x_{t|t-1}, x_{t|t-1} ± √(k+δ) Σ_{t|t-1,x} ], where k is the number of states and δ = α²(k+κ) - k is a scaling parameter, α usually between 10^{-4} and 1 and determines the spread of the sigma points. κ is a secondary scaling parameter usually set to zero;
  - (2) For each sigma point, compute χ_{t|t-1,i} = h(χ_{t-1,i});
  - (3) Compute the predicted state mean x_{t|t-1} = Σ_{i=0}^{2k} w_i^m χ_{t|t-1,i}, where w_0^m = δ/(k + δ), w_i^m = 1/[2(k + δ)]; and
  - (4) Compute the predicted state covariance matrix Σ_{t|t-1,x} = Σ_{i=0}^{2k} w_i^c (χ_{t|t-1,i} - x_{t|t-1})(χ_{t|t-1,i} - x_{t|t-1})ᵀ + WWᵀ, where w_i^c is the weight for each point. w_0^c = δ/(k + δ) + (1 - α² + β), w_i^c = 1/[2(k + δ)]. β is used to incorporate prior knowledge of the distribution of x. It is optimal to set β = 2 if x is Gaussian.

- 2. Perform the measurement prediction:
  - (1) Re-draw sigma points χ_t = [x_{t|t-1}, x_{t|t-1} ± √((k + δ)Σ_{t|t-1,x})];
  - (2) Record η_{t,i} = g(χ_{t,i}); and
  - (3) Compute the predicted observable vector y_{t|t-1} = Σ_{i=0}^{2k} w_i^m η_{t,i}.

- 3. Update the measurement equation:
  - (1) Predict the covariance matrix of observable vector Σ_{t|t-1,y} = Σ_{i=0}^{2k} w_i^c (η_{t,i} - y_{t|t-1})(η_{t,i} - y_{t|t-1})ᵀ + VVᵀ;
  - (2) Predict the covariance matrix of state and observable vectors Σ_{t|t-1,xy} = Σ_{i=0}^{2k} w_i^c (χ_{t,i} - x_{t|t-1})(η_{t,i} - y_{t|t-1})ᵀ;
  - (3) Compute the Kalman gain K_t = Σ_{t|t-1,xy} Σ_{t|t-1,y}^{-1};
  - (4) Update the mean of state variable x_{t|t} = x_{t|t-1} + K_t (y_t - y_{t|t-1}); and
  - (5) Update the covariance matrix of state variable Σ_{t|t,x} = Σ_{t|t-1,x} - K_t Σ_{t|t-1,y} K_tᵀ.

### 64.3.4 Application

The most popular implementation of the Kalman filter in economics and finance is the EKF. It can be computed very quickly when the explicit forms of Jacobian matrices of the nonlinear transition and measurement equations are available. For example, Li and Zhao (2006) estimate the canonical forms of the three-factor quadratic term structure model using LIBOR bond yields via an extended Kalman filter and find the quadratic term structure models have serious difficulties in hedging caps and cap straddles, even though they capture bond yields well. Wu and Xia (2016) employs the EKF that makes a nonlinear term structure model extremely tractable for analysis of an economy operating near the zero lower bound for interest rates.
