PageRank is a version of the eigenvector centrality measure. There are different versions of the measure. In one version, the value of a network node centrality is calculated by the following formula

```
PR(i) = (1 - α) + α · ∑_j PR(j → i) / |N_i(g)| , (9C.4)
```

where R(i) is the value of the node centrality i, α is so-called damping factor (usually set at 0.85), PR(j → i) is the value of the central node j, which has a direct link with the node i, N_i(g) is the number of links of a node j. In other words, PageRank for node i is determined by the PageRank of each node j, which has a direct link with the node i.
