$P\{N_{\lambda}(t)=n\}=\frac{e^{-\lambda t}(\lambda t)^n}{n!}.\tag{34.6}$

The paths of $N_{\lambda}$ are piecewise constant on each finite interval, with predictable jumps of size 1 at the random times $\tau_n = \inf\{t \ge 0, N_{\lambda}(t)=n\}$. Applebaum (2004) adopted similar principles for a Poisson process illustration. During merger, specifically when there is a single bid, stock price movements tend to be stable. Rossi and Volpin (2004) illustrated this phenomenon before. It follows that the call of the Margrabe formula when it is a Poisson process is

$S(S,\tau,K,\sigma,r,\gamma,y)=\mathbb{E}_Q\left[\underbrace{\left(\frac{e^{-\lambda t}(\lambda t)^n}{n!}\right)}_{PP}\left(S(t)-K\right)^+|\mathcal{F}_s\right],\tag{34.7}$

where $\mathbb{E}$ illustrates an expectation of a call option, $Q$ is a martingale measure for the process $S$, $PP$ stands for a Poisson Process and denotes the process is a filtration of information at time $s$. Note that $\mathcal{F}_s$ is not only filtration process in relation to information at time $s$, but prior information to one at time $s$ is included as well. This would imply information at time $s$ where $t < s$. The lemma in equation (34.7) is similar to the one used by Blenman and Clark (2005) for their first proof. Given the fact that jumps are experienced in $\frac{S_1}{S_2}$, $y$ because it includes $r$ and $\gamma,\sigma$ as it changes as per changes in prices, it follows that when equation (34.1) incorporates a Poisson process, it changes into

$C_p(S_1,S_2,\tau)=\left(\frac{e^{-\lambda t}(\lambda t)^n}{n!}\right)\underbrace{K S_1 e^{y_1 \tau} N(d_1)-S_2 e^{y_2 \tau} N(d_2)}_{\text{MCO}},\tag{34.8}$

where $C_p$ is a call option underpinned by a Poisson process, MCO is the Margrabe call option and the rest of the parameters are the same as before. Intuitively, equation (34.8) can be interpreted as jumps (as illustrated by Poisson process) multiplied by exchange option (as illustrated by Margrabe formula). Although equation (34.8) seems simple, it is quite dynamic. Just like in Schmutz (2011), this chapter allows $\tau$ to be random. The later phenomenon allows equation (34.8) to “capture” option value all the way up to positive infinity. To one’s knowledge this is the first Margrabe-type model that captures option value all the way to positive infinity.
