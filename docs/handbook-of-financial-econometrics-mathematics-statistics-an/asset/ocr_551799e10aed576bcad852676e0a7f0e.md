Substituting μ = tr − tσ_k²/2, σ² = tσ_k² and a = X/S into equations (85.18) and (85.26) in Section 85.4, we obtain

$$\int_{X/S}^{\infty} x g(x) dx = e^{rt} N(d_1), \tag{85.57}$$ $$\int_{X/S}^{\infty} g(x) dx = N(d_2), \tag{85.58}$$

where

$$d_1 = \frac{tr - \frac{t}{2}\sigma_k^2 - \log\left(\frac{X}{S}\right)}{\sqrt{t}\sigma_k} + \sqrt{t}\sigma_k = \frac{\log\left(\frac{S}{X}\right) + \left(r + \frac{1}{2}\sigma_k^2\right) t}{\sqrt{t}\sigma_k}, \tag{85.59}$$

and

$$d_2 = \frac{\log\left(\frac{S}{X}\right) + \left(r - \frac{1}{2}\sigma_k^2\right) t}{\sqrt{t}\sigma_k} = d_1 - \sqrt{t}\sigma_k. \tag{85.60}$$

Substituting equation (85.58) into equation (85.56), we obtain

$$C = S N(d_1) - X \exp[-rt] N(d_2). \tag{85.61}$$

This is equation (85.48) defined in Section 85.6.

We have defined a put option as a contract conveying the right to sell a designated security at a stipulated price. It can be shown that the relationship between a call option (C) and a put option (P) can be defined as

$$C + X e^{-rt} = P + S. \tag{85.62}$$

Substituting equation (85.33) into equation (85.34), we obtain the put option formula as

$$P = X e^{-rt} N(-d_2) - S N(-d_1), \tag{85.63}$$

where S, C, r, t, d1, and d2 are identical to those defined in the call option model.

# 85.8 The Bivariate Normal Density Function

In correlation analysis, we assume a population where both X and Y vary jointly. It is called a joint distribution of two variables. If both X and Y are normally distributed, then we call this known distribution a bivariate normal distribution.
