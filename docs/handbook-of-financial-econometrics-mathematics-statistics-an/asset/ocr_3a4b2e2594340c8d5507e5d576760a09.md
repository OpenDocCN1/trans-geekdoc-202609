Since some columns of $\mathbf{X}'\mathbf{P}_Z\mathbf{M}_X$ will be identical to $\mathbf{0}$ (because $\mathbf{Z}$ and $\mathbf{X}$ have $\mathbf{X}_2$ in common), we can restrict our attention to

$$\operatorname{plim}\left(\frac{\mathbf{X}'\mathbf{P}_Z\mathbf{M}_X\mathbf{Y}}{T}\right)=\operatorname{plim}\left(\frac{\hat{\mathbf{X}}'\mathbf{M}_X\mathbf{Y}}{T}\right)=0. \tag{28.16}$$

So in many applications, this test can then be carried out by using an $F$-test on the $q$ vector of parameters, $\delta$, in the artificial regression

$$\mathbf{Y}=\mathbf{X}\boldsymbol{\beta}+\hat{\mathbf{X}}_1\boldsymbol{\delta}+\text{residuals}, \tag{28.17}$$

where $\hat{\mathbf{X}}_1$ are the predicted values obtained by regressing $\mathbf{X}_1$ on $\mathbf{Z}$, i.e., $\hat{\mathbf{X}}_1=\mathbf{Z}(\mathbf{Z}'\mathbf{Z})^{-1}\mathbf{Z}'\mathbf{X}_1=\mathbf{P}_Z\mathbf{X}_1$. Equation (28.17) is the unrestricted model for the $F$-test and (28.8) is the restricted model, so

$$F=\frac{(\mathrm{ESS}_R-\mathrm{ESS}_U)/q}{\mathrm{ESS}_U/(T-K-q)}. \tag{28.18}$$

can be treated as an $F(q,T-K-q)$ random variable under $H_0$ since $qF^a\sim\chi_q^2$. See Davidson and MacKinnon (1989) and MacKinnon (1992) for additional detail, they show that most of these tests can be carried out using artificial regressions.

# 28.5  Robust DWH Test

The efficiency of the estimator requirement in the null hypothesis above can be relaxed. For example, if there is a reason to use robust standard errors then the estimator is not fully efficient, so the form of the DWH test above is not applicable. If the estimator in the null hypothesis is not efficient, direct estimation using auxiliary regressions (Davidson and MacKinnon, 1989; MacKinnon, 1992) or the paired bootstrap (Cameron and Trivedi, 2005) can be used to estimate the $\operatorname{var}(\hat{\theta}-\tilde{\theta})$, in particular the last term on the right-hand-side of (28.2).
