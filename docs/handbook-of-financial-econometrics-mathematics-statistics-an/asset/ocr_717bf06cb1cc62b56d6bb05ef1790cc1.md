Taking the partial derivative of E with respect to a1, we obtain

∂E/∂a1 = [(2b11a1 + 2b12a2)(C11a1² + C22a2² + 2C12a1a2) − (b11a1² + b22a2² + 2b12a1a2)(2C11a1 + 2C12a2)] × (C11a1² + C22a2² + 2C12a1a2)−2 = 2[b11a1 + b12a2) − E(C11a1 + C12a2)] × C11a1² + C22a2² + 2C12a1a2)−1.

Setting this equation equal to zero and simplifying, we get

b11a1 + b12a2 = E(C11a1 + C12a2).

Using vector notation, we have

[b11, b12]A = E[C11, C12]A. (77B.4)

Similarly, it can be shown that, upon equating ∂E/∂a2 to zero and simplifying, we get

[b21, b22]A = E[C21, C22]A. (77B.5)

It is evident that equations (77B.4) and (77B.5) can be written as a single matrix equation:

[ b11  b12 ]       [ C11  C12 ]
[ b21  b22 ] A = E [ C21  C22 ] A

or

(B − EC)A = 0. (77B.3)

Equation (77B.3) can be used to formulate the characteristic equation for solving eigenvector A as indicated in the text.

If A* maximizes the function shown in equation (77B.1), then so does any A** = KA*, where K is a scalar. Substituting A** for A* simply multiplies both the numerator and denominator by K². Because the coefficients themselves are not unique, there are several methods of calculating the discriminant function. Johnston and Dinardo show (1996), for example, that the vector A* that maximizes the ratio E is proportional to the vector A (that is, A = KA*), which maximizes G = A′DD′A subject to the constraint that L = A′CA, where L is an arbitrary constant.
