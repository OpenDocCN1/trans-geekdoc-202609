Back-propagation is one of the most popular learning algorithms in NN and is derived to minimize the error using the following formula:

$E = 0.5 \sum_{p} \left( \sum_{k} (t_{pk} - O_{pk})^2 \right), \quad (112A.1)$

where

+   - $p$ = the pattern $i$,\n- $k$ = the output unit,\n- $t_{pk}$ = the target value of output unit $k$ for patter $p$,\n- $O_{pk}$ = the actual output value of output layer unit $k$ for patter $p$.
