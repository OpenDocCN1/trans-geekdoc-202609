These ideas can be formalized by defining X to be an NxP matrix of data with var[X] = Σ and considering a linear combination of these data α₁ᵀ X. The method of PCA produces α₁, this is the eigenvector obtained from maximizing the explained variation in the data and making sure that the new variables are as uncorrelated as possible (e.g., see Flury, 1988 for more information). Formally, the method of PCA can be set up as the following optimization problem

```
max_{α₁} var[α₁ᵀ X]
s.t. α₁ᵀ α₁ = 1.
```

Moreover, it can be simplified as

```
{
max_{α₁} var[α₁ᵀ X]
s.t. α₁ᵀ α₁ = 1
}
≡ {
max_{α₁} α₁ᵀ var[X] α₁
s.t. α₁ᵀ α₁ = 1
}
≡ {
max_{α₁} α₁ᵀ Σ α₁
s.t. α₁ᵀ α₁ = 1.
}
```

The Lagrangian of this optimization is

```
L = α₁ᵀ Σ α₁ - λ₁(α₁ᵀ α₁ - 1). (61.1)
```

The first order condition is set up and simplified below

```
∂L/∂α₁ = 2Σ α₁ - 2λ₁ α₁ = 0
→ (Σ - λ₁ I_p) α₁ = 0. (61.2)
```

The eigenvector, also called the principal component, solves this equation.² The usefulness of this discussion as it relates to affine term structure models begins to become apparent when we note that this method of PCA is most suitable for inclusion in problems that are linear in nature. Hence, recent advances in the realm of dynamic term structure modeling focus on the static linear factor model as

```
y_{i,t} = β_i f_{it} + ε_{it}. (61.3)
```
