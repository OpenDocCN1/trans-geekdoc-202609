We assume a normal prior for ψ and an inverse gamma for Ω; that is,

pri(ψ,Ω)=pri(ψ|Ω)pri(Ω) ∝ exp( -(ψ-ψ0)²/(2Ω/p0) ) Ω^{-(v0+1)} exp( -λ0/Ω ).

Combining the last equation with equation (52.5), we get the posterior

p(ψ,Ω|~r,~h,d,α,δ)=p(ψ|Ω,~r,~h,d,α,δ)p(Ω|~r,~h,d,α,δ)
= p(~r,~h|ψ,Ω,d,α,δ)pri(ψ|Ω)p(~r,~h|Ω,d,α,δ)pri(Ω)
∝ 1/Ω^{T/2} exp( -(a22,1+(ψ-^ψ)²a11)/(2Ω) )

∝ exp( -(ψ-~ψ)²/(2Ω/(p0+a11)) ) Ω^{-(v0+T/2+1)}
exp( -(λ0+a22,1/2)/Ω ),

where ~ψ = (a11 ^ψ + p0 ψ0)/(a11 + p0). The result can be summarized as follows.

# Prior distribution:

pri(Ω) ~ IG(v0, λ0)
pri(ψ|Ω) ~ N(ψ0, Ω/p0).

# Posterior:

p(Ω|~r,~h,d,α,δ) ~ IG(v0 + T/2, λ0 + a22,1/2)
p(ψ|Ω,~r,~h,d,α,δ) ~ N(~ψ, Ω/(a11 + p0)).

The posterior of α and δ follows standard time series estimation. We impose normal prior for (α,δ); that is, (α,δ)' ~ N(β0, σ²_{β0}), where β0 is a 2×1 vector and σ²_{β0} is a 2×2 matrix. Since εt and ut are correlated, we have the following relation:

u_t = σ_v ρ ε_t + b_{2,t}, b_{2,t} ~ N(0, (1-ρ²)σ²_v).
