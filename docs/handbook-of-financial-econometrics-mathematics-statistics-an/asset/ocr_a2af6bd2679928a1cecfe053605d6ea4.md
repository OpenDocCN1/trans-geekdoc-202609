# Appendix 97B: Derivation of Equation (97.20)

This appendix presents a detailed procedure for deriving equation (97.20). Following the Euler–Lagrange condition (see Chiang, 1984), we first take the first-order condition on equation (97.17) with respect to t allowing only n(t) and g(t) to change over time, and set the first-order condition equal to zero. Then we obtain

$$\frac{\partial p(0)}{\partial t}\bigg|_{\dot{g}(t)=0} = (\lambda - 1) n(t)^{\lambda-2} \dot{n}(t) [r(t) - g(t)] A'(0) \exp\left(\int_0^t g(s) ds\right) - a' A'^2(0) \sigma^2(t) (\lambda - 2) n(t)^{\lambda-3} \dot{n}(t) \exp\left(2 \int_0^t g(s) ds\right) = 0, \qquad (97B.1)$$

$$\frac{\partial p(0)}{\partial t}\bigg|_{\dot{n}(t)=0} = \left[ n(t)^{\lambda-1} r(t) A'(0) g(t) \exp\left(\int_0^t g(s) ds\right) - n(t)^{\lambda-1} A'(0) \dot{g}(t) \exp\left(\int_0^t g(s) ds\right) - n(t)^{\lambda-1} A'(0) g(t)^2 \exp\left(\int_0^t g(s) ds\right) \right] - \left[ 2 a' A'^2(0) \sigma^2(t) n(t)^{\lambda-2} g(t) \exp\left(2 \int_0^t g(s) ds\right) \right] = 0. \qquad (97B.2)$$

After rearranging equations (97B.1) and (97B.2), we can obtain equations (97.18) and (97.19).

$$n(t) = \frac{(\lambda - 2) a' A'(0) \sigma^2(t) \exp\left(\int_0^t g(s) ds\right)}{(\lambda - 1) [r(t) - g(t)]}, \qquad (97.16)$$ $$n(t) = \frac{2 a' A'(0) \sigma^2(t) \exp\left(\int_0^t g(s) ds\right)}{r(t) - g(t) - \dot{g}(t)/g(t)}. \qquad (97.17)$$

Therefore, from equations (97.18) and (97.19), we can derive the following well-known logistic differential equation as

$$\lambda g(t)^2 - \lambda r(t) g(t) + (2 - \lambda) \dot{g}(t) = 0. \qquad (97.20)$$
