Therefore, we have the following equation holds.

$$puS + (1 - p)dS = e^{r\Delta t} S.$$ (102.18)

The volatility of a stock price is defined as $\sigma$, therefore, in the short time period $\Delta t$, the standard deviation of the stock return is $\sigma\sqrt{\Delta t}$, i.e., the variance of the return is $\sigma^2\Delta t$.

The variance of the stock price return is⁴: $pu^2+(1-p)d^2-(pu+(1-p)d)^2$. We have the following equation holds:

$$pu^2 + (1 - p)d^2 - (pu + (1 - p)d)^2 = \sigma^2 \Delta t.$$ (102.19)

Combining the two equations, we get

$$e^{r\Delta t}(u + d) - u d - e^{2r\Delta t} = \sigma^2 \Delta t.$$ (102.20)

When ignoring terms $\Delta t^2$ and higher power of $\Delta t$, one solution of this equation is⁵:

$$u = e^{\sigma\sqrt{\Delta t}},$$
$$d = e^{-\sigma\sqrt{\Delta t}}.$$ (102.21)

These are the values of $u$ and $d$ proposed by Cox et al. (1979). To summarize the main relations between the parameters of the two alternative OPMs, we have the following important equations to link the two models:

$$\Delta t = \frac{T}{n},$$
$$R = e^{r\Delta t},$$
$$u = e^{\sigma\sqrt{\Delta t}},$$
$$d = e^{-\sigma\sqrt{\Delta t}}.$$ (102.22)

If $n$ gets very large, the binomial OPM value will get close to the Black–Scholes OPM value. Benninga and Czaczkes (2000) demonstrated that the binomial value will be close to Black–Scholes when the parameter $n$ exceeds 500.
