The highest- and the lowest-valued estimates for each coefficient then provide the true coefficient’s maximum likelihood boundary.² On the other hand, if any of the reverse regression estimates has a sign different from that of the direct regression estimate, then not only is that coefficient estimate unbounded, but the coefficient estimates for all the variables are also unbounded (Cready et al., 2001).³ In such situations, one can make additional assumptions regarding measurement error to conditionally bound the coefficients. For example, if one is willing to assume that one of the variables is measured without error, then the direct and reverse regression estimates associated with that variable can be excluded from the set of estimates used to bound the coefficients for the other variables and sign differences in the set of coefficient estimates due to that variable (measured without error) would not be a source of unboundedness (Klepper and Leamer, 1984; Cready et al., 2001).

Klepper and Leamer (1984), however, point out that it is not necessary to assume that some of the explanatory variables are measured correctly in order to bound the set of maximum likelihood estimates. For the unbounded cases, they demonstrate that additional prior information about the seriousness of the measurement errors in the variables can be employed to bound the feasible region. Klepper and Leamer (1984) and Klepper (1988a, 1988b) developed a series of diagnostics to assess the sensitivity of regression coefficient estimates to measurement error in the regressors when the set of feasible values of the coefficients cannot initially be bounded. The diagnostics identify which measurement error variance(s) must be constrained, and by how much, to bound the set of feasible values of the coefficients to an acceptable range. Alternatively stated, the diagnostics indicate how prior constraints on the amount of measurement error in each regressor can be transformed into bounds on the true regression coefficients when all or some of the regressors are subject to the measurement error (Klepper, 1988a).
