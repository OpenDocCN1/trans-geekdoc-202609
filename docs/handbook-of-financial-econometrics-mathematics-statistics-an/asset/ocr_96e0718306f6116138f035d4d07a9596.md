# 64.3.2 The extended Kalman filter

The extended Kalman filter (EKF) relies on a first-order Taylor expansion of the transition equation around x_{t-1} and the measurement equation around the predicted state vector x_{t|t-1}. The above system can then be written as follows:

```
x_t = H_{t-1} x_{t-1} + W w_t,

y_t = G_t x_t + V v_t.
```

# 64.3.3 The unscented Kalman filter

Unlike the EKF, the unscented Kalman filter (UKF) uses the exact nonlinear functions and does not linearize the equations. Instead, the UKF approximates the conditional distribution of x_{t|t-1} and using the scaled unscented transformation (Julier, 2000), which can be defined as a method for computing the statistics for a nonlinear transformation of a random variable. Julier and Uhlmann (2004) prove that such an approximation is accurate to the third order for Gaussian states and to the second order for non-Gaussian states. Because the approximation does not require computation of the Jacobian or Hessian matrices, the computational burden associated with the UKF is comparable to that of the EKF.
