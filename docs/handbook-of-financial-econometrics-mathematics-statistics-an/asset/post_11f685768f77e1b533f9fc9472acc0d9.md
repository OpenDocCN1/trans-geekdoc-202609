Second, the fuzzy set approach facilitates DMs’ participation to avoid suboptimization of the overall company’s goals. This model supports divisional autonomy more than any other mathematical programming model by allowing differences in each decision maker’s preference.

Third, solving MC² problems in a real-world setting is not practical because of computational complexity. The fuzzy set approach is more straightforward and easy to solve using currently available computer software.

Finally, the structure of the MCMDM international transfer pricing is flexible. We can add or delete more objectives or constraints as easily as possible as economic or political environment changes which is common in international business environments.

## 54.6 Conclusions

A multiple factor international transfer pricing model has been developed to solve the transfer pricing problems in a multi-divisional corporation. This model can provide a comprehensive scenario about possible optimal transfer prices depending on multiple criteria and multiple constraint levels. This method allows to foster goals of transfer pricing such as global optimization, division autonomy, and performance evaluation. In addition, this fuzzy set approach can handle better real-world problems with uncertainty. The fuzzy set model and its solution method provide better solutions in transfer pricing problems than the previous linear programming or goal programming models by receiving input from all decision maker’s preference.

We can extend the fuzzy set approach to other real-world problems in business. The framework of this model can be applied to other areas, such as financial planning, portfolio determination, inventory management, resource allocation, audit sampling objectives, and personnel planning for a CPA firm if the decision variables and formulation are expressed appropriately.
