# 28.3 The Durbin–Wu–Hausman (DWH) Test

The DWH test is based on vectors of contrasts. In general, consider two estimators providing parameter vectors $\hat\theta$ and $\tilde\theta$ and testing

$H_0: \ \text{plim}\left(\hat\theta - \tilde\theta\right)=0 \ \text{versus}\ H_A: \ \text{plim}\left(\hat\theta - \tilde\theta\right)\neq0.$

If the difference between the root-$T$ consistent estimators is root-$T$ consistent under the null hypothesis, then it converges in distribution, with mean $\mathbf{0}$ and a limit normal distribution

$\sqrt{T}\left(\hat\theta - \tilde\theta\right) \xrightarrow{d} N\left[\mathbf{0}, \Omega\left(\hat\theta - \tilde\theta\right)\right],$

where $\Omega\left(\hat\theta - \tilde\theta\right)$ is the contrast in variance–covariance matrices in the limiting distribution. The DWH test statistic is then given by

$m = \left(\hat\theta - \tilde\theta\right)'\left(\frac{\Omega\left(\hat\theta - \tilde\theta\right)}{T}\right)^{-1}\left(\hat\theta - \tilde\theta\right)^a \sim \chi^2(q). \quad (28.1)$

That is, $m$ is asymptotically distributed $\chi^2(q)$ under the null, where $q$ is the number of parameters (associated with potential endogenous variables) being compared across the two models considered. The null hypothesis is rejected at significance level $\alpha$ if $m > \chi^2_{\alpha}(q)$.

In the context of instrumental variables, for example, if the original $X$ variables are valid instruments (i.e., they are not correlated with the contemporaneous error), then the LS estimator is consistent and preferred to the IV estimator with other valid instruments. Since both would then have the same probability limit, both provide consistent parameter estimates so the preference between the estimators is then based on the efficiency of the parameter standard errors.

In general, to carry out the test we need a consistent estimate of

$\Omega\left(\tilde\theta - \hat\theta\right) = \text{var}\left[\hat\theta\right] + \text{var}\left[\tilde\theta\right] - 2\text{cov}\left[\hat\theta, \tilde\theta\right]. \quad (28.2)$
