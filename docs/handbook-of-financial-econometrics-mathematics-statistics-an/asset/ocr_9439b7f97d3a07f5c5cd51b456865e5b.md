If the estimated Jensen’s measure, α̂_i, and the estimated systematic risk, β̂_i, are significantly corrected, the estimate of the residual return (ε̂_it) used in testing the efficient market hypothesis will be biased. The residual return is estimated by

```
ε̂_it = (R_it − R_f) − α̂_i − β̂_i (R_Mt − R_f). (68.17)
```

Following the above conclusions, α̂_i is negatively correlated with β̂_i during the time period over which R_f is smaller than the expected market return (μ). Then, a negative correlation between α̂_i and β̂_i means that securities having low beta coefficients are favorably evaluated to have high non-market returns (or intercept terms), α̂_i. As a result, the use of equation (68.17) leads to underestimating the residual returns. This result can be easily shown as follows: let α̂'_i be the estimate of non-market return when β̂_i and α̂_i are negatively correlated, then α_i being favorably evaluated implies that α̂'_i is greater than the true estimate of α_i, say α̂*_i. One may then write

```
α̂'_i = α̂*_i + δ_i,   δ_i > 0. (68.18)
```

Using equations (68.17) and (68.18) leads to the equation

```
ε̂'_it = ε̂*_it − δ_i,   δ_i > 0, (68.19)
```

where ε̂'_it = (R_it − R_f) − α̂'_i − β̂_i(R_Mt − R_f) and ε̂*_it = (R_it − R_f) − α̂*_i − β̂_i(R_Mt − R_f). Equation (68.19) indicates that ε̂'_it is less than ε̂*_it. In other words, the residual return is underestimated if the non-market return is favorably assessed. This implies that the estimated average residual return and the estimated cumulative average residual return will be downward biased.
