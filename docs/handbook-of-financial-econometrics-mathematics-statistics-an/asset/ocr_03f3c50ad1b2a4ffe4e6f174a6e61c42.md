# Table 11.1: A list of different static hedge ratios.

| Hedge ratio | Objective function |
|---|---|
| • MV hedge ratio | Minimize variance of $R_h$ |
| • Optimum mean-variance hedge ratio | Maximize $E(R_h)-\frac{A}{2}\operatorname{Var}(R_h)$ |
| • Sharpe hedge ratio | Maximize $\frac{E(R_h)-R_F}{\sqrt{\operatorname{Var}(R_h)}}$ |
| • Maximum expected utility hedge ratio | Maximize $E[U(W_1)]$ |
| • Minimum MEG coefficient hedge ratio | Minimize $\Gamma_v(R_h\nu)$ |
| • Optimum mean-MEG hedge ratio | Maximize $E[R_h]-\Gamma_v(R_h\nu)$ |
| • Minimum GSV hedge ratio | Minimize $V_{\delta,\alpha}(R_h)$ |
| • Maximum Mean-GSV hedge ratio | Maximize $E[R_h]-V_{\delta,\alpha}(R_h)$ |
| • Minimum VaR hedge ratio over a given time period $\tau$ | Minimize $Z_{\alpha}\sigma_h\sqrt{\tau}-E[R_h]\tau$ |

*Notes:*

1. $R_h$ = return on the hedged portfolio,  
   $E(R_h)$ = expected return on the hedged portfolio,  
   $\operatorname{Var}(R_h)$ = variance of return on the hedged portfolio,  
   $\sigma_h$ = standard deviation of return on the hedged portfolio,  
   $Z_{\alpha}$ = negative of left percentile at $\alpha$ for the standard normal distribution,  
   $A$ = risk aversion parameter,  
   $R_F$ = return on the risk-free security,  
   $E(U(W_1))$ = expected utility of end-of-period wealth,  
   $\Gamma_v(R_h\nu)$ = mean extended-Gini coefficient of $R_h$,  
   $V_{\delta,\alpha}(R_h)$ = generalized semivariance of $R_h$.

2. With $W_1$ given by equation (11.17), the maximum expected utility hedge ratio includes the hedge ratio considered by Lence (1995, 1996).
