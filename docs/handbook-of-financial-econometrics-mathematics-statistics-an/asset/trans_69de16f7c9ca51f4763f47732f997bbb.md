
基于公式（114.25），我们可以无限次地代入滞后的公司收益率，并发现市场收益率的系数可以表示为 β_i2 (1 + β_i1 + β_i1² + β_i1³ + ⋯)。因此，只要 β_i1 与 0 显著不同，我们就可以将长期乘数定义如下：

LRM = β_i2 / (1 − β_i1). (114.31)

如果 β_i1 与 0 无显著差异或违反约束条件而落在区间 (−1,0] 内，则 LRM 为 β_i2。
