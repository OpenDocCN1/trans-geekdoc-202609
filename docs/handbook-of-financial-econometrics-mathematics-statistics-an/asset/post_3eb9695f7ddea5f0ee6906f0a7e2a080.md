
$$= \sum_{i=1}^{m+1} Q_i \Big[ D\rho_i^2 + c\rho_i + \int_0^{\infty} \big(e^{z\rho_i} - 1 - \rho_i z \mathbf{1}_{|z|\le1}\big) v(dz) 
+ \lambda \sum_{j=1}^{m} \frac{p_j\eta_j}{\eta_j + \rho_i} - (\lambda + r) \Big] 
+ \lambda \sum_{j=1}^{m} e^{-\eta_j x} p_j \times \Big[ -\sum_{i=1}^{m+1} \frac{\eta_j Q_i}{\eta_j + \rho_i} + \eta_j \int_{-\infty}^{0} g(y) e^{\eta_j y} dy \Big].$$

Since $\psi(\rho_i) - r = 0$ for all $i$ and $Q$ satisfies (41.48) and hence (41.47), we conclude that $(L - r)\phi(x) = 0$. By Proposition 41.4.1, $\phi \equiv \Phi$ on $R$.

## Appendix 41B: Toolbox for Phase-Type Distribution

We first give a summary of some facts of matrix algebra.

### Theorem 41B.1:
- (1) *The matrix exponential function $e^{hA}$ is differentiable on $R$ and*
$$
\frac{d e^{hA}}{dh} = A e^{hA} = e^{hA} A.
$$
- (2) *Let $\theta_1,\dots,\theta_k$ be the eigenvalues of a matrix $A$. Then, for each $s > \max_i R(\theta_i)$, $\lim_{t\to\infty} e^{-st}\exp(tA)=0$.*
- (3) *Let $B$ be a subintensity matrix. Then $B$ is nonsingular if and only if eigenvalues of $B$ have strictly negative real parts.*
- (4) *If $A$ is nonsingular, then $\int_v^t e^{xA}dx = A^{-1}(e^{tA}-e^{vA})$; if further all eigenvalues of $A$ have strictly negative real parts, then $\int_0^{\infty} e^{xA}dx = -A^{-1}$.*

The following summarizes the main analytic properties of phase-type distributions.

### Theorem 41B.2: Suppose that $F$ is $PH(\alpha, B)$. Then:
- (1) *The $n$th moment of $F$ is $(-1)^n n! \alpha B^{-n} e^T$.*
- (2) *For any $s \in C$ with $R(s) \ge 0$, $s \mapsto \int_0^{\infty} e^{-sx} dF(x) = \alpha(sI - B)^{-1} b^T$ is a rational function.*

Assume that $B$ is a nonsingular subintensity matrix. Theorem 41B.1(2) and (3) imply that
$$
\lim_{y\to\infty} e^{By} e^{\delta y}=0.
$$
For some $\delta > 0$. Hence, $T_B^{\pm}$ given by (41.22) is well defined.

### Theorem 41B.3: Let $h$ be a bounded Borel-measurable function. If $h$ is continuous at $x$, then $T_B^{\pm}$ are both differentiable at $x$ and $(\frac{d}{dx} - B) T_B^+ = I$, $-(B + \frac{d}{dx}) T_B^- = I$. Moreover, if $h \in C_{0,b}(R_{++})$, each entry of $T_B^{\pm} h$ is in $C_{0,b}(R_{++})$.

Proof. Assume that $h$ is bounded and continuous at $x$. By Theorem 41B.1(1), $\frac{d}{dx} e^{Bx} = B e^{Bx}$. On the other hand, since $h$ is continuous at $x$, $\frac{d}{dx} \int_{-\infty}^x h(y) e^{-B y} dy = h(x) e^{-x B}$. Therefore,

$$\frac{d}{dx} T_B^+ h(x) = \frac{d}{dx} \left( e^{Bx} \int_{-\infty}^x h(y) e^{-B y} dy \right) = B T_B^+ h(x) = h(x) I.$$

This shows that $(\frac{d}{dx} - B) T_B^+ h(x) = h(x) I$. Similarly, $-(B + \frac{d}{dx}) T_B^- h(x) = h(x) I$. Finally, if $h \in C_{0,b}(R_{++})$, then it is clear that $T_B^{\pm} h$ is bounded on $R$. Moreover, by dominated convergence, $T_B^{\pm} h \in C_{0,b}(R_{++})$. This proves the last statement.

## Appendix 41C: First-Order Derivative of $\Phi$ at Zero

We consider the process (41.2) and set

$$\Delta = \sup \left\{ \xi \in R_+; \int e^{\xi y} dF(y) < \infty, \forall \xi \in [0, \xi] \right\}. \tag{41C.1}$$

Throughout this section, we assume that $\Delta > 0$ and $\psi(\Delta-) > 0$. Let $r > 0$. Since $\psi(0) - r < 0$ and $\psi$ is strictly convex on $[0,\Delta)$, there exists a unique number $\rho^* \in (0,\Delta)$ such that $\psi(\rho^*) - r = 0$. ($\rho^*$ is called the Lundberg constant in the actuarial literature.) We write

$$\beta = \frac{c}{D} + \rho^*, \ \alpha = \beta + \rho^*, \tag{41C.2}$$

and $h_{\rho^*} = e^{-\rho^* x} h(x)$ for any function $h$. Recall that $\Phi(x) = E_x[e^{-r t} g(X_\tau)]$ for some fixed bounded Borel-measurable function $g : (-\infty, 0] \to R$ and $\tau = \inf\{t \ge 0; X_\tau \le 0\}$. Following similar arguments as in $(..., \text{Section 3})$ of Gerber and Landry (1998), we calculate the first-order derivative of $\Phi$ at $0$.

### Theorem 41C.1: Suppose $r > 0$. The derivative of $\Phi$ at 0 is given by

$$\Phi'(0+) = \theta_0 - \frac{\lambda}{D} \int_{-\infty}^0 dF(y) \int_0^{-y} dv \, \Phi_{\rho^*}(v) e^{-\rho^* y}, \tag{41C.3}$$

where

$\theta_0 = -\beta g(0) + \frac{\lambda}{D} \int_0^\infty dv \int_v^\infty dF(y) e^{-\rho^* y} g_{\rho^*}(v - y). \tag{41C.4}$

In particular, if $\int_{(-\infty,0]} dF = 0$, then $\Phi'(0+) = \theta_0$.

Proof. By Theorem 41.2.4, we have $(L - r)\Phi(v) = 0$ for all $v > 0$. Multiplying both sides of this equation by $e^{-\rho^* v}$ gives

```
e^{-ρ^* v} [D d²/dv² + c d/dv - (λ + r)] Φ(v) + λ ∫_{-∞}^∞ Φ(v - y)e^{-ρ^* y} dF(y) = 0. (41C.5)
```

□

Note that $\Phi(v) = e^{\rho^* v} \Phi_{\rho^*}(v)$ for $v \in R$. Then

```
Φ'(v) = ρ^* e^{ρ^* v} Φ_{ρ^*}(v) + e^{ρ^* v} Φ'_{ρ^*}(v) (41C.6)
```

and

```
Φ''(v) = (ρ^*)^2 e^{ρ^* v} Φ_{ρ^*}(v) + 2ρ^* e^{ρ^* v} Φ'_{ρ^*}(v) + e^{ρ^* v} Φ''_{ρ^*}(v).
```

Hence, (41C.5) becomes

```
0 = D Φ''_{ρ^*}(v) + (c + ρ^* σ²) Φ'_{ρ^*}(v) + λ ∫_{-∞}^∞ Φ_{ρ^*}(v - y)e^{-ρ^* y} dF(y) - λ Φ_{ρ^*}(v) ∫ e^{-ρ^* y} dF(y). (41C.7)
```

By Theorem 41.2.1, $\Phi'(0+)$ exists as a right-hand side derivative. Therefore, integrating (41C.7) from $v = 0$ to $v = z$ gives

```
D[Φ'_{ρ^*}(z) - Φ'_{ρ^*}(0+)] + (c + ρ^* σ²)[Φ_{ρ^*}(z) - Φ_{ρ^*}(0)] + λ ∫_0^z dv ∫_{-∞}^∞ dF(y) Φ_{ρ^*}(v - y)e^{-ρ^* y} - λ ∫_0^z dv ∫ dF(y) Φ_{ρ^*}(v)e^{-ρ^* y} + λ ∫_0^z dv ∫ dF(y) g_{ρ^*}(v - y)e^{-ρ^* y} = 0. (41C.8)
```

Note that we have, by Fubini's theorem, a change of variables; again, by Fubini's theorem,

$$\int_{0}^{z} dv \int dF(y)\Phi_{\rho^*}(v-y)e^{-\rho^* y}=\int_{-\infty}^{0} dF(y)\int_{0}^{z} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y}+\int_{0}^{z} dF(y)\int_{y}^{z} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y}$$
$$=\int_{-\infty}^{0} dF(y)\int_{0}^{z} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y}+\int_{0}^{z} dF(y)\int_{0}^{z-y} dv\Phi_{\rho^*}(v)e^{-\rho^* y}$$
$$=\int_{-\infty}^{0} dF(y)\int_{0}^{z} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y}+\int_{0}^{z} dv\int_{0}^{z-v} dF(y)\Phi_{\rho^*}(v)e^{-\rho^* y}.$$

So, (41C.8) is equivalent to

$$0 = D[\Phi'_{\rho^*}(z)-\Phi'_{\rho^*}(0)] + (c+\rho^*\sigma^2)[\Phi_{\rho^*}(z)-\Phi_{\rho^*}(0)]$$ 
$$+\lambda\Big[\int_{-\infty}^{0} dF(y)\int_{0}^{z} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y} -\int_{0}^{z} dv\Big(\int_{z-v}^{\infty}+\int_{-\infty}^{0}\Big)dF(y)\Phi_{\rho^*}(v)e^{-\rho^* y}+\int_{0}^{z} dv\int_{v}^{\infty} dF(y)e^{-\rho^* y}g_{\rho^*}(v-y)\Big].\tag{41C.9}$$

By Theorem 41.2.1, $\Phi'(z)$ and $\Phi(z)$ tend to zero as $z\to\infty$. Hence, letting $z\to\infty$ in the last equation gives

$$\Phi'_{\rho^*}(0)=\frac{1}{D}\Big[-(c+\rho^*\sigma^2)g(0)-\lambda\int_{-\infty}^{0} dF(y)\int_{0}^{-y} dv\Phi_{\rho^*}(v-y)e^{-\rho^* y}+\lambda\int_{0}^{\infty} dv\int_{v}^{\infty} dF(y)e^{-\rho^* y}g_{\rho^*}(v-y)\Big].\tag{41C.10}$$

Since $\Phi'(0)=\rho^* g(0)+\Phi'_{\rho^*}(0)$, we get (41C.3).

### Proposition 41C.2: Assume that (41.15) holds, and $r>0$. Then the number $\Delta$ defined by (41C.1) is in $(0,\infty]$, and $\psi(\Delta-)=+\infty$.

**Proof.** First, we show that $\Delta > 0$. Since all eigenvalues of $B_{-}$ have strictly negative real parts by Theorem 41B.1(3), so do the eigenvalues of $B_{-} + \xi I$ for all $\xi$ in an open interval in $(0, \infty)$. For all these $\xi$, from Theorem 41B.1(4) we obtain that

$$\int_{0}^{\infty} e^{\xi y} f_{(-)}(y) dy = \alpha_{-} (-\xi I - B_{-})^{-1} b_{-}^{T} < \infty,$$

and hence, $\int e^{\xi y} dF(y) < \infty$.

Next, we show that $\psi(\Delta-) = +\infty$. If $\Delta < \infty$, $\Delta$ must be a pole of $\psi(\xi)$ on $C$ so that $\psi(\Delta-) = +\infty$ or $-\infty$. Since $\psi$ is strictly convex on $[0, \Delta)$, we have $\psi(\Delta-) = +\infty$. If $\Delta = \infty$, we have $\psi(\Delta-) = +\infty$ by the fact $D > 0$. This completes the proof. $\square$
