where $U_{t,j}$ denotes the $j$th jump size and is assumed to be normally distributed with mean $\theta$ and standard deviation $\delta$. The number of jumps, $n_t$ is assumed to be Poisson distributed with an autoregressive conditional jump intensity (ARJI)

$\lambda_t = \lambda_0 + \rho\lambda_{t-1} + \gamma\xi_{t-1}, \quad (70.4)$

where the intensity residual $\xi_{t-1}$ is defined as the difference between the expected number of jumps given the log-return $Y_{t-1}$ and the previous intensity $\lambda_{t-1}$. The specification of the conditional intensity allows the probabilities of jumps to vary over time and cluster with a persistence parameter $0 < \rho < 1$. The conditional density of the log-return $Y_t$ given the information set $\mathcal{F}_{t-1}$ at time $t-1$ is

$f(Y_t \mid \mathcal{F}_{t-1}) = \sum_{n_t=0}^{\infty} f(Y_t \mid n_t, \mathcal{F}_{t-1}) \frac{e^{-\lambda_t} \lambda_t^{n_t}}{n_t!}, \quad (70.5)$

where the conditional probability density $f(Y_t \mid n_t, \mathcal{F}_{t-1})$ is

$\frac{1}{\sqrt{2\pi(\sigma_t^2 + n_t\delta^2)}} \exp\left(-\frac{(Y_t - \mu + \theta\lambda_t - \theta n_t)^2}{2(\sigma_t^2 + n_t\delta^2)}\right).$

The GARJI model (70.1)-(70.5) allows for different components of the return innovation, $\varepsilon_{t-1}$ to affect future expected volatility differently. However, the cut-off point between normal and extreme price movements cannot be identified based on the observed log-returns. Thus, the number of jumps $n_t$ is unobservable and only an ex post probability distribution for $n_t$ given the information set $\mathcal{F}_t$ can be derived as follows:

$P(n_t \mid \mathcal{F}_t) = \frac{f(Y_t \mid n_t, \mathcal{F}_{t-1})}{f(Y_t \mid \mathcal{F}_{t-1})} \times \frac{e^{-\lambda_t}\lambda_t^{n_t}}{n_t!}. \quad (70.6)$

Differing from the GARJI model, the VG NGARCH model is constructed based on a purely jump VG process, therefore no cut-off point is required between normal and extreme price movements. Furthermore, an ex ante probability for large price movements can be derived. An introduction of a variance-gamma process is given in Section 70.2.2.
