We wanted to add the negative numbers to all numbers to make all numbers positive. Second, we took the absolute value of the lowest negative numbers. If it was not done so, we would have negative numbers, plus negative numbers result in bigger negative numbers. For example, −6 + (−6) = −12. Third, we wanted to take into account the rounding error by adding 0.1 to the absolute value of the lowest negative numbers. For example, to normalize the data of company A, we added the absolute value of lowest negative numbers of company A, that is, |−6.7| to 0.1. As a result, we have 6.8. Then we used 6.8 to add all number. Let us say we used the lowest numbers: 6.8 + (−6.7) = 0.1. To sum up, the formula we used to normalize the data = (|lowest negative number| + 0.1 + all number in our data set).
