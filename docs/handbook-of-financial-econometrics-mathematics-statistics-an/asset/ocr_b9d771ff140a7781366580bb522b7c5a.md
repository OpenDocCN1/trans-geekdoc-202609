function of $\chi_v'^2(\lambda)$ is

$$F(x; v, \lambda) = P(\chi_v'^2(\lambda) \le x)$$

$$= e^{-\lambda/2} \sum_{j=0}^{\infty} \frac{(\lambda/2)^j}{j! 2^{v/2} \Gamma(v/2 + j)} \times \int_0^x y^{v/2 + j -1} e^{-\frac{y}{2}} dy, \quad x > 0.$$

(109.21)

An alternative expression for $F(x; v, \lambda)$ is

$$F(x; v, \lambda) = \sum_{j=0}^{\infty} \left( \frac{(\lambda/2)^j e^{-\lambda/2}}{j!} \right) P(\chi_{v+2j}^2 \le x).$$

(109.22)

The complementary distribution function of $\chi_v'^2(\lambda)$ is

$$Q(x; v, \lambda) = 1 - F(x; v, \lambda),$$

(109.23)

where $F(x; v, \lambda)$ is given in either equation (109.21) or equation (109.22).

The probability density function of $\chi_v'^2(\lambda)$ can be expressed as a mixture of central Chi-square probability density functions:

$$P_{\chi_v'^2(\lambda)}(x) = e^{-\lambda/2} \sum_{j=0}^{\infty} \frac{(\frac{1}{2}\lambda)^j}{j!} p_{\chi_{v+2j}^2}(x) = \frac{e^{-(x+\lambda)/2}}{2^{v/2}} \sum_{j=0}^{\infty} \frac{x^{v/2 + j -1} \lambda^j}{\Gamma(v/2 + j) 2^{2j} j!}.$$

(109.24)

An alternative expression for the probability density function of $\chi_v'^2(\lambda)$ is

$$P_{\chi_v'^2(\lambda)}(x) = \frac{1}{2} \left( \frac{x}{\lambda} \right)^{(v-2)/4} \exp\left\{ -\frac{1}{2}(\lambda + x) \right\} \times I_{(v-2)/2}(\sqrt{\lambda x}), \quad x > 0,$$

(109.25)

where $I_k$ is the modified Bessel function of the first kind of order $k$ and is defined as

$$I_k(z) = \left( \frac{1}{2} z \right)^k \sum_{j=0}^{\infty} \frac{(z^2/4)^j}{j! \Gamma(k + j + 1)}.$$

(109.26)

It is noted that for integer $k$, 

$$I_k(z) = \frac{1}{\pi} \int_0^{\pi} e^{z \cos(k\theta)} \cos(k\theta) d\theta = I_{-k}(z).$$

(109.27)

The noncentral Chi-square distribution satisfies the reproducibility property with respect to $n$ and $\lambda$. If $X_1, \dots, X_k$ are independent random variables with $X_t$ distributed as $\chi_{n_i}'^2(\lambda_i)$ then

$$Y = \sum_{i=1}^{k} X_i \sim \chi_{\sum_{i=1}^{k} n_i}'^2 \left( \sum_{i=1}^{k} \lambda_i \right).$$

(109.28)
