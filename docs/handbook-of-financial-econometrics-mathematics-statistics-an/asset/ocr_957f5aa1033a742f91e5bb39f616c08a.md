The total equity funds available over any time interval $i$ is the sum of the expressions (49.1a) and (49.1d), i.e.,

$\sum_{k=0}^{i} Y_{1,k} + \sum_{k=0}^{i} Y_{3,k}. \tag{49.1g}$

For bond financing, the following logical assumptions are: (i) if in any time interval a bond is issued, only a single issue is made, and (ii) any time a bond is called, the entire issue is called. Now, let us define a state vector $\mathbf{X}_i$ as follows:

$\mathbf{X}_i = [X_{1,i}, X_{2,i}, X_{3,i}, \dots, X_{N_0,i}, X_{N_0+1,i}, \dots, X_{N',i}]'$

where $N' = N_0 + N$ and each element $X_{j,i}$ represents the number of bonds in the $j$th issue outstanding in the interval $i$. The first $N_0$ terms of the state vector $\mathbf{X}_i$ represent the $N_0$ bonds previously outstanding at time $t = t_0$. The last $N$ terms of the state vector represent the bonds to be issued in the succeeding $N$ time intervals, one issue per each interval. For example, $X_{N_0+1,i}$ corresponds to the bond issued in the first interval.

If no bond is issued in the first interval, then $X_{N_0+1,i}$ is zero for all $i$ greater than or equal to 1. Also, if this particular bond is called in interval $i - 1$, then $X_{N_0+1,i}$ also becomes zero. From this, it should be clear that in general,

$X_0 = [X_{1,0}, X_{2,0}, X_{3,0}, \dots, X_{N_0,0}, 0, 0, \dots, 0]'$,
$X_1 = [X_{1,1}, X_{2,1}, X_{3,1}, \dots, X_{N_0,1}, X_{N_0+1,1}, 0, 0, \dots, 0]'$,
$\vdots$
$X_i = [X_{1,i}, X_{2,i}, X_{3,i}, \dots, X_{N_0,i}, X_{N_0+1,i}, \dots, X_{N_0+i,i}, 0, 0, \dots, 0]'$,
$\vdots$
$X_N = [X_{1,N}, X_{2,N}, X_{3,N}, \dots, X_{N_0,N}, X_{N_0+1,N}, \dots, X_{N_0+N,N}]'$

The relationship between the state vectors $\mathbf{X}_i$ and $\mathbf{X}_{i-1}$ is as follows:
$X_{j,i} = X_{j,i-1}$ if a bond $j$ is not issued, called, or matured in the interval $i$
$= 0$ if the bond is called in the interval $i$ or $j > N_0 + i$, the bond has matured or was never issued.
$= X_{j,i}$ if $j = N_0 + i$ and a bond is issued in interval $i$. In this case $X_{j,i-1} = 0.$
