The variance of the error terms in the between-groups regression, (28.30), is σ_v² + σ_ε²/T. Therefore, if we run it as a regression with N observations, divide the resulting sum of squared errors by N − K, and then subtract σ_ε²/T, we obtain a consistent estimate of σ_v². If this estimate is negative, Greene (2018), among others, provides details on alternative approaches for estimating the covariance components that can be tried but we should probably not be estimating a RE model in this case.

The FGLS estimator of the RE model are matrix-weighted averages of the within-groups (FE, equation (28.10)) and the between-groups estimators, (28.31). Fuller and Battese (1973, 1974) show that the GLS estimator of the RE model can be obtained by using OLS with the transformed data, i.e.,

(I − λP_D) y = (I − λP_D) Xβ + residuals, (28.33)

where the scalar

λ ≡ 1 − (Tσ_v²/σ_ε² + 1)^(−1/2) = 1 − (σ_ε²/(Tσ_v² + σ_ε²))^(1/2) (28.34)

and the consistent variance estimators developed above are used in (28.34). If λ = 0 then this estimator is just OLS and if λ = 1 this is the FE (within-groups) estimator. As long as λ ∈ (0,1), the RE GLS estimator is more efficient that the FE estimator, (28.10), as well as the OLS pooled estimator.

# 28.12 DWH Test for FE Versus RE Models

In estimating the model, the effects are specified as either

+   - **Fixed Effects (FE)**: parameters to be estimated, can be estimated using dummy variables (the so-called LSDV estimator) or by group mean differencing and LS.
+   - **Random Effects (RE)**: The e_it covariance matrix is specified as functions of the variances of the u_t, v_i, and ε_it, and FGLS is commonly used for estimation.

Joint hypothesis tests of the effects can be carried out with an F-test (for the FE model) or Wald, LR, or LM test (for the RE model). A DWH test can be used to choose between the FE and RE specifications of the model:

+   - If effects are uncorrelated with X, RE is consistent and efficient, FE is consistent but inefficient.
