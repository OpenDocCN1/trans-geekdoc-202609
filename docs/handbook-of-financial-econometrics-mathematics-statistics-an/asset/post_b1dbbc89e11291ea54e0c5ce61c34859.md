
Equation (37.3) implies that $\hat{\beta}$ is downward biased and $\hat{\alpha}$ is upward biased.

## 37.2.2 Multivariate case

Suppose we have a trivariate structural relationship

$$W_i = \alpha + \beta U_i + \gamma V_i.$$ (37.4)

$W_i, U_i,$ and $V_i$ are unobserved, but we can observe $Z_i = W_i + \tau_i, X_i = U_i + \varepsilon_i,$ and $Y_i = V_i + \eta_i$. $U_i$ and $V_i$ have a joint normal distribution with variances $\sigma_U^2$ and $\sigma_V^2$ and correlation coefficient $\rho_{UV}$. In the observed variables $X, Y,$ and $Z$, the observed errors $\varepsilon, \eta,$ and $\tau$ are independent normal variables with zero means and variance $\sigma_1^2, \sigma_2^2, \sigma_3^2$. $X, Y,$ and $Z$ have a multivariate normal distribution.

### 37.2.2.1 The classical case

The effects of measurement errors on the estimates of $\beta$ and $\gamma$ in the classical case can be seen from the following:

$$\operatorname{plim} \hat{\beta} = \frac{(\sigma_V^2 + \sigma_2^2)\sigma_{WU} - (\sigma_{UV}\sigma_{WV})}{(\sigma_U^2 + \sigma_1^2)(\sigma_V^2 + \sigma_2^2) - (\sigma_{UV})^2}, \tag{37.5a}$$ $$\operatorname{plim} \hat{\gamma} = \frac{(\sigma_U^2 + \sigma_1^2)\sigma_{WV} - (\sigma_{WU}\sigma_{UV})}{(\sigma_U^2 + \sigma_1^2)(\sigma_V^2 + \sigma_2^2) - (\sigma_{UV})^2}. \tag{37.5b}$$

From equations (37.5a) and (37.4), the asymptotic biases of $\hat{\beta}$ and $\hat{\gamma}$ can be defined as

$$\operatorname{plim} \hat{\beta} - \beta = \frac{\sigma_{WU}\sigma_2^2 - \beta(\sigma_U^2\sigma_2^2 + \sigma_V^2\sigma_1^2 + \sigma_1^2\sigma_2^2)}{(\sigma_U^2\sigma_V^2 - \sigma_{UV}^2) + \sigma_U^2\sigma_2^2 + \sigma_V^2\sigma_1^2 + \sigma_1^2\sigma_2^2}, \tag{37.6a}$$ $$\operatorname{plim} \hat{\gamma} - \gamma = \frac{\sigma_{WV}\sigma_1^2 - \gamma(\sigma_U^2\sigma_2^2 + \sigma_V^2\sigma_1^2 + \sigma_1^2\sigma_2^2)}{(\sigma_U^2\sigma_V^2 - \sigma_{UV}^2) + \sigma_U^2\sigma_2^2 + \sigma_V^2\sigma_1^2 + \sigma_1^2\sigma_2^2}. \tag{37.6b}$$

The direction of the biases of $\hat{\beta}$ and $\hat{\gamma}$ can be treated according to the following:

- Under the assumption that Cov $(UV) = 0$
  - (i) If $\sigma_1^2 = 0, \quad \sigma_2^2 > 0,$
    - (a) $\operatorname{plim} \hat{\beta} - \beta = \frac{\sigma_2^2(\sigma_{WU} - \beta\sigma_U^2)}{\sigma_U^2(\sigma_V^2 + \sigma_2^2)} = 0,$ (37.7a)
    - (b) $\operatorname{plim} \hat{\gamma} - \gamma = \frac{-\gamma\sigma_U^2\sigma_2^2}{\sigma_U^2(\sigma_V^2 + \sigma_2^2)} = \frac{-\gamma\sigma_2^2}{(\sigma_V^2 + \sigma_2^2)}.$ (37.7b)

Equation (37.7a) implies that $\hat{\beta}$ is an asymptotic unbiased estimator of $\beta$, while equation (37.7b) implies that $\hat{\gamma}$ is downward biased estimator of $\gamma$.

- (ii) If $\sigma_1^2 > 0$, $\sigma_2^2 = 0$,  
  - (a) $\text{plim } \hat{\beta} - \beta = \frac{-\beta \sigma_1^2}{\sigma_V^2(\sigma_U^2 + \sigma_1^2)}$,  (37.8a)  
  - (b) $\text{plim } \hat{\gamma} - \gamma = \frac{\sigma_1^2(\sigma_{WV} - \gamma \sigma_V^2)}{\sigma_V^2(\sigma_U^2 + \sigma_1^2)} = 0.$  (37.8b)

In accordance with equation (37.8a), equation (37.8b) can be used to draw some meaningful conclusions about the biases of both $\hat{\beta}$ and $\hat{\gamma}$.

- (iii) Finally, if $\sigma_1^2 > 0$, $\sigma_2^2 > 0$,  
  - (a) $\text{plim } \hat{\beta} - \beta = -\frac{\beta \sigma_1^2}{\sigma_U^2 + \sigma_1^2}$,  (37.9a)  
  - (b) $\text{plim } \hat{\gamma} - \gamma = -\frac{\gamma \sigma_2^2}{\sigma_V^2 + \sigma_2^2}.$  (37.9b)

In this case, both $\hat{\beta}$ and $\hat{\gamma}$ are downward biased estimators of $\beta$ and $\gamma$.

- Suppose that $\text{Cov}(UV) \neq 0$  
  - (i) If $\sigma_1^2 = 0$, $\sigma_2^2 > 0$,  
    - (a) $\text{plim } \hat{\beta} - \beta = \gamma b_{VU} \left(\frac{\sigma_2^2}{\sigma_2^2 + \sigma_V^2(1 - R_{UV}^2)}\right)$,  (37.10a)  
    - (b) $\text{plim } \hat{\gamma} - \gamma = \frac{-\gamma \sigma_2^2}{\sigma_V^2 - b_{VU} + \sigma_2^2}$,  (37.10b)  
    where $b_{VU}$ is the auxiliary regression coefficient of a regressing $V$ on $U$, and $R_{UV}^2$ is the correlation coefficient between $U$ and $V$.  
    Equation (37.10a) implies that the direction of the bias of $\hat{\beta}$ depends upon the sign of both $\gamma$ and $b_{VU}$; equation (37.10b) implies that $\hat{\gamma}$ is a downward biased estimator of $\gamma$ unless $(\sigma_V^2 - b_{VU} + \sigma_2^2)$ is greater than zero.  
  - (ii) If $\sigma_1^2 > 0$, $\sigma_2^2 = 0$,  
    - (a) $\text{plim } \hat{\beta} - \beta = \frac{-\beta \sigma_1^2}{\sigma_U^2 - b_{UV} + \sigma_1^2}$,  (37.11a)  
    - (b) $\text{plim } \hat{\gamma} - \gamma = \beta b_{UV} \left(\frac{\sigma_1^2}{\sigma_1^2 + \sigma_U^2(1 - R_{UV}^2)}\right) = 0$,  (37.11b)  
    where $b_{UV}$ = the auxiliary regression coefficient of regressing $U$ on $V$.

- (iii) If $\sigma_1^2 > 0, \quad \sigma_2^2 > 0,$

  - (a) $\operatorname{plim} \hat{\beta} - \beta = \frac{\gamma b_{VU} - \frac{\beta}{\sigma_V^2}(\sigma_V^2 \sigma_1^2 + \sigma_1^2 \sigma_2^2)}{\sigma_V^2 - b_{UV} + \sigma_2^2 + \frac{(\sigma_V^2 \sigma_1^2 + \sigma_1^2 \sigma_2^2)}{\sigma_V^2}}, \quad (37.12a)$

  - (b) $\operatorname{plim} \hat{\gamma} - \gamma = \frac{\beta b_{VU} - \frac{\gamma}{\sigma_V^2}(\sigma_U^2 \sigma_2^2 + \sigma_1^2 \sigma_2^2)}{\sigma_U^2 - b_{UV} + \sigma_1^2 + \frac{\sigma_V^2 \sigma_1^2 + \sigma_1^2 \sigma_2^2}{\sigma_V^2}}. \quad (37.12b)$

From equations (37.12a) and (37.12b), we can see that the direction of the biases of both $\hat{\beta}$ and $\hat{\gamma}$ are ambiguous.

### 37.2.2.2 The constrained classical case

If we impose $\beta + \gamma = 1$, and assume that only $V$ is measured with error, then (37.10a) should be rewritten as

$\operatorname{plim} \hat{\beta} - \beta = \frac{\sigma_\eta^2 (1 - \beta)}{\sigma_U^2 + \sigma_V^2 - 2\sigma_{UV} + \sigma_\eta^2}. \quad (37.13)$

The asymptotic bias of this case can be analyzed as follows:

- (i) If $\beta > 0$, then $\hat{\beta}$ is unbiased when $\beta = 1$, $\hat{\beta}$ is upward biased when $\beta < 1$ and $\hat{\beta}$ is downward biased when $\beta > 1$.
- (ii) If $\beta < 0$, then $\hat{\beta}$ is always upward biased.

Concerning the coefficient of the reliability, Cochran (1970) has shown that measurement errors of both explained and explanatory variables will reduce the multiple correlations and increase the residual variance. In addition, he also points out that the good prediction formula is more sensitive to measurement errors than the poor one. Moreover, from the analysis of the effects of measurement error on both the simple regression coefficient and residual variance, in general, we can conclude that the $t$ statistic of the simple regression coefficient will be downward biased if variables are measured with errors.

## 37.3 Estimation Methods When Variables are Subject to Error

In this section, we will discuss alternative EIV estimation methods, classical method, grouping method, instrumental variable method, mathematical method, maxima likelihood method, LISREL method, and the Bayesian approach. In addition, we will extend from simple regression to multiple regression.

### 37.3.1 Classical estimation method

### 37.3.1.1 The classical method to a simple regression analysis

In general, the classical method considers three cases: (i) either σ₁² or σ₂² is known; (ii) λ = σ₂² / σ₁² is known; and (iii) σ₁² and σ₂² are known. We can obtain the estimate for β from equation (37.2) under every possible situation as:

(i)  $\hat{\beta} = \frac{S_{XY}}{S_{XX} - \sigma_1^2}$, when $\sigma_1^2$ is known. (37.14)

$\hat{\beta} = \frac{S_{YY} - \sigma_2^2}{S_{XY}}$, when $\sigma_2^2$ is known. (37.15)

(ii) $\hat{\beta} = \frac{(S_{YY} - \lambda S_{XX}) + \{ (S_{YY} - \lambda S_{XX})^2 + 4\lambda S_{XY} \}^{1/2}}{2 S_{XY}}$, when $\lambda = \frac{\sigma_2^2}{\sigma_1^2}$ is known. (37.16)

(iii) When both σ₁² and σ₂² are known, Kendall and Stuart (1961) regarded it as an over-identified situation unless a non-zero covariance between U_i and V_i is introduced. Barnett (1967) followed Kiefer's (1964) suggestion and derived a consistent estimator of $\hat{\beta}$ as one of the real roots of equation (37.17).

$\hat{\beta}^4 - \left( \frac{1}{b_2} - \frac{\lambda}{b_1} - 2\lambda b_2 \right) \hat{\beta}^3 - 3\lambda \left( 1 - \lambda \frac{b_2}{b_1} \right) \hat{\beta}^2 + \lambda^2 \left( \lambda \frac{b_2}{b_1^2} - \frac{1}{b_1} - 2b_2 \right) \hat{\beta} - \lambda^3 \frac{b_2}{b_1} = 0$, (37.17)

where $S_{XX} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{n}$, $S_{YY} = \frac{\sum_{i=1}^n (Y_i - \bar{Y})^2}{n}$, $S_{XY} = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{n}$, $m_{XX} = Var(X) = \sigma_U^2 + \sigma_1^2$, $m_{YY} = Var(Y) = \beta^2 \sigma_U^2 + \sigma_2^2$, $m_{XY} = Cov(X,Y) = \beta \sigma_U^2$, $b_1 = \frac{m_{XY}}{m_{XX}}$, $b_2 = \frac{m_{XY}}{m_{YY}}$, and $\lambda = \frac{\sigma_2^2}{\sigma_1^2}$.

It has been shown that the meaningful solution of equation (37.17) is identical to equation (37.12a). The advantage of the knowledge of both σ₁² and σ₂² is that one obtains a more efficient estimator of $\hat{\beta}$.
