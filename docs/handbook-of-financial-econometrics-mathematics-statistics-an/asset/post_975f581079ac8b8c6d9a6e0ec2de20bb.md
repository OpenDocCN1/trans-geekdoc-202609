
In the original set of variables. Essentially, of interest in conducting PCA is the variance across data and the structure of its correlations. These ideas can be formalized by defining X to be an NxP matrix of data with var[X] = Σ and considering a linear combination of these data α₁ᵀ X. The method of PCA produces α₁, this is the eigenvector obtained from maximizing the explained variation in the data and making sure that the new variables are as uncorrelated as possible (e.g., see Flury, 1988 for more information). Formally, the method of PCA can be set up as the following optimization problem

```
max_{α₁} var[α₁ᵀ X]
s.t. α₁ᵀ α₁ = 1.
```

Moreover, it can be simplified as

```
{
max_{α₁} var[α₁ᵀ X]
s.t. α₁ᵀ α₁ = 1
}
≡ {
max_{α₁} α₁ᵀ var[X] α₁
s.t. α₁ᵀ α₁ = 1
}
≡ {
max_{α₁} α₁ᵀ Σ α₁
s.t. α₁ᵀ α₁ = 1.
}
```

The Lagrangian of this optimization is

```
L = α₁ᵀ Σ α₁ - λ₁(α₁ᵀ α₁ - 1). (61.1)
```

The first order condition is set up and simplified below

```
∂L/∂α₁ = 2Σ α₁ - 2λ₁ α₁ = 0
→ (Σ - λ₁ I_p) α₁ = 0. (61.2)
```

The eigenvector, also called the principal component, solves this equation.² The usefulness of this discussion as it relates to affine term structure models begins to become apparent when we note that this method of PCA is most suitable for inclusion in problems that are linear in nature. Hence, recent advances in the realm of dynamic term structure modeling focus on the static linear factor model as

```
y_{i,t} = β_i f_{it} + ε_{it}. (61.3)
```

In equation (61.3), y_it is the time-t observation from the ith maturity or cross-section of the yield curve, β_i is a N×1 vector of factor loadings and it describes how the yields relate to the ith principal component factor at time-t f_it. Finally, ε_it is the idiosyncratic noise component at time-t corresponding to the ith bond yield. In most applications ε_it i.i.d. ~ N(0, σ²). As a small demonstration of the suitability of PCA to parameter estimation in the factor model setting, we use zero coupon yield curve data from the US term structure spanning the period January 2000 through December 2017 to conduct principal component regressions (PCR). To implement PCR, we compute the eigenvectors using PCA, then, we regress the actual yield on the eigenvectors and finally, we compute the fitted yield as the product of the principal component factor and the factor loading as prescribed above. The root mean squared error representing the difference between the actual yield and the aforementioned fitted yield was of about order of magnitude 10⁻¹² for each yield. Moreover, the computation was completed in a matter of only a few seconds. We can also see from this discussion that, in principle, the application of PCA to a problem works well when large variances have important interpretations (e.g., see Schlens, 2005). Litterman and Scheinkman (1991) note that the first three principal components explain about 98% of the variation in the yield curve, and they interpret these factors as level, slope, and curvature based on how their changes impact bond yields. Hence, based on its suitability to linear factor structures, the ease of computational burden on the computer, and remarkable fit of the yield curve, early applications of PCA to the modeling of DTSM involve estimation with ordinary least squares regressions. In Section 61.2.2, we provide an overview of some of the more prominent early applications of PCA to DTSM.

## 61.2.2 Early Work on DTSM involving PCA

The purpose of this section is to provide an overview of some of the major model frameworks constructed in the extant literature on DTSM. We begin with a discussion of the model of Ang and Piazzesi (2003) in Section 61.2.2.1.

### 61.2.2.1 The model of Ang and Piazzesi (2003)

Ang and Piazzesi (2003) completed the first work that attempts to incorporate PCA into a dynamic term structure model.³ These authors develop a discrete-time dynamic term structure model that supposes that there are K₁

³For convenience, we retain much of the same notation as the authors.

observable macroeconomic variables $f_t^o$ and $K_2$ unobservable latent variables $f_t^u$ that are combined into vector $F_t = (f_t^{oT}, f_t^{uT})$. As their model incorporates several different components, it is estimated in several steps each of which we explain in the following. The first step involves the extraction of the macroeconomic variables and these are obtained from PCA in the following manner. We gather data on two groups of measures; inflation and real economic activity. We include in the first group CPI, the PPI of finished goods, and spot commodity prices. The second group of variables includes the index of help wanted advertising in newspapers, unemployment rate, the growth rate of employment, and the growth rate of industrial production. Then, we compute the first principal component from each of these two groups for inclusion as our macroeconomic variables, and so this means that $K_1 = 2$ in the estimation of this method. This vector is assumed to follow a Gaussian vector autoregressive process of order $p$:

$F_t = \Phi_0 + \Phi_1 F_{t-1} + \cdots + \Phi_p F_{t-p} + \theta u_t. \quad (61.4)$

In equation (61.4), $u_t \sim N(0,I)$. In order to simplify the estimation of the vector autoregressive process describing the state variables, the authors make a number of additional assumptions. We briefly describe them in the following. We use $x_t$ to describe the state of the economy and define it as a K by one vector, where, $K = K_1 p + K_2$, so with the assumption of three latent variables ($K_2 = 3$) and that we use p = 12 lags of real activity and inflation ($K_1 = 2$), $x_t$ is a 27 dimensional vector ($K = 2\times12 + 3 = 27$). Then, we partition $x_t$ into current and the 11 (p - 1) past lags of macroeconomic variables along with only contemporaneous latent factors and write $x_t = (x_t^{0T}, x_t^{uT})$ as

$x_t = \mu + \Phi x_{t-1} + \Sigma \varepsilon_t. \quad (61.5)$

We estimate the above Gaussian VAR dynamics by assuming independence across the error processes associated with macroeconomic variables $u_t^o$ and latent factors $u_t^u$, respectively, so that $\varepsilon_t = (u_t^{oT}, 0, \ldots, 0, u_t^{uT})^T$. In this system, $\mu$ is fixed to be a K-dimensional vector of zeros (please see the bottom of Table 6 on page 765 for detail) and $\Phi$ is a K $\times$ K matrix with the upper left $K_1 p \times K_1 p$ block containing coefficients corresponding to the macro factors and the lower-right $K_2 \times K_2$ corner is for the estimates of the latent factor coefficients. The remaining entries are zeros. Within this system above, we estimate the following bivariate process for the macro factors,

$f_t^o = \rho_1 f_{t-1}^o + \cdots + \rho_{12} f_{t-12}^o + \Omega u_t^o. \quad (61.6)$

In this expression, the coefficients corresponding to the lags of the macro factors ρ₁ to ρ₁₂ and the covariance matrix of the bivariate process Ω are 2 × 2 matrices with its error process given by uₜᵒ ∼ N(0,I). These macro factors comprise xₜᵒ, as xₜᵒ = (fₜᵒᵀ, fₜ₋₁ᵒᵀ, …, fₜ₋₍ₚ₋₁₎ᵒᵀ). We also estimate the following system for the latent factors,

$$f_t^u = \rho f_{t-1}^u + u_t^u.$$\tag{61.7}

In this system, the 3 × 3 matrix containing the coefficients corresponding to the latent factors ρ is lower-triangular with the error process modeled as a three-dimensional shock vector uₜᵘ ∼ N(0,I). This assumption ensures identification of the entire system and in Σ the lower-right corner of the matrix is given by the 3 × 3 identity matrix. On page 761 of their paper (Ang and Piazzesi, 2003), the authors note that they impose independence between macroeconomic and latent factors so that the upper-right 24 × 3 corner and lower-left 3 × 24 corner of the Φ and Σ matrices contain only zeros. These matrices are shown below,

$$\Phi_{\text{obs}} = \begin{bmatrix}
\rho_{1(2\times2)} & 0 & \cdots & 0 \\
0 & \ddots & 0 & \vdots \\
\vdots & 0 & \ddots & 0 \\
0 & \cdots & 0 & \rho_{12(2\times2)}
\end{bmatrix}_{(24\times24)},$$

$$\Phi = \begin{bmatrix}
\Phi_{\text{obs}(24\times24)} & 0_{24\times3} \\
0_{3\times24} & \Phi_{u(3\times3)}
\end{bmatrix}_{(27\times27)}.$$

We define Ω in a similar fashion,

$$\Omega_{\text{obs}} = \begin{bmatrix}
\Omega_{1(2\times2)} & 0 & \cdots & 0 \\
0 & \ddots & 0 & \vdots \\
\vdots & 0 & \ddots & 0 \\
0 & \cdots & 0 & \Omega_{12(2\times2)}
\end{bmatrix}_{(24\times24)},$$

$$\Sigma = \begin{bmatrix}
\Omega_{\text{obs}(24\times24)} & 0_{24\times3} \\
0_{3\times24} & I_{(3\times3)}
\end{bmatrix}_{(27\times27)}.$$
