Second, for each set, equations (48.12) and (48.13) are applied to derive the conditional $R_{t+1}^B(v_t,c_t)$ and $R_{t+1}^s(v_t,c_t)$. However, the value of $M_t^{t+1}(l,m,m)$ for each set should be decided first. Because there is a term $E_t[e^{-eta\phi_{t+1}(c_{t+1}-v_{t+1})}]$ inside $M_t^{t+1}(l,m,m)$, this expectation is needed to be calculated before deriving the value of $M_t^{t+1}(l,m,m)$ for each set. In this model, the arithmetic average of $e^{-eta\phi_{t+1}(c_{t+1}-v_{t+1})}$ is derived as the approximation of this expectation. Once we have the value of $E_t[e^{-eta\phi_{t+1}(c_{t+1}-v_{t+1})}]$, and for each set of $(c_{t+1},c_{t+2},v_{t+1},v_{t+2})$, we judge whether $c_{t+j}-v_{t+j}$ (j = 0, 1, 2) is larger than zero, then we can settle on the right form of $M_t^{t+1}(l,m,m)$ for each set. Given the information of $v_t$ and the chosen value of $c_t$, for each set of values $c_{t+1},c_{t+2},v_{t+1},v_{t+2}$, and $y_t^{t+1}$,^{12} the corresponding values of conditional $R_{t+1}^B(v_t,c_t)$ and $R_{t+1}^s(v_t,c_t)$ can be derived according to equations (48.12) and (48.13). Calculate the arithmetic average of rates of return over the 5000 sample sets, and we can obtain the values of the conditional expected rates of return, $R_{t+1}^B(v_t,c_t)$ and $R_{t+1}^s(v_t,c_t)$.
