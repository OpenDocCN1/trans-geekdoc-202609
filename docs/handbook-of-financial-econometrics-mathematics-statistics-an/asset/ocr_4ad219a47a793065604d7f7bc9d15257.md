$i = 1,\ldots,N$ and $t = 1,\ldots,T$, and column $j$, for $j = 1,\ldots,N$, is equal to 1 if $i = j$ and 0 otherwise. The $N$ vector $\gamma$ has typical element $v_i$ so that the $NT$ vector $D\gamma$ has $v_i$ in the row corresponding to observation $it$. Therefore there is exactly one element of $D$ equal to 1 in each row, which implies that the $NT$ vector $\mathbf{ι}$ with each element equal to 1 is a linear combination of the columns of $D$. The parameter vector $\gamma$ measures the impact of the *fixed effects*, $v_i$. They must be independent of the errors $\varepsilon_{it}$ but may be correlated with the $\mathbf{X}$ variables. Regardless, the fixed effects model (28.24), interpreted conditionally on $\gamma$, implies the following moment conditions are satisfied:

$$E\left(\mathbf{X}_{it}'\left(y_{it}-\mathbf{X}_{it}\beta-v_i\right)\right)=0 \quad\text{and}\quad E\left(y_{it}-\mathbf{X}_{it}\beta'z-v_i\right)=0. \tag{28.25}$$

The FE estimator (28.10) is based on these moment conditions. From Frisch and Waugh (1933) and Lovell (1963), we have what is known as the Frisch–Waugh–Lovell Theorem. The OLS estimator of $\beta$ in (28.24) can be obtained by regressing $\mathbf{M}_{D}\mathbf{y}$, the errors from a regression of $\mathbf{y}$ on $\mathbf{D}$, on $\mathbf{M}_{D}\mathbf{X}$, the matrix of errors from regressing each column of $\mathbf{X}$ on $\mathbf{D}$. This leads to the fixed effects estimator presented in (28.10). For any $NT$ vector $\mathbf{x}$, the group mean is $\bar{x}_i = \frac{1}{T}\sum_{t=1}^{T}x_{it}$. It is straightforward to check that element $it$ of the vector $\mathbf{M}_{D}\mathbf{X}$ is equal to the deviation from the group mean, $x_{it}-\bar{x}_i$.

In the linear (in parameters) FE model, the sufficient statistic is the group mean (a statistic is called sufficient for a parameter if the distribution of the sample given $i$ does not depend on the parameter). Since all the variables in (28.10) are premultiplied by $\mathbf{M}_{D}$, it follows that the estimator uses only information on the variation around the mean of each of the $N$ groups, which is why this is called the within-groups estimator. This estimator is unbiased if $\mathbf{X}$ and $\mathbf{D}$ are exogenous (if there is no contemporaneous correlation between explanatory variables and the error term). If the LS assumptions hold, the FE estimator is BLUE (the Gauss–Markov Theorem holds).

An advantage of the FE estimator is that it is easy to compute (all that is needed is to compute the $N$ group means for each variable if parameters associated with $\mathbf{D}$ are not of interest). Specification of the dummy variables is required only if estimates of $\hat{\gamma}$ are of interest. Multicollinearity may be an issue. If the $\mathbf{X}$ variables are well explained by the dummy variables in $\mathbf{D}$ then $\beta$ will not be precisely estimated with FE, due to the correlation between $\mathbf{X}$ and $\mathbf{D}$. Exact multicollinearity prohibits some specifications. The FE estimator cannot be used for explanatory variables that are constant within each cross-section because such a variable would be perfectly collinear with the columns of dummy variables, $\mathbf{D}$.
