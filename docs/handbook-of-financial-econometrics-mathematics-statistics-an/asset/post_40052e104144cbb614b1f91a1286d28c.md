## Appendix 66B: Definitions of Variables

| Variable | Definitions |
|---|---|
| Firm Value |  |
| Tobin's Q | Tobin's Q = (common stock + preferred stocks + short- and long-term loans and debt)/total assets. |
| Social Media |  |
| Facebook | Dummy variable that equals 1 if a firm's home page provides a link to an official Facebook page and 0 otherwise. |
| YouTube | Dummy variable that equals 1 if a firm's home page provides a link to an official YouTube channel and 0 otherwise. |
| Twitter | Dummy variable that equals 1 if a firm's home page provides a link to an official Twitter account and 0 otherwise. |
| Others | Dummy variable, 1 if a firm's home page has another social media contact icon such as Google+ or LinkedIn and 0 otherwise. |
| Bank Relationships |  |
| BankRelationship | Measured by the logarithm of 1 plus the total number of banks lending to a firm in a fiscal year. |
| BankDebt_TA | Measured by total bank loans divided by total assets. |
| Firm Characteristics |  |
| Age | The number of years since the firm was established. |
| LnSize | Firm size measured by the logarithm of a firm's book value of total assets. |
| Intan_Assets | Measured by total goodwill and intangible assets divided by total assets. |
| SaleGrowth | Sales growth rate measured by (Sales_t – Sales_{t-1})/Sales_{t-1}. |
| OCF_CL | Cash flow ratio measured by the book value of operating cash flows divided by the current liabilities. |
| Leverage | Measured by the book value of a firm's total liabilities divided by the total assets. |
| CurrentRatio | Current ratio measured by the book value of a firm's current assets divided by the current liabilities. |
| NWC_Assets | Working capital ratio measured by the net working capital divided by the total assets. |
