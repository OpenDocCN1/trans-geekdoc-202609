The impact of downside risk on the expected return lasts longer if downside risk is naively presumed to be a short memory. However, the dynamic path would die out much sooner after appropriately filtering out the long memory from downside risk. As a result, its unexpected impact would become modest and short-lived. In Figure 58.2, the gray lines depict the impulse response functions to a unit shock in short memory risk innovations, while the dark line exhibits the impulse response functions to a unit shock in long memory adjusted risk innovations. Using Hong Kong as an example, the one-period lagged impact of a downside risk shock with long memory adjustment on future returns is 0.0132; it is 0.0243 without a long memory adjustment. In addition, the shock lasts for at least 6 lagged periods before the long memory adjustment, whereas after filtering out the long memory, its impact lasts only 3 lagged periods.
