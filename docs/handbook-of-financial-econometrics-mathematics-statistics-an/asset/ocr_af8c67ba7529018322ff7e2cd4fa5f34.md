# 99.4.4 Testing of the price adjustment process

In this paper, we are more interested in the market adjustment parameter, γ. Compared with equilibrium model, the parameter of most interest in the disequilibrium model is the market adjustment parameter, γ. In the case of continuous time, the limiting values of γ are zero and infinity. If γ = 0, then there is no price adjustment in response to an excess demand, and if γ is infinity, it indicates instantaneous adjustment. In other words, if one assumes there is price rigidity in response to an excess demand, then the value of γ should be equal to zero. That is, the most important test of the disequilibrium model is to test the hypothesis that the price adjustment parameter is zero. The null hypothesis can be stated as follows: if there is no price adjustment mechanism in response to an excess demand, the value of γ will be equal to zero, or can be stated as

H₀ : γ = 0 vs. H₁ : γ ≠ 0.

This hypothesis will be empirically tested in the following section.
