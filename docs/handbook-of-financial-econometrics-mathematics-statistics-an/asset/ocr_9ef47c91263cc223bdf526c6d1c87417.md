# Overidentifying restrictions in GMM.

The validity of overidentifying instruments can be tested if the parameters of the overidentified model are estimated with optimal GMM. (No such test can be carried out for the model where the number of moments conditions is equal to the number of parameters to be estimated.) This test is commonly known as Hansen's (1982) J-statistic, which is χ² distributed with degrees of freedom equal to the number of overidentifying restrictions. It is equal to the optimized value of the GMM objective function (i.e., the GMM objective function evaluated at the optimal parameter values). This test goes by several other names as well, including a test of overidentifying restrictions, Hansens's test, Sargan's test, and the Hansen–Singleton test.

```
.estat overid

Test of overidentifying restriction:

Hansen's J chi2(1) = .000119 (p = 0.9913)
```

The test statistic is χ²(1) distributed since the number of overidentifying restrictions is 3 − 2 = 1. Given p = 0.9913 > 0.05, do not reject the null hypothesis H₀ : E { z′ ( c − β̂₀ − β̂₁ y ) } = 0, so the overidentifying restriction is valid. Note that this test does not imply that all instruments are valid, it only tests the validity of the overidentifying instruments. If the null hypothesis were rejected, the implication would be that the instruments are not valid (they do not satisfy orthogonality conditions).

The number of steps or iterations will not matter for the exactly identified (the same number of moment conditions and parameters to be estimated) regressions. However, if there are more moment conditions than parameters to be estimated then iteration can improve results. Compare the one-step and iterative results below to the two-step directly above.
