# 33.3.2 Internal consistency

First, we study the internal consistency of the Heston stochastic volatility model by testing Hypothesis 1. To this end, we fit the discretized time series model specification (33.5) to calibrated variances, {$V^{SV}$}_t, using the Maximum Likelihood (ML) estimation technique. Since the Heston option-pricing model is re-calibrated daily, a time series of parameters {\eta^c,\rho^c}_t emerges. To mirror daily Heston model re-calibration, the time series model is also re-estimated daily, using a 500-observation rolling window.
