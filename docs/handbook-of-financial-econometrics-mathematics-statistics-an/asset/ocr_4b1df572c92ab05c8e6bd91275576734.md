# Appendix 11A: (Continued)

| References | Return definition and objective function | Summary |
|------------|-------------------------------------------|---------|
| Lien and Luo (1993b) | Ret1 O9 | This chapter derives the multi-period hedge ratios where the hedge ratios are allowed to change over the hedging period. The method suggested in this chapter still falls under the MV hedge ratio. |
| Lence (1995) | O4 | This chapter derives the expected utility maximizing hedge ratio where the terminal wealth depends on the return on a diversified portfolio that consists of the production of a spot commodity, investment in a risk-free asset, investment in a risky asset, as well as borrowing. It also incorporates the transaction costs. |
| De Jong, De Roon, and Veld (1997) | Ret2 O7 (also uses O1 and O3) | This chapter derives the optimal hedge ratio that minimizes the GSV. It also compares the GSV hedge ratio with the MV hedge ratio as well as the Sharpe hedge ratio. It uses E1 (for the MV hedge ratio), E3 (for the Sharpe hedge ratio) and E4 (for the GSV hedge ratio) as the measures of hedging effectiveness. |
| Chen, Lee, and Shrestha (2001) | Ret1 O8 | This chapter derives the optimal hedge ratio that maximizes the risk-return function given by U(R_h) = E[R_h] - V_{δ,α}(R_h). The method can be considered as an extension of the GSV method used by De Jong et al. (1997). |
| Hung, Chiu, and Lee, M.C. (2006) | Ret2 O10 | This chapter derives the optimal hedge ratio that minimizes the VaR for a hedging horizon of length τ given by Z_α σ_h √τ - E[R_h]τ. |

Notes:

A. Return model:

(Ret1) ΔV_H = C_s ΔP_s + C_f ΔP_f ⇒ hedge ratio = H = C_f / C_s , C_s = units of spot commodity and C_f = units of futures contract

(Ret2) R_h = R_s + h R_f , R_s = (S_t - S_{t-1}) / S_{t-1}

(a) R_f = (F_t - F_{t-1}) / F_{t-1} ⇒ hedge ratio: h = C_f / C_s 

(b) R_f = (F_t - F_{t-1}) / S_{t-1} ⇒ hedge ratio: h = C_f / C_s .
