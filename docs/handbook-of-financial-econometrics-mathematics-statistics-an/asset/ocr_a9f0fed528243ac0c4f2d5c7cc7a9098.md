# 58.4.2 Tests for long memory

The long memory model provides a middle ground between short memory and unit root specification; therefore, it is necessary to test the appropriateness of a filtering process of I(d) against two extremes, I(0), and I(1), for the downside risk series. The estimates of the long memory parameters (d_EML and d_GPH) using both the parametric method (the EML) and the semi-parametric method (the GPH) are reported in Table 58.4. The significance of the long memory parameters can be justified by using the estimated t-statistics. The null for the absence of a long memory is set by H₀ : d = 0 and we test for a unit root by H₀ : d = 1. The statistics indicate that the semi-parametric point estimates of d_GPH in Table 58.4 range widely from 0.356 to 0.742, falling in between the stationary and non-stationary regions. The estimated d_GPH values vary around 0.5. The South Korea, Hong Kong, Singapore, and Taiwan markets are classified as the more advanced emerging markets, and the estimated d_GPH < 0.5, suggesting that the behavior of the autocorrelation function (ACF) decays at a polynomial, rather than an exponential, rate. The parametric estimates, d_EML, all are below 0.5, indicating a stationary long memory. However, the literature suggests that the estimates obtained from the EML appear less robust in the large sample, so that the semi-parametric estimate is preferred to get rid of the large sample bias.
