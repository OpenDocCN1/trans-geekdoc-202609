# Theorem 41B.3: Let $h$ be a bounded Borel-measurable function. If $h$ is continuous at $x$, then $T_B^{\pm}$ are both differentiable at $x$ and $(\frac{d}{dx} - B) T_B^{\pm} = -(B + \frac{d}{dx}) T_B^- = I$. Moreover, if $h \in C_{0,b}(R_{++})$, each entry of $T_B^{\pm} h$ is in $C_{0,b}(R_{++})$.

Proof. Assume that $h$ is bounded and continuous at $x$. By Theorem 41B.1(1), $\frac{d}{dx} e^{Bx} = B e^{Bx}$. On the other hand, since $h$ is continuous at $x$, $\frac{d}{dx} \int_{-\infty}^x h(y) e^{-B y} dy = h(x) e^{-x B}$. Therefore,

$$\frac{d}{dx} T_B^+ h(x) = \frac{d}{dx} \left( e^{Bx} \int_{-\infty}^x h(y) e^{-B y} dy \right) = B T_B^+ h(x) = h(x) I.$$

This shows that $(\frac{d}{dx} - B) T_B^+ h(x) = h(x) I$. Similarly, $-(B + \frac{d}{dx}) T_B^- h(x) = h(x) I$. Finally, if $h \in C_{0,b}(R_{++})$, then it is clear that $T_B^{\pm} h$ is bounded on $R$. Moreover, by dominated convergence, $T_B^{\pm} h \in C_{0,b}(R_{++})$. This proves the last statement.

# Appendix 41C: First-Order Derivative of $\Phi$ at Zero

We consider the process (41.2) and set

$$\Delta = \sup \left\{ \xi \in R_+; \int e^{\xi y} dF(y) < \infty, \forall \xi \in [0, \xi] \right\}. \tag{41C.1}$$

Throughout this section, we assume that $\Delta > 0$ and $\psi(\Delta-) > 0$. Let $r > 0$. Since $\psi(0) - r < 0$ and $\psi$ is strictly convex on $[0,\Delta)$, there exists a unique number $\rho^* \in (0,\Delta)$ such that $\psi(\rho^*) - r = 0$. $$\beta = \frac{c}{D} + \rho^*, \ \alpha = \beta + \rho^*, \tag{41C.2}$$
