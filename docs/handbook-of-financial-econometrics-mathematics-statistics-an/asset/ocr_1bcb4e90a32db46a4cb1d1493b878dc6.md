# Abstract

In this chapter, we will discuss how to use discriminant analysis to do credit analysis and calculate financial z-score, then we will use both discriminant analysis and factor analysis to forecast bond rating by using financial ratio information. In addition, we will discuss Ohlson’s model and the KMV–Merton model for default probability estimation. Finally, we will cite some empirical results about default probability estimation and compare the results of two different probability estimation models.

# 78.1 Introduction

Anderson (2003) has discussed theoretical and methodological results of discriminant analysis and factor analysis. This chapter will show how this method can be used to analyze financial data and perform related financial decision-making. Section 78.2 discusses how discriminant analysis can be used in loan credit analysis. Section 78.3 applies discriminant analysis to bankruptcy and financial distress analysis, as well as possible problems faced in using discriminant analysis are discussed. Section 78.4 demonstrates how the factor-analysis technique can be used to select useful financial ratios. Section 78.5 discusses how k-group discriminant-analysis methods can be used to forecast bond ratings. Also explored in this section is the method of combining factor analysis and discriminant analysis in financial analysis application. Section 78.6 explores the issues related to bond quality ratings and the change of quality rating for the electric utility industry. Section 78.7 discusses other models for estimating default probability. Finally, Section 78.8 summarizes the results of this chapter.
