## Appendix 73A: Standardized Student’s t-Distribution

Let T be a continuous variable with domain D = (-∞,∞), while its distribution function F is given by F(t) = P(T ≤ t). If T follows a Student’s t-distribution with v degrees of freedom, its density function is

$$f_v(t) = (v\pi)^{-1/2} \cdot \frac{\Gamma((v+1)/2)}{\Gamma(v/2)} \cdot \left(1 + \frac{t^2}{v}\right)^{-(v+1)/2}$$

where Γ is the gamma function. If we define X = μ + σT, then X has a generalized t-distribution with density function as follows:

$$f_v(x|\mu,\beta) = (\beta v \pi)^{-1/2} \cdot \frac{\Gamma((v+1)/2)}{\Gamma(v/2)} \cdot \left(1 + \frac{(x-\mu)^2}{\beta v}\right)^{-(v+1)/2}$$

where the expectation of X is μ, and the variance of X is σ² = βv(v-2)⁻¹. If μ = 0 and βv = v-2 (so that σ² = 1), then X ∼ t_v(0,1), and the density function for the standardized Student’s t-distribution is as follows:

$$f_v(x) = (\pi(v-2))^{-1/2} \cdot \frac{\Gamma((v+1)/2)}{\Gamma(v/2)} \cdot \left(1 + \frac{x^2}{v-2}\right)^{-(v+1)/2}$$

If the degree of freedom is small, the distribution will have a lower peak and longer tails compared to a normal distribution. As ν → ∞, the distribution approaches the normal distribution with mean 0 and variance 1.

## Appendix 73B: Density Functions for Elliptical Copulas

The Gaussian copula distribution cannot be written in a simple closed form, and it can only be expressed as an integral. When n = 2, the bivariate Gaussian copula function is

$$C(u_1, u_2; \varrho) = \Phi_\varrho(\Phi^{-1}(u_1), \Phi^{-1}(u_2)) = \int_{-\infty}^{\Phi^{-1}(u_1)} \int_{-\infty}^{\Phi^{-1}(u_2)} (2\pi)^{-1}(1 - \varrho^2)^{-1/2} \exp\left(-\frac{x_1^2 - 2\varrho x_1 x_2 + x_2^2}{2(1 - \varrho^2)}\right) dx_1 dx_2,$$

where $\varrho$ is the correlation coefficient between the two variables. Differentiating the function, the bivariate Gaussian copula density function is

$$c(u_1, u_2; \varrho) = (1 - \varrho^2)^{-1/2} \exp\left(-\frac{\varrho^2 \xi_1^2 - 2\varrho \xi_1 \xi_2 + \varrho^2 \xi_2^2}{2(1 - \varrho^2)}\right).$$

Similarly, the Student's $t$ copula distribution cannot be written in a simple closed form. When $n = 2$, the bivariate Student's $t$ copula function is

$$C(u_1, u_2; \varrho) = t_{v,\varrho}(t_v^{-1}(u_1), t_v^{-1}(u_2)) = \int_{-\infty}^{t_v^{-1}(u_1)} \int_{-\infty}^{t_v^{-1}(u_2)} (2\pi)^{-1}(1 - \varrho^2)^{-1/2} \left[1 + v^{-1}\frac{x_1^2 - 2\varrho x_1 x_2 + x_2^2}{1 - \varrho^2}\right]^{-(v+2)/2} dx_1 dx_2.$$

Differentiating the function, the bivariate Student's $t$ copula density function is

$$c(u_1, u_2; \varrho) = K (1 - \varrho^2)^{-1/2} \left[1 + v^{-1}(1 - \varrho^2)^{-1} (\xi_1^2 - 2\varrho \xi_1 \xi_2 + \xi_2^2)\right]^{-(v+2)/2} \cdot \left[(1 + v^{-1} \xi_1^2)(1 + v^{-1} \xi_2^2)\right]^{(v+1)/2},$$

where $\xi_1 = t_v^{-1}(u_1)$ and $\xi_2 = t_v^{-1}(u_2)$ are realizations of the Student's $t$ variables, and $K$ is a constant, $K = \Gamma(v/2) \cdot \Gamma((v+1)/2)^{-2} \cdot \Gamma((v+2)/2).$

## Appendix 73C: Maximum Likelihood Estimation

The full maximum likelihood estimation (MLE) method can be applied to estimate the copula parameters. Let the joint density be expressed as follows:

$$f(x_1, \dots, x_n) = c(F_1(x_1), \dots, F_n(x_n)) \cdot f_1(x_1) \cdots f_n(x_n).$$

Denoting the marginal densities and distributions as $f_i(x_i;\alpha_i)$ and $F_i(x_i;\alpha_i)$, the joint density can be written as

$$f(x_1,\dots,x_n;\boldsymbol{\alpha},\boldsymbol{\theta}) = c(F_1(x_1;\alpha_1),\dots,F_n(x_n;\alpha_n);\boldsymbol{\theta})\cdot\prod_{i=1}^n f_i(x_i;\alpha_i),$$

where $\boldsymbol{\alpha}=(\alpha_1,\dots,\alpha_n)$ is the vector of parameters for the marginal densities, and $\boldsymbol{\theta}=(\theta_1,\dots,\theta_n)$ is the vector of copula parameters. Hence, the log likelihood function is

$$\ln L(\boldsymbol{\alpha},\boldsymbol{\theta},\boldsymbol{X}_1,\dots,\boldsymbol{X}_T) = \sum_{t=1}^T\left(\ln c(F_1(x_{1t};\alpha_1),\dots,F_n(x_{nt};\alpha_n);\boldsymbol{\theta}) + \sum_{i=1}^n \ln f_i(x_{it};\alpha_i)\right),$$

where $\boldsymbol{X}_t=(x_{1t},\dots,x_{nt})$ is the row vector of observations on $n$ random variables at time $t$. Thus, it is possible to maximize the log likelihood in two separate steps as follows:

- (i) Estimate the parameters ($\hat{\alpha}_i$) for each marginal density individually by using MLE

$$\max_{\alpha_i}\sum_{i=1}^T\ln f_i(x_{it};\alpha_i),\quad\text{for }i=1,\dots,n.$$

- (ii) Estimate the copula parameters by solving

$$\max_{\theta}\sum_{t=1}^T\ln c(F_1(x_{1t};\hat{\alpha}_1),\dots,F_n(x_{nt};\hat{\alpha}_n);\boldsymbol{\theta}).$$

Let us consider these steps for the estimation of a Clayton copula. First, the two variables are standardized at the mean level. Then, the parameter ($\hat{v}_i$) of the standardized Student's $t$-distribution density for each standardized variable is estimated individually using MLE. The following function is maximized:

$$\max_{v_i}\sum_{i=1}^T\ln f_i(x_{it};v_i),\quad\text{for }i=1,2,$$

where $f_v(x)=(\pi(v-2))^{-(1/2)}\cdot\Gamma(v/2)^{-1}\cdot\Gamma((v+1)/2)\cdot\left(1+\frac{x^2}{v-2}\right)^{-(v+1)/2}$.
