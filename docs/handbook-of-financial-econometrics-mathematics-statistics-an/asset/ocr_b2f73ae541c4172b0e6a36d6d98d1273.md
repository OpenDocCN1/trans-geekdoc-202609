# Appendix 57A: Proof of Lemma 57.2.3

Recall the matrix Ξ is the variance–covariance for the whole population, which can be decomposed into the within-group variance–covariance matrix Σ and the variability between the K groups as Ξ = Σ + ∑_{i=1}^k w_i (μ_i - μ̄)(μ_i - μ̄)'.

The objective function g₂(ξ) in (57.5) can be decomposed accordingly and rewritten as g₂(ξ_i) = (1 / ξ_i' Σ^{-1} ξ_i) {ξ_i' (I_{p×p} + A) ξ_i}, (57A.1) where the positive-definite matrix A = Σ^{-1/2} (∑_{j=1}^K w_j (μ_j - μ̄)(μ_j - μ̄)')^{-1/2} Σ .

To maximize the two objective functions g₁(ξ) and g₂(ξ) subject to the constraints that ξ'ξ = 1 and ξ' ξ_j = 0 for all j < i, consider the matrices W₁ = (I_{p×p} - P_i)A(I_{p×p} - P_i) and W₂ = (I_{p×p} - P_i)Σ^{-1}(I_{p×p} - P_i), where I_{p×p} is the identity matrix and P_i is the projection matrix that maps vectors in R^N onto the subspace spanned by ξ₁,…,ξ_{i-1}. By Lemma 57.2.2, the objective g₁(ξ) can be rewritten as g₁(ξ) = ξ'W₁ξ. By Lemma 57.2.2 and (57A.1), ξ' ξ_j = 0 for all j < i, the objective g₂(ξ) can be rewritten as g₂(ξ) = ξ'{I_{p×p} + W₁}ξ / ξ'W₂ξ .

Let λ₁* ≥ λ₂* ≥ ⋯ ≥ λ_p* ≥ 0 and λ₁ ≥ λ₂ ≥ ⋯ ≥ λ_p ≥ 0 be the eigenvalues of W₁ and W₂, respectively. If W₁ and W₂ share the same normalized eigenvector v₁ corresponding to the largest eigenvalues λ₁* and λ₁, respectively, then the two objective functions g₁(ξ) and g₂(ξ) are maximized simultaneously at ξ* = v₁ subject to the constraints that ξ*'ξ* = 1 and ξ*'ξ_j = 0 for all j < i. In addition, g₁(ξ*) = λ₁* and g₂(ξ*) = λ₁(λ₁ + 1).
