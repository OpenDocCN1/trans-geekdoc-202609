## 6.3.2 Integration of the intervention analysis into ARIMA-GARCH model

When establishing the ARIMA process model, the researchers first determined the order of the series: ARIMA(p,1,q) p < 5, q < 5. According to the selection standards for Akaike Information Criterion (AIC) and Schwarz Information Criterion (SIC), ARIMA (0,1,1) achieved the minimum AIC and SIC. In the Ljung-Box Q test, the residuals had no autocorrelation, but the Ljung-Box Q² test showed that the residuals were inconsistent; in other words, the residuals demonstrated the problem of heteroskedasticity. The researchers used ARIMA (0,1,1)-GARCH(1,1) to modify the model, but the residual problem had not been solved completely. According to the outlier detection results shown in Table 6.3, the model detected the temporary changes (TC) in July 1997, July 2007, and additive outliers (AO) in November 1993, and November 2001.

According to Box and Tiao (1975), when affected by external events at a specific point in time, intervention analysis should be incorporated in the model establishment process. The detected external events of July 1997, July 2007, November 1993, and November 2001 are, therefore, incorporated into the model analysis to construct the model for the TAIEX, which can be represented as follows:

## 6.3.4 Multiple transfer function

According to the multiple transfer function method proposed by Liu and Hanssens (1982) and Kaylen (1986), the researchers selected a random efficient ℓ value and a reasonable disturbance term to estimate the multiple transfer function. By repeated screening and estimation, the researchers applied the multiple transfer function model until the residual self-correlation function was consistent with white noise and the parameter estimated value of the disturbance terms was not close to 1. Because the series was affected by external events in July 1997, July 2007, November 1993, and November 2001, the intervention analysis was incorporated to reconstruct the multiple transfer function model. According to estimation results as shown in Table 6.7, the model parameter values were all significant, and the residues are consistent with the white noise. Therefore, the TAIEX model with the intervention analysis integrated into the multiple transfer function model can be represented as follows:

```
Δᵈ ln Pₜ = 0.317 I₁ₜ − 0.024 I₂ₜ + 0.251 I₃ₜ − 0.019 I₄ₜ + 0.717 Δᵈ ln Dₜ
          − 1.035 Δᵈ ln Eₜ − 0.613 Δᵈ ln Cₜ₋₁ + εₜ + 0.172 εₜ₋₁,
εₜ ∼ N(0, σ²_{ε,t}).
(6.4)
```

Preliminary determination showed that the model can operate in the following three situations:

- 1. The INDU positively affects with the TAIEX mainly because the INDU is one of the indicators of investor observations; when the INDU fluctuates, the TAIEX is affected.
- 2. The exchange rate negatively affects with the TAIEX mainly because fluctuations in the exchange rate will affect foreign funds. When the exchange rate increases, the NTD depreciates, and the flow of foreign funds into the stock market is diminished.
- 3. The consumer price index negatively affects the TAIEX mainly because fluctuation will affect the opportunity cost of currency holding. When the consumer price index increases, the opportunity cost of holding currency will increase, and then the investment in TAIEX will also decrease.
