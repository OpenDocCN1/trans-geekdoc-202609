+   1. Generate $\lambda_{t+1}^{(j)}$ from its predicative distribution $p(\lambda_{t+1}|\lambda_{1:t}^{(j)},\mathrm{KF}_t^{(j)},y_{t+1})$;
+   2. Obtain $\mathrm{KF}_{t+1}^{(j)}$ by a one-step Kalman filter, conditional on {$\mathrm{KF}_t^{(j)}$, $z_{t+1}$, $\lambda_{t+1}^{(j)}$},
+   $P_{t+1}=H_{\lambda_{t+1}}\Sigma_t H'_{\lambda_{t+1}}+W_{\lambda_{t+1}}W'_{\lambda_{t+1}}$
+   $S_{t+1}=GP_{t+1}G'+VV'$, 
+   $\mu_{t+1}=H_{\lambda_{t+1}}\mu_t+P_{t+1}G'S_{t+1}^{-1}(z_{t+1}-GH_{\lambda_{t+1}}\mu_t-Dg_{t+1})$
+   $\Sigma_{t+1}=P_{t+1}-P_{t+1}G'S_{t+1}^{-1}GP_{t+1}$; and
+   3. Update the new weight as $w_{t+1}^{(j)}=w_t^{(j)}\times u_{t+1}^{(j)}$, where
+   $u_{t+1}^{(j)}=\frac{p(\lambda_{1:t}^{(j)},\lambda_{t+1}^{(j)}|y_{1:t+1})}{p(\lambda_{1:t}^{(j)}|y_{1:t})p(\lambda_{t+1}^{(j)}|\lambda_{1:t}^{(j)},\mathrm{KF}_t^{(j)},y_{t+1})}\propto p(y_{t+1}|\mathrm{KF}_t^{(j)})$ 
+   $=\sum_{i\in I}p(y_{t+1}|\Lambda_{t+1}=i,\mathrm{KF}_t^{(j)})p(\Lambda_{t+1}=i|\lambda_{1:t}^{(j)})$, 
+   4. (resampling-rejuvenation) if the coefficient of variance of the $w_{t+1}$ exceeds a threshold value, resample a new set of $\mathrm{KF}_{t+1}$ from {$\mathrm{KF}_t^{(1)},...,\mathrm{KF}_t^{(m)}$} with probability proportional to the weights $w_{t+1}^{(j)}$.

where $I$ is the set of possible values of $\Lambda_t$. Specifically, the MKF updating step 3 can be implemented in the following steps:

+   (3.1) for each $\Lambda_{t+1}=i$, $i\in I$, run the Kalman filter to obtain $v_i^{(j)}\propto p(y_{t+1}|\Lambda_{t+1}=i,\mathrm{KF}_t^{(j)})p(\Lambda_{t+1}=i|\lambda_{1:t}^{(j)})$, where $p(\Lambda_{t+1}=i|\lambda_{1:t}^{(j)})$ is the prior transition probability for the indicator and $p(y_{t+1}|\Lambda_{t+1}=i,KF_t^{(j)})$ is a by-product of the Kalman filter $p(y_{t+1}|y_{1:t},\lambda_{1:t},\lambda_{t+1})\sim N(GH_{\lambda_{t+1}}\mu_t+Dg_{t+1},S_{t+1})$;
+   (3.2) sample a $\lambda_{t+1}^{(j)}$ from the set $I$, with probability proportional to $v_t^{(j)}$;
+   (3.3) let $\mathrm{KF}_{t+1}^{(j)}$ be the one with $\Lambda_{t+1}=\lambda_{t+1}^{(j)}$; and
+   (3.4) the new weight is $w_{t+1}^{(j)}=w_t^{(j)}\sum_{i\in I}v_i^{(j)}$.
