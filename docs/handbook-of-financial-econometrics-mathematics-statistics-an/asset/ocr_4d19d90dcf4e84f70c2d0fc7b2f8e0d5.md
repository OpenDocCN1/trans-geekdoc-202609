In this section, we will compare the performance of \hat{S}^2, \hat{S}^2_{less_biased}, \hat{S}^2_{less_biased+}, \hat{S}^2_{Bayes}, \hat{S}^2_{mixed} and \hat{S}^2_{adj}. We assume asset return multivariate normally distributed and use simulation to evaluate bias and RMSE of six estimators. The true values of parameters are assumed to be estimates of \hat{\psi}^2_u, \hat{\mu}_g, \hat{\sigma}^2_{gu} by value-weighted monthly returns on the US market from July 1926 to December 2017: \psi^2 = 0.043037, \mu_g = 0.007426, \sigma^2_g = 0.001962 and S^2 = 0.071148. Here, we ignore the estimation error in (\hat{\mu}_g^+)^2 / \hat{\sigma}^2_{gu} (m_g = 0.000971), so S^2 = 0.071148 is slightly different from \hat{S}^2_{less_biased} = 0.070181 in Table 74.4.
