¹⁶ Note that for a typical long memory process, if one just simply takes a first difference, the series is likely to be overdifferenced. Granger and Ding (1996), Parke (1999) and Tsay (2010) provide detailed illustrations of long-memory models and discuss the processes in relation to different regimes of d.

To model the long memory in downside risk, we consider the autoregressive fractionally integrated moving average (ARFIMA) process.¹⁷ A process is usually labeled as an ARFIMA(p, d, q) process if its d-th difference is stationary and invertible, where d is not an integer. To be specific, a demeaned downside risk can be expressed as:

φ_i(L)(1 − L)^d V_{i,t} = ψ_i(L) ε_{i,t}    (58.10)

where φ_i(L) = 1 − Σ_{k=1}^p φ_k L^k and ψ_i(L) = 1 + Σ_{k=1}^q ψ_k L^k are polynomials of orders p and q in the lag operator L with roots strictly outside the unit circle. Instead of modeling the data as either I(0) or as integrated I(1), (1 − L)^d allows us to more accurately and flexibly deal with the data by using a fractional filter that estimates the value of d to govern the long memory process.

¹⁷ The ARFIMA process is distinct from the traditional stationary ARMA process having a short memory with d = 0 in the sense that the autocorrelation function decays exponentially.

The memory parameter d can be estimated by the parametric, the semi-parametric, and the non-parametric approaches. The conventional approach uses the log-periodogram estimator developed by Geweke and Porter-Hudak (1983, hereafter GPH) because of the required weaker assumptions on the short memory process ε_{i,t} in equation (58.10).¹⁸ GPH demonstrate that for frequencies near zero, d can be consistently estimated from the least-squares regression and is popularized as a log-periodogram model. In the expression,

log(I(θ_j)) = C − d log{4 sin²(θ_j/2)} + ε_j    (58.11)

where I(θ_j) = (Σ_{t=1}^T V_{i,t} exp(iθ_j t))² / 2πT is the periodogram of downside risk, V_t, evaluated at the frequencies θ_j = 2πj / T, j ∈ (l, m), where l is a trimming parameter discarding the lowest frequencies and m is a bandwidth parameter with m = T^α, 0 < α < 1, where T is the sample size. GPH propose the estimation of d_GPH by regressing the log-periodogram I(θ_j) at frequencies θ_j against a constant and log{4 sin²(θ_j/2)}. Owing to their popularity and several statistical advantages, we focus on the GPH estimators (d_GPH) in the bivariate system.¹⁹

¹⁸ The Gaussian semi-parametric estimator developed by Robinson (1995) is considered as an alternative approach. Baillie (1996) argues that the GPH estimator is potentially robust to non-normality.

¹⁹ One of the statistical advantages of this approach is that d can be tested using standard t-statistics (Hassler et al., 2006). In addition, the estimate of d is consistent and asymptotically normally distributed.

Alternatively, Sowell (1992) derives the exact Maximum Likelihood Estimator (EML) for estimating the ARFIMA(p, d, q) process in equation (58.10) with unconditionally normally distributed disturbances, ε_{i,t}. For comparison, we compute the EML estimators (d_EML) for the long memory parameters, although they may be less robust in large samples and subject to model selection. The non-parametric estimators, however, are often criticized for not satisfying asymptotic theory and for a lack of robustness (Sibbertsen, 2004).

### 58.4.2 Tests for long memory

The long memory model provides a middle ground between short memory and unit root specification; therefore, it is necessary to test the appropriateness of a filtering process of I(d) against two extremes, I(0), and I(1), for the downside risk series. The estimates of the long memory parameters (d_EML and d_GPH) using both the parametric method (the EML) and the semi-parametric method (the GPH) are reported in Table 58.4. The significance of the long memory parameters can be justified by using the estimated t-statistics. The null for the absence of a long memory is set by H₀: d = 0 and we test for a unit root by H₀: d = 1. The statistics indicate that the semi-parametric point estimates of d_GPH in Table 58.4 range widely from 0.356 to 0.742, falling in between the stationary and non-stationary regions. The estimated d_GPH values vary around 0.5. The South Korea, Hong Kong, Singapore, and Taiwan markets are classified as the more advanced emerging markets, and the estimated d_GPH < 0.5, suggesting that the behavior of the autocorrelation function (ACF) decays at a polynomial, rather than an exponential, rate. The parametric estimates, d_EML, are all below 0.5, indicating a stationary long memory. However, the literature suggests that the estimates obtained from the EML appear less robust in the large sample, so that the semi-parametric estimate is preferred to get rid of the large sample bias.

As indicated by the statistics, the testing results from both the EML and the GPH methods indicate the rejection of the hypothesis d = 0 and d = 1, confirming that downside risk is characterized by long memory behavior. In particular, the column labeled τ_d = 1 in Table 58.4 reports the test statistic (d_EML − 1)/σ_d, and the column labeled τ_d = 0 reports the test statistic (d_EML − 0)/σ_d.
