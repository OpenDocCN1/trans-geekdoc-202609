# Appendix 57B: Proof of Lemma 57.2.4

Using (57A.1), the logarithm of $g_2(\xi)$ can be decomposed as

$$\log[g_2(\xi_i)] = \log\left(\frac{1}{\xi_i'\Sigma^{-1}\xi_i}\right) + \log\{\xi_i'(\mathbf{I}_{p\times p} + \mathbf{A})\xi_i\}.$$

As the first component is maximized at $\boldsymbol{u}_1$ and the second component is maximized at $\boldsymbol{v}_1$, one can conclude that $\log(g_2(\xi_i))$ is maximized at $\xi_i = (\alpha\boldsymbol{v}_1 + (1-\alpha)\boldsymbol{u}_1)/|\alpha\boldsymbol{v}_1 + (1-\alpha)\boldsymbol{u}_1|$ for some $0 \le \alpha \le 1$.
