# 6.3.1 Data

The basic statistics of each variable are shown in Table 6.1. Dickey and Fuller (1979) used the unit root test to deal with the problem of the nonstationary series. According to test results shown in Table 6.2, all series are stationary after first-order differentiation.

To confirm that the series can be used to construct the multiple transfer function model, the researchers first conducted the Granger causality test on the series; according to results, several time-series, including the INDU, exchange rate, and consumer price index, led the TAIEX; however, the INDU, exchange rate, and consumer price index were mutually independent. According to Granger and Newbold (1974), spurious regression may occur between nonstationary variables; therefore, a test was conducted
