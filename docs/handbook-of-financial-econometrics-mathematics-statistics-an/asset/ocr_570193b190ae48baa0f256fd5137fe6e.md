(c) In order to have x satisfy the limit norm condition, $x'x = 1$, we divided each element of

$$\begin{bmatrix}36\\18\\36\end{bmatrix}$$

by $\sqrt{36^2 + 18^2 + 36^2} = 54$, and obtain

$x' = \left(\frac{36}{54}\ \frac{18}{54}\ \frac{36}{54}\right) = [0.6667\ \ 0.3333\ \ 0.6667]$

This example has shown how the solution of a special kind of homogeneous-equation system (as indicated in equation (77.7)) can be solved. This kind of equation system differs in two respects from the regular equation system of equation (77.4). First, the vector of constraint on the right-hand side is a null vector. Second, the matrix of coefficients on the left-hand side, $A - \lambda I$, involves an unknown scalar quantity $A$. Therefore, in order to solve $x$, we should first solve $\lambda$ by using the characteristic equation of matrix $A'$ as indicated in equation (77.8).

Alternatively, $x$ can be solved by the equation system as

$-5x_1 + 2x_2 + 4x_3 = 0,$
$2x_1 - 8x_2 + 2x_3 = 0,$
$4x_1 + 2x_2 - 5x_3 = 0.$

The solution of this equation system is $2x_1 = x_2 = 2x_3$. Hence, $(2d, d, 2d)$ is the eigenvector associated with the eigenvalue $\lambda = 8$ (where $d$ is a constant). This implies that one element in the eigenvector is arbitrary. We may normalize the vector by setting its length at unity, $x_1^2 + x_2^2 + x_3^2 = 1$, and obtain the normalized solution as indicated above.

The concepts and methods of solving for eigenvalue and eigenvectors discussed in this section are important to understand both discriminant analysis and factor analysis, which will be discussed in later sections of this chapter.

$A^{-1} = \frac{1}{|A|}\ \text{(adjoint }A);\qquad (77.9)$

by using the previous example, we have

$|A| = \begin{vmatrix}3 & 2 & 4\\2 & 0 & 2\\4 & 2 & 3\end{vmatrix} = (0 + 16 + 16) - (0 + 12 + 12) = 8.$
