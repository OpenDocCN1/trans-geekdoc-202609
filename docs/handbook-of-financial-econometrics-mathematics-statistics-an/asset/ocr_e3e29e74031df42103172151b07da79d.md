# An Integral Equation Approach for Bond Prices with Applications

Proposition 110.3. We have

G_D(x,T) = E_x[1_D Φ(X_{J_1}, T - J_1)]

= ∫_0^T dF_{J_1}(t) ∫ dF(y) ∫_{y^+} ^∞ dw Φ(w - y, T - t) H(x, w, t),

where H is defined in (110.15)

Proof. Note that 	ilde{D} = {J_1 ≤ T, min_{s≤J_1} X_s > 0} ∈ F_{J_1}. Therefore, by the Strong Markov Property, we have G_D(x, T) = E_x[E_x[1_D ψ(X_{τ(T)})1(τ(T) ≤ T)|F_{J_1}]] = E_x[1_D Φ(X_{J_1}, T - J_1)]. Recall that Y_1 = -log(1+U_1). Therefore, by the independence of J_1, Y_1 and {W_t; t ≥ 0}, we get

G_D(x, T) = E [ 1( J_1 ≤ T, min_{x≤J_1} x + X_s^c > 0, x + X_{J_1}^c - Y_1 > 0 ) × Φ(x + X_{J_1}^c - Y_1, T - J_1) ]

= ∫_0^T dF_{J_1}(t) ∫ dF(y) E [ 1( min_{x≤t} x + X_s^c > 0, x + X_t^c - y > 0 ) Φ(x + X_t^c - y, T - t) ].

We compute the integrand. Using the symmetry of Brownian motion, we get

E [ 1( min_{x≤t} x + X_s^c > 0, x + X_t^c - y > 0 ) × Φ(x + X_t^c - y, T - t) ]

= E [ 1( max_{x≤t} -x - cs + σ W_s < 0, -x - cs + σ W_t + y < 0 ) × Φ(x + ct - σ W_t - y, T - t) ]

= E [ 1( max_{x≤t} - \hat{x} - \hat{c} s + W_s < 0, - \hat{x} - \hat{c} s + W_t + y < 0 ) × Φ(x - σ(- \hat{c} t + W_t) - y, T - t) ].
