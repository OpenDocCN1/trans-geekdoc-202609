# 6.2.1 *ARIMA-GARCH model*

According to Box and Tiao (1975), the ARMA model of TAIEX could be setup as follows: $ln P_t = φ_1 ln P_{t−1} + ⋯ + φ_p ln P_{t−p} + ε_t + θ_1 ε_{t−1} + ⋯ + θ_q ε_{t−q}$, where $p$ is the order of autoregression, $q$ is the order of moving average, $φ_1, ⋯, φ_p$ are the parameters of autoregression, $θ_1, ⋯, θ_q$ are the parameters of moving average, $ε_t$ is the residuals at term $t$. This model can also be represented as ARMA(p, q). The model can also be represented by using lag symbols, the model can be represented as $(1 − φ_1L^1 − ⋯ − φ_pL^p) ln P_t = (1 + θ_1L^1 − ⋯ − θ_qL^q)ε_t$, where $L$ is the lag symbol. The model can finally be represented as $φ_p(L)ln P_t = θ_q(L)ε_t$.

According to Dickey and Fuller (1979), when the series is not stationary, we need to take the appropriate difference with the series, the series called ARIMA(p, d, q), the model can be represented as $φ_p(L)Δ^d ln P_t = θ_q(L)ε_t$, where d is the difference of numbers.

According to Hansen and Lunde (2005), the residuals test is inconsistent which means the residuals demonstrated the problem of heteroskedasticity. The model improvement is necessary. The GARCH model would work. The model is $σ^2_{ε,t} = a_0 + a_1σ^2_{ε,t−1} + ⋯ + a_pσ^2_{ε,t−p} + ε_t + b_1ε^2_{t−1} + ⋯ + b_qε^2_{t−q}$, that represents GARCH(p, q). According to Jeon and Taylor (2016), Mohammadi (2017), the model could applicate on forecasting issues.
