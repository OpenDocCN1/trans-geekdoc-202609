If the firm does not hire investment banks or no investment banks are retained, the sample is categorized as "No IB". The event study methodology with the market model is used to compute the abnormal returns. The model parameters are estimated from day −270 to day −60, where day 0 is the announcement date. Student t-statistic is used to test the significance level. Two-sample t-statistics is used to test the difference in announcement returns.

More importantly, an additional analysis shows that domestic advisors create slightly higher gains to targets relative to their foreign counterparts. Targets hired by domestic advisors earn 5.52% cumulative abnormal returns over a 3-day (−1,+1) event window higher than 4.74% for those with foreign advisors. While domestic advisors may better know the market and have superior information to evaluate the deals, this can lead to higher announcement returns to targets. However, the difference of announcement returns between domestic and foreign advisors is not statistically significant.

# 76.5.4.2 Bidder announcement returns

This section presents the empirical evidence for bidder announcement returns with respect to the use of financial advisors. The empirical analysis is the same as the analysis for target firms. As shown in Table 76.5, the results show that bidders on average obtain gains around the announcement date, but experience losses during the post-announcement period. For example, bidders obtain 3.16% cumulative abnormal returns for a 3-day (−1,+1) event window, but experience up to −13.15% cumulative abnormal returns over a 361-day (0,+360) post-announcement event window.

Taking into account the use of financial advisors, the evidence indicates that bidders hired by financial advisors on average earn lower announcement returns around the announcement date relative to those without using financial advisors. The evidence shows that bidders obtain 2.38% and 3.53% cumulative abnormal returns over a 3-day (−1,+1) event window for those with and without using financial advisors, respectively.
