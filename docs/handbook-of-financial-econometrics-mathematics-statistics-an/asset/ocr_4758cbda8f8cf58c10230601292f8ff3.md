the y-residuals contain information that is not captured by previous components, \(\Delta F_{r-1}p'_{r-1}\), we use the resulting residual to calculate \(\Delta F_{tr}\) and \(p'_r\).

Based on the previous equations, we can write what looks like a multiple regression model as follows:

\(fsi_{t+j}=\sum_{r=1}^{R}c_r\sum_{i=1}^{N}w^{*}_{tr}x_{ti}+\xi_{t+j}.\)

If the constants \(\phi_{tr}\)'s are chosen judiciously, then such partial least squares regression (PLSR) approaches can often outperform the two-stage factor model approach and least square regression (Geladi and Kowalski, 1986).

# **_B. The nonlinear iterative partial least squares (NIPALS) algorithm_**

Unlike the two-stage factor model approach, the PLS approach attempts to find directions that help explain both the response and the predictors. To obtain the latent components, one can implement a recursive algorithm for PLS, that is, the _NIPALS algorithm_ that does not calculate all the principal components at once. In computing the first PLS direction (\(\Delta F_1\)), PLS places the highest weight on the variables that are most strongly related to the response variable. To identify the second PLS direction we first adjust each of the variables for \(\Delta F_1\), by regressing each variable on \(\Delta F_1\) and obtaining residuals. One can interpret these residuals as the remaining information that is not explained by the first PLS component. Using these residuals in a recursive fashion in each iteration, we then find the next PLS direction.

The Nonlinear Iterative Partial Least Squares (NIPALS) algorithm is shown below. It starts with scaled and centered data.

+   1. The X-weights, \(w_{N\times1}\):
+   
+      \(w_{N\times1}=X'_{N\times T}u_{T\times1}/u'_{1\times T}u_{T\times1}\)
+   
+      (getting a starting vector of \(u\), usually \(u=y\)).

+   2. Calculate X-scores, \(\Delta F_{T\times1}\):
+   
+      \(\Delta F_{T\times1}=X_{T\times N}w_{N\times1}.\)

+   3. The y-weights, \(c\):
+   
+      \(c=y'_{1\times T}\Delta F_{T\times1}/\Delta F'_{1\times T}\Delta F_{T\times1}.\)

+   4. Update the set of Y-scores, \(u\):
+   
+      \(u_{T\times1}=cy_{T\times1}.\)
