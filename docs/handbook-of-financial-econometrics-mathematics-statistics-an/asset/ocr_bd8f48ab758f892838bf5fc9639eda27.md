To model the long memory in downside risk, we consider the autoregressive fractionally integrated moving average (ARFIMA) process.¹⁷ A process is usually labeled as an ARFIMA(p, d, q) process if its dth difference is stationary and invertible, where d is not an integer. To be specific, a demeaned downside risk can be expressed as:

φᵢ(L)(1 − L)ᵈVᵢ,ₜ = ψᵢ(L)εᵢ,ₜ,  (58.10)

where φᵢ(L) = 1 − Σₖ₌₁ᴾ φₖLᵏ and ψᵢ(L) = 1 + Σₖ₌₁ᵠ ψₖLᵏ are polynomials of orders p and q in the lag operator L with roots strictly outside the unit circle. Instead of modeling the data as either I(0), or as integrated, I(1), (1 − L)ᵈ allows us to more accurately and flexibly deal with the data by using a fractional filter that estimates the value of d to govern the long memory process.

The memory parameter d can be estimated by the parametric, the semi-parametric, and the non-parametric approaches. The conventional approach uses the log-periodogram estimator developed by Geweke and Porter-Hudak (1983, hereafter GPH) because of the required weaker assumptions on the short memory process εᵢ,ₜ in equation (58.10).¹⁸ GPH demonstrate that for frequencies near zero, d can be consistently estimated from the least-squares regression and is popularized as a log-periodogram model.
