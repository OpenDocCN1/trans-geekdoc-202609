In the traditional multi-objective optimization approach, the objectives are averaged with a weight vector, and the solution depends on the weight vector chosen by the decision maker, which may not be acceptable to another decision maker in a changed environment. Under such circumstance, it may be useful to have knowledge about alternative Pareto-optimal solutions. Population-based techniques including the multi-objective genetic algorithm (GA) (e.g., see Deb et al., 2002), and the Particle Swarm Optimization (PSO) (e.g., see Coello et al., 2004; Mostaghimi and Teich, 2003; Reyes-Sierra and Coello, 2006) has been shown to solve multi-objective optimization problem successfully by capturing a set of Pareto-optimal solutions. Instead of optimizing, this study considers a satisficing compromised solution by the decision maker using goal programming technique. The difference between the philosophies of optimizing versus satisficing is well documented (Byron, 2004). In the following section, a goal programming technique is proposed to find a satisficing compromised solution between the two objectives g1 and g2.

# 57.3 Hybrid of Principle Component and Fisher’s Discriminant Analysis Using Goal Programming

The goal programming (GP) technique, a multi-objective optimization approach, introduced by Charnes et al., (1955), was later developed in the seminal works by Lee (1972), Ignizio (1976), Ignizio et al. (1994, 2003), and Romero (1991). The large number of goal programming applications in many diverse fields are accounted by Jones and Tamiz (2002). Depending on the nature of the problem, several classes of goal programming can be obtained, including weighted goal programming, lexicographic goal programming, and MINIMAX goal programming (e.g., see Ignizio and Romero, 2003; Tamiz and Jones, 1996; Tamiz et al., 1998). In case a balance between the levels of satisfaction of goals is desired, the MINIMAX goal programming technique by Flavell (1976) is adopted. In this study, as a balance between sufficient discriminant power as well as explanatory power is desired, the MINIMAX goal programming technique is considered. In the standard GP formulation, each of the objectives is given an aspiration level. Unwanted deviations from these aspiration levels are minimized in an achievement function.
