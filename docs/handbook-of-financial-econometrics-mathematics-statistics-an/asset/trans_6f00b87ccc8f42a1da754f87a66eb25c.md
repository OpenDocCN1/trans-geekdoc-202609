
看涨期权和看跌期权的价格之间存在关系。这种关系被称为看涨-看跌平价。方程84.5显示了看涨期权和看跌期权价格之间的关系。

$$P = C + X/R - S,$$
(84.5)

其中 C 是看涨期权价格，X 是行权价，R 是 1 + 利率，S 是股票价格。

以下使用看涨-看跌平价来计算 GE 看跌期权价格：

$$P = \$0.777 + \$20/(1.03) - \$20$$
$$= 0.777 + 19.417 - 20$$
$$= 0.194.$$
