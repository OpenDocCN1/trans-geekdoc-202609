# 82.2 Sharpe Performance-Measure Approach with Short Sales Allowed

In deriving the capital asset pricing model (CAPM), Lintner (1965) suggests a performance-measure approach for determining the efficient frontier. Lintner arrived at this approach through a sequence of logical steps.

Following Markowitz (1952, 1959), the objective function for portfolio selection can be expressed:

Max L = Σ_{i=1}^n W_i \bar{R}_i + λ₁ { [ Σ_{j=1}^n Σ_{i=1}^n Cov(R_i,R_j) ]^{1/2} - σ_p } + λ₂ ( Σ_{i=1}^n W_i - 1 )  (82.1)

where \bar{R}_i is the average rates of return for security i, W_i (or W_j) is the optimal weight for ith (or jth) security, Cov(R_i,R_j) is the covariance between R_i and R_j, σ_p is the standard deviation of a portfolio, and λ₁, λ₂ are the Lagrangian multipliers.

Markowitz portfolio-selection model minimizes the variance given the targeted expected rate of return. Equation (82.1) maximizes the expected rates of return given targeted standard deviation.

If a constant risk-free borrowing and lending rate R_f is subtracted from equation (82.1),

Max L' = Σ_{i=1}^n (W_i \bar{R}_i - R_f) + λ₁ { [ Σ_{i=1}^n Σ_{j=1}^n W_i W_j Cov(R_i,R_j) ]^{1/2} - σ_p } + λ₂ ( Σ_{i=1}^n W_i - 1 )  (82.2a)
