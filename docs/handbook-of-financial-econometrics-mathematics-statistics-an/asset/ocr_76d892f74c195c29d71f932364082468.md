# Figure 35.1.: Path diagram of the SEM approach.

Notes: This figure presents the path diagram of the structural equation modeling system. The SEM formulas are specified as follows: β = [0 β1; 0 0], Φ = [Φ1 0; 0 Φ2], Λy = [Λy1 Λy2; 0 Λy3], Λ = [Λ1 0; 0 Λ2; Λ3 Λ4] where Λy1, Λy2, Λy3, Λ1, Λ2, Λ3, and Λ4 denote unknown factor loadings, β1, Φ1, and Φ2 denote unknown regression weights, v1, v2, δ1, δ2, and δ3 denote measurement errors, and ζ1 and ζ2 denote error terms.

x is the matrix of observed independent variables as the indicators of attributes; y is the matrix of observed dependent variables as the indicators of capital structure. ξ is the matrix of latent variables as attributes; η is the latent variables that link determinants of capital structure (a linear function of attributes) to capital structure (y).

Figure 35.1 shows an example of the path diagram of the SEM approach where the observed independent variables x = (x1, x2, x3)' are located in rectangles; the observed dependent variables y = (y1, y2)' are set in hexagons; variables η = (η1, η2)', ξ = (ξ1, ξ2)' in ovals denote the latent variables; the corresponding sets of disturbance are ζ = (ζ1, ζ2)', v = (v1, v2)'; and δ = (δ1, δ2, δ3)'.

The structural model can be specified as the system of equations that combines equations (35.1) and (35.2). We can then obtain the structural model in Titman and Wessels (1988) as follows: y = Γξ + ε. (35.4)

In this paper, the accounting items can be viewed as the observable independent variables (x), which are the causes of attributes as the latent variables (ξ), and the debt–equity ratios representing the indicators of the capital structure are the observable dependent variables (y).
