that $\Phi(x,T) \le (1 - e^{\lambda T}) + G_A(x,T)$. Therefore, we obtain

$$\limsup_{T\to0+} s(V,T) = \limsup_{T\to0+} \frac{1}{V} \log\left(\frac{1}{1-\Phi(x,T)}\right)$$ $$\le \lim_{T\to0+} \frac{1}{T} \log\left(\frac{1}{e^{-\lambda T} - G_A(x,T)}\right).$$

Note that $G_A(x,T) \le \Phi(x,T) \to 0$ as $T \to 0+$ and, thence, $\lim_{T\to0+}(e^{-\lambda T} - G_A(x,T)) = 1$. By L'Hospital's rule, we have

$$\lim_{T\to0+} \frac{1}{T} \log\left(\frac{1}{e^{-\lambda T} - G_A(x,T)}\right) = \lim_{T\to0+} \frac{-(-\lambda e^{-\lambda T} - \frac{\partial G_A}{\partial T}(x,T))}{e^{-\lambda T} - G_A(x,T)}$$ $$= \lim_{T\to0+} \left(\lambda + \frac{\partial G_A}{\partial T}(x,T)\right).$$

To compute $\lim_{T\to0+} \frac{\partial G_A}{\partial T}(x,T)$, we note that $G_A(x,T) = \psi(0)e^{-\lambda T} P[\min_{s\le T} s + c s + \sigma W_s \le 0]$.

By Lemma 110.7, we get $\lim_{T\to0+} \frac{\partial G_A}{\partial T}(x,T) = 0$. We have obtained the upper bound in (110.21). This completes the proof. $\square$
