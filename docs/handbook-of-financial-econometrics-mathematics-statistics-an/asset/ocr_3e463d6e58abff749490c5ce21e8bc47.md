in which the defaultable asset vector $\vec{X} = (X_1, X_2, \dots, X_n)' \in \mathcal{R}^{n \times 1}$ is assumed centered normally distributed $\vec{X} \sim \mathcal{N}(\vec{0}, \Sigma)$, $\Sigma$ with dimension $n$ and its default threshold vector is denoted by $\vec{D} = (D_1, D_2, \dots, D_n)' \in \mathcal{R}^{n \times 1}$. For simplicity, in the Matlab experiment below we further assume that $\vec{D} = d \times \underbrace{(1, \dots, 1)'}_{n \times 1}$. More general distributions and relevant (efficient) importance sampling can be found in the author's work.

Matlab codes for this case study can be found below for CPU and GPU computing.

```
%Parameters and variables
d = -1; rho = 0.25;
n = 5;
Nrepl = 750000;  %total number of simulation
```

| Matlab CPU Computing | Matlab GPU Computing |
|---|---|
| Sigma = rho*ones(n,n) + (1-rho)*eye(n); T = chol(Sigma); X_MC = randn(Nrepl,size(T,1)) * T; MC = prod(1*(X_MC < d*ones(Nrepl,n)),2); P_MC = mean(MC); SE_MC = std(MC) / sqrt(Nrepl); | Sigma = rho*gpuArray.ones(n,n) + (1-rho)*gpuArray.eye(n); T = chol(Sigma); X_MC = gpuArray.randn(Nrepl,size(T,1)) * T; MC = prod(1*(X_MC < d*gpuArray.ones(Nrepl,n)),2); P_MC_g = mean(MC); SE_MC_g = std(MC) / sqrt(Nrepl); P_MC = gather(P_MC_g); SE_MC = gather(SE_MC_g); |
