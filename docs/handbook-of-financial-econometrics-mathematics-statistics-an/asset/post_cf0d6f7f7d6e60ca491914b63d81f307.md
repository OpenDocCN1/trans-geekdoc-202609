## Appendix 63A: Partial Least Squares Regression

### A. Partial least squares regression

PLS attempts to extract factors from the **X** matrix that are associated with predicting *y* (i.e., \(fsi_{t+j}\)). Let \(\Delta F_{t1}, \Delta F_{t2}, \dots, \Delta F_{tR}\) represent \(R < N\) linear combinations of our original predictor variables. That is,

\[
\Delta F_{tr} = \sum_{i=1}^{N} w^{*}_{ir} X_{ti}
\]

where \(t = 1,2,\dots,T\) and \(\Delta F_{tr}\) (\(r = 1,\dots,R\)) are called **X**-scores¹ and components. They are estimated as linear combinations of the original predictors \(X_{ti}\) with the weights, \(w^{*}_{tr}\). The **X**-scores have the following two properties:

- (1) The matrix **X** can be decomposed as \(\mathbf X = \Delta\mathbf F \mathbf P' + \mathbf E\), where \(\Delta\mathbf F\) is a matrix whose columns are the **X**-scores, and **P** is a matrix whose columns are called the **X**-loadings. In other words, **X**-scores are multiplied by the loadings \(p_{ri}\), which can provide good summaries of **X**, so that the residuals of **X**, \(e_{ti}\), are small enough:

\[
X_{ti} = \sum_{r=1}^{R} \Delta F_{tr} p_{ri} + e_{ti}.
\]

- (2) \(fsi_{t+j}\) is modeled using linear regression on the **X**-scores², so that the **X**-scores are predictors of \(fsi_{t+j}\):

\[
fsi_{t+j} = \sum_{r=1}^{R} c_r \Delta F_{tr} + \xi_{t+j}
\]

where \(j = 1,2,\dots,k\), \(c_r\)'s are y-weights, and the y-residuals, \(\xi_{t+j}\), represent the deviations between the observed and modeled response. It is important to note that Nonlinear Iterative Partial Least Squares (NIPALS) does not estimate all the principal components at once. Since we believe the y-residuals contain information that is not captured by previous components, \(\Delta F_{r-1}p'_{r-1}\), we use the resulting residual to calculate \(\Delta F_{tr}\) and \(p'_r\).

Based on the previous equations, we can write what looks like a multiple regression model as follows:

\[
fsi_{t+j}=\sum_{r=1}^{R}c_r\sum_{i=1}^{N}w^{*}_{tr}x_{ti}+\xi_{t+j}.
\]

If the constants \(\phi_{tr}\)'s are chosen judiciously, then such partial least squares regression (PLSR) approaches can often outperform the two-stage factor model approach and least squares regression (Geladi and Kowalski, 1986).

### B. The nonlinear iterative partial least squares (NIPALS) algorithm

Unlike the two-stage factor model approach, the PLS approach attempts to find directions that help explain both the response and the predictors. To obtain the latent components, one can implement a recursive algorithm for PLS, that is, the *NIPALS algorithm* that does not calculate all the principal components at once. In computing the first PLS direction (\(\Delta F_1\)), PLS places the highest weight on the variables that are most strongly related to the response variable. To identify the second PLS direction we first adjust each of the variables for \(\Delta F_1\), by regressing each variable on \(\Delta F_1\) and obtaining residuals. One can interpret these residuals as the remaining information that is not explained by the first PLS component. Using these residuals in a recursive fashion in each iteration, we then find the next PLS direction.

The Nonlinear Iterative Partial Least Squares (NIPALS) algorithm is shown below. It starts with scaled and centered data.

1. The X-weights, \(w_{N\times1}\):

\[
w_{N\times1}=X'_{N\times T}u_{T\times1}/u'_{1\times T}u_{T\times1}
\]

(getting a starting vector of \(u\), usually \(u=y\)).

2. Calculate X-scores, \(\Delta F_{T\times1}\):

\[
\Delta F_{T\times1}=X_{T\times N}w_{N\times1}.
\]

3. The y-weights, \(c\):

\[
c=y'_{1\times T}\Delta F_{T\times1}/\Delta F'_{1\times T}\Delta F_{T\times1}.
\]

4. Update the set of Y-scores, \(u\):

\[
u_{T\times1}=cy_{T\times1}.
\]

5. Convergence is tested on the change in \(u\), i.e., \(\|u_{\text{old}} - u_{\text{new}}\| < 10^{-8}\). If the convergence has not been reached, return to step 2; otherwise continue with step 6.

6. Remove the present component from **X** and \(y\), then use these deflated matrices as **X** and \(y\) in the next component.³

   (a) \[
   X'_{T\times N} = X_{T\times N} - \Delta F_{T\times1}p'_{1\times N},
   \]
   where \(p_{N\times1} = X'_{N\times T}\Delta F_{T\times1} / (\Delta F'_{1\times T}\Delta F_{T\times1})\).

   (b) \[
   y_{T\times1} = y_{T\times1} - c\Delta F_{T\times1}.
   \]

7. Continue with the next component (i.e., back to step 1 with the deflated \(y\) and **X**) until one determines there is no more significant information in **X** about \(y\).

> ¹ The **X**-scores are orthogonal predictors of \(y\) and also model **X**.
>
> ² In many cases, the goal is to model **X** and \(y\) with a small number of factors, so that the matrix **X** is never fully decomposed.
>
> ³ It is important to note that after each component, \(r\), the design matrix \(X_{T\times N}\) is deflated by subtracting \(\Delta F_{T\times1}p'_{1\times N}\) from \(X_{T\times N}\). Hence, the weights \(w_{N\times1}\) refer to the residuals after the previous dimension, \(e_{ti,a-1}\), rather than to the X-variables themselves. Therefore, the equation \(\Delta F_{tr} = \sum_{i=1}^{N} w_{ir}^* X_{ti}\) becomes \(\Delta F_{tr} = \sum_{i=1}^{N} w_{ir} e_{ti,a-1}\), where \(e_{ti,a-1} = e_{ti,a-2} - \Delta F_{t,a-1}p_{a-1,i}\). When \(a = 1\), \(e_{ti,0} = X_{ti}\). However, the weights \(w\) can be transformed to \(w^*\), which are directly related to \(X\), given the equation \(\Delta F_{tr} = \sum_{i=1}^{N} w_{ir}^* X_{ti}\). Manne (1987) shows that the relationship between the above two is expressed by \(W^*_{N\times R} = W_{N\times R} (P'_{R\times N} W_{N\times R})^{-1}\).
