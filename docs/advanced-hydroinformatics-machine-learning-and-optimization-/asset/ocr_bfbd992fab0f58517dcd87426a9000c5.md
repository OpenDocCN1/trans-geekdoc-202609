# *MLP*

Figure 15.7a shows the general scheme of an MLP. The information that enters the network is propagated forward using connections with different values or weights. The MLP has an input layer, where the data are entered, which is processed in the neurons of the hidden layers using activation functions until reaching the output layer, where the results are generated. The output value $y_t$ of a single hidden layer MLP with $M$ inputs values is defined as:

$y_t = c + \sum_{i=1}^{N} v_i f_i(I_t \cdot w_i + b_i), \quad (15.3)$

where $N$ is the number of neurons with an activation function $f_i(\bullet)$ (e.g., sigmoidal function); $I_t$ is the $M$-dimensional inputs vector of the network; $w_i$ is the $M$-dimensional vector that represents the connections between the input and the hidden layer; $v_i$ is the $N$-dimensional vector for the connections between the hidden layer and the output layer; $b_i$ is the $N$-dimensional vector of bias for the neurons of the hidden layer; and $c$ is the bias value of the output layer. The number of parameters in this network is $p = N(M + 2) + 1$.
