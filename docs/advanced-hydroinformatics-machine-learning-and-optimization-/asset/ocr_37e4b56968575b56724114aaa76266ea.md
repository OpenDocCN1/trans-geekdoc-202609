# 10.3.4. Step 4 (Data Extraction and Preprocessing)

As a result of Step 3, for every newspaper article related to each water body, the URL was obtained through the Web-crawling process. The consequent step was to perform Web scraping, based on the parameters of each newspaper website obtained in Step 1. In this process, the information was filtered, downloaded, and processed from an HTML format to a comma-separated values (CSV) file as unstructured data. Python scripts with Googleapiclient, BeautifulSoup, and Panda libraries were used to download, extract, and transform the digital news. These scripts are available in a GitHub repository at https://github.com/sduarte09/buscandoelmagdalena.

Next, the unstructured data were transformed into a structured data format, so the text of each article, the title, the date, and the ID of the news websites were extracted. This information was then used to filter the news articles in order to remove duplicates, empty website pages, music/video links, or image galleries, as illustrated in Figure 10.5.
