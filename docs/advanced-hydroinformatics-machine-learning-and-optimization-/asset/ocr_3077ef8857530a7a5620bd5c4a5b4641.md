# A TWO-STAGE SURROGATE-BASED PARAMETER CALIBRATION FRAMEWORK FOR A COMPLEX DISTRIBUTED HYDROLOGICAL MODEL

Haiting Gu, Yue-Ping Xu, Li Liu, Di Ma, Suli Pan, and Jingkai Xie

Institute of Hydrology and Water Resources, Zhejiang University, Hangzhou, China

Distributed hydrologic models have been widely used for their functional diversity and rationality in theory. However, calibration of distributed models is computationally expensive since it requires a large number of model runs, even if an efficient multi-objective optimization algorithm is employed. To alleviate the burden of computation, we develop a two-stage surrogate-based model calibration framework by coupling standard backpropagation neural network with AdaBoost (ADBP) to efficiently calibrate the parameters of a large and complex distributed hydrologic model, that is, the Variable Infiltration Capacity (VIC) model. The first-stage model (SM-I) picks out the parameter sets whose simulated outputs are in the crucial range and the second-stage model (SM-II) estimates the values of outputs accurately with the parameter sets picked out by SM-I. The proposed surrogate model is tested in the Lanjiang River basin and the Xiangjiang River basin for parameter calibration. With the similar calibrated parameter sets for VIC, the surrogate model gains up to 20 times speedup
