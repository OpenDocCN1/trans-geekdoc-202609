## 9.5.3 De-Noised Wavelet ANN Model

The same model shown just before is improved even further by de-noising the input time series. Soft-threshold was applied and the threshold value was found via optimization. GODLIKE (a generalization of various population-based global optimization schemes) was used for this purpose (http://nl.mathworks.com/matlabcentral/fileexchange/24838-godlike-a-robust-single-multi-objective-optimizer). The objective function was set as RMSE in the cross-validation process; however, any other statistical or error measure can be set as an objective function as well. The training set minimally improved by 0.03% (77.01 m³/s to 76.98 m³/s) compared with the WANN model and by 16.1% (91.81 m³/s to 81.1604 m³/s) compared with the ANN stand-alone model. For the validation set, improvements of 6.2% and 4.3% were accomplished relative to the WANN and ANN models, respectively. As in the case of the test set, performance increased by 9.6% compared with the WANN model and increased by about 27% compared with the ANN stand-alone model. Results are considered highly accurate for the case study; however, if more effort is invested in fine-tuning the parameters, even greater accuracies can be accomplished. In this exercise, the number of hidden nodes and decomposition levels was set as fixed, based on the best result of the WANN model, and the only variable to optimize was the threshold value. Besides, the optimizer was run with a small population and a modest number of iterations; therefore, if bigger computational resources are at disposal, it is thought that excellent results could be accomplished.

In Figure 9.13, visual inspection of time series shows consistent best estimates of flow in this order: 1st de-noised wavelet ANN (light), 2nd wavelet ANN (grey), and 3rd ANN stand-alone (dark). In the residual error graph, it is clear that the WANN model can capture peak flows more accurately than the ANN model; however, the de-noised WANN is even better. Even for the other flow regimes (medium and low flows), the WANN model outperforms the ANN model, where the grey spikes in the residual are almost always smaller than the dark ones in absolute magnitude. In the case of the WANN and de-noised WANN, these other regimes present similar behavior.

## 9.5.4 Other Data-Driven Models: Least Median Square, Model Tree (M5P), Pace Regression, and Linear Regressions

Four different DDMs were tested, these being (1) least median square, (2) model tree (M5P), (3) pace regression, and (4) linear regressions. Results can be visualized in Figures 9.14 and 9.15. The charts are divided into the training, validation, and testing sets for all decomposition levels. It can be seen that for different DDMs, data preprocessing with wavelet analysis is always improving the model skills, however, only for certain decomposition levels. This is an indicator that wavelet subseries can play an important role in the modeling process, reflected by the improved results that must be cautiously found in the decomposition space at the expense of greater computational resources. Among models, the coupled wavelet-M5P (DDM 2) seems to consistently provide the best results and is quite comparable with the performance of the coupled WANN model done in the previous section. In second place are the methods (3) and (4) with wavelet as preprocessor, presenting similar performances in all data sets. Finally, method (1) had the lowest performance within the studied models, clearly showing that the problem to solve cannot be assumed with linear behavior and is negligibly improved by the wavelet subseries.

Figure 9.16 depicts the simulated discharges during the testing phase for all the proposed DDMs. As mentioned before, the wavelet model tree (WM5P) outperformed others in all regimes (low, medium, and high flow). Nevertheless, the method manages to overcome (or close) to the 100 m³/s RMSE barrier (considered as good) but is still not better than the WANN model (Table 9.4).

## 9.6 Conclusions

Wavelets and ANN coupled together proved to be of great value and easy to apply, the best of all the models tested. So far, many researchers have come to the same conclusion; however, the contribution of this work is the insertion of de-noising techniques using optimization tools. The results ended up being superior to the best WANN model. This was to be expected, since filtering the noise in the time series should reduce the spread of these errors to the result.
