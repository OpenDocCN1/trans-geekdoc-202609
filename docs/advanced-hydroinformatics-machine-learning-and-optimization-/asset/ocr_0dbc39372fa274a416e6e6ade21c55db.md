To address these issues, we incorporated an unsupervised clustering technique, the K-means method, into an existing spatial random sampling toolbox for grid-based data analysis (SRS-GDA toolbox; Wang & Xuan, 2020). The SRS-GDA toolbox can help to reduce drastically the overhead of sampling data for training; and the new addition of the machine learning component makes it possible to classify and extract spatial temporal features from large environment observations data sets. The enhanced toolbox is tested using the daily rainfall images extracted from the GEAR data set (Tanguy et al., 2016), which is a grid-based data set (1 km × 1 km) of daily rainfall covering Great Britain (700 × 1,250 grids) over the period of 1898–2010. The daily rainfall is the total rainfall amount over a 24 hr period from 9 a.m. of the reporting day until 9 a.m. on the following day. The chosen data set shares many features of other large environmental modeling results and observations, for example, climate reanalysis and projections, such as those from ERA40 (Uppala et al., 2005), CMIP5 (Taylor et al., 2012). Therefore, the example given in this chapter can be readily expanded to cover many other similar cases.

There are three main indices used for quantifying the patterns of the variable (daily rainfall in this study), (1) geographic location, (2) pattern size, and (3) orientation. The rainfall patterns over the last century in Great Britain (GB) was first extracted using the toolbox automatically before several significant patterns in England, Wales, and Scotland were recognized, respectively. The efficacy of the toolbox in deep learning is demonstrated by the training of a CNN model to automatically recognize the rainfall patterns from a test set of 1,166 daily rainfall in GB.

Finally, the conclusions and recommendations of further study are given in section 12.4.
