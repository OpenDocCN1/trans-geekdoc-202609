# 9.5.3. De-Noised Wavelet ANN Model

The same model showed just before is improved even further by de-noising the input time series. Soft-threshold was applied and the threshold value was found via optimization. Godlike (a generalization of various population-based global optimization scheme) was used for this purpose (http://nl.mathworks.com/matlabcentral/fileexchange/24838-godlike-a-robust-single-multi-objective-optimizer). The objective function was set as RMSE in the cross-validation process; however, any other statistical or error measure can be set as an objective function as well. The training set minimally improved in 0.03% (77.01 m³/s to 76.98 m³/s) compared with the WANN model and 16.1% (91.81 m³/s to 81.1604 m³/s) with the ANN stand-alone model. For the validation set an improvement of 6.2% and 4.3% were accomplished respectively to the WANN and ANN models. As in the case of the test set, performance increased by 9.6% compared with the WANN model and increased by about 27% to the ANN stand-alone model. Results are considered highly accurate for the case study, however, if more effort is invested in keeping tuning the parameters even major accuracies can be accomplished. In this exercise, the number of hidden nodes and decomposition levels was set as fixed, based on the best result of the WANN model and the only variable to optimize was the threshold value. Besides, the optimizer was run with a small population and a modest number of iterations, therefore if bigger computational resources are at disposal is thought that excellent results could be accomplished.
