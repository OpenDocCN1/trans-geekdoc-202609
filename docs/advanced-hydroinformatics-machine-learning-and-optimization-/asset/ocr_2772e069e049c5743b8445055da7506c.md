A commonly used activation function in MLP is the sigmoid function, which is presented as

f_i = 1 / [1 + exp[-(I_t · w_i + b_i)]]. (15.4)

For this MLP function, the output layer does not have an activation function because the data are standardized using the standard scoring method (see section 15.2.2).

# RBN

These networks use Gaussian functions for data processing, incorporating the center and radius parameters of processing units known as bases (instead of neurons, as in MLPs). Figure 15.7b shows the general schematic of an RBN. The function that the RBN represents is as follows:

y_t = sum_{i=1}^{N} w_i g_i(I_t), (15.5)

g_i(I_t) = exp[ - sum_{j=1}^{M} [(I_t)_j - c_{j,i}]^2 / r_{j,i}^2 ], (15.6)

where y_t is the output value; N is the number of bases with Gaussian functions g_i; M is the number of input variables; w_i is the N-dimensional weight vector between the hidden layer and the output layer; I_t is the M-dimensional inputs vector of the network; and c_{j,i} and r_{j,i} are the center and radial M-dimensional vectors of the i th base. The number of parameters for an RBN is p = N(2M + 1).

# LF

These are the mathematical functions used to find relationships between variables with linear trends. Unlike the previous functions, they do not have the ability to accurately replicate complex patterns. If y_t is a dependent variable and I_t is the independent variables (input values), the function can be expressed as follows:

y_t = b + β1 I_{t,1} + β2 I_{t,2} + ... + β_M I_{t,M}, (15.7)

where y_t is the output value; I_{t,1}, I_{t,2}, ... I_{t,M} are the input values; M is the number of input values; β1, β2, ... β_M are the weight coefficients of the Input values; and b is the bias of the function. The number of parameters is p = M + 1.
