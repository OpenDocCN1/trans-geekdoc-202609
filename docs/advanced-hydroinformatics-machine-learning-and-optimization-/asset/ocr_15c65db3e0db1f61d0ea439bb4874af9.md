Parada et al., 2003; Voisin et al., 2011; Xie et al., 2007), seven parameters in VIC are selected for calibration and their feasible ranges are shown in Table 3.2. Generally, the parameters selected to be calibrated are the thickness of the second and third soil moisture layer (d2, d3), the fraction of maximum soil moisture where nonlinear baseflow occurs (Ws), the maximum velocity of baseflow (Ds_max), fraction of Ds_max where nonlinear baseflow begins (Ds), and the variable infiltration curve parameter (b_inf).

Both the surrogate model and VIC parameters are optimized via ε-NSGA II in parallel. The initial sample size of ε-NSGA II is set as 24. The maximum generations per run and maximum number of populations were specified as 250 and 100,000, respectively. To reduce the runtime of VIC parameters optimization, the program would be terminated when the solutions were not improved in 30 generations.

BPNN is employed as a weak learner in AdaBoost. Since there is no need to train a weak predictor with high accuracy, a three-layer BPNN model was chosen according to the empirical formula proposed by Li and Liu (2009) as shown in equation (3.9),

$m = \sqrt{n + l} + a,$
(3.9)

where m is the number of nodes in hidden layer, n is the number of neural cells in network input layer, l is the number of neural cells in output layer, a is a number between 0 and 10. The structure was determined as 7-10-1. The numbers indicated that there are 7 nodes in the input layer, 10 nodes in the hidden layer, and one output in this BPNN model.
