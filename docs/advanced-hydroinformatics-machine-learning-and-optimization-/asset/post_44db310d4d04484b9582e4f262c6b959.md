
The connection between neurons that flows in one direction is called feed-forward networks. This flow direction goes from the input layer, through hidden layers that contain the neurons, to the output layers (see Fig. 8.1). There are two feed-forward network types that have been used by many authors in rainfall-runoff modeling: The Multilayer Perceptron (MLP) and the Radial-Basis Function (RBF). The MLP is defined by Solomatine and Wagener (2011) as a device that consists of several layers of mutually interconnected neurons, which transform the inputs using a multiparameter nonlinear transformation so the resulting model is capable of approximating complex input-output relationships. The objective of the training process is to optimize the number of neurons and hidden layers to which the network is applied using a trial and error procedure (Shamseldin, 1997). If there are too few neurons in the hidden layer, the Artificial Neural Network may not be capable of reproducing the output function. On the contrary, if there are too many neurons, the ANN may overfit the output function, losing the ability to generalize (Dawson & Wilby, 2001). The Radial-Basis Function is a feed-forward ANN, similar in topology to the MLP (Fernando & Jayawardena, 1998), which tries to approximate a function y = f(x) by a superposition of other functions F(x,σ), where σ is a parameter that characterizes the width of the function in the input space (Solomatine & Wagener, 2011). Typically, Gaussian functions are used as RBF functions. More details on RBF networks can be seen in Dayhoff (1990), Fernando and Jayawardena (1998), Dawson and Wilby (2001), Sudheer and Jain (2003), and Solomatine and Wagener (2011).

### 8.2.2. Data Partitioning

Data analysis and preparation is an important procedure in developing hydrological models. In particular, a DDM Rainfall-Runoff model requires that the complete data set should be separated into three different data sets: training (i.e., calibration), cross-validation, and verification. This particular data partitioning in DDM models is quite different from the standard procedure for calibration in conceptual and physically based models since the data are split into two data sets: calibration and verification. The cross-validation data set serves as a small test set, which avoids overfitting of the function and stops the training process. The verification data set serves as testing set, which allows seeing how the model would perform if new data were fed into it. Nevertheless, Lachtermacher and Fuller (1994) identified the following problems in three data sets partitioning.

- 1. Difficulties in creating three independent data sets in cases where limited data are encountered. In hydrology, it is difficult to split the data in independent and statistically similar data sets, so the modeler should try to ensure similarity in the distribution.
- 2. The model results can be affected by the method of partitioning.
- 3. When using a cross-validation data set, it is not always clear when the model is learning the noise of the data.

### 8.2.3. Choice of Model Input Variable

The data cleansing and the selection of proper input variables are another important step in DDM, which take more time and effort than the modeling part. It is common that real-life data have a lot of errors, noise, or missing data. Additionally, outliers may also pose a problem since they could be an indicator of extreme event or erroneous measurement. For this reason, the modeler should be able to identify these atypical values (i.e., outliers) before building any kind of hydrological model.

Another important step is the choice of the model variable that has to consider the physics of the underlying process. In DDM, the physics is introduced by the choice of the relevant input variable that contributes to predicting the output value. Bowden et al. (2005) stated that many DDM modelers often present a large number of inputs and rely on the network to identify the inputs. This deficiency in the modeling process can increase the complexity, reduce the learning process, and model performance.

In literature, five approaches for input determination in DDM modeling have been addressed by Bowden et al. (2005): (1) Methods that rely upon the use of a priori knowledge, (2) methods based on linear cross-correlation, (3) methods that utilize a heuristic approach, (4) methods that extract the knowledge contained within trained ANN, and (5) a combination of the above four approaches.

In this study, the most appropriate inputs for predicting future discharge were estimated using the linear correlation and the average mutual information (AMI) as it was done by Solomatine and Dulal (2003) and Corzo et al. (2009).

The Average Mutual Information (Shannon, 1948) is used to investigate linear and nonlinear relationships and lag effects between the time series variables. It is the measure of information available from one set of data having knowledge of another data set. In other words, it represents the measure of information that can be learned from one data set (X) having the knowledge of another data set (Y).

```
AMI = Σ_{i,j} P_{XY}(x_i,y_j) log₂ [ P_{XY}(x_i,y_j) / (P_X(x_i) P_Y(y_j)) ] . (8.3)
```

Equation (8.3) presents the Average Mutual Information formula where P_X(x) and P_Y(y) are the marginal probability density functions of X and Y, respectively; and P_XY(x,y) is the joint probability density function of X and Y. A high value of AMI would indicate a strong dependency between two variables. Conversely, if X is completely independent of Y, then AMI is equal to zero.

Another way to identify the relevant input variables is the analysis of linear correlation between the predicted discharge and the input variable. The correlation analysis is a measure of only linear dependency where a value +1 indicates a total positive linear correlation, 0 indicates that a linear relationship does not exist between two variables, and −1 indicates total negative linear relationship. Overall, the input variables with high correlation and Average Mutual Information (AMI) to the output should be selected in the experimental setup of Data-Driven Models. These metrics are good indicators for detecting the input variable in a DDM. (Solomatine, 2016).

## 8.3. Characterization of The Grande De San Miguel Catchment

The Grande de San Miguel river is one of the most important rivers in El Salvador. It is located in the eastern part of El Salvador (see Fig. 8.2) between the Pacific Ocean and the mountain range Tecapa and Chinameca. In the catchment headwater, many fast-moving streams are encountered. These streams join and form the Grande de San Miguel river, which pours its water into Bahia de Jiquilisco, a mangrove estuary in the Pacific Ocean (Häggström & Lindström, 1990). The catchment has a total drainage area of 2,397 km², which includes two lakes: the Olomega lake (24.2 km²), which has a damping influence on the flow in the river, and the Jocotal lake with an area of 2.8 km². The length of the river from its source to the Pacific Ocean is about 120 km and the major tributaries are the San Francisco, Yamabal, and Yaguabar rivers.

In recent years, flood impacts produced by the Grande de San Miguel river have increased due to various factors: increased urbanization and land use change, low infiltration capacity, erosion, poor or nonexistent water management, and changes in temporal and spatial distribution of rainfall (Servicio Hidrologico Nacional, 2004).
