# The Root Mean Square Error (RMSE)

The Root Mean Square Error (RMSE) is a widely used goodness-of-fit function for verifying hydrological model performance ensures Maximum Likelihood Estimation (MLE). This error function punishes large deviation, which is usually found in high flows but the bias and shape might be not contemplated (Corzo Perez, 2009).

$$\text{RMSE} = \sqrt{\frac{\sum (Q_{sim} - Q_{obs})^2}{n}} \tag{8.7}$$

# The Normalized Root Mean Square Error (NRMSE)

The normalized Root Mean Square Error (NRMSE) compares the classical RMSE with the standard deviation of the measurement ($\sigma_{obs}$). This error function can be used to compare different time series (Corzo Perez, 2009).

$$\text{NRMSE} = \frac{\text{RMSE}}{\sigma_{obs}} \tag{8.8}$$

# The Kling-Gupta Efficiency (KGE)

The Kling-Gupta efficiency (KGE) was proposed by Gupta et al. (2009). It is based on the decomposition of the Nash-Sutcliffe efficiency into three distinctive components representing the linear correlation (r), the variability bias ($\alpha$), and mean bias ($\beta$).

$$\text{KGE} = 1 - \sqrt{(r - 1)^2 + (\alpha - 1)^2 + (\beta - 1)^2} \tag{8.9}$$

Equation (8.9) can be represented using the following formula:

$$\text{KGE} = 1 - \sqrt{(r - 1)^2 + \left(\frac{\sigma_{sim}}{\sigma_{obs}} - 1\right)^2 + \left(\frac{\mu_{sim}}{\mu_{obs}} - 1\right)^2} \tag{8.10}$$

where $\sigma_{obs}$ is the standard deviation in observations, $\sigma_{sim}$ the standard deviation in simulations, $\mu_{sim}$ the simulation mean, and $\mu_{obs}$ the observation mean. Similar to the NSE, a value of KGE equal to 1 indicates a perfect agreement between the observed and simulated discharge.
