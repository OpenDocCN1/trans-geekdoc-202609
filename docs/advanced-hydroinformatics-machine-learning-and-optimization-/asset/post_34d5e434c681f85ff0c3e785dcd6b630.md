To address these issues, we incorporated an unsupervised clustering technique, the K-means method, into an existing spatial random sampling toolbox for grid-based data analysis (SRS-GDA toolbox; Wang & Xuan, 2020). The SRS-GDA toolbox can help to reduce drastically the overhead of sampling data for training; and the new addition of the machine learning component makes it possible to classify and extract spatio-temporal features from large environment observations data sets. The enhanced toolbox is tested using the daily rainfall images extracted from the GEAR data set (Tanguy et al., 2016), which is a grid-based data set (1 km × 1 km) of daily rainfall covering Great Britain (700 × 1,250 grids) over the period of 1898–2010. The daily rainfall is the total rainfall amount over a 24 hr period from 9 a.m. of the reporting day until 9 a.m. on the following day. The chosen data set shares many features of other large environmental modeling results and observations, for example, climate reanalysis and projections, such as those from ERA40 (Uppala et al., 2005), CMIP5 (Taylor et al., 2012). Therefore, the example given in this chapter can be readily expanded to cover many other similar cases.

There are three main indices used for quantifying the patterns of the variable (daily rainfall in this study), (1) geographic location, (2) pattern size, and (3) orientation. The rainfall patterns over the last century in Great Britain (GB) was first extracted using the toolbox automatically before several significant patterns in England, Wales, and Scotland were recognized, respectively. The efficacy of the toolbox in deep learning is demonstrated by the training of a CNN model to automatically recognize the rainfall patterns from a test set of 1,166 daily rainfall in GB.

The remainder of this chapter is organized as follows: section 12.2 describes the toolbox and pattern identification and extraction; section 12.3 shows the rainfall patterns classified over a hundred years in GB and the pattern recognition by CNN. Finally, the conclusions and recommendations of further study are given in section 12.4.

## 12.2. Toolbox

### 12.2.1. Spatial Random Sampling Toolbox for Grid-Based Data Analysis (SRS-GDA)

The Spatial Random Sampling toolbox for Grid-Based Data Analysis (SRS-GDA) was originally designed by Wang and Xuan (2020), which is used to generate arbitrary regions of interests (ROIs) from grid-based
hydroclimatic data sets, aiming to address the needs of quantifying hydroclimatic responses that vary with location and scale. The features of the sampled ROIs can be either randomly set or customized by a variety of constraints such as shape, size, location, dominant orientation, and resolution. The sampling process is conducted within a boundary where there are valid records, over the ROIs defined by the three main parameters, which are the centroid coordinates defining the geographic location, the ROI size, and the shape parameter sp defined as a ratio between the north-south direction D_NS and the west-east direction D_WE ( sp = D_NS / D_WE ).

In this study, we continue to use the first two parameters to define the ROIs but improve the sp to be a ratio of the major axis and the minor axis (instead of N-S versus W-E). A new parameter ω is also added to define the orientation of this ROI, that is, the angle between the major axis of the ROI and the north direction.

### 12.2.2. Pattern Recognition and Feature Extraction of Rainfall Data

The original SRS-GDA toolbox does not have the capacity to directly support the deep learning of grid-based environment data set. A new pattern recognition with feature labeling is implemented in this study. The structure of the enhanced SRS-GDA toolbox is shown in Figure 12.1. The improvement lies in that it can now extract important features/attributes from the input images or data sets by an unsupervised clustering algorithm.

As shown in Figure 12.1, there are two different types of inputs to the toolbox: images or data sets. If the inputs are rainfall images, there is a transformation carried out before detecting rainfall patterns. The color scale of the images is normally represented by RGB (red, green, and blue channels) in image processing, which has some drawbacks because it produces a nonlinear and discontinuous space and thus is affected by illumination changes. In this study, a transformation is applied to convert the colors from the RGB space to the CIELab color space (Tkalcic & Tasic, 2003), where a color is specified by three values: L for the lightness from black (0) to white (100); a from green to red; and b from blue to yellow. The use of the CIELab color space has helped improve the performance of the toolbox in quantifying the visual differences of colors.

The inputs fed to the toolbox are organized in a format of 3-D arrays whose third dimension are set as the time reference.
