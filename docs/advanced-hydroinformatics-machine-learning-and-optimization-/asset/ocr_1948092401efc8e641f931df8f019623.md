Each tree in a random forest can be picked only from a random subset of features. This potential limitation makes more variation among the trees in the model, and eventually leads to a lower correlation among trees and more diversification. However, one of the main problems of regression trees is that they are prone to overfitting in the training period and thus perform poorly in validation when given unseen data (e.g., Murphy, 2012). Overfitting occurs when the model is flexible and has a high capacity to memorize and learn both the actual relationship in the training data and any noise present in the data set. The RF model can overcome this deficiency by learning the structure of the decision tree that varies considerably with the training data. Instead of searching for the most important feature while splitting a node, RF searches for the best feature among a random subset of features. This results in a wide diversity that generally leads to better performance, thus avoiding overfitting of the model to the training data set. Users have the ability to make trees more random by using random thresholds for each feature, rather than searching for the best possible thresholds.

# *Determination of Input Structure and Calibration Setup*

Antecedent values of input variables could be considered to represent the catchment characteristics in the ML models (Solomatine & Xue, 2004; Tongal & Booij, 2018). In this study, a combination of precipitation ($P$), maximum and minimum temperatures ($T^{\mathrm{max}}$ and $T^{\mathrm{min}}$), solar radiation ($Srad$), and humidity ($H$) was used in addition to the antecedent day streamflow ($Q^s_{t-1}$) to build the rainfall-runoff simulation. The antecedent day streamflow was calculated using a Feed-Forward Neural Network (FFNN). After a number of experiments on the training data set aimed at finding the most relevant inputs, the following common input structure was selected:

$Q^s_t = f(P_t, \ldots, P_{t-3}, T^{\mathrm{max}}_t, T^{\mathrm{min}}_t, Srad_t, H_t, Q^s_{t-1})$. (5.4)

Prior to the model development, normalization was applied to all input variables as

$X_{norm} = \frac{X_0 - \mu_x}{\sigma_x}$. (5.5)

where $X_{norm}$ and $X_0$ indicate, respectively, the scaled and original data. The $\mu_x$ and $\sigma_x$ represent the mean and standard deviation of the original data, correspondingly.
