An important step in any ML exercise is partitioning data into training, cross-validation, and testing subsets. There are various approaches for data partitioning, from simple methods like random sampling, to more complex methods aimed at optimization of the resulting models (e.g., Genetic Algorithm, Self Organizing Maps; Bowden et al., 2002). The most widely used and simplest method is random sampling, which was used in this study for the Time-Delayed Neural Network (TDNN) models. Each subset is filled with randomly selected samples from the overall data set, which avoids high bias in the performance of the model (Reitermanova, 2010). The data partitioning for the LSTM model is explained in a later section.

The NWP rainfall data were from the Interactive Grand Global Ensemble data set, and downloaded from the ECMWF (https://apps.ecmwf.int/datasets/). This download was performed using a Python script and Application Programming Interface (API), which allows for connecting to the ECMWF server and downloading requested data. The script specified the class of data preferred, the type of data set, the date required, grid size, the parameter(s) required, the time step(s) desired, and specific grid coordinates for selecting a desired region. The data were stored in gridded format and these files were processed using the software Panoply, a data viewing tool developed by National Aeronautics and Space Administration, which allows for the visualization of Network Common Data Form (NetCDF), General Regularly Distributed Information in Binary form (GRIB), and other data sets.

For building ML models, Google’s TensorFlow (Abadi et al., 2016a; Abadi et al., 2016b) was used. It is used widely for its deep learning capabilities, and the high-level API Keras (Chollet, 2015) makes building and evaluating ML models easy. The ANN was the Machine Learning technique used, and two model architectures were developed: a Multi-Layer Perceptron (MLP) TDNN (Luk et al., 2001) as well as a LSTM (Sherstinsky, 2020) network. Both architectures were designed with a single hidden layer (see experimental setup for number of nodes), and to generate a single output, and one of each architecture was developed for each location under study.
