The use of synthetic instead of real data is acceptable since, from a practical viewpoint, calibration is only an auxiliary stage of the overall modeling procedure. Furthermore, in order to assess the predictive capacity of the model, all available historical information is accounted for, thus the validation data set is also extended. Under this premise, the decision of which part of data should be used for calibration and which for validation makes no sense any more.

The use of stochastically generated data instead of historical samples that contain relatively few combinations of system inputs (rainfall), outputs (runoff), and states (storage conditions), and obviously miss long-term hydroclimatic fluctuations and rare events, also allows for addressing the major issue of representativeness of hydrological information from which the model parameters are inferred. It is recognized that the observed data partially only reflect the actual statistical and stochastic behavior of the input and output processes, while further uncertainties arise due to measurement and processing errors.
