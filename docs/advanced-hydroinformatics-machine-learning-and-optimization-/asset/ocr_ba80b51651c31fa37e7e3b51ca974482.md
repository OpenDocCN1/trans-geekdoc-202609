# 10.3.7. Step 7 (Sentiment Analysis)

An important analysis that could be derived from NLP tools is sentiment analysis. Sentiment analysis shows the perception of an author when writing the article, interpreting this sentiment with a number that ranges between 0 (negative sentiment) and 1 (positive sentiment). For this purpose, a neuronal network is built to classify the writer’s sentiment through a numerical value; a summary of the involved processes is shown below. This requires statistical data sampling, data normalization, input variable selection, training, and validation.

# Algorithm 10.1 Sentiment analysis pseudo code

```
Input: x=[x₁, . . . , xₙ], xₜ ∈ Rᵐ and s=[s₁, . . . , sₙ], xₜ and sₜ ∈ [0,1]
Initialize parameters: w=[w₁, . . . , wⱼ], wₜ ∈ Rⁿ
for t=1, . . . , n do
  Calculate y=w•x
  Update w
  Calculate error(y,s)
end for
Output: sₙ₊₁ ∈ [0,1]
```

In this research, we used the spanish_sentiment_analysis library (Hofman, 2017/2021), which was already trained and tested in its open source version. The library used almost one million reviews of users of the following webpages: Trip Advisor, PedidosYa, Apestan, QuejasOnline, MercadoLibre, SensaCine, OpenCine, TASS, and Twitter (Spanish-language version) for its calibration and validation. TensorFlow and Marisa-trie libraries were used for building the sentiment neuronal network. In this process, the model developed a regression between the users’ reviews of the websites and their corresponding scores on a scale from 0 to 5 (websites’ 5-star reviews). Then, this information was represented as a numerical value between 0 and 1, where a 5-star review represented a sentiment value of 1. This calibrated model was used to predict the news sentiment over the Magdalena River Basin.
