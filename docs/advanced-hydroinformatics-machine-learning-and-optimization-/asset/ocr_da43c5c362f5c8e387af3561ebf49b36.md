The ANN-MLP models for different lead times have been optimized using a cross-validation data set, which allows to stop the training process, determine the number of neurons (i.e., nodes) using a trial-and-error optimization, and avoid overfitting (i.e. the model tries to follow all the training data points). Last, the verification data set allows to see how the model would perform with a data that it never seen.

The results of the each trained MLP-ANN forecast model for different lead times were evaluated using goodness-of-fit functions and visual inspection analysis between the observed and simulated discharge. The following error functions are used as goodness-of-fit function between the observed discharge (Q_obs) and the simulated discharge (Q_sim).

# The Mean Error (ME)

The Mean Error function is calculated using the mean difference between the observed (Q_obs) and simulated discharge (Q_sim). The problem related to this error is that it could display a low value as well as low accuracy and precision.

ME = Σ (Q_sim − Q_obs) / n. (8.5)

# The Nash-Sutcliffe Efficiency (NSE)

The Nash-Sutcliffe efficiency (1970) is defined as one minus the sum of the absolute square difference between the simulated and observed values normalized by the variance of the observed values. The NSE range varies from −∞ to 1 where a value of 1 indicates a perfect reproduction between the observed and simulated discharge. Conversely, if the NSE value is equal or less than 0, it means that the model is not a better predictor than the mean observed discharge (Q̅_obs). In literature, a value larger than 0.6 indicate a satisfactory result of the model performance. (Gupta et al., 1998). The major disadvantage of this goodness-of-fit function was stated by Legates and McCabe (1999) and Krause et al. (2005) in which the NSE value overestimates larger values and neglects lower ones.

NSE = 1 − Σ (Q_sim − Q_obs)² / Σ (Q_obs − Q̅_obs)². (8.6)
