For cross-validation between all k-folds, we used the early stop method to avoid overfitting. A common practice is to average the performance across the entire validation set for all the folds used to select the best structure from the ANN model (in this case, HN). This is done to emulate randomness and therefore represent statistical independence. The average here, by default, would decrease the possibility of having poor results in future tests, due to the average effect. Only it would also reduce the chances of getting the best results. However, in the example in this study, the test set was never submitted to the process, nor was it considered to guarantee the best results. The best fold was selected and, subsequently, we evaluated the parameters obtained in the test partition. To keep the same conditions for the following experiments (WANN and WANN without noise), only the third fold (the best fold in the ANN structure) was used. By doing this, the expected improvement would not be a reflection of other factors, such as better matching of subsets. Therefore, the improvement could be attributed to the chosen modeling method.
