The features of the sampled ROIs can be either randomly set or customized by a variety of constraints such as shape, size, location, dominant orientation, and resolution. The sampling process is conducted within a boundary where there are valid records, over the ROIs defined by the three main parameters, which are the centroid coordinates defining the geographic location, the ROI size, and the shape parameter sp defined as a ratio between the north-south direction D_NS and the west-east direction D_WE ( sp = D_NS / D_WE ).

In this study, we continue to use the first two parameters to define the ROIs but improve the sp to be a ratio of the major axis and the minor axis (instead of N-S versus W-E). A new parameter ω is also added to define the orientation of this ROI, that is, the angle between the major axis of the ROI and the north direction.

of Rainfall Data

The original SRS-GDA toolbox does not have the capacity to directly support the deep learning of grid-based environment data set. A new pattern recognition with feature labeling is implemented in this study. The structure of the enhanced SRS-GDA toolbox is shown in Figure 12.1. The improvement lies in that it can now extract important features/attributes from the input images or data sets by an unsupervised clustering algorithm.

As shown in Figure 12.1, there are two different types of inputs to the toolbox: images or data sets. If the inputs are rainfall images, there is a transformation carried out before detecting rainfall patterns. The color scale of the images is normally represented by RGB (red, green, and blue channels) in image processing, which has some drawbacks because it produces a nonlinear and discontinued space and thus is affected by illumination changes. In this study, a transformation is applied to convert the colors from the RGB space to the CIELab color space (Tkalcic & Tasic, 2003), where a color is specified by three values: L for the lightness from black (0) to white (100); a from green to red; and b from blue to yellow. The use of the CIELab color space has helped improve the performance of the toolbox in quantifying the visual differences of colors.
