independent and statistically similar data sets, so the modeler should try to ensure similarity in the distribution.

+   2. The model results can be affected by the method of partitioning.
+   3. When using a cross-validation data set, it is not always clear when the model is learning the noise of the data.

# 8.2.3. Choice of Model Input Variable

The data cleansing and the selection of proper input variables are another important step in DDM, which take more time and effort that the modeling part. It is common that real-life data have a lot of errors, noise, or missing data. Additionally, outliers may also pose a problem since they could be an indicator of extreme event or erroneous measurement. For this reason, the modeler should be able to identify these atypical values (i.e., outliers) before building any kind of hydrological model.

Another important step is the choice of the model variable that has to consider the physics of the underlying process. In DDM, the physics is introduced by the choice of the relevant input variable that contributes to predicting the output value. Bowden et al. (2005) stated that many DDM modelers often present a large number of inputs and rely on the network to identify the inputs. This deficiency in the modeling process can increase the complexity, reduce the learning process, and model performance.

In literature, five approaches for input determination in DDM modeling have been addressed by Bowden et al. (2005): (1) Methods that rely upon the use of a priori knowledge, (2) methods based on linear cross-correlation, (3) methods that utilize a heuristic approach, (4) methods that extract the knowledge contained within trained ANN, and (5) a combination of the above four approaches.

In this study, the most appropriate inputs for predicting future discharge were estimated using the linear correlation and the average mutual information (AMI) as it was done by Solomatine and Dulal (2003) and Corzo et al. (2009).

The Average Mutual Information (Shannon, 1948) is used to investigate linear and nonlinear relationships and lag effects between the time series variables. It is the measure of information available from one set of data having knowledge of another data set. In other words, it represents the measure of information that can be learned from one data set (X) having the knowledge another data set (Y).

```
AMI = Σ_{i,j} P_{XY}(x_i,y_j) log₂ [ P_{XY}(x_i,y_j) / (P_X(x_i) P_Y(y_j)) ] . (8.3)
```
