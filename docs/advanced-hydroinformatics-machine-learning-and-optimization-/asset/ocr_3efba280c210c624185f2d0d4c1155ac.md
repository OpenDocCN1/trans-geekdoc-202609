# 2.1. Introduction

Hydrological models are essential elements for supporting water engineering and management decisions. These typically adopt the concept of stationarity, which allows for handling the process descriptions and model parameters as time-invariant. In this respect, while model-based decisions refer to the intrinsically uncertain future, the identification of the underlying modeling scheme and the evaluation of its predictive capacity as well, are founded on past information about the catchment’s response against a known set of meteorological inputs.

In a generic context, the identification of a particular hydrological model is subject to a sequence of user decisions, where the interplay of parameter values, process parameterization equations, and the overall system architecture should ensure the minimal uncertainty against the available information (Gharari et al., 2021). However, the typical problem posed in real-world applications is restricted to the parameter estimation of a given model structure. According to the common hydrological practice, this task is formalized by means of the well-known split-sample test (Klemeš, 1986) and its variants (e.g., Gowda et al., 2012; Arsenault et al., 2018; Nicolle et al., 2021). This requires separating the observed data in a calibration subset for parameter adjusting, and a second one for validation. Any important drop in model performance in validation with respect to calibration may raise flags about the model robustness, which is often due to overfitting against nonrepresentative calibration data. Therefore, key decisions are the separation strategy and the length of calibration, which should embed diverse hydroclimatic conditions, also including unusual events (Singh & Bárdossy, 2012), to ensure that all model features are well activated.
