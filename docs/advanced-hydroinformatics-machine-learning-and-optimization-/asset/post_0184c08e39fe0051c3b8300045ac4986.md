$$RMSE = \sqrt{\frac{\sum_{i=1}^{n} (O_i - P_i)^2}{n}}.$$

It is a nonnegative metric that has no upper bound and for a perfect model, the result would be zero (Dawson et al., 2007). The method is more sensitive to larger errors due to the square component in the residual error, afterward the mean and the square root are computed to bring the error in the same units as the value to be predicted.

- 2. Nash-Sutcliffe efficiency (NSE): It is used to assess the predictive power of hydrological models and is defined as

$$NSE = 1 - \frac{\sum_{i=1}^{n} (O_i - P_i)^2}{\sum_{i=1}^{n} (O_i - \bar{O})^2}.$$

NSE can lie between 1.0 (a perfect match of modeled discharge) and $-\infty$. If NSE is zero, it indicates that the model predictions are as accurate as the mean observed data. When lower than zero, it indicates that the mean value of the observed time series would have been a better predictor than the model (Krause et al., 2005).

- 3. Persistence Index (PERS): The persistence index focuses on the relationship between the model performance and the performance of a naïve model, a model that assumes as the forecasted value the same current value.

$$PERS = 1 - \frac{SSE}{SSE_{naive}};\text{ where } SSE_{naive} = \sum_{i=1}^{n} (O_{t+L} - O_t)^2.$$

Other error metrics were also computed, such as mean absolute error (MAE), normal root mean square error (NRMSE), correlation coefficients (Cor), StdT, StdP, MuT, MuP, RMSEN, NRMSEN, MARE.

For cross-validation between all k-folds, we used the early stop method to avoid overfitting. A common practice is to average the performance across the entire validation set for all the folds used to select the best structure from the ANN model (in this case, HN). This is done to emulate randomness and therefore represent statistical independence. The average here, by default, would decrease the possibility of having poor results in future tests, due to the average effect. Only it would also reduce the chances of getting the best results. However, in the example in this study, the test set was never submitted to the process, nor was it considered to guarantee the best results. The best fold was selected and, subsequently, we evaluated the parameters obtained in the test partition. To keep the same conditions for the following experiments (WANN and WANN without noise), only the third fold (the best fold in the ANN structure) was used. By doing this, the expected improvement would not be a reflection of other factors, such as better matching of subsets. Therefore, the improvement could be attributed to the chosen modeling method.

Figure 9.7 shows how the behavior differs according to the particular data selection or fold during the training process, highlighting the importance of the k-fold cross-validation procedure. The same chart was built for the remaining 19 HNs, however only the best result is shown here (for HN = 20). Although Figure 9.8 highlights that nodes 9–11, 15, and 17 provide poor results for the test set, the modeler is not allowed to use this set to choose the best model. The best model is chosen via the best cross-validation set. Table 9.3 shows a summary of statistics and error measures belonging to the best ANN model (third fold of HN = 20), in section 9.5.3. The training set gave an RMSE value of 91.81 m³/s considered as good for the case study; the validation set gave an even better result of 84.79 m³/s. In the test set, a mildly acceptable result was obtained (112.44 m³/s). A high correlation was found between the observed and simulated discharge for all data sets, being in all cases greater than 0.9.
