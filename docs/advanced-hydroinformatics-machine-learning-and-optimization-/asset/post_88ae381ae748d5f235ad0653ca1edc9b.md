## 15.3.1. Machine Learning (ML) Models

The reservoir operations in terms of daily release can be parameterized using mathematical functions adjusted to the patterns or shapes that define them. To this end, some artificial intelligence techniques or ML models, most notably ANNs, have proven to be efficient; some have even been classified as universal approximation functions (Tikk et al., 2003). Several authors have shown the benefits of these functions in the analysis of reservoir operation. Not only can they learn and replicate real operating behaviors (Ehsani et al., 2016; Zhang et al. 2018), they also adjust to artificial behaviors induced by purpose fulfillment in optimization problems (Momtahen & Dariane, 2007; Giuliani et al., 2016). The present study proposes two types of ANNs as approximation functions: the MLP and the RBN, in addition to a linear approximation function (LF).

### MLP

Figure 15.7a shows the general scheme of an MLP. The information that enters the network is propagated forward using connections with different values or weights. The MLP has an input layer, where the data are entered, which is processed in the neurons of the hidden layers using activation functions until reaching the output layer, where the results are generated. The output value $y_t$ of a single hidden layer MLP with $M$ input values is defined as:

$y_t = c + \sum_{i=1}^{N} v_i f_i(I_t \cdot w_i + b_i), \quad (15.3)$

where $N$ is the number of neurons with an activation function $f_i(\bullet)$ (e.g., sigmoidal function); $I_t$ is the $M$-dimensional input vector of the network; $w_i$ is the $M$-dimensional vector that represents the connections between the input and the hidden layer; $v_i$ is the $N$-dimensional vector for the connections between the hidden layer and the output layer; $b_i$ is the $N$-dimensional vector of bias for the neurons of the hidden layer; and $c$ is the bias value of the output layer. The number of parameters in this network is $p = N(M + 2) + 1$.

![](img/dd2f1e467aed0a84f984e6e656b2cc0f_437_0.png)

Figure 15.7 Architecture of the ANN: (a) MLP, (b) RBN.

A commonly used activation function in MLP is the sigmoid function, which is presented as

$f_i = \frac{1}{1 + \exp[-(I_t \cdot w_i + b_i)]}. \quad (15.4)$

For this MLP function, the output layer does not have an activation function because the data are standardized using the standard scoring method (see section 15.2.2).

### RBN

These networks use Gaussian functions for data processing, incorporating the center and radius parameters of processing units known as bases (instead of neurons, as in MLPs). Figure 15.7b shows the general schematic of an RBN. The function that the RBN represents is as follows:

$y_t = \sum_{i=1}^{N} w_i g_i(I_t), \quad (15.5)$

$g_i(I_t) = \exp\left[ - \sum_{j=1}^{M} \frac{[(I_t)_j - c_{j,i}]^2}{r_{j,i}^2} \right], \quad (15.6)$

where $y_t$ is the output value; $N$ is the number of bases with Gaussian functions $g_i$; $M$ is the number of input variables; $w_i$ is the $N$-dimensional weight vector between the hidden layer and the output layer; $I_t$ is the $M$-dimensional input vector of the network; and $c_{j,i}$ and $r_{j,i}$ are the center and radial $M$-dimensional vectors of the $i$th base. The number of parameters for an RBN is $p = N(2M + 1)$.

### LF

These are the mathematical functions used to find relationships between variables with linear trends. Unlike the previous functions, they do not have the ability to accurately replicate complex patterns. If $y_t$ is a dependent variable and $I_t$ are the independent variables (input values), the function can be expressed as follows:

$y_t = b + \beta_1 I_{t,1} + \beta_2 I_{t,2} + ... + \beta_M I_{t,M}, \quad (15.7)$

where $y_t$ is the output value; $I_{t,1}, I_{t,2}, ... I_{t,M}$ are the input values; $M$ is the number of input values; $\beta_1, \beta_2, ... \beta_M$ are the weight coefficients of the input values; and $b$ is the bias of the function. The number of parameters is $p = M + 1$.

## 15.3.2. Building ML Surrogate Models of the Real Reservoir Operation

As mentioned in section 15.2.1, the information about operating rules of the reservoir were not available for the case study. Therefore, ML surrogate models were used to simulate the operation of the reservoir. That is, to represent the amount of water that must be released at each time step through models that learn from the real data of the reservoir. This method in which the model learns from known output data or examples is known as supervised learning (Cunningham, 2008).

Initially, the parameterization of the reservoir’s actual discharge $Q_t$ was sought for the analysis period, in which three ML models were tested: MLP, RBN, and LF. The outputs $Q_t$ correspond to total discharges (i.e., turbine discharge, valves discharge, and spills).

Considering that the correlation coefficient is commonly used to determine mathematical linear relations between two samples of random variables, or time series, correlation analysis was applied to select the inputs of the ML models, similar to Corzo (2009). Therefore, these correlations were performed between discharges at each time step $t$ and the other time series (i.e., inflows, reservoir storage levels, and previous discharges). Correlation analysis revealed that for the inflows $IN$, the storage levels $S$, and the previous discharges $Q$, each using a lag time of 1 and 2 days ($IN_{t-1}, IN_{t-2}; S_{t-1}, S_{t-2}; Q_{t-1}, Q_{t-2}$), have the highest correlation values with respect to discharges $Q_t$ (Fig. 15.8).

Using these six inputs for all ML models, different configurations for MLP and RBN were tested varying the number of neurons (MLP) or bases (RBN). The Scikit-learn Python library (Pedregosa et al., 2011) was used for MLP and LF models, while for RBN, Keras was used (Chollet, 2015). In all ML models, 80% of the data was used for training and 20% for the test. The final configurations of the ML models were determined by trial and error. In the case of MLP, configurations with several layers and different numbers of neurons were tested; however, in this case, by increasing the complexity of the network with more hidden layers and neurons, the results were not improved but the number of parameters and decision variables (weights and biases) was increased. Therefore, simple configurations of a single hidden layer and a maximum of 7 neurons in the hidden layer were chosen. Likewise, for the RBN, configurations of a maximum of 7 bases were used. The final configurations of the ML models are as follows:

- 1. Three MLP configurations: 6-7-1, 6-6-1, and 6-4-1 (i.e., 6 inputs - $N$ neurons in a hidden layer - 1 output layer) using the parameters of equation (15.3) with the application of a sigmoid activation function (equation (15.4)).
- 2. Three RBN configurations: 6-7-1, 6-6-1 and 6-4-1. (i.e., 6 inputs - $N$ bases - 1 output layer) using the parameters of equations (15.5) and (15.6).
- 3. Finally, a LF is proposed using the parameters of equation (15.7).

The test runs for the 6-7-1 MLP configuration generated the best performance metrics (RMSE 5.17 and MAE 2.97).
