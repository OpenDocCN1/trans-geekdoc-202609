l and h in the previous equations are calculated as equation (4.8):

l = (Q_obs,max - Q_sim,i) / Q_obs,max,   h = Q_obs,i / Q_obs,max   (4.8)

where Q_obs,max is max observed flow value, α is a threshold for selecting weights, N is the power (see Table 4.1). N was chosen to be 2 ans 3, the value of α is a ratio between calculated discharge at a particular time step and the maximum discharge value in the calibration data set (Q_t/Q_obs,max). α, determines the range of values where both models are working together, and the range where discharge value from the high flow model is only considered, α was chosen to be 0.75. It is important to mention that the values of RMSE_lf, RMSE_hf, and RMSE are calculated differently and cannot be compared with each other, as they have been multiplied by different weights.
