# Extract Features of Rainfall Region(s)

+   Step 1: Detect the boundary
+   Step 2: Segment the (usually) irregular area inside the boundary into many small relative-regular regions such as rectangle, triangle. Then add them all to be the area size A.
+   Step 3: Calculate the centroid of the area: calculate the distance between each centroid of region and x/y-axis, multiply each regular size and get Ax and Ay, then compute the centroid by using formula Cx or y = Σ Axi or yi/A.
+   Step 4: Calculate ω which is the angle of main axis with the westing direction.
+   Step 5: Draw the main axis of this area by known centroid C and ω. Using an outer rectangle to limit the length of main axis and minor axis.
+   Step 6: The attributes are transformed into GEAR map and summarized as the outputs.
