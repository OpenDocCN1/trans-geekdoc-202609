# 9.2.2. The Continuous Wavelet Transform (CWT)

The wavelet transform of a continuous signal for the wavelet function is defined as

T(a, b) = w(a) ∫_{-∞}^{∞} x(t) ψ* ((t - b)/a) dt Addison (2010). (9.1)

Usually w(a) (weighting function) is normalized to 1/√a, is in the sense of the wavelet energy, and the convolution is between the signal x(t) and the wavelet function ψ. In the wavelet, the dilation and contraction are governed by the dilation parameter a, and the movement is governed by the translation parameter b. The shifted and dilated version of the mother wavelet is denoted ψ[(t-b)/a]. The normalized wavelet function is often written more compactly as ψ_{a,b}(t) = 1/√a ψ((t-b)/a); so the wavelet transform can be written as T(a, b) = ∫_{-∞}^{∞} x(t) ψ*_{a,b}(t) dt; T(a, b) = ⟨x, ψ_{a,b}⟩. The product of the wavelet and the signal integrated over the window length of the wavelet like function is called convolution.

# 9.2.3. The discrete wavelet transform (DWT)

The a and b parameter can be sampled with a logarithmic discretization of the a scale, then to move in discrete steps b by making b proportional to a, ψ_{m,n}(t) = 1/√(a₀^m) ψ((t - n b₀ a₀^m)/a₀^m). When the discrete wavelet parameters a₀ and b₀ are chosen to be 2 and 1, respectively, the arrangement is known as the dyadic grid, ψ_{m,n}(t) = 1/√(a₀^m) ψ((t - n b₀ a₀^m)/a₀^m) = 1/√(2^m) ψ((t - n 2^m)/2^m).

The discrete wavelet transform values, given on a scale location grid of index m, n, are known as detail coefficients and they are expressed as follows T_{m,n} = ∫_{-∞}^{∞} 1/√(2^m) ψ((t - n 2^m)/2^m) x(t) dt. The scaling function is associated with the smoothing of the signal and it has the same form as the wavelet, given by φ_{m,n}(t) = 1/√(2^m) φ((t - n 2^m)/2^m). When the scaling function is convolved with the signal, the approximation coefficients are produced; S_{m,n} = ∫_{-∞}^{∞} 1/√(2^m) φ((t - n 2^m)/2^m) x(t) dt.
