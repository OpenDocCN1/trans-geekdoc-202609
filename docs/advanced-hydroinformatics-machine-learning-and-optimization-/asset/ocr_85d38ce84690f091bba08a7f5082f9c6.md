Alternatively, the wavelet function can be calculated with this relation:

$$\frac{1}{2}\psi\left(\frac{t}{2}\right) = \varphi(t) - \frac{1}{2}\varphi\left(\frac{t}{2}\right).\tag{9.8}$$

After the convolution is done $T_{m,n}=\langle x(t),\psi\left(\frac{t-b}{a}\right)\rangle$, the same results are expected. Due to the link between decompositions at a different level, the multiresolution algorithm can be constructed $S_{0,n}=S_{m,n}+\sum_{m=1}^{M}T_{m,n}$.

# 9.2.5. Artificial Neural Networks

The artificial neural network is a well-established method. It had its beginnings with the threshold logic model (McCulloch & Pitts, 1943) and the model paved the way for the now known ANN. It was developed in the field of machine learning, quickly accepted, and established in applications where it is not possible to have a physically based model. ANNs are generally presented as systems of interconnected "neurons" that learn from experience as humans do. Zijderveld (2003) presents comprehensive documentation that readers not so familiar with ANN can review to delve into details. The mentioned author explains neural networks as a directed graph consisting of nodes with synaptic links and interconnection activation characterized by four properties:

+   1. Each neuron is presented by a set of linear synaptic links and externally applied bias.
+   2. The synaptic links of a neuron weight their respective input signals.
+   3. The weighted sum of the input signals defines the induced local field of the neuron in question.
+   4. The activation link squashes the induced local field of a neuron to produce an output.

The components of neural networks are weighting factors, summation, transfer, scaling, output, error, and learning functions. Once the network is ready and prepared for a particular task, the following step is the learning process. In this process, there are two approaches (supervised and unsupervised). In the first (of our interest) both the input series and the output series are presented to the model and the learning process is carried out by comparison. Optimization is carried out by taking the objective function as the difference between the modeled and the observed value. In this process, the back-propagation algorithm is in charge of adjusting the weights between nodes to find the best approximation for the objective function.
