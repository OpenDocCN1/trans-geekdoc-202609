Three correlation-based feature selection and extraction algorithms have been proposed [108] to find the essential feature subsets that are most significant. The efficacy as well as the feature selection algorithm effectiveness is evaluated on the basis of a highly intrinsic brain image dataset.

A novel image retrieval system has been proposed [85] in which three distinct feature selection and extraction algorithms are used to extort the essential textures from images, and potential feature vectors are identified using a hybrid approach and evaluated on breast image datasets along with brain tumor and thyroid images.

Feature enrichment–based CNN (FE-CNN) has been proposed [91] for heartbeat classification from electrocardiogram (ECG) signals. The ECG signals are transferred to a time-frequency image format and enhanced using a discrete short-time approach based on a Fourier Transform algorithm, and then these formatted images are input to the proposed CNN model. Another popular model called FE-CNN is trained on an MIT-BIH arrhythmia database and outperforms other popular algorithms without the use of a hand-crafted feature extraction algorithm. PFAF-Net, as introduced in [7], is a Pyramid Feature Network model that incorporates the fundamental concept of merging high- and low-level features at multiple scales. The attention-based fusion strategy is adopted to fuse the global and local features effectively. The decoder model will reconstruct the extracted image and then will integrate it with the multimodal data, resulting in rich content details. The model is experimented on four benchmark datasets: medical, multiexposure, multifocus, and visual-infrared. Selected numerical algorithms [96] for enhancing the performance of symmetric multiprocessing machine have also been introduced.
