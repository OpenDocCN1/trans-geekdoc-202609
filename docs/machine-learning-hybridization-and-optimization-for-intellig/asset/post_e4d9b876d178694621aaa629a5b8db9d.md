## 12.4.6 A* ALGORITHM

One of the most popular path planning algorithms is the A* method, which may be used in either metric or topographical configuration spaces. This algorithm employs a heuristic search strategy in addition to the shortest path finding. Since every cell in the solution space is assessed using the value mentioned below, A* approach is also known as the best-first algorithm [51]:

x(v) = y(v) + z(v) (1)

where y(v) is the length of the route through the chosen series of cells from the original state to the target state, and z(v) is the heuristic distance of the unit to the target point. Naturally, this pattern terminates in the cell that was really evaluated. The value x is applied to each neighboring cell of the cell that was really visited (v). The following cell in the sequence is selected based on which cell has the minimum values of x(v). This algorithm’s advantage is that the lengths used as a parameter can be changed, added, or substituted. This provides a large range of variations on this fundamental idea [52]. The simulation took an average computer over an hour to complete for the map with 60,000 cells. This is really disappointing for the robot while using this algorithm. As a result, further research into the A* algorithm’s customization options was done.

## 12.4.7 RAPIDLY EXPLORING RANDOM TREE

In the rapidly exploring random tree (RRT) algorithm, points are randomly generated and connected to the closest available node. After several iterations, possible paths look like branches. In the field of path planning, it is a widely used approach. There should be an initial point and a target point specified in the workspace for the RRT technique to find a path. The system receives the starting point as input and then builds the tree until it reaches the last node or goal node. This approach is renowned for constructing its path finding tree. It begins by creating a random component in the workspace according to the distance between the nodes after the initial node. It chooses the node in the tree that is the closest to this random node [53]. Figure 12.2 shows the flowchart for the RRT algorithm.

## 12.4.8 PATH PLANNING IN UNSTRUCTURED, NOISY, AND LARGE-SIZED Map DATA

Path planning in unstructured, noisy, and large-sized data refers to real-time warehouse data, which can be inconsistent or inaccurate or contain unrelated information because it is not organized in a specific style or structure. In the context of robot path planning, unstructured data may include the data received from sensors such as cameras or lidar, which record the environment around the robot in a continuous and unstructured way, which also creates errors and inaccuracies [55]. An example of this would be sensor measurements that are impacted by the lighting of the surroundings. Robot path planning can be difficult when dealing with this kind of data because it can result in poor or inefficient choices being made.

Big-sized data can refer to enormous amounts of sensor data that must be processed in real time for the robot to make decisions and navigate through its surroundings when used in the context of planning a robot’s route. Depending on the sort of data being collected and the technique being used for collection, warehouse data can be either structured or unstructured [56].

A database or spreadsheet can be used to quickly organize inventory data, such as the quantity of things in stock, their location, and their movement within the warehouse. However, because they gather data continuously and haphazardly, frequently with missing or incorrect readings, sensors like cameras, barcodes, and RFID tags may produce unstructured and noisy data. The position and movement of the items within the warehouse, as well as information on environmental variables like temperature, humidity, and lighting conditions, can all be included in this data. Data can be both structured and unstructured when used for robot route planning in a warehouse.

Structured data can contain details about the layout of the warehouse, the placement of objects and obstacles, the robot’s current position, and its intended destination. The robot’s route can be planned to use a database or map that can be created from this structured data.
