The software layer that makes virtualization possible is the hypervisor. An attacker may be able to access every virtual machine running on that physical server if the hypervisor is hacked. In light of this, hypervisor security is essential for safeguarding virtual computers and the data they house. Cloud providers must put in place stringent security controls, such as frequent security patches, access controls, and intrusion detection systems, to reduce the risks associated with hypervisor security. They should also employ isolation and segmentation strategies to stop virtual machines from communicating with one another, as well as monitor hypervisor activity for any odd behavior. Additionally, to find and fix any vulnerabilities in the security of the hypervisor, cloud providers should do routine security audits. Additionally, they must stay informed of the most recent risks and weaknesses to the security of hypervisors and take the necessary steps to resolve them.

# 7.5.2 SHARED INFRASTRUCTURE VULNERABILITIES

Security flaws that affect numerous people or systems that share the same underlying infrastructure or resources are referred to as *shared infrastructure vulnerabilities*. On shared infrastructure components like servers, databases, or network devices, these vulnerabilities may develop as a result of inadequate security controls, incorrect configuration, or out-of-date software [17]. A data breach brought on by an improperly configured cloud storage bucket is an illustration of a vulnerability in shared infrastructure. When several users store their data in the same bucket, there is a risk that a configuration error could make the bucket accessible to the public, making all the data visible to unwanted parties. Strong security measures should be put in place, and shared infrastructure components should be monitored and updated often in order to reduce vulnerabilities in shared infrastructure. To reduce the effect of any security events that do happen, they should also adhere to best practices for access control and privilege management.
