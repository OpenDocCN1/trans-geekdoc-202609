## 4.3 PROPOSED SYSTEM

The objective of the AgTech Revolutionize Farming Practices using IoT [33] is to enhance plant health monitoring by the gathering and [32] analysis of real-time data on critical parameters such as temperature, humidity, soil moisture, and nutrient levels. It enables soil monitoring and analysis, including measurement of pH, nutrient levels, and other critical factors. Machine learning and predictive analytics are used to support agricultural activities such as planting, fertilizing, and harvesting decision-making. Data-driven scheduling and management are used to optimize irrigation operations based on soil moisture and weather conditions. It creates an intuitive interface for farmers to access and engage with the intelligent farming [36] assistant, including data input, reports, alerts, and recommendations. It also integrates with other farming systems and technologies [37, 38, 39, 40, 41], such as weather forecasts, pest control, and irrigation. ### 4.3.1 HARDWARE DETAILS

- **Raspberry Pi 3:** Raspberry Pi is a series of low-cost, single-board computers developed in the United Kingdom by the Raspberry Pi Foundation to promote the teaching of basic computer science in schools and developing countries. We are using Raspberry Pi as an interface between cloud and vision sensors. It is enacted as an intermediary which will convert the sensory data into the desired form and transfer it to the cloud storage.
- **Pi Camera rev 1.3:** The Raspberry Pi camera is an add-on module for the Raspberry Pi, which allows users to take high-quality photos and videos. This will send these clicks to our Raspberry Pi, which will further send it over the cloud for data processing.
- **NoIR Camera:** This Raspberry Pi [1] camera is made to function with the Raspberry Pi. It is a top-notch camera module that offers several features and functionalities, as well as the ability to take photos and record videos in high definition, even in poor lighting. This camera can get infrared reflectance values which will be useful to map the NDVI index. This is another cam module we are using for taking pictures in order to monitor the health of plants and record their daily growth.
- **Arduino IDE:** Arduino is an open-source electronics platform based on simple, easy-to-use hardware and software. It is designed to make it easier for people to get started with electronics and programming. The Arduino platform consists of a series of microcontroller boards and a software development environment that allows users to write code and upload it to the boards. The Arduino IDE is a software tool for writing programs and uploading them to boards with Arduino microcontrollers. With features like code highlighting, auto-complete, and debugging tools, it offers a user-friendly interface for creating, testing, and distributing code. We are using Arduino for interfacing sensors related to monitoring plants’ environment.
- **DHT Sensor:** The DHT (Digital Humidity and Temperature) sensor is a commonly used sensor in electronics projects to measure the temperature and humidity of the environment. It is available in different types, including DHT11, DHT22, and AM2302, each with different levels of accuracy and range. We are using DHT as a part of our project for capturing the details of the surroundings of the testing area. We are using Arduino to interface it with NodeMCU.
- **Soil NPK Sensor:** The Soil NPK sensor measures the levels of nitrogen, phosphorus, and potassium in the soil. This sensor is interfaced with an Arduino and NodeMCU microcontroller board, which can then transmit the data wirelessly to a central database. By monitoring NPK levels in the soil, farmers and gardeners can determine when to fertilize, how much to fertilize, and what type of fertilizer to use, thereby optimizing plant growth and yield while minimizing environmental impact.
- **pH Sensor:** The pH sensor can measure the acidity or alkalinity of the soil, which is a crucial factor in plant growth and health. By integrating the sensor with Arduino and NodeMCU, we are sending the data to a cloud-based platform for analysis and visualization. This allows farmers or gardeners to monitor the pH levels of their soil in real time and make informed decisions about soil health management.
- **NodeMCU:** NodeMCU is an open-source microcontroller board (SoC). It is made to make it simpler for individuals to get started using linked devices and IoT. Wi-Fi connection, microcontroller capability, and a variety of input/output (I/O) pins for interacting with sensors, actuators, and other devices are just a few of the features and capabilities offered by NodeMCU. The purpose of using NodeMCU in our project is to act as a transfer medium for sensory readings and a network pipeline connecting to our Google Cloud database to perform the required processing.
- **Google Cloud Database:** For our cloud storage, we used Google Cloud BigQuery, which is a cloud-native data warehouse for storing, analyzing, and querying large datasets. It is highly scalable, supports multiple data sources and formats, and provides built-in support for advanced analytics tools. With BigQuery, we are storing data coming from Raspberry Pi and NodeMCU in different buckets ready for analysis.

### 4.3.3 MOBILE APPLICATION

The mobile application module is responsible [1, 2] for providing a user interface for end-users to interact with the system. It allows the users to view the data collected by the sensors, set up alerts and notifications, and perform various actions based on the data. The mobile application also acts as a control center, where users can remotely control various devices based on the data collected by the sensors.

The UML diagram shown in Figure 4.3 illustrates a system created to meet the demands of users looking for information on plant health, weather forecasts, and gardening advice. The major module that includes the sign-in menu, matchmaking, username, password, IP address, and a map of users is called the user. For easier user interaction, the user module offers functions like getchoicesubject(), getchoicemenu(), setuserName(), and getuserName(). A user can sign in or out of the system by inputting their login and password using the Sign-In/Sign-Out UI module, which offers a straightforward and user-friendly interface. Two text boxes for the username and password, as well as two sign-in and sign-out buttons, are included in this module. The Sign-In/Sign-Out module’s interface is like that of the Login UI module, but it offers extra capabilities such as the ability to display the user’s name and password in plain text. A text box for the username and password as well as two buttons for logging in and out are provided by this module. The system’s multiple features, including weather updates, plant health, gardening advice, and settings, are all easily accessible through the Weather/Plant Health/Tips/Settings module. The module has four buttons that the user can utilize to choose between these various capabilities. The basic and language settings, as well as the choice of using the Celsius or Fahrenheit temperature scales, are all accessible through the Settings section. The Weather module offers functions like fetchLocation(), fetchWeatherData(), and recommendAction() that can be used to retrieve weather data and generate suggestions depending on the current weather. To give the user a better understanding of their plants’ health depending on the present and upcoming weather conditions, the Plant Health module offers methods like setPlant(), currentWeather(), futureWeather(), and getPlantHealth(). Based on the user’s plant type, the suggestions module recommends pertinent suggestions using methods like getTips().
