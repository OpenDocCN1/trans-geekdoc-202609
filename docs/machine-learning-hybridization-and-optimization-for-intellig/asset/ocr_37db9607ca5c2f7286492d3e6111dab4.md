# 8.8.2 High-Security Passwords

Each and every application, device, and software-based thing is secured with password options. Even appliances used in our homes may have password options to secure the device. Embedded systems are controlled by our smartphones, even if we are not in that location. In such cases, there may be a high grade of cyberattacks if there is no password to the system. So, for these reasons, there is a security password technique to secure the system each time. By setting passwords, the system may ask for the password each time while accessing. And each time, the system may check whether the password is valid or invalid. Only if the password is valid will the system allow the device to connect to the network, and if it is invalid, the system may give three retry permissions to the users to provide the valid password. If the retry permissions end, the system may block the connection to that device as well. So, it is the highest security technique to secure the devices effectively.

# 8.8.3 Multiple Wi-Fi Networks to the Devices

Commonly, we connect a single Wi-Fi to most of the devices in our home due to lower charges. But here, we are not identifying one of the most effective means. The main advantage of routers is creating the guest network, which has the ability to create more networks with the routers. This is a very useful and fast-accessing network. The main advantage of this guest network is the separation of the network paths of the connected devices. In our daily lives, we may connect to the Wi-Fi with different network connections. For example, consider that there is only a single Wi-Fi connected to all devices in our home. Now assume that our relatives or friends ask for our Wi-Fi network connection. In such situations, they may also connect to that single network available in our home, resulting in multiple devices working with the same network.
