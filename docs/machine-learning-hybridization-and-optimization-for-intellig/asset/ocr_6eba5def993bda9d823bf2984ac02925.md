# 11.3.2 PREPROCESSING

Image preprocessing is the process of formatting UAV_OPL images before they are used in model training. This procedure includes color corrections, resizing, and orientation. Model training and inference are speeded up by image preprocessing. Because the input images are particularly large, it shrinks the images and significantly improves model training time without compromising model performance, and thereby errors are removed from the original image.

# 11.3.3 GENERATING FEATURES WITH GABOR FILTERS

There are a variety of ways to extract features using Gabor filters. The Gabor filter is an image-processing filter for detecting edges, classifying textures, extracting features, and estimating disparity. A band-pass filter enables frequencies in one band to pass while attenuating those in another. A Gabor filter is a Gaussian filter with a plane wave modulation. Gabor filter banks are employed in the classification of features. The real parts of various Gabor filter kernels are used to filter features from OPL images. A classification based on the least squared error is then generated based on the mean and variance of the filtered images. There are several Gabor filters of different parameters that are put together to make up a Gabor filter bank. The parameters lambda, theta, sigma, pi, and gamma must be modified to define Gabor filters. When the Gabor parameters are changed, an image can be used to extract a variety of low-level features.
