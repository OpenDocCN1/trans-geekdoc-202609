Images’ original intrinsic structural information and non-local information are preserved by implementing high-order clustering tensors and are tested on the simulated synthetic aperture radar (SAR) dataset consisting of four real SAR images.

An integrated feature selection algorithm and an innovative technique have been introduced [112] in which both the independence criterion of Hilbert–Schmidt and the linear discriminant analysis of the Kernel Fisher technique have been combined to extract the uncorrelated, low-dimensional, and low-distinctive features. The extracted low-dimensional features are classified using a Naive Bayes classifier. The proposed approach is tested on two typical circuits and successfully detects and classifies most analog circuit faults.

An extended framework [17] has been proposed to mine the inherent features which help in classifying the PolSAR land dataset based on a tensor embedding approach. Every pixel image is represented as an intrinsic feature and the statistical image properties are symbolized in a matrix form. Algorithms based on a vector are then applied to obtain the projection matrices, and the algorithms’ effectiveness seems to be outstanding when tested on three different datasets that cover the regions of San Francisco, Xi’an, and Flevoland.

Feature extraction frameworks [84] that consist of using a feature-centric technique to extract the unique information from a research study have been introduced. To extract the logical outline from articles, a four-stage novel approach is introduced called FLAG-PDFe. The proposed model is built upon an SVCML model and trained on the textual as well as the geometric feature information to extract the unique sections in an article, and comprehensive generic feature evaluations are then done.

A discriminant correlation feature fusion analysis has been proposed [119] to extract features of three unrelated matching types and to differentiate scenes together. The results of one or more classifier models are merged, and finally the best one is identified using the majority voting method; this can further be improved to achieve substantial improvement in classification performance for remote sensing. The proposed feature extraction algorithm is a heterogeneous method that is validated on three well-known datasets: the WHU-RS, the SIRI-WHU, and the Merced UC land-use dataset. As well as this, several researchers have also been concentrating on resolving the problem of insufficient datasets by fusing both global and local features using the traditional PCA method. These feature extraction algorithms are evaluated using a new performance metric called locality preserving projections (LPP). A trainable non-linear reaction diffusion (TNRD) model is the most prevalent method to estimate and remove noises from the floating algae index (FAI) images that are derived from multispectral instruments (MSI). This novel approach extracts sargassum features automatically from the spatial patterns of these images and achieved 86% extraction accuracy when tested on the Landsat-8 and Sentinel-2 satellite datasets. The use of an extreme multikernel learning machine (MK-ELM) [64] has been proposed to classify received signal strength indicator (RSSI) images. A two-level feature extraction technique using the PCA method is used for measuring RSSI accurately.

## 6.6 ENCODER AND DECODER FRAMEWORKS FOR GENERATING IMAGE CAPTIONS

Due to the enormous progress in visual understanding techniques, the image captioning process plays a vital role in numerous applications. Image caption generation will automatically create captions for any given image and will bridge the existing large gap between the linguistic and visual domains. This enables the initial identification of the important features in an image, and then the extracted textures are finally mapped to create automatic annotations for the given image. The automatic captions can be easily generated using a natural language processing model, and many researchers are working on the same to optimize the model performance. Very recently, advanced deep learning techniques have been widely used for machine translation with natural language processing algorithms and feature extraction techniques for generating language. The encoder and decoder models are highly successful in the field of image-caption generation.

### 6.6.1 GENERATING CAPTIONS FOR NON-MEDICAL IMAGES

Several dialogue-recognition fully automatic captioning systems have been developed by researchers that will act as a solution in cases where doctors’ conversational speech usually includes lots of medical terms in different spontaneous styles that are not frequently used. Therefore, a novel greedy algorithm with language model (LM) is used along with a forward weight adjustment (FWA) technique, where weights are automatically estimated using a traditional expectation-maximization algorithm, and thus this improves the accuracy of caption generation substantially. Most of the novel techniques developed in recent years filter noisy detections and create syntactic trees to automatically generate natural image descriptions [35].

A template-based description generation model has been proposed [33]. This model is currently trained on visual representations and focuses on establishing connections between multiple objects in an image. By hypothesizing the dependency representation, image description can be improved. Computer vision algorithms are most predominantly used for recognizing and detecting images as proposed in [67], in which the terms that best describe an image are identified with the help of recognition algorithms. The generated final descriptions are remarkably accurate and in line with the image content. A novel visual dependency representation (VDR) model has been proposed [34], where different objects are identified using an object detector, and finally the detections (objects) are used to produce an automatic description for a new unseen image using a template-based description generation model.

A novel approach for automatic image description has been proposed [39] that includes using multiple learning instances to train the visual detectors, and the model has been tested with more than 4 lakhs of descriptions to automatically incarcerate the information about the usage of words. A novel method that integrates [115] huge high-level concepts into the encoder-decoder model has been proposed, which achieves a considerable enhancement in terms of both visual question answering and image captioning systems.

An encoder network based on GoogleNet model [110] that extracts image features successfully has been developed, and these extracted features will act as a first input to the language model, which is often called a language decoder model (LSTMLM), for automatically captioning the image description effectively. A deterministic forward attention mechanism [121] has been introduced that focuses on a minute segment of an expanse in an individual image instead of concentrating on an entire image as a whole as such, due to which the captioning system performance is increased to a larger extent. A natural language processing model that works based on a hybrid concept by combining a top-down as well as bottom-up approach was proposed by the authors in [127]. A semantic attention model is validated and experimented on two public benchmark datasets, the Flickr30K and Microsoft COCO datasets, which select only the semantic concepts and blend them in hidden states using both the top and bottom computation methodologies.

A double deep recurrent CNN has been implemented [31] which learns both time and space compositional representations. The proposed modern model, which belongs to the category of RNN, is very engaging; videos of various lengths are mapped to natural text outputs and it models the temporal dynamics efficiently using a back propagation technique.

A novel framework [124] has been introduced that assimilates the attributes of the encoder CNN model into the LSTM and helps the model to train in an end-to-end fashion. Image feature representations and word attributes are fed as an input into the RNN model in multiple different ways to explore the fuzzy correlation between them and they are tested on the COCO image captioning dataset. A novel visual captioning model has been proposed [15], which can select visual content based on linguistic knowledge. A visual gate, a key control unit, decides the word generation process. All preceding outputs of the language generator are fed into a latent space to derive the sentence structures, which assist the visual gate in choosing the appropriate attention timing. The current work is evaluated using the MSCOCO and the MSVD benchmark datasets.

One innovative method similar to [115] to automatically produce very simple and genuine caption statements for diabetic patients has been proposed. The current work is based on a generative model that uses both CNN and LSTM networks for enhancing the likelihood of caption generation at the target domain.
