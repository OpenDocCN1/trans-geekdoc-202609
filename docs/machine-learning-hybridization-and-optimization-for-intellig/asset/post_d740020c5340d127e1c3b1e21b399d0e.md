### 11.3.3 GENERATING FEATURES WITH GABOR FILTERS

There are a variety of ways to extract features using Gabor filters. The Gabor filter is an image-processing filter for detecting edges, classifying textures, extracting features, and estimating disparity. A band-pass filter enables frequencies in one band to pass while attenuating those in another. A Gabor filter is a Gaussian filter with a plane wave modulation. Gabor filter banks are employed in the classification of features. The real parts of various Gabor filter kernels are used to filter features from OPL images. A classification based on the least squared error is then generated based on the mean and variance of the filtered images. There are several Gabor filters of different parameters that are put together to make up a Gabor filter bank. The parameters lambda, theta, sigma, pi, and gamma must be modified to define Gabor filters. When the Gabor parameters are changed, an image can be used to extract a variety of low-level features. Equations (1) and (2) describe convolution kernels as follows:
