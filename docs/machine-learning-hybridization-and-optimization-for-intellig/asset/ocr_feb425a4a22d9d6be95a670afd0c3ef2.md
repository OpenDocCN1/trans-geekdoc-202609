Distributed scheduling techniques employ a few algorithms such as game theory, federated learning, matching theory, and blockchain auction. As per [6, 7], the batch mode heuristics algorithm (BMHA), online mode heuristics algorithm (OMHA), and dependency mode heuristics algorithm (DMHA) are cloud and edge scheduling algorithms. When tasks appear in a system, the BMHA creates a queue and collects them into a set, and the program begins after a certain amount of time. Some examples are first-come-first-served (FCFC), round robin (RR), shortest job first scheduling (SJF), minimum–minimum (Min–Min), and maximum–minimum (Max–Min). The jobs or resources are processed in the OMHA when they arrive at the system. Online mode heuristic algorithms play a critical role in dynamic and real-time decision-making scenarios across various domains, from machine learning and pathfinding to resource allocation and inventory management. Some of these are most fit task scheduling, dependency mode heuristic algorithm, genetic algorithm, multi objective genetic algorithm (MOGA), and online routing and traffic management algorithms.
