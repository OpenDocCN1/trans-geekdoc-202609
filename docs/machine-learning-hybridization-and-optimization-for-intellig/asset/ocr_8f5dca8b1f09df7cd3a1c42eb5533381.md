# 3.1.1 WHY ML/AI IN COVID-19?

If we need to understand why ML algorithms are being used for COVID-19, we need to first understand how useful they can be for helping in predicting COVID-19's various factors so that we can stop another pandemic like this if it occurs again. For COVID-19, some of the approaches which involved machine learning algorithms were

+   i. Identifying who has a high potential risk of getting infected;
+   ii. Diagnosing affected patients;
+   iii. Faster development of drugs/medicines;
+   iv. Predicting the spread of the disease across the globe;
+   v. Understanding the complexity of virus;
+   vi. Understanding the source of virus origin and their mapping;
+   vii. Predicting the next pandemic (second/third wave).

As you can see, we have enlisted many possibilities in which ML algorithms can be used to help in the identification of viruses, prediction of pandemics, isolation, and methods to eradicate the virus, although the study is at an early stage for a new problem like COVID-19, bringing in the concept of ML and its subfields can push forward research by leaps and can help to provide a faster solution to this new problem. In the above factors mentioned, each factor alone would not provide much help to research, but a combination of them would help in providing a faster solution to new problems. In the upcoming sections, this chapter will look into how a few ML algorithms that have been used have helped provide insights into the problem of the COVID-19 pandemic and how we can use the features to take precautionary measures.
