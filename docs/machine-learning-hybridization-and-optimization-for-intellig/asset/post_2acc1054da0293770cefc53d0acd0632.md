Using depth images, as described in Gangrade, the ISL digits found in [19] were calculated, causing the hand gesture to appear as a white region surrounded by a dark background. This reduces the amount of information that can be gathered about the sign-specific hand features for the ORB. The algorithm is used to identify crucial data points. The proposed method, on the other hand, eliminates depth images in favor of hand coordinates, which provide a more precise location of the hand region as well as convolutional features on the original image and the edge image, so that both the ensemble classifiers and the hybrid artificial neural network are capable of learning hand outlines. These various characteristics facilitate a more distinct distinction between each digit. Due to the fact that the NUS I dataset had low levels of segregation between the various classes and the NUS II dataset has extremely complicated backgrounds, it is abundantly clear that the NUS II dataset is of a complex type. Hand coordinates are the most effective characteristic for categorizing images within them, as they represent the location of hand regions in 3D space. In addition, the application of a CNN is preferable to ORB in this scenario, as described by J. Gangrade [19], because, with the aid of convolutional filters, a CNN can identify both the low-level and high-level features required for distinguishing labels of such complex datasets, whereas a representative ORB keypoint of the same features can be the same for multiple classes. It also drew attention to the fact that, in the context of the ASL fingerspelling dataset, hand coordinates are capable of transcending the convolutional characteristics of a PCANet model, as specified by W. Aly et al. [20], in order to test leave-one-out despite their imprecision. This is because, despite the fact that each user is unique, hand coordinates, also known as the relative distance between the hand joints for a given sign, are not constant across all users. In contrast to the case of W. Aly et al. [20], a portion of this information is missing because PCA is used within the PCANet model to select the appropriate convolutional filters. In addition, according to W. Aly et al. [20], the PCANet appears to generate more features than the total number of instances in the dataset. Because of this, the SVM is unable to progress because it becomes stuck in a specific hyperplane that could have provided a more accurate separation of image classes. Ensemble classifiers and ANN are not affected in any way by this issue. The application of a convolutional related feature renders the background of gestures in [21] completely transparent. Compared to a CNN with softmax classification, as described by K.M. Sagayam, the precision of CNN features on hand edges combined with an ensemble classifier such as XGBoost is greater. This is because ensembles, by definition, enhance predictive performance by reducing variance in the predictive process by employing multiple classifiers, each of which introduces bias. In contrast, the capabilities of a singular CNN are limited by its architecture in order to achieve only a limited degree of precision using epochs. Second, the use of hand coordinates helps pinpoint the precise locations of the hand gesture’s regions of interest, resulting in enhanced mapping. Adjustment of the hyperparameters can be done to attain the exact same properties. Moreover, it is evident that the hybrid ANN performs significantly better than CNN because it takes into consideration both the actual image information and information about the edges of the gestures when classifying the sign images. It is evident from Table 1 that each dataset is distinct by its very nature and that all the results follow a similar trend of increasing precision toward 100. For the modified dataset, the proposed work is able to obtain an acceptable level of accuracy with a reduction of 35.47% compared to the original dataset. This is because new features with histogram-equalized features were introduced, requiring a few more similar training examples. More comprehensive training with hyper-tuning enhances the performance of the proposed model.
