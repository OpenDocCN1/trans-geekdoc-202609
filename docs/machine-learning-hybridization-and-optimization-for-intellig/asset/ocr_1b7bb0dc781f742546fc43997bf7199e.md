# 11.3.4 Canny Edge Detection

Canny edge detectors generally take grayscale images as input and output images indicating where intensity discontinuities (edges) occur. By using Gaussian convolutions, a Canny edge detector smooths and removes noise from input images. To highlight regions with high first spatial derivatives, the smoothed image is subjected to a first derivative operator. As a result of calculating both the x- and y-derivatives of the gradient, the algorithm can figure out the direction as well as the magnitude of the gradient. Then, non-maximal suppression is applied, in which pixels not on ridge tops are set to zero, resulting in a thin line if any pixels are not on ridge tops. Then it is checked whether neighboring points in both positive and negative gradient directions have the same gradient as the previous step to ensure that the gradient calculated in the previous step is the maximum. The gradient is considered to be part of the edge if it is the greatest, and vice versa. The tracking process described above is governed by two thresholds, t1 and t2, such that t1 > t2, a phenomenon known as hysteresis threshold. Tracking begins at a higher point on the ridge than t1 and proceeds in both directions until the height of the ridge is less than t2. So, basically, it is necessary to select all edge points that are greater than the upper threshold t1 and then search for neighbors of these points that are less than the upper threshold t1 but greater than the lower threshold t2. Such neighbors would form part of the edge in this case.
