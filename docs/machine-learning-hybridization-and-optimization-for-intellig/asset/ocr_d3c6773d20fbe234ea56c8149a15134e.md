# 6.4.2 TRANSFER LEARNING FRAMEWORKS FOR HANDLING NON-MEDICAL DATASETS

In very recent times, several transfer learning concepts for classifying target models have been introduced and have been successfully used in numerous applications that are dealing with both an online target domain and heterogeneous source domains. A novel framework [43] has been proposed that includes auto encoders, where multiple source domains are used for learning and then knowledge is transferred to the target domain. The feature mapping is created from the original instances of all source domains to a hidden representation of the target domain and subsequently tested on well-known real-world text and image datasets.

Two novel online transfer learning paradigms, one for uniform and homogeneous consistent transfer learning and the other for different heterogeneous learning, have been designed and proposed [92], where the weights are adjusted automatically or dynamically for the initial source model. Then the target model classification performance will be enhanced using multiple source domains; most importantly here, the target data were received online. A new and innovative technique based on online heterogeneous transfer (OHT) learning has been proposed [129], which exploits both online knowledge and offline knowledge of different domains. An offline decision function is built and a hedge weighing strategy is employed for different feature spaces.
