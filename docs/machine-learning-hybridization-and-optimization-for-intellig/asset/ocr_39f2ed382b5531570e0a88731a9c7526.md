This layer enables wireless connectivity to connect smart devices using Radio Access Technology (RAT), Wi-Fi, short-range communication, and other technologies. In this layer, the data is received, processed, and forwarded from the device layer. In the cloud layer, all the infrastructure related to CC, such as storage, data centers, and others, are connected to the edge layer through a central network. Among the three-tier model, the key roles of the cloud layer are computation intensive, storage center, data aggregation and analytics, backup and recovery, scalability and flexibility, and centralized management. While the edge and fog layers focus on low-latency processing and immediate data handling, the cloud layer is the powerhouse for intensive computations and extensive storage supporting the overall infrastructure with its scalability and robust capabilities. In some cases, the advantages of edge computing can be leveraged to offload computing services from the cloud to the edge to improve users’ QoE.

In this section the configuration of cloud versus edge computing is described. It is noticed that an edge server is placed between the handled device and the cloud. As a result, the latency is low in edge computing configuration. CC is a model for providing timely, on-request access to divide infrastructure and allow the user to access resources as a service via a network instead of procuring and operating infrastructure and software. Edge computing is a model where the network and computational abilities are brought closer to the data sources, such as computers, smart devices, mobile phones, and routers that connect to the network. The computation time in CC is longer than that in EC. In EC, the computation process happens on the smart devices (IoT) near the client’s location. In CC, the computational process occurs in the data center. EC provides a shorter computation time and reduces waiting time, which ensures the quality of service to the user.
