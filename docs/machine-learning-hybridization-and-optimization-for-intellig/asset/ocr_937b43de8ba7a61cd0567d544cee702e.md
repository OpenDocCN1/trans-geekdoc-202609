# 9.2.5 FEATURE EXTRACTION

The resultant data of the NLMS filter is a noise-free ECG with all the required information. The noise-free ECG data is always recommended for extracting features, as it plays a major role in the classification of abnormalities. It is the most important stage prior to classification.
