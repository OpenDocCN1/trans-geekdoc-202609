Figure 17.2 shows the snapshots of a sequence of events in the game. Figure 17.2 (a) shows the main menu of the game, which allows the user to start a new game or quit. Multiple techniques were used for maximising game performance. The C# code was thoroughly examined and unnecessary components excluded. Unity Profiler was used to assess the performance of the game while making necessary changes to the code. Unity Profiler is an in-built tool in Unity that lets developers get an overview of the game in terms of CPU usage, GPU usage, rendering, audio, and more. Dynamic batching was enabled to reduce overhead from GPU rendering.
