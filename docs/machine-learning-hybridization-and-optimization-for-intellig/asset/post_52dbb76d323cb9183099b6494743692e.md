

## 7.2 THE ROOT OF CLOUD SECURITY

Along with being closely related to network security, database security, web security, and so on, cloud security is sometimes referred to as cloud computing security. IT security [6, 7] is also relatively closely related to it. Cloud security is significant in the context of ensuring the information and material in the cloud environments are safe and secure. Security is also required in all cloud computing platforms and modes.

The shared responsibility concept that serves as the foundation for most cloud computing systems is where cloud security has its origins. According to this approach, the cloud provider is in charge of the physical security of data centers, networking, and storage as well as the security of the underlying cloud architecture. The cloud client, however, is in charge of protecting data and applications in the cloud. Because of this shared responsibility paradigm, businesses are required to actively participate in protecting their cloud-based data and apps. This entails putting in place the proper access controls and authentication procedures, utilizing robust encryption to safeguard data both in transit and at rest, and keeping an eye out for any irregularities or vulnerabilities in cloud computing platforms.

The virtualization of IT infrastructure, which includes software, hardware, networks, online systems, and so on, is known as cloud computing. The following models may be used to access, design, and develop this.

**Public cloud computing:** This entails implementing the right technologies while virtually constructing and maintaining IT systems from remote places. When a third-party cloud service provider makes computer resources and services available online, this is known as public cloud computing. In a public cloud environment, multiple clients or businesses can share the same infrastructure, which is owned and controlled by the cloud service provider. Public cloud computing frequently offers a variety of services, including infrastructure-as-a-service (IaaS), platform-as-a-service (PaaS), and software-as-a-service (SaaS). With IaaS, the customer is in charge of managing and maintaining the operating system, middleware, and applications while the cloud service provider provides the supporting infrastructure, including servers, storage, and networking. Scalability and flexibility are two key advantages of public cloud computing, as consumers may rapidly and easily add extra resources as needed to meet shifting demands. Additionally, pay-as-you-go pricing is frequently available with public cloud computing, which can lower expenses and boost operational effectiveness.

Public cloud computing may also present a number of difficulties and risks, such as issues with data security and privacy, vendor lock-in, and the potential for service interruptions or downtime. Adopting suitable security and risk management methods is crucial to overcoming these obstacles. These tactics should include putting in place tight access controls, encryption, and routine monitoring and evaluation of cloud-based services.

**Private cloud computing:** This involves the planning and creation of one's own cloud-based infrastructure within one's own country. A private cloud environment is one that is exclusively used by one company and is often hosted on-site or by a different cloud service provider. In contrast to public cloud computing, private cloud computing offers more control and security because the infrastructure, apps, and services are created and managed exclusively for the enterprise. In terms of scalability, flexibility, and cost effectiveness, private cloud computing has many of the same advantages as public cloud computing. Private cloud computing, however, also provides other advantages, including improved security and more control over data and apps. In a private cloud setting, the firm has complete control over the infrastructure and can tailor and enhance it to suit certain business requirements. Private cloud computing can be implemented in a number of different ways, such as by utilizing the organization's own data center's specialized infrastructure or by engaging a third-party cloud provider to host and operate the environment. In a hybrid cloud context, private cloud computing can also be employed alongside public cloud services to increase flexibility and scalability while preserving the privacy and control of the private cloud. The expense of constructing and maintaining the infrastructure, as well as the requirement for qualified IT professionals to manage the environment, is one of the major issues with private cloud computing.

**Hybrid cloud computing:** This combines both types of cloud computing, that is, public and private, and uses them as needed. A hybrid cloud computing system mixes public and private cloud computing services, enabling businesses to profit from both while minimizing some of the risks and difficulties involved in each. When using public cloud services for less sensitive or less important applications or workloads, an enterprise often maintains a private cloud infrastructure for sensitive or vital applications and data. Normally, a secure network connects the two environments, enabling data and application mobility between the two domains. Flexibility and scalability are two key advantages of hybrid cloud computing, enabling businesses to swiftly and effectively add extra resources as needed to meet fluctuating demand. Hybrid cloud computing enables enterprises to choose to use public cloud services for less important workloads or during times of high demand, while keeping the security and control of private cloud services for important applications and data. This allows organizations to reduce expenses. The need to manage and maintain both the public and private cloud environments, as well as the requirement to provide safe connectivity between the two environments, are just a few of the difficulties that hybrid cloud computing poses. Strong access restrictions, encryption, and routine monitoring and assessment of both the public and the private cloud environments are just a few of the techniques that enterprises must apply to solve these difficulties.

## 7.3 TECHNOLOGY USED IN VIRTUALIZATION

A computer is divided into several logical computers via virtualization [10], each of which is able to run a separate operating system. Additionally, the apps can run independently of each other in isolated spaces, significantly improving the computer’s potential to carry out its responsibilities. Virtual machine monitor (VMM), a middle-layer software that runs between the physical server and the virtual machines, is a crucial utility for virtualization. It has access to the server’s complete physical hardware, such as the processor, RAM, disk, and network card. Alongside coordinating access to these hardware assets, the VMM also gives protection for virtual machines [11]. When the server first starts up and executes the VMM, it loads all of the virtual machine client operating systems (OSs) and allocates enough storage, CPU (Central Processing Unit). It runs the operating system and applications, constantly receiving input from the user or active software programs, network, and disk for each virtual machine.
