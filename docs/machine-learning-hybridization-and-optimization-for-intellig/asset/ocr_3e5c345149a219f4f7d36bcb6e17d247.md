The final step in arrhythmia detection or classification is to choose the best classifier. Artificial neural network (ANN) is one such classifier that provides accurate predictions. Different types of arrhythmia classifiers are discussed in the literature [15, 16, 17]. A standard 12-lead ECG recording system and ANN-based classification technique can be implemented to identify the cardiac arrhythmia diseases discussed in the publication [18], and also to predict multiclass classification using a multilayer perceptron (MLP) model [19]. Neural networks are used to identify diseases [20]. The Levenberg–Marquardt back-propagation algorithm is utilized to train the network. The outcomes achieved are more efficient than the methods previously proposed. This study [21] investigates feature extraction parameters from ECG signals such as Poincaré plot, Lyapunov exponent, and spectral entropy. This research utilizes an artificial neural network to identify heart disease abnormalities. A novel method for input ECG signal classification and feature extraction is achieved by employing wavelet packet decomposition (WPD); the performance evaluation is done in reference to GA-BPNN and is discussed in the publication [22]. In journal [23], an automated approach is used for initial seed discovery, and the regressive learning-based neural network classifier (RLNNC) is discussed for heart disease classification. To enhance the patient output considerably in instances, the identification established from a large volume of data, particularly atrial fibrillation, myocardial infarction, cardiac arrhythmias, and electrophysiology, is discussed in [24, 25, 26, 27, 28] using a machine learning algorithm.
