impurity is a measure of heterogeneity in decision tree learning that derives from the concept of entropy in information theory. The Gini impurity index is then computed for each potential split of the data to determine the best split at each node, and the split with the least heterogeneity is chosen. The term random in RFs refers to the learning process's two major layers of randomness: To begin, RFs grow each individual decision tree using a bootstrapped sample of the original training dataset (i.e., a random sample with replacement). As a result, the training sets for the trees are (for the most part) distinct. This may appear strange at first, but it reduces tree correlation and improves prediction generalization significantly. The second random component is a random selection of the features (such as spectral bands) that are taken into account at each node. As a result, splits for various features of insulators are determined, making tree decoration easier. Many trees may produce different class labels for the same insulator data point. All trees in the RF vote to determine the final class assignment of each UAV image pixel.

# 11.3.9.2 Support Vector Machine

Classifying and predicting images can be done using SVMs, which are supervised learning algorithms. Basically, SVMs are designed to separate the classes as much as possible in the training data by using hyperplanes. The greatest margin is determined by finding the hyperplane with the greatest distance from the closest class data point. Once the hyperplane for the insulator features has been determined, new data can be classified according to which side it falls on. It is particularily beneficial to use SVMs when data consists of a large number of features or a distinct margin of separation. SVM classifiers automatically separate insulators. Data that can be separated linearly works very well with them. A linearly separable dataset is one that can be plotted in a graph and classified based on a straight line.
