Efficient machine learning methods like support vector classification (SVC), ensemble learning, K-Nearest Neighbors (KNN), and RF algorithm have been used for classifying COVID-19 disease effectively. An ML framework that utilizes the adversarial reverse mapping technique to explore task dependencies was introduced in [128]. An innovative approach [97] for analyzing anomalies in breast images using a fuzzy expert system has been introduced. One new novel application [37] has been introduced to automatically detect genetic diseases using a chromatic pupillometry device, especially in pediatric patients. This will especially support diagnosis and early detection of inherited retinal diseases particularly in pediatric subjects.

As seen in the literature, the handling of data is continually increasing in biomedicine research. However, more essential information like the cause of the disease and its real-time data are very limited or unavailable for several rare diseases. This lack of rare -disease chronological data poses a large challenge to statistical ML-based approaches.
