# 19.3 ML IN LATE YEARS

In 1985, Gerald DeJong introduced explanation-based learning, which brought historical training data to ML. This data is used to create rules based on training data and remove non-relevant data. This was also the time when exploratory data analysis (EDA) came into existence, and explanation-based learning became an integral part of ML.

Machine Learning Research Group (MLRG) was created by AT&T in 1985 as a research group for ML, which eventually evolved into NIPS, a leading conference on ML. This group tackled real-world problems and aimed to replace humans in tasks like recognizing digits, zip codes, and checking amounts.
