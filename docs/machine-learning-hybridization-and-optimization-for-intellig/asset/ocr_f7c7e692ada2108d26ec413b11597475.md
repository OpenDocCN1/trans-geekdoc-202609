# 10.8 CONCLUSION

This work presents the study of various machine learning classifiers in remote sensing image classification. The studied classifiers include maximum likelihood, Mahalanobis distance, minimum distance, neural networks, random forest, and support vector machine classifiers. The classifier performance is assessed in terms of overall accuracy and kappa value. In the literature, various works using these classifiers for remote sensing image classification are presented. The study area is identified, and multispectral remote sensing of the study area is used for the classification.
