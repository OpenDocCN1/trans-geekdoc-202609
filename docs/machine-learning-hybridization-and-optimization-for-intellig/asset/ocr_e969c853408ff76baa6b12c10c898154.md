Additionally, image processing and machine learning techniques were used to detect and categorize rice plant illnesses. SVM was utilized for classification, and K-means clustering was used to segment the damaged area of the rice leaves [22].

Authors Kussul et al. [23] published one of the earliest studies on crop categorization employing CNN classifiers to multisource, multi-temporal satellite images. The study used two CNNs—one 2D CNN for learning spatial features and one 1D CNN for learning spectral features—to classify crops, outperforming multilayer perceptron (MLP) and random forest (RF) classifiers with an overall classification accuracy of 94.6%.

Zhang et al. [24] used a patch-based deep learning CNN algorithm with a multi-temporal Landsat-like dataset, phenology data, and land-surface temperature to extract rice crops. The 2D CNN outperformed classic machine learning classifiers, support vector machines, and random forest, with an overall classification accuracy of 91.23% using multi-temporal spectral bands as input.

# 18.3.1 Basic Approach

The basic approach to detecting the plant disease based on the images is shown in Figure 18.2. The process of getting images of infected leaves is referred to as *image acquisition*. A machine learning model, as a preprocessing step, is used to characterize the disease based on the attributes from the input images. Several processes of image processing include image background removal, noise removal, image scaling, picture segmentation, and image feature extraction. Certain image databases contain low-resolution images; therefore, image scaling is not always essential. Machine learning assessment criteria including accuracy, precision, recall, and confusion matrix are used to assess the system.
