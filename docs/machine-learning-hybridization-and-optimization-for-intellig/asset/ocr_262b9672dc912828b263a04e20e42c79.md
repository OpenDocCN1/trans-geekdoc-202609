# 4.3.3 MOBILE APPLICATION

The mobile application module is responsible [1, 2] for providing a user interface for end-users to interact with the system. It allows the users to view the data collected by the sensors, set up alerts and notifications, and perform various actions based on the data. The mobile application also acts as a control center, where users can remotely control various devices based on the data collected by the sensors.
