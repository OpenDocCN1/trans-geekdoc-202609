A trainable non-linear reaction diffusion (TNRD) model is the most prevalent method to estimate and remove noises from the floating algae index (FAI) images that are derived from multispectral instruments (MSI). This novel approach extracts sargassum features automatically from the spatial patterns of these images and achieved 86% extraction accuracy when tested on the Landsat-8 and Sentinel-2 satellite datasets. The use of an extreme multikernel learning machine (MK-ELM) [64] has been proposed to classify received signal strength indicator (RSSI) images. A two-level feature extraction technique using the PCA method is used for measuring RSSI accurately.

# 6.6 ENCODER AND DECODER FRAMEWORKS FOR GENERATING IMAGE CAPTIONS

Due to the enormous progress in visual understanding techniques, the image captioning process plays a vital role in numerous applications. Image caption generation will automatically create captions for any given image and will bridge the existing large gap between the linguistic and visual domains. This enables the initial identification of the important features in an image, and then the extorted textures are finally mapped to create automatic annotations for the given image. The automatic captions can be easily generated using a natural language processing model, and many researchers are working on the same to optimize the model performance. Very recently, advanced deep learning techniques have been widely used for machine translation with natural language processing algorithms and feature extraction techniques for generating language. The encoder and decoder models are highly successful in the field of image-caption generation.
