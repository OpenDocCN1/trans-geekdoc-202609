# Glossary

# A

AI A computer science branch, focusing on the creation of intelligent machines that process data and take appropriate decisions by itself.
ACC It is the degree of closeness between a measurement and the true value.
AV The value is obtained by measuring the available data.
Alzheimer's disease A progressive neurodegenerative disorder that affects memory and cognitive functions, often occurring in older individuals.
Analytics – The discovery of insights in data.
Artificial intelligence – Developing intelligence machines and software that are capable of perceiving the environment and that take corresponding action when required and even learn from those actions.

# B

BAG It is an ensemble estimator that fits the base classifier on random subsets and aggregates the predictions to form a final prediction.
BCS A multinational cyber defense exercise.
BDA Examining vast datasets to obtain insights.
BC Collection of quantum benchmark circuit files.
Business intelligence (BI): Using data analysis tools and techniques to gain insights and make data-driven decisions in business.
Big data – Big data is an all-encompassing term for any collection of datasets so large or complex that it becomes difficult to process them using traditional data processing applications.

# C

CA It is the ration of the number of correct predictions to the total number of input samples.
