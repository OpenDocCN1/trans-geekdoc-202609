### 8.1 INTRODUCTION

IoT security is one of the best firewalls for the increase in devices that are connected to a network. Devices like laptops perform a wide variety of tasks, such as transmitting data to other devices. The purpose of IoT devices is to establish protocols to secure the devices while sharing information. As a result, IoT devices can develop recognizable and unique patterns for the behavior of those devices. These IoT devices utilize artificial intelligence and machine learning techniques to create distinctive and identifiable patterns for such devices. Once these patterns are established, IoT can establish a baseline between the devices and the network and monitor and detect attacks on the devices. After monitoring such attacks, devices can send alert notifications to the administrator through communication formats such as SMS or device notifications, and these steps are automated by the system [1]. Upon receiving the alert message from the system, the administrator can also receive a sequence of steps to secure the device from those breaches or attacks. Identifiable and unique patterns can be used to reallocate the devices to resume their tasks normally after securing the devices from the attacks. These patterns also serve a crucial function in establishing a firewall between the devices during information sharing or when attacks occur.

Nowadays, most real-time devices use IoT-based devices, as shown in Figure 8.1 which depicts the applications of IoT that we discuss in this chapter. In this chapter, we have selected some applications to illustrate IoT security and how they are used in defense systems, the finance sector, the banking sector, and home networks. IoT security is implemented in defense systems like drones and other devices to maintain secure data sharing. The finance sector relies on IoT systems to prevent cyberattacks. In the banking sector, IoT systems are used to secure transactions between accounts and protect account information. Home appliances such as refrigerators, CCTV cameras, and televisions can also benefit from IoT systems for enhanced security.

### 8.2 IOT LAYERS AND SECURITY BREACHES

An IoT system consists of three layers that protect devices from attacks: the application layer, the network layer, and the perception layer. The reason behind the implementation of these layers is the challenges that occur in the system. These layers can fulfill the IoT requirements that are required for security and privacy [7]. ### 8.2.1 APPLICATION LAYER

The application layer may observe devices or systems that connect with applications developed by the IoT. The applications of IoT include the home sector, health sector, defense sector, and finance sector, which are secured by an IoT system. These provide services to the application and to build security and protective firewalls between the application and the devices. Services provided by the application layer can vary from one application to another because it provides services based on data collected by the sensors. Some issues that cause changes in the applications are the following:

- An injection attack focuses on the scripting of the site; this attack allows the hacker to insert client-side script, which changes contents into the application, and original data is illegally used by the third person.
- A code attack can be applied to the software at any part of the system, and it hacks software to make changes in the working model to cause damage to the system.
- An increase in the usage of the software system and devices that are interconnected to each other, and transmission of data between devices may cause a disturbance in the network, which leads to a loss of data and raises security issues in applications. It is better to use different security protocols for different applications, which may prevent the attacks discussed above, and also to develop security software in case of cyberattacks that disable the connection between devices that store the data.

### 8.2.2 NETWORK LAYER

The network layer acts as an interface between the application layer and the perception layer, transmitting data that was collected from the physical layer through the sensors. This layer is solely responsible for connecting devices to the network. A high-security issue is associated with this layer because authentication details and data can be transmitted through this layer. Some of the attacks that happen in this region are the following:

- Denial-of-service (DoS) attacks prevent main users from using network resources and accessing devices. These attacks make accessing applications or devices more critical.
- A man-in-the-middle (MiTM) attack interrupts data that is being transmitted from the sender to the receiver. It acts like a tower between devices that transmit data and makes changes in data, wherein the actual data has been interrupted by the attackers. It causes serious online security issues that are reflected in the application layer also.
- Storage attacks interrupt data that is mainly stored in devices. This type of attack is also known as a cloud attack.
- An illegal attack takes control of both hardware and software to steal information from data storage devices and make the application unusable. Such attacks can be dealt with by enabling end-to-end encryption to safeguard data while transmitting it to other devices and also implementing key sensors to devices like locks to data storage, which prevents unauthorized access [13, 14]. The usage of encryption provides different keys to different users while sharing data with other devices.

### 8.2.3 Perception Layer

The perception layer, also known as the sensor layer, acts as a sense organ in the system, and there are different types of sensors attached to this layer that may sense or identify things and collect data from devices. The sensors are selected according to the application requirements. The information that is collected by the sensors, such as temperature identification, face scanning, and fingerprint scanning, is commonly used in devices. The main issue that arises in relation to the perception layer is when hackers replace the original sensor with a duplicate sensor of their own, through which they may hack the devices and collect data from them [11, 12]. Therefore, the main threat in the perception layer is to the sensors and can include the following:

- A sniffing attack is a real-time attack that mainly targets personal communication, such as phone calls, text messages, and conferences, which are hacked by the attackers. Data can be stolen by attackers at the time of transmitting data into the network. There may be a chance of giving acknowledgment by the hackers to the sender and receiver with their own access [16].
- A capture of node is one of the more dangerous attacks faced by the perception layer. The attacker may create a gateway in the form of a key node and thereby take control of the application or device. The key node created by attackers may cause insecurity in communication between sender and receiver.
- In fake node implementation, hackers implement a fake node in the system or device, which may stop the transmission of real data to the receiver, and they replace the real data with their own data.
