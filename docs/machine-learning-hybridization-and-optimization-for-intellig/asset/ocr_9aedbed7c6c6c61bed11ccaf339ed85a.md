# 17.4 CONCLUSION

This chapter is intended to build an interactive game that runs relatively smoothly and looks nicer than games developed with older engines and libraries such as OpenGL and DirectX. Due to the fact that these games are not compatible with any other operating system, we also aimed to make them cross-platform. Unity3D was used since it has these features built in and can produce much higher quality visuals on any platform. Our implementation, together with the referenced articles, proves how simple it is to create and release Unity-based 3D interactive games. Still, mobile devices cannot match the power of specialised gaming consoles or personal computers when it comes to running the most cutting-edge, graphically demanding 3D video games. Our testing showed that our game ran well on both desktop and mobile platforms, proving its true cross-platform nature. The games are of very high quality, using only a little amount of RAM (21% on average for the 2D space shooting game and 23% for the arcade game) and using up little to no storage space. The game can run smoothly and without lags or crashes because of the strong FPS.

# 17.5 FUTURE SCOPE

We used Unity’s unique capabilities, such as the Particle System and the Inspector window, to make our work better. We also covered how Unity3D’s built-in tools for generating visuals, object movement, loading assets and textures, and so on are very helpful for novice game developers. Since we were able to locate professional-grade materials in the Unity shop, development was simplified by using Unity itself. Our case for switching to a different game engine has been made since Unity’s many advantages have been well demonstrated. We are able to make additional attempts to enhance the performance and incorporate more features. The game can also be improved by employing three-dimensional graphics and more recent technologies for the creation of games. It has the potential to develop into a multiplayer game.
