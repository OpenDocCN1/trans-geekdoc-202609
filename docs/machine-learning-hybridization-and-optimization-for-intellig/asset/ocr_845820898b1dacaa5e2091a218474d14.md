This layer takes in one feature from the input image and later filters out the different features and makes a feature map. The pixel with the equivalent values is deducted by moving the filter over the entire image. The next layer, which is the MaxPool layer, shrinks the image size to decrease the computation time. The second set of the convolution layer and MaxPool layer, which is the hidden layer, consists of 64 units with the same kernel size and same activation function and is used for replacing the negative pixel values. After this, the model layer is flattened, and to prevent overfitting, a dropout of 25% is given.

For developing the digital whiteboard, the first step is to import Pygame and all of its dependencies. After customizing the window's dimensions, font, and title, the next action is triggered by a mouse click. When the mouse is moved in a circular motion, the cursor follows the path of the motion. This procedure is repeated until the mouse motion no longer works. Once the numeral is typed, a rectangle may be shown around it. The screen is calibrated to record the digit, and the X and Y coordinates are saved. The image is then adjusted in size and form so that it may be used by the model, and then it is provided to the model and stored for prediction. The rectangle is then given a text overlay of numbers in order to decipher the numeral put there. To close the window and erase the whiteboard, the key is pressed down. The “N” key clears the whiteboard, while the “Q” key closes the program. The final output neuron is a dense layer with 10 neurons for accommodating the digits 0–9, and the activation function for this is the SoftMax function. The maximum value from the output neurons is selected and used for the prediction of the digit.
