The classification is performed using each classifier, and performance analysis is carried out. The performance of the classifier shows that support vector machine provides the highest accuracy of 95.35% and Mahalanobis distance provides the lowest accuracy of 87.19% for the remote sensing image of the study area. These results help to choose the appropriate classifier to carry out the remote sensing image classification for any study area in the future to obtain better assessment results in terms of LULC class.
