# 11.2 RELATED WORKS

According to the author [3], image processing can be used to inspect electrical insulator surfaces under complex climate conditions remotely. Water, ice, and snow covered an insulator, allowing experiments to be conducted with recorded images. To detect snow, ice, and water droplets on insulator images, minimum-distance nearest-neighbor classifiers were applied.

This study [4] describes how aerial images are analyzed using the ED-Net encoder–decoder architecture to identify insulators intelligently and accurately. In the encoder path, the initial module and the CA bottleneck are proposed for extracting features from images and generating finer feature maps. The maximum receptive field is maintained by using global average pooling. For performing boundary optimization on the feature map generated by the encoder path, the decoder path includes the refinement boundary module and asymmetric convolution module. This module bridges the gap between high-level and low-level features by combining high-level and low-level features in the decoder path as presented in this chapter.
