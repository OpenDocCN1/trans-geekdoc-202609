Apurbala et al. [11] used piece-wise regression for the prediction of
upcoming cases, deaths, and recovery. The initial method of using simple
linear regression was providing huge error values because in various parts
of India the growth in the number of cases was exponential at certain
points, and henceforth, they used doubling time. Doubling time is the time
taken for the current period for the infections to double. Doubling time is
inversely proportional to the infection increase rate, because when the
doubling time is large, then the increase in cases has been linear until that
point, after which it doubles. The point in the graph where there was an
increase that had doubled its previous value was considered as a breakpoint;
with the help of breakpoints, piece-wise regression occurs. The chapters
find breakpoints based on the difference between the current and previous
points. Finally, with the help of piece-wise regression with linear
regression, they were able to produce accurate values matching those of real
data.

Muhammad et al. [12] used various supervised machine learning models
for the forecasting of cases in various countries and suggested the best
model out of them. The models used are decision trees, support vector
machines, the naive Bayes model, and logistic regression. On running
various models, it was discovered that the decision tree model provided the
best accuracy, the SVM model had the highest sensitivity, and naive Bayes
provided the highest specificity.
