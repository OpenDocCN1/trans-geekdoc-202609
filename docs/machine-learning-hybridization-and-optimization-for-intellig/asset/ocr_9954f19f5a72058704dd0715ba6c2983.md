# ## 15.5 FUTURE SCOPE

The goal of this project for the sign language recognition (SLR) system is to create a method for identifying the numbers 0–9 by creating our own dataset, although it is also possible to get the dataset from the Internet, such as the MNIST dataset or ASL dataset. One way that gesture recognition might prove its worth is by facilitating effective human–machine and human–human interactions for those who have trouble hearing or speaking. This work can be extended in the future to include the recognition of alphabets and other hand motions. Specifically, the image processing part of the system needs work so that it can convert spoken language into sign language and vice versa, allowing for bidirectional interaction. A similar ideology can be implemented and extended using the clustering [22, 23]. The scope of the upcoming work also provides several opportunities to increase precision. In the future, this can be incorporated into block chains if there are sufficient numbers of large datasets available.
