Robot path planning using unstructured, noisy, and big-sized data can be a challenging problem. To overcome this issue, there are various methods that can be applied. ## 12.4.9 ENVIRONMENTAL ANALYSIS OF PATH PLANNING PROBLEM

The environment for the robotic path planning problem is primarily categorized into two types based on geographical conditions, that is, static and dynamic. Both stationary and moving environments can be employed to resolve the path planning issue. In a stationary environment, obstructions do not move over time, the initial and target positions are constant, and the environment is unchanging [59]. Though in a varying environment, the location of the target and barriers may change throughout the activity of seeing. Path planning in dynamic contexts typically is due to the environment's unpredictability, which makes it more challenging than a static context. The methods must therefore adjust to any unprecedented event, such as the introduction of when the objective is consistently shifting or when there are additional impediments moving in the premeditated path. For the dynamic challenge, the path planning techniques used in static situations are inappropriate [60]. The shape of obstacles in robotic environments serves as a defining characteristic. There are two primary categories of environments. A structured environment is a map with barriers that are neatly positioned and have a structured shape. In this situation, the robot's movement path around obstacles can be easily specified by the robotic map [61]. For instance, barriers are shown as dots (for position alone) or circles rather than having the real shape of an obstacle. Environments with only rectangular impediments are assigned with various additional research studies. In certain methods, robot environments are discretized using grids and quad trees, and obstructions are roughly indicated by adjusting the blocks. A real robotic environment is typically semi- or unstructured, with obstacles that can be positioned at an angle and come in a variety of shapes and sizes. This path planning issue is therefore quite challenging in this scenario [62]. The algorithm must determine a viable and ideal path. For unorganized road transportation, real-time path planning for robot vehicles has been presented.
