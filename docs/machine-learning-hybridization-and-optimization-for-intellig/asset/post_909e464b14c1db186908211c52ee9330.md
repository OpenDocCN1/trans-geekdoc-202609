
## 10.3 BIG DATA IN REMOTE SENSING

The method of discovering an object’s or surface’s characteristics from a distance is called remote sensing (RS). RS data are measurements of the globe that are continuously collected via sensors in orbit, sensors in the air, and various other methods of data collection. Big data is an enormous collection of datasets whose volume and rate are at a level that is substantially above even the most potent technological breakthroughs, changing the way problems are addressed. Due to the likelihood that it may define what RS big data really is, remote sensing and earth sciences are also impacted. Some of the attributes and characteristics of RS big data that need to be managed include its enormous volume and rate, diversity, and complexity, especially its growing dimensionality [31].

As a result of recent developments in sensors and earth observation methods, we are currently at the beginning of the high-resolution observation period (EOS-4), as illustrated in Figure 10.2. Multi-spatial, multi-temporal RS data are currently being collected from multiple instruments by more than 200 on-orbit satellite sensors. These constant worldwide measurements can span the earth’s atmosphere, surface, and oceans [24].

## 10.4 IMAGE CLASSIFICATION

The classification process is used to identify different features of the earth’s surface, since they each have different remittance qualities and spectral reflectance. Each pixel in an image or the raw data from remotely sensed satellites is classified through the image classification process to be assigned to one of the LULC classes. The image classification procedure includes the following:

- 1. Classification procedures for design images: These are typically informational categories like urban, agricultural, and forest regions, among others. These gather ground data, ancillary data, and other information about the study area through field surveys.
- 2. Image enhancement, original image clustering, and radiometric, atmospheric, geometric, and topographic adjustments are all included in the image’s preprocessing.
- 3. Using representative regions of the image to develop training signatures or analyze the results of the initial clustering.
- 4. Running the image categorization algorithms.
- 5. Completing geometric rectification, filtering, and categorization decorating in post-processing.
- 6. Comparison of classification findings with field studies for accuracy evaluation.

To determine the outcomes, the accuracy of any categorization process must be quantitatively assessed. The term accuracy in RS data analysis refers to the degree of classification correctness. The term error in classification refers to a difference that has been noticed between the scenarios depicted in a thematic map of the real world. A region on a map is compared to reference data (ground truth) for the same area as part of the accuracy assessment. The reference statistics are assumed to be accurate. Test data and verify data are other names for the reference data. Without evaluating the classified image’s accuracy to determine how well the algorithm worked, image classification cannot be considered complete.

The overall classification accuracy (OCA) and the kappa statistics produced from the error matrix are the two most frequently used traditional accuracy metrics. The accuracy research also considers each class’s correctness, which is determined by combining the accuracy of the producer and the accuracy of the user. Additionally, statistical research is done for classes and layers. The mean and standard deviations are taken into consideration for statistical research. The information that is being classified is from the region around the Udupi district. Following classification, an error matrix is produced that provides information about the classification results.

Since qualitative (visual) analysis is unable to pinpoint the picture with the highest degree of classification accuracy, an accuracy evaluation must be done. The image processing program ERDAS IMAGINE v9.1 RS was used to evaluate accuracy. The evaluation of classification accuracy produced the overall classification accuracy and kappa statistics for each set of data using a number of points (validation points) on the image of the classified data. Both the overall classification accuracy and the kappa value change when the number of validation points used in the RS data for accuracy evaluation changes. For various classification algorithms, the usual values of OCA and kappa statistics are shown in Table 10.4.
