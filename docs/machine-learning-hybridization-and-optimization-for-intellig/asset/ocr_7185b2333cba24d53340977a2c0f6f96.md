# # 7.2 THE ROOT OF CLOUD SECURITY

Along with being closely related to network security, database security, web security, and so on, cloud security is sometimes referred to as cloud computing security. IT security [6, 7] is also relatively closely related to it. Cloud security is significant in the context of ensuring the information and material in the cloud environments are safe and secure. Security is also required in all cloud computing platforms and modes.

The shared responsibility concept that serves as the foundation for most cloud computing systems is where cloud security has its origins. According to this approach, the cloud provider is in charge of the physical security of data centers, networking, and storage as well as the security of the underlying cloud architecture. The cloud client, however, is in charge of protecting data and applications in the cloud. Because of this shared responsibility paradigm, businesses are required to actively participate in protecting their cloud-based data and apps. This entails putting in place the proper access controls and authentication procedures, utilizing robust encryption to safeguard data both in transit and at rest, and keeping an eye out for any irregularities or vulnerabilities in cloud computing platforms.

The virtualization of IT infrastructure, which includes software, hardware, networks, online systems, and so on, is known as cloud computing. The following models may be used to access, design, and develop this.

**Public cloud computing:** This entails implementing the right technologies while virtually constructing and maintaining IT systems from remote places. When a third-party cloud service provider makes computer resources and services available online, this is known as public cloud computing. In a public cloud environment, multiple clients or businesses can share the same infrastructure, which is owned and controlled by the cloud service provider. Public cloud computing frequently offers a variety of services, including infrastructure-as-a-service (IaaS), platform-as-a-service (PaaS), and software-as-a-service (SaaS). With IaaS, the customer is in charge of managing and maintaining the operating system, middleware, and applications while the cloud service provider provides the supporting infrastructure, including servers, storage, and networking.
