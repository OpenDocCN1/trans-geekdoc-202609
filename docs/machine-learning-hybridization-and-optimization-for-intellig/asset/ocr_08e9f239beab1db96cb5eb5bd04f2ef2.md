# 5.3 MATERIALS AND METHODS

As mentioned earlier in the proposed work, it’s essential to analyze the role of AI in other important domains, as it is more or less uniform across varied fields. Say, for instance, best practices from different domains, such as healthcare, can be adapted because accuracy is an uncompromised goal that is aimed to be achieved at a high level through AI in healthcare; the same means can be applied in the case of law. Say, for example, in the proposed work [22, 23, 24,41] in the medical domain, the transfer learning model is implemented. In the existing work [22, 23, 24, 41] the trained source domain knowledge, learned from plentiful datasets, is finally transferred to the very limited target domain task. In the existing work, a multilevel framework is introduced for the classification of digital breast tomosynthesis (DBT) datasets. The basic MLTL architecture proposed [22, 23, 24, 41] consists of three domains. The first source domain is trained on an easily available dataset. An intermediate domain is introduced to learn the source domain generalized features, and then the middle domain with its intrinsic specific features of medical images are accurately learned and in turn carried to the last target domain to give outstanding classification results with DBT datasets. Preprocessing of the dataset is done using an adaptive median filtering technique followed by a region-based segmentation method. An expectation maximization technique is used to estimate the model parameters.
