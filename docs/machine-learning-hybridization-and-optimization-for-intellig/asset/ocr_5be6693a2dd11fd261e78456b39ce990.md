Our work has been influenced by various factors, including noise, occlusions, changing lighting conditions, and shadows, It can be challenging to extract objects from images taken against complex backgrounds, particularly when using unmanned aerial vehicle (UAV) images. However, there are several techniques available, and the overall methodology proceeds as follows:

+   - The UAV images are initially preprocessed.
+   - Secondly, Gabor filter banks are applied to UAV images because they contain required information with pixel values that can be used to extract features from the images.
+   - Lastly, the classification algorithms RF [10], SVM [17], and XGBoost [11] are employed to calculate accuracy and forecast segmented classes from images.
