# 11.3.8 SCHARR OPERATOR

Scharr can also be used to find the horizontal and vertical second derivatives of OPL images. This method’s syntax is as follows:
Scharr (src, dst, ddepth, dx, dy) (src, dst, ddepth, dx, dy) (source, destination, depth, x, y)

+   The following parameters are accepted by this method:
+   Src – the source (input) image represented by a Mat object
+   dst – a Mat object representing the final (output) image
+   depth – an integer variable that represents the depth of the image (–1)
+   dx – an integer variable that represents the x-derivative (0 or 1)
+   dy – an integer variable that represents the y-derivative (0 or 1)
