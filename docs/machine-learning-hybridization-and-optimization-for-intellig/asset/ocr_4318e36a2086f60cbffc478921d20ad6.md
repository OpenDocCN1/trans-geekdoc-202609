As per [7, 17], the primary goal of scheduling algorithms in a cloud computing environment is to optimize resource utilization while managing the load between resources to achieve the shortest execution time possible. There are two types of scheduling algorithms: static and dynamic scheduling algorithms. The most critical activity in the cloud computing environment is scheduling. The most popular acceptable allocation mechanism policy for fair resource allocation is (weighted) max-min fairness, which maximizes the minimum resource allocation obtained by a user in a shared computing system. Along dimensions such as performance, availability, and reliability, QoS is defined as the minimum resource allocation obtained by a user in a shared computing system.
