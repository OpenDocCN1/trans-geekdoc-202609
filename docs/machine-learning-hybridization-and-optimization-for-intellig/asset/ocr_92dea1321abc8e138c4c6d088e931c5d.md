An efficient and very effective deep learning model for gesture classification and recognition has been proposed [107]. This gesture recognition is enhanced by learning only the necessary informative features based on large amounts of electromyography data, and thereby reducing the recording burden to a greater extent. The current transfer learning technique systematically improves the performance substantially when the model is trained on raw continuous wavelet transform (CWT), EMG, and spectrograms datasets, respectively.

An efficient deep learning–based coding method for low-rank cross-domain learning was introduced [133]. The current low-rank coding model is multilayer in nature and deployed at the top layers that are very specific to the task, and some general features are shared to resolve the domain inconsistency problem so that enriched knowledge is shared across the domains that are invariant in a layer-by-layer fashion. The proposed framework preserves the global large-scale structures that are familiar among the target as well as the source domains, and an identical one with similar samples which are frequent in both domains are combined for positive and effective knowledge transfer. In addition to this, several domain adaptation techniques are combined and integrated for effective optimization of coding using a semi-supervised learning method. Furthermore, marginal and conditional disparity problems across all the domains are alleviated. Several other successful works [76, 78, 104, 117, and 135] can also be implemented for the medical domain.

The distinctive characteristics of both domains are effectively managed through the utilization of partial transfer learning and feature extraction methods, as proposed in [114], where only a portion of the source model is employed in the target model. This model uses a multitask approach to fine-tune the network and was finally tested on in situ hybridization (ISH) labeled images.
