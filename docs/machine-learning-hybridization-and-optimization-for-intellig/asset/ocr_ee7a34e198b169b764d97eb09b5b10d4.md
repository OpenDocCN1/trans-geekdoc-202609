# 7.8 CONCLUSION

The availability and adaptability of hardware resources are both increased and administrative costs are significantly decreased thanks to virtualization. Virtualization serves as the foundation of cloud computing technology. The numerous advantages of virtualization technology include better hardware usage and lower administrative expenses, but it also brings about fresh security threats that must be carefully controlled, especially in the context of cloud computing. The potential for a hypervisor-level attack, in which an attacker gains access to the hypervisor layer and is able to manage or modify several virtual machines running on the same host, is one of the main security dangers connected to virtualization. In addition to the possibility of service interruptions and downtime, this may lead to illegal access to important data and systems. The rapid and widespread usage of cloud computing has been hampered by security issues. Analyzing the key security concerns provided by virtualization technology is crucial in order to enhance the security measures of virtualization.
