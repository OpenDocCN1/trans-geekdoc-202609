# 18.3.3 FEATURE SELECTION

To choose a subset of features for model construction, feature selection is used. The model can be simplified, training time is reduced, the curse of dimensionality is avoided, and overfitting is decreased. These are the main reasons why feature selection should be done. The fundamental premise underpinning feature selection is that a feature set may include duplicate and unnecessary features. Redundant and irrelevent are two different concepts since one useful feature could become redundant if another connected feature is present.
