## 17.1.1 Unity3D

Unity3D is a game engine and game development suite used for creating 3D, 2D, virtual reality, and augmented reality games and experiences. It is available for free and can be used on macOS, Windows, Linux, and mobile platforms. It is highly accessible and straightforward to learn, with a wide range of tools available to help developers create stunning visuals and immersive experiences. Unity3D offers a comprehensive suite of features for game developers, allowing them to create anything from simple 2D games to complex 3D worlds. It has a large number of features, including a drag-and-drop interface, physics engine, animation system, integrated scripting language, and many more. As it includes a powerful scripting language, it allows developers to customise the engine to their specific needs for a project. With the engine’s built-in physics engine, developers can create realistic and immersive game worlds with stunning visuals, immersive experiences, and engaging games that can be played on almost any device. A new developer can quickly approach, script, and program the transition of the game object thanks to Unity3D’s graphical user interface (GUI). In addition to 3ds Max, Maya, Softimage, Blender, Modo, ZBrush, Cinema 4D, Cheetah3D, Adobe Photoshop, Adobe Fireworks, and Algorithmic Substance, Unity also supports their art assets and file formats. The GUI of Unity can be used to manage these assets and add them to the game project.

Mono, an open-source version of the .NET Framework, serves as the foundation for Unity’s scripting. An open-source IDE for Linux, macOS, and Windows is called Mono-Develop. Boo, C, C++, C#, CIL, D, F#, Java, Oxygene, Python, Vala, and VB.NET are all supported. The use of scripts allows games to react to user input and plan for gameplay events to occur at the appropriate times. Scripts can also be used to design graphics effects, manage how things behave physically, or even construct a unique AI system for the game’s characters. Windows, Mac, Linux/Steam OS, the Unity Web Player, Android, iOS, Blackberry 10, Windows Phone 8, Tizen, Windows Store apps, WebGL, PlayStation 3, PlayStation 4, PlayStation Vita, Wii U, Xbox One, Xbox 360, Android TV, Samsung Smart TV, Oculus Rift, and Gear VR are just a few of the platforms that Unity can be deployed on. Developers have control over how a project is delivered to consoles, desktop computers, mobile devices, and web browsers. For every platform the game is compatible with, Unity also enables specification of the texture compression and resolution parameters.

## 17.1.2 COMPARISON BETWEEN OPENGL, DIRECTX, AND UNITY3D

- (1) OpenGL: OpenGL is an open-source, cross-platform application programming interface (API) for rendering 2D and 3D vector graphics. It is designed to be hardware-independent and platform-agnostic, providing high-level access to graphics operations on a wide range of hardware. OpenGL provides a powerful set of features such as high-quality anti-aliasing and high-performance vertex and fragment shaders.

    Resolution: OpenGL is capable of rendering high-resolution images with a wide range of colour depths.

    Hardware utilisation: OpenGL is highly optimised to utilise modern graphics processing unit (GPU) hardware, allowing for smoother and faster graphics rendering.

    CPU performance: OpenGL does not require a dedicated graphics processor, making it ideal for low-end systems with low CPU power.

- (2) DirectX and Unity3D: DirectX and Unity3D are both Windows-based proprietary graphics APIs. DirectX is a collection of low-level APIs for rendering 2D and 3D graphics, while Unity3D is a game engine used to create 3D applications.

    Resolution: DirectX and Unity3D are capable of rendering high-resolution graphics with a wide range of colour depths.

    Hardware utilisation: DirectX and Unity3D allow smoother and faster graphics rendering.

    CPU performance: DirectX does not have any inherent performance impact on the CPU, as it is a set of APIs that are used by developers to create applications that can access the capabilities of a computer’s GPU. Therefore, the performance of a system with DirectX will depend on the performance of the GPU and the specific application.

    Unity3D is optimised for multicore CPUs and can make use of up to 8 cores for improved performance. Unity3D is also optimised for multithreaded operations and is capable of utilising up to 8 threads for better performance.

## 17.2 DESIGN OF 2D SPACE SHOOTER GAME

The majority of today’s most popular 2D games either have exceptionally high graphics or large file sizes and RAM requirements. Miniature games have worse visuals and gameplay since their file sizes are smaller. However, games with high-quality sprites require a lot of RAM, which can cause computers to overheat. One or the other must be severely degraded, and it is either the CPU’s speed or the game’s overall quality. Furthermore, systems with insufficient RAM would struggle to run games with high-quality visuals. If your machine does not have enough RAM, the game will operate poorly, with stuttering frames and other performance issues. It is possible that the game will not launch at all if you do not have enough RAM.
