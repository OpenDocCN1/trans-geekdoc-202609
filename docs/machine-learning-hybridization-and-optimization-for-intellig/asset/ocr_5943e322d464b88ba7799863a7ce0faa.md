# 9.3.1 PNN

The PNN type of neural network is primarily used in classification and pattern recognition problems. The architecture of the PNN has three layers: the input layer, the hidden layer, and the output layer, as shown in the Figure 9.6. The first layer of the PNN, the input layer, has N number of nodes through which all feature vectors are connected to the hidden layer. Each hidden node in the group belongs to a class k and corresponds to a Gaussian function in the kth class centered on its related feature vector. In a class group, this Gaussian function produces effective values for the k number of output nodes.
