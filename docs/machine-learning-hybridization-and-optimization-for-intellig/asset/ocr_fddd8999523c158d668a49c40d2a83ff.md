# 6.2 CAD METHODS AND MACHINE LEARNING TECHNIQUES FOR PROCESSING MEDICAL IMAGES

Recently the advancements in CADx and CADe technologies have made additional contributions to medical imaging. In very recent years, the usage of machine learning techniques in such CAD systems is continually growing. The described work [103] considers a valuable platform for the automated analysis of medical images. The proposed framework helps in the diagnosis of carotid artery problems using ultrasound images. The diagnosis includes segmenting the arterial wall automatically, selecting Regions of Interest (ROIs) plaque, estimating, and clustering of texture features and analysis of tissues in different image areas. A shape analysis strategy for solving various segmentation problems in a unified framework was introduced in [89], and has been tested on many clinical lung CT images.

The classification of lesions in 3D images using a CAD system is introduced in [106]. The proposed work automatically segments lesions using a spiral scanning technique, for which a seed point in combination with dynamic programming and a spiral scanning technique is deployed.
