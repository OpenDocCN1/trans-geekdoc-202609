Cloud computing (CC) is the deployment of computing and various resources centrally. These resources are due to the emergence of the Internet of Things (IoT), and massive amounts of data are generated at a significant rate.

Adequate processing infrastructure is required to help users trigger actions on predefined goals. With the real-time application and spread of IoT, the requests for data transfer and computing calls are realized using edge computing. The cloud provides pre-packaged services for IoT operators and has a prominent position as a centralized platform for deploying IoT solutions. Thus, cloud computing is an alternative to or sometimes complements traditional data centers. There is a computational infrastructure demand to move to the network edge that ideally stores the data and performs computation [1]. It has integrated cloud and edge computing to provide vertical and horizontal offloading techniques between the virtual machine server nodes. However, long latency presents a challenge and analysis of edge and cloud computing is necessary to reduce the problem. If the majority of the work is executed in cloud computing servers, considering the three-tier architecture, the jobs are completed after some delay. Thus extending the computation at the edge can offload some of the jobs from the cloud center. According to [2], the task delay time is reduced by using an extended short-term memory algorithm in a mobile–edge–cloud computing model. The offloading strategy from the cloud to the mobile device was based on task prediction. The authors claimed that this architecture and algorithm effectively reduced the delay caused by a growing number of tasks and subtasks.
