# ## 2.2.3 CENTRALIZED INFORMATION MERGING AND CENTRALIZED DECISION-MAKING (CIMCD)

In [9], the authors proposed an algorithm in which a central base station accounts for coupling the data and deciding the path for a group of homogeneous UAVs. In this case, each UAV collects some information during its flight. The UAVs are unfit for communicating the information with other UAVs or the ground station during their flight. After the robots reach the base station, the collected data is shared with the base station. The robots also receive information from the base station at this moment. Hence, the base station is responsible for merging the partial and delayed data from the various UAVs with the help of a consolidated hunt chart. The base station is also responsible for assigning new paths as per the K-shortest path algorithm [10]. This process is repeated again and again unless the query in the region to be explored has dropped below a certain level. In [11], Lum et al. use various robots with varied abilities to explore a particular terrain and search for the position of various fixed targets. It is assumed that there is perfect communication among the UAVs and the ground station during their flight. Hence, the complexity of information lagging is avoided. The base station combines the information from all the UAVs and stores it in a residency-grounded hunt chart. It generates immediate routes for all the robots which restrict them to different Voronoi partitions [12]. The system guarantees a total hunt of the terrain.
