## 16.3 DESIGN OF TURTLE SIDESTEP GAME

We propose a game called Turtle Sidestep. This is an NFT-based game that runs on the Polygon network of the Ethereum blockchain, powered by Chainlink's decentralized oracle. In order to dodge through the blocks, the turtle can move left or right using the arrow keys. The speed of the left and right movements of the turtle varies for each turtle NFT. The game is really fun to play, and it can get really challenging as the speed of the platforms increases with time. The player is rewarded with a new random turtle NFT every time a new checkpoint score is reached. The checkpoint score is at least 110 points higher than the player's previous high score. The higher the score achieved for a new checkpoint, the faster the NFT character the user receives as a reward. More speed allows the player to move faster through the platforms and reach high scores easily. Users would want to own NFTs with higher speed, and hence it acts as a selling point. The NFTs are dynamic. Every new turtle NFT has a unique name, a randomized image, and a random speed that ranges according to the score achieved by the user. The way we intend the random turtles to be generated is by using a custom API. The API will have four components: a head, a turtle shell, legs, and a tail. Every time a random turtle is called, using the chain link from the contract, the API is going to randomize the combination of these components and generate a new image and immediately put that image into NFT dot storage, which stores the files on Filecoin and InterPlanetary File System (IPFS). It also returns the IPFS hash to the contract. In the contract, whenever the chain link request is being fulfilled, it will set the token.
