A 2D picture segmentation algorithm based on K-means clustering, Gabor filters, and moving meshes is presented in this study. The mesh is adaptively concentrated in regions of high gradient, and the location feature is used in the clustering process. The image feature values are obtained using a convolution operation between the image and the Gabor filter. This approach has the advantage of being able to constantly add new features, such as location, pixel, or Gabor filter, to improve the segmentation result. The results show that these algorithms can rapidly segment and crack medical images without sacrificing quality [23, 24, 25].

The YOLO v7 model has been enhanced [26, 27] to improve detection results. K-means++ is used to cluster target boxes of the insulator dataset so that more appropriate anchor boxes can be generated in order to detect insulator defects. After that, the HorBlock and coordinate attention modules are added to the network. By weakening the ineffective features in the channel and spatial domains, the network can strengthen the effective features of the feature extraction process. For accelerating model convergence and resolving the imbalance between positive and negative samples, the SIoU and focal loss functions are used. A non-maximum suppression (NMS) method has also been improved to reduce accidental deletions and false detections of defect targets, thus improving the model's overall performance. Based on these experiments, it was found that the model was 7.6% more precise than the faster R-CNN model, 3.7% more precise than the YOLOv7 model, and 4% more precise than the YOLOv5s model. It is possible to detect small objects with high accuracy under complex background conditions using the proposed YOLOv7 model.
