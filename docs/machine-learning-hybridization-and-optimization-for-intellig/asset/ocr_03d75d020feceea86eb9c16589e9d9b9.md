# 12.4.5 Fuzzy Logic

Mobile robots are frequently controlled via fuzzy logic (FL). When a perfect solution cannot be foreseen, fuzzy logic provides a potential solution and is used to address pattern matching issues. Fuzzy logic copes with neither totally true nor completely incorrect statements and robot tasks that are more durable [44]. The inherent human language is translated by the fuzzy logic into machine comprehension of control principles. Here, a mobile robot’s control functions are shown and can be carried out in accordance with the rules whenever going from one place to another and descending when the experts in the environment lose information. The application of fuzzy logic in mobile robots is to follow a visual item by displaying a color in a certain location using a sensor [45].
