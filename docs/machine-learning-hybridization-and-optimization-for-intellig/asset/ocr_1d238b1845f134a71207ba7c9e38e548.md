One innovative approach [100] has been introduced for detecting rare diseases using facial images that are in 2D. The model is trained on 12 diverse classes with 1,772 facial images and the results are outperforming several other state-of-the-art methods. An automatic detection method [98] for identifying neo-vascularization syndrome (NVD) in the retinal image of the optic disc region was introduced. This machine learning–based approach involves feature extraction along with Gabor filtering and feature selection techniques for segmenting vessels and detecting NVD using an SVM classifier. Of the 424 retinal images, 42 features are extracted as essential ones from NVD images, 134 are classified as NVD, and 290 are classified as non-NVD images.

An efficient clustering-based approach is developed in [122] for reconstructing images with 3D low-dose CT images. The image patches are retrieved from a pool of CT images. The proposed CT rebuilding step is completed by using a Lagrangian approach with a minimum number of forward and backward projections in images, and it substantially optimized the quality of the reconstructed CT image by using an edge-preserving regularizer that is non-adaptive in nature.

The proposed machine learning technique [125] to detect lung lesions is an innovative approach using low-dose PET images. An image quality transfer (IQT) technique will enhance the information content or its resolution using a patch-regression method that will transform the map parameters from low-quality to high-quality images. Thus, IQT helps in improving image quality to detect lesions from low-dose images. The technique [111] for classifying Parkinson's syndrome was introduced. Several machine learning algorithms like ensemble based machine learning algorithms, genetic algorithms, and extreme ML algorithms [79,87] have been used effectively for detecting malignancy in breast images.
