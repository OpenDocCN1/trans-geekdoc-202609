# 7.7.1 Hypervisor Security Policy

The current generation of widely used virtualization technologies, such as Xen, VMware, and KVM [18], all include security weaknesses that could jeopardize the hypervisor’s integrity and security measures. A virtualization platform must be protected, and that protection starts with the hypervisor. Building a lightweight hypervisor, preserving the integrity of a hypervisor using trusted computing technology, and bolstering the hypervisor’s defenses by configuring a virtual firewall and sparingly allocating host resources are currently the three main steps in hardening the security of a hypervisor.
