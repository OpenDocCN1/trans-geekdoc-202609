As discussed earlier in Section 9.2.5, various algorithms are used to extract features from the ECG signal. Table 9.5 depicts the list of feature extraction methods used in the literature. Based on this comparison, it is convenient to select the best method depending on the dataset, network architecture, nature of the input signal, and so on.

| 5. | WPD [43] | • Good for nonstationary signals | • High computation time |
| 6. | FFT [44] | • Frequency domain analysis | • Only for stationary signals<br>• Greater sensitivity to noise<br>• Poor time localization |
