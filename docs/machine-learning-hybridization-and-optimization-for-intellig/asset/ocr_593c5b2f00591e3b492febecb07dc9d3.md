# 7.6.4 Denial of Service Attack

A denial of service (DoS) attack is a form of cyberattack that tries to stop a system or network from functioning normally by flooding it with traffic or requests. Using resources like CPU, memory, or bandwidth, a DoS attack aims to block legitimate users from using the targeted system or network. These attacks try to overwhelm a target system with so much traffic that it uses up all of its bandwidth or resources. ICMP floods, DNS amplification assaults, and UDP floods are a few examples of volume-based attacks. These attacks drain system resources by taking advantage of flaws in network protocols like TCP/IP [24]. SYN floods, Ping of Death attacks, and Smurf attacks are a few examples of protocol-based attacks. Resources are shared by physical and virtual machines [24]. The assets of the other virtual machines will be impacted or even crashed because they do not have any assets, even if an attacker takes control of one virtual machine and has access to all host computer resources. Denial of service in a virtual environment would be what this is [25].

# 7.6.5 Issue with the Virtual Machine Monitor

The key component of virtualization is the virtual machine monitor (VMM), which generates or manages virtual resources and also manages and isolates virtual machines. If the virtual machine monitor is hacked, the attacker will have access to the virtual machine metadata maintained by the virtual machines and will be able to control all the virtual machine instances it maintains [26]. Attackers may use VMM flaws to compromise the host system, access information or resources on other virtual machines, or take over the virtual environment. Security flaws brought on by improperly configured VMM settings may include providing unauthorized access to virtual machines or disclosing sensitive information. Unauthorized users may be able to access or alter virtual machines or resources in the virtual environment due to lax or ineffective access controls.
