## 11.5 CONCLUSION

A method for segmenting OPL components using Gabor filter banks and MLA is presented. This chapter is designed for extracting features via Gabor filter banks. The method works with blurred UAV images with varying lighting angles. Gabor filters are used in conjunction with SVM, RF, and XGBoost. According to the tabled results, XGBoost achieves a high accuracy of 95.12% in predicting images, with a processing time of 2 seconds. In the future, 3D or video surveillance images will be used for image segmentation using instance segmentation techniques.
