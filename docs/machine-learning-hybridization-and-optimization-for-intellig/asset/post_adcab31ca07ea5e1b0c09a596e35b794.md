## 13 Pneumonia Prediction Model Using Deep Learning on Docker

Yash Seth, Philip Anand, Jinen Rathore, R Gayathri, and Shola Usharani

DOI: 10.1201/9781003465775-13

### 13.1 INTRODUCTION

For the deep learning model, we are applying the VGG16 model. VGG16 is a CNN or convolutional neural network that is 16 layers deep. While these 16 layers are predefined, we may remove layers and add in our own layers to change how data is fed to the model and passed from one layer to another. For creating the model, we removed the original 16th layer and added our own layer to give output in two categories: normal and pneumonia. We also preprocessed the images by rotating, zooming, and making them black and white and then fed them into the model for training. This was a trial and error-based approach, so as to maximize the accuracy of the model. To distribute the model and make it highly available to those who require it, our model is accessible through Docker. Docker is a platform that is commonly used to create, package, and deliver applications that run over the cloud. It speeds up and simplifies the process of creating reproducible and shareable systems. It provides a system to manage your infrastructure in the same way you would do your apps and products.

We have created a Docker image which contains the model file and the UI for easy access to the model. After putting up the Docker image online, anyone who wishes to use the model may pull the Docker image, create a container, and thereby use it for their requirement. We have also created an easy-to-use UI website on a FastAPI server, which allows the user to select an image from their system’s file system, and then the image would be fed to the model, and the output would be displayed on the same UI website.

Therefore, the complete flow of the proposed system is as follows. The user will first need to obtain images of the lungs that they want to check are normal or have pneumonia. Next, they will be required to pull the image of our system from the Docker repository, which they will run in a Docker container. The Docker container will install all the requirements of our system locally in an independent environment and then launch the UI, which is connected to the model in the backend. The UI prompts the user to upload the lung images, and it would then be fed to the backend, where the model takes in the input and classifies it as either normal or pneumonia. This output is passed to the frontend and displayed to the user, where they can relay their findings to wherever it is required.

Thus, by putting together all the modules, we have come up with an easy-to-use yet reliable solution for pneumonia detection. The proposed model is highly available, reproducible, and fairly lightweight. Our vision for the system is that such a process can be implemented in regular health checkups for the early detection of pneumonia.

### 13.2 LITERATURE REVIEW

In this section, a brief summary of various significant contributions from the recent literature is given in order to make it possible to apply the findings to our problem statement. In order to diagnose pneumonia, a gradient-based visualization method has been suggested by Rajpurkar et al. [1]. They utilized 121 tightly connected layers to calculate the illness risk. Ge et al. [2] combined multilayer perceptron and recurrent neural network techniques with more conventional methods such as traditional machine learning algorithms. Sirazitdinov et al. [3] proposed a region-based CNN model to segment and enhance lung images to make a pneumonia diagnosis. A deep learning model was proposed by Bhandary et al. [4] for the purpose of analyzing pneumonia and lung cancer, applying AlexNet pre-trained models for X-ray image identification and classification into the classes of healthy and unhealthy (pneumonia). Chouhan et al. [5] applied transfer learning concepts in the context of deep learning, which we believe can be extended to our project. They built the model using ImageNet.

Jaiswal et al. [6] developed a system which applied region-based CNN or Mask R-CNN. In their proposed system, image augmentation was applied, which combines attributes to localize pneumonia in chest X-rays. Guan et al. [7] proposed an attention-guided mask estimate algorithm where the X-ray scan denoted regions that are indicative of pneumonia. The network branches' local and global characteristics are incorporated in their established framework. To anticipate pneumonia, in order to pinpoint the part of the image that needs to be analyzed, heat maps were used. Xu et al. [8] suggested a solution that applied hierarchical CNN. The loss function they applied was sine-loss, which gave them good results. The outcomes showed that the deep learning-based model performs better than several traditional machine learning techniques [9, 10].

Xiao et al. [11] proposed a novel approach, which applies a multi-scale and heterogeneous technique. This is applied on a convolutional neural network of three dimensions. This was chest X-rays, and the findings open a door for researchers to dive deeper into experimental approaches. Labhane et al. [12] made a comparative study using VGGNet-based CNN models and InceptionV3, all of which achieved an accuracy score of over 97%. Srivastav et al. [13] proposed a model which used VGG16 as the base model followed by transfer learning techniques, and the model achieved a testing accuracy of 94.5%, which was significantly higher when compared with naïve models. Hashmi et al. [14] proposed a model that applied an ensemble learning approach. They designed a classifier that applied various deep learning models, and, based on weights given to the various models, the output was determined. The models they applied were Resnet18, InceptionV3, Xception, DenseNet121, and MobileNetV3. This approach achieved an accuracy and AUC score of 98.4% and 99.76% on the validation data, respectively. Rahman et al. [15] used four different pre-trained models for training the transfer learning framework into three schemes in all possibilities of a combination of normal, bacterial, and viral pneumonia, and this model achieved accuracies of 98%, 95%, and 93.3% for the respective schemes.

Cha et al. [16] proposed an attention-based transfer learning framework with optimized features of Resnet 152, Densenet121, and Resnet18, and this model achieved accuracy and AUC scores of 96.96% and 96.03%, respectively. Salehi et al. [17] used an automated convolutional neural network (CNN)-based transfer learning approach consisting of pre-built models such as VGG19, DenseNet121, Xception, and Resnet50, and the DenseNet121 model achieved an accuracy score of 86.8%. Liang et al. [18] developed a model that combined residual thought. This was done as a measure to counter overfitting and problems such as degradation. This approach provided accuracy and F1 scores of 96.7% and 92.7%. Luján-García et al. [19] proposed a model that applies transfer learning by using the weights of a pre-trained model. For this purpose, they used the Xception network weights, using which they obtained an accuracy score of 84% and an F1 precision score of 91%. Manickam et al. [20] proposed a deep learning-oriented solution with U-Net architecture-based segmentation, and classification was done with pre-trained models such as ResNet50, InceptionV3, and InceptionResNetV2, with the ResNet50 model achieving the highest accuracy score of 93.06% against other models.

When consulting recent literature works having common features, Showkat et al. [21] designed a twofold study wherein they assessed the performance of ResNet models. They were applied on chest X-ray images requiring classification. They also built a custom ResNet model to compare its performance, and the latter model was able to achieve accuracy. The metrics they used were specificity and sensitivity. The findings for the same were 95.65%, 92.74%, and 92.95%, respectively. Alharbi et al. [22] used a fusion model approach, wherein image segmentation and machine learning models were combined to achieve an improved version of the model. They proposed an improved BoxENet model by integrating ImageNet and SqueezeNet’s transfer learning methodologies. The proposed BoxENet model outperforms other models when compared against execution time, binary, and multi-classification models. Avola et al. [23] explored the effectiveness of established neural network models through the transfer learning paradigm by exploring the 12 known pre-trained ImageNet models for classification tasks of the 6,330 images. Most models reached an average F1 score of 84.46%. Sardar et al. [24] designed a novel MapReduce-based fuzzy C-Medoids clustering algorithm. This proved extremely vital in efficient data preprocessing and feature selection. Jayakanthan et al. [25] proposed a novel architecture with the aid of separable convolutions, residual connection, and residual attention learning.
