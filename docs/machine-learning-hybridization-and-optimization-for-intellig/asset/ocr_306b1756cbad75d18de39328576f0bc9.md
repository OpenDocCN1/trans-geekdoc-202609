For the analysis of faulty parts in a machine, a two-stage learning network model has been proposed [123] that can be used in the manufacturing field. The present study also aims to address challenges related to inadequate training dataset size and variations in data distribution. The proposed work obtains a balanced dataset by simulating the data using various manufacturing strategies. The resultant virtually generated data is used for training the model for better diagnosis of faulty parts. For the real-time diagnosis of faulty parts in a car, the pre-trained model weights are transferred to aid the production side physical space.

But very recently, techniques based on knowledge transfer have been widely used in sentiment analysis [65] and for classifying text [25]. In the classification of the imbalanced real-world Chinese dataset [116], a pre-trained network trained on a balanced hotel reviews dataset is employed. With the help of an under sampling technique, the weights of the model are transferred, so that the target model performance for classifying tourist datasets has increased substantially. An intelligent multilabel metric transfer learning (MLMTL) model [101] is introduced for classifying bibtex, emotion, and scene by adjusting both the instance and label distributions for the multilabel dataset. Only the distance metrics, such as MMD, are considered here, whereas the other algorithms will consider the instance-level distributions and their references.

A two-stage classifying approach was introduced [19] for classifying fine-art paintings that are publicly available. Six existing standard CNNs, including VGG-16 and Alexnet, are used in the first stage classifier with five patches of image dataset. The probability class vectors that result from the first model will help to make the final predictions or decisions in the second stage, which are more accurate and thereby increase the performance substantially.
