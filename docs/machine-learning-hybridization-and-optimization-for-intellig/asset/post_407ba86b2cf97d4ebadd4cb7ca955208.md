For the analysis of faulty parts in a machine, a two-stage learning network model has been proposed [123] that can be used in the manufacturing field. But very recently, techniques based on knowledge transfer have been widely used in sentiment analysis [65] and for classifying text [25]. In the classification of the imbalanced real-world Chinese dataset [116], a pre-trained network trained on a balanced hotel reviews dataset is employed. With the help of an under sampling technique, the weights of the model are transferred, so that the target model performance for classifying tourist datasets has increased substantially. An intelligent multilabel metric transfer learning (MLMTL) model [101] is introduced for classifying bibtex, emotion, and scene by adjusting both the instance and label distributions for the multilabel dataset. Only the distance metrics, such as MMD, are considered here, whereas the other algorithms will consider the instance-level distributions and their references.

A two-stage classifying approach was introduced [19] for classifying fine-art paintings that are publicly available. Six existing standard CNNs, including VGG-16 and Alexnet, are used in the first stage classifier with five patches of image dataset. The probability class vectors that result from the first model will help to make the final predictions or decisions in the second stage, which are more accurate and thereby increase the performance substantially.

A reinforcement-based curriculum transfer learning method for StarCraft micromanagement is proposed [68], the aim being to control multiple units within it. The proposed technique reduces the complexity level in the game environment that is caused due to the large state space, and this is controlled by adapting the Gradient Descent Sarsa proposed algorithm for training the model. This proposed framework for the curriculum model is used to expand to even more additional complex scenarios. As a result, this helps to hasten the training process and thereby improve the learning performance to a greater extent.

An efficient and very effective deep learning model for gesture classification and recognition has been proposed [107]. This gesture recognition is enhanced by learning only the necessary informative features based on large amounts of electromyography data, and thereby reducing the recording burden to a greater extent. The current transfer learning technique systematically improves the performance substantially when the model is trained on raw continuous wavelet transform (CWT), EMG, and spectrograms datasets, respectively.

An efficient deep learning–based coding method for low-rank cross-domain learning was introduced [133]. The current low-rank coding model is multilayer in nature and deployed at the top layers that are very specific to the task, and some general features are shared to resolve the domain inconsistency problem so that enriched knowledge is shared across the domains that are invariant in a layer-by-layer fashion. The proposed framework preserves the global large-scale structures that are familiar among the target as well as the source domains, and an identical one with similar samples which are frequent in both domains are combined for positive and effective knowledge transfer. In addition to this, several domain adaptation techniques are combined and integrated for effective optimization of coding using a semi-supervised learning method. Furthermore, marginal and conditional disparity problems across all the domains are alleviated. Several other successful works [76, 78, 104, 117, and 135] can also be implemented for the medical domain.

The distinctive characteristics of both domains are effectively managed through the utilization of partial transfer learning and feature extraction methods, as proposed in [114], where only a portion of the source model is employed in the target model. This model uses a multitask approach to fine-tune the network and was finally tested on in situ hybridization (ISH) labeled images.

## 6.5 FEATURE EXTRACTION METHODS TO AUGMENT CLASSIFIER PERFORMANCE

In recent years, several research scholars have been concentrating on feature extraction techniques for enhancing the model’s classification performance when trained on image datasets. Predominantly, feature extraction techniques play a dominant role especially in the medical domain and perform well in identifying the type of lesions and classifying them very accurately. It is observed that models’ classifier performance was improved by combining appropriate data fusion techniques with some important feature extraction methods.

### 6.5.1 EXTRACTING MEDICAL IMAGE FEATURES

The use of linear discriminant analysis [46] has been introduced along with feature selection and extraction methods for classifying brain MRI datasets accurately. Both low-level and high-level features are extracted; shape, intensity, and texture features along with high-level CNN-based image features are retrieved from the brain MRI and then the dataset is trained on traditional machine learning classifiers. Both breast and brain images feature a high intrinsic pattern, which can be easily processed using an existing GLCM algorithm and genetic algorithm that are embedded with CNN in what is called a hybrid approach.

Three correlation-based feature selection and extraction algorithms have been proposed [108] to find the essential feature subsets that are most significant. The efficacy as well as the feature selection algorithm effectiveness is evaluated on the basis of a highly intrinsic brain image dataset.

A novel image retrieval system has been proposed [85] in which three distinct feature selection and extraction algorithms are used to extract the essential textures from images, and potential feature vectors are identified using a hybrid approach and evaluated on breast image datasets along with brain tumor and thyroid images.

Feature enrichment–based CNN (FE-CNN) has been proposed [91] for heartbeat classification from electrocardiogram (ECG) signals. The ECG signals are transferred to a time-frequency image format and enhanced using a discrete short-time approach based on a Fourier Transform algorithm, and then these formatted images are input to the proposed CNN model. Another popular model called FE-CNN is trained on an MIT-BIH arrhythmia database and outperforms other popular algorithms without the use of a hand-crafted feature extraction algorithm. PFAF-Net, as introduced in [7], is a Pyramid Feature Network model that incorporates the fundamental concept of merging high- and low-level features at multiple scales. The attention-based fusion strategy is adopted to fuse the global and local features effectively. The decoder model will reconstruct the extracted image and then will integrate it with the multimodal data, resulting in rich content details. The model is experimented on four benchmark datasets: medical, multiexposure, multifocus, and visual-infrared. Selected numerical algorithms [96] for enhancing the performance of symmetric multiprocessing machine have also been introduced.
