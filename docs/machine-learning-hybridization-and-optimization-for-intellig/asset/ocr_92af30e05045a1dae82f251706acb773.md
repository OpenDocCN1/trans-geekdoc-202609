Secondly, an LSTM framework is proposed as shown in Figure5.2. The proposed LSTM network will have the tendency to process both the word and the feature vectors. The embedding layer contains the word vector, and the feature vector is given as output from the BLTL framework. Therefore the LSTM model and its layers are trained on both the word and feature indices. The sentences of law cases cannot directly be used for training and cannot be fed directly into an LSTM layer. Hence, now, the sentences of law documents are converted into a list of tokenized words. After this, all the distinctive words of cases are converted to a unique integer value. In an LSTM model, the embedding layer input will be an integer. The integer of the word index is given as input to the embedding layer. This layer outputs vector arrays corresponding to each word.
