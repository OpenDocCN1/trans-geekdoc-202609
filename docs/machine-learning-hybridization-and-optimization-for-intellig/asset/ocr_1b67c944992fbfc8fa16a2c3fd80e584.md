Once the signal is preprocessed without any noise, the next step is to
extract the features from the denoised data. A variety of feature extraction
techniques are discussed in the literature. The most prominent features of
the input ECG waveform are peak-to-peak intervals, peak amplitudes, and
the QRS complex. By applying CWT and a neural network, a study [6]
developed a new technique to detect and classify the QRS complex in ECG
signals. This technique results in QRS complex detection among various
morphologies by applying four wavelet basis functions. Signal denoising
and feature extraction are also achieved using thresholding, resulting in
97.2% accuracy in terms of classification. In [7], a complex QRS
identification with different decision rules for event vectors is implemented.
Experts have proven a wavelet transformation method to extract these
features accurately. To obtain the morphological features [8], DWT is
applied to each heartbeat. RR interval data is used as the dynamic feature.
Independent component analysis is applied for the reduction of the
dimensions of DWT sub-bands, and 12 coefficients are chosen as
morphological features. Principal component analysis (PCA) and dynamic
time warping (DTW) are used to extract morphological features from P-
QRS-T waves, and ECG features are acquired from the input ECG segment
[9]; finally, support vector machine (SVM) is used over the extracted
features, and the results of automated diagnosis are presented. In studies
[10, 11], R-peaks are detected using a multi-resolution approach combined
with adaptive thresholding. Denoising is done by removing the D1 and D2
detailed coefficients. In addition, real-time electrocardiogram wave peak
detection is also possible [12]. To improve the accuracy of the current
classification algorithm, categorization of an input ECG is done by fusion
feature under multi-classification conditions. Multilayer CNN and RNN are
used in the algorithm [13]. The most traditional and simplest method for
extracting the QRS complex is discussed in [14], where the authors describe
an algorithm to observe the QRS complex by enabling the input ECG signal
through a sequence of processes. Primarily, the input ECG signal is passed
through low-pass and high-pass filters, designed with appropriate cutoff
frequencies to locate the main energy of ECG. Following the filtering
process, differentiation, squaring, and averaging of the signal are
performed. To complete the averaging process, a sliding window has to be
chosen.
