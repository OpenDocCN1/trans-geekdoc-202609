# **FIGURE 9.4 DWT using filters**

In the proposed work, the input ECG signal is passed through DWT and decomposed into eight levels of approximate and detailed coefficients. By validating the frequency of each decomposed level, the db8 sub-band of the signal reflects the original ECG signal. Based on the obtained detailed and approximate wavelet coefficients, the P and R peaks of the ECG signal are extracted to estimate the RR interval and PR interval. The extracted features mentioned above are further used to train and test the dataset for classification purposes.
