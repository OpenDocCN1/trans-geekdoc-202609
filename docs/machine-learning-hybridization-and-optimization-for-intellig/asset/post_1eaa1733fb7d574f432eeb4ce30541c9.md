### 11.3.4 Canny Edge Detection

Canny edge detectors generally take grayscale images as input and output images indicating where intensity discontinuities (edges) occur. By using Gaussian convolutions, a Canny edge detector smooths and removes noise from input images. To highlight regions with high first spatial derivatives, the smoothed image is subjected to a first derivative operator. As a result of calculating both the x- and y-derivatives of the gradient, the algorithm can figure out the direction as well as the magnitude of the gradient. Then, non-maximal suppression is applied, in which pixels not on ridge tops are set to zero, resulting in a thin line if any pixels are not on ridge tops. Then it is checked whether neighboring points in both positive and negative gradient directions have the same gradient as the previous step to ensure that the gradient calculated in the previous step is the maximum. The gradient is considered to be part of the edge if it is the greatest, and vice versa. The tracking process described above is governed by two thresholds, t1 and t2, such that t1 > t2, a phenomenon known as hysteresis threshold. Tracking begins at a higher point on the ridge than t1 and proceeds in both directions until the height of the ridge is less than t2. So, basically, it is necessary to select all edge points that are greater than the upper threshold t1 and then search for neighbors of these points that are less than the upper threshold t1 but greater than the lower threshold t2. Such neighbors would form part of the edge in this case. As a result, the tracker's t1 (upper) and t2 (lower) thresholds are the same, as is the width of the Gaussian kernel used to smooth the input image. In the future, this Gabor filter based on threshold values will extract the edges from the UAV_OPL images containing insulators.

### 11.3.6 Sobel Operator

The Sobel operator detects edges of UAV_OPL images using a type of 2D derivative mask. The masks will be used as follows: The vertical mask will be created using a numpy array. The vertical mask will be used to create the horizontal mask. Then the mask is passed to the Sobel edge detection function as an argument, allowing us to use any mask. The data is then smoothed using the Gaussian blur function. Finally, the image and the vertical filter pass through the Sobel edge detection function. The horizontal mask is then used to apply the convolution. Simply transpose the mask by flipping it along the horizontal axis. Later, both vertical and horizontal edges are combined in extracting the features in terms of pixel values from UAV images.

### 11.3.7 Prewitt Operator

The Prewitt operator detects UAV_OPL images' edges along the x- and y- axes horizontally and vertically. When the intensity of pixels suddenly changes, the mask detects the edges. The edge can be calculated based on differentiation because it represents a change in pixel intensities. A Prewitt mask is a mask with first-order derivatives. As a graph representation of the Prewitt result, the edges are represented by the local maxima or minima. First and second derivative masks have the following three properties. A higher weight equals better edge detection. For the mask, use the inverse sign (+ and -). A positive sum must be found when the mask values are added together. The Prewitt operator thus provides two masks: one that detects edges horizontally, and another that detects edges vertically.

X-axis Prewitt operators: [-1 0 1; -1 0 1; -1 0 1]
Y-axis Prewitt operators: [-1 -1 -1; 0 0 0; 1 1 1]

### 11.3.9.1 Random Forest Classifier

As opposed to the manual (expert-based) decision rule definition, the random forest (RF) uses self-learning decision trees. As a result of this “self-learning” process, each node sets its own rules based on inputs and labels from a training dataset. Based on a set of input features and training points, one method for determining the optimal split would be to minimize the heterogeneity (i.e., mixtures) between the two subsets. The Gini impurity is a measure of heterogeneity in decision tree learning that derives from the concept of entropy in information theory. The Gini impurity index is then computed for each potential split of the data to determine the best split at each node, and the split with the least heterogeneity is chosen. The term random in RFs refers to the learning process's two major layers of randomness: To begin, RFs grow each individual decision tree using a bootstrapped sample of the original training dataset (i.e., a random sample with replacement). As a result, the training sets for the trees are (for the most part) distinct. This may appear strange at first, but it reduces tree correlation and improves prediction generalization significantly. The second random component is a random selection of the features (such as spectral bands) that are taken into account at each node. As a result, splits for various features of insulators are determined, making tree decoration easier. Many trees may produce different class labels for the same insulator data point. All trees in the RF vote to determine the final class assignment of each UAV image pixel.

### 11.3.9.2 Support Vector Machine

Classifying and predicting images can be done using SVMs, which are supervised learning algorithms. Basically, SVMs are designed to separate the classes as much as possible in the training data by using hyperplanes. The greatest margin is determined by finding the hyperplane with the greatest distance from the closest class data point. Once the hyperplane for the insulator features has been determined, new data can be classified according to which side it falls on. It is particularly beneficial to use SVMs when data consists of a large number of features or a distinct margin of separation. SVM classifiers automatically separate insulators. Data that can be separated linearly works very well with them. A linearly separable dataset is one that can be plotted in a graph and classified based on a straight line.
