An imperfect knowledge graph technique for classifying rare diseases was introduced in [72]. The proposed classification algorithm will classify the text dataset and will therefore result in performance gain. The same technique when evaluated on two diverse datasets categorizes a total of 1 lakh data into 849 diseases efficiently. In certain circumstances where the labeling of samples is difficult, especially in the case of applications like in the medical domain, data augmentation with feature extraction could be used to alleviate the limited dataset problem. An efficient automatic CAD technique for tuning and learning the Gaussian interval has been introduced by the authors in [93] for lung classification using Type-2 Fuzzy membership functions.

An innovative CAD approach [49] was introduced using attention mechanisms for diagnosing endometrial cancer (also known as uterine cancer) using histopathological images. This deadly disease can seriously affect the female reproductive system. The proposed approach helps pathologists in better interpreting and in diagnosing diseases, for which the histopathological correlations are used as effective features of low-level pixel images with endometrial tissues containing morphological characteristics.

Breast cancer anomaly detection systems using efficient ML techniques have been proposed in [53]. A dimensionality reduction technique like principle component analysis (PCA) was used initially for sinking the proportions of the information up to the minimum level, and the multi layer perceptron (MLP) method was then used to retrieve essential data characteristics, which were finally classified using an SVM classifier. A novel intelligent technique has been proposed by the authors [66] for classifying breast micro-calcifications (MCs), which are difficult to detect but diagnosis at an earlier stage is efficient. The proposed approach uses an ensemble of decision trees (EDT) and an SVM classifier that involve feature extraction techniques to optimize the result from 91.42% to 99.55% effectively. Reinforcement learning techniques [42] for real-time 3D landmark detection of computed tomography scans have been introduced. A model is trained to differentiate volumetric and anatomical objects in space. The proposed work is tested using 3D computed tomography scans that are 1,487 in volume, which is a total of 500,000 image slices collected across 532 patients.
