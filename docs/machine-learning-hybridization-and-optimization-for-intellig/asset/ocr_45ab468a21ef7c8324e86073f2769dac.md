# 2.1 INTRODUCTION

Autonomous mobile robots have gained huge importance and popularity in recent years. They are being used for various tasks, which otherwise could have been much more difficult or costly to accomplish. Unmanned aerial vehicles (UAVs) are robots that have the ability to move in any three-dimensional space. Tasks such as surveillance, intruder detection, delivery, and so on are being easily performed by UAVs, at a nominal cost. But there are some constraints associated with UAVs. The power available to any UAV is limited and needs to be used in an optimized way [1]. However, we can obtain better results if we use a network of UAVs instead of a single UAV [2]. The UAVs need to communicate with each other. By communicating, we mean that they should be able to share information among themselves, which will help the network of UAVs to cover a broader area much more effectively. The multi-robot system is also cheaper to implement than implementing a single powerful robot for the same task. It also provides better fault tolerance, robust information, increased coverage area, and better reliability.
