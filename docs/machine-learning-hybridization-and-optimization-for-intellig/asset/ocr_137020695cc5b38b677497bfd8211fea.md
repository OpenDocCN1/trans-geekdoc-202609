# 7.5 VIRTUALIZATION CONCERNS WITH CLOUD COMPUTING

The interaction between the OS and hardware has changed as a result of virtualization. This in and of itself raises questions about conventional security viewpoints since it casts doubt on the security you may feel when installing an OS and an application on a server you can see. However, some of us already think that this level of comfort is inappropriate in the majority of circumstances. For the average user, it is quite difficult to realistically determine the actual security posture of even a PC with an Internet connection. Although visualization makes things more difficult, it does not necessarily improve or worsen security. Although virtualization offers many advantages, using it in the context of cloud computing also raises particular security issues.
