# FIGURE 14.2 Neural network architecture of the proposed handwritten recognition system

+   - The image is initially converted to grayscale level.
+   - The matrix is then converted to a single-dimensional array of the format [1, n] for making it ready for the normalization process.
+   - The single-dimensional array is then normalized by dividing the entries with 255 to convert it to binary format, and then the image is preprocessed.
+   - The neural network is fed with this preprocessed array as input, and a value between 0 and 1 is obtained for each neuron at the output end after passing through the hidden layers with ReLU activation function.
+   - The maximum value out of the output neuron is found out using the argmax function, and the digit is recognized.

# 14.2.1 DATA ACQUISITION AND PREPROCESSING STAGE

The MNIST dataset from the Keras library has around 60,000 handwritten digit images classified into 10-digit classes. The data is initially imported from the database and preprocessed. In the preprocessing stage, the pixels that have a constant intensity value were removed, viz. the constantly white pixels and the constantly black pixels. Additionally, the images were rescaled and flattened to make the model process information faster with a higher learning rate. A sequential model with one hidden layer was then set up. The TensorFlow platform is used to set up this model, and since the MNIST dataset is used to train the model, the image size is centrally set to 28×28 pixels.
