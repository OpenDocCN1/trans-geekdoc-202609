Innovative and novel caption generation methods [77] have been proposed which outperform other existing models and give comparably good results when tested on the publicly available MSCOCO dataset. This model uses two-level optimization methods for detecting the most important semantic features and finally a selection procedure is applied to automatically choose the most suitable concept. A novel report generation framework is proposed [20] using a soft attention mechanism into which a feature pooling method is also incorporated to detect and analyze abnormalities in an image, and it generates diverse captions routinely. In the current hierarchical recurrent network, a topic matching mechanism is additionally added and has been tested for efficiency on the CT lung dataset.

One other intelligent image captioning model has been introduced [63] based on a multimodal transformer (MT) network that will process the intra- and interactions using a unified attention block. The proposed technique produces accurate captions using a complex multimodal reasoning technique. The MT model is further trained on visual features to move forward and improve the model’s captioning performance. Now the CNN model which is acting as an encoder will take out the visual features that are region-based in an image, whereas the decoder RNN will be primarily responsible for generating captions and the RNN automatically predicts the output descriptions that are completely based on just the given visual features. A novel and innovative topic RNN model was introduced [16] to generate sentences automatically. The memory network is incorporated with topic words to guide sentence generation successfully. The current model is validated and tested to generate automatic captions on the basis of remote sensing images (RSI); this work also captures the diverse portions of a single image for the purpose of accurate annotation.
