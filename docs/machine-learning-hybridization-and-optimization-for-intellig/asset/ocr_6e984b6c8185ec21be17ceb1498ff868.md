# 8.8 STEPS FOR SECURING HOME DEVICES

# 8.8.1 THE SETUP OF ROUTER

The main pathway for the IoT is the Wi-Fi router, which connects each device to the Internet. So the first security that is needed is for the routers. And these may be more susceptible to being hacked easily by others. So home network security starts with router security. There are three main levels which can secure these routers.

# 8.8.1.1 Altering the Default Name of Router

For each router, a default name is created which is commonly known to that router, and this may be visible to all network users. This default name can pose a high risk of unauthorized access, meaning that neighboring devices may also connect to these routers without permission. So, by changing the default name, it may provide a secure way since it will only be known to the main users and others may be confused when connecting to that device.

# 8.8.1.2 Unique Password to the Router

As discussed above, changing the name of the device may help secure the device, but there may still be a chance that other users can still connect to it. For this reason, another technique is changing the password for the router, which provides full security. This means that changing the password for the router will not allow access to other users unless the password is known.
