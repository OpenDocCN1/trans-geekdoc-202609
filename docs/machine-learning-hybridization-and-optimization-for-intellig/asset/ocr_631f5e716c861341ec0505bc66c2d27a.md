# Algorithm

+   1. Start
+   2. Login with MetaMask:
+      - MetaMask – Crypto Wallet.
+      - Supports Ethereum, Bitcoin, Solana, etc.
+      - NFTs will be stored here with a unique hash.

+   3. Play game:
+      - Obstacle Assault is a hurdle game with 4 levels.

+   4. Reach the final destination:
+      - Third level is the final destination.
+      - To win, completion of third level and score are necessary.
+      - The higher the score, the more unique NFT one gets.

+   5. Win NFTs:
+      - NFTs can be sold to NFT marketplaces like OpenSea.

End
