In the proposed work, we will see how this artificial general intelligence can help lawyers to manage court cases expeditiously.

Therefore the main objective of the current model is to transform the Indian court system to be fully automatic with the aid and help of ICT (information and communication technology) tools. The proposed work will be very useful for justice delivery, law referencing, contract translation, and summing up total cases based on their category in courts. The goal of the proposed model is to design and implement a single transfer learning framework that can be reused efficiently for all types of time-bound service delivery. The proposed framework is useful for multiple purposes as an all-in-one software for the translation of judicial documents, for contract management, for providing decisions and prediction assistance, and for process automation in district courts. The collection of data and the generation of datasets for the implementation of above said features is an even more challenging and crucial issue. The details of cases can initially be obtained in scanned copies. First, the dataset should be made ready by preserving its original meaning; then preparing it for use is even more challenging in a legal setting.

The proposed work undoubtedly acts as one single solution to manage all legal matters, contracts, and documents and is also aimed at mining, tracking, decision making, and translating using an AI-based single transfer learning technique that can be finetuned and modified for many different domains. Therefore, this framework provides accessibility of information for all stakeholders with full transparency, which is easily accessible and very cost effective.
