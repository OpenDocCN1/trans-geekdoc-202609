Word2VisualVec [59] is an advanced neural network architecture for predicting features in the form of visual representation from the actual textual input. Instead of relying on a joint subspace for retrieving captions, the proposed model works on features of visual space, where the captions are encoded into the embedding layer using a multiscale vectorization technique. The model is further enhanced using an efficient and simple multilayer perceptron network. The Word2VisualVec framework is further made more comprehensive for retrieving captions from videos. The current work not only predicts captions from text but is also very effective in captioning the audio-visual representation. The model is validated on the Flickr8k, Microsoft Video Description, and Flickr30k datasets.

An adaptive CNN architecture has been proposed [6] for automatic annotation of articles with the help of both image and text data. Canonical correlation analysis is done and the great circle distance–based loss function is deployed in CNN and tested on 100,000 news article datasets that include heterogeneous data like captions, images, and texts. Faster R-CNN [36] is an attention technique based on the multilayer model which will extort image features effectively, and finally the extorted textures are input to the faster recurrent convolutional neural network which will act as a decoder for decoding the samples effectively. Finally, the automatic descriptions are generated and the model’s performance is further augmented using the preeminent gradient optimization technique. The attention mechanisms that are employed in the network layers can in fact evade the hindrance of non-salient features and help to effectively carry out the decoding process to determine the corresponding description text accurately. The model is experimented on three datasets: the Microsoft COCO Caption Data Set, the Flickr dataset, and the AI challenge Chinese dataset.
