# 8.2.2 NETWORK LAYER

The network layer acts as an interface between the application layer and the perception layer, transmitting data that was collected from the physical layer through the sensors. This layer is solely responsible for connecting devices to the network. A high-security issue is associated with this layer because authentication details and data can be transmitted through this layer. Some of the attacks that happen in this region are the following:

+   - Denial-of-service (DoS) attacks prevent main users from using network resources and accessing devices. These attacks make accessing applications or devices more critical.
+   - A man-in-the-middle (MiTM) attack interrupts data that is being transmitted from the sender to the receiver. It acts like a tower between devices that transmit data and makes changes in data, wherein the actual data has been interrupted by the attackers. It causes serious online security issues that are reflected in the application layer also.
+   - Storage attacks interrupt data that is mainly stored in devices. This type of attack is also known as a cloud attack.
+   - An illegal attack takes control of both hardware and software to steal information from data storage devices and make the application unusable. Such attacks can be dealt with by enabling end-to-end encryption to safeguard data while transmitting it to other devices and also implementing key sensors to devices like locks to data storage, which prevents unauthorized access [13, 14]. The usage of encryption provides different keys to different users while sharing data with other devices.
