### 14.2.1 DATA ACQUISITION AND PREPROCESSING STAGE

The MNIST dataset from the Keras library has around 60,000 handwritten digit images classified into 10-digit classes. The data is initially imported from the database and preprocessed. In the preprocessing stage, the pixels that have a constant intensity value were removed, viz. the constantly white pixels and the constantly black pixels. Additionally, the images were rescaled and flattened to make the model process information faster with a higher learning rate. A sequential model with one hidden layer was then set up. The TensorFlow platform is used to set up this model, and since the MNIST dataset is used to train the model, the image size is centrally set to 28×28 pixels. The ratio of training to testing data is then set at 80:20, respectively. The dimensions of the data are (60000, 28, 28), and since the model requires 3D classification, we reshape the matrix to fit the data dimensions as (60000, 28, 28, 1). The training and testing data values are normalized to the [0, 1] range and passed on as inputs to the model.

This layer takes in one feature from the input image and later filters out the different features and makes a feature map. The pixel with the equivalent values is deducted by moving the filter over the entire image. The next layer, which is the MaxPool layer, shrinks the image size to decrease the computation time. ## 14.4 CONCLUSION

Innovations in technology and the rate at which they are developed never cease to astound. One such development is the ability for machines to read handwritten numbers on photographs, documents, and the like. This process is known as _handwritten digit recognition_. Optical character recognition is the gold standard for recognizing text on scanned documents by reading typed or handwritten text. In this investigation, a neural network model is used to identify digits written by hand on a digital whiteboard. The same could be implemented with audible output for the benefit of the deaf, hard of hearing, and physically impaired. We first used the MNIST database's datasets to create a sequential model for use in training and testing before moving on to the TensorFlow platform. The Python programming language's Pygame framework was used to create the digital chalkboard's number detection system. The results of the tests showed that 99% accuracy could be achieved when classifying the handwritten numbers.

## 14.5 FUTURE SCOPE

When a number was drawn on the whiteboard, the model was able to identify it, and the result was superimposed on top of the handwritten character. Integration of voice feedback that can read aloud the detected digit to enable deaf and speech-impaired persons to understand the digit is a potential future effort and scope. Here, Python’s text-to-speech (TTS) commands may be used to have the text read aloud in English. Eventually, if a substantial number of large datasets are available, this can be incorporated into block chains. In future, the proposed model can be extended for the approaches [20, 21, 22, 23, 24] for an effective OCR-based handwritten digit recognition.
