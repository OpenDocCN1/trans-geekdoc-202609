### 1.1 INTRODUCTION

Big data in the cloud is a new trend in data-intensive platforms that makes it simple to quickly construct analyses and distribute them across a scalable infrastructure. Big data in the cloud may be classified into four groups based on the services provided to end users, as outlined below:

- 1. Public big data clouds are large-scale organizations processing on an elastically expandable cloud architecture.
- 2. Pay-per-use computing provides Internet resources. Examples are Amazon’s cloud-based big data computing, Windows Azure HDInsight, Rackspace Cloudera Hadoop, and Google’s platform.
- 3. Private big data clouds implement a big data platform inside a business on a virtualized infrastructure, providing more control and privacy to individual organizations.
- 4. Hybrid big data clouds are a federation of public and private big data clouds designed for scalability, disaster recovery, and high availability.

High-demand private clouds can be moved to public and private big data clouds designed for scalability, disaster recovery, and high availability. High-demand private clouds can be moved to public infrastructure. Big data access networks and computing platforms, like those provided by enterprises, provide data, computing, and analytics services. Cloud computing (CC) is the deployment of computing and various resources centrally. These resources are due to the emergence of the Internet of Things (IoT), and massive amounts of data are generated at a significant rate.

Adequate processing infrastructure is required to help users trigger actions on predefined goals. With the real-time application and spread of IoT, the requests for data transfer and computing calls are realized using edge computing. The cloud provides pre-packaged services for IoT operators and has a prominent position as a centralized platform for deploying IoT solutions. Thus, cloud computing is an alternative to or sometimes complements traditional data centers. There is a computational infrastructure demand to move to the network edge that ideally stores the data and performs computation [1]. It has integrated cloud and edge computing to provide vertical and horizontal offloading techniques between the virtual machine server nodes. However, long latency presents a challenge and analysis of edge and cloud computing is necessary to reduce the problem. If the majority of the work is executed in cloud computing servers, considering the three-tier architecture, the jobs are completed after some delay. Thus extending the computation at the edge can offload some of the jobs from the cloud center. According to [2], the task delay time is reduced by using an extended short-term memory algorithm in a mobile–edge–cloud computing model. The offloading strategy from the cloud to the mobile device was based on task prediction. The authors claimed that this architecture and algorithm effectively reduced the delay caused by a growing number of tasks and subtasks.
