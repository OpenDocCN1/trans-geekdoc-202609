The recent performance of transformer models in solving language translation problems has been nothing short of impressive. The idea behind this was applied to closed captioning video content [14]. The transformer was modified using the Connectionist Temporal Classification (CTC) loss to facilitate sign language interpretation. This model's features were created using a Convolution Neural Network-long short-term memory-hidden Markov model (CNN-LSTM-HMM) architecture, which entails first establishing gloss labels in an unsupervised manner and then using an HMM model that is aligned to those labels. It has been proven that while an LSTM performs well with output tokens longer than 100, transformers function well with tokens longer than 1,000. Whereas a conventional RNN would take each input in turn, a transformer takes them all at once.
