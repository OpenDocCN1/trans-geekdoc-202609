A Euclidean space technique [50] was introduced for EEG data alignment that facilitates transfer learning to be used for brain–computer interfaces (BCIs). Feature extraction techniques along with machine learning algorithms are applied to achieve better learning performance even when no subject-specific data is provided.

The decompose, transfer, and compose (DeTrac) approach was introduced [11] for classifying medical images using popular transfer learning approaches. The performance of such Imagenet pre-trained classifiers is further improved by using the class decomposition method. Transfer learning models struggle to offer a robust solution when there are more irregularities in the distribution of the dataset. Therefore, a new innovative CNN architecture was proposed using a class decomposition technique, which makes it easier to deal with complex data irregularities, and the current model is tested on different datasets like histological image datasets, chest X-ray datasets, and digital mammograms.

It has been identified that the classification accuracy of breast malignancy is increased substantially by using a data augmentation technique, and the same was introduced [81] using a transfer learning technique. New training samples are obtained using several data augmentation techniques. Several operations like zooming, rotating, flipping, and so on of the breast X-ray images are obtained. This overcomes the problem of insufficient datasets, and thereby increases the model's accuracy. Two networks, say Inception V3 and VGG19, have been introduced [71], which are pretrained on the public ImageNet image dataset. The power of transfer learning with different levels has been analyzed. A magnetic resonance imaging (MRI) dynamic contrast-enhanced method (DCE) for categorizing fibro adenoma along with ductal invasive carcinoma was introduced to detect breast tumors.
