These two metrics can be combined to get an aggregated score called an F1 score. This is a single score for a model which combines precision and recall and is a representation of the performance of the model class-wise. For Pneumonia Class, we get an F1 score of 0.76, whereas for Normal Class, we get an F1 score of 0.89.

Support is the value of the number of occurrences of records in each class. It simply tells us the number of records there are in y_true. For the pneumonia case, we have a support value of 234 and for the normal case, we have a support value of 390.
