# 6.4 TRANSFER LEARNING FRAMEWORKS FOR HANDLING LIMITED TRAINING SAMPLES

In recent years, many scholars have been focusing on alleviating the insufficient dataset problem using transfer learning. This is achieved by transferring the knowledge from the initial source to the final target, whereas the initial source model is trained on a huge dataset.
