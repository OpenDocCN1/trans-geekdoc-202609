Therefore, the goal of this study is to create a system for recognizing British sign language that employs CNN and LSTM while simultaneously maximizing accuracy by fine-tuning the relevant parameters. However, an issue arises when two people who speak different languages cannot communicate with one another without the physical assistance of a translator, which may not always be convenient to arrange while using LSTM. A similar issue also arises when a normal person and a person who is deaf or speech impaired interact with one another. The proposed model makes use of deep learning to create a low-priced sign language recognition system. The system is implemented in Python using the OpenCV and Keras libraries. The project evolved via three distinct stages as follows.

# 15.2.1 PREPARATION OF A DATASET WITH EXISTING STATE-OF-THE-ART DATA

The dataset is produced using the video camera’s live feed. Every frame that recognizes a hand in the defined region of interest (ROI) will be saved in a directory called “gesture directory,” which has two folders called “train” and “test,” each of which has 10 folders for the numbers 1–10 containing pictures taken with the create_gesture_data.py. The live cam feed is taken using OpenCV, and an ROI is created.

The background and foreground (ROI) are differentiated. The threshold values are calculated for every frame, and contours (for converting the image obtained to black and white such that the background is black and the objects detected in ROI are white) are determined by which we can know if there is any foreground object being detected in ROI (i.e., a hand).

Inspired by [21] and [22], who have presented the novel histogram equalization techniques, we impart adaptive histogram equalization which tries to predict the actual range of bins and try to exhaustively utilize the range between 0 and 255. Histogram equalization is performed by converting the image into HSV color space, and the algorithm is applied to luminous without changing the hue and saturation values of the image.
