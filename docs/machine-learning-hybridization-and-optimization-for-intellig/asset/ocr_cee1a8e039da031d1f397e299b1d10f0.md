On generating the classification report for our model, we get the precision, recall, F1 score, and support metrics. Precision tells us “How many of the records labeled to the current class actually belong to the current class”, whereas recall tells us “How many of the records of the current class were fetched from the total number of records that belong to the current class”. For our model, we got a precision score of 0.95 for the Pneumonia Class (Class 0) and 0.81 for the Normal Class (Class 1). This tells us that if the model classifies a lung image as pneumonia, it is most likely to be correct, and for normal cases, it is average performance. For recall scores, we got a score of 0.63 for pneumonia and 0.98 for normal. This implies that the model is fit well to correctly classify most of the normal cases present.
