One part of the proposed design describes the model generation, while another part focuses on the creation of the user interface window.

Model creation entails constructing and training a model in sequence using data from the MNIST database. To further investigate any discrepancies, we additionally examine the data split 80:20. Designing an application’s user interface with Python’s Pygame module is the focus of GUI window development. The integrated GUI window and model are shown in Figure 14.1, together with the associated system process. The user enters the digit by writing it on a digital whiteboard, which is then processed. In the preprocessing phase, the picture is cleaned up and improved so that the model can identify it with greater ease. Grayscale images are normalized and converted to pixel values in the feature extraction block before being given to the neural network model as input. The model classifies and recognizes written digits by evaluating the normalized pixel-valued matrix to get the highest-valued output neuron for making such predictions. The text of the handwritten numbers is shown in the output block on top of the rectangular block made in the feature extraction stage, making recognition simple.
