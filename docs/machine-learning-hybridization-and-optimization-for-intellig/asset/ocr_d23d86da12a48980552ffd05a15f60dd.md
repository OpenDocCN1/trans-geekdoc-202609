# # 6.6.1 GENERATING CAPTIONS FOR NON-MEDICAL IMAGES

Several dialogue-recognition fully automatic captioning systems have been developed by researchers that will act as a solution in cases where doctors’ conversational speech usually includes lots of medical terms in different spontaneous styles that are not frequently used. Therefore, a novel greedy algorithm with language model (LM) is used along with a forward weight adjustment (FWA) technique, where weights are automatically estimated using a traditional expectation-maximization algorithm, and thus this improves the accuracy of caption generation substantially. Most of the novel techniques developed in recent years filter noisy detections and create syntactic trees to automatically generate natural image descriptions [35].

A template-based description generation model has been proposed [33]. This model is currently trained on visual representations and focuses on establishing connections between multiple objects in an image. By hypothesizing the dependency representation, image description can be improved. Computer vision algorithms are most predominantly used for recognizing and detecting images as proposed in [67], in which the terms that best describe an image are identified with the help of recognition algorithms. The generated final descriptions are remarkably accurate and in line with the image content. A novel visual dependency representation (VDR) model has been proposed [34], where different objects are identified using an object detector, and finally the detections (objects) are used to produce an automatic description for a new unseen image using a template-based description generation model.

A novel approach for automatic image description has been proposed [39] that includes using multiple learning instances to train the visual detectors, and the model has been tested with more than 4 lakhs of descriptions to automatically incarcerate the information about the usage of words. A novel method that integrates [115] huge high-level concepts into the encoder-decoder model has been proposed, which achieves a considerable enhancement in terms of both visual question answering and image captioning systems.
