As discussed above, it is important for cloud infrastructure to be able to handle real-time resource-intensive applications. However, some applications require a subset of resources and can be handled by a low-configuration device, say a device at the edge of the cloud. This is achieved by edge computing technology through offloading tasks at the edge level. Edge computing was first introduced in the 1990s with the launch of Akamai’s Content Delivery Network (CDN). CDN delivered images and videos to users. In general, IoT devices near the edge devices require moderate computational resources. Some real-time applications such as cloud gaming, smart series, and augmented reality require this infrastructure. Edge computing (EC) acts as a gateway to edge devices (mobiles, smart grids, connected appliances) to compute and store the data source at the edge. It provides solutions to significant infrastructure issues and challenges such as network congestion, higher latency, and bandwidth limitations. EC handles these issues effectively by bringing the cloud closer to the users. EC enables the user to perform and execute a task at the edge and provides the results as fast as possible. As a result, transmission delays and other communication issues are resolved. The benefits of EC are cost-effective solutions, faster response time, and reliable operations with intermittent connectivity and security compliances with computing.

In this chapter, we describe a typical structured view of edge computing. Cloud-deployed high-end services interface directly with devices. Machines learn tasks at the edge, reducing time. Edge-cloud computing delivers low-latency remote cloud services for new IoT devices. This can be used to offload computing processing services from the cloud to the edge to improve a client’s quality of service (QoS) and quality of experience (QoE). The EC model cannot always replace CC since it does not have as substantial a resource capacity as the cloud. Therefore, EC and CC complement each other and are mutually reinforced. Various researchers widely accept the popular three-tier model. The device boundaries, also called a thing-layer or user’s border, are composed of all devices such as mobiles, surveillance cameras, IoT devices, smart devices, drones, and other equipment. Some devices have limited storage capacity and processing capabilities. As per the client’s requirement, these data can be prepared locally or offloaded to the edge and the cloud.
