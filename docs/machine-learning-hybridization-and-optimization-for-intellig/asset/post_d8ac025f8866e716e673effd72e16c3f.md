The method proposed in [12] uses a disentanglement technique for lesion classification. This technique combines the specific representation of one image with the unspecified representation of another image. This combination produces a new sample for classification among different variants of specific classes. The authors in [26] have introduced two advanced deep CNN based networks to detect the risk of cardiovascular disease, and the model is trained on coronary calcium CT datasets. The proposed two models adapt the multitask CNN model with a median filtering technique. This efficiently classifies epicardial tissues and segments thoracic tissues. A novel CNN model [105] that uses a combination of distance regression has been proposed along with a fusion scheme method. This will learn specific features from 6,000 2DCT and MRI kidney datasets. The authors in [73] have introduced an efficient multistage CNN model for classifying instances of gland adenocarcinoma. The model proposed is a multitask algorithm and is validated on the MICCAI dataset. This proposed work yields better F1 score values with an accurate measure of index dice.

The effectiveness of deep neural networks has been established in numerous applications [13, 69, 131] connecting the lungs, liver, breast, kidney, and so on, for example, classifying liver cancer, segmenting liver tumors and so on. A new data augmentation approach has been introduced by the authors in [40] to reconstruct super-resolution slices of liver tumors in CT using multiframe technique. The method proposed [18] employs a supervised pattern classification technique for classifying liver, breast, and blood neoplasias to diagnose tumors based on machine learning methods.

Recently, due to their effective and accurate prediction outcomes, image segmentation methods have become widespread in the field of medicine. ### 6.4.1 Using the Concept of Transfer Learning in Medical Imaging

In the medical imaging field, transfer learning seems to be very successful in detecting breast lesions. Apart from this several other classifications that involve the lungs, the abdomen, the brain, Parkinson’s disease, and electroencephalogram (EEG) signals are also taking advantage of transfer learning. This transfer learning technique based on instance was proposed [109] for classifying chronic pulmonary disease. They identified this disease using CT scan images of the chest. The proposed method can be generalized across domains using different protocols or using scanners. Another innovative approach [83] to addressing the mass detection problem in mammogram images has been introduced. The solution for the above said problem has been achieved using CNN-based transfer learning techniques.

Classifying breast cancer was proposed by the authors [80] in which the convolutional neural network plays a major role in feature extraction. The SVM and RBF classifiers are adapted for tuning kernel. This can be achieved because of the algorithm’s flexibility in fitting the dataset adequately to the required dimension. As a result of combining CNN and RBF-based SVM, due to the hybridization process, a substantial increase in the results has been achieved. An intermediate domain to decrease the domain dissimilarity has been introduced among the target and the source networks. Multistage learning was introduced in [95] for classifying the last target DBT dataset using the knowledge of the initial source network along with the mammography images in the intermediate domain.

Using histopathologic images (HI) for detecting breast cancer has been proposed in [62]. To improve the support vector machine (SVM) classification accuracy to some extent, irrelevant patches from the images are removed before training the model. Different models [48] have been proposed to classify breast malignancy in histology images. The images have multiple cellular and nuclei configurations and are trained on AlexNet, ResNet, and GoogleNet models.

Domain adaptation–based joint knowledge transfer learning approaches for classifying and recognizing EEG signals have been proposed [132], in which the model is tested on Bonn images in addition to CHBMIT datasets to determine the accuracy. The proposed work achieves a higher accuracy with an iterative approach. Another novel positive approach [58] for detecting Parkinson's disease has been introduced that consists of domain-specific data instead of patient data. The proposed work solved negative transfer, which is an important issue in transfer learning which avoids the problem of performance degradation. The model outperforms other techniques without using the transfer learning technique.

A novel unsupervised approach was introduced [56] to characterize tumors based on a 3D CNN model which is trained on 171 MRI and 1,018 CT images. GIST descriptors have been incorporated into the model to find the differences between pancreas and lung cysts. To detect breast malignancy and for detecting tumors in whole-scale images, an effective adaptive sampling method using transfer learning models [24] has been proposed that notably increases the classification accuracy to a greater extent.

A new transfer learning technique [3] with a novel image weighing method for segmenting images has been introduced that reduces maximum mean discrepancy (MMD) error to a greater extent between training, testing, and the validation data. The model performance is further optimized by joining both the image weighing and kernel learning method and it is trained on the heterogeneous data. The transfer learning technique in conjunction with feature selection and normalization techniques [94] has been proposed for classifying molecular cancer using deep neural networks. The proposed method uses sparse auto encoders and is tested on gene expression data. This unsupervised learning technique is used to make accurate decisions on different types of tumors and is also found to be very useful for diagnosis and treatment.

An advanced deep learning end-to-end framework was introduced [57] for accurate and automatic detection of analyzing sleep staging. Two transfer learning models were derived to address two problems very effectively: data inefficiency and data variability. The proposed two transfer learning based sleep staging networks are tested on multiple objective fields, namely the Cassette database, the Telemetry Expanded database, and the EEGrid database, respectively.
