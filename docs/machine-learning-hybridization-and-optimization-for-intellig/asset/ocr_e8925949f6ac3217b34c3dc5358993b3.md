# 8.2 IOT LAYERS AND SECURITY BREACHES

An IoT system consists of three layers that protect devices from attacks: the application layer, the network layer, and the perception layer. The reason behind the implementation of these layers is the challenges that occur in the system. These layers can fulfill the IoT requirements that are required for security and privacy [7].
