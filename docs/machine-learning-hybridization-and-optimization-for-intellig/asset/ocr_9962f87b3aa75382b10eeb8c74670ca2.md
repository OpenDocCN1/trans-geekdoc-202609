# R

RNNs A particular kind of neural network architecture that is excellent for handling sequential input, including speech and text.

RBMs A form of neural network that learns to represent the input in a more effective manner and is stacked in numerous layers to create DBNs. Several applications, including recommender systems, anomaly detection, and image identification, have used DBNs.

RFID Wireless technology for tracking and recognizing items.

RFC It is a supervised machine learning algorithm used widely in classification and regression problems.

Real-time data – Data that is created, processed, stored, analyzed, and visualized within milliseconds.

# S

Spark It is designed to process data in real time and follows in-memory computing, which is much faster than Hadoop’s disk-based computing.

SKU Inventory items are identified by a unique code.

SWAP A quantum gate used to exchange the position of qubits.

SGD It is a very popular and common algorithm used in various machine learning algorithms and most importantly forms the basis of neural networks.

SVM It is one of the most popular supervised learning algorithms, which is used for classification as well as regression problems.

Supervised fine-tuning: Training a deep learning model with labeled data.

Structured dataset: A dataset that is organized in a structured format.

Semi-structured dataset: A dataset that is partially organized in a structured format.

Statistical analysis: Using statistical methods to analyze data and draw conclusions.

Sentic LSTM: An extension of LSTM that incorporates token-level memory and concept-level input through separate output gates, proposed by Ma et al. for e-commerce applications.
