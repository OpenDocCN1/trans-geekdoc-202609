## 8.8.2 High-Security Passwords

Each and every application, device, and software-based thing is secured with password options. Even appliances used in our homes may have password options to secure the device. Embedded systems are controlled by our smartphones, even if we are not in that location. In such cases, there may be a high grade of cyberattacks if there is no password to the system. So, for these reasons, there is a security password technique to secure the system each time. By setting passwords, the system may ask for the password each time while accessing. And each time, the system may check whether the password is valid or invalid. Only if the password is valid will the system allow the device to connect to the network, and if it is invalid, the system may give three retry permissions to the users to provide the valid password. If the retry permissions end, the system may block the connection to that device as well. So, it is the highest security technique to secure the devices effectively.

## 8.8.3 Multiple Wi-Fi Networks to the Devices

Commonly, we connect a single Wi-Fi to most of the devices in our home due to lower charges. But here, we are not identifying one of the most effective means. The main advantage of routers is creating the guest network, which has the ability to create more networks with the routers. This is a very useful and fast-accessing network. The main advantage of this guest network is the separation of the network paths of the connected devices. In our daily lives, we may connect to the Wi-Fi with different network connections. For example, consider that there is only a single Wi-Fi connected to all devices in our home. Now assume that our relatives or friends ask for our Wi-Fi network connection. In such situations, they may also connect to that single network available in our home, resulting in multiple devices working with the same network. In such cases, there may be a chance for network disconnection or misuse of our network, such as hacking, thereby creating more burden on the network and the main user. Due to these disadvantages, we should move to the guest networking system in which the routers support multiple Wi-Fi connections. By utilizing these advantages, we can easily solve the previously discussed problems. For example, assume that there are two networks in our home and all our home appliances are working with one network, while other guest users are connected to a separate network. In this case, there is no chance of hacking our home appliance network because the user-connected and device-connected networks vary, allowing the system to protect each device with its own protocols while connecting to the network.

## 8.8.4 UPDATING THE DEVICES

Like our smartphones, IoT devices may also have update options. In our smartphones, updating applications may be automated or manual depending on the model. However, with routers or network connectors, updating these devices will be visible to the main controller. The system may provide the option for users to update devices periodically. The main reason for updating is to increase system security, as each update includes security upgrades. The system automatically performs security work more effectively.

## 8.8.5 MULTILEVEL AUTHENTICATION

As we observe in real-time examples, when connecting devices such as mobiles to TVs or connecting applications to other devices, the system or application may require verification through OTP or scanners. This is to provide high security to the application or device. Similarly, when linking home appliance devices or applications, verification must be obtained through steps like OTP, sending a code, or using scanners. This verification system determines access rights to the application or device, and only through this authentication will the device be accepted to link with other networks.

## 8.11 CONCLUSION

Security issues are crucial due to the growing use of IoT devices in numerous applications and personal life. Many risks exist because of resource limitations and component heterogeneity in various IoT environments, which often lead to system failures. IoT security has been extensively researched, and this chapter discusses different types of attacks at different layers of the IoT. It covers security breaches across the three layers of the IoT and several IoT applications. Hacking is a severe security breach in the defense sector, and account hacking is common in the financial and banking sectors, where the highest level of protection is required. While everyone has access to basic linked home products every day, unauthorized access remains the biggest security vulnerability. Data interruption poses a serious issue in the healthcare sector. To address the security flaws mentioned above, several studies on IoT security are currently being conducted, but they must be strengthened because there will be millions of connected devices in the future.
