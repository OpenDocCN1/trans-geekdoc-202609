they may be exposed to security threats if the VMM is not appropriately

# ## 7.6.6 DECOUPLING ATTACKS ON VIRTUALIZATION PLATFORMS

Attacks on virtualization platforms that target the hypervisor, the layer of
software that governs and controls the virtual machines, are known as
_decoupling attacks_. In order to gain access to or control over data or
resources in other virtual machines using the same hypervisor, a decoupling
attack aims to undermine the isolation between virtual machines.
Hypervisor escape attacks seek to exit the virtual machine and gain access
to the hypervisor behind it, from which the attacker may be able to gain
access to other virtual machines or private information. In order to gain
access to or control over data or resources in other virtual machines
operating on the same hypervisor, these attacks take advantage of flaws in
the VMM. Only the physical machine with the system vulnerability is
susceptible in a typical working environment, and the attacker’s potential
targets are severely limited. By sharing information throughout the entire
system via a cloud computing virtualization platform, multiple rent users
can use a single virtual machine to exploit the current virtual vulnerability
platform.
