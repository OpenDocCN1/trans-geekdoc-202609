# 12.1 INTRODUCTION

Robotics is frequently described as an inertial navigation system which comprises a set of computer devices working together to complete a task. At the beginning, robotics was restricted to a few engineering and heavy- industry applications. Eventually, when robotics gained widespread acceptance across a variety of industries, numerous robot forms were used to complete different tasks [1], which increased the need for route planning procedures. The procedure of detecting the best way from a particular location to another in a search space is called path planning. Path planning improves the way by figuring out the easiest route connecting sending and target endpoints. Another definition of path planning includes the technique of decomposing a significant path transition into a series of repeated steps to produce precise moves to optimize particular objects. Robots that are independent in nature and employ [2] route-finding algorithms to establish passage endpoints across space might be considered as objects. A mobile robot is one that fits this description and can be utilized to resolve the difficulties in this domain. Path planning issues are significantly influenced by environmental conditions [3]. Path planning can be classified into dynamic and static classes depending on the description of the surrounding environment. In the first case, information about a search space with known geometry stationary barriers is provided, and an approach is then used to find the path.
