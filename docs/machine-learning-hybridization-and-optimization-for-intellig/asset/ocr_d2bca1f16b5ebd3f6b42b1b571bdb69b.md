The following cell in the sequence is selected based on which cell has the minimum values of x(v). # 12.4.7 RAPIDLY EXPLORING RANDOM TREE

In the rapidly exploring random tree (RRT) algorithm, points are randomly generated and connected to the closest available node. After several iterations, possible paths look like branches. In the field of path planning, it is a widely used approach. There should be an initial point and a target point specified in the workspace for the RRT technique to find a path. The system receives the starting point as input and then builds the tree until it reaches the last node or goal node. This approach is renowned for constructing its path finding tree. It begins by creating a random component in the workspace according to the distance between the nodes after the initial node.
