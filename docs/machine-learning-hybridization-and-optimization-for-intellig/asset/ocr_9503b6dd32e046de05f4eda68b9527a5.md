# # 6.4.1 Using the Concept of Transfer Learning in Medical Imaging

In the medical imaging field, transfer learning seems to be very successful in detecting breast lesions. Apart from this several other classifications that involve the lungs, the abdomen, the brain, Parkinson’s disease, and electroencephalogram (EEG) signals are also taking advantage of transfer learning. This transfer learning technique based on instance was proposed [109] for classifying chronic pulmonary disease. They identified this disease using CT scan images of the chest. The proposed method can be generalized across domains using different protocols or using scanners. Another innovative approach [83] to addressing the mass detection problem in mammogram images has been introduced. The solution for the above said problem has been achieved using CNN-based transfer learning techniques.

Classifying breast cancer was proposed by the authors [80] in which the convolutional neural network plays a major role in feature extraction. The SVM and RBF classifiers are adapted for tuning kernel. This can be achieved because of the algorithm’s flexibility in fitting the dataset adequately to the required dimension. As a result of combining CNN and RBF-based SVM, due to the hybridization process, a substantial increase in the results has been achieved. An intermediate domain to decrease the domain dissimilarity has been introduced among the target and the source networks. Multistage learning was introduced in [95] for classifying the last target DBT dataset using the knowledge of the initial source network along with the mammography images in the intermediate domain.

Using histopathologic images (HI) for detecting breast cancer has been proposed in [62]. To improve the support vector machine (SVM) classification accuracy to some extent, irrelevant patches from the images are removed before training the model. Different models [48] have been proposed to classify breast malignancy in histology images. The images have multiple cellular and nuclei configurations and are trained on AlexNet, ResNet, and GoogleNet models.

Domain adaptation–based joint knowledge transfer learning approaches for classifying and recognizing EEG signals have been proposed [132], in which the model is tested on Bonn images in addition to CHBMIT datasets
