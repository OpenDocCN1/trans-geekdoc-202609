# 16.2.2 RESULTS AND DISCUSSION

The initial objective of the project was to make an NFT-based obstacle course game. To do this, we were required to explore the Unreal Engine 5. We were completely new to this platform and did all the necessary research to build this game. We used VS Code to write the code and the Remix IDE for the NFTs. At the end of the project, we were successful in creating an obstacle course game and the NFT separately.

Some of the shortcomings observed in the design are the following:

+   Providing real-time rendering was a major bottleneck for game performance. The performance could not surpass the maximum limit of time required to produce one frame. The optimal frame rate varies depending on the player's PC configuration.

+   Certain gaming peripherals call for a certain frame rate to function properly. For instance, due to human brain physiology, virtual reality headsets demand 60 or more frames per second (FPS) or risk making gamers dizzy and nauseated.

# 16.3 DESIGN OF TURTLE SIDESTEP GAME

We propose a game called Turtle Sidestep. This is an NFT-based game that runs on the Polygon network of the Ethereum blockchain, powered by Chainlink's decentralized oracle. In order to dodge through the blocks, the turtle can move left or right using the arrow keys. The speed of the left and right movements of the turtle varies for each turtle NFT. The game is really fun to play, and it can get really challenging as the speed of the platforms increases with time. The player is rewarded with a new random turtle NFT every time a new checkpoint score is reached. The checkpoint score is at least 110 points higher than the player's previous high score. The higher the score achieved for a new checkpoint, the faster the NFT character the user receives as a reward. More speed allows the player to move faster through the platforms and reach high scores easily. Users would want to own NFTs with higher speed, and hence it acts as a selling point. The NFTs are dynamic. Every new turtle NFT has a unique name, a randomized image, and a random speed that ranges according to the score achieved by the user. The way we intend the random turtles to be generated is by using a custom API. The API will have four components: a head, a turtle shell, legs, and a tail.
