Every field is categorized into one of the four different types of learning, based on learning instances, based on learning features, based on learning parameters, and based on learning relations, respectively. The current work demonstrates the evolution of transfer learning and its importance in different fields like recommendation systems, healthcare systems, remote sensing, sentiment analysis, and signal processing.

An innovative deep learning model [30] for processing medical images has been proposed, in which the current model is based on a generative adversarial network, which is very successful for the encryption and decryption of medical images. The proposed work will transfer initially the original data corresponding to the medical domain from the source into the encrypted task that is at the target domain. This helps and guides the model to learn and realize the encryption process. The encoded section of the processed medical image is subsequently converted back to its original form, aiding in the process of image decryption. An interesting object is retrieved from the encrypted medical image using a ROI network. The model is evaluated on the chest X-ray dataset. A negative-resistant mechanism is proposed [126] that uses a fuzzy clustering model (FCM) along with a cross-domain latent space transfer learning technique for segmenting the brain CT images. However, the current clustering-based transfer learning method is not guaranteed to resist negative transfer.

A novel channel fusion (CF-Trans) technique has been implemented [22] where an additional domain is designed in the middle by combining the data manifolds of both the target and source domains. Initially, the information is sourced, followed by training on the intermediate middle network, and subsequently on the target domain. This process acts as a catalyst for facilitating positive knowledge transfer. A novel framework [1] for diagnosing COVID-19 has been introduced in which four popular uncertainty-aware networks –DenseNet121, ResNet50, InceptionResNetV2, and VGG16 – have been used for extracting the essential features from the computed tomography medical images and the chest X-ray medical images. The extracted features are then trained by multiple ML classifier algorithms along with other statistical techniques that have been used to detect and identify COVID-19 cases accurately.
