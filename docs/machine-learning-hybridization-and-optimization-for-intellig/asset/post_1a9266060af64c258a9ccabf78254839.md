## 18.2 LITERATURE SURVEY

The authors tried to predict the yield of rice using support vector regression (SVR) models with different kernels like linear, polynomial, and radial basis functions, considering India as a whole and the top five states that produce rice by taking into account influencing factors like the area under cultivation and production. Cross-validation and hyper-parameter optimization of various parameters led to selecting the best-fit models [15].

The authors in [16] suggest employing an enhanced version of the extreme learning machine to predict crop yield. The authors performed data preprocessing using the Kalman filter algorithm, retrieved some features using linear discriminant analysis, and predicted crop yield using the modified extreme learning machine. Rice crop yield has been forecasted based on geography, season, and cultivation area.

The primary goal of this research [17] is to use several machine learning approaches to forecast agricultural production. Among the classifier models utilized here, random forest has achieved the highest level of accuracy, followed by logistic regression and naive Bayes. By considering variables like temperature, rainfall, area, and other characteristics, the predictions provided by machine learning algorithms will assist farmers in choosing which crop to cultivate to induce the greatest yield.

Authors in [18] suggest centroid feeding-based K-means clustering for segmenting the disease section from a leaf picture to enable reliable feature extraction. By deleting green pixels from the illness part, they improve the output of the K-means clustering. Three categories of features—color, shape, and texture—are extracted. For multi-class classification, they used support vector machine (SVM).

Sharma et al. employed Convolution Neural Network (CNN) to characterize disease predictions in rice crop production. Diseased plants or crops are extremely harmful and can cause significant damage to yields if not treated quickly. Utilizing CNNs for early disease forecasts, the proposed model will improve decision-making regarding various diseases in rice crops, minimizing yield losses [19].

Three rice crop illnesses were classified and evaluated by Bashir et al. using an SVM-based method. Two steps make up the procedure: training and sickness prediction. The technique recognizes disease on the leaf using a trained classifier. The suggested research study maximizes the effectiveness of SVM parameters [20].

Fuzzy judgment algorithms were developed by Sabitha et al. using the information on sick leaf sections retrieved by threshold segmentation to identify various rust severity levels in images. These trials’ outcomes were decided using six different color and texture characteristics. Fuzzy algorithms were used to cluster plant diseases, and the study’s results outperformed more conventional approaches. This makes it the best feature extraction strategy, which can then be used to diagnose plant diseases from leaf photos. Additional disease classes or crop/disease classifications may be established to describe these capabilities [21].

Additionally, image processing and machine learning techniques were used to detect and categorize rice plant illnesses. SVM was utilized for classification, and K-means clustering was used to segment the damaged area of the rice leaves [22].

Authors Kussul et al. [23] published one of the earliest studies on crop categorization employing CNN classifiers to multisource, multi-temporal satellite images. The study used two CNNs—one 2D CNN for learning spatial features and one 1D CNN for learning spectral features—to classify crops, outperforming multilayer perceptron (MLP) and random forest (RF) classifiers with an overall classification accuracy of 94.6%.

Zhang et al. [24] used a patch-based deep learning CNN algorithm with a multi-temporal Landsat-like dataset, phenology data, and land-surface temperature to extract rice crops. The 2D CNN outperformed classic machine learning classifiers, support vector machines, and random forest, with an overall classification accuracy of 91.23% using multi-temporal spectral bands as input.

## 18.3 PROPOSED METHODOLOGY

### 18.3.1 Basic Approach

The basic approach to detecting the plant disease based on the images is shown in Figure 18.2. The process of getting images of infected leaves is referred to as *image acquisition*. A machine learning model, as a preprocessing step, is used to characterize the disease based on the attributes from the input images. Several processes of image processing include image background removal, noise removal, image scaling, picture segmentation, and image feature extraction. Certain image databases contain low-resolution images; therefore, image scaling is not always essential. Machine learning assessment criteria including accuracy, precision, recall, and confusion matrix are used to assess the system.
