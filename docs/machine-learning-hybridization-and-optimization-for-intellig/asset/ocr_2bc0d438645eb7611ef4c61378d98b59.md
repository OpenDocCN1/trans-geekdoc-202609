# 14.5 FUTURE SCOPE

When a number was drawn on the whiteboard, the model was able to identify it, and the result was superimposed on top of the handwritten character. Integration of voice feedback that can read aloud the detected digit to enable deaf and speech-impaired persons to understand the digit is a potential future effort and scope. Here, Python’s text-to-speech (TTS) commands may be used to have the text read aloud in English. Eventually, if a substantial number of large datasets are available, this can be incorporated into block chains. In future, the proposed model can be extended for the approaches [20, 21, 22, 23, 24] for an effective OCR-based handwritten digit recognition.
