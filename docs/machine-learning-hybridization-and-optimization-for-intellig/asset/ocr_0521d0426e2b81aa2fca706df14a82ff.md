# 11.3.5 Roberts Edge Detection

A 2D spatial gradient on an image can be measured quickly and easily with this operator. A spatial gradient zone that often coincides with an edge is therefore highlighted in this way. Operators typically use grayscale images to input and output data. An estimated absolute magnitude of the spatial gradient in the input image is represented by the pixel values at every position in the output image.

# 11.3.6 Sobel Operator

The Sobel operator detects edges of UAV_OPL images using a type of 2D derivative mask. The masks will be used as follows: The vertical mask will be created using a numpy array. The vertical mask will be used to create the horizontal mask. Then the mask is passed to the Sobel edge detection function as an argument, allowing us to use any mask. The data is then smoothed using the Gaussian blur function. Finally, the image and the vertical filter pass through the Sobel edge detection function. The horizontal mask is then used to apply the convolution. Simply transpose the mask by flipping it along the horizontal axis. Later, both vertical and horizontal edges are combined in extracting the features in terms of pixel values from UAV images.
