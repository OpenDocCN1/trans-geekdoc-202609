## 7.7.4 MONITORING THE SECURITY OF VIRTUAL MACHINES

To ensure the efficient operation of each virtual machine, VM security monitoring is necessary [21]. For monitoring the security of virtual machines, there are two extensively used designs. The first is the virtual machine self analysis–based monitor and control architecture, which embeds a monitoring module in the hypervisor and uses virtual machine introspection technology to identify other virtual machines. The other is a virtualization-based protection continuous monitoring architecture that attempts to incorporate hook functions into the observed VM in order to detect changes in system status before jumping to a longer period of time without a VM [22]. To guarantee that any known vulnerabilities are patched, virtual machines must be patched and updated on a regular basis. This can be achieved by putting in place an automatic patch management system that updates virtual machines as new security patches are released. Regular virtual machine backups can assist in guaranteeing that data is safeguarded in the case of a security breach or data loss. Both cloud-based backup services and virtual machine backup solutions can be used to perform backups.

## 7.7.6 PHYSICAL RESOURCE OVERLOADING

In a virtualized environment, physical resource overloading can be a major issue as it may result in the failure of virtual nodes or a decline in network performance below acceptable levels. When virtual machines are not provided with enough physical resources (such as CPU, memory, or storage) to meet their demands, this overloading can occur. Check the physical server and virtual machines’ resource utilization frequently to make sure they are being used effectively and to spot any potential bottlenecks [28]. Assign physical resources (such as CPU, memory, and storage) to virtual machines in a way that takes into account their individual requirements, and make sure there is enough overhead to manage peak loads. Utilize resource pools to dynamically manage and distribute resources depending on shifting workload demands [26].

## 7.8 CONCLUSION

The availability and adaptability of hardware resources are both increased and administrative costs are significantly decreased thanks to virtualization. Virtualization serves as the foundation of cloud computing technology. The numerous advantages of virtualization technology include better hardware usage and lower administrative expenses, but it also brings about fresh security threats that must be carefully controlled, especially in the context of cloud computing. The potential for a hypervisor-level attack, in which an attacker gains access to the hypervisor layer and is able to manage or modify several virtual machines running on the same host, is one of the main security dangers connected to virtualization. In addition to the possibility of service interruptions and downtime, this may lead to illegal access to important data and systems. The rapid and widespread usage of cloud computing has been hampered by security issues. Analyzing the key security concerns provided by virtualization technology is crucial in order to enhance the security measures of virtualization.
