+   (a) User privacy: Some procedures must be observed for the data controller to avoid monitoring a user’s use of the retrieval system. Improving user security and privacy at every level is now a top priority.

+   (b) Access control: The information service provider shall apply any accessibility management technique to protect data from unauthorized access and damage to a user’s private communication. Data must only be available to the people to whom it belongs.

+   (c) Identity management: This is a broad administrative topic that deals with system-wide item identification utilizing a number of ways and access control by coupling user rights and restrictions to the identified identity.

+   (d) Secure data communication: A significant component of IoT security is protecting data transmission. This entails preserving the identity of communication objects, ensuring the integrity and confidentiality of sent data, and validating communicating items.

+   (e) Resilience to attacks: In the open and interconnected IoT environment, attackers can quickly identify and take advantage of any vulnerabilities. Any defense mechanism for the system must prevent such assaults. In the event of a node failure, it must adjust and be protected against single points of failure. It should be able to defend itself from a variety of assaults.

+   (f) Trust: As trust is largely dependent on the quality of data, this is also one of the fundamental requirements for IoT. Gadget trust, institution trust, and data trust are the three components of trust.

# 20.5.2 RECENT ADVANCES IN IOT PRIVACY AND SECURITY IN START-UPS

If IoT alters how we live and work, it will depend on how we handle its security. Security issues plagued the conventional Internet, but the IoT environment created new security problems. It should be a primary goal to solve these issues and guarantee the security of IoT goods and services.
