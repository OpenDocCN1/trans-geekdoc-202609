# 8.8.4 UPDATING THE DEVICES

Like our smartphones, IoT devices may also have update options. In our smartphones, updating applications may be automated or manual depending on the model. However, with routers or network connectors, updating these devices will be visible to the main controller. The system may provide the option for users to update devices periodically. The main reason for updating is to increase system security, as each update includes security upgrades. The system automatically performs security work more effectively.

# 8.8.5 MULTILEVEL AUTHENTICATION

As we observe in real-time examples, when connecting devices such as mobiles to TVs or connecting applications to other devices, the system or application may require verification through OTP or scanners. This is to provide high security to the application or device. Similarly, when linking home appliance devices or applications, verification must be obtained through steps like OTP, sending a code, or using scanners. This verification system determines access rights to the application or device, and only through this authentication will the device be accepted to link with other networks.
