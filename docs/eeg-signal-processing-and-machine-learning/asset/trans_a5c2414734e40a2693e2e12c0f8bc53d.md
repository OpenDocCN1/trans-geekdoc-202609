

## 8.5 利用结构方程建模对连接性进行建模

正如文献[[33](#c08.xhtml#c8-bib-0033), [34](#c08.xhtml#c8-bib-0034)]所述，连接性可以被建模，且节点信号之间的协方差可与实际测量值进行比较。

结构方程建模（SEM）旨在建立一个先验连接模型，并旨在解答：(i) 变量信噪比（SNR）水平对SEM获得的模式连接性估计准确性的影响，(ii) 皮层区域间连接性估计获得良好准确性所需的数据量，(iii) 不精确的解剖模型构建在多大程度上降低SEM性能，以及当皮层区域间的连接未被正确假设时，其是否仍能对连接模式进行良好估计，(iv) 应避免哪类错误。SEM也已被用于对来自高分辨率（空间和时间双高分辨率）EEG数据的此类活动进行建模。解剖学和生理学约束已被利用将一个欠定方程组转化为一个定解方程组。

SEM由一组包含观测变量和定义变量间因果关系参数的线性结构方程组成[[35](#c08.xhtml#c8-bib-0035)]。变量可以是内生的（即在模型中独立于其他变量）或外生的（独立于模型本身）。考虑一组变量（表示为偏离其均值的偏差），具有N个观测值，对这些变量的SEM估计可表示为：

(8.23)
```
y = By + Γx + ξ
```

其中，**y**是*m* × 1因变量（内生变量）向量，**x**是*n* × 1自变量（外生变量）向量，**ξ**是*m* × 1方程误差向量（随机扰动），**B**（*m* × *m*）和**Γ**（*m* × *n*）分别为内生变量和外生变量的系数矩阵。假设**ξ**与数据不相关，**B**为零对角矩阵。若**z**为包含按以下顺序排列的所有*p = m + n*个外生和内生变量的向量：

(8.24)
```
z^T = [x1 ⋯ xn y1 ⋯ ym]
```

则观测协方差可表示为：

(8.25)
```
Σ_obs = (1/(N−1)) Z·Z^T
```

其中**Z**为**z**的*N*个观测值组成的矩阵。模型隐含的协方差矩阵可按如下方式获得：

(8.26)
```
Σ_mod = E[z z^T] = [ E[xx^T]  E[xy^T] ]
                    [ E[yx^T]  E[yy^T] ]
```

若*E*[**xx**^(*T*)] = Φ，则

(8.27)
```
E[xy^T] = ((I − B)^(−1) ΓΦ)^T
```

(8.28)
```
E[yx^T] = (I − B)^(−1) ΓΦ
```
