
睡眠呼吸暂停综合征（SAS）在30至60岁人群中的患病率较高，女性约为2%，男性约为4%，它会导致许多生理和心理问题，从而改变患者的生活方式[[19](#c12.xhtml#c12-bib-0019), [55](#c12.xhtml#c12-bib-0055)]。该综合征通常通过持续气道正压通气治疗或手术进行治疗。SAS是指导致夜间睡眠期间呼吸暂停的睡眠障碍。SAS可能由不同的解剖或生理因素引起。最近的研究将两种常见的SAS——中枢性睡眠呼吸暂停（CSA）和阻塞性睡眠呼吸暂停（OSA）进行了分类[[56](#c12.xhtml#c12-bib-0056)]。

在CSA的情况下，睡眠呼吸暂停源于中枢神经系统。如果在睡眠期间，上呼吸道和肺系统的呼吸暂停持续时间同时至少达到10秒，则可诊断为CSA。在OSA的情况下，呼吸暂停的原因是呼吸道阻塞。

使用标准多导睡眠图（PSG）一直是诊断和监测该疾病的常用方法。测量通常在夜间进行，以在有人值守的实验室环境中记录睡眠阶段、呼吸努力、口鼻气流、心电图发现和氧合血红蛋白饱和度参数[[20](#c12.xhtml#c12-bib-0020)]。然而，PSG不易获得，且昂贵且有创。因此，研究人员试图从上述较少数量的记录模态中提取必要的诊断信息。除了打鼾声和血氧水平外，脑电图（EEG）是用于评估睡眠呼吸暂停的另一种模态。

在最近对睡眠和睡眠呼吸暂停的评估中，EEG已被用于检测SAS。相干函数（CF）和互信息（MI）测度已被用作EEG信号特征，以将CSA和OSA与对照组区分开来。利用前馈神经网络（FFNN）对患者和健康志愿者记录的睡眠EEG序列进行分类，该网络包含两个隐藏层，并利用EEG记录中C3和C4导联之间的同步活动。在睡眠阶段中，第二阶段被用于测试。结果表明，夜间睡眠期间中枢EEG同步的程度与CSA和OSA等睡眠障碍密切相关。已证明MI和CF能协同提供有意义的信息以支持临床发现[[56](#c12.xhtml#c12-bib-0056)]。

除非研究其他生理症状，否则睡眠障碍和其他相关异常的诊断可能不完整。这些症状表现为其他生理和肺部信号，如呼吸气流、患者体位、肌电图（EMG）信号、睡眠图、SaO[2]水平、腹部努力和胸部努力，这些也可纳入分类系统中。

文献[[12](#c12.xhtml#c12-bib-0012)]建议并使用了一个简单的系统，利用从睡眠信号中提取的特征对呼吸暂停进行分类并检测SAS。该系统分三个阶段处理信号。在第一阶段，提取信号的相关特征，并基于可变长度的显著时间间隔进行分割。中间阶段包括为这些间隔分配合适的标签，并将这些符号信息源与上下文信息相结合，以构建识别临床显著事件所需的结构。最后，收集所有相关信息并建立一个基于规则的系统，以利用上述数据、提供归纳并产生一组结论。

在用于检测SAS的基于规则的系统中，从EEG信号中检测并表征两种大脑活动：节律性（α、β、θ和δ节律）和瞬态（K-复合波和睡眠纺锤波）[[57](#c12.xhtml#c12-bib-0057)]。测量幅度及其变化（演变），并将相应的数值与基于临床和启发式[[13](#c12.xhtml#c12-bib-0013)]标准的其他特征一起进行分类。

为了完善该分类器，使用电眼图（EOG）信号测量睡眠I期常见的慢速眼动和快速眼动（REM）。上述两种眼动的区分基于EOG信号的同步性、幅度和斜率[[12](#c12.xhtml#c12-bib-0012)]。

在另一种针对OSA患者睡眠分期的方法中，使用EEG特征进行分类，并与心肺特征的结果进行比较[[14](#c12.xhtml#c12-bib-0014)]。

Prochazka等人利用PSG采用机器学习方法研究睡眠异常。他们分析了33名健康个体、25名睡眠呼吸暂停个体以及18名同时患有睡眠呼吸暂停和不宁腿综合征个体的多导睡眠图记录[[58](#c12.xhtml#c12-bib-0058)]，记录均在夜间进行。他们使用的PSG截图可见于[图12.12](#c12.xhtml#c12-fig-0012)。

采用六阶Savitzky-Golay滤波器[[59](#c12.xhtml#c12-bib-0059)]，使用80个重叠帧来减少估计频谱分量的波动。随后，他们计算时域和小波域特征，并使用支持向量机（SVM）、k-近邻、决策树和神经网络（NN）进行分类。在几乎所有情况下，决策树和NN分类器在清醒期、REM期和所有非快速眼动期（即睡眠阶段）的分类中达到了最高准确率（在85.6%-97.5%之间）。他们还得出结论：随着年龄增长，清醒阶段的出现增加，而REM阶段的出现减少。

在另一种机器学习方法中，Jarchi等人利用PSG的心电图（ECG）和肌电图（EMG）成分来识别呼吸和运动相关的睡眠障碍[[60](#c12.xhtml#c12-bib-0060)]。他们利用熵和统计矩提取EMG特征，并利用同步挤压小波变换（SSWT）开发了一种迭代脉搏峰值检测算法，以从ECG中可靠地提取心率和呼吸相关特征。他们采用了一种非常全面的深度学习方法，结合循环神经网络（RNN）和深度神经网络（DNN），对健康受试者、OSA患者、不宁腿综合征患者以及同时患有OSA和腿综合征的患者进行准确分类。然而，该方法未利用EEG。

在另一项研究中，利用单通道ECG信号和呼吸相关调制分析了睡眠呼吸暂停和低通气[[61](#c12.xhtml#c12-bib-0061)]。在呼吸频率范围内使用SSWT分析信号。估计时频脊以提供瞬时呼吸频率的稳健估计，并检测有/无睡眠呼吸暂停/低通气事件的区域。利用逆同步挤压小波变换（ISSWT）进行信号重构，其中突出的峰值可识别并测量睡眠呼吸暂停/低通气事件的持续时间。
