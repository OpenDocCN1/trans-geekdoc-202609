

# 人工神经网络 (ANN)

人工神经网络 (ANN) 是另一种试图模仿人脑的决策系统。大脑包含数十亿个神经元，如 [图 7.8](#c07.xhtml#c7-fig-0008) 所示，它们彼此相连并提供了巨大的处理能力。此类网络中的神经元和层数越多，通常产生的处理能力和计算复杂度就越大。

ANN 是通过级联决策单元链（神经元后跟非线性函数和决策器）构建的监督非线性机器学习算法，用于识别非线性和复杂函数 [[8]](#c07.xhtml#c7-bib-0008)。在传感器网络中，由于学习网络权重的高计算需求和高管理开销，以分布式方式使用神经网络 (NN) 仍不普遍。然而，在集中式解决方案中，NN 可以一次性学习多个输出和决策边界 [[65]](#c07.xhtml#c7-bib-0065)，这使得它们适合使用同一模型解决多个网络挑战。

![图 7.8 表达 ANN 中神经元基本要素的生物神经元。](images/c07f008.gif)

**[图 7.8](#c07.xhtml#R_c7-fig-0008)** 表达 ANN 中神经元基本要素的生物神经元。

如 [图 7.9](#c07.xhtml#c7-fig-0009) 所示，每个 ANN 由输入层和输出层以及若干隐藏层组成。每层包含若干神经元，每个神经元对其输入执行非线性运算。硬限幅器（符号函数）、Sigmoid、指数和双曲正切 (`tanh`) 函数是最常用的。

使用 ANN 的主要挑战在于其优化（即链路权重的估计）以及层数和神经元数量的选择。反向传播算法常用于多层 ANN [[66](#c07.xhtml#c7-bib-0066), [67](#c07.xhtml#c7-bib-0067)]。这与自适应滤波器系数的优化非常相似，通过最小化实际标签（输出）与期望标签之间的误差，以获得最优的链路权重集。计算成本随神经元和层数的增加呈指数级增长。

![图 7.9 用于三维空间传感器网络节点定位的简单三层 NN。](images/c07f009.gif)

**[图 7.9](#c07.xhtml#R_c7-fig-0009)** 用于三维空间传感器网络节点定位的简单三层 NN。

在传感器网络节点定位的 ANN 应用示例中，输入变量是来自锚节点的接收信号的传播角度和距离测量值 [[68]](#c07.xhtml#c7-bib-0068)。此类测量值可能包括如 [图 7.9](#c07.xhtml#c7-fig-0009) 所示的接收信号强度指示 (RSSI)、到达时间 (TOA) 和到达时间差 (TDOA)。经过监督训练后，ANN 生成以三维空间矢量值坐标形式表示的估计节点位置。相关的 ANN 算法包括自组织映射（或 Kohonen 映射）和学习矢量量化 (LVQ)（有关这些方法的介绍请参见 [[69]](#c07.xhtml#c7-bib-0069) 及其参考文献）。除了函数估计外，NN 的一个重要应用在于大数据（高维和复杂数据集）的特征检测、分类和降维 [[70]](#c07.xhtml#c7-bib-0070)。

权重和偏置通常随机初始化，然后在训练期间通过反向传播迭代更新。使用反向传播算法训练 ANN 时，将每个输出神经元的输出与目标值（或簇中心）之间的误差进行比较，以找到各层之间的链路权重。对于 [图 7.9](#c07.xhtml#c7-fig-0009) 的双层网络，假设 `z[k]` 为神经元 `k` 的输出，`t[k]` 为目标值，代价函数定义为：

(7.37)
```
J(w) = 1/2 Σ_{k=1}^C (t_k - z_k)^2
```
其中 `C` 代表输出（类别）的数量。输出 `z[k]` 的估计是直接的；假设 ANN 的输入向量为 `x`，神经元 `k` 的输出为：

(7.38)
```
z_k = f(w_k^T f(w_j^T x))
    = f( Σ_{j=1}^{n1} w_kj f( Σ_{i=1}^{n2} w_ji x_i + w_j0 ) + w_k0 )
```

在上述公式 ([式 7.38](#c07.xhtml#c7-disp-0044)) 中，`n1` 和 `n2` 分别为第一层和第二层的神经元数量，`w_j0` 和 `w_k0` 为偏置值（未在 [图 7.8](#c07.xhtml#c7-fig-0008) 中显示），`f(y)` 为神经元激活函数，是一个连续函数，最能逼近硬限幅器，通常称为修正线性单元 (ReLU)。激活函数的一个常用示例是以下指数 (Sigmoid) 函数：

(7.39)
```
f(y) = 1 / (1 + e^{-y})
```
其曲线如 [图 7.10](#c07.xhtml#c7-fig-0010)a 所示。在 [图 7.10](#c07.xhtml#c7-fig-0010)b 中可以看到 ReLU 激活函数。如前所述，还可以使用许多其他函数。可使用不同的优化技术（如 MSE 最小化 [[71]](#c07.xhtml#c7-bib-0071)）来最小化 `J(w)` 并找到最优的 `w_ji` 和 `w_kj` 值。

ReLU 的优势在于它不会饱和。因此，它更适合多层网络，避免饱和误差在网络中传播。

## 7.3.9.1 深度神经网络

随着高性能计算机的发展以及对本地和远程内存集群及云的访问，深度神经网络 (DNN) 已广泛流行。这些分类器通常拥有更多的神经元和层、更强的学习能力、更好的可扩展性，以及其层上更进一步的处理能力。与过去不同，目前可使用 DNN 实时处理大数据。使用 DNN 的深度学习允许由多个处理层组成的计算模型学习具有多个抽象层次的数据表示。
