

该系统的性能已通过记录的 EEG 数据进行了考察，受试者要求为非吸烟者、睡眠模式正常、不从事夜班工作且不服用药物。正如[第 13.3.2 节](#c13.xhtml#c13-sec-0010)所述，在每次试验中，向受试者呈现一个由三个大写字母组成的水平数组，其中中央字母为目标字母，其余字母为伴随字母。受试者被指示：如果中央字母为 H，则尽快做出左手反应；如果中央字母为 S，则做出右手反应。字母数组保留在屏幕上，直到受试者给出反应，或在 1200 ms 后消失。受试者还被允许在初始反应后 500 ms 内纠正其错误反应。在 50% 的试验中，目标字母呈现于红色或绿色背景上，而在另一半试验中呈现于黑色背景上。在一半试验中，伴随字母与目标字母具有相同的类型和颜色（例如 HHH 或 SSS：相容），而在另一半试验中，它们与目标字母具有不同的类型和颜色（例如 SHS 或 HSH：不相容）。不同类型的刺激以相等的概率随机呈现。在三个字母出现前约 1000 ms，呈现一个前提示，持续 150 ms，指明目标字母的颜色（荷兰语的“红”或“绿”）或反应手（荷兰语的“左”或“右”）。手部提示和颜色提示以相等的概率随机呈现。在 80% 的试验中，提示是有效的。在每次试验过程中，一个注视标记（一个 0.5×0.5 cm 的星号）始终可见于屏幕上。

对某次试验的初始反应与下一次试验前提示呈现开始之间的间隔在 900 至 1100 ms 之间随机变化。受试者被指示快速准确地反应，并在任务执行期间尽量减少眼动和眨眼。任务包含一个不间断的两小时实验区块，随后是一个 80 次试验的练习区块。EEG 数据从 22 个头皮位置记录，并去除了眨眼伪迹。在一些使用该数据集的先前研究中，通过平均 ERP 检测到了 `P300` [[38]](#c13.xhtml#c13-bib-0038)。考虑到前半小时和第四个半小时各 50 次试验，将 `CRBPF` 应用于 `Fz` 和 `Pz` 通道。在第一个半小时受试者处于非疲劳状态，而在第四个半小时受试者处于疲劳状态。在这两种情况下，在疲劳前和疲劳期间，均使用 20 次试验的平均 ERP 来初始化 `CRBPF` 的粒子。`P3a` 和 `P3b` 变异性的跟踪结果如[图 13.3](#c13.xhtml#c13-fig-0003)所示。该图展示了疲劳状态前和期间 `P3a` 和 `P3b` 振幅、潜伏期和宽度的变异性。基于这些结果，可以得出一些关于精神疲劳对 `P300` 影响的结论。

一般来说，在其他一些关于精神疲劳的研究中 [[17](#c13.xhtml#c13-bib-0017), [32](#c13.xhtml#c13-bib-0032), [33](#c13.xhtml#c13-bib-0033), [39](#c13.xhtml#c13-bib-0039), [40](#c13.xhtml#c13-bib-0040)]，已有报告指出总体 `P300` 振幅下降及其潜伏期增加。但使用上述方法，我们可以将 `P300` 分离为其组成亚成分，并分别评估疲劳对每个亚成分的影响。根据结果，`P3a` 和 `P3b` 的潜伏期均随任务时间的推移而增加。在疲劳状态下，`P3a` 潜伏期的增加略多于 `P3b`。确实，`P3a` 振幅的下降幅度大于 `P3b`。`P3b` 的宽度在疲劳状态下保持近似恒定，而 `P3a` 的宽度则减小。`P3a` 振幅似乎随任务时间变小，而 `P3b` 振幅似乎略有增加。

在前半小时，观察到 `P3a` 和 `P3b` 头皮位置有明显差异；`P3a` 在 `Fz` 处更为突出，这符合预期。在最后半小时，`P3a` 在 `Pz` 处变得非常小，而 `P3b` 在该位置突出。`P3a` 与新奇性有关。然而，`P3a` 振幅随任务时间下降可能与对任务的练习或习惯化有关。因此，精神疲劳可能与 `P3a` 和 `P3b` 潜伏期的增加以及 `P3a` 振幅和宽度的减小有关。为了更详细地研究疲劳的影响，将该方法应用于更多信号以及额叶和枕叶头皮区域的更多电极将很有用。

尽管监测受精神疲劳影响的 ERP 是一种有价值的诊断工具，但它可能不够稳健，无法标记渐进变化的细节。这也适用于相干性和同步性的评估。然而，为了稳健性，如果能将这两种方法同时应用于从同一受试者记录的同一数据集，将极为有用。这需要一个合适的记录方案，能同时诱发 ERP 和脑节律的变化。为此，一种方法是在较长的时间间隔后刺激大脑，以允许大脑在每次刺激后完全稳定，并能够评估这些间隔内的同步性和相干性。

## 13.5 P3a 和 P3b 的分离

为了能够评估 `P3a` 和 `P3b` 的参数，可以尝试将它们作为两个不同的源成分进行分离。处理该问题最重要的一点在于：这两个成分源自同一激活，或者其中一个是另一个的结果。`P3a` 反映了大脑对新颖或显著刺激的非意向性反应，该反应与任务相关性无关 [[42](#c13.xhtml#c13-bib-0042), [43](#c13.xhtml#c13-bib-0043)]。前额叶、额叶和前颞叶脑区在产生 `P3a` 中起重要作用，使其呈现额-中分布 [[42]](#c13.xhtml#c13-bib-0042)。`P3b` 主要由后颞叶、顶叶和后扣带回机制产生，主要分布在中-顶区。此外，`P3a` 的潜伏期比 `P3b` 短，习惯化更快。
