
文献[53]的作者使用三种不同的方法估计了alpha频带的脑功能网络：偏导向相干性（`PDC`）、定向传递函数（`DTF`）和相位滞后指数（`PLI`）。然后，他们利用功能连接（22个判别性连接的值）作为特征来区分警觉和疲劳状态。他们报告的准确率高达84.7%。基于他们的成果，所选特征揭示了由精神疲劳引起的功能网络改变，特别是脑区间信息流的减少。他们还建立了一种特征排序策略，以尽量减少疲劳监测应用所需的电极数量。

## 13.8 用于疲劳评估的深度学习方法

机器学习方法最近转向深度学习网络，因为它们能够在利用丰富的内存和处理能力的同时，同步执行特征学习和分类。

文献[54]提出了一种基于深度学习的新型特征提取策略，用于对模拟驾驶实验中从六名健康志愿者记录的EEG信号进行驾驶疲劳分类。`PCA`和深度学习被整合到一个称为`PCA网络（PCANet）`[55]的模型中。`PCANet`由两个基于`PCA`的滤波层和一个输出层组成，输出层包括二值哈希和分块直方图的处理。`PCA`已被用于降维，使该方法变得可行，而深度网络用于特征学习。随后，使用`SVM`和`k`近邻（`KNN`）对特征进行分类，以识别脑状态。

`PCANet`广泛用于二维图像处理，如人脸识别[55]。在该研究中，每个优化的多通道EEG片段被视为一个二维数据矩阵（32×20）并输入`PCANet`进行特征提取。`PCANet`框图如图13.16所示。

使用`PCANet`，声称分类准确率高达95%[54]。在分析过程中，作者确定大脑的顶叶和枕叶与疲劳密切相关。

循环神经网络可用于从EEG信号中进行疲劳或嗜睡预测，以避免承受高强度脑力负荷人员（如驾驶员、飞行员或军人）发生事故。Liu等人[56]同时记录了EEG和EOG信号，提取了频谱特征，并采用循环模糊神经网络（`RFNN`）架构，在分类和预测驾驶员嗜睡时增强了实际EEG应用中的适应性。他们开发了一个复杂的网络，以捕捉由疲劳引起的功率谱中的微小变化。

文献[57]的作者结合提升策略和迁移学习方法，基于不同EEG频带的功率谱密度建立了一个驾驶嗜睡和警觉状态分类模型。该模型使用先前记录的数据进行训练，并由一小部分当前记录的数据进行微调（这是迁移学习中的常见做法）。他们声称，所提出的提升迁移学习方法显著优于`SVM`和`Adaboost`分类器。该过程被建议为一种适合警觉-疲劳分类的方法。

在Jeong等人[58]的一项更新研究中，报告了基于32通道EEG和5通道EOG信号对两种精神状态（即警觉和嗜睡状态）以及五个嗜睡等级的分类。然而，他们仅使用EEG对嗜睡等级进行分类，而将EOG作为参考，用于眼动相关基线的去除。他们还使用`ICA`进行眨眼伪迹去除。对于特征学习和分类，他们使用了深度时空卷积双向长短期记忆网络（`DSTCLN`）模型。`Bi`-`LSTM`网络被用于利用时间序列数据的长期依赖性问题。他们构建了一个分层卷积神经网络（`CNN`）架构以提取高层时空特征，并应用`Bi`-`LSTM`网络来利用EEG时间序列特征。

## 13.9 总结

正常脑节律和大脑对各种刺激的反应均受到精神疲劳引起的脑状态变化的影响。此外，在脑状态从警觉向疲劳及反之转变过程中，脑叶的同步性、相干性和连接性也会发生变化。在本章中，这些概念已被详细探讨，并详细解释了从EEG记录中提取、跟踪和分类精神疲劳指标的方法。未来可开展更多调查和实验，以进一步了解不同年龄受试者以及患有精神或躯体异常者的记忆与疲劳的相互影响。
