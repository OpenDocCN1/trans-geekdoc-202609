
在一种简单但不太准确的方法中，ICA被用于分离EEG源[\[33\]](#c10.xhtml#c10-bib-0033)。然后利用估计源与混合信号的相关值来建立混合介质的模型。接着使用LS方法，通过这些相关值的倒数来寻找源，即`d[ij] ≈ 1/(C[ij])^(0.5)`，其中`d[ij]`表示源`i`与电极`j`之间的距离，`C[ij]`表示它们信号的相关性。使用相关值使该方案成为一种基于逆问题定位的简单方法。该方法已被应用于分离和定位五名健康受试者和五名精神分裂症患者的P3a和P3b子成分的源。对ERP成分（如P300）及其组成子成分的研究在精神和心理障碍的分析、诊断和监测中非常重要。必须量化这些成分的源位置、振幅和潜伏期，并将其用于分类过程。[图10.4](#c10.xhtml#c10-fig-0004)展示了叠加在上述两种情况的两个MRI模板上的结果。可以看出，对于健康受试者，子成分在空间上是分开的；而对于精神分裂症患者，它们在几何上是混合的。

### 10.4.2 MUSIC算法

多信号分类（MUSIC）[\[34\]](#c10.xhtml#c10-bib-0034)已被用于利用EEG信号定位大脑内的磁偶极子\[[35](#c10.xhtml#c10-bib-0035)–[38](#c10.xhtml#c10-bib-0038)\]。在该算法的早期发展中，在一个三维头部体积内扫描单偶极子模型，并计算其在估计信号子空间上的投影[\[39\]](#c10.xhtml#c10-bib-0039)。为了定位源，用户必须在头部体积中搜索投影度量中的多个局部峰值。为了克服MUSIC算法的穷举搜索，开发了一种递归MUSIC算法[\[35\]](#c10.xhtml#c10-bib-0035)。按照这种方法，通过递归使用子空间估计，可以自动提取固定、旋转或同步偶极子源的位置。这种方法试图解决如何选择能在信号（EEG）空间上产生最佳投影的位置的问题。在无噪声且使用完美头部和传感器模型的情况下，正确位置处源的正向模型完全投影到信号子空间中。然而在实践中，由于噪声存在估计误差。在寻找上述问题的解决方案时，有两个假设可能并不总是成立：第一，数据受加性空间白噪声污染；第二，数据由一组异步偶极子源产生。这些假设在提出的递归MUSIC算法中被放宽了[\[35\]](#c10.xhtml#c10-bib-0035)。

用于脑源估计的原始MUSIC算法可描述如下。考虑将偶极子场传递到电极的头部模型为`A(ρ,θ)`，其中`ρ`和`θ`分别为偶极子位置和方向参数。观测值（EEG）`X`、模型`A`和源`S`之间的关系如下：

(10.7)
```
X = AS^T + E
```

其中`E`为噪声矩阵。目标是给定数据集`X`，估计参数`{ρ, θ, S}`。`X`的相关矩阵，即`R[x]`可分解为：

(10.8)
```
X_F = [Φ_s, Φ_e] [Λ + n_e σ_e^2 I  0; 0  n_e σ_e^2 I] [Φ_s, Φ_e]^T
```

或

(10.9)
```
R_x = Φ_s Λ_s Φ_s^T + Φ_e Λ_e Φ_e^T
```

其中`Λ_s = Λ + n_e σ_e^2 I`是结合了模型和噪声特征值的`m × m`对角矩阵，`Λ_e = n_e σ_e^2 I`是仅含噪声特征值的`(n[e] − m) × (n[e] − m)`对角矩阵。因此，信号子空间张成（`Φ[s]`）和仅噪声子空间张成（`Φ[e]`）是正交的。在实践中，使用数据的`T`个样本来估计上述参数，即
