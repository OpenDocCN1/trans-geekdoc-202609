### 2.2.4 信号调理

原始 EEG 信号的幅度约为 μV 量级，包含高达 300 Hz 的频率成分。为保留有效信息，信号在 ADC 之前必须进行放大，并在 ADC 之前或之后进行滤波，以降低噪声并使信号适合处理和可视化。滤波器的设计旨在不向信号引入任何变化或失真。通常使用截止频率低于 0.5 Hz 的高通滤波器来消除干扰性的极低频成分（如呼吸产生的成分）。反之，则使用截止频率约为 50–70 Hz 的低通滤波器来减轻高频噪声。通常需要零点频率为 50 Hz 的陷波滤波器，以确保完美抑制强烈的 50 Hz 电源干扰。在这种情况下，采样频率可以低至带宽的两倍，这也是大多数 EEG 系统的常用做法。EEG 记录常用的采样频率为每秒 100、250、500、1000 和 2000 个样本。主要伪迹可分为患者相关（生理性）伪迹和系统伪迹。患者相关或内部伪迹包括体动相关伪迹、肌电图 (EMG)、心电图 (ECG)（及脉搏）、眼电图 (EOG)、球istocardiogram（注：原文为 ballistocardiogram，此处保留原文或译为“弹道心动图”）和出汗。系统伪迹包括 50/60 Hz 电源干扰、阻抗波动、电缆缺陷、电子元件的电噪声以及电极不平衡阻抗。通常在预处理阶段，这些伪迹会被高度抑制，并恢复有效信息。一些去除 EEG 伪迹的方法将在本书相关章节中讨论。[图 2.11](#c02.xhtml#c2-fig-0011) 显示了一组受眨眼伪迹影响的正常 EEG 信号。同样，[图 2.12](#c02.xhtml#c2-fig-0012) 显示了一组多通道 EEG，枕区电极上清晰地出现了 ECG 信号。

## 2.3 睡眠

在正常睡眠的各个阶段，脑波会发生变化。入睡时，高频波形逐渐消失，连续慢波（delta 频带）随后出现纺锤波和 K 复合波，从睡眠第二阶段开始并延伸至第四阶段。在睡眠后期阶段，快速眼动 (REM) 开始并结束于人醒来之前。通过分析正常睡眠期间的 EEG 信号，可以观察并准确检测和自动评分所有这些阶段。

![Figure 2.11 A set of normal EEG signals affected by an eye‐blinking artefact.](images/c02f011.gif)

**[图 2.11](#c02.xhtml#R_c2-fig-0011)** 一组受眨眼伪迹影响的正常 EEG 信号。

反之，也存在受试者患有睡眠障碍的情况。这些包括阻塞性睡眠呼吸暂停 (OSA)、失眠（包括伴随性失眠和嗜睡症）、REM 睡眠行为障碍、昼夜节律睡眠障碍、非 24 小时睡眠-觉醒障碍、周期性肢体运动障碍 (PLMD)、轮班工作睡眠障碍、发作性睡病。睡眠障碍需要被诊断和治疗。

此类障碍通常通过心率和呼吸等其他记录模式来检测、监测或诊断。尽管如此，睡眠 EEG 在异常睡眠的检测或监测中的应用最近已成为一个研究课题。一些方法将在本书相关章节中讨论。

## 2.4 精神疲劳

精神疲劳通常是长时间认知负荷的结果，可在短期或长期内对人产生负面影响，并可能导致大脑无法执行其常规任务。精神疲劳主要影响大脑网络的功能，而非显著改变正常的大脑节律 [[21](#c02.xhtml#c2-bib-0021), [22](#c02.xhtml#c2-bib-0022)]。这些研究表明，当大脑处于精神疲劳状态时，左右脑叶之间的同步性降低，各脑叶之间的连接性也随之降低。

精神疲劳还会通过衰减和时移诱发电位 (ERP) 来削弱大脑对听觉、视觉和其他刺激的反应。研究表明，ERP 的振幅（特别是 P3b，即 P300 的一个亚成分）会降低，而 ERP 潜伏期（特别是 P3b）会随着精神疲劳的增加而延长 [[23](#c02.xhtml#c2-bib-0023)–[25](#c02.xhtml#c2-bib-0025)]。

本书专门用一章详细分析疲劳状态下大脑的 EEG。

## 2.5 情绪

大脑右半球与情绪相关。在情绪激动状态下测量的侧向化电生理参数发现，在回忆与愤怒或放松相关的过去事件时，EEG 显示出相对激活（通过 alpha 功率降低来测量）。在对视觉材料的自我报告情绪反应中也获得了类似发现 [[26](#c02.xhtml#c2-bib-0026)]。其他实验研究证实了当参与者被要求产生情绪意象时 [[27](#c02.xhtml#c2-bib-0027)]，以及在催眠诱导的抑郁状态下 [[28](#c02.xhtml#c2-bib-0028)]，右半球相对激活。更近期的定量 EEG 研究证明了大脑激活幅度与情绪唤醒强度之间存在可靠关系 [[29](#c02.xhtml#c2-bib-0029)]。在相关研究中，情绪记忆的年代久远程度与使用定量 EEG 测得的激活幅度相关 [[30](#c02.xhtml#c2-bib-0030)]。大多数这些研究均基于侧脑叶活动的不对称性得出结论 [[31](#c02.xhtml#c2-bib-0031)]。

或许，支持效价假说最有力的证据来自大量 EEG 研究，这些研究将相对增加的左半球活动与积极情绪状态相关联，将相对增加的右半球活动与消极情绪状态相关联，如文献 [[32](#c02.xhtml#c2-bib-0032)] 所示。额叶 EEG 在积极情绪反应期间显示相对左半球活动，而在消极情绪反应期间则显示相反模式。

一些近期的机器学习应用 [[33](#c02.xhtml#c2-bib-0033)] 表明，EEG 在 beta 频带与 theta 频带的功率比及其不对称性与情绪变化相关。
