
# 迷走神经刺激与神经技术项目

迷走神经刺激涉及向迷走神经传递电脉冲。抑郁症、炎症、代谢综合征和心脏病之间的关系可能由迷走神经介导。迷走神经刺激有时用于治疗癫痫和抑郁症。

在日本，一个名为“疾病研究整合神经技术脑图谱”的脑图谱项目于2014年启动（[http://www.brainminds.jp](http://www.brainminds.jp/)）。

在美国，DARPA资助并展示了依赖手术植入电极与中枢或周围神经系统接口的先进神经技术（[https://www.darpa.mil/news‐events/2019‐05‐20](https://www.darpa.mil/news-events/2019-05-20)）。该机构展示了诸如神经控制假肢、恢复假肢使用者的触觉、缓解原本难治的神经精神疾病（如抑郁症），以及改善记忆形成和回忆等成就。由于手术固有的风险，这些技术迄今为止仅限于有临床需求的志愿者使用，包括军事服务人员。目前，有六个团队正在采用一系列方法，利用光学、声学和电磁学来记录神经活动和/或以高速和高分辨率向大脑发送信号。采取了有创和无创两种方法。这些团队包括：

*   **Battelle团队**，旨在开发一种微创接口系统，将外部收发器与电磁纳米换能器配对，后者可非手术递送至目标神经元。纳米换能器将把神经元的电信号转换为可被外部收发器记录和处理的磁信号，反之亦然，以实现双向通信。

*   **卡内基梅隆大学团队**，旨在开发一种完全无创的设备，采用声光方法记录大脑活动，并利用干涉电场向特定神经元写入信息。该团队将利用超声波引导光线进出大脑以检测神经活动。其写入方法利用神经元对电场的非线性响应，实现特定细胞类型的局部刺激。

*   **约翰霍普金斯大学应用物理实验室团队**，旨在开发一种完全无创的相干光学系统，用于记录大脑活动。该系统将直接测量与神经活动相关的神经组织光程长度变化。

*   **PARC团队**，旨在开发一种完全无创的声磁设备，用于向大脑写入信息。其方法将超声波与磁场相结合，产生局部电流以实现神经调节。这种混合方法有望实现大脑深处的局部神经调节。

*   **莱斯大学团队**，旨在开发一种微创的双向系统，用于记录和写入大脑。对于记录功能，接口将使用漫射光学断层扫描，通过测量神经组织中的光散射来推断神经活动。为了实现写入功能，该团队将采用磁遗传学方法，使神经元对磁场敏感。

*   **Teledyne团队**，旨在开发一种完全无创的集成设备，使用微型光学泵磁力计来检测与神经活动相关的微小局部磁场。该团队将使用聚焦超声向神经元写入信号。

此外，美国还有21家以上正在运营的公司和初创企业涉及脑机接口、植入物和神经假体领域。

## 17.12 用于BCI的联合EEG与其他脑扫描模态

通常，混合BCI（如EEG-功能性近红外光谱（fNIRS）[[158]](#c17.xhtml#c17-bib-0158)、[[159]](#c17.xhtml#c17-bib-0159)或EEG-fMRI[[160]](#c17.xhtml#c17-bib-0160)）提供的分类准确率高于单模态BCI[[161]](#c17.xhtml#c17-bib-0161)、[[162]](#c17.xhtml#c17-bib-0162)。这主要归因于EEG的低空间分辨率以及fMRI等成像模态的低时间分辨率或NIRS的低成像深度。最近的MEG技术也因MEG对深度和电导率的更高灵敏度，允许进行联合EEG-MEG。

### 用于BCI的联合EEG-fMRI

尽管单独使用fMRI或将其与EEG联用对于现实生活中的BCI应用并不实用，但已有一些实验旨在利用fMRI的高空间分辨率来提升通常仅使用EEG所能达到的BCI性能。文献[[149]](#c17.xhtml#c17-bib-0149)提出了一种新的张量分解方法，用于将fMRI的能力迁移至EEG，该方法包括同步EEG-fMRI会话以寻找从EEG到fMRI的映射，随后仅使用EEG数据进行BCI运行，但由先前识别出的映射获得的类fMRI特征驱动[[163]](#c17.xhtml#c17-bib-0163)。

在他们的方法中，他们使用基于Tucker模型的正交张量分解作为EEG子空间分解和fMRI去卷积的方法。然后，他们设计了一个高阶偏最小二乘（HOPLS）模型，用于发现EEG和去卷积fMRI的潜在子空间表示之间的关系[[149]](#c17.xhtml#c17-bib-0149)。

他们的实验涉及一个开环基于P300的拼写范式，其中脑活动可通过从同步采集的EEG-fMRI数据中提取的潜在特征进行解码。已证明使用EEG-fMRI数据的字母解码准确率优于仅使用EEG获得的准确率。

这种数据驱动方法有望发现先前使用模型驱动方法未探索的电生理和血流动力学神经活动特征之间的潜在联系，并有望作为一种多模态策略的模板，其中跨模态EEG-fMRI交互被利用于单模态EEG系统的操作。

### 17.12.1 用于BCI的联合EEG-fNIRS

NIRS对电噪声相对鲁棒，且具有良好的空间分辨率。为了缓解ITR退化，文献[[159]](#c17.xhtml#c17-bib-0159)的作者提出了一种由直观心智任务操作的同步EEG-fNIRS，例如在短试验长度（5秒）内执行心算（MA）和词链（WC）任务。受试者在无需预先训练的情况下执行MA和WC任务，并保持放松状态（基线；BL）。ITR（比特/秒）定义为：

[(17.24)](#c17.xhtml#R_c17-disp-0025)

```
ITR = m × (log₂N + P log₂P + (1 − P) log₂((1 − P)/(N − 1)))
```
