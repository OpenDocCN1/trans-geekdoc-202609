

# 张量分解及其应用

张量是一个多维数组。更正式地说，N 阶或 N 阶张量是 N 个向量空间的张量积中的一个元素，每个向量空间都有自己的坐标系。一阶张量是向量，二阶张量是矩阵，三阶张量有三个索引。三阶或更高阶的张量称为高阶张量。张量的阶数是维度的数量，也称为方式或模式。张量分解已广泛应用于信号处理（如文献 [41]–[50]）和神经科学（如文献 [51]–[60], [96]）。[图 5.7](#c05.xhtml#c5-fig-0007) 说明了这一概念。

高阶张量分解在化学计量学、信号处理、通信、线性代数、计算机视觉、数据挖掘、神经科学和图分析中均有应用。用于检测、分离、定位、去噪和跟踪。传统上，有两种特定的张量分解可被视为矩阵 SVD 的高阶扩展，即规范分解 (CANDECOMP)/PARAFAC (CP) 张量分解。

从数学角度来看，主要有两种通用的张量分解方法。第一种是 Tucker 模型，它试图将一个三路张量分解为一个较小的张量（核心张量）和其他三个因子/矩阵。该模型不是唯一的，因为核心张量有多种组织方式。第二种是具有超对角核心张量的 PARAFAC 张量模型。由于这种核心张量没有其他变体，PARAFAC 分解是唯一的，这意味着对于正交或独立源，混合信号可以无歧义地分解为其组成源。[图 5.8](#c05.xhtml#c5-fig-0008) 表示了上述模型。此外，PARAFAC 将张量分解为秩一张量之和，而 Tucker 分解是主成分分析 (PCA) 的高阶形式。

还有许多其他张量分解，包括 INDSCAL、PARAFAC2、CANDELINC、DEDICOM 和 PARATUCK2，以及它们所有的非负变体 [[61]](#c05.xhtml#c5-bib-0061)。N-way Toolbox、Tensor Toolbox 和 Multilinear Engine 是用于处理张量的软件包示例。

最近，张量分解已广泛用于瞬时混合和卷积混合的盲源分离 (BSS)。为了能从张量建模中受益，我们需要从二维多通道测量数据中构建一个张量。例如，可以通过首先将数据变换到时频 (TF) 域，然后引入空间（传感器的几何位置）维度，来构建一个时空频张量。对于 EEG 或脑磁图 (MEG) 的分析，这可以如 [图 5.9](#c05.xhtml#c5-fig-0009) 所示进行说明。

一般来说，可以选择数据变化显著且符合预期的任何其他维度。例如，为了利用非平稳性，其中一个维度可以用信号段编号来表示。这使得数据的统计变化能够在张量模型中得到有效跟踪。

**图 5.9** 一组多通道 EEG 信号的张量表示。(a) 时域表示。(b) 每个电极信号的时频表示。(c) 构建的张量。

文献 [[60]](#c05.xhtml#c5-bib-0060) 提出了一种基于 EEG 新颖 STF 模型和鲁棒最小方差波束成形器 (RMVB) 去除 EEG 信号中眼动伪迹的方法。在该方法中，为了去除伪迹，RMVB 获得了先验信息，即对应于眼动点源的导向矢量的估计。去伪迹后的 EEG 通过通量消除法重建。先验知识，即对应于眼动因子空间分布的矢量，是利用 PARAFAC 方法提供的 EEG STF 模型来识别的。为了降低使用三路 PARAFAC 估计 STF 模型时存在的计算复杂度，将时域细分为若干段，然后建立四路数组，利用四路 PARAFAC 估计数据的空间-时间-频率-时间/段 (STF-TS) 模型。STF 模型的正确因子数已通过一种基于新颖核心一致性诊断 (CORCONDIA) 的度量得到有效估计。

随后，STF-TS 模型被证明能以显著更低的计算成本紧密逼近经典 STF 模型。结果表明，该算法能有效地从原始 EEG 测量中识别并去除眼动 (EB) 伪迹。采用这种方法，[图 5.10](#c05.xhtml#c5-fig-0010) 显示了应用 PARAFAC 后眼动的空间、时间和频率特征。[图 5.11](#c05.xhtml#c5-fig-0011) 显示了应用 STF-TS 方法后恢复的 EEG。正如 [5.8.2 节](#c05.xhtml#c5-sec-0021) 所讨论的，该方法还通过分割利用了数据的非平稳性。

上述方法表明，PARAFAC 可以与另一种模态相结合，主要是为了智能地选择和提取感兴趣的原子（源）。

PARAFAC 的更多应用，如文献 [[59]](#c05.xhtml#c5-bib-0059) 中与 BCI 相关的内容，将在本书的其他章节中解释。
