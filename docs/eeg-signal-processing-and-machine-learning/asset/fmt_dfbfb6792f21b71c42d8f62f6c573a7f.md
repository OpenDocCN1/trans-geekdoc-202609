
#### 4.5.1.5 Wavelet Transform Using Fourier Transform

Consider the scalar products `c[0](k) = ⟨f(t). φ(t − k)⟩` for continuous wavelets. If `φ(t)` is band limited to half of the sampling frequency, the data are correctly sampled. The data at the resolution `j = 1` are:

(4.43)
```
c₁(k) = ⟨f(t). ½ φ(t/2 − k)⟩
```

and we can compute the set `c[1](k)` from `c[0](k)` with a discrete‐time filter with frequency response `H(ω)`:

(4.44)
```
H(ω) = { Φ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

and for `∀ ω` and `∀ integer m`

(4.45)
```
H(ω + m) = H(ω)
```

Therefore, an estimate of the coefficients is:

(4.46)
```
C_{j+1}(ω) = C_j(ω) H(2^j ω)
```

The cut‐off frequency is reduced by a factor 2 at each step, allowing a reduction of the number of samples by this factor. The wavelet coefficients at the scale `j + 1` are:

(4.47)
```
w_{j+1} = ⟨f(t), 2^{-(j+1)} ψ(2^{-(j+1)} t − k)⟩
```

and they can be computed directly from `C[j]` by:

(4.48)
```
W_{j+1}(ω) = C_j(ω) G(2^j ω)
```

where `G` is the following discrete‐time filter:

(4.49)
```
G(ω) = { Ψ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

The relations [(4.34)](#c04.xhtml#c4-disp-0034) and [(4.35)](#c04.xhtml#c4-disp-0035) have to be also satisfied. A large class of compact wavelet functions can be used. Many sets of filters were proposed, especially for coding [[22]](#c04.xhtml#c4-bib-0022). It was shown that the choice of these filters must be guided by the regularity of the scaling and the wavelet functions. The complexity is proportional to `N`. The algorithm provides a pyramid of `N` elements.
