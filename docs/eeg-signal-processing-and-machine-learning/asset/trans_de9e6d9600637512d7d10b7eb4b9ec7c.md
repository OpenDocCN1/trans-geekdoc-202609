重要性采样权重指示了相应粒子的重要性水平。相对较小的权重意味着该采样点远离后验分布的主体，且在最终估计中的贡献较小。这样的粒子被称为无效粒子。如果无效粒子的数量增加，则对状态估计有贡献的粒子数量减少，因此滤波过程的性能会恶化。通过重采样可以避免退化现象。在重采样过程中，权重较小的粒子被淘汰，而权重较大的粒子被复制。
