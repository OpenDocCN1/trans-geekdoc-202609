## 5.9 用于欠定源分离的张量分解

[第 5.4 节](#c05.xhtml#c5-sec-0011)中的 SCA 方法利用构成源的稀疏性对信号进行分组和分离。此外，这些方法的主要假设是：在每个时间瞬间，只有一个信号具有非零振幅。尽管在某些具有稀疏源的应用中成功实现了混合通道的识别，但在许多情况下，原始源信号的重构要么困难，要么不够准确。

在最近为欠定或稀疏源分离开发的张量分解方法中（如文献 [[41](#c05.xhtml#c5-bib-0041), [90](#c05.xhtml#c5-bib-0090)–[93](#c05.xhtml#c5-bib-0093)]），利用了两个主要概念。第一个特性是源的稀疏性，这与 SCA 方法相同；第二个特性是张量分解相对于其他分离方法的主要优势之一，即张量的秩可以高于相关矩阵的秩。因此，预期可分离源的最大数量会随着张量秩的增加而增加。此外，在某些应用中（如文献 [[91]](#c05.xhtml#c5-bib-0091)），提出了稀疏事件的概念。这意味着在每个时间段内，最多有一定数量的源可以是活跃的。这种方法也可视为第节所述 SCA 方法的推广，即我们可以有多个源同时活跃，且一个源的活跃持续时间可以超过一个采样周期。

因此，张量分解技术，特别是 PARAFAC [[44](#c05.xhtml#c5-bib-0044), [92](#c05.xhtml#c5-bib-0092)]，已被用于求解 UBI 问题，即使源是非稀疏或完全活跃的（例如 `k[a] ≤ N[s]`）[[88]](#c05.xhtml#c5-bib-0088)。随后，开发了基于二阶和高阶统计量的方法，利用一系列对称方阵的联合/同步对角化来求解 UBI 问题，例如欠定混合的二阶盲识别 (SOBIUM) [[90]](#c05.xhtml#c5-bib-0090) 和基于四阶累积量的欠定混合盲识别（即 FOOBI）[[41]](#c05.xhtml#c5-bib-0041)。SOBIUM 方法处理不同片段的协方差矩阵，并试图将 UBI 问题转化为一个具有两个相同因子的 PARAFAC 问题，称为标度个体差异 (INDSCAL) [[43]](#c05.xhtml#c5-bib-0043)，进而转化为一些精确定 Hermitian 矩阵的联合分块对角化。[表 5.1](#c05.xhtml#c5-tbl-0001) 显示了 SOBIUM 和 FOOBI 可分离源的最大数量上限。

在文献 [[91]](#c05.xhtml#c5-bib-0091) 中，开发了一种基于张量分解的 `k[a]`‐SCA 方法（在文献 [[28]](#c05.xhtml#c5-bib-0028) 中称为 `k`‐SCA），用于求解 UBSS 尤其是 UBI 问题。每个信号片段中认为有 `k[a]` 个源是活跃的。与第节介绍的 `k[a]`‐SCA 方法类似，`k[a]` 必须满足 `k[a] ≤ N[x] – 1`。然而，在该方法中，引入并考虑了稀疏事件（即在特定持续时间的某些信号片段内有限个源处于活跃状态），而不是稀疏信号（即在每个瞬间有限个信号处于活跃状态）。因此，首先估计每个信号片段中活跃源的数量。此类方法起作用的必要条件是拥有足够数量的片段，使每个源在某些片段中处于活跃状态。然后利用稀疏活跃源的片段执行 UBI。

**表 5.1** 使用不同基于张量的欠定源分离方法可分离的最大源数。

| `N[x]` `N[s]` | | 2 | | 3 | | 4 | | 5 | | 6 | | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SOBIUM (实数) | | 2 | | 4 | | 6 | | 10 | | 15 | | 20 |

该算法称为（欠定正交模型 BSS），用于求解类似 (7.51) 的问题，步骤如下 [[91]](#c05.xhtml#c5-bib-0091)：

*   **步骤 1**：随机初始化所有模型参数；`iter` = 1。
*   **步骤 2**：对所有 `k = 1, …, K`，使用 `P[k] = U[k] V[k]^T` 估计 `P[k]`。
*   **步骤 3**：使用以下公式估计 `A`：
    ```
    A = (Σ_{k=1}^K X[k]^T P[k] D[k]) (Σ_{k=1}^K D[k]^2)^†
    ```
*   **步骤 4**：对所有 `k = 1, …, K`，使用以下公式估计 `D[k]`：
    ```
    D[k] ← λ D̄[k] + (1 − λ) D[k]
    ```
