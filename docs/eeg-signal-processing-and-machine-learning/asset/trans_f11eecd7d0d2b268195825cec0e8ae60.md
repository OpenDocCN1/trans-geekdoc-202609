

## 4.4 信号分割

通常需要将 EEG 信号标记为具有相似特征的片段，这对临床医生和神经生理学家的评估尤为重要。在每个片段内，信号被视为统计平稳的，通常具有相似的时间和频率统计特性。例如，癫痫患者的 EEG 记录可分为三个片段：发作前期、发作期和发作后期。每个片段的持续时间可能不同。[图 4.1](#c04.xhtml#c4-fig-0001) 显示了一个包含上述所有片段的 EEG 序列。

![图 4.1 包含发作前期、发作期和发作后期三个片段的强直-阵挛性癫痫发作 EEG 信号集。](images/c04f001.gif)

[**图 4.1**](#c04.xhtml#R_c4-fig-0001) 包含发作前期、发作期和发作后期三个片段的强直-阵挛性癫痫发作 EEG 信号集。

在 EEG 分割中，可利用信号的时间或频率特性。这最终导致一种不相似度度量，记为 `d(m)`，用于相邻 EEG 帧之间，其中 `m` 是为帧编号的整数值，差值在 `m` 帧和 `(m − 1)`th（连续）信号帧之间计算。若 `d(m) > η[T]`，则两个不同片段的边界定义为 `m` 帧和 `(m − 1)`th 帧之间的边界，其中 `η[T]` 是经验阈值。在专家临床医生的帮助下，通过突出并有效利用信号中的诊断信息，可以实现高效分割。然而，并不总能接触到此类专家；因此，需要算法方法。

基于信号处理基础，可定义多种不同的不相似度度量。一种准则基于片段 `m` 的自相关函数，定义为：

**公式 (4.7)**
```
r_x(k, m) = E[x(n, m) x(n + k, m)]
```

假设时间区间为 `n, n + 1, …, n + (N − 1)`，第 `m` 个长度为 `N` 的帧的自相关函数可近似为：

**公式 (4.8)**
```
r̂_x(k, m) = {
    (1/N) Σ_{l=0}^{N-1-k} x(l + m + k) x(l + m),  k = 0, …, N-1
    0,                                             k = N, N+1, …
}
```

然后准则设定为：

**公式 (4.9)**
```
d_1(m) = [ Σ_{k=-∞}^{∞} (r̂_x(k, m) - r̂_x(k, m-1))^2 ] / [ r̂_x(0, m) r̂_x(0, m-1) ]
```
