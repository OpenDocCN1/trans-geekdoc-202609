
## 单次试验ERP分析中的小波网络应用

作为示例，单次试验ERP已使用小波网络（WN）进行分析，并将开发的算法应用于ADHD的研究[\[52\]](#c09.xhtml#c9-bib-0052)。ADHD是一种精神和神经行为障碍，其特征是显著的注意力不集中或多动和冲动行为。在这项工作中，假设ERP和背景EEG是相关的，即描述刺激前信号的参数不适用于刺激后时期[\[55\]](#c09.xhtml#c9-bib-0055)。

在WN拓扑中，他们将ERP $\hat{s}(t)$ 表示为*K*个修正小波函数 $h(n)$ 的线性组合：

```
(9.27) $\hat{s}(n) = \sum_{k=1}^{K} w_k h\left(\frac{n - b_k}{a_k}\right)$
```

其中 $b_k$、$a_k$ 和 $w_k$ 分别是位移、尺度和权重参数，$s(n)$ 称为小波节点。[图 9.8](#c09.xhtml#c9-fig-0008) 显示了用于信号表示的WN拓扑。在该图中，对于Morlet小波，$\psi_k = h((u - b_k)/a_k)$：

```
(9.28) $\hat{s}(n) = \sum_{k=1}^{K} w_{1,k} \cos\left(\omega_k \frac{n - b_k}{a_k}\right) + w_{2,k} \sin\left(\omega_k \frac{n - b_k}{a_k}\right) \exp\left[-\frac{1}{2}\left(\frac{n - b_k}{a_k}\right)^2\right]$
```

在这个方程中，每个频率参数 $\omega_k$ 和相应的尺度参数 $a_k$ 定义了一个节点频率 $f_k = \omega_k / 2\pi a_k$，并在学习过程中进行优化。

在上述方法中，WN被视为一个单隐藏层感知机，其神经元激活函数[\[56\]](#c09.xhtml#c9-bib-0056)由小波函数定义。因此，使用著名的反向传播神经网络算法[\[57\]](#c09.xhtml#c9-bib-0057)同时更新WN参数（即节点 $k$ 的 $w_{1,k}$、$w_{2,k}$、$\omega_k$、$a_k$ 和 $b_k$）。最小化是在节点输出与使用自回归移动平均（ARMA）建模获得的残差误差的带通滤波版本之间的误差上执行的。带通滤波器和锥形时间窗口的应用确保了所需范围被强调，并且节点看到其在时频平面上的特定部分[\[52\]](#c09.xhtml#c9-bib-0052)。据报道，对于ADHD的研究，这种方法能够在传统时间平均方法因该成分位置变化而失效的地方检测到N100 ERP成分。

### 9.3.5 卡尔曼滤波器的应用

在ERP信号的线性时不变滤波中，主要问题是信号和噪声频率成分高度重叠。另一个问题是ERP信号是瞬态的，其频率成分可能不落在某个特定范围内。对于大多数噪声去除情况，在均方（MS）意义上提供最优解的维纳滤波不适用于ERP等非平稳信号。

假设ERP信号是动态缓慢变化的过程，未来的实现可以从过去的实现中预测。这些变化可以使用状态空间模型来研究。卡尔曼滤波和通用观测模型已被用于去噪ERP信号[\[59\]](#c09.xhtml#c9-bib-0059)。考虑刺激时刻 $n$ 的单通道EEG观测向量 $\mathbf{x}[n] = [x[n](1), x[n](2), \dots, x[n](N)]^T$，目标是估计一个长度为 $k$ 的参数向量 $\boldsymbol{\theta}[n]$，使得从 $\mathbf{x}[n]$ 到 $\boldsymbol{\theta}[n]$ 的映射（最好）是线性映射。一个最优估计器 $\hat{\boldsymbol{\theta}}_{n,\text{opt}}$，它最小化 $E[\|\hat{\boldsymbol{\theta}}_n - \boldsymbol{\theta}_n\|^2]$，是 $\hat{\boldsymbol{\theta}}_{n,\text{opt}} = E[\boldsymbol{\theta}_n \mid \mathbf{x}_n]$，并且可以证明为：
