## 12.3 昼夜节律的影响

在24小时内发生的生物学变化称为昼夜节律。昼夜节律由人体的生物钟控制。许多身体机能都遵循生物钟，但睡眠和觉醒构成了最重要的昼夜节律。昼夜睡眠节律是由下丘脑调节的几种身体节律之一。

光线直接影响昼夜睡眠节律。光线被称为`zeitgeber`，这是一个德语词，意为“时间给予者”，因为它设定了生物钟。

体温周期也受下丘脑控制。白天体温升高，夜间则观察到下降。体温的峰值和谷值被认为反映了睡眠节律。晚上警觉性较高的人（即夜猫子型）在傍晚时分出现体温峰值，而那些清晨最清醒的人（即早起鸟型）则在清晨出现体温峰值。

褪黑素（由大脑松果体产生的一种化学物质，也是一种与睡眠相关的激素）被认为是光同步作用的调节因子。它在夜间分泌达到最大值。催乳素、睾酮和生长激素也表现出昼夜节律，在夜间分泌达到最大值。[图12.4](#c12.xhtml#c12-fig-0004)显示了健康成年男性典型的褪黑素浓度。

睡眠和觉醒受大脑中不同神经递质的影响。某些物质可以改变这些神经递质的平衡，从而影响我们的睡眠和觉醒。含咖啡因的饮料（例如咖啡）和药物（例如减肥药）会刺激大脑的某些部位，导致难以入睡。许多治疗抑郁症的处方药会抑制REM睡眠。

重度吸烟者睡眠通常很浅，且REM睡眠持续时间减少。他们往往在睡眠三四小时后因尼古丁戒断而醒来。一些失眠者可能会借酒助眠。尽管酒精可能帮助人们进入浅睡眠，但它会剥夺他们的REM睡眠以及更深、恢复性更强的睡眠阶段。酒精使他们停留在较浅的睡眠阶段，容易被唤醒。在REM睡眠期间，我们会失去部分调节体温的能力。因此，异常炎热或寒冷的温度会干扰我们的REM睡眠。如果REM睡眠受到干扰，正常的睡眠周期进程会在下一次睡眠时受到影响，并有可能直接滑入REM睡眠，经历漫长的REM睡眠期，直到补回丢失的REM睡眠时长。

总体而言，任何原因导致的睡眠中断都可能成为癫痫发作频率或严重程度增加的原因。它也会对短期记忆、注意力和情绪产生负面影响。夜间癫痫发作本身就会扰乱睡眠。此外，使用任何抗惊厥药物都可能以不同方式影响睡眠。根据国际睡眠障碍分类[11](#c12.xhtml#c12-bib-0011)，已报告了大约90种不同的睡眠障碍，包括打鼾、阻塞性睡眠呼吸暂停低通气综合征(OSAHS)、失眠、发作性睡病、磨牙症、不宁腿综合征。

癫痫发作的频率和大脑内癫痫灶的定位可能在不同睡眠阶段和觉醒状态下发生变化。

## 12.4 睡眠剥夺

睡眠剥夺从受损任务和平均持续时间两方面进行评估。在需要判断力的任务中，随着总睡眠时间被限制在每晚五小时，会出现越来越冒险的行为。睡眠剥夺者关注有限的收益，似乎忽略了行动的高昂代价。这些发现可以用以下事实解释：连续24小时睡眠剥夺者，大脑前额叶和顶叶联合区的新陈代谢会下降。这些大脑区域对判断、冲动控制、注意力和视觉联想非常重要。

睡眠剥夺是一个相对概念。少量的睡眠损失（例如每晚少睡一小时，持续多夜）会产生微妙的认知损伤，这可能不被察觉。一周内更严重的睡眠限制会导致深刻的认知缺陷，这也可能不被个体自己察觉。如果白天感到困倦，入睡时间极短（五分钟左右），或躺下后立即经常入睡，则该个体很可能处于睡眠剥夺状态。

许多研究已明确表明睡眠剥夺是危险的。随着睡眠减少，高阶认知任务会早期且不成比例地受损。在用于测试协调性的任务中，睡眠剥夺者的表现与醉酒者一样差，甚至更差。连续一周每晚睡眠七小时，导致简单反应时间任务和要求更高的计算机生成数学解题任务的速度均下降。连续一周每晚睡眠五小时，显示出速度下降和准确性开始失效。

一些研究人员报道了利用睡眠剥夺检测和诊断某些脑部异常[12](#c12.xhtml#c12-bib-0012)–[14](#c12.xhtml#c12-bib-0014)。这包含24-26小时的睡眠丧失。Klingler等人[15](#c12.xhtml#c12-bib-0015)利用此法检测原本可能被遗漏的癫痫样放电。基于这些研究，也得出结论认为睡眠剥夺是一种真正的激活方法[16](#c12.xhtml#c12-bib-0016)。其诱发异常脑电放电的功效并非源于嗜睡。利用第三阶段睡眠的信息，可对局灶性和全面性癫痫发作进行分类[17](#c12.xhtml#c12-bib-0017)。
