
# Entropy and Multiscale Fluctuation-Based Dispersion Entropy

Entropy is not only a measure of uncertainty but also represents the minimum amount of information we can use to encode a binary code. However, if the objective is to evaluate the uncertainty or irregularities in the signals at one temporal scale, other measures such as sample entropy (`SampEn`), fuzzy entropy (`FuzEn`), and permutation entropy (`PerEn`) can be used.

Nevertheless, these approaches fail to account for the inherent multiple time scales of physiological signals such as EEG [[3]](#c06.xhtml#c6-bib-0003), [[4]](#c06.xhtml#c6-bib-0004). To deal with this limitation, multiscale `SampEn` was proposed [[5]](#c06.xhtml#c6-bib-0005) and it has become a prevalent algorithm to quantify the complexity of univariate time series, especially physiological recordings [[6]](#c06.xhtml#c6-bib-0006).

A multiscale fluctuation‐based dispersion entropy (`MFDE`) is based on a coarse‐graining process [[3]](#c06.xhtml#c6-bib-0003) and fluctuation‐based dispersion entropy (`FDispEn`) [[7]](#c06.xhtml#c6-bib-0007).

Consider a signal `u(t)` of length `L`, it is first divided into non‐overlapping segments `x[j]` of length `l`, where `j = 1, 2…, L/l`. The normal cumulative distribution function (`NCDF`) maps `x[j]` into `y[j]` in the `[0, 1]` interval as [[6]](#c06.xhtml#c6-bib-0006):

```
(6.4) y_j = (1 / (σ√(2π))) ∫_{-∞}^{x_j} e^{-(t-μ)²/(2σ²)} dt
```

where `μ` and `σ` represent the centre and width of the mapping waveform. This value is then linearly quantized into `C` levels as:

```
(6.5) z_j^C = round(C · y_j + 0.5)
```

Then we define `z_i^{m,C} = {z_i^C, z_{i+d}^C, …, z_{i+(m-1)d}^C}` for `i = 1, 2, …, N − (m − 1)d`. Then a fluctuation‐based dispersion pattern `π_{v0 v1 … v_{m-1}}` is associated with each `z_i^{m,C}` where `v_{m-1} = z_{i+(m-1)d}^C`. The number of possible fluctuation‐based dispersion patterns that can be assigned to each time series `z_i^{m,C}` is equal to `(2C − 1)^(m−1)`. Then we define:

```
(6.6) p(π_{v0 v1 … v_{m-1}}) = #{i | i ≤ N − (m − 1)d} / (N − (m − 1)d)
```

where `#` refers to cardinality. This, in fact, shows the number of dispersion patterns of `π_{v0 v1 … v_{m-1}}` assigned to `z_i^{m,C}`. The `MFDE` is then defined as the related entropy, i.e.:

```
(6.7) FDispEn(x, m, C, d) = - Σ_{π=1}^{(2C-1)^{m-1}} p(π_{v0 v1 … v_{m-1}}) · ln(p(π_{v0 v1 … v_{m-1}}))
```

Some applications of `MFDE` to physiological signals including EEG can be found in [[6]](#c06.xhtml#c6-bib-0006).
