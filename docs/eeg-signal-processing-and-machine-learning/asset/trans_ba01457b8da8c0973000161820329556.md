

## 5.3.3.2 卷积性 BSS 在 EEG 中的应用

对于 EEG 混合模型，`f[s]` 通常较低（因为带宽 <100 Hz），且传播速度等同于电磁波（300 000 km s^(−1)）。因此，延迟几乎为零，我们总是可以将时域 BSS 的混合模型视为瞬时的。对于 EEG，信号源被认为是平稳的（位置固定）。这一重要假设在许多情况下（如分离正常脑电节律与眨眼伪迹）是可以接受的，从而使线性 BSS 能够得到有效应用。然而，在其他一些情况下（如长时间的身体运动），信号源被视为电流源，即其位置可能发生变化。要提取此类信号源，线性 BSS 解不再有效。EEG 的空间 BSS 中，混合信号以每通道采样点的形式存在（即电极空间中的交替采样点），因此这可以被视为卷积性的。空间位移类似于时间延迟，主要是由于一个空间信号片段内的信号源移动引起的。这一思想已在文献 [\[100\]](#c05.xhtml#c5-bib-0100) 中得到发展，该文献利用最大似度卷积 ICA 对 EEG 进行了时空分析。

将 BSS 应用于 EEG 信号分离的主要缺点在于：

*   未知的生理和测量噪声统计特性
*   未知且变化的信号源数量
*   信号源的非平稳性，主要由诱发反应和运动相关脑反应引起
*   与突触电流相关的分布式移动信号源的存在。

尽管已有许多尝试旨在解决上述问题，但仍需更多努力，以便为不同应用提供鲁棒的解决方案。

## 5.4 稀疏成分分析

欠定系统问题的求解——即信号源数量多于混合信号数量的情况——通常极具挑战性，无法使用传统的 BSS 系统来完成。这意味着在此类情况下，需要将更多先验信息集成到分解算法中。在自然界中，存在许多具有稀疏性质的事件和信号源。例如包括海马内的发作间期放电、ECG 中的 QRS 信号、EEG 中的眨眼伪迹以及基因组序列中的突变。在信号源稀疏的地方，即每个时刻只有一个信号源具有显著的非零值，混合矩阵的列可以单独计算，这使得欠定情况的求解成为可能。该问题可表述为一个聚类问题，因为散点图中的直线可以根据其方向性通过聚类方法加以分离 \[[16](#c05.xhtml#c5-bib-0016), [17](#c05.xhtml#c5-bib-0017)\]。Li 等人 [\[18\]](#c05.xhtml#c5-bib-0018) 更全面地遵循了这一思路。然而，在他的方法中，分离是在两个不同阶段进行的。首先，使用 `k-means` 聚类方法估计未知的混合矩阵。然后，使用标准线性规划算法估计信号源矩阵。数据集的直线方向可被视为其最大方差的方向。一种方法是对数据的协方差矩阵进行特征向量分解，所得的主特征向量（即具有最大特征值的特征向量）指示了数据的方向。在许多情况下，信号源在时域以外的其他域中是不相交的。在这些情况下，可以在这些域中更高效地执行 SCA。一种称为退化解混估计技术（DUET）的方法 [\[19\]](#c05.xhtml#c5-bib-0019) 利用短时傅里叶变换将无回声卷积观测值转换到时频域，并从对应时频点的比值中计算两个观测值之间的相对衰减和延迟值。然后将显著振幅区域（原子）视为时频域中的信号源成分。

对于瞬时情况，在稀疏信号源分离中，大多数研究者采用的通用方法是试图最大化分离器输出中提取信号的稀疏性。混合矩阵 `A` 的列根据与这些列的某种接近度度量，将每个观测数据点仅分配给一个信号源 [\[20\]](#c05.xhtml#c5-bib-0020)，即每个时刻仅认为一个信号源是活跃的。因此，混合系统可表示为：

(5.32)
```
x_i(n) = Σ_{j=1}^{M} a_{ji} s_j(n)  i=1, ..., N
```
