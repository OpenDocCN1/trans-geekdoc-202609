
# 脑电波节律

## Alpha波

Alpha波出现在头部后半部分，通常位于大脑枕叶区域，可在大脑后叶的所有部位检测到。Alpha波的频率范围为 8–13 Hz，通常呈现为圆形或正弦波形信号。但在极少数情况下，可能表现为尖波。此时负向分量呈尖锐状，正向分量呈圆形，类似于罗兰多μ节律的波形形态。Alpha波被认为既表示无注意力或专注的放松觉知状态。Alpha波是整个大脑活动领域中最显著的节律，其覆盖范围可能比之前公认的更广。在高达 20 Hz 的频率范围内，常可见Beta波范围内的峰值，这具有Alpha波状态的特征而非Beta波状态。此外，我们经常在Alpha状态下观察到 75 Hz 的反应。大多数受试者闭眼时会产生一些Alpha波，因此有人声称这仅仅是大脑视觉区域产生的等待或扫描模式。睁眼、听到陌生声音、焦虑或精神集中/注意均可减弱或消除Alpha波。阿尔伯特·爱因斯坦在保持Alpha状态下能解决复杂的数学问题；尽管通常Beta波和Theta波也同时存在。Alpha波在枕区振幅较高，正常振幅小于 50 μV。Alpha波的起源和生理意义仍未明了，仍需更多研究来理解这一现象如何源自皮层细胞 [[3]](#c02.xhtml#c2-bib-0003)。

## Beta波

Beta波是大脑电活动在 14–26 Hz 范围内的变化（部分文献未给出上限）。Beta波是大脑典型的清醒节律，与主动思维、主动注意、关注外部世界或解决具体问题相关，见于正常成人。人处于恐慌状态时可能出现高水平Beta波。有节律的Beta活动主要见于额区和中央区。重要的是，中央Beta节律与罗兰多μ节律相关，可被运动活动或触觉刺激阻断。Beta节律振幅通常低于 30 μV。与μ节律类似，Beta波也可能因骨缺损 [[1]](#c02.xhtml#c2-bib-0001) 及肿瘤周围区域而增强。

## Gamma波

30 Hz 以上（主要高达 45 Hz）的频率对应Gamma波段（有时称为快Beta波）。尽管这些节律振幅极低且出现罕见，但检测这些节律可用于确诊某些脑部疾病。高EEG频率区域及脑血流量最高水平区域（氧和葡萄糖摄取最高区域）均位于额中央区。Gamma波段也被证明是大脑事件相关同步化（ERS）的良好指标，可用于显示左右食指运动、右脚趾运动以及舌运动对应的相当宽泛的双侧区域 [[4]](#c02.xhtml#c2-bib-0004)。

## 高频脑电活动

远超EEG正常活动频率范围的波（主要在 200–300 Hz 范围内）已在动物小脑结构中发现，但在临床神经生理学中未发挥作用 [[5]](#c02.xhtml#c2-bib-0005)[[6]](#c02.xhtml#c2-bib-0006)。

## 典型正常脑节律

[图 2.1](#c02.xhtml#c2-fig-0001) 展示了典型正常脑节律及其常见振幅水平。总体而言，EEG信号是神经活动的投影，这些活动被软脑膜、脑脊液、硬脑膜、骨质、帽状腱膜和头皮所衰减。皮层电图放电显示振幅范围为 0.5–1.5 mV，尖波可达数毫伏。然而在头皮上，振幅通常在 10–100 μV 范围内。

若受试者状态不变，上述节律可持续存在，因此近似呈周期性。反之，存在其他脑波形，其可能：

1.  具有宽频带或表现为尖峰型信号，如K-复合波、顶点波（睡眠中出现）或裂隙节律（因颅骨缺损产生的Alpha型节律）[[7]](#c02.xhtml#c2-bib-0007)，其不随运动反应，主要见于中颞区（T3或T4电极下），以及某些癫痫信号。
2.  为瞬态，如事件相关电位（ERP），包含枕区正性尖锐瞬态（POST）信号（也称ρ波）。
3.  源自大脑缺损区域，如肿瘤性脑损伤。
4.  具有空间定位性且被视为周期性，但易被身体运动阻断，如μ节律。μ代表运动，与运动皮层密切相关。罗兰多（中央）μ节律在振幅和频率上与后部Alpha相关。然而，其地形分布和生理意义截然不同。通过μ节律可研究皮层功能及受物理和想象运动影响的大脑（多为双侧）活动变化。μ节律也用于癫痫发作障碍治疗等目的的生物反馈训练 [[1]](#c02.xhtml#c2-bib-0001)。

## 其他研究者引入的节律

研究者还引入了其他节律：

1.  **Phi (φ) 节律**（< 4 Hz）：闭眼后两秒内出现。由Daly提出 [[3]](#c02.xhtml#c2-bib-0003)。
2.  **Kappa (κ) 节律**：前颞Alpha样节律，被认为是眼球离散侧向振荡的结果，属伪迹信号。
3.  **睡眠纺锤波**（也称Sigma [σ] 活动）：频率范围 11–15 Hz。
4.  **Tau (τ) 节律**：代表颞区Alpha活动。
5.  **闭眼眼睑颤动**：引起Alpha频带内的额区伪迹。
6.  **Chi节律**：类μ活动，被认为是 11–17 Hz 的特定罗兰多模式。在哈他瑜伽练习过程中观察到该波 [[8]](#c02.xhtml#c2-bib-0008)。
7.  **Lambda (λ) 波**：清醒患者中最显著，但不常见。视觉探索时行走受试者枕区出现的尖锐瞬态。为正向波，与扫视眼动时锁定，振幅不一，通常低于 90 μV [[9]](#c02.xhtml#c2-bib-0009)。
