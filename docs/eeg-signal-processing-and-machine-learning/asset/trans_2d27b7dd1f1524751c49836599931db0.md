
在大多数睡眠测量和研究中，脑电图（EEG）已被结合多种其他生理参数一同使用。失眠可能是最常见的心理效应，它直接影响睡眠质量以及整夜非快速眼动睡眠（NREM）/快速眼动睡眠（REM）分布的变化。此外，脑电研究已记录了有自杀行为的精神病患者睡眠模式的异常，包括更长的睡眠潜伏期、增加的REM时间以及增加的相位性REM活动。Sabo等人[\[18\]](#c12.xhtml#c12-bib-0018)比较了有和无自杀未遂史的成年抑郁症患者的睡眠脑电特征，并指出那些有过自杀未遂的人在第二REM周期中持续表现出更多的REM时间和相位性活动，但在第四非REM周期中delta波计数较少。在同一实验室进行的另一项研究[\[19\]](#c12.xhtml#c12-bib-0019)在精神病患者中复现了这些发现。基于这两项研究，作者[\[19\]](#c12.xhtml#c12-bib-0019)提出，REM睡眠与自杀倾向之间的关联可能跨越诊断界限，且睡眠脑电变化可能对未来的自杀行为具有预测价值。后来，其他研究在自杀型精神分裂症[\[20\]](#c12.xhtml#c12-bib-0020)和抑郁症[\[21\]](#c12.xhtml#c12-bib-0021)中复现了REM睡眠的变化。

三项横断面研究考察了抑郁青少年睡眠脑电与自杀倾向之间的关系。Dahl等人[\[22\]](#c12.xhtml#c12-bib-0022)比较了抑郁自杀组、抑郁非自杀组和正常对照组之间的睡眠脑电。他们的结果表明，与非自杀抑郁组和对照组相比，有自杀倾向的抑郁患者表现出显著延长的睡眠潜伏期和增加的REM相位性活动，并呈现出REM潜伏期缩短的趋势。Goetz等人[\[23\]](#c12.xhtml#c12-bib-0023)和McCracken等人[\[24\]](#c12.xhtml#c12-bib-0024)复现了抑郁自杀青少年REM密度更高的发现。

对正常衰老和老年人短暂性认知障碍的研究也表明，老年受试者脑电图中最常见的异常是alpha频率减慢，而大多数健康个体维持alpha活动在9–11 Hz范围内\[[25](#c12.xhtml#c12-bib-0025), [26](#c12.xhtml#c12-bib-0026)\]。

## 12.6 脑电睡眠分析与评分

### 12.6.1 采用盲源分离检测节律波形和纺锤波

脑电记录完成后，为了分析和监测睡眠障碍，主要阶段是检测对应不同睡眠阶段的波形。为了便于在睡眠期间用少量电极记录脑电，一种能最佳选择电极位置并去除心电图（ECG）、眼电图（EOG）和肌电图（EMG）影响的方法可能很有用[\[21\]](#c12.xhtml#c12-bib-0021)。

通常需要长时段记录，以充分研究睡眠信号并建立夜间睡眠概况，上述信号中表现出的电生理活动必须被识别和研究。寻求一种盲源分离（BSS）算法来分离四个期望信号：脑电、两个眼电和一个心电。为了保持连续数据块中估计源的连续性，估计的独立分量已与电极信号进行互相关运算，那些与特定电极信号最相关的连续信号段被视为同一来源的片段。由于BSS系统通常是欠定的，因此无法将alpha活动从其他脑活动中分离出来，结果可能导致alpha活动无法被一致地观察到。然而，EMG复合波和REM在分离出的源中是明显的。

### 12.6.2 采用匹配追踪进行睡眠脑电的时频分析

Malinowska等人[\[27\]](#c12.xhtml#c12-bib-0027)利用常规脑电信号处理方法，对Rechtschaffen和Kales（R&K）系统提出了一些扩展。这些扩展包括：比划分为20–30秒历元更精细的时间尺度、纺锤波强度的度量，以及对单个和随机诱发的K-复合波与自发周期性K-复合波的区分（前者对刺激有反应）。[图12.5](#c12.xhtml#c12-fig-0005)展示了一些典型的纺锤波和K-复合波波形。

最初由Mallat和Zhang[\[29\]](#c12.xhtml#c12-bib-0029)提出的利用匹配追踪（MP）进行信号自适应时频（T–F）近似，已被用于开发一种研究上述扩展的方法[\[27\]](#c12.xhtml#c12-bib-0027)。本书[第2章](#c02.xhtml)回顾了MP。所需的波形字典主要由Gabor函数组成，因为这些函数提供最优的联合时频定域[\[30\]](#c12.xhtml#c12-bib-0030)。实值连续时间Gabor函数可表示为：
