根据额叶脑不对称性概念，负面情绪的体验与右侧额叶和前额叶半球活动增加有关，而正面情绪则唤起增强的左半球活动。假设在 FP1、FP2 和 F3-F4（连在一起）记录的 EEG 信号分别代表信号 *X*、*Y* 和 *Z*，并利用不对称性概念，一种评估信号 *X* 和 *Y* 中这种不对称性信息的度量，同时考虑信号 *Z* 传播给它们双方的信息，将引入一个指标，表明情绪被唤起的有效程度。为此，假设隐藏在 EEG 信号中并在左右半球之间共享的信息总量 *S*（如 [(14.11)](#c14.xhtml#c14-disp-0011) 所示），在受试者平静时达到最大（指信息对称），而在受试者情绪唤起时达到最小（信息不对称）。遵循 MDI 概念，引入了两个表示为 *S*[*r*] 和 *S*[*p*] 的变量 [[62]](#c14.xhtml#c14-bib-0062)。*S*[*r*] 是指在考虑 *Z* 的情况下 *X* 和 *Y* 之间的双向信息共享，此时受试者不处于任何情绪状态下，即放松，意味着：
