
## 6.7 Estimation of Lyapunov Exponents from Time Series

Calculation of the Lyapunov exponents from time series was first proposed by Wolf et al. [[10]](#c06.xhtml#c6-bib-0010). In their method, initially a finite embedding sequence is constructed from the finite time series of `2 * N + 1` components as:

```
x(0), x(τ), x(2τ), …
```

These are the basic data (often called reference trajectory or reference orbit) upon which the model builds. Generally, we do not have the start point since there is no explicit governing equation that would generate the trajectory. From this sequence we may choose a point `x(k[0] τ)`, which approximates the desired initial point `z(0)`. Considering **Figure 6.3**, these approximations should satisfy:

(6.14)
```
|x(k[0] τ) - x(0)| < δ
```

where `δ` is an a priori chosen tolerance. We may rename this point as

(6.15)
```
z[0](0) = x(k[0] τ)
```

The successors of this point are known as:

(6.16)
```
z[0](r τ) = x((k[0] + r) τ), r = 1, 2, 3, …
```

Now there are two trajectories to compare. The logarithmic error amplification factor for the first time interval becomes:

(6.17)
```
l[0] = (1/τ) log (|z[0](τ) - z[0](0)| / |x(τ) - x(0)|)
```
