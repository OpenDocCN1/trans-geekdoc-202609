[**图 18.5**](#c18.xhtml#R_c18-fig-0005) EEG 与 fMRI 固有联系的机制。（上）区域“神经元活动”的增加（局部神经元群体对抑制性和兴奋性输入以及神经元间前馈和反馈活动的整体突触乘积）导致代谢需求增加（神经元和星形胶质细胞），伴随能量和氧气消耗增加。作为对这些神经代谢变化的响应，局部脑灌注量增加，超过了代谢需求。因此，尽管总氧消耗量增加，但部分氧提取率和局部静脉血中脱氧血红蛋白的百分比均下降（fMRI 记录到的正 BOLD 变化）。（下）在一个包含前向和后向兴奋性及抑制性连接的神经网络中，与精心定义的基线相比，BOLD 信号的变化反映了网络“状态”的变化 [[25](#c18.xhtml#c18-bib-0025), [26](#c18.xhtml#c18-bib-0026)]。

两者之间的差异中，存在突触反应与血流动力学反应之间的时间滞后差异 [[27](#c18.xhtml#c18-bib-0027)]。这种关系通常是非线性的，且 EEG 中的信噪比（SNR）显著高于 fMRI 中的 SNR [[28](#c18.xhtml#c18-bib-0028)]。尽管如此，两者之间的关系取决于神经元活动的类型。虽然 BOLD 信号的幅度和空间尺度与神经生理学之间的关系仍在争论中，但一些研究者已报告了 BOLD 与神经元活动之间主要呈线性耦合。例如，[[29](#c18.xhtml#c18-bib-0029)] 中证实了躯体感觉诱发电位与 BOLD 之间的线性关系。Rees 等人 [[30](#c18.xhtml#c18-bib-0030)] 和 Heeger 等人 [[31](#c18.xhtml#c18-bib-0031)] 也宣称猴大脑皮层区域的平均尖峰发放率与 BOLD 信号之间存在线性相关性。这表明 EEG 和 fMRI 具有固有关系，因此可以联合分析。EEG 和 fMRI 的同步测量因此为提供关于这两种模态之间确切关系的更多信息铺平了道路。

## 18.3.2 用于 BOLD 检测的基于模型的方法

一般线性模型（GLM）常用于分析 fMRI 数据。文献 [[32](#c18.xhtml#c18-bib-0032), [33](#c18.xhtml#c18-bib-0033)] 是利用 GLM 从 fMRI 数据中检测 BOLD 的良好范例。基于该模型，利用刺激时间进程构建 HRF，并将其与 fMRI 序列卷积以突出 BOLD。GLM 是基于模型的 fMRI 分析中最常用的方法。GLM 方法用于在无限多种不同的实验设计中，为各类研究问题寻找良好的解决方案。该模型可表示为：

[(18.6)](#c18.xhtml#R_c18-disp-0008)![equation](images/c18-disp-0008.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="block" overflow="scroll"><mi mathvariant="bold">x</mi><mo>=</mo><mi mathvariant="bold">Yb</mi><mo>+</mo><mi mathvariant="bold">e</mi></math>

其中 **`x`** 为包含多元测量序列的向量，**`Y`** 称为设计矩阵，**`b`** 为包含待估计未知参数的向量，**`e`** 表示误差或噪声向量，假设服从正态分布。

在 GLM 中，采集到的 fMRI 图像体积中的每个体素均被视为刺激的血流动力学反应及其对应加权参数的线性组合，即矩阵 **`x ∈ ℜ^(M×P)`** 的每一列对应每个体素的 fMRI 时间序列。因此，GLM 解释了每个体素的时间进程变化。[图 18.6](#c18.xhtml#c18-fig-0006) 显示了 fMRI 实验中一个样本体素的时间序列。**`M`** 指实验中的扫描次数，**`P`** 是单次扫描体积中所有体素的数量。在使用 GLM 进行 fMRI 分析时，设计矩阵是利用给定任务的预测脑反应来构建的。矩阵 **`Y ∈ ℜ^(M×N)`** 的每一列显示通过将刺激函数与 HRF 卷积获得的一种反应。**`N`** 指基于某些先验知识获得的可用预测变量的数量。刺激函数根据 fMRI 记录期间的实验设计类型确定，可以是块设计或事件相关设计。HRF 可以从已知函数（如伽马函数）中选择。

[图 18.7](#c18.xhtml#c18-fig-0007) 表示针对样本 fMRI 时间序列构建的模型示意图。在该模型中，有 **`β[1]`**、**`β[2]`**、…、**`β[M]`** 共 M 个参数待估计。这些参数被视为基于某些先验知识获得的预定义回归量的系数。模型确定后，应估计权重参数 **`B`**。这可以通过最大似然估计（MLE）或贝叶斯估计等技术获得。拟合数据并使平方误差最小化的参数值可通过以下公式估计：

## 18.3.3 同步 EEG–fMRI 记录：从 EEG 中去除伪迹

在同步 EEG 和 fMRI 数据记录中，EEG 信号受磁场效应影响严重，产生强伪迹 [[37](#c18.xhtml#c18-bib-0037)]。若不去除 fMRI 诱导的伪迹，几乎无法实现 EEG 中潜在的信息。在磁场中记录的 EEG 信号主要受两大伪迹影响，即梯度伪迹和球istocardiogram（BCG）伪迹。在对这些数据进行任何联合处理之前，应有效去除伪迹。以下各节总结了这些伪迹的主要特征，并提供了从 EEG 信号中去除它们的常用及最新方法。

### 18.3.3.1 从 EEG 中去除梯度伪迹
