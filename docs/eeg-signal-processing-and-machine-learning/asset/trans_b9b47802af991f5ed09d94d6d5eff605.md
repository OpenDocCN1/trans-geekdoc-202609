在实践中，估计的源并不完全不相关，因此 **Γ** ≠ **P**^T。然而，对于每一行，预期仅获得一个接近于 1 的元素 *γ*[*ij*]，对应 *j* = *j*[0]，其余接近于零。因此，该算法仍可应用于保持信号的连续性。

源估计完成后，可应用 TNM 来跟踪估计源信号的动态变化。
