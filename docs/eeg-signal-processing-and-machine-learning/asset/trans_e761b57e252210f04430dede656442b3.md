

# 纤维肌痛综合征 (FMS)

纤维肌痛综合征 (FMS) 的定义是存在慢性、通常为全身性的疼痛，并伴有多种额外症状，如广泛的肌肉骨骼疼痛、疲劳、肌腱韧带疼痛以及睡眠障碍。鉴于这些症状的多样性和复杂性，纤维肌痛常被误诊，使患者感到沮丧和困惑。然而，睡眠呼吸暂停通常与纤维肌痛共存。被称为 alpha-EEG 异常的睡眠障碍在 FMS 患者中很普遍。该病症的定义是：类清醒脑活动打断了深度睡眠。

Alpha 波表明你处于清醒但放松的状态。在相应的 EEG 记录中，睡眠中的大脑通常在睡眠第三阶段显示 delta 波，这被认为是“深度”睡眠。在 alpha-EEG 异常中，alpha 波侵入深度睡眠，表明大脑没有像应该的那样休息。当预期出现 delta 活动的非 REM 睡眠期间出现 alpha 波时，就会发生 Alpha 波侵入。一些研究者推测，这种异常可能解释了纤维肌痛特有的非恢复性睡眠 [[62](#c12.xhtml#c12-bib-0062), [63](#c12.xhtml#c12-bib-0063)]。因此，EEG 评估可为该疾病的诊断揭示一些有价值的信息。

## 12.7.3 新生儿睡眠障碍

最近，研究了与新生儿呼吸暂停发作相关的 EEG 变化，例如见 [[64](#c12.xhtml#c12-bib-0064)–[66](#c12.xhtml#c12-bib-0066)]。在 [[64](#c12.xhtml#c12-bib-0064)] 中发现，伴有缺氧和心动过缓的延长性呼吸暂停发作可能与新生儿大脑功能改变有关。该研究有助于临床医生了解抑制 EEG 活动所需的最低血氧饱和度限值。研究还表明，仅当血氧饱和度降至 20% 以下的呼吸暂停事件才与完全的 EEG 抑制相关。

尽管新生儿呼吸暂停发生频繁，且人们担心其不良的长期影响 [[66](#c12.xhtml#c12-bib-0066)]，但很少有研究利用 EEG 来检查呼吸暂停发作的影响 [[64](#c12.xhtml#c12-bib-0064)]。通过睡眠 EEG 可以发现呼吸暂停是否与新生儿惊厥、缺氧或任何其他神经系统甚至生理疾病相关或相关联。

## 12.8 梦与噩梦

很难否认我们都会做梦。在睡眠实验中从 REM 期被唤醒的人报告说，他们有 80–100% 的时间在做梦。REM 梦被认为更具感知性和情绪性，这与 NREM 梦形成对比。NREM 梦的内容通常是某些心理上重要事件的重现。根据弗洛伊德 [[67](#c12.xhtml#c12-bib-0067)] 的理论，REM 梦类似于初级过程思维，这通常是不切实际且情绪化的；而 NREM 梦类似于次级过程思维，这更为现实。关于梦的意义主要有三种理论。

基于弗洛伊德理论，我们做梦是为了满足无意识的欲望或愿望，尤其是涉及性和攻击性的愿望。如果我们在白天实现这些愿望，会产生过多的焦虑。弗洛伊德指出，愿望用符号来表示，因为否则它们会产生焦虑。基于这一理论，治疗师必须解释这些符号，以帮助来访者发现无意识欲望。

该理论指出，后脑（脑干的下部，由小脑、脑桥和延髓组成）向大脑皮层传输混乱的信号模式，然后大脑皮层中的高级认知过程试图将这些信号整合成一个梦的情节 [[68](#c12.xhtml#c12-bib-0068)]。

梦也可以被视为清醒生活的延伸，其中包括思想和担忧，尤其是情绪方面的。从这个意义上说，梦为一个人的问题、担忧和情绪提供了线索 [[69](#c12.xhtml#c12-bib-0069)]。与噩梦不同，做梦可能是睡眠良好的迹象。尽管关于梦有许多理论和假设，但关于梦的原因、其确切功能以及生理过程如何参与其中，仍有许多未解之谜。在《梦的解析》[[70](#c12.xhtml#c12-bib-0070)] 中，弗洛伊德预言：“更深入的研究终将进一步追踪这条路径，并为精神事件发现一个有机基础。”最近的研究开始通过包括 EEG 分析在内的一切可能途径来实现这一预言。

睡眠 EEG 记录可能会呈现 alpha 衰减，作为梦境中视觉活动的指标 [[71](#c12.xhtml#c12-bib-0071)]。相反，与一般的梦不同，噩梦已知仅发生在 REM 睡眠期间，以及睡眠周期后半段较长和较晚的 REM 期。

从神经科学的角度来看，梦的研究可被视为睡眠期间认知过程的研究。然而，神经生物学证据固有地受限于无法直接接触梦境，以及必须专注于觉醒后清醒期收集的梦境体验回忆（即梦境回忆）的必要性。许多研究强调了清醒和睡眠中调节认知功能机制的连续性 [[72](#c12.xhtml#c12-bib-0072)]。特别是，有人强调 EEG 研究提供了实证数据，支持 theta 振荡在清醒和睡眠中对情景信息提取所起的预测作用，将梦境回忆视为一种情景记忆痕迹。为了在睡眠和做梦期间监测所有可能的生理症状，建议将 PSG 作为此目的的金标准工具 [[72](#c12.xhtml#c12-bib-0072)]。

## 12.9 EEG 与意识

EEG 已日益成为监测麻醉过程和意识状态的首选工具。额叶脑活动随麻醉深度的变化而显著改变，可作为临床手术期间监测意识深度的良好生物标志物。这可在丙泊酚输注期间监测大脑状态，以调整正确剂量。

因此，基于行为量表或源自额叶 EEG 指数的意识评估方法已在临床环境中被广泛采用 [[73](#c12.xhtml#c12-bib-0073), [74](#c12.xhtml#c12-bib-0074)]，尽管尚未达成共识，即哪种标志物在评估患者意识水平方面更优。

在无意识状态下，慢波从额叶皮层产生并扩散到全脑。与睡眠不同，没有纺锤波或 K 综合波。因此，在监测无意识水平时，评估额区周围（通过空间滤波促进）低频范围（主要在 delta 和 theta 频带内）的频谱特征（如功率谱）似乎是足够的。

双频谱指数 (BIS) 监测仪是常用于评估镇静深度的系统之一，当在手术和医疗过程中给予镇静剂、催眠剂或麻醉剂时使用。BIS 是一个基于统计、经验推导得出的复杂参数，由时域、频域和高阶频谱子参数的组合构成。
