
where $z_i = \rho_i e^{j\omega_i}$ and $M < N$. Using vector notation we can write:

(9.71)
$$\mathbf{x}_g = \mathbf{Za} + \mathbf{x}_3$$

where $\mathbf{x}_g = [x_g(L_1) \dots x_g(N + L_1 - 1)]^T$, $\mathbf{x}_3 = [x_3(L_1) \dots x_3(N + L_1 - 1)]^T$, $\mathbf{a} = [a_1 \dots a_M]^T$ and

(9.72)
$$\mathbf{Z} = \begin{bmatrix}
\rho_1 e^{j\omega_1} & \dots & \rho_M e^{j\omega_M} \\
\vdots & \ddots & \vdots \\
\rho_1 e^{j\omega_1 N} & \dots & \rho_M e^{j\omega_M N}
\end{bmatrix}$$

Therefore, in order to estimate the waveform $\mathbf{s} = \mathbf{Za}$ both $\mathbf{Z}$ and $\mathbf{a}$ have to be estimated. The criterion to be minimized is the weighted LS criterion given by:

(9.73)
$$\min_{\mathbf{Z}, \mathbf{a}} \{ (\mathbf{x}_g - \mathbf{Za})^H \mathbf{R}_{\mathbf{x}_3}^{-1} (\mathbf{x}_g - \mathbf{Za}) \}$$

where $\mathbf{R}_{\mathbf{x}_3}$ is the covariance matrix of the EEG (as a disturbing signal) after stimulation. For a fixed $\mathbf{Z}$ the optimum parameter values are obtained as:

(9.74)
$$\mathbf{a}_{\text{opt}} = (\mathbf{Z}^H \mathbf{R}_{\mathbf{x}_3}^{-1} \mathbf{Z})^{-1} \mathbf{Z}^H \mathbf{R}_{\mathbf{x}_3}^{-1} \mathbf{x}_g$$

Then, the corresponding estimate of the single‐trial ERP is achieved as:

(9.75)
$$\mathbf{s} = \mathbf{Z} \mathbf{a}_{\text{opt}}$$

Prony's method is employed to minimize (9.73) for coloured noise. In order to do that a matrix $\mathbf{F}$ orthogonal to $\mathbf{Z}$ is considered, i.e. $\mathbf{F}^H \mathbf{Z} = 0$ [[69]](#c09.xhtml#c9-bib-0069). The $i$th column of $\mathbf{F}$ is $\text{col}\{\mathbf{F}\}_i = [\underbrace{0 \dots 0}_{i-1} \ f_0 \dots f_M \ \underbrace{0 \dots 0}_{N-M-i}]^T$. The roots of the polynomial $f_0 + f_1 z^{-1} + \dots + f_M z^{-M}$ are the elements $z_i$ in $\mathbf{Z}$ [[69]](#c09.xhtml#c9-bib-0069). The minimization in (9.73) is then converted to

(9.76)
$$\min_{\mathbf{F}} \{ \mathbf{x}_g^H \mathbf{F} (\mathbf{F}^H \mathbf{R}_{\mathbf{x}_3} \mathbf{F})^{-1} \mathbf{F}^H \mathbf{x}_g \}$$

In practise a linear model is constructed from the above nonlinear system using [[69](#c09.xhtml#c9-bib-0069), [70](#c09.xhtml#c9-bib-0070)]

(9.77)
$$\mathbf{F} (\mathbf{F}^H \mathbf{R}_{\mathbf{x}_3} \mathbf{F})^{-1} \mathbf{F}^H \approx \tilde{\mathbf{F}} \mathbf{R}_{\mathbf{x}_3}^{-1} \tilde{\mathbf{F}}^H$$
