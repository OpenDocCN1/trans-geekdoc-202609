
# 癫痫检测方法综述

## 多阶段SVM与HMM方法

在第三阶段，使用具有非线性（RBF）核的多维`SVM`处理来自多通道输入的数据。据报道，对于全面性发作和大多数局灶性发作的检测，准确率高达100% [[46]](#c11.xhtml#c11-bib-0046)。

隐马尔可夫模型（`HMM`）也被用于文献[[47]](#c11.xhtml#c11-bib-0047)中的癫痫检测。该方法开发了一种名为自适应小波系数阈值计数斜率（`ASCOT`）的自动化方法，将患者发作分类为癫痫波形。`ASCOT`通过计算各频率子带中小波系数计数在不同阈值下的平均斜率来提取特征矩阵。作者还评估了不同窗口大小下的方法性能，得出结论：较短的窗口尺寸能获得更好的结果。

## 基于DNN的时空异常检测

Sakai等人[[48]](#c11.xhtml#c11-bib-0048)提出了一种`DNN`，用于检测癫痫患者`EEG`中由癫痫引起的时空异常区间。其`CNN`可检测异常时空区间，这些区间不仅通过灶区附近的电极估计，还通过周围区域的电极估计。在应用`CNN`之前，某一时间槽从16个电极获得的信号可视为一个5×4矩阵（16个电极+4个缺失角值）。因此，时空`EEG`记录被配置为一个5×4×*n*的三阶张量（*n*为时间维度的数据长度）。每个张量片段作为所提系统的输入。在他们的`CNN`中，输入和输出数量相同，并对每个通道识别异常。*n*=500时的网络结构如[图11.2](#c11.xhtml#c11-fig-0002)所示[[48]](#c11.xhtml#c11-bib-0048)。

然而，癫痫放电的确切形状识别（这通常比文献[[46]](#c11.xhtml#c11-bib-0046)中考虑的更为复杂）需要对颅内神经元活动进行深入研究，这将在本章后续章节中讨论。研究表明，这些波形的形态不仅因受试者而异，还随年龄变化。

## IED的年龄依赖性特征

文献[[49]](#c11.xhtml#c11-bib-0049)证明了癫痫样放电（`IED`）具有年龄依赖性特征。随年龄增长，局灶性`IED`变得不那么尖锐，振幅降低，慢波不那么突出，且变得更加偏侧化。这些发现有助于`EEG`阅读者检测并正确描述不同年龄患者的`IED`。使用卵圆孔（`FO`）硬膜下电极和头皮`EEG`电极记录的此类波形（即`IED`）示例分别见[图11.3](#c11.xhtml#c11-fig-0003)a和b。因此，`EEG`阅读者在解读`IED`时应始终考虑患者年龄。

不过，这些`IED`在到达`EEG`电极前会被头部组织抹平和高度衰减。通常，头皮`EEG`中可见的`IED`不足10%。使用颞侧电极或下拉的`T7`和`T8`电极（如`Maudsley`电极设置）可更好地检测它们。

## 基于动力学变化的癫痫检测

癫痫常表现为相对较大脑神经网络内同步活动的突然发生，干扰大脑正常工作。因此，一些动力学变化测度也被用于癫痫检测。这些测度在癫痫前期到发作期的过渡，甚至在发作间期和发作期的过渡中显著变化。后一种情况下，过渡可能表现为相位的连续变化（如内侧颞叶癫痫`MTLE`部分病例），或表现为突变（如大多数失神发作病例）。

在基于混沌测量的吸引子维数估计方法中（详见本章后续讨论），对于第一种情况，系统吸引子从发作间期逐渐变形为发作期吸引子。对于发生尖锐临界跃迁的第二种情况，可假设系统始终至少同时存在发作间期和发作期两个吸引子。

Lopes da Silva等人[[50]](#c11.xhtml#c11-bib-0050)的研究将三种状态（路径）表征为癫痫发作的说明性模型：
1. 由随机扰动引起的分叉型突变过渡。典型例子是表现为`EEG`阵发性棘慢波和非惊厥性失神发作的癫痫综合征；
2. 由外部扰动引起的吸引子变形路径（光敏性癫痫）；
3. 吸引子变形导致逐渐演变为发作期状态，如颞叶癫痫（`TLE`）。

作者得出结论：在这些路径下，可以理解从持续（发作间期）活动模式向发作（癫痫发作）模式的过渡在何种情况下可能被预测，或可能无法预测。此外，根据基础癫痫类型，这三条路径中的任何一条都是可能的。癫痫发作可能通常不可预测（如特发性（原发性）全面性癫痫的失神型发作），或可预测（如前期动力学逐渐变化，可在发作表现前一段时间检测到，如`TLE`）。

## 11.2.2 新生儿癫痫检测

癫痫发作约发生在0.5%的新生儿（出生后前四周）身上。它代表中枢神经系统（`CNS`）异常的独特指标。导致这种异常的原因有很多，主要包括`CNS`内的生化失衡、颅内出血和感染、发育（结构）缺陷，以及被动药物成瘾和戒断反应[[51]](#c11.xhtml#c11-bib-0051)。新生儿`EEG`分析是生物医学信号处理领域的一个非常困难的问题。与成人不同，尖波的存在可能不代表癫痫发作。新生儿的临床体征不像成人那样显而易见，成人癫痫发作常伴有身体不可控制的重复或抽搐运动，或肌张力性屈肌痉挛。新生儿不太明显的症状（即隐性发作）可能包括眼睑持续睁开伴注视固定、重复眨眼或眼睑颤动、流涎、吸吮或其他轻微面部表情或身体运动。因此，新生儿癫痫发作的检测比成人复杂得多，迄今仅尝试了少数方法。本节简要讨论这些方法。
