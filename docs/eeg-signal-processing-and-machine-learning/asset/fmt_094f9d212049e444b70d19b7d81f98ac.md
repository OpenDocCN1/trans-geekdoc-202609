
### 9.3.5 Kalman Filtering for ERP Estimation

(9.45) 
```
K_n = P_{n-1} H_n^T (H_n P_{n-1} H_n^T + C_{v_n})^{-1}
```

(9.46) 
```
P_n = (I - K_n H_n) P_{n-1} + C_{w_n}
```

(9.47) 
```
\hat{\theta}_n = \hat{\theta}_{n-1} + K_n (x_n - H_n \hat{\theta}_{n-1})
```

where `P[n]` and `K[n]` are called respectively, the recursive covariance matrix estimate and Kalman‐gain matrix. At this stage it is interesting to compare these parameters for the four well‐known recursive estimation algorithms namely recursive least squares (RLS), least‐mean‐square (LMS), normalized least‐mean‐square (NLMS), and the above Kalman estimators for the above simple model. This is depicted in [Table 9.1](#c09.xhtml#c9-tbl-0001) [[59]](#c09.xhtml#c9-bib-0059).

In practise `C_{w_n}` is considered as a diagonal matrix such as `C_{w_n} = 0.1 I`. Also it is logical to consider `C_{v_n} = I`, and, by assuming the background EEG to have Gaussian distribution it is possible to use the Kalman filter to dynamically estimate the ERP signals. As an example, it is possible to consider `H[n] = I`, so that the ERPs are recursively estimated as:

(9.48) 
```
\hat{s}_n = \hat{\theta}_n = \hat{\theta}_{n-1} + K_n (x_n - \hat{\theta}_{n-1}) = K_n x_n + (I - K_n) \hat{s}_{n-1}
```

Such assumptions make the application of the algorithms in [Table 9.1](#c09.xhtml#c9-tbl-0001) for ERP tracking and parameter estimation easier.

In a more advanced algorithm `H[n]` may be adapted to the spatial topology of the electrodes. This means that the column vectors of `H[n]` are weighted based on the expected locations of the ERP generators within the brain. [Figure 9.9](#c09.xhtml#c9-fig-0009) compares the estimated ERPs for different stimuli for the LMS and recursive MS estimator (Kalman filter). From this figure it is clear that the estimates using the Kalman filtering appear to be more robust and show very similar patterns for different stimulation instants.

### 9.3.6 Particle Filtering and its Application to ERP Tracking
