# 16 EEG作为精神疾病和神经发育障碍的生物标志物

## 16.1 简介

神经发育障碍 (NDDs) 是多方面的疾病，表现为因大脑发育异常导致的认知、沟通、行为和/或运动技能受损。智力障碍、沟通障碍、自闭症谱系障碍 (ASD)、注意缺陷多动障碍 (ADHD) 和精神分裂症等均属于NDDs的范畴，且非常常见 [[1]](#c16.xhtml#c16-bib-0001)。

借助新的诊断工具和技术，所有这些疾病均可被诊断，甚至有些可被轻松预测。在疾病的不同阶段，会使用各种方法和生物标志物来识别患有精神疾病的受试者。这些方法包括异常面部表情、声音变化、步态恶化和减缓，以及许多可观察到的行为改变。然而，从早期的医学史来看，这些疾病的根源已被公认为来自大脑。因此，通过观察大脑信号，有望对这些疾病进行更好的诊断和监测。

### 16.1.1 历史

查阅Noba网站 ([https://nobaproject.com/modules/history‐of‐mental‐illness](https://nobaproject.com/modules/history-of-mental-illness))，精神疾病的演变取决于行为周围的语境，因此作为特定时间和文化的函数而变化。在过去，不寻常的行为或偏离特定文化和时期的社会文化规范与期望的行为，曾被用作压制或控制某些个人或群体的理由和借口。因此，一种较少文化相对主义的异常行为观点，转而关注行为是否对自己或他人构成威胁，或造成如此多的痛苦和折磨，以至于干扰了一个人的工作责任或与他人的关系。

根据《万迪达》（Vandidad），《阿维斯塔》（Avesta，琐罗亚斯德教圣书，约公元前1000年）中关于社会行为的章节，医生分为三类：外科医生 (Avestan语中的 *kareto baešaza*)、使用草药的医生 (*urvaro baešaza*) 和用圣言治疗的医生 (*mansrspand baešaza*)，后者优于其他疗法。这些医生从琐罗亚斯德教祭司中选拔，被认为是历史上第一批精神科医生 [[2]](#c16.xhtml#c16-bib-0002)。

纵观历史，关于精神疾病病因一直有三大理论：超自然说、躯体生成说和心理生成说。躯体生成说认为，疾病、遗传、脑损伤或失衡导致的躯体功能障碍是病因。心理生成说则关注创伤或压力经历、适应不良的习得联想与认知，或扭曲的知觉。精神疾病的病因学理论决定了精神病患者所接受的护理和治疗。

希腊医生拒绝用超自然解释精神障碍。大约在公元前400年，希波克拉底 (公元前460–370年) 试图通过系统化“四种基本体液（即体液）——血液、黄胆汁、黑胆汁和痰液——中某种体液的缺乏或特别是过多，导致躯体和精神疾病”这一信念，将迷信和宗教与医学区分开来。例如，脾气过于暴躁的人被认为血液过多，因此放血疗法将是必要的治疗手段。
