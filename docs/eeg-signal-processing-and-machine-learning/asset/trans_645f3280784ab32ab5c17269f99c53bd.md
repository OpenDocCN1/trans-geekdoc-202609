这与最大边际分类器类似，唯一的区别在于，这里我们有一个新的约束条件 `a[i] + r[i] = C`，其中 `r[i]` ≥ 0，因此 0 ≤ `a[i]` ≤ `C`。这意味着值 `C` 设定了拉格朗日优化变量 `a[i]` 的上限。这有时被称为**盒约束**。`C` 的值在数据拟合精度和正则化之间提供了一种权衡。较小的 `C` 值（即 `C` < 1）会显著限制误差点（或离群点）的影响，而如果 `C` 被选为非常大（或无穷大），则软间隔（如[图 7.5](#c07.xhtml#c7-fig-0005)所示）方法将变得与最大边际分类器完全相同。因此，在使用软间隔分类器时，`C` 的选择强烈依赖于数据。`C` 的适当选择很重要，且仍是一个研究领域。设定 `C` 的一种方法是从 max (`α[i]`) 逐渐增加 `C`（对所有 `i`），并找到使误差（离群点、交叉验证或误分类点数量）最小的值。最终，`C` 可以通过经验找到 [[44]](#c07.xhtml#c7-bib-0044)。
