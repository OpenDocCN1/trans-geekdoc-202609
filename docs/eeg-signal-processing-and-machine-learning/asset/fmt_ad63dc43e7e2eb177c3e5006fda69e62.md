
#### 4.5.1.6 Reconstruction

The reconstruction of the data from its wavelet coefficients can be performed step‐by‐step, starting from the lowest resolution. At each scale, we compute:

(4.51)
```
C_{j+1} = H(2^j ω) C_j(ω)
```
(4.52)
```
W_{j+1} = G(2^j ω) C_j(ω)
```

we look for `C[j]` knowing `C[j + 1]`, `W[j + 1]`, `h`, and `g`. Then `C_j(ω)` is restored by minimizing:

(4.53)
```
P_h(2^j ω) |C_{j+1}(ω) - H(2^j ω) C_j(ω)|^2 + P_g(2^j ω) |W_{j+1}(ω) - G(2^j ω) C_j(ω)|^2
```

using a least minimum squares estimator. `P_h(ω)` and `P_g(ω)` are weight functions which permit a general solution to the restoration of `C_j(ω)`. The relationship from of `C_j(ω)` is in the form of:

(4.54)
```
C_j(ω) = C_{j+1}(ω) \tilde{H}(2^j ω) + W_{j+1}(ω) \tilde{G}(2^j ω)
```

where the conjugate filters have the expressions:

(4.55)
```
\tilde{H}(ω) = (P_h(ω) H^*(ω)) / (P_h(ω) |H(ω)|^2 + P_g(ω) |G(ω)|^2)
```
(4.56)
```
\tilde{G}(ω) = (P_g(ω) G^*(ω)) / (P_h(ω) |H(ω)|^2 + P_g(ω) |G(ω)|^2)
```

It is straightforward to see that these filters satisfy the exact reconstruction condition given in [Eq. (4.35)](#c04.xhtml#c4-disp-0035). In fact, [Eqs. (4.55)](#c04.xhtml#c4-disp-0055) and [(4.56)](#c04.xhtml#c4-disp-0056) give the general solutions to this equation. In this analysis, the Shannon sampling condition is always respected. No aliasing exists, so that the anti‐aliasing condition [(4.76)](#c04.xhtml#c4-disp-0078) is not necessary.
