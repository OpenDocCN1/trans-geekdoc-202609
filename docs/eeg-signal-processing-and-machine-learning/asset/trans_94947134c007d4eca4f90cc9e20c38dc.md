总体而言，利用基于 Prony 的方法进行单次试验 ERP 提取所获得的结果相当可靠，且与生理学和临床预期一致。上述算法已在多种情况下得到验证，包括刺激前、刺激后以及刺激后期间。在提取的信号中，主要对应 P300 来源的清晰峰值显而易见。

在另一尝试中，类似于上述方法，考虑到 ERP 信号的频率、幅度和相位特性随时间变化，因此提出了一种分段 Prony 方法（PPM）[\[71\]](#c09.xhtml#c9-bib-0071)。使用 PPM 的主要优势在于：首先，该方法能够对具有非零起始时间的非单调增长或衰减分量进行建模。因此，使用 PPM 时假设正弦分量具有增长或衰减的包络，以及幅度和相位的突变。PPM 使用可变长度窗口（由 \[[71](#c09.xhtml#c9-bib-0071), [72](#c09.xhtml#c9-bib-0072)\] 先前建议）和可变采样频率（Kulp [\[73\]](#c09.xhtml#c9-bib-0073) 也曾通过调整采样率以匹配待建模频率来执行此操作），以克服原始 Prony 方法的局限性。其次，窗口大小根据信号特征确定。此外，大带宽信号分多步建模，每步聚焦于较小的频带，正如 [\[74\]](#c09.xhtml#c9-bib-0074) 所提议的。第三，可变长度窗口试图包含常规 Prony 分量。因此，在检测 ERP 特征（频率、幅度和相位）方面具有更高的一致性。最后，合理假设从具有相同频率的相邻窗口获得的信号分量属于同一分量，并可将其合并为一个分量。

### 9.3.9 自适应时频方法

自适应信号估计技术与时频信号表示的结合可以增强 ERP 和 EP 检测的性能。这通常指利用可变参数系统对信号建模，并应用自适应估计器来估计合适的参数。

使用 STFT 时，无法利用关于活动持续时间的信息，因此无法描述比窗口长度短得多或长得多的结构。WT 通过允许可变窗口长度克服了这一限制，但小波的中心频率与其窗口长度之间仍存在倒数关系。因此，WT 无法精确估计短时长的低频分量或窄带高频分量。

在另一项工作中，自适应啁啾变换（ACT）被用于表征 VEP 从瞬态到稳态阶段的时变行为 [\[75\]](#c09.xhtml#c9-bib-0075)。通常，该方法使用匹配追踪（MP）算法来估计啁啾基函数，并使用 ML 算法来优化结果，从而实现低信噪比下的信号估计。使用此方法可以可视化 VEP 响应的早期时刻。

ACT 试图将信号分解为具有四个可调参数（时间展宽、啁啾率、时间中心和频率中心）的高斯啁啾基函数。此外，研究表明仅需三个啁啾基函数即可表示一个 VEP 响应。

在此方法中，视觉刺激开始后首先出现的瞬态 VEP [\[76\]](#c09.xhtml#c9-bib-0076) 与稳态 VEP \[[77](#c09.xhtml#c9-bib-0077), [78](#c09.xhtml#c9-bib-0078)\] 一起进行分析。稳态 VEP 的识别具有许多临床应用，并有助于诊断感觉功能障碍 \[[79](#c09.xhtml#c9-bib-0079), [80](#c09.xhtml#c9-bib-0080)\]。然而，如果不考虑瞬态模式，仅使用稳态 VEP 的模型是不完整的。在患者精神状态不稳定的情况下，真正的稳态 VEP 也难以获得。
