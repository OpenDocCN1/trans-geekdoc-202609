
Considering the selected pure harmonic signal `f(t) = Acos(ωt)`, it is simple to observe that `ω(a, b) = ω`. The candidate IFs are exploited to recover the actual frequencies. Therefore, a reallocation technique has been used to map the time domain into TF domain using `(b, a) ⇒ (b, ω(a, b))`. Based on this, each value of `W(a, b)` (computed at discrete values of `a[k]`) is re‐allocated into `T[f] (ω[l], b)` as provided in the following equation ([Eq. 4.61](#c04.xhtml#c4-disp-0062)):
