
左脚和右脚的表征区位于感觉运动皮层的大脑半球间裂内，且空间位置相邻。这使得在左脚和右脚运动想象期间，难以直观呈现事件相关（去）同步化（ERD/ERS）的皮层侧化。

文献[82]研究了在左脚和右脚背屈动觉运动想象（KMI）期间，利用μ波段、低β波段和高β波段的ERD/ERS作为BCI单侧控制指令的可能性。研究从9名健康受试者在提示式左/右脚背屈KMI任务中记录脑电（EEG）。提取的时频特征分别针对共同平均参考和双极参考进行了分析。在每种参考下，均利用时频变换、头皮地形图和ERD/ERS平均时间进程对μ波段和β波段功率特征进行了分析。结果证实了左脚和右脚KMI期间ERD/ERS的皮层侧化。统计学显著特征通过LDA、SVM和*k*近邻（KNN）分类器进行分类，并利用受试者工作特征曲线下面积（ROC AUC）进行评估。研究还确认，在KMI结束后，顶点处左右半球的高β功率均有增加。筛选出的特征可在单次EEG试验中唤起左右腿的差异。经LDA和SVM分类验证，取得了良好性能。该成果必将惠及从事脑损伤（如卒中）患者康复工作的临床医生和患者。

### 17.2.3 运动后短暂β活动

该活动也称为运动后β同步化（PMBS），是另一种信息丰富且一致的事件，始于运动过程中，持续约600 ms [79]。它见于双侧半球的手指或足部运动后，无显著双侧相干性。频带范围因人而异：手指运动约为16–21 Hz [83]，足部运动约为19–26 Hz [84]。PMBS在快速和缓慢手指运动中的振幅相似。这很有趣，因为快慢运动涉及不同的神经通路。此外，与手指运动相比，手部运动引发的该活动显著更大 [79]。与手指运动相比，腕部运动产生更大的β振荡，可解释为运动皮层神经元群体从运动行为期间的神经放电增强，转变为皮层去易化或皮层闲置状态 [79]。这意味着移动更多手指会产生更大的β波。β活动在抓握信号生成中也很重要，因为它与其他频率成分的重叠较少 [85]。

### 17.2.4 γ波段振荡

γ波段（35–45 Hz）内神经活动的振荡（ERS）近期也受到关注。这种活动在视觉刺激后或运动任务前非常明显。它可能作为α波和低β波振荡的载波，与感觉信息捆绑和感觉运动整合有关。γ波段活动连同上述其他波段活动，可在执行运动任务后大致同一时间被观察到。γ波段ERS表现为运动前即刻出现，而β波段ERS则发生在事件后即刻。

不同方法尝试检测或突显γ波段ERS。例如，文献[86]作者对单通道（Cz）脑电应用经验模态分解（EMD），随后进行时频分析，改进了γ波段ERS检测。近期同一团队的另一项工作中，在想象运动期间测量了经滤波和去伪迹处理的Cz通道脑电信号在30–60 Hz内的功率 [87]。该工作使用FieldTrip [88]完成大部分脑电信号处理。

### 17.2.5 长δ波活动

不同于α、β、γ波段已知的ERS和ERD活动，长δ波振荡在手指运动后即刻开始，持续数秒。尽管文献中较少报道，但因其高功率和对噪声不敏感，可作为区分运动与非运动状态的显著特征。

BCI的主要任务是如何利用想象运动前、中、后，或特定脑刺激后，上述频段脑电行为来生成控制信号。后续章节将探讨此问题。文献[89]研究表明，δ波段脑电信号包含可用于推断手指运动学、解码重复手指运动的有用信息。此外，最高解码准确度的特征是高度相关的δ波段脑电活动，主要定位于对侧中央头皮区域。δ波段活动与三维伸手抓握BCI运动也高度相关 [90]。总体而言，利用具有记忆的线性解码器，可在一定程度上从全头皮δ波段滤波后的脑电振幅波动中推断手指运动学 [89]。

### 17.2.6 事件相关电位（ERP）

ERP变异性广泛应用于许多BCI系统设计中。在拼写BCI等重要应用中，通过奇异范式考察和量化对新颖/目标刺激的P300反应，特别是其P3b亚成分。ERP还用于许多其他BCI应用。Beverina等人[91]使用了P300和稳态视觉诱发电位（SSVEP）。他们利用SVM对ERP特征模式进行分类。其SSVEP方法使用枕区电极（`Oz`、`O2`、`PO8`）信号。刺激时间点被视为随机，并建议用视觉反馈 [42] 进行训练。正常情况下可通过反馈放大脑波。另一项工作在视觉精细的沉浸式3D游戏中使用了SSVEP [92]。相位反转棋盘图案诱发的SSVEP用于该BCI方案。本章后续章节将讨论多个使用ERP（特别是P300）的BCI应用。
