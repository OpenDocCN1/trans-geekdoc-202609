
在文献[\[28\]](#c16.xhtml#c16-bib-0028)中，利用`VIGALL 2.1`（[`http://www.uni‐leipzig.de/vigall`](http://www.uni-leipzig.de/vigall/)）估算的觉醒水平被用于识别成人的ADHD程度。连续的一秒EEG片段基于频带和利用`LORETA`进行源定位，被分类为七个不同的EEG觉醒阶段（0、A1、A2、A3、B1、B2/3和C）。此外，水平慢眼动被用于区分阶段0和B1。Alpha频率和振幅水平进行了个性化调整。研究表明，觉醒调节（即觉醒稳定性评分）可预测回顾性评估的儿童期ADHD症状严重程度，支持了脑觉醒调节的特质属性。

尽管多变量系统在ADHD的分类或检测方面具有鲁棒性，但这些多特征方法的主要问题在于难以对结果进行临床解释。然而，随着机器学习方法的进步，以及更多全局性（而非受试者相关性）试验和特征的可用，预计算法对受试者和条件变异性的敏感性将会降低。

### 16.2.2 ASD

ASD是一种多基因发育性和神经生物学障碍[\[29\]](#c16.xhtml#c16-bib-0029)，其特征是非典型行为和缺乏社会互惠。它由一组异质性的行为症状星群定义，这些症状在生命的头几年内出现。它影响一个人感知和与他人社交的方式，导致社交互动和沟通方面的问题。该障碍还包括有限且重复的行为模式。ASD中的“谱系”一词指的是症状和严重程度的广泛范围。

ASD包含以前被认为是独立的病症——自闭症、阿斯伯格综合征、儿童瓦解性障碍和未特定的广泛性发育障碍。有些人仍使用“阿斯伯格综合征”一词，这通常被认为处于ASD的轻度端。

#### 16.2.2.1 ASD症状及可能的治疗

ASD始于幼儿早期，最终导致在社会中功能受损，例如在学校和工作中的社交功能。通常儿童在第一年内就会表现出自闭症症状。少数儿童在第一年似乎发育正常，随后在18至24个月大之间经历一段退缩期，此时出现自闭症症状。虽然ASD无法治愈，但密集的早期治疗能极大地改善许多儿童的生活。

一些儿童在婴儿早期就会表现出ASD迹象，如眼神接触减少、对名字无反应或对照顾者漠不关心。其他儿童可能在生命的头几个月或几年发育正常，但随后突然变得孤僻、具有攻击性，或丧失已习得的语言技能。体征通常在两岁前被发现。

每个患有ASD的儿童都可能拥有独特的行为模式和严重程度。

一些患有ASD的儿童有学习困难，一些表现出低于正常的智力迹象。其他患有该障碍的儿童智力正常至较高——他们学习很快，但在日常生活中沟通和运用所学知识以及适应社交场合方面存在困难。由于每个儿童症状的独特混合，严重程度有时难以确定。通常基于损伤程度及其对功能能力的影响来判断。

#### 16.2.2.2 基于EEG的ASD诊断

近年来EEG已被用于ASD研究。自闭症可被描述为一种动力学障碍，并从复杂动力学系统的角度进行分析。皮层兴奋性的可测量变化可能导致连接异常，或是其表现。此外，观察到自闭症发育的一个关键特征是早期脑过度生长[\[30\]](#c16.xhtml#c16-bib-0030)，随后导致局部连接增强和长程连接受抑。研究显示，证据表明正在发育较短程的皮层-皮层半球内连接，而半球间以及皮层和皮层下结构之间的连接参与度很低[\[30\]](#c16.xhtml#c16-bib-0030)。自闭症的行为症状可能是这些受损神经回路的表现。在一些研究中，如文献[\[31\]](#c16.xhtml#c16-bib-0031)，发现了支持大尺度远程网络内连接不足以及局部网络内连接不足假设的证据。他们利用静息态记录的EEG信号复杂性作为特征，以区分典型发育儿童和有ASD风险的儿童。

许多研究者（如文献[\[30\]](#c16.xhtml#c16-bib-0030)）尝试利用EEG连接性进行ASD研究。这项研究在面部感知任务试验中对儿童进行128导联EEG记录，以获取个体同步状态（即同步态）及其转换序列。每个同步态指受试者表现出与观察到的面部相似的情绪面部表情的时间段（观察快乐面孔变得快乐、观察悲伤面孔变得悲伤、观察中性面孔保持中性、观察愤怒面孔表现出恐惧）。

他们分析了12名儿童在处理恐惧、快乐和中性面孔时的EEG。选择每个受试者出现最少和最多的同步态以提取脑连接特征。他们使用连续小波变换（`CWT`）在gamma频带上EEG信号的相位同步作为连接性的度量。随后利用这些特征，通过线性判别分析（`LDA`）和支持向量机（`SVM`），对这两组受试者进行分类[\[30\]](#c16.xhtml#c16-bib-0030)。

文献[\[32\]](#c16.xhtml#c16-bib-0032)考察了三种EEG定量方法（即功能连接分析、频谱功率分析和信息动力学）在ASD诊断中的有效性。然而，他们得出结论：由于结果的高度异质性，无法进行推广，目前没有任何单一方法可作为诊断工具。

文献[\[31\]](#c16.xhtml#c16-bib-0031)的工作在文献[\[33\]](#c16.xhtml#c16-bib-0033)中得以延续，其中从EEG信号计算非线性（动力学复杂性）特征，并作为统计学习系统的输入。在他们的实验中，从每个受试者EEG记录开始时儿童安静坐着的连续30秒片段中选择数据。未对片段进行拼接或基于审查的选择。随后，他们应用Haar小波变换的`CWT`将数据分解为六个频带，包括常规EEG频带。对每个频带，他们计算了广泛的特征。这些特征包括：样本熵、去趋势波动度量（时间序列“长程记忆”的度量）、源自递归图的熵（与香农熵相关）、最大线长（与混沌信号最大李雅普诺夫指数相关）、平均线长（递归图轨迹两段彼此接近的时间）、递归率（系统状态在有限时间内重现的概率）、确定性（源于系统中的重复模式，表明其可预测性）、层流性（代表不稳定性转换的速度，或从一种状态转换到另一种状态的频率）以及捕获时间（系统将保持在给定状态的时间估计）[\[33\]](#c16.xhtml#c16-bib-0033)。最后，他们应用`SVM`对其进行分类。
