
# CSP正则化方法

大多数现有的基于CSP的方法在逐受试者的基础上利用协方差矩阵，从而忽略了受试者间的信息。CSP及其变体已受到广泛关注，并成为BCI最高效的特征提取方法之一。然而，尽管其数学原理直观，CSP容易过拟合数据，且对噪声高度敏感。

为提升CSP性能并解决这些缺陷，近期提出利用正则化项或约束形式的先验信息来改进CSP学习过程。Lotte等人[\[159\]](#c07.xhtml#c7-bib-0159)对11种不同的CSP正则化方法进行了分类和比较。这些方法包括：
- EEG协方差矩阵估计中的正则化[\[163\]](#c07.xhtml#c7-bib-0163)
- 复合CSP[\[161\]](#c07.xhtml#c7-bib-0161)
- 带通用学习的正则化CSP[\[164\]](#c07.xhtml#c7-bib-0164)
- 带对角加载(DL)的正则化CSP[\[158\]](#c07.xhtml#c7-bib-0158)
- 不变CSP[\[165\]](#c07.xhtml#c7-bib-0165)

所有算法均应用于17名受试者的多次试验。研究建议采用Tikhonov正则化的CSP，即在优化`J(w)`时通过最小化`||w||²`进行惩罚，从而最小化伪迹和离群值的影响，该方法被认为是最佳方法。

为使CSP对噪声不那么敏感，公式[(7.59)](#c07.xhtml#c7-disp-0065)中的目标函数可在估计各类别的协方差矩阵期间，或在通过向空间滤波器`w`施加先验来最小化CSP代价函数的过程中进行正则化[\[159\]](#c07.xhtml#c7-bib-0159)。正则化类别`i`的协方差矩阵估计（即`C̃_i`）的一种直接方法表示为：

(7.61)
```
C̃_i = (1 - γ)P + γI
```

其中`P`估计为：

[(7.62)](#c07.xhtml#R_c7-disp-0068)
```
P = (1 - β)C_i + βG_i
```

在上述方程中，`C[i]`是类别`i`的初始空间协方差矩阵，`G[i]`是所谓的通用协方差矩阵，通过对类别`i`的多次试验的协方差矩阵求平均计算得出，尽管也可仅基于神经生理学先验定义。`γ`和`β` ∈ [0, 1]为正则化参数。通用矩阵代表了对所考虑心理状态的协方差矩阵应有形式的特定先验。

相反，对于CSP目标函数的正则化，向CSP目标函数添加正则化项，以惩罚不满足给定先验的空间滤波器。这导致目标函数略有不同[\[159\]](#c07.xhtml#c7-bib-0159)：

(7.63)
```
J(w) = (w^T C_1 w) / (w^T C_2 w + αQ(w))
```

惩罚函数`Q(w)`由惩罚（或拉格朗日）参数`α` ≥ 0加权，指示空间滤波器`w`满足给定先验的程度。类似于公式[(7.62)](#c07.xhtml#c7-disp-0068)分母中的第一项，为最大化代价函数`J(w)`，需最小化该项。文献中定义了不同的二次和非二次惩罚函数。一些示例方法见[\[159\]](#c07.xhtml#c7-bib-0159)、[\[165\]](#c07.xhtml#c7-bib-0165)、[\[166\]](#c07.xhtml#c7-bib-0166)。二次约束（如`Q(w) = w^T K w`）导致求解一组新的特征值问题[\[159\]](#c07.xhtml#c7-bib-0159)：

(7.64a)
```
(C_2 + αK)^(-1) C_1 w = λw  for the first pattern
```
(7.64b)
```
(C_1 + αK)^(-1) C_2 w = λw  for the second pattern
```

[\[161\]](#c07.xhtml#c7-bib-0161)提出的复合CSP算法通过利用其他受试者的数据正则化协方差矩阵，实现受试者间迁移。此方法中`α`和`γ`为零，仅`β`非零。通用协方差矩阵`G[i]`根据其他受试者的协方差矩阵定义。

基于带通用学习的正则化CSP的方法[\[164\]](#c07.xhtml#c7-bib-0164)同时使用`β`和`γ`正则化项，意在将协方差矩阵同时向单位矩阵和通用协方差矩阵`G[i]`收缩。此处，类似于复合CSP，`G[i]`从其他受试者的协方差矩阵计算得出。

DL是BCI文献中使用的另一种协方差矩阵正则化形式[\[158\]](#c07.xhtml#c7-bib-0158)，即将协方差矩阵向单位矩阵收缩（有时称为正交化）。因此，此方法仅使用`γ`（`α = β = 0`），其值可使用Ledoit和Wolf的方法[\[167\]](#c07.xhtml#c7-bib-0167)或交叉验证[\[159\]](#c07.xhtml#c7-bib-0159)自动确定。

在基于Tikhonov正则化的方法[\[159\]](#c07.xhtml#c7-bib-0159)中，惩罚项定义为`P(w) = ||w||² = w^T w = w^T I w`，这通过在公式(7.64)中使用`K = I`获得。这种正则化预期将解约束为小范数的滤波器，从而减轻伪迹和离群值的影响。
