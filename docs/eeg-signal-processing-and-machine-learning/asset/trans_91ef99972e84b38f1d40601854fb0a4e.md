## 8.4 多变量方向性估计

通常，在多通道记录中将格兰杰因果性应用于多变量数据在计算上并不高效 [[18](#c08.xhtml#c8-bib-0018), [20](#c08.xhtml#c8-bib-0020)]。作为格兰杰因果性的扩展，DTF [[16](#c08.xhtml#c8-bib-0016)] 由多通道数据获得，可用于检测和量化耦合方向。DTF 优于谱相干性的优势在于，当两个脑区的频谱重叠时，它能确定耦合中的方向性。由于已证明在手指运动前，感觉运动区周围传感器之间存在定向的信息流或串扰 [[25]](#c08.xhtml#c8-bib-0025)，一些研究者已采用 DTF 来确定耦合方向性 [[23](#c08.xhtml#c8-bib-0023), [24](#c08.xhtml#c8-bib-0024)]。DTF 基于将 EEG 拟合到 MVAR 模型。假设 `x(n)` 为 `M` 通道 EEG 信号，则以向量形式可建模为：
