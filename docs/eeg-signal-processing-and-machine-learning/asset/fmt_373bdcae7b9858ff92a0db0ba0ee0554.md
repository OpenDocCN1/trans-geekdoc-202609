
一种使用通用头部模型（以解剖图谱形式）的方法也被提出用于生成EEG源定位[\[43\]](#c10.xhtml#c10-bib-0043)。该图谱通过一组表面标志点，利用非刚性变形适配至受试者。变形后的图谱用于计算神经电流发生器与EEG电极之间的正向映射或导场的FEM（有限元模型）。这些导场用于根据受试者的EEG数据定位电流源，随后将源映射回解剖图谱。该方法提供了一种在基于图谱的坐标系中比较受试者间源定位的机制。

### 10.4.3 LORETA算法

用于脑源定位的LORETA已实现商业化。在该方法中，电极电位与矩阵`X`被认为存在如下关系：

[(10.15)](#c10.xhtml#R_c10-disp-0015)
```
X = LS
```

其中`S`为实际（电流）源振幅（密度），`L`为`n[e] × 3m`矩阵，表示从每个源到传感器阵列的正向传输系数。`L`也被称为系统响应核或导场矩阵[\[44\]](#c10.xhtml#c10-bib-0044)。`L`的每一列包含当源向量在某一位置和朝向具有单位振幅而在其他所有位置为零时，在电极处观测到的电位。这要求电位基于叠加原理随源振幅线性测量。通常情况下这并不成立，因此该假设固有地会产生一些误差。拟合源振幅`S`可通过逆LS解的穷举搜索近似估计，即：

(10.16)
```
S = (L^T L)^(-1) L^T X
```

`L`可通过头部电流流动的3D仿真近似，这要求求解著名的泊松方程[\[45\]](#c10.xhtml#c10-bib-0045)：

(10.17)
```
∇·(σ∇X) = -ρ
```

其中`σ`为头部体积电导率（Ωm）^(−1)，`ρ`为源体积电流密度（A/m³）。可使用FEM或BEM求解该方程。在这类模型中，必须已知大脑层的几何信息及其电导率[\[46\]](#c10.xhtml#c10-bib-0046)。除非能在公式化中利用某种先验知识，否则解析模型是不适定的，难以获得唯一解。

反之，源的数量`m`通常远大于传感器数量`n[e]`，因此公式[(10.15)](#c10.xhtml#R_c10-disp-0015)中的系统是欠定的。此外，在需要估计更集中的焦点源的应用中，此类方法会失效。稍后我们将看到，采用最小范数方法时，一些研究者选择满足某些约束（如逆解的平滑性）的解。

一种方法是最小范数解，它在正向问题约束下最小化`S`的范数：

(10.18)
```
min ||S||₂₂, subject to X = LS
```

其解为：

[(10.19)](#c10.xhtml#R_c10-disp-0019)
```
S = L^T (L L^T)^† X
```

最小范数解的动机是创建一个稀疏解，使大多数源的贡献为零。该方法的严重缺点是在三维（3D）空间中定位性能差。该方法的一种扩展是加权最小范数（WMN）解，它补偿深层源，从而在3D空间中表现更好。在这种情况下，`L`的列范数被归一化。因此约束WMN公式化为：

(10.20)
```
min ||WS||₂₂, subject to X = LS
```

其解为：

(10.21)
```
S = W^(-1) L^T (L W^(-1) L^T)^† X
```

其中`W`为对角`3m × 3m`加权矩阵，通过以下方式补偿深层源：

(10.22)
```
W = diag[ 1/||L₁||₂, 1/||L₂||₂, ..., 1/||L₃ₘ||₂ ]
```

其中`||L[i]||₂`表示`L`第`i`列的欧几里得范数，即`W`对应于源与电极间距离的倒数。
