Assuming that the background EEG is statistically stationary, `W(z)` is identified from the pre‐stimulus data via auto‐regressive (AR) modelling of the pre‐stimulus interval and used for post‐stimulus analysis [[35]](#c09.xhtml#c9-bib-0035). The template and measured EEG are filtered through the identified `W(z)` to whiten the background EEG signal and thus, a closed‐form least‐squares (LS) solution of the model is formulated. Therefore, the only parameters to be identified are the matrices `B[i](z)`. This avoids any iterative identification of the model parameters. This can be represented using a regression‐type equation as:

(9.5)
```
x̂(n) = Σ(i=1 to p) Σ(j=-d to d) b_{i,j} · T̂_i(n-j) + e(n)
```

(9.6)

x̂ = [x̂(d+1), x̂(d+2), …, x̂(N-d)]^T,
