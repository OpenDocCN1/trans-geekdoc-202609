
此过程将针对参考轨迹的下一个点 `x(τ)` 重复执行。对于该点，我们需要从轨迹中找到另一个点 `z[1](τ)`，它代表的误差方向与由 `z[0](τ)` 相对于 `x(τ)` 得到的方向接近。如果先前的轨迹仍然接近参考轨迹，我们可以直接继续使用它，即令 `z[1](τ) = z[0](τ)`。这将产生一个误差放大因子 `l[1]`。通过沿用相同过程直到时间序列段耗尽，也可找到其他因子 `l[1], l[2], …, l[m−1]`。当前时间序列段的最大李雅普诺夫指数近似值，可通过对整个参考轨迹上的对数放大因子取平均获得：

(6.18)
```
λ = (1/m) Σ_{j=0}^{m-1} l_j
```

除了上述平均值，误差放大因子的最大值也可视为最大李雅普诺夫指数。有必要研究噪声的影响。数据通常源于物理测量，因此包含噪声。因此，扰动点 `z[k](kτ)` 不应过于接近，否则噪声将主导混沌吸引子上的拉伸效应。反之，也不应允许误差过大，以避免非线性效应。因此，实践中我们规定最小误差 `δ[1]` 和最大误差 `δ[2]`，并要求：

(6.19)
```
δ[1] < |x(kτ) - z[k](kτ)| < δ[2]
```

### 6.7.1 最优时间延迟

在上述计算中，找到*最优时间延迟 `τ`* 至关重要。极小的时间延迟可能导致近似线性重构，使得连续相空间点间高度相关；而过大的延迟可能忽略序列的任何确定性结构。在早期的一个提案 [[11]](#c06.xhtml#c6-bib-0011) 中，使用自相关函数来估计时间延迟。在此方法中，`τ` 等同于自相关降至最小值或降至其初始值一小部分时的时长。在另一尝试 [[12](#c06.xhtml#c6-bib-0012), [13](#c06.xhtml#c6-bib-0013)] 中，已验证互信息（MI）取局部最小值时的 `τ` 值，等同于相关和的对数取局部最小值时的 `τ` 值。

### 6.7.2 最优嵌入维数

为进一步优化李雅普诺夫指数的测量，我们需要指定 `m` 的最优值，称为*嵌入维数*。在此之前，需给出以下定义。

分形维数是与动力学测量相关的另一统计量。奇异吸引子 [[14]](#c06.xhtml#c6-bib-0014) 是分形，其分形维数 `D[f]` 与建模吸引子动力学所需的最小动力学变量数直接相关。概念上，测量 `D[f]` 的一种简单方法是测量*柯尔莫哥洛夫容量*。在此测量中，用大小为 `ε` 的小单元覆盖一个集合，单元形状取决于维数（即二维嵌入用正方形，三维用立方体，以此类推）。若 `M(ε)` 表示集合内此类单元的数量，则分形维数定义为：

(6.20)
```
D[f] = lim_{ε→0} [log(M(ε)) / log(1/ε)]
```

对于单点集 `D[f] = 0`，直线 `D[f] = 1`，平面区域 `D[f] = 2`。但分形维数不一定为整数。

*相关维数* 定义为：

(6.21)
```
D[r] = lim_{r→0} [log(C(r)) / log(r)]
```

其中

(6.22)
```
C(r) = Σ_{i=1}^{M(r)} p_i^2
```

为相关和。

准确估计李雅普诺夫指数所需的最优嵌入维数 `m`，须满足 `m ≥ 2D[f] + 1`。然而 `D[f]` 通常无法预先知道。Grassberger–Procaccia 算法仍可用于测量相关维数 `C[r]`。吸引子的最小嵌入维数为 `m + 1`，其中 `m` 是测得的相关维数 `C[r]` 保持恒定以上的嵌入维数。

另一个极重要的结论：

(6.23)
```
D[f] = D[L] = 1 + λ[1] / |λ[2]|
```

即分形维数 `D[f]` 等价于李雅普诺夫维数 [[1]](#c06.xhtml#c6-bib-0001)。

混沌已被用作多种信号和数据分析中的度量。其在癫痫发作预测中的应用将在 [第 4 章](#c04.xhtml) 中展示。

## 6.8 近似熵

*近似熵*（AE）是一种统计量，可从离散时间序列估计，特别适用于实时应用 [[15](#c06.xhtml#c6-bib-0015), [16](#c06.xhtml#c6-bib-0016)]。该度量可量化系统的复杂性或不规则性。AE 对噪声不敏感，可用于短数据。此外，它对短时强瞬态干扰（离群值）如尖峰具有鲁棒性 [[16]](#c06.xhtml#c6-bib-0016)。
