

#### 4.5.1.5 使用傅里叶变换的小波变换

考虑连续小波的标量积 `c[0](k) = ⟨f(t). φ(t − k)⟩`。如果 `φ(t)` 的带宽限制在采样频率的一半，则数据采样正确。分辨率 `j = 1` 处的数据为：

(4.43)
```
c₁(k) = ⟨f(t). ½ φ(t/2 − k)⟩
```

我们可以用一个频率响应为 `H(ω)` 的离散时间滤波器，从 `c[0](k)` 计算出集合 `c[1](k)`：

(4.44)
```
H(ω) = { Φ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

且对 `∀ ω` 和 `∀ integer m` 有：

(4.45)
```
H(ω + m) = H(ω)
```

因此，系数的估计值为：

(4.46)
```
C_{j+1}(ω) = C_j(ω) H(2^j ω)
```

截止频率在每一步都减少 2 倍，从而允许样本数量按此因子减少。尺度 `j + 1` 处的小波系数为：

(4.47)
```
w_{j+1} = ⟨f(t), 2^{-(j+1)} ψ(2^{-(j+1)} t − k)⟩
```

它们可以直接从 `C[j]` 通过以下公式计算：

(4.48)
```
W_{j+1}(ω) = C_j(ω) G(2^j ω)
```

其中 `G` 是以下离散时间滤波器：

(4.49)
```
G(ω) = { Ψ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

关系式 [(4.34)](#c04.xhtml#c4-disp-0034) 和 [(4.35)](#c04.xhtml#c4-disp-0035) 也必须满足。一大类紧支集小波函数均可使用。已提出许多组滤波器，特别是用于编码 [[22]](#c04.xhtml#c4-bib-0022)。研究表明，这些滤波器的选择必须以缩放函数和小波函数的正则性为指导。复杂度与 `N` 成正比。该算法提供一个包含 `N` 个元素的金字塔结构。
