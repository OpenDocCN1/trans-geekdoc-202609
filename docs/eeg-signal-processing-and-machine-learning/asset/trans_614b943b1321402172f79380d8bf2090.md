
其中 `Cij(ω) = Xi(ω) Xj*(ω)` 是 EEG 通道 *i* 和通道 *j* 之间互相关系数的傅里叶变换。[图 8.1](#c08.xhtml#c8-fig-0001) 显示了手指运动前约一秒时交叉频谱相干性的一个示例。该相干性的一种度量（例如在某个频带上的平均值）能够检测零时滞同步和固定非零时滞同步，当两个神经元群落部位之间存在显著延迟时，后者可能发生 [[15]](#c08.xhtml#c8-bib-0015)。尽管如此，它并不提供关于两个记录部位之间耦合方向性的任何信息。

脑连接表示的一项重要要求是信息流的方向。在这方面，提出了多变量频谱技术，如 `DTF` 或部分定向相干性 (`PDC`) [[16](#c08.xhtml#c8-bib-0016), [17](#c08.xhtml#c8-bib-0017)]，用于确定多变量数据集中任意给定通道对之间的定向影响。`DTF` 和 `PDC` [[17](#c08.xhtml#c8-bib-0017), [18](#c08.xhtml#c8-bib-0018)] 都依赖于时间序列之间格兰杰因果性的关键概念 [[19]](#c08.xhtml#c8-bib-0019)，根据该概念，如果观测时间序列 `x(t)` 的过去信息能显著改善对 `y(t)` 的预测，则称 `x(t)` 导致 `y(t)`；这种时间序列之间的关系不是互惠的，即 `x(t)` 可能导致 `y(t)`，而 `y(t)` 不一定导致 `x(t)`。这种非互惠性允许评估结构之间信息流的方向。

格兰杰因果性（也称为维纳-格兰杰因果性）[[19]](#c08.xhtml#c8-bib-0019) 试图从 EEG 中提取并量化方向性。它基于数据的双变量自回归 `AR` 估计。在多通道环境中，该因果性是通过电极的成对组合来计算的。该方法已被用于评估猫视觉系统中局部场电位的源运动方向性 [[20]](#c08.xhtml#c8-bib-0020)。

根据格兰杰因果性，如果一个时间序列 `y(t)` 的过去样本可用于预测另一个序列 `x(t)`，则称 `y(t)` 导致 `x(t)`。为了确定该因果性的估计值，考虑：

(8.2)
```
e(t) = x(t) − Σ(i=1 to p) â(i) x(t − i)
```

和

(8.3)
```
e1(t) = x(t) − Σ(i=1 to p) a11(i) x(t − i) − Σ(i=1 to p) a12(i) y(t − i)
```

这也意味着：

(8.4)
```
e2(t) = y(t) − Σ(i=1 to p) a22(i) y(t − i) − Σ(i=1 to p) a21(i) x(t − i)
```

格兰杰因果性指数定义为：

(8.5)
```
GCI(x(t)→y(t)) = ln(σ²_e2 / σ²_e1)
```

其中 `σ²_e1` 和 `σ²_e2` 分别是第一和第二信号的方差。当包含的通道改变残差方差比时，这种定义可以很容易地扩展到多通道情况。这是一种时域度量。然而，格兰杰因果性度量对独立噪声的任意混合很敏感。

## 8.3 相位斜率指数

为了克服噪声的影响并建立更稳健的连接度量，引入了相位斜率指数 (`PSI`) [[21]](#c08.xhtml#c8-bib-0021)。`PSI` 背后的主要思想是原因在时间上先于结果，因此两个时间序列之间交叉频谱相位的斜率反映了方向性 [[22]](#c08.xhtml#c8-bib-0022)。两个信号 `z[i](t)` 和 `z[j](t)` 的交叉频谱定义为：

(8.6)
```
Sij(f) = E[ Zi(f) Zj*(f) ]
```
