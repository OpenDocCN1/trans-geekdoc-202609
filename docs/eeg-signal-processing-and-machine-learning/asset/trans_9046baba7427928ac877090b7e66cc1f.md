
文献[135]中提出的用于估计类**C̃**<sub>i</sub>的正则化协方差矩阵的方法如下：

(17.17)
```
C̃_i = (1 - γ)P + γI
```

其中

(17.18)
```
P = (1 - β)C_i + βG_i
```

在上述方程中，`C_i`为初始空间协方差矩阵，`G_i`为所谓的通用协方差矩阵，`γ`和`β` ∈ [0, 1]为正则化参数。`G_i`通过对类别`i`的若干次试验的协方差矩阵求平均来进行经验估计。

在对CSP目标函数进行正则化时，相反地，向CSP目标函数添加一个正则化项，以惩罚不满足给定先验的结果空间滤波器。这导致了一个略有不同的目标函数，如文献[132]所示：

(17.19)
```
J(w) = (w^T C_{X_1} w) / (w^T C_{X_2} w + αQ(w))
```

其中，由惩罚参数`α` ≥ 0加权的惩罚函数`Q(w)`指示空间滤波器`w`在多大程度上满足给定先验。为了最大化`J(w)`，该项需要被最小化。遵循本书[第7章](#c07.xhtml)中的讨论，文献中定义了不同的二次和非二次惩罚函数，如文献[[132](#c17.xhtml#c17-bib-0132), [137](#c17.xhtml#c17-bib-0137)]和[[139](#c17.xhtml#c17-bib-0139)]中的那些。在文献[132]中实现11种不同正则化方法所取得的结果表明，在数据含噪的情况下，正则化平均可使结果提高约3%。然而，最佳算法在平均分类准确率上比CSP高出约3-4%，在中位数分类准确率上高出近10%。正则化方法也更稳健，即它们在各类别和受试者间表现出更低的方差。在各种方法中，文献[132]中提出的加权Tikhonov正则化CSP据报具有最佳性能。

在CSP中，通常并非使用所有EEG通道。在实际BCI应用中，如[图17.15](#c17.xhtml#c17-fig-0015)高亮显示的，从中央-顶叶头皮区域（运动皮层上方的电极）记录的数据，在实施CSP滤波器之前，首先在8至30 Hz之间进行带通滤波。

## 17.8 多类脑机接口

通常，一个用于执行完整BCI任务或检测各种身体运动的良好模型变得有用且重要。如果没有一个稳健的多类分类器，这是无法实现的。大多数文献涉及二分类问题，可使用SVM等高效分类器求解。对于通用应用，NNs等多类分类器一直是一种选择。此类算法的效率或计算复杂度通常受到质疑。

文献[28]中介绍了两种用于BCI的新分类方法。其中一个分类器基于到黎曼均值的距离，另一个在黎曼切空间中工作。显然，LDA、SVM和NNs等流行的分类算法无法直接在黎曼流形上实现，因为它们基于投影到超平面。

在该BCI方法中，考虑短时片段，每个片段包含EEG信号的`T_s`个采样点或试验，形式为矩阵`X_i = [x_{t+T_i} ... x_{t+T_i+T_s-1}] ∈ R^{n×T_s}`，对应于时间`T_i`开始的真实或想象运动的第*i*次试验。定义`P_i`为*n* × *n*样本协方差矩阵：

[(17.20)](#c17.xhtml#R_c17-disp-0021)
```
P_i = (1 / (T_s - 1)) X_i X_i^T
```
