

## 12.7 基于 EEG 和多模态 PSG 分析的睡眠期脑异常检测与监测

EEG 为睡眠期大脑提供了重要且独特的信息。PSG 一直是一项成熟的睡眠分析方法，也是睡眠医学中的主要诊断工具，它根据 R&K 解释的标准对睡眠信号的宏观结构进行解读 [[50]](#c12.xhtml#c12-bib-0050)。多导睡眠图或睡眠研究是一项多参数测试，对睡眠期间发生的生理生物学变化进行全面记录。通常在夜间进行。PSG 监测睡眠期间的多种身体功能，包括大脑 (EEG)、眼动 (EOG)、肌肉活动或骨骼肌激活 (EMG) 以及心律 (ECG)。

### 12.7.1 睡眠呼吸暂停分析

睡眠呼吸暂停综合征 (SAS)、慢性打鼾和日间过度嗜睡会给日常生活带来问题，并产生短期和长期的生理及心理影响。自 20 世纪 70 年代识别出睡眠呼吸暂停后，PSG 已被用作金标准，结合并评估呼吸、外周脉搏血氧测定、心率以及两导 EEG，以评估这些疾病。后来，记录的打鼾声成为研究的主要焦点。总体而言，研究表明，并非 PSG 记录的所有信号都用于评估呼吸暂停或低通气 [[51](#c12.xhtml#c12-bib-0051)–[53](#c12.xhtml#c12-bib-0053)]。文献 [[51](#c12.xhtml#c12-bib-0051), [52](#c12.xhtml#c12-bib-0052)] 中表明，打鼾声和血氧仪输出的 SpO2 值可用于呼吸暂停分析。也有报告称仅使用这两种模态中的一种即可，即声音信号 [[53]](#c12.xhtml#c12-bib-0053) 或使用血氧仪评估低氧血症 [[54]](#c12.xhtml#c12-bib-0054) 足以评估呼吸暂停。然而，睡眠纺锤波和慢波活动、觉醒及相关活动可从 EEG 信号中检测并在睡眠期间进行监测。对于呼吸暂停分析，描述这些活动通常需要将信号在时间上分割为 20–30 秒的固定片段。
