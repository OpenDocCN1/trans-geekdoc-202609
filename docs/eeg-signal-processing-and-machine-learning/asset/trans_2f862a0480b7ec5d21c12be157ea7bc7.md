
其中 `X(z)`、`T(z)` 和 `E(z)` 分别代表 z 域观测（或测量）信号、平均 EP 和高斯白噪声。假设背景 EEG 在统计上是平稳的，`W(z)` 通过预刺激数据的自回归（AR）建模从预刺激区间识别得出，并用于刺激后分析 [[35]](#c09.xhtml#c9-bib-0035)。模板和测量的 EEG 通过识别出的 `W(z)` 进行滤波以使背景 EEG 信号白化，从而建立模型的闭式最小二乘（LS）解。因此，唯一需要识别的参数是矩阵 `B[i](z)`。这避免了对模型参数进行任何迭代识别。这可以用回归型方程表示为：

(9.5)
```
x̂(n) = Σ(i=1 to p) Σ(j=-d to d) b_{i,j} · T̂_i(n-j) + e(n)
```

其中 `d` 表示延迟（潜伏期），`p` 是模板的数量，`x̃(n)` `T̃(n)` 分别是 `x(n)` 和 `T(n)` 的白化版本。令 `A^(T)` 为输入模板矩阵，`b^(T)` 为滤波器系数向量；则我们构造：

(9.6)
```
x̂ = [x̂(d+1), x̂(d+2), …, x̂(N-d)]^T,
```
