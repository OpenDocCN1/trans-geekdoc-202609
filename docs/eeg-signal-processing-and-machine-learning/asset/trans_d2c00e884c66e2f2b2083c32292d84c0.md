### 7.3.14 隐马尔可夫模型

HMM 是状态空间机器，旨在检测可能发生在较长数据序列中的正确数据序列。HMM 以状态图的形式呈现。因此，对于每个应用，HMM 都有一定数量的状态，并知道每个状态中每个可能事件发生的概率。在介绍 HMM 在 EEG 中的应用之前，一个有助于更好理解 HMM 概念的好例子是 [图 7.16](#c07.xhtml#c7-fig-0016) 中所示的心电图 (ECG) 信号中的 QRS 波检测。

从 [图 7.16](#c07.xhtml#c7-fig-0016) 可知，当符号在信号中按正确顺序出现时，即可识别出 ECG。假设 [图 7.16](#c07.xhtml#c7-fig-0016) 中的波形是健康受试者的 ECG，则只要在其 ECG 记录中检测到上述 ECG 序列，[图 7.17](#c07.xhtml#c7-fig-0017) 中的状态图即将该受试者分类为健康。

在该图中，状态 `Q[0]` 是等待状态，用于检测从竖线 (b) 开始的序列开头。状态 `Q[1]` 表示已检测到竖线。状态 `Q[2]` 仅表明已识别出竖线和一个小驼峰 (p)。`Q[3]` 表示竖线、小驼峰和 QRS 波正确排序时的系统状态。`Q[4]` 和 `Q[5]` 类似地显示了在数据序列中分别添加了竖线和大驼峰 (t) 后的状态。检测到正确序列后，输出为“受试者健康”。在每个状态之后，如果检测到错误符号或噪声，系统输出为“受试者不健康”。

在需要检测特定心脏状况的场合，应设计单独的 HMM 来识别该状况。除了在生物医学信号分析和疾病识别中的应用外，HMM 在语音、视频、生物科学（如基因组学）和人脸识别等领域也有广泛应用。

为了使用 HMM 进行分类，应已知初始状态（`π = π[i]`，其中 `i = 1, …, N`，`N` 为状态数）、状态概率（`A = {a[ij]}`，`i,j = 1, …, N`）和状态转移概率（`B = {b[j](k)}`，`j = 1, …, N`，`k = 1, …, T`，其中 `T` 为观测序列长度）。然而，对于 HMM 的训练（即寻找模型参数），则应已知一组观测值和状态数。

在使用或设计 HMM 时存在三个主要问题（目标）：

1.  给定观测序列 `O = o[1], o[2], …, o[T]` 和模型 `λ = (A, B, π)`，观测序列的概率 `p(O|λ)` 将是多少？

2.  给定上述观测序列和模型，如何找到生成此类观测序列的状态序列 `Q = Q[1], …, Q[N]`？

3.  给定观测值和状态数，如何构建 HMM 模型，即如何求得 `λ = (A, B, π)`。

求解第一个问题时，通常使用迭代前向-后向算法；求解第二个问题时，则采用维特比算法。最后，可以使用一些算法（其中最流行的是 Baum-Welch 算法（Leonard E Baum，1960年代）[[149]](#c07.xhtml#c7-bib-0149)，[[150]](#c07.xhtml#c7-bib-0150)）来求解第三个问题，这也是最重要的一个。
