

### 18.3.5.3 脑电与功能性磁共振的融合；基于模型的方法

PMBR 与 fMRI 之间的相关性已被用于建立一种基于数据驱动的 EEG–fMRI 融合方法，该方法利用从 EEG 信号中提取的信息作为 BOLD 信号的预测变量。为此，利用上一节提出的方法获得的罗兰多 β 节律的功率时间进程。计算出的功率时间进程代表了 β 频带 EEG 活动与运动任务之间的瞬时相互作用。然后将功率时间进程与 HRF 卷积，以生成用于 fMRI 分析的回归量。该回归量用于预测与 EEG 同时采集的 fMRI 数据中的 BOLD 响应。数据分析的示意图如 [图 18.19](#c18.xhtml#c18-fig-0019) 所示。

### 18.3.6 在癫痫发作检测中的应用

尽管受限于缺乏合适的时间进程，但在癫痫等病理情况下，在线性简化假设下工作一直是一项成功的策略，可充分利用 fMRI 的高空间分辨率和无创性 [[95]](#c18.xhtml#c18-bib-0095)。因此，越来越多的工程和临床研究已将 EEG–fMRI 转变为一种强大的工具，用于研究癫痫网络中自发脑活动相关的血流动力学变化，包括皮层下变化，以及研究清醒和睡眠期间的内源性脑节律和诱发脑活动 [[25]](#c18.xhtml#c18-bib-0025)。

神经元群体与脑区之间的相互作用（宏观尺度，外在连接）构成了动态因果建模（DCM）的基础。EEG 信号源自锥体细胞产生的瞬时电位，并通过头部体积传导。在细胞层面，fMRI 信号是发生在秒级时间尺度上的代谢和血流动力学级联的最终结果。对称融合模型依赖于寻找这些模型的逆解，以估计潜在神经元群体的神经活动和连接性 [[25]](#c18.xhtml#c18-bib-0025)。

#### 方程 (18.26)–(18.30)

(18.26)
```
A ← (Y₁(C ⊙ F) + λMR)((CᵀC) ⊙ (FᵀF) + λRᵀR)†
```

(18.27)
```
F ← Y₂(C ⊙ A)((CᵀC) ⊙ (AᵀA))†
```

(18.28)
```
C ← Y₃(F ⊙ A)((FᵀF) ⊙ (AᵀA))†
```

(18.29)
```
M_uk ← (ARᵀ[:, K+1:L])
```

其中 ⊙ 和 ⊗ 分别为 Khatri-Rao 积和 Hadamard 积。为了计算排列矩阵 `R`，执行与计算 `P[k]` 相同的过程。由于 `R` 是正交规范矩阵，对 `R` 最小化 [(18.22)](#c18.xhtml#c18-disp-0026) 简化为：

(18.30)
```
R ← argmax_R {tr(R Aᵀ M)}
```

令 `A⁽ᵀ⁾ M = U∑V⁽ᵀ⁾`，则 [(18.28)](#c18.xhtml#c18-disp-0032) 的唯一最小值为 `R = VU⁽ᵀ⁾ R = VU⁽ᵀ⁾`。所得矩阵 `R` 为正交规范矩阵。若 λ 随迭代次数减小，性能会提升。
