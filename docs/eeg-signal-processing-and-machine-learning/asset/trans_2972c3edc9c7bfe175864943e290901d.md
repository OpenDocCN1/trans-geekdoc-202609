

与 Hodgkin-Huxley 模型中的钠电流类似，钙电流也是一种内向电流。由于钙激活电流相对于钾电流而言是一个快速过程，因此将其建模为瞬时函数。这意味着对于每个电压 `E`，都要计算稳态函数 `a[Ca](E)`。钙电流不包含任何失活过程。此处的激活变量 `w[k]` 类似于 Hodgkin-Huxley 模型中的 `a[k]`，最后，两个模型的漏电流是相同的 [[12]](#c03.xhtml#c3-bib-0012)。[图 3.6](#c03.xhtml#c3-fig-0006) 展示了 Morris-Lecar 模型的仿真。

钙依赖性钾通道由细胞内钙激活；钙浓度越高，通道激活程度越高 [[12]](#c03.xhtml#c3-bib-0012)。为了使 Morris-Lecar 模型表现出爆发行为，必须改变最大时间常数和输入电流这两个参数 [[12]](#c03.xhtml#c3-bib-0012)。[图 3.7](#c03.xhtml#c3-fig-0007) 展示了 Morris-Lecar 模型的爆发行为。爆发神经元的基本特征包括尖峰活动的持续时间、爆发期间动作电位（AP）的频率以及静息期的持续时间。一次完整爆发事件的周期是活跃期持续时间与静息期持续时间之和 [[12]](#c03.xhtml#c3-bib-0012)。

神经元通过轴突-树突或树突-树突连接跨越突触进行相互通信，这些连接可以是兴奋性的、抑制性的或电性的 [[12]](#c03.xhtml#c3-bib-0012)。通过组合上述多个模型，可以构建一个神经网络。由于神经元之间的突触连接，该网络表现出振荡行为。通常认为，兴奋性突触耦合倾向于使神经元放电同步化，而抑制性耦合则推动神经元走向反同步。这种行为已在神经回路模型中被观察到 [[1]](#c03.xhtml#c3-bib-0001)。

一旦神经元发放动作电位，就会产生突触电流。该电流刺激相连的神经元，可用一个 Alpha 函数乘以最大电导和驱动力来建模，公式如下：

(3.33)
```
I[syn] = ḡ[syn] · g[syn](t) · (E(t) − E[syn])
```

其中：

(3.34)
```
g[syn](t) = t · e^(−t/u)
```

`t` 为潜伏期或自突触电流触发以来的时间，`u` 为达到峰值振幅所需的时间，`E[syn]` 为突触反转电位，`ḡ[syn]` 为最大突触电导。参数 `u` 改变电流的持续时间，而 `ḡ[syn]` 改变电流的强度。这结束了对动作电位建模的论述。

由于 EEG 信号源的性质无法直接从电极信号中确定，许多研究人员尝试利用信号处理技术提取的信息来对这些过程进行建模。本章后面章节描述的线性预测（LP）方法常用于提取参数描述。

David Beeman 关于使用 Hodgkin-Huxley 兴奋模型进行真实神经建模的教程，已记录在 2005 年于美国德克萨斯州举行的首届世界建模者协会（WAM）生物学精确建模会议（BAMM）上。可在 [http://www.brains‐minds‐media.org/archive/218](http://www.brains-minds-media.org/archive/218) 查看。

## 3.3 基于神经元活动建模生成 EEG 信号

本节旨在介绍一些用于生成正常和某些异常 EEG 的成熟模型。这些模型通常是非线性的，其中一些被提出 [[15]](#c03.xhtml#c3-bib-0015) 用于建模正常 EEG 信号，另一些则用于建模异常 EEG。

一种简单的分布式模型由一组模拟神经元、丘脑皮层传递细胞和中间神经元组成，该模型 [[16](#c03.xhtml#c3-bib-0016), [17](#c03.xhtml#c3-bib-0017)] 融合了当时有限的生理学和组织学数据。其基本假设足以解释 α 节律的产生，即频率范围在 8–13 Hz 内的 EEG。

一个通用的非线性集总模型可采用 [图 3.8](#c03.xhtml#c3-fig-0008) 所示的形式。尽管该模型本质上是模拟的，但所有模块均以离散形式实现。该模型能够考虑分布式模型的主要特征，且便于研究改变丘脑皮层传递细胞和中间神经元的兴奋性和抑制性影响范围所产生的结果。
