
大多数癫痫预测研究均基于 iEEG 记录。将先前的方法应用于头皮 EEG 数据面临两大主要挑战：(i) 头皮信号比 iEEG 更易受环境噪声和伪迹影响；(ii) 有意义的信号在通过软组织和骨骼传播时会衰减和混合。传统非线性方法 (TNMs)，如柯尔莫哥洛夫熵或李雅普诺夫指数，可能受上述两大困难影响，因此可能无法区分头皮 EEG 略有不同的混沌状态 [\[88\]](#c11.xhtml#c11-bib-0088)。规避这些困难的一种途径是定义不同的非线性度量，使其在头皮 EEG 上的表现优于 TNM。Hively 和 Protopopescu [\[89\]](#c11.xhtml#c11-bib-0089) 即采用此途径。他们提出了一种基于相空间非相似性度量 (PSDM) 的方法，用于根据头皮 EEG 预警癫痫发作。Iasemidis 等人提出的动态同步方法也已被证明在头皮未滤波 EEG 数据的癫痫发作预测中效果良好 \[[90](#c11.xhtml#c11-bib-0090)–[92](#c11.xhtml#c11-bib-0092)\]。

原则上，非线性系统可以位于高维或无限维相空间中。然而，当系统进入稳态时，相空间的某些部分会随时间被重复访问，系统位于相空间的一个子集中，该子集具有有限且通常较小的维数，称为**吸引子**。当该吸引子对初始条件具有敏感依赖性（即呈混沌状态）时，称为**奇异**吸引子，其几何复杂性由其维数 `D[a]` 反映。在实践中，系统的方程通常不可用，我们只有代表系统的单一可观测量 `u(n)` 的离散测量值。如果系统进入这种稳态，可以通过从原始可观测量 `u(n)` 生成 `p` 个不同的标量信号 `x[i](n)`，并将它们嵌入 `p` 维向量来重构 `p` 维相空间：

[(11.17)](#c11.xhtml#R_c11-disp-0018)
```
x(n) = [x1(n), x2(n), …, xp(n)]^T
```

根据 Takens [\[93\]](#c11.xhtml#c11-bib-0093) 的理论，如果 `p` 选取足够大，通常可以获得吸引子的良好相图，从而获得非线性量的良好估计。特别地，Takens 定理指出嵌入维数 `p` 至少应等于 `2 × D[a] + 1`。从 `u(n)` 获取嵌入向量 `x(n)` 最简单且可能最好的方法是**延迟法**。根据该方法，选择 `p` 个不同的时间延迟 `n[0] = 0, n[1] = τ, n[2] = 2τ, …, n[p] = (p − 1)τ`，并获得 `p` 个不同的标量信号 `x[i](n) = x(n + n[i])`（`i = 0, …, p − 1`）。若 `τ` 选取得当，可获得吸引子的良好相图，从而获得非线性行为参数的良好估计。

由于大脑是非平稳系统，从严格动力学意义上讲，它永不处于稳态。然而，可将其视为一个不断从一个稳定稳态移动到另一个稳定稳态的动力系统。因此，非线性度量的局部估计是可能的，这些量的变化应代表大脑的动力学变化。

先前的研究已证明，癫痫发作期间癫痫大脑的状态比发作前或发作后更有序。相关维数已被用于估计发作状态的维数 `d` [\[77\]](#c11.xhtml#c11-bib-0077)。获得的值在 2 到 3 之间，证明了低维吸引子的存在。因此，嵌入维数为 7 应足以获得该吸引子的良好图像和发作状态的良好空间图像。正如[第 2 章](#c02.xhtml)所述，将 `p` 的值增加到严格必要之以上会增加噪声的影响，因此不建议使用更高的 `p` 值。

一种新方法 [\[94\]](#c11.xhtml#c11-bib-0094) 表明，TNMs 可间接应用于头皮 EEG。这要求在没有关于源信号或信号组合方式的任何先验信息的情况下，正确地将大脑的潜在源从观测到的电极信号中分离出来。遵循相同策略也能高度缓解噪声和其他内部及外部伪迹的影响。预期可获得类似于颅内记录的信号，从而可应用 TNM。为此，信号片段首先通过盲源分离 (BSS)（假设源相互独立）分离为其组成源。由于实际预测算法要求在长程 EEG 记录上量化非线性动力学。使用基于分块的 BSS 算法后，必须保持整个记录的连续性。由于 BSS 固有的两大模糊性，该问题并不容易：(i) 独立分量的方差（能量）未知；(ii) 由于 BSS 算法固有的排列问题，无法确定独立分量的顺序。

第一种模糊性表明源只能估计到一个标量因子。因此，在从一个分块移动到另一个分块时，源幅度通常不同，信号可能被反转。如下所述，这种模糊性可被解决，从而避免其影响。非线性动力学由最大李雅普诺夫指数 `λ[1]` 量化。每个分块的 `λ[1]` 估计基于分块内点间距离的比率。因此，只要 `λ[1]` 是针对对每个 EEG 数据分块单独应用 BSS 获得的源进行估计的，就无需调整源的能量。

然而，第二种模糊性严重影响算法。BSS 算法输出的估计源顺序会从分块到分块发生变化。因此，我们需要一个过程对信号重新排序，以对齐从一个分块到另一个分块的同一信号，并保持整个记录的连续性。下一节将解释我们算法中为此目的采用的方法。

我们采用重叠窗口法来保持估计源的连续性，同时解决这两种不确定性。我们不将 EEG 记录划分为顺序且不连续的分块，而是采用固定长度 `L`、重叠 `L-N` 个样本（`N < L`）的滑动窗口，并将 BSS 算法应用于该窗口内的数据分块。因此，我们假设 `x(n) = [x1(n), x2(n), …, xm(n)]^T` 代表整个头皮 EEG 记录，其中 `m` 为传感器数量。选择两个连续的数据窗口为 `x1(n) = x(n0 + n)` 和 `x2(n) = x(n0 + N + n)`（`t = 1, …, L`），其中 `n0 ≥ 0`。因此
