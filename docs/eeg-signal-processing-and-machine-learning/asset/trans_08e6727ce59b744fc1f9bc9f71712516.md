
此外，rTMS影响下的FD变化使临床医生能够明确判断刺激效果是积极还是消极，同时也让治疗师能够评估rTMS的最佳时机。

在一种BCI类型的方法[\[43\]](#c16.xhtml#c16-bib-0043)中，视觉刺激由快乐面孔和悲伤面孔图片组成。男性/女性和悲伤/快乐的人群比例均为1。此外，单词"happy"或"sad"写在每张面孔的中心。在一致任务中，图片中的面部表情与单词的含义（悲伤或快乐）一致。在不一致任务中，面孔图片中的面部表情与单词不同。一个示例可见[图16.2](#c16.xhtml#c16-fig-0002)。随后要求受试者判断面孔是悲伤还是快乐，并通过立即按下底部按钮之一作出反应。左键代表悲伤，右键代表快乐。刺激的顺序是伪随机的，悲伤和快乐的概率相等。

在一个简单的ERP实验后，关注的参数是正确回答试验的反应时（`RT`）以及对情绪面孔和一致/不一致状态的反应准确率（`ACR`）。对于两组（抑郁组和对照组），根据两种任务提取并平均了相应的历元。每个历元的长度为1000 ms（刺激前200 ms和刺激后800 ms）。分别选择了预期潜伏窗口为[80, 120]、[120, 200]、[200, 300]、[300, 400]和[400, 600]毫秒的N100、P200、N200、P300和N450进行分析，并对所有通道进行了平均。从其产生的ERP波形中，可以明显看出P300和N450振幅在不一致和一致状态下均有所下降。

为了估算`RT`和`ACR`，作者采用了文献[\[44\]](#c16.xhtml#c16-bib-0044)中的动态时间规整方法。结果显示，抑郁受试者在一致和不一致状态下的`RT`均增加了约40 ms。对于一致状态，`ACR`下降约3%；对于不一致状态，`ACR`下降约6%，两种情况下抑郁受试者的方差均明显较高。

在一种基于EEG的抑郁症评估的普适特征方法中，仅使用了`Fp1`、`Fp2`和`Fpz`三个通道，耳垂电极接地[\[45\]](#c16.xhtml#c16-bib-0045)。向受试者展示了六个视频，包括两个中性、两个负面和两个正面视频，每个播放90秒，间隔6秒。计算了大量特征，包括线性时域和频域特征（质心频率、相对质心频率、绝对质心频率、相对功率、绝对功率、峰值、方差、偏度、峰度和Hjorth参数）以及动态（非线性）特征（功率谱熵、香农熵、相关维数、C0复杂度和柯尔莫哥洛夫熵）[\[45\]](#c16.xhtml#c16-bib-0045)。对于所选特征的分类，他们测试了不同的分类器，并得出结论：使用k近邻（`kNN`）可达到最佳分类率（超过76%）。

人们认为，使用各种刺激并应用准确的单次试验ERP成分追踪技术，可以成为监测抑郁水平的一种非常有前景的方法。传统上，枕叶α节律和顶叶μ节律振幅的降低，仍然是区分抑郁症患者和健康受试者的稳健指标。

#### 16.2.3.2 用于监测双相情感障碍的EEG

双相情感障碍（`BP`），又称躁郁症，一生中约每50名成年人中就有1人会在某个阶段患病。`BP`包括四种类型：经典躁郁症（双相I型障碍）、双相II型障碍、环性心境障碍和未另行分类的`BP`。这些是常见的、终身的、危及生命的疾病，与功能和临床预后不良及高自杀率相关[\[46\]](#c16.xhtml#c16-bib-0046)。通常发病于15至25岁之间，50岁后发病罕见。`BP`的四种类型取决于其发作的持续时间和严重程度以及情绪波动[\[47\]](#c16.xhtml#c16-bib-0047)。

多种筛查模式在`BP`的检测和监测中很流行，如基于视频/音频的方法[\[48\]](#c16.xhtml#c16-bib-0048)，以及通过自评量表评估社会/情绪节律[\[46\]](#c16.xhtml#c16-bib-0046)。目前专门使用EEG评估`BP`及其亚型的研究仍然有限。

将EEG应用于`BP`的一个例子见于文献[\[41\]](#c16.xhtml#c16-bib-0041)，也在[16.2.3.1节](#c16.xhtml#c16-sec-0013)中简要回顾，该研究调查了rTMS对抑郁症和双相情感障碍受试者的影响。他们的方法利用功能连接来区分抑郁症、双相情感障碍和对照组。

在另一项尝试中，研究人员试图对`BP`的I型和II型进行分类[\[25\]](#c16.xhtml#c16-bib-0025)。他们结合并分类了形态学、时域、频域和时频域特征，以及非线性特征，如近似熵和互信息。该研究声称取得了合理的准确率。

相反，`BP`与精神分裂症症状之间存在重叠，这可能导致诊断上的模糊性。文献[\[49\]](#c16.xhtml#c16-bib-0049)考虑了这一问题；向精神分裂症组和`BD`患者组呈现了以16 Hz调制的光刺激，持续95秒，期间记录EEG数据。利用稳态视觉诱发电位（`SSVEPs`）的统计量（均值、偏度和峰度）进行评估和分类。来自大脑额叶和枕叶区域的指标在两组之间显示出统计学显著差异。

### 16.2.4 精神分裂症

#### 16.2.4.1 精神分裂症的症状与管理

精神分裂症是一种慢性脑部疾病，影响全球不到0.8%的人口。当精神分裂症处于活跃期时，患者表现出高水平的思维和感知障碍，并在处理人际关系时感到极度困难。症状可能包括妄想、幻觉、言语紊乱、思维困难和缺乏动力。然而，经过治疗，大多数精神分裂症症状会改善，复发的可能性也会降低。虽然目前尚无彻底治愈精神分裂症的方法，但研究正在带来创新且更安全的治疗手段。
