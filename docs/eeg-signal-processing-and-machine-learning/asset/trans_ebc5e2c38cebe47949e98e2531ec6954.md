

# fNIRS在情绪障碍中的应用

fNIRS在抑郁症和双相情感障碍等情绪障碍的研究中具有应用价值。研究发现，近一半的重度抑郁症患者表现出健康个体未见的非优势半球反应模式。根据惯用手情况，`TotHb`在左半球的增加程度明显低于右半球。另一半抑郁症患者则表现出双侧反应模式，即在镜画任务下，`HbT`、`HbO`和`HbR`在双侧半球相当。此外，还有观点认为抑郁症的病程与反应模式之间可能存在某种相关性 [\[17\]](#c18.xhtml#c18-bib-0017)。fNIRS不仅能测量抑郁症的病程和大脑激活模式，其应用还可延伸至重复经颅磁刺激（`rTMS`）和电休克疗法（`ECT`）等治疗模式 [\[18\]](#c18.xhtml#c18-bib-0018)。

## 焦虑障碍研究

焦虑障碍的研究也表明，当面对与焦虑相关或与焦虑无关但非情绪相关的刺激时，患者的左额叶`HbO`显著低于对照组受试者。该研究未发现患者或对照组受试者在观察任何刺激时存在额叶脑不对称的证据 [\[19\]](#c18.xhtml#c18-bib-0019)。

## PTSD评估

文献[\[20\]](#c18.xhtml#c18-bib-0020)使用多通道fNIRS系统，在播放创伤相关和对照刺激视频期间，监测前额叶皮层的`HR`和皮肤电反应（`SCR`）。结果显示，无论是患有创伤后应激障碍（`PTSD`）的受害者组，还是未患`PTSD`的受害者组，前额叶皮层的`HbO`均显著升高。然而，`PTSD`受试者的`HbO`和`HbT`增幅小于非`PTSD`受试者，且伴随`SCR`增强。由于氧合血红蛋白的增加在创伤相关刺激后至少持续三分钟，这种持久的心理生理反应与既往使用脉搏、血压、`SCR`和肌电图等其他测量指标的研究结果一致。因此，有观点认为利用fNIRS测量大脑`HR`对于`PTSD`的心理生理评估是有用的。

## 局限性与优势

尽管如此，尽管存在这些优势和应用，fNIRS仍是一项新兴技术，需要与其他更成熟的功能性神经成像模态进行更多的交叉验证。然而，它是一项极具前景的神经成像技术，因为与`fMRI`等传统神经成像系统相比，它的成本低得多。fNIRS的第二大关键优势是受试者实验运行的货币成本低，这使得社会神经科学家能够通过招募更大样本量来增强研究的统计效能。最后，fNIRS成像系统速度快，相对不受受试者运动干扰，且具有便携、紧凑且日益小型化的设计。这意味着fNIRS可灵活部署于自然情境中，从而增强生态效度 [\[13\]](#c18.xhtml#c18-bib-0013)。

# 18.2.3 脑磁图

`MEG`是测量神经元电活动产生的磁场。一个常见的假设是，每个神经元发生器等效于一个电流偶极子。因此，`MEG`数据重建的原理基于等效电流偶极子（`ECD`）模型 [\[21\]](#c18.xhtml#c18-bib-0021)。`MEG`磁场穿过头部时不产生任何畸变。这是`MEG`相对于`EEG`的一个显著优势。由于电极（磁线圈——256个及以上）数量相对较多，`MEG`提供了高时空分辨率。`MEG`数据外观类似于`EEG`。基于上述原因，与`EEG`相比，`MEG`在脑源定位方面具有更广泛的应用 \[[22](#c18.xhtml#c18-bib-0022), [23](#c18.xhtml#c18-bib-0023)\]，如事件相关电位（`ERP`）和癫痫灶定位。尽管如此，由于系统和维护成本高昂，`MEG`的应用受到限制 [\[24\]](#c18.xhtml#c18-bib-0024)。

# 18.3 联合EEG–fMRI

## 18.3.1 EEG与fMRI的关系

自20世纪90年代末以来，同步`EEG`–`fMRI`，或更准确地说，`EEG`相关`fMRI`，已作为一种无创脑成像技术出现 [\[25\]](#c18.xhtml#c18-bib-0025)。虽然`EEG`能提供具有高时间分辨率的突触活动直接表征，但由于空间分辨率低，仅凭`EEG`识别潜在的神经元源是不完整的。相反，`fMRI`具有高空间分辨率，但耗时很长（每层扫描约需一到两秒，或全脑扫描需两分钟以上），远超`EEG`。`fMRI`的低时间分辨率忽略了大脑对刺激的快速变化反应。因此，`EEG`和`fMRI`相互补充。

`fMRI`捕获的血流动力学脑反应反映了神经元活动的间接或次级效应。相比之下，`EEG`是突触活动的直接测量。因此，推导`EEG`和`fMRI`之间的生理关系，取决于理解`EEG`捕获的神经元活动变化如何影响`fMRI` `BOLD`信号。然而，这种关系并非简单直接。

解读`fMRI`图谱的一个基本假设是：区域性“神经元活动”（局部神经元群体对抑制性和兴奋性输入及神经元间前馈和反馈活动的整体突触产物）增加，会导致代谢需求（神经元和星形胶质细胞）增加，伴随能量和氧消耗增加。为响应这些神经代谢变化，局部脑灌注量上升，超过了代谢需求。因此，尽管总氧消耗增加，但局部静脉血中的氧提取分数和脱氧血红蛋白百分比降低（`fMRI`记录到的正`BOLD`变化）。在一个包含前向和后向兴奋性及抑制性连接的神经网络中，`BOLD`信号变化反映了与精心定义的基线相比，网络“状态”的变化。局部场电位的变化提供了对`HR`的最佳估计 [\[25\]](#c18.xhtml#c18-bib-0025)。其潜在机制如[图 18.5](#c18.xhtml#c18-fig-0005)所示。
