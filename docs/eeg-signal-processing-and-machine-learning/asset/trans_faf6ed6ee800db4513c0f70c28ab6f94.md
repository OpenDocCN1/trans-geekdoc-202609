

# BCI

BCI 涉及对一组头皮电极或植入大脑皮层或脑内的电极所检测和提取的复杂神经生理行为进行分析、概念化、监测、测量和评估。各个身体部位的运动相关节律从运动皮层获取。图 [17.1](#c17.xhtml#c17-fig-0001) 的示意图中展示了运动皮层的横截面，显示了与每个器官相关的区域。

BCI 系统应易于使用、有效、在计算时间和适应性方面高效，且用户友好。BCI 是一个多学科交叉的研究领域，因为它涉及认知、神经生理学、心理学、传感器设计、定位、电路和通信、机器学习、信号检测和信号处理。

BCI 现已在许多机构和不同国家普及。然而，作为 BCI 领域的先驱，柏林 BCI (BBCI) 小组成立于 2000 年，一直遵循将训练工作从人类转移到机器的目标。他们工作的主要重点是通过最小化受试者训练水平来减少 BCI 的受试者间变异性。他们的部分成果已报道于文献 [[6](#c17.xhtml#c17-bib-0006)–[8](#c17.xhtml#c17-bib-0008)] 中。Wadsworth BCI 研究小组主要在训练受试者后，利用 μ 节律的事件相关去同步化 (ERD) 对真实或想象运动的 EEG 进行分类 [[9](#c17.xhtml#c17-bib-0009), [10](#c17.xhtml#c17-bib-0010)]。在奥地利，Graz BCI 研究组利用 μ 或 β 节律进行训练和控制。他们的系统专家用户能够基于感觉运动皮层前中央 μ 或 β 节律的调制来控制设备，这与 Wadsworth BCI 方法类似。然而，Wadsworth BCI 直接向用户呈现功率调制，而 Graz 系统首次也利用机器适应来控制 BCI。他们还成功让一名残疾患者通过由 EEG 信号控制的功能性电刺激 (FES) 实现了无功能手臂的抓握动作 [[11](#c17.xhtml#c17-bib-0011)–[15](#c17.xhtml#c17-bib-0015)]。相反，Martigny BCI 与 BBCI 并行，起步于自适应 BCI。研究人员提出了一种基于线性判别分析 (LDA) 的神经网络 (NN) 分类器，用于静态特征的分类 [[16](#c17.xhtml#c17-bib-0016)]。在他们的方法中，三名受试者在几天的训练后，在异步环境下通过想象左手或右手运动或闭眼放松，能够达到 75% 的正确分类率 [[17](#c17.xhtml#c17-bib-0017), [18](#c17.xhtml#c17-bib-0018)]。最后，主要为闭锁综合征患者开发的思维转换装置 (TTD)，使受试者能够利用 EEG 或皮层脑电图 (ECoG) 学习中枢头皮部位慢皮层电位 (SCPs) 的自我调节。受试者能够产生二元决策，并有望为外部世界提供一个合适的沟通通道 [[19](#c17.xhtml#c17-bib-0019)]。

近年来，侵入式和非侵入式传感器设计、神经植入物以及无线记录系统的可用性的改进，加上信号处理和机器学习技术的进步，进一步提升了 BCI 系统的使用率和准确性。

其他相关技术，如多受试者记录（也称为 EEG 超扫描），以及虚拟现实和增强现实的惊人参与，极大地推动了 BCI 在人类心理（如情绪）和生理（如中风或瘫痪）康复方面的应用。

除了基于 EEG 的 BCI，其他功能性脑扫描模态（如 fMRI）单独使用或与 EEG 联合使用也开始被采用。本章回顾了利用 EEG 信号进行 BCI 设计的基本概念和要求，并简要介绍了一些最新的应用。

## 17.1.1 BCI 的最新进展

EEG 模式与计算机动作之间的对应关系构成了一个机器学习问题，因为计算机必须学会如何识别给定的 EEG 模式。与其他学习问题一样，为了解决这个问题，需要一个训练阶段，在此阶段要求受试者执行规定的心理活动，而计算机算法负责提取相关的 EEG 模式。训练阶段结束后，受试者应能凭借思想控制计算机动作。这是 BCI 系统的主要目标。

就信号获取而言，BCI 系统分为侵入式（颅内）和非侵入式。非侵入式系统主要利用 EEG 来控制计算机光标或机械臂。由于这类系统无创且灵活，其设计技术多年来一直在发展 [[1](#c17.xhtml#c17-bib-0001)[19](#c17.xhtml#c17-bib-0019)–[27](#c17.xhtml#c17-bib-0027)]。然而，尽管避免了让患者承担脑部手术的风险，但基于 EEG 的技术提供的信息有限，主要原因是现有技术的局限性、头部体积传导（严重扭曲了单个神经元的皮层活动）以及生理和干扰性的非期望信号、噪声和伪迹。然而，尽管存在这些缺点，基于 EEG 的方法仍能检测到与视觉刺激、注视角度、自主意图和认知状态相关的大脑活动调制 [[5](#c17.xhtml#c17-bib-0005)]。这些优势促成了几类基于 EEG 系统的发展，它们根据记录的皮层区域、提取的 EEG 特征以及向受试者提供反馈的感觉模态而有所不同。在特征检测和分类方面，常见空间模式 (CSP)、决策树、基于黎曼几何的分类 [[28](#c17.xhtml#c17-bib-0028), [29](#c17.xhtml#c17-bib-0029)] 以及利用深度神经网络 (DNN) 的迁移学习是最流行的技术。

在视觉、听觉和触觉（触觉或躯体感觉）这三种常用于反馈 BCI 系统的模态中，最有效的反馈是视觉和触觉。Kauhanen 等人 [[30](#c17.xhtml#c17-bib-0030)] 的一篇短文得出结论，视觉和触觉反馈对大脑有相似的影响。触觉反馈对于盲人受试者可能是必要的。听觉反馈实验通常报告的准确性较低。然而，在一篇综述中强调，触觉反馈提供的感觉比纯视觉环境 [[31](#c17.xhtml#c17-bib-0031)] 更完整、更具沉浸感。触觉反馈涉及触觉和本体感觉模态，因此有助于在重复执行任务时提高受试者的注意力和动力。

要在非侵入式 BCI 中检测左手/右手或腿部运动的开始，分析运动和运动前脑区周围的 EEG 功率通常就足够了。然而，对于多任务运动的分析和长时间运动轨迹的识别，则需要对所有 EEG 通道进行更复杂的信息处理，并有效估算大脑连接随时间的变化。
