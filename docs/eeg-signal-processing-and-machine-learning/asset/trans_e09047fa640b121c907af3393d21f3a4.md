

## 4.9 主成分分析

所有次优变换（如 DFT 和 DCT）均将信号分解为一组系数，这些系数不一定代表信号的组成成分。此外，变换核与数据无关，因此它们在样本去相关和能量压缩方面均不高效。因此，通常无法使用这些次优变换实现信号和噪声成分的分离。

将数据扩展为一组正交成分必定能实现信号的最大去相关。这使得数据能够分离为信号子空间和噪声子空间。
