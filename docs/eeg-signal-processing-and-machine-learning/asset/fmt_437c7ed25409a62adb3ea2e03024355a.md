# 18. EEG与其他同步记录的脑功能神经成像模态的联合分析

## 18.1 简介

脑电图（EEG）是一种具有良好时间分辨率但空间分辨率较差的功能性脑筛查模态。相反，从头皮上记录的脑活动在组织电导率方面严重受到头部组织非线性的影响。多年来，已经开发了许多神经成像工具和系统，用于研究大脑功能的不同方面并弥补上述EEG的缺陷。如果将这些脑筛查模态获得的信息添加到EEG中，可以更好地表征和识别大脑状态及其对各种刺激的反应。与EEG联合使用的三种重要脑筛查模态是功能性磁共振成像（fMRI）、功能性近红外光谱（fNIRS）和脑磁图（MEG）。

EEG和fMRI可能比其他方法更常用于研究大脑功能。近年来采集系统的进步使得同步EEG–fMRI脑记录成为可能。从这两种数据模态获得的信息对于分析大脑对事件相关和运动相关刺激的反应非常重要。

不幸的是，在MRI扫描仪中记录的EEG会受到磁场的严重降级。因此，为了确保EEG信号有用且信息丰富，需要全面的预处理技术。

在本章中，我们回顾文献并描述用于从EEG信号中去除fMRI伪迹以及这两种模态联合分析的新信号处理方法的最新进展。简要解释了fNIRS的概念及其与EEG的联合应用，并展示了一些EEG–MEG联合分析的例子。随后介绍了上述双模态数据处理中的许多新方法及其相关问题的解决方案。

## 18.2 基本概念

### 18.2.1 功能性磁共振成像
