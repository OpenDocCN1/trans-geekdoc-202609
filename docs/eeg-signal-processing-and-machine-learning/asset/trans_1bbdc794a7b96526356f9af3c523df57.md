
据估计，8.4% 的儿童和 2.5% 的成人患有 ADHD [[7](#c16.xhtml#c16-bib-0007), [8](#c16.xhtml#c16-bib-0008)]。ADHD 通常首先在学龄儿童中被识别出来，当时它会导致课堂秩序混乱或学业问题。男孩比女孩更常见。

### 16.2.1.1 ADHD 症状与可能的治疗

许多 ADHD 症状，如活动水平高、长时间难以保持静止和注意力持续时间有限，在幼儿中普遍存在。ADHD 儿童的多动和注意力不集中明显超出了预期水平，无论身处何地都会导致痛苦或社交问题。

ADHD 可分为注意力不集中型、多动/冲动型或混合型。诊断依据是在被转诊至诊所前六个月以上出现的症状。

目前尚未确定 ADHD 的具体病因。有证据表明遗传因素会导致 ADHD。早产、脑损伤，以及母亲在怀孕期间吸烟、饮酒或承受极度压力可能是其他原因。

### 16.2.1.2 基于 EEG 的 ADHD 诊断

文献 [[9]](#c16.xhtml#c16-bib-0009) 综述了一些基于 EEG 的 ADHD 早期诊断方法。然而，其重点在于多变量分析，并侧重于理解 EEG 的神经发生源。作者将这些方法分为两大类：一类是观察 Jasper 等人 [[6]](#c16.xhtml#c16-bib-0006) 最初提到的慢波，以及事件相关电位（ERP）的变化。随后，研究了 EEG 特征与 ADHD 临床异质性之间的联系，并得出结论：多变量分析和将 EEG 信号分解为其神经发生源，可以使 EEG 用于 ADHD 的临床实践。

许多研究人员发现的与 ADHD 相关的最稳健的 EEG 特征是慢波 θ 波功率升高，通常伴随快 β 波（14–30 Hz）功率降低，记录于 Cz 导联，可呈现为单变量 θ/β 比率，大约在 0.6 到 3.0 之间变化 [[10](#c16.xhtml#c16-bib-0010)–[14](#c16.xhtml#c16-bib-0014)]。然而，尽管 2016 年美国神经病学学会宣布 θ/β 比率测量为标准方法，Nuwer 等人 [[15](#c16.xhtml#c16-bib-0015)] 在一篇评论中对此提出批评，主要是因为该比率具有显著的年龄效应，随着儿童从童年期向成年期过渡，该比率显著下降。当然，θ/β 比率测量可以与年龄相关的基线进行比较，仍可用于临床实践。在一项较新的研究 [[16](#c16.xhtml#c16-bib-0016)] 中，通过观察大脑活动的频谱和空间足迹，发现 ADHD 受试者在任务期间 β 活动降低，静息时 θ/β 比率较高，这与先前的研究结果一致。此外，大多数 ADHD 受试者在注意力测试期间表现出的 β 功率落在以正常儿童群体为基础定义的正常范围之外。

作为利用频谱功率进行 ADHD 研究的另一个方向，文献 [[17](#c16.xhtml#c16-bib-0017)] 采用了基于弹性网络 [[18](#c16.xhtml#c16-bib-0018)] 的惩罚逻辑回归，利用包括 θ/β 比率在内的整个 EEG 频谱（1–45 Hz）测量值对受试者进行分类。

给定数据（特征）矩阵 `X`、标签向量 `y` 和参数向量（分类器超平面）`w`，基于弹性网络的 `w` 估计优化与最小绝对收缩和选择算子（LASSO）正则化优化非常相似。在 LASSO 中，尝试解决以下正则化问题：

(16.1)
```
min_w (||y - Xw||^2 + λ||w||_1)
```
其中 `||∙||_1` 指 `l_1` 范数，`λ` 为正则化参数。解如下：

(16.2)
```
ŵ_LASSO = arg min_w (w^T (X^T X) w - 2 y^T Xw + λ||w||_1)
```

在弹性网络中，使用两个正则化参数，即 `λ_1` 和 `λ_2`，`w` 的解变为：

(16.3)
```
ŵ_Elastic = arg min_w (w^T ((X^T X + λ_2 I) / (1 + λ_2)) w - 2 y^T Xw + λ_1 ||w||_1)
```

引入 `λ_2` 提高了结果的稳定性 [[18](#c16.xhtml#c16-bib-0018)]。他们得出结论，ADHD 状态的最佳预测指标可能是中央顶区 δ、θ 和低 α 功率的增加，以及额区低 β 和顶区中 β 的增加。此外，睁眼状态下 δ、θ、低 α 和低 β 功率的升高可用于区分一级亲属和对照组。因此，他们认为，总体而言，θ/β 比率本身并非 ADHD 的准确诊断标志，尽管它对儿童期 ADHD 效果尚可。

鉴于 γ 活动被认为是大脑网络功能的指标，这些功能支撑着高阶认知过程，文献 [[19](#c16.xhtml#c16-bib-0019)] 得出结论：成人 ADHD 患者的 γ 活动减少，且这种减少主要呈右侧中央顶区分布。这一结果与儿童 ADHD 文献中关于患者枕后区 γ 活动减弱的发现一致，这可能反映了背侧注意网络功能的改变。
