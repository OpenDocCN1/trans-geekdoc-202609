

#### 7.3.14.2 后向算法

令 `β[i](t) = p(o[t+1] = y[t+1], … o[T] = y[T], Q[t] = i | λ)` 为在时刻 `t` 处于状态 `i` 且观测到 `y[t+1], y[2], … y[T]` 部分序列的概率：

(7.50)
```
β[i](T) = 1,
```

并对 `t` 进行迭代：

(7.51)
```
β[i](t) = Σ(j=1 to N) β[j](t+1) a[ij] b[j](y[t+1])
```

#### 7.3.14.3 HMM 设计

对于 HMM 设计，我们需要根据贝叶斯定理计算以下辅助变量：

(7.52)
```
γ[i](t) = p(Q[t] = i | O, λ) = p(Q[t] = i, O | λ) / p(O | λ) = α[i](t) β[i](t) / Σ(j=1 to N) α[j](t) β[j](t)
```

这是在给定模型 `λ` 和观测序列 `O` 的情况下，时刻 `t` 处于状态 `i` 的概率。那么，在给定模型 `λ` 和观测序列 `O` 的情况下，时刻 `t` 和 `t + 1` 分别处于状态 `i` 和 `j` 的概率为：

(7.53)
```
ξ[ij](t) = p(Q[t] = i, Q[t+1] = j | O, λ) = p(Q[t] = i, Q[t+1] = j, O | λ) / p(O | λ)
        = α[i](t) a[ij] β[j](t+1) b[j](y[t+1]) / Σ(i=1 to N) Σ(j=1 to N) α[i](t) a[ij] β[j](t+1) b[j](y[t+1])
```
