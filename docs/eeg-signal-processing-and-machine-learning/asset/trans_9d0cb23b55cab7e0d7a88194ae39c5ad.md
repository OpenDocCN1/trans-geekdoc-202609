

#### 4.5.1.6 重构

数据可从其小波系数中逐步重构，从最低分辨率开始。在每个尺度上，我们计算：

(4.51)
```
C_{j+1} = H(2^j ω) C_j(ω)
```
(4.52)
```
W_{j+1} = G(2^j ω) C_j(ω)
```

我们利用已知的 `C[j + 1]`、`W[j + 1]`、`h` 和 `g` 来求解 `C[j]`。然后通过最小化以下表达式来恢复 `C_j(ω)`：

(4.53)
```
P_h(2^j ω) |C_{j+1}(ω) - H(2^j ω) C_j(ω)|^2 + P_g(2^j ω) |W_{j+1}(ω) - G(2^j ω) C_j(ω)|^2
```

此处采用最小二乘估计器。`P_h(ω)` 和 `P_g(ω)` 是权函数，允许对 `C_j(ω)` 的恢复给出通用解。`C_j(ω)` 的关系式形式为：

(4.54)
```
C_j(ω) = C_{j+1}(ω) \tilde{H}(2^j ω) + W_{j+1}(ω) \tilde{G}(2^j ω)
```

其中共轭滤波器的表达式为：

(4.55)
```
\tilde{H}(ω) = (P_h(ω) H^*(ω)) / (P_h(ω) |H(ω)|^2 + P_g(ω) |G(ω)|^2)
```
(4.56)
```
\tilde{G}(ω) = (P_g(ω) G^*(ω)) / (P_h(ω) |H(ω)|^2 + P_g(ω) |G(ω)|^2)
```

很容易看出，这些滤波器满足 [式 (4.35)](#c04.xhtml#c4-disp-0035) 中给出的精确重构条件。实际上，[式 (4.55)](#c04.xhtml#c4-disp-0055) 和 [(4.56)](#c04.xhtml#c4-disp-0056) 给出了该方程的通用解。在该分析中，香农采样条件始终得到满足。不存在混叠，因此反混叠条件 [(4.76)](#c04.xhtml#c4-disp-0078) 并非必要。
