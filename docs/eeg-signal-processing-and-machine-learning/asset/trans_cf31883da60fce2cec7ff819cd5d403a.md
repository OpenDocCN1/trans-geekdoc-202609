

### 18.3.5.1 从 EEG 中提取 fMRI 时间进程

如果时间进程可用，构建、增强或检测 BOLD 信号最稳健的技术是 GLM。在记录未时间锁定、无提示、存在自主运动，或 BOLD 由神经生理疾病（如癫痫发作）引起的情况下，时间进程是未知的。尽管盲源技术（如 ICA 或 NMF）能够估计空间和时间信息，但它们往往会引入错误，导致结果误读；因此，估计一个有效的时间进程，便可应用基于模型的方法（如 GLM），而后者需要准确构建 HRF。

在与运动相关的脑活动情况下，神经元群同步活动的变化会导致 EEG 振荡幅度出现事件相关变化 [[71]](#c18.xhtml#c18-bib-0071)。在本书前几章中已提到，脑振荡中存在两种强烈的事件相关变化：α 节律中的事件相关去同步化（ERD）和 β 节律中的事件相关同步化（ERS）。受试者为运动做准备的行为会抑制感觉运动区 α 和 β 节律上的 EEG 振荡 [[72](#c18.xhtml#c18-bib-0072)–[74](#c18.xhtml#c18-bib-0074)]。这就是 ERD 信号，它大约在运动开始前一秒出现。运动结束后，当 α 节律恢复到基线时，β 功率也恢复到基线并超过运动前水平 [[75](#c18.xhtml#c18-bib-0075), [76](#c18.xhtml#c18-bib-0076)]。β 频带信号功率的这种剧烈增加即为 ERS 信号或运动后 β 反跳（PMBR）。利用从 EEG 节律获得的信息作为 fMRI 分析的回归量，可实现与特定神经节律相关的 BOLD 定位。同步记录 EEG 和 fMRI 对此目的很有用。

### 18.3.5.2 EEG 与 fMRI 的融合；盲源方法

EEG–fMRI 融合揭示了关于脑功能更完整的信息，这是单独使用 EEG 和 fMRI 无法观察到的。总体而言，尽管本章开头提供了相关信息，同步神经活动与 BOLD 之间的关系尚不完全清楚。EEG 和 fMRI 的同步记录提供了识别 EEG 事件期间涉及的不同脑区的机会。利用 [18.3.5 节](#c18.xhtml#c18-sec-0018) 所述方法提取的时间进程，可以研究 PMBR 与 BOLD 之间的相关性。从 EEG 分析中提取的信息被用作约束，以将源自 EEG 信号的信息融入 fMRI 分析流程中。

本书前几章解释的张量分解可用于此目的。在一种新方法中，选择 PARAFAC2 作为张量分解算法用于 EEG–fMRI 融合。使用 PARAFAC2 的主要优势在于能够以多模式而非仅两种模式分析数据。这一特性有助于获得关于 BOLD 及其时间进程的有价值信息。此外，多维数据分析能以系统化方式处理数据。该方法能有效检测负责 PMBR 的脑区。通过将结果与 GLM 获得的结果进行比较，可以从经验上证明这一点。

目前的 EEG–fMRI 融合方法主要分为两大类：模型驱动和数据驱动。计算生物物理模型构成了模型驱动方法的基础 [[77]](#c18.xhtml#c18-bib-0077)。在这些方法中，利用关于神经活动的假设来建立 EEG 和 fMRI 之间的关系。尽管模型驱动方法能提供对神经机制更深入的理解，但它们需要对共同神经底物进行显式描述，以标注测得的 EEG 和 fMRI 数据。然而，由于对神经底物缺乏足够的了解，对模型驱动方法的应用需求已有所下降 [[77]](#c18.xhtml#c18-bib-0077)。

数据驱动方法基于 EEG 和 fMRI 之间的共同相互作用。这些方法分为两大类：基于约束的 EEG–fMRI 融合和基于预测的 EEG–fMRI 融合。在基于约束的方法中，通过 fMRI 分析获得的 fMRI 激活图被用作电磁源定位的先验信息。由于 EEG 传感器的数量通常少于大脑内的源数量，EEG 逆问题往往是欠定且病态的。因此，需要额外的约束或先验信息，以获得 EEG 源定位的唯一稳定解。

针对所谓的 fMRI 约束偶极子拟合和分布源建模，存在两种 EEG–fMRI 融合方法。Fujimaki 等人 [[78]](#c18.xhtml#c18-bib-0078) 提出了一种基于偶极子拟合的方法。在他们的方法中，每个 fMRI 热点的神经活动被建模为等效区域电流偶极子。然后，将偶极子位置固定在 fMRI 热点上，或将 fMRI 热点作为偶极子拟合的种子点，同时施加最大距离约束。估计出偶极子位置后，可通过将 ECD 模型拟合到 EEG 数据来确定偶极子矩。区域神经活动的时间动态在估计出偶极子时间进程后确定。尽管这些方法能给出唯一解，但它们只能检测 fMRI 激活区的活跃偶极子。一些基于分布源建模的技术也已开发出来 [[79](#c18.xhtml#c18-bib-0079), [80](#c18.xhtml#c18-bib-0080)]。在这些工作中，利用从 fMRI 激活图获得的 BOLD 几何信息来推导源重建的协方差先验。加权最小范数框架和维纳滤波分别被 [[79](#c18.xhtml#c18-bib-0079), [80](#c18.xhtml#c18-bib-0080)] 用作此目的的两种技术。与基于偶极子拟合的方法不同，fMRI 约束分布源成像方法不仅能获得 fMRI 激活区的偶极子，还能获得 fMRI 未显示任何激活区域的偶极子。然而，这些方法的性能受一些缺点影响，例如 fMRI 加权因子的识别，以及 EEG 与 fMRI 时间分辨率差异导致的问题。这些问题主要是如何处理 fMRI 额外源、fMRI 不可见源和 fMRI 差异源 [[81]](#c18.xhtml#c18-bib-0081)。文献 [[82](#c18.xhtml#c18-bib-0082)–[84](#c18.xhtml#c18-bib-0084)] 的作者建议了一些加权因子的经验值以克服该问题。在另一项研究中，Phillips 等人 [[85]](#c18.xhtml#c18-bib-0085) 使用期望最大化（EM）作为一种数据驱动技术来选择 fMRI 加权因子。
