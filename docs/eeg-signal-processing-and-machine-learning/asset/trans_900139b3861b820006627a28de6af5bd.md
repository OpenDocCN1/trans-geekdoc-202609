

# 癫痫的历史与治疗

## 19世纪的发展

在19世纪，随着神经学作为一门独立于精神病学的新学科出现，癫痫作为一种脑部疾病的概念得到了更广泛的认可，尤其是在欧洲和美利坚合众国（USA）。这有助于减少与该疾病相关的耻辱感。**溴化物**于1857年作为世界上第一种有效的抗癫痫药物被引入，在上半叶的后半期在欧洲和美国被广泛使用。

第一家针对*“瘫痪和癫痫患者”*的医院中心于1857年在伦敦建立。与此同时，对癫痫社会问题采取更人道的方法，促成了用于护理和就业的癫痫“村落”的建立。

19世纪，随着神经学家**休林斯·杰克逊**（Hughlings Jackson）于1873年的研究，对癫痫（病理生理学）的新理解也随之建立。他提出癫痫发作是大脑中突然、短暂的电化学放电的结果。他还指出，发作的性质取决于放电部位的位置和功能。不久之后，**大卫·费里尔**（David Ferrier）在伦敦，以及**古斯塔夫·特奥多尔·弗里奇**（Gustav Theodor Fritsch）和**爱德华·希齐希**（Eduard Hitzig）在德国，发现了动物和人脑的电兴奋性。

## 20世纪的进展：脑电图与药理学

从20世纪30年代起，**脑电图（EEG）**的重要应用领域在于癫痫。脑电图揭示了大脑中电放电的存在。它还显示了与不同发作类型相关的不同脑电波放电模式。脑电图还有助于定位癫痫放电部位，并扩展了神经外科治疗的可能性，从20世纪50年代起，这种治疗在伦敦、蒙特利尔和巴黎变得更为普遍。

在20世纪上半叶，主要治疗药物为**苯巴比妥**（phenobarbitone，1912年首次使用）和**苯妥英钠**（phenytoin，1938年首次使用）。自20世纪60年代以来，药物发现经历了一个加速过程，这在一定程度上基于对大脑电化学活动（特别是兴奋性和抑制性神经递质）的更深入理解。在发达国家，近年来已有多种新药上市，新确诊的儿童和成人中，70%–80%的癫痫发作现可得到控制。

## 现代诊断与全球倡议

**功能性磁共振成像（fMRI）**和**正电子发射断层扫描（PET）**等神经影像技术提高了癫痫诊断的成功率。此类技术揭示了许多导致癫痫的细微脑部病变。创伤、先天性、发育性、感染性、血管性和肿瘤等多种脑部病变可能在某些人身上导致癫痫。全球5000万癫痫患者中，约有3500万人无法获得适当治疗。这要么是因为服务不存在，要么是因为癫痫不被视为一种医学问题或可治疗的脑部疾病。

作为一项针对癫痫治疗的重大运动，**国际抗癫痫联盟（ILAE）**和**国际癫痫局（IBE）**于1997年联合**世界卫生组织**发起**全球抗癫痫运动**，以解决这些问题。

## 癫痫发作特征与治疗选择

癫痫发作随机发生，损害大脑的正常功能。癫痫在许多情况下可得到治疗，目前最重要的治疗方法是药物治疗。患者每日服用**抗惊厥药物**，旨在达到血液中的稳态浓度，以提供最有效的发作控制。**手术干预**是针对药物治疗无效的精心挑选病例的一种替代方案。然而，在确诊癫痫的患者总数中，近25%的患者无法通过任何现有疗法控制发作。此外，药物和手术治疗均有副作用报告。

## 癫痫发作分类与脑电图分析

观察头皮**脑电图（EEG）**，癫痫发作可表现为阵发性同步振荡的发生。神经活动的强同步化（以代数连通性度量为特征）是由发作起始期异常神经元放电引起的 [[4]](#c11.xhtml#c11-bib-0004)。根据各脑区受累程度，此类发作可分为两大类：**局灶性（或部分性）**和**全面性**。全面性发作涉及大脑大部分区域，而局灶性发作源于大脑的一个限定区域，常称为**癫痫灶** [[5]](#c11.xhtml#c11-bib-0005)。[图 11.1](#c11.xhtml#c11-fig-0001) 分别展示了涉及全面性和局灶性发作的两段脑电信号。

局灶性癫痫的成功手术治疗需要精确定位癫痫灶，并将其与功能相关区域区分开 [[6]](#c11.xhtml#c11-bib-0006)。癫痫发作产生的生理学方面，以及发作的治疗和监测（包括术前检查）已得到充分确立 [[5]](#c11.xhtml#c11-bib-0005)，并有医学文献佐证。

**脑电图（EEG）**、**脑磁图（MEG）**以及最近的**功能性磁共振成像（fMRI）**是用于癫痫发作检测的主要神经影像模态。头部fMRI中的**血氧水平依赖（BOLD）**区域清晰地显示了癫痫灶。然而，每个地区的fMRI设备数量有限，成本高昂，且全身扫描耗时较长。因此，对所有患者在所有时间使用fMRI是不可行的。**MEG**反之则噪声大，且由于受监护患者记录期间必须保持静止，使用当前MEG设备难以获得中重度病例的清晰数据。

因此，**EEG**仍然是研究癫痫最有用且最具成本效益的模态。虽然对于全面性发作，发作持续时间可用肉眼轻松检测，但对于大多数局灶性癫痫，此类间隔难以识别。

## 癫痫发作的病理分类

从病理学角度来看，癫痫发作有明确的分类方案。**“部分性”**用于描述反映局灶性皮层活动的孤立现象，无论其在临床上还是通过脑电图均表现明显。**“单纯”**一词表示意识未受损。例如，表现为上肢短暂抽搐并随之缓解的发作，可称为**伴运动症状的单纯部分性发作**。部分性发作可能伴有运动、躯体感觉、精神或自主神经症状 [[7]](#c11.xhtml#c11-bib-0007)。

**“复杂”**一词定义为与发作相关的意识改变。**“全面化”**是指从皮层局灶区扩散的术语，可在临床上或通过脑电图观察到，涉及所有皮层区域，导致全面性运动惊厥。已知在成人中，最常见的发作类型是皮层某一区域初始激活，随后扩散至所有皮层区域；这种扩散往往过快，无法通过床边观察察觉。

癫痫发作类型的另一主要分组是**全面性发作**，可称为**惊厥性**或**非惊厥性**。此类型中，所有皮层区域同时被激活。例如见于**失神发作**和**肌阵挛发作** [[8]](#c11.xhtml#c11-bib-0008)。
