反之，`p(k)` 也可通过对[式 (9.24)](#c09.xhtml#c9-disp-0024) 进行逆变换轻松计算得出。因此，可获得 `h(n)` 和 `g(n)` 的采样值。最后，执行小波变换（WT）只需进行低通和高通滤波，随后进行下采样。在这样一种多分辨率方案中，小波系数的数量从一个尺度到下一个尺度减半。这要求并证明了低频需要较长的时间窗，而高频需要较短的时间窗是合理的。

在上述工作中，VEP 波形采用常规 10-20 EEG 系统的 `C[z]` 和 `O[z]` 电极位置的双极导联记录。采样率为 1 kHz。因此，每个尺度覆盖以下频带：250-500、125-250、62.5-125、31.3-62.5、15.5-31.5、7.8-15.6 Hz（包含 N70、P100 和 N130），以及 0-7.8 Hz（残余尺度）。虽然此方法并非旨在区分正常受试者和病理受试者，但可以突显 ERP（事件相关电位），并可观察到正常和异常病例之间的差异。通过使用上述样条小波分析，观察到 N70-P100-N130 复合波潜伏期偏移的主要效应，反映在 7.8-15.6 Hz 频带内第二、第三和第四小波系数的符号和幅度上。在最近十年的文献中，还引入了许多其他版本的 WT 方法，如 [[52](#c09.xhtml#c9-bib-0052)–[54](#c09.xhtml#c9-bib-0054)] 所述。
