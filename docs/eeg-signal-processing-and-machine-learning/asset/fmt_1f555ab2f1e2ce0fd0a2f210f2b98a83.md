
#### 7.3.14.2 Backward Algorithm

Let `β[i](t) = p(o[t+1] = y[t+1], … o[T] = y[T], Q[t] = i | λ)` be the probability of observing `y[t+1], y[2], … y[T]` partial sequence and being in state `i` at time `t`:

(7.50)
```
β[i](T) = 1,
```

and iterate over `t`:

(7.51)
```
β[i](t) = Σ(j=1 to N) β[j](t+1) a[ij] b[j](y[t+1])
```

#### 7.3.14.3 HMM Design

For the HMM design we need to calculate the following auxiliary variables following Bayes theorem:

(7.52)
```
γ[i](t) = p(Q[t] = i | O, λ) = p(Q[t] = i, O | λ) / p(O | λ) = α[i](t) β[i](t) / Σ(j=1 to N) α[j](t) β[j](t)
```

This is the probability of being in state `i` at time `t` for a given model `λ` and the observed sequence `O`. Then, the probability of being in states `i` and `j` at times `t` and `t + 1` respectively for the given model `λ` and the observed sequence `O` is:

(7.53)
```
ξ[ij](t) = p(Q[t] = i, Q[t+1] = j | O, λ) = p(Q[t] = i, Q[t+1] = j, O | λ) / p(O | λ)
        = α[i](t) a[ij] β[j](t+1) b[j](y[t+1]) / Σ(i=1 to N) Σ(j=1 to N) α[i](t) a[ij] β[j](t+1) b[j](y[t+1])
```
