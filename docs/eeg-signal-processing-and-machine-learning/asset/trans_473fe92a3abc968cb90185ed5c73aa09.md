
S变换（或S相干性）的虚部常被用作大脑功能连接的估计。该技术在[第8章](#c08.xhtml)中也有解释。在Eftaxias等人[[128](#c17.xhtml#c17-bib-0128)–[130](#c17.xhtml#c17-bib-0130)]的开创性工作中，S变换的虚部被用作带有参数`a[lk] (t, f)`的功能连接度量，并被用作扩散卡尔曼自适应协作滤波器的组合权重，该滤波器带有参数向量`ϕ [k, t]`，用于对顺时针和逆时针手部绘制动作进行分类。该方法的简要框图如[图17.13](#c17.xhtml#c17-fig-0013)所示。

Monajemi等人[[131](#c17.xhtml#c17-bib-0131)]提出了一种使用多任务扩散自适应的类似方法，以识别大脑连接与帕金森病患者手部震颤之间的联系。

基于EEG的功能连接在BCI中的应用可以为BCI研究开辟两个新方向。一个是模拟从思维到行动的路径，而无需任何反馈（视觉、触觉等）。第二个方向是在大脑超扫描框架中实现从一个大脑到另一个大脑的信息传输。在这样的框架中，执行相似或竞争性任务的多个大脑会接受EEG扫描。这或许是大脑间通信或脑互联网（IoB）建立的主要基础。

## 17.7 通用空间模式的应用

正如[第7章](#c07.xhtml)所述，CSP可能是BCI分类中使用的最有效的特征选择算法。2000年初，在一个两分类BCI设置中，Ramoser等人[[72](#c17.xhtml#c17-bib-0072)]提出了一种CSP，它学习最大化一类带通滤波EEG信号的方差，同时最小化另一类信号的方差。形式上，`CSP(w)`最小化空间协方差矩阵的瑞利商，以实现两类数据`X [1]`和`X [2]`之间的方差不平衡，并使用以下公式定义：
