### 5.4.2 k‐稀疏混合

大多数基于 SCA 的源分离和欠定盲辨识 (UBI) 方法 [[18](#c05.xhtml#c5-bib-0018), [152](#c05.xhtml#c5-bib-0152)–[156](#c05.xhtml#c5-bib-0156)] 利用了信号区间的信息，这些区间仅包含在特定时刻有一个占主导地位的活跃源。当没有足够的仅包含单一主导源的区间来估计 `A` 的所有列时，这些方法就会失效。

一些较新的方法已将 SCA 扩展到每个时刻或区间有多个源（设为 `k`[*a*] ，其中 `k`[*a*] < `N`[*x*]）活跃的情况。它们的方法能够利用这些区间的信息来估计混合矩阵 `A` 的列 [[22](#c05.xhtml#c5-bib-0022)–[24](#c05.xhtml#c5-bib-0024)]。这些方法被称为 `k`‐SCA 方法 [[25](#c05.xhtml#c5-bib-0025)]，在某些温和条件下（即：拥有足够的时间样本以获得足够的平面/子空间来覆盖 `A` 的所有列，以及 `k`[*a*] < `N`[*x*]）[[25](#c05.xhtml#c5-bib-0025), [154](#c05.xhtml#c5-bib-0154)]，能够使用一些聚类方法估计 `A` 和源信号。

文献 [[22](#c05.xhtml#c5-bib-0022)] 假设在每个时刻平均有 `k`[*a*] < `N`[*x*] /2 个源是活跃的（非零）。该文的主要思想是将多个主导源的问题转化为一系列单主导源问题，后者可用已知方法求解。然后通过求解这些单主导问题分别估计 `A` 的每一列。这种方法要求已知源的数量。文献 [[23](#c05.xhtml#c5-bib-0023)] 解决了这个后续问题并提出了一个解决方案。文献 [[24](#c05.xhtml#c5-bib-0024)] 提出的算法提高了对变化环境的适应性以及对噪声和离群值（即不满足稀疏条件的区间）的鲁棒性。相反，在该方法中 `k`[*a*] 满足 `N`[*x*] − 1 > `k`[*a*] > `N`[*x*] /2。SCA 已应用于 ERP 检测和源定位的 EEG 源估计 [[157](#c05.xhtml#c5-bib-0157), [158](#c05.xhtml#c5-bib-0158)]。

当前欠定源恢复 (USR) 解（包括松弛族和贪婪族）的分离性能会随着混合系统维度的降低和稀疏度 `k` 的增加而下降。因此，文献 [[151](#c05.xhtml#c5-bib-0151)] 的作者考虑了源稠密稀疏的应用，即活跃源的数量很高且非常接近传感器的数量。在他们的工作中，他们开发了一种基于 `k`‐SCA 的算法，适用于低维混合系统中的 USR。假设源最多为 (`m` − 1) 稀疏，其中 `m` 是混合信号的数量。他们的方法能够在使用子空间检测方法估计混合矩阵后恢复源信号。

用于求解欠定盲源分离 (UBSS) 问题的 `k`‐SCA 算法通常侧重于通过 UBI 识别混合矩阵，如文献 [[162](#c05.xhtml#c5-bib-0162)] 所示，并利用传统的源恢复算法，即贪婪方法，如 OMP [[159](#c05.xhtml#c5-bib-0159)]，松弛方法，如基追踪 [[160](#c05.xhtml#c5-bib-0160)] 或平滑 `l`[*0*] 算法 [[161](#c05.xhtml#c5-bib-0161)]。

已证明 [[153](#c05.xhtml#c5-bib-0153)]，只要 `k` ≤ `m` − 1，其中 `k` 是 `S` 每列中活跃源的数量，就可以识别 `A` 并估计 `S`。解决该问题的一种近期方法基于上述证明和不相交子空间的定义 [[151](#c05.xhtml#c5-bib-0151)]。这些定义指出：如果子空间之间没有公共混合向量，则称它们为不相交子空间；如果子空间之间有 `f` 个公共混合向量，则称它们为 `f` ‐非不相交子空间。在这种情况下，`f` ‐非不相交子空间的数量为 ![images](images/c5-i0026.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><msub><mi>n</mi><mi>f</mi></msub><mo>=</mo><msubsup><mi>C</mi><mrow><mi>m</mi><mo>&#8722;</mo><mi>f</mi><mo>&#8722;</mo><mn>1</mn></mrow><mrow><mi>n</mi><mo>&#8722;</mo><mi>f</mi></mrow></msubsup></math>，其中 `f` = 1, 2, *… m* − 1。
