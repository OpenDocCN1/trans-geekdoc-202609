
人们已经使用了不同的连接度量，例如 MI [\[122\]](#c14.xhtml#c14-bib-0122)。为了更清晰地评估大脑连接性，连接度量通常是在不同的传统 EEG 频带上进行计算的。

与 [第 8 章](#c08.xhtml) 中解释的其他大脑连接度量类似，为了定义 MDI，考虑两个平稳时间序列 `X` 和 `Y` 的简单情况，它们的长度均为 `N`，被分成 `n` 个长度为 `L = N/n` 的纪元；每个长度为 `L = P + 1 + M` 的纪元被写成两个部分的序列，这两个部分分别位于时间序列 `X` 和 `Y` 在时间 `k` 处的样本 `x[k]` 和 `y[k]` 之前和之后，长度分别为 `P` 和 `M`，即 [\[62\]](#c14.xhtml#c14-bib-0062)：
