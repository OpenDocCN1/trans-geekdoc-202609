
# Graph Signal Processing and Brain Connectivity

## Graph Definition and Adjacency Matrix

A graph *G* consists of a set *N*[*G*] of *N* nodes, and a set ℑ of edges such that if nodes *m* and *n* are linked, then (*m, n*) ∈ ℑ. For undirected graphs, these node pairs are unordered.

At the node level, a recorded signal **y** = [*y*[1], …, *y*[*N*]]^(*T*), assumed to be real valued, where *y*[*n*] is the sample of signal **y** at node *n*. Also, the adjacency matrix **A** [[72]](#c08.xhtml#c8-bib-0072), [[73]](#c08.xhtml#c8-bib-0073) is defined as an *N* × *N* matrix whose entries *a*[*n,m*] are zero if (*m,n*) ∉ ℑ and one otherwise. The adjacency matrix describes the interactions between entities and, by extension, can be considered as a tool for representing relationships between the data channels (vertices).

In general, any one of the methods previously described in this chapter can be used to characterize or define a graph. For the particular case of brain connectivity estimation, the proposed method has the advantage of adaptability given the data are available [[74]](#c08.xhtml#c8-bib-0074). In this application, the graph topology is considered unknown beforehand and has been estimated from the data.

## Dynamic Graphs and Kernel Methods

Moreover, some graphs can be dynamic, such as brain activity supported by neurons or brain regions. A network structure is then proposed to capture online the nonlinear dependencies among streaming graph signals in the form of a possibly directed adjacency matrix. By projecting the data into a higher- or infinite-dimension space, the nonlinear relationships between the electrode recordings (agents) are estimated. Kernel dictionaries are used to mitigate the increasing number of data points.

## Brain Network Modeling

Consider that an *N*-node graph with adjacency matrix **A**, as defined above, models a system such as the brain network. In this setting, the brain activity in each brain zone, **y**(*i*) can be measured at time instant *i*. For the case of brain connectivity, the existing nonlinearity in the connections motivates modelling the brain dynamics. Consider the following data model [[74]](#c08.xhtml#c8-bib-0074):

**(8.49)**
```
**y**(*i*) = **A****f**(*i*) + **v**(*i*)
```

Matrix **A** models how entries of **f**(*i*) ≜ col{*f*_*m*(*y*_{*L*_*m*}(*i*))}_{*m*=1}^*N*, where *f*_*m* : ℝ^{*L*_*m*} → ℝ, affect every node. **v**(*i*) accounts for additive noise.

The least-mean-squares solution to this problem is:

**(8.50)**
```
**Â** = argmin_**A** ½ E[||**y**(*i*) − **A****f**(*i*)||²₂] + Ψ(**A**) subject to *a*_*nm* ∈ {0, 1}
```

where Ψ(**A**) is a regularization term to account for some prior knowledge of **A** such as symmetry or sparsity.
