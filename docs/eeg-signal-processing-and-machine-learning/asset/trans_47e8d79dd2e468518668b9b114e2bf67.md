迭代持续进行，直到解不再显著变化。在 Liu 等人 [\[51\]](#c10.xhtml#c10-bib-0051) 提出的另一种称为收缩标准 LORETA–FOCUSS (SSLOFO) 的方法中，使用 sLORETA 进行初始化。然后，它使用 FOCUSS 的重加权最小范数 (re‐WMN)。在此过程中，通过引入上述标准化技术，定位结果得到了进一步改进。然而，FOCUSS 通常在迭代过程中产生越来越稀疏的解。因此，最好消除无源活动的节点，或恢复那些可能被错误丢弃的活动节点。[\[52\]](#c10.xhtml#c10-bib-0052) 中提出的算法在 FOCUSS 的每次迭代后收缩源空间，从而减少计算量 [\[51\]](#c10.xhtml#c10-bib-0051)。为防止算法陷入局部极小值，会执行平滑操作。因此，总体 SSLOFO 可概括为以下步骤 \[[51](#c10.xhtml#c10-bib-0051), [52](#c10.xhtml#c10-bib-0052)\]：

1.  使用 sLORETA 估计电流密度 ![images](images/c10-i0021.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><msub><mover accent="true"><mi mathvariant="bold">S</mi><mo stretchy="true">&#38;c.circ;</mo></mover><mn mathvariant="bold">0</mn></msub></math>。

2.  将加权矩阵初始化为 **Q** [0] = *diag*\[![images](images/c10-i0022.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><msub><mover accent="true"><mi mathvariant="bold">S</mi><mo stretchy="true">&#38;c.circ.</mo></mover><mn>0</mn></msub></math>(1), ![images](images/c10-i0023.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><msub><mover accent="true"><mi mathvariant="bold">S</mi><mo stretchy="true">&#38;c.circ.</mo></mover><mn>0</mn></msub></math>(2)… ![images](images/c10-i0024.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><msub><mover accent="true"><mi mathvariant="bold">S</mi><mo stretchy="true">&#38;c.circ.</mo></mover><mn>0</mn></msub></math>(3*m*)\]。

3.  使用标准化 FOCUSS 估计源功率。

4.  保留显著节点及其相邻节点。通过平滑调整这些节点上的值。

5.  重新定义解空间，使其仅包含保留的节点，即 **S** 中仅对应的元素和 **L** 中仅对应的列。

6.  更新加权矩阵。

7.  重复步骤 3–6，直到满足停止条件。

8.  最终解为平滑前最后一步的结果。

停止条件可以通过定义阈值来确定，或者当权重在进一步迭代中没有显著变化时确定。

### 10.4.6 其他加权最小范数解

在 Phillips 等人 [\[5\]](#c10.xhtml#c10-bib-0005) 的一种 LD 方法中，提出了一种 WMN 解（或 Tikhonov 正则化）方法 [\[53\]](#c10.xhtml#c10-bib-0053)。该解通过将一些解剖学和生理学信息以约束的形式施加于总代价函数上而得到正则化。平方误差代价根据空间和时间特性进行加权。来自其他成像模态（如 fMRI）的脑活动血流动力学测量等信息，被用作约束（或先验），与提出的代价函数结合使用。在该方法中，假设源分布足够密集，且源朝向垂直于皮层表面。
