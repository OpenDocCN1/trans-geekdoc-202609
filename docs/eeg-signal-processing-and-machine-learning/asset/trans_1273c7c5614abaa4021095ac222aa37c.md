

## 6.7 从时间序列估算李雅普诺夫指数

从时间序列计算李雅普诺夫指数最早由 Wolf 等人提出 [[10]](#c06.xhtml#c6-bib-0010)。在他们的方法中，首先从包含 `2 * N + 1` 个分量的有限时间序列构建一个有限嵌入序列，如下所示：

```
x(0), x(τ), x(2τ), …
```

![Figure 6.2 The attractors for (a) a sinusoid and (b) the above chaotic time sequence, both started from the same initial point.](images/c06f002.gif)

**图 6.2** (a) 正弦波和 (b) 上述混沌时间序列的吸引子，二者均从同一初始点出发。

![Figure 6.3 The reference and the model trajectories, evolution of the error, and start and end of the model trajectory segments. The model trajectory ends when its deviation from the reference trajectory is more than a threshold.](images/c06f003.gif)

**图 6.3** 参考轨迹与模型轨迹、误差的演化，以及模型轨迹段的起点和终点。当模型轨迹偏离参考轨迹超过某一阈值时，模型轨迹终止。

这些是模型构建所依据的基本数据（通常称为参考轨迹或参考轨道）。通常我们没有起始点，因为不存在能够生成该轨迹的显式控制方程。从该序列中我们可以选择一个点 `x(k[0] τ)`，它近似于期望的初始点 `z(0)`。参考 **图 6.3**，这些近似值应满足：

(6.14)
```
|x(k[0] τ) - x(0)| < δ
```

其中 `δ` 是预先选定的容差。我们可以将该点重命名为

(6.15)
```
z[0](0) = x(k[0] τ)
```

该点的后继点已知为：

(6.16)
```
z[0](r τ) = x((k[0] + r) τ), r = 1, 2, 3, …
```

现在有两条轨迹可供比较。第一个时间间隔的对数误差放大因子变为：

(6.17)
```
l[0] = (1/τ) log (|z[0](τ) - z[0](0)| / |x(τ) - x(0)|)
```
