## 4.10 小结

本章回顾了一些适用于 EEG 信号的基本信号处理工具和算法。这些基本技术可用于揭示信号的内在结构和主要特征，据此可确定大脑状态。时频域分析确实是正常和异常情况下 EEG 的良好描述符。相反，熵的变化可描述癫痫患者从发作前期到发作期的转换。这些概念将在本书后续章节中得到利用。
