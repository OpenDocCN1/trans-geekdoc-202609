

## 真实数据应用

上述技术已应用于一组真实数据。此处使用的真实 EEG 数据属于参加连续视觉实验的受试者之一。刺激呈现在距离观察者 80 cm 的计算机屏幕中心。在每次试验中，参与者会看到三个大写字母的水平排列，其中中央字母为目标字母，其余为伴随字母。参与者被指示：若中央字母为 H 则做快速左手反应，若为 S 则做右手反应。实验持续三小时。EEG 从 22 个头皮部位记录，使用连接在电极帽（ElectroCap International）上的 Sn 电极。标准 10-20 系统部位包括 F7、F3、Fz、F4、F8、T7、C3、Cz、C4、T8、P7、P3、Pz、P4、P8、O1、Oz 和 O2。额外的中间部位为 FC5、FC1、FC2 和 FC6。分别提取了前半小时和后半小时的两个独立数据段，分别代表警觉和疲劳状态。每个数据段单独分析，以测量左右半球间的线性同步（相干性）和非线性同步（相位同步）。alpha 节律从 F7 和 F4 提取，beta 节律从 FC5 和 FC6 提取，theta 节律从 P7 和 P8 提取。应用 HT 并估算相干性与相位同步时，考虑了长度为 4 秒的重叠窗口。各半球提取各节律的通道选择，基于左右脑多个电极产生的 IMF 的 HT 结果。从在时频分布中具有更连续频率轨迹的通道（在特定频带内）中选择 IMF。由于生成的 beta 节律噪声较大，使用 ALE 对其进行增强。两个数据段在三个更有效频带上的估算相干性和相位同步值分别如 [Figure 13.1](#c13.xhtml#c13-fig-0001) 和 [13.2](#c13.xhtml#c13-fig-0002) 所示。算法在警觉和疲劳状态下对更多试验重复进行。在几乎所有试验中，左右半球 beta 节律的相干性降低，而 alpha 和 theta 节律的相干性从警觉到疲劳状态呈增加趋势。节律间估算的相位同步值在不同试验中表现出差异，尤其是 theta 节律。然而，在大多数试验中，beta 节律的相位同步降低，而 alpha 节律的相位同步从警觉到疲劳状态增加。

部分工作已被其他研究者重复，如 [\[36\]](#c13.xhtml#c13-bib-0036) 在驾驶疲劳评估背景下的研究。他们利用区域间的相位同步及各区域内的同步（称为功能单元）作为疲劳评估的特征。他们得出结论：从警觉到疲劳，整体同步程度增加；由于驾驶疲劳，额叶和枕后叶 EEG 信号的 delta 和 alpha 频带同步值显著增加。

## 13.4 ERP 在精神疲劳评估中的应用

评估精神疲劳导致的 ERP 参数变化是疲劳分析的另一种通用方法。正如本书前几章所述，从单次试验测量中提取 ERP 成分最流行也最简单的方法是对时锁定的单次试验进行平均。在此方法中，ERP 波的特征（振幅、潜伏期和宽度）被认为在各试验中保持不变，对单次试验平均会导致背景 EEG（视为随机过程）衰减。在许多实际应用中，这一假设并不成立。例如，当精神疲劳程度、习服或注意水平发生变化时，ERP 波形会在试验间发生变化。对多次试验的 ERP 进行平均会忽略 ERP 成分的这种变异性。ERP 成分的试验间变异性是研究脑异常的重要参数。基于统计信号处理，已开发出多种单次试验 ERP 成分估计方法。这些方法包括 Wiener [\[37\]](#c13.xhtml#c13-bib-0037)、最大后验概率（MAP）[\[34\]](#c13.xhtml#c13-bib-0034) 和卡尔曼滤波 \[[30](#c13.xhtml#c13-bib-0030), [35](#c13.xhtml#c13-bib-0035)\] 方法。所有这些方法的目标都是从单次试验测量中估计 ERP 成分，并跟踪其参数在试验间的变异性。然而，在 ERP 信号与背景噪声比极低或测量的 ERP 在试验间变化的情况下，这些方法可能失效。因此，有效的 ERP 分析应基于稳健的单次试验估计，同时考虑 ERP 的试验间变异性。[\[38\]](#c13.xhtml#c13-bib-0038) 中的最新工作将时锁定测量 ERP 的小波系数构建在状态空间中，然后利用粒子滤波估计 ERP 成分。结果表明，构建的粒子滤波优于卡尔曼滤波。但该方法无法估计 ERP 亚成分。在这种情况下，粒子滤波是解决该问题的更好方案。此处提出的方法考虑了从大脑不同部位记录的亚成分间的时间相关性，实现了 ERP 亚成分的分离和识别。

实验显示了不同 ERP 随时间的变化。在这些实验中，受试者无法阻止注意力自动转移 [\[1\]](#c13.xhtml#c13-bib-0001) 到无关刺激，这表现为无关刺激在 N1 潜伏期范围（160-220 ms）引发的负性比相关刺激更大。这种负性差异不受任务用时影响。然而，N1 和 N2b（350-410 ms）振幅随时间变化：N1 振幅降低，相关与无关刺激引发的 N2b 振幅差异（相关刺激引发更大的 N2b 振幅）随任务时间减小。这些实验结果表明，精神疲劳对目标导向（自上而下）和刺激驱动（自下而上）注意的影响是分离的：精神疲劳导致目标导向注意力下降，使受试者以更多刺激驱动的方式执行任务。
