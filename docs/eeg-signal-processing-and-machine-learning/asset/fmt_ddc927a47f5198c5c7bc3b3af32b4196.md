# 第1章 电脑电图导论

## 1.1 简介

大脑是人体最神奇、最复杂的部分，负责控制所有其他器官。人脑的神经活动始于产前发育的第17至23周。人们认为，从这一早期阶段开始，贯穿一生，大脑产生的电信号不仅代表大脑功能，也代表全身状态。这一假设为研究和理解各种大脑活动提供了动力，包括正常脑电节律、大脑对刺激的反应、大脑运动发生器，以及大脑连接性。在大脑疾病、病变或异常情况下，这些活动中的一项或多项会发生变化。通过将先进的数字信号处理和机器学习方法应用于从大脑测得的脑电图（EEG）信号，便可识别大脑状态，往往也能识别全身状况，这为本书后续章节奠定了基础。
