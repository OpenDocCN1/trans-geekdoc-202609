common interpretation is to say “any piece of information that is *potentially relevant* to a person’s current situation.” Dey makes this a bit more concrete by identifying some common categories: location (where), identity (who), time (when), and activity (what) [Dey 2010]. However, other categories can be considered personal context, for example, the social context of an interpersonal relationship.

For now, rather than obsessing over a precise definition, we’ll just establish some guidelines to help you identify instances of personal context. Personal context is personal: it relates to an individual. It changes on some time scale, whether that is on the order of milliseconds, hours, weeks, or even years. For our purposes, it should also be plausibly useful: inferring context doesn’t matter if nobody can come up with a reason that having that context is helpful or important in some way.

Within these guidelines, there remain many different possibilities for personal context. For example, time is not simply restricted to clock time, it could be something much more relative, such as “breakfast time.” *Breakfast time* might be a more useful piece of context for a particular application than, say specifying a clock time when we expect the user to be eating breakfast. It even has a pretty straightforward definition “the time during which the user is eating breakfast in the morning.” However, this doesn’t mean that inferring this piece of context from phone sensors is as straightforward: how do we know from the available sources of data that the user is actually eating breakfast? # **9.1.1 A Continuum of Personal Data**

While it can be useful to think about “types” of personal context as noted, another way to think about context is to think about levels of abstraction within personal data. Personal context is a type of personal data—it is data about an individual. Personal data is also what fuels personal context inferences. Figure 9.1 shows a continuum of personal data, ranging from low level streams on the far left side all the way up to a holistic understanding on the far right side. In general, the process of inferring personal context means taking data at some point on this continuum (often more on the left side) and developing a model or inference to move it up the continuum toward the right side. For example, it is possible to use accelerometer and gyroscope data (far left side) to infer step count.
