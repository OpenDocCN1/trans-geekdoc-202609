# 术语表

当你阅读本书的章节时，你可能会遇到一些不熟悉的术语。本术语表旨在成为你浏览常见AI术语的便捷伴侣。它不是AI术语的详尽百科全书，而是一本友好的指南。在这里，你将找到关键概念的清晰简洁解释，对于建立你的AI素养技能至关重要。

## A

**准确率（机器学习中）**
: 用于评估机器学习（ML）模型性能的指标，衡量在检查的总案例中正确预测的比例。

**通用人工智能（AGI）**
: 一种假设的AI形式，能够以匹配或超越人类认知能力的方式理解、学习和应用智能，适用于广泛的任务。与为特定任务设计的狭窄AI不同，AGI能够将知识和技能推广到新情境。

**AI辅助（AI增强）**
: 该术语描述了使用人工智能增强人类在各种任务中的能力。主要目标是提高效率、准确性和生产力，使学者能够专注于工作的更具创新性和战略性的要素。AI辅助工具充当数字协作者，增强而非取代人类专业知识。

**AI生成（输出）**
: 主要由人工智能系统创建的内容或输出。示例包括文本、图像、音乐、视频和其他数据形式。这些通常使用深度学习和自然语言处理等复杂的AI技术制作。AI系统分析庞大的数据集以生成展示类人创造力或分析能力的创新内容。AI生成内容的质量和复杂性取决于多种因素，包括所使用的算法和训练数据。

**AI素养**
: 有效交互、管理或利用人工智能技术所需的理解和技能组合。这包括对AI是什么、如何工作及其潜在应用的基本知识。AI素养超越了技术技能，涵盖对伦理考虑、AI偏见以及AI对就业、隐私和安全等各领域影响的认识。

**AI工具**
: 集成人工智能以执行或改进任务的软件应用程序或平台。AI工具正越来越多地集成到学术工作流程中，以增强研究和写作流程。

**AI寒冬/AI盛夏**
: 在人工智能研究历史中，“AI寒冬”指进展停滞、导致兴趣和资金减少的时期。相反，“AI盛夏”描述的是进展加速、激发该领域 renewed 兴趣和投资的时期。

**算法**
: 一组设计用于执行特定任务或解决特定问题的逐步指令或规则。在计算中，算法用于操纵、处理和分析数据，形成计算机程序的基础。算法的效率和有效性至关重要，因为它们直接影响软件应用程序或系统的性能和能力。
