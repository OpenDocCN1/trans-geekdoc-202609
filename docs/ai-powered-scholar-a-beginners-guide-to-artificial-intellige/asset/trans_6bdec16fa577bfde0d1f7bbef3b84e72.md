
# 提示示例

- “请总结10篇附带的关于医院患者安全的护理研究论文中呈现的关键主题和理论。摘要应从希望为新毕业护士设计有效的安全协议和错误避免课程的护士教育者角度撰写。请将回复限制在300字以内，并使用适合课堂课程的随意、对话式语言。谢谢！”
  - 这结合了动词“summarise”、护理研究论文的重点、护士教育者视角的背景、与课程设计的契合度，以及字数/语言风格限制。

- “请批判性地评估附带的关于教师教育技术采用的草案实证论文中使用的方法论和数据分析方法。从具有混合方法研究专业知识的学术期刊同行评审员的观点评估其优势和局限性。批判的重点应放在评估所选方法回答研究问题的适用性上，而非对研究领域本身的评论。回复应约为500字。谢谢！”
  - 这结合了动词“critique”、对草案论文的关注、同行评审视角的背景、针对方法评估的契合度，以及字数限制。

- “请解释支撑社会生态模型的关键概念，这些概念我可以在为刚接触该框架的大学生的入门公共卫生课程中教授。使用非正式的语言和贴切的例子阐明该模型的核心原则、层级和因素，使其对来自不同学术背景的本科生有意义。将回复限制在750字。谢谢”。
  - 这结合了动词“explain”、对特定框架的关注、入门本科课程的背景、要求使用非正式语言/例子的契合度，以及对AI应生成字数的指导。

## 附加示例

撰写自己的提示时，您可以参考的附加示例包括：

- “综合这10篇与\[topic\]相关的论文中的共同主题和关系，以在250字的摘要中突出关键见解。采用客观观点，尽可能避免偏见”。
- “构建概念图，描绘附带章节中涵盖的核心理论和关系。具体聚焦于与\[subtopic\]相关的部分”。
- “为附带的关于儿童发展的研究论文撰写3分钟视频介绍脚本，以简单易懂的术语突出关键发现，供普通观众观看”。
- “分析附带的数据集，以识别与\[research topic\]相关的关键趋势和模式，并解释其对公共政策影响的关键要点。以250字的执行摘要呈现研究结果”。
- “审阅测量\[variables\]的附带草案调查问卷，并提出改进效度和减少偏见的建议。从专家调查方法学的角度，重点反馈问题类型、用词、顺序、评分量表等”。
- “从同行评审员的视角批判附带论文中使用的方法论的优势和劣势。重点评估方法对研究目标的适当性，并提出更好地建立因果关系的建议”。
- “比较这两篇关于\[topic\]的研究论文中描述的实验发现，并综合相似点和差异。避免讨论工作本身的含义或观点”。
- “请撰写一篇博客文章，总结关于\[topic\]的最新研究，以通俗语言突出对教育者的关键实践意义。假设读者为学校管理人员和教师”。
- “起草一份200字的会议演讲摘要，总结附带的关于\[topic\]的研究手稿的目标、方法、主要发现和结论”。

正如这些示例提示所示，通过策略性地组合元素，您可以创建细致、量身定制的指令，引导AI工具实现您的特定学术目标。这样可以实现近乎无限的提示多样性，每个提示都精确地针对您的独特研究需求和目标进行调整。

# 提示编写策略总结

基于实践经验，结合最佳实践方法，

- 使用自然、对话式的语言，而非简略或技术性的表述。
- 通过具体化避免歧义。定义任何可能含糊的指令（除非您有意寻求AI的模糊回应）。
- 提供相关示例和附件以锚定上下文。
- 设定有助于创意的限制，如字数、格式、包含/排除标准。
- 对局限性保持透明——承认如果生成文本需要意图、伦理和准确性审查。
- 为AI设定指定角色（在[第4章](#C_008_c4.xhtml)中探讨）。
- 表达情感和对话风格偏好以塑造互动。
- 回顾之前的回应以建立关联和连贯性。
- 用具体的行动动词开始提示，如“summarise”、“analyse”、“compare”等。
- 指定期望的格式、风格以及其他要求。
- 监控输出并逐步优化提示，使AI回应与您的目标保持一致。

最后，请记住提示编写是一个迭代过程——您的初始尝试很少能产生完美的结果。在我的经验中，与AI聊天机器人的互动有点像打网球。想法和指令在数字网前来回传递，每次交流都在完善您的方法。就像任何技能一样，练习越多，您就越可能变得更好。如果您的第一次发球没有完全命中目标，请不要气馁。

考虑到提示的这种迭代特性，让我们探索一种方法，帮助您在这个过程中变得更加舒适和熟练。

# 迭代提示优化

迭代提示优化是指根据AI的回应逐步调整提示的措辞，以便您获得更准确、相关且有用的结果。这种迭代循环不仅能提升AI生成内容的质量，还能加深您对有效提示设计的理解。

下面，让我们探索一个与AI系统进行迭代对话的工作流程，确保每次互动都更接近您期望的AI生成结果。

1. 从明确的目标开始：在启动优化过程之前，明确定义您的目标。您希望从AI获得什么具体信息或类型的回应？明确的目标有助于聚焦优化过程并根据目标评估AI的回应。
2. 分析初始回应：评估AI的初始回应，以了解其如何解读您的提示。识别错位区域，如不准确、信息不相关或对任务的误解。此分析将指导您的提示调整。
3. 实施增量调整：基于您的分析，对提示进行增量调整。这可能涉及澄清上下文、补充、完善指令或指定限制。小而集中的更改可让您分离每次修改的影响，了解提示的每个元素如何影响AI的回应。

增量调整的策略可以包括：

- 明确任务：如果AI的回应偏离目标，请使任务更明确。
- 调整细节程度：如果回应过于笼统，请调整提示以指定期望的细节程度或回应的范围。
- 提供示例：包含期望输出的示例可以帮助AI朝向偏好的风格或格式。
