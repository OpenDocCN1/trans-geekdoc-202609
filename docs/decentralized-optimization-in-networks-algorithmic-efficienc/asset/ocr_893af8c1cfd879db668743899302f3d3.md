apparent that solving an additional optimization problem at each time step, as depicted in (1.11), is not necessary. Instead, we can efficiently obtain the minimizer by utilizing \(x_i^t = \min\{\max\{\nabla C_i^{-1}(v_i^t), x_{i,\min}\}, x_{i,\max}\}\) as referenced in [28,31]. Here, \(\nabla C_i^{-1}\) represents the inverse function of \(\nabla C_i\), which is defined within the interval \([\nabla C_i^{-1}(x_{i,\min}), \nabla C_i^{-1}(x_{i,\max})]\). By adopting this approach, the computation of (1.11) can be achieved in a cost-effective way.

# ## 1.3.3 Notation simplification

To simplify notation, we consider the following equivalent form of (1.8):

```
\(\min_{p \in \Sigma} b^T p, \text{ s.t. } f_i(p) \le 0, i = 1, ..., n,\) (1.16)
```

where \(p = (y, k^T)^T \in \mathbb{R}^{n+1}\) and \(b = (0, 1_n^T)^T\). Furthermore, \(f_i : \mathbb{R}^{n+1} \to \mathbb{R}\) is a convex function. For any integer \(t \ge 1\), define \(p_i^t = (y_i^t, (k_i^t)^T)^T\), \(i \in \mathcal{V}\). Subsequently, the algorithms (1.15a), (1.15c), and (1.15d) for addressing (1.16) can be expressed as follows: \(\forall i \in \mathcal{V}, t \ge 1\),

```
\(p_i^t = h_i^t - \frac{[f_i(h_i^t)]_+}{|\xi_i^t||^2} \xi_i^t, i \in \{i', j'\},\) (1.17a)
\(p_i^t = \sum_{j=1}^n W_{ij}^t p_j^{t-1}, i \notin \{i', j'\},\) (1.17b)
```

where \(h_i^t = \sum_{j=1}^n W_{ij}^t p_j^{t-1} - \alpha_i^t b\) for \(i \in \{i', j'\}\). Additionally, the vector \(\xi_i^t \in \partial[f_i(h_i^t)]_+\) if \([f_i(h_i^t)]_+ > 0\) and \(\xi_i^t = \xi_i\) for some \(\xi_i \neq 0_{n+1}\) if \([f_i(h_i^t)]_+ = 0\). We denote \(\Xi_i = \{p \in \Sigma | f_i(p) \le 0\}\), \(\Sigma_0 = \Sigma_1 \cap \dots \cap \Sigma_n\), and \(\Sigma^* = \{\theta \in \Sigma_0 | b^T p \le b^T p', \forall p' \in \Sigma_0\}\).

Here, we can infer that the subgradient \(\xi_i^t\) remains consistently bounded within the set \(\Sigma\) as defined in (1.8), such that its norm satisfies \(||\xi_i^t|| \le D, \forall i \in \mathcal{V}, t \ge 1\). Given the simplicity of this conclusion, we omit the corresponding proofs and direct the reader to Proposition 1 in [22]. Moreover, we can ascertain that (1.16) is viable and possesses a non-empty set of optimal solutions, that is, \(\Sigma_0 \neq \emptyset\) and \(\Sigma^* \neq \emptyset\).
