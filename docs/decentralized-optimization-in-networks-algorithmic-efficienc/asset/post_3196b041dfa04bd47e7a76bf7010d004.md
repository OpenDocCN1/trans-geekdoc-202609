

\(\sum_{l=0}^{\tau-1} \alpha_l t_w^{t-l} [ ||y_l' - 1_N \otimes \bar{y}_l'||^2 ] + L^2 [ ||x_l - 1_N \otimes \bar{x}_l||^2 ] + \frac{L^2}{N} [ ||\bar{x}_l - x^*||^2 ]\)
\(+ \frac{8c_w^{\frac{3}{2}} c_\rho \alpha_t^2}{(1-\tau_w)^3} (\frac{\pi^2 C}{6} + U_1) + \frac{\sqrt{c_w} c_\rho U_1 \alpha_t^2}{1-\tau_w},\)
(4.34)

where \(\tau_2\) can be any positive number, and the inequality relies on several factors: \(\bar{y}'_l = \frac{1}{N} \sum_{i=1}^N \nabla f^i(x_l^i)\), \(2(a,b) \le \tau_2 a^2 + b^2/\tau_2\), and (4.13). By inserting Eq. (4.34) into (4.27), and invoking Lemma 4.1 and Theorem 4.1, we arrive at the conclusion that

\(\mathbb{E}[||\bar{x}_{t+1} - x^*||^2] \le (1 - \frac{\mu - (L+1)\sqrt{N}\tau_2}{N} \alpha_t) \mathbb{E}[||\bar{x}_t - x^*||^2]\)
\(+ \mathcal{O}(\alpha_t^2) + \mathcal{O}(\alpha_t^3) + \mathcal{O}(\alpha_t^4)\)
\(\le (1 - \frac{\mu}{2N} \alpha_t) \mathbb{E}[||\bar{x}_t - x^*||^2] + \mathcal{O}(\alpha_t^2),\)

where \(\tau_2\) is set to \(\mu / 2(L+1)\sqrt{N}\). Subsequently, utilizing Lemma 5 from [10], it gives

\(\mathbb{E}[||\bar{x}_{t+1} - x^*||^2] = \mathcal{O}(\alpha_t).\)

Observing that \(\lim_{t \to \infty} \alpha_{t-1} / \alpha_t = 1\), we can confirm that (4.33) is valid. Assuming \(\alpha_t\) is defined as \(a/(t+1)\) and the positive scalar \(a\) meets the condition \(a > (2N/\mu)\), it follows that \((\mu a / 2N) > 1\). Consequently, based on Lemma 4 from the reference [10], we can draw the following inference:

\(\mathbb{E}[||\bar{x}_t - x^*||^2] = \mathcal{O}(\frac{1}{t}).\)

The proof is completed.

To showcase the effectiveness of the event-triggering mechanism, let us first define: \(A = \max\{4U_2 a^2 + 6U_{22}a^2, 4U_3 a^2 + 6U_2 a^2\}\), \(B = \max\{4U_2 a^2 + 12L^2 U_3 a^2, 4U_3 a^2 + 12L^2 U_3 a^2\}\), and \(D = \frac{24 N c_w}{(1-\tau_a)^2} (\frac{\pi^2 C}{6} + U_1)\), where \(U_3\) represents a positive scalar that fulfills the condition \(\mathbb{E}[||\bar{x}_t - x^*||^2] \le U_3 \alpha_t\) as stated in Theorem 4.2. Following this, we proceed with the demonstration in the theorem below.

## **Theorem 4.3.** Under the conditions that Assumptions 4.1-4.3 are valid, and provided that the step-size \(\alpha_t\) meets the criteria outlined in Theorem 4.2, along with the event-triggering parameter \(C\) satisfying that \(C \ge 2A - (A+B)^2 / 4D\), then, \(\forall i \in \mathcal{V}, t \ge 1, t_{k+1}^i - t_k^i \ge 2\).

**Proof.** From Eq. (4.4), it can be inferred that

\(||e_t^{i,x}||^2 + ||e_t^{i,y}||^2\)
\(= ||x_t^i - x_t^i||^2 + ||y_t^i - y_t^i||^2\)

\le 4||x_{t_k}^i - \bar{x}_{t_k}^i||^2 + 4||\bar{x}_{t_k}^i - x^*||^2 + 4||x^* - \bar{x}_t||^2
+ 4||\bar{x}_t - x_t^i||^2 + 6||y_{t_k}^i - y_{t_k}^{i'}||^2 + 6||y_t^{i'} - y_t^i||^2
+ 6||y_{t_k}^{i'} - \bar{y}_{t_k}^{i'}||^2 + 6||\bar{y}_t^{i'} - y_t^{i'}||^2
+ 6||\bar{y}_{t_k}^{i'} - \frac{1}{N}\nabla f(x^*)||^2 + 6||\frac{1}{N}\nabla f(x^*) - \bar{y}_t^{i'}||^2.

Keeping in mind that $\mathbb{E}[||\bar{x}_t - x^*||^2]$ is of the order $\mathcal{O}(\alpha_t)$, $\mathbb{E}[||x_t - 1_N \otimes \bar{x}_t||^2]$ is bounded by $U_2\alpha_t^2$, and $\mathbb{E}[||y_t^i - 1_N \otimes \bar{y}_t^i||^2]$ is also limited by $U_2\alpha_t^2$, we can deduce that

||e_t^{i,x}||^2 + ||e_t^{i,y}||^2 \le \mathcal{O}(\alpha_{t_k}) + \mathcal{O}(\alpha_t) + D
\le A \frac{1}{t_k^i + 1} + B \frac{1}{t + 1} + D.

It is important to note that in the event that the triggering condition is not fulfilled, the triggering time remains unchanged. This signifies that the sum of squared norms $||e_t^{i,x}||^2 + ||e_t^{i,y}||^2$ is less than or equal to $C/(t+1)^2$ for all non-negative values of $t$ and for every $i$ belonging to the set $\mathcal{V}$. Consequently, at the time $t = t_{k+1}^i$, the subsequent equation necessarily applies:

||e_{t_{k+1}^i}^{i,x}||^2 + ||e_{t_{k+1}^i}^{i,y}||^2 \ge \frac{C}{(t_{k+1}^i + 1)^2},

which suggests that

A \frac{1}{t_k^i + 1} + B \frac{1}{t_{k+1}^i + 1} + D \ge \frac{C}{(t_{k+1}^i + 1)^2}. \quad (4.35)

Evidently, we can deduce that Eq. (4.35) is valid provided that the constant $C$ fulfills

t_{k+1}^i - t_k^i \ge \frac{A^2 + B^2 + 2AB + 4CD}{4AD}. \quad (4.36)

Thus far, it is adequate to demonstrate that the interval between $t_{k+1}^i$ and $t_k^i$ is greater than or equal to 2, provided that $C$ is selected in accordance with Theorem 4.3. $\square\)

**Remark 4.4.** The communication overhead associated with ET-DSGT is significantly influenced by the event-triggering parameter \(C\). Provided that \(C\) meets the criterion outlined in Theorem 4.3, namely \(C \ge 2A - (A + B)^2/4D\), and all other parameters align with Theorem 4.2, it becomes evident that the duration between consecutive triggering instances exceeds 2. Specifically, \(t_{k+1} - t_k \ge 2\) for all \(t \ge 1\). This inference indicates that, when utilizing the event-triggering mechanism, the communication expenditure of ET-DSGT is greatly reduced.

## 4.4 Simulation experiments

In this section, we present two simulations to verify the efficiency of ET-DSGT. Note that the simulations are implemented using Matlab® R2021a on a laptop with Intel i3-10100 CPU@3.60 GHz, RAM 16.0 GB, and Windows 11 operating system.

### 4.4.1 Logistic regression

In this subsection, we present the initial simulation that revolves around the decentralized logistic regression problem on an undirected network. Within this simulation framework, the network is randomly connected, featuring m = 10 agents and a connection likelihood of p<sub>c</sub> = 0.8. The decentralized logistic regression problem assumes the shape of:

$$\min_{x \in \mathbb{R}^p} \frac{1}{N} \sum_{i=1}^N \frac{1}{m^i} \sum_{h=1}^{m^i} \ln(1 + \exp(-w^{i,h}(v^{i,h})^\mathrm{T} x)) + \frac{\pi}{2} ||x||_2^2,$$

where N represents the quantity of agents, while the local function f<sup>i</sup>(x) is expressed as

$$f^i(x) = \frac{1}{m^i} \sum_{h=1}^{m^i} \ln(1 + \exp(-w^{i,h}(v^{i,h})^\mathrm{T} x)) + \frac{\pi}{2} ||x||_2^2,$$

where v<sup>i,h</sup> \(\in \mathbb{R}^p\) signifies the dataset, whereas w<sup>i,h</sup> \(\in \{-1, 1\}\) corresponds to the locally stored data labels by agent i for each h ranging from 1 to m<sup>i</sup>. The final component serves as a regularization term, aiming to avert over-fitting.

For this simulation, we employ a genuine dataset, specifically the breast cancer Wisconsin dataset sourced from the UCI Machine Learning Repository [44]. Additionally, a total of m = 200 data instances are randomly allocated to each local agent for training purposes, with each instance containing d = 9 attributes. It is worth mentioning that all dataset features have undergone pre-processing and normalization. The simulation outcomes can be categorized into three primary sections.

- (1) Convergence: In this simulation, Fig. 4.1 displays three randomly chosen dimensions of the transient behaviors of estimator x, demonstrating that in ET-DSGT, the estimator x ultimately reaches a stable condition, specifically, the global minimum. In other words, ET-DSGT exhibits excellent convergence capabilities.

- (2) Triggering times: In this simulation, we explore the trigger times for 5 agents executing the ET-DSGT algorithm. The findings from the simulation are presented in Fig. 4.2 and Table 4.1, confirming Theorem 4.3. Both Table 4.1 and Fig. 4.2 reveal that communication in ET-DSGT is intermittent. When juxtaposed with Fig. 4.1, it becomes evident that ET-DSGT can attain comparable convergence precision with a reduced communication frequency over a similar number of iterations when compared to the associated methods.
