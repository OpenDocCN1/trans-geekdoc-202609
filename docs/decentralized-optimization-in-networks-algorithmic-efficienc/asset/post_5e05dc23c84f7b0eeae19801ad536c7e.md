## 7.4 Convergence guarantees

This section provides a theoretical analysis of the convergence behavior of Algorithm 1. Initially, two preliminary results related to projection operation and the matrix \( P(k) \) are presented. Subsequently, two crucial lemmas are introduced by defining several auxiliary vectors, which significantly impact the main results. Finally, the convergence of Algorithm 1 is established based on these findings.

### 7.4.1 Preliminary results

We first present two useful preliminary results.

**Lemma 7.1.** [17] For any \(\vartheta, \sigma \in \mathbb{R}^d\), the following holds:

\(\left\|\Pi_\Omega^\vartheta(\vartheta, \gamma) - \Pi_\Omega^\sigma(\sigma, \gamma)\right\| \le \gamma \|\vartheta - \sigma\|.\)

Define the state transition matrix \(\psi(k_1, k_2) = [\psi_{ij}(k_1, k_2)] \in \mathbb{R}^{d \times d}\), which satisfies:

\(\psi(k_1, k_2) = \begin{cases} P(k_2 - 1)P(k_2 - 2) \cdots P(k_1), & k_2 > k_1, \\ I_n, & k_2 \le k_1. \end{cases}\)

Based on [11, Corollary 2], we obtain the following result for \(\psi(k_1, k_2)\).

**Lemma 7.2.** [11] Under Assumption 7.2, for any \(k_2 \ge k_1 > 0\), there exists a sequence of stochastic vectors \(\phi(k) = [\phi_1(k), ..., \phi_v(k)]^\mathrm{T} \in \mathbb{R}^v\) (\(i.e., \phi_i(k) \ge 0\), \(\sum_{i=1}^v \phi_i(k) = 1\)) such that

\(|\phi_i(k) - \psi_{ij}(s, k)| \le C \lambda^{k-s}, \forall i, j \in \mathcal{V},\)

where \(C > 0\) is a constant and \(\lambda \in (0, 1)\). Additionally, the following inequality holds:

\(\mu \le \sum_{j=1}^v \psi_{ij}(1, k) \le \kappa, \forall i \in \mathcal{V},\)

where \(\mu\) and \(\kappa\) are positive constants.

### 7.4.2 Supporting results

This subsection presents two key lemmas to further illustrate the performance of Algorithm 1.

**Lemma 7.3.** Given that Assumptions 7.1 and 7.2 are satisfied, define the auxiliary vector \(\bar{h}(k+1) = \frac{1}{v}\sum_{i=1}^v h_i(k+1)\). There exists a constant \(\Theta > 0\) such that for all \(k \ge 1\) and \(i \in \mathcal{V}\), the following inequality holds:

\(\left\| \frac{h_i(k)}{q_i(k)} - \bar{h}(k) \right\| \le \Theta,\)

where

\(\Theta = \frac{1}{\mu}(\delta Q + (1 + v)L + \kappa \sum_{j=1}^v ||h_j(1)||) + \frac{Cv(2L + \delta Q)}{\mu(1 - \lambda)} + ||\bar{h}(1)||.\)

_Proof._ It follows from (7.4) and (7.5a) that

\(h_i(k+1) = \sum_{s=1}^{k-1} \sum_{j=1}^v \psi_{ij}(s+1, k+1) \sum_{l=1}^v P_{jl}(s)\tau_{jl}(s) + g_i(k) + \sum_{s=1}^{k-1} \sum_{j=1}^v \psi_{ij}(s+1, k+1) g_j(s) + \sum_{j=1}^v P_{ij}(k)\tau_{ij}(k) + \sum_{j=1}^v \psi_{ij}(1, k+1)h_j(1).\) (7.8)

Similarly, according to (7.5b), we can obtain that

\(q_i(k+1) = \sum_{j=1}^v P_{ij}(k)q_j(k) = \sum_{j=1}^v \psi_{ij}(1, k+1),\) (7.9)

derived from the condition \(q_j(1) = 1\) for all \(j \in \mathcal{V}\). Utilizing (7.7) and the definition of \(\bar{h}(k+1)\), we obtain

\(\bar{h}(k+1) = \frac{1}{v} \sum_{i=1}^v (\sum_{j=1}^v P_{ij}(k)h_j(k) + \sum_{j=1}^v P_{ij}(k)\tau_{ij}(k) + g_i(k)) = \frac{1}{v} \sum_{j=1}^v h_j(k) + \frac{1}{v} \sum_{i=1}^v \sum_{j=1}^v P_{ij}(k)\tau_{ij}(k) + \frac{1}{v} \sum_{i=1}^v g_i(k) = \bar{h}(k) + \frac{1}{v} \sum_{i=1}^v g_i(k),\) (7.10)

where the second equation holds since \(P(k)\) is column-stochastic. Therefore

\(\bar{h}(k+1) = \bar{h}(k) + \frac{1}{v} \sum_{i=1}^v g_i(k) = \frac{1}{v} \sum_{i=1}^v h_i(1) + \frac{1}{v} \sum_{s=1}^k \sum_{i=1}^v g_i(s). \tag{7.11}\)

Thus it follows from (7.8)–(7.10) that

\(\bar{h}(k+1) - \frac{h_i(k+1)}{q_i(k+1)} = \frac{\omega_1 + \omega_2 + \omega_3}{q_i(k+1)} + \omega_4, \tag{7.12}\)

where

\(\omega_1 = \frac{1}{v} \sum_{s=1}^k \sum_{j=1}^v g_j(s) q_i(k+1) - \sum_{s=1}^k \sum_{j=1}^v \psi_{ij}(s+1, k+1) g_j(s), \\ \omega_2 = \sum_{s=1}^{k-1} \sum_{j=1}^v \psi_{ij}(s+1, k+1) \sum_{l=1}^v P_{jl}(s) \tau_{jl}(s) + \sum_{j=1}^v P_{ij}(k) \tau_{ij}(k), \\ \omega_3 = \sum_{j=1}^v g_j(k) - g_i(k) - \sum_{j=1}^v \psi_{ij}(1, k+1) h_j(1)\)

and \(\omega_4 = \bar{h}(1)\). Next, we analyze the terms \(\omega_1, \omega_2\), and \(\omega_3\), respectively. Defining a sequence of stochastic vectors \(\phi(k) = [\phi_1(k), \dots, \phi_v(k)]^T \in \mathbb{R}^d\) as in Lemma 7.2, we obtain

\(\omega_1 = \sum_{s=1}^k \sum_{j=1}^v g_j(s) (\frac{q_i(k+1)}{v} - \phi_i(k+1)) + \sum_{s=1}^k \sum_{j=1}^v g_j(s) (\phi_i(k+1) - \psi_{ij}(s+1, k+1)) = \frac{1}{v} \sum_{s=1}^k \sum_{j=1}^v g_j(s) \sum_{j=1}^v (\psi_{ij}(1, k+1) - \phi_i(k+1)) + \sum_{s=1}^k \sum_{j=1}^v g_j(s) (\phi_i(k+1) - \psi_{ij}(s+1, k+1)). \tag{7.13}\)

According to Lemma 7.2, it follows that

\[
\|\omega_1\| \le \frac{1}{v} \sum_{s=1}^k \sum_{j=1}^v \|g_j(s)\| |\sum_{j=1}^v (\psi_{ij}(1, k+1) - \phi_i(k+1))| + \sum_{s=1}^k \sum_{j=1}^v \|g_j(s)\| |\phi_i(k+1) - \psi_{ij}(s+1, k+1)| \le vLC \sum_{s=1}^k \lambda^k + vLC \sum_{s=1}^k \lambda^{k-s} \le \frac{2vLC}{1 - \lambda},
\]

where \(\|g\| \le L\) is used in the second inequality. Similarly, for \(\omega_2\), we have

\(\omega_2 = \sum_{s=1}^{k-1} \sum_{j=1}^v [\psi_{ij}(s+1, k+1) - \phi_i(k+1)] \sum_{l=1}^v P_{jl}(s) \tau_{jl}(s) + \phi_i(k+1) \sum_{s=1}^{k-1} \sum_{j=1}^v \sum_{l=1}^v P_{jl}(s) \tau_{jl}(s) + \sum_{j=1}^v P_{ij}(k) \tau_{ij}(k).\)

From (7.7), we know that \(\sum_{j=1}^v \sum_{l=1}^v P_{jl}(s) \tau_{jl}(s) = 0\) for any \(s\). Then, according to Lemma 7.2, it follows that

\(\|\omega_2\| \le \sum_{s=1}^{k-1} \sum_{j=1}^v |\psi_{ij}(s+1, k+1) - \phi_i(k+1)| \delta Q + \delta Q \le \sum_{s=1}^{k-1} v \max_j |\psi_{ij}(s+1, k+1) - \phi_i(k+1)| \delta Q + \delta Q = \frac{vC\delta Q}{1 - \lambda} + \delta Q,\)

where the first inequality follows from \(\sum_{l=1}^v \|P_{jl}(s) \tau_{jl}(s)\| \le \delta Q\) for \(\|\tau_{ij}(k)\| \le \delta, \forall i, j \in \mathcal{V}\), and \(\sum_{j=1}^v \|P_{ij}(k)\| < Q, \forall k \ge 1\). In addition, we also deduce that

\(\|\omega_3\| \le \|\sum_{j=1}^v g_j(k) - g_i(k)\| + \|\sum_{j=1}^v \psi_{ij}(1, k+1) h_j(1)\| \le (1 + v)L + \kappa \sum_{j=1}^v \|h_j(1)\|.\)

Combining (7.12), (7.14), (7.16), and (7.17), we can derive

\(\left\| \frac{h_i(k+1)}{q_i(k+1)} - \bar{h}(k+1) \right\| \leq \frac{\|\omega_1\| + \|\omega_2\| + \|\omega_3\|}{q_i(k+1)} + \|\omega_4\| \leq \frac{2vLC + vC\delta Q}{\mu(1-\lambda)} + \frac{\delta Q + (1+v)L + \kappa \sum_{j=1}^v \|h_j(1)\|}{\mu} + \|\bar{h}(1)\|.\)

Hence, we conclude the proof.

Next, we provide the necessary definitions for the subsequent supporting lemma. For every \(k \ge 1\), an auxiliary variable is defined as follows:

\(\varsigma(k) = \Pi_\Omega^\omega(\bar{h}(k), \gamma(k-1)).\)

Moreover, for any vector \(\sigma \in \mathbb{R}^d\) and \(\gamma > 0\), a conjugate-type function related to the function \(\varphi(\cdot)\) is given by

\(\varphi^\dagger(\sigma, \gamma) = \sup_{x \in \Omega} \{ \langle \sigma, x \rangle - \frac{1}{\gamma} \varphi(x) \}.\)

Moreover, we define \(\hat{g}(s) = (1/v) \sum_{i=1}^v g_i(s)\). Using the above definitions, we now establish a crucial lemma to support the main results.

**Lemma 7.4.** Consider the functions \(\Pi_\Omega^\omega(\sigma, \gamma)\) and \(\varphi^\dagger(\sigma, \gamma)\) given by (7.2) and (7.20), respectively. For a non-increasing and positive sequence \(\{\gamma(k)\}_{k=1}^\infty\), the following statements hold:

- (a) \(\nabla \varphi^\dagger(-\sigma, \gamma) = \Pi_\Omega^\omega(\sigma, \gamma);\)
- (b) \(\sum_{s=1}^k \langle \hat{g}(s), \varsigma(s) - x^* \rangle \leq \frac{1}{2} \sum_{s=1}^k \gamma(s-1) \|\hat{g}(s)\|^2 + \frac{1}{\gamma(k)} \varphi(x^*) + \varphi^\dagger(-\bar{h}(1), \gamma(0)) + \langle h(1), x^* \rangle, \forall x^* \in \Omega.\)
