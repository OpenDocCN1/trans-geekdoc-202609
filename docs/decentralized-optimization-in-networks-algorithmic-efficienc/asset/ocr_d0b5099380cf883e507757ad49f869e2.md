**Remark 6.9.** In parts \( 2) \) and \( 3) \), we presume that the training of the decentralized logistic regression classification model takes place in a static (non-time-varying cost function) setting, a logical and prerequisite assumption grounded in two pivotal reasons. Firstly, given that the algorithms under consideration converge asymptotically, a time-varying cost function (where labels fluctuate at each iteration) poses a challenge for achieving convergence within a single cycle, ultimately hindering the accuracy of machine learning training. Consequently, the algorithm's performance metrics become less reliable and precise. This is an inherent limitation that transcends algorithmic optimization efforts. Secondly, assessing the privacy-preserving efficacy of Algorithm 1 within a static environment furnishes a more robust validation (please see footnote 3 for more details).
