Let \( p^* \in \mathbb{R}^{n+1} \) denote an optimal solution of the problem (1.16). In the subsequent analysis, we will leverage Lemma 1.5 to derive the convergence properties of Algorithm 1.

# **Theorem 1.1.** Assuming that Assumptions 1.1 and 1.2 are valid. If \( 0 < \epsilon < 1/2 \), there exists a threshold \( \hat{t} = \hat{t}(\epsilon, n) \) (large enough) such that for all \( t \ge \hat{t}, i \in \mathcal{V} \), \( \lim_{t \to \infty} p_i^t = p^* \) a.s., and \( \lim_{t \to \infty} x_i^t = x_i^* \) a.s..

**Proof.** Revisiting Lemma 1.5 and setting \( v = p^* \), we obtain that

```
\[
\sum_{i=1}^n \pi_i \mathbb{E}_{t-1} \left[ \| p_i^t - p^* \|^2 \right] \\
\le (1 + \frac{\alpha_3}{t^{3/2-\epsilon}}) \sum_{i=1}^n \pi_i \| p_i^{t-1} - p^* \|^2 - \frac{2}{t} \mathbb{E}_{t-1} \left[ b^T(\tilde{\phi}^t - p^*) \right] \\
- \eta_{\min} \beta \mathbb{E}_{t-1} \left[ \sum_{i=1}^n \pi_i \| \phi_i^t - \phi_i^t \|^2 \right] \\
+ (\frac{\alpha_3}{t^{3/2-\epsilon}} + \frac{\alpha_2}{t^2}(1 + 4\nu + \tau))\|b\|^2.
\]
(1.33)
```

Observing that \( \epsilon \) falls within the range \( 0 < \epsilon < 1/2 \), it follows that \( 1 < (3/2 - \epsilon) < 3/2 \). This inequality enables us to deduce that the infinite series \( \sum_{t=0}^\infty \frac{\alpha_2}{t^{3/2-\epsilon}} \) converges, and similarly, the series \( \sum_{t=0}^\infty (\frac{\alpha_3}{t^{3/2-\epsilon}} + \frac{\alpha_2}{t^2}(1 + 4\nu + \tau))\|b\|^2 \) also converges. Given that \( \phi_i^t \) belongs to the set \( \Xi_0 \), we have the positive quantity \( b^T(\tilde{\phi}^t - p^*) > 0 \). Since we have already established that \( \beta \) is positive, all the prerequisites of Lemma 1.3 are met. Therefore applying Lemma 1.3 shows that

```
\(\left\{ \sum_{i=1}^n \pi_i \| p_i^t - p^* \|^2 \right\} \text{ converges } a.s. \text{ as } t \to \infty, \quad (1.34a)\)
\(\sum_{t=0}^\infty -\frac{2}{t} b^T (\tilde{\phi}^t - p^*) < \infty \quad a.s., \quad (1.34b)\)
\(\sum_{t=0}^\infty \sum_{i=1}^n \pi_i \| \phi_i^t - \phi_i^t \|^2 < \infty \quad a.s.. \quad (1.34c)\)
```

```
\(\lim_{t \to \infty} \inf b^T \tilde{\phi}^t = b^T p^* \quad a.s..\)
```
