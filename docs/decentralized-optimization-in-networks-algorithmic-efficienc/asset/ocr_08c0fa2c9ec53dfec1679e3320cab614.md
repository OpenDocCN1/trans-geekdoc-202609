step-size \(\alpha_i \ge 0\). During each subsequent iteration \(t + 1\), the variables are updated in step 3. Following the update, the measurement errors are determined using (2.9), serving as the basis for evaluating the triggering condition in the next step. Only if the error value surpasses the threshold set in (2.8), does generator \(i\) disseminate \(\theta_i^{t+1}\) and \(z_i^{t+1}\) to its neighboring node \(j \in \mathcal{N}_i\) and updates the most recent triggering time. If not, the local estimate remains the same.
