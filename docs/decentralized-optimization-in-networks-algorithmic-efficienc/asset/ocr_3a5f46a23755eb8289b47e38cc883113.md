\(\alpha^T = \sum_{l=1}^T \frac{1}{\sqrt{l}} \approx \int_1^T \frac{1}{\sqrt{l}} dl = \sqrt{T}.\)

Consequently, the complexity of the proposed algorithm is determined to be \(\mathcal{O}(1/\epsilon^2)\) [63]. The proof is thus complete.

**Remark 8.7.** Corollary 8.2 implies that the proposed algorithm can converge as quickly as \(\mathcal{O}(1/\sqrt{T})\) almost surely if \(\gamma_i^t = 1/\sqrt{t}\) for all \(i \in \mathcal{V}\). This represents the optimal result for such decentralized gradient-based algorithms [49]. Consequently, the complexity described in Corollary 8.2 is consistent with existing complexity results [23,24,36,61]. It is essential to remember that problem complexity refers to the lower bound of the complexities of methods that can effectively solve the problem. Therefore the complexity of the EDP discussed in this chapter is also \(\mathcal{O}(1/\epsilon^2)\). Note that only methods closely related to the algorithm proposed here—decentralized gradient-based algorithms—are considered, as considering others would render the problem complexity result irrelevant.

**Remark 8.8.** In fact, it is possible to further enhance the communication efficiency of Algorithm 1 by employing the well-known event-triggering strategy [50,51]. This strategy eliminates the need for real-time information exchange between generators, thus reducing communication overhead. Additionally, inspired by recent studies [43, 52], one could consider time-varying implementations and asynchronous schemes for Algorithm 1 using either a broadcast-based or gossip-based mechanism. These enhancements could significantly advance the development of Algorithm 1 and will be the focus of future research.

This section presents the privacy analysis of the decentralized random sleep algorithm with privacy protection, as described in Algorithm 1. The cost function used here is analogous to those found in existing studies [13,19,36] on EDP, often taking the form of a quadratic function.
