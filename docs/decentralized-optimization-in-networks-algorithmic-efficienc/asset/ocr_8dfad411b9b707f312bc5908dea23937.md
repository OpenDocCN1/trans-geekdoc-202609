# ### 4.1.4 Notation

Let R^N and R^(N x N) represent the Euclidean spaces of dimensions N and N x N, respectively. The identity matrix of size N x N is denoted by I_N, which belongs to R^(N x N). # ### 4.2.1 Problem description

In this chapter, we tackle the following optimization problem:

```
\(\min_{x \in \mathbb{R}^d} f(x) = \frac{1}{N} \sum_{i=1}^N f^i(x), \quad (4.1)\)
```

where x ∈ R^d serves as the optimization estimator, f^i(x) represents the local cost function of each agent.

Our aim is to address problem (4.1) within an undirected network setting. The network is depicted by G = {V, E, W}, in which V = {1, 2, ..., N} signifies the entities within the network, E ⊆ V x V signifies the connections between these entities, and W = [w^ij] ∈ R^(N x N) signifies the network’s adjacency matrix. A positive value of w^ij indicates a connection between entities i and j, whereas a zero value indicates no such connection. Furthermore, the notation N^i = {j | w^ij > 0} is used to represent the adjacent entities to entity i.
