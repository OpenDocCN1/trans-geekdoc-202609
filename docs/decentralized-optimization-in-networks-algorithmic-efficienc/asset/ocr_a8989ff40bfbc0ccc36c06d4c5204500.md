**Remark 1.5.** Based on Corollary 1.2, we deduce that when Algorithm 1 utilizes a constant step-size of \(\alpha^t = 1/\sqrt{t}\), its convergence rate can achieve the optimal \(\mathcal{O}(1/\sqrt{t})\) speed, which is a benchmark for this class of decentralized subgradient algorithms, as noted in [31,33,45]. Consequently, the associated computational complexity of Algorithm 1 aligns well with existing complexity findings reported in [22,28,31,33,34]. Additionally, it is noteworthy that Algorithm 1 leverages a gossip-based communication protocol, making it a suitable choice for computing nodes with constrained communication capabilities.

# 1.4.3.2 Runtime complexity

Moving forward, we derive the runtime complexity of Algorithm 1. Here, we establish the total runtime complexity as the multiplication of the computational complexity and the duration of each iteration, as referenced in [46]. Assuming that a single local variable calculation necessitates 1 unit time step for execution, we shall now present the comprehensive total runtime complexity of Algorithm 1 in the following corollary.

**Corollary 1.3.** Assuming that the prerequisites stated in Theorem 1.1 are satisfied, we can infer from Corollary 1.2 that, in order to achieve an expectation bound of \(\mathbb{E}[J^K - J^*] \le \epsilon\), the total runtime complexity of Algorithm 1 has a worst-case value of \(\mathcal{O}(n \exp(1/\epsilon))\) units and a best-case value of \(\mathcal{O}(\exp(1/\epsilon))\) units. Here, \(n\) represents the number of nodes involved in the algorithm.

**Proof.** Drawing from the details presented in Section 1.3.1, the gossip-based communication protocol necessitates the random selection of a single directed edge \((i_t, j_t)\) for communication during each iteration \(t\). As a result, in Algorithm 1 (Steps 1 and 3, outlined in Section 1.3.2), only the dual-associated variables \((v_i^t, u_i^t\) for \(i = j^t\) and \(z_i^t, y_i^t, k_i^t\) for \(i \in \{i^t, j^t\})\) of the involved nodes \(i_t\) and \(j_t\) are updated, while the dual-associated variables of other nodes remain static. This leads to a runtime complexity of \(\mathcal{O}(1)\) units for the dual-related components in each iteration \(t\). Additionally, for the primal variable \(x_i^t\) (Step 2, as specified in Section 1.3.2), the runtime complexity ranges from \(\mathcal{O}(n)\) in the worst-case scenario to \(\mathcal{O}(1)\) in the best-case scenario. The best-case situation occurs when \(x_i^t\) does not change due to the stability of the dual-associated variable \(v_i^t\). Utilizing the insights provided in Corollary 1.2 and the definition of total runtime complexity, we can derive the conclusions stated in Corollary 1.3. This proof is completed.

**Remark 1.6.** It is worth noting that in the context of a uniform step-size, the total runtime complexity of Algorithm 1 exhibits a distinct advantage compared to the approach presented in [31]. Specifically, due to the employment of the gossip-based communication protocol, the runtime complexity of Algorithm 1 for updating the dual-related variables is decoupled from the network size, contrasting with the \(\mathcal{O}(n)\) complexity observed in [31] for each iteration. This attribute contributes significantly to the overall superiority of Algorithm 1 in terms of runtime complexity.
