# **Algorithm 2** Decentralized asynchronous algorithm based on the random sleep protocol at each node $i \in \mathcal{V}$.

+   1. **Initialization:** Each node $i$ initializes $x_i^0 \in \mathbb{R}$, $y_i^0 \in \mathbb{R}$, $k_i^0 \in \mathbb{R}^n$, $v_i^0 = y_i^0$, and $u_i^0 = k_i^0$.\n2. for $t = 0, 1, 2, \dots$ do\n3. **Generating the random variable:** Generate a Bernoulli random variable $h_i^t$ independently and identically.\n4. **Consensus on the dual variable:** Update two intermediate state variables $v_i^t, u_i^t$ as follows:

\(\left\{\begin{array}{ l } h_i^t = 1: v_i^t = \sum_{j=1}^n \hat{w}_{ij}^t y_j^t, u_i^t = \sum_{j=1}^n \hat{w}_{ij}^t k_j^t, \\ h_i^t = 0: v_i^t = y_i^t, u_i^t = k_i^t, \end{array}\right. \quad (1.41)\)

where $\hat{w}_{ij}^t$ is the weight from node $j$ to node $i$ at time $t$.

+   5. **Optimization on the primal variable:** Update the local primal variable $x_i^t$ as follows:

\(x_i^{t+1} = \arg\min_{x_i \in \Omega_i} C_i(x_i) - v_i^t(x_i - r_i).\)

+   6. **Optimization on the dual variable:** Update $y_i^t, k_i^t$ according to the following:

\(\left\{\begin{array}{ l } h_i^t = 1: \\ \quad z_i^t = u_i^t - \alpha_i^t 1_n, \\ \quad y_i^{t+1} = v_i^t - \frac{[J_i(v_i^t) - \xi_i^t] z_{i+}^t}{1+||a_i^t||^2} a_i^t, \\ \quad k_i^{t+1} = z_i^t + \frac{[J_i(v_i^t) - \xi_i^t] z_{i+}^t}{1+||a_i^t||^2} e_i, \\ h_i^t = 0: y_i^{t+1} = y_i^t, k_i^{t+1} = k_i^t, \end{array}\right. \quad (1.42)\)

where $\alpha_i^t$ is a step-size and the vector $a_i^t \in \partial J_i(v_i^t)$.

+   7. **end for**

and $\hat{w}_{ii}^t = 1 - \sum_{j \in \mathcal{N}_i^{\text{in}}, j \neq i} \hat{w}_{ij}^t > \rho, \forall i \in \mathcal{V}$, where $0 < \rho < 1$.
