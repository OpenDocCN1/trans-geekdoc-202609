## 4.2 Problem description and algorithm construction

In this section, we initially focus on addressing the stated decentralized optimization challenge. Following that, we present the pertinent approach and devise an innovative event-triggered system. Ultimately, we introduce a new decentralized optimization algorithm.

### 4.2.1 Problem description

In this chapter, we tackle the following optimization problem:

\(\min_{x \in \mathbb{R}^d} f(x) = \frac{1}{N} \sum_{i=1}^N f^i(x), \quad (4.1)\)

where x ∈ R^d serves as the optimization estimator, f^i(x) represents the local cost function of each agent.

Our aim is to address problem (4.1) within an undirected network setting. The network is depicted by G = {V, E, W}, in which V = {1, 2, ..., N} signifies the entities within the network, E ⊆ V x V signifies the connections between these entities, and W = [w^ij] ∈ R^(N x N) signifies the network’s adjacency matrix. A positive value of w^ij indicates a connection between entities i and j, whereas a zero value indicates no such connection. Furthermore, the notation N^i = {j | w^ij > 0} is used to represent the adjacent entities to entity i.

**Assumption 4.1.** The function f(x) exhibits μ-strongly convexity, while the individual cost function for each agent, denoted as f^i(x), possesses gradients that are L-Lipschitz continuous. This implies that for any $x$ and $y$, the following conditions hold: (i) $f(y) \ge f(x) + \nabla f(x)^{\text{T}}(y - x) + \frac{\mu}{2} \|y - x\|^2$; (ii) $\|\nabla f^i(x) - \nabla f^i(y)\| \le L \|x - y\|$ for any $x, y \in \mathbb{R}^d$.

**Assumption 4.2.** (i) The underlying network $\mathcal{G}$ is undirected and connected; (ii) The non-negative weight matrix, denoted as $W = [w^{ij}] \in \mathbb{R}^{N \times N}$, is doubly stochastic, meaning it satisfies the conditions $W1_N = 1_N$ and $1_N^{\text{T}}W = 1_N^{\text{T}}$.

**Assumption 4.3.** [14] For every agent $i$ belonging to the set $\mathcal{V}$, there are constants $p > 0, U_1 > 0$, and a positive random variable $L^i(\varsigma^i)$ that satisfy the condition that (i) $\mathbb{E}[L^i(\varsigma^i)^p] < \infty$ and $L_0 = \max_{1 \le i \le N} \{L^i(\varsigma^i)\}$; (ii) $\mathbb{E}[\|\nabla f^i(x, \varsigma^i) - \nabla f^i(x)\|^p] \le U_1^{p/2}$; (iii) $\|\nabla g^i(x, \varsigma^i) - \nabla g^i(y, \varsigma^i)\| \le L^i(\varsigma^i) \|x - y\|, \forall x, y \in \mathbb{R}^d$.

**Remark 4.1.** Assumptions 4.1 and 4.2 constitute typical prerequisites and are effortlessly fulfilled in decentralized optimization challenges. Given Assumption 4.3, it suffices to examine ET-DSGT's efficacy specifically when $p = 2$ [17,42]. These three presumptions facilitate the creation of a stochastic decentralized approach for addressing problem (4.1).

### 4.2.2 Related method

In this section, we examine a decentralized method for gradient tracking amidst stochastic noise, as outlined in reference [14]. This method serves as the foundation for developing ET-DSGT. To address problem (4.1), the method incorporates two key updates during every iteration:

\(x_{t+1}^i = \sum_{j=1}^N a^{ij} x_t^j - \alpha_t y_t^i, \qquad (4.2a)\)
\(y_{t+1}^i = \sum_{j=1}^N b^{ij} y_t^j + \nabla g^i(x_{t+1}^i, \varsigma_{t+1}^i) - \nabla g^i(x_t^i, \varsigma_t^i), \qquad (4.2b)\)

where $A = \{a^{ij}\}$ represents a non-negative matrix with stochastic rows, $B = \{b^{ij}\}$ denotes a non-negative matrix with stochastic columns, $\varsigma_t^i$ signifies a random variable associated with the $t$th iteration at agent $i$. The step-size, denoted as $\alpha_t > 0$, is decaying and remains positive. Regarding initialization, $x_0^i$ belongs to $\mathbb{R}^d$ and $y_0^i$ is set as $\nabla g(x_0^i, \varsigma_0^i)$.

The method employs weights that are row-stochastic and column-stochastic, along with a diminishing step-size, operating over a directed network. It demonstrates impressive performance in terms of convergence speed and precision. However, it faces certain restrictions due to the requirement of real-time communication, implying that every agent must accomplish both the computation of estimators and the sharing of data with adjacent agents during each iteration. Consequently, each agent bears significant communication expenses, resulting in elevated consumption and reduced algorithmic efficiency. Given these circumstances, it is imperative to devise an event-triggering system to eliminate the need for real-time communication.

### 4.2.3 Event-triggering mechanism

In this subsection, we present a unique event-based triggering strategy for communication, where the agent transmits its estimators to adjacent nodes only when the specified triggering criteria are met.

To enhance the design of the event-triggering mechanism, we initially establish \(t_k^i\) to signify the kth triggering instant for agent i. The estimators of agent i at the specific triggering moment are denoted as \(x_{t_k^i}^i\) and \(y_{t_k^i}^i\), respectively. Moreover, the starting states for these estimators are set as \(x_{t_0^i}^i = x_0^i\) and \(y_{t_0^i}^i = y_0^i\) across all agents. Subsequently, we introduce the event-triggering mechanism as follows:

\( t_{k+1}^i = \inf\{t|t > t_k^i, \|e_t^{i,x}\|^2 + \|e_t^{i,y}\|^2 > \frac{C}{(t + 1)^2}\}, \quad (4.3) \)

where the threshold is represented by \(C/(t + 1)^2\), where \(C > 0\) serves as a parameter. To quantify the errors, \(e_t^{i,x}\) and \(e_t^{i,y}\) are utilized, and their definitions are provided below:

\( e_t^{i,x} = x_{t_k^i}^i - x_t^i, \quad e_t^{i,y} = y_{t_k^i}^i - y_t^i. \quad (4.4) \)

> **Remark 4.2.** The introduction of the event-triggering mechanism offers an innovative approach to data exchange within multi-agent networks. It is important to mention that agent i initially assesses its estimators prior to and following an iteration. When the disparity attains the threshold stipulated by the event-triggering criteria, agent i proceeds to disseminate its present estimators \(x_{t+1}^i\) and \(y_{t+1}^i\) to adjacent agents. Subsequently, the neighboring agents update the estimators of agent i retained in their local storage with the most recent ones. As a result, methodologies incorporating the event-triggering mechanism circumvent the need for continuous data transmission, in contrast to time-triggered methods [15–17,26].
