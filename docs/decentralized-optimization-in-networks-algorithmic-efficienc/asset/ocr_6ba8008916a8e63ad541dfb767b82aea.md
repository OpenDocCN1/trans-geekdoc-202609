# 5.2.1 Problem descriptions

Consider a directed network \(\mathcal{G} = \{\mathcal{V}, \mathcal{E}\}\) composed of \(n\) nodes, where \(\mathcal{V} = \{1, 2, ..., n\}\) and \(\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}\) represents the connections. Within this graph, node \(j\) can acquire data from the vertices in its adjacent set \(\mathcal{N}_j^{in} = \{i \in \mathcal{V} | (i, j) \in \mathcal{E}\}\). Assume that every node in the directed graph has access only to the data communicated by its incoming neighbors. This data is relayed through a dependable communication link, unaffected by delays, lost packets, or network congestion. Given these conditions, each vertex can use the information obtained from its incoming neighbors via the link to efficiently perform its iterations. Furthermore, each node \(i \in \mathcal{V}\) is associated with a collection of local convex cost functions \(\{f_{i,k}\}_{k=1}^K\), whose precise shapes are not predetermined but are determined as node \(i\) makes decisions at each instance \(k\). Under these circumstances, the objective of the nodes within the graph, at every instance \(k \in \{1, \cdots, K\}\), is to collectively optimize the subsequent minimization problem:

$$\min f_k(x) = \sum_{i=1}^n f_{i,k}(x), \quad \text{s.t. } x \in \Omega, \quad (5.1)$$

where \(\Omega\) is a non-empty, closed, and convex subset of \(\mathbb{R}^m\), and let \(x\) represent a global decision vector belonging to \(\mathbb{R}^m\).

In this study, like previous investigations [12,15,23,28], we utilize regret as a measure to assess the effectiveness of our proposed algorithm. Due to the stochastic nature of the algorithm being examined (introducing randomized noise to obscure the true state of nodes for privacy reasons), we employ the concept of pseudo-individual-regret for node \(j \in \mathcal{V}\) across the timeframe \(K\), as referenced in [12,23,28]:

$$\bar{R}_{j,K} = \mathbb{E}[\sum_{k=1}^K \sum_{i=1}^n f_{i,k}(x_{j,k})] - \mathbb{E}[\sum_{k=1}^K \sum_{i=1}^n f_{i,k}(x^*)], \quad (5.2)$$

where \(x_{j,k}, j \in \{1, \cdots, n\}\) represents the local variable for \(x\) at time instant \(k\). Furthermore, the optimal decision over the time horizon \(K\) is denoted as \(x^*\), which is obtained by \(\arg\min_{x \in \Omega} \sum_{k=1}^K \sum_{i=1}^n f_{i,k}(x)\).

Our primary objective in this context is to devise an efficient decentralized online optimization algorithm that not only ensures sublinear regret with respect to \(K\) as expressed in (5.2), specifically satisfying the condition \(\lim_{K \to \infty} \bar{R}_{j,K} / K = 0\) for all \(j \in \mathcal{V}\), but also fully preserves the privacy of the participating nodes. Furthermore, we operate under a set of presuppositions outlined in [32,47].

**Assumption 5.1.** a) \(\mathcal{G}\) remains constant and possesses a robust connectivity; b) The matrix \(A\), belonging to \(\mathbb{R}^{n \times n}\), is row-stochastic, satisfying the condition that the sum of its elements in each row equals 1, that is, \(\sum_{j=1}^n A_{ij} = 1\) for every \(i\) in the set \(\mathcal{V}\).

**Assumption 5.2.** a) The maximum possible diameter of \(\Omega\) is bounded above by a positive number \(M\); b) The subgradient \(g_{i,k}(x)\) possesses \(L\)-Lipschitz continuity, where \(L\) is a positive constant. This implies that the norm of \(g_{i,k}(x)\) is always less than or equal to \(L\), regardless of the values of \(k\) (as long as it is greater than or equal to 1), \(i\) (belonging to the set \(\mathcal{V}\)), and \(x\) (within the domain \(\Omega\)).
