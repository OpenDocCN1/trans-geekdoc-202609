By incorporating (1.22) into (1.21), it yields that

\(\|p_i^t - v\|^2 \leq \|o_i^t - v\|^2 - \frac{\|[f_i(h_i^t)]_+\|^2}{\|\xi_i^t\|^2} - \frac{2}{t\eta_i} b^T(\phi_i - v)
+ \frac{\alpha_3}{t^{3/2-\epsilon}} \|\phi_i - v\|^2 + \frac{\alpha_3}{t^{3/2-\epsilon}} \|b\|^2
+ \frac{1}{4\nu} \|o_i^t - \phi_i\|^2 + (\alpha_i^t)^2(1+4\nu)\|b\|^2.\) (1.23)

Observing the convexity of \(\|\cdot\|^2\), we note that \(\|\varphi_i^t - v\|^2 = \|\sum_{j=1}^n W_{ij}^t p_j^{t-1} - v\|^2 = \|\sum_{j=1}^n W_{ij}^t(p_j^{t-1} - v)\|^2 \leq \sum_{j=1}^n W_{ij}^t \|p_j^{t-1} - v\|^2\). Now, introducing the notation \(\phi_i = \varphi_i^t = P_{\Xi_0}(\varphi_i^t)\), where \(P_{\Xi_0}(\varphi_i^t)\) represents the projection of \(\varphi_i^t\) onto the convex set \(\Xi\), we can directly obtain

\(\|p_i^t - v\|^2
\leq \sum_{j=1}^n W_{ij}^t \|p_j^{t-1} - v\|^2 - \frac{\|[f_i(h_i^t)]_+\|^2}{\|\xi_i^t\|^2} - \frac{2}{t\eta_i} b^T(\varphi_i^t - v)
+ (\alpha_i^t)^2(1+4\nu)\|b\|^2 + \frac{1}{4\nu} \|\varphi_i^t - \phi_i^t\|^2
+ \frac{\alpha_3}{t^{3/2-\epsilon}} \|\phi_i^t - v\|^2 + \frac{\alpha_3}{t^{3/2-\epsilon}} \|b\|^2.\) (1.24)

Then, for the term \(\|[f_i(h_i^t)]_+\|^2\), it yields that

\(\|[f_i(h_i^t)]_+\|^2
= \|[f_i(h_i^t)]_+ - [f_i(\varphi_i^t)]_+ + [f_i(\varphi_i^t)]_+\|^2
\geq \|[f_i(\varphi_i^t)]_+\|^2 - 2|[f_i(h_i^t)]_+ - [f_i(\varphi_i^t)]_+|\|[f_i(\varphi_i^t)]_+|
\geq \|[f_i(\varphi_i^t)]_+\|^2 - 2D\alpha_i^t \|b\|\|[f_i(\varphi_i^t)]_+|
\geq (1 - \frac{1}{\tau})\|[f_i(\varphi_i^t)]_+\|^2 - \tau D^2(\alpha_i^t)^2\|b\|^2,\) (1.25)

where the second and third inequalities follow from \(|[f_i(h_i^t)]_+ - [f_i(\varphi_i^t)]_+| \leq D|h_i^t - \varphi_i^t|\) and \(2D\alpha_i^t\|b\|\|[f_i(\varphi_i^t)]_+| \leq \tau D^2(\alpha_i^t)^2\|b\|^2 + (1/\tau)\|[f_i(\varphi_i^t)]_+\|^2\), respectively. Here, \(\tau\) represents a tunable parameter with a value greater than 1. Given the fact that \(\|\xi_i^t\| \leq D\) for all \(i \in \mathcal{V}\), we can deduce from (1.24) that

\(\|p_i^t - v\|^2
\leq \sum_{j=1}^n W_{ij}^t \|p_j^{t-1} - v\|^2 - \frac{(\tau - 1)}{\tau D^2}\|[f_i(\varphi_i^t)]_+\|^2
- \frac{2}{t\eta_i} b^T(\varphi_i^t - v) + \frac{\alpha_3}{t^{3/2-\epsilon}} \|\phi_i^t - v\|^2 + \frac{\alpha_3}{t^{3/2-\epsilon}} \|b\|^2\)
