# 2.4.2 Supporting results

To assess the performance of ET-PDA, we monitor the evolution of the following five metrics: (i) Network consensus error: ||θ^{t+1} - Jθ^{t+1}||; (ii) Optimality gap ||Jθ^{t+1} - 1_n ⊗ θ^*||; (iii) State differences: ||θ^{t+1} - θ^t||; (iv) Gradient tracking error: ||z^{t+1} - Jz^{t+1}||; (v) Gradient tracking differences: ||z^{t+1} - z^t||.

As these five metrics gradually converge to zero in a linear fashion, they guarantee that the sequence {θ^t} converges linearly towards the optimal solution of the problem (2.5). Lemmas 2.4–2.8 sequentially demonstrate the bounds on the historical values of these five metrics, and we construct a set of linear inequalities based on these bounds, enabling us to investigate the spectral characteristics of their respective coefficient matrices.

To streamline the entire proof process, we initially determine an upper limit for ||z^t||, and replace ĝ with the reciprocal of μ̌, denoted as 1/μ̌.

# Lemma 2.3. Given the stipulated conditions in Assumptions 2.1 and 2.2, the subsequent inequality remains valid for all positive values of t:

```
||z^t|| ≤ ĝ√n||θ^t - Jθ^t|| + ĝ√n||Jθ^t - 1_n ⊗ θ^*|| + ||z^t - Jz^t||.
```

Proof. The norm of ||z^t|| can be disentangled into the subsequent set of inequalities:

```
||z^t|| = ||z^t - Jz^t + Jz^t|| ≤ ||z^t - Jz^t|| + ||Jz^t||. (2.15)
```

Subsequently, we impose limitations on the second term in (2.15).

```
||Jz^t|| = ||1/n (1_n ⊗ I_n)(1_n^T ⊗ I_n) ∇q(θ^t)||
= || sum_{i=1}^n ∇q_i(θ_i^t) - sum_{i=1}^n ∇q_i(θ^*) ||
≤ ĝ√n||θ^t - 1_n ⊗ θ^*||
≤ ĝ√n||θ^t - Jθ^t|| + ĝ√n||Jθ^t - 1_n ⊗ θ^*||.
```

Based on Lemma 2.2(b), the initial equivalence in the above inequality is derived. Then, we obtain Lemma 2.3.
