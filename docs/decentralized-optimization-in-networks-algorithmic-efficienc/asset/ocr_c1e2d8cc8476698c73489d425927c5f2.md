L-Lipschitz continuous. This implies that for any $x$ and $y$, the following conditions hold: (i) $f(y) \ge f(x) + \nabla f(x)^{\text{T}}(y - x) + \frac{\mu}{2} \|y - x\|^2$; (ii) $\|\nabla f^i(x) - \nabla f^i(y)\| \le L \|x - y\|$ for any $x, y \in \mathbb{R}^d$.

**Assumption 4.2.** (i) The underlying network $\mathcal{G}$ is undirected and connected; (ii) The non-negative weight matrix, denoted as $W = [w^{ij}] \in \mathbb{R}^{N \times N}$, is doubly stochastic, meaning it satisfies the conditions $W1_N = 1$ and $1_N^{\text{T}}W = 1_N^{\text{T}}$.

**Assumption 4.3.** [14] For every agent $i$ belonging to the set $\mathcal{V}$, there are constants $p > 0, U_1 > 0$, and a positive random variable $L^i(\varsigma^i)$ that satisfy the condition that (i) $\mathbb{E}[L^i(\varsigma^i)^p] < \infty$ and $L_0 = \max_{1 \le i \le n} \{L^i(\varsigma^i)\}$; (ii) $\mathbb{E}[\|\nabla f^i(x, \varsigma^i) - \nabla f^i(x)\|^p] \le U_1^{p/2}$; (iii) $\|\nabla g^i(x, \varsigma^i) - \nabla g^i(y, \varsigma^i)\| \le L^i(\varsigma^i) \|x - y\|, \forall x, y \in \mathbb{R}^d$.

**Remark 4.1.** Assumptions 4.1 and 4.2 constitute typical prerequisites and are effortlessly fulfilled in decentralized optimization challenges. Given Assumption 4.3, it suffices to examine ET-DSGT's efficacy specifically when $p = 2$ [17,42]. These three presumptions facilitate the creation of a stochastic decentralized approach for addressing problem (4.1).

# 4.2.2 Related method

In this section, we examine a decentralized method for gradient tracking amidst stochastic noise, as outlined in reference [14]. This method serves as the foundation for developing ET-DSGT. To address problem (4.1), the method incorporates two key updates during every iteration:

```
\(x_{t+1}^i = \sum_{j=1}^n a^{ij} x_t^j - \alpha_t y_t^i, \qquad (4.2a)\)
\(y_{t+1}^i = \sum_{j=1}^n b^{ij} y_t^j + \nabla g^i(x_{t+1}^i, \varsigma_{t+1}^i) - \nabla g^i(x_t^i, \varsigma_t^i), \qquad (4.2b)\)
```

where $A = \{a^{ij}\}$ represents a non-negative matrix with stochastic rows, $B = \{b^{ij}\}$ denotes a non-negative matrix with stochastic columns, $\varsigma_t^i$ signifies a random variable associated with the $t$th iteration at agent $i$. The step-size, denoted as $\alpha_t > 0$, is decaying and remains positive. Regarding initialization, $x_0^i$ belongs to $\mathbb{R}^d$ and $y_0^i$ is set as $\nabla g(x_0^i, \varsigma_0^i)$.

The method employs weights that are row-stochastic and column-stochastic, along with a diminishing step-size, operating over a directed network. It demonstrates impressive performance in terms of convergence speed and precision. However, it faces certain restrictions due to the requirement of real-time communication, implying that every agent must accomplish both the computation of estimators and the sharing of data with adjacent agents during each iteration. Consequently, each agent bears significant communication expenses, resulting in elevated consumption and reduced algorithmic efficiency. Given these circumstances, it is imperative to devise an event-triggering system to eliminate the need for real-time communication.
