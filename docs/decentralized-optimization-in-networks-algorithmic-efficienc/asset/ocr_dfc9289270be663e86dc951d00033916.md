**Corollary 1.1.** If the conditions stated in Theorem 1.1 are met, then it follows that \(\mathbb{E}[b^T(\hat{\phi}^t - p^*)] \le \Gamma^t/\gamma^t\), where \(\Gamma^t = \exp(\sum_{s=1}^t q^s)(\mathbb{E}[\sum_{i=1}^n \pi_i ||p_i^1 - p^*||^2] + \mathbb{E}[\sum_{s=1}^t c^s]) < \infty\).

**Proof.** By taking the total expectation of (1.33), we arrive at the conclusion that

\(\sum_{i=1}^n \pi_i \mathbb{E}_{t-1} \left[ ||p_i^t - p^*||^2 \right] - (1 + q^{t-1}) \sum_{i=1}^n \pi_i ||p_i^{t-1} - p^*||^2\)
\(\le - \frac{2}{t} \mathbb{E}_{t-1} \left[ b^T (\bar{\phi}^t - p^*) \right] + c^t, \quad (1.35)\)

where \(q^{t-1} = \frac{\alpha_2}{t^{3/2-\epsilon}}\) and \(c^t = (\frac{\alpha_3}{t^{3/2-\epsilon}} + \frac{\alpha_2}{t^2}(1+4\nu+\tau))||b||^2\). Denote \(\psi^{t+1,s} = (1+q^t)\psi^{t,s}\) and \(\psi^{s,s} = 1\) for any \(t \ge s \ge 1\). By recursively applying the expectation from (1.35), we obtain the following result:

\(\mathbb{E} \left[ \sum_{i=1}^n \pi_i ||p_i^t - p^*||^2 \right] - \psi^{t,1} \mathbb{E} \left[ \sum_{i=1}^n \pi_i ||p_i^1 - p^*||^2 \right]\)
\(\le \sum_{s=1}^t \psi^{t,s} ( - \frac{2}{s} \mathbb{E} \left[ b^T (\bar{\phi}^s - p^*) \right] + \mathbb{E}[c^s] ). \quad (1.36)\)

Given that \(\psi^{t,s} \ge 1\) and \(\psi^{t,s} \le \psi^{t,1}\) for any \(t \ge s \ge 1\), we can derive the following conclusion from (1.36):

\(\mathbb{E} \left[ \sum_{s=1}^t \frac{b^T (\bar{\phi}^s - p^*)}{s} \right]\)
\(\le \psi^{t,1} ( \mathbb{E} \left[ \sum_{i=1}^n \pi_i ||p_i^1 - p^*||^2 \right] + \mathbb{E} \left[ \sum_{s=1}^t c^s \right] ). \quad (1.37)\)

Dividing by \(\gamma^t\), we obtain

\(\mathbb{E} \left[ b^T (\hat{\phi}^t - p^*) \right]\)
\(\le \frac{\psi^{t,1}}{\gamma^t} ( \mathbb{E} \left[ \sum_{i=1}^n \pi_i ||p_i^1 - p^*||^2 \right] + \mathbb{E} \left[ \sum_{s=1}^t c^s \right] ). \quad (1.38)\)

Utilizing the fact that \(\exp(y) \ge 1 + y\) for all \(y \ge 0\), we have \(\psi^{t,0} \le \exp(\sum_{s=1}^t q^s)\). Combining this with (1.38), we arrive at the conclusions stated in Corollary 1.1. Specifically, \(\Gamma^t\) is defined as \(\exp(\sum_{s=1}^t q^s)(\mathbb{E}[\sum_{i=1}^n \pi_i ||p_i^1 - p^*||^2] + \mathbb{E}[\sum_{s=1}^t c^s]) < \infty\), which is guaranteed by Lemma 1.2. This completes the proof.
