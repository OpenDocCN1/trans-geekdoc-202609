Furthermore, we proceed to obtain

```
\mathbb{E}[||\vartheta_2||] \le \mathbb{E}[||\sum_{l=1}^{k-1} \sum_{j=1}^n ((A^{k-l})_{ij} - \pi_j) \frac{g_{j,l}}{y_{j,l}}||] + 2\theta L \\
+ || \frac{g_{i,t}}{y_{i,t}} || + \sum_{i=1}^n \pi_i || \frac{g_{i,k}}{y_{i,k}} || \\
\le n\theta L C \sum_{l=1}^{k-1} \varpi^{k-l} + 2\theta L .
```

Since \(\gamma_{j,k}\) originates from a Laplace distribution parameterized by \(b_k\), it follows that \(\mathbb{E}[|\gamma_{j,k}|^2]\) is less than or equal to \(\mathbb{E}[|\gamma_{j,k}|^2] = 2mb_{\max}^2\). Furthermore, we proceed to deduce

```
\mathbb{E}[||\vartheta_3||] = \mathbb{E}[||\sum_{l=1}^k \sum_{j=1}^n ((A^{k-l+1})_{ij} - \pi_j)\gamma_{j,l}||] \\
\le n\sqrt{2m}b_{\max} C \sum_{l=0}^k \varpi^{k-l+1} .
```

Finally, it comes to

```
\mathbb{E}[||z_{i,k} - \bar{z}_k||] \\
\le \mathbb{E}[||\vartheta_1||] + \mathbb{E}[||\vartheta_2||] + \mathbb{E}[||\vartheta_3||] \\
\le \frac{n C(\theta L + \sqrt{2m}b_{\max})}{1 - \varpi} + C \sum_{i=1}^n ||z_{i,1}|| + 2\theta L \quad (5.15)
```

and the proof is completed.
