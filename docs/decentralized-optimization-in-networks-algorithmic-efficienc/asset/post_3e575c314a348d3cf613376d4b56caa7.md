## 8.6 Conclusion

This chapter presents a novel privacy-preserving decentralized random sleep algorithm for solving the EDP over an unbalanced directed network. The proposed algorithm incorporates conditional noises into state exchanges, effectively protecting sensitive information. Additionally, the algorithm integrates a random sleep strategy into the decentralized inexact gradient method with gradient rescaling, enhancing computational efficiency on an unbalanced directed network. Theoretical analysis demonstrates that the proposed algorithm can achieve the optimal solution of the EDP. Furthermore, the error bound and privacy properties of the algorithm have been theoretically investigated. Several simulation examples have been conducted to verify the algorithm's performance. Future research may explore the incorporation of asynchronous broadcast-based communication mechanisms into the algorithm. Additionally, investigating more efficient computational intelligence algorithms to solve the EDP in smart grids presents a promising avenue for future research.

## Appendix 8.A Proof of Lemma 8.4

Consider any \(i \in \mathcal{V}\). If \(h_i^t = 1\), Algorithm 1 implies that

\[
y_i^{t+1} = \sum_{j=1}^m b_{ij} y_j^t + \varepsilon_i^t - \gamma_i^t \frac{p_i^t - d_i}{[z_i^t]_i}.
\]

Similarly, if \(h_i^t = 0\) for \(i \in \mathcal{V}\), it follows that

\[
y_i^{t+1} = \sum_{j=1}^m b_{ij} y_j^t + \varepsilon_i^t.
\] (8.A.2)

By applying (8.A.1) and (8.A.2), and taking the conditional expectation with respect to \(\mathcal{F}^t\), we obtain for any \(i \in \mathcal{V}\), \(i \in \mathcal{V}\),

\[
\mathbb{E} [y_i^{t+1} | \mathcal{F}^t] = \sum_{j=1}^m b_{ij} y_j^t + \varepsilon_i^t - \eta_i \gamma_i^t \frac{p_i^t - d_i}{[z_i^t]_i},
\] (8.A.3)

where \(\eta_i\) represents the probability that \(h_i^t = 1\). Based on the definitions of \(\varepsilon_i^t\) and \(\gamma_i^t\), it follows that \(\lim_{t \to \infty} \varepsilon_i^t = 0\) and \(\lim_{t \to \infty} \gamma_i^t = 0\) for every \(i \in \mathcal{V}\). Considering the facts that \(0 \le \eta_i \le 1\), \(|p_i^t - d_i| \le C\), and \(\kappa^{-1} \le [z_i^t]_i \le 1\) for all \(i \in \mathcal{V}\), we conclude that

\[
\lim_{t \to \infty} |\varepsilon_i^t - \eta_i \gamma_i^t \frac{p_i^t - d_i}{[z_i^t]_i}| \le \lim_{t \to \infty} (\varepsilon_i^t + \eta_i \kappa C \gamma_i^t) = 0.
\] (8.A.4)

Thus by applying Lemma 4 in [47], we obtain that \(\lim_{t \to \infty} |y_i^t - \bar{y}^t| = 0\) almost surely for all \(i \in \mathcal{V}\), completing the proof.

## Appendix 8.B Proof of Lemma 8.5

For any \(i \in \mathcal{V}\), if \(h_i^t = 1\), it follows for any \(v \in \mathbb{R}\) that

\[
|y_i^{t+1} - v|^2
= |v_i^t + \varepsilon_i^t - v|^2 + |\gamma_i^t \frac{\nabla Q_i(v_i^t)}{[z_i^t]_i}|^2 + 2(v_i^t + \varepsilon_i^t - v)\gamma_i^t \frac{\nabla Q_i(v_i^t)}{[z_i^t]_i}
\le \sum_{j=1}^m b_{ij} |y_j - v|^2 + 2\varepsilon_i^t (v_i^t - v) + |\varepsilon_i^t|^2 + |\gamma_i^t \frac{\nabla Q_i(v_i^t)}{[z_i^t]_i}|^2
+ 2\gamma_i^t (v_i^t - v) \frac{\nabla Q_i(v_i^t)}{[z_i^t]_i} + 2\varepsilon_i^t \gamma_i^t \frac{\nabla Q_i(v_i^t)}{[z_i^t]_i},
\] (8.B.1)

where the inequality arises from the row-stochasticity of \(B\) and the application of Jensen's inequality for the convex function \(|\cdot|^2\). We can further infer that for all \(t \ge \hat{t}\),

\[
2\gamma_i^t \nabla Q_i(v_i^t)(v_i^t - v)
= 2(\gamma_i^t - \frac{1}{t \eta_i})\nabla Q_i(v_i^t)(v_i^t - v) + \frac{2}{t \eta_i} \nabla Q_i(v_i^t)(v_i^t - v)
\le \phi^t |\nabla Q_i(v_i^t)|^2 + \phi^t |v_i^t - v|^2 + \frac{2}{t\eta_i}(Q_i(v_i^t) - Q_i(v))
\le \phi^t |\nabla Q_i(v_i^t)|^2 + \phi^t \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2C}{t\eta_i} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2
+ \frac{2}{t\eta_i} (Q_i(\bar{y}^t) - Q_i(v)),
\] (8.B.2)

where the first and second inequalities stem from the convexity of \(-Q_i\) and the bound \(|\nabla Q_i| \le C\) for all \(i \in \mathcal{V}\), respectively. Using (8.B.1), (8.B.2), along with the conditions \(|\nabla Q_i| \le C\) and \(\kappa^{-1} \le [\xi_i^t]_i \le 1\) for all \(i \in \mathcal{V}\), we derive for all \(t \ge \hat{t}\),

\[
|y_i^{t+1} - v|^2
\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2}{t\eta_i[z_i^t]_i} (Q_i(\bar{y}^t) - Q_i(v))
+ C^2 \kappa^2 |\gamma_i^t|^2 + 2\varepsilon_i^t \gamma_i^t C \kappa + 2|\varepsilon_i^t| |v_i^t - v| + |\varepsilon_i^t|^2
+ \phi^t \kappa C^2 + \frac{2C\kappa}{t\eta_i} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2.
\] (8.B.3)

Similarly, if \(h_i^t = 0\) for \(i \in \mathcal{V}\), it follows that

\[
|y_i^{t+1} - v|^2
\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + |\varepsilon_i^t|^2 + 2|\varepsilon_i^t| |v_i^t - v|.
\] (8.B.4)

Considering both cases (8.B.3) and (8.B.4), and taking the conditional expectation with respect to \(\mathcal{F}^t\), we can conclude that for all \(i \in \mathcal{V}\) and for all \(t \ge \hat{t}\),

\[
\mathbb{E} \left[ |y_i^{t+1} - v|^2 | \mathcal{F}^t \right]
\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2}{t[z_i^t]_i} (Q_i(\bar{y}^t) - Q_i(v))
+ C^2 \kappa^2 \eta_i |\gamma_i^t|^2 + 2C\kappa \eta_i \varepsilon_i^t \gamma_i^t + 2|\varepsilon_i^t| |v_i^t - v| + |\varepsilon_i^t|^2
+ \phi^t \kappa^2 \eta_i + \frac{2C\kappa}{t} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2.
\] (8.B.5)

By multiplying both sides by \(c_i\) and summing over \(i = 1\) to \(m\), we obtain that for all \(t \ge \hat{t}\),

\[
\sum_{i=1}^m c_i \mathbb{E} \left[ |y_i^{t+1} - v|^2 | \mathcal{F}^t \right]
\le (1+\phi^t\kappa)\sum_{i=1}^m c_i|y_i^t-v|^2+\frac{2}{t}\sum_{i=1}^m\frac{c_i}{|z_i^t|_i}(Q_i(\bar{y}^t)-Q_i(v))
+C^2\kappa^2\hat{\eta}\sum_{i=1}^m|\gamma_i^t|^2+2C\kappa\hat{\eta}\sum_{i=1}^m\varepsilon_i^t\gamma_i^t+2\sum_{i=1}^m|\varepsilon_i^t||v_i^t-v|
+\sum_{i=1}^m|\varepsilon_i^t|^2+\phi^t\kappa C^2\hat{\eta}+\frac{2C\kappa}{t}\sum_{i=1}^m|y_i^t-\bar{y}|^2.
\]

Utilizing the properties \(c^T B = c^T\) and \(0 < c_i < 1\) for \(i \in \mathcal{V}\), we also derive that for all \(t \ge \hat{t}\),

\[
\frac{2}{t}\sum_{i=1}^m\frac{c_i}{|z_i^t|_i}(Q_i(\bar{y}^t)-Q_i(v))
\le\frac{2}{t}\sum_{i=1}^m(Q_i(\bar{y}^t)-Q_i(v))+\frac{2}{t}\sum_{i=1}^m|\frac{[z_i^t]_i-c_i}{[z_i^t]_i}||Q_i(\bar{y}^t)-Q_i(v)|
\le\frac{2}{t}\sum_{i=1}^m(Q_i(\bar{y}^t)-Q_i(v))+\frac{2}{t}m\kappa C W(\lambda^t)|\bar{y}^t-v|.
\]

Thus combining (8.B.6) and (8.B.7) allows us to conclude Lemma 8.5. The proof is complete. \(\square\)
