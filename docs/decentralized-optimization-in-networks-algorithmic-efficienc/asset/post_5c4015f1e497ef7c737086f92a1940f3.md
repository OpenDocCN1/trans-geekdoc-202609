
## 7.2.1 Problem formulation

This work aims to address the following decentralized constrained optimization problem:

```
\min_{x \in \Omega} f(x) = \sum_{i=1}^v f_i(x),\qquad(7.1)
```

where \(x \in \mathbb{R}^d\) is the global decision variable and \(\Omega \subseteq \mathbb{R}^d\) is a non-empty, closed, and convex set. Each node \(i \in \{1, 2, ..., v\}\) has its local cost function \(f_i : \mathbb{R}^d \to \mathbb{R}\), and no node has access to the global cost function \(f\). Additionally, we make the following assumptions.

**Assumption 7.1.**
- (a) The optimization problem (7.1) has at least one finite solution \(x^*\);
- (b) Each function \(f_i(x)\) is convex and \(L\)-Lipschitz continuous over the set \(\Omega\) for any \(i \in \{1, 2, ..., v\}\).

Assumption 7.1(a) ensures the existence of a solution \(x^*\) that minimizes problem (7.1). Assumption 7.1(b) implies that \(||g_i|| \le L\) for any \(x \in \Omega\) and any subgradient \(g_i \in \partial f_i(x)\), for all \(i \in \{1, 2, ..., v\}\).

## 7.2.2 Communication network

Consider a time-varying directed network \(\mathcal{G}(k) = \mathcal{V}, \mathcal{E}(k)\), comprising the set of nodes \(\mathcal{V} = \{1, 2, ..., v\}\) and the set of edges \(\mathcal{E}(k) \subseteq \mathcal{V} \times \mathcal{V}\) for \(k \ge 1\). If node \(j\) can directly send messages to node \(i\) at time \(k\), then \((j, i) \in \mathcal{E}(k)\), where node \(j\) is an in-neighbor of node \(i\), and node \(i\) is an out-neighbor of node \(j\). The in-neighbors of node \(i\) at time \(k\) are denoted by \(\mathcal{N}_i^{\text{in}}(k) = \{j \in \mathcal{V} | (j, i) \in \mathcal{E}(k)\}\), and its out-neighbors are denoted by \(\mathcal{N}_i^{\text{out}}(k)\). The network is unbalanced if a node's in-degree differs from its out-degree. The weighted matrix of the network \(\mathcal{G}(k)\) is represented by \(P(k) = [P_{ij}(k)] \in \mathbb{R}^{v \times v}\), where \(P_{ij}(k) > 0\) if \((j, i) \in \mathcal{E}(k)\), and \(P_{ij}(k) = 0\) otherwise. Additionally, we make the following assumptions regarding the network.

**Assumption 7.2.**
- (a) There exists a positive integer \(B\) such that the joint network \(\mathcal{G}(k) \cup \mathcal{G}(k+1) \cup \cdots \cup \mathcal{G}(k+B-1)\), \(k \ge 1\), is strongly connected;
- (b) The matrix \(P(k) \in \mathbb{R}^{v \times v}\) is column-stochastic, meaning \(\sum_{i=1}^v P_{ij}(k) = 1\) for all \(j \in \mathcal{V}, k \ge 1\).

**Remark 7.1.** Assumption 7.2(a) ensures that all nodes can obtain information from their in-neighbors or indirectly from any other nodes within any period of \(B\). This is a more general assumption than requiring strong connectivity of each directed network \(\mathcal{G}(k)\), \(\forall k \ge 1\). Assumption 7.2(b) specifies that the weighted matrix \(P(k)\) is column-stochastic, which means the sum of each column of \(P(k)\) is 1. This is a common assumption in the literature [11,27,28,36] on time-varying directed networks and is crucial for the convergence analysis of the designed algorithm. Furthermore, constructing \(P(k)\) to meet Assumption 7.2(b) is straightforward if each node knows its out-degree. For instance, \(P_{ij}(k) = \frac{1}{d_j^{\text{out}}(k)+1}\) if \(j \in \mathcal{N}_i^{\text{in}}(k)\), and \(P_{ij}(k) = 0\) otherwise, where \(d_j^{\text{out}}(k) = |\mathcal{N}_j^{\text{out}}(k)|\) is the out-degree of node \(j\) at time \(k\). Here, \(|\cdot|\) denotes the cardinality of a set.

## 7.2.3 Motivating Examples

Problem (7.1) is a general decentralized constrained optimization problem where network nodes aim to collectively minimize the sum of local cost functions subject to a shared constraint set. Such problems are prevalent in many engineering applications, such as energy-based source localization in wireless sensor networks [6,7] and information control [8,9]. They also appear in machine learning applications like distributed regression [46,48,49]. Below, are two practical applications fitting problem (7.1).

**Example 7.1.** A prominent example of problem (7.1) is the decentralized constrained sparse logistic regression problem [48,49], which has significant applications in machine learning. Building on [48,49], we introduce a general constraint \(\Omega\) to prevent extreme deviations during optimization. The decentralized constrained sparse logistic regression problem is formulated as:

```
$$\min_{x \in \Omega} \sum_{i=1}^v \sum_{j=1}^{n_i} \ln[1 + \exp(-b_{ij} e_{ij}^T x)] + \rho_1 ||x||_1 + \rho_2 ||x||^2,$$
```

where each node \(i\) is assigned \(n_i\) pairs of samples \(\{b_{ij}, e_{ij}\}_{j=1,2,...,n_i}\) to train, where \(b_{ij} \in \{-1, 1\}\) represents the label of the \(i, j\)th sample and \(e_{ij} \in \mathbb{R}^d\) denotes the feature vector. The positive constants \(\rho_1, \rho_2\) are regularization coefficients for the \(l_1\)-norm and \(l_2\)-norm, respectively, and \(\Omega\) is a closed, convex set. This problem can be rewritten in the form of problem (7.1) by defining

```
$$f_i = \sum_{j=1}^{n_i} \ln[1 + \exp(-b_{ij} e_{ij}^T x)] + \frac{\rho_1}{v} ||x||_1 + \frac{\rho_2}{v} ||x||^2,$$
```

which satisfies Assumption 7.1. The goal is to use the training set to find the optimal solution \(x^*\), which can then be used for regression. During decentralized regression, each server only needs to send information to its neighbors without feedback, making the network directional. Furthermore, long-term server operations can cause link or partial server failures, resulting in a time-varying communication network. Therefore problem (7.1) models the decentralized constrained sparse logistic regression problem well. Section 7.6.1 will demonstrate our algorithm’s performance on this decentralized regression problem using a real-world dataset.

**Example 7.2.** Another common example of problem (7.1) is the decentralized energy-based source localization problem [46,52]. Determining the location of an acoustic source is crucial in military and environmental fields. Inspired by [46,52], consider an unknown location \(\breve{x} \in \Omega\) of a fixed acoustic source. Each sensor in the network aims to estimate this location through local communication and computation. Each sensor \(i \in \mathcal{V}\) is randomly located at \(c_i\), known only to itself, and takes \(n_i\) measurements. The isotropic energy propagation model \(m_{ij} = a / ||\breve{x} - c_i||^\nu + b_{ij}\) is used for the \(j\)th measurement at sensor \(i\), where \(\nu \ge 1\) is an attenuation factor, \(a > 0\) is a constant, and \(b_{ij}\) is a zero-mean Gaussian noise with bounded variance. The maximum-likelihood estimator for the source's location is found by solving:

\(\min_{x \in \Omega} \sum_{i=1}^v (\frac{1}{n_i} \sum_{j=1}^{n_i} (m_{ij} - \frac{a}{||x - c_i||^\nu})^2),\)

with the local objective function $f_i(x)$ being

\(f_i(x) = \frac{1}{n_i} \sum_{j=1}^{n_i} (m_{ij} - \frac{a}{||x - c_i||^\nu})^2,\)

which satisfies Assumption 7.1. Communication in wireless sensor networks is typically directional, and sensor networks face link failures over long periods, leading to varying communication networks. Hence, problem (7.1) effectively models the decentralized energy-based source localization problem in wireless sensor networks. Section 7.6.2 will demonstrate our algorithm's performance in estimating an acoustic source's location.

## 7.3 Algorithm construction

In this section, we start by revisiting some decentralized dual averaging algorithms from previous research [17, 27], and subsequently introduce our own algorithm.

### 7.3.1 Overview of decentralized dual averaging techniques

Our algorithm builds upon the dual averaging approach initially introduced by [17] for undirected networks. We define the projection operator as follows:

\(\Pi_\Omega^\varphi(h, \gamma) = \arg\min_{x \in \Omega} \{ \langle h, x \rangle + \frac{\varphi(x)}{\gamma} \}, \quad (7.2)\)

where $\gamma > 0$ and $\varphi(x)$ is assumed to be a 1-strongly convex function, satisfying $\varphi(0) = 0$ and $\varphi(x) > 0$. This function $\varphi(x)$ involves a norm $\|\cdot\|$ that primarily influences the computation of the projection operator $\Pi_\Omega^\varphi(h, \gamma)$ (refer to [17, 40, 44] for more details). The update procedure for the standard decentralized dual averaging algorithm [17] for each node $i \in \mathcal{V}$ is given by:

\(\begin{cases} h_i(k+1) = \sum_{j=1}^v W_{ij} h_j(k) + g_i(k), \\ x_i(k+1) = \Pi_\Omega^\varphi(h_i(k+1), \gamma(k)), \end{cases}\)

where $h_i(k)$ is a state variable, $x_i(k)$ is a primal variable, $g_i(k) \in \partial f_i(x_i(k))$, $\gamma(k) > 0$ is a decreasing step-size, and $W = [W_{ij} \in \mathbb{R}^{d \times d}$ is a doubly stochastic matrix, ensuring $\sum_{i=1}^v W_{ij} = \sum_{i=1}^v W_{ji} = 1$, for all $i, j \in \mathcal{V}$.
