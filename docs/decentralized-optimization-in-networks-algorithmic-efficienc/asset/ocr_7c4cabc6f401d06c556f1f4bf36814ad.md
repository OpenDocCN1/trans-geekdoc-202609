where $\mathcal{F}^k$ represents the historical data of the dynamical system produced by the set $\{\chi_t^i\}_{t\le k-1}^{i=[1,\dots,n^i]}$, where $t$ denotes the iteration count. By applying the standard conditional variance decomposition, we obtain $\mathbb{E}[\|\mathbf{a}_k^i - \mathbb{E}[\mathbf{a}_k^i | \mathcal{F}^k]\|^2 | \mathcal{F}^k] \le \mathbb{E}[\|\mathbf{a}_k^i\|^2 | \mathcal{F}^k]$. ```


In conclusion, we accumulate the inequality denoted by (3.33) across all values of \(i\) and compute the overall expected value to finalize the demonstration.
