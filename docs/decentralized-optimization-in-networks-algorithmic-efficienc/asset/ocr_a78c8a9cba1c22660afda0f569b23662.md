Furthermore, at each iteration $t$ within the timeframe $\{1, \dots, T\}$, node $i$ maintains three distinct local variables: a primal variable $x_t^i$ residing within the contracted set $(1-\xi)\Omega$, an auxiliary variable $v_t^i$ in the real number space $\mathbb{R}$, and a dual variable $q_t^i$ belonging to the $m$-dimensional real space $\mathbb{R}^m$. These variables commence with predefined initial values, where $q_1^i$ is initialized in $\mathbb{R}^m$, $x_1^i$ is set to the projection of $q_1^i$ onto $(1-\xi)\Omega$ with a step-size $\alpha_0$ under a certain mapping $\phi$, and $v_1^i$ is assigned a value of 1. To safeguard privacy during the $t$th iteration, node $i$ initially generates a random noise vector $\vartheta_t^i$ that follows a Laplace distribution. This noise vector is then utilized to perturb the dual variable $q_t^i$, effectively masking its true value, i.e.,

\(\tilde{q}_t^i = q_t^i + \vartheta_t^i, \tag{6.8}\)

where $\vartheta_t^i \sim \mathcal{L}(0, b_t)$ with the parameter $b_t$. Subsequently, node $i$ disseminates $c_t^{ji} v_t^i$ and $r_t^{ji} \tilde{q}_t^i$ to its outgoing neighbors $j$ within the set $\mathcal{N}_{t,\text{out}}^i$. Immediately thereafter, it computes the subgradient estimator $\hat{g}_t^i(x_t^i)$. Upon receiving $c_t^{ij} v_t^j$ and $r_t^{ij} q_t^j$ from its incoming neighbors $j$ in $\mathcal{N}_{t,\text{in}}^i$, node $i$ initiates by updating the auxiliary variable $v_{t+1}^i$. It then amalgamates the received information and proceeds to update its dual variable $q_{t+1}^i$ by incorporating the rescaled subgradient estimator $\hat{g}_t^i(x_t^i)/v_{t+1}^i$ in the following manner:

\(v_{t+1}^i = \sum_{j=1}^n c_t^{ij} v_t^j, \tag{6.9}\)

\(q_{t+1}^i = \sum_{j=1}^n r_t^{ij} q_t^j + \frac{\hat{g}_t^i(x_t^i)}{v_{t+1}^i}, \tag{6.10}\)

where $r_t^{ij} = (c_t^{ij} v_t^j)/v_{t+1}^i$ denotes the entry at the $i$th row and $j$th column of $R_t = [r_t^{ij}] \in \mathbb{R}^{n \times n}$. Given Assumption 6.1(b), one can straightforwardly deduce that $R_t$ constitutes a row-stochastic matrix by recalling Eq. (6.9) and the construction of $r_t^{ij}$. In this context, the purpose of $v_{t+1}^i$ in (6.9) is to recalibrate the zeroth-order oracle $\hat{g}_t^i(x_t^i)$ featured in (6.12), thereby mitigating the imbalances stemming from the dynamic, directed network topology. The summation $\sum_{j=1}^n r_t^{ij} \tilde{q}_t^j$ within (6.12) serves to ensure consistency across iterations. Leveraging the projection operator $\Pi_{(1-\xi)\Omega}^\phi(\cdot)$, the updated primal variable $x_{t+1}^i$ can be derived, as stated here

\(x_{t+1}^i = \Pi_{(1-\xi)\Omega}^\phi(q_{t+1}^i, \alpha_t), \tag{6.11}\)

where $\alpha_t$ is specified in the subsequent section and exhibits a non-increasing pattern. Therefore the outlined method, dubbed ZO-DDA, is formally detailed in Algorithm 1 for addressing problem (6.1) at each individual node $i$ within the set $\mathcal{V}$.
