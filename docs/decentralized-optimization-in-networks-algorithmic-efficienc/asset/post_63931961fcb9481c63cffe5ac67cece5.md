
Proof. Recalling from (8.11), one obtains

```
$$\mathbb{E}[\sum_{i=1}^m c_i | y_i^{t+1} - y^* |^2 | \mathcal{F}^t ] + \frac{2}{t}(-Q(\bar{y}^t) + Q(y^*)) \leq (1 + \varphi^t) \sum_{i=1}^m c_i | y_i^t - y^* |^2 + b^t, \tag{8.19}$$
```

where \(b^t\) is given in Theorem 8.1. Denote \(\varphi^t = \phi^t \kappa; \psi^{t,s-1} = (1 + \varphi^t)\psi^{t-1,s-1}\) and \(\psi^{s,s} = 1\) for any \(t \ge s \ge 1\). By iterating (8.19), we have

```
$$\mathbb{E}[\sum_{i=1}^m c_i | y_i^{t+1} - y^* |^2] - \psi^{t,0}\mathbb{E}[\sum_{i=1}^m c_i | y_i^1 - y^* |^2] \leq \sum_{s=1}^t \psi^{t-1,s-1}(\frac{2}{s}\mathbb{E}[(Q(\bar{y}^s) - Q(y^*))] + \mathbb{E}[b^s]). \tag{8.20}$$
```

Since \(\psi^{t,s} \ge 1\) and \(\psi^{t,s} \le \psi^{t,0}\) for any \(t \ge s \ge 0\). It follows from (8.20) that

```
$$\mathbb{E}[\sum_{s=1}^t \frac{-Q(\bar{y}^s) + Q(y^*)}{s}] \leq \psi^{t,0}(\mathbb{E}[\sum_{i=1}^m c_i | y_i^1 - y^* |^2] + \mathbb{E}[\sum_{s=1}^t b^s]), \tag{8.21}$$
```

where the convexity of \(-Q\) is utilized. Dividing by \(\alpha^t\) and leveraging the convexity of \(-Q\), we find

```
$$\mathbb{E}[-Q(\frac{1}{\alpha^t} \sum_{s=1}^t \frac{\bar{y}^s}{s}) + Q(y^*)] \leq \frac{\psi^{t,0}}{\alpha^t}(\mathbb{E}[\sum_{i=1}^m c_i | y_i^1 - y^* |^2] + \mathbb{E}[\sum_{s=1}^t b^s]). \tag{8.22}$$
```

Recalling that \(|\nabla Q_i| \le C\) for all \(i \in \mathcal{V}\), we obtain

```
$$\mathbb{E}[-Q(\hat{y}_i^t) + Q(\frac{1}{\alpha^t} \sum_{s=1}^t \frac{\bar{y}^s}{s})] \leq \frac{C}{\alpha^t}\mathbb{E}[\sum_{s=1}^t \frac{|y_i^s - \bar{y}^s|}{s}]. \tag{8.23}$$
```

Substituting (8.23) into (8.22), we can obtain

```
$$\mathbb{E}[-Q(\hat{y}_i^t) + Q(y^*)] \leq \frac{\psi^{t,0}}{\alpha^t}(\mathbb{E}[\sum_{i=1}^m c_i | y_i^1 - y^* |^2] + \mathbb{E}[\sum_{s=1}^t b^s]) + \frac{C}{\alpha^t} \mathbb{E}[\sum_{s=1}^t \frac{|y_i^s - \bar{y}^s|}{s}], \quad (8.24)$$
```

which follows from \(\psi^{t,0} \le \exp(\sum_{s=1}^t \phi^s \kappa)\) (due to \(\exp(y) \ge 1 + y, \forall y \in \mathbb{R}_{\ge 0}\)). This completes the proof.

### Remark 8.5 (Effects of Conditional Noises)
From the definition of \(b^t\) and Corollary 8.1, we infer that the added conditional noise \(\varepsilon_i^t\) to the state \(y_i^t\) slightly reduces the convergence rate but does not impact the algorithm's precision in solving the EDP. The bound of the noises, \(\hat{\varepsilon}^t\), is inversely related to the algorithm's convergence rate. This tradeoff is acceptable since we achieve a significant objective (privacy protection) at a minor cost (slower convergence rate), as confirmed by simulations.

### Remark 8.6 (Impact of the Random Sleep Strategy)
Based on the definition of \(\phi_i^l\) and the conclusions from Corollary 8.1, it is evident that the likelihood \(\mathbb{P}(h_i^t = 1) = \hat{\eta}_i^l\) produced by the random sleep strategy directly influences the algorithm's convergence speed. As \(\hat{\eta}_i\) decreases (potentially leading to fewer gradient updates), the algorithm's convergence rate slows accordingly. This aligns with the common understanding that reducing the frequency of optimization steps generally slows convergence. However, it is important to emphasize that the random sleep strategy (8.7) allows generator \(i\) to perform gradient updates at time \(t\) only with a certain probability \(\eta_i\); otherwise, only local computations are executed. Therefore the proposed algorithm effectively lowers the consumption of computational resources, as demonstrated in the simulation.<sup>1</sup>

<sup>1</sup> Reducing gradient computations may extend the convergence time of the algorithm. While we cannot quantitatively assess the resource savings achieved by the proposed algorithm, the random sleep strategy has indeed been shown to achieve the desired outcome in subsequent simulation results.

Next, we focus on analyzing the complexity of the proposed algorithm. The complexity of an algorithm refers to the number of iterations required to achieve a specified accuracy [49,63]. The following corollary provides the complexity of the proposed algorithm in achieving \(\mathbb{E}[-(Q^T - Q^*)] \le \epsilon\), where \(T > 0\) represents the number of required iterations, \(Q^T = Q(\hat{y}^T)\), and \(Q^* = Q(y^*)\). Here, \(\hat{y}^T\) is derived from the output \(y_i\) of the proposed algorithm at iteration \(T\).

### Corollary 8.2
Given the conditions outlined in Theorem 8.1, the complexity of the proposed algorithm is \(\mathcal{O}(1/\epsilon^2)\) when the coordinated step-size \(\gamma_i^t = 1/\sqrt{t}, i \in \mathcal{V}\), is employed.

*Proof.* The result of Corollary 8.1 further suggests that

\(\mathbb{E}[-(Q^T - Q^*)] \le \mathcal{O}(\frac{1}{\alpha^T}),\)

for a specific state \(\breve{y}^T\). When the coordinated step-size \(\gamma_i^t = 1/\sqrt{t}, i \in \mathcal{V}\) is applied at each time \(t\) within the proposed algorithm, it follows that

\(\alpha^T = \sum_{l=1}^T \frac{1}{\sqrt{l}} \approx \int_1^T \frac{1}{\sqrt{l}} dl = \sqrt{T}.\)

Consequently, the complexity of the proposed algorithm is determined to be \(\mathcal{O}(1/\epsilon^2)\) [63]. The proof is thus complete.

### Remark 8.7
Corollary 8.2 implies that the proposed algorithm can converge as quickly as \(\mathcal{O}(1/\sqrt{T})\) almost surely if \(\gamma_i^t = 1/\sqrt{t}\) for all \(i \in \mathcal{V}\). This represents the optimal result for such decentralized gradient-based algorithms [49]. Consequently, the complexity described in Corollary 8.2 is consistent with existing complexity results [23,24,36,61]. It is essential to remember that problem complexity refers to the lower bound of the complexities of methods that can effectively solve the problem. Therefore the complexity of the EDP discussed in this chapter is also \(\mathcal{O}(1/\epsilon^2)\). Note that only methods closely related to the algorithm proposed here—decentralized gradient-based algorithms—are considered, as considering others would render the problem complexity result irrelevant.

### Remark 8.8
In fact, it is possible to further enhance the communication efficiency of Algorithm 1 by employing the well-known event-triggering strategy [50,51]. This strategy eliminates the need for real-time information exchange between generators, thus reducing communication overhead. Additionally, inspired by recent studies [43, 52], one could consider time-varying implementations and asynchronous schemes for Algorithm 1 using either a broadcast-based or gossip-based mechanism. These enhancements could significantly advance the development of Algorithm 1 and will be the focus of future research.

## 8.4 Privacy analysis

This section presents the privacy analysis of the decentralized random sleep algorithm with privacy protection, as described in Algorithm 1. The cost function used here is analogous to those found in existing studies [13,19,36] on EDP, often taking the form of a quadratic function. Specifically, let the local cost function be \(J_i(p_i) = c_i p_i^2 + b_i p_i + a_i, i \in \mathcal{V}\), where \(c_i \in \mathbb{R}_{\ge 0}\), \(b_i \in \mathbb{R}\), and \(a_i \in \mathbb{R}\). Here, the private information to be safeguarded includes \(p_i^t\) and the parameters \(c_i\) and \(b_i\) in the local cost function \(J_i\) for any \(i \in \mathcal{V}\).

Using privacy analysis methods from [36,45], we will demonstrate that even if all samples are collected, external eavesdroppers without access to network information cannot deduce any private information about any of the generators.

### Theorem 8.2
_In Algorithm 1 for solving EDP, external eavesdroppers with only intercepted information cannot infer the private details of the output power_ \(p_i^t\) _or the parameters_ \(\{c_i, b_i\}\) _in the local cost function_ \(J_i\) _for any_ \(i \in \mathcal{V}\) _and for any_ \(t \ge 0\)_._

Proof. Without any network information, if external eavesdroppers are unable to discern the form of the update rule based on transmitted data, the associated private information cannot be inferred. The worst-case scenario assumes that external eavesdroppers could deduce the decentralized primal-dual gradient update rule using a Lagrangian-based transformation [24], expressed as

```
\begin{cases} y_i^{t+1} = v_i^t - \gamma_i^t \frac{p_i^t - d_i}{[\hat{z}_i^t]_i}, \\ v_i^{t+1} = \sum_{j=1}^m b_{ij} y_j^{t+1}, z_i^{t+1} = \sum_{j=1}^m b_{ij} z_j^t, \\ p_i^{t+1} = \min\{\max\{\frac{v_i^{t+1} - b_i}{2c_i}, p_i^{\min}\}, p_i^{\max}\}. \end{cases}
(8.25)
```

Given that the local step-size sequence \(\{\gamma_i^t\}\), the parameters \(\{d_i, p_i^{\max}, p_i^{\min}\}\) of the constraints, and the parameters \(\{c_i, b_i\}\) of the cost function are unknown to the external eavesdroppers, we assume that they attempt to deduce the private information of generator \(i \in \mathcal{V}\) by gathering the transmitted data over \(T > 0\) iterations within the network. From the update rules of (8.25), external eavesdroppers can obtain

```
\begin{cases} \tilde{y}_i^1 = \tilde{v}_i^0 - \gamma_i^0 \frac{\tilde{v}_i^0 - b_i}{2c_i [\tilde{z}_i^0]_i} + \gamma_i^0 \frac{d_i}{[\tilde{z}_i^0]_i}, \\ \tilde{y}_i^2 = \tilde{v}_i^1 - \gamma_i^1 \frac{\tilde{v}_i^1 - b_i}{2c_i [\tilde{z}_i^1]_i} + \gamma_i^1 \frac{d_i}{[\tilde{z}_i^1]_i}, \\ \quad \vdots \\ \tilde{y}_i^T = \tilde{v}_i^{T-1} - \gamma_i^{T-1} \frac{\tilde{v}_i^{T-1} - b_i}{2c_i [\tilde{z}_i^{T-1}]_i} + \gamma_i^{T-1} \frac{d_i}{[\tilde{z}_i^{T-1}]_i}, \end{cases}
(8.26)
```

where the variables \(\tilde{y}_i^t\) for \(t=1, ..., T\), \(\tilde{v}_i^t\) for \(t=0, ..., T-1\), and \(\tilde{z}_i^t\) for \(t=0, ..., T-1\) represent values that have either been computed or intercepted by external eavesdroppers. Based on this equation, we perform the privacy analysis from two perspectives.

First, we analyze the privacy of the private parameters \(\{b_i, c_i\}\) within the local cost function. Assuming that all \(T\) equations in (8.26) hold true, external eavesdroppers would need to solve for \(T + 3\) unknowns \(\{\gamma_i^0, \gamma_i^1, ..., \gamma_i^{T-1}, b_i, c_i, d_i\}\) in (8.26) to precisely determine the private data. Given the principles of polynomial equation solving, it is impractical to derive \(T + 3\) unknowns from only \(T\) equations. Therefore the private parameters \(\{b_i, c_i\}\) in the local cost function cannot be deduced by the eavesdroppers. Additionally, the update rules in (8.26) fundamentally differ from the proposed algorithm, further complicating the eavesdroppers’ task of inferring private data, especially due to the inclusion of conditional noise \(\varepsilon_i^t\) and the random sleep strategy (which generates a Bernoulli random variable) in the proposed algorithm.

Next, we assess the privacy of \(p_i^t\) for \(i \in \mathcal{V}\). In Algorithm 1, the initial setting of \(p_i^0\) for \(i \in \mathcal{V}\) is random (\(p_i^0 \in \mathbb{R}_{\ge 0}\)) and independent of other variables, making it impossible for eavesdroppers to know the exact value of \(p_i^0\).
