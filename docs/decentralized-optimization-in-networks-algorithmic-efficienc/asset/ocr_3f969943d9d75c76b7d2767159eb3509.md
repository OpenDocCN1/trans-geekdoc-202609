# ### 1.4.3.1 Computation complexity

The computational burden of the algorithm is contingent upon the number of iterations required to determine the gradient of J. In the subsequent corollary, we shall elaborate on the specific computational complexity associated with Algorithm 1.

> > **Corollary 1.2.** Provided that the prerequisites of Theorem 1.1 are satisfied, in order to achieve an expected value of $\mathbb{E}[J^K - J^*]$ that is less than or equal to $\epsilon$, the computational complexity of Algorithm 1 amounts to $\mathcal{O}(1/\epsilon^2)$ when the algorithm employs a constant step-size of $\alpha^t = 1/\sqrt{t}$. Here, $J^K$ represents the value of $J$ evaluated at $\hat{y}^K$, which is derived from $y_i$ at iteration $K$, where $K$ is a positive integer.

Proof. Corollary 1.1 directly implies that

```
$$\mathbb{E}\left[\mathbf{b}^{\mathrm{T}}(\hat{\phi}^K - p^*)\right] \le \frac{\Gamma^K}{\gamma^K}.$$
```

Drawing from the transformation of the dual-related problem into an epigraph representation, we recognize that attaining the optimal value $J^*$ hinges on identifying the minimum $k^*$ among the auxiliary variable $k$ within the epigraph. Moreover, given the definitions of vectors $\mathbf{b}$ and $p$, inequality (1.39) further means that

```
$$\mathbb{E}\left[J^K - J^*\right] \approx \mathcal{O}(\frac{1}{\gamma^K}),$$
```

for an estimator $\hat{y}^K$. Then, if Algorithm 1 adopts the uniform step-size $\alpha^t = 1/\sqrt{t}$, we have that

```
$$\gamma^K = \sum_{s=1}^K \frac{1}{\sqrt{s}} \approx \int_1^K \frac{1}{\sqrt{s}} ds = \sqrt{K},$$
```

which, by computation, further indicates that the computation complexity of Algorithm 1 is $\mathcal{O}(1/\epsilon^2)$ [45]. This proof is completed.
