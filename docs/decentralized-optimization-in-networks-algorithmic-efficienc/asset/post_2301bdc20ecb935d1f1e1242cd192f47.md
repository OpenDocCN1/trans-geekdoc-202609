
## 1.4.3 Complexity analysis

In this subsection, we offer an examination of the intricacies associated with Algorithm 1, delving into its complexity analysis.

### 1.4.3.1 Computation complexity

The computational burden of the algorithm is contingent upon the number of iterations required to determine the gradient of J. In the subsequent corollary, we shall elaborate on the specific computational complexity associated with Algorithm 1.

**Corollary 1.2.** Provided that the prerequisites of Theorem 1.1 are satisfied, in order to achieve an expected value of $\mathbb{E}[J^K - J^*]$ that is less than or equal to $\epsilon$, the computational complexity of Algorithm 1 amounts to $\mathcal{O}(1/\epsilon^2)$ when the algorithm employs a constant step-size of $\alpha^t = 1/\sqrt{t}$. Here, $J^K$ represents the value of $J$ evaluated at $\hat{y}^K$, which is derived from $y_i$ at iteration $K$, where $K$ is a positive integer.

Proof. Corollary 1.1 directly implies that

$$
\mathbb{E}\left[\mathbf{b}^{\mathrm{T}}(\hat{\phi}^K - p^*)\right] \le \frac{\Gamma^K}{\gamma^K}.
$$

Drawing from the transformation of the dual-related problem into an epigraph representation, we recognize that attaining the optimal value $J^*$ hinges on identifying the minimum $k^*$ among the auxiliary variable $k$ within the epigraph. Moreover, given the definitions of vectors $\mathbf{b}$ and $p$, inequality (1.39) further means that

$$
\mathbb{E}\left[J^K - J^*\right] \approx \mathcal{O}(\frac{1}{\gamma^K}),
$$

for an estimator $\hat{y}^K$. Then, if Algorithm 1 adopts the uniform step-size $\alpha^t = 1/\sqrt{t}$, we have that

$$
\gamma^K = \sum_{s=1}^K \frac{1}{\sqrt{s}} \approx \int_1^K \frac{1}{\sqrt{s}} ds = \sqrt{K},
$$

which, by computation, further indicates that the computation complexity of Algorithm 1 is $\mathcal{O}(1/\epsilon^2)$ [45]. This proof is completed.

**Remark 1.5.** Based on Corollary 1.2, we deduce that when Algorithm 1 utilizes a constant step-size of \(\alpha^t = 1/\sqrt{t}\), its convergence rate can achieve the optimal \(\mathcal{O}(1/\sqrt{t})\) speed, which is a benchmark for this class of decentralized subgradient algorithms, as noted in [31,33,45]. Consequently, the associated computational complexity of Algorithm 1 aligns well with existing complexity findings reported in [22,28,31,33,34]. Additionally, it is noteworthy that Algorithm 1 leverages a gossip-based communication protocol, making it a suitable choice for computing nodes with constrained communication capabilities.

### 1.4.3.2 Runtime complexity

Moving forward, we derive the runtime complexity of Algorithm 1. Here, we establish the total runtime complexity as the multiplication of the computational complexity and the duration of each iteration, as referenced in [46]. Assuming that a single local variable calculation necessitates 1 unit time step for execution, we shall now present the comprehensive total runtime complexity of Algorithm 1 in the following corollary.

**Corollary 1.3.** Assuming that the prerequisites stated in Theorem 1.1 are satisfied, we can infer from Corollary 1.2 that, in order to achieve an expectation bound of \(\mathbb{E}[J^K - J^*] \le \epsilon\), the total runtime complexity of Algorithm 1 has a worst-case value of \(\mathcal{O}(n \exp(1/\epsilon))\) units and a best-case value of \(\mathcal{O}(\exp(1/\epsilon))\) units. Here, \(n\) represents the number of nodes involved in the algorithm.

**Proof.** Drawing from the details presented in Section 1.3.1, the gossip-based communication protocol necessitates the random selection of a single directed edge \((i_t, j_t)\) for communication during each iteration \(t\). As a result, in Algorithm 1 (Steps 1 and 3, outlined in Section 1.3.2), only the dual-associated variables \((v_i^t, u_i^t)\) for \(i = j^t\) and \(z_i^t, y_i^t, k_i^t\) for \(i \in \{i^t, j^t\}\) of the involved nodes \(i_t\) and \(j_t\) are updated, while the dual-associated variables of other nodes remain static. This leads to a runtime complexity of \(\mathcal{O}(1)\) units for the dual-related components in each iteration \(t\). Additionally, for the primal variable \(x_i^t\) (Step 2, as specified in Section 1.3.2), the runtime complexity ranges from \(\mathcal{O}(n)\) in the worst-case scenario to \(\mathcal{O}(1)\) in the best-case scenario. The best-case situation occurs when \(x_i^t\) does not change due to the stability of the dual-associated variable \(v_i^t\). Utilizing the insights provided in Corollary 1.2 and the definition of total runtime complexity, we can derive the conclusions stated in Corollary 1.3. This proof is completed.

**Remark 1.6.** It is worth noting that in the context of a uniform step-size, the total runtime complexity of Algorithm 1 exhibits a distinct advantage compared to the approach presented in [31]. Specifically, due to the employment of the gossip-based communication protocol, the runtime complexity of Algorithm 1 for updating the dual-related variables is decoupled from the network size, contrasting with the \(\mathcal{O}(n)\) complexity observed in [31] for each iteration. This attribute contributes significantly to the overall superiority of Algorithm 1 in terms of runtime complexity.

## 1.5 Generalizing the algorithm design

In this section, we delve into a related decentralized asynchronous algorithmic approach that utilizes the random sleep protocol and epigraph strategy to tackle the problem in the context of time-varying directed networks.

### 1.5.1 Network and algorithm

Assuming the interplay between nodes fluctuates over time, we define \(\mathcal{G}^t = \{\mathcal{V}, \mathcal{E}^t\}\) to represent the evolving directed communication network at each time \(t \ge 0\). Here, \(\mathcal{E}^t \subseteq \mathcal{V} \times \mathcal{V}\) signifies the set of directed edges, and \(\mathcal{N}_i^{\text{in},t} = \{j \mid (j, i) \in \mathcal{E}^t\}\) denotes the set of in-neighbors for node \(i\) at time \(t\). In the subsequent discussion, we typically adopt the following assumptions regarding the networks.

**Assumption 1.3.** We introduce a positive integer constant \(B\) such that, for any non-negative time \(t\), the union of consecutive networks from \(\mathcal{G}^t\) to \(\mathcal{G}^{t+B-1}\) maintains strong connectivity, denoted as \(\mathcal{G}^t \cup \mathcal{G}^{t+1} \cup \dots \cup \mathcal{G}^{t+B-1}\).

Assumption 1.3 stipulates that within any given period of \(B\) time units, any node has the capability to acquire information either directly from its incoming neighbors or indirectly through any other node in the network. This assumption encompasses a broader scope compared to presuming the individual directed networks \(\mathcal{G}^t\) to be strongly connected.

Here, we propose a decentralized asynchronous algorithm that leverages the random sleep protocol and epigraph strategy. To clarify the approach, we first elaborate on the random sleep mechanism. Specifically, we introduce \(h_i^t\), a random variable that determines whether node \(i\) is active or inactive at time \(t \ge 1\). If \(h_i^t = 1\), node \(i\) performs updates at time \(t\); otherwise, it remains unchanged. Notably, \(h_i^t\) is assumed to be an independent and identically distributed Bernoulli random variable with probability \(\mathbb{P}(h_i^t = 1) = \hat{\eta}_i\) and \(\mathbb{P}(h_i^t = 0) = 1 - \hat{\eta}_i\), where \(0 < \hat{\eta}_i \le 1\) for all \(i \in \mathcal{V}\). We further define \(\hat{\eta}_{\max}\) and \(\hat{\eta}_{\min}\) as the maximum and minimum activation probabilities among all nodes in the network. Subsequently, we formally present Algorithm 2, which outlines the decentralized asynchronous algorithm for each node \(i\) utilizing the random sleep protocol.

Algorithm 2 employs the same decaying step-size (random) \(\alpha_i^t, i \in \mathcal{V}\), analogous to Algorithm 1. Specifically, \(\alpha_i^t = 1 / \Gamma_i^t\), where this formulation adheres to the prerequisites outlined in Lemma 1.2 with distinct parameters \(\alpha_1, \alpha_2\), and \(\alpha_3\) (see Lemma 3 in [31] for a detailed proof). This eliminates the need for any global parameters, allowing each node to update its states by either receiving information from its neighboring nodes or solely relying on its own data at each time \(t\). Furthermore, we introduce a matrix \(\hat{W}^t = [\hat{w}_{ij}^t] \in \mathbb{R}^{n \times n}\) that corresponds to the network \(\mathcal{G}^t\) at time \(t \ge 0\) and adheres to the conditions as:

\[
\hat{w}_{ij}^t = \begin{cases} \ge \rho, & j \in \mathcal{N}_i^{\text{in},t}, \\ 0, & \text{otherwise}, \end{cases} \quad \sum_{j=1}^n \hat{w}_{ij}^t = 1, \forall i \in \mathcal{V}
\]
