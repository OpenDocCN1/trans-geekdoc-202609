### 6.5.2 Decentralized classification via logistic regression

In this example, we concentrate on a linear classification challenge, motivated by [56], wherein fifty nodes, \(n=50\), interconnected in a network, collaborate to train a linear classifier tailored for a set of dynamically evolving points in a designated feature space. Each node \(i\) is tasked with managing fifty (\(v^i=50\) for all \(i\)) sample pairs \(\{a^{i,l}, c_t^{i,l}\}_{l=1}^{v^i}\) for training purposes at any given time \(t \ge 1\). Here, \(a^{i,l}\) takes on values from the set \(\{-1, 1\}\) as the label, while \(c_t^{i,l}\) belongs to the real plane \(\mathbb{R}^2\), signifying the point's position. Our primary objective is to devise a linear classification model leveraging these training samples. Specifically, we aim to identify a discriminant hyperplane \(\{c \in \mathbb{R}^2 | y^\top c + h = 0\}\) characterized by a tuple \((y, h) \in \Omega_1 \times \Omega_2\), with \(\Omega_1\) and \(\Omega_2\) being subsets of \(\mathbb{R}^2\) and \(\mathbb{R}\), respectively. At each time instant \(t \ge 1\), the optimal hyperplane \((y_t^*, h_t^*)\) segregates the points with \(a^{i,l}=1\) from those with $a^{i,l} = -1$. In other words, for every $(i, l)$ pair, if $(y_t^*)^\top c_t^{i,l} + h_t^* \ge 0$, then $a^{i,l}$ equals $1$; otherwise, it equals $-1$. Consequently, this online classification task can be framed as a minimization problem at every time step \(t \ge 1\):

$$\min_{y,h} \sum_{i=1}^n \sum_{l=1}^{v^i} \log(1 + e^{-a^{i,l}(y^\top c_t^{i,l} + h)}) + \frac{K}{2}(\|y\|^2 + h^2),$$

where $K = 1$ is the regularization parameter. Each point $c_t^{i,l} \in \mathbb{R}^2$ traverses along a circular path, adhering to the subsequent rule:

$$c_t^{i,l} = c_p^{i,l} + r \left[ \begin{array}{c} \cos(t/100) \\ \sin(t/100) \end{array} \right],$$

with radius $r = 1$, where $c_p^{i,l} \in \mathbb{R}^2$ denotes the randomly generated circle center. We define $\alpha_t$ as $\frac{1}{20\sqrt{t+1}}$, set $\delta$ equal to $\frac{d}{\sqrt{T}}$, and assign $b_t$ a value of $5$.
