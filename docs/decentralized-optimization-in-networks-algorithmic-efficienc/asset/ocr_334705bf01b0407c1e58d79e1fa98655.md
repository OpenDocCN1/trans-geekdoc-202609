where $f(x) : \mathbb{R}^p \to \mathbb{R}$ denotes the global function, which is expressed as a finite-sum of local functions $f^i(x) : \mathbb{R}^p \to \mathbb{R}$, specifically, $f(x) = \frac{1}{m} \sum_{i=1}^m f^i(x)$. Here, $\Omega_0 \subseteq \mathbb{R}^p$ signifies a closed convex set. Additionally, $m$ stands for the total count of nodes, while $p$ indicates the data dimension. Each local function $f^i(x)$ can be further decomposed as $f^i(x) = \frac{1}{n^i} \sum_{j=1}^{n^i} f^{i-j}(x)$, where $f^{i \cdot j}(x) : \mathbb{R}^p \to \mathbb{R}$ represents an individual component of $f^i(x)$ corresponding to the $j$th datum on the $i$th node, and $n^i$ is the number of data assigned to node $i$.

Broadly speaking, addressing optimization problems through a decentralized lens necessitates the establishment of a communication network among nodes for information exchange. Consider a collection of nodes represented by $\mathcal{V} = \{1, ..., m\}$ and a set of connections indicated by $\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}$. It is straightforward to fashion a communication network represented by an undirected, interconnected graph $\mathcal{G}$. If the criteria $(i, j) \in \mathcal{E}, i, j = 1, ..., m$, and $i \neq j$ are met, i.e., indicating the presence of a link between node $i$ and node $j$, then these nodes can engage in mutual information sharing; otherwise, communication is not possible. Associated with graph $\mathcal{G}$ is a doubly stochastic matrix $A \in \mathbb{R}^{m \times m}$ that assigns significance to the data transmitted within the network. Denote $a^{ij}$ as the matrix element of $A$ positioned at row $i$ and column $j$. When $a^{ij} > 0$, it signifies that node $i$ and node $j$ can exchange information, whereas $a^{ij} = 0$ means information cannot be transferred between them. Furthermore, for the doubly stochastic matrix $A$, it is guaranteed that $A 1_n = 1_n$ and $1_n^\text{T} A = 1_n^\text{T}$ are consistently valid.

Next, we establish the subsequent assumptions and definitions to articulate the problem we intend to investigate.

**Assumption 3.1.** For every $i$ belonging to the set $\{1, ..., m\}$, each local function $f^i$ fulfills the criteria of being $\beta$-smooth and $\lambda$-strongly convex, with $\beta$ and $\lambda$ both being greater than zero.

It should be noted that Assumption 3.1 ensures that there exists a unique optimal solution, denoted as $x^*$ for the problem given in (3.1). Additionally, the global function $f(x) : \mathbb{R}^p \to \mathbb{R}$ possesses properties of being both $\beta$-smooth and $\lambda$-strongly convex, i.e.,

\(f(\nu) \ge f(\mu) + \nabla f(\mu)^\text{T}(\nu - \mu) + \frac{\lambda}{2}\|\nu - \mu\|^2,\)
\(\quad (3.2)\)

\(\|\nabla f(\nu) - \nabla f(\mu)\| \le \beta\|\nu - \mu\|,\)
\(\quad (3.3)\)

where $\nu, \mu \in \mathbb{R}^p$ are arbitrary vectors.

**Assumption 3.2.** The structure of the communication network connecting various nodes is represented by an undirected, interconnected graph denoted as $\mathcal{G}$. Assuming that $A$ is a basic and doubly stochastic matrix linked to the network $\mathcal{G}$, and let $\sigma_2$ represent the second greatest singular value of $A$, it follows that $\sigma_2 = \|A - \frac{1}{m} 1_m 1_m^\text{T}\|$, which is less than 1.
