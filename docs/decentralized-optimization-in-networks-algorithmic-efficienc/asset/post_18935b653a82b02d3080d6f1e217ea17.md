
**Lemma 3.3.** [36] Granted that Assumption 3.2 is valid, it follows that \(\forall x \in \mathbb{R}^{m \times p}\), \(\|Ax - A_\infty x\| \le \sigma_2^2 \|x - A_\infty x\|\), where \(A_\infty = \frac{1}{m} \mathbf{1}_m \mathbf{1}_m^\mathrm{T}\).

**Lemma 3.4.** [52] Provided a non-negative matrix \(B \in \mathbb{R}^{m \times m}\) and a positive vector \(\epsilon \in \mathbb{R}^m\), whenever it holds true that for all \(\alpha > 0\), \(B\epsilon\) is element-wise less than or equal to \(\alpha \epsilon\), then the inequality \(\rho(B) \le \|B\|_\infty \le \alpha\) holds.

## 3.4.2 Auxiliary lemmas

To ensure that all nodes converge to the same consensus solution, we will limit the disparity represented by \(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2]\). To achieve the optimal solution arrived at by the consensus, we will restrict the difference denoted by \(\mathbb{E}[\|\overline{x}_{k+1} - x^*\|^2]\). To obtain an exact global gradient estimator, we will bound the divergence given by \(\mathbb{E}[\|y_{k+1} - A^\infty y_{k+1}\|^2]\). Thanks to the integration of the variance-reduction method into our algorithm, we will confine the divergence represented by \(\mathbb{E}[\|t_k^{i,j} - x^*\|^2]\) to neutralize the variance introduced by the stochastic gradient. By defining \(v_k^i\) as \((1/n^i) \sum_{j=1}^{n^i} \|t_k^{i,j} - x^*\|^2\) and setting \(v_k\) as the sum of all \(v_k^i\) from \(j=1\) to \(n^i\), we will limit the scope of \(\mathbb{E}[v_{k+1}]\) as a surrogate for limiting the scope of \(\mathbb{E}[\|t_k^{i,j} - x^*\|^2]\). Initially, we derive Lemma 3.5 by limiting the scope of \(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2]\).

**Lemma 3.5.** Provided that Assumption 3.2 is valid, it follows that: \(\forall k \ge 0\),

```
\(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2] \le (1+a)\sigma_2^2 \mathbb{E}[\|x_k - A^\infty x_k\|^2] + (1+a^{-1})\eta^2 \mathbb{E}[\|y_k - A^\infty y_k\|^2].\)
```

By assigning the values of 1 and \(\frac{1-\sigma_2^2}{2\sigma_2^2}\) to \(a\) in the aforementioned inequality, we can derive the subsequent two results:

```
\(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2] \le 2 \mathbb{E}[\|x_k - A^\infty x_k\|^2] + 2\eta^2 \mathbb{E}[\|y_k - A^\infty y_k\|^2]\)
```

```
\(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2] \le \frac{1+\sigma_2^2}{2} \mathbb{E}[\|x_k - A^\infty x_k\|^2] + \frac{2\eta}{1-\sigma_2^2} \mathbb{E}[\|y_k - A^\infty y_k\|^2].\)
```

**Proof.** Based on the updating principle outlined in (3.7) and Young's inequality, which states that \(\|a+b\|^2 \le (1+\zeta)\|a\|^2 + (1+\frac{1}{\zeta})\|b\|^2, \forall a, b \in \mathbb{R}^{m \times p}, \forall \zeta > 0\) [19], we arrive at the subsequent conclusion:

```
\(\mathbb{E}[\|x_{k+1} - A^\infty x_{k+1}\|^2]\)
\(=\mathbb{E}[\|P_\Omega(Ax_k) - P_\Omega(A^\infty x_k) - A^\infty(P_\Omega(Ax_k) - P_\Omega(A^\infty x_k)) - \eta(I_m - A^\infty)y_k\|^2]\)
\(\le (1+a) \mathbb{E}[\|(I_m - A^\infty)(P_\Omega(Ax_k) - P_\Omega(A^\infty x_k))\|^2]\)
\(+ (1+a^{-1})\eta^2 \mathbb{E}[\|y_k - A^\infty y_k\|^2]\)
```

```
\(\le(1+a)\mathbb{E}[\|P_\Omega(Ax_k)-P_\Omega(A^\infty x_k)\|^2]+(1+a^{-1})\eta^2\mathbb{E}[\|y_k-A^\infty y_k\|^2]\)
\(\le(1+a)\sigma_2\mathbb{E}[\|x_k-A^\infty x_k\|^2]+(1+a^{-1})\eta^2\mathbb{E}[\|y_k-A^\infty y_k\|^2].\)
```

By setting \(a\) to \(1\) and then to \(\frac{1-\sigma_2^2}{2\sigma_2^2}\) in succession, we finalize the demonstration of Lemma 3.5. \(\square\)

Subsequently, we limit \(\mathbb{E}[m\|\bar{x}_{k+1}-x^*\|^2]\) to guarantee the precise optimal solution.

**Lemma 3.6.** Provided that Assumptions 3.1 and 3.2 are valid and given that \(0<\eta \le \frac{1}{\beta}\), the subsequent correlation applies: \(\forall k \ge 0\),

\(\mathbb{E}[m\|\bar{x}_{k+1}-x^*\|^2]\le(2\eta^2\beta^2+2\eta^2(1-\eta\lambda)\beta^2+2\sigma_2+2(1-\eta\lambda)\sigma_2)\)
\(\mathbb{E}[\|x_k-A^\infty x_k\|^2]+2\mathbb{E}[m\|\bar{x}_k-x^*\|^2]\)
\(+\frac{2\eta^2}{m}\mathbb{E}[\|g(P_\Omega(x_k))-\nabla F(P_\Omega(x_k))\|^2].\)

**Proof.** Based on the formulas \(\bar{y}_k=\frac{1}{m}\mathbf{1}_m^Ty_k\), \(\bar{s}_k=P_{\Omega_0}[\bar{x}_k]\), and \(x^*=s^*-\eta\nabla f(s^*)\), we substitute Eq. (3.8a) for \(\bar{x}_{k+1}\) to obtain

\(\mathbb{E}[\|\bar{x}_{k+1}-x^*\|^2]\)
\(=\mathbb{E}[\|\frac{1}{m}\mathbf{1}_m^TP_\Omega[Ax_k]-\eta\frac{1}{m}\mathbf{1}_m^Ty_k-(s^*-\eta\nabla f(s^*))\|^2]\)
\(=\mathbb{E}[\|\bar{s}_k-s^*-\eta(\nabla f(\bar{s}_k)-\nabla f(s^*))\|^2]+\mathbb{E}[\|\frac{1}{m}\mathbf{1}_m^T(P_\Omega[Ax_k]\)
\(-P_\Omega(\mathbf{1}_m\bar{x}_k))+\eta\nabla f(P_{\Omega_0}(\tilde{x}_k))-\eta\bar{y}_k\|^2]\)
\(+2\mathbb{E}[\langle\bar{s}_k-s^*-\eta(\nabla f(\bar{s}_k)-\nabla f(s^*)),\eta\nabla f(P_{\Omega_0}(\tilde{x}_k))-\eta\bar{y}_k\)
\(+\frac{1}{m}\mathbf{1}_m^T(P_\Omega[Ax_k]-P_\Omega(\mathbf{1}_m\bar{x}_k))\rangle].\)

By employing (3.8c), Lemma 3.2, and Young's inequality referenced in [19], we infer the following:

\(\mathbb{E}[\|\bar{x}_{k+1}-x^*\|^2]\)
\(\le(1-\eta\lambda)^2\mathbb{E}[\|\bar{s}_k-s^*\|^2]+\frac{(1+a)}{m}\mathbb{E}[\|P_\Omega[Ax_k]-P_\Omega(\mathbf{1}_m\bar{x}_k)\|^2]\)
\(+2\mathbb{E}[\langle\bar{s}_k-s^*-\eta(\nabla f(\bar{s}_k)-\nabla f(s^*)),\frac{1}{m}\mathbf{1}_m^T(P_\Omega[Ax_k]-P_\Omega(\mathbf{1}_m\bar{x}_k))\)
\(+\eta\nabla f(P_{\Omega_0}(\tilde{x}_k))-\eta\frac{1}{m}\mathbf{1}_m^T\nabla F(s_k))\)
\(+(1+a^{-1})\eta^2\mathbb{E}[\|f(P_{\Omega_0}(\tilde{x}_k))-\bar{y}_k\|^2].\)

Drawing upon the inequality (3.4) and the Cauchy–Schwarz inequality, as cited in [53], stating that $\langle A, B \rangle \le \|A\|\|B\|$, one can deduce

```
\mathbb{E}[\|\bar{x}_{k+1} - x^*\|^2]
\le 2(1-\eta\lambda)\mathbb{E}[\|\bar{x}_k - x^*\|^2 \| \frac{1}{m}\mathbf{1}_m^T(P_\Omega[Ax_k] - P_\Omega(1_m\bar{x}_k))\|]
+ 2\eta(1-\eta\lambda)\mathbb{E}[\|\bar{x}_k - x^*\|\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \nabla \bar{F}(s_k)\|]
+ (1-\eta\lambda)^2 \mathbb{E}[\|\tilde{x}_k - x^*\|^2] + \frac{(1+a)}{m} \mathbb{E}[\|Ax_k - A^\infty x_k\|^2]
+ (1+a^{-1})\eta^2 \mathbb{E}[\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \bar{y}_k\|^2].
```

By applying Young's inequality, as referenced in [19], we obtain the subsequent conclusion:

```
\mathbb{E}[\|\bar{x}_{k+1} - x^*\|^2]
\le (1-\eta\lambda)^2 \mathbb{E}[\|\bar{x}_k - x^*\|^2] + \frac{(1+a)}{m} \mathbb{E}[\|Ax_k - A^\infty x_k\|^2]
+ (1+a^{-1})\eta^2 \mathbb{E}[\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \bar{y}_k\|^2]
+ \eta(1-\eta\lambda)b \mathbb{E}[\|\bar{x}_k - x^*\|^2] + (1-\eta\lambda)c \mathbb{E}[\|\bar{x}_k - x^*\|^2]
+ \eta(1-\eta\lambda)b^{-1} \mathbb{E}[\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \nabla \bar{F}(P_{\Omega_0}(\tilde{x}_k))\|^2]
+ \frac{(1-\eta\lambda)}{m} c^{-1} \mathbb{E}[\|Ax_k - A^\infty x_k\|^2].
```

In inequality (3.17), by utilizing $\nabla \bar{F}(P_\Omega(x_k))$ to elaborate on the third term, which is $\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \bar{y}_k$, we arrive at

```
\mathbb{E}[\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \bar{y}_k\|^2]
= \mathbb{E}[\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \nabla \bar{F}(P_\Omega(x_k))\|^2] + \mathbb{E}[\|\nabla \bar{F}(P_\Omega(x_k)) - \bar{y}_k\|^2]
= \|\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \nabla \bar{F}(P_\Omega(x_k))\|^2] + \frac{1}{m^2} \mathbb{E}[\|g(P_\Omega(x_k)) - \nabla F(P_\Omega(x_k))\|^2],
```

where $\mathbb{E}[\nabla \bar{F}(P_\Omega(x_k))] = \bar{y}_k$ [19]. Within the inequality denoted by (3.18), the initial component additionally implies that

```
\|\nabla f(P_{\Omega_0}(\tilde{x}_k)) - \nabla \bar{F}(P_\Omega(x_k))\|^2
= \|\| \frac{1}{m} \mathbf{1}_m^T \nabla F(P_\Omega(1_m \tilde{x}_k)) - \frac{1}{m} \mathbf{1}_m^T \nabla F(P_\Omega(x_k)) \|^2
\le \frac{\beta^2}{m^2} \|x_k - A^\infty x_k\|^2.
```

By incorporating Eq. (3.18) and inequality (3.19) into inequality (3.17), we can infer that

$$
\mathbb{E}[\|\bar{x}_{k+1} - x^*\|^2]\\
\le ((1-\eta\lambda)^2 + \eta(1-\eta\lambda)b + (1-\eta\lambda)c)\mathbb{E}[\|\bar{x}_k - x^*\|^2]\\
+ \frac{(1+a^{-1})\eta^2}{m^2}\mathbb{E}[\|g(P_\Omega(x_k)) - \nabla F(P_\Omega(x_k))\|^2]\\
+ (\frac{(1+a^{-1})\eta^2\beta^2}{m} + \frac{\eta(1-\eta\lambda)b^{-1}\beta^2}{m} + \frac{(1+a)\sigma_2}{m}\\
+ \frac{(1-\eta\lambda)c^{-1}\sigma_2}{m})\mathbb{E}[\|x_k - A^\infty x_k\|^2].
$$
(3.20)

By assigning \(a=1\), \(b=k_1/2\), \(c=\eta k_1/2\), respectively, and multiplying both sides of the inequality denoted by (3.20) by \(m\), we finalize the demonstration of Lemma 3.6. \(\square\)
