# 4.4 Simulation experiments

In this section, we present two simulations to verify the efficiency of ET-DSGT. Note that the simulations are implemented using Matlab® R2021a on a laptop with Intel i3-10100 CPU@3.60 GHz, RAM 16.0 GB, and Windows 11 operating system.

# 4.4.1 Logistic regression

In this subsection, we present the initial simulation that revolves around the decentralized logistic regression problem on an undirected network. Within this simulation framework, the network is randomly connected, featuring m = 10 agents and a connection likelihood of p<sub>c</sub> = 0.8. The decentralized logistic regression problem assumes the shape of:

$$\min_{x \in \mathbb{R}^p} \frac{1}{N} \sum_{i=1}^N \frac{1}{m^i} \sum_{h=1}^{m^i} \ln(1 + \exp(-w^{i,h}(v^{i,h})^\mathrm{T} \mathrm{T} x)) + \frac{\pi}{2} ||x||_2^2,$$

where N represents the quantity of agents, while the local function f<sup>i</sup>(x) is expressed as

$$f^i(x) = \frac{1}{m^i} \sum_{h=1}^{m^i} \ln(1 + \exp(-w^{i,h}(v^{i,h})^\mathrm{T} \mathrm{T} x)) + \frac{\pi}{2} ||x||_2^2,$$

where v<sup>i,h</sup> \(\in \mathbb{R}^p\) signifies the dataset, whereas w<sup>i,h</sup> \(\in \{-1, 1\}\) corresponds to the locally stored data labels by agent i for each h ranging from 1 to m<sup>i</sup>. The final component serves as a regularization term, aiming to avert over-fitting.

For this simulation, we employ a genuine dataset, specifically the breast cancer Wisconsin dataset sourced from the UCI Machine Learning Repository [44]. Additionally, a total of m = 200 data instances are randomly allocated to each local agent for training purposes, with each instance containing d = 9 attributes. It is worth mentioning that all dataset features have undergone pre-processing and normalization. The simulation outcomes can be categorized into three primary sections.

(1) Convergence: In this simulation, Fig. 4.1 displays three randomly chosen dimensions of the transient behaviors of estimator x, demonstrating that in ET-DSGT, the estimator x ultimately reaches a stable condition, specifically, the global minimum. In other words, ET-DSGT exhibits excellent convergence capabilities.

(2) Triggering times: In this simulation, we explore the trigger times for 5 agents executing the ET-DSGT algorithm. The findings from the simulation are presented in Fig. 4.2 and Table 4.1, confirming Theorem 4.3. Both Table 4.1 and Fig. 4.2 reveal that communication in ET-DSGT is intermittent.
