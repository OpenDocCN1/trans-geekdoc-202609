\(\le \phi^t |\nabla Q_i(v_i^t)|^2 + \phi^t |v_i^t - v|^2 + \frac{2}{t\eta_i}(Q_i(v_i^t) - Q_i(v))\)
\(\le \phi^t |\nabla Q_i(v_i^t)|^2 + \phi^t \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2C}{t\eta_i} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2\)
\(+ \frac{2}{t\eta_i} (Q_i(\bar{y}^t) - Q_i(v)),\)
(8.B.2)

where the first and second inequalities stem from the convexity of \(-Q_i\) and the bound \(|\nabla Q_i| \le C\) for all \(i \in \mathcal{V}\), respectively. Using (8.B.1), (8.B.2), along with the conditions \(|\nabla Q_i| \le C\) and \(\kappa^{-1} \le [\xi_i^t]_i \le 1\) for all \(i \in \mathcal{V}\), we derive for all \(t \ge \hat{t}\),

\(|y_i^{t+1} - v|^2\)
\(\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2}{t\eta_i[z_i^t]_i} (Q_i(\bar{y}^t) - Q_i(v))\)
\(+ C^2 \kappa^2 \gamma_i^t |t|^2 + 2\epsilon_i^t \gamma_i^t C \kappa + 2|\epsilon_i^t| |v_i^t - v| + |\epsilon_i^t|^2\)
\(+ \phi^t \kappa C^2 + \frac{2C\kappa}{t\eta_i} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2.\)
(8.B.3)

Similarly, if \(hi^t = 0\) for \(i \in \mathcal{V}\), it follows that

\(|y_i^{t+1} - v|^2\)
\(\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + |\epsilon_i^t|^2 + 2|\epsilon_i^t| |v_i^t - v|.\)
(8.B.4)

Considering both cases (8.B.3) and (8.B.4), and taking the conditional expectation with respect to \(\mathcal{F}^t\), we can conclude that for all \(i \in \mathcal{V}\) and for all \(t \ge \hat{t}\),

\(\mathbb{E} \left[ |y_i^{t+1} - v|^2 | \mathcal{F}^t \right]\)
\(\le (1 + \phi^t \kappa) \sum_{j=1}^m b_{ij} |y_j^t - v|^2 + \frac{2}{t[z_i^t]_i} (Q_i(\bar{y}^t) - Q_i(v))\)
\(+ C^2 \kappa^2 \eta_i |t|^2 + 2C\kappa \eta_i \epsilon_i^t \gamma_i^t + 2|\epsilon_i^t| |v_i^t - v| + |\epsilon_i^t|^2\)
\(+ \phi^t \kappa^2 \eta_i + \frac{2C\kappa}{t} \sum_{j=1}^m b_{ij} |y_j^t - \bar{y}^t|^2.\)
(8.B.5)
