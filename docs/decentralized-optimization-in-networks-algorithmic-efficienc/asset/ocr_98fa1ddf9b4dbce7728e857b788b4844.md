\(\sum_{l=0}^{\tau-1} \alpha_l t_w^{t-l} [ ||y_l' - 1_N \otimes \bar{y}_l'||^2 ] + L^2 [ ||x_l - 1_N \otimes \bar{x}_l||^2 ] + \frac{L^2}{N} [ ||\bar{x}_l - x^*||^2 ]\)
\(+ \frac{8c_w^{\frac{3}{2}} c_\rho \alpha_t^2}{(1-\tau_w)^3} (\frac{\pi^2 C}{6} + U_1) + \frac{\sqrt{c_w} c_\rho U_1 \alpha_t^2}{1-\tau_w},\)
(4.34)

where \(\tau_2\) can be any positive number, and the inequality relies on several factors: \(\bar{y}'_l = \frac{1}{N} \sum_{i=1}^N \nabla f^i(x_l^i)\), \(2(a,b) \le \tau_2 a^2 + b^2/\tau_2\), and (4.13). By inserting Eq. (4.34) into (4.27), and invoking Lemma 4.1 and Theorem 4.1, we arrive at the conclusion that

\(\mathbb{E}[||\bar{x}_{t+1} - x^*||^2] \le (1 - \frac{\mu - (L+1)\sqrt{N}\tau_2}{N} \alpha_t) \mathbb{E}[||\bar{x}_t - x^*||^2]\)
\(+ \mathcal{O}(\alpha_t^2) + \mathcal{O}(\alpha_t^3) + \mathcal{O}(\alpha_t^4)\)
\(\le (1 - \frac{\mu}{2N} \alpha_t) \mathbb{E}[||\bar{x}_t - x^*||^2] + \mathcal{O}(\alpha_t^2),\)

where \(\tau_2\) is set to \(\mu / 2(L+1)\sqrt{N}\). Subsequently, utilizing Lemma 5 from [10], it gives

\(\mathbb{E}[||\bar{x}_{t+1} - x^*||^2] = \mathcal{O}(\alpha_t).\)

Observing that \(\lim_{t \to \infty} \alpha_{t-1} / \alpha_t = 1\), we can confirm that (4.33) is valid. Assuming \(\alpha_t\) is defined as \(a/(t+1)\) and the positive scalar \(a\) meets the condition \(a > (2N/\mu)\), it follows that \((\mu a / 2N) > 1\). Consequently, based on Lemma 4 from the reference [10], we can draw the following inference:

\(\mathbb{E}[||\bar{x}_t - x^*||^2] = \mathcal{O}(\frac{1}{t}).\)

The proof is completed.
