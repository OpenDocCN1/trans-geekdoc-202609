# ## 1.3.1 Gossip-based communication protocol

Prior to delving into the proposed algorithm, let us first acquaint ourselves with the gossip-based communication protocol. Essentially, this protocol facilitates node j to disseminate its estimates to node i by probabilistically activating a directed edge (j, i) within the strongly connected directed network G during each iteration. This approach ensures robust consensus attainment through sparse communication exchanges.

The gossip-based communication protocol adheres to a similar asynchronous time model as outlined in [26,27,39]. Each node is equipped with a local Poisson clock that ticks at a rate of 1, effectively serving as a virtual clock. Whenever any local clock ticks, the global virtual clock is considered to tick as well, conforming to a Poisson process with a rate of n. We define Z^t as the absolute time corresponding to the rth tick of the global Poisson clock. Time is discretized into intervals [Z^(t-1), Z^t), representing discrete-time t. At time t, node i^t wakes up (or transmits information to a chosen outgoing neighbor) and selects an outgoing neighbor j^t for communication. The selection of j^t follows a non-negative stochastic vector κ_i, that aligns with the network G = {V, E}. Specifically, κ_ji > 0 is positive only when there exists a directed edge (i, j) in the network. For the sake of simplicity, we typically assume a directed network structure.

Assumption 1.2. (i) The directed network G possesses the property of strong connectivity, guaranteeing that there exists a path from any node to any other node in the network. The corresponding weighted matrix Υ = [wij] ∈ R^(n×n) is comprised of non-negative elements. (ii) The in-neighbor selection process exhibits independence and identical distribution. Specifically, at any given time, node j is chosen by its in-neighbor i ∈ N_j^in with a probability κ_ji > 0, provided that i is indeed an in-neighbor of j (κ_ji = 0 if i ∉ N_j^in). This selection occurs independently of the other selections made at that time.
