
\( k_i^t = z_i^t + \frac{[J_i(v_i^t) - e_i^T z_i^t]_+}{1 + ||a_i^t||^2} e_i, \quad (1.13b) \)

where the vector \( a_i^t \in \partial J_i(v_i^t) \). Moreover, nodes excluding \( i^t \) and \( j^t \) refrain from updating the values of \( y_i^t \) and \( k_i^t \), i.e., for \( i \notin \{i^t, j^t\} \),

\( y_i^t = y_i^{t-1}, \quad k_i^t = k_i^{t-1}. \quad (1.14) \)

To facilitate the concise representation of the aforementioned three procedures, at each time \( t \ge 1 \), we define a non-negative matrix \( W^t = [W_{ij}^t] \in \mathbb{R}^{n \times n} \) as follows:

\( W^t = I_n + w_{i^t j^t} (e_{j^t} e_{i^t}^T - e_{j^t} e_{j^t}^T), \)

which represents a row-stochastic matrix adhering to the definition of \( e_i \) for \( i \in \mathcal{V} \). By employing the matrix \( W^t \), we can rewrite the updates (1.9)--(1.14) in the following manner: for all \( t \ge 1 \) and each \( i \in \mathcal{V} \),

\( v_i^t = \sum_{j=1}^n W_{ij}^t y_j^{t-1}, \quad u_i^t = \sum_{j=1}^n W_{ij}^t k_j^{t-1}, \quad (1.15a) \)

\( x_i^t = \arg \min_{x_i \in \Omega_i} C_i(x_i) - v_i^t (x_i - r_i), \quad (1.15b) \)

\( y_i^t = v_i^t - \frac{\psi_i^t a_i^t}{1 + ||a_i^t||^2} \chi_{i \in \{i^t, j^t\}}, \quad (1.15c) \)

\( k_i^t = u_i^t + (\frac{\psi_i^t e_i}{1 + ||a_i^t||^2} - \alpha_i^t 1_n) \chi_{i \in \{i^t, j^t\}}, \quad (1.15d) \)

where \( \psi_i^t = [J_i(v_i^t) - e_i^T(u_i^t - \alpha_i^t 1_n)]_+ \). Here, \( \chi_\mathcal{P} \) satisfies that \( \chi_\mathcal{P} = 1 \) if \( \mathcal{P} \) holds, and \( \chi_\mathcal{P} = 0 \), otherwise.

Therefore the proposed decentralized asynchronous algorithm for resolving the resource allocation problem (1.1) at each node \( i \) is formally outlined in Algorithm 1. In Algorithm 1, \( \alpha_i^t \), for \( i \) belonging to the set \( \mathcal{V} \), represents a diminishing step-size (local and stochastic) that relies on the frequency of updates made by node \( i \). Specifically, \( \alpha_i^t = 1/\Gamma_i^t \), where \( \Gamma_i^t \) signifies the cumulative number of updates executed by node \( i \) up to time \( t \), as stated in [31]. As each node \( i \) solely utilizes the locally determined quantity \( \Gamma_i^t \), there is no need for synchronization among the nodes' step-sizes, thus ensuring the fully decentralized nature of Algorithm 1. Furthermore, Algorithm 1 may minimize communication overhead and enhance communication efficiency due to its requirement of only a single communication instance per iteration. Ultimately, from a network adaptability standpoint, Algorithm 1 exhibits compatibility with the directed network and the gossip-based communication protocol explored in this chapter.

## Algorithm 1 Decentralized asynchronous algorithm based on the gossip communication protocol at each node $i \in \mathcal{V}$.

- **1: Initialization:** Each node $i$ commences with initial values of $x_i^0 \in \mathbb{R}$, $y_i^0 \in \mathbb{R}$, $k_i^0 \in \mathbb{R}^n$, $v_i^0 = y_i^0$, and $u_i^0 = k_i^0$.
- **2: for** $t=1, 2, 3, \dots$ **do**
- **3: Gossip-based communication:** In the strongly connected directed network $\mathcal{G}$, select randomly a single directed edge $(i^t, j^t)$ for the purpose of communication.
- **4: Consensus on the dual variable:** To proceed with the iteration, update the two intermediate state variables $v_i^t, u_i^t$ according to the following rules:
  $$
  \begin{cases}
  i = j^t : & \begin{cases} v_i^t = w_{i^t j^t} y_{i^t}^{t-1} + (1-w_{i^t j^t}) y_i^{t-1}, \\ u_i^t = w_{i^t j^t} k_{i^t}^{t-1} + (1-w_{i^t j^t}) k_i^{t-1}, \end{cases} \\ i \neq j^t : v_i^t = y_i^{t-1}, u_i^t = k_i^{t-1}.
  \end{cases}
  $$
- **5: Optimization on the primal variable:** To proceed with the iteration, update the local primal variable $x_i^t$ according to the following rule:
  $$
  x_i^t = \arg \min_{x_i \in \Omega_i} C_i(x_i) - v_i^t(x_i - r_i).
  $$
- **6: Optimization on the dual variable:** Update $y_i^t, k_i^t$ as follows:
  $$
  \begin{cases}
  i \in \{i^t, j^t\} : & \begin{cases} z_i^t = u_i^t - \alpha_i^t 1_n, \\ y_i^t = v_i^t - \frac{[J_i(v_i^t)-z_i^t]z_i^t^\top}{1+\|z_i^t\|^2} \alpha_i^t, \\ k_i^t = z_i^t + \frac{[J_i(v_i^t)-z_i^t]z_i^t^\top}{1+\|z_i^t\|^2} e_i, \end{cases} \\ i \notin \{i^t, j^t\} : y_i^t = y_i^{t-1}, k_i^t = k_i^{t-1}.
  \end{cases}
  $$
- **7: end for**

**Remark 1.2.** The measure of the memory resources consumed by an algorithm to execute, which varies with the length of the input, is defined as its space complexity. This metric is pivotal in assessing the algorithm's efficiency, regardless of its execution time. As seen in Algorithm 1, each node $i$ demands the allocation of an array of size $(\varsigma_1 n + \varsigma_2)$ to store quantities such as $x_i, y_i, k_i, w_{ij}, j \in \mathcal{N}_i^{\text{in}}$, and so on. Notably, $\varsigma_1$ and $\varsigma_2$ are constants that are independent of the node count $n$. Thus the space complexity of Algorithm 1 for a single node $i$ is $\mathcal{O}(cn)$, where $c$ represents the fundamental space unit, and $\mathcal{O}(\cdot)$ encapsulates a universal constant. Consequently, the overall space complexity required for Algorithm 1 scales as $\mathcal{O}(cn^2)$.

**Remark 1.3.** When applying Algorithm 1 to tackle the decentralized economic dispatch problems (EDPs) in power systems, as outlined in Section 1.2.2, it becomes apparent that solving an additional optimization problem at each time step, as depicted in (1.11), is not necessary. Instead, we can efficiently obtain the minimizer by utilizing \(x_i^t = \min\{\max\{\nabla C_i^{-1}(v_i^t), x_{i,\min}\}, x_{i,\max}\}\) as referenced in [28,31]. Here, \(\nabla C_i^{-1}\) represents the inverse function of \(\nabla C_i\), which is defined within the interval \([\nabla C_i^{-1}(x_{i,\min}), \nabla C_i^{-1}(x_{i,\max})]\). By adopting this approach, the computation of (1.11) can be achieved in a cost-effective way.

## 1.3.3 Notation simplification

To simplify notation, we consider the following equivalent form of (1.8):

\[
\min_{p \in \Sigma} b^T p, \text{ s.t. } f_i(p) \le 0, i = 1, ..., n, \tag{1.16}
\]

where \(p = (y, k^T)^T \in \mathbb{R}^{n+1}\) and \(b = (0, 1_n^T)^T\). Furthermore, \(f_i : \mathbb{R}^{n+1} \to \mathbb{R}\) is a convex function. For any integer \(t \ge 1\), define \(p_i^t = (y_i^t, (k_i^t)^T)^T\), \(i \in \mathcal{V}\). Subsequently, the algorithms (1.15a), (1.15c), and (1.15d) for addressing (1.16) can be expressed as follows: \(\forall i \in \mathcal{V}, t \ge 1\),

\[
p_i^t = h_i^t - \frac{[f_i(h_i^t)]_+}{\|\xi_i^t\|^2} \xi_i^t, i \in \{i^t, j^t\}, \tag{1.17a}
\]
\[
p_i^t = \sum_{j=1}^n W_{ij}^t p_j^{t-1}, i \notin \{i^t, j^t\}, \tag{1.17b}
\]

where \(h_i^t = \sum_{j=1}^n W_{ij}^t p_j^{t-1} - \alpha_i^t b\) for \(i \in \{i^t, j^t\}\). Additionally, the vector \(\xi_i^t \in \partial[f_i(h_i^t)]_+\) if \([f_i(h_i^t)]_+ > 0\) and \(\xi_i^t = \xi_i\) for some \(\xi_i \neq 0_{n+1}\) if \([f_i(h_i^t)]_+ = 0\). We denote \(\Xi_i = \{p \in \Sigma | f_i(p) \le 0\}\), \(\Sigma_0 = \Sigma_1 \cap \dots \cap \Sigma_n\), and \(\Sigma^* = \{\theta \in \Sigma_0 | b^T p \le b^T p', \forall p' \in \Sigma_0\}\).

Here, we can infer that the subgradient \(\xi_i^t\) remains consistently bounded within the set \(\Sigma\) as defined in (1.8), such that its norm satisfies \(\|\xi_i^t\| \le D, \forall i \in \mathcal{V}, t \ge 1\). Given the simplicity of this conclusion, we omit the corresponding proofs and direct the reader to Proposition 1 in [22]. Moreover, we can ascertain that (1.16) is viable and possesses a non-empty set of optimal solutions, that is, \(\Sigma_0 \neq \emptyset\) and \(\Sigma^* \neq \emptyset\).

### 1.4.1 Auxiliary results

It is noteworthy that the matrix sequence $\{W^t\}$ is both independent and identically distributed in accordance with Assumption 1.2. Then, the subsequent lemma is presented as follows.

**Lemma 1.1.** [32] Given that Assumption 1.2 is valid, we can deduce the following: (i) For each $W^t$ where $t \ge 1$, it possesses row-stochastic properties. Additionally, the corresponding expected matrix denoted as $\tilde{W} = E[W^t] = [\tilde{W}_{ij}] \in \mathbb{R}^{n \times n}$, exhibits row-stochastic characteristics. (ii) There exists a positive constant $\bar{\tau}$ such that $\forall i, j \in \mathcal{V}$, if $\tilde{W}_{ij} > 0$, then $\tilde{W}_{ij} > \bar{\tau}$. (iii) There exists a vector $\pi = [\pi_1, \dots, \pi_n]^T \in \mathbb{R}^n (\pi_i > 0, \forall i \in \mathcal{V})$ of $\tilde{W}$ satisfying that $\lim_{t \to \infty} (\tilde{W})^t = 1_n \pi^T, \pi^T \tilde{W} = \pi^T, \pi^T 1_n = 1$.

Let $E_i^t = \{i \in \{i^t, j^t\}\}$ denote the event that node $i$ performs an update at time $t$. We introduce the notation $\eta_i$ to represent the likelihood of event $E_i^t$, and it is given by $\eta_i = (1/n) + (1/n) \sum_{j \in \mathcal{N}_i^{in}} \kappa_{ij}, \forall i \in \mathcal{V}$. Here, $0 < \kappa_{ij} < 1$ signifies the probability that node $i$ is chosen by its incoming neighbor $j$ for communication. Then, we derive the following conclusions regarding the step-size $\alpha_i^t$, for all $t \ge 1$ and $i$ belonging to the set $\mathcal{V}$.
