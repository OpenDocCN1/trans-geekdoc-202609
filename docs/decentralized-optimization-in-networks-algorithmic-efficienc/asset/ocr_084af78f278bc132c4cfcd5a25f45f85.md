# ## 2.2.3 Network model

The interconnection framework facilitating the exchange between generators is formulated as a graph \(\mathcal{G} = (\mathcal{V}, \mathcal{E}, \mathbf{W})\). Here, \(\mathcal{V} = \{1, \dots, n\}\) denotes the set of nodes, each representing a generator. The set of edges, \(\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}\), comprises pairs of nodes that are interconnected. The presence of an edge \((i, j) \in \mathcal{E}\) signifies a communication channel between generators \(i\) and \(j\), enabling them to privately exchange messages. Consequently, \(i\) is deemed an inbound neighbor of \(j\), and conversely, \(j\) is an outbound neighbor of \(i\). The set of neighbors for generator \(i\) is denoted as \(\mathcal{N}_i = \{j \in \mathcal{V} | (j, i) \in \mathcal{E}\}\). The matrix \(\mathbf{W} = [w_{ij}] \in \mathbb{R}^{n \times n}\) represents a symmetric weighting scheme, where only the diagonal elements are non-zero. Additionally, the weights \(w_{ij}\) adhere to the following specified conditions:

\(\begin{cases} w_{ij} > 0, & \text{if } (i, j) \in \mathcal{E}, \\ w_{ij} = 0, & \text{otherwise.} \end{cases}\) (2.1)

# ## 2.2.4 EDP formulation

In the Economic Dispatch Problem (EDP), a smart network emerges by interconnecting \(n\) generators. The overarching aim of this network is to cater to the aggregate load while minimizing the cost of generation for each individual generator. As a result, the problem formulation can be mathematically articulated in the following manner:

\(\min_{\mathbf{x} \in \mathbb{R}^n} f(\mathbf{x}) = \sum_{i=1}^n f_i(x_i), \quad (2.2a)\)
\(\text{s.t. } \sum_{i=1}^n x_i = \sum_{i=1}^n c_i, \quad (2.2b)\)
\(\ell_i \le x_i \le u_i, \forall i = 1, \dots, n. \quad (2.2c)\)

Here, \(x_i \in \mathbb{R}\) indicates the power generated by generator \(i\), noting that each generator \(i\) only knows its own local cost function \(f_i : \mathbb{R} \to \mathbb{R}\). \(\mathcal{H} = \{ \mathbf{x} \in \mathbb{R}^n | \sum_{i=1}^n x_i = \sum_{i=1}^n c_i \}\) is the set of coupling constraints, similarly, we use the set \(\mathcal{X}_i = \{ x \in \mathbb{R} | \ell_i \le x_i \le u_i \}\) to characterize the range of limits for each generator's generation capacity. Therefore their Cartesian product can be naturally expressed as \(\mathcal{X} = \mathcal{X}_1 \times \mathcal{X}_2 \times \cdots \times \mathcal{X}_n\). Finally, \(\mathbf{x}^\star = [x_1^\star, x_2^\star, \dots, x_n^\star]^T\) is the optimal solution (i.e., \(f(\mathbf{x}^\star) = f^\star\) is the optimal value), and \(\Omega = \mathcal{X} \cap \mathcal{H}\) is the feasible set of problem (2.2). Hence, \(\mathcal{X}^\star = \{ \mathbf{x} \in \Omega | \sum_{i=1}^n f_i(x_i) = f^\star \}\) is used to denote the optimal solution, assuming that it is a non-empty set.
