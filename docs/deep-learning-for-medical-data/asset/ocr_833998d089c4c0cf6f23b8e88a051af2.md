# 2.2.1 Background

In the mathematical model of CNNs and G-CNNs introduced in Cohen and Welling (2016), input images and output segmentation masks are considered to be functions $f: Z^2 \rightarrow R^K$, where $K$ denotes the number of channels, and $f$ is implicitly assumed to be zero outside some rectangular domain. A standard convolution*2 of an input $f$ with filter $\psi$ is defined as:

```
$[f * \psi](x) = \sum_{y \in Z^2} \sum_{k=1}^{K} f_k(y)\psi_k(x-y). \quad (2.1)$
```

G-CNNs are a generalization of CNNs that are equivariant under more general symmetry groups, such as the group $G = p4$ of 90° rotations, or $G = p4m$ which additionally includes reflection.
