# ## 5.A EXPERIMENTAL SETUP

We use PyTorch (Paszke et al., 2017) for all our experiments.

# ### 5.A.1 Vision Experiments

In our vision experiments, we employ the ResNet-50 v2 architecture (He et al., 2016b), and adjust the first convolutional layer in such a way that the size of the feature map stays constant. Thus, the first convolutional layer uses a kernel size of 5, a stride of 1 and a padding of 2. Additionally, we do not employ batch normalization (Loffe and Szegedy, 2015b).

We train our model on 8 GPUs (GeForce 1080 Ti) with a minibatch of 16 images. We train it for 300 epochs using Adam (Kingma and Ba, 2014b) and a learning rate of 1.5e-4 and use the same random in all our experiments.

For the self-supervised training using the InfoNCE objective, we need to contrast the predictions of the model for its future representations against negative samples. We draw these samples uniformly at random from across the input batch that is being evaluated. Thus, the negative samples can contain samples from the same image at different patch locations, as well as different images. We found that including the positive sample (i.e the future representation that is currently to be predicted) in the negative samples did not have a negative effect on the final performance. For each evaluation of the InfoNCE loss, we use 16 negative samples and predict up to $k=5$ rows into the future. For contrasting patches against one another, we spatially mean-pool the representations of each patch.
