# 5.4 EXPERIMENTS

We test the applicability of the GIM approach to the visual and audio domain. In both settings, a feature-extraction model is divided by depth into modules and trained without labels using GIM. The representations created the final (frozen) module are then used as the input for a linear classifier, whose accuracy provide us with a proxy for the quality and generalizability of the representations created by the self-supervised model.
