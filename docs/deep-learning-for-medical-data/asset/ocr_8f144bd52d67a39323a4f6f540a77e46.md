**Figure 6.6:** By using a 1-dimensional matrix factorization for a SQUAD-factorized distribution, we can visualize the type of (stochastic) activation functions learned by the method. The right y-axis indicates the value and in blue the most likely value is shown, and the grey dots represent samples from the neuron. The red line depicts the expected output of the neuron. The shape of the expected output is akin to a peaky sigmoid activation, and similar shapes are found in the other neurons of the network as well. This provides food for thought on the design of activation functions for conventional neural networks.
