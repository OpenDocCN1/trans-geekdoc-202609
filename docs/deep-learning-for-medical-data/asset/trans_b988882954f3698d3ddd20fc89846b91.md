正确预测与错误预测的排名仍然是一个活跃的研究领域。

深度潜变量模型（DLVMs，图 1.1）通过假设存在潜变量 $z$ 来处理问题，其中 $p(z|x)$ 中的不确定性会影响对目标预测的置信度。近期，人们提出了变分推断形式的高效推理算法，通过优化推理网络来预测变分分布的参数，从而近似一个原本不可处理的分布（Kingma and Welling, 2013; Rezende et al., 2014; Alemi et al., 2016; Achille and Soatto, 2016）。

![](img/3013a5e7af0c305d337644a32207e3ef_21_0.png)

在第三部分中，我们将探索如何量化深度学习中的不确定性。我们通过 Tishby 等人（2000）提出的信息瓶颈（IB）视角来处理这一问题。信息瓶颈 $I(y,z; \theta) - \beta I(x,z; \theta)$ 被优化以最大化 $z$ 与 $y$ 之间的互信息，同时利用 Alemi 等人（2016）以及 Achille 和 Soatto（2016）所示的变分推断方案最小化 $z$ 与 $x$ 之间的互信息。在马尔可夫假设 $p(z,x,y) = p(z|x)p(y|x)p(x)$ 下，我们推导出以下下界：

```
$I(y,z;;theta) - \beta I(x,z;;theta) \geq \mathcal{L} = \frac{1}{N}\sum_{n=1}^N E_{p(z|x_n)}[\log q_\theta(z|x_n)] - \beta D_{KL}[p_\theta(z|x_n)||r(z)],$
```

其中对于 $E_{p(z|x_n)}$ 的期望通常使用单个蒙特卡洛样本进行估计，而 $r(z)$ 是边缘分布 $p(z)$ 的变分近似。$r(z)$ 的常用选择是简单分布，如标准正态分布。Alemi 等人（2016）和 Achille 和 Soatto（2016）继续证明，Kingma 和 Welling（2013）以及 Rezende 等人（2014）提出的变分自动编码器（VAE）证据下界（ELBO）当 $y=x$ 且 $\beta=1$ 时是 IB 的特例。

```
$I(z,i) - I(z,i) \geq E_{p(z|x_n)}[\log q_\theta(z|x_n)] - D_{KL}[p_\theta(z|x_n)||r(z)],$
```

其中 $i$ 代表数据点 $x_i$ 的标识。有趣的是，VAE 视角认为该下界优化的是变分分布 $q(z|x)$，而 IB 则规定 ELBO 中的 $q(z|x)$ 不是变分后，而是真实的编码器 $p(z|x)$，相反，$p(y|z)$ 和 $p(z)$ 是用变分对应项近似的分布。然而，在条件后验 $p(y|x)$ 上推导 ELBO会导致近似后验 $q(z|x)$ 与真实后验 $p(z|x)$ 之间的 KL 散度（后者在测试时是不可用的），而不是先验 $p(z)$。

另一种，方程 1.1 可以被解释为一种领域转换的 beta-VAE（Higgins et al., 2016），其中输入图像被编码到潜空间并解码到目标领域。正如 Alemi 等人（2017）所言，拉格朗日乘子 $\beta$ 控制了速率与失真之间的平衡。然而，这并不是通过利用 Jensen 不等式在条件似然性 $p(y|x)$ 上推导 ELBO 时自然产生的。

# 用于数字病理学的旋转等变 CNN

## 2.1 引言

数字病理学领域正在快速发展，这归功于显微成像硬件的最新进展，允许将玻片数字化为全切片图像（WSIs）。这种数字化促进了图像分析算法来协助和自动化诊断任务。一种证明有效的方法是卷积神经网络（CNN），这是一种深度学习模型，它在从全切片图像中提取的补块（patches）上进行训练。这些基于补块的预测聚合形成了切片级表示，模型利用该表示来识别转移、癌症分期或诊断并发症。这种性能是通过使用最初为自然图像设计的现成 CNN 架构实现的（Litjens et al., 2017）。这些模型的有效性可以在很大程度上归于卷积层中参数的高效共享。结果是局部模式独立于其空间位置进行编码。这种特性被称为平移等变，输入偏移会导致输出产生预测的偏移。

与自然图像相反，WSIs 不仅具有平移对称性，还具有旋转和反射对称性。CNN 没有利用这些对称性，结果上发现它们将大部分参数花费在了滤波器的旋转和反射副本上（Zeiler \et al., 2014）。此外，我们发现训练于病理数据的 CNN 在输入旋转和反射下预测会出现异常波动。在模型中强制等变性预计减少这种不稳定，并通过改进参数共享降低过拟合风险。

为了编码这些对称性，我们利用了旋转等变 CNN 的最新发现（Cohen and Welling, 2016; Worall \et al., 2017; Weiss \et al., 2017），这是一个机器学习社区感兴趣的话题。这些方法在有限数据集规模下显示出很强的泛化能力，并且对对抗扰动更具鲁性（Dumont \et al., 2018）。我们提出了一种对 $90^{\circ}$ 旋转和反射等变的全卷积补块分类模型，使用了 Cohen 和 Welling（2016）提出的方法。我们在 Camelion16 基准（Ehtesami Bejnordi \et al., 2017）上评估了该模型，显示其在任务上优于类似的 CNN。

由于切片级指标掩盖了补块级模型的相对性能，我们进一步在补块级任务上进行了验证。在该领域，目前没有基准能匹配 Camelion16 的高、、高质量和多样。因此，我们提出了 PatchCamelyon (PCam)，这是一个源自 Camelion16 的大规模补块级数据集。通过该数据集，我们证明了与相应的标准 CNN 相比，提出的模型在输入旋转和反射下更准确、更鲁棒。

我们工作的贡献如下：
- **(1)** 我们提出了一种利用病理学固有对称性的新深度学习模型$^{1}$
- **(2)** 证明了旋转等变提高了模型的可靠性，并提供了一个新的大规模病理数据集用于模型评估。

$^{1}$ PCam 详情和数据见 https://github.com/basveeling/pcam。等变层的实现见 https://github.com/basveeling/keras.gcnn。
