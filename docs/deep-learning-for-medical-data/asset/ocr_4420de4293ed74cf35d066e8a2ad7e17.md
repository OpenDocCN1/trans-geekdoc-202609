To impose a flexible, multi-modal distribution over $\mathbf{z}$, we first make a mean-
field assumption $p(\mathbf{z}|\mathbf{x}) = \prod_k p(z_k|\mathbf{x})$. We then quantify the domain of each
the $K$ latent variables $z_k$ such that only a small set of potential values
remain: $z_k \in \{v_1, \dots, c\}$ $\forall k$ with, e.g., $C=11$. We use the
quantization scheme, defined by $\mathbf{v}$, for all the latents. The specific scheme
is considered part of the prior, and is discussed in figure 6.3.

Although the number of values that $\mathbf{z}$ can take is relatively small, the number grows exponentially. We thus take to
a monte-carlo estimation scheme, when sampling over all possible values of
mathbf{z}$. To optimize the parameters $\theta$ with Stochastic Gradient Descent (SGD), we
need to derive a fully differentiable sampling scheme that allows us to sample
values of $\mathbf{z}$. To formulate this, we re-parametrize the expectation over $\mathbf{z}$ in
equ 6.1 using a set of variables $s_k \in \{1, \dots, C\}$ which index the value
vector, allowing us to use a softmax function to represent the distribution
over:

```
$p_{	heta}(z_k|\mathbf{x}) = v_c \triangleq p_{\theta}(s_k=c|\mathbf{x}) = \text{softmax}(\mathbf{W}\mathbf{x} + \mathbf{b}).quad(6.2)
```

These indexing values are used in conjunction with variables $\mathbf{v}$ as input in
q_{	heta}(\mathbf{y}|\mathbf{x})$, which is modelled with a small network $f_{	heta}(\)$: (abusing notation to
element-wise indexing with $\mathbf{s}$):

```
$\mathcal{L}_{\text{error}} = \mathbb{E}_{\sim p_{	heta}}[\log f_{	heta}(\mathbf{s})]).
```

To enable sampling from the discrete variables $\mathbf{s}$, we use the Gumbel-Max trick
(Gumbel, 1954), re-parameterizing the expectation $\mathbb{E}_{\mathbf{s}-p}$ with
uniform noise $\epsilon \sim U(0,1):

```
$\mathcal{L}_{\text{error}} = \mathbb{E}_{c} \left[ \log f_{\theta} \left( \mathbf{v} \cdot [\arg \max_c p_{\theta}(\mathbf{s}|\mathbf{x}), \epsilon] \right) \right].quad(6.3)
```

As the argmax is not differentiable, we approximate this expectation using the
nGumbel-Softmax trick (Maddison et al., 2016; Jang et al., 2016), which gen-
erates samples that smoothly deform into one-hot samples as the softmax temper-
ature $\tau$ approaches 0. Using the inner product $(\cdot)$ of the approximate
one-hot samples and $\mathbf{v}$, we create samples from $\mathbf{z}$:

```
$\mathcal{L}_{\text{error}} \approx \mathbb{E}_{c} [\log f_{\theta} (\mathbf{v} \cdot \text{gumb}(p_{\theta}(\mathbf{s}|\mathbf{x}), \epsilon))].quad(6.4)
```
