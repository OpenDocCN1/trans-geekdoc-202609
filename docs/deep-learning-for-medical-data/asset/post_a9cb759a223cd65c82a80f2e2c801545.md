
# PREDICTIVE UNCERTAINTY THROUGH QUANTIZATION

Variational inference relies on a tractable class of distributions that can be optimized to closely resemble the true distribution (fig. 1.2), and it is hypothesized that more flexible classes lead to more faithful approximations and thus better performance (Jordan et al., 1999). To explore this hypothesis, we propose a novel tractable class of highly flexible variational distributions. Considering that neural networks with low-precision activations exhibit good performance (Holi and Hwang, 1993; Hubara et al., 2016), we make the modeling assumption that latent variables can be expressed under a strong quantization scheme, without loss of predictive fidelity. If this assumption holds, it becomes tractable to model a scalar latent variable with a flexible multinomial distribution over the quantization bins (fig. 6.1).

By repositioning the variational distribution from a potentially limited description of moments, as found in commonly applied conjugate distributions, to a direct expression of probabilities per discrete value, a variety of benefits arise. As the support of the discrete distribution is constrained, the method does not suffer from normalization issues, relieving the model from batch normalization techniques (Loffe and Szegedy, 2015a). Furthermore, interesting priors can be explored and the model is able to learn unique activation functions per neuron.

## 6.1 METHOD

In this work, we follow the IB interpretation of the bound in equation 1.1 and leave the evaluation of our proposed variational inference scheme in other models like the VAE for further work. At the heart of our proposal lies the assumption that neural networks can be effective under strong activation quantization schemes. We start with presenting the derivation of the model in the context of a single latent-layer with an information bottleneck. Following the single data-point loss in equation 1.1 and dropping the subscript $n$ for clarity, we obtain:

```
$\mathcal{L} = \mathcal{L}_{\text{error}} = \mathbb{E}_{p_{\theta}(\mathbf{z})}[\log q_{\theta}(\mathbf{y}|\mathbf{z})] - \beta D_{\text{KL}}(p_{\theta}(\mathbf{z}|\mathbf{x})||r(\mathbf{z}))$.quad(6.1)
```

To impose a flexible, multi-modal distribution over $\mathbf{z}$, we first make a mean-field assumption $p(\mathbf{z}|\mathbf{x}) = \prod_k p(z_k|\mathbf{x})$. We then quantify the domain of each of the $K$ latent variables $z_k$ such that only a small set of potential values remain: $z_k \in \{v_1, \dots, c\}$ $\forall k$ with, e.g., $C=11$. We use the quantization scheme, defined by $\mathbf{v}$, for all the latents. The specific scheme is considered part of the prior, and is discussed in figure 6.3.

Although the number of values that $\mathbf{z}$ can take is relatively small, the number grows exponentially. We thus take to a monte-carlo estimation scheme, when sampling over all possible values of $\mathbf{z}$. To optimize the parameters $\theta$ with Stochastic Gradient Descent (SGD), we need to derive a fully differentiable sampling scheme that allows us to sample values of $\mathbf{z}$. To formulate this, we re-parametrize the expectation over $\mathbf{z}$ in equation 6.1 using a set of variables $s_k \in \{1, \dots, C\}$ which index the value vector, allowing us to use a softmax function to represent the distribution over:

```
$p_{\theta}(z_k|\mathbf{x}) = v_c \triangleq p_{\theta}(s_k=c|\mathbf{x}) = \text{softmax}(\mathbf{W}\mathbf{x} + \mathbf{b}).quad(6.2)
```

These indexing values are used in conjunction with variables $\mathbf{v}$ as input in $q_{\theta}(\mathbf{y}|\mathbf{x})$, which is modelled with a small network $f_{\theta}(\cdot)$: (abusing notation to element-wise indexing with $\mathbf{s}$):

```
$\mathcal{L}_{\text{error}} = \mathbb{E}_{\sim p_{\theta}}[\log f_{\theta}(\mathbf{s})]).
```

To enable sampling from the discrete variables $\mathbf{s}$, we use the Gumbel-Max trick (Gumbel, 1954), re-parameterizing the expectation $\mathbb{E}_{\mathbf{s}-p}$ with uniform noise $\epsilon \sim U(0,1)$:

```
$\mathcal{L}_{\text{error}} = \mathbb{E}_{c} \left[ \log f_{\theta} \left( \mathbf{v} \cdot [\arg \max_c p_{\theta}(\mathbf{s}|\mathbf{x}), \epsilon] \right) \right] \right].quad(6.3)
```

As the argmax is not differentiable, we approximate this expectation using the Gumbel-Softmax trick (Maddison et al., 2016; Jang et al., 2016), which generates samples that smoothly deform into one-hot samples as the softmax temperature $\tau$ approaches 0. Using the inner product $(\cdot)$ of the approximate one-hot samples and $\mathbf{v}$, we create samples from $\mathbf{z}$:

```
$\mathcal{L}_{\text{error}} \approx \mathbb{E}_{c} [\log f_{\theta} (\mathbf{v} \cdot \text{gumb}(p_{\theta}(\mathbf{s}|\mathbf{x})))].quad(6.4)
```

In practice, we anneal $\tau$ from 1.0 to 0.5 during the training process, as proposed by Yang et al. (2017) to reduce variance initially. To conclude our derivation, we use a fixed prior $r(z)$ as shown in figure 6.3. We can then derive the KL term analytically using the fact that the KL divergence is additive for independent variables, we get our final loss:

```
$\mathcal{L}=\mathbb{E}_{e} \left[\log f_{\theta} \left( \mathbf{v} \cdot e\right)\right]-\sum_{k=1}^{K}\sum_{c=1}^{C} p_{\theta}(s_{k}=c|x)\log \frac{p_{\theta}(s|x)}{r(z)}$.quad(6.5)
```

For this work, we will refer to the latents as $z$, for clarity. At this time, we can approximate the predictive function $p(y^*|x^*)$ for a new data-point $x^*$ by taking $T$ samples from the latent variables i.e. $\hat{z}_{t}\sim p(z|x^*)$, and averaging the predictions for $y^*$:

```
$p_{\theta}(y^*|x^*) \approx \int q_{\theta}(y^*|z)p_{\theta}(z|x^*)dz \approx \frac{1}{T}\sum_{t=1}^{T}q_{\theta}(\hat{z}_{t}).quad(6.6)
```

A downside of mean-field variational approximations is that latents are assumed to be uncorrelated. We can bring correlation to the latents, extend the flexibility of the proposed method, by creating a hierarchical set of latent variables. We maintain a mean-field assumption for the prior, and the joint posterior distribution of L layers as factors follows:

```
$p_{\theta}(z_{1,...,z_{L})=p_{\theta}(z_{L}|z_{L-1})\cdots p_{\theta}(z_{1}|x).\quad(6.7)
```

Interestingly, the strong quantization in our method can itself be considered an additional information bottleneck, as it upper-bounds the number of bits per latent variable. These bottlenecks are hypothesized to have a beneficial effect on generalization (Tishby et al., 2000; Achille and Soatto, 2016; Alemi et al., 2017; Alemi et al., 2016), and we can directly control this bottleneck by varying the number of quantization bins.
