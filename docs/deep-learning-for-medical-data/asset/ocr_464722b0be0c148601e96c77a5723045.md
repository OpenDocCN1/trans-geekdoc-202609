features come from a pair of consecutive patches versus a pair of randomly selected patches:

```
$f_W(\mathbf{z}_a, \mathbf{z}_b) = \exp\left(\mathbf{z}_a^T\mathbf{W}\mathbf{z}_b\right) \quad (4.1)$
```

We call this the contrastive model. The contrastive model is trained by taking one patch's features $\mathbf{z}_i$ and a bag $\mathcal{X}$ filled with the consecutive patch features $\mathbf{z}_i$ as well as randomly selected patch features drawn from the training dataset. The contrastive model $f_W(\cdot)$ and feature model $e_{\theta}(\cdot)$ are jointly trained to solve the classification task of selecting the correct contrastive patch from the bag, minimizing this loss:

```
$\mathcal{L} = -\log \frac{f(\mathbf{z}_l, \mathbf{z}_{l+1})}{\sum_{\\mathbf{z}_i \in \mathcal{X}} f(\mathbf{z}_l, \mathbf{z}_i)} \quad (4.2)$
```

Which can be minimized using a typical mini-batch stochastic gradient descent method, using mini-batches consisting of multiple bags.

To further improve the predictive quality of the features we contrast patches varying a number of steps ahead by jointly train multiple contrastive models. We can simply learn a model $f_k(\cdot)$ for each step size $k$, while using the same feature extraction model. As larger steps make the task more difficult, we introduce a context aggregation model $\mathbf{c}_l = a(\mathbf{z}_0, \cdots, \mathbf{z}_l)$ shared among the steps. This allows the contrastive model $f_{W_k}(\mathbf{c}_l, \mathbf{z}_{l+k})$ to consider a brief history of the signal, encoded into $\mathbf{c}_l$, to predict which patch $\mathbf{z}_i$ in the bag is the consecutive one. This results in the loss:

```
$\mathcal{L}_{CPC} = -\sum_k \log \frac{f(\mathbf{c}_l, \mathbf{z}_{l+k})}{\sum_{\mathbf{z}_i \in \mathcal{X}} f(\mathbf{c}_l, \mathbf{z}_i)} \quad (4.3)$
```

To extend the method to 2D images, we have to induce an arbitrary ordering of patches on an image. We can consider a top-down approach where we contrast patches underneath the patch of focus. In the 2D regime the context aggregation model $\mathbf{c} = a(-)$ can take shape of a small autoregressive PixelCNN-styleOord et al., 2016 neural network, where we are careful to maintain a receptive field of solely of patches that are above and up to $w$ steps to the side of the patch of focus, $\mathbf{z}_{i,j} = a(\mathbf{z}_{y\le i, x=j\pm w})$.
