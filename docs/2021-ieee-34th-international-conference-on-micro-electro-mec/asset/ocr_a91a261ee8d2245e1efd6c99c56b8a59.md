Predictive models were developed using eight representative parameters obtained from the broadband impedance spectra, i.e. using the resistance values at 20 Hz, 336 kHz, 2 MHz, and the reactance values at 189 kHz, 299 kHz, 710 kHz, 1.19 MHz, 2 MHz. First, principal component analysis (PCA) was applied for classification of multivariate data and to reduce the dimensionality of the original data set. PCA is a powerful unsupervised analysis tool that allows a qualitative survey of the discriminating power of the sensor [10]. The linear discrimination analysis (LDA) was performed as a supervised pattern recognition tool meaning that the correct classification is known for each object. The

resultant principal components in the PCA were used as input variables to the LDA to quantitatively identify different test analytes [11]. A cross-validation method was used to estimate the identification. To quantify concentrations of individual vapor in a mixture, we applied partial least squares (PLS) with five latent variables (LVs) [8]. Multivariate data processing (PCA, LDA and PLS) was carried out in MATLAB programs in this study.

# RESULTS AND DISCUSSION

The surface morphology of the Ti3C2Tx based sensor is shown in Fig. 1b, which reveals a uniform deposition of the Ti3C2Tx film. A cross-sectional SEM image of the Ti3C2Tx film is shown in Fig. 1c, which is produced through vacuum filtration of the same Ti3C2Tx solution used for the sensor fabrication. The observed layered structure is due to the ordered stacking of individual layers of Ti3C2Tx, which results in increased surface-to-volume ratio, potentially contributing to a large sensing response. The Ti3C2Tx based sensor was exposed to eight different VOCs (i.e. methanol (MeOH), ethanol (EtOH), acetone, isopropanol (IPA), acetonitrile (MeCN), dichloromethane (DCM), hexane, and toluene (TOL)) with different concentrations from 100 ppm to 800 ppm, and the broadband impedance spectra were measured.
