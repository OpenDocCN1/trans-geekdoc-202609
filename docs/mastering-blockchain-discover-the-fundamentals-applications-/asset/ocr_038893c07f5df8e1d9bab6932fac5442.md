The sender and the recipient share this secret key, which must be kept secure. Symmetric key algorithms are efficient and fast but suffer from the challenge of securely distributing and managing the secret key.

+   - **Asymmetric Keys:** Asymmetric or public key cryptography uses a pair of related keys—a public key and a private key. The public key is openly shared with others in the network, while the private key is kept secret and known only to the owner. Messages encrypted with the public key can only be decrypted with the corresponding private key, and vice versa. Asymmetric key algorithms offer enhanced security and address the challenges of key distribution in symmetric key cryptography.

# CRYPTOGRAPHIC HASH FUNCTIONS

Cryptographic hash functions are vital in blockchain technology for maintaining the integrity of data and ensuring the security of the blockchain. Here are some key aspects of cryptographic hash functions:

+   a) **Deterministic:** A hash function always produces the same hash value for the same input. Even a slight change in the input will result in a significantly different hash value.
+   b) **One-Way:** It is computationally infeasible to derive the original input from the hash value. In other words, given a hash value, it is nearly impossible to reverse-engineer the original input.
