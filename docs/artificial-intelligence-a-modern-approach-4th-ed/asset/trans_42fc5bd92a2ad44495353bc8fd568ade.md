
因此，尽管 HMM 在从语音识别到分子生物学等众多领域都有许多用途，但它们在表示复杂过程的能力上存在根本性限制。在[第2章](#Chapter02-00.xhtml)中引入的术语中，HMM 是一种原子表示：世界的状态没有内部结构，只是简单地用整数标记。[第14.5节](#Chapter14-05.xhtml#sec14-5)展示了如何使用动态贝叶斯网络——一种分解表示——来建模具有多个状态变量的领域。下一节将展示如何处理具有连续状态变量的领域，这当然会导致无限状态空间。

## 14.4 卡尔曼滤波器

想象一下在黄昏时观看一只小鸟穿过茂密的丛林树叶飞行：你瞥见短暂、间歇性的运动闪现；你努力猜测鸟在哪里以及它接下来会出现在哪里，以免失去它。或者想象你是一名二战雷达操作员，凝视着屏幕上每10秒出现一次的微弱、游移的信号点。或者，更进一步地，想象你是开普勒，试图从一组在不规则且测量不精确的时间间隔内取得的高度不准确的角度观测中重建行星的运动。

在所有这些情况下，你都在进行滤波：根据随时间推移的噪声观测来估计状态变量（这里是运动物体的位置和速度）。如果变量是离散的，我们可以用隐马尔可夫模型来建模该系统。本节研究处理连续变量的方法，使用一种名为卡尔曼滤波的算法，以其发明者之一鲁道夫·卡尔曼命名。

*卡尔曼滤波*

鸟的飞行可能由每个时间点的六个连续变量指定；三个用于位置（`Xt`、`Yt`、`Zt`）和三个用于速度 $({\overset{˙}{X}}_{t},{\overset{˙}{Y}}_{t},{\overset{˙}{Z}}_{t})$。我们需要合适的条件密度来表示转移和传感器模型；与[第13章](#Chapter13-00.xhtml)中一样，我们将使用线性-高斯分布。这意味着下一个状态 `Xt+1` 必须是当前状态 `Xt` 的线性函数，外加一些高斯噪声，这一条件在实践中被证明是相当合理的。例如，考虑鸟的 X 坐标，暂时忽略其他坐标。设观测之间的时间间隔为 `Δ`，并假设该间隔内速度恒定；则位置更新由 $X_{t + \text{Δ}} = X_{t} + \overset{˙}{X}\text{Δ}$ 给出。加上高斯噪声（以考虑风的变化等），我们得到一个线性-高斯转移模型：

$\left. P(X_{t + \Delta} = x_{t}{}_{+ \Delta} \middle| X_{t} = x_{t},\,{\overset{.}{X}}_{t} = {\overset{.}{x}}_{t}) = N(x_{t}{}_{+ \Delta};x_{t} + {\overset{.}{x}}_{t}\Delta,\sigma^{2}). \right.$

具有位置向量 `Xt` 和速度 $\mathbf{\overset{˙}{X}}_{t}$ 的系统的贝叶斯网络结构如图[图14.9](#Chapter14-04.xhtml#fig14-9)所示。请注意，这是一种非常特定的线性-高斯模型形式；一般形式将在本节后面描述，并涵盖了超出第一段简单运动示例的广泛应用。读者可能希望查阅[附录A](#Appendix-A-00.xhtml#app-A)了解高斯分布的一些数学性质；就我们目前的目的而言，最重要的是 `d` 个变量的多元高斯分布由 `d` 个元素的均值 `μ` 和 `d x d` 协方差矩阵 `∑` 指定。

### 14.4.1 更新高斯分布

在[第13章](#Chapter13-00.xhtml)的[第441页](#Chapter13-02.xhtml#page_441)上，我们提到了线性-高斯分布族的一个关键性质：它在贝叶斯更新下保持封闭。（也就是说，给定任何证据，后验仍然在线性-高斯族中。）这里我们在时间概率模型中滤波的背景下精确地说明这一说法。所需的性质对应于[公式（14.5）](#Chapter14-02.xhtml#eq14-5)中的两步滤波计算：

1. 如果当前分布 `P(Xt|e1:t)` 是高斯分布且转移模型 `P(Xt+1|xt)` 是线性-高斯，则由

$\left. \mathbf{P}(X_{t + 1} \middle| \mathbf{e}_{1:t}) = {\int_{\mathbf{x}_{t}}\left. \mathbf{P}(\mathbf{X}_{t + 1} \middle| \mathbf{x}_{t}) \right.}\begin{matrix} \left. P(\mathbf{x}_{t} \middle| \mathbf{e}_{1:t})d\mathbf{x}_{t} \right. & {\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.17)} \\ \end{matrix} \right.$

给出的单步预测分布也是一个高斯分布。

2. 如果预测 `P(Xt+1|e1:t)` 是高斯分布且传感器模型 `P(et+1|Xt+1)` 是线性-高斯，则在对新证据进行条件化后，更新后的分布

$\begin{matrix} \left. \mathbf{P}(\mathbf{X}_{t + 1} \middle| \mathbf{e}_{1:t + 1}) = \alpha\mathbf{P}(\mathbf{e}_{t + 1} \middle| \mathbf{X}_{t + 1})\mathbf{P}(\mathbf{X}_{t + 1} \middle| \mathbf{e}_{1:t}) \right. & {\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.18)} \\ \end{matrix}$

也是一个高斯分布。

因此，卡尔曼滤波的 `FORWARD` 算子接受一个由均值 `μt` 和协方差 `∑t` 指定的高斯前向消息 `f1:t`，并产生一个新的由均值 `μt+1` 和协方差 `∑t+1` 指定的多元高斯前向消息 `f1:t+1`。因此，如果我们从高斯先验 `f1:0 = P(X0) = N(μ0,∑0)` 开始，使用线性-高斯模型进行滤波会产生所有时间的高斯状态分布。

这似乎是一个漂亮、优雅的结果，但为什么它如此重要？原因在于，除了这种等少数特殊情况外，使用连续或混合（离散和连续）网络进行滤波会产生状态分布，其表示会随时间无界增长。这一说法在一般情况下不容易证明，但练习 14.KFSW 展示了简单示例中会发生什么。

### 14.4.2 一个简单的单维示例

我们说过卡尔曼滤波器的 `FORWARD` 算子将一个高斯映射为一个新的高斯。这转化为从之前的均值和协方差计算新的均值和协方差。在一般（多元）情况下推导更新规则需要相当多的线性代数，因此我们现在将坚持一个非常简单的单变量情况，并稍后给出一般情况的结果。即使对于单变量情况，计算也有些繁琐，但我们认为它们值得一看，因为卡尔曼滤波器的有用性与高斯分布的数学性质密切相关。
