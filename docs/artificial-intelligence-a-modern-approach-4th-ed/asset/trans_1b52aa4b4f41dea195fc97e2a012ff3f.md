
$\\begin{matrix} {\\mathbf{f}\_{1:t + 1}\\text{~=~}\\alpha\\,\\,\\mathbf{O}\_{t + 1}\\mathbf{T}^{\\top}\\mathbf{f}\_{1:t}} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.12)} \\\\ \\end{matrix}$

且向后 [方程 (14.9)](#Chapter14-02.xhtml#eq14-9) 变为

$\\begin{matrix} {\\mathbf{b}\_{k + 1:t}\\text{~=~}\\mathbf{T}\\mathbf{O}\_{k + 1}\\,\\mathbf{b}\_{k + 2:t}.} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.13)} \\\\ \\end{matrix}$

由这些方程可知，将前向-后向算法 [图 14.4](#Chapter14-02.xhtml#fig14-4) 应用于长度为 `t` 的序列，其时间复杂度为 O(`S`2`t`)，因为每个步骤都需要将一个 `S`\-element 向量与一个 `S` × `S` 矩阵相乘。空间需求为 O(`S`t`)，因为前向传递存储了 `t` 个大小为 `S` 的向量。

除提供 HMMs 滤波和平滑算法的优雅描述外，矩阵形式还揭示了改进算法的机会。第一个是对前向-后向算法的简单变体，允许平滑在与序列长度无关的常数空间中进行。思想是，针对特定时间片 `k` 的平滑需要同时存在前向和后向消息 `f1:k` 和 `bk+1:t`，根据 [方程 (14.8)](#Chapter14-02.xhtml#eq14-8)。前向-后向算法通过存储前向传递计算得到的 `fs` 来实现这一点，以便在后向传递期间可用。另一种实现方式是使用单次传递同时向同一方向传播 `f` 和 `b`。例如，“前向”消息 `f` 可以通过操纵 [方程 (14.12)](#Chapter14-03.xhtml#eq14-12) 使其在另一方向工作而向后传播：

`f[1 : t] = α′(T⊤)(−1)O[t + 1](−1)f[1 : t + 1]`.

修改后的平滑算法首先运行标准前向传递以计算 `ft:t`（忘记所有中间结果），然后同时对 `b` 和 `f` 运行后向传递，使用它们在每一步计算平滑估计。由于每个消息只需要一份拷贝，存储需求是常数（即与 `t`、序列长度无关）。该算法有两个重要限制：它要求转移矩阵可逆，且传感器模型没有零值——也就是说，每个观测在每个状态下都可能出现。

矩阵形式揭示的第二个改进领域是固定滞后的在线平滑。平滑可以在常数空间中完成这一事实表明应该存在一种高效的递归在线平滑算法——即其时间复杂度与滞后长度无关的算法。假设滞后为 `d`；也就是说，我们在时间片 `t – d` 进行平滑，其中当前时间为 `t`。根据 [方程 (14.8)](#Chapter14-02.xhtml#eq14-8)，我们需要计算

`α f[1 : t − d] × b[t − d + 1 : t]`

对于切片 `t – d`。然后，当新的观测到来时，我们需要计算

`α f[1 : t − d + 1] × b[t − d + 2 : t + 1]`

对于切片 `t – d + 1`。这如何增量完成？首先，我们可以使用标准滤波过程 [方程 (14.5)](#Chapter14-02.xhtml#eq14-5) 从 `f1:t−d` 计算 `f1:t−d+1`。

增量计算后向消息更棘手，因为旧的后向消息 `bt−d+1:t` 与新的后向消息 `bt−d+2:t+1` 之间没有简单的关系。相反，我们将研究旧的后向消息 `bt−d+1:t` 与序列前端的后向消息 `bt+1:t` 之间的关系。为此，我们将 [方程 (14.13)](#Chapter14-03.xhtml#eq14-13) 应用 `d` 次得到

$\\begin{matrix} {\\mathbf{b}\_{t - d + 1:t} = \\,\\left( {\\prod\\limits\_{i = t - d + 1}^{t}{\\mathbf{T}\\mathbf{O}\_{i}}} \\right)\\mathbf{b}\_{t + 1:t}\\text{~=~}\\mathbf{B}\_{t - d + 1:t}\\mathbf{1}\\text{,}} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.14)} \\\\ \\end{matrix}$

其中矩阵 `Bt−d+1:t` 是 `T` 和 `O` 矩阵序列的乘积，而 `1` 是一个全 1 向量。`B` 可以被视为一种“变换算子”，它将后面的后向消息变换为前面的消息。下一个观测到来后，新的后向消息也满足类似的方程：

$\\begin{matrix} {\\mathbf{b}\_{t - d + 2:t + 1} = \\,\\left( {\\prod\\limits\_{i = t - d + 2}^{t + 1}{\\mathbf{T}\\mathbf{O}\_{i}}} \\right)\\mathbf{b}\_{t + 2:t + 1}\\text{~=~}\\mathbf{B}\_{t - d + 2:t + 1}\\mathbf{1}\\text{.}} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.15)} \\\\ \\end{matrix}$

检查 [方程 (14.14)](#Chapter14-03.xhtml#eq14-14) 和 [(14.15)](#Chapter14-03.xhtml#eq14-15) 中的乘积表达式，我们发现它们之间有简单的关系：要得到第二个乘积，“除以”第一个乘积中的第一个元素 `TOt−d+1`，并乘以新的最后一个元素 `TOt+1`。在矩阵语言中，旧的和新的 `B` 矩阵之间存在简单的关系：

$\\begin{matrix} {\\mathbf{B}\_{t - d + 2:t + 1} = \\mathbf{O}\_{t - d + 1}^{- 1}\\,\\mathbf{T}^{- 1}\\,\\mathbf{B}\_{t - d + 1:t}\\,\\mathbf{T}\\mathbf{O}\_{t + 1}.} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(14.16)} \\\\ \\end{matrix}$

该方程为 `B` 矩阵提供了增量更新，进而通过 [方程 (14.15)](#Chapter14-03.xhtml#eq14-15) 使我们能够计算新的后向消息 `bt−d+2:t+1`。需要存储和更新 `f` 和 `B` 的完整算法如 [图 14.6](#Chapter14-03.xhtml#fig14-6) 所示。

## 14.3.2 隐马尔可夫模型示例：定位

在 [第 151 页](#Chapter04-04.xhtml#page_151) 中，我们介绍了真空世界定位问题的简单形式。在那个版本中，机器人有一个单一的非确定性 Move 动作，其传感器能完美报告正北、正南、正东、正西是否立即存在障碍物；机器人的信念状态是它可能所在位置的集合。

在这里，我们通过允许传感器存在噪声，使问题更具现实性，并形式化了机器人随机移动的想法——它移动到任何相邻空方格的可能性相等。状态变量 `Xt` 表示机器人在离散网格上的位置；该变量的域是空方格的集合，我们将用整数 {1,...,`S` } 对其进行标记。令 `NEIGHBORS(i)` 为与 `i` 相邻的空方格集合，`N(i)` 为该集合的大小。那么 Move 动作的转移模型说明机器人以相同的概率结束于任何相邻方格：

$\\left. P(X\_{t + 1} = j \\middle| X\_{t} = i) = \\mathbf{T}\_{ij} = \\left\\{ \\,\\,\\,\\begin{array}{l} {1/N(i)\\text{~if~}j\\ \\in \\text{~NEIGHBORS}(i)} \\\\ {\\text{0~otherwise}\\text{.}} \\\\ \\end{array} \\right. \\right.$

我们不知道机器人从哪里开始，所以我们假设所有方格上的均匀分布；即 `P(X0 = i) = 1/S`。对于我们考虑的特定环境（[图 14.7](#Chapter14-03.xhtml#fig14-7)），`S = 42`，转移矩阵 `T` 有 42 × 42 = 1764 个元素。
