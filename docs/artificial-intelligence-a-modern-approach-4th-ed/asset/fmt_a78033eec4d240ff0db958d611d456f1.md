
## Linear Regression

[Figure 19.13(a)](#Chapter19-06.xhtml#fig19-13) shows an example of a training set of `n` points in the `x`, `y` plane, each point representing the size in square feet and the price of a house offered for sale. The task of finding the `hw` that best fits these data is called linear regression. To fit a line to the data, all we have to do is find the values of the weights `w0`, `w1` that minimize the empirical loss. It is traditional (going back to Gauss[6](#Chapter19-11.xhtml#sup19-6)) to use the squared-error loss function, `L2`, summed over all the training examples:

<p class="sidebar">Linear regression</p>

$Loss\\text{(}h\_{\\mathbf{w}}) = {\\sum\\limits\_{j = 1}^{N}{L\_{2}(y\_{j},\\, h\_{\\mathbf{w}}\\text{(}x\_{j}\\text{)})}} = {\\sum\\limits\_{j = 1}^{N}{{\\text{(}y\_{j} - h\_{\\mathbf{w}}\\text{(}x\_{j}\\text{))}}^{\\text{2}} = {\\sum\\limits\_{j = 1}^{N}{{\\text{(}y\_{j}\\ - (w\_{1}x\_{j} + w\_{0}\\text{))}}^{\\text{2}}\\text{.}}}}}$

We would like to find `w* = argmin_w Loss(hw)`. The sum *Σ*[*j* = 1]^(*N*)(*y*[*j*] − (*w*[1]*x*[*j*] + *w*[0]))² is minimized when its partial derivatives with respect to `w0` and `w1` are zero:

$\\frac{\\partial}{\\partial w\_{0}}{\\sum\\limits\_{j = 1}^{N}{{(y\_{j} - (w\_{1}x\_{j} + w\_{0}))}^{2} = 0\\,\\,\\,}}\\text{and}\\,\\,\\,\\text{and}\\,\\,\\,\\frac{\\partial}{\\partial w\_{1}}{\\sum\\limits\_{j = 1}^{N}{{(y\_{j} - (w\_{1}x\_{j} + w\_{0}))}^{2} = 0.}}$

These equations have a unique solution:

$\\begin{matrix} {w\_{1} = \\frac{N(\\sum x\_{j}y\_{j}) - (\\sum x\_{j})(\\sum y\_{j})}{N(\\sum x\_{j}^{2}) - {(\\sum x\_{j})}^{2}};} & {w\_{0} = (\\sum y\_{j} - w\_{1}(\\sum x\_{j}))/N.} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\text{(19}\\text{.3)}} \\\\ \\end{matrix}$

For the example in [Figure 19.13(a)](#Chapter19-06.xhtml#fig19-13), the solution is `w1 = 0.232`, `w0 = 246`, and the line with those weights is shown as a dashed line in the figure.

Many forms of learning involve adjusting weights to minimize a loss, so it helps to have a mental picture of what’s going on in weight space—the space defined by all possible settings of the weights. For univariate linear regression, the weight space defined by `w0` and `w1` is two-dimensional, so we can graph the loss as a function of `w0` and `w1` in a 3D plot (see [Figure 19.13(b)](#Chapter19-06.xhtml#fig19-13)). We see that the loss function is convex, as defined on [page 140](#Chapter04-02.xhtml#page_140); this is true for every linear regression problem with an `L2` loss function, and implies that there are no local minima. In some sense that’s the end of the story for linear models; if we need to fit lines to data, we apply [Equation (19.3)](#Chapter19-06.xhtml#eq19-3).[7](#Chapter19-11.xhtml#sup19-7)

## 19.6.2 Gradient descent

The univariate linear model has the nice property that it is easy to find an optimal solution where the partial derivatives are zero. But that won’t always be the case, so we introduce here a method for minimizing loss that does not depend on solving to find zeroes of the derivatives, and can be applied to any loss function, no matter how complex.

As discussed in [Section 4.2](#Chapter04-02.xhtml#sec4-2) ([page 137](#Chapter04-01.xhtml#page_137)) we can search through a continuous weight space by incrementally modifying the parameters. There we called the algorithm hill climbing, but here we are minimizing loss, not maximizing gain, so we will use the term gradient descent. We choose any starting point in weight space—here, a point in the (`w0`, `w1`) plane—and then compute an estimate of the gradient and move a small amount in the steepest downhill direction, repeating until we converge on a point in weight space with (local) minimum loss.

<p class="sidebar">Gradient descent</p>

The algorithm is as follows:

$\\begin{array}{l} \\left. \\mathbf{w}\\leftarrow\\text{any~point~in~the~parameter~space} \\right. \\\\ {\\mathbf{while}\\,\\,\\mathbf{not}\\text{~converged~}\\mathbf{do}} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\mathbf{for}\\,\\,\\mathbf{each}\\ w\_{i}\\ \\mathbf{in}\\,\\,\\mathbf{w}\\,\\,\\mathbf{do}} \\\\ \\left. \\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, w\_{i}\\leftarrow w\_{i} - \\alpha\\frac{\\partial}{\\partial w\_{i}}Loss\\text{(}\\mathbf{w}\\text{)}\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\text{(19}\\text{.4)} \\right. \\\\ \\end{array}$

The parameter `α`, which we called the step size in [Section 4.2](#Chapter04-02.xhtml#sec4-2), is usually called the learning rate when we are trying to minimize loss in a learning problem. It can be a fixed constant, or it can decay over time as the learning process proceeds.

<p class="sidebar">Learning rate</p>

For univariate regression, the loss is quadratic, so the partial derivative will be linear. (The only calculus you need to know is the chain rule: ∂`g`(`f`(`x`))/∂`x` = `g'`(`f`(`x`))∂`f`(`x`)/∂`x`, plus the facts that $\\frac{\\partial}{\\partial x}x^{2} = 2x$ and $\\frac{\\partial}{\\partial x}x = 1$.) Let’s first work out the partial derivatives—the slopes—in the simplified case of only one training example, (`x`, `y`):

<p class="sidebar">Chain rule</p>

$\\begin{array}{l} {\\frac{\\partial}{\\partial w\_{i}}Loss(\\mathbf{w}) = \\frac{\\partial}{\\partial w\_{i}}{(y - h\_{\\mathbf{w}}(x))}^{2} = 2(y - h\_{w}(x)) \\times \\frac{\\partial}{\\partial w\_{i}}(y - h\_{\\mathbf{w}}(x))} \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, = \\, 2(y - h\_{\\mathbf{w}}(x)) \\times \\frac{\\partial}{\\partial w\_{i}}(y - (w\_{1}x + w\_{0})).\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(19.5)} \\\\ \\end{array}$

Applying this to both `w0` and `w1` we get:

$\\begin{matrix} {\\frac{\\partial}{\\partial w\_{0}}Loss\\text{(}\\mathbf{w}\\text{)~} = \\ - \\text{2(}y - h\_{\\mathbf{w}}\\text{(}x\\text{))~;}} & {\\frac{\\partial}{\\partial w\_{1}}Loss\\text{(}\\mathbf{w}\\text{)~} = - \\text{2(}y - h\_{\\mathbf{w}}\\text{(}x\\text{))} \\times x} \\\\ \\end{matrix}\\,.$

Plugging this into [Equation (19.4)](#Chapter19-06.xhtml#eq19-4), and folding the 2 into the unspecified learning rate `α`, we get the following learning rule for the weights:

$\\begin{matrix} \\left. w\_{0}\\leftarrow w\_{0} + \\alpha(y - h\_{\\mathbf{w}}(x))\\ ; \\right. & \\left. w\_{1}\\leftarrow w\_{1} + \\alpha(y - h\_{\\mathbf{w}}(x)) \\times x. \\right. \\\\ \\end{matrix}$
