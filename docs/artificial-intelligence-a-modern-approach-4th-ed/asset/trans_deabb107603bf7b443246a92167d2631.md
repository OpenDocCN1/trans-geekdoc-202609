
## 6.3.1 评估函数

实际上，这种分析需要太多类别，因此需要太多经验来估计所有概率。相反，大多数评估函数会计算每个特征的单独数值贡献，然后将它们组合起来找到总价值。几个世纪以来，国际象棋选手已经发展出仅使用这一思想来判断局面价值的方法。例如，入门国际象棋书籍为每种棋子给出近似的物质价值：每个兵价值 1，马或象价值 3，车价值 5，后价值 9。其他特征如“良好兵形”和“王的安全”可能价值半个兵左右。这些特征值然后简单地加起来以获得局面的评估。

> **材料价值**

从数学上讲，这种评估函数称为加权线性函数，因为它可以表示为

$\\text{EVAL}\\,\\text{(}s\\text{)~=~}w\_{\\text{1}}\\ f\_{\\text{1}}\\text{(}s\\text{)}\\,\\text{+}\\, w\_{\\text{2}}\\ f\_{\\text{2}}\\text{~(}s\\text{)~+}\\ldots\\text{+~}w\_{n}\\ f\_{n}\\,\\text{(}s\\text{)~=}{\\sum\\limits\_{i = 1}^{n}{w\_{i}\\ f\_{i}\\,\\text{(}s\\text{)~,}}}$

其中每个 `fi` 是局面的一个特征（如“白象的数量”），每个 `wi` 是一个权重（表示该特征的重要性）。权重应归一化，使得总和始终在失败（0）到胜利（+1）的范围内。相当于一个兵的稳固优势会带来相当大的获胜可能性，而相当于三个兵的稳固优势应带来几乎确定的胜利，如 [图 6.8(a)](#Chapter06-03.xhtml#fig6-8) 所示。我们说评估函数应与实际获胜机会高度相关，但不必线性相关：如果状态 `s` 获胜的可能性是状态 `s'` 的两倍，我们并不要求 `EVAL(S)` 是 `EVAL(S')` 的两倍；我们只要求 `EVAL(S)` > `EVAL(S')`。

将特征值相加似乎是合理的做法，但实际上它涉及一个强假设：每个特征的贡献独立于其他特征的值。因此，当前国际象棋和其他游戏的程序也使用特征的非线性组合。例如，一对象可能价值超过单个象的两倍，而象在残局中的价值高于早期——当着法数特征较高或剩余棋子数特征较低时。

特征和权重从何而来？它们不是国际象棋规则的一部分，而是人类国际象棋对局经验文化的一部分。在没有这种经验的游戏中，评估函数的权重可以通过 [第23章](#Chapter23-00.xhtml) 的机器学习技术来估计。将这些技术应用于国际象棋证实了象确实价值约三个兵，并且似乎几个世纪的人类经验可以在几小时的机器学习中得到复制。

## 6.3.2 剪枝搜索

下一步是修改 `ALPHA-BETA-SEARCH`，使其在适当剪枝搜索时调用启发式 `EVAL` 函数。我们用以下行替换 [图 6.7](#Chapter06-02.xhtml#fig6-7) 中提到 `IS-TERMINAL` 的两行：

```
if game.IS-CUTOFF(state, depth) then return game.EVAL(state, player), null
```

我们还必须安排一些记账工作，以便在每次递归调用时递增当前深度。控制搜索量的最直接方法是设置固定深度限制，使得 `IS-CUTOFF(state, depth)` 对所有大于某个固定深度 `d` 的深度（以及所有终止状态）返回 true。深度 `d` 的选择使得在分配的时间内选择一个着法。更稳健的方法是应用迭代加深。（参见 [第3章](#Chapter03-00.xhtml)。）当时间用完时，程序返回最深完成的搜索所选择的着法。作为奖励，如果在每次迭代加深的轮次中我们保留 transposition table 中的条目，后续轮次会更快，并且我们可以使用评估结果来改进着法排序。

这些简单方法由于评估函数的近似性可能导致错误。再次考虑基于物质优势的国际象棋简单评估函数。假设程序搜索到深度限制，达到 [图 6.8(b)](#Chapter06-03.xhtml#fig6-8) 中的局面，其中黑方领先马和两个兵。它会将此报告为该状态的启发式值，从而宣布该状态是黑方很可能获胜。但白方的下一步吃掉黑方的后且没有补偿。因此，该局面实际上对白方有利，但只有通过前瞻才能看出。

评估函数只应应用于静止的局面——即没有会剧烈改变评估的待处理着法（如吃后）的局面。对于非静止局面，`IS-CUTOFF` 返回 false，搜索继续直到达到静止局面。这种额外的静止搜索有时会限制只考虑某些类型的着法，例如吃子着法，以快速解决局面中的不确定性。
