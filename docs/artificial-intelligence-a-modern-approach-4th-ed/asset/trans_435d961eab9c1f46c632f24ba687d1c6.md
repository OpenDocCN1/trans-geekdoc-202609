现在假设 `hw(x)` 具有明确的数学形式，我们可以考虑选择权重 `w` 以最小化损失。在 [章节 19.6.1](#Chapter19-06.xhtml#sec19-6-1) 和 [章节 19.6.3](#Chapter19-06.xhtml#sec19-6-3) 中，我们既以闭式（通过将梯度设为零并求解权重）也通过权重空间的梯度下降来完成此操作。这里我们无法做这两件事，因为梯度在权重空间几乎处处为零，除了 `w · x = 0` 的那些点，而在这些点梯度未定义。

然而，存在一个简单的权重更新规则，该规则会收敛到一个解——即对数据进行完美分类的线性分隔符——前提是数据线性可分。对于单个示例 (`x`, `y`)，我们有

$\\begin{matrix} \\left. w\_{i}\\ \\leftarrow\\text{~~}w\_{i} + \\text{α}(y - h\_{\\mathbf{w}}(\\mathbf{x})) \\times x\_{i} \\right. & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\text{(19}\\text{.8)}} \\\\ \\end{matrix}$

这与 [方程 (19.6)](#Chapter19-06.xhtml#eq19-6) 基本相同，即线性回归的更新规则！该规则称为感知器学习规则，其原因将在 [第 22 章](#Chapter22-00.xhtml) 中变得清晰。因为我们考虑的是 0/1 分类问题，所以行为有所不同。真实值 `y` 和假设输出 `hw(x)` 均为 0 或 1，因此有三种可能性：

<p class="sidebar">感知器学习规则</p>

• 如果输出正确（即 `y = hw(x)`），则权重不发生变化。
• 如果 `y` 为 1 但 `hw(x)` 为 0，则当对应输入 `x_i` 为正时 `w_i` 增加，当 `x_i` 为负时减小。这是有道理的，因为我们希望使 `w · x` 增大，以便 `hw(x)` 输出一个 1。
• 如果 `y` 为 0 但 `hw(x)` 为 1，则当对应输入 `x_i` 为正时 `w_i` 减小，当 `x_i` 为负时增加。这是有道理的，因为我们希望使 `w · x` 减小，以便 `hw(x)` 输出一个 0。

通常学习规则一次应用一个示例，以随机选择示例（如随机梯度下降）。[图 19.16(a)](#Chapter19-06.xhtml#fig19-16) 显示了将此学习规则应用于地震/爆炸数据的训练曲线，该数据见 [图 19.15(a)](#Chapter19-06.xhtml#fig19-15)。训练曲线衡量分类器在固定训练集上的性能，随着学习过程在该训练集上一次一个更新地进行。曲线显示更新规则收敛到零误差线性分隔符。“收敛”过程并不完全漂亮，但它总是有效。此次运行在 63 个示例的数据集上收敛需要 657 步，因此每个示例平均大约呈现 10 次。通常，不同运行之间的变化很大。

我们已经说过，当数据点线性可分时，感知器学习规则会收敛到完美的线性分隔符；但如果不是呢？这种情况在现实世界中太常见了。例如，[图 19.15(b)](#Chapter19-06.xhtml#fig19-15) 重新加入了 Kebeasy 等人 (1998) 在绘制 [图 19.15(a)](#Chapter19-06.xhtml#fig19-15) 所示数据时排除的数据点。在 [图 19.16(b)](#Chapter19-06.xhtml#fig19-16) 中，我们显示感知器学习规则即使在 10,000 步后仍未能收敛：即使它多次达到最小误差解（三 个错误），算法仍在不断改变权重。一般来说，对于固定学习率 `α`，感知器规则可能无法收敛到稳定解，但如果 `α` 以 `O(1/t)` 的速率衰减，其中 `t` 为迭代次数，则可以证明该规则在示例以随机顺序呈现时收敛到最小误差解。[10](#Chapter19-11.xhtml#sup19-10) 也可以证明找到最小误差解是 NP-hard，因此预期需要多次呈现示例才能实现收敛。[图 19.16(c)](#Chapter19-06.xhtml#fig19-16) 显示了采用学习率调度 `α(t) = 1000/(1000 + t)` 的训练过程：在 100,000 次迭代后收敛并不完美，但比固定-α 情况好得多。

## 19.6.5 Logistic 回归的线性分类

我们已经看到，将线性函数的输出通过阈值函数会产生线性分类器；然而阈值的硬性导致了一些问题：假设 `hw(x)` 不可微，并且实际上是其输入和权重的间断函数。这使得使用感知器规则的学习变得非常不可预测。此外，线性分类器总是宣布对 1 或 0 的完全自信预测，即使对于非常接近边界的示例也是如此；最好是它能将一些示例分类为明确的 0 或 1，而将其他示例分类为不明确的边界情况。
