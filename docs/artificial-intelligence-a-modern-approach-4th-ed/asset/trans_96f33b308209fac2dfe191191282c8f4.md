
# 交替出价谈判模型

一个有影响力的谈判协议是交替出价谈判模型。为简单起见，我们再次假设只有两个代理。谈判在一系列回合中进行。`A1`在第0回合开始时提出报价。如果`A2`接受报价，则报价被实施。如果`A2`拒绝报价，则谈判进入下一回合。这次`A2`提出报价，`A1`选择接受或拒绝，依此类推。如果谈判永远不终止（因为代理拒绝每一个报价），则我们将结果定义为冲突交易。一个方便的简化假设是，两个代理都更愿意在有限时间内达成结果——任何结果——而不是陷入无限耗时的冲突交易。

我们将使用分饼的场景来说明交替出价。其思想是存在某种资源（“饼”），其价值为1，可以分成两部分，每位代理各得一部分。因此在此场景中报价是一对`(x, 1 - x)`，其中`x`是`A1`得到的饼的量，`1 - x`是`A2`得到的量。可能的交易空间（谈判集）因此为：

`{ (x, 1 - x) : 0 ≤ x ≤ 1 }`.

现在，在这种设定下代理应如何谈判？为了理解这个问题的答案，我们将首先看几个更简单的案例。

首先，假设我们只允许进行一轮。因此，`A1`提出建议；`A2`可以接受它（在这种情况下交易被实施），或拒绝它（在这种情况下冲突交易被实施）。这是一个最后通牒游戏。在这种情况下，结果是`A1`——第一行动者——拥有全部权力。假设`A1`提议得到全部饼，即提议交易`(1,0)`。如果`A2`拒绝，则实施冲突交易；由于按定义`A2`宁愿得到0也不愿冲突交易，`A2`最好接受。当然，`A1`不能比得到整个饼更好。因此，这两个策略——`A1`提议得到整个饼，以及`A2`接受——构成纳什均衡。

现在考虑我们允许恰好两轮谈判的情况。现在权力发生了转移：`A2`可以简单地拒绝第一次报价，从而将游戏变成一轮游戏，其中`A2`是第一行动者，因此将得到整个饼。一般来说，如果回合数是固定数，则最后行动者将得到全部饼。

现在让我们进入一般情况，其中对回合数没有限制。假设`A1`使用以下策略：

始终提议`(1,0)`，并且始终拒绝任何还价。

对此，`A2`的最佳反应是什么？如果`A2`持续拒绝提议，则代理将永远谈判下去，这按定义是对`A2`（以及对`A1`）的最差结果。所以`A2`做得不会比接受`A1`提出的第一个提议更好。同样，这是一个纳什均衡。但如果`A1`使用策略：

始终提议`(0.8,0.2)`，并且始终拒绝任何报价。

通过类似的论证，我们可以看到，对于此报价或谈判集中任何可能的交易`(x, 1 - x)`，都存在一对谈判策略的纳什均衡，使得结果将在第一个时间段达成协议。

### 不耐烦的代理

这一分析告诉我们，如果不对回合数施加限制，则将存在无限多个纳什均衡。所以让我们增加一个假设：

对于任何结果`x`和时间`t1`和`t2`，其中`t1 < t2`，两个代理都更喜欢在时间`t1`得到结果`x`而不是在时间`t2`得到结果`x`。

换句话说，代理是不耐烦的。对不耐烦的常用方法是为每个代理使用贴现因子`γi`（参见[第555页](#Chapter16-01.xhtml#page_555)），其中`0 ≤ γi ≤ 1`。假设在谈判的某个时刻代理`i`被提供一块大小为`x`的饼。切片`x`在时间`t`的价值为`γ[i]^(t) * x`。因此在第一次谈判步骤（时间0），价值为`γ[i]^0 * x = x`，而在任何后续时间点，同样的报价价值会更低。`γi`的值越大（越接近1）意味着越有耐心；值越小意味着耐心越少。

为了分析一般情况，让我们首先考虑固定时期的谈判，如上所述。1轮情况的分析与上面给出的一样：我们只是有一个最后通牒游戏。两轮时情况发生变化，因为饼的价值根据贴现因子`γi`减少。假设`A2`拒绝`A1`的初始提议。然后`A2`将在第二轮的最后通牒中得到整个饼。但整个饼的价值已经降低：对`A2`来说只值`γ2`。代理`A1`可以考虑到这一点，通过提供`(1 - γ2, γ2)`，`A2`不妨接受，因为此时`A2`做不到比`γ2`更好。（如果你担心平局的情况，只需将报价设为`(1 - (γ[2] + ϵ), γ[2] + ϵ)`，其中`ϵ`为某个小值。）

因此，`A1`提供`(1 - γ2, γ2)`，而`A2`接受该报价的两个策略处于纳什均衡。耐心较强的玩家（`γ2`较大的那些）在此协议下能够获得更大的饼块：在这种设定下，耐心确实是美德。

现在考虑一般情况，其中对回合数没有限制。如1轮情况一样，`A1`可以制定`A2`应该接受的提议，因为它在给定贴现因子的情况下给予`A2`最大可实现的数量。结果是`A1`将得到

$\\frac{\\text{1} - \\gamma 2}{\\text{1} - \\gamma 1\\,\\gamma 2}$

而`A2`将得到剩余部分。

### 任务导向领域的谈判

在本节中，我们考虑任务导向领域的谈判。在此类领域中，必须完成一组任务，每个任务最初分配给一组代理。代理可以通过谈判谁执行哪些任务而受益。例如，假设一些任务在车床上完成，其他任务在铣床上完成，并且任何使用机器的代理都必须承担显著的设置成本。那么一个代理向另一个代理提供“反正我必须在铣床上设置；要不要我做你所有的铣削任务，你做我所有的车削任务？”是有意义的。

与谈判场景不同，我们从初始分配开始，因此如果代理未能就任何报价达成一致，他们将执行最初分配给他们的任务`T[i]^0`。

为保持简单，我们再次假设只有两个代理。设`T`为所有任务的集合，并设`(T[1]^0, T[2]^0)`表示在时间0时任务对两个代理的初始分配。`T`中的每个任务必须分配给恰好一个代理。我们假设我们有一个成本函数`c`，它对每组任务`T'`给出一个正实数`c(T')`，表示任何代理执行任务`T'`的成本。（假设成本仅取决于任务，而不取决于执行任务的代理。）成本函数是单调的——增加更多任务永远不会降低成本——并且不做任何事情的成本为零：`c({ }) = 0`。例如，假设设置铣床的成本为10，每个铣削任务成本为1，则两项铣削任务的集合成本为12，五项的集合成本为15。

形式为`(T1, T2)`的报价意味着代理`i`承诺执行任务集`Ti`，成本为`c(Ti)`。代理`i`的效用是其接受报价所能获得的收益——执行这组新任务的成本与最初分配任务集的成本之差：

`U[i]((T[1], T[2])) = c(T[i]) - c(T[i]^0)`.

报价`(T1, T2)`是个人理性的，如果对两个代理都有`Ui((T1, T2)) ≥ 0`。如果交易不是个人理性的，则至少有一个代理可以通过简单地执行其最初分配的任务而做得更好。
