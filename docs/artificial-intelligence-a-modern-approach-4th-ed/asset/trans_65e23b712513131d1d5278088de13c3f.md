
# 监控电池供电机器人

让我们现在考虑一个更有趣的例子：在 X–Y 平面中移动的电池供电机器人的监控，正如在 [第14.1节](#Chapter14-01.xhtml#sec14-1) 末尾介绍的那样。首先，我们需要状态变量，其中将包括用于位置的 `Xt = (Xt, Yt)` 和用于速度的 $\\mathbf{\\overset{˙}{X}}\_{t} = ({\\overset{˙}{X}}\_{t},{\\overset{˙}{Y}}\_{t})$。我们假设有某种测量位置的方法——也许是固定摄像头或机载 GPS（全球定位系统）——产生测量值 `Zt`。下一步的位置取决于当前位置和速度，如标准卡尔曼滤波器模型中所述。下一步的速度取决于当前速度和电池状态。我们添加 `Batteryt` 来表示实际电池电量，其父节点为之前的电池电量和速度，并添加 `BMetert`，它测量电池电量。这给出了 [图14.13(b)](#Chapter14-05.xhtml#fig14-13) 中显示的基本模型。

值得更深入地研究 `BMetert` 的传感器模型的性质。为了简单起见，我们假设 `Batteryt` 和 `BMetert` 都可以取离散值 0 到 5。（练习 14.BATT 要求你将此离散模型与相应的连续模型联系起来。）如果仪表始终准确，则 CPT `P(BMetert | Batteryt)` 应在“对角线”上具有 1.0 的概率，在其他地方具有 0.0 的概率。实际上，噪声总是会渗入测量中。对于连续测量，可以使用具有较小方差的高斯分布。[7](#Chapter14-07.xhtml#sup14-7) 对于我们的离散变量，我们可以使用一种概率误差以适当方式下降的分布来近似高斯分布，使得大误差的概率非常小。我们使用术语高斯误差模型来涵盖连续和离散两种版本。

### 高斯误差模型

任何有机器人、计算机化过程控制或其他形式自动传感实践经验的人都会 readily 证明，少量测量噪声往往是最不重要的问题。实际传感器会失效。当传感器失效时，它不一定会发送信号说，“哦，顺便说一下，我即将发送给你的数据是一堆胡言乱语。”相反，它只是发送胡言乱语。最简单的失效类型称为瞬态故障，其中传感器偶尔决定发送一些胡言乱语。例如，电池电量传感器可能有一种习惯，当有人撞到机器人时发送 0 的读数，即使电池已完全充电。

### 瞬态故障

让我们看看当高斯误差模型不考虑此类故障时瞬态故障发生时会发生什么。假设，例如，机器人安静地坐着并观察到 20 个连续的电池读数为 5。然后电池仪表出现暂时性抽搐，下一个读数是 `BMeter21 = 0`。简单的高斯误差模型会让我们相信 `Battery21` 吗？根据贝叶斯规则，答案取决于传感器模型 `P(BMeter21 = 0| Battery21)` 和预测 `P(Battery21 | BMeter1:20)`。如果大传感器误差的概率明显小于转换到 `Battery21 = 0` 的概率，即使后者非常不可能，则后验分布将赋予电池为空的较高概率。

t = 22 时的第二个 0 读数将使这一结论几乎确定。如果瞬态故障随后消失，并且从 t = 23 起读数返回到 5，则电池电量的估计值将迅速返回到 5。（这并不意味着算法认为电池神奇地重新充电了，这在物理上可能是不可能的；相反，算法现在相信电池从未耗尽，并且电池仪表有两次连续巨大误差的极不可能的假设必须是正确的解释。）这一系列事件在 [图14.14(a)](#Chapter14-05.xhtml#fig14-14) 的上曲线中有所说明，该曲线显示了使用离散高斯误差模型时 `Batteryt` 的期望值（参见附录 A）随时间的变化。

图14.14(a) 上曲线：对于由全部为 5 的观测序列组成的轨迹，除了 t = 21 和 t = 22 时为 0 外，使用简单的高斯误差模型时 `Batteryt` 期望值的轨迹。下曲线：当观测值从 t = 21 起保持为 0 时的轨迹。(b) 使用瞬态故障模型运行相同的实验。瞬态故障得到很好处理，但持续故障会导致对电池电量的过度悲观。

尽管恢复了，但在 t = 22 时机器人确信其电池为空； presumably，然后它应该发出求救信号并关闭。不幸的是，其过于简化的传感器模型导致它误入歧途。故事的寓意很简单：为了使系统正确处理传感器故障，传感器模型必须包含故障的可能性。

传感器最简单的故障模型允许传感器以一定的概率返回完全错误的值，而与世界真实状态无关。例如，如果电池仪表通过返回 0 而失效，我们可能会说

`P(BMeter[t] =0|Battery[t]=5)=0.03`,

这 presumably 比简单高斯误差模型分配的概率大得多。让我们称之为瞬态故障模型。当我们面临 0 的读数时，它如何提供帮助？只要根据迄今为止的读数，空电池的预测概率远小于 0.03，则观测值 `BMeter21 = 0` 的最佳解释是传感器暂时失效。直观上，我们可以将对电池电量的信念视为具有一定“惯性”，有助于克服仪表读数中的暂时波动。[图14.14(b)](#Chapter14-05.xhtml#fig14-14) 中的上曲线显示，瞬态故障模型可以在没有信念灾难性变化的情况下处理瞬态故障。
