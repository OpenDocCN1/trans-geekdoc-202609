
# Event Calculus

To assert that a fluent is actually true starting at some point in time `t1` and continuing to time `t2`, we use the predicate `T`, as in `T(At(Shankar,Berkeley),t1,t2`. Similarly, we use `Happens(E1,t1,t2)` to say that the event `E1` actually happened, starting at time `t1` and ending at time `t2`. The complete set of predicates for one version of the event calculus[4](#Chapter10-08.xhtml#sup10-4) is:

$\\begin{array}{l} {T(\\ f,\\ t\_{1},\\ t\_{2})} \\\\ {Happens(e,\\ t\_{1},\\ t\_{2})} \\\\ {Initiates(e,\\ f,\\ t)} \\\\ {Ter\\min ates(e,\\ f,\\ t)} \\\\ {Initiated(\\ f,\\ t\_{1},\\ t\_{2})} \\\\ {Terminated(\\ f\\text{,~}t\_{1},\\ t\_{2})} \\\\ {t\_{1} < t\_{2}} \\\\ \\end{array}\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\begin{array}{l} {\\text{Fluent~}f\\text{~is~true~for~all~times~between~}t\_{\\text{1}}\\text{~and~}t\_{\\text{2}}} \\\\ {\\text{Event~}e\\text{~starts~at~time~}t\_{\\text{1}}\\text{~and~ends~at~}t\_{\\text{2}}} \\\\ {\\text{Event~}e\\text{~causes~fluent~}f\\text{~to~become~true~at~time~}t} \\\\ {\\text{Event~}e\\text{~causes~fluent~}f\\text{~to~cease~to~be~true~at~time~}t} \\\\ {\\text{Fluent~}f\\text{~become~true~at~some~point~between~}t\_{\\text{1}}\\text{~and~}t\_{\\text{2}}} \\\\ {\\text{Fluent~}f\\text{~cease~to~be~true~at~some~point~between~}t\_{\\text{1}}\\text{~and~}t\_{\\text{2}}} \\\\ {\\text{Time~point~}t\_{\\text{1}}\\text{~occurs~before~time~}t\_{\\text{2}}} \\\\ \\end{array}$

We can describe the effects of a flying event:

$\\begin{array}{l} E \\\\ \\\\ \\end{array}\\begin{array}{l} = \\\\ \\\\ \\end{array}\\begin{array}{l} \\left. Flyings(a,here,there) \\land Happens(E,t\_{1},t\_{2})\\Rightarrow \\right. \\\\ {Terminates(E,At(a,here),t\_{1})\\, \\land Initiates(E,At(a,there),t\_{2})} \\\\ \\end{array}$

We assume a distinguished event, `Start`, that describes the initial state by saying which fluents are true (using `Initiates`) or false (using `Terminated`) at the start time. We can then describe what fluents are true at what points in time with a pair of axioms for `T` and `¬T` that follow the same general format as the successor-state axioms: Assume an event happens between time `t1` and `t3`, and at `t2` somewhere in that time interval the event changes the value of fluent `f`, either initiating it (making it true) or terminating it (making it false). Then at time `t4` in the future, if no other intervening event has changed the fluent (either terminated or initiated it, respectively), then the fluent will have maintained its value. Formally, the axioms are:

$\\begin{array}{l} \\left. Happens(e,t\_{1},t\_{3}) \\land Initiates(e,f,t\_{2}) \\land \\neg Terminated\\,(f,t\_{2},t\_{4}) \\land t\_{1} \\leq t\_{2} \\leq t\_{3} \\leq t\_{4}\\Rightarrow \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, T(f,t\_{2},t\_{4})} \\\\ \\left. Happens(e,t\_{1},t\_{3}) \\land Terminated(e,f,t\_{2}) \\land \\neg Initiates\\,(f,t\_{2},t\_{4}) \\land t\_{1} \\leq t\_{2} \\leq t\_{3} \\leq t\_{4}\\Rightarrow \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\neg T(f,t\_{2},t\_{4})} \\\\ \\end{array}$

where `Terminated` and `Initiated` are defined by:

$\\begin{array}{l} \\left. Terminated(f,t\_{1},t\_{5})\\Leftrightarrow \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\exists e,t\_{2},t\_{3},t\_{4}\\, Happens(e,t\_{2},t\_{4}) \\land Terminated\\,(e,f,t\_{3}) \\land t\_{1} \\leq t\_{2} \\leq t\_{3} \\leq t\_{4} \\leq t\_{5}} \\\\ \\left. Initiated(f,t\_{1},t\_{5})\\Leftrightarrow \\right. \\\\ {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\exists e,t\_{2},t\_{3},t\_{4}\\, Happens(e,t\_{2},t\_{4}) \\land Initiates\\,(e,f,t\_{3}) \\land t\_{1} \\leq t\_{2} \\leq t\_{3} \\leq t\_{4} \\leq t\_{5}} \\\\ \\end{array}$

We can extend event calculus to represent simultaneous events (such as two people being necessary to ride a seesaw), exogenous events (such as the wind moving an object), continuous events (such as the rising of the tide), nondeterministic events (such as flipping a coin and having it come up heads or tails), and other complications.

## 10.3.1 Time

Event calculus opens us up to the possibility of talking about time points and time intervals. We will consider two kinds of time intervals: moments and extended intervals. The distinction is that only moments have zero duration:

$\\begin{array}{l} {Partition(\\left\\{ Moments,\\ ExtendedIntervals \\right\\},\\ Intervals)} \\\\ \\left. i \\in Moments\\Leftrightarrow Duration\\text{(}i\\text{)} = {Sec}onds\\text{(0)~}\\text{.} \\right. \\\\ \\end{array}$

Next we invent a time scale and associate points on that scale with moments, giving us absolute times. The time scale is arbitrary; we will measure it in seconds and say that the moment at midnight (GMT) on January 1, 1900, has time 0. The functions `Begin` and `End` pick out the earliest and latest moments in an interval, and the function `Time` delivers the point on the time scale for a moment. The function `Duration` gives the difference between the end time and the start time.

$\\begin{array}{l} \\left. Interval(i)\\ \\Rightarrow\\ Duration(i) = (Time(End(i)) - Time(Begin(i))). \\right. \\\\ {Time(Begin(AD1900)) = Seconds(0).} \\\\ {Time\\text{(}Begin\\text{(}AD\\text{2001))} = Seconds\\text{(3187324800)~}\\text{.}} \\\\ {Time(End\\text{(}AD\\text{2001))} = Seconds\\text{(3218860800)~}\\text{.}} \\\\ {Duration(AD2001) = Seconds\\text{(}31536000).} \\\\ \\end{array}$

To make these numbers easier to read, we also introduce a function `Date`, which takes six arguments (hours, minutes, seconds, day, month, and year) and returns a time point:

$\\begin{array}{l} {Time(Begin(AD2001)) = Date(0,0,0,1,Jan,2001)} \\\\ {Date(0,20,21,24,1,1995) = Seconds(3000000000).} \\\\ \\end{array}$

Two intervals Meet if the end time of the first equals the start time of the second. The complete set of interval relations (Allen, 1983) is shown below and in [Figure 10.2](#Chapter10-03.xhtml#fig10-2):

Description

The interval relations are depicted using a set of two blocks labeled `i` and `j`. `Meet(i, j)`: Blocks `i` and `j` meet at a common point. `Before(i, j)` after (`j`, `i`): Blocks `i` and `j` are aligned horizontally in a sequence, at a small distance. `During(i, j)`: Blocks `i` and `j` are aligned vertically with block `i` at the top. Block `j` is longer than block `i`. `Overlap(i, j)`: Blocks `i` and `j` are aligned vertically in such a way block `i` is aligned toward the left and block `j` is aligned slightly toward the right. Block `j` is longer than block `i`. `Starts(i, j)`: Blocks `i` and `j` are aligned one below the other toward the left. Block `j` is longer than block `i`. `Finishes(i, j)`: Blocks `i` and `j` are aligned one below the other toward the right. Block `j` is longer than block `i`. `Equals(i, j)`: Blocks `i` and `j` are aligned one below the other. Both the blocks have equal length.
