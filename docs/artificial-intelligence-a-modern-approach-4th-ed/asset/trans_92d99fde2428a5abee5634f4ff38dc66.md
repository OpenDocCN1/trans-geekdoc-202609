其中最终项 `max[x1:t−1] P(x[1:t−1], x[t], e[1:t])` 正好是消息向量 `m1:t` 中特定状态 `xt` 的条目。[方程 (14.11)](#Chapter14-02.xhtml#eq14-11) 本质上与滤波 [方程 (14.5)](#Chapter14-02.xhtml#eq14-5) 相同，只是 [方程 (14.5)](#Chapter14-02.xhtml#eq14-5) 中对 `xt` 的求和被 [方程 (14.11)](#Chapter14-02.xhtml#eq14-11) 中的对 `xt` 的最大化所取代，并且 [方程 (14.11)](#Chapter14-02.xhtml#eq14-11) 中没有归一化常数 `a`。因此，计算最可能序列的算法与滤波类似：它从时间 0 开始，以先验 `m1:0 = P(X0)` 为起点，然后沿序列向前运行，使用 [方程 (14.11)](#Chapter14-02.xhtml#eq14-11) 在每个时间步计算 `m` 消息。此计算的进展如图 [图 14.5(b)](#Chapter14-02.xhtml#fig14-5) 所示。

在观测序列结束时，`m1:t` 将包含到达每个最终状态的最可能序列的概率。因此可以很容易地选择整体最可能序列的最终状态（步骤 5 中用粗体描出的状态）。为了识别实际序列，而不是仅仅计算其概率，算法还需要为每个状态记录导致它的最佳状态；这些状态由 [图 14.5(b)](#Chapter14-02.xhtml#fig14-5) 中的粗体箭头表示。通过从最佳最终状态向后跟踪这些粗体箭头即可识别出最优序列。

我们刚刚描述的算法称为 `Viterbi algorithm`，以其发明者 Andrew Viterbi 命名。与滤波算法一样，其时间复杂度与序列长度 `t` 成线性关系。与仅使用常数空间的滤波不同，其空间需求也与 `t` 成线性关系。这是因为 `Viterbi algorithm` 需要保留指向每个状态的最佳序列的指针。

> 维特比算法

最后一点实际问题：数值下溢对于 `Viterbi algorithm` 来说是一个重要问题。在 [图 14.5(b)](#Chapter14-02.xhtml#fig14-5) 中，概率变得越来越小——这只是一个玩具示例。DNA 分析或消息解码中的实际应用可能有数千或数百万步。一个可能的解决方案是在每一步简单地对 `m` 进行归一化；这种重标定不会影响正确性，因为 `max(cx, cy) = c ⋅ max(x,y)`。第二个解决方案是在所有地方使用对数概率并用加法代替乘法。同样，正确性不受影响，因为 `log` 函数是单调的，所以 `max(log x, log y) = log max(x, y)`。

## 14.3 隐马尔可夫模型

前一节使用一个通用框架开发了时间概率推理的算法，该框架独立于转移模型和传感器模型的具体形式，也独立于状态变量和证据变量的性质。在本节和接下来的两节中，我们讨论更具体的模型和应用，以说明基本算法的强大功能，并在某些情况下允许进一步改进。

我们从隐马尔可夫模型开始，即 `HMM`。`HMM` 是一种时间概率模型，其中过程的状态由单个离散随机变量描述。该变量的可能取值是世界可能的各种状态。前一节中描述的雨伞示例因此是一个 `HMM`，因为它只有一个状态变量：`Raint`。如果模型有两个或多个状态变量会怎样？你仍然可以将它纳入 `HMM` 框架，通过将变量组合成一个“巨变量”，其取值是各个状态变量取值的所有可能元组。我们将看到 `HMMs` 的受限结构允许对所有基本算法进行简单而优雅的矩阵实现。[6](#Chapter14-07.xhtml#sup14-6)

> 隐马尔可夫模型

尽管 `HMMs` 要求状态为单个离散变量，但对证据变量没有相应的限制。这是因为证据变量始终被观测，这意味着无需跟踪其取值上的任何分布。（如果某个变量未被观测，它可以简单地从该时间步的模型中删除。）可以有许多证据变量，既有离散的也有连续的。

### 14.3.1 简化的矩阵算法

对于单个离散状态变量 `Xt`，我们可以为转移模型、传感器模型以及前向和后向消息的表示赋予具体形式。设状态变量 `Xt` 的取值用整数 `1,...,S` 表示，其中 `S` 是可能状态的数量。转移模型 `P(X[t] | X[t−1])` 成为一个 `S × S` 矩阵 `T`，其中

`T[i j]` = `P(X[t] = j | X[t−1] = i)`.

也就是说，`Tij` 是从状态 `i` 转换到状态 `j` 的概率。例如，如果我们将状态 `Rain = true` 和 `Rain = false` 分别编号为 `1` 和 `2`，那么在 [图 14.2](#Chapter14-01.xhtml#fig14-2) 中定义的雨伞世界的转移矩阵是

