
关键问题是确定第一幅视图中的某一点在第二幅视图中对应哪一点。使用简单纹理特征（如[第27.3.2节](#Chapter27-03.xhtml#sec27-3-2)中所述）对一点的局部外观进行详细描述，通常足以匹配点。例如，在街道交通场景中，两张拍摄的图像中可能只有一个绿灯可见；我们就可以假设它们相互对应。多个摄像机视图的几何关系已被很好地理解（但遗憾地说太复杂，无法在此详述）。该理论对一个图像中的点可以与另一个图像中的哪个点匹配产生了几何约束。通过对重建表面的平滑性进行推理，还可以获得其他约束。

获得场景多视角的方法有两种。一种是使用两个摄像机或两只眼睛（[第27.6.2节](#Chapter27-06.xhtml#sec27-6-2)）。另一种是移动（[第27.6.3节](#Chapter27-06.xhtml#sec27-6-3)）。如果你有超过两个视角，就能非常准确地恢复世界几何和视图细节。[第27.7.3节](#Chapter27-07.xhtml#sec27-7-3)讨论了该技术的一些应用。

## 27.6.2 双目立体视觉

大多数脊椎动物都有两只眼睛。这在失去一只眼睛时提供了冗余，但它还有其他帮助。大多数猎物眼睛位于头部两侧，以获得更宽的视野。捕食者的眼睛在前方，使它们能够使用双目立体视觉。将双手食指举在脸前，闭上一只眼，并调整它们，使前面的手指在睁开的眼睛视野中遮挡另一根手指。现在换眼；你应该注意到手指相对于彼此的位置发生了变化。从左视图到右视图的位置这种变化被称为视差。在合适的坐标系中，如果我们叠加某个深度物体的左右图像，该物体在叠加图像中会水平移动，且移动的大小是深度的倒数。你可以在[图27.14](#Chapter27-06.xhtml#fig27-14)中看到这一点，其中金字塔最近的点在右图像中向左移动，在左图像中向右移动。

视差

要测量视差，我们需要解决对应问题——确定左图像中一点在右图像中的“伙伴”，该伙伴是由同一场景点的投影产生的。这类似于测量光流时所做的工作，最简单的方法在某种程度上是相似的。这些方法搜索匹配的左右像素块，使用平方差之和（如[第27.3.3节](#Chapter27-03.xhtml#sec27-3-3)所述）。更复杂的方法使用像素块的更详细纹理表示（如[第27.3.2节](#Chapter27-03.xhtml#sec27-3-2)所述）。实际上，我们使用更复杂的算法，利用额外的约束。

假设我们可以测量视差，这如何提供场景深度的信息？我们需要弄清视差与深度之间的几何关系。我们首先考虑两只眼睛（或摄像机）向前看且光轴平行的情况。那么右摄像机相对于左摄像机的关系就是沿 x\-axis 移动 `b` 的距离，`b` 为基线。我们可以使用[第27.3.3节](#Chapter27-03.xhtml#sec27-3-3)中的光流方程，如果我们将其视为由平移向量 `T` 在时间 `δt` 内作用的结果，其中 `Tx = b/δt` 且 `Ty = Tz = 0`。水平和垂直视差由光流分量乘以时间步长 `δt` 给出，`H = vxδt`，`V = vyδt`。进行代换后，我们得到结果 `H = b/Z`，`V = 0`。换句话说，水平视差等于基线与深度的比值，而垂直视差为零。在已知 `b` 且能测量 `H` 的情况下，我们可以恢复深度 `Z`。

## 27.6.3 来自移动相机的3D线索

假设我们有一个在场景中移动的摄像机。取[图27.14](#Chapter27-06.xhtml#fig27-14)并将左图像标记为“时间 t”，右图像标记为“时间 t +1”。几何关系没有改变，因此关于立体视觉的讨论中的所有内容在摄像机移动时也适用。我们在该节中称之为视差的东西现在被认为是图像中的视运动，并称为光流。这是对摄像机运动和场景几何信息的来源。为了理解这一点，我们陈述（不加证明）一个将光流与观察者的平移速度 `T` 和场景深度联系起来的方程。

光流场是图像中速度的向量场，(`vx(x, y)`, `vy(x, y)`)。在以摄像机为中心的坐标系中，假设焦距为 `f = 1`，这些分量的表达式为

$\\begin{matrix} {v\_{x}(x,y) = \\frac{- T\_{x} + xT\_{z}}{Z(x,y)}\\text{and}} & {v\_{y}(x,y) = \\frac{- T\_{y} + yT\_{z}}{Z(x,y)}} \\\\ \\end{matrix}.$

其中 `Z(x, y)` 是场景中对应于图像中点 (`x`, `y`) 的点的 z\-coordinate（即深度）。

请注意，光流的两个分量 `vx(x, y)` 和 `vy(x, y)` 在点 `x = Tx/Tz`、`y = Ty/Tz` 处为零。该点称为流场的扩张焦点。假设我们将 x–y 平面中的原点更改为位于扩张焦点；那么光流的表达式会变得特别简单。设 (`x'`, `y'`) 为新的坐标，定义为 `x' = x – Tx/Tz`，`y' = y – Ty/Tz`。那么
