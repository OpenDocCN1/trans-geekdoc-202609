
权重共享，如在卷积网络（[第22.3节](#Chapter22-03.xhtml#sec22-3)）和循环网络（[第22.6节](#Chapter22-06.xhtml#sec22-6)）中使用，被简单地处理为将每个共享权重视为计算图中的一个具有多个输出弧的单一节点。在反向传播期间，这会导致多个传入的梯度消息。根据[方程 (22.11)](#Chapter22-04.xhtml#eq22-11)，这意味着共享权重的梯度是其在网络中被使用的每个位置的梯度贡献之和。

从对反向传播过程的这一描述可以明显看出，其计算成本与计算图中的节点数量成线性关系，就像前向计算的成本一样。此外，由于节点类型在网络设计时通常是固定的，所有梯度计算都可以提前以符号形式准备，并编译成针对图中每个节点的高效代码。还请注意，[图 22.6](#Chapter22-04.xhtml#fig22-6)中的消息不一定是标量：它们同样可以是向量、矩阵或更高维张量，以便梯度计算可以映射到GPU或TPU以受益于并行性。

反向传播的一个缺点是，它需要在反向传递中计算梯度，以便存储前向传播期间计算的大多数中间值。这意味着训练网络的总内存成本与整个网络中单元的数量成正比。因此，即使网络本身仅由大量循环的传播代码隐式表示，而不是由数据结构显式表示，所有这些传播代码的中间结果仍必须显式存储。

### 22.4.2 批归一化

批归一化是一种常用的技术，通过从每个小批量中的示例重新缩放网络内部层生成的数值来提高`SGD`的收敛速度。尽管其有效性的原因在撰写时尚未完全理解，但我们将其包含在内，因为它在实践中带来了显著的好处。在某种程度上，批归一化似乎具有与残差网络相似的效果。

批归一化

考虑网络中某个节点 `z`：小批量中 `m` 个示例的 `z` 的值是 `z1,..., zm`。批归一化用新的量 `ẑ[i]` 替换每个 `zi`：

`$\hat{z}_i = \gamma \frac{z_i - \mu}{\sqrt{\epsilon + \sigma^2}} + \beta,$`

其中 `µ` 是小批量中 `z` 的平均值，`σ` 是 `z[1],..., z[m]` 的标准差，`ϵ` 是为防止除零而添加的小常数，而 `γ` 和 `β` 是学习参数。

批归一化根据 `β` 和 `γ` 的值标准化值的均值和方差。这使得训练深度网络变得简单得多。如果没有批归一化，当层的权重太小时，信息可能会丢失，并且该层的标准差会衰减到接近零。批归一化防止了这种情况的发生。它还减少了对网络中所有权重仔细初始化的需求，以确保每一层的节点处于正确的操作区域以允许信息传播。

使用批归一化时，我们通常将 `β` 和 `γ`，它们可能是 `node-specific` 或 `layer-specific`，包含在网络的参数中，以便它们被纳入学习过程。训练后，`β` 和 `γ` 固定在其学习到的值。

## 22.5 泛化

到目前为止，我们已经描述了如何将神经网络拟合到其训练集，但在机器学习中，目标是泛化到以前未见过的新数据，以测试集上的性能来衡量。本节我们重点介绍三种提高泛化性能的方法：选择合适的网络架构、惩罚大权重以及在训练期间随机扰动通过网络的值。

### 22.5.1 选择网络架构

深度学习研究中投入了大量精力来寻找泛化良好的网络架构。事实上，对于每一种特定类型的数据——图像、语音、文本、视频等等——性能的很大一部分进步来自于探索不同类型的网络架构以及改变层数、它们的连接方式和每一层中节点的类型。[6](#Chapter22-10.xhtml#sup22-6)

一些神经网络架构被明确设计用于在特定类型的数据上良好泛化：卷积网络体现了同一特征提取器在空间网格的所有位置都很有用的思想，而循环网络体现了同一更新规则在序列数据流的所有点上都有用的思想。在这些假设成立的程度上，我们期望卷积架构在图像上泛化良好，而循环网络在文本和音频信号上泛化良好。

深度学习领域最重要经验发现之一是，在比较具有相似权重数量的两个网络时，更深的网络通常具有更好的泛化性能。[图 22.7](#Chapter22-05.xhtml#fig22-7) 展示了这一效应，至少在一个现实世界应用中——识别房屋号码。结果表明，对于任何固定的参数数量，十一层网络的测试集误差远低于三层网络。
