
可能在机器学习中最常用的贝叶斯网络模型是朴素贝叶斯模型，该模型首次在[第420页](#Chapter12-05.xhtml#page_420)引入。在此模型中，“类”变量 `C`（待预测）是根节点，而“属性”变量 `Xi` 是叶节点。该模型之所以“朴素”，是因为它假设在给定类的情况下，属性彼此条件独立。（[图21.2(b)](#Chapter21-02.xhtml#fig21-2)中的模型是一个朴素贝叶斯模型，类为 `Flavor`，只有一个属性，`Wrapper`。）在布尔变量的情况下，参数为
`θ = P(C = true)`，`θ[i1] = P(X[i] = true | C = true)`，`θ[i2] = P(X[i] = true | C = false)`。

最大似然参数值与[图21.2(b)](#Chapter21-02.xhtml#fig21-2)中的求法完全相同。一旦模型以这种方式训练完成，就可用于对类变量 `C` 未观测的新示例进行分类。给定观测到的属性值 `x1,...,xn`，每个类的概率由
$\\left. \\mathbf{P}\\text{(}C \\middle| x\_{1}\\text{,}\\ldots\\text{,}x\_{n}\\text{)~} = \\alpha\\mathbf{P}(C){\\prod\\limits\_{i}\\left. \\mathbf{P}(x\_{i} \\middle| C). \\right.} \\right.$
给出。通过选择最可能的类可以得到确定性预测。[图21.3](#Chapter21-02.xhtml#fig21-3)显示了将该方法应用于[第19章](#Chapter19-00.xhtml)中的餐厅问题时的学习曲线。该方法学习效果相当好，但不如决策树学习；这很可能是因为真实假设——即决策树——不能用朴素贝叶斯模型精确表示。朴素贝叶斯学习在广泛的应用中表现令人惊讶地好；其提升版本（Exercise 21.BNBX）是最有效的通用学习算法之一。朴素贝叶斯学习可很好地扩展到非常大的问题：对于 `n` 个布尔属性，只有 `2n + 1` 个参数，且无需搜索即可找到 `hML`，即最大似然朴素贝叶斯假设。最后，朴素贝叶斯学习系统能很好地处理噪声或缺失数据，并在适当时给出概率预测。其主要缺点是条件独立性假设很少准确；正如[第421页](#Chapter12-06.xhtml#page_421)所述，该假设会导致过度自信的概率，通常非常接近0或1，尤其是在属性数量很多时。

## 21.2.3 生成与判别模型
我们可以区分用于分类器的两种机器学习模型：生成式和判别式。生成模型对每个类的概率分布进行建模。例如，来自[第12.6.1节](#Chapter12-06.xhtml#sec12-6-1)的朴素贝叶斯文本分类器为每种可能的文本类别创建单独的模型——一个用于体育，一个用于天气，等等。每个模型都包括类别的先验概率——例如 `P(Category = weather)`——以及条件概率 `P(Inputs | Category = weather)`。由此我们可以计算联合概率 `P(Inputs, Category = weather)`，并且可以生成代表天气类别文本的随机词选择。

<p class="sidebar">生成模型</p>

判别模型直接学习类之间的决策边界。也就是说，它学习 `P(Category | Inputs)`。给定示例输入，判别模型会给出输出类别，但你不能使用判别模型来，例如生成代表某个类别的随机词。逻辑回归、决策树和支持向量机都是判别模型。

<p class="sidebar">判别模型</p>

由于判别模型将全部重点放在定义决策边界上——即实际执行其被要求完成的分类任务——因此在训练数据任意多的极限情况下，它们往往表现更好。然而，在数据有限的情况下，有时生成模型表现更好。(Ng and Jordan, 2002) 将生成式朴素贝叶斯分类器与判别式逻辑回归分类器在15个（小型）数据集上进行比较，发现使用最大数据量时，判别模型在15个数据集中有9个表现更好，但使用少量数据时，生成模型在15个数据集中有14个表现更好。

## 21.2.4 最大似然参数学习：连续模型
诸如线性–高斯模型之类的连续概率模型已在[第440页](#Chapter13-02.xhtml#page_440)展示。由于连续变量在实际应用中无处不在，因此了解如何从数据中学习连续模型的参数非常重要。最大似然学习的原理在连续和离散情况下是相同的。

让我们从一个非常简单的例子开始：学习单变量上的高斯密度函数参数。也就是说，我们假设数据按如下方式生成：
$P(x) = \\frac{1}{\\sigma\\sqrt{2\\pi}}e^{- \\frac{{(x - \\mu)}^{2}}{2\\sigma^{2}}}.$
该模型的参数是均值 `μ` 和标准差 `σ`。（请注意，归一化“常数”取决于 `σ`，因此我们不能忽略它。）设观测值为 `x1,...,xN`。则对数似然为
$L = {\\sum\\limits\_{j = 1}^{N}{\\log\\frac{1}{\\alpha\\sqrt{2\\pi}}}}e -^{\\frac{{(x\_{j} - \\mu)}^{2}}{2\\sigma^{2}}} = N( - \\log\\sqrt{2\\pi} - \\log\\alpha) - {\\sum\\limits\_{j = 1}^{N}{\\frac{{(x\_{j} - \\mu)}^{2}}{2\\sigma^{2}}.}}$

按通常做法令导数为零，我们得到
$\\begin{array}{l} \\left. \\frac{\\partial L}{\\partial\\mu} = \\frac{1}{\\sigma^{2}}\\sum\_{j = 1}^{N}(x\_{j} - \\mu) = 0\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\Rightarrow\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\mu = \\frac{\\sum\_{j}x\_{j}}{N} \\right. \\\\ \\left. \\frac{\\partial L}{\\partial\\sigma} = - \\frac{N}{\\sigma} + \\frac{1}{\\sigma^{3}}\\sum\_{j = 1}^{N}{(x\_{j} - \\mu)}^{2} = 0\\,\\,\\,\\,\\,\\,\\,\\,\\Rightarrow\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\sigma = \\sqrt{\\frac{\\sum\_{j}{(x\_{j} - \\mu)}^{2}}{N}}.\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,(21.4) \\right. \\\\ \\end{array}$
也就是说，均值的最大似然值是样本平均值，标准差的最大似然值是样本方差的平方根。再次，这些令人安心的结果证实了“常识性”做法。
