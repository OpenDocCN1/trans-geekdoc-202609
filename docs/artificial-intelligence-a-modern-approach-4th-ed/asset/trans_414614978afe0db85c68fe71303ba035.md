
决策列表和决策树则允许存在较长的计算路径，这些路径可以依赖于许多输入变量——但仅适用于可能输入向量中的相对较小一部分（[图 22.1(b)](#Chapter22-00.xhtml#fig22-1)）。如果决策树对可能输入的很大一部分具有较长的计算路径，则它在输入变量的数量上必须是呈指数级增长的。深度学习的基本思想是训练电路，使其计算路径变长，从而允许所有输入变量以复杂的方式相互作用（[图 22.1(c)](#Chapter22-00.xhtml#fig22-1)）。这些电路模型被证明具有足够的表达能力，能够捕捉许多重要学习问题中真实世界数据的复杂性。

## 22.1 简单前馈网络

前馈网络顾名思义，仅在一个方向上具有连接——也就是说，它形成一个具有指定输入和输出节点的有向无环图。每个节点计算其输入的函数并将结果传递给网络中的后继节点。信息从输入节点流向输出节点，网络中没有环。另一方面，循环网络会将中间或最终输出反馈到自身的输入中。这意味着网络内部的信号值形成一个具有内部状态或记忆的动态系统。我们将在 [第 22.6 节](#Chapter22-06.xhtml#sec22-6) 中考虑循环网络。

前馈网络
循环网络

布尔电路实现了布尔函数，是前馈网络的一个例子。在布尔电路中，输入仅限于 0 和 1，每个节点实现其输入的简单布尔函数，产生 0 或 1。在神经网络中，输入值通常是连续的，节点接收连续输入并产生连续输出。节点的某些输入是网络的参数；网络通过调整这些参数的值来学习，以便整个网络拟合训练数据。

### 22.1.1 网络作为复杂函数

网络中的每个节点称为一个单元。传统上，遵循 McCulloch 和 Pitts 提出的设计，一个单元计算来自前驱节点的输入的加权和，然后应用非线性函数产生其输出。设 `aj` 表示单元 `j` 的输出，`wi,j` 为从单元 `i` 到单元 `j` 的连接上的权重；则我们有

单元

`aj = gj(∑i wi,j ai) ≡ gj(inj)`,

其中 `gj` 是与单元 `j` 关联的非线性激活函数，`inj` 是输入到单元 `j` 的加权和。

激活函数

如 [第 19.6.3 节](#Chapter19-06.xhtml#sec19-6-3)（[第 697 页](#Chapter19-06.xhtml#page_697)）所述，我们规定每个单元都有一个额外的输入，来自固定为 +1 的虚拟单元 0，并且该输入有一个权重 `w0,j`。这使得即使前一层的输出全部为零，输入到单元 `j` 的总加权输入 `inj` 也可以非零。在此约定下，我们可以将前述方程写成向量形式：

`aj = gj(wᵀx)` (22.1)

其中 `w` 是进入单元 `j` 的权重向量（包括 `w0,j`），`x` 是输入到单元 `j` 的输入向量（包括 +1）。

激活函数是非线性的这一事实很重要，因为如果不是这样，单元的任何组合仍然代表线性函数。非线性使得足够大的单元网络能够表示任意函数。通用近似定理指出，仅有两个计算单元层的网络，第一层非线性，第二层线性，可以以任意精度逼近任何连续函数。证明是通过展示指数级大的网络可以在输入空间的不同位置表示指数级多的不同高度的“凸起”，从而逼近所需函数。换句话说，足够大的网络可以为连续函数实现查找表，就像足够大的决策树为布尔函数实现查找表一样。

使用各种不同的激活函数。最常见的是以下几种：

• 逻辑或 Sigmoid 函数，也用于逻辑回归（参见 [第 703 页](#Chapter19-06.xhtml#page_703)）：

Sigmoid

`σ(x) = 1/(1 + e^(-x))`.

• ReLU 函数，其名称是 rectified linear unit 的缩写：

ReLU

`ReLU(x) = max(0, x)`.

• Softplus 函数，是 ReLU 函数的光滑版本：

Softplus

`softplus(x) = log(1+e^(x))`.

Softplus 函数的导数是 Sigmoid 函数。

• tanh 函数：

Tanh

`tanh(x) = (e^(2x) - 1)/(e^(2x) + 1)`.

请注意，`tanh` 的取值范围是 (–1, +1)。`Tanh` 是 Sigmoid 的缩放和平移版本，因为 `tanh(x) = 2σ(2x) - 1`。
