
建立随机占优所需的属性分布之间的精确关系最好通过检查累积分布来观察，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。如果`S1`的累积分布始终位于`S2`的累积分布右侧，则从随机意义上讲，`S1`比`S2`便宜。形式上，如果两个行动`A1`和`A2`导致属性`X`上的概率分布`p1(x)`和`p2(x)`，则`A1`在`X`上随机占优于`A2`当且仅当

$\\forall x\\,\\,{\\int\\limits\_{- \\infty}^{x}{p\_{1}(x')dx'\\, \\leq {\\int\\limits\_{- \\infty}^{x}{p\_{2}(x')dx'.}}}}$

该定义与最优决策选择的相关性来自以下性质：如果`A1`随机占优于`A2`，则对于任何单调非递减效用函数`U(x)`，`A1`的期望效用至少与`A2`的期望效用一样高。要了解其原因，请考虑两个期望效用，`∫ p1(x)U(x)dx`和`∫ p2(x)U(x)dx`。最初，鉴于随机占优条件中`p1`积分小于`p2`积分，第一积分为何更大并不明显。
然而，与其考虑关于x的积分，不如考虑关于y的积分，即累积概率，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。对于y的任何值，对应的x值以及`U(x)`的值对`S1`来说比对`S2`更大；因此，如果我们在y的整个范围内积分一个更大的量，我们必然会得到更大的结果。形式上，这只是将y = `P1(x)`代入`S1`期望值积分中，将y = `P2(x)`代入`S2`积分中。进行这些替换后，我们有$dy = \\frac{d}{dx}(P\_{1}(x))dx = p\_{1}(x)dx$对于`S1`，dy = `p2(x)dx`对于`S2`，因此

$\\int\\limits\_{- \\infty}^{\\infty}{p1(x)U(x)dx = {\\int\\limits\_{0}^{1}{U(P\_{1}^{- 1}(y))dy \\geq {\\int\\limits\_{0}^{1}{U(P\_{2}^{- 1}(y))dy = {\\int\\limits\_{- \\infty}^{\\infty}{p\_{2}(x)U(x)dx}}}}}}.}$

该不等式使我们能够在单属性问题中偏好`A1`而非`A2`。更一般地，如果一个行动在多属性问题的所有属性上都被另一个行动随机占优，则可以将其丢弃。
随机占优条件可能看起来相当技术化，也许如果没有广泛的概率计算就很难评估。事实上，在许多情况下它可以很容易地确定。例如，你宁愿从3毫米还是3米的高度头朝下摔到混凝土上？假设你选择了3毫米——好选择！为什么它必然是一个更好的决定？在两种情况下，你将遭受的损害程度都存在很大不确定性；但对于任何给定的损害水平，从3米跌落时遭受至少该水平损害的概率高于从3毫米跌落时。换句话说，3毫米在安全属性上随机占优于3米。

$\\forall x\\,\\,{\\int\\limits\_{- \\infty}^{x}{p\_{1}(x')dx'\\, \\leq {\\int\\limits\_{- \\infty}^{x}{p\_{2}(x')dx'.}}}}$

该定义与最优决策选择的相关性来自以下性质：如果`A1`随机占优于`A2`，则对于任何单调非递减效用函数`U(x)`，`A1`的期望效用至少与`A2`的期望效用一样高。要了解其原因，请考虑两个期望效用，`∫ p1(x)U(x)dx`和`∫ p2(x)U(x)dx`。最初，鉴于随机占优条件中`p1`积分小于`p2`积分，第一积分为何更大并不明显。
然而，与其考虑关于x的积分，不如考虑关于y的积分，即累积概率，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。对于y的任何值，对应的x值以及`U(x)`的值对`S1`来说比对`S2`更大；因此，如果我们在y的整个范围内积分一个更大的量，我们必然会得到更大的结果。形式上，这只是将y = `P1(x)`代入`S1`期望值积分中，将y = `P2(x)`代入`S2`积分中。进行这些替换后，我们有$dy = \\frac{d}{dx}(P\_{1}(x))dx = p\_{1}(x)dx$对于`S1`，dy = `p2(x)dx`对于`S2`，因此

$\\int\\limits\_{- \\infty}^{\\infty}{p1(x)U(x)dx = {\\int\\limits\_{0}^{1}{U(P\_{1}^{- 1}(y))dy \\geq {\\int\\limits\_{0}^{1}{U(P\_{2}^{- 1}(y))dy = {\\int\\limits\_{- \\infty}^{\\infty}{p\_{2}(x)U(x)dx}}}}}}.}$

该不等式使我们能够在单属性问题中偏好`A1`而非`A2`。更一般地，如果一个行动在多属性问题的所有属性上都被另一个行动随机占优，则可以将其丢弃。

让我们从确定性情况开始。在[第522页](#Chapter15-02.xhtml#page_522)我们指出，对于确定性环境，智能体具有一个价值函数，我们在此记为`V(x1,...,xn)`；目标是简洁地表示该函数。确定性偏好结构中出现的[content]
建立随机占优所需的属性分布之间的精确关系最好通过检查累积分布来观察，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。如果`S1`的累积分布始终位于`S2`的累积分布右侧，则从随机意义上讲，`S1`比`S2`便宜。形式上，如果两个行动`A1`和`A2`导致属性`X`上的概率分布`p1(x)`和`p2(x)`，则`A1`在`X`上随机占优于`A2`当且仅当

$\\forall x\\,\\,{\\int\\limits\_{- \\infty}^{x}{p\_{1}(x')dx'\\, \\leq {\\int\\limits\_{- \\infty}^{x}{p\_{2}(x')dx'.}}}}$

该定义与最优决策选择的相关性来自以下性质：如果`A1`随机占优于`A2`，则对于任何单调非递减效用函数`U(x)`，`A1`的期望效用至少与`A2`的期望效用一样高。要了解其原因，请考虑两个期望效用，`∫ p1(x)U(x)dx`和`∫ p2(x)U(x)dx`。最初，鉴于随机占优条件中`p1`积分小于`p2`积分，第一积分为何更大并不明显。
然而，与其考虑关于x的积分，不如考虑关于y的积分，即累积概率，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。对于y的任何值，对应的x值以及`U(x)`的值对`S1`来说比对`S2`更大；因此，如果我们在y的整个范围内积分一个更大的量，我们必然会得到更大的结果。形式上，这只是将y = `P1(x)`代入`S1`期望值积分中，将y = `P2(x)`代入`S2`积分中。进行这些替换后，我们有$dy = \\frac{d}{dx}(P\_{1}(x))dx = p\_{1}(x)dx$对于`S1`，dy = `p2(x)dx`对于`S2`，因此

$\\int\\limits\_{- \\infty}^{\\infty}{p1(x)U(x)dx = {\\int\\limits\_{0}^{1}{U(P\_{1}^{- 1}(y))dy \\geq {\\int\\limits\_{0}^{1}{U(P\_{2}^{- 1}(y))dy = {\\int\\limits\_{- \\infty}^{\\infty}{p\_{2}(x)U(x)dx}}}}}}.}$

该不等式使我们能够在单属性问题中偏好`A1`而非`A2`。更一般地，如果一个行动在多属性问题的所有属性上都被另一个行动随机占优，则可以将其丢弃。
随机占优条件可能看起来相当技术化，也许如果没有广泛的概率计算就很难评估。事实上，在许多情况下它可以很容易地确定。例如，你宁愿从3毫米还是3米的高度头朝下摔到混凝土上？假设你选择了3毫米——好选择！为什么它必然是一个更好的决定？在两种情况下，你将遭受的损害程度都存在很大不确定性；但对于任何给定的损害水平，从3米跌落时遭受至少该水平损害的概率高于从3毫米跌落时。换句话说，3毫米在安全属性上随机占优于3米。
这种推理对人类来说是第二天性；它如此明显，我们甚至不会去思考。随机占优在机场问题中也很常见。例如，假设建筑运输成本取决于到供应商的距离。成本本身是不确定的，但距离越大，成本越大。如果`S1`比`S2`更近，则`S1`将在节俭性上占优于`S2`。尽管我们在此不介绍，但存在用于在定性概率网络中传播这种定性信息于不确定变量之间的算法，使系统能够基于随机占优做出理性决策，而无需使用任何数值。

> *定性概率网络*

## 15.4.2 偏好结构与多属性效用

假设我们有n个属性，每个属性都有d个不同的可能值。要指定完整的效用函数`U(x1,...,xn)`，在最坏情况下需要`d^n`个值。多属性效用理论旨在识别人类偏好中的额外结构，以便我们不需要单独指定所有`d^n`个值。在确定了偏好行为中的一些规律性后，我们随后推导出表示定理，以表明具有某种偏好结构的智能体具有效用函数

> *表示定理*

`U(x1,…,xn) = F[ f1(x1),…, fn(xn)]`,

其中`F`是（我们希望）像加法这样的简单函数。注意这与使用贝叶斯网络分解多个随机变量的联合概率的相似性。
例如，假设每个`xi`是智能体在特定货币中的金额：美元、欧元、马克、里拉等。`fi`函数然后可以将每个金额转换为通用货币，而`F`则简单地为加法。

### 无不确定性的偏好

让我们从确定性情况开始。在[第522页](#Chapter15-02.xhtml#page_522)我们指出，对于确定性环境，智能体具有一个价值函数，我们在此记为`V(x1,...,xn)`；目标是简洁地表示该函数。确定性偏好结构中出现的[content]
建立随机占优所需的属性分布关系最好通过累积分布观察，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。若`S1`的累积分布始终在`S2`右侧，则随机上`S1`比`S2`便宜。形式上，若两行动`A1`、`A2`在属性`X`上产生概率分布`p1(x)`、`p2(x)`，则`A1`在`X`上随机占优于`A2`当且仅当

$\\forall x\\,\\,{\\int\\limits\_{- \\infty}^{x}{p\_{1}(x')dx'\\, \\leq {\\int\\limits\_{- \\infty}^{x}{p\_{2}(x')dx'.}}}}$

该定义与最优决策选择的相关性来自：若`A1`随机占优于`A2`，则对任意单调非递减效用函数`U(x)`，`A1`的期望效用不低于`A2`。考虑`∫ p1(x)U(x)dx`和`∫ p2(x)U(x)dx`，在随机占优条件下`p1`积分更小，第一积分为何更大并不直观。
改用关于y即累积概率的积分，如[图 15.5(b)](#Chapter15-04.xhtml#fig15-5)所示。对任意y，对应x及`U(x)`对`S1`更大，故在y全域积分必更大。形式上令y=`P1(x)`、`P2(x)`，则$dy = \\frac{d}{dx}(P\_{1}(x))dx = p\_{1}(x)dx$对`S1`，dy=`p2(x)dx`对`S2`，故

$\\int\\limits\_{- \\infty}^{\\infty}{p1(x)U(x)dx = {\\int\\limits\_{0}^{1}{U(P\_{1}^{- 1}(y))dy \\geq {\\int\\limits\_{0}^{1}{U(P\_{2}^{- 1}(y))dy = {\\int\\limits\_{- \\infty}^{\\infty}{p\_{2}(x)U(x)dx}}}}}}.}$

该不等式允许在单属性问题中偏好`A1`。更一般地，若某行动在多属性问题所有属性上被另一行动随机占优，则可舍弃。
随机占优条件看似技术化，实则多可易判。如宁愿从3毫米还是3米头朝下摔向混凝土？选3毫米是好选择。两情形损害程度均不确定，但对任一损害水平，从3米跌落遭受至少该水平损害的概率高于3毫米。换言之，3毫米在安全属性上随机占优于3米。
此种推理对人类是本能。机场问题中随机占优亦常见。如建设运输成本随供应商距离而变，成本不确定但距离越大成本越大。若`S1`比`S2`更近，则`S1`在节俭性上占优。虽未在此呈现，定性概率网络中存在传播此类定性信息的算法，可使系统基于随机占优做理性决策而无需数值。

## 15.4.2 偏好结构与多属性效用

设n个属性各有d个可能值。指定完整效用函数`U(x1,...,xn)`最坏需`d^n`个值。多属性效用理论旨在识别偏好额外结构，避免逐个指定`d^n`个值。确定偏好行为的规律性后，可导出表示定理，表明具有某种偏好结构的智能体效用函数为

> *表示定理*

`U(x1,…,xn) = F[ f1(x1),…, fn(xn)]`,

其中`F`希望是加法等简单函数。类似贝叶斯网络分解联合概率。
例如各`xi`为智能体在某货币的金额：美元、欧元、马克、里拉等。`fi`可将各金额换算为通用货币，`F`即为加法。

### 无不确定性的偏好

从确定性情形开始。在[第522页](#Chapter15-02.xhtml#page_522)已指出，确定性环境下智能体有价值函数记为`V(x1,...,xn)`，目标是简洁表示。确定性偏好结构中出现的基本规律性称为偏好独立性。两属性`X1`、`X2`对第三属性`X3`偏好独立，若结果`<x1, x2, x3>`与`<x'1,x'2,x3>`的偏好不依赖于`X3`的具体值`x3`。

> *偏好独立性*

回到机场例子，考虑安静度、节俭性、安全。可提出安静度与节俭性对安全偏好独立。如当安全水平均为0.006死亡/十亿乘客英里时，偏好飞行路径居住2万人且建设成本40亿的方案优于居住7万人且成本3.7亿的方案，则安全水平为0.012或0.003时偏好不变；对安静度与节俭性的任意取值对亦成立。亦可看出节俭性与安全对安静度偏好独立，安静度与安全对节俭性偏好独立。
称属性集{安静度,节俭性,安全}具有互偏好独立性MPI。MPI表明各属性虽重要，但不影响彼此权衡方式。

> *互偏好独立性 (MPI)*

互偏好独立性名称复杂，但导致价值函数简洁形式(Debreu,1960)：若属性`X1,..., Xn`互偏好独立，则偏好可由价值函数表示

$V\\text{(}x\_{1}\\text{,}\\ldots\\text{,}x\_{n}\\text{)~=}{\\sum\\limits\_{i}{V\_{i}(x\_{i})\\ ,}}$

其中每个`Vi`仅涉及属性`Xi`。例如机场决策可用价值函数

`V(quietness, frugality, safety) = quietness × 10⁴ + frugality + safety × 10^(12)`.
