`Probit`

`probit` 模型的另一种选择是 `expit` 或 `inverse logit` 模型。它使用 `logistic function` `1/(1 + e–x)` 来产生一个软阈值——它将任意 `x` 映射到 0 到 1 之间的值。同样，对于我们的示例，我们将其翻转以使其成为递减函数；我们还将指数按 $4/\\sqrt{2\\pi}$ 缩放以匹配均值处 `probit` 的斜率：

`Expit` `Inverse logit` `Logistic function`

$\\left. P(buys \\middle| Cost = c) = 1 - \\frac{1}{1 + exp( - \\frac{4}{\\sqrt{2\\pi}},\\frac{c - \\mu}{\\sigma})}. \\right.$

这在 [图 13.8(b)](#Chapter13-02.xhtml#fig13-8) 中有所说明。两个分布看起来相似，但 `logit` 实际上具有更长的“尾部”。`probit` 通常更符合实际情况，但 `logistic function` 在数学上有时更容易处理。它在机器学习中被广泛使用。两种模型都可以推广以处理多个连续父节点，通过取父节点值的线性组合。这也适用于离散父节点，如果其值是整数；例如，对于 `k` 个布尔父节点，每个父节点被视为具有值 0 或 1，输入到 `expit` 或 `probit` 分布将是一个具有 `k` 个参数的加权线性组合，从而产生一个与前面讨论的 `noisy-OR` 模型非常相似的模型。

## 13.2.4 案例研究：汽车保险

一家汽车保险公司收到个人为特定车辆投保的申请，必须根据为该申请人预计支付的索赔决定收取的适当年保费。任务是构建一个 `Bayes net`，该网络捕捉领域的因果结构，并在申请表提供的证据下给出输出变量的准确、良好校准的分布。[3](#Chapter13-07.xhtml#sup13-3) `Bayes net` 将包括既不是输入也不是输出变量的隐藏变量，但这些变量对于构建网络使其具有合理的稀疏性和可管理的参数数量至关重要。隐藏变量在 [图 13.9](#Chapter13-02.xhtml#fig13-9) 中以棕色阴影显示。

待支付的索赔——在 [图 13.9](#Chapter13-02.xhtml#fig13-9) 中以淡紫色阴影显示——分为三种：申请人所受伤害的 `MedicalCost`；其他方对申请人及公司提起诉讼的 `LiabilityCost`；以及对任一方车辆的损坏和因盗窃导致的车辆损失的 `PropertyCost`。申请表要求以下输入信息（[图 13.9](#Chapter13-02.xhtml#fig13-9) 中的浅蓝色节点）：

•关于申请人：`Age`；`YearsLicensed`——自首次获得驾驶执照以来的时间；`DrivingRecord`——近期事故和交通违规的某些汇总，可能基于“积分”；以及（针对学生）`GoodStudent` 指标，表示 4 分制下的平均绩点为 3.0（B）。

•关于车辆：`MakeModel` 和 `VehicleYear`；是否具有 `Airbag`；以及 `SafetyFeatures` 的某些汇总，例如防抱死制动和碰撞预警。

•关于驾驶情况：每年行驶的 `Mileage` 以及车辆是否 `Garaged`，以及存放的安全程度。

现在我们需要思考如何将这些安排成因果结构。关键的隐藏变量是下一个时间段是否会发生 `Theft` 或 `Accident`。显然，不能要求申请人预测这些；它们必须从可用信息和保险公司的先前经验中推断出来。

导致 `Theft` 的因果因素是什么？`MakeModel` 肯定很重要——有些车型被盗的频率远高于其他车型，因为车辆和零件存在高效的转售市场；`CarValue` 也很重要，因为旧的、破旧的或行驶里程高的车辆转售价值较低。此外，存放在 `Garaged` 中且具有 `AntiTheft` 装置的车辆更难被盗。隐藏变量 `CarValue` 反过来又取决于 `MakeModel`、`VehicleYear` 和 `Mileage`。`CarValue` 还决定了发生 `Theft` 时的损失金额，因此它是 `OwnCarCost` 的贡献者之一（另一个是事故，我们稍后会讨论）。

在这种类型的模型中引入另一个隐藏变量 `SocioEcon`，即申请人的社会经济类别是很常见的。这被认为会影响广泛的行为和特征。在我们的模型中，没有以观察到的收入和职业变量形式存在的直接证据；[4](#Chapter13-07.xhtml#sup13-4) 但 `SocioEcon` 影响 `MakeModel` 和 `VehicleYear`；它还影响 `ExtraCar` 和 `GoodStudent`，并且在某种程度上取决于 `Age`。
