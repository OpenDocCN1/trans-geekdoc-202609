A more general way to think about the network is as a computation graph or dataflow graph—essentially a circuit in which each node represents an elementary computation. [Figure 22.3(b)](#Chapter22-01.xhtml#fig22-3) shows the computation graph corresponding to the network in [Figure 22.3(a)](#Chapter22-01.xhtml#fig22-3); the graph makes each element of the overall computation explicit. Each weight is like a volume control knob that determines how much the next node in the graph hears from that particular predecessor in the graph.

Just as [Equation (22.1)](#Chapter22-01.xhtml#eq22-1) described the operation of a unit in vector form, we can do something similar for the network as a whole. We will generally use `W` to denote a weight matrix; for this network, `W(1)` denotes the weights in the first layer (`w1,3`, `w1,4`, etc.) and `W(2)` denotes the weights in the second layer (`w3,5` etc.). $\\begin{matrix} {h\_{\\mathbf{w}}(\\mathbf{x})\\ = \\ \\mathbf{g}^{(2)}(\\mathbf{W}^{(2)}\\mathbf{g}^{(1)}(\\mathbf{W}^{(1)}\\mathbf{x})).} & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\text{(22}\\text{.3)}} \\\\ \\end{matrix}$

The computation graph in [Figure 22.3(b)](#Chapter22-01.xhtml#fig22-3) is relatively small and shallow, but the same idea applies to all forms of deep learning: we construct computation graphs and adjust their weights to fit the data. The graph in [Figure 22.3(b)](#Chapter22-01.xhtml#fig22-3) is also fully connected, meaning that every node in each layer is connected to every node in the next layer. This is in some sense the default, but we will see in [Section 22.3](#Chapter22-03.xhtml#sec22-3) that choosing the connectivity of the network is also important in achieving effective learning.

## 22.1.2 Gradients and learning

In [Section 19.6](#Chapter19-06.xhtml#sec19-6), we introduced an approach to supervised learning based on gradient descent: calculate the gradient of the loss function with respect to the weights, and adjust the weights along the gradient direction to reduce the loss. (If you have not already read [Section 19.6](#Chapter19-06.xhtml#sec19-6), we recommend strongly that you do so before continuing.) We can apply exactly the same approach to learning the weights in computation graphs. For the weights leading into units in the output layer—the ones that produce the output of the network, the gradient calculation is essentially identical to the process in [Section 19.6](#Chapter19-06.xhtml#sec19-6). For weights leading into units in the hidden layers, which are not directly connected to the outputs, the process is only slightly more complicated.

<p class="sidebar">Output layer</p> <p class="sidebar">Hidden layer</p>

For now, we will use the squared loss function, `L2`, and we will calculate the gradient for the network in [Figure 22.3](#Chapter22-01.xhtml#fig22-3) with respect to a single training example (`x`, `y`). (For multiple examples, the gradient is just the sum of the gradients for the individual examples.) The network outputs a prediction `ŷ` = `hw(x)` and the true value is `y`, so we have

$Loss(h\_{\\mathbf{w}})\\ = \\ L\_{2}(y,h\_{\\mathbf{w}}(\\mathbf{x}))\\ = \\ \\parallel y - h\_{\\mathbf{w}}(\\mathbf{x}) \\parallel^{2}\\ = \\ {(y - \\overset{\\land}{y})}^{2}.$
