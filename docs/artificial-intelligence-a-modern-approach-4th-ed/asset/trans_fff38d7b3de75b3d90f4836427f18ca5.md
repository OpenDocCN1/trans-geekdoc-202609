- 添加 `MaryCalls`：无父节点。
- 添加 `JohnCalls`：如果 Mary 打电话，那很可能意味着警报已经响起，这使得 John 打电话的可能性更大。因此，`JohnCalls` 需要 `MaryCalls` 作为父节点。
- 添加 `Alarm`：显然，如果两人都在打电话，那么警报响起的可能性比仅一人或无人打电话时更大，因此我们需要 `MaryCalls` 和 `JohnCalls` 都作为父节点。
- 添加 `Burglary`：如果我们知道警报状态，那么 John 或 Mary 的来电可能会给我们关于电话响铃或 Mary 音乐的信息，但与盗窃无关：

`P(Burglary|Alarm,JohnCalls,MaryCalls) = P(Burglary|Alarm)`.

因此我们只需要 `Alarm` 作为父节点。
- 添加 `Earthquake`：如果警报开启，更可能发生了地震。（警报有点像地震探测器。）但如果我们知道发生了盗窃，那么这就解释了警报，地震的概率也只会略高于正常水平。因此，我们需要 `Alarm` 和 `Burglary` 都作为父节点。

所得网络比 [图 13.2](#Chapter13-01.xhtml#fig13-2) 中的原始网络多出两个链接，并且需要 13 个条件概率而不是 10 个。更糟糕的是，其中一些链接代表着脆弱的关系，需要进行困难且不自然的概率判断，例如评估在给定 `Burglary` 和 `Alarm` 的情况下 `Earthquake` 的概率。这种现象相当普遍，并且与 [第 12.5.1 节](#Chapter12-05.xhtml#sec12-5-1) 中引入的因果模型与诊断模型之间的区别有关（另见练习 13.WUMD）。如果我们坚持因果模型，我们最终需要指定的数字就会更少，而且这些数字通常更容易给出。例如，在医学领域，Tversky 和 Kahneman（1982）已表明，专家医生更倾向于对因果规则而非诊断规则给出概率判断。[第 13.5 节](#Chapter13-05.xhtml#sec13-5) 更深入地探讨了因果模型的思想。

[图 13.3(b)](#Chapter13-02.xhtml#fig13-3) 显示了一个非常糟糕的节点顺序：`MaryCalls`、`JohnCalls`、`Earthquake`、`Burglary`、`Alarm`。该网络需要指定 31 个不同的概率——恰好与完整联合分布的个数相同。然而，必须认识到，任何这三个网络都可以表示完全相同的联合分布。[图 13.3](#Chapter13-02.xhtml#fig13-3) 中的两个版本只是未能表示所有条件独立关系，因此最终指定了大量不必要的数字。

## 13.2.1 Bayesian networks 中的条件独立关系

从 [方程 (13.2)](#Chapter13-02.xhtml#eq13-2) 中定义的贝叶斯网的语义出发，我们可以推导出许多条件独立性质。我们已经看到一个变量在给定其父节点的情况下与其它前驱变量条件独立的性质。还可以证明更一般的“非后代”性质，即：

每个变量在给定其父节点的情况下与它的非后代条件独立。

*后代*

例如，在 [图 13.2](#Chapter13-01.xhtml#fig13-2) 中，变量 `JohnCalls` 在给定 `Alarm` 的值时与 `Burglary`、`Earthquake` 和 `MaryCalls` 独立。该定义在 [图 13.4(a)](#Chapter13-02.xhtml#fig13-4) 中进行了说明。

描述

事实证明，非后代性质结合网络参数 `θ(Xi | Parents(Xi))` 被解释为条件概率 `P(Xi | Parents(Xi))`，足以重构 [方程 (13.2)](#Chapter13-02.xhtml#eq13-2) 中给出的完整联合分布。换句话说，可以以不同方式看待贝叶斯网的语义：与其将完整联合分布定义为条件分布的乘积，网络定义了一组条件独立性质。完整联合分布可以从这些性质中推导出来。

非后代性质隐含的另一个重要独立性质是：

一个变量在给定其父节点、子节点和子节点的父节点——即给定其马尔可夫毯——的情况下，与网络中所有其它节点条件独立。

*马尔可夫毯*

（练习 13.MARB 要求你证明这一点。）例如，变量 `Burglary` 在给定 `Alarm` 和 `Earthquake` 的情况下与 `JohnCalls` 和 `MaryCalls` 独立。该性质在 [图 13.4(b)](#Chapter13-02.xhtml#fig13-4) 中进行了说明。马尔可夫毯性质使得能够使用完全局部和分布式的随机采样过程进行推理算法，如 [第 13.4.2 节](#Chapter13-04.xhtml#sec13-4-2) 中所解释的。

在贝叶斯网中可能提出的最一般条件独立问题是，节点集合 `X` 是否在给定第三集合 `Z` 的情况下与另一集合 `Y` 条件独立。这可以通过检查贝叶斯网来高效确定 `Z` 是否 d-分离 `X` 和 `Y`。过程如下：

*d-分离*

1. 仅考虑由 `X`、`Y`、`Z` 及其祖先组成的祖先子图。

*祖先子图*

2. 在任意未链接且共享一个共同子节点的节点对之间添加链接；现在我们得到所谓的道德图。

*道德图*

3. 将所有有向链接替换为无向链接。

4. 如果在所得图中 `Z` 阻断了 `X` 与 `Y` 之间的所有路径，则 `Z` d-分离 `X` 和 `Y`。在这种情况下，给定 `Z`，`X` 与 `Y` 条件独立。否则，原始贝叶斯网不要求条件独立。

简而言之，d-分离意味着在无向、道德化、祖先子图中的分离。将该定义应用于 [图 13.2](#Chapter13-01.xhtml#fig13-2) 中的盗窃网络，我们可以推断 `Burglary` 和 `Earthquake` 在给定空集时独立（即它们绝对独立）；它们在给定 `Alarm` 时不一定条件独立；并且 `JohnCalls` 和 `MaryCalls` 在给定 `Alarm` 时条件独立。还要注意，马尔可夫毯性质直接由 d-分离性质得出，因为一个变量的马尔可夫毯将其与所有其它变量 d-分离。
