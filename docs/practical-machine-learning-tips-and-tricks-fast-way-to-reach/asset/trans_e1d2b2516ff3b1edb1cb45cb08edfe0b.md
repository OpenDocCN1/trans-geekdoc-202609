# 符号约定

## 简介

不可否认，要想出一份单一、可靠的文档来涵盖我们所讨论的各种信息、模型和计算，无疑是极具挑战性的。此外，符号约定在 AI 与统计学之间、以及不同书籍和论文之间均有差异。尽管如此，我们已尽力做到尽可能一致。下文我们总结了本书使用的大部分符号，尽管个别章节可能会引入新的符号。另请注意，同一符号在不同语境下可能具有不同含义，尽管我们在可能的情况下尽量避免这种情况。

## 通用数学符号

| 符号 | 含义 |
| :--- | :--- |
| `⌊x⌋` | `x` 的下取整，即向下取最接近的整数 |
| `⌈x⌉` | `x` 的上取整，即向上取最接近的整数 |
| `x * y` | `x` 和 `y` 的卷积 |
| `x ⊙ y` | `x` 和 `y` 的 Hadamard（逐元素）积 |
| `a ∧ b` | 逻辑与 |
| `a ∨ b` | 逻辑或 |
| `¬a` | 逻辑非 |
| `I(x)` | 指示函数，若 `x` 为真则 `I(x) = 1`，否则 `I(x) = 0` |
| `∞` | 无穷大 |
| `→` | 趋向于，例如 `n → ∞` |
| `∝` | 正比于，因此 `y = ax` 可写作 `y ∝ x` |
| `\|x\|` | 绝对值 |
| `\|S\|` | 集合的大小（基数） |
| `n!` | 阶乘函数 |
| `∇` | 一阶导数向量 |
| `∇²` | 二阶导数的 Hessian 矩阵 |
| `≜` | 定义为 |
| `O(·)` | Big-O：通常暗示上界 |
| `R` | 实数集 |
| `1 : n` | 范围：`1 : n = 1, 2, ..., n` |
| `≈` | 近似等于 |
| `arg max f(x)` | Argmax：使 `f` 最大化的 `x` 值 |
| `B(a,b) = Γ(a)Γ(b)/Γ(a+b)` | Beta 函数 |
| `B(α) = ∏ₖ Γ(αₖ) / Γ(∑ₖ αₖ)` | 多元 Beta 函数 |
| `(n k)` | `n` 选 `k`，等价于 `n!/(k!(n-k)!)` |
| `δ(x)` | Dirac delta 函数，若 `x = 0` 则 `δ(x) = ∞`，否则 `δ(x) = 0` |
| `exp(x)` | 指数函数 `eˣ` |
| `Γ(x) = ∫₀^∞ uˣ⁻¹e⁻ᵘ du` | Gamma 函数 |
| `ψ(x) = d log Γ(x) / dx` | Digamma 函数 |

## 线性代数符号

我们使用粗体小写字母表示向量，如 `x`；粗体大写字母表示矩阵，如 `X`。我们用非粗体大写字母表示矩阵中的元素，例如 `Xᵢⱼ`。除非另有说明，向量均视为列向量。我们用 `(x₁, · · · , x_D)` 表示通过堆叠 `D` 个标量构成的列向量。假设我们写作 `X = (x₁, · · · , x_n)`，其中左侧是一个矩阵，则意指将 `x_i` 沿列方向堆叠，形成一个矩阵。

| 符号 | 含义 |
| :--- | :--- |
| `X ≻ 0` | `X` 是正定矩阵 |
| `tr(X)` | 矩阵的迹 |
| `det(X)` | 矩阵 `X` 的行列式 |
| `\|X\|` | 矩阵 `X` 的行列式 |
| `X⁻¹` | 矩阵的逆 |
| `X†` | 矩阵的伪逆 |
| `Xᵀ` | 矩阵的转置 |
| `xᵀ` | 向量的转置 |
| `diag(x)` | 由向量 `x` 生成的对角矩阵 |
| `diag(X)` | 从矩阵 `X` 中提取的对角向量 |
| `I` or `I_d` | 大小为 `d×d` 的单位矩阵（对角线为 1，其余为 0） |
| `1` or `1_d` | 全 1 向量（长度为 `d`） |
| `0` or `0_d` | 全 0 向量（长度为 `d`） |
| `\|x\|₂ = \|x\| = √(∑ⱼ xⱼ²)` | 欧几里得范数或 `ℓ₂` 范数 |
| `\|x\|₁ = ∑ⱼ \|xⱼ\|` | `ℓ₁` 范数 |
| `X_{:,j}` | 矩阵的第 `j` 列 |
| `X_{i,:}` | 矩阵的第 `i` 行（一个列向量） |
| `X_{i,j}` | 矩阵 `X` 的元素 `(i, j)` |
| `x ⊗ y` | `x` 和 `y` 的张量积 |

## 概率符号

我们用小写字母表示随机和固定标量，粗体小写字母表示随机和固定向量，粗体大写字母表示随机和固定矩阵。偶尔我们也用非粗体大写字母表示标量随机变量。同样，我们对离散和连续随机变量均使用 `p()` 表示。

| 符号 | 含义 |
| :--- | :--- |
| `X, Y` | 随机变量 |
| `P()` | 随机事件的概率 |
| `F()` | 累积分布函数（CDF），也称分布函数 |
| `p(x)` | 概率质量函数（PMF） |
| `f(x)` | 概率密度函数（PDF） |
| `F(x,y)` | 联合 CDF |
| `p(x,y)` | 联合 PMF |
| `f(x,y)` | 联合 PDF |
| `p(X\|Y)` | 条件 PMF，也称条件概率 |
| `f_{X\|Y}(x\|y)` | 条件 PDF |
| `X ⊥ Y` | `X` 独立于 `Y` |
| `X ⊥̸ Y` | `X` 不独立于 `Y` |
| `X ⊥ Y \| Z` | 在给定 `Z` 的条件下，`X` 条件独立于 `Y` |
| `X ⊥̸ Y \| Z` | 在给定 `Z` 的条件下，`X` 不条件独立于 `Y` |
| `X ∼ p` | `X` 服从分布 `p` |
| `α` | Beta 或 Dirichlet 分布的参数 |
| `cov[X]` | `X` 的协方差 |
| `E[X]` | `X` 的期望值 |
| `E_q[X]` | `X` 关于分布 `q` 的期望值 |
| `H(X)` or `H(p)` | 分布 `p(X)` 的熵 |
| `I(X;Y)` | `X` 和 `Y` 之间的互信息 |
| `KL(p\|q)` | 从分布 `p` 到 `q` 的 KL 散度 |
| `ℓ(θ)` | 对数似然函数 |
| `L(θ,a)` | 当自然真实状态为 `θ` 时采取行动 `a` 的损失函数 |
| `λ` | 精度（方差的倒数）`λ = 1/σ²` |
| `Λ` | 精度矩阵 `Λ = Σ⁻¹` |
| `mode[X]` | `X` 的最可能值 |
| `μ` | 标量分布的均值 |
| `μ` | 多元分布的均值 |
| `Φ` | 标准正态分布的 CDF |
| `ϕ` | 标准正态分布的 PDF |
| `π` | 多项式参数向量，马尔可夫链的平稳分布 |
| `ρ` | 相关系数 |
| `sigm(x) = 1 / (1 + e⁻ˣ)` | Sigmoid（logistic）函数 |
| `σ²` | 方差 |
| `Σ` | 协方差矩阵 |
| `var[x]` | `x` 的方差 |
| `ν` | 自由度参数 |
| `Z` | 概率分布的归一化常数 |

## 机器学习/统计学符号

通常，我们用大写字母表示常量，如 `C, K, M, N, T` 等。我们用小写字母作为相应范围的哑索引，如 `c = 1 : C` 索引类别，`i = 1 : M` 索引数据样本，`j = 1 : N` 索引输入特征，`k = 1 : K` 索引状态或聚类，`t = 1 : T` 索引时间等。我们用 `x` 表示观测到的数据向量。在监督问题中，我们用 `y` 或 `y` 表示期望的输出标签。我们用 `z` 表示隐变量。有时我们也用 `q` 表示隐离散变量。

| 符号 | 含义 |
| :--- | :--- |
| `C` | 类别数量 |
| `D` | 数据向量的维度（特征数量） |
| `N` | 数据样本数量 |
| `N_c` | 类别 `c` 的样本数量，`N_c = ∑ᵢᴺ I(y_i = c)` |
| `R` | 输出数量（响应变量） |
| `D` | 训练数据 `D = {(x_i, y_i) \| i = 1 : N}` |
| `D_test` | 测试数据 |
| `X` | 输入空间 |
| `Y` | 输出空间 |
| `K` | 变量的状态数或维度（通常为隐变量） |
| `k(x,y)` | 核函数 |
| `K` | 核矩阵 |
| `H` | 假设空间 |
| `L` | 损失函数 |
| `J(θ)` | 代价函数 |
| `f(x)` | 决策函数 |
| `P(y\|x)` | 条件概率 |
| `λ` | `ℓ₂` 或 `ℓ₁` 正则化项的强度 |
| `ϕ(x)` | 特征向量 `x` 的基函数展开 |
| `Φ` | 设计矩阵 `X` 的基函数展开 |
| `q()` | 近似或建议分布 |
| `Q(θ, θ_old)` | EM 算法中的辅助函数 |
| `T` | 序列长度 |
| `T(D)` | 数据的检验统计量 |
| `T` | 马尔可夫链的转移矩阵 |
| `θ` | 参数向量 |
| `θ⁽ˢ⁾` | 参数向量的第 `s` 个样本 |
| `θ̂` | `θ` 的估计值（通常为 MLE 或 MAP） |
| `θ̂_MLE` | `θ` 的极大似然估计 |
| `θ̂_MAP` | `θ` 的 MAP 估计 |
| `θ̄` | `θ` 的估计值（通常为后验均值） |
| `w` | 回归权重向量（统计学中称为 `β`） |
| `b` | 偏置项（统计学中称为 `ε`） |
| `W` | 回归权重矩阵 |
| `x_{i,j}` | 数据样本 `i` 的分量（即特征）`j`，其中 `i = 1 : N, j = 1 : D` |
| `x_i` | 训练样本，`i = 1 : N` |
| `X` | 大小为 `N×D` 的设计矩阵 |
| `x̄` | 经验均值 `x̄ = 1/N ∑ᵢᴺ x_i` |
| `x̃` | 未来测试样本 |
| `x̃` | 特征测试样本 |
