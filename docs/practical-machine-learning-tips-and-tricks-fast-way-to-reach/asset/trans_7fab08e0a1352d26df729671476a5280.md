在 E 步中，我们使用以下公式计算数据点 `I` 对组 `k` 的后验责任：

```
rik p(qi = k | xi, θ) π N(xi | µk, Wk Wk^T ψk) (12.16)k
```

`zi` 的条件后验分布由下式给出：

```
p(zi | xi, qi = k, θ) = N(zi | µik, Σik) (12.17)

µik ≜ Σik Wk^T ψk^−1 (xi − µk) (12.19)
```

## 12.2 主成分分析 (PCA)

考虑一个 FA 模型，其中我们约束 `Ψ = σ²I`，且 `W` 为正交矩阵。可以证明 (Tipping and Bishop 1999)，当 `σ² → 0` 时，该模型退化为传统的（非概率）主成分分析 (PCA)，也称为 Karhunen-Loève 变换。`σ² > 0` 的变体称为概率 PCA (PPCA) (Tipping and Bishop 1999)，或合理 PCA (Roweis 1997)。

在 M 步中，通过定义以下量，同时估计 `µk` 和 `Wk` 最为直接：

```
W̃k = (Wk, µk) (12.20)
z̃ = (z, 1) (12.21)
bik = E[z | xi, qi = k] = E[(µik; 1)] (12.22)
Cik = E[zz^T | xi, qi = k] ≜ (12.23)
```

```
(E[zz^T | xi, qi = k]  E[z | xi, qi = k]) = E[z | xi, qi = k]^T 1 (12.24)
```

然后 M 步如下：

```
π̂k = 1/N ∑ rik (12.25)
W̃k = (∑ rik xi bik^T) (∑ rik xi Cik)^−1 (12.26)
Ψ̂ = 1/N diag ∑ rik (xi − W̃k bik) xi^T (12.27)
```

### 12.2.1 经典 PCA

#### 12.2.1.1 定理陈述

经典 PCA 的组合视角总结在以下定理中。

**定理 12.1。** 假设我们需要寻找一组 `L` 个正交基向量 `wj ∈ RD`，以及相应的得分 `zi ∈ RL`，使得我们最小化平均重构误差

```
J(W, Z) = 1/N ∑ ||xi − x̂i||²₂ (12.28)
i=1
```

其中 `x̂i = W zi`，受约束于 `W` 是正交的。等价地，我们可以将此目标写为如下形式

```
J(W, Z) = 1/N ||X − W Z^T||²_F (12.29)
```

其中 `Z` 是一个 `N × L` 矩阵，其列为 `zi`，`||A||_F` 是矩阵 `A` 的 Frobenius 范数，定义为

```
||A||_F ≜ √(∑∑ a²_ij) = tr(A^T A) (12.30)
i=1 j=1
```

标准做法是先标准化数据，或者等价地，使用相关矩阵而不是协方差矩阵。

最优解通过设置 `Ŵ = VL` 获得，其中 `VL` 包含经验协方差矩阵中具有最大特征值的 `L` 个特征向量，

```
Σ̂ = 1/N ∑ xi xi^T. （为符号简便，我们假设 xi 均值为零。）
i=1
```

此外，数据的最优低维编码由 `zi = W^T xi` 给出，这是数据在特征向量张成的列空间上的正交投影。图 12.1(a) 展示了 `D = 2` 和 `L = 1` 时的一个示例。倾斜的线是向量 `w1`；这被称为第一主成分或主方向。数据点 `xi ∈ R²` 被正交投影到这条线上以获得 `zi ∈ R`。这是对数据的最佳 1 维近似。（我们稍后将讨论图 12.1(b)。）

### 12.2.2 奇异值分解 (SVD)

我们已经用协方差矩阵的特征向量刻画了 PCA 的解。然而，还有一种基于奇异值分解 (SVD) 的求解方法。这本质上将特征向量的概念从方阵推广到了任意矩阵。

![](image_rsrc1RU.jpg) (a)
![](image_rsrc1RV.jpg) (b)

**图 12.1：** `D = 2` 和 `L = 1` 时 PCA 和 PPCA 的示意图。圆圈是原始项目，叉号是重构。红星是数据均值。(a) PCA。点被正交投影到线上。(b) PPCA。投影不再是正交的：重构向数据均值（红星）收缩。

主方向是数据显示最大方差的方向。这意味着 PCA 可能会被那些仅因测量尺度而导致方差高的方向误导。因此

**定理 12.2. (SVD)。** 任何矩阵都可以分解如下

```
X = U Σ V^T (12.31)
N×D  N×N  N×D  D×D
```

其中 `U` 是一个 `N × N` 矩阵，其列正交归一化（即 `U^T U = I`），`V` 是 `D × D` 矩阵，其行和列正交归一化（即 `V^T V = V V^T = ID`），`Σ` 是一个 `N × D` 矩阵，包含主对角线上的 `r = min(N, D)` 个奇异值 `σ ≥ 0`，其余位置填充 `0`。

这展示了如何将矩阵 `X` 分解为三个矩阵的乘积：`V` 描述数据空间中的一组正交基，`U` 描述余域中的一组正交基，`σ` 描述 `V` 中的向量被拉伸多少以得到 `U` 中的向量。由于最多有 `D` 个奇异值（假设 `N > D`），`U` 的最后 `N − D` 列无关紧要，因为它们将乘以 `0`。经济型 SVD 或精简 SVD 避免计算这些无用元素。

让我们用 `Û Σ̂ V̂^T` 表示这种分解。如果 `N > D`，我们有

```
X = Û Σ̂ V̂^T (12.32)
N×D  N×D  D×D  D×D
```

如图 12.2(a) 所示。如果 `N < D`，我们有

```
X = Û Σ̂ V̂^T (12.33)
N×D  N×N  N×N  N×D
```

计算经济型 SVD 需要 `O(ND min(N, D))` 时间 (Golub and van Loan 1996, p254)。

特征向量与奇异向量的联系如下：

```
U = evec(X X^T) (12.34)
V = evec(X^T X) (12.35)
Σ² = eval(X X^T) = eval(X^T X) (12.36)
```

证明请阅读 MLAPP 第 12.2.3 节。由于特征向量不受矩阵线性缩放的影响，我们看到 `X` 的右奇异向量等于经验协方差 `Σ̂` 的特征向量。此外，`Σ̂` 的特征值是平方奇异值的缩放版本。

然而，PCA 和 SVD 的联系更深。从公式 12.31，我们可以得到一个

![](image_rsrc1RX.jpg) (b)

**图 12.2：** (a) 非方阵 `X = U Σ V^T` 的 SVD 分解。`Σ` 的阴影部分及所有非对角项均为零。`U` 和 `Σ` 中的阴影条目在经济型版本中不计算，因为它们不是必需的。(b) 秩为 `L` 的截断 SVD 近似。

```
||X − XL||_F ≈ σL (12.38)
```

此外，可以证明 SVD 提供了矩阵的最佳秩 `L` 近似（最佳指在最小化上述 Frobenius 范数的意义上）。让我们将其联系回 PCA。设 `X = U Σ V^T` 为 `X` 的精简 SVD。我们知道 `Ŵ = V`，并且

```
Ẑ = X W, 所以
Ẑ = U Σ V^T V = U Σ (12.39)
```

此外，最优重构由 `X̂ = Z W` 给出，所以我们发现

```
X̂ = U Σ V^T (12.40)
```

这正是截断 SVD 近似！这是 PCA 是数据最佳低秩近似这一事实的另一种表述。
