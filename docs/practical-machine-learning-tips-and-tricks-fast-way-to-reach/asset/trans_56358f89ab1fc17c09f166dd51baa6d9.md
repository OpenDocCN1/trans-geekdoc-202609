

# 3.2.2 先验

先验是由人类而非机器选择的，因此它是抽象的。先验的主观性是有争议的。例如，一个年轻人和一位数学相关的教师将会得出不同的结论。由于概率项严重依赖于 `N`，而先验保持稳定，随着我们获得越来越多的数据，MAP 估计将趋向于最大似然估计或 MLE：

```
hMLE ≜ arg max_h p(D|h) = arg max_h log p(D|h)  (3.6)
```

换句话说，假设我们有足够的数据，我们会看到数据压倒了先验。

# 3.2.4 后验预测分布

后验预测分布的概念通常用于贝叶斯设定中，它利用给定观测数据的参数的整个后验分布，产生一个区间上的概率分布，而不仅仅是一个点估计。

```
p(x̃|D) = E_{h|D}[p(x̃|h)] = ∑_h p(x̃|h)p(h|D)  (3.7)
       = ∫ p(x̃|h)p(h|D)dh
```

这仅仅是每个单独假设预测的加权平均，被称为贝叶斯模型平均。

```
p(θ|Da,Db) = p(θ,Db|Da) / p(Da) ∝ p(θ,Db|Da)
           = p(Db,θ|Da)
           = p(Db|θ)p(θ|Da)
           = Bin(Nb1|θ, Nb1+Nb0) Beta(θ|Na1+a, Na0+b)
           = Beta(θ|Na1+Nb1+a, Na0+Nb0+b)  (3.10 and 2.19 combined)
```

这使得贝叶斯推断特别适合在线学习，稍后我们将看到。

# 3.3 Beta-二项模型

## 3.3.1 似然

给定 `X ~ Bin(θ)`，`D` 的概率由下式给出

```
p(D|θ) = Bin(N1|N,θ)  (3.8)
```

如果我们使用均匀先验，那么 MAP 估计将简化为 MLE：

```
θ_MAP ∝ θ_MLE = N1/N  (3.13)
```

## 3.3.2 先验

```
Beta(θ|a,b) ∝ θ^{a-1}(1-θ)^{b-1}  (3.9)
```

先验的参数被称为超参数。

我们现在将展示后验均值是先验均值和 MLE 的凸组合，这体现了后验是在我们先前所信和数据告诉我们的之间进行折衷。

### 3.3.3.1 后验均值和众数

根据表 2.7，后验均值由下式给出

```
θ̄ = (a+N1) / (a+b+N)  (3.11)
```

众数由下式给出

```
θ̂_MODE = (a+N1-1) / (a+b+N-2)  (3.12)
```

### 3.3.3.2 后验波动

均值和众数是点估计，但了解我们能在多大程度上信任它们是有帮助的。后验的方差是衡量这一点的一种方法。

Beta 后验的方差由下式给出

```
var(θ|D) = (a+N1)(b+N0) / [(a+N1+b+N0)^2 (a+N1+b+N0+1)]  (3.14)
```

在 `N ≫ a,b` 的情况下，我们可以简化这个繁琐的表达式，得到

```
var(θ|D) ≈ N1 N0 / N^3 = θ̂_MLE (1 - θ̂_MLE) / N  (3.15)
```

## 3.3.4 后验预测分布

```
Bb(x̃ | M, a, b) = B(x̃+a, M-x̃+b) / B(a,b)  (3.21)
```

到目前为止，我们一直专注于未知参数的推断。现在让我们将注意力转向未来可观测数据的预测。考虑在 `Beta(a,b)` 后验下预测单次未来试验中正面朝上的概率。我们有

```
p(x̃|D) = ∫_0^1 p(x̃|θ)p(θ|D)dθ
       = ∫_0^1 θ Beta(θ|a,b)dθ
       = E[θ|D] = a / (a+b)  (3.16)
```

该分布具有以下均值和方差

```
mean = M a / (a+b)
var  = M a b (a+b+M) / [(a+b)^2 (a+b+1)]  (3.22)
```

这一过程如图 3.1 所示。我们从 `Beta(2,2)` 先验开始，并在观测到 `N1 = 3` 次正面和 `N0 = 17` 次反面后绘制后验预测密度。图 3.1(b) 绘制了使用 MAP 估计的插值近似。我们看到贝叶斯预测具有更长的尾部，将其概率质量分布得更广，因此不太容易过拟合和黑天鹅类型的悖论。

### 3.3.4.1 过拟合与黑天鹅悖论

现在让我们推导一个简单的贝叶斯解决方案来解决这个问题。我们将使用均匀先验，所以 `a = b = 1`。在这种情况下，插入后验均值给出了拉普拉斯继承规则

```
p(x̃|D) = (N1 + 1) / (N0 + N1 + 1)  (3.17)
```

这证明了向经验计数加 1、归一化然后插入它们的常见做法是合理的，这种技术称为加一平滑。（注意插入 MAP 参数不会产生这种平滑效果，因为如果 `a = b = 1`，众数会变成 MLE，见第 3.3.3.1 节。）

### 3.3.4.2 预测多次未来试验的结果

现在假设我们对预测 `M` 次未来试验中正面的数量 `x̃` 感兴趣。这由下式给出

```
p(x̃|D) = ∫_0^1 Bin(x̃ | M,θ) Beta(θ|a,b) dθ  (3.18)
       = (M choose x̃) / B(a,b) ∫_0^1 θ^{x̃+a-1} (1-θ)^{M-x̃+b-1} dθ  (3.19)
```

# 3.4 Dirichlet-多项模型

在上一节中，我们讨论了如何推断硬币正面朝上的概率。在本节中，我们将这些结果推广到推断具有 `K` 个面的骰子朝上面 `k` 的概率。

## 3.4.1 似然

假设我们观测到 `N` 次掷骰子，`D = {x1, x2, ..., xN}`，其中 `xi ∈ {1, 2, ..., K}`。似然的形式为

```
p(D|θ) = (N! / (N1! ... NK!)) ∏_{k=1}^K θ_k^{Nk}  (3.23)
```

其中 `Nk = ∑_{i=1}^N I(yi = k)` 与公式 2.21 实质相同。

## 3.4.2 先验

```
Dir(θ|α) = (1/B(α)) ∏_{k=1}^K θ_k^{αk-1} I(θ ∈ S_K)  (3.24)
```

## 3.4.3 后验

```
p(θ|D) ∝ p(D|θ)p(θ)
       ∝ ∏_{k=1}^K θ_k^{Nk} ∏_{k=1}^K θ_k^{αk-1}
       = Dir(θ|α1+N1, ..., αK+NK)  (3.27)
```

根据公式 2.38，MAP 估计由下式给出

```
θ̂_k = (Nk + αk - 1) / (N + α0 - K)  (3.28)
```

如果我们使用均匀先验，`αk = 1`，我们恢复 MLE：

```
θ̂_k = Nk / N  (3.29)
```

## 3.4.4 后验预测分布

单次多努利试验的后验预测分布由以下表达式给出：

```
p(X = j|D) = ∫ p(X = j|θ)p(θ|D)dθ  (3.30)
           = ∫ [∫ p(X = j|θj) p(θ_{-j}, θj|D) dθ_{-j}] dθj  (3.31)
           = ∫ θj p(θ|D) dθj = E[θj|D] = (αj + Nj) / (α0 + N)  (3.32)
```

其中 `θ_{-j}` 是除 `θj` 以外的 `θ` 的所有分量。上述表达式避免了零计数问题。

事实上，这种贝叶斯平滑形式在多项情况下比二项情况下重要得多，因为一旦我们开始将数据分配到许多类别中，数据稀疏的可能性就会增加。

# 3.5 朴素贝叶斯分类器

假设特征在给定类别标签的条件下是独立的，那么类条件密度具有以下形式

```
p(x|y=c, θ) = ∏_{j=1}^D p(xj|y=c, θ_{jc})  (3.33)
```

由此产生的模型被称为朴素贝叶斯分类器 (NBC)。类条件密度的形式取决于每个特征的类型。我们在下面给出几种可能性：

*   对于真值特征，我们可以使用高斯分布：
    `p(x|y,θ) = ∏_{j=1}^D N(xj | µ_{jc}, σ^2_{jc})`，其中 `µ_{jc}` 是类别 `c` 中特征 `j` 的均值，`σ^2_{jc}` 是其方差。
*   对于二元特征，`xj ∈ {0,1}`，我们可以使用伯努利分布：
    `p(x|y,θ) = ∏_{j=1}^D Ber(xj | µ_{jc})`，其中 `µ_{jc}` 是特征 `j` 在类别 `c` 中出现的概率。这有时被称为多元伯努利朴素贝叶斯模型。我们将在下面看到它的一个应用。
