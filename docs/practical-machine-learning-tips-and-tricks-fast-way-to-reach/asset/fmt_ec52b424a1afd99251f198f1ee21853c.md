## Linear algebra notation

We use boldface lower-case to indicate vectors, such as `x`, and boldface capitalized to mean matrices, such as `X`. We indicate entries in a matrix by non-bold capitalized letters, for example, `Xᵢⱼ`. Vectors are thought to be column vectors, except if noted in any case. We use `(x₁, · · · , x_D)` to indicate a column vector made by stacking `D` scalars. Assuming we compose `X = (x₁, · · · , x_n)`, where the left hand side is a matrix, we intend to stack the `x_i` along the columns, making a matrix.

| Symbol | Meaning |
| :--- | :--- |
| `X ≻ 0` | `X` is a positive definite matrix |
| `tr(X)` | Trace of a matrix |
| `det(X)` | Determinant of matrix `X` |
| `\|X\|` | Determinant of matrix `X` |
| `X⁻¹` | Inverse of a matrix |
| `X†` | Pseudo-inverse of a matrix |
| `Xᵀ` | Transpose of a matrix |
| `xᵀ` | Transpose of a vector |
| `diag(x)` | Diagonal matrix produced using vector `x` |
| `diag(X)` | Diagonal vector extracted from matrix `X` |
| `I` or `I_d` | Identity matrix of size `d×d` (ones on diagonal, zeros off) |
| `1` or `1_d` | Vector of ones (of length `d`) |
| `0` or `0_d` | Vector of zeros (of length `d`) |
| `\|x\|₂ = \|x\| = √(∑ⱼ xⱼ²)` | Euclidean or `ℓ₂` norm |
| `\|x\|₁ = ∑ⱼ \|xⱼ\|` | `ℓ₁` norm |
| `X_{:,j}` | `j`'th column of matrix |
| `X_{i,:}` | `i`'th row of matrix (a column vector) |
| `X_{i,j}` | Element `(i, j)` of matrix `X` |
| `x ⊗ y` | Tensor product of `x` and `y` |

## Probability notation

We signify random and fixed scalars by lower case, random and fixed vectors by bold lower case, and random and fixed matrices by bold upper case. Occasionally we utilize non-bold capitalized to indicate scalar random variables. Likewise, we use `p()` for both discrete and continuous random variables.

| Symbol | Meaning |
| :--- | :--- |
| `X, Y` | Random variable |
| `P()` | Probability of a random event |
| `F()` | Cumulative distribution function (CDF), also called distribution function |
| `p(x)` | Probability mass function (PMF) |
| `f(x)` | Probability density function (PDF) |
| `F(x,y)` | Joint CDF |
| `p(x,y)` | Joint PMF |
| `f(x,y)` | Joint PDF |
| `p(X\|Y)` | Conditional PMF, also called conditional probability |
| `f_{X\|Y}(x\|y)` | Conditional PDF |
| `X ⊥ Y` | `X` is independent of `Y` |
| `X ⊥̸ Y` | `X` is not independent of `Y` |
| `X ⊥ Y \| Z` | `X` is conditionally independent of `Y` given `Z` |
| `X ⊥̸ Y \| Z` | `X` is not conditionally independent of `Y` given `Z` |
| `X ∼ p` | `X` is distributed by distribution `p` |
| `α` | Parameters of a Beta or Dirichlet distribution |
| `cov[X]` | Covariance of `X` |
| `E[X]` | Expected value of `X` |
| `E_q[X]` | Expected value of `X` wrt distribution `q` |
| `H(X)` or `H(p)` | Entropy of distribution `p(X)` |
| `I(X;Y)` | Mutual information between `X` and `Y` |
| `KL(p\|q)` | KL divergence from distribution `p` to `q` |
| `ℓ(θ)` | Log-likelihood function |
| `L(θ,a)` | Loss function for making action `a` when true state of nature is `θ` |
| `λ` | Precision (inverse variance) `λ = 1/σ²` |

| `mode[X]` | Most probable value of `X` |
| `μ` | Mean of a scalar distribution |
| `μ` | Mean of a multivariate distribution |
| `Φ` | CDF of standard normal |
| `ϕ` | PDF of standard normal |
| `π` | Multinomial parameter vector, Stationary distribution of Markov chain |
| `ρ` | Correlation coefficient |
| `sigm(x) = 1 / (1 + e⁻ˣ)` | Sigmoid (logistic) function |
| `σ²` | Variance |

| `Z` | Normalization constant of a probability distribution |

## Machine learning/statistics notation

In general, we use upper case letters to denote constants, such as `C, K, M, N, T`, etc. We use lower case letters as dummy indexes of the appropriate range, such as `c = 1 : C` to index classes, `i = 1 : M` to index data cases, `j = 1 : N` to index input features, `k = 1 : K` to index states or clusters, `t = 1 : T` to index time, etc. We utilize `x` to address a noticed information vector. In a managed issue, we use `y` or `y` to address the ideal result name. We use `z` to address a secret variable. Once in a while we likewise use `q` to address a covered up discrete variable.

| Symbol | Meaning |
| :--- | :--- |
| `C` | Number of classes |
| `D` | Dimensionality of data vector (number of features) |
| `N` | Number of data cases |
| `N_c` | Number of cases of class `c`, `N_c = ∑ᵢᴺ I(y_i = c)` |
| `R` | Number of outputs (response variables) |
| `D` | Training data `D = {(x_i, y_i) \| i = 1 : N}` |
| `D_test` | Test data |
| `X` | Input space |
| `Y` | Output space |
| `K` | Number of states or dimensions of a variable (typically latent) |
| `k(x,y)` | Kernel function |
| `K` | Kernel matrix |
| `H` | Hypothesis space |
| `L` | Loss function |
| `J(θ)` | Cost function |
| `f(x)` | Decision function |
| `P(y\|x)` | Conditional probability |
| `λ` | Strength of `ℓ₂` or `ℓ₁` regularizer |
| `ϕ(x)` | Basis function expansion of feature vector `x` |
| `Φ` | Basis function expansion of design matrix `X` |
| `q()` | Approximate or proposal distribution |
| `Q(θ, θ_old)` | Auxiliary function in EM |
| `T` | Length of a sequence |

| `w` | Vector of regression weights (called `β` in statistics) |
| `b` | Bias (called `ε` in statistics) |
| `W` | Matrix of regression weights |
| `x_{i,j}` | Component (i.e., feature) `j` of data case `i`, for `i = 1 : N, j = 1 : D` |
