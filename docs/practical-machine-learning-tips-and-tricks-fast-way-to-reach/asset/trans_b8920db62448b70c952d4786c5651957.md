## 3.5.1.2 贝叶斯朴素贝叶斯

我们目前考察如何训练朴素贝叶斯分类器。这通常意味着求解参数的 MLE（极大似然估计）或 MAP（最大后验估计）。然而，我们也将探讨如何计算完整后验分布 `p(θ|D)`。

对 `π` 使用 `Dir(α)` 先验。对于二元特征，对每个 `θjc` 使用 `Beta(β0,β1)` 先验；对于离散特征，对每个 `θjc` 使用 `Dir(α)` 先验。通常我们只取 `α = 1` 和 `β = 1`，这对应加一平滑或拉普拉斯平滑。

## 3.5.2 使用模型进行预测

我们可以使用 MLE 或 MAP 估计参数，然后通过简单地代入参数 `θ̂(MLE)` 或 `θ̂(MAP)` 获得后验预测密度。或者我们可以使用 BMA（贝叶斯模型平均），直接对未知参数进行积分边缘化。

## 3.5.3 log-sum-exp 技巧

当使用任何类型的生成式分类器时，由于数值下溢，使用公式 3.1 计算类标签的后验可能会失败。问题在于 `p(x|y = c)` 通常是一个非常小的数字，特别是当 x 是高维向量时。这是因为我们要求 `∑x p(x|y) = 1`，所以观察到特定高维向量的概率很小。显而易见的解决方案是在应用贝叶斯规则时取对数，如下所示：

```
log p(y = c|x,θ) = bc − log ∑ e^bc'
c'
```

其中 `bc ≜ log p(x|y = c,θ) + log p(y = c|θ)`。我们可以提取最大的项，并仅计算相对于该项的剩余数值。例如：

```
log(e^−120 + e^−121) = log(e^−120(1+e^−1))
= log(1+e^−1) − 120
```

一般来说，我们有：

```
log ∑ e^bc = log ∑ e^(bc−B) + B

```

其中 `B ≜ max{bc}`。这被称为 log-sum-exp 技巧，被广泛使用。

## 3.5.4 使用互信息进行特征选择

这被称为伯努利乘积模型，或二元独立模型。由于 NBC 要对潜在的许多特征拟合联合分布，它可能会遭受过拟合。此外，运行时成本是 `O(D)`，对于某些应用可能过高。解决这两个问题的一种常见方法是执行特征选择，以消除对分类问题帮助不大的无关特征。最简单的特征选择方法是单独评估每个特征的重要性，然后取前 K 个，其中 K 是基于精度和复杂度之间的某种权衡来选择的。这种方法称为特征排序、过滤或筛选。衡量重要性的一种方法是使用特征 `Xj` 和类标签 `Y` 之间的互信息（第 2.8.3 节）：

```
I(Xj,Y) = ∑ ∑ p(xj,y) log p(xj,y) / (p(xj)p(y))
xj y
```

如果特征是二元的，很容易证明 MI 可以按如下方式计算：

```
Ij = ∑ [ θjc πc log (θjc/θj) + (1− θjc) πc log ((1− θjc)/(1− θj)) ]
c
```

其中 `πc = p(y = c)`，`θjc = p(xj = 1|y = c)`，且 `θj = p(xj = 1) = ∑c πc θjc`。

然而，忽略每个词在文档中出现的次数会丢失一些信息（McCallum and Nigam 1998）。一种更准确的表示是统计每个词的出现次数。具体来说，令 `xi` 为文档 i 的计数向量，因此 `xij ∈ {0,1,··· ,Ni}`，其中 `Ni` 是文档 i 中的术语数量（所以 `∑j xij = Ni`）。对于类条件密度，我们可以使用多项分布：


我们在此隐含地假设文档长度 `Ni` 与类别无关。这里 `θjc` 是在类别 c 的文档中生成词 j 的概率；这些参数满足约束条件 `∑j=1^D θjc = 1`，对每个类别 c 均成立。

虽然多项式分类器易于训练且在测试时简单易用，但它在文档分类方面效果不佳。原因之一是它没有考虑词语使用的爆发性。这指的是大多数词从不出现在任何给定文档中，但如果它们出现一次，则很可能再次出现，即词语成簇出现。多项式模型无法捕捉爆发性现象。要了解原因，请注意公式 3.46 具有 `θjc^xij` 的形式，由于罕见词的 `θjc ≪ 1`，生成大量此类词的概率变得越来越小。对于更常见的词，衰减率没有那么快。为了直观地理解原因，请注意最常见的词是功能词，它们不特定于类别，例如 and、the 和 but；无论词 and 之前出现过多少次（模ulo 文档长度），它出现的机会大致相同，因此独立性假设对常见词更合理。

然而，由于罕见词对于分类目的最为重要，这些是我们最希望仔细建模的词。
