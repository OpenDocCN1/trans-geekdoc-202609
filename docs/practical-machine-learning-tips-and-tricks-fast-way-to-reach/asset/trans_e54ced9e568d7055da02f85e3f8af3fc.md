### 11.4.11.1 F 函数的极大化-极大化算法

**定义 11.1。** 给定隐变量 Z 的概率分布为 `˜(Z)`，定义 F 函数如下：

```
˜ ˜ F(P,θ) = E ˜[logP(X,Z|θ)] + H(P) (11.34)
```

其中 `H(P) = −E ˜[log ˜P(Z)]`，即 `˜P(Z)` 的熵。

假设 `θt−1` 是第 (t−1) 次迭代中 `θ` 的估计，`˜t−1` 是第 (t−1) 次迭代中 `˜P` 的估计。则第 t 次迭代的两个步骤为：
1. 固定 `θt−1`，寻找使 `F(˜P, θt−1)` 极大化的 `˜t`；
2. 固定 `˜t`，寻找使 `F(˜Pt, θ)` 极大化的 `θt`。

**引理 11.1。** 对于固定的 `θ`，仅存在一个分布 `˜Pθ` 使 `F(˜P, θ)` 极大化：

```
˜Pθ(Z) = P(Z|X,θ) (11.35)
```

**证明。** 给定固定的 `θ`，我们可以得到使 `F(˜P, θ)` 极大化的 `˜θ`。我们构造拉格朗日函数：

```
˜ log ˜Pθ(Z)
L(˜P, θ) = E ˜[logP(X,Z|θ)] − E ˜[P] + λ(1 − ∑P(Z))
Z
```

对 `˜Pθ(Z)` 求偏导数，得到：

```
∂L/∂˜Pθ(Z) = logP(X,Z|θ) − log ˜Pθ(Z) − 1 − λ
```

令其等于 0，可得 `λ = logP(X,Z|θ) − log ˜θ(Z) − 1`。

然后我们可以推导出 `˜Pθ(Z)` 与 `P(X,Z|θ)` 成正比：

```
P(X,Z|θ) = e1+λ ˜Pθ(Z)
˜Pθ(Z) = P(X,Z|θ) / e1+λ
∑P(X,Z|θ) = 1
Z
⇒ e1+λ = ∑P(X,Z|θ) = P(X|θ)
Z
⇒ ˜Pθ(Z) = P(X,Z|θ) / P(X|θ) = P(Z|X,θ)
```

**引理 11.2。** 若 `˜Pθ(Z) = P(Z|X,θ)`，则：

```
˜F(P, θ) = logP(X|θ) (11.37)
```

**定理 11.2.** EM 算法的一次迭代可以实现为 F 函数的极大化-极大化。

**证明。**
(1) 根据引理 11.1，可得 `˜Pt(Z) = P(Z|X,θt−1)`。
(2) 根据上述，可得：

```
˜F(Pt, θ) = E ˜t[logP(X,Z|θ)] + H(Pt)
= ∑P(Z|X,θt−1)logP(X,Z|θ) + H(Pt)
Z
= Q(θ, θt−1) + H(Pt)
```

且 `˜Pθ` 关于 `θ` 连续。则使 `F(˜Pt, θ)` 极大化的 `θt` 为：

```
θt = arg max F(Pt, θ) = arg max Q(θ, θt−1)
θ θ
```

### 11.4.11.2 广义 EM 算法 (GEM)

在上述 EM 算法的公式化中，`θt` 被选为使 `Q(θ, θt−1)` 极大化的 `θ` 值。虽然这确保了 `ℓ(θ)` 最大程度地增加，但可以将极大化的要求放宽为仅增加 `Q(θ, θt−1)`，即 `Q(θt, θt−1) ≥ Q(θt−1, θt−1)`。这种仅增加而不一定极大化 `Q(θt, θt−1)` 的方法称为**广义期望极大化 (GEM)** 算法，在极大化困难的情况下通常很有用。GEM 算法的收敛性与 EM 算法类似。

## 11.5 潜变量模型的模型选择

使用 LVM 时，我们必须指定潜变量的数量，这控制着模型复杂度。特别是对于混合模型，我们必须指定 K，即聚类的数量。选择这些参数是模型选择的一个例子。下面我们讨论一些方法。

### 11.5.1 概率模型的模型选择

第 5.3 节讨论的最优贝叶斯方法是选择边际似然 `K = arg maxk p(D|k)` 最大的模型。这存在两个问题。首先，对 LVM 计算边际似然相当困难。实践中，可以使用简单的近似，如 BIC（参见例如 Fraley and Raftery 2002）。或者，我们可以使用交叉验证似然作为性能度量，尽管这可能很慢，因为它需要拟合每个模型 F 次，其中 F 是 CV 折数。第二个问题是需要在潜在的大量模型中搜索。通常的方法是对所有候选 K 值进行穷尽搜索。然而，有时我们可以将模型设置为最大规模，然后依靠贝叶斯奥卡姆剃刀的力量来消除不需要的组件。第 TODO 21.6.1.6 节将展示一个例子，届时我们将讨论变分贝叶斯。另一种方法是在模型空间中进行随机采样。传统方法（如 Green 1998, 2003; Lunn et al. 2009）基于可逆跳 MCMC，使用出生移动来提议新中心，使用死亡移动来消除旧中心。然而，这可能很慢且难以实现。一种更简单的方法是使用狄利克雷过程混合模型，它可以使用吉布斯采样进行拟合，但仍允许无限数量的混合成分；详见第 TODO 25.2 节。也许令人惊讶的是，这些基于采样的方法可能比单独评估每个 K 质量的简单方法更快。原因在于为每个 K 拟合模型通常很慢。相比之下，采样方法通常能快速确定某个 K 值较差，因此无需在后验的该部分浪费时间。

### 11.5.2 非概率方法的模型选择

如果我们不使用概率模型怎么办？例如，如何为 K-means 算法选择 K？由于这不对应概率模型，因此没有似然，所以上述方法都无法使用。似然的一个明显代理指标是重构误差。定义使用模型复杂度 K 对数据集 D 的平方重构误差如下：

```
E(D, K) ≜ 1/N ∑|xi − x̂i|² (11.38)
|D| i=1
```

对于 K-means，重构由 `xi = µzi` 给出，其中 `zi = arg mink ||xi − µk||²`，如第 11.4.2.6 节 TODO 所述。在监督学习中，我们总是可以使用交叉验证在不同复杂度的非概率模型之间进行选择，但无监督学习则不然。最常用的方法是绘制训练集上的重构误差随 K 变化的曲线，并尝试识别曲线中的肘部或拐点。
