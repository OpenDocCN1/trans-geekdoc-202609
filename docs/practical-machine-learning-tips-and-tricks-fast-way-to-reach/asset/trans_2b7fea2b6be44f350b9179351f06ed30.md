### 5.2.3 比例差异的推断

```

```

有时我们有多个参数，并且我们有兴趣计算这些参数的某个函数的后验分布。例如，假设你要从 Amazon.com 购买某样东西，并且有两个供应商以相同的价格提供该商品。供应商 1 有 90 条好评和 10 条差评。供应商 2 有 2 条好评和 0 条差评。你应该从谁那里购买？ 18. 表面上看，你应该选择供应商 2，但我们不能非常确定供应商 2 更好，因为它的评价很少。在本节中，我们将概述对该问题的贝叶斯分析。类似的技术可用于在各种不同情境下比较各组间的比率或比例。

设 `θ1` 和 `θ2` 为两个供应商未知的可靠性。由于我们对它们知之甚少，我们将赋予它们均匀先验，`θ ~ Beta(1,1)`。后验分别为 `p(θ1|D1) = Beta(91,11)` 和 `p(θ2|D2) = ~Beta(3,1)`。我们需要计算 `p(θ1 > θ2|D)`。为了方便，让我们定义 `δ = θ1 − θ2` 为比率之差。（或者我们可以用对数几率比来处理。）我们可以使用数值积分计算所需的量：

```
∫ 1 ∫ 1
p(δ > 0|D) = I(θ1 > θ2) Beta(θ1|91,11) Beta(θ2|3,1) dθ1 dθ2
0 0  (5.2)
```

我们发现 `p(δ > 0|D) = 0.710`，这意味着你最好从供应商 1 处购买！

由此，我们可以轻松计算 MAP 模型，`m = arg max_m p(m|D)`。这被称为贝叶斯模型选择。如果我们对模型使用均匀先验，这相当于选择使以下公式最大化的模型：

```
∫
p(D|m) = p(D|θ)p(θ|m) dθ  (5.4)
```

该量被称为边际似然、积分似然或模型 `m` 的证据。关于如何执行此积分的细节将在第 5.3.2 节讨论。但首先，我们给出该量含义的直观解释。

### 5.3.1 贝叶斯奥卡姆剃刀

人们可能会认为，使用 `p(D|m)` 来选择模型将总是倾向于参数最多的模型。

```
ˆ
```

如果我们使用 `p(D|θ_m)` 来选择模型，其中 `ˆ θ_m` 是模型 `m` 参数的 MLE 或 MAP 估计，那么这是正确的，因为参数更多的模型将更好地拟合数据，从而获得更高的似然。然而，如果我们对参数进行积分（边缘化），而不是最大化它们，我们将自动免受过拟合之害：参数更多的模型不一定具有更高的边际似然。这被称为贝叶斯奥卡姆剃刀效应（MacKay 1995b; Murray and Ghahramani 2005），得名于奥卡姆剃刀原则，即应选择能充分解释数据的最简单模型。

理解贝叶斯奥卡姆剃刀的一种方法是注意到，根据概率链式法则（公式 2.3），边际似然可以重写如下：

```
p(D) = p((x1,y1)) p((x2,y2)|(x1,y1))
       p((x3,y3)|(x1,y1) : (x2,y2)) ···  (5.5)
       p((xN,yN)|(x1,y1) : (xN−1,yN−1))
```

这类似于似然的留一交叉验证估计（第 1.3.4 节），因为我们根据所有过去的点预测每个未来的点。（当然，上述表达式中数据的顺序无关紧要。）如果模型过于复杂，它将过拟合早期的样本，进而对剩余样本预测不佳。

理解贝叶斯奥卡姆剃刀效应的另一种方法是注意到概率必须归一。因此 `∑ p(D′) p(m|D′) = 1`，其中求和是在所有可能的数据集上进行的。能预测许多事物的复杂模型必须将其概率质量分散得很薄，因此对于任何给定的数据集，其获得的似然不会比简单模型大。这有时被称为概率质量守恒原则，如图 5.3 所示。

```

当使用贝叶斯方法时，我们不局限于在有限的网格值上评估证据。相反，我们可以使用数值优化来寻找 `λ = arg max_λ p(D|λ)`。这种方法称为经验贝叶斯或 II 类最大似然估计（详见第 5.6 节）。图 TODO(b) 显示了一个示例：我们看到该曲线的形状与 CV 估计相似，但可以更高效地计算。

在讨论固定模型的参数推断时，我们经常写作：

```
p(θ|D,m) ∝ p(θ|m) p(D|θ,m)  (5.6)
```

因此忽略了归一化常数 `p(D|m)`。这对于 `θ` 是有效的，因为 `p(D|m)` 相对于 `θ` 是常数。然而，在比较模型时，我们需要知道如何计算边际似然 `p(D|m)`。通常这可能非常困难，因为我们需要对所有可能的参数值进行积分，但当我们有共轭先验时，计算起来很容易，我们现在将展示这一点。

设 `p(θ) = q(θ)/Z0` 为我们的先验，其中 `q(θ)` 是未归一化分布，`Z0` 是先验的归一化常数。设 `p(D|θ) = q(D|θ)/Zℓ` 为似然，其中 `Zℓ` 包含似然中的任何常数因子。

```
