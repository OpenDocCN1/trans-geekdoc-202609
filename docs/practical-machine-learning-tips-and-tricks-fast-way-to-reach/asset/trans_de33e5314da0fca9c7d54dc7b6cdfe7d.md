

# w 的大小决定了策略容量的陡峭程度

`w` 的大小决定了策略容量的陡峭程度，这取决于均值之间的隔离程度与方差的相对比较。在脑科学和信号检测理论中，通常使用一个称为 d-prime 的量来表征信号相对于背景噪声的可辨别度：

```
d′ ≜ (µ1 − µ0) / σ
```

其中 `µ1` 是信号的均值，`µ0` 是噪声的均值，`σ` 是噪声的标准差。如果 `d′` 很大，信号将更容易从噪声中分离出来。

## 4.2.5 防止过拟合的策略

MLE 方法的速度和简洁性或许是其最大的吸引力。然而，MLE 在高维情况下可能会严重过拟合。具体来说，当 `N_c < D` 时，全协方差矩阵的 MLE 是奇异的。即使 `N_c > D`，MLE 也可能是病态的，意味着它接近奇异。针对这个问题有几种潜在的解决方案：

*   对每个类使用对角协方差矩阵，这假设特征在条件上是独立的；这等同于使用朴素贝叶斯分类器（第 3.5 节）。
*   使用全协方差矩阵，但将其约束为所有类共享，即 `Σ_c = Σ`。这是参数绑定或参数共享的一个例子，等同于 LDA（第 4.2.2 节）。
*   使用对角协方差矩阵并约束其共享。这称为对角协方差 LDA，将在第 TODO 节讨论。
*   使用全协方差矩阵，但施加先验然后将其积分掉。如果我们使用共轭先验，这可以利用第 TODO 节的结果以闭式形式完成；这类似于第 3.5.1.2 节的贝叶斯朴素贝叶斯方法。详见 (Minka 2000f)。
*   通过 MAP 估计拟合全或对角协方差矩阵。我们在下面讨论两种不同类型的先验。
*   将数据投影到低维子空间，在那里拟合高斯分布。参见第 TODO 节以寻找最佳（最具判别性）线性投影的方法。

### 4.3.1 结果陈述

**定理 4.2.** (多元正态分布的边缘分布和条件分布)。假设 `X = (x1, x2)` 服从联合高斯分布，参数为：

```
µ = (µ1, µ2),  Σ = (Σ11 Σ12; Σ21 Σ22),  Λ = Σ^−1 = (λ11 λ12; λ21 λ22)
```

则边缘分布由下式给出：

```
p(x1) = N(x1 | µ1, Σ11)
p(x2) = N(x2 | µ2, Σ22)
```

后验条件分布由下式给出：

```
p(x1 | x2) = N(x1 | µ1|2, Σ1|2)
µ1|2 = µ1 + Σ12 Σ22^−1 (x2 − µ2)
     = µ1 − λ11^−1 λ12 (x2 − µ2)
     = Σ1|2 (λ11 µ1 − λ12 (x2 − µ2))
Σ1|2 = Σ11 − Σ12 Σ22^−1 Σ21 = λ11^−1
```

## 4.4 线性高斯系统

假设我们有两个变量 `x` 和 `y`。令 `x ∈ R^Dx` 为隐变量，`y ∈ R^Dy` 为 `x` 的噪声观测。假设我们有以下先验和似然：

```
p(x) = N(x | µx, Σx)
p(y | x) = N(y | W x + µy, Σy)
```

其中 `W` 是大小为 `Dy × Dx` 的矩阵。这是一个线性高斯系统的例子。我们可以用 `x → y` 示意性地表示，意味着 `x` 生成 `y`。在本节中，我们展示如何反转箭头，即如何从 `y` 推断 `x`。我们在下面陈述结果，然后给出一些例子，最后推导结果。我们将在后续章节看到这些结果的更多应用。

### 4.4.1 结果陈述

**定理 4.3.** (线性高斯系统的贝叶斯规则)。给定如公式 4.37 所示的线性高斯系统，后验 `p(x | y)` 由下式给出：

```
p(x | y) = N(x | µx|y, Σx|y)
Σx|y = (Σx^−1 + W^T Σy^−1 W)^−1
µx|y = Σx|y [W^T Σy^−1 (y − µy) + Σx^−1 µx]
```

此外，归一化常数 `p(y)` 由下式给出：

```
p(y) = N(y | W µx + µy, Σy + W Σx W^T)
```

### 5.2.1.1 无不确定性度量

使用后验分布来总结我们对一组未知变量的所有了解，是贝叶斯统计的核心。在本章中，我们将更详细地讨论这种统计方法。

MAP 估计最明显的缺点，实际上任何点估计（如后验均值或中位数）的缺点，都是它不提供任何不确定性度量。在许多应用中，知道可以在多大程度上信任给定的估计至关重要。我们可以从后验中获得此类确定性度量，正如我们在第 5.2.2 节讨论的那样。后验 `p(θ | D)` 总结了我们对未知量 `θ` 的所有了解。在本节中，我们讨论可以从概率分布（如后验）中得出的一些基本量。这些汇总统计量通常比完整的联合分布更易于理解和可视化。
