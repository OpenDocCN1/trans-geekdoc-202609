之所以在 ICA 中早先拒绝将高斯分布作为源，是因为它不允许对源进行唯一恢复。这是因为 PCA 似然对源 `zt` 和混合矩阵 `W` 的任何正交变换都是不变的。PCA 可以恢复信号所在的最佳线性子空间，但无法唯一恢复信号本身。ICA 要求 `W` 是方阵，因此可逆。在非方阵情况下（例如源比传感器多时），我们无法唯一恢复真实信号，但可以计算后验 `p(zt|xt,W)`，这代表了我们对源的信念。在这两种情况下，我们都需要估计 `W` 以及源分布 `pj`。下面我们将探讨如何做到这一点。

令 `xt ∈ RD` 为时刻 `t` 传感器处观测到的信号，`zt ∈ RL` 为源信号向量。我们假设

```
xt = W zt + ϵt (12.50)
```

其中 `W` 是一个 `D×L` 矩阵，且 `ϵt ∼ N(0,Ψ)`。在本部分中，我们将每个时间点视为独立观测，即我们不建模时间相关性（因此可以用 `I` 替换下标 `t`，但我们保留 `t` 以与大部分 ICA 文献保持一致）。目标是推断源信号 `p(zt|xt,θ)`。在此背景下，`W` 称为混合矩阵。如果 `L = D`（源的数量 = 传感器的数量），则 `W` 为方阵。

在本部分中，我们讨论评估无噪声 ICA 模型中方形混合矩阵 `W` 的方法。按照惯例，我们假设观测值已中心化；因此我们也可以假设 `z` 为零均值。此外，我们假设观测值已白化，这可以通过 PCA 完成。如果数据已中心化且白化，则有 `E[xxT] = I`。然而，在无噪声情况下，我们还有

```
cov[x] = E[xxT] = WE[zzT]WT (12.52)
```

因此我们看到 `W` 必须是正交的。这将我们需要估计的参数数量从 `D2` 减少到 `D(D−1)/2`。它还将简化数学推导和算法。令 `V = W−1`；这些通常称为识别权重，相对于 `W`（即生成权重）。因为 `x = W z`，根据公式 2.46，我们有

```
px(W zt) = pz(zt)|det(W−1)| = pz(V xt)|det(V)| (12.53)
```

因此，假设有 `T` 个独立同分布样本，我们可以写出对数似然如下：

```
log p(D|V) = log |det(V)| + 1/T ∑∑ log pj(vjTxt) (12.54)
```

其中 `vj` 是 `V` 的第 `j` 列。因为我们强制 `V` 为正交，第一项是常数，所以可以省略。我们也可以用期望算子替换对数据的平均，得到以下目标：

```
NLL(V) = ∑ E[Gj(zj)]
```

其中 `zj = vjTx` 且 `Gj(z) ≜ −log pj(z)`。我们需要在 `V` 的列正交的约束下最小化该目标。我们还需要它们具有单位范数，因为这保证了因子的方差为单位（因为对于白化数据，`E[vjTx] = ||vj||2`，这是固定权重尺度所必需的）。换句话说，`V` 应该是一个正交矩阵。推导梯度下降算法来拟合此模型是直接的；然而，它相当缓慢。也可以推导出遵循自然梯度的更快算法；详见例如 (MacKay 2003, ch 34)。一种流行的替代方法是使用近似牛顿法，我们将在第 12.6.2 节中讨论。另一种方法是使用 EM，我们将在第 12.6.3 节中讨论。

# 14.1 简介

我们在下面给出几个例子。到目前为止，在本书中，我们一直假设我们希望分类、聚类或以其他方式处理的每个对象都可以表示为固定大小的特征向量，通常形式为 `xi ∈ RD`。然而，对于某些类型的对象，如何最好地将它们表示为固定大小的特征向量并不清楚。例如，我们如何表示一个文本文档或蛋白质序列，它们可以是可变长度的？或者一个分子结构，它具有复杂的 3D 几何形状？又或者一个系统发育树，它具有可变的大小和形状？解决此类问题的一种方法是为数据定义一个生成模型，并使用推断出的潜在表示和/或模型的参数作为特征，然后将这些特征输入标准方法。例如，在第 28 章 TODO 中，我们讨论深度学习，它本质上是一种学习良好特征表示的无监督方法。另一种方法是假设我们有某种衡量对象间相似性的方法，而不需要将它们预处理为特征向量形式。例如，在比较字符串时，我们可以计算它们之间的编辑距离。令 `κ(x,x′) ≥ 0` 为对象 `x, x′ ∈ X` 之间的某种相似性度量，我们将称 `κ` 为核函数。注意，“核”一词有多种含义；我们将在第 14.7.1 节 TODO 中讨论另一种解释。在本章中，我们将研究几种核函数。然后我们描述一些可以纯粹用核函数计算来编写的算法。当我们无法访问（或选择不查看）正在处理的对象 `x` 的内部结构时，可以使用此类策略。

# 14.2 核函数

**定义 14.1。** 核函数是一个两个参数的实值函数，`κ(x,x′) ∈ R`。通常该函数是对称的（即 `κ(x,x′) = κ(x′,x)`）且非负的（即 `κ(x,x′) ≥ 0`）。

## 14.2.1 RBF 核

高斯核或平方指数核 (SE 核) 定义为

```
κ(x,x′) = exp(−1/2 (x−x′)T Σ−1 (x−x′)) (14.1)
```

如果 `Σ` 是对角的，这可以写为

```
κ(x,x′) = exp(−1/2 ∑ (xj−x′j)2 / σj2) (14.2)
```

我们可以将 `σ` 解释为定义维度 `j` 的特征长度尺度。如果 `σ = ∞`，则忽略相应的维度；因此这被称为 ARD 核。如果 `Σ` 是球形的，我们得到各向同性核

```
κ(x,x′) = exp(− ||x−x′||2 / 2σ2) (14.3)
```

这里 `σ2` 称为带宽。公式 14.4 是径向基函数或 RBF 核的一个例子，因为它只是 `||x−x′||2` 的函数。

## 14.2.2 TF-IDF 核

```
κ(x,x′) = ϕ(x)T ϕ(x′) / (||ϕ(vecx)||2 ||ϕ(x′)||2) (14.4)
```

其中 `ϕ(x) = tf-idf(x)`。

## 14.2.3 Mercer（正定）核

如果核函数满足要求，即对于任意输入集合 `{xi}i=1N`，由下式定义的 Gram 矩阵

```
K = [κ(x1,x1) ... κ(x1,xN); ... ; κ(xN,x1) ... κ(xN,xN)] (14.5)
```

为正定。我们称这样的核为 Mercer 核，或正定核。如果 Gram 矩阵是正定的，我们可以按如下方式计算其特征向量分解：

```
K = UT Λ U (14.6)
```

其中 `Λ` 是特征值 `λi > 0` 的对角矩阵。现在考虑 `K` 的一个元素：

```
Kij = (Λ1/2 U:,i)T (Λ1/2 U:,j) (14.7)
```

令我们定义 `ϕ(xi) = Λ1/2 U:,i`，那么我们可以写成 `Kij = ϕ(xi)T ϕ(xj)` (14.8)。

## 14.2.4 线性核

```
κ(x,x′) = xT x′ (14.10)
```

## 14.2.5 Matern 核

Matern 核常用于高斯过程回归（见第 15.2 节），具有以下形式：

```
κ(r) = 21−ν / Γ(ν) (√2ν r / ℓ)ν Kν(√2ν r / ℓ) (14.11)
```

其中 `r = ||x−x′||`，`ν > 0`，`ℓ > 0`，且 `Kν` 是修正贝塞尔函数。当 `ν → ∞` 时，这趋近于 SE 核。如果 `ν = 1`，核简化为

```
κ(r) = exp(−r/ℓ) (14.12)
```
