

# 使用不确定预测对问题进行分组

在 `p(y|x)` 极不确定的分组问题中，我们可能倾向于选择一项“异常”活动，即我们不将模型归类为任何预定类别，而是输出“不知道”。此类模糊情况可由人类专家等处理。这在医疗和金融等规避风险的领域非常有价值。

我们可以按如下方式形式化“异常”选择。令选择 `f(x) = cK+1` 对应选择“异常”活动，选择 `f(x) ∈ {C1, ..., Ck}` 对应选择其中一个类别。假设我们将损失函数定义为：

```
L(f(x), y) =
  0          if f(x) = y and f(x), y ∈ {C1, ..., Ck}
  λ_r        if f(x) ≠ y and f(x), y ∈ {C1, ..., Ck}
  λ_r        if f(x) = cK+1
```

(5.32)

其中 `λ_r` 是替换错误的代价，`λ_r` 是“异常”动作的代价。

## 5.7.1.5 监督学习

当自然的未知状态为 `θ`（数据生成过程的参数）时，我们可以将 `f(x)` 造成的损失（即使用该预测器）描述如下：

```
L(θ, f) = E_{p(x,y|θ)}[ℓ(y − f(x))]
```

(5.33)

## 频率学派统计

人们曾尝试设计统计推断方法，避免将参数视为随机变量，从而避免使用先验和贝叶斯规则。此类方法被称为频率学派统计、传统统计或标准统计。它们不基于后验分布，而是依赖于抽样分布的概念。

```
R_exp(θ, f) = E_{p(D̃|θ)}[L(θ, f(D̃))]
           = ∫ L(θ, f(D̃)) p(D̃|θ) dD̃
```

(6.1)

其中 `D̃` 是从由参数 `θ` 表示的分布中抽取的数据。换句话说，期望是针对估计量的抽样分布而言的。将其与贝叶斯后验期望损失进行对比：

```
ρ(f|D)  (6.2)
```

# 线性回归

## 7.1 简介

线性回归是统计学和（监督）机器学习的主力模型。当结合基函数或其他形式的基函数扩展时，它还可以建模非线性关系。此外，当高斯输出被伯努利或多努利分布替代时，它可用于分类，正如我们将在下文看到的。因此，详细研究这一模型大有裨益。

## 7.2 表示

```
p(y|x, θ) = N(y | w^T x, σ^2)
```

(7.1)

其中 `w` 和 `x` 是增广向量，`x = (1, x)`，`w = (b, w)`。通过用输入的某个非线性函数 `ϕ(x)` 替换 `x`，线性回归可以用于建模非线性关系：

```
p(y|x, θ) = N(y | w^T ϕ(x), σ^2)
```

(7.2)

这被称为基函数扩展。（注意模型在参数 `w` 上仍然是线性的，因此仍称为线性回归；其意义将在下文变得清晰。）一个简单的例子是多项式基函数，此时模型形式为：

```
ϕ(x) = (1, x, ···, x^d)
```

(7.3)

我们不最大化对数似然，而是等价地最小化负对数似然或 NLL：

```
NLL(θ) = −ℓ(θ) = −log p(D|θ)
```

(7.4)

NLL 形式有时更方便，因为许多优化软件包旨在寻找函数的最小值而非最大值。现在让我们将 MLE 方法应用于线性回归设定。将高斯定义代入上式，可得对数似然为：

```
ℓ(θ) = ∑_{i=1}^N log (1/√(2πσ^2)) exp(−(y_i − w^T x_i)^2 / 2σ^2)
```

(7.5)

```
= −N/2 log(2πσ^2) − 1/(2σ^2) RSS(w)
```

(7.6)

`RSS` 代表残差平方和，定义为：

```
RSS(w) = ∑_{i=1}^N (y_i − w^T x_i)^2
```

(7.7)

我们看到 `w` 的 MLE 是使 RSS 最小化的那个，因此该方法称为最小二乘法。

去除关于 `w` 的常数项，NLL 可写为：

```
NLL(w) = 1/N ∑_{i=1}^N (y_i − w^T x_i)^2
```

(7.8)

最小化 `NLL(w)` 有两种方法。

## 7.3 MLE

定义：

```
y = (y_1, y_2, ···, y_N)^T
X = (x_1^T, x_2^T, ···, x_N^T)^T
```

则 `NLL(w)` 可写为：

```
NLL(w) = 1/2 (y − Xw)^T (y − Xw)
```

(7.9)

当 `D` 较小（例如 `N < 1000`）时，我们可以使用以下公式直接计算 `w`：

```
w_OLS = (X^T X)^{−1} X^T y
```

(7.10)

该线性方程组对应的解 `ŵ_OLS` 称为普通最小二乘解或 OLS 解。

**证明。** 我们现在不加证明地陈述几个矩阵求导事实（本节不需要用到这些）。

```
∂/∂w NLL(w) = 1/2 (Xw − y)^T (Xw − y)
```

```
∂/∂w NLL = 1/2 ∂/∂w (w^T X^T X w − w^T X^T y − y^T X w + y^T y)
         = 1/2 ∂/∂w (w^T X^T X w − w^T X^T y − y^T X w)
         = 1/2 ∂/∂w tr(w^T X^T X w − w^T X^T y − y^T X w)
         = 1/2 ∂/∂w (tr w^T X^T X w − 2 tr y^T X w)
```

结合公式 7.12 和 7.13，我们发现：

```
tr A = ∑_{i=1}^n A_ii
```

```
∂/∂A tr(AB) = B^T
```

(7.11)

```
∂/∂A^T f(A) = ∂/∂A f(A)
```

(7.12)

```
∂/∂A tr(ABA^T C) = CAB + C^T A B^T
```

(7.13)

```
∂/∂A |A| = |A| (A^{−1})^T
```

(7.14)

则：

```
∂/∂w NLL = 1/2 (X^T X w + X^T X w − 2 X^T y)
         = X^T X w − X^T y
```

```
∂/∂w NLL = 0  ⇒  X^T X w − X^T y = 0
```

```
X^T X w = X^T y
```

(7.15)

```
w_OLS = (X^T X)^{−1} X^T y
```

公式 7.15 称为正规方程。
