

## 5.2.1 MAP 估计

### 5.2.1.2 代入 MAP 估计可能导致过拟合

如果我们不建模边界中的脆弱性，那么此时我们的预测分布将会是傲慢的。预测中的傲慢在我们可能厌恶风险的情况下尤为危险；详见第 5.7 节。

### 5.2.1.3 众数是一个非典型点

我们可以通过计算后验均值、中位数或众数，无疑地得出一个未知量的点估计。在第 5.7 节中，我们将探讨如何利用决策理论在这些方法之间进行选择。通常，后验均值或中位数是实值量最合适的选择，而后验边缘向量是离散量的最佳选择。然而，后验众数，即 MAP 估计，是最流行的选择，因为它归结为一个优化问题，对于此类问题通常存在高效的算法。此外，MAP 估计可以用非贝叶斯术语来解释，即通过使用决策理论，我们将在第 5.7 节中讨论。基本思想是指定一个损失函数，其中 `L(θ, ˆθ)` 是假设真值为 `θ` 而你的估计为 `ˆθ` 时所造成的损失。如果我们使用 0-1 损失 `L(θ, ˆθ) = I(θ ≠ ˆθ)`（见 1.2.2.1 节），那么最优估计就是后验众数。0-1 损失意味着只有在你不犯任何错误时才能得分，否则一分不得：在这种损失函数下没有部分得分！对于连续值量，我们通常更倾向于使用平方误差损失，`L(θ, ˆθ) = (θ − ˆθ)²`；正如我们在第 5.7 节所示，相应的最优估计量是后验均值。或者我们可以使用更稳健的损失函数，`L(θ, ˆθ) = |θ − ˆθ|`，这将得到后验中位数。

### 5.2.1.4 MAP 估计对重参数化不具有不变性

MAP 估计一个更微妙的问题是，我们得到的结果取决于我们如何定义概率分布。从一种表示变换到另一种等价表示会改变结果，这并不理想，因为度量单位是任意的（例如，测量距离时，我们可以使用厘米或英寸）。为了理解这个问题，假设我们计算 `x` 的后验。如果我们定义 `y = f(x)`，则 `y` 的分布由公式 2.44 给出。`dx/dy` 项称为雅可比矩阵，它衡量单位体积通过 `f` 后大小的变化。令 `ˆx = arg max_x p_x(x)` 为 `x` 的 MAP 估计。通常 `x = arg max_x p_x(x)` 并不由 `f(x)` 给出。例如，设 `X ~ N(6,1)` 且 `y = f(x)`，其中 `f(x) = 1/(1+exp(−x+5))`。

## 5.2.2 可信区间

除了点估计，我们通常还需要一个确定性的度量。对某个（标量）量 `θ` 的确信程度的一个标准度量是其后验分布的宽度。这可以使用 `100(1−α)%` 可信区间来估计，它是一个（连续的）区域 `C = (ℓ, u)`（代表下限和上限），包含 `1−α` 的后验概率质量，即 `C_α(D)` 其中 `P(ℓ ≤ θ ≤ u) = 1 − α` (5.1)。

可能存在许多这样的区间，所以我们选择一个使得每个尾部有 `(1−α)/2` 的质量；这称为中心区间。如果后验具有已知的函数形式，我们可以使用 `ℓ = F⁻¹(α/2)` 和 `u = F⁻¹(1−α/2)` 计算后验中心区间，其中 `F` 是后验的累积分布函数 (cdf)。如果我们不知道函数形式，但可以从后验中抽取样本，则可以使用后验分位数的蒙特卡洛近似：我们只需对 `S` 个样本进行排序，并找到位于排序列表 `α/S` 位置处的那个样本。当 `S → ∞` 时，这收敛到真实分位数。人们经常混淆贝叶斯可信区间与频率学派置信区间。然而，它们并不相同，正如我们在 TODO 节中讨论的那样。通常，可信区间通常是人们想要计算的，但置信区间通常是他们实际计算的，因为大多数人学的是频率学派统计而不是贝叶斯统计。幸运的是，计算可信区间的机制与计算置信区间几乎一样简单。

## 5.3 贝叶斯模型选择

通常，当面对一组不同复杂度的模型（即参数分布族）时，我们该如何选择最好的一个？这被称为模型选择问题。一种方法是使用交叉验证来估计所有候选模型的泛化误差，然后选择看起来最好的模型。
