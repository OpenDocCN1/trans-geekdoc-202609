### 10.1.2 条件独立性

给定 `Z` 时，`X` 和 `Y` 条件独立，记作 `X ⊥ Y|Z`，当且仅当条件联合分布可以写成条件边缘分布的乘积，即：

```
X ⊥ Y|Z ⇐⇒ p(X,Y|Z) = p(X|Z)p(Y|Z) (10.2)
```

有向图模型（DGM）是其图为有向无环图（DAG）的图模型。这些更常被称为贝叶斯网络。然而，贝叶斯网络并没有什么内在的“贝叶斯”属性：它们只是定义概率分布的一种方式。这些模型也被称为信念网络。此处“信念”指的是主观概率。再次强调，DGMs 所表示的概率分布类型并没有什么内在的主观性。

### 10.1.3 图模型

图模型（GM）是一种通过做条件独立性假设来表示联合分布的方式。特别地，图中的节点代表随机变量，边的（不）存在代表条件独立性假设。根据图是有向、无向，还是有向和无向的组合，有几种图模型。在本章中，我们只研究有向图。我们将在第 19 章讨论无向图。

### 10.4.1 从完整数据中学习

如果在每种情况下所有变量都被完全观测，因此没有缺失数据且没有隐变量，我们称数据是完整的。对于具有完整数据的 DGM，似然由下式给出：

```

V
= ∏ p(Dt|θt) (10.11)

```

其中 `Dt` 是与节点 `t` 及其父节点相关的数据，即第 `t` 个家族。现在假设先验也分解：

```
V

```

那么显然后验也分解：


## 11.2 混合模型

在第 10 章中，我们展示了如何使用图模型来定义高维联合概率分布。基本思想是通过在图中它们之间添加一条边来建模两个变量之间的依赖关系。（严格来说，图代表条件独立性，但你明白意思。）另一种方法是假设观测变量之所以相关，是因为它们源于一个隐藏的共同原因。带有隐变量的模型也被称为潜变量模型（LVMs）。正如我们将在本章看到的，这类模型比没有潜变量的模型更难拟合。然而，它们可能具有显著优势，主要有两个原因。

* 首先，LVMs 通常比直接在可见空间表示相关性的模型拥有更少的参数。
* 其次，LVM 中的隐变量可以作为一个瓶颈，计算数据的压缩表示。这构成了无监督学习的基础，正如我们将看到的那样。
