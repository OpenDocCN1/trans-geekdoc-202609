

# 4.1.2 高斯分布的最大熵推导

在本节中，我们将展示多元高斯分布是在预定义均值和协方差的约束下，具有**最大熵**的分布（另见第 TODO 节）。这是高斯分布被**广泛使用**的原因之一：前两个矩通常是我们能从数据中可靠估计的全部，因此我们需要一种能捕捉这些性质，但除此之外做尽可能**少的额外假设**的分布。为简化符号，我们将假设均值为零。概率密度函数（pdf）具有以下结构：

```
f(x) = 1/Z exp(-1/2 x^T Σ^{-1} x)  (4.10)
```

# 4.2 高斯判别分析

多元正态分布（MVN）的一个重要用途是为生成式分类器中的类条件密度建模，即：

```
p(x|y = c, θ) = N(x|μ_c, Σ_c)  (4.11)
```

由此产生的方法称为（高斯）判别分析或 GDA（尽管它是生成式而非判别式分类器，有关此区别的更多信息请参见第 TODO 节）。如果 `Σ_c` 是对角的，这等同于朴素贝叶斯。我们可以使用以下决策规则对特征向量进行分类，该规则源自公式 3.1：

```
y = argmax_c [log p(y = c|π) + log p(x|θ)]  (4.12)
```

当我们计算 x 在每个类条件密度下的似然时，我们实际上是在使用马氏距离测量 x 到每个类中心 `μ_c` 的距离。这可以被视为最近质心分类器。例如，图 4.2 展示了二维空间中两个高斯类条件密度，分别代表人类的身高和体重。我们可以看到特征之间存在相关性，这符合预期（个子高的人通常体重也更重）。每个类别的椭圆包含 95% 的概率质量。假设我们对类别有均匀先验，我们可以按如下方式对新的测试向量进行分类：

```
y = arg max_c (x - μ_c)^T Σ^{-1} (x - μ_c)  (4.13)
```

## 4.2.1 二次判别分析 (QDA)

通过将高斯密度的定义代入公式 3.1，我们可以得到：

```
p(y|x, θ) = π_c |2π Σ_c|^{-1/2} exp[-1/2 (x - μ)^T Σ^{-1} (x - μ)]
            -------------------------------------------------------------  (4.14)
            ∑_c' π_c' |2π Σ_c'|^{-1/2} exp[-1/2 (x - μ)^T Σ^{-1} (x - μ)]
```

对该结果进行阈值处理会得到 x 的二次函数。该结果称为**二次判别分析 (QDA)**。图 4.3 给出了一些二维空间中决策边界外观的示例。

## 4.2.2 线性判别分析 (LDA)

我们现在考虑一种特殊情况，即协方差矩阵在各类别间被绑定或共享，`Σ_c = Σ`。在这种情况下，我们可以将公式 4.14 简化如下：

```
p(y|x, θ) ∝ exp(μ_c^T Σ^{-1} x - 1/2 μ_c^T Σ^{-1} μ_c + log π_c)  (4.15)
```

由于二次项 `x^T Σ^{-1} x` 与 c 无关，它将在分子和分母中抵消。假设我们定义：

```
γ_c ≜ -1/2 μ_c^T Σ^{-1} μ_c + log π_c  (4.16)
β_c ≜ Σ^{-1} μ_c  (4.17)
```

我们可以写成：

```
p(y|x, θ) = e^{β_c^T x + γ_c} / ∑_c' e^{β_c'^T x + γ_c'} = σ(η)_c  (4.18)
```

其中 `η ≜ (e^{β_1^T x + γ_1}, ..., e^{β_C^T x + γ_C})`，`σ()` 是 softmax 激活函数，定义如下：

```
exp(q_i)
σ(q, i) = ------------  (4.19)
∑_j exp(q_j)
```

当由某个常数 `α > 0` 定义时，以下公式成为最大值函数的一个平滑、可微近似：

```
∑_D x_j e^{α x_j}
S_α(x) = ---------------  (4.20)
∑_D e^{α x_j}
```

`S_α` 具有以下性质：
1. `S_α → max` 当 `α → ∞` 时
2. `S_0` 是其输入的平均值
3. `S_α → min` 当 `α → -∞` 时

请注意，softmax 激活函数源自统计物理学领域，在那里通常使用玻尔兹曼分布，其形式与 softmax 激活函数相同。公式 4.18 的一个有趣性质是，如果我们取对数，最终会得到 x 的**线性函数**。（之所以是线性的，是因为 `x^T Σ^{-1} x` 从分子和分母中抵消了。）因此，任意两个类别（设为 c 和 c′）之间的决策边界将是一条直线。因此该方法称为**线性判别分析 (LDA)**。

> 16 http://en.wikipedia.org/wiki/Softmax_activation_function

另一种方法是不先拟合 LDA 模型再推导类后验，而是直接拟合 `p(y|x, W) = Cat(y|W x)`，其中 W 为某个 `C × D` 权重矩阵。这称为多类逻辑回归，或多项逻辑回归。我们将在第 TODO 节详细讨论该模型。这两种方法的区别在第 TODO 节中解释。

## 4.2.3 二分类 LDA

为了更深入地了解这些方程的含义，让我们考虑二分类情况。在这种情况下，后验概率由下式给出：

```
p(y = 1|x, θ) = e^{β_0^T x + γ_0} / (e^{β_0^T x + γ_0} + e^{β_1^T x + γ_1})  (4.21)
              = 1 / (1 + e^{(β_0 - β_1)^T x + (γ_0 - γ_1)})  (4.22)
              = sigm((β_1 - β_0)^T x + (γ_0 - γ_1))  (4.23)
```

其中 `sigm(x)` 指代 sigmoid 函数。

现在：

```
γ_1 - γ_0 = -1/2 μ_1^T Σ^{-1} μ_1 + 1/2 μ_0^T Σ^{-1} μ_0 + log(π_1/π_0)  (4.24)
          = 1/2 (μ_1 - μ_0)^T Σ^{-1} (μ_1 + μ_0) + log(π_1/π_0)  (4.25)
```

因此如果我们定义：

```
w = β_1 - β_0 = Σ^{-1} (μ_1 - μ_0)  (4.26)
x_0 = log(π_1/π_0) - 1/2 (μ_1 + μ_0)^T Σ^{-1} (μ_1 - μ_0)  (4.27)
```

图 4.4：`Σ_1 = Σ_2 = I` 时二分类 LDA 的几何解释。更靠近 `μ_0`，因此更多的线段属于类别 1 推断。另一方面，如果 `π_1 < π_0`，边界向右移动。因此我们看到类先验 c 仅改变决策阈值，而不改变整体几何结构，正如我们之前所承诺的。（类似的论证适用于多分类情况。）
