
• 如果这两种怀疑都不成立，我们就说信息不是无差别缺失的，即 NMAR（非随机缺失）。对于这种情况，我们需要对缺失信息机制建模，因为缺失模式对于缺失信息的值及相应参数具有信息量。例如，这在大多数协作过滤问题中就是这种情况。更多讨论请参见 (Marlin 2008)。我们在此之后将假设数据为 MAR（随机缺失）。

在处理缺失信息时，区分仅在测试时存在缺失的情况（此时训练数据是完整数据），以及更难处理的在训练时也存在缺失的情况，是很有帮助的。我们将在下文讨论这两种情况。注意，根据定义，类别标签在测试时始终是缺失的；如果类别标签在训练时有时也缺失，该问题称为半监督学习。

# 第 9 章 广义线性模型与指数族

## 9.1 指数族

公式 9.2 可以通过以下写法推广：

在定义指数族之前，我们先注意到它重要的几个原因：
• 可以证明，在特定正则性条件下，指数族是具有有限充分统计量的唯一分布族，这意味着我们可以将数据压缩成固定大小的摘要而不丢失信息。这对在线学习特别有用，稍后我们将看到。
• 指数族是存在共轭先验的唯一分布族，这简化了后验的计算（见第 9.1.5 节）。
• 可以证明指数族是在用户选定约束下使先验假设最少的分布族（见第 9.1.6 节）。
• 指数族是广义线性模型的核心，如第 9.2 节所述。
• 指数族是变分推断的核心，如第 TODO 节所述。

```
p(x|θ) = h(x)exp[η(θ)T ϕ(x)−A(η(θ))] (9.5)
```

其中 `η` 是一个将参数 `θ` 映射到标准参数 `η = η(θ)` 的函数。如果 `dim(θ) < dim(η(θ))`，则称为弯曲指数族，这意味着我们拥有的充分统计量比参数多。如果 `η(θ) = θ`，则称模型为标准形式。除非另有说明，我们将假设模型为标准形式。

### 9.1.1 定义

对于 `x ∈ Rm` 和 `θ ∈ RD`，如果 pdf 或 pmf `p(x|θ)` 具有以下形式，则称其属于指数族：

```
p(x|θ) = h(x)exp[θT ϕ(x)] (9.1)
Z(θ)
```

```
= h(x)exp[θT ϕ(x)−A(θ)] (9.2)
```

其中

```
∫
Z(θ) = h(x)exp[θT ϕ(x)]dx (9.3)
```

```
A(θ) = log Z(θ) (9.4)
```

这里 `θ` 称为自然参数或标准参数，`ϕ(x) ∈ RD` 称为充分统计量向量，`Z(θ)` 称为配分函数，`A(θ)` 称为对数配分函数或累积生成函数，`h(x)` 是一个缩放常数，通常为 1。如果 `ϕ(x) = x`，我们称其为自然指数族。

### 9.1.2 示例

#### 9.1.2.1 伯努利分布

`x ∈ {0,1}` 的伯努利分布可以写成指数族形式如下：

```
Ber(x|µ) = µx(1−µ)1−x = exp[x log µ + (1−x) log(1−µ)] (9.6)
```

其中 `ϕ(x) = (I(x = 0), I(x = 1))` 且 `θ = (log µ, log(1−µ))`。然而，这种表示是过完备的，因为 `1T ϕ(x) = I(x = 0) + I(x = 1) = 1`。因此 `θ` 不具有唯一可识别性。通常要求表示是极小的，这意味着存在与该分布相关联的唯一 `θ`。在这种情况下，我们可以简单地定义

```
Ber(x|µ) = (1−µ) exp[x log µ/(1−µ)] (9.7)
```

其中 `ϕ(x) = x`，`θ = log µ/(1−µ)`，`Z = 1−µ`。

我们可以使用以下公式从标准参数恢复均值参数 `µ`：

```
µ = sigm(θ) = 1/(1+e−θ) (9.8)
```

#### 9.1.2.2 多努利分布

我们可以将多努利分布表示为极小指数族，如下所示：

```
Cat(x|µ) = ∏(K) k=1 exp[∑(K) k=1 xk log µk] (9.9)
```

```
= exp[∑(K−1) k=1 xk log µk + (1−∑(K−1) k=1 xk) log(1−∑(K−1) k=1 µk)]
```

```
= exp[∑(K−1) k=1 xk log µk/(1−∑(K−1) k=1 µk) + log(1−∑(K−1) k=1 µk)]
```

```
= exp[θT ϕ(x)−A(θ)] (9.9)
```

其中

```
θ = (log µ1/µK, ..., log µK−1/µK) (9.10)
```

```
ϕ(x) = (x1, ..., xK−1) (9.11)
```

我们可以使用以下公式从标准参数恢复均值参数：

```
µk = eθk / (1+∑(K−1) j=1 eθj) (9.12)
```

```
µK = 1 / (1+∑(K−1) j=1 eθj) (9.13)
```

因此

```
A(θ) = −log µK = log(1+∑(K−1) j=1 eθj) (9.14)
```

一元高斯分布可以写成指数族形式如下：

```
N(x|µ,σ2) = 1/√(2πσ) exp[−1/(2σ2)(x−µ)2]
```

其中

```

```


#### 9.1.2.4 非示例

并非所有感兴趣的分布都属于指数族。例如，均匀分布 `X ∼ U(a,b)` 不属于，因为分布的支撑集取决于参数。此外，Student T 分布（见第 TODO 节）也不属于，因为它不具备所需的形式。

### 9.1.3 对数配分函数

指数族的一个重要性质是，对数配分函数的导数可用于生成充分统计量的累积量。因此，`A(θ)` 有时被称为累积生成函数。我们将针对单参数分布证明这一点；这可以直接推广到 K 参数分布。

对于一阶导数，我们有

```
dA/dθ = d/dθ {log ∫ exp[θϕ(x)]h(x)dx}
= (d/dθ ∫ exp[θϕ(x)]h(x)dx) / ∫ exp[θϕ(x)]h(x)dx
= ∫ ϕ(x)exp[θϕ(x)]h(x)dx / exp(A(θ))
= ∫ ϕ(x)exp[θϕ(x)−A(θ)]h(x)dx
= ∫ ϕ(x)p(x)dx = E[ϕ(x)] (9.19)
```

对于二阶导数，我们有

```
d2A/dθ2 = ∫ [ϕ(x)−A′(θ)] ϕ(x)exp[θϕ(x)−A(θ)]h(x)dx
= ∫ ϕ2(x)p(x)dx − A′(θ) ∫ ϕ(x)p(x)dx
= E[ϕ2(x)] − E[ϕ(x)]2 = var[ϕ(x)] (9.20)
```

在多元情况下，我们有

```
∂2A/∂θi∂θj = E[ϕ(x)ϕ(x)T] − E[ϕ(x)]E[ϕ(x)]T (9.21)
```

因此

```
∇2A(θ) = cov[ϕ(x)] (9.22)
```

由于协方差矩阵是正定的，我们可以看出 `A(θ)` 是一个凸函数（见第 A.1 节）。
