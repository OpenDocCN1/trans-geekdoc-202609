
# 2.8 信息论

## 2.8.1 熵

具有分布 `p` 的任意变量 `X` 的熵，记作 `H(X)` 或有时记作 `H(p)`，是其**不确定性**的度量。具体而言，对于具有 `K` 个状态的离散变量，其定义为

```
H(X) = −∑_{k=1}^K p(X = k) log2 p(X = k)  (2.50)
```

通常我们使用以 2 为底的对数，此时单位称为 **比特**（bit，binary digit 的缩写）。假设我们使用以 `e` 为底的对数，单位称为 **奈特**（nat）。具有最大熵的离散分布是均匀分布（证明见第 XXX 节）。因此，对于一个 `K` 元离散变量，当 `p(x = k) = 1/K` 时熵最大；在这种情况下，`H(X) = log2 K`。相反，熵最小（为零）的分布是将所有质量集中在一个状态上的任意 Delta 函数。这种分布没有不确定性。

可以证明（Cover and Thomas 2006），交叉熵是指当我们使用模型 `q` 来构建码本时，对来自分布 `p` 的源进行编码所需的平均比特数。因此，普通熵 `H(p) = H(p,p)`（定义见 §2.8.1 节）是在我们使用真实模型时的平均比特数，所以 KL 散度就是这两者之间的差异。换句话说，KL 散度是由于我们使用分布 `q` 而非真实分布 `p` 来编码数据而导致的额外平均比特数。额外比特数这一理解应能说明 `KL(p||q) ≥ 0`，且仅当 `q = p` 时 KL 散度等于零。

我们现在给出这一重要结果的证明。

**定理 2.1.（数据差异/不等式）** `KL(p||q) ≥ 0`，当且仅当 `p = q` 时取等号。

这一结果的一个重要推论是，具有最大熵的离散分布是均匀分布。

## 2.8.2 KL 散度

衡量两个概率分布 `p` 和 `q` 差异的一种方法称为 **Kullback-Leibler 散度**（KL 散度）或相对熵。其定义如下：

```
KL(P||Q) = ∑_x p(x) log2 q(x)  (2.51)
```

仅当 `P` 和 `Q` 均归一化为 1 且 `q(x) = 0` 蕴含 `p(x) = 0` 对所有 `x` 成立（绝对连续）时，KL 散度才有定义。如果公式中出现 `0 ln 0`，它被解释为零，因为 `lim_{x→0} x ln x = 0`。

我们可以将其重写为

```
KL(p||q) = ∑_{k=1}^K p(x) log2 p(x) − ∑ p(x) log2 q(x)
         = H(p,q) − H(p)  (2.52)
```

其中 `H(p,q)` 称为**交叉熵**。

## 2.8.3 互信息

**定义 2.9.** **互信息**（MI）定义如下：

```
I(X;Y) = KL(P(X,Y) || P(X)P(Y))
       = ∑_x ∑_y p(x,y) log (p(x,y) / (p(x)p(y)))  (2.54)
```

对于概率密度函数（pdf），求和号替换为积分。我们有 `I(X;Y) ≥ 0`，当且仅当 `P(X,Y) = P(X)P(Y)` 时取等号。即，若变量相互独立，则 MI 为零。

为了深入理解 MI 的含义，将其用联合熵和条件熵重新表达会有所帮助。可以证明上述表达式等价于以下形式：

```
I(X;Y) = H(X) − H(X|Y)  (2.55)
       = H(Y) − H(Y|X)  (2.56)
       = H(X) + H(Y) − H(X,Y)  (2.57)
       = H(X,Y) − H(X|Y) − H(Y|X)  (2.58)
```

其中 `H(X)` 和 `H(Y)` 是边缘熵，`H(X|Y)` 和 `H(Y|X)` 是条件熵，`H(X,Y)` 是 `X` 和 `Y` 的联合熵，见图 2.10。

![图 2.10：一对具有互信息 I(X;Y) 的相关子系统 X,Y 的边缘熵 H(X)、H(Y)、联合熵 H(X,Y) 和条件熵。](image_rsrc1R4.jpg)

直观上，我们可以将 `X` 和 `Y` 之间的 MI 解释为观察 `Y` 后关于 `X` 的不确定性的减少，或者对称地，观察 `X` 后关于 `Y` 的不确定性的减少。

一个与 MI 密切相关的量是**点互信息**（PMI）。对于两个事件（而非随机变量）`x` 和 `y`，其定义为

```
PMI(x,y) = log (p(x,y) / (p(x)p(y))) = log (p(x|y) / p(x)) = log (p(y|x) / p(y))  (2.59)
```

这衡量了这些事件共同发生与偶然预期之间的差异。显然，`X` 和 `Y` 的 MI 仅仅是 PMI 的期望值。

有趣的是，我们可以将 PMI 重写如下：

```
PMI(x,y) = log (p(x|y) / p(x)) = log (p(y|x) / p(y))  (2.60)
```

这是将先验 `p(x)` 更新为后验 `p(x|y)` 所获得的信息量，或者等价地，将先验 `p(y)` 更新为后验 `p(y|x)` 所获得的信息量。

# 第 3 章 离散数据的生成模型

## 3.1 生成式分类器

```
p(y = c|θ) p(x|y = c, θ)
p(y = c|x, θ) = ------------------------------------  (3.1)
     ∑_{c'} p(y = c'|θ) p(x|y = c', θ)
```

这被称为**生成式分类器**，因为它利用类条件密度 `p(x|y=c)` 和类先验 `p(y=c)` 指定了如何生成数据。另一种方法是直接拟合类后验 `p(y = c|x)`；这被称为**判别式分类器**。

## 3.2 贝叶斯概念学习

心理学研究表明，人类可以仅从正例中学习概念（Xu and Tenenbaum 2007）。我们可以将学习单词含义视为概念学习，而概念学习又等同于二元分类。为了说明这一点，定义 `f(x) = 1` 如果 `x` 是概念 `C` 的一个例子，否则 `f(x) = 0`。那么目标就是学习指示函数 `f`，它仅定义了哪些元素在集合 `C` 中。

### 3.2.1 似然

```
p(D|h) = (1 / |h|)^N  (3.2)
```

这个关键公式体现了 Tenenbaum 所谓的**大小原则**，即模型倾向于与数据一致的最简单（最小）假设。这更常被称为**奥卡姆剃刀**。

### 3.2.3 后验

后验仅仅是似然乘以先验，再归一化。

```
p(D|h) p(h)
p(h|D) = ----------------------------  (3.3)
         ∑_{h' ∈ H} I(D ∈ h') p(h')
```

其中 `I(D ∈ h) p(h)` 当且仅当所有数据都在假设 `h` 的外延中时为 1。

通常情况下，当我们有足够的数据时，后验 `p(h|D)` 会集中在单一概念上，即 MAP 估计：

```
p(h|D) → ĥ_MAP  (3.4)
```

其中 `ĥ_MAP` 是后验众数，

```
ĥ_MAP = arg max_h p(h|D) = arg max_h p(D|h) p(h)
       = arg max_h [log p(D|h) + log p(h)]  (3.5)
```
