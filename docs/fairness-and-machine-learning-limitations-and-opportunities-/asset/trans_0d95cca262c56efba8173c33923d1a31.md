我们将刚才计算的结果视为在已选路线出现坏交通的情况下，选择另一条路线的 *反事实*（counterfactual）。

### 一般配方

我们可以将前面例子中的反事实计算推广到一般程序。之前有三个关键步骤。第一步，通过条件操作对已有观测证据进行偏向处理，使外生噪声变量与证据保持一致。第二步，在对外生噪声变量已偏向后，对结构因果模型执行 do-操作 `X := x`。第三步，计算目标变量的分布。这三个步骤通常被称为 *abduction*（抽象）、*action*（行动）和 *prediction*（预测），具体描述如下。

**定义 5** _Given a structural causal model M, an observed event E, an action X := x, and target variable Y, we define the counterfactual Y*[*X*:=*x*](*E*) by the following three-step procedure:_

*1.* **Abduction:** *Adjust noise variables to be consistent with the observed event. Formally, condition the joint distribution of U = (U[1], …, U[d]) on the event E. This results in a biased distribution U'***.

*2.* **Action:** *Perform do-intervention X := x in the structural causal model M resulting in the model M' = M[X := x].*

*3.* **Prediction:** *Compute target counterfactual Y*[*X*:=*x*](*E*) *by using U'* *as the random seed in M'.* 

重要的是认识到，这个程序 *定义* 了在结构因果模型中什么是反事实。符号 *Y*[*X*:=*x*](*E*) 表示该程序的结果，也是本定义的一部分。我们之前未曾使用过这个符号。用文字解释，形式反事实 *Y*[*X*:=*x*](*E*) 表示在事件 *E* 描述的情形下，如果将变量 *X* 设为 *x*，*Y* 会取何值。

在一般情况下，反事实 *Y*[*X*:=*x*](*E*) 是一个随机变量，随 `U'` 变化。但反事实也可以是确定的。当事件 *E* 将 `U` 的分布缩小到一个质量点（即 *unit*）时，`U'` 是常数，反事实 *Y*[*X*:=*x*](*E*) 就变为一个单一数值。此时，常用简写 *Y*[*x*](*u*) = *Y*[*X*:=*x*]({*U* = *u*})，其中 *X* 隐式，`u` 表示一个单一质量点。

“unit” 这个名称来源于结构因果模型通常描述的人口实体，这些实体是我们研究的原子单元。通常，一个 unit 可以是个体（或对个体的描述）。然而，根据应用场景，单元的选择可能会有所不同。在我们的交通例子中，噪声变量决定了我们选择的路线以及道路的状况。

反事实问题的答案高度依赖于结构因果模型的具体细节，包括外生噪声变量的精确建模方式。即使两个模型具有相同的图结构并行为相同于干预，也可能在反事实查询上给出不同的答案 \[[185](#references.xhtml#ref-185)\。
