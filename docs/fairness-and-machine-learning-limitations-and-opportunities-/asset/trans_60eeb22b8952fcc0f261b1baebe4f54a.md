
# 在许多专业领域，包括一些工程领域，伦理责任部分通过对从业人员的许可来强制执行。像医生和律师等专业人士必须掌握一套专业知识，包括伦理准则，并被法律要求在取得执业许可前通过标准化考试，若他们犯下伦理违规行为，许可证可能会被撤销。这并非软件工程的情况。无论如何，目前存在的软件工程认证标准 \[[437](#references.xhtml#ref-437)\] 与本书涉及的主题几乎没有重叠。

## 研究社区

机器学习研究社区是另一个重要的改革与转型场所。推动变革的最大力量是持续努力将公平、伦理和正义等研究主题视为合法且重要的议题。传统上，一些机器学习主题（如优化算法）被视为“核心”或“真正的”机器学习，而其他主题——甚至数据集构建——则被视为边缘且在智力上不那么严肃。Abeba Birhane、Pratyusha Kalluri、Dallas Card 等人对 ICML 和 NeurIPS 等顶级机器学习会议的论文进行文本分析，发现大多数论文通过强调性能和泛化来为自己辩护，仅有 1% 的论文提及潜在的负面影响 \[[438](#references.xhtml#ref-438)\]。

一些其他关键争论：所有机器学习研究者是否应被要求反思其研究的伦理？是否过于关注修正偏见，而忽视了更深层次的权力与正义问题 \[[440](#references.xhtml#ref-440)\]？如何才能将受机器学习系统影响的人和社区的视角置于中心？在存在利益冲突的情况下，工业界在公平机器学习方面的角色是什么？

## 组织干预以实现更公平的决策

我们上面讨论的结构性干预需要社会运动或其他集体行动，并且其演进时间跨度为数年甚至数十年。这并不意味着组织应当束手无策，等待结构性转变。大多数决策者都有大量可选的干预措施。本节概述了最重要的干预措施。

表 8.2A 概览主要类型的组织干预

| 类型 | 干预措施 | 示例 |
| --- | --- | --- |
| 修改输出 | 再分配 | 组别特定的决策阈值 |
| 修改决策过程 | 打击人际歧视 | 隐性偏见培训 |
|  | 正式化 | 采用统计决策制定 |
|  | 程序保护 | 解释与救济 |
| 决策前 | 外展 | 发送关于奖学金的邮件 |
|  | 干预因果因素 | 工作培训、预防性健康 |
| 决策后 | 修改环境 | 帮助被告出庭 |

随着阅读，你会发现大多数干预措施旨在改善所有决策主体的结果，而不是将公平视为不可回避的权衡。之所以可能，是因为许多干预措施并非在决策瞬间进行。此外，评估干预效果——无论是公平度还是其他指标——通常需要因果推断。最后，只有极小一部分潜在的公平干预措施可以在机器学习框架内实现；其余干预措施侧重于组织或人类实践，而非决策过程中的技术子系统。

### 重新分配或再分配

重新分配和再分配是指对决策过程进行干预，以显式偏好某一或多个群体（通常是被视为处于劣势的群体）。当我们谈论公平干预时，这通常是最直观的类型. 当应用于招聘或大学录取等拥有相对固定名额的选择问题时，算法公平性干预大多退化为不同形式的再分配。这包括在优化步骤中加入公平约束，或在后处理阶段对弱势群体的得分进行调整。无论目标是人口平等或其他统计指标，这种做法都适用。

再分配之所以吸引人，是因为它不需要先理解导致差异的根本因果关系。与此同时，再分配是一种粗糙的干预措施。它设计用来惠及某一群体，并且通过量化该群体的收益提供透明度的优势，但大多数再分配程序并未在群体内部考虑成员的“应得性”。再分配通常通过对弱势群体的uniform preference（均匀偏好）来实现，或者通过调整优化目标来纳入群体偏好。在此方法中，再分配的内部分配由模型负责，这可能导致非直观且 unintended 的分配（例如，交叉族裔子群可能在无干预条件下更受劣势）。在最佳情况下，再分配方法会确保群体内部的相对排名保持不变。

尽管再分配粗糙，另一种更糟糕的干预措施是完全忽略与群体身份相关的特征。为了明确，如果该特征在统计、因果或道德上无关，则忽略它可能是合理的（第 2 章）。但如果该特征实际上与结果相关呢？例如，假设贡献开源软件项目的人往往是更好的软件工程师。这种影响通过 morally relevant（ morally 相关）的因果路径产生，因为程序员通过参与开源获得实用的软件工程技能。遗憾的是，许多开源社区对女性和少数族裔充满敌意和歧视（这可能是因为缺乏像企业那样的正式组织结构来一定程度控制人际歧视）。认识到这一点，软件公司可以在招聘决策中显式考虑这一点，或者简单地忽略开源贡献作为评估标准。如果后者，则平均招聘的候选人资质会更低；同时也会使那些在歧视中仍坚持提升技能的群体—— arguably 最值得尊重的群体——受到不利影响。

基于统计考量而无需 moral 或 causal 正当性的特征忽略，在实践中极为流行，因为它实现简单、政治上可接受，并且规避了因歧视性对待而产生的法律风险。

### 打击人际歧视

与直接干预输出不同，组织可以尝试改进决策过程。在许多情况下，歧视者在调查和面试中往往坦诚地表达其偏见 \[[318](#references.xhtml#ref-318)\]。他们是否可以通过培训来消除隐性或显性偏见？这就是所谓的偏见消除，常被称为“多元化培训”。
