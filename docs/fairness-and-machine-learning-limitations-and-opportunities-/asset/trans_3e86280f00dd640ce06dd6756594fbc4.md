| 每种方法都有正面和负面的规范性优缺点。传统方法通过选择标准和分配给它们的权重，使得可以通过标准的选择和分配的权重来表达多个目标和规范价值。 |  |  |  |  |
| 在机器学习方法中，多个目标和规范考量需要被整合到目标的选择中。例如，在大学录取中，这些目标和考量可能包括——除了学术潜力之外——体育和领导潜力，申请人对校园生活的贡献程度，申请人是否拥有非凡的生活经历，其需求程度，以及其他许多因素。最常见的做法是定义一个复合目标变量，它线性组合多个组成部分，但这很快变得笨重，而且很少受到严谨的讨论。此外，仍有一定空间可以在决定性标准的包含或排除上行使规范判断，但这远不及 deliberative policy making（ deliberative policy making 指通过审议性政策制定来进行的决策制定）那样充分。 |  |  |  |  |
| 另一方面，如果我们相信目标实际上捕捉了决策者所考虑的全部目标，那么机器学习模型可能更有效地服务于这些目标。例如，在一篇比较两种政策制定方法的论文中，Rebecca Johnson 和 Simone Zhang 表明，传统方法（即通过审议和辩论手动制定规则）往往无法产生符合其所谓目标的规则 \[[72](#references.xhtml#ref-72)\]。在检查用于分配住房援助的规则时，他们发现住房主管部门将退伍军人置于特别负担沉重的家庭之上，尽管支持这类家庭似乎更符合政策的基本目标。Johnson 和 Zhang 指出，尽管这种优先级可能是决策者在制定规则时的实际意图，但这些优先级的原因很少在审议过程中明确说明，而且在事后尤其难以辨认。如果这些规则是通过机器学习开发的，决策者就需要同意一个明确的预测目标，这将大大减少关于决策者意图的混淆空间。而且，这将确保生成的规则**只**用于预测该目标 \[[72](#references.xhtml#ref-72)\]。正如 Rediet Abebe、Solon Barocas、Jon Kleinberg 及其同事所论述的，“计算的本质是需要对系统的输入、目标、约束和假设作出明确选择”——这可能是一件好事，因为它迫使某些政策考量和规范判断公开化。 |  |  |  |  |
| 然而，机器学习方法面临严重风险——即只关注预测的准确性。换句话说，“良好”的决策是准确预测目标的决策。但决策可能因其他原因被视为“良好”：关注正确的属性或结果（即目标是目标的良好代理），只考虑相关因素，考虑所有相关因素，纳入其他规范原则（如需求、应得等），或让人们理解并可能质疑政策。即使决策过程本身预测性不强，只要具备这些其他属性，也可能被视为良好 \[[74](#references.xhtml#ref-74)\]。在接下来的章节中，我们将探讨这些关切如何具体应用于机器学习。 |  |  |  |  |
| **目标与目标之间的不匹配** |  |  |  |  |
| 找到一个与决策者目标良好匹配的预测目标并不容易。决策者往往没有预先存在、明确且离散的目标 \[[75](#references.xhtml#ref-75)\]。即使有目标，它也可能比一个离散且易于测量的结果更为复杂和多维 \[[76](#references.xhtml#ref-76)\]。事实上，决策者可能拥有多个相互冲突的目标，涉及它们之间的权衡。例如，大学招生官的决策方案往往包含多种不同的目标。他们并不是简单地根据预测的绩点（GPA）对申请人进行排名，然后录取排名靠前的申请人以填补学校的物理容量。除了显而易见的事实——即这将偏向于选修“轻松”课程的申请人外，招生官还希望招收兴趣多样的学生群体，并具备为更广泛社区作出贡献的能力。 |  |  |  |  |
| 此外，可能存在严重的实际挑战，使得测量真正感兴趣的结果变得困难，导致决策者只能选择作为合理代理的替代指标。在大多数情况下，决策者会选择**便利目标**——即数据容易获取的目标 \[[56](#references.xhtml#ref-56), [77](#references.xhtml#ref-77)\]。例如，逮捕数据（即某人是否被逮捕）常被用作犯罪数据（即某人是否犯罪）的代理，尽管许多犯罪从未被观察，因此从未导致逮捕；而且警察可能在观察到的犯罪中选择性地进行逮捕 \[[78](#references.xhtml#ref-78)\]。尽管我们并不认可警察采用这一目标的决定，但我们仍可认识到其背后的实际困难：不可能观察到所有犯罪，因此决策者可能觉得使用逮捕作为替代是合理的。 |  |  |  |  |
| 即使决策者有某种方式获取犯罪信息，也**仍然**不明显该选定的目标与警察 underlying 目标的匹配程度如何。准确预测未来犯罪的发生并不等同于帮助减少犯罪；事实上，准确的犯罪预测可能导致警察观察到更多犯罪并产生更多逮捕，而非防止犯罪发生 \[[79](#references.xhtml#ref-79)\]。如果警察的实际目标是减少犯罪而非仅确保所有犯罪都导致逮捕，那么即使以犯罪为预测目标，也可能无法帮助警察实现这些目标。警察可能更应估计警务干预的抑制作用，但这比基于观察数据进行预测要复杂得多；要回答这些问题需要进行实验。当然，即使这种问题的表述也应受到进一步批判性分析，因为它未考虑除改善警务存在感的抑制作用之外，还有其他种类的干预方式能够帮助减少犯罪。即便如此，决策者可能仍倾向于选择不够精确但成本更低或更易操作的简化方案 \[[56](#references.xhtml#ref-56), [61](#references.xhtml#ref-61)]。 |  |  |  |  |
