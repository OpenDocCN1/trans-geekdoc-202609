
# 第4章

第4章探讨了针对系统性不同群体待遇和这些群体所经历的结果差异的规范性基础的异议。我们回顾了关于歧视的许多关于其错误性的论述，并展示这些论述如何与提供平等机会的不同观点相关联。在此过程中，我们突出了一些关于平等机会的相互竞争愿景之间的紧张关系——有些相当狭隘，有些则极为宽泛——以及为调和这些冲突而提出的各种论点。在此基础上，我们进一步探讨常见的道德直觉和既定的道德理论如何帮助我们理解第3章中引入的形式主义，旨在赋予这些定义更多的规范性实质。

在技术和法律关于歧视的研究中，一种普遍的观念是将规范性权重分配给因果关系。群体成员是否是拒绝的原因？如果他们属于不同种族，他们是否会被拒绝？如果他们的性别不同，他们是否会被接受？为了理解这类陈述以及因果在歧视中的作用，本书第5章是一份关于因果形式概念的自包含介绍。

在对统计学和因果公平定义的正式遭遇之后，我们在第6章转向美国在歧视方面的法律维度。法律情境既不完全对应于道德基础，也不完全对应于形式工作，使情况变得相当复杂。两大主导法律教条——显性待遇歧视和影响歧视——似乎在显性考虑群体成员与干预以避免歧视之间形成了张力。

在第7章，我们进一步探讨了因果和法律章节的内容，重点在于通过实验和审计在实践中检验歧视的复杂性。

对决策中的歧视进行研究一直受到批评，因为它是一种狭隘的视角，忽视了更广泛的不公正体系，至少有两个原因。首先，作为一种歧视概念，它忽视了歧视的有力结构性决定因素，如法律和政策、基础设施、教育等。其次，它将干预空间定位为改革现有决策系统的方案，在机器学习的情况下通常通过更新算法来实现。因此，这种视角可能显得过于关注“技术解决方案”，而忽视了更有力的结构性干预措施以及放弃部署机器学习系统的替代方案。与其惩罚因未出庭而失败的被告，或许更有效的做法是通过提供交通和儿童照护来促进法院预约的便利。第8章从经验角度向读者介绍了这种更广阔的视角及其相关的干预空间。

认识到更广泛的社会和结构性视角的重要性，我们为何仍应研究决策中的歧视概念？一个好处是它为向个别决策者施加压力提供了政治和法律策略。我们可以提出针对特定个人、公司或机构的歧视指控。我们可以讨论在决策者合理可及的范围内存在的干预措施，从而预期决策者会实施这些措施。某些微观干预措施可能比结构性干预措施更直接可行。

采取微观视角并不意味着忽视情境。事实上，那些避免显性考虑群体成员而为群体创造机会的分配规则，往往是通过将分配规则与外部社会事实相结合来实现的。一个显著的例子是“德克萨斯10%规则”，该规则保证在德克萨斯州高中毕业班中成绩排名前10%的学生可自动获得所有州立大学的入学资格。如果高中班级在最初就存在种族隔离，该规则就无法促进公立大学的种族多样性。这一例子说明了在详细考察特定决策规则的同时，也应关注更广泛的社会背景。两者并非互斥，而是相辅相成。

更广泛的社会世界与机器学习生态系统之间的接触点是数据集。整个第9章探讨了数据集的历史、意义和科学基础。对数据集的详细考察、数据收集与构建，以及与数据相关的危害，通常在机器学习课程中缺乏。

公平性仍是一个活跃的研究领域，距离解决尚远。我们在写作这本书的同时，研究活动达到了爆发式的程度。过去五年内，数千篇相关论文发表。关于促进公平的算法干预措施的研究进展尤为迅速，因此我们没有尝试全面调查它。

本书存在一些严重、甚至显而易见的局限性。

书的大部分内容特定于美国。由三位在美国教育和就业机构受教育并受雇的作者撰写，本书基于西方道德传统，假设美国的法律和法律理论，并在全书中不断引用美国的工业和政治背景。我们在此书中没有尝试解决这一严重局限性。事实上，要解决这一局限性需要一本完全不同的书。

第二个局限性源于我们的主要目标是发展参与该主题所需的道德、规范和技术基础。由于其关注基础，本书可能给一些读者一种脱离那些因算法使用而受到严重伤害和损害的个人和社区实际经历的感觉。由于作者缺乏系统性压迫的第一手经验，这一缺陷进一步被放大。因此，本书无法替代那些活动家、记者和学者的重要工作，他们教会我们在具体情境中了解算法决策的危害。我们在写作这本书时，建立在这些关键贡献之上。我们试图在全书中加以强调，但很可能在某些方面仍未做到位。

本书既不是对算法决策的全面支持，也不是对其的广泛谴责。在写作这本书时，我们尝试了可能是任何主题中最不受欢迎的立场：保持平衡。我们努力找出算法决策的优点，同时给予其危害和局限性相当多的关注。一些人可能认为我们的平衡是缺乏政治承诺的表现，一种两边主义。

尽管政治局势紧迫，我们的书并未提供关于如何做出公平决策的直接实用指南。事实上，我们写这本书是为了长期来看。我们相信关于算法决策的争论将持续下去。我们的目标是加强未来辩论的知识基础，这些辩论将在未来的具体实例中展开。任何希望塑造社会中算法决策未来的人很可能会在本书中找到一些有价值的材料。
