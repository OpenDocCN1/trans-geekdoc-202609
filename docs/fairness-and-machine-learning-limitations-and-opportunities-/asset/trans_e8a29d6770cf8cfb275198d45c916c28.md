
游戏是一个常见的问题，因为大多数模型都没有发现解释结果的因果机制。因此，防止游戏需要因果建模 \[[98](#references.xhtml#ref-98)\]。此外，一个可被游戏的方案随着时间的推移会变得效果递减，可能会削弱决策者的目标以及资源的合理分配。事实上，即使决策主体并非对抗性地行事，游戏仍可能是一个问题。求职者可能会花费大量时间和金钱去获得他们被告知在行业中重要的无意义的资质，结果发现虽然这有助于他们获得工作，但并不能让他们更好地准备实际工作 \[[101](#references.xhtml#ref-101)\]。在这种情况下，战略行为可能代表了善意行为者在努力上的浪费性投资。

## Concluding Thoughts

在本章中，我们拆解了三种自动化形式。我们讨论了每种自动化在一定程度上如何回应关于某些决策的随意性的担忧，同时也为合法性的新问题打开了大门。随后，我们深入探讨了第三种自动化形式——预测优化，这也是本书大部分内容的关注点。

需要明确的是，我们并未对自动化决策的合法性作出绝对主张。在与人们生活机会无关的应用场景中，合法性问题显得不那么突出。例如，在信用卡欺诈检测中，统计模型用于在交易数据中寻找模式，如地点突然变化，这可能表明因被盗信用卡信息而导致的欺诈。对个人的影响通常较低。例如，在美国，个人责任上限为50美元，前提是满足特定条件。因此，虽然错误的成本较高，但主要由决策者（在此例中为银行）承担。因此，银行倾向于基于成本考量部署此类模型，而不必担心（例如）为客户提供质疑模型的途径。

在具有重要影响的应用场景中，为了建立合法性，决策者必须能够在我们所提出的维度上主动为其方案辩护：说明目标与所有利益相关者可以达成一致的目标之间的关系，验证部署系统的准确性，提供申诉途径，以此类推。在许多情况下，可以通过在自动化系统周围设置程序性保护措施来实现这种合法性，但决策者往往不愿这么做，因为这会削弱自动化本应实现的成本节约。

# 3 Classification

分类的目标是利用自然和社会过程中的模式来推测不确定的结果。结果可能不确定是因为它发生在未来。例如，我们试图通过查看信用历史和收入等各种特征来预测贷款申请人是否会偿还贷款。分类也适用于结果已经发生但我们仍不确定的情况。例如，我们可能会通过查看财务交易来判断是否发生了金融欺诈。

使分类成为可能的是人口中结果与我们可以观察到的信息之间存在的模式。分类特定于某个人口以及该人口中普遍存在的模式。高风险贷款申请人可能表现出高信用利用率的记录。金融欺诈往往与财务报表中数字分布的不规则性相吻合。这些模式在某些情境中可能存在，在其他情境中则可能不存在。因此，分类的效果程度因情境而异。

我们将分类形式化为两个步骤。第一步是将人口表示为概率分布。虽然在当今的量化工作中这通常被视为理所当然，但将动态变化的人口表示为概率分布这一行为本身是一个重要的假设。第二步是应用统计学，特别是统计决策理论，到代表人口的概率分布上。统计决策理论形式化了分类目标，使我们能够讨论不同分类器的优劣。

统计决策理论对分类的处理构成了监督机器学习的基础。监督学习使分类算法化，它通过提供从人口中抽取的样本转化为良好分类规则的启发式方法。

## Modeling Populations as Probability Distributions

概率用于研究人类群体的最早应用之一是哈利的`life table`（1693年）。哈利统计了一个小城镇的出生和死亡，以估计人口的预期寿命（[figure 3.1](#chapter_3.xhtml#fig3-1)）。当时，预期寿命的估计与概率理论本身一样新颖，并被用于精确定价那些在个人余生中每年支付固定金额的投资。

然而，随后几个世纪里，将概率用于建模人类群体仍然在科学和政治层面受到争议 \[[102](#references.xhtml#ref-102), [103](#references.xhtml#ref-103), [104](#references.xhtml#ref-104)\]。在19世纪，天文学家和社会学家阿多lf·克瓦特莱特（Adolphe Quetelet）是最早将统计应用于社会科学之一。他在其被称为“社会物理”的科学计划中，试图证明人类群体中存在统计`规律`。他提出了“平均人”的概念，该概念由若干测量变量（如身高）的平均值特征，这些值遵循正态分布。平均值既是描述性也是规范性的提案。克瓦特莱特将它们视为应追求的理想。其工作还影响了弗朗西斯·加尔顿（Francis Galton）发展优生学。

统计学在整个20世纪的成功巩固了将概率用于建模人类群体的做法。如今，如果我们说“调查”是从分布中抽取响应，这似乎不再令人惊讶。现在似乎显而易见，我们希望从收入、家庭规模或其他类似属性的分布中估计均值和标准差等参数。统计学已经深深植根于社会科学，我们很少会质疑我们是否可以将人类群体表示为概率分布。

人类群体与分布之间的差异显著。人类群体会随着时间的推移而变化，有时因个体行为、机制以及个体间的相互作用而迅速变化。相比之下，分布可以被视为一个静态数组，其中行对应个体，列对应个体的测量变量。这种数学抽象是一组非负数（称为`probabilities`），它们的和为1，并为每一行提供该设定变量在人口中的相对权重。从该分布中抽样相当于在权重的比例下随机选择表中的一行。我们可以重复此过程而不产生任何变化或退化。在此视角下，分布是不可变的。我们所做的任何事情都无法改变人口。
