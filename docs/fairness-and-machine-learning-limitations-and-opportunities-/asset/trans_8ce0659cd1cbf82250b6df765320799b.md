
-   [这种自动化方式可能有助于解决人类决策中的随意性问题，通过形式化和固定决策方案，类似于过去人类可能使用的方式。在此方面，机器学习可能是可取的，因为它可以帮助平滑人类决策中的任何不一致性，从而推导出一些决策规则。例如，上文所述的作文评分模型可能会减少教师主观评价中出现的评分差异，因为该模型正在学习复制这些评价。自动化可以再次帮助解决被理解为不一致的随意性问题，即使被自动化的是主观判断。

几十年前，一种流行的自动化方法依赖于明确编码人类用于做出决策的推理过程 \[[66](#references.xhtml#ref-66)\]。这种方法称为“专家系统”，因多种原因失败，包括人们并不总是能够解释自己的推理 \[[67](#references.xhtml#ref-67)\]。专家系统最终被一种方法取代，即直接让人们标记示例，并让学习算法发现如何最好地预测人类会赋予的标签。虽然这种方法证明了其强大，但也存在危险。

首先，它可能给那些仅仅自动化人类主观判断的决策方案一种客观评估的表象。结果，人们可能更倾向于认为其决策不值得深入批判性审查。这一点尤其令人担忧，因为从人类之前的决策中学习决策规则，显而易见会复制并放大人类决策中任何不良特质，因为学习的例子本身就是人类设定的糟糕示例。（事实上，许多试图学习预测某种看似客观目标的规则的尝试——即我们下一节将讨论的自动化形式——实际上只是以掩盖人类判断的形式，如果无法获得目标的客观真理，就无法摆脱人类判断 \[[68](#references.xhtml#ref-68)\\)。其次，这类决策方案可能被视为与人类使用的方法相同，因此很可能运作方式相同，尽管模型可能在决策过程和产生的错误模式上有所不同 \[[69](#references.xhtml#ref-69)\\)。即使模型能够在高度准确的程度上预测人类在任何特定输入下会做出的决策，也不能保证模型继承了人类决策中所有的细微因素和考量。更糟的是，模型可能学会依赖人类认为令人不安或不acceptable的标准，即使这些标准仍能产生与人类相似的决策结果 \[[70](#references.xhtml#ref-70)\\)。例如，一个自动化作文评分的模型可能会因为论文使用了更高级的词汇而给出更高分数，从而合理地复制人类评分员的判断（可能因为高质量写作往往依赖更高级的词汇），但检查特定词汇的出现不太可能是评估论文逻辑连贯性和事实正确性的可靠替代 \[[71](#references.xhtml#ref-71)\\)。

总之，使用机器学习自动化人类先前执行的决策可能是有问题的，因为机器学习模型可能既过于像人类决策者，又过于不同于它们。

### 通过学习预测目标来推导决策规则

最后一种自动化形式是决策者利用机器学习从数据中学习决策规则或策略的形式。我们称之为预测优化。这种自动化形式直接针对有理由的决策问题。注意，前两种自动化形式并不如此。一致执行已有的政策通过自动化并不确保该政策本身是有理由的。同样，依赖过去的人类决策来诱导决策规则也不能保证自动化决策的基础会反映出有理由的判断。在这两种情况下，决策方案的合理性只能与被自动化的正式政策或非正式判断的合理性相匹配。

相反，预测优化试图通过仅在能够实证预测感兴趣的结果或质量的前提下，依赖于标准来提供更严谨的决策基础。当以这种方式使用机器学习时，它似乎能确保有理由的决策，因为纳入决策方案的标准（及其具体权重）是由它们预测目标的效果所决定的。只要选定的目标是决策者目标的良好代理，那么依赖能够预测该目标的标准来进行决策似乎是合理的，因为这有助于实现决策者的目标。

与前两种自动化形式不同，预测优化是对传统决策方式的根本背离。在传统方式中，一组决策者有一个目标——即使这个目标是模糊且难以界定的——他们希望制定一个明确的决策方案来实现该目标。他们通过讨论和 deliberation 试图达成关于相关标准及其在决策方案中权重的共识。决策者依据直觉、先前证据和规范性推理，选择并组合特征，认为这样能实现他们的目标。

统计或机器学习方法则不同。首先，决策者尝试识别一个明确的预测目标，他们认为该目标与其目标同义，或是其合理的代理。例如，在大学录取情境中，一个目标可能是大学期间的学业成就，而大学绩点平均分（GPA）可能是其代理。一旦确定这一点，决策者便利用数据发现应使用哪些标准以及如何加权，以最佳预测该目标。虽然他们在选择标准时可能保留一定自由裁量，但标准的加权完全由最大化对选定目标预测准确性的目标所决定。换句话说，决策规则在很大程度上是从数据中学习得到的，而不是由决策者的主观直觉、期望和规范性承诺来设定（\[[table 2.1](#chapter_2.xhtml#tab2-1)\\)）。
