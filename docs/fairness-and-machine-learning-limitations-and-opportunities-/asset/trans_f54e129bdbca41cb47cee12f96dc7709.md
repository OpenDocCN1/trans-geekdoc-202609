
人们提供训练数据时可能对手头任务有`knowledge`，但只向系统提供他们的`behavior`作为输入（比如电子邮件收件人点击“报告垃圾邮件”按钮）。机器学习则以集中化的方式构建一种知识形式。相反，领域专家在与其互动的个体的知识和亲身经历中部分学习。诚然，像医师这样的专家常被批评贬低决策主体（患者）的知识和经验 \[[415](#references.xhtml#ref-415)\]。但这种争论的发生本身已证明患者在传统体系中至少拥有一些权力 \[[416](#references.xhtml#ref-416)\]。

与传统决策方式相比，域专家的角色也更为有限，而在传统决策中，这类专家的酌情权和判断力占主导。在监督机器学习中，域专业知识主要在两个步骤中被需要：制定问题和任务，以及标记训练示例。实际上，工具开发者往往不看重域专家的作用，因此专家的角色更加受限。例如，一项基于六十八次访谈的研究发现，“开发者将\[域专家\]视为腐败、懒惰、不合规，并且试图通过游戏化等手段让工人收集更高质量的数据” \[[417](#references.xhtml#ref-417)\]。

这种权力转移的公平性影响是复杂的。在政府官僚机构中，“基层官员”（如警察和社会服务案件处理人员）所拥有的权力——他们将政策转化为个人决策——可能被滥用，而剥夺他们的酌情权通常被视为公平性干预。然而，这些决策者的酌情权和人类智能也因训练数据中未见或政策中未覆盖的特殊情况或新形势而成为促进公平的重要因素 \[[59](#references.xhtml#ref-59), [418](#references.xhtml#ref-418)\]。当系统本身不公正时，负责执行该系统的人可以通过不服从或吹哨来提供重要的抵抗力量。

与基层官员不同，机器学习赋予了政策制定者或集中决策者（即官僚体系顶层的人）更大的权力。例如，儿童保护机构使用风险预测工具筛选来电。根据机构预算及其他因素，决策者可能希望筛选更高或更低比例的来电。通过统计工具，这种政策改变可以立即实施，远比重新培训数百名案件处理人员以调整其心理捷径更为容易。这只是一个说明，为何此类工具对决策者具有强大吸引力。

机器学习专家当然在核心位置。利益相关者的要求必须由这些专家转化为实现；有意或无意之间，实际实现的政策与期望政策之间常存在显著差距 \[[273](#references.xhtml#ref-273)\]。在每个自动化系统中，都有从人类语言到计算机代码的翻译过程中丢失的内容。例如，曾出现软件错误计算监狱囚犯的提前释放资格，导致被关押时间过长，或在释放后再次入狱的令人痛心的后果 \[[419](#references.xhtml#ref-419), [420](#references.xhtml#ref-420)\]。但在传统自动化系统中，这些差距往往是显而易见的错误（虽然这对受害者并无慰藉）。但当涉及机器学习时，专家的介入往往是识别问题的必要条件，因为政策往往更模糊（比如“高风险”指什么？），且偏离政策的情况只能在聚合层面显现。

此外，决策者常常将权力让渡给工具开发者，使后者更具影响力。Deirdre Mulligan 和 Kenneth Bamberger 阐述了政府机构如何通过采购流程获取机器学习系统——这种流程与聘请承包商建造桥梁相同 \[[421](#references.xhtml#ref-421)\]。采购思维忽视了所得产品用于做出重要决策，即实际上制定政策的事实，其关注点在于价格和风险规避，而非决策透明度或监督。

## Structural Interventions for Fair Machine Learning

机器学习可能导致结构性歧视，这促使需要同等宽泛的干预措施。我们称这些“结构性干预”：改变机器学习的构建和部署方式。我们设想的改变超出任何单一组织的范畴，需要集体行动。这可能体现为广泛的社会运动，或包括社区、工人、研究人员和用户在内的其他集体。

### 重塑底层机构

一种做法是关注底层机构而非技术，使其本身更不易采用有害的机器学习工具。例如，将刑事司法系统的重点从 incapacitation（隔离）转向 rehabilitation（康复），可能会降低对风险预测工具的需求 \[[422](#references.xhtml#ref-422)\]。许多学者和活动人士区分 reform（改革）与 abolition（废除，亦称非reformist reform），后者是更激进和变革性的方式 \[[193](#references.xhtml#ref-193), [423](#references.xhtml#ref-423), [424](#references.xhtml#ref-424)\]。但就我们目的而言，两者都将干预焦点放在机构而非技术上。

在许多领域，我们机构的目的和旨归根结底是有争议的。例如，警务的目标是什么？公认的目标包括犯罪威慑与预防、确保公共安全与最小化秩序混乱、将违法者绳之以法；也可能包括更广泛的社区健康与活力提升。这些目标的相对重要性因社区和时代而异。因此，将警务分配决策作为优化问题（如预测性警务系统所做），实际上涉及对这些深层争议问题的立场。

历史表明，许多看似现代社会固定不变的机构，如高等教育，实际上多次重新定义其目标和目的以适应变化的世界。有时这种转变的动力甚至是*更有效地进行歧视*。在二十世纪初，精英美国大学从把入学规模（ enrollment size）视为声望来源转变为强调选择性。主要原因是为了在不设定显性 quotas（配额）的情况下遏制日益上升的犹太学生比例；新的选择性使他们能够在招生中强调品格和个性等特质，从而为酌情权留下空间。事实上，Harvard 在 1926 年采用的系统正是如今仍备受争议的全面录取（holistic admissions）方法的起源，正如 Jerome Karabel 在其著作 *The Chosen* 中所解释 \[[425](#references.xhtml#ref-425)\]。
