
对于本章余下部分，我们可以将监督学习视为一个黑盒，它在获得标记训练数据时会提供分类器。重要的是这些分类器在总体层面的属性。在总体层面，我们将分类器视为随机变量，通过考虑 `$Ŷ = f(X)$` 来解释。我们忽略 `$Ŷ$` 是如何从有限样本中学习的，分类器的功能形式是什么，以及如何从有限样本中估计各种统计量。虽然有限样本考虑是机器学习的基础，但它们并不在本章讨论的公平性概念和技术问题的核心。

### 群体在总体中的分布

第 2 章介绍了为何个体可能希望对统计分类规则在重要决策中的使用提出异议。我们现在转向一个具体的关注点，即 *基于总体中特定群体成员的歧视*。歧视并非一般概念，它关注的是在过去曾受到不公正且系统性不利对待的、在社会上具有显著性的类别。美国法律认定了若干 *受保护类别*，包括 `race`、`sex`（涵盖 `sexual orientation`）、`religion`、`disability status` 和 `place of birth`。

在许多分类任务中，特征 `X` 隐含或明示地编码了个体在受保护类别中的状态。我们将字母 `A` 用作占位符，表示一个离散随机变量，用来捕捉一种或多种敏感特征。不同的 `A` 取值对应于总体中相互不重叠的群体。随机变量 `A` 在技术文献中常被称为 *sensitive attribute*（敏感属性）。

注意，形式上我们总是可以将任意数量的离散受保护类别表示为一个离散属性，其取值范围对应于原始属性的每一种可能取值。因此，本章的形式化处理同样适用于多个受保护类别的情况。但这种形式化并未解决 *intersectionality*（交叉性）这一重要概念，它指的是属于多个受保护类别的个体所经历的特定不利形式 \[[105](#references.xhtml#ref-105)\]。

为群体成员分配一个专门的随机变量并不意味着我们可以将特征集合干净地划分为“中性”和“敏感”两类。事实上，我们稍后会看到，大量看似中性的特征往往能够非常准确地预测群体成员身份。这并不令人惊讶。毕竟，如果我们把 `A` 视为分类问题的目标变量，那么剩余特征很可能为 `A` 提供非平凡的分类器。

选择敏感属性会产生深远影响，因为它决定了我们在研究中突出哪些人群以及从调查中得出什么结论。由离散化诱导的分类法本身如果过于粗糙、过于细致、误导或不准确，就可能成为伤害的来源。将状态归类到受保护类别并收集相应数据本身就可能是有问题的。我们将在下一章重新审视这一重要讨论。

### 无意识公平的不可能性

有人希望通过删除或忽视敏感属性来确保得到的分类器的公正性。遗憾的是，这种做法可能无效，甚至有害。

在典型数据集中，我们有许多与敏感属性略有相关的特征。写作时，访问美国的 `pinterest.com` 网站，例如，与性别存在微小的统计相关性。单独的相关性本身不足以高精度地判断个人的性别。然而，如果有大量这类特征（如在典型的浏览历史中），则可以在更高的准确率下完成性别分类（[figure 3.4](#chapter_3.xhtml#fig3-4)）。

![Figure 3.4On the left, we see the distribution of a single feature that differs only very slightly between the two groups. In both groups the feature follows a normal distribution. Only the means are slightly different in each group. Multiple features like this can be used to build a highly accurate group membership classifier. On the right, we see how the accuracy grows as more and more features become available.](images/fig3-4.png)

[Figure 3.4](#chapter_3.xhtml#fig3_4)左侧，我们看到一个单一特征在两组之间仅略有差异的分布。两组的特征均遵循正态分布，仅均值略有不同。多个此类特征可以用于构建高精度的群体成员分类器。右侧，我们看到随着特征数量的增加，准确率也随之提升。

一些能够略微预测敏感属性的特征可以用于构建对该属性的高精度分类器。在大规模特征空间中，敏感属性通常在其他特征的条件下是 *冗余* 的。如果一个在原始数据上训练的分类器使用了敏感属性，并且我们删除该属性，分类器会在其他特征中找到冗余的编码。这导致一个本质上等价的分类器，即它实现相同的函数。

为了进一步说明问题，考虑一个虚构的初创公司，其目标是根据你的基因组预测收入。乍一看，这似乎不可能。基因如何能揭示收入呢？然而，我们知道 DNA 编码关于祖先的信息，而祖先在像美国这样一些国家与收入存在关联。因此，DNA 很可能被用于比随机猜测更准确地预测收入。 resulting classifier 隐含地使用了祖先信息。从基因组中去除祖先的冗余编码是一项困难的任务，不能仅通过删除少数单个基因标记来完成。我们学到的是，机器学习可以在未被明确要求的情况下，利用敏感属性的可用性来提升准确性。

冗余编码在大规模特征空间中普遍存在。例如，性别可以从视网膜照片中以极高的准确率预测 \[[106](#references.xhtml#ref-106)\]。那如果只使用精心挑选的少量手工特征呢？在某些研究中，特征被精心选择以使它们在统计上大致相互独立。在这种情况下，敏感属性可能没有良好的冗余编码。这并不意味着删除它是个好主意。例如，药物有时会在合法的情况下依赖种族，因为这些种族与根本原因相关 \[[21](#references.xhtml#ref-21)\]。强制药物与种族无相关性可能会损害个体。

### 统计非歧视准则

统计非歧视准则旨在用统计表达式来定义分类或决策场景中不存在歧视的状态。形式上，统计非歧视准则是关于敏感属性 `A`、目标变量 `Y`、分类器 `Ŷ` 或评分 `R`（以及在某些情况下特征 `X`）的联合分布的属性。这意味着我们可以通过观察这些随机变量的联合分布，明确判断一个准则是否满足。
