
# 线上市场中的歧视检测方法

线上市场中的歧视检测方法与传统环境（如住房和就业）相似；审计研究和观察方法的结合已被使用。一个显著的例子是本杰明·埃德尔曼、迈克尔·卢卡和丹·斯维斯基针对 Airbnb 的领域实验 \[[355](#references.xhtml#ref-355)\]。作者创建了名称暗示种族（非裔美国人或白人）和性别（女性或男性）但除此之外完全相同的假客户账户，使用了 20 个不同的名称：每种种族和性别组合各 5 个。随后，他们通过这些账户联系了 6,400 个列表的主机，在五个城市询问可用性。他们发现，名字听起来像白人的人的询问接受率为 50%，而名字听起来像非裔美国人的询问接受率为 42%。这种差异在主机的种族、性别、经验、列表类型（高价或低价；整套房或共享）以及社区多样性方面均保持一致。需要注意的是，账户没有头像照片；如果主机在一定程度上是根据外貌来推断种族，那么改变账户的头像照片可能会发现更大的效果。

与传统环境相比，在线平台上可以轻易获得某些观察数据，这对研究者很有用。在上述研究中，列表评论的公开可得性证明了其价值。虽然它不是研究设计的必要条件，但它提供了一个有趣的有效性检查。当分析仅限于样本中 29% 的主机——这些主机至少收到过一条非裔美国人宾客的评论——时，种族差异在响应中急剧下降。如果研究结果是实验设计的偶然现象而非 Airbnb 主机的实际种族歧视，那么解释为何在该子集的主机中效果会消失将会很困难。这支持了该研究的外部有效性。

此外，在线市场还必须面对的另一个公平问题涉及地理差异的效果。一项关于 TaskRabbit 和 Uber 的研究发现，人口密度高且收入高的社区从共享经济中获得最大收益 \[[356](#references.xhtml#ref-356)\]。由于贫困与种族/民族之间存在普遍关联，这些社区也转化为种族差异。在本研究所在的芝加哥地区，黑人和拉丁裔社区人口密度较低，这进一步加剧了这一效果。

当然，这些市场的地理和结构性差异并非由在线平台造成，线下类似的情况（如基于口碑的零工工作）也存在这些差异。事实上，在打车招手的场景中，种族歧视的程度远大于技术中介的交互场景 \[[357](#references.xhtml#ref-357)\]。然而，与受反歧视法律监管的市场（如酒店）相比，在线市场的歧视更为严重。无论如何，这些平台的正式化特性使审计更加容易。此外，这些平台的集中化特性为公平干预提供了强大的机会。

平台可以通过设计来最小化用户进行歧视的能力（例如隐藏对方信息）以及促使歧视的动力（例如在界面上使参与者特征不那么显著，而突出产品特征） \[[358](#references.xhtml#ref-358)\]。平台无法对参与者的歧视保持中立立场：即使是未明确考虑歧视的选择，也会影响用户的偏见态度如何转化为歧视行为。

作为设计决策的具体例子，Airbnb 研究的作者建议平台在预订前隐藏宾客信息（注意，叫车服务也隐藏客户信息；而拼车服务则允许用户在选择匹配时查看姓名，这不出所料地使得对种族少数群体的歧视成为可能 \[[359](#references.xhtml#ref-359)\\]）。关于地理不平等的研究建议，拼车服务等可以提供“地理声誉”评分给司机，以应对司机常常错误地认为某些社区比实际更危险的问题。

## 歧视机制

我们已经查看了若干关于在算法系统中发现不公平的研究。让我们来梳理一下。

在导论章节中，我们从高层次上讨论了机器学习系统中不公平可能出现的不同方式。这里我们看到，不公平的具体来源和机制可以既复杂又具有领域特定性。研究人员需要了解该领域，才能有效提出和测试关于不公平来源和机制的假设。

例如，考虑前文提到的性别分类系统研究。人们很容易猜测不代表性的训练数据导致了观察到的准确率差异，但不代表性在何种方面？跟进论文由 Vidya Muthukumar、Pedapati Tejaswini、Ratha Nalini 等人考虑了这个问题 \[[360](#references.xhtml#ref-360)\]。他们在实验室环境中（而非原始论文中的商业 API 现场测试）分析了多个最先进的性别分类器，并指出训练数据中较深肤色调的代表性不足并不是导致观察到的差异的原因。相反，作者提出的机制基于这样一个事实：许多面部人像训练数据集包含名人照片。他们发现，名人女性的照片相比一般女性的照片有更显著的化妆。这导致分类器将化妆作为性别的代理，而这种代理并不推广到整个人口。

略有不同的假设可以产生截然不同的结论，尤其是在内容生产者、消费者和平台之间存在复杂交互的情况下。例如，Ronald Robertson、Shan Jiang、Kenneth Joseph 等人进行的一项研究测试了搜索引擎中的党派偏见，以及相关的“过滤泡泡”假设——即搜索引擎返回的结果会强化搜索者既有观点。研究人员招募了不同政治观点的参与者，从其电脑上在标准窗口和无个人化窗口中收集了关于政治话题的 Google 搜索结果，发现标准（个性化）搜索结果并不比无个人化的搜索结果更具党派性，似乎为反驳“在线搜索强化用户既有信念”的主张提供了证据。

这一发现与事实相符：Google 只根据搜索者位置和近十分钟的搜索历史来个性化搜索结果，这一点已由 Google 本人承认 \[[362](#references.xhtml#ref-362)\] 以及 prior 研究证实 \[[363](#references.xhtml#ref-363)\]。
