
# 从个体图像到图像数据集

当我们从单个图像转换到图像数据集时，我们引入了另一种潜在偏见的层。考虑用于训练当今计算机视觉系统的图像数据集，这些数据集用于执行诸如目标识别等任务。如果这些数据集是底层视觉世界的代表性样本，我们可能期望在一个数据集上训练的计算机视觉系统在另一个数据集上也能表现良好。但事实上，我们观察到在不同数据集上进行训练和测试时，准确率会出现显著下降 \[[17](#references.xhtml#ref-17)\]。这表明这些数据集在统计意义上相互偏向，这为探讨这些偏见是否包含文化刻板印象提供了良好的出发点。

这并非全然坏消息：机器学习实际上可以帮助缓解测量偏差。回到相机动态范围的问题，包括机器学习在内的计算技术正在使图像色调的表现得以改善 \[[18](#references.xhtml#ref-18), [19](#references.xhtml#ref-19), [20](#references.xhtml#ref-20)\]。另一个例子来自医学：诊断和治疗有时会按种族进行个性化。但事实证明，种族被用作粗糙的祖先和遗传学代理，有时也代表环境和行为因素 \[[21](#references.xhtml#ref-21), [22](#references.xhtml#ref-22)\]。如果我们能够测量医学上相关的因素，并将其（而不是种族）纳入疾病和药物反应的统计模型中，我们可以提高诊断和治疗的准确性，同时缓解种族差异。

总结来说，测量涉及定义感兴趣的变量、构建将观测转换为数值的过程，以及实际收集数据。机器学习实践者通常不关注这些步骤，因为其他人已经完成了它们。然而，理解数据的来源至关重要。即使是其他人收集的数据，也几乎总是过于混乱，无法直接供算法使用，因此需要 dreaded “data cleaning” 步骤。但真实世界的混乱并非仅仅是需要清理的烦恼；它是一个多元世界的体现，人们不易于被精确分类。忽视这些细微差别可能对边缘化群体产生特别大的伤害。

# 从数据到模型

我们已经看到，训练数据反映了真实世界的差异、扭曲和偏见，以及测量过程。这引出一个显而易见的问题：当我们从这类数据中学习模型时，这些差异是被保留、缓解，还是被放大？

使用监督学习方法训练的预测模型通常在校准方面表现良好，能够在预测结果时涵盖数据中的所有特征。但校准也意味着，默认情况下我们应当期望模型忠实地反映输入数据中发现的差异。

另一种思考方式是：训练数据中的某些模式（如“吸烟与癌症相关”）是我们希望机器学习挖掘的知识，而其他模式（如“女孩喜欢粉色，男孩喜欢蓝色”）则是我们希望避免学习的刻板印象。但学习算法没有一般性的方法区分这两类模式，因为这些模式来源于社会规范和道德判断。缺乏具体干预，机器学习会像提取知识一样，提取刻板印象，包括错误和有害的内容。

一个典型的例子出现在机器翻译领域。图 1.3 显示了从英文到土耳其语再反译回英文的结果 \[[23](#references.xhtml#ref-23)\]。在众多语言对和职业相关词汇中，我们观察到相同的刻板翻译结果。原因显而易见：土耳其语使用性别中性代词，翻译时系统会根据训练集的统计（通常是大量未经精心筛选的历史文本和网络文本）选择最匹配的句子。

当我们基于此类文本构建语言统计模型时，我们应当期望性别与职业词汇的关联大致反映现实劳动统计。此外，由于“男性‑默认”偏见（在性别未知时使用男性代词）的影响，我们还应期望翻译倾向于使用男性代词。重复数十个职业词汇的实验表明，这两个因素——劳动统计和男性‑默认偏见——几乎完全预测了返回的代词。

有人可能会提出：既然模型会反映数据偏差，那么我们是否可以在构建简历评分模型时仅剔除性别信息？遗憾的是，情况并非如此，因为存在“伪装”（proxy）或“冗余编码”（redundant encodings）的问题 \[[9](#references.xhtml#ref-9), [25](#references.xhtml#ref-25)\]，如第 3 章所讨论。数据中还有许多可能与性别相关的属性。例如，在我们的社会中，某人开始编程的年龄与性别存在关联。这说明我们不能简单地消除伪装：它们可能对决策本身是真正相关的。编程时长是一个能提供有价值信息的因素，能够反映其对编程工作适合性的情况，但同时也反映了性别刻板印象。

另一个导致机器学习在不同群体表现不一的常见原因是样本量不均。如果我们从训练数据中均匀抽样构建训练集，那么必然会导致少数群体的数据点更少。显然，机器学习在数据点更充足时表现更好，因此在假设多数群体和少数群体在预测任务上存在系统性差异的前提下，模型会对少数群体表现更差 \[[25](#references.xhtml#ref-25)\]。

更糟的是，在许多场景中少数群体相对于总体统计数据本身就被低估。例如，少数群体在科技行业中表现不足。不同群体对技术的采用速率也可能不同，这会导致从社交媒体等渠道收集的数据集出现偏差。如果训练集来源于这些不具代表性的情境，则少数个体的样本更是稀缺。

在开发机器学习模型时，我们通常只关注整体准确率；一个“5% 错误”统计可能掩盖了模型在少数群体上的极差表现。按群体报告准确率有助于发现上述问题。在第 3 章中，我们将介绍能够量化不同群体之间错误率差异的指标。
