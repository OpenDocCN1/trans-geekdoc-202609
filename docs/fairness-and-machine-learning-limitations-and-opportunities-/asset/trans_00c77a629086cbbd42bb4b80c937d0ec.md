
在我们的形式框架的语言中，中介分析旨在将总因果效应分解为路径特定的组成部分。我们将在中介的基本三变量情况中阐述概念，尽管这些想法可扩展到更复杂的结构。

存在两条从 *X* 到 *Y* 的不同路径。一条是直接路径，另一条是经过中介器 *Z* 的路径（[figure 5.11](#chapter_5.xhtml#fig5-11)）。条件期望 𝔼\[*Y| X* = *x*\] 将两条路径的影响合并。如果我们的图中存在另一个混杂变量，它同时影响 *X* 和 *Y*，那么条件期望也会包含混杂带来的相关性。我们可以通过 do-算子 𝔼\[*Y|* do(*X* := *x*)\] 消除混杂路径。这给出了将 *X* := *x* 的行动对 *Y* 的总效应。但总效应仍然混合了两条因果路径，即直接效应和间接效应。我们现在将看到如何分别识别直接和间接效应。

### 反事实歧视标准

除了在路径分析中的应用，反事实也可以作为提出规范公平标准的工具。考虑第 3 章的典型设置。我们有特征 *X*、一个敏感属性 *A*、一个结果变量 *Y*、以及一个预测 *Ŷ*。

一个技术上自然的标准会说：对于每一个由事件 *E* := {*X* := *x, A* := *a*} 描述的可能人口和每一个 *A* 的可能取值 *a*′，我们要求反事实 *Ŷ*[*A*:=*a*](*E*) 和 *Ŷ*[*A*:=*a*′](*E*) 遵循相同的分布。

这被称为“反事实公平” \[[187](#references.xhtml#ref-187)\]，我们称之为“反事实人口平等”，因为它与观测标准“条件人口平等”密切相关。回想，条件人口平等要求在每个由特征设置 *X* = *x* 定义的人口中，敏感属性与预测是独立的。形式上，我们有条件独立关系 *Ŷ* ⊥ *A | X*。对于二元预测器，这一条件等价于要求对所有特征设置 *x* 和组别 *a, a*′：

![](images/pg140-1.png)

满足反事实人口平等最简单的方法是让预测 *Ŷ* 仅使用因果图中 *A* 的非后代。这与使用仅与 *A* 无关的特征的统计条件相类比。

同样，我们可以像定义反事实人口平等那样，探索其他统计标准的因果类比。在此过程中，我们需要小心区分观测标准和因果标准之间的技术差异，以及标准的规范内容。仅仅因为因果变体可能规避一些非因果相关性的统计问题，并不意味着因果标准解决了与其观测 counterpart 相关的规范性关切或问题。
