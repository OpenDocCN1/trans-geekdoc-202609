
# 官僚机构所保护的有问题的决策可以称为“任意”决策。Kathleen Creel 和 Deborah Hellman 有用地区分了两种任意性 \[[54](#references.xhtml#ref-54)\]。第一种，任意性可能指基于不一致或临时应变的决策。第二种，任意性可能指决策缺乏理由，即使决策在该基础上是一致的。这种第一种任意性主要关注程序规则的规律性 \[[55](#references.xhtml#ref-55)\]：决策方案是否以一致且正确的方式执行。对这种任意性的担忧，实际上是担心重要决策的规则是否提前固定并恰当应用，以减少决策者随意做出决策的能力。

当决策在如此狭义的意义上是任意的时，个体可能会发现自己受到不同的决策方案的影响，仅仅因为他们在不同时间通过决策过程。不仅决策方案可能随时间变化，人类决策者在处理不同案件时也可能在如何应用这些方案上不一致。这种不一致既可能出现在单个决策者的行为随时间不一致的情况，也可能出现在决策过程将案件分配给不同个体的情形——这些个体各自一致，但彼此不同。因此，即使两个人在决策标准上完全相同，也可能因受不同个体影响而得到不同的决定，这违背了在高风险决策中相似的人应得到相似对待的预期。

这一原则基于这样的信念：除非有理由对个体进行不同的对待，否则人们应获得相似的决定（我们稍后会讨论什么是“良好”理由）。对于特别重要的决定，人们可能会好奇，为什么与自己相似的人在决策过程中获得了期望的结果，而自己没有。

当不一致性阻碍人们根据必须在其中导航以获取理想资源和机会的决策系统的预期来制定有效的生活计划时，它也是有问题的 \[[54](#references.xhtml#ref-54)\]。因此，不一致的决策既因为可能导致对相似个体的不当差别对待，也因为它削弱了个人自主性，阻碍人们有效决定如何追求人生目标。

第二种任意性触及更深层的关切：决策方案的样子是否有充分理由——或者任何理由——来支持？例如，如果教练根据跑者鞋子的颜色来选拔队伍，但做法是一致的，它仍然是任意的，因为该标准缺乏合理依据。它并未帮助实现决策者的目标（如组建一支能赢得即将到来比赛的队伍）。

从这个角度看，任意性之所以有问题，是因为它削弱了选择该决策方案的根本依据：即该方案能够推进决策者的目标。如果决策方案对实现这些目标毫无贡献，那么就没有正当理由选择该方案，并据此对待他人。当理想资源和机会被任意分配时，它徒然使个体受到不同的对待，尽管所有个体对这些资源和机会的兴趣可能是平等的。

在政府决策的语境中，通常有法律要求决策必须基于“理性”依据——即必须有良好的理由来支持决策的做法 \[[54](#references.xhtml#ref-54)\]。那些不能帮助政府实现其明确政策目标的规则将违背正当程序原则。这可能是因为规则是任意选择的，或者是因为这些规则背后的推理本身存在缺陷。这些要求源于政府对某些高度重要的决策拥有垄断地位，使得人们无法通过向其他决策者上诉来寻求救济。

私人决策者则没有相应的法律义务，Kathleen Creel 和 Deborah Hellman 指出。公司往往自由做出推理不足——甚至完全任意——的决定。理论上，那些看似对私人决策者目标毫无帮助的决策方案应被更有效的方案所取代，从而退出市场 \[[54](#references.xhtml#ref-54)\]。

然而，我们通常期望即使由私人决策者做出的重大影响决策，也应是基于良好理由的。我们不太可能容忍雇主、贷款人或招生官员通过抛硬币或根据申请者鞋子颜色来做决定。为什么会是这样？

任意决策未能尊重这些决策的严肃性，也显示出对受其影响的人缺乏尊重。即使我们接受不能 dictate 机构的目标，我们仍然反对让它们完全自由地随意对待人们。当 stakes 足够高时，决策者有义务以对受影响人群利益的尊重来为其决策方案辩护。即使人们可以在同一领域尝试其他决策者（如另一雇主、贷款人或招生官），这也很少能减轻这种期望。

## 三种自动化形式

回顾我们 earlier 的讨论，自动化可能会削弱官僚决策中的重要程序保护。但机器学习具体帮助自动化了什么呢？原来有三种不同的自动化类型。

第一种自动化涉及将由人工制定的决策规则（例如通过传统的政策制定过程得出）翻译成软件，以实现对特定案例的自动应用 \[[56](#references.xhtml#ref-56)\]。例如，许多政府机构在采用软件自动化福利资格判定以符合既定政策时采取此方法。同样，雇主在确定职位的最低资格后，也会开发软件自动拒绝不符合条件的申请人。在这两种情况下，规则仍由人制定，但其应用由计算机自动完成；在此情形下机器学习并无明显作用。

但如果人类决策者主要依赖非正式判断而非明确规则呢？这就是第二种自动化的所在。它利用机器学习来复制人类的非正式判断。一旦自动发现一种能够产生与人类过去决策相同的方案，它便在软件中实现该方案，以取代原本进行决策的人。本章开头提到的那位学生的创意作文被电脑评估的例子正是此类做法：该软件试图复制人类评级员的主观评价。
