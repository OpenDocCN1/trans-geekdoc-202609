
# 复利不公

**复利不公**：也许对歧视的问题在于它可能会加剧既有的不公正 \[[149](#references.xhtml#ref-149)\]。在很多方面，这延续了之前关于控制的论点，但专门针对过去不公正的影响。特别是，这是一个论点，认为人们不能因某些关于自身的事实而被道德责备，尤其是这些事实并非源于他们自己的行为，尤其是当这些事实是因为曾经受到过某些过去不公正的影响。如果没有考虑到某些群体的成员过去可能经历了上述许多问题中的一种，这可能导致决策者感到完全有理由对待他们不同。然而，人们在决策时可能因为一些过去的不公正，包括过去的歧视 \[[150](#references.xhtml#ref-150)\]。

忽视这一事实意味着决策者仅仅因为这些群体之前已经遭受了一些早期伤害，就对它们做出更差的决定。注意，这一反对意见与准确性的顾虑无关；事实上，正如我们在第二章中讨论的那样，我们可能有道德义务在某些情况下，对那些人们无法控制的因素的影响进行打折，即使这意味着做出更不准确的预测。在第二章中，我们在没有特别关注分配结果的情况下考虑了这一原则；在此，我们可以通过指出因某人属于某一特定群体而遭受过去的错误待遇，这可能超出其控制范围，来适应这一原则以说明歧视的错误性。
