
-   [基于不可更改的特征的决策](https://example.org)可能令人担忧，因为它们威胁到人们的自主性。按照定义，任何人都无法改变不可更改的特征（例如出生国家）。由此推论，任何人都无法改变基于不可更改特征所做的决策。在这种情况下，人们被迫接受既定命运，不再是自己生活的主宰。剥夺人们通过改变决策过程而获得不同结果的能力是令人不安的，尤其是当这些决策可能显著影响个人的生活机会和人生轨迹时。这种情况在没有其他方式让决策者在不依赖不可更改特征的前提下，对人做出有效判断时显得尤为问题。换句话说，如果可以开发出同样准确但仍然让决策主体能够调整行为以提升获得有利决策的可能性的决策方案，那么决策者应出于对人们自主性的尊重，有道德义务采用此类方案。

-   回应（recourse）是一个相关但更为宽泛的概念，指人们有多大程度的能力去做出能导致不同决策的改变 \[[93](#references.xhtml#ref-93)\]。虽然任何人都无法改变不可更改的特征，但人们在原则上可更改的特征的变化能力可能有强有弱之分 \[[94](#references.xhtml#ref-94), [95](#references.xhtml#ref-95)\]。一些人可能需要付出远比其他人更多的资源才能从决策过程中获得他们想要的结果。选择作为决策依据的标准本身也是关于决策者在寻求不同决策时所能进行的行动的选择。不同处境的人有不同的能力来成功实现这一点。在某些情况下，人们可能永远没有足够的资源来实现这一目标，从而回到前文讨论的相同情形。例如，一位信用申请人可能有条件去搬到新社区，以使自己在使用位置作为重要决策标准的决策方案中更具吸引力；但另一位申请人可能因财务、文化或其他原因无法做到。

-   机器学习中的回应研究主要集中在确保人们能够获得关于如何通过模型实际可执行的方式获得不同决策的 *解释* \[[96](#references.xhtml#ref-96)\]。鉴于解释模型决策的方式有很多种，本工作的目标是确保所提供的解释引导人们采取可行的行动，而不是暗示实现所需结果的唯一方法是超出其能力的行为。即使在只依赖可更改特征的决策方案中，决策者仍可以通过将对模型决策的解释侧重于人们最容易改变的行动，来进一步保持回应能力。在这个前提下，人们越能够进行能够带来所需结果的改变，决策方案和解释就越好。

-   如前文所述，我们可以把某些决策方案视为不公平，如果它们对人们对其控制之外的特征负责。关于道德责任的基本观念通常基于对促成关注结果的行为的某种理解。例如，我们可能会因为某人撞倒了我们并导致我们珍贵物品破碎而感到愤怒。若发现他们是被其他人推动的，我们倾向于认为他们无辜，并将批评转向推动者。这种推理同样适用于我们对在分配有利资源和机会的决策中依赖某些标准的公平性的看法。除非我们了解 *为什么* 某些结果会发生，否则我们无法判断决策者在依赖能够准确预测该结果的标准时是否在规范上是正当的。我们需要理解关注结果的原因，以便反思该决策主体在其原因下是否对结果负有道德责任。

-   例如，正如 Barbara Kiviat 所探讨的，许多美国州的法律限制汽车保险公司在承保或定价决策时考虑“特殊生活境遇”的程度，包括配偶、子女或父母的死亡 \[[97](#references.xhtml#ref-97)\]。这些法律禁止保险公司考虑一系列人们无法控制的因素——如家人死亡——但这些因素仍可能导致经济困难，从而在即使是轻微事故发生时增加其对保险单提出索赔的可能性。这些禁令反映了这样一种信念：如果人们不是对导致他们显得不配获得更优待遇的行为负责，则不应受到不利决策的影响。换句话说，人们应仅基于他们在道德上可责的因素来评判。完全实现这一原则在实际中不切实际，因为决策者可能使用的大多数属性（如收入）部分但不完全是个人选择的结果。然而，如家人死亡等属性似乎明确位于这一界限的一边。

-   当然，这一切也有另一面。如果人们能够轻易改变用于决策的特征，他们可能会“游戏”决策过程。这里的“游戏”指的是通过修改特征的值来改变决策，而不改变特征原本 intended 所预测的期望结果 \[[98](#references.xhtml#ref-98)\]。熟悉的“教学到考试”是此类游戏的例子。在此情境下，考试成绩是一个特征，用来预测未来表现（如在工作上的表现）。假设考试确实具有预测价值，因为做得好的人通常已经掌握了某些基础知识，而这种掌握提升了工作表现。教学到考试指的是通过准备技巧提高考试成绩，而不相应地提升考试所要反映的底层能力。例如，教师可能通过利用考试只评估非常具体的知识或技能——而非考试声称测量的全部知识或技能——并专注于仅限于这些将被评估的部分来帮助学生应对考试 \[[99](#references.xhtml#ref-99)\]。Jane Bambauer 和 Tal Zarsky 提供了许多关于如何游戏决策系统的例子 \[[100](#references.xhtml#ref-100)\]。
