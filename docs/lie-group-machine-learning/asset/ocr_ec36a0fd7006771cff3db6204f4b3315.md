Therefore, the learning sample set $ P $ is considered to be standardised into a partial order and mapped to a corresponding learning subspace as required, so that it can correspond to the reasonable operation operator set $ F $ ($ F \subset G_{n} $). Then, we use partially ordered set theory to outline this type of learning problem.
