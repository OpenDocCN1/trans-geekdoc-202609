# 7.3.1.1 Two theorems of singular value decomposition

**Theorem 7.1.** *Singular Value Decomposition Theorem of Matrix*

*Suppose that A \in R$^{mxn}$ and rank(A) = r \leq min(m, n). Then, there are always orthogonal matrices U \in R$^{mxn}$ and V \in R$^{nxn}$ that make*

$$A = U \sum_{i=1}^{r} V^{T} = \sum_{i=1}^{r} \sigma_{i} u_{i} v_{i}^{T} \text{.}$$

*Here, the symbol 'T' represents the transpose of the matrix*

$$U = (u_{1}, u_{2}, ..., u_{m}) \in R$^{mxn}$$$

$$v = (v_{1}, v_{2}, ..., v_{n}) \in R$^{nxn}$$$

$$\sum = \left[\begin{array}{cc}\sum_{1} & 0 \\ 0 & 0\end{array}\right] \in R$^{mxn}$$$

*where \sum_{1} = diag(\sigma_{1}, \sigma_{2}, \sigma_{3}, ..., \sigma_{r}) and \sigma_{1} \geq \sigma_{2} \geq \sigma_{3} \geq ... \geq \sigma_{r} > \sigma_{r+1} = \sigma_{r+2} = ... = \sigma_{p} = 0, p = \min(m, n). Here, B is a real number, i.e., the singular value of A. Further, u_{i}, v_{i} (i = 1, 2, ..., r) are the left and right singular vectors belonging to C of matrix A, respectively. All the singular values are arranged in ascending order. The vector (\sigma_{1}, \sigma_{2}, \sigma_{3}, ..., \sigma_{r}) is the singular value vector of the matrix [48].*

*On the one hand, this theorem characterises the decomposition structure of the matrix more clearly. On the other hand, this theorem enables us to deal with the rank of a matrix reasonably. From the formula A = \sum_{i=1}^{r} \sigma_{i} u_{i} v_{i}^{T} = U_{r} \sum_{r} V_{r}^{T}, the matrix is actually obtained through the orthogonal changes that can express the rank and the number of ranks [49]. In the application of face image recognition, the rank of the matrix is a complicated issue because the acquisition of the basic data of the face image is affected by the expression, light, and attitude. However, we can obtain the effective rank of the image matrix by singular value decomposition of the matrix and judgment of the singular value. The following theorem illustrates the relationship between the matrix of some singular values and the original matrix.*

**Theorem 7.2.** *If the matrix A \in R$^{mxn}$, set m \leq n (m, n, r, s are positive integers). The matrix singular value decomposition theorem [53] is*

$$A = UWV^{T} \text{,}$$

$$W = \operatorname{diag}(\sigma_{1}, \sigma_{2}, \sigma_{3}, ..., \sigma_{r}, ..., \sigma_{n}). \text{ Let } W_{s} = \operatorname{diag}(\sigma_{1}, \sigma_{2}, \sigma_{3}, ..., \sigma_{s}) \text{;}$$

$$A_{s} = U \left[\begin{array}{cc}W_{s} & 0 \\ 0 & 0\end{array}\right] V^{T} = \sum_{i=1}^{s} \sigma_{i} u_{i} v_{i}^{T} \text{.}$$

*From the above formula, it can be concluded that rank(A$_{s}$) = rank(W$_{s}$) = s. Then,*

$$\|A - A_{s}\|_{F} = \min \{\|A - B\|_{F} \mid B \in R$^{mxn}_{s} \}$$

*where R$^{mxn}_{s}$ is the linear space of the m \times n-order matrix with rank s.*
