A centre-based data set partition method is given as follows. See Algorithm 13.1.

# **Algorithm 13.1: Centre-based data set partition**

**Input:** Training data set $X_{\text{tr}} = \{\mathbf{x}_{\text{tr}1}, \mathbf{x}_{\text{tr}2}, \ldots, \mathbf{x}_{\text{tr}N} \in R^D\}$, training data set label $Y_{\text{tr}} = \{y_{\text{tr}1}, y_{\text{tr}2}, \ldots, y_{\text{tr}N} \in \mathbb{R}\}$, testing data set $X_{\text{tst}} = \{\mathbf{x}_{\text{tst}1}, \mathbf{x}_{\text{tst}2}, \ldots, \mathbf{x}_{\text{tst}M} \in R^D\}$

**Output:** Partition of the entire data set $S_1, S_2, \ldots, S_n, n$ is the number of data classes

(1) Find the total number of categories of the data set

```
$$T = \text{distinct}\{Y_{\text{tr}}\}
n = |T|$$
```

(2) Initialise $S_i = \varnothing, 1 \le i \le n$. Suppose that $T = \{T_1, T_2, \ldots, T_n\}$.

(3) Partition the training data set

```
$$S_i \leftarrow S_i \cup \mathbf{x}_{\text{tr}j}, y_{\text{tr}j} = T_i, 1 \le j \le N$$
```

(4) Find the data centre points of each category in the training data set

```
$$m_i = \frac{\sum_{S_{ij} \in S_i} S_{ij}}{|S_i|}$$
```

(5) Partition the test data set

```
$$S_i \leftarrow S_i \cup \mathbf{x}_{\text{tst}j}, i = \underset{1 \le i \le n}{\operatorname{arg} \min} d(\boldsymbol{\rho}_i, \mathbf{x}_{\text{tst}j}), 1 \le j \le M$$
```

(6) Output partition set $S_1, S_2, \ldots, S_n$

From Algorithm 13.1, we can see that the algorithm mainly focuses on the training data set and then divides the test data set into the nearest one.

Algorithm 13.1 can be regarded as a simple classification process that divides the whole data set and prepares for the data processing afterwards.

For already partitioned data sets, we assume that a single set $S_i, 1 \le i \le n$ has a single manifold structure. From the above hypothesis, we can use the classical algorithms to reduce the dimension. In this paper, we adopt the LLE algorithm to reduce the dimension. For the entire data set, we will use the LLE algorithm to reduce the dimension of the set $S_1, S_2, \ldots, S_n$ partitioned by Algorithm 13.1. Then, the adjacency graph is constructed according to the data set, and the distance is measured by the Finsler metric.

# **Algorithm 13.2: Dimensionality reduction algorithm for data centers**

**Input:** Sample dimension $d$, Neighborhood parameter $K$, training data set $X_{\text{tr}} = \{\mathbf{x}_{\text{tr}1}, \mathbf{x}_{\text{tr}2}, \ldots, \mathbf{x}_{\text{tr}N} \in R^D\}$, training data set label $Y_{\text{tr}} = \{y_{\text{tr}1}, y_{\text{tr}2}, \ldots, y_{\text{tr}N} \in \mathbb{R}\}$, testing data set $X_{\text{tst}} = \{\mathbf{x}_{\text{tst}1}, \mathbf{x}_{\text{tst}2}, \ldots, \mathbf{x}_{\text{tst}M} \in R^D\}$

**Output:** Low dimensional embedding of the central points

(1) Construct a dataset nearest neighbor graph $M$

```
$$M_{ij} = \begin{cases} d(\mathbf{x}_i, \mathbf{x}_j) & \mathbf{x}_i, \mathbf{x}_j \in X_{\text{tr}}, y_i = y_j \
d_{\text{Finsler}}(\mathbf{x}_i, \mathbf{x}_j) & \text{else} \end{cases}$$
```

$d_{\text{Finsler}}(\mathbf{x}_i, \mathbf{x}_j)$ is calculated by the formula (7.14) in Chapter 7.
