# Algorithm 2.2: Orbit generation depth-first algorithm
Orbit-depth–first

```
**Data structure:** *levelcount*: An integer array that counts for each layer
weight-structure stack
Each $\mathbf{w}$ weight-structure contains:
$\quad$ $\omega=\langle\omega_1, \ldots, \omega_l\rangle$: Weight vector
$\quad$ *level*: Rank of $\omega$
$\quad$ *from*: An integer that labels the parent value
$\quad$ $i$: The next index to be tested
**Input:** $\mathbf{m}=\langle m_1, \ldots, m_I\rangle$: Control weight
$\quad$ $D$: Dynkin matrix
$\quad$ $l$: rank of G
$\quad$ *maxlevel*: Calculate the maximum level of the track
**Output:** Weight vector list $\omega=\langle\omega_1, \ldots, \omega_l\rangle$ and four related integers
$\quad$ The first integer indicates the position of $\omega$ in the list
$\quad$ The second integer is the hierarchy of $\omega$
$\quad$ The third and fourth integers indicate the weight vector and the calculation of $\omega$
**Process:** Make *level*= 0, *levelcount*[*level*]= 1, *i*= 1;
$\quad$ Make *from*= 1; $\quad$// Location of paternity values
$\quad$ Make *to*= 1; $\quad$//Position of the new weight, i.e., the total number of weights computed
$\quad$ Output $\mathbf{m}$; $\quad$// Initial state, i.e., original collection of samples that have not been learned
$\quad$ Put $\mathbf{m}$, *level*, *from*, *i* into the stack;
$\quad$ *while* (The stack is nonempty)
$\quad$ { Out $\omega$, *level*, *from*, *i* of stack;
$\quad$ $\quad$ *while* ($i \leq l$)
$\quad$ $\quad$ $\quad$ *if* ($\omega_i > 0$)
$\quad$ $\quad$ $\quad$ { $\quad$*if* ($v_j \geq 0$ to $i < j \leq l$)
$\quad$ $\quad$ $\quad$ $\quad${ $\quad$//Store $v$ ?
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$*if* ($i = 1 \leq \bar{\jmath}$)
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$Out $\omega$, *level*, *from*, $i + 1$ of stack; // Then return to $\omega$
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$*level* $+ -;$
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$*levelcount*[*level*] $+ -;$
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$ Output $v$, *level*, *from*, $i$, *to*;
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$*if* (*level* $\geq$ *max level*) jump out *while* loop;
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$ Copy $v$ to $\omega$; // Continue with the track of $\omega = v$
$\quad$ $\quad$ $\quad$ $\quad$ $\quad$ Let $i$ be equal to the first element in D$_{\bar{\jmath}}$;
$\quad$ $\quad$ $\quad$ }
$\quad$ $\quad$ $\quad$ $\quad$ Otherwise $i + -;$
$\quad$ $\quad$ }
$\quad$ $\quad$ Otherwise $i + -;$
$\quad$ }
```
