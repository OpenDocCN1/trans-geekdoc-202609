a ∨ b is read as a join b, whereas a ∧ b is read as a meet b.

When the lattice L contains a finite number of elements, it is called a finite lattice.

It is easy to see that ∨ and ∧ are two algebraic operations of L, and for any of the elements a, b, c in L, the following properties are true:

- L1: a ∨ b = b ∨ a, a ∧ b = b ∧ a (Exchange law);
- L2: (a ∨ b) ∨ c = a ∨ (b ∨ c), (a ∧ b) ∧ c = a ∧ (b ∧ c) (Combined law);
- L3: a ∨ a = a, a ∧ a = a (Idempotent law);
- L4: (a ∨ b) ∧ a = a, (a ∧ b) ∨ a = a (Absorption law).

### 2.2.1 LML subspace orbit generation lattice

The formation of the orbit can be considered in two directions: (1) from the given set of samples gradually 'to' the objective function to generate the orbit; (2) from the objective function back to the sample set can also generate the desired orbit. It is proved that the partial order of the subspace can be found by the relation of inclusion and anti-inclusion.

Let the sample data be mapped to the new data set $\mathbb{F}_q$, i.e., a finite field of $q$ elements, where $q$ is a prime power. Let $\mathbb{F}_q^n$ be the $n$-dimensional row vector space on $\mathbb{F}_q$. In the set $\mathrm{L}\left(\mathbb{F}_q^n\right)$ of all subspaces of $\mathbb{F}_q^n$, the partial order $\supseteq$ of the subspace is found by the inclusion relation, referred to as finding the partial order $\supseteq$ of $\mathrm{L}\left(\mathbb{F}_q^n\right)$ by the inclusion relation. Then, $\mathrm{L}\left(\mathbb{F}_q^n\right)$ makes a partially ordered set for the partial order $\supseteq$ sought, and it is denoted by $\mathrm{L}_O\left(\mathbb{F}_q^n\right)$. In the partially ordered set, there are subspaces $X$ and $Y$ for $\mathbb{F}_q^n$:

$$X \vee Y = \cap \left\{ Z \in \mathrm{L}\left(\mathbb{F}_q^n\right) \mid X \cup Y \subset Z \right\}, X \wedge Y = X \cap Y.\tag{1}$$

Hence, $\mathrm{L}_O\left(\mathbb{F}_q^n\right)$ is a lattice, 0 is its minimal element, the 1-dimensional subspace is its atom, and the dimension of the subspace is its rank function.

In $\mathrm{L}\left(\mathbb{F}_q^n\right)$, if the inverse order is used to find the partial order $\supseteq$ of the subspace, $\mathrm{L}\left(\mathbb{F}_q^n\right)$ is still the partially ordered set, denoted as $\mathrm{L}_R\left(\mathbb{F}_q^n\right)$. Since sup $\{X, Y\}$ and inf $\{X, Y\}$ in $\mathrm{L}_R\left(\mathbb{F}_q^n\right)$ are exactly the same as inf $\{X, Y\}$ and sup $\{X, Y\}$ in the partially ordered set $\mathrm{L}_O\left(\mathbb{F}_q^n\right)$, hence, in $\mathrm{L}_R\left(\mathbb{F}_q^n\right)$, we have

$$X \vee Y = X \cap Y, X \wedge Y = \cap \left\{ Z \in \mathrm{L}_R\left(\mathbb{F}_q^n\right) \mid X \cup Y \subset Z \right\}\tag{2}$$

Thus, $\mathrm{L}_R\left(\mathbb{F}_q^n\right)$ is also a lattice.

So there is:

**Proposition 2.9. *Mapping***

$$\phi: \mathrm{L}_O\left(\mathbb{F}_q^n\right) \rightarrow \mathrm{L}_R\left(\mathbb{F}_q^n\right), \mathcal{P} \rightarrow \mathcal{P}^{\perp}\tag{3}$$

*is an isomorphic mapping. The lattices* $\mathrm{L}_O\left(\mathbb{F}_q^n\right)$ *and* $\mathrm{L}_R\left(\mathbb{F}_q^n\right)$ *are lattice isomorphic.*

*The orbit from the sample data set 'towards' the target result is formed in isomorphism with the target result, i.e., it reverses back to the trajectory of the sample set.*

*From the sample data set 'to' the target results of the orbit and the target results back to the sample set of the orbital isomorphism.*
