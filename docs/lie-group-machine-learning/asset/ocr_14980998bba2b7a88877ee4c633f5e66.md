the element $g(0, \dots, a^{\mu}, \dots, 0)$, let $a^{\mu} = Na^{\mu}$, where $N$ is a large positive integer and $a^{\mu}$ is a small one. Hence,

```
$$g(0, \dots, a^{\mu}, \dots, 0) = (g(0, \dots, a^{\mu}, \dots, 0))^{N} = (e + ia^{\mu}X_{\mu})^{N} \text{(do not sum }\mu\text{)} = \left(e + i\frac{a^{\mu}}{N}X_{\mu}\right)^{N}$$
```

Let $a^{\mu}\rightarrow 0, N\rightarrow 0$, and use the algebraic identity

```
$$\lim_{N\to\infty}\left(1+\frac{g}{N}\right)^{N} = \exp g.$$
```

Obtain

```
$$g(0, \dots, a^{\mu}, \dots, 0) = \exp(ia^{\mu}X_{\mu}) \text{(do not sum }\mu\text{)}$$
```

which is an accurate result.

For the general element of parameter Lie group $G$, use the above results. Then, we can get

```
$$g(a^{1}, \dots, a^{r}) = \exp(ia^{\mu}X_{\mu}).$$
```

The infinitely small element that is near the unit element of $G$, i.e., the infinitely small transformation, will constitute a transform group. Hence, let the infinitely small element be

```
$$g_{\lambda} = g(0, \dots, a^{\lambda}, \dots, 0) = e + ia^{\lambda}X_{\lambda} \text{(do not sum }\lambda\text{)}$$ $$g_{\nu} = g(0, \dots, a^{\nu}, \dots, 0) = e + ia^{\nu}X_{\nu} \text{(do not sum }\nu\text{)}.$$
```

After calculating the first-order approximate of $a^{\mu}(\mu = 1,\dots, r)$, we have

```
$$g_{\lambda}g_{\nu} = g_{\nu}g_{\lambda} = e + i\left(a^{\lambda}X_{\lambda} + a^{\nu}X_{\nu}\right) \text{(do not sum }\lambda,\nu\text{)}.$$
```

Here, (8.34) still gives the infinitely small element of $G$.

**Theorem 8.1.** *In the parameter space ($r$ dimension) of Lie group $G$, the group element that is in the unit element neighbourhood can be generated by the following infinitely small generated meta (where $a_{\rho}(\rho = 1,\dots, r)$ is a group element):*

```
$$X^{(\beta)} = V_{\beta\rho}(a)\frac{\partial}{\partial a_{\rho}} = \left(\frac{\partial\phi_{\rho}(a, b)}{\partial b_{\beta}}\right)_{b=0}\frac{\partial}{\partial a_{\rho}}$$ $$(a = (a_{1}, a_{2}, \dots, a_{r}))$$
```

*where $\phi_{i}(a, a)\equiv a_{i} + da_{i}$ is the transformation function of group parameter space (as shown in Fig 8.8), and the parameter space is an $r$-dimensional linear space. Group element $A(a)$ is just like $F(x)$, which is a function of $n$-dimensional linear space.*
