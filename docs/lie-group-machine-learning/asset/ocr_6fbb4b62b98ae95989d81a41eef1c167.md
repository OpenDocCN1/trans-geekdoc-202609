**Definition 1.8.** Continuous mapping: Suppose that \((M_{1}, \tau_{1})\) and \((M_{2}, \tau_{2})\) are topological spaces, \(f: M_{1} \to M_{2}\) is a mapping, \(x_{0} \in M_{1}\), and \(y_{0}=f(x_{0}) \in M2\). If for any open neighbourhood \(V\) of \(y_{0}=f(x_{0})\), there is an open neighbourhood \(U\) of \(x_{0}\) such that \(f(U)=\{f(x)|x \in U\} \subset V\), then \(f\) is continuous in point \(x_{0}\). If \(f\) is continuous in every point of \(M_{1}\), then \(f\) is a continuous mapping.

Note that according to the definition of the continuous property of topology, \(f\) is continuous \(\Leftrightarrow\) for any open set \(V\) of \((M_{2}, \tau_{2})\), \(f^{-1}(v) = \{x \in M_{1}|f(x) \in V\}\) is an open set of \((M_{1}, \tau_{1})\) \(\Leftrightarrow\) for any closed set \(F\) of \((M_{2}, \tau_{2})\), and \(f^{-1}(F) = \{x \in M_{1}|f(x) \in F\}\) is a closed set of \((M_{1}, \tau_{1})\).

**Definition 1.9.** If \(f: M_{1} \to M_{2}\) is a one-to-one correspondence, and \(f\) and \(f^{-1}\) are continuous mappings, then \(f\) is a homeomorphism (topology) mapping.

**Definition 1.10.** Suppose that \(M\) is a \(T_{2}\) (Hausdorff) space. If for any \(p \in M\), there exists an open neighbourhood \(U\) of \(p\) in \(M\) and homeomorphism \(\varphi: u \to \varphi(u)\), where \(\varphi(u) \subset \\mathbf{R}^{n}\) is an open set (partial Euclidean), then \(M\) is a \(n\)-dimensional topological manifold or \(C^{o}\) manifold.

\((U, \varphi)\) is a partial coordinate system (coordinate card, picture), \(U\) is a partial coordinate neighbourhood, \(\varphi\) is a partial coordinate mapping, and \(x^{i}(p) = (\varphi(p))^{i} (1 \leq i \leq n)\), is a partial coordinate of \(p \in U\), simplified as \(\{x^{i}\}\), which is sometimes called a partial coordinate system. A topological manifold is an atlas consisting of pictures from all \(D\) of the partial coordinate system. If \(p \in U\), then \((U, \varphi)\) is a partial coordinate system of \(p\).
