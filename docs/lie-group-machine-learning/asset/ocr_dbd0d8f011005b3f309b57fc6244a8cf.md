Using the above theoretical analysis, the semi-supervised learning algorithm based on linear Lie group is described in Algorithm 8.4:

# Algorithm 8.4: SSIA-GL(n) algorithm flow

```
//algorithm function: Semi-supervised learning with linear Lie group method.//
Input: Sample set X = (x₁, x₂, ..., xₗ, xₗ₊₁, ..., xₗ₊ₖ ∈ Rⁿ), where x₁, x₂, ..., xₗ are labelled data, and there exists a set L = {(x₁,y₁), (x₂,y₂), ..., (xₗ,yₗ)}, xₗ₊₁, xₗ₊₂, ..., xₗ₊ₖ are unlabelled data (l << k).
Output: The label y of data x
```

Steps:

+   1. Step 1: According to the input sample set X = (x₁, x₂, ..., xₗ, xₗ₊₁, ..., xₗ₊ₖ ∈ Rⁿ), represented by a matrix, find the automorphism of the GL(n) linear Lie group of the corresponding learning system using labelled data fully, representing the object that is to be studied as a linear Lie group, requiring the learning object to satisfy the linear Lie group structure.

+   2. Step 2: According to the algebra structure of Lie group, the group method is used for labelling. Based on the marked data as the base point, find its operator generator (or the base vector of the corresponding algebra) through its infinitesimal right shift

```
$$X_{\mu}(x)=\psi_{\mu}^{x}(x) \frac{\partial}{\partial x^{v}}=\left.\frac{\partial \delta^{V}(x, y)}{\partial y^{v}}\right|_{y=\epsilon} \frac{\partial}{\partial x^{v}} \ ;$$
```

+   3. Determine other unlabelled data according to the group operation rules. If the unmarked data can be used to generate the meta-representation of the operator, it is marked by the category.

+   4. Step 3: According to the geometric structure of the linear Lie group, the analytic manifold is used for marking.

+   5. A constant inner product under the action of the automorphism is taken in the Lie algebra g of X:

```
$$<A d(g) x_{1}, A d(g) x_{2}>=<x_{1}, x_{2}>_{,} x_{1}, x_{2} \in g, g \in G$$
```

+   6. Take a set of standard orthogonal bases {Xi; 1<= i <= l + k), < Xi, Xj > = δij. The left shift expands {Xi; 1 <= i <= l + k} into the left constant vector field of G, which is recorded as Xi.
   Thus, the Riemann space structure is established:
   In the Riemann space structure, the unmarked data is marked in each TxG space, with the marked data as the base point and the left (or right) translation linear transformation dLi (or drx) of X. The tangent space TxG is mapped to the marked sample point xi.
   Step 4: Check whether all the data is marked. If not, then return to Step 2 and repeat; otherwise, go to the next step of Lie group machine learning, which is to classify the data. Complete data reduction and structural learning.
