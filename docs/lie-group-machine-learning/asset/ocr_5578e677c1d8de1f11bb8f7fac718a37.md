However, to guarantee the global optimum of the manifold, it is more favourable for face manifold learning to learn the whole structure of the eyes, nose, mouth, and so on. Based on this global idea, a manifold learning method called Laplacian eigenvalue estimation (LPE) is proposed in this section.

Suppose that the sample set $X = [x_1, x_2, \ldots, x_n]$ belongs to class $r$, and the LPE algorithm maps each data point to different strip plane curves. The algorithm is inspired by the LE algorithm, and its solution space is constrained by the similarity matrix and subspace. The result of each mapping is a column of the matrix $Y \in R^{mxr}$, and the $ith$ row of the matrix is the embedded coordinate of the $ith$ point.
