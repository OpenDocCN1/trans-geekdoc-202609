the sum of the Euclidean distances from each point in $\{x_i\}_{i=1}^n$, i.e., $\mu$ can be expressed as

```
$$\mu = \operatorname*{arg\,min}_{x \in \mathbb{R}^{d}} \sum_{i=1}^{n} \|x - x_i\|^{2}\ . \tag{9.16}$$
```

Since a $d$-dimensional manifold $M^{d}$ is usually not a vector space, the actual distance between the two points on the manifold cannot be represented by the Euclidean distance. Hence, (9.16) cannot be directly applied to the manifold. The result is shown in Fig. 9.5. However, the $d$-dimensional manifold $M^{d}$ is locally homologous to $R^{d}$, and it is possible to find a homeomorphism mapping $\Phi : M^{d} \rightarrow R^{d}$ in the local domain of $M^{d}$. Embedding the local part of $M^{d}$ into $R^{d}$, such that $\mu_{\Phi} : \mu_{\Phi} = \operatorname*{arg\,min}_{x \in M^{d}} \sum_{i=1}^{n} \|\Phi(x) - \Phi(x_i)\|^{2}$ can be calculated using (9.16) in $R^{d}$. At the same time, we need to define a mapping $\pi : R^{d} \rightarrow M^{d} : \mu = \pi(\mu_{\Phi})$ so that $\mu_{\Phi}$ can be mapped back to $M^{d}$. By omitting $\mu_{\Phi}$, we can get

```
$$\mu = \pi\left(\operatorname*{arg\,min}_{x \in M^{d}} \sum_{i=1}^{n} \|\Phi(x) - \Phi(x_i)\|^{2}\right)\ . \tag{9.17}$$
```

In practice, it is difficult to find the appropriate $\Phi$ and $\pi$ for $M^{d}$, and $M^{d}$ is not necessarily embedded in $R^{d}$ by $\Phi$. A more reasonable approach is to use the Riemann distance on $M^{d}$ instead of the $\Phi$-function in (9.17) to calculate the distance between any $x_i, x_j \in M^{d}$ directly on $M^{d}$, rather than in Euclidean space.

```
$$\mu = \bar{x} = \operatorname*{arg\,min}_{x \in M^{d}} \sum_{i=1}^{n} d(x, x_i)^{2}\ . \tag{9.18}$$
```

In the above formula, $d(., .)$ represents the geodesic distance between the two points in the parentheses. The shortest distance between any two elements $X_1$ and $X_2$ is defined as $d(X_1, X_2) = \|\log\left(X_1^{-1}X_2\right)\|$. By substituting it into (9.18), we can get

```
$$\mu = \operatorname*{arg\,min}_{x \in G} \sum_{i=1}^{n} \|\log\left(x^{-1}x_i\right)\|^{2}\ . \tag{9.19}$$
```

Using the first-order BCH formula to approximate the right-hand side $\|\|$

```
$$\log\left(x^{-1}x_i\right) = -\log(x) + \log(x_i)\ . \tag{9.20}$$
```

To obtain a more accurate result, we can find the former n-th order approximation, but according to the BCH formula, the calculation of the latter approximation becomes very large, and the contribution to the overall approximation is small. Hence, the first-order approximation is used to replace $\log\left(x^{-1}x_i\right)$, and the internal mean formula can be simplified as:

```
$$\begin{aligned}\tilde{\mu} &= \operatorname*{arg\,min}_{x \in G} \sum_{i=1}^{n} \|-\log(x) + \log(x_i)\|^{2} \\ &= \operatorname*{arg\,min}_{x \in G} \sum_{i=1}^{n} \|-m + m_i\|^{2}\ . \tag{9.21}\end{aligned}$$
```
