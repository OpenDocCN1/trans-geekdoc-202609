# 8.3.1 The general linear group

**Definition 8.8.** Let $A \in \mathrm{GL}(n)$. Then,

```
$$A = \begin{pmatrix} g_{1}^{1} & \dots & g_{1}^{n} \\ \dots & \dots & \dots \\ g_{1}^{1} & \dots & g_{1}^{n} \end{pmatrix} \text{ and } |A| \neq 0$$
```

Hence, $\mathrm{GL}(n)$, which represents the multiplication of matrices, constitutes a group, and the unit matrix is the unit element of the group. Otherwise, $\mathrm{GL}(n)$ is an open subset of $R^{n^{2}}$; hence, $\mathrm{GL}(n)$ has smooth structure as an open sub-manifold of $R^{n^{2}}$. Assume that $A = (a_{i}^{j})$, $B = (b_{i}^{j}) \in \mathrm{GL}(n)$, where $a_{i}^{j}$ is the $j$ th row and $i$ th column element of $A$, and the $j$ th row and $i$ th column element of $B$ is

```
```latex
(A \cdot B)_{i}^{j} = \sum_{k=1}^{n} a_{k}^{i} b_{i}^{k} \, .
```
```

In addition,

```
```latex
(A^{-1})_{i}^{j} = \frac{\overline{A_{i}^{j}}}{\det A} \, ,
```
```

where $\overline{A_{i}^{j}}$ represents the algebra of the element $a_{i}^{j}$ of the determinant det $A$. Thus, the inverse matrix $A^{-1}$ is the rational formula of the element of the matrix $A$. Thus, the multiplication and the inverse operation of the group $\mathrm{GL}(n)$ are both smooth. Hence, $\mathrm{GL}(n)$ is an $n^{2}$-dimensional Lie group [42].
