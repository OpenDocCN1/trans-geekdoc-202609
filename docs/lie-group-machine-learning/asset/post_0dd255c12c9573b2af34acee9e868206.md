### 15.1.3 Basic concepts of category theory

The study of many fields of modern mathematics can be generalised to the study of specific mathematical objects and mapping between these objects. For example, mapping between sets is the main object of set theory research. Group (or ring) and group homomorphism (or ring homomorphism) constitute the main research object of group theory (or ring theory). The continuous mapping between topological spaces constitutes the main research object of topology, and so on. The category concept is the generalisation and abstraction of these particular mathematical objects and mappings.

**Definition 15.1. Category** $\mathbb{C}$:
- (1) Object ob$\mathbb{C}$;
- (2) Any pair of objects $A, B$ corresponds to a set $\mathbb{C}(A, B)$. Its element is called a morphism, and it satisfies the condition that if $A \neq A'$ or $B \neq B'$, $\mathbb{C}(A, B)$ and $\mathbb{C}(A', B')$ have no intersection.

A morphism has the following properties:

- (a) Composition law: If $A, B, C \in \text{ob}\mathbb{C}$, $f \in \mathbb{C}(A, B)$, $g \in \mathbb{C}(B, C)$, then there is only one $gf \in \mathbb{C}(A, C)$, called the composite $f$ and $g$;
- (b) Associativity: If $A, B, C, D \in \text{ob}\mathbb{C}$, $f \in \mathbb{C}(A, B)$, $g \in \mathbb{C}(B, C)$, $h \in \mathbb{C}(C, D)$, then $h(gf) = (hg)f$;
- (c) Identity morphism: For each object $A$, there is a morphism $1_{A} \in \mathbb{C}(A, A)$ that satisfies the following condition: any $f \in \mathbb{C}(A, B)$ and $g \in \mathbb{C}(C, A)$ have $f1_{A} = f$ and $1_{A}g = g$.

**Singlet morphism:** Let $\mathbb{C}$ be a category and $f: A \rightarrow B$ be a morphism in $\mathbb{C}$. If any pair of parallel morphisms $g, h: C \rightarrow A$ in $\mathbb{C}$ satisfies $fg = fh$, then $g = h$, where $f$ denotes a monomorphism.

**Full morphism:** Let $\mathbb{C}$ be a category and $f: A \rightarrow B$ be a morphism in $\mathbb{C}$. If and only if any pair of parallel morphisms $g, h: B \rightarrow C$ in $\mathbb{C}$ satisfies $gf = hf$, then $g = h$, where $f$ denotes an epimorphism.

**Definition 15.2.** Let $\mathcal{C}$ and $\mathcal{D}$ be categories. A functor $F: C \rightarrow D$ consists of two mappings,
$$
\begin{aligned}
& \mathrm{ob}\mathcal{C} \rightarrow \mathrm{ob}\mathcal{D}: A \rightarrow F(A), \\
& \operatorname{Mor}\mathcal{C} \rightarrow \operatorname{Mor}\mathcal{D}: f \rightarrow F(f),
\end{aligned}
$$
which satisfy $\operatorname{dom}(F(f)) = F(\operatorname{dom}(f))$, $\operatorname{cod}(F(f)) = F(\operatorname{cod}(f))$, $F(1_A) = 1_{F(A)}$, and if $\operatorname{dom}(g) = \operatorname{cod}(f)$, then $F(gf) = F(g)F(f)$.

Any category $\mathcal{C}$ has a unit functor $1_C: C \rightarrow C$ to itself, satisfying the condition that the correspondence between the object and the morphism is constant.

Group category Gp (topological space category Top, etc.) has a forgetful functor $G$ to set category Set, and $G$ satisfies the condition that each group (topology, space, etc.) corresponds to the set where it is located, and each group of homomorphisms (continuous mapping, etc.) corresponds to itself.

In general, we say that a functor $\mathcal{C}^{\mathrm{op}} \rightarrow \mathcal{D}$ is a contravariant functor from $\mathcal{C}$ to $\mathcal{D}$.

**Definition 15.3.** Let $\mathcal{C}$ and $\mathcal{D}$ be a category, where $F: \mathcal{C} \rightarrow \mathcal{D}$ and $G: \mathcal{C} \rightarrow \mathcal{D}$ be functors. A natural transformation $\alpha: F \rightarrow G$ is a mapping $\mathrm{ob}\mathcal{C} \rightarrow \mathrm{Mor}\mathcal{D}$:

$$
A \mapsto (\alpha_A: F(A) \rightarrow G(A)), A \in \mathrm{ob}\mathcal{C}
$$

Natural transformation $\alpha: F \rightarrow G$ satisfies the condition that for any $A \in \mathrm{ob}\mathcal{C}$, $\alpha_A: F(A) \rightarrow G(A)$ is an isomorphism. Then, we say that $\alpha$ is a natural isomorphism.

In some studies, we often encounter such structures. In a small sub-category given a specific category (can also be considered as a small category to a functor of the category), the exchangeable mapping formed by an object and the object to a state of each object in the category of mapping form family have the property of ‘universal nature’. For example, given a topological space $\{X_i | i \in I\}$, the mapping family $\{\pi_i: \prod X_i \rightarrow X_i | i \in I\}$ between product space $\prod X_i$ to each factor space has the property of ‘universal nature’. For any topological space $X$ and continuous mapping family $\{f_i: X \rightarrow X_i | i \in I\}$, there exists a unique continuous mapping $f = \langle f_i \rangle: X \rightarrow \prod X_i$, where each $f_i$ can be broken down into $f_i = \pi_i f$ with $f$. Such properties can be abstracted into purely categorical properties, i.e., categorical limits and residual limits.
