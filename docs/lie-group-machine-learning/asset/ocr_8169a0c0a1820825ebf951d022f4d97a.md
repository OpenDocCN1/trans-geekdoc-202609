$E_{i}^{j}(i, j \leqslant n)$ in $M(n, n)$ is obtained, where $E_{i}^{j}(i, j \leqslant n)$ represents the $n \times n$ matrix whose $i$ th row and $j$ th column element is 1, and other elements are 0. Hence, any $n \times n$ matrix can be represented as

```
$X=\sum_{i, j=1}^{n} X_{j}^{i} E_{i}^{j}$

(8.6)
```

where $X_{j}^{i}$ represents the element in the $i$ th row and $j$ th column of matrix $X$. Further, according to (4.6), the coordinate of the point $X \in M(n, n) \cong R^{n^{2}}$ under the standard frame $(O ; E_{i}^{j})$ is $X_{j}^{i}$, i.e., the coordinate system in $M(n, n)$ is given. The natural standard frame produced under the coordinate system is $\left\{X, \partial / \partial X_{j}^{i}\right\}_{X}$, and

```
$\left.\frac{\partial}{\partial X_{j}^{i}}\right|_{X}=E_{i}^{j}$.

(8.7)
```

Because $\mathrm{GL}(n)$ is the open subset of $M(n, n)$, the above coordinate system and natural standard frame of $M(n, n) \cong R^{n^{2}}$ can also fit $\mathrm{GL}(n)$. Let the multiplication in $\mathrm{GL}(n)$ be denoted by $\varphi$. Then, the expression of $\varphi$ in the above coordinate system is

```
$\left(\varphi(A, B)\right)_{j}^{i}=(A \cdot B)_{j}^{i}=\sum_{k=1}^{n} A_{k}^{i} B_{j}^{k}$.

(8.8)
```

We now require the left invariant vector field produced by the leftward movement of the tangent vector $\vec{E}^{i}=\left.\partial / \partial X_{j}^{i}\right|_{I}$ at the unit element $I$ on the Lie group $\mathrm{GL}(n)$, denoted by $\vec{E}_{i}^{\perp}$. Then,

```
$\left.\vec{E}_{i}^{j}\right|_{A}=(L_{A})_{* I}\left(\left.\frac{\partial}{\partial X_{j}^{i}}\right|_{I}\right)$

$=\sum_{k, l=1}^{n}\left.\frac{\partial(\varphi(A, X))_{j}^{k}}{\partial X_{l}^{i}}\right|_{X=I} \cdot\left.\frac{\partial}{\partial X_{k}^{l}}\right|_{A}$

$=\sum_{k, l, h=1}^{n} A_{0}^{k} g^{h}\left.\delta_{l}^{j} \frac{\partial}{\partial X_{k}^{l}}\right|_{A}$

$=\sum_{k=1}^{n} A_{i}^{k}\left.\frac{\partial}{\partial X_{j}^{k}}\right|_{A}=\left(\sum_{k=1}^{n} X_{i}^{k}\left.\frac{\partial}{\partial X_{j}^{k}}\right|_{X}\right)_{X=A} .$

(8.9)
```

We directly calculate

```
$\left[\vec{E}_{i}^{j}, \vec{E}_{k}^{l}\right]$

$=\left[\sum_{p=1}^{n} X_{j}^{p}\left.\frac{\partial}{\partial X_{i}^{p}}\right|_{A}, \sum_{q=1}^{n} X_{k}^{q}\left.\frac{\partial}{\partial X_{l}^{q}}\right|_{A}\right]$

$=\sum_{p=1}^{n}\left(\delta_{k}^{l} X_{j}^{p}\left.\frac{\partial}{\partial X_{i}^{p}}\right|_{A}-\delta_{i}^{l} X_{k}^{p}\left.\frac{\partial}{\partial X_{j}^{p}}\right|_{A}\right)$

$=\delta_{k}^{l} \vec{E}_{i}^{\perp}-\delta_{i}^{l} \vec{E}_{k}^{\perp}$.

(8.10)
```
