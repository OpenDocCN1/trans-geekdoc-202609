
**Definition 2.9.** Let the LML sample data set *P* be a nonempty set and $\gtrapprox$ be a binary relationship defined on *P*. If the following three axioms P01–P03 are established, *P* is called a partially ordered set and $\gtrapprox$ is called a partial order on *P* (order for short).

- P01: For any *x* $\in$ *P*, there is no *x* $\gtrapprox$ *x*;
- P02: For any *x*, *y* $\in$ *P*, if *x* $\gtrapprox$ *y* and *y* $\gtrapprox$ *x*, then *x* = *y*;
- P03: For any *x*, *y*, *z* $\in$ *P*, if *x* $\gtrapprox$ *y* and *y* $\gtrapprox$ *z*, then *x* $\gtrapprox$ *z*.

In addition to the above three axioms, if the following axiom P04 is also established, then *P* is called a serially ordered set or chain and $\gtrapprox$ is called the total order on *P*.

- P04: For any *x*, *y* $\in$ *P*, at least one of *x* $\gtrapprox$ *y* and *y* $\gtrapprox$ *x* holds.

Let *T* be a subset of the partially ordered set *P*, *m* $\in$ *T*, and if there is no *x* $\in$ *T* such that *m* $\prec$ *x* (*m* $\succ$ *x*), where *m* is called the maximal element (or minimal element) of *T*. If for all *x* $\in$ *T*, *m* $\gtrapprox$ *x* (*m* $\preccurlyeq$ *x*), then *m* is called the largest element (or smallest element) of *T*. If *u* $\in$ *P*, for all *x* $\in$ *T*, i.e., *u* $\gtrapprox$ *x* (or *u* $\preccurlyeq$ *x*), *u* is called an upper bound (or lower bound) of *T*. Note that the upper bound (or lower bound) of *T* does not necessarily belong to *T*. If *u* is the upper bound of *T*, and for any upper element of *T* *v* $\gtrapprox$ *u*, then *u* is called the supremum of *T*, and the infimum of *T* can be defined. According to PO2, if *T* has an upper bound (or lower bound), it must be unique and is denoted as sup *T* (or inf *T*). Similarly, the supremum (or infimum) of *T* does not necessarily belong to *T*.

If *x*, *y* $\in$ *P* and *x* $\gtrapprox$ *y*, where [*x*, *y*] = {*z* $\in$ *P* | *x* $\gtrapprox$ *z* $\gtrapprox$ *y*}, then [*x*, *y*] is called an interval with *x* and *y* as endpoints, *x* $\prec$ *y*.

If *x*, *y* $\in$ *P*, *x* $\prec$ *y*, and there is no *z* $\in$ *P* such that *x* $\prec$ *z* $\prec$ *y*, we say that *y* is the coverage of *x*, denoted as *x* $\prec\prec$ *y*.

**Definition 2.11.** The partial order $P$ is said to satisfy the Jordan–Dedekind condition, referred to as the $JD$ condition, if for any $a$, $b \in P$, and $a < b$, all great chains with $a$ as the starting point and $b$ as the ending point have the same limited length.
