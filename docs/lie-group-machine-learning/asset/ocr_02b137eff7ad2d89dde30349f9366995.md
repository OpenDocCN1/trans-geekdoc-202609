$A_{1} \odot A_{2}=\exp \left(\log _{2} A_{1}+\log _{2} A_{2}\right) .$

(9.3)

Then we can form a group $(Sy m^{\triangle}, \odot)$, which is a Lie group, where $\exp$ and $\log _{2}$ are the exponential and logarithmic operations of the matrix. In Lie group theory, we call these the exponential mapping and logarithm mapping, respectively, which will be described later.

In the above, we introduce several common matrix groups, where $O(n), \operatorname{SO}(n)$, $U(n)$, and SU(n) are all Lie groups. $Sy m^{+}(n)$ can also be formed as a Lie group after adding a new matrix operation. The detailed proof can be found in [25] and [43].

# 9.1.3 The learning algorithm of the matrix group

The previous section introduced the basic concepts of matrix groups and the knowledge of matrix group spatial measures. On this basis, this section constructs a KNN algorithm and K-Means an algorithm based on a matrix vector space.

$M_{m n}(K)$ is a K vector space with matrix addition and scalar multiplication. A metric operator is added to the vector space: $\rho(A, B)$, where $A, B \in M_{m n}(K)$, which satisfies the five properties of the norm mapping. The specific expression of the norm depends on the specific situation and the specific matrix group. In Section 9.1.3, we present a case analysis.

Once the space formed by the matrix group has measurement, i.e., a form of distance, then for a specific problem, as long as the measurement is reasonable, we can use this measure to solve many problems. We extend the most basic classification and clustering algorithm in machine learning problems to the matrix group space, and the distance between the two matrices is represented by the correlation measure.

```
Algorithm 9.1: KNN based on matrix group
Input: Known $c$ categories of $n$ matrix samples $\left\{x_{1}, x_{2}, \ldots, x_{n}\right\}$, $m$ unknown class samples $\left\{y_{1}, y_{2}, \ldots, y_{m}\right\}$, number of neighbours $k$.
Output: The specific category of each sample in the unknown sample set $\left\{y_{1}, y_{2}, \ldots, y_{m}\right\}$.
(1) Take a sample $y_{i}$ from a sample of $m$ unknown categories by a certain method.
(2) Calculate the distance $\rho\left(y_{i}, x_{j}\right)$ between $y_{i}$ and $\left\{x_{1}, x_{2}, \ldots, x_{n}\right\}$ in all samples.
(3) According to step (2), to get the ascending order, take the first $k$ smallest metrics corresponding to $\left\{x_{1}, x_{2}, \ldots, x_{k}\right\}$.
(4) Take the category with the largest number of samples from $\left\{x_{1}, x_{2}, \ldots, x_{k}\right\}$, assigning the value to the sample $y_{i}$.
(5) Repeat the above steps until the sample in each unknown category sample set $\left\{y_{1}, y_{2}, \ldots, y_{m}\right\}$ is processed.
```
