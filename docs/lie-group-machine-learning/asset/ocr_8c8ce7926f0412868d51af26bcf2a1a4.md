Intuitively, the ordering of a tensor [21, 21] means the energy of the kernel tensor. Based on this point, we can use A' to denote approximate tensor A (Figure 10.7):

```
A = S ×₁ U^(1) ×₂ U^(2) … ×_N U^(N) = A' = S' ×₁ U^(1) ×₂ U^(2) … ×_N U^(N) (10.21)
```

Here A, S ∈ R^{I₁×…×I_N}, A', S' ∈ R^{K₁×…×K_N}, U^(n) ∈ R^{I_n×K_n}. Based on the decomposition method of HOSVD, we can find the implementation form of f.

We know that A_i ∈ R^{I_1×…×I_N}, S_i ∈ R^{K_1×…×K_N} (i = 1 …, m), which belongs to two tensor fields Φ and Φ':

```
S_i = f(A_i) = A_i × U^(1) × U^(2) … U^(N) . (10.22)
```

Here, we have U^(n) ∈ R^{I_n×K_n} and U^(n)(U^(n))^T = I_N, U^(n) is the transformation matrix of f. Because K_n < I_n, n = 1 …, N, Φ' is a simple form of Φ, we can use f(Φ') to represent Φ, i.e.,

```
Φ ≈ f(Φ') . (10.23)
```

Specifically, we have to complete the optimisation problem as:

```
min_U^(1),...,U^(N)
S_1,...,S_N Σ_i ||A_i - S_i ×_1 (U^(1))^T ×_2 (U^(2))^T … ×_N (U^(N))^T||_F^2 . (10.24)
```

Then, we can deduce that the minimisation problem is equivalent to the following maximisation problem [4–9, 24].

```
max_U^(1),...,U^(N) Σ_i ||A_i ×_1 U^(1) … ×_N U^(N)||_F^2 . (10.25)
```

Then, we have:

```
Y_i^k = A_i ×_1 U^(1) … ×_{k-1} U^(k-1) ×_{k+1} U^(k+1) … ×_N U^(N) . (10.26)
```
