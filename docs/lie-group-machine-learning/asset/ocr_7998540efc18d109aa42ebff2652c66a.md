We can get some properties of equal spectrum manifolds from the asymptotic expansion theorem of Minakshisundaram-Pfeijer in differential geometry. Some geometric and topological properties are given by equal spectra.

**Theorem 12.1.** [22] Suppose that $spec(M, g) = spec(\tilde{M}, g)$. Then, $\dim M = \dim \tilde{M}$, $volM = vol\tilde{M}.$

*Proof.* Since $spec(M, g) = spec(\tilde{M}, g)$, then $\lambda_i = \tilde{\lambda}_i$, $i = 0, 1, 2, \dots$,
i.e.,

$(4\pi t)^{\frac{n}{2}} \sum_{i=0}^{+\infty} a_i t^i \sim \sum_{i=0}^{+\infty} e^{-\lambda_i t} = \sum_{i=0}^{+\infty} e^{-\tilde{\lambda}_i t} \sim (4\pi t)^{\frac{n}{2}} \sum_{i=0}^{+\infty} \tilde{a}_i t^i .$

From this, we can see that

$$\begin{aligned} & \dim M = n = \tilde{n} = \dim \tilde{M} \ , \\ & volM = a_0 = \tilde{a}_0 = vol\tilde{M} \ . \end{aligned}$$

In other words, if the spectra of the two manifolds are the same, then their internal geometric structure are the same. Therefore, we can obtain the eigenvalues of the 40-year-old face image by solving the eigenvalues of the face image of the same person at the age of 30, as shown in Figure 12.3.

# 12.2.4 Determining the number of clusters

The number of clusters directly influences the clustering results. There are two ways to deal with the problem of the number of unknown clusters. One is to try different $c$ values several times, compare the values of the criterion functions under different $c$, and select the $c$ of the criterion function value as the number of clusters. The other is to automatically determine the number of clusters. Examples include Rcut-based spectral clustering algorithms [23], nonlinear dimensionality reduction (NLDR) algorithms [24], and distance-based heuristic methods [20].
