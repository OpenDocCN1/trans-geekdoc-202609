# **1.6.1 Overview of dynkin graphs in Lie group machine learning**

In Lie group machine learning, suppose that $g$ is a complex semi simple Lie algebra of study space $G$ and $\eta$ is its Cantan sub-algebra. Furthermore, $g$ decomposes the root subspace of $\eta$ into

```
$$g = \eta + \sum_{\alpha \in \Delta} g_\alpha$$
```

where $\Delta$ is the root system of $\eta$ and $|\Delta|$ is the number of elements. Further, $\eta^*$ is the dual space of $\eta$; hence, $\Delta \subset \eta^*$. Then, let $(x, y)$ represent the Killin $g$ type of $g$ and $\prod = \{\alpha_1, \alpha_2, \dots, \alpha_l\}$ be the simple root system of complex semi simple Lie algebra $g$. Then, $[\prod]$ can be decomposed into the sum of two orthogonal subsets, and each subset cannot be decomposed

```
$$\prod = \prod_1 \cup \prod_2 \cup \dots \cup \prod_k; \left( \prod_i, \prod_j \right) = 0 \ (i \neq j) \ . \quad \quad \quad \quad (1.17)$$
```

Naturally, this division of $[\prod]$ must derive an equivalence relationship in $[\prod]$; each $[\prod_i]$ is an equivalence class. This equivalence class relationship can be established in the following way.

Let $\alpha, \beta \in [\prod]$, if there exists a sequence in $[\prod]$

```
$$\alpha = \alpha_{i_1}, \alpha_{i_2}, \dots, \alpha_{i_m} = \beta$$
```

such that $\alpha_{ij}, \alpha_{ij+1} \neq 0 \ (j = 1, 2, \dots, m - 1)$, then $\alpha$ and $\beta$ have a relationship denoted by $\alpha \sim \beta$.

Obviously, the relationship $\sim$ has the following properties:

+   (1) $\alpha \sim \alpha$;
(2) if $\alpha \sim \beta$, then $\beta \sim \alpha$;
(3) if $\alpha \sim \beta, \beta \sim \gamma$, then $\alpha \sim \gamma$;

Thus, $\sim$ is an equivalence relationship. The same equivalence class cannot be decomposed into two mutually orthogonal subsets. Different equivalence classes are orthogonal to each other, i.e., the division of the equivalence relation correspond to $[\prod]$ (1.17).

**Definition 1.22. If the simple root system $[\prod]$ cannot be decomposed into the sum of two non-empty mutually orthogonal subsets, then $[\prod]$ is an irreducible simple root system; otherwise, $[\prod]$ is reducible.**
