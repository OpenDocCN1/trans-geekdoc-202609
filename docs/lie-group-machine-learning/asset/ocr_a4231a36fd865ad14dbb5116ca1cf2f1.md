input layer. Further, $\hat{h^i(x)}$| represents the size of layer i, and $b_j^i$ represents the inner offset of the i-th layer's j-th unit, which is the default activation code. $W_{jk}^i$ represents the weight set between the $i-1$-th layer $\hat{h_k}^{i-1}(x)$ and the i-th layer $\hat{h_j^i}(x)$. $\hat{h_j^i}(x)$ is defined as follows: $\hat{h_j^i}(x) = \textit{sigm}(a_j^i)$, where

$a_j^i(x) = b_j^i + \sum_{k} W_{jk}^i\hat{h_k}^{i-1}(x), \forall i \in \{1, \dots, l\}, \hat{h}^0(x) = x \tag{7.1}$

Here, $\textit{sigm}(*)$ is an S-shaped function: $\hat{h_j^l}(x) = \textit{sigm}(a) = 1 / 1 + e^{-a}$. The output layer is expressed as follows: $o(x) = \hat{h^{l+1}}(x) = f(a^{l+1}(x))$, where $a^{l+1}(x) = b^{l+1} + W^{l+1}\hat{h^l}(x)$. A is a startup function for classification; it is defined as follows:

$f_j(a) = \underset{j}{\textit{soft\max}}(a) = \frac{e^{a_j}}{\sum_{k=1}^{K} e^{a_k}} \tag{7.2}$

where k represents k classes.

For the deep structure of the data, it is expressed as a manifold structure, so that each submanifold corresponds to a simple structure. Thus, a learning problem is decomposed into a number of simple questions. Each simple problem corresponds to a layer in the deep structure, and each layer provides a valid index on the submanifold (Fig. 7.2).
