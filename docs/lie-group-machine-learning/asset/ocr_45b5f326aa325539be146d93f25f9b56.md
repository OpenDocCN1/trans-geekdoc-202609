which requires the synthesis function $\phi^{\mu}$ to be parsed. When $x$ is close to $e$, then $f^{x}(y)=f(x y)$ is meaningful to the other point $y$ of the $e$ neighbourhood, and

$X_{x} f=Z f^{x}=\lambda^{\mu} \frac{\partial}{\partial y^{\mu}}$.
(8.17)

In (8.17), $Z=\lambda^{\mu} \partial / \partial y^{\mu}$. If $x y=z$, (8.12) becomes

$X_{x} f=\lambda^{\mu} \frac{\partial f}{\partial z^{v}}\left.\frac{\partial \phi^{v}}{\partial y^{\mu}}\right|_{y=e}$.
(8.18)

To visually see that this is an infinitesimal rightward move, let $y^{\mu}=e^{\mu}+\lambda^{\mu} \delta_{t}$, and omit the item $\delta_{t}$, which is higher than one. The mapping $x \mapsto x y$ can be regarded as an infinitesimal rightward move. The corresponding change of $f$ is

$\delta f=f(x)-f(x)=\left.\frac{\partial f}{\partial z^{v}} \frac{\partial \phi^{v}(x, y)}{\partial y^{\mu}}\right|_{y=e} \lambda^{\mu} \delta_{t}$.
(8.19)

Comparing (8.18) with (8.19), we can see that $X f$ represents the following: when you move right along the given direction $\lambda^{\mu}$, it corresponds to a change in the value of the unit of parameter $t$. To write (4.18) in a more convenient form, set

$\psi_{\mu}^{\nu}=\left.\frac{\partial \phi^{\nu}}{\partial y^{\mu}}\right|_{y=e}(\mu, \nu=1, \ldots, r)$.
(8.20)

The function $\psi_{\mu}^{\nu}$ defined as such is the transform function of the Lie group. Using (8.20), we can write

$X_{x} f=\lambda^{\mu} \psi_{\mu}^{\nu}(x) \frac{\partial f}{\partial x^{\nu}}$

such that

$X_{x}=\lambda^{\mu} \psi_{\mu}^{\nu}(x) \frac{\partial}{\partial x^{\nu}}(\mu, \nu=1, \ldots, r)$.
(8.21)

Here, (8.21) is the infinitesimal rightward movement defined by $Z=\lambda^{\mu} \partial / \partial y^{\mu}$, and it can be seen that the infinitesimal rightward motion is the inverse vector field. From the infinitesimal right move (8.21), we know that

$X_{\mu}(x)=\left.\psi_{\mu}^{\nu}(x) \frac{\partial}{\partial y^{\mu}}\right|_{y=e} \frac{\partial \phi^{\nu}(x, y)}{\partial y^{\mu}} \frac{\partial}{\partial x^{\nu}}$
(8.22)

is the generator of the Lie group. This generator is given in the form of an operator, called the Lie generation operator [43].

Similarly, we can define

$X_{\mu}(y)=\left.\psi_{\mu}^{\nu}(y) \frac{\partial}{\partial x^{\mu}}\right|_{x=e} \frac{\partial \phi^{\nu}(x, y)}{\partial x^{\mu}} \frac{\partial}{\partial y^{\nu}}$
(8.23)

as the operator generating element corresponding to the infinitesimal leftward motion of the Lie group. When the synthetic function of the Lie group is given, it is easy to find the operator generating element of the Lie group.

From the viewpoint of the Lie group, (8.22) and (8.23) can be regarded as the generators of the Lie group, but from the viewpoint of Lie algebra, (8.22) and (8.23) are the basis vectors of Lie algebra.
