# **Definition 10.6.** The tensor *n*-mode product $X \times_d U$ of tensor $X \in R^{N_1...\times N_M}$ and a matrix is a tensor, and its form is $N_1 \times \cdots \times N_{d-1} \times N' \times N_{d-1} \times \cdots \times N_M$:

```
$$(X \times_d U)_{i_1,...,i_{d-1},j,i_{d+1},...,i_m} = \sum_{i_d} (X_{i_1,...,i_m}U_{j,i_d}) \qquad (10.19)$$
```

# **Definition 10.7.** The *n* pattern unfold of tensor $A \in R^{I_1\times...\times I_N}$ is a matrix $A_{(n)} = R^{I_n\times(I_{n+1}...I_{N-1}I_N)}$. The element of this matrix is $a_{i_1,...,i_N}$. The row-coordinate is $i_n$ and the column-coordinate is

```
$$(i_{n+1}-1)I_{n+2}I_{n+3}\cdots I_NI_1I_2\cdots I_{n-1} + (i_{n+2}-1)I_{n+3}I_{n+4}\cdots I_NI_1I_2\cdots I_{n-1} +$$
$$ (i_N-1)I_1I_2\cdots I_{n-1} + (i_1-1)I_2I_3\cdots I_{n-1} + (i_2-1)I_3I_4\cdots I_{n-1} + \cdots + i_{n-1}$$
```

# **Definition 10.8.** The *n*-mode vector of tensor *A* is the column vector of $A_n$ (Figure 10.6). We can represent each tensor $A \in R^{I_1\times...\times I_N}$ as an *n*-mode product by using HOSVD:

```
$$A = S_{\times_1} U^{(1)}_{\times_2} U^{(2)}\cdots \times_N U^{(N)} \qquad (10.20)$$
```

Here, we have the following rules:

+   (1) $U^{(n)} = (u_1^n u_2^n \cdots u_N^n)$ is called the *n*-mode $U^{(n)} \in R^{L_n \times I_n}$ matrix.

+   (2) $S \in R^{I_1 \times ... \times I_N}$ is a kernel tensor, and its sub-tensor has two characters. Complete orthonogonal character: for any $\alpha, \beta, \alpha \neq \beta$, we have $\langle S_{i_n=\alpha}, S_{i_n=\beta} \rangle = 0$; Ordering, i.e., $\|S_{i_n=1}\| \geq \|S_{i_n=2}\| \geq \cdots \geq \|S_{i_n=I_n}\| \geq 0$.
