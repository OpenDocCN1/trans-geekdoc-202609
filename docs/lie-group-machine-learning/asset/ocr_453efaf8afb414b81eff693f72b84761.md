# **8.4.2.2 Algorithm description**

Using the above theoretical analysis, we describe the semi-supervised learning algorithm based on the parameter Lie group (SSLA-PLG), as shown in Algorithm 8.5:

### Algorithm 8.5: SSLA-PLG Algorithm flow
//Algorithm function: use Lie group method for semi-supervised learning //
**Input:** Sample set $X=\left\langle x_{1}, x_{2}, \ldots, x_{l}, x_{l+1}, \ldots, x_{l+k} \in \mathcal{R}^{D}\right\rangle$, where $x_{1}, x_{2}, \ldots, x_{l}$ is the labelled data, i.e., there exits the set $L=\{(x_{1}, y_{1}), (x_{2}, y_{2}), \ldots, (x_{l}, y_{l})\}$, where $x_{l+1}, x_{l+2}, \ldots, x_{l+k}$ are unlabelled data ($l<<k$).
**Output:** Label $y$ of data $x$
**Process:**

**Step 1:** According to the input sample set $X=\left\langle x_{1}, x_{2}, \ldots, x_{l}, x_{l+1}, \ldots, x_{l+k} \in \mathcal{R}^{D}\right\rangle$, represent it with a parameter separately. Determine the corresponding learning system isomorphism (state) parameter Lie group and make full use of the marked data, representing the object to be learned with the parameters of Lie group. The object is required to meet the structure of the parameter Lie group.

**Step 2:** According to the algebraic structure of the parameter Lie group, the group method is used for marking.
Based on the marked data as the base point, the definition of the element generated by the parameter Lie group is

```
$$\chi_{y} = \lim _{\alpha^{\mu} \to 0} \frac{g(0, \ldots, \alpha^{\mu}, \ldots, 0)}{i \alpha^{\mu}}-g(0, \ldots, 0)$$
```

which calculates the generated meta.
Determine other unlabelled data according to the group operation rule, and if the unlabelled data can be represented by the matrix generator, the category is marked.

**Step 3:** According to the geometric structure of the parameter Lie group, the analytic manifold is used for marking.
Generate the field $U_{i}(1<i<l)$ of all labelled sample points $x_{i}$;
Analyse the neighbourhood information $U_{i}(1<i<l)$ of each labelled sample point $x_{i}$. Select each constant inner product $\mathbf{g}_{i, j}(x_{i})$ under the function of self-isomorphism on the unit point in the sample set. Calculate the value of $\mathbf{g}_{i, j}(x_{i})$;
Put the value of $\mathbf{g}_{i, j}(x_{i})$ into the following formula:

```
$$d(x_{i}, x_{j})=\sqrt{\sum_{i, j=1}^{n} \mathbf{g}_{i, j}\left(x_{i}\right)\left(x_{i j}-x_{j j}\right)\left(x_{i j}-x_{j j}\right)}$$
```

Calculate the distance between $x_{i}$ and $x_{j}$ in $U_{i}(1<i<l)$.
Determine the smallest value $d$ of each point $x_{i}$ corresponding to $x_{j}$, and mark $x_{j}$ as the marker that is the same as $x_{i}$.

**Step 4:** Check whether the data is marked; if not, return to Step2 and repeat. Otherwise, go to the next step, i.e., data classification. Complete the data reduction and structural learning steps.
