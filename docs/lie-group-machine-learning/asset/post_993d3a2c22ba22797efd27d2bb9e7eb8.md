
$(q^n - 1)(q^{n} - q) \cdot \cdot (q^n - q^{m-1})$ possible choices. However, a definite $m$-dimensional subspace can have different bases.

It is proven that the number of $m$-dimensional subspaces is equivalent to the number of $m$ orbits that can be generated (i.e., the number of operators used). In the course of learning, to distinguish each subspace, it is marked with specific real values.

**Definition 2.17.** Let $P$ be a partially ordered set containing the smallest element $0$, and for $a \in P$, if $l(0, a)$ exists, i.e., the chain from $0$ to $a$ can be refined into a maximal chain. It is easy to understand that the set $P$ containing several samples can be represented in terms of duality according to the dual hypothesis whereby each instance to be learned can be expressed in terms of a particular value. Here, the rank function can also be seen as the maximum possible length of the orbit limit, orbit length $\leq r(x)$.

**Proposition 2.6.** Let $P$ be a partially ordered set containing the smallest element $0$ and assume that for any $a, b \in P$ with $a < b$, the chains from $a$ to $b$ can be refined into a maximal chain. $$0 < a_{1} < a_{2} < \cdots < a_{n} = a$$
is the $0, a$ maximal chain. Then,
$$0 < a_{1} < a_{2} < \cdots < a_{n} < b$$
is a $0, b$ maximal chain, $r(b) = n + 1 = r(a) + 1$, i.e., (2) holds.

Now, let $r: P \rightarrow \mathbb{N}_{0}$ be a function that satisfies (1), (2). Let $a, b \in P$ and $a < b$. Assume that
$$a = a_{0} < a_{1} < a_{2} < \cdots < a_{n} = b,$$
$$a = a_{0}^{l} < a_{1}^{l} < a_{2}^{l} < \cdots < a_{m}^{l} < b$$
are two $a, b$ maximal chains. According to (2),
$$r(b) = r(a_{n}) = r(a_{n-1}) + 1 = \cdots = r(a_{0}) + n = r(a) + n,$$
$$r(b) = r(a_{m}^{l}) = r(a_{m-1}^{l}) + 1 = \cdots = r(a_{0}^{l}) + m = r(a) + m.$$

$0 < a_1 < a_2 < \cdots < a_n = a$
be a $0, a$ maximal chain. According to definition 2.17, $r'(a)=n$. Because $r$ satisfies (1) and (2),
$r(a) = r(a_n) = r(a_{n-1}) + 1 = \cdots = r(0) + n = n$
Then, $r=r'$, i.e., $r$ is the rank function of $P$.
