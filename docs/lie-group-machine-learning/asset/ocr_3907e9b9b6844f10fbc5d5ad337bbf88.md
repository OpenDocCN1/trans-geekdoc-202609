(3) Optimising the decision strategy: The decision rules of the basic KNN algorithm have an obvious drawback. When the sample distribution density is not uniform, the sizes of the distances of the nearest $K$ neighbours are considered instead of their distances, which may lead to miscalculation. Therefore, an improved strategy is to use the reciprocal of the distance as the weight of the sample contribution to the decision.

# ### 13.2.2 KNN algorithm based on the Finsler metric

The Finsler metric is a more general measure than the Riemann metric. Because of the generality of its definition, we can construct many Finsler metrics. Many scholars have studied Finsler geometry and given some Finsler metrics that have good properties or are easy to compute [8–15].

This section adopts a class of computable Finsler metrics, i.e., ($\alpha$, $\beta$) metrics [13, 14]. They play a crucial role in Finsler geometry. Let $F = \alpha\phi(s)$, $s = \beta/\alpha$, where $\alpha = \sqrt{a_{ij}(x)y^{i}y^{j}}$ is the Riemann metric, $\beta = b_{i}(x)y^{i}$ is non-zero in the 1 form, $y$ is the differential of $x$, and $\phi = \phi(s)$ is defined in the open interval $(-b_{0}, b_{0})$ and satisfies

```
    $$\phi(0) = 1, \phi(s) > 0, \phi(s) - s\phi^{\prime}(s) + (b^{2} - s^{2})\phi^{\prime\prime}(s) > 0, |s| \leq b < b_{0} \quad(13.9)$$
```

For any $x \in M$, $F$ is the positive definite Finsler metric on manifold $M$. $F$ is called the ($\alpha$, $\beta$) metric. It is easy to verify that the ($\alpha$, $\beta$) metric satisfies the definition of the Finsler metric as follows:

```
    Let: $\alpha_{\lambda} = \alpha(x^{1}, \dots, x^{m}; \lambda y^{1}, \dots, \lambda y^{m}), \beta_{\lambda} = \beta(x^{1}, \dots, x^{m}; \lambda y^{1}, \dots, \lambda y^{m})$
    $\therefore \alpha_{\lambda} = \alpha(x^{1}, \dots, x^{m}; \lambda y^{1}, \dots, \lambda y^{m}) = \sqrt{a_{ij}(x)\lambda y^{i}\lambda y^{j}} = |\lambda|\sqrt{a_{ij}(x)y^{i}y^{j}}$
    $\beta_{\lambda} = \beta(x^{1}, \dots, x^{m}; \lambda y^{1}, \dots, \lambda y^{m}) = b_{i}(x)\lambda y^{i} = \lambda b_{i}(x)y^{i}$
    $\therefore F(x^{1}, \dots, x^{m}; \lambda y^{1}, \dots, \lambda y^{m}) = \alpha_{\lambda}\phi(\beta_{\lambda}/\alpha_{\lambda}) = |\lambda|\sqrt{a_{ij}(x)y^{i}y^{j}}\phi\left(\frac{\lambda}{|\lambda|}\frac{\beta}{\alpha}\right)$.
```

Hence, we just have to show that function $\phi$ is an even function and constantly greater than 0, i.e., $\phi(-s) = \phi(s)$ and $\phi(s) \geq 0$ can guarantee that the ($\alpha$, $\beta$) metric is a Finsler metric.

This section uses the concise form of the Finsler metric. Let $F = \alpha + |\beta|$, where $\alpha$ is the Euclidean distance, $\alpha = \sqrt{y^{i}y^{i}}$, $\beta = tw^{T}y$, $t$ is an arbitrary constant, and $w$ is a projection vector. Note that $w$ is the projection vector in the linear discriminant analysis (LDA) [16] algorithm. Suppose $X$ as a data set whose classes are set as $C = \{C_{1}, C_{2}, \dots, C_{s}\}$. Suppose that $Z = w^{T}X$. Then, the intra-class distance $S_{W}^{\prime}$ and inter-class distance $S_{B}^{\prime}$ after projection can be expressed as

```
    $$S_{W}^{\prime} = \sum_{i=1}^{s} N_{i}\left(w^{T}m_{i} - w^{T}m\right)\left(w^{T}m_{i} - w^{T}m\right)^{T}\quad(13.10)$$
```
