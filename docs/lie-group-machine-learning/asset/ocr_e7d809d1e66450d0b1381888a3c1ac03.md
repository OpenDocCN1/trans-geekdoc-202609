```
min<sub>S<sub>i</sub></sub> ||S<sub>i</sub>||<sub>1</sub>
s.t. ||x<sub>i</sub> - XS<sub>i</sub>||<sup>2</sup> < ε (∑<sub>j=1</sub><sup>n</sup> S<sub>ij</sub> = 1)    (12.9)
```

where ||x<sub>i</sub> - XS<sub>i</sub>||<sup>2</sup> denotes the reconstruction error. The SPP algorithm constructs an adjacency graph G = (X, (S<sub>ij</sub>)<sub>nxn</sub>) to describe the relation between a sparse mapping and the sample points. The sparse graph can be well maintained by finding the mapping matrix W. Similar to the NPE algorithm and the LLE algorithm, the SPP algorithm solves the following objective function to get W:

```
min<sub>W</sub> ∑<sub>i=1</sub><sup>n</sup> ||W<sup>T</sup>(x<sub>i</sub> - XS<sub>i</sub>)||<sup>2</sup> / ∑<sub>i=1</sub><sup>n</sup> ||W<sup>T</sup>x<sub>i</sub>||<sup>2</sup>    (12.10)
```

which is equivalent to solving the following problem of matrix traces:

```
max<sub>W</sub> tr(W<sup>T</sup>XS<sub>β</sub>X<sup>T</sup>W) / tr(W<sup>T</sup>XX<sup>T</sup>W)    (12.11)
```

where S<sub>β</sub> = S + S<sup>T</sup> - SS<sup>T</sup> can be solved by generalized eigenvalues. Although the SPP algorithm can use the matrix trace as far as possible to balance the weight on each side of the graph, some useful information of the samples is lost.

The Laplacian eigenvalues (LPE) algorithm proposed in this section is based on the SPP algorithm. The approximation of the sample points by the local tangent space not only ensures the convergence of the local minimum error but also maintains the local geometric characteristics of the manifold. The asynchronous spectrum estimation manifold learning algorithm is modelled as follows:

```
min<sub>W,S<sub>i</sub></sub> J(W, S) = ∑<sub>i=1</sub><sup>n</sup> ||W<sup>T</sup>(x<sub>i</sub> - XS<sub>i</sub>)||<sup>2</sup> / ∑<sub>i=1</sub><sup>n</sup> ||W<sup>T</sup>x<sub>i</sub>||<sup>2</sup> + ∑<sub>i=1</sub><sup>n</sup> λ<sub>i</sub> ||S<sub>i</sub>||<sub>1</sub>
s.t. W<sup>T</sup>W = I    (12.12)
```

where W ∈ R<sup>D×d</sup> (d < D) is a mapping matrix, the sample point set is X = {x<sub>1</sub>, x<sub>2</sub>, . . . , x<sub>n</sub>}, x<sub>i</sub> ∈ R<sup>D</sup>, (S<sub>ij</sub>)<sub>nxn</sub> is a similarity matrix with diagonal 0, S<sub>i</sub> is the ith column of the reconstructed coefficient matrix S of the sample point x<sub>i</sub>, and λ<sub>i</sub> is a harmonic parameter. λ<sub>i</sub> is also the main eigenvalue of matrix L = S<sup>-1</sup>L = I - S<sup>-1</sup>W, and I is a d×d identity matrix. The purpose of this method is to avoid the non-unique solutions of the matrix trace by solving the regularisation problem.
