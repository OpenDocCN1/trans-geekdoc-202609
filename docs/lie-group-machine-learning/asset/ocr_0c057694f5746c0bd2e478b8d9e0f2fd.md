**Definition 1.25.** If the \(\pi\)-system \(\Pi\) cannot be decomposed into a sum of two ortho-gonal non-empty subsets, then \(\Pi\) is an irreducible \(\pi\)-system.

Obviously, an irreducible simple root system is an irreducible \(\pi\)-system.

In the same way that the Dynkin graphs of the simple root system are constructed under Definition 1.23, we can also construct a graph, called the Dynkin diagram of \(\Pi\), for each \(\pi\)-system \(\Pi\).

Obviously, a \(\pi\)-system \(\Pi\) is irreducible if and only if its Dynkin diagram is con-nected. Hence, we can also judge the solvability of learning problems through the Dynkin diagram of the simple root system. The algorithm is described as follows:

```
**Algorithm 1.15:** Solvability discriminant of Lie group machine learning

**Initialisation:** Let the input space vector group be denoted by \(\Pi = \{\alpha_1, \alpha_2, \dots, \alpha_n\}\), \(D\) is its Dynkin diagram, it contains \(n\) nodes \(\alpha_1, \alpha_2, \dots, \alpha_n\) //

**Input:** \(D\) //

**Output:** \(\{0, 1\}\) //

\quad procedure SOLVABLE2(D)

\quad\quad for i=1 to n-1; j=2 to n do

\quad\quad\quad if there is no path from \(\alpha_i\) to \(\alpha_j\)

\quad\quad\quad\quad then return 0; // the learning problem is not solvable //

\quad\quad\quad else

\quad\quad\quad\quad \(i \leftarrow i+1\) ;

\quad\quad\quad\quad \(j \leftarrow j+1\) ;

\quad\quad end if

\quad\quad\quad repeat

\quad\quad\quad end for

\quad\quad return 1; // the learning problem is solvable //

\quad end SOLVABLE2
```

If \(\Pi_1\) is a subset of \(\Pi\), then the Dynkin diagram of \(\Pi_1\) is the Dynkin diagram with \(\Pi\) elements of the points and their interconnected lines are retained, and the remaining points and lines are removed from the map. The Dynkin diagram of \(\Pi_1\) is also the subset Dynkin diagram of \(\Pi\).
