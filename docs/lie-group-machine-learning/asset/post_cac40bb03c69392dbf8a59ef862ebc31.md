
Note: In the specific learning algorithm, the two issues can be directly expressed by positive and negative coordinates, and there are many types of problems with integer coordinates as well as regression problems with real coordinates. Of course, regardless of the type of complex problem, it can be classified into one of the two categories to be dealt with.

The above theorem provides an effective way to calculate another orbit from one orbit, and it should be noted that the new generated weight $\sigma_i(v)$ can be determined only by referring to the coordinates and index $i$ of $\sigma_i(v)$. In other words, there is no need to remember (store) too much weight, which is quite meaningful for reducing the number of weights at the highest level.

The algorithm is described as follows:

### Branch($v$):

1. Set $i_0 = 0$.
2. Suppose that $i$ is the first exponent, with $i > i_0$ and $n_i > 0$. If there is no such index $i$, the algorithm is terminated.
3. Calculate the weight $\xi = \sigma_i(v) = (x_1, \ldots, x_i)$.
4. If $x_{i+1}, \ldots, x_l \geq 0$, then output $\xi$ and execute $Branch(\xi)$.
5. Set $i_0 = i$ and go to step 2.
6. $Branch(\mu)$ will give all the weight points in the tree. The only operation in $Branch$ is to compare the integer and the calculation in the third step. The shortest path in the tree (from $\xi$ to root node $\mu$) is found to indicate that the hierarchy of $\xi = (x_1, \ldots, x_l)$ can be quickly calculated.

### Reflection($\xi$):

1. Let $i$ be the index $x_i < 0$ of the first negative coordinate. If there is no such index, the algorithm is terminated.
2. Calculate the weight $v = \sigma_i(\xi)$.
3. Output index $i$.
4. Set $\xi = v$ and go to the first step of the algorithm.

Description: The number given by $Reflection(\xi)$ is clearly the level of $\xi$, since the level is reduced by one in the second step. The algorithm can control the maximum number of computational levels, since an orbit needs only to be calculated to the $N/2$ layer, where $N$ is the number of layers in the orbit. The rest of the orbit can be calculated using the equation $\omega_0(v) = (-n_{s(1)}, \ldots, -n_{s(l)})$, assuming that $v = (n_1, \ldots, n_l)$ has level $k$.

### Algorithm 2.1: Orbit generation breadth-first algorithm

**Orbit-Breadth-First**

- **Data structure:**
  - `levelcount`: An array of integers counted for each layer (initialised to 0)
  - `current-level`, `next-level`: Link list of weight nodes
  - Each weight node contains:
    - $\boldsymbol{\omega}=(\omega_1,\dots,\omega_l)$: Weight vector
    - `next`: A pointer to the next weight point
- **Input:**
  - $\boldsymbol{m}=(m_1,\dots,m_l)$: Dominance vector (all $m_i>0$)
  - $D$: Dynkin matrix
  - $l$: rank of G
- **Output:** Weight vector list $\boldsymbol{\omega}=(\omega_1,\dots,\omega_l)$ and three related integers
  - The first integer indicates the position of $\boldsymbol{\omega}$ in the list
  - The second and third integers indicate the weight vector and the calculation of $\boldsymbol{\omega}$
- **Process:**
  1. Output $\mathbf{m}$; // initial state, i.e., the original sample set that has not been studied
  2. Insert $\mathbf{m}$ into the header of the `current-level` list;
  3. Make $level=0$, $levelcount[level]=1$;
  4. Make $from=1$; //Position of the patriarchal values
  5. Make $to=1$; //Position of the new weight value is also the total number of weights that are calculated
  6. While ($levelcount[level]>0$ and $level<max\ level$)
     - $level++;$
     - Set $from: to$; //Count down the weights in the `current-level` list
     - For (Each weight $\boldsymbol{\omega}$ in the `current-level` list)
       - For ($i=1$ to $l$)
         - If ($\omega_i>0$)
           - Calculate $\sigma_i$ to $\boldsymbol{\omega}$ via $\mathbf{v}$;
           - If ($v_j\geq0$ to $i<j\leq l$)
             - //Store $v$?
             - Insert $v$ into the header of the $next-level$ list;
             - $levelcount[level]++;$
             - Output $v, to, from, i$;
           - End If
         - End If
       - End For
     - $from--; // Follow the 'first in, first out' principle in the current list
     - End For
     - Release the previous list `current-level`;
     - Make `current-level` = `next-level`;
     - Make `next-level` = empty table;
     - End While

Description: The `current-level` is used to store the weights that have just been calculated (initially, the `current-level` list only includes the control weights $\mu$). The `next-level` stores the new weights generated by the `current-level`. When the weights in the `current-level` are all calculated, the `next-level` list is assigned to it and the original list is released.

### Algorithm 2.2: Orbit generation depth-first algorithm

**Orbit-depth–first**

- **Data structure:**
  - `levelcount`: An integer array that counts for each layer
  - `weight-structure stack`
  - Each $\mathbf{w}$ weight-structure contains:
    - $\omega=\langle\omega_1, \ldots, \omega_l\rangle$: Weight vector
    - `level`: Rank of $\omega$
    - `from`: An integer that labels the parent value
    - $i$: The next index to be tested
- **Input:**
  - $\mathbf{m}=\langle m_1, \ldots, m_I\rangle$: Control weight
  - $D$: Dynkin matrix
  - $l$: rank of G
  - `maxlevel`: Calculate the maximum level of the track
- **Output:** Weight vector list $\omega=\langle\omega_1, \ldots, \omega_l\rangle$ and four related integers
  - The first integer indicates the position of $\omega$ in the list
  - The second integer is the hierarchy of $\omega$
  - The third and fourth integers indicate the weight vector and the calculation of $\omega$
- **Process:**
  1. Make `level`= 0, `levelcount`[`level`]= 1, $i$= 1;
  2. Make `from`= 1; // Location of paternity values
  3. Make `to`= 1; // Position of the new weight, i.e., the total number of weights computed
  4. Output $\mathbf{m}$; // Initial state, i.e., original collection of samples that have not been learned
  5. Put $\mathbf{m}$, `level`, `from`, $i$ into the stack;
  6. While (The stack is nonempty)
     - Out $\omega$, `level`, `from`, $i$ of stack;
     - While ($i \leq l$)
       - If ($\omega_i > 0$)
         - If ($v_j \geq 0$ to $i < j \leq l$)
           - //Store $v$ ?
           - If ($i = 1 \leq \bar{j}$)
             - Out $\omega$, `level`, `from`, $i + 1$ of stack; // Then return to $\omega$
           - `level` $+ -$;
           - `levelcount`[`level`] $+ -$;
           - Output $v$, `level`, `from`, $i$, `to`;
           - If (`level` $\geq$ `max level`) jump out `while` loop;
           - Copy $v$ to $\omega$; // Continue with the track of $\omega = v$
           - Let $i$ be equal to the first element in $D_{\bar{j}}$;
         - Else
           - $i + -$;
         - End If
       - End If
       - Else
         - $i + -$;
       - End If
     - End While
     - End While

Note: The weights mentioned above are treated as sample data or related parameter weights generated in the learning algorithm.
