**Definition 1.16.** Suppose that $G$ is a non-empty set satisfying the following conditions:

+   – $G$ is a group;
– $G$ is a differential manifold;
– The operations of the group are differentiable, i.e., the mapping $(g_1, g_2) \mapsto g_1g_2^{-1}$
from $G \times G$ to $G$ is a differentiable mapping.

Then, $G$ is a Lie group.
