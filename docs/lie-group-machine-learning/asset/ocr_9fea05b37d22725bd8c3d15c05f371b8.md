Algorithm 1.14: Solvability discriminant of Lie group machine learning

Initialisation: Input data set simple root system of Lie algebras is $\Pi = \{\alpha_1, \alpha_2, \ldots, \alpha_n\}$ //

**Definition 1.23.** Let $\Pi = \{\alpha_1, \alpha_2, \ldots, \alpha_l\}$ be a simple root system of complex semisimple Lie algebras, use $l$ point denoted $\alpha_1, \alpha_2, \ldots, \alpha_l$, and the $i$-th and $j$-th use the number of

$\frac{2(\alpha_i, \alpha_j)}{(\alpha_i, \alpha_i)} \cdot \frac{2(\alpha_i, \alpha_j)}{(\alpha_j, \alpha_j)} = r_{ij}$

lines to be connected. If $(\alpha_i, \alpha_j) < (\alpha_j, \alpha_i)$, then draw an arrow pointing from point $j$ to point $i$. The resulting graph is called the Dynkin diagram of $\Pi$ (or g).

Obviously, if $\Pi$ is decomposable (1.17), then the Dynkin diagram of $\Pi$ can be composed into $k$ interconnected branches.

For convenience of study, we can abstract the property of the simple root system as the property of the space vector group.

**Definition 1.24.** Let $E$ be an $n$-dimensional study space, $\Pi = \{\alpha_1, \alpha_2, \ldots, \alpha_n\}$ be a positive vector group of $E$, and when $i \neq j$, $2(\alpha_i, \alpha_j)/(\alpha_i, \alpha_i) \in \mathbb{Z}$. We call $\Pi = \{\alpha_1, \alpha_2, \ldots, \alpha_n\}$ as a $\pi$-system.

The following four conclusions are obvious.

+   (1) $\Pi$ is a linear unrelated group, so $m \leq n$. $\Pi$ is a $\pi$-system of $E$'s subspace $L(\Pi)$;

+   (2) Any subset $\Pi_1$ of $\Pi$ is a $\pi$-system.

+   (3) If $\alpha, \beta \in \Pi$, $\alpha \neq \beta$, then
$0 \leq \frac{2(\alpha, \beta)}{(\alpha, \alpha)} \cdot \frac{2(\alpha, \beta)}{(\beta, \beta)} \leq 3$.

+   (4) The simple root system $\Pi$ of semisimple Lie algebras is a $\pi$-system.
