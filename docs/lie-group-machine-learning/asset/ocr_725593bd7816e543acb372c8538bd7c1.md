# Initialisation:

Initialise $W = I^2$, and model (12.12) is simplified as
$$\min _{S_{i}} \frac{\sum_{i=1}^{n}\left\|\boldsymbol{x}_{i}-X S_{i}\right\|^{2}}{\sum_{i=1}^{n}\left\|\boldsymbol{x}_{i}\right\|^{2}}+\sum_{i=1}^{n} \lambda_{i}\left\|S_{i}\right\|_{1} \text {. }$$

It can be further simplified to the following form:
$$\min _{S_{i}} \sum_{i=1}^{n}\left\|\boldsymbol{x}_{i}-X S_{i}\right\|^{2}+\sum_{i=1}^{n} \bar{\lambda}_{i}\left\|S_{i}\right\|_{1}$$ (12.13)
where $\bar{\lambda}_{i}$ is a constant factor of $\lambda_{i}$. As can be seen, the problem (12.13) has been transformed into a simple sparse mapping problem.

# Iterative steps:

By solving the problem (12.13), the graph $S$ is obtained, and the optimisation problem (12.12) is converted into
$$egin{gathered} \min _{W, S_{i}} \frac{\sum_{i=1}^{n}\left\|W^{T}\left(\boldsymbol{x}_{i}-X S_{i}\right)\right\|^{2}}{\sum_{i=1}^{n}\left\|W^{T} \boldsymbol{x}_{i}\right\|^{2}} \\ \text { s.t. } \quad W^{T} W=I \end{gathered}$$

which is equivalent to
$$egin{gathered} \min _{W} \frac{\operatorname{tr}\left[W^{T} X(I-S-S^{T}+S S^{T}) X^{T} W\right]}{\operatorname{tr}\left(W^{T} X X^{T} W\right)} \\ \text { s.t. } \quad, W^{T} W=I \text {. } \end{gathered}$$ (12.14)

This is a regularised matrix trace problem, and its global optimal solution can be obtained by an efficient iterative algorithm. For example, Y. Gao et al. proposed a generalised Fourier transform algorithm based on the Fisher discriminant [29], and H. Wang et al. [30] proposed the trace ratio method. This section adopts the efficient trace ratio method proposed by Y. Jia et al. [31], whose effectiveness has been demonstrated.

In combination with $W$ obtained in the first step and $S = \left(S_{ij}\right)_{nxn}$ obtained from the optimisation problem, the objective function can be simplified to the following form:
$$\min _{S_{i}} \sum_{i=1}^{n}\left\|W^{T}\left(\boldsymbol{x}_{i}-X S_{i}\right)\right\|^{2}+\sum_{i=1}^{n} \lambda_{i}\left\|S_{i}\right\|_{1} \text {. }$$ (12.15)
By solving (12.13) and (12.15), the above optimisation problem is completely transformed into a sparse reconstruction problem.
