the infinity symbol. The notation for max norm is ||v||inf, where inf is a subscript.

$L^{inf}(v) = ||v||_{inf}$ (8.5)

The max norm is calculated as returning the maximum value of the vector, hence the name.

$||v||_{inf} = \max a_1, a_2, a_3$ (8.6)

The max norm of a vector can be calculated in NumPy using the norm() function with the order parameter set to inf.

```
```python
# vector max norm
from math import inf
from numpy import array
from numpy.linalg import norm
# define vector
a = array([1, 2, 3])
print(a)
# calculate norm
maxnorm = norm(a, inf)
print(maxnorm)
