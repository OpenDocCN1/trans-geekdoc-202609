## 线性代数速查表

本附录提供了常用线性代数操作的 NumPy 示例快速参考。

### C.1 数组创建

创建 NumPy 数组有多种方法。

### C.1.1 数组

```
from numpy import array
A = array([[1,2,3],[1,2,3],[1,2,3]])
```

### C.1.2 空数组

```
from numpy import empty
A = empty([3,3])
```

### C.1.3 零数组

```
from numpy import zeros
A = zeros([3,5])
```

### C.1.4 一数组

```
from numpy import ones
A = ones([5, 5])
```

### C.2 向量

向量是标量的列表或列。

### C.2.1 向量加法

```
c = a + b
```

### C.2.2 向量减法

```
c = a - b
```

### C.2.3 向量乘法

```
c = a * b
```

### C.2.4 向量除法

```
c = a / b
```

### C.2.5 向量点积

```
c = a.dot(b)
```

### C.2.6 向量-标量乘法

```
c = a * 2.2
```

### C.2.7 向量范数

```
from numpy.linalg import norm
l2 = norm(v)
```

### C.3 矩阵

矩阵是标量的二维数组。

### C.3.1 矩阵加法

```
C = A + B
```

### C.3.2 矩阵减法

```
C = A - B
```

### C.3.3 矩阵乘法（Hadamard 积）

```
C = A * B
```

### C.3.4 矩阵除法

```
C = A / B
```

### C.3.5 矩阵-矩阵乘法（点积）

```
C = A.dot(B)
```

### C.3.6 矩阵-向量乘法（点积）

```
C = A.dot(b)
```

### C.3.7 矩阵-标量乘法

```
C = A.dot(2.2)
```

### C.4 矩阵类型

不同类型的矩阵常用作更广泛计算中的元素。

### C.4.1 三角矩阵

```
# lower
from numpy import tril
lower = tril(M)
# upper
from numpy import triu
upper = triu(M)
```

### C.4.2 对角矩阵

```
from numpy import diag
d = diag(M)
```

### C.4.3 单位矩阵

```
from numpy import identity
I = identity(3)
```

### C.5 矩阵运算

矩阵运算常用作更广泛计算中的元素。

### C.5.1 矩阵转置

```
B = A.T
```

### C.5.2 矩阵求逆

```
from numpy.linalg import inv
B = inv(A)
```

### C.5.3 矩阵迹

```
from numpy import trace
B = trace(A)
```

### C.5.4 矩阵行列式

```
from numpy.linalg import det
B = det(A)
```

### C.5.5 矩阵秩

```
from numpy.linalg import matrix_rank
r = matrix_rank(A)
```

### C.6 因式分解

矩阵因式分解（或矩阵分解）将矩阵分解为其组成部分，以使其他操作更简单且数值更稳定。

### C.6.1 LU 分解

```
from scipy.linalg import lu
P, L, U = lu(A)
```

### C.6.2 QR 分解

```
from numpy.linalg import qr
Q, R = qr(A, 'complete')
```

### C.6.3 Cholesky 分解

```
from numpy.linalg import cholesky
L = cholesky(A)
```

### C.6.4 特征值分解

```
from numpy.linalg import eig
values, vectors = eig(A)
```

### C.6.5 奇异值分解

```
from scipy.linalg import svd
U, s, V = svd(A)
```

### C.7 统计

统计量总结向量或矩阵的内容，并常用作更广泛操作中的组件。

### C.7.1 均值

```
from numpy import mean
result = mean(v)
```

### C.7.2 方差

```
from numpy import var
result = var(v, ddof=1)
```

### C.7.3 标准差

```
from numpy import std
result = std(v, ddof=1)
```

### C.7.4 协方差矩阵

```
from numpy import cov
sigma = cov(A)
```
