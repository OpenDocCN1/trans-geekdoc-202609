**Deep neural network (DNN)**

在 DNN 中，输入和输出之间存在多层感知器或隐藏层。所有层都与前一层相连；通过每一层，网络根据权重和激活函数估计精确输出。通过 DNN，我们可以建模任何复杂的非线性关系。DNN 的核心特性是学习与目标最相关的特征 \[7\]。DNN 在模型选择、训练动态方面存在研究缺口，通过结合图卷积神经网络优化和贝叶斯神经网络来估计不确定性。DNN 有大量应用，如计算机视觉、机器翻译、社交网络过滤、棋盘游戏、视频游戏和医疗诊断（见图 2）。

**Recurrent neural network (RNN)**

RNN 是一种专门用于处理序列数据或时间序列（如视频、语音等）的深度学习网络。RNN 通常将前一个状态的数据保留到下一个状态。它之名“循环”，因为它对每个输入执行相同的函数，但输出不同，因为它还取决于过去的计算。RNN 与深度学习的前沿主题——长短期记忆网络（LSTM）密切相关。RNN 解决了许多问题，如智能交通系统 \[8\]、时间变矩阵求反 \[9\]，以及许多其他。RNN 以句子评估和语言数据处理而闻名（见图 3）。

**Deep belief network (DBN)**

DBN 是一种概率性的无监督深度学习算法。它包含多层隐藏变量。为了解决更复杂的问题，需要更多的隐藏层；每层与其他层之间存在特殊的统计关系。

DBN 可以概率性地学习；学习后，DBN 需要在监督下进行训练以进行分类。DBN 用于识别簇并生成图像、视频序列以及运动捕获数据（见图 4）。
