# 引言

深度学习专注于视频、图像、文本和音频识别、自动驾驶、机器人、医疗保健等方面。[1]。深度学习是一个以结果为导向的研究领域，因此受到研究人员和学者的极大关注。Rina Dechter在1986年提出了“深度学习”这一术语，深度学习领域的主要动机是创造一种能够模仿人脑的智能机器。在人类中，大脑是最重要的决策器官；大脑根据视觉、嗅觉、触觉和听觉做出决策。大脑还能存储记忆并基于经验解决复杂问题。

过去几十年里，研究人员梦想创造一种与人脑一样智能的机器，他们开始研究人脑的生物结构和工作方式。创造能够执行特定任务的机器人以及自动驾驶汽车是减少道路事故的手段。

根据世界卫生组织（WHO）的数据，每年有135万人在道路事故中丧生，大约90%的事故是由于人为错误引起的[2][3]。为了开发上述应用的前沿设备，需要以不同的、创新的方式思考，找到一些能够在一定程度上实现这些目标的前沿范式。在深度学习中，"deep"（深度）指的是神经网络的层数。

## 5

以某种方式相互关联。机器学习是任何程序，它可以在没有程序员特别编程的情况下自行学习。机器学习有两种类型：监督学习和无监督学习。在监督学习中，你用完全标记的数据教或训练机器，机器从标记数据中学习，然后预测未见的数据。在监督学习中，机器只能在训练阶段已经经历过的输入时给出正确的输出；它基于经验；训练数据集或机器的经验越多，得到准确输出的可能性就越大。这是一个耗时的过程，也需要大量的数据科学专业知识。相反，在无监督学习中，模型不需要受监督，而是模型自行处理新数据并发现数据内部的信息。它通常处理无标签数据；与监督学习相比，无监督学习发现数据内部的模式。

深度学习模型在复杂抽象的方面表现敏捷且以结果为导向。深度学习模型主要基于人工神经网络（ANN），分类为卷积神经网络（CNN），尽管也有深度信念网络、生成模型、命题公式和玻尔兹曼机等也发挥作用（见图1）。
