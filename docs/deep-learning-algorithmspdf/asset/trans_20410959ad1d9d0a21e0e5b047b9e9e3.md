1Korea University, Seoul, Republic of Korea

本章介绍了一种动态且低复杂度的决策算法，旨在实现深度学习平台的时间平均效用最大化，灵感来自Lyapunov优化。在深度学习计算中，由于计算成本高昂，可能会出现大延迟。因此，处理延迟是深度学习算法商业化的重要问题。本文提出的算法首先观察系统延迟，并在此基础上动态地在效用（即深度学习性能）和系统延迟之间进行权衡。为了评估所提算法的性能，本文在超分辨率框架的应用下，展示了真实数据的评估结果。最后，本文总结说Lyapunov优化算法可以应用于各种新兴应用。

**Keywords:-** Lyapunov optimization, stochastic optimization, real-time computing, deep learning platforms, computer vision platforms **INTRODUCTION**

当今，各种机器学习和深度学习算法已在计算机视觉、自然语言处理等众多应用中得到发展。此外，这些算法的性能不断提升。因此，机器学习和深度学习算法的发展已趋于成熟。然而，专注于算法在现实世界中实现的研究贡献相对较少，相比之下，算法本身的发展更为丰富。为了在现实世界中运行深度学习算法，必须考虑实时计算的问题。

因此，延迟处理是必要的，因为深度学习算法的计算通常会引入大延迟。在通信和网络研究文献中，存在一种著名的随机优化算法，用于在保持系统稳定的同时最大化效用函数。

这里，稳定性以队列建模，而该算法旨在在稳定队列动态的同时优化计算。
