## 17.2 Machine Learning

Machine learning seeks to build computer systems that will increasingly learn and develop. Machine learning has had a huge impact on AI's recent success. One of the first occasions the word “computer learning” was stated in 1959 when a machine-learning software was qualified to play machine-learning checks. There are many ways to explain what machine learning is. One of the most frequently cited descriptions is Mitchell: “It is said that a computer program learns from experience E with some tasks T and measure P, when the performance in T tasks, measured by P, improves with E experience”. An algorithm should be trained for better performance in a selected measured task(s) about a performance metric. As data is used to perform algorithms, they “gain” from the method. In the subsequent executions, the algorithms work well. Depending on the nature of the query, a machine learning algorithm can be built in three ways: supervised learning, unsupervised learning, and reinforcement learning. An algorithm with a dataset of input–output examples is educated in supervised learning. The algorithm learns to map inputs by observing data patterns to specify outputs. For example, classification and regression exercises may be used with supervised learning. The dataset consists of input examples without their goal production in unsupervised learning. Unsupervised learning algorithms may be used by analyzing their trends to calculate the similarities or variations between the inputs. Unsupervised learning tasks include cluster analysis, for example. An algorithm does not have a finite training dataset in reinforcement learning but must extract data by sensing and interacting with its environment. Any acts are recompensed, and some are disciplined. Thus, the algorithm strengthens the behavior that results in rewards and prevents actions that lead to sanctions [1, 17].

### 17.2.1 Neural Network

The neural network is an AI technique used for supervised learning tasks. Neural networks began in the 1950s. Initially, the motivation of NNs was the biological investigation of the brain and its billions of neurons which process and transmit data in an extremely intricate network [2, 3].

### 17.2.2 Deep Learning

Traditional AI techniques struggle to proceed as the dimensionality of the input data increases. For instance, in image classification, input images may contain a large number of pixel values. This issue is known as the curse of dimensionality. To address this issue, conventional methods require manual feature engineering of raw data to reduce the input dimension. However, in practice, designating these features from a mass of data is hard without specific domain expertise [4, 5]. This is where deep learning steps in. Deep learning addresses the curse of dimensionality by learning hierarchical representations of the data with complex models of multiple layers. This is accomplished with representation learning. In representation learning, no feature engineering is used. Instead, a model learns on its own which features of the data are significant for the task. When a deep learning model is trained, the model learns conceptual representations of the data by observing data patterns. The first layers of a deep learning model learn simpler features of the data, while the last layers learn more specific features of the data [6, 7]. Why has deep learning become well known? Deep learning models require impressive amounts of data for training. These days, during the era of big data, more and more data is being produced. This is one reason for the change. The more data there is, the better it is for model generalization. Deep learning models are also much larger in size than traditional AI models. The larger size increases their modeling capacity and enables them to tackle complex issues yet increases their computational burden. In light of the computational burden, the use of deep learning was impractical previously. This has changed. Compared to the computing power in the 1990s, the computing power of modern graphics processing units is over many times faster. In addition to the computing improvement, the advances and software used for deep learning have made great progress. ### 17.2.3 Three Activities for Object Recognition

- Classification of the image: Predict the entity form or class of an image.
  - Input: a single entity image, such as a snapshot.
  - Output: A mark of class (e.g., one or more integers that are mapped to class labels).
- Object Position: Locate items in a picture and show their location using a boundary box.
  - Embedding: a picture of one or more items, for example, a frame.
  - Output: Output boxes one or more (e.g., defined by a point, width, and height).
- Object detection: Find in a picture the presence of bounding objects and the groups or groups of objects found.
  - Input: an image of one or more objects, for example, a photograph [9, 11].
  - Output: One or more bounding boxes and a class mark for each box, e.g., specified by point, width, and height.

Another extension of this breakdown of computer vision activities is object segmentation, or “object instance segmentation,” where instances of known artifacts are indicated by highlighting the object’s pixels rather than a rough boundary box [12, 13].

### OverFeat

OverFeat was published in 2013 as one of the key developments in the use of deep learning for object recognition. They proposed a multi-scale computation of the sliding window Convolutional Neural Networks (CNNs) [15].

### R-CNN

Shortly after OverFeat, R-CNN from Girshick et al. was developed at UC Berkeley that virtually partially improved for the task of object detection.

### Recognize All SVMs Locals

Although it achieved tremendous success, the approach had several challenges. To do this, you originally had to make proposals for the training dataset, use the CNN feature extraction (usually taking over 200 GB for the Pascal 2012 dataset) and then train the supervised learning on the last stage [10, 18].

### Fast R-CNN

This methodology quickly evolved into a cleaner deep learning one, when after a year Ross Girshick (currently at Microsoft Research) published Fast R-CNN. Like R-CNN, it used Selective Search to generate object proposals, but instead of processing each of them independently and using SVM classifiers, it applied the CNN to the entire image and then used Region of Interest (ROI) Pooling on the feature map with the final feedforward network for classification and regression [19].

Not only was this approach faster, but having the ROI Pooling layer and fully connected layers allowed the model to be end-to-end differentiable and easier to train. The greatest disadvantage was that the model depended on Selective Search (or some other region proposal algorithm), which became the bottleneck when using it for inference [20, 21].

### YOLO

Not long after that: You Only Look Once (YOLO) paper by Joseph Redmon was published together (with Girshick appearing as one of the co-authors). YOLO has proposed a unified neural network method that has both amazing results and high speed, with the first step being continuous object recognition [22].
