In the following part of this section, the methodology will be briefly introduced. Logistic regression, despite its name, is a linear model for classification rather than regression. It is also referred to in the literature as logit regression, maximum entropy classification (MaxEnt), or the log-linear classifier. This is a standard linear regression formula

```
h_{\theta}(x) = \theta'x
```

where x is a series of features, θ is a vector containing coefficients for each feature and represents the regression output. While in logistic regression, since we need to perform classification rather than regression, the linear regression equation is fitted into a sigmoid function

$$g(z) = \frac{1}{1+e^{-z}}$$ (2.2)

Finally, the logistic regression model becomes

$$h_{\theta}(x) = \frac{1}{1+e^{-\theta^T x}}$$ (2.3)

The function is plotted in Figure 2.10. It can be seen that the range of logistic regression output is between 0 and 1. A threshold, say 0.5, can be chosen to separate two distinct classes (for example, if output < 0.50, predict the case to be in class 0, otherwise predict class 1). After training with the dataset, which aims to find improved θ to minimize the cost function, the model is adjusted to minimize the prediction error based on the training set and the coefficients of each variable.

$$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} y^i \log(h_\theta x^i) + (1-y^i) \log(1 - h_\theta x^i)$$ (2.4)
