## 10.14 Data Streams Clustering by Sensors

Remote sensor networks are deployed independent networks comprised of small nodes with sensors, data processing unit, and wireless communication module. Sensor networks perform reliable operations in different application areas, including environmental monitoring, health monitoring, vehicle global positioning system, military surveillance, and earthquake monitoring. Sensor networks facilitate the process of monitoring the physical environment and make real-time decisions about events in the environment. In such monitoring applications, automated event detection is a fundamental task that aims at identifying new physical phenomena of specific concern to the clients. Specifically, the change in clustering patterns frequently indicates that something significant is happening. For instance, clustering network event streams can assist us with understanding the normal patterns, and attack alerts can be raised if the clustering pattern changes. In an pervasive computing condition, sensors are frequently distributed and, as a rule, embedded in several devices. Information, perhaps as streams, might be emitted from different sensors, and these streams must be collected, combined, stored, managed, and analyzed for different applications. Rather than attempting to stream an enormous measure of information into a central processing facility, we propose to integrate external sources into a network for mobile agent computing. This network of agent processing nodes is a parallel computer for pattern detection. Clustering streaming sensors is the assignment of grouping various sources of information streams due to the information similarity. This process attempts to extract information about the proximity between information created by various sensors through time. The requirements typically introduced for clustering information streams are that the framework must have a compact representation of clusters, must process data quickly and incrementally, and ought to detect changes in the clustering structure. Algorithms aim to find groups of sensors that have similar behavior through time. In the following sections, after an introduction to the flocking model, a methodology for clustering information streams due to a bio-inspired model is described.
