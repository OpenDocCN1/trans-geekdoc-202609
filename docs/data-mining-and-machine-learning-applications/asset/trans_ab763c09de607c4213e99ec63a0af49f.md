
确定每个项目在集群中的注册情况。数值表达式如下。

$$C(i,l)=\frac{\delta_l^{(i)}}{\sum_{k \in L} \delta_k^{(i)}}, \text{ where } \delta_l^{(i)} = \frac{H(G_l^{(i)})}{H(G_l)} \quad (14.6)$$
