## Clustering Methods

As we have seen, grouping is an unsupervised strategy that is helpful when the information is not marked or if there is no reaction values (y) [36]. Clustering observations of a data set involves assigning them to distinct groups, so observations within each group are very similar to one another, while observations in different groups share less in common. To illustrate this technique, we should take a model from advertising. Assume that we have a significant volume of information about customers. This information may include median family income, occupation, distance from the nearest metropolitan area, etc. This data might then be utilized for market segmentation. Our task is to recognize different groups of clients without prior information on shared characteristics that may exist among them. Such division may then be used for fitting advertising efforts targeting explicit groups of shoppers.

There are various clustering strategies to do this; however, the most well-known are k-means clustering algorithm and hierarchical clustering. This section will describe the k-means strategy, a highly efficient algorithm covering a broad range of use cases. In k-means clustering, we need to partition observations into a pre-defined number of groups. Although setting the number of groups before clustering is viewed as a constraint of the k-means algorithm, it is a highly effective procedure. In our clustering problem, we are given a training set of x1, ..., x(m) customers with particular features xj. Features are vectors of variables describing different properties of customers, such as median income, age, gender, etc. The standard is that every observation (customer) should belong to exactly one group and no observation should belong to more than one group, as shown in Figure 18.19.

The concept behind k-means clustering is that a good cluster is one for which the within-cluster variation or within-cluster sum of squares (WCSS) is minimized. Customers in the same category should interact more with each other than with customers from separate classes. Our goal is to computationally minimize WCSS across all pre-defined classes to achieve this design. This task shall be done accordingly.
