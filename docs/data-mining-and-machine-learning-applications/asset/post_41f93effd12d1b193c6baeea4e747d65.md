Note that for mining multimedia information, the combination of at least two information types, for example, text and video, or text, video, and audio, should be performed, which is not a primary strategy [29]. One solution is to develop mining tools that operate directly on multimedia information, as represented in Figure 2.4.

Multimedia information mining refers to the mining of multimedia content. In other words, it is the analysis of large amounts of multimedia data to discover patterns or statistical relationships. When information is collected, computer programs are used to analyze it and search for meaningful associations. This data can be used in marketing to discover consumer tendencies. However, it is predominantly used by governments to improve social systems. Multimedia information mining generally discovers patterns, extracts rules, and refers to information acquisition from multimedia database mining, specifically, from different perspectives [30].

#### 2.2.6.2.3 Mobility Prediction for Delay Reduction in WLAN Using Location Tracking and Data Mining

Prediction of the movement path of a mobile node is important because it reduces handoff delays caused during the handoff process. The proposed framework is called the Predictive Mobility Management scheme. We track the movement of mobile nodes through location tracking and data mining. In location tracking, we continuously monitor the movement of a mobile node. The movement of mobile nodes can be predicted by the movement trajectory of mobile nodes and past path history, which can be obtained through data mining techniques. The data mining technique is used to search the path history of a mobile node, and the method uses this data to predict the future movement of a mobile node. NG pruning scheme can be used for prediction along with location tracking. In NG pruning, we discard examining entries that are not reachable. Thus, scanning delay can be greatly reduced. Using the prediction scheme, we can reduce delays during handoff, track a mobile node, and so on. When a node enters the coverage area, data transmission to the node is directed to the AP selected by prediction where the node will connect.

#### A. Text Mining

Text mining is an emerging new field that aims to collect relevant information from a specific text document. Considering the type of data held in datasets, documents are unstructured, unidentifiable, and difficult to handle algorithmically. In today's society, text is the most commonly known medium for traditional data exchange. The field of text mining generally deals with text whose value lies in actual data or evaluations, and the motivation for attempting to extract information from such material is, of course, compelling, regardless of whether success is quite significant [37].

#### B. Image Mining

Image mining systems that can automatically extract semantically significant information from image data are increasingly popular. The core challenge in image mining is how low-level pixel representation found in a raw image or image layout can be processed to identify high-level structural objects and relationships.

#### C. Video Mining

Video contains several types of multimedia information, such as text, images, metadata, visual, and audio. It is widely used in many important potential applications such as security and surveillance, entertainment, medicine, training programs, and sports. The goal of video data mining is to discover and describe interesting patterns from the massive amount of video data, as it is one of the core issue areas of the data mining research community [38].
