## 8.5 结论

该模型在从客户样本数据集中为交叉销售和升级销售活动分类最佳潜在客户方面非常成功。这些潜在客户的预期购买率大约是样本数据整体预期购买率的七倍。这些潜在客户响应专属活动的预测概率约为 0.97，这意味着 100 个潜在客户中有 97 个可能会对活动做出积极响应。影响客户购买倾向的大多数参数属于服务提供商的“客户体验”类别。
