

# 交通大数据中心建设与发展现状

## 3.4.1 交通大数据中心建设规划

交通大数据中心一期工程将整合市交通委内部数据，包括低碳数据中心、数据机房、公交数据、甲醇车数据、水上搜救等六类数据的整合。二期将整合横向协同数据，包括省交通厅数据、住建数据、气象数据、交管数据、城管数据、停车数据、铁路数据、民航数据。三期将向市政府汇报协调中石化、中石油数据，如智能网联汽车信令数据、移动运营商手机信令数据、新能源汽车数据，实现交通要素“一网通办”。

交通大数据中心建成后，将实现公共交通、综合调度、拥堵指数、车辆需求、建设规划的可视化和综合分析。利用大数据技术对城市客运特征进行定量分析，挖掘城市交通需求热点、分布规律、特征变化等。在交通拥堵、资源配置、执法薄弱等领域形成自处理的预警、预知、预测，构建指导科学决策、智能调度的智慧交通新管理模式。

未来，贵阳将依托市交通委总指挥、协调、协同调度机制，纵向打通省、市、县交通数据服务资源，横向整合水、陆、空、港公共服务信息，形成调度、投诉、监管“三个一指挥”。

贵阳将整合全国交通投诉服务热线 12328 和市长热线 12345，形成融合客运枢纽、公交服务、出租车投诉、执法管理以及城市公共交通拥堵预警预测、交通服务事件监管等对外公共服务职能。完成与公安交管执法力量的综合协调和打非联合执法。协同民航、铁路，形成联程运输、换乘服务等方面的数据融合，推进贵阳综合交通枢纽“零换乘”。

## 3.4.2 数据类型多样，数据资源丰富

我国交通情况较为复杂，涵盖公路、铁路、水运等多种运输方式，将产生海量数据资源。以公路为例，城市道路、高速公路、乡镇道路等路段生成大量数据资源。主要资源类型包括：

- 传感器数据（位置、温度、压力、图像、速度、RFID 等信息）
- 系统数据（日志、设备记录、MIBs 等）
- 服务数据（收费信息、互联网服务等信息）
- 应用数据（厂商、能源、交通、性能、兼容性等信息）

因此，我国交通数据类型繁多，体量巨大。未来，随着人口从农村向城市迁移，交通领域将出现更多视频监控、卡口报警、路况信息、管控信息、运营信息、GPS 定位信息、RFID 识别信息等数据。这些数据量大且珍贵。

多元化数据可为政府部门和企业提供相应支撑。例如，可深度挖掘交通大数据，公安部门可推出车辆轨迹、道路交通、案件聚类等大数据模型。基于大数据模型，可推出车牌识别、车身颜色识别、车型识别、车标识别、年款识别等通用功能，以及遮阳板检测、安全带检测、接打电话检测、驾驶员人脸识别等分析功能，可用于智能跟车分析、轨迹碰撞、人脸比对、舆情分析等。此类数据资源挖掘有助于政府部门逐步解决行业深层次问题。

此外，政府部门可利用交通大数据管理系统获取路况天气、施工情况、事故情况数据，结合大数据分析，还可为驾驶员和交通管理部门提供天气、路况、事故多发点位、停车场等信息。相关服务企业可根据车辆目的地、驾驶习惯、路况推荐驾驶路线。

## 3.4.3 后发优势明显

美国、欧洲、日本的交通大数据技术和经验积累多年，我国具有在先进基础上发展的后发优势。一方面，政府和企业可借鉴既有建设经验和技术，快速转化和应用交通大数据；另一方面，可在此基础上创新和本地化。例如，中国高铁作为“四大新发明”之一，就是在消化吸收引进基础上形成的拥有自主知识产权的高铁产品。

然而，与其他国家和地区交通大数据发展相比，我国交通大数据发展仍存在诸多问题，需政府和企业共同面对和解决。

## 3.4.4 统筹规划不足

我国国情特殊，各省市自治区发展条件不同，导致交通大数据建设过程中目前地方色彩过重。各行政区域独立发展，未形成全国一盘棋局面。因此，在交通数据资源采集标准、存储标准、使用规范、共享原则等方面缺乏国家统一规划。交通大数据发展早期可能气象万千、快速推进，但随着全国联网交通网络形成，跨区域交通联系日益紧密，之前缺乏统一规划将导致发展瓶颈，易形成信息孤岛。

## 3.4.5 政府职能分割导致闭环管理缺失

涉及交通的行政单位众多，如公安部、交通部、住建部等。这些部门在交通管理过程中沟通不畅、各自为政，形成各部门各有要求、各有标准的管理混乱局面。
