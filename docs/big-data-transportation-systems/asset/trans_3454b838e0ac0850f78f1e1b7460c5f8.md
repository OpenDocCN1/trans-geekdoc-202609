
# 对于中央新批准的雄安新区，政府主导以智能公共交通为主要出行方式进行建设。

据“雄安发布”微信公众号2017年10月14日报道，雄安新区与百度集团举行了对接会。双方就大数据、人工智能、云计算等潜在合作领域进行了对接。

河北省委常委、副省长，雄安新区党工委书记、管委会主任陈刚表示，雄安新区是一座白纸上建设的新城，要把这张蓝图画好，需在信息技术与智慧城市发展融合上实现突破。

未来，雄安新区将实施以智能公共交通和无人驾驶私家车个性化驾驶行为为基础的出行方式，这将构成雄安新区未来的路网结构和空间配置模式。雄安新区未来规划建设的核心理念之一是把城市还给人民，从按汽车尺度设计城市和道路的传统方式，转变为按人的尺度设计，从而把城市还给人民，把道路和空间还给人民。百度集团在智慧城市建设、大数据、自动驾驶等方面具有领先优势。欢迎百度筹备在雄安新区建设开放型、国际化的国家级人工智能实验室和高端应用研究机构，特别是建设无人驾驶高新技术产业示范区。

百度集团总裁兼首席运营官陆奇表示，百度集团希望在智慧城市规划设计、信息基础设施建设、智能产业试点示范等领域深化与雄安新区的合作。^([3](#ch01.xhtml#fn3))

从雄安新区的建设可以看出，在传统交通系统中，由于技术等因素，人、车、路无法统一、协调、融合，整个交通系统的效率和安全无法得到保障。在智能交通系统中，我们运用信息技术、数据通信传输技术、电子传感技术、卫星导航定位技术、电子控制技术、计算机处理技术和交通工程技术，这些技术能够实现集成与融合。传统交通系统的短板与难点被逐一攻克，人、车、路的协同更加紧密。交通效率得到提升，交通安全得到保障，交通环境大幅改善，能源效率大幅提高。

## 1.2.2 智能交通中的大数据

智能交通之所以区别于传统交通，在于其“智能性”。先进的信息技术、数据通信传输技术、电子传感技术、控制技术、计算机技术以及大数据技术，保障了交通系统在指挥调度中能发挥更强大的作用，能比传统交通系统更主动地预测风险、防范各类突发事件。

大数据技术为此价值提供了有力支撑。

随着社会经济的快速发展，全球交通将面临越来越复杂的局面。随着机动车增加，城市化发展导致交通路网系统失衡，传统交通信息系统已无法满足当前交通形势。例如，在北京、上海、深圳等一线城市，交通拥堵已成为全城治理的难题。

然而，通过汇聚各类分散的交通数据形成“数据池”，并利用大数据技术处理数据，我们可以分析出一些交通趋势、需求、难点等。再通过精细的数据处理和图像处理，形成交通建议和决策。例如，某些人对某路段有特定的信息需求，虽然需求人数和占比似乎很小，但通过大数据技术处理和汇聚其他类似需求，可以形成特定的个性化服务。在此基础上，交通管理系统将更加智能。

大数据让交通管理更智能，体现在以下几个方面。

第一，跨行政区域的数据将被整合，交通管理将突破以往行政区划的限制，建立全局“一盘棋”管理意识。这将有助于政府部门更有效地开展交通设施建设，更合理地进行交通路线规划。

第二，大数据技术能合理配置交通信息资源，提高信息利用效率。目前我国交通部门职责存在重叠，部分职责界定不清。利用大数据技术，可合理配置人力物力资源，协助相关部门做出更合理的总体规划，使交通信息利用率更高，交通管理更智能。

第三，大数据技术改变了以往的交通管理思维模式。在传统交通管理思维中，遇到拥堵就采取拓宽道路、增加里程的措施来提高通行能力。事实上，这种管理往往目光短浅。土地资源是不可再生资源，拓宽道路只会浪费更多土地。而且，在交通高峰期，拓宽道路也无法解决所有问题。通过大数据技术的分析整合，我们可以清晰掌握拥堵的时段、地点、原因，从而因地制宜、合理疏导治理，减少对土地、空间等资源的依赖，实现交通设施与系统的良性循环。

我们可以通过观察长沙智能交通建设来理解大数据在智能交通中的价值。

目前，长沙在交通信息化方面主要建设了“两个平台、六大系统、五个应用软件”。2016年3月，智能交通三期建设启动，由青岛海信网络科技股份有限公司承建，并与百度、高德等互联网公司签订了数据交换协议，以科技手段助推交通管理。

目前，长沙所有交警业务均可通过手机APP办理，包括车价、违章扣分查询等。下一步，可通过手机APP查询周边停车场信息及停车容量。
