

# 9.2 大数据交通与上海世博会

2010年，上海世博会是北京奥运会后中国举办的另一项重大活动，同样吸引了全世界的关注。与北京奥运会相比，世博会的影响范围更广，不再局限于体育领域，涵盖了世界上大多数国家的文化，因此参观人数更多。据数据显示，共有46个国家和国际组织参加了上海世博会，接待游客7308.4万人次，日均39.7万人次，创造了世博会历史纪录。

与2008年北京奥运会相比，大数据经历了两年的发展，其技术能力更加成熟。因此，上海世博会进一步改进了大数据的应用，特别是在预测等方面。大数据发挥了关键作用，为世博会期间更好地服务交通奠定了基础。

## 9.2.1 大数据预测

在上海世博会正式开幕前，上海交通大数据已正式开始运行。通过与票务平台、酒店、餐饮等机构的合作，逐步掌握了上海世博会期间的相关数据。上海大多数商业机构均接入了大数据系统，数据能够在最早时间进行统计。

同时，汽车4S店的销售数据也纳入了大数据系统，完善了相关信息。借助这一大数据模型，上海交通部门对世博会期间的交通进行了预测：2010年，上海交通量将达到5000万人次/天，汽车保有量将达到160万辆。在高峰期，8号线、6号线等轨道交通线路将面临巨大挑战，特别是在世博会期间，9月至10月的交通压力将进一步增加。

通过大数据，上海交通部门对世博会期间的交通运行情况有了初步判断。因此，根据数据，相关部门制定了以下交通建议：

1. **倡导乘坐公交出行。** 为应对道路交通压力，世博会开幕前，上海持续呼吁鼓励游客当时使用公共交通，特别是公交车。交通部门希望超过90%的游客能通过轨道和地面公交参观。

2. **均衡入园。** 借助大数据分析，我们可以看到世博会客流在周末和节假日达到最大。由于这些时段酒店预订率高，我们提前制定了“均衡入园”策略，将客流从高峰日引导至平日，并制定了详细方案。鼓励游客从高峰时段向平峰时段出行，从浦西向浦东入园，以缓解交通压力，让全球游客真切感受上海世博会的魅力。

3. **适当的管理措施。** 为减少世博会交通与日常交通的相互影响，上海交通部门还发布了其他管控政策，包括车辆使用管理和施工区域管理，以避免交通压力失控。

正是通过大数据的应用，上海交通部门发现了可能出现的问题，并制定了这三项交通管理方案。这三项方案确立了世博会交通管理的基调，并通过大数据进一步优化，使工作更加精细。

## 9.2.2 大数据智能系统的利用

为更好地服务世博会，上海交通管理部门基于大数据建立了智能交通综合信息平台和世博园区交通信息分平台，提供智能化服务。世博会大数据平台的特点是数据处理能力强，不仅供内部使用，也面向所有游客。当大数据监测到前方道路明显拥堵等交通问题时，会立即向世博交通向导、世博交通网站、交通服务热线、广播电视台、可变信息标志、手机车载导航终端发送相关信息，持续提醒游客并提供换乘方案查询等服务。同时，该系统还与一线交通指挥员关联。交通指挥员也能随时随地获取园区交通信息，以便尽快开展交通疏导工作。与北京奥运会相比，世博会大数据平台有了显著提升。大众可通过互联网快速查询相关信息，而无需等待信息标志的提示。

围绕大数据平台，上海世博会将大数据智能交通推向了极致。这类应用有四大亮点，为未来大型活动提供了极好的参考。
