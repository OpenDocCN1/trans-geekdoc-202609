
# 智能交通管理模式与出行方式分析

建立智能交通管理模式应以人们的出行模式为基础，并需突显其人性化与智能化考量。从出行用户数量的角度来看，人们的出行模式可分为两大类。

## 1. 自由出行
在自由出行模式下，个体出行者对出行工具拥有完全独立的控制权和使用权，可自由分配其内部空间设施，能够满足人们的个性化出行需求。

## 2. 共享出行
在共享出行模式下，两名或以上出行者共同使用一件出行工具，彼此相互影响。内部空间与设施的分配受到一定约束，同时也涉及一定的隐私保护问题。严格来说，只有个体自驾出行才算作自由出行。

## 3. 特殊情况：乘坐出租车
自由出行与共享出行存在一种共同的特殊情况。当一个人独自乘坐出租车时，出租车司机与出租车一样属于服务提供者，而非共享使用者。出租车司机本人是具有独立意识的独立个体，乘客无法忽视其存在，因此乘客的自由度会受到限制。若遇到不道德的出租车司机，乘客的人身财产安全可能受到威胁。

## 4. 优势对比
- **自由出行**的优势主要体现在便利性、安全性和舒适性；
- **共享出行**的优势主要在于低成本、绿色环保，能有效减少城市汽车总量，缓解交通拥堵和停车难问题，提高资源利用效率。

在特定经济条件下，大多数人倾向于选择自由出行，共享意识有待提高。

## 5. 按出行工具所有权划分
从出行工具所有权的角度来看，可进一步将人们的出行方式分为两类：**私家车出行**和**公共出行**。当人们使用的车辆所有权不属于使用者本人时，即视为公共出行方式，例如：出租车、网约车、公交车、地铁、通勤巴士、面包车，以及使用家人或朋友的私家车。

处于载人驾驶状态下的公共出行，以及两人及以上共享私家车的出行，均不属于自由出行。随着无人驾驶技术的成熟发展，乘坐无人驾驶出租车将类似于自驾出行，从而成为真正的自由出行。

换言之，**无人驾驶出租车**将实现自由出行与公共出行的深度融合，让人们在享受自由出行的便利、舒适、安全优势的同时，也能获得公共出行的低成本、绿色优势。考虑到无人驾驶汽车早期发展阶段价格较高、用户有限，以及无人驾驶出租车可降低人力成本，其率先大规模投入市场应用成为顺理成章之事。

# 12.4.2 无人驾驶出租车与自由出行模式

2016年8月，新加坡出租车初创公司 `nuTonomy` 在新加坡开展无人驾驶出租车试运营，符合条件的乘客可通过智能手机呼叫服务。试运营阶段投入6辆无人驾驶出租车，12名乘客获得体验资格，运营范围限制在2.5平方英里的商住区内，且乘客须在指定地点上下车。根据 `nuTonomy` 的规划，随着更多无人驾驶汽车投入使用，新加坡汽车总量未来将从90万辆减少至30万辆。2017年10月，`Delphi Pike Electric` 宣布以4.5亿美元完成对 `nuTonomy` 的全资收购。

对于新加坡这类国土面积小、经济发达的国家，推广无人驾驶出租车的难度相对较小，其应用将给人们的出行带来诸多便利，对缓解交通拥堵有着积极影响。值得注意的是，公共交通是新加坡交通体系的核心组成部分，无人驾驶出租车的应用并非要完全取代传统出租车，而是进一步完善它。新加坡发布的未来交通发展规划预期，到2025年，公共交通将承担新加坡高峰时段高达75%的出行服务。

`Uber` 等公司不仅在新加坡，还在加利福尼亚、密歇根、匹兹堡等多个城市测试无人驾驶汽车，尝试推出无人驾驶出租车服务。特别是对于 `Uber` 这类网约车公司而言，应用无人驾驶出租车后，平台能为人们的日常出行定制设计完美的出行方案。通过智能系统可有效预测人们的出行需求，实现车辆资源的高效调度；更重要的是，结合大数据与云计算技术，可对不同区域的交通资源分配进行针对性调整，以更好地满足高峰出行需求、降低空驶率。

滴滴研究院联合 `Uda Xue Cheng` 与 `Zhihu` 举办的算法大赛口号是：“改变世界的梦想可以成真，你的算法将用在真实的出行世界，也许有一天你能说，‘在这座城市里，我的算法掌管你选择坐哪辆车’”。如果无人驾驶出租车能大规模推广普及，人们将不再需要购买、维修、定期保养私家车，从而消除停车难、车险、拥堵、故障、途中事故等各类问题，这高度契合人们对美好生活的向往。

儿童、老年人、残疾人及无驾照人群也可通过无人驾驶出租车享受出行自由，这将大幅减少私家车数量，有助于环境保护、减少交通事故、提升出行效率与体验。

科学研究发现，若无人驾驶出租车作为城市机动出行的主流模式推广，并严格限制私家车数量，则城市车辆总量将减少近50%，停车占地面积减少40%，事故率降低约90%。若无人驾驶汽车升级为电动及其他新能源车型，车辆尾气排放将减少约80%。届时城市将拥有更多空间提升居民生活品质，例如建设更多公园、足球场等公共休闲设施；自行车道也可拓宽。

为解决市中心空气污染问题，挪威奥斯陆将在2019年前实现“零私家车”；西班牙马德里宣布到2020年将禁止车辆进入约2平方公里的市中心区域。当然，为满足人们的个性化出行需求，私家车在相当长一段时间内不会消失，但体验驾驶私家车的自由不一定非要购买私家车，未来可能会出现一些长期租赁无人驾驶汽车的服务提供商。
