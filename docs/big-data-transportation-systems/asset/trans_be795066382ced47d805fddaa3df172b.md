

# 简介

本书旨在作为一本关于交通大数据的科普读物。首先向读者概括介绍交通大数据，随后从全球视角阐述各国交通大数据的发展情况，包括战略、现状、行动、优势等，最后解释相关概念与技术基础，阐述交通大数据创新的广阔前景。在阐释概念之后，从实践角度探讨如何利用交通大数据。首先探讨大数据的来源（这是基础），并分析互联网企业入口之争的目的，继而探讨交通大数据平台的应用。最后，详细阐述交通行业中物流、公共交通、交通事故等领域的大数据痛点、应用案例、商业模式及运营经验。

本书定位为大数据交通科学的大众读物。

其旨在让读者对大数据交通建立直观的场景感知。从全球视角介绍各国大数据交通的发展，包括战略、现状、行动、优势等，阐明相关概念与技术基础，并从创新视角补充大数据交通创新的广阔前景。这有助于我们建立对大数据交通的基本认知。

在建立大数据交通认知的基础上，我们应从实践角度考虑如何应用。大数据的来源是大数据交通应用的基础。同时也分析了互联网企业争夺入口的目的。在探讨数据之后，将研究大数据交通平台的应用。书中还详细描述了交通行业中涉及痛点、应用案例、商业模式、运营经验、物流、公共交通和交通事故等大数据具体领域。还可增加不同层级的更多交通平台，如县级、三四线城市级，使不同岗位的人员都能有自己的参考和启发案例。

# 第一部分：认知：理解大数据

第一部分涵盖对大数据交通的理解，包括大数据交通的各种应用场景、国外大数据发展现状、大数据交通概念的阐明、安全问题以及创新的本质。

# 第一章：什么是大数据交通？

所谓大数据交通，是指通过互联网技术和大数据技术，利用数据处理工具对交通行业产生和沉淀的数据进行处理、分析和运营，从而产出更有效、便捷、高价值的交通、优化和治理方案，给人们出行带来便利，提高交通效率，节约能源资源，减少污染排放，并优化产业结构。

## 1.1 大数据交通与互联网+

### 1.1.1 大数据来势汹汹

随着工业社会向信息社会迈进，人类所有成果均以二进制信息的形式存储和传输，信息被转化为数字形式。有学者将人类社会的信息化进程划分为三个时代，即计算机时代、互联网时代和大数据时代。^([1](#ch01.xhtml#fn1)) 随着信息技术革命的兴起，互联网、移动互联网、社交网络、物联网、车联网、智能手机、平板电脑等信息技术的完善与普及，人类产生的数据呈指数级增长。

MBA在线网站发布的信息图表显示，每天发送2940亿封电子邮件，在线发布200万篇博客，上传2.5亿张照片到Facebook，上传864万小时视频到YouTube，在流媒体音乐网站Pandora上播放1.87亿小时音乐会。^([2](#ch01.xhtml#fn2)) 根据IBM的分析，人类文明获得的所有数据中，90%是在过去两年内产生的。到2020年，全球产生的数据规模将达到当时的44倍。

根据国际数据公司（IDC）的一份研究报告，在未来十年，全球大数据将增长50倍，到2020年，世界将达到35泽比特（约3.5 × 10位）的数据信息量。涌现的数据类型繁多，数据在通信网络中快速传输，待开发的数据数量不断增加。人类社会正式步入大数据时代。
