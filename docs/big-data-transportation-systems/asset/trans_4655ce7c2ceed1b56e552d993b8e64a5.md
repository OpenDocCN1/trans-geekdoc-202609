

# 2.2 大数据交通之高铁出行

随着中国高铁网络的密集分布，中国人选择高铁出行的频率越来越高。根据中国铁路总公司的相关数据统计，自2008年京津城际铁路运营以来，至2017年9月30日，中国高铁动车组已累计输送旅客超过70亿人次，年均增长率超过35%。要知道，根据不完全统计，世界总人口也不超过73亿人。如果按中国高铁每年输送旅客20亿人次计算，到2018年，累计输送旅客人数必将超过世界总人口数。

中国高铁建设速度之快令人瞩目。仅2012年至2017年短短五年间，京广、沪昆、哈大、贵广、兰新（乌鲁木齐）、海南环岛等一批重点高铁项目相继建成通车，“四纵四横”高铁网基本形成。从北方小城到南方海滨三亚，从西部新疆到东部沿海，高铁如同人体动脉般连接起祖国大地。据统计，中国高铁与其他铁路共同构建了4万公里以上的快速客运网络，基本覆盖了全国省会城市和人口50万以上的城市。长三角、珠三角、环渤海等城市群通过高铁联系更加紧密，东、中、西、东北四大板块实现了高铁互联互通。

高铁如此便捷高效，人们的出行自然更加智能。但庞大的高铁网络需要大数据技术进行统一管控。一旦某个节点出现故障，都可能影响后续列车运行。往年常有高铁调度问题导致后续列车晚点的新闻，但现在此类报道已很少见。因为中国交通网络系统日益完善，大数据技术愈发强大，能够保障高效复杂的高铁网络运行。

我们可以从同程旅行和中国交通报联合发布的《2018年春运大数据报告》中窥见一斑。

2018年春运预计铁路发送旅客3.93亿人次，同比增长10%，远高于公路运输的1.1%。随着人们消费观念的转变和民航运力的增加，春运期间选择民航出行的消费者越来越多，2018年预计发送旅客6700万人次，同比增长14%，增幅在三大运输方式中居首位。^([3](#ch02.xhtml#fn3))

铁路发送旅客人数同比增长10%，这与高铁线路的逐步投入使用密不可分。目前，中国拥有2700多列动车组，日开行列车4500列以上，居世界首位，累计发送旅客超60亿人次。以京沪高铁为例，运营六年来已安全输送旅客6.72亿人次。

高铁出行是重要的交通方式，其在大数据中的应用与实践主要体现在以下几个方面。

## 2.2.1 智能化

无论是购买高铁票还是乘坐高铁检票，高铁网络都变得越来越智能。例如，北京西站已开通人脸识别系统；旅客刷身份证进站，再通过人脸识别系统检票进闸。检票仅需1-2秒即可完成。这些过去需要人工完成的任务，如今让出行效率大幅提升。

## 2.2.2 自助服务

自助服务背后实则是智能化的体现。旅客可根据出发地、换乘点、出发时间等信息，通过自有APP自主查询订票，不仅提高了效率，还节省了人力物力。高铁还开通了订餐、订票等功能，让旅客在出行过程中更加便捷、绿色。

## 2.2.3 低成本

虽然高铁票价远高于普速列车，但从社会整体经济价值和时间价值来看，高铁节省了出行时间，提高了单位时间经济价值，降低了消费者的出行成本，如下新闻所述。

高铁发展也带动了大城市周边地区的经济商贸活跃。在金融行业工作的陈先生，在候车大厅用两部手机和一台笔记本电脑处理邮件。因工作原因，他每周需多次往返北京和天津武清。北京至武清约90公里，自驾无堵车也需1个多小时，而高铁仅需24分钟。“高铁省时省力。开车很麻烦，尤其是在北京，一开车就可能堵车。坐高铁没堵车风险，不用耽误工作。开车成本太高，其实油费加过桥费远超高铁票价。我来回才花70多元，开车成本肯定比这高。”^([4](#ch02.xhtml#fn4))

## 2.2.4 安全性

在准点率和乘客人身安全方面，高铁出行比航空和公路出行具有更明显的优势。

中国拥有世界上总里程最长的高铁和公众出行频率最高的高铁。高铁出行将持续改变人们的出行方式，进一步提高交通效率，便利生活，减少环境污染（见图[2.2](#ch02.xhtml#fig2.2)）。所有这些都与交通大数据网络密切相关。可以说，高铁网络就是一个数据网络。在海量数据的支撑下，高铁才能做到极致便捷、高效、安全。
