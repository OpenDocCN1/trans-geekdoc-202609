

# 大数据分析重塑贵阳城市交通

正是通过此类大数据信息分析，贵阳市对城市交通进行了彻底变革。贵阳位于山区；与平原城市相比，其基础交通建设相对落后。尽管近年来建设力度加大，但随着人口、机动车和房地产的快速发展，交通拥堵、停车难等问题日益凸显。

为解决这些问题，2014年，贵阳交通部门引入了大型数据库软件，如 `MySQL` 数据库，并开始对269个交通监测点的大数据进行筛选。结果，这一大数据应用取得了显著成效。2014年9月1日至13日，大数据累积了1.54亿条原始数据。通过大数据库的筛选，贵阳的交通特征被迅速发现。

例如，根据“黄金路与枣山路交叉口”的大数据调查发现，该路段每天早上6:00交通流量显著增加，在8:00–9:00达到高峰，期间近8000辆车通过。从10:00到19:00，一直处于高峰的交通流量略有减弱。22:00又出现一个小高峰。

过去，仅靠基层工作人员的调查无法实现此类数据分析。但凭借大数据强大的计算能力，数百台监测设备协同工作，很快便找到了贵阳各路口的交通数据。有了这些数据，城市交通的变革便能精准有效。

经过数天的大数据分析，贵阳交通部门发现了一些问题。例如，私家车保有量过高，占比超过70%，这意味着贵阳公共交通存在明显短板。未来，公共交通的发展必将成为重点，以有效缓解交通拥堵问题。特别是对一环路及一环路内路段的监测发现，此处路口是拥堵的主要地点，也是未来解决问题的主要方向。同时，与其他城市相比，贵阳并非仅有早高峰拥堵的简单城市。贵阳的拥堵全天候且延续至午夜前，因此照搬其他城市经验并不奏效（见图 [10.1](#ch10.xhtml#fig10.1)）。

有了此类数据分析，贵阳的城市交通变革必须有的放矢，而非盲目增加公交车或拓宽道路。

这种大数据分析模式可在各城市有效推广，为交通提供最直接的数据。例如，公交卡可积累海量乘客出行数据，通过数据分析可找出乘客主要流向和集中站点，从而建立公共交通模型，有效制定应对方案，科学配置运力。

## 10.3 大数据交通的技术变革

大数据与交通的结合并非一成不变。随着大数据技术的持续进步，交通管理技术也在不断变革中，以适应时代发展。因此，对于基层交通部门而言，有必要持续升级大数据技术、采购新型大数据检测设备，以使工作持续改进、始终符合时代发展要求。

### 10.3.1 硬件设备升级

早期的大数据检测往往只是给传统交通设备加装视频拍摄功能和数据回传功能。但随着技术的持续创新，硬件设备有了显著提升。特别是这些硬件设备的应用，为大数据检测提供了更丰富的手段。

(1) **物联网传感器**。与传统传感器相比，物联网传感器的信息采集内容大幅提升。交通管理部门在路面嵌入物联网传感器，可在移动设备上实时观测车辆通行量和客流信息，并监管车辆尾气排放。物联网传感器可实现多车辆数据同步采集，效率更高。这为指挥交通管理系统奠定了基础，并能更高效地采集数据。

(2) **卫星地图应用**。过去，卫星地图数据不向公众开放，多属军事用途。但随着大数据在商业和民用领域的广泛应用，卫星地图也可有效用于交通管理。因此，交通管理部门应尽快接入卫星地图，通过卫星实时捕捉路况制定相应策略，以开展交通规划和道路规划。

(3) **智能手机应用**。对公众而言，大力倡导智能手机的大数据应用也能有效解决交通问题。智能手机已普及应用。它们可轻松与交通管理部门的相关平台链接互动，如 `WeChat`、`Weibo` 及相关 `APPs`。同时，`GPS` 定位和 `北斗` 定位系统的应用，使地图供应商能在自身大数据应用中发挥良好作用，首时间为乘客和车主推送路况拥堵及出行趋势。这些信息可优化路网。

基于这三大技术变革，智能红绿灯、大数据售票平台等技术已趋成熟。企业和政府部门均开始利用这些技术变革红利转型交通行业。主动将先进技术引入交通系统，将为交通管理带来新局面。

### 10.3.2 新大数据技术变革

大数据技术仍在更新，为交通管理带来新变化。例如，当前主流智能大数据交通技术主要使用路口监测设备和电子警察。实现车辆抓拍、车牌识别等工作仍属传统技术范畴。虽能快速分析车辆，但难以深度挖掘。传统算法使大数据交通遭遇瓶颈。

新大数据技术呈现出此类特征：通过拍摄照片，可检测年检次数、年检标志形状、车窗是否悬挂危险物品、驾驶员是否有违规行为。例如，北京图存科技院所研发的智能交通识别算法可实现上述目标，助交警部门快速获取路况信息。一旦发现问题，数据将尽快存储，为公安后续办案提供有力证据，督促驾驶员规范自身行为，进一步保障交通安全。
