
# *大数据交通系统*

*大数据交通系统*为我们观察和利用大数据带来了全新的视角，这得益于赵光辉博士从密歇根大学归来后的辛勤耕耘，以及朱古生教授对中国交通事业的持续关注。我曾为他们合著的《“互联网+”交通》一书作序。本书《大数据交通系统》描绘了交通发展的新阶段。在中国建设交通强国的战略背景下，这种前瞻性研究、学者与交通一线工作者的互动，以及学者为世界交通发展做出的贡献，显得愈发必要。每个人都应有其人生目的，因为你的存在会影响社会和身边的人。无论扮演何种角色，每个人都能为世界带来改变。我希望赵博士继续努力、勤奋工作，把握世界重大技术变革，顺应世界潮流，以其国际视野、博大胸怀和非凡智慧，为交通强国梦提供更多研究成果，为读者奉献更多著作。

我相信，凭借中国交通领域人才的智慧和世界各地人才的贡献，中国的交通大数据未来必将更加先进。中国将更接近建设世界交通强国的目标，凭借大数据推动中国交通发展的前景也将更加光明。

倪军

*美国密歇根大学*

2017年12月12日

## 前言

大数据是一个备受全球瞩目的热门领域，因为它将深刻改变人们的工作和生活方式。其巨大的应用潜力已在许多领域得到充分体现。通过应用大数据技术，菜鸟物流建立了由“天网+地网+人网”支撑的中国智慧物流骨干网；[toutiao.com](http://toutiao.com)积极构建具有个性化设计、覆盖面广、投入产出比高的智能推荐算法；亚马逊专注于开发智能化、互联网化、自动化的智慧供应链管理系统。大数据在交通领域的应用也备受期待。交通大数据是指采集具有大规模、多源、多类型、结构复杂、价值密度低等特征的数据。通过运用大数据技术和分析方法挖掘其关联性和共性规律，可以为相关部门的管理决策提供有力的数据支撑，加速智能交通和智慧城市的成功实施。

虽然中国交通事业起步不长，但凭借后发优势取得了显著进步。作为一个幅员辽阔、地形气候条件复杂、地理差异巨大的国家，中国经过多年的实践，在基础设施项目的研究、设计、试验、建设、养护和管理方面积累了丰富经验。我们攻克了在高原冻土、膨胀土和沙漠修建公路和铁路的世界性难题，高铁已成为“中国制造”的新名片并走向世界。然而，作为支撑国民经济发展的基础性、先导性、服务性产业，交通运输业是一个庞大而复杂的系统。要赶上日本、欧洲、美国等交通强国，绝非易事。发展交通运输业，光靠投入资金远远不够。我们不仅需要提供充足的人才、资金和技术，还需要在顶层设计上制定科学合理的战略规划、有效的实施方案和全面的长效保障机制。

毫无疑问，中国各级政府高度重视交通运输业的发展。在他们的努力下，公路和铁路里程快速增长；公共交通体系和地铁建设有序推进；在地方政府的支持和引导下，网约车、共享单车等“互联网+交通”新模式也蓬勃发展。然而，总体而言，中国交通运输业仍处于发展的初级阶段。区域发展不平衡、产业互联互通缺乏、信息技术滞后，导致了交通拥堵、交通事故频发、运输效率低、成本高等诸多问题。这些问题给人们的工作生活带来不便，也制约了中国经济平稳健康增长。交通大数据的出现，为解决上述问题提供了有效途径。

美国、英国等发达国家对大数据在交通领域的应用进行了深入研究和实践，在缓解交通拥堵、恶劣天气应急响应、路况分析预测等方面取得了良好成效。中国各级政府正努力追赶，在北京、上海、杭州等地积极探索应用，为全国树立了良好榜样。事实上，中国在推进交通大数据进程中投入了大量资源。但由于缺乏总体战略规划，重复建设、资源利用率低等问题尤为突出。同时，大数据人才极其匮乏。即使在发达国家，此类人才也是稀缺资源，因此大数据理论与应用研究仍相当有限。中国既懂大数据技术和分析方法又懂交通的复合型人才更是凤毛麟角。
