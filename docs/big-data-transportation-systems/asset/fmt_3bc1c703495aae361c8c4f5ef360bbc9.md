
# 前言

2017年5月10日，我和我的学生赵光辉博士在杭州AIMS探讨了智能交通发展相关问题。随后，他计划撰写一部关于交通大数据的著作。我告诉他，密歇根大学拥有世界领先的智能交通实验室。他们花费数年时间试图优化密歇根大学旁边的几个红绿灯。之后，他们来到中国的一个大城市，开始利用大数据管理红绿灯，开展交通大数据实验。在传统摄像头和感应线圈的帮助下，红绿灯通过人工操作每90秒切换一次。通过分析发送到监控室的拥堵数据，利用人工智能调整红绿灯。两个月后，该城市高峰时段的拥堵缓解了20%。未来，世界上更多的城市将通过大数据优化红绿灯，这将有助于最大限度地利用有限的道路资源，节约大量时间和交通资源。此外，中国有1.5亿至2亿辆私家车。这些车每天约有95%的时间闲置在停车场。它们占用大量空间，浪费资源，并导致拥堵。借助大数据，这些闲置资源可以被调动起来，服务于需要乘车的人们。这种实践将做出多大的贡献啊！

读完赵光辉博士和朱谷生教授合著的这本书稿后，我深信大数据技术已经推动了中国交通的发展。书中涵盖的例子包括交通大数据源的采集、交通大数据平台的应用、交通物流、公共交通和交通安全的痛点、案例及商业模式、运营经验，以及其他国家交通大数据的现状、策略和行动。赵博士提出，交通大数据改变了中国社会的出行模式，从过去的“找车”转变为现在的“安排车找人”。通过分析雨天、晴天、高峰时段、平峰时段、工作日和节假日的数据，可以预测在这些情况下特定地点未来的出行状况和客流量。准确率现已达到85%–90%。可以提前15分钟做出决策，将车辆调度到指定地点。凭借提前15分钟的调度、路线规划和定位，网约车给人们带来了极大的便利，这是以前难以想象的。现在人们已经习以为常。

匹配乘客和车辆的努力并非唯一应用。由于大数据，匹配人和物资的努力也发生了巨大变化。2017年11月11日24:00，天猫当天销售额达到1682亿元。其中，网购贡献了90%，买卖双方覆盖222个国家和地区。在“双11”前，卖家利用大数据预测快递包裹量将比2016年增长30%以上，大数据预测“双11”当天包裹量将达到1.4亿个，将有170多万快递员参与物流。通过加强协同和数据共享提升物流服务，面单覆盖了全行业80%以上。这是大数据预测首次覆盖行业一半以上的快递包裹，通过大数据与社会协同的连接提高了效率。在物流预警雷达升级的基础上，大数据平台已从时间段预测全面升级为实时预测，覆盖中国50%以上的快递包裹。算法优化使更多维度的大数据得以应用。结果，每日包裹派送量的实时预测成为可能，准确率超过90%。这些数据可帮助快递合作伙伴部署运力，企业可根据预测数据提前准备运力。因此，努力增加了4000名临时工和5240辆货车，并提前增加了飞机租赁吨位。“大数据分单路由”可根据面单信息自动计算配送路径，将包裹分配给离买家最近的网点。超过50%的包裹通过大数据分单路由更快地送达买家。卖家利用大数据预测各类畅销商品，在全国仓库管理库存，使包裹尽可能离买家更近。通过使用大数据预测包裹量，商品能尽早送达买家。模式从“买家等包裹”转变为“包裹找买家”。
