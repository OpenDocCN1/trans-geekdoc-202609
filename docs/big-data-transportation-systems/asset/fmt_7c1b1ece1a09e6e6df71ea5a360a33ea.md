
# 无人驾驶汽车的安全性与发展

当驾驶员与车辆争夺控制权（交通事故）时，交通部门难以判定事故责任方。若要求驾驶员在车辆行驶时保持警惕、随时准备切换至人工驾驶模式，不如直接采用人工驾驶。这种“人或车”设计使无人驾驶失去意义，增加驾驶员心理负担，让自由舒适驾驶的愿望落空。

从本质上讲，“人或车”设计是对无人驾驶安全性的不负责任表现。若存在人工驾驶这条“后路”，相关人员就不会专注于无人驾驶安全问题，无人驾驶汽车的设计制造统一标准短期内无法建立，用户安全无法得到有效保障。

2016年5月7日，开启自动驾驶辅助系统的特斯拉 `Autopilot` 行驶中与一辆白色牵引拖车相撞，`Autopilot` 车顶完全毁坏，驾驶员当场身亡。特斯拉解释称：白色卡车在蓝天背景下未被识别，且从 `Autopilot` 视角拖车侧面悬空，导致系统误判未启动自动刹车，引发碰撞。又因碰撞位置在 `Autopilot` 挡风玻璃处，碰撞安全系统失效，致驾驶员当场死亡。

该事故引发轩然大波，因特斯拉曾宣称美国每 9400 万英里发生一起致命交通事故，而 `Autopilot` 辅助驾驶系统行驶已达 1.3 亿英里。特斯拉强调无人驾驶技术持续演进，`Autopilot` 并不完美。究竟谁该为此负责？有人认为是特斯拉，有人认为是疏忽的驾驶员，也有人认为是传感器供应商 `Mobileye`。这种对无人驾驶交通事故的认知，让人联想到特斯拉与爱迪生的交流电之战。

1880年，特斯拉发明世界首台交流发电机，爱迪生发明电椅以宣传交流电危险。经过激烈角逐，特斯拉交流电胜出，为人类文明发展做出杰出贡献。凡新事物皆利弊共生，无绝对优劣。面对无人驾驶汽车这一新事物，应把握发展趋势，不因单一事故全盘否定。

## 如何解决无人驾驶汽车安全问题？

为减少无人驾驶车辆行驶中的交通事故，厂商应建立严格的车辆定期回厂维护制度和行驶应急处置服务体系，重点建立“双系统”控制模式，解决车辆网络可能遭破坏的问题（如黑客入侵、病毒破坏等）。“双系统”中主系统指联网开放系统，备系统指独立闭环系统。驾驶员一旦发现主系统被破坏，可立即切换至备系统，确保车辆正常运行、人员安全下车，随后送修。

若主系统受损驾驶员未察觉（如系统代码被篡改导致遇障碍物不绕行反撞击），驾驶员可能来不及切换系统而酿成事故。因此，厂商必须为无人驾驶汽车安装防护软件，使车辆能自动检测故障、查杀病毒，并对因防护不力导致的交通事故承担责任，避免厂商推卸责任损害用户权益。此外，厂商还应确保车辆内外部接口难以拆卸篡改，防止人为破坏，有效提升安全性能。

此外，若交通部门规定无人驾驶车辆必须随时可切换至人工驾驶模式，最适合引入无人驾驶车辆的公交、出租公司将彻底失去“免人力”优势。原因在于：若不配备全职驾驶员，公司须先核查用户驾照、饮酒、吸毒等情况，流程不简反繁，无人驾驶汽车的便利初衷恐化为泡影。

综上，交通部门不应制定“无人驾驶汽车必须随时可切换至人工驾驶模式”法规，否则将导致行业标准模糊、责任不清，陷入混乱尴尬局面。若为规避事故接受人工辅助做法，无人驾驶存在重大漏洞。为实现无人驾驶发展终极目标，交通主管部门必须改革现行交通体系，明确无人驾驶车辆制造商、系统软件提供商、巴士运营公司及保险公司责任，让用户安心乘坐。近期，美国联邦政府及部分州肯定无人驾驶合法性，美国公路安全管理局认定 `Google` 无人驾驶汽车接受自动驾驶系统控制而非车主手动控制。即“必须配备方向盘和刹车”旧规不再适用。

未来，无人驾驶汽车将不再配备方向盘、踏板、仪表、操纵杆、后视镜等设备，改配全景门窗、3D屏幕、宽敞开放车厢、移动通讯办公设备等。届时汽车不再是生活的“连接器”，而成为生活空间延伸，人们的时间精力将完全解放，投入更有意义、更有价值的事务。
