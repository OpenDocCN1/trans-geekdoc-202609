

# 自动驾驶分级与无人驾驶技术演进路径

## 12.1.2 自动驾驶分级标准

### 12.1.2.1 Level 0：无自动化

Level 0 意味着汽车没有任何自动驾驶功能，驾驶员完全控制汽车的所有功能。驾驶汽车时，驾驶员负责汽车的启动、制动和操作，并观察周围路况。只要由人类控制汽车，无论汽车配备了何种驾驶辅助技术，均归类为 Level 0。因此，尽管普通汽车配备了前向碰撞预警、车道偏离预警、自动雨刮控制和自动大灯控制等功能，但只能由人类控制驾驶，仍归类为 Level 0。

### 12.1.2.2 Level 1：单一功能自动化

Level 1 意味着驾驶员负责驾驶安全，但可放弃部分控制权交给系统。此阶段已实现部分功能自动化，如常见的自适应巡航控制、紧急制动辅助、车道保持等。Level 1 仅具备单一功能，驾驶员驾驶时仍控制汽车，汽车不能完全自主行驶。

### 12.1.2.3 Level 2：部分自动化

Level 2 下，汽车可与驾驶员共享控制权。在特定预定义环境中，驾驶员无需控制汽车，汽车可自动工作，但驾驶员始终处于待命状态，负责驾驶安全，随时准备接管车辆。此阶段部分自动化的关键不在于拥有两个以上功能，而在于驾驶员不再是主要操作者。例如，ACC 与 LKS 组合形成的跟踪功能，以及特斯拉发明的自动辅助驾驶功能，均属于 Level 2 功能。

### 12.1.2.4 Level 3：有条件自动化

此阶段汽车可在有限情境下自动控制，如在高速公路或车流稀少道路上行驶。遇紧急情况时，驾驶员有足够时间接管车辆以确保安全驾驶。此阶段驾驶员在最大程度上得到解放，驾驶时不再负责驾驶安全，无需持续监控路况。

### 12.1.2.5 Level 4：高度自动化（无人驾驶）

此阶段汽车可在无人协助下，通过预先输入出发和到达信息自主抵达目的地。汽车全程负责驾驶安全，对驾驶员依赖极低，车辆可无乘客行驶。

除 NHTSA 外，美国汽车工程师学会（SAE）也对自动驾驶分级，将自动驾驶技术分为 0 到 5 共六级。其中 Level 0 至 Level 3 与 NHTSA 分类一致，分别强调无自动化、驾驶辅助、部分自动化和有条件自动化。针对完全自动化，SAE 进行了细分，进一步强调了对道路和环境驾驶的要求。

根据 SAE 关于自动驾驶 Level 4 的规定，汽车仅能在封闭园区、固定行驶路线等特定路况下实现自动化。而 Level 5 则允许在多种环境下自动驾驶，并能对复杂的车辆、行人和路况做出有效响应。

总的来说，不同级别的驾驶功能相应递增。高级驾驶辅助系统（ADAS）属于最高级别的驾驶辅助系统，归属于 Level 0 至 Level 2（见[表 12.1](#ch12.xhtml#tab12.1)）。

其中，Level 0 自动驾驶仅具备传感器检测和决策预警功能；若配备夜视系统，则能检测前方行人、识别交通标志、车辆偏离车道时发出预警等。

- Level 1 自动驾驶具备单一控制功能，如主动紧急制动、自适应巡航控制等。
- Level 2 自动驾驶可执行多重控制功能，如配置 AEB 和 LKA。

- SAE 定义的 Level 5 指完全无人驾驶，为最高级别及自动驾驶最终形态，允许在任意场景下无人驾驶。

与半自动化相比，完全自动化无人驾驶汽车更安全，因前者易受人为失误影响，而后者不受其影响。例如，弗吉尼亚理工交通研究所（VTTI）调查显示，Level 3 自动驾驶汽车驾驶员响应车辆接管请求需 17 秒，若车速 65 mph，这 17 秒内车辆将行驶 1,621 英尺（约 494 米）。

从发现路面物体到踩下刹车，人类驾驶员需 1.2 秒，远长于车载计算机的 0.2 秒。虽仅差 1 秒，但若车速 120 km/h，1.2 秒内车辆行驶 40 米，而 0.2 秒仅 6.7 米。紧急情况下，这 1 秒差距可能关乎乘客生死。因此，对整个汽车行业而言，无人驾驶是自动驾驶的终极目标。

## 12.1.3 无人驾驶技术演进路径

无人驾驶技术是基于传统汽车制造技术的综合技术，融合了智能化、自动化、电动化、网联化等技术。无人驾驶汽车，又称“自动驾驶车辆”或“轮式移动机器人”，通过车载传感器系统感知周边路况环境，对行驶路线进行合理规划，控制车辆驶向预定目的地。无人驾驶汽车是自动控制、人工智能、模式识别、视觉计算等多项技术发展的产物，也是计算机科学、模式识别、智能控制技术发展到一定阶段的产物，现被视为衡量一国科研实力和经济发展水平的重要指标，未来可广泛应用于国防、国民经济等领域。

中国人口众多，交通问题严峻。若无人驾驶技术全面推广，将尽快解决城市交通拥堵、环境问题和城市发展难题，有效提升工业制造水平，改善民生。随着无人驾驶技术逐渐成熟，交通管理部门须做好准备，推动无人驾驶技术融入智能交通，实现全面发展。
