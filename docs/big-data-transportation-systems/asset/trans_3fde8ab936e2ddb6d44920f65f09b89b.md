

# “大城市病”如交通拥堵已被诟病许久

如何解决交通拥堵问题已成为城市管理决策者的重要议题。业内人士认为，如何通过信号控制提高路口通行效率是解决问题的关键，这也是智慧城市建设与发展中最基础的关键环节。

近期，基于智慧城市建设中人工智能的数据挖掘与深度学习，海信向外界展示了其在交通领域早期布局的突破性应用方案。据称，海信研发的“数据魔方”可在30秒内完成10亿量级交通大数据的可视化分析，并基于深度学习实现交通预测。

“依托海量交通数据，我们分析交通运行的规律性与相似性，构建智能学习模型，通过机器学习预测车流量、拥堵等交通参数。”海信城市交通信控专家马晓龙表示，通过对路网车流的实时监测分析，根据动态交通数据自动切换、配置信号灯时长，最直观的变化是红绿灯时间不再固定，甚至全程绿灯不停车。

据了解，上述理想的交通状态已成现实。在海信的自适应信号控制系统中，按推荐车速行驶可实现“一路绿灯”。数据显示，在山东青岛，智能交通系统建设完成后，高峰时段时长减少1.48小时，平均车速比提升9.71%，为车辆节省出行时间107,938,000小时。^([5](#ch01.xhtml#fn5))

上述应用仅是中国人工智能交通应用的一个缩影。中国各大城市正不断探索应用人工智能提升交通效率，使城市交通更加顺畅。此外，中国已出台多项政策法规鼓励人工智能与大数据交通发展。未来，中国的大数据交通与人工智能交通将焕然一新。

当然，从全球视角看，世界主要经济体都在发展人工智能。美国已将“智慧地球”构想上升为国家战略。日本和韩国通过人工智能与大数据技术切入国民生活生产的各个领域，不断提高人民生活水平。欧盟也在持续聚焦环境、交通、医疗、智能建筑等领域的智慧城市建设，这些领域的发展比中国更早、更深。

尽管人工智能处于发展阶段，但其前景十分广阔。交通领域每时每刻都在产生海量数据，这些数据经人工智能分析学习后，将为交通参与者描绘出更清晰的图景。对于政府交通部门、铁路、航空公司及旅游机构而言，可精准锁定客户群体，提供更个性化的服务。

# 第2章

# 大数据交通：走近生活

许多人觉得大数据交通离生活很远，但事实是，它无处不在。日常出行信息预报、共享单车、地铁公交调度，都与大数据交通紧密相关。它深刻影响着我们的生活，极大地改变了我们的出行行为与习惯。

## 2.1 大数据交通的自助出行

随着汽车普及率提高、出行方式多元化以及智能交通发展，人们的出行方式日益个性化。无论是通勤还是假期出游，自助出行越来越受消费者青睐。人们的自主意识与自助意识日益增强，出行途中不再需要工作人员全程指引，仅凭手机APP即可完成全程查询。

观察当前市场，人们自助出行的方式涵盖多种交通工具，包括自行车、汽车、火车、高铁、飞机等。

### 2.1.1 自行车自助出行

自助自行车，即公共自行车，原本是政府部门为改善城市交通、缓解拥堵、减少污染而提供的自行车租赁服务。在政府设立的公共自行车租赁点，市民可刷卡或手机解锁使用。但因押金缴纳不便、需归还至固定站点、车型陈旧等原因，政府主导的租赁体验并不理想。

近年来，随着共享单车兴起，自助骑行出行愈发普及。从用户注册、缴纳押金、用车、还车，全流程由用户自主完成。共享单车运营团队仅负责交通信息数据处理、车辆调度与维护。

例如，大众熟知的摩拜、ofo等共享单车，是人们自助出行的最佳方式。用户可随时随地取还车。在“地铁站到公司”、“公交站到家”等短途场景中，共享单车价值巨大。特别是在公交线网密集、交通拥堵的一线城市，共享单车在短途出行中发挥重要作用，提供了更快捷、经济、直达的出行方式。尽管共享单车在一定程度上与公交、出租车短途运输形成竞争，但也在一定程度上缓解了拥堵、减少了污染，可作为城市公共交通“最后一公里”接驳的有益补充。
