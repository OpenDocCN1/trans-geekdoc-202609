
# 百度、阿里巴巴、腾讯在大数据交通领域的布局

百度无疑是最强的。百度地图和百度无人驾驶汽车是百度集团直接进军大数据交通行业的举措。随后，一系列投资并购也在迅速推进。2017年11月，百度宣布对首汽约车进行战略投资。百度资本、蔚来资本、丝路华创领投，完成了总计7亿元人民币的融资。百度用实际行动表达了对大数据交通行业的关注，并持续在该领域深耕。

阿里巴巴的步伐也非常坚定。2017年10月，阿里云与上海地铁展开合作，开发了语音购票、刷脸进站等技术，并宣布进军大数据智能交通领域。在此之前，阿里巴巴通过一系列投资并购，已在大数据交通行业积累了丰富经验。2013年，阿里巴巴对出租车领域表现出浓厚兴趣，先后投资了实时公交服务提供商“车来了”和通勤班车“接我云班车”。同时，易图通科技和高德地图也是阿里巴巴的投资品牌。

阿里巴巴的大数据技术是国内科技公司的领军技术。阿里云系统已与众多商业机构建立合作，因此在交通大数据应用方面具有极高的熟练度。

腾讯在大数据交通行业也有快速布局。2017年12月，中海科技宣布与腾讯合作，腾讯由此进入大数据智能交通市场。腾讯看重的是中海科技在交通行业的经验。中海科技依托浙江大学，从事城市轨道交通系统建设和综合票务系统建设，已在沈阳、西安、郑州等城市的地铁项目开展业务，并相继创新开发了轨道交通无人驾驶信号系统和智能列车相关产品。可见腾讯也对大数据交通行业垂涎已久。

无论是初创企业还是互联网巨头，越来越多的企业参与大数据交通行业，意味着行业爆发期即将到来。交通关乎民生，反映城市的发展活力与潜力，因此我们有理由相信，未来大数据交通行业的发展必将日趋成熟，引领世界潮流。

## 11.4 大数据交通行业的政策引导

大数据交通在商业领域的发展如火如荼，国家政策层面也对此高度关注，并不断出台政策引导，鼓励行业发展。

### 11.4.1 “十三五”规划明确支持

在“十三五”规划中，明确提出了建设现代化综合交通运输体系、实现网络化智能化发展前景的目标。规划纲要指出：“要建设综合交通运输网络，实现交通枢纽一体化衔接。要逐步优化综合交通枢纽空间布局，完善国家、区域、地方三级综合交通枢纽体系建设。”为实现这一目标，必须积极接入大数据体系，形成数据体系模式，有效连接交通领域的所有环节。该规划纲要将进一步激发行业活力，为行业未来趋势奠定基础。

### 11.4.2 国务院关于积极推进“互联网+”行动的指导意见

2015年，国务院发布《关于积极推进“互联网+”行动的指导意见》，对大数据在交通领域的应用作出明确阐述。指导意见指出：

(1) **创新发展、支撑引领**。充分利用互联网、大数据、云计算等信息技术，优化交通组织模式，提供多元化产品，更好满足多样化需求。以智能交通发展为引领，增强行业创新能力，培育业务发展新形式新模式。

(2) **市场运作、提质增效**。充分发挥传统交通企业和互联网企业的主动性，鼓励以资本运作、技术合作、管理合作等形式全方位合作。充分发挥技术和市场优势，聚焦客户，提升综合交通运输体系整体运行效率和服务质量。

到2018年实施“互联网+”便捷出行重点示范工程，基本实现公众通过移动互联网终端获取动态路况交通信息、完成包括导航、购票、支付在内的客运全程一站式服务，提升用户出行体验。基本实现重点城市群“交通一卡通”互联互通和重点营运车辆（船舶）“一网统管”。推动线上线下企业加快融合，在国家干线物流通道率先实现“一单制”贯穿始末。实现交通基础设施、交通工具、运营信息的互联互通，使系统运行更安全、更高效。

重点在于提升通行能力、缓解交通拥堵、减少排放、提高全国高速公路ETC车道覆盖率。提升ETC系统安装缴费便利度，增加用户发展量。重点提升道路、车辆、出租车等各类营运车辆利用率，力争三年内实现公交ETC利用率达到50%以上。研究推广标准厢式货车ETC。提升客服网点和省级网上结算中心服务水平，建设高效结算体系。推动ETC系统与互联网深度融合，实现ETC系统在高速公路、城市公共交通、出租车、停车、道路客运、铁路客运等交通领域广泛应用。
