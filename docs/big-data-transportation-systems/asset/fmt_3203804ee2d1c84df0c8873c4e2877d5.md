
# 无人驾驶技术的发展与商业应用前景

## 12.2.2 无人驾驶技术的发展历程

2010年，柏林自由大学Rogas教授领导的团队改装了一辆大众Passat，开发出一辆无人驾驶汽车，能够准确识别道路上的其他人员和车辆，甚至在隧道中也能实现。该无人驾驶汽车利用摄像头、激光扫描仪、热传感器、卫星导航等技术和设备，可根据红绿灯调整汽车的行驶状态。

为了采用更科学合理的驾驶策略以应对路况，无人驾驶汽车通常需要在车载计算机中构建3D图像。无人驾驶汽车可通过对路况、车辆位置等数据的分析，为汽车制定科学合理的行驶路线，为乘客或控制者提供预计到达时间。

2010年，伦敦希思罗机场启用了名为Uterra的无人驾驶汽车，该车由布里斯托大学与交通系统领域的多家先进公司联合开发，但需在专用道路上行驶。

法国INRIA公司开发的无人驾驶汽车Saikabo相对成熟，应用了先进的GPS全球定位技术，并配备触摸屏，乘客或控制者可通过触摸屏规划行驶路线。同时，双目摄像头能准确识别路标，在物联网和移动互联网的帮助下实现车车、车路、车人互动，促进交通信息自由流动共享，缓解交通拥堵，提升交通网络通行能力。

### 12.2.2.2 中国无人驾驶技术的发展

中国国防科技大学（NUDT）于1989年研制出第一辆智能汽车；1992年研制出第一辆真正的无人驾驶汽车，中国无人驾驶汽车技术的研发正式启动并进入探索阶段。

由上海交通大学牵头的城市无人驾驶汽车项目“Cyber C3”智能汽车，主要在非主干城市道路等非结构化道路上行驶（路型和环境背景复杂、车道线和道路边界不清晰），平均时速低于10 km/h，具备自动定位、导航、驾驶、避障和交互能力。

西安交通大学郑南宁教授团队于2001年底启动无人驾驶智能汽车项目，2002年推出“无人驾驶汽车思源1号”，2005年思源1号成功完成校园路况环境测试，随后项目组尝试让思源1号智能汽车走出校园。随之制定了“新丝绸之路挑战计划”，让思源1号从西安自动行驶至敦煌，但实际测试中发现思源1号难以适应真实交通环境。经过十余年研究，思源1号逐步实现重大突破：可从特定路段行驶至复杂路况、从直线行驶实现转弯和超车，车速从10–15 km/h提升至70–80 km/h。

2011年，一汽红旗HQ3无人驾驶汽车完成286 km路测；2015年，百度无人驾驶汽车完成北京开放高速公路自动驾驶测试；2016年，长安无人驾驶汽车完成2000 km超长距离无人驾驶测试，均标志着中国无人驾驶技术日趋成熟。

在无人驾驶技术快速发展过程中涌现出许多新技术。据汤森路透知识产权与技术报告，2010年至2015年出现22,000项与无人驾驶技术相关的专利，许多技术已投入使用。特别是在深度学习算法和云服务技术的支持下，无人驾驶技术发展日益加速。

## 12.2.3 无人驾驶商业应用的全球前景

无人驾驶汽车初期制造成本较高，因需安装雷达、摄像头和人工智能系统，价格自然昂贵，普通消费者难以承担。因此，首批使用无人驾驶汽车的将是部分特种行业和特殊群体，如快递行业、工业企业、出租车、老年或残疾人服务等。

### 12.2.3.1 公共交通

未来公共交通行业将大规模采用无人驾驶汽车。据德克萨斯大学奥斯汀分校关于共享无人驾驶汽车（SAV）的研究，一辆共享SAV可替代11辆传统汽车，并使运营里程至少增加10%。这意味着随着共享SAV的普及，交通拥堵可得到有效缓解，环境恶化可得到有效控制，凭借使用便利性，共享SAV将成为人们首选的出行方式。

为推广无人驾驶汽车，一些城市规划为无人驾驶汽车指定专用街区，实现有人驾驶车辆与无人驾驶车辆分时或分道行驶，由无人驾驶出租车和共享SAV承担为用户提供所有交通服务的责任。为给无人驾驶汽车创造良好运行环境，城市规划部门将实施区域优化。

### 12.2.3.2 快递车辆与工业应用

无人驾驶汽车也将在快递行业的排队卡车领域得到广泛应用。随着互联网电商的快速发展，快递公司迅速涌现。网购消费者总希望在最短时间内收到货物，特别是生鲜水果等食品，希望快递公司能在几小时内送货上门。据商务部数据，2018年上半年中国电商行业销售额达4.08万亿元，快递包裹总量已超2015年全年业务量，众多电商企业承诺当日达，进一步推动了电动汽车和卡车配送的发展。

电动汽车和卡车数量的增加在一定程度上加剧了交通事故。据调查，在美国，卡车行驶里程占机动车总行驶里程的5.6%，但卡车引发的交通死亡人数占交通事故死亡总数的9.5%。一般来说，大型卡车生产成本超过15万美元，若加装摄像头和传感器成本更高。相比之下，小型汽车固有生产成本较低。因此，受成本制约，早期难以大规模采用无人驾驶卡车。

### 12.2.3.3 老年人与残疾人

目前，无人驾驶汽车已大规模应用于老年人和残疾人两大群体。因身体机能限制，老年人和残疾人面临出行不便问题，无人驾驶汽车的使用可帮助这两类人群解决出行难题。
