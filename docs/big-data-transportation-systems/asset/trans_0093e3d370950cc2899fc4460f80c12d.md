

# 12.3.3 决策层：路径规划与实时导航

目前阶段，环境感知主要采用的技术包括视觉感知、激光感知和微波感知。借助这些技术，车载传感器、车载通信系统和雷达系统可以采集环境信息，利用信息技术呈现二维或三维图像，并将获取的信息发送至信息处理终端，由技术人员处理三维图像以感知和判断汽车的实时环境。此外，不同汽车之间还可以互联，采集不同车辆的实时环境和行驶信息。远程通信技术和李永乐无线网络技术在无人驾驶领域的应用，有效提升了汽车的环境感知能力，推动了无人驾驶的整体发展。

无人驾驶汽车决策层的主要功能是规划行驶路线并提供实时导航服务。这两项功能的实现需要使用高精度地图，也称为“高精度数字地图”。高精度地图与普通地图的区别在于前者更精准、信息量更大，且专供无人驾驶汽车使用。

无人驾驶汽车无法使用普通地图的原因在于，普通地图标注的信息简单，用两条平行线代表道路，用交叉口代表十字路口。人类可以凭借认知能力根据这些简单信息做出判断，但无人驾驶汽车难以以此方式运作。因此，高精度数字地图是三维的，涵盖丰富信息，包括车道线和周边设施的坐标位置，精度极高，可达厘米级。

与普通电子地图相比，高精度地图的另一特殊功能是其采集路面激光雷达反射强度的能力。对人类驾驶员而言，此功能毫无意义，但对自动驾驶车辆却极其宝贵。路面激光雷达反射强度是一种变化缓慢且微小的路面特征，可为利用光学雷达对无人车辆进行定位提供依据。通过将光学雷达扫描获得的信息与高精度地图上已有的信息进行比对，无人驾驶系统便能精准锁定车辆当前位置。

无人驾驶决策系统运行需要两个条件：独立智能车辆和智能交通系统，如 `V2V`。`V2X` 是除高精度地图外另一种可实现路径规划的技术，它基于 `V2I`。`V2X` 使车辆能与周围环境连接，形成覆盖车车通信系统、车路通信系统和车人通信系统的物联网。

如果车辆在行驶中能“获取”信号灯信息，而非仅“看见”信号灯信息，则可完全避免闯红灯。此处“获取”是指：当传感器尚未“看见”信号灯时（如距离信号灯 100 米处），信号灯主动将当前信号状态、变化时长等信息发送给车辆，提醒其减速、加速或刹车，从而避免闯红灯。此外，若无人驾驶车辆在行驶中能“获取”周围车辆的行驶意图（如停车、变道、转弯等），将有效避免交通事故。

在高精度数字地图和 `V2X` 通信网络的支持下，自动驾驶系统可利用搜索算法精准评估各种驾驶行为的代价，从而规划最优行驶路径。

# 12.3.4 智能交通执行层：对汽车运行的精准控制

在整个控制系统中，执行层位于底层，其主要功能是执行制动、转向、加速等操作。系统采用“线控装置”控制方向盘和油门，并配置由多处理器组成的子系统，对自动驾驶汽车的整个机械系统进行稳准控制。

汽车驾驶控制器是实现车辆控制和自动驾驶的核心模块，包含两类功能：一方面，它将结合自动驾驶汽车的动力学性能和车内传感器性能来调整车辆行驶参数，以安全、高效、低能耗完成驾驶任务；另一方面，汽车将能像拥有多年经验的驾驶员一样思考和决策，这基于无人驾驶汽车的动力学性能和传感器识别性能。汽车还可能综合考量安全、经济、舒适、伦理等诸多因素，根据实时路况调整驾驶状态，这将同时为乘客带来良好的出行体验，并维持车辆与其他车辆、行人之间的和谐。

对车辆的精准控制是自动驾驶的关键，车辆控制的基本原则是保障人车安全，这显然需要先进制动系统的有力支撑。当汽车遭遇事故时，制动系统能在智能驾驶控制器的指挥下实施精准、实时的制动，以避免或减轻事故的负面影响。有了强有力的制动系统，智能汽车还需要更智能的控制算法，这是赋予制动系统更强控制力、精度和鲁棒性的主要手段。

目前阶段，几乎所有自动驾驶汽车项目都可能利用机器学习等技术，让汽车学习并模拟人类驾驶经验，再结合智能系统实时分析控制车辆。然而，若无人驾驶汽车具备应对紧急情况的能力，将有效管控风险。应对紧急情况的智能系统不会像普通人那样普遍感到紧张、恐慌；无人驾驶汽车在决策上理性果断，其前提是强大的“智能大脑”。

安全是无人驾驶汽车的首要考量。在人工驾驶状态下，驾驶员的驾驶技术、心理素质、应急处理能力、操作习惯等存在差异。遇到紧急情况时，驾驶员可采取差异化应对措施，但无人驾驶汽车无情感，安全保障应为第一优先级。其次应考虑用车体验。目前市场上的智能汽车主要为提供驾驶辅助服务的半自动化汽车，因此保障乘客在无人驾驶汽车中的舒适体验是未来的重要课题。
