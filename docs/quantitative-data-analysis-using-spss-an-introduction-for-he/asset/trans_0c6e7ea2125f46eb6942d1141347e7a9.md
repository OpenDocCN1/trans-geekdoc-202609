#### Name

-   输入代码本中列出的第一个SPSS变量名称，即`patient`。然后按右箭头键移动到下一列——*type*。

#### Type: 它是什么类型的数据？

-   输入变量名称后，**Type** 的默认值会自动显示为numeric。所有变量都是数值型，因为我们将把任何单词（如男性和女性）编码为数字（即男性为1，女性为2）。因此，你可以继续到下一列——**Width**（见`Box 2.2`，在某些情况下需要输入文字）。

#### Width: 你将输入多少个数字？

-   SPSS默认八个字符。我们最多只需要两个（例如，24年，12次会议）。无需更改。如果你输入非常大的数字，例如184,333,333.24（即11个字符），则需要增加它。

#### Decimals

-   SPSS默认两位小数。由于我们的数据不需要小数位，只需点击**Decimals**单元格，然后点击单元格右侧的上下箭头来调整所需的小数位数。

![Screenshot 2.6](Images/p24-1.jpg)

-   对于许多变量且不需要小数位的数据集，将默认设置更改为0小数位可能很有价值。你可以通过点击屏幕顶部的**Edit**菜单，然后选择**Options**。接着，点击**Data**选项卡，并在**Display**格式中将新数值变量的小数位数值更改为0。

#### Label

-   **Label**列允许你为变量提供更长的描述，这将在SPSS生成的输出中显示。对于‘patient’或其他变量，标签不需要填写，因为名称已经自解释。^()

#### Values

-   名义变量的值是分配给类别的数字，例如，男性=1，女性=2。由于第一个变量（patient）没有‘值’，你不需要在这里填写任何内容。

#### Missing

-   有时为缺失数据分配特定值很有用。但SPSS将任何空白单元格视为缺失数据并将其排除在计算之外，因此如果你打算留空单元格，无需为缺失数据输入值。而且我们没有缺失数据。^()

#### Columns

-   你可以调整列宽以减少屏幕上的空间占用。但需要为变量名称提供足够的空间，因此默认的8通常足够。

#### Align

-   通常设置为**Right**，这没问题。

#### Measure

-   默认测量值是**Scale**，但你可以通过点击单元格并点击单元格右侧的下拉箭头，将其更改为**Ordinal**或**Nominal**。我们有尺度数据和名义数据：

**Table 2.2** Measure definitions

| *Measure*  || *Definition* |

| --- | --- |

| Scale: || For numeric values on an interval or ratio scale: age, sessions, satisfaction. |

| --- | --- |

| Nominal: || For values that represent categories with no intrinsic order: patient, sex,counsellor. |

| --- | --- |

| Ordinal: || For values with some intrinsic order (e.g., low, medium, high; first, second third). |

-   由于我们的第一个变量仅列出患者/问卷编号，我们应将其更改为‘nominal’，因为这些数字仅用于标识患者（它们没有作为尺度的意义）。
