# Recovering Changed Extension Files

+   1. First, if the software is on removable media, scan it using your antivirus software to clean any viruses from it.

![](bbox=[0.01, 0.23, 0.52, 0.47])

Above: Running the command prompt.

+   2. Run the command prompt. In Windows 7/8, type cmd in the Start screen. In Windows XP, click Start, select Run and then type cmd.

+   3. In the black console screen, type: ATTRIB -H -R -S /S /D [drive letter] \*.* replacing [drive letter:] with the letter of the drive where your infected file is, such as E:.

![](bbox=[0.1, 0.51, 0.95, 0.7])

Above: Restoring file extensions in drive E: using the command prompt.

+   4. Press Enter. Now, when you open your file folder, your files should be present and correct.

> Hot Tip
> If you cannot clean an infected flash drive or change file extensions using the command prompt, check the file extensions are not Read Only (right click and Properties).
