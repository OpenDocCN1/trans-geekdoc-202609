# MICROSOFT SECURITY ESSENTIALS

The latest version of Microsoft Windows, Windows 8, comes with its own antivirus program installed called Windows Defender. For older versions of Windows, Microsoft Security Essentials can be downloaded at: http://windows.microsoft.com/en-GB/windows/security-essentials-download/ although support for Windows XP has now ended.

# Cost

While it is only available for users of Windows PCs running Windows Vista with Service Pack 1 or Service Pack 2, Windows 7 and Windows 8, it is completely free of charge for home users and for small businesses (on up to 10 devices). However, it may well be free, but is it in any good?

> Hot Tip
> 
> PC Mag (http://pcmag.com) reviews and tests nearly all antivirus software produced, so they are a good resource for discovering the pros and cons of available solutions.

# Features

Microsoft Security Essentials is quite a small file (24 MB), but it contains all the basic antivirus functions of paid-for software, such as malware protection, real-time scanning and monitoring,
