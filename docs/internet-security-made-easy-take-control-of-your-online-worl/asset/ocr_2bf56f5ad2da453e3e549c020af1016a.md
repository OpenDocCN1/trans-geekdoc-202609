# Granting Device Access

Not only can you grant certain access to games and applications, but you can also set up a list of approved devices that can access your router. Sometimes this is described as an access blocking policy, or it may just be listed as access restrictions. If you have a list, you must remember that any new devices you want to connect to the router will have to be added to gain access to the Internet.
