# Additional Tablet and Smartphone Locks

Both later iOS and Android devices have other security features installed that you can use to lock/unlock your phone. To access these, you need to visit the security menu in your device's settings.

+   Face unlock: Some tablets and smartphones allow the use of facial recognition software that ensures only your face can unlock the device.

+   Signature: Some devices, such as the Galaxy Note tablet, let you lock/unlock the device using your written signature.

+   Passwords and PIN: Some Android devices, such as 2.2 Froyo, permit the use of passcodes and passwords.

+   SIM card PIN: To prevent someone removing your SIM card and using it in another phone, you can set a PIN lock on some smartphones.
