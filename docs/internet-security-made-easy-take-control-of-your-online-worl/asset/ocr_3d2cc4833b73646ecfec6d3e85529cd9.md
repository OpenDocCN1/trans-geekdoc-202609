# # RECOVERING CHANGED EXTENSION FILES

Due to the way computers erase files (more on this in a bit), malware rarely deletes files completely, but in order to prevent you from using files, they sometimes change the file extensions (the application suffix, such as '.doc', '.jpg'). Often this is done by changing the file into a shortcut, which will not open, making you think the file is lost for ever. This is very common with infected files stored on removable media, but you can normally convert the file extension back.
