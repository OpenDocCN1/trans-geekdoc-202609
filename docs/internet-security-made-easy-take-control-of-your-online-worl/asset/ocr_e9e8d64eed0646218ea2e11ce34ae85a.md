If you have no backup, and there is no temporary file to help you out, you may think all is lost, but that may not necessarily be so, as you can use a wide variety of software tools to search for lost files on your computer.

# How Computers Erase Files

When you delete a file (and empty the recycle bin), you may think the file has been deleted for ever; however, computers never actually delete files. What normally happens is that the location on the hard drive where the file is stored is marked as accessible, allowing other data to overwrite it, but that can take weeks, months or even years, so your file can linger on the hard drive for a long time.
