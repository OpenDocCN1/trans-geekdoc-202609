# Reformatting a Mac

To reformat a hard drive on a Mac, you need to use Disk Utility (see pages 225–26).

Above: Entering name and size for partition.

![](bbox=[0.01, 0.44, 0.53, 0.69])

+   1. Select your Mac's hard drive and select **Partition**.\n2. In the Partition Information box, enter a name for your hard drive and the size of partition.\n3. Click **Apply**, and then click **Partition**.\n4. Go back to the **Disk Utility** main menu and select the partition you have just created.\n5. Select **Erase** (ensure that the format is Mac OS Extended, which is set by default).\n6. Select a security option. The securer the option, the more thorough it will be in erasing your data, but it will also be slower.\n7. Once formatting is complete, reinstall your OS X operating system.
