# # Swipe Security on Android Devices

Most Android devices include the ability to lock a phone using a swipe pattern, unique shape created using your finger, that will unlock the phone. As with passwords, you need to come up with something that cannot be easily guessed or cracked using trial and error. This means not using an obvious shape such as a cross or L-shape.

# ## Setting an Android Swipe Pattern

+   1. Go into Settings and choose Security.
+   2. Select Change Unlock Pattern and check Require Pattern.
+   3. Swipe the pattern you want to use to unlock your phone.
