# THIRD-PARTY SOFTWARE

There is also a range of third-party software solutions, which let you limit your child's web use.

+   • **PC moderator (http://www.pcmoderator.com/)**: Hardware devices that turn off your monitor after a set time limit.
+   
+   • **Safe eyes (http://www.internetsafety.com/)**: A web-based system that lets you control your entire family's web use. Available for both Windows and Mac machines.
+   
+   • **ContentProtect (http://www.contentwatch.com/)**: A flexible content-filtering system but more aimed at corporate web filtering. However, it is highly effective at blocking adult content from family machines.
+   
+   • **iShield (http://ishield.ph/)**: Prevents children from accessing pornographic sites whether accidentally or deliberately. It uses image-recognition software to identify nudity and sexual acts.
+   
+   • **KuruPira webfilter (http://www.kurupira.net/en/)**: A free and easy-to-use software platform that lets you block web access, set time limits and monitor web use.
