# Conclusion

The construction of a value does not determine where it lives. Only how a value is shared will determine what the compiler will do with that value. Anytime you share a value up the stack stack, it is going to escape. There are other reasons for a value to escape which I will explore in the next post.

What these posts are trying to lead you to is guidelines for choosing value or pointer semantics for any given type. Each semantic comes with a benefit and cost. Value semantics keep values on the stack which reduces pressure on the GC.
