# 1.4 Productivity vs Performance

Productivity and performance both matter, but in the past I couldn't have both. I needed to choose over the other. We naturally gravitated to productivity, with the idea or hope that hardware would resolve our problems for free. This movement towards productivity has resulted in the design of programming languages that is outacing the hardware’s ability to make them faster.

By Following Go idioms and a few guidelines, I can write code that be reasoned about by average developers. I can write software that simplifies, minimizes and reduces the amount of code we need to solve the problems we are working on. I don't have to choose productivity over performance or performance anymore. I can have both.
