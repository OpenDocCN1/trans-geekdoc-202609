# Listing 6.12

```
func printHashes(prefix string) {
  for i := 1; i <= 50000; i++ {
    num := strconv.Itoa(i)
    sum := sha.Sum([]byte(num))
    fmt.Printf("%s: %05d: %x\n", prefix, i, sum)
  }
  fmt.Println("Completed", prefix)
}

```

This function is performing like I/O bound work that has the potential of being context switched.
