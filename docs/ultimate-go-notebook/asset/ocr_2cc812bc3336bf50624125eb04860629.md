# Listing 4.40

```
type admin struct {
    *user // Pointer Semantic Embedding
    level string
}

func (a *admin) notify() {
    fmt.Printf("Sending admin Email To %s<%s\n",
        a.name,
        a.email)
}
```

When the outer type implements a method already implemented by the inner type, the promotion doesn't take place.
