One goal of the collector is to eliminate the need for Mark Assists. If any given collection ends up requiring a lot of Mark Assist, the collector can start the next garbage collection earlier. This is done in an attempt to reduce the amount of Mark Assist that will be necessary on the next collection.

# Mark Termination - STW

Once the Marking work is done, the next phase is Mark Termination. This is when the Write Barrier is turned off, very clean up tasks are performed, and the next collection goal is calculated. Goroutines (in versions of Go prior to 1.14) that find themselves in a tight loop during the Marking phase can also cause Mark Termination STW latencies to be extended.
