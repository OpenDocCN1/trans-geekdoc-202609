```
func mockServer() *httptest.Server {
    f := func(w http.ResponseWriter, r *http.Request) {
        w.Header().Set("Content-Type", "application/xml")
        fmt.Fprint(w, feed)
    }
    return httptest.NewServer(f)
}
```

Before I can write the test function I need a way to mock a web server. The mockServer is providing just that. It uses the NewServer function from the httptest package. This function takes an handler function that can be executed when a request is sent to the mock server and returns the localhost port the mock server is listening on.

In this case, the handler function sets the status code to 200, the content type to application/xmls. The feed string is mocking a small portion of the response. The RSS document that is returned from the Ardan blog call for the first test.
