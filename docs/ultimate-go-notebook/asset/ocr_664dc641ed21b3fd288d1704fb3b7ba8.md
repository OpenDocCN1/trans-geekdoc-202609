# Listing 3.39

```
func main() {
	users := make(map[string]user)

	users["Roy"] = user("Rob", "Roy")
	users["Ford"] = user("Henry", "Ford")
	users["Mouse"] = user("Mickey", "Mouse")
	users["Jackson"] = user("Michael", "Jackson")

	for key, value := range users {
		fmt.Println(key, value)
	}
}
```

Output:
Roy (Rob Roy)
Ford (Henry Ford)
Mouse (Mickey Mouse)
Jackson (Michael Jackson)

If the built-in function is used to construct a map, then the assignment operator can be used to add and update values in the map. The order of how keys/values are returned when ranging over a map is undefined by the spec and to the compiler to implement.

# Listing 3.40

```
func main() {
	users := map[string]user{
	"Roy": {"Rob", "Roy"},
	"Ford": {"Henry", "Ford"},
	"Mouse": {"Mickey", "Mouse"},
	"Jackson": {"Michael", "Jackson"},
}

	for key, value := range users {
		fmt.Println(key, value)
}
```

Output:
Ford (Henry Ford)
Jackson (Michael Jackson)
Roy (Rob Roy)
Mouse (Mickey Mouse)

In this case, the output was returned in a different order from how they are listed in the construction. The current algorithm for 1.16 will return the results in a random order once the number of values reaches a certain limit. Again, this is a compiler implementation that is allowed to change. I can’t depend on it.
