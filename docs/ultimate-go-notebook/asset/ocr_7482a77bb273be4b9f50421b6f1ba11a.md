# Listing 3.25

```
slice1 := [string("A", "B", "C", "D", "E")
slice2 := slice1[2:4]
inspectSlice(slice1)
inspectSlice(slice2)
```

Output:
Length[5] Capacity[5]
[0] 0xc00007e000 A
[1] 0xc00007e010 B
[2] 0xc00007e020 C
[3] 0xc00007e030 D
[4] 0xc00007e040 E
Length[2] Capacity[2]
[0] 0xc00007e020 C
[1] 0xc00007e030 D

The syntax for a three index slice is [a:b:c] when b and c should be the same [a-b] sets the length and [-c] sets the capacity. Now the length and capacity of slice2 is the same.

# Listing 3.26

```
slice1 := [string("A", "B", "C", "D", "E")
slice2 := slice1[2:4]
slice2 = append(slice2, "CHANGED")
inspectSlice(slice1)
inspectSlice(slice2)
```

Output:
Length[5] Capacity[5]
[0] 0xc00007e000 A
[1] 0xc00007e010 B
[2] 0xc00007e020 C
[3] 0xc00007e030 D
[4] 0xc00007e040 E
Length[3] Capacity[4]
[0] 0xc000016080 C
[1] 0xc000016090 D
[2] 0xc0000160a0 CHANGED

Notice after the call to append, slice2 has a new backing array.
