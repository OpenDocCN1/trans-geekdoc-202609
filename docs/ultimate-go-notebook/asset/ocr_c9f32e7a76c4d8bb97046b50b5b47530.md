Because of syntactic sugar, slices look and feel like an array.

slice := make([]string, 5)

I can tell the difference between slice and array construction since an array has a known size at compile time and slices necessarily not.

If I try to access an element beyond the slice's length, I will get a runtime error.

slice := make([]string, 5)

Compiler Error:

In this example, the length of the slice is 5 and I am attempting to access the 6th element, which does not exist.

# 3.13 Data Semantic Guideline For Slices

As a guideline, if the data I'm working with is a slice, then use semantics to move the data around my program. This includes declaring fields on a type.
