If you were passing the address of a User value, the variable would have needed to be declared as a *User. Even though all pointer variables store address values, they can't be passed any address, only addresses associated with the pointer type. This is the key, the reason to share a value is because the receiving function needs to perform a read or write to that value. You need the type information of any value in order to read and write to it. The compiler will make sure that only values associated with the correct pointer type are shared with that function.
