# 2.15 IOTA

IOTA provides support for setting successive integer constants. It's possible the name comes from the integer function l from the programming language APL. In APL, the l function (represented with the ninth letter of the Greek alphabet, iota) is used to create a zero-based array of consecutive, ascending integers of a specified length.

# Listing 2.30

```
const (
Al = iota // Start at 0
B1 = iota // Increment by 1
C1 = iota // Increment by 1
)
fmt.Println(Al, B1, C1)
```

Output:
0 1 2

The iota keyword works within a constant block and starts with the value of 0. For each successive constant declared in the block, iota increments by 1.
