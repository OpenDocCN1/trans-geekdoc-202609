# 10.2 Example Code

I have a program that takes a stream of data looking for the name elvis with a lowercase e. If that name is found in the stream, the name is corrected by replacing the lowercase e with a capital E.

# Listing 10.1

```
var data = []struct {
    input []byte
    output []byte
}(
    []byte("abc"), []byte("abc"),
    []byte("elvis"), []byte("Elvis"),
    []byte("Elvis"), []byte("AElvis"),
    []byte("abc"), []byte("Aabc"),
    []byte("eelvis"), []byte("eeElvis"),
    []byte("aelis"), []byte("aaelis"),
    []byte("aabaeeelvis"), []byte("aabaeeElvis"),
    []byte("e l v i s"), []byte("e l v i s"),
    []byte("aa bb e l v i saa"), []byte("Aa bb l v i saa"),

    []byte("elvielis"), []byte("elvielis"),
    []byte("elvielvieleiselvil"), []byte("elvielviElviselvil"),
    []byte("elvielelmis"), []byte("elviElvis"),
)
```

This is a data table that represents the potential data from the stream. It lays out the input stream and expected output stream.

# Listing 10.2

```
func assembleInputStream() []byte {
    var in []byte
    for _, d := range data {
        in = append(in, d.input...)
    }
    return in
}

func assembleOutputStream() []byte {
    var out []byte
    for _, d := range data {
        out = append(out, d.output...)
    }
    return out
}
```
