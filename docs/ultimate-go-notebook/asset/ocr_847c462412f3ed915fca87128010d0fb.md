When your Go program starts up, the runtime creates the main Goroutine to start executing all initialization code including the code inside the main function. A Goroutine is a path of execution that is placed on an operating system thread that eventually executes on some core. As of version 1.8, every Goroutine is given an initial 2,048 byte block of contiguous memory which forms its stack space. This initial stack size has changed over the years and can change again in the future.
