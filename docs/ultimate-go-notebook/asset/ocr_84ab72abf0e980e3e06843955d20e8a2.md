# 12.4 Fan-Out

One concurrency pattern I could use is a fan-out pattern. This would allow me to have a concurrent algorithm with the least amount of code change. The idea of this pattern is to create a Goroutine for each file that needs to be processed and let the scheduler manage all the Goroutine, scheduling them across all the logical processors. I can fan-out all these Goroutines because the order of the work doesn't matter. What matters is all the work is performed.
