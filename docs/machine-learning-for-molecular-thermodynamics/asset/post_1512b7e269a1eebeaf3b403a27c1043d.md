Thermodynamic properties of complex systems play an essential role in driving chemical engineering research. It remains a challenge to predict the thermodynamic properties of complex systems in a wide range and describe the behavior of ions and molecules in complex systems. Machine learning emerges as a powerful tool to resolve this issue; it can describe complex properties beyond the capacity of traditional mathematical functions. This review will summarize the discovery of traditional machine learning methods and explore the different aspects of machine learning using several examples. The first aspect is to apply machine learning to predict the thermodynamic properties of a broad spectrum of systems based on known data. The second aspect is to integrate machine learning and molecular simulations to accelerate the discovery of new materials. The third aspect is to develop machine learning models that handle both harmonic and all-atom molecular dynamics simulations. The applications in these three aspects illustrate the potential of machine learning in thermodynamics of chemical engineering. We will also discuss the perspective of the broad applications of machine learning in chemical engineering.

# Introduction

Machine learning has emerged as a versatile tool to predict and investigate the thermodynamics of complex systems. One task for molecular thermodynamics is to predict the thermodynamic properties of complex systems with high accuracy. The theoretical or semi-theoretical models have been used for learning of various systems [1–11]. However, it remains a challenge to develop robust models that can predict the thermodynamic properties of complex systems at the molecular level using the traditional mathematical framework. Machine learning offers computer algorithms that can learn from [12,13]. The machine learning methods are known for their extraordinary performance in self-driving vehicles and games against humans [14–16]. Due to the ability of learning to describe complex relationship between variables, we have witnessed growing accuracy of these models in the material and chemical engineering fields, ranging from [17–22] exploration to molecular thermodynamics prediction [28–34].

Machine learning has helped the research of molecular dynamics from three aspects (Fig. 1). First, it can help develop robust molecular models for complex systems. Obtaining accurate thermodynamic properties of a system is essential for developing processes. Nevertheless, theoretical or empirical models have been developed for predicting thermodynamic properties of various systems. These models use although consist of mathematical functions using hypothesis-driven functions and the parameters derived from theory or experiment. Most of the limitations of these methods rely heavily on the intuition of a "trial-and-error" approach. Deep machine learning methods provide a new way of learning and predicting the thermodynamic properties of complex systems. Many learning methods such as the neural network and decision tree can quantify the relationship between the targeted properties with the selected molecular database provide opportunity to develop such machine learning models [39–42].

Second, machine learning can predict the complex behavior of systems by combining with classical modules. Molecular simulations show their essential role in revealing mechanisms governing thermodynamics. They provide coordinates and velocities of atoms or particles that we use to analyze their thermodynamic and kinetic properties [43–45]. This analysis is usually using a “hypothesis-driven” strategy. Machine learning, however, operates using the “data-driven” strategy. High-throughput molecular simulations contribute to this “data-driven” strategy by providing a large amount of data [13–46–50]. These data far exceed the scale of classical databases and thus enhance the performance of the machine learning model.

Third, machine learning can provide “many-body” force fields for molecular simulations, enabling a fast and accurate description of complex interactions. Classical MD simulations [55–59] have well-known force fields that are relatively fast but limited in their potential overlap over bonding and formation. In contrast, quantum molecular simulations can describe complex systems but the computational cost is immense. Their unique feature originates from the ability of the machine learning models to describe complex interactions. The systems using machine learning force fields can achieve the accuracy of quantum calculations while improving the efficiency of classical MD.

This minreview introduces several examples in the applications of machine learning in the three aspects mentioned above. The goal of this review is to inspire the application of machine learning in molecular thermodynamics and introduce necessary knowledge of machine learning. Many comprehensive reviews have showcased the applications of machine learning in the development of materials and processes [60–65]. Section 2 will introduce some basic concepts of machine learning. Section 3 will illustrate the applications of machine learning in complex relation-ship problems based on experiment. Section 4 will discuss the applications of machine learning based on high-throughput simulations using the methods of peptide design and prediction of thermodynamic properties. Section 5 will discuss machine learning in complex domains that enables high speed and accurate simulations. Finally, we will present a perspective of machine learning in thermodynamic contexts.

# 2. Data, Descriptor, and Algorithm

As stated, machine learning refers to the methods that can predict the output of a system based on selected features (descriptors) using algorithms from a set of databases. The development of a machine learning model includes four critical steps: (1) data collection, (2) selecting the descriptors and algorithm, (3) training the algorithm based on the dataset, and (4) using the trained model to predict the output of a test set. The process of developing a machine learning model depends on three ingredients: dataset, descriptors, and algorithms [66–68]. The research on these ingredients and many comprehensive reviews have covered the relevant knowledge of them [62,66,67]. This section will only introduce them.
