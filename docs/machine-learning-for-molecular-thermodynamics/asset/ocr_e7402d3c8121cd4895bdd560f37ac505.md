Molecular simulations show their essential role in revealing mechanisms governing thermodynamics. They provide coordinates and velocities of atoms or particles that we use to analyze their thermodynamic and kinetic properties [43–45]. This analysis is usually using a “hypothesis-driven” strategy. Machine learning, however, operates using the “data-driven” strategy. High-throughput molecular simulations contribute to this “data-driven” strategy by providing a large amount of data [13–46–50]. These data far exceed the scale of classical databases and thus enhance the performance of the machine learning model.

Third, machine learning can provide “many-body” force fields for molecular simulations, enabling a fast and accurate description of complex interactions. Classical MD simulations [55–59] have well-known force fields that are relatively fast but limited in their potential overlap over bonding and formation. In contrast, quantum molecular simulations can describe complex systems but the computational cost is immense. Their unique feature originates from the ability of the machine learning models to describe complex interactions. The systems using machine learning force fields can achieve the accuracy of quantum calculations while improving the efficiency of classical MD.

# 2. Data, Descriptor, and Algorithm

As stated, machine learning refers to the methods that can predict the output of a system based on selected features (descriptors) using algorithms from a set of databases. The development of a machine learning model includes four critical steps: (1) data collection, (2) selecting the descriptors and algorithm, (3) training the algorithm based on the dataset, and (4) using the trained model to predict the output of a test set. The process of developing a machine learning model depends on three ingredients: dataset, descriptors, and algorithms [66–68]. The research on these ingredients and many comprehensive reviews have covered the relevant knowledge of them [62,66,67]. This section will only introduce them.
