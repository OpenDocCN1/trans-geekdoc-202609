### 回归评估指标

以下是回归任务中最常用的一些评估指标：

*   **平均绝对误差**：`MAE` 衡量实际值与预测值之间平均绝对差异。它提供直观的解释，数值越低表示模型性能越好。
*   **均方误差**：`MSE` 计算实际值与预测值之间平方差的平均值。平方操作会对较大误差施加更重的惩罚，使 `MSE` 对异常值敏感。
*   **均方根误差**：`RMSE` 是 `MSE` 的平方根，提供与目标变量相同单位的可解释度量。与 `MSE` 一样，`RMSE` 惩罚较大误差，但因量纲一致而更具可解释性。
*   **均方根对数误差**：`RMSLE` 衡量预测值与实际值对数的 `RMSE`。当目标变量跨越多个数量级且关注相对误差而非绝对误差时，该指标非常实用。
*   **平均绝对百分比误差**：`MAPE` 计算相对于实际值的实际值与预测值之间平均百分比差异。它以百分比形式表示误差，便于跨不同数据集进行解释和比较。

这些指标用于评估回归模型的性能，帮助确定哪个模型最适合数据。每个指标都有其优缺点，指标的选择取决于具体问题和期望结果。

### 使用线性回归预测 ETA

以网约车应用为例，准确预测到达时间（`ETA`）是创造满意客户体验的关键组件。可靠的 `ETA` 预测在服务的各个方面发挥着关键作用，例如计算费用、匹配乘客与司机以及规划配送。客户依赖准确的 `ETA` 做出明智决策并管理预期，平台的成功在很大程度上取决于维护用户满意度和信任。不准确或不可靠的 `ETA` 预测会导致用户沮丧和不满，可能损害平台声誉并对整体业绩产生负面影响。

以下命令读取数据集，并可视化网约车服务中行驶距离与耗时之间的线性关系。数据集 `cab_data.csv` 包含每趟行程的行驶距离及对应耗时信息。

```
# Load the required libraries
library(dplyr)
library(ggplot2)
library(ModelMetrics)

# Read the dataset
cab_data <- read.csv("cab_data.csv")

# Visualize the linear relationship between distance and time
ggplot(cab_data, aes(x = Distance, y = Time_Taken)) +
  geom_point(col = "steelblue4") +
  labs(title = "Linear Relationship between Distance and Time",
       x = "Distance (kms)",
       y = "Time Taken (minutes)") +
  theme_bw()
```

[Figure 11.5](#ch11.xhtml#fig11-5) 展示了两个变量之间的线性关系。图表表明，随着行驶距离增加，耗时也成比例增加：

接下来，将数据集划分为训练集和测试集。

```
# Split data into train and test
set.seed(123)
rows = seq(1, nrow(cab_data), 1)
trainRows = sample(rows, (80 * nrow(cab_data)) / 100)
train = cab_data[trainRows, ]
test = cab_data[-trainRows, ]
```

设置随机种子以确保可复现性，并随机抽样行以创建训练集和测试集。具体而言，80% 的行分配给训练集，剩余 20% 分配给测试集。

使用 `lm()` 函数训练线性回归模型。以下代码基于 `Distance` 变量训练模型以预测 `Time_Taken` 变量。

```
# Train a linear Regression Model
lm_time <- lm(Time_Taken ~ Distance, data = train)
```

公式 `Time_Taken ~ Distance` 指定 `Time_Taken` 为响应变量，`Distance` 为预测变量。`data` 参数指定用于训练的数据集。

生成的模型存储在 `lm_time` 变量中，可用于对新的未见数据进行预测。`summary` 输出提供了关于线性回归模型性能及响应变量 `Time_Taken` 与预测变量 `Distance` 之间关系的宝贵信息。

**残差** 代表因变量（`Time_Taken`）观测值与模型预测值之间的差异。摘要显示了残差的最小值、第一四分位数、中位数、第三四分位数和最大值。

**系数** 估计线性方程的截距（6.49814）和斜率（1.37346），表明平均而言，每增加一公里行驶距离，耗时约增加 1.37 分钟。

两个系数的 **p 值** 均高度显著，表明距离与时间之间存在很强的线性关系。

**残差标准误** 代表残差的标准差，约为 4.173。它衡量 `Time_Taken` 观测值与预测值之间的典型差异。

**决定系数**（`R²`）量化回归模型中自变量解释的因变量方差比例，并以基线模型（即数据均值的方差）进行归一化。

![](images/eq-8.jpg)

`R²` 值为 1 表示模型捕获了 100% 的方差，而负 `R²` 表明模型表现比仅遵循数据均值的简单模型还要差。

**多重 R 平方值**（0.5039）表明，`Time_Taken` 中约 50.39% 的变异性可由与 `Distance` 的线性关系解释。**调整后 R 平方值**（0.5026）根据模型中的预测变量数量调整 `R²` 值，提供更准确的模型拟合度量。

**F 统计量**（401.2）评估模型的整体显著性。在此例中，F 统计量的 p 值极低（< 2.2e-16），表明该模型在预测 `Time_Taken` 方面具有高度整体显著性。
