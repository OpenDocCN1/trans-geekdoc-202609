## 测试集预测与评估

接下来，我们使用训练好的决策树模型（`Model_rpart`）对测试数据集进行贷款违约预测。`type="class"` 参数确保返回类别标签而非概率。预测结果存储在 `pred_rpart` 变量中。

```r
# Predicting on Test
pred_rpart <- predict(Model_rpart, test, type="class")
```

### 混淆矩阵

```r
# Confusion Matrix
conf_matrix = table(test$default, pred_rpart)
conf_matrix
```

```
## pred_rpart
##    0  1
## 0 159  4
## 1  28  9
```

### 性能指标计算

```r
# Calculate True Positives (TP), True Negatives (TN), False Positives (FP), and False Negatives (FN)
TP <- conf_matrix[2,2]
TN <- conf_matrix[1,1]
FP <- conf_matrix[1,2]
FN <- conf_matrix[2,1]

# Calculate Accuracy
accuracy <- (TP + TN) / sum(conf_matrix)
accuracy
## 0.84

# Calculate Precision
precision <- TP / (TP + FP)
precision
## 0.6923077

# Calculate Recall (Sensitivity)
recall <- TP / (TP + FN)
recall
## 0.2432432
```

基于混淆矩阵，我们计算了准确率、精确率和召回率（灵敏度）指标。准确率是正确预测实例占所有实例的比例，本例中为 0.84。精确率是真阳性占所有预测阳性的比例，结果为 0.69。召回率是真阳性占所有实际阳性的比例，结果为 0.24。

# 回归树

[回归树](#contents.xhtml#sc3_167a)

回归树是另一种决策树类型，用于目标变量为连续值的场景。与预测分类结果的分类树不同，回归树预测数值。

回归树通过递归地将特征空间划分为多个区域来工作，每个区域对应一个预测数值。当需要预测新实例时，它会沿着树向下遍历，遵循每个节点的决策规则，直到到达叶子节点，在那里被分配预测数值。回归树有多种分裂方法，两种常见的方法是平方和减少（RSS）和均方误差减少（MSE）。

RSS 方法使每个分区内预测值与实际值之间的平方差之和最小化。在每个节点，算法会考虑每个特征的所有可能分裂，并计算每个分裂的 RSS。然后选择使所有分区总 RSS 最小化的分裂。

MSE 方法与 RSS 类似，但在某些方面有所不同。它专注于使每个分区内的均方误差最小化。均方误差是预测值与实际值之间平方差的平均值。算法选择使所有分区总 MSE 最小化的分裂。

## 超参数调优

在训练决策树模型时，可以调整多个超参数以帮助降低过拟合风险。三个关键超参数包括：

*   **最大深度** (`maxdepth`)：决策树的最大深度，控制模型的复杂度。更深的树可以捕捉数据中更复杂的模式，但也更容易过拟合。设置较低的最大深度有助于防止树变得过于复杂并拟合训练数据中的噪声。
*   **分裂最小样本数** (`minsplit`)：分裂一个节点所需的最小样本数。增加此参数可以通过在分裂前要求更多样本来减少过拟合，防止树创建特定的、高方差的分裂。
*   **叶节点最小样本数** (`minbucket`)：每个叶节点所需的最小样本数。为此参数设置较高值有助于防止创建样本极少的叶节点，这类节点更容易过拟合训练数据。

通过微调这些超参数，可以在模型复杂度和泛化能力之间取得适当的平衡。一棵过深的树，若分裂和创建叶节点所需的样本太少，很可能会过拟合训练数据。调整这些超参数有助于决策树模型捕捉数据中的潜在模式，而不会变得过于复杂并对噪声或异常值敏感。

# 偏差-方差权衡

[偏差-方差权衡](#contents.xhtml#sc2_168a)

预测误差可理解为两个主要组成部分：偏差误差和方差误差。偏差代表用简化模型近似现实世界问题所引入的误差。它是模型平均预测值与被预测真实值之间的差异。高偏差模型倾向于欠拟合数据，它过度简化了特征与目标变量之间的关系。

方差衡量模型对给定数据点的预测变化程度。它量化了模型对训练数据波动的敏感性。高方差模型倾向于过拟合数据。它将训练数据中的噪声视为真实模式，导致在未见数据上泛化能力差。

偏差-方差权衡源于：减少其中一个分量往往会导致另一个分量增加。高偏差模型复杂度低，可能无法捕捉数据中的潜在模式。同时，高方差模型复杂度高，可能过于紧密地拟合训练数据中的噪声。通过以偏差换取方差（或反之），我们可以为数据集找到一个平衡的模型。下图 [Figure 11.11](#ch11.xhtml#fig11-11) 展示了偏差-方差权衡：
