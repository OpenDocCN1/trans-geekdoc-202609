`ggplot2` 代码片段中的最后一条命令通过更改字体属性来修改 x 轴标签的外观。`theme()` 函数可自定义绘图的各种视觉样式方面。在本例中，`axis.text.x` 参数指定我们要修改 x 轴标签。`element_text()` 使用以下参数为 x 轴标签创建一个新的文本元素：

*   `angle = 90`：将文本顺时针旋转 90 度，使其垂直排列。
*   `vjust = 0.5`：调整文本的垂直对齐方式。在此语境下，它使标签垂直居中。
*   `hjust = 1`：调整文本的水平对齐方式。值为 1 表示右对齐。

解决条形图中长标签挑战的一种更有效方法，通常是交换 x 轴和 y 轴，使条形呈水平方向。这种重新定向缓解了标签重叠的问题，并提供了更清晰、更节省空间的数据表示。

要在 `ggplot2` 中实现此解决方案，我们可以使用 `coord_flip()` 函数，它交换 x 轴和 y 轴，将垂直条形图转换为水平条形图。这解决了 x 轴标签拥挤的问题，并提供了更美观的数据表示。

```
# 香料消费量分布
ggplot(spice_top10, aes(x = Country, y = Value)) +
  geom_bar(stat = "identity") +
  coord_flip()
```

![](images/Figure7.4.png)

图 7.4：香料消费量条形图

无论条形是垂直还是水平排列，其排列顺序都至关重要。随机或任意的排列会导致混淆，使图表不够直观。在 R 中，默认排列是标签的字母顺序，这并不总是组织数据最有意义的方式。以香料消费量图表为例，按香料消费量的顺序重新排列条形更有意义。通过以这种方式重新排列条形，我们可以创建更有效的可视化效果，帮助读者一目了然地理解数据。

```
# 香料消费量分布
ggplot(spice_top10, aes(x = fct_reorder(Country, Value), y = Value)) +
  geom_bar(stat = "identity", fill = "steelblue3") +
  labs(title = "Spice Consumption",
       x = "Country",
       y = "Spice Consumption (kt)") +
  coord_flip() +
  theme_bw()
```

图 7.5：香料消费量条形图

让我们探讨一下上述代码中用于更有意义、更易解释地呈现数据的一些新函数和参数。

`fct_reorder(Country, Value)`：这是 `forcats` 包的一部分，用于根据 `Value` 列中的值重新排序 `Country` 因子的水平。这意味着条形图中的条形将按香料消费量递减的顺序排列。

`fill = steelblue3`：此参数指定用于填充图表中条形的颜色。此处，`fill` 参数设置为 `steelblue3`。

`labs()` 函数为绘图的坐标轴和标题添加标签。它将绘图标题设置为 Spice Consumption，x 轴标签设置为 Country，y 轴标签设置为 Spice Consumption (kt)。

`theme_bw()` 函数为绘图应用黑白主题。`ggplot2` 中的 `theme_` 函数是一组允许用户自定义绘图视觉外观的函数。`ggthemes` 包通过提供具有特定样式的其他预定义主题，扩展了 `ggplot2` 中的主题选项。您可以轻松地将这些主题应用于 `ggplot2` 绘图，以获得美观的外观。

必须注意的是，只有当条形所代表的类别没有自然顺序或层级时，我们才应重新排列条形。如果类别已经有意义地排序（例如，如果我们的分类变量是有序因子），则建议在可视化中保留该顺序。

## 直方图

直方图是连续数据分布的图形表示。直方图是通过将 x 轴划分为等距的区间（称为箱）来创建的。直方图中每个条形的高度代表落在相应箱内的数据点数量。这创建了一个显示数据频率分布的图表，揭示了数据在数值范围内的分布情况。

它们可以告诉我们数据是对称的、向左或向右偏斜的，还是有多个峰值。这些信息对于识别数据中的模式和离群值至关重要。离群值是不遵循其余数据总体模式的观测值，可能表明错误、异常或有趣的现象。通过检查直方图，我们可以轻松发现离群值，并决定它们是否值得进一步调查。

在 `ggplot2` 中，您可以使用 `binwidth` 参数设置区间的宽度。尝试不同的箱宽以找到最能说明数据潜在结构的最佳区间大小至关重要。您也可以选择使用 `bins` 参数指定箱的数量，默认设置为 30。

现在，我们将从 FAOSTAT 导入一个营养不良指标数据集，并创建 173 个国家营养不良患病率的直方图。联合国粮农组织（FAO）将营养不良患病率（PoU）定义为一个估计值，代表常规食物摄入量低于维持正常、活跃和健康生活所需的膳食能量水平的人口百分比。以下代码生成直方图以可视化 2021 年营养不良患病率的分布。

```
# 读取数据集
undernourishment <- read.csv("undernourishment_data.csv")

# 筛选 2021 年数据
undernourishment_2021 <- undernourishment %>% filter(Year == 2021)

# 营养不良患病率分布
ggplot(undernourishment_2021, aes(x = Value)) +
  geom_histogram(binwidth = 2, fill = "steelblue3", color = "black") +
  labs(title = "Prevalence of Undernourishment",
       x = "Prevalence (%)",
       y = "Frequency") +
  theme_bw()
```

![](images/Figure7.6.png)

图 7.6：营养不良患病率分布

> **注意：** 在 FAO 数据集中，营养不良率低于 2.5% 的国家和地区被归类为 2.5%。

此处，`geom_histogram(binwidth = 2, fill = "steelblue3", color = "black")` 使用 `geom_histogram()` 向绘图添加直方图层。它将 x 轴划分为宽度为 2 的箱，并用 `steelblue3` 填充每个箱；每个箱的边框为黑色。

要在直方图的每个条形上方添加计数标签，可以使用统计变换函数 `stat_bin()`。它允许我们直接在相应条形顶部显示每个箱内的频率计数。这一简单的添加可以提供对潜在分布更精确的理解。它还可以帮助您准确比较不同箱以及跨不同数据集的情况。

```
# 营养不良患病率分布
ggplot(undernourishment_2021, aes(x = Value)) +
  geom_histogram(binwidth = 2, fill = "steelblue3", color = "black") +
  labs(title = "Prevalence of Undernourishment",
       x = "Prevalence (%)",
       y = "Frequency") +
  stat_bin(aes(label = after_stat(count)),
           binwidth = 2,
           geom = "text", vjust = -0.5, color = "black", size = 3) +
  theme_bw()
```
