# 线性模型的局限性

线性模型的局限性如下：

*   当输入变量与输出变量之间的关系近似线性时，线性模型简单且有效。虽然线性模型提供了简洁性和可解释性，但由于其固有的线性假设，它们可能无法始终捕捉数据中存在的复杂关系。
*   线性模型在捕捉变量间的非线性关系和交互作用方面存在固有局限。这可能导致欠拟合，即模型无法捕捉数据中真实的潜在模式。
*   线性模型对异常值敏感，异常值可能不成比例地影响模型参数和预测，导致估计产生偏差。

既然我们已经探讨了线性模型，现在让我们转向另一种预测建模技术：决策树。

# 决策树

决策树是一种使用树形模型来表示决策及其可能后果的机器学习算法。决策树由节点和分支组成。最顶层的节点称为根节点。它代表初始问题。每个分支代表节点上测试的结果，每个节点代表对一个属性（或自变量）的测试。叶节点代表结果或类别标签（在分类问题中）或数值（在回归问题中）。

描述决策树时使用了几个关键术语和概念：

*   **根节点**：代表整个样本总体或数据集，并作为构建树的起点。
*   **决策节点**：决策树中基于特征值做出决策的节点。
*   **终端/叶节点**：决策树中分配结果或类别标签的节点。
*   **深度**：测量从根节点沿分支到叶节点的路径长度，通常用于在生长过程中控制树的大小。
*   **分裂准则**：用于确定在每个节点按哪个特征和值分裂数据的度量，通常基于基尼不纯度、熵或信息增益等指标。
*   **剪枝**：通过移除预测能力较弱的树枝来减小决策树规模的过程。它有助于避免过拟合并提高泛化性能。

决策树的一些优势包括：

*   **模型可解释性**：决策树的一大优势是其能够提供清晰的见解以简化决策过程。决策树生成的规则促进了与领域专家和监管机构的沟通与协作。
*   **非参数方法**：它们适用于解决各种问题结构，无需对数据分布做严格假设。
*   **处理混合数据类型**：决策树可处理数值型和分类型特征，简化了预处理工作。
*   **抗异常值能力**：与参数方法相比，决策树对极端观测值表现出更强的韧性。

然而，缺点主要源于过拟合风险和对数据集微小变化的敏感性。解决这些问题涉及超参数调优或利用集成技术。

决策树主要有两类：

*   **分类树**处理离散或分类因变量。
*   **回归树**处理连续因变量。

## 分类树

分类树是一种决策树，用于预测给定数据点的类别或类别。它们通过递归地将特征空间划分为若干区域来工作，每个区域对应一个特定的类别标签。当需要对新实例进行分类时，它会沿着树向下遍历，遵循每个节点的决策规则，直到到达叶节点，在那里分配类别标签。有几种不同的方法用于确定如何在每个节点分裂数据。两种常见的方法是基尼指数和熵。

*   **基尼指数**：衡量一组数据点的不纯度或不确定性。其范围从 0 到 1，其中 0 表示完全纯净（所有元素属于同一类），1 表示最大不纯度（元素在所有类别中均匀分布）。具有 C 个类别的集合 S 的基尼不纯度指数计算公式为：

基尼指数方法旨在最大化分裂后子节点的纯度，从而构建出分类更准确的决策树。

*   **熵**：是衡量一组数据点随机性或不确定性的指标。在决策树的背景下，熵用于量化节点的不纯度。低熵的节点意味着它是纯净的（所有数据点属于同一类），而高熵的节点意味着它是不纯净的（数据点在各类别间均匀分布）。信息增益是通过在特定特征上分裂节点所实现的熵减少量来衡量的。决策树算法选择使信息增益最大化的分裂。具有 C 个类别的集合 S 的熵由以下公式给出：

让我们构建一个决策树，使用 `rpart`（递归分区和回归树）来预测贷款违约。

```r
# load the required libraries
library(rpart)
library(rpart.plot)

# Train a Decision Tree model 
Model_rpart = rpart(default ~ credit_score + debt_to_income_ratio,
                    data = train, method = "class", maxdepth = 5)
```

在这里，模型基于两个输入特征：`credit_score` 和 `debt_to_income_ratio` 来预测贷款违约 (`default`) 的二元结果。训练数据存储在 `train` 数据集中。`method = "class"` 参数指定该模型用于分类，`maxdepth = 5` 参数将决策树的最大深度限制为 5 层。

生成的 `Model_rpart` 对象代表训练好的决策树模型，可用于对新数据进行预测。
