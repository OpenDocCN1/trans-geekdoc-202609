

# R 语言中的列表

列表是 R 语言中一种有用的数据结构，可以容纳任意 R 对象的集合。与向量和矩阵不同，列表中的对象允许不同的类型，包括字符型、数值型，甚至其他列表。因此，列表非常通用，有助于完成各种任务，例如排列复杂的数据结构或开发自定义函数。Aarya 可以使用列表以有意义的方式组织她的 Netflix 数据，如下面的列表所示：

```r
# 创建一个向量列表
movies_list <- list(
  movie_names = c("Inception", "The Dark Knight", "Edge of Tomorrow"),
  movie_durations = c(148, 152, 113),
  genre = factor(c("Sci-fi", "Action", "Sci-fi")),
  ratings = factor(c(3, 5, 4), ordered = TRUE, levels = c(3, 4, 5))
)

# 打印列表
movies_list
```

## 输出

```
## $movie_names
## [1] "Inception" "The Dark Knight" "Edge of Tomorrow"
##
## $movie_durations
## [1] 148 152 113
##
## $genre
## [1] Sci-fi Action Sci-fi
## Levels: Action Sci-fi
##
## $ratings
## [1] 3 5 4
## Levels: 3 < 4 < 5
```

在本例中，我们创建了一个名为 `movies_list` 的列表，它包含四个不同类型的向量——字符型、数值型、因子和有序因子。我们使用 `list()` 函数创建列表，并使用相同的语法为每个向量分配了名称。

# 数据框

数据框是一种包含行和列的表格结构。它无非就是列表的二维版本。每一列可以有不同的数据类型，且必须有一个名称。数据框常用于存储和操作数据，因为它们易于处理，并允许进行许多操作，例如筛选、排序和汇总数据。让我们熟悉一下数据框，这是最常用的 R 对象之一。

# 函数

函数封装重复或复杂的操作，使代码更有条理、高效且可复用。在 R 语言中，函数可以是内置的、用户定义的，或从包中加载的。自定义函数使用 `function()` 关键字定义，后跟函数名称及其参数（在括号中）。函数体则包含在花括号 `{}` 中。让我们为各种业务场景创建一些自定义函数。

## 电子商务

一个函数，用于计算电子商务网站上某产品产生的总收入，给定产品价格和销售数量：

```r
# 计算总收入的函数
calculate_revenue <- function(price, num_sold) {
  total_revenue <- price * num_sold
  return(total_revenue)
}
```

这里，`price` 是电子商务网站上产品的价格，`num_sold` 是销售数量。该函数将价格与销售数量相乘来计算产品产生的总收入，并返回结果：

```r
# 定义向量以计算收入
price <- c(250, 2099, 1999, 750)
num_sold <- c(1000, 250, 100, 1150)

# 计算每个产品的总收入
total_revenue <- calculate_revenue(price, num_sold)

# 打印结果
total_revenue
```

## 输出

```
## 250000 524750 199900 862500
```

这里，我们定义了两个向量 `price` 和 `num_sold`，分别包含四种不同产品的价格和销售数量。然后我们将这些向量作为参数传递给 `calculate_revenue` 函数，该函数计算每个产品的总收入并返回一个结果向量。

## 市场营销

一个函数，用于计算营销活动的转化率，给定展示次数和点击次数：

```r
# 计算转化率的函数
calculate_conversion_rate <- function(impressions, clicks) {
  conversion_rate <- clicks / impressions
  return(conversion_rate)
}
```

这里，`impressions` 是营销信息展示的次数，`clicks` 是被点击的次数。该函数通过将点击次数除以展示次数来计算转化率。

你可以将 `conversion_rate` 函数用于包含展示次数和点击次数的数据向量：

```r
# 定义展示次数和点击次数向量
impressions <- c(1205, 2000, 1532, 4101)
clicks <- c(90, 75, 82, 210)

# 计算每个广告活动的转化率
conversion_rates <- calculate_conversion_rate(impressions, clicks)

# 打印转化率
conversion_rates
```

## 输出

```
## 0.07468880 0.03750000 0.05352480 0.05120702
```

这里，我们定义了两个数据向量 `impressions` 和 `clicks`，分别包含四个不同广告活动的展示次数和点击次数。然后我们将这些向量作为参数传递给 `conversion_rate` 函数，该函数计算每个活动的转化率并返回一个结果向量。我们也可以使用 `round()` 来对结果进行四舍五入。

## 金融

一个函数，用于计算贷款的复利，给定本金、利率、贷款期限（年）以及每年计息次数：

```r
# 计算复利的函数
calculate_compound_interest <- function(principal, interest_rate, years, compounding_frequency) {
  n <- compounding_frequency
  interest <- principal * (1 + interest_rate / n)^(n * years) - principal
  return(interest)
}

# 定义向量输入
principal <- c(5000, 7500, 9200)
```
