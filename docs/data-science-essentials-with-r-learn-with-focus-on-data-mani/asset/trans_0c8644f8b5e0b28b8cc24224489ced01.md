
# 使用 `melt()` 和 `dcast()` 重塑数据

`melt()` 的关键参数之一是 `id.vars`。该参数指定在长格式数据中保留哪些列作为 ID 变量。这些列将保持原样，输出数据中的每一行将对应 ID 变量中值的唯一组合。

在我们的停车数据集中，`SystemCodeNumber` 和 `LastUpdated` 唯一标识每个观测值。因此，它们是 ID 变量的良好候选者，因为每一行代表 `SystemCodeNumber` 和 `LastUpdated` 的唯一组合。

```r
# 将 parking_df 从宽格式转换为长格式数据
parking_melt <- melt(parking_df, id.vars = c("SystemCodeNumber", "LastUpdated"))

# 显示熔化后 DataFrame 的前 6 行
head(parking_melt)
```

```
## SystemCodeNumber LastUpdated variable value
## BHMBCCMKT01 2016-10-04 07:59:42 Capacity 577
## BHMBCCMKT01 2016-10-04 08:25:42 Capacity 577
## BHMBCCMKT01 2016-10-04 08:59:42 Capacity 577
## BHMBCCMKT01 2016-10-04 09:32:46 Capacity 577
## BHMBCCMKT01 2016-10-04 09:59:48 Capacity 577
## BHMBCCMKT01 2016-10-04 10:26:49 Capacity 577
```

标记为 Capacity 和 Occupancy 的列合并到一个名为 Variable 的更大类别中，而它们各自的测量值则堆叠在 value 列之下。要自定义长格式数据中熔化列（variable 和 value）的默认列标题，可以使用 `variable.name` 和 `value.name` 参数。这些参数允许你分别指定将保存变量名和值的列的名称。

```r
# 自定义 variable 和 value 的默认列标题
parking_melt <- melt(parking_df, id.vars = c("SystemCodeNumber", "LastUpdated"),
                     variable.name = "parking_variable",
                     value.name = "parking_value")

# 打印更新后 parking_melt 的前 6 行
head(parking_melt)
```

```
## SystemCodeNumber LastUpdated parking_variable parking_value
## BHMBCCMKT01 2016-10-04 07:59:42 Capacity 577
## BHMBCCMKT01 2016-10-04 08:25:42 Capacity 577
## BHMBCCMKT01 2016-10-04 08:59:42 Capacity 577
## BHMBCCMKT01 2016-10-04 09:32:46 Capacity 577
```

## 将长格式数据转换为宽格式数据

`reshape2` 包提供了多个函数用于将数据从长格式转换为宽格式。由于我们经常处理 DataFrame，我们将重点关注 `dcast()` 函数。如果需要，也可以使用 `acast()` 转换为向量、矩阵或数组。

要使用 `dcast()` 函数，你需要指定一些参数。首先，你需要使用 `data` 参数指定要转换的 DataFrame。接下来，你需要使用 `formula` 参数指定一个公式。该公式将指定你想要用于将数据从长格式转换为宽格式的变量。你还需要使用 `value.var` 参数指定包含要转换值的列。最后，如果有必要，你可以使用 `fun.aggregate` 参数指定一个在转换前应用于数据的函数。

现在，让我们关注之前创建的长格式数据 `parking_melt`，并使用它恢复到原始的宽格式数据：

```r
# 将 parking_melt 从长格式转换为宽格式数据
parking_cast <- dcast(parking_melt, SystemCodeNumber + LastUpdated ~ parking_variable, value.var = "parking_value")

# 显示更新后 parking_cast 的前 6 行
head(parking_cast)
```

```
## SystemCodeNumber LastUpdated Capacity Occupancy
## BHMBCCMKT01 2016-10-04 07:59:42 577 61
## BHMBCCMKT01 2016-10-04 08:25:42 577 64
## BHMBCCMKT01 2016-10-04 08:59:42 577 80
## BHMBCCMKT01 2016-10-04 09:32:46 577 107
## BHMBCCMKT01 2016-10-04 09:59:48 577 150
## BHMBCCMKT01 2016-10-04 10:26:49 577 177
```

我们将在以下代码中仔细查看 `dcast()` 函数中使用的公式：

```r
SystemCodeNumber + LastUpdated ~ parking_variable
```

该公式定义了用于将数据从长格式转换为宽格式的变量。在公式中，波浪号（`~`）将左侧（LHS）与右侧（RHS）分开。我们在左侧有两个 ID 变量，`SystemCodeNumber` 和 `LastUpdated`。这些变量将成为生成的宽格式数据的行名。在右侧，我们有 `parking_variable`，即包含要在宽格式数据中使用的变量名的列。

通过在公式中同时指定行变量和列变量，它创建了一个宽格式 DataFrame，其中每个 `SystemCodeNumber` 和 `LastUpdated` 的唯一组合对应一行，而 `parking_variable` 列中的每个唯一值对应一列。

## 分组与汇总数据

接下来，为了加深你对基于分组变量汇总数据的理解，我们将利用加州大学欧文分校机器学习存储库中的批发客户数据集。

批发客户数据集指的是一家批发分销商 440 位客户的消费行为。该数据集包含每位客户在不同产品类别上的年支出（货币单位 M.U.）：鲜食产品、奶制品、杂货产品、冷冻产品、洗涤剂和纸制品、熟食产品。

```r
# 读取批发客户数据集
wholesale_df <- read.csv("Wholesale customers data.csv")

# DataFrame 的结构
str(wholesale_df)
```

在以下数据中，Region 中的水平 1、2 和 3 分别对应里斯本、波尔图和其他地区。Channel 中的水平 1 和 2 分别对应餐饮住宿业（Hotel/Restaurant/Café）和零售业，如下所示：

```r
# 将 Region 和 Channel 转换为具有相应水平和标签的因子
wholesale_df <- wholesale_df %>%
  mutate(Region = factor(Region, levels = c(1, 2, 3),
                         labels = c("Lisbon", "Oporto", "Other Region")),
         Channel = factor(Channel, levels = c(1, 2),
                          labels = c("Horeca", "Retail")))

# 检查 Channel 和 Region 列的频数
table(wholesale_df$Channel)
```

```

## 298 142
```

```r
table(wholesale_df$Region)
```

```

## 77 47 316
```

> **注意：** `mutate()` 函数基于现有变量生成新列。如果同名列已存在，也可以修改它。此外，通过将列的值赋为 `NULL` 可以删除列。

这里，`mutate()` 函数修改了两个变量：`Region` 和 `Channel`。我们在 `mutate()` 中使用 `factor()` 函数将 `Region` 和 `Channel` 列的数值转换为具有指定相应水平和标签的因子：

```r
# 计算每个产品类别的平均支出
spending_summary <- wholesale_df %>%
  summarise(mean_fresh = mean(Fresh),
            mean_milk = mean(Milk),
            mean_grocery = mean(Grocery),
            mean_frozen = mean(Frozen),
            mean_detergents_paper = mean(Detergents_Paper))
```
