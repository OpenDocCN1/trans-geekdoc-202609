
One crucial aspect of `mutate()` is that it creates a new DataFrame with additional columns rather than modifying the original DataFrame in place. This is a valuable feature because it allows the user to keep track of the original data and apply multiple transformations without overwriting it.

How can we create a new variable that represents the population in millions?

*   `# add a new column, population_millions`
*   `gapminder_population <- gapminder %>%`
*   `mutate(population_millions = population / 1000000)`
*   
*   `# add a new column, population_millions`
*   `gapminder_population2 <- gapminder %>%`
*   `mutate(population_millions = round(population / 1000000, 2))`

It creates a new column called `population_millions` using the `mutate()` function by dividing the existing `population` column by 1,000,000 and rounding the result to two decimal places using the `round()` function. The command returns a DataFrame, `gapminder_population2`, containing all columns of the original Gapminder DataFrame along with a new column, `population_millions`, with the population of each country in millions.

How can we extract the countryname, year, life expectancy, continent, and region of countries and identify which countries are located in Asia?

*   `# extract the country name, year, life expectancy, continent, and region of countries and identify which countries are located in Asia or not`
*   `gapminder_is_asia <- gapminder %>%`
*   `select(country, year, life_expectancy, continent, region) %>%`
*   `mutate(is_asia = ifelse(continent == "Asia", 1, 0))`
*   
*   `View(gapminder_is_asia)`

This command adds a new column called `is_asia` using the `mutate()` function. The new column contains a binary value of 1 or 0 depending on whether the country is located in Asia or not. The `ifelse()` function from the base package is used to assign the binary value. If the `continent` value is Asia, it assigns a value of 1; otherwise, a value of 0 is set.

This variable can help to analyze and compare trends and patterns between countries in Asia and those outside the region.

## Working with factors

One of the key benefits of using factors in R is that it provides a way to preserve the underlying order of data, which can be necessary for analysis and visualization. For example, suppose you have a dataset of customer satisfaction ratings on a scale of 1 to 5, where 1 represents very dissatisfied, and 5 illustrates very satisfied. If you store this variable as a factor, R will preserve the order of the levels, which is important for calculating summary statistics.

In this section, you will use the `forcats` package, a part of the tidyverse suite of packages in R, that provides additional functionality for working with factors. For instance, it allows for easy manipulation of factor levels and labels and offers functions to reorder and rename factor levels.

How can you count the number of observations in each continent?

*   `# check levels attribute of the factor variable, continent`
*   `levels(gapminder$continent)`
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania"`
*   
*   `# count the number of observations in each continent`
*   `continent_count <- fct_count(gapminder$continent)`
*   
*   `View(continent_count)`
*   `## f n`
*   `## Africa 2907`
*   `## Americas 2052`
*   `## Asia 2679`
*   `## Europe 2223`
*   `## Oceania 684`
*   
*   `# sort the result by setting argument, sort to TRUE, and also display fraction by prop argument`
*   `continent_count_sorted <- fct_count(gapminder$continent, sort = TRUE, prop = TRUE)`
*   
*   `View(continent_count_sorted)`
*   `## f n p`
*   `## Africa 2907 0.276`
*   `## Asia 2679 0.254`
*   `## Europe 2223 0.211`
*   `## Americas 2052 0.195`
*   `## Oceania 684 0.0649`

`fct_count()` returns a DataFrame with two columns: the factor levels and their corresponding frequencies in the input vector. In this case, it will return a DataFrame with the unique continents in the Gapminder dataset and the number of times each continent has occurred.

How can you add new levels to the continent variable?

One of the variables in our dataset is `continent` which contains information about the continent each country belongs to. Now, let us say you noticed that the continent Antarctica is missing from the `continent` variable, and you want to add it to the factor levels. One way to do this is to use the `fct_expand()` function from the `forcats` package.

*   `# add "Antarctica" to the continent variable`
*   `gapminder$continent <- fct_expand(gapminder$continent, "Antarctica")`
*   
*   `# check levels of the continent to verify if Antarctica has been added or not`
*   `levels(gapminder$continent)`
*   
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania" "Antarctica"`
*   
*   `# count the number of observations of each continent`
*   `fct_count(gapminder$continent)`
*   `## A tibble: 6 x 2`
*   `## f n`
*   `## <fct> <int>`
*   `## Africa 2907`
*   `## Americas 2052`
*   `## Asia 2679`
*   `## Europe 2223`
*   `## Oceania 684`
*   `## Antarctica 0`

> **Note:** If the Antarctica level already existed in the continent variable, `fct_expand()` would not add it again. Instead, it would just return the original factor with its levels unchanged.

How can you drop unused levels from the continent variable?

To drop unused levels from the continent variable, you can use the `fct_drop()` function. Here is how you can do it:

*   `# drop unused levels from the continent variable`
*   `gapminder$continent <- fct_drop(gapminder$continent)`

Now, if you recheck the levels of the continent, you will notice the unused level, Antarctica is removed.

*   `levels(gapminder$continent)`
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania"`

How can you move Asia to the second position in the continent column?

In a few scenarios, releveling factors becomes essential because it allows you to change the order of the levels of a categorical variable, which can affect the behavior of statistical functions and data visualizations.

For example, if you have a factor variable representing the days of the week, the default order of levels will be alphabetical (that is, Friday, Monday, Saturday, Sunday, Thursday, Tuesday, Wednesday). However, suppose you want to analyze or visualize your data by order of days in the week. In that case, reordering the factor levels to reflect the logical order of the days (i.e., Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday) is necessary.

*   `# move Asia to the second position`
*   `gapminder$continent <- fct_relevel(gapminder$continent, "Asia", after = 1)`
*   
*   `levels(gapminder$continent)`
*   `## "Africa" "Asia" "Americas" "Europe" "Oceania"`

This command will modify the `continent` column by moving the level Asia to the second position after the first, default level. The argument specifies the position after which the level should be moved.

## Handling missing values

The symbol `NA` (not available) is used in R to represent missing values, whereas impossible values (such as dividing by zero) are represented by Not a Number (`NaN`).

The function `is.na()` is used to check if an object has any missing values represented by `NA`, whereas `is.nan()` is used to test if an object has any `NaN` values.

For example, to check for missing values in the `infant_mortality` variable, you can use the following code:

*   `# number of missing values in the column infant_mortality`
*   `sum(is.na(gapminder$infant_mortality))`
*   `## 1453`

This will give us the total number of missing values in the `infant_mortality` variable. We can use the same code for other variables to check the missing values. To know the number of missing values in the dataset column-wise, you can use the following code:

*   `# number of missing values in each column of gapminder dataset`
*   `colSums(is.na(gapminder))`
*   `## country year infant_mortality life_expectancy fertility`
*   `## 0 0 1453 0 187`
