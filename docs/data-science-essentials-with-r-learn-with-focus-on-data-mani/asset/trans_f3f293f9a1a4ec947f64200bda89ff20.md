### 类

R 中的每个对象都有一个 `class` 属性，用于标识该对象的类型。这一点至关重要，因为 R 拥有大量可用于各种对象类型的函数。例如，你可以使用 `mean()` 函数计算数值向量的平均值，但不能用它来计算字符向量的平均值。这是因为对字符串求平均值在逻辑上讲不通。

当我们创建对象时，R 可能会自动为其分配一个类。例如，当你使用 `c()` 函数创建一个数字向量时，R 会为其分配 `numeric` 类。`class()` 函数也允许你直接为对象分配一个类。下表展示了用于测试变量中存储的数据类型以及在必要时在不同数据类型之间转换变量的函数：

| 数据类型 | 逻辑测试 | 强制转换函数 |
| --- | --- | --- |
| 数值型 | `is.numeric()` | `as.numeric()` |
| 整数型 | `is.integer()` | `as.integer()` |
| 字符型 | `is.character()` | `as.character()` |
| 逻辑型 | `is.logical()` | `as.logical()` |
| 因子 | `is.factor()` | `as.factor()` |
| 日期 | `is.Date()` | `as.Date()` |
| POSIXct | `is.POSIXct()` | `as.POSIXct()` |
| 矩阵 | `is.matrix()` | `as.matrix()` |
| 数组 | `is.array()` | `as.array()` |

表 2.3：不同数据类型的逻辑测试和强制转换函数

`is.*` 函数返回一个逻辑值（`TRUE` 或 `FALSE`），指示输入变量是否为指定类型。`as.*` 函数将输入变量强制转换为指定类型。重要的是要注意，强制转换可能导致数据丢失或意外行为，因此应谨慎使用。

> **注意：** 你也可以使用 `c()` 连接不同数据类型的向量，例如数值向量和字符向量。然而，当你连接不同数据类型的向量时，R 会将所有值转换为单一数据类型。

### 日期和时间

R 提供了多种用于处理日期和时间的类，包括 `Date`、`POSIXct` 和 `POSIXlt`。这些类使 Aarya 能够存储和操作日期和时间值，从而更容易随时间分析她的 Netflix 使用情况。

例如，Aarya 可以使用 `as.Date()` 函数创建一个日期对象，表示她开始观看某个电视节目的日期。她也可以使用 `as.POSIXct()` 创建一个 `POSIXct` 对象，表示她开始观看某一集的具体时间。创建后，她可以对这些对象执行各种操作，例如使用 `format()` 函数提取月份或年份，或使用 `difftime()` 函数计算两个日期之间经过的时间。我们将在[第 5 章](#ch05.xhtml)“处理日期”中深入探讨日期功能。

现在，假设 Aarya 想计算她在一月份观看电视节目所花费的总时间。她可以首先创建一个 `POSIXct` 向量，包含她在一月观看的所有节目的开始时间。她可以使用 `as.POSIXct()` 函数来实现这一点：

```r
# 观看电视节目的开始时间
jan_start_times <- as.POSIXct(c("2023-01-07 14:00:00", "2023-01-08 15:30:00", "2023-01-14 18:00:00", "2023-01-22 19:00:00"))
```

接下来，她可以创建一个 `POSIXct` 向量，包含她在一月观看的所有节目的结束时间：

```r
# 观看电视节目的结束时间
jan_end_times <- as.POSIXct(c("2023-01-07 16:00:00", "2023-01-08 16:30:00", "2023-01-14 20:00:00", "2023-01-22 22:00:00"))
```

现在，她可以通过从结束时间减去开始时间来计算每个节目的时长，如下所示：

```r
# 计算每个节目花费的时间
jan_durations <- jan_end_times - jan_start_times

# 打印 jan_durations
jan_durations
## Time differences in hours
## 2 1 2 3
```

最后，她可以将这些时长相加，得到她在一月份观看电视节目的总时长：

```r
# 计算总时长
jan_total_duration <- sum(jan_durations)

# 打印 jan_total_duration
jan_total_duration
## Time difference of 8 hours
```

通过这种方式，Aarya 可以利用日期和时间对她的 Netflix 使用情况随时间的变化进行基本计算和分析。

### 因子

在 R 中，分类数据使用因子表示。电影类型或评分是固定可能值集合内分类数据的示例。在 R 对因子的表示中，每个数字代表一个不同的类别。

因子是存储字符值的高效方式，因为它们使用整数向量来表示唯一值，每个值仅存储一次。这种存储方法在保持原始字符信息的同时减少了存储数据所用的内存。例如，Aarya 的 Netflix 数据中有一列用于电影类型和评分。在 `factor()` 函数的帮助下，她可以将这些列转换为因子。假设 Aarya 有以下数据：

```r
# 创建电影类型向量
movie_genres <- c("Action", "Action", "Romance", "Thriller", "Thriller", "Thriller")

# movie_genres 的类
class(movie_genres)
## "character"

# 创建电影评分向量
movie_ratings <- c(4, 3, 2, 5, 5, 3)

# movie_ratings 的类
class(movie_ratings)
## "numeric"
```

Aarya 可以按如下方式从这些向量创建因子：

```r
# 为电影类型创建因子
movie_genres_factor <- factor(movie_genres)

# movie_ratings 的类（原文如此，应为 movie_genres_factor 的类）
class(movie_genres_factor)
## "factor"

# 为电影评分创建因子
movie_ratings_factor <- factor(movie_ratings)

# movie_ratings_factor 的类
class(movie_ratings_factor)
## "factor"
```

在本例中，Aarya 创建了两个因子：`movie_genres_factor` 和 `movie_ratings_factor`。R 会为因子中的每个唯一值分配一个整数值。Aarya 可以使用 `levels()` 函数查看每个因子中的唯一值：

```r
# 查看电影类型因子中的唯一值
levels(movie_genres_factor)
## "Action" "Romance" "Thriller"

# 查看电影评分因子中的唯一值
levels(movie_ratings_factor)
## "2" "3" "4" "5"
```

Aarya 也可以使用 `levels()` 函数为每个水平分配自定义标签：

```r
# 为电影类型因子分配自定义标签
levels(movie_genres_factor) <- c("Act", "Rom", "Thrill")

# 为电影评分因子分配自定义标签
levels(movie_ratings_factor) <- c("two", "three", "four", "five")
```

因子还可以是有序或无序的。在 Aarya 的例子中，她可能想根据评分对电影进行排序。她可以使用 `ordered()` 函数创建一个有序因子：

```r
# 为电影评分创建有序因子
movie_ratings_ordered_factor <- ordered(movie_ratings, levels = c(2, 3, 4, 5))

# 打印 movie_ratings_ordered_factor
movie_ratings_ordered_factor
## 4 3 2 5 5 3
## Levels: 2 < 3 < 4 < 5
```

`levels = c(2, 3, 4, 5)` 参数指定了因子中水平的顺序。在本例中，我们按评分升序指定了水平，从 2 到 5：

```r
# 查看电影评分因子中的有序水平
levels(movie_ratings_ordered_factor)
## "2" "3" "4" "5"
```

因子是 R 中表示分类数据的基本数据类型，`factor()` 函数可以轻松地将字符向量转换为因子。
