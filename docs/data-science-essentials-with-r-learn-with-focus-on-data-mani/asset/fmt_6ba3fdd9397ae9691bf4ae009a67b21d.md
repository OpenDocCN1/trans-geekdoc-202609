
# 机器学习问题定义与数据要求

## 何时使用机器学习

虽然有人认为机器学习（ML）是一种适用于所有类型业务问题的通用工具，但现实是 ML 是为解决特定问题而设计的专用工具。必须避免在更简单的非 ML 方法足以解决问题时，实施复杂的 ML 解决方案。

为确保 ML 是最佳方法，请在投资 ML 替代方案前，彻底评估现有非 ML 解决方案的性能。请考虑以下问题以确定是否需要 ML 解决方案：

*   **量化预期改进**：与现有（已优化的）非 ML 解决方案相比，ML 解决方案能否带来显著影响？较小的收益可能意味着应坚持当前方法。
*   **成本对比**：审视 ML 解决方案相关的短期和长期费用。ML 实施可能在计算资源和时间方面产生巨大成本。
*   **成本效益论证**：在大型系统中，即使 ML 带来的微小改进也能转化为显著收益，从而抵消实施和维护成本。
*   **维护考量**：ML 模型通常需要专人负责监控、重新训练和潜在调试。评估团队是否具备长期维护所需的资源和专业知识。

## 训练数据质量要求

用于训练的数据质量在决定模型准确性和有效性方面起着至关重要的作用。为创建稳健可靠的模型，数据应具备以下关键特征：

*   **数据量与相关性**：数据集中相关且有价值的示例越多，模型越稳健。更大的数据集为模型提供了更广泛的泛化空间，并提升其预测能力。
*   **数据收集可靠性**：数据收集流程应当合理，并应尽力减少数据录入、存储和处理过程中的错误。一致可靠的数据集使模型能够学习有意义的模式，降低偏差风险。
*   **标注准确性**：虽然大型数据集中难免存在少量标注错误，但高比例的错误标签会严重损害模型性能。确保标注准确对于构建产生可信预测的模型至关重要。
*   **真实世界代表性**：数据集应尽可能贴近被建模的真实场景。这意味着要捕捉实际环境中发生的相关事件、用户行为和其他现象。这样模型才能适应现实世界的变化和变体，在预测时表现更佳。

满足这些数据要求对于创建强大且可靠的预测性 ML 模型不可或缺。

## 特征预测能力

为使模型生成准确预测，数据集中的特征必须具备显著的预测能力。特征与其对应标签之间的相关程度直接影响其预测准确性。相关性越高，该特征作为给定标签的可靠预测指标的可能性越大。

在**医疗患者再入院预测**场景中，不同特征表现出不同程度的预测能力。`previous_hospitalizations`、`medication_compliance` 和 `age` 等特征可能具有较高的预测能力。既往住院次数可反映患者健康史，`medication_compliance` 反映治疗依从性，`age` 可成为预测再入院风险的关键因素。另一方面，`patient_gender` 和 `day_of_week` 等特征预测能力可能较低。

然而，必须认识到特征的预测能力可能依赖于上下文。在医疗保健的特定子领域中，通常预测能力较低的特征可能变得更有影响力。因此，理解特征相关性在不同语境或领域中的动态性质，对于构建准确且符合语境的预测模型至关重要。

## 选择 ML 模型类型

决定使用哪种类型的 ML 模型并非“一刀切”的情况。模型的输出需要满足您期望的结果。因此，第一个关键问题是：**什么样的输出能有效解决我的问题？**

*   如果目标涉及**分类**或**数值预测**，预测性 ML 可能是合适的选择。
*   如果任务涉及**生成新内容**、**翻译语言**或**创建类人对话**，生成式 AI 将是恰当的选择。

接下来，您需要定义关键绩效指标（`KPIs`），以衡量 ML 实施的成功与否。这些 `KPIs` 应与项目目标对齐，并传达最重要的方面，如提升用户体验、增加参与度或促进适当行动。成功指标示例包括：

*   **参与度**：追踪用户与平台交互的时长、推荐项目的点击次数或回访频率。
*   **转化率**：监控采取期望行动的用户比例，如购买产品、注册服务或完成任务。
*   **时间节省**：评估 ML 实施在多大程度上减少了用户搜索相关内容或解决问题所花费的时间。
*   **成本效益**：计算利用 ML 技术实现的成本节约。此评估可能需要对比实施 ML 系统的支出与传统人工流程的相关成本。
