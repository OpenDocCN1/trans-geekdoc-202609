```r
predicted_values <- predict(lm_time, newdata = test)
```

然后，创建一个新的数据框 `compare_df`，包含两列：`Actual` 和 `Predicted`。`Actual` 列代表测试数据集中响应变量 `Time_Taken` 的真实值，`Predicted` 列包含从线性回归模型获得的相应预测值。

```r
# Create a dataframe with Actuals and Predicted values
compare_df <- data.frame(Actual = test$Time_Taken, Predicted = predicted_values)
```

### 均方根误差 (RMSE)

```r
# Root Mean Squared Error (RMSE)
rmse(compare_df$Actual, compare_df$Predicted)
```

```
## 3.974987
```

### 平均绝对误差 (MAE)

```r
# Mean Absolute Error (MAE)
mae(compare_df$Actual, compare_df$Predicted)
```

```
## 3.289056
```

在这种情况下，RMSE 为 3.975，表明平均而言，模型的预测值与实际值偏离约 3.975 个 `Time_Taken` 单位。与 RMSE 相比，MAE 提供了更具可解释性的误差度量。MAE 值 3.29 表明模型的预测值平均与实际值相差约 3.29 个单位。

## 逻辑回归

逻辑回归在生成概率估计作为输出方面非常高效。这些概率可通过以下两种方式使用：

*   直接使用返回的概率，无需任何转换。
*   根据指定阈值将概率转换为二元类别。

在逻辑回归中，我们建模自变量与因变量处于特定类别的对数几率之间的关系。几率定义为事件发生的概率与不发生的概率之比。

## 逻辑回归的似然函数

在逻辑回归中，似然函数用于估计模型参数（系数），以最大化在给定模型下观察到训练数据的概率。由于逻辑回归预测概率，因此它特别适合使用似然函数对二元数据进行建模。

其中，`p(xi)` 是给定输入特征 `xi` 时正类别（在本例中为 Default）的概率。`yi` 是第 `i` 个数据点的类别标签，`n` 是数据点的总数。

似然函数度量在给定输入特征 `xi` 和模型参数 ![](images/eq-33.jpg) 和 ![](images/eq-41.jpg) 的情况下，观察到给定类别 `yi` 的可能性。逻辑回归模型通常使用最大似然估计 (MLE) 或梯度下降等优化技术进行拟合。这些技术迭代调整回归系数的值以最大化似然函数，从而找到能准确预测观察到的类别的最佳拟合模型参数。

## 分类评估指标

以下是分类中常用的一些评估指标：

*   **混淆矩阵**：混淆矩阵是一个表格（如表 11.1 所示），通过比较预测类别和实际类别来显示分类器的性能。它包含四个类别：
    *   **真阳性 (TP)**：预测类别和实际类别均为阳性。
    *   **真阴性 (TN)**：预测类别和实际类别均为阴性。
    *   **假阳性 (FP)**：实际类别为阴性，但预测类别为阳性。
    *   **假阴性 (FN)**：实际类别为阳性，但预测类别为阴性。

| | Predicted positive | Predicted negative |
| --- | --- | --- |
| Actual positive | True positive (TP) | False negative (FN) |
| Actual negative | False positive (FP) | True negative (TN) |

**Table 11.1: 混淆矩阵**

*   **准确率**：正确分类实例的比例与总实例数的比值。它衡量分类器做出正确预测的频率。然而，它可能不适用于不平衡数据集，即某些类别的数据点多于其他类别的情况。

![](images/eq-14.jpg)

*   **精确率**：在分类器做出的所有阳性预测中，真阳性预测所占的比例。它指示分类器在预测阳性结果时的准确程度。

![](images/eq-15.jpg)

*   **召回率 (灵敏度或真阳性率)**：在数据集中所有实际阳性实例中，真阳性预测所占的比例。它指示分类器识别阳性实例的能力。

![](images/eq-16.jpg)

*   **F1 分数**：精确率和召回率的调和平均数。它通过结合精确率和召回率，提供了分类器性能的平衡度量。

`F1 Score = 2 * (precision * recall) / (precision + recall)`

*   **AUC (ROC 曲线下面积)**：接收者操作特征 (ROC) 曲线在不同分类阈值下绘制真阳性率与假阳性率的关系。AUC 衡量分类器区分阳性和阴性类别的能力。较高的 AUC 值表示更好的分类性能。AUC 范围从 0 到 1，其中 0.5 表示随机分类，1 表示完美分类。

AUC 评估模型的预测能力，而不依赖于选定的分类阈值。这种独立性确保了性能评估在不同决策边界下保持一致。
