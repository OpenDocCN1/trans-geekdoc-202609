## Pivoting Data

Pivoting data is a crucial technique in data analysis to restructure datasets for more effective exploration. Often, data comes in either wide or long formats, each with its own advantages. Each row corresponds to a single observation or measurement in a long data format, with multiple rows representing different time points. Conversely, in a wide data format, each subject or entity is represented by a single row, with multiple columns used to denote different time points. The wide format is suitable for preliminary summary statistics, while the long format is better for certain analyses like time series or repeated measures. By converting data between these formats, you can tailor it to meet your specific requirements.

### Long and Wide Format Data

Imagine you work for a fruit-selling company. You have a spreadsheet that lists the total number of apples, bananas, and oranges sold each day of the week. The data looks like **Table 4.1** below:

| Day | Apples | Bananas | Oranges |
| --- | --- | --- | --- |
| Monday | 10 | 5 | 7 |
| Tuesday | 8 | 3 | 9 |
| Wednesday | 12 | 2 | 6 |
| Thursday | 15 | 6 | 8 |
| Friday | 11 | 4 | 10 |

**Table 4.1**: An example of wide-format data

This is an example of wide data because there is a separate column for each type of fruit. The advantage of wide data is that it is easy to read and understand. You might want to analyze your dataset in different ways. Sometimes, you want to see each variable in its own column, and other times, you want to see all the variables in a single column. This is where wide and long data formats come into play.

However, when you want to visualize the data using `ggplot2` package, you might need to work with long-format data. In a long format, each observation corresponds to a single sale, with columns indicating the day, the type of fruit, and the number of fruits sold. Some libraries, such as `ggplot2` and `plyr`, and most modelling functions, such as `lm()`, `glm()`, and `gam()` require long-format data. **Table 4.2** below shows the long-format data:

| Day | Fruits | Sales |
| --- | --- | --- |
| Monday | Apples | 10 |
| Monday | Bananas | 5 |
| Monday | Oranges | 7 |
| Tuesday | Apples | 8 |
| Tuesday | Bananas | 3 |
| Tuesday | Oranges | 9 |
| Wednesday | Apples | 12 |
| Wednesday | Bananas | 2 |
| Wednesday | Oranges | 6 |
| Thursday | Apples | 15 |
| Thursday | Bananas | 6 |
| Thursday | Oranges | 8 |
| Friday | Apples | 11 |
| Friday | Bananas | 4 |
| Friday | Oranges | 10 |

**Table 4.2**: An example of long-format data

Generally, wide data is appropriate when you have a fixed set of columns corresponding to variables of interest, and long data is appropriate when you have many different variables that should be organized into rows.

#### Introducing reshape2

Hadley Wickham created the `reshape2` package, which helps easily convert data between wide and long formats. The `reshape2` package utilizes two primary functions: `melt()` and `cast()`. The `melt()` transforms data from a wide format to a long format, while the `cast()` takes data in a long format and converts it back to a wide format.

The `melt()` function is a useful tool for converting wide-format data into long-format data. This can be helpful for data analysis and visualization because many statistical and graphical methods require data to be in a long format.
