
# Lists in R

A list is a beneficial data structure in R that can hold any collection of R objects. In contrast to vectors and matrices, the objects in lists allow different types, including character, numeric, and even other lists. Because of this, lists are very versatile and helpful for various tasks, such as arranging intricate data structures or developing custom functions. Aarya can use lists to organize her Netflix data in a meaningful way, as we can see in the following list:

```r
# Create a list of vectors
movies_list <- list(
  movie_names = c("Inception", "The Dark Knight", "Edge of Tomorrow"),
  movie_durations = c(148, 152, 113),
  genre = factor(c("Sci-fi", "Action", "Sci-fi")),
  ratings = factor(c(3, 5, 4), ordered = TRUE, levels = c(3, 4, 5))
)

# Print the list
movies_list
```

## Output

```
## $movie_names
## [1] "Inception" "The Dark Knight" "Edge of Tomorrow"
##
## $movie_durations
## [1] 148 152 113
##
## $genre
## [1] Sci-fi Action Sci-fi
## Levels: Action Sci-fi
##
## $ratings
## [1] 3 5 4
## Levels: 3 < 4 < 5
```

In this example, we created a list called `movies_list` which contains four vectors of different types—character, numeric, factor, and ordered factor. We used the `list()` function to create the list and assigned names to each vector using the same syntax.

# DataFrames

A DataFrame is a table-like structure that contains rows and columns. It is nothing but a two-dimensional version of a list. Each column can have a different data type and must have a name. DataFrames are commonly used to store and manipulate data because they are easy to work with and allow for many operations, such as filtering, sorting, and summarizing data. Let us get familiar with DataFrames, one of the most commonly used R objects.

Using Aarya's Netflix data, she can create a DataFrame with the columns `movie_names`, `movie_durations`, and `watched_scifi`. Each vector has to be of the same length. She uses the `data.frame()` to create the DataFrame. Let us take a look at the following data frame figure for reference:

# Functions

Functions encapsulate repetitive or complex operations, making code more organized, efficient, and reusable. In R, functions can be built-in, user-defined, or loaded from packages. Own-defined functions are defined using the `function()` keyword, followed by the name of the function and its arguments in parentheses. The body of the function is then enclosed in curly braces `{}`. Let us create a few of our own defined functions for various businesses.

## E-commerce

A function that calculates the total revenue generated by a product on an e-commerce website, given the price of the product and the number of units sold:

```r
# function to calculate total revenue
calculate_revenue <- function(price, num_sold) {
  total_revenue <- price * num_sold
  return(total_revenue)
}
```

Here, `price` is the product's price on the e-commerce website, and `num_sold` is the number of units sold. The function calculates the total revenue generated by the product as the product of the price and the number of units sold and returns the result:

```r
# Define vectors to calculate revenue
price <- c(250, 2099, 1999, 750)
num_sold <- c(1000, 250, 100, 1150)

# Calculate the total revenue for each product
total_revenue <- calculate_revenue(price, num_sold)

# Print the results
total_revenue
```

## Output

```
## 250000 524750 199900 862500
```

Here, we define two vectors, `price` and `num_sold`, containing the price and number of units sold for four different products respectively. We then pass these vectors as arguments to the `calculate_revenue` function, which calculates the total revenue for each product and returns a vector of results.

## Marketing

A function that calculates the conversion rate for a marketing campaign, given the number of impressions and clicks:

```r
# function to calculate conversion rate
calculate_conversion_rate <- function(impressions, clicks) {
  conversion_rate <- clicks / impressions
  return(conversion_rate)
}
```

Here, `impressions` are the number of times the marketing message was displayed, and `clicks` are the number of times it was clicked. The function calculates the conversion rate by dividing the number of clicks by the number of impressions.

You can use the `conversion_rate` function with vectors of data for impressions and clicks:

```r
# Define impressions and clicks vector
impressions <- c(1205, 2000, 1532, 4101)
clicks <- c(90, 75, 82, 210)

# Calculate conversion rates for each ad campaign
conversion_rates <- calculate_conversion_rate(impressions, clicks)

# Print the conversion_rates
conversion_rates
```

## Output

```
## 0.07468880 0.03750000 0.05352480 0.05120702
```

Here, we define two vectors of data, `impressions` and `clicks`, containing the number of impressions and clicks for four different ad campaigns. We then pass these vectors as arguments to the `conversion_rate` function, which calculates the conversion rate for each campaign and returns a vector of results. We can also use `round()` to round off the results.

## Finance

A function that calculates the compound interest on a loan given the principal, interest rate, length of the loan in years, and the number of times interest is compounded per year:

```r
# function to calculate compound interest
calculate_compound_interest <- function(principal, interest_rate, years, compounding_frequency) {
  n <- compounding_frequency
  interest <- principal * (1 + interest_rate / n)^(n * years) - principal
  return(interest)
}

# define vector inputs
principal <- c(5000, 7500, 9200)
```
