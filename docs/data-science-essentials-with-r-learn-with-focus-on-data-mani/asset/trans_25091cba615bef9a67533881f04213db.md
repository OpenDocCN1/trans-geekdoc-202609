
通过对差值进行平方，我们确保了正偏差和负偏差不会相互抵消。因此，方差始终为非负数，即零或正数。方差为零表示所有数据点的值都相同，表明不存在变异性。另一方面，随着数据值变得更加分散，变异性也会增加。然而，由于方差涉及平方单位而非自然数据单位，因此解释起来可能具有挑战性。较高的方差意味着变异性增加；尽管如此，对于特定数值并没有明确的解释标准。

### 计算方差

```
visits_variance <- var(daily_visits)
cat("Variance of daily website visits:", visits_variance, "visits^2\n")
```

## Variance of daily website visits: 109472.2 visits^2

`var()` 函数计算数值向量的方差，它衡量每个数据点偏离均值的平均平方偏差。在指定期间内，每日网站访问量的方差约为 109472.2 visits^2。由于方差以平方单位（visits^2）表示，其直观解释性可能不如原始数据。

标准差是方差的平方根，它用原始数据的单位来表示变异性。较小的标准差值意味着数据点紧密聚集在均值周围，而较大的值则表明数据在不同数量级上分散得更广。与以平方单位表示变异性且可能不如原始数据直观的方差不同，标准差通过使用与原始数据相同的单位简化了解释。

## 概率

概率是衡量事件发生可能性的指标。它定义了在所有可能结果中事件发生的几率或概率。概率总是表示为 0 到 1 之间的数字，其中 0 代表不可能事件，1 代表必然事件。

概率帮助我们量化数据中的不确定性并对结果建模。例如，想象一下构建一个预测客户流失的模型。你无法确定哪些客户会流失；通过分析过去的行为并结合购买历史和人口统计特征等因素，你可以计算每个客户的流失概率。这有助于确定外联工作的优先级并有效分配资源。

我们用 `P(E)` 表示事件 E 的概率。在概率论中，事件可以是独立的，也可以是依赖的。独立事件的特点是其结果互不相关，即一个事件的发生不影响另一个事件的概率。另一方面，依赖事件则紧密相关，一个事件的发生提供了关于另一个事件可能性的信息。让我们考虑两个事件 E 和 F。对于独立事件，两者同时发生的联合概率，记为 `P(E and F)`，等于它们各自概率的乘积：

```
P(E and F) = P(E) * P(F)
```

例如，想象抛掷两枚独立的硬币，每枚硬币正面朝上的概率都是 50%。两枚硬币都正面朝上的概率是 50% * 50% = 25%，这说明了它们的独立性。

然而，对于依赖事件，情况则不同。在事件 F 已经发生的条件下事件 E 发生的概率，记为 `P(E | F)`，是通过条件概率计算的：

```
P(E | F) = P(E and F) / P(F)
```

已知 F 条件下 E 的条件概率，等于两个事件同时发生的联合概率除以事件 F 单独发生的概率。

假设你是一家零售店的经理，想要确定顾客在拿起商品并查看后购买该商品的概率。这是一个条件概率的例子，因为你试图确定顾客购买商品的概率，前提是他们已经通过拿起和查看表现出了兴趣。

这里的事件是：

*   **E**：顾客购买商品。
*   **F**：顾客拿起并查看商品。

条件概率：`P(E|F)`：已知顾客拿起并查看商品的条件下，其购买该商品的概率。

条件概率 = (购买商品的概率) × (拿起并查看商品的概率) / (拿起并查看商品的概率)

## 推断统计

推断统计帮助我们根据样本数据得出有意义的结论并对总体进行预测。与仅总结和描述数据集主要特征的描述性统计不同，推断统计更进一步，利用从中抽取样本的更大总体进行推断或概括。这一过程涉及使用概率论和统计技术，将具有代表性的数据子集的发现推广到整个总体。

## 统计假设检验

我们经常会遇到需要检验某个假设是否具有统计显著性的情况。这些假设的例子包括：实施新功能后，人均收入增加了；或者周末的客户参与度高于工作日。假设检验允许我们使用稳健的统计方法批判性地审视这些陈述。假设检验过程包含几个关键步骤：

1.  **构建假设**：定义原假设（`H0`）和备择假设（`H1`）
    *   **原假设（`H0`）**：原假设假设被比较的变量或组别之间不存在显著关系、效应或差异。它总是包含一个等式条件，表明如果仅是随机偶然性在起作用，则结果不会偏离预期结果。
    *   **备择假设（`H1`）**：相反，备择假设是数据科学家旨在确立的内容。备择假设通过断言被比较的变量或组别之间存在统计上显著的关系、效应或差异，来挑战原假设。值得注意的是，备择假设从不包含等式条件。

实质上，`H0` 和 `H1` 是数学上的对立面，代表了对数据中变量关系的两种截然不同的观点。让我们考虑一个实际场景。你正在调查电商平台引入个性化推荐系统是否显著提高了用户点击率。在这种情况下，原假设可能断言推荐系统没有效果，任何观察到的变化仅仅是由于随机偶然性。相反，备择假设断言归因于推荐系统的点击率存在切实的增加。
