### Changing case

Next, we will use the `mutate()` function to update the columns product name and product category in lowercase. The `mutate()` takes a data frame and a list of expressions as input and returns a new data frame with the new or updated columns.

Converting product names and categories to lowercase before creating URLs has several benefits. Firstly, it is considered a best practice for search engine optimization (SEO) as search engines tend to index and rank URLs in lowercase more effectively. Secondly, lowercase URLs are more accessible for users to understand and remember, making them more user-friendly. The code below uses the `str_to_lower()` function to convert the product names and product categories to lowercase.

```
# Changing case of product_name and product_category
books <- books %>%
  mutate(product_name = str_to_lower(product_name),
  product_category = str_to_lower(product_category))

# Display books
View(books)
```
