
## 计算复利

```r
interest_rate <- c(0.05, 0.06, 0.09)
years <- c(1, 2, 3)
compounding_frequency <- c(1, 2, 4)

# calculate compound interest for each set of inputs
compound_interest <- calculate_compound_interest(principal, interest_rate, years, compounding_frequency)

compound_interest
```

## 输出结果

```
## [1] 250.0000 941.3161 2815.6599
```

这告诉我们，对于第一组输入（`principal = 5000`，`interest_rate = 0.05`，`years = 1`，`compounding_frequency = 1`），复利将是 250.00 卢比。同样，对于第二组输入（`principal = 7500`，`interest_rate = 0.06`，`years = 2`，`compounding_frequency = 2`），复利将是 941.3161 卢比，依此类推。

> **注意**：虽然 R 会自动返回函数最后一行的值，但显式使用 `return()` 函数来指示函数返回的内容被认为是更好的实践。这有助于使函数更具可读性且更易于理解，特别是对于可能不熟悉该函数行为的其他用户。

例如，下面的 `calculate_revenue` 函数在不使用 `return` 语句的情况下也能工作：

```r
# calculate total revenue (without return statement)
calculate_revenue <- function(price, num_sold) {
  price * num_sold
}
```

## 获取帮助页面

接收帮助是你作为 R 用户踏上旅程时最需要的关键要素之一。无论你作为程序员有多么丰富的经验，你都会不断遇到新函数，并需要帮助来理解如何使用它们。

每个 R 函数都附带一个帮助页面，你可以通过在问号后输入函数名来访问它。例如，你可以使用以下代码访问 `mean()` 函数的文档：

```r
# display help page for the mean function
?mean
help(mean)

# quotes are optional
?"mean"
help("mean")
```

这将调出 `mean()` 函数的帮助页面，提供有关如何使用该函数、它接受什么参数以及返回什么值的信息。帮助页面还可能包括在实践中使用该函数的示例，以及关于关键注意事项或限制的说明。如果函数来自 R 包，则必须先加载该包，R 才能找到帮助页面。否则，你可以使用 `package` 参数指定包名：

```r
# documentation of select function from dplyr package
help(select, package = "dplyr")
```

上述命令将返回 `dplyr` 包中 `select` 函数的文档。随着你在 R 方面知识和熟练度的提高，帮助页面对于了解特定函数和包的更多信息非常有用。

## 保存数据

在 R 中，根据你正在处理的数据类型以及想要保存的格式，有多种保存数据的方法。下面讨论其中几种。

### 另存为 CSV 文件

逗号分隔值（CSV）文件是存储和交换表格数据的常用方式。要将数据另存为 CSV 文件，可以使用 `write.csv()` 函数。示例如下：

```r
# save data as a CSV file
write.csv(netflix_df, file = "Netflix_Data.csv")
```

这将在你的工作目录中创建一个名为 `Netflix_Data.csv` 的 CSV 文件。`file` 参数指定要创建的文件名。

需要注意的一点是，`write.csv()` 默认会在输出文件中包含行名。如果你不想包含行名，可以将 `row.names` 参数设置为 `FALSE`。请参考以下示例：

```r
write.csv(netflix_df, file = "Netflix_Data.csv", row.names = FALSE)
```

这将从输出文件中排除行名。

### 另存为文本文件

有时，你可能想将数据另存为文本文件而不是 CSV 文件。你可以使用 `write.table()` 将数据另存为文本文件。示例如下：

```r
# Create a data frame
my_data <- data.frame(x = 1:5, y = c("A", "B", "C", "D", "E"))

# Save data as a text file
write.table(my_data, file = "my_data.txt", sep = "\t", row.names = FALSE)
```

这将在你的工作目录中创建一个名为 `my_data.txt` 的文本文件。`sep` 参数指定分隔符（在本例中为制表符），`row.names = FALSE` 从输出中移除行名。

### 另存为二进制文件

R 提供了将数据另存为二进制文件的功能，这是一种以紧凑高效方式存储数据的文件格式。要将数据另存为二进制文件，可以使用 `saveRDS()` 函数。它创建一个可移植的二进制文件，可以轻松地在不同的 R 安装或版本之间共享和使用。如果你需要与可能未安装相同包或 R 版本的人共享数据，这会特别有用。

与以基于文本的格式（如 CSV）保存相比，使用 `saveRDS()` 以二进制格式保存对象通常更高效。二进制文件体积更小，读写速度快得多。要将数据另存为二进制文件：

```r
# create a sample data
my_data <- list(x = 1:5, y = c("A", "B", "C", "D", "E"))

# save data as a binary file
saveRDS(my_data, file = "my_data.rds")
```

这将在你的工作目录中创建一个名为 `my_data.rds` 的二进制文件。这些只是保存数据的众多方法中的几个示例。根据你的需求，可能还有其他更合适的函数或文件格式。
