## Retrieving date and time components

`lubridate` offers you a friendly set of tools to dig into the specific elements of a date or time. Imagine you are working with fitness data from a smartwatch. You have a timestamp representing a morning run on Aug 25, 2023, at 6:30 AM. Now, let us look into this temporal data using `lubridate` functions.

```r
# Create a timestamp for the morning run
run_timestamp <- ymd_hm("2023-08-25 06:30")
run_timestamp
## "2023-08-25 06:30:00 UTC"

# Identifies the year
year(run_timestamp)
## 2023

# Identifies the month
month(run_timestamp)
## 8

# Identifies the day of the month
mday(run_timestamp)
## 25

# Identifies the day of the year
yday(run_timestamp)
## 237

# Identifies the day of the week (Friday, represented as 6)
wday(run_timestamp)
## 6

# Setting label = TRUE displays the day of the week as an ordered factor
wday(run_timestamp, label = T)
## Fri
## Levels: Sun < Mon < Tue < Wed < Thu < Fri < Sat
```

## Modifying date and time components

Although less common in typical data analysis tasks, the capability of modifying date and time components proves invaluable when cleaning data with erroneous dates. Let us consider the following datetime example where you have a datetime object representing an event on 2023-09-15 14:30:45. You need to adjust its day to 14 and time to 4:45 PM.

```r
# create a datetime object
event_datetime <- ymd_hms("2023-09-15 14:30:45")

# display the original datetime
event_datetime
## "2023-09-15 14:30:45 UTC"

# update multiple components: change to September 14, 2023, at 16:45:00
event_datetime <- update(
  event_datetime,
  day = 14,
  hour = 16,
  minute = 45,
  second = 00
)

# display the updated datetime
event_datetime
## 2023-09-14 16:45:00 UTC
```

## Diving into electricity production data

The following table provides a description of each column in the `MonthlyElectricityStatistics` dataset:

| Column name | Description |

Let us prepare our `monthly_electricity` dataset for analysis. The `Time` column in our dataset is formatted as Month Year (e.g., May 2023). To work with this data effectively, we are adding a day component, specifically '01', to each date. This step ensures that we have complete date strings (01 May 2023), which we can then parse and use for further analysis.

```r
# add a day component (e.g., 01) and parse the date
monthly_electricity <- monthly_electricity %>%
  mutate(
    Time = dmy(paste("01", Time))
  )
```

In the following code, we are adding `Month`, `Year`, and `Quarter` columns in our `monthly_electricity` dataset for precise temporal analysis. Subsequently, we focus on India's electricity data within the Electricity product category, filtering data from 2021 onwards. We then group and summarize this information by quarters, calculating total and average values.

```r
# extract different components from Time
monthly_electricity <- monthly_electricity %>%
  mutate(
    Month = month(Time),
```
