# 第 6 章：操作字符串

## 简介

现实世界的数据集通常包含大量文本数据，以及数值和逻辑数据。无论您处理的是客户评论、社交媒体评论还是调查回复，文本数据都隐藏着宝贵的见解。然而，原始文本数据往往包含噪声、不一致性和其他问题，必须在适当分析之前解决这些问题。在本章中，您将接触到一套全面的字符串操作函数，帮助您应对与文本数据相关的常见挑战。您将学习如何清洗文本、提取相关信息，并将文本数据转换为适合进一步分析的结构化形式。

## 结构

本章将探讨和讨论与操作字符串相关的各种基本概念。我们将在本章中讨论以下主题：

*   基本字符串操作
    *   更改大小写
    *   计算字符串长度
    *   替换子字符串
    *   移除不必要的空白字符
    *   填充
*   连接字符串
*   提取子字符串
*   正则表达式
    *   正则表达式要素
    *   贪婪与非贪婪匹配
*   检测和提取模式

## 目标

本章旨在利用 `stringr` 包，深入理解字符串操作技术。本章涵盖基本字符串操作，如清洗和操作字符串、更改大小写、计算字符串长度、替换子字符串、移除不必要的空白字符、填充以及连接字符串。本章还涵盖使用 `str_sub()` 和 `str_extract()` 函数从字符串中提取子字符串。提取子字符串是数据科学中的典型操作，因为经常需要从字符串中提取特定信息片段，如从时间戳中提取日期。本章还介绍正则表达式（regex），它有助于搜索和操作文本。正则表达式是一组共同形成模式的字符，用于在字符串中搜索、验证和提取信息。它们可用于查找和提取字符串中的特定模式，如电子邮件地址、电话号码和日期。

## 基本字符串操作

在整章中，我们将使用 `stringr` 包中的函数，该包是 Tidyverse 生态系统的组成部分。`stringr` 包提供了高效且有效的工具来执行字符串操作任务。首先，我们加载数据操作所需的包。

```
# load tidyverse
library(tidyverse)

# install stringr
install.packages("stringr")

# load stringr
library(stringr)
```

`stringr` 提供了广泛的函数来处理文本数据，包括用于基本字符串操作的函数，如修剪空白字符和转换大小写，以及更高级的功能，如正则表达式匹配。其一致的命名约定使您容易记住哪个函数执行什么操作，让您专注于解决问题，而不是记忆语法。在 RStudio 中，您可以输入 `str_` 并按 Tab 键查看 `stringr` 包中可用的字符串操作函数列表。此快捷方式允许您轻松访问并选择所需的函数，而无需输入其完整名称。

假设您负责创建新的产品页面并确保它们针对搜索引擎进行了优化。创建结构良好的 URL 是搜索引擎优化 (SEO) 最重要的方面之一。创建 URL 时，必须遵循某些最佳实践。这些最佳实践有助于提高产品页面的 SEO 并使其更加用户友好。

现在，您将利用可用的特定数据点（如产品名称、产品类别和产品 ID）创建 URL 名称。您可以手动创建每个 URL 名称，但这既耗时又容易出错。更好的方法是使用 `stringr` 从数据点创建 URL 名称并实现流程自动化。

首先，我们创建一个名为 `books` 的数据框，包含三列：产品名称、产品类别和产品 ID。产品名称列包含产品的名称，产品类别列包含产品的类别，产品 ID 列包含产品的唯一标识符。

```
# Create a data frame of product data

# Display the data frame
View(books)
```

### 更改大小写

接下来，我们将使用 `mutate()` 函数将产品名称和产品类别列更新为小写。`mutate()` 接受一个数据框和一个表达式列表作为输入，并返回一个包含新列或更新列的新数据框。

在创建 URL 之前将产品名称和类别转换为小写有几个好处。首先，这被认为是搜索引擎优化 (SEO) 的最佳实践，因为搜索引擎倾向于更有效地索引和排名小写 URL。其次，小写 URL 更便于用户理解和记忆，使其更加用户友好。下面的代码使用 `str_to_lower()` 函数将产品名称和产品类别转换为小写。

```
# Changing case of product_name and product_category
books <- books %>%
  mutate(product_name = str_to_lower(product_name),
  product_category = str_to_lower(product_category))

# Display books
View(books)
```
