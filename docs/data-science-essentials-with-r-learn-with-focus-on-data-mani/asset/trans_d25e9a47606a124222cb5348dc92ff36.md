# R 惯例

## 目标

在本章结束时，您将掌握 R 语言的基础知识，从而具备高效使用 R 进行数据分析的技能。本章将全面概述使用 R 所需的基本概念，包括 RStudio 界面、包、工作目录、不同的 R 对象、函数、加载和保存数据以及 R 惯例。

## RStudio 界面

R 是一种编程语言，能够处理大型数据集、执行复杂计算，并创建可视化图表以帮助您理解数据。它是开源且免费使用的，使得任何对统计计算感兴趣的人都能轻松上手。它拥有庞大且活跃的用户和开发者社区，他们为各种包和库的开发与维护做出贡献。下图展示了 R 编程的几个特性：

![](images/Figure2.1.png)

图 2.1：R 的特性

当您首次打开 R 时，可能会感到无从下手。这就是 RStudio 发挥作用的地方。RStudio 是一个集成开发环境（IDE），它使得各个层次的用户都能更流畅、更便捷地使用 R。

RStudio 界面有四个主要面板：

*   **控制台**：您在此输入命令并查看输出。
*   **脚本编辑器**：您在此输入命令并将其保存到文件中。您也可以提交命令在控制台中运行。
*   **环境/历史**：您在此查看所有活动对象和历史记录，以追踪在控制台中运行的所有命令。
*   **文件/图表/包/帮助**

### R 作为计算器

现在，让我们进入 Aarya 的故事，她想用 R 来分析她的 Netflix 使用数据。她首先将 R 用作计算器。她想计算出过去一周内，她观看 Netflix 电影和电视剧总共花费了多少小时。以下是 Aarya 记下的信息：

*   她看了两部电视剧，每部 12 集。每集 30 分钟。
*   此外，她还看了三部 2 小时的电影。

![](images/Figure2.3.jpg)

图 2.3：Aarya 分析其 Netflix 数据的示意图

上图展示了 Aarya 分析其 Netflix 数据的过程。Aarya 使用 R 中的简单算术运算来计算总小时数。

对于电视剧，Aarya 观看了 12 x 2 = 24 集。每集 30 分钟，因此观看电视剧的总时间为 24 x 30 = 720 分钟。要将分钟转换为小时，Aarya 可以除以 60。因此，观看电视的总时间为：720 / 60 = 12 小时。

对于电影，Aarya 总共观看了 3 x 2 = 6 小时。要计算观看电视剧和电影的总时间，Aarya 可以将小时数相加：12 + 6 = 18 小时。下图显示了 R 控制台中的计算过程：

![](images/Figure2.4.png)

图 2.4：R 控制台中的基本计算

因此，Aarya 使用 R 中的简单算术运算计算了在 Netflix 上观看电视剧和电影的总小时数。

## 包

当您下载并安装 R 时，它附带一组默认函数，可用于各种用途。然而，随着全球 R 社区开发新的函数和功能，将它们全部纳入核心软件包已变得不切实际。相反，许多函数被捆绑到包中，可根据需要下载和安装，以解决这一问题。

R 包是函数、数据集和文档的集合，旨在协同工作。例如，一些包专门用于数据整理，而另一些则专门用于数据可视化。

例如，安装一个包就像为您的汽车订购一项新功能，例如导航系统。您不能立即使用它，因为您需要先安装它。一旦新功能安装在您的车上，您就可以打开并使用它。

同样，要使用一个新的 R 包，您首先需要使用 `install.packages()` 函数将其安装在您的计算机上。此外，您还需要使用 `library()` 函数将包加载到您的工作会话中，以访问它提供的新函数和功能。

就像您可以在车上安装多个功能，但在特定时间只开启您需要的那些一样，您可以在计算机上安装多个 R 包，但只为特定项目加载所需的包。下图展示了汽车显示系统和车载导航应用的示意图：

![](images/Figure2.6.png)

图 2.6：汽车显示系统中的显示系统和导航应用

例如，要安装 `lubridate` 包（包含处理日期的实用函数），您只需将包名 `lubridate` 作为字符串参数传递给该函数：

```
# install the lubridate package
install.packages("lubridate")
```

包下载并安装完成后，您可以使用 `library()` 函数将其加载到 R 会话中：

```
# load the lubridate package
library(lubridate)
```

加载后，您就可以在代码中使用该包提供的函数，就像使用任何其他 R 函数一样。

> **注意：** R 中的井号（`#`）是注释符号。请为您的代码添加注释，以阐明每部分代码的功能。如果您这样做，其他人（以及未来的您自己！）会更容易理解您的代码。

有几个良好的实践可以帮助您更高效、更有效地使用包。

*   **在脚本开头加载包**：最好在脚本开头加载您将要使用的所有包。这将确保在代码运行前安装并加载所有必要的包，避免因缺少依赖项而导致的潜在错误或问题。
*   **定期更新包**：R 社区不断更新和改进包，因此保持包的更新很重要。您可以通过定期运行 `update.packages()` 函数来实现这一点，该函数将检查已安装包的更新并安装任何可用的新版本。
*   **注意包的依赖关系**：某些包可能依赖于其他包，这意味着您需要安装并加载这些依赖包，才能使用您想要的包。
