
您可以遵循许多约定和最佳实践，以在 R 中编写清晰、高效且可维护的代码。下面列出了一些：

*   R 区分大小写，意味着大写和小写字母会被区别对待。对变量和函数名使用小写字母是一种良好的实践。
*   为变量和函数使用有意义的名称。这有助于提高代码的可读性和可理解性。使用易于理解和记忆的描述性变量名。
*   缩进在 R 中很重要，能让您的代码更具可读性。因此，您应该始终如一地缩进代码，使用空格或制表符。
*   为您的代码添加注释，解释您在做什么以及为什么这么做。这使得其他人（以及未来的您自己）更容易理解您的代码。
*   编写模块化代码。将代码拆分为小型的、可复用的函数，以便在代码的不同部分中使用。这使您的代码更易于阅读、理解和维护。
*   避免使用 R 中已定义的变量名，例如 `mean`、`sum` 或 `sd`。这可能导致意外行为。
*   使用包。R 拥有庞大的包生态系统，可以为您节省大量时间和精力。使用 `dplyr`、`tidyr` 和 `ggplot2` 等包来简化您的代码。
