

## 数据预处理

收集数据后，必须对其进行处理以准备用于机器学习。这可能涉及清洗数据、处理缺失值、归一化数据，以及将数据转换为合适的格式。预处理是关键步骤，因为它会显著影响机器学习模型的准确性。

## 特征工程

特征工程是从现有数据创建新特征的过程，有助于提高机器学习模型的性能。这可能涉及创建衍生特征、组合现有特征，以及从数据中提取相关信息。

## 训练机器学习模型并评估

选择合适的算法，并在训练数据集上训练模型。使用与问题相关的指标以及泛化能力，在测试数据集上评估模型的性能。

## 模型部署

评估模型后，您可以将其部署到生产环境，用于为业务创造价值。部署可能涉及将模型与现有系统集成、创建 API 端点、监控模型性能，并根据需要进行更新。

## 监控

必须随时间监控机器学习模型的性能，以确保其保持准确和相关。建立监控系统，确保模型保持其预期的性能水平。快速检测并解决任何性能下降或异常，以维持模型的准确性和相关性。

## 线性回归

线性回归是一种用于预测连续结果变量的统计技术。尽管历史悠久，线性回归在现代数据分析中仍是一种流行且有效的方法。

线性回归的核心思想是构建一个线性模型，以捕捉因变量（`Y`）与一个或多个自变量（`X`）之间的关系。该模型通过计算输入特征的加权和，加上一个称为偏置或截距的常数项，来预测给定 `X` 时 `Y` 的期望值。数学上可表示为：

```
Y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
```

其中：

*   `Ŷ` 是预测的结果变量
*   `β₀` 是偏置项，表示当所有 `X` 变量均等于零时 `Y` 的基准值
*   `β₁` 是与 `x₁` 相关的权重，决定了在保持其他 `X` 变量不变时，`x₁` 每变化一个单位 `Y` 所发生的变化
*   `x₁` 是单个特征或输入变量

要训练机器学习模型，我们使用带标签的示例来确定权重和偏置的最优值。在监督学习中，机器学习算法通过分析大量示例并识别出一个使损失最小化的模型来构建模型。损失是对不准确预测的惩罚，用一个数值表示单个示例中错误的程度。理想情况下，模型的预测完美无缺，损失为 0。然而，如果预测不完美，损失就会增大。训练模型的目标是找到一组权重和偏置，使其在所有示例上的损失较低。

我们的目标是获得系数估计，并确保线性模型很好地拟合可用数据。我们可以基于 `X` 的值表达对 `Y` 的预测为：

```
ŷᵢ = β₀ + β₁xᵢ
```

残差（`eᵢ`）是观测响应值（`yᵢ`）与预测响应值（`ŷᵢ`）之间的差异。残差（`eᵢ`）计算公式为 `eᵢ = yᵢ - ŷᵢ`。

在线性回归中，成本函数通常定义为均方误差（MSE）。MSE 测量预测值与实际值之间平方差的平均值。

```
MSE = (1/n) Σ(yᵢ - ŷᵢ)²
```

最小化 MSE 有助于确保线性模型准确捕捉数据中的潜在模式，并为新观测值提供合理的预测。

线性回归模型基于若干假设，必须满足这些假设才能确保模型预测的有效性。以下是线性回归的一些关键假设：

*   假设自变量与因变量之间的关系是线性的。
*   观测值必须相互独立。
*   假设残差的方差在自变量的所有水平上是恒定的。当误差项的变异性在自变量的不同水平上发生变化时，就会出现异方差性。
*   假设残差呈正态分布。
*   自变量之间不应高度相关。变量间的高度相关性会在模型拟合过程和结果解释中造成困难。
*   残差不应随时间相互关联。

## 数据拆分

我们通常将数据集拆分为两个子集：训练集和测试集。训练集用于训练模型。它包含大部分数据，使模型能够学习数据中的模式和关系。另一方面，测试集用于评估模型的性能。下图 [Figure 11.2](#ch11.xhtml#fig11-2) 展示了数据拆分为两个集合的情况：

![](images/Figure11.2.png)

Figure 11.2: 将数据拆分为训练数据集和测试数据集

现在，让我们讨论一些将数据拆分为训练数据集和测试数据集的最佳实践。

*   首先，确保测试集足够大，以产生统计学上显著的结果。您要避免测试集过小，因为它可能无法准确反映模型的真实性能。根据经验，常见的拆分比例是 80% 训练和 20% 测试，但这可能因数据集的大小和复杂性而异。
*   其次，至关重要的是要避免选取与训练集具有不同特征的测试集。这是因为测试集作为新数据的代理，目标是创建一个能很好地泛化到新的、未见过的数据的模型。
*   第三，绝不要在测试数据上训练模型，也不要使用测试集的任何信息来影响模型训练。确保测试集在整个模型构建过程中始终与训练集完全分离。数据泄露，即测试集的信息无意中影响了模型，会导致过拟合和误导性的评估指标。

在训练阶段，机器学习算法通过调整模型参数来学习训练数据中的模式。然而，模型可能会过拟合训练数据，意味着它在训练数据上表现良好，但在新的、未见过的数据上表现不佳。为了防止这种情况，我们可以使用验证集在训练过程中评估模型性能并根据需要进行调整。这确保模型不仅仅是记忆训练数据，而是学习能泛化到新数据的有用模式。下图 [Figure 11.3](#ch11.xhtml#fig11-3) 展示了数据拆分为三个子集的情况：

![](images/Figure11.3.png)

Figure 11.3: 将数据拆分为训练、验证和测试数据集

典型的数据划分工作流包括以下步骤：

1.  将初始数据集拆分为三个子集：训练集、验证集和测试集。常见的拆分比例为 80-10-10% 或 70-15-15%。
2.  在训练集上训练模型，并在验证集上评估其性能。
3.  调整模型的任何方面，添加或移除特征，应用正则化技术，甚至构建一个全新的模型。进行修改后，返回步骤 2 并继续迭代，直到达到满意的性能。
