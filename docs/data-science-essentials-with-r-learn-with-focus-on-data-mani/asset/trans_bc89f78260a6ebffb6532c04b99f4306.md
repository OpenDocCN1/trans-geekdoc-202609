## 创建日期和日期时间对象

在本章中，我们将使用几个有用的包。随着我们深入本章，我们将发现 `lubridate` 包如何显著增强我们管理和分析时间信息的能力。安装 `lubridate` 有两种选择。

一种是安装完整的 `tidyverse` 套件，其中包含 `lubridate` 以及其他用于数据操作和可视化的有用包。要开始使用 Tidyverse 包集合，请首先使用以下命令安装并加载它：

1.  `install.packages("tidyverse")`
2.  `library(tidyverse)`

或者，您可以单独安装 `lubridate`：

1.  `install.packages("lubridate")`
2.  `library(lubridate)`

让我们首先了解三种指代特定时间点的主要日期/时间数据类型：日期、一天中的时间、日期时间。在我们的数据分析中，我们必须处理日期或日期时间。

### 从字符串创建

当事件的确切时间不相关，而日期本身才相关时，通常使用日期。设想这样一个场景：您的数据集包含一列以各种格式呈现的日期，如 Sep 02, 2023。这些日期的顺序可能不同；有些可能是月-日-年格式，而另一些可能是年-月-日顺序。

为了高效地将这些日期字符串转换为日期对象，`lubridate` 包提供了一系列针对不同日期元素顺序量身定制的函数。这些函数的命名使用了代表基本日期和时间元素的首字母组合：

*   日期组件包括 `y` 代表年，`m` 代表月，`d` 代表日。
*   时间组件包括 `h` 代表时，`m` 代表分，`s` 代表秒。

函数名称中这些组件的顺序决定了如何以字符串形式提供您的日期和时间信息。例如，如果您的日期结构为月-日-年，您将使用 `mdy()` 函数将其转换为日期对象。反之，如果您的日期组织为年-月-日，`ymd()` 函数则是合适的选择。

简而言之，`lubridate` 提供了函数来处理日期数据中 `m`、`d` 和 `y` 的每一种可想象的排列组合，无论您的数据集中日期格式如何变化，都能使转换过程无缝衔接。

```
# 从字符串创建日期对象

ymd("2023-08-30")
## "2023-08-30"

ymd("20230830")
## "2023-08-30"

mdy("09 02 2023")
## "2023-09-02"

dmy("31-Aug-2023")
## "2023-08-31"
```

要创建日期时间对象，请在上述函数名称后添加下划线和一个或多个 `h`（时）、`m`（分）和 `s`（秒）。这使您不仅能精确指定日期，还能指定时间组件。

例如，如果您的数据包含类似 `2023-09-02 14:30:45` 的日期时间字符串，其中同时包含年-月-日 时:分:秒格式的日期和时间，您将使用 `ymd_hms()` 函数进行解析：

```
ymd_hms("2023-09-02 14:30:45")
## "2023-09-02 14:30:45 UTC"
```

或者，如果您的数据包含不同格式的日期时间字符串，如 `"09/02/2023 14:30"`，其中日期和时间为月/日/年 时:分格式，您可以使用 `mdy_hm()` 函数进行解析：

```
mdy_hm("09/02/2023 14:30")
## "2023-09-02 14:30:00 UTC"

class(ymd("2023-08-30"))
## "Date"

class(ymd_hms("2023-09-02 14:30:45"))
## "POSIXct" "POSIXt"
```

> **注意：** 始终应尽量使用能胜任工作的最简单数据类型。如果日期足够，就不要用日期时间。日期时间更棘手，因为它们必须处理时区，这会使事情变得更复杂。

有时，如果您的 CSV 或 Excel 表已经遵循 ISO8601 格式 ^([1](#ch05.xhtml#footnote-000))，您可能根本不需要转换日期或日期时间。

### 从变量创建

在数据分析中，经常会遇到日期信息分散在多个列中的数据集，例如年、月和日。为了有效处理这些数据，`lubridate` 提供了特定函数将此类列转换为单个日期列。

例如，我们创建一个包含单独日期组件（年、月、日）的 `date_data` 数据框。

```
# 创建一个包含单独日期组件的数据框

date_data <- data.frame(
  year = c(2023, 2022, 2021),
  month = c(8, 12, 5),
  day = c(24, 15, 3)
)
```

我们使用 `lubridate` 中的 `make_date` 函数创建一个统一的日期列。该函数将单独的日期组件（年、月、日）作为参数，并将它们组合成单个日期对象。

```
# 添加新的日期列

date_data <- date_data %>%
  mutate(full_date = make_date(year, month, day))

# 显示结果
print(date_data)

## year month day full_date
## 2023 8 24 2023-08-24
## 2022 12 15 2022-12-15
## 2021 5 3 2021-05-03

str(date_data$full_date)
```
