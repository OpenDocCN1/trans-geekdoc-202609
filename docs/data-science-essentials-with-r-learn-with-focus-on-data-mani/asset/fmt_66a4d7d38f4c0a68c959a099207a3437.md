# Filtering rows

How can you filter the dataset only to include countries in Asia with a life expectancy greater than 70 years in 2015?

*   **Filter the countries in Asia with a life expectancy > 70 years in 2015**
*   `gapminder_asia <- filter(gapminder, year == 2015, continent == "Asia", life_expectancy > 70)`

We use `filter()` to extract only the observations from the year 2015, continent Asia, and a life expectancy greater than 70.

How can you create a subset of the Gapminder dataset that includes only countries from the continents of Americas and Asia?

*   **Create a subset of the gapminder dataset that only contains countries from the Americas and Asia continents.**
*   `gapminder_asia_america <- filter(gapminder, continent == "Americas" | continent == "Asia")`

This command uses the `|` operator to filter for two values in the `continent` column, which can become difficult to read and understand if we need to filter for more than two values. You can write a clean and more efficient way to rewrite the above command using the `%in%` operator. `%in%` checks if each element in the selected column exists within the specified vectors, returning a logical vector indicating whether each row should be included in the final output or not.

*   `gapminder_asia_america2 <- filter(gapminder, continent %in% c("Americas", "Asia"))`

The above command using the `%in%` operator is better than the previous command using the `|` operator because it is more concise and easier to read, especially when there are multiple values to filter for. Here, we are keeping only those rows where the value in the `continent` column falls into one of two categories: either Asia or Americas.

# Introducing pipe operator

The `%>%` operator is commonly referred to as the pipe operator. It is used to chain multiple operations together readably and efficiently.

In 2010, what were the total population, GDP, and infant mortality of countries in Asia and Europe with a life expectancy greater than 70?

```
gapminder_asia_europe <- gapminder %>%
  filter(year == 2010, continent %in% c("Asia", "Europe"), life_expectancy > 70) %>%
  select(country, continent, country_population, country_gdp, infant_mortality, life_expectancy)
```

The first operation in this command is to filter the dataset based on three conditions using the `filter()` function. The first condition is that the year must be equal to 2010, the second condition is that the continent must be either Asia or Europe, and the third condition is that the life expectancy must be greater than 70.

The second operation in this command is to select specific columns from the filtered dataset using the `select()` function. The selected columns include `country`, `continent`, `country_population`, `country_gdp`, `infant_mortality`, and `life_expectancy`.

So, the resulting `gapminder_subset` dataset will only include rows where the year is 2010, the continent is either Asia or Europe, and the life expectancy is greater than 70.

The `%>%` operator takes the function output on the left-hand side and passes it as the first argument to the function on the right-hand side. This allows you to chain together multiple functions in a way that is easy to read and understand.

Which countries had a population greater than 100 million in 2015? In the following code, we will filter the original DataFrame to retain only rows corresponding to the target year and population threshold. Then, we will select only the `country` column from the filtered DataFrame, as shown:

# De-duplicating data

What are the distinct continent categories in the dataset?

*   **Identify unique continents in the gapminder dataset**
*   `unique_continents <- gapminder %>%`
*   `distinct(continent)`
*   **Print the dataframe, unique_continents**
*   `unique_continents`

**Output:**

```
## continent
## Europe
## Africa
## Americas
## Asia
## Oceania
```

The `distinct()` function is used to extract unique values of a column or a combination of columns. In this case, we want to extract unique continents from the `continent` column in the Gapminder dataset. The resulting output is stored in a new DataFrame `unique_continents`.

If you want to save the result as a vector, you can use `pull()` to extract the unique continents.

*   **Identify unique continents**
*   `continents <- gapminder %>%`
*   `distinct(continent) %>%`
*   `pull(continent)`
*   **Display the vector**
*   `continents`

**Output:**

```
## Europe Africa Americas Asia Oceania
## Levels: Africa Americas Asia Europe Oceania
```

# Arranging data

How can you rank countries based on population size to identify the top countries with the largest populations in 2015?

*   **Identify the top countries with the largest populations in 2015**
*   `gapminder_arranged1 <- gapminder %>%`
*   `filter(year == 2015) %>%`
*   `arrange(country_population)`

Here, the `arrange()` function is used to sort the resulting DataFrame in ascending order based on the `country_population` column.

How about arranging the dataset based on the population in descending order?

*   `gapminder_arranged2 <- gapminder %>%`
*   `filter(year == 2015) %>%`
*   `arrange(desc(country_population))`

The resulting DataFrame `gapminder_arranged2` will contain only the rows of 2015, and these rows will be sorted in descending order based on the `country_population`.

Which ten countries had the highest life expectancy in 2015, and what was their population?
