
### 密度图

当探索数值数据时，直方图常用于可视化分布。密度图是直方图的平滑版本。这使其特别适合快速掌握分布的整体形状，包括其偏度和多峰性。[图 7.8](#ch07.xhtml#fig7-8) 展示了营养不良患病率的密度图。

```r
# Density Plot of Undernourishment Prevalence
ggplot(undernourishment_2021, aes(x = Value)) +
  geom_density(fill = "lightblue", color = "steelblue4") +
  labs(title = "Prevalence of Undernourishment",
       x = "Prevalence (%)",
       y = "Frequency") +
  theme_bw()
```

### 可视化比例

有效传达一个群体、实体或数量分解为其组成部分是数据可视化中的常见任务。无论是描绘人口中的性别分布，还是选举中不同政党的得票份额，可视化比例在数据探索和沟通中都起着至关重要的作用。它帮助观众理解不同部分如何构成整体。

### 饼图

饼图长期以来一直是比例或百分比的首选可视化方式，广泛用于商业演示和报告。其圆形布局和比例切片使其成为说明不同组成部分如何贡献于整体的流行选择。饼图能提供比例分布的总体概念，特别是在处理少量类别时。然而，数据科学家经常因以下几个缺点而批评饼图：

*   **难以比较比例**：当处理众多类别时，使用饼图比较比例变得越来越困难。
*   **人类感知局限**：人眼不适合准确判断饼图切片的相对大小，尤其是在处理小切片时。
*   **不利于突出变化**：饼图不适合可视化比例随时间或不同条件下的变化。

现在，让我们使用 `ggplot2` 创建一个饼图，以直观地描绘全球饥饿的地理分布。虽然 `ggplot2` 没有专门用于饼图的 `geom`，但我们可以通过变通方法创建一个。我们可以使用 `geom_bar()` 构建一个只有一个条形的堆叠条形图，然后使用 `coord_polar()` 将图表转换为圆形布局，从而得到一个饼图。可以把它想象成获取一个常规条形图并将其弯曲成一个圆，从而得到一个切片代表不同类别的饼图。

绘图中使用的默认坐标系是笛卡尔坐标系，其中每个点由其独立的 x 和 y 坐标定义。然而，还有两种额外的坐标系可用：专为绘制空间数据设计的 `coord_quickmap()`，以及利用极坐标的 `coord_polar()`。

让我们创建一个如下所示的简单饼图：

```r
hunger_2021 <- read.csv("hunger_2021.csv")

# Pie chart
ggplot(hunger_2021, aes(x = "", y = Value, fill = Region)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar(theta = "y")
```

![](images/Figure7.9.png)

**图 7.9：饼图**

在这种情况下，我们通过在引号中指定空字符串来留空 x 轴。饼图切片基于 `Value` 变量绘制，每个切片根据相应的 `Region` 着色。默认情况下，它按类别的字母顺序逆时针绘制切片。`coord_polar(theta = "y")` 将绘图的坐标系设置为极坐标，这适合饼图。`theta = "y"` 表示每个切片的角度由 y 变量（`Value`）决定。

现在，如果你仔细观察上图，可能会注意到图表背景中有一些多余的东西。让我们去除它们，使其看起来更整洁。我们将通过函数 `theme_void()` 移除数字和网格线。可以把它想象成擦除除切片本身之外的所有内容。为了使切片突出，我们将通过在 `geom_bar()` 中添加 `color` 并根据营养不良人口规模重新排序图表，为每个切片添加边框。下图显示了各地区营养不良人口的分布。

```r
# Pie Chart displaying the undernourished population across different regions
ggplot(hunger_2021, aes(x = "", y = Value, fill = fct_reorder(Region, Value))) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar(theta = "y") +
  theme_void() +
  theme(legend.position = "bottom") +
  labs(title = "Undernourished People by Region", fill = "Region") +
  scale_fill_brewer(palette = "Set3") +
  geom_text(aes(x = 1.7, label = ifelse(Value >= 30, paste(Region, "\n", round(Value, 0), "M"), "")),
            position = position_stack(vjust = 0.5),
            size = 3, show.legend = FALSE)
```

![](images/Figure7.10.png)

**图 7.10：各地区营养不良人口分布**

让我们了解上述命令中使用的额外组件：

*   **布局与主题**
    *   `theme_void()`：移除不必要的背景元素，以获得更整洁的展示。
    *   `theme(legend.position = "bottom")`：将图例置于底部，以提高可读性。
*   **标签与颜色**
    *   `labs(title = "Undernourished People by Region", fill = "Region")`：为图表添加标题，并将填充（颜色）图例标记为 Region。
    *   `scale_fill_brewer(palette = "Set3")`：从 Set3 调色板中选择颜色调色板用于切片颜色。
*   **添加文本标签**
    *   `geom_text`：向图表添加文本标签。
    *   `aes(x = 1.7, label = ifelse(Value >= 30, paste(Region, "\n", round(Value, 0), "M"), ""))`：设置 x 位置和标签文本。标签有条件；如果 `Value` 大于或等于 3000 万，标签包含 Region 和 Value（四舍五入到最接近的整数并附加 M）；否则为空字符串。
    *   `position_stack(vjust = 0.5)`：将标签垂直居中定位在每个切片内。
    *   `size = 3`：设置文本大小。
    *   `show.legend = FALSE`：从图例中隐藏文本标签。

上图显示，亚洲是遭受饥饿人群的主要地区，2021 年有 4.14 亿人，占营养不良总人口的 56%。非洲拥有约 37%（2.71 亿）营养不良人口，而拉丁美洲和加勒比地区约占 6%（4600 万）。
