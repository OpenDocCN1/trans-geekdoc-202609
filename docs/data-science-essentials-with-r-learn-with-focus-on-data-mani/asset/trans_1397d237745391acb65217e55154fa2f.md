# 筛选行

如何筛选数据集，仅包含 2015 年预期寿命大于 70 岁的亚洲国家？

*   **筛选 2015 年预期寿命 > 70 岁的亚洲国家**
*   `gapminder_asia <- filter(gapminder, year == 2015, continent == "Asia", life_expectancy > 70)`

我们使用 `filter()` 仅提取 2015 年、亚洲大陆且预期寿命大于 70 的观测值。

如何创建一个 Gapminder 数据集的子集，仅包含美洲和亚洲大陆的国家？

*   **创建一个仅包含美洲和亚洲大陆国家的 gapminder 数据集子集。**
*   `gapminder_asia_america <- filter(gapminder, continent == "Americas" | continent == "Asia")`

此命令使用 `|` 运算符筛选 `continent` 列中的两个值，但如果我们需要筛选两个以上的值，这会变得难以阅读和理解。您可以使用 `%in%` 运算符以更简洁高效的方式重写上述命令。`%in%` 检查所选列中的每个元素是否存在于指定向量中，返回一个逻辑向量，指示每一行是否应包含在最终输出中。

*   `gapminder_asia_america2 <- filter(gapminder, continent %in% c("Americas", "Asia"))`

与使用 `|` 运算符的前一个命令相比，上述使用 `%in%` 运算符的命令更好，因为它更简洁且易于阅读，尤其是在需要筛选多个值时。在这里，我们仅保留 `continent` 列的值属于两个类别之一（亚洲或美洲）的行。

# 引入管道操作符

`%>%` 操作符通常被称为管道操作符。它用于以可读且高效的方式将多个操作链接在一起。

2010 年，预期寿命大于 70 岁的亚洲和欧洲国家的总人口、GDP 和婴儿死亡率是多少？

```
gapminder_asia_europe <- gapminder %>%
  filter(year == 2010, continent %in% c("Asia", "Europe"), life_expectancy > 70) %>%
  select(country, continent, country_population, country_gdp, infant_mortality, life_expectancy)
```

此命令中的第一个操作是使用 `filter()` 函数基于三个条件筛选数据集。第一个条件是年份必须等于 2010，第二个条件是大陆必须是亚洲或欧洲，第三个条件是预期寿命必须大于 70。

此命令中的第二个操作是使用 `select()` 函数从筛选后的数据集中选择特定列。选定的列包括 `country`、`continent`、`country_population`、`country_gdp`、`infant_mortality` 和 `life_expectancy`。

因此，生成的 `gapminder_subset` 数据集将仅包含年份为 2010、大陆为亚洲或欧洲且预期寿命大于 70 的行。

`%>%` 操作符获取左侧函数的输出，并将其作为第一个参数传递给右侧的函数。这使您能够以一种易于阅读和理解的方式将多个函数链接在一起。

哪些国家在 2015 年的人口超过 1 亿？在以下代码中，我们将筛选原始 DataFrame 以仅保留对应目标年份和人口阈值的行。然后，我们将从筛选后的 DataFrame 中仅选择 `country` 列，如下所示：

*   **筛选 2015 年人口 > 1 亿的国家**
*   `gapminder_country2015 <- gapminder %>%`
*   `filter(year == 2015, country_population > 100000000) %>%`
*   `select(country)`
*   `View(gapminder_country2015)`

**输出：**

```
## country
## Bangladesh
## Brazil
## China
## India
## Indonesia
## Japan
## Mexico
## Nigeria
## Pakistan
## Philippines
## Russia
## United States
```

管道操作符是一种多功能工具，有助于简化工作流，使编码更高效、更易读。它将复杂的数据转换转化为优雅且易于遵循的序列。

# 数据去重

数据集中有哪些不同的大陆类别？

*   **识别 gapminder 数据集中的唯一大陆**
*   `unique_continents <- gapminder %>%`
*   `distinct(continent)`
*   **打印数据框 unique_continents**
*   `unique_continents`

**输出：**

```
## continent
## Europe
## Africa
## Americas
## Asia
## Oceania
```

`distinct()` 函数用于提取一列或多列组合的唯一值。在本例中，我们要从 Gapminder 数据集的 `continent` 列中提取唯一的大陆。生成的输出存储在一个新的 DataFrame `unique_continents` 中。

如果您想将结果保存为向量，可以使用 `pull()` 提取唯一的大陆。

*   **识别唯一大陆**
*   `continents <- gapminder %>%`
*   `distinct(continent) %>%`
*   `pull(continent)`
*   **显示向量**
*   `continents`

**输出：**

```
## Europe Africa Americas Asia Oceania
## Levels: Africa Americas Asia Europe Oceania
```

数据集中有多少个唯一的国家？

*   **识别数据集中唯一国家的数量**
*   `gapminder %>%`
*   `distinct(country) %>%`
*   `count()`

**输出：**

```
## n
## 185
```

此命令使用 `distinct()` 函数仅选择不同的国家名称。然后，使用 `dplyr` 中的 `count()` 函数计算唯一国家的数量。

# 数据排序

如何根据人口规模对国家进行排名，以确定 2015 年人口最多的前几个国家？

*   **识别 2015 年人口最多的国家**
*   `gapminder_arranged1 <- gapminder %>%`
*   `filter(year == 2015) %>%`
*   `arrange(country_population)`

这里，`arrange()` 函数用于根据 `country_population` 列对生成的 DataFrame 进行升序排序。

如果按人口降序排列数据集呢？

*   `gapminder_arranged2 <- gapminder %>%`
*   `filter(year == 2015) %>%`
*   `arrange(desc(country_population))`

生成的 DataFrame `gapminder_arranged2` 将仅包含 2015 年的行，并且这些行将根据 `country_population` 以降序排列。

哪十个国家在 2015 年拥有最高的预期寿命，它们的人口是多少？

*   **识别 2015 年预期寿命最高的十个国家，并显示它们的人口**
*   `gapminder %>%`
*   `filter(year == 2015) %>%`
*   `arrange(desc(life_expectancy)) %>%`
*   `select(country, life_expectancy, country_population) %>%`
*   `head(10)`

**输出：**

```

```

此命令包含 2015 年的数据，按预期寿命降序排序，选择三列（`country`、`life_expectancy` 和 `country_population`），并返回生成的 DataFrame 的前 10 行。
