
## k-Nearest Neighbor (kNN)
`k-Nearest Neighbor (kNN)` is a kind of object-based learning that depends on similarity with other objects. The objects near others, are known as a “neighbor.” At the point when a new object is placed, distance from every case in the model is determined. By doing this grouping, cases are specified to their most similar nearest neighbor and are put into their groups. The `kNN` method is also capable of consistently computing the values for the target.

For continuous variables, distance can be calculated using three distance measures, i.e., `Euclidean`, `Manhattan`, or `Minkowski` distance. Whereas for categorical variables, `Hamming` distance is used. `Euclidean` and `Hamming` distances are given in the below equations.

(6.5)${Euclidean\, Distance} = \\ \\sqrt{\\sum\\limits\_{i = 1}^{k}\\left( {x\_{i} - y\_{i}} \\right)2}$ (6.6)${Hamming\, Distance} = \\ D\_{H =}\\sum\_{i = 1}^{k}\\left| {x\_{i} - y\_{i}} \\right|$ 

Where `i` refers to the nearest neighbor whose values are 1, 2, 3 … .`k`. `x` and `y` refer to the variables.

## Decision Tree (DT)
`Decision Tree (DT)` also belongs to a class of supervised ML technique. The main aim of `DT` is to prepare a training model that will help in the predictions of target variables by implementing learning decision rules, which are deduced from training data. Its structure is like a flowchart that consists of leaf nodes, internal nodes, and branches ([Figure 6.6](#bodymatter-006.xhtml#b_9783110648195-006_fig_006)). The prediction for any record is always started from the root node. To choose one root variable from a number of variables, one of the methods used is the information gain. Information gain further measures the uncertainty of variable, which is known as Entropy ([Safavian and Landgrebe, 1991](#bodymatter-006.xhtml#b_9783110648195-006_ref_085)). ## Random Forest (RF)
`Random Forest (RF)` is another type of supervised ML algorithm introduced by Tin Kam Ho. `RF` builds the forest like structures with a number of decision trees in which independent vectors are divided equally and individual tree assigns a value 1 (unit) to the most voted input class `x` ([Figure 6.7](#bodymatter-006.xhtml#b_9783110648195-006_fig_007)). More the number of trees in the `RF`, more accurate will be the prediction ([Breiman, 2001](#bodymatter-006.xhtml#b_9783110648195-006_ref_009)). Let `h(x|θ[1])`, `h(x|θ[2])`, …, `h(x|θ[k])` be the number of `k` classifiers with parameters `θk` and a random vector `θ`. Then the equation for the `kth` decision tree classifier is given by

## Linear Discriminant Analysis (LDA)
`Linear Discriminant Analysis (LDA)` algorithm is described as a dimensionality reduction method that is used for pre-processing and pattern classification problems. Its main aim is to reduce the dimensions by transferring the variables from multi-dimensional space to smaller-dimensional space. ## Logistic Regression (LR)
`Logistic Regression (LR)` is another supervised ML technique commonly used in the field of statistics. `LR` is named after the function called the logistic function ([Cook, 1977](#bodymatter-006.xhtml#b_9783110648195-006_ref_019)). To give a binary output (either 0 or 1), the algorithm uses `x` input values combined linearly with coefficient values. The equation for Logistic Regression is given by:

(6.10)*y*\=*e*^∧(*b*0 + *b*1^(*x*))/(1+*e*^∧(*b*0 + *b*1 \* *x*)) 

Where the output is denoted by `y`, `b0` refers to the intercept word, `b1` refers to the coefficient and `x` refers to the input variable. The curve for logistic regression is given as in below figure ([Figure 6.9](#bodymatter-006.xhtml#b_9783110648195-006_fig_009)).

## Gaussian Process
`Gaussian Process` is defined as the algorithm which solves both problems of regression and classification. This algorithm is very useful in supervised learning as it can give an estimate of their own uncertainty. It is a stochastic process that works only on a finite set of variables ([Rasmussen, 2003](#bodymatter-006.xhtml#b_9783110648195-006_ref_079)). The equation that satisfies the Gaussian process is given as follows.

(6.11)$E\\left( {{exp}\\left( {i\\sum\\limits\_{l - 1}^{k}s\_{l}X\_{t\_{l}}} \\right)} \\right) = {exp}\\,\\left( \\left. {- \\frac{1}{2}\\,\\sum\\limits\_{lj}{\\sigma\_{l\_{j}}s\_{l}s\_{j + i}\\,\_{\\sum\\limits\_{l}{\\mu\_{l}s\_{l}}}}} \\right) \\right.\\,$ 

Where `t[1]`, `t[2]`, … .., `t[k]` are finite variables, `μ[l]` is the mean of variable, `σ[l[j]]` is the covariance with `σ[jj]` > 0 and `s[1]`, `s[2]`, … …, `s[k]` € R. The curve for Gaussian Process is given in below figure ([Figure 6.10](#bodymatter-006.xhtml#b_9783110648195-006_fig_010)).

## Ensemble Learning
`Ensemble Learning`, also known as meta-algorithms merges several machine learning algorithms into one accurate model so as to decrease boosting, bagging, or stacking. This algorithm is basically divided into two categories – sequential ensemble methods and parallel ensemble methods ([Dietterich, 2002](#bodymatter-006.xhtml#b_9783110648195-006_ref_023)). Many common types of ensembles are used, such as Bootstrap aggregating, Boosting, Bayes optimal classifier, etc. One of the types of ensemble, i.e., Bayes optimal classifier is expressed by the following equation.

(6.12)*y* = *a**r**g**m**a**x*[*c*[*j*] ∈ *C*]∑[*h*[*i*] ∈ *H*]*P*(*c*[*j*]|*h*[*i*])*P*(*T*|*h*[*i*])*P*(*h*[*i*]) 

where `y` is the output label that is being predicted, `C` is the group of possible outcomes, `H` is the hypothesis space, `P` refers to likelihood, and `T` refers to the data that is used for training.
