# 15 Computational health informatics using evolutionary-based feature selection

Vanaja Ramaswamy Department of Information Science and Technology, College of Engineering Guindy, Anna University, Chennai, Tamil Nadu, India Saswati Mukherjee Department of Information Science and Technology, College of Engineering Guindy, Anna University, Chennai, Tamil Nadu, India

## Abstract

This chapter is a recent survey of evolutionary computation (EC)-based feature selection (FS) techniques whose objective is mainly to improve the accuracy of the machine learning algorithm in minimized computation time. The idea is to bring forth the main strengths of EC as a naturally inspired optimization technique for FS in the machine learning process. The modeling of biological and natural intelligence that has made progressive advancements in the recent decade motivates us to review state-of-the-art FS techniques to add more to the area of computational intelligence. Owing to its importance, the use-case in support of health informatics is also exhibited.

Keywords: Evolutionary Computation, Feature selection, Machine learning, Computational intelligence,

## 15.1 Introduction

The chapter introduces machine learning techniques with a focus on feature selection (FS) and reviews the recent state-of-the-art FS mechanisms and their types. FS as an essential sub-process in machine learning allows the learning algorithm to train faster and improves the accuracy of the model by choosing the right subset of features ([Dash and Liu, 1997](#bodymatter-015.xhtml#b_9783110648195-015_ref_012)). It also results in a better understanding of the data with good generalization capability. The predictive performance is highly improved when a machine learning task is preceded by an effective FS approach. The chapter explains the general notion of filter-based method and wrapper-based method of FS with the differences in their respective approaches. A general FS (filter/wrapper) is readily applicable as long as the number of features available in the data set is small. As we progress to access big data, both in terms of the sample size and the feature size, no more general approach can do well as the search space is very large ([Xue et al., 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_048)). The immediate need is a mechanism that randomly starts with a heuristic and proceeds on with effective moves in the search of the global optimal position. Therefore, the interest of the chapter is to provide an overview of the evolutionary paradigm of FS mechanism and their importance in computational intelligence. Due to its global exploration ability in search, the evolutionary approach of FS namely genetic algorithm (GA), genetic programming (GP), particle swarm optimization (PSO), ant colony optimization (ACO), and others have become popular in the recent past of the research ([De La Iglesia, 2013](#bodymatter-015.xhtml#b_9783110648195-015_ref_013)). This chapter categorizes the FS as filter-based evolutionary methods (FBEM), wrapper-based evolutionary methods (WBEM), and hybrid-based evolutionary methods (HBEM). It explains these three categories of FS with a specific combination of the above-mentioned evolutionary approaches based on the relevance of application and the need for implementation. Concerning the time-sensitiveness of the industry, healthcare is considered as an application where specific use-cases one for FBEM and the other for WBEM are discussed.

## 15.2 Machine learning techniques with a focus on feature selection

“Machine learning is a kind of artificial intelligence which provides an automated learning ability for a system by using the experiences gained in the past.” As irrelevant and redundant features can impact the performance of a model negatively ([https://towardsdatascience.com/feature-selection-techniques-in-machine-learning-with-python-f24e7da3f36e](https://towardsdatascience.com/feature-selection-techniques-in-machine-learning-with-python-f24e7da3f36e)), they can be removed before the learning phase of a machine learning cycle.

FS as an efficient pre-processor can be added as an important paradigm to do this to bring improvement both in time and space complexity.

### 15.2.1 Terminologies involved with machine learning

The following are the terminologies involved for machine learning paradigm:

* *Model*

  A model is a hypothetical representation that learns some concepts from the data by using machine learning techniques.

* *Dataset*

  The file that contains “n” number of instances (records to be trained) represented in rows and “f” number of features represented as columns.

* *Feature Vector and features*

  The individual record of a data set will constitute a feature vector and each entity in the feature vector represents a feature.

* *Target (Label)*

  An output label that a record is associated with is called the target. This will apply to supervised learning methods.

* *Training*

  A machine learning algorithm is used to generate patterns that result out of the learning model.

* *Prediction*

  New data can be applied to the model to make a prediction based on the features of the data.
