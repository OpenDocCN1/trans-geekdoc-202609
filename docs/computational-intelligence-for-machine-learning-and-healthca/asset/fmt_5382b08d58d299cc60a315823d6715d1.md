# C. Supervised Learning Techniques

## `Naïve Bayes (NB)`

`Naïve Bayes (NB)` is also a supervised ML technique and a numerical method used for classification. It is named after Thomas Bayes who developed the Bayes Theorem. It expects a fundamental probabilistic model and permits to bind uncertainty of it in a moral path after deciding probabilities from the outcomes. So it is used to explain the predictive and diagnostic problems of the process ([Murphy, 2006](#bodymatter-006.xhtml#b_9783110648195-006_ref_070)). `NB` is vigorous to noise in the input dataset. The mathematical representation of the Naïve Bayes classifier is given by equation.

(6.1)${Posterior\\, Probability} = P\\left( {{Xi}|Y} \\right) = \\ \\frac{P\\left( {Y|Xi} \\right)P\\left( {Xi} \\right)}{P\\left( Y \\right)}$

Where `Xi` refers to “m” classes whose values are `X1`, `X2`, `X3`, … … .`Xm`. `P(Y|Xi)` refers to posterior probability, `P(Y|Xi)` refers to predictor probability, `P(Xi)` stand for prior probability and `P(Y)` stands for predictor probability of the class. ## `Support Vector Machine (SVM)`

`Support Vector Machine (SVM)`, most famous supervised ML algorithm introduced in 1995, which can solve both regression and classifications problems ([Cortes and Vapnik, 1995](#bodymatter-006.xhtml#b_9783110648195-006_ref_020)). This algorithm draws “hyperplane” and distributes the data within different classes with the goal that all instances that belong to one class get classified on one part and they lie on the opposite part of the plane (shown in [Figure 6.3](#bodymatter-006.xhtml#b_9783110648195-006_fig_003)). Linear SVM Classification is characterized for SVM classifying functions, and partitioning happens if the selected line includes the most oppressed portion ([Maji and Garg, 2014](#bodymatter-006.xhtml#b_9783110648195-006_ref_066)). For non-linear cases, the advanced selection of kernel and data preprocessing is needed. It has an important application in healthcare as it can predict various diseases from MRI scan reports. The equation for the hyperplane is given below.

![Figure 6.3: SVM representation with hyperplane.](graphic/converted/b_9783110648195-006_fig_003.png)

Figure 6.3: SVM representation with hyperplane.

Where `b` stands for bias value for input variable `x` and `w` refers to the weight vector. The SVM classification equation is written using minimization formula as given below.

## `Neural Network (NN)`

`Neural Network (NN)`, also known as the neuron, is an information processing technique that originates from the human mind. This framework incorporates enormous amount of tiny processors that deal with information processing. Various processors used in `NN` operate as an interconnected system parallel to one another to tackle an issue. `NN` are known for their capacity approximations, which is why they can be connected to practically any ML issue ([Hansen and Salamon, 1990](#bodymatter-006.xhtml#b_9783110648195-006_ref_037)). The result of the `NN` is defined as

(6.4)$N = \\sum\_{i = 1}^{H}{v\_{i}\\sigma\\left( z\_{i} \\right)}$

Where `v[i]` refers to i^(th) weight parameter, `x[i]` refers to the input vector, `w[i]` refers to the weight parameter, `σ` refers to an sigmoid function, and `b[i]` refers to the bias for i^(th) unit. Also `z[i]` = `w[i]`*`x[i]` + `b[i]` and `$\\sigma = \\frac{1}{1 + \\ e^{- x}}$`. The structure of `NN` is presented in [Figure 6.4](#bodymatter-006.xhtml#b_9783110648195-006_fig_004).
