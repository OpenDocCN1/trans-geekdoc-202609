

Bounded Staled Sync (BSSync) 是一个在本文中解释的框架（[Lee 等, 2015](#bodymatter-008.xhtml#b_9783110648195-008_ref_018)）。它具有硬件栈和软件栈，以在并行 ML 系统中并行执行的微小作业为基础来降低开销。微小任务被委派到逻辑内存的层级上执行，以便中央处理单元能够完全用于 ML 算法。在某些 ML 场景中，原子进程被实现用于读操作、写操作、修改操作和追加操作。它通常用于并行计算，以便使每个并行运行的线程都能够更改特定变量的同一内存位置的值。五种不同的 ML 函数（最小二乘矩阵 (LSM) 分解、单源最短路径、潜在狄利克雷分配 (LDA)、LASSO 回归和广度优先搜索 (BFS)）通过改变输入来用于框架评估。

[Lee 等, 2017](#bodymatter-008.xhtml#b_9783110648195-008_ref_040) 的研究文章中提出了一个框架。它源自相似性搜索关联记忆 (SSAM)。它通过 NDP 加速相似性搜索。相似性搜索是 k-最近邻 (kNN) 算法的基础的关键思想。相似性搜索的思想被用于多种功能，如自然语言处理 (NLP)、图像处理等。本文主要关注特定的 ML 算法，即 kNN 算法。kNN 中的阻塞通常出现在相似性搜索阶段。论文发现 SSAM 在 50% 的搜索精度中提供 170 倍的吞吐量提升，并在 99% 的搜索精度中提供 13 倍的提升。多个动态随机存取存储器 (DRAM) 层被垂直分割成多个称为 vault 的部分。主机处理单元的驱动程序负责处理、配置和编译 SSAM 加速器。类似的 SSAM 框架在 [Lee 等, 2018](#bodymatter-008.xhtml#b_9783110648195-008_ref_041) 中提出。在这篇研究论文中，架构是在多个参数之间的欧几里得距离限制以及用于 kNN 的特征向量约束的基础上评估的，并使用了三个特定数据集，即 AlexNet 数据集、词向量全局表示 (GloVe) 数据集和 GIST 数据集。在 [Lee 等, 2018](#bodymatter-008.xhtml#b_9783110648195-008_ref_041) 中提出的框架中，SSAM 与主机单元和 DRAM 集成。它被评估用于线性加近似 kNN 算法。SSAM 框架是基于 Hybrid Memory Cube 2.0 (HMC2.0) 生成的，以利用增强的内存传输容量优势。节省费用的计算判断未考虑数据中心中存在的额外开销，如电力使用开销和网络工具开销。

异构可重构逻辑 (HRL) 架构在 Gao 等, 2016 中提出。HRL 包含许多不同的部分，链接用于路由的静态可重构结构。具有粗粒度可重构阵列 (CGRA) 模式网格和功能单元 (FUs)（粗粒度 FUs）的预期 HRL 架构用于执行常见的数学函数。架构还使用现场可编程门阵列 (FPGA) 模式和可配置逻辑块 (CLBs)（细粒度 CLBs）来执行明确的逻辑和特定功能。HRL 系统利用静态可重构网络来降低能源需求开销。HRL 系统包含一种基于总线的粗粒度数据网络，以及一种细粒度的位级控制网络。架构不包含分布式 BRAM，即块 RAM。作者设计了一个具有可扩展属性的 NDP 系统，具有多个内存堆栈以及基于 HRL 的中央计算系统来处理分析工作负载。类似的系统在 Gao 等, 2015 和 Gao 等, 2016 中有所解释，并用于深度神经网络 (DNN)、图处理和 MapReduce 框架。系统硬件栈中的重要部分有 vault 硬件、主机处理器以及 3D 内存堆栈。[Gao 等 (2015](#bodymatter-008.xhtml#b_9783110648195-008_ref_025)) 提供了 NDP 系统的软件和硬件栈的详细信息。它为 MapReduce 框架上的应用程序提供内存内分析方法，处理图和神经网络。

论文 ([Hong 等, 2016](#bodymatter-008.xhtml#b_9783110648195-008_ref_004)) 提出的框架将链表遍历 (LLT) 的实现移近数据存储，并通过减少数据访问来降低 LLT 延迟。片上还通过 LLT 引擎（专用设备）增强了并行实现的效率和能效。设计的系统适用于每种类型的链表。[Hong 等, 2016](#bodymatter-008.xhtml#b_9783110648195-008_ref_004) 中描述的利用 NDP 加速 LLT 的架构与 LLU、Graph500、Memcached 和 Hash join 的工作负载一起进行了评估。在处理/主机单元处，网络通过星型拓扑配置，内存网络（芯片间网络）因为唯一的计算单元有权使用内存单元，而 HMC 内存单元之间的互连是不必要的。LLT 引擎、数据定位和批处理的使用对系统性能有影响。除了 memcached 之外的所有工作负载中，完整 LLT 事件的完成都与完成时间有关。然而在 Memcached 中，每个 LLT 函数都与一个客户端请求相关联，并且所有 LLT 中的延迟可能会影响到用户级请求的延迟。

[Vermij 等 (2017](#bodymatter-008.xhtml#b_9783110648195-008_ref_011)) 解释的系统研究了 GRAPH500 算法以及旨在与基于共享内存概念的 NDP 框架一起工作的 HPGA 算法的性能。它讨论了各种特性，例如程序优化、系统约束计划以及类似用户增强逻辑的特殊结构特征的管理，以及为多个处理器之间的数据传输而进行的数据局部性扩展。系统的主要模块命名为 NDP 管理器、NDP 核心和 NDP 访问点 (AP)。框架使用常规模拟器进行评估，该模拟器用于模拟系统。采用了具有共享内存的嵌套 OpenMP 并行化技术用于设计的框架。该架构的性能测量显示，与常规主机单元相比，速度提升了 3.5 倍。

云端系统的自动扩展和调整平台 (ASAPCS) 在 [Kampars 等 (2017](#bodymatter-008.xhtml#b_9783110648195-008_ref_016)) 中给出。它是为处理数据同化和处理问题而创建的架构，用于提出数据驱动的应用程序并部署在基于 CloudStack 的远程终端单元 (RTUs) 上。架构的组件是 Apache SPARK 集群、Kafta 集群、数据驱动系统、调整引擎、Cassandra 集群和 ASAPCS 核心单元。Kafta 集群为系统安全性提供了额外高度。

基于 NDP 的 3D 堆叠内存的 CNN 逻辑单元 (CLU) 在 [Das 等 (2018](#bodymatter-008.xhtml#b_9783110648195-008_ref_027)) 中提出。系统的评估已通过仿真执行。仿真显示了有利于 CNN 过程的性能提升，而计算在内存中进行，同时与具有 DRAM 的主机计算单元相比。它显示了 76 倍的执行增强，而功耗需求降低了 55 倍。
