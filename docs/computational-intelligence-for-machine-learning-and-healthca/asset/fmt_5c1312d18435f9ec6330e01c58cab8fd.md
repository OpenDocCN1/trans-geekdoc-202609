
### 15.5.3 FB-PSO

A filter-based FS with a variant of PSO embedded with the GA is proposed to mitigate the premature convergence problem that exists in the conventional PSO approach. The work uses non-replaceable memory, secondary swarm, and a new update mechanism in velocity. In-depth analysis is performed for recognizing seven facial emotions by using multiple classifiers ([Mistry et al., 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_030)). When exhaustive search does not result in the effective selection of features due to time-consumption, the use of a meta-heuristic PSO algorithm serves good in efficient search of the solution space. The proposed work has performed filter-based FS where the performance of the classifier and the selected features length are adopted as heuristic information. The experiments are conducted on benchmark data sets ([Aghdam and Heidari, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_001)).

### 15.5.4 FB-ACO

Novel selection of features is performed using a combination of graph clustering and ACO. One of the algorithms for detecting the communities is used after performing clustering and as a third step, ACO is used as a search paradigm to select the final subset of features. The evaluation is performed using the separability index and executed as a filter-based approach ([Moradi and Rostami, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_032)). A modified version of binary-coded ACO is combined with GA to perform filter-based FS. The proposed works have modeled on two aspects, one based on visibility density and the other based on pheromone density. The performance is analyzed by comparing the other existing and leading methods based on GA and PSO, and it is found that the proposed approach is better in terms of accuracy ([Wan et al., 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_047)).

## 15.6 Wrapper-based evolutionary methods

The following subsections explain the recent research progresses in wrapper-based mechanism executed in combination with GA, GP, PSO, and ACO evolutionary approaches.

### 15.6.1 WB-GA

A bi-objective genetic algorithm is used for selecting the features where rough set and information theories are used for the definition of the objective function. A parallel implementation of ensemble FS is performed to reduce the execution time by using the pareto-based approach ([Das et al., 2017](#bodymatter-015.xhtml#b_9783110648195-015_ref_010)). Credit scoring in financial computation is handled using two methods namely information gain-based and wrapper-based genetic algorithm where for assessing the features K-nearest neighbor, Naive Bayes, and support vector machine classifiers are used. The observation from the results implies that classification accuracy mostly depends on the nature of the dataset used ([Jadhav et al., 2018](#bodymatter-015.xhtml#b_9783110648195-015_ref_023)). To differentiate between normal and abnormal traffic, an anomaly-oriented intrusion detection system is proposed using the genetic algorithm and support vector machine. The new form of FS that uses the genetic algorithm makes a difference in terms of the fitness function used. More stable features are selected which have effectively reduced the false positive rate ([Gharaee and Hosseinvand, 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_016)). The work proposes a multi-stage FS mechanism to select the best parameters based on the time-frequency domain. GA is used in a supervised environment for selecting the best features along with the artificial neural network as a classifier. The exploration and exploitation abilities of the genetic algorithms are studied in the experiment conducted. The whole of the work is dedicated to condition-based monitoring of gearboxes ([Cerrada et al., 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_006)).

### 15.6.2 WB-GP

GP is used for powerful FS to improve the performance of segmentation in the standard classification process. The work has proposed three FS techniques that are tested using standard classifiers and are executed on two high varying datasets. Investigations of single and multiple objectives GP techniques have been performed ([Liang et al., 2017](#bodymatter-015.xhtml#b_9783110648195-015_ref_026)). An ensemble way of genetic programming is proposed for effective FS where the c-class problem is divided into c binary classification problem. A weighted voting scheme has been adopted in the ensemble that uses false-positive and false-negative values on the training data. The work is compared with a bi-objective GP scheme that uses a reduction of rule size strategy and the proposed method holds good ([Nag and Pal, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_033)).

### 15.6.3 WB-PSO

A new wrapper-based FS is proposed to improve the capability of a classifier to classify datasets which are incomplete. PSO is used for searching the feature subsets and C4.5 is used as the classifier to assess the feature subsets. Empirical results are obtained and analyzed on 14 datasets (Tran C.T. et al., 2016). A variant of PSO named as competitive swarm optimizer is used for resolving FS for high-dimensional problems. Here, the developed algorithm is used as a combinatorial optimization technique rather than being used as a continuous optimization technique. To reduce the cost of computation, an archive technique is also developed ([Gu et al., 2018](#bodymatter-015.xhtml#b_9783110648195-015_ref_018)). PSO-based FS is performed with local search combined with `gbest` resetting mechanism to find the solution for local optima problem. The proposed algorithm is compared with three existing FS techniques. To ensure good generalization ability, it is noticed from the developed system that bias in FS should be avoided ([Tran et al., 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_042)). For effective retrieval and analysis of an image, the semantic concepts should be assigned to an input image. An improved quantum-based PSO for selecting the features and ensemble-based boosting technique has been used in the research ([Jin and Jin, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_024)).

### 15.6.4 WB-ACO

The proposed work selects the optimal features without the use of prior information using ACO for searching and one classifier for assessing the features selected. The development of a facial recognition system is the application proposed in the work ([Dadaneh et al., 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_009)). Wrapper-based approach in selecting the features is executed for the application of intrusion detection. The work uses support vector machine for validating the reduced data set. On performing the experiments on `KDD99` dataset, the detection based on signature and anomaly is intended to be performed ([Mehmod and Rais, 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_029)).
