

工业组织正在使用大量通过机器学习（ML）识别的数据。通过收集这些数据的感知，组织可以更高效地工作，并比竞争对手取得更好的成果（[Amin et al., 2013](#bodymatter-005.xhtml#b_9783110648195-005_ref_003)）。在各个领域，ML 算法已被用于创新的预测模型（[Anand et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_004)）。甚至深度学习技术也被用于日常活动中的广告、Google 搜索和 YouTube。在多学科和医疗保健信息学领域，ML 和深度学习技术的应用在数据处理挑战和技术广告方面变得相同（[LeCun et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_029)；[Russakovsky, 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_038)）。科学领域如健康或医学信息学处理存储、检索和医疗数据的最佳使用以及为问题解决和决策提供的信息。过去几十年里，健康技术取得了巨大的发展，如信息收集、通信、研究和治疗方面的进步。通过医疗信息数字化，患者数据有所增加，这些数据可以与先进设备生成的医疗结果和患者提供的数据相关联（[Hirschberg et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_025)）。这一信息革命是一个共同结果，人们面临着解读和理解数据的令人沮丧的任务。处理或管理这些大量数据仅靠手动技术和工具是不可能的，而且也是一个非常缓慢和繁琐的过程。因此，为了理解数据，需要来自计算科学或数据科学和数据分析的数据驱动方法。关键的健康信息可以被提取，医疗数据可以利用这些方法进行分析，这可以帮助医生和患者做出更好的决策（[Hinton et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_022)）。
目前，为了分析医疗数据，学术界和工业界在数据科学上投入了大量资金。在未来几年，随着医学中生成数据的数量快速增长，数据科学将发挥重要作用。在将人工智能（AI）系统部署到医疗保健应用之前，需要通过临床活动对其进行训练，例如诊断、治疗和筛查评估，这些活动会生成数据（[Kotsiantis, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_028)）。这是为了让 AI 通过相似的受试者群体以及结果与感兴趣特征之间的关联来学习。AI 设备主要有两大类。
第一类使用 ML 技术：这将分析结构化数据，如基因、合格提供者（EP）和影像数据，并用于尝试找出疾病结果概率的医疗应用（[Brazdil et al., 2003](#bodymatter-005.xhtml#b_9783110648195-005_ref_011)）。
另一类使用自然语言处理（NLP）：这将从医学期刊和临床记录等非结构化数据中提取信息，从而补充和丰富结构化医疗数据（[Cheng et al., 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_012)）。NLP 程序的主要目标是将文本转化为机器可读的结构化数据，然后使用 ML 技术进一步分析。
在本章中，第 5.1 节提供了关于 ML 和深度学习在医疗保健中使用的简要介绍；第 5.2 节包含 ML 方法的分类，分为四种类型。第 5.3 节给出了在医疗保健领域使用 ML 技术的系统程序。第 5.4 节给出了 ML 在医疗保健中的应用，包含各研究者在医疗保健不同领域的工作以及比较研究。第 5.5 节给出了医疗保健和其他行业中的深度学习解决方案以及比较研究，第 5.6 节包含深度学习在医疗保健和医学领域的当前和未来应用。

### 5.2.1 监督学习

监督学习被赋予的另一个名称是预测模型，用于使用数据集中其他值预测一个值的任务等（[Anil Mathur, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_005)）。预测模型训练的过程被确定为监督学习，因为预测模型被明确告知它们需要学习什么以及如何学习。在存在不确定性的情况下，监督 ML 能够预测存在的证据。[Figure 5.2](#bodymatter-005.xhtml#b_9783110648195-005_fig_002) 显示了语音学习的图表。正如在监督学习算法中那样，从输入数据集和已知数据响应中获得输出。一些监督 ML 算法如下：

![Figure 5.2: Supervised learning (Anil Mathur, 2007).](graphic/converted/b_9783110648195-005_fig_002.png)

Figure 5.2: Supervised learning ([Anil Mathur, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_005))。

* **支持向量机（SVM）：** SVM 被认为是与经典多层感知器神经网络（NNs）密切相关的最新类型的监督 ML 技术（[Yang et al., 2018](#bodymatter-005.xhtml#b_9783110648195-005_ref_045)）。它在用于分离两个或两个以上对象或数据类的超平面上工作，作用于对象与超平面的边界（[Zhang et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_046)）。通过减小边界或在实例与分离它的超平面之间创建较大距离，预计泛化误差将减少。
* **朴素贝叶斯（NB）：** 在分类和训练阶段，NB 监督 ML 方法需要非常少的存储空间（[Zhu et al., 2009](#bodymatter-005.xhtml#b_9783110648195-005_ref_047)）。这意味着为了存储先验和条件概率，需要非常少的存储空间，这导致训练阶段的存储内存非常少，但执行空间应等于训练部分的空间。
* **NN：** NN 监督 ML 方法或技术能够执行回归和分类的各种任务，但单个网络仅执行单一任务（[Hiregoudar et al., 2014](#bodymatter-005.xhtml#b_9783110648195-005_ref_024)）。因此，在大多数情况下，网络中只有一个输出变量，但在处理具有多种状态分类问题的情况时，可以有多个输出单元。
* **决策树（DT）：** 这些树通过根据特征值对实例进行简单排序来对实例进行分类。DT 中每个节点表示一个待分类的实例特征，而其中每个分支表示每个节点假设的值（[Gillies et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_016)）。实例的分类从根节点开始，然后根据特征值进行排序。
