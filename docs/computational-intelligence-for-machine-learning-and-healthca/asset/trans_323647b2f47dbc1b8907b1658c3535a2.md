# 3 使用 Stockwell 变换和 ABC 优化的双 SVM 进行心律失常识别

Sandeep Raj 电子与通信工程系，印度信息技术学院 Bhagalpur 分校，Bhagalpur，印度 Arvind Choubey 电子与通信工程系，印度信息技术学院 Bhagalpur 分校，Bhagalpur，印度

## Abstract

世界卫生组织报告称，心脏疾病是全球死亡的主要原因之一，并将在未来十年持续存在。因此，心脏医疗保健需要对较长时间的脑电图（ECG）信号或心跳进行自动计算机辅助诊断。在本章中，高效的特征表示和机器学习方法被结合并开发用于处理 ECG 信号。最初，原始心跳经过预处理以消除其中固有的各种噪声。随后，通过在信号中应用 Pan–Tompkins 技术来定位 QRS 波。QRS 波定位后，选择固定大小的矩形窗口对心跳进行分割。然后，采用 Stockwell 变换方法从心跳中提取时频（TF）信息作为特征。选择少量系数以实现心跳的高效表示，这进一步降低了使用分类器处理时的复杂度。这些输出系数代表了单个心跳的特征并有助于根据其形态区分它们。此外，捕获心跳之间的 R 峰到 R 峰信息并将其与输出 TF 系数连接起来。结果，该最终特征向量表示每个心跳，应用于双支持向量机分类器以将其分类为相应的类别。分类器的性能也得到增强，因为其参数采用人工蜂群算法在患者特定方案下进行优化。所提出的方法在 PhysioNet 数据库上得到验证，并将分类器模型的输出与数据库中相应心跳的标签进行比较以形成结果。所进行的实验报告了总体准确率达到 88.22%，优于现有的最先进方法。

关键词：脑电图（ECG），心律失常，Stockwell 变换，RR 间期，双支持向量机。

## 3.1 Introduction

世界卫生组织统计数据显示，由于心脏异常，全球死亡人数显著增长。2008 年，约有 1730 万人死于心血管疾病（CVDs），预计到 2030 年将达到 2330 万。约 80% 的死亡发生在人均收入低或中等国家。这些死亡中的绝大多数是由于 CVDs 误诊或晚诊造成的。脑电图（ECG）是一种低成本、准确且无创的工具，广泛用于诊断 CVDs，常用分析心脏过程的行为（[Garge et al., 2018](#bodymatter-003.xhtml#b_9783110648195-003_ref_007)； [Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)； [Raj et al., 2018f](#bodymatter-003.xhtml#b_9783110648195-003_ref_036)）。ECG 是心脏泵血动作产生的电位图形记录。它是心脏组织的去极化和复极化，产生电位差以供检查。该机制始于窦房结的触发——心脏的起搏器产生电脉冲，触发心脏中一系列电事件。这样的自然事件由电极提及，波动在 ECG 信号的波成分中表示。ECG 信号通常由 P 波成分组成，这是心房去极化的指示，QRS 复合波成分，这是心室去极化的指示，ST 斜率成分，表示血液在人体内的正常流动，以及 T 波，这是心室复极化的指示。从 ECG 记录中检测心脏疾病是使用节律、心率变异性测量和 QRS 时长进行的（[Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)）。R 波峰分类在自动信号分类中非常重要，尤其是在危急情况和心脏异常时。如今 ECG 是全球最有前景的心脏诊断方法，因为它揭示了重要的临床信息（[Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)）。它诊断 ECG 的节律性发作，如果患者有任何心脏疾病，则进一步分类心律失常。心律失常是由于心脏肌肉损伤、糖尿病、吸烟习惯、低和高呼吸、血压等引起（[Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)）。这些心律失常分为危及生命（关键）和非危及生命（非关键）（[Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)）。严重的心脏异常不允许任何时间进行治疗，而非关键的心脏异常需要特殊治疗以挽救生命。仅凭肉眼的简单诊断可能会导致检测失误。因此，在该阶段需要计算机化诊断（[Raj, 2018a](#bodymatter-003.xhtml#b_9783110648195-003_ref_023)）。
