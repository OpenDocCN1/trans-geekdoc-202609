
To show improvement in randomization and search operation, the genetic algorithm is enhanced with new crossover and mutation operations. The comparison between the GA and the proposed enhanced GA results in a reduction in dimensions and time. Accurate categorization of text is performed by bringing forth some hybrid FS methods along with the enhanced genetic algorithm concept ([Ghareb et al., 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_017)). Owing to several limitations that exist in the existing FS techniques, a hybrid GA that combines wrapper and embedded FS methods is proposed. A novel chromosome encoding is used where the objective is to optimize the control parameters for good optimization ([Liu et al., 2018](#bodymatter-015.xhtml#b_9783110648195-015_ref_027)). A hybrid GA for efficient local search is proposed that works in combination with K-nearest neighbor classifier. The features are ranked and associated weight is given to those features during the classification process. The system is proposed to be applied for bringing innovation in management during the strategic decision making process ([Eroglu and Kilic, 2017](#bodymatter-015.xhtml#b_9783110648195-015_ref_015)).

## 15.7.2 HB-GP

High-dimensional feature construction and selection is executed to produce smaller feature sets that will improve the performance of the learning algorithm. A hybrid approach is followed and is applied to six high-dimensional data sets to prove the efficiency of the proposed work. Dynamically tuned evolutionary GP approaches have boosted the performance of the system (Tran et al., 2016, December).

## 15.7.3 HB-PSO

Correlation information-based local search strategy is used with the existing PSO concept to guide the search process effectively. The proposed work also determines the size of the feature subset to select the subset with a reduced size. The comparison with the existing state-of-the-art filter-based FS methods has been performed to show the effectiveness of the proposed hybrid strategy ([Moradi and Gholampour, 2016](#bodymatter-015.xhtml#b_9783110648195-015_ref_031)). A hybrid FS strategy is first proposed where most of the evaluations in the search process of PSO are filter-based and some of the evaluations are wrapper-based. The second proposal includes reducing the number of evaluations for wrapper-approach in order to save time. The proposed work depicts that the wrapper-approach results in achieving high classification performance with a reasonable number of selected features and the filter-approach results in good accuracy with a reduced number of features during the selection process ([Butler-Yeoman et al., 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_004)).

## 15.7.4 HB-ACO

ACO is used both for FS and classification by using the Ant-Miner classifier. The proposed hybrid method of FS performs well in comparison with other existing methods to discriminate the input features properly and in the optimal way of selecting the features ([Rasmy et al., 2012](#bodymatter-015.xhtml#b_9783110648195-015_ref_038)). An ensemble classifier is coupled with ACO algorithm to perform effective FS and to improve the predictive accuracy of filters. Experiments are conducted on 11 publicly available data sets operated over four different classifiers. The results show that the proposed hybrid approach outperforms many existing FS techniques ([Naseer et al., 2018](#bodymatter-015.xhtml#b_9783110648195-015_ref_034)).
