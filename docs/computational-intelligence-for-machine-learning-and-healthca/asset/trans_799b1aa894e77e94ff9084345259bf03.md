### 7.3.3 QRS 波定位与 windowing

本研究根据 ECG 信号中 R 波的定位对不同类型的心律失常进行分类。在提取特征之前对 ECG 信号进行分割之前，有必要确定 R 波的位置。文献中已报道了大量用于检测 R 峰的研究（Raj et al., 2018e），其中本研究采用了成熟的 Pan-Tompkins（PT）算法（Pan, 1985）。由于其在嘈杂环境下具有已证实的较低计算负担和更高性能而被选用。检测到的 R 波与数据库中提供的 R 峰注释位置进行了验证。[图 7.4](#bodymatter-007.xhtml#b_9783110648195-007_fig_004)。描绘了数据库中记录 #118 心跳中 R 波的定位。

![Figure 7.4: QRS wave detection.](graphic/converted/b_9783110648195-007_fig_004.png)

图 7.4：QRS 波检测。

在本研究中，分割步骤与几乎所有已报道的工作略有不同。他们使用恒定时间或样本的矩形窗口。样本取自后 R 峰右侧的 65%，而从左侧取前 R 峰的 35% 来估计每个心跳的长度。确保从起始 P 波到结束 T 波的 ECG 的所有信息都被保留，且不会丢失任何波的信息。

### 7.3.4 特征选择

特征矩阵输入数据包含其性质和特征的大量有用数据。直接输入数据处理会增加算法在分类器模型复杂性方面的难度。因此，有必要从任何输入数据中提取大量有意义的信息作为特征，以表示用于分类目的的心跳。这些特征作为输入应用于分类器模型，该模型经过训练和测试，这些特征必须作为输入提供。EMD 的信号分解产生 (N-1) 个 IMF 和一个剩余元素。由于低阶 IMF（即高频 IMF）显示快速振荡模式，而高阶 IMF 显示延迟振荡模式，经实验发现，前四个 ECG 心跳的 IMF 包含有关初始信号所需的数据。因此，仅前四个 IMF 可用于确定本次实验的输入特征。这样我们不仅降低了过程的复杂性，也减少了计算时间。本研究中 ECG 心跳包含的其他元素如 [表 7.1](#bodymatter-007.xhtml#b_9783110648195-007_tab_001) 和 [7.2](#bodymatter-007.xhtml#b_9783110648195-007_tab_002) 所示。

* **i. 加权平均频率（特征 I）**：本章利用 HHT 计算 ECG 心跳数据的希尔伯特谱。当使用瞬时频率和瞬时幅度计算所有 IMF（除剩余元素外）的原始信号的平均频率时。具有 m 个 IMF，它定义了 `cj(t)` 的平均瞬时频率 `MIF(j)`，其中 jε\[1, m\] 且 tε\[1, n\] 包含 n 个数据集的第 j 个 IMF，作为希尔伯特谱的瞬时频率 `wj(t)` 和瞬时幅度 `aj(t)` 的加权平均值，如下所示：

```
(7.8)$MIF\\left( J \\right) = {}\\frac{\\sum\\limits\_{t = 1}^{n}w\\left( t \\right)\_{j}a\\left( t \\right)\_{j}^{2}}{\\sum\\limits\_{t = 1}^{n}a\\left( t \\right)\_{j}^{2}}\\ldots\\ldots.$
```

原始信号的平均频率应由下式确定

```
(7.9)$WMF = \\frac{{\\sum\_{j = 1}^{n}MIF\\left( j \\right) \\parallel a\_{j}} \\parallel}{\\sum\_{j = 1}^{m} \\parallel a\_{j} \\parallel}$
```

* **ii. KC（特征 II）：** 在获得信号 `x(t)` 的 EMD 分解后，其构成的 IMF `c[j](t)`，j ε\[1, m\] 且 t ε\[1, n\] 将在采用以下规则时转换为二值信号：

```
$c\_{j}\\left( t \\right)\\ = \\left\\{ {\\begin{matrix} {1,{ifcj}\\left( t \\right) \\geq E\\left( {{cj}\\left( t \\right)} \\right)\\ } \\\\ {0,{ifcj}\\left( t \\right){< E}\\left( {{cj}\\left( t \\right)} \\right)} \\\\ \\end{matrix}\\!\\!} \\right\\}$
```

* **iii. R 峰幅度（特征 III）：** R 峰是指 ECG 心跳的峰值幅度。R 峰位于 ECG 心跳的 QRS 波群中，其幅度是心跳的重要特征。
