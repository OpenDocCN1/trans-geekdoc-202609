### 4.3.2 自动语音识别

语音是人类之间最自然、最便捷的交流方式。以此作为人与机器之间交流的媒介，如今已成为最理想的方式。这种交互需要将人类的口语转换为机器可理解的形式。自动语音识别就是完成此任务的方法。ASR 利用计算机算法将口语转换为文本。诸如听写系统、命令和控制指令以及信息检索等多种潜在应用都使用该技术。这些系统范围从孤立语音识别到高度会话式语音信号的识别。ASR 系统也可以根据词汇量大小进行分类，从小型（最多 1000 个词）到超大（超过十万个词）不等（[Whittaker and Woodland, 2001](#bodymatter-004.xhtml#b_9783110648195-004_ref_028)）。

[图 4.5](#bodymatter-004.xhtml#b_9783110648195-004_fig_005) 展示了标准 ASR 系统的总体架构。ASR 系统是三个主要组件的集成：声学模型、词法模型和语言模型。ASR 系统的工作分为两个阶段，首先是对输入语音进行参数化，然后使用这些特征对系统进行训练和测试。在系统的核心，使用代表语言中各种音素单元的参数来开发统计模型。在第一阶段，即训练过程为语音声学（需要大量用户的录音样本）、语言统计（使用文本数据进行语法知识和 n-gram 模型）以及识别词典（可识别词元的词库及其音标转写及多种变体）创建模型。此处创建的声学模型可以是上下文相关的（音位变体、三音节等）以及上下文无关的（单音素）模型，能够捕捉语音、说话人和信道变异性。

![Figure 4.5: The general architecture of the ASR system.](graphic/converted/b_9783110648195-004_fig_005.png)

图 4.5：ASR 系统的总体架构。

在训练期间，以向量的形式提取特征以构建声学模型。这些语音特征可以是线性预测系数、Mel 频率倒谱系数（MFCC）、感知线性预测、伽玛音频率倒谱系数和基底膜频率带倒谱系数，或作为多特征集组合检索的混合特征（MF-PLP）（[Dua et al., 2018](#bodymatter-004.xhtml#b_9783110648195-004_ref_010)）。特征提取过程有助于降维以及概率建模。识别词典的创建是词法建模的一步。它将词典中的每个正字法词元分配给口语（可以是音素、音节或词）。语言建模有助于在声学建模过程中选择最合适的识别假设。语言模型还有助于建模目标语言的语法、语义和结构。语言模型的优劣基于用于经验估计的文本数据的规模和多样性。

对于声学模型的创建，当今的 ASR 使用诸如隐马尔可夫模型（HMM）（[Young et al., 2008](#bodymatter-004.xhtml#b_9783110648195-004_ref_029)）、动态规划（[Jing et al., 2010](#bodymatter-004.xhtml#b_9783110648195-004_ref_017)）、支持向量机（SVM）（[Solera-Urena et al., 2007](#bodymatter-004.xhtml#b_9783110648195-004_ref_024)）和人工神经网络（[Mohamed et al., 2011](#bodymatter-004.xhtml#b_9783110648195-004_ref_020)）等技术。最近，模型创建方法已扩展到使用深度神经网络（[Upadhyaya et al., 2019](#bodymatter-004.xhtml#b_9783110648195-004_ref_025)）和动态信念网络。图 [4.5](#bodymatter-004.xhtml#b_9783110648195-004_fig_005) 中描绘的系统基于随机 HMM 方法。这些语音解码器使用一种实现令牌传递的方法，并使用维特比算法创建（[Young et al., 2008](#bodymatter-004.xhtml#b_9783110648195-004_ref_029)）。它们可以生成表示识别假设的词/音素 N-best 列表，这些列表使用语言模型重新评分并选择得分最佳的一个。易于适应的开源工具包（如 Julius、Sphinx、HTK 和 Kaldi）的可用性帮助开发人员在任何目标语言中制作 ASR 应用。

**ASR 性能：** 评估任何 ASR 系统性能最常见的指标是词错误率（`WER%`）。该参数通过将转录输出与参考转录进行比较来评估。此错误可进一步用于评估三类错误。

* 插入（`I`）：输出转录中存在的单元，但在输入样本中不存在。
* 删除（`D`）：转录输出中缺失的单元，而在输入样本中存在。
* 替换（`S`）：输出转录中混淆并因此被另一单元替换的词/单元。

有了这三类错误，`WER%` 计算为 `WER% = (I + D + S)/N`，其中 `N` 为参考词数。除此之外，在少数语言中，性能以字符错误率和语句错误率来计算。
