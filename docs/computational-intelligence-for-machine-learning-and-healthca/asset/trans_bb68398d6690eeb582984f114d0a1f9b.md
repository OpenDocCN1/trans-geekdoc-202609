本章旨在开发一种方法，该方法结合特征提取和机器学习算法，以在真实场景中高效分析心跳。在此，Stockwell 变换（`ST`）用于从后续心跳中提取 TF 信息。这些特征代表每个 ECG 信号，并进一步使用人工蜂群（`ABC`）调优的双支持向量机（`TSVMs`）识别为不同类别的心跳。所开发的方法在 PhysioNet 数据上根据患者特定方案进行验证，以估计其准确性。实验结果报告的识别准确率高于之前的研究。

## 3.2 方法

本节重点介绍本研究中使用的方法，如用于特征提取的 S 变换、用于识别的 `TSVM` 和用于优化 `TSVM` 参数的 `ABC`。

### 3.2.1 Stockwell 变换

`ST`（[Stockwell, 2007](#bodymatter-003.xhtml#b_9783110648195-003_ref_037)）是一种时频 TF 分析工具，用于分析一维信号。它被认为是短时傅里叶变换的推广及其扩展连续小波变换（`CWT`）。`CWT` 的缺点已被 `ST` 很好地解决。`ST` 提供时频空间的频率相关分辨率。此外，它还提供输入信号的绝对参考相位信息，其组合是唯一的。`ST` 的推导（[Stockwell, 2007](#bodymatter-003.xhtml#b_9783110648195-003_ref_037)）可以理解为相位校正的 `CWT` 结合高斯窗函数。

```
S_x({t,f}) = ∫_{-∞}^{+∞} x(τ) · |f| · e^{-π(t - τ)^2 f^2} · e^{-2π f τ}
```

上述表达式说明 S 变换函数可以表示为 (*x*(*τ*) *e*^(−2*π**f**τ*)) 和 (|*f*| *e*^(−*π**t*²*f*²)) 的卷积。通过对两侧应用傅里叶变换

```
S_x({t,f}) = ∫_{-∞}^{+∞} X({f + α}) · e^{-π α^2 / f^2} · e^{j2π α t} dα
```

离散 Stockwell 变换（[Stockwell, 2007](#bodymatter-003.xhtml#b_9783110648195-003_ref_037)）可以写为

```
S_x({nΔ_T, mΔ_f}) = Σ_{p = 0}^{N - 1} X[{(p + m)Δ_F}] e^{-π p^2 / m^2} e^{j2pn/N}
```
