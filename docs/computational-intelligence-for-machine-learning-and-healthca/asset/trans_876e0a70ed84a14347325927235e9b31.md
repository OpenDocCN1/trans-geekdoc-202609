

# 进化算法

进化算法（`EAs`）被认为是旨在进行优化的算法类型，其可能采用源自人类大脑神经元结构的技术以及适者生存理论。基于生物遗传实践的搜索型算法可能已被适应并在不断不稳定的环境中培养，被称为 `GAs`。在较早的某个时期，`GAs` 常被用于解决控制系统优化问题。随着我们可以看到许多场景都具有机器人控制系统，编码的难度正在增加。`GAs` 为上述问题陈述提供了增强的解决方案。因此，随着所述任务难度的增加，`GA` 的难度也随之增加。与人类细胞的生命周期类似，`GAs` 可能具有基因、染色体、适应度函数、种群和突变等（[Malhotra et al., 2011](#bodymatter-008.xhtml#b_9783110648195-008_ref_035)）。生活在我们地球上的生物能够通过各自的遗传编码（`genotype`）以及以形态、生理和行为活动形式表现出的反应（`phenotype`）得到独特地说明。`genotype` 与 `phenotype` 的矛盾操作提供了两种不同的模拟生长技术。在 `genotype` 中，表示旨在生物的基因结构。任务的决策得以阐明，因为决策与生物的染色体和基因相似。遗传算子被指定用于形成染色体转换，通常在现有属中观察到，例如突变、交叉等，表示编码在解决方案中的数据结构。在 `phenotype` 中，模拟侧重于从称为 `population` 的解决方案集合中引导候选解决方案。各种改变相应行为的技术可用于创建新行为，同时仍保持父母与其子女之间基于行为的紧密关系。

1. 开始：为问题陈述产生合适的关键方案（在遗传学中是染色体的随机种群）。
2. 适应度：评估解决方案集中单独存在的每个解决方案的性能（在遗传语言中，可以称为种群中每个染色体的适应度）。
3. 新种群：通过复制以下阶段生成新种群，直至完成新种群的生成。
   1. 选择：从种群中挑选计算出的两个解决方案（在遗传学术语中我们可以说在种群中选择父染色体）根据其对应用的准确性和准确性（在遗传学中可称为适应度）。
   2. 交叉：在交叉概率过程中，合并解决方案以生成新解决方案（在遗传学中是交叉父母以形成子代）或后代。如果未进行交叉，子代将与父母完全相同。
   3. 突变：以突变可能性，将新解决方案转换（在遗传学中可以描述为在每个位点突变新后代）。
   4. 接受：将新方案（后代）置于更新的解决方案集合中（可以说是新种群）。
4. 替换：用新产生的解决方案集合（种群）占据以便进一步实施所述算法。
5. 测试：如果条件语句得到满足，则返回当前集合（种群）中最佳可能结果。
6. 循环：跳转到步骤 II。

突变和交叉的机制影响着 `GA` 的执行。

在博弈论中，有许多算法和应用是由使用 `GAs` 创建的。其他工程领域如化学或机械工程应用也采用并使用 `GA` 来开发应用，例如如果 `GA` 用于预测某些化学品或气体的性质（[Cheng et al., 2012](#bodymatter-008.xhtml#b_9783110648195-008_ref_017)）。当前在 `GA` 领域的研究和实施正在增长，涉及进化硬件的创建或通过 `GA` 对进化硬件进行构建更改。

### 8.3.2 进化编程

进化是一种优化过程，可以通过计算机模拟并用于创建工程应用。进化类似于为机器创造智能的做法。进化编程（`EP`）也是 `EA` 的一个分支，就像 `GAs` 一样（[Fogel, 1995](#bodymatter-008.xhtml#b_9783110648195-008_ref_007)）（Chiong et al., 2014）。`EP` 存在于另一种进化类别中。在 `EP` 中，重点在于能够为给定实验提出的函数的分歧，因此它可以与解释的行为相对于作业的执行量化进行有益的微调。智能行为是联合能力预测指定相关情况并将这些预测转换为通往预期结果的合适答案的必要条件。通常，环境被阐明为从固定字母表集合中选择的符号链。创建可在符号序列上工作的代码，即用于生成输出符号的环境，该符号可能有助于增强代码在通往预计从序列中出现的下一个符号的执行，并且可以明确解释的收益函数可以称为进化问题。

有限状态机（`FSM`）是一种提供机器或程序可预测行为的图形演示的机制。进化编程的实时应用之一可以是 `FSM`。`FSM` 的结果/结果集合对符号序列开放，或者用不同的术语来说，符号序列是 `FSM` 中的输入符号（输入）。对于每个父 `FSM`，在每个输入符号发送到机器时，会评估特定结果符号以及以下输入符号。上述预测的结果会根据收益函数进行评估。相关操作的适应度可能由相关函数在最终计算后计算。父机器被随机选择并相互突变以生成子机器。多种不同的技术能够用于突变父机器，即修改与状态相关的转换、删除特定状态、插入新状态，以及修改起始或初始状态以及输出符号。可靠的概率分布能够选择并导出突变。新创建的后代随后会根据提供的环境进行检查。在后续迭代中，能够提供最大收益的机器被保留为父代。上述过程重复进行，直到对序列中下一个符号的确定估计被认为必要。最优秀的机器生成此预测，并且新选择的符号被放置到合格的符号序列中，并且该过程进一步重复（[Fogel, 1999](#bodymatter-008.xhtml#b_9783110648195-008_ref_008)）。
