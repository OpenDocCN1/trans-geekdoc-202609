### C. 无监督机器学习中用于疾病预测的技术

**K-means 聚类算法，** 最初由 MacQueen 于 1967 年提出 ([Haraty et al., 2015](#bodymatter-006.xhtml#b_9783110648195-006_ref_038))，是能够解决聚类问题的无监督 ML 技术之一。每个 k 中心将数据集分类为不同的 k 个簇。预测结果取决于与簇中心的距离，因此为了获得更好的结果，它们应彼此相距较远。然后在下一步中，数据集应与最近的中心关联到所属的簇。当所有点都关联后，通过将“k”作为新的质心进行重新计算。重复这样做会生成一个循环，k 中心在每一步都会改变位置。这将一直持续到不再发生变化为止。该算法的主要目标是减少目标函数，也称为平方误差函数，其在 [方程 (6.15)](#bodymatter-006.xhtml#b_9783110648195-006_eq_015) 中给出。K-means 聚类的示例显示在 ([图 6.15](#bodymatter-006.xhtml#b_9783110648195-006_fig_015))。

![Figure 6.15: Example of K-means clustering.](graphic/converted/b_9783110648195-006_fig_015.png)

其中 `||xi – vj||` 表示 `x[i]` 和 `v[j]` 之间的欧几里得距离，`c[i]` 指第 i 个簇中的数据点，“c”指簇中心的总数。

**主成分分析 (PCA)** 是一种用于统计的无监督学习技术，用于寻找变量组之间的相互关系。它通过将一组相关变量转换为不相关变量来帮助减少数据集的维度 ([Rokhlin and Tygert, 2009](#bodymatter-006.xhtml#b_9783110648195-006_ref_084))。重复相同的过程可获得全新的变量集，这些变量简单地称为主成分或正交。PCA 也称为一般因子分析，其中回归找到最佳拟合线。PCA 的基本矩阵方程由下式给出：

(6.16)*Y* = *W*^′*X*,

其中 `X` 是具有 n 行和 p 列的输入矩阵，`Y` 是得分矩阵，`W` 是系数矩阵。PCA 方程也以线性形式给出为 p 个线性方程的集合：

(6.17)*y**i**j* = *w**l**i**x**l**j* + *w*2*i**x*2*j* + ⋯ + *w**p**i**x**p**j*

设数据集的原始维度为 `X` 和 `Y`。使用 PCA，数据集的维度减少为新的向量 `X'` 和 `Y'` 整体说明见 ([图 6.16](#bodymatter-006.xhtml#b_9783110648195-006_fig_016))。

## 6.3 机器学习技术验证的比较度量

为了评估预测率，有一些指标，例如精确度、灵敏度、特异性和准确度来评估模型的真实性。这些指标由下图所示的混淆矩阵确定 ([表 6.4](#bodymatter-006.xhtml#b_9783110648195-006_tab_004))。该模型是评估各种算法预测疾病质量的非常有用的工具 ([Linden, 2006](#bodymatter-006.xhtml#b_9783110648195-006_ref_061))。理想状态，必须包含重要数据，必须存在于矩阵的主对角线上，而其余值应标记为零或非零。

表 6.4:混淆矩阵。

|  | Class A (predicted) | Class B (predicted) |
| --- | --- | --- |
| **Class A** **(actual)** | True positive (`TP`) | False negative (`FN`) |
| --- | --- | --- |
| **Class B** **(actual)** | False positive (`FP`) | True negative (`TN`) |

True Positive (`TP`) = 当观察结果为阳性，且预测也为“正确”时。

False Negative (`FN`) = 当观察结果为阳性，但预测为“阴性”时。

`TN` = 当观察结果为阴性，且预测也为“阴性”时。

`FP` = 当观察结果为阴性，但预测为“阳性”时。

### 6.3.1 各种指标的公式如下所述

1. *Accuracy –* 它被给出为正确预测的比例，即准确的预测占所做预测总数的比例。

(6.18)${Accuracy =}\\frac{\\left( {TP + TN} \\right)}{\\left( {TP + FN + FP + TN} \\right)}$

1. *Recall or Sensitivity –* 它被认为是实际为阳性的阳性数据点的比例除以所有阳性数据点的总和。它也被称为 TPR，即真阳性率。

(6.19)${Recall =}\\frac{\\left( {TP} \\right)}{\\left( {TP + FN} \\right)}$

1. *Precision –* 它被认为是正确预测的比例除以所有预测为阳性的总和。

(6.20) ${Precision =}\\frac{\\left( {TP} \\right)}{\\left( {TP + FP} \\right)}$

1. *Specificity –* 实际为阴性的阳性数据点的比例除以所有阴性数据点的总和被称为特异性。它也被称为 FPR，即假阳性率。

(6.21)${Specificity =}\\frac{\\left( {TN} \\right)}{\\left( {FP + TN} \\right)}$
