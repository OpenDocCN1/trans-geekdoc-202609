

在这种情况下，`v(t)` 是任意当前时刻的振幅，同时 *θ* 是相位函数，而任意时刻的频率表示为

(7.4)$\\omega = \\frac{d\\theta}{dt}$ 

像这样，每一个 IMF 的瞬时振幅和频率都将利用 HHT 方法计算出来，并且 ECG 波形中固有的基本特征可以进一步获得。

### 7.2.2 Kolmogorov 复杂度

关于如何估计有限长度随机序列的可行性的想法最初由 Andrew Kolmogorov 提出。KC 用于衡量强随机信号所涉及的可预测性，因此在 ECG 信号评估中很受欢迎。它通常表示定义一个项目所需的计算资源量，即它指的是可以通过实现自限定开发方法来介绍给定序列的措施的数量。因为附着于不同类别的心跳在复杂性上有所不同，所以该指标可以很容易地将时域空间属性转换为高维空间函数。由 Lempel 和 Ziv 提出的计算 ([Lempel and Ziv, 1976](#bodymatter-007.xhtml#b_9783110648195-007_ref_013)) 使用数学上成本更低的方法来有效管理 KC。它最初通过从用户获取阈值 T，将有限振幅的时间序列转换为二进制序列。如果信号振幅大于 T，则分配的值为一，而如果小于 T，则二进制序列将被赋值为零。

该计算继续迭代，直到子序列 Q 达到最后一个分量，并且 KC (n) 在停止时提供模式 S 的难度尺度。如 [Lempel and Ziv (1976](#bodymatter-007.xhtml#b_9783110648195-007_ref_013)) 中所述，记录的熵应标准化，以便对于任何大小的序列，建议的算法执行渐近等分原理。因此，步骤直接涉及执行整个序列所需的唯一子字符串的数量及其在过程中的出现频率。KC (n) 的上限定义如下：

(7.5)${KC}\\left( n \\right)\\ = \\frac{n}{\\begin{matrix} {\\left( {1 - \\in\_{n}} \\right){log}\_{\\alpha}^{(n)}} \\\\ e \\\\ \\end{matrix}}$ 

其中 α = |Г| 表示字母表 Γ 中的字母大小，并且 *e*[*n*] → 0 当 n → ∞。因此，当模式的长度达到无穷大时，KC(n) 的值变化为：

(7.6)$b\\left( n \\right) = \\lim\\limits\_{n\\rightarrow\\infty}\\text{KC}\\left( n \\right) = \\frac{\\text{KC}\\left( n \\right)}{b\\left( n \\right)}$ 

因此，通过将 (7.5) 除以 (7.6) 得到标准 KC，如：

(7.7)${KC} = \\frac{{KC}\\left( n \\right)}{b\\left( n \\right)}$ 

由于 KC 已标准化，KC = 1 表示信号的最大变异性。

### 7.2.3 支持向量机 (SVMs)

Vapnik 的 ([Vapnik, 2000](#bodymatter-007.xhtml#b_9783110648195-007_ref_027)) 提出的 SVM 是为二进制表示而设计的，然而许多工作正在进行以有效地将其引入多类分类 ([Weston, 1998](#bodymatter-007.xhtml#b_9783110648195-007_ref_028))。通过一定的先验非线性映射，支持向量机将输入趋势映射到更高维的函数空间。之后设计一个线性决策面来识别组，因此 SVM 将二进制组的输入数据作为线性分类器在整个输入空间中进行分类。此外，SVM 能够分离输入模式的非线性映射，为此它使用核函数。这些核函数将非线性输入模式投影到更高维空间以区分彼此。SVM 方法侧重于构建超平面 `w^T x + b = 0`，其中 `w` 表示超平面参数而 `b` 表示偏置词。构建优化问题的限制是超平面与支持向量之间的间隔应最大化。通过实现目标和受限函数，将 SVM 的条件表述为二次优化问题。

与 ANN 相比，SVMs 作为比较机制要好得多。它们不太可能过拟合，获得简单的几何理解，以及提供稀疏的替代方案。还发现支持向量机具有更大的泛化能力。SVM 中用于非线性识别的核的选择纯粹取决于数据的性质，因此，选择合适的核函数以获得更高的准确性至关重要。通常采用两种方法来解决使用 SVM 对两个以上类别进行分类的挑战，一种使用多个二进制分类器，另一种使用更高级的优化问题。两种常用的技术是基于使用各种二进制分类器的“一对所有”(OAA) 和“一对一”(OAO)。OAA 方法是最古老的 MCSVM 评估执行，用于构建 `b` 个二进制 SVM 模型，其中 `b` 是类别的数量。在此策略中，SVM 通过将每个第 i 个 SVM 模型视为一个房间来看待每个第 i 个类别的数据集，然后将其他数据集视为另一个房间。OAO 方法 ([Kreßel, 1999](#bodymatter-007.xhtml#b_9783110648195-007_ref_012)) 是应用 MCSVM 的适当且有效的方法。这种技术形成 `k(k-1)/2` 个分类器，其中每一个都在两类信息上练习。OAO 技术已被发现更适合实际使用 ([Hsu et al., 2002](#bodymatter-007.xhtml#b_9783110648195-007_ref_006))，因为它使用较少的对偶问题导致它们快速停止。在本研究中，使用 OAO 策略对 MCSVM 进行分类并客观研究核函数的选择。选择 RBF 作为核被认为能产生理想的结果。

### 7.3.2 去噪

任何诊断系统的性能在很大程度上受心跳质量的影响。与心跳相关的噪声可能包含基线漂移、工频干扰、肌肉伪影、接触噪声、电外科噪声和量化噪声。必须消除这些不同种类的噪声，否则可能导致误报。此外，此步骤增强了信噪比 (SNR)，有助于准确检测心跳中的 fiducial 点。为了消除噪声，采用不同的滤波器来去除不同种类的噪声。
