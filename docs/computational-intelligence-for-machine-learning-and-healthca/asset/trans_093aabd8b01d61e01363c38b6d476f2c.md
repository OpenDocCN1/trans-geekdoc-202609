

开发的方法在个人计算机（`windows 10` 平台，`Intel core i5`（`CPU`），2.5 `GHz`，8GB `RAM`）上实现，在 `MATLAB`（版本 8.2，`R2018b`）仿真环境中，其性能通过在患者特异性评估方案下对各类心跳进行识别来估计。所提方法的识别性能报告是通过在基准 `MIT-BIH` 心律失常数据上进行实验得出的，该数据描述于 [第 3.3.1 节](#bodymatter-003.xhtml#b_9783110648195-003_s_003_s_003_s_001)。训练分类器的性能以混淆矩阵的形式报告，如 [表 3.2](#bodymatter-003.xhtml#b_9783110648195-003_tab_002) 和 [3.3](#bodymatter-003.xhtml#b_9783110648195-003_tab_003) 所示，用于患者特异性策略中每类心跳。混淆矩阵是通过将正确识别的实例和误识别的实例映射到由开发方法学识别的相应类别中而制定的（[Raj and Ray, 2018e](#bodymatter-003.xhtml#b_9783110648195-003_ref_034)）。混淆矩阵的列表示由所提方法识别的心脏事件总数。而混淆矩阵的行表示基准数据库中提供的用于参考的真实值或注释（[Moody and Mark, 2001](#bodymatter-003.xhtml#b_9783110648195-003_ref_018)）。在总计 43,112 和 89,414 个测试 ECG 实例中，81,803 个实例被开发方法学正确识别，并在等分数据集和 22 折交叉验证策略中分别报告了 86.53% 和 88.22% 的更高准确率，同时误差率分别为 13.47% 和 11.78%。在 [表 3.2](#bodymatter-003.xhtml#b_9783110648195-003_tab_002) 和 [3.3](#bodymatter-003.xhtml#b_9783110648195-003_tab_003) 中，可以观察到，与其他类别的心跳相比，类别“e”和“q”的准确率相当低，这是由于在这两个类别中用于训练的 ECG 实例数量较少。必须注意，实验是针对基准 PhysioNet 数据中这两个类别的所有可用数据进行的。

计算混淆矩阵后，性能指标如灵敏度（`S[E]`）、F 分数（`Fs`）和阳性预测值（`P[P]`）指标会为每类心跳计算。在确定这些性能指标之前，重要的是先计算特定类别心跳的其它参数，如真阳性（`T[P]`）、假阳性（`F[P]`）和假阴性（`F[N]`）指标，如 [表 3.4](#bodymatter-003.xhtml#b_9783110648195-003_tab_002) 和 [3.5](#bodymatter-003.xhtml#b_9783110648195-003_tab_003) 所示。在患者特异性方案下，[表 3.4](#bodymatter-003.xhtml#b_9783110648195-003_tab_002) 和 [3.5](#bodymatter-003.xhtml#b_9783110648195-003_tab_003) 呈现了为所有五类心跳计算的 `Fs`、`P[P]` 和 `S[E]` 参数，分别报告在等分数据集中整体为 86.53%，在 22 折交叉验证策略中为 88.22%。
