
It is one of the commonly used technique for disease prediction. Supervised ML can be represented as the search for algorithm from an external source to produce general hypotheses that are used in making predictions for future sources. The output is then presented to “training” data function and is defined by using the algorithm that uses this trained data to map the input variables with the output marked. This way, the algorithm gives the most accurate relation between input and output variable. There is no involvement of humans in supervised learning. Supervised Machine Learning Techniques has two categories as – regression and classification ([Kotsilieris et al., 2018](#bodymatter-006.xhtml#b_9783110648195-006_ref_054)). Algorithms designed to predict a number of days a person with cancer may survive is an example of regression problems. Designing algorithms to predict brain cancer is one of the examples of classification problems.
