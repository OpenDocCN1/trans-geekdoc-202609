
Industrial organizations are using large amount of data that is recognized using machine learning (ML). By collecting perceptions from these data, a more efficient work can be done by organization and can get better results than their competitors ([Amin et al., 2013](#bodymatter-005.xhtml#b_9783110648195-005_ref_003)). In various domains, ML algorithms have been used in innovative predictive models ([Anand et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_004)). Even deep learning techniques are used in various day-to-day activities such as advertisement, Google Search, and YouTube. The use of ML and deep learning techniques in the field of multidisciplinary and healthcare informatics has become the same in terms of data handling challenges and technological advertisements ([LeCun et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_029); [Russakovsky, 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_038)). The scientific field such as health or medical informatics deal with storing, retrieving, and optimal use of medical data as well as information along with a knowledge provided for problem solving and decision making. Over the last few decades, an immense development has been achieved in health technology such as advances in information gathering, communication, research, and treatments. By medical information digitization, there is an increase in patient’s data that can be related to advanced equipment-generated medical results and data provided by patients ([Hirschberg et al., 2015](#bodymatter-005.xhtml#b_9783110648195-005_ref_025)). This information revolution is a common outcome, where people face disheartened tasks of interpreting and understanding data. Handling or managing these large amount of data is not possible by simply using manual techniques and tools, and is also a very slow and tedious process. So, to understand the data there is a need of data-driven approaches from computational sciences or data science and data analytics. Critical health information can be extracted, and the medical data can be analyzed using these approaches that can help doctors and patients in making better decisions ([Hinton et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_022)).
Currently for analyzing medical data, a large investment is done in data science by academia and industry. In the coming years, an important role will be played by data science due to rapid growth in the amount of generated data in medicine. Before the deployment of artificial intelligence (AI) systems in healthcare applications, there is a need to train it through clinical activities such as diagnosis, treatment, and screening assessments that generate data ([Kotsiantis, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_028)). This is done to learn AI by similar groups of subjects and associations between outcomes and features of interest. There are two major categories of AI devices.
First one with ML technique: This will analyze structured data such as genetic, eligible provider (EP) , and imaging data and are used in medical applications that attempt to find the probability of disease outcomes ([Brazdil et al., 2003](#bodymatter-005.xhtml#b_9783110648195-005_ref_011)).
Other with natural language processing (NLP): This will extract information from medical journals and clinical notes like unstructured data that supplements and enriches the structured medical data ([Cheng et al., 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_012)). The main target of NLP procedures is to turn texts into machine-readable structured data that is further analyzed using ML techniques.

### 5.2.1 Supervised learning

Another name given to supervised learning is the predictive model, which is used for tasks such as use of other values in the dataset including prediction of one value ([Anil Mathur, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_005)). The process of predictive model training is identified as supervised learning due to a clear instruction given to predictive models about what and how they need to learn. In existence of uncertainty, the supervised ML is able to predict the evidence in existence. [Figure 5.2](#bodymatter-005.xhtml#b_9783110648195-005_fig_002) shows the diagram of speech learning. As in supervised learning algorithms, an output is taken from an input dataset and known data response. Some of the supervised ML algorithms are as follows:

![Figure 5.2: Supervised learning (Anil Mathur, 2007).](graphic/converted/b_9783110648195-005_fig_002.png)

Figure 5.2: Supervised learning ([Anil Mathur, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_005)).

* **Support vector machine (SVM):** SVM is considered as the most recent type of supervised ML technique that is closely related to classical multilayer perceptron neural networks (NNs) ([Yang et al., 2018](#bodymatter-005.xhtml#b_9783110648195-005_ref_045)). It works on the margin of objects from hyperplane that is drawn for separating two or more than two objects or data classes ([Zhang et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_046)). The expected generalization errors will be reduced by reducing the margin or creating a large distance between the instances and hyperplane separating it.
* **Naïve Bayes (NB):** During the stage of classification and training, there is a need of very less storage space in NB supervised ML method ([Zhu et al., 2009](#bodymatter-005.xhtml#b_9783110648195-005_ref_047)). That means to store the prior and conditional probabilities, there is a need of very less storage space that results in very less storing memory for training phases but the execution space should be equal to the space of training part.
* **NN:** The NN supervised ML methods or techniques are able to perform various tasks of regression and classification but only a single task is performed by an individual network ([Hiregoudar et al., 2014](#bodymatter-005.xhtml#b_9783110648195-005_ref_024)). Therefore, in most of the cases there is only single output variable in the network but there can be a number of output units while working on cases having many state classification problems.
* **Decision tree (DT):** These trees classify instances by simply sorting them on the basis of values of feature. A feature is represented as an instance to be classified by each node in a DT and an assumed value by each node is represented by each branch in it ([Gillies et al., 2012](#bodymatter-005.xhtml#b_9783110648195-005_ref_016)). The classification of instances starts from the root node, and then according to the values of feature, they are sorted out.
