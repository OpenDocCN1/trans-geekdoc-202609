

一系列研究使用了不同的方法来评估心电图信号的主要方面；其中一些已在此呈现。2001年（[Osowski et al., 2001](#bodymatter-007.xhtml#b_9783110648195-007_ref_018)），作者提取了二阶、三阶和四阶累积量来表示单个心跳，并采用混合模糊神经网络进行表征方法，而Acur（[Acır, 2005](#bodymatter-007.xhtml#b_9783110648195-007_ref_001)）则使用振幅值来构建特征集、离散傅里叶变换（`DFT`）、离散余弦变换（`DCT`）、离散小波变换（`DWT`）和自适应自回归常数。Mahmoodabadi等人（[Mahmoodabadi et al., 2005](#bodymatter-007.xhtml#b_9783110648195-007_ref_015)）主要强调使用多分辨率的小波变换来提取心电图函数。因此，这些方法中都假设了信号的平稳性，从而使其在数据处理上失去了自适应性。另一种科学数据分析工具，Hilbert-Huang变换（`HHT`）由Huang等人提出（[Huang et al., 1971](#bodymatter-007.xhtml#b_9783110648195-007_ref_009)），通过不规则和非平稳技术产生特定的物理数据表示。该方法基于经验确定的理论，通常包括两个部分：`EMD`和`HSA`。经验模态分解（`EMD`）是一种自适应技术，完全基于输入数据的信息量。`EMD`克服了经典`DWT`方法的局限性。`EMD`方法将任何输入数据分解为独特的本征模态函数（`IMFs`）（[Huang, 2005](#bodymatter-007.xhtml#b_9783110648195-007_ref_008)），这些`IMFs`用于结合时频能量规范以执行`HSA`。此外，自适应`EMD`方法仍然是选择合适的特征集以提供通用解决方案来充分揭示心电图搏动的明显选择。Kolmogorov复杂度（`KC`）是在高维复杂系统中决定动态运动的有用方法。即使心电图信息模型充当固有的非线性时空框架，它也是确定此类长序列的复杂性、熵或随机性的极其有用的工具。这是确定属于不同类别的心跳之间差异的重要度量。

人工神经网络（`ANN`）（[Yegnanarayana, 2009](#bodymatter-007.xhtml#b_9783110648195-007_ref_029)）由于其主导的自确定、随机模式识别和感知能力而通常用于识别。然而，这会产生诸如众多局部极小值和计算复杂度依赖于输入空间维度的缺点。`SVM`（[Vapnik, 1995](#bodymatter-007.xhtml#b_9783110648195-007_ref_002)）作为一种新的计算技术被执行，具有基本的几何描述和稀疏替代方案来解决此类限制。`SVM`优于`ANN`，因为ANN过拟合的可能性较小。利用经验模态分解构建了一组新的特征，以确保建议的心跳集能够更准确地分类。一旦`EMD`过程开始，它就会生成五个`IMFs`来表示特定心跳。`HHT`已被用于从每个`IMF`中提取瞬时振幅和频率，然后计算使用`IMFs`的实际信号的加权平均频率。此外，为了有效地区分不同类别的心电图搏动，对前四个`IMFs`进行受限选择的统计属性与所得`KCs`一起确定。`SVM`分类器通过为其核值选择`RBF`来进行分类。相应的分类精度根据通过获取混淆矩阵来识别测试信息集合的情况进行计算。

## 7.2 特征提取和分类算法

本节描述了用于获得心电图特征的Hilbert-Huang变换和Kolmogorov复杂度算法，而`SVM`旨在使用这些特征将这些心电图搏动区分成六种公认的类型。

### 7.2.1 Hilbert-Huang变换

`HHT`通常用于随机和不规则的时间序列信号，如统计分析方法，具有两种类型：`HSA`和`EMD`。`EMD`将复杂的时序分解为多个`IMFs`，其频率元素按递减顺序排列，从高频元素到低频元素。一个`IMF`充当`SHM`的序列。任何`IMF`都应满足以下属性：

1. 极值数与过零点数之差必须为零或一，并且
2. 由下包络描述的上包络的平均值以及由局部极小值设计的局部极大值应为零，该信号使用插值信号，如三次样条特征。

`EMD`方法改变了以下自适应方法来从初始信号中分离`IMFs`：

1. 发现信号`a(t)`的所有局部极小值和极大值，分别标记为`M[i]`，`i ∈ {1, 2, … .}`和`m[j]`，`j ∈ {1, 2, … }`。
2. 设`P(t)`为上包络，而下包络由`p(t)`表示，插值信号将被计算。
3. 因此，使用这些插值信号估计包络的局部均值`M(t) = (P(t) + p(t))/2`。
4. 从初始信号中减去均值，如`q(t) = a(t) − M(t)`。当`q(t)`不满足`IMF`特性时，避免步骤(v)和(vi)并跳至步骤(i) 用新的输入`h(t)`重复该方法，将`x(t)`替换为`x(t)`。
5. 如果`q(t)`遵循`IMF`的属性，则将其视为`IMF`，例如`z[i](t) = q(t)`，并从第一个信号中减去它，例如，`x(t) = a(t)-z[i](t)`，其中`i`是第i个`IMF`。
6. 从步骤(i)重新开始，新的贡献为`x(t)`，并且`z[i](t)`作为特定心电图的`IMF`被存储。

自适应方法通常在获得单调`IMF`时被阻止；然而，在本报告中，`EMD`算法中的筛分方法停止标准是（[Rilling et al., 2003](#bodymatter-007.xhtml#b_9783110648195-007_ref_025)）中提到的。因此，`EMD`方法产生一系列`IMFs`加上最后的剩余元素，`r(t)`。
