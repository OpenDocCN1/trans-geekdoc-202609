# C. 有监督学习技术

## `Naïve Bayes (NB)`

`Naïve Bayes (NB)` 也是有监督的 ML 技术，是一种用于分类的数值方法。它以开发贝叶斯定理的 Thomas Bayes 命名。它期望一个基本概率模型，并在决定结果的概率后允许以道德的方式绑定其不确定性。因此它用于解释该过程的预测和诊断问题（[Murphy，2006](#bodymatter-006.xhtml#b_9783110648195-006_ref_070)）。`NB` 对输入数据集中的噪声具有很强的鲁棒性。朴素贝叶斯分类器的数学表示由方程给出。

(6.1)${Posterior\\, Probability} = P\\left( {{Xi}|Y} \\right) = \\ \\frac{P\\left( {Y|Xi} \\right)P\\left( {Xi} \\right)}{P\\left( Y \\right)}$

其中 `Xi` 指代 “m” 个类别，其值分别为 `X1`、`X2`、`X3`、……、`Xm`。`P(Y|Xi)` 指后验概率，`P(Y|Xi)` 指预测概率，`P(Xi)` 代表先验概率，`P(Y)` 代表类别的预测概率。朴素贝叶斯的示例显示在 [图 6.2](#bodymatter-006.xhtml#b_9783110648195-006_fig_002)

## `Support Vector Machine (SVM)`

`Support Vector Machine (SVM)`，最著名的有监督 ML 算法于 1995 年引入，可解决回归和分类问题（[Cortes 和 Vapnik，1995](#bodymatter-006.xhtml#b_9783110648195-006_ref_020)）。该算法绘制“超平面”并在不同类别中分配数据，使得属于一个类别的所有实例都被分类到一侧，并且它们位于平面的另一侧（显示在 [图 6.3](#bodymatter-006.xhtml#b_9783110648195-006_fig_003)）。线性 SVM 分类是 SVM 分类函数所特有的，并且如果所选线包含最受压迫的部分，则会发生划分（[Maji 和 Garg，2014](#bodymatter-006.xhtml#b_9783110648195-006_ref_066)）。对于非线性情况，需要高级的核选择和数据预处理。它在医疗保健中具有重要应用，因为它可以从 MRI 扫描报告中预测各种疾病。超平面的方程如下所示。

## `Neural Network (NN)`

`Neural Network (NN)`，也称为神经元，是一种源自人类大脑的信息处理技术。该框架包含大量处理信息的小型处理器。`NN` 中使用的各种处理器作为相互连接的并行系统运行，以解决一个问题。`NN` 以其逼近能力而闻名，这就是为什么它们可以应用于几乎任何 ML 问题（[Hansen 和 Salamon，1990](#bodymatter-006.xhtml#b_9783110648195-006_ref_037)）。`NN` 的结果定义为

(6.4)$N = \\sum\_{i = 1}^{H}{v\_{i}\\sigma\\left( z\_{i} \\right)}$

其中 `v[i]` 指第 i 个权重参数，`x[i]` 指输入向量，`w[i]` 指权重参数，`σ` 指 sigmoid 函数，`b[i]` 指第 i 个单元的偏置。并且 `z[i]` = `w[i]`*`x[i]` + `b[i]` 且 `$\\sigma = \\frac{1}{1 + \\ e^{- x}}$`。`NN` 的结构呈现在 [图 6.4](#bodymatter-006.xhtml#b_9783110648195-006_fig_004)。
