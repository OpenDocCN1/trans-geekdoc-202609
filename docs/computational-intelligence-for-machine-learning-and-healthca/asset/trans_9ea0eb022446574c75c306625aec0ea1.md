## 9.3.4 Methods performed in other TDs

Principal component analysis (`PCA`) ([Pohl and Van Genderen, 1998](#bodymatter-009.xhtml#b_9783110648195-009_ref_038)), `IHS` ([Daneshvar and Ghassemian, 2010](#bodymatter-009.xhtml#b_9783110648195-009_ref_007)), gradient domain ([Wang et al., 2004](#bodymatter-009.xhtml#b_9783110648195-009_ref_056)), independent component analysis ([Zhou and Prasad, 2017](#bodymatter-009.xhtml#b_9783110648195-009_ref_071)), fuzzy theory ([Jiang et al., 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_013)), hue saturation value ([Lu et al., 2017](#bodymatter-009.xhtml#b_9783110648195-009_ref_031)), `IHS` transform ([Majumdar and Patil, 2013](#bodymatter-009.xhtml#b_9783110648195-009_ref_033)), `SD` (non transforms) ([Jiang et al., 2017](#bodymatter-009.xhtml#b_9783110648195-009_ref_014); [Kazemi and Moghaddam, 2003](#bodymatter-009.xhtml#b_9783110648195-009_ref_018); [Zhang et al., 2011](#bodymatter-009.xhtml#b_9783110648195-009_ref_065)), and Gram-Schmidt matting decomposition (Li et al., 2013) are major transform methods used in this domain.

`PCA` is a mathematical mechanism that reduces the multidimensional data sets to smaller analytical sizes. The weight factor is determined by this technique and added in an input picture at each pixel position and takes an average pixel value for results for the same place. In the field of remote sensing, panchromatic images with high resolution are fused with multispectral images with low resolution, which leads to the “pansharpening” problem ([Loncan et al., 2015](#bodymatter-009.xhtml#b_9783110648195-009_ref_030)). Component substitution ([Rahmani et al. 2010](#bodymatter-009.xhtml#b_9783110648195-009_ref_040)), spatial context-based weighted average ([Liu et al., 2015](#bodymatter-009.xhtml#b_9783110648195-009_ref_029); [Zhang et al., 2014](#bodymatter-009.xhtml#b_9783110648195-009_ref_069); [Li and Kang, 2012](#bodymatter-009.xhtml#b_9783110648195-009_ref_025)), model-based method ([Algorithm 2010](#bodymatter-009.xhtml#b_9783110648195-009_ref_001)), machine learning-based weighted average ([Li et al., 2002](#bodymatter-009.xhtml#b_9783110648195-009_ref_027); [Song et al., 2006](#bodymatter-009.xhtml#b_9783110648195-009_ref_049)), and region-based activity level measurement ([Li and Yang, 2008](#bodymatter-009.xhtml#b_9783110648195-009_ref_028)) are fusion strategies.

Decisions are made by people based on laws. Fuzzy machines that always imitate people conduct work in the same manner. The choice and means of choice are nevertheless substituted by uncertain sets of decisions, while the guidelines are replaced by uncertain laws. The Fuzzy laws also work on a number of if–then declarations. If X then A, for example, if Y then B, if A and B all are X and Y sets. Fuzzy rules describe fluid patches, which in the fluid logic are the main concept.

## 9.4 Quantitative analysis metric

Qualitative analysis (i.e., visual analysis) alone is not adequate to check the efficiency of fusion algorithm rather certain quantitative analysis like entropy ([Sreeja and Hariharan, 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_051)), mean, standard deviation ([Manchanda and Sharma, 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_034)), average gradient ([Gosain and Singh, 2015](#bodymatter-009.xhtml#b_9783110648195-009_ref_009)), and `PSNR` ([Sreeja and Hariharan, 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_051)) are required ([Tsai et al., 2008](#bodymatter-009.xhtml#b_9783110648195-009_ref_053)). Based on the grading of statistical evaluation metric, the performance of algorithms can be judged.

The average amount of information conveyed in an image is referred to as entropy ([Sreeja and Hariharan, 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_051)). The proximity of the entropy values illustrates better fusion. If in case reference image (ground truth) is unavailable, desirable values for entropy are higher for better fusion results. Entropy may be defined as [eq. (9.1)](#bodymatter-009.xhtml#b_9783110648195-009_eq_001).

(9.1) $E\_{I} = - \\sum\\limits\_{j = 1}^{2^{L} - 1}p\\left( s\_{j} \\right){lo}g\_{2}\\left( {p\\left( s\_{j} \\right)} \\right)\\ $ 

where `L` is number of gray levels, `p(s[j])` is the probability of occurrence of gray level `s[j]` in an image `I` of size `M × N`.

The second metric is mean, it measures the central tendency of the given data, and dispersion around mean is referred as standard deviation ([Manchanda and Sharma, 2018](#bodymatter-009.xhtml#b_9783110648195-009_ref_034)). A higher value of mean and standard deviation is expected for fused image in order to have better fusion results. For an image `I` of size `M × N,` mean and standard deviation are given by equations, where `μ[I]` defines mean and `σ[I]` symbolize standard deviation and

(9.2)$\\mu\_{I} = \\sum\\limits\_{i = 1}^{M}\\sum\\limits\_{j = 1}^{N}I\\left( {i,j} \\right)\\ $ (9.3)$\\sigma\_{I} = \\left\\lbrack {\\frac{1}{MN - 1}\\sum\\limits\_{i = 1}^{M}\\sum\\limits\_{j = 1}^{N}{(I\\left( {i,j} \\right) - \\mu\_{I})}^{2}} \\right\\rbrack^{\\frac{1}{2}}$ 

For image `I`, `Δ[I,x]` is the gradient in horizontal direction and `Δ[I,y]` is the gradient in vertical direction. The average gradient denoted by `Δ[I]` is given by [eq. (9.4)](#bodymatter-009.xhtml#b_9783110648195-009_eq_004):

(9.4)$\\Delta\_{I} = \\frac{1}{MN}\\sum\\limits\_{i = 1}^{M}\\sum\\limits\_{j = 1}^{N}\\frac{{(\\Delta\_{I,x}^{2} - \\Delta\_{I,y}^{2})}^{\\frac{1}{2}}}{2}\\ $ 

The average gradient for reference and resultant image should be closer for the better fused results. If in case reference image is not available, higher value of average gradient is expected for better fusion results. `PSNR` is peak signal-to-noise ratio and it is a most important parameter in image quality analysis. It indicates similarity between two images. The `PSNR` between fused image `I[F]` and ground truth `I[G]`, each of size `M × N`, is calculated as in [eq. (9.5)](#bodymatter-009.xhtml#b_9783110648195-009_eq_005):

Higher `PSNR` value results in more similarity between two images.
