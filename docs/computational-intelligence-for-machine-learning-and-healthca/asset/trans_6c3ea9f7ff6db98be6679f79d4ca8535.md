### 13.5.2.3 其他方法的比较

`NNA` 有效且准确地最大化了对象阈值分割的模糊熵。所提出的算法针对自然对象的算法有效性进行了测试。一些优化技术如 `DE`、`PSO` 和 `FA` 与模糊熵一起比较了所提出方法的結果。与 `DE`、`PSO` 和 `FA` 相比，所提出的算法具有更高/最大适应度值。使用所提出的算法，`PSNR` 值显示出高于 `DE`、`PSO` 和 `FA` 的值，因此使用所提出的方法可以获得更好的图像质量。`NNA` 方案用于有效地计算阈值水平。根据文献规则，引入了 `NNA`、`DE`、`PSO` 和 `FA` 的参数建立。

#### 13.5.2.3.1 稳定性分析

由于优化过程中涉及随机性，结果本质上是不可预测的，并且每次运行的结果并不不同。通过多次运行和不同的初始值来验证算法的有效性。如果在相同条件下其结果是合适的，则认为算法是鲁棒的。因此，我们运行了相同的算法 30 次，并发现结果为 30 次独立运行，我们考虑了结果。通过均值和标准差来评估算法的一致性。

#### 13.5.2.3.2 PSNR

作为以分贝为单位的两个对象之间视觉区分度量，`PSNR` 表示图像限制与对象生成之间的差异。较低的 `PSNR` 值表示更好的图像质量或图像阈值恢复。

```
(13.31) ${PSNR} = \\ 10\\log\_{10}\\left( \\frac{255^{2}}{MSE} \\right)\\,\\,\\,\\left( {dB} \\right)
```

## 13.6 结论与未来工作

从上述讨论可以看出，基于多级模糊熵的分割阈值技术比基于香农的技术表现明显更好。基于熵的模糊阈值技术提供了足够的视觉比较结果。通过在视觉和数值分析方面与香农熵进行比较，将评估模糊策略的成功。这些说法肯定是由最先进的特征相似性指数测量 `FSIM` 和复小波结构相似性指数测量 `CW-SSIM` 图像质量评估指标创建的。`NNA` 无疑为该算法增加了速度和精度。然而，为了获得更好的性能，可以使用更好的自适应 `DE` 或其他未经证实的 `NNA` 变体。此外，为了更好地分离分割区域，可以评估几个额外的隶属函数。未来，分割算法的能力可以通过更多的图像质量指标来展示。最后但并非最不重要的一点是，为了获得更好的结果，可以引入基于 2D 直方图的方法。通过改进算法方法，未来将提高 `NNA` 的收敛时间和性能。
