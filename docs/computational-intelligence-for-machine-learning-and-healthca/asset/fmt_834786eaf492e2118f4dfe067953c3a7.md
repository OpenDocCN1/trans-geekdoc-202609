
To detect arrhythmia in heart patients using ECG signals, a novel three-layer genetic algorithm-based classifier is built. The developed method combines the advantages of ensemble learning, deep learning, and evolutionary computation (EC). The experiments conducted by using the developed method have shown good classifier accuracy along with better recognition sensitivity in detecting the disease ([Pławiak and Acharya, 2019](#bodymatter-015.xhtml#b_9783110648195-015_ref_036)). The parallel processes of FS along with parameter optimization of the artificial neural network have been designed using the GA for automatic diagnosis of breast cancer in women. The proposed method uses three types of back-propagation techniques for the effective diagnosis of the disease. The resilient back-propagation approaches of the proposed algorithm have produced the best results experimentally ([Ahmad F and Isa, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_002)). Mutation operation is applied aggressively in the GA to perform FS to design the brain–computer interface (BCI). The proposed FS is compared with the existing FS techniques that apply to BCI and the method is found to be superior ([Rejer, 2015](#bodymatter-015.xhtml#b_9783110648195-015_ref_039)). A multi-objective system is proposed for intrusion detection where the problem of imbalanced classification is handled effectively. Method of special domination and predefined search based on multiple targets are the two strategies used. The work consists of bias-selection and fit-selection processes to handle the imbalanced data set to perform efficient FS ([Zhu et al., 2017](#bodymatter-015.xhtml#b_9783110648195-015_ref_050)). A rough set theory based FS is performed using a group incremental approach where the genetic algorithm is used for selecting optimal features. The objective is to perform FS dynamically by using the `reduct` set that is obtained in the previous generation in the optimization process ([Das et al., 2018](#bodymatter-015.xhtml#b_9783110648195-015_ref_011)). A tree-based embedded approach can be used for feature construction and selecting the features implicitly. The proposed work is used for high-dimensional data classification. Experimental investigations have been performed on seven high-dimensional gene expression problems and analyses of overfitting occurrence also have been handled (Tran et al., 2016, March). In the gene selection process to identify cancer, k-means clustering is used for redundancy removal and random forest is used for ranking the genes inside every cluster. The filtered genes are used in the classification process where eight benchmark classification methods are used. FS, which is an NP-hard problem, is performed on liver and kidney datasets to be used in the intelligent diagnosis system of diseases. Two modified PSO algorithms named velocity bounded and improved velocity bounded PSO algorithms are proposed to be used in the diagnosis system. To help pathologists in the diagnosis of breast cancer, the proposed system performs bandwidth selection and other feature subset selection for the estimation of kernel density in the decision making process. Ant activities have shown its importance in resolving several problems based on combinatorial optimization. Several filter-based iterations help in finding the optimal subset of features. ## 15.9 Application of filter-based and wrapper-based PSO for health care informatics

### 15.9.1 Filter-based feature selection using a variant of PSO with digital pheromone concept

As the basic PSO method usually suffers from the local optima problem, the proposed variant of PSO uses digital pheromone as a third important component in the velocity update. This proposed methodology is executed as a filter-based model for the FS process ([Ramaswamy and Mukherjee, 2019](#bodymatter-015.xhtml#b_9783110648195-015_ref_037)). The decrease in the computation time and increase in the classifier accuracy of the proposed FFS-PSODP have motivated to conduct the experimental results on four benchmark datasets taken from the UCI machine learning repository ([https://archive.ics.uci.edu/ml/datasets.php](https://archive.ics.uci.edu/ml/datasets.php)). New fitness functions were designed for handling imbalanced datasets. The performance analysis for diabetes disease in balanced data set and hepatitis disease in imbalanced data set are handled in the proposed work and shared as obtained below. The existing filter-based FS techniques that are considered for comparison are pair-wise correlation, Eigen-centrality, relief, and PSO. The proposed work has used the FFS-PSODP algorithm and has performed comparatively better in achieving good accuracy in possible minimum time.
