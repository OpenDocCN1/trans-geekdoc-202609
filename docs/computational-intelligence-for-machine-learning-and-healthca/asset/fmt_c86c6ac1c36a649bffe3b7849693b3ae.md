
The reduction of the modification factor `β[N N A]` is made to enhance the exploitation of the algorithm as the iterations increase by allowing the algorithm to search for the optimum solution near to the target solution especially at the final iterations.

In comparison with `ANNs`, the transfer function operator is used in `NNA` to produce solutions of better quality. The operator of the transfer function `TF` is defined as follows:

```
X[i]^*(k+1) = TF(X[i](k+1)) = X[i](k+1) + 2.rand.(X^Target(k)-X[i](k+1)) (13.30) i = 1, 2, 3, …, N[pop]
```
