
**Bayesian network (BN):** It is a graphical model for relationships of probability among various sets of features or any other variable. It is considered as a very famous representative of structured ML algorithms ([Shin et al., 2010](#bodymatter-005.xhtml#b_9783110648195-005_ref_040)). As compared to NN or DT supervised ML methods, a most important or different feature of BN is that it considers the possibility of taking prior information about any problem.

### 5.2.2 Unsupervised learning

Its another name is a descriptive model that is used for tasks that will benefit from understanding summarized data in interesting and new ways. With predictive models, a target of interest is predictive; on the other hand, any feature is a descriptive model that will be more important than any other single feature. Unsupervised learning is the process used for training a descriptive model due to no involvement of learning goal for distinguishing the data and gets few structures ([Kaelbling, 1996](#bodymatter-005.xhtml#b_9783110648195-005_ref_026)). It is mainly used on transactional data. Some of the unsupervised ML algorithms are as follows:

* `k`-Means clustering: This is a type of unsupervised ML technique that creates groups automatically on initiation of it. Then the items having same characteristics come under the same cluster ([Li, 2016](#bodymatter-005.xhtml#b_9783110648195-005_ref_030)). As it creates `k` distinct clusters according to the input data given to it, this algorithm is known as `k`-means. In any particular cluster, its mean values are the center of that cluster.
* Fuzzy `c`-means
* Hidden Markov model

They are mainly used to segment text topics and identify data outliers.

**Semisupervised learning:** It can be used in place of supervised learning. The only difference is to train both labeled and unlabeled data used in semisupervised learning. This type of learning is mostly used in prediction, regression, and classification. And in cases of high labeling cost for a fully labeled training process, a semisupervised learning gives beneficial results ([Thompson, 2007](#bodymatter-005.xhtml#b_9783110648195-005_ref_042)). One of the examples in using semisupervised ML algorithm is in recognizing the face of persons on a web.

**Reinforcement learning (RL):** In this case, a machine is trained to have same decisions in business requirement with the main motive to have maximum efficiency. In it there is less participation of human expertise that results in saving of time. It also helps in discovering the trial and error through algorithms that help in having best rewards. It is most often used in gaming, navigation, and robotics or for decision making. Some of the examples of RL ML algorithms are:

* **Multitask learning:** The main motive of multitask learning technique of RL is to help learners so that it can perform in a better way. The procedure of solving any problem is remembered by multitask learning algorithms that help to reach a particular conclusion. After that these steps are used by algorithms that help in finding the similar solution as found while working earlier on the same task or problem. This help is also known as an inductive transfer mechanism in which learners share their experience with each other that helps them all to learn concurrently in a faster way rather than individually ([Darcy et al., 2016](#bodymatter-005.xhtml#b_9783110648195-005_ref_014)).
* **Ensemble learning:** When a number of individual learners are combined, it is known as ensemble learning. In this case, an individual learner can be a DT, NB, NN, and so on. It has been observed that a better result can be achieved by a collection of learners rather than individual learners ([Murff et al., 2011](#bodymatter-005.xhtml#b_9783110648195-005_ref_036)).
* Q-learning
* R-learning
* TD learning

### 5.3.1 Steps to apply ML to data

Below are some of the steps for applying ML task:

* Data collection
* Exploring and preparing the data
* Training a model on the data
* Evaluating performance of model
* Improving performance of model
* **Data collection:** This is the first block of [Figure 5.3](#bodymatter-005.xhtml#b_9783110648195-005_fig_003). For analysis purpose, data needs to be gathered in an electronic format irrespective of whether it is written on paper, stored in SQL database, and recorded in spreadsheets and text files. * **Exploring and preparing the data:** On the basis of used data quality, an ML project quality is measured. In this step of ML process, there is more involvement of humans. In ML, 80% of effort is dedicated to data, and data exploration is the time spent on learning about data.
