## 6.1 梯度提升简介

梯度提升是一种稳健的集成机器学习模型，它按顺序训练一系列弱学习器，最终生成一个更准确的模型 [[1]](#9789815136982-C6.html#r1)[[2]](#9789815136982-C6.html#r2)。弱学习器通常是一个相当简单的决策树，是一种基础的机器学习模型，预测准确率较低，但仍优于随机猜测。如[图 6.1](#9789815136982-C6.html#f6.1)所示，随着每棵新决策树的加入并与所有先前的决策树集成，集成模型的预测误差逐渐减小 [[3]](#9789815136982-C6.html#r3)。梯度提升是一种高效且准确的算法，已被应用于工程、医疗、自然语言处理和计算机视觉等众多领域的回归和分类问题。梯度提升的一个关键优势在于其能够利用多个弱学习器的集体知识，最终生成一个更稳健、更准确的模型。这是通过迭代地关注前几个弱学习器未能准确预测的区域，并随后改进这些区域来实现的。因此，梯度提升已成为解决复杂问题并在各种应用中实现最先进性能的热门选择，在某些情况下甚至优于其他集成方法（如随机森林）。其通用性和适应性使梯度提升成为机器学习从业者和研究人员工具箱中的宝贵工具。

## 6.2 用于回归的梯度提升数学原理

梯度提升的基本思想是通过拟合弱学习器来逼应损失函数关于前一个模型预测值的残差或梯度，从而迭代地改进整体模型。这一过程可视为一种数值优化技术，旨在最小化训练数据集上的损失函数。算法首先用一个常数值初始化模型。算法的主循环按预定的迭代次数（`M`）进行迭代，每次迭代执行以下四个步骤。首先，通过计算损失函数关于当前模型预测值的负梯度来得到伪残差。这些伪残差代表了模型为最小化损失函数所需移动的方向。其次，将一个弱学习器（通常是决策树）拟合到伪残差上。该树通过将输入特征空间划分为不同区域，并学习每个区域的最优值来最小化损失函数而构建。第三，通过最小化关于前一个模型预测值加上新弱学习器输出的损失函数，计算每个区域的最优值（记为 `ã`）。第四，通过将新弱学习器的加权输出添加到前一个模型的预测值中来更新模型；此处的权重（记为 `á`）是一个收缩参数，用于控制梯度提升的学习率。最后，重复这四个步骤 `M` 次迭代，最终模型是弱学习器的组合，能够通过集体最小化损失函数来做出准确预测。连同通用伪代码 [[4]](#9789815136982-C6.html#r4)，用于回归的梯度提升数学原理见表 6.1。本章通用的符号包括：`xi` 表示第 `i` 个样本的特征值（来自训练数据集共 `n` 个样本）；`yi` 和 `Fxi` 分别表示第 `i` 个样本的真实输出和预测输出；`m` 和 `M` 分别表示决策树的索引和梯度提升模型中决策树的总数；`rim` 表示第 `m` 棵决策树中第 `i` 个样本的残差；`Rjm` 表示第 `m` 棵决策树的第 `j` 个叶节点；`á` 指构建模型时的学习率。
