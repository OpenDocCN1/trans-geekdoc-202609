## 2.1. 线性回归简介

线性回归是一种监督机器学习算法，旨在确定因变量与一个或多个自变量之间的最佳拟合线性关系。它通常执行回归任务。它是许多机器学习应用中最简单、理解最透彻、最流行的算法之一 [[1](#9789815136982-C2.html#r1), [2](#9789815136982-C2.html#r2)]。它可用于预测连续数值变量的值，例如薪资、销售收入、股息收益率、温室气体排放量和房价等。

尽管线性回归很简单，但它仍然是机器学习领域的一个强大工具，为理解变量之间潜在的输入-输出关系提供了坚实基础。它是该领域初学者的绝佳切入点，提供了一种直观且可解释的建模方法。此外，线性回归还可以作为评估更复杂算法性能的基准，使从业者能够衡量其所选模型的有效性。虽然线性回归并不总是针对每种情况最先进或最精确的方法，但其易用性、可解释性和通用性使其在各种实际应用和行业中继续保持着宝贵的资产地位。

线性回归有几个基本假设 [[3](#9789815136982-C2.html#r3), [4](#9789815136982-C2.html#r4)]。首先，假设因变量与自变量呈线性相关。其次，当存在多个自变量时，自变量之间不应存在相关性（即无多重共线性）。第三，真实值与线性回归模型预测值之间的误差应近似服从正态分布，大多数误差接近 0。第四，误差的分布（即误差的方差）应沿因变量的值保持恒定。这在技术上称为同方差性，可通过绘制误差与因变量的散点图来检验。

## 2.2. 线性回归的数学原理

线性回归的数学原理始于一个简单的线性方程，如公式 (2.1) 和 (图 **2.1**) 所示，其中只有一个自变量 `X` 和一个因变量 `Y`。

```
Y = b + wX
```

![Fig. (2.1)](Images/9789815136982-C2-F1.jpg)

简单线性方程 Y=b+wX 的图示。

变量 `X` 有一个关联的系数 `w`，它常与以下术语交替使用：*权重*、*斜率* 或 *梯度*。在机器学习语境下，它最常被称为权重。

同理，`b` 代表与 *Y* 轴的截距，在机器学习中常称为 *偏置*。自变量 `X` 通常称为 *输入*，可与以下术语交替使用：*输入特征*、*属性*、*特征*、*字段* 和 *列*。因变量 `Y` 通常称为 *输出*、*目标、类别* 和 *标签*。

在现实中，我们往往不止有一个自变量，因此公式 (2.1) 必须更新为通用项公式 (2.2) 以适应这种情况。

```
Y = b + Σ(wj * Xj) for j=1 to n
```

其中，

- `Y` 是因变量
- `b` 是偏置
- `n` 是输入特征的数量
- `wj` 是第 j 个特征的权重
- `Xj` 是第 j 个特征的输入值

线性回归的目标是找到一个最佳拟合线性方程模型，该模型以公式 (2.2) 的形式映射输入 `X` 和输出 `Y` 之间的关系，并具有最优的权重和偏置，从而在已知真实输出 `Y` 值与模型预测输出 `Y` 值之间产生最小的误差（在机器学习中同义称为损失）。

让我们用小写 `xi` 表示第 i 个样本（来自训练数据集共 `m` 行样本）的特征值，则 `xij` 将是第 i 个样本中第 j 个特征（共 `n` 个输入特征）的值，如 [图 (**2.2**)](#9789815136982-C2.html#f2.2) 所示。小写 `yi` 用于表示第 i 个样本的已知输出值（即真实输出值），`y^i` 用于表示线性方程模型对应的预测输出值。公式 (2.2) 随后更新为公式 (2.3)。

```
y^i = b + Σ(wj * xij) for j=1 to n
```

其中，

- `i ∈ {1, ..., m}` `m` 是训练样本数量
- `xij` 是第 i 个样本处第 j 个特征的值
- `b` 是偏置
