## 4.3. 逻辑回归的数值示例

假设我们有一个如表 **[1](#9789815136982-C4.html#t1)** 所示的小型训练数据集，仅包含 3 个样本（*即* `m=3`），拥有两个特征，分别为房屋面积（平方英尺，缩写为 `size_sqft`）和房屋卧室总数（缩写为 `num_bedrooms`），以及一个关于房屋在房地产市场上是否容易出售（缩写为 `is_easy_sell`）的输出。该输出为二分类，仅有两个可能的值/类别/标签（*即* `0` 和 `1`），其中 `0` 表示否（不容易出售），`1` 表示是（容易出售）。换句话说，对于本示例，`X` 为 `size_sqft` 和 `num_bedrooms`，`Y` 为 `is_easy_sell`。我们的任务是构建一个将 `X` 映射到 `Y` 的逻辑回归模型。

**表 1：用于逻辑回归的小型数据集。**

| **size_sqft** | **num_bedrooms** | **is_easy_sell** |
| --- | --- | --- |
| 1600 | 5 | 1 |
| 1200 | 4 | 1 |
| 740 | 2 | 0 |

接下来，使用最大-最小归一化（如公式 4.15 所示）将特征值（*即* `size_sqft` 和 `num_bedrooms` 列的值）归一化，使其处于 0 到 1 的同一尺度上。若不进行归一化，某些特征可能会主导机器学习过程。

![](Images/9789815136982-C4-Eq15.jpg)

`size_sqft` 的最大值和最小值分别为 `1600` 和 `740`。同理，`num_bedrooms` 的最大值和最小值分别为 `5` 和 `2`。输出标签（*即* `is_easy_sell`）保持原样，不进行任何归一化。对特征进行最大-最小归一化后的小型数据集如表 **[2](#9789815136982-C4.html#t2)** 所示。

**表 2：逻辑回归最大-最小归一化后的小型数据集。**

| **size_sqft** | **num_bedrooms** | **is_easy_sell** |
| --- | --- | --- |
| 1 | 1 | 1 |
| 0.5349 | 0.6667 | 1 |
| 0 | 0 | 0 |

现在，让我们开始机器学习过程以构建逻辑回归模型。

初始化偏置：
```
b = 0
```

初始化特征 `size_sqft` 的权重：
```
w1 = 0
```

初始化特征 `num_bedrooms` 的权重：
```
w2 = 0
```

设置学习率：
```
α = 0.1
```

请注意，为便于书写和表达，除非另有说明，以下所有 `xij` 默认均指归一化后的 `xij`。
