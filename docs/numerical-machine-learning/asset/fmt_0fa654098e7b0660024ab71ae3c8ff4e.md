## Model Formulation

Looking back, we used the following expression in Step 2(d) when `m=2`:

`F2(xi) = F1(xi) + á(ãj2 | xi ∈ Rj2)`

Do not forget that we applied this expression in Step 2(d) when `m=1`:

`F1(xi) = F0(xi) + á(ãj1 | xi ∈ Rj1)`

If concatenating them together, we can get this expression:

`F2(xi) = F0(xi) + á(ãj1 | xi ∈ Rj1) + á(ãj2 | xi ∈ Rj2)`

This will be our trained gradient boosting regression model for this simple example!

Here, `(ãj1 | xi ∈ Rj1)` and `(ãj2 | xi ∈ Rj2)` are the values we can find from the first and second decision trees, respectively. `á` is the learning rate, and we set it as `0.5` in this example.

# 6.4. MATHEMATICS OF GRADIENT BOOSTING FOR CLASSIFICATION

To understand the gradient boosting for classification, we must first review two fundamental statistics terminologies, namely, probability and odds. Probability (`P`) represents the chance that an event occurs. Odds is just an expression of relative probability and is defined as the ratio of the probability of an event occurring to the probability of an event not occurring (*i.e*., `odds = P / (1 - P)`). The loss function employed in gradient boosting classification appears somewhat peculiar at first glance. It essentially starts from the loss function we have seen in Chapter 4 for logistic regression, that is, the cross-entropy loss function!

`L = -yi log(Pi) + (1 - yi) log(1 - Pi)`

Here, `Pi` is the predicted probability (∈ [0, 1]) for the `i`th sample and `yi` is the true label (*e.g.*, 0 or 1) for the `i`th sample.

Then, a series of transformations of the cross-entropy loss function are performed:

We set `Fxi = log(oddsi)` to represent the predicted value for the `i`th sample before it is mapped to the predicted probability by the previously derived equation: `P = 1 / (1 + e^(-log(odds))) = e^(log(odds)) / (1 + e^(log(odds)))`

Note: Does this `P = 1 / (1 + e^(-log(odds)))` remind you of the sigmoid function utilized in Chapter 4 for logistic regression?

Finally, replace all the `log(oddsi)` with `Fxi` in the loss function:

`L = -yi F(xi) + log(1 + e^(F(xi)))`

So, `L` has become a function of `yi` and `Fxi`:

`L(yi, F(xi)) = -yi F(xi) + log(1 + e^(F(xi)))`

Here, `yi` represents the true output (*e.g.*, 0 or 1); and `Fxi` represents the predicted value (this is not the predicted probability in the range of 0 to 1).
