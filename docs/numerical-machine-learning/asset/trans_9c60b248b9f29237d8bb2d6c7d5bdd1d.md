注意 `x1→` 和 `x2→` 是 2 个负样本；`x3→` 和 `x4→` 是 2 个正样本。

```
∑i αi yi K(xi→, u→) + b = 1  if u→ is +ve support vector
∑i αi yi K(xi→, u→) + b = -1 if u→ is -ve support vector
∑i αi yi = 0
```

现在，令 `âi = αi yi`，然后展开：

```
â1 K(x1→, x1→) + â2 K(x2→, x1→) + â3 K(x3→, x1→) + â4 K(x4→, x1→) + b = -1  当 u→ = x1→
â1 K(x1→, x2→) + â2 K(x2→, x2→) + â3 K(x3→, x2→) + â4 K(x4→, x2→) + b = -1  当 u→ = x2→
â1 K(x1→, x3→) + â2 K(x2→, x3→) + â3 K(x3→, x3→) + â4 K(x4→, x3→) + b = 1   当 u→ = x3→
â1 K(x1→, x4→) + â2 K(x2→, x4→) + â3 K(x3→, x4→) + â4 K(x4→, x4→) + b = 1   当 u→ = x4→
â1 + â2 + â3 + â4 = 0
```

**RBF 核函数：**

```
K(xi→, xj→) = e^(-γ ||xi→ - xj→||^2)
```

令 `γ = 0.2`，则：

```
K(xi→, xj→) = e^(-0.2 ||xi→ - xj→||^2)
```

所以，

```
K(x1→, x1→) = e^(-0.2 ||(1, 2) - (1, 2)||^2) = e^(-0.2 * 0) = e^0 = 1
K(x2→, x1→) = e^(-0.2 ||(5, 5) - (1, 2)||^2) = e^(-0.2 * 25) = e^(-5)
K(x3→, x1→) = e^(-0.2 ||(2, 1) - (1, 2)||^2) = e^(-0.2 * 2) = e^(-0.4)
K(x4→, x1→) = e^(-0.2 ||(4, 4) - (1, 2)||^2) = e^(-0.2 * 13) = e^(-2.6)

K(x1→, x2→) = e^(-0.2 ||(1, 2) - (5, 5)||^2) = e^(-5)
K(x2→, x2→) = e^(-0.2 ||(5, 5) - (5, 5)||^2) = 1
K(x3→, x2→) = e^(-0.2 ||(2, 1) - (5, 5)||^2) = e^(-5)
K(x4→, x2→) = e^(-0.2 ||(4, 4) - (5, 5)||^2) = e^(-0.4)

K(x1→, x3→) = e^(-0.2 ||(1, 2) - (2, 1)||^2) = e^(-0.4)
K(x2→, x3→) = e^(-0.2 ||(5, 5) - (2, 1)||^2) = e^(-5)
K(x3→, x3→) = e^(-0.2 ||(2, 1) - (2, 1)||^2) = 1
K(x4→, x3→) = e^(-0.2 ||(4, 4) - (2, 1)||^2) = e^(-2.6)

K(x1→, x4→) = e^(-0.2 ||(1, 2) - (4, 4)||^2) = e^(-2.6)
K(x2→, x4→) = e^(-0.2 ||(5, 5) - (4, 4)||^2) = e^(-0.4)
K(x3→, x4→) = e^(-0.2 ||(2, 1) - (4, 4)||^2) = e^(-2.6)
K(x4→, x4→) = e^(-0.2 ||(4, 4) - (4, 4)||^2) = 1
```

然后，将数值代入方程：

```
â1 + e^(-5)â2 + e^(-0.4)â3 + e^(-2.6)â4 + b = -1
e^(-5)â1 + â2 + e^(-5)â3 + e^(-0.4)â4 + b = -1
e^(-0.4)â1 + e^(-5)â2 + â3 + e^(-2.6)â4 + b = 1
e^(-2.6)â1 + e^(-0.4)â2 + e^(-2.6)â3 + â4 + b = 1
â1 + â2 + â3 + â4 = 0
```

求解该线性方程组得到唯一解如下：

```
â1 = -3, â2 = -3, â3 = 3, â4 = 3, b = -0.1
```

**超平面：** `∑i αi yi K(xi→, u→) + b = 0`

```
∴ â1 K(x1→, u→) + â2 K(x2→, u→) + â3 K(x3→, u→) + â4 K(x4→, u→) + b = 0
```

我们已求得 `â1, â2, â3, â4, b`，且 `x1→, x2→, x3→, x4→` 已知。RBF 核函数 `K(xi→, xj→) = e^(-0.2 ||xi→ - xj→||^2)` 也已知。

因此，超平面本质上是满足以下方程的那些 `u→`：

```
-3 K(x1→, u→) - 3 K(x2→, u→) + 3 K(x3→, u→) + 3 K(x4→, u→) - 0.1 = 0
```

两边同时除以 3：

```
-K(x1→, u→) - K(x2→, u→) + K(x3→, u→) + K(x4→, u→) - 0.033 = 0
```

因此，能以最简形式表示超平面的 `âi` 和 `b` 值为：

```
â1 = -1
â2 = -1
â3 = 1
â4 = 1
b = -0.033
```

设向量 `u→` 在二维空间中表示为 `(u1, u2)`，其中 `u1` 是水平轴上的标量/大小，`u2` 是垂直轴上的标量/大小。

```
K(x1→, u→) = e^(-0.2 ||(1, 2) - (u1, u2)||^2) = e^(-0.2 [(1-u1)^2 + (2-u2)^2])
K(x2→, u→) = e^(-0.2 ||(5, 5) - (u1, u2)||^2) = e^(-0.2 [(5-u1)^2 + (5-u2)^2])
K(x3→, u→) = e^(-0.2 ||(2, 1) - (u1, u2)||^2) = e^(-0.2 [(2-u1)^2 + (1-u2)^2])
K(x4→, u→) = e^(-0.2 ||(4, 4) - (u1, u2)||^2) = e^(-0.2 [(4-u1)^2 + (4-u2)^2])
```

然后，

```
-e^(-0.2 [(1-u1)^2 + (2-u2)^2]) - e^(-0.2 [(5-u1)^2 + (5-u2)^2]) + e^(-0.2 [(2-u1)^2 + (1-u2)^2]) + e^(-0.2 [(4-u1)^2 + (4-u2)^2]) - 0.033 = 0
```

该方程的绘图如 **图 7.13** 所示，为分隔正负类的曲线。

## 8.1. 聚类与距离度量简介

在无监督学习中，算法不提供带标签的训练数据。相反，它仅获得一组输入示例，无监督学习的主要目标是发掘数据中固有的结构或模式，使算法能够基于这些发现的模式进行预测、决策或推荐 [[1]](#9789815136982-C8.html#r1)。这与有监督学习形成对比，在有监督学习中，算法同时获得输入示例和相应的带标签输出，并能通过进行预测并将其与真实标签比较来学习。无监督学习算法无需依赖带标签示例即可发现数据中隐藏的结构和关系，这使得它们在获取带标签数据具有挑战性、耗时或昂贵的情况下特别有价值。
