
# 数学表示

数学上，用 `Ö(xi˙→)` 表示变换后的 `xi˙→`，其中 `xi˙→` 是支持向量。现在，我们不再计算 `xi˙→∙xj˙→`，而是计算 `Öxi˙→∙Öxj˙→`，它可以用符号 `K` 表示为 `xi˙→` 和 `xj˙→` 的函数（即核函数）。

```
K(xi˙→, xj˙→) = Öxi˙→ ∙ Öxj˙→
```

## 多项式核

首先，让我们讨论多项式核：

```
K(xi˙→, xj˙→) = [ã xi˙→ ∙ xj˙→ + r]^d
```

其中：

- `xi˙→` 和 `xj˙→` 是支持向量
- `d` 是多项式核函数的次数
- `ã` 是核系数，`r` 是独立项

使用图（**[7.7](#9789815136982-C7.html#f7.7)**）中提到的示例来理解多项式核的工作原理。

由于它是一维的，向量可以仅表示为标量，即 `xi˙→ = xi`（根据定义，标量集是一维向量空间）。

对于多项式核：

```
K(xi˙→, xj˙→) = [ã xi˙→ ∙ xj˙→ + r]^d
```

设 `ã = 1`，`r = 2`，`d = 2`，则：

```
K(xi˙→, xj˙→) = [xi˙→ ∙ xj˙→ + 2]^2
            = xi xj + 2^2
            = 4 xi xj + xi^2 xj^2 + 4
            = (2, xi, xi^2, 2) ⋅ (2, xj, xj^2, 2)
```

注意 `(2, xi, xi^2, 2)` 就是变换后的 `xi˙→`（即 `Öxi˙→`），`(2, xj, xj^2, 2)` 就是变换后的 `xj˙→`（即 `Öxj˙→`），如表 **[7.2](#9789815136982-C7.html#t7.2)** 所示。

### 表 7.2 原始 (`xi˙→`) 和变换后 (`Öxi˙→`) 的支持向量

| i | xi˙→ | Öxi˙→ = (2, xi, xi^2, 2) |
|---|---|---|
| 1 | 1 | (2, 1, 2) |
| 2 | 2 | (4, 4, 2) |
| 3 | 0 | (0, 0, 2) |
| 4 | 3 | (6, 9, 2) |

如果省略 `Öxi˙→` 的第 3 个坐标（因为它们都具有相同的值 2），则可以在二维空间中绘图，如图（**[7.9](#9789815136982-C7.html#f7.9)**）所示。

![图 (7.9) 变换后的支持向量 (Öxi˙→) 在二维空间中的示意图](Images/9789815136982-C7-F9.jpg)

现在，正如观察到的，你可以大致画一条线性线来分离正负样本，这意味着一维空间中的线性不可分问题在二维空间中变成了线性可分的！

回顾多项式核表达式：

```
K(xi˙→, xj˙→) = [xi˙→ ∙ xj˙→ + 2]^2
            = xi xj + 2^2
            = 4 xi xj + xi^2 xj^2 + 4
            = (2, xi, xi^2, 2) ⋅ (2, xj, xj^2, 2)
```

使用核函数计算变换后支持向量点积的神奇之处在于，我们实际上不需要变换每个单独的支持向量（例如从 `xi` 到 `(2, xi, xi^2, 2)`）然后计算它们的点积。我们只需将原始支持向量代入核函数（例如 `K(xi˙→, xj˙→) = [xi˙→ ∙ xj˙→ + 2]^2`），因为这实际上等于变换后支持向量的点积（例如 `Öxi˙→ ∙ Öxj˙→ = (2, xi, xi^2, 2) ⋅ (2, xj, xj^2, 2)`）。

回顾在线性可分情况一节中，我们推导出了以下方程：

```
∑i αi yi xi˙→ ⋅ u˙→ + b = 1  if u˙→ 是正支持向量
∑i αi yi xi˙→ ⋅ u˙→ + b = -1 if u˙→ 是负支持向量
超平面: ∑i αi yi xi˙→ ⋅ u˙→ + b = 0
∑i αi yi = 0
```

如前所述，在线性不可分情况下，我们不再基于原始支持向量计算 `xi˙→ ⋅ u˙→`，而是基于变换后的支持向量计算 `Öxi˙→ ∙ Öu˙→`，这可以用核函数 `K(xi˙→, u˙→)` 表示。

因此，上述 4 个方程都需要相应更新：

```
∑i αi yi K(xi˙→, u˙→) + b = 1  if u˙→ 是正支持向量
∑i αi yi K(xi˙→, u˙→) + b = -1 if u˙→ 是负支持向量
超平面: ∑i αi yi K(xi˙→, u˙→) + b = 0
∑i αi yi = 0
```

# 7.5 支持向量机数值示例与代码对比：使用多项式核的线性不可分情况

在本节中，我们将使用上一节末尾所示的更新方程，配合多项式核来求解上述线性不可分数据集。数据点如图（**[7.10](#9789815136982-C7.html#f7.10)**）和表 **[7.3](#9789815136982-C7.html#t7.3)** 所示。

![图 (7.10) 用于带多项式核 SVM 的一维空间线性不可分数据集绘图](Images/9789815136982-C7-F10.jpg)

### 表 7.3 用于带多项式核 SVM 的线性不可分数据集

| X | y |
|---|---|
| 1 | -1 |
| 2 | -1 |
| 0 | 1 |
| 3 | 1 |

```
∑i αi yi K(xi˙→, u˙→) + b = 1  if u˙→ 是正支持向量
∑i αi yi K(xi˙→, u˙→) + b = -1 if u˙→ 是负支持向量
∑i αi yi = 0
```

现在，令 `âi = αi yi`，然后展开方程：

```
â1 K(x1˙→, x1˙→) + â2 K(x2˙→, x1˙→) + â3 K(x3˙→, x1˙→) + â4 K(x4˙→, x1˙→) + b = -1  when u˙→ = x1˙→
â1 K(x1˙→, x2˙→) + â2 K(x2˙→, x2˙→) + â3 K(x3˙→, x2˙→) + â4 K(x4˙→, x2˙→) + b = -1  when u˙→ = x2˙→
â1 K(x1˙→, x3˙→) + â2 K(x2˙→, x3˙→) + â3 K(x3˙→, x3˙→) + â4 K(x4˙→, x3˙→) + b = 1   when u˙→ = x3˙→
â1 K(x1˙→, x4˙→) + â2 K(x2˙→, x4˙→) + â3 K(x3˙→, x4˙→) + â4 K(x4˙→, x4˙→) + b = 1   when u˙→ = x4˙→
â1 + â2 + â3 + â4 = 0
```

注意：由于它是一维的，`xi˙→ = xi`；`x1` 和 `x2` 是 2 个负样本；`x3` 和 `x4` 是 2 个正样本。

多项式核函数：

```
K(xi˙→, xj˙→) = [ã xi˙→ ∙ xj˙→ + r]^d
```

设 `ã = 1`，`r = 2`，`d = 2`，则：

```
K(xi˙→, xj˙→) = [xi˙→ ∙ xj˙→ + 2]^2
```

所以：

```
K(x1˙→, x1˙→) = [1∙1+2]^2 = 9;   K(x2˙→, x1˙→) = [2∙1+2]^2 = 16
K(x3˙→, x1˙→) = [0∙1+2]^2 = 4;   K(x4˙→, x1˙→) = [3∙1+2]^2 = 25

K(x1˙→, x2˙→) = [1∙2+2]^2 = 16;  K(x2˙→, x2˙→) = [2∙2+2]^2 = 36
K(x3˙→, x2˙→) = [0∙2+2]^2 = 4;   K(x4˙→, x2˙→) = [3∙2+2]^2 = 64

K(x1˙→, x3˙→) = [1∙0+2]^2 = 4;   K(x2˙→, x3˙→) = [2∙0+2]^2 = 4
K(x3˙→, x3˙→) = [0∙0+2]^2 = 4;   K(x4˙→, x3˙→) = [3∙0+2]^2 = 4

K(x1˙→, x4˙→) = [1∙3+2]^2 = 25;  K(x2˙→, x4˙→) = [2∙3+2]^2 = 64
K(x3˙→, x4˙→) = [0∙3+2]^2 = 4;   K(x4˙→, x4˙→) = [3∙3+2]^2 = 121
```

然后，将值代入方程：

```
9â1 + 16â2 + 4â3 + 25â4 + b = -1
16â1 + 36â2 + 4â3 + 64â4 + b = -1
4â1 + 4â2 + 4â3 + 4â4 + b = 1
25â1 + 64â2 + 4â3 + 121â4 + b = 1
â1 + â2 + â3 + â4 = 0
```

求解这个线性方程组得到如下多组解：

```
â1 = 2.375 - 3â3
â2 = -4 + 3â3
â3 是自由变量
â4 = 1.625 - â3
b = 1
```

当取 `â3 = 1` 时：

```
â1 = -0.625
â2 = -1
â3 = 1
â4 = 0.625
b = 1
```

超平面：`∑i αi yi K(xi˙→, u˙→) + b = 0`

```
∴ â1 K(x1˙→, u˙→) + â2 K(x2˙→, u˙→) + â3 K(x3˙→, u˙→) + â4 K(x4˙→, u˙→) + b = 0
```

我们已经找到 `â1, â2, â3, â4, b`，且 `x1˙→, x2˙→, x3˙→, x4˙→` 已知。

核函数 `K(xi˙→, xj˙→) = [xi˙→ ∙ xj˙→ + 2]^2` 也已知。

此外，由于一维，`u˙→ = u`。

所以，超平面本质上是满足以下方程的那些 `u˙→`（一个易解的二次方程）：

```
-0.625[u+2]^2 - 1[u+2]^2 + 4 + 0.625[3u+2]^2 + 1 = 0
-0.625u^2 - 2.5u - 2.5 - 4u^2 - 8u - 4 + 4 + 5.625u^2 + 7.5u + 2.5 + 1 = 0
-0.625u^2 - 4u^2 + 5.625u^2 - 2.5u - 8u + 7.5u - 2.5 - 4 + 4 + 2.5 + 1 = 0
u^2 - 3u + 1 = 0
```

```
u = 0.382 或 2.618
```

有了这些，正负类别清晰可辨，如图（**[7.11](#9789815136982-C7.html#f7.11)**）所示。

![图 (7.11) 由带多项式核的 SVM 在一维空间确定的超平面 (u=0.382 或 2.618) 示意图](Images/9789815136982-C7-F11.jpg)

# 7.6 支持向量机数值示例与代码对比：使用径向基函数核的线性不可分情况

使用径向基函数（RBF）核的概念与多项式核相同，只是用于将低维输入空间变换到高维空间的函数不同。

对于多项式核，它使用此函数：

```
K(xi˙→, xj˙→) = [ã xi˙→ ∙ xj˙→ + r]^d
```

然而，对于 RBF 核，函数将是：

```
K(xi˙→, xj˙→) = e^(-ã ||xi˙→ - xj˙→||^2)
```

这里，`ã` 是核系数；`xi˙→` 和 `xj˙→` 是支持向量。

下表 **[7.4](#9789815136982-C7.html#t7.4)** 和图（**[7.12](#9789815136982-C7.html#f7.12)**）展示了另一个线性不可分数据集；让我们应用带 RBF 核的 SVM 来分离这 2 个类别。
