Note that `x1→` and `x2→` are the 2 negative samples; `x3→` and `x4→` are the 2 positive samples.

```
∑i αi yi K(xi→, u→) + b = 1  if u→ is +ve support vector
∑i αi yi K(xi→, u→) + b = -1 if u→ is -ve support vector
∑i αi yi = 0
```

Now, let `âi = αi yi`, and then expanding:

```
â1 K(x1→, x1→) + â2 K(x2→, x1→) + â3 K(x3→, x1→) + â4 K(x4→, x1→) + b = -1  when u→ = x1→
â1 K(x1→, x2→) + â2 K(x2→, x2→) + â3 K(x3→, x2→) + â4 K(x4→, x2→) + b = -1  when u→ = x2→
â1 K(x1→, x3→) + â2 K(x2→, x3→) + â3 K(x3→, x3→) + â4 K(x4→, x3→) + b = 1   when u→ = x3→
â1 K(x1→, x4→) + â2 K(x2→, x4→) + â3 K(x3→, x4→) + â4 K(x4→, x4→) + b = 1   when u→ = x4→
â1 + â2 + â3 + â4 = 0
```

**RBF Kernel function:**

```
K(xi→, xj→) = e^(-γ ||xi→ - xj→||^2)
```

Let `γ = 0.2`, then:

```
K(xi→, xj→) = e^(-0.2 ||xi→ - xj→||^2)
```

So,

```
K(x1→, x1→) = e^(-0.2 ||(1, 2) - (1, 2)||^2) = e^(-0.2 * 0) = e^0 = 1
K(x2→, x1→) = e^(-0.2 ||(5, 5) - (1, 2)||^2) = e^(-0.2 * 25) = e^(-5)
K(x3→, x1→) = e^(-0.2 ||(2, 1) - (1, 2)||^2) = e^(-0.2 * 2) = e^(-0.4)
K(x4→, x1→) = e^(-0.2 ||(4, 4) - (1, 2)||^2) = e^(-0.2 * 13) = e^(-2.6)

K(x1→, x2→) = e^(-0.2 ||(1, 2) - (5, 5)||^2) = e^(-5)
K(x2→, x2→) = e^(-0.2 ||(5, 5) - (5, 5)||^2) = 1
K(x3→, x2→) = e^(-0.2 ||(2, 1) - (5, 5)||^2) = e^(-5)
K(x4→, x2→) = e^(-0.2 ||(4, 4) - (5, 5)||^2) = e^(-0.4)

K(x1→, x3→) = e^(-0.2 ||(1, 2) - (2, 1)||^2) = e^(-0.4)
K(x2→, x3→) = e^(-0.2 ||(5, 5) - (2, 1)||^2) = e^(-5)
K(x3→, x3→) = e^(-0.2 ||(2, 1) - (2, 1)||^2) = 1
K(x4→, x3→) = e^(-0.2 ||(4, 4) - (2, 1)||^2) = e^(-2.6)

K(x1→, x4→) = e^(-0.2 ||(1, 2) - (4, 4)||^2) = e^(-2.6)
K(x2→, x4→) = e^(-0.2 ||(5, 5) - (4, 4)||^2) = e^(-0.4)
K(x3→, x4→) = e^(-0.2 ||(2, 1) - (4, 4)||^2) = e^(-2.6)
K(x4→, x4→) = e^(-0.2 ||(4, 4) - (4, 4)||^2) = 1
```

Then, plug the values into the equations:

```
â1 + e^(-5)â2 + e^(-0.4)â3 + e^(-2.6)â4 + b = -1
e^(-5)â1 + â2 + e^(-5)â3 + e^(-0.4)â4 + b = -1
e^(-0.4)â1 + e^(-5)â2 + â3 + e^(-2.6)â4 + b = 1
e^(-2.6)â1 + e^(-0.4)â2 + e^(-2.6)â3 + â4 + b = 1
â1 + â2 + â3 + â4 = 0
```

Solving this system of linear equations gives a unique solution as follows:

```
â1 = -3, â2 = -3, â3 = 3, â4 = 3, b = -0.1
```

**Hyperplane:** `∑i αi yi K(xi→, u→) + b = 0`

```
∴ â1 K(x1→, u→) + â2 K(x2→, u→) + â3 K(x3→, u→) + â4 K(x4→, u→) + b = 0
```

We have found `â1, â2, â3, â4, b`, and `x1→, x2→, x3→, x4→` are given. RBF kernel function `K(xi→, xj→) = e^(-0.2 ||xi→ - xj→||^2)` is also known.

So, hyperplane is essentially those `u→` that satisfy the following equation:

```
-3 K(x1→, u→) - 3 K(x2→, u→) + 3 K(x3→, u→) + 3 K(x4→, u→) - 0.1 = 0
```

Divide both sides by 3:

```
-K(x1→, u→) - K(x2→, u→) + K(x3→, u→) + K(x4→, u→) - 0.033 = 0
```

So, `âi` and `b` values in the simplest form that can represent the hyperplane are:

```
â1 = -1
â2 = -1
â3 = 1
â4 = 1
b = -0.033
```

Let us represent the vector `u→` as `(u1, u2)` in the two-dimensional space, where `u1` is the scalar/magnitude in the horizontal axis and `u2` is the scalar/magnitude in the vertical axis.

```
K(x1→, u→) = e^(-0.2 ||(1, 2) - (u1, u2)||^2) = e^(-0.2 [(1-u1)^2 + (2-u2)^2])
K(x2→, u→) = e^(-0.2 ||(5, 5) - (u1, u2)||^2) = e^(-0.2 [(5-u1)^2 + (5-u2)^2])
K(x3→, u→) = e^(-0.2 ||(2, 1) - (u1, u2)||^2) = e^(-0.2 [(2-u1)^2 + (1-u2)^2])
K(x4→, u→) = e^(-0.2 ||(4, 4) - (u1, u2)||^2) = e^(-0.2 [(4-u1)^2 + (4-u2)^2])
```

Then,

```
-e^(-0.2 [(1-u1)^2 + (2-u2)^2]) - e^(-0.2 [(5-u1)^2 + (5-u2)^2]) + e^(-0.2 [(2-u1)^2 + (1-u2)^2]) + e^(-0.2 [(4-u1)^2 + (4-u2)^2]) - 0.033 = 0
```

The plot of this equation is shown in **Fig. 7.13** as the curved line for separating the positive and negative classes.

**Fig. 7.13.** Illustration of the determined hyperplane (curved line) by SVM with RBF kernel on two-dimensional space.

## 8.1. INTRODUCTION TO CLUSTERING AND DISTANCE METRICS

In unsupervised learning, the algorithm is not provided with labeled training data. Instead, it is only given a set of input examples, and the primary objective of unsupervised learning is to uncover the inherent structure or patterns within the data, enabling the algorithm to make predictions, decisions, or recommendations based on these discovered patterns [[1]](#9789815136982-C8.html#r1). This contrasts with supervised learning, where the algorithm is given both input examples and corresponding labeled outputs and can learn by making predictions and comparing them to the true labels. The ability of unsupervised learning algorithms to discover hidden structures and relationships in the data without relying on labeled examples makes them particularly valuable in situations where obtaining labeled data is challenging, time-consuming, or expensive.
