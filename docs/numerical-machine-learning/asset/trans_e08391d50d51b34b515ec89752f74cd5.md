

# K-Means 聚类迭代

## 第一次迭代

### 从 C1 计算距离

C1 到 S2 的距离 `=45-602+35-752=42.72`

C1 到 S3 的距离 `=45-652+35-702=40.31`

C1 到 S4 的距离 `=45-902+35-902=71.06`

C1 到 S5 的距离 `=45-1002+35-952=81.39`

C1 到 S6 的距离 `=45-452+35-352=0`

### 从 C2 计算距离

计算 C2 到所有 6 个样本的距离：

C2 到 S1 的距离 `=60-402+75-452=36.06`

C2 到 S2 的距离 `=60-602+75-752=0`

C2 到 S3 的距离 `=60-652+75-702=7.07`

C2 到 S4 的距离 `=60-902+75-902=33.54`

C2 到 S5 的距离 `=60-1002+75-952=44.72`

C2 到 S6 的距离 `=60-452+75-352=42.72`

### 从 C3 计算距离

计算 C3 到所有 6 个样本的距离：

C3 到 S1 的距离 `=65-402+70-452=35.36`

C3 到 S2 的距离 `=65-602+70-752=7.07`

C3 到 S3 的距离 `=65-652+70-702=0`

C3 到 S4 的距离 `=65-902+70-902=32.02`

C3 到 S5 的距离 `=65-1002+70-952=43.01`

C3 到 S6 的距离 `=65-452+70-352=40.31`

K-Means 算法第一次迭代中计算出的所有欧氏距离列于表 **8.2** 中。

**表 8.2** K-Means 聚类第一次迭代中每个样本到 3 个质心的计算欧氏距离。

| **\-** | **C1** | **C2** | **C3** |
| --- | --- | --- | --- |
| S1 | 11.18 | 36.06 | 35.36 |
| S2 | 42.72 | 0 | 7.07 |
| S3 | 40.31 | 7.07 | 0 |
| S4 | 71.06 | 33.54 | 32.02 |
| S5 | 81.39 | 44.72 | 43.01 |
| S6 | 0 | 42.72 | 40.31 |

利用表 **8.2** 中的数据，我们可以根据样本到 3 个质心的距离，确定在 K-Means 算法第一次迭代中每个样本被分配到哪个簇。如表 **8.3** 所示，样本被分配给最近的质心。例如，S1 比 C2 和 C3 更接近 C1，因此分配给 C1；S2 比 C1 和 C3 更接近 C2，因此分配给 C2；S3 比 C1 和 C2 更接近 C3，因此分配给 C3。

对样本进行聚类后，我们需要通过计算分配给该簇的样本的均值，来重新计算每个簇的新质心。

**表 8.3** K-Means 聚类第一次迭代中每个样本的分配质心。

| **\-** | **C1** | **C2** | **C3** | **分配的质心** |

| S1 | 11.18 | 36.06 | 35.36 | C1 |
| S2 | 42.72 | 0 | 7.07 | C2 |
| S3 | 40.31 | 7.07 | 0 | C3 |
| S4 | 71.06 | 33.54 | 32.02 | C3 |
| S5 | 81.39 | 44.72 | 43.01 | C3 |
| S6 | 0 | 42.72 | 40.31 | C1 |

新质心 C1 是 S1 和 S6 的均值：

`C1=40+452, 45+352=(42.5, 40)`

新质心 C2 是 S2 的均值：

`C2 =601, 751=(60, 75)`

新质心 C3 是 S3、S4 和 S5 的均值：

`C3 =65+90+1003, 70+90+953=(85, 85)`

现在，我们可以使用新更新的 C1、C2 和 C3 进行 K-Means 聚类算法的第二次迭代。
