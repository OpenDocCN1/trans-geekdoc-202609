

# 监督学习

![](rsrcWV.jpg)在监督学习中，程序员使用标记数据。在开始使用算法之前，我们查看的数据是预先确定的。我们知道我们要寻找的输入和输出。`X`，和 `Y`。我们试图找到我们选择的 `X` 和 `Y` 之间的关系。在找到 `X` 和 `Y` 之间的关系后，你会得到一个模型，该模型将根据机器在数据中观察到的关系来预测结果。监督学习用于回归和分类模型。在机器学习中，我们将特征称为数据的某个可测量属性或特征。我们将讨论的第一种监督学习，也是第一种统计模型，称为回归。回归是一种数据输入和输出均为连续值的模型。回归有不同类型，但最基本的形式是线性回归。我们使用线性回归来找到某个输入 `X` 和输出 `Y` 之间的关系。一旦我们估计了这种关系，就可以使用 `X` 来预测 `Y`。线性模型可以，并且通常确实，拥有不止一个 `X`。在回归中，输出 `Y` 具有数值。

## 回归分析

回归是最简单的机器学习类型；当你刚开始学习如何使用数据时，这通常是你的起点。你有一组 `X` 值，并希望研究它们与输出 `Y` 的关系。我们模型中的自变量，即 `X`，被赋予权重，对于 `X` 的每个值，它都会乘以权重，直到聚合函数为 `Y` 创建预测。我们可以通过使用已知 `X` 和 `Y` 的数据来为 `Y` 创建预测模型。对这些信息进行回归将为我们提供 `X` 的权重。如果我们有足够的相关数据，最终我们将能够使用已知的 `X` 值来预测未知的 `Y`。我们将已知的 `Y` 和 `X` 值绘制在散点图上，我们的回归模型会找到穿过数据点的“最佳拟合”线。回归线称为超平面。线的陡峭程度称为斜率。我们可以测量预测值与实际数据点之间的距离，并将该测量值称为偏差。当我们创建线性回归时，我们的目标是最小化预测中的偏差。差异越小，偏差越小，你的模型就越准确。机器学习中使用的大多数统计模型都根植于这个第一个算法。通过沿线或聚类绘制数据点来创建一个预测结果的模型。但线并不总是直的，有时线不能显示最佳拟合。非线性回归函数的一个例子是 Sigmoid 函数。Sigmoid 函数创建一个 S 形曲线。与预测值不同，Sigmoid 函数获取自变量并生成 0 到 1 之间的概率。

## 简单线性回归

在简单线性回归中，我们研究某个预测值 `Y` 和某个预测因子 `X` 之间的关系。我们将 `Y` 称为因变量，因为它取决于 `X` 的值。我们的 `X` 被称为自变量。如果你在高中或大学学习过代数或预科微积分，那么你可能记得直线方程为；`Y = mX+b` 如果你绘制这个方程，你会得到一个看起来像这样的图表：![A close up of a logo Description automatically generated](rsrcWW.jpg)如你所见，线显示每个 `X` 值都有一个不同的 `Y` 值。你可以为每个新的 `X` 值做出 `Y` 值的预测。在这个图表中，随着 `X` 值的增加，`Y` 值也增加。情况并不总是如此。这是最简单的回归，但了解它的工作原理很重要，因为我们将在此基础上继续构建。大多数统计分析涉及类似上面所示的图表，它根据输入（自变量）对输出因变量进行预测。这是监督学习的一个例子，因为我们在开始建模之前指定了要使用的 `Y` 变量和 `X` 变量。在几乎所有预测中，都会有不止一个自变量来决定我们的因变量。这引出了我们的下一种回归类型。

## 多元线性回归

在数据科学和大多数统计任务中，这将是最流行的回归类型。在多元线性回归中，我们将有一个输出变量 `Y`，就像之前一样。现在的区别在于，我们将有多个 `X` 或自变量来预测我们的 `Y`。使用多元线性回归预测纽约市房地产公寓价格是一个例子。我们的 `Y` 或因变量是纽约市公寓的价格。价格将由 `X` 决定，即我们的自变量，例如面积、距离交通的距离、房间数量。如果我们将其写成表达式，它看起来会像这样：

```
apt_price = β0 + β1 sq_foot + β2 dist_transport + β3 num_rooms
```

我们获取样本数据，即我们已知其 `X` 和 `Y` 的数据，并像这样在图表上查看它们：![A close up of a logo Description automatically generated](rsrcWX.jpg)![A screenshot of a cell phone Description automatically generated](rsrcWY.jpg)你可以看到 `X` 和 `Y` 的值并不形成一条完美的线，但存在趋势。我们可以利用该趋势来对 `Y` 的未来值进行预测。因此，我们创建一个多元线性回归，最终得到一条穿过数据点中间的线。这被称为最佳拟合线，当我们将来获得新的 `X` 值时，我们将使用它来预测 `Y`。这里的区别在于，我们没有为斜率写 `m`，而是写了 `β`。这个方程基本上和写 `Y = b + m1X1 + m2x2 + m3x3` 是一回事，只不过现在我们有了标签，并且知道我们的 `X` 和 `Y` 是什么。将来，如果你看到多元线性方程，它很可能会以这种形式书写。我们的 `β` 是我们称之为参数的东西。它就像一个魔法数字，告诉我们 `X` 的值对 `Y` 有什么影响。每个自变量都会有一个唯一的参数。我们通过创建回归模型来找到参数。随着时间的推移，随着机器学习，我们的模型将接触越来越多的数据，因此我们的参数会得到改进，模型也会变得更加准确。我们可以使用包含纽约市公寓实际价格以及面积、距离交通距离和房间数等实际输入变量的训练数据来创建模型。我们的模型将“学习”从真实数据中近似价格。之后，当我们为一个价格未知的公寓输入自变量时，我们的模型可以预测价格会是多少。这是使用线性回归模型的监督学习。它是监督的，因为我们告诉模型我们希望它给出什么答案；即纽约市公寓的价格。随着它获得更多数据，并且我们继续评估其准确性，它学会了更准确地预测价格。

## 多项式回归

我们的下一种回归称为多项式回归。在前两种回归中，我们的模型创建了一条直线。这是因为我们的 `X` 和 `Y` 之间的关系是线性的，这意味着 `X` 对 `Y` 的影响不会随着 `X` 值的变化而改变。在多项式回归中，我们的模型将产生一条带有曲线的线。如果我们尝试使用线性回归来拟合具有非线性特征的图表，我们将无法很好地创建最佳拟合线。以左边的图表为例；散点图有类似之前的上升趋势，但带有曲线。在这种情况下，直线行不通。相反，使用多项式回归，我们将创建一条带有曲线的线来匹配数据中的曲线，就像右边的图表一样 ![A close up of a device Description automatically generated](rsrcWZ.jpg)![A close up of a logo Description automatically generated](rsrcX0.jpg)多项式方程看起来会像线性方程，区别在于一个或多个 `X` 值上会附带某个多项式表达式。例如：`Y = mX2+b` 随着 `X` 值的变化，`X` 对 `Y` 的影响会呈指数级变化。

## 支持向量回归

这是数据科学家的另一个重要工具，你应该熟悉它。它最常用于分类情况。这里的想法是找到一条穿过空间的线，将数据点分隔为不同的类别。支持向量回归是另一种监督学习类型。它也用于回归分析。它是一种与概率无关的二元分类技术。![](rsrcX1.jpg)在支持向量回归中，所有训练数据都属于某一类别或另一类别。你想找出新数据点属于哪个类别。你的数据由一个超平面分隔为这两个类别。当你为超平面创建模型时，你试图找到一个最大化两个类别之间距离的超平面。例如，在下一张图片中，你有一个散点图，其中的数据点可以分隔为两个不同的类别。在这种情况下，线一和线三可以将数据点分隔为两个不同的类别。但是，对于你的模型，你应该选择线二，因为它最大化了两个类别之间的边际，使它们更加明显。边际越宽越好。![](rsrcX2.jpg)

## 岭回归

这是一种常用于分析存在多重共线性问题的数据的技术。正确使用岭回归可以减少标准误差，并根据数据的特征使模型更加准确。当你的数据包含高度相关的自变量时，岭回归可能很有用。如果你可以使用另一个自变量来预测某个自变量，那么你的模型就存在多重共线性的风险。例如，如果你使用测量人身高和体重的变量；这些变量很可能在模型中产生多重共线性。多重共线性会影响预测的准确性。为了避免多重共线性，要注意你使用的预测变量类型。你使用的数据类型以及收集方法都可能是多重共线性的原因。你可能没有选择足够广泛的自变量范围。由于你选择的自变量有限，你的数据点可能过于相似。多重共线性也可能是由模型过于具体引起的。你拥有的变量比数据点多。如果你决定使用线性模型，并且这使多重共线性更加严重，那么你可以尝试应用岭回归技术。岭回归通过允许模型中带有一点偏差来使你的预测更加准确。这种技术也称为正则化。另一种方法是通过标准化自变量来提高模型的准确性。最简单的方法是将某些自变量的系数改为零以减少复杂性。但是，我们不会简单地将它们改为零，而是标准化实施了一个奖励接近零的系数的系统。这将导致系数收缩，因此模型的复杂性降低，但自变量仍然保留在模型中。这将使模型带有更多偏差，但这是为了更准确的预测而做出的权衡。

## LASSO 回归

LASSO 回归是另一种“收缩”技术。与岭回归非常相似，它鼓励构建更精简、更简单的预测模型。在 LASSO 回归中，模型对降低系数值更加严格。LASSO 代表最小绝对收缩和选择算子。散点图上的数据被收缩到一个更紧凑的点，类似于数据的平均值。就像岭回归一样，当模型存在多重共线性问题时，我们使用这种方法。

## ElasticNet 回归

ElasticNet 回归通过结合 LASSO 和岭回归的技术来工作。其主要目标是尝试改进 LASSO 回归。它结合了 LASSO 和岭回归中奖励较低系数的两种方法。这三种模型都可以在 R 和 Python 的 `glmnet` 包中访问。

## 贝叶斯回归

当我们数据不足或数据分布不佳时，贝叶斯回归模型很有帮助。这些回归是使用概率分布而不是数据点创建的，这意味着图表将呈现为一条钟形曲线，代表方差，曲线中间是出现频率最高的值。在贝叶斯回归中，因变量 `Y` 不是一个值，而是一个概率。我们不是试图预测一个值，而是试图预测结果的概率。这被称为频率统计学，贝叶斯定理构成了这种统计学的基础。频率统计学假设某事是否会发生，以及它发生的概率。当我们谈论频率统计学时，我们还包括条件概率。条件概率涉及结果相互依赖的事件。每次你抛硬币时，它都是一个独立事件，这意味着之前的硬币抛掷不会改变下一次硬币抛掷的可能性。因此，抛硬币不是条件概率。事件也可以是依赖的，这意味着之前的事件可以改变下一个事件的概率。假设我有一袋弹珠，我想知道从袋子里抽出不同颜色弹珠的概率。如果我有一袋 3 个绿色弹珠和 3 个红色弹珠，并且我抽出一个红色弹珠，那么下一次抽出红色弹珠的概率就会降低。这就是条件概率的一个例子。

## 决策树

我们将稍后讨论的一种模型称为神经网络。它们是最先进的机器学习类型，用于许多不同的目的。我将其与决策树联系起来，是因为人们经常在分类问题上求助于神经网络，而实际上有更简单的模型可用。决策树和相关的随机森林模型同样有用。尽管神经网络功能强大，但它们不能用于所有事情。幸运的是，我们有选择，这本书的目的就是让你知道当你决定要构建模型时有哪些选择。当神经网络不起作用时，下一个应该考虑的是决策树。决策树使用决策节点和叶节点以树状结构将数据分解为子类别。决策树相对于神经网络（本章后面讨论）有几个优势。首先，神经网络需要大量数据和强大的计算机来处理。使用决策树的好处是它们相对简单，尤其是与神经网络相比。与本书中的大多数模型不同，即使是未经训练的人也很容易读懂决策树。这使得它们成为在需要向利益相关者展示时选择模型的良好候选。决策树是另一种监督学习形式，这意味着我们在创建模型之前就标记了我们想要分类的类别。在某些情况下，决策树可以完成回归任务，但通常它们被用作分类模型。当决策树用于回归时，叶节点以概率结束。决策树从树顶部的所谓根节点开始。然后根节点在根节点之后分裂为两个节点。节点是树上的单个叶子，中间节点是做出决策的地方，称为决策节点。决策树在底部结束于所谓的终端节点，它位于分支的底部，决策在此完成。理想情况下，决策树会快速地逐层对数据进行分类。因此，我们称该模型为“贪婪”，因为顶层节点试图尽可能快地对数据进行分类，以便需要更少的层数。像神经网络一样，决策树经常遭受过拟合的问题。决策树通常无法与其他数据集一起工作，因为分类对每个数据集来说都太具体了。![](rsrcX3.jpg)下面是一个关于是否根据资格因素授予求职者面试机会的决策树示例。根节点是申请人是否拥有大学学位，随后是决策节点，所有决策节点都导向不雇佣或授予面试的决定。你可以从这个决策树中看出，为什么这种模型对你正在使用的特定数据如此具体，因为每个数据集在资格方面都会有所不同，因此每个数据集都会被不同地分类。![](rsrcX4.jpg)

## 随机森林

在模型中仅使用一棵决策树会对数据被分割的类别以及决策结果产生限制因素。由于决策树是“贪婪”的，这意味着某些类别被选中进行分类，从而禁止其他类别也被选中。但有一个简单的方法可以绕过这个问题。多样化决策树并提高模型准确性的一种方法是使用随机森林。如果真正的森林由几棵不同的树组成，那么随机森林正是如此。与只有一棵决策树不同，你将数据分割为几棵决策树。当你只有一棵树时，模型经常会遭受高方差的问题。创建随机森林是解决模型中这一问题的一种方法。它是数据挖掘可用的最佳工具之一。随机森林是你能接近用于数据挖掘目的的预打包算法的最接近方式。在随机森林中，所有树协同工作。所有树的聚合结果通常是正确的，即使少数树最终得出错误的预测。为了创建最终预测，所有树的结果被汇总。使用所有树的平均值的投票为我们提供最终预测。由于我们使用的是相似的数据，如果所有树都试图做同样的事情，树之间存在相关性的风险。如果我们使用相关性较低的树，模型将表现更好。想象一下我们要押注硬币抛掷。我们每人有一百美元，有三个选择。我可以抛一次硬币，那次抛掷的赢家可以保留 100 美元。或者，我可以抛十次硬币，每次押注十美元。第三个选择是抛 100 次硬币，每次押注一美元。这个游戏每个版本的真实预期结果是相同的。但是，如果你进行 100 次硬币抛掷，你比只进行一次硬币抛掷更不太可能输光所有钱。数据科学家将这种方法称为自助法。它是机器学习者分散股票投资组合的等价物。我们希望有一个能给出准确预测的模型。我们分割的决策树越多，我们的数据就越准确。但是，重要的是单个树之间具有低相关性。森林中的树需要多样化。我们如何避免随机森林中的相关性？首先，每棵树从数据集中取一个随机样本，因此每棵树拥有略有不同的数据集。树以贪婪的过程选择一个在节点之间创造最大分离的特征，就像单个树一样。但是，在随机森林中，树只能从整体特征组中选择某些特征，因此每棵树通过不同的特征进行分离。因此，树将是不相关的，因为它们使用不同的特征来对分类做出决策。在随机森林中，最好至少使用 100 棵树来获得数据的准确图景，具体取决于你正在使用的数据集。一般来说，树越多，模型过拟合的可能性就越小。随机森林机器学习被称为“弱监督技术”，因为我们的结果是选定的，我们可以看到分类方法，但每棵树负责根据特征对变量进行分类和分离。分类模型会告诉我们某事物属于哪个类别。类别由程序员在开始时定义。使用随机森林的分类模型示例可以是一个模型，用于确定传入电子邮件应该进入你的‘收件箱’还是‘垃圾邮件’文件夹。为了创建模型，我们创建两个 `Y` 可以落入的类别；垃圾邮件和非垃圾邮件。我们编程模型查找可能指示垃圾邮件的关键字或某些电子邮件地址。像“购买”或“优惠”这样的词的存在将帮助模型确定电子邮件消息是否属于垃圾邮件或非垃圾邮件类别。算法接收数据，并通过将其预测与输出的实际值进行比较来学习。随着时间的推移，它对模型进行微小调整，使算法随时间变得更加高效。
