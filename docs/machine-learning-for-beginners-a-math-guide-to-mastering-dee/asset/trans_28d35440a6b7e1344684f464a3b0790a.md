

# 分类

在本书中，我们多次提到分类模型。虽然我们已经提到的一些模型能够进行分类，但以下是更多专门用于分类的监督学习模型。分类需要标记数据，并生成非连续预测。在分类问题中，图表是非线性的。分类问题中可能有两个类别，甚至更多。分类模型可能是机器学习和数据科学中最广泛使用的部分。

## 二元分类

第一种分类类型是二元分类。使用二元分类时，数据被分为两个类别，用 `1` 或 `0` 表示。我们称之为二元分类，因为只有两个可能的类别，所有数据都属于其中之一。但也有我们拥有超过两个类别的情况，这时我们使用多类分类模型。此外，我们有线性决策边界，数据被一条线分为两侧。并非所有数据都能被分到决策边界的某一侧。第一张图展示了使用线性决策边界进行分类的示例。在第二张图中，几乎有两个类别，但它们不是线性可分的。在第三张图中，数据点混合在一起，线性边界分类是不可能的。根据你使用的数据类型，有不同的模型选择更适合不同的任务 ![](rsrcX5.jpg)![A close up of a logo Description automatically generated](rsrcX6.jpg)![A close up of a logo Description automatically generated](rsrcX7.jpg)

## 逻辑回归/分类

此方法用于分类因变量和分类变量。逻辑回归根据自变量计算概率。它给变量赋予“是或否”的值以进行排序。通常与二元分类一起使用。当你无法像上面的示例那样通过线性边界将数据分为类别时，就必须使用此方法。它是最常见的机器学习算法类型之一。它不仅将数据分为类别，还告诉我们某个类别存在的概率。我们通过取赔率函数来表示此模型，其中 `p` 是事件发生的概率；![](rsrcX8.jpg)并创建一个称为 logit 的公式 ![](rsrcX9.jpg)

## K 近邻

K 近邻是数据分类中最简单且最广泛使用的方法之一。它是一种监督学习形式，既用于分类也用于回归，也是最基本的聚类算法。简单来说，就是取一个数据点，将其与散点图中最常见且最近的组放在一起。在 KNN 中，新数据点由其邻居 `K` 的平均中位数值进行分类。新数据点的最近邻居“投票”决定它属于哪个分类。`K` 是模型中投票的最近邻居的数量。将 `k` 设置为一个数字——这就是新数据点将分析以确定其适合哪个类别的最接近数据点的数量。数据点的接近程度使用欧几里得距离来衡量。以下两张图作为示例。我们将数据分为两个分类；白点和黑点。引入一个新数据点，即三角形，我们希望预测它属于哪个分类。在此模型中，我们选择了 `K=4`。如果你选择 `k=4`，则将分析四个最接近的数据点。邻近数据点中最普遍的类别就是新数据点将被放置的类别。在此情况下，你可以看到右侧图像中四个白点是最近的分类。因此，新数据点被分类到该类别中。 ![A close up of a logo Description automatically generated](rsrcXA.jpg)![A picture containing object Description automatically generated](rsrcXB.jpg)

在选择 `k` 的值时，需要考虑几个因素。`k` 的数值越高，我们就越接近新数据点的真实分类。存在一个最佳点，`k` 的值应停止增加以避免过拟合。如果你选择使用一个过低的 `K` 值，那么你的模型可能会遭受高偏差的问题。如果你使用一个过高的数值，那么计算该值所需的计算能力将过于昂贵。你可能会考虑在选择 `K` 的值时使用奇数，而不是偶数。如果你使用奇数，那么在类别对数据点进行投票时，出现平局的可能性较小。数据科学家通常将数字 `5` 作为 `k` 的默认设置。如果你使用一个较大的 `K` 值，这将非常耗费数据。大型数据集也难以与 KNN 机器学习模型一起使用。如果你使用较大的数据集，那么你必须计算数百甚至数千个数据点之间的距离。当你在存在超过两个维度的模型上使用此方法时，它的表现也不好。这同样与计算许多数据点之间的距离所需的计算能力有关。

## 支持向量

支持向量是另一种分类器。它使用超平面进行分类。通常，我们会在较小的数据集上使用支持向量模型，其表现相当出色。

## 朴素贝叶斯

回顾监督学习第一节中的贝叶斯定理。在朴素贝叶斯模型中，假设预测器是独立的。该模型易于使用，在大型数据集中很有帮助。它常被用来帮助分类垃圾邮件。我们在此使用贝叶斯规则。贝叶斯规则的理念是，通过将新的相关信息添加到我们已知的信息中，我们可以根据这些新信息更新我们的知识。如果我们想知道今天下午下雨的概率，我们可以计算一年中下雨天数所占的百分比。但随后我们发现今天早上下过雨。你认为这会如何影响今天下午下雨的概率？因此，当我们获得更多关于事件的信息时，我们预测某事发生概率的能力就会提高。在数学上，贝叶斯定理表示如下：![](rsrcXE.jpg)因此，我们可以使用贝叶斯定理对新数据点进行分类。其工作方式是，当给出一个新数据点时，我们根据该数据点的特征计算其落入某个类别的概率。
