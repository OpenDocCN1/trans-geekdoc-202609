

# 后记

希望阅读本书后，你能很好地理解机器学习的基本原理。你现在已经了解了几种不同类型的流行机器学习模型及其用途。我们探讨了高级数据科学家如何使用机器学习来创建预测，以及他们需要哪些参数才能在引入新数据时创建准确且可靠的预测。数据科学和机器学习的魅力在于其广泛的应用范围。如果你走出去积累机器学习经验，那么将有广泛的工作和机会，与各种不同类型的数据打交道。无论你是喜欢商业竞争和刺激，想要使用预测股票涨跌或猜测客户下次会购买什么的模型；还是你对医学和医疗保健感兴趣，你可以应用机器学习来改善癌症诊断，并对疾病的特征及其对不同个体的影响获得新的认识。无论你的兴趣在哪里，都有机会将机器学习植入其中，以改进我们已经能够做到的事情。世界越互联，可用的数据就越多。几乎每个人都有某种智能设备在记录和跟踪其用户数据。数据科学家正在寻找更具创造力的方法来学习和解释这些数据。机器学习是数据科学家检查超出人类理解范围的趋势的一种方式，这意味着我们的预测将继续变得更加准确，我们的数据也将更加有用。计算机将继续变得更加强大，而这种力量将变得越来越容易获得，这意味着机器学习和数据科学将不再仅仅是流行语，而是寻找有价值信息的广泛应用方法。不再仅仅是大型企业在利用数据和机器学习；即使是小型企业，将大数据纳入其决策过程也变得越来越可行。既然你已经了解了机器学习的基本理论，现在是时候继续前进，并找到应用和实践这些知识的方法了。如果你有兴趣成为一名专注于机器学习的数据科学家，那么本书只是这个过程的开始。我强烈建议你致力于学习像`Python`、`R`或`C++`这样的语言。这是成为数据科学家的下一步，也是将这些机器学习理论应用到实际模型和算法中的下一步。多亏了互联网，有大量免费的书籍、视频和教程可供你学习计算机语言。学习如何编码并创建自己的模型，现在是最好的时机。本书只是关于该主题的大量可用信息中的一小部分。如果你认真对待机器学习，那么这不应该是你读的唯一一本书。你可以找到描述特定模型过程的整本书。神经网络是一个非常先进的领域，你可以找到仅基于这种特定模型类型的整本书。挑选几本统计学学习指南也不是个坏主意，这样当你有疑问时可以参考它们。留意可能的数据来源，你可能能够利用这些数据，以及可能值得用统计数学探索的潜在问题。仅就业机会就足以成为你在该领域追求更多知识的理由。缺乏能够应用本书中列出的方法和技术的有经验的数据科学家。这意味着，对于那些愿意动手并开始编写自己的模型的人来说，是一个机会。现在就有企业和组织在寻找能够正确使用这些信息的人。请记住，这种需求不会永远存在。已经，全球各地的大学正在创建专门针对数据科学（作为计算机科学和统计学的结合）的新学位课程。这意味着下一代数据科学家已经在路上了。所以，现在就开始你的学习吧。找一个在线教程和一些免费的在线数据集，开始弄清楚如何进行回归和分类，以本书为指南。一次学习一个模型。在互联网上找到完成的模型示例，并尝试看看你是否可以复制结果。学习编程语言需要时间，所以要有耐心，并寻找新的机会来学习和调整你的技能。尝试一个专门针对统计建模的在线社区，以此来初试身手，并从其他数据科学家正在做的事情中学习。我建议你查看`Kaggle.com`。这是一个为有志成为数据科学家的人举办统计建模竞赛的网站。不同的公司和组织会发布包含数据集的竞赛。这是尝试各种任务并获取可用数据的好方法。旧的竞赛也在线上可用，有大量相关的教程在`youtube.com`和其他数据科学社区供你学习。这可能是有志成为数据科学家扩展简历并与其他数据科学家建立人脉的最佳方式。如果你觉得这有用，你可能也会喜欢：[PYTHON MACHINE LEARNING: Discover the Essentials of Machine Learning, Data Mining and Artificial Intelligence Using Python Code with Python Tricks](https://www.amazon.com/dp/B07X43CYD7) By Samuel Hack 我想感谢你阅读这本书，如果你喜欢它，我将不胜感激你在Amazon上留下评论！
