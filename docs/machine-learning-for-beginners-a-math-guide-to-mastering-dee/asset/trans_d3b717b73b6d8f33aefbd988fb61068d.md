

# 神经网络

神经网络是一种被称为深度学习的机器学习形式。它可能是最先进的机器学习方法，真正理解其工作原理可能需要博士学位。你可以写一整本书来介绍机器学习中最技术性的模型。神经网络是设计用来模拟人脑内部通信路径的计算机系统。在你的身体里，你有数以亿计的神经元，它们相互连接，沿着脊柱向上延伸进入大脑。它们通过类似根的节点相连，一次传递一个神经元的消息，一直传递到整个链条直到到达大脑。虽然目前还无法用计算机完全复制这一过程，但我们采用其核心理念并将其应用于计算机神经网络，以复制像人脑一样学习的能力；识别模式并从新信息的发现中推断信息。在神经网络的情况下，与我们所有的机器学习模型一样，信息作为数值数据通过神经网络进行处理。通过给出数值数据，我们赋予它使用算法进行预测的能力。就像大脑中的神经元一样，数据从顶部开始，逐层向下传递，首先被分离到节点中。神经网络使用节点在每一层之间进行通信。神经网络由三部分组成；输入层、隐藏层和输出层。下图中，我们有神经网络的可视化表示，圆圈代表网络中的每个单独节点。在左侧，我们有输入层；这是我们的数据进入的地方。数据通过输入层后，会经过几个隐藏层进行过滤。隐藏层是数据根据不同特征和属性进行分类的地方。隐藏层寻找数据集中的模式。隐藏层是‘魔法’发生的地方，因为数据是根据我们手动排序可能无法识别的模式进行分类的。每个节点都有一个权重，这将有助于确定正在排序的特征的重要性。

这些神经网络的最佳用途是对人类来说简单但对计算机来说极其困难的任务。回顾本书开头我们讨论推理和归纳推理时的内容。我们的人脑是归纳推理的强大工具；这是我们相对于能在几秒钟内计算大量数据的先进计算机的优势。我们模仿人类思维来构建神经网络，因为我们试图教会计算机像人类一样‘推理’。这是一个相当大的挑战。神经网络的一个好例子就是我们提到的，我们将神经网络应用于对人类来说极其简单但对计算机来说非常具有挑战性的任务。神经网络可能需要大量的计算能力。神经网络处理起来具有挑战性的第一个原因是构建准确模型所需的数据集的数量。如果你想让模型学习如何对照片进行分类，照片之间存在许多细微差别，模型需要学习这些差异才能有效地完成任务。这导致了下一个挑战，即神经网络正常工作所需的变量数量。你使用的数据越多，分析的变量数量越多，隐藏网络的数量就越多。在任何给定时间，都有数百甚至数千个特征正在通过模型进行分析和分类。以自动驾驶汽车为例。自动驾驶汽车拥有超过150个用于排序的节点。这意味着，自动驾驶汽车在同时分析数千个输入的情况下做出瞬间决策所需的计算能力是非常大的。在对照片进行分类的情况下，神经网络非常有用，数据科学家使用的方法也在迅速改进。如果我给你看一张狗的照片和一张猫的照片，你可以轻松地告诉我哪一张是猫，哪一张是狗。但对于计算机来说，这需要复杂的神经网络和大量数据来训练模型。神经网络的一个常见问题是过拟合。模型可以预测训练数据的值，但当它接触到未知数据时，它对旧数据的拟合过于具体，无法对新数据进行泛化预测。假设你即将参加数学考试并想要复习。你可以记忆所有你认为会出现在考试中的公式，并希望考试当天能够将新信息代入你已经记忆的内容中。或者你可以更深入地学习；了解每个公式的工作原理，以便即使条件发生变化也能取得良好结果。过拟合的模型就像为考试记忆公式。如果新数据相似，它会表现良好，但当出现变化时，它就不知道如何适应了。你通常可以通过模型在训练数据上表现良好但在测试数据上表现不佳来判断模型是否过拟合。当我们检查模型的性能时，可以使用代价值来衡量。代价值是模型预测值与实际值之间的差异。神经网络的挑战之一是无法确定特定输入与输出之间的关系。隐藏层之所以被称为隐藏层是有原因的；它们太难以解释或理解。最简单的神经网络类型称为感知机。它之所以简单，是因为它只有一层数据通过。输入层通向一个分类隐藏层，得到的预测是二进制分类。回顾一下，当我们将分类技术称为二进制时，这意味着它只在两个不同的类别之间进行排序，分别由0和1表示。感知机最初由Frank Rosenblatt开发。如果你想了解更多关于神经网络的知识，熟悉感知机是个好主意。感知机使用与其他神经网络模型相同的过程，但通常你会使用更多层和更多可能的输出。当接收到数据时，感知机将输入乘以给定的权重。然后将所有这些值的总和代入激活函数。激活函数告诉输入属于哪个类别，换句话说就是预测输出。如果你在图表上观察感知机，它的线会是这样的：

感知机图表的线看起来像一个台阶，在1的两侧各有一个值。台阶的这两侧是模型根据输入将预测的不同类别。从图表中你可能能看出，这有点粗糙，因为类别之间的线上几乎没有分离。输入变量的微小变化就会导致预测输出变成不同的类别。它在用于训练的原始数据集之外的表现不会那么好，因为它是一个阶跃函数。感知机的替代方案是一个称为Sigmoid神经元的模型。使用Sigmoid神经元的主要优势是它不是二进制的。与只能将数据分类为两个类别的感知机不同，Sigmoid函数创建的是概率而不是分类。下图显示了Sigmoid神经元的曲线。注意曲线在1附近的形状，数据在该处由感知机进行排序；台阶使得仅基于微小差异对数据进行分类变得困难。使用Sigmoid神经元时，数据是根据其落入给定类别的概率来预测的。如你所见，线在1处弯曲，这意味着数据点落入给定类别的概率在1之后会增加，但这只是一个概率。
