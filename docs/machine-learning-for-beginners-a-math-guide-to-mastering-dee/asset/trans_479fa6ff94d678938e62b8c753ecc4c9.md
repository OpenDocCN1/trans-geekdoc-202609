

# 数据分析的最新进展

机器学习自1959年亚瑟·塞缪尔（Arthur Samuel）的跳棋计算机问世以来发生了巨大变化。但过去二十年的变化比其整个历史的变化还要大，尤其是随着计算能力的提升。过去，机器学习和大数据分析曾非常有限。只有拥有昂贵技术的大型公司才有能力利用数据做出商业决策。现在，几乎任何人都可以使用笔记本电脑或家用电脑，利用一定量的数据进行商业或其他用途。数据更容易获取，处理数据的机器也变得更加普及。过去需要昂贵计算能力才能完成的事情，现在可以更便宜、更快地完成。云技术的出现使得小型企业更容易访问大型数据集，而无需大量数据存储。现在，机器学习已成为计算机科学的一个完全不同的领域，拥有专门从事机器学习和数据科学的人员，作为其自身的领域。如今，越来越多的事物相互连接，互联网不断壮大。这意味着数据访问量在增加，但数据来源也在发生变化。即使是人们的汽车也有计算机，这意味着当他们驾驶时，他们正在创造可以被解读的数据。绝大多数美国人都携带手机，进行网上购物，并使用应用程序进行导航。人们使用手机控制家用电器，这是另一个潜在的数据来源。有Fitbit和智能手表，允许人们追踪健康数据。连接的设备越多，不仅仅是计算机和手机，而是各种各样的设备，收集和研究数据的可能性就越大。这种万物互联；智能手机、智能汽车等，让人们担心他们可能面临丢失私人数据的风险。他们担心自己的隐私岌岌可危，总有人在监视他们。但机器学习和数据分析正在让我们的生活变得更加轻松。找到合适的产品更容易，导航更容易，发现新音乐也更容易。这一切都要归功于机器学习。

## 图像识别

机器学习模型的应用之一是数据的排序和分类。这种分类甚至可以用于图像分类。搜索引擎使用这种算法来识别照片，社交媒体网站现在使用人脸检测在照片被标记之前识别照片中的人。他们通过从其他照片汇编的数据中学习来做到这一点。如果你的社交媒体账户可以在新照片中识别你的脸，这是因为它使用了来自你账户中所有其他照片的数据创建了模型。图像识别技术需要深度学习模型。深度学习模型是用人工神经网络构建的，这将在本书后面更广泛地介绍。深度学习是最复杂的机器学习类型，数据通过几个隐藏层的节点进行过滤。它们被称为隐藏层，因为模型是无监督的，这意味着模型识别的特征不是由数据科学家事先选择的。通常，特征是模型自行识别的模式。神经网络中识别的特征可能非常复杂，任务越复杂，模型拥有的层数就越多。图像排序模型可能只有两三层，而自动驾驶汽车则会有一到两百个隐藏层。近年来，由于计算能力的可用性增加，我们在这一领域取得了重大进展。想象一下，同时将数千个数据点传递给数百个堆叠节点所需的计算能力。在过去十年中，随着计算机的改进和处理大量数据成本的降低，深度学习和人工神经网络变得更加可行。尤其是随着云技术的出现，它允许数据科学家在不使用物理存储空间的情况下访问大量数据。有一个名为ImageNet的网站，它是对照片分类和神经网络感兴趣的数据科学家的绝佳资源。ImageNet是一个图像数据库，可公开用于机器学习。其理念是，通过公开访问，机器学习技术的改进将成为全球数据科学家的合作努力。ImageNet的数据库中有大约1400万张照片，超过21,000个可能的类别组。这为数据科学家访问和分类照片以学习和实验神经网络提供了无限可能。每年，ImageNet都会为全球数据科学家举办竞赛，以创建新的图像分类模型。每年的竞赛都会变得更难。现在，他们开始转向对视频而不是图像进行分类，这意味着所需的复杂性和处理能力水平将继续呈指数级增长。利用数据库中的数百万张照片，ImageNet竞赛在过去几年中推动了图像识别的突破性进步。现代照片分类模型需要能够进行非常具体分类的方法。即使两张图片应该被归入同一类别，它们看起来也可能非常不同。你如何创建一个能够区分它们的模型？

举个例子，看看这两张不同的树木照片。如果你正在创建一个分类树木图片的神经网络模型，那么理想情况下，你希望模型将两者都归类为树木照片。人类可以识别这两张都是树木照片，但照片的特征会使它们很难用机器学习模型进行分类。变量之间的差异越少，分类就越容易。如果你所有的树木照片都像左边的图片一样，树木完整展示且具有所有特征，那么模型就更容易制作。不幸的是，这会导致过拟合，当模型接触到像右边那样的照片数据时，你的模型将无法正确分类。我们希望模型能够分类我们的数据，即使它们不那么容易分类。令人难以置信的是，ImageNet已经能够创建能够分类具有许多变量且非常相似的数据的模型。最近，他们创建了图像识别，甚至可以识别和分类不同品种的狗的照片。想象一下，模型需要识别多少变量和相似性，才能正确地区分不同品种的狗。识别类别内共同点的挑战被称为类内变异性。当我们有一张树桩的照片和一张田野中树木剪影的照片时，我们正在处理类内变异性。这个问题是同一类别中的变量如何彼此不同，使得我们的模型更难正确预测它们属于哪个类别。最重要的是，它需要大量的数据随时间推移来改进模型并使其准确。为了在高类内变异性的情况下拥有准确的模型，我们需要在神经网络模型中使用额外的技术来在图像中寻找模式。一种方法涉及使用卷积神经网络。而不是只有一个模型或算法，数据被输入到几个相互堆叠的模型中。神经网络将图像特征转换为数值以进行排序。不幸的是，试图理解这些深度神经网络的运作方式超出了本书的范围，但有许多书籍涵盖了这些类型的模型，并包含执行此类分析所需代码的更全面解释。

## 语音识别

人工智能的改进使得语音识别最近变得更加有用。我们的大多数智能手机现在都有某种程度的语音识别能力，这涉及机器学习。语音识别将我们给它的音频数据转换为可以解释的文本。语音识别的难点在于人们说话方式的不规则性。就像类内变异性一样。你和我可能有不同的口音和不同的语调，这在教计算机理解人类声音时很难考虑到。如果我们都用不同的口音说同一个单词，我们如何教模型理解我们？语音识别也使用神经网络来解释数据，就像图像识别一样。这是因为音频数据中的模式人类可能无法识别。数据科学家使用采样来解释数据并做出准确预测，尽管人们的声音存在差异。采样是通过测量声波的高度和长度来完成的，信不信由你，这可以用来解读用户在说什么。录制的音频被转换为频率波形图。这些频率由数值测量，然后输入神经网络的隐藏层以寻找模式。

## 医学与医疗诊断

机器学习不仅对数字营销或让计算机响应你的请求有用。它还有潜力改善医学领域，特别是利用以前患者的数据进行患者诊断。尽管机器学习在医疗诊断方面潜力巨大，但由于围绕患者隐私的法律，要找到可用于机器学习的患者数据可能具有挑战性。它正在逐渐在医学领域获得接受，这意味着数据正在变得对数据科学家可用。不幸的是，到目前为止，要拥有足够有意义的数据来制作医疗诊断模型一直很困难。但技术已经存在并可供使用。机器学习可以利用图像识别来诊断X光片，通过获取多个患者的影像扫描数据来对新患者做出预测。聚类和分类可以用于对同一种疾病的不同类型进行分类，以便患者和医疗专业人员更好地了解两名患者之间同一种疾病的差异以及生存的可能性。机器学习医疗诊断可以减少医生的诊断错误，或为医生提供第二意见。它还可以用于根据患者因素和疾病特征预测阳性诊断的概率。总有一天，医疗专业人员可能能够查看数千名患者关于某种疾病的数据来做出新诊断。但医疗诊断只是机器学习在医学中可以利用的众多方式之一。今天，医疗数据集仍然很小，机器学习科学在医学领域仍有大量未开发的潜力。

## 股票预测

股票交易者会查看许多变量来决定如何处理一只股票，无论是想买入、卖出还是等待。他们会查看股票的某些特征以及市场环境的趋势，以对应该做什么做出有根据的猜测。多年来一直是这样做的。经纪人和交易者必须手动进行研究才能做出最佳猜测。现在可以使用机器学习来做同样的事情，只是机器学习可以做得更快、更高效。要成为一名有效的交易者，你必须能够实时分析趋势，以免错过机会。机器学习可以帮助交易者在股票之间寻找相似性，以使用统计数据做出财务决策。交易者可以使用线性回归模型来研究股票市场价格过去趋势的数据，以及导致股票价格上涨和下跌的变量。他们可以使用这些回归来决定如何处理一只股票。通常，想要分析股票表现的交易者会使用所谓的支持向量机。支持向量机是一种分类模型，其中数据点被一条边界线分开，一边是一个类别，另一边是另一个类别。交易者将使用支持向量机来分类哪些股票买入，哪些股票卖出。使用某些应能表明给定股票表现的变量，该股票被放置在边界线的一侧，以表示价格可能上涨或下跌。深度学习也常用于制作股票模型。神经网络的隐藏层可能有助于识别可能导致股票价格上涨或下跌的未见趋势或特征。没有所谓的稳赚不赔或无风险投资。当人们做决策时这是事实，当我们使用数据科学进行财务预测时，这仍然是事实。重要的是要记住，投资股票市场始终是有风险的。不可能创建一个能对股票市场做出任何可靠预测的模型。它是狂野且不可预测的。但我们已经了解到，机器学习可以发现人类可能无法自行发现的模式。如果你理解股票市场的趋势可能完全是随机且不可预测的，那么拥有一个能帮助你估计股票可预测性的另一个模型就很有用。了解你对给定股票的预测有多准确，与预测本身同样重要。创建一个单独的模型来衡量给定股票的可预测性，这样你就知道你的预测有多可靠。不同的股票会有不同程度的可预测性。重要的是用你的模型来说明这一点，以便你可以从最可靠的预测中进行选择。交易者将继续对股票价值是上涨还是下跌做出最终决定。但数据科学和机器学习可以简化分析信息的过程，从而帮助决策过程。这就是为什么你会看到越来越多的机器学习模型用于股票预测，以及为什么你至少应该让自己熟悉这个想法。

## 关联学习

各行各业的营销人员，从实体零售到在线零售，总是在寻找将产品关联起来并增加销售的方法。无论你拥有一家小型自行车店还是一个巨大的在线仓库，在客户的购买习惯中发现模式将帮助你做出主动决策以推动销售并赚取更多钱。我们大多数人每周都会去一次杂货店。杂货店是利用产品摆放来促进销售的完美例子。任何一家杂货店都会组织自己，使相似的物品放在一起。烘焙食品有自己的过道，而水果和蔬菜有它们的位置。他们这样做有两个原因；这使购物者更容易找到所需物品并改善客户体验。此外，产品摆放可以帮助将客户与他们愿意购买但刚进店时并未寻找的产品联系起来。除了把蔬菜放在同一过道之外，杂货店还可以实施另一种策略来引导客户购买某些产品。他们可能会推断购买特定产品的客户的特征，并利用这一点来推荐其他不相关的产品。例如，你可以假设从蔬菜区购买新鲜蔬菜的人饮食更健康。你可以把冰沙放在蔬菜区，放在你存放水果的同一个冰箱里。如果客户进来寻找精酿啤酒，你可以用零食诱惑他们，并将薯片放在12罐装淡啤酒的同一过道。如果这一切对你都有意义，那么你就在理解一种称为协同过滤的技术的道路上了。这是一种广泛用于互联网营销的机器学习技术。如果你的搜索数据显示你一直在浏览前往坎昆的机票，你可能会开始注意到浏览器上出现泳衣广告。营销数据科学家总是在努力回答这个问题；我们如何利用数据找到一种方法将产品与其目标市场联系起来？这关乎利用数据将两个原本不相关的产品联系起来以推动销售。这是一种基于你对客户了解的情况向客户做出推荐的方式。机器学习通常可以发现我们可能不知道要寻找的客户相似性或购买模式。这是一种在现代开始出现的强大营销工具。以前，大多数营销机构不得不依靠直觉来寻找目标市场。现在，数据科学家可以使用定量数据来描绘更准确的理想客户画像。如果你有兴趣在数字营销中使用机器学习，那么这是一个你应该熟悉的话题。协同过滤与仅仅向客户推荐类似产品不同。你是根据从其他客户那里收集的数据，对客户的口味或偏好做出预测。你基于在两个产品之间发现的相关性来做出这个预测，然后衡量产品Y与产品X一起被购买的可能性。你使用这些相关性估计来决定向谁推销什么。Spotify在制作歌曲推荐时使用类似的过程。它使用你随时间推移喜欢的所有音乐的数据。如果两个艺术家之间存在相关性，即很多人在他们的库中同时拥有这两个艺术家，模型可以预测你会喜欢另一位艺术家的概率。你在商店里拥有的产品越多，找到这些相关性就越费力。在完美的世界里，你会寻找商店中每种不同产品组合之间的相关性。这种基于购买另一种产品来预测你会喜欢一种产品的方法称为Apriori算法。有三个标准需要满足，以确认两个产品之间存在相关性，并且你应该以某种方式在商店中将它们关联起来。第一个标准是支持度。这给你一个特定产品受欢迎程度的衡量。在所有交易中，这个物品出现在人们购物车中的频率是多少？第二部分是两个产品之间相关性的置信度。当客户购买X产品时，他们购买Y产品的可能性有多大？最后，产品Y的提升度是多少？换句话说，仅基于Y产品的受欢迎程度，有人与X一起购买Y的可能性有多大。模型还可以使用购买、社交媒体互动等数据来预测你会喜欢哪种类型的产品。这使其区别于单纯的数据分析，因为模型在寻找相似性，但程序员没有要求特定的输出。也许程序员甚至不知道该组的某些特征或特点。也许通过无监督机器学习，数据告诉我们两种类型的客户之间存在高度相关性。这些相关性在我们周围不断发生，不同人群之间存在相似性。有时，需要一个好的计算机模型来发现数据中的模式。机器学习可以在没有计算机和良好建模帮助的情况下无法看到的相似性。营销领域的数据科学家已经在使用统计学来改进他们的在线商店，如果你想跟上在线零售的步伐，那么建议开始阅读如何利用数据识别产品之间的相似性和趋势，将机器学习作为你的工具。

## 金融

金融行业正在看到机器学习使用量的增加。使用数据科学和机器学习模型使金融机构的决策过程更快、更高效。机器学习的可能性和应用可能被误解，这意味着它在金融领域往往被利用不足或被滥用。曾经繁琐且需要数百小时人工工作的工作，现在可以由计算机在几分钟内完成。一个常见的例子是使用机器学习进行呼叫中心和客户服务工作。许多曾经需要人工操作员的任务，现在可以通过电话与一个设计用于机器学习的机器人完成。除了客户服务，银行现在可以处理和分析来自数千名客户的合同和财务信息，这些工作原本劳动密集——用于创建信用报告和预测客户违约贷款的可能性。机器学习技术可以在银行决定是否向个人贷款之前查看借款人的交易历史。机器学习也被用于欺诈预防。它使金融行业更加安全。机器学习提高了银行检测交易中欺诈迹象的模式的能力。与派人监控交易并寻找欺诈迹象不同，机器学习模型可以从欺诈数据中学习，通过自动筛选数百万笔客户交易来发现模式。

## 垃圾邮件检测

一个相对简单的机器学习工具的常见示例是垃圾邮件检测。如果我们使用监督学习，定义相关变量，那么模型将在接收到的电子邮件中寻找某些特征。模型可能会寻找某些关键词或短语，以检测电子邮件是否为垃圾邮件。像“买”或“省钱”这样的词可能会让你的收件箱知道你何时收到垃圾邮件。这种方法的问题是，有很多情况下这些词不一定意味着垃圾邮件。可能有其他关键词或词语组合我们会忽略。这就是强化学习发挥作用的地方。有很多特征可能表明是垃圾邮件，其中一些我们甚至可能无法解释。强化学习将允许模型自行发现这些模式，而无需明确指导。相反，我们告诉模型它何时正确识别了垃圾邮件。有时我们会在收件箱中发现一条模型没有分类为垃圾邮件的电子邮件，所以我们手动将其移动到垃圾邮件文件夹。现在模型知道这条消息是垃圾邮件，这条数据被添加到模型中以改进下次的预测。因此，随着时间的推移，机器在获得更多相关数据时会不断改进。这种类型的机器学习被称为分类。我们的输出落在离散类别中。在统计学中，离散变量是只能在有限数量的类别中识别的变量。离散变量的示例是汽车经销商一周内销售的汽车数量。它是离散的，因为汽车经销商不能卖出半辆车。变量必须是整数。
