# C. Short Long Term Memory

Short-term, long-term memory is a type of recurrent neural network (RNN). LSTM (Sepp Hochreiter et al [4]) are designed for learning and classifying sequences. Networks aim to solve the problem of fading gradients by using gates to select the information to update and forget irrelevant details [3]. Sensitivity to time inputs makes LSTM networks better than RNN for data analysis tasks.

Architecture: The architecture of the LSTM (Sepp Hochreiter et al [4]) is shown below. An LSTM unit has a cell state, input gate, exhale valve, and bypass valve in addition to the state of the RNN. The entry gates and offsets control how the new value in the cell enters. Likewise, the weights and offsets for the output gate control the extent to which the value remains in the cell and is used to calculate the output activation of the LSTM-Block [4].

# D. Gated Recurrent Unit

The gated recurrent unit (GRU) is a gating mechanism in recurrent network (RNN), similar to the LSTM block without the output gate. Proposed (Jun Chung et al [5]) to solve the problem of the vanishing gradient that can occur with such recurrent networks. It can be thought of as a type of LSTM block which is as similar and in some cases gives similar results.
