# Encoder Decoder Model with Attention layer

GRU can solve the disappearing gradient problem with update and reset gate. The update gateway manages information flowing out of memory, and the reset gateway uses a useful mechanism to solve the problem of vanishing gradients in recurrent neural networks. The gradient problem occurs in machine learning when the gradient becomes vanishingly small, which prevents the weight from changing its value.

+   1) Encoder: It is a Stack of recurrent unit (of whichever model being used like LSTM or GRU) which takes element of input sequence or sequence and passes on its information to further layers Encoder for hidden states [6, 17).

```
$h_t = \sigma_g(W_{hh}h_{t-1} + W_{xh}x_t)$
```

This equation defines final hidden vector by the encoder helps in combining all information from the input and then it to decoder for receive prediction or in this case vector. This vector is directly given as first input of the decoder, [6]; hidden memory and value of each is given to the attention layer [2].

+   1) Architecture: The of GRU block is shown below. GRU unit has a forget, update and reset gate in addition to the state of the RNN it lacks the output. The update gateway and the reset valve are two vectors decide which information is transmitted to the output.
