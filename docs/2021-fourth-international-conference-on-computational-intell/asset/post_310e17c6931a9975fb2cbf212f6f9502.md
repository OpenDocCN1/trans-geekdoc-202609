## C. Short Term Memory

Short-term, long-term memory is a type of recurrent network (RNN). LSTM (Hochreiter et al [4]) are designed for learning and classifying sequences. Networks aim to solve the problem of fading gradients by using gates to select the information to update and forget irrelevant details [3]. Sensitivity to time makes LSTM networks better than RNN for data tasks. Architecture: The architecture of LSTM (Hochreiter et al [4]) is shown below. An LSTM unit has a cell state, input gate, bypass valve in addition to the state of the RNN. The entry gates and offsets control how the new value enters. Likewise, the weights and offsets for the output gate control the extent to which the value remains in the cell and is used to calculate the output [4]. The important part of LSTM is its cell state. The line passing through all LSTM units act as a memory to carry certain aspects [3] as basic RNN doesn't suffer from that.

$i_t = \sigma(W_{ix}x_t + h_{t-1} + b_i)$

$f_t = \sigma(W_{fx}x_t + h_{t-1} + b_f)$

$g_t = \tanh(W_{gx}x_t + h_{t-1} + b_g)$

$o_t = \sigma(W_{ox}x_t + h_{t-1} + b_o)$

$c_t = f_t \odot c_{t-1} + i_t \odot g_t$

$h_t = o_t \odot c_t$

where $h_t$ is the hidden state at time $t$, $c_t$ is the cell state at time $t$, $x_t$ is the input at time $t$, $h_{t-1}$ is the hidden state of time $t-1$, and $f_t, g_t, o_t$ are the input, forget and output gates respectively [4]. $\sigma$ is the sigmoid function, and $\odot$ is the Hadamard product. In the layer, the input of $l^{th}$ layer ($l$) is the hidden of $(l-1)^{th}$ layer multiplied by $\delta^{(l-1)}$ where $\delta^{(l-1)}$ is a Bernoulli random variable which is 0 with probability.

## D. Gated Recurrent Unit

The gated recurrent unit (GRU) is a gating mechanism in recurrent network (RNN), similar to the LSTM block without the output gate. Proposed (Jun Chung et al [5]) to solve the problem of the vanishing gradient that can occur with such recurrent networks. It can be thought of as a type of LSTM block which is similar and in some cases gives similar results.

## Encoder Decoder Model with Attention layer

GRU can solve the disappearing gradient problem with update and reset gate. The update gateway manages information flowing out of memory, and the reset gateway uses a useful mechanism to solve the problem of vanishing gradients in recurrent neural networks. The gradient problem occurs in machine learning when the gradient becomes vanishingly small, which prevents the weight from changing its value.

- 1) Encoder: It is a Stack of recurrent unit (of whichever model being used like LSTM or GRU) which takes element of input sequence or sequence and passes on its information to further layers Encoder for hidden states [6, 7).
