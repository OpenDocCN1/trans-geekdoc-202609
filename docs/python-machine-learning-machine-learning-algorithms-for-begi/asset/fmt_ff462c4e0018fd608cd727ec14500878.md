
4- The algorithm training: This is the actual step where the machine learning action occurs. In other words, this step is the core and the realization of the learning process. First, we provide the algorithms a ready, cleansed and healed data from the steps one and two. Then, information is extracted. This step creates formats that are ready to be applied and used by the machine in the next steps. Remember that in the unsupervised learning we do not need the training step. 5- Algorithm Testing: In this step, we have our algorithm ready to be tested and applied to other datasets in order to extract information, utilizing the knowledge gained in the previous step. In case we are not satisfied on the results, we can go back to step 3 and make some changes that tune and affect the flow of the process, in which updated and better results are gained. 6- Algorithm programming: This is simply the stage where you choose the suitable tool or programming language to write the algorithm and make the real program.
