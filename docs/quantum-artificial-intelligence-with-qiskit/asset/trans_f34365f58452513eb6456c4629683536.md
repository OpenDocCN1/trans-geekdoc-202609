在应用 Grover 算法的放大步骤之前，我们将输出还原为输入。我们使用 qiskit 的 `inverse` 命令通过函数定义逆操作。

```python
def rules_inv():
    qc = rules()
    qc_inv = qc.inverse()
    qc_inv.name="RULES_INV"
    return qc_inv
```
