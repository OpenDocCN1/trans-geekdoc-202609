# 19.3.2 QFT for three qubits

For $F_3$ we need to define phase gate on three qubits $|x_3x_2x_1angle$ and a swap operation of the first and last. The swap operation is simply the swap of the value of $x_1$ with the value of $x_3$

```
$F_3 = \frac{1}{\sqrt{8}} \left(|0\rangle + e^{-2\pi i \cdot x_1}|1\rangle\right) \otimes \left(|0\rangle + e^{-2\pi i \cdot x_2}|1\rangle\right) \otimes \left(|0\rangle + e^{-2\pi i \cdot x_3}|1\rangle\right) \quad (19.22)$
```

The circuit is represented as (see Figure 19.3)

```
qc = QuantumCircuit(3)
qc.h(0)
qc.cp(pi/2, 1, 2) # CROT from qubit 1 to qubit 2
qc.cp(pi/4, 1, 3) # CROT from qubit 1 to qubit 3
qc.cp(pi/4, 0, 2) # CROT from qubit 0 to qubit 2
qc.h(1)
qc.cp(pi/2, 0, 1) # CROT from qubit 0 to qubit 1
qc.h(0)
qc.swap(0,2)
```

# 19.3.3 QFT for Four qubits

The circuit for four qubits is represented as (see Figure 19.4)

```
qc = QuantumCircuit(4)
qc.h(3)
qc.cp(pi/2, 2, 3) # CROT from qubit 2 to qubit 3
qc.cp(pi/4, 1, 3) # CROT from qubit 1 to qubit 3
qc.cp(pi/8, 0, 3) # CROT from qubit 0 to qubit 3
qc.barrier()
qc.h(2)
qc.cp(pi/2, 1, 2) # CROT from qubit 1 to qubit 2
qc.cp(pi/4, 0, 2) # CROT from qubit 0 to qubit 2
qc.barrier()
qc.h(1)
qc.cp(pi/2, 0, 1) # CROT from qubit 0 to qubit 1
qc.barrier()
qc.h(0)
qc.barrier()
qc.swap(0,3)
qc.swap(1,2)
```
