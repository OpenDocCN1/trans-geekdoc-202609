## 23.3 SPSA OPTIMIZER

Simultaneous Perturbation Stochastic Approximation (SPSA) optimizer performs stochastic gradient approximation (https://www.jhuapl.edu/SPSA/), which requires only two measurements of the loss function, regardless of the dimension of the optimization problem [13]. The goal is to find

```python
$w^{*} = \arg_{w} \min L(w) \quad (23.13)$
```

with the gradient operator

```python
$\nabla = \begin{bmatrix} \frac{\partial}{\partial w_{1}}, & \frac{\partial}{\partial w_{2}}, & \dots, & \frac{\partial}{\partial w_{D}} \end{bmatrix}^{T}$
```

```python
$g(w) = \nabla L(w) = \begin{bmatrix} \frac{\partial L}{\partial w_{1}}, & \frac{\partial L}{\partial w_{2}}, & \dots, & \frac{\partial L}{\partial w_{D}} \end{bmatrix}^{T}$
```

SPSA use the iterative process with $\tau$ indicating the iteration starting at $\tau=1$ with

```python
$w_{\tau+1} = w_{\tau} - \eta_{\tau} \cdot \hat{g}(w_{\tau}) \quad (23.14)$
```

with $\eta_{\tau}$ the learning rate that decreases with $\tau$ and $\hat{g}(w_{\tau})$ estimation of the gradient $\hat{g}(w_{\tau})$ with

```python
$\hat{g}_{\tau} = \frac{L(w_{\tau} + c_{\tau} \cdot \Delta_{\tau}) - L(w_{\tau} - c_{\tau} \cdot \Delta_{\tau})}{2c_{\tau} \cdot \Delta_{\tau}} \quad (23.15)$
```

$\Delta_{\tau}$ is a random perturbation vector and $c_{\tau}$ is a small positive number that decreases with $\tau$. The number of loss function measurements needed in the SPSA method for each is 2, independent of the dimension. SPSA with the random search direction does not follow the gradient path but approximates it. Using a variational classifier on 1 quantum classifier SPSA is the most recommended choice it can be used in the presence of noise.

```python
from qiskit.utils import algorithm_globals
algorithm_globals.random_seed = 3142

import numpy as np
np.random.seed(algorithm_globals.random_seed)

from qiskit_machine_learning.datasets import ad_hoc_data
TRAIN_DATA, TRAINING_LABELS, TEST_DATA, TEST_LABELS = (
    ad_hoc_data(training_size=10,
    test_size=5,
    gap=0.3,
    onehot=False)
)

from qiskit.circuit.library import ZZFeatureMap, TwoLocal
FEATURE_MAP = ZZFeatureMap(feature_dimension=2, reps=2)
VAR_FORM = TwoLocal(2, ['rz', 'rz'], 'cz', reps=2)
AD_HOC_CIRCUIT = FEATURE_MAP.compose(VAR_FORM)

from sklearn.preprocessing import OneHotEncoder
encoder = OneHotEncoder()
training_labels_oh = encoder.transform(TRAIN_LABELS.reshape(-1, 1)).toarray()
test_labels_oh = encoder.transform(TEST_LABELS.reshape(-1, 1)).toarray()

from qiskit.algorithms.optimizers import SPSA

class OptimizerLog:
    """to store optimizer's intermediate results"""
    def __init__(self):
        self.evaluations = []
        self.parameters = []
        self.costs = []
    def update(self, evaluation, parameter, cost, _stepsize, _accept):
        """Save intermediate results. Optimizer passes five values
        but we ignore the last two."""
        self.evaluations.append(evaluation)
        self.parameters.append(parameter)
        self.costs.append(cost)
```

## 24.1 EPILOGUE

Quantum computation with the quantum gate model is based on principles to speed up the computation that lead to quantum advantage

- Grover's algorithm can speed up the search quadratically for a given number of solutions.
- The QFT can determine the period of a wave or be the basis of the phase estimation algorithm.
- Variational Classifier can compute functions in extremely high dimensional space that cannot be easily solved by conventional computers.

Most machine learning algorithms suffer from the input destruction problem [1]. Efficient preparation of data is possible in part for sparse data [39]. However, the input destruction problem has not yet been solved, and theoretical speeds are usually analyzed [94] by ignoring the input problem, which is the main bottleneck for data encoding. Linear algebra-based quantum machine learning is based on quantum gates that achieve theoretical exponential speed over their classical counterparts and are subroutines that are essential for machine learning. Basic quantum linear algebra subroutines use a quantum coprocessor for extensive and intractable routines in machine learning. Such “mathematical” quantum coprocessors can be used on a conventional computer.

Quantum supremacy means that programmable quantum devices can solve a problem that no classical computer can solve in any feasible amount of time. Quantum computers will dominate when enough qubits are available.
