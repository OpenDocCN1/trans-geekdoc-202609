```python
def qft2():
    qc = QuantumCircuit(2)
    qc.h(1)
    qc.cp(pi/2, 0, 1) # CROT from qubit 0 to qubit 1
    qc.h(0)
    qc.swap(0,1)
    qc.name="QFT_2"
    return qc
```

## 19.3.2 QFT for three qubits

For $F_3$ we need to define phase gate on three qubits $|x_3x_2x_1\rangle$ and a swap operation of the first and last. The swap operation is simply the swap of the value of $x_1$ with the value of $x_3$

```math
$F_3 = \frac{1}{\sqrt{8}} \left(|0\rangle + e^{-2\pi i \cdot x_1}|1\rangle\right) \otimes \left(|0\rangle + e^{-2\pi i \cdot x_2}|1\rangle\right) \otimes \left(|0\rangle + e^{-2\pi i \cdot x_3}|1\rangle\right) \quad (19.22)$
```

The circuit is represented as (see Figure 19.3)

```python
qc = QuantumCircuit(3)
qc.h(0)
qc.cp(pi/2, 1, 2) # CROT from qubit 1 to qubit 2
qc.cp(pi/4, 1, 3) # CROT from qubit 1 to qubit 3
qc.cp(pi/4, 0, 2) # CROT from qubit 0 to qubit 2
qc.h(1)
qc.cp(pi/2, 0, 1) # CROT from qubit 0 to qubit 1
qc.h(0)

```

## 19.3.4 QFT Costs

The first term requires one Hadamard gate, the second requires one Hadamard gate and a phase gate. Each following term requires an additional phase gate. Summing up

$1 + 2 + 3 + \cdots + (m-1) + m = \frac{m(m+1)}{2} = O(m^2)$.

The costs of QFT are $O(m^2)$ compared to the cost of $O(2^m)$ on a conventional computer, the costs of QFT are exponentially less.

# Phase Estimation

The Kitaev's Phase Estimation Algorithm (also referred to as quantum eigenvalue estimation algorithm) is a quantum algorithm to estimate the phase (or eigenvalue) of an eigenvector of a unitary operator. We explain the algorithm and indicate an example of the determination of the eigenvalue of the $T$ gate. Then we introduce the quantum counting algorithm that is based on the quantum phase estimation algorithm and on the Grover's search algorithm. Quantum counting algorithm is a quantum algorithm for counting the number of solutions for a given search problem.

## 20.1 KITAEV'S PHASE ESTIMATION ALGORITHM

Given a unitary operator $U$ on $m$ qubits with an eigenvector $|u\rangle$ with an unknown eigenvalue $e^{2\pi i\theta}$, we want to determine the phase $\theta$ [48], [47]. If we apply $U$ to $|u\rangle$ we get

```math
$U|u\rangle = e^{2\pi i\theta}|u\rangle. \quad (20.1)$
```

if we apply $U^w$ to $|u\rangle$ we get

```math
$U^w|u\rangle = U^{w-1}\cdot(e^{2\pi i\theta}|u\rangle) = (e^{2\pi i\theta})^w \cdot |u\rangle = e^{2\pi i\theta w}|u\rangle. \quad (20.2)$
```

However, we will not gain any information because $|u\rangle$ are equivalent states and they represent the same state when measurement is performed. Instead of the unitary operator $U^w$, we use controlled $U^w$ operator. If the control qubit is then $U$ applied to the target qubits, $CU^w$ is reversible and defines an injective mapping onto qubits that

```math
$CU^w|0\rangle = |0\rangle, CU^w|1\rangle = (e^{2\pi i\theta})^w \cdot |u\rangle.$
```

The QFT is represented as tensor product of single-qubit operations. The QFT can be factored into tensor product of $m$ single-qubit operations,

```math
$|y\rangle = F_m \cdot |x\rangle = \frac{1}{\sqrt{2^m}} \sum_{y \in B^m} e^{2\pi i \cdot y \cdot x} \cdot |y\rangle = \frac{1}{\sqrt{2^m}} \left(|0\rangle + e^{2\pi i \cdot x_1}|1\rangle\right) \otimes \left(|0\rangle + e^{2\pi i \cdot x_2}|1\rangle\right) \otimes \cdots \otimes \left(|0\rangle + e^{2\pi i \cdot x_m}|1\rangle\right).$
```

If we set $\theta = 0.x_m \cdots x_1$, we can rewrite the equation as

```math
$|y\rangle = F_m \cdot |x\rangle = \frac{1}{\sqrt{2^m}} \sum_{y \in B^m} e^{2\pi i \cdot y \cdot \theta} \cdot |y\rangle = \frac{1}{\sqrt{2^m}} \left(|0\rangle + e^{2\pi i \cdot \theta^{m-1}}|1\rangle\right) \otimes \left(|0\rangle + e^{2\pi i \cdot \theta^{m-2}}|1\rangle\right) \otimes \cdots \otimes \left(|0\rangle + e^{2\pi i \cdot \theta^{0}}|1\rangle\right).$
```

For $m$ qubits, we define $CU_{j+1}$ in the following way. For $j \in \{0, 1, 2, \cdots, m-1\}$, the control qubit $j+1$ of the $m$ qubits is set, $CU_{j+1}$ is applied to the target $|u\rangle$, otherwise not. The first step of the algorithm is

```math
$|0^{\otimes m}\rangle|u\rangle$
```

with $|u\rangle$ being the eigenvector of $U$. In the first step of the algorithm we build a superposition of $m$ controls

```math
$H_m \cdot |0^{\otimes m}\rangle|u\rangle = \frac{1}{\sqrt{2^m}} \sum_{x \in B^m} |x\rangle|u\rangle = \frac{1}{\sqrt{2^m}} \left(|0\rangle + |1\rangle\right) \otimes \cdots \otimes \left(|0\rangle + |1\rangle\right) \cdot |u\rangle.$
```

In the second step we apply $CU_{j+1}$ operators to the target $|u\rangle$

```math
$\prod_{j=0}^{m-1} CU_{j+1} \cdot \frac{1}{\sqrt{2^m}} \left(|0\rangle + |1\rangle\right) \otimes \cdots \otimes \left(|0\rangle + |1\rangle\right) \cdot |u\rangle = \frac{1}{\sqrt{2^m}} \left(|0\rangle + e^{2\pi i \cdot \theta^{m-1}}|1\rangle\right) \otimes \cdots \otimes \left(|0\rangle + e^{2\pi i \cdot \theta^{0}}|1\rangle\right) \cdot |u\rangle.$
```

In the third step we apply inverse QFT to the $m$ controls

```math
$F_m \cdot \frac{1}{\sqrt{2^m}} \sum_{y \in B^m} e^{2\pi i \cdot y \cdot \theta} \cdot |y\rangle = F_m \cdot \frac{1}{\sqrt{2^m}} \sum_{y \in B^m} e^{-2\pi i \cdot y \cdot \theta} \cdot |y\rangle = |x\rangle|u\rangle.$
```

In the fourth step we measure the first register composed of $m$ control qubits and estimate $\theta$

```math
$$\theta = 0.x_m \cdots x_2x_1 = \frac{x}{n}=\frac{x}{2^m}.$$
```
