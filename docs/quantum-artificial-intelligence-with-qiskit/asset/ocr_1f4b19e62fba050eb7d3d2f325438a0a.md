# 2.9 PHASE KICK-BACK

If we apply CX gate to the target value $\frac{|0angle}{\sqrt{2}}$ with the control qubit $|1angle$ we get

```
$CX|1\rangle \cdot \left(\frac{|0\rangle}{\sqrt{2}}\right)=|1\rangle \cdot \left(\frac{X|0\rangle - X|1\rangle}{\sqrt{2}}\right)$$
$$CX|1\rangle \cdot \left(\frac{|0\rangle}{\sqrt{2}}\right)=|1\rangle \cdot \left(-1\right) \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)$$
$$CX|1\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)=-|1\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)$
```

For the control qubit $|0angle$ does nothing,

```

```

We say that the value (phase) is being "kicked back" to the control register.
