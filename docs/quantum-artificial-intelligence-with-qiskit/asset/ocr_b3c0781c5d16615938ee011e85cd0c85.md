# 19.3 QFT for two qubits

We demonstrate the definition of the quantum circuit on $F_2$

```
$F_2 = \frac{1}{\sqrt{4}} \cdot (|0\rangle + e^{2\pi i+0.x_1}|1\rangle) \otimes (|0\rangle + e^{2\pi i+0.x_2}|1\rangle) \quad (19.19)$
```

on the input $|x_2x_1\rangle$. We define the circuit recursively on the back. Because

```
$e^{2\pi i+0.x_1} = e^{2\pi i/2^1} = (-1)^{x_1}$
```

it follows that

```
$\frac{1}{\sqrt{2}} \cdot (|0\rangle + e^{2\pi i+0.x_1}|1\rangle) = \frac{1}{\sqrt{2}} \cdot (|0\rangle + (-1)^{x_1}|1\rangle)$
```

can be represented by

```
$(I_1 \otimes H_1) \cdot |x_2x_1\rangle$.
```

The "first" operation can be represented as

```
$\frac{1}{\sqrt{2}} \cdot (|0\rangle + e^{-2\pi i+0.x_2}|1\rangle) = \frac{1}{\sqrt{2}} \cdot (|0\rangle + e^{-2\pi i/2^2}|1\rangle \cdot e^{-2\pi i/2^2}|11\rangle)$
```

and can be represented as

```
$CP_1 \cdot (H_1 \otimes I_1) \cdot |x_2x_1\rangle$.
```

We together get

```
$(I_1 \otimes W_1) \cdot CP_2 \cdot (W_1 \otimes I_1) \cdot |x_2x_1\rangle = \nfrac{1}{\sqrt{4}} \cdot (|0\rangle + e^{-2\pi i+0.x_1}|1\rangle) \otimes (|0\rangle + e^{-2\pi i+0.x_2}|1\rangle) \quad (19.20)$
```

The arrangement of the bits is not correct. This is because the last qubit in the result uses the first input qubit and so on. To correct the error we have to apply swap gate SWAP . The decomposition is given by

