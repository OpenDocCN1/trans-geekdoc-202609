## 1.2.4 Tree Search

The search is performed from an initial state through the following states until goal state is reached. A search tree is represented by nodes and edges. Each node represents a state, and each edge represents a transition from one state to another. The initial state defines the root of the tree. In contrast to computer science, the root of a tree structure is at the top and the leaves are at the bottom. Every node beside the root has a unique parent from which it was reached. The parent is the node above it and is connected by an edge. Each parent $v$ has $B_v$ children, and at the same depth $k$ there are $B^k$ nodes. For a tree with constant branching factor $B$, at level $k$, there are $B^k$ nodes. Breadth-first search performs level-wise search. All nodes at a level have been visited before visiting a node at the next. Depth-first search expands the deepest node in the search tree until a goal is reached or all nodes are impasse.

## 1.2.5 Informed Search

Heuristic search is based on a heuristic function $h(v)$ that estimates the cheapest cost from node $v$ to the goal. We will demonstrate the principles of heuristic $h(v)$ on the 8-puzzle example, and "Manhattan distance" [73, 78, 61] counts the number of misplaced tiles in each state compared to desired goal. While this heuristic fails to take into account all available information such as the distance tiles must move to reach a position of the desired state, "Manhattan distance" sums all the distances by which the tiles are out of place, also called "Manhattan distance," is often better than the "number of misplaced tiles". Greedy-first search expands the node $v$ that is closest to the goal according to heuristic function $h(v)$. Of the $B$ children node $v$ is chosen $\min(h(v_i))$, $1\leq i\leq B$.

Like depth-first search follows a single path to the goal, it always expands the deepest node in the search according to $h(v)$ until a goal is reached or all nodes are impasse. $A$ search evaluates the nodes through a function $f(v)$ that is composed of the heuristic function $h(v)$ and the function $g(v)$ that estimates the cost of reaching node $v$ from the root node representing the initial state. Finally $A^*$ is equivalent to $A$ search with the constraint that the function $h(v)$ is an admissible heuristic, it never overestimates the cost to reach the goal. General invention of heuristic functions is difficult.

## 1.3 MACHINE LEARNING

Many of the ML techniques are derived from the efforts of psychologists and biologists to make more sense of human learning through computational models [7, 121]. There are some parallels between humans and ML. During learning, humans attempt to gain some knowledge, which involves modification of behavioral tendencies by experience. In ML, we can distinguish between supervised learning and unsupervised learning. In supervised learning, the algorithm is presented with examples of inputs and their desired outputs. The goal is to learn a general rule that maps inputs to outputs. Supervised learning is frequently referred to as learning with a teacher because the desired outputs are indicated by some kind of teacher. Consequently, unsupervised learning is referred to as learning without a teacher. In unsupervised learning, the algorithm groups information that is primarily represented by vectors into groups. The algorithm attempts to find the hidden structure of unlabeled data; clustering is an example of such an algorithm [121]. Statistical ML is mostly based on distributed representation using vector representation.

### 1.3.1 Vector Representation

In ML a subsymbolical or distributed representation is used. One form of distributed representation corresponds to vectors. A vector $\mathbf{x}$ of dimension $D$ is represented as:

$$\mathbf{x} = \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_D \end{pmatrix} = (x_1, x_2, \dots, x_D)^T,$$

with each dimension $x_i$ representing a value like for a real number. One can measure the distance between two $D$ dimensional vectors by a distance function like the Euclidean distance function:

$$d(\mathbf{x}, \mathbf{y}) = ||\mathbf{x} - \mathbf{y}|| = \sqrt{|x_1 - y_1|^2 + |x_2 - y_2|^2 + \dots + |x_D - y_D|^2},$$

or the Taxicab or Manhattan metric $d_1$:

$$d_1(\mathbf{x}, \mathbf{y}) = ||\mathbf{x} - \mathbf{y}|| = |x_1 - y_1| + |x_2 - y_2| + \dots + |x_D - y_D|,$$

The "Manhattan distance" sums all the distances by which the tiles are out of place, also called "Manhattan distance," is often better than the "number of misplaced tiles".
