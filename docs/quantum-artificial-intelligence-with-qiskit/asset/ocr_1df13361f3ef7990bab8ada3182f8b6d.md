# 6.3.2 Un-Computation

In quantum computation, it is not possible to reset the information to the pattern representing the initial state. Instead, we un-compute the output back to the input as indicated in the following:

```
from qiskit import QuantumCircuit,QuantumRegister, Aer, execute
from qiskit.visualization import plot_histogram
from qiskit.circuit.library import MCXGate
from qiskit.quantum import Info StateVector
```

```
qc = QuantumCircuit(6)
#Input 0,1,4
qc.h(0)
qc.h(1)
qc.h(4)
qc.barrier()
```
