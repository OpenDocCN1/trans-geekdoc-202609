# 18.1.2 Amplitude Coding

An operation that would produce a copy of an arbitrary quantum state such as $|\psiangle$ is not possible; we cannot copy non-basis states because of the linearity of quantum mechanics. We can to some extent simulate the copy of non-basis states using $qRAM$, with the complexity $O(n\log(m))$ where $n$ is the dimension of the resulting superposition vector [119]. We have a basis state of $m$ qubits $|xangle = |0\dots 1angle$ of dimension $2^m$ in Hilbert space into a $n$-dimensional superposition

We divide the binary vector of the dimension $2^m$ into $v$ parts, each substraining $code_i$, a real number with $n=2^m/v$.

```
$|0\dots1\rangle\cdot\frac{1}{\sqrt{n}}\sum_{i=1}^n|i\rangle\to|0\dots1\rangle\cdot\frac{1}{\sqrt{n}}\sum_{i=1}^n\alpha_i|i\rangle. \quad (18.3)
```

We add an auxiliary state $|0^nangle$

```
$|code_1\dotscode_v\rangle\cdot\frac{1}{\sqrt{n}}\sum_{i=1}^n|i\rangle\to|code_1\dotscode_v\rangle\cdot\frac{1}{\sqrt{n}}\sum_{i=1}^n|i\rangle|0^n\rangle. \quad (18.4)
```

For each $code_i$ represents a binary representation of a fractional real number that is smaller than one

```
$code_i = \alpha_i < 1$.
```

For each $value_i$, we perform a controlled rotation $R(\alpha_i)$

```
$(C\cdot\alpha_i|1|+\sqrt{1-C^2\cdot\alpha_i^2}|0\rangle)
```

and perform a measurement. By measuring the corresponding auxiliary register with the result 1 we know that the resulting state is correct. We repeat the procedure at least $n$ times with the resulting state

```
$|0\dots1\rangle\cdot\sum_{i=1}^n\alpha_i|i\rangle. \quad (18.6)
```

The resulting complexity of the routine is $O(n)$, which is the same as reading a classic information. However to read classically $m$ vectors of dimension $n$, the complexity is $O(n\cdot m)$, using $qRAM$ ignoring the preparation cost is $O(n\log(m))$. The described routine is non-reversible since it is based on measurement.
