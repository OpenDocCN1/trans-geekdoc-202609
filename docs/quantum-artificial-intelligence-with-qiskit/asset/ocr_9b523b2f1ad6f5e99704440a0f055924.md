# 5.1.1 Quantum Oracle

We represent $n$ states in a superposition, each state has the same positive amplitude. A parallel computation is applied to all the $n$ states, and the state with the solution $o(x) = 1$ is marked by a minus sign, the amplitude is now negative. We then apply a linear operation that is based on Householder reflection; by the reflection the value of the marked amplitude grows linearly.

For the function $o(x)$, the solution is encoded by $(-1)^{o(x)}$, the sign of the amplitude. To see why the solution is encoded by $(-1)^{o(x)}$, we indicate the derivative. The unitary operator $T$ represents the quantum oracle function $o(x)$ that determines if the configuration is the goal

```
$T \cdot |xangle|cangle = |xangle|o(x) \oplus cangle$
```

The auxiliary qubit $c$ is set to zero, and the state is represented by $m$ qubits $|0^mangle$. First, we set qubits representing the states and the auxiliary qubit in superposition for $m+1$ qubits $H_{m+1}$, and then we execute the Hadamard gate operator $T$

```
$T \cdot H_{m+1} \cdot |0^mangle|1angle=\\frac{1}{\sqrt{2^{m+1}}} \cdot \sum_{x \in B^m} T \cdot |xangle|0angle - \frac{1}{\sqrt{2^{m+1}}} \cdot \sum_{x \in B^m} |xangle|o(x) \oplus 1angle=\\frac{1}{\sqrt{2^{m+1}}} \cdot \sum_{x \in B^m} |xangle|o(x) \oplus 0angle - \sum_{x \in B^m} |xangle|o(x) \oplus 1angle \quad (5.2)
```

There are four possible cases with the state $|\xiangle$ being the solution:

```
$T \cdot |xangle|0angle = |xangle|o(x) \oplus 0angle = |xangle,\nT \cdot |xangle|1angle = |xangle|o(x) \oplus 1angle = -|xangle,\nT \cdot |\xiangle|0angle = |\xiangle|f(\xi) \oplus 0angle = |\xiangle,\nT \cdot |\xiangle|1angle = |\xiangle|f(\xi) \oplus 1angle = -|\xiangle$.
```

It follows that

```
$$\frac{1}{\sqrt{2^{m+1}}} \cdot \left( \sum_{x \neq \xi} |x\rangle|0| + |\xi\rangle - \sum_{x \neq \xi} |x\rangle|1| - |\xi\rangle \right)\\\\frac{1}{\sqrt{2^m}} \sum_{x \in B^m} (-1)^{o(x)} \cdot |x\rangle \otimes \sqrt{\frac{(|0-|1|)}{\sqrt{2}}} . \quad (5.3)
```

The value of the function $o(x)$ is encoded by $(-1)^{o(x)}$, the operation is a phase kickback. We can set the auxiliary qubit $c = \frac{|0-|1\rangle}{\sqrt{2}}$ to zero by the Hadamard gate.
