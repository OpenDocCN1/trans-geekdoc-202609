The qubit is described by a vector $|x\rangle$ with complex numbers $\omega_1, \omega_2$ that represent the amplitude of each dimension

```
$|x\rangle = \omega_0 \cdot |0\rangle + \omega_1 \cdot |1\rangle$.
```

The vector has length with one

```
$|\omega_0|^22 + |\omega_1|^22 = 1 \rightarrow |||x|||^2 = 1$.
```

The unitary matrix $H$ (Hadamard matrix) performs the mapping in the ket notation

```
$H \cdot |0\rangle = \frac{1}{\sqrt{2}} |0\rangle + \frac{1}{\sqrt{2}} |1\rangle$
```

with the vector notation

```
$\frac{1}{\sqrt{2}} \left( \begin{array} 1 & 1 \ 1 & -1 \end{array} \right) \cdot \left( \begin{array} 1 \ 0 \end{array} \right) = \left( \begin{array} 1/\sqrt{2} \ 1/\sqrt{2} \end{array} \right)$.
```

Applying $H$ again results in

```
$H \cdot \left( \frac{1}{\sqrt{2}} |0\rangle + \frac{1}{\sqrt{2}} |1\rangle \right) = H \cdot \frac{1}{\sqrt{2}} |0\rangle + W \cdot \frac{1}{\sqrt{2}} |1\rangle = |0\rangle$
```

with the vector notation

```
$\frac{1}{\sqrt{2}} \left( \begin{array} 1 & 1 \ 1 & -1 \end{array} \right) \cdot \left( \begin{array} 1/\sqrt{2} \ 1/\sqrt{2} \end{array} \right) = \left( \begin{array} 1 \ 0 \end{array} \right).$.
```
