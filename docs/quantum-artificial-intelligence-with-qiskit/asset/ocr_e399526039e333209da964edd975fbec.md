# Symbolic State Representation

An economic symbolic representation of objects and attributes that can represent a state during problem solving is introduced. This representation is motivated by the biological what where principle and requires a low number of bits. Such an economical demanded representation is ideal for the current generation of quantum computers. We describe the search tree on which problem solving is based. Nodes and edges represent a search tree. Each node represents a state, and each edge represents a transition from one state to the following state. The path descriptors are the basis of quantum tree search. In a quantum tree search we represent all possible path descriptors simultaneously and use Grover's amplification algorithm to determine the solution.

# 7.1 BIT REPRESENTATION OF OBJECTS AND ATTRIBUTES

We represent $n$ symbols with $[log_2n]$ bits. To represent four symbols $A, B, C, D$ we require two bits with the following code: $A=00, B = 01, C = 10, D = 11$. To represent a string $B A D C$ we code each symbol at a corresponding position: $01 00 11 10$. In this representation the attribute is fixed, and the code descriptors of the object moves. Each object can have one or more attributes (adjectives), like position in one or two dimensions. In our case the attribute corresponds to the position in the representation. Instead of coding symbols we alternatively code the positions, for four positions we code the first position by 00, second position by 01, third position by 10 and fourth position by 11. A symbol would be represented by the order, to represent a string $D B A C$ with code $10 01 00 11$. $A$ at position 10 (the string), $B$ at position 01 (second position in the string), $C$ at position 11 (fourth position in the string), and $D$ at position 00 (first position in the string). In this representation the code descriptors of the object are fixed, and the attribute moves. In the case several attributes are present, it is more economical to represent the code fixed some attributes may change while the other remain fixed.
