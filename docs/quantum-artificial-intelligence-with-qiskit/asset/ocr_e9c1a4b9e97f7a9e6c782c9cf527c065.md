Each of the operators is represented as triples of description. The first element is the precondition, the world state that must be met for an operator to be applied. It can be true or false when variables become identified with the variables, which describe the state. The second element is the additions to the state description that are a result of applying the operator. The last element is the items that are removed from the state description to create a new state when the operator is applied. These operators obey the axiom since they specify what is true in one state of the world and exactly what has changed by performing some action by an operator. The problem of specifying which part of the description should change and which should not be called the frame problem [125].

Instead of operators, we can use simple rules. A rule [125, 88, 61] contains several “if” patterns and one or more “then” patterns. A pattern in the context of rules is an individual predicate that can be negated together with arguments. The rule can establish a new assertion by the “then” part, the conclusion whenever the “if” part, the premise, is true.
