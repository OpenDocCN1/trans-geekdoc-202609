In quantum computation is not possible to reset the information to the pattern representing the initial state. Instead we un-compute the back to the input before applying the application step of the Grover's algorithm. Because of the unitary evolution follows that

> $((L) \otimes I_1)^t \cdot (I \otimes T) \cdot (L) \otimes I_1)^t \cdot |\kappa^t, x, c)$

the computation can be undone and the corresponding part is marked by a negative sign using the auxiliary qubit

We use the qiskit inverse command inverse() to perform the inverse operation

```
def rules1_inv():
```
