# 22.2.1.1 Diagonalization

If the matrix $H$ is diagonal

```
$H = \begin{pmatrix} a_1 & 0 & \dots & 0 \ 0 & a_2 & \dots & \vdots \ \vdots & \vdots & \ddots & \vdots \ 0 & 0 & \dots & a_n \end{pmatrix} \quad (22.13)$
```

then its exponential can be obtained by exponentiating each entry on the main diagonal

```
$e^H = \begin{pmatrix} e^{a_1} & 0 & \dots & 0 \ 0 & e^{a_2} & \dots & 0 \ \vdots & \vdots & \ddots & \vdots \ 0 & 0 & \dots & e^{a_n} \end{pmatrix} \quad (22.14)$
```

This result also allows one to exponentiate diagonalizable matrices.

```
$H = U \cdot D \cdot U^{-1} \quad (22.15)$
```

and $D$ is diagonal, then

```
$e^H = U \cdot e^D \cdot U^{-1} \quad (22.16)$
```

# 22.2.1.2 Product Formulas

If the Hamiltonian $H$ can be written as

```
$H = \sum_{k=1}^l H_k \quad (22.17)$
```

and $H_k$ commute,

```
$H_j \cdot H_k = H_k \cdot H_j, \quad \text{for all } j, k$
```

then

```
$e^{-itH} = e^{-itH_1} \cdot e^{-itH_2} \cdot \dots \cdot e^{-itH_l} \quad \text{for all } t. \quad (22.18)$
```

General case: For general case of non-commuting $H_k$

```
$e^{-itH} \neq e^{-itH_1} \cdot e^{-itH_2} \cdot \dots \cdot e^{-itH_l} \quad \text{for all } t. \quad (22.19)$
```

For non-commuting $H_k$ the following asymptotic Suzuki-Trotter formula (Lie product formula) is true for real $t$.

```
$e^{-itH} = \lim_{m \to \infty} e^{-itH_1/m} \cdot e^{-itH_2/m} \cdot \dots \cdot e^{-itH_l/m} \quad (22.20)$
```

or we can write equivalently

```
$e^{-itH} = e^{-itH_1} \cdot e^{-itH_2} \cdot \dots \cdot e^{-itH_l} + O(t^2) \quad (22.21)$
```

For small $t$ the factorization is approximately valid,

```
$U_t = e^{-itH_1} \approx e^{-itH_2} \cdot \dots \cdot e^{-itH_l}. \quad (22.22)$
```
