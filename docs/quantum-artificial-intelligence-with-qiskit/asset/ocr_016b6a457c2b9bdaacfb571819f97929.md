The solution to the problem

$A = \left( \begin{array}{cc} 1 & -1/3 \ -1/3 & 1 \end{array} \right), \quad b = \left( \begin{array}{c} 1 \ 0 \end{array} \right).$

is represented by

$A^{-1} = \left( \begin{array}{cc} 3/5 & 1/5 \ 1/5 & 3/5 \ \end{array} \right), \quad x = \left( \begin{array}{c} 9/5 \ -3/5 \ \end{array} \right).$

with the normalized vector being

$\mathbf{x}_n = \frac{\mathbf{x}}{\|\mathbf{x}\|}} = \left( \begin{array}{c} 0.948683 \ 0.316228 \ \end{array} \right).$

# 22.4 CONSTRAINTS

In quantum we efficiently find the eigenvectors and eigenvalues by the Kitaev's phase estimation algorithm [39]. We will compute

$\mathbf{x} = A \cdot \mathbf{b} \qquad (22.38)$

or

$\mathbf{x} = A^{-1} \cdot \mathbf{b}. \qquad (22.39)$

We assume $A$ is Hermitian. In the case $A$ is Hermitian, we define

$A' = \left( \begin{array}{cc} 0 & A \ A^* & 0 \ \end{array} \right), \quad \mathbf{b}' = \left( \begin{array}{c} 0 \ b \ \end{array} \right), \quad \mathbf{x}' = \left( \begin{array}{c} x \ \end{array} \right). \qquad (22.40)$

and

$A' \cdot \mathbf{x}' = \mathbf{b}'. \qquad (22.41)$
