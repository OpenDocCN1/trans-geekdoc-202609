We can define QFT for two qubits as a function, calling the function with the command inverse computes the inverse QFT which see Figure 19.2 (c).

```
def qft2():
    qc = QuantumCircuit(2)
    qc.h(1)
    qc.cp(pi/2, 0, 1) # CROT from qubit 0 to qubit 1
    qc.h(0)
    qc.swap(0,1)
    qc.name="QFT_2"
    return qc
```

```
qc = QuantumCircuit(2)
qc.append(qft2().inverse(),range(2))
```
