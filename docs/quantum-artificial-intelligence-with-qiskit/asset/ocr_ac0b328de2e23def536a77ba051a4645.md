Figure 13.7 (a) The control qubit 2 ($c_1 = 1$) is entangled with the memory register [11] of the processing branch by the multi-controlled X (Toffoli) gate. The processing branch is split by the operator $CS_2$ ($p=2$), creating a new memory branch. (b) The resulting state is $|\psiangle = \frac{1}{\sqrt{3}}|0,0;0;1angle + \frac{1}{\sqrt{3}}|1,0;1;0angle + \frac{1}{\sqrt{3}}|1,1;1;0angle$.

The complete circuit is defined by

```
qc = QuantumCircuit(6,2)
#0-1 loading register
#2-3 control register
#4-5 storage, memory
qc.x(3)
qc.x(0)
qc.barrier()

qc.x(4)
qc.x(5)
qc.barrier()
qc.ccx(4,5,2)
qc.cu(1,2.3095941734075,pi,pi,0,2,3)
qc.ccx(4,5,2)
qc.barrier()
qc.x(4)
qc.x(5)
qc.cx(1,5)
qc.cx(0,4)
#Uncompute
qc.barrier()
```
