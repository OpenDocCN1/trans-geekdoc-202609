
# Quantum Lernmatrix ■ 209

Applying controlled operation phase with $N$ for present ones in the query vector and $count_j \le N$

```
$\frac{1}{\sqrt{2}} \cdot |0\rangle \left(\sum_{j=1}^{n} e^{i \frac{\pi \cdot count_j}{2}}} |count_j\rangle|unit_j\rangle\right) \otimes |query\rangle$
```

```
$\frac{1}{\sqrt{2}} \cdot |1\rangle \left(\sum_{j=1}^{n} e^{-i \frac{\pi \cdot count_j}{2}}} |count_j\rangle|unit_j\rangle\right) \otimes |query\rangle \quad (15.20)$
```

and applying the Hadamard gate to the control qubit we get the final result

```
$\left(\frac{1}{\sqrt{n}} \sum_{j=1}^{n} \cos(\frac{\pi \cdot count_j}{2 \cdot N}) |0,count_j\rangle|unit_j\rangle\right) \otimes |query\rangle$
```

```
$\left(\frac{1}{\sqrt{n}} \sum_{j=1}^{n} \sin(\frac{\pi \cdot count_j}{2 \cdot N}) |1,count_j\rangle|unit_j\rangle\right) \otimes |query\rangle \quad (15.21)$
```

The cost of one query is $O(n)$ and for $k=\log_2(n/4)$ queries $O(\log(n) \cdot n)$.

## 15.42 Example

In this example we state three patterns representing associations: $\mathbf{x_1} = (1,1,0,0,0,0,1)$, $\mathbf{y_1} = (1,1,0,0,0,0,1)$, $\mathbf{x_2} = (0,0,1,0,1,0,0)$, $\mathbf{y_2} = (0,0,1,0,1,0,0)$ and $\mathbf{x_3} = (0,0,0,1,1,0,1)$, $\mathbf{y_3} = (0,0,1,0,0,0,0,1)$. The weight matrix after the learning phase is represented by eight qubits (see Figures 15.12 and 15.13). After the entanglement of index qubits in superposition

| $|index_1\rangle = |111\rangle$ | $|index_2\rangle = |110\rangle$ |
| $|index_3\rangle = |101\rangle$ | $|index_4\rangle = |100\rangle$ |
| $|index_5\rangle = |011\rangle$ | $|index_6\rangle = |010\rangle$ |
| $|index_7\rangle = |001\rangle$ | $|index_8\rangle = |000\rangle$ |

with the weight vectors the following state is present, the state $count_j$ and $unit_j$ are represented by eight qubits [111], [112].

```
$\frac{1}{\sqrt{s}}(\sum_{j=1}^{s} |index_j\rangle|count_j\rangle|unit_j\rangle).$
```

With the query vector $\mathbf{x_q} = (1,1,0,0,0,0,0,0)$ we see (see Figure 15.13 (a))

```
$\frac{1}{\sqrt{s}}(\sum_{j=1}^{s} |index_j\rangle|count_j\rangle|unit_j\rangle) \otimes |000000111\rangle.$
```

Figure 15.2 Weight matrix represented by eight units after learning the correlation of the three patterns $\mathbf{x}_1 = (1, 1, 0, 0, 0, 0, 1, 0)$; $\mathbf{y}_1 = (1, 1, 0, 0, 0, 0, 1, 0)$, $\mathbf{x}_2 = (0, 1, 0, 1, 1, 0, 0, 0)$; $\mathbf{y}_2 = (0, 1, 0, 1, 1, 0, 0, 0)$ and $\mathbf{x}_3 = (0, 0, 1, 0, 0, 1, 0, 1)$, $\mathbf{y}_3 = (0, 0, 1, 0, 0, 1, 0, 1)$. ## 15.4.3 Applying Trojan Amplification Several Times

According to Trojanberger [112] applying control qubit sequential, $b$ times results in

$$\sum_{j=1}^8 \frac{1}{\sqrt{8}} \left( \cos\left(\frac{\pi \cdot count_j}{2 \cdot N}\right) \cdot |0\rangle\langle unit_j| \right) \otimes |00000011\rangle + \sum_{j=1}^8 \frac{1}{\sqrt{8}} \left( \sin\left(\frac{\pi \cdot count_j}{2 \cdot N}\right) \cdot |1\rangle\langle unit_j| \right) \otimes |00000011\rangle$$
