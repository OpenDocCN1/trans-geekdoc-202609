# 15.1.1 Learning and Retrieval

Initially, no information is stored in the associative memory. Because the information is represented in weights, all unit weights are initially set to zero. Let x be the query vector and y is the answer vector, the learning rule is:

```
$w_{ij}^{new} = \begin{cases} 1 & \text{if } y_i \cdot x_j = 1 \ 0 & \text{otherwise.} \end{cases} \quad (15.1)$
```
