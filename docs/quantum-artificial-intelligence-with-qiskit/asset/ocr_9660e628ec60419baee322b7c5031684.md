# 20.1.1 Example with $T$ Gate

The $T$ gate corresponds to the unitary matrix

```
$T = \begin{pmatrix} 1 & 0 \ 0 & e^{i\pi/4} \end{pmatrix}$
```

With the eigenvector $|1\rangle$ and the eigenvalue $e^{2\pi\theta}$

```
$U \cdot |u\rangle = T|u\rangle = e^{2\pi\theta} \cdot |u\rangle = e^{2\pi\theta} \cdot |1\rangle \quad (20.9)$
```

with the phase $\theta=rac{1}{8}$ since

```
$T|1\rangle = e^{2\pi\theta} = e^{i\pi/4} \cdot |1\rangle = e^{2\pi/4} \cdot |1\rangle$.
```

The phase estimation algorithm will write the phase of $T$ to $m$ qubits in our simple case $m=3$. The value of $m$ determines the precision of the result.

```
$\theta = x_0x_1x_2 = \frac{x}{2^3}$
```

The controlled $T$ gate is represented by the controlled phase gate $CP(\lambda)$ where $\lambda=\pi/4$. The circuit is composed of 4 qubits, qubits 0, 1, 2 represent the 3 qubits in the control register. The qubit 3 represents the eigenvector $|1\rangle$. The control register is mapped into superposition by Hadamard gates and the qubit 4 is initialized to the eigenvector $|1\rangle$ with the NOT gate. The control register controls the unitary operations $T$ applied to the target eigenvector $|1\rangle$ resulting in the Fourier representation of the three control qubits. To estimate the phase $\theta$, we perform the inverse QFT to the 3 control qubits and measure the three quits and estimate with $\theta$

```
$x = |q_2q_1q_0\rangle$
```

and

```
$\theta = \frac{x}{2^3}$
```
