# 21.3 SIMPLE EXAMPLE

In this example we implement a quantum Perceptron with $D=2$ and two control qubits ($m=2$) qubit 0 and qubit 2 and 3 representing the input and qubit 4 the bias $x_0=1$ (see Figure 21.1).

```
import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.visualization import plot_histogram
from math import pi
from qiskit.circuit.library import QFT

qc = QuantumCircuit(5, 2)

#Free Parameters set by the User
-------------------------------
#Setting the values of weihts
w0=0
w1=1
w2=1
#Setting the Input x1=qubit 2, x2=qubit 3
qc.x(2)
qc.x(3)
-------------------------------
#Constant values with N=m-1 (m number of controll qubits)
N=1
qc.h(0)
qc.h(1)
#Bias w0 qubit 4
qc.x(4)
qc.barrier()
#qc.cp(lambda, control, target)
#w1
#w2

qc.cp(w1*pi/(2*N), 0, 2)
qc.cp(w2*pi/(2*N), 0, 3)
#w0
qc.cp(w0*pi/(2*N), 0, 4)
```
