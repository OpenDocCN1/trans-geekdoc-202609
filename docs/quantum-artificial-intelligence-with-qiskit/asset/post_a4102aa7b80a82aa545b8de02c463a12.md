## 3.3 BACKEND SIMULATOR FUNCTIONS

Qiskit provides different backend simulator functions by Aer package. We will use two simulators.

- The statevector simulator performs an ideal execution of qiskit circuits and returns the final state vector after application (all qubits). The state vector of the circuit can represent the probability values (probability in newer version) that correspond to the multiplication of the state vector by the unitary matrix that the statevector simulator will take longer than other simulation methods and requires more computer memory, since the state vector dimension grows exponentially with the number of qubits with n = 2^m (with m number of qubits).

Figure 3.1 (a) Qiskit 0.34.2 version running on an older computer with 8 Gb; (b) Qiskit 0.43.0 version running on a modern computer with 16 Gb.

- The qasm simulator behaves like an actual device of today, which is prone to noise resulting from decoherence. It runs count, the sampling of the measured qubits that have to be defined in the circuit. It is much smaller in size and will not increase size exponentially as the number of qubits increases.

## 3.5 EXAMPLE: QUANTUM COIN

We start with a very simple example, the quantum coin. The quantum coin is a system with two basis states 0 and 1 with

```
$|0\rangle = \begin{pmatrix} 1 & 0 \end{pmatrix}, |1\rangle = \begin{pmatrix} 0 & 1 \end{pmatrix}. \quad (3.1)$
```

The mapping is represented as

```
$|0\rangle \rightarrow \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle. \quad (3.2)$
```

and

```
$|1\rangle \rightarrow \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle. \quad (3.3)$
```

The corresponding operator is indicated by the following unitary matrix,

```
$W = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} = \frac{1}{\sqrt{2}} \cdot \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}. \quad (3.4)$
```

If the system starts in state |0⟩ and undergoes the time evolution, the probability of observing 0 or 1 is $|\frac{1}{\sqrt{2}}|^2=1/2$. If we do not perform a measurement and repeat the mapping, the probability of observing 0 becomes zero and observing 1 becomes one. This is due to the fact, that the amplitudes of [1] cancel each other. This effect is due to destructive interference and cannot occur in the probability distribution since all coefficients are non-negative real numbers.
