# Grover's Amplification

We describe the Grover amplification algorithm. We represent $n$ state by a superposition, each state has the same real positive amplitude. A parallel computation is applied to all the $n$ states, and the state with the solution is marked by a minus sign, the amplitude is now negative. We then apply a linear operation that is based on Householder reflection, by the reflection the the value of the marked amplitude grows linearly. For dimensions higher than four, the operations of marking and Householder reflection must be repeated $\sqrt{n}$ times, at each step the amplitude only grows linearly. With $\sqrt{n}$ steps we measure the solution. The algorithm guarantees a quadratic speed up a classical computer that would require $n$ steps. Grover's amplification algorithm is optimal, one can prove that a better algorithm cannot exist. We will demonstrate the principles of Grover's amplification using quantum notation with a qubit $NumP_q$. Then we explain how to represent the algorithm with quantum answer representing eight states using one and two rotations.
