# HHL

The quantum algorithm for linear systems of equations for one of the main fundamental algorithms expected to provide a speedup over their classical counterparts. In the honor of its inventors Aram Harrow, Avinatan Hassidim, and Seth Lloyd, it is called the HHL is going to be one of the most useful subroutines for any quantum machine learning algorithm because almost machine learning uses some form of a linear system of equations. For example, in support vector machines and quantum support vector machines, maximizing the objective function with the optimum values of the Lagrange multipliers are based on solving linear equations. We describe the HHL algorithm, give an example step by using qiskit HamiltonianGate, and indicate the constraints of the algorithm.

# 22.1 QUANTUM ALGORITHM FOR LINEAR SYSTEMS OF EQUATIONS

We see systems of equations in many real-life applications across a wide range of areas. For an invertible complex matrix $n 	imes n$ $A$ and a complex vector $\mathbf{b}$

```
$A \cdot \mathbf{x} = \mathbf{b}$
```

we want to find $\mathbf{x}$. If $A^* = A$ (for real matrix $A^T = A$) then A can be represented by a linear spectral decomposition

```
$A = \lambda_1 \cdot |u_1\rangle\langle u_1| + \lambda_2 \cdot |u_2\rangle\langle u_2| + \cdots + \lambda_n \cdot |u_n\rangle\langle u_n|$
```

and

```
$A^{-1} = \frac{1}{\lambda_1} |u_1\rangle\langle u_1| + \frac{1}{\lambda_2} |u_2\rangle\langle u_2| + \cdots + \frac{1}{\lambda_n} |u_n\rangle\langle u_n|$
```

It follows

```
$A^{-1} \cdot |u_j\rangle = \frac{1}{\lambda_j} |u_j\rangle$
```

and writing $|b\rangle$ as a linear combination of the eigenvectors of $A$

```
$|b\rangle = \sum_{j} |u_j\rangle\langle u_j|b|$
```
