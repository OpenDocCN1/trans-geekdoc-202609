In the third step a Hadamard gate is applied to the first qubit

```
$H_1 \cdot I_2 \cdot H_2 \cdot |01\rangle. \quad (3.7)$
```

There are four possible outcomes,

```
$i) |0\rangle \otimes \left(\frac{|0\rangle-|1\rangle}{\sqrt{2}}\right),\nii) -|0\rangle \otimes \left(\frac{|0\rangle-|1\rangle}{\sqrt{2}}\right),\niii) |1\rangle \otimes \left(\frac{|0\rangle-|1\rangle}{\sqrt{2}}\right),\nvi) -|1\rangle \otimes \left(\frac{|0\rangle-|1\rangle}{\sqrt{2}}\right).$
```

In the fourth step the first qubit (that is in the base state) is measured. It is $|0\rangle$ if the function is constant, otherwise $|1\rangle$.

In our simulation, for simplicity we assume the unknown function is the identity mapping $f(x)=0$

```
$i \ U_f(00) = |0\rangle\otimes|0\rangle = |00\rangle, U_f(01) = |01\rangle,\nU_f(10) = |10\rangle, U_f(11) = |11\rangle$.
```

qc = QuantumCircuit(2,1)\nqc.x(0)\nqc.barrier()
