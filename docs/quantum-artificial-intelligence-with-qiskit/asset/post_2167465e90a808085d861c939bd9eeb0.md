
## 22.3.1 Kitaev's Phase Estimation to Hamiltonian Simulation

Using Kitaev's phase estimation algorithm, we get the relation

```
$$U \cdot |u\rangle = e^{2\pi i\theta_j} \cdot |u\rangle$$
```

By using Hamiltonian simulation, the relation is

```
$$U_j \cdot |u\rangle = e^{-it\lambda_j} \cdot |u\rangle$$
```

We will use during Kitaev's phase estimation algorithm QFT instead of the inverse QFT to deal with the minus sign. In this case the relation becomes

```
$$e^{2\pi i\theta_j} \cdot |u\rangle = e^{it\lambda_j} \cdot |u\rangle$$
```

with

```
$$\theta_j = \frac{\lambda_j \cdot t}{2 \cdot \pi}$$
```

In our simulation, we use two qubits in the control register and we choose $t=2\cdot\pi/8$ and we get

```
$$\theta_j = \frac{3}{8} \cdot \lambda_j$$
```

with

```
$$\theta_1 = \frac{3}{8} \cdot \frac{3}{4} = \frac{2}{4}, \quad \theta_2 = \frac{2}{8} \cdot \frac{3}{3} = \frac{1}{4}$$
```

with measured two qubits being [10] representing 2 and [01] representing 1

```
$$\theta=0.x_2x_1 = \frac{x}{4} = \frac{x}{2^2}$$
```

We represent

```
$$|b\rangle = |0\rangle = \mathbf{b} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$
```

with

```
$$|u_1\rangle = \frac{|0\rangle - |1\rangle}{\sqrt{2}}, \quad |u_2\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}}$$
```

and with

```
$$|b\rangle = \sum_j \beta_j |u_j\rangle = \frac{1}{\sqrt{2}} |u_1\rangle + \frac{1}{\sqrt{2}} |u_2\rangle$$
```

```
$$|b\rangle = \frac{1}{\sqrt{2}} \frac{|0\rangle - |1\rangle}{\sqrt{2}} + \frac{1}{\sqrt{2}} \frac{|0\rangle + |1\rangle}{\sqrt{2}} = |0\rangle.$$
```

We will use qiskit command HamiltonianGate [21] where data is a Hermitian matrix $A$ is represented and time $t=2\cdot\pi/8$ to perform Hamiltonian evolution and use QFT instead of inverse QFT (see Figure 22.1).

## 22.3.2 Conditioned Rotation and Un-Computation

We perform conditioned rotation on the auxiliary state $|0\rangle$ by

```
$$R_Y(\alpha) = \begin{pmatrix} \cos(\frac{\alpha}{2}) & -\sin(\frac{\alpha}{2}) \\ \sin(\frac{\alpha}{2}) & \cos(\frac{\alpha}{2}) \end{pmatrix}$$
```

with two control qubits [10] representing $\lambda_1 = 2$ and [01] representing $\lambda_2 = 1$,

```
$$\alpha_1 = 2 \cdot \arccos(\frac{1}{\lambda_1}) = 2 \cdot \arccos(\frac{1}{2}) = \frac{\pi}{3}$$
```

```
$$\alpha_2 = 2 \cdot \arccos(\frac{1}{\lambda_2}) = 2 \cdot \arccos(\frac{1}{1}) = \pi$$
```

using a conditional $RY$ gate controlled by $\lambda$ represented by qubits 1 and 2, then we
un-compute. The result is reconstructed in qubit 3 in the case the qubit 0 is one (see Figure 22.2).

```python
from qiskit import QuantumCircuit, Aer, execute
from qiskit.quantum_info import Statevector
from qiskit.visualization import plot_histogram
from math import pi
from qiskit.quantum_info import Operator
from qiskit.extensions import HamiltonianGate
from qiskit.circuit.library import QFT
qft = QFT(2, inverse=False).to_gate()
qft.label = "QFT"
qft_dagger = QFT(2, inverse=True).to_gate()
dagger = Operator([[1, -1/3],[-1/3, 1]])

op = Operator([[1, 0], [0, 1]])
# create gate which evolves according to exp(-i*op*3*pi/4)
gate = HamiltonianGate(op,3*pi/4).control()
gate_dagger = HamiltonianGate(op,3*pi/4).inverse().control()
qc = QuantumCircuit(4)
qc.h([1,2])
# apply gate to qubits [0, 1, 2] in circuit
qc.append(gate, [1, 3])
qc.append(gate, [2, 3])
```

## 22.3.3 Obtaining the Solution

The solution to the problem
$A = \begin{pmatrix} 1 & -1/3 \\ -1/3 & 1 \end{pmatrix}, \quad b = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ is represented by
$A^{-1} = \begin{pmatrix} 3/5 & 1/5 \\ 1/5 & 3/5 \end{pmatrix}, \quad x = \begin{pmatrix} 9/5 \\ -3/5 \end{pmatrix}.$
with the normalized vector
$\mathbf{x}_n = \frac{\mathbf{x}}{\|\mathbf{x}\|} = \begin{pmatrix} 0.94868 \\ 0.31622 \end{pmatrix}.$

The measured result of our HHL simulation is in qubit 3 in the case the qubit 0 is 0, see **Figure 22.2 (b)**
$x_m = \frac{0.562 \cdot 0.062}{0.562 + 0.062}$ with the measured value being
$X_m = \begin{pmatrix} 0.94889 \\ 0.31567 \end{pmatrix} \approx X_n = \begin{pmatrix} 0.94868 \\ 0.31622 \end{pmatrix}.$

Obtaining the required coefficient $x_i$ from $|x\rangle$ would require at least $n$ measurements, so the complexity of the algorithm would be $O(n)$ which is problematic since the cost on a classical computer for an approximate solution via conjugate gradient descent are equivalent. Many applications are interested in global properties of $|x\rangle$ rather than the coefficients $x_i$. For example, we as well estimate if solutions of different equations are the same or not [39].

## 22.4 CONSTRAINTS

In quantum we efficiently find the eigenvectors and eigenvalues by the Kitaev's phase estimation algorithm [39]. We will compute
$\mathbf{x} = A \cdot \mathbf{b}$ (22.38)
or
$\mathbf{x} = A^{-1} \cdot \mathbf{b}.$ (22.39)

We assume $A$ is Hermitian. In the case $A$ is Hermitian, we define
$A' = \begin{pmatrix} 0 & A \\ A^* & 0 \end{pmatrix}, \quad \mathbf{b}' = \begin{pmatrix} 0 \\ b \end{pmatrix}, \quad \mathbf{x}' = \begin{pmatrix} x \end{pmatrix}.$ (22.40)
and
$A' \cdot \mathbf{x}' = \mathbf{b}'$. (22.41)

with the constraints:
- The vectors $|b\rangle$, $|x\rangle$ have length one in the $l_2$ norm. $|b|$ is represented by $\log_2 n$ qubits
```
$$|b\rangle = \frac{\sum_{i=1}^n b_i[t]}{\sqrt{\sum_{i=1}^n |b_i[t]|^2}}$$ (22.42)
```
and
```
$$|x\rangle = \frac{\sum_{i=1}^n x_i[t]}{\sqrt{\sum_{i=1}^n |x_i[t]|^2}}$$ (22.43)
```
- $|b\rangle$ has to be prepared efficiently with the cost $\log(\log_2 \cdot n)$. For example being constant with
- The matrix $A$ is sparse.
- For the output we are interested in the global properties of $|x\rangle$ rather than the coefficients $x_i$.

We will use the shorthand notation (Bachmann-Landau notation) since it is mostly used in the related literature with
```
$$\hat{O}(f(n)) = O(f(n)poly(\log(f(n)))) = O(f(n)\log(f(n))^k)$$ (22.44)
```
for some $k$ logarithmic factors. The point of notation is to only show the important part of the asymptotic complexity.
