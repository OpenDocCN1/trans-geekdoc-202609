# Grover's Amplification

```
H=np.matrix([[1, 1], [1, -1]])
H=H*1/np.sqrt(2)
np.view(H)
print("H=\n",H)
```

```

[[ 0.7071 -0.7071]

```
H2=np.kron(H,H)
H3=np.kron(H,H2)
