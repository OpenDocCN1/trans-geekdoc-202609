# 2.2.3 Linear Operators

The computation on the coherent qubits (before the measurement) is described by linear operators that change the distribution of the quantum probabilities represented by amplitudes in a linear way [119]. The operators are represented by orthogonal matrices for real amplitudes (inverse of the matrix is the transpose of the matrix), for complex amplitudes by unitary matrices (inverse matrix is the conjugate transpose of the matrix)

Operators represented by a square matrix give mathematical description how something changes in the quantum world. For a 2-state quantum system, an operator that acts on the memory register would be a $2 \times 2$ dimensional unitary matrix. In unitary matrices, its conjugate transpose is equal to its inverse.

```
$U^* = U^{-1}$
```

For a example coin is a system with two basis states 0 and 1 with

```
$|0\rangle = \left( \begin{matrix} 1 \ 0 \end{matrix} \right), |1\rangle = \left( \begin{matrix} 0 \ 1 \end{matrix} \right)$
```

The mapping is represented as

```
$|0\rangle \rightarrow \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle$
```

and

```
$|1\rangle \rightarrow \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle$
```

The corresponding operator is indicated by the unitary matrix,

```
$H = \left( \begin{matrix} \frac{1}{\sqrt{2}} & \frac{1}{\sqrt{2}} \ \frac{1}{\sqrt{2}} & -\frac{1}{\sqrt{2}} \end{matrix} \right) = \frac{1}{\sqrt{2}} \left( \begin{matrix} 1 & 1 \ 1 & -1 \end{matrix} \right)$
```

called a Hadamard or Hadamard Walsh, matrix. If the system starts in state |0> and undergoes the time evolution, the probability of observing 0 or 1 is $|1/\sqrt{2}|^2 = \frac{1}{2}$. If we do not perform a measurement and repeat the mapping, the probability of observing 0 becomes 1 and observing 1 becomes zero. This is due to the fact, that the amplitudes of |1 cancel each other. This effect is called destructive interference and cannot occur in the probability distribution since all its coefficients are non-negative real numbers.
