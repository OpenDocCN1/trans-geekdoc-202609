# 2.4 MEASUREMENT

After a unitary information processing start form an initial state the result of the algorithm is determined by the measurement. The measurement corresponds to the collapse of the state vector, a projection into a base state. The projection is not reversible and is not consistent with the unitary evolution. For a state represented by a unit-length vector

```
$$|omega_1 \cdot |x_1\rangle + \omega_2 \cdot |x_2\rangle + \dots + \omega_n \cdot |x_n\rangle$$
```

in n-dimensional Hilbert space $|x_y\rangle$ is observed. After the measurement (observation-state) is in a base

```
$|1 \cdot |x_y\rangle$$
```

The state of a quantum system is projected to the subspace that corresponds to the observed state and the vector representing it is renormalized to the unit length. An observable describes a subspace for some dimensions with a special case of one dimension. A part of the system can be observed by a projection in a subspace with dimension higher than one. The compound system of n-dimensional Hilbert space $|x\rangle \in \mathcal{H}_n$ and a w-dimensional Hilbert space $|y\rangle$ defined by an orthonormal basis $|xy\y_{w} \rangle \in \mathcal{H}_{n-w}$. A state of the system is represented as

```
$|xy\rangle = \sum_{i=1}^n \sum_{j=1}^w \omega_{ij} |x_i\rangle |y_j\rangle \quad (2.22)$
```
