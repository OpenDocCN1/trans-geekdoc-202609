# 23.3 SPSA OPTIMIZER

Simultaneous Perturbation Stochastic Approximation (SPSA) optimizer performs stochastic gradient approximation (https://www.jhuapl.edu/SPSA/), which requires only two measurements of the loss function, regardless of the dimension of the optimization problem [13]. The goal is to find

```
$w^{*} = \arg_{w} \min L(w) \quad (23.13)$
```

with the gradient operator

```
$\nabla = \begin{bmatrix} \frac{\partial}{\partial w_{1}}, & \frac{\partial}{\partial w_{2}}, & \dots, & \frac{\partial}{\partial w_{D}} \end{bmatrix}^{T}$
```

```
$g(w) = \nabla L(w) = \begin{bmatrix} \frac{\partial L}{\partial w_{1}}, & \frac{\partial L}{\partial w_{2}}, & \dots, & \frac{\partial L}{\partial w_{D}} \end{bmatrix}^{T}$
```

SPSA use the iterative process with $	au$ indicating the iteration starting at $\tau=1$ with

```
$w_{	au+1} = w_{	au} - \eta_{	au} \cdot \hat{g}(w_{	au}) \quad (23.14)$
```

with $\eta_{	au}$ the learning rate that decreases with $	au$ and $\hat{g}(w_{	au})$ estimation of the gradient $\hat{g}(w_{	au})$ with

```
$\hat{g}_{\tau} = \frac{L(w_{	au} + c_{	au} \cdot \Delta_{	au}) - L(w_{	au} - c_{	au} \cdot \Delta_{	au})}{2c_{	au} \cdot \Delta_{	au}}} \quad (23.15)$
```

$\Delta_{	au}$ is a random perturbation vector and $c_{	au}$ is a small positive number that decreases with $\tau$. The number of loss function measurements needed in the SPSA method for each is 2, independent of the dimension. SPSA with the random search direction does not follow the gradient path but approximates it. Using a variational classifier on 1 quantum classifier SPSA is the most recommended choice it can be used in the presence of noise.
