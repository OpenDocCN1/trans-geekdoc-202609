# 2.2.1 Qubits

A qubit is represented by a two-dimensional vector. The first dimension of the vector corresponds to zero and the second to a one. The values of the two dimensions correspond to the probabilities that when measured, one of the two states is present. We can combine a qubit to several qubits by a tensor operation. Two qubits have four possible states, the first dimension represents the state-zero, the second-zero, the third-zero, and the fourth-one. They are described by a four-dimensional vector. Four qubits would represent 16 combinations, 256 combinations, represented by a 256-dimensional vector, and so on. The number of possible grows exponentially in relation to the number of qubits, with the number of states being equal to two the number of represented qubits [119]. In a vector representing several states, each dimension corresponds to the probabilities of measuring. The probability values are represented by amplitudes. The relation between an amplitude and the probability is the absolute value of the amplitude. For example the probability value 0.25 corresponds to an amplitude 0.5, $|0.5|^2 = 0.25$. The amplitude can be negative, if $|-0.5|^2 = 0.25$ is or even imaginary numbers like $|i0.5|^2 = 0.25$. As a consequence of this result, the Euclidean length of the vector represents the probabilities is always one, all probabilities sum to one. If a dimension of the state vector represents the probability zero, the corresponding state will never be measured. If one dimension of the state vector represents the probability one, all other dimensions represent the probabilities zero, and the corresponding dimension will be measured for. If the represented probabilities are bigger than zero or smaller than one, they will be measured with certain probability. Repeating the same experiment several times the measured values converge to the represented probability values, the individual measurement is random. A qubit with the probability values 0.5 (amplitude $\sqrt{0.5}$) and 0.5 (amplitude $\sqrt{0.5}$) represents a random process when measured, True random numbers are generated during the measurement.
