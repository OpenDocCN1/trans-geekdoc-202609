# 22.3.1 Kitaev's Phase Estimation to Hamiltonian Simulation

Using Kitaev's phase estimation algorithm, we get the relation

```
$$U \cdot |u\rangle = e^{2\pi i\theta_j} \cdot |u\rangle$$
```

By using Hamiltonian simulation, the relation is

```
$$U_j \cdot |u\rangle = e^{-it\lambda_j} \cdot |u\rangle$$
```

We will use during Kitaev's phase estimation algorithm QFT instead of the inverse QFT to deal with the minus sign. In this case the relation becomes

```
$$e^{2\pi i\theta_j} \cdot |u\rangle = e^{it\lambda_j} \cdot |u\rangle$$
```

with

```
$$$\theta_j = \frac{\lambda_j \cdot t}{2 \cdot \pi}$$$
```

In our simulation, we use two qubits in the control register and we choose $t=2\cdot\pi/8$ and we get

```
$$$\theta_j = \frac{3}{8} \cdot \lambda_j$$$$
```

with

```
$$$\theta_1 = \frac{3}{8} \cdot \frac{3}{4} = \frac{2}{4}, \quad \theta_2 = \frac{2}{8} \cdot \frac{3}{3} = \frac{1}{4}$$$
```

with measured two qubits being [10] representing 2 and [01] representing 1

```
$$$\theta=0.x_2x_1 = \frac{x}{4} = \frac{x}{2^2}$$$
```

We represent

```
$$|b\rangle = |0\rangle = \mathbf{b} = \begin{pmatrix} 1 \ 0 \end{pmatrix}$$$
```

with

```
$$|u_1\rangle = \frac{|0\rangle - |1\rangle}{\sqrt{2}}, \quad |u_2\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}}$$$
```

and with

```
$$|b\rangle = \sum_j \beta_j |u_j\rangle = \frac{1}{\sqrt{2}} |u_1\rangle + \frac{1}{\sqrt{2}} |u_2\rangle$$
```

```
$$|b\rangle = \frac{1}{\sqrt{2}} \frac{|0\rangle - |1\rangle}{\sqrt{2}} + \frac{1}{\sqrt{2}} \frac{|0\rangle + |1\rangle}{\sqrt{2}} = |0\rangle.$$$
```

We will use qiskit command HamiltonianGate [21] where data is a Hermitian matrix $A$ is represented and time $t=2\cdot\pi/8$ to perform Hamiltonian evolution and use QFT instead of inverse QFT (see Figure 22.1).
