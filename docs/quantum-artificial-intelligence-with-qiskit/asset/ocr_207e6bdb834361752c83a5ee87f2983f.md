# 4.3.2 T† Gate - T†

```
qc.tdg(qubit)
```

The T gate corresponds to the RZ with $	heta = -\pi/4$.

```
$T\dagger|0\rangle \rightarrow |0\rangle \quad T\dagger|1\rangle \rightarrow e^{-i\pi/2}|1\rangle = \left(\frac{1}{\sqrt{2}}-\frac{i}{\sqrt{2}}\right)|1\rangle$
```

The T gate defines a quantum gate on one qubit and can be represented by a unitary matrix $T$ in Hilbert space $\mathcal{H}_2$

```
$T^{\dagger} = \begin{pmatrix} 1 & 0 \ 0 & e^{-i\pi/2} \end{pmatrix}$
```

With $T^{\dagger}$ gate being the square root of the $S$ gate

```
$S=(T^{\dagger})^2$
```

# 4.4 PARAMETERIZED ROTATION GATES

Parameterized gates play an important role in quantum machine learning. A parameterized rotation gate is a parameterized gate with the parameter the amount of rotation to be performed around the three axes

# 4.4.1 RX Gate - RX

```
qc.rx(theta,qubit)
```

The $RX$ gate performs a rotation of one qubit along the $x$-axis by the rotation angle $	heta$. The rotation angle is in radians.

With $	heta = \pi$

```
$RX|0\rangle \rightarrow -i|1\rangle \quad RX|1\rangle \rightarrow -i|0\rangle$
```

With $	heta = \pi/2$

```
$RX|0\rangle \rightarrow \frac{1}{\sqrt{2}}|0\rangle-\frac{i}{\sqrt{2}}|1\rangle \quad RX|1\rangle \rightarrow \frac{i}{\sqrt{2}}|0\rangle+\frac{1}{\sqrt{2}}|1\rangle$
```

The $RX$ gate defines a quantum gate on one qubit and can be represented by a unitary matrix $RX$ in Hilbert space $\mathcal{H}_2$

```
$R_{X}(\theta) = \begin{pmatrix} \cos(\\frac{\theta}{2}) & -i\sin(\\frac{\theta}{2}) \ -i\sin(\\frac{\theta}{2}) & \cos(\\frac{\theta}{2}) \end{pmatrix}$
```
