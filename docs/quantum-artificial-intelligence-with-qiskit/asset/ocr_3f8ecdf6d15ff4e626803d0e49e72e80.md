+   - association if both vectors are different $x \neq \mathbf{y}$,

# 15.2 Storage Capacity

We analyze the optimal costs of the Lernatrix. For an estimation of the asymptotic number $L$ of vector pairs $(x,y)$ that can be stored in an associative memory before it begins to make mistakes in the retrieval phase, it is assumed that both vectors have the same dimension $n$. each composed of $k$ ones, which are equally likely to be in any coordinate of the vector. In this case it was shown [75, 42, 102] that the optimum value for $k$ is approximately

```
$k \leq \log_2(n/4).$
```
