# 1.3.5 Perceptron

Perceptron describes an algorithm for supervised learning that considers only linearly separable problems in groups which can be separated by a line or hyperplane [67] [86]. Defining $x_0 = 1$ [42, 44], the perceptron implements the mathematical function $sgn(net)$

```
$net := \sum_{j=0}^{D} w_j \cdot x_j = \sum_{j=1}^{D} w_j \cdot x_j + w_0 = \langle\mathbf{w}\rangle + w_0 \cdot x_0 \quad (1.9)$
```

and $o$ being the output of the artificial neuron

```
$o := sgn(net) = \begin{cases} 1 & \text{if } net \geq 0 \ -1 & \text{if } net < 0 \end{cases} \quad (1.10)$
```

The value $w_0$ is called the "bias", it is a constant value that does not depend on any input value. The goal of the perceptron is to learn how to classify patterns into one of two classes $C_1 = 1$ and $C_2 = -1$. To achieve this, the model needs examples of correct associations between patterns and their respective classes.

```
$Data = \{(x_1, t_1), (x_2, t_2), \dots, (x_N, t_N)\}$
```

with

```
$t_k \in \{-1, 1\}$,
```

the output for class $C_1$ is $o = -1$ and for $C_2$ is $o = 1$ with

```
$o = sgn(\sum_{j=0}^{D} w_j \cdot x_j) = sgn(\langle\mathbf{w}\angle + w_0 \cdot x_0) \quad (1.11)$
```

and $x_0 = 1$.

Simplified, the perceptron learns to learn the function $f(x)$

```
$f(x) = \begin{cases} 1 & \text{if } \langle\mathbf{w}\angle + w_0 \geq 0 \ -1 & \text{otherwise.} \end{cases} \quad (1.12)$
```

With this approach, the perceptron is only able to solve linearly separable problems (see Figure 1.7), that is, that can be separated by a line or hyperplane. The hyperplane is determined by the model weights $\mathbf{w}$ and $w_0$. The correct weights can be determined by a supervised learning algorithm.

Before learning, the weights $w_i$ are initialized to some random values, so the hyperplane is placed randomly in the space. The perceptron learning algorithm verifies, for any input $x_k$, the output value $o_k$ belongs to the desired class represented by $t_k$. If the input matches the class, the algorithm does not touch the boundary, if it does not, the algorithm moves the boundary in a direction where the input $x_k$ is closer to being correctly classified. This movement corresponds to the following updated rule

```
$\Delta w_j = \eta \cdot (t_k - o_k) \cdot x_j, \quad (1.13)$
```
