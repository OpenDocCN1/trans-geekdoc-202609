# 13.3 ENTANGLEMENT OF BINARY PATTERNS

The method is based on the entanglement of the index qubits that are in the superposition with the patterns. To stores m binary patterns

> $|pattern_m>, |pattern_{m-1}>, \dots, |pattern_1|$

we entitle the index qubits using multi-controlled NOT gates (cCX gate or MCX-Gate). First, we generate $v = |log_2(m)$ index qubits using Hadamard gates

```
$H^{\otimes m}|0\rangle^{\otimes m} = \frac{1}{\sqrt{m}} \sum_{j=1}^{m} index_j$
```

and entitle m binary pattern with the index qubits with a superposition

```
$|\psi\rangle = \frac{1}{\sqrt{m}} \sum_{j=1}^{m} |index_j\rangle|pattern_j\rangle$ (13.1)
```
