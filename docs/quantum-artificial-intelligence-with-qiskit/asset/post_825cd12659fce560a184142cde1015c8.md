## 1.3.4 Artificial Neuron

With two vectors of the same dimension $D$, the vector $x$ represents an input pattern (signals incoming from other neurons) and the vector $w$ represents a stored pattern (in the weights of each synapse). We can define a scalar product also called the dot product

![](img/52faec2d621d75e53089d939bb234a82_40_0.png)

**Figure 1.6** how Hopfield network restores distorted pattern. The network will converge after several steps using the update rule to an attractor representing the stored pattern or a spurious state composed of a linear combination of an odd number of stored patterns.

```
$(\mathbf{x}) = \sum_{j=1}^{D} w_j \cdot x_j = \cos \omega \cdot ||\mathbf{x}||, \quad (1.5)$
```

measures the projection of one vector onto another. The dot product is a linear representation usually represented by the value $net$,

```
$net = \sum_{j=1}^{D} w_j \cdot x_j.$
```

The components $w_j$ are called weights, they model the synapses representing the traces of memory. Nonlinearity of the linear representation can be achieved by a threshold operation in which the threshold $T$ has a certain value

```
$o = \begin{cases} 1 & \text{if } net \ge T \\ -1 & \text{if } net < T \end{cases} \quad (1.6)$
```

being the output of the artificial neuron. This threshold operation can be described by a nonlinear transfer function like $sgn$ for $T=0$,

```
$o = sgn(net) = \begin{cases} 1 & \text{if } net \ge 0 \\ -1 & \text{if } net < 0 \end{cases} \quad (1.7)$
```

The $sgn(net)$ operation is related to the threshold operation of a real biological neuron with $-1$ meaning not firing and 1 firing. Firing indicates that the neuron sends output information to other neurons to which it is connected. No firing indicates that no information is sent. The transfer function is also the activation function, with $o$ being the output of the artificial neuron

```
$o = sgn(net) = sgn(\mathbf{x}|\mathbf{w}) = sgn(\sum_{j=1}^{D} w_j \cdot x_j) \quad (1.8)$
```

This model is also known as the linear threshold unit (LTU).

## 1.3.5 Perceptron

Perceptron describes an algorithm for supervised learning that considers only linearly separable problems in groups which can be separated by a line or hyperplane [67] [86]. Defining $x_0 = 1$ [42, 44], the perceptron implements the mathematical function $sgn(net)$

```
$net := \sum_{j=0}^{D} w_j \cdot x_j = \sum_{j=1}^{D} w_j \cdot x_j + w_0 = \langle\mathbf{w}\rangle + w_0 \cdot x_0 \quad (1.9)$
```

and $o$ being the output of the artificial neuron

```
$o := sgn(net) = \begin{cases} 1 & \text{if } net \geq 0 \\ -1 & \text{if } net < 0 \end{cases} \quad (1.10)$
```

The value $w_0$ is called "bias", it is a constant value that does not depend on any input. The goal of the perceptron is to learn how to classify patterns into one of two classes $C_1=1$ and $C_2=-1$. To achieve this, the model needs examples of correct associations between patterns and their respective classes.

```
$Data = \{(x_1, t_1), (x_2, t_2), \dots, (x_N, t_N)\}$
```

with

```
$t_k \in \{-1, 1\}$,
```

the output for class $C_1$ is $o = -1$ and for $C_2$ is $o = 1$ with

```
$o = sgn(\sum_{j=0}^{D} w_j \cdot x_j) = sgn(\langle\mathbf{w}\rangle + w_0 \cdot x_0) \quad (1.11)$
```

and $x_0 = 1$. Simplified, the perceptron learns to learn the function $f(x)$

```
$f(x) = \begin{cases} 1 & \text{if } \langle\mathbf{w}\rangle + w_0 \geq 0 \\ -1 & \text{otherwise.} \end{cases} \quad (1.12)$
```

With this approach, the perceptron is only able to solve linearly separable problems (see Figure 1.7), that is, can be separated by a line or hyperplane. The hyperplane is determined by model weights $\mathbf{w}$ and $w_0$. The correct weights can be determined by supervised learning algorithm. Before learning, the weights $w_i$ are initialized to some random values, so hyperplane is placed randomly in the space. The perceptron learning algorithm verifies, for any input $x_k$, the output value $o_k$ belongs to the desired class represented by $t_k$. If the input matches the class, the algorithm does not touch the boundary, if it not, the algorithm moves the boundary in a direction where the input $x_k$ is closer to being classified. This movement corresponds to the following updated rule

```
$\Delta w_j = \eta \cdot (t_k - o_k) \cdot x_j, \quad (1.13)$
```

![](img/52faec2d621d75e53089d939bb234a82_42_0.png)

Figure 1.7 The hyperplane is described by $w$ and $w_0$, in two dimensions by a line $w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 = 0$. The perceptron only solves linearly separable problems, in our example class 1 and class 2.

and

$w_j^{new} = w_j^{old} + \Delta w_j, \quad (1.14)$
```

where $\eta$ is called the learning rate that defines the size of the movement that is applied to the boundary with $0 < \eta \leq 1$.

The algorithm converges to the correct classification if the training data are linearly separable and sufficiently small. When assigning a value to $\eta$, we must consider two conflicting requirements: averaging of past inputs to provide stable weight estimates, which requires small $\eta$; however, fast adaptation with respect to real changes in the underlying distribution of the process responsible for generating the input vector $\mathbf{x}$, which requires a large $\eta$.

This simple algorithm is the basis for many supervised algorithms. If training set is not linearly separable, no solution exists. In this setting, after several epochs, the weights begin to oscillate. To get an approximate solution, the learning rate $\eta$ has to decrease slowly to zero as the epochs go by.

## 1.3.6 Support Vector Machine

Given a training set $\{\mathbf{x}_i, t_i\}_{i=1}^N$, with $t_i \in \{-1, +1\}$ of linearly separable patterns have

```
$\mathbf{w}^T \cdot \mathbf{x}_i + w_0 \geq 0, \quad \text{for} \quad t_i = +1$
$\mathbf{w}^T \cdot \mathbf{x}_i + w_0 < 0, \quad \text{for} \quad t_i = -1$
```

with a hyperplane

```
$$\mathbf{w}^T \cdot \mathbf{x} + w_0 = \mathbf{w}^T \cdot \mathbf{x} + b = 0$$
```

We want to have a margin between each class and the boundary, we want to find the parameters $w_{opt}$ and $b_{opt}$ such that

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} \geq 1, \quad \text{for} \quad t_i = +1 \quad (1.15)$$
```

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} \leq -1, \quad \text{for} \quad t_i = -1 \quad (1.16)$$
```

for the hyperplane

```
$$\mathbf{w}^T \cdot \mathbf{x} + w_0 = 0 \quad (1.17)$$
```

The value of 1 is set for convenience because we can rescale $w_{opt}$ and $b_{opt}$ correspondingly. The data points that are closest to the boundary: those points $\{\mathbf{x}_i, t_i\}$ for which

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} = \pm 1 \quad (1.18)$$
```

are support vectors. That is why the algorithm is called a support vector machine. All the remaining examples in the training sample are **irrelevant** to determine where to place the hyperplane. After optimization, we get

```
$$\mathbf{w} = \sum_{i=1}^{N} \alpha_i \cdot t_i \cdot \mathbf{x}_i, \quad \sum_{i=1}^{N} \alpha_i \cdot t_i = 0, \quad (1.19)$$
```

and we define the dual optimization problem that depends entirely on the training data and the Lagrange multipliers. Given the training sample $\{\mathbf{x}_i, t_i\}_{i=1}^N$, with $t_i \in \{-1, +1\}$ of linearly separable patterns, we want to find the Lagrange multipliers $\{\alpha_i\}_{i=1}^N$ that maximize

```
$$\Q(\alpha) = \sum_{i=1}^{N} \alpha_i - \frac{1}{2} \sum_{i=1}^{N} \sum_{j=1}^{N} \alpha_i \cdot \alpha_j \cdot t_i \cdot t_j \cdot \mathbf{x}_j^T \mathbf{x}_j \quad (1.20)$$
```

subject to the usual constraints

```
$$\sum_{i=1}^{N} \alpha_i \cdot t_i = 0 \quad (1.21)$$
```

and adding a new constraint

```
$0 \leq \alpha_i \leq C, \quad i = 1, 2, \dots, N \quad (1.22)$
```

where $C$ is a user specified positive parameter. Having determined the optimum Lagrange multipliers $\alpha_{opt,i}$ (not equal to zero) by solving a system of $N \times N$ linear equations, we may recover

```
$$\mathbf{w} = \sum_{i=1}^{N} \alpha_{opt,i} \cdot t_i \cdot \mathbf{x}_i \quad (1.23)$$
```
