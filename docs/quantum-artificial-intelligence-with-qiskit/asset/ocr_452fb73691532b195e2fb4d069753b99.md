Convert the processing branch into a memory branch by setting the qubit 3 of the control register $c_2$ to zero by the entangled qubit 0 of the pattern |11⟩ (using controlled NOT gate cX).

```
qc.cx(0,3)
```

We reset the load register to the ground state |00. The entangled qubit in the load register is set to zero by the ccX gate (CCNOT gate) with the control qubits represented by the memory register of the stored pattern |11⟩.

```
qc.ccx(4,5,0)
qc.x(1)
```
