# 5.8 GENERALIZATION OF $\Lambda_M$ FOR $M$ QUBITS

For $m$ qubits we can define $\Lambda_m$ accordingly using the $MCX$ gate

```
gate = MCXGate(m)
qc.append(gate, [0, 1, 2, \dots, m, m+1])
```

with

$X_m = X \otimes X \otimes \dots \otimes X$\n$m \text{ times}$
$H_0^m = I \otimes I \otimes \dots \otimes I \otimes H$\n$M-1 \text{ times}$
$\Lambda_m = X_m \cdot H_0^m \cdot MCX \cdot H_0^m \cdot X_m$

Alternatively $\Lambda_m$ can be implemented efficiently with $f_0(x)$

$f_0(x) = \begin{cases} 1 & x=0 \ 0 & \text{else} \end{cases} \quad (5.19)$

as

$\frac{1}{\sqrt{m}} \sum_{x \in B^m} (-1)^{f_0(x)} \cdot |x\rangle \otimes \left( \frac{|0\rangle - |1\rangle}{\sqrt{2}} \right) \quad (5.20)$
