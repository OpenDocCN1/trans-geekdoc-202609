# SAT Problem

The Boolean satisfiability problem (SAT problem) is the problem of determining if there exists an interpretation that satisfies a given Boolean formula, whether the formula evaluates true [22]. Each variable of the formula can have the values true (one). We formulate the formula satisfiability problem and indicate an example step by step. We discuss the relation between the SAT problem and the time complexity. Computational complexity addresses questions regarding which problems can be solved in a finite amount of time on a computer. A decision problem is a computational problem with instances formulated as a question with a binary answer. An is an example of whether a certain number n is a prime number. Most problems can be converted into a decision problem. The time complexity describes the amount of time it takes to run an algorithm. Time operations performed by the algorithm are estimated by counting the number of elementary operations. The amount of time taken is linearly related to the number of elementary operations performed by the algorithm. A is easy if an algorithm on a computer can determine the instances related to the input for the answer in polynomial time. Polynomial-time algorithms are said to be fast since they can be executed in an acceptable time on a computer. Otherwise, we state that the problem is hard, the time required grows exponentially and cannot be executed in an acceptable time on a computer. We describe a simple SAT problem with three Boolean variables and indicate it step by step using qiskit framework to solve the problem using Grover's amplification algorithm by a quantum circuit.
