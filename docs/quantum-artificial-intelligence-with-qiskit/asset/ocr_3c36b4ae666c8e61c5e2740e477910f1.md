The objective function for the dual of optimization is

$Q(\alpha) = \sum_{i=1}^4 \alpha_i - \frac{1}{2} \sum_{i=1}^4 \sum_{j=1}^4 \alpha_i \cdot \alpha_j \cdot t_i \cdot k(\mathbf{x}_i, \mathbf{x}_j)$

$Q(\alpha) = \alpha_1 + \alpha_2 + \alpha_3 + \alpha_4 - \frac{1}{2}(9\alpha_1^2 + 2\alpha_1\alpha_2 - 2\alpha_1\alpha_3 - 2\alpha_1\alpha_4 + 9\alpha_2^2)$

We maximize the objective function $Q(\alpha)$ by determining the partial derivatives

```
$$\frac{\partial Q(\alpha)}{\partial \alpha_1} = 1 - 9\cdot\alpha_1 + \alpha_2 + \alpha_3 - \alpha_4 = 0 \ \frac{\partial Q(\alpha)}{\partial \alpha_2} = 1 + \alpha_1 - 9\cdot\alpha_2 - \alpha_3 + \alpha_4 = 0 \ \frac{\partial Q(\alpha)}{\partial \alpha_3} = 1 + \alpha_1 - \alpha_2 - 9\cdot\alpha_3 + \alpha_4 = 0 \ \frac{\partial Q(\alpha)}{\partial \alpha_4} = 1 - \alpha_1 + \alpha_2 + \alpha_3 - 9\cdot\alpha_4 = 0$$
```
