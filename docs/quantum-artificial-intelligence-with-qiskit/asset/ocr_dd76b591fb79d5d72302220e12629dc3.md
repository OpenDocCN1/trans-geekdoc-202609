with a hyperplane

```
$$\mathbf{w}^T \cdot \mathbf{x} + u_0 = \mathbf{w}^T \cdot \mathbf{x} + b = 0$$
```

We want to have a margin between each class and the boundary, we want to find the parameters $w_{opt}$ and $b_{opt}$ such that

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} \geq 1, \quad \text{for } t_i = +1$$$ (1.15)
```

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} \leq -1, \quad \text{for } t_i = -1$$$ (1.16)
```

for the hyperplane

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} = 0.$$ (1.17)
```

The value of 1 is set for convenience because we can rescale $w_{opt}$ and $b_{opt}$ correspondingly [24]. The data points that are closest to the boundary: that, those points $\{\mathbf{x}_i, t_i\}$ for which

```
$$\mathbf{w}^{opt} \cdot \mathbf{x}_i + b_{opt} = \pm 1$$$ (1.18)
```

are support vectors $\mathbf{x}^{(s)}$. That is why the algorithm is called a support vector machine. All the remaining examples in the training sample are **irrelevant** to determine where to place the hyperplane. After optimization, we get

```
$$\mathbf{w} = \sum_{i=1}^{N} \alpha_i \cdot \mathbf{x}_i, \quad \sum_{i=1}^{N} \alpha_i \cdot t_i = 0,$$ (1.19)
```

and we define the dual optimization problem that depends entirely on the training data and the Lagrange multipliers. Given the training sample $\{\mathbf{x}_i, t_i\}_{i=1}^{N}$, with $t_i \in \{-1, +1\}$ of linearly separable patterns, we want to find the Lagrange multipliers $\{\alpha_i\}_{i=1}^{N}$ that maximize

```
$$\Q(\alpha) = \sum_{i=1}^{N} \alpha_i - \frac{1}{2} \ \sum_{i=1}^{N} \sum_{j=1}^{N} \alpha_i \cdot \alpha_j \cdot t_i \cdot t_j \cdot \mathbf{x}_j^T \mathbf{x}_j$$$$ (1.20)
```

subject to the usual constraints

```
$$\sum_{i=1}^{N} \alpha_i \cdot t_i = 0$$$ (1.21)
```

and adding a new constraint

```
$0 \leq \alpha_i \leq C, \quad i = 1, 2, \dots, N$$$ (1.22)
```

where $C$ is a user specified positive parameter. Having determined the optimum Lagrange multipliers $\alpha_{opt,i}$ (not equal to zero) by solving a system of $N \times N$ linear equations, we may recover

```
$$\mathbf{w} = \sum_{i=1}^{N} \alpha_{opt,i} \cdot t_i \cdot \mathbf{x}_i,$$$$ (1.23)
```
