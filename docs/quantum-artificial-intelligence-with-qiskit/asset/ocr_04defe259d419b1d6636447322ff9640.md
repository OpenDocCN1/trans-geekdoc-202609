Deep learning enables high-level abstractions in data by architectures composed of multiple nonlinear transformations. It offers a natural progression from low-level structures to high-level structures, as demonstrated by natural complexity. [56, 84, 85, 83].

By increasing the number of layers we can increase the number of parameters faster. By doing so, we can add enough degrees of freedom to model large training sets. This is extremely helpful since nowadays a really large amount of data is collected for specific tasks.

The models achieved tremendous results, however they requires high computational resources of very large training sets which is a bottleneck in current quantum ML applications. However, quantum basic linear algebra subroutines can be used to speed up the deep learning algorithms, a kind of “mathematical” quantum coprocessor that can be used with a conventional computer.
