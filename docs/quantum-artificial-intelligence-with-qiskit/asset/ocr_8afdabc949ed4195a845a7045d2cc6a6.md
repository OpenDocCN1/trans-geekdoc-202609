# 22.2.5 Measurement

By measuring the auxiliary qubit with the result 0, we get

```
$|0\rangle \sum_{j=1}^{n} \left( 1 - \frac{C^2}{\lambda_j^2} \right) \cdot \beta_j |u_j\rangle$ \quad (22.29)$
```

and with the result 1

```
$C|0\rangle \sum_{j=1}^{n} \left( \frac{\beta_j}{\lambda_j} |u_j\rangle \right) = C|0\rangle A^{-1}(b) \approx C|0\rangle|x\rangle. \quad (22.30)$
```

We have to select the outcome of the measurement 1.

```
$|x\rangle = A^{-1}(b) = \sum_{j=1}^{n} \frac{\beta_j}{\lambda_j} |u_j\rangle$ \quad (22.31)$
```

# 22.2.6 Obtaining the Solution

Obtaining the required coefficient $x_i$ from $|x\rangle$ would require at least $n$ measurements, so the complexity of the algorithm would be $O(n)$ which prevents the cost on a classical computer for an approximate solution for a sparse matrix via gradient descent. We are interested in the global properties of $|x\rangle$ rather than the coefficients $x_i$. Many features describing the vector $|x\rangle$ can be efficiently extracted, for example in different values. We can well efficiently estimate if two solutions of two different equations are the same or not [39].

# 22.3 EXAMPLE

```
$A = \begin{pmatrix} 1 & -1/3 \ -1/3 & 1 \end{pmatrix}, \quad \mathbf{b} = \begin{pmatrix} 1 \ 0 \end{pmatrix}. \quad (22.32)$
```

and eigenvectors

```
$|u_1\rangle = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 \ -1 \end{pmatrix}, \quad |u_2\rangle = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 \ 1 \end{pmatrix}. \quad (22.33)$
```

and eigenvalues

```
$\lambda_1 = \frac{4}{3}, \quad \lambda_2 = \frac{2}{3}$
```

It follows

```
$U = e^{-i\frac{4}{3}\pi} \cdot |u_1\rangle\langle u_1| + e^{-i\frac{2}{3}\pi} \cdot |u_2\rangle\langle u_2| = \begin{pmatrix} \frac{1}{2}e^{-i\frac{4}{3}\pi} + \frac{1}{2}e^{-i\frac{2}{3}\pi} & \frac{1}{2}e^{-i\frac{4}{3}\pi} - \frac{1}{2}e^{-i\frac{2}{3}\pi} \ \frac{1}{2}e^{-i\frac{4}{3}\pi} - \frac{1}{2}e^{-i\frac{2}{3}\pi} & \frac{1}{2}e^{-i\frac{4}{3}\pi} + \frac{1}{2}e^{-i\frac{2}{3}\pi} \end{pmatrix} \quad (22.34)$
```

and

```
$U^* = e^{i\frac{4}{3}\pi} \cdot |u_1\rangle\langle u_1| + e^{i\frac{2}{3}\pi} \cdot |u_2\rangle\langle u_2| = \begin{pmatrix} \frac{1}{2}e^{i\frac{4}{3}\pi} + \frac{1}{2}e^{i\frac{2}{3}\pi} & \frac{1}{2}e^{i\frac{4}{3}\pi} - \frac{1}{2}e^{i\frac{2}{3}\pi} \ \frac{1}{2}e^{i\frac{4}{3}\pi} - \frac{1}{2}e^{i\frac{2}{3}\pi} & \frac{1}{2}e^{i\frac{4}{3}\pi} + \frac{1}{2}e^{i\frac{2}{3}\pi} \end{pmatrix} \quad (22.35)$
```
