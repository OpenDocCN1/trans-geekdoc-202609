# 23.1.1 Example

We use the parameterized qiskit circuit over two qubits $U_{\phi(x)} = ZZFeatureMap [21]$ where two parameters are defined by the data $bind\parameters$ with the two-dimensional vector $x$. The variational circuit contains the free parameter $w$ that will adapt during training. The TwoLocal circuit is a parameterized circuit consisting of alternating rotation layers and entanglement layers. The rotation layers are single gate applied on all qubits. The entanglement layer uses two-qubit gates to affect the qubits according to the direction. In our example, we will use the rotation gates RX and R and the entanglement controlled Z, CZ, with two repetitions in 12 free parameters. The two-dimensional vector $w$ defines the parameters by the $bind\parameters$. After the operations, we measure the two qubits (see Figure 23.1)

```
from qiskit import QuantumCircuit, QuantumRegister, Aer, execute
from qiskit.visualization import plot_histogram
import numpy as np
from qiskit.circuit.library import ZZFeatureMap, Local
```

```
x = [0.1, 0.1]
feature_map = ZZFeatureMap(feature_dimension=2, reps=2)
feature_map = feature_map.bind_parameters(x)
weights = np.array([3.28659325, 4.58859278, 5.13099949, 0.88732228, 4.08885928, 2.45568528, 4.92364943, 5.59302315, 3.66837805, 4.48623313, 2.4354561])
```

```
two_local = TwoLocal(2, ['rz', 'cz'], reps=2)
two_local = two_local.bind_parameters(weights)
```
