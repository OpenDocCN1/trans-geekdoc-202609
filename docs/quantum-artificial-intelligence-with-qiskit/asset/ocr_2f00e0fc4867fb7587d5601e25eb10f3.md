# 22.2.2 Kitaev's phase Estimation

After applying Kitaev's phase estimation algorithm to $U$ that was estimated by the Hamiltonian simulation for each value $j$, the values $\lambda_{kj}$ approximate the true value $\lambda_j$. For simplicity we assume

```
$$\sum_{j=1}^{n} \sum_{k=0}^{T-1} \alpha_{kj} \cdot |\lambda_{kj}|u_j\rangle \approx \sum_{j=1}^{n} \beta_j \cdot |\tilde{\lambda}_j|u_j\rangle$
```

# 22.2.3 Conditioned Rotation

We add an auxiliary state |0>

```
$$\sum_{j=1}^{n} \beta_j \cdot |\tilde{\lambda}_j|u_j\rangle|0$
```

and perform the conditioned rotation on the auxiliary state |0> by the operator R

```
$R = \begin{pmatrix} \cos \alpha & -sin \alpha \ \sin \alpha & \cos \alpha \end{pmatrix}$
```

with the relation

```
$$\alpha = \arccos\left(\frac{C}{\lambda}\right)$
```

with $C$ being a constant of normalization. For each eigenvalue indicates a special rotation we have

```
$$\sum_{j=1}^{n} \beta_j \cdot |\tilde{\lambda}_j|u_j\rangle(R((\lambda_j^{-1})|0\rangle)) =$
```

```
$$\sum_{j=1}^{n} \beta_j \cdot |\tilde{\lambda}_j|u_j\rangle\left(\frac{C}{\lambda_j}|1\rangle + \sqrt{1-\frac{C^2}{\lambda_j^2}}|0\rangle\right)$
```

# 22.2.4 Un-Computation

We uncompute the phase estimation procedure with $F_m = IF_m, CU^*$ resulting in the state

```
$|0\rangle\sum_{j=1}^{n} \beta_j \cdot |u_j\rangle\left(\frac{C}{\lambda_j}|1\rangle + \sqrt{1-\frac{C^2}{\lambda_j^2}}|0\rangle\right)$
```

```
$|0\rangle\sum_{j=1}^{n} (C \cdot \frac{1}{\lambda_j}|u_j\rangle + \sqrt{1-\frac{C^2}{\lambda_j^2}} \cdot \beta_j|u_j\rangle)|0\rangle$
```
