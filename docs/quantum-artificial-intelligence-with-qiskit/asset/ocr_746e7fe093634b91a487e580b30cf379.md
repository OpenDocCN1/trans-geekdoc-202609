# 9.2 REPRESENTATION

There are four different objects: three cells and one empty cell. Each object can be coded by two qubits (2²), and a configuration of the four objects can be represented by a register of eight qubits [x]. The object 1 is represented by 00, 2 is represented by 01, 3 is represented by 10, and empty space x is represented by 11. The state is represented by 8 qubits x₀ x₁, x₂, x₃ x₄ x₅ x₆ x₇, and the state of the Figure 9.1 is represented by the 8 qubits 10 11 00 01, Figure 9.3.

In this representation, position description (adjective) is fixed and the class descriptors moves. In the qiskit circuit, all qubits before the computation are in the state 0, so that the state of Figure 9.3 is prepared with the NOT gate with the following commands of the qubits 0 to 7:

```
qc.x(0)
qc.x(4)
qc.x(5)
qc.x(7)
```

In the 3-puzzle task, we have four different rules defined by the position of the empty space. Each of the rules has two instantiations, moving the empty space clockwise or a counter-clockwise move. We recognize the rules that indicate the presence of a rule by a qubit. We use four qubits to represent the presence of the four rules and call them trace. We need the trace represented by the four qubits, since we cannot delete the information and uncompute the output back. By uncomputing, we undo the rules. Additionally, we use a flag represented by a qubit that indicates to us if the rule with the corresponding instantiation can be executed or not. Finally, we need a qubit that represents the path description will be present by superposition using a Hadamard gate. Altogether, we use 14 qubits, and define the following circuit:

```
qc = QuantumCircuit(14,8)
#State Preparation 0-7
qc.x(0)
qc.x(4)
qc.x(5)
```
