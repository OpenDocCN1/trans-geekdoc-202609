## 11.3 NUMBER OF ITERATIONS

For A, B, C blocks $B_{max} = 6, B_{min} = 1,$ and

> $B_{average} = \frac{6 \cdot 1 \cdot 1 + 3 \cdot 6}{13} = 2.30769.$

Naively, we would assume that the branching factor is reduced by Grover's amplification to the number 8 represented by three qubits

> $\sqrt{8} = 2.82843$

With growing value $m$, the branching factor is reduced by Grover's amplification to

> $B_{average} = \sqrt{2.30769} = 1.51911.$

For $k$ solutions, the probability of measuring a state that represents one solution of $k$ solutions is related to the number $r$ of iterations of the Grover's operator. Simplified, we can state that relates

> $r = \sqrt{\frac{(8)^m}{k}} = (11.4)$

## Five Pennies Game

Games involving two players represent one of classic applications of symbolic solving. Starting with some initial position, the algorithm explores the tree of all legal moves down to requested depth. An example is the nim game in which two players take objects from distinct piles. Simplified version is the nim game with no piles, the five pennies game. Two players alternate one, two, or three pennies from a stack that contains five pennies. The player who pick up loses. The five pennies game is zero game where neither player has legal options. The first player loses, and the second wins if correct moves are chosen. We indicate architecture for the five pennies game and indicate that quantum search cannot implement minimax. We can determine the search path, but we cannot model the behavior of the player that chooses the best move since we cannot compare different states that are described by different descriptors.

### 12.1 QUANTUM CIRCUIT

In our implementation of five pennies game we explore legal moves to depth. In initial game the five pennies are represented by qubits 0 to 4. Player A starts the game, can remove one, two, or three pennies. The path descriptor is represented by two qubits 6 and 7. The qubit 5 is a flag that indicates a rule with path descriptor. The first rule removes three pennies, the second pennies and one penny. Since we have four possible paths, the three and four are identical. The player B has either a stack with three, four, or two pennies. Depending on the number of pennies, different rules can be executed, either the rule of type 1, type 2 or type 3. The correct type is identified and marked in trace represented by qubits 8, 9, and 10, see Figure 12.1. Each of the rules is instantiated with path descriptor and can be executed in parallel. The resulting states corresponding to one penny are marked by the oracle, see Figure 12.2. They correspond to the loss of player A, since the player who up the last pennies.
