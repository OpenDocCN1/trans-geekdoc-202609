Using the block examples, four operations "pickup", "putdown", "stack", and "un-
stack" can be defined [73]: The expressions are universally true, and therefore the universal quantifier ∀ is omitted.

```
pickup(x) {nP : gripping() ∧ clear(x) ∧ ontable(x)
A : gripping(x)
D : ontable(x) ∧ gripping() }
```

```
putdown(x) {nP : gripping(x)
A : ontable(x) ∧ gripping() ∧ clear(x)
D : gripping(x) }
```

```
stack(x, y) {nP : gripping(x) ∧ clear(x)
A : on(x, y) ∧ gripping(y) ∧ clear(x)
D : clear(y) ∧ gripping(y) }
```

```
unpack(x, y) {nP : gripping() ∧ clear(x) ∧ on(x, y)
A : gripping(x) ∧ clear(y)
D : on(x, y) ∧ gripping() }
```
