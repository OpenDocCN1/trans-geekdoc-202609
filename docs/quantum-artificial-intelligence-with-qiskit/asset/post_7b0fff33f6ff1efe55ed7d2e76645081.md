## 2.4 MEASUREMENT

After a unitary information processing start form an initial state the result of the algorithm is determined by the measurement. The measurement corresponds to the collapse of the state vector, a projection into a base state. The projection is not reversible and is not consistent with the unitary evolution. For a state represented by a unit-length vector

```
$$|omega_1 \cdot |x_1\rangle + \omega_2 \cdot |x_2\rangle + \dots + \omega_n \cdot |x_n\rangle$$
```

in n-dimensional Hilbert space $|x_y\rangle$ is observed. After the measurement (observation-state) is in a base

```
$$|1 \cdot |x_y\rangle$$
```

The state of a quantum system is projected to the subspace that corresponds to the observed state and the vector representing it is renormalized to the unit length. An observable describes a subspace for some dimensions with a special case of one dimension. A part of the system can be observed by a projection in a subspace with dimension higher than one. The compound system of n-dimensional Hilbert space $|x\rangle \in \mathcal{H}_n$ and a w-dimensional Hilbert space $|y\rangle$ defined by an orthonormal basis $|xy_{w} \rangle \in \mathcal{H}_{n-w}$. A state of the system is represented as

```
$$|xy\rangle = \sum_{i=1}^n \sum_{j=1}^w \omega_{ij} |x_i\rangle |y_j\rangle \quad (2.22)$$
```

For example

$|xy\rangle = \sum_{i=1}^{2}\sum_{j=1}^{2} \omega_{ij}|x_i\rangle|y_j\rangle = \omega_{11}|x_1\rangle|y_1\rangle + \omega_{12}|x_1\rangle|y_2\rangle + \omega_{21}|x_2\rangle|y_1\rangle + \omega_{22}|x_2\rangle|y_2\rangle$.

For simplicity we use the notation for a qubit register

$|xy\rangle = \omega_0 \cdot |00\rangle + \omega_1 \cdot |01\rangle + \omega_2 \cdot |10\rangle + \omega_3 \cdot |11\rangle$.

The probability of observing $x_k$ is $\sum_{j=1}^{w} |\omega_{kj}|^2$. If we observe $x_k$, the system after the observation is projected into

$|xy\rangle = \frac{1}{\sqrt{\sum_{j=1}^{w}|\omega_{kj}|^2}}} \sum_{j=1}^{w} \omega_{kj}|x_k\rangle|y_j\rangle$.

Suppose the two qubits are in the following state

$\sqrt{0.25} \cdot |00\rangle + \sqrt{0.25} \cdot |01\rangle + \sqrt{0.25} \cdot |10\rangle + \sqrt{0.25} \cdot |11\rangle = \begin{pmatrix} \sqrt{1/2} \\ \sqrt{1/2} \\ 0 \\ 0 \end{pmatrix}$.

The first qubit is $|0\rangle$. The probability of the observation is

$|\omega_{00}|^2 + |\omega_{01}|^2 = |\sqrt{0.25}|^2 + |\sqrt{0.25}|^2 = 0.25 + 0.25 = 0.5$

the system after the observation is projected into

$\sqrt{0.25} \cdot |00\rangle + \sqrt{0.25} \cdot |01\rangle = \sqrt{0.5} \cdot |00\rangle + \sqrt{0.5} \cdot |01\rangle = \begin{pmatrix} \sqrt{1/2} \\ \sqrt{1/2} \\ 0 \\ 0 \end{pmatrix}$.

## 2.5 COMPUTATION WITH ONE QBIT

A unitary operator on a qubit is called an unitary gate. It is described by a unitary matrix of the dimension $2 \times 2$. For the qubit with basis

$|0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, |1\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$,

the quantum gate $X$ does the operation on a qubit

$X(0) = |1\rangle, X(1) = |0\rangle$

and is represented by the unitary matrix

$$X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \quad (2.23)$$
