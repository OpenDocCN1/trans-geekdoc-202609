# 13.2.1 Storage Algorithm

The initial state is

```
$|psi_0\rangle = |0\dots0:1;0;pattern_p\rangle$
```

with control qubit $c_2=1$ indicating that this is a processing branch. In the next steps are described by a loop that stores $m$ binary patterns

```
$|pattern_m\rangle, |pattern_{m-1}\rangle, \dots |pattern_1\rangle$
```

FOR $p = m$ TO 2 STEP -1

+   - Load the pattern $pattern_p$ into the load register.
- IF $p = m$ THEN BEGIN
  - Invert the ground state of the memory register of the processing branch to $[11\dots1]$ using NOT gates.
- ELSE BEGIN
  - Copy the pattern $pattern_p$ into the memory register of the processing branch $c_2=1$ using cX gate, controlled controlled not gate.
  - Copy the pattern $pattern_p$ into the memory register of the memory branch $c_2=0$ using $\epsilon$ cX gate (CNOT gate, controlled not gate, invert $c_2$). As a result the memory register of the processing branch is in the ground state $[00\dots0]$, this is not the case for the memory register of memory branches where the bits are flipped.
  - Invert the ground state of the memory register of the processing branch to $[11\dots1]$ using NOT gates to all memory registers. Only the memory register of the processing branch represents $[11\dots1]$.
- The control qubit $c_1=1$ is entangled with the memory register $[11\dots1]$ by the multi-controlled $X$ (Toffoli) gate. As a result the control qubit $c_1=1$ is entangled with the processing branch.
- The processing branch is split by the operator $CS_p$. Since the control qubit $c_1=1$ is entangled with the memory register we create a new memory branch and a processing branch.
