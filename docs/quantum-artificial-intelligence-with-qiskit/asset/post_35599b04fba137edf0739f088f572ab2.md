## 2.8 CLONING

A linear operation that would produce a copy of an arbitrary quantum state is not possible. We cannot copy an unknown amplitude distribution of a state. This has profound implications in the field of quantum computing, since we cannot reuse an arbitrary quantum state.

To perform this we define a copy machine. We use one orthonormal basis of the orthogonal space, for example $|x_1\rangle$ and define a unitary copy operator that copies $|x\rangle \in H_n$ as:

$$U_{copy}(|x\rangle, |x_1\rangle) = |x\rangle|x\rangle. \quad (2.38)$$

Does $U_{copy}$ exist? For basis states $U_{copy}$ is defined. It can be realized for example $CX$ with $|x_1\rangle = |0\rangle$ and $|x_2\rangle = |1\rangle$,

$$U_{copy}(|x_1\rangle, |x_1\rangle) = |x_1\rangle|x_1\rangle$, $U_{copy}(|x_2\rangle, |x_1\rangle) = |x_2\rangle|x_2\rangle.$$

If this is in a superposition

$$|x\rangle = \frac{|x_1\rangle + |x_2\rangle}{\sqrt{2}}$$

it implies that

$$U_{copy}(|x\rangle, |x_1\rangle) = |x\rangle|x\rangle = \left(\frac{|x_1\rangle + |x_2\rangle}{\sqrt{2}}\right) \otimes \left(\frac{|x_1\rangle + |x_2\rangle}{\sqrt{2}}\right) = \frac{1}{2} \cdot (|x_1\rangle|x_1\rangle + |x_1\rangle|x_2\rangle + |x_2\rangle|x_1\rangle + |x_2\rangle|x_2\rangle).$$

Because of the linearity of $U_{copy}$ it follows,

$$U_{copy}(|x\rangle, |x_1\rangle) = U_{copy}\left(\frac{|x_1\rangle + |x_2\rangle}{\sqrt{2}}, |x_1\rangle\right) =$$

$$U_{copy}(|x\rangle, |x_1\rangle) = U_{copy}\left(\frac{|x_1\rangle|x_1\rangle + |x_2\rangle|x_1\rangle}{\sqrt{2}}\right) =.$$

$$U_{copy}(|x_1\rangle|x_1\rangle) + U_{copy}(|x_2\rangle|x_1\rangle) = \frac{1}{\sqrt{2}} \cdot (|x_1\rangle|x_1\rangle + |x_2\rangle|x_2\rangle)$$

it leads to a contradiction. An operation that would produce a copy of an arbitrary quantum state is not possible and we cannot copy an unknown amplitude distribution of a state. For example we cannot copy an unknown qubit $\alpha|0\rangle+\beta|1\rangle$. The amplitude distribution is specified by the values of $\alpha$ and $\beta$.

## 2.9 PHASE KICK-BACK

If we apply CX gate to the target value $\frac{|0\rangle}{\sqrt{2}}$ with the control qubit $|1\rangle$ we get

$$CX|1\rangle \cdot \left(\frac{|0\rangle}{\sqrt{2}}\right)=|1\rangle \cdot \left(\frac{X|0\rangle - X|1\rangle}{\sqrt{2}}\right)$$
$$CX|1\rangle \cdot \left(\frac{|0\rangle}{\sqrt{2}}\right)=|1\rangle \cdot (-1\right) \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)$$
$$CX|1\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)=-|1\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)$$

For the control qubit $|0\rangle$ does nothing,

$$CX|0\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)=|0\rangle \cdot \left(\frac{|0\rangle - |1\rangle}{\sqrt{2}}\right)$$

We say that the value (phase) is being "kicked back" to the control register.
