Figure 13-14 shows a real-world phishing URL that pretends to be affiliated with Google. I received a phishing email that claimed to be from Google. It had a file attachment and message that stated I had to execute an “emergency patch” for Google Chrome. I knew that Google Chrome already had its own auto-update service running on my computer, and I never had to run a separate file to update Google Chrome. The phishing email also included a rogue URL with a DNS domain of googlechromeupdates.com. I was interested in learning if Google actually owned that domain. So, I did a Whois query on that domain, and found out, not surprisingly, that Google did not own the domain.
