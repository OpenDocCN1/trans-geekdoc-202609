# Hostname

After the two forward slashes and the colon, usually what follows is the name of the host computer where the object being referenced in the URL is located. For example, if you see www, that means the hostname of the computer hosting the website is www. The hostname can be missing (in which case it might be guessed at by the involved tool after using the URL). The hostname can be the “real” hostname that the computer is logically labeled with, or it can be a virtual hostname advertised and published by the web server software. For example, www is the hostname in many URLs, but the hostname of the computer referenced in the URL is usually not really www. www is usually just a “virtual name” published and advertised by the web server software running on the host. If there is a hostname, it will be followed by a period.

# DNS Domain Name

The Domain Name Service (DNS) domain name follows the hostname and period (if there is a hostname and period). This is the logical location on the Internet as defined by the Domain Naming Service (DNS). The DNS domain name will end with a period and a “top-level” domain (TLD) name, such as .com, .pub, or .gov., followed by another period.
