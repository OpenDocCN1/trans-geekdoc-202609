These programs will monitor what a user types into their browser search bar and often instead take the user to where the browser hijacker wants to go. Browser hijackers can also steal login information, banking information, and other website details.

*Browser notification phishing* is a particular type of phishing that originates from the user’s operating system or browser notification features. Most of today’s most popular operating systems and browsers have an industry-standard message notification feature built into them, which allows websites and apps to ask for permission to send messages (see Figure 2-9). We’ve probably all been prompted to approve notifications at least a few times.
