# # Examining Emails

All emails can be examined for more details about where they came from and who made them. There are a variety of tools and techniques that can be used and the most common will be shared here.

There are many common signs of phishing in the text of a message. They include the following:

+   * Email/message/call arrives unexpectedly.
+   * It’s asking you to do something that person or company has never asked you to do before.
+   * The requested action could be harmful, if malicious.
+   * The message tries to create a sense of urgency (“stressor”).
+   * It contains a suspicious URL link or file attachment.
