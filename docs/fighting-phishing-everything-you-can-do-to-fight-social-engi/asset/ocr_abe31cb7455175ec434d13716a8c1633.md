The DNS domain is where inputting or clicking on the URL is going to take you. If it points to a legitimate domain, then you can likely (most of the time) trust the URL. If it points to a domain name you don't immediately recognize, you must use caution. For example, if you get an email that you think might be a phishing email, but you are not sure, check out the DNS domain name on the included URL. If it says microsoft.com, facebook.com, instagram.com, paypal.com, knowbe4.com, or some other legitimate DNS domain that is the normal legitimate domain name for the brand the email says it's from, then more than likely you can trust the email. If the DNS domain is strange-looking or unusual (e.g., microwsoft.com, facebook.biz, know.be.4.com, etc.), then there is a greater chance than not that the email is rogue.
