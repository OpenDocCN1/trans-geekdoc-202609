## 4.11. Libraries for Natural Language Processing

Here we will see some python libraries for NLP

### Natural Language Toolkit(NLTK)

`NLTK` Python framework is a very famous NLP tool. It is not only used for education and research but also used in production environments. It is effortless and free to use the tool.
Features: Tokenization, Named Entity Recognition, Part of Speech tagging, Sentiment analysis

### spaCy

`spaCy` is another widely used open-source natural language processing library available for python. It is swift and optimal and used mainly for production environments.
Features: Tokenization, Named Entity Recognition, Part Of Speech tagging, Sentiment analysis, Dependency parsing

### TextBlob

`TextBlob` is a python library used for processing large textual data.
Features: Classification, Noun phrase extraction, Language translation, Part-of-Speech tagging, Sentiment analysis, Wordnet integration.

### Gensim

`Gensim` is another NLP python framework used for similarity detection. Although it is not a general-purpose NLP library, it handles the assigned tasks very well.
Features: Non-negative matrix factorization, TF-IDF, Latent semantic analysis

### Pattern

`Pattern` is an NLP python framework with straightforward syntax that is used for scientific research purposes and production. It is a potent and valuable tool for NLP researchers and students.
Features: Named entity recognition, Tokenization, Part of Speech tagging, Parsing, Sentiment analysis

### 5.1. Artificial Neural Network

Artificial Neural Network is a relatively new and efficient system whose key working idea is based on biological neural networks. `ANN` is also known as "artificial neural systems" or "connectionist systems." Artificial Neural Networks are composed of lots of small interconnected units called nodes or neurons, and these units are capable of exchanging information between them. These units can be considered as simple processors that have the ability to operate in parallel. There exist a connection between each neuron, and the connections are associated with a weight. This weight bears information about the input signal. The presence of weights is essential, and a key factor for `ANN`; changes to these connection weights can excite or inhibit the input signal being communicated. Each neuron has an internal activation function, and only the input signals satisfying the activation function pass through the neuron. The output of such neurons is again fed as he input to the other linked neurons. Now let us consider the Biological Neuron for understanding the fundamental principles.
