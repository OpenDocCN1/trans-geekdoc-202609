## 4.1. 自然语言处理 (NLP)
人类表达信息的方式完全是非结构化的。人类通常用词语和句子进行交流，而不是表格、列表或 Excel 表格。由于人类书写和口语是非结构化的，机器和计算机理解其复杂性非常高。自然语言处理 (NLP) 解决这个问题。它帮助计算机和机器理解非结构化的文本和语音，以从中提取有意义的信息。你可以将自然语言处理 (NLP) 视为人工智能 (AI) 的一个子领域，它帮助计算机与人类交互。

### NLP 的应用
1. 语音识别
2. 语言翻译
3. 自动问答
4. 自动文本摘要生成
5. 聊天机器人
6. 拼写和语法检查
7. 自动建议和自动完成
8. 电子邮件垃圾邮件检测器
