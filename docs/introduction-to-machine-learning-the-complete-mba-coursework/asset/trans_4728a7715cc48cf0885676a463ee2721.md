## 3.5. Fuzzy C Means 聚类

模糊聚类是一种适用于数据点可以存在于多个簇中的聚类形式。模糊聚类另称为软 ![](Image00208.jpg)-means 或软聚类。每个数据点都表现出属于每个簇的概率。我们可以说隶属系数对应于元素属于特定簇的程度。距离簇中心更近的点比位于簇边界的点具有更高的隶属度。让我们考虑一个示例。例如，一片叶子可以是绿色或黄色（硬聚类），但一片叶子也可以是绿色并且是黄色（模糊聚类）。在这里，叶子可以在一定程度上是绿色，也可以是在一定程度上是黄色。与其说叶子属于绿色 ![](Image00290.jpg) 而不属于黄色 ![](Image00291.jpg)，不如说叶子可以属于绿色 ![](Image00292.jpg) 和黄色 ![](Image00293.jpg)。尽管这些值是 ![](Image00225.jpg) 和 ![](Image00190.jpg)，但它们不代表概率，并且这两个值的总和不一定等于 ![](Image00223.jpg)。聚类的模糊性可以用聚类的 Dunn 分区系数 ![](Image00294.jpg) 来解释，其中 ![](Image00208.jpg) 表示簇的总数。Dunn 分区系数定义为所有隶属系数的平方和除以数据点的总数。![](Image00294.jpg) 的值介于 ![](Image00295.jpg) 之间。Dunn 系数的低值表示非常模糊的聚类，而接近 ![](Image00223.jpg) 的值表示接近清晰的聚类。我们之前看到的其他聚类形式与模糊聚类的关键区别在于，在模糊聚类中，数据点可以存在于多个簇中，而在 ![](Image00208.jpg) means 或 ![](Image00208.jpg) medoid 聚类中，数据点只能与一个簇相关联。最受欢迎的模糊聚类技术之一是模糊 c-means `(FCM)` 技术。在 `FCM` 中，簇质心计算为所有数据点的均值，按其属于该簇的程度加权。正如我们之前讨论的，模糊 c-means 聚类算法旨在最小化下面给出的成本函数 ![](Image00296.jpg) 其中 ![](Image00297.jpg) 表示数据点 ![](Image00273.jpg) 属于簇 ![](Image00134.jpg) 的程度，![](Image00298.jpg) 表示簇 ![](Image00299.jpg) 的中心，![](Image00300.jpg) 称为模糊化因子。可以看出，模糊 c means 算法与 ![](Image00208.jpg) means 算法不同之处在于引入了隶属值 ![](Image00301.jpg) 和模糊化因子 ![](Image00018.jpg) 我们可以如下定义 ![](Image00302.jpg) 作为 ![](Image00303.jpg) 从上式可以清楚地看出，隶属度 ![](Image00297.jpg) 与数据点 ![](Image00005.jpg) 到簇中心 ![](Image00066.jpg) 的距离成反比。参数 ![](Image00018.jpg) 表示聚类的模糊性，![](Image00018.jpg) 的取值范围在 ![](Image00304.jpg) 之间。如果 ![](Image00018.jpg) 的值更接近 ![](Image00223.jpg)，则该聚类与 ![](Image00208.jpg)-means 聚类非常相似，而 ![](Image00018.jpg) 的值接近 ![](Image00305.jpg) 会导致聚类完全模糊。模糊 c means 中簇的质心由所有点的均值与属于该簇的程度之比给出。质心 ![](Image00306.jpg) 由方程 ![](Image00307.jpg) 给出 这里 ![](Image00306.jpg) 是簇的质心，![](Image00297.jpg) 表示数据点 ![](Image00273.jpg) 属于 ![](Image00306.jpg) 的程度。现在让我们看看模糊 c means 聚类的算法。

## 3.6. DBSCAN

`DBSCAN` 算法（基于密度的具有噪声的空间聚类）专门用于聚类大型数据集。`DBSCAN` 背后的思想是创建具有最小点数和密度的簇。密度是彼此一定距离内数据点的最小数量的度量。这一思想有助于排除异常值形成的簇。任何簇中的最小点数必须最初定义；让我们用 ![](Image00310.jpg) 表示该参数。![](Image00311.jpg) 是另一个参数，定义簇内数据点之间保持的阈值距离。![](Image00311.jpg)-邻域或数据点的邻域定义为落在 ![](Image00311.jpg) 距离内的点集。在 `DBSCAN` 算法中，输出中的簇数不是预先定义的；相反，算法确定簇数 ![](Image00308.jpg)。为了理解 `DBSCAN` 及其操作，必须理解密度的概念。如果 ![](Image00314.jpg) ![](Image00315.jpg)，则数据点 ![](Image00312.jpg) 被认为是从数据点 ![](Image00313.jpg) 直接密度可达的 第一部分确保数据点 ![](Image00316.jpg) 位于可接受范围 ![](Image00311.jpg) 内。定义的第二部分确保彼此靠近的最小核心点数 ![](Image00317.jpg)。这些核心点有助于簇的中心部分。直接密度可达点必须指向这些核心点之一，但它本身不必是核心点。在这种情况下，它被称为边界点。只有当从一个到另一个存在直接密度可达点的链时，两点才被认为是密度可达的。该属性确保任何簇都将具有非常接近大量其他数据点（核心点）的核心数据点，然后是一些接近至少一个核心点的边界点。让我们尝试用示例图来解释 ![](Image00311.jpg) 邻域、核心点和密度可达的概念。在图 3.1 的第一部分 ![](Image00318.jpg) 中，由于 ![](Image00310.jpg) 的值为 ![](Image00319.jpg)，点 ![](Image00312.jpg) 在邻域内有 4 个数据点，因此数据点 ![](Image00312.jpg) 被认为是核心点。在图 3.1 的第二部分 ![](Image00320.jpg) 中，有五个核心点，并且请注意，在 ![](Image00312.jpg) 邻域内的 4 个点中，只有 3 个本身是核心点。这 4 个点被认为是直接从 ![](Image00312.jpg) 密度可达的。点 ![](Image00313.jpg) 不是核心点，因此称为边界点。我们将点划分为彼此都很接近的核心点集；然后是边界点，它们接近至少一个核心点；最后是剩余点，它们不接近任何核心点。![](Image00321.jpg) 显示即使点 ![](Image00322.jpg) 不是核心点，它也是从 ![](Image00313.jpg) 密度可达的。![](Image00323.jpg)
