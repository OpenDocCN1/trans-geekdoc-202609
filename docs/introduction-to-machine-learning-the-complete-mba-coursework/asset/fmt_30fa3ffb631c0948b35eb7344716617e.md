## 3.4. K-Medoids Clustering or PAM (Partitioning Around Medoids)

`K` medoid clustering is otherwise called `PAM` (partitioning around medoid). In this type of clustering, a medoid represents each cluster. This method effectively handles outliers since it is using medoids for clustering. Outliers are the data points that could not be included in any clusters; they can either be ignored or considered a new cluster. We start the `K`-medoid clustering by taking a random set of ![](Image00208.jpg) data points as the set of medoids. Then at each step, all data points that are not medoids are analyzed one by one to see if they should be medoids. As we progress, the algorithm decides whether there is an item among data points to replace existing medoids. The algorithm chooses the pair that enhances the overall quality of the clustering the best and exchanges them. The Sum of all the distances from a non-medoid object to the medoid for the cluster is computed to determine the clustering quality. ## 3.5. Fuzzy C Means Clustering

The point closer to the center of a cluster has a high degree of membership than the points in the boundaries of a cluster. Let us consider an example. ## 3.6. DBSCAN

`DBSCAN` algorithms (density-based spatial clustering of applications with noise) are specially used for clustering large datasets. The idea behind `DBSCAN` is to create clusters having a minimum number of points and density. Density is a measure of the minimum number of data points within a certain distance of each other points. This idea helps to exclude the cluster formation by an outlier. The minimum number of points in any cluster must be defined initially; let us denote that parameter with ![](Image00310.jpg). ![](Image00311.jpg) is another parameter that defines the threshold distance to maintain between data points within a cluster. The ![](Image00311.jpg)-neighborhood or neighborhood of a data point is defined as the set of points that falls within a distance of ![](Image00311.jpg). In the `DBSCAN` algorithm, the number of clusters in the output is not pre-defined; instead, the algorithm determines the number of clusters ![](Image00308.jpg). In order to understand `DBSCAN` and its operations, one must understand the concept of density. A data point ![](Image00312.jpg) is said to be directly density reachable from data point ![](Image00313.jpg), if ![](Image00314.jpg) ![](Image00315.jpg) The first part ensures that the data points ![](Image00316.jpg) lies within the acceptable range ![](Image00311.jpg). The second part of the definition ensures a minimum number of core points close to each other ![](Image00317.jpg). These core points contribute to the central portion of the cluster. A directly density-reachable point must be done to one of these core points, but it need not be a core point itself. In that case, it is called a border point. Two points are said to be density-reachable only if there exists and chain of directly density-reachable points from one to another. This property ensures that any cluster will have core data points very close to a larger number of other data points (core points) and then some border points close to at least one core point.
