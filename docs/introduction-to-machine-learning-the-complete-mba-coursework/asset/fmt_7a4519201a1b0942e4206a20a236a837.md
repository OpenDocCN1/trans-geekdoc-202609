## 5.4. Types of Artificial Neural Networks

Now let us see different types of artificial neural networks. Based on the architecture of neural networks, there are mainly three types. They are
- `Feedforward Network`
- `Feedback Network`
- `Lateral Network`

### 5.4.1. Feedforward Network

![](Image00371.jpg) As shown in the above figure, there are three layers in this type of network. They are the input layer, the hidden/middle layer, and the output layer. The first layer is the input layer, and the number of neurons in this layer is proportional to the number of inputs. The input layer is said to be a passive layer since the neurons in this layer will not participate in processing the data. They just pass input to the next layers. The second layer is a hidden layer, and they receive inputs from the input layer. The number of neurons and the layers in the hidden layer are arbitrary and vary according to the model design. Neurons in this layer as said to be active since they participate in data processing and signal modification. The third layer of this architecture is the output layer; they are also active layers. The number of neurons in this layer is proportional to the neural network's output values. `Feedforward networks` can have multiple hidden layers depending on the model design. ![](Image00372.jpg) `Feedback neural networks` are the network in which feedback is present, that means the output of neurons in the networks is either directly or indirectly fed back to its input via other linked neurons. `Feedback neural networks` are otherwise called `Recurrent Neural Networks`. `LSTM` (`Long Short-Term Memory`) is an example of `RNN`.

## 5.6. Need For Deep Learning

Deep learning models are often known as deep neural networks because most deep learning models are implemented using neural networks. The idea behind the term “deep” is from the usage of more hidden layers in neural networks. A deep neural network may contain more than 100 hidden layers than two or three layers of standard neural networks. Machine learning extracts relevant features manually from the data set, and these features are used to create a model, but in deep learning, relevant features are automatically extracted from the dataset. Another critical difference is that deep learning is designed to use for large data sets and are usually scalable.

## 5.7. Convolutional Neural Networks

[Convolutional neural networks](https://www.mathworks.com/discovery/convolutional-neural-network-matlab.html) (`CNN` or `ConvNet`) are among the most popular deep neural networks, the technique being used in many of the deep learning applications. `CNN` is suitable for 2-D data because `CNN`'s operation is a 2-D convolution of extracted features with input data. `CNN` is widely being used for deep learning over image data. The advantage of `CNN` is that there is no need for manual feature extraction. The system is designed to extract features directly from input data. You do not need to define and provide the relevant features. Since the feature extraction is automated, `CNN` based deep learning models can be used for real-time object detection and provide high accuracy for computer vision. Below is a simple architecture of a convolutional neural network. There are several convolutional layers, optional pooling layers, and fully connected layers. Let us see each layer in detail below.

### 5.7.1. Convolution Layer

The fundamental of a `CNN` resides in the convolution operation. Hence they got the name convolutional neural networks. The first layer of `CNN` is convolution, and this layer is being used to extract features from input data. The convolution stage convolves a feature map of an input hidden layer with a weight matrix and produces an output feature map. There are four dimensions associated with a weight matrix; the first two are the number of feature maps of the convolutional input layer ![](Image00388.jpg) and the number of feature maps of the convolutional output later ![](Image00389.jpg). The other two are the size of the receptive field width and receptive field height. In `CNN`, a subset is convolved instead of the whole input data or image, and the goal is to find similar patterns in the input data irrespective of the pattern’s position in the data. The pixel relationships are preserved by learning image features using small squares of input data. The stride determines the size of the resulting output image (width x height). The stride is simply the number of pixels by which one slides in the vertical and/or the horizontal direction before applying the convolution operation. Typically `ReLU` is used at the convolutional layers. In short, convolution is a mathematical operation that takes two inputs, such as an image matrix and a filter. The convolutions in `CNN` can often become complicated but aid in resolving complex problems.
