### 2.2.4. Logistic Regression
Logistic regression is a suitable regression analysis to conduct when the dependent variable is dichotomous (binary). Unlike linear regression, the dependent variable of logistic regression is discrete rather than continuous. Logistic regression is applied to describe data and the relationship between one dependent binary variable and one or more ordinal, nominal, interval, or ratio-level independent variables. Sometimes logistic regressions are challenging to interpret; the Intellects Statistics tool easily allows you to conduct the analysis, then in plain English interprets the output. Logistic regression was employed in the biological sciences in the early 20th century. It was then practiced in many social science applications as well. Logistic regression is implemented when the dependent variable (target) is categorical. For example, Whether the tumor is malignant (1) or not (0) To predict whether an e-mail is spam (1) or not (0) Consider a case where we need to classify whether a tumor is malignant or not. If we use linear regression for such a problem, there is a need for setting up a threshold based on which classification can be done. If the actual class is malignant, the threshold value is 0.7, and the predicted continuous value 0.6, the data point will be classified as not malignant, leading to severe consequences in real-time. From the above example, it can be inferred that linear regression is not suitable for classification problems. Linear regression is unbounded, and this brings logistic regression into the picture. Its value strictly ranges from 0 to 1. Types of Logistic Regression - Binary Logistic Regression: The categorical response has only two possible outcomes. Example: Spam or Not. - Multinomial Logistic Regression: It deals with three or more categories without ordering. Example: Predicting which food is preferred more (Veg, Non-Veg, Vegan). - Ordinal Logistic Regression: It deals with three or more categories with ordering—for example, A movie rating from 1 to 5.

## 2.3. Classification
Classification is simply the process of mapping inputs to categorical labels, and a model that performs this task is said to be a classifier. Regression is generally applied for numerical problems, i.e., forecasting the turnover for the upcoming business year. Classification problems are quite different and applied to map inputs to corresponding labels. For example, consider a simple bank activity; the bank's automated system can decide to map a customer's loan request to either "safe" or "risky". Here in this example, "safe" and "risky" were the labels. Classification is a two-step process; the first step is the learning stage for the model. The model is created with a training set. The training stage includes inputs and their corresponding correct labels. Since the class label of each training inputs is provided, this step is also known as supervised learning (teacher present - correct outputs known). The second stage uses the trained model and uses it to classify the new inputs to corresponding labels. Mathematically you can write a classified as ![](Image00008.jpg)The first stage of classification can be considered as the generation of function ![](Image00007.jpg)and the second stage as the operation of function ![](Image00007.jpg)on input ![](Image00005.jpg)to generate corresponding class label ![](Image00006.jpg). The classifier's accuracy is given as the ratio of correctly classified test samples to total test samples. Once a classifier is generated with accepted accuracy, then it is used for classification. You can compare different classifiers with the parameters such as accuracy, speed, robustness, and scalability. Accuracy, as we explained before, refers to the given classifier's ability to predict the label correctly, speed refers to the computational resources required to perform the classification, robustness refers to the ability of the system to perform when incomplete or noisy data is given. Scalability refers to the ability of classifiers to handle a large amount of data.

### 2.3.1. Challenges in classification
Data cleaning: Data cleaning is a pre-processing stage in classification to reduce uncertainty in the learning process and produce a classifier with better accuracy. The input data should be analyzed for the presence of noise and absence of valuable data, i.e., missing values. Noise can be treated using several smoothening techniques, and missing values can be solved either by replacing that value with a most commonly observed value or using statistical methods to predict that value. Relevance analysis: Relevance analysis can be used to identify relevant features that are important for classification. One example of relevance analysis is a correlation. If two features are highly correlated, one of those could be removed in the pre-processing stage. Feature subset selection can also be used to reduce the set of features. This technique can be used to find a reduced set of features so that the resulting probability distribution of the data classes is as close as possible to the original distribution obtained, using all features. The classification problem can be further simplified and made cost-effective by removing features that do not contribute to the classification using these two-relevance analysis techniques. Such attributes may slow down the whole classifier and fail during performance comparison against other classifiers. Data transformation and reduction: Data normalization is a very important pre-processing for classification. For example, consider some features such as distance, or income, etc. These typically have large integer values, and operation on these large values is complex for complex classification networks or deep networks. Using such data could slow down the whole classification process, and there will be huge performance loss. In order to address the above problem, we will use a technique called normalization. Normalization scales all values for a given feature so that they fall within a small specified range, like −1.0 to 1.0 or 0.0 to 1.0. Normalization applies to numerical data such as distance, salary, and turn over. Another data transformation technique is Generalization; data can be generalized to higher-level concepts to avoid complexity. For example, feature marks can be generalized to Grades. Similarly, profit can be generalized to low, medium, and high, and categorical attributes, like streets, can be generalized to higher-level concepts, like a city. The generalization process compresses the original data to be trained, resulting in fewer input-output operations and leading to less memory utilization, thereby achieving better performance. Different types of classification techniques are available such as decision tree classification, Bayesian, Support Vector Machines (`SVM`), K-Nearest Neighbour classification, etc. We will go through these classification techniques in this chapter.

## 2.4. Decision Tree Classification
The decision tree is a supervised learning technique that can be used for both classification and Regression problems, but mostly it is preferred for solving classification problems. A decision tree is simply a tress structure, where each internal node denotes a question/test on the attribute, each branch represents the possible outcome of that question/test, and each leaf node represents the class label. A decision tree simply asks a question, and created on the answer (Yes/No), it further split the tree into sub-trees. The process of generating decision trees from the labeled training samples is called decision tree induction. The topmost node in a tree is the root node. We use the `CART` algorithm to construct a tree, which stands for Classification and Regression Tree algorithm. The decisions or the test are performed based on features of the given dataset. The graphical representation of the decision tree depicts all the possible solutions to a problem/decision based on given conditions. It is called a decision tree because, like a tree, it starts with the root node, which expands on further branches and constructs a tree-like structure. Let us consider a bank processing of loan application. First, at the root node, the applicant's age group is checked, and for age groups such as youth and middle age, employment status is checked. For old age, past history of pending loans checked. According to the answers to such test questions, each application is classified to label "safe" or "risk." ![](Image00064.jpg)The decision tree classifiers are so popular because decision tree classifiers are reasonably simple and do not require any domain knowledge and specific parameter settings. Decisions trees can easily handle high dimensional data, thereby mostly useful in all forms of applications such as bio-medical, financial analysis, manufacturing, production, astronomy, and physics. In fact, decision trees are the basics of several rule-based induction systems such as online shopping sites. Advantages of the Decision Tree - It is simple to comprehend as it follows the same process that a human follows while making any real-life decision. - It can be very valuable for solving decision-related problems. - It benefits to think about all the possible outcomes for a problem. - There is less requirement for data cleaning related to other algorithms. Disadvantages of the Decision Tree - The decision tree covers lots of layers, which makes it complicated. - For more class labels, the computational complexity of the decision tree may influence growth. - It may have an overfitting issue, which can be determined using the Random Forest algorithm.

### 2.4.1. Feature Selection Measures
Deciding which features to be considered as the root node at each decision tree level is a challenging task in a decision tree algorithm. Various methods have been introduced to assign numerical values to the various features such that the values resemble the relative importance of the features. Such measures are called feature selection measures. There are two widely used feature selection measures; they are information gain and Gini index. In order to understand these feature selection methods, one must be familiar with entropy. Let us discuss these terminologies below. - Entropy The degree to which a subset of examples contains only a single class is known as purity, and any subset composed of only a single class is called a pure class. Simply entropy is a measure of impurity in a dataset. Sets with high entropy are very diverse and provide little information about other items that may also belong in the set, as there is no apparent commonality. The measure of entropy is bits. Entropy values range from 0 to 1 when there are only two classes. If there are n classes, entropy ranges from 0 to log2 (n). If entropy is minimum, it indicates that the sample is homogeneous means less dissimilarity. In contrast, the maximum value of entropy indicates that the data is much more diverse.
