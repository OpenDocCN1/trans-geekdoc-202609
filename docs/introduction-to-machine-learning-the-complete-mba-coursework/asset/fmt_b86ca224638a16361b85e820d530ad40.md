### 4.9 Bag-of-Words method

In this method, raw text is analyzed to extract meaningful features. It is said to be a bag of words since the words are mixed up; that is, there is no order in these words' occurrence. This model transforms the given text into words, and it also records the frequency of the words in the text. In short, you can consider bag words as a representation of a sentence as a collection of words with a frequency of occurrence with no given importance to the order. ![](Image00338.jpg)

1. `Raw Text`: This is the input text on which we operate
2. `Clean Text`: Unnecessary characters such as punctuation marks and stop words are removed to clean up the text.
3. `Tokenize`: The sentence is represented as a group of tokens or words.
4. `Building Vocab`: This contains total words used in the text after removing unnecessary data.
5. `Generate Vocab`: This contains the words along with their frequency of occurrence in the sentences.

### 4.10 Term Frequency — Inverse Document Frequency (TF-IDF)

`Term Frequency — Inverse Document Frequency (TF-IDF)` is a word scoring measure used for information retrieval and summarization. The term is used to express the importance of a word in a given text. The word that appears multiple times in a document can be considered an essential word compared to other words that appear fewer times. If a word appears many times in a document and the same word frequently appears in some other documents, then the word can be considered a general occurring word, and we cannot assign much importance to it. Suppose we want to search for “quality mobile” and consider the search done on an extensive database with mobile descriptions. The search program is designed to display the closest response to the user query. The search engine will compute the `TF-IDF` to calculate the score for all of our available descriptions in the database, and the result with the higher score will be retrieved as a search result. If there exists an exact match for the user query, there is no need for `TF-IDF` calculation, and the exactly matched description is shown as a result. Suppose we have the following description in our database
1. The good mobile
2. a quality cell
3. a fast mobile
4. the cheap mobile cell phone

Description a has one word out for three words in the user query; description c has one-word matching user query also description d has one-word matching a user query. However, description b has the one-word “quality,” which is an essential word. So the search program will display description b as the search result. Now, if you look at the descriptions, you can see that the word “mobile” is common in the descriptions, and therefore it will have a significantly lesser `IDF` value and, thereby, a lower `TF-IDF` value. If you consider the word “quality,” it rarely appears in the other descriptions and has a high discriminating power compared to the word “mobile”. Hence, the `TF-IDF` value will be higher, and the search program can conclude the result as description b. `TF*IDF` score is directly proportional to the importance of the term; that is, higher the `TF*IDF` score, valuable the term, and vice versa Equations for `TF`, `TF-IDF`, `IDF`
