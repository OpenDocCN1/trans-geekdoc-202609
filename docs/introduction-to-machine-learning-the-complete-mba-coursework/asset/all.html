1.2.1.                          Supervised Learning
The supervised learning algorithms use labeled data for training the models deployed for learning intelligent behavior. Most of the real-world data collected are unlabelled and need to be annotated carefully if supervised learning algorithms are utilized. It is generally more manageable for the models to learn patterns and create distinctions between various data classes if labels are provided. The labels serve as teachers and therefore guide the model to learn what is what precisely.
Supervised learning is similar to teaching a child to walk. You will hold the child's hand, show him how to take his foot forward, and demonstrate walking to let the child understand, and you will continue the same process until the child learns to walk on himself. This technique is the first developed machine technique. In simple, you can consider this form of learning where a teacher is present to show the right and wrongs. Regression and Classification techniques are examples of supervised learning.
Examples of supervised learning algorithms include fraudulent activity detection, spam detection, face detection algorithm, etc. In all these examples, the input data used for learning is already annotated as fraudulent, non-fraudulent, spam, non-spam, face, and non-face. Thus, it is easier for the model to learn patterns from the available classes.

1.2.2.                          Unsupervised Learning
This type of learning algorithm makes use of unlabelled data for training the models deployed for intelligent behavior. When the data at hand is unlabelled, the algorithm tries to find out similar patterns and places data with relevant features into one group.
Unsupervised learning is a type of learning where no teacher is present, and the system learns without any supervision. Here the system learns based on experience. Clustering is an example of unsupervised learning.
Examples of unsupervised learning algorithms include customer market segmentation, clustering, image restoration, drug discovery, etc.
1.2.3.                          Reinforcement Learning
Reinforcement learning was introduced when the researchers discovered that it would be nice to provide a reward as the system does the job in an intended way. In simple words, here, the system learns from the mistake.
Reinforcement learning, often known as real AI, is utilized when we are not given enough training data. Lack of training data means the model has no expertise in the problem at hand and therefore learns gradually by experience. It tries random moves, in the beginning, to learn from its environment and then finds out what is the best strategy to solve the problem. There is an iterative feedback loop between the agent and its environment that helps it learn more interactively. Unlike the traditional machine learning algorithms, reinforcement learning algorithms like SARSA (State-Action-Reward-State-Action), Monte Carlo methods, and Q- learning are more dynamic in their behavior.
The reinforcement learning algorithm works on the principle of learning patterns by reinforcing reward and punishment. The model tries to make the most suitable action in a particular situation that would maximize the cumulative reward and minimize punishment. If the step taken is right, it is awarded; otherwise, it is penalized. Reinforcement learning differs from the supervised learning approach where the training data already has an answer key so that the model is trained with the correct answer; in reinforcement learning, there is no answer/label, and the model decides to perform the given task in the light of its past experience. Thus in reinforcement learning, decision making is a sequential process, where we give labels to a sequence of decisions made earlier.
One of the best examples of reinforcement learning is playing chess, where each of our moves on the board is rated as positive or negative given the history of previous moves. Some other typical reinforcement learning applications are seen in robotics for industrial automation, control theory, and game theory. In all these applications, there is a well-defined environment, actions, and rewards. A great example of game theory is the AlphaGo Reinforcement Learning model that was able to beat the world's best human player.

Reinforcement algorithms that incorporate deep neural networks can beat human experts playing numerous Atari video games, Starcraft II and Dota-2, and the world champions of Go. While that may sound trivial to non-gamers, it is a vast improvement over reinforcement learning's previous accomplishments, and state of the art is progressing rapidly.

It is one of the artificial intelligence areas that shows great promise, so let us look at what it is and explore real-world applications.
Deep reinforcement learning is a category of artificial intelligence and machine learning where intelligent machines can learn from the results of their actions, similar to the way humans learn from experience. A machine keeps learning through a series of trial and error, making this technology fitted for dynamic environments that keep evolving. 2.2.4.                          Logistic Regression
Logistic regression is a suitable regression analysis to conduct when the dependent variable is dichotomous (binary). Unlike linear regression, the dependent variable of logistic regression is discrete rather than continuous. Logistic regression is applied to describe data and the relationship between one dependent binary variable and one or more ordinal, nominal, interval, or ratio-level independent variables. Sometimes logistic regressions are challenging to interpret; the Intellects Statistics tool easily allows you to conduct the analysis, then in plain English interprets the output.
Logistic regression was employed in the biological sciences in the early 20th century. It was then practiced in many social science applications as well. Logistic regression is implemented when the dependent variable (target) is categorical. For example,
Whether the tumor is malignant (1) or not (0)
To predict whether an e-mail is spam (1) or not (0)
Consider a case where we need to classify whether a tumor is malignant or not. If we use linear regression for such a problem, there is a need for setting up a threshold based on which classification can be done. If the actual class is malignant, the threshold value is 0.7, and the predicted continuous value 0.6, the data point will be classified as not malignant, leading to severe consequences in real-time.
From the above example, it can be inferred that linear regression is not suitable for classification problems. Linear regression is unbounded, and this brings logistic regression into the picture. Its value strictly ranges from 0 to 1.

-           Binary Logistic Regression: The categorical response has only two possible outcomes. Example: Spam or Not.
-          Multinomial Logistic Regression: It deals with three or more categories without ordering. Example: Predicting which food is preferred more (Veg, Non-Veg, Vegan).
-           Ordinal Logistic Regression: It deals with three or more categories with ordering—for example, A movie rating from 1 to 5.

2.3.       Classification
Classification is simply the process of mapping inputs to categorical labels, and a model that performs this task is said to be a classifier. Regression is generally applied for numerical problems, i.e., forecasting the turnover for the upcoming business year. Classification problems are quite different and applied to map inputs to corresponding labels. For example, consider a simple bank activity; the bank's automated system can decide to map a customer's loan request to either "safe" or "risky". Here in this example, "safe" and "risky" were the labels.
Classification is a two-step process; the first step is the learning stage for the model. The model is created with a training set. The training stage includes inputs and their corresponding correct labels. Since the class label of each training inputs is provided, this step is also known as supervised learning (teacher present - correct outputs known). The second stage uses the trained model and uses it to classify the new inputs to corresponding labels.

The first stage of classification can be considered as the generation of function and the second stage as the operation of function on input to generate corresponding class label . The classifier's accuracy is given as the ratio of correctly classified test samples to total test samples. Once a classifier is generated with accepted accuracy, then it is used for classification. You can compare different classifiers with the parameters such as accuracy, speed, robustness, and scalability. Accuracy, as we explained before, refers to the given classifier's ability to predict the label correctly, speed refers to the computational resources required to perform the classification, robustness refers to the ability of the system to perform when incomplete or noisy data is given. Scalability refers to the ability of classifiers to handle a large amount of data.
2.3.1.                          Challenges in classification
Data cleaning: Data cleaning is a pre-processing stage in classification to reduce uncertainty in the learning process and produce a classifier with better accuracy. The input data should be analyzed for the presence of noise and absence of valuable data, i.e., missing values. Noise can be treated using several smoothening techniques, and missing values can be solved either by replacing that value with a most commonly observed value or using statistical methods to predict that value.
Relevance analysis: Relevance analysis can be used to identify relevant features that are important for classification. One example of relevance analysis is a correlation. If two features are highly correlated, one of those could be removed in the pre-processing stage. Feature subset selection can also be used to reduce the set of features. This technique can be used to find a reduced set of features so that the resulting probability distribution of the data classes is as close as possible to the original distribution obtained, using all features. The classification problem can be further simplified and made cost-effective by removing features that do not contribute to the classification using these two-relevance analysis techniques. Such attributes may slow down the whole classifier and fail during performance comparison against other classifiers.
Data transformation and reduction: Data normalization is a very important pre-processing for classification. For example, consider some features such as distance, or income, etc. These typically have large integer values, and operation on these large values is complex for complex classification networks or deep networks. Using such data could slow down the whole classification process, and there will be huge performance loss. In order to address the above problem, we will use a technique called normalization. Normalization scales all values for a given feature so that they fall within a small specified range, like −1.0 to 1.0 or 0.0 to 1.0. Normalization applies to numerical data such as distance, salary, and turn over.
Another data transformation technique is Generalization; data can be generalized to higher-level concepts to avoid complexity. For example, feature marks can be generalized to Grades. Similarly, profit can be generalized to low, medium, and high, and categorical attributes, like streets, can be generalized to higher-level concepts, like a city. The generalization process compresses the original data to be trained, resulting in fewer input-output operations and leading to less memory utilization, thereby achieving better performance.
Different types of classification techniques are available such as decision tree classification, Bayesian, Support Vector Machines (SVM), K-Nearest Neighbour classification, etc. We will go through these classification techniques in this chapter.
2.4.       Decision Tree Classification
The decision tree is a supervised learning technique that can be used for both classification and Regression problems, but mostly it is preferred for solving classification problems.

A decision tree simply asks a question, and created on the answer (Yes/No), it further split the tree into sub-trees. Support Vector Machine (SVM) is a supervised learning technique to solve classification problems and regression challenges. However, it is mostly practiced in classification problems. This technique aims to find the best hyperplane in an n-dimensional space (n-the number of features) that distinctly classifies the data points, which classifies the data set to different classes. Here, the support vectors are the data points closest to the created hyperplane. These are very critical since these points lie close to the hyperplane; hence, removing these points could alter the hyperplane's position. Also, the hyperplane dimension depends upon the number of features, i.e., if the number of input features is 2, then the hyperplane might just be a straight line.
Support vectors are data points closer to the hyperplane; thus, they influence the hyperplane's position and orientation. Using these support vectors, we maximize the margin of the classifier. Deleting the support vectors will change the position of the hyperplane. These are the points that help us build our SVM decision boundary.

K means clustering algorithm is one of the primary and straightforward unsupervised learning algorithms for solving the clustering problem. Typically, unsupervised algorithms make implications from datasets using only input vectors without referring to known or labeled outcomes.

Consider that we have to classify the data set into clusters. We start the clustering process by selecting random points as the initial cluster centers for the number of clusters. After each data point is associated with corresponding cluster centers, we take the averages of the data points associated with a center and replace the center with the average, which is done for each center. The process is repeated until the centers converge to some fixed points. After the clusters are created, each cluster's data points exhibit maximum intra-class similarity and minimal interclass similarity. 
The objective of k-means is simple: group related data points together and discovered underlying patterns. To achieve this objective, k-means searches for a fixed number (k ) of clusters in a dataset.

4.4.       Stemming
Stemming is a procedure in Natural Language Processing used to normalize words. In languages, a single word can have multiple forms depending upon the context used. Let us consider an example word "carry," The word "carry" is a verb, but it can take many other forms such as "carries," "carried," "carrying," and so on, related to its context. During the lexical analysis phase, the input text or speech is tokenized, and the interpreter considers these input words as different words even though they convey the same meaning. Since Natural Language Processing aims to understand the meaning of content for different contexts, we use it to resolve this problem.
The stemming procedure normalizes the word by truncating the word to its stem word. Let us see one example, the words "carries," "carried," "carrying" will be reduced to "carri", and all these words are referred to by the stem word "carri" only. That is the token used for all the word forms is "carri". The stemmed output "carri" does not carry any meaning or included in the dictionary. Stemming may not give us a dictionary, grammatical word for a particular set of words.  There are different types of Stemming, such as Porter's Stemmer, Snowball Stemmer, Lovin's Stemmer, and many more. One advantage of Snowball Stemmer is that it supports a wide variety of languages.
4.5.       Lemmatization
Lemmatization operates similarly to stemming and tries to find a similar base "stem" for a given word. However, Lemmatization differs from stemming; Lemmatization finds a dictionary word as a base "stem" instead of truncating the original word. Lemmatization is slower than stemming because stemming does not consider the context or meaning of the stemmed word. Lemmatization is slower but more accurate compared to stemming.
The choice of stemming or lemmatization depends on the requirement and project goal. If a project needs faster responses, then stemming may be used, but If higher accuracy is crucial, then the best option is Lemmatization.
Lemmatization takes into account Part of Speech (POS) values, The process may produce different outputs for different values of POS. We generally have four options for POS, such as Verb(v), Noun(n), Adjective(a) and Adverb()

4.10.                         Term Frequency — Inverse Document Frequency (TF-IDF)
Term Frequency — Inverse Document Frequency is a word scoring measure used for information retrieval and summarization. The term is used to express the importance of a word in a given text. The word that appears multiple times in a document can be considered an essential word compared to other words that appear fewer times. If a word appears many times in a document and the same word frequently appears in some other documents, then the word can be considered a general occurring word, and we cannot assign much importance to it.
Suppose we want to search for “quality mobile” and consider the search done on an extensive database with mobile descriptions. The search program is designed to display the closest response to the user query. The search engine will compute the TF-IDF to calculate the score for all of our available descriptions in the database, and the result with the higher score will be retrieved as a search result. If there exists an exact match for the user query, there is no need for TF-IDF calculation, and the exactly matched description is shown as a result.
Suppose we have the following description in our database
  1. The good mobile
  2. a quality cell
  3. a fast mobile
  4. the cheap mobile cell phone
Description a has one word out for three words in the user query; description c has one-word matching user query also description d has one-word matching a user query. However, description b has the one-word “quality,” which is an essential word. So the search program will display description b as the search result.
Now, if you look at the descriptions, you can see that the word “mobile” is common in the descriptions, and therefore it will have a significantly lesser IDF value and, thereby, a lower TF-IDF value. If you consider the word “quality,” it rarely appears in the other descriptions and has a high discriminating power compared to the word “mobile”. Hence, the TF-IDF value will be higher, and the search program can conclude the result as description b. TF*IDF score is directly proportional to the importance of the term; that is, higher the TF*IDF score, valuable the term, and vice versa

5.7.       Convolutional Neural Networks
Convolutional neural networks  (CNN or ConvNet) are among the most popular deep neural networks, the technique being used in many of the deep learning applications. CNN is suitable for 2-D data because CNN's operation is a 2-D convolution of extracted features with input data. CNN is widely being used for deep learning over image data.
The advantage of CNN is that there is no need for manual feature extraction. The system is designed to extract features directly from input data. You do not need to define and provide the relevant features. Since the feature extraction is automated, CNN based deep learning models can be used for real-time object detection and provide high accuracy for computer vision. Below is a simple architecture of a convolutional neural network. There are several convolutional layers, optional pooling layers, and fully connected layers. Let us see each layer in detail below.
5.7.1.                          Convolution Layer
The fundamental of a CNN resides in the convolution operation. Hence they got the name convolutional neural networks. The first layer of CNN is convolution, and this layer is being used to extract features from input data. The convolution stage convolves a feature map of an input hidden layer with a weight matrix and produces an output feature map. There are four dimensions associated with a weight matrix; the first two are the number of feature maps of the convolutional input layer and the number of feature maps of the convolutional output later . The other two are the size of the receptive field width and receptive field height.
In CNN, a subset is convolved instead of the whole input data or image, and the goal is to find similar patterns in the input data irrespective of the pattern’s position in the data. The pixel relationships are preserved by learning image features using small squares of input data. The stride determines the size of the resulting output image (width x height). The stride is simply the number of pixels by which one slides in the vertical and/or the horizontal direction before applying the convolution operation. Typically ReLU is used at the convolutional layers.
In short, convolution is a mathematical operation that takes two inputs, such as an image matrix and a filter. The convolutions in CNN can often become complicated but aid in resolving complex problems.
5.7.2.                          Pooling Layer
The pooling layers are introduced to reduce the number of parameters; these are optional and used when the data or image is too large. You may apply to subsample to reduce the dimensionality of each map, retaining valuable information. The subsampling is otherwise called down sampling or spatial pooling.
 Different types of spatial pooling are given below
  • Max Pooling
  • Average Pooling
  • Sum Pooling
Max pooling chooses the largest element from the receptive field. Average pooling takes the average value of the receptive field, and sum pooling takes the sum of the feature map elements.
5.7.3.                          Batch Normalization
Batch normalization allows every layer in CNN to perform more independent learning. You may simply consider this as a layer used to normalize the output of the previous layer. The activations scale the input layer in normalization. Batch normalization can be used to produce more accurate and efficient CNN models, which avoids the problem of overfitting. This layer is typically placed after convolution and pooling layers.
5.7.4.                          Fully connected layer
After the convolution and pooling layers, the rest is similar to any feed forward networks. We flattened our matrix into the vector and fed it into a fully connected layer like a neural network.
Consider the obtained feature map matrix is converted and turned to a vector , this is fed to fully connected layers to create a model. We can apply any activation function at this stage to produce an output. The choice of the activation function is the freedom of the model designer. You can choose activation functions such as softmax, sigmoid, etc.

Such layers are applied in a particular order all over the network

Performance degradation means the problem of “vanishing gradient,” where the back-propagated gradient becomes infinitely small.
ResNet used the idea of “identity shortcut connection” that transfers results to few deeper layers and skips some other layers in between.
