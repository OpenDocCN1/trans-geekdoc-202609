## Pros and Cons of Naive Bayes

### Pros
* It is relaxed and fast to predict the class of test data sets. It also performs well in multi-class prediction.
* When the supposition of independence holds, a Naive Bayes classifier performs better than other models like logistic regression and needs less training data.
* It performs well in the case of categorical input variables likened to the numerical variable(s). For a numerical variable, the normal distribution is assumed (bell curve, which is a strong assumption).

### Cons
* If the categorical variable has a category (in the test data set), which was not perceived in the training data set, then the model will assign a 0 (zero) probability and be unable to predict, which is frequently known as "Zero Frequency". To solve this, we can apply the smoothing technique. One of the simplest flattening techniques is called Laplace estimation.
* On the other side, naive Bayes is also recognized as a bad estimator, so the probability outputs from predicting probability are not taken too seriously.
* An additional limitation of [Naive Bayes](https://courses.analyticsvidhya.com/courses/naive-bayes?utm_source=blog&utm_medium=naive-bayes-explained) is the assumption of independent predictors. It is almost impossible in real life that we get a set of completely independent predictors.

## Applications of Naive Bayes Algorithms
* Multi-class Prediction: This algorithm is also well recognized for the multi-class prediction feature. We can easily predict the probability of multiple classes of the target variable.
* Real-time Prediction: Naive Bayes is a keen learning classifier, and it is sure swift. Thus, it could be employed for making predictions in real-time.
* Text classification/ Sentiment Analysis/ Spam Filtering: Naive Bayes classifiers frequently used in text classification (due to better results in multi-class problems and independence rule) have a higher success rate than other algorithms. As a consequence, it is widely used in Spam filtering (identify spam e-mail) and Sentiment Analysis (in social media analysis, to recognize positive and negative customer sentiments)
* Reference System: Naive Bayes Classifier and Collaborative Filtering together build a Reference System that uses machine learning and data mining techniques to filter unseen information and predict whether a user would like a given resource or not.
