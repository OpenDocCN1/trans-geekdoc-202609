## 3.1. 无监督学习

无监督学习是一种学习技术，其中学习算法尝试以最少的人工监督对先前未检测到的数据点进行标记。这种学习技术涉及使用尚未分类或标记的信息对机器进行训练，并且与监督学习技术相比，学习过程在没有监督的情况下继续进行。机器尝试通过识别模式、相似性和差异，在没有任何先验信息的情况下对数据点进行分类。让我们通过一个简单的例子来理解学习情况和算法操作，假设系统被提供了一张包含汽车和踏板车的图像，并且假设机器之前既没有见过汽车也没有见过踏板车。在这种情况下，我们的机器对汽车或踏板车的特征没有任何概念，但机器被赋予了学习能力，以便它可以通过识别相似性、差异和模式来从图像中对汽车和踏板车进行分类。无监督学习通常允许机器使用未标记的数据处理。无监督学习有两类：

### 3.1.1. 聚类

聚类是一种过程，它将一组数据点划分为多个组，使得同一组内数据点之间的相似度很高，而不同组之间数据点的相似度较低。这些组被称为簇，同一簇内数据点之间的相似性称为类内相似性，不同簇的数据点之间的相似性称为类间相似性。

### 3.1.2. 关联

关联规则学习问题是指某人希望发现描述数据大部分部分的规则，例如购买 X 的人也倾向于购买 Y。有不同类型的聚类技术，我们将在下面部分讨论每种技术

#### 聚类类型
1. `K-means clustering`
2. `K-NN` (`k nearest neighbors`)
3. `K-medoid clustering` or `PAM` (`partitioning around medoids`)
4. `Fuzzy C means clustering`
5. `DBSCAN`

## 3.2. K-均值聚类

一个簇指的是由于某些相似性而聚合在一起的数据点集合。你将描述一个目标数字 `k`，它指的是数据集中需要的 `centroids` 的数量。`centroid` 是表示簇中心的想象或真实位置。每个数据点通过降低簇内平方和被分配到各个簇中。换句话说，`k-means` 算法识别出 `k` 个 `centroids` 的数量，然后将每个数据点分配到最近的簇，同时保持 `centroids` 尽可能小。`K means clustering` 算法是解决聚类问题的首要且直接的无监督学习算法之一。通常，无监督算法仅使用输入向量从数据集中得出推断，而不参考已知或标记的结果。`k-means` 中的 'means' 指的是数据的平均值，有助于找到 `centroid`。假设我们需要将数据集分类为 ![](Image00208.jpg)个簇。我们通过选择 ![](Image00208.jpg)个随机点作为 ![](Image00227.jpg)个簇的初始聚类中心来开始聚类过程。现在计算数据点与 ![](Image00208.jpg)个簇的每个聚类中心之间的距离度量。距离聚类中心最小的数据点被归入该簇。在每个数据点与相应的聚类中心关联后，我们取与中心关联的数据点的平均值并用平均值替换中心，这对每个中心都执行。该过程重复进行，直到中心收敛到某些固定点。簇创建后，每个簇的数据点表现出最大类内相似性和最小类间相似性。`k-means` 的目标很简单：将相关数据点分组在一起并发现潜在模式。为了实现这一目标，`k-means` 在数据集中搜索固定数量 (`k`) 的簇。

尽管 `K-means` 聚类算法很简单，但它具有某些缺点，例如
1. 聚类中心的随机选择可能不会导致最优结果
2. 该算法只能在数值数据上工作；它不能应用于分类数据
3. 最终簇的结构取决于初始聚类中心的选择
4. 用户在算法执行前指定簇的数量
