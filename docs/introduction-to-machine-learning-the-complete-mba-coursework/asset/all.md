1.1.        Introduction Artificial Intelligence (AI) refers to the ability of machines to replicate human intelligence. These machines are well programmed using different algorithms to exhibit human behavior and actions. The term AI can be simply stated as a machine's intelligence to learn and solve a problem as humans do. As computational resources' availability became easy to common man, Artificial Intelligence surpassed block-chain exposure, virtual reality, and quantum computing. Machine Learning is an application of Artificial Intelligence, which can be defined as a system's ability to continuously learn using the available data and prior experience without being specifically programmed. Creation of such kind of intelligent systems which can learn themselves needs sufficient data and enormous computational resource. High-Performance Computing (HPC) 's easy availability facilitates the researchers and developers to create various machine learning models that offer better accuracy and results. Cloud providers like Google, Amazon, and Microsoft all provide highly configurable GPU-ready virtual machines and Machine Learning toolkits, which users can leverage to create, train, and retrain  models. Machine learning (ML) has borrowed its ideas from probability, statistics, and optimization theory to induce intelligence to machines without being programmed explicitly. The goal of the field is to develop machines that can automatically learn and understand the data to generate predictions in unseen situations. Only humans are well-known to portray this character in everyday life; they understand how to behave if anything uncertain happens, and that is why they are deemed intelligent well-beings. Similar intelligence is induced to machines by developing machine learning (ML) algorithms that are powered by data. The data may come in any form, such as images, speech, text, etc. The developed ML algorithms are based on many applications, ranging from vision to language processing, forecasting, pattern recognition, games, data mining, expert systems, and robotics. Knowingly or unknowingly, we have been using many services that are built upon machine learning models. For example, let us take the scenario of talking to google assistant or Alexa. Both use complex machine learning models to understand the semantics and communication context to offer the requested response. They even improve over time by continuously learning your usage. Another example is the smart suggestions on online shopping sites, which display precisely the same item you are looking for. Such smart suggestions are made possible by studying your past purchase and search preferences using machine learning models. Although machine learning algorithms are developed drastically,  understanding these techniques is mandatory for your journey through machine learning. Statistical methods were suitable when the availability of data was less. In the current world, the availability of data is abundant, and these techniques have some limitations of their own. Hence far more advanced techniques such as deep learning and deep reinforced learning are developed to solve challenging problems. There are different types of machine learning techniques that are developed as per the increasing requirement of better accuracy and result. They are given in below figure 1.1. The techniques at the far left are the first developed techniques, and the right most one is the most advanced.  ![](Image00004.jpg)1.2.1.                           Supervised Learning The supervised learning algorithms use labeled data for training the models deployed for learning intelligent behavior. Most of the real-world data collected are unlabelled and need to be annotated carefully if supervised learning algorithms are utilized. It is generally more manageable for the models to learn patterns and create distinctions between various data classes if labels are provided. The labels serve as teachers and therefore guide the model to learn what is what precisely. Supervised learning is similar to teaching a child to walk. You will hold the child's hand, show him how to take his foot forward, and demonstrate walking to let the child understand, and you will continue the same process until the child learns to walk on himself. This technique is the first developed machine technique. In simple,  you can consider this form of learning where a teacher is present to show the right and wrongs. Regression and Classification techniques are examples of supervised learning. Examples of supervised learning algorithms include fraudulent activity detection, spam detection, face detection algorithm, etc. In all these examples, the input data used for learning is already annotated as fraudulent, non-fraudulent, spam, non-spam, face, and non-face. Thus, it is easier for the model to learn patterns from the available classes. The supervised learning algorithms can be used to achieve two tasks: 

1.  Regression 
2.  Classification 

Both will be discussed in detail ahead. 1.2.2.                           Unsupervised Learning This type of learning algorithm makes use of unlabelled data for training the models deployed for intelligent behavior. When the data at hand is unlabelled, the algorithm tries to find out similar patterns and places data with relevant features into one group. Unsupervised learning is a type of learning where no teacher is present, and the system learns without any supervision. Here the system learns based on experience. Clustering is an example of unsupervised learning. Examples of unsupervised learning algorithms include customer market segmentation, clustering, image restoration, drug discovery, etc. 1.2.3.                           Reinforcement Learning Reinforcement learning was introduced when the researchers discovered that it would be nice to provide a reward as the system does the job in an intended way. In simple words, here, the system learns from the mistake. Reinforcement learning, often known as real AI, is utilized when we are not given enough training data. Lack of training data means the  model has no expertise in the problem at hand and therefore learns gradually by experience. It tries random moves, in the beginning, to learn from its environment and then finds out what is the best strategy to solve the problem. There is an iterative feedback loop between the agent and its environment that helps it learn more interactively. Unlike the traditional machine learning algorithms, reinforcement learning algorithms like SARSA (State-Action-Reward-State-Action), Monte Carlo methods, and Q- learning are more dynamic in their behavior. The reinforcement learning algorithm works on the principle of learning patterns by reinforcing reward and punishment. The model tries to make the most suitable action in a particular situation that would maximize the cumulative reward and minimize punishment. If the step taken is right, it is awarded; otherwise, it is penalized. Reinforcement learning differs from the supervised learning approach where the training data already has an answer key so that the model is trained with the correct answer; in reinforcement learning, there is no answer/label, and the model decides to perform the given task in the light of its past experience. Thus in reinforcement learning, decision making is a sequential process, where we give labels to a sequence of decisions made earlier. One of the best examples of reinforcement learning is playing chess, where each of our moves on the board is rated as positive or negative given the history of previous moves. Some other typical reinforcement learning applications are seen in robotics for industrial automation, control theory, and game theory. In all these applications, there is a well-defined environment, actions, and rewards. A great example of game theory is the AlphaGo Reinforcement Learning model that was able to beat the world's best human player. 1.2.4.                           Deep Leaning Neurons in the human brain are stimulated as artificial neural networks in our binary computers to solve problems. Such learning techniques is called Deep Learning. 1.2.5.                           Deep Reinforcement Learning Deep reinforcement learning incorporates artificial neural networks with the reinforcement learning architecture that sanctions software-defined agents to learn the best actions possible in a virtual environment to attain their goals, i.e., it unites function approximation and target optimization, mapping state-action pairs to expected rewards. Reinforcement algorithms that incorporate deep neural networks can beat human experts playing numerous Atari video games, Starcraft II and Dota-2, and the world champions of Go. While that may sound trivial to non-gamers, it is a vast improvement over reinforcement learning's previous accomplishments, and state of the art is progressing rapidly. One of the most intriguing areas of artificial intelligence is the concept of deep reinforcement learning, where machines can teach themselves based upon the results of their actions. It is one of the artificial intelligence areas that shows great promise, so let us look at what it is and explore real-world applications. Deep reinforcement learning is a category of artificial intelligence and machine learning where intelligent machines can learn from the results of their actions, similar to the way humans learn from experience. Inherent in this type of machine learning is that an agent is rewarded or penalized based on their actions. Actions that get them to the target outcome are rewarded (reinforced). A machine keeps learning through a series of trial and error, making this technology fitted for dynamic environments that keep evolving. Although reinforcement learning has been around for decades, it was recently combined with deep learning, which established phenomenal results. Here, the "deep" portion of reinforcement learning refers to multiple (deep) layers of artificial neural networks that replicate a human brain structure. Deep learning needs large amounts of training data and significant computing power. Now, over the last few years, the volumes of data have  exploded while computing power costs have dramatically reduced, which has enabled the explosion of deep learning applications. The input data should be analyzed for the presence of noise and absence of valuable data, i.e., missing values. Noise can be treated using several smoothening techniques, and missing values can be solved either by replacing that value with a most commonly observed value or using statistical methods to predict that value. Relevance analysis: Relevance analysis can be used to identify relevant features that are important for classification. One example of relevance analysis is a correlation. If two features are highly correlated, one of those could be removed in the pre-processing stage. Feature subset selection can also be used to reduce the set of features. This technique can be used to find a reduced set of features so that the resulting probability distribution of the data classes is as close as possible to the original distribution obtained, using all features. The classification problem can be further simplified and made cost-effective by removing features that do not contribute to the classification using these two-relevance analysis techniques. Such attributes may slow down the whole classifier and fail during performance comparison against other classifiers. Data transformation and reduction: Data normalization is a very important pre-processing for classification. For example, consider some features such as distance, or income, etc. These typically have large integer values, and operation on these large values is complex for complex classification networks or deep networks. Using such data could slow down the whole classification process, and there will be huge performance loss. In order to address the above problem, we will use a technique called normalization. Normalization scales all values for a given feature so that they fall within a small specified range, like −1.0 to 1.0 or 0.0 to 1.0. Normalization applies to numerical data such as distance, salary, and turn over. Another data transformation technique is Generalization; data can be generalized to higher-level concepts to avoid complexity. For example, feature marks can be generalized to Grades. Similarly, profit can be generalized to low, medium, and high, and categorical attributes, like streets, can be generalized to higher-level concepts,  like a city. The generalization process compresses the original data to be trained, resulting in fewer input-output operations and leading to less memory utilization, thereby achieving better performance. 2.6.        Support Vector Machine (SVM) Support Vector Machine (SVM) is a supervised learning technique to solve classification problems and regression challenges. However, it is mostly practiced in classification problems. This technique aims to find the best hyperplane in an n-dimensional space (n-the number of features) that distinctly classifies the data points, which classifies the data set to different classes. Here, the support vectors are the data points closest to the created hyperplane. These are very critical since these points lie close to the hyperplane; hence, removing these points could alter the hyperplane's position. Also, the hyperplane dimension depends upon the number of features, i.e., if the number of input features is 2, then the hyperplane might just be a straight line. Support vectors are data points closer to the hyperplane; thus, they influence the hyperplane's position and orientation. Using these support vectors, we maximize the margin of the classifier. Deleting the support vectors will change the position of the hyperplane. These are the points that help us build our SVM decision boundary. A support vector machine (SVM) is a supervised machine learning model that uses classification algorithms for two-group or multi-group classification problems. Average pooling takes the average value of the receptive field, and sum pooling takes the sum of the feature map elements. 5.7.3.                           Batch Normalization Batch normalization allows every layer in CNN to perform more independent learning. You may simply consider this as a layer used to normalize the output of the previous layer. The activations scale the input layer in normalization. Batch normalization can be used to produce more accurate and efficient CNN models, which avoids the problem of overfitting. This layer is typically placed after convolution and pooling layers. 5.7.4.                           Fully connected layer After the convolution and pooling layers, the rest is similar to any feed forward networks. We flattened our matrix into the vector and fed it into a fully connected layer like a neural network. Consider the obtained feature map matrix is converted and turned to a vector ![](Image00390.jpg), this is fed to fully connected layers to create a model. We can apply any activation function at this stage to produce an output. The choice of the activation function is the freedom of the model designer. You can choose activation functions such as softmax, sigmoid, etc. 5.8.        Types of Convolutional Neural Networks (CNN) There are several Convolutional neural networks, and some of them are listed below. 5.8.1.                          [LeNet- 5](https://towardsdatascience.com/illustrated-10-cnn-architectures-95d78ace614d#e276) LeNet is an exceptional CNN introduced to perform object classification. It is exceptional in its performance, accuracy, and capability. This algorithm was initially developed and trained to classify 0-9 hand-written digits from the MNIST  dataset. LeNet consists of 7 layers, and the activation function applied is RELU. 5.8.2.                          [AlexNe t](https://towardsdatascience.com/illustrated-10-cnn-architectures-95d78ace614d#e971) AlexNet was introduced by Alex Krizhevsky, Ilya Sutskever, and Geoffery E. Hinton and won ImageNet ILSVRC-2012 competition. This CNN is very similar to the LeNet structure but consists of many filters compared to the original LeNet. AlexNet is able to classify large set of objects. To deal with overfitting issues, AlexNet uses “dropout” instead of regularization to deal with overfitting. 5.8.3.                          [VGGNet-1 6](https://towardsdatascience.com/illustrated-10-cnn-architectures-95d78ace614d#c5a6) VGGNet-16 was designed by Simonyan and Zisserman and became the runners up of the ILSVRC-2014competition.VGGNet is exceptional for feature extraction because of the simple pattern that it follows. The hyper-parameters for the filter size and the strides for both the convolution and pooling layers are constant: Filters of size 3 X 3 and stride = 1 used at the convolution layer, and the max-pooling layer make use of filters of size 2 X 2 and stride = 2. Such layers are applied in a particular order all over the network 5.8.4.                          [ResNe t](https://towardsdatascience.com/illustrated-10-cnn-architectures-95d78ace614d#e4b1) ResNet provided better performance than VGGNet and came first in all the awards of the ILSVRC 2015 for classification, detection, and localization. ResNet is otherwise called Residual Networks and was the most groundbreaking development in the area of CNN so far. ResNet makes use of “skip-connections” and “ heavy batch-normalizations” to aid training with thousands of layers without performance degradation. Performance degradation means the problem of “vanishing gradient,” where the back-propagated gradient becomes infinitely small. ResNet used the idea of “identity shortcut connection” that transfers results to few deeper layers and skips some other  layers in between. 5.8.5.                           GoogleNet/Inception
