
## 1.1 Introduction
Artificial Intelligence (AI) refers to the ability of machines to replicate human intelligence. These machines are well programmed using different algorithms to exhibit human behavior and actions. The term AI can be simply stated as a machine's intelligence to learn and solve a problem as humans do. As computational resources' availability became easy to common man, Artificial Intelligence surpassed block-chain exposure, virtual reality, and quantum computing. Machine Learning is an application of Artificial Intelligence, which can be defined as a system's ability to continuously learn using the available data and prior experience without being specifically programmed. Creation of such kind of intelligent systems which can learn themselves needs sufficient data and enormous computational resource. High-Performance Computing (HPC) 's easy availability facilitates the researchers and developers to create various machine learning models that offer better accuracy and results. Cloud providers like Google, Amazon, and Microsoft all provide highly configurable GPU-ready virtual machines and Machine Learning toolkits, which users can leverage to create, train, and retrain models. Machine learning (ML) has borrowed its ideas from probability, statistics, and optimization theory to induce intelligence to machines without being programmed explicitly. The goal of the field is to develop machines that can automatically learn and understand the data to generate predictions in unseen situations. Only humans are well-known to portray this character in everyday life; they understand how to behave if anything uncertain happens, and that is why they are deemed intelligent well-beings. Similar intelligence is induced to machines by developing machine learning (ML) algorithms that are powered by data. The data may come in any form, such as images, speech, text, etc. The developed ML algorithms are based on many applications, ranging from vision to language processing, forecasting, pattern recognition, games, data mining, expert systems, and robotics. Knowingly or unknowingly, we have been using many services that are built upon machine learning models. For example, let us take the scenario of talking to google assistant or Alexa. Both use complex machine learning models to understand the semantics and communication context to offer the requested response. They even improve over time by continuously learning your usage. Another example is the smart suggestions on online shopping sites, which display precisely the same item you are looking for. Such smart suggestions are made possible by studying your past purchase and search preferences using machine learning models. Below listed are few more example scenarios.

### 1.1.1 Machine Learning Applications
Machine learning algorithms are at play in a large variety of applications around us. Some of the most common applications we encounter in our day to day routine are listed below:
* Spam Filtering (Yahoo, Gmail, Hotmail, etc. use spam filters that categorize e-mail into spam and non-spam automatically)
* Facial Recognition (facebook somehow already knows your friends and tags them automatically using ML algorithms when you upload a picture)
* Text to Speech or Voice Recognition (smart virtual assistant like Sri, Google Assistant, Cortana, etc. have text to speech and speech to text recognition features and respond accordingly)
* Unmanned Aerial Vehicles (UAVs or drones are remotely controlled and behave in unseen situations. The ground-based controller uses machine learning algorithms to understand the flying territory and perform the destined task)
* Social Media and E-commerce Advertisements (Facebook, Netflix, Amazon use ML techniques to gauge user's interest and relevant recommendations are given accordingly)
* Space Exploration Probes (Space exploration probes utilize ML algorithms to discover new galaxies and explore new territories such as Mars)
* Customer Segmentation in online shopping websites (Companies predict the behavior of their customers using ML algorithms, i.e., to know which customers will respond to a particular promotion)
* Real-Time Object Identification for self-driving cars (Accurate detection of street buildings, vehicles, pedestrians, and road signs using artificial intelligence)
* Search engine result improvements (Search engine optimization uses ML algorithms to improve search results)
* Business Intelligence and Stock Market Prediction (Business Intelligence serve as a basis for Stock Market Prediction & Portfolio Analysis)
* Online fraud detection (Deep Learning algorithms powered by an Artificial Intelligence Neural network identify fraudsters or bots)

### 1.2.1 Supervised Learning
The supervised learning algorithms use labeled data for training the models deployed for learning intelligent behavior. Most of the real-world data collected are unlabelled and need to be annotated carefully if supervised learning algorithms are utilized. It is generally more manageable for the models to learn patterns and create distinctions between various data classes if labels are provided. The labels serve as teachers and therefore guide the model to learn what is what precisely. Supervised learning is similar to teaching a child to walk. You will hold the child's hand, show him how to take his foot forward, and demonstrate walking to let the child understand, and you will continue the same process until the child learns to walk on himself. This technique is the first developed machine technique. In simple, you can consider this form of learning where a teacher is present to show the right and wrongs. Regression and Classification techniques are examples of supervised learning. Examples of supervised learning algorithms include fraudulent activity detection, spam detection, face detection algorithm, etc. In all these examples, the input data used for learning is already annotated as fraudulent, non-fraudulent, spam, non-spam, face, and non-face. Thus, it is easier for the model to learn patterns from the available classes. The supervised learning algorithms can be used to achieve two tasks:
1. Regression
2. Classification
