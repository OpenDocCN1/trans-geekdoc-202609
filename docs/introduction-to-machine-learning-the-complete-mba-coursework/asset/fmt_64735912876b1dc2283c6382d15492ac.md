## 3.1. Unsupervised Learning

Unsupervised learning is the type of learning technique in which the learning algorithm tries to label previously undetected data points with minimal human supervision. This type of learning technique involves the training of machines using the information that is neither classified nor labeled earlier, and the learning process continues without supervision compared to supervised learning techniques. The machine tries to classify the data point without any prior information by identifying the patterns, similarities, and differences. Let us understand the learning situation and algorithm operation using a simple example, consider the system is given an image having both cars and scooters, and let us say that the machine has neither seen a car nor a scooter before. In this case, our machine does not have any idea of the features of either car or scooter, but the machine is given the learning ability so that it can categorize cars and scooters from the image by identifying their similarities, differences, and patterns. Unsupervised learning generally allows machines to work with unlabelled data. There are two categories of unsupervised learning:

### 3.1.1. Clustering

Clustering is a process that divides a set of data points into many groups such that the similarity between data points within the same group is high, and the similarity between data points in a different group is less. These groups are said to be clusters, and the similarity between data points within the same cluster is said to be intra-class similarity, and similarity between data points of different clusters is said to be an inter-class similarity.

### 3.1.2. Association

An association rule learning problem is where someone wants to discover rules that describe large portions of the data, such as people that buy X also tend to buy Y. There are different types of clustering techniques, and we will discuss each technique in the below section

#### Clustering Types
1. `K-means clustering`
2. `K-NN` (`k nearest neighbors`)
3. `K-medoid clustering` or `PAM` (`partitioning around medoids`)
4. `Fuzzy C means clustering`
5. `DBSCAN`

## 3.2. K-Means Clustering

A cluster mentions a collection of data points aggregated together because of certain similarities. You will describe a target number `k`, which refers to the number of `centroids` you need in the dataset. A `centroid` is the imaginary or real location expressive of the center of the cluster. Each data point is allocated to each of the clusters by dropping the in-cluster sum of squares. In other words, the `k-means` algorithm identifies the `k` number of `centroids` and then allocates every data point to the nearest cluster while keeping the `centroids` as small as possible. `K means clustering` algorithm is one of the primary and straightforward unsupervised learning algorithms for solving the clustering problem. Typically, unsupervised algorithms make implications from datasets using only input vectors without referring to known or labeled outcomes. The 'means' in the `k-means` refers to the averaging of the data that helps find the `centroid`. Consider that we have to classify the data set into ![](Image00208.jpg)clusters. Now distance measure is computed between the data points and each cluster center of ![](Image00208.jpg)clusters. The data point with a minimal distance to the cluster center is grouped to that cluster. After each data point is associated with corresponding cluster centers, we take the averages of the data points associated with a center and replace the center with the average, which is done for each center. The process is repeated until the centers converge to some fixed points. After the clusters are created, each cluster's data points exhibit maximum intra-class similarity and minimal interclass similarity. The objective of `k-means` is simple: group related data points together and discovered underlying patterns. To achieve this objective, `k-means` searches for a fixed number (`k`) of clusters in a dataset.
