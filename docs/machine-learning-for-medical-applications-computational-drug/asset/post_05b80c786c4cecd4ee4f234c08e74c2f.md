Generation of Frequent Itemsets: It involves periodically producing frequent itemsets, which are itemsets that satisfy a minimum support value. The process starts with individual items and builds upward toward forming larger itemsets, eliminating those that do not meet the support threshold.

Rule Generation: Once the frequent itemsets have been identified, the algorithm formulates association rules based on the confidence value of the possible rules that can be generated from the frequent itemsets derived. The rules that have crossed the specified confidence level are the set of rules to be considered valid.

Apriori was quite effective when a large number of items are involved, but it has limitations because many itemsets must be created and tested.

As a result of improved computing performance, the FP-Growth (Frequent Pattern Growth) method provides an alternative to Apriori. FP-Growth constructs a compressed data structure, frequently called the FP-tree, instead of candidate itemsets. This tree compresses the significant frequency information of items and makes the frequent itemsets immediately extractable from it without the generation of candidates. Compared to Apriori, this method significantly reduces memory and computational overhead costs, which are major issues in that algorithm.

Convolutional Autoencoders: Try utilizing convolutional layers in the encoder and the decoder to process spatial data, such as images. Convolutional Autoencoders should be implemented because of their capability to learn hierarchical representations as well as reconstruct high-dimensional image data with minimal computational resources.

VAEs: They extend conventional autoencoders by providing a new probabilistic encoding method. In particular, using VAEs to train a distribution across the latent space could mean that, in lieu of being able to obtain fresh samples from the observed data distribution, new samples that belong to the learned distribution could be generated. When it came to emulating generative modeling and creating new data instances, this method was of great value.

Denoising Autoencoders: Designed to reconstruct clean data based on inputs that have been corrupted. The original signal can then be reconstructed by denoising autoencoders, which are trained on noisy data; they can be applied in areas that require anomaly detection and image denoising.

When using sparse autoencoders, the model is forced to seek a more complete and concise representation of the data by limiting the variance in the latent space. This approach is beneficial when computing sparse representations and selecting features.

Autoencoders have significant applications in the context of drug toxicity prediction:

Dimensionality Reduction: Autoencoders have valuable aspects in the representation and visualization of large densities of chemicals and bioinformatics through dimensionality reduction. Autoencoders enable the detection of important features that cause toxicity by reducing the depth of data to a latent space.

Feature Extraction: Autoencoders can be useful for increasing efficiency in the predictive models employed in drug development because they help extract valuable features from raw data – such as gene expression patterns and molecular descriptors.

Anomaly Detection: Peculiarities and outliers are well captured by denoising and sparse autoencoders in drug safety data. These models can recognize patterns of toxicity while being able to understand normal patterns in the data.

Despite their advantages, autoencoders face several challenges:

Model Complexity: Autoencoders suffer from the problem of hyperparameter and network structure selection in many aspects. Overcomplicated models distort the data and do not work as well, whereas when a model is too simple, it omits some data characteristics.

Interpretability: The embeddings of the autoencoder models are opaque and thus make it complex to explain the features that are being used to predict toxicity. The absence of interpretability tools makes it important to develop methods for visualizing and analyzing latent representations.

Computational Resources: Deep and convolutional forms of autoencoder training indeed require a great deal of memory and computing power. These difficulties can be mitigated by the use of proper hardware acceleration as well as efficient training algorithms.

Autoencoders remain a prominent direction in the development of new methods within the framework of unsupervised learning, providing useful instruments for encoding and feature extraction, as well as anomaly detection at the present stage. They are also promising for finding latent relationships in drug toxicity prediction and enhancing the safety assessment of newly developed chemicals.

## 4 Ensemble learning methods

### 4.1 Bagging

Bagging is a type of ensemble learning algorithm designed to combine different base learners to make overall prediction models more robust. Bagging, a method created by Leo Breiman, aims to reduce variance and increase the actual precision of models prone to overfitting.

The basic concept of bagging is to create multiple bootstrap sample subsets of the initial training data, derived from repeated random sampling of the original data, with replacement being made for each draw. Figure 11 demonstrates the Bagging ensemble method, whereby multiple models are created, and the final prediction is a weighted mean of all the models built in a process designed to minimize variance and thereby prevent overfitting. We trained a different instance of the basic model with each subgroup. For these separate models, to develop a final output, the average of the results was typically taken for regression problems, while voting was used for classification problems. To achieve a more stable and generalized outcome, this method utilizes the diversity of the base models, which serves as the foundation for this aggregation operation.

Data Resampling: For each bootstrap sample, the original data set was resampled with replacement to create a new data set. Even though it contains twin samples, each bootstrap sample also has the same number of instances as the initial data set.

Model Training: To build a base model, a decision tree, each of the bootstrap samples was trained independently. This leads to a situation where there are many models, all of them trained on somewhat different data sets.

Aggregation: The majority voting works in the following way: the base models operate independently to make a prediction of a class, and whichever class is most frequently predicted by the individual base models is considered the final prediction for classification problems. For regression tasks, the final prediction is obtained by averaging the predictions made by all the models that have been designed.

Variance Reduction: Thus, by taking the average of the mistakes made by each base model, bagging reduces the variance of the model. High-variance models, which include deep decision trees and other models with high variability, can benefit from this more than any other.

Improved Accuracy: Normally, the bagging technique achieves a better estimated error rate compared to any of the base models. This is because the aggregated ensemble's special feature of learning ability across different partitions enhances the general comparative performance.

Robustness: When bagged, the model seems to be more robust to noise in the training dataset. The influence of the noisy cases was also reduced in the final aggregated predictions because every base model predicted the targets based on different subsets of the data.
