# 2.3 Autoencoders for dimensionality reduction in material characterization

Autoencoders, a class of neural networks used primarily for unsupervised learning, have gained widespread attention due to their dimensionality reduction capabilities. These models consist of an encoder that compresses high-dimensional input data into a lower-dimensional latent space, and a decoder that reconstructs the original data from this compressed representation. In the context of material characterization (MC), autoencoders help preserve critical features while minimizing redundant information, making them highly effective for analyzing large-scale datasets derived from material science simulations and experimental results.
