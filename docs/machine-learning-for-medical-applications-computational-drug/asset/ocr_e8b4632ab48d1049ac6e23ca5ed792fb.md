# 5.1.1 Algorithm selection

Some of the problems associated with data from many sources include data security and privacy. Patient-specific data is often incorporated into biomedical data, and combining datasets from multiple sources can lead to compromising a patient’s right to privacy. Data protection laws such as the GDPR and HIPAA have to be upheld to ensure that ethical standards and patient privacy are maintained. To address these privacy issues, it is necessary to apply suitable methods of data integration and anonymization of such data.

# 5.1.3 Model training

The fine-tuning of the parameters describing the predictive model was necessary for the materials’ property prediction; thus, the training process requires the use of a dataset. To ensure that the model was trained on many different instances to be able to generalize when faced with new data, this method requires the splitting of the dataset into the training set and the validation set. During training, structural hyperparameters such as learning rate, layer density, and regularizing factors are set in order to achieve optimality. To ensure that the data model can be valid for other data subsets and not overfit the model, there are techniques like cross-validation used.
