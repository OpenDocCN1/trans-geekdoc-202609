Fine-tuning: It involves fine-tuning a model with certain weights adjusted to serve another purpose apart from the one it was trained for. Typically, the last layers of the model are trained on the target data, while the earlier layers of the model are locked to reutilize the domain invariances learned from the source domain data. The likewise referred-to fine-tuning allows the model to adapt the learned representations to the specific details of the new job.

It used to be called “domain-specific pre-training” when a model was pre-trained on a domain similar to the target one. A model learned on chemical compounds, for instance, can be further trained using data on the toxicity of drugs. This intermediate pre-training was important because it introduces features that, depending on the target dataset, need to be fine-tuned.

Domain adaptation is concerned with the process of transferring learned information from one source domain to another related but distinct domain. To address the shift between the source and target domains, it involves modifying either the model or its parameters. Thus, the objectives in the present work are focused on enhancing the model's ability in the target domain and reducing the domain shift.

Domain-Invariant Feature Learning: This approach was employed with the view of learning features that are invariant to the given source and target domains. The so-called domain adversarial training promotes the model to seek representations that reduce the differences between domains to make the learned features more transferable.

Instance Weighting: Example-based schema adaptation includes the modification of weights of the instances from the source domain during the training process according to their similarity with the target domain. This technique is beneficial in terms of correcting the deceptive focus of the main model toward the parameters of the target domain.

Data Augmentation: To address the domain shift of the target domain, splintered data augmentation procedures produce additional samples. Due to the ability to change the values with completely synthetic data, these methods can fill the gap between the source and the target domain and lead to performance enhancement.

Model Regularization: Auxiliary functions applied to strengthen the recovery regularizations are utilized to impose constraints that ensure the model performs well across domains. It is easy to lose performance when transitioning between domains, but methods like domain-specific regularization assist with this.
