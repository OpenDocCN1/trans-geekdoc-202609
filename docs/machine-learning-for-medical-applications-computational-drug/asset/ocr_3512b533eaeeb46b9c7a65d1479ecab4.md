# 3.3 Stacking and blending techniques for integrating multiple ML models

Ensemble learning is a powerful branch of machine learning that requires multiple algorithms to generate predictions, performing better than single models and offering increased generalizability compared to other models. Within this context, two interesting techniques, known as stacking and blending, are more complex methods deployed to orchestrate diverse machine learning models with the specific goal of maximizing their particular strengths. These techniques are especially useful in highly multifaceted, nonlinear areas like biomedical materials, where the synergistic use of various models for property predictions results in better resolution.

# 3.3.1 Stacking: integrated models: a layered view

Stacking generalization is an ensemble learning technique whereby a meta-model is used to blend the outcomes of base models. In the context of material science, stacking can be used to combine several models oriented to different characteristics of materials, such as mechanical strength, biocompatibility, and degradation rate. The base models, which can also be diverse in many cases – ranging from decision trees to neural networks – make predictions that form the input for a meta-model. The meta-model commonly used is, for instance, a simple algorithm such as linear regression or a more complex one like gradient boosting, where the latter learns how the individual models’ predictions should be best combined in order to achieve better results. This layered approach enables one to capture fine-grained patterns in the data that are not observable when working only with individual models and yields better forecasts of material properties and their design for optimum performance.

# 3.3.2 Blending: an adaptive ensemble strategy

Stacking, as another type of ensemble technique, was quite similar to blending, with the only difference being how the meta-model was trained. While in stacking, the meta-model was learned from predictions on a new set of data so that it was not overfitted to the training data, in blending, the meta-model was learned using the holdout set – a part of the training data that was segregated exclusively for this purpose. In the field of material science, the use of blending was most beneficial where there was not a large amount of data available, as blending permits the inclusion of a number of models without necessarily needing more data to train the meta-model. In blending, typically, the meta-learners can be basic models like weighted averages that are used effectively to combine the basic models’ predictions.
