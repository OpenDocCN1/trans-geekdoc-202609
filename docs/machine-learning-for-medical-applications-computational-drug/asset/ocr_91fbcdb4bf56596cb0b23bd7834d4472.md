# 6.4 Transfer learning and pretrained models in medical imaging

Transfer learning has been regarded as one of the effective learning paradigms that can enhance the medical image processing and accelerate the development of machine learning. These methods improve certain medical imaging tasks by leveraging information from large-scale data and models learned from different tasks.

Transferring knowledge and the approach used to learn that knowledge from the original set of data to a new, normally different set of data is referred to as transfer learning. This reduces the need for large amounts of training data and computation time the model is expected to complete; instead, this method can presume the model knows how to complete related tasks. Transfer learning in medical imaging utilizes previously trained models from larger image data sets as a way to create learning models for specific illnesses.

From the above discussion, transfer learning has the following benefits in the processing of medical images. First, it allows the use of models trained on a large amount of varied data, which serve as a good starting point when training on medical images when there is not much data at one's disposal. In medical imaging, gathering large annotated datasets is quite costly and time-intensive. It assists in handling this difficulty, shows how to work with quantitative data, and provides a brief description of two case studies. Transfer learning allows for achieving faster convergence of pertinent characteristics from the original training in the pretrained model.

Other types of NNs, known as pretrained models, have been trained on datasets such as ImageNet – comprises millions of tagged photos in various categories. These models in medical imaging can be interactively programmed to perform activities like identifying an illness. The popular names of good models for image classification and feature extraction are VGG, ResNet, and inception.

Fine-tuning of a model previously trained for a different task was termed as fine-tuning, and no pretraining session was done. To optimize the model for the specific application, this involves adjusting its parameters and training it with the particular data set, which was in the medical images. The last layers are typically replaced and retrained in an endeavor to fine-tune the model, while the other layers, which contain features generally learned, are preserved. By doing so, the model preserves most of the nonspecific information obtained from the original training set while learning about the specificities of a certain domain.

Transfer learning and pretrained models are used in some of the mentioned medical imaging domains. For example, they are used in identifying tumors in MRI, segmenting organs in CT, and classifying diseases in X-ray.
