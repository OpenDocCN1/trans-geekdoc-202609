# 4.3 Standards and protocols for interoperable EHR systems

Interoperability within EHR systems entails compliance with standard data and structural interoperability, communication, as well as the relationship between EHR systems. A number of standards and protocols have been evolved, which offer standards and guidelines for representing, exchanging, and integrating EHR systems. Some of the key standards and protocols for interoperable EHR systems include:

Specifications that relate to the exchange, combination, sharing and access to electronic health information are referred to as HL7 (Health Level Seven) standards. IT infrastructure of healthcare operates on HL7 standards, which offer data formats, communication formats and interaction standards for clinical care, public health, and administrative healthcare transactions, among others. HL7 standards are applicable to the management of EHR information as well as facilitate integration of information from one HIT system with another. Some of these standards are HL7 Version 2 (V2) and HL7 Version 3 (V3).

FHIR which stands for Fast Healthcare Interoperability Resources is a relatively modern interoperability standard unveiled by HL7 that employs Web-based technologies to allow timely and seamless exchange of health information. Examples of these technologies include RESTful APIs (Application Programming Interfaces). EHR continuation is the defined structure of the data, namely patient identification data, observations derived from the patient, prescribed medications, etc., based on the FHIR resources using a concept of the module and extension. FHIR's basic and fine-grain features make it ideal for interoperability of EHR systems to enable developers to construct light weight as well as interoperability applications that are capable of acquiring EHR data.
