# 5 Evaluation and validation techniques

# 5.1 Cross-validation

Since it allowed us to estimate and ensure the performance of the machine learning models and their robustness, cross-validation was a mandatory procedure. This approach reduces the chances of overfitting by splitting the dataset into several parts, providing a better measure of performance, as well as the robustness and effectiveness of the model when determining efficiencies.

Cross-validation helps in breaking the dataset in to training and validation sets systematically, which enables testing the model on a new set and training it on the first set. Figure 16 pictorially explains cross-validation as a method of measuring the performance and accuracy of the generalization of a machine learning model by dividing the available data in to sub-sections for training and validation areas. This is done multiple times through employing different divisions of data for training as well as validation. This generalization is important when making actual predictions in the real-world by generating new data, as the main aim of the exercise is to assess the efficiency of the model on unseen data.

k-Fold Cross-Validation: In this case, the dataset was partitioned into k folds that are of equal proportions. For k-1 folds, an 8–3 train/verify split was performed on the data, and for the last fold, the roles were reversed to form an 8–3 verify/train split.
