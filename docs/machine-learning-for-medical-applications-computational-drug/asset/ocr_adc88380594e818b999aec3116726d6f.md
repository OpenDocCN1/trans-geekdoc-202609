A large reduction in the variation of the model is an indirect sign of the high importance of this feature. Another method implemented is Shapley additive explanations (SHAP), which unifies the measure of feature importance calculation by adding the average marginal SHAP value of the given feature, relative to all other feature combinations. The concepts of partial dependence plots are applied to depict the contribution of individual features on model output, which is effective for feature importance and interaction. These procedures aid in the determination of key parameters that define the characteristics of materials and direct the fine-tuning of material models.

# 6.1.2 Handling sensitivity analyses in material models

Sensitivity analysis focuses on the capability to establish relationships between the variations of input features and a model's output. More specifically, this analysis is very useful for gaining insight into the stability of the material models themselves. One procedure is local sensitivity analysis, whereby one alters the values of input features only slightly and observes the effect of the changes on the model outcomes. This technique assists in evaluating the required level of sensitivity to specific features locally. Global sensitivity analysis examines the effect of changing each feature at the same time over their entire range of values. Tools used in quantifying the contribution of input features to model output include variance-based sensitivity analysis and Sobol indices. Identifying the features important for optimal material design and ensuring there are no significant points that influence the model heavily is made possible by performing sensitivity analysis.
