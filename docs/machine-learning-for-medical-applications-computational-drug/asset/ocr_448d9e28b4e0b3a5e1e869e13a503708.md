# 3.5 Feature engineering for improving hit identification models

Feature engineering works as a veritable way of enriching hit identification models in drug discovery by incorporating known feature sets from raw data and developing features that can help make a model function optimally. In hit identification, the focus mainly lays on features quality and relevance, which influences the predictive accuracy and reliability of employing machine learning models.

This can be implemented through the extraction of molecular descriptors from chemical compounds in the case of hit identification. Optimized molecular descriptors relate to the size, shape, polar, and electronic character of compounds within the set, which are known to have an impact on their bioactivity. Molecular descriptors are some of the information handles that can be extracted from molecular data; these include molecular weight, topological indices, and pharmacophore fingerprints. When using molecular descriptors that describe the molecular structures of interested compounds in a study, the use of the features in machine learning models help in improving accuracy of predictions.

In the construction of the hit identification models, feature selection approaches are adopted to determine the most relevant and worthy features. It also means that feature selection makes the model less complex, easier to interpret, and improves its predictive abilities as well as rejects unnecessary features that clutter the set. Some of the feature selection techniques include filter methods, wrapper methods, and embedded methods that assess the features based on utilization of statistical measures – the learning algorithm of the intrinsic kind.

Fundamental knowledge and specific experiences are employed to design informative features that include the mechanisms and chemical characteristics linked with the drug activity. For example, a particular chemical molecular substructure, which is observed to bind to a particular biological receptor desired pharmacological effect can be formulated as a feature. In the same way, structure alerts suggesting toxicity can also be introduced for enhancing the model selectivity and safety.

Normalization, scaling, and other operations and transformation functions are used to preprocess data in order to make it fit for use in machine learning. Data transformation increases feature interpretability and helps avoid the impact of skewed distribution of number of outliers in the learning process and the model. For example, taking logarithm of skewed continuous variables measures of the variables within 0 and 1 makes learning more effective.
