# 4.2 Comparison with traditional image processing techniques

In medical imaging, machine learning has been shown to define new techniques that are distinct from prior image processing methods. The analysis of these methodologies has revealed noticeable differences in their characteristics, and, as a consequence, possible applications.

It was usually the case that in the evaluation of medical pictures, the traditional image processing systems used manually extracted features and algorithms. These descriptive techniques include methods that are based on prior knowledge and assumptions about the structural properties of images such as edges, texture, and morphological procedures. Traditional approaches work well only within a certain scope and are worse at handling the content and variability of medical images.
