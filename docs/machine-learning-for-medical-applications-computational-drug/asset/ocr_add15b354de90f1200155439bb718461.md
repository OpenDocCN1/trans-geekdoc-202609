# 3.5 Hybrid ML models combining supervised and unsupervised learning

In the generation and analysis of biological systems, there is a new research direction involving the integration of supervised and unsupervised machine learning. Supervised learning is highly efficient in problem-solving scenarios where the outcome is known, such as regression and classification, because it utilizes labeled data. On the other hand, unsupervised learning algorithms discover relationships between variables in an unlabeled dataset. These shared characteristics make the combination of these two learning methods even more effective when used together, as one can augment the other where it was previously ineffective, particularly in cases with subtle and nuanced differentiations. This is especially true when the data set was large and high-dimensional, making it very challenging to obtain labeled data.

In biomedical applications, for instance, a number of methods have been described for designing and developing biomedical materials.

Thus, the application of hybrid models in BM materials has significant benefits, especially regarding characterization and designing processes. For example, in situations where only a limited amount of information is classified, a hybrid model can use the elements of supervised learning to classify the material while simultaneously applying elements of unsupervised learning to detect mass patterns in the entirety of the assigned dataset. This approach is particularly beneficial for finding new material classes, as well as uncovering the relationships between structure and properties, and identifying materials that we would not be able to search for in such a way using conventional methodologies. The flexibility of these approaches makes it possible to investigate material space in a deeper manner, which in turn results in the growth and development of improved material interventions.
