Using ACLs control matrices (ACMs) to specify the permissions and access privileges of certain users inside the EHR system is one method for integrating fine-grained access control with smart contracts. These ACLs can be updated dynamically by smart contracts on the blockchain in response to modifications in user roles or permissions. The accompanying smart contract checks the user’s identification and credentials against the access control list when the user seeks access to a certain resource or a specific activity inside the EHR system. It then grants access in accordance with preset criteria.

Another way of achieving fine-grained access control with smart contract is to apply ABAC. In ABAC models access control decisions are made based on assignments of attributes, conditions related to the user, resource, other contextual factors, and its environment. Smart contract can assess these attributes into the contract, with flexibility to change the permission profile depending on the situation. For example, a smart contract should only allow a specific user to gain access to a specified patient’s file if that user has the right credentials to access patient and client information if he/she is given the authority by the patient and only if the access is compliant with the requisite regulatory laws.

By implementing fine-grained access control with smart contracts, healthcare organizations achieve several benefits, including:

Transparency and auditability: Smart contracts ensure the access control decisions and transactions are always consigned and can help organizations monitor the user’s access to EHR data in real time. Recording of access control events on the blockchain ledger strengthens the efficiency of smart contracts since it improves the levels of both accountability and trust in records related to access management.
