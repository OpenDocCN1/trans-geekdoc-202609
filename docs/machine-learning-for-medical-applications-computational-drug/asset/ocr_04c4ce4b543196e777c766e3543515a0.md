These generative models can be used to design structure from scratch. Molecular libraries can be designed to hit a certain biological target. This means that by pretraining generative models on target protein structures, the researchers can obtain libraries containing compounds with high affinity and selectivity to the target protein of interest. This focused strategy to de novo drug design can potentially speed up the process of the identification of lead compounds, and also reduce off target interactions, which result in an efficient drug discovery process.
