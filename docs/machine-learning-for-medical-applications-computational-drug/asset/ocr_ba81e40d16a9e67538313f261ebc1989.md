# 4.2 Structure-based virtual screening using ML algorithms

An important component of drug repurposing comprises structure-based virtual screening, which relies on the use of chemical databases to predict how well a novel candidate is expected to bind to a target protein. The machine learning techniques in structure-based virtual screening has enhanced the efficiency and accuracy to a significant level.

Support Vector Machines (SVMs) are among the most widely used machine learning techniques in structure-based virtual screening (VS). SVMs classify compounds as active or inactive based on features derived from chemical structures. In VS applications, SVMs are trained on datasets containing known active and inactive compounds to identify patterns that govern ligand binding. Using these patterns, SVMs can predict the likelihood that new compounds will interact with a target protein, based on the correlation between their molecular descriptors and bioactivity. Structure-based virtual screening also uses another machine learning approach known as the random forests. Random forests, an ensemble learning technique, is composed of multiple decision trees each of which is trained on bootstrap samples of the training data. Random forests are trained for virtual screening that predicts a compound binding affinity to a target protein by categorizing it according to its molecular fingerprints. Decision tree overfitting can be prevented by the use of random forests because the results of several decision trees are combined together in order to enhance prediction rates.
