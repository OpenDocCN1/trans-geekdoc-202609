# 3.2.1 Clustering techniques for biomaterial classification

There are different types of biomaterials based on their characteristics and behaviors in use, and to classify them, there are mainly algorithms that belong to the unsupervised learning category, called clustering techniques. To cluster biomaterials in a way that subdivides them based on similar properties, some of the general algorithms that are used include k-means, hierarchical clustering, and DBSCAN (density-based spatial clustering of applications with noise). For example, a dataset of biomaterial qualities can be grouped into k clusters using k-means clustering, where each cluster represents a collection of materials with similar characteristics. The hierarchical relationships between biomaterials are shown using a dendrogram prepared through hierarchical clustering. On the other hand, DBSCAN can identify clusters of different geometrical shapes and sizes since it discovers clusters based on their density. Such clustering techniques are helpful in defining the patterns and systematic relationships of biomaterials, which can then be utilized for material development and enhancement.
