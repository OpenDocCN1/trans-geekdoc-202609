# 2.4 Dataset augmentation for machine learning models

Improving the efficacy and resilience of ML models, especially in domains such as biomaterials where limited data and unequal distribution of classes impede model precision, is crucial. Because biomaterials research involves sophisticated and expensive experiments, it can be difficult to gather vast and diverse datasets. ML models trained on small amounts of data, therefore, perform poorly when applied to fresh, untried data. This problem can be addressed by dataset augmentation, which makes the training dataset artificially larger. This approach enables models to learn more widely distributed patterns and lowers the chance of overfitting.
