# 6.5 Ensemble methods and hybrid models

Ensemble methods and hybrid models are considered to be the state of the art in the field of machine learning, and this section describes how these techniques can improve the accuracy and reliability of developed medical image processing systems. Thus, these approaches use a combination of models to take the best combination of characteristics, hence improving both the accuracy and the generalization of the models.

In ensemble approaches, numerous predictors of machine learning models are integrated to give a result that would not be attainable if a single model was employed. The general concept behind ensemble techniques is that the performance should be uplifted and the chance for errors should be reduced by aggregating predictions from various models. In medical image processing, a number of widely utilized ensemble approaches are employed including

Using bootstrap aggregating (Bagging): Training several instances of the same model type on various subsets of the training data, which are produced by random sampling with replacement, is called bagging. Lastly, the incurred predictions from the developed models are then aggregated to a final result through voting. There is a bagging algorithm called random forest that creates numerous decision trees and reaches an averaged outcome.

Boosting: Boosting works as a sequence of models in which every ensuing model tries to reduce the error made by previous models. This technique addresses the circumstances in which previous models failed to make accurate predictions and boosts the performance. AdaBoost and gradient boosting machines are two subtypes of boosting methods used in medical image analysis to enhance the results of the model.
