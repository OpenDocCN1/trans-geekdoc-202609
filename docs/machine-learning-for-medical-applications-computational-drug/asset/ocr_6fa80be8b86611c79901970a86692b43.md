# 6.2.1 Mechanisms of SHAP values

SHAP values are derived from Shapley values, which originate from game theory, and represent the contribution of each player (or feature, in this case) to the output. SHAP values are used to represent the marginal contribution of features to outputs for all possible subsets of features under machine learning models. Therefore, an additive value set was created, the sum of which is equal to the difference between the average and model values. The partition of the prediction into each feature's contribution is expressed by SHAP values, which provide a more coherent and interpretable manner to explain how each feature impacts the model.

SHAP values find usage in almost all material science applications including failure analysis, material design optimization, and the prediction of material properties. For example, SHAP values are used for selecting features to answer questions like which of the composition or processing parameters contributes most to the projected characteristics when using machine learning models to predict the properties of new materials. Such realizations help researchers focus on the key factors only and adjust experiments accordingly. By providing brief rationales for model predictions, this fundamental piece is crucial in high-risk applications, such as safety assessment, regulation, and compliance. SHAP values can enhance the interpretability and accuracy of predictive models.

# 6.2.2 Challenges and considerations

There are some problems with the approach associated with applying SHAP values in material science. One major issue identified is the high computation time required to perform the calculations of SHAP values for large-scale models with numerous features. The process of considering every feasible feature occurrence can be extremely expensive in terms of computational resources and time, which can render SHAP analysis infeasible when dealing with huge datasets.
