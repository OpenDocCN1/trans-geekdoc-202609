RL was employed by live feedback systems in MC to adjust and improve the methods of characterization for materials. ## 6 Explainable AI and interpretability in materials science

### 6.1 Feature importance and sensitivity analysis in material models

Feature importance and sensitivity analysis are fundamental components of Explainable AI (XAI) and are essential for ensuring interpretability in materials science applications. These methods help clarify how various input features influence the predictions and decisions made by machine learning models. Understanding which attributes have the greatest impact allows researchers and engineers to deepen their insight into material behavior, leading to more trustworthy, accurate, and transparent models. This level of interpretability is not only critical for validating model outputs but also supports material design efforts and ensures compliance with regulatory standards. #### 6.1.1 Methods used in measuring feature importance

Several methods are used to evaluate the importance of the features in material models. Still, one of the most frequently applied techniques includes permutation importance, which entails observing a model's efficacy after permuting the values of a particular feature. A large reduction in the variation of the model is an indirect sign of the high importance of this feature. Another method implemented is Shapley additive explanations (SHAP), which unifies the measure of feature importance calculation by adding the average marginal SHAP value of the given feature, relative to all other feature combinations. The concepts of partial dependence plots are applied to depict the contribution of individual features on model output, which is effective for feature importance and interaction. These procedures aid in the determination of key parameters that define the characteristics of materials and direct the fine-tuning of material models.

#### 6.1.2 Handling sensitivity analyses in material models

Sensitivity analysis focuses on the capability to establish relationships between the variations of input features and a model's output. More specifically, this analysis is very useful for gaining insight into the stability of the material models themselves. One procedure is local sensitivity analysis, whereby one alters the values of input features only slightly and observes the effect of the changes on the model outcomes. This technique assists in evaluating the required level of sensitivity to specific features locally. Global sensitivity analysis examines the effect of changing each feature at the same time over their entire range of values. Tools used in quantifying the contribution of input features to model output include variance-based sensitivity analysis and Sobol indices. Identifying the features important for optimal material design and ensuring there are no significant points that influence the model heavily is made possible by performing sensitivity analysis.
