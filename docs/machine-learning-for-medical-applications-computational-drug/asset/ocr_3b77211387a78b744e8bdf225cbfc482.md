Clustering: One of the most used clustering methods was clustering: k-Means. Although the approach minimizes the variance within each cluster, it ultimately categorizes the data into different clusters. The following stages are taken by the algorithm: it starts by placing centroids randomly, then it assigns every data point to the nearest centroid, computes the centroid value again in terms of the average of the points belonging to a certain centroid, and continues this process until reaching proper optimization. The choice for which k-Means was made quite successful involved employing criteria such as the Elbow Method. However, with clusters of different densities and shapes, k-Means was not so efficient despite being one of the simplest methods.

A hierarchy of clusters was created via hierarchical clustering, which can be applied in two ways: either bottom-up. In the agglomerative technique, each data point forms its individual cluster that merges according to its distance to nearby clusters until this criterion is met: there exists no pair of clusters that can be merged. In contrast, in the divisive technique, every data point initially starts as a single cluster and is recursively divided into further subclusters. A dendrogram, a tree-like diagram that depicts the process of merging or splitting, was the most frequently used outcome. Nevertheless, hierarchical clustering is useful because it can demonstrate the hierarchical structure of the data, but it is computationally expensive for large datasets.

The density of data points was accordingly applied by the density-based clustering method, DBSCAN, to distinguish between clusters. The technique was based on observing that clusters are areas characterized by high density and separated by areas of low density. Two parameters are needed for DBSCAN: These two important parameters are MinPts, which defines the minimum number of points to form a dense zone, and ρ, the maximum distance between the points belonging to a single cluster. The system divides the data into three categories: noise points, which are those outside the neighborhood; boundary points, which are those within the neighborhood range but not within the dense range; and finally, core points, which are within the dense neighborhood zone. As seen, its performance was dependent on the set parameters, but overall, it was excellent in finding clusters of any shape and handling noise points.

Average Shift: Given a set of data points, clustering is an exploratory method that seeks the peaks of a probability density function. The algorithm also controls how a data point is constantly shifted toward the mean of other data points that fall within a specific range, and this is done repeatedly until the algorithm converges. Clusters are essentially sets of points that coalesce into a single point. While using the Mean Shift algorithm, there is no need to specify the number of clusters to be identified, and it is flexible in identifying clusters of different sizes and shapes. However, it can be computationally heavy at times, especially when dealing with large datasets.
