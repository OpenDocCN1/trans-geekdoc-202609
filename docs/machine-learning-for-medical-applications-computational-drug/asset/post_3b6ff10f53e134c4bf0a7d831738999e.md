
## 4.2 Data cleaning and preprocessing techniques

Before using data in the concrete field of biological material science as a foundation for applying machine learning (ML) algorithms, data cleaning and preprocessing become critical steps. These strategies have a direct impact on the accuracy and reliability of the resulting models, as they ensure the data is accurate, consistent, and analysis-ready. In the context of biological materials, where data is often complex and heterogeneous, proper sample cleanup and treatment are essential. Without these measures, predictive insights and meaningful interpretations cannot be achieved. The importance of these preprocessing techniques is illustrated in Figure 6.

### 4.2.1 Handling missing data

This data was incomplete because sometimes experiments are only partially completed erroneously. Several techniques are employed to address this problem:

- **Imputation techniques:** Where the data is quantitative, mean or median should be used for replacing missing values. In qualitative data, most often mode imputation should be used. The final technique is called regression imputation, which seeks to assign a value to the missing field based on other fields.
- **Multiple imputations:** Another limitation of this approach was that for the imputation process uncertainty, many datasets are created using different imputed values, and the results are averaged.
- **Deletion methods:** Specifically, if the proportion of missing data was low and the number of cases that should be dropped due to the presence of missing values could be considered negligible, the rows that contained the missing values were deleted.

### 4.2.2 Data normalization and scaling

Features in biomedical datasets are mostly quantitative and can be scaled differently, making up the structures that can influence the results from a ML system. Normalization and scaling techniques are used to standardize the data:

- **Min-max normalization:** In this method, features are rescaled with the help of the minimum and maximum values to bring the data to a desired scale, commonly in the range of 0 to 1.
- **Z-score standardization:** Standardization of features involves subtracting the mean from the data and scaling it based on the standard deviation.
- **Robust scaling:** This technique scales the data using statistical measures such as the median and interquartile range (IQR) that are not considerably affected by outliers.

### 4.2.3 Feature engineering and selection

Effective feature engineering and selection are critical for improving model performance and interpretability.

Feature extraction: New features can be created from previous features using mathematical transformations like dimensionality reduction (PCA).

Feature selection: Techniques such as recursive feature elimination and mutual information are used to address the curse of dimensionality problem and the number of features problem, enabling the reduction of dimensionality and increasing the efficiency of the model.

Handling categorical data: To support the analyses, categorical variables are first encoded, often through a process such as one-hot encoding, to ready them for application to an AI model.

### 4.2.4 Coordination and harmonization of data

Biomedical material science often involves integrating data from multiple sources such as experimental results, literature, and clinical databases:

Data integration: Integrating data from different data sources entails the matching of schemas to allow proper alignment of the data format as well as the proper definition of the variables.

Data harmonization: Techniques like data mapping and data standardization were applied to eliminate the complexities in the different approaches used in data representations so as to transform it to a common form in order to make it compatible with other datasets.

## 4.3 Handling missing data and inconsistencies

Mainly, missing value treatment and dealing with inconsistency were the major issues in biological material science data gathering and preprocessing stages. As biological and material data contain large amounts of information and, as such contain nuances, it means that the quality and reliability of ML can be significantly influenced by gaps and differences. These challenges were crucial to fulfill in order to ensure an accurate and relevant study.

### 4.3.1 Causes of missing data and inconsistencies

There are many possible causes for missing data in biomedical material science data such as experimental errors, data entry errors, and the limitations of measurement instruments. This happens due to differences in procedures involved in data collection, and differences in measurements, among other factors, in datasets from different authors. Knowledge of the causes of missing data and other inconsistencies is important in choosing proper approaches to address them.

### 4.3.2 Strategies for handling missing data

Several methods are available for addressing missing data, each with its advantages and limitations:

Imputation techniques: Imputation is a process in which missing values in a dataset are estimated using statistical means. Mean imputation and median imputation are common techniques that involve replacing the missing values with average values, respectively. Some of the more sophisticated techniques include the use of methods such as multiple imputation and k-nearest neighbors (kNN) imputation, where the algorithm makes educated guesses using pattern recognition techniques to try and make a better-educated guess at the missing data.

Model-based approaches: Model-based imputation techniques, like regression imputation, create missing value expectations based on relationships established in data analysis. These techniques make use of available data to develop models for predicting gaps, and as such, imputations made using these methods are often more semantically suitable than average ones.

Data augmentation: Sometimes, bootstrapping activities can be applied in an attempt to mitigate missing data problems. This approach mainly involves the formulation of additional input feature data points whenever distribution patterns are noticed and can be utilized to improve the resiliency of the ML model.

### 4.3.3 Managing inconsistencies:

Addressing inconsistencies in biomedical material data requires a combination of techniques to standardize and harmonize the dataset:

Data cleaning: Data cleaning is the process of screening the data and removing or correcting any errors. These steps involve formatting and finalizing data in such a way as to make units of measurement consistent, making decisions that clarify differences between datasets, and fixing data entry mistakes. It is possible to use algorithms to solve some problems and organize the work of an analyst in such a way that focuses on critical cases.
