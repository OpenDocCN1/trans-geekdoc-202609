Data Resampling: For each bootstrap sample, the original data set was resampled with replacement to create a new data set. Even though it contains twin samples, each bootstrap sample also has the same number of instances as the initial data set.

Model Training: To build a base model, a decision tree, each of the bootstrap samples was trained independently. This leads to a situation where there are many models, all of them trained on somewhat different data sets.

Aggregation: The majority voting works in the following way: the base models operate independently to make a prediction of a class, and whichever class is most frequently predicted by the individual base models is considered the final prediction for classification problems. For regression tasks, the final prediction is obtained by averaging the predictions made by all the models that have been designed.

Variance Reduction: Thus, by taking the average of the mistakes made by each base model, bagging reduces the variance of the model. High-variance models, which include deep decision trees and other models with high variability, can benefit from this more than any other.

Improved Accuracy: Normally, the bagging technique achieves a better estimated error rate compared to any of the base models. This is because the aggregated ensemble's special feature of learning ability across different partitions enhances the general comparative performance.

Robustness: When bagged, the model seems to be more robust to noise in the training dataset. The influence of the noisy cases was also reduced in the final aggregated predictions because every base model predicted the targets based on different subsets of the data.
