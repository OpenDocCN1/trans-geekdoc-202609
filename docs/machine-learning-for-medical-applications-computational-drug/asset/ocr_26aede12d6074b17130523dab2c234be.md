# 6.2 Transfer learning and domain adaptation

Transfer learning also addresses problems related to low sample sizes and other related issues that stem from the irregular distribution of data. Thanks to these methods, models can transfer information from one task to another and therefore facilitate performance on similar but different tasks. Figure 22 shows the process of transfer learning and the adaptation of the gained knowledge to another but related domain. Crucially, this feature is most valuable in areas such as predicting medication toxicity, where large, labeled datasets are scarce, and models need to be robust across domains.

Transfer learning is the act of enhancing a model that works on a new but related task by using a model that was developed on a large and, in many cases, different data set. This method uses features or similarities between the source task and the new task that one wants to perform. In practice, transfer learning often refers to changes in a model's architecture for a specific assigned task. Using prior knowledge reduces the need for extensive training on new data each time, which is achieved in this way.

Feature Extraction: The method identified in this paper uses a pre-trained model for feature extraction. As for the new job, the higher levels of the model are changed, whereas the lower ones, more basic in their functionality, are retained. Some of the characteristics were then extracted from the pre-trained model and input into a new model developed to achieve the intended job.
