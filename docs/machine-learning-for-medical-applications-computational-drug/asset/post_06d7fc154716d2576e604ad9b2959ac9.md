
Bagging has demonstrated its utility in the field of drug toxicity prediction through several applications:

Model Stability: In general, where noisy data is available in drug safety assessment, bagging can be used to produce more stable data by combining a number of models, thereby providing greater accuracy in the results.

Feature Importance: When using decision trees as base models, bagging was also capable of offering feature importance to provide a degree of decision insight, leading to variable importance for toxicity predictions.

Handling Imbalanced Data: If the sample size of an observational set had more toxic cases than nontoxic ones, bagging was extremely useful. It was used to minimize class imbalance problems since bagging involves training on multiple subsets of a given data set.

Computational Complexity: The development of more than one base training model was computationally intensive and time-consuming, especially if the data was large and the base learners were complex. These challenges can be overcome by implementing the process more efficiently and by having some steps processed in parallel.

Diminishing Returns: Bagging is beneficial and does improve model performance, but the change that occurs as we increase the number of base models diminishes. There is always a compromise between the number of models to simulate and the time it takes to do so.

Interpretability: In case each model is placed in a group, an increase in the ensemble’s opacity is observed; that is, the understanding of particular forecasts becomes less clear. For this reason, methods for interpreting ensemble models and explaining the importance of features can be helpful.

Bagging is an important type of ensemble learning that has consistently proven effective in improving predictive accuracy and model robustness by integrating different types of base learners. In drug toxicity prediction, its utilization leads to providing stable quantitative predictions and facilitates the creation of safer pharmaceutical interventions.

## 4.2 Boosting

Boosting is an old method known as ensemble learning that uses many weak learners to create a strong learner, which, in other words, enhances the performance of prediction models. A typical example of the development of powerful predictive models is the boosting process shown in Figure 12: A number of weak learners are trained, and new strong learners are built, where each new learner achieves a better outcome than the previous one by correcting the errors of the earlier learner. The main premise of boosting is to learn from the errors made by earlier models by using weak learning algorithms on reweighted copies of the data in succession. The efficiency of
this process is realized through the iterative procedure of integrally combining the results of multiple learners and, as a result, achieving overall enhanced efficiency and robustness in the constructed model.

Figure 12: Boosting.

The boosting algorithm operates in several stages:

Initialization: A base model, often a weak learner, was developed from the original data by building a decision tree with a few levels. The first model was used as the basis for developing the subsequent models.

Error Calculation: After the training of the base model, the errors (or residuals) are computed. For the primary model above, the errors are computed after the base model is trained. These residuals show where the model has underperformed; that is, they reveal the data that needs more focus to be effectively predicted.

Reweighting: As with the previous round, the errors obtained are used to alter the training dataset. Misclassified cases are given higher weight than correctly categorized cases. This change ensures that the successive model gives more focus to the hard cases.

Model Training: As for the reweighted dataset, a new weak learner was built. This learner focuses solely on the cases that the earlier model classified incorrectly to correct its errors.

Aggregation: Of all the learners, it was the final weak learner that was obtained by combining the predictions of all the weak learners. For the aggregate of learners, weighted voting (for classification) and weighted averaging (for regression) can be used, with each learner’s rating being proportional to the accuracy it displayed.

Iteration: When a certain number of rounds have been completed and no further improvement is made, the procedure is repeated. The above model becomes more sophisticated in the way it describes the complexity of the patterns in the data during each iteration.

Several boosting algorithms have been developed, each with unique characteristics:

The AdaBoost (Adaptive Boosting) algorithm was one of the first and most widely used boosting algorithms. To focus future models on these harder scenarios, AdaBoost adjusts the weights of misclassified examples. All the individual learners are combined into a final model, and the models are weighted, with higher-performing models being given more weight.

Gradient Boosting Machines (GBMs): GBMs train each new model to predict the residuals of the prior models in a step-by-step process. It is generalizable for all kinds of data and loss functions because this method performs gradient descent to minimize a given loss function.

XGBoost (Extreme Gradient Boosting): an improved gradient boosting flavor that includes techniques designed to prevent overfitting as well as improve efficiency. Due to its flexibility and rapid calculation, XGBoost can easily solve vast, complex problems and handle large datasets.

LightGBM (Light Gradient Boosting Machine): LightGBM has been developed to be incredibly fast and scalable by employing histogram-based methods for boosting. This is especially useful for handling big data as well as feature spaces with a high number of dimensions.

CatBoost (Categorical Boosting): Focuses on the efficient management of categorical features through the application of approaches used for coding and processing categories in variables. The original CatBoost aims to minimize the amount of preprocessing and enhance the raw evaluation of a model based on datasets that contain categorical features.

Boosting methods have demonstrated significant utility in predicting drug toxicity and side effects:

Enhanced Predictive Accuracy: When a number of weak learners are combined, boosting algorithms enable them to capture the complex patterns and interactions in toxicity data, thereby enhancing the prediction accuracy.

Handling Imbalanced Data: Some of the improvement methods, especially those with complex initialization strategies, are efficient in managing instance imbalance problems, as are common with toxicity datasets where dangerous effects are infrequent compared to nontoxic ones.

Feature Importance: Using boosting algorithms, information on the importance of individual features can be provided, which helps in understanding the factors responsible for drug toxicity and subsequently aids further research.

Despite their strengths, boosting methods face several challenges:

Overfitting: Boosting algorithms have limitations, including the over-fitting problem, which arises frequently when using complex base models in boosting. To counter this danger, it is necessary to make use of regularization techniques and carefully tune the hyperparameters.

Computational Complexity: The training of multiple models in an MTL manner is a computationally expensive and time-consuming procedure. Some of these concerns
include inefficient implementations and the inability to handle multiple operations simultaneously.

Interpretability: The combined nature of boosting models complicates interpretation. Methods for displaying models and their assessment are crucial for identifying the individual impact of learners and general model trends.

Boosting is a powerful and flexible technique in the ensemble learning model that significantly improves predictive performance. Thus, when applied to predict drug toxicity, the proposed method enhances the detection of potential side effects and supports the development of safer and more efficient drugs.

## 4.3 Stacking

Stacking generalization is one of the most complex ensemble learning methods, where multiple models are used to enhance the predictive accuracy of a particular model. This method produces the final prediction by utilizing the advantages of many base learners, often surpassing the performance of individual learners. Figure 13 presents the stacking process, where a number of models provide their prediction results, which are then used to formulate the final prediction after aligning with each other. The main concept behind stacking is to achieve better accuracy and robustness of the ensemble by learning the final decision-making process from many base learners.

The stacking process involves two main stages: the basic level and the meta level.

Base Level: At this point, several base models are trained on the same data set. These models consist of different methods, such as decision trees and support vector machines. All base models apply the patterns they have learned to generate outputs.

Subsequently, a meta-learner utilizes predictions as input features of basic models found in the literature. This meta-learner learns how the predictions of such underlying models should be combined to give the final result. It is often a more complex model, such as the logistic regression model. To ensure the meta-learner is well generalized, it is trained on a different validation set.

Stacking employs different training strategies to optimize the ensemble:

Layered Stacking: Includes placing one model on top of another. The first layer is built from the base models learned directly on the original data, while the other layers are built from the predictions of the previous layers. This can reflect the effect of one model on another but creates a high risk of over learning.

Stacked Generalization: This work involves employing base models that were trained with the original dataset to train the meta-learner using the predictions of the base models. To ensure that the meta-learner has an unbiased prediction, cross-validation is often used to partition the data into training and validation sets for both the base and meta-level learners.
