# 5.5 Edge computing and AI at the sensor level

The incorporation of edge computing with AI at the location of the sensors is a major step forward for biomedical sensors as it provides efficient analytical capacity and data evaluation right at the origin. This approach helps solve main issues of health monitoring that include latency in the data acquisition, low bandwidth, and security.

Edge computing relates to the accommodation of computational assets nearer to the point of data collection, for example, within the biomedical sensor edge device. Here, data processing occurs at the network edge eliminating dependency on physical servers and thus enhancing decision-making by reducing latency. This is especially important in monitoring health sessions, which require real-time response to such conditions so that intervention and diagnosis can be made on time.

When used at the sensor level, embedded AI algorithms allow certain analysis and decision-making to be performed directly on the sensor. Local real-time processing means that the analyzed data from sensors can be interpreted instantly, for example, for anomaly detection or pattern recognition.
