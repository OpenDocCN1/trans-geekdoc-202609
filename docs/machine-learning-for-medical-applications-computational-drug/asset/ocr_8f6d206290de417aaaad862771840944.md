# 4.2 Data cleaning and preprocessing techniques

Before using data in the concrete field of biological material science as a foundation for applying machine learning (ML) algorithms, data cleaning and preprocessing become critical steps. These strategies have a direct impact on the accuracy and reliability of the resulting models, as they ensure the data is accurate, consistent, and analysis-ready. In the context of biological materials, where data is often complex and heterogeneous, proper sample cleanup and treatment are essential. Without these measures, predictive insights and meaningful interpretations cannot be achieved. The importance of these preprocessing techniques is illustrated in Figure 6.

# 4.2.1 Handling missing data

This data was incomplete because sometimes experiments are only partially completed erroneously. Several techniques are employed to address this problem:

+   - **Imputation techniques:** Where the data is quantitative, mean or median should be used for replacing missing values. In qualitative data, most often value imputation should be used. The final technique is called regression imputation, which seeks to assign a value to the missing field based on other fields.
+   - **Many imputations:** Another limitation of this approach was that for the imputation process uncertainty, many datasets are created using different imputed values, and the results are averaged.
+   - **Deletion methods:** Specifically, if the proportion of missing data was low and the number of cases that should be dropped due to the presence of missing values could not be considered negligible, the rows that contained the missing values were deleted.

# 4.2.2 Data normalization and scaling

Features in biomedical datasets are mostly quantitative and can be scaled differently, making up the structures that can influence the results from a ML system. Normalization and scaling techniques are used to standardize the data:

+   - **Min-max normalization:** In this method, features are rescaled with the help of the minimum and maximum values to bring the data to a desired scale, commonly in the range of 0 to 1.
+   - **Z-score standardization:** Standardization of features reduces the range of choice regarding how the mean should be subtracted from the chosen set of data and defines a new measurement of skewness and dispersion that is scaled based on the standard deviation.
+   - **Robust scaling:** This technique scales the data using statistical measures such as the median and interquartile range (IQR) that are not considerably affected by outliers.
