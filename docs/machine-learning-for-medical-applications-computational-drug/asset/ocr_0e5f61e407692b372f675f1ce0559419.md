# 5.5 Real-time feedback systems in material characterization using RL

RL was employed by live feedback systems in MC to adjust and improve the methods of characterization for materials. These systems are designed to actively read and adapt MC methods based on the data that flows through them. Introducing RL to construct plastic models, which could update their approaches based on continuous measurements, led to better characterization of material properties. Subsequently, this strategy was particularly helpful for high-dimensional and complex material systems where conventional methods might not be adequate.

Currently, there are various feedback mechanisms in RL within the context of feedback systems.

RL allows the models to learn what the best scene for them to take is by trial, and this provides an opportunity to introduce feedback systems. RL algorithms, such as Q-learning, can be employed in the case of MC to purposefully determine the most appropriate protocols from current investigation procedures based on a current study. In communication with the MC environment, the RL agent is rewarded based on how well the process functions and the accuracy of the predictions. Gradually, the agent becomes capable of achieving the highest total amount of reward with the help of action improvement, which in turn enhances the characterization results.
