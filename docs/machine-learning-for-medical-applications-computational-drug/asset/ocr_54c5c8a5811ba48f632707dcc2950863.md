# 4.5.1 Techniques for hyperparameter tuning

There are several methods for fine-tuning ML models’ hyperparameters that are applied to biomaterials. Grid search is a methodical process that tests every conceivable combination of hyperparameter values to determine the ideal configuration by evaluating a predetermined set of values. Contrarily, random search chooses hyperparameter combinations at random, which is more effective than grid search, particularly in high-dimensional environments. In previous evaluations, Bayesian optimization uses a statistical model of the objective function that guides the exploration toward promising areas of the hyperparameter space. In the same regard, there are sophisticated hyperparameter tuning auto-optimization frameworks like Optuna and Hyperopt, among others, that allow for more advanced optimization algorithms because they possess inherent intelligence to optimize based on certain metrics.
