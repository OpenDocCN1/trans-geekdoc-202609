Often known as hyperparameters, these values are assigned prior to model training and do not undergo modification based on learned data. For predictive tasks like medication toxicity prediction, the unavoidable settings of such parameters are an obligatory step to achieve good results, as they affect the training process and the accuracy of models.

Parameters like the strength of the regularization, learning rate, and model complexity of the machine learning algorithms are all hyperparameters. In neural networks, the number of layers and units that exist, the type and parameters of the kernel in support vector machines, and the number of trees and depth in random forests are some of the best-known hyperparameters. It can therefore be seen that even the choice of hyperparameters affects the ability of the model to fit the data “too well,” and to generalize to new datasets.

Grid Search: Grid search is an exhaustive approach where each possibility of hyperparameters is examined in combination with each of the fixed hyperparameter values. Generally, by applying this strategy, a grid of hyperparameter values is defined, the model is trained on each of them, and the combination that provides maximal performance according to some measure is selected. Even though grid search is performed, there is high complexity involved with a lot of hyperparameters, and the process can be computationally costly and time-consuming.

The first approach to the setup of the hyperparameters was called random search, in which the values of hyperparameters are chosen randomly according to a pre-determined distribution. Random search was computationally less intensive compared to grid search, where not all possible combinations are compared. Sometimes it produces better results, in addition to being more effective than a grid search at navigating through the hyperparameter space, especially when there are many hyperparameters.

Bayesian optimization: This technique utilized probabilistic models to guide the search for the best hyperparameters. Finally, Bayesian optimization was very efficient in searching for the best hyperparameters by progressively constructing a probabilistic model that estimates the utility of different regions of the hyperparameter space. Unlike grid and random search, this method optimizes both exploration and exploitation simultaneously in a bid to find the best hyperparameters with the least amount of evaluation.

Gradient-Based Optimization: A selection of hyperparameters that can be optimized with gradient-based methods includes learning rates in neural networks. These include what is known as gradient computations of hyper-parameter values in relation to the performance of the model in question. Performance-based ranking is especially helpful for hyperparameters, whereby they are optimized to an optimal value selected from a continuous array.
