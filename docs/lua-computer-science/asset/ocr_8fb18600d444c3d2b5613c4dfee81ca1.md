We change the names of the Lua .exe files, to make it easier for us to use cmd later

![](bbox=[0.105, 0.128, 0.893, 0.555])

As we can see above, the Lua .exe files are now named without a version number.

We have changed the name of the exe files to make it easier for us to later cmd our folder and thus to activate our scripts we now only have to write in command prompt:

```
lua nameOfScript.lua
```

instead of

```
lua54 nameOfScript.lua
```
