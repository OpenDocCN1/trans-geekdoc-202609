*Retrieving the ID of the Previously Inserted Item with MySQL (mysqli_insert_id.php; excerpt)*

When using MySQL's auto_increment feature, the database automatically assigns a value for that column whenever you insert a new item into the table. It might be interesting to determine this generated value after the insert. The mysqli_insert_id() function can help us here. Just provide the database connection handle, and you will receive the ID in return. The value is only available for the last INSERT SQL statement executed with the provided connection.
