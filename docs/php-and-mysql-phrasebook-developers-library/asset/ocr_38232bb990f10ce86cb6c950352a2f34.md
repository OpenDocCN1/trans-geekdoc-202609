# Sorting Nested Arrays

```
function sortNestedArray(&$sa) {
 sort($sa);
 for ($i = 0; $i < count($sa); $i++) {
 if (is_array($sa[$i])) {
 sortNestedArray($sa[$i]);
 }
 }
}
```
