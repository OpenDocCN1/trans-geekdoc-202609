+   - The constant __FILE__ contains the full path of the current script.
+   - The function dirname() determines the directory name portion of a path.

To use a relative path, you can now call dirname(__FILE__) and then attach the relative path, taking into consideration the directory separator character, which is / on UNIX/Linux, \ on Windows, and : on Mac OS X. PHP tells you the system’s default in its DIRECTORY_SEPARATOR constant.

The sister function to dirname() is basename(): this one determines the filename portion of a path.
