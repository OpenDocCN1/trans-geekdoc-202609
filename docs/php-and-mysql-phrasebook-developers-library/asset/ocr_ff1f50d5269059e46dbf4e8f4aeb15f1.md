# Using Traits

```
```php
class MyTraitClass {
    use MyTrait1, MyTrait2 {
        MyTrait1::showTime as now;
        MyTrait2::showCopyright insteadOf MyTrait1;
    }
}
```
```

One of the new features in PHP 5.4 is support for traits, a means for code reuse. A trait is a collection of functions, a kind of class without instantiation. In order to use this new feature, you must create a trait by using the trait keyword.

```
```php
trait MyTrait1 {
    public function showTime() {
        $date = new DateTime('now');
        echo $date->format('H:i:s');
    }
}
```
```

Then, within a class, you can load the traits, with the use keyword. The methods are then at your disposal:

```
```php
class MyTraitClass {
    use MyTrait1;
}

$c = new MyTraitClass();
$c->showTime();
```
```
