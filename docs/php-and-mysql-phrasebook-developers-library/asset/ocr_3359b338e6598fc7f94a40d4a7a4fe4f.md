Then, you can call the sort() and asort() methods, which work analogously to their PHP counterparts but take the locale information into account:

```php
$a = array('Frédéric', 'Froni', 'Frans');
$coll = new Collator('fr_FR');
$coll->sort($a);
echo implode(' ', $a);
```

function sanitize($s) {
