# Consuming a Web Service
with NuSOAP

```
<?php
    require_once 'nusoap.php';

    $soap = new soapclient('http://localhost/
    wsdl-nusoap-server.php?wsdl', true);
    $proxy = $soap->getProxy();
    $result = $proxy->add(47, 11);
    echo "47 + 11 = $result";
?>
```
