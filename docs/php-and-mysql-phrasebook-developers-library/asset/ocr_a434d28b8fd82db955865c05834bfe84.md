**NOTE:** When you are using OCI_DEFAULT as the commit mode. the changes must be written to the database using oci_commit($db): oci_rollback($db) performs a rollback.

**TIP:** By the way, if you want to retrieve the autovalue of the most recent INSERT operation, you have to do it within a transaction and execute SELECT quotes_id.CURRVAL AS id FROM DUAL. where quotes_id is the name of the sequence you are using.
