You can, however, use header() to force the client to create a second request. In the first request, you set the cookie; in the second request, you check whether that worked.

In the preceding code, two cookies are set, one temporary cookie and one persistent cookie—because it is possible to configure some browsers so that one kind of cookie is accepted, the other one is not. Then, the redirect is done using header() and the Location: HTTP header, and the presence of the cookies is checked.

Of course, you should configure your browser to show a message window when a cookie arrives; that makes debugging much easier.
