However, with a bit of JavaScript, it can be possible to avoid this trap. The code in the following listing is client-side JavaScript code that determines the current time (client side) as an epoch value and sends it to a server-side script, setcookie-specific.php. The main difference between PHP's time() function and JavaScript's getTime() method is that the latter returns the number of milliseconds since January 1, 1970, whereas the former just works with the number of seconds. So, the JavaScript value first has to be divided by 1,000 and rounded down.

The code for this file can be seen at the beginning of this phrase: The transmitted value is taken as the basis for the calculation of the relative cookie expiration date:

```
<script type="text/javascript">
var epoch = (new Date()).getTime();
epoch = Math.floor(epoch / 1000);
location.replace("setcookie-specific.php?time=" +
epoch);
</script>
```
