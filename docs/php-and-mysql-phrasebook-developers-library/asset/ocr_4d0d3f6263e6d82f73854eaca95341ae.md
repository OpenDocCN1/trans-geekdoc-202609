Retrieving Data from MySQL (mysqli_fetch.php; excerpt)

The return value of mysqli_query() is a pointer to the actual resultset. It can be used to iterate through the complete list of entries returned by a SELECT statement. For this, these functions come in handy:

+   - mysqli_fetch_assoc() returns the current row in the resultset as an associative array (field names become keys) and then moves on to the next row.
+   - mysqli_fetch_object() returns the current row in the resultset as an object (field names become properties) and then moves on to the next row.
