installed separately). Then, oci_connect() tries to establish a connection to the server. The order of the parameters is a bit strange: first username and password and then the name of the service (that has been configured using the configuration assistant or is part of the tnsnames.ora file). The return value is a handle to the connection and is required by further operations in the database.

# Sending SQL to Oracle

```
```php
<?php
  if ($db = @oci_connect('scott', 'tiger', 'orcl'))
  {
    require_once 'stripFormSlashes.inc.php';
    $sql = 'INSERT INTO quotes (quote, author, year)
VALUES (:quote, :author, :year)';
    $stmt = oci_parse($db, $sql);
    oci_bind_by_name($stmt, ':quote',
$_POST['quote']);
    oci_bind_by_name($stmt, ':author',
$_POST['author']);
    oci_bind_by_name($stmt, ':year',
intval($_POST['year']));
    oci_execute($stmt, OCI_COMMIT_ON_SUCCESS);
    echo 'Quote saved.';
    oci_close($db);
  } else {
    echo 'Connection failed.';
  }
?>
