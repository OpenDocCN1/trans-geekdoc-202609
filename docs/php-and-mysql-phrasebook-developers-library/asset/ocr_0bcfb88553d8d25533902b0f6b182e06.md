# Setting Up Classes

```
```
class MyClass {
}
```
```

This phrase gives you a concise (and certainly incomplete) rundown of the most important OOP basics from a PHP point of view. The central element of the concept of OOP is a class. A class may contain constants, properties, and methods. Visibility keywords public, protected, and private denote who may access which property or method.

If a class is instantiated (with new), the $this keyword provides a reference to the calling object. If the class contains a method called __construct(), this method will be called upon instantiation of the class:

```
```php
<?php
class MyClass {
    private $prop = null;

    public function setProperty($value) {
        $this->prop = $value;
    }

    public function getProperty() {
        return $this->prop;
    }

    public function __construct($value = null) {
        if ($value !== null) {
            $this->prop = $value;
        }
    }
}
```
