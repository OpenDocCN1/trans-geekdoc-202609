# Consuming a Web Service with the PHP 5 SOAP Extension

```
<?php
$soap = new SoapClient('AddService.wsdl');
try {
    $result = $soap->add(47, 11);
    echo "47 + 11 = $result";
} catch (SoapFault $e) {
    echo "Error: {$e->faultstring}";
}
}
```
