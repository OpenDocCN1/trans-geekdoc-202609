# What Does PEAR Offer?

The following PHP Extension and Application Repository (PEAR) packages offer functionality that can be used for working with files and streams:

+   - `File` offers some helper functions for file access, some of them deprecated to new functionality in more recent PHP releases.
+   - `File_Find` searches a path for certain files or patterns.
+   - `File_SearchReplace` does a Search and Replace within files.
+   - `Stream_Var` allows you to save variables in streams so that you can access them like you would access files or streams.
