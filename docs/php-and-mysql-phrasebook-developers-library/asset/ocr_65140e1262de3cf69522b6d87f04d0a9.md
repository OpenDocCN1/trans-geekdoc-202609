# Prefilling Text Fields and Password Fields

```
<input type="text" name="textfieldname" value="<?php echo isset($_POST['textfieldname']) ? htmlspecialchars($_POST['textfieldname']) : '';?>" />
```

The value in a text field (and in a password field and in a hidden field, as well) is provided in its value attribute. However, the data there must be properly encoded with htmlspecialchars() to get rid of dangerous characters such as " or < or >.
