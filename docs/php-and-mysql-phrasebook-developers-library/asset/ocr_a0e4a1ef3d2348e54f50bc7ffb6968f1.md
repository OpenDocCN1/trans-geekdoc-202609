```
<?php
$ftp = @ftp_connect('mirror.netcologne.de');
$login = @ftp_login($ftp, 'anonymous',
'email@example.com');

if ($ftp && $login) {
    ftp_chdir($ftp, '/apache.org/httpd/');
    ftp_get($ftp, 'Apache-README-ftp.html',
    'README.html', FTP_ASCII);
    echo 'File written.';
    ftp_close($ftp);
} else {
    echo 'Error!';
}
?>
```

Reading in an FTP file Using the Built-In Functions
(ftp-functions.php)

Note that the syntax of ftp_get() is a bit strange. After the FTP resource, you first have to provide the local filename, and then you must provide the remote filename. (Intuitively, you would expect it to be the other way around.) The last parameter is the transfer mode: FTP ASCII for text files, and FTP BINARY for all other data.
