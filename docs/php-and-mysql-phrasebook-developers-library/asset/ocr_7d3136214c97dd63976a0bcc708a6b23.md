On a single selection list, the value of the selected <option> element is transferred to the server when submitting the form. This value can then be manually checked to prefill the form, using the selected HTML attribute, as shown in the preceding code.

The same effect can be implemented using getFormData.inc.php; then data from the site's cookies is used, if available:
