
还有一个使用已弃用的ext/mssql扩展的剩余原因：在异构网络中，UNIX/Linux系统可以访问MSSQL安装，并使用旧的MSSQL扩展连接到它们。要实现这一点，你必须从www.freetds.org/下载FreeTDS库，并在解压发行版后使用以下命令安装：

```
./configure --prefix=/usr/local/tds --with-tdsver=4.2
make
sudo make install
```

然后，使用`--with-sybase=/usr/local/freetds`开关重新配置PHP。

最后，你可以使用`mssql_connect()`连接到服务器，并使用`mssql_select_db()`选择要使用的数据库，这与其他数据库扩展使用的API类似。使用`mssql_query()`执行SQL查询后，可以使用以下函数之一检索返回的数据：

- `mssql_fetch_assoc()` 将结果集中的当前行作为关联数组返回。
- `mssql_fetch_object()` 将结果集中的当前行作为对象返回。
- `mssql_fetch_row()` 将结果集中的当前行作为数值数组返回。

**注意：** MSSQL支持两种用户认证模式：SQL认证和Windows认证。后者检查当前Windows用户是否具有足够的权限访问数据库。在受控环境中，这可能比使用用户名和密码更好。但是，你首先必须找出使用的是哪个用户。例如，Microsoft Internet信息服务（IIS）Web服务器软件通常使用Internet来宾帐户（即IUSR <机器名>）。因此，该用户需要数据库中的权限。

要使用Windows认证——有时也称为受信任连接——你需要以下php.ini指令：

```
mssql.secure_connection = On
```

## 连接到InterBase/Firebird（ibase_connect.php）

Firebird数据库目前更像是一个内行才知道的秘诀，而不是广泛使用的数据库，但它正在获得更多用户，并且可能成为成熟关系型数据库管理系统（RDBMS）的替代品。该数据库起源于Borland的InterBase产品。因此，Windows用户需要在php.ini中设置`extension=php_interbase.dll`，而“自行编译者”必须使用`--with-interbase=/path/to/firebird`开关配置PHP。此外，Firebird支持两种模式：一种是与SQLite类似的文件模式，一种是服务器模式。为了互操作性和易于部署，本节使用文件模式。

本节还使用与Firebird和InterBase兼容的.gdb文件；新的Firebird格式扩展名为.fdb。创建此文件后，`ibase_connect()`连接到该文件或数据库。对于主机，当使用TCP/IP时，你必须提供格式为'localhost:/path/to/file.gdb'的字符串，或提供本地文件名（列表假定文件位于本地机器的/tmp目录中）；你还需要用户名和密码。

## 向Firebird发送SQL

### ibase_execute()

```
<?php
if ($db = ibase_connect('localhost:/tmp/quotes.gdb', 'user', 'password')) {
    require_once 'stripFormSlashes.inc.php';
    $sql = 'INSERT INTO quotes (id, quote, author, year) ' .
        'VALUES (GEN_ID(quotes_gen, 1), ?, ?, ?)';
    $stmt = ibase_prepare($db, $sql);
    ibase_execute($stmt, $_POST['quote'], $_POST['author'], intval($_POST['year']));
    echo 'Quote saved.';
    ibase_close($db);
} else {
    echo 'Connection failed.';
}
?>
```

向InterBase/Firebird发送SQL（ibase_execute.php；摘录）

可以使用`ibase_query()`函数向数据库发送SQL字符串。但是，没有`ibase_escape_string()`函数；因此，为防止SQL注入，必须使用预处理语句。这里，`ibase_prepare()`函数发挥作用：它解析一条SQL语句（以问号作为占位符）并返回一个语句对象。然后，`ibase_execute()`执行该语句，并将占位符的值作为附加参数获取。

注意：前面的代码包含Firebird的两个特性。首先，标识列由数据库中的生成器驱动：插入新字段时，调用`GEN_ID(quotes_gen, 1)`会在此列中输入下一个可用值。另外，单词`year`在Firebird中是保留字，因此列名为`qyear`。

*从InterBase/Firebird检索数据（ibase_fetch.php；摘录）*

无论你使用`ibase_query()`还是`ibase_execute()`，最终都会有一个结果集的句柄，你可以使用`ibase_fetch_assoc()`（返回关联数组）或`ibase_fetch_object()`（返回对象）对其进行迭代。此代码使用后一种方法。

请记住，Firebird和InterBase以大写形式返回列名，因此对象属性（以及关联数组中的键）也是大写的。

通过PDO连接（pdo_connect.php）

PDO是PHP Data Objects的缩写，是由一些PHP核心开发者推动的新成果，也是PHP 5.1的关键特性之一。PHP中有几个抽象类，但PDO最终将成为官方标准。从PHP 5.3开始，PDO是PHP核心的一部分，因此Windows用户不需要在php.ini中引用特定的DLL。（在旧版PHP中，`extension=php_pdo.dll`可以实现这一点。）

除了可以使用PDO本身之外，还必须加载用于目标数据库的驱动程序。截至撰写本文时，可用的驱动程序如下：

- PDO_CUBRID 用于Cubrid
- PDO_DBLIB 用于Microsoft SQL Server（基于旧的ext/mssql扩展）
- PDO_FIREBIRD 用于InterBase/Firebird
- PDO_IBM 用于DB2
- PDO_INFORMIX 用于Informix
- PDO_MYSQL 用于MySQL 3.x–5.x
- PDO_OCI 用于Oracle
- PDO_ODBC 用于ODBC
- PDO_PGSQL 用于PostgreSQL
- PDO_SQLITE 用于SQLite版本2和3
- PDO_SQLSRV 用于Microsoft SQL Server（基于新的ext/sqlsrv扩展）
- PDO_4D 用于4D

为了尽可能使其可移植且易于部署，下面的示例使用SQLite驱动程序；但其他驱动程序和数据库系统也同样出色。无论你选择哪个系统，请在php.ini中下载并安装驱动程序。如果使用的是PHP 5.3之前的版本，请确保在PDO之后加载驱动程序——在新版PHP中，无需特意加载PDO。

PDO提供了一种面向对象的方法。你只需要一个合适的数据源名称（DSN）、一个用户和一个密码（可能还有其他选项）。前面的代码连接/创建了一个SQLite版本3文件。
