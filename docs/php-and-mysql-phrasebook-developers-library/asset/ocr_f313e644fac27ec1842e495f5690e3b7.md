# Connecting to Firebird

```
<?php
if ($db = ibase_connect('localhost:/tmp/quotes.gdb', 'user', 'password')) {
	echo 'Connected to the database.';
	ibase_close($db);
} else {
	echo 'Connection failed.';
}
?>
```

The origins of this database lie in Borland's InterBase product.
