The following code shows how to use an array with replacement characters.

```
```php
<?php
$string = '<p>This is <span class="acronym">HTML</span></p>';
echo str_replace(
    array('<', '>', '"', "'", '&'),
    array('&lt;', '&gt;', '&quot;', '&apos;',
    '&amp;'),
    $string
);
?>
