+   - A more-or-less platform-independent way to secure your Web site is to use authentication via HTTP. If you send an HTTP status code 401 (unauthorized), browsers prompt the client for a username and a password. This information is then available using `$_SERVER['PHP_AUTH_USER']` and `$_SERVER['PHP_AUTH_PW']`—however, only if you are running PHP as a server module, not in Common Gateway Interface (CGI) mode.

You can then check this and decide whether to send out a 401 header again or to show the page's actual contents. The preceding listing shows an implementation for that. Figure 6.10 shows the prompt for a username and password.
