NOTE: Usually, PHP takes care of escaping special characters in the cookie values (in URL format). However, it is possible to do this manually by sending raw cookie data. For this, the function setrawcookie() accepts the same parameter as setcookie(), but does not encode the cookie's value. You must do that manually, with the function urlencode().
