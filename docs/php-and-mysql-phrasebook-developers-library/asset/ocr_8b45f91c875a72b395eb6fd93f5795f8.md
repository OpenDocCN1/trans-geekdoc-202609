# Sorting Associative Arrays Alphabetically

```
ksort($a);
asort($a);
```

```
<pre>
<?php
$a = array('one' => 'I', 'two' => 'II', 'three' =>
'III', 'four' => 'IV');
ksort($a);
print_r($a);
asort($a);
print_r($a);
?>
</pre>
```
