# Creating a Secured Area with Sessions

```
session_start();
if (!isset($_SESSION['authorized']) &&
$_SESSION['authorized'] != '') {
header("Location:
login.php?url={$_SERVER['PHP_SELF']}");
}
```

*Checking Whether the User Is Authenticated*
*(session_authentication.inc.php)*

Sessions can be a great way to secure certain parts of a Web site. The approach is simple: After the user is authenticated, write this information into a session variable. On all protected pages, check for the presence of this session variable.

You can first check for the session variable. The code from the beginning of this phrase must be included (with require_once) in all pages that are only accessible for authorized users.

The script login.php, to which the preceding code redirects the user, contains an HTML form (see also Figure 6.9) and checks whether the provided data is correct; you might have to add your own users and passwords, and also want to use encryption.
