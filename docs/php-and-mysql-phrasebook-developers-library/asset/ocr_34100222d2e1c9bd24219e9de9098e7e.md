# Serializing and Deserializing Objects

```
public function __sleep() {
    $this->db->close();
    return array('guid');
}
public function __wakeup() {
    $this->connectDb();
}
```

When you are storing objects for later use, they need to be transformed into something that can easily be put in, say, a database. PHP provides several ways to transform an object instance into a string (and putting it back into its original form); the most common approach is to use the serialize() and deserialize() functions, which are also used in other chapters of this book.
