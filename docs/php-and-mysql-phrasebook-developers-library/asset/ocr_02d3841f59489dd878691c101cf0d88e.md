# Protecting Email Addresses
Using ASCII Codes

```
```php
<?php
function protectMail($s) {
    $result = '';
    $s = 'mailto:' . $s;
    for ($i = 0; $i < strlen($s); $i++) {
        $result .= '&#' . ord(substr($s, $i, 1)) . ';';
    }
    return $result;
}

echo '<a href="' .
    protectMail('email@address.xy') .
    '">Send mail</a>';
?>
```
