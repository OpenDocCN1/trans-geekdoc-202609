
-   [除直接增强和双耳系统外，附着也可以通过技术手段实现，至少需要方向扬声器和波场合成（WFS）。然而，正如第2.10节所讨论的，WFS的挑战在于需要多个扬声器，这些扬声器可能难以隐藏或在叙事上难以合理解释。

在音频制作和渲染流程中，附着并不专属于对象式音频（OBA）；类似的效果也可以通过场景式音频管道实现，例如多点HOA（高阶听觉），甚至可以通过使用假人头的头戴式双耳录音（如在 *Séance* 中）来实现。不过，在这些情况下，更合适的术语可能是“空间对齐”，因为不存在可以“附着”或赋予位置坐标的独立声音对象。

### 9.2.3 在手可及与遥不可及之间

无论被增强的对象是 *within-reach* 还是 *out-of-reach*，都会产生一些实际影响。当对象在手可及范围内，即位于“播放区”内时，用户可以靠近它并可能绕行于其周围。这对虚拟音频渲染提出了很高的要求；例如，使用双耳系统时，需要准确且低延迟的6DoF（六自由度）追踪。远处的声音、窗户后的声音、邻室漏出的声音以及整体环境音都是 out-of-reach——用户无法到达这些声音。这些声音的实现相对容易，因为空间精度不那么关键。与其使用对象式音频，头部中心化的全向音（Ambisonics）能够提供许多 out-of-reach 声音的效果。

### 9.2.4 跨模态支持

如果在正确对齐虚拟声音与真实世界物体时遇到技术困难，诸如通俗化效果（ventriloquism effect）或视觉提示等手段可能会有所帮助，如前文所述。其他感官也可能派上用场；例如，如果用户能够触摸到物体，但听到的虚拟声音方向错误，本体感（proprioception） —  — 对位置的感觉 —  — 可以纠正定位感知（参见 Pick, Warren 和 Hay, [1969](#chapter09.xhtml#r326)）。此外，物体与声音之间的情境一致性至少能帮助用户判断误对齐的声音属于哪个物体（Yang et al., [2020](#chapter09.xhtml#r338)）。

尽管如此，根据实际经验，如果 binaural 系统中的头部追踪不稳定，且虚拟声音源不断 erratic 地移动，前述线索不足以稳定声音图像。快速的解决办法是对追踪数据进行平滑处理，而不是让其不断变动，即使这会牺牲一些响应速度。

### 9.2.5 术语

虽然“attachment”和“attached sound”这两个术语直观且使用广泛，但它们并不标准化。描述相同概念的其他术语包括 *spatially registered*（Kaghat and Cubaud, [2010](#chapter09.xhtml#r317); Tsepapadakis and Gavalas, [2023](#chapter09.xhtml#r332)），*localized*（Härmä et al., [2004](#chapter09.xhtml#r315); Brandenburg and Sloma, [2024](#chapter09.xhtml#r306)），*anchored*（Väänänen-Vainio-Mattila et al., [2013](#chapter09.xhtml#r336)），以及 *spatially aligned*。每个术语含义略有不同，并在合适的情境下提供更精准的描述。

### 9.3 对象一致性

在本书开头（第2.6章）简要讨论了可信度、逼真度和一致性的概念。有意调整虚拟声音与其现实对应物之间的一致性，可作为 AAR（增强现实音频）中的叙事手法。为区分这种匹配与其他类型的匹配（如视听一致或房间一致），此处将其称为 *object congruence*。Object congruence 仅指对象与其声音之间的情境对齐，而不涉及虚拟声音的声学属性。

Object congruence 可用于补充和强化对象，但当匹配具体且直白时，也可能导致音调贴合和强调（tone painting and underscoring）（Naphtali and Rodkin, [2019](#chapter09.xhtml#r325)），从而产生平淡无趣的效果（Stevens, [2009](#chapter09.xhtml#r331); Fry, 2019）。

人们对“一致”的感知因人而异，也因体验而异。文化背景、学习关联以及情境都会影响这种感知（Stevens, [2009](#chapter09.xhtml#r331)）。因此，在声音设计中，音频应顺应听者的心理模型和期待，而不是真实世界中实际的声音（Lyons, Gandy and Starner, [2000](#chapter09.xhtml#r321); Chion, [2019](#chapter09.xhtml#r308)）。 genre 或情境在此起重要作用。例如，狗在现实中通常不说话，但在卡通或马戏团中它们会。

Object congruence 需要添加或替换对象所 *可能* 或 *正在* 产生声音的声响。可信的声源包括扬声器、运行的机器、其他人、视频投影以及只能通过声音感知的被遮挡物体。博物馆中常见的文物过去曾发出声音，但如今已不再如此，例如历史收音机。恢复这类 *被静音* 的物体的声音（Cliffe, [2022](#chapter09.xhtml#r309)）可以实现 object congruence，前提是声音让该物体看起来像是正在发出该声音。

然而，为了使声音与收音机完全一致，设备必须开机，且频率旋钮应调至正确的电台频率。一致性始终高度依赖于情境。例如，当一台 1930 年代的老收音机开机时，在大多数地方你可能只会听到噪音，因为长波和中波电台已很少。但在历史叙事语境下，听到虚拟广播是合理的。正如任何叙事媒介一样，听者会根据情境调整自己并参与其中，除非他们极度怀疑或体验本身设计和实现不佳。

虚拟声音可能是原始录音，例如老收音机节目的记录，也可能是近似再现，如重新表演的版本。亦或是完全虚构的声音，只要它看起来像是该物体可能产生的声音。例如，在一次“旧”收音机采访中，嘉宾预测未来，这与当下事件巧妙地契合。利用 object congruence 创造这种听觉幻觉是 AAR 的核心艺术手段之一（参见 Cliffe, 2022）。换言之，声音改变了我们对物体的感知，通过其制造的对比增添了价值（Chion, [1994](#chapter09.xhtml#r307)）。
