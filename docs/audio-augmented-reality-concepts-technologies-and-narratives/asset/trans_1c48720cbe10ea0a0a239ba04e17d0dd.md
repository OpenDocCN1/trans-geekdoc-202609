
# 听力是我们最重要的感官。

虽然我们可能生活在视觉主导的文化中，但可以认为是通过耳朵我们理解世界。与视觉不同，听力是全向的，360度覆盖所有方向，能够检测和识别障碍物后方的声源。它也能在黑暗中以及我们睡眠时工作。在缺乏听力的情况下，对环境的存在感和理解感会大幅下降——世界显得不那么有生命（McGill et al., [2020](#chapter01.xhtml#r5)）。虽然眼睛可能提供更精确的数据，但耳朵将我们在三维和情感上与世界连接起来。

## 音频增强现实（AAR）将虚拟声音与真实环境相结合。

通过 AAR，世界以我们以前无法听到的方式与我们交流。当信息和叙事以声音的形式附着于环境和物体时，我们可以依赖直觉，更深入地感受世界。AAR 能够制造出虚拟声音与现实共存的幻觉：声音的方向和距离感觉正确，并且在声音上与环境相协调。当这些声音开始响应真实世界（包括用户），它们显得更加生动。

此外，感官增强使我们能够听到耳朵原本捕捉不到的真实世界现象——太安静、太远、太低、太高，或根本不是声音的现象，如辐射、距离和温度变化。AAR 不仅能添加声音，还能消除真实的声音。通过操控个人声景以去除不想要的声音并增强想要的声音，提供了提升生活质量的有趣可能性。一些最新的降噪耳机和医用助听器已经能够识别语音和其他声音并将其与背景噪声隔离。未来更多控制我们听世界方式的技术将出现，帮助社交互动并为珍贵的未经中介的时刻保护我们的听力。

*我们开始走向建筑物，潜入一条街道峡谷。虚拟的自然声效随路径自然演变：树木和藤蔓在沙沙作响，松鼠在树与树之间奔跑。我们看到一名建筑工人把金属棒掉在尘土飞扬的地面上，但我们只听到轻微的“啪”声。稍后我们了解到，系统正在测量我的心率并调整声音的节奏，让我感觉更加放松。*

*‘我们现在的目标是让当局在现场听到这些声景。声音会让他们感受到这个地方。他们将理解生物亲和设计的需求。最终，我希望他们会松开钱包。’*

*在听觉漫步结束后，我们前往附近的一家家庭艺术博物馆。该博物馆原本属于一位本地艺术家及其妻子，后者是一位专业作曲家，却因丈夫的阴影而被忽视。由于我们拥有兼容的耳机，便接受了博物馆媒体服务器的音频馈送。对于没有个人设备的人，博物馆提供了专用耳机。*

*我听到有人在客厅弹奏钢琴。走近时，我看见一架大钢琴位于房间中央，但没有人在弹它。尽管如此，音乐仍从琴体中发出，声音极其逼真，且在移动时音色会发生变化。我的朋友被墙上的画作吸引，却没注意到这架钢琴。*

*音乐像是有人在尝试不同的音乐点子，碎片化地展开。不久后，我听到了一个女人的声音，从钢琴手应坐的位置传来。*

*‘亲爱的，你觉得这个和声进行太明显了吗？’*

*一位男性的声音从房子的另一侧传来，可能是厨房，因为背景可以听到切菜和其他厨房用具的声音。*

*‘去吧！在我看来，这听起来很清新。’*

*乐谱架上贴有手写的乐谱。当我靠近查看时，系统判断我对这部作品感兴趣，便让这位女性继续在琴上构思，轻声哼唱并尝试和声。我看到朋友走向厨房，她一定在追随艺术家的故事。*

*展览以类似的方式继续进行。有时声音来源位于室外，如屋顶雨滴声，或在其他房间，如楼上卧室里的争吵。我们看不到声音的来源，这使得声音显得格外真实。其他时候，声音像幽灵一样漂浮在房间中，仿佛是曾经居住在此 house 的家人留下的痕迹，即使我们闭眼或失明，声音依然真实。音频体验不仅让这家屋子显得生机勃勃，还让我们更好地理解屋内居民的两条截然不同的叙事。*

*晚上晚些时候，我们去餐厅用餐。餐厅非常拥挤，热情的人们你来我往地交谈，形成了巨大的噪音。我立刻启动了语音分离模式。餐厅的喧闹消失了，但当服务员走近打招呼时，几秒钟内我的耳机分析了他的声音并将其隔离、清晰地传来。一分钟后，我的朋友的邻居加入了我们，她的声音也被隔离，从而让我们能够在不争夺音量的情况下进行轻松交谈。*

*然而，我们在寻找一段我们都能流利交流的共同语言时遇到了困难。为解决这个问题，我们启动了翻译模式。耳机随后聆听邻居的 speech，并实时翻译。系统屏蔽了她原始的声音，用我们的语言的语音合成替代，并将其空间化为如果来自她嘴边的样子。当然，没有唇同步，但虚拟声音的音色极其接近她本人，且声学模拟完美贴合当前环境，使人几乎忘记微处理器在做的“魔术”。*

*傍晚的空气感觉清爽，我们选择步行而不是骑自行车。过去几天我一直在玩一款间谍音频游戏，想在回家的路上继续揭开谜题。*

*‘Buds, spy game.’*

*不久后，我从附近的巷子里听到了‘Pssst！’的声音。沿着声音走去，我听到我的线人告知附近的砖墙建筑里有间谍会议，并鼓励我窃听。该信息是由另一位玩家留下的——不是在这条特定的巷子里，而是在他们自己的社区的某条巷子里。耳机中的游戏分析了我的周围环境，识别出一个与该环境相似的特征来放置信息。这样，故事就与每个人的生活产生了联系。*

*没过多久，我确实在一座废弃的砖墙仓库附近发现了它，并走近观察。通过一个窗户，我听到了一段虚构的对话正在内部展开。*

*‘…我们会始终保持通信加密。总理的右臂会拍照这份秘密备忘录并交给我们。我们必须快速行动，在纸张传播到更广之前进行干预…’*

*所以，总理的助手是间谍！我继续散步，准备了一条语音信息，然后‘丢’在下一个巴士站后面。在另一个城市，稍后，另一位玩家在巴士站后面发现了我的信息，并了解到总理内阁的阴谋细节。*
