# 2.6.6 Expression of the Radon inversion formula

The derivative, the Hilbert transform, and the backprojection algorithm are also referred to as the Radon inversion formula, which can be obtained by factoring the ramp filter \(|\omega|\) into the derivative part and the Hilbert transform part:

```
|\omega| = (2\pi i\omega) \times \left[ \frac{1}{2\pi} (-\text{sgn}(\omega)) \right].
```

The inverse Fourier transform of \(-i \text{sgn}(\omega)\) is \(1/(\pi s)\) and the inverse Fourier transform of \(2\pi i\omega\) is the derivative operator. Thus,

```
q(s, \theta) = \frac{\partial p(s, \theta)}{\partial s} * \frac{1}{2\pi^2 s},
```

and

```
f(x, y) = \int_0^\pi \int_{-\infty}^\infty \frac{\partial p(s, \theta)}{\partial s} \frac{1}{2\pi^2 (x \cos \theta + y \sin \theta - s)} ds d\theta.
```

# 2.6.7 Derivation of the backprojection-then-filtering algorithm

Let us first look at the backprojection \(b(x, y)\) of the original data \(p(s, \theta)\) (without filtering). The definition of the backprojection is

```
b(x, y) = \int_0^\pi p(s, \theta)|_{s=x \cos \theta + y \sin \theta} d\theta.
```

Using the definition of the inverse Fourier transform, \(p(s, \theta)\) can be represented with its Fourier transform

```
b(x, y) = \int_0^\pi \left[ \int_{-\infty}^\infty P(\omega, \theta) e^{2\pi i\omega (x \cos \theta + y \sin \theta)} d\omega \right] d\theta.
```

Using the central slice theorem, we can replace \(P\) by \(F\):

