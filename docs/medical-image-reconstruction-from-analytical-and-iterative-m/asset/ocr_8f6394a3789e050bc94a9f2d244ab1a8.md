# Example 2: On the $\gamma$-$\beta$ plane (similar to the sinogram for the parallel-beam projections), identify the double measurements for a fan-beam $2\pi$ scan.

# Solution

From Figure 3.15, we can readily find the fan-beam data redundancy conditions for

$$g(\gamma_1, \beta_1) = g(\gamma_2, \beta_2) \quad (3.28)$$

as

$$\gamma_2 = -\gamma_1 \quad (3.29)$$

and

$$\beta_2 = \beta_1 + 2\gamma_1 + \pi. \quad (3.30)$$

Using these conditions, the fan-beam data redundancy is depicted on the $\gamma$-$\beta$ plane in Figure 3.16, where every vertical line corresponds to a redundant slant line.
