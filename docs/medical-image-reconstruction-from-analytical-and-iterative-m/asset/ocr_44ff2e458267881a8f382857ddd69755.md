In the detector \(\alpha-w\) coordinates, \(g(\vec{\theta}, \vec{a}(s_k))\) and \(g(\vec{\theta}, \vec{a}(s_{k+1}))\) will have different \(a\) values. If you let us abuse the notation a little and use the detector coordinate system, we let

```
\(\begin{array}{ c }
g \left( a - \frac{\Delta s}{2} s, w, \vec{a}(s_k) \right) = g \left( \vec{\theta}, \vec{a}(s_k) \right) \\ \\
(5.59) \\
\end{array}\)
```

and

```
\(\begin{array}{ c }
g \left( a - \frac{\Delta s}{2} s, w, \vec{a}(s_{k+1}) \right) = g \left( \vec{\theta}, \vec{a}(s_{k+1}) \right), \\ \\
(5.60) \\
\end{array}\)
```

then we approximate the derivative as

```
\(\begin{array}{ c }
\frac{\partial g \left( (a, w, \vec{a} \left( s_{k+\frac{1}{2}} \right) \right)}{\partial s} \approx \frac{g \left( a + \frac{\Delta s}{2} s, w, \vec{a}(s_{k+1}) \right) - g \left( a - \frac{\Delta s}{2} s, w, \vec{a}(s_k) \right)}{\Delta s}, \\ \\
(5.61) \\
\end{array}\)
```

where \(\Delta s = s_{k+1} - s_k\).

Step 2: The result of Step 1 is weighed by the cosine function \(d/\sqrt{D^2 + w^2}\), obtaining

```
\(\begin{array}{ c }
\frac{D}{\sqrt{D^2 + w^2}} \frac{\partial g \left( a, w, \vec{a} \left( s_{k+\frac{1}{2}} \right) \right)}{\partial s}. \\ \\
(5.62) \\
\end{array}\)
```

This scaling is also called the length-correction weighting. This is a point-by-point scaling on the detector.

Step 3: To prepare for Hilbert transform operation, we rebin the \(\kappa\)-curves to horizontal lines, mapping the \(\alpha-w\) detector representation to \(a-\psi\) representation (see Figure 5.35). In other words, we move each data point on the \(\alpha-w\) detector up or down according to \(w = \frac{Dh}{2\pi R} \left( \psi \cos a + \frac{\psi}{\tan \psi} \sin a \right)\) so that the \(\kappa\)-curves become horizontal lines.
