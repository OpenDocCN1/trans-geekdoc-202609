We can see that the common practice in machine learning is the use of piecewise polynomial approximation, which is also known as spline interpolation. The piecewise constant function approximation is the zeroth-order spline interpolation. The piecewise linear function approximation is the first-order spline interpolation. Of course, we can try quadratic or cubic splines if we want.

The piecewise constant function approximation uses the unit step function as the building block.
