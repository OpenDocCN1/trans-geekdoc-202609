
where \( W = \text{diag}\{w_i\} \), the Landweber algorithm becomes

```
X^{\text{next}} = X^{\text{current}} - \alpha A^T W (AX^{\text{current}} - P).
```

The upper bound of the step size \(\alpha\) is determined by the square root of the largest eigenvalue of matrix \( A^T W A \). In reality, this eigenvalue is unknown. The following method can narrow down the range of \(\alpha\) to \(0 < \alpha < 1\):

```
x_i^{\text{next}} = x_i^{\text{current}} - \alpha \frac{\sum_j a_{ji} w_j (\sum_n a_{jn} x_n^{\text{current}} - p_j)}{\sum_j a_{ji} w_j \sum_n a_{jn}}.
```

In the above expression, \(\sum_j a_{ji} w_j \sum_n a_{jn}\) is a scalar for each pixel \( i \). It can be understood as follows. Let us form a constant image volume, and each voxel has a value of 1. Then we perform forward projection on this constant image along the \( j \)-th path, which is what \(\sum_n a_{jn}\) does. Next, we multiply this projection value by a scalar \( w_j \), which is the meaning of \( w_j \sum_n a_{jn} \). Finally, we backproject the scalar value \( w_j \sum_n a_{jn} \) into the image domain along the \( j \)-th path (which is the same path as we perform the forward projection) to the \( i \)-th image voxel. The expression \(\sum_j a_{ji} w_j \sum_n a_{jn}\) generates an image that is used to normalize the step size in the Landweber algorithm; this \(\sum_j a_{ji} w_j \sum_n a_{jn}\) normalization image can be precalculated.

## 6.9.3 CG algorithm

This CG algorithm solves the normal equations

```
A^T A X = A^T P.
```

Let \( M = A^T A \) and \( B = A^T P \). The normal equations become

```
M Y = B.
```

Matrix \( M \) is real, symmetric, and positive definite (or semidefinite). The implementation steps of the CG algorithm are given as follows.

Set up initial conditions:

```
X^{(0)} = \vec{0}, R_0 = B, \text{and } \Delta_0 = R_0.
```

These three image domain arrays are represented as three 1D column vectors.

Iterations (for \( n = 1, 2, 3, \dots \) do the following):

Update the step size (a scalar) \(\alpha_n\) as a ratio of two scalars:

```
\alpha_n = (R_{n-1}^T R_{n-1}) / (\Delta_{n-1}^T M \Delta_{n-1}).
```

Update the image with

$$X^{(n)} = X^{(n-1)} + \alpha_n \Delta_{n-1}.$$
(6.54)

Calculate the residual image

$$R_n = R_{n-1} - \alpha_n M \Delta_{n-1}.$$
(6.55)

Calculate the factor (a scalar) \(\beta_n\) used to find the searching direction

$$\beta_n = (R_n^T R_n) / (R_{n-1}^T R_{n-1}).$$
(6.56)

Calculate the new searching direction for the next iteration

$$\Delta_n = R_n + \beta_n \Delta_{n-1}.$$
(6.57)

endfor

This CG algorithm has some properties:

- (1) A Krylov subspace, \(\kappa_n\), is expanding as the iteration number increases

```
$$\kappa_n = \langle B, MB, M^2B, ..., M^{n-1}B \rangle$$ $$= \langle X^{(1)}, X^{(2)}, X^{(3)}, ..., X^{(n)} \rangle$$ $$= \langle R_0, R_1, R_2, ..., R_{n-1} \rangle$$ $$= \langle \Delta_0, \Delta_1, \Delta_2, ..., \Delta_{n-1} \rangle$$ (6.58)
```

where \(\langle R_0, R_1, R_2, ..., R_{n-1} \rangle\) denotes a space spanned by \(R_0, R_1, R_2, ..., R_{n-1}\).

- (2) The residuals are orthogonal to each other, that is,

```
$$R_n^T R_j = 0, \quad j < n.$$
(6.59)
```

- (3) The search directions are M-conjugate with each other, that is,

```
$$\Delta_n^T M \Delta_j = 0, \quad j < n.$$
(6.60)
```

- (4) At each iteration, \(X^{(n)}\) minimizes the objective function over the Krylov subspace \(\kappa_n\). Therefore, if M is \(m \times m\), the algorithm converge in at most m iterations.

What makes the iterative CG algorithm remarkable is the choice of the search direction \(\Delta_{n-1}\) which has the special property that minimizing the objective function over \(X^{(n)} + \langle \Delta_{n-1} \rangle\) actually minimizes it over all of \(\kappa_n\).

## 6.9.4 ML-EM

The emission data ML-EM algorithm is the most popular iterative algorithm in emission tomography and is expressed as

![](img/dd555effd38151c67af30d84800c554a_170_0.png)

where the summation over \(\hat{j}\) is the projector identical to \(Ax\) in Section 6.9.1, and the summations over \(i\) are the backprojectors. This algorithm compares the measured projection \(p_i\) with the forward projection of the current estimate \(Ax\) as a ratio. This ratio is backprojected to the image domain. The summation \(\sum_i a_{ij}\) is the backprojection of constant 1 to the image domain. The ratio of these two backprojected images determines a modification factor to update the current estimate of the image.

The following is the derivation of the emission-projection ML-EM algorithm. If \(p\) is a random variable with the Poisson distribution, then its probability mass function is given as

![](img/dd555effd38151c67af30d84800c554a_170_1.png)

where \(\lambda\) is the expected value of this random variable. For an imaging problem \(AX = P\), the number of photons emitted from each image pixel is a Poisson random variable, and each measurement \(p_i\) can be treated as the summation of these Poisson variables. We write

![](img/dd555effd38151c67af30d84800c554a_170_2.png)

where \(c_{ij}\) is the Poisson random variable and

![](img/dd555effd38151c67af30d84800c554a_170_3.png)

Note that \(X\) is not random.

We can set up the likelihood function as the joint probability mass function of all Poisson distributed random variables \(c_{ij}\):

![](img/dd555effd38151c67af30d84800c554a_170_4.png)

Taking the logarithm of this likelihood function yields

![](img/dd555effd38151c67af30d84800c554a_170_5.png)

The second summation term \(\sum_{ij} \ln(c_{ij}!)\) does not contain the parameters \(x_j\) to be estimated; therefore, it can be discarded without changing the ML problem. To find the ML solution of \(x_j\), we will maximize the following objective function:

\(L = \sum_{ij} (c_{ij} \ln(a_{ij}x_j) - a_{ij}x_j).\) (6.67)

### The "E" Step:

The above objective function contains random variables \(c_{ij}\). The "E" (expectation) step is to replace it by the expected value using the measurement \(p_i\) and the current estimate of the parameters \(x_j\). That is, \(c_{ij}\) is replaced by

\(E(c_{ij}|p_i, X^{current}) = \frac{a_{ij}x_j^{current}}{\sum_k a_{ik}x_k^{current}} p_i.\) (6.68)

Thus, after the "E" step, the objective function becomes

\(E(L|P, X^{current}) = \sum_{ij} \left( \frac{a_{ij}x_j^{current}}{\sum_k a_{ik}x_k^{current}} p_i \ln(a_{ij}x_j) - a_{ij}x_j \right).\) (6.69)

### The "M" Step:

To maximize the new objective function \(E(L|P, X^{current})\), we will take the derivative of it with respect to estimation parameters \(x_j\) and set the derivatives to zero, that is,

\(\frac{\partial E(L|P, X^{current})}{\partial x_j} = \sum_i \left( \frac{a_{ij}x_j^{current}}{\sum_k a_{ik}x_k^{current}} p_i \frac{a_{ij}}{a_{ij}x_j} - a_{ij} \right)\)
\(= \frac{1}{x_j} \sum_i \frac{a_{ij}x_j^{current}}{\sum_k a_{ik}x_k^{current}} p_i - \sum_i a_{ij}\)
\(= 0.\) (6.70)

Solving for \(x_j\), we finally have the ML-EM algorithm:

\(x_j = \frac{x_j^{current}}{\sum_i a_{ij}} \sum_i a_{ij} \frac{p_i}{\sum_j a_{ij}x_j^{current}}.\) (6.71)

In fact, this multiplicative ML-EM algorithm can also be written in an additive form so that it appears like a gradient descent algorithm as

\(X^{next} = X^{current} + S^{current} A^T \Lambda^{current} (P - AX^{current}),\) (6.72)

where the step size is

\(S^{current} = \text{diag} \left\{ x_j^{current} / \sum_i a_{ij} \right\},\) (6.73)

and the noise variance weighting is

```
\Lambda^{\text{current}} = \text{diag}\{1/\sum_k a_{ik}x_k^{\text{current}}\} \approx \text{diag}\{1/p_i\}.
```

In reality, the measurement noise may not be exactly Gaussian distributed or Poisson distributed. The author personally believes that it is not very critical what the noise distribution is, while it is very important to know the variance of the measurement noise, because it is the variance that is used in measurement weighting. For example, in an imaging system, the measurement \(p_i\) is noisy and the noise variance is related to \(p_i\) as

```
(\text{Variance of } p_i) = s_i \bar{p}_i,
```

where \(s_i\) can be a system scaling factor, \(p_i\) may not be Poisson distributed, and \(\bar{p}_i\) is the expected value of \(p_i\). Realizing that the imaging model is

```
\sum_k a_{ik}x_k = p_i,
```

we can modify the ML-EM algorithm and obtain a general image reconstruction algorithm as

```
x_j^{\text{next}} = \frac{x_j^{\text{current}}}{\sum_i a_{ij} \frac{1}{s_i}} \sum_i a_{ij} \frac{p_i}{s_i \sum_j a_{ij}x_j^{\text{current}}}.
```

If we rewrite this modified algorithm in the additive form, the noise variance weighting is

```
\Lambda^{\text{current}} = \text{diag}\left\{1/\left(s_i \sum_k a_{ik}x_k^{\text{current}}\right)\right\} \approx \text{diag}\{1/(s_ip_i)\}.
```

## 6.9.5 OS-EM

With minor changes to the ML-EM algorithm, the ordered subset version of it can be readily obtained as the OS-EM algorithm:

```
x_j^{\text{next}} = \frac{x_j^{\text{current}}}{\sum_{i \in S_k} a_{ij}} \sum_{i \in S_k} a_{ij} \frac{p_i}{\sum_j a_{ij}x_j^{\text{current}}},
```

where \(S_k\) represents the \(k\)-th subset of the projections.
