## 1.5.3 The Dirac $\delta$-function

The Dirac $\delta$-function is not a regular function that maps a value in the domain to a value in the range. The Dirac $\delta$-function is a generalized function or a distribution function. The $\delta$-function can be defined in many ways. Here, we use a series of Gaussian functions to define the $\delta$-function. Each of the Gaussian functions (see Figure 1.13) has a unit area underneath its curve, and as the parameter \(n\) gets larger, the curve gets narrower and taller (see Figure 1.13):

$$\left(\frac{n}{\pi}\right)^{1/2} e^{-nx^2}. \quad (1.19)$$

![](img/dd555effd38151c67af30d84800c554a_25_0.png)

Fig. 1.13: Using a train of Gaussian functions to define the $\delta$-function.

Let \(f(x)\) be the smooth function that is differentiable everywhere with any order and \(\lim_{x \to \infty} x^N f(x) = 0\) for all \(N\). Then the $\delta$-function is defined implicitly as

$$\lim_{n \to \infty} \int_{-\infty}^{\infty} \left(\frac{n}{\pi}\right)^{1/2} e^{-nx^2} f(x) dx = \int_{-\infty}^{\infty} \delta(x) f(x) dx = f(0). \quad (1.20)$$

The $\delta$-function has some properties:

\(\int_{-\infty}^{\infty} \delta(x-a)f(x)dx = \int_{-\infty}^{\infty} \delta(x)f(x+a)dx = f(a), \quad (1.21)\)

\(\int_{-\infty}^{\infty} \delta(ax)f(x)dx = \frac{1}{|a|}f(0), \quad (1.22)\)

\(\int_{-\infty}^{\infty} \delta^{(n)}(x)f(x)dx = (-1)^n f^{(n)}(0) \text{[the nth-order derivative]}, \quad (1.23)\)

\(\delta(g(x))f(x) = f(x) \sum_n \frac{1}{|g'(\lambda_n)|} \delta(x-\lambda_n), \quad (1.24)\)

where \(\lambda_n\)s are the zeros of \(g(x)\).

In 2D and 3D cases, \(\delta(\vec{x}) = \delta(x)\delta(y)\) and \(\delta(\vec{x}) = \delta(x)\delta(y)\delta(z)\), respectively. In the last property, \(|g'|\) will be replaced by \(|\text{grad}(g)| = \sqrt{(\partial g/\partial x)^2 + (\partial g/\partial y)^2}\) and \(|\text{grad}(g)| = \sqrt{(\partial g/\partial x)^2 + (\partial g/\partial y)^2 + (\partial g/\partial z)^2}\), respectively, in 2D and 3D cases.

In 2D imaging, we use a 2D \(\delta\)-function \(\delta(\vec{x} - \bar{x}_0)\) to represent a point source at location \(\vec{x} = \bar{x}_0\). The Radon transform of \(f(\vec{x}) = \delta(\vec{x} - \bar{x}_0) = \delta(x - x_0)\delta(y - y_0)\) is given as

\(p(s, \theta) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(\vec{x}) \delta\left(\vec{x} \cdot \vec{\theta} - s\right) d\vec{x}, \quad (1.25)\)

\(p(s, \theta) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} \delta(x, x_0)\delta(y - y_0)\delta(x \cos \theta + y \sin \theta - s) dx dy, \quad (1.26)\)

\(p(s, \theta) = \int_{-\infty}^{\infty} \delta(y - y_0) \left[ \int_{-\infty}^{\infty} \delta(x, x_0) \delta(x \cos \theta + y \sin \theta - s) dx \right] dy, \quad (1.27)\)

\(p(s, \theta) = \int_{-\infty}^{\infty} \delta(y - y_0)\delta(x_0 \cos \theta + y \sin \theta - s) dy, \quad (1.28)\)

\(p(s, \theta) = \delta(x_0 \cos \theta + y_0 \sin \theta - s), \quad (1.29)\)

which is a sinogram similar to that shown in Figure 1.6.

Example 2: Find the projections of a uniform disk. The center of the disk is not at the center of detector rotation.

*Solution*

We already know that if the center of the disk is at the center of detector rotation, the projection can be evaluated as

```
p(s, θ) = 2ρ√R²−s² if |s| < R; p(s, θ) = 0 otherwise. (1.30)
```

Without loss of generality, we now assume that the center of the disk is on the positive x-axis with the coordinates (r, 0) (Figure 1.16).

For this new setup, we need to shift the projection data on the s-axis. The shifting distance is \(r \cos \theta\). That is,

```
$p(s, \theta) = 2\rho \sqrt{R^2 - (s - r \cos \theta)^2} \quad \text{if } |s - r \cos \theta| < R; \ p(s, \theta) = 0 \text{ otherwise.} \quad (1.31)$
```

Example 3: Show that the parallel-beam data redundancy condition is p(s, theta) = p(-s, theta + pi).

Proof. Using the projection definition in Section 1.5, we have

$$p(-s, \theta + \pi) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x,y)\delta(x \cos(\theta + \pi) + y \sin(\theta + \pi) - (-s))dxdy$$
$$= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x,y)\delta(-x \cos\theta - y \sin\theta + s)dxdy$$
$$= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x,y)\delta(-(x \cos\theta + y \sin\theta - s))dxdy$$
$$= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x,y)\delta(x \cos\theta + y \sin\theta - s)dxdy$$
$$= p(s, \theta).$$ (1.32)

[The \(\delta\)-function is an even function.]

**Example 4:** Show that the point spread function of the projection/backprojection operator is 1/r, where \(r = \|\vec{x} - \vec{x}_0\|\) and the point source object is \(f(\vec{x}) = \delta(\vec{x} - \vec{x}_0)\).

Proof. Using the definition of the backprojection, we have

\(b(\vec{x}) = \int_{0}^{\pi} p(\vec{x} \cdot \vec{\theta}, \theta) d\theta = \int_{0}^{\pi} \int_{-\infty}^{\infty} f\left( (\vec{x} \cdot \vec{\theta}) \vec{\theta} + t \vec{\theta}^{\perp} \right) dt d\theta.\) (1.33)

We realize that the line integral \(\int_{-\infty}^{\infty} f\left( (\vec{x} \cdot \vec{\theta}) \vec{\theta} + t \vec{\theta}^{\perp} \right) dt\) is along the line that passes through the point \(\vec{x}\) and in the direction of \(\vec{\theta}^{\perp}\) (see Figure 1.17), so

\(\int_{-\infty}^{\infty} f\left( (\vec{x} \cdot \vec{\theta}) \vec{\theta} + t \vec{\theta}^{\perp} \right) dt = \int_{-\infty}^{\infty} f\left( \vec{x} - \hat{t} \vec{\theta}^{\perp} \right) d\hat{t}.\) (1.34)

Therefore, the projection/backprojection image can be obtained as

\(b(\vec{x}) = \int_{0}^{\pi} \int_{-\infty}^{\infty} f\left( \vec{x} - \hat{t} \vec{\theta}^{\perp} \right) d\hat{t} d\theta.\) (1.35)

![](img/dd555effd38151c67af30d84800c554a_30_0.png)

Fig. 1.17: The line integral is performed on a line passing through the backprojection point.

Let \(\widehat{x} = \hat{t}\widehat{\theta}^{\perp}\) with \(\|\widehat{x}\| = |\hat{t}|\), \(d\widehat{x} = |\hat{t}| d\hat{t} d\theta\). The above expression becomes

\(b(\vec{x}) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} \frac{f\left( \vec{x} - \widehat{x} \right)}{\|\widehat{x}\|} d\widehat{x}.\) (1.36)

Let \( f(\vec{x}) = \delta(\vec{x} - \vec{x}_0) \). The point spread function of the projection/backprojection operator is

\( b(\vec{x}) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} \frac{\delta\left(\vec{x} - \vec{x}_0 - \widehat{\vec{x}}\right)}{\|\widehat{\vec{x}}\|} d\widehat{\vec{x}} = \frac{1}{\|\vec{x} - \vec{x}_0\|} = \frac{1}{r}. \tag{1.37} \)

**Example 5:** Evaluate \( \int_{-\infty}^{\infty} \delta\left(e^{2(x-3)(x+4)} - 1\right) f(x) dx \).

_Solution_ Let

\( g(x) = e^{2(x-3)(x+4)} - 1. \tag{1.38} \)

Solving \( g(x) = e^{2(x-3)(x+4)} - 1 = 0 \), we obtain the zeros of \( g(x) \) as

\( \lambda_1 = 3 \text{ and } \lambda_2 = -4. \tag{1.39} \)

The derivative of \( g(x) \) is

\( g'(x) = 2[(x-3) + (x+4)]e^{2(x-3)(x+4)} = 2(2x+1)e^{2(x-3)(x+4)}. \tag{1.40} \)

Thus, at the two zeros of \( g(x) \), we have

\( g'(3) = 14 \text{ and } g'(-4) = -14. \tag{1.41} \)
