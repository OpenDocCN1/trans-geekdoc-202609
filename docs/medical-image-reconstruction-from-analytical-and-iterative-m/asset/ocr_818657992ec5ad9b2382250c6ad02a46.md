Both functions can now be treated as periodic with the same period $M$. We treat discrete signals to be periodic because we use the fast Fourier transform (FFT) method to indirectly compute convolution and the FFT method can only compute circular convolution.

Let the discrete version of eq. (2.52) be $H(k)$, $k = 0, 1, 2, \dots, M - 1$, and $\text{RAMP}(\omega)$ in eq. (2.52) be $H_c(\omega)$, whose corresponding discrete convolution kernel is $h(n)$. Then $H(k)$ can be calculated as

```
H(k) = \sum_{n=0}^{M-1} h_c(n) e^{-j 2 \pi n k / M}
= \sum_{n=0}^{M-1} \int_{-0.5}^{0.5} H_c(\omega) e^{j 2 \pi \omega n} d\omega e^{-j 2 \pi n k / M}
= \int_{-0.5}^{0.5} H_c(\omega) \sum_{n=0}^{M-1} e^{j 2 \pi n (\omega - k / M)} d\omega
= \int_{-0.5}^{0.5} H_c(\omega) \frac{1 - e^{j 2 \pi M (\omega - k / M)}}{1 - e^{j 2 \pi (\omega - k / M)}} d\omega
= \int_{-0.5}^{0.5} H_c(\omega) \frac{\sin(\pi M (\omega - k / M))}{\sin(\pi (\omega - k / M))} e^{j \pi (M - 1) (\omega - k / M)} d\omega.
```
