s'(x) = \frac{e^{-x}}{(1+e^{-x})^2} = s(x)[1-s(x)], \quad (9.10)

which implies that the derivative of the sigmoid function is the sigmoid function itself multiplied by 1 minus the sigmoid function. Equation (9.10) is useful in implementation of the backpropagation algorithm that involves sigmoid functions. It is clear to see that the sigmoid function s(ax) tends to the unit step function u(x) as a -> \infty.
