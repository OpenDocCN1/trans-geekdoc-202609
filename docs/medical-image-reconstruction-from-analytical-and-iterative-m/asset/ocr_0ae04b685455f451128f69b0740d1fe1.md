# 7.4 Mathematical expressions

In this section, we assume that a slice selection has been done and **M̲**(x, y) is a function of x and y. The vector **M̲**(x, y) can be decomposed into the x-component Mx(x, y), the y-component My(x, y), and the z-component Mz(x, y). We define a complex function f(x, y) as

```
f(x,y) = Mx(x,y) + iMy(x,y). (7.3)
```

The goal of MRI is to obtain this function f(x, y) and display its magnitude |f(x, y)| as the final output for the radiologists to read.

Let us first consider the effect of the readout (x) gradient. When the x-gradient is turned on, the magnetic field strength is a function of x as

```
B(x) = B0 + xGx, (7.4)
```

and the associated Larmor frequency is calculated as

```
ω(x) = γ(B0 + xGx). (7.5)
```

At readout, the function f(x, y) will be encoded as

```
f(x,y)cos(2πω(x)t) = f(x,y)cos(2πγ(B0 + xGx)t), (7.6)
```

where γB0 is the carrier frequency and has no contribution for image reconstruction. In the MRI receiver, there is a demodulator that can remove this carrier frequency. After the removal of the carrier frequency, the leftover baseband signal is given as

```
f(x,y)cos(2πγxGx t). (7.7)
```

Since the signal comes from the entire x–y plane, the received baseband signal is the summation of the signals from each location (x, y):

```
∫∫ f(x,y)cos(2πγxGx t)dxdy. (7.8)

```
