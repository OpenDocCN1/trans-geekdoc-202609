Let

$$\omega = \hat{\omega} \cos \alpha, \quad -\frac{\mu}{2\pi i} = \hat{\omega} \sin \alpha, \tag{4.17}$$

which give

$$\hat{\omega} = \sqrt{\omega^2 - (\frac{\mu}{2\pi})^2}, \quad \alpha = \frac{i}{2} \ln \frac{\omega + \frac{\mu}{2\pi}}{\omega - \frac{\mu}{2\pi}}. \tag{4.18}$$

Changing the $s$-$t$ coordinate system to the $x$-$y$ coordinate system with $s = x \cos \theta + y \sin \theta$ and $t = -x \sin \theta + y \cos \theta$, we have

$$\hat{p}_{s \to \omega}(\omega, \theta) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x,y) e^{-2\pi i \hat{\omega} [x \cos(\theta + \alpha) + y \sin(\theta + \alpha)]} \, dx \, dy \tag{4.19}$$ $$= F(\hat{\omega} \cos(\theta + \alpha), \hat{\omega} \cos(\theta + \alpha)).$$

Here $F$ is the 2D Fourier transform of the image $f$. Since $F(\hat{\omega} \cos(\theta + \alpha), \hat{\omega} \cos(\theta + \alpha))$ is a periodic function in $\theta$ with a period of $2\pi$, $F$ has a Fourier series expansion. Thus, we can use the Fourier series expansion on the right-hand side of eq. (4.19):

$$\hat{p}_{s \to \omega}(\omega, \theta) = \sum_n F_n(\hat{\omega}) e^{in(\theta + \alpha)}, \tag{4.20}$$

where the Fourier coefficients are defined as

$$F_n(\hat{\omega}) = \frac{1}{2\pi} \int_0^{2\pi} F(\hat{\omega} \cos \theta, \hat{\omega} \sin \theta) e^{-in\theta} \, d\theta. \tag{4.21}$$

Then,

$$\hat{p}_{s \to \omega}(\omega, \theta) = \sum_n F_n(\hat{\omega}) e^{in(\theta + \alpha)} \tag{4.22}$$ $$= \sum_n F_n \left( \sqrt{\omega^2 - (\frac{\mu}{2\pi})^2} \right) e^{in\theta} e^{\frac{in i}{2} \ln \frac{\omega + \frac{\mu}{2\pi}}{\omega - \frac{\mu}{2\pi}}}$$ $$= \sum_n \left( \frac{\omega - \frac{\mu}{2\pi}}{\omega + \frac{\mu}{2\pi}} \right)^{\frac{n}{2}} F_n \left( \sqrt{\omega^2 - (\frac{\mu}{2\pi})^2} \right) e^{in\theta}.$$
