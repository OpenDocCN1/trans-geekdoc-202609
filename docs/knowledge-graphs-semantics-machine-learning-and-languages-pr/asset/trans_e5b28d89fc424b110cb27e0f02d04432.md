
class *transraz:Event* 被定义为 *crm:E2 Temporal Entity* 的子类，用于表示可与时间点关联的文化、政治、军事及其他事件。 *transraz:Event* 继承 *crm:E2 Temporal Entity* 的所有属性以连接其他事件，并额外提供属性用于将事件与主体连接，例如 *transraz:participant*（REQ1）。此外，类 *crm:E5 Event* 被扩展为两个额外的子类。类 *transraz:Relabeling* 包含主体和对象实例名称的变更。而类 *transraz:Refunction* 处理功能层面的变更，例如建筑物的功能从药房变为商店（REQ2）。

为了应对历史数据中时间单位的不确定性和不完整性，必须考虑不同粒度水平的时间表达。因此，新的属性 *transraz:time* 将事件与 OWL-Time [16] 中的 *time:TemporalEntity* 连接起来。与 *crm:E52 Time-Span* 相比，它提供了更细粒度的时间指示表示，提供了时间瞬间和区间的类与关系，以及关于持续时间的信息和包括日期时间信息在内的时序位置。此外，通过提供类型为 interval-interval 和 interval-instant 的时序关系来解决时间区间的不确定性和不完整性。因此，即使确切的事件时间未知，也能对时序关系进行建模，例如 *interval time:overlaps interval2*（REQ4 和 REQ5）。

## 3.2.4. 文档的表示与注释。

在 TRANSRAZ 数据模型中，文档的使用具有双重性：

- REQ1：历史文献本身被视为文化遗产对象，需要语义表示以实现资源的检索性和互联性（CQ6.1、CQ6.3）。
- REQ2：需要溯源以追踪陈述和实体的来源，它们所衍生的来源被用作背景证据（CQ6.1-4）。

遵循最佳实践，历史文献及其层级使用 FRBR 对齐书目本体（FaBiO）[23] 进行建模。FaBiO 为记录和发布书目记录提供了丰富的语义。它支持档案记录（*fabio:ArchivalDocumentSet* 和 *fabio:ArchivalDocument*）、期刊（*fabio:Journal*）、其期号（*fabio:JournalIssue*）和文章（*JournalArticle*）、书籍 *fabio:Book* 及其章节（*fabio:BookChapter*）的表示。部分使用 DCMI 元数据术语词汇表，历史文献被标注了相关元数据，例如 *dcterms:creator*、*dcterms:publisher*。Web 注释本体（OA）用于为资源提供注释。注释（*oa:Annotation*）将信息连接到信息被提取出的来源，例如地址簿中提到的人或从 NKL 派生的事实。此外，属性 *oa:hasSelector* 允许将注释链接到文档的特定部分，包括注释所做的文本坐标。这样，数据摘录的溯源始终可以被检索和证明。从丰富、复杂和异构的资源中表示知识，并进一步实现信息的可使用性和探索性，这带来了多样化的建模挑战。为应对这些挑战，TRANSRAZ 数据模型中开发并呈现了一种模块化建模方法，该方法能够通过领域特定本体受益于来自不同领域的数据连接。

## 3.3. TRANSRAZ 数据模型的评估

第 4.2 节中引入的能力问题用于界定数据模型、指导建模过程，并提供评估数据模型的方式。CQ 是与领域专家——艺术史学家和数字艺术史专家——共同迭代开发的。对数据模型的评估是通过检查 CQ 是否可以转换为 SPARQL 查询并验证数据模型在提供正确答案方面的适用性来进行的。²³ ²⁴ 评估表明，TRANSRAZ 数据模型四个主要构建模块的集成支持多方面的查询。用例进一步表明，构建模块之间的互联是必要的，并能实现最有价值的发现。所呈现的贡献不会保持静态，并在与领域专家合作集成更多资源后将得到进一步增强和扩展。

## 5. 结论与未来工作

在 TRANSRAZ 项目中创建了 TRANSRAZ 数据模型，该模型能够对历史城市的主体、事件、建筑物对象和历史文献进行语义表示。该模型能够在 3D 虚拟环境中对纽伦堡历史进行科学准确的探索，并可应用于具有类似目标的其他历史城市。它是公开可用的，计划通过添加新词汇表和受控词汇表来扩展它，以保持历史术语的一致性。此外，集成到 TOPORAZ VRE 中的 TRANSRAZ 知识图谱将通过添加更多数据资源而得到扩展。探索从历史资源中提取的知识及其与 3D VRE 的互联将使用户获得对隐藏过去的印象，从而更好地理解当今世界的形成、其社会和自身。
