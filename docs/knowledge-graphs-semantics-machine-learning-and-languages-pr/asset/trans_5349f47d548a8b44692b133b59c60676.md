## 4. 结论与展望

经策划的 KG，在经过仔细的工程设计和数据集成后，可作为信息检索、决策支持和推荐系统等各种应用的有用资源。在本工作中，我们展示了将 PlanQK 平台数据即时集成到统一 KG 的管道。语义化过程可以通过机器学习增强技术，例如命名实体识别，从文本属性中提取相关概念和关系而进一步改进。为了便于在平台上进行 IR，我们实现了原生语义搜索以及分面语义搜索。还需要进一步的工作来评估搜索功能并完善搜索能力。我们计划将 PlanQK KG 的一部分作为 Linked Open Data 公开，并与相关外部来源建立连接，例如 DBPedia [19]、Wikidata [20] 以及研究领域中的图，例如开放研究知识图谱 (ORKG) [21]。由于量子计算领域的知识目前正在迅速变化，应建立社区受控的图策划的可能性。
