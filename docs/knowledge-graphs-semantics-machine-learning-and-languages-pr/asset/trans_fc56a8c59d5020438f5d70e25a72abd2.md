## 语义网研究

语义网已经发展成为一个成熟的研究领域。其方法在万维网内外都有着创新的应用。其底层技术对相邻研究领域和工业应用产生了重大影响。本丛书报道语义网及其底层技术在基础、方法、应用等方面的最新进展。它是交流最新发展的核心论坛，收录了与语义网相关的所有主题的研究专著、教科书和编辑文集。

**摘要。** 本卷收录了 SEMANTiCS 2023——第19届国际语义系统会议的论文集。SEMANTiCS 是积极投身于语义计算力量利用的专业人士和研究人员的重要盛会。在 SEMANTiCS 上，与会者既能深入理解其变革潜力，也会面对它所呈现的实际限制。每年，该会议都会吸引来自研究机构、非营利组织、公共管理部门以及全球最大型企业等广泛组织的信息管理者、IT 架构师、软件工程师和研究人员。

**关键词。** 语义系统，知识图谱，人工智能，语义网，关联数据，机器学习，知识发现

SEMANTiCS 是一个充满活力的平台，促进了语义系统领域前沿科学成果的交流。此外，其范围还扩展到数据科学、机器学习、逻辑编程、内容工程、社会计算和语义网等领域的新研究挑战。会议已进入第19个年头，发展成为在学术界与工业界之间架起无缝桥梁的杰出国际盛会。

SEMANTiCS 的参与者与投稿者从受人尊敬的研究人员和行业专家那里获得宝贵的见解，从而能够紧跟语义计算广阔领域中新兴的趋势与主题。SEMANTiCS 社区凭借其多元化的构成而蓬勃发展，吸引着来自人工智能、数据科学、知识发现与管理、大数据分析、电子商务、企业搜索、技术文档、文档管理、商业智能和企业词汇管理等多元角色的专业人士。
