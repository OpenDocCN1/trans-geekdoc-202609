文化遗产机构，尤其是那些拥有民族志收藏的机构，通过了解物品传记的新事实，不断对物品进行（重新）情境化[5]。传统的方法是对单个物品进行专门研究，即所谓的*来源研究*。文化遗产物品的来源描述了一件物品的所有权历史以及物品法律地位的证据[6]。它还可以用于评估文物的真实性，并识别任何非法占有的作品[7]。在许多情况下，这项广泛研究的细节并不可作为结构化数据获得，而仅以叙述性文本文件的形式报告，这限制了此类信息的可发现性、可重用性和互操作性。通常，开展研究的人员或其代表的机构会反思物品元数据[8]。研究完成后，研究人员可能会更新收藏管理系统中有限数量的元数据。在这个过程中，潜在的多种观点被简化为单一的“真相”视角。例如，同一件物品可以被标注为“战利品”或“合法拥有的财产”，这取决于研究人员对战事文献的解读。这样的解读可能受到个人、文化或政治背景的影响，并且很可能随着时间而变化。更重要的是，当不止一种注释具有同等的有效性时，有必要在元数据中保留这两种解读。为了让未来的研究人员和专业人员能够研究这些多重视角，机构的信息系统需要能够保存、维护和交付物品的不同视图及其来源数据[9]。

作为信息架构的语义网和作为数据模型的知识图谱，是此类多声部知识表征的有前途的技术[9]。其分散和网络化的特性使其非常适合处理多样化的意见，同时保留相互竞争的观点及其来源。我们认为这项关于多视角表征的研究就是这种多声部知识表征的一个例子。我们研究了现有的语义网解决方案（如命名图以及现有的来源和遗产本体）在多大程度上适用于在数据中表示多重视角。

本文的贡献在于研究如何将语义网技术（即命名图、PROV-DM）与现有的文化遗产本体（即CIDOC-CRM）结合起来形成一个统一的模型，以满足领域专家指定的多声部来源需求。我们首先确定了这些表示多视角民族志物品来源信息的需求。我们提出了此类信息的建模方法，并将该模型应用于11件民族志物品，展示了在保留数据来源的同时表达物品传记复杂保管链的能力。该解决方案在存在多种替代理论时保留了此类信息的多声部性。最终的知识图谱通过与需求分析构建的能力问题进行验证。

## 2. 相关工作

高质量的元数据对于提高数字内容的可访问性和可重用性至关重要。博物馆物品的元数据必须包含物品进入博物馆之前的详细信息，以及物品在博物馆期间生成的细节[10]。在对文化遗产数据进行建模时，必须以一种对非技术用户（如文化遗产专家）可用的方式来表示，以便他们查询、审查和重用。关于文化遗产元数据的建模已经进行了广泛的研究[1,3,11,12,13]。然而，这些工作都没有研究如何对丰富的物品来源信息进行建模，这些信息通常仅以文本报告的形式存在。

为了表示文化遗产元数据，人们开发了以对象为中心和以事件为中心的本体。然而，研究发现，以事件为中心的方法在表示来源或其他时间数据方面具有优势[1,14]。事件中心模型通过关联事件（如征集或制作）来表示知识。CIDOC-CRM自2006年起成为ISO标准[15,16]，是一种以事件为中心的本体，专为文化遗产领域设计，以促进集成和交换。CIDOC-CRM可以通过添加多个信息层来对给定现实的多个语义信息实例进行建模。然而，研究[17]表明，这本身并不是表示多视角数据的可行解决方案，因为这些多层只是信息的积累，而没有提及数据来源。作者认为，必须对数据进行组织，以便研究人员能够轻松找到先前的信息并用于新的推理。

关于多重视角的讨论正在文化遗产领域进行[18,19]。Dijkshoorn等人[1]提出了文化遗产本体的六项要求，其中之一支持在描述同一文物时捕获可能相互冲突的多个来源。他们的研究表明，Europeana数据模型[20]通过使用代理（proxy）允许多条记录描述同一对象。然而，EDM中的代理只能通过将代理连接到对象资源来在一般层面上描绘对象，而不能连接到关于该资源的特定陈述。Ockeloen等人[21]采用了类似的方法，他们提出了一种代理解决方案，用于表示来自不同视角和来源的传记描述。

另一种多视角表示解决方案是使用命名图。Bizer等人[22]指出，信息提供者有不同的世界观；因此，命名图允许不同的信息提供者对同一实体作出不同的声明。命名图的优点在于，它允许对三元组集合进行分组以对整个集合进行陈述，并且在以RDF实现CIDOC-CRM时可以快速采用。在命名图上使用IRI，可以将数据来源附加到图本身。

尽管对文化遗产数据的多视角表示的需求已被确认，但实际应用仍具有挑战性。本研究提出了一种基于上述领域标准的可行解决方案，用于表示文化遗产物品来源的多视角解读。

### 3.1. 方法

为了收集文化遗产来源多视角表示的数据需求，我们通过与领域专家的焦点访谈进行问题分析，旨在深入了解问题的本质。焦点访谈是一种基本的需求工程工具，用于调查当前的问题和关注点。在确定了数据模型的需求后，我们利用这些需求来构建模型（第4节）。此外，我们从访谈中提炼出九个能力问题，用于验证模型。

在焦点访谈中，我们招募了五位以不同身份参与Pressing Matter项目⁴的博物馆学专家（受访者概览见表1）。表中参与者提到的索引将在本文其余部分用于指示相应的受访者。Pressing Matter是一个荷兰项目，旨在调查殖民时期收集的文物，以支持社会与殖民历史的和解。选择这些专家是基于他们不同的经验、背景和工作方法。尽管他们研究的是不同的民族志物品收藏，但他们都有使用当前博物馆信息系统的经验，并负责用来源信息更新物品元数据。这些专家可以被视为本研究开发的数据模型的最终用户。

每位参与者完成了一小时的个人半结构化访谈，所有访谈均遵循相同的访谈指南。访谈指南[24]与本研究的目的一致⁵。访谈涉及文化遗产来源数据的适当表示，涵盖（1）来源研究过程和挑战，（2）研究文献记录，（3）来源信息的表示，以及（4）此类信息的效用。在实际研究之前进行了一次试点访谈，其见解被纳入后续访谈。除试点访谈外，所有访谈均通过网络会议进行。
