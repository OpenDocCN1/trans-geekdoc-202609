为履行对处理个人数据的实体的新义务，欧洲委员会发布了一份文件，确立了其*数据战略*，包括立法使用非个人和公共数据、数字服务和数字市场的活动以及开发*共同欧洲数据空间* [2] 的新法规提案包。在将数据置于此次变革的核心、使其对所有人可用并促进其在各部门之间流动的同时，数据主体和数据持有者的利益将通过制定明确的数据共享政策来保障，以规范数据的用途和访问，并通过可信实体实现共享，同时执行对新法规的合规性。

特别是，欧洲议会和理事会关于欧洲数据治理的法规，即《数据治理法案》（DGA），旨在提高公共数据的可用性，促进对数据中介服务提供商和数据利他主义组织的信任，使其成为数据持有者和数据使用者为公共利益目的进行数据共享的推动者，并设立一个新的超国家机构——欧洲数据创新委员会 [3]，负责监督此类实体的活动。DGA 与拟议的欧洲健康数据空间 [4] 和《数据法案》 [5] 的愿景一起，强调了数据的利他性再利用——在健康数据空间的案例中，旨在解决电子健康数据获取和共享的挑战——这些数据目前被困在欧盟各机构内部，无法供所有人使用。实现这些愿景的关键挑战与以下相关：

- Ch1. *数据集的可用性/发现*：如果不促进和提供技术支持来开发共同数据空间和可信数据共享实体，数据主体和数据持有者将没有自动化工具来共享其数据以供公共利益目的再利用，也没有解决方案来支持他们行使权利，而数据使用者将没有工具来搜索他们所需的数据。

- Ch2. *建立数据使用和访问条件*：如果没有标准和元数据词汇表来表达可互操作、可机器读取的政策，基于不仅是法律而且是伦理、组织和社会规范的个人、非个人和公共部门数据的用途和访问条件的建立，将在提供和寻求数据访问的实体之间引发互操作性问题。

- Ch3. *文档生产*：如果不以结构化格式记录其活动，数据中介服务提供商和数据利他主义组织将依赖手动流程来生成证明其负责任和负责实践的文档。

因此，语义网词汇表，例如 W3C 的数据隐私词汇表（DPV）¹、开放数字权利语言（ODRL）² 或数据目录词汇表（DCAT）³，在这些过程中发挥着重要作用，因为它们是可互操作的并构成通用标准，使机器可读工具能够用于任务自动化。DCAT 和 ODRL 是 W3C 建议，分别用于描述在网络上发布的数据目录 和表达使用规则

DPV is a W3C Community Group Report, which has recently published a stable version 1, aimed at providing a complete, open-access set of taxonomies to express machine-readable metadata about the use and processing of personal data, such as taxonomies for legal entities, purposes, types of processing activities, legal basis, types of data, rights or technical and organisational measures. 为了应对已识别的挑战，我们确定了需要指定*如何*共享数据、*谁*是新的相关利益相关者以及遵守新法律需要*什么*文件的再利用条件。因此，以下研究目标作为本工作的基础提出：
