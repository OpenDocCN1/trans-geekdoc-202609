## 面向历史研究的基于虚拟现实的知识图谱访问

Julia BECKERᵃ Mario BOTSCHᵇ Philipp CIMIANOᵃ,¹ Melanie DERKSENᵇ  
Mohammad Fazleh ELAHIᵃ Angelika MAIERᵃ Marius MAILLEᵃ  
Ingo Oliver PÄTZOLDᵃ Jonas PENNINGROTHᵃ Bettina REGLINᵃ  
Markus ROTHGÄNGERᵃ Silke SCHWANDTᵃ  
ᵃ 比勒费尔德大学  
ᵇ 多特蒙德工业大学

**摘要。目的：** 迄今为止，知识图谱已在文化遗产领域得到大量应用。然而，当前的交互范式和界面往往局限于文本表示或二维可视化，没有考虑到数据的四维特性。尤其是在数字历史领域，事件以及地理和时间关系发挥着重要作用，考虑事件相关数据四维特性的探索范式十分重要，因为它们有可能支持历史学家生成新知识并发现新关系。在本文中，我们探讨了虚拟现实作为一种范式的潜力，使数字人文研究者，尤其是历史学家，得以从自我中心视角探索由知识图谱定义的语义四维空间。**方法：** 我们介绍了 *eTaRDiS*：一种基于虚拟现实、支持知识图谱沉浸式探索的工具。我们在一项任务情境中对该工具进行评估，在该任务中，历史学家和具有历史背景的非专业人士探索DBpedia和Wikidata。我们报告了一项涉及13名受试者的研究结果，这些受试者在特定任务背景下与eTaRDiS中的数据进行交互，以深入了解用户与我们系统的交互模式。我们使用问卷对该工具的可用性进行评估，问卷中除任务特定问题外，还包括系统可用性量表（SUS）中的问题。**发现：** 可用性评估显示，我们的工具总体SUS得分为71.92，对应'满意'评级。具有历史背景的非专业人士的平均得分相当高，为76.0，对应'优秀'评级，而历史学家的得分较低，为69.4，对应'足够到满意'评级。对交互数据的定性分析显示，参与者利用多种策略并借助eTaRDiS提供的功能，迅速识别出任务中的相关信息。**价值：** 据我们所知，eTaRDiS是首个支持知识图谱探索的基于虚拟现实的探索工具。可用性评估结果与探索模式的定性分析表明，该系统有望成为数字人文研究者探索知识图谱的宝贵工具，以发现历史事件与感兴趣人物之间的新关系。

**关键词。** 知识图谱，VR，数字人文，数字历史，关联数据，语义网
