## 为量子应用语义化PlanQK平台与生态系统

Darya MARTYNIUK a, Naouel KARAM a, Michael FALKENTHAL b, Yufan DONG a and Adrian PASCHKE a,c

a 德国柏林弗劳恩霍夫FOKUS数据与分析中心DANA
b 德国柏林Anaqor AG
c 德国柏林自由大学计算机科学研究所

摘要. 量子计算目前正经历快速发展。由于该领域知识的复杂性和持续增长，以能够轻松访问、分析和导航可靠资源的方式存储信息至关重要。具有机器可读语义的知识图谱（KGs）提供了结构化的信息表示，并能增强知识处理和信息检索的能力。在本文中，我们为量子应用平台与生态系统（PlanQK）扩展了一个知识图谱。具体来说，我们描述了研究人员和行业参与者提交到平台上的量子计算知识是如何被纳入图谱的。此外，我们还概述了基于PlanQK知识图谱的语义搜索。

关键词. 知识图谱，本体，语义网，语义搜索，分面搜索，基于本体的搜索，量子计算

### 1. 引言

近年来，量子计算经历了显著增长，导致该领域的知识也相应增加。获取广泛的科学和商业信息，包括出版物、编程代码、软件和硬件文档，无疑对新技术的研究和开发非常有益。然而，这也意味着即使在利用搜索引擎的情况下，在量子计算相关资源中找到相关知识也变得越来越繁琐和耗时。知识图谱（KGs）在增强搜索系统能力、促进更高效的信息检索（IR）方面展现出了巨大潜力[1]。将数据表示为图可以定义形式化语义，并提高集成异构数据源的灵活性[1]，[2]。

在本文中，我们介绍了一种以知识图谱形式组织和整理PlanQK¹上可用信息的方法。PlanQK是一个以量子增强应用为中心的协作平台和生态系统。PlanQK的使命是使关于量子软件和解决方案的研究与工业知识易于获取，并提供部署、托管、执行和货币化量子服务的能力。我们提出了一个对用户提交的数据进行持续语义化的流水线。此外，我们还概述了原生语义搜索和分面语义搜索，它们利用PlanQK知识图谱中已索引的部分来提高相关信息的检索效率。

本文结构如下。在第2节中，我们简要介绍PlanQK知识图谱及其底层本体，并概述平台数据的语义化过程，即将其集成到图谱中。在第3节中，我们描述了基于知识图谱的语义搜索和语义分面搜索的实现。我们在第4节中展望了未来工作并给出结论。

### 2. PlanQK知识图谱

PlanQK知识图谱通过将信息组织为命名节点和表示这些节点之间特定关系的有向边，提供了平台知识的结构化、机器可解释表示²。遵循资源描述框架（RDF）³标准，每个节点和属性都由统一资源标识符（URI）标识。为了查询图谱，我们使用SPARQL[3]查询语言，该语言广泛应用于语义网应用。

*PlanQK本体*[4]通过定义PlanQK平台上下文中的选定计算概念及其之间的关系，充当PlanQK知识图谱的形式化模式。该本体（包括文档和使用示例）对研究社区公开访问⁴。在创建PlanQK本体期间，我们审查了已有的包含相关概念定义的词汇表，并复用了某些本体，例如ML Schema[5]、主题资源应用本体（SRAO）[6]和软件包数据交换（SPDX）许可证列表[7]。图1展示了PlanQK本体的核心概念，即算法、实现、用例、数据池和服务。尽管PlanQK中语义注释的主要焦点在于描述与量子相关的信息，但它也涵盖了与经典计算相关的知识。原因有两个：首先，量子概念通常与经典概念相关，例如量子算法可能受到经典算法思想的启发；其次，由于含噪中等规模量子（NISQ）[8]时代量子设备的若干限制，量子增强应用目前大多以混合方式开发，即同时包含量子和经典部分[9]，[10]。

![](img/5368dd329bd72fa0bf97ac91d6cef632_252_0.png)

图2. 平台数据集成到知识图谱的概览。

PlanQK平台的语义化过程如图2所示。平台前端允许用户创建、修改和删除知识。例如，用户可以创建一个新条目，描述具有特定名称和计算设计（即量子、经典或混合）的算法。用户还可以通过填写各种文本属性（例如缩写、意图和解决方案）来修改条目，并从受控词汇表中选择注释（例如问题类别和应用领域）。一旦数据被提交，平台后端管理将信息插入关系数据库⁵，并触发对云消息服务的请求，该服务将有关数据变更的消息发布到特定频道。为了接收来自频道的通知，知识服务需要有效订阅。如果订阅有效，该服务将获得一条JSON格式的消息。新数据从JSON到RDF的转换由Karma[11]集成工具实现。Karma提供了一种半自动方法来定义映射模型。

⁵ 在PlanQK平台的背景下，决定同时使用关系数据库和知识图谱进行数据存储，是出于安全性和组件解耦的考虑。除了平台的显式内容外，关系数据库还包含有关用户权限的信息。数据存储的解耦有助于促进知识服务在未来扩展到类似平台的生态系统。
