
已经采用深度神经网络和语言生成技术来实现这一目标，通常使用带有注意力机制或变换器的序列到序列（Seq2Seq）架构。这些方法能够生成比抽取式摘要更具表现力且更自然的摘要，而抽取式摘要只是简单地从原始文档中选择句子。例如，See等人[16]提出了指针生成器网络，它结合了生成新词的能力与从输入文本中复制词的能力。这种混合方法能够生成更流畅、更准确的摘要，其在CNN/Daily Mail数据集上的评估结果证明了这一点，该方法的性能优于多个基线。另一个例子是在大规模摘要数据集上微调预训练语言模型，这可以显著改善生成式摘要并生成更高质量的摘要[17]。T5、BART和GPT-2等预训练语言模型在生成摘要的相关性、流畅性和语义准确性方面也取得了出色的性能[18]。受这一成功的启发，我们提出了使用预训练语言模型生成DBPEDIA摘要的生成式摘要的方法。据我们所知，这是首次将语言模型应用于该任务的研究。现有的为DBPEDIA摘要（即短摘要）创建摘要的方法只是从每个实体的描述中选择前几句话。

## 评估LLM生成的摘要

评估大语言模型生成的摘要质量是一项具有挑战性的任务[19]。一种方法是使用人工评估，即请人类专家根据他们对内容的理解和感知对摘要进行评分[20]。例如，Iskender等人[21]在一个德语摘要数据集上，将众包评分与专家评分以及ROUGE、BLEU或BERTScore等自动指标进行了比较。他们发现，在衡量结构和连贯性时，众包可以直接替代专家，但在判断整体质量、语法正确性、清晰度和摘要信息量时，应谨慎使用。

另一方面，研究人员提出了自我评估方法，如BERTScore[22]和Self-ROUGE[23, 24]，用于比较生成摘要相对于原文的质量。具体来说，BERTScore指标通过计算生成摘要与其对应原文的上下文BERT嵌入之间的余弦距离来衡量语义相似度[22]。例如，Koroteev[25]展示了使用语义文本相似度指标来评估俄语生成式摘要的质量。作者认为，语义文本相似度指标是多种自然语言处理（NLP）任务（如机器翻译、信息检索和文本摘要）的有用工具。

由于缺乏DBPEDIA摘要的黄金标准摘要，我们遵循了先前工作[22, 23, 26]使用的评估方法，即采用BERTScore和Self-ROUGE以及众包评估来评估我们实验中生成摘要的质量。我们将在第4.3节中提供关于这些评估指标的更多细节。

### 3.1. 预处理

我们注意到，BART和T5等先进的语言模型是在大规模文本语料库上预训练的，能够处理大小写、停用词和词形变化[27]。因此，在将这些模型应用于文本摘要之前，我们不需要对文本进行小写化、停用词去除以及词干提取或词形还原等预处理。然而，我们需要根据语言模型的特定要求对输入文本进行格式化[8, 28]。

- **分词：** 分词是将文本拆分为更小单元（称为词元）的过程，这些词元可以是字符、子词或词。语言模型要求使用它们自己的分词器对输入文本进行分词，这些分词器能够适当地处理标点符号和特殊字符，并与模型的预处理要求保持兼容。
- **截断和填充：** 为了确保语言模型输入序列的长度统一，需要将长于或短于预定义最大长度的输入文本进行填充或截断。填充过程涉及在较短的序列末尾附加特殊词元（如⟨pad⟩），而截断则需要从较长的序列中移除多余的词元。
- **格式化：** 语言模型需要特定的输入格式来区分不同的任务。对于文本摘要任务，应使用任务提示（例如“summarize”）来指示所需的输出。
