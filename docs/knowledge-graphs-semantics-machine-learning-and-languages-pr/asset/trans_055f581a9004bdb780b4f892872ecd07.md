## 民族志文化遗产对象来源的多声知识建模

Sarah Binta Alam SHOILEE a,1, Victor DE BOER a,2, 和 Jacco VAN OSSENBRUGGEN a,3

a 阿姆斯特丹自由大学，荷兰

ORCiD ID：Sarah Binta Alam Shoilee https://orcid.org/0000-0001-9458-8105, Victor de Boer https://orcid.org/0000-0001-9079-039X, Jacco van Ossenbruggen https://orcid.org/0000-0002-7748-4715

## 摘要.

目的：关于博物馆物品传记（物品来源）的信息通常没有机器可读的格式。这限制了物品来源信息在领域研究中的可发现性和可重用性。我们面临挑战，需要定义一个数据模型来表示民族志文化遗产对象的来源，这包括对对象传记、保管链和获取背景的多种解释（多声性）和理论。方法：为了开发一个表示民族志对象来源的数据模型，我们对五位来源专家进行了（半）结构化访谈，以收集一系列需求。基于这些需求和对六个不同民族志对象来源报告示例的仔细审查，我们建立了一套建模选择，利用现有本体，如CIDOC-CRM（领域标准）和PROV-DM，以及RDF命名图。评估：最后，我们在包含来自三个不同来源的六个已见和五个未见民族志文化遗产对象的来源报告上验证了该模型。这11份报告按照所提出的数据模型转换为RDF三元组。我们还构建了与领域专家提出的九个能力问题相对应的SPARQL查询，以报告可满足性。发现：结果表明，经过调整的组合模型使我们能够表达对象来源信息的异质性和多声性、追踪数据来源，并与其他数据源链接以进一步丰富。价值：本文提出的模型允许以机器可读格式发布此类知识，这将促进信息的情境化、可发现性和可重用性。

关键词：文化遗产，来源信息，多声性，领域建模，知识表示。
