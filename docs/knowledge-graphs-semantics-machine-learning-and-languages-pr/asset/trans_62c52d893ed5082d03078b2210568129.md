## 2.2. 与KGQA系统和基准测试相关的工具

### 2.2.1. 问答系统基准测试：

GERBIL QA [4] 是一个在线问答系统基准测试平台（源自用于评估实体识别方法的GERBIL工具，参见[7]）。GERBIL QA遵循FAIR原则，提供对QA系统的质量评估。该平台允许用户使用相关数据集（如QALD和LC-QuAD）对自己的系统进行基准测试。GERBIL QA还允许用户上传自己的数据集。该平台与相关的KGQA解决方案相连，以便用户将自己的系统与可用的相关系统进行比较；这些系统只有在用户上传的私有数据集使用QALD-JSON格式时才可以使用。GERBIL QA提供七项基准测试指标，并支持在线和基于文件的系统。

### 2.2.2. 问答基准管理工具

QUANT [8] 是一个用于创建或管理QA基准的框架，可为问题-查询对及其元数据生成智能编辑建议，并为查询提供预定义的质量检查。QUANT可将QA基准的管理工作量减少高达91%。QUANT是KGQA数据集开发过程中的合适工具，例如QALD-9就使用了QUANT。

## 3. QALD-9-ES数据集的开发与描述

### 3.1. QALD-9的定性分析

QALD-9数据集包含558个问题，其中408个对应训练数据集，150个对应测试数据集。每个问题都包含一个针对每种可用语言的问题对象列表。一个问题对象由问题字符串和问题关键词组成。问题字符串是以给定语言（例如西班牙语）表达的问题，而问题关键词是问题的关键元素，KGQA系统可以将其作为回答给定语言问题的支持。这些关键词通常与专有实体名称、动词、名词和形容词相关（但不限于此）。

如前所述，QALD-9已经有西班牙语翻译；经过探索性审查，我们得出结论：这些西班牙语翻译的质量存疑。因此，我们决定审查所有原始翻译，并将每个翻译分为七种情况。

情况1至6对应错误情况，可细分为问题字符串有误的情况（情况1、2、5和6），或问题关键词有误的情况（情况3、4），而情况7表示翻译正确。

每个问题可以被归入多个情况，唯一例外是情况7。如果一个问题属于情况7，则意味着翻译正确；因此，它不能归入问题字符串有翻译错误的情况，但可以归入问题关键词有错误的情况。

- 1. 第一种情况涉及我们所说的“轻微翻译错误”，我们将其定义为不会改变问题原始含义的翻译错误。这种情况下的常见错误包括：使用错误的性（例如，对阴性名词或主语使用“hermoso”）、遗漏不影响问题含义的词语、缺少开闭问号（‘¿?’）、缺少字母、复数形式使用不当、专有名称首字母未大写或使用错误的时态。这些问题的一个例子可以在问题“Who developed Skype?”中找到，它被翻译为“Quien desarrollado Skype?”；动词“desarrollado”是过去分词形式。要使其成为正确的翻译，助动词“ha”应该伴随主动词，从而得到翻译“¿Quién ha desarrollado Skype?”。另一个正确的替代方案是将主动词改为一般过去时，得到“¿Quién desarrolló Skype?”。

- 2. 第二种情况涉及我们所说的“重大翻译错误”，这些错误的主要特征是导致问题中具有意义的元素丢失，如动词、专有名称和其他有意义的词语。这种情况的一个例子可在问题“In which U.S. state is Area 51 located?”中找到，它被翻译为“En cual Nosotros estado es Zona 51 ¿situado?”。如果我们反向翻译，会得到“In which us state is Zone 51 located?”。如您所见，实体“U.S.”被错误翻译为“us”，而实体“Area 51”被转换为“Zone 51”。这两种情况下，问题中的实体都丢失了，这意味着KGQA系统无法正确处理此翻译。另一个例子可在问题“Where did Abraham Lincoln die?”中找到，它被翻译为“Dónde hizo Abraham Lincoln el?”。在这个翻译中，动词“die”完全丢失，导致问题毫无意义。在原始QALD-9翻译中，我们发现有些问题缺少对应的西班牙语翻译。这些问题被归入此类。这种情况可能由问题及问题关键词中的错误引发。

- 3. 第三种情况涉及这样的问题：由于问题原始翻译中的某些错误传播到问题关键词中，导致问题关键词需要修改。我们可以在问题“What is the last work of Dan Brown?”中找到这种情况，它被翻译为“Qué es el último trabajo de Y Marrón?”。在这种情况下，实体Dan Brown被错误翻译为“Y ¿Marrón?”，导致错误传播到问题关键词“último trabajo, Y marrón”。这个问题的正确关键词是“último trabajo, Dan Brown”。

- 4. 第四种情况与第三种情况类似；不同之处在于，问题关键词中发现的错误与问题翻译中的错误无关。例如，单词在问题翻译中正确书写，但在问题关键词中书写错误。在问题“Which monarchs were married to a German?”中，我们发现该问题的西班牙语关键词是“monarcha, casado, alemán”。单词“monarcha”被错误翻译；正确翻译是“monarca”。这个误译只在问题关键词中发现；翻译本身没有这个错误。

- 5. 第五种情况是关于西班牙语的重音符号。在西班牙语中，字符“´”被称为“正字法重音”。这个重音用于某些单词的元音上，可以改变单词的含义。一个例子是“mas”和“más”。“mas”相当于“but”，而“más”是数量副词。一些QALD-9翻译缺少正字法重音，导致某些单词的真实含义丢失。这种情况可能由问题及问题关键词中的错误引发。

- 6. 第六种情况包括翻译正确但为了更自然而被重新表述的问题。对问题关键词的修改不会触发这种情况。问题“How deep is Lake Placid?”被翻译为“Cómo de hondo es el Lago Placid?”，这在技术上是一个正确的翻译，但我们认为直译“Cómo de hondo”不是表达“How deep”的最佳方式；因此，我们将翻译修改为“¿Qué tan profundo es el Lago Placid?”。

- 7. 最后，第七种情况涉及不需要修改的问题。对问题关键词的修改不影响这种情况。问题“Which presidents were born in 1945?”被翻译为“¿Qué presidentes nacieron en 1945?”。我们认为这个翻译正确且自然；因此，我们将其归类为情况7。
