所识别的实体可分为数据持有者、数据主体、数据用户、数据中介服务提供者（或数据中介机构）、数据利他组织、法律代表、国家或主管机构、单一信息点提供者、公共部门机构或主管机构。包括即将成立的欧洲数据创新委员会和欧盟委员会在内的信息流也显示在图1中。其定义如下：

- **数据主体** 其个人数据被处理的个人
- **数据持有者** 有权授予访问或共享某些个人数据或非个人数据的实体
- **数据用户** 有权将个人或非个人数据用于商业或非商业目的的实体
- **数据中介服务提供者** 一方面在数据主体和数据持有者与另一方面数据用户之间建立数据共享商业关系的实体
- **数据利他组织** 为利他目的收集和共享数据的非营利组织
- **公共部门机构** 由一个或多个国家、地区或地方当局组成的受公法管辖的实体或实体协会
- **法律代表** 被指定代表数据中介服务提供者或利他组织行事的法人实体代表
- **主管机构** 由公共部门机构指定，为公共部门数据的访问和再利用提供法律和技术支持的实体
- **单一信息点提供者** 负责接收和传输公共数据再利用请求的实体
- **主管当局** 负责监督数据中介服务提供者和数据利他组织活动，并维护上述实体公共登记册的机构
- **欧洲数据创新委员会** 负责监督数据中介机构和数据利他组织活动的机构

例如，数据中介机构与数据用户共享开放或商业许可下的数据访问条件（图1中以红色箭头表示的信息流），并保留其活动记录（图1中以(K)箭头表示的信息流）。该图源自对DGA第二章（“公共部门机构持有的某些类别受保护数据的再利用”）、第三章（“适用于数据中介服务的要求”）、第四章（“数据利他”）和第六章（“欧洲数据创新委员会”）的分析。对这些章节中的每一条进行了人工研究，以寻找已识别实体之间的交互，当发现多个实体之间存在信息流时，相应的交互被记录在图中。此外，与合规文档编制相关的要求也记录在图中，因为这些要求需要记录信息，而这些信息可以通过语义技术的使用实现自动化。

在接下来的三个小节中，我们重点关注与公共数据再利用条件（第2.1小节）、利他和中介活动登记册的维护（第2.2小节）以及数据利他活动（第2.3小节）相关的信息流，在这些领域，语义技术的使用最能帮助相关实体自动完成其与信息流相关的任务。对于每个示例用例，都针对每个已识别的信息流手动进行了涉及信息流及需要交换的相应信息条目的系统性研究，并在以下小节中进行了系统化整理。
