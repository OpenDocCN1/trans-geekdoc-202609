

## 算法 1 DiscoverLinksAreaBased(Gₛ, Gₜ, r)
```
1: Input: Source KG Gₛ, Target KG Gₜ, Topological relation r
2: Output: Mapping : M = {(s,r,t) | s ∈ Gₛ, t ∈ Gₜ}
3: tree ← buildRtree(Gₛ)
4: Initialise M ← {}
5: for each MBB(t) t ∈ Gₜ do
6:   I ← queryRtree(tree, t)
7:   if r is disjoint then
8:     Add all pairs(s,r,t) ∀ s ∈ (Gₛ \ I) to M
9:   end if
10: for each MBB(s) s ∈ I do
11:   X ← Fₐ(MBB(s),MBB(t))
12:   Y ← Fₐ(MBB(t),MBB(s))
13:   Z ← X + Y
14:   if X,Y,Z match the respective values of the relation r in Table 1 then
15:     Add (s,r,t) to M
16:   end if
17: end for
18: end for
19: return M
```

## 算法 2 MatchTrees(sourceTree, targetTree)
```
1: Result ← {}
2: if area(sourceTree) < area(targetTree) then
3:   swap sourceTree and targetTree
4: end if
5: for each child of sourceTree do
6:   if child is leaf then
7:     Result = Result ∪ queryRtree(targetTree, MBB(child))
8:   else
9:     Result = Result ∪ MatchTrees(child, targetTree)
10:  end if
11: end for
12: return Result
```

## 为两个数据集建立索引

在许多情况下，交换源数据集和目标数据集会导致不同的运行时间。为了减少数据集顺序对运行时间的影响，我们研究了同时为两个数据集建立索引而不是仅为一个数据集建立索引的可能性。我们不再为每个目标几何体查询 R-tree，而是使用算法 2 将两个 R-tree 相互匹配，并递归地查找所有相交的配对。这种方法消除了选择对哪个数据集进行索引的需要，但代价是增加了我们方法的内存占用，因为我们必须将两个数据集都保存在内存中。

我们将原始多边形分割成大小相等的部分。得到的多边形部分是原始多边形上的网格模式与原始多边形本身的交集。在某些情况下，这会导致一些分割无法获得任何额外信息，因为它们在网格中的部分为空。例如，在图 **3a** 中，对左上角单元格（蓝色高亮单元格）的任何进一步分割都不会提高 **CoBALT** 的准确性，因为原始多边形在该单元格内没有任何点。

**2) 拟合分割**，即我们使用当前多边形部分的 MBB 进行进一步分割，将多边形分成大小相等的部分。使用该策略对上一示例中同一多边形的左上角单元格进行分割，将得到图 **3b** 所示的分割结果，其中对蓝色高亮单元格的进一步分割会产生更精细、更贴合多边形形状的分割。

分割多边形后，我们计算所有部分的 MBB。现在由于我们有多个多边形部分，我们改变了确定原始多边形关系的方式。设 *t* 为分割成四部分的次数。设 $A_{(i,j)}$ 为几何体 *A* 在第 *i* 列第 *j* 行的分割部分，$B_{(k,l)}$ 为几何体 *B* 在第 *k* 列第 *l* 行的分割部分，其中 $\{(i,j,k,l) \in \mathbb{N}^{4} \mid 0 \leq i,j,k,l < 2^{t}\}$。新定义的关系可在表 2 中找到。具体来说，为了使等于关系成立，每个网格模式 $A_{(i,j)}$ 必须等于 $B_{(k,l)}$。对于相交关系，至少一个 $A_{(i,j)}$ 必须与至少一个 $B_{(k,l)}$ 相交。对于包含于关系，所有 $A_{(i,j)}$ 都必须包含于与其相交的所有 $B_{(k,l)}$ 的并集的 MBB 中。对于包含关系，我们交换 *A* 和 *B*，然后改而计算我们的关系。对于重叠关系，必须满足以下三个条件：1) 至少一个 $A_{(i,j)}$ 不在 *B* 内；2) 至少一个 $B_{(k,l)}$ 不在 *A* 内；3) 至少一个 $A_{(i,j)}$ 与至少一个 $B_{(k,l)}$ 相交。对于接触关系，至少一个 $A_{(i,j)}$ 必须接触某个 $B_{(k,l)}$，并且每个 $A_{(i,j)}$ 与每个 $B_{(k,l)}$ 要么是接触关系，要么是相离关系。

### 硬件与软件

所有实验均在 *帕德博恩大学* 的 *Noctua*⁵ 集群上进行。Noctua 由 256 个计算节点组成，每个节点配备两个 Intel Xeon Gold "Skylake" 6148 处理器，共 40 核，主频 2.4 GHz，主存 192 GiB。所有使用的算法均用 *Java* 实现，计算节点运行 *OpenJDK* 11.0.2。为了准确测量运行时间，所有实验都是在所有数据集已加载到主存后开始的。此外，为了链接每一对数据集，我们在同一计算节点上运行算法。所有实验均在 30 GB 的内存限制下进行。除非另有说明，所有实验都只使用一个核。
