## COBALT：一种基于内容的相似度方法，用于地理空间知识图谱上的链接发现

Alexander BECKER a、Abdullah AHMED a 和 Mohamed Ahmed SHERIF a
Axel-Cyrille NGONGA NGOMO a

a DICE研究组，帕德博恩大学计算机科学系
ORCiD编号：Alexander Becker https://orcid.org/0009-0000-8212-4647, Abdullah Ahmed https://orcid.org/0000-0002-0668-0735, Mohamed Ahmed Sherif https://orcid.org/0000-0002-9927-2203, Axel-Cyrille Ngonga Ngomo https://orcid.org/0000-0001-7112-3516

摘要。目的：知识图谱（KG）之间的数据集成和应用在很大程度上依赖于发现这些KG中资源之间的链接。地理空间链接发现算法必须处理包含数十亿点的数百万个点集。方法：为了加速地理空间链接的发现，我们提出了COBALT。COBALT将内容度量与R树索引相结合。内容度量基于多边形最小边界框的面积、对角线和距离，这加快了处理速度，但并非完全准确。因此，我们提出了两种多边形分割方法来提高COBALT的准确性。结果：我们在真实世界数据集上的实验表明，与最先进的链接算法相比，COBALT能够将地理空间KG上的拓扑关系发现速度提升高达1.47 × 10⁴倍，同时根据具体关系保持F值在0.7到0.9之间。此外，通过在应用内容度量之前应用我们的多边形分割方法，我们能够实现高达0.99的F值。价值：通过牺牲结果的最优性，地理空间资源之间链接发现的过程可以显著加快。这对于实时数据驱动应用（如应急响应、基于位置的服务和交通管理）尤其重要。在未来的工作中，可以集成其他度量，例如多边形的位置或由多边形表示的实体的名称，以进一步提高结果的准确性。

关键词。知识图谱，数据集成，关联数据，地理空间知识图谱，内容度量相似性，拓扑关系

### 1. 引言

由于关联地理空间数据的快速增长，对高度可扩展的地理空间资源链接发现方法的需求已经出现。正如早期文献[1]所指出的，资源之间的关系中只有7.1%涉及地理要素。这有两个基本原因：1）关联开放数据（LOD）中大量以地理空间表示的资源需要可扩展的技术来计算地理空间资源之间的链接。例如，LINKEDGEODATA [2]拥有超过200亿条三元组，描述了数百万个地理事物。2）某些关系（如地理空间资源之间的距离和拓扑链接）的计算必须处理地理空间数据的矢量表示。例如，用于识别给定半径内的附近兴趣点。

根据关联数据原则[3]，在RDF中发现知识图谱（KG）之间的链接对于许多数据驱动应用至关重要。如今，处理地理空间资源是许多实时应用[4]（如应急响应、基于位置的服务和实时交通管理）的基础。然而，为了支持实时决策，在这种实时地理空间KG中生成链接是一项具有挑战性的任务。因此，链接发现过程的效率和可扩展性变得更具挑战性。

最近，已经开发了诸如RADON [5]、RADON2 [6]、GIA.NT [7]和DORIC [8]等算法。这些算法可以快速有效地计算地理资源之间的拓扑关系。这些都使用了维度扩展九交集模型（DE-9IM）[9]。DE-9IM通过计算两个几何体的内部、边界和外部之间交集的维度来定义二维几何体之间的拓扑关系。DE-9IM定义的关系是自然语言[10]中常用的关系：相等（Equals）、不相交（Disjoint）、相交（Intersects）、接触（Touches）、穿越（Crosses）、在内部（Within）、包含（Contains）、重叠（Overlaps）、覆盖（Covers）和被覆盖（Covered By）。为了加速地理空间关系的计算，Ahmed等人[11]研究了简化资源几何对链接发现方法运行时间和F值的影响。然而，计算DE-9IM在运行时间方面仍然非常昂贵。

在本文中，我们提出了COBALT，一种基于内容度量结合R树索引的方法，用于发现[9]和[10]中定义的拓扑关系。据我们所知，这是第一个将基于内容的度量与R树索引集成用于发现RDF地理空间资源之间链接的工作。我们的贡献总结如下：

- 1. 我们提出并形式化了基于内容度量和R树索引的地理空间资源拓扑关系发现问题。
- 2. 我们研究了使用不同R树构建算法、节点容量以及同时对两个数据集进行索引的影响。
- 3. 我们研究了使用基于内容的度量进行拓扑关系发现在运行时间和准确性两方面的影响。
- 4. 为了提高我们方法的准确性，我们提出了两种多边形分割策略，并分析了它们对运行时间和准确性的影响。

本文的其余部分组织结构如下。我们首先在第2节介绍RDF KG上的链接发现问题，并在那里基于内容度量正式定义拓扑关系。然后，我们在第3节描述我们的方法。在第4节中，我们展示我们的评估和结果。然后，我们在第5节讨论最先进的相关工作。最后，我们在第6节总结论文并提出一些未来工作。我们的COBALT实现是开源的，并已集成到LIMES框架中。¹
