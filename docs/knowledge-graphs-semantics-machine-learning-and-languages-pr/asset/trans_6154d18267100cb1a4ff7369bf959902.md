我们本体的特殊性在于对LOM描述的扩展，以考虑学习对象中涉及的主题及其相关度分数。为此，我们使用RDF语句级具体化。具体化允许以一种通用的方式对语句进行陈述。对我们而言，它允许说明一个教育资源（ER）*在某种程度上*涉及某个特定主题（在我们的案例中是一个DBpedia资源）。具体来说，它允许在事实（unr:EducationalResource, dct:subject, dbr:Resource）中为属性dct:subject附加相关度分数。这些分数由维基化过程确定，该过程识别出属于[0..1]范围的PageRank值和余弦相似度值。有关该过程的更多信息将在下一节中提供。

除了被具体化之外，dct:subject还是一个多值属性，即一个主语-谓词对可以拥有多个宾语。这些宾语是DBpedia资源，它们是DBpedia、Wikidata和Yago本体中类的实例。我们还考虑DBpedia类别，这些类别在维基百科中用于按主题组织文章和页面。由于我们的知识图谱（KG）的目标是根据主题识别教育资源，DBpedia类别至关重要。DBpedia资源通过dct:subject属性与其类别关联（dbr:Resource, dct:subject, dbr:Category）。

### 2.2. 教育资源的维基化

将命名实体映射到维基百科实体的实体链接技术称为维基化。文本维基化是指自动提取文档中最重要词语和短语，并为每个此类关键词确定到维基百科文章的适当链接的任务[1]。维基化过程通常涉及两个阶段：术语提取和链接消歧。

维基化有多种方法，它们在提取短语并将其链接到外部资源所使用的技术上有所不同。名为*Wikifier*的维基化工具与一些最先进的方法相比表现出良好的性能[2][4]。该工具识别*提及*——从输入文档中提取的短语——并将它们用作维基百科页面之间的超链接。某个提及所链接的维基百科页面被视为该提及的候选概念。Wikifier构建一个由提及及其对应候选概念组成的二部图。然后利用维基百科页面之间超链接的内部结构对边进行加权
