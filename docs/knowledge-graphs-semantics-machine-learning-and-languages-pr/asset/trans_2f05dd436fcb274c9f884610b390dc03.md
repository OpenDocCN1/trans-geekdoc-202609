## 来源研究：
访谈结果表明，来源研究没有标准目标。然而，所有受访者都同意，这有助于更好地了解藏品和物件的来源，从而实现藏品记录的完善。受访者在开展研究的方法上各不相同，对档案馆、图书馆和网络搜索等来源的依赖程度也各有差异。然而，所有受访者都从博物馆的藏品管理系统（CMS）⁶ 开始其研究。值得注意的是，有两人提到该系统经常包含缺失信息和观察偏差。受访者还表示，目前没有关于如何表述来源信息的指南。通常，当信息超出 CMS 范围时，会撰写一份单独的报告。然而，除了非结构化文本报告外，系统中没有有效的方式来追踪或查找此类信息。

## 当前表述存在的问题：
参与者一致认为，由于信息错误、不完整或不可靠，CMS 中的当前信息表述存在问题。档案材料的数字化不足（R5）和信息可用材料的分散化（R3）被认为是主要挑战。CMS 中来源的当前表述与来源研究的复杂性不匹配（R4），并且人与人、地点、物件和事件之间的重要关系无法以机器可读的方式表示（R3）。所有受访者都指出的另一个问题是，当前管理系统不包含任何数据来源信息，使得难以追溯先前关于某件物件所作陈述的来源。

## 对文化遗产数据多视角表述的意见：
受访者一致认为，在物件来源信息中保留细微差别很重要，因为时代和视角的变化会导致信息感知方式的改变。博物馆数据库记录可能受到其时代主导视角的影响，例如殖民表述和语言使用，这些可能与当前观点不一致（R2, R4）。承认物件过去被如何看待，可以告诉我们关于藏品的一些信息（R4）。如果存在多种来源版本，都应予以表述，因为来源很少能完全得到证实（R5）。另一方面，一些受访者（R1, R3）认为，保留所有信息并不实际，这取决于研究目标。另一位受访者（R2）指出，区分现在认为更正确的信息与先前研究之间的重要性。他们还一致认为，他们的研究只是对物件历史的一种解读；不可能说他们研究是物件历史的最终解读。

## 3.3. 已识别需求与能力问题
领域专家报告的表述总体需求如下列出，分为三类：总体表述、物件来源（与物件保管链相关的被确定为重要信息）以及数据来源（关于文化遗产来源陈述，例如研究过程中使用的来源）。

### 总体表述
领域专家报告称：

- *数字表述*：如果文化遗产数据以数字形式可用，则来源研究更容易开展。
- *以事件为中心表述*：当以事件为中心的方式表述时，更容易识别行为者、物件和地点之间的关系。
- *机器可读*：与仅以书面报告形式呈现来源研究相比，机器可读的表述更容易访问。

### 物件来源
- *物件数据*：物件标题、物件编号、物件类别、材质、所属藏品及其来源的表述。
- *物件创建*：物件何时、何地、由谁创建。
- *行为者*：参与物件收集的行为者网络。
- *地点*：物件获取和创建地点以及旅行路线。
- *事件和时间段*：历史事件或时间段，可能提供背景，包括殖民物件的不道德获取。
- *多重描述*：如果对一次获取存在多种观点，应予以记录以保留细微差别。
- *注释*：事件可能需要自然语言中的详细注释和说明。

### 数据来源
- *来源陈述来源*：用户应能够审查来源陈述的来源/作者。
- *来源*：用户应能够找到物件来源的来源材料。
- *对先前研究的追溯性*：物件来源研究的每个版本都应包含数据来源信息。

### 3.3.1. 能力问题
能力问题（CQs）是用自然语言提出的问题，概述知识并指定知识表述的约束条件 [25]。在访谈期间解释了能力问题的概念，并要求受访者根据自身需求提出具体问题。随后在本研究中对这些单独的 CQs 进行了汇总。所有参与者一致认为，追踪参与物件获取的 *人员*（收藏家、交易商……）至关重要，以便识别参与物件获取的个人网络（**CQ1**、**CQ2**、**CQ3**）。传达关于 *日期和事件* 的信息也很重要；例如，物件获得的日期或场合（**CQ4**）。这使得能够通过历史事件识别相关物件的网络，这些事件可能共同影响物件的获取（**CQ5**）。*地理位置* 对于确定哪些物品在特定地区或国家被买卖很重要（**CQ6**）。受访者还将 *数据来源* 识别为其能力问题中的关键部分。参与者一致同意，关于物件来源的每个主张都必须有文档记录以追踪先前研究（**CQ7**、**CQ8** 和 **CQ9**）。他们还提到需要重新审视早期的来源版本，以获得所有先前研究的完整图景。上文汇总的能力问题的完整列表显示在表 2 的前两列中。在第 5.2 节中，我们描述了这些问题如何用于验证目的。
