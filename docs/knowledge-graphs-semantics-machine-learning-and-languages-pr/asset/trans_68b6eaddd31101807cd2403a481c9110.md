
## 3.2.1. Hub

Hub 在 eTaRDiS 的虚拟环境中充当中央据点，用户可在其中编辑语言、键盘输入类型等基本设置。此外，Hub 也是虚拟数据探索的起点。合适的界面使用户能够过滤数据，以创建针对个人（研究）兴趣量身定制的子数据集（见图 1），随后可在下一个房间 Fragmentarium 中进行可视化和探索。

为了让用户对所选数据有一个概览，关于过滤后子数据集的信息会动态显示在仪表板上，以便用户根据个人兴趣过滤数据集。除了显示所创建子数据集中节点（片段）的总数外，还会显示时空信息。整个子数据集的统计信息会显示，并且各个片段的空间分布会在世界地图上变得可见。基于这些信息，可以对所选过滤器做出初步考虑。

除了过滤功能外，Hub 界面还允许加载已保存的点和预设。已保存的点使用户能够在稍后时间继续会话，从而在 Fragmentarium 中从同一位置开始；而预设可用于保存和加载定义的过滤器。预设也可以稍后编辑。

## 3.2.2. Fragmentarium

Fragmentarium 是允许用户探索在 Hub 中选定的知识图谱中节点的邻域的界面。可视化由一个历史主片段和相关片段组成。用户站在表示为彩色圆形平台的主片段上，因此旨在从沉浸式的自我中心视角探索场景。相关片段以带标签的彩色球体表示，环绕用户（见图 2）。颜色表示片段的类别（例如，agent、event），球体的大小与对应 DBpedia 文章中可用的来源数量相关（即 `dbo:wikiPageExternalLinks`）。

对于相关片段的排列，使用了两种距离度量。第一种用于将球体放置在用户周围的球面上，使得相似度低的片段彼此靠近。第二种根据其与主片段的差异性确定它们各自与中心的距离。中心以及与用户的最小和最大距离分别为 1.7 m 和 3 m。高差异性最多会导致与中心相距 3 m。

为了将球体放置在球面上，我们依赖 UMAP 算法 [27]，这是一种降维技术。以相关片段之间的差异性计算作为其输入度量，以 haversine 作为其输出度量，UMAP 可找到相关片段围绕用户的合适排列。为了防止颈部不适，在我们的案例中，UMAP 算法在其优化过程中额外获得两个固定在极点上并不断排斥所有其他数据点的虚拟点，从而避免球体直接在用户上方或下方累积的构型。

我们依赖四个属性来计算差异性：i) 时间 (t)、ii) 空间 (s)、iii) 语义 (sem) 和 iv) 分类 (c)。用户可以通过排列相对于这些不同差异性最近的其他节点来定义要探索的邻域。我们首先为每个上述属性计算相关片段在一可视化中的成对距离，然后按属性 a 将其缩放到 0（表示相似）到 1（表示最大差异）的区间，以获得每个单独属性的归一化差异性度量。如果片段 n ∈ F 的某个属性值 a_n 没有可用数据，则该值被视为无效。更正式地，对于具有相关片段集 F 的可视化，两个片段 i、j ∈ F 关于一个属性 a ∈ {t, s, sem, c} 的差异性 diss，其中 a_i、a_j 为其对应的属性值，定义为：

diss_a(i, j) = { (dist_a(i,j) - min_{k,l} dist_a(k,l)) / (max_{m,o} dist_a(m,o) - min_{k,l} dist_a(k,l)), with k,l,m,o ∈ F, k ≠ l if a_i, a_j are valid, 0 if a_i, a_j are invalid, 1 otherwise. }

请注意，两个相关片段在缩放过程后可能具有不同的差异性值。这是因为两个片段可能在不同的主片段下同时出现，而这些主片段可能具有不同的相关片段集，不同的最小和最大距离，从而可能导致不同的缩放。我们在下面描述不同距离的计算方式：

### Temporal distance:

对于两个片段之间的时间距离 dist_t，考虑其时间段 t_i 和 t_j 的最小分离间隔。如果提供了不重叠的时间段，则考虑天数的差异。如果其时间段重叠，或两个片段均未给出时间段，则其距离为 0。

形式上，片段的时间段 t_i 是一个区间 [t_i,start; t_i,end]，从开始日期 t_i,start 开始，到结束日期 t_i,end 结束，其中每个日期均以天为单位表示（从公元纪元到与片段相关联的对应日期所经过的天数）。两个时间段 t_i 和 t_j 重叠，如果它们的交集非空：t_i ∩ t_j ≠ ∅。它们的天数时间距离 dist_t(i, j) 可计算如下：

dist_t(i, j) = { min{||t_i,start - t_j,end||, ||t_j,start - t_i,end||} if t_i ∩ t_j = ∅, 0 otherwise. }

### Spatial distance:

两个片段之间的空间距离 dist_s 定义为对应位置的最短距离。由于位置以经纬度对 (φ, θ) 表示，两个位置 (φ_i, θ_i) 和 (φ_j, θ_j) 之间的距离 dist_s 可通过大圆距离计算，其中地球半径 r_earth ≈ 6371,009 km：

dist_s(i, j) = r_earth arccos( sin(θ_i) sin(θ_j) + cos(θ_i) cos(θ_j) cos(φ_i − φ_j) ).

### Semantic distance:

我们使用 Clark 等人 [28] 提出的 Sentence Mover’s Distance，这是一种用于多句文本的评估方法。作为句子向量，我们使用基于预训练模型 ‘all-MiniLM-L12-v2’⁴ 的微调 sBERT 模型 [29]。我们将 Sentence Mover’s Distance 应用于作为实体文本描述的摘要，并在距离计算中使用统一的句子权重。

### Categorical distance:

分类距离按定义是一种差异性，如果两个片段不共享同一类别则估计为 1。否则设为 0。给定两个片段的类别 c_i 和 c_j，分类距离 dist_c 计算为：

dist_c(i, j) = { 1 if c_i ≠ c_j, 0 otherwise. }

用户可根据要排列数据的差异性进行选择。在我们的场景中，作为 UMAP 算法输入度量的距离度量考虑了相关片段之间类别的差异性值，而第二个度量则使用相关片段与主片段之间的语义差异性。因此，共享同一类别的相关片段在用户周围形成簇，而与主片段语义差异性高的相关片段在空间上远离中心。因此，可视化能够一目了然地提供关于主片段与其对应相关片段之间关系以及相关片段之间相互关系的线索。
