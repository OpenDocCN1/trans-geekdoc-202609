## 对习语感到困惑？

J. Nathanael PHILIPPᵃ,ᵇ,¹, Max KÖLBLᶜ, Erik DAASᵇ, Yuki KYOGOKUᵇ 和 Michael RICHTERᵇ

ᵃ 塞尔布斯基研究所  
ᵇ 莱比锡大学  
ᶜ 大阪大学

ORCID 标识符：J. Nathanael Philipp https://orcid.org/0000-0003-0577-7831，Max Kölbl https://orcid.org/0000-0001-7460-4139，Erik Daas https://orcid.org/0009-0007-0879-0878，Michael Richter https://orcid.org/0000-0001-7460-4139

¹ 通讯作者：J. Nathanael Philipp，nathanael@philipp.land。

**摘要。** 本研究旨在使用*困惑度*这一度量来识别英语中的习语表达。假设是，在给定参考文本的情况下，习语表达比字面表达引起更高的困惑度。我们研究中的困惑度是基于句子边界内的 (i) 词性标注、(ii) 词元 和 (iii) 主题角色的 n-元语法计算的。在我们的研究设置中，我们观察到在 (i)、(ii) 和 (iii) 情境下的困惑度都无法区分习语表达和字面表达。我们假定，在确定困惑度时应使用更大的、句子之外的上下文。此外，为了减少 n-元语法的均匀分布，(iii) 中的主题角色数量应缩减为更少的基础角色数量。

**关键词。** 困惑度，习语表达，字面表达，信息论

### 1. 引言

习语表达，或称短语学（以下简称为**习语**），如动名复合词（**VNC**）*翘辫子、闹翻天、告密、睡觉* 或 *丢脸*，在英语中无处不在。本研究旨在利用信息论框架 [1] 自动识别英语文本中的习语。

与非习语表达相比，习语远不遵循组合原则 [2,3]，因为在大多数情况下，表达的意义不能直接从其组成部分的意义推导出来。习语的解释不是还原论的。因此，要理解习语的意义，例如在句子*我们家的事已经闹翻天了*中，仅知道*屎*、*打* 和 *风扇*的意义是不够的。理解习语涉及语言的规约性，因为其意义是通过特定的语言使用和约定演化而来的。[2] 强调 *[习语的意义涉及例如隐喻和夸张*，而习语构成部分的意义被否决了。习语是稳定的语言结构，大多具有特定句法，如 *丢脸* 或 *告密*，这一特征被称为 *(不)灵活性* [2,3]。这一特征也意味着习语的不透性，即语法转换、提取和插入会导致不合语法，如 (1) 中的句子所示。('*' 表示不合语法)：

- (1)a * 我们家的风扇被屎打了。（被动转换：宾语变成语法主语）
- b * 是风扇被屎打了。（分裂句）
- c * 屎打了我们家那个破风扇。（插入）

在本研究中，我们探讨是否有可能通过困惑度的散度度量来区分习语和字面表达，困惑度与信息论中的惊异度特征密切相关 [4,5,6,7]。因此，我们想知道，在给定参考数据集的情况下，习语是否比字面表达引起更高的困惑度。困惑度的数量在等式 1 和 2 中做了精确定义，它表示惊异度的数量，惊异度是情境化的信息，应当被解释为与预期的偏差。一个语言单位的惊异度越高，因此它引起的困惑度越高，处理它所需的认知努力就越大 [5,7]，这是一个经验上已被证实的论断（另见 [8,9]）。

在我们的研究中，我们测量习语和字面表达相对于参考文本的散度，并假设这些散度应该不同。在研究数据集（见第 3 节）中，VNC 既可以按字面理解，也可以作为习语理解。

我们将困惑度定义为两类数据集中语言模式的 n-元语法概率之间的散度，一方面是一个包含习语的数据集和另一个不包含习语的数据集，另一方面是两个大型参考数据集。

处理习语识别有什么实际意义？虽然一些最先进的翻译程序和聊天机器人能够识别习语并提供正确的翻译和解释，但另一些却不能。例如，谷歌翻译将“昨天我们家的事闹翻了天”翻译成德语“gestern hat die Scheiße den Lüfter unseres Hauses getroffen”，这字面上正确，但完全讲不通。DeepL 和特别是 OpenAI/ChatGPT 在这方面做得好得多。然而，后者在解释德语习语“nicht auf den Kopf gefallen sein”时表现出些许弱点，该习语意为聪明。我们与 Open AI 的 ChatGPT 进行了一次对话。

问题：我们不是摔到头上。这是什么意思？字面意思：“我们没有摔到头上。那是什么意思？”

回答：这个表达的意思是，一个人聪明机智，不愚蠢。他能够做出明智的决定，并且不容易被愚弄。“这个表达意味着一个人聪明机智，不愚蠢。他能够做出明智的决定，并且不容易被愚弄。”

这是一个非常好的回答，聊天机器人识别出了习语并解释得很好。现在考虑以下对话：

问题：我们不是从自行车上摔到头上。这是什么意思？“我们没有从自行车上摔到头上。那是什么意思？”
