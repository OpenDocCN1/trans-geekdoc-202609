## 5. 讨论与结论

在我们的研究中，IE 无法通过任何类型的困惑度来识别。观察到基于 PoS 标签的语法惊奇度的困惑度失效是合理的，因为语料库中的所有 IE 都是动词-名词复合词 VNC。它们在结构上对应于字面表达的 VNC。我们可以将语法惊奇度的困惑度解释为基线，而且这还表明困惑度是我们目标的合适度量：当困惑度基于语法结构时，IE 和字面表达中的 VNC 不应表现出很大差异。这正是我们观察到的结果。然而，词法惊奇度也没有困惑度，这并非我们所期望的。也就是说，词元的 n-gram 并未为语言处理器提供区分 IE 与字面表达的线索。这实际上是一个语义区分。该发现令人惊讶，因为在常见且有影响力的分布语言模型 [25] 中，假设语言单位的含义在其上下文中表示。典型地，该模型中的上下文意味着语言单位在预定义上下文窗口中的共现。相似的上下文表示语言单位具有相似的含义，而不同的上下文表示不同的含义。我们将本研究中词元 n-gram 的问题归因于上下文大小过小。二元到四元 n-gram 的上下文无法表示更大的会话上下文，更不用说语篇了。所以，例如，如果单词 ganache，即一种柔软的巧克力馅料，出现在比如量子力学的会话上下文中，据推测，无法从二元上下文中推导出 ganache 在这种特殊上下文中引起的高度惊奇度 / 困惑度。语义惊奇度也出现同样的效应，因为句子边界内的主题角色 n-gram 并不会使 IE 的困惑度高于字面表达。

限制在句子边界内的局部上下文是由于我们的数据基础，因为这里字面表达和习语是以孤立的句子表示的。然而，这是一个关键的不足，因为 Levy 的惊奇度定义 [7] 提供了跨句上下文。根据该定义，惊奇度是基于共现的预期偏差，也是基于更大上下文的偏差，该上下文可以是语篇、整个语料库或段落，简而言之，任何超出句子边界的语言材料。我们为词法和语义惊奇度计算的困惑度分数支持了 Levy 的定义，因为我们观察到句内上下文不足以区分 IE 与字面表达。因此，语言处理器需要更大的上下文来判断一个表达是字面理解还是作为 IE。惊奇度 / 困惑度从跨句上下文的推导因此是未来工作的任务。

计算语义惊奇度的另一个问题在于 LOME 分配的主题角色数量庞大，这使得某个给定上下文仅出现一次的可能性相当高，最终这将导致均匀的困惑度值。在未来的工作中，我们将考虑简化为 Fillmore [11] 最初引入的“基本”主题角色，如施事、受事、主题、工具和来源。
