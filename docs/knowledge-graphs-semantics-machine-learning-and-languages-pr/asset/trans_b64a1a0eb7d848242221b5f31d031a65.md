## QALD-9-ES：用于问答系统的西班牙语数据集

Javier SORUCO a,1，Diego COLLARANA a,b,2，Andreas BOTH c,d,3 和 Ricardo USBECK e,4

a 玻利维亚私立大学，科恰班巴，玻利维亚
b 弗劳恩霍夫FIT，圣奥古斯丁，德国
c 莱比锡应用科学大学，莱比锡，德国
d DATEV eG，纽伦堡，德国
e 汉堡大学，汉堡，德国

摘要. 知识图谱问答（KGQA）系统使得任何能够用自然语言构成问题的用户都可以访问语义信息。KGQA系统如今是许多工业应用的核心组成部分，包括聊天机器人和对话式搜索应用。尽管世界各地的不同文化使用不同的语言，但KGQA系统及其资源所覆盖的语言数量主要局限于英语。为了在全球范围内实现KGQA系统，我们需要将当前的KGQA资源扩展到除英语以外的语言。考虑到近来大规模语言模型受到的关注，我们认为提供高质量资源是未来流水线开发的关键。这些资源之一就是用于训练和测试KGQA系统的数据集。在少数可用的多语言KGQA数据集中，只有一个涵盖西班牙语，即QALD-9。我们审查了QALD-9数据集中的西班牙语翻译，并确认了几个可能影响KGQA系统质量的问题。鉴于这一点，我们为这个数据集创建了新的西班牙语翻译，并在母语者的帮助下进行了人工审查。该数据集为QALD-9提供了新建的高质量翻译；我们将此扩展命名为QALD-9-ES。我们将这些翻译合并到QALD-9-plus数据集中，该数据集提供了QALD-9在九种语言中的可信母语翻译，旨在创建一个高质量翻译的完整来源。我们使用与语言无关的定量文本分析度量将新翻译与QALD-9原始翻译进行了比较，发现新翻译的结果有所改进。最后，我们使用支持西班牙语的KGQA系统，通过GERBIL QA基准框架对两种翻译进行了比较。虽然问答得分仅略有提高，但我们相信提高现有翻译的质量将带来更好的KGQA系统，从而增加KGQA在西班牙语领域的适用性。
