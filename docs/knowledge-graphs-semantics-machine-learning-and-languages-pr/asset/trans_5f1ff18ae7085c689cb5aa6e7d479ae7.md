## 5.3. 自动评估与人工评估结果的关联性

为了回答Q₂，我们使用两种非参数等级相关系数来衡量自动指标得分与人工判断之间的相关性：Spearman等级相关和Kendall等级相关。具体来说，Spearman等级相关系数（用Spearman的ρ表示）基于两个变量的秩来评估它们之间的线性关联[38]。类似地，Kendall等级相关系数（用Kendall的τ表示）评估两个排序变量之间的一致程度[39]。我们针对单文档任务计算了这两个系数[40]，并将它们绘制在图7中。这些度量不需要对变量的分布或其联合分布做任何假设。我们的相关性分析表明，BERTScore与人工信息性评分的关系最强，Spearman和Kendall系数分别达到ρ ≤ 0.61和τ ≤ 0.49。此外，ROUGE-1与人工连贯性评估的相关性最高，Spearman和Kendall系数分别为ρ ≤ 0.31和τ ≤ 0.25。我们还观察到，在所有这些情况下，简洁性与人工评估呈负相关，Spearman和Kendall系数分别为ρ ≥ −0.62和τ ≥ −0.52，而流畅性的相关性可以忽略不计，数值接近0。因此，BERTScore是评估生成摘要信息性的推荐指标，而ROUGE-1可以有效地捕捉连贯性维度。然而，简洁性的自动分数和人工分数呈负相关，这表明未来工作可以探索这种关系。此外，没有任何一个指标与人工流畅性判断显示出强相关性，这仍然是一个开放性的挑战。

## 6. 结论
