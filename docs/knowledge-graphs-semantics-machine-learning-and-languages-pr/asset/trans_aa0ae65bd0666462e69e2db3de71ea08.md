## 2. 预备知识

### 知识图谱。

知识图谱 (KG) G 是一个三元组 (s, p, o) ∈ (ℛ ∪ ℬ) × 𝒫 × (ℛ ∪ ℒ ∪ ℬ) 的集合，其中 ℛ 是所有资源的集合，ℬ 是所有空白节点的集合，𝒫 是所有谓词的集合，ℒ 是所有字面量的集合。

### 链接发现。

给定一个源知识图谱 Gs 和一个目标知识图谱 Gt（例如，包含国家边界几何表示的两个 KG）以及一个关系 r（例如，:touches），链接发现问题的目标是找到所有满足 r(s, t) 成立的对 (s, t) ∈ Gs × Gt。结果以称为映射的链接集合的形式产生：M = {(s, r, t) | s ∈ Gs, t ∈ Gt}。

### 拓扑关系的含量度量。

我们使用 Godoy 等人 [12] 定义的含量度量来判断关系 r(s,t) 是否存在。Godoy 等人实现了三种含量度量，通过比较多边形的最小边界框的面积、对角线或面积和对角线来确定两个多边形之间是否存在拓扑关系。含量度量区分的关系如图 1 所示。具有 n ≥ 3 个点 ((x1,y1),..., (xn,yn)) 的多边形 P 的最小边界框 (MBB) 定义为完全包含多边形点的最小矩形。形式上，MBB(P) = ((Xmin, Ymax), (Xmax, Ymin))，其中 Xmin = min(x1,...,xn)，Xmax = max(x1,...,xn)，Ymin = min(y1,...,yn) 且 Ymax = max(y1,...,yn)。MBB M 的面积定义为 area(M) = (Xmax − Xmin) · (Ymax − Ymin)。MBB M 的对角线形式定义为 diagonal(M) = √((Xmax − Xmin)² + (Ymax − Ymin)²)。我们进一步使用 [12] 中 MBB 之间的交集、并集和距离的相同定义。

## 3. 方法

我们通过使用 R-树对源数据集多边形进行索引，然后对索引后的多边形应用含量度量来开始我们的方法。

### R-树索引。

R-树 [13] 是二叉树的增强变体，其中 R-树存储多边形的 MBB 而不是多边形本身。在 COBALT 中，我们使用 Guttman 的 R-树 [14] 对源数据集进行索引，以便过滤掉尽可能多的不相连多边形对，从而减少链接过程的运行时间。每个节点的 MBB 包含其所有子节点的 MBB，因此如果父节点的 MBB 与查询矩形不相交（查询矩形是来自目标数据的 MBB），则其后代也不可能相交 [14]。R-树的底层存储源数据集多边形的 MBB，其上方的所有层都符合对底层索引所应用的标准。手工制作的 R-树示例如图 2 所示。

### 查询 R-树。

R-树易于递归查询。设 q 为我们想要查找源多边形相交 MBB 的多边形的目标 MBB。由于 R-树的节点是 R-树，我们对每个节点使用相同的算法。如果 R-树的当前节点位于底层（即它不包含其他 R-树而只包含多边形），我们则验证 q 是否与该节点中保存的源多边形的每个 MBB 相交，并将此类源多边形添加到查询结果中。如果 R-树的当前节点不在底层，我们检查每个子节点的 MBB 是否与 q 至少有一个公共点，如果是，则递归地对该节点重复该方法。例如在图 2 中，左侧两个蓝色节点的 MBB 重叠。如果查询矩形 q 位于两个节点 MBB 重叠的区域，我们必须检查两个节点的子节点。因此，我们需要一种快速的构建方法来最小化父节点的重叠。

### 构建 R-树。

构造 R-树主要有两种方法：(i) 静态构建算法通过将所有数据作为输入，然后一次性使用所有数据构建树。 (ii) 动态构建算法通过一次插入一个数据到树中。由于我们的数据集不经常变化，我们专注于静态算法，因为动态算法需要更多运行时间来重新插入数据以保持 R-树平衡。由于我们对每个目标几何只查询一次 R-树，构建质量（重叠）对于整体快速执行并不那么重要。为了测试不同构建算法的影响，我们使用了四种静态 R-树构建算法（即 SmallestX、STR、OTM 和 PackedHilbertR-tree）和一种动态算法（即 R*-Tree）。第一个静态算法是 SmallestX [15]，它按最小 x 坐标对 MBB 进行排序。SortTileRecursive [16] 算法（STR）自底向上构建 R-树，并将 MBB 按 x 坐标排序划分为切片，然后按 y 坐标排序，然后递归组合底层的父节点。OTM 算法 [17] 与 STR 类似，但使用自上而下的批量加载方法递归地按交替的 x 和 y 坐标对 MBB 进行排序。我们使用的最后一个静态构建算法是 PackedHilbertR-tree [18] 算法，它按 MBB 在 Hilbert 曲线上的位置对它们进行排序。另一方面，我们使用动态 R-树构建算法 R*-Tree [19]，它支持创建后插入新元素并尝试最小化节点占用的面积。在我们的实验中，我们一次一个地将多边形插入 R*-Tree，并使用 {4,8,16,32,64,128,256} 作为每个节点的容量。

### 拓扑关系的含量度量。

给定两个 MBB $A$ 和 $B$，基于面积的含量度量 ($F_a$) 是 [12] 中的三种含量度量中的第一个。$F_a$ 是将 $A$ 和 $B$ 的两个 MBB 的面积归一化为 $A$ 和 $B$ 并集的 MBB 的面积。形式上，

$$F_a(A,B)=\frac{\text{area}(A)}{\text{area}(\text{MBB}(A\cup B))},\tag{1}$$

其中 $F_a(B,A)$ 类似定义。$F_a$ 的范围为 $(0,1]$。在表 1 中，我们给出了不同拓扑关系下 $F_a(A,B)$、$F_a(B,A)$ 和 $F_a(A,B)+F_a(B,A)$ 的值。$F_a$ 无法区分以下关系对：(Meet, disjoint)、(covers, contains) 和 (covered by, inside)。例如，对于 contains 和 covers，并集 MBB 将与 MBB 的 MBB 相同。然而，该度量可以准确检测相等关系，因为两个输入 MBB 的面积与其并集的 MBB 的面积相同。第二个含量度量是基于对角线的含量度量 ($F_d$) [12]，形式定义为：

$$F_d(A,B)=\frac{\text{diagonal}(A)}{\text{diagonal}(\text{MBB}(A\cup B))}.\tag{2}$$

$F_d$ 的范围为 $(0,1]$，并且由于与 $F_a$ 相同的原因，它无法区分 (covers, contains) 和 (covered by, inside)。第三个含量度量是混合含量度量 ($F_m$) [12]。$F_m$ 利用 MBB 的面积、对角线和距离来寻找拓扑关系。与其他两种含量度量不同，它能够区分 (contains, covers) 和 (inside, covered by)。形式上，

$$F_m(A,B)=\frac{\text{area}(A)-2\cdot\text{area}(\text{MBB}(A\cap B))}{\text{area}(A)}+\frac{\text{distance}(A,B)}{\text{diagonal}(A)}.\tag{3}$$

### 结合 R-树索引与含量度量。

我们的 R-树索引基于其 MBB 过滤掉不相交的多边形对。我们只将索引后的源数据集保留在内存中，这减少了空间复杂度，因为我们随后以流式处理目标数据集。对于不相交关系，我们首先将索引会过滤掉的所有几何对添加到结果集，然后对剩余的几何对检查其他关系。在算法 1 中，我们概述了基于面积的含量度量 $F_a$ 的步骤。对于其他度量，我们将 $F_a$ 替换为对角线度量的 $F_d$ 和混合度量的 $F_m$（第 11-12 行）。此外，$F_a$ 的值需要根据 [12] 中其他度量的值进行检查（第 14 行）。
