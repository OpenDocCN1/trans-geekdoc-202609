

**发现 4。** *一种从性别和性取向身份角度、以知识为基础的仇恨理解方法，有助于识别与仇恨言论中相关身份识别有关的语言，以及可能与模型错误或标注错误相关的术语。*

## 5. 结论

我们提出了一种新颖的混合方法，将深度学习预测建立在与识别仇恨言论中涉及性别和性取向的语言相关的语义知识之上。首先，选择知识图谱（KG）作为语义知识，相较于现有的语言学方法，它是一种更丰富的结构化知识形式，能够提供语义增强的新型预测，其效果不逊于使用黑盒语言模型。其次，基于机器学习的适配阶段能够找到最优的表示层级，而这正是将语义知识应用于下游任务时面临的主要挑战。最后，我们提出了一种简单而有效的、基于特征的方法，将经过适配的知识图谱整合到神经网络中。我们在性别和性取向方面的评估表明，以知识为基础的方法对于增强模型的透明性、鲁棒性以及处理标注错误的能力至关重要。尤其是，该方法能够突出相关词汇，从而更好地理解训练数据如何捕捉身份群体语言、模型错误的类型，以及更有意义的是，人类标注中的歧义。

我们承认，目前仅在两个特定群体和一个知识图谱上评估了我们的方法。未来针对其他目标群体开展研究，将进一步凸显基于知识的方法在仇恨言论检测中的价值。同样，考虑不同领域和规模的知识图谱，也将有助于深入了解如何更有效地整合这些知识图谱。知识图谱通常生成和维护成本高昂，有时其覆盖范围可能不足以满足任务需求 [50]。然而，我们的研究表明，当这些知识可用时，它们能够积极地补充并增强标准深度学习方法。我们承认，使用标准性能指标评估仇恨言论存在局限性，并将针对该任务的特定设置 [51,52]，以及针对这些身份群体进行定制，留作未来工作。在标注结果方面，我们的语义增强模型在 97% 的假阳性错误中发现了相关指称。还需要进行更全面的分析，以探究这些分歧背后的原因，以及这些案例在多大程度上属于难以分类的训练样本，而这些样本可能有助于改进仇恨言论识别器 [53]。尽管如此，根据被针对的群体来分析仇恨仍然至关重要，因为这类语言具有微妙性，使得标注人员更难理解和感知仇恨言论，从而进一步增加了识别难度 [20]。

总而言之，我们特别强调，本研究并不旨在推断个人的敏感属性 [54]。相反，本研究旨在关注仇恨言论中的社会语言学层面，希望通过相关语言所体现的社会现实，为自动识别系统提供更好的语境化理解。
