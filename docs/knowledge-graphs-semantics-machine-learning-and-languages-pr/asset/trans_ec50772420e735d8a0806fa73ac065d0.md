## 研究问题 Q₂.

从图 4a 可以看出，在 COBALT 中实现的所有基于内容的度量（即 COBALT_area、COBALT_diagonal 和 COBALT_mixed）使用 R 树索引，比基于 RADON 的空间平铺索引部署的对应方法（即 COBALT_area(R)、COBALT_diagonal(R) 和 COBALT_mixed(R)）快 4 到 8 倍。例如，COBALT_mixed 的总运行时间为 195 毫秒，而 COBALT_mixed(R) 的总运行时间为 849 毫秒，这意味着 COBALT_mixed 比 COBALT_mixed(R) 快 4.3 倍。COBALT 中最慢的基于内容的度量（即 COBALT_area）平均比 RADON 快 4840 倍。COBALT_mixed 最快可比 RADON 快 1.47 × 10⁴ 倍，这是 COBALT 相对于所有其他算法的最佳加速。这清楚地表明了基于内容的度量在运行时间方面的效率，这清楚地回答了我们的第二个研究问题 Q₂。
