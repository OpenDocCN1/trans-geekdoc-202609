## 基于知识的仇恨言论目标群体语言识别

Paula REYERO LOBO a,1, Enrico DAGA a, Harith ALANI a and Miriam FERNANDEZ a

a 知识媒体研究所，开放大学，英国

ORCiD ID: Paula Reyero Lobo https://orcid.org/0000-0001-5238-4550, Enrico Daga https://orcid.org/0000-0002-3184-5407, Harith Alani https://orcid.org/0000-0003-2784-349X, Miriam Fernandez https://orcid.org/0000-0001-5939-4321

摘要。仇恨言论的形式因目标社群而异，通常基于性别、性取向、种族或宗教等因素。在线检测仇恨言论具有挑战性，因为现有系统没有考虑基于目标身份而产生的仇恨多样性，并且可能对某些群体存在偏见，导致结果不准确。当前的语言模型在识别目标社群方面表现良好，但只能提供仇恨言论文本包含特定群体指代的概率。这种缺乏透明度是有问题的，因为这些模型从可能不熟悉目标群体的人工标注数据中学习偏见。为了提高仇恨言论检测，尤其是目标群体识别能力，我们提出了一种新的混合方法，该方法融入了关于特定身份群体所用语言的显式知识。我们利用知识图谱（KG）并对其进行调整，在适当的抽象级别上识别与性别和性取向相关的仇恨言论语言。一项全面的定量和定性评估表明，我们的方法在效果上与最先进的语言模型相当，同时能更好地适应领域和数据变化。通过将任务基于显式知识，我们可以更好地将所提方法生成的结果与最常受到这些技术影响的群体的语言结合起来。语义丰富化帮助我们检查模型输出和仇恨言论检测系统使用的训练数据，并更有效地处理人工标注中的模糊案例。总体而言，在仇恨言论检测中注入语义知识对于增强对模型行为的理解和解决训练数据产生的偏见至关重要。

关键词。仇恨言论、语义丰富化、知识图谱、语言模型

从性别和性取向的角度来看，某些术语如“butch”和“bimbo”带有与女性男性气质或外貌相关的含义。根据上下文，这些术语可被用于侮辱或强化社会刻板印象。这些语言上的细微差异使得识别仇恨言论的任务高度依赖于所涉及的特定身份群体和语言使用的语境 [2]。

目前识别仇恨言论中目标群体语言的主要方法有两种。第一种，我们称之为系统A，是有监督学习方法 [3,4,5]，其中最先进（SOTA）的方法基于语言模型 [6]。虽然它们能达到高性能，但只能给出帖子包含特定身份群体指代的概率。在我们的示例中，只有第二条帖子会以高概率被判定包含敏感语言，但没有提供进一步的原因。由于人工标注者可能存在主观解释和偏见，这种缺乏支持信息的情况令人担忧。对仇恨言论的判断会因人口统计学特征而显著不同 [7,8]，因为可以预期任何人工标注者都可能不熟悉特定目标群体的语言。因此，整合基础性知识可能有助于更好地理解预测，而且更重要的是，使模型对训练数据集中的偏见更加鲁棒。第二种，我们称之为系统B，是显示更高透明度的语言学方法 [9,10,11]。它们使用术语列表（词典）或正则表达式模式提供参考，例如可以识别第一条帖子中的相关术语 [12]。然而，它们准确性较低，因为它们只捕获了身份群体敏感语言的稀疏表示。
