**摘要。** 随着语义网上发布的RDF数据集数量持续增长，高效地链接这些数据集之间的相似实体变得越来越重要。然而，现有的数据链接工具（通常是为通用目的而开发）的性能似乎已到达平台期，这表明需要更模块化、更高效的解决方案。在本文中，我们提出——并在OWL中形式化——一种不同类型链接问题类型（LPTs）的分类，以帮助链接数据社区提前识别问题并开发更高效的解决方案。我们的分类基于文献中描述的异质性——特别是五篇文章——并确定了五种主要的链接问题类型：谓词值问题、谓词问题、类问题、子图问题和图问题。通过对LPTs进行分类，我们提供了一个理解和解决与语义数据链接相关挑战的框架。它可用于基于现有的模块化工具开发针对特定LPT的新解决方案，从而提升数据链接的整体效率。

**关键词。** 数据链接，语义网，链接问题类型，分类

## 1. 引言

二十多年来，人们一直在为语义网的发展进行重要工作[1]，目的是在线共享数据并促进机器对人类知识的访问。在这一方法中，链接开放数据（LOD）基于语义网模型和工具（如RDF和OWL表示语言）倡导免费数据集的共享和重用。但是，尽管以LOD形式提供的数据集数量逐年增加，仍有一个新的挑战需要应对：数据链接。实际上，为了最大化从资源中获取的知识，浏览这些数据集的代理必须能够链接两个指向同一事物但在各自数据集中由不同标识符（URI）标识的资源。例如，一位著名演员可能涉足政坛，导致其同时出现在电影和政治两个独立知识库中并被描述。为了撰写他的传记，通常不同的两个URI标识同一个人，必须通过等价链接（如语义关系`owl:sameAs`，其用法见[2,3,4,5]）将它们链接回去。

## 2. 相关工作

数据链接已例如被定义为：“在自动链接发现系统的帮助下，在不同RDF数据集中的实体之间建立类型化链接的任务。”[11]。在[12]中，作者区分了两种数据链接方法：“（i）基于相似性的方法，两个资源越相似，它们被链接的可能性就越大；（ii）基于键的方法，键决定资源的身份：具有相同键的两个资源必须被链接”。在本文中，我们将数据链接定义为在两个不同语义数据集中被区分标识的实体之间建立相似性或层次关系的任务。

以下是一些常见数据链接技术的总结：

- *确定性链接*涉及基于唯一标识符（如前述例子中的社会保障号码）或其他唯一标识符来链接数据集记录，这些标识符允许不同数据集中的实体进行一一匹配。这种方法被认为是最准确和高效的，但要求跨数据集使用共同的唯一标识符，而这些标识符可能不存在或难以识别。
- *概率性链接*涉及基于非唯一标识符属性（如姓名、地址和出生日期）来匹配实体。该技术计算两条记录指向同一实体的概率。然而，基于几对属性和值来确定唯一键仍然是一项艰巨的任务。人们已经开展了自动确定这些键的工作[13,14,15]。当唯一标识符不可用时，概率性链接很有用，但其准确性低于确定性链接。
- *基于规则的链接*涉及定义规则，指定数据集之间记录链接的条件[16,17]。例如：如果两条记录具有相同的姓名和地址，则它们匹配。当记录链接的条件具有高度确定性时，基于规则的链接很有用。
- *知识图谱嵌入*涉及将关系表示为嵌入空间中的平移[18]。图被转置到向量空间中，因为向量空间提供了更广泛的数学和统计处理工具。这意味着机器学习等技术可以更容易地应用于这些图。这是数据链接领域最新的技术之一，但尽管它比传统技术有许多优势，它仍然有局限，例如当关系路径较长或复杂时，该方法的鲁棒性不佳[19]。
