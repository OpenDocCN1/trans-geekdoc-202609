## 4.1.2. 基线

我们选择最具代表性的系统 A（监督学习）和系统 B（语言学）方法作为基线。作为系统 A，RoBERTa_base [6] 模型在性能方面设定了上限。然而，该模型无法提供文本为何与特定身份群体相关联的任何见解，且仅从训练数据中学习。作为系统 B，Toxic Debias [11] 是最常用于识别仇恨言论中针对边缘化群体敏感语言的术语和正则表达式列表。在针对这些群体的 53 个潜在冒犯性提及和 26 个非冒犯性提及中，47 个表达与性别和性取向相关。我们在公开可用的存储库中突出了 14 个非冒犯性和 33 个可能冒犯性的提及。

## 4.1.3. 评估指标

出于可比性考虑，我们采用与监督学习基线相同的评估方法，并根据 0.5 阈值考虑准确率和 F1 分数，以及两个与阈值无关的指标：接收者操作特征曲线下面积（ROC AUC）和精确率-召回率曲线下面积（PR AUC）。
