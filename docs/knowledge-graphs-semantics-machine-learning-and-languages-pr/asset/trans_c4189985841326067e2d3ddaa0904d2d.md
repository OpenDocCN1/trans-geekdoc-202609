### 命名图

Carroll 等人 [7] 提出了对 RDF 数据模型的一种扩展，允许 RDF 图通过 URI 命名，这些图被称为命名图。在这种方法中，命名图表示为二元组 (g, n)，其中 g 是 RDF 图，n 是 IRI、空白节点或默认图。要被标注的语句定义在一个 RDF 图中，而标注本身定义在另一个 RDF 图中。标注直接链接到该图。图 4(b) 显示了这个示例的语法。

### 单例属性

单例属性模型 [8] 提出为每个具有关联元数据的三元组创建一个唯一属性。在该模型中，创建一个新节点来表示新属性，该节点通过所提出的 *singletonPropertyOf* 属性直接连接到原始标注属性。同一属性用于与一条语句关联的所有元数据。使用该模型的 RDF 三元组示例见图 4(c)。

### RDF-Star

[9][10] 提出了将 RDF-star 和 SPARQL-star 作为 RDF 和 SPARQL 的扩展，以实现图嵌套并简化具体化语句的表示。RDF-star 和 SPARQL-star 允许图的递归嵌套，无需声明与元数据关联的边标识符。RDF-star 通过双尖括号 << >> 支持将三元组嵌套在其他三元组中作为主语或宾语。因此，每条具体化语句都可以被解释为单个 RDF 三元组。RDF-star 具体化的示例见图 4(d)。

### 查询模板

基于 [12] 中使用的 A、B 和 F 系列查询，我们定义了七个查询模板，为简单起见，这些模板以 SPARQL-star 查询形式呈现。模板将被称为 Q1 至 Q7。所有模板可见于图 6。Q1 和 Q5 使用 ER 实例进行实例化，而 Q2、Q3、Q4 和 Q6 使用概念实例进行实例化。Q7 没有实例化。在这些查询中，只有主语是被引用的。Q2、Q3 和 Q4 是星形查询。

- 1. Q1 是属性路径查询。对于给定的 ER，它返回概念列表以及关联的类别层次结构（使用 skos:broader*）。
- 2. Q2 是 FILTER 查询，比较一个概念的注解。给定一个概念，它使用 FILTER 关键字返回相关的 ER，这些 ER 的 pageRank 分数大于余弦相似度。
- 3. Q3 是连接查询。它返回与三个给定概念相关联的 ER 集合。
- 4. Q4 与 Q3 类似，但增加了一个 FILTER，用于指定三个 pageRank 分数之间的相对关系。

Q5 是连接查询，另外使用了 OPTIONAL 子句。它返回给定 ER 的所有可用信息、关联概念列表以及对应的 pageRank 分数。

Q7 是使用 COUNT 运算符的 GROUP BY 查询。它按概念返回 ER 数量，并过滤掉低于 pageRank 阈值的结果。
