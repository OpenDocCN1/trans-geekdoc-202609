摘要。

目的：本研究解决了当前 DBPEDIA 实体简短摘要的局限性，这些摘要由于其创建方法（即从完整的 DBPEDIA 摘要中选择前两到三句话）往往缺乏全面概述。

方法：我们利用预训练语言模型生成六种语言（英语、法语、德语、意大利语、西班牙语和荷兰语）的 DBPEDIA 摘要的抽象摘要。我们进行了多项实验以评估语言模型生成的摘要质量。特别是，我们使用人工判断和自动指标（Self-ROUGE 和 BERTScore）评估生成的摘要。此外，我们研究了人工判断与自动指标在评估生成的摘要在不同方面（信息性、连贯性、简洁性和流畅性）时的相关性。

发现：预训练语言模型生成的摘要比现有的简短摘要更简洁且更具信息性。具体而言，基于 BART 的模型有效克服了 DBPEDIA 简短摘要的局限性，尤其是在较长的摘要方面。此外，我们表明 BERTScore 和 ROUGE-1 是评估生成的摘要相对于完整 DBPEDIA 摘要的信息性和连贯性的可靠指标。我们还发现简洁性与人工评分之间存在负相关。此外，在没有人工判断的情况下，流畅性评估仍然具有挑战性。

价值：本研究对依赖 DBPEDIA 资源机器学习和自然语言处理中的各种应用具有重要意义。通过提供简洁而全面的摘要，我们的方法提高了 DBPEDIA 摘要的质量，并为语义网社区做出了贡献。

关键词：抽象摘要，大型语言模型，知识图谱。

## 1. 引言

DBPEDIA 是 Linked Open Data 云 (LOD) [1] 中最受欢迎的知识图谱之一。DBPEDIA 已被广泛用作在网络上访问和链接知识的重要资源，尤其是在语义网和链接数据背景下。实体摘要 (dbo:abstract) 是 DBPEDIA 的重要组成部分，因为它们为每个实体的 Wikipedia 页面提供简明摘要。此外，DBPEDIA 摘要有两种类型：1) 完整摘要，从每个实体的对应 WIKIPEDIA 文章的第一段中提取。2) 短摘要² 是通过从完整摘要中选择前几句话（即两到三句话）自动创建的 [2]。短摘要用于为用户提供有关实体的最重要信息的全面概述。例如，Google 在知识面板中采用搜索概念的短摘要，为用户提供所搜索实体的简明摘要 [3]。然而，创建这些短摘要的方法忽略了完整摘要剩余部分中的其他相关信息。图 1 显示了通过截断³ 其完整摘要⁴ 的第一句话创建的“Marie Curie”实体的缩短摘要示例。该缩短摘要忽略了其他基本信息，例如“The cause of her death was given as aplastic pernicious anaemia, a condition she developed after years of exposure to radiation through her work”，这对于理解 Marie Curie 的生活和成就至关重要。需要注意的是，DBPEDIA 的某些短摘要在特定语言中不可用。

为解决这些挑战，我们利用预训练语言模型 (LLMs) 生成 DBPEDIA 实体的抽象摘要。最近，预训练语言模型的进步在文本摘要任务中取得了令人印象深刻的性能，在各种基准数据集上实现了最先进的性能 [4–7]。受此成功启发，我们在比较研究中采用了两种最先进的 LLM：i) BART（Bidirectional Auto-Regressive transformers 的缩写）模型，通过在两个方向（从左到右和从右到左）考虑文本的上下文，可以生成更准确和连贯的摘要 [8]，ii) T5（Text-To-Text Transfer Transformer 的缩写）模型基于具有自注意力机制的 Transformer 架构，采用文本到文本方法，即 T5 模型经过训练以根据输入生成输出文本。这使得 T5 模型可用于各种任务（例如，文本摘要、问答、机器翻译）。为了确保我们的摘要方法的可访问性和经济性，我们选择了这些开源模型（BART 和 T5），而不是需要 API 订阅（例如 OpenAI API）或大量计算资源商业模型（例如 GPT-3、GPT-4）。此外，开源模型具有高度适应性，可以在特定领域数据集上轻松微调，几乎不需要额外工作。此外，先前的研究表明，BART 和 T5 都可以生成与较小的 GPT-3 模型 [9–11] 生成的摘要质量相当的摘要。

我们进行了多项实验，以确定生成六种语言 DBPEDIA 摘要抽象摘要的最合适的预训练 LLM。我们使用了英语、德语、法语、意大利语、西班牙语和荷兰语的 DBPEDIA 摘要作为评估数据集，并使用各种 LLM 生成摘要。然后，我们使用人工判断和自动指标评估 LLM 生成的摘要与现有缩短摘要的质量。此外，我们研究了自动指标与摘要质量的人工评估之间的相关性。我们的评估结果表明，LLM 是为 DBPEDIA 摘要创建信息性摘要的有效工具。然而，LLM 的选择应根据特定语言进行调整。我们总结本研究的主要贡献如下：

- 据我们所知，这是首个利用 LLM 生成 DBPEDIA 摘要的抽象摘要的研究，与现有自动从完整摘要中选择前几句话的方法相比。
- 我们比较了不同 LLM 在六种语言（英语、德语、法语、意大利语、西班牙语和荷兰语）中生成抽象摘要的性能，使用人工和自动评估指标
- 我们分析了自动指标（BERTScore 和 self-ROUGE）与生成摘要质量的人工判断之间的相关性。
- 我们提供了所有 DBPEDIA 摘要（v2022）的抽象摘要资源，涵盖英语和德语。⁵

## 2. 相关工作

### 用于抽象摘要的 LLM。

近年来，人们对总结知识图谱中现实世界实体的描述越来越感兴趣 [12, 13]。该任务称为文本摘要，需要从知识图谱中选择最基本和最突出的概念、实体和关系，并生成它们的简短连贯摘要。文本摘要通常可分为两类：i) *抽取式摘要* [14]，涉及从文档中选择最突出和最具信息性的句子来创建摘要，以及 ii) *抽象式摘要* [15]，涉及生成传达原始文档主要思想的新摘要，可能使用原始文本中不存在的新短语和句子。我们的研究侧重于后者，用于生成 DBPEDIA 摘要的抽象摘要。
