## 5.1.4. 子图问题

子图问题可分为两类：一类是子图描述异质性问题，另一类是子图无文本描述问题（见图 10）。我们区分了描述的异质性与实体某些特征描述的缺失。

对于 LPT 4.1，一个示例是一对描述同一资源、但信息量不同的数据集（例如，一侧是纽约市及其名称、人口和地理位置，另一侧只是它的名称和位置）。

## 5.1.5. 图问题

图问题可分为八个层级（见图 11）。图问题层级必须显式添加到分类中，因为我们要将更一般的问题与在 RDF 三元组层面呈现的问题区分开来。例如，某些语言与其他语言相比在可扩展性和表达力方面的问题，比如否定的表达。

对于 LPT 5.4.4，一个示例是一对使用不同语言、在逻辑概念表示上存在差异的数据集（例如，一种语言直接表达类不相交（A disjoins B），而另一种语言需要使用否定（A subclass-of (NOT B)））。对于 LPT 5.4.6，一个示例是一对描述同一城市人口和动态、但时间不同的数据集。对于 LPT 5.6，一个示例是一对数据集，在图层面描述模式相同，但描述内容不同（例如，两组三元组都仅由 person 类的个体组成，但一侧只有一个自反关系“hasSister”，另一侧只有一个自反关系“hasBrother”）。这类问题对嵌入图尤其有用。

我们再次注意到，不同作者按层级对每个问题的分布存在一些差异，例如 Achichi 只报告了与图概念键异质性和图概念数据集时效性相关的异质性。

我们添加了 LPT 5.8，因为我们认为它在开发融合 LM 和 OM 的混合技术时可能很有用，在这些技术中 TBox 的缺失会被视为一个问题。

## 5.2. LPT 分类的形式化

我们形式化了 LPT 分类，如图 12 所示。我们使用 lpt 前缀作为本分类的命名空间。lpt:LPT 类是我们模型中的主类。为了最大限度地复用，我们尽可能依赖已有词汇表，而不是创建新的类和属性。特别是，我们使用 SKOS、RDF-S、Dublin Core 和 PROV-O [27] 来描述这些类。此外，我们使用 DCAT 词汇表 [28] 来定义数据集及其分布。我们引入了 lpt:PairOfDatasets 类，用于表示一对已经链接或需要链接的 dcat:Datasets。该类将这一对数据集表示为一个可以独立描述的对象，例如链接状态、链接日期、链接来源；我们在此不描述这些内容。lpt:occursIn 属性是我们模型中的关键关系：它编码了某个链接问题类型发生/出现在某一对数据集中的事实。为了详细描述这样一对数据集，lpt:PairOfDatasets 类的实例通过 lpt:hasSource 和 lpt:hasTarget 属性链接到 dcat:Dataset 类的两个独立个体。prov:wasInfluencedBy 属性将 lpt:LPT 类与多位作者报告并用 lpt:Heterogeneity 类编码的底层异质性连接起来。我们使用 prov:wasDerivedFrom 属性，将指导我们分类的异质性描述所来源的书目资源关联到 BIBO 本体 [29] 中的一个对象。

图 13 给出了 LPT 分类模型实例化的一个示例。该示例实际上是 LPT 2.1.1 问题（称为 `Predicate terminological synonymy`）出现在 lpt:datasetOAEI101 和 lpt:datasetOAEI205 数据集中的真实案例，这两个数据集分别可通过 https://oaei.ontologymatching.org/tests/101/onto.rdf 和 https://oaei.ontologymatching.org/tests/205/onto.rdf 访问。OAEI 提供这对 RDF 数据集，以便未来的参与者测试他们的工具。

该分类目前正以 OWL 格式在网络上提供。选择这种表示语言，是着眼于编码一个层级分类，以便未来的软件解决方案能够利用

## 6. 结论

数据链接使得相似实体能够被链接起来，从而让分散在多个异构数据集中的语义数据得到更有效的利用。因此，在本文中，我们提出了一种对链接 RDF 数据集时可能遇到的不同类型问题进行形式化分类的方法。我们希望这一分类能帮助数据链接社区更好地识别：当两个术语、结构及逻辑异构的 RDF 数据集需要链接时，可能会出现哪些问题。建立尽可能贴近待处理 RDF 数据的精确画像，应有助于更好地选择解决数据链接任务所需的算法模块，以期改进现有数据链接工具的性能，而这些工具大多采用通用解决方案。

未来，我们计划继续完善这一分类，例如持续为所描述的每个 LPT 提供来自数据链接竞赛所用数据集对的实际案例。能够解决这些 LPT 的不同技术也将一并附上。最终，我们希望构建一个 OWL 本体，并当然会将其在线提供给数据链接领域的所有用户。

这项工作是在 DACE-DL（以数据为中心的 AI 驱动数据链接）项目 5 的背景下完成的，该项目通过聚焦自下而上、以数据为中心的方法论 [11]，提出了数据链接领域的范式转变。该研究项目的目标是利用机器学习技术和表示学习模型，通过促进将正确的链接工具应用于相应的链接问题来改进数据链接。因此，需要将链接问题类型的分类形式化。我们设想，通过机器学习过程，根据一对数据集暴露出的不同问题，利用我们的分类来确定数据链接所需的相应具体链接工具模块，从而为链接任务提供比当前方法更具体的解决方案。

这项工作的另一个视角是尝试通过无监督机器学习过程对不同数据集对进行归类，我们会为这些数据集对手动确定其可能暴露出的不同 LPT。此类实验的目标是验证我们通过 LPT 分类进行的分组，能否得到由机器学习过程进行的归类的印证。这些数据集对取自 OAEI 等各类数据链接基准。每个数据集对都记录有它们暴露的不同 LPT、一个包含运行链接工具后理论上应获得的不同对齐结果的附加文件，以及经测试性能最佳的链接工具。还提供了关于这些数据集的其他信息（即描述、创建年份、来源、对齐类型（T-Box/模式匹配、实例匹配或链接发现、实例与模式匹配，以及表格数据到知识图谱匹配））。在我们的下一个项目中，我们旨在建立一个自动化软件解决方案，其输入是我们试图链接的一对数据集，输出则是它们暴露出的 LPT。
