为了确定实体是否出现在给定文本中（实体匹配），我们考虑的不仅是实体的标签，还包括其替代名称和现有同义词。例如，在图 2 (A) 中我们观察到“X-gender”由“Male to X-gender”、“Female to X-gender”、“Genderqueer”和“Gender nonbinary”定义。除这些术语外，我们还考虑词干变化，例如“genderqu”和“gender nonbinari”。任何包含这些表达式中的任何一个的文本都被视为实体出现的文本。具体而言，图 2 (A) 中显示的 KG 属性用于推导实体匹配的同义词。我们基于 Whoosh 2.7.4 库 (https://whoosh.readthedocs.io) 开发了一个搜索索引以加快实体匹配，并使用其 Porter stemmer 原生函数获得词干变化。

## 3.2.3. 实体加权

最后，我们考虑两种类型的实体加权方案：(i) 基于预训练数据中实体的频率和 (ii) 基于用于领域任务的 ML 模型学习到的系数，在本例中为二元分类。

### 实体加权基于频率 (DocF)
赋予实体的权重基于该实体在正样本（即所有与性别和性取向相关的文本）中出现的比率与负样本（即所有与任何其他身份相关的文本）中出现的比率。设 Dp 为与该类别相关的所有文本的集合，Dn 为与任何其他身份相关的所有文本的集合。给定实体 ei，我们考虑 ei 在 Dp 中的出现次数 (Dp′)，以及 ei 在 Dn 中的出现次数 (Dn′)。实体的权重 w(ei) 然后计算为 w(ei)=Dp′/Dp−Dn′/Dn，使得 w∈[−1,1]。

### 实体加权基于 ML 系数 (LR 和 MultiNB)
该方法根据机器学习模型定义的系数为不同实体提供权重。系数反映了实体在预测特定文本是否指代（或不指代）该类别时的判别能力。我们为该任务使用了两种不同的 ML 模型：Logistic Regression (LR) 和 Multinomial Naive Bayes (MultiNB)。作为训练 ML 模型的输入，我们为每个预训练样本提供：(i) 一个类别标签（即文本是否包含对性别和性取向的任何语言引用）和 (ii) 由上述实体匹配产生的实体的独热编码。也就是说，ML 模型使用实体作为分类的特征。得到的结果系数反映了特征重要性以及每个实体对预测的贡献程度。

### 基于层次实体扩展的加权方案的额外修改
为了测试 KG 结构是否可以帮助我们更好地完善适配，我们提出了一种影响纳入加权过程的实体的修改。图 2 (B) 以粗体显示了扩展类实体（例如 "lesbian"）或实例实体（例如 "fag"）的过程。每个类都扩展到其顶层，使用 rdfs:SubclassOf 属性收集，例如 "lesbian" 是 Gay Person、LGBTQ person、Person 等。对于每个实例，我们将基于 rdf:type 属性进行扩展，并还包括 "fag" 是 Homophobic slur、Cross-cultural dysphemism 和 Gay male slang 等。因此，在这种修改后的加权方案版本中，如果文本中出现了实体 e_i 本身、其任何子类或其任何实例，则认为实体 e_i 在文本中被提及。

## 3.3. 知识图谱集成

本阶段描述了如何将适配后的 KG 与深度学习架构嵌入。以下我们介绍所提出混合学习框架的两个主要组成部分。

### 语义组件
我们的混合方法在特征提取中考虑了适配后的 KG（带预训练权重的 KG）。在训练样本中发现的实体的权重构成了用作输入的特征向量。也就是说，深度学习组件的输入是一个稀疏向量表示，其中非零分量是训练样本中实体的权重。与上下文词嵌入相比，基于 KG 的特征提取提供了输入文本的低维数值表示。我们将我们的混合方法与 SOTA 中使用的预训练 Transformer 架构进行比较，其中 RoBERTa [42] 相对于 BERT [43] 和 Universal Sentence Encoder [44] 表现最佳。

### 深度学习组件
SOTA 中用于识别仇恨言论中目标群体语言的深度学习架构由具有 dropout 层的 Feed-forward 多层神经网络和 M 个二元层用于分类组成，每个群体身份一个（性别、性取向、宗教、种族、残疾、民族血统和年龄）[6]。也就是说，对于给定的输入文本，模型提供 M 个概率，指示其是否包含与每个群体相关的任何语言。由于我们的工作重点是性别和性取向，我们仅考虑属于这两个类别中的任何一个的概率。
