**convex combination**: A linear combination \sum_i \alpha_i \cdot x^{(i)} of the vectors {x^(i)} where the coefficients satisfy \alpha_i \ge 0 and \sum_i \alpha_i = 1. See 76, 108, 257.

**convex function**: A real-valued function g : X -> R, whose domain X is a convex set in a vector space, is a convex function if for any x^(1), x^(2) in X, the function satisfies the inequality
g (\alpha x^(1) + (1 - \alpha) x^(2)) \le \alpha g (x^(1)) + (1 - \alpha) g (x^(2)) ,
for any \alpha \in [0, 1]. See 177, 179-182, 184, 186-189, 192, 194, 210-212, 216, 221, 231, 259.

**convex hull**: The smallest convex set containing the set X, or equivalently, the intersection of all convex sets containing X, or the set of all convex combinations of the points in X. For a finite set X = {x^(i)}, its convex hull is thus given by C_X = { \sum_i \alpha_i x^(i) | \sum_i \alpha_i = 1 \land \forall i \alpha_i \ge 0 }. See 213, 214, 227, 228.

**convex optimization**: The process of minimizing a convex function over a convex set. See 94, 147, 177, 184, 195, 211, 232.

**convex set**: A set A is convex if for any pair of objects a, b in A, all convex combinations of a and b are also in A; i.e., \alpha a + (1 - \alpha) b in A for all \alpha \in [0, 1]. See 200, 201, 210-212, 215, 218, 221-225, 231, 232, 257, 259.

**convex-inducing classifier**: A binary classifier f for which either X_f^+ or X_f^- is a convex set. See 11, 18, 200-202, 206, 209-211, 218, 225, 231, 232, 244, 245, see also classifier.

**cost function**: A function that describes the cost incurred in a game by a player (the adversary or learner) for its actions. In this book, the cost for the learner is a loss function based solely on the learner's predictions whereas the cost for the adversary may also be data dependent. See 32.

K-covering of X: A collection of K balls of size \epsilon (i.e., sets B_i) arranged such that the object represented by set X is completely contained within their union; i.e., X \subseteq \cup_i B_i.

+   ▶ covering number: The minimum number of balls needed to cover an object and hence, a measure of the object's complexity. See 205, 230.

**data**: A set of observations about the state of a system. See 20, see also dataset.

**data collection**: The process of collecting a set of observations about the system that comprise a dataset. See 23, 45.

**data point (x)**: An element of a dataset that is a member of X. See 23, 26, 27.

**data sanitization**: The process of removing anomalous data from a dataset prior to training on it. See 18.
