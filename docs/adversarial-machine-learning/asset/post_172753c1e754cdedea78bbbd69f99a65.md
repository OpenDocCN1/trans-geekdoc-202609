### Corollary 7.15 (Privacy of PRIVATESVM)

For any β > 0, database D of size N, C > 0, D̂ ∈ Ψ, loss function ℓ (y, ŷ) that is convex and L-Lipschitz in ŷ, and translation-invariant kernel k, PRIVATESVM run on D with loss ℓ, kernel k, noise parameter λ ≥ 2^{2.5} LC√D̂ / (βN), approximation parameter D̂, and regularization parameter C guarantees β-differential privacy.

**Proof** The result follows from Theorem 7.10 since w̃ is the primal solution of SVM with kernel k, the response vector ŵ = w̃ + μ, and k̃(x, x) = 1 for all x ∈ H^D. The extra factor of √2 comes from the fact that φ̃( · ) is a 2D̃-dimensional feature map.

This result is surprising, in that PRIVATESVM is able to guarantee privacy for regularized ERM over a function class of infinite dimension, where the obvious way to return the learned classifier (responding with the dual variables and feature mapping) reveals all the entries corresponding to the support vectors completely.

The remainder of this section considers the following result, which states that PRIVATESVM is useful with respect to the SVM.

### Theorem 7.16 (Utility of PRIVATESVM)

Consider any database D, compact set M ⊆ H^D containing D, convex loss ℓ, translation-invariant kernel k, and scalars C, ε > 0 and δ ∈ (0, 1). Suppose the SVM with loss ℓ, kernel k, and parameter C has dual variables with ℓ1-norm bounded by Λ. Then Algorithm 7.4 run on D with loss ℓ, kernel k, parameters D̂ ≥ 4(D+2)/θ(ε) log_ε( 2^2 (ε_p diam(M))^2 / δ^{θ(ε)} ) where θ(ε) = min { 1, ε^4 / (2^4 (Λ + √2(CL/Λ/2)^4)^4 } , λ ≤ min { ε / (2^4 log 2 √D̂), ε√D̂ / (8 log 2/δ) } , and C is (ε, δ)-useful with respect to Algorithm 7.1 run on D with loss ℓ, kernel k and parameter C, with respect to the || · ||_{∞;M}-norm.

### Remark 7.17

Theorem 7.16 introduces the assumption that the SVM has a dual solution vector with bounded ℓ1-norm. The motivation for this condition is the most common case for SVM classification: learning with the hinge loss. Under this loss the dual program (7.1) has box constraints that ensure that this condition is satisfied.

The result of Theorem 7.16 bounds the pointwise distance between classifiers f* output by SVM and f̂* output by PRIVATESVM with high probability. Let f̃ be the function parametrized by intermediate-weight vector w̃. Then we establish the main result by proving that both f* and f̂* are close to f̃ with high probability and applying the triangle inequality. We begin by relating f̃ and f*. As f* is the result of adding Laplace noise to w̃, the task of relating these two classifiers is almost the same as proving the utility of PRIVATESVM-FINITE (see Theorem 7.11).

### Corollary 7.18

Consider a run of Algorithms 7.1 and 7.4 with D̂ ∈ N, C > 0, convex loss, and translation-invariant kernel. Denote by f̂* and f̃ the classifiers parametrized by weight vectors ŵ and w̃, respectively, where these vectors are related by ŵ = w̃ + μ with μ ∼ iid Laplace(0, λ) in Algorithm 7.4. For any ε > 0 and δ ∈ (0, 1), if 0 < λ ≤ min { ε / (2^4 log_e 2√D), ε √D / (8 log_e 2/δ) } then Pr( ||f̂* - f̃||_∞ ≤ ε/2 ) ≥ 1 - δ/2.

**Proof** As in the proof of Theorem 7.11 we can use the Chernoff trick to show that, for an Erlang 2D̂-distributed random variable X, the choice of t = (2λ)^{-1}, and for any ε > 0

\[
\text{Pr} \left( \|\hat{f}^* - \tilde{f}\|_\infty > \epsilon/2 \right) \le \frac{\text{E} [e^{tX}]}{e^{\epsilon t \sqrt{\hat{D}}/2}} \\
\le (1 - \lambda t)^{-2\hat{D}} e^{-\epsilon t \sqrt{\hat{D}}/2} \\
= 2^{2\hat{D}} e^{-\epsilon \sqrt{\hat{D}}/(4\lambda)} \\
= \exp \left( \hat{D} \log_e 4 - \epsilon \sqrt{\hat{D}}/(4\lambda) \right) .
\]

Provided that \( \lambda \le \epsilon / \left( 2^4 \log_e 2\sqrt{\hat{D}} \right) \) this is bounded by \( \exp \left( -\epsilon \sqrt{\hat{D}}/(8\lambda) \right) \). Moreover, if \( \lambda \le \epsilon \sqrt{\hat{D}} / \left( 8 \log_e \frac{2}{\delta} \right) \), then the claim follows.

To relate f* and f̃, we exploit smoothness of regularized ERM with respect to small changes in the RKHS itself. We begin with a technical lemma that we will use to exploit the convexity of the regularized empirical risk functional; it shows a kind of converse to Remark 7.14 relating that functions with risks that are close in value will also be close in proximity.

### Lemma 7.19

Let R be a functional on Hilbert space H satisfying R[f] ≥ R[f*] + a/2 ||f - f*||_H^2 for some a > 0, f* ∈ H, and all f ∈ H. Then R[f] ≤ R[f*] + ε implies ||f - f*||_H ≤ √(2ε/a), for all ε > 0, f ∈ H.

**Proof** By assumption and the antecedent

\[
\|f - f^*\|_{\mathcal{H}}^2 \le \frac{2}{a} (R[f] - R[f^*]) \\
\le \frac{2}{a} (R[f^*] + \epsilon - R[f * ]) \\
= \frac{2\epsilon}{a} .
\]

Taking square roots of both sides yields the result.

Provided that the kernels k, k̂ are uniformly close, we now show that f* and f̃ are pointwise close, using the insensitivity of regularized ERM to feature mapping perturbation.

### Lemma 7.20

Let H be an RKHS with translation-invariant kernel k, and let Ĥ be the random RKHS corresponding to feature map (7.6) induced by k. Let C be a positive scalar and loss ℓ(y, ŷ) be convex and L-Lipschitz continuous in ŷ. Consider the regularized empirical risk minimizers in each RKHS, where R_emp[f] = n^{-1} \sum_{i=1}^N \ell(y^{(i)}, f(\mathbf{x}^{(i)})),

\[
f^* \in \operatorname{argmin}_{f \in \mathcal{H}} \left[ C R_{\text{emp}}[f] + \frac{1}{2} \|f\|_{\mathcal{H}}^2 \right].
\]

\[
g^* \in \operatorname{argmin}_{g \in \hat{\mathcal{H}}} \left[ C R_{\text{emp}}[g] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2 \right].
\]

Let M ⊆ \Re^D be any set containing x^{(1)}, ..., x^{(N)}. For any ε > 0, if the dual variables from both optimizations have ℓ1-norms bounded by some Λ > 0 and \|k - \hat{k}\|_{\infty; \mathcal{M}} \le \min \left\{ 1, \frac{\epsilon^2}{2^2 (\Lambda + 2\sqrt{(CL+\Lambda/2)^\Lambda})^2} \right\} then \|f^* - g^*\|_{\infty; \mathcal{M}} \le \epsilon/2.

**Proof** Define regularized empirical risk functional R_reg[f] = C R_emp[f] + ||f||^2 / 2, for the appropriate RKHS norm. Let minimizer f* ∈ H be given by parameter vector α*, and let minimizer g* ∈ Ĥ be given by parameter vector β*. Let g_{α*} = \sum_{i=1}^N \alpha_i^* y^{(i)} \hat{\phi}(\mathbf{x}^{(i)}) and f_{β*} = \sum_{i=1}^N \beta_i^* y^{(i)} \phi(\mathbf{x}^{(i)}) denote the images of f* and g* under the natural mapping between the spans of the data in RKHS's Ĥ and H, respectively. We will first show that these four functions have arbitrarily close regularized empirical risk in their respective RKHS, and then that this implies uniform proximity of the functions themselves. Observe that for any g ∈ Ĥ,

\[
R^{\hat{\mathcal{H}}}_{\text{reg}}[g] = C R_{\text{emp}}[g] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2
\ge C \langle \partial_g R_{\text{emp}}[g^*], g - g^* \rangle_{\hat{\mathcal{H}}} + C R_{\text{emp}}[g^*] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2
= \langle \partial_g R^{\hat{\mathcal{H}}}_{\text{reg}}[g^*], g - g^* \rangle_{\hat{\mathcal{H}}} - \langle g^*, g - g^* \rangle_{\hat{\mathcal{H}}} + C R_{\text{emp}}[g^*] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2 .
\]

The inequality follows from the convexity of R_emp[·] and holds for all elements of the subdifferential ∂_g R_emp[g*]. The subsequent equality holds by ∂_g R^{\hat{\mathcal{H}}}_{\text{reg}}[g] = C ∂_g R_emp[g] + g. Now since 0 ∈ ∂_g R^{\hat{\mathcal{H}}}_{\text{reg}}[g*], it follows that

\[
R^{\hat{\mathcal{H}}}_{\text{reg}}[g] \ge C R_{\text{emp}}[g^*] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2 - \langle g^*, g - g^* \rangle_{\hat{\mathcal{H}}}
= R^{\hat{\mathcal{H}}}_{\text{reg}}[g^*] + \frac{1}{2} \|g\|_{\hat{\mathcal{H}}}^2 - \langle g^*, g \rangle_{\hat{\mathcal{H}}} + \frac{1}{2} \|g^*\|_{\hat{\mathcal{H}}}^2
= R^{\hat{\mathcal{H}}}_{\text{reg}}[g^*] + \frac{1}{2} \|g - g^*\|_{\hat{\mathcal{H}}}^2 .
\]
