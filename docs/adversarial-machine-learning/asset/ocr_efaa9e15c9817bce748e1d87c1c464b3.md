```
\(\text{SetSearch}\left(\mathbb{P}, \mathbb{Q} = \{ \mathbf{x}^{(j)} \in \mathbb{P} \}, \mathbf{x}^4, \mathbf{x}^-, \mathbf{C}_0^+, C_0^-, \epsilon\right)\)

\(C_t \leftarrow \sqrt{C_t^- \cdot C_t^+}\)
\([\mathbf{x}^\star, \mathbb{P}', \mathbb{Q}'] \leftarrow \text{IntersectSearch} \left(\mathbb{P}, \mathbb{Q}, \mathbf{x}^4, C_t\right)\)
if intersection found then begin
\(C_{t+1}^- \leftarrow A (\mathbf{x}^\star - \mathbf{x}^4)\) and \(C_{t+1}^+ \leftarrow C_t^+\)
\(\mathbb{P} \leftarrow \mathbb{P}'\) and \(\mathbb{Q} \leftarrow \mathbb{Q}'\)
else

end if

end while
```

# LEMMA 8.9 The largest \(\ell_p\) (\(p > 1\)) ball enclosed within a \(C\)-cost \(\ell_1\) ball has a cost of \(C \cdot D^{\frac{1-p}{p}}\) and for \(p = \infty\) the cost is \(C \cdot D^{-1}\).

Proof By symmetry, the point \(\mathbf{x}^\star\) on the simplex \(\left\{ \mathbf{x} \in \Re^D \middle| \sum_{i=1}^D x_i = 1, x_i \ge 0 \forall i \right\}\) that minimizes the \(\ell_p\) norm for any \(p > 1\) is

```
\(\mathbf{x}^\star = \frac{1}{D} \left( 1, 1, \dots, 1 \right).\)
```

The \(\ell_p\) norm (cost) of the minimizer is

```
\(\left\| \mathbf{x}^\star \right\|_p = \frac{1}{D} \left( \sum_{i=1}^D 1^p \right)^{1/p}\)
\(= \frac{1}{D} D^{1/p}\)
\(= D^{\frac{1-p}{p}}\)
```
