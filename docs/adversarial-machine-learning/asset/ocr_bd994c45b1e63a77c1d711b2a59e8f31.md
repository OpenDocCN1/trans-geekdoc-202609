# 7.7.1 Upper Bounds

Combining Theorems 7.10 and 7.11 immediately establishes the upper bound on the optimal differential privacy \(\beta^*\) for mechanisms achieving a given desired level \((\epsilon, \delta)\) of usefulness.

COROLLARY 7.23 The optimal differential privacy \(\beta^*\) among all mechanisms that are \((\epsilon, \delta)\)-useful with respect to the SVM with finite \(F\)-dimensional feature mapping inducing bounded norms \(k(\mathbf{x}, \mathbf{x}) \le \kappa^2\) and \(\|\phi(\mathbf{x})\|_\infty \le \Phi\) for all \(\mathbf{x} \in \Re^D\), hinge loss, parameter \(C > 0\), on \(N\) training, is at most

\(\beta^* \le \frac{8\kappa \Phi C \left( F \log_e 2 + \log_e \frac{1}{\delta} \right)}{N \epsilon}\)
\(= \mathcal{O} \left( \frac{C}{\epsilon N} \log \frac{1}{\delta} \right) \).

Proof The proof is a straightforward calculation for general \(L\)-Lipschitz loss. In the general case the bound has the numerator leading coefficient \(8\kappa \Phi C L\). The result then follows from the fact that hinge loss is 1-Lipschitz on \(\Re\): i.e., \(\partial_y \ell = \mathbf{1}[1 \ge y\hat{y}] \le 1\).

Observe that \(\Phi \ge \kappa / \sqrt{F}\), so \(\kappa\) could be used in place of \(\Phi\) to simply the result's statement; however, doing so would yield a slightly looser bound. Also note that by this result, if we set \(C = \sqrt{N}\) (needed for universal consistency, see Remark 7.5) and fix \(\beta\) and \(\delta\), then the error due to preserving privacy is on the same order as the error in estimating the “true” parameter \(\mathbf{w}\).

Recall the dual program for learning under hinge loss from Section 7.3 repeated here for convenience:

\(\max_{\mathbf{a} \in \mathbb{N}^N} \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y^{(i)} y^{(j)} k\left(\mathbf{x}^{(i)}, \mathbf{x}^{(j)}\right)\)
\(\text{s.t. } 0 \le \alpha_i \le \frac{C}{N} \forall i \in [n].\)

We split the calculation of the upper bound for the translation-invariant kernel case into the following two steps because they are slightly more involved than the finite-dimensional feature mapping case.

COROLLARY 7.24 Consider any database \(\mathbb{D}\) of size \(N\), scalar \(C > 0\), and translation-invariant kernel \(k\). For any \(\beta > 0\) and \(\hat{D} \in \Re\), PRIVATESVM run on \(\mathbb{D}\) with hinge loss, noise parameter \(\lambda \ge \frac{2^{5+\epsilon}\sqrt{D}}{\beta N}\), approximation parameter \(\hat{D}\), and regularization parameter \(C\) guarantees \(\beta\)-differential privacy. Moreover, for any compact set \(\mathcal{M} \subseteq \Re^D\) containing \(\mathbb{D}\), and scalers \(\epsilon > 0\) and \(\delta \in (0, 1)\), PRIVATESVM run on \(\mathbb{D}\) with hinge loss, kernel \(k\), noise parameter \(\lambda \le \min \left\{ \frac{\epsilon}{2^4 \log_e 2^\sqrt{D}}, \frac{\epsilon \sqrt{\delta}}{8 \log_e \frac{2}{3}} \right\}\), approximation parameter \(\hat{D} \ge \frac{4(D+2)}{\theta(\epsilon)} \log_e \left( \frac{2^9 (\sigma_{pr}(\text{diam}(\mathcal{M}))^2}{\delta \theta(\epsilon)} \right)\) with \(\theta(\epsilon) = \min \left\{ 1, \frac{\epsilon^4}{2^{12} c^4} \right\}\), and parameter \(C\) is \((\epsilon, \delta)\)-useful with respect to hinge-loss SVM run on \(\mathbb{D}\) with kernel \(k\) and parameter \(C\).
