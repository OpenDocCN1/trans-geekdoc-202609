relation from Equation (D.3), we bound the number of queries, \(Q_1\), used in case 1 by
\[
Q_1 = \sum_{t \in C_1} (K + |\mathbb{W}_t| - 1)\\
\le \sum_{t \in C_1} (K + |\mathbb{W}| - 1)\\
= \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot (K + |\mathbb{W}| - 1)\\
\le \left( \frac{L_\epsilon}{K} + 1 \right) \cdot K + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot (|\mathbb{W}| - 1)\\
= L_\epsilon + K + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot (|\mathbb{W}| - 1) .\\
\]

For each case 2 iteration, the adversary makes exactly \(K + E_t\) queries, and each eliminates \(E_t \ge 1\) directions; hence, \(|\mathbb{W}_{t+1}| = |\mathbb{W}_t| - E_t\). The malicious classifier will always make \(E_t = 1\) in every case 2 instance since that maximally limits how much the adversary gains. Nevertheless, since case 2 requires the elimination of at least one direction, the following bound applies: \(|C_2| \le |\mathbb{W}| - 1\). Moreover, regardless of the choice of \(E_t\), \(\sum_{t \in C_2} E_t \le |\mathbb{W}| - 1\) since each direction can be eliminated no more than once and at least one direction must remain. Thus,
\[
Q_2 = \sum_{i \in C_2} (K + E_t)\\
\le |C_2| \cdot K + |\mathbb{W}| - 1\\
\le (|\mathbb{W}| - 1)(K + 1) .\\
\]

The total number of queries used by Algorithm 8.3 is
\[
Q = Q_1 + Q_2 \le L_\epsilon + K + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot (|\mathbb{W}| - 1) + (|\mathbb{W}| - 1)(K + 1)\\
= L_\epsilon + K + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot |\mathbb{W}| - \left\lfloor \frac{L_\epsilon}{K} \right\rfloor + K \cdot |\mathbb{W}| - K + |\mathbb{W}| - 1\\
= L_\epsilon + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot |\mathbb{W}| + K \cdot |\mathbb{W}| + |\mathbb{W}| - \left\lfloor \frac{L_\epsilon}{K} \right\rfloor - 1\\
\le L_\epsilon + \left\lfloor \frac{L_\epsilon}{K} \right\rfloor \cdot |\mathbb{W}| + K \cdot |\mathbb{W}| + |\mathbb{W}|\\
= L_\epsilon + \left( \left\lfloor \frac{L_\epsilon}{K} \right\rfloor + K + 1 \right) |\mathbb{W}|\\
\]

Finally, choosing \(K = \lceil \sqrt{L_\epsilon} \rceil\) minimizes this expression. Substituting this \(K\) into \(Q\)’s bound and using the bound \(L_\epsilon / \lceil \sqrt{L_\epsilon} \rceil \le \sqrt{L_\epsilon}\), yield
\[
Q \le L_\epsilon + \left( 2 \lceil \sqrt{L_\epsilon} \rceil + 1 \right) |\mathbb{W}|\\
\]
so \(Q = \mathcal{O} \left( L_\epsilon + \sqrt{L_\epsilon} |\mathbb{W}| \right)\).
