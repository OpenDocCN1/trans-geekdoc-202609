if the adversary fails to achieve a \(\phi_\epsilon^*\)-K-covering of \(\mathbb{X}\) of the \(C_0^-\)-hypersphere, the alternative classifier \(g\) has \(MAC (g, A_2) < C_0^- \cos \phi_\epsilon^* = \frac{C_0^-}{1+\epsilon}\) and any \(\mathbf{x} \in \epsilon\text{-}IMAC^{(*)} (g, A_2)\) must have

```
A_2 \left( \mathbf{x} - \mathbf{x}^4 \right) \le (1 + \epsilon)MAC < (1 + \epsilon)\frac{C_0^-}{1 + \epsilon} = C_0^-
```

whereas any \(\mathbf{y} \in \epsilon\text{-}IMAC^{(*)}(f, A)\) must have \(A \left( \mathbf{y} - \mathbf{x}^4 \right) \ge C_0^-\) . Thus, there are no common points in the \(\epsilon\text{-}IMAC^{(*)}\) sets of these consistent classifiers (i.e., \(\epsilon\text{-}IMAC^{(*)} (f, A) \cap \epsilon\text{-}IMAC^{(*)} (g, A) = \emptyset\) ), and so the adversary would have failed to ensure \(\epsilon\)-multiplicative optimality. Thus, an \(\phi_\epsilon^*\)-K-covering of \(\mathbb{X}\) is necessary for \(\epsilon\)-multiplicative optimality for \(\ell_2\) costs. Moreover, from our definition of \(\phi_\epsilon^*\), for any \(\epsilon \in (0, \infty)\), \(\phi^* \in \left(0, \frac{\pi}{2}\right)\) and thus, Lemma A.1 is applicable for all \(\epsilon\). From Lemma A.1, to achieve an \(\phi_\epsilon^*\)-K-covering of \(\mathbb{X}\) requires at least

```
M \ge \left( \frac{1}{\sin \phi_\epsilon^*} \right)^{D-2}
```

queries. Using the trigonometric identity \(\sin \left( \arccos(x) \right) = \sqrt{1 - x^2}\), and substituting for \(\phi_\epsilon^*\) yields the following bound on the number of queries required for a given multiplicative accuracy \(\epsilon\) :

```
M \ge \left( \frac{1}{\sin \left( \arccos \left( \frac{1}{1+\epsilon} \right) \right)} \right)^{D-2}
\ge \left( \frac{(1 + \epsilon)^2}{(1 + \epsilon)^2 - 1} \right)^{\frac{D-2}{2}} .
```
