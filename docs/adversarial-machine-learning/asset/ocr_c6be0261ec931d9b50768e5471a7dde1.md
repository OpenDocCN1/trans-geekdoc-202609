Each database has $x_N = M - m$, with $y^{(N)} = -1$ for $\mathbb{D}^{(1)}$ and $y^{(N)} = 1$ for $\mathbb{D}^{(2)}$. In what follows we use subscripts to denote an example's parent database, so $(x_{i,j}, y^{(i,j)})$ is the $j^{th}$ example from $\mathbb{D}^{(i)}$. Consider the result of running primal SVM on each database:

```
$$w^*_1 = \underset{w \in \Re}{\text{argmin}} \left[ \frac{1}{2} w^2 + \frac{C}{N} \sum_{i=1}^N (1 - y^{(1,i)} w x_{1,i})_+ \right] \quad w^*_2 = \underset{w \in \Re}{\text{argmin}} \left[ \frac{1}{2} w^2 + \frac{C}{N} \sum_{i=1}^N (1 - y^{(2,i)} w x_{2,i})_+ \right].$$
```

Each optimization is strictly convex and unconstrained, so the optimizing $w^*_1, w^*_2$ are characterized by the first-order KKT conditions $0 \in \partial_w f_i(w)$ for $f_i$ being the objective function for learning on $\mathbb{D}^{(i)}$, and $\partial_w$ denoting the subdifferential operator. ```


where

```
$$\tilde{\mathbf{1}}[x] = \begin{cases} \{0\}, & \text{if } x < 0 \\ [0, 1], & \text{if } x = 0 \\ \{1\}, & \text{if } x > 0 \end{cases}$$
```

is the subdifferential of $(x)_+$.
