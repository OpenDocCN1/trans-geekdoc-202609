With this negative sensitivity result in hand, we can lower bound the optimal differential privacy for any mechanism approximating the SVM with hinge loss.

**THEOREM 7.27** (Lower bound on optimal differential privacy for linear SVM) _For any_ \(C > 0, N > 1, \delta \in (0, 1)\), _and_ \(\epsilon \in \left(0, \frac{\sqrt{C}}{2N}\right)\), _the optimal differential privacy for the hinge-loss SVM with linear kernel is lower bounded by_ \(\log_e \frac{1-\delta}{\delta} = \Omega \left(\log \frac{1}{\delta}\right)\).

**Proof** Consider \((\epsilon, \delta)\)-useful mechanism \(\hat{M}\) with respect to SVM learning mechanism \(M\) with parameter \(C > 0\), hinge loss, and linear kernel on \(N\) training examples, where \(\delta > 0\) and \(\frac{\sqrt{C}}{2N} > \epsilon > 0\). By Lemma 7.26 there exists a pair of neighboring databases \(\mathbb{D}^{(1)}, \mathbb{D}^{(2)}\) on \(N\) entries, such that \(\|f^*_1 - f^*_2\|_\infty > 2\epsilon\) where \(f^*_i = f_{\mathcal{M}(\mathbb{D}^{(i)})}\) for each \(i \in [2]\). Let \(\hat{f}_i = f_{\hat{M}(\mathbb{D}^{(0)})}\) for each \(i \in [2]\). Then by the utility of \(\hat{M}\),

\(\text{Pr} \left( \hat{f}_1 \in \mathcal{B}^\infty_\epsilon (f^*_1) \right) \ge 1 - \delta, \tag{7.11}\)

\(\text{Pr} \left( \hat{f}_2 \in \mathcal{B}^\infty_\epsilon (f^*_1) \right) \le \text{Pr} \left( \hat{f}_2 \notin \mathcal{B}^\infty_\epsilon (f^*_2) \right) < \delta. \tag{7.12}\)

Let \(\hat{\mathcal{P}}_1\) and \(\hat{\mathcal{P}}_2\) be the distributions of \(\hat{M} \left(\mathbb{D}^{(1)}\right)\) and \(\hat{M} \left(\mathbb{D}^{(2)}\right)\), respectively, so that \(\hat{\mathcal{P}}_i(t) = \text{Pr} \left( \hat{M} \left(\mathbb{D}^{(i)}\right) = t \right)\). Then by Inequalities (7.11) and (7.12)

\(\text{E}_{T \sim \mathcal{P}_1} \left[ \frac{d\mathcal{P}_2(T)}{d\mathcal{P}_1(T)} \bigg| T \in \mathcal{B}^\infty_\epsilon (f^*_1) \right] = \frac{\int_{\mathcal{B}^\infty_\epsilon (f^*_1)} \frac{d\mathcal{P}_2(t)}{d\mathcal{P}_1(t)} d\mathcal{P}_1(t)}{\int_{\mathcal{B}^\infty_\epsilon (f^*)} d\mathcal{P}_1(t)} \le \frac{\delta}{1 - \delta}.\)

Thus there exists a \(t\) such that \(\log \frac{\text{Pr}(\hat{M}(\mathbb{D}^{(1)})=t)}{\text{Pr}(\hat{M}(\mathbb{D}^{(2)})=t)} \ge \log \frac{1-\delta}{\delta} = \Omega \left(\log \frac{1}{\delta}\right)\).
