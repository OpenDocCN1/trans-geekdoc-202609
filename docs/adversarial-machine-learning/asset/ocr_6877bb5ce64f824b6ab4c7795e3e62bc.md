ALGORITHM 8.3 K-STEP MULTILINESEARCH
KMLS (W, x^4, x^-, C_0^+, C_0^-, \epsilon, K)
x^* <- x^-
t <- 0
while C_t^- / C_t^+ > 1 + \epsilon do begin
Choose a direction w in W
B^+ <- C_t^+
B^- <- C_t^-
for K steps do begin
B <- sqrt(B^+ . B^-)
Query: f_w <- f(x^4 + B . w)
if f_w = "+" then B^+ <- B
else B^- <- B and x* <- x^4 + B . w
end for
for all i in W \\ {w} do begin
Query: f_i^t <- f(x^4 + (B^+) . i)
if f_i^t = "-" then begin
x* <- x^4 + (B^+) . i
Prune k from W if f_k^t = "+"
break for-loop
end if
end for
C_{t+1}^- <- B^-
if \forall i in W f_i^t = "+" then C_{t+1}^+ <- B^+
else C_{t+1}^- <- B^+
t <- t + 1
end while
return: x*

Theorems 8.6 and 8.7 show that \(\eta\)-additive optimality and \(\epsilon\)-multiplicative optimality require \(\Omega \left( L_\eta^{(+)} + D \right)\) and \(\Omega \left( L_\epsilon^{(*)} + D \right)\) queries, respectively. Thus, the K-STEP MULTILINESEARCH algorithm (Algorithm 8.3) has close to the optimal query complexity for weighted \(\ell_1\)-costs with its \(\mathcal{O} \left( L_\epsilon + \sqrt{L_\epsilon} D \right)\) queries. This lower bound also applies to any \(\ell_p\) cost with \(p > 1\), but in Section 8.3 we present tighter lower bounds for \(p > 1\) that substantially exceed this result for some ranges of \(\epsilon\) and any range of \(\eta\).
