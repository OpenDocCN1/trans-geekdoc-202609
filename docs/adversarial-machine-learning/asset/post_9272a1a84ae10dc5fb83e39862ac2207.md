
sequence $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M^{(1)}, \infty)}$ such that $D \left( \boldsymbol{\alpha}^* \right) = D_N^* \left( M^{(1)}, \infty \right)$. However, we also have $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M^{(2)}, \infty)}$; that is, any optimal sequence from $\mathcal{A}^{(M^{(1)}, \infty)}$ is also in the space $\mathcal{A}^{(M^{(2)}, \infty)}$ but uses at most $M^{(1)} < M^{(2)}$ of its total attack capacity. Moreover, since $\sum_t \alpha_t^* \le M^{(1)}$ and all sequences consist of elements $\alpha_t^* \in \mathfrak{N}_0$, there must exist a last non-zero index $\tau \in \mathfrak{N}$ of $\alpha_\tau^*$; i.e., for all $t > \tau, \alpha_t^* = 0$. From this, we construct an alternate sequence $\boldsymbol{\alpha}'$, which is identical to $\boldsymbol{\alpha}^*$ except that we add the excess attack capacity to its last non-zero element: $\alpha'_\tau = \alpha_\tau^* + m$ where $m = M^{(2)} - M^{(1)} > 0$. The difference in the distances of these two sequences is simply the difference in their final non-zero contributions:

```
D \left( \boldsymbol{\alpha}^* \right) - D \left( \boldsymbol{\alpha}' \right) = \delta_\tau \left( \boldsymbol{\alpha}^* \right) - \delta_\tau \left( \boldsymbol{\alpha}' \right)
= \frac{\alpha_\tau^*}{M^{(1)} + N} - \frac{\alpha_\tau^* + m}{M^{(2)} + N}
= \frac{\alpha_\tau^* M^{(2)} + \alpha_\tau^* N - \alpha_\tau^* M^{(1)} - \alpha_\tau^* N - m M^{(1)} - m N}{\left( M^{(1)} + N \right) \left( M^{(2)} + N \right)}
= \frac{\left( \alpha_\tau^* - M^{(1)} - N \right) m}{\left( M^{(1)} + N \right) \left( M^{(2)} + N \right)} ,
```

where $m > 0$ and $M^{(2)} > M^{(1)} \ge 0$. All terms in this ratio are *positive* except the term $\left( \alpha_\tau^* - M^{(1)} - N \right)$, which is *negative* since $\alpha_\tau^* \le M^{(1)}$ and $N \ge 1$. Thus, the above difference is negative and $D_N^* \left( M^{(2)}, \infty \right) \ge D \left( \boldsymbol{\alpha}' \right) > D \left( \boldsymbol{\alpha}^* \right) = D_N^* \left( M^{(1)}, \infty \right)$. This proof also holds for any fixed $T \ge 1$, thus also showing that $D_N^* \left( M^{(2)}, T \right) > D_N^* \left( M^{(1)}, T \right)$. Second, for $N = 0$, we demonstrate strict monotonicity of $D_0^* \left( \cdot, \infty \right)$ and $D_0^* \left( \cdot, T \right)$ for any $T > 1$. Since $D_0^* \left( M, \infty \right) \ge 0$ for any $M \in \mathfrak{N}_0$, and $D_0^* \left( M, \infty \right) = 0$ if and only if $M = 0$, we have that $D_0^* \left( M, \infty \right) > D_0^* \left( 0, \infty \right)$ for any $M > 0$, as required. In the case $M^{(2)} > M^{(1)} = 1$, every sequence in $\mathcal{A}^{(1, \infty)}$ (or $\mathcal{A}^{(1, T)}$) achieves $D_0^* \left( 1, \infty \right) = D_0^* \left( 1, T \right) = 1$. Further the sequence $\left( 1, 1 \right)$ is in $\mathcal{A}^{(M^{(2)}, \infty)}$ for all $M^{(2)} > 1$ (and also in $\mathcal{A}^{(M^{(2)}, T)}$ for any $T > 1$), and it achieves a distance of $1 + \frac{1}{2}$, thus exceeding $D_0^* \left( 1, \infty \right)$. Thus, it again follows that $D_0^* \left( M^{(2)}, \infty \right) > D_0^* \left( 1, \infty \right)$ and for any fixed $T > 1, D_0^* \left( M^{(2)}, T \right) > D_0^* \left( 1, T \right)$. Finally, for $M^{(2)} > M^{(1)} > 1$, we use a similar proof as was used above for $N > 0$. Again, there is a sequence $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M^{(1)}, \infty)}$ such that $D \left( \boldsymbol{\alpha}^* \right) = D_0^* \left( M^{(1)}, \infty \right)$ and we take $\tau$ to be index of the last non-zero element of $\boldsymbol{\alpha}^*$. We again construct an alternate sequence $\boldsymbol{\alpha}'$ that is identical to $\boldsymbol{\alpha}^*$ except the excess attack capacity is added to its last non-zero element: $\alpha'_\tau = \alpha_\tau^* + m$ where $m = M^{(2)} - M^{(1)} > 0$. Then, as above, in examining the difference in the distances of these two sequences, it can be shown that

```
D \left( \boldsymbol{\alpha}^* \right) - D \left( \boldsymbol{\alpha}' \right) = \frac{\left( \alpha_\tau^* - M^{(1)} \right) m}{M^{(1)} \cdot M^{(2)}} ,
```

where $m > 0$ and $M^{(2)} > M^{(1)} > 1$. Again, all terms in the fraction are *positive* except the term $\left( \alpha_\tau^* - M^{(1)} \right)$. But, by Lemma B.2, $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M^{(1)}, \infty)}$ for $M^{(1)} > 1$ cannot be optimal unless $\alpha_\tau^* < M^{(1)}$. Thus the above difference is negative and $D_0^* \left( M^{(2)}, \infty \right) \ge D \left( \boldsymbol{\alpha}' \right) > D \left( \boldsymbol{\alpha}^* \right) = D_0^* \left( M^{(1)}, \infty \right)$. This proof construction also holds for any fixed duration $T > 1$, thus also showing that $D_0^* \left( M^{(2)}, T \right) > D_0^* \left( M^{(1)}, T \right)$.

Thirdly, we show that $D_N^*(M, T)$ is strictly monotonically increasing with respect to $T \in \{1, \dots, M\}$; that is, for any fixed $N \in \mathbb{N}_0$ and $M \in \mathfrak{N}$ and $\forall T_1 < T_2 \in \{1, \dots, M\}$, we claim $D_N^*(M, T_1) < D_N^*(M, T_2)$.

For $T_1, T_2 \le M$, by Definition 4.10 of $D_N^*(M, T)$, there exists a sequence $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M, T_1)}$ such that $D(\boldsymbol{\alpha}^*) = D_N^*(M, T_1)$. However, since $T_2 > T_1$, we also have $\boldsymbol{\alpha}^* \in \mathcal{A}^{(M, T_2)}$; that is, any optimal sequence from $\mathcal{A}^{(M, T_1)}$ is also in the space $\mathcal{A}^{(M, T_2)}$ but has a trailing sequence of zeros: $\alpha_{T_1+1}^* = \dots = \alpha_{T_2}^* = 0$. Alternatively, there is some last index $\tau < T_2$ such that $\alpha_\tau^* > 0$ and $\alpha_t^* = 0$ for all $t > \tau$.

In fact, this $\tau^{\text{th}}$ element must be greater than 1 since, by Theorem 4.14, the non-zero elements of $\boldsymbol{\alpha}^*$ must be non-decreasing. Thus, either $\alpha_\tau^* > 1$ or all previous elements must be in $\{0, 1\}$. However, since $\tau < T_2 \le M$, such a sequence can have at most $M - 1$ elements, but the first part of this theorem already showed that such a sequence is not optimal. Hence, $\alpha_\tau^* > 1$.

Using this fact, we can construct an alternative sequence $\boldsymbol{\alpha}' \in \mathcal{A}^{(M, T_2)}$ that moves one attack point from the $\tau^{\text{th}}$ element of $\boldsymbol{\alpha}^*$ to its $(\tau+1)^{\text{th}}$ element:

```
\(\alpha'_t = \begin{cases} \alpha_t^*, & \text{if } t < \tau \\ \alpha_t^* - 1, & \text{if } t = \tau \\ 1, & \text{if } t = \tau + 1 \\ \alpha_{t-1}^*, & \text{if } t > \tau + 1 \end{cases}\)
```

By design, $\boldsymbol{\alpha}^*$ and $\boldsymbol{\alpha}'$ are $(\tau, 1)$-differing sequences and Lemma B.1 yields

```
\(\Delta_{\boldsymbol{\alpha}^*, \boldsymbol{\alpha}'} = \frac{(\mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha'_\tau) \cdot \alpha'_\tau \cdot \alpha^*_{\tau+1} - (\mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha^*_\tau) \cdot \alpha'_\tau \cdot \alpha'_{\tau+1}}{(\mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha^*_\tau) \left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha'_\tau \right) \left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha^*_\tau + \alpha^*_{\tau+1} \right)}\)
\(= \frac{-1 \cdot \left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha'_\tau \right) \cdot (\alpha^*_\tau - 1)}{\left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha^*_\tau \right) \left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha'_\tau \right) \left( \mu_{\tau-1}^{(\boldsymbol{\alpha}^*)} + \alpha^*_\tau + \alpha^*_{\tau+1} \right)}\)
```

in which $\mu_t^{(\alpha^\text{opt})} = N + \sum_{\ell=1}^t \alpha_\ell^{opt}$. This difference is negative, from which we conclude that $D(\boldsymbol{\alpha}^*) < D(\boldsymbol{\alpha}')$. This contradicts assumption (B.3) that $\boldsymbol{\alpha}^*$ is optimal in $\mathcal{A}^{(M, T_2)}$; i.e., we have shown there is a sequence in $\mathcal{A}^{(M, T_2)}$ whose distance exceeds $D_N^*(M, T_1)$. Thus, $D_N^*(M, T)$ is strictly monotonically increasing for $T \le M$.

Finally, to see that $D_N^*(M, T) = D_N^*(M, \infty)$ for $T \ge M$, any sequence in $\mathcal{A}^{(M, T)}$ must have at least $M - T$ zero elements. As we showed in Theorem 4.12, the distance of a sequence is invariant to the placement of these zero elements so, without loss of generality, we can place them at the end. Thus, any sequence in $\mathcal{A}^{(M, T)}$ achieves the same distance as a sequence in $\mathcal{A}^{(M, M)}$, and the optimal distances achieved within these two spaces is equal.

Notice that the above argument does not hold for the space $\mathcal{B}^{(M, \infty)}$ of all positive-real-valued sequences with total mass of $M$ since there need not be a greatest non-zero element in such a sequence. However, optimality is not well-defined on such a space. This proof does, however, extend directly to sequences in $\mathcal{B}^{(M, T)}$ since the finite attack duration $T$ implies the existence of a greatest non-zero element.
