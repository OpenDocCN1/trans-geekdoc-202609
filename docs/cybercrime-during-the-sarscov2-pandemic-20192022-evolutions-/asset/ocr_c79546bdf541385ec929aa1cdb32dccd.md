# 1.2.3. Leveraging weekly data: the case of China

The data used for monitoring the evolution of cybercrime in China have been drawn from CNCERT. They have been published weekly since the end of July 2017. These weekly data involve the following variables:

+   - the number of infected computers in China (controlled by Trojans or botnets);
- the number of defaced websites in China;
- the number of backdoored websites in China;
- the number of phishing web pages targeting sites in China;
- the number of new vulnerabilities (including low-, medium- and high-risk vulnerabilities);
- the number of network security incidents handled by the CNCERT.
