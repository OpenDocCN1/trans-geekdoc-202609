

# 引言

是网络犯罪增加的受害者，还是说网络犯罪分子的战术发生了变化？本章依赖探索性研究来研究南非的网络犯罪趋势，同时试图对这两个问题提供一些答案。本文考虑了国际排名、国家法律法规和事件报告以分析犯罪趋势。南非对网络犯罪和安全事件缺乏官方报告是一个局限性。所需信息提取自事件报告、行业报告以及说明趋势的白皮书。
