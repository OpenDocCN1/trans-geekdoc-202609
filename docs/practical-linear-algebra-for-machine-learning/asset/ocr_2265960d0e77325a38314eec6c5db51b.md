# Moore–Penrose Pseudoinverse

Before, digging into how SVD can help us with pseudoinverse calculations, let’s talked about what is a Pseudoinverse?

Assuming we have the matrix of **A** ∈ ℂ^{M×N}. Then, we have a pseudoinverse of **A**, defined as **A**⁺ ∈ ℂ^{M×N}, that satisfies all of the following criteria:

+   - **A A**⁺ **A** = **A**
+   - **A**⁺ **A A**⁺ = **A**⁺
+   - (**A A**⁺)* = **A A**⁺
+   - (**A**⁺ **A**)* = **A**⁺ **A**

How we can *calculate the* **Pseudoinverse** *of a matrix using SVD*? If we have the SVD of a matrix **A** as **U Σ V***, then **A**⁺ can be calculated as below:

**A**⁺ = **V Σ**⁺ **U***

where Σ⁺ is the pseudoinverse of Σ and we create it by replacing each non-zero diagonal entry σ in Σ by 1/σ and transposing the resulting matrix.

# Matrix Rank Determination

Previously, the linear dependence and the matrix ranks were discussed. Now, as we have SVD, a more general approach compared to eigendecomposition, we can conclude the following directions.

**Matrix Rank:** Assume we have the SVD of a matrix **A** as **U Σ V***. The rank of **A** equals the number of non-zero singular values which is the number of non-zero diagonal elements in Σ.
