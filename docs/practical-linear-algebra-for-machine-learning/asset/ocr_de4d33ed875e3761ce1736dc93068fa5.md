# Definition

Assuming we have the square matrix of \(A \in \mathbb{R}^{N\times N}\). The nonzero vector \(\mathbf{v} \in \mathbb{R}^{N\times 1}\) is an eigenvector and scalar \(\lambda\) is its associated eigenvalue if we have:

\[A\mathbf{v}=\lambda\mathbf{v}\]

From the above definition, it is clear that if \(\mathbf{v}\) is an eigenvector, any vector \(\alpha\mathbf{v}\), \(\alpha \in \mathbb{R}\) is also an eigenvector with the same eigenvalue \(\lambda\). Therefore, if we have one eigenvector, then we have infinite ones!

![](bbox=[0.274, 0.347, 0.711, 0.529])

**Fig. 7.1.** Since \(\mathbf{v}\) is an eigenvector, any vector \(\alpha\mathbf{v}\) is also an eigenvector

Due to that, it is customary to only work with eigenvectors that have **unit norm**. It is simple to construct an eigenvector with the unit norm. Assume \(\mathbf{v}\) is our eigenvector. Then, the following vector is also an eigenvector with the unit norm:

\[\mathbf{w}=\alpha\mathbf{v}=\frac{1}{\lVert\mathbf{v}\rVert}\mathbf{v}\]

where \(\lVert\mathbf{v}\rVert\) is the norm of vector \(\mathbf{v}\). We usually consider the euclidean norm.
