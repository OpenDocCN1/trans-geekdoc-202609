# Matrix Inverse

Assume we have the square matrix **A** ∈ ℝ^{N×N}, it can be eigendecomposed and it is nonsingular. Therefore, we can calculate its inverse as below:

**A**^{-1} = **V** Λ^{-1} **V**^{-1}

Since Λ is diagonal, it inverse Λ^{-1} is also diagnoal and we can calculate it as:

Λ_{jj}^{-1} = 1 / λ_j

# 7.2.4 One Special Matrix Type and its Decomposition

We are interested to investigate a special kind of matrix: **Real symmetric matrix**. A real symmetric matrix is basically a symmetric matrix in which all elements belong to the space of real numbers ℝ.

For the **real symmetric matrix** of **A** ∈ ℝ^{N×N}, the eigenvalues are real numbers and we can choose eigenvectors in a way that they are orthogonal to each other. Then, we can factorize matrix **A** as below:

**A** = **Q** Λ **Q**^{T}

where **Q** is an orthogonal matrix whose columns are the eigenvectors of **A**, and Λ is a diagonal matrix whose diagonal elements are the corresponding eigenvalues, Λ_{jj} = λ_j.

# 7.2.5 Useful Properties

So far, the concepts and how we can decompose a matrix were explained. Let’s see how we can leverage it. Assuming **A** ∈ ℝ^{N×N}:

+   - The determinant of the matrix **A** equals the product of its eigenvalues.
+   - The trace of the matrix **A** equals the summation of its eigenvalues.
+   - If the eigenvalues of **A** are λ_i, and **A** is non-singular, then the eigenvalues of **A**^{-1} are simply 1/λ_i.
+   - The eigenvectors of **A**^{-1} are the same as the eigenvectors of **A**.
