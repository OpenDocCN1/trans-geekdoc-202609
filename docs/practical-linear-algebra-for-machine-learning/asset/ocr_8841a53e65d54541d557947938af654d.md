# 6.4. The Relationship With Matrix Rank

The linear dependence of vectors has been discussed so far. Assume we have the matrix $\mathbf{M} \in \mathbb{R}^{m\times n}$. The matrix has m rows and n columns. Let’s focus on the columns. The n columns form n vectors. The $j^{th}$ column is denoted with $\mathbf{M}_{:,j}$. So we have the set of n vectors {$\mathbf{M}_{:,1}, \mathbf{M}_{:,2}, \ldots, \mathbf{M}_{:,n}$} as columns. The size of the largest subset of {$\mathbf{M}_{:,1}, \mathbf{M}_{:,2}, \ldots, \mathbf{M}_{:,n}$} that its vectors are linearly independent, is called the **column rank** of the matrix $\mathbf{M}$. Considering the rows of $\mathbf{M}$, the size of the largest subset of rows that form a linearly independent set is called the **row rank** of the matrix $\mathbf{M}$.

We have the following properties for matrix ranks:

+   - For $\mathbf{M} \in \mathbb{R}^{m\times n}$, $\operatorname{rank}(\mathbf{M}) \leq \min(m,n)$. If $\operatorname{rank}(\mathbf{M}) = \min(m,n)$, the matrix $\mathbf{M}$ is full rank.
+   - For $\mathbf{M} \in \mathbb{R}^{m\times n}$, $\mathbf{N} \in \mathbb{R}^{n\times q}$, and $\mathbf{H}=\mathbf{MN} \in \mathbb{R}^{m\times q}$, $\operatorname{rank}(\mathbf{H}) \leq \min(\operatorname{rank}(\mathbf{M}),\operatorname{rank}(\mathbf{N}))$.
+   - For $\mathbf{M} \in \mathbb{R}^{m\times n}$, $\mathbf{N} \in \mathbb{R}^{m\times n}$, and $\mathbf{H}=\mathbf{M}+\mathbf{N} \in \mathbb{R}^{m\times n}$, $\operatorname{rank}(\mathbf{H}) \leq \operatorname{rank}(\mathbf{M}) + \operatorname{rank}(\mathbf{N})$.
