A_num_columns = A.shape[1]

C = np.matmul(A , B)

C = np.matmul(B , A)
print('C=BA= {}'.format(C))
```

The output will be:

```
Shape A is: (2, 3)
Shape B is: (3, 2)
C=AB= [[ 9 -6]
       [16 17]]
C=BA= [[11  6  0]
       [-3  6 -4]
       [37  3  9]]
```

You can clearly check that AB ≠ BA. Properties of matrix multiplication are as below:

+   - (AB)C = A(BC)
+   - A(B + C) = AB + AC
+   - (AB)^T = B^T A^T

You can check all the above properties with the following Python code:

```
