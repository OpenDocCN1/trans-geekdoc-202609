# 5.2.1 The Norm Function Properties

It is crucial to know the norms properties as we may need them in mathematical computation, especially mathematical proofs. A norm function ℒ(.) has the following properties:

+   1. If the norm is zero, then the vector is all zero as well: ℒ(v) = 0 ⇒ v = 0
+   2. ℒ(v + w) ≤ ℒ(v) + ℒ(w). This is called triangle inequality.
+   3. ∀β ∈ ℝ : ℒ(βv) = |β| ℒ(v)

# 5.2.2 Proving the Properties (Advanced)

Properties (1) is easy to prove. As the norm add the absolute values of vector elements to any power, if the norm is zero, the only possible answer is that all vector elements must be zero.

We can prove property (3) as below:

ℒ^q(βv) = (∑_k |β v_k|^q)^{1/q} = (|β|^q ∑_k |v_k|^q)^{1/q} = |β| (∑_k |v_k|^q)^{1/q} = |β| ℒ^q(v)
