# ## Appendix A: The Notations

| Notation | Meaning |
|---|---|
| $a$ | A scalar |
| **v** | vector |
| **A** | matrix |
| $\mathbb{A}$ | A set which can be the set of real number $\mathbb{R}$ for example |
| $\{1,\ldots,n\}$ | The set of all integers in the range of 1 to **n** |
| $v_i$ | Element $i$ of vector **v** |
| $v_{-i}$ | All vector **v** elements except $i$ |
| $A_{i,j}$ | The element of row $i$ and column $j$ from the matrix **A** |
| $A^T$ | The transpose of matrix **A** |
| $A^H$ | The conjugate transpose of matrix **A** |
| $\|v\|_p$ | The $\mathcal{L}^p$ norm of vector **v** |
