### 附录 A：符号说明

| 符号 | 含义 |
|---|---|
| $a$ | 一个标量 |
| **v** | 向量 |
| **A** | 矩阵 |
| $\mathbb{A}$ | 一个集合，例如可以是实数集 $\mathbb{R}$ |
| $\{1,\ldots,n\}$ | 从 1 到 **n** 的所有整数的集合 |
| $v_i$ | 向量 **v** 的第 $i$ 个元素 |
| $v_{-i}$ | 向量 **v** 除第 $i$ 个元素外的所有元素 |
| $A_{i,j}$ | 矩阵 **A** 中第 $i$ 行第 $j$ 列的元素 |
| $A^T$ | 矩阵 **A** 的转置 |
| $A^H$ | 矩阵 **A** 的共轭转置 |
| $\lVert v \rVert_p$ | 向量 **v** 的 $\mathcal{L}^p$ 范数 |
