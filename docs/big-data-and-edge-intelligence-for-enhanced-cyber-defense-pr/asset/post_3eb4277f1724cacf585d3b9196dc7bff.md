## 7.2.1 The Internet OF THINGS attacks, VULNERABILITIES, AND THREATS IN THE USER INTERFACE AND APPLICATION

The IoT has brought about a multitude of benefits by interconnecting devices, but it has also introduced various security challenges. Attacks, vulnerabilities, and threats in the user interface and application layer of IoT devices can pose significant risks. Some of these include the following:

- Denial-of-service (DoS) and distributed DDoS attacks: Attackers can overwhelm IoT devices or their applications with a flood of requests, causing them to become unresponsive or malfunction. In a DoS attack, a single source (one computer or a small number of systems) attempts to overwhelm a target server, network, or service by flooding it with an excessive amount of traffic [36]. This flood of traffic consumes the target’s resources, rendering it unable to respond to legitimate requests from users. DDoS attacks, on the other hand, handle multiple sources (a network of compromised devices, also) simultaneously.

**Bluesnarfing/Bluejackacking:** Bluesarfing and bluejacking are two distinct attacks, often associated with IoT devices [39]. Bluesarfing is a cyberattack in which unauthorized access is gained to information, such as contacts, emails, calendars, and even control functions [40]. Insecure authentication or default credentials in IoT devices can be exploited by attackers gaining access to the system, allowing them to extract sensitive information [41].

Bluejacking is a more nuisance-based activity than serious cyberattack [42]. It involves sending unsolicited messages to Bluetooth-enabled devices within proximity. The messages are typically benign, intended to surprise or annoy the device owner. It relies on the fact that some Bluetooth devices can receive messages without any pairing or permission.

**Eavesdropping:** Eavesdropping in an IoT-based system refers to the unauthorized interception of communication between devices within the IoT network [44]. This interception could occur through various means, such as monitoring wireless transmissions or accessing data through network connections. Eavesdropping poses significant risks in IoT systems as it can lead to exposure of sensitive information, personal data, authentication credentials, or control mechanisms [45]. If the data transmitted between IoT devices or between a device and a server is not properly encrypted, it becomes vulnerable to interception. Attackers can easily intercept and read this data [46]. Some IoT devices might use outdated or insecure network protocols, making it easier for attackers to intercept data packets [47].

**Malware:** Malware in IoT systems represents a serious threat, exploiting vulnerabilities within interconnected devices to propagate and execute malicious activities [48]. These malicious software programs can infiltrate IoT devices through various means, including unpatched software, weak authentication, or insecure network connections. Once embedded in IoT devices, malware can compromise their functionality, create bots for large-scale attacks, or facilitate unauthorized access to connected networks. Furthermore protecting IoT systems from malware requires implementing robust security measures such as regular firmware updates, network segmentation, strong authentication mechanisms, IDSs, and behavior-based anomaly detection to detect and prevent malware infections, safeguarding the integrity and security of IoT ecosystems [50, 51].
