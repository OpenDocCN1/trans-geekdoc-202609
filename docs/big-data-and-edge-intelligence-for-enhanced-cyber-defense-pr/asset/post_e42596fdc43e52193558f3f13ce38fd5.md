## AI and IoT-Based Intrusion System for Cybersecurity

### 2.1 INTRODUCTION

It is difficult, not impossible, to create an IDS that is completely successful. Most modern systems contain various security issues. Not all types of incurs are recognized by the increase of IoT.

An intrusion detection system (IDS) monitors traffic to identify malicious activity or violations. The primary goal of IDS is to protect availability, confidentiality, and integrity.

There are two types of IDS: network (NIDS) and host (HIDS). NIDS are IDS that are strategically positioned in the network. NIDS examines network traffic to determine whether malicious attacks are taking place. HIDS are IDS that are installed on all network clients; if it finds anomalous behavior, it will raise an alarm. The well-known variants are signature-based detection (recognizing patterns, such as malware) and anomaly-based detection (detecting departure from a “good” model, based on machine learning). Another popular method is detection by reputation.
