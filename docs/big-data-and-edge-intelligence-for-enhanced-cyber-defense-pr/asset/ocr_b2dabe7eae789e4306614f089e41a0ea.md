Calculate the gradient of the weighted sum (3.20) as follows:

```
$$\frac{\partial z_j}{\partial w_j} = x \quad \frac{\partial z_j}{\partial b_j} = 1 \quad (3.20)$
```

Using chain rule to calculate the gradient of the objective function with respect to the weights and biases (3.21) as follows:

```
$$\frac{\partial E}{\partial w_j} = \frac{\partial E}{\partial \hat{y}_j} * \frac{\partial \hat{y}_j}{\partial a_j} * \frac{\partial a_j}{\partial z_j} * \frac{\partial z_j}{\partial w_j} \quad \ \frac{\partial E}{\partial b_j} = \frac{\partial E}{\partial \hat{y}_j} * \frac{\partial \hat{y}_j}{\partial a_j} * \frac{\partial a_j}{\partial z_j} * \frac{\partial z_j}{\partial b_j} \quad (3.21)$
```

Now, the weights are Updated (3.22):

```
$w_{j(new)} = w_j - \eta^* \frac{\partial E}{\partial w_j} \quad (3.22)$
```

where $\eta$ is the learning rate.

Then, the biases are updated (3.23):

```
$b_{j(new)} = b_j - \eta^* \frac{\partial E}{\partial b_j} \quad (3.23)$
```

This backpropagation algorithm iteratively adjusts the weights and biases of the neural network to minimize the objective function (MSE) and improve the accuracy of the predictions. By updating the weights and biases based on the gradients calculated using the chain rule, the model learns to better capture complex patterns in the input data.

EdgeAI enables DL models to handle and evaluate data in real time, dramatically lowering the latency associated with data transmission to centralized processing centres. This helps investigators to discover and respond to cyber threats more quickly, enhancing incident response capabilities.
