# Performance Metrics

We evaluate the models using the following performance metrics:

+   - Accuracy: The percentage of correctly classified instances out of all instances in the test set.

+   - Precision: The percentage of true positive instances (attacks correctly detected) out of all instances classified as positive (predicted attacks).
