# 1.3.2.2 Network Layer

This is a global positioning wireless networking. Ad hoc, low-voltage Bluetooth-4G-LTE, and 5G communication networks are all supported by this intermediary layer. In addition to heterogeneous networks, it incorporates a wide range of technologies and protocols. # 1.3.2.3 Application Layer

This layer of the IoT architecture uses a variety of devices, including computers, smartphones, and personal digital assistants, to deliver IoT-based services to people all over the world. The user offers an interface so that they may communicate with the system. There are many different applications domains for IoT. Examples of these include the initial processing of data analysis and data mining that are industrial, commercial, human-specific, and consumer-focused.
