黑客攻击每年让互联网用户损失大量资金。它指的是利用用户端漏洞的攻击。利用了多种策略，直到没有单一策略能够妥善地减少钓鱼中的每一个漏洞。在这项研究中，我们研究了检测钓鱼网站的三种策略。第一种技术查看URL的不同部分；它托管在哪里以及运行在哪里；第三种查看网站的外观外观。为了分析这些URL和网页的许多组件，我们使用了深度学习技术和算法。本页提供了几种方法的概述。
