# 6.33 True positive, precision, false positive, and RMSE of proposed IDS engine.

A IDS engine has been proposed to counter classification problem of high imbalance. The dataset considered here is CICIDS2017, which is a recent consisting of a normal instance called benign and instances of 14 other classes. The challenge was to design an IDS framework for this huge dataset consisting of more than 28 lakh instances with 85 features that too exist with high-class imbalance. To counter this, first features were ranked through a probabilistic latent graph-based ranking approach called infinite latent feature selection, then required features are selected for sample generation.
