# Java Decompilation

Most people find it much easier to read high-level code like Java instead of Java Virtual Machine (JVM) disassembly. Because JVM is fairly simple, the decompilation process is doable and can recover Java source code from class files. Dex2jar brings all the Java decompiler tools to the Android world and allows for easy decompilation of Android applications written in Java.

Many Java decompilers are available online, but most of them are outdated and no longer maintained. The JD decompiler⁵ is probably the most popular and well-known decompiler. It also supports three different GUI applications for viewing source code: JD-GUI, JD-Eclipse, and JD-IntelliJ. JD-GUI is a custom GUI for quick analysis of source code without the need to install big Java editors. JD-GUI is available for the Windows, macOS, and Linux operating systems.
