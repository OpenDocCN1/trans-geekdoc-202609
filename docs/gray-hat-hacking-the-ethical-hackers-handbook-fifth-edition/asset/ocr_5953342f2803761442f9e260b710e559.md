+   1. Fix all unknown code as functions. Several heuristics are used to convert data and code not recognized as functions in IDA into proper IDA functions.

+   The pass first performs the “Fix unknown code that has a well-known function prolog to functions” sweep. This ensures that during this first pass, only code that has strong indicators gets converted into a function. In this case, the standard function prolog (push ebp; mov ebp, esp or 55 8B EC) is used as a heuristic. After that, the plug-in will try to convert all other instructions into function code.
