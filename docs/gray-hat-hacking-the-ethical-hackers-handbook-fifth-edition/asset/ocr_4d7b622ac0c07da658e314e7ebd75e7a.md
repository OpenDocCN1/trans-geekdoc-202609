# Lab 16-1: XSS Refresher

Our first lab is a basic refresher of how XSS works. At its essence, XSS is an injection
attack. In our case, we're going to be injecting code into a web page so that it is rendered by
the browser. Why does the browser render this code? Because in many XSS situations, it's
not obvious where the legitimate code ends and where the attacking code starts. As such,
the browser continues doing what it does well and renders the XSS.

We'll start this lab using Firefox. At the time of writing, the latest version is Firefox 56, so
if you have problems with the instructions because things are being filtered, revert back to
an earlier version of Firefox.
