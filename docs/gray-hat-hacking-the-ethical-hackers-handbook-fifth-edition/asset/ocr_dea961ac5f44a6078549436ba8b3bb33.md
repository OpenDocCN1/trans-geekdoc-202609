# ## Simplifying the Process with Direct Parameter Access

To make things even easier, you can access the seventh parameter from the stack by what is called direct parameter access. The #$ format token is used to direct the format function to jump over a number of parameters and select one directly. Here is an example:

```
```text
//dirpar.c
#include <stdio.h>
int main(){
printf ("This is a %3$s.\n", 1, 2, "test" );
}
$gcc -o dirpar dirpar.c
$./dirpar
This is a test.
$
```
```
