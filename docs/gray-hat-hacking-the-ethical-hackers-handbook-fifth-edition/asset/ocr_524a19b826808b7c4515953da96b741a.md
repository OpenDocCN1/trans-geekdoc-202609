As you can see, the value ④ we found for system is 0x1000 off from what search found. When we look at the other values and add in the offset we computed for system, we can see that exit and "/bin/sh" are at the newly computed locations. The reason that these are in a slightly different place is due to how the linker puts together a binary. When we use ldd to look at where the different shared objects are attached to each file, we can see that the location where libc is attached is different for the two binaries, thus leading to this 0x1000 discrepancy:

$ ldd search

    libdl.so.2 => /lib/i386-linux-gnu/libdl.so.2 (0xb7fd1000)

    /lib/ld-linux.so.2 (0x80000000)
