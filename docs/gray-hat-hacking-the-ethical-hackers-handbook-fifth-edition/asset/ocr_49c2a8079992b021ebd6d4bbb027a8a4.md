# Summary

The highly active reverse engineering community is constantly evolving tools and techniques used to analyze a variety of file formats for different analysis goals. Sometimes interesting tools and research may fall through the cracks and be unjustly overlooked in this active community. This chapter presented some relatively new tools and plug-ins that, if given a chance, might significantly improve your analysis confidence and speed.
