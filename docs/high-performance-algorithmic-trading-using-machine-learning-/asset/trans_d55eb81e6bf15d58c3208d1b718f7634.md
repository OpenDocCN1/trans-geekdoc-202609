
正如我们已经说过的，在这个语境中，负类与价格模式保持在波动率通道内相关联，这被认为是正常行为。

上述报告强调了预测负类的高准确性；当模型预测负类时，它有 91% 的时间是正确的。召回率指标[10](#chap07.xhtml#footnote-084)也很高（73%），表明模型非常擅长检测正常行为（价格模式在波动率通道内）。

相反，正类的精确率较低，表明当模型预测正类时，它正确的时间不到一半（45%）。

从装袋法过渡到提升法，这两种都是目标共同为模型改进的强大集成技术，我们现在将探究是什么区分了这些方法，以及它们各自如何独特地贡献于模型的预测能力。

### 利用提升方法实现高准确性

提升法是一个顺序过程，其中每个后续模型都试图纠正其前驱模型的错误，有效地将弱学习器组合起来创建一个强大的整体模型。与装袋法独立构建模型不同，提升法通过更多地关注前一个模型分类错误的训练实例，来专注于提高集成的准确性。

提升法的主要优势在于其通过专注于难以分类的示例来持续改进的能力。

流行的提升算法包括 `AdaBoost`（自适应提升）、`GBM`（梯度提升机）、`XGBoost`（极端梯度提升）和 `LightGBM`（轻量级梯度提升机）：

• `AdaBoost` 通常被认为是较简单的提升方法之一，可以作为一个好的起点。

• `GBM` 更灵活但需要仔细调优。

• `XGBoost`[11](#chap07.xhtml#footnote-083) 以其性能和速度著称，由于其效率和可扩展性，经常赢得机器学习竞赛。

• `LightGBM`[12](#chap07.xhtml#footnote-082) 设计得更快、更高效，特别是在大数据集上，使其成为交易场景中处理大量数据和快速决策至关重要的强大工具。

然而，由于这些后者算法的复杂性和超参数[13](#chap07.xhtml#footnote-081)的数量庞大，调优它们可能更具挑战性，这也意味着更高的计算需求。您可以参考[第 5 章](#chap05.xhtml)《交易系统的监督学习》了解这些算法的详细信息。

#### XG-Boost

对于表格数据，这在交易场景中很常见，例如 `OHLC` 数据集，`XGBoost` 发布时被誉为最先进的算法。然而，自那时起，像 `LightGBM` 这样的新算法已经出现，在某些情况下提供了卓越的性能。

不幸的是，最大化这些算法的效率通常需要仔细的超参数调优，这是一个既具挑战性又耗时的过程。

利用[第 3 章](#chap03.xhtml)《优化交易系统、指标和自动化报告》中的见解，该章专注于使用 `HyperOpt`[14](#chap07.xhtml#footnote-080) 等工具增强交易策略，我们现在将应用类似的方法使用 `Scikit-Optimize`[15](#chap07.xhtml#footnote-079)。该工具箱使我们能够在超参数空间内进行智能的贝叶斯搜索。我们的目标是微调这些超参数并实现最优性能。
