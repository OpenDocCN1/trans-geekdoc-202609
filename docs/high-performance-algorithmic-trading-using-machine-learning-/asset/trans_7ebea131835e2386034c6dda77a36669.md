### 算法选择

AutoML 平台实现了算法选择的自动化，即为给定数据集和问题选择最佳机器学习算法的过程。这通常通过搜索策略的组合来实现，例如网格搜索、随机搜索，或更复杂的方法，如用于 `auto-SkLearn`[7](#chap08.xhtml#footnote-067) 工具的贝叶斯优化，或用于 `TPOT`[8](#chap08.xhtml#footnote-066) 的遗传编程。

AutoML 平台根据预定义指标，针对数据集评估从线性模型到复杂集成方法的多种算法，以确定哪种算法产生最有希望的结果。

这种从简单到更复杂模型的逐步推进是机器学习开发的基本原则。我们在[第 5 章](#chap05.xhtml)《交易系统的监督学习》和[第 7 章](#chap07.xhtml)《交易的高级机器学习模型》中遵循了相同的方法，首先介绍简单的线性模型（如逻辑回归），然后在后续章节中增加复杂度。这一迭代过程将持续直到达到所需的性能水平。

机器学习从业者广泛使用这种方法论，且与前文讨论的奥卡姆剃刀原则一致。AutoML 平台通过系统地自动化搜索过程来封装这种方法，从更简单的模型开始，仅在必要时增加复杂度。通过这种方式，它们在保持可解释性、计算效率和预测性能之间平衡的同时，简化了模型开发。

AutoML 和复杂的低代码平台[9](#chap08.xhtml#footnote-065)为用户提供了简化的界面以启动算法选择过程。用户可以指定其问题类型（例如分类、回归等），并让平台推荐或自动选择要尝试的最佳算法，将对深度编程和机器学习知识的需求降至近乎为零。
