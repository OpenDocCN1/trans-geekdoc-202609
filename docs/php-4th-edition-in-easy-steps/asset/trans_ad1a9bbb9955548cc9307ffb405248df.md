## 初始化成员

![image](images/pg110_1.jpg)

程序可以通过声明类的多个实例轻松创建多个对象，并且每个对象可以通过其 setter 方法分配单独的值来具有唯一的属性。

通常将 setter 方法合并为一个接受每个私有变量参数的单一方法很方便。这意味着所有值都可以用程序中的单条语句分配，但该方法将包含多条语句。

可选地，每个参数可以指定传递的每个参数的允许数据类型，并且还可以有意义地为每个参数指定默认值：

![image](images/1v.jpg) 重命名先前示例“`object.php`”的副本为新程序“`initializer.php`”

![image](images/commonv.jpg)

`initializer.php`

![image](images/2v.jpg) 在 `Dog` 类声明中，用一个指定参数数据类型和默认值的单一组合 setter 方法替换三个 setter 方法

```
public function setValues
( int $yrs \= 2 , int $lbs \= 8 , string $fur \= ‘black’ )
{
 // Statements to be inserted here.
}
```

![image](images/3v.jpg) 在方法定义块中，插入三条语句以将传递的参数值分配给类变量

`$this->age \= $yrs ;`

`$this->weight \= $lbs ;`

`$this->color \= $fur ;`

![image](images/4v.jpg) 在修改后的类定义之后，用对组合 setter 方法的单次调用替换对三个 setter 方法的调用 – 传递三个参数

## 使用构造函数

![image](images/pg112_1.jpg)

类变量成员可以通过一个特殊的“构造函数”方法进行初始化，该方法在每次创建类的实例时被调用。构造函数方法始终命名为 `__construct()`，并且可以接受参数来设置类变量的初始值。

构造函数方法有一个配套的“析构函数”方法 – 当类的实例被销毁时调用。析构函数方法始终命名为 `__destruct()`。

构造函数和析构函数方法没有返回值并且是自动调用的 – 它们不能显式调用，因此其声明不需要访问限定符。

用于初始化类变量的值在创建对象的语句中传递给构造函数方法，放在对象名称后的括号中：

![image](images/1v.jpg) 重命名先前示例“`initializer.php`”的副本为新程序“`constructor.php`”

![image](images/commonv.jpg)

`constructor.php`

![image](images/2v.jpg) 在 `Dog` 类声明中，用此构造函数替换 `setValues` 方法

```
function __construct
( int $yrs \= 2 , int $lbs \= 8 , string $fur \= ‘black’ )
{
 $this->age \= $yrs ;
 $this->weight \= $lbs ;
 $this->color \= $fur ;
}
```

![image](images/3v.jpg) 现在，添加一个简单的析构函数方法

`function __destruct() { echo ‘<hr>Object Destroyed.’ ; }`

![image](images/4v.jpg) 在 `Dog` 类声明之后，编辑创建“`fido`”对象的语句 – 以向其构造函数方法传递值，以便初始化属性

`$fido = new Dog( 3 , 15 , ‘brown’ ) ;`

![image](images/5v.jpg) 同样地，编辑创建“`pooch`”对象的语句 – 以向构造函数方法传递值

`$pooch \= new Dog( 4 , 18 , ‘gray’ ) ;`

![image](images/hot.jpg)

类方法的定义也称为方法的“实现”。

![image](images/6v.jpg) 还编辑创建“`rover`”对象的语句 – 以使用构造函数方法的默认值

`$rover = new Dog( ) ;`

![image](images/7v.jpg) 删除调用所有三个对象的 `setValues` 方法的语句 – 构造函数现在取代了该方法

![image](images/forget.jpg)

尽管变量成员的初始值由构造函数设置，但可以添加 setter 方法以随后更改值 – 并且这些新值可以通过 getter 方法检索。

PHP 提供了几个用于检查类的函数，例如 `class_exists(*class*)`、`method_exists(*class*, *method*)` 和 `property_exists(*class*, *property*)`，成功时返回 TRUE。你也可以使用 `get_class_vars(*class*)` 和 `get_class_methods(*class*)` 获取类成员列表，以仅查看“可见”成员：

![image](images/8v.jpg) 添加语句以显示 `Dog` 类中可访问变量的总数

`$items \= get_class_vars( ‘Dog’ ) ;`

`echo ‘<br>Dog variables : ‘.count( $items ) ;`

![image](images/9v.jpg) 添加语句以显示 `Dog` 类中可访问方法的名称

`echo ‘<br>Dog methods :’ ;`

`$items \= get_class_methods( ‘Dog’ ) ;`

`foreach( $items as $item ) { echo “$item, ” ; }`
