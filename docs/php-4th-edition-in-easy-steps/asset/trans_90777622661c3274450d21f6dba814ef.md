## 如何使用本书

本书中的示例演示了 PHP 脚本语言的功能，屏幕截图说明了所列代码示例实际产生的结果。为了阐明步骤中列出的代码，使用了某些着色约定…
PHP 语言的组件着色为蓝色，程序员指定的名称着色为红色，文字和数值着色为黑色，代码注释为绿色，如下所示：

```
<?php
# Write the traditional greeting.
$greeting = ‘Hello World!’ ;
echo “<h1>$greeting</h1>” ;
?>
```

此外，为了标识步骤中描述的每个源代码文件，文件图标和文件名会出现在步骤旁边的页边距中：

![image](images/pg6_1.jpg)

### 获取源代码

为方便起见，本书所有示例中的源代码文件都包含在一个 ZIP 归档中。您可以按照以下简单步骤获取此归档：

![image](images/1g1.jpg)浏览至 **[www.ineasysteps.com](http://www.ineasysteps.com)** 然后导航到免费资源并选择下载部分
![image](images/2g1.jpg)接下来，在列表中找到 PHP in easy steps, 4th edition，然后点击标题为 All Code Examples 的超链接下载 ZIP 归档文件
![image](images/3g1.jpg)现在，将归档内容解压到您电脑上 Web 服务器的 `/htdocs` 目录

如果您在任何示例中未达到所示结果，只需将您的代码与已下载的原始示例文件中的代码进行比较即可找出错误所在。
