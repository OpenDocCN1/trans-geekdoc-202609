
# Go 语言排序包详解

## `sort` 包与 `sort.Interface` 接口

幸运的是，`sort` 包提供了对任意序列的原地排序，且可根据任意排序函数进行排序。其设计颇为独特。在许多语言中，排序算法与序列数据类型关联，而排序函数与元素类型关联。相比之下，Go 的 `sort.Sort` 函数不对序列或其元素的表示做任何假设。相反，它使用接口 `sort.Interface` 来指定通用排序算法与每个可排序序列类型之间的契约。该接口的实现决定了序列的具体表示（通常是切片）及其元素的期望排序顺序。

原地排序算法需要三样东西：序列的长度、比较两个元素的方法、交换两个元素的方法——它们正是 `sort.Interface` 的三个方法：

[Click here to view code image](#part0137_split_036.html#id186pro02_r)

```go
package sort

type Interface interface {
    Len() int
    Less(i, j int) bool // i, j are indices of sequence elements
    Swap(i, j int)
}
```

## 实现 `sort.Interface` 进行排序

要对任意序列排序，我们需要定义一个实现了这三个方法的类型，然后对该类型的实例调用 `sort.Sort`。作为最简单的例子，考虑对字符串切片排序。下面展示了新类型 `StringSlice` 及其 `Len`、`Less` 和 `Swap` 方法。

[Click here to view code image](#part0137_split_037.html#id187pro01_r)

```go
type StringSlice []string

func (p StringSlice) Len() int           { return len(p) }
func (p StringSlice) Less(i, j int) bool { return p[i] < p[j] }
func (p StringSlice) Swap(i, j int)      { p[i], p[j] = p[j], p[i] }
```

现在我们可以通过将切片转换为 `StringSlice` 来对字符串切片 `names` 进行排序：

```go
sort.Sort(StringSlice(names))
```

转换产生的切片值与 `names` 具有相同的长度、容量和底层数组，但其类型拥有排序所需的三个方法。

对字符串切片排序非常常见，因此 `sort` 包提供了 `StringSlice` 类型以及一个名为 `Strings` 的函数，使得上述调用可简化为 `sort.Strings(names)`。

该技术易于适配其他排序顺序，例如忽略大小写或特殊字符。（本书用于排序索引词和页码的 Go 程序就做了这件事，并额外处理了罗马数字。）对于更复杂的排序，我们使用相同的思路，但会用到更复杂的数据结构或更复杂的 `sort.Interface` 方法实现。

## 示例：音乐播放列表排序

我们的排序示例将是一个音乐播放列表，以表格形式显示。每个曲目是一行，每列是该曲目的一个属性，如艺术家、标题和播放时长。假设图形用户界面呈现该表格，点击列头会按该属性对播放列表排序；再次点击同一列头则反转顺序。让我们看看每次点击会发生什么。

下面的变量 `tracks` 包含一个播放列表。（作者之一为另一作者的音乐品味道歉。）每个元素是间接的，即指向 `Track` 的指针。虽然如果直接存储 `Track` 值下面的代码也能工作，但排序函数会交换许多元素对，若每个元素是一个指针（单个机器字），而不是整个 `Track`（可能占八个机器字或更多），运行会更快。

[Click here to view code image](#part0137_split_038.html#id187pro02_r)

```go
type Track struct {
    Title  string
    Artist string
    Album  string
    Year   int
    Length time.Duration
}

var tracks = []*Track{
    {"Go", "Delilah", "From the Roots Up", 2012, length("3m38s")},
    {"Go", "Moby", "Moby", 1992, length("3m37s")},
    {"Go Ahead", "Alicia Keys", "As I Am", 2007, length("4m36s")},
    {"Ready 2 Go", "Martin Solveig", "Smash", 2011, length("4m24s")},
}

func length(s string) time.Duration {
    d, err := time.ParseDuration(s)
    if err != nil {
        panic(s)
    }
    return d
}
```

`printTracks` 函数将播放列表打印为表格。图形化显示会更美观，但这个小程序使用 `text/tabwriter` 包生成列对齐且填充整齐的表格，如下所示。注意 `*tabwriter.Writer` 满足 `io.Writer`。它收集写入的每一片数据；其 `Flush` 方法格式化整个表格并写入 `os.Stdout`。

[Click here to view code image](#part0137_split_039.html#id188pro01_r)

```go
func printTracks(tracks []*Track) {
    const format = "%v\t%v\t%v\t%v\t%v\t\n"
    tw := new(tabwriter.Writer).Init(os.Stdout, 0, 8, 2, ' ', 0)
    fmt.Fprintf(tw, format, "Title", "Artist", "Album", "Year", "Length")
    fmt.Fprintf(tw, format, "-----", "------", "-----", "----", "------")
    for _, t := range tracks {
        fmt.Fprintf(tw, format, t.Title, t.Artist, t.Album, t.Year, t.Length)
    }
    tw.Flush() // calculate column widths and print table
}
```

## 按 `Artist` 字段排序

要按 `Artist` 字段对播放列表排序，我们定义一个具有所需 `Len`、`Less` 和 `Swap` 方法的新切片类型，类似于 `StringSlice` 的做法。

[Click here to view code image](#part0137_split_040.html#id188pro02_r)

```go
type byArtist []*Track

func (x byArtist) Len() int           { return len(x) }
func (x byArtist) Less(i, j int) bool { return x[i].Artist < x[j].Artist }
func (x byArtist) Swap(i, j int)      { x[i], x[j] = x[j], x[i] }
```

要调用通用排序例程，我们必须先将 `tracks` 转换为定义排序顺序的新类型 `byArtist`：

```go
sort.Sort(byArtist(tracks))
```

按艺术家排序后，`printTracks` 的输出为：

[Click here to view code image](#part0137_split_041.html#id188pro03_r)

```
Title       Artist          Album              Year  Length
-----       ------          -----              ----  ------
Go Ahead    Alicia Keys     As I Am            2007  4m36s
Go          Delilah         From the Roots Up  2012  3m38s
Ready 2 Go  Martin Solveig  Smash              2011  4m24s
Go          Moby            Moby               1992  3m37s
```

## 反转排序顺序

如果用户第二次请求“按艺术家排序”，我们将按反序排列曲目。我们无需定义一个具有反转 `Less` 方法的新类型 `byReverseArtist`，因为 `sort` 包提供了 `Reverse` 函数，可将任意排序顺序转换为其逆序。

[Click here to view code image](#part0137_split_042.html#id189pro01_r)

```go
sort.Sort(sort.Reverse(byArtist(tracks)))
```

反向按艺术家排序后，`printTracks` 的输出为：

Go Ahead    Alicia Keys     As I Am            2007  4m36s

## `sort.Reverse` 实现原理

`sort.Reverse` 函数值得仔细研究，因为它使用了组合（[§6.3](#part0056.html#id-composition)），这是一个重要的概念。`sort` 包定义了一个未导出类型 `reverse`，它是一个嵌入了 `sort.Interface` 的结构体。`reverse` 的 `Less` 方法调用嵌入的 `sort.Interface` 值的 `Less` 方法，但交换了索引，从而反转排序结果。

[Click here to view code image](#part0137_split_044.html#id189pro03_r)

```go
package sort

type reverse struct{ Interface } // that is, sort.Interface

func (r reverse) Less(i, j int) bool { return r.Interface.Less(j, i) }

func Reverse(data Interface) Interface { return reverse{data} }
```
