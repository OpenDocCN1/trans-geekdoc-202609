
`ReadFile` 返回一个字节切片，必须将其转换为 `string`，以便能用 `strings.Split` 进行分割。我们将在 [3.5.4 节](#part0033.html#id-stringsandbyteslices) 详细讨论字符串和字节切片。

在底层，`bufio.Scanner`、`ioutil.ReadFile` 和 `ioutil.WriteFile` 使用 `*os.File` 的 `Read` 和 `Write` 方法，但大多数程序员很少需要直接访问这些底层例程。来自 `bufio` 和 `io/ioutil` 的高级函数更易于使用。

## 1.4 GIF 动画

下一个程序演示了 Go 标准图像包的基本用法，我们将用它创建一系列位图图像，然后将该序列编码为 GIF 动画。这些图像被称为 *利萨如曲线*，是 1960 年代科幻电影中的常见视觉效果。它们是由二维谐振产生的参数曲线，例如将两个正弦波分别输入示波器的 *x* 和 *y* 输入端。[图 1.1](#part0015.html#id-figures-lissajous) 展示了一些示例。

![四个利萨如曲线。](images/00004.jpeg)

**图 1.1.** 四个利萨如曲线。

这段代码包含几个新结构，包括 `const` 声明、结构体类型和复合字面量。与大多数示例不同，本示例还涉及浮点数计算。我们将仅简要讨论这些主题，大部分细节留待后续章节，因为目前的主要目标是让你了解 Go 的外观，以及使用该语言及其库可以轻松完成哪些事情。

[点击此处查看代码图像](#part0129_split_011.html#id013pro01_r)

gopl.io/ch1/lissajous

```
// Lissajous generates GIF animations of random Lissajous figures.
package main

import (
    "image"
    "image/color"
    "image/gif"
    "io"
    "math"
    "math/rand"
    "os"
)

var palette = []color.Color{color.White, color.Black}

const (
    whiteIndex = 0 // first color in palette
    blackIndex = 1 // next color in palette
)

func main() {
    lissajous(os.Stdout)
}

func lissajous(out io.Writer) {
    const (
        cycles  = 5     // number of complete x oscillator revolutions
        res     = 0.001 // angular resolution
        size    = 100   // image canvas covers [-size..+size]
        nframes = 64    // number of animation frames
        delay   = 8     // delay between frames in 10ms units
    )
    freq := rand.Float64() * 3.0 // relative frequency of y oscillator
    anim := gif.GIF{LoopCount: nframes}
    phase := 0.0 // phase difference
    for i := 0; i < nframes; i++ {
        rect := image.Rect(0, 0, 2*size+1, 2*size+1)
        img := image.NewPaletted(rect, palette)
        for t := 0.0; t < cycles*2*math.Pi; t += res {
            x := math.Sin(t)
            y := math.Sin(t*freq + phase)
            img.SetColorIndex(size+int(x*size+0.5), size+int(y*size+0.5),
                blackIndex)
        }
        phase += 0.1
        anim.Delay = append(anim.Delay, delay)
        anim.Image = append(anim.Image, img)
    }
    gif.EncodeAll(out, &anim) // NOTE: ignoring encoding errors
}
```

导入路径包含多个组件的包（如 `image/color`）后，我们用最后一个组件的名称来引用该包。因此变量 `color.White` 属于 `image/color` 包，而 `gif.GIF` 属于 `image/gif`。

`const` 声明（[§3.6](#part0034.html#id-constants)）给常量命名，即编译时固定的值，例如 cycles、frames 和 delay 的数值参数。与 `var` 声明一样，`const` 声明可出现在包级别（名称在整个包可见）或函数内部（名称仅在该函数内可见）。常量的值必须是数字、字符串或布尔值。

表达式 `[]color.Color{...}` 和 `gif.GIF{...}` 是*复合字面量*（[§4.2](#part0037.html#id-slices)，[§4.4.1](#part0039.html#id-structliterals)），一种通过元素值序列实例化 Go 任意复合类型的简洁表示法。这里第一个是切片，第二个是*结构体*。

类型 `gif.GIF` 是一个结构体类型（[§4.4](#part0039.html#id-structs)）。结构体是一组称为*字段*的值的集合，通常类型不同，被收集在一个可作为单元处理的对象中。变量 `anim` 是 `gif.GIF` 类型的结构体。结构体字面量创建一个结构体值，其 `LoopCount` 字段设为 `nframes`；所有其他字段具有其类型的零值。结构体的各个字段可通过点号表示法访问，如最后两个赋值显式更新了 `anim` 的 `Delay` 和 `Image` 字段。

`lissajous` 函数有两层嵌套循环。外层循环运行 64 次迭代，每次生成动画的一帧。它创建一个新的 201×201 图像，调色板有白、黑两色。所有像素初始设为调色板的零值（调色板中的第零种颜色），我们将其设为白色。内层循环每次通过将某些像素设为黑色来生成新图像。结果连同 80ms 的指定延迟，使用内置 `append` 函数（[§4.2.1](#part0037.html#id-theappendfunction)）追加到 `anim` 的帧列表中。最后将帧序列和延迟编码为 GIF 格式并写入输出流 `out`。`out` 的类型是 `io.Writer`，这让我们能写入多种可能的目标，稍后将展示。

内层循环运行两个振荡器。*x* 振荡器只是正弦函数。*y* 振荡器也是正弦波，但其相对于 *x* 振荡器的频率是 0 到 3 之间的随机数，其相对于 *x* 振荡器的相位初始为零，但随动画每帧增加。循环运行直到 *x* 振荡器完成五个完整周期。每一步调用 `SetColorIndex` 将对应 (*x*, *y*) 的像素着色为黑色，即调色板中位置 1 的颜色。

`main` 函数调用 `lissajous` 函数，指示其写入标准输出，因此此命令生成的动画 GIF 帧如 [图 1.1](#part0015.html#id-figures-lissajous) 所示：

[点击此处查看代码图像](#part0129_split_012.html#id015pro01_r)

```
$ go build gopl.io/ch1/lissajous
$ ./lissajous >out.gif
```
