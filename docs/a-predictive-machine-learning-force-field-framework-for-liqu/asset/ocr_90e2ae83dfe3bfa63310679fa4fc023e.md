# Architecture of GEL layers

In Fig. 2c, the GEL architecture used in BAMBOO draws inspiration mainly from the TorchM-NET. Beginning with the atom blocks $[Z_i]$ and the positions between atoms $[\mathbf{r}_{ij}]$, we first initialize the scalar representation $x_i^0$ and the vector representation $v_i^0$, as well as the scalar edge blocks. We feed $x_i^0$ and $v_i^0$ into the GEL layers to be transformed iteratively (c). As indicated in Fig. 1d, each GEL layer transforms each scalar block within a cut-off radius ($r=5$ Å). This figure illustrates how information is exchanged between nodes and edges. After the transformer block, on the scalar side, we update with $x_i^l$; the vector representation $v_i^l$ is transformed into a scalar $u_i^l$. The transformation from vector to scalar is achieved through the inner-product operation to maintain rotational invariance. Finally, we combine $x_i^l$ and $u_i^l$ to obtain the next-layer scalar representation $x_i^{l+1}$, and $v_i^l$ and $u_i^l$ to obtain the next-layer vector representation $v_i^{l+1}$.
