**关键技能**：`Python`、`TensorFlow`、`PyTorch`、`Pandas`、`NumPy`。

#### 2. AI 研究科学家

**主要关注**：开发新的 AI 架构、算法和方法论。AI 研究人员关注：

*   开发新的深度学习架构（例如 `transformers`、`diffusion models`、强化学习）。
*   撰写学术论文并向 `NeurIPS` 和 `ICML` 等会议贡献内容。
*   实验 `自监督学习`和生成式 AI。

**你可以在哪里找到这种角色**：OpenAI、DeepMind、Google Brain、Meta AI、顶尖研究大学。

#### 3. 深度学习工程师

**主要关注**：为高复杂度任务训练、微调和部署深度学习模型。这些工程师专注于：

*   处理海量神经网络、`LLMs` 和计算机视觉。
*   为实时应用优化模型（例如语音识别、图像生成）。
*   使用先进的硬件加速器，如 `GPUs`、`TPUs` 和自定义 AI 芯片。

**你可以在哪里找到这种角色**：自动驾驶汽车（Tesla, Waymo）、NLP 公司（Anthropic, OpenAI）、生成式 AI 初创公司。

**主要关注**：将 AI 技术与现实世界的产品开发相结合。

*   将 AI 研究转化为市场就绪的应用。

**你可以在哪里找到这种角色**：科技初创公司、SaaS AI 公司、电子商务。

**关键技能**：AI APIs、全栈开发、产品思维、模型服务、云 AI 部署。

### 核心 AI 概念与技术基础

在深入研究 AI 系统设计之前，候选人必须证明对 AI 基础有深入理解——不仅是在理论层面，而是要能够转化为可扩展、生产就绪的 AI 解决方案。

#### AI vs 机器学习 vs 深度学习

许多候选人在面试中无法清晰地阐述 `AI`、`ML` 和深度学习之间的区别。虽然这些术语经常互用，但它们指的是不同的问题解决方法：

*   人工智能 (`AI`) – 一个包含基于规则的系统、专家系统、搜索算法和机器学习的广泛领域。
*   机器学习 (`ML`) – `AI` 的子集，其中系统从数据中学习模式，而不是通过显式编程。
*   深度学习 (`DL`) – `ML` 的子集，它利用多层神经网络来提取特征并学习复杂的表示。

**面试小贴士**：

一个常见的面试问题是：

> “你如何决定使用传统的 `ML`（例如 `Random Forest`、`SVM`）还是深度学习（`CNNs`、`Transformers`）？”

候选人必须解释：

*   计算权衡——`DL` 需要更多的计算资源和标注数据。
*   可解释性——传统的 `ML` 模型更容易调试和解释。
*   用例对齐——`CNNs` 用于图像数据，`Transformers` 用于 NLP（语言处理）等。

#### 神经网络与模型架构

面试官会期望候选人理解各种深度学习架构以及何时使用它们：

*   全连接网络 (`FCNs`)
*   卷积神经网络 (`CNNs`)
*   循环神经网络 (`RNNs`)
*   Transformers (`GPT`, `BERT`, `LLaMA`)
*   扩散模型

#### 特征工程与预处理

数据预处理至关重要。AI 工程师必须理解：

*   缩放：`MinMax`, `Z-score`
*   降维：`PCA`, `t-SNE`
*   处理不平衡数据：`SMOTE`
*   特征选择：`SHAP` 值

#### 训练、评估与模型优化

关键评估指标：

*   分类：`Precision`, `Recall`, `F1-score`, `ROC-AUC`
*   回归：`RMSE`, `MAE`, `R-squared`

AI 工程师面试不仅是知识的测试——更是对你在压力下思考能力的测试。`FAANG`、`OpenAI`、`Tesla` 和 `DeepMind` 的招聘经理寻找的不是基于记忆的答案；他们在评估候选人是否能将结构化的问题解决框架应用于应对新的 AI 挑战。

#### 从零开始实现神经网络

**示例问题**：

> “使用 `NumPy` 从零实现一个基础的前馈神经网络。你的网络应支持反向传播并在小型数据集上进行训练。”

**测试的关键概念**：

*   矩阵乘法与激活函数（`ReLU`、`Softmax`）。
*   前向和反向传播。
*   使用 `SGD` 或 `Adam` 优化器进行梯度更新。

```python
import numpy as np

class NeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size, learning_rate=0.01):
        self.lr = learning_rate
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros((1, output_size))

    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))

    def sigmoid_derivative(self, x):
        return x * (1 - x)

    def forward(self, X):
        self.z1 = np.dot(X, self.W1) + self.b1
        self.a1 = self.sigmoid(self.z1)
        self.z2 = np.dot(self.a1, self.W2) + self.b2
        self.a2 = self.sigmoid(self.z2)
        return self.a2

    def backward(self, X, y, output):
        loss = y - output
        d_output = loss * self.sigmoid_derivative(output)
        d_hidden = np.dot(d_output, self.W2.T) * self.sigmoid_derivative(self.a1)
        self.W2 += self.lr * np.dot(self.a1.T, d_output)
        self.b2 += self.lr * np.sum(d_output, axis=0, keepdims=True)
        self.W1 += self.lr * np.dot(X.T, d_hidden)
        self.b1 += self.lr * np.sum(d_hidden, axis=0, keepdims=True)

    def train(self, X, y, epochs=1000):
        for _ in range(epochs):
            output = self.forward(X)
            self.backward(X, y, output)

# 使用示例：
X = np.array([[0], [1]])
y = np.array([[1]])
nn = NeuralNetwork(input_size=2, hidden_size=4, output_size=1)
nn.train(X, y)
print(nn.forward(X))
```

优秀的候选人会：

*   解释每个组件（权重初始化、反向传播）。
*   讨论防止过拟合措施（`dropout`、批归一化）。
*   将其方法与 `PyTorch` 或 `TensorFlow` 进行比较。

# 第七章：附录：AI 工程师薪资谈判与 Offer 优化

## 在 FAANG 和顶级 AI 公司实现薪资最大化

AI 工程是科技领域薪酬最高的领域之一，但大多数工程师因未能优化薪资而错失收益。

### 7.1 理解 AI 薪资

**核心洞察**：底薪并不是 AI Offer 中最重要的部分。

#### 1. AI Offer 的四个组成部分

- **底薪 (Base Salary)**：FAANG 中级工程师通常为 150,000–250,000 美元；通常有上限。
- **股票期 (`RSUs`/`Equity`)**：最具谈判价值的组件；在高级别，四年内的授予金额可超过 100 万美元。
- **绩效奖金 (Performance Bonuses)**：通常为底薪的 10%–25%；并非保证且视公司而异。
- **入职奖金 (Signing Bonus)**：可以翻倍或三倍；范围从 25,000 到 200,000 美元。

**谈判策略**：

- 重点谈判股票和入职奖金，而不仅仅是底薪。
- 理解归属周期（vesting schedules）——大多数 `RSUs` 在四年内归属，但某些公司（如 `Meta`、`Amazon`）在前两年集中授予股票。
- `FAANG` 的基础薪在所有级别上都有硬性上限——这方面的谈判空间有限。

**你可以做什么**：

- 使用 `Levels.fyi` 和 `Blind` 进行薪资基准对比。
- 争取更高的初始基础薪，尽管知道它可能会触顶。
- 如果基础薪触顶，将重点放在 `RSUs` 和奖金上。

#### 2. 股票谈判（RSUs/股权授予）

**核心洞察**：`FAANG` 的股票授予是最具谈判价值的，可以为你的总薪包增加六位数的收入。

**如何在录取（Offer）中获得更多股票**：

- 使用竞争对手的录取（Competing Offers）作为筹码。
- 要求在 1–2 年后获得股权回拨保障（Equity Refresher Guarantee）。
- 谈判更早的股票归属（例如 `Meta` 的前置归属机制）。

**股票谈判脚本示例**：

```
“我很感谢这个录取，但我来自 `[X Company]` 的竞争性录取包含了更高的 `RSU` 授予。股权包是否有调整空间以匹配？”
```

**为什么这有效**：

- 保持谈判聚焦在长期薪酬上。
- 迫使招聘人员最大化股票授予，这通常比基础薪更具灵活性。

#### 3. 谈判签约奖金（Signing Bonuses）

**核心洞察**：`FAANG` 的签约奖金通过谈判通常可以翻倍甚至三倍。

**如何最大化你的签约奖金**：

- 使用另一个录取的签约奖金作为筹码。
- 单独要求搬迁报销，以避免影响签约奖金。
- 如果公司在基础薪或 `RSUs` 上不让步，就更努力地争取签约奖金。

**签约奖金谈判脚本示例**：

```
“我想继续推进，但 `[X Company]` 提供的签约奖金更高。签约部分是否有调整灵活性？”
```

**为什么这有效**：



- 签约奖金不影响薪资职级，因此招聘人员在这方面有更大的灵活性。
- 公司更倾向于调整签约奖金，而不是基础薪或股票。
