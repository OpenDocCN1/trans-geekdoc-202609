
# 术语表

## J

**Java**  
面向对象的语言，不仅用于编写小程序，也作为通用编程语言。

**JavaScript Object Notation**  
参见——**JSON**

**JIT**  
即时访问涉及仅在需要访问时创建账户或提供授权，且通常意味着自动移除访问权限。

**JSON**  
**JavaScript Object Notation**，一种数据交换格式。

**Just-In-Time**  
参见——**JIT**

## K

**KDC**  
**Key Distribution Center**，密钥分发中心，一种 Kerberos 服务，用于认证主体。

**Keep it Simple**  
也称为“KISS 原则”，一种设计原则，认识到更简单的系统比复杂的系统更安全。

**Kerberos**  
一种第三方认证服务，可用于支持单点登录。

**Kernel**  
操作系统的核心，通常运行在 Ring 0。它提供硬件与操作系统其余部分（包括应用程序）之间的接口。

**Key Distribution Center**  
参见——**KDC**

**Key lock**  
需要物理钥匙才能解锁的预防性设备。

**Key Performance Indicator**  
参见——**KPI**

**Key Risk Indicator**  
参见——**KRI**

**Keyboard dynamics**  
生物特征控制，指一个人按压每个键的力度以及按键的节奏。

**Keyboard unit**  
外部键盘。

**Knowledge base**  
专家系统组件，由“if/then”语句组成。

**KPI**  
**Key Performance Indicator**，关键绩效指标，一种衡量可用性的方法。

**KRI**  
**Key Risk Indicator**，关键风险指标，一种衡量风险的方法。

## L

**L2F**  
**Layer 2 Forwarding**，第 2 层转发，设计用于隧道传输 PPP。

**L2TP**  
**Layer 2 Tunneling Protocol**，第 2 层隧道协议，结合了 PPTP 和 L2F。

**Label**  
分配给对象的安全级别，如机密、秘密或绝密。

**LAN**  
**Local Area Network**，局域网，规模相对较小的网络，通常局限于一栋建筑或其中的一个区域。

**LAND attack**  
**DoS** 攻击，使用伪造的 SYN 数据包，将受害者的 IP 地址同时作为源地址和目的地址。

**Lattice-Based Access Controls**  
基于格的访问控制，由系统实施的具有定义上下界的非自主访问控制。

**Layer 2 Tunneling Protocol**  
参见——**L2TP**

**Layered defense**  
参见——**Defense-in-depth**

**Layering**  
将硬件和软件功能分离为模块化的层级。

**LCP**  
**Link Control Protocol**，链路控制协议，CHAP 使用的初始未认证连接。

**LDAP**  
**Lightweight Directory Access Protocol**，轻量级目录访问协议，用于与网络操作系统提供的目录服务信息进行接口和查询的开放协议。通过 TCP 或 UDP 使用端口 389。

**LEAP**  
**Lightweight Extensible Authentication Protocol**，轻量级可扩展认证协议，一种思科专有协议，在 802.1X 最终确定前发布。

**Least privilege**  
参见——**Principle of least privilege**

**Legal liability**  
通过民法强制执行的责任。

**Li-Fi**  
**Light Fidelity**，光保真，使用 LED（发光二极管）传输数据。

**Lightweight Directory Access Protocol**  
参见——**LDAP**

**Lightweight Extensible Authentication Protocol**  
参见——**LEAP**

**Linear cryptanalysis**  
线性密码分析，已知明文攻击，密码分析师找到使用同一密钥创建的大量明文/密文对。

**Link Control Protocol**  
参见——**LCP**

**Link state**  
链路状态，在确定最佳路由时考虑额外度量（包括带宽）的路由协议。

**Live forensics**  
实时取证，获取物理内存的二进制镜像，收集正在运行的进程详情，并收集网络连接数据。

**LLC**  
**Logical Link Control**，逻辑链路控制，处理 LAN 通信的第 2 层协议。

**Local Area Network**  
参见——**LAN**

**Lock bumping**  
撞匙攻击，使用磨制的钥匙撞击销钉，使锁转动。

**Lock picking**  
撬锁，不使用钥匙解锁的技术。

**Logic bomb**  
逻辑炸弹，当满足逻辑条件时触发的恶意程序，例如在处理一定数量的交易后，或在特定日期。

**Logical Link Control**  
参见——**LLC**

**Logical Unit Numbers**  
参见——**LUN**

**Lumen**  
流明，一支蜡烛产生的光量。

**LUN**  
**Logical Unit Numbers**，逻辑单元号，提供一种跨网络寻址存储的方式。也用于网络可访问存储的基本访问控制。

**Lux**  
勒克斯，每平方米一流明。

**LWP**  
参见——**Thread**

## M

**MAC (Access Control)**  
**Mandatory Access Control**，强制访问控制，基于主体的许可和对象的标签的系统强制访问控制。

**MAC (Telecommunications)**  
**Media Access Control**，介质访问控制，向物理层传输数据和从物理层传输数据的第 2 层协议。

**MAC address**  
**NIC** 的第 2 层地址。

**Machine code**  
由 CPU 直接执行的软件。

**Machine learning**  
采用基于先前遇到的训练数据集进行学习的算法的系统。

**MAD**  
参见——**MTD**

**Magnetic stripe card**  
磁条卡，不包含电路的无源设备。有时称为刷卡：通过在读卡器上刷卡使用。

**Maintenance hook**  
维护钩子，系统设计人员和程序员安装的快捷方式，允许开发人员在开发期间绕过正常的系统检查。

**Malicious Code**  
参见——**Malware**

**Malware**  
恶意软件，攻击应用程序或系统的任何类型的软件。

**MAN**  
**Metropolitan Area Network**，城域网，通常局限于一个城市、一个邮政编码、一个校园或办公园区。

**Managed**  
**CMM** 第 4 阶段。

**Managed mode**  
客户端用于连接到接入点的 802.11 模式。

**Mandatory Access Control**  
参见——**MAC**

**Mandatory leave**  
强制休假，强迫员工休假或离开办公室。也称为强制休假。

**Mantrap**  
人员阱，一种具有两扇门的预防性物理控制。每扇门都需要单独的认证形式才能打开。

**Master mode**  
接入点使用的 802.11 模式。

**Maximum Allowable Downtime**  
参见——**MTD**

**Maximum Tolerable Downtime**  
参见——**MTD**

**Maximum Transmission Unit**  
参见——**MTU**

**MCH**  
参见——**Northbridge**

**MD5**  
**Message Digest 5**，消息摘要算法 5，一种生成 128 位消息摘要的哈希函数。

**Mean Time Between Failures**  
参见——**MTBF**

**Mean Time to Repair**  
参见——**MTTR**

**Media Access Control**  
参见——**MAC**

**Memory**  
易失性或非易失性计算机存储。

**Memory Controller Hub**  
参见——**Northbridge**

**Mesh**  
网状拓扑，将网络节点相互互连的物理网络拓扑。

**Message Digest 5**  
参见——**MD5**

**Message Integrity Check**  
参见——**MIC**

**Method**  
对象执行的函数。

**Metropolitan Area Network**  
参见——**MAN**

**MIC**  
**Message Integrity Check**，消息完整性检查，WPA2 使用的完整性协议。

**Micro-segmentation**  
微分段，在所有系统之间进行过滤的过程，无论是物理还是基于云的。

**Microkernels**  
微内核，一种模块化内核。

**Microservices**  
微服务，通过 API 访问服务，并使用容器和无服务器等技术。

**Microwave motion detector**  
微波运动探测器，使用微波能量的主动运动探测器。

**Middleware**  
中间件，连接程序到程序。

**Minimum Operating Requirements**  
参见——**MOR**

**Minimum security requirements**  
最低安全要求，描述第三方公司与组织开展业务所需的基线安全控制。

**Minutiae**  
细节特征，包括漩纹、脊线、分叉等在内的特定指纹细节。

**Mirroring**  
镜像，将数据完全复制到另一磁盘，某些 RAID 级别使用此技术。

**Mission Owners**  
参见——**Business Owners**

**Misuse Case Testing**  
误用案例测试，建模对手滥用应用程序的影响。

**Mobile sites**  
移动站点，DRP 备份站点选项，即“轮式数据中心”；包含计算机设备机架、暖通空调、灭火和物理安全的可拖拽拖车。

**Modem**  
调制解调器；获取二进制数据并将其调制为可在电话网络上传输的模拟声音。

**Modes of Operation**  
操作模式，专用、系统高、分区和多级模式。

**Monitor mode**  
用于嗅探的 802.11 只读模式。

**Monoalphabetic cipher**  
单表代换密码，使用一个字母表的替换密码。

**Monolithic kernel**  
宏内核，静态编译的内核。

**MOR**  
**Minimum Operating Requirements**，最低运行要求，描述运行计算机设备所需的最低环境和连接要求。
