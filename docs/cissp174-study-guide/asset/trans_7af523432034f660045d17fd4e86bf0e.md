
# 全盘加密 (FDE)

全盘加密 (FDE)，也称为整盘加密，可加密整个磁盘。这优于部分加密解决方案，例如加密卷、目录、文件夹或文件。后一种方法的问题在于存在将敏感数据留在磁盘未加密区域的风险。例如，将文件从未加密目录拖放到加密目录可能会留下作为未分配数据的未加密数据。

## 持续监控

威胁、漏洞和资产形势在不断变化。组织历来最关注季度扫描、年度审计，甚至临时审查期间的安全性。虽然定期检查很有价值，但对手的 24×7 特性始终存在。持续监控的一个目标是迁移到内联模式。从架构上讲，主动响应 NIPS 类似于 [图 8.12](#Ch008_361-457_B9780443187346000064_1.xhtml#f0065) 中的 NIDS；区别在于监控接口是读/写的。主动响应 NIPS 可通过多种方法“拦截”恶意流量，包括向源、目的（或两者）伪造 TCP RST 段，或向源发送 ICMP 端口、主机或网络不可达消息。

Snort 是一款流行的开源 NIDS 和 NIPS（参见 [www.snort.org](http://www.snort.org)），具有以下主动响应规则：

- `reset_dest`：向目的发送 TCP RST
- `reset_source`：向源发送 TCP RST
- `reset_both`：向源和目的均发送 TCP RST
- `icmp_net`：向源发送 ICMP 网络不可达
- `icmp_host`：向源发送 ICMP 主机不可达
- `icmp_port`：向源发送 ICMP 端口不可达
- `icmp_all`：向源发送 ICMP 网络、主机和端口不可达

内联 NIPS 处于流量“内联”位置，通过放行或允许流量发挥第 3-7 层防火墙的作用，如 [图 8.13](#Ch008_361-457_B9780443187346000064_1.xhtml#f0070) 所示。
