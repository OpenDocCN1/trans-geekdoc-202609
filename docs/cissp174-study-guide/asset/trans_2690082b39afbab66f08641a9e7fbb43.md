## 2. 哪种形式的人工智能使用知识库和推理引擎？

1.  A. 人工神经网络（ANN）
2.  B. 贝叶斯过滤
3.  C. 专家系统
4.  D. 遗传算法

### 正确答案及解析：C

答案 `C` 正确；专家系统由两个组件组成：一个由“如果/那么”语句组成的知识库。这些语句包含专家系统用于决策的规则。第二个组件是推理引擎。

### 错误答案及解析：A、B 和 D

答案 `A`、`B` 和 `D` 不正确。人工神经网络（ANN）模拟人类和动物大脑中的神经网络。贝叶斯过滤使用数学公式分配概率以做出决策，例如识别垃圾邮件。遗传算法和编程从根本上改变了软件开发方式：软件不再由程序员编写，而是通过进化来解决问题。

## 3. 什么敏捷方法论专注于通过流水线快速部署代码更新？

1.  A. 安全编排、自动化与响应（SOAR）
2.  B. DevSecOps
3.  C. 集成开发环境（IDE）
4.  D. 持续集成和持续交付（CI/CD）

### 正确答案及解析：D

答案 `D` 正确；持续集成和持续交付（CI/CD）专注于通过流水线快速部署代码更新。

### 错误答案及解析：A、B 和 C

答案 `A`、`B` 和 `C` 不正确。安全编排、自动化与响应（SOAR）是一种用于集中管理安全运营的敏捷方法论。DevSecOps（开发、安全与运维）将安全集成到 DevOps 流程中，延续了对敏捷方法论的关注。集成开发环境（IDE）通过为程序员提供一个可执行多种功能的单一界面来提高生产力。

## 4. 什么描述了一种更敏捷的开发和支持模型，其中开发人员直接支持运维？

1.  A. DevOps
2.  B. Sashimi
3.  C. Spiral
4.  D. Waterfall

### 正确答案及解析：A

答案 `A` 正确；DevOps 是一种更敏捷的开发和支持模型，其中开发人员直接支持运维。

### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。Sashimi、Spiral（螺旋模型）和 Waterfall（瀑布模型）是软件开发方法论，它们不描述开发人员直接支持运维的模型。

## 5. 在系统开发生命周期（SDLC）的哪个阶段，安全应成为流程的一部分？

1.  A. 启动前
2.  B. 开发/获取期间
3.  C. 系统实施时
4.  D. SDLC 不包含安全流程

### 正确答案及解析：A

答案 `A` 正确；安全是整个 SDLC 流程的关键组成部分，通常始于启动前的安全计划。

### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。安全是 SDLC 的第一步，也是 SDLC 每个阶段的一部分。

## 6. 一个对象根据输入消息的上下文不同而表现出不同的行为。这说明了面向对象编程的哪个概念？

1.  A. 委托
2.  B. 继承
3.  C. 多实例化
4.  D. 多态

### 正确答案及解析：D

答案 `D` 正确；多态（基于希腊词根“poly”和“morph”，分别意为“多”和“形”）：允许重载运算符，根据输入消息的上下文执行不同的方法。

### 错误答案及解析：A、B 和 C

答案 `A`、`B` 和 `C` 不正确。委托允许对象将消息委托给其他对象。继承意味着对象从其父类继承能力。多实例化意为“多个实例”，即两个名称相同但数据不同的对象。

## 7. 两个同名对象拥有不同的数据。这说明了面向对象编程的哪个概念？

1.  A. 委托

4.  D. 多态

### 正确答案及解析：C

答案 `C` 正确；多实例化意为“多个实例”，即两个名称相同但拥有不同数据的对象。

### 错误答案及解析：A、B 和 D

答案 `A`、`B` 和 `D` 不正确。委托允许对象将消息委托给其他对象。继承意味着对象从其父类继承能力。多态允许重载运算符，根据输入消息的上下文执行不同的方法。

## 9. 程序员为用户名变量分配了 20 字节，攻击者输入了一个 1000 字节长的用户名。所有 1000 字节都被复制到了栈中。攻击者执行了哪种类型的攻击？

1.  A. 缓冲区溢出
2.  B. 跨站脚本攻击（XSS）
3.  C. 模糊测试
4.  D. 检查时间/使用时间（TOC/TOU）

### 正确答案及解析：A

答案 `A` 正确；当程序员未执行变量边界检查时，会发生缓冲区溢出。

### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。跨站脚本攻击（XSS）利用第三方在受信任站点的安全上下文中执行 Web 脚本语言（如 JavaScript）。模糊测试是一种黑盒软件测试形式，将随机畸形数据作为输入输入软件程序以确定其是否会崩溃。检查时间/使用时间（TOCTOU）攻击也称为竞争条件：攻击者试图在操作系统检查条件后、使用条件前修改该条件。
