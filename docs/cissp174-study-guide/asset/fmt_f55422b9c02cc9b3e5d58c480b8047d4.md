
# Metasploit 框架与 Meterpreter

Metasploit 是一个极其流行的免费开源利用框架。Metasploit 框架最重要的成就之一是对攻击的底层组件进行了模块化。这种模块化使得利用开发者能够专注于其核心能力，而无需在分发甚至开发其利用程序的投递、定位和载荷机制上耗费精力；Metasploit 提供了可复用的组件以减少额外工作。

载荷是 Metasploit 在成功利用目标后执行的操作；Meterpreter 是最强大的 Metasploit 载荷之一。作为 Meterpreter 提供的部分功能示例，图 8.1 展示了受害计算机的密码哈希被导出到攻击者的机器上。这些密码哈希随后可输入密码破解工具，最终推导出关联的明文密码。或者，这些密码哈希可能直接用于 Metasploit 的 `PsExec` 利用模块，该模块实现了 Microsoft Sysinternals `PsExec` 提供的功能，并经过增强以支持“传递哈希”功能。关于 Sysinternals `PsExec` 的信息可参阅 <https://docs.microsoft.com/en-us/sysinternals/downloads/psexec>。关于“传递哈希”技术的进一步细节可参阅 Bashar Ewaida 的优秀白皮书 <https://www.sans.org/white-papers/33283/>。

除了导出密码哈希，Meterpreter 还提供以下功能：

*   远程系统命令执行
*   文件上传或下载
*   屏幕捕获
*   键盘记录
*   禁用防火墙
*   禁用杀毒软件
*   注册表查看和修改（如图 8.2 所示）
    ![图 8.2 使用 Meterpreter 导出注册表](images/B9780443187346000064/f08-02-9780443187346.jpg)
    **图 8.2** 使用 Meterpreter 导出注册表。
*   权限提升
*   以及更多：Meterpreter 的功能会定期更新

除了上述功能，Meterpreter 在设计时就考虑了规避检测。Meterpreter 几乎可以在不在受害系统上创建新文件的情况下提供上述所有功能。Meterpreter 完全在被利用的受害进程上下文中运行，所有信息均存储在物理内存中而非硬盘上。

设想攻击者已执行上述所有操作，取证调查人员拔掉了受害机器的电源，销毁了易失性内存：调查人员将几乎没有任何信息可供分析。Metasploit 的 Meterpreter 或类似高级载荷可能被用于入侵，这使得易失性数据获取成为当前利用时代的必要手段。

# 网络取证

网络取证是对运动中数据的研究，特别关注通过可支持法庭采纳的流程收集证据。这意味着数据的完整性至关重要，收集过程的合法性亦然。网络取证与网络入侵检测密切相关：前者侧重法律，后者侧重运营。SANS 学院这样强调网络取证的重要性：“在任何取证调查中，极少不涉及网络组件。终端取证将始终是该职业的关键基础技能，但忽视其网络通信无异于忽视犯罪发生时的安防摄像头录像。无论您处理入侵事件、数据窃取案件、员工滥用场景，还是从事主动对手发现，网络往往能提供事件无与伦比的视角。其证据可提供必要的证明以显示意图、揭露活跃数月甚至更久的攻击者，甚至可能在确凿证明犯罪实际发生方面发挥作用” [3]。

# 取证软件分析

取证软件分析侧重于软件的比较或逆向工程：恶意软件逆向工程是最常见的例子之一。调查人员通常会获得恶意程序的二进制副本，并寻求推断其行为。

用于取证软件分析的工具包括反汇编器和软件调试器。虚拟化软件也大有裨益：调查人员可有意用恶意软件样本感染虚拟操作系统，然后密切监控其行为表现。

# 嵌入式设备取证

数字取证领域面临的最大挑战之一是消费级电子硬件和嵌入式设备的激增。虽然取证调查人员已有数十年时间理解和开发工具、技术来分析磁盘，但固态硬盘（SSD）等较新技术既缺乏取证理解，也缺乏能够分析的取证工具。

Vassilakopoulos Xenofon 在其论文“GPS 取证，一种通过取证就绪获取 GPS 证据的系统方法”中探讨了这一挑战：“数字取证领域长期以来一直以硬盘等传统介质为中心。作为分发中最常见的数字存储设备，它们成为主要证据点显而易见。然而，随着技术将数字存储带入存储容量不断增长的更多设备，取证检查员需要为证据设备类型的变化做好准备。手机、GPS 接收器和平板电脑已变得如此普遍，以至于成为当今数字检查的标准。这些小型设备给取证检查员带来了沉重负担，从现场到实验室有不同的处理规则，数据类型也像嫌疑人一样多样。手持设备植根于其自身的操作系统、文件系统、文件格式和通信方法。应对这些会给检查员带来独特问题” [4]。

# 电子取证

电子取证，或称 eDiscovery，指法律顾问在民事法律程序的庭前取证阶段获取相关电子信息。取证的总体目的是收集潜在证据以构建案件。电子取证与传统取证的区别仅在于 eDiscovery 寻求 ESI（电子存储信息），这通常通过取证调查获取。尽管传统取证与 eDiscovery 的差异看似微小，但考虑到组织存储的潜在海量电子数据，eDiscovery 在后勤和财务上可能极为繁重。

与 eDiscovery 相关的部分挑战源于组织看似无害的备份策略。虽然计算机信息的长期存储通常被认为是良好的实践，但这些数据可被取证。要具有可取证性（即可供法律取证），ESI 无需方便访问或传输。举证责任落在组织身上，组织必须向对方律师提供数据，几乎不考虑组织实际提供 ESI 所产生的成本。
