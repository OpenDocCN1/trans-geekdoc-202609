
虽然最初面向 Web，但 SSL 或 TLS 可用于加密多种类型的数据，并可用于隧道传输其他 IP 协议以形成 VPN 连接。SSL VPN 可能比其 IPsec 对应物更简单：IPsec 对 IP 网络进行了根本性更改，因此安装 IPsec 软件会更改操作系统（这需要超级用户权限）。SSL 客户端软件不需要更改操作系统。此外，IPsec 很难通过防火墙；SSL 则简单得多。

## 远程访问

在远程办公和移动办公的时代，安全的远程访问是一项关键控制。这包括通过 DSL 或有线调制解调器等方式连接移动用户，回拨等安全机制，以及即时通讯和远程会议技术等较新的关注点。

### ISDN

综合业务数字网（ISDN）曾尝试通过“铜线对”提供数字服务，即普及于全球家庭和小型办公室的 `POTS`（普通老式电话服务）。这被称为“最后一英里”，通过（历史上为铜线对的）最后一英里提供高速数字服务一直是一个长期存在的挑战。

ISDN 设备称为终端。ISDN 基本速率接口（BRI）服务通过铜线对提供两个 64 K 数字信道（外加一个 16K 信令信道）。PRI（主速率接口）提供二十三个 64K 信道，外加一个 16K 信令信道。

ISDN 从未在家庭中得到广泛应用；它很快就被 DSL 和有线调制解调器所取代。ISDN 通常用于电话会议和视频会议。

### DSL

数字用户线路（DSL）拥有类似于 ISDN 的“最后一英里”解决方案：利用现有的铜线对为家庭和小型办公室提供数字服务。与 ISDN 相比，DSL 因速度更高而获得了更广泛的应用，速度可达 10 兆比特及以上。

常见的 DSL 类型包括对称数字用户线路（SDSL，上传和下载速度匹配）、非对称数字用户线路（ADSL，下载速度快于上传）和超高速数字用户线路（VDSL，具有快得多的非对称速度）。另一种选择是 HDSL（高速率 DSL），它使用两对铜线达到 SDSL 的速度；HDSL 用于提供廉价的 T1 服务。

对称 DSL 也称为单线 DSL。ADSL 的一个优势是它允许同时使用 POTS 线路，通常可从 DSL 流量中分离出来。一般来说，站点距离中心局（CO）越近，可用服务速度越快。

| 类型 | 下载速度 | 上传速度 | 距离中心局 |
| --- | --- | --- | --- |
| ADSL | 1.5–9 Mbps | 16–640 Kbps | 18,000 英尺 |

### 有线调制解调器

`Cable modems` 由有线电视提供商用于通过宽带有线电视提供互联网接入。有线电视接入并非无处不在，但在工业化地区的大多数大城镇和城市都可用。宽带与基带不同，拥有多个信道（如电视频道），因此为网络服务分配带宽需要为此目的专用信道。有线调制解调器为有线电视公司提供了一个引人注目的“最后一英里”解决方案：他们已经投资连接了最后一英里，而互联网服务则基于该投资提供了另一条收入来源。

与 DSL 不同，有线调制解调器带宽通常与同一网段上的邻居共享。

### 回拨和来电显示

`Callback` 是一种基于调制解调器的认证系统。创建回拨账户时，会将用户拨打的调制解调器号码录入账户。用户稍后通过调制解调器连接并进行认证。系统挂断后，再回拨到预配置的号码。

`Caller ID` 是一种类似的方法：除了用户名和密码外，它要求从正确的电话号码拨打。来电显示很容易被伪造：许多电话服务商允许最终用户选择任何他们想要的来电显示号码。这使得来电显示成为一种薄弱的认证形式。

### 远程桌面控制台访问

许多用户需要远程访问计算机的控制台。自然，应使用某种形式的安全通道，如 IPsec VPN、SSH 或 SSL 隧道，以确保连接的机密性，特别是当连接源自组织外部时。有关远程控制台访问这一层的更多详细信息，请参阅上文的“VPN”部分。

几十年来，使用协议远程访问控制台一直是常见做法，例如类 UNIX 操作系统上明文且认证薄弱的 rlogin 和 rsh，它们分别利用 TCP 端口 513 和 TCP 端口 514。提供远程桌面访问的两种常见现代协议是虚拟网络计算（VNC），通常运行在 TCP 5900 上，以及远程桌面协议（RDP），通常运行在 TCP 端口 3389 上。VNC 和 RDP 允许对远程系统进行图形化访问，这与基于终端的旧式远程访问方法形成对比。RDP 是微软的专有协议。

越来越多的用户期望能快速、从任意数量的个人设备通过互联网轻松访问图形化桌面。出于安全考虑，传统的基于 VNC 和 RDP 的方法通常通过 VPN 等加密通道进行隧道传输，这使得满足这些期望变得困难。

这些方法的一个近期替代方案是使用反向隧道，它允许建立出站加密隧道的用户通过同一隧道连接回来。这通常需要在用户计算机上安装一个小型代理，该代理将使用 HTTPS over TCP 443 发起出站连接。该连接将终止于一台中央服务器，用户可对其进行认证（从办公室外部）以控制其办公室桌面机器。采用这种方法的两个最著名的解决方案是 GoToMyPC 和 LogMeIn。

### 桌面和应用虚拟化

除了远程访问独立桌面系统外，提供对计算资源远程访问的另一种方法是通过桌面和应用虚拟化。桌面虚拟化是一种提供集中式基础设施的方法，该基础设施托管可由员工远程利用的桌面镜像。桌面虚拟化通常称为 VDI，根据相关供应商不同，代表虚拟桌面基础设施或虚拟桌面接口。VDI 也称为 DaaS（桌面即基础设施）。

与提供完整桌面环境相反，组织可以选择仅虚拟化将集中提供的关键应用程序。与桌面虚拟化一样，应用虚拟化相关的集中控制允许组织实施严格的访问控制，并可能更快地修补应用程序。此外，应用虚拟化还可用于运行传统应用程序，否则这些应用程序将无法在员工使用的系统上运行。
