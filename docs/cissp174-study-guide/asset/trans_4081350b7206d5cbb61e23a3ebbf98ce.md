
# 工业控制系统 (ICS)

工业控制系统 (ICS) 是发电、制造和自动化等行业使用的计算机。历史上，工业控制系统中使用的协议（如 `Modbus`）均为明文且相当不安全。这种风险曾因这些系统（过去）通常与互联网隔离，并依赖串行通信（很像调制解调器）在一个设施内进行通信而得到缓解。多年来，这种情况已发生相当大的变化，这些系统现在通常连接到互联网。以前使用串行线路的协议（如 `Modbus`）已更新为使用 `TCP/IP`（`Modbus TCP`）。不幸的是，`Modbus TCP` 是明文的，需要加密隧道才能安全传输。

Dong-Ho Kang、Byoung-Koo Kim、Jung-Chan Na 对 `Modbus` 进行了如下描述：*Modbus 中不存在安全要素。任何能够访问 Modbus 服务器的攻击者都能够读写现场设备，以及重启设备和运行诊断命令。Modbus 协议的简单性以及免费 Modbus 客户端的广泛可用性，使得攻击 Modbus 服务器变得相对简单* [\[25\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0130)。

## 重要 ICS 术语

*   **数据采集与监视控制系统 (SCADA)：** SCADA（即数据采集与监视控制）系统是指一个由若干远程终端单元（或 RTU）组成的系统，这些单元采集现场数据并通过通信系统连接回主站。
*   **远程终端单元 (RTU)：** RTU（有时称为远程遥测单元）顾名思义，是一个独立的数据采集和控制单元，通常基于微处理器，用于监控和控制距离中央站较远位置的设备。
*   **分布式控制系统 (DCS)：** 在 DCS 中，数据采集和控制功能由若干基于微处理器的分布式单元执行，这些单元位于受控设备附近或采集数据的仪表附近 [\[26\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb261)。
*   **可编程逻辑控制器 (PLC)：** 一种小型、模块化的固态计算机，带有用于执行特定任务的定制指令。PLC 用于工业控制系统 (ICS) 的各种行业，已很大程度上取代了机械继电器、鼓式定序器和凸轮定时器 [\[27\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0135)。

# 系统漏洞、威胁和对策

系统威胁、漏洞和对策描述了安全架构和设计漏洞，以及可能危害系统安全的相应利用手段。我们还将讨论降低相关风险的对策或缓解措施。

## 电磁辐射

*电磁辐射* 是指从电子系统逸出的能量，在特定情况下可被远程监控。能量包括电磁干扰，将在本章后面讨论。

《Wired Magazine》在文章“解密的 NSA 文件揭示 TEMPEST 秘史”中讨论了电子辐射的发现：“那是 1943 年，一位贝尔电话工程师正在研究美国政府最敏感、最重要的战时机械之一——贝尔电话 131-B2 型……然后他注意到了一些奇怪的事情。实验室远处，一个独立的示波器养成了一个习惯：每当电传打字机加密一个字母，它就会尖峰一次。仔细检查后，这些尖峰可以转译为该机器正在处理的明文消息。尽管他当时可能并不知情，但这位工程师刚刚发现了所有信息处理机器都会将其秘密发送到电磁以太中” [\[28\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0140)。

基于这一发现，开发了 *TEMPEST*（并非首字母缩写，而是美国国家安全局的一个代号），作为一项屏蔽计算机设备电磁辐射的标准。

## 隐蔽信道

*隐蔽信道* 是指任何违反安全策略的通信。安装在系统上的恶意软件用于定位个人身份信息 (PII)（如信用卡信息）并将其发送到恶意服务器所使用的通信信道，就是隐蔽信道的一个例子。隐蔽信道有两种具体类型：*存储信道* 和 *时序信道*。

隐蔽信道的对立面是 *公开信道*：符合安全策略的授权通信。

### 隐蔽存储信道

存储信道示例使用共享存储（如临时目录）来允许两个主体相互发送信号。设想 Alice 是拥有最高机密许可的主体，而 Bob 是拥有机密许可的主体。Alice 拥有她想与 Bob 共享的最高机密信息，但强制访问控制 (MAC) 系统会阻止她这样做。

Bob 可以看到 Alice 临时文件的大小，但看不到内容。他们制定了一种代码：1 兆字节文件意味着战争迫在眉睫（标记为最高机密的数据），0 字节文件意味着“一切安全”。Alice 在临时目录中维护一个 0 字节文件，直到战争迫在眉睫时将其改为 1 兆字节文件，从而向 Bob 发送信号，违反了系统的 MAC 策略。

### 隐蔽时序信道

隐蔽时序信道依赖系统时钟来推断敏感信息。隐蔽时序信道的一个例子是不安全的登录系统。该系统配置为：如果用户输入正确的用户名但密码错误，或用户名和密码均错误，则提示“用户名或密码错误”。这样做是为了防止外部攻击者推断真实用户名。

我们这个不安全的系统在用户输入错误用户名/错误密码时会立即打印“用户名或密码错误”，但当用户输入正确用户名但密码错误时，会有轻微延迟（由于检查加密哈希所需的时间）。这种时序延迟允许攻击者推断哪些用户名是正确或错误的，违反了系统的安全设计。

## 后门

*后门* 是系统中的一种捷径，允许用户绕过安全检查（如用户名/密码认证）进行登录。攻击者在攻破系统后通常会安装后门。例如，攻击者通过利用缺失补丁导致的漏洞获得系统的 Shell 访问权限。攻击者希望保持访问权限（即使系统打了补丁），因此她安装了一个后门以允许未来的访问。

*维护钩子* 是一种后门；它们是系统设计人员和程序员安装的捷径，旨在允许开发人员在开发期间绕过正常的系统检查，例如要求用户认证。如果维护钩子保留在生产系统中，就会成为安全问题。

## 恶意代码

*恶意代码* 或 *恶意软件* 是攻击应用程序或系统的任何类型软件的统称。恶意代码有多种类型；病毒、蠕虫、特洛伊木马和逻辑炸弹都可能对目标系统造成损害。

零日漏洞利用是指没有供应商提供的补丁的恶意代码（威胁）（意味着存在未修补的漏洞）。

### 计算机病毒

计算机病毒是不会自动传播的恶意软件：它们需要载体（通常是人）。它们经常通过软盘传播，以及（最近更多地）通过便携式 USB (通用串行总线) 内存传播。这些设备可能被物理携带并插入多台计算机。

病毒类型包括：

*   **宏病毒：** 使用宏语言编写的病毒（如 Microsoft Office 或 Microsoft Excel 宏）
*   **引导扇区病毒：** 感染 PC 引导扇区的病毒，确保病毒在系统启动时加载
