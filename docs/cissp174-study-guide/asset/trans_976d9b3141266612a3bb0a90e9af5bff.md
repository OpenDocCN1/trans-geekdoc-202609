# 作者简介

**Eric Conrad** (`CISSP®`, `GIAC GSE`, `GPEN`, `GCIH`, `GCIA`, `GCFA`, `GAWN`, `GSEC`, `GMON`, `GISP`) 是SANS Institute Fellow（资深研究员）兼Backshore Communications的首席技术官，该公司提供威胁狩猎、渗透测试、事件处理和入侵检测咨询服务。Eric于1991年开始其职业生涯，在一家小型海洋通信公司担任UNIX系统管理员。他在研究、教育、电力、互联网和医疗保健等多个行业积累了信息安全经验，职位涵盖从系统程序员到安全工程师，再到HIPAA安全官和ISSO。他合著了`MGT414: SANS Training Program for the CISSP Certification`、`SEC511: Continuous Monitoring and Security Operations`和`SEC542: Web App Penetration Testing and Ethical Hacking`。Eric毕业于SANS Technology Institute，获得信息安全工程理学硕士学位。

**Seth Misenar** (`CISSP®`, `GSE`, `GDSA`, `GDAT`, `GMON`, `GCDA`, `GCIH`, `GCIA`, `GCFA`) 担任SANS Institute Faculty Fellow（教职研究员）兼Context Security, LLC的首席顾问（总部位于密西西比州Jackson）。他是全球精英安全专家之一，获得了`GIAC GSE (#28)`认证。Seth的专业领域包括安全研究、网络防御与安全运营、安全架构和云安全。Seth曾为财富100强公司担任物理和网络安全顾问，并担任过州政府机构的HIPAA和信息安全官。Seth为SANS Institute教授各种网络安全课程，包括两门他合著的热门课程：最畅销的`SEC511: Continuous Monitoring and Security Operations`和`MGT414: SANS Training Program for the CISSP Certification`。Seth拥有Millsaps College的理学学士学位。
