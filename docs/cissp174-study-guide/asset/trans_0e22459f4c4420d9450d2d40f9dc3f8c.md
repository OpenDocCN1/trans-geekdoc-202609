## 第 2 章：领域 1：安全与风险管理

### 问题 1
**以下哪项是策略声明的示例？**

1.  A. 通过加固服务器来保护 PII
2.  B. 首先安装预加固的操作系统镜像来加固 Windows 11
3.  C. 你可以通过选取句子中每个单词的首字母并混合数字和符号来创建强密码
4.  D. 下载 CISecurity Windows 基准并应用它

**正确答案与解析：** **A**。答案 **A** 正确；策略是高层级的，避免技术细节。

**错误答案与解析：** **B**、**C** 和 **D**。答案 **B**、**C** 和 **D** 不正确。**B** 是程序声明。**C** 是指南。**D** 是基线。

### 问题 2
**以下哪项描述了通过实施安全控制所节省的资金？**

1.  A. 总拥有成本
2.  B. 资产价值
3.  C. 投资回报率
4.  D. 控制节省

**正确答案与解析：** **C**。答案 **C** 正确；投资回报率 (ROI) 是通过安全控制保护资产所节省的资金数额。

**错误答案与解析：** **A**、**B** 和 **D**。答案 **A**、**B** 和 **D** 不正确。总拥有成本是实施安全控制的成本。资产价值是受保护资产的价值。控制节省是一个干扰项，它在不使用正确术语的情况下描述了 ROI。

### 问题 3
**根据《通用数据保护条例》(GDPR)，违规的最高罚款是多少？**

1.  A. 2000 万欧元或全球收入的 4%（以较低者为准）
2.  B. 2000 万欧元或全球收入的 4%（以较高者为准）
3.  C. 2000 万欧元或全球利润的 4%（以较低者为准）
4.  D. 2000 万欧元或全球利润的 4%（以较高者为准）

**正确答案与解析：** **B**。答案 **B** 正确；GDPR 最高罚款为 2000 万欧元或全球收入的 4%（以较高者为准）。

**错误答案与解析：** **A**、**C** 和 **D**。答案 **A**、**C** 和 **D** 不正确。最高罚款以两者中的较高者为准，且基于全球收入而非利润。

### 问题 4
**以下哪项证明身份声明？**

1.  A. 认证
2.  B. 授权
3.  C. 问责
4.  D. 审计

**正确答案与解析：** **A**。答案 **A** 正确；认证证明身份声明。

**错误答案与解析：** **B**、**C** 和 **D**。答案 **B**、**C** 和 **D** 不正确。授权描述主体被允许执行的操作。问责通过提供审计数据来追究用户责任。审计验证是否符合信息安全框架。

### 问题 5
**以下哪项防止对数据的未授权更改？**

1.  A. 机密性
2.  B. 完整性
3.  C. 可用性
4.  D. 篡改

**正确答案与解析：** **B**。答案 **B** 正确；完整性防止对数据的未授权更改。

**错误答案与解析：** **A**、**C** 和 **D**。答案 **A**、**C** 和 **D** 不正确。机密性防止数据未授权泄露。可用性意味着系统可供正常业务使用。篡改是对数据的未授权更改：与完整性相反。
