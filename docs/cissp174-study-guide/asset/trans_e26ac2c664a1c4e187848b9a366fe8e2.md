

# 取证工具与分析

随着与调查相关的数据复杂性和数量稳步增加，工具的使用对于取证分析师高效开展分析至关重要。虽然使用任何特定工具可能并非可靠呈现证据的明确要求，但取证工具确实比信息安全领域使用的大多数工具都需要更严格的审查。为此，NIST 维护着公开可用的计算机取证工具测试计划，旨在“确保计算机取证工具的可靠性” [\[2\]](#Ch008_361-457_B9780443187346000064_2.xhtml#bb0015)。

## 取证工作站

鉴于现代调查相关的数据量巨大，取证调查员使用的系统通常需要配备实质性的高端硬件，至少包括：快速、最新一代的处理器；大容量内存；大容量高速磁盘；独立显卡。**取证工作站**一词常用于指代满足这一需求的高端硬件组件集合。

## 写保护器

**写保护器**是一种物理上位于计算机和存储设备之间的便携设备，可防止数据被修改。由于存在各种类型的物理介质和相关接口，写保护器的设计旨在适配这些不同的物理连接器。写保护器通过限制对连接物理介质中存储数据的有意和无意修改，协助保全数据。

## 专用取证镜像硬件

写保护器可协助取证分析师以保全数据的方式获取介质镜像，但它们仍要求分析师将证据连接到其取证工作站、提供目标介质，并运行软件执行镜像获取。**专用取证镜像硬件**通过在独立硬件中提供取证获取所需的硬件和软件，实现了更快、更简便的介质获取。分析师只需连接源介质和目标介质即可。写保护功能内置于镜像硬件中。

## 移动设备取证

移动设备的爆发式增长自然导致其常与取证调查相关。历史上，取证获取主要关注传统辅助存储介质，如硬盘驱动器，或最近的固态硬盘。移动设备通常不允许分离辅助存储以进行介质获取。通常需要**专用移动设备取证硬件和软件**，仅通过将移动设备连接到获取平台即可执行取证获取。

## 取证套件

取证调查的软件方面与基于硬件的取证工具同等重要。获取取证镜像后，与调查相关的实质性工作便可开始。**取证套件**旨在促进并提高数据提取、分析和报告过程的效率。虽然非强制要求，但使用标准取证套件或工具有助于证明：只要提供相同的介质，另一位称职的取证分析师也能复现取证分析的结果。

# 取证工件

取证调查的关键在于对显著工件的分析。**取证工件**就是可能包含与调查相关信息的可观察细节。存在许多类型的工件可能与特定安全事件相关。工件的大类包括但不限于与系统、网络和应用程序相关的工件。这些大类及更详细的分类存在的目的，仅在于允许对其潜在获取和分析采取更结构化的方法。例如，移动设备从广义上可归属于系统范畴；然而，这些系统差异显著，往往需与通用桌面或服务器系统显性区分。

与系统相关的工件类别包括：文件、进程、服务、用户、注册表、Shell 组件、日志等。此外，特定工件及其调查方式可能取决于获取的证据来源于非易失性（如硬盘、固态硬盘）还是易失性（内存/RAM）源。

如上所述，移动设备常被从通用计算系统中单独区分。原因之一在于不同的获取流程，以及工件的不同位置和目标。此外，移动设备还常可用于确定特定时间点的地理位置。

面向网络的工件来源包括：全包捕获、基于流的数据、IDS 警报和 DNS 日志。主机名、IP 地址和端口常用于在这些来源中查找相关的网络工件。

# 取证介质分析

除了实时取证捕获期间收集的宝贵数据外，取证数据的主要来源通常来自辅助存储和便携式存储设备的二进制镜像，如硬盘驱动器、USB 闪存驱动器、CD、DVD，以及可能相关的手机和 MP3 播放器。使用二进制或位流镜像的原因是因为需要原始数据的精确副本。普通备份软件仅会归档磁盘活动分区上的已分配数据。普通备份可能会遗漏攻击者故意删除的重要数据；因此，首选二进制镜像。

以下是基于磁盘的取证数据的四种基本类型：

*   **已分配空间**—磁盘分区中标记为活跃包含数据的部分。
*   **未分配空间**—磁盘分区中不包含活跃数据的部分。这包括从未分配过的部分，以及先前已分配但现标记为未分配的部分。如果文件被删除，存放该已删除文件的磁盘部分会被标记为未分配并可供使用。
*   **松散空间**—数据以称为簇的特定大小块存储（簇有时也称为扇区或块）。簇是文件系统可分配的最小单位。如果特定文件或文件的最后一部分不需要使用整个簇，则簇内会存在一些额外空间。这种剩余空间称为松散空间：它可能包含旧数据，或被攻击者故意用于隐藏信息。
*   **“坏”块/簇/扇区**—硬盘因物理缺陷常会产生无法读取的扇区。操作系统会忽略标记为坏的扇区，因为这些缺陷部分无法读取数据。攻击者可故意将扇区或簇标记为坏，以便在此磁盘部分隐藏数据。

考虑到攻击者可能利用的磁盘级技巧来隐藏取证感兴趣的信息，会使用二进制备份工具，而非仅关注已分配空间的传统备份工具。可用于创建此类二进制备份的工具众多，包括免费工具如 `dd` 和 `dc3dd`，以及商业工具如 AccessData 的 FTK Imager 或 OpenText 的 Tableau Forensic Imager。

## 实例学习：实时取证

传统上取证调查员会给系统断电，但现在的典型方法是收集易失性数据。获取易失性数据称为**实时取证**，相对于从断电系统获取二进制磁盘镜像的**事后取证**。有一款攻击工具凸显了实时取证的必要性。
