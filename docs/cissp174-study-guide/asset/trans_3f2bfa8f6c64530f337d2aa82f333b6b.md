

# 相关计划

正如前文所述，业务连续性计划（BCP）是一项包含其他计划的总体计划。除了灾难恢复计划（DRP）外，其他计划还包括：运营连续性计划（COOP）、业务恢复/复原计划（BRP）、支持连续性计划、网络事件响应计划、人员应急计划（OEP）以及危机管理计划（CMP）。[表 8.5](#Ch008_361-457_B9780443187346000064_1.xhtml#t0030) 摘自 NIST Special Publication 800-34，总结了这些计划。

[表 8.5](#Ch008_361-457_B9780443187346000064_1.xhtml#B-t0030)

**NIST SP 800-34 中 BCP 计划摘要** [[12]](#Ch008_361-457_B9780443187346000064_2.xhtml#bb0065)

| 计划 | 目的 | 范围 |
| :--- | :--- | :--- |
| 业务连续性计划 (BCP) | 提供在从重大中断中恢复期间维持基本业务运营的程序 | 涉及业务流程；IT 仅基于其对业务流程的支持被涉及 |
| 业务恢复（或复原）计划 (BRP) | 提供灾难发生后立即恢复业务运营的程序 | 涉及业务流程；非 IT 为重点；IT 仅基于其对业务流程的支持被涉及 |
| 运营连续性计划 (COOP) | 提供在备用站点维持组织基本战略职能长达 30 天的程序和能力 | 涉及被视为最关键的组织任务子集；通常在总部层面编写；非 IT 为重点 |
| 支持连续性计划 / IT 应急计划 | 提供恢复主要应用程序或通用支持系统的程序和能力 | 同 IT 应急计划；涉及 IT 系统中断；非业务流程为重点 |
| 危机沟通计划 | 提供向人员和公众传播状态报告的程序 | 涉及与人员和公众的沟通；非 IT 为重点 |
| 网络事件响应计划 | 提供检测、响应恶意网络事件并限制其后果的策略 | 专注于针对影响系统和/或网络的事件的信息安全响应 |
| 灾难恢复计划 (DRP) | 提供在备用站点恢复能力的详细程序 | 通常以 IT 为重点；仅限于具有长期影响的重大中断 |
| 人员应急计划 (OEP) | 提供协调程序，以在应对物理威胁时最大限度地减少人员伤亡和财产损失 | 专注于特定设施的人员和财产；非基于业务流程或 IT 系统功能 |

## 运营连续性计划 (COOP)

运营连续性计划（COOP）描述了在灾难期间维持运营所需的程序。这包括将人员转移到备用灾难恢复站点，以及该站点的运营。

## 业务恢复计划 (BRP)

业务恢复计划（也称为业务复原计划）详细说明了在从破坏性事件中恢复后，恢复正常业务运营所需的步骤。这可能包括将运营从备用站点切换回（已修复的）主站点。

业务恢复计划在 COOP 完成后开始执行。该计划范围窄且聚焦：BRP 有时作为附录包含在业务连续性计划中。

## 支持连续性计划

支持连续性计划专门关注对特定 IT 系统和应用程序的支持。它也称为 IT 应急计划，强调 IT 而非通用业务支持。

## 网络事件响应计划

网络事件响应计划旨在应对破坏性网络事件，包括基于网络的攻击、蠕虫、计算机病毒和特洛伊木马。例如，蠕虫等自我传播的恶意代码有可能破坏网络。对于许多组织而言，单纯丧失网络连接就可能构成灾难。

## 人员应急计划 (OEP)

人员应急计划（OEP）提供了“设施人员在发生对人员健康和安全、环境或财产构成潜在威胁的情况时的响应程序。此类事件包括火灾、飓风、犯罪袭击或医疗急救” [[12]](#Ch008_361-457_B9780443187346000064_2.xhtml#bb0065)。该计划侧重于设施，而非业务或 IT。

OEP 侧重于安全和疏散，应描述具体的安全演练，包括疏散演练（也称为消防演练）。应描述具体的安全角色，包括安全监护人和集合点负责人，详见[第 4 章](#Ch004_107-223_B9780443187346000076_1.xhtml)，领域 3：安全架构与工程。

## 危机管理计划 (CMP)

危机管理计划（CMP）旨在在紧急情况或破坏性事件发生时，为组织管理者之间提供有效的协调。CMP 详细说明了管理层必须采取的行动，以确保在灾难发生时立即保护人员的生命安全和财产安全。

### 危机沟通计划

危机管理计划的一个关键组成部分是危机沟通计划（有时简称为沟通计划）：一项在破坏性事件发生时向员工和公众进行沟通的计划。通知受影响组织成员的说明是任何 BCP/DRP 不可或缺的一部分。

# 移动站点

**移动站点** 是“轮子上的数据中心”：可拖拽的拖车，包含计算机设备机架，以及 HVAC（供暖、通风与空调）、火灾抑制和物理安全系统。它们非常适合数据中心洪水等灾难，即数据中心受损但设施其余部分及周边财产完好无损的场景。它们可被拖拽至现场，接入电力和网络，并上线运行。

移动数据中心通常放置在物理财产边界内，并受到围栏、大门和安全摄像头等防御措施的保护。另一个优势是人员可以前往其主要站点和办公室报到。

# 订阅服务

一些组织通过支付费用让另一家公司执行这些服务，从而将其 BCP/DRP 规划和/或实施外包。这实际上将风险转移给了承保公司。这基于一个简单的保险模型，公司建立了利润模型并为客户提供 BCP/DRP 保险服务。云启用的灾难恢复服务提供商变得越来越普遍，甚至拥有了自己的云化术语：DRaaS（灾难恢复即服务）。
