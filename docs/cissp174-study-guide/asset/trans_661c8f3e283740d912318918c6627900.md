## 7. 什么可用于确保软件满足客户的运营需求？

1.  A. 集成测试
2.  B. 安装测试
3.  C. 验收测试
4.  D. 单元测试

### 正确答案与解析：C

答案 `C` 正确；验收测试旨在确保软件满足客户的运营需求。

### 错误答案与解析：A、B 和 D

答案 `A`、`B` 和 `D` 不正确。集成测试测试多个软件组件在组合成工作系统时的表现。安装测试测试软件在安装和首次运行时的表现。单元测试是对软件组件（如函数、过程或对象）的低级测试。

## 8. 什么术语描述了一种无技术或低技术含量的方法，利用人类思维绕过安全控制？

1.  A. 模糊测试
2.  B. 社会工程学
3.  C. 战争拨号
4.  D. 零知识测试

### 正确答案与解析：B

答案 `B` 正确；社会工程学是一种无技术或低技术含量的方法，利用人类思维绕过安全控制。

### 错误答案与解析：A、C 和 D

答案 `A`、`C` 和 `D` 不正确。模糊测试是一种黑盒测试类型，将随机畸形数据作为输入输入软件程序，以确定它们是否会崩溃。战争拨号使用调制解调器拨打一系列电话号码，寻找应答调制解调器的载波音。零知识渗透测试开始时没有任何外部或可信信息，仅使用公开信息开始攻击。

## 9. 什么术语描述了一种黑盒测试方法，旨在识别并测试所有软件输入的唯一组合？

1.  A. 组合软件测试
2.  B. 动态应用安全测试
3.  C. 误用用例测试
4.  D. 静态应用安全测试

### 正确答案与解析：A

答案 `A` 正确；组合软件测试是一种黑盒测试方法，旨在识别并测试所有软件输入的唯一组合。

### 错误答案与解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。动态应用安全测试在代码执行时对其进行测试。误用用例测试正式建模对手滥用应用程序如何实现安全影响。静态应用安全测试被动地测试代码；代码不运行。这包括演练、语法检查和代码审查。

## 10. 什么术语描述了一种确定访问控制有效性的整体方法，且范围广泛？

1.  A. 安全评估
2.  B. 安全审计
3.  C. 渗透测试
4.  D. 漏洞评估

### 正确答案与解析：A

答案 `A` 正确；安全评估是一种确定访问控制有效性的整体方法，且范围广泛。

### 错误答案与解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。安全审计验证对信息安全框架的合规性。渗透测试旨在确定攻击者是否能渗透组织。漏洞评估旨在发现环境中的不良配置和缺失补丁。

## 使用以下场景回答第 11 至 14 题

您是一家大型银行的 CISO，并聘请了一家公司提供整体安全评估，并对您的组织进行渗透测试。您的目标是确定整体信息安全有效性。您特别有兴趣确定窃取财务数据是否可能。

您的银行最近部署了一个定制开发的三层 Web 应用程序，允许客户查询余额、进行转账，并通过用智能手机拍照上传支票图像来存款。除了传统的浏览器界面外，贵公司还为 Apple iOS 和 Android 设备开发了智能手机应用程序。

合同已签署，双方已就范围和交战规则达成一致。银行已提供一名 24/7 值班的 IT 联系人，以防渗透测试期间出现任何意外情况，包括潜在的服务意外中断。

## 11. 假设渗透测试成功，渗透测试公司证明财务数据被盗风险的最佳方式是什么？

1.  A. 指示渗透测试团队对包含财务数据的服务器进行彻底的漏洞评估
2.  B. 指示渗透测试团队下载财务数据、将其编辑并据此报告
3.  C. 指示渗透测试团队只能通过加密且经过认证的通道下载财务数据
4.  D. 在财务数据的同一位置放置一个无害的“标志”文件，并通知渗透测试团队下载该标志

### 正确答案与解析：D

答案 `D` 正确；标志是一个不包含受监管或敏感数据的虚拟文件，放置在系统中与信用卡数据相同的区域，并受相同权限保护。如果测试人员能读取和/或写入该文件，则证明他们本可以对信用卡数据做同样的事。

### 错误答案与解析：A、B 和 C

答案 `A`、`B` 和 `C` 不正确。答案 A 是漏洞评估，而非渗透测试。答案 B 和 C 很危险，可能涉及未经授权访问受监管数据，如医疗记录。

## 12. 哪种类型的渗透测试将导致时间和小时顾问费用的最高效利用？

1.  A. 自动化知识
2.  B. 全知识
3.  C. 部分知识
4.  D. 零知识

### 正确答案与解析：B

答案 `B` 正确；全知识测试比其他形式的渗透测试高效得多，允许渗透测试人员更快地发现薄弱环节。

### 错误答案与解析：A、C 和 D

答案 `A`、`C` 和 `D` 不正确。自动化知识不是有效的考试术语。零知识和部分知识测试都不如全知识测试高效。

## 13. 您希望安全公司测试新的 Web 应用程序，但决定不共享底层源代码。哪种测试类型可用于帮助确定定制 Web 应用程序的安全性？

2.  B. 模糊测试
3.  C. 静态测试
4.  D. 白盒测试

### 正确答案与解析：B

答案 `B` 正确；模糊测试是一种黑盒测试方法，不需要访问源代码。

### 错误答案与解析：A、C 和 D

答案 `A`、`C` 和 `D` 不正确。这些都是需要访问源代码的静态方法。
