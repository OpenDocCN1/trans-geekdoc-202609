
# 术语表

## P

**Punitive damages**  
旨在惩罚个人或组织的损害赔偿。

**Purpose Specification Principle**  
OECD 隐私指南原则，规定数据收集的目的应当是已知的，且后续的数据使用应限于收集时概述的目的。

**PVC**  
`Permanent Virtual Circuit`，永久虚拟电路，一种始终保持连接的电路。

## Q

**QoS**  
`Quality of Service`，服务质量，在分组交换网络上赋予特定流量优于其他流量的优先权。

**Qualitative Risk Analysis**  
使用近似值的风险分析（`RA`）方法。

**Quality of Service**  
参见——`QoS`。

**Quantitative Risk Analysis**  
使用货币等硬性指标的 `RA` 方法。

**Quantum encryption**  
利用量子力学来确定某物是否已被观测，使密钥接收者能够知道密钥是否已被第三方观测。

**Query language**  
用于搜索和更新数据库的语言。

## R

**Race condition**  
参见——`TOCTOU`。

**RAD**  
`Rapid Application Development`，快速应用开发，通过使用原型、“虚拟” GUI、后端数据库等快速开发软件。

**Radio-Frequency Identification**  
参见——`RFID`。

**RADIUS**  
`Remote Authentication Dial In User Service`，远程认证拨号用户服务，一种基于 `UDP` 的第三方认证系统。

**RAID**  
`Redundant Array of Inexpensive Disks`，廉价磁盘冗余阵列，一种使用多个磁盘驱动器来实现更高数据可靠性、更高速度或两者兼备的方法。

**RAID 0**  
`RAID` 条带化集合。

**RAID 1**  
`RAID` 镜像集合。

**RAID 1 + 0**  
`RAID 0` 与 `RAID 1` 结合，有时称为 `RAID 10`。

**RAID 10**  
参见——`RAID 1 + 0`。

**RAID 2**  
`RAID` 海明码。

**RAID 3**  
带专用奇偶校验的 `RAID` 条带化集合（字节级）。

**RAID 4**  
带专用奇偶校验的 `RAID` 条带化集合（块级）。

**RAID 5**  
带分布式奇偶校验的 `RAID` 条带化集合。

**RAID 6**  
带双重分布式奇偶校验的 `RAID` 条带化集合。

**Rainbow Table**  
彩虹表，充当包含大多数或所有可能密码的哈希输出的数据库。

**RAM**  
`Random Access Memory`，随机存取存储器，允许直接访问任意地址的内存。

**Random Access Memory**  
参见——`RAM`。

**Ransomware**  
勒索软件，一种使用 `AES` 等强加密并扣留解密密钥以勒索赎金的恶意软件。

**Rapid Application Development**  
参见——`RAD`。

**RAT**  
`Remote Access Trojans`，远程访问木马，可被远程控制的特洛伊木马。

**RBAC**  
`Role-Based Access Controls`，基于角色的访问控制，主体被分组为角色，每个定义的角色基于角色而非个人拥有访问权限。

**RC4**  
`Rivest Cipher 4`，`WPA` 用于提供机密性的算法。

**RC5**  
`Rivest Cipher 5`，`RSA Laboratories` 的对称分组密码。

**RC6**  
`Rivest Cipher 6`，`RSA Laboratories` 的对称分组密码，`AES` 入围算法。

**Read-through test**  
通读测试，一种简单的灾难恢复测试，通过审查计划以确保恢复所需的组件将可用。

**Read Only Memory**  
参见——`ROM`。

**Real evidence**  
实物证据，由有形或物理对象组成的证据。

**Realm**  
领域，一个逻辑 `Kerberos` 网络。

**Real-time Transport Protocol**  
参见——`RTP`。

**Reciprocal agreement**  
互惠协议，两个组织之间的双向协议，其中一个组织承诺另一个组织在发生灾难时可以迁入并共享空间。也称为互助协议。

**Recovery controls**  
恢复控制，恢复受损系统或流程的控制措施。

**Recovery phase**  
恢复阶段，将先前受损系统恢复到运行状态的事件管理阶段。

**Recovery Point Objective**  
参见——`RPO`。

**Recovery Time Objective**  
参见——`RTO`。

**Reduced Instruction Set Computer**  
参见——`RISC`。

**Reduction analysis**  
归约分析，分析和降低风险的过程。

**Redundant Array of Inexpensive Disks**  
参见——`RAID`。

**Redundant site**  
冗余站点，系统的精确生产副本，具备无缝运行所有必要 IT 操作且不中断最终用户服务的能力。

**Reference monitor**  
参考监视器，在主体和客体之间的所有访问中进行中介。

**Referential integrity**  
参照完整性，要求辅助表中的每个外键都与父表中的主键匹配。

**Registers**  
寄存器，`CPU` 用于存储指令和数据的小型存储位置。

**Regression Testing**  
回归测试，在更新、修改或补丁后测试软件。

**Regulatory law**  
参见——Administrative law（行政法）。

**Relational database**  
关系型数据库，包含相关数据的二维表。

**Religious law**  
宗教法，以宗教教义或解释作为法律理解和法规来源的法律体系。

**Remanence**  
残留磁性/数据残留，移除尝试后可能持续存在的数据。

**Remote Access Trojans**  
参见——`RAT`。

**Remote Authentication Dial In User Service**  
参见——`RADIUS`。

**Remote File Inclusion**  
参见——`RFI`。

**Remote journaling**  
远程日志记录，将数据库检查点和数据库日志保存到远程站点。在主站点发生故障时，可恢复数据库。

**Remote meeting technology**  
远程会议技术，允许用户通过互联网进行在线会议的较新技术，包括桌面共享功能。

**Remote wipe**  
远程擦除，远程擦除移动设备的能力。

**Repeatable**  
可重复，`CMM` 第 2 阶段。

**Repeater**  
中继器，第 1 层设备，在一个端口接收比特，并从另一个端口“重复”发出。

**Reporting phase**  
报告阶段，提供事件最终报告的事件管理阶段。

**Representational State Transfer**  
参见——`REST`。

**Reserved ports**  
保留端口，`TCP/IP` 端口 1023 及以下。

**Responsible disclosure**  
参见——Ethical disclosure（负责任披露/道德披露）。

**REST**  
`Representational State Transfer`，表述性状态转移，用于实现 Web 服务。

**Retina scan**  
视网膜扫描，对供应视网膜的毛细血管进行的生物特征激光扫描。

**Return on Investment**  
投资回报率，通过部署保障措施节省的资金。

**RFC 1918 addresses**  
`RFC 1918` 地址，可用于内部流量的私有 `IPv4` 地址。

**RFI**  
`Remote File Inclusion`，远程文件包含，通过修改 Web `URL` 以包含远程内容。

**RFID**  
`Radio-Frequency Identification`，射频识别，一种非接触式卡技术。

**Rijndael**  
`Rijndael` 密码，即 `AES`，以作者 `Vincent Rijmen` 和 `Joan Daemen` 命名。

**Ring (physical)**  
环形（物理），将节点连接成物理环的物理网络拓扑。

**Ring model**  
环模型，一种 `CPU` 硬件分层形式，将域（如内核模式和用户模式）相互分离和保护。

**RIP**  
`Routing Information Protocol`，路由信息协议，一种使用跳数作为度量标准的距离矢量路由协议。

**RISC**  
`Reduced Instruction Set Computer`，精简指令集计算机，指令短小简单的 `CPU`。

**Risk**  
风险，匹配的威胁和脆弱性。

**Risk-Based Access Control**  
基于风险的访问控制，一种动态访问控制模型，旨在将威胁和脆弱性作为授权过程的一部分进行考量。基于风险的访问控制可能要求主体因访问请求的威胁概况评估而通过 `MFA` 提示。

**Risk Analysis Matrix**  
风险分析矩阵，用于将风险发生的可能性与该风险的后果（或影响）进行映射的象限图。

**Risk maturity modeling**  
风险成熟度建模，持续改进过程的一部分，旨在衡量组织风险管理过程的成熟度。

**Robust Security Network**  
参见——`RSN`。

**Role-Based Access Controls**  
参见——`RBAC`。

**Rollback**  
回滚，在提交失败后恢复数据库。

**ROM**  
`Read Only Memory`，只读存储器，非易失性内存。

**Rootkit**  
`Rootkit`，替换内核和/或操作系统部分组件的恶意软件。

**Rotation Cipher**  
移位密码，将密文每个字符向后固定移动一定数量超过明文字符的替换密码。

**Rotation of duties**  
职务轮换，要求关键职能或职责不由同一人不间断地持续执行。也称为工作轮换。

**Router**  
路由器，第 3 层设备，基于 `IP` 地址将流量从一个 `LAN` 路由到另一个。

**Routing Information Protocol**  
参见——`RIP`。

**RPO**  
`Recovery Point Objective`，恢复点目标，组织所能承受的数据丢失量或系统不可访问时间（以时间衡量）。

**RSN**  
`Robust Security Network`，强健安全网络，`802.11i` 的一部分，允许在发现新漏洞时更改加密密码。

**RST**  
`TCP` 标志，复位（拆除）连接。
