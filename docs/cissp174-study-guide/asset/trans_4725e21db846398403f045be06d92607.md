## 11. 一个数据库包含一个主键为空的条目。违反了哪个数据库概念？

1. A. 实体完整性
2. B. 规范化
3. C. 参照完整性
4. D. 语义完整性

### 正确答案及解析：A

答案 A 正确；实体完整性意味着每个元组都有一个非空的唯一主键。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。规范化旨在使数据库表中的数据在逻辑上简洁、有序且一致。参照完整性意味着辅助表中的每个外键都与父表中的一个主键匹配：如果不成立，则参照完整性已被破坏。语义完整性意味着每个属性（列）的值与属性数据类型一致。

## 12. 哪种漏洞允许第三方在受信任站点的安全上下文中重定向静态内容？

1. A. 跨站请求伪造 (CSRF)
2. B. 跨站脚本攻击 (XSS)
3. C. PHP 远程文件包含 (RFI)
4. D. SQL 注入

### 正确答案及解析：A

答案 A 正确；跨站请求伪造 (CSRF) 允许第三方在受信任站点的安全上下文中重定向静态内容。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。跨站脚本攻击 (XSS)：第三方在受信任站点的安全上下文中执行 Web 脚本语言（如 Javascript）。XSS 与 CSRF 相似；区别在于 XSS 使用主动代码。PHP 远程文件包含 (RFI)：篡改正常的 PHP 变量以引用远程内容，可能导致恶意 PHP 代码的执行。SQL 注入通过前端 Web 服务器操纵后端 SQL 服务器。

## 13. 哪种语言允许 CORBA（公共对象请求代理体系结构）对象通过消息接口进行通信？

1. A. 分布式组件对象模型 (DCOM)
2. B. 接口定义语言 (IDL)
3. C. 对象链接与嵌入 (OLE)
4. D. 对象管理指南 (OMG)

### 正确答案及解析：B

答案 B 正确；接口定义语言 (IDL) 允许 CORBA 对象通过消息接口进行通信。

### 错误答案及解析：A、C 和 D

答案 A、C 和 D 不正确。DCOM（分布式组件对象模型）是一种 Microsoft 对象代理，用于在网络上定位对象。对象链接与嵌入 (OLE) 是 DCOM 的一部分，提供了一种将文档链接到其他文档的方式。对象管理指南是一个干扰项，利用了 OMG 这个术语：对象管理组 (OMG) 开发了 CORBA。

## 14. 哪种数据库高可用性选项允许多个客户端同时访问多个数据库服务器？

1. A. 数据库提交
2. B. 数据库日志
3. C. 复制数据库
4. D. 影子数据库

### 正确答案及解析：C

答案 C 正确；数据库复制镜像一个活动数据库，允许客户端对多个复制数据库进行同时读写。

### 错误答案及解析：A、B 和 D

答案 A、B 和 D 不正确。DBMS 可能会尝试提交更新：使挂起的更改永久化。数据库日志是所有数据库事务的日志。影子数据库类似于复制数据库，但有一个关键区别：影子数据库镜像主数据库的所有更改，但客户端不访问影子数据库。

## 15. 专家系统的哪个组件由“如果/那么”语句组成？

1. A. 逆向链接
2. B. 正向链接
3. C. 推理引擎
4. D. 知识库

### 正确答案及解析：D

答案 D 正确；知识库由“如果/那么”语句组成。这些语句包含专家系统用于做决策的规则。

### 错误答案及解析：A、B 和 C

答案 A、B 和 C 不正确。正向链接从无前提开始，向前工作以确定解决方案。逆向链接从一个前提开始，向后工作。推理引擎遵循由知识库形成的树，并在匹配时触发规则。

# 词汇表

> 本词汇表按首字母缩写词组织：例如，“Data Encryption Standard”条目显示“See—DES”。“DES”条目包含定义。这样做是因为这是技术书籍的合乎逻辑的方法，并允许更快地查找定义。
>
> 第二个原因是鼓励你学习首字母缩写词到术语的映射（反之亦然）。通用知识体系中的正式短语可以提供一条捷径，帮助你在考试题目中抽丝剥茧。了解正式的首字母缩写词可以提供识别问题核心的最快路线图。
>
> 在参加考试前，你应该理解本词汇表中定义的每个术语。通读一遍词汇表是一个很好的最后考前准备步骤，正如简介中“如何准备考试”部分所讨论的那样。

**802.11** 无线网络标准

**\*完整性公理** Biba 属性，规定“不写上”

**\*安全属性** Bell-LaPadula 属性，规定“不写下”

**“坏”块/簇/扇区** 标记为坏的良好磁盘块

**4GL** 第四代编程语言，旨在通过自动创建计算机编程代码来提高程序员效率

**4G** 使用宏基站的第四代蜂窝技术

**5G** 使用小基站的第五代蜂窝技术

**802.11-1997** 802.11 的原始模式，使用 2.4 GHz 频率，运行速率为 2 Mbps

**802.11a** 使用 5 GHz 频率、运行速率为 54 Mbps 的 802.11 模式

**802.11ac** 使用 5 GHz 频率、运行速率高达 1.3 Gbps 的 802.11 模式

**802.11ax** 使用 2.4、5 和 6 GHz 频率、运行速率高达 10 Gbps 的 802.11 模式

**802.11b** 使用 2.4 GHz 频率、运行速率为 11 Mbps 的 802.11 模式

**802.11g** 使用 2.4 GHz 频率、运行速率为 54 Mbps 的 802.11 模式

**802.11i** 第一个提供合理安全性的 802.11 无线安全标准

**802.11n** 同时使用 2.4 和 5 GHz 频率、允许速度达到 144 Mbps 及以上的 802.11 模式

**802.1X** 基于端口的网络访问控制，第 2 层认证

**ABM** 异步平衡模式，HDLC 混合模式，节点可作为主站或从站，无需接收许可即可发起传输

**抽象** 向用户隐藏不必要的细节

**验收测试** 为确保软件满足客户运营需求而进行的测试

**访问聚合** 多个系统授予单个用户的权利总和。可能导致权限蔓延

**访问控制列表** 见—ACL

**访问控制矩阵** 定义特定主体和客体之间存在的访问权限的表

**账户锁定** 在一组失败登录次数后（有时在特定时间段内）禁用账户

**问责制** 让个人对其行为负责

**问责原则** OECD 隐私指南原则，规定个人应有权质疑所持有的任何个人数据的内容，并拥有在发现个人数据不准确或不完整时更新其个人数据的流程
