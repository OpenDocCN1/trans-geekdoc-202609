

## 术语表

### H

**保持定时器**  
距离矢量路由协议的一种防护机制，用于防止路由振荡

**蜜网**  
由多个蜜罐组成的网络

**蜜罐**  
旨在吸引攻击者的系统

**基于主机的入侵检测系统**  
参见—HIDS

**基于主机的入侵防御系统**  
参见—HIPS

**主机到主机层**  
参见—传输层 (TCP/IP)

**主机到主机传输层**  
参见—传输层 (TCP/IP)

**热站点**  
一种备份站点，拥有所有必要的硬件，且关键应用数据实时镜像

**HPC**  
高性能计算，利用海量 CPU 实现每秒千万亿次浮点运算 (FLOPs) 的系统

**HTML**  
超文本标记语言，用于显示网页内容

**HTTP**  
超文本传输协议，一种通过网络传输网页数据的协议

**HTTPS**  
超文本传输安全协议，使用 SSL 或 TLS 的 HTTP

**集线器**  
第 1 层网络接入设备，充当多端口中继器

**混合攻击**  
一种密码攻击，在字典单词的末尾添加、开头添加或更改字符

**混合风险分析**  
结合定量和定性风险分析

**超文本标记语言**  
参见—HTML

**超文本传输协议**  
参见—HTTP

**超文本传输安全协议**  
参见—HTTPS

**虚拟机监控程序**  
控制虚拟客户机与宿主硬件之间访问的软件或操作系统

**虚拟机监控程序模式**  
允许客户机在 Ring 0 下运行，由运行在“Ring -1”的虚拟机监控程序控制

### I

**I/O 控制器枢纽**  
参见—南桥

**IaaS**  
基础设施即服务，提供完整的虚拟化操作系统，由客户从操作系统层面向上进行配置

**ICC**  
参见—智能卡

**ICH**  
参见—南桥

**ICMP**  
互联网控制消息协议，一种用于故障排查和报告错误状况的协议

**ICS**  
工业控制系统，发电、制造和自动化等行业使用的计算机系统

**IDaaS**  
身份即服务，也称为云身份，允许组织利用云服务进行身份管理

**IDE**  
集成开发环境，通过为程序员提供单一界面以执行编辑、语法检查、编译等多种功能来提高生产力

**IDEA**  
国际数据加密算法，一种使用 128 位密钥和 64 位分组大小的对称分组密码

**标识**  
将个人与其身份关联起来的过程

**识别预防性控制**  
NIST SP 800-34 应急计划流程的第三步

**身份即服务**  
参见—IDaaS

**IDL**  
接口定义语言，CORBA 对象用于通信

**IDS**  
入侵检测系统，一种检测型技术控制

**IGP**

**IKE**  
互联网密钥交换，管理 IPsec 加密算法

**IMAP**  
互联网消息访问协议，一种电子邮件客户端协议

**影响**  
损害的严重程度，有时以美元（价值）表示

**增量备份**  
自上次执行任何类型的备份以来所有已更改文件的归档

**个人参与原则**  
经合组织隐私准则原则，规定个人应对其数据拥有控制权

**工业控制系统**  
参见—ICS

**工业、科学和医疗**  
参见—ISM

**推理**  
一种演绎攻击，用户能够利用较低级别的访问权限获取受限信息

**推理引擎**  
专家系统组件，遵循知识库形成的树状结构，当匹配时触发规则

**信息技术基础设施库**  
参见—ITIL

**信息技术安全评估标准**  
参见—ITSEC

**基础设施即服务**  
参见—IaaS

**继承**  
对象从其父类继承能力

**初始级**

**实例**

**无形资产**  
非实物资产，如数据、知识产权和品牌声誉

**集成开发环境**  
参见—IDE

**集成产品团队**  
参见—IPT

**综合业务数字网**

**完整性**

**内部测试**

**知识产权**

**接口定义语言**

**接口测试**  
测试用户与应用程序交互的所有方式，关注适当功能的暴露。从安全角度来看，目标是确保安全性在各种接口上得到统一应用

**互联网控制消息协议**

**互联网密钥交换**

**中断**  
表示发生了异步 CPU 事件

运行 TCP/IP 的私有网络

**入侵检测系统**  
参见—IDS

**入侵防御系统**  
参见—IPS

**IoT**  
物联网，连接互联网的嵌入式设备，如恒温器、婴儿监视器、家电、灯泡和智能电表

**IP**  
互联网协议，包括 IPv4 和 IPv6

**IPS**  
入侵防御系统，一种旨在防止恶意行为的预防性设备

**IPsec**  
互联网协议安全，一套为 IPv4 和 IPv6 提供加密层的协议

**IPT**  
集成产品团队，一个以客户为中心、关注项目整个生命周期的团队

**IPv4**  
互联网协议第 4 版，通常称为 IP。它是互联网的基础协议

**IPv6**  
互联网协议第 6 版，IPv4 的继任者，具有更大的地址空间、更简单的路由和更简单的地址分配

**IPv6 自动配置**  
唯一 IPv6 地址的自动配置，省去了静态寻址或 DHCP 的需要

**IRC**  
互联网中继聊天，一个全球性的聊天服务器和客户端网络

**虹膜扫描**  
对虹膜（眼睛的有色部分）进行的被动生物特征扫描

**ISAKMP**  
互联网安全协会和密钥管理协议，管理 IPsec 安全协会流程

**iSCSI**  
互联网小型计算机系统接口，通过以太网和 TCP/IP 传输的存储区域网络 (SAN) 协议

**ISDN**  
综合业务数字网，通过铜线对提供数字业务

**ISM**  
工业、科学和医疗，划拨供无证使用的无线频段

**ISO 17799**  
国际标准化组织制定的一种广泛的信息安全实践守则方法

**ISO 22301**  
以管理为重点的业务连续性指南，称为“业务连续性管理体系——要求”

**ISO/IEC-27031**  
以技术为重点的业务连续性指南，属于 ISO 27000 系列的一部分

**ITIL**  
信息技术基础设施库，是一个为 IT 服务管理提供最佳服务的框架

**ITSEC**  
信息技术安全评估标准，第一个成功的国际评估模型
