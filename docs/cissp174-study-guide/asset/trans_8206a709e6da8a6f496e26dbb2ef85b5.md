

## 网络与安全知识问答

### 4. 哪种网络线缆类型能在最长距离传输最多数据？

1. A. 同轴电缆
2. B. 光纤
3. C. 屏蔽双绞线 (STP)
4. D. 非屏蔽双绞线 (UTP)

**正确答案及解析：B**。答案 B 正确；光纤网络线缆能传输最多数据且距离最远。

**错误答案及解析：A、C、D**。答案 A、C、D 错误。在这四个选项中，STP 和 UTP 传输距离最短。同轴电缆传输数据量和距离虽比双绞线强，但远不及光纤。

### 5. 哪个设备工作在 OSI 模型的第 2 层？

1. A. 集线器
2. B. 防火墙
3. C. 交换机
4. D. 路由器

**正确答案及解析：C**。答案 C 正确；交换机工作在 OSI 模型的第 2 层（数据链路层）。

**错误答案及解析：A、B、D**。答案 A、B、D 错误。集线器工作在第 1 层（物理层）。包过滤和状态检测防火墙工作在第 3、4 层，电路级代理（如 SOCKS）工作到第 5 层（会话层），应用层代理工作到第 7 层（应用层）。路由器工作在第 3 层（网络层）。

### 6. OSI 模型各层名称自底向上的正确顺序是什么？

1. A. 物理层、数据链路层、传输层、网络层、会话层、表示层、应用层
2. B. 物理层、网络层、数据链路层、传输层、会话层、表示层、应用层
3. C. 物理层、数据链路层、网络层、传输层、会话层、表示层、应用层
4. D. 物理层、数据链路层、网络层、传输层、表示层、会话层、应用层

**正确答案及解析：C**。答案 C 正确；OSI 模型自底向上为：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。可用助记符 "Please Do Not Throw Sausage Pizza Away" 记忆。

**错误答案及解析：A、B、D**。答案 A、B、D 错误。顺序均不正确。

### 7. 以下哪种认证协议使用三次握手认证？

1. A. CHAP
2. B. EAP
3. C. Kerberos
4. D. PAP

**正确答案及解析：A**。答案 A 正确；CHAP（挑战握手认证协议）使用三次握手认证。

**错误答案及解析：B、C、D**。答案 B、C、D 错误。EAP 是可扩展认证协议，描述多种认证方法的框架。Kerberos 是使用票据的单点登录系统。PAP 是密码认证协议，比 CHAP 更简单（步骤更少）。

### 8. 限制蓝牙设备发现依赖于什么的保密性？

1. A. MAC 地址
2. B. 对称密钥
3. C. 私钥
4. D. 公钥

**正确答案及解析：A**。答案 A 正确；限制蓝牙设备发现依赖于 48 位蓝牙 MAC 地址的保密性。

**错误答案及解析：B、C、D**。答案 B、C、D 错误。虽然 E0 是对称密码，但不用于限制发现（用于加密数据）。公钥或私钥也不用于蓝牙发现。

### 9. 哪种无线安全协议也称为 RSN（强健安全网络），且实现了完整的 802.11i 标准？

1. A. AES
2. B. WEP
3. C. WPA
4. D. WPA2

**正确答案及解析：D**。答案 D 正确；WPA2（Wi-Fi Protected Access 2）实现了 802.11i 标准定义的 AES 和 CCMP（计数器模式 CBC-MAC 协议）。

**错误答案及解析：A、B、C**。答案 A、B、C 错误。AES 是 WPA2 的一部分，WPA2 还包含 CCMP，因此 WPA2 是更完整的答案。WEP 是有线等效隐私，一种过时且不安全的协议。WPA 使用 RC4 和 TKIP，安全性低于 WPA2。

### 10. TCP/IP 封装的正确顺序是什么？

1. A. 数据、段、包、帧、比特
2. B. 数据、帧、段、包、比特
3. C. 数据、帧、包、段、比特
4. D. 数据、包、段、帧、比特

**正确答案及解析：A**。答案 A 正确：TCP/IP 封装的正确顺序是数据、段、包、帧、比特。

**错误答案及解析：B、C、D**。答案 B、C、D 均错误。列出的 TCP/IP 封装顺序不正确。

### 11. HDLC 和 SDLC 都支持哪种传输模式？

1. A. 异步平衡模式 (ABM)
2. B. 异步响应模式 (ARM)
3. C. 正常平衡模式 (NBM)
4. D. 正常响应模式 (NRM)

**正确答案及解析：D**。答案 D 正确；HDLC 和 SDLC 都支持正常响应模式 (NRM)，即从节点在获得主节点许可后才能发送。

**错误答案及解析：A、B、C**。答案 A、B、C 错误。HDLC 支持异步平衡模式 (ABM) 和异步响应模式 (ARM)，而 SDLC 不支持。不存在正常平衡模式 (NBM)。

### 12. 哪种 EAP 类型最安全？

1. A. EAP-TLS
2. B. EAP-TTLS
3. C. LEAP
4. D. PEAP

**正确答案及解析：A**。答案 A 正确；EAP-TLS 是最安全（且成本最高）的 EAP 形式，因为它要求服务端和客户端都使用证书。

**错误答案及解析：B、C、D**。答案 B、C、D 错误。EAP-TTLS 和 PEAP 类似，不需要客户端证书。LEAP 是思科专有协议，不需要客户端证书，且存在根本安全弱点。

---

### 13. 哪种 WAN 协议没有错误恢复机制，依赖高层协议提供可靠性？

1. A. ATM
2. B. 帧中继
3. C. SMDS
4. D. X.25

**正确答案及解析：B**。答案 B 正确；帧中继是一种第 2 层分组交换 WAN 协议，没有错误恢复功能。

**错误答案及解析：A、C、D**。答案 A、C、D 错误。ATM 和 SMDS 是基于信元的 WAN 协议，提供纠错。X.25 是类似帧中继的分组交换协议，但 X.25 具有错误恢复功能。

### 14. ZigBee 在美国使用什么频率？

1. A. 784 MHz 和 2.4 MHz
2. B. 868 MHz 和 2.4 MHz
3. C. 915 MHz 和 2.4 MHz
4. D. 2.4 MHz 和 6 MHz

**正确答案及解析：C**。答案 C 正确；ZigBee 在美国使用 915 MHz 和 2.4 MHz。

**错误答案及解析：A、B、D**。答案 A、B、D 错误。中国使用 784 MHz，欧洲使用 868 MHz，5 MHz 不为 ZigBee 使用。

### 15. 通过 IPv4 网络访问 IPv6 网络称为什么？

1. A. CIDR
2. B. NAT
3. C. Translation
4. D. Tunneling

**正确答案及解析：D**。答案 D 正确；通过 IPv4 网络访问 IPv6 网络称为隧道技术。

**错误答案及解析：A、B、C**。答案 A、B、C 错误。CIDR 是无类别域间路由，一种创建灵活子网的方法。NAT 是网络地址转换，用于 IP 地址互转。Translation 是干扰选项。
