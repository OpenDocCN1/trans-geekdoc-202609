

# AH 和 ESP

AH 和 ESP 可以单独使用，也可以组合使用。IPsec 安全关联（`SA`）是一个单工（单向）连接，可用于协商 ESP 或 AH 参数。如果两个系统通过 ESP 通信，它们将使用两个 SA（每个方向一个）。如果系统除了 ESP 还利用 AH，则会再使用两个 SA，总共四个。一个称为安全参数索引（`SPI`）的唯一 32 位数字用于标识每个单工 SA 连接。互联网安全关联和密钥管理协议（`ISAKMP`）管理 SA 的创建过程。

## 隧道模式和传输模式

IPsec 可用于隧道模式或传输模式。隧道模式由安全网关使用（可提供点对点 IPsec 隧道）。ESP 隧道模式加密整个数据包，包括原始数据包头部。ESP 传输模式仅加密数据（不加密原始头部）；这通常用于发送和接收系统能够原生“讲” IPsec 的场景。

AH 对原始 IP 头部进行认证，因此它常用于（配合 ESP）传输模式，因为原始头部未被加密。隧道模式通常单独使用 ESP（原始头部被 ESP 加密，从而受到保护）。

> **注意**
>
> IPsec 是一个由委员会设计的协议示例，这并非赞美。它过于复杂，包含多个重叠的部分。复杂性是安全的敌人。请参阅 Bruce Schneier 和 Niels Ferguson 的 *A Cryptographic Evaluation of IPsec*（IPsec 密码学评估），他们在文中主张应完全移除 AH 模式和传输模式：“我们对 IPsec 的主要批评是其复杂性。IPsec 包含过多的选项和过度的灵活性；完成相同或类似的事情往往有多种方法” [[47]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0235)。参见 <https://www.schneier.com/academic/archives/2003/12/a_cryptographic_eval.xhtml>。

## IKE

IPsec 可以使用多种加密算法，例如用于完整性的 MD5 或 SHA-1，以及用于机密性的三重 DES 或 AES。互联网密钥交换协商算法选择过程。IPsec 隧道的双方通常使用 IKE 协商至最高且最快的安全级别，例如如果双方都支持 AES，则选择 AES 而非单 DES 用于机密性。

# PGP

*Pretty Good Privacy*（PGP，优良隐私协议）将非对称加密带给了大众。Phil Zimmerman 于 1991 年发布 PGP 时引发了争议。这是普通计算机用户首次能够轻松利用非对称加密的力量，它允许陌生人（包括罪犯）在不预先共享密钥的情况下安全通信。

1991 年，PGP 源代码被发布到 Usenet 电子公告板系统后，Zimmerman 因涉嫌违反军火出口管制而遭到美国政府调查。检察官于 1996 年撤销了案件。RSA 公司曾就 Zimmerman 在 PGP 中包含（当时）受专利保护的 RSA 算法向其投诉。Zimmerman 曾鼓励用户若使用该算法则向 RSA 支付许可费。为解决专利问题，Zimmerman 同意停止发布 PGP（尽管副本仍可从其他来源自由获取）。

PGP 提供了现代密码学套件：机密性、完整性、认证和不可抵赖性。它可用于加密电子邮件、文档或整个磁盘驱动器。PGP 使用*信任网*模型来认证数字证书，而非依赖中央证书颁发机构（`CA`）。如果你信任我的数字证书能证明我的身份，信任网意味着你也信任我所信任的所有数字证书。换句话说，如果你信任我，你就信任我所信任的每个人。

# S/MIME

MIME（多用途互联网邮件扩展）提供了一种格式化电子邮件的标准方式，包括字符集和附件。S/MIME（安全/MIME）利用 PKI 对 MIME 编码的电子邮件进行加密和认证。客户端或客户端的电子邮件服务器（称为 S/MIME 网关）可执行加密操作。

# 托管加密

托管加密是指第三方组织持有一份公钥/私钥对的副本。私钥通常被分成两个或多个部分，每个部分由不同的受信任第三方组织托管，只有在获得适当授权（如法院命令）时，才会释放其持有的那部分密钥。这提供了职责分离。

托管加密的一个目标是在个人隐私与执法需求之间提供平衡。另一个目标是确保在密钥丢失或员工离职时，加密数据仍可恢复。

## Clipper 芯片

Clipper 芯片是托管加密标准（`EES`）中使用的技术名称，这是美国政府于 1993 年宣布的一项在电信设备中部署托管加密的计划。该计划引发了媒体风暴，并于 1996 年被放弃。

Clipper 芯片使用 Skipjack 算法，这是一种使用 80 位密钥的对称密码。该算法最初被列为机密。算法的保密性是另一个有争议的问题：算法的保密性并不能提供密码学强度，且保密算法往往被发现相当不安全。Skipjack 后来于 1998 年解密（在 Clipper 芯片计划被放弃之后）。

# 隐写术

隐写术是隐蔽通信的科学。该名称源于希腊语“steganos”和“graphein”，意为“覆盖”和“书写”，即隐蔽书写。例如，加密可为无线电传输提供机密性，但通信本身并未隐藏；仅隐藏了含义。隐写术隐藏了通信正在发生这一事实。

古希腊历史学家希罗多德在《希罗多德历史》中记录了隐写术的首次使用。希罗多德描述了剃光奴隶的头，在头上纹上指令，待头发长回后，派遣奴隶穿越敌军防线。另一种方法将信息藏在兔子的胃里。

现代隐写术将信息隐藏在数据文件（如图像）中。例如，8 位位图有 256 种颜色。假设图像中两个不同的白色像素（称为 `W0` 和 `W1`）在肉眼看来完全相同。你可以通过将 `W0` 和 `W1` 视为比特流来编码消息。

假设文件按以下顺序包含一系列像素：`W1`、`W1`、`W1`、`W1`、`W0`、`W0`、`W0`、`W1`。你想在图像中编码“10101010”。将 `W0` 视为二进制 0，`W1` 视为二进制 1。然后相应地翻转像素，结果为 `W1`、`W0`、`W1`、`W0`、`W1`、`W0`、`W1`、`W0`。[图 4.28](#Ch004_107-223_B9780443187346000076_1.xhtml#f0145) 显示了该过程。白色箭头表示像素未改变；黑色箭头表示像素已改变。

![图 4.28 位图像素的隐写术替换。](images/B9780443187346000076/f04-28-9780443187346.jpg)

[图 4.28](#Ch004_107-223_B9780443187346000076_1.xhtml#B-f0145) 位图像素的隐写术替换。

该图像现包含隐藏消息“10101010”，尽管肉眼看起来相同（且大小未变）。图像的完整性已改变。此方法称为替换法。其他方法包括注入法（向文件添加数据，生成更大的文件）和新建文件法。替换法和注入法需要宿主文件；新建文件法顾名思义创建一个新文件。

通过隐写术隐藏的消息通常先经过加密，从而同时提供数据的机密性和通信的隐蔽性。
