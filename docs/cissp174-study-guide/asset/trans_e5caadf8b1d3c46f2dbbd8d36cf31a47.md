
沙箱技术采用的总体思路是渲染或执行潜在的恶意内容，并分析在一个被充分理解、严格控制、专门用于此目的的牺牲系统上发生的变化。通过测量该虚拟系统上发生的行为和状态变化，沙箱工具可以判断被测文件是恶意、可疑还是良性。虽然沙箱技术既不完美也不充分，但对于与通过基于 Web 的下载或电子邮件获取的恶意内容相关的客户端利用，沙箱技术证明特别有用。

意图是以内联方式部署恶意软件沙箱，从而阻止被判定为恶意或过度可疑的内容的传递。然而，特别是对于基于 Web 的内容，沙箱工具行为分析引入的延迟可能会使其无法配置为阻止内容传递。即使在这种情况下，沙箱工具也能快速检测可疑内容，但需要采取自动或手动的纠正措施来响应警报。

## 端点安全

虽然大多数组织早已部署了边界防火墙、入侵检测系统（`IDS`）以及许多其他以网络为中心的预防和检测对策，但纵深防御要求采用额外的保护层。当防火墙、`IDS`、Web 内容过滤器等被绕过时，端点可能会被攻破。

由于端点是攻击的目标，端点本身的预防和检测能力提供了超越以网络为中心的安全设备的一层防护。现代端点安全套件通常包含除简单防病毒软件之外的无数产品。这些套件能将安全对策的深度提升到远超网关或网络边界的程度。

虽然纵深防御本身是一个值得称道的目标，但端点安全套件为现代组织提供的显著优势远不止安全深度的增加。即使设备超出了组织的边界，这些工具也能帮助提升设备的安全态势，无论是因为设备物理移动，还是因为用户将内部设备连接到了 Wi-Fi 或蜂窝网络。端点安全产品提供的另一项优势是，即使通信一直加密到相关端点，它们也能提供预防和检测控制。与端点安全相关的典型挑战在于容量考量：必须管理大量的产品/系统；必须分析并可能保留大量数据。

许多端点产品可被视为整体端点安全套件的一部分。其中最重要的包括防病毒、应用程序白名单、可移动介质控制、磁盘加密、主机入侵防御系统和桌面防火墙。

### 反恶意软件/防病毒

部署最广泛的端点安全产品是反恶意软件，仍普遍称为防病毒软件。许多功能齐全的端点安全套件都是从最初仅提供基于特征码的防病毒产品逐渐演变而来的。防病毒产品常因持续无法阻止恶意软件传播而受到诟病。然而，反对防病毒的大多数论点似乎都在抱怨这些产品单独使用不足以阻止恶意软件。遗憾的是，没有能阻止恶意软件的灵丹妙药，在出现之前，防病毒或反恶意软件产品将继续是必要的，尽管它们并不充分。防病毒是端点安全纵深防御中的一层（众多层之一）。

虽然防病毒供应商通常采用启发式或统计方法进行恶意软件检测，但检测恶意软件的主要手段仍然是基于特征码的。基于特征码的方法要求防病毒供应商拥有恶意软件样本以创建特征码。这是应用程序黑名单的一个例子，现在有时称为阻止列表（请参阅下文的“[应用程序白名单/应用程序控制](#Ch008_361-457_B9780443187346000064_1.xhtml#s0320)”部分）。对于快速变异的恶意软件或以前未遇到过的恶意软件，基于特征码的检测成功率要低得多。

### 应用程序白名单/应用程序控制

应用程序白名单，也称为应用程序控制，是端点安全套件中较新增的功能。应用程序白名单的主要重点是预先确定哪些二进制文件被认为可以在给定系统上安全执行。一旦建立了这个基线，任何不在已知良性二进制文件列表中、试图运行的二进制文件都将被阻止执行。这种方法的一个弱点是，当攻击者利用“已知良性”二进制文件并将其用于恶意目的时。

白名单技术包括允许运行以下二进制文件：

*   通过受信任的代码签名数字证书签名的
*   与已知良性的加密哈希匹配的
*   具有受信任的完整路径和名称的

最后一种方法最弱：攻击者可以用恶意版本替换受信任的二进制文件。

应用程序白名单优于应用程序黑名单（后者禁止已知的恶意二进制文件）。

### 可移动介质控制

另一个进入大型套件的较新端点安全产品协助进行可移动介质控制。对更好地控制可移动介质的需求在两个方面尤为强烈。首先，将感染恶意软件的可移动介质插入组织计算机，一直是攻破原本相当安全的组织的一种方法。其次，指甲盖大小的介质能容纳惊人的存储量，并被用于秘密窃取敏感数据。

恶意软件传播的常见载体是许多较新版 Microsoft 操作系统的 `Autorun`（自动运行）功能。如果将格式正确的可移动驱动器插入支持 `Autorun` 的 Microsoft Windows 操作系统，介质根目录下 `Autorun.inf` 文件引用的任何程序都将自动执行。许多形式的恶意软件会向所有驱动器的根目录写入恶意的 `Autorun.inf` 文件，试图在驱动器被移除并连接到另一个系统时病毒式传播。

最佳实践是在 Microsoft 操作系统上禁用 `Autorun`。请参阅 Microsoft 文章“如何在 Windows 中禁用 Autorun 功能”（[https://support.microsoft.com/kb/967715](https://support.microsoft.com/kb/967715)）以获取禁用 `Autorun` 的信息。

主要由于这些问题，组织被迫对可连接到设备的可移动介质类型实施更严格的控制。可移动介质控制产品是与禁止未经授权使用可移动介质的策略授权等管理控制相匹配的技术控制。

### 磁盘加密

另一个越来越常见的端点安全产品是磁盘加密软件。组织通常强制要求使用全盘加密产品，以防止落入未经授权之手的硬盘上的敏感数据泄露，尤其是移动设备，因为它们面临更高的被盗风险。
