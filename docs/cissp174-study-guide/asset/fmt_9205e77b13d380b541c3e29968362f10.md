
# 练习题

## 9. 无线网络切换安全特性

你正通过无线网络浏览网页。无线连接变得不可靠，因此你插入有线网络以继续浏览。在你更换物理网络时，浏览器无需任何更改。什么安全特性允许这样做？

1.  A. 抽象
2.  B. 硬件分段
3.  C. 分层
4.  D. 进程隔离

**正确答案和解释：C**。答案 **C** 正确；分层意味着一层（硬件）的变化不会直接影响非相邻层（应用）。

**错误答案和解释：A、B 和 D**。答案 **A**、**B** 和 **D** 不正确。抽象向用户隐藏不必要的细节，这与分层相关（但不同）。硬件分段为特定安全域提供专用硬件或硬件部分。进程隔离防止一个进程影响另一个进程的机密性、完整性或可用性。

## 10. 推理攻击

罪犯根据停车场进出的低流量推断某组织正在举行外勤会议，大楼内人员很少，并利用这个机会闯入大楼偷窃笔记本电脑。发起了哪种类型的攻击？

1.  A. 聚合
2.  B. 电磁辐射
3.  C. 推理
4.  D. 维护钩子

**正确答案和解释：C**。答案 **C** 正确；推理要求攻击者“填补空白”，从公开信息中推断出敏感信息。

**错误答案和解释：A、B 和 D**。答案 **A**、**B** 和 **D** 不正确。聚合是一种数学运算，所有问题都被问到且所有答案都被接收：不需要推导。电磁辐射是从电子设备广播出的能量。维护钩子是供应商留下的系统维护后门。

## 11. EMI 问题主要影响的安全方面

诸如串扰之类的 EMI 问题主要影响安全的哪个方面？

1.  A. 机密性
2.  B. 完整性
3.  C. 可用性
4.  D. 认证

**正确答案和解释：B**。答案 **B** 正确；虽然诸如串扰之类的 EMI 问题可能影响列出的所有方面，但它最常见地影响完整性。

**错误答案和解释：A、C 和 D**。答案 **A**、**C** 和 **D** 不正确；机密性可能受影响（例如在语音电话中听到另一个通话），极端情况下可用性和认证也可能受影响（串扰严重到导致系统停止运行）。这些场景远不如由 EMI 问题（如串扰）引起的简单完整性违规常见。

## 12. 火灾抑制系统最重要的目标

火灾抑制系统最重要的目标是什么？

1.  A. 关键数据的保存
2.  B. 人员安全
3.  C. 建筑完整性
4.  D. 迅速扑灭火灾

**正确答案和解释：B**。答案 **B** 正确；人员安全是物理（环境）安全领域的首要关注点。

**错误答案和解释：A、C 和 D**。答案 **A**、**C** 和 **D** 不正确；这些都是有效的关注点，但不如安全重要。数据保护始终是次于安全的次要关注点；这就是为什么水是推荐的灭火剂。建筑完整性和迅速扑灭火灾也很重要并影响安全，但安全本身是目标，因此是更有力的答案。例如，空楼的完整性是次要关注点，虽然扑灭火灾的速度很重要，但必须撤离的人员安全是更重要的关注点。扑灭火灾最快的方法是切断氧气，这对人来说是致命的。

## 13. 容器与虚拟机的对比

关于容器和虚拟机，以下哪项陈述是正确的？

1.  A. 容器和虚拟机都共享同一个内核
2.  B. 虚拟机共享同一个内核；容器使用自己的内核
3.  C. 容器共享同一个内核；虚拟机使用自己的内核
4.  D. 容器和虚拟机都使用自己的内核

**正确答案和解释：C**。答案 **C** 正确；容器共享同一个内核，虚拟机使用自己的内核。

**错误答案和解释：A、B 和 D**。答案 **A**、**B** 和 **D** 不正确。

## 14. 不可否认性的最佳描述

不可否认性最好描述为？

1.  A. 证明用户执行了事务
2.  B. 证明事务未被更改
3.  C. 认证事务
4.  D. 证明用户执行了未被更改的事务

**正确答案和解释：D**。答案 **D** 正确；不可否认性是用户执行了事务的证明，也是事务未被更改的证明。

**错误答案和解释：A、B 和 C**。答案 **A**、**B** 和 **C** 不正确。证明事务未被更改是不可否认性的一半；证明用户执行了事务是另一半。不可否认性需要两者兼备。认证事务是用户执行了事务的另一种说法，也只是不可否认性的一半。

# 第 5 章：领域 4：通信与网络安全

## 1. 音频流服务器协议选择

对于音频流服务器，可以接受一定的丢包，应使用哪种协议？

1.  A. IP
2.  B. ICMP
3.  C. TCP
4.  D. UDP

**正确答案和解释：D**。答案 **D** 正确；`UDP` 用于可接受一定丢包的高速应用。

**错误答案和解释：A、B 和 C**。答案 **A**、**B** 和 **C** 不正确。`IP` 是承载协议，需要像 `UDP` 这样的高层协议来支持应用。`ICMP` 是辅助协议，不承载应用数据。`TCP` 是可靠但较慢的协议，当需要速度且可接受丢包时不是最佳选择。

## 2. 使用固定长度单元传输数据的网络技术

什么网络技术使用固定长度单元来传输数据？

1.  A. ARCNET
2.  B. ATM
3.  C. Ethernet
4.  D. FDDI

**正确答案和解释：B**。答案 **B** 正确；`ATM` 是一种使用 53 字节固定长度单元的网络技术。

**错误答案和解释：A、C 和 D**。答案 **A**、**C** 和 **D** 不正确。`ARCNET` 传递令牌。`Ethernet` 使用帧。`FDDI` 也使用令牌。

## 3. SSH 服务器监听端口和协议

Secure Shell（`SSH`）服务器监听什么端口和协议？

1.  A. TCP 端口 20
2.  B. TCP 端口 21
3.  C. TCP 端口 22
4.  D. TCP 端口 23

**正确答案和解释：C**。答案 **C** 正确；`SSH` 服务器监听 `TCP` 端口 22。

**错误答案和解释：A、B 和 D**。答案 **A**、**B** 和 **D** 不正确。`FTP` 使用 `TCP` 端口 20 和 21。`Telnet` 使用 `TCP` 端口 23。
