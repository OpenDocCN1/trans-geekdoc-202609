
# 术语表

## D

**DNP3** Distributed Network Protocol，提供一种开放标准，主要用于能源领域，实现不同供应商的 SCADA 和智能电网应用之间的互操作性。

**DNS** Domain Name System，一个分布式全球层级数据库，将名称转换为 IP 地址，反之亦然。

**DNS reflection attack** 使用第三方 DNS 服务器的欺骗性 DoS 攻击。

**DNSSEC** Domain Name Server Security Extensions，通过使用公钥加密为 DNS 响应提供认证和完整性。

**Domain Name Server Security Extensions** 见——**DNSSEC**。

**Domain Name System** 见——**DNS**。

**Domains of trust** Windows Active Directory 使用的访问控制模型。

**DoS** Denial of Service，针对可用性的攻击。

**DRAM** Dynamic Random Access Memory，将比特存储在小电容器中（如小电池），比 SRAM 更便宜但速度更慢。

**DRM** Digital Rights Management，旨在通过水印、产品密钥和区域锁定等控制手段限制受版权保护材料和其他形式知识产权的使用。

**DRP** Disaster Recovery Plan，从破坏性事件中恢复的短期计划。

**DSL** Digital Subscriber Line，利用现有铜线对为家庭和小型办公室提供数字服务。

**DSSS** Direct Sequence Spread Spectrum，一次性使用整个无线频段。

**DTE** Data Terminal Equipment，网络“终端”，如台式机、服务器或实际终端。

**DTE/DCE** 跨越分界点的连接。

**Dual-factor authentication** 见——**Strong authentication**。

**Dual-homed host** 具有两个网络接口的主机：一个连接到受信网络，另一个连接到不受信网络。

**Due care** 要求关键组织利益相关者在履行职责时审慎行事，又称“审慎人规则”。

**Due diligence** 对尽职照管的管理。

**Dumpster diving** 一种物理攻击，攻击者翻找垃圾，希望找到仅被丢弃而未被销毁的敏感信息。

**Dynamic Host Configuration Protocol** 见——**DHCP**。

**Dynamic Application Security Testing** 见——**DAST**。

**Dynamic password** 定期更改的密码。

**Dynamic signatures** 测量某人签名过程的生物特征控制。

**Dynamic testing** 在代码执行时对其进行测试。

## E

**E1** 承载 30 个信道的专用 2.048 兆比特电路。

**E3** 24 个 E1。

**EAP** Extensible Authentication Protocol，一种第 2 层认证框架，描述了许多具体的认证协议。

**EAP-FAST** EAP-Flexible Authentication via Secure Tunneling，由 Cisco 设计用于替代 LEAP。

**EAP Over LAN** 见——**EAPOL**。

**EAP-Transport Layer Security** 见——**EAP-TLS**。

**EAP Tunneled Transport Layer Security** 见——**EAP-TTLS**。

**EAP-TLS** EAP-Transport Layer Security，使用 PKI，要求服务端和客户端均持有证书。

**EAP-TTLS** EAP Tunneled Transport Layer Security，通过取消客户端证书要求简化了 EAP-TLS。

**EAPOL** EAP Over LAN，一种用于多种 EAP 的第 2 层协议。

**ECB** Electronic Code Book mode，DES 最简单也最弱的模式。

**ECE** 新的 TCP 标志，Explicit Congestion Notification Echo。

**ECPA** Electronic Communications Privacy Act，为非电话电子通信提供搜查和扣押保护。

**Edge computing** 分布式计算的一个组件，旨在将数据推送到网络边缘（更靠近客户）。

**eDiscovery** Electronic Discovery，指法律顾问在民事诉讼审前取证阶段获取相关 ESI（Electronically Stored Information，电子存储信息）的过程。

**EEPROM** Electrically-Erasable Programmable Read Only Memory，通过刷写程序实现电擦除的存储器。

**EF** Exposure Factor，因事件导致资产价值损失的百分比。

**EGP** Exterior Gateway Protocol，互联网上使用的一种路由协议。

**Egress monitoring** 专注于检测基于数据离开组织的对手活动的控制措施。

**Electrically-Erasable Programmable Read Only Memory** 见——**EEPROM**。

**Electronic backups** 以电子形式存储、可在破坏性事件或灾难发生时检索的数据。

**Electronic Code Book** 见——**ECB**。

**Electronic Communications Privacy Act** 见——**ECPA**。

**Electronic Discovery** 见——**eDiscovery**。

**Electronic vaulting** 定期按计划时间间隔，以批处理方式电子传输待备份数据的过程。

**Emanations** 从电子系统逸出的能量，在特定条件下可被远程监控。

**Embedded systems** 执行有限功能集的计算机。嵌入式系统示例包括 HVAC 控制器、医疗设备（如心脏监护仪或静脉滴注泵）、ATM 机和“智能”家电。

**Emergency Operations Center** 见——**EOC**。

**Encapsulating Security Payload** 见——**ESP**。

**Encapsulation (network)** 接收来自较高网络层的信息并添加报头，将较高层信息视为数据处理。

**Encapsulation (object)** 包含并隐藏对象方法的细节。

**Encryption** 将明文转换为密文。

**End-User License Agreement** 见——**EULA**。

**End-of-Life** 见——**EOL**。

**End-of-Service** 见——**EOS**。

**Enrollment** 向系统（如生物特征认证系统）注册的过程，即首次创建账户。

**Enticement** 为已有意图违法者创造有利的犯罪条件。

**Entitlements** 授予用户的权限。

**Entity integrity** 要求每个元组具有唯一且非空的主键。

**Entrapment** 一种法律抗辩，被告声称执法人员诱导其犯下原本不会犯的罪行。

**EOC** Emergency Operations Center，紧急事件期间或刚结束后建立的指挥所。

**EOL** End-of-Life，供应商不再销售但仍提供支持的产品。

**EOS** End-of-Service，供应商不再提供支持的产品。

**Ephemeral ports** TCP/IP 端口 1024 及以上。

**EPROM** Erasable Programmable Read Only Memory，可用紫外线擦除的存储器。

**Eradication phase** 清理受损系统的事件管理阶段。

**Erasable Programmable Read Only Memory** 见——**EPROM**。

**ESP** Encapsulating Security Payload，IPsec 协议，主要通过加密数据包数据提供机密性。

**Ethernet** 占主导地位的局域网技术，通过帧传输网络数据。

**Ethical disclosure** 私下与供应商共享漏洞信息，并在补丁可用前暂不公开发布的做法。也称为负责任披露。

**Ethics** 做道德上正确的事。

**EU Data Protection Directive** 允许信息自由流动，同时保持对各成员国公民数据一致保护的隐私指令。

**EULA** End-User License Agreement，一种软件许可协议形式。

**Exclusive Or** 见——**XOR**。

**Executive Succession Planning** 确定组织的继任顺序。

**Exfiltration** 违反策略将敏感数据从安全边界移出。

**Exigent circumstances** 就证据获取而言，因证据极有可能被销毁，而在无搜查令情况下扣押证据的正当理由。

**Expert systems** 旨在复制人类专家的知识和决策能力。

**Exposure Factor** 见——**EF**。

**Extensible Authentication Protocol** 见——**EAP**。

**Extensible Markup Language** 见——**XML**。

**Exterior Gateway Protocol** 见——**EGP**。

**External testing** 在组织边界外执行的安全测试，由内部员工或第三方实施。
