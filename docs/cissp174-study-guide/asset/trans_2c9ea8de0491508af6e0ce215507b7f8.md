
# 验收测试

验收测试测试软件是否满足来自用户或客户、合同或合规视角的各种最终状态需求。ISTQB（国际软件测试资格委员会）将验收测试定义为：“一种正式测试，针对用户需求、要求和业务流程进行，以确定系统是否满足验收标准，并使用户、客户或其他授权实体能够决定是否接受该系统” [\[34\]](#Ch009_459-508_B9780443187346000088.xhtml#bb0175)。

ISTQB 还列出了验收测试的四个级别：

*   **用户验收测试**：主要关注功能，从而验证系统对业务用户的**适用性**。用户验收测试由用户和应用程序管理员执行。
*   **运营验收测试**：也称为生产验收测试，验证系统是否满足运行要求。在大多数组织中，运营验收测试由系统管理员在系统发布前执行。运营验收测试可能包括备份/恢复测试、灾难恢复、维护任务以及安全漏洞的定期检查。
*   **合同验收测试**：针对合同的验收标准执行，用于定制开发的软件。验收标准应在商定合同时正式定义。
*   **合规验收测试**：也称为法规验收测试，针对必须遵守的法规执行，例如政府、法律或安全法规” [\[35\]](#Ch009_459-508_B9780443187346000088.xhtml#bb0180)。

## 评估所获取软件的安全影响

我们希望能够信任供应商关于产品能力的声明。在被证明为真之前，供应商的声明应被视为营销宣传。不要仅依赖供应商的声明，即使是关于基本能力的声明。

一个重要的观点是在评审产品**之前**收集需求。如果在评审产品**之后**才定义需求，供应商可能会说服组织，使其认为自己有特定需求，而只有该供应商的产品能满足。不要让产品或营销决定组织在产品中“需要”什么。

### 商用现成软件 (COTS)

对于商用现成软件 (COTS)，供应商的声明更容易验证。对于 COTS，应进行**实地对比测试**，比较已满足需求的产品。不要依赖产品路线图会成为现实。一个特别重要的安全需求是寻找与现有基础设施和安全产品的集成能力。虽然**最佳单品**可能是组织的总体偏好，但要认识到增加一个管理控制台（以及随之而来的额外用户配置）会增加产品的运营成本。要考虑产品的**总拥有成本 (TCO)**，而不仅仅是资本支出和年度维护成本。

由于产品可以被评估以确定其是否提供声称的能力，因此对于 COTS 软件，供应商的声明更容易验证。

第三方研究和分析机构提供特定领域各参与者的评估，这可以在不需要大量内部测试的情况下提供产品的基本（尽管可能有偏见）对比。

通常可以联系供应商的客户。当然，如果这些联系人是由供应商自己提供的，那么在接受其声明时要谨慎。更好的方法是自行寻找正在使用该产品的人，并询问他们的优缺点及喜好/厌恶。

针对 COTS 的一些问题/顾虑：如果供应商倒闭了怎么办？如果缺少关键功能怎么办？寻找供应商产品的内部或第三方支持有多容易？

### 定制开发的第三方产品

COTS 的替代方案是采用定制开发的应用程序。这些定制开发的第三方应用程序提供了超越 COTS 的额外风险和潜在收益。在与第三方开发商打交道时，合同条款和**服务级别协议 (SLA)** 至关重要。除非合同强制要求提供安全能力，否则永远不要假设安全性会成为产品开发过程中的一个考量因素。

应在签署合同和制定 SLA **之前**讨论基本安全需求，以确保供应商预期能够交付这些能力。与 COTS 非常相似，关键问题包括：如果供应商倒闭了怎么办？如果缺少关键功能怎么办？寻找供应商产品的内部或第三方支持有多容易？

# 人工智能

计算机进行计算：它们完全按照指令行事。“计算机”一词最早于 1613 年被用来描述从事加法运算的人。人工智能是让电子计算机更“智能”地“思考”的科学，有时模仿哺乳动物大脑的能力。

## 专家系统

*专家系统*由两个主要组件组成。第一个是*知识库*，由“如果/那么”语句组成。这些语句包含专家系统用于做决策的规则。第二个组件是*推理引擎*，它遵循知识库形成的树状结构，并在有匹配时触发规则。

下面是一个示例“互联网中断”专家系统，当用户致电抱怨无法访问互联网时，服务台可能会使用它：

1.  **如果您的计算机已开启**
    *   否则：开启您的计算机
2.  **那么如果您的显示器已开启**
    *   否则：开启您的显示器
3.  **那么如果您的操作系统已启动且您能打开 `cmd.exe` 提示符**
    *   否则：修复操作系统
4.  **那么如果您能 ping 通 `127.0.0.1`**
    *   否则：检查网络接口配置
5.  **那么如果您能 ping 通本地网关**
    *   否则：检查本地网络连接
6.  **那么如果您能 ping 通互联网地址 `192.0.2.187`**
    *   否则：检查网关连接
7.  **那么如果您能 ping 通 `syngress.com`**
    *   否则：检查 DNS

**正向链接**从无前提开始（在前面的示例中为“计算机是否开启”），向前推导以确定解决方案。**反向链接**从一个前提开始（例如“可能是 DNS 坏了”），向后推导。

知识库的完整性至关重要。整个知识库应形成一棵逻辑树，始于一个树干（在前面的示例中为“计算机是否开启”）。知识库随后应分支展开。推理引擎遵循这棵树，根据如果/那么语句的回答进行分支或触发。

不应有循环规则；使用前面示例的一个循环规则例子：“如果您的计算机已开启，那么如果您的显示器已开启，那么如果您的操作系统已启动且您能打开 `cmd.exe` 提示符，那么如果您的计算机已开启……”。也不应有未引用的规则（不连接到知识库树的分支）。

## 人工神经网络

人工神经网络 (ANN) 模拟人类和动物大脑中的神经网络。人脑的神经网络拥有 1000 亿个神经元，每个神经元通过数千个或更多突触相互连接。每个神经元可能会根据突触输入而激发。这种多层神经网络能够基于数千个或更多输入做出单一决策。
