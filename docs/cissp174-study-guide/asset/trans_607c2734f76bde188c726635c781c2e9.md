## 场景题 (Questions 11–14)

**场景描述：**
你是一家大型银行的 CISO，已聘请一家公司提供整体安全评估，并对组织进行渗透测试。目标是确定整体信息安全有效性，特别是判断财务数据被盗是否可能。

该银行最近部署了一个定制开发的三层 Web 应用程序，允许客户查询余额、转账，并通过智能手机拍照上传支票图像进行存款。除了传统的浏览器界面，公司还为 Apple iOS 和 Android 设备开发了智能手机 App。

合同已签署，双方已就范围和交战规则达成一致。银行提供了一名 24/7 值班的 IT 联系人，以防渗透测试期间发生任何意外情况，包括潜在的服务意外中断。

### 11. 假设渗透测试成功，渗透测试公司证明财务数据被盗风险的最佳方式是什么？
1. A. 指示渗透测试团队对包含财务数据的服务器进行彻底的漏洞评估
2. B. 指示渗透测试团队下载财务数据，对其进行编辑，并据此报告
3. C. 指示渗透测试团队只能通过加密且经过身份验证的通道下载财务数据
4. D. **在财务数据所在的同一位置放置一个无害的“标志”文件，并通知渗透测试团队下载该标志**

### 12. 哪种类型的渗透测试能最有效地利用时间和小时顾问费用？
1. A. 自动化知识
2. B. **全知晓**
3. C. 部分知晓
4. D. 零知识

### 13. 你希望安全公司测试新的 Web 应用程序，但决定不共享底层源代码。可使用哪种测试类型来帮助确定定制 Web 应用程序的安全性？
1. A. 安全编译器警告

3. C. 静态测试
