
# 术语表

## A

**Book cipher**  
使用知名文本（如字典）中的完整单词作为明文的一对一替换的加密方法。

**Boot sector virus**  
感染 PC 引导扇区的病毒，确保病毒在系统启动时加载。

**BOOTP**  
Bootstrap Protocol，无盘系统用于通过网络引导的协议。

**Bootstrap Protocol**  
参见——BOOTP。

**Border Gateway Protocol**  
参见——BGP。

## B

**Bot**  
运行恶意软件并通过僵尸网络控制的计算机系统。

**Botnet**  
中心化的僵尸命令与控制（C&C）网络，由被称为“bot herders”的人类管理。

**Bottom-Up programming**  
从低级技术实现细节开始，逐步构建完整程序概念的编程方法。

**Breach Attack Simulations**  
参见——BAS。

**Breach notification**  
通知其个人数据已被泄露或极有可能已被泄露的相关人员。

**Brewer-Nash**  
参见——Chinese Wall Model。

**BRI**  
Basic Rate Interface，提供两个 64 K 数字 ISDN 信道。

**Bridge**  
具有两个端口的第 2 层设备，用于连接网段。

**Broadband**  
具有多个信道的网络；可同时发送多个信号，如有线电视。

**Broadcast**  
发送给局域网上所有站点的流量。

**BRP**  
Business Recovery Plan，详述从破坏性事件中恢复后恢复正常业务运营所需的步骤。也称为 Business Resumption Plan。

**Brute force attack**  
尝试每一个可能的密钥或组合的攻击。

**BS-25999**  
英国标准学会（BSI）制定的连续性标准。

**Buffer overflow**  
攻击者可在缓冲区变量末尾之后插入数据的状况。

**Bus**  
将网络节点串联连接的物理网络拓扑。

**Business Continuity Plan**  
参见——BCP。

**Business interruption testing**  
部分或完全故障转移到备用站点。

**Business Owners**  
也称为 Mission Owners，创建信息安全计划并确保其拥有适当人员配备、资金支持和组织优先级的高级管理层成员。

**Business Recovery Plan**  
参见——BRP。

**Business Resumption Plan**  
参见——BRP。

**Bytecode**  
Java 使用的机器无关解释型代码。

## C

**Cable modem**  
通过宽带有线电视提供互联网接入。

**Cache memory**  
系统中最快的内存，用于跟上 CPU 获取和执行指令的速度。

**Caesar Cipher**  
一种 rot-3 替换密码。

**Callback**  
基于调制解调器的认证系统。

**Caller ID**  
识别来电电话号码，有时用作弱认证方法。

**Candidate keys**  
表中具有唯一值的任何属性（列）。

**Capability Maturity Model**  
参见——CMM。

**Carrier Sense Multiple Access**  
参见——CSMA。

**CASB**  
Cloud Access Security Broker，集中管理多种基于云的安全控制，包括防火墙、WAF、单点登录、加密、反恶意软件、日志记录和告警。

**CASE**  
Computer-Aided Software Engineering，使用程序协助其他计算机程序的创建和维护。

**CBC**  
Cipher Block Chaining，DES 的一种分组模式，将前一个加密的密文分组与下一个待加密的明文分组进行 XOR 运算。

**CCD**  
Charge-Coupled Device，数字闭路电视。

**CCMP**  
Counter Mode CBC MAC Protocol，WPA2 用于创建 MIC 的协议。

**CCTV**  
Closed Circuit Television，用于协助警卫检测限制区域内入侵者存在的侦测设备。

**CDN**  
Content Distribution Networks（也称 Content Delivery Networks）使用一系列分布式缓存服务器来提高性能并降低下载在线内容的延迟。

**Central Processing Unit**  
参见——CPU。

**Centralized access control**  
将系统或组织的访问控制集中在一个逻辑点。

**CER**  
Crossover Error Rate，描述拒真率（FRR）和认假率（FAR）相等的点。

**Certificate Authority**  
PKI 组件，在向个人或组织颁发证书前验证其身份。

**Certificate Revocation List**  
参见——CRL。

**Certification**  
验证系统是否满足文档化安全需求的详细检查。

**CFB**  
Cipher Feedback，一种类似于分组模式 CBC 的 DES 流模式。

**Chain of custody**  
要求一旦获取证据，必须完整保存关于谁、什么、何时、何地处理证据的文档记录。

**Chaining**  
将前一个加密分组植入下一个待加密分组的分组密码机制。

**Challenge Handshake Authentication Protocol**  
参见——CHAP。

**Change management**  
理解、沟通和记录变更的过程。

**Channel Service Unit/Data Service Unit**  
参见——CSU/DSU。

**CHAP**  
Challenge Handshake Authentication Protocol，一种使用共享密钥的更安全的网络认证协议。

**Charged Couple Discharge**  
参见——CCD。

**Checklist testing**  
列出成功恢复所需的所有必要组件，并确保它们已就绪或将在灾难发生时随时可用。也称为一致性测试。

**Chinese Wall Model**  
旨在通过禁止一个人（如顾问）访问多个利益冲突类别（CoIs）来避免利益冲突的模型。

**CI/CD**  
Continuous Integration and Continuous Delivery，一种专注于通过流水线快速部署代码更新的敏捷方法论。

**CIA triad**  
Confidentiality, Integrity, and Availability（机密性、完整性、可用性）。

**CIDR**  
Classless Inter-Domain Routing，允许超越任意有状态网络大小的多种网络规模。

**Cipher**  
一种加密算法。

**Cipher Block Chaining**  
参见——CBC。

**Cipher Feedback**  
参见——CFB。

**Ciphertext**  
加密后的消息。

**Circuit-level proxy**  
工作在第 5 层的代理防火墙。

**Circuit-switched network**  
在两个节点之间提供专用电路或信道的网络。

**Circumstantial evidence**  
用于确立与特定要点甚至其他证据相关情况的证据。

**CIRT**  
Computer Incident Response Team，执行事件管理的团队。

**CISC**  
Complex Instruction Set Computer，指令更长、功能更强大的 CPU。

**Civil law**  
解决个人或组织间纠纷的法律。

**Civil law (legal system)**  
利用成文法或法规来确定何为合法的法律体系。

**Clark-Wilson**  
一种通过让主体通过程序访问客体来保护完整性的现实世界完整性模型。

**Class I gate**  
专为家庭使用设计的住宅门。

**Class II gate**  
商用门，如停车场门。

**Class III gate**  
工业/限制访问门，如大型装卸码头。

**Class IV gate**  
限制访问门，用于机场或监狱。

**Classful addresses**  
A 类到 E 类的 IPv4 网络。

**Classless Inter-Domain Routing**  
参见——CIDR。

**Clearance**  
通常由高级安全专业人员做出的关于用户是否可被信任处理特定级别信息的判定。

**Client-side attack**  
用户下载恶意内容的攻击。

**Clipper Chip**  
（失败的）1993 年托管加密标准（EES），使用了 Skipjack 算法。

**Clipping level**  
最低报告阈值级别。

**Closed Circuit Television**  
参见——CCTV。

**Closed source**  
以可执行形式发布的软件：源代码保密。

**Closed system**  
使用专有硬件或软件的系统。

**Cloud Access Security Broker**  
参见——CASB。

**CMM**  
Capability Maturity Model，用于评估和改进软件开发过程的成熟度框架。

**CMP**  
Crisis Management Plan。

**Coaxial**  
内部铜芯与金属编织层或屏蔽层由绝缘体隔开的网络布线。
