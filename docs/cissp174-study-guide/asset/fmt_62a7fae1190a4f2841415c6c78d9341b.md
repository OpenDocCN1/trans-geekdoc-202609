
# 术语表

## C

**COBIT**  
Control Objectives for Information and related Technology，组织内部采用信息安全治理最佳实践的控制框架。

**COCOM**  
Committee for Multilateral Export Controls，1947 年至 1994 年生效的军火法。旨在冷战期间控制关键技术（包括密码学）向“铁幕”国家的出口。

**Code Repositories**  
用于存储项目源代码的安全服务，公共示例是 `GitHub`。

**Codebreakers (The)**  
David Kahn 编写的密码学历史著作。

**Cohesion**  
OOP 概念，描述独立对象。高内聚的对象具有低耦合。

**Cold site**  
备用站点，具有架空地板、电力、公用设施和物理安全，但没有配置好的系统或数据。

**Collection Limitation Principle**  
OECD 隐私指南原则，规定个人数据收集应有限度，以合法方式获得，除非有令人信服的相反理由，否则应征得个人知情和同意。

**Collision**  
两个或多个明文生成相同的哈希值。

**Collusion**  
两个或多个个人为颠覆系统安全而达成的协议。

**Color of law**  
依据执法权力行事。

**COM**  
Component Object Model，在本地定位和连接对象。

**Combinatorial software testing**  
黑盒测试方法，旨在识别并测试所有唯一的软件输入组合。

**Commandments of Computer Ethics**  
Computer Ethics Institute 的道德准则。

**Commit**  
使数据库更改永久生效。

**Common Criteria**  
国际公认的用于描述和测试 IT 产品安全性的标准。

**Common law**  
重视具体案例和司法判例作为法律决定因素的法律体系。

**Common Object Request Broker Architecture**  
参见——`CORBA`。

**Compartmentalization**  
对“需知”原则的技术强制执行。

**Compensating controls**  
为弥补其他控制措施的弱点而实施的额外安全控制。

**Compensatory damages**  
作为补偿提供的损害赔偿。

**Compiler**  
将源代码（如 C 或 Basic）转换并编译为机器代码。

**Complex Instruction Set Computer**  
参见——`CISC`。

**Component Object Model**  
参见——`COM`。

**Computer bus**  
计算机系统上的主要通信通道。

**Computer crimes**  
利用计算机实施的犯罪。

**Computer Fraud and Abuse Act**  
Title 18 United States Code Section 1030。

**Computer Incident Response Team**  
参见——`CIRT`。

**Computer Security Incident Response Team**  
参见——`CSIRT`。

**Computer-Aided Software Engineering**  
参见——`CASE`。

**Commercial Off-the-Shelf Software**  
参见——`COTS`。

**Conduct the business impact analysis (BIA)**  
NIST SP 800-34 应急规划流程的第二步。

**Confidentiality**  
旨在防止信息未经授权的披露。

**Configuration management**  
开发一致的系统安全配置并可在整个组织中利用的过程。

**Confusion**  
明文和密文之间的关系应尽可能混淆（或随机）。

**Consistency testing**  
参见——`Checklist testing`。

**Constrained user interface**  
向用户提供有限的信息控制，如 ATM 键盘。

**Container**  
一种将文件、进程和网络与主机系统隔离的技术。与虚拟机不同，容器共享主机的内核。

**Containment phase**  
事件管理阶段，旨在防止事件导致进一步损害。

**Content-dependent access control**  
在识别和认证之外增加额外标准：主体尝试访问的实际内容。

**Content Distribution Networks**  
参见——`CDN`。

**Context-dependent access control**  
在识别和认证之外增加额外标准：访问的上下文，如时间。

**Continuity of Operations Plan**  
参见——`COOP`。

**Continuity of Support Plan**  
专门关注对特定 IT 系统和应用程序的支持。

**Continuity Planning Project Team**  
参见——`CPPT`。

**Continuous Integration and Continuous Delivery**  
参见——`CI/CD`。

**Contraband check**  
旨在识别禁止进入安全区域（如飞机）的物品。

**Control Objectives for Information and related Technology**  
参见——`COBIT`。

**Control unit**  
CPU 组件，充当交通指挥，向 ALU 发送指令。

**Convergence**  
网络上的所有路由器就路由状态达成一致。

**COOP**  
Continuity of Operations Plan，灾难期间维持运营的计划。

**Copyright**  
保护艺术、音乐或文学作品表达形式的知识产权类型。

**CORBA**  
Common Object Request Broker Architecture，开放的供应商中立的网络对象代理框架。

**Corrective controls**  
修复受损系统或过程的控制措施。

**Corroborative evidence**  
为可能受到质疑的事实提供额外支持的证据。

**COTS**  
Commercial Off-the-Shelf Software，面向公众的第三方开发商业软件。

**Counter Mode**  
参见——`CTR`。

**Counter Mode CBC MAC Protocol**  
参见——`CCMP`。

**Coupling**  
OOP 概念，将对象连接到其他对象。高耦合对象具有低内聚。

**Covert channel**  
任何违反安全策略的通信。

**CPPT**  
Continuity Planning Project Team，由组织内的利益相关者组成的团队，专注于确定如果发生特定紧急事件，谁需要发挥作用。

**CPU**  
Central Processing Unit，计算机的“大脑”，能够控制和执行数学计算。

**Credential Management System**  
实现账户凭据和密码更安全存储和使用的软件。

**Criminal law**  
受害者可视为社会本身的法律。

**Crippleware**  
部分功能的专有软件，通常禁用关键功能。用户通常需要付费以解锁全部功能。

**Crisis Management Plan**  
参见——`CMP`。

**CRL**  
Certificate Revocation Lists，PKI 组件，列出已被吊销的数字证书。

**Crossover**  
遗传算法概念，结合两种算法。

**Crossover Error Rate**  
参见——`CER`。

**Cross-Site Request Forgery**  
参见——`CSRF`。

**Cross-Site Scripting**  
参见——`XSS`。

**Cryptanalysis**  
破解加密消息（恢复其含义）的科学。

**Cryptographic Protocol Governance**  
描述为特定工作选择正确密码和实现的过程。

**Cryptography**  
创建隐藏含义消息的科学。

**Cryptology**  
安全通信的科学。

**CSIRT**  
Computer Security Incident Response Team，负责监控、识别和响应安全事件的团队。

**CSMA**  
Carrier Sense Multiple Access，以太网网络用于允许共享基带网络并避免冲突的方法。

**CSRF**  
Cross-Site Request Forgery，在受信任站点的安全上下文中对静态内容的第三方重定向。

**CSU/DSU**  
Channel Service Unit/Data Service Unit，DCE 设备。

**CTR**  
Counter，使用计数器进行反馈的 DES 流模式。

**Custodian**  
提供资产的实操保护。

**Customary Law**  
被群体普遍接受以至于被视为法律的习俗或惯例。

**CWR**  
新 TCP 标志，Congestion Window Reduced。

**Cyber Incident Response Plan**  
旨在应对破坏性网络事件的计划，包括基于网络的攻击、蠕虫、计算机病毒和特洛伊木马。

**Cybersquatting**  
注册与另一组织知识产权相关的互联网域名。
