## 13. 何种方法通过将磁带或磁盘驱动器等磁性介质暴露于强磁场中，破坏其完整性以及其中所含数据的完整性？

- A. 位级覆写
- B. 退磁
- C. 销毁
- D. 粉碎

### 正确答案及解析：B

答案 B 正确；退磁通过将磁带或磁盘驱动器等磁性介质暴露于强磁场中，破坏介质的完整性以及其中所含数据的完整性。

### 错误答案及解析：A、C 和 D

答案 A、C 和 D 不正确。位级覆写通过覆盖磁盘的每个扇区来移除数据。销毁通过物理方式销毁数据，例如焚烧。电子数据粉碎涉及在删除文件前覆写文件内容。

## 14. 哪种相对昂贵且快速的内存使用称为“触发器”的小锁存器来存储位？

- A. DRAM
- B. EPROM
- C. SRAM
- D. SSD

### 正确答案及解析：C

答案 C 正确；SRAM 是一种相对昂贵且快速的内存，它使用称为“触发器”的小锁存器来存储位。

### 错误答案及解析：A、B 和 D

答案 A、B 和 D 不正确。DRAM 是一种相对便宜的内存，使用电容器。EPROM 是可擦除可编程只读存储器，可用紫外线擦除。SSD 是固态硬盘，是 DRAM 和 EEPROM 的组合。

## 15. 哪种内存将位存储在小电容器中（像小电池一样）？

- A. DRAM
- B. EPROM
- C. SRAM
- D. SSD

### 正确答案及解析：A

答案 A 正确；DRAM 将位存储在小电容器中（像小电池一样）。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。EPROM 是可擦除可编程只读存储器，可用紫外线擦除。SRAM 是一种相对昂贵且快速的内存，使用称为“触发器”的小锁存器来存储位。SSD 是固态硬盘，是 DRAM 和 EEPROM 的组合。

# 第 4 章：领域 3：安全架构与工程

## 1. 哪种类型的喷淋系统最适合美术馆？

- A. 湿式管道
- B. 干式管道
- C. 淹没式
- D. 预作用

### 正确答案及解析：D

答案 D 正确；预作用喷淋系统通过要求两个独立的触发条件才能启动来降低意外喷水的几率：喷头必须打开且火灾报警必须触发。这些系统降低了误报风险，通常用于水会造成昂贵损失的区域。

### 错误答案及解析：A、B 和 C

答案 A、B 和 C 不正确；它们都在单一触发条件下释放水。这增加了误报导致昂贵损失的几率。

## 2. 使用犬只作为外围控制的主要缺点是什么？

- A. 训练
- B. 成本
- C. 法律责任
- D. 外观

### 正确答案及解析：C

答案 C 正确；法律责任是使用犬只作为安全控制手段的主要缺点。犬只可能误伤意外进入受控区域的人员。

### 错误答案及解析：A、B 和 D

答案 A、B 和 D 不正确；它们都是潜在的有效问题，但与法律责任和安全相比属于次要考量。

## 3. RSA 算法基于哪种单向函数？

- A. 椭圆曲线
- B. 离散对数
- C. 频率分布
- D. 将合数分解为其素数

### 正确答案及解析：D

答案 D 正确；RSA 基于将大合数分解为其素数的困难性。

### 错误答案及解析：A、B 和 C

答案 A、B 和 C 不正确。椭圆曲线和离散对数是其他类型的单向函数。频率分布是一种执行密码分析的方法。

## 4. 以下关于数字签名的描述哪项是正确的？

- A. 发送方使用公钥加密哈希值
- B. 发送方使用私钥加密哈希值
- C. 发送方使用公钥加密明文
- D. 发送方使用私钥加密明文

### 正确答案及解析：B

答案 B 正确；发送方生成明文的哈希值，并使用私钥加密该哈希值。接收方使用公钥解密哈希值。

### 错误答案及解析：A、C 和 D

答案 A、C 和 D 不正确。发送方使用私钥而非公钥加密哈希值。明文是经过哈希处理的，而非加密。

## 5. 对于必须采用数字签名的低功耗设备，应使用哪种算法？

- A. AES
- B. RSA
- C. ECC
- D. ElGamal

### 正确答案及解析：C

答案 C 正确；数字签名需要非对称加密。ECC 是每比特密钥长度提供最强强度的非对称算法。这允许使用较短的密钥长度，从而需要更少的 CPU 资源。

### 错误答案及解析：A、B 和 D

答案 A、B 和 D 不正确。AES 是对称密码；对称密码不用于数字签名。RSA 基于将合数分解为其素数，ElGamal 基于离散对数。这两种方法每比特提供的强度大致相同，且远弱于 ECC。

## 6. 如果你主要关注信息的机密性，应该使用哪种模型？

- A. Bell-LaPadula
- B. Biba
- C. Clark-Wilson
- D. 机密性模型

### 正确答案及解析：A

答案 A 正确；Bell-LaPadula 模型保护数据的机密性。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。Biba 和 Clark-Wilson 是完整性模型。不存在“机密性模型”。

## 7. 在 Intel ×86 系统上，内核通常运行在哪个 CPU 特权环？

- A. 0 环
- B. 1 环
- C. 2 环
- D. 3 环

### 正确答案及解析：A

答案 A 正确；内核通常运行在 0 环，这是系统中最受信任的部分。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。1 环理论上用于不适合放在 0 环的操作系统部分。2 环理论上用于设备驱动程序。3 环用于用户应用程序。

## 8. Linux 托管将在哪种云服务层级下提供？

- A. IaaS
- B. IDaaS
- C. PaaS
- D. SaaS

### 正确答案及解析：A

答案 A 正确；IaaS（基础设施即服务）提供完整的虚拟化操作系统，客户从操作系统层面向上进行配置。

### 错误答案及解析：B、C 和 D

答案 B、C 和 D 不正确。IDaaS（身份即服务）也称为云身份，允许组织利用云服务进行身份管理。PaaS（平台即服务）提供预配置的操作系统，客户配置应用程序。SaaS（软件即服务）从操作系统到应用程序完全配置好，客户只需使用应用程序。
