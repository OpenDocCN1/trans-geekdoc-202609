

# 评估方法与标准

评估方法和标准旨在衡量系统和产品的现实安全性。*可信计算机系统评估标准*（TCSEC，即橙皮书）是评估模型的鼻祖，由美国国防部于 20 世纪 80 年代开发。随后出现了其他国际模型，包括 ITSEC（欧洲*信息技术安全评估标准*）和通用标准。

在选择安全产品时，如何知道哪个最好？安全专业人员如何知道选择并使用特定供应商的软件不会引入恶意代码？安全专业人员如何了解软件测试得如何以及测试结果是什么？TCSEC 和 ITSEC 曾是这些问题的答案。通用标准是这些问题的较新答案，因此我们接下来将重点关注它。

## 国际通用标准

*国际通用标准*是一项国际商定的标准，用于描述和测试 IT 产品的安全性。它旨在避免超出当前最先进技术水平的要求，并为一系列分类和系统提供了需求层级。通用标准是继 ITSEC 之后的第二个主要国际信息安全标准工作。通用标准使用了 ITSEC 的术语，如评估对象和安全目标。

通用标准的开发旨在评估商业现成的以及政府设计和构建的信息保障（IA）和支持 IA 的 IT 产品。通用标准的一个主要目标是消除待测试目标的已知漏洞。

### 通用标准术语

通用标准在定义测试过程的特定部分时使用特定术语。

*   **评估对象**：正在被评估的系统或产品
*   **安全目标**：描述 TOE 的文档，包括安全需求和运行环境
*   **保护配置文件**：针对特定类别产品或系统（如防火墙或入侵检测系统）的一组独立的安全需求和目标
*   **评估保证级别**：经过测试的产品或系统的评估分数

### 评估级别

在通用标准中，共有七个 EAL 级别；每一级都建立在对前一级进行深入审查的基础之上 [\[14\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0075)。例如，EAL3 级产品预期可满足或超过 EAL1 或 EAL2 级产品的要求。

EAL 级别在《信息技术安全评估通用标准，第 3 部分：安全保证组件》（2009 年 7 月，版本 3.1，修订版 3，最终版，可在以下网址获取：[http://www.commoncriteriaportal.org/files/ccfiles/CCPART3V3.1R3.pdf](http://www.commoncriteriaportal.org/files/ccfiles/CCPART3V3.1R3.pdf)）中进行了描述。这些级别包括：

*   **EAL1**：功能测试
*   **EAL2**：结构测试
*   **EAL3**：系统地测试和检查
*   **EAL4**：系统地设计、测试和评审
*   **EAL5**：半正式地设计和测试
*   **EAL6**：半正式地验证、设计和测试
*   **EAL7**：正式地验证、设计和测试 [\[14\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0075)

# 安全系统设计概念

安全系统设计超越了特定的硬件和软件实现，代表了通用的最佳实践。

## 分层

*分层*将硬件和软件功能分离为模块化层级。诸如从磁盘驱动器读取扇区这类问题的复杂性被限制在一层内（本例中为硬件层）。一层（如应用层）不会直接受到另一层变更的影响。从 `IDE`（集成驱动器电子设备）磁盘驱动器更换为 `SCSI`（小型计算机系统接口）驱动器，不会影响保存文件的应用程序。这些细节包含在一层内，可能仅影响相邻层。

`OSI` 模型（我们将在[第 5 章](#Ch005_225-293_B9780443187346000039.xhtml)，领域 4：通信与网络安全中讨论）是网络分层的一个示例。与 `OSI` 模型不同，安全架构的层没有适用于所有架构的通用标准名称。安全架构层的通用列表如下：

1.  硬件
2.  `内核` 和设备驱动程序
3.  `操作系统`
4.  应用程序

在我们之前的 `IDE` → `SCSI` 驱动器示例中，硬件层中的磁盘驱动器已从 `IDE` 变更为 `SCSI`。相邻层中的设备驱动程序也将随之变更。其他层（如应用层）保持不变。

## 抽象

*抽象*向用户隐藏不必要的细节。复杂性是安全的敌人：流程越复杂，安全性越低。话虽如此：计算机是极其复杂的机器。抽象提供了一种管理这种复杂性的方法。

用户双击一个包含音乐的 `MP3` 文件，音乐通过计算机扬声器播放。在后台，正在发生极其复杂的操作：操作系统打开 `MP3` 文件，查找与之关联的应用程序，并将比特发送给媒体播放器。比特由媒体播放器解码，转换为数字流，并发送给声卡。声卡将流转换为声音并发送给扬声器输出设备。最后，扬声器播放声音。在声音播放时，数百万次计算正在发生，同时正在访问底层设备。

抽象意味着用户只需按下播放键即可听到音乐。

## 安全域

*安全域*是主体被允许访问的对象列表。更广泛地定义，域是具有相似安全需求的主体和对象的组合。例如，机密、秘密和绝密是美国国防部（DoD）使用的三个安全域。就内核而言，两个域分别是用户模式和内核模式。

内核模式（也称为管理员模式）是内核所在的位置，允许对 `内存`、`CPU`、磁盘等进行低级访问。它是系统中最受信任、权力最大的部分。用户模式是用户账户及其进程所在的位置。这两个域是分离的：用户模式下的错误或安全疏漏不应影响内核。大多数现代操作系统都使用这两种模式；一些较简单的（如嵌入式）和较旧的（如 Microsoft `DOS`）操作系统完全运行在内核模式下。

## 环模型

*环模型*是一种 CPU 硬件分层形式，用于将域（如内核模式和用户模式）相互分离和保护。许多 CPU（如 Intel `×86` 系列）有四个环，从环 0（内核）到环 3（用户），如[图 4.7](#Ch004_107-223_B9780443187346000076_1.xhtml#f0040)所示。最内层的环最受信任，每一层向外的环信任度依次降低。

这些环（理论上）的用途如下：

*   **环 0**：内核
*   **环 1**：不适合环 0 的其他操作系统组件
*   **环 2**：设备驱动程序
*   **环 3**：用户应用程序
