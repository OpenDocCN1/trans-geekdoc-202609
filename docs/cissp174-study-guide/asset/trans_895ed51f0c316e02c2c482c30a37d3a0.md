
# 微分段

微分段描述了在所有系统之间进行过滤的过程，无论这些系统是物理的还是基于云的：“微分段是在数据中心和云环境中创建区域以将工作负载相互隔离并单独保护它们的一种方法。通过微分段，系统管理员可以基于零信任方法创建策略，以限制工作负载之间的网络流量。组织使用微分段来减少网络攻击面、改进入侵遏制并加强法规遵从性”（[https://www.paloaltonetworks.com/cyberpedia/what-is-microsegmentation](https://www.paloaltonetworks.com/cyberpedia/what-is-microsegmentation)）。

微分段是核心**零信任**（前文[第4章](#Ch004_107-223_B9780443187346000076_1.xhtml)，领域3：安全架构与工程中已讨论）概念，并使用诸如`Software-Defined Networking (SDN)`、`Software-Defined Wide Area Network (SD-WAN)`和`Virtual eXtensible Local Area Network (VXLAN)`等技术，下文将进行讨论。

## 软件定义网络

通过虚拟化和云服务，存储和计算正日益从传统的服务器和磁盘密集型数据中心中解耦。`Software-Defined Networking (SDN)`寻求在组织网络方法上实现类似的范式转变。一个有助于理解的过度简化说法是，将`SDN`视为一种虚拟化网络并将网络从通常用于此目的的硬件中解耦的方法。

`Software-Defined Networking (SDN)`将路由器的控制平面与数据（转发）平面分离。控制平面做出路由决策。数据平面通过路由器转发数据（数据包）。有了`SDN`，路由决策是在远程做出的，而不是在每个单独的路由器上。

`SDN`的目标之一是允许微分段：灵活且可定制的网络能力。`SDN`的一个标志是有可能使用廉价的“白盒”网络硬件和开放协议来实现这种灵活性，而非传统的专有硬件、固件和软件。`SDN`的另一个常见目标是适应网络能力规则的动态实例化，当基础设施需要时即可生成。

该领域最知名的协议是`OpenFlow`，除其他功能外，它允许在中央控制器指定或更新交换规则的控制权。`OpenFlow`是一种使用`TLS`加密的`TCP`协议。

## 软件定义广域网

`Software-Defined Wide Area Network (SD-WAN)`将`Software-Defined Networks`的概念扩展到云端。它使用多种网络技术的组合，包括`MPLS`、蜂窝网络和宽带：*软件定义广域网(SD-WAN)是一种虚拟WAN架构，允许企业利用任意组合的传输服务——包括MPLS、LTE和宽带互联网服务——来安全地将用户连接到应用程序。SD-WAN使用集中控制功能，跨WAN安全且智能地直接引导流量至受信任的SaaS和IaaS提供商。这提高了应用程序性能并提供高质量的用户体验，从而提高业务生产力和敏捷性并降低IT成本* [\[10\]](#Ch005_225-293_B9780443187346000039.xhtml#bb0055)。

`SD-WAN`可以为任何用户或应用程序自动提供最佳连接：“SD-WAN允许网络基于集中管理的角色和规则路由流量，无论流量的入口和出口点是什么，并提供全方位的安全性。例如，如果分支机构的用户正在使用Office365工作，SD-WAN可以将其流量直接路由到该应用最近的云数据中心，提高用户的网络响应速度并降低企业的带宽成本” [\[11\]](#Ch005_225-293_B9780443187346000039.xhtml#bb0060)。

## 虚拟可扩展局域网

`Virtual eXtensible Local Area Network (VXLAN)`将`VLANs`（虚拟局域网，本章后文讨论）的概念扩展到云端。`VLAN`支持4096个段ID（或VLAN），限制了其在大规模云部署中的使用。`VXLAN`支持1600万个段ID（因此得名“eXtensible/可扩展”），允许全球规模部署。`VXLAN`通过`UDP port 4789`封装数据；封装和解封装由`VTEPs`（虚拟隧道端点）完成。

Juniper对`VXLANS`的描述：

*VXLAN是一种技术，允许您对网络进行分段（就像VLAN一样），但也解决了VLAN的扩展限制，并提供了VLAN无法提供的优势。使用VXLAN的一些重要优势包括：*

*   • *您理论上可以在一个管理域中创建多达1600万个VXLAN（相比之下VLAN只有4094个）。*
*   • *VXLAN提供了云构建者所需规模的网络分段，以支持大量租户。*
*   • *使用传统的第2层网络，您受限于第2层边界，被迫创建大型或地理跨度大的第2层域。VXLAN的功能允许您在数据中心内部或之间动态分配资源，并通过在第3层网络上建立隧道传输流量，实现存在于不同第2层域中的服务器之间的虚拟机迁移* [\[12\]](#Ch005_225-293_B9780443187346000039.xhtml#bb0065)。

# 无线局域网

`Wireless Local Area Networks (WLANs)`通过电磁波（如无线电波）或光传输信息。历史上，无线数据网络非常不安全，往往依赖于（认为）攻击流量的机密性或完整性很困难。这种认知通常是错误的。最常见的无线数据网络形式是`802.11`无线标准，而提供合理安全性的第一个`802.11`标准是`802.11i`。

## DoS与可用性

`WLANs`无法保证可用性。具有物理邻近性的攻击者可以发起多种拒绝服务攻击，包括简单地用噪声污染无线频谱。如果您将`CIA三要素`视为一张三条腿的凳子，“无线安全”就缺了一条腿。需要可靠网络的关键应用应使用有线连接。

## 非授权频段

“频段”是一小段连续的无线电频谱。`Industrial, Scientific, and Medical (ISM)`频段被划出供无证使用，这意味着您无需从`Federal Communications Commission (FCC)`等组织获取许可证即可使用它们。许多无线设备，如无绳电话、`802.11`无线网络和`Bluetooth`都使用`ISM`频段。不同国家使用不同的`ISM`频段：国际上常用的两个`ISM`频段是2.4 GHz和5 GHz。

## FHSS、DSSS和OFDM

`Frequency Hopping Spread Spectrum (FHSS)`和`Direct Sequence Spread Spectrum (DSSS)`是通过无线电频段发送流量的两种方法。某些频段，如2.4 GHz `ISM`频段，可能受到相当严重的干扰污染：`Bluetooth`、某些无绳电话、某些`802.11`无线网络、婴儿监视器，甚至微波炉都可能向该频段发射信号或造成干扰。`DSSS`和`FHSS`均旨在最大化吞吐量，同时最小化干扰的影响。

`DSSS`一次性使用整个频段，将信号“扩展”至整个频段。`FHSS`使用频段中的多个小频率信道，并按伪随机顺序在这些信道间“跳频”。

`Orthogonal Frequency-Division Multiplexing (OFDM)`是一种较新的复用方法，允许使用多个相互独立、互不干扰的无线频率进行同时传输。
