## 1. 密码破解和密码猜测有什么区别？

1.  A. 它们是相同的
2.  B. 密码猜测尝试登录系统；密码破解尝试确定用于创建哈希的密码
3.  C. 密码猜测使用盐值；密码破解不使用
4.  D. 密码破解有账户锁定风险，密码猜测没有

### 正确答案及解析

**B**。答案 *B* 正确；密码破解依赖于破解密码的哈希值；密码猜测尝试登录系统。

### 错误答案及解析

*A*、*C* 和 *D*。*A* 不正确：密码猜测与密码破解不同。*C* 不正确，因为盐值是密码破解的问题，而非密码猜测的问题。*D* 不正确：密码猜测存在账户锁定风险。

## 2. 同一系统上的两个用户拥有相同的密码，但 `/etc/shadow` 文件中存储的哈希值不同。哈希值不同的最可能原因是什么？

1.  A. 用户名不同，所以哈希值会不同
2.  B. 使用了多种哈希算法
3.  C. 使用了彩虹表
4.  D. 使用了盐值

### 正确答案及解析

**D**。答案 *D* 正确；盐值是一个与用户密码一起进行哈希运算的随机数，这使得两个密码相同的用户极不可能拥有相同的哈希值。

### 错误答案及解析

*A*、*B* 和 *C*。答案 *A*、*B* 和 *C* 均不正确。在大多数系统中，不同的用户名不会影响密码哈希。在同一系统上使用多种哈希算法是可能的，但不太可能。彩虹表不用于创建哈希；它们作为数据库，包含大多数或所有可能密码的哈希输出。

## 3. 哪种认证方法会以明文形式暴露密码？

1.  A. CHAP
2.  B. Kerberos
3.  C. PAP
4.  D. SESAME

### 正确答案及解析

**C**。答案 *C* 正确；密码认证协议 (PAP) 在网络上以明文形式暴露密码。

### 错误答案及解析

*A*、*B* 和 *D*。答案 *A*、*B* 和 *D* 均不正确。CHAP、Kerberos 和 SESAME 均不会暴露明文密码。

## 4. 视网膜扫描和虹膜扫描的主要区别是什么？

1.  A. 视网膜扫描无创，虹膜扫描有创
2.  B. 虹膜扫描侵犯个人隐私，视网膜扫描不侵犯
3.  C. 虹膜扫描随个人健康状况变化，视网膜扫描稳定
4.  D. 视网膜扫描随个人健康状况变化，虹膜扫描稳定

### 正确答案及解析

**D**。答案 *D* 正确；视网膜中的血管可能因特定健康状况而发生变化。

### 错误答案及解析

*A*、*B* 和 *C*。*A* 不正确，因为视网膜扫描是有创的——它们可能泄露用户健康信息。*B* 不正确，因为虹膜扫描无创。*C* 不正确，因为虹膜扫描（相对而言）稳定，不受尝试访问用户的总体健康状况影响。

## 5. 组织在实施基于角色的访问控制 (RBAC) 时，需要做出的最重要的决定是什么？

1.  A. 确定每个用户的安全许可
2.  B. 明确定义用户在系统中的角色
3.  C. 明确标记用户的数据
4.  D. 用户必须在 IT 系统中相互隔离，以防止敏感数据泄露

### 正确答案及解析

**B**。答案 *B* 正确；在基于角色的访问控制 (RBAC) 中，必须明确定义用户的角色，以便根据这些角色限制对数据的访问，符合组织策略。

### 错误答案及解析

*A*、*C* 和 *D*。答案 *A* 不正确，因为在 RBAC 中不考虑用户的许可。答案 *C* 不正确，因为 MAC 会给每个对象打标签并将其与主体的许可进行比较，而非 RBAC。答案 *D* 不正确，因为在 RBAC 中用户不会相互隔离。

## 6. 哪种访问控制方法在授予访问权限前，可以审查诸如尝试访问时间等额外因素？

1.  A. 自主访问控制
2.  B. 基于属性的访问控制
3.  C. 基于角色的访问控制
4.  D. 基于规则的访问控制

### 正确答案及解析

**B**。答案 *B* 正确；基于属性的访问控制 (ABAC) 允许考虑无数额外因素，包括尝试访问时间等要素，以做出访问控制决策。

### 错误答案及解析

*A*、*C* 和 *D*。答案 *A*、*C* 和 *D* 均不正确。自主访问控制涉及由主体控制对对象的访问，主体对其创建或被授予完全控制权的对象拥有完全控制权。基于角色的控制基于主体的角色。基于规则的访问控制考虑管控访问决策的已定义规则，最常与防火墙或类似类型的控制相关联。

## 7. 哪种服务被称为云身份，并允许组织利用云服务进行身份管理？

1.  A. IaaS
2.  B. IDaaS
3.  C. PaaS
4.  D. SaaS

### 正确答案及解析

**B**。答案 *B* 正确；身份即服务 (IDaaS)，也称为云身份，允许组织利用云服务进行身份管理。

### 错误答案及解析

*A*、*C* 和 *D*。答案 *A*、*C* 和 *D* 均不正确。IaaS（基础设施即服务）提供完整的虚拟化操作系统，由客户从操作系统层面向上进行配置。PaaS（平台即服务）提供预配置的操作系统，由客户配置应用程序。SaaS（软件即服务）从操作系统到应用程序均已完全配置，客户只需使用应用程序即可。

## 8. 第二类生物特征错误还被称为？

1.  A. 交叉错误率 (CER)
2.  B. 等错误率 (EER)
3.  C. 错误接受率 (FAR)
4.  D. 错误拒绝率 (FRR)

### 正确答案及解析

**C**。答案 *C* 正确；错误接受率 (FAR) 被称为第二类错误。请记住，错误拒绝通常比错误接受更严重，且 II 大于 I。

### 错误答案及解析

*A*、*B* 和 *D*。答案 *A*、*B* 和 *D* 均不正确。交叉错误率 (CER) 和等错误率 (EER) 是同义词，用于衡量生物特征系统的准确性。错误拒绝率 (FRR) 是第一类错误。

## 9. 在 Kerberos 中，哪个部分是单点故障？

1.  A. 票据授予票据
2.  B. 领域
3.  C. 密钥分发中心
4.  D. 客户端-服务器会话密钥

### 正确答案及解析

**C**。*C* 是正确答案，因为 KDC 是 Kerberos 中唯一能够认证主体的服务。如果 KDC 失去可用性，则不会签发票据授予票据，也无法进行新的认证。

### 错误答案及解析

*A*、*B* 和 *D*。*A* 不正确，因为 TGT 是由主体从 KDC 接收的。*B* 不正确，因为领域是共享认证的 Kerberos 网络。*D* 不正确，因为可以签发新的 C-S 会话密钥。
