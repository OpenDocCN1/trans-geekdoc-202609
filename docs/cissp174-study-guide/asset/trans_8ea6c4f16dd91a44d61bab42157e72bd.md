

# 术语表

**VoIP** (Voice over Internet Protocol)：通过数据网络传输语音

**VPN** (Virtual Private Network)：虚拟专用网络，一种在不安全网络（如互联网）上传输私有数据的方法

**Vulnerability** (漏洞)：系统中的弱点

**Vulnerability management** (漏洞管理)：漏洞信息的管理

**Vulnerability scanning** (漏洞扫描)：发现环境中错误配置和缺失补丁的过程

**VXLAN** (Virtual eXtensible Local Area Network)：虚拟可扩展局域网，将 VLAN 的概念扩展到云环境。VLAN 支持 4096 个段 ID（或 VLAN），限制了其在大型云部署中的使用。VXLAN 支持 1600 万个段 ID

**WAF** (Web Application Firewall)：Web 应用防火墙，一种用于 Web 应用的内联第 7 层防护和检测工具

**WAN** (Wide Area Network)：广域网，通常覆盖城市、州或国家

**WAP** (Wireless Application Protocol)：无线应用协议，旨在为手持无线设备（如智能手机）提供安全的 Web 服务

**War dialing** (战争拨号)：使用调制解调器拨打一系列电话号码，寻找应答的调制解调器载波音

**Warded lock** (弹子锁/盘片锁)：一种通过通道（称为 wards）转动钥匙来解锁的预防装置

**Warm site** (温站)：具备所有必要硬件和连接性、已配置好计算机但无实时数据的备份站点

**Wassenaar Arrangement** (瓦森纳协议)：继 COCOM 之后的军火法，始于 1996 年

**Watchdog timer** (看门狗定时器)：在关键进程挂起或崩溃后通过重启来恢复系统

**Waterfall Model** (瀑布模型)：一种应用开发模型，使用严格的阶段：一个阶段结束，下一个阶段开始

**WSDL** (Web Services Description Language)：Web 服务描述语言，提供关于如何调用 Web 服务的详细信息

**Weak tranquility property** (弱宁静性属性)：Bell-LaPadula 模型的一个属性，声明安全标签不会以违反安全策略的方式改变

**Web Application Firewall**：参见 **WAF**

**Web Services Description Language**：参见 **WSDL**

**Well-formed transactions** (格式良好的事务)：Clark-Wilson 模型中为对应用程序实施控制的控制项

**WEP** (Wired Equivalent Privacy)：有线等效隐私，一种非常薄弱的 802.11 安全协议

**White box software testing** (白盒软件测试)：给测试人员访问程序源代码、数据结构、变量等的权限

**Whole Disk Encryption** (全盘加密)：参见 **FDE**

**Wide Area Network**：参见 **WAN**

**Wi-Fi Protected Access**：参见 **WPA**

**Wi-Fi Protected Access 2**：参见 **WPA2**

**Wiping** (擦除/清零)：在文件数据的每一位或每个块上写入新数据。也称为 shredding (粉碎)

**Wired Equivalent Privacy**：参见 **WEP**

**Wireless Application Protocol**：参见 **WAP**

**WLAN** (Wireless Local Area Network)：无线局域网，通过电磁波（如无线电）或光传输信息的网络

**Work factor** (工作因子)：破解密码系统所需的时间量（在没有密钥的情况下解密密文）

**Work Recovery Time** (工作恢复时间)：参见 **WRT**

**Worm** (蠕虫)：能够自我传播的恶意软件

**WORM** (Write Once Read Many)：一次写入多次读取，一种可写入一次、多次读取的存储介质

**WPA** (Wi-Fi Protected Access)：Wi-Fi 保护访问，802.11i 的部分实现

**WPA2** (Wi-Fi Protected Access 2)：Wi-Fi 保护访问 2，802.11i 的完整实现

**Write Once Read Many**：参见 **WORM**

**WRT** (Work Recovery Time)：工作恢复时间，配置恢复系统所需的时间

**X.25**：较早的分组交换广域网协议

**XML** (Extensible Markup Language)：可扩展标记语言，一种设计用于以标准方式编码文档和数据的标记语言

**XOR** (Exclusive OR)：异或，一种二元运算，当且仅当两个输入中有一个为真（但不同时为真）时结果为真

**XP** (Extreme Programming)：极限编程，一种敏捷开发方法，使用成对的程序员基于详细规格说明工作

**XSS** (Cross-Site Scripting)：跨站脚本攻击，在受信任站点的安全上下文中由第三方执行 Web 脚本语言（如 JavaScript）

**Zachman Framework** (Zachman 框架)：为信息安全提供六个框架，询问 what、how、where、who、when 和 why，并将这些框架映射到包括 planner、owner、designer、builder、programmer 和 user 在内的规则中

**Zero knowledge test** (零知识测试/盲测)：一种盲渗透测试，测试人员在测试开始时没有任何内部信息

**Zero Trust** (零信任)：一种将每个设备视为不受信任的模型，无论其是本地还是远程

**Zero-day exploit** (零日漏洞利用/0day 攻击)：针对尚无厂商补丁可用的漏洞的利用代码

**ZigBee**：一种个人局域网无线技术。它是一种低功耗、短距离的无线网状技术，广泛用于仓库、物联网、楼宇自动化与控制 (BAC) 等领域

**Zombie** (僵尸主机)：参见 **Bot**
