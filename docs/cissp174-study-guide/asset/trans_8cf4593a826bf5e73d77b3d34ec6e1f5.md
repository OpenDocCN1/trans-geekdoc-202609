

# 术语表

**Accreditation**  
数据所有者对系统所代表的风险的接受。

**ABAC**  
一种较新的访问控制模型，通过在访问请求时考虑主体和客体的属性来确定授权。

**ACK**  
TCP 标志，确认接收到的数据。

**ACL**  
访问控制列表。

**Act honorably, honestly, justly, responsibly, and legally**  
(ISC)²® 职业道德准则的第二条准则。

**Active RFID**  
有源 RFID 标签，可在更大距离上运行。

**Active-active cluster**  
涉及多个系统，所有系统均在线并主动处理流量或数据。

**Active-passive cluster**  
涉及已就位、已配置、已通电并准备好在主系统发生故障时开始处理网络流量的设备或系统。

**ActiveX controls**  
Java Applet 的功能等价物。它们使用数字证书而非沙箱来提供安全性。

**Ad hoc mode**  
802.11 对等模式，无中心接入点。

**Address Space Layout Randomization**  
参见——`ASLR`。

**Administrative controls**  
通过创建和遵循组织政策、程序或法规来实施。也称为指令性控制。

**Administrative law**  
由政府机构颁布的法律，又称监管法。

**ADSL**  
非对称数字用户线路，下载速度快于上传的 DSL 技术。

**Advance and protect the profession**  
(ISC)²® 职业道德准则的第四条准则。

**Advanced Encryption Standard**  
参见——`AES`。

**AES**  
高级加密标准，一种分组密码，使用 128 位、192 位或 256 位密钥加密 128 位数据块。

**Agents of law enforcement**  
代表执法部门行事的私人公民。

**Aggregation**  
聚合攻击，用户能够利用低级别访问权限获取受限信息。

**Agile Software Development**  
一种灵活的软件开发模型，是对瀑布模型等僵化软件开发模型的反应而演变而来的。

**AH**  
认证头，IPsec 协议，为每个网络数据包提供认证和完整性。

**ALE**  
年化损失期望值，一年内因风险导致的损失成本。

**All pairs testing**  
参见——成对测试。

**Allocated space**  
磁盘分区中标记为活跃包含数据的部分。

**ALU**  
算术逻辑单元，执行数学计算的 CPU 组件。

**Analog**  
发送连续信息波的通信方式。

**ANN**  
人工神经网络，模拟人类和动物大脑中发现的神经网络。

**Annual Rate of Occurrence**  
参见——`ARO`。

**Annualized Loss Expectancy**  
参见——`ALE`。

**Antivirus software**  
旨在预防和检测恶意软件感染的软件。

**API**  
应用程序编程接口，允许应用程序与另一个应用程序、操作系统、数据库、网络等进行通信。例如，`Google Maps API` 允许应用程序集成第三方内容，如叠加在 Google 地图上的餐厅。

**Applet**  
嵌入在其他软件（如 Web 浏览器）中的小段移动代码。

**Application layer (OSI)**  
OSI 模型的第 7 层，用户在此与计算机应用程序交互。

**Application layer (TCP/IP)**  
TCP/IP 模型层，合并了 OSI 模型的第 5 至第 7 层。

**Application-layer proxy**  
工作在第 7 层的代理防火墙。

**Application Programming Interface**  
参见——`API`。

**Arithmetic Logic Unit**  
参见——`ALU`。

**ARM**  
异步响应模式，HDLC 模式之一，允许辅助节点主动与主节点发起通信。

**ARO**  
年化发生率，每年遭受的损失次数。

**ARPAnet**  
互联网的前身。

**Artificial Intelligence**  
让电子计算机“更智能地思考”的科学，有时模仿哺乳动物大脑的能力。

**Artificial Neural Networks**  
参见——`ANN`。

**ASLR**  
地址空间布局随机化，通过使系统使用的内存地址更难预测，以降低成功利用的可能性。

**Assembly language**  
低级计算机编程语言，指令为简短助记符（如 `ADD`、`SUB`（减法）、`JMP`（跳转）），与机器语言指令一一对应。

**Asset**  
对组织有价值且必须受到保护的资源。

**Asset Value**  
参见——`AV`。

**Asymmetric Digital Subscriber Line**  
参见——`ADSL`。

**Asymmetric encryption**  
非对称加密，使用两个密钥：若用其中一个加密，则可用另一个解密。

**Asynchronous Balanced Mode**  
参见——`ABM`。

**Asynchronous dynamic token**  
未与中央服务器同步的认证令牌；包括质询-响应令牌。

**Asynchronous Response Mode**  
参见——`ARM`。

**Asynchronous Transfer Mode**  
参见——`ATM`。

**Attribute**  
关系数据库表中的一列。

**Attribute-Based Access Control**  
参见——`ABAC`。

**Authentication**  
身份声明的证明。

**Authentication Header**  
参见——`AH`。

**Authorization**  
个人在系统上可执行的操作。

**Authorization creep**  
授权蔓延，指员工不仅保留旧的访问权限，还在组织内部跨部门调动时获得新权限。

**AV**  
资产价值，受保护资产的价值。

**Availability**  
确保在需要时信息可用。

**Awareness**  
旨在改变用户行为的安全控制。

**Backdoor**  
系统中的捷径，允许用户绕过安全检查。

**Background checks**  
对个人背景和经历的核实，也称为入职前筛查。

**Backward chaining**  
专家系统模式之一，从前提开始，向后推理。

**BAS**  
攻击模拟，旨在自动化渗透测试，通常全天候运行。

**Baseband**  
基带网络，只有一个信道；一次只能发送一个信号。

**Baseline**  
实施保障措施的统一方式，属于管理控制。

**Baselining**  
捕获当前系统安全配置时间点理解的过程。

**Basic Input Output System**  
参见——`BIOS`。

**Basic Rate Interface**  
参见——`BRI`。

**Bastion host**  
堡垒主机，放置在互联网上且未受其他设备保护的任何主机。

**Bayesian filtering**  
贝叶斯过滤，使用数学公式分配概率以做出决策，如识别垃圾邮件。

**BCI**  
商业连续性学会。

**BCP**  
业务连续性计划，确保业务运营连续性的长期计划。

**BCP/DRP project manager**  
BCP/DRP 项目经理，确保 BCP/DRP 不仅完成，而且定期测试的关键联系人。

**bcrypt**  
基于 Blowfish 的慢速密码哈希算法。

**Bell-LaPadula**  
专注于维护对象机密性的安全模型。

**Best evidence rule**  
最佳证据规则，要求使用最有力的证据。

**Best practice**  
最佳实践，保护资产机密性、完整性和可用性的最佳方式的共识。

**BGP**  
边界网关协议，互联网上使用的路由协议。

**Biba**  
专注于维护对象完整性的安全模型。

**Big Bang testing**  
大爆炸测试，测试所有集成软件组件的集成测试。

**Binary image**  
内存的位级副本。

**BIOS**  
基本输入输出系统，通常存储在固件中。

**Black box software testing**  
黑盒软件测试，不向测试人员提供任何内部细节：软件被视为接收输入的黑盒。

**Blowfish**  
一种分组密码，使用 32 位至 448 位（默认 128 位）密钥加密 64 位数据。

**Bluetooth**  
802.15 网络，一种 PAN 无线技术。

**Bollard**  
挡车柱，设计用于阻挡车辆，通常部署在建筑入口前。
