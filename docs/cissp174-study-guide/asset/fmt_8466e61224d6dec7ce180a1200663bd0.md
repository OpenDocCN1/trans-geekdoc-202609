
# 术语表

**Tailgating**  
跟随授权人员进入建筑物而不提供凭证。也称为 piggybacking（搭便车）。

**Tailoring**  
为组织定制标准的过程。

**Take-Grant Protection Model**  
确定遵循特定规则的给定计算机系统的安全性。

**Tangible asset**  
有形资产，如计算机、网络设备、电缆和显示器等物理资产。

**TAP**  
Test Access Port（测试接入端口），提供一种“窃听”网络流量并查看网络上所有单播流的方法。

**TCP**  
Transmission Control Protocol（传输控制协议），使用三次握手在网络上创建可靠连接。

**TCP/IP model**  
具有四层的网络模型：网络接口层、网际层、传输层和应用层。

**TCSEC**  
Trusted Computer System Evaluation Criteria（可信计算机系统评估标准），即 Orange Book（橙皮书），由美国国防部开发的评估模型。

**Teardrop attack**  
一种畸形数据包 DoS 攻击，针对系统的分片重组功能。

**Technical controls**  
使用软件、硬件或固件实施，限制对信息技术系统的逻辑访问。

**Telnet**  
一种协议，使用 TCP 端口 23 通过网络提供终端仿真。

**TEMPEST**  
一种用于屏蔽计算机设备电磁辐射的标准。

**Temporal Key Integrity Protocol**  
参见——TKIP。

**Terminal Access Controller Access Control System**  
参见——TACACS。

**TFTP**  
Trivial File Transfer Protocol（简单文件传输协议），一种无需认证或目录结构即可传输文件的简单方式。

**TGS**  
Ticket Granting Service（票据授予服务），一种 Kerberos 服务，用于授予对服务的访问权限。

**TGT**  
Ticket Granting Ticket（票据授予票据），使用 TGS 密钥加密的 Kerberos 凭证。

**Thicknet**  
较旧类型的同轴电缆，用于以太网总线网络。

**Thin client applications**  
使用 Web 浏览器作为通用客户端，提供对健壮应用程序的访问，这些应用程序从瘦客户端服务器下载并在客户端浏览器中运行。

**Thin clients**  
依赖集中式应用程序和数据的简单计算机系统。

**Thinnet**  
较旧类型的同轴电缆，用于以太网总线网络。

**Thread**  
轻量级进程（LWP）。

**Threat**  
潜在的负面事件。

**Threat agents**  
导致威胁的行为体，可能利用漏洞。

**Threat hunting**  
基于已知威胁情报，搜索对手活动的证据。

**Threat intelligence**  
关于对手和入侵活动的详细信息，旨在通过创建和共享来实现更好的防护和检测。

**Threat modeling**  
旨在正式描述系统可用的各种攻击向量，并帮助规划部署适当的缓解措施。

**Threat vectors**  
允许漏洞利用连接到漏洞的载体。

**Throughput**  
向系统（如生物识别认证系统）进行认证的过程。

**Ticket**  
用于认证 Kerberos 主体身份的数据。

**Ticket Granting Service**  
参见——TGS。

**Ticket Granting Ticket**  
参见——TGT。

**Time multiplexing**  
时间复用，在多个进程之间共享（复用）系统资源，每个进程拥有专用的时间片。

**Time of Check/Time of Use**  
参见——TOCTOU。

**Timing attacks**  
一种侧信道攻击，利用时间来破坏系统或泄露敏感数据。

**Timing channel**  
依赖系统时钟推断敏感信息的隐蔽信道。

**TKIP**  
Temporal Key Integrity Protocol（临时密钥完整性协议），WPA 用于提供完整性的协议。

**TLS**  
Transport Layer Security（传输层安全），SSL 的继任者。

**TNI**  
Trusted Network Interpretation（可信网络解释），即 Red Book（红皮书）。

**TOCTOU**  
Time of Check/Time of Use（检查时间/使用时间），在操作系统检查条件后但在使用前更改该条件。

**Top-Down programming**  
自顶向下编程，从最广泛和最高层级的需求（最终程序的概念）开始，逐步深入到低层级的技术实现细节。

**Total Cost of Ownership**  
总拥有成本，保护措施的成本。

**TPM**  
Trusted Platform Module（可信平台模块），一种处理器，可在硬件级别提供额外的安全功能，支持基于硬件的加密操作。

**Traceability Matrix**  
追踪矩阵，将客户需求映射到软件测试计划：它“追踪”“需求”，并确保它们得到满足。

**Traceroute**  
使用 ICMP Time Exceeded（超时）消息追踪网络路由的命令。

**Trade secret**  
商业机密，对组织竞争能力至关重要的专有业务信息。

**Trademark**  
商标，允许创建品牌以区分产品来源的知识产权保护。

**Training**  
旨在提供技能组合的安全控制。

**Transmission Control Protocol**  
参见——TCP。

**Transport layer (OSI)**  
OSI 模型第 4 层，处理数据包排序、流量控制和错误检测。

**Transport layer (TCP/IP)**  
TCP/IP 模型中连接网际层和应用层的层。

**Transport Layer Security**  
参见——TLS。

**Transposition**  
参见——Permutation（置换）。

**Tree**  
具有根节点且分支节点至少三层深的物理网络拓扑。

**Triple DES**  
每个块应用三次 56 位 DES。

**Trivial File Transfer Protocol**  
参见——TFTP。

**Trojan**  
木马，执行两种功能的恶意软件：一种良性（如游戏）和一种恶意。也称为 Trojan Horses（特洛伊木马）。

**Trust, but Verify**  
一种安全模型，要求所有访问（本地和远程）都进行双因素认证，加强日志记录，并确保日志的完整性。

**Trusted Computer System Evaluation Criteria**  
参见——TCSEC。

**Trusted Network Interpretation**  
参见——TNI。

**Trusted Platform Module**  
参见——TPM。

**Truth table**  
真值表，用于映射数学运算（如 XOR）所有结果的表。

**Tuple**  
关系数据库表中的一行。

**Turnstile**  
转闸，一种通过强制执行“每次认证一人”的规则来防止尾随的设备。

**Twofish**  
AES 决赛算法，使用 128 至 256 位密钥加密 128 位块。

**Type 1 authentication**  
类型 1 认证：你所知（Something you know）。

**Type 2 authentication**  
类型 2 认证：你所拥有（Something you have）。

**Type 3 authentication**  
类型 3 认证：你的固有特征（Something you are）。

**Type I error**  
参见——FRR。

**Type II error**  
参见——FAR。

**Typosquatting**  
注册由合法域名商标可能的拼写错误或打字错误组成的互联网域名。

**UDP**  
User Datagram Protocol（用户数据报协议），TCP 更简单、更快的表亲。

**UEBA**  
User and Entity Behavior Analytics（用户和实体行为分析），一种侦测控制，构建典型用户和端点系统活动的配置文件，并监控与预期行为的可疑偏差。

**Ultrasonic motion detector**  
超声波运动探测器，使用超声波能量的主动运动探测器。

**Unallocated space**  
磁盘分区中不包含活动数据的部分。

**Unicast**  
单播，一对一网络流量，如客户端浏览网页。

**Unit Testing**  
单元测试，软件组件（如函数、过程或对象）的低层级测试。

**Unshielded Twisted Pair**  
参见——UTP。

**URG**  
TCP 标志，表示数据包包含紧急数据。

**Use Limitation Principle**  
使用限制原则，OECD 隐私指南原则，规定未经个人同意或法律要求，不得披露个人数据。

**User Datagram Protocol**  
参见——UDP。

**User and Entity Behavior Analytics**  
参见——UEBA。

**UTP**  
Unshielded twisted pair（非屏蔽双绞线），使用绞合在一起的线对的网络布线。

**VDSL**  
Very High Rate Digital Subscriber Line（超高速数字用户线路），具有更快的非对称速度的 DSL。

**Very High Rate Digital Subscriber Line**  
参见——VDSL。

**Virtual memory**  
虚拟内存，在应用程序和硬件内存之间提供虚拟地址映射。

**Virtual Private Network**  
参见——VPN。

**Virtualization**  
虚拟化，在操作系统和底层计算机硬件之间增加一个软件层。

**Virus**  
病毒，需要载体传播的恶意软件。

**Vishing**  
语音钓鱼，通过语音进行的网络钓鱼。

**VLAN**  
虚拟局域网，可视为虚拟交换机的 LAN。

**Voice over Internet Protocol**  
参见——VoIP。

**Voice print**  
声纹，一种生物识别控制，测量主体在陈述特定句子或短语时的语调。
