

# 术语表

## M

**Motherboard**  
包含计算机硬件，包括`CPU`、内存插槽、固件以及外设插槽（如`PCI`（Peripheral Component Interconnect）插槽）。

**MPLS**  
Multiprotocol Label Switching，提供一种通过标签转发`WAN`数据的方式。

**MTBF**  
Mean Time Between Failures，量化新系统或修复后的系统在发生故障前平均能运行多长时间。

**MTD**  
Maximum Tolerable Downtime，系统在组织受到严重影响前可处于不可操作状态的总时间。

**MTTR**  
Mean Time to Repair，描述恢复故障系统所需的时间。

**MTU**  
Maximum Transmission Unit，网络上的最大`PDU`大小。

**Multicast**  
一对多网络流量，“多”是预先选定的。

**Multipartite virus**  
通过多种载体传播的病毒。也称为multipart virus。

**Multiprocessing**  
在多个`CPU`上运行多个进程。

**Multiprotocol Label Switching**  
参见——`MPLS`。

**Multitasking**  
允许多个任务（重量级进程）在一个`CPU`上同时运行。

**Mutation**  
遗传算法概念，向算法引入随机变化。

**Mutual Aid Agreement**  
参见——Reciprocal agreement。

## N

**NAT**  
Network Address Translation，转换`IP`地址。

**NDA**  
Non-disclosure agreement，一种合同协议，确保个人或组织了解其对维护敏感信息机密性的法律责任。

**Need to know**  
要求主体在访问信息前需知晓该信息。

**Network access layer**  
`TCP/IP`模型层，结合了`OSI`模型的第1层和第2层。它描述第1层问题，如能量、比特以及承载它们的介质。

**Network Address Translation**  
参见——`NAT`。

**Network Interface Card**  
参见——`NIC`。

**Network Intrusion Prevention System**  
参见——`NIPS`。

**Network layer**  
`OSI`模型的第3层，描述从一个`LAN`上的系统到另一个`LAN`上的系统的数据路由。

**Network model (databases)**  
允许分支有两个父节点的层次型数据库类型。

**Network model (telecommunications)**  
网络协议套件如何运行的描述。

**Network stack**  
以软件或硬件编程的网络协议套件。

**Network-based Intrusion Detection System**  
参见——`NIDS`。

**NIC**  
Network Interface Card，将系统连接到网络的卡。

**NIDS**  
Network-based Intrusion Detection System，一种侦查型技术控制。

**NIPS**  
Network Intrusion Prevention System，一种旨在防止恶意网络流量的预防性设备。

**NIST SP 800-34**  
NIST Special Publication 800-34 “Contingency Planning Guide for Information Technology Systems”。

**Nonce Sum**  
参见——`NS`。

**Non-disclosure agreement**  
参见——`NDA`。

**Non-discretionary access control**  
基于主体的角色或任务的访问控制。

**Non-interference Model**  
确保不同安全域的数据彼此保持分离。

**Non-repudiation**  
确保特定用户执行了特定事务，且该事务未被篡改。

**Normal Response Mode**  
参见——`NRM`。

**Normalization**  
旨在使数据库表中的数据在逻辑上简洁、有序且一致。

**Northbridge**  
将`CPU`连接到`RAM`和视频内存，也称为Memory Controller Hub（`MCH`）。

**NRM**  
Normal response mode，`SDLC`/`HDLC`模式，其中次级节点在获得主节点许可后可传输。

**NS**  
Nonce Sum，最新的`TCP`标志，用于拥塞通知。

## O

**OAuth**  
一种授权框架，允许以标准化方式进行通信并将授权委托给应用程序，而无需用户透露其凭据。

**Object**  
数据文件。

**Object**  
一个结合了代码和数据的“黑盒”，能够发送和接收消息。

**Object encapsulation**  
将进程视为“黑盒”处理。

**Object Linking and Embedding**  
参见——`OLE`。

**Object Request Brokers**  
参见——`ORBs`。

**Object-Oriented Analysis**  
参见——`OOA`。

**Object-oriented database**  
在面向对象框架中将数据与函数（代码）结合的数据库。

**Object-Oriented Design**  
参见——`OOD`。

**Object-Oriented Programming**  
参见——`OOP`。

**Occupant Emergency Plan**  
参见——`OEP`。

**OCSP**  
Online Certificate Status Protocol，一种用于查找吊销证书的客户端-服务器方法。

**OCTAVE**  
Operationally Critical Threat, Asset, and Vulnerability Evaluation，来自卡内基梅隆大学的风险管理框架。

**OECD Privacy Guidelines**  
Organization for Economic Cooperation and Development隐私指南，包含八项原则。

**OEP**  
Occupant Emergency Plan，一种基于设施的计划，侧重于安全和疏散。

**OFB**  
Output Feedback，一种使用密钥部分进行反馈的`DES`流模式。

**OFDM**  
Orthogonal Frequency-Division Multiplexing，一种较新的无线复用方法，允许使用多个互不干扰的独立无线频率进行同时传输。

**Offshoring**  
外包给另一个国家。

**OIDC**  
OpenID Connect提供了一种现代单点登录或联合身份验证框架，构建于`OAuth`授权协议之上。`SAML`的替代方案。

**OLE**  
Object Linking and Embedding，`DCOM`的一部分，用于将文档链接到其他文档。

**Onboarding**  
将新员工引入组织的过程，包括账户创建、授权授予，以及确保员工知晓所有相关政策和程序。

**One-Time Pad**  
理论上无法破解的加密，使用成对的随机字符垫。

**One-time password**  
可用于单次身份验证的密码。

**Online Certificate Status Protocol**  
参见——`OCSP`。

**OOA**  
Object-Oriented Analysis，理解问题域的高层方法，识别所有对象及其交互。

**OOD**  
Object-Oriented Design，一种面向对象的高层软件设计方法。

**OOP**  
Object-Oriented Programming，改变了旧的过程式编程方法，将程序视为一系列通过消息通信的连接对象。

**Open Authorization**  
参见——`OAuth`。

**Open Shortest Path First**  
参见——`OSPF`。

**Open source**  
源代码公开发布的软件，允许任何人检查、修改或编译代码。

**Open system**  
使用开放硬件和标准的系统，使用来自多个供应商的标准组件。

**OpenID Connect**  
参见——`OIDC`。

**Openness Principle**  
OECD Privacy Guideline原则，规定个人数据的收集和使用应公开可得。

**Operating system**  
操作计算机的软件。

**Operationally Critical Threat, Asset, and Vulnerability Evaluation**  
参见——`OCTAVE`。

**Optimizing**  
`CMM`第5阶段。

**Orange Book**  
参见——`TCSEC`。

**ORBs**  
Object Request Brokers，用于定位对象并与之通信。

**Organizationally Unique Identifier**  
参见——`OUI`。

**Orthogonal Frequency-Division Multiplexing**  
参见——`OFDM`。

**OSI model**  
一个具有七层的网络模型：物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。

**OSPF**  
Open Shortest Path First，一种开放的链路状态路由协议。

**OUI**  
Organizationally Unique Identifier，`MAC`地址的前24位。

**Output Feedback**  
参见——`OFB`。

**Outsourcing**  
使用第三方提供以前在内部执行的信息技术支持服务。

**Overt channel**  
符合安全策略的授权通信。

## P

**PaaS**  
Platform as a Service，提供预配置的操作系统，由客户配置应用程序。

**Packet**  
第3层`PDU`。

**Packet filter**  
一种简单快速的防火墙，没有状态概念。

**Packet-switched network**  
一种网络形式，带宽共享，数据以包为单位传输。

**Pairwise testing**  
一种组合软件测试形式，测试输入的唯一对。

**PAN**  
Personal Area Network，一种范围在100米或更小的极小型网络。
