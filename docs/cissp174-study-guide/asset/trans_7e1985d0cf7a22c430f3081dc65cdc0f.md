## 第 3 章：领域 2：资产安全

### 1. 哪种类型的内存常用于 CPU 寄存器？

1.  A. DRAM
2.  B. 固件
3.  C. ROM
4.  D. SRAM

**正确答案及解析：D。** 答案 D 正确；SRAM（静态随机存取存储器）速度快且昂贵，常用于高速缓存内存，包括 CPU 寄存器。

**错误答案及解析：A、B 和 C。** 答案 A、B 和 C 不正确。DRAM 比 SRAM 慢且便宜，常用作主内存。固件是 EEPROM 等可编程逻辑器件使用的一种技术。只读存储器是一种固件，为 BIOS 等用途提供非易失性内存。

### 2. 哪种类型的固件通过紫外线擦除？

1.  A. EPROM
2.  B. EEPROM
3.  C. 闪存
4.  D. PROM

**正确答案及解析：A。** 答案 A 正确；EPROM（可擦除可编程只读存储器）通过暴露在紫外线下来擦除。

**错误答案及解析：B、C 和 D。** 答案 B、C 和 D 不正确。EEPROM（电可擦除可编程只读存储器）通过电子方式擦除，即通过刷写程序。闪存驱动器是一种 EEPROM，也通过电子方式擦除。PROM（可编程只读存储器）无法擦除。

### 3. 以下哪项描述了确定组织将采用标准中哪些部分的过程？

1.  A. 基线
2.  B. 策略
3.  C. 划定范围
4.  D. 裁剪

**正确答案及解析：C。** 答案 C 正确；划定范围是确定组织将采用标准中哪些部分的过程。

**错误答案及解析：A、B 和 D。** 答案 A、B 和 D 不正确。基线是实施防护措施的统一方式，属于管理控制。策略是高层管理指令。裁剪是为组织定制标准的过程。

### 4. 哪个术语表示供应商不再销售某产品？

1.  A. 停止支持
2.  B. 遗留
3.  C. 停止生命周期
4.  D. 停止支持生命周期

**正确答案及解析：C。** 答案 C 正确；停止生命周期意味着供应商不再销售该产品，但通常仍会在一段时间内提供支持。

**错误答案及解析：A、B 和 D。** 答案 A、B 和 D 不正确。停止支持（也称为停止服务生命周期）意味着供应商不再支持该产品。遗生是指不受支持设备的通用术语。

### 5. ISO 17799 更名为什么？

1.  A. BS 7799-1
2.  B. ISO 27000
3.  C. ISO 27001
4.  D. ISO 27002

**正确答案及解析：D。** 答案 D 正确；ISO 17799 更名为 ISO 27002。

**错误答案及解析：A、B 和 C。** 答案 A、B 和 C 不正确。BS 7799-1 是 ISO 17799 的前身。ISO 27000 是一系列信息安全标准文档。ISO 27001 是另一个 ISO 27000 系列文档，旨在支持审计。

### 6. 以下哪项描述了数据所有者的职责？

1.  A. 给系统打补丁
2.  B. 报告可疑活动
3.  C. 确保其文件已备份
4.  D. 确保数据具有适当的安全标签

**正确答案及解析：D。** 答案 D 正确；数据所有者确保数据具有适当的安全标签。

**错误答案及解析：A、B 和 C。** 答案 A、B 和 C 不正确。保管员给系统打补丁。用户应保持警惕并报告可疑活动。确保文件已备份是数据所有者职责的一个较弱答案，旨在混淆数据所有者与自主访问控制系统上的“文件所有者”。

### 7. 哪个控制框架在五个域中拥有 40 个流程？

1.  A. COSO
2.  B. COBIT
3.  C. ITIL
4.  D. OCTAVE

**正确答案及解析：B。** 答案 B 正确；COBIT 在五个域中拥有 40 个信息技术流程。

**错误答案及解析：A、C 和 D。** 答案 A、C 和 D 不正确。这些都是审计或控制框架，但只有 COBIT 在五个域中拥有 40 个流程。

### 8. OCTAVE 的哪个阶段识别漏洞并评估防护措施？

1.  A. 阶段 1
2.  B. 阶段 2
3.  C. 阶段 3
4.  D. 阶段 4

**正确答案及解析：B。** 答案 B 正确；阶段 2 识别漏洞并评估防护措施。

**错误答案及解析：A、C 和 D。** 答案 A、C 和 D 不正确。阶段 1 识别员工知识、资产和威胁。阶段 3 进行风险分析并制定风险缓解策略。OCTAVE 中没有阶段 4。

### 9. 以下哪项是从未受物理损坏的固态硬盘安全移除数据的最佳方法？

1.  A. ATA 安全擦除
2.  B. 位级覆盖
3.  C. 退磁
4.  D. 文件粉碎

**正确答案及解析：A。** 答案 A 正确；ATA 安全擦除可可靠地从未受损的固态硬盘 (SSD) 中移除数据。

**错误答案及解析：B、C 和 D。** 答案 B、C 和 D 不正确。位级覆盖无法可靠地销毁固态硬盘上的所有数据。退磁对非磁性介质无效。文件粉碎（删除前覆盖文件内容）也无法可靠地销毁固态硬盘上的所有数据。

### 10. 泄露哪类机密数据可能导致“对国家安全造成极其严重的损害”？

1.  A. 机密
2.  B. 秘密
3.  C. 敏感但未分类
4.  D. 绝密

**正确答案及解析：D。** 答案 D 正确；泄露绝密数据可能导致“对国家安全造成极其严重的损害”。

**错误答案及解析：A、B 和 C。** 答案 A、B 和 C 不正确。泄露机密数据可能导致“对国家安全造成损害”。泄露秘密数据可能导致“对国家安全造成严重损害”。泄露 SBU 数据不涉及国家安全，但出于其他原因很重要，包括保护个人的 PII。

### 11. 某公司将薪资服务外包给第三方公司。以下哪个角色最可能适用于该第三方薪资公司？

1.  A. 数据控制者
2.  B. 数据处理者
3.  C. 数据所有者
4.  D. 数据处理器

**正确答案及解析：D。** 答案 D 正确；第三方薪资公司是数据处理器的一个示例。

**错误答案及解析：A、B 和 C。** 答案 A、B 和 C 不正确。数据控制者是创建 PII 的人，例如人力资源部门。“数据处理者”不是一个正式术语，是一个干扰项。数据所有者是负责确保特定数据受到保护的管理层员工。

### 12. 哪个管理角色负责存放数据的实际计算机，包括硬件和软件配置的安全性？

1.  A. 保管员
2.  B. 数据所有者
3.  C. 任务所有者
4.  D. 系统所有者

**正确答案及解析：D。** 答案 D 正确；系统所有者负责存放数据的实际计算机，包括硬件和软件配置的安全性。
