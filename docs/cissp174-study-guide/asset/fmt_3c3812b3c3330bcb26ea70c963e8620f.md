
# 术语表

## R
**RTO** (Recovery Time Objective)：允许恢复业务或 IT 系统的最长时间。

**RTP** (Real-time Transport Protocol)：一种 VoIP 协议，旨在传输流式音频和视频。

**Rule-based access control** (基于规则的访问控制)：使用一系列定义好的规则、限制和过滤器来访问系统内的对象。

**Running-key cipher** (流密钥密码/连续密钥密码)：一种加密方法，使用来自知名文本（如字典）的完整单词，通过模运算将字母“添加”到明文中。

**Runtime** (运行时)：当前正在执行的进程的状态（也称为运行中）。

## S
**S/MIME** (Secure/Multipurpose Internet Mail Extensions)：安全/多用途互联网邮件扩展，利用 PKI 对 MIME 编码的电子邮件进行加密和认证。

**SA** (Security Association)：安全关联，一种单工连接，可用于协商 ESP 或 AH 参数。

**SaaS** (Software as a Service)：软件即服务，完全配置好的基于云的应用程序，涵盖从操作系统向上的所有层面。

**Salt** (盐值)：与密码一起哈希的随机数。允许同一密码以多种方式哈希。

**SAML** (Security Assertion Markup Language)：安全断言标记语言，一种基于 XML 的框架，用于交换安全信息，包括认证数据。

**SAN** (Storage Area Network)：存储区域网络，通过网络提供块级磁盘存储。

**Sanction** (制裁/处罚)：因违反政策而采取的行动。

**Sandboxing** (沙箱技术)：一种基于在安全环境（称为沙箱）中渲染或执行内容时表现出的行为分析，来保护和检测恶意内容的方法。

**Sarbanes-Oxley Act** (萨班斯-奥克斯利法案)：参见 **SOX**。

**Sashimi Model** (刺身模型/重叠模型)：步骤高度重叠的开发模型；可视为瀑布模型在现实世界中的继任者。

**SAST** (Static Application Security Testing)：静态应用安全测试，被动测试代码：代码不运行。

**Satellite communications** (卫星通信)：通过与地球轨道匹配、看似静止在天空中的地球同步卫星提供语音和数据服务。

**Savepoint** (保存点)：数据库表的一个干净快照。

**Schema** (模式)：描述数据库表的属性和值。

**Scoping** (范围界定)：确定组织将采用标准中哪些部分的过程。

**Screened host architecture** (屏蔽主机架构)：使用单个路由器通过 ACL 过滤进出堡垒主机的外部流量的较旧扁平网络设计。

**Screened subnet architecture** (屏蔽子网架构)：两个防火墙屏蔽一个 DMZ。

**Script kiddies** (脚本小子)：使用他们几乎不理解的工具攻击计算机系统的攻击者。

**SCM** (Software Configuration Management)：软件配置管理，一种自动化系统管理任务（包括服务器部署和配置管理）的敏捷方法。

**SCRM** (Supply Chain Risk Management)：供应链风险管理，描述管理从第三方采购产品和服务风险的过程。

**Scrum** (Scrum 敏捷框架)：使用小团队的敏捷开发模型，角色包括 Scrum Master 和 Product Owner。

**Scrum Master** (Scrum 主管)：充当 Scrum 团队教练的组织高级成员。

**scrypt**：一种缓慢的密码哈希算法。

**SDLC (Applications)** (Systems Development Life Cycle)：系统开发生命周期，一种关注每个阶段安全性的系统开发模型。

**SDLC (Telecommunications)** (Synchronous Data Link Control)：同步数据链路控制，一种使用轮询传输数据的同步第 2 层 WAN 协议。

**SDN** (Software Defined Networking)：软件定义网络，将路由器的控制平面与数据（转发）平面分离。路由决策在远程做出，而非在每个单独的路由器上。

**SDSec** (Software-defined security)：软件定义安全，对 SIEM、防火墙、IDS 和 IPS 等安全设备进行自动化编排，类似于软件定义网络。

**SDSL** (Symmetric Digital Subscriber Line)：对称数字用户线，上传和下载速度匹配的 DSL。

**SDWAN** (Software-Defined Wide Area Networking)：软件定义广域网，将软件定义网络的概念扩展到云端。

**Search warrant** (搜查令)：允许合法搜查的法院命令。

**Secondary evidence** (次级证据/间接证据)：由原始文件副本和口头描述组成的证据。

**Secure defaults** (安全默认值/默认安全)：也称为“默认安全”，操作系统和应用程序以安全状态部署。历史上操作系统以（有时）高度不安全的状态部署，安装后需要加固。

**Secure Hash Algorithm 1** (安全哈希算法 1)：参见 **SHA-1**。

**Secure Hash Algorithm 2** (安全哈希算法 2)：参见 **SHA-2**。

**Secure Real-time Transport Protocol** (安全实时传输协议)：参见 **SRTP**。

**Secure Shell** (安全外壳协议)：参见 **SSH**。

**Secure Sockets Layer** (安全套接层)：参见 **SSL**。

**Secure/Multipurpose Internet Mail Extensions** (安全/多用途互联网邮件扩展)：参见 **S/MIME**。

**Security Assertion Markup Language** (安全断言标记语言)：参见 **SAML**。

**Security assessments** (安全评估)：评估访问控制有效性的整体方法。可能将其他测试作为子集，包括渗透测试和漏洞扫描。

**Security audit** (安全审计)：针对已发布标准的测试。

**Security champions** (安全倡导者/安全冠军)：非信息安全团队（包括运维、工程、软件开发等）的成员，充当与信息安全团队的联络人。

**Security domain** (安全域)：主体被允许访问的对象列表。

**Security Orchestration, Automation, and Response** (安全编排、自动化和响应)：参见 **SOAR**。

**Security Parameter Index** (安全参数索引)：参见 **SPI**。

**Security Safeguards Principle** (安全保障原则)：OECD 隐私指南原则，规定个人数据应受到合理保护，防止未经授权的使用、披露或篡改。

**Segment** (段)：第 4 层 PDU。

**Semantic integrity** (语义完整性)：要求每个值与属性数据类型一致。

**Separation of Duties** (职责分离)：参见 **SoD**。

**Serial Line Internet Protocol** (串行线路互联网协议)：参见 **SLIP**。

**Serverless** (无服务器/Serverless)：也称为 Functions as a Service (FaaS)，代码发送到另一台服务器并返回结果，通常通过 JSON。

**Server-side attack** (服务端攻击)：直接从攻击者发起针对监听服务的攻击。也称为服务端攻击。

**Service Level Agreement** (服务级别协议)：参见 **SLA**。

**Service Level Requirement** (服务级别要求)：描述第三方提供的服务。这些要求用于设计 SLA。

**Service Set Identifier** (服务集标识符)：参见 **SSID**。

**Servicemark** (服务商标)：允许创建区分服务来源的品牌的知识产权保护。

**Session hijacking** (会话劫持)：现有网络会话的妥协/接管。

**Session Initiation Protocol** (会话初始协议)：参见 **SIP**。

**Session layer** (会话层)：OSI 模型的第 5 层，管理会话，为连接提供维护。

**SHA-1** (Secure Hash Algorithm 1)：安全哈希算法 1，一种生成 160 位消息摘要的哈希函数。

**SHA-2** (Secure Hash Algorithm 2)：安全哈希算法 2，一种哈希函数，包含 SHA-224、SHA-256、SHA-384 和 SHA-512，以各自生成的消息摘要长度命名。

**SHA-3** (Secure Hash Algorithm 3)：安全哈希算法 3，一种哈希函数，包含 SHA-224、SHA-256、SHA-384 和 SHA-512（与 SHA-2 提供的模式相同），并增加了两种额外模式：SHAKE128 和 SHAKE256。

**Shadow database** (影子数据库)：类似于复制数据库，但有一个关键区别：影子数据库镜像主数据库的所有更改，但客户端不访问影子数据库。

**Shared responsibility** (共担责任/共享责任模型)：划分客户与提供商在物理安全、网络、服务器、操作系统和应用程序方面责任的云模型。

**Shareware** (共享软件)：功能完整的专有软件，最初可免费使用。如果用户在特定时间后继续使用，共享软件许可证通常要求付费。

**Shielded Twisted Pair** (屏蔽双绞线)：参见 **STP**。

**Shoulder surfing** (肩窥/偷窥)：攻击者观察凭证（如按键组合）的物理攻击。

**Shredding** (粉碎/擦除)：参见 **Wiping**。

**Side-channel attack** (侧信道攻击)：利用物理数据破解密码系统的密码攻击，例如监控加密或解密时使用的 CPU 周期或功耗。

**Simple integrity axiom** (简单完整性公理)：Biba 模型属性，规定“不向下读取”。

**Simple Mail Transfer Protocol** (简单邮件传输协议)：参见 **SMTP**。

**Simple Network Management Protocol** (简单网络管理协议)：参见 **SNMP**。

**Simple Security Property** (简单安全属性)：Bell-LaPadula 模型属性，规定“不向上读取” (NRU)。

**Simplex** (单工/单向通信)：单向通信，如调至音乐频道的汽车收音机。
