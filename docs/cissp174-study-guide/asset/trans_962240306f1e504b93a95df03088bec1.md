
*缓存内存* 是系统中速度最快的内存，用于跟上 CPU 获取和执行指令的速度。CPU 最常使用的数据存储在缓存内存中。CPU 缓存中速度最快的部分是 *寄存器* 文件，它包含多个寄存器。寄存器是 CPU 用来存储指令和数据的小型存储位置。

接下来速度最快的缓存内存形式是 1 级缓存，位于 CPU 本身上。最后，2 级缓存连接在 CPU 外部（但紧邻 CPU）。*SRAM*（静态随机存取存储器）用于缓存内存。

> **注意**
>
> 离 CPU 最近的内存（缓存内存）是计算机中速度最快、价格最昂贵的内存。随着离 CPU 越来越远，从 SRAM 到 *DRAM*，再到磁盘、磁带等，内存速度变慢，价格也变低。

## RAM 和 ROM

RAM 是易失性内存，用于存放当前正在运行程序的指令和数据。断电后会丢失数据完整性。RAM 内存模块安装在计算机主板上的插槽中。RAM 也越来越多地直接嵌入到计算机主板中，使得升级变得困难，甚至不可能。

ROM（只读存储器）是非易失性的：存储在 ROM 中的数据在断电后仍保持完整性。计算机 *基本输入输出系统* (BIOS) *固件* 存储在 ROM 中。虽然 ROM 是“只读”的，但某些类型的 ROM 可以通过刷写进行写入，我们将在“闪存”部分很快看到。

> **注意**
>
> RAM 的易失性是正在进行的研究课题。历史上，人们认为 DRAM 断电后会丢失数据完整性。“冷启动”攻击表明 RAM 具有残留性：断电后可能保持完整性几秒甚至几分钟。这具有安全隐患：加密密钥通常以明文形式存在于 RAM 中，可能通过从安装在 DVD 或 USB 密钥上的小型操作系统“冷启动”计算机，然后快速转储内存内容来恢复。关于冷启动攻击影响的视频“Lest We Remember: Cold Boot Attacks on Encryption Keys”可在 <https://citp.princeton.edu/our-work/memory/> 查看。
>
> 请记住，考试有时会简化复杂问题。对于考试，只需记住 RAM 是易失性的（尽管不像我们曾经认为的那样易失性）。

## DRAM 和 SRAM

静态随机存取存储器 (SRAM) 是一种速度快、价格昂贵的内存，它使用称为“触发器”的小锁存器来存储位。动态随机存取存储器 (DRAM) 将位存储在小电容器中（像小电池一样），比 SRAM 慢且便宜。DRAM 使用的电容器会泄漏电荷，必须不断刷新以保持完整性，通常每隔几毫秒到几百毫秒刷新一次，具体取决于 DRAM 的类型。刷新会将位读回并写回内存。SRAM 不需要刷新，只要供电就能保持完整性。

## 固件

固件存储不经常更改的小型程序，例如计算机的 BIOS（见下文讨论）或路由器的操作系统和已保存配置。各种类型的 ROM 芯片可用于存储固件，包括 *PROM*、*EPROM* 和 *EEPROM*。

PROM（可编程只读存储器）只能写入一次，通常在工厂完成。EPROM（可擦除可编程只读存储器）和 EEPROM（电可擦除可编程只读存储器）可以“刷写”，即多次擦除和写入。“刷写”一词源于 EPROM 的使用：在芯片上的一个小窗口照射紫外线可擦除 EPROM。该窗口通常用箔纸覆盖，以防止因光照导致意外擦除。EEPROM 是现代类型的 ROM，可通过刷写程序进行电擦除。

可编程逻辑器件 (PLD) 是一种现场可编程器件，意味着它在出厂后进行编程。EPROM、EEPROM 和闪存都是 PLD 的示例。

### 闪存

*闪存*（如 USB 闪存盘）是一种特定类型的 EEPROM，用于小型便携式存储驱动器。区别在于 EEPROM 的任何字节都可写入，而闪存驱动器按（较大的）扇区写入。这使得闪存比 EEPROM 更快，但仍比 RAM 慢。

> **注意**
>
> 固件基于芯片，不同于磁盘。“闪存驱动器”一词可能会让一些人认为闪存驱动器是“磁盘驱动器”。它们在物理上截然不同，且具有不同的残留特性。
>
> 简单的磁场无法擦除闪存。用于磁性驱动器的安全销毁方法（如消磁，我们稍后将讨论）对闪存驱动器无效。

## 固态硬盘 (SSD)

固态硬盘 (SSD) 是闪存 (EEPROM) 和 DRAM 的组合。消磁对 SSD 无效。此外，虽然物理磁盘具有物理块（“块 1”位于磁盘的特定物理位置），但 SSD 上的块是逻辑的，并映射到物理块。而且，SSD 不会覆盖包含数据的块：设备会将数据写入未使用的块，并将之前的块标记为未分配。

一个称为垃圾回收的过程稍后会处理这些旧块：“未使用且未擦除的块被移开并在后台擦除。这称为‘垃圾回收’过程。在后台工作时，垃圾回收系统地识别包含不需要数据的存储单元，并在非高峰时段清除不需要数据的块，以在正常操作期间保持最佳写入速度” [\[6\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0035)。

TRIM 命令可改善垃圾回收。“TRIM 是 ATA 数据集管理命令的一个属性。TRIM 功能通过允许驱动器在后台进行垃圾回收，提高了兼容性、耐用性和性能。此回收消除数据块，例如已删除的文件” [\[7\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0040)。虽然 TRIM 命令提高了性能，但不能可靠地销毁数据。

“逐扇区覆盖”在 SSD 与磁性驱动器上的表现截然不同，且不能可靠地销毁所有数据。此外，电子粉碎文件（在删除前覆盖文件数据，我们稍后将讨论）也无效。

加利福尼亚大学圣地亚哥分校计算机科学与工程系进行的测试发现：“总体而言，覆写的结果很差：虽然覆写在某些情况下对各种驱动器似乎有效，但显然并非普遍可靠。对于花费精力对设备进行清理的个人或组织来说，似乎不太可能对这种性能水平感到满意” [\[8\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0045)。

未物理损坏的 SSD 驱动器上的数据可通过 ATA 安全擦除安全移除。SanDisk 提供了以下细节：“当在 SanDisk SSD 上执行相关的安全擦除命令时，物理地址空间中的所有块，无论它们当前是否分配给逻辑空间或之前曾分配过，都会被完全擦除（‘逻辑到物理映射表’也会被擦除）。此外，会生成一个新的加密密钥并丢弃旧密钥。
