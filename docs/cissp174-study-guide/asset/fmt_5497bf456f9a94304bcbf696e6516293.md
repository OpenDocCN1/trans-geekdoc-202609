
# 术语表

## S

**Simulation test**  
灾难恢复测试，要求团队成员执行恢复流程。

**Single Loss Expectancy (SLE)**  
单次损失预期，单次损失的成本。

**Single Sign-On (SSO)**  
单点登录，允许主体进行一次身份验证，然后访问多个系统。

**SIP (Session Initiation Protocol)**  
会话发起协议，一种 VoIP 信令协议。

**SLA (Service Level Agreement)**  
服务级别协议，有助于保证可用性的合同协议。

**Slack space**  
磁盘上文件结束标记与簇末尾之间的空间。

**SLE**  
参见 **Single Loss Expectancy**。

**SLIP (Serial Line Internet Protocol)**  
串行线路互联网协议，一种第 2 层协议，通过异步连接（如串行线路和调制解调器）提供 IP 连接。

**Slow hash algorithms**  
计算成本高的哈希算法（如 `bcrypt` 和 `scrypt`），用于密码哈希。

**Smart card**  
包含集成电路的物理访问控制设备。也称为集成电路卡（ICC）。

**SMDS (Switched Multimegabit Data Service)**  
交换兆比特数据服务，一种类似 ATM 的较早 WAN 技术。

**SMTP (Simple Mail Transfer Protocol)**  
简单邮件传输协议，一种存储转发协议，用于在服务器之间交换电子邮件。

**Smurf attack**  
使用 ICMP 洪水和定向广播地址的攻击。

**Sniffing**  
针对网络流量的机密性攻击。

**SNMP (Simple Network Management Protocol)**  
简单网络管理协议，用于监控网络设备。

**SOAP**  
最初代表 Simple Object Access Protocol，现在简称为 "SOAP"。用于实现 Web 服务。

**SOAR (Security Orchestration, Automation, and Response)**  
安全编排、自动化和响应，一种用于集中管理安全运营的敏捷方法论。

**Social engineering**  
利用人性绕过安全控制。

**Socket**  
一个节点上 IP 地址与 TCP 或 UDP 端口的组合。

**Socket pair**  
描述两个节点之间的唯一连接：源端口、源 IP、目的端口和目的 IP。

**SOCKS**  
流行的电路级代理。

**SoD (Separation of Duties)**  
将敏感交易分配给多个主体。

**Software as a Service (SaaS)**  
软件即服务。

**Software Configuration Management (SCM)**  
软件配置管理。

**Software Defined Networking (SDN)**  
软件定义网络。

**Software-Defined Wide Area Networking (SDWAN)**  
软件定义广域网。

**Software-defined security (SDSec)**  
软件定义安全。

**Software escrow**  
由中立第三方持有的源代码。

**Software piracy**  
未经授权复制受版权保护的软件。

**Solid State Drive (SSD)**  
固态硬盘，闪存（EEPROM）和 DRAM 的组合。

**SONET (Synchronous Optical Networking)**  
同步光网络，通过光纤电缆承载多个 T 载波电路。

**Source code**  
用文本编写的计算机编程语言指令，在 CPU 执行前必须被翻译成机器码。

**Southbridge**  
连接输入/输出（I/O）设备，如磁盘、键盘、鼠标、光驱和 USB 端口。

**SOX (Sarbanes-Oxley Act of 2002)**  
2002 年萨班斯-奥克斯利法案，为上市公司创建了监管合规授权。

**SPAN port (Switched Port Analyzer)**  
交换端口分析器，接收从其他交换端口转发来的流量。

**Spear phishing**  
针对少量高价值受害者的定向网络钓鱼攻击。

**SPI (Security Parameter Index)**  
安全参数索引，用于标识单工 IPsec 安全关联。

**Spiral Model**  
旨在控制风险的软件开发模型。

**Split horizon**  
距离矢量路由协议的保护机制，不会通过学习到路由的接口发送路由更新。

**Spoofing**  
伪装成另一个端点。

**Spring-bolt lock**  
一种“弹入”并从门框弹出的锁定机制。

**SQL (Structured Query Language)**  
结构化查询语言，最流行的数据库查询语言。

**SRAM (Static Random Access Memory)**  
静态随机存取存储器，昂贵且快速的内存，使用称为“触发器”的小锁存器来存储位。

**SRTP (Secure Real-time Transport Protocol)**  
安全实时传输协议，用于提供安全的 VoIP。

**SSD (Solid State Drive)**  
固态硬盘，闪存（EEPROM）和 DRAM 的组合。

**SSH (Secure Shell)**  
安全外壳，Telnet、FTP 和 UNIX “R”命令的安全替代品。

**SSID (Service Set Identifier)**  
服务集标识符，充当无线网络名称。

**SSL (Secure Sockets Layer)**  
安全套接字层，对网络流量（如 Web 流量）进行身份验证并提供机密性。

**SSO (Single Sign-On)**  
单点登录，允许主体进行一次身份验证，然后访问多个系统。

**Standard**  
描述技术的具体用途，通常应用于硬件和软件，属于管理控制。

**Star**  
物理网络拓扑，将每个节点连接到中心设备（如集线器或交换机）。

**Stateful firewall**  
具有状态表的防火墙，允许防火墙将当前数据包与之前的数据包进行比较。

**Static password**  
可重复使用的密码，可能过期也可能不过期。

**Static Random Access Memory**  
参见 **SRAM**。

**Static route**  
固定路由条目。

**Static Application Security Testing (SAST)**  
静态应用安全测试。

**Statutory damages**  
法律规定的损害赔偿。

**Stealth virus**  
隐藏自身以躲避操作系统和其他防护软件（如防病毒软件）的病毒。

**Steganography**  
隐蔽通信的科学。

**Storage Area Network (SAN)**  
存储区域网络。

**Storage channel**  
使用共享存储（如临时目录）允许两个主体相互发信号的隐蔽信道。

**STP (Shielded Twisted Pair)**  
屏蔽双绞线，包含每对双绞线周围额外金属屏蔽层的网络布线。

**Strike plate**  
门框上的金属板，带有供插销或弹簧锁插入的槽。

**Striping**  
将数据写入分散到多个磁盘以实现性能增益，某些 RAID 级别使用此技术。

**Strong authentication**  
要求用户提供不止一个认证因子。也称为双因子认证。

**Strong tranquility property**  
Bell-LaPadula 模型的一个属性，规定安全标签在系统运行期间不会改变。

**Structured Query Language**  
参见 **SQL**。

**Subject**  
信息系统上访问或更改数据的主动实体。

**Substitution**  
用一个字符替换另一个字符的加密方法。

**Supply Chain Risk Management (SCRM)**  
供应链风险管理。

**SVC (Switched Virtual Circuit)**  
交换虚拟电路，按需建立的电路。

**Swapping**  
使用虚拟内存将主内存（RAM）的内容复制到辅助内存或从辅助内存复制回主内存。

**Switch**  
第 2 层设备，在一个 LAN 上传输流量。

**Switched Multimegabit Data Service**  
参见 **SMDS**。

**Symmetric Digital Subscriber Line (SDSL)**  
对称数字用户线路。

**Symmetric Encryption**  
使用一个密钥进行加密和解密的加密方式。

**Synthetic transactions**  
也称为综合监控，涉及构建脚本或工具来模拟应用程序中正常执行的活动。

**System owner**  
负责存放数据的实际计算机的管理者。这包括硬件和软件配置，包括更新和补丁。

**SYN**  
TCP 标志，同步连接。

**SYN Flood**  
填满系统半开连接表的资源耗尽型 DoS 攻击。

**Synchronous Data Link Control (SDLC)**  
同步数据链路控制。

**Synchronous Dynamic Token**  
使用时间或计数器将显示的令牌代码与认证服务器预期的代码同步。

**Synchronous Optical Networking**  
参见 **SONET**。

**System call**  
允许进程与内核通信，并提供 CPU 环之间的窗口。

**System unit**  
计算机机箱，包含所有内部电子计算机组件，包括主板、内部磁盘驱动器和电源。

**Systems Development Life Cycle (SDLC)**  
系统开发生命周期。

**Synthetic Transactions**  
也称为综合监控，涉及构建脚本或工具来模拟应用程序中正常执行的活动。

## T

**T1**  
专用 1.544 Mbps 电路，承载 24 个 64-bit DS0 信道。

**T3**  
28 个捆绑的 T1。

**Table**  
关系数据库中一组相关的数据。

**Tabletop exercise**  
一种更彻底的演练式灾难恢复测试，负责恢复的团队成员将在考虑模拟灾难场景的情况下讨论建议的恢复程序。

**TACACS (Terminal Access Controller Access Control System)**  
终端接入控制器访问控制系统，一种常用于网络设备的 SSO 方法。
