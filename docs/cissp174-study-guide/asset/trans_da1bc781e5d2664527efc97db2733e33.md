

# 数据丢失防护与内存残留

## 数据丢失防护

随着大规模、高关注度的数据泄露事件持续不断，对旨在解决数据丢失问题的解决方案的需求日益增长。数据丢失防护（DLP）是一类解决方案，其特定任务是尝试检测，或最好是防止数据以未授权的方式离开组织。DLP 的方法差异很大。一种常见方法采用面向网络的工具，尝试检测和/或防止敏感数据以明文形式被泄露。这种方法很难解决通过加密通道泄露数据的可能性。通常，应对加密泄露的潜在风险需要端点解决方案，以便在加密前提供可见性。

### 数字版权管理

数字版权管理（DRM）旨在限制受版权保护材料和其他形式知识产权的使用。DRM 技术包括加密（通过数字签名提供机密性和不可抵赖性）、水印、产品密钥（或加密狗）以解锁软件、区域锁定等。

水印可以是可见的，也可以是不可见的。[图 3.1](#Ch003_81-105_B9780443187346000118.xhtml#f0010) 显示了《CISSP® 学习指南》早期电子版中的一个可见水印。不可见水印通常使用隐写术来隐藏数据。水印的一个目标是识别被不当共享的知识产品的购买者。请注意，我们将在第 4 章（第 3 领域：安全架构与工程）中讨论加密、数字签名、隐写术（及更多内容）。

DRM 备受争议，因为它常被用来限制合法所有者的权利。例如包括：持续在线 DRM（也称为持久在线激活：运行需要互联网连接的软件）、禁止打印或复制粘贴的电子书、基于 IP 的地理定位（阻止来自世界特定地区的在线服务访问）、软件复制保护（阻止购买者备份自己的软件）、DVD 区域锁定（阻止在世界某一地区购买的 DVD 在其他地区播放）等。

### 云访问安全代理

Gartner 创造了云访问安全代理（CASB）这一术语，将其定义为：“部署在本地或基于云的安全策略执行点，位于云服务消费者和云服务提供商之间，在访问基于云的资源时结合并注入企业安全策略。CASB 整合了多种类型的安全策略执行。示例安全策略包括身份验证、单点登录、授权、凭据映射、设备画像、加密、令牌化、日志记录、告警、恶意软件检测/防护等” [\[3\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0020)。

Forcepoint 描述了 CASB 的支柱：

#### 可见性

*   IT 部门未知的云应用会导致信息资产处于失控状态，且位于企业治理、风险和合规流程之外。企业需要了解云应用账户的使用情况，包括谁在使用哪些云应用、他们的部门、位置以及使用的设备。

#### 数据安全

*   数据丢失防护（DLP）工具旨在阻止因未授权共享导致的企业数据泄露，但云使得与错误的人共享数据变得前所未有的容易。如果组织使用云文件存储，传统的 DLP 产品将无法知晓什么数据被外部分享以及是谁在分享。

#### 威胁防护

*   很难防范授权用户的恶意意图或疏忽。为了检测可疑的内部人员行为，组织需要全面了解其正常使用模式。同样，前员工构成重大风险，因为他们可能已从组织目录中禁用，但仍可访问包含业务关键信息的云应用。PWC 发现，归因于前员工的安全事件从 2013 年的 27% 上升到 2014 年的 30%。

#### 合规性

*   随着数据迁移到云端，组织将希望确保符合确保数据隐私和安全的区域法规。CASB 可以帮助确保符合 SOX 和 HIPAA 等法规，并帮助根据 PCI DSS、NIST、CJIS、MAS 和 ISO 27001 等监管要求对安全配置进行基准测试。

#### BYOD、影子 IT 和云使用量增加

*   自带设备（BYOD）策略、SaaS 和云应用日益普及、影子 IT 的兴起等现象，使得将云应用访问限制在一组已定义的端点上变得困难。托管和非托管设备通常需要不同的策略来有效保护企业数据。CASB 有助于执行细粒度访问策略，以及识别和分类组织中的云应用 [\[4\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0025)。

### 数据收集限制

组织应仅收集所需的最少量敏感信息。

经济合作与发展组织（OECD，见第 2 章，第 1 领域：安全与风险管理）的收集限制原则探讨了数据限制：“应对个人数据的收集加以限制，且任何此类数据的获取应通过合法和公平的方式，并在适当情况下，经数据主体知情或同意” [\[5\]](#Ch003_81-105_B9780443187346000118.xhtml#bb0030)。收集敏感数据应有明确记录的业务需求，且仅在没有其他替代方案时才收集敏感数据。

## 内存与残留

考试最近增加了及时的主题，例如固态硬盘（SSD）的残留特性，稍后将讨论。我们将首先讨论计算机内存本身，然后是易失性和非易失性内存的残留特性。请注意，内存保护和 CPU 设计等相关概念见第 4 章（第 3 领域：安全架构与工程）。

### 数据残留

在讨论介质清理和数据销毁时，理解数据残留这一术语非常重要。数据残留是指数据在非侵入式删除手段之后仍然存在。虽然数据残留有时专门指残留在磁性存储介质上的数据，但残留问题不仅限于磁性存储介质。安全专业人员必须了解各类内存和存储的残留特性，并理解使数据不可恢复的步骤。

### 内存

内存是一系列代表位的开关：0（关）和 1（开）。内存可以是基于芯片的、基于磁盘的，或使用磁带等其他介质。RAM 是随机存取存储器：“随机”意味着 CPU 可以随机访问（跳转到）内存中的任何位置。顺序存储器（如磁带）必须从偏移量零开始顺序读取内存，直到所需的内存部分。易失性内存（如 RAM）在断电后失去完整性；非易失性内存（如 `ROM`、磁盘或磁带）在无电源的情况下保持完整性。

*真实*（或主）内存，如 RAM，可直接由 CPU 访问，用于保存当前正在执行的进程的指令和数据。辅助内存，如基于磁盘的内存，不可直接访问。

#### 高速缓存内存
