In 1970, a “Monty Python's Flying Circus” program was broadcast on one of a Britain TV. Guido van Rossum is from the Netherlands. He was a fan of this TV show. He is an excellent software developer. In 1991, he developed a computer language. He was thinking of putting this name into the computer language. Then he remembered that TV show. The TV program took the name of Python and named him Python for his computer language. This is the reason for this Python language.
