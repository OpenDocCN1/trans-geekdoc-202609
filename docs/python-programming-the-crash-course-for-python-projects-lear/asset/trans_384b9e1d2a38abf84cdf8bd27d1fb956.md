# 第3章：为什么叫Python？

1970年，英国电视台播出了“Monty Python's Flying Circus”节目。Guido van Rossum来自荷兰。他是这档电视节目的爱好者。他是一名出色的软件开发人员。1991年，他开发了一门编程语言。他当时考虑将这个名字用于这门编程语言。然后他想起了这档电视节目。这档电视节目取名Python，并以此命名他的编程语言。这就是Python语言的由来。
