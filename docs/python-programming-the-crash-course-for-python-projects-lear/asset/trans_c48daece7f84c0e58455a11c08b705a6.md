Chapter 15: Python 程序基本原理 程序的基本信息应写在 Python 程序中。让我们详细了解它们。 •   变量 对于所有计算机语言，变量都非常重要。要学习一门计算机语言，首先需要了解变量。变量是一个容器。我们给出的值存储在这个变量中。变量可以是整数、字符串或浮点数。在 C、C++、Java 中，你需要输入数据类型。但在 Python 中无需输入数据类型。变量的第一个字符必须以字母开头。数字或特殊字符不能是第一个字符。Python 是大小写敏感语言。如果你使用小写字母然后使用大写字母，就会出现语法错误。在 Python 中无需输入数据类型来声明变量。 ![](rsrc100.jpg)

•   关键字 关键字是 Python 的重要组成部分。Python 总共有 33 个关键字。关键字是 Python 语言的保留字。这些关键字不能用作变量名、函数名或任何标识符。下面给出 Python 关键字列表。 ![](rsrc10D.jpg)

•   数字 数字是 Python 中最重要的部分之一。数字分为三类：整数、浮点数和复数。Python 可以作为计算器使用。它可以执行基本计算，如加法、减法、乘法、除法。更复杂的计算也可以解决。 ![](rsrc10S.jpg)![](rsrc10V.jpg)

•   字符串 字符串是一个词。它由一个字符或多个字符组成。不包含数字或特殊字符。你可以以两种方式声明字符串：单引号和双引号。`a = 'python'`（单引号）`b = "python"`（双引号） ![](rsrc117.jpg)

•   类型转换 类型转换很重要。类型转换是将一种类型转换为另一种类型。你可以将整数转换为字符串。同样，字符串也可以转换为整数。你也可以将整数转换为浮点数，将浮点数转换为整数。 ![](rsrc11H.jpg)
