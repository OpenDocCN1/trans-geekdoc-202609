# SUMMARY

+   HTTP (Hypertext Transfer Protocol) is the set of rules for transferring files (text, graphic images, sound, video, and other multimedia files) on the World Wide Web. As soon as a Web user opens their Web browser, the user is indirectly making use of HTTP.

+   The input field in our HTML form above is named "fileToUpload"

+   We have already explained about form validation using JavaScript and jQuery, but this time we will show you how to validate your form using PHP.

+   So far we only worked with optional fields - in all previous examples the scripts worked fine if you didn't enter any data.

+   HTTP is a stateless protocol, which means that once a web server completes a client's request for a web page, the connection between the two goes away.

+   PHP provides many ways to access cookies. Simplest way is to use either $_COOKIE or $_HTTP_COOKIE_VARS variables.

+   An alternative way to make data accessible across the various pages of an entire website is to use a PHP Session.
