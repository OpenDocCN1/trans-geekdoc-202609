# 4.2.2 Complex (curly) Syntax

This isn't called complex because the syntax is complex, but because it allows for the use of complex expressions. Any scalar variable, array element or object property with a string representation can be included via this syntax. Simply write the expression the same way as it would appear outside the string, and then wrap it in {}. Since {cannot be escaped, this syntax will only be recognized when the $ immediately follows the {. Use to get a literal $[. Some examples to make it clear:

```php
<?php
// Show all errors
error_reporting(E_ALL);
```

```php
$great = 'fantastic';
```

```php
// Won't work, outputs: This is { fantastic}
echo "This is {$great}";
```

```php
// Works, outputs: This is fantastic
echo "This is {$great}";
```

```php
// Works
echo "This square is {$square->width}00 centimeters broad."
```

```php
// Works, quoted keys only work using the curly brace syntax
echo "This works: {$arr['key']}";
```

```php
// Works
echo "This works: {\$arr[4][3]}";
```

```php
// This is wrong for the same reason as $foo[bar] is wrong outside string.
// In other words, it will still work, but only because PHP first looks for a
// constant named foo; is an error of level E_NOTICE (undefined constant) will be // thrown.
echo "This is wrong: {\$arr[foo][3]}";
```

Works When using multi-dimensional arrays, always use braces around arrays when inside strings

# PHP: String

It is also possible to access class properties using variables within strings using this syntax.

```php
<?php
class foo {
    var $bar = 'I am bar.';
}

$foo = new foo();
$bar = 'bar';
$baz = array('foo', 'bar', 'baz', 'quux');
echo "{$foo->\$bar}\n";
echo "{$foo->\$baz[1]}\n";
?>
```

The above example will output:
I am bar.
I am bar.

Using single braces (()) will not work for accessing return values of functions or methods or values of static class variables.

# 4.2.3 String Access and Modification

Characters within strings may be accessed and modified by specifying the zero-based offset of the desired character after the string using square brackets, as in $str[4]. Think of a string as an array of characters for this purpose. The functions substr() and substr_replace() can be used when you want to extract or replace more than 1 character.

Integer is a whole number (not a fraction) that can have decimal places. Therefore the numbers 10, 0, -25, and 5.14 are all integers. Integer is a commonly used data type in computer programming. As of PHP 7.1.0, negative offsets are also supported. These specify the offset from the end of the string. Formerly, negative offsets emitted E_NOTICE for reading (yielding an empty string) and E_WARNING for writing (leaving the string untouched). Writing an out of range offset pads the string with spaces. Non-integer types are converted to integer. Illegal offset emits E_NOTICE. Only the first character of an assigned string is used. As of PHP 7.1.0, assigning a string throws a fatal error. Internally, PHP strings are byte arrays. As a result, accessing or modifying a string using array brackets is not multi-byte safe, and should only be done with strings that are in a single-byte encoding as ISO-8859-1.

# 4.2.4 Converting to String

A value can be converted to a string using the (string) cast or the strval() function. String conversion is automatically done in the scope of an expression where a string is needed. This happens when using the echo or print functions, or when a variable is compared to a string. The strings on Types and Type Juggling will make the following clearer.

A boolean TRUE value is converted to the string "1". Boolean FALSE is converted to "" (the empty string). This allows conversion back and forth between boolean and string values.

An integer or float is converted to a string representing the number textually (including the exponent for floats). Floating point numbers can be converted using exponential notation (4.1E+6).

The decimal point character is defined in the script's locale (category LC_NUMERIC).

Arrays are always converted to the string "Array"; because of this, echo and print cannot show the contents of an array. To view a single element, use a construction such as echo `$arr['foo']`.

In order to convert objects to string method __toString must be used.

Resources are always converted to strings with the structure "Resource #1", where 1 is the resource number assigned to the resource by PHP at runtime. While the exact structure of this string should not be relied on and is subject to change, it will always be unique for a given resource within the lifetime of a script being executed (ie a Web request or CLI process) and not be reused. To get a resource's type, use the `get_resource_type()` function.
