# Basic Computer Coding: PHP

Heredoc text behaves just like a double-quoted string, without the double quotes. This means that in a heredoc do not need to be escaped, but the escape codes listed above can still be used. Variables are expanded, but the same care must be taken when expressing complex variables inside a heredoc as strings.

Example of string
