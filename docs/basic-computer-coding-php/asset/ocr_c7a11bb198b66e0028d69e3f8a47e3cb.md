Notice that we used a special $this variable to access a property of an object. PHP uses the $this variable to refer to the current object. To access a property you use the arrow (->) operator as follows:

```
object->property
```

+   - The deposit(amount) method increases the total balance of the account.

+   - The withdraw() method checks the available balance. If the total balance is less than the amount to be withdrew, it issues an error message, otherwise it decreases the total balance.
