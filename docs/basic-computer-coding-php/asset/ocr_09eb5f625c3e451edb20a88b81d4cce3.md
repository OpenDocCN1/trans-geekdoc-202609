# Basic Computer Coding: PHP

# SUMMARY

+   - Object-oriented programming (OOP) is way of organizing your code to be more efficient, and it takes advantage of some really nice features in modern versions of PHP.

+   - The basic building blocks of object-oriented programming are classes and objects. Understanding object-oriented object and class and the differences between object and class is very important before we can dive into object-oriented programming approach.

+   - In object-oriented terminology, characteristics of an object are called properties.

+   - Behaviors of the object or class are called methods. Similar to the class properties, the methods can have three different visibility levels: private, protected, and public.

+   - To call a method of an object, you use the (->) operator followed by the method name and parentheses.

+   - Variables containing object references are just normal variables—they can be used in the same ways as other variables.

+   - To design your program or code library in an object-oriented fashion, you will need to define your own classes, using the class keyword. A class definition includes the class name and the properties and methods of the class.

+   - A method is a function defined inside a class. Although PHP imposes no special restrictions, most methods act only on data within the object in which the method resides.
