The third and most widespread technique for maintaining state is to use cookies. A cookie is a bit of information that the server can give to a client. On every subsequent request the client will give that information back to the server, identifying itself. Cookies are useful for retaining information through repeated visits by a browser, but they’re not without their own problems. The main problem is that most browsers allow users to disable cookies.
