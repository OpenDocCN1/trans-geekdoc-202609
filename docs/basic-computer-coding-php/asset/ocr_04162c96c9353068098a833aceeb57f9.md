# 4.2.5 String Conversion to Numbers

When a string is evaluated in a numeric context, the resulting value and type are determined as follows.

Numerical value is a quantitative value assigned to a letter of the alphabet. If the string does not contain any of the characters ',', 'e', or 'E' and the numeric value fits into integer type limits (defined by PHP_INT_MAX), the string will be evaluated as an integer. In all other cases it will be evaluated as afloat.

The value is given by the initial portion of the string. If the string starts with valid numeric data, this will be the value 0 (zero). Otherwise, valid numeric data is an optional sign, followed by one or more digits (optionally containing a decimal point), followed by an optional exponent. The exponent is 'e' or 'E' followed by one or more digits.

```
php
$foo = 1 + "10.5"; // $foo is float
(11.5)

$foo = 1 + "-1.3e3"; // $foo is float
(-1299)

$foo = 1 + "bob-1.3e3"; // $foo is integer
(1)
```
