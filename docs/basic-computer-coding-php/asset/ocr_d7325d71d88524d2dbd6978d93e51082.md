# 2.2.7 Logical Operators

Since the logical operators provides the way to make decisions based on the values of multiple variables. These operators are most useful while creating PHP applications. So, it is possible to direct the flow of program with logical operators. Logical operators are mostly used with control structures such as if condition, and for loop. Following are the list of logical operators in PHP and their uses.

+   - AND, && → And operators → True if both of the variables are True.
- OR, || → OR operators → True if at least one variable is True.
- NOT, ! → Not operator → True if the variable is not True.
- XOR → Exclusive OR → True if only one of the variable is True.
