# Basic Computer Coding: PHP

Now here are the steps to install Apache PHP5 on your Windows machine. If your PHP version is different then please take care accordingly.

+   Extract the binary archive using your unzip utility; C:\PHP is a common location.

+   Copy some .dll files from PHP directory to your systems directory (usually C:\Wint\System32). You need php5.dll for every case. You will also probably need to copy the file corresponding to your Web server module - C:\PHP\Sapi\php5isapi.dll. It's possible you will also need others from the dll folder - but start with the two mentioned above and add more if you need them.

+   Copy each php.ini-dist or php.ini-recommended (preferably the latter) to your Windows directory (C:\Wint or C:\Win40), and rename it php.ini. Open this file in a text editor (for example, Notepad). Edit this file get configuration directives; We highly recommend new users set reporting to E_ALL on their development machines at this point. For now, the most important thing is the doc_root directory under the Paths and Directories section.make sure this matches your IIS Inpub folder (folders) or wherever you plan to save out of.

+   Start and restart the WWW Service. Go to the Start menu ❖ Settings ❖ Control Panel ❖ Services. Scroll down the list to IIS Admin Service. Select it and click Stop. After it stops, select World Web Publishing Service and click Start. Stopping and restarting the service from within Internet Service Manager will not suffice. Since this is Windows, you may also wish to reboot.

+   Open a text editor. Type: <?php phpinfo(); ?>. Save this file in your server's document root as info.php.

+   Start any Web browser and browse the file.you must always use an HTTP request (http://www.testdomain.com/info.php or http://localhost/info.php or http://127.0.0.1/info.php) rather than a filename (/home/httpd/info.php) for the file to be parsed correctly

You should see a long table of information about your new PHP installation message Congratulations!
