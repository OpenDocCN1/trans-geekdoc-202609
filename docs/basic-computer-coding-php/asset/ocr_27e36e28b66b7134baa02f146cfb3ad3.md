# PHP: String

It is also possible to access class properties using variables within strings using this syntax.

```
<?php
class foo {
    var $bar = 'I am bar.';
}

foo = new foo();
$bar = 'bar';
$baz = array('foo', 'bar', 'baz', 'quux');
echo "{$foo->\$bar}\n";
echo "{$foo->\$baz[1]}\n";?>
```

The above example will output:
I am bar.
I am bar.

Using single curly braces (\)) will not work for accessing the return values of functions or methods or the values of static class variables.

# Remember

```
<?php
// Show all errors.
error_reporting(E_ALL);

class beers {
    const softdrink = 'rootbeer';
    public static \$ale = 'ipa';
}
```

Functions, method calls, static class variables, and class constants inside {$ work inside PHP 5. However, the value will be interpreted as the name of a variable in the scope in which the string is defined.

$rootbeer = 'A & W';
\$ipa = 'Alexander Keith\s';
