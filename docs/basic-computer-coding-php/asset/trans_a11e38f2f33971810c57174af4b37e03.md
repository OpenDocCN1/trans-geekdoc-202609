

## 3.2 CPU 使用率信息

我们将利用 `getrusage()` 函数。请记住，该函数在 Windows 平台上不可用。

```php
print_r(getrusage());
/* prints
Array
(
    [ru_oublock] => 0
    [ru_inblock] => 0
    [ru_msgsnd] => 2
    [ru_msgrcv] => 3
    [ru_maxrss] => 12692
    [ru_ixrss] => 764
    [ru_idrss] => 3864
    [ru_minflt] => 94
    [ru_majflt] => 0
    [ru_nsignals] => 1
    [ru_nvcsw] => 67
    [ru_nivcsw] => 4
    [ru_nswap] => 0
    [ru_utime.tv_use] => 0
    [ru_utime.tv_sec] => 0
    [ru_stime.tv_use] => 6269
    [ru_stime.tv_sec] => 0
)
/*
```

除非你已经有系统管理背景，否则这些看起来有些神秘。以下是每个值的解释（你不需要记忆这些内容）：

- ru_oublock: 块输出操作
- ru_inblock: 块输入操作
- ru_msgsnd: 发送的消息数
- ru_msgrcv: 接收的消息
- ru_maxrss: 最大驻留集大小
- ru_ixrss: 整数共享内存大小
- ru_idrss: 整数不共享数据大小
- ru_minflt: 页面回收
- ru_majflt: 页面缺页
- ru_nsigals: 接收的信号
- ru_nvcsw: 自愿性上下文切换
- ru_nivcsw: 非自愿上下文切换
- ru_nswap: 交换（swaps）
- ru_utime,tv_use: 用户时间（微秒）
- ru_utime.tv_sec: 用户时间（秒）
- ru_stime,tv_use: 使用的系统时间（微秒）
- ru_stime.tv_sec: 使用的系统时间（秒）

微秒是时间的一个 SI 单位，等于百万分之一（0.000001）或 $10^{-6}$ 秒。要查看脚本消耗了多少 CPU 功率，我们需要查看“用户时间”和“系统时间”值。默认情况下秒和微秒部分分开提供。你可以将微秒除以 100 万，并加到秒上，即可得到小数形式的总秒数。

让我们来看一个例子：

```php
// 睡眠 3 秒（非忙碌）
sleep(3);
```

```php
$data = getrusage();
echo "User time: ".
($data['ru_utime.tv_sec'] +
$data['ru_utime.tv_use'] / 1000000);
echo "System time: ".
($data['ru_stime.tv_sec'] +
$data['ru_stime.tv_use'] / 1000000);
```

```php
/* prints
User time: 0.011552
System time: 0
*/
```

尽管脚本运行了大约 3 秒，但 CPU 使用率非常低。因为在睡眠操作期间，脚本实际上并没有消耗 CPU 资源。许多其他任务可能会消耗实际时间，但可能不会 CPU 时间，例如等待磁盘操作。所以如你看到的，CPU 使用率和实际运行长度并不总是一致的。

这是另一个例子：
```php
// 循环 1000 万次（忙碌）
for(i=0;$i<10000000;$i++) {
}
```

```php
$data = getrusage();
echo "User time: ".
($data['ru_utime.tv_sec'] +
$data['ru_utime.tv_use'] / 1000000);
echo "System time: ".
($data['ru_stime.tv_sec'] +
$data['ru_stime.tv_use'] / 1000000);
```

```php
/* prints
User time: 1.4245992
System time: 0.004204
*/
```

这消耗了大约 1.4 秒的 CPU 时间，几乎所有都是用户时间，因为没有系统调用。

系统时间是 CPU 代替程序内核执行系统调用花费的时间。以下是该示例：

```php
$start = microtime(true);
// 持续调用 microtime 大约3秒
while(microtime(true) - $start < 3) {

}
```

```php
$data = getrusage();
echo "User time: " . 
($data['ru_utime.tv_sec'] + $data['ru_utime.tv_use'] / 1000000);
echo "System time: " . 
($data['ru_stime.tv_sec'] + $data['ru_stime.tv_use'] / 1000000);
```

```php
/* prints
User time: 1.08817
System time: 1.67535
*/
```

现在你看到，由于存在系统调用，系统时间占了很大比例。
