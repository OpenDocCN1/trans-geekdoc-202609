# 7.1.2 Form Validation

JavaScript is a high-level, interpreted programming language explained about form validation using JavaScript and jQuery, but this time we will show you how to validate your form using PHP.

Very first we have to create a form in html setting action "#" and method "POST" with some fields, when a user clicks on submit button all the data starts travel in URL but it will be hidden, as we set method = "POST".

Now, on page refresh, PHP code runs, all values fetches from URL into PHP variables and applying "preg_match( )" function on them.
