# ## 6.3 SETS

A set is an unordered collection of `unique` values. Sets may contain only immutable objects, like strings, `int`s, `float`s and tuples that contain only immutable elements. Though sets are iterable, they are not sequences and do not support indexing and slicing with square brackets, `[]`. Dictionaries also do not support slicing.
