# ## Conditional Expressions

Sometimes the suites in an if else statement assign different values to a variable, based on a condition, as in:

```
In [7]: grade = 87

In [8]: if grade >= 60:
    ...     result = 'Passed'
    ... else:
    ...     result = 'Failed'
    ...
```

We can then print or evaluate that variable:

```
In [9]: result
Out[9]: 'Passed'
```
