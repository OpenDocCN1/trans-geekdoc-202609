# ## Class Attributes FACES and SUITS

Each object of a class has its own copies of the class's data attributes. For example, each `Account` object has its own `name` and `balance`. Sometimes, an attribute should be shared by _all_ objects of a class. A **class attribute** (also called a **class variable**) represents _class-wide_ information. It belongs to the _class_, not to a specific object of that class. Class `Card` defines two class attributes (lines 5–7):

+   - `FACES` is a list of the card face names.

+   - `SUITS` is a list of the card suit names.
