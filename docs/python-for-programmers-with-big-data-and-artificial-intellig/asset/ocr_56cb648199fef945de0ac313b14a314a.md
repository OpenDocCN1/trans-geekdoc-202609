# Evaluating an Expression

The unit of work in a notebook is a cell in which you can enter code snippets. By default, a new notebook contains one cell—the rectangle in the `TestDrive.ipynb` notebook—but you can add more. To the cell's left, the notation `[ ]:` is where the Jupyter Notebook will display the cell's snippet number _after_ you execute the cell. Click in the cell, then type the expression

```
45 + 72
```

To execute the current cell's code, type `Ctrl + Enter` (or `control + Enter`). JupyterLab executes the code in IPython, then displays the results below the cell:

![](bbox=[0.141, 0.53, 0.923, 0.649])
