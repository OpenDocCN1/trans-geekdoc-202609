# # Text to Speech

The Text to Speech service, 2 which we'll also use in building this chapter's app, enables you to synthesize speech from text. You can use Speech Synthesis Markup Language (SSML) to embed instructions in the text for control over voice inflection, cadence, pitch and more. Currently, this service supports English (U.S. and U.K.), French, German, Italian, Spanish, Portuguese and Japanese.
