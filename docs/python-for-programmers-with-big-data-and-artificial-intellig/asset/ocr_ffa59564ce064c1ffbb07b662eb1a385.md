# Identifying the Elements in a Two-Dimensional List

The following diagram shows the names of list a's elements:

| | Column 0 | Column 1 | Column 2 | Column 3 |
|---|---|---|---|---|
| Row 0 | a[0][0] | a[0][1] | a[0][2] | a[0][3] |
| Row 1 | a[1][0] | a[1][1] | a[1][2] | a[1][3] |
| Row 2 | a[2][0] | a[2][1] | a[2][2] | a[2][3] |

Every element is identified by a name of the form a[i][j]—a is the list's name, and i and j are the indices that uniquely identify each element's row and column, respectively. The element names in row o all have 0 as the first index. The element names in column 3 all have 3 as the second index.
