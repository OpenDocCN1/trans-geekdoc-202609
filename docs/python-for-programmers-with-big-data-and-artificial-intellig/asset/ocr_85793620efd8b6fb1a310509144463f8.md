As we did in the classification and regression case studies, let's run multiple clustering algorithms and see how well they cluster the three species of Iris flowers. Here we'll attempt to cluster the Iris dataset's samples using the kmeans object we created earlier 5 and objects of scikit-learn's DBSCAN, MeanShift, SpectralClustering and AgglomerativeClustering estimators. Like KMeans, you specify the number of clusters in advance for the SpectralClustering and AgglomerativeClustering estimators:
