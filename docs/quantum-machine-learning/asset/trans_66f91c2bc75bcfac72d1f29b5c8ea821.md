
量子计算是计算机科学中一个新兴领域，它利用量子力学执行经典计算机无法完成的操作。量子计算机使用量子位，或 `qubits`，而不是传统位来维护和处理数据。量子物理学调节 `qubits` 的行为，使它们能够同时存在于多个状态，并与其他 `qubits` 相耦合。这意味着某些类型的问题，包括在经典计算机上具有挑战性或不可能执行的因式分解和优化问题，特别适合量子计算机。包括医疗护理、材料科学和数据加密在内的许多领域都将从量子计算中受益。量子计算机不以位的形式存储数据。相反，它使用 `qubits`。除了 1 或 0 之外，每个 `qubit` 都可以同时调谐为 1 和 0。

### 6.2.2 量子通信
在量子通信中，量子信息或量子位 (`qubits`) 借助量子纠缠和密码学从一个位置移动到另一个位置。为了建立防窃听和黑客攻击的安全通道，量子通信利用了量子力学的特殊特性，例如叠加和纠缠。量子隐形传态、量子网络和量子密钥分发是量子通信的几个重要应用。高性能计算和信息安全是两个可能因有效量子通信技术的发展而发生革命的领域。

[图6.2](#ch6.xhtml#fig6_2) 显示的利用量子物理概念传输和处理数据的通信网络被称为量子网络。量子网络有能力增强多个领域，包括分布式量子计算、安全通信和密码学。然而，由于量子态对外界干扰（退相干）的敏感性，以及在长距离上纠缠和操纵 `qubits` 的困难，创建和维护量子网络都面临着重大的技术挑战。在量子纠缠和不可克隆定理的帮助下，可能能够完成目前通信技术无法实现的工作。安全密钥分发 between 两个远程用户到目前为止主要被研究，现在已准备好投入使用，为量子通信创造了更大的潜力。例如，量子媒体传输使得分布式量子计算、极高密度编码和多方密码协议成为可能。

### 6.2.3 量子传感
量子传感一词指的是使用量子系统、量子现象或量子特征测量物理量的过程。它是一种尖端的传感器技术，能够识别旋转、温度、电磁场、运动和其他物理特征的变化。量子传感器通过利用原子和光的基本特性进行极其精确的观测，有可能改变导航、矿物开采和医学成像等领域。原子磁力计、光机械传感器以及金刚石中的氮空位 (`NV`) 中心只是量子传感应用的几个例子。

### 6.2.4 量子密码学
量子密码学是指研究将量子力学特征应用于密码操作，利用这些特性以高度安全的方式传输和保护数据的研究。它也被称为量子密钥分发 (`QKD`)，并根据量子纠缠概念运行，该概念允许在两个粒子相关联时生成密钥。为了确保无法被访问或干扰的安全通信，量子密码学试图开发无法被算法破解的加密技术。与传统密码系统相比，量子密码学在安全范式的基本组成部分中更强调物理学而非数学。在这种情况下，密钥被转换为光子序列，在希望共享秘密的双方之间传输。根据海森堡不确定性原理，攻击者无法在不导致这些光子发生变化或消失的情况下观察它们（[图6.3](#ch6.xhtml#fig6_3)）。

## 6.3 量子信息
与量子系统相关联的信息被称为量子信息。它是量子信息理论研究的基石，并应用于量子计算 [[3](#ch6.xhtml#ref6_3)]。同时存在于多种状态的能力以及纠缠的能力——即一个粒子的状态取决于另一个粒子的状态——是量子信息与经典信息不同的两种方式。因此，量子信息的研究是解决使用传统计算无法或难以处理的问题的一个令人兴奋的领域。在量子计算中，量子信息的基本构建块被称为 `qubit`，它类似于经典计算中使用的位。它使用双态量子系统表示，例如光子的偏振或电子的自旋，是传统位的量子力学等价物。`qubit` 能够同时处于两种状态的组合中，而传统位只能表示 0 或 1，这使得计算更加复杂和强大。

基本态 [[2](#ch6.xhtml#ref6_2)] `∣0⟩` 和 `∣1⟩` 呈线性组合，可用于表示量子位的态。这可以科学地写成：

(6.1)

`∣ψ⟩=α∣0⟩+β∣1⟩`

其中 `∣α∣²` 和 `∣β∣²` 分别表示测量 `qubit` 处于态 `∣0⟩` 和 `∣1⟩` 的概率，而 `α` 和 `β` 指的是复数值，使得 `∣α∣² + ∣β∣² = 1`。

这被称为叠加原理，是量子力学的主要特性。它使量子计算机能够比传统计算机更快地执行某些计算，因为它允许 `qubit` 以经典态 `∣0⟩` 和 `∣1⟩` 的线性组合的状态存在 [[3](#ch6.xhtml#ref6_3), [4](#ch6.xhtml#ref6_4)]。叠加是系统同时存在于多个状态或点的能力。尽管在量子力学中的解释可能与经典对应物有很大不同，但这仍然是经典物理和量子物理中的基本原理。在量子力学中，叠加是指粒子在被测量或观察之前能够同时存在于多个状态的能力。在经典物理学中，叠加是指波能够与其他波相加或相消的能力（[图6.4](#ch6.xhtml#fig6_4)）。

![图6.4 量子计算中数据的表示（量子位）。](images/fig6_4_B.jpg)

根据叠加原理，系统对多个输入的总体响应等于其对每个单独输入的响应的总和。

从数学上讲，这一原理可以用方程表示：

(6.2)

`y(t)=αx1(t)+βx2(t)`
