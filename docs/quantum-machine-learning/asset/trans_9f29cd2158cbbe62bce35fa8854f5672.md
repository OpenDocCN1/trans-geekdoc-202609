
多个 QSVM 过程在 [图 3.2](#ch3.xhtml#fig3_2) 的功能示意图中被描绘。经典特征映射函数 `ϕ(x[i])`，表示为 `|ϕ(x[i])⟩`，用于首先将经典数据点 (`x[i]`) 映射到更高维的特征空间。然后使用量子特征映射 (`Uϕ`) 将特征向量编码为量子态。特征向量随后使用量子特征映射 (`Uϕ`) 编码为量子态。量子电路 (`U`) 用于编码后的量子态上执行量子计算。然后对量子电路进行测量以获得经典结果。基于测量结果训练经典 SVM 模型以对新数据点进行分类并产生预测输出。

为了透彻掌握这种方法，深入了解 QSVM 的底层算术、方程和描述非常重要 [[7](#ch3.xhtml#ref3_7)]。

#### 3.3.1.1 数学符号和方程
1. **数据表示：**
   * 设我们考虑一个包含 N 个数据点的数据集：{`xᵢ`, `yᵢ`}，其中 `xᵢ` 表示第 `i` 个数据点的特征，`yᵢ` 表示其对应的类别标签。类别标签可以是二元（+1 或 −1）或使用 one-hot 编码的多类编码。
2. **量子特征映射：**
   * QSVM 使用量子特征映射将经典数据转换为量子特征空间 [[8](#ch3.xhtml#ref3_8)]。使用一种称为量子特征映射或 QFM 的量子电路 `ϕ(x)`，将经典数据 `x` 编码为量子态 `|ϕ(x)⟩`。
3. **核矩阵：**
   * 使用量子特征向量计算核矩阵 `K`。
   `K(x,x′)=⟨ϕ(x)|ϕ(x′)⟩`。
4. **支持向量分类：**
   * 给定核矩阵 `K`，QSVM 算法找到支持向量，即最接近决策边界的数据点。
5. **决策函数：**
   * QSVM 中的决策函数由下式给出：
   `f(x)=sign(∑[i] α[i] y[i] K(x[i],x)+b)`，
   其中 `b` 是偏置项。

#### 3.3.1.2 QSVM 算法描述
以下数学符号可用于描述 QSVM 算法。
1. **步骤 1：** 对于每个经典数据点 `x[i]`：
   * 应用量子特征映射将 `x[i]` 编码为量子特征向量 `|ϕ(xᵢ)⟩`。
2. **步骤 2：** 使用量子特征向量 `|ϕ(xᵢ)⟩` 计算核矩阵 `K`：
   `K(x[i],x[j])=⟨ϕ(x[i])|ϕ(x[j])⟩`。
3. **步骤 3：** 找到支持向量并计算定义决策函数的系数 `αᵢ`：
   * 在 `x[i]` 数据点中发现最接近决策边界的支持向量。
   * 使用支持向量和类别标签 `yᵢ` 计算系数 `α[i]`。
4. **步骤 4：** 确定偏置项 `b`：
   * 使用系数 `α[i]` 和类别标签 `yᵢ` 计算偏置项 `b`。
5. **步骤 5：** 给定一个新数据点 `x`，使用决策函数预测其类别标签：
   * 计算决策函数：
   `f(x)=sign(∑[i] α[i] y[i] K(x[i],x)+b)`。
   * 根据决策函数的方向，预测新数据点 `x` 的类别标签 `y[pred]`。

通过应用量子计算，QSVM 可以提升分类任务。理解 QSVM 背后的基本思想将使研究人员和从业者能够使用它来解决困难的分类问题并利用量子计算在机器学习中的能力。

### 3.3.2 量子神经网络（QNN）
传统神经网络通过提供强大的模式识别和决策工具彻底改变了机器学习。量子神经网络（QNNs）旨在利用量子系统的计算能力进一步增强数据的学习和处理。在 QNNs 中应用量子力学原理 [[9](#ch3.xhtml#ref3_9)] 以改善数据的表示和处理。此外，QNNs 将经典神经网络架构与量子电路模型相结合，创建混合框架。它们利用量子态和量子操作来表示和操纵数据，在解决复杂优化问题和学习任务方面提供潜在优势。本章探讨 QNNs 的数学符号、方程和描述，突出其独特特征和潜在应用。

在 QNNs 中，量子神经元充当基本处理单元。它们由量子态表示并实现量子操作以转换输入数据。量子神经元可以使用量子电路或其他量子计算模型实现。在 QNN 中，量子层是一组按特定拓扑连接的量子神经元。每个神经元接收输入数据，执行量子计算并产生输出数据。量子层堆叠以创建更深的架构，使数据中更复杂模式和关系的表示成为可能。

[图 3.3](#ch3.xhtml#fig3_3) 中的功能示意图说明了 QNN 中涉及的不同步骤。量子特征映射 `|ϕ(x)⟩` 首先用于将经典输入 (`x`) 编码为量子态 `|x⟩`。编码后的量子态经历由量子电路 (`Uθ`) 表示的量子计算，该电路由可训练参数集 `θ` 参数化。对量子电路进行测量以获得测量结果，然后用于生成经典输出。经典输出代表 QNN 的预测或结果。

![图 3.3 量子神经网络的功能示意图。](images/fig3_3_B.jpg)

[图 3.3 量子神经网络的功能示意图。](#ch3.xhtml#R_fig3_3)

通常，QNNs 在训练时采用参数化量子电路，其中训练过程用于优化量子门的程序化参数。这些参数决定了量子神经元应用的变换，并被学习以最小化合适的损失函数。否则，QNNs 使用另一种重要方法进行训练，称为量子反向传播 [[10](#ch3.xhtml#ref3_10), [11](#ch3.xhtml#ref3_11)]。它涉及通过参数化量子电路计算梯度，从而允许使用常规优化程序优化电路参数。

#### 3.3.2.1 量子神经网络（QNN）算法
1. **步骤 1**：对于每个经典数据点 `xᵢ`：
   * 应用量子特征映射将 `xᵢ` 编码为量子特征向量 `|ψ(xᵢ)⟩`。
2. **步骤 2**：对于每个量子层 `l`：
   * 将参数化量子电路 `U(θ[l])` 应用于量子特征向量 `|ψ(xᵢ)⟩`。
   * 将变换后的量子态 `|ψ′(xᵢ)⟩` 作为输出获得。
3. **步骤 3**：为参数化量子电路初始化参数 `θ`。
4. **步骤 4**：迭代以下步骤直至收敛：
   * 前向传播：
     * 对于每个训练数据点 (`xᵢ`, `yᵢ`)：
       * 为获得量子特征向量，应用量子特征映射 `|ψ(x[i])⟩`。
       * 应用量子层以获得变换后的量子态 `|ψ′(xᵢ)⟩`。
     * 基于变换后的量子态 `|ψ′(x[i])⟩` 计算输出预测。
   * 反向传播：
     * 计算损失函数 `L` 相对于变换后的量子态 `|ψ′(xᵢ)⟩` 的梯度 `∂L/∂|ψ′(xᵢ)⟩`。
     * 使用计算得到的梯度更新参数 `θ`。
