
# 量子机器学习

## 量子计算原理

量子计算原理如叠加和纠缠可用于改进量子机器学习算法中的数据表示、处理和分析。集成中的每个成员代表一种可设想的量子系统状态。例如，如果我们有一组量子位，每个量子位可以处于基态 `∣0⟩` 和 `∣1⟩` 的叠加态。如果我们取一个 2 位量子计算机，集成将由这些量子位状态的各种组合构成，例如 `∣00⟩`、`∣01⟩`、`∣10⟩` 和 `∣11⟩` [[2](#ch11.xhtml#ref11_2)]。在量子计算中，量子基础模型或分类器是利用量子电路或量子算法构建的。这些基础模型可利用多种量子方法生成，包括量子支持向量机、量子神经网络和量子变分算法。每个量子基础模型旨在处理量子输入并预测量子状态。在这些模型中可使用量子门、叠加和纠缠来编码和操纵数据，捕捉量子关联和模式。在集成机器学习方法中，单个基础模型通常在训练数据的不同子集上训练，或使用不同的初始参数。

在量子计算环境中训练量子基础模型涉及优化量子电路或算法以最小化给定的损失函数。量子优化技术，例如量子梯度下降或量子变分算法，可用于反复更新量子基础模型的参数，以便找到使损失函数最小化的最佳配置。训练过程寻求编码训练数据中模式和相关性的量子态，从而实现准确预测。在训练完量子基础模型后，其预测结果会被汇总以生成集成预测。为了汇总量子基础模型的预测结果，可以使用集成组合程序。投票（例如多数投票或加权投票）、平均（例如取预测的平均值或加权平均值）以及堆叠（在基础模型的预测上训练元模型）是常见的组合方法。这些组合策略考虑了量子态及其测量的概率特性，可以定制以处理量子预测。当新的量子数据提供给集成模型时，每个量子基础模型分别分析数据并做出预测。为了获得最终的集成预测，这些单独的预测会使用选定的组合方法合并。量子基础模型的集成旨在利用多个量子模型的多样性和互补特性，提高预测准确性、鲁棒性和泛化能力 [[3](#ch11.xhtml#ref11_3)]。量子位可以处于叠加态，这意味着它可以同时处于多个状态。基本态的线性组合可用于数值表达叠加态。线性组合的系数将表示系统状态假设为某一状态的振幅概率。设方程 (11.1) 中的状态表示单个量子位的任意状态。

系数 `α` 和 `β` 是复整数，表示 `∣ψ⟩` 的振幅概率。

(11.1)

`∣ψ⟩=α∣0⟩+β∣1⟩`

因此，分类器集成是一种将多个分类器的输出组合以获得最终响应的分类方法。例如，考虑一个二元分类问题，其类别集合为 `Y` = {−1, 1}。设 `E` = `a[1]`、`a[2]`、`a[3]`、… `a[n-1]` 表示分类器的集合。给定一个未知数据样本 `x`，每个分类器的输出被合并以得到集成的最终响应，如方程 (11.2) 所述 [[4](#ch11.xhtml#ref11_4)]。

(11.2)

$$
\widehat{y} = \operatorname{sign}\left( \sum\limits_{a \in E}w_{\alpha}f\left( \widetilde{x},a \right) \right.
$$

其中 `sign` 为符号函数，`ŷ` 为集成的答案（类别）。

## 11.2 QBoost

Boosting 是一种在传统计算中使用的机器学习集成方法，它将多个弱学习器（通常是决策树）组合起来生成强大的预测模型。Boosting 的基本原理是逐步训练模型，每个新模型都集中于旧模型分类错误或做出大量不准确预测的案例。Boosting 过程中的第一个弱学习器使用完整的训练数据集进行训练。在每种情况下，它都会产生预测，然而最初这些预测可能不正确。在训练数据集中，每个样本都被赋予一个初始权重。大多数情况下，所有权重最初都设为相等。然而，随着 boosting 过程的推进，权重会根据早期弱学习器的准确性进行修改。

Boosting 算法有过拟合训练数据的倾向，特别是当弱学习器非常复杂或迭代次数过多时。过拟合发生在模型在训练数据上过度特化，无法成功泛化到新数据时。Boosting 易受训练集中的噪声或异常值影响。因为 boosting 方法会给被误分类的案例赋予更大权重，噪声数据会对模型性能产生相当大的影响，导致结果不令人满意 [[5](#ch11.xhtml#ref11_5)]。

`AdaBoost` 是一种 boosting 算法，其中若干复杂因素会影响 `AdaBoost` 算法的计算需求和性能。`AdaBoost` 需要多次训练弱学习器的循环。每次迭代的时间复杂度由所使用的弱学习器算法决定。在本部分中，我们应用量子方法来增加 `AdaBoost` 的复杂度。我们将量子 boosting 算法分为几个阶段。我们量子 boosting 方法中的大部分技术工作都集中在降低训练误差上 [[6](#ch11.xhtml#ref11_6)]。

1. 为了在近似分布 `D[t]` 下生成弱假设 `h[t]`，在训练集 `S` 上调用弱量子学习器 `A`。
2. 我们的技术通过对 `h[t]` 执行量子查询来计算 `ϵ[t]^(l)`，它是 $\widetilde{\epsilon_{t}} = P_{\gamma_{x\sim\widetilde{D}}t\lbrack h_{t}(x) \neq C(x)\rbrack}$ 的近似值。
3. 使用 `ε[t]` 计算权重 `α[t]`。输出经过 `T` 步后的 `H(x)` 假设 = `sign` $\sum_{t:1}^{T}\alpha_{t}h_{t}\left( x \right)$。

量子 boosting 算法利用量子计算机的能力来增强传统 boosting 方法的精度和有效性。经典 boosting 中的弱学习器经常是决策树或其他传统机器学习模型。量子 boosting 中的弱学习器是可在量子计算机上运行的量子电路或量子模型。量子弱学习器，即优于传统机器学习算法的量子电路或模型，是量子 boosting 技术的基础。在这些弱学习器的实现中采用了量子门和量子过程。用于训练第一个量子弱学习器的量子数据集。量子数据集 either 通过直接利用量子数据创建，或通过将经典数据编码为量子态创建。基于量子数据集，第一个量子模型会产生预测，然而这些预测最初可能不正确 [[7](#ch11.xhtml#ref11_7)]。
