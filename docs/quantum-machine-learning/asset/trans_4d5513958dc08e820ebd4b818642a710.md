
1. 输入数据点根据 `bloch sphere` 中的变量状态进行编码以实现叠加。`bloch sphere` 是量子位在三维平面中的表示，其中量子位通过改变状态放置在 `Pauli X` 轴上。`Pauli Z` 轴表示状态 0 和状态 1，以了解量子位是否属于这些状态中的任何一个。`Pauli Y` 轴提供与量子位状态相关联的复数值 [[9](#ch7.xhtml#ref7_9)]。
2. 将数据点叠加到 `bloch sphere` 之后，纠缠阶段开始。在纠缠中，一对量子位通过共同的 `NOT Gate` 共享共同信息。两个量子位之间的共同性为输入数据生成新的特征向量 [[10](#ch7.xhtml#ref7_10)]。
3. 一旦为输入生成特征向量，量子计算的特征映射将被生成。量子特征映射是特征向量和量子态的组合。
4. 特征映射通过量子硬件进行编码和处理，以实现更快的处理和精确的结果。
量子复杂性始终依赖于纠缠和量子硬件处理；然而，许多复杂问题可使用量子计算有效处理。

## 7.3 量子嵌入
量子嵌入被定义为通过特征映射解析输入，将经典数据点或数据表示为量子态的过程 [[11](#ch7.xhtml#ref7_11)]。嵌入可以通过两种不同方式进行：
1. 基本嵌入
2. 振幅嵌入

### 7.3.1 基本嵌入
基本嵌入中，数据将直接转换为量子态 [[12](#ch7.xhtml#ref7_12)]。量子态将由 `|Ψ[x]⟩` 表示，转换如方程 (7.1) 所示。

(7.1)
`X{x1,x2,x3…,xn}=|Ψx1⟩,|Ψx2⟩,……,|Ψxn⟩`
假设用于表示数据集中一个示例的位数总数为 `N`，则量子子系统的数量将等于 `N`。样本总数由 `M` 表示。方程 (7.1) 将重写为

(7.2)
```
\left. \mid \textbf{Data} \right\rangle\left. = \frac{1}{\sqrt{M}}\sum_{m = 1}^{M} \mid x^{m} \right\rangle
```
[图 7.3](#ch7.xhtml#fig7_3) 以简单的方式提供了对量子嵌入的更好理解。
![图 7.3 经典数据到量子态的基本嵌入。](images/fig7_3_B.jpg)
[图 7.3 经典数据到量子态的基本嵌入。](#ch7.xhtml#R_fig7_3)

### 7.3.2 振幅嵌入
每个状态的振幅都被嵌入以在希尔伯特量子空间中生成量子态。基于振幅的嵌入通过方程 (7.3) 描述。

(7.3)
```
\left. \mid \textbf{Data} \right\rangle\left. = \sum_{m = 1}^{2M}a_{m} \mid m \right\rangle
```
其中，`a[m]` 是归一化连接数据，而 `m` 是计算基态。
还有类似的最新嵌入可用，例如 `angle encoding`、`rotation encoding`、`Qsample encoding`，以及 `divide`、`Conquer encoding` 等 [[13](#ch7.xhtml#ref7_13)]。

## 7.4 量子主成分分析 (qPCA)
一种称为量子主成分分析 (`qPCA`) 的量子方法利用量子计算来减少数据集中维度的数量并确定最重要的特征。对于传统机器学习应用中的信息分析和压缩，`PCA` 仍然是一种广泛采用的方法。在传统的 `PCA` 中，该方法识别出一组主成分，即轨道流形方向，导致数据变化最大。这些元素通过捕获每个数据集的重要信息来实现降维和特征提取。
量子 `PCA` 试图通过利用量子计算的潜在优势来加速 `PCA` 计算。与使用传统 `PCA` 方法相比，使用这种方法可以更快地处理海量数据集 [[14](#ch7.xhtml#ref7_14)]。这些数据集中包含的变量数据值随后被转换为 `X n` 相关矩阵，其中 `n` 是变量的总数。主成分代表向量的累积，这些向量是单位向量，包含一个相对于初始 `i - 1` 向量正交的第 `i` 个向量，提供相关矩阵 [[15](#ch7.xhtml#ref7_15)]。有 `d` 个向量对应于 `d` 个维度。单个点与一个向量之间的中位数平方距离最小，因为该向量具有确保最佳拟合到数据集的属性。指定数据集合中的特征向量对应于这些向量。较高的特征值表示相关向量之间存在显著变化。由于方差较小，较低特征值向量可能不予考虑。不幸的是，突破性的量子主成分分析 (`qPCA`) 仍存在几个潜在问题 [[16](#ch7.xhtml#ref7_16)]。首先，过程必须使用大量量子门，其次，近似可能导致精度下降。
该算法已被多位研究人员检验并发现为精确算法，这意味着使用该技术时，它会产生精确的结果而不是低复杂度的估计结果。这一属性使其比基于量子奇异值阈值 (`qSVT`) 的当前研究中一些学者工作中解释的技术更有效。只有这两种方法独立于受控操作以及初始化矩阵 [[17](#ch7.xhtml#ref7_17)]。低复杂度 `qPCA` 算法的操作阶段如下：
1. 相位估计：在此阶段，特征值被抽象到量子寄存器。
2. 幺正操作：在此阶段，平凡特征值从量子寄存器中分离出来。
3. 幺正受控操作：在此阶段，使用幺正受控操作和辅助量子位来确定观测量子位特征值是否属于主成分。
4. 幺正逆操作：在此阶段，认为多余的值存储寄存器被移除。
5. 测量：此阶段量化量子位。
6. 第二次相位估计：在此阶段，可以获得量子态。

## 7.5 机器学习中的量子线性模型
线性回归模型已被广泛用于根据预测因子预测目标。`x` 和 `y` 变量的线性相关性可如方程 (7.4) 所示识别。

(7.4)
`y = a x + b`
其中 `a` 和 `b` 表示由 `x` 和 `y` 变量相关性得出的线性模型的斜率和截距 [[18](#ch7.xhtml#ref7_18)]。然而，当数据量增大时，确定 `a` 和 `b` 的最优值总是很繁琐。量子线性模型在解决在更大数据集中识别最佳最优值的问题方面表现出色。为了更好地理解，[图 7.4](#ch7.xhtml#fig7_4) 描述了线性模型与量子线性模型。
![图 7.4 量子回归模型。](images/fig7_4_B.jpg)
[图 7.4 量子回归模型。](#ch7.xhtml#R_fig7_4)
概念上，量子线性回归结合了每个量子位的状态，并在 [图 7.4](#ch7.xhtml#fig7_4) 中绘制为离散映射。因此，数学上，`x` 和 `y` 已转换为量子位并且可以如方程 (7.5) 所示进行归一化：

(7.5)
```
\left. \mid y \right\rangle = \frac{1}{C_{y}}y
```
