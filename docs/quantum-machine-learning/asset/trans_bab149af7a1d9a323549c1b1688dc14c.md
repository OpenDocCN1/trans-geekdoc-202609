
# 8 计算复杂度

[表 8.1 传统算法的计算复杂度](#ch8.xhtml#R_table8_1)

| 算法 || 复杂度 |
| --- | --- |
| SVM || `exp(O(log(N) + log(d)))` |
| --- | --- |
| 决策树 || `exp(O(log(N) + log(d) + log(log(N))))` |
| 随机森林 || `exp(O(log(M) + log(N) + log(d) + log(log(N))))` |

在 [表 8.1](#ch8.xhtml#table8_1) 中，“`N`” 表示数据点的总数，“`d`” 表示特征空间的维度，而 “`M`” 表示随机森林中树的总数。经典分类算法（如 SVM、决策树和随机森林）的复杂度随数据集大小和特征维度呈多项式增长。

在 [表 8.2](#ch8.xhtml#table8_2) 中，展示了量子分类算法（如量子 SVM、量子决策树和量子随机森林）的复杂度。这些算法的量子复杂度可能受数据点数量、特征维度和随机森林中树的数量的影响。这些量子算法相对于经典方法具有潜在的指数级加速。

[表 8.2 量子分类算法的计算复杂度](#ch8.xhtml#R_table8_2)

| 算法 || 复杂度 |
| --- | --- |
| 量子 SVM || `exp(O(log(N^3)))` |
| --- | --- |
| 量子决策树 || `exp(O(log(N) + 2log(N) + log(d) + log(log(N))))` |
| 量子随机森林 || `exp(O(log(M) + 2log(N) + log(d) + log(log(N))))` |

[表 8.3](#ch8.xhtml#table8_3) 提供了 SVM、决策树和随机森林的经典算法与量子算法计算复杂度的比较。它突出了量子算法实现的显著复杂度降低，这可能导致指数级加速。

[表 8.3 计算复杂度的比较](#ch8.xhtml#R_table8_3)

| 算法 || 经典复杂度 || 量子复杂度 |
| --- | --- | --- |
| SVM || `exp(O(log(N) + log(d)))` || `exp(O(log(N^3)))` |
| --- | --- | --- |
| 决策树 || `exp(O(log(N) + log(d) + log(log(N))))` || `exp(O(log(N) + 2log(N) + log(d) + log(log(N))))` |
| 随机森林 || `exp(O(log(M) + log(N) + log(d) + log(log(N))))` || `exp(O(log(M) + 2log(N) + log(d) + log(log(N))))` |

然而，需要注意的是，要在实践中实现这种指数级加速，需要克服若干挑战。其中主要挑战之一是在物理量子硬件上实现量子算法。量子计算机仍处于早期发展阶段，当前量子系统具有有限的量子比特相干时间和较高的错误率。因此，在现有量子硬件上实现量子分类算法具有挑战性。

此外，量子分类算法的复杂度取决于具体问题和数据集的大小。虽然量子算法可为某些任务提供指数级加速，但它们仍可能需要大量量子比特或量子门来实现这一优势。随着数据集规模的增大，所需的量子比特数和量子操作数也会增加，这可能对量子分类算法的可扩展性构成实际限制。

## 8.5 总结

总之，量子分类算法有潜力相对于经典方法提供指数级加速，从而实现更快、更准确的分类。比较表展示了量子算法实现的计算复杂度显著降低。然而，要在实践中充分发挥量子分类的潜力，需要解决与量子硬件限制相关的问题，并优化量子算法的可扩展性和效率。

## 9.1 Boosting 简介

由于能够解决传统机器无法解决的计算问题，量子计算有能力革新计算，并在农业、金融、能源和材料科学设计等关键行业产生重大影响。在构建拥有 50 至 100 个量子比特及更大的量子计算系统时，正在做出设计选择以尽可能榨取机器的最大处理能力。这导致了对简单量子体积（SQV）\[[1](#ch9.xhtml#ref9_1)\]的研究，其可通过将机器的计算量子比特数乘以预期能够无错误执行的门数量来建模，如 [图 9.1](#ch9.xhtml#fig9_1) 所示。量子计算中最小的存储单元是量子比特，即极易出错的物理量子位。这意味着这些机器上的计算受量子比特快速衰减寿命的限制。这目前是 SQV 的一个限制。为弥补这一点，系统设计师正在努力创建更好的物理量子比特，然而这非常具有挑战性，因此可能建议使用经典系统来减轻负载。

![图 9.1 使用纠错码的量子计算机增强。](images/fig9_1_B.jpg)

[图 9.1 使用纠错码的量子计算机增强。](#ch9.xhtml#R_fig9_1)

特别是，量子纠错是一种传统的控制方法，可降低量子比特出错率并提高 SQV。纠错的下一步是将要通过算法处理的逻辑量子比特组编码到一组物理有缺陷的量子比特中。一种特定的量子电路，称为综合征，可在不干扰底层过程的情况下提取有关设备当前状态的数据。纠错协议可通过称为解码的过程将数据转换为一组校正。如果校正选择正确，系统应恢复到正确的逻辑状态。通过随码距呈指数级降低量子比特错误，全容错机器可以迅速扩展 SQV。
