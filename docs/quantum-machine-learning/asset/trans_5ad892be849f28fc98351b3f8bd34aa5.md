
在公式 (7.5) 中，$\\frac{1}{`C_y`}$ 被视为归一化因子。均方误差被降低以在最终模型中获得更高的精度 [[19](#ch7.xhtml#ref7_19)]。成本函数降低均方误差。然而，不同的研究人员提出了许多方法来估计量子线性回归的成本函数 [[20](#ch7.xhtml#ref7_20)]。多项式实现了基于高阶拟合的扩展量子回归技术。

## 7.6 量子聚类
参考文献 \[8\] 聚类被认为是无监督学习算法，主要用于识别输入数据流中的潜在模式。模式主要用于根据数学概念和统计推断确定数据流的行为，在某些情况下，它被用作混合建模的降维技术 [[21](#ch7.xhtml#ref7_21)]。聚类的基本原理是确定数据或示例之间的相似性。然而，当数据流庞大时，经典机器上的冗余计算无法取得最佳结果 [[22](#ch7.xhtml#ref7_22)]。量子计算通过其对大规模数据流的聚类算法的硬件实现解决了这些问题。接下来使用传统的 `K-Means` 和 `K-Median` 聚类来解释和讨论量子聚类的实现以及算法的有效性。

### 7.6.1 量子 K-Means 聚类
量子 `K-Means` 聚类在训练数据和测试数据上执行，并识别每个向量之间的对应关系以获得最佳精度 [[23](#ch7.xhtml#ref7_23)]。相比之下，在经典 `K-Means` 聚类中，训练输入数据被用于确定测试精度。[图 7.5](#ch7.xhtml#fig7_5) 中的流程图详细描述了 `K-Means` 聚类的过程。

![图 7.5 量子聚类过程。](images/fig7_5_B.jpg)

[图 7.5 量子聚类过程。](#ch7.xhtml#R_fig7_5)

在对训练向量和测试向量执行量子嵌入后，训练向量和测试向量之间的对应关系根据位置程度建立 [[24](#ch7.xhtml#ref7_24)]。执行旋转操作以从原始向量获得新向量并获得输入向量之间更好的对应关系。获得新配置的 `Qubits` 后，对向量进行归一化 [[25](#ch7.xhtml#ref7_25)]。在最高有效量子位上对归一化向量执行 `Hadamard` 操作。执行测量操作以识别量子态的概率。整个过程重复以识别量子态的相对差异，最终通过推断变分态获得准确的聚类结果。

### 7.6.2 量子 K-Median 聚类
`K-Median` 是一种传统的聚类技术，其中 `K` 表示从输入数据中所需的聚类数量。一旦执行开始，选择 `K` 个点，并计算数据点与质心的接近程度并形成聚类。此过程将递归重复直到达到稳定的质心。该过程的递归性质耗时，且当数据规模增大时复杂度呈指数增长。为了有效地处理大型数据集，量子 `K-Median` 实现有助于更快收敛并降低复杂度 [[26](#ch7.xhtml#ref7_26)]。已引入了多个版本的 `K-Median` 聚类，其中最著名的是由 Aïmeur 等人开发的 Diffie-Hellman 算法 (`DH`) 算法 [[27](#ch7.xhtml#ref7_27)]，该算法被广泛用于缓解 `K-Median` 聚类中的最小化问题。

### 7.6.3 量子层次聚类
量子层次聚类是用于聚类和识别数据最突出特征的领先方法之一。层次聚类通过每一层的接近度递归识别训练数据之间的相关性 [[28](#ch7.xhtml#ref7_28)]。层表示数据的突出特征，有助于识别聚类。接近度使用基于距离的方法计算。层次聚类在 [图 7.6](#ch7.xhtml#fig7_6) 中显示。

![图 7.6 层次聚类。](images/fig7_6_B.jpg)

[图 7.6 层次聚类。](#ch7.xhtml#R_fig7_6)

## 7.7 Harrow–Hassidim–Lloyd (`HHL`) 算法
求解任何线性系统在工程领域非常重要。本质上，线性系统没有解、多个解或唯一解。无解的线性系统称为不一致，多解的线性系统称为一致且相关，因为解依赖于其他解，而单解的线性系统称为一致且独立，因为解独立于任何输入或影响 [[30](#ch7.xhtml#ref7_30), [31](#ch7.xhtml#ref7_31)]。所有线性系统都遵循齐次原理，如公式 (7.6) 所示。

(7.6)
```
\[*a**y*1(*t*)+*b**y*2(*t*)\] = *T*\[*a**x*1(*t*)+*b**x*2(*t*)\] = *a**T*\[*x*1(*t*)\] + *b**T*\[*x*2(*t*)\]
```

由于求解线性系统在经典计算中存在严重的复杂性问题，量子计算机在求解线性系统以获得一致且独立的输出方面更为成功。科学家 Hassidim、Harrow 和 Lloyd 开发了一种有效求解线性系统的算法，称为 `HHL` 算法。

## 7.8 二次无约束二值优化 (`QUBO`)
二次无约束二值优化 (`QUBO`) 方法广泛用于解决各个领域的组合优化问题。`QUBO` 方法是统一的建模框架，用于解决网络流、调度以及 NP-Hard 问题（如数字划分、匹配和生成树等）中的优化问题。`QUBO` 求解一组变量（输入），对应于目标函数（最小/最大），以及一组约束（无需遵循） [[32](#ch7.xhtml#ref7_32)]。`QUBO` 如果得到的解不遵循约束，则提供惩罚，这最终使我们能够为二值变量问题获得多个解。[图 7.7](#ch7.xhtml#fig7_7) 描述了解决二值优化问题。
