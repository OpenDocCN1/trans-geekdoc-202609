# 2.2 量子计算的量子力学

量子力学是现代物理学基础理论，彻底改变了对微观世界的理解，为描述量子尺度粒子行为提供了数学框架。这一20世纪早期发展起来的理论是量子计算的基石，通过利用量子现象实现指数级强大计算。

“量子力学之父”维尔纳·海森堡在该领域发挥关键作用。1925年，海森堡与马克斯·玻恩、帕斯库尔·约当共同提出量子力学的革命性数学形式体系——矩阵力学。海森堡的工作引入了不确定性原理，指出位置和动量等某些物理性质对不能同时被任意精确测量。该原理挑战了经典决定论，为量子现象的概率本质奠定基础。

海森堡不确定性原理结合埃尔温·薛定谔、保罗·狄拉克、尼尔斯·玻尔等人的开创性贡献，导致了基于波函数概念的波力学这一量子力学替代表述。薛定谔于1926年提出的波动方程提供了描述量子系统时间演化和计算其波函数的方法。

## 2.2.1 量子态与波函数

在量子力学中，量子态是量子系统的基本描述，概括了系统的性质和潜在结果，为后续计算和预测奠定基础。为理解量子态的复杂性，我们转向波函数这一数学表征。波函数记为 `|ψ⟩`，包含量子系统状态的完整信息。它是在希尔伯特空间框架下定义的复值函数，该数学结构为量子力学提供了严格基础。在此形式体系中，量子态由希尔伯特空间中的向量表示，其随时间演化受幺正变换原理支配。数学上，波函数 `|ψ⟩` 可表示为基态的线性组合，记为 `|ψ⟩ = Σ_i α[i] |Φ[i]⟩`，其中 `α[i]` 为复系数，`|Φ[i]⟩` 为正交归一基态。这些系数即概率幅，决定测量时获得各种测量结果的概率 [[3](#ch2.xhtml#ref2_3)]。

归一化条件确保所有可能测量结果的概率之和为1。它要求波函数绝对值平方在整个空间上的积分等于1：

(2.1)

∫ |`ψ`(`x`)|² d`x` = 1

该条件保证量子系统处于任何可能状态的总概率守恒 [[4](#ch2.xhtml#ref2_4)]。

例如，考虑长度为 `L` 的一维盒中粒子。表示粒子状态的波函数可表示为：

(2.2)

$$\\psi\\left( x \\right) = \\sqrt{\\frac{2}{L}\\sin\\mspace{6mu}\\ \\left( \\frac{\\mathit{n\\pi x}}{L} \\right)}$$

其中 `n` 为整数，表示粒子的能级。通过归一化该波函数，我们确保在盒内找到粒子的概率为1。

叠加概念是量子力学的标志，进一步探讨以加深理解。量子系统可同时存在于多个状态的线性组合中，数学上表示为：

(2.3)

$$\\left. \\mid \\psi \\right\\rangle\\left. = \\sum\\limits\_{i}\\alpha\_{i} \\mid \\Phi\_{i} \\right\\rangle$$

其中 `α[i]` 为复系数，`|Φ[i]⟩` 为正交归一基态。叠加特性导致了著名的薛定谔猫思想实验，其中猫可在既活又死的状态叠加中存在，直至被观测 [[4](#ch2.xhtml#ref2_4), [5](#ch2.xhtml#ref2_5)]。

量子力学中的测量过程会使波函数坍缩到其可能本征态之一，对应确定的测量结果。获得特定测量结果的概率由玻恩规则给出，该规则指出测量系统处于状态 `|Φ[i]⟩` 的概率等于系数 `α[i]` 的模平方：

(2.4)

`P(Φ[i]) = |α[i]|²`

量子力学的这种概率性与经典物理不同，后者系统性质可确定地确定。在量子力学中，测量仅给出概率结果，只有对相同制备的系综进行重复测量才能揭示统计行为。量子态还表现出另一种奇特特性——纠缠。当两个或多个量子系统纠缠时，其各自波函数不再能独立描述。相反，纠缠系统由联合波函数描述，考虑系统间的关联。这种纠缠可导致非局域关联，由爱因斯坦、波多尔斯基和罗森在其EPR佯谬中著名描述。此外，量子态随时间演化由薛定谔方程描述，这是量子力学中的核心方程。薛定谔方程规定量子系统波函数如何响应其哈密顿量而变化，后者代表系统的总能量 [[3](#ch2.xhtml#ref2_3), [4](#ch2.xhtml#ref2_4) and [5](#ch2.xhtml#ref2_5)]。

其定态形式为：

(2.5)

`Ĥ|ψ⟩ = E|ψ⟩`

其中 `Ĥ` 为哈密顿算符，`E` 为与状态 `|ψ⟩` 相关的能量本征值。求解薛定谔方程可确定量子系统的允许能级和相应波函数。

量子力学中的可观测量概念与量子态密切相关。可观测量是可以测量的物理量，如位置、动量、能量和自旋。在量子力学中，可观测量由相应算符表示，作用于波函数以产生测量结果。算符的本征值表示可能的测量结果，而本征态对应测量确定的状态。例如，粒子的位置由位置算符 `x̂` 表示，其动量由动量算符 `p̂` 表示。作用于波函数时，这些算符分别给出位置和动量测量结果。获得特定测量结果的概率由波函数展开中相应系数的模平方给出。需要注意的是，量子力学中的测量行为可导致波函数坍缩到所测可观测量的本征态。这种坍缩是非决定性过程，测量结果本质上是不确定的。该特性通常被称为量子力学中的测量问题，一直是哲学争论和解释的主题。
