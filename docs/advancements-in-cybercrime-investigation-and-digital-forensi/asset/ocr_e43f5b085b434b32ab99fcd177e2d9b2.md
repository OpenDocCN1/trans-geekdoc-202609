# 16.6.3.6 AUTHORIZATION FLOWS

Each client profile must have its own protocol rush for obtaining the grant to access the resource owner’s data. The basic OAuth 2.0 protocol defines four major “grant forms” for authorization, as well as a method for introducing innovative grant forms (Boukhdir, Lachiheb, & Gouider, 2015).
