## 18.3.1 TYPES OF ACQUISITION

The integrity of evidence is recognized, and digital evidence is collected in the order that secures maximum safety. Data is stored in a way that improves integrity and availability and reduces the impact on the system under investigation (Figure 18.3).

- 1. **Logical Acquisition:** This data extraction is mainly done to get basic device data. This import does not retrieve unallocated space data. In the absence of device root, retrieving information can be a huge advantage, but during this exposure only marked data will not affect deleted data.
- 2. **Physical Acquisition:** The actual way to get evidence of extraction is to access the device’s RAM and isolate the information. Makes a bit-by-bit copy of the mobile device. First, it supports retrieving deleted records. These two types of data collection are often done on both rooted and non-rooted mobile devices for information and knowledge.
- 3. **Manual Acquisition:** Manually importing data is a simple way to import data from your Android smartphone. The investigator uses the mobile keyboard to query the contents of the mobile device. The main advantage is that it is as convenient as possible and does not require the training of an investigator to understand how to get the contents of the call. It does not retrieve all data on your Android smartphone, including deleted and hidden files.

## 18.3.2 EXTRACTION

It is the method of extracting data from e-mails, PDFs, PDF forms, text files, images, etc. It is a crucial part of a digital forensics investigation. Data extraction is the method of retrieving any deleted data, file, content, etc., from the electronic devices when they cannot be accessed, searched, or opened normally by the user. Being able to extract the deleted data could help the investigators or analysts to solve various civil or criminal cases.

PC forensic tools are used to obtain data from a system or a PC. They’re used to secure logs and diverse encrypted data from the PC. Though memory forensic tools are used to acquire and analyze the PC’s volatile memory (RAM). They’re used to save evidence inside the memory that is lost once the system is shutting. They directly analyze the OS and diverse running processes inside the memory. The various stages whereby these devices work is Windows, UNIX, Linux, DOS, MAC:

- 1. **Windows:** It is a GUI operating system that is developed and marketed by Microsoft. UNIX: UNIX is a multi-user PC operating system that performs a variety of tasks, and this exists in variants. Unix was developed in the C programming language.
- 2. **Linux:** A Unix-like PC OS based on a free and open-source package model. Customers change, create, and sell their OS versions for their benefit.
- 3. **DOS:** An operating system that manages gadget memory devices and data.
- 4. **MAC OS:** It is primarily a GUI operating system developed by Apple INC. For the Macintosh computer line.
