# 16.8 CONCLUSION

Protected resources from a protected place can be accessed by the required authorized client using tokens. Tokens are created on the basis of parameters provided by the client. The token can be secured using digital signatures to prevent intruders from accessing protected resources. OAuth 2.0 elevates the concept of social authentication by offering more security than previous methods. However, it can be more secure if all of the challenges presented by this protocol are fulfilled. Issues such as the CSRF attack should be considered while creating a new protocol.
