# 12.4.1 EXPERIMENTAL SETUP AND OBSERVATION

In the credit card dataset, the fraud transactions are very small in comparison to valid transactions, so the dataset is highly skewed, and to tackle this problem a little bit, weights are used while building models (Kirkos, 2007). To evaluate the final predictions three different evaluation metrics are used, to get a better understanding. A consistent score or result of these metrics means better performance.

The confusion matrix is a two-cross-two matrix that contains four possible outcomes of a binary classifier.

Confusion Matrix = 
  TP  FN
  FP  TN

ROC (receiver operator characteristic curve) can help in deciding the best threshold value. It is generated by plotting the true positive rate (y-axis) against the false positive rate (x-axis).

TPR = Sensitivity = TP / (TP + FN)

FPR = 1 - Specificity = FP / (FP + TN)

MCC is robust to imbalance. It is related to the chi-square statistic and takes values between −1 and +1. For binary classification:

MCC = (TP × TN − FP × FN) / sqrt((TP + FP)(TP + FN)(TN + FP)(TN + FN))
