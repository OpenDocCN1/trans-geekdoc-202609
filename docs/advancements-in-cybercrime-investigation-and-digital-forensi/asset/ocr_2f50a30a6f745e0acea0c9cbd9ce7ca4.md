# 6.4.2 VARIOUS DATA MINING (DM) TECHNIQUES

DM is the process of using advanced data analysis technologies to find previously unknown, valid patterns and linkages in big data sets. This technology can make use of mathematical methods like neural networks, statistical models, and ML approaches like decision trees altogether. As a result, DM is used to make predictions as well as data analysis. Different fundamental DM techniques have been created and used for contemporary DM applications, including association, sequential patterns, clustering, prediction, classification, and regression (Han et al., 2011).
