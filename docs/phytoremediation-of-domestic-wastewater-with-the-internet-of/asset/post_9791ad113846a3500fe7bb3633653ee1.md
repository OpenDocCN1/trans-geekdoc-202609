### 10.2.3 ARTIFICIAL NEURAL NETWORK (ANN)

In this study, feedforward neural network (FFNN) structures were implemented, and their effectiveness was evaluated and compared with the SVM, ANFIS and multilinear model (MLR). The proposed two-model combinations (M1 and M2) were trained with three-layer (input, hidden and output) ANN architecture in which the number of hidden nodes is greater than the number of inputs. The FFNN was built for predicting the ORP of the effluent water samples using four input variables, $X_i$ $(i=1, ..., 4)$ (temperature, turbidity, TDS and ORP of the influent samples). The $n+1$ formula was used in selecting the hidden nodes, it has a better degree generalization that helps in preventing over-fitting issues. As a result, insufficient nodes can hinder the performance training and validation of the network (Ahmed & Sarma, 2007; Guo et al., 2015).

### 10.2.4 CONCEPT OF SUPPORT VECTOR MACHINE (SVM)

In this study, the model prediction was generated using SVM. Additionally, the two models were trained using cubic, linear, fine Gaussian, polynomial, coarse Gaussian and medium Gaussian kernel with a cross-validation of 10. After 100 iterations, it was discovered that the fine Gaussian kernel resulted in the optimum fit model for predicting the effluent water quality. For a given set of training data $\{(x_i, d_i)\}$, $(x_i$ is the input vector, $d_i$ is the actual value and $N$ is the total number of data patterns), the general SVM function is given in Equations 10.2–10.7.

```
$y = f(x) = w\phi(x) + b$
```

```
$Minimize: \frac{1}{2}\|w\|^2 + C\left(\sum_{i=1}^{N}(\xi_i + \xi_i^*)^2\right)$
```

```
$Subject to: \begin{cases} w\phi(x_i) + b_i - d_i \le \varepsilon + \xi_i^* \\ d_i - w\phi(x_i) + b_i \le \varepsilon + \xi_i^* \\ \xi_i, \xi_i^* \ge 0 \quad i=1, 2, ..., N \end{cases}$
```

```
$w^* = \sum_{i=1}^{N}(\alpha_i - \alpha_i^*)\phi(x_i)$
```

The final form of SVM can be expressed as:

```
$f(x, \alpha_i, \alpha_i^*) = \sum_{i=1}^{N}(\alpha_i - \alpha_i^*)K(x, x_i) + b$
```

```
$k(x_1, x_2) = \exp(-\gamma||x_1 - x_2||^2)$
```

where $\gamma$ is the kernel parameter.

### 10.2.5 CONCEPT OF ADAPTIVE NEURO-FUZZ INFERENCE SYSTEM (ANFIS)

ANFIS is a FFNN structure comprised of neuro-fuzzy system components at each layer. The ANFIS model utilizes the fuzzy Sugeno model within an adaptive system framework to promote learning and adaptation. The fuzzy inference applied in this study has four inputs and one output for Model 1 (M1), three inputs and one-output for Model 2 (M2). ANFIS architecture can be described by assuming that there are two inputs assigned as x and y. The two fuzzy if-then rules for a first-order Sugeno fuzzy model can be expressed as follows:

```
Rule 1: If ($x$ is $A_1$) and ($y$ is $B_1$), ($f_1 = p_1x + q_1y + r_1$), (10.8)
```

```
Rule 2: If ($x$ is $A_2$) and ($y$ is $B_2$), ($f_2 = p_2x + q_2y + r_2$), (10.9)
```

$A_i$ and $B_i$ are fuzzy sets, $f_i$ is the output, $p_i, q_i,$ and $r_i$ are the design parameters that are determined during the training process. The ANFIS architecture used to implement the two rules is shown below:

```
Layer 1: $Q_i^1 = \mu_{Ai}(x)$ for $i=1,2$ or $Q_i^1 = \mu_{Bi}(x)$ for $i=3,4$ (10.10)
```

```
Layer 2: $Q_i^2 = w_i \mu_{Ai}(x) \mu_{Bi}(y)$ for $i=1,2$ (10.11)
```

```
Layer 3: $Q_i^3 = \frac{W_i}{W_1 + W_2} i =1,2$ (10.12)
```

```
Layer 4: $Q_i^4 = w_i(p_ix + q_iy + r_i) = \bar{w}_i f_i$ (10.13)
```

$p_i, q_i,$ and $r_i$ are consequent parameters.

```
Layer 5: $Q_i^5 = w_i(p_ix + q_iy + r_i) = \frac{\sum w_i f_i}{\sum w_i}$ (10.14)
```

For the purpose of this study, the optimumparameter tuning for developing the ANFIS model especially the membership functions (MF) (Gaussian, trapezoidal and triangular) was selected using trial-and-error. The choice of the best algorithms between backpropagation and hybrid learning was both employed for optimizing the parameters of the MFs; subsequently, hybrid emerged as the training algorithm. The error tuning was set to 0.005 and the iterations were between the range of 30 and 70 for both the training and testing phase.

### 10.2.6 MULTILINEAR REGRESSION (MLR)

MLR is used in determining the level of variation between two or more variables. The model is defined as (Chen & Liu, 2015):

```
$y = b_0 + b_1x_1 + b_2x_2 + b_3x_3 + \cdots + b_ix_i$ (10.15)
```

$x_i$ is the value of the predictor, $b_0$ is the constant and $b_i$ is the coefficient.

### 10.3 MODEL VALIDATION AND PERFORMANCE EVALUATION

The model performance of the ANN, SVM, ANFIS and MLR was determined by splitting the predicted data into 70% training and 30% testing. To monitor the performance of the models, different evaluation criteria namely coefficient of correlation (R), coefficient of determination (R²), mean square error (MSE) and root mean square error (RMSE) were used. The model parameters are formulated as follows:

```
$R = 1 - \frac{\sum_{i=1}^n (A_i - P_i)^2}{\sum_{i=1}^n (A_i - \bar{A})^2}$ (10.16)
```

```
$R^2 = 1 - \frac{\sum_{i=1}^n (A_i - P_i)^2}{\sum_{i=1}^n (A_i - \bar{A})^2}$ (10.17)
```

```
$MSE = \frac{\sum_{i=1}^n (A_i - P_i)^2}{n}$ (10.18)
```

```
$RMSE = \sqrt{\frac{\sum_{i=1}^n (A_i - P_i)^2}{n}}$ (10.19)
```

where $A_i, \bar{A}$ and $P_i$ represent the actual values, the average of actual values and predicted values, respectively, while $n$ represents the number of data.

### 10.4.1 DESCRIPTIVE STATISTICAL ANALYSIS

In this research, the estimation of the chosen parameters were made up of different sets of input and output variables as shown in Table 10.2. In addition, the degree and type of relationship between the influent and effluent was investigated using the correlation matrix and descriptive statistical analysis. R was evaluated to determine the extent of linear interaction between the influent and effluent variables. The concept of R is to predict a variable using a linear function that acts as a tentative indicator of a possible correlation between the set of variables. As presented in Table 10.3, the R-value in bold shows the statistically significant variables with a probability less than 0.05 (p<0.05). This indicates a high degree of linear correlation. Additionally, the R values with the negative sign suggests that the two variables have an inverse interaction between them. Furthermore, the weakness observed by R showed that it is important to apply more robust methods in complex modelling. The evaluation of R was also important in the pre-analysis of the data and generation of the data-driven models, since the directional sign (positive or negative) shows the relationship between the dimension and proportionality of the variables (dependent and independent).

As mentioned earlier, two different models based on dominant factors were generated to predict the ORP of the S. molecule treatment system. This could be better understood by considering the correlation matrix between the parameters as indicated in Figure 10.1.

The choice of two combinations is primarily focused on the analysis of linear sensitivity techniques. Several authors have noted the significance of applying the non-linear sensitivity input variables methods in determining the most critical factors (Hadi et al., 2019; Nourani & Sayah, 2012).

From Figure 10.1, the Spearman Pearson Correlation demonstrates how effectively a linear function can be used to explain the relationship between the water quality variables. The direction or the sign does not affect the strength of the correlation. In other words, a positive correlation implies that an increase in the first parameter is proportional to an increase in the second parameter, whereas a negative coefficient implies an inverse relationship, in which as one increases, the second parameter decreases (Abba et al., 2020; Ghali et al., 2020; Eisinga et al., 2013).

Except for ORPr and TEMPr in the case of TDS and TURBt, respectively, all the WO variables displayed unsatisfactory relationship with the target variables, although previous studies (Elkiran et al., 2019; Hadi et al., 2019) discouraged the application of classical linear input variable methods and suggested the use of non-linear methods.
