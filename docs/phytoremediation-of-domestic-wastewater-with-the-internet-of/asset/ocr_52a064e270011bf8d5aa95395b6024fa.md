In ANFIS technique, training of the models is independent of expert knowledge (Srisaeng et al., 2015).

# 8.7 ERROR ENSEMBLE LEARNING APPROACH

Ensemble learning is a ML technique used in improving the final performance of prediction through the integration of multiple homogeneous or heterogeneous models (Baba et al., 2015). This method gives precise results compared to single models when solving the problem. Ensemble techniques have been used in different areas such as regression and time series problems, clustering and classification and web ranking algorithm (Kazieno et al., 2013). The fundamental element of ensemble learning is the base learner, which is generated using a base learning algorithm. The general formula for ensemble learning is presented in Equation 8.3 (Kazieno et al., 2013).

```
P_{e}(x) = \sum_{i=1}^{n} p_{i}(x)
```

where $p(x)$ and $P_{e}(x)$ represent single predictor and ensemble with $n$ total number of predictors.
