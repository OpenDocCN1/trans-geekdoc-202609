# 8.3 ARTIFICIAL NEURAL NETWORK (ANN)

ANN is a mathematical model that is used to process information in a synaptic weight and brain-like learning process (Gaya et al., 2014). Generally, ANN comprises of tightly coupled units called neurons to analyse data in a manner comparable to the central nervous system (Hayder et al., 2014). Therefore, the development of ANN involves the collection and pre-processing of data, handling, network training and testing, data splitting, selection of inputs, activation function and learning algorithm (Abbraht et al., 2012). Furthermore, the activation function could be linear, hyperbolic tangent sigmoid, Gaussian or logistic depending on the selected learning algorithm and scaling technique (Bennett et al., 2013; Esfe, 2017). The most frequently used activation functions in water and wastewater quality monitoring are as hyperbolic tangent functions and logistic sigmoid, which can be calculated using the mathematical expressions given in Equations 8.1 and 8.2 (Maier & Dandy, 2000; Oyebode & Stretch, 2019). Additionally, ANN can be classified based on learning techniques as Levenberg-Marquardt (LM), back-propagation (BP), adaptive back-propagation, Bayesian regularization (BR) and gradient descent with momentum learning rate (Rajajee et al., 2019). In some circumstances, when compared to other models, ANN models trained using LM learning methods are faster (Senthil Kumar et al., 2013). Additionally, ANN can be applied in novel paradigms for function approximation owing to its great characteristics of adaptability, improved input and output mapping, fault tolerance, nonlinearity and self-learning (Aiboun et al., 2018).
