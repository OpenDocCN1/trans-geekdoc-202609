# 10.2.4 CONCEPT OF SUPPORT VECTOR MACHINE (SVM)

In this study, the model prediction was generated using SVM. Additionally, the two models were trained using cubic, linear, fine Gaussian, polynomial, coarse Gaussian and medium Gaussian kernel with a cross-validation of 10. After 100 iterations, it was discovered that the fine Gaussian kernel resulted in the optimum fit model for predicting the effluent water quality. For a given set of training data $\{(x_i, d_i)\}$, $(x_i$ is the input vector, $d_i$ is the actual value and $N$ is the total number of data patterns), the general SVM function is given in Equations 10.2–10.7.

```
$y = f(x) = w\phi(x) + b$
```

```
$Minimize: \frac{1}{2}\|w\|^2 + C\left(\sum_{i=1}^{N}(\xi_i + \xi_i^*)^2\right)$
```

```
$Subject to: \begin{cases} w\phi(x_i) + b_i - d_i \le \varepsilon + \xi_i^* \ d_i - w\phi(x_i) + b_i \le \varepsilon + \xi_i^* \ \xi_i, \xi_i^* \ge 0 \quad i=1, 2, ..., N \end{cases}$
```

```
$w^* = \sum_{i=1}^{N}(\alpha_i - \alpha_i^*)\phi(x_i)$
```

The final form of SVM can be expressed as:

```
$f(x, \alpha_i, \alpha_i^*) = \sum_{i=1}^{N}(\alpha_i - \alpha_i^*)K(x, x_i) + b$
```

```
$k(x_1, x_2) = \exp(-\gamma||x_1 - x_2||^2)$
```

where $\gamma$ is the kernel parameter.
