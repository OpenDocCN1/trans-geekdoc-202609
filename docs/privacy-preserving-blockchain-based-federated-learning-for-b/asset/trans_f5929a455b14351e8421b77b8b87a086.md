
联邦学习中，每个用户 \( u \in U \) 都拥有自己的私有数据集样本。

```
\( F_l(w) = \frac{1}{|D_i|} \sum_{j \in D_i} f_j(w; x_i, y_i) \) (2)
```

一个全局损失函数 \( f_j(w; x_i, y_i) \) 用于最小化数据集 \( D \) 中多家医院的权重。为了处理参与客户端之间的统计异质性，将近端项作为局部子问题添加到每个客户端的优化中，以有效限制发散的局部变量更新的影响，如下所示：

```
\( F_i(w; w^t) = \frac{1}{|D_i|} \sum_{j \in D_i} f_j(w; x_i, y_i) + \frac{\mu}{2} \|w - w^t\|^2, \) (3)
```

其中 \( w^t \) 是最新的全局参数更新，\( \mu \) 是近端项的缩放参数。

全局模型函数 \( F(w) \) 定义为每家医院估计值与实际值之间的差异，表示为 \( f_j(w; x_i, y_i) \)。

```
\( F(w) = \frac{1}{|M_I|} \sum_{l \in I} u_l \cdot F_l(w) \)
\( = \frac{1}{|M_I|} \sum_{l \in I} \sum_{j \in D_i} u_l \cdot \frac{f_j(w; x_i, y_i)}{|D_i|} \) (4)
```

其中 \( i \) 表示来自画廊 \( I = 1, 2, \dots, n \) 的样本 \( (x_i, y_i) \)，\( n_i \) 表示医院的独立数据集模型数量。在我们提出的训练方法中，我们通过迭代最小化与全局模型相关的损失函数来提高模型的准确性。

### 2.2. 区块链背景

为工业 4.0 训练有效的 AI 模型需要从多个来源收集数据，同时不损害隐私。为了对用户进行身份验证，区块链网络是必不可少的。在中央服务器上的联邦学习中仍然存在一些挑战，例如激励不足和中毒攻击的风险。为了解决这些问题，一些作者，例如 Lu 等人 [39] 和 Qu 等人 [40]，已利用区块链来保护联邦学习数据。Choi 和 Pokhrel [41] 设计了一种使用区块链保护联邦学习隐私的技术。然而，以前研究的一个主要问题是未能包含用于保护模型参数的加密和掩码技术。因此，我们将联邦学习与区块链分布式账本相结合，用于安全的数据共享，并利用来自不同医院的数据更新全局 AI 模型。区块链技术的主要优势是其能够收集不同节点的数据模型并聚合本地模型和全局模型。智能合约用于上传权重并更新模型。我们提出的架构无缝结合了区块链技术的优势与联邦学习的能力，从而构建了一个具有增强安全措施的完全去中心化系统。这种去中心化方法不仅提高了模型的精度，还在参与实体之间培养了更高的信任度。

### 3.2. 用于模型广播的联邦学习

首先，我们介绍了训练本地模型和全局模型的算法。算法 1 展示了使用其数据集训练第 \(i_{th}\) 个本地模型的伪代码，该算法在本地客户端机器上独立运行。基本符号的定义在表 1 中给出。

联邦学习算法用于训练分布式医院数据集的我们的模型。 _H_ 家医院正在合作使用每家医院的私有数据训练全局模型，且不会发生数据泄露。每家医院 \(H_i\)，\( i \in \{1, ..., n\} \)，其中 _n_ 表示医院数量，拥有一个本地数据集 _D<sub>i</sub>_，每个预训练模型有 _X<sub>i</sub>_ 个计划训练样本。各家医院本地模型的损失权重，受模型权重 _w<sub>i</sub>_ 约束，计算如下

```
L(w, D) = \frac{\sum_{i=1}^n L_i (w_i, D_i)}{n}, \tag{6}
```

多家医院针对训练好的全局模型发送区块链账本请求，区块链节点会自动调整不同时间接收反馈的医院数量。控制 _n_ 个请求的函数表示如下：

```
n = \gamma C, \tag{7}
```

其中 _C_ 表示系数，\(\gamma\) 是系数阈值。因此，_n_ 表示控制区块链网络的多家医院（参见图 1）。

使用以下公式，本文通过降低损失函数的值来优化目标函数，以加快模型收敛：

```
w^* = \min L(w) \tag{8}
```

为了在 _H_ 家医院之间共享权重向量，我们采用秘密 _s_ 共享技术。在第一阶段，它生成一个 _m_-1 次多项式，其中 \(\beta(0)\) 是要共享的密钥。这确保每家医院不会生成自己的随机数 \(B_1, B_2, ..., B_{m-1}\)。各家医院只需将 \(s_1 = \beta(1), s_2 = \beta(2), s_3 = \beta(n)\) 发送给 \(H_1, H_2, ..., H_n\)。 _m_ 和 \(\beta(1), \beta(2)...\beta(n)\) 可以一起求解，_m_-1 不是 _s_ 的正确解。Shamir 引入了同态加密来共享密钥 [42]。其中 \(\beta(d)\) 的计算如下

```
\beta(d) = s + \beta_1 d + \beta_2 d^2 + \cdots + \beta_{m-1} d^{m-1} \mod p \tag{9}
```

为防止访问每家医院的私有数据集，我们实现了一种动态密钥共享方案。密钥的时间组件被分成多个部分，每个碎片部分在初始时被更新。每家医院在时间 _t_ 的分布式全局模型快照实例记录在区块链账本 \(s'_i\) 中。

联邦学习聚合各家医院训练的本地模型参数。除了聚合本地模型权重 _w_ 外，我们还采用随机梯度下降和批量梯度下降算法来优化损失函数，以确保全局模型的收敛。为防止数据泄露并增强数据安全性，实现了秘密密钥共享技术来掩码模型参数。
