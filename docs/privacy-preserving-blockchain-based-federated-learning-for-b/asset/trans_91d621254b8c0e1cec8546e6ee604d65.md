每家医院从区块链网络请求全局模型，然后使用其关联的本地数据和本地模型实例。深度学习模型使用随机梯度下降，其中在指定数据下模型的梯度为 $g_i$，权重为 $w_i$。联邦学习模型聚合每家本地医院模型的权重，并在不泄露数据隐私的情况下更新本地模型。

所提出的模型分为三部分：(i) 模型训练，(ii) 模型数据共享，以及 (iii) 模型掩码和上传。

- 1. **模型训练**：每家医院使用相同的模型采用 CNN 神经网络训练全局模型。然而，为了节省时间和内存资源，我们不会从零开始训练神经网络模型。为了降低通信开销，梯度不会直接上传到区块链。相反，医院共享其梯度，然后对梯度进行聚合，以进一步训练最新的模型权重 $w_i$。此外，训练过程分为两部分。在第一部分中，每家医院共享其模型信息。然后区块链根据数据质量验证医院的模型。在第二阶段，联邦学习平均算法聚合权重，并将更新后的权重随后发送到本地模型。

- 2. **模型共享**：为了提高每家医院的模型质量，多家医院在区块链网络中共享其模型以增强模型质量。然而，医院采用差分隐私共享模型，以实现医院之间安全共享模型的方式。假设使用两个相似的数据集 D 和 $\hat{D}$，它们之间仅差异一个数据实例，映射函数 $f : f(D) = (z_1, z_2, ..., z_d)^T$，其中 $D \rightarrow R^d$ 用于显示向量空间与数据集之间的关系。为保护数据集添加噪声，我们使用 Laplace 函数 $Laplace(\frac{\Delta f}{\epsilon})$，其中输出函数 $f$ 定义为如下的 $A(D)$：$A(D) = f(D) + \left( Laplace_1(\frac{\Delta f}{\epsilon}) \cdot Laplace_2(\frac{\Delta f}{\epsilon}) \right)$ (11) 其中 $\Delta f$ 定义如下 $\Delta f = \max_{D,D'} \| f(D) - f(D') \|_c,$ (12) 其中 $\Delta f$ 确认双方且 $c$ 取为 1 $P_r[A(D) = O] \le e^\epsilon * P_r [ A ( D' ) = O ]$ (13)

算法 1 显示了保护隐私的模型，其中医院在数据集中添加掩码；然后区块链节点根据其权重更新医院模型。区块链网络向模型添加掩码噪声，其中 $t$ 表示时间槽，掩码定义为 $\{\vec{g^i_1}, \vec{g^i_2}, ..., \vec{g^i_n}\}$。对于每家医院，更新权重的收敛函数是将 $\{\vec{g^i_1}, \vec{g^i_2}, ..., \vec{g^i_n}\}$ 映射到 $\{w^i_1, w^i_2, ..., w^i_j, ..., w^i_n\}$。然而，每个数据集及从其他医院接收的其他权重如下所示：

$$\vec{g^i_r} \leftarrow \frac{1}{n} \sum_{j=1}^n \left( \vec{g^i_j}(d_i) + Laplace\left( \frac{\Delta f}{\epsilon} \right) \right)$$ (14)

基于本地模型准确性，区块链网络可以拒绝来自低准确性本地模型的权重上传。通过这种方式，全局模型聚合具有最佳准确性的模型的权重，以构建更好的模型。全局模型不会接受低准确性模型或恶意模型，因为这些模型会影响全局模型的性能。

## 4.2. 用于信任的委员会区块链共识机制

每家医院将本地模型广播到区块链账本并请求全局模型。所有本地模型在区块链网络中聚合。以下是计算模型信任的步骤：

- 1. 根据其他收集的模型验证本地医院模型的训练。
- 2. 计算本地模型与其他模型集之间的准确性。
- 3. 模型的准确性计算如下
  \(\rho_b^t = \left( 1 + \frac{\sum_{R \in R} (A_b - A_j)}{|B| - 1} \right)\)
- 4. 当前或本地医院模型可以计算信任。它基于历史信任值更新模型：计算如下 \(S_{R_b}^t = \frac{1}{1 + e^{-\alpha(S_{R_b}^{t-1} - \rho_b^t)}}\)
- 5. 计算信任后，将根据模型的准确性给予奖励。

奖励的计算过程如下：

- 1. 区块链根据训练准确性更高的模型验证信任值。如果该值验证某个阈值，则模型将被发布；否则被拒绝。
- 2. 奖励范围为 0 到 1，对偏差率较高的模型给予更高信任的奖励，同时对偏差率较低的模型给予较少信任的惩罚。
- 3. 计算过程计算如下：
  \(S'_{R_k^i} = \begin{cases} S'_{R_k^i} - \frac{\eta_i e^{A_i}}{\sum_{i=1}^n \eta_i e^{A_i}}, & 0 < \beta < 1 \\ S'_{R_k^i} + \frac{\eta_i e^{A_i}}{\sum_{i=1}^n \eta_i e^{A_i}}, & 1 \le \beta \end{cases}\)
- 4. 最后，我们按如下方式计算信任值评估：max \(\left( S_{R_b} = [\max_{b \in B} S_{R_b}^k (\alpha, \rho_b^t)] \right)\)

可信度模型确保消息按时且无错误地传送，从而促进各方之间的有效通信。可靠性通过比较传输的数据包数量与确认已接收的数据包数量来确定。此外，我们考虑节点选择过程以增强模型的可靠性。步骤如下：

- 1. 节点的初始位置为 (x0, y0)，且 k = 1
- 2. 为网络区域内的目标位置 (xk, yk) 从 [smin, smax] 中选择速度 sk；然后节点以恒定速度 sk 在 (x0, y0) 和 (xk, yk) 之间移动。
- 3. 如果启用暂停功能，节点将暂停一段时间 (tRP)，暂停时间取自具有密度函数 (f p(t)) 的分布。
- 4. 增加 k+1 并转到步骤 2

## 5. 安全性分析与性能分析

### 5.1. 安全性分析

通过利用许可型区块链架构，为各种医疗机构之间的协作建立了一个去中心化且安全的框架。区块链共识机制与联邦学习技术的集成，有效地缓解了关于信任、潜在安全漏洞以及敏感患者信息机密性的担忧。

- 1. **确保差分隐私**：为了保护用户隐私，我们提出的协议保证生成的值与随机生成的值不可区分。选择一个随机向量来创建密文 wii，其中 K 作为安全参数以确保与随机值不可区分。然后，多项式 \(\widetilde{w}_i\) 用于基于这些随机值计算 Hi。
- 2. **数据访问**：所提出的技术结合联邦学习和区块链技术，其主要目标是保护数据隐私。该模型通过结合加密技术和区块链来确保数据隐私，从而保证数据的保护。
- 3. **模型权重的安全聚合**：区块链和本地模型客户端通过以下步骤协作，以确保权重聚合过程的安全性：
  - (a) **初始化**：首先，建立安全算法为模型生成必要的公共参数。
  - (b) **加密**：客户端定义参数对 (i, m)，其中 i 表示实体的索引，m 表示明文消息。然后将加密值 Enc(i, m) 返回到模型。
  - (c) **迭代妥协**：模型纳入 i 实体，聚合模型释放密钥 SKc。此阶段迭代多次。
  - (d) **单次挑战**：此步骤在整个过程中仅允许一次。对于每个 i ∈ K，生成并发送两个明文消息 m1 和 m2。如果位等于 0，则计算 ci = Enc(mi)。否则，以相同方式执行加密，并发送 ci。
  - (e) **最终预测**：该过程的输出为 1 或 0。
- 4. **消除对集中式信任的需求**：通过利用区块链技术的去中心化特性，医院可以在不依赖中介或第三方信任的情况下开展协作。
- 5. **安全数据管理**：仅受信任的数据提供者向网络上传数据以确保模型的可靠性。此外，加密算法保证数据的安全性。
- 6. **确保共享模型的完整性**：系统采用的共识机制用于验证学习过程中使用的数据的质量和可靠性，从而保障生成模型的完整性。
