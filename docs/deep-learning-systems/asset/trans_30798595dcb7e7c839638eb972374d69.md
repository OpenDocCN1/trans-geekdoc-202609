
## 嵌入

嵌入（也称为编码或思想向量）是数据样本的低维稠密向量表示。它通常用作语言或推荐模型的输入。嵌入层将高维稀疏数据映射到嵌入。为说明目的，假设一个词典有 10,000 个词。10,000 维向量中除对应索引处为一外其余全为零，表示一个词。这称为独热向量。无监督学习算法，例如 `word2vec` 或 `GloVe`，可以学习将词语料库映射到低维稠密表示 \[MSC+13, PSM14\]。其他用途是为社交网络中的人或大型目录零售业务中的产品学习稠密表示。在图像中，`CNN` 模型的最后一层或倒数第二层的激活通常用于嵌入图像。

## 2.8 注意力

注意力层学习输入向量如何影响每个输出向量，如 [图 2.12](#12_Chapter02.xhtml#fig2-12) 所示。某些注意力层还捕捉邻近输出向量之间的相互影响。注意力层在语言模型中很受欢迎，用于确定输入和输出词元之间的关联 \[VSP+17\]。词元是一个词、一个子词或一个符号，例如问号。注意力层在计算上可能很昂贵，因为每一层可能需要为每种输入和输出词元的组合计算一个注意力值。这种额外的计算可能会使某些工作负载的服务延迟增加到超出给定应用可接受的范围。尽管如此，使用注意力层可以提高统计性能。

注意力层还用于某些推荐器中，以学习捕捉用户之间影响的上下文向量。它们还用于图像描述，以使解码器专注于图像的相对部分 \[CZZ+19, YHG+15\]。注意力可以提高可解释性。注意力层可用于观察和解释输入特征如何影响特定输出。

## 2.9 Dropout

Dropout 设计用于减少过拟合，并且可在全连接非循环层中使用。在训练期间，层中一定百分比的权重在一次迭代中被忽略（丢弃），如 [图 2.13](#12_Chapter02.xhtml#fig2-13) 所示。在每次迭代中，随机忽略一组新的权重，这通过减少权重之间的合作来减少过拟合。在推理期间，所有权重都使用。

`RNN`-based 模型可以在嵌入层之后以及 `RNN` 堆栈之间使用 dropout。虽然如果在所有时间步中丢弃同一组权重，则 dropout 可以跨时间单元使用，但通常不使用。`CNN`s 层通常不使用 dropout，因为这些层本身权重就很少。

在实践中，归一化技术更常用于减少过拟合，较新的模型不使用 dropout。根据经验评估，归一化和 dropout 不应联合使用，因为它们会产生负面的收敛影响 \[LCH+19\]。

### SLIDE

`SLIDE` 是 dropout 的扩展 \[CMF+20\]。在 dropout 中，权重是随机丢弃的。在 `SLIDE` 中，产生小激活的权重被丢弃。`SLIDE` 中丢弃权重的百分比可以为 90–95%，而在 dropout 中通常为 50%。因此，在每次训练迭代中只有最相关的权重得到更新。`SLIDE` 解决的挑战是预测哪些权重向量会产生大激活。`SLIDE` 使用局部敏感哈希（`LSH`）来选择与输入激活向量相似的向量权重。

`SLIDE` 对 `CPU` 有亲和性，主要有两个原因。首先，`LSH` 依赖于分支，而 `CPU` 在这方面经过了很好的优化。其次，`LSH` 表需要很大的内存容量，这也更有利于 `CPU`。正在进行研究以使哈希在 `GPU` 上更高效 \[AFO18\]。

与 dropout 类似，`SLIDE` 主要对具有许多单元的全连接、非循环层有益，因为这些层通常过度参数化并且可以被大量稀疏化。特别是对于极端分类任务（常见于推荐系统）中进入 `softmax` 层的仿射层，其中 `softmax` 具有数十万个单元。与 dropout 类似，联合使用 `SLIDE` 和归一化不被推荐。最后，`SLIDE` 相对较新，尚未在生产环境中采用。需要进一步的工作来促进采用。

在本章中，我们详细介绍了商业应用中使用的拓扑的标准构建块并解释了其目的。这些构建块或层具有不同的硬件需求。通常，嵌入层需要大内存和内存带宽，卷积层需要大量计算，而循环层需要大量内存带宽。我们引入了图的概念，其中节点和边作为拓扑的表示。一种标准的图优化技术，详细说明在 [第 8 章](#18_Chapter08.xhtml) 中，是将密集线性节点，如 `GEMM` 和卷积，与逐元素节点，如 `ReLU`，合并以减少内存访问并提高性能。我们建议当批量大小大于或等于 32 时对非循环层使用 `batch normalization`，否则使用 `group normalization`。此外，归一化优于 dropout，并且两者不应联合使用。在下一章中，我们将讨论由这些构建块组成的奠基性拓扑及其在超大规模公司中的应用。

# 第 3 章

## 模型与应用

`DL` 模型在生产中使用的主要工作负载类型是推荐系统、计算机视觉和 `NLP`。

推荐系统通常是超大规模公司中最普遍的模型类别，因为它们产生的收入显著。神经（`DL`-based）推荐器通常有两个主要组件：嵌入层和 `NN`，通常是 `MLP`。嵌入层将高维稀疏数据映射到低维稠密数据。例如，一个电影推荐器可能有一个包含 1 亿用户的数据库，每个用户对 10,000 部可用电影中的几部进行评分。该数据集是稀疏的，因为大多数用户只观看电影的很小一部分。嵌入层将这种稀疏表示映射为稠密表示，然后传递给 `MLP`。标准的推荐模型是 `Wide &Deep` (`W&D`)、神经协同过滤（`NCF`）、深度与交叉网络（`DCN`）、深度兴趣演化网络（`DIEN`）和深度学习推荐模型（`DLRM`），在 [第 3.1 节](#13_Chapter03.xhtml#sub3-1) 中介绍。

计算机视觉模型具有多个卷积层，通常随后是归一化函数，例如 `batch normalization`，和非线性激活函数，例如 `ReLU`。标准的计算机视觉模型是 `Inception`、`ResNet`、`MobileNet`、`UNet`、`Mask-RCNN`、`SSD`、`YOLO`、`DCGAN` 和 `StyleGAN`，在 [第 3.2 节](#13_Chapter03.xhtml#sub3-2) 中介绍。
