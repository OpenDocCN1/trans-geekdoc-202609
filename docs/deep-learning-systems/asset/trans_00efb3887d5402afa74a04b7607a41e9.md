# 前言
书中许多概念相互依赖，并且经常以迭代的方式引入，并引用详细阐述该概念的章节。如果你是该领域的新手，请完整阅读导论章节以及每章的引言部分和结尾段落，以把握一些关键要点。然后再回头完整阅读每一章。线性代数、微积分、编程、编译器和计算机体系结构方面的背景知识对某些部分可能有帮助，但不是必需的。本书的组织结构如下：

[第1章](#11_Chapter01.xhtml) 从对书中详细阐述的核心概念的介绍开始。我们回顾深度学习（DL）的历史和应用。我们讨论在多个领域工业界和学术界采用的各种拓扑类型。我们还提供了一个训练简单 DL 模型的示例，并介绍了一些架构设计考虑因素。

[第2章](#12_Chapter02.xhtml) 涵盖生产中使用的模型的构建模块。我们描述这些构建模块中哪些是计算受限，哪些是内存带宽受限。

[第3章](#13_Chapter03.xhtml) 涵盖受益于 DL 最多的应用、工业界采用的主流模型，以及未来几年可能被商业采用的学术趋势。我们回顾推荐系统、计算机视觉、自然语言处理（NLP）和强化学习（RL）模型。

[第4章](#14_Chapter04.xhtml) 涵盖领域专家为成功采用 DL 算法应遵循的训练流程。我们回顾数据科学家采用的拓扑设计考虑因素，例如权重初始化、目标函数、优化算法、使用有限数据集训练、处理数据不平衡以及在有限内存下训练。我们还描述了训练模型的反向传播算法背后的数学细节。

[第5章](#15_Chapter05.xhtml) 涵盖在数据中心和边缘设备（称为联邦学习）中采用的分布式算法。我们讨论数据并行和模型并行方面的进展和挑战。我们还回顾通信原语和 `AllReduce` 算法。

[第6章](#16_Chapter06.xhtml) 涵盖生产和学术界中使用的较低数值格式。这些格式相对于标准 32 位单精度浮点数可以提供计算性能优势，有时以较低的统计性能（准确性）为代价。我们还讨论进一步减少内存占用量的剪枝和压缩技术。

[第7章](#17_Chapter07.xhtml) 涵盖硬件架构设计。我们回顾计算机体系结构的基础、计算能力增长放缓的原因以及部分缓解这种放缓的方法。我们解释屋顶线模型以及用于服务和多节点训练的重要硬件特性。我们还讨论 CPU、GPU、CRGAs、FPGAs、DSPs 和 ASICs 及其优缺点，以及市场上或正在开发的知名 DL 处理器和平台。

[第8章](#18_Chapter08.xhtml) 涵盖高级语言和编译器。我们回顾语言类型并解释编译过程的基础。我们讨论将程序转换为 `LLVM` 内部表示（`IR`）的前端编译器以及 `LLVM` 后端编译器。我们还描述了 DL 工作负载的标准编译器优化传递。

[第9章](#19_Chapter09.xhtml) 涵盖框架和 DL 编译器。我们详细回顾 TensorFlow 和 PyTorch 框架，并讨论正在开发的各种 DL 编译器。

[第10章](#20_Chapter10.xhtml) 以对未来机遇和挑战的展望作结。我们讨论利用机器学习算法推进 DL 系统栈各个部分的机遇。我们讨论一些挑战，例如安全、可解释性和这些系统的社会影响。我们还提供一些结论性意见。
