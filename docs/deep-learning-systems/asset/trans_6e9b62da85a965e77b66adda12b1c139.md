
基于模型的算法使用包含其环境规则的模型。智能体使用该模型推断各种动作集合的结果，并选择奖励最大的集合。基于模型的算法用于像国际象棋和围棋这样的游戏中，在这些游戏中游戏规则是已知的。DeepMind 的 AlphaGo、AlphaGo Zero、AlphaZero 和 MuZero 使用基于模型的算法 \[SHM+16, SSS+17, SSS+18, SAH+20\]。通过试错学习模型会引入偏差，并且推断结果中的误差会在预测时域内累积。基于模型的策略优化（`MBPO`）使用模型与策略优化相结合来缓解累积误差 \[JFZ+19\]。

在本章中，我们详细介绍了超大规模计算公司中通常使用深度学习模型的 workload 类型：推荐系统、计算机视觉和自然语言处理。我们讨论了在这些 workload 中使用的常见拓扑结构。尽管在学术界的采用率最低，但顶级超大规模计算公司广泛使用推荐模型。我们强调了强化学习中可能很快转向商业应用的热门学术趋势。在下一章中，我们回顾如何训练拓扑结构，包括数据科学家如何利用现有拓扑结构来指导相关应用的拓扑设计。

## 训练模型

在计算和功耗预算内训练模型以实现高统计性能需要考虑多个设计因素。这些包括定义拓扑结构、准备数据集、正确初始化模型权重、选择优化算法和目标函数、减小模型大小以及评估训练好的模型。训练过程可能在计算和内存方面都很密集，本章和接下来的两章中讨论了一些技术来减少训练时间并缓解内存瓶颈。

在[第1.6节](#11_Chapter01.xhtml#sub1-6)中，我们介绍了训练步骤。当验证误差小于某个阈值或在多次迭代后不再继续下降时，训练停止。验证误差每 `n` 次训练迭代计算一次，其中 `n` 由数据科学家选择。它被用作衡量模型部署后性能的指标。

在反向传播步骤中，计算得到的梯度提供了每个权重对成本贡献的度量。术语 cost、loss、penalty、error 和 objective function 有时可以互换使用。在本书中，`loss` 表示单个数据样本的期望输出与实际输出之间差异的度量，而 `cost`、error 和 objective function 同义地表示一批样本的损失之和。常见目标函数的例子分别是用于分类和回归任务的交叉熵误差（在[第4.4节](#14_Chapter04.xhtml#sub4-4)中讨论）和均方误差（`MSE`）。

### 4.1 从训练到生产数据集的泛化

设计良好且训练有素的模型在训练期间未使用过的生产数据上具有良好的性能。也就是说，模型能够从训练数据集泛化到生产或测试数据集。具体来说，模型在训练集和测试集上都有较低的错误率。相反，测试错误率高的模型不可靠。在本节中，我们描述了高测试错误率的来源，具体包括欠拟合、过拟合和尖锐最小值，以及如何减少这种误差。红色点代表模型的预测。

![image](images/fig4_1.png)

图4.1：（a）四个训练样本（蓝色点）和一个验证样本（绿色点）。（b）四阶多项式函数训练误差为零但验证误差很高。（c）更简单的 first-order 多项式函数验证误差较低。红色点代表模型的预测。

欠拟合发生在模型太小、学习能力不足，无法正确学习数据的一般特征时。欠拟合的症状是训练误差高和测试误差高。缓解欠拟合的最佳技术是使用更复杂的模型。在深度学习中，这意味着通过添加更多层和更多权重来增加拓扑的表征能力。

过拟合发生在模型学习能力过强，学习到训练数据样本中的噪声或训练集特有的其他特征时。当使用训练样本不足的庞大模型时就会发生过拟合。过拟合的症状是训练误差低而测试误差高。[图4.1](#14_Chapter04.xhtml#fig4-1)使用线性回归——一种简单的机器学习算法——通过一个玩具1D示例说明了过拟合。[图4.1a](#14_Chapter04.xhtml#fig4-1)显示了四个训练样本（蓝色点）和一个训练期间未使用的验证样本（绿色点）。x轴是一个特征，例如房屋大小，y轴是标签，例如房屋价格。三阶或更高阶的多项式函数可以完美地穿过四个训练数据点。该插图使用四阶多项式以便简单可视化。[图4.1b](#14_Chapter04.xhtml#fig4-1)显示模型没有训练误差但验证误差更高（红色点和绿色点之间的平方距离）。更简单的 first-order（仿射）函数不能完美地穿过所有训练数据点，但验证误差较低，如[图4.1c](#14_Chapter04.xhtml#fig4-1)所示。红色点显示每个模型对验证样本的预测，绿色点是该样本的真实值。复杂模型过拟合了训练样本；与更简单的模型相比，它训练误差为零但验证误差很高。因此，在此示例中，更简单的模型更受青睐。

[图4.2](#14_Chapter04.xhtml#fig4-2)说明了随着模型复杂度的增加，训练误差和验证误差会发生什么变化。随着复杂度的增加，训练误差会下降，而验证误差先下降后上升。虚线左侧复杂度的模型欠拟合，虚线右侧复杂度的模型过拟合。最佳点就在虚线上，此时模型验证误差最低。该模型足够复杂以学习数据的特征从而避免欠拟合，又足够简单以避免过拟合。

![image](images/fig4_2.png)

图4.2：模型复杂度的理想水平是验证误差最低的地方。

验证误差比训练误差重要得多，因为它代表模型在生产中部署时的预期误差。在机器学习理论中，最小化这些误差被称为偏差-方差权衡。高训练误差表示高偏差或欠拟合。高验证误差和低训练误差表示高方差或过拟合。在开处方之前，始终必须确定性能不佳的来源（过拟合或欠拟合）。
