
矩阵运算算子计算密集型，且（取决于硬件和数据重用量）可能受计算限制（在某些GPU文献中称为Math bound）。逐元素算子计算轻量且受内存带宽限制。这些函数的输入从内存中读取，结果写回内存；没有数据重用。

提高模型计算效率的常见技术是将计算轻量的逐元素算子融合到计算密集型的矩阵运算算子中。因此，中间结果不会写入主内存再读回。逐元素计算在矩阵运算计算之后立即进行，此时数据仍在寄存器或靠近计算单元的存储中。[第8章](#18_Chapter08.xhtml)详细介绍了这一技术以及通过软件优化提高效率的其他技术。

在本章和下一章中，我们采用自底向上的方法。本章介绍在超大规模企业中流行模型使用的标准原语。下一章讨论使用这些原语构建的实际模型和应用。喜欢自顶向下方法的读者可以先阅读[第3章](#13_Chapter03.xhtml)，以便在深入本章的构建块之前更好地了解模型和应用的类型。回顾[第1.10节](#11_Chapter01.xhtml#sub1-10)中引入的记号有助于理解本章中呈现的方程。

## 2.1 激活函数

激活函数是对层输入张量的每个元素应用的非线性函数。最流行的激活函数是整流线性单元（ReLU）。ReLU函数及其梯度计算成本低。一些模型在使用ReLU函数时收敛更快\[KSH12\]。ReLU还增加了稀疏性，这可能带来计算和内存节省\[GBB11\]。

ReLU的主要缺点是负激活的梯度为零，对应的权重在反向传播期间不会改变。这被称为死亡ReLU，并促使了ReLU的变体，例如Leaky ReLU（LReLU）、参数化ReLU（PReLU）、缩放指数线性单元（SELU）以及在某些基于注意力的模型中采用的高斯误差线性单元（GELU）\[HZR+15, KUM+17, HG16\]。另一个变体是ReLU6，它将最大ReLU输出限制为6，并且在使用小数值表示时可能改善统计性能。这些变体并不总是带来更优的统计性能，需要通过实验来评估其益处。

`k`-胜者通吃（`k`-WTA）激活函数保留层中最大的`k`个激活值，其余置零。通常为每个层选择不同的`k`以在各层间保持恒定的稀疏比率，例如80%\[XZZ20\]。

sigmoid和双曲正切（tanh）激活函数，如[图2.1](#12_Chapter02.xhtml#fig2-1)所示，常用于RNN模型。它们的主要缺点是对于大正或负激活，梯度非常小。在反向传播期间，各种小梯度的乘积由于计算机中有限的数值表示而导致值消失。这被称为梯度消失问题。较不易受梯度消失影响的RNN模型变体在[第2.5节](#12_Chapter02.xhtml#sub2-5)中讨论。

双曲正切相对于sigmoid函数的一个好处是它保持零均值分布。除非期望输出是概率分布，否则应优先使用它而不是sigmoid。sigmoid函数通常用作二元分类输出层的激活函数，因为输出在0到1之间，可以表示概率。

## 2.3 卷积

卷积核（通常称为滤波器）在计算机视觉中被广泛采用，并与2D图像、3D体素图像（如MRI扫描）以及3D时序图像或视频一起使用。对于输入值中存在与空间或时间邻近性相关关联的任务，例如图像、视频和频谱图（在[第2.4节](#12_Chapter02.xhtml#sub2-4)中讨论），可以使用卷积核。

卷积在DL和信号处理文献中的含义不同。DL文献中使用的卷积算子，以及本书中使用的，是权重与输入激活（卷积层输入值）之间的互相关算子。每个卷积输出值是滤波器与输入子集的点积。整个卷积输出通过将该滤波器在输入的所有子集上滑动来计算。
