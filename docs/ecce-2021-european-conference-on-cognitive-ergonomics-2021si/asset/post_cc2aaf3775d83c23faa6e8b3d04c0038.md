# ABSTRACT

The concept of creativity is an important part of human society and the continuous evolution of artificial society has raised questions about creativity among machines. The aim of this study is to explore machine learning algorithms' ability to be creative. This paper presents a survey of music generated by IBM Watson that have been evaluated using expert consensus and control samples. The results show that one of the machine generated samples showed the same level of creativity as the human generated samples. Here, there are indications that machine learning algorithms can create music that is hard to distinguish from human created music and can be considered creative.

## 2.1 Machine Learning

There are plenty of problems in software development that are characterized by the fact that the algorithm for something are unknown [2]. We know the desired output from our given input data but lack the ability to formally satisfy the required steps to derive such an answer from data. This machine learning is produced by the construction of programs that learn characteristics from data and exploit them to produce the desired output. This process is often called enough (application) depth which output is usually referred to as learning [2]. There are plenty of approaches to machine learning and a wide range of different domains.
