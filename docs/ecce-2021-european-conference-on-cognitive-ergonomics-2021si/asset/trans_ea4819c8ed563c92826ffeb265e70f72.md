## 2.5 Watson Beat

Watson Beat [5] 是 IBM 研究实施的 IBM [14] 项目的一个分支。它是一种机器学习算法，在音乐样本上进行训练后，可以根据建议引擎产生独特的曲目。在底层，Watson Beat 由一组用于读取和输出 MIDI 文件的受限玻尔兹曼机组成 [13]。

## 3 方法

本研究将利用一种在创造力研究中建立的方法 [3]，并在 1.1 节中简要说明。该方法基于一种观点，即“创造性”在于提取从设计中观察到的创造力。Amable [3] 使用了这种方法，通过多位专家评估艺术作品的创造力。评判员是一群具有5年经验的画室艺术家。本研究也旨在模仿 Amable [3] 的研究。本研究使用的评委目前担任音乐教师，且被认为是音乐和音乐创作领域的专家。

### 3.1 参与者

本研究使用了 51 位领域专家。如前所述，这些专家都曾或目前是某种形式的音乐教师。大多数参与者（71.7%）在当前位置工作了至少10年。在被问及音乐工作的总经验时，58.5% 的人表示他们拥有超过40年的音乐评分经验。51位参与者中的每一个人在某种风格上都至少有10年的音乐工作经验。

## 3.2 实现

为了提高质量，研究通过在线问卷进行了定量分析。问卷包含四种不同类型的器样本。两个样本由人类创建，两个由 Watson Beat 创建。评委被要求在 1-6 分的量表上单独对四个片段中的每个片段进行创造力评分（1=完全没有创造力，6=非常有创意）。为了避免某些偏见 [7]，没有使用偶数尺度。除了对作品评分外，还允许以自由文本格式解释评分。为了防止评委产生偏见，未提供样本创建的背景信息。使用 MATLAB 对收集的数据进行了统计分析。整个研究于 2018 年春季进行。
