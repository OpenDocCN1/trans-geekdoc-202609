# # DISCUSSION

Before getting into the interpretation and implications of these results we will spend some time discussing the methodology and its effect on the result. Due to the relatively large number of participants, it is reasonable to believe that the statistical analysis provides enough

Factors that may have influenced our result is one of even numbered scale. As already mentioned one member providing neutral answers. The fact of this course is that we had a majority of the users who did not express any creativity. In this kind of study it is likely that some people would have been tempted to provide neutral results in order as not to outdo composer of the sample.

Since the samples were not that created using machine learning algorithms, this could have no effect. Our choice is motivated by the fact that the preconceptions about the creative abilities of machine learning algorithms otherwise have influenced the result.

The scope of this study is limited due to the number of samples. It is not possible to make a reliable statement about all machine learning algorithms or whether they are less creative as humans. The only thing that we can state is that the specific algorithm used can produce musical pieces, that it shows the level of creativity as sample created by humans.

# # 5.1 Conclusions and future research

As discussed, it is possible to draw any conclusion from this result. It is possible to say that one sample in our experiment was rated at the same level mark as its human counter. On the other hand: this finding is quite remarkable still the only reasonable interpretation of this result is that machine learning has the ability to produce creative pieces of work. Remember that the definition of a creative agent created in section 1.1 of this paper is that an agent is considered creative

if it has the ability to produce pieces of work. When using this definition at the conclusion that machine learning algorithms can be creative.

The extent of creativity is, however, something that has been mapped out in future. It is possible that only this piece of music produced by machine learning has the property of being creative. It should also be investigated what machine learning algorithms perform better on creative tasks and which creativity machine learning algorithms have.
