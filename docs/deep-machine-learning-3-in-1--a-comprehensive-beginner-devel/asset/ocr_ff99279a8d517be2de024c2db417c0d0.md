Just as you can add elements to a list, you also can remove the same. For example, if a player destroys an accessory, you can program the game to remove the element from the list so that it doesn’t exist on the screen anymore.

If you know the position of the element inside a list, you can use the del statement to remove it from a list. See the following example.

```
computer_accessories = ['mouse', 'keyboard', 'monitor', 'cables',
'charger', 'bluetooth connector', 'wi-fi', 'modem', 'internet', 'webcam']
print(computer_accessories)
del computer_accessories[0]
print (computer_accessories)
```
