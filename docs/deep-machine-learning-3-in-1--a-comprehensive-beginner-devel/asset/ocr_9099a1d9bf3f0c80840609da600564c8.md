You can see that I have used three methods to change the cases of strings. You can do that with any variable while writing code and building a program. A method in Python is a kind of action that Python performs on a certain piece of data. Each method has a set of parameters to follow because methods occasionally need additional information to perform their work. The additional information is then provided within parenthesis. The title() case converts the string into the capital case. Python allows simple concatenation of different strings. As we have two strings, we can easily merge them up by using a simple mathematical operation that is the ‘+’ sign. See how to do that.

```
x = " I am reading a book on deep learning techniques to build AI
models."

y = ' AI is revolutionizing different fields in the business world.'

xy = x + " " + y

print(xy)

>>> ================= RESTART =================
==============================================
>>> 
I am reading a book on deep learning techniques to build AI models.
AI is revolutionizing different fields in the business world.
>>>
```
