# Jupyter Notebooks

They are the most efficient way to run deep learning experiments. They also are the most widely used in data science as well as machine-learning communities. A notebook in a deep learning system is akin to a file that is generated by the Jupyter app. You can edit the file in the browser. It allows users to break down lengthy experiments into tiny chunks that you can execute independently. It ought to make development interactive. It also means that you don’t have to rerun the previous code if something must go wrong in a particular experiment.

If you don’t have a GPU or you don’t want to install one on your machine, you can still build deep learning models in a cloud. A cloud offers a simple and low-cost way to kick off the process without buying additional hardware. If you use Jupyter notebook, the process of using cloud or a local machine is the same. A WS EC2 is the easiest cloud offering to start building models with deep learning systems.
