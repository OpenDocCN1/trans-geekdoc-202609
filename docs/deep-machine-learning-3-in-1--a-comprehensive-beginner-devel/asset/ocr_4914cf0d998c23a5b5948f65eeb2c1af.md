# Speech Recognition

This is one of the most frequent uses of Artificial Neural Networks. Speech occupies a visible and vital role in human to human interaction. Therefore, it is natural for people to feel the need to expect speech interfaces with machines. However, even as the world has immensely progressed, humans still require some sophisticated languages to communicate with machines. These languages are hard to learn. To ease off the communication barrier and to flatten the learning curve, there is a simple solution to the problem. Communication should be done in a medium that is easy for the machine to understand. And there has been great progress in this field as well. However, problems such as limited vocabulary and grammar pop up off and on and try to sabotage the progress. ANNs are considered as the game-changer in the field of communications with machines. You can use multiplayer networks, self-organizing feature maps, and multiplayer networks that have recurrent connections for the purpose.

The most important network is Kohonen's self-organizing feature map. This network will map out similar kinds of phonemes in the form of an output array, which is dubbed as a feature extraction technique. After the network has extracted the features with the help of acoustic models, it will start recognizing the speech.

# Signature Verification

Signature verification is one of the most important ways to stay secure while authenticating a person during legal transactions. This is a non-vision based technique. The first approach is the extraction of a geometrical feature set that represents a particular signature. When you have got these feature sets, you can train the artificial neural networks by writing a neural network algorithm. The trained neural network will label signatures as fake or genuine.
