Keras also supports multi-input or multi-output models, model sharing, and layer sharing. This means that Keras is quite fit for building any kind of deep-learning model right from an adversarial network to a kind of Turing machine.

As Keras is generally distributed under an MIT license, it is free to use even for commercial activities. You can combine it with any version of Python from 2.7 to 3.6. Keras boasts of over 200,000 users that span everyone from academic researchers to startups and big companies, and even hobbyists. If you want to know or view where Keras is being implemented presently, you should take a look at CERN, Google, Yelp, Netflix, and Uber. It also is a favorite framework on Kaggle, a website that conducts machine learning competitions. Almost every model that wins the competition is made up of Keras.

Keras is a model-level library that generally provides top-level building blocks for high-profile deep learning models. You must not use it for tensor manipulation and other low-level activities such as differentiation. Keras has a well-managed and well-optimized library to back up the models.

# A Deep Learning Workstation

Before you move on to setting up your workstation, it is recommended that you run deep learning code on a modern NVIDIA GPU. Some applications such as sequence processing and image processing are likely to work slowly on a Central Processing Unit and even on a multicore Central Processing Unit. It will work perfectly fine on a Graphical Processing Unit (GPU). If you don’t like the option of installing a GPU on your computer machine, you may consider running your deep learning experiments on a cloud platform such as Google’s. However, you need to know that cloud GPU can take burn a hole in your pocket.

No matter if you are running the system in a cloud or on a local machine, you must use the Unix operating system for an easy experience. Technically, it is possible to use Keras on a Windows operating system but it is not recommended in any condition.
