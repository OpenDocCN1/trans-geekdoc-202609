Machine learning systems developed in the 1990s and since then it has fast become a highly popular and successful subfield of AI. As the datasets and hardware got faster and more efficient, machine learning gained popularity and success. Mathematical statistics drives machine learning. Unlike mathematical statistics, machine learning deals with complex and large datasets like the dataset of millions of pictures.

Machine learning demands certain input data points. For example, if the task is recognition of speech, the data points can speeches by the people. If the task is the recognition of pictures, the data points can be images of people. For a speech recognition task, the expected output can be human-generated transcripts of audio files while in the image task, the outputs can be tags like humans or animals. You also can measure the performance of an algorithm.

A machine learning model transforms the input data into something meaningful. The main problem in the processes of deep learning and machine learning is the meaningful transformation of data. A color image can be easily encoded into RGB format which includes red-green-blue colors. It can also be encoded into HSV format which is the short form of hue-saturation-value. These are considered as the two different representations of the same type of data. If a task appears to be difficult with one representation, you can easily do that with another. The objective of machine learning models are to locate the appropriate representation for the input data.

# Deep Learning Models

Deep learning is a branch of machine learning. You can see it as a new take on educating a system with the help of data that tries to emphasize leaning successive layers of different meaningful representations. Deep learning is not a reference to any type of deep understanding that you can achieve by this approach. It denotes the idea of different types of layers of representations. The higher the number of layers is the more the depth of the model is. Other names for the field can be hierarchical representations learning and layered representations learning. Presently, deep learning systems have tens even hundreds of successive layers of representations. They tend to learn from exposure to training data. The machine learning systems that focus on just a couple of layers of representations are called shallow learning systems.
