One of the simplest things to do in strings is changing the case of different words in a string. Take a look at the following code and try to determine how you can change the case of different words and phrases.

```python
x = " I am reading a book on deep learning techniques to build AI
models."

y = ' AI is revolutionizing different fields in the business world.'

print(x.upper())

print(y.title())

print(x.lower())
```

A method in Python is a kind of action that Python performs on a certain piece of data. ## Whitespaces

You can add whitespaces to tabs, spaces, and end-of-line symbols. Whitespace can make it easier for you to organize the output and make it comprehensible.

```python
x = " \tI am reading a book on deep learning techniques to build AI models."
y = ' \nAI is revolutionizing different fields\n in the business world.'
print(x)
print(y)
>>> ================================ RESTART
============================================
>>>
I am reading a book on deep learning techniques to build AI models.

AI is revolutionizing different fields
in the business world.
>>>
```

## Syntax Errors

One of the most common types of errors that you might come across is the syntax error. A syntax error usually occurs when Python is unable to recognize a particular section of the program as a valid Python code. For instance, if you are using apostrophe inside of single quotes, you will trigger error because Python takes everything with an apostrophe as a string.

```python
x = " I am reading Tony's book on deep learning techniques to build AI
models."
y = 'AI progress is revolutionizing different fields in the business
world.'

print(x)
print(y)

>>> ================= RESTART
============================================
>>>

I am reading Tony's book on deep learning techniques to build AI
models.

AI progress is revolutionizing different fields in the business world.

>>>
```

You might think that there is no error message in the result. This is because everything will be fine if you use double quotes for the string and then use an apostrophe. If you use single quotes for the string, the result will be a syntax error.

```python
x = ' I am reading Tony's book on deep learning techniques to build AI
models.'
y = 'AI' progress is revolutionizing different fields in the business
world.'
print(x)
print(y)
```

## Python Lists

A list in Python is a collection of items that you can put together in a particular order. You can make a list that will include different letters of alphabet, names of vegetables and fruits or other household items. Put whatever you want inside a list. Lists are extremely useful when you are building a database to feed a deep learning system. You can cram multiple lists in the database and train a deep learning model. The square brackets will always denote a list. See how to build one.

```python
computer_accessories = ['mouse', 'keyboard', 'monitor', 'cables',
'charger', 'bluetooth connector', 'wi-fi', 'modem', 'internet', 'webcam']

print(computer_accessories)
```
