## Chapter Six

### Mathematical Terms Explained

If you want to understand deep learning techniques, you should be familiar with different mathematical concepts such as gradient descent, tensors, differentiation, and tensor operations. To build a deep learning model, you need a multidimensional Numpy library, which is full of data. The data in the library is stored in Numpy arrays which are known as tensors. All the present machine-learning models use these tensors as the basic structure of data. If you analyze a tensor, we will know that a tensor is a container that stores data. You must know that the data it stores is numerical.

### Scalar

Some matrices are 2D tensors. A dimension is also known as an axis. If a tensor only contains one number, it is known as a scalar tensor. It also is called a 0D tensor. Float 64 and float 32 in Numpy library are known as scalar tensors. A scalar tensor doesn’t have any axes. The number of axes in a tensor is also labeled as a rank.

### Vectors

An array of multiple numbers is labeled as a vector. Some also call it 1D tensor. As apparent from its name, it contains a single axis. If a vector has five entries, it will be labeled as a 5-dimensional vector. Keep in mind that a 5D vector is not the same as a 5D tensor. The basic difference is that a 5D vector has five dimensions along the axis while a 5D tensor has a total of five axes. It may different number of dimensions along their axes. Dimensionality either shows the number of axes within a tensor or the number of entries about a single axis.

### Matrices

An array that contains vectors is known as a matrix. Its other name is a 2D tensor. Two axes are often referred to as columns and rows and you can define the matrix as a rectangular grid of numbers. The entries in the first axis are known as rows while those in the second axis are known as columns.

### 3D Tensors

If you pack up different matrices in the form of a new array, you will obtain a 3D tensor, which you will be able to interpret as a cube of numbers. If you pack 3D tensors inside of an array, you will be able to create a 4D tensor. That’s how it goes on.

Three key attributes generally define a tensor. The first is the number of axes. For example, a 3D tensor might have three axes while a matrix possesses two axes. This is also known as the ndim of a tensor in Numpy. The shape of a tensor is a sort of a tuple of integers that describe how many dimensions each tensor has along a certain axis. Then there is a data type that is denoted by dtype symbol in Python libraries. This is a particular type of data that is contained in a tensor. A tensor’s type can be uint8, float64, and float32. You may also see a char tensor as well on certain occasions. You must take note that there is hardly any existence of string tensors.

### Vector Dataset

This is one of the most common cases in terms of data. In this kind of dataset, a single data point can be easily encoded in the form of a vector. Therefore a batch of data is to be encoded in the form of a 2D tensor which is known as an array of vectors. Here the first axis is known as the samples axis while the second axis is known as the features axis. Take the example of a dataset of people where you have to consider a particular person’s age, income, and ZIP code. Each person in the dataset ought to be characterized as a vector that is packed with three values. Therefore the entire dataset that consists of 300,000 people can be easily packed up in a 2D tensor of the following shape (300000, 3).

Then there is a dataset of text documents in which we would present each document based on how many times a certain word surfaces in it. You can calculate this in a dictionary of 10,000 words. Each document will have to be encoded in the form of a vector of 10,000 values, which will be one count per single word in the dictionary. Therefore, the entire dataset of 400 documents will be easily stored inside a tensor in the following form (400, 10000).

### Sequence Data

Whenever time matters in data, it is wiser to store the data inside a 3D tensor that has quite an explicit 3D tensor. Here each sample ought to be encoded in the form of a 3D tensor. The time axis always is considered a second axis by tradition. Take a look at a couple of examples.

Suppose there is a dataset of the stock prices. As each minute passes, the current price of a particular stock has to be stored, along with the lowest and highest prices from the last minute. So, in this way each minute is being encoded in the form of a 3D vector. When the day ends, the entire trading day is encoded as follows (350, 3) in case the trading day has 350 minutes in total. You can use a 3D tensor to store 250 days’ worth of data as follows (250, 350, 3). Each sample of the tensor would be worth a single day’s worth of data.

You also can form a dataset of multiple tweets where you can encode a single tweet that consists of 250 characters. Each character of the tweet can be encoded as a binary vector of size 128 - the number of alphabets is 128. You can then encode each tweet as a 2D tensor in the following form (250, 128). If you have to create a dataset of 100,000 tweets, it will look like the following (100000, 250, 128).

### Images

Typically, images consist of three dimensions namely width, height, and depth of the color. Grayscale images similar to that are contained in MNIST digits possess a solitary color channel. They can be stored in 2D tensors. An image, by tradition, is packed in 3D tensors. Grayscale images have a 1-dimensional color channel. If you have a batch of 256 grayscale images that have 128, 128 sizes, you can store them in the following form (256, 128, 128, 1).

If we talk about conventions for images tensors, those are two namely channels-first conventions and channels-last convention.

### Videos

Video data is the type of real-world data for which you will need 5D tensors. A video should be viewed in the form of a frame sequence where each frame is considered a color image. Each frame ought to be stored in the form of a 3D tensor which looks like the following (height, width, color depth). If you have to store a frame sequence in the form of a 4D tensor, you will have to add the attribute of frames at the start. If you are dealing with a batch of different videos that ought to be stored in a 5D tensor, the dataset will have the attribute of samples before frames.
