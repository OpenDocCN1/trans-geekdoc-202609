trigger error because Python takes everything with an apostrophe as a string.

```
x = " I am reading Tony's book on deep learning techniques to build AI
models."
y = 'AI progress is revolutionizing different fields in the business
world.'

print(x)
print(y)

>>> ================= RESTART
============================================
>>>

I am reading Tony's book on deep learning techniques to build AI
models.

AI progress is revolutionizing different fields in the business world.

>>>
```

You might think that there is no error message in the result. This is because everything will be fine if you use double quotes for the string and then use an apostrophe. If you use single quotes for the string, the result will be a syntax error.

```
x = ' I am reading Tony's book on deep learning techniques to build AI
models.'
y = 'AI' progress is revolutionizing different fields in the business
```
