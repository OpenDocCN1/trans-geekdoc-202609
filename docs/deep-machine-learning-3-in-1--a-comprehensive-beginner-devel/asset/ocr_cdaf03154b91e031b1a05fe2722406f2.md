Traditional machine learning is different in the sense that the learning process is largely supervised. The programmer needs to be very specific when educating the computer on what types of things it must be looking for to decide whether a certain image is of a cat or a dog or any other animal. The process is dubbed as feature extraction. The success rate of the computer is dependent upon the ability of the programmer to define a particular feature set for a cat. Simply put, you have to define the feature set yourself while in deep learning, the program itself builds this feature without any kind of supervision. This makes the process faster and highly accurate.

The process is largely smooth. The computer program is fed with training data which is a bunch of images that are labeled with a cat or not cat. The labels are known as meta tags. The computer program uses this initial dose of information for training the model. Then it receives a constant feed of data while the model trains itself. The very first form of the model is known as the predictive model. The first model may predict that anything that has four legs is known as a cat. It will label it a cat even if it is a dog because it will match the images by looking for different pixels in the data. Each iteration makes the model complex and highly accurate.

A toddler may take months to decipher and digest the concept of a cat but a deep learning model will take a fraction of that time to learn how a cat looks as it will be able to iterate through millions of images in a short time.

Some people question the accuracy of the model. If a model is not accurate, it is a matter of much concern. Deep learning programs need access to a bulk of processing power and training data. Deep learning models are accurate because they can easily create highly complex statistical models from an iterative output. Constant iterations help the model build accurate models out of unlabeled and unstructured data.
