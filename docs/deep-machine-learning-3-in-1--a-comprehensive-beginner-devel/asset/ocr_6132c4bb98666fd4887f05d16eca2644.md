# **Layers**

These are named as the building blocks when you are making a model in deep learning. A layer is the fundamental data structure inside neural networks. It is a kind of data-processing structure that is fed with input in the form of tensors and yields tensors as well. Some of the layers don’t have a state but most of them do. Different layers are deemed fit for multiple formats of tensor and multiple forms of data processing. For example, vector data is packed up in 2D tensors. This is processed by fully connected layers which are also called dense layers. More complex data form, also known as sequence data, is packed up in 3D tensors that contains attribute such as samples, features, and timesteps. These are typically processed in the form of recurrent layers such as Image data and LSTM layers.

Layers can be viewed as the LEGO bricks in the world of deep learning. Deep-learning models are built-in Keras by clipping together different compatible layers to form multiple data-transformation pipe-lines. The idea of compatibility of a layer refers to the fact that each layer will accept only the input tensors of shape and will return the output tensors of a certain shape. If you are working in Keras, you must not worry about the problem of compatibility because all the layers that you want to add to the models can be dynamically built for the sake of matching an incoming layer.

Deep learning models are networks of layers. They are directed graphs that consist of multiple layers. One of the most common instances is a linear stack of different layers that would map a single input to a particular single output. On top of the list are two-branch network models. Then there are multiple head network models and in the end, there are inception blocks. A network’s topology would try to define a hypothesis space. Choosing the right network structure is an art. There exist some best practices for the purpose and there also are certain principles that you must follow if you want to land a suitable network architecture for your model.
