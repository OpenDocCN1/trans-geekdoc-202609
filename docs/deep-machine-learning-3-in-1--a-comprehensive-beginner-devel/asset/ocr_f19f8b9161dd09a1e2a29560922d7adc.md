# Modifications

You can modify a list by adding, changing, and removing elements from a list. Lists are dynamic hence you can easily build them, add elements to them, and remove elements from them as the program runs its course. For instance, you might be able to create a game in which a player builds and destroys computer accessories. You can store the accessories in a list and remove each as the player destroys an accessory. Each time, he buys or builds one, it will be added to the list. You can change the value of an element by adding a new element after mentioning the index number.

```
computer_accessories = ['mouse', 'keyboard', 'monitor', 'cables',
'charger', 'bluetooth connector', 'wi-fi', 'modem', 'internet', 'webcam']

print(computer_accessories)

computer_accessories[1] = 'biometric scanner'

print (computer_accessories)
```
