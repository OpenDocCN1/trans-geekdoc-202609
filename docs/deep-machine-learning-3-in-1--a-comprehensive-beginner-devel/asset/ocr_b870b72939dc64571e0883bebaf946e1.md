# Anatomy of a Neural Network

A neural network consists of layers that are combined to form a network or a network model. The input data is one layer. Then there are corresponding targets. There also is a loss function which by default would define the feedback signal which is used to learn. The optimizer in a neural network usually determines how the learning process proceeds.

The network that is made up of different layers maps out the input data for making predictions about a certain activity. The loss function moves on to run those predictions through a comparison with the targeted values. This helps the model produce a particular loss value, which is a measure of how well the predictions are matching the expectations.
