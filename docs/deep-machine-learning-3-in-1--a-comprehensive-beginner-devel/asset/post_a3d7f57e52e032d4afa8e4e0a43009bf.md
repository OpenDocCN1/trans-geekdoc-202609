## Anatomy of a Neural Network

A neural network consists of layers that are combined to form a network or a network model. The input data is one layer. Then there are corresponding targets. There also is a loss function which by default would define the feedback signal which is used to learn. The optimizer in a neural network usually determines how the learning process proceeds.

The network that is made up of different layers maps out the input data for making predictions about a certain activity. The loss function moves on to run those predictions through a comparison with the targeted values. This helps the model produce a particular loss value, which is a measure of how well the predictions are matching the expectations. This also paves the way for the next steps in the fine-tuning of the model. The optimizer makes use of the loss value for updating the weights of the network.

## Layers

These are named as the building blocks when you are making a model in deep learning. A layer is the fundamental data structure inside neural networks. It is a kind of data-processing structure that is fed with input in the form of tensors and yields tensors as well. Some of the layers don’t have a state but most of them do. Different layers are deemed fit for multiple formats of tensor and multiple forms of data processing. For example, vector data is packed up in 2D tensors. This is processed by fully connected layers which are also called dense layers. More complex data form, also known as sequence data, is packed up in 3D tensors that contains attribute such as samples, features, and timesteps. These are typically processed in the form of recurrent layers such as Image data and LSTM layers.

Layers can be viewed as the LEGO bricks in the world of deep learning. Deep-learning models are built-in Keras by clipping together different compatible layers to form multiple data-transformation pipelines. The idea of compatibility of a layer refers to the fact that each layer will accept only the input tensors of shape and will return the output tensors of a certain shape. If you are working in Keras, you must not worry about the problem of compatibility because all the layers that you want to add to the models can be dynamically built for the sake of matching an incoming layer.

Deep learning models are networks of layers. They are directed graphs that consist of multiple layers. One of the most common instances is a linear stack of different layers that would map a single input to a particular single output. As you move on with the models, you will come across a variety of network topologies. Some of the common network models are as under.

On top of the list are two-branch network models. Then there are multiple head network models and in the end, there are inception blocks. A network’s topology would try to define a hypothesis space. Choosing the right network structure is an art. There exist some best practices for the purpose and there also are certain principles that you must follow if you want to land a suitable network architecture for your model. We will discuss them in the next sections.

## Loss Functions

Once you have defined the architecture of a network, you will have to choose additional things. A loss function of which we will also talk about in the next section is a certain quantity that ought to be minimized during the training period. By using loss function, you can measure the rate of success for your task. The optimizer determines how your network is going to be updated based on the loss function. The optimizer will implement a stochastic gradient descent (SGD).

A neural network that has multiple outputs may also have multiple loss functions. Choosing an accurate objective function for your problem is very important. This means that your network is likely to take any kind of shortcut it can to cut down the losses. If the objective doesn’t correlate with success for a given job, the network is likely to end up performing things that you might not have desired in the first place. If the AI network is poorly trained and its objective is not clearly defined, it will do more harm than good. The AI model is trained to maximize the overall well-being of humans across the world. AI may choose to murder humans except for a bunch of them because this is one way to maximize the wellbeing of the remaining humans in the world. This might not be what you had intended but that’s what a poorly trained model will understand and execute accordingly. Therefore, you ought to pick up the objectives for creating the models wisely. If you don’t do that, you will have some serious repercussions to face.

To tackle the problems of regression, classification, and sequence prediction, there are a bunch of simple guidelines that you have to follow to pick up the correct loss. For example, you will use binary cross-entropy to solve the two-class classification issue. To solve a multi-class classification issue, you will have to use categorical cross-entropy. It is only when you work truly on the latest research problems, you will have to develop unique objective functions.

## Keras

Keras is a specific deep learning system for Python that offers a viable and easy way to define your objectives and train the model accordingly. It was initially developed for researchers to make fast experiments.

Keras remains mostly in demand because it offers you the advantage of running the same code seamlessly on a GPU and a CPU. Keras is user friendly and it allows the users to make prototypes of deep learning models in a fast and efficient manner. Keras also has a built-in support system for convolutional networks that form the basis for computer vision, recurrent neural networks and any combination of the same. Keras also supports multi-input or multi-output models, model sharing, and layer sharing. This means that Keras is quite fit for building any kind of deep-learning model right from an adversarial network to a kind of Turing machine.

As Keras is generally distributed under an MIT license, it is free to use even for commercial activities. You can combine it with any version of Python from 2.7 to 3.6. Keras boasts of over 200,000 users that span everyone from academic researchers to startups and big companies, and even hobbyists. If you want to know or view where Keras is being implemented presently, you should take a look at CERN, Google, Yelp, Netflix, and Uber. It also is a favorite framework on Kaggle, a website that conducts machine learning competitions. Almost every model that wins the competition is made up of Keras.

Keras is a model-level library that generally provides top-level building blocks for high-profile deep learning models. You must not use it for tensor manipulation and other low-level activities such as differentiation. Keras has a well-managed and well-optimized library to back up the models.
