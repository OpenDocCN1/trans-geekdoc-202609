# The Break Keyword

You can use the break keyword in a while loop to exit the loop at any point. The break statement regulates the flow of the program. You can add it to control the lines of code to see which are executed and which are not. That’s how the program only executes the code that you desire it to.

```
prompt = "\nName the city you have been to:"
prompt += "\nYou must enter q if you want to exit out of this program...."
```
