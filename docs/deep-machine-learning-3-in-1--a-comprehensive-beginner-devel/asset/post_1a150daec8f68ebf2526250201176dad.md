## Types of Neural Networks

Here is a rundown of different types of neural networks.

### Multi-Layer Perceptron

This kind of neural network is used for mainly three purposes namely complex classification, speech recognition, and machine translation. Each node in the neural network is connected to all the neurons in the next layers. These connections make this neural network fully connected. The input and output layers exist and have multiple hidden layers, which means they have three or more layers in total. There is also a bi-directional propagation in the neural network.

The inputs are first multiplied and then fed to the activation function. When it is in backpropagation, the inputs are reduced to cut short the loss. Simply put, the weights in the neural network are generally machine-learned values from the neural networks. They tend to adjust themselves according to the difference between the training inputs and the predicted outputs.

### Convolutional Neural Networks

A convolutional neural network (CNN) contains a multi-dimensional pattern of neurons instead of a traditional two-dimensional pattern. The first layer of the network is known as a convolutional layer. Each neuron in that layer processes the information from a smaller part of this visual field. The input features are received in the form of batches just like a filter does. The network scans and understands the images in parts and then compute the operations several times to conclude the processing of a complete image. The processing involves the conversion of an image from an HSI or RGB scale to a grey-scale. Ramping up the changes in the pixel value is likely to help the network to spot any changes in the edges of the images. It then classifies the images into multiple categories.

The propagation pattern in a convolutional neural network is mainly unidirectional. CNN may contain single or multiple convolutional layers. The output of the network is channelized toward a connected neural network, which then classified the images. There are filters installed that extract different parts of a certain image. CNNs are considered the best for the classification of images, paraphrase detection, recognition of videos, and for semantic parsing purposes.

### Radial Basis Function Neural Network

This type of neural network contains an input vector which is followed by one layer of RBF neurons. There is an output layer that has a single node per category. Classification is generally performed after measuring the similarity of the input to different data points in the training set where neurons would store a certain prototype.

When an input vector must be classified, each neuron in the network ought to measure the Euclidean distance between the prototype and input. If there are two classes, namely X and Y, the new input that must be classified will be closer to class X prototypes than it will be to class Y prototypes. Hence, it must be classified as class X.

### Recurrent Neural Networks

Recurrent Neural Networks or RNNs are popular among programmers because they would like to add an intriguing twist to a simple neural network. It is this twist that makes them unique. RNNs are generally designed to absorb a series of input without any restrictions on the size of the input. Recurrent Neural Networks differ from ordinary neural networks because they have a powerful memory and they remember what had happened in the past. Their learnings of the past generally influence their decisions. Some may say that basic feed-forward networks also remember things from the past but they remember things that they have learned during the training phase. For example, a neural network that has an image classifier learns how the number 5 looks like during the training phase. Then the neural network uses the same knowledge for classifying things in the production phase.

RNNs learn similarly but in addition to that, they also remember different things from the previous output while they generate outputs. RNNs tend to take multiple input vectors and then produce multiple output vectors. In RNNs, only weights don’t influence outputs but hidden state vectors also influence them.

## Building a Neural Network

A neural network works just like the human brain. You can consider it analogous to the brain when you describe one. Without delving straight into the brain analogy, you can first take it as a mathematical function that would map a certain input toward the desired output. The following are the components of a neural network.

There is an input layer which you can name as s. There should be an arbitrary amount of hidden layers in the neural network. Then there ought to be an output layer which you can name as t. There should also be a particular set of biases and weights between each hidden layer. You can denote them as b and W respectively. Make sure you have got Python installed on your computer system as building a neural network in Python is relatively easy. Let’s get it started right away.

```
class MyNeuralNetwork:

    def __init__(self, s, t):
        self.input  = s

        self.weights1  = np.random.rand(self.input.shape[1],4)

        self.weights2 = np.random.rand(4,1)

        self.t  = t

        self.output = np.zeros(t.shape)
```

Once you have created an artificial neural network, you will have to train it. If you can fill in the biases and weights, you will be able to strengthen your predictions. They will be more accurate. Training, in simple words, is choosing the right values for the biases and weights. It is about trying out different values and then fine-tuning them based on the input data. The more correct the values for these two parameters, the more trained the neural network.

Every single iteration of this training process goes through two steps. The first is the calculation of the predicted output which also is labeled as feedforward. The second step is updating the biases and weights which are known as backpropagation.

A feedforward is a basic calculus. You will have to add a feedforward function to the Python code.
