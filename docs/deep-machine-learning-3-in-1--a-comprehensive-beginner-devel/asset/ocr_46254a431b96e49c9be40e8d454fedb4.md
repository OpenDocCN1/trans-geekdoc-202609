When you have built a list in Python, you can easily access different elements inside of a list by using the index number. Lists are generally ordered and there is an index to each item in the list. In order to access a particular element, you will have to write the name of the list and then the index number. I will access different items from the same list in the following code snippet.

```
computer_accessories = ['mouse', 'keyboard', 'monitor', 'cables',
'charger', 'bluetooth connector', 'wi-fi', 'modem', 'internet', 'webcam']
print (computer_accessories[0])
print (computer_accessories[2])
print (computer_accessories[4])
print (computer_accessories[5])
print (computer_accessories[7])
print (computer_accessories[11])
>>> ================================ RESTART
===============================
```
