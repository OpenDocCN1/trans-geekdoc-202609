Building lists in this way is common because sometimes you don’t know what data you have to fill into the list at the start. You get to know that as you build the program. There is another method by which you can add elements to a list. This method is known as the insert method and it is used to add elements at a specific index.

```
computer_accessories = ['mouse', 'keyboard', 'monitor', 'cables',
'charger', 'bluetooth connector', 'wi-fi', 'modem', 'internet', 'webcam']
print(computer_accessories)

computer_accessories.insert(0, 'biometric scanner')
```
