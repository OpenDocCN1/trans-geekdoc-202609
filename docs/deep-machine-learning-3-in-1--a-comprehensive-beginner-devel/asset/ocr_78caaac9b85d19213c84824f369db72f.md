# Convolutional Neural Networks

Convolutional layers are considered the key building blocks of convolutional neural networks or CNN. A convolution is the simplest application of a filter to get an input that would result in a kind of activation. Recurrent application of a filter yields a map of activations that are called a feature map. This indicates the exact locations and the strengths of a certain feature in the input. This can be an image.

Why convolutional neural networks differ from simple neural networks is from the fact that they can learn by themselves about different filters that are specific to a particular training dataset within the constraints of a particular modeling problem like the classification of images. The result is highly specific features that you can detect anywhere.

A convolutional neural network is known as a specialized kind of neural network model that is specifically designed to work with two-dimensional data. However, they also can be used with three-dimensional and two-dimensional data-types. The core of a convolutional neural network is the convolutional layer which gives this network its peculiar name. This particular layer would like to perform a specific operation popularly known as a convolution.

It is a kind of linear operation that includes multiplication of weights with the input you feed to the network. Here it acts just like a traditional network. This technique was particularly designed for 2D input. The filter in the convolutional neural networks is smaller than the size of the input data. There is a dot product in convolutional neural networks which is an element-wise multiplication process between the filter and input. Their sum is drawn which always yields a single value. The full operation can be referred to as a scalar product.
