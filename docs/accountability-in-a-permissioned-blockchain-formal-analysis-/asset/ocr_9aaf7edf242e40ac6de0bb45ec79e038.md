We define a new environment $\tilde{\mathcal{E}}$ that connects to $\mathcal{A}_D | \mathcal{P}_{\text{sig}}$ and internally simulates $\mathcal{E} | \mathcal{A} | \mathbb{P}_{\text{F}}^p$, except for using the external machine $\mathcal{P}_{\text{sig}}$ for signing requests. The simulation continues at most until the polynomial runtime bound of $\mathcal{E} | \mathcal{A} | \mathbb{P}_{\text{F}}^p$ has been reached. At the end of the simulation, $\tilde{\mathcal{E}}$ checks whether the judge violated fairness or completeness. Note that $\tilde{\mathcal{E}}$ can indeed observe a violation since this decision depends only on information that is available in the internal simulation and on the correctness of signatures, which can be checked by using $\mathcal{P}_{\text{sig}}$. If a violation is detected, then $\tilde{\mathcal{E}}$ outputs 1. Otherwise, the environment outputs 0. Note that $\tilde{\mathcal{E}}$ is a ppt environment as it performs at most a polynomial number of steps, no matter which system it connects to.
