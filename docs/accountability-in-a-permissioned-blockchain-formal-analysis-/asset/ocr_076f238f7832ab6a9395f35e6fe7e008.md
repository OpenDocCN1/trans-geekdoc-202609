# ## Appendix A. Adding Signatures to Kafka

In this section, we detail our first change to Kafka for Fabric* that was briefly discussed in Section 3.3.

Recall that, on the input side, a Kafka leader gets requests to add messages to the stream. On the output side, orderers and other Kafka brokers pull new messages from the Kafka leader.
