Google Colaboratory has support for other technologies such as HTML and SVG, enabling you to render SVG-based graphics in notebooks that are in Google Colaboratory. One point to keep in mind: any software you install in a Google Colaboratory notebook is only available on a per-session basis: if you log out and log in, you need to perform the same installation steps as performed during your earlier Google Colaboratory session.

As mentioned earlier, there is one other vice feature of Google Colaboratory: you can execute code on a GPU per day for up to twelve hours. This free GPU support is extremely useful for people who do not have a suitable GPU on their local machine (which is probably the majority of users), and they now launch TensorFlow to train neural networks in less than 20 or 30 minutes that would otherwise require hours of CPU-based execution time.

Keep in mind the following details about Google Colaboratory. First, whenever you connect to a server in Google Colaboratory, you start what is known as a session. You can execute the code in a session with a CPU (the default), a GPU, or a TPU (which incurs a cost), and you can execute your code without any time limit for your session. However, if you select the GPU option for your session, the first 12 hours of GPU execution time are free. Any additional GPU time during that same session incurs a small charge (see the website for details).
