# Formatting Strings in Python

Python provides the functions string.lstrip(), string.rstrip(), and string.center() for positioning a text string so that it is left justified, right justified, and centered, respectively. As you saw in a previous section, Python also provides the format() method for advanced interpolation features.

Now enter the following commands in the Python interpreter:

```
import string
str1 = 'this is a string'
print string.ljust(str1, 10)
print string.rjust(str1, 40)
print string.center(str1, 40)
```

The output is shown here:

this is a string
    this is a string
this is a string
