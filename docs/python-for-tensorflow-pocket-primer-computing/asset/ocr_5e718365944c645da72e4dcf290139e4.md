# Transposing a Pandas Dataframe

The T attribute (as well as the transpose function) enables you to generate the transpose of a Pandas DataFrame, similar to a NumPy array.

For example, the following code snippet defines a Pandas dataframe df1 and then displays the transpose of df1:

```
df1 = pd.DataFrame({'a' : [1, 0, 1], 'b' : [0, 1, 1] }, dtype=int)

print("df1.T:")
print(df1.T)
```

The output is:

| df1.T: |
|---|---|
| a | 1 0 1 |
| b | 0 1 1 |
