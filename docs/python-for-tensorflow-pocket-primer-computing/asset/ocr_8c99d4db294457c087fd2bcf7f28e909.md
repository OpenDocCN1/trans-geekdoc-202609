Python distinguishes between an uninitialized variable and the value None. The former is a variable that has not been assigned a value, whereas the value None is a value that indicates “no value.
Collections and methods often return the value None, and you can test for the value None in conditional logic.

# # SLICING AND SPLICING STRINGS

Python enables you to extract substrings of a string (called “slicing”) using array notation. Slice notation is start:stop:step, where the start, stop, and step values are integers that specify the start value, and the increment value. The interesting part of slicing in Python is that you can use the value -1, which operates from the right side instead of the left side of a string.
Some examples of slicing a string are here:

```
text1 = "this is a string"
print 'First 7 characters:',text1[0:7]
print 'Characters 2-4:',text1[2:4]
print 'Right-most character:',text1[-1]
print 'Right-most 2 characters:',text1[-3:-1]
```

The output from the preceding code block is here:

```
First 7 characters: this is
Characters 2-4: is
Right-most character: g
Right-most 2 characters: in
```
