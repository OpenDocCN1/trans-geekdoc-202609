# DISPLAYING IMAGES IN SKLEARN

Listing 4.21 displays the contents of load-digits.py that illustrates how to display the Digits dataset in Sklearn.

LISTING 4.21: load-digits.py

```python
from sklearn import datasets
from sklearn.datasets import load_digits
from matplotlib import pyplot as plt

digits = load_digits()
```

```python
# Figure size (width, height) in inches
fig = plt.figure(figsize=(6, 6))

# Adjust subplots
fig.subplots_adjust(left=0, right=1, bottom=0,
top=1, hspace=0.05, wspace=0.05)

# For each of 64 images
for i in range(64):
    # Initialize subplots: add a subplot
    # the grid of 8 by 8
    ax = fig.add_subplot(8, 8, i + 1, xticks=[], ticks=[])
    # Display an image at the i-th position
    ax.imshow(digits[i], cmap=plt.cm.binary, interpolation='nearest')
    # label the image with the target value
    ax.text(0, 7, str(digits.target[i]))

# Show the plot
plt.show()
```
