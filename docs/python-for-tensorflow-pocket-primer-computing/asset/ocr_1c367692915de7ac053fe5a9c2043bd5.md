# LISTING 4.24: sklearn-linreg.py

```
import warnings
warnings.filterwarnings(action="ignore",
module="scipy", message="^internal gelsd")

from sklearn import linear_model

reg = linear_model.LinearRegression()
reg.fit([[0, 0, 0], [1, 1], [2, 2]], [0, 1, 2])
print(reg.coef_)
```

Listing 4.24 starts with two statements (shown in bold) that suppress warning messages involving gelsd. You can comment out these two lines to see if a warning message is displayed.

The next portion of Listing 4.24 initializes the variable reg as an instance of the LinearRegression class, and then invokes the fit() method in order to train the model with the hard-coded list of values. The print() statement displays the result of the training, which is a pair of numbers that correspond to the slope and intercept of the best-fitting line. The output from Listing 4.24 is

[0.5 0.5]
