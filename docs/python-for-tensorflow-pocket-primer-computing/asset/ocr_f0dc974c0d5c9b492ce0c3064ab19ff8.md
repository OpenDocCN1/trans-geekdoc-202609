# EXTRACTING DATA FROM TITANIC DATASET IN SEABORN

Listing 4.31 displays the contents of seaborn-titanic.py which illustrates how to extract subsets of data from the Titanic dataset.

LISTING 4.31: seaborn-titanic.py

```
import matplotlib.pyplot as plt
import seaborn as sns

titanic = sns.load_dataset("titanic")
print("titanic info:")
titanic.info()

print("first five rows of titanic:")
print(titanic.head())

print("first four ages:")
titanic.loc[0:3,'age']

print("fifth passenger:")
titanic.iloc[4])
```
