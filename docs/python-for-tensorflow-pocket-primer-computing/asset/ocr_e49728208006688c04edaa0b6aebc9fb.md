x = tf.Variable(., name='x')
threshold = tf.constant(5.)

model = tf.global_variables_initializer()

with tf.Session() as session:
    session.run(model)
    while session.run(tf.less(x, threshold)):
        x = x + 1
        x_value = session.run(x)
    print(x_value)

Notice that the while loop inside the code block has a more complex condition than the with code block that you saw previously in this chapter. The while loop increments x, assigns the result to x_value, and then prints the value of x_value as long as the value of x is less than the value of threshold. The output from Listing 5.19 is:

3.0
