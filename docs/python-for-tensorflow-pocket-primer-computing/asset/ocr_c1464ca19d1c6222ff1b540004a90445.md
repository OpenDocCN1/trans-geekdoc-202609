# WHAT IS PANDAS?

Pandas is a Python package that is compatible with other
Python packages, such as NumPy, Matplotlib, and so forth. Install
Pandas by opening a command shell and invoking this command
for Python 2.x:

```
pip install pandas
```

Launch this command to install Pandas for Python 3.x:

```
pip3 install pandas
```

In many ways the Pandas package has the semantics of a
spreadsheet, and it also works with xsl, xml, html, and csv file
types. Pandas provides a data type called a DataFrame (similar to a
Python dictionary) with extremely powerful functionality, which is
discussed in the next section.

Pandas DataFrames support a variety of input types, such as
darrays, lists, dicts, or Series. Pandas also provides another
data type called Pandas Series (briefly discussed in this chapter);
this data structure provides another mechanism for managing data
search online for more details).
