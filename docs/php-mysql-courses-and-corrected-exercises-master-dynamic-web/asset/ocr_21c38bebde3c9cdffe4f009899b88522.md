# Random number generation :

+   - **rand($min, $max)**: This function generates a random number between the values $min and $max. The value returned is an integer.

# Example:

```
<?php
$random_number = rand(1, 100);
echo "Random number between 1 and 100: $random_number";
?>
```

Each time you run this code, you'll get a random number between 1 and 100.

+   - **mt_rand($min, $max)**: Similar to rand(), but uses a **Mersenne Twister** random number generator, renowned for its better random number distribution.

# Example:

```
<?php
$random_number = mt_rand(1000, 9999);
echo "Random 4-digit PIN code: $random_number";
?>
```
