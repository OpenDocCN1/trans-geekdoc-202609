# Introduction to variables and constants in PHP

PHP programming is based on the use of variables and constants to store and manipulate data. In this chapter, we'll explore in detail these two fundamental concepts and their use in the development of dynamic web applications.

Imagine you're a magician and you've got a magic box. This box can hold all sorts of different things. You can put rabbits, coins, doves and so on inside. At any time, you can change what you put in your hat. It's like a variable in PHP where you can store different values and change them to suit your needs.
