To preserve line breaks when reading a file with file_get_contents(), you can use PHP's predefined nl2br() function to convert line breaks into HTML <br> tags. This allows line breaks to be displayed correctly in an HTML context.

Here's how you can modify your example to include the nl2br() function:

```
<?php
// Read the contents of a file in a string
$content = file_get_contents('filetext/poem1.txt');
// Convert line breaks into HTML tags <br>
$content_with_br = nl2br($content);
// Display file contents with line breaks preserved
echo $content_with_br;
?>
```

With this modification, line breaks in the poeme.txt file will be correctly displayed in your HTML page.
