```
// File path
$filename = "new_folder/poem1.txt";

// New permissions (e.g. 0644 for read and write for owner, read for group and read for others)
$new_permissions = 754;

// Change file permissions
if (chmod($filename, $new_permissions)) {
echo "File permissions have been successfully modified;
} else {
echo "Error: Unable to change file permissions";
}
?>

```

In this example, the **chmod()** function is used to modify the permissions of the file specified by the `$filename` path, using the new permissions specified. If the modification is successful, a message is displayed indicating that the file permissions have been successfully modified. Otherwise, an error message is displayed. The value 754 specified in the `$new_permissions` variable grants the owner all permissions (7 = 4+2+1), the user group read and execute permissions (5 = 4+1) and others only read permissions (4).
