In this example, we've declared an interface called "Connectable", which contains two methods: "connect()" and "disconnect()". This interface defines a contract that classes must respect when implementing these methods. Classes implementing this interface must provide an implementation for each of these methods. Note that interface names must be descriptive, clearly indicating the interface's role or function. Interface names are generally singular and often begin with a capital letter, like classes. For example: Connectable, Loggable, Calculable, etc.

# Implementing interfaces in classes

To use interfaces, one or more classes can implement one or more interfaces using the implements keyword. When a class implements an interface, it must provide concrete definitions for all the methods defined in the interface.

Create a new Database.php file, and implement the Connectable interface as follows:

```
<?php
require_once 'Connectable.php';

class Database implements Connectable {
public function connect() {
    echo "Database connection established.";
}
}
```
