# Updating the bulletin board of all authors

In the previous chapter, we developed the process of displaying the data of all authors in a table. In this section, we will enhance this process by adding a link to each row of the table. This link will pass the author's identifier to a script called "form_edit_author.php", which will retrieve the data of the author corresponding to this identifier and display this data in a form allowing new information to be entered.

In the file display_authors.php, we make two main changes:

We add a column to the display table with a header titled "Edit": <th>Edit</th>.

We then add the "Edit" link to each table cell:

```
echo "<td><a href='form_edit_author.php?id={$author['author_id']}'>
Edit</a></td>";
```

