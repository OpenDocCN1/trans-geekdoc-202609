The function returns a new array containing the updated elements.

Here's an example of how to use array_replace() :

```
```php
<?php
$array1 = ["a" => "red", "b" => "green", "c" => "blue"];
$array2 = ["b" => "yellow", "d" => "orange"];
$new_array = array_replace($array1, $array2);
echo "<pre>";
print_r($new_array);
echo "</pre>";
?>
```
```

In this example, the array $array1 is replaced by the values in the $array2 array. The "b" keys of $array1 and $array2 both exist, so the value of key "b" in $new_array will be replaced by the value of $array2. Keys "a", "c", and "d" are only present in one of the arrays, so they will be added to $new_array.
