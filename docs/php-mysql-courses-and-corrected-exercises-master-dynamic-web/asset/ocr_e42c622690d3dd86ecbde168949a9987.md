# The while loop

The **while** loop is a control structure in PHP that allows you to execute a block of code repeatedly as long as
a specified condition is true. It functions as follows:

+   **Step 1:** Initialize condition: Before entering the **while** loop, a condition is defined. This condition is a
+   Boolean expression that is evaluated before each iteration of the loop.

+   **Step 2:** Condition evaluation: The condition is evaluated to determine whether it is true or false.

+   **Step 3:** If the condition is true (i.e. returns true), the block of code inside the loop, i.e. the "Instructions"
+   block, is executed. Once this block of code has been executed, the program returns to step 2 and re-
+   evaluates the condition.

+   **Step 4:** If the condition is false (i.e. returns false), the while loop ends and program execution continues
+   after the loop.
