# Exercise 28 (following Exercise 27):

Create a class Car that inherits from the Vehicle class, with an additional attribute number_doors. The Car class should also have a constructor that takes this additional attribute into account.

The Car class should have getters and setters for the number_doors attribute, as well as a display() method that displays the car's information as a string, also calling the display() method of the parent class.

Then, create an object of type Car with initial information and use the display() methods and setters to modify the car's information.
