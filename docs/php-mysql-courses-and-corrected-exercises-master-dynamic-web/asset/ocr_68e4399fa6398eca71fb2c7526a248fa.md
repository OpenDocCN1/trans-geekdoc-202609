# Indexed tables (numbered)

Indexed arrays, also known as numbered arrays, are data structures where each element is associated with a numerical index. These indices generally start at zero and increment by 1 for each additional element.

Indexed arrays are one of the simplest forms of arrays in PHP and are widely used to store ordered collections of data.
