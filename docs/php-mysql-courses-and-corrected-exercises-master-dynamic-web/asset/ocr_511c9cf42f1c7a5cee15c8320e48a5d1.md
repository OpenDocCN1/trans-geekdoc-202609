# Exercise 15

Write a PHP script that stores a list of names in an array, then displays these names in a bulleted list.

# Correction

```
<?php
$names = array("Alice", "Bob", "Mohammed", "Charlie", "David", "Sara", "Eve");

echo "<ul>";

foreach ($names as $name) {
    echo "<li>".$name."</li>";
}
```
