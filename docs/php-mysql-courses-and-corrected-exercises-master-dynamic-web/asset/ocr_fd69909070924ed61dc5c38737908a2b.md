| Function | Description |
| :--- | :--- |
| `array_unshift()` | Additions one or more elements to the beginning of an array |
| `array_pop()` | Deletes the last element of an array |
| `array_shift()` | Deletes the first element of an array |
| `array_slice()` | Extract part of a painting |
| `array_merge()` | Merges one or more arrays |
| `array_key_exists()` | Checks whether a key exists in an array |
| `in_array()` | Checks whether a given value exists in an array |
| `array_search()` | Searches for a given value in an array and returns the corresponding key |
| `array_replace()` | Replaces the elements of an array with those of one or more other arrays |

+   • The **sort()** function: sorts an array in ascending order of values. It directly modifies the array in place and returns a Boolean indicating the success of the operation. Here's an example:

```
```php
<?php
$fruits = ["orange", "apple", "banana", "strawberry"];
sort($fruits);
```
