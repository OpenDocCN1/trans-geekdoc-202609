# Functions with default settings

In this section, we'll look at functions with default parameters. These functions allow you to define default values for certain parameters, meaning that these parameters can be omitted when the function is called. Here is the general syntax for defining a function with default parameters:

```
```
function function_name(param1, param2=default_value) {
  // Block of code to execute
}
```
```
