```
<?php
$a = 5;
$b = "5";
$result = ($a != $b);
echo $result;
?>
```

In this code, the variable $result is set to true because the variables $a and $b have different types. In fact,
$a is of type Integer and $b is of type string.

**Spaceship (<=>) comparison operator**: Compares two expressions. Returns - , 0 or 1 depending on whether
the first expression is less than, equal to or greater than the second.

# Example:

```
<?php
$a = 10;
$b = 5;
$c = 20;
$result1 = ($a <=> $b);
$result2 = ($a <=> $c);
echo $result1;
echo "<br>";
```
