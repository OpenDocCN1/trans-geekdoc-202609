$name = "Bob"; : This line declares a variable $name and assigns it the value "Bob". The variable $name now contains the string "Bob".

echo $name; : This line displays the contents of variable $name. The echo function is used to display text or variables in PHP. In this case, it displays the value of the variable $name, which is "Bob".
