By default, this directive is generally set to Off.

```

Change the value of the display_errors directive to On.

You can also set the error_reporting directive to specify the level of errors to be displayed. For example, you can set error_reporting = E_ALL to display all errors, or error_reporting = E_ALL & ~E_NOTICE to display all errors except notifications.

```

Save your changes to php.ini.
