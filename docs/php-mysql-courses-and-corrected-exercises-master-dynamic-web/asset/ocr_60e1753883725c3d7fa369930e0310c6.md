+   - The **array_push()** function is used to addition one or more elements to the end of an array. It directly modifies the array in place and returns the new number of elements in the array. Here's an example:

```
```php
<?php

$fruits = ["orange", "apple", "banana", "strawberry"];
array_push($fruits, "Pineapple", "kiwi");

echo "<pre>";
print_r($fruits);
echo "</pre>";

?>
```
