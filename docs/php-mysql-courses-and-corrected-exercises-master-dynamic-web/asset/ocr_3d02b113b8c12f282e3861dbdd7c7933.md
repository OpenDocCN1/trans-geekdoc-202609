# # File existence check

Checking the existence of files in PHP can be performed using the **file_exists()** function. This function
checks whether a file or directory exists at the specified location. Here's an example of how to use the
file_exists() function to check the existence of a file:

```
<?php
// File path
$filename = "new_folder/poem1.txt";

// Check file existence
if (file_exists($filename)) {
    echo "The file exists";
} else {
    echo "The file does not exist";
}
?>
```
