# Use of the logical AND operator (&&) :

The logical AND operator (&&) returns TRUE if all conditions combined are true. Here's an example:

```
<?php
$a = 10;
$b = 25;
if($a > 5 && $b < 100) {
    echo "You succeeded, condition true";
} else {
    echo "Sorry, condition false";
}
?>
```
