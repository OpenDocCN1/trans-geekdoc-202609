# Function Arrays to merge Output type array_merge($tab1, $tab2, ..$tabn): array

**tab1, $tab2, ... $tabn**: The tables to be merged. You can supply several tables separated by commas.

Here's an example of how to use array_merge() :

```
<?php
$tab1 = ["a" => "apple", "b" => "banana"];
$tab2 = ["c" => "orange", "d" => "strawberry"];
$tab3 = ["e" => "ananas"];

$result = array_merge($tab1, $tab2, $tab3);
echo "<pre>";
print_r($result);
echo "</pre>";
?>
```

In this example, the **array_merge()** function merges the arrays $tab1, $tab2 and $tab3 into a single array
