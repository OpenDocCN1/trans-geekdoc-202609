Here's how to use this generator to display even numbers up to 17:

```
<?php
function generate_even_numbers($max) {
    for ($i = 0; $i <= $max; $i += 2) {
        yield $i;
    }
}

foreach (generate_even_numbers(17) as $number) {
    echo $number . " ";
}
?>
```
