# Defining magic methods

PHP magic methods are special methods predefined in a class, which are automatically invoked by the PHP engine in response to certain interactions with objects in that class. They generally begin with two underscores (__) and provide special functionality to control the behavior of objects in particular situations. Magic methods enable developers to customize object behavior, including operations such as object instantiation, access to inaccessible properties, calling non-existent methods, serialization and deserialization, among others.

# Main magic methods

PHP offers a number of so-called magic methods, and in this section we'll look at some of the most commonly used.

+   a. __construct()

The __construct() method is called automatically when an object is instantiated. It is called "Constructor". It is used to initialize object properties or perform other necessary operations before the object is used.

+   b. __get()

The __get() method is used to intercept attempts to read inaccessible object properties. It can be used to implement customized behavior for this operation.
