| Operators | Use | Meaning |
|---|---|---|
| = | $a = $b | Assigning the value
of $b to the variable
$a |
| += | $a += $b | $a = $a + $b |
| -= | $a -= $b | $a = $a - $b |
| *= | $a *= $b | $a = $a * $b |
| /= | $a /= $b | $a = $a / $b |
| %= | $a %= $b | $a = $a % $b |
| **= | $a **= $b | $a = $a**$b |
| .= | $a .= $b | $a = $a.$b |

# Examples:

```
<?php
// Simple assignment operator
$a = 10; // $a is now equal to 10
echo "\$a after simple assignment operator: $a <br>";

// Combined assignment operators
$b = 5;
```
