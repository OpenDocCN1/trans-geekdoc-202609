### Updating data in a database

In this section, we'll look at updating data in a database. Updating is the process of modifying existing values in a table. Whether to correct errors, update information or monitor data evolution, the ability to perform updates is essential in the development of web applications.

We'll explore the various steps involved in updating data in a MySQL database using PHP. This includes preparing update requests, executing these requests and checking the success of the operation.

To illustrate update operations, we are continuing to develop our "library" mini-project. We'll be giving you detailed instructions on how to update your own projects securely and efficiently.

### Update process

In general, to update the data in a table, you need to follow these steps:

- Identification of the record to be updated: You must first identify the table record you wish to update. This can be done by retrieving the identifier of that record, such as the author ID in our example.

- Retrieving new data: Get the new data you want to update for this record.

- Database connection: Establish a database connection using PDO to run SQL queries.

- Preparing and executing the update request: Prepare the update SQL query using PDO's prepare() method. Execute the request using the execute() method.

- Linking values: Link replacement values to query parameters using the bindParam() method.

- Checking the success of the update: Check the result of the query execution to confirm that the update was successful.

- Display a confirmation message: Display an appropriate message to inform the user of the result of the update operation.

Here's an example of PHP code you can place in a new file called "edit_author.php".

```php
<?php
$author_id = 1; // Example of author ID to be updated

// New author information
$new_lastname = "New Last Name";
$new_firstname = "New First Name";
$new_email = "newaddress@example.com";
$new_password = "new_password";
$new_biography = "New biography";
```

```php
// Database connection
$connection = new PDO("mysql:host=localhost;dbname=library", "root", "");
$connection->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
```

```php
// Update request
$request = $connection->prepare("UPDATE authors SET
    last_name = :new_lastname,
    first_name = :new_firstname,
    email = :new_email,
    password = :new_password,
    biography = :new_biography
WHERE author_id = :author_id");
```

```php
// Bind parameters
$request->bindParam(':new_lastname', $new_lastname);
$request->bindParam(':new_firstname', $new_firstname);
$request->bindParam(':new_email', $new_email);
$request->bindParam(':new_password', $new_password);
$request->bindParam(':new_biography', $new_biography);
$request->bindParam(':author_id', $author_id);
```

```php
// Execute query
$result = $request->execute();
```

```php
// Verify successful update
if ($result) {
    echo "Information updated successfully";
} else {
    echo "An error occurred during the update";
}
?>
```

This PHP code illustrates the process of updating the information of a single author with author_id = 1 in the "authors" table. In this operation, the new values for the author's last name, first name, email, password and biography are defined beforehand. A database connection is then established using PDO. An update SQL query is prepared using the PDO object's prepare() method, where the UPDATE ... SET statement is used to specify the columns to be updated and the new values. The values of the new author information and the author ID to be updated are then bound to the query parameters using the bindParam() method. Finally, the update request is executed using the PDO object's execute() method. If you execute this code, you should normally get the message :
