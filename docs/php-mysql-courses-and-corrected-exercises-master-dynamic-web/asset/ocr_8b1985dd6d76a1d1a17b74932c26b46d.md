Note that the **$this** variable is a very important keyword in PHP, and refers to the object currently in use.

Within the getInfosUser() method, private attribute values are accessed using the syntax $this->name, $this->firstname, $this->age and $this->email. The -> operator is used to access the properties of the current object.
