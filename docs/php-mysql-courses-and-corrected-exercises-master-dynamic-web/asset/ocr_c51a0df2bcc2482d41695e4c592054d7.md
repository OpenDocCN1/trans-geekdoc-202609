| Functions | Description | Examples |
| :--- | :--- | :--- |
| abs() | Returns absolute value | abs(-10) = 10 |
| sqrt() | Returns the square root of a number | sqrt(25) = 5 |
| pow() | Returnsn the power of a number | pow(2,3) = 8 |
| round() | Rounds a number to the nearest decimal place | round(3,7) = 4 |

+   * **abs()** : This function returns the absolute value of a number, i.e. its value without sign. For example:

```
$number = -10;

$absolute_value = abs($number); // $absolute_value is 10
```

+   * **sqrt()** : The sqrt() function returns the square root of a number. For example:

```
$number = 25;

$square_root = sqrt($number); // square_root is 5
```
