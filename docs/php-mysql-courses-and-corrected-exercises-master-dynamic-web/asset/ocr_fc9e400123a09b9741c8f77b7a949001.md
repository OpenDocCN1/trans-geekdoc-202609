# Exercise 9

Using the for loop, write a program to calculate the product of all integers from 1 to 20 (1x2x3x4x5x.....x19x20).
Then display the result.

# Correction

```
<?php

$product = 1;

for ($x=1; $x<=20; $x++) {
	$product = $product * $x;
}

echo "The product of all numbers from 1 to 20 is $product";
```
