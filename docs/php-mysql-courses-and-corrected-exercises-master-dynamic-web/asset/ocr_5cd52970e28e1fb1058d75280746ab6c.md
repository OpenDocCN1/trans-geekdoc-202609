```
// Retrieve user data
$email = $_POST['email'];
$password = $_POST['password'];

// Secure SQL query with linked parameters
$sql = "SELECT * FROM authors WHERE email = :email AND password = :password";
$request = $connection->prepare($sql);
$request->bindParam(':email', $email);
$request->bindParam(':password', $password);

// Execute request
$request->execute();

// Check results
if ($request->rowCount() > 0) {
  echo "Connection successful!";
} else {
  echo "Login failed.";
}
?>
```

With this approach, the values of the $email and $password variables are passed as bound parameters in the prepared query. This prevents SQL injection attacks, as the parameter values are not interpreted as SQL
