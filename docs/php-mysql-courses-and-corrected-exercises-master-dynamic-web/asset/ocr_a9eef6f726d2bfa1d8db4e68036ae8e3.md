strtoupper() and strtolower() : These functions convert a string to **upper** or **lower case** respectively.

# Example:

```
<?php
$text = "Hello everyone";
$upper_text = strtoupper($text); // $upper_text is "HELLO EVERYONE".

$lower_text = strtolower($text); // $lower_text is "hello everyone".

echo $upper_text;
echo "<br>";
echo $lower_text;
?>
```
