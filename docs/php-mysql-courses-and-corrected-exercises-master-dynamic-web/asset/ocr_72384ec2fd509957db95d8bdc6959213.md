So, when evaluating the expression (++$x) * (++$y), the values of $x and $y are incremented before they are used in the expression. This means that $x becomes 6 and $y becomes 3 when the expression is evaluated.
The expression is then translated as (6) * (3), giving 18 as the result.

After evaluating the expression, the values of $x and $y remain incremented, so that $x has the value 6 and
$y has the value 3.

# Suffixed and prefixed use of the - operator

The decrement operator in PHP, represented by "--", works on the same principle as the increment operator
++, except that it reduces the value of a variable by 1 instead of increasing it by 1. It can be used in two ways:
as a prefix (--$x) or as a suffix ($x--).

The prefix decrement operator (--$x) decrements the value of the variable before using it in an expression.
For example, if $x is initially 5, --$x reduces its value to 4 and then returns 4.

The suffix decrement operator ($x--) decrements the value of the variable after using its value in an
expression. For example, if $x is initially 5, $x-- first uses the value 5 in an expression, then decrements $x
to 4.
