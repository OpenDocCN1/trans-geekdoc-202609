It is possible to consider the device architecture as a product that includes a smart sensor board along with a smart phone application. A module for measuring food is included on the sensor board. In an IoT network, the device is thus converted to a ‘thing’. The corresponding nutritional data of the food item is acquired through the smart phone application with the help of the smart phone camera.
