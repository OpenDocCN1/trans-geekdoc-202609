## 2.7 挑战

用于检测 COVID-19，ML 和 DL 方法是有用的，因为它们可以学习模式、保留它们并随后使用学习结果。然而，在许多情况下，ML 和 DL 系统的应用面临着重大挑战，例如数据稀缺、大规模预训练数据缺乏、大规模噪声数据和假阳性标记、医学科学和工程领域之间缺乏理解、数据保护和监管等。下面强调了一些重要术语：
