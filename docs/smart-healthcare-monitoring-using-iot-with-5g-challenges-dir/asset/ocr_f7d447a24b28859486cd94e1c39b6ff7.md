# 3.5.1 **Health Monitoring Wearable Systems**

The health tracking system differs based on the type of sensors used. There are four main types of wearable devices [31]:

+   1. **Bio-potential sensors**—Electrocardiography (ECG), electroencephalography (EEG), photoplethysmography (PPG), and electromyography (EMG) are examples of bio-potential sensors.
+   2. **Motion sensors**—The examples of the motion sensors are gyroscope and accelerometer.
+   3. **Environmental sensors**—The examples of the environmental sensors are ultrasound, temperature, and pressure.
+   4. **Biochemical sensors**—Analyzing the above signs provides a wealth of information about the patient’s or user’s well-being.
