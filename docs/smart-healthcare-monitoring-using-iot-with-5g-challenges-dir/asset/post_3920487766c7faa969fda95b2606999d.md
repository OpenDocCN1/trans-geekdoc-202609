## 2.7 CHALLENGES

For detecting COVID-19, ML and DL methods are useful as these can learn patterns, retain them, and use the learning subsequently. However, in many situations the application of ML and DL systems is confronted with significant challenges, such as data scarcity, the lack of large-scale pre-trained data, large noisy data and false positive labeling, a lack of understanding between medical science and engineering fields, data protection, and regulation, to name a few.
