# 8.1 BACKGROUND

The current disastrous outbreak of dreadful, rapidly spread COVID-19 (coronavirus disease), caused by SARS-CoV-2 (severe acute respiratory syndrome coronavirus-2), spreads continuously. On August 5, the cumulative number of COVID19 cases worldwide exceeded 200 million, and it was only six months before reaching 100 million cases. This week alone, more than 4.2 million new cases and more than 65,000 new deaths were reported, a slight increase compared to the previous week.
