### 4.1.2 Random Forest Regression (RFR)

RFR was initially proposed by Breiman [91] and adds a randomization layer to the bagging technique. Due to the Law of Large Numbers, this method’s strength rests in its reduced susceptibility to overfitting, making it a valuable instrument for predictive modeling. RFR excels at both classification and regression tasks through the intelligent incorporation of controlled variance. It constructs each tree of the ensemble using a distinct data aggregation approach.

RFR relies on bootstrap aggregation for decision trees. RFR differs from previous approaches that examine the optimum split across all variables. It randomly chooses a subset of predictors and finds the optimal split at each node. This novel approach changes categorization and regression tree construction. RFR outperforms support vector machines (SVM) and other ML models [91]. It just requires two parameters: the number of variables in the random subset at each node and the number of trees in the forest, making it user-friendly and overfit-resistant. Values for these parameters seldom matter [92]. In practical implementation, the dataset is divided into distinct segments corresponding to each input variable. The computation of the sum of squared error (SSE) involves the evaluation of anticipated and actual values at each of the given locations. Following that, the minimum sum of squared errors (SSE) value of the node is computed, as described in the reference [93].

### 4.1.3 K-Nearest Neighbors (KNN)

KNN algorithm is a well-established nonparametric method that aims to point the k-nearest data points to a query and categorize them using a majority vote. [94]. The method is widely recognized and utilized in modern computer programming techniques due to its efficacy, simplicity, and intuitive nature [95, 96]. A significant benefit of the KNN algorithm is its independence from a dedicated training phase as it highlights the capacity of KNN to classify data points without prior knowledge of the statistical properties of the training examples [97, 98].

### 4.2.1 Evaluation Metrics

In this study, the key evaluation metrics, namely $R^2$, $MAE$, $MSE$, and $RMSE$, were utilized to assess the performance of the developed predictive models. The $R^2$ metric measures the model's ability to explain the variability in the data, with higher values indicating a better fit. The $MAE$ metric quantifies the average magnitude of errors between predicted and actual values, offering a straightforward measure of accuracy. A lower $MAE$ implies better model performance. On the other hand, $MSE$ metric represents the average of the squared difference between the original and predicted values in the data set. It measures the variance of the residuals. Lastly, the $RMSE$ is similar to $MAE$ but places a greater penalty on larger errors, providing insights into the spread of prediction errors. A lower value of $MSE$ and $RMSE$ suggests that the model's predictions are generally close to actual values.
