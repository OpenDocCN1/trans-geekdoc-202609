## Abstract

聚对苯二甲酸乙二醇酯 PET 纤维增强聚合物 FRP 近期已开发出来，具有双线性拉伸应力-应变关系和大破裂应变 LRS 能力。本研究提出了一种利用机器学习 ML 技术准确预测 PET FRP 约束混凝土应力-应变行为的新方法。用于训练和测试机器学习模型的是包含 154 个轴向压缩试验试件的综合数据集，包括圆形和非圆形情况。三种先进的机器学习模型，即极端梯度提升 XGBoost、随机森林回归 RFR 和 K 近邻 KNN，被应用于预测圆形和非圆形试件的力学性能。XGBoost 一直优于 RFR 和 KNN，在预测两种试件类型的应力-应变曲线方面表现出更高的准确性。性能评估依赖于决定系数 R²、均方误差 MSE、均方根误差 RMSE 和平均绝对误差 MAE 等关键指标。此外，由 XGBoost 生成的预测应力-应变曲线与实验数据和机理模型进行了比较，突出了 XGBoost 在捕捉关键曲线点方面的优越性，并强调了其准确性和一致性。此外，还进行了特征重要性分析，结果显示 PET FRP 层数、纤维厚度 和 圆角半径 等参数显著影响应力-应变行为。

## 1 Introduction

研究人员已探索使用纤维增强聚合物 FRP 材料，如碳 FRP CFRP、玻璃 FRP GFRP 和芳纶 FRP AFRP 来约束混凝土柱，旨在提高其强度和变形特性 [1–7]。然而，FRP 约束混凝土中的一个关键挑战是当内部混凝土膨胀时 FRP 片材可能发生断裂，这受 FRP 材料拉伸性能的强烈影响 [8, 9]。

用于混凝土柱约束的常用 FRP 材料，如 CFRP、GFRP 和 AFRP，表现出线性弹性应力-应变行为，并在相对较低的破裂应变下易发生脆性破坏 [10]。然而，当 FRP 约束混凝土得到有效约束时，与普通混凝土相比表明其具有更大的延性能力。尽管如此，当 FRP 片材发生拉伸断裂时，材料的延性行为就会结束。值得注意的是，约束混凝土柱中 FRP 的破裂应变通常远低于通过拉伸条带试验测量的拉伸破裂应变 [11]。FRP 应变的效率通过将有效破裂应变除以拉伸破裂应变来量化，已观察到大破裂应变 LRS FRP 复合材料在促进约束混凝土延性方面比标准 FRP 材料提供更大的益处。这意味着使用 LRS FRP 复合材料在促进受限混凝土更延性的响应方面提供更多益处 [12–15]。此外，LRS FRP 复合材料在提高高强和超高强混凝土的变形能力方面显示出前景，特别是在暴露于冲击、爆炸和地震等巨大变形的应用中 [16, 17]。这使得它们适用于需要高延性的特殊建筑，如防护和地下设施 [10, 18]。

聚对苯二甲酸乙二醇酯 PET FRP 是一种由再生 PET 材料制成的大破裂应变 LRS FRP 复合材料，具有超过 7% 的拉伸破裂应变和相对较低的弹性模量。它为改造现有钢筋混凝土柱提供了一种经济有效的解决方案，尤其是在需要高变形能力时 [16, 18–20]。已对 FRP 约束混凝土柱的受压行为进行了广泛研究，包括圆形和非圆形，利用 FRP 高强度重量比和形状灵活性 [21–28]。圆形柱从 FRP 约束中显著受益，而非圆形柱表现出半有效约束，方形柱的强度增强相比圆形柱较小 [23, 25, 29]。非圆形柱中的圆角半径在 FRP 约束有效性中起关键作用，因为较大的圆角半径导致更均匀的约束压力和增强的抗压强度 [7, 25, 29–31]。

已开发出各种预测模型来估计 FRP 约束下混凝土的力学响应，分为设计导向型 [32–41] 和完整分析模型 [42–50]。Ozbakkaloglu 等人 [51] 进行了全面评估，其中他们系统地分析了总共 88 个专门为圆形截面 FRP 约束混凝土试件设计的应力-应变模型。Al-Salloum [52] 和 Lam 和 Teng [53] 提供的模型在具有不同圆角半径比的有限试件上表现良好。Wu 和 Wei 的模型 [54] 准确预测了材料的极限强度。在另一项研究中，Dong 等人 [55] 计算了圆形截面极限应变。Shehata 等人 [56] 模型很好地预测了最终强度。然而，它倾向于高估低约束试件的强度。在另一项研究中，使用并比较了多种力学模型来估计 PET FRP 约束混凝土的应力-应变特性 [57]。Pimanmas 等人 [57] 的预测模型优于其他模型。它准确预测了具有尖锐边缘试件的极限强度并与应力-应变响应相关。该模型在 PET 和 PEN FRP 约束圆形混凝土样品上表现良好。这些设计导向和分析导向模型使用数学模型和实验来预测材料行为。该背景包括基于预测检查、观察、建立、预测和修改模型。这些方法依赖于详细模型，涉及假设，并花费很长时间来生产精细复合材料。将异质材料行为整合到单一模型中很困难。尽管研究很多，但仍没有模型能够准确预测 FRP 约束复合材料的极限情况和应力-应变响应 [1]。

人工智能 AI 的应用在土木工程中预测混凝土力学性能方面变得越来越流行，从而节省了时间和成本。一些研究人员已利用机器学习 ML 方法预测地聚合物混凝土的抗压强度 [58–60]。另一些研究采用了 ML 模型来预测钢筋混凝土深梁的抗剪强度 [61–63]。在他们的研究中，Keshtegar 等人 [64] 利用混合回归和 ML 模型准确预测了 FRP 约束混凝土的极限状态。在另一项研究中，Zhang 等人 [65] 利用人工智能技术预测 FRP 材料的应力-应变曲线。Jiang 等人 [1] 进行的研究证明了数据驱动的 ML 模型在预测 FRP 约束混凝土应力-应变曲线方面相比传统数学模型具有优越的性能。这一发现强调了 ML 模型在准确预测 PET FRP 约束混凝土应力-应变行为方面的潜力，特别是在结构设计和响应预测的背景下。

因此，在本研究中，提出了一种利用 ML 技术准确预测 PET FRP 约束混凝土应力-应变曲线的新方法。该研究主要侧重于预测应力-应变曲线中的关键参数，包括峰值、斜率变化、过渡结束和最大值。首先，汇编并系统整理了包含 154 个 PET FRP 约束混凝土轴向压缩试验试件的完整数据集。该数据集由 103 个圆形试件和 51 个非圆形试件组成，用于模型训练和测试。本研究采用了三种先进的 ML 模型，即极端梯度提升 XGBoost、随机森林回归 RFR 和 K 近邻 KNN，来预测圆形和非圆形试件 PET FRP 约束混凝土的力学性能。为了评估三种 ML 模型的性能，采用了四个关键评估指标，决定系数 R²、均方误差 MSE、均方根误差 RMSE 和平均绝对误差 MAE。基于评估指标，XGBoost 模型在预测力学性能方面相比 RFR 和 KNN 被发现是最准确的。此外，由 XGBoost 预测的圆形和非圆形试件 PET FRP 约束混凝土的完整应力-应变曲线与实验曲线进行了比较
