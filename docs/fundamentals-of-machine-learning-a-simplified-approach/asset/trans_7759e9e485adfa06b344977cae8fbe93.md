# 67). 何时会使用分类而非回归？

分类用于你的目标是类别型时，而回归用于目标变量是连续时。分类和回归都属于监督 [机器学习算法](https://www.simplilearn.com/10-algorithms-machine-learning-engineers-need-to-know-article "机器学习算法")。

分类问题的示例包括：

 预测是或否  

 估计性别  

 动物的品种  

 颜色的类型  

回归问题的示例包括：

 估计产品的销售额和价格  

 预测团队的得分  

 预测降雨量

# 68). 什么是过拟合，以及如何避免它？  

![](d2d_images/chapter_title_below.png)  

过拟合是指模型学习训练集过于彻底，将训练数据中的随机波动视为概念。这些波动影响模型的泛化能力，并且不适用于新数据。  

当模型接收训练数据时，它会显示100%的准确率——技术上是一个略小的损失。但是，当我们使用测试数据时，可能会出现错误并低效。这种情况被称为过拟合。  

避免过拟合的多种方法包括：

 正则化。它在目标函数中加入对特征的成本项  

 构建简单模型。通过减少变量和参数，可以降低方差  

 如k折叠交叉验证等交叉验证方法也可以使用  

如果某些模型参数容易导致过拟合，可以使用LASSO等正则化技术，对这些参数进行惩罚。
