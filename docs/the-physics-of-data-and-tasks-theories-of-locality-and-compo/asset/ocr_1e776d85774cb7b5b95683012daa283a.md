ONE-STEP GRADIENT DESCENT Finally, to support the connection with standard training techniques, we consider a simplified setting where a linear architecture is trained via gradient descent to predict the token $x_{t+1}$ given an adjacent tuple $(x_1, \dots, x_t)$. This task corresponds to learning the score function $E[x_t(0)|x_{(t)}]$, which is in invariant to exchanging the tuple $(x_1, \dots, x_t)$ with a synonym. As proved in Section E.2, one step of gradient descent aligns the learned weights with the empirical token-tuple correlations. If the size of the training set is large enough for the accurate measure of correlations, the network can build a representation of the tuple $(x_1, \dots, x_t)$, which is invariant to exchanging synonyms. This invariance is empirically observed for the U-Net in Figure 57 of Section E.4.
