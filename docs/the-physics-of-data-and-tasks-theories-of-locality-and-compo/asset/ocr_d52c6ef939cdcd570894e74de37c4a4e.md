Therefore:


where $n_k$ is the number of sequences $x \in S$ having Hamming distance $\Delta_{xx}=k$ from $x$. Since the sequences are sampled randomly, the numbers $n_1, ..., n_s$ are distributed according a multivariate hypergeometric distribution,

```
$P(n_1, ..., n_s) = \frac{\prod_{k=1}^s \binom{v-1}{n_k}}{\binom{mv-1}{s}} \quad (294)$
```

which averages over

```
$$\langle n_k\rangle_S = \frac{mv-1}{vs-1} \left( \frac{s}{k} \right) (v-1)^k = f \binom{s}{k}(v-1)^k, \quad (295)$
```

```
$f = \frac{mv-1}{vs-1}. \quad (296)$
```

```
$$\langle\tilde{\psi}(y)\rangle_\psi = \delta_{	ilde{y},y}B(0) + f \Psi_y \sum_{k=1}^s B(k) \left( \frac{s}{k} \right) (v-1)^k. \quad (297)$
```

```

```

which gives

```
$$\langle\tilde{\psi}(y)\rangle_\psi = \delta_{	ilde{y},y}B(0) + f \Psi_1 [1-B(0)]. \quad (299)$
```
