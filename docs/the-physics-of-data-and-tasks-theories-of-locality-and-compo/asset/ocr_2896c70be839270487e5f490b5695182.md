# APPENDIX: A PHASE TRANSITION IN THE DIFFUSION PROCESS

# C.1 BELIEF PROPAGATION INITIALIZATION FOR THE DENOISING OF THE RHM

As discussed in Section 4.4, we define the diffusion process for the input variable $X_t^{(0)}$. In particular, its value $x(t)$ at time $t$ is

```
$x(t) = \sqrt{a_t}x(0) + \sqrt{1-a_t}\eta,\quad(276)$
```

with $\eta \sim \mathcal{N}(0, \mathbf{I}_v)$ and $x(0)$ its starting value at time $t_1$ is a one-hot-encoding vector of the factor $x(0) = e_{\mu_h}$. Given the value $x(t)$, the conditional probabilities for the values of $x(0)$ are given by Bayes rule

```
$p(x(0) = e_{\mu_h}|x(t)) = \frac{p(x(t)|x(0) = e_{\mu_h})p(x(0) = e_{\mu_h})}{\sum p(x(t)|x(0) = e_{\lambda})}\quad(277)$
```

The prior probabilities on $x(0)$ are taken to be uniform over the alphabet, e.g., $p(x(0) = e_{\lambda}) = 1/v, \lambda$, while $p(x(t)|x(0) = e_{\mu_h})$ is given by the diffusion process of Equation 276:

```
$p(x(t)|x(0) = e_{\mu_h}) = C_t \exp\left[-\frac{1}{2(1-\bar{a}_t)}\sum(x_y(t) - \sqrt{\bar{a}_t}e_{\mu_h})^2\right]\\= C_t \exp\left[-\frac{||x(t)||^2 + \bar{a}_t}{2(1-\bar{a}_t)}\right]\exp\left[frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_y(t)\right]\quad(278)$
```

where $C_t$ is the normalization constant. Putting Equation 278 into Equation 277, we obtain

```
$p(x(0) = e_{\mu_h}|x(t)) = \frac{1}{Z}e^{\frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_y(t)}\quad(279)$
```

with $Z = \sum_{\lambda=1}^v e^{\frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_{\lambda}(t)}$
