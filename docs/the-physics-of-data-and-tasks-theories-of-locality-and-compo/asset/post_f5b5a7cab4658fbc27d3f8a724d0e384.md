
## C.2 BELIEF PROPAGATION EQUATIONS

Since each sequence $x = \bar{x}$ the association $y \leftarrow \bar{x}$ is done randomly, independently of $\Delta_{xx}$, then from Equation 289g, we have $\langle\psi(y,x)\rangle_{y\leftarrow x} \approx 1/v$. More precisely, since we have associated the reference sequence $\bar{x}$ to $\tilde{y}$:

$$\Psi_y = \langle\psi(y,x)\rangle_{y\leftarrow x} = \frac{m-1}{mv-1}\delta_{y,\tilde{y}} + \frac{m}{mv-1}(1-\delta_{y,\tilde{y}}). \quad (292)$$

Therefore:

$$\langle\tilde{\psi}(y)\rangle_\psi = \delta_{\tilde{y},y}B(0) + \Psi_y \sum_{k=1}^s B(k) \left( \sum_{x\in S} \Delta_{xx}=k} 1 \right) \quad (293)$$
$$= \delta_{\tilde{y},y}B(0) + \Psi_y \sum_{k=1}^s B(k) \langle n_k\rangle_S,$$

where $n_k$ is the number of sequences $x \in S$ having Hamming distance $\Delta_{xx}=k$ from $x$. Since the sequences are sampled randomly, the numbers $n_1, ..., n_s$ are distributed according a a multivariate hypergeometric distribution,

$$P(n_1, ..., n_s) = \frac{\prod_{k=1}^s \binom{v-1}{n_k}}{\binom{mv-1}{s}} \quad (294)$$

which averages over:

$$\langle n_k\rangle_S = \frac{mv-1}{vs-1} \left( \frac{s}{k} \right) (v-1)^k = f \binom{s}{k}(v-1)^k, \quad (295)$$

with

$$f = \frac{mv-1}{vs-1}. \quad (296)$$

Therefore:

$$\langle\tilde{\psi}(y)\rangle_\psi = \delta_{\tilde{y},y}B(0) + f \Psi_y \sum_{k=1}^s B(k) \left( \frac{s}{k} \right) (v-1)^k. \quad (297)$$

From the beliefs Equation 286, we see that:

$$\sum_{k=1}^s B(k) \left( \frac{s}{k} \right) (v-1)^k = \sum_{k=1}^s B(k) \left( \frac{s}{k} \right) (1-\epsilon) \left( 1 + \frac{\epsilon}{v} \right)^{s-k}$$
$$= \left[ 1 - \left( 1 - \epsilon + \frac{\epsilon}{v} \right)^s \right] = 1 - B(0), \quad (298)$$

which gives:

$$\langle\tilde{\psi}(y)\rangle_\psi = \delta_{\tilde{y},y}B(0) + f \Psi_1 [1-B(0)]. \quad (299)$$

The normalization constant is:

$$\langle Z_{\psi}\rangle_\psi = \sum_y \langle\tilde{\psi}(y)\rangle_\psi = B(0) + f [1-B(0)]. \quad (300)$$

## APPENDIX: A PHASE TRANSITION IN THE DIFFUSION PROCESS

Finally, we obtain the average belief for $Y$:

$$\langle\bar{y}(y)\rangle_\psi = \frac{\langle\bar{y}(y)\rangle_\psi}{\langle Z_y\rangle_\psi} = \frac{\delta_{y,\bar{y}}B(0) + f\Psi_y[1-B(0)]}{B(0) + f[1-B(0)]} \quad (301)$$

We have that:

- for $y = \bar{y}$
  $$\langle\bar{y}(\bar{y})\rangle_\psi = \frac{B(0) + f\frac{m-1}{mv-1}}[1-B(0)]}{B(0)+f[1-B(0)]} \quad (302)$$
- for $y \neq \bar{y}$
  $$\langle\bar{y}(y)\rangle_\psi = f\frac{m}{mv-1}B(0) + f[1-B(0)] \quad (303)$$

**ITERATING LAYERS** The average messages of two kinds: one for the reference $\bar{y}$ Equation 302 and another for the $y \neq \bar{y}$, and they both depend on the previous beliefs through $B(0) = (1-\epsilon^s)$. Therefore, the average beliefs at the higher level have the same structure as that at the lower level Equation 285. We then define a new $e'$:

$$1-e' = \frac{e'}{v} = \frac{\frac{(1-\epsilon^s)^s}{v} + f\frac{m}{mv-1}[1-(1-\epsilon^s)^s]}{(1-\epsilon^s)^s + f[1-(1-\epsilon^s)^s]} \quad (304)$$

$$p' = \frac{p^s + f\frac{m-1}{mv-1}(1-p^s)}{p^s + f(1-p^s)} = F(p) \quad (305)$$

$p' = 1-e'/v$ and $p = 1-\epsilon/v$. The derivative of $F(p)$ with respect to $p$ is given by:

$$F'(p) = \frac{m(v-1)}{mv-1}\frac{fs^{s-1}}{[p^s+f(1-p^s)]^2} = fs\frac{p^{s-1}}{[p^s+f(1-p^s)]^2} + \mathcal{O}(\frac{1}{v}) \quad (306)$$

We can extend the tree in Figure 42 iteratively to higher levels of the hierarchy, where the variables $Y$ take the place of the variables $X_i$ and so on.

The iteration Equation 305 has fixed points $p=1$ (corresponding to $\epsilon=0$) or $p=1/v$ (corresponding to $\epsilon=1$). An additional repulsive fixed point at $f$ appears if

$$F'(1) < 1, \quad (307)$$

### C.2.1.2 Downward iteration

We consider the downward process when we try reconstructing the reference association $\hat{y} \to \hat{X}_1, \dots, \hat{X}_s$ from the higher-level variable $Y$ to the lower-level tuple $X_1, \dots, X_s$, via the set of rules $\Psi$. The message received by variable $X_1$ (Figure 42):

$$\hat{v}_1(x_1) = \sum_{x_2, \dots, x_s \in \mathcal{A}} \Psi(y, x_1, \dots, x_s) v_y(y) \prod_{i=2}^s v_{X_i}(x_i) = \hat{v}_{X_1}(x_1) + \sum_{x_2 \dots \in \mathcal{D}_{\Delta x_i>0}} \Psi(y, x) \prod_{j \neq i}^s v_{X_j}(x_j) \quad (310)$$

**AVERAGED** To study the iteration of Equation 310 analytically, we compute the average message $\langle\hat{v}_i(x_i)\rangle$ over realizations of the random rules $\Psi$ as done in Section C.2.1.2 for upward iteration. We call $n_{X_1}$ the number of sequences having $X_1 = x_1$, that have been sampled by choice of rules. The rules $n_{X_1}$ are distributed according to multivariate hypergeometric distribution:

$$P(\{n_{X_i} \in \mathcal{A}\}) = \frac{\binom{v-1}{n_{X_1}}}{\dots} \quad (311)$$

which gives averages:

$$\langle n_{X_1}\rangle = \frac{mv-1}{vs-1} ... \quad (312)$$
$$\langle n_{X_i \neq X_1}\rangle = \frac{mv-1}{vs-1} \quad (313)$$

### C.2.1.2 Downward messages

Award downward messages over choices of rules $\psi$, we obtain:

- for $x_1 \neq \bar{X}_1$:
  $$\langle v_i(x_1)\rangle_\psi = \sum_{y} v_i(y) \langle\sum_{x_2 \dots x_s \in S} \psi(y,x)\rangle_{y\leftarrow x} \prod_{i=2}^s \nu_t(x_i) = \frac{m-v_i(y)}{mv-1} \delta_{x_k \in S} \dots \frac{m-v_i(y)}{mv-1} f \quad (314)$$
  where $\delta_{x_k \in S} = \frac{n_{X_k \neq X_1}}{v^{s-1}-1}$,

- for $x_1 = \bar{X}_1$:
  $$\langle v_i(X_1)\rangle_\psi = \prod_{i=2}^s \nu_t(x_i) + \sum_{y} v_i(y) \langle\sum_{x_2 \dots x_s \in S, x \neq y} \psi(y,x)\rangle_{y\leftarrow x} \prod_{i=2}^s \nu_t(x_i) = v_i(x_1) \prod_{i=2}^s \nu_t(x_i) + \frac{m-v_i(y)}{mv-1} [1 - \prod_{i=2}^s \nu_t(X_i)] \quad (315)$$

where $\delta_{x_k \in S} = \frac{n_{X_1}}{v^{s-1}-1}$.

## C.2 BELIEF PROPAGATION EQUATIONS

The normalization factor is:

$$\langle Z_l \rangle_\phi = \sum_{x_1} \langle \tilde{v}(x_1)\rangle_\phi = v_l(\tilde{y}) \prod_{i=2}^m v_t(\tilde{x}_i) + f \frac{m-v_l(\tilde{y})}{mv-1} \left[ 1 - \prod_{i=2}^m v_t(\tilde{x}_i) \right] + (v-1)f \frac{v_l(\tilde{y})}{mv-1} \quad (316)$$

which gives the normalized average messages:

- for $x_1 = \tilde{X}_1$
  $$\langle \tilde{v}(\tilde{X}_1)\rangle_\phi = \frac{v_l(\tilde{y}) \prod_{i=2}^m v_t(\tilde{x}_i) + f \frac{m-v_l(\tilde{y})}{mv-1} [1 - \prod_{i=2}^m v_t(\tilde{x}_i)]}{\langle Z_l \rangle_\phi} \quad (317)$$
- for $x_1 \neq \tilde{X}_1$
  $$\langle \tilde{v}(x_1)\rangle_\phi = f \frac{m-v_l(\tilde{y})}{mv-1}}{\langle Z_l \rangle_\phi} \quad (320)$$

**ITERATING OVER LAYERS** As for the upward process, the messages for downward process are of two kinds, one for the correct $x_1$ and one for the other values $x_1 \neq \tilde{X}_1$. To obtain a mean-field description of the BP process, we combine the average downward messages with the average upward ones by substituting $v_l(\tilde{x}_i) \to \tilde{v}(\tilde{x}_i)$ in Equation 317. We use the notation:

$$p_t^{(l)}(\tilde{X}_i) = p_t^{(l)} \quad (319)$$
$$p_l^{(l)}(\tilde{X}_i) = p_l^{(l)} \quad (320)$$

where the upwards and downwards beliefs $p_t^{(l)}, p_l^{(l)}$ in the latent variable $X_i^{(l)}$ depend only on the layer $\ell$ and not on the specific position $i$ inside the process. Putting together Equation-305 and Equation 317, we obtain:

$$p_t^{(l+1)} = F_t(p_t^{(l)}) \quad (321)$$
$$p_l^{(l)} = F_l(p_l^{(l+1)}, p_t^{(l)}) \quad (322)$$

with

$$F_t(p) = \frac{p^s + f \frac{m-v-1}{mv-1}}{p^s + f(1-p^s)} \quad (323)$$

$$F_l(q_l, p) = \frac{q^{s-1} + f \frac{m-q}{mv-1}(1-p^{s-1})}{q^{s-1} + f \frac{m-q}{mv-1}(1-p^{s-1}) + (v-1)f} \quad (324)$$
