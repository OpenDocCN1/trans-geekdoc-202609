A model which is local (as $f^{LC}$ in Equation 20) can be obtained by lifting the constraint of weight-sharing, which forces, for $h=1,\dots,H$, the same filter $w_h$ to apply to all patches $x_i$.

**Definition 2.3.2 (the one-hidden LCN).** A one-hidden layer-connected network with $H$ hidden neurons is given by:

$$f^{CN}(\mathbf{x}) = \frac{1}{\sqrt{H}} \sum_{h=1}^{H}\sum_{i\in\mathcal{P}} a_{hj}\sigma(w_{hi}+b_{hj}), (30)$$

For all $i \in \mathcal{P}$ and $h=1,\dots,H$: $x_i$ is an $s$-dimensional patch of $\mathbf{x}$, $w_{hj} \in \mathbb{R}^s$ is a filter with filter size $s$, $b_h \in \mathbb{R}$ is a scalar value, and $a_{hj} \in \mathbb{R}$ is a scalar weight.

The above reduces to a fully-connected network when the filter size is set to the input dimension, $s=d$, and $\mathcal{P}=\{1\}$. With the target functions using one of the two forms in Equation 20, our framework contains the case where the observations are generated by neural networks such as Definition 2.3.1 and Definition 2.3.2.

We introduce the concept of Neural Tangent Kernel (NTK):

**Definition 2.3.3 (Neural Tangent Kernel).** For a neural network function $f(\mathbf{x};\theta)$ where $\theta=(\theta_1,\dots,\theta_N)$ denotes the complete set of parameters and $N$ total number of parameters, the Neural Tangent Kernel (NTK) is defined as:

$$K_{NTK}(\mathbf{x},\mathbf{y}) = \sum_{n=1}^{N} \partial_{\theta_n}f(\mathbf{x},\theta)\partial_{\theta_n}f(\mathbf{y},\theta). (31)$$

## 2.3 CONVOLUTIONAL AND LOCAL KERNELS

As the functions in Equation 20, $f^{CN}$ is written as a combination of a lower-dimensional kernel $K_{NTK}^{FC}$ acting on patches, and the dimensionality of the constituent kernel coincides with the filter size of the corresponding network.

**Lemma 2.3.2.** Call $K_{NTK}^{LC}$ the NTK of a locally-connected network function (Definition 2.3.2) with size $s$ acting on $d$-dimensional inputs. Then:

$$K_{NTK}^{LC}(x,y) = \frac{1}{|\mathcal{P}|} \sum_{i\in\mathcal{P}} K_{NTK}^{FC}(x, y). (33)$$

Following the general structure of Equation 32 and Equation 33, we define local ($K^{LC}$) and convolutional ($K^{CN}$) kernels as sums of lower-dimensional constituent kernels $C$:

$$K^{CN}(x,y) = \frac{1}{|\mathcal{P}|^2} \sum_{i\in\mathcal{P}} C(x, y), (34a)$$

$$K^{LC}(x,y) = \frac{1}{|\mathcal{P}|} \sum_{i\in\mathcal{P}} C(x, y). (34b)$$

These are characterized by the dimensionality of the constituent kernel $C$, size $s$ (for the student, or $t$ for the teacher) and a smoothness exponent: the nonanalytic behavior of the kernel at small distance $C(x,y) \sim |x-y|^{-\alpha}$ (for the student, or $\alpha$ for the teacher). If $\alpha \in \mathbb{N}$, then the constituent kernel $C$ is at least $n$ times differentiable.

For instance, the NTK of ReLU units $K_{NTK}^{FC}$ has a cusp at the origin, $\alpha=1$. Moreover, in the $H \to \infty$ limit, a network initialized with random weights converges to a Gaussian process. The covariance of the kernel for ReLU activations, has nonanalytic behavior with $\alpha=3$.

## MERCER'S DECOMPOSITION

The eigendecomposition of the constituent kernel $C$ induces an eigendecomposition of convolutional and local kernels under the following assumptions:

- i) The constituent kernel $C(x,y)$ on $\mathbb{R}^s \times \mathbb{R}^s$ admits the following Mercer's decomposition:
$$C(x,y) = \sum_{\rho=1}^{\infty} \lambda_{\rho} \phi_{\rho}(x) \phi_{\rho}(y). (35)$$
with (ordered) eigenvalues $\lambda_{\rho}$ and eigenfunctions $\phi_{\rho}$ such that, with $\phi^{(s)}(dx)$ denoting the $s$-dimensional patch measure, $\phi_1(x)=1$ for all $x$ and $\int d^s x \phi_{\rho}(x)=0$ for all $\rho > 1$;

- ii) Convolutional and local kernels from Equation 34 have non-overlapping patches, i.e., $d$ is an integer multiple of $s$ and:
$$\mathcal{P} = \{n \times s \mid n=1, \dots, d/s\} (36)$$
with $|\mathcal{P}|=d/s$;

- iii) The $s$-dimensional marginals on the $d$-dimensional input measure $p^{(d)}(dx)$ are all identical and equal to $p^{(s)}(dx)$.

The part of assumption $i)$ regarding the eigenfunctions' properties is satisfied, for example, when the constituent kernel $C$ is isotropic and data are distributed over a $d$-dimensional torus. The request of non-overlapping patches in assumption $ii)$ can be relaxed at the price of further assumptions, i.e., $C(x,y)=c(x-y)$ and data distributed over the torus, so that $C$ is diagonalized in Fourier space (details in Section A.3).

**Lemma 2.3.3 (Spectra of convolutional kernels).** Let $K^{CN}$ be a convolutional kernel with constituent kernel $C$ satisfying assumptions $i)$, $ii)$ and $iii)$. $K^{CN}$ has the following Mercer's decomposition:

$$K^{CN}(x,y) = \sum_{p=1}^{\infty} \Lambda_p \Phi_p(x)\Phi_p(y), \quad (37)$$

with eigenvalues and eigenfunctions:
$$\Lambda_1 = \lambda_1, \Phi_1(x)=1; \Lambda_p = \frac{1}{d}\lambda_p, \Phi_p(x) = \frac{1}{\sqrt{d}} \sum_{i\in\mathcal{P}} K_{NTK}^{FC}(\mathbf{x}_i, \mathbf{y}_j). (38)$$

**Lemma 2.3.4 (Spectra of local kernels).** Let $K^{LC}$ be a local kernel with constituent kernel $C$ satisfying assumptions $i)$, $ii)$ and $iii)$. Then $K^{LC}$ has the following Mercer's decomposition:

$$K^{LC}(x,y) = \sum_{p=1}^{\infty} \Lambda_p \Phi_p(x)\Phi_p(y), \quad (39)$$

with eigenvalues and eigenfunctions:
$$\Lambda_1 = \lambda_1, \Phi_1(x)=1; \Lambda_p = \frac{1}{d}\lambda_p, \Phi_p(x) = \frac{1}{\sqrt{d}} \sum_{i\in\mathcal{P}} K_{NTK}^{FC}(\mathbf{x}_i, \mathbf{y}_j). (40)$$
