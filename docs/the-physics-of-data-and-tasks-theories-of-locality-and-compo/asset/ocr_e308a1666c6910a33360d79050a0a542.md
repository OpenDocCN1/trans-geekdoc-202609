BEYES-OPTIMAL DENOISING OF THE RHM USING BELIEF PROPAGATION We consider the Random Hierarchy Model [Cag+24], and use the notation $h^{(\ell)}$ to indicate the value at level $\ell$ and position $i \in [s^{-\ell}]$. The leaf nodes $h^{(1)}, \dots, h^{(L)}$ correspond to the visible tokens, while the upper-level nodes represent latent variables. We define the distance tree $t$ between two visible tokens as the number of edges between them and their lowest common ancestor. Their corresponding space distance $r$ is $r = s^t - 1$. Because of the hierarchical structure generating the data, the visible tokens have non-trivial spatial correlations, which depend on their tree distance [CW24].

As discussed in Chapter 4, knowing the production rules and the tree structure of the RHM, the probabilities of the latent variables, conditioned on some observation, can be reconstructed exactly SF25 using the Belief Propagation (BP) algorithm [MM09]. Specifically, if an RHM datum $x_0$ is corrupted by some noise, e.g., by masking a fraction of tokens, resulting in a noisy observation $x_t$, then BP can be used:

+   - compute the marginal probabilities of any latent or visible variables, conditioned on the noisy observation $x_i: p(h^{(i)}|x_i)$;n sample directly from the posterior $p(x_0|x_i)$.
