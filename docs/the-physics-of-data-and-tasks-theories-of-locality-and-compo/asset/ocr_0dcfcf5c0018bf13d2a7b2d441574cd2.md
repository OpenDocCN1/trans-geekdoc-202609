# C.2.1.2 Downward iteration

We consider the downward process when we try reconstructing the reference association $\hat{y} \to \hat{X}_1, \dots, \hat{X}_s$ from the higher-level variable $Y$ to the corresponding lower-level tuple $X_1, \dots, X_s$, via the set of rules $\Psi$. The message received by the variable $X_1$ (**Figure 42**):

```
$\hat{v}_1(x_1) = \sum_{\substack{x_2, \dots, x_s \in \mathcal{A}^{(s-1)} \ y \in Y}} \Psi(y, x_1, \dots, x_s) \ v_y(y) \prod_{i=2}^s v_{X_i}(x_i) \\n\= \hat{v}_{X_1}(x_1) v_y(y) \prod_{i=2}^s v_{X_i}(x_i) + \sum_{i=2}^s v_{X_i}(x_i) \sum_{\substack{x_2, \dots, x_s \ x \in \mathcal{D}_{\Delta x_i>0}}} \Psi(y, \mathbf{x}) \prod_{j \neq i}^s v_{X_j}(x_j) \\quad (310)$
```
