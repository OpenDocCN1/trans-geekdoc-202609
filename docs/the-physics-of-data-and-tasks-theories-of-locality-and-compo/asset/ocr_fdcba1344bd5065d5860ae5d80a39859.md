Hilbert Space (RKHS), the kernel regression estimator $\hat{f}$
f^*$ is defined by:

```
$$\hat{f} = \text{argmin}_{f \in \mathcal{H}} \left( \frac{1}{p} \sum_{\nu=1}^p (f(x_{\nu}) - f^*)^2 + \lambda ||f||_{\mathcal{H}}^2 \right)$
```

where $\$\cdot\|$ denotes the RKHS norm and $\lambda$ is the ridge regularization parameter. The ridgeless case $(\lambda \rightarrow 0^+)$ corresponds to the minimum-norm interpolation solution. The optimization problem in Equation 21 is convex and its unique solution is

```
$$\hat{f}(\mathbf{x}) = \frac{1}{p} \sum_{\nu=1}^p K(x_{\nu}, \mathbf{x}) \left( \frac{1}{p} K_p + \lambda I_p \right)^{-1}_{\nu} f^*_{\nu}$
```

where $K_p$ is the Gram matrix defined as $(K_p)_{\mu\nu} = \mathcal{K}(x_{\mu}, x_{\nu})$, and $I_p$ is the identity matrix of dimension $P$. Our objective is the generalization error, defined as expected mean squared error over the data distribution $p(d^x)$ and the target $f^*$, i.e.,

```
$$\mathcal{E}_{X,f^*} = \left[ (f(\mathbf{x}) - f^*(\mathbf{x}))^2 \right]$
```

STATISTICAL MECHANICS OF GENERALIZATION IN KERNEL REGRESSION In general, theoretical understanding of the generalization error is still an open problem. Recent works [BCP20; CBP21] derived approximate expressions for $\mathcal{E}$ using the decomposition of the target function in the eigenbasis of the kernel. Mercer's theorem allows any positive-definite kernel $\mathcal{K}$ to be expressed in terms of its eigenvalues $(\lambda_{\rho})$ and eigenfunctions $(\phi_{\rho})$ as:

```
$$\mathcal{K}(\mathbf{x}, \mathbf{y}) = \sum_{\rho=1}^{\infty} \lambda_{\rho} \phi_{\rho}(\mathbf{x})\phi_{\rho}(\mathbf{y}), \quad \int \mathcal{K}(\mathbf{x}, \mathbf{y}) p(d^y) = \lambda_{\rho} \phi_{\rho}(\mathbf{x})$
```

Defining the kernel features $\phi_{\rho}(\mathbf{x}) = \sqrt{\lambda_{\rho}} \phi_{\rho}(\mathbf{x})$, since the kernel's eigenfunctions form a complete basis, the target function and estimator can be decomposed as:

```
$$\f^*(\mathbf{x}) = \sum_{\rho} w^*_{\rho} \phi_{\rho}(\mathbf{x}), \quad f(\mathbf{x}) = \sum_{\rho} w_{\rho} \phi_{\rho}(\mathbf{x})$
```

The replica method — a heuristic technique from statistical physics [MPV87b;BCP20; CBP21] yields the following set of equations in the ridgeless limit $\lambda \rightarrow 0^+$

```
$$\mathcal{E}(P) = \sum_{\rho} \frac{\mathbb{E}[|w_{\rho}|^2]}{\lambda_{\rho}} \left( \frac{1}{\lambda_{\rho}} + \frac{P}{t(P)} \right)^{-2} \left( 1 - \frac{P_{\gamma(P)}}{t(P)^2} \right)$
```

```
$t(P) = \sum_{\rho} \left( \frac{1}{\lambda_{\rho}} + \frac{P}{t(P)} \right)^{-1}, \quad \gamma(P) = \sum_{\rho} \left( \frac{1}{\lambda_{\rho}} + \frac{P}{t(P)} \right)^{-2}$
```
