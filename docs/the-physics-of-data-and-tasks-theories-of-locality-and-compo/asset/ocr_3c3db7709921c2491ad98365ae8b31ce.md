+   * Two patches $x_i$ and $x_j$ overlap if $x_i \cap x_j 
eq \emptyset$. The overlap $x_{ij} \equiv x_i \cap x_j$ is an $o$-dimensional patch of $x$, with $o=|x_i \cap x_j|$

+   * Let $\mathcal{P}$ denote the set of patches associated with a given kernel/architecture. We denote with $\mathcal{P}_i$ the set of patches which overlap with $x_i$, i.e.,

```
$\mathcal{P}_i = \{i-s+1, \dots, i+s-1\} = \{\mathcal{P}_{-i}, i, \mathcal{P}_{+i}\};$
```

+   * Given two overlapping patches $x_i$ and $x_j$ with $o$-dimensional overlap, the union $x_{ij} \equiv x_i \cup x_j$ and differences $x_{i\setminus j} \equiv x_i \setminus x_j$ and $x_{j\setminus i} \equiv x_j \setminus x_i$ are all patches of $x$, with differences $2s-o$, $s-o$ and $s-0$, respectively.

We also use the following notation for denoting subspaces of the $k$-space $\approx \mathbb{Z}^s$

```
$\mathcal{F}^u = \{k=2\pi n \mid n \in \mathbb{Z}^s; n_v \neq 0 \\forall v < u \leq s\}$. (137)
```

$\mathcal{F}^s$ is the set of all wavevectors $k$ having nonzero extremal components $k_l$. $\mathcal{F}^u$ is formed by first considering only wavevectors having the last $s-u$ wavevectors equal to zero, then asking the result $u$-dimensional wavevectors to have nonvanishing extremal components. Practically, $\mathcal{F}^u$ contains wavevectors which can be explicitly specified by the first $u$-dimensional patch $\mathbfmathbfk}^{(u)}=(k_1, \dots, k_u)$ but not the first $(u-1)$-dimensional one. Notice that, in order to compare $K_l$ in different $\mathcal{F}^s$, we have introduced an index $u$ denoting the dimensionality of the patch.
