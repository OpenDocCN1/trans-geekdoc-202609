The probability of the type $P(h^{(0)}=\bar{a} \dots)$ are given by $1-P(h^{(0)}=\bar{a} \dots)$. Since these averages only depend on the layer level $\ell$, they are the same for $P(h_m^{(\ell-1)},h_m^{(\ell-2)})_{\psi}$. The last term to compute is the point $P(h_m^{(\ell-1)},h_m^{(\ell)}=y)$ which can be expressed in terms of BP messages:

```
$$\ P(h_m^{(\ell-1)}=a_m, h_m^{(\ell)}=y) \propto \sum_{a_{m+1},\dots,a_s \in V^{(\ell-2)}} \prod v_{\uparrow}(y,a_i,a_m,\dots,a_s) v_{\uparrow}(h_i^{(\ell)}=a_i) v_{\uparrow}(h_m^{(\ell)}=a_m) \prod_{i\neq l,m} v_{\uparrow}(h_i^{(\ell)}=a_i). \quad (360)$$
```

Computing the averages over the rules, we have:

```
\left\langle h_l^{(l-1)} = \bar{a}_l, h_m^{(l-1)} = \bar{a}_m | \bar{y} \right\rangle_\varphi = p_l^{(l-1)} / Z_y^{(l-1)},
```

```
\left\langle h_l^{(l-1)} = \bar{a}_l, h_m^{(l-1)} \neq \bar{a}_m | \bar{y} \right\rangle_\varphi = p_{\ell-1}(1-p_{\ell-1})\frac{m-1}{mv} / Z_y^{(l-1)},
```

```
\left\langle h_l^{(l-1)} = \bar{a}_l, h_m^{(l-1)} \neq \bar{a}_m | \bar{y} \right\rangle_\varphi = f(1-p_{\ell-1})^2\frac{m-1}{mv} / Z_y^{(l-1)},
```

```
Z_y^{(l-1)} = p_l^{(l-1)} + f\frac{m-1}{mv}(1-p_{\ell-1})^2,
```

```
\left\langle h_l^{(l-1)} = \bar{a}_l, h_m^{(l-1)} \neq \bar{a}_m \right\rangle_\varphi = 0,
```

```
\left\langle h_l^{(l-1)} \neq \bar{a}_l, h_m^{(l-1)} = \bar{a}_m | \bar{y} \right\rangle_\varphi = p_{\ell-1}(1-p_{\ell-1})\frac{m}{mv} / Z_y^{(l-1)},
```

```
\left\langle h_l^{(l-1)} \neq \bar{a}_l, h_m^{(l-1)} \neq \bar{a}_m | \bar{y} \right\rangle_\varphi = f(1-p_{\ell-1})^2\frac{m}{mv} / Z_y^{(l-1)},
```

```
Z_y^{(l-1)} = f\frac{m}{mv}(1-p_{l-1})^2,
```

# D.2 GAUSSIAN RANDOM FIELD

Consider a Gaussian random field $X(u)$ with mean zero and covariance function $C(u,u')$. Assume that the field is isotropic, so $C(u,u') = C(|u-u'|)$. For large $|u-u'|$, the covariance follows $C(r) \sim r^{-a}$. This is used to model the noise in the hierarchical process.
