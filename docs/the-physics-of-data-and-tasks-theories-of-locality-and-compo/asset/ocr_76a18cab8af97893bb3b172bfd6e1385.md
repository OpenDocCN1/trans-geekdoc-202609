# DEEP GENERATIVE MODELING

# 1.3 unsupervised learning

The goal of unsupervised learning is to uncover the underlying structure of data without access to labels or supervision. This is particularly relevant in generative modeling, where we aim to learn a model that captures the probability distribution of natural data and can generate new, realistic samples from.

Real-world data distributions are complex and usually unknown. A common approach is to approximate the true data distribution $p_{data}(x)$ with a parameterized model $p_{	heta}(x)$, typically a deep neural network. The parameters $	heta$ are learned by maximizing the likelihood of the data:

```
$$\int p_{data}(x) \log p_{	heta}(x)dx.$ (12)
```

In practice, we approximate $p_{data}$ by the empirical distribution over a dataset, $\hat{p}_{data}(x) = P^{-1}\sum_{i=1}^{P}\delta(x-x_i)$, yielding a training objective that seeks to assign high probability to observed samples. Once trained, such a model can be used to sample new data.

# 1.3.2 Score-based diffusion models

A breakthrough in generative modeling comes from score-based diffusion models, which draw inspiration from non-equilibrium physics [SD+15; HJA20; SEI19; Son+20].

These models define a *forward process* that progressively corrupts data, transforming an unknown distribution into a simple, known one by adding noise. For instance, in the case of images, this can be implemented as an independent random walk per pixel, gradually turning the image into noise. A *backward process* is then defined as the reversal of this trajectory: starting from pure noise, the model learns to recover naturalistic data.

Formally, the diffusion process is defined by a stochastic differential equation (SDE):

```
$dx = f(x,t)dt + g(t)dw,$ (13)
```
