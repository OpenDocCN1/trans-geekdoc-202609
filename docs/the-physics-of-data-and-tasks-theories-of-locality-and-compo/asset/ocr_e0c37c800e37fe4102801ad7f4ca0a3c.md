From the orthogonality of the eigenfunctions $\Phi_{ho}$, the first integral is non-zero and equal to one only when $ho = \sigma$, while, from assumption $i$, $p^{(s)}(d^4x)\Phi_{ho}(x) = 0$ for all $ho > 1$, so that the second integral is always zero. Therefore,

```
$$\Phi_{ho}\Phi_{\sigma} = \delta_{ho,\sigma}. \quad (119)$
```

When $ho = 1$ and $\sigma \neq 1$, $\int p(d^4x)\Phi_1(x)\Phi_{ho}(x) = 0$ from assumption $i$, i.e., $\Phi_1 = 1$ and $\int p^{(s)}(d^4x)\Phi_{ho}(x) = 0$ for all $\rho > 1$. Finally, if $\rho = 1$, $\int p(d^4x)\Phi_1(x) = 1$. Then, we prove that the eigenfunctions and the eigenvalues defined in Equation 38 satisfy the kernel experiment. For $\rho = 1$,

```
$$\int p(d^4y)K^{CN}(\mathbfx,y}) = \int p(d^4y)\sum_{i,j\in P} \frac{s^2}{d_i^2} C(x_i,y_j) = \frac{s^2}{d^2} \sum_{i,j\in P} \lambda_1 = \Lambda_1, \quad (120)$
```

where we used $\int p^{(s)}(d^4y)C(\mathbfx,y) = \lambda_1$ from assumption $i$. For $\rho > 1$,

```
$$\int p(d^4y)K^{CN}(\mathbfx,y)\Phi_{ho}(y) = \int p(d^4y)\sum_{i,j\in P} \frac{s^2}{d_i^2} C(x_i,y_j)\sqrt{\frac{s}{d^2}} \sum_{i\in P} \Phi_{ho}(y_i). \quad (121)$
```

Splitting the sum over $l$ into the term with $l=j$ and the remaining ones, the RHS has been written as

```
$$\frac{s^2}{d_2^2} \sum_{i,j\in P} \left( \int p(d^4y)C(x_i,y_j)\sqrt{\frac{s}{d^2}} \Phi_{ho}(y_j) \right) + \intint p(d^4y)C(x_i,y_j)\sqrt{\frac{s}{d^2}} \sum_{i\neq j\in P} \int p(d^4y)\Phi_{ho}(y_l). \quad (122)$
```

Using assumption $i$), the third integral is always zero, therefore

```
$$\int p(d^4y)K^{CN}(\mathbfx,y)\Phi_{ho}(y) = \frac{s^2}{d^2} \sum_{i,j\in P} \Lambda_{ho}\sqrt{\frac{s}{d^2}} \Phi_{ho}(x_i) = \Lambda_{ho}\Phi_{ho}(\mathbfx). \quad (123)$
```
