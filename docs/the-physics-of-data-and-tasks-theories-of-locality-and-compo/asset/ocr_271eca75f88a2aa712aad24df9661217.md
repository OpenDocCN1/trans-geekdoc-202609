For the generative model defined in Section 4.3, the leaves correspond to the variables at the bottom layer while the root is the class variable at the top of the hierarchy. Each rule, connecting variables at different layers, corresponds to a factor node. The BP messages that flow from the variable nodes to the factor nodes, therefore correspond to upward messages, while those going from factor nodes correspond to downward messages

To each variable node $X_i^{(\ell)}$ at level $\ell$, we associate the upward messages $u_i^{(\ell)}$ and downward messages $v_i^{(\ell)}$ for each possible value of the alphabet it can. To simplify the notation, here consider how messages propagate from one level to the other, and we call $Y$ the variable corresponding to the higher level and $X_{i, \ell-1}$ the lower level connected to it. The factor node connecting them is, for each possible assignment $y \rightarrow x_1, \dots, x_s$, it takes values

```
$\psi^{(\ell)}(y, x_1, \dots, x_s) = \begin{cases} 1, & \text{if } y \rightarrow (x_1, \dots, x_s) \text{ is a rule at level } \ell \ 0, & \text{otherwise.} \end{cases}$
```

The BP upward and downward iterations are defined as follows.

+   - Upward iteration:

```
$	ilde{V}_y^{(\ell+1)}(y) = \sum_{x_1, \dots, x_s \in A^{\oplus}} \psi^{(\ell+1)}(y, x_1, \dots, x_s) \prod_{i=1}^s V_{x_i}^{(\ell)}(x_i), \quad (280)$
```

```
$v_y^{(\ell)}(y) = \frac{	ilde{V}_y^{(\ell)}(y)}{\sum_{y'} \tilde{V}_{y'}}^{(\ell)}(y')} \quad (281)$
```

+   - Downward iteration:

```
$	ilde{V}_{x_i}^{(\ell)}(x_i) = \sum_{y \in A, x_2, \dots, x_s \in A^{\ell-1}}} \psi^{(\ell)}(y, x_1, \dots, x_s) v_y^{(\ell)}(y) \prod_{i=2}^s V_{x_i}^{(\ell)}(x_i) \quad (282)$
```

```
$v_{x_i}}^{(\ell)}(x_i) = \frac{	ilde{V}_{x_i}}^{(\ell)}(x_i)}{\sum_{x'} \tilde{V}_{x'}}^{(\ell)}(x')} \quad (283)$
```

$v_y^{(\ell)}(y)$ and $v_{x_i}^{(\ell)}(x)$ are fluctuating quantities that depend on the position of the node.
