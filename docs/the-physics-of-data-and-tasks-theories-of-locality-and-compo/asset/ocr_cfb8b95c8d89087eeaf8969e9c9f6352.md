# GLOSSARY

ACTIVATION FUNCTION A non-linear function applied to the output of a neuron in a neural network, such as ReLU ($\sigma(u)$ = max(0,u)). It allows the network to learn complex, non-linear patterns in the data.

ARITHMETIC (TASK) See *Arithmetic.*

BACKPROPAGATION The algorithm used to train neural networks by efficiently computing the gradient of the loss function with respect to its weights. It works by applying the chain rule recursively through the network's layers.

BAYES Refers to a statistical method or predictor that achieves the lowest possible error rate for a given problem and data distribution. In the context of the thesis, it often represents the theoretical best-case performance against which other methods are compared.

BELIEF PROPAGATION (BP) A message-passing algorithm for performing inference on graphical models. In this, it is used to exactly compute the Bayes-optimal denoising process for the Random Hierarchy Model (RHM), revealing the evolution of latent variables during diffusion.

COMPOSITIONALITY A principle suggesting that complex data or features are constructed from simpler, reusable parts or often in a hierarchical manner. For example, images are composed of objects, which are made of parts, textures, and edges. This thesis argues compositionality is a key structure in data that deep learning models exploit to generalize effectively.

CONVOLUTIONAL NEURAL NETWORK (CNN) A class of deep networks designed primarily for processing structured data, such as images. CNNs use convolutional filters to capture local patterns and enforce translational invariance through weight sharing, making them highly effective for tasks with spatial structure.

CURSE OF DIMENSIONALITY A phenomenon where the amount of data required to achieve a certain level of statistical confidence grows exponentially with the number of dimensions (features) of the data. This makes learning from high-dimensional data, such as images, statistically intractable without a strong underlying structure in the data.
