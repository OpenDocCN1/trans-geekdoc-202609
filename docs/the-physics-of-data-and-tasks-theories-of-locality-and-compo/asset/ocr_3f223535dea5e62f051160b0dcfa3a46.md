where $\sigma'$ denotes the derivative of $\sigma$ with respect to its argument.
If all the parameters are initialized independently from a standard Normal distribution, $K_{	ext{NTK,N}}^{	ext{FC}}(\mathbf{x}, \mathbf{y}; \boldsymbol{	heta})$ is a random-feature kernel that in the $H 	o \infty$ limit converges to

```
$K_{	ext{NTK}}^{	ext{FC}}(\mathbf{x}, \mathbf{y}) = \mathbb{E}_{\mathbf{w}}[\sigma'(\mathbf{x}^	op\mathbf{w})\sigma'(\mathbf{y}^	op\mathbf{w})] + \mathbb{E}_a[a^2]\mathbb{E}_{\mathbf{w}}[\sigma'(\mathbf{x}^	op\mathbf{w})\sigma'(\mathbf{y}^	op\mathbf{w}) + (\mathbf{x}^	op\mathbf{y}+1)]$
```

When $\sigma$ is the ReLU activation function, the expectations can be computed exactly using techniques from the literature of arc-cosine kernels [Cs09b]

```
$K_{	ext{NTK}}^{	ext{FC}}(\mathbf{x}, \mathbf{y}) = \frac{1}{2\pi}\sqrt{\mathbf{x}\|^2+1}\sqrt{\mathbf{y}\|^2+1}\sin(\varphi)(\pi-\varphi)\cos(\varphi) + \frac{1}{2\pi}(\mathbf{x}^	op\mathbf{y}+1)(\pi-\varphi)$,
```

with $\varphi$ denoting the angle

```
$\varphi = \arccos(\frac{\mathbf{x}}^	op\mathbf{y}+1}{\sqrt{\mathbf{x}\|^2+1}\sqrt{\mathbf{y}\|^2+1}}\right)$
```

Notice that, in Section 2.3, for ReLU networks $K_{	ext{NTK,x}}^{	ext{FC}}(\mathbf{x})$ displays a cusp at $\mathbf{x}=\mathbf{y}$.
