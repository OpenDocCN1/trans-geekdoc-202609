# 2.3 CONVOLUTIONAL AND LOCAL KERNELS

In this section, we introduce convolutional and local kernels, and motivate our choice by considering one-layer convolutional architectures. Due to the close relationship between our kernels and the Neural Kernel of one-layer convolutional neural networks, our framework naturally encompasses regression tasks using simple neural networks in the lazy training regime. For simplicity, we limit the discussion to inputs represented as sequences in $\mathbb{R}^d$, denoted as $x=(x_1, ..., x_d)$. Extending these to higher-order tensor inputs using images as $x \in \mathbb{R}^{s \times d}$ is straightforward. We handle boundary conditions by setting $x_{i+d} = x_i$ for all $i=1, \dots, d$.

**Definition 2.3.1** (one-layer CNN). A convolutional network with $H$ hidden neurons and averaging pooling is:

```
$f^{CNN}(\mathbf{x}) = \frac{1}{\sqrt{H}} \sum_{h=1}^{H} \sum_{i \in \mathcal{P}}} \sigma(\mathbf{w}_h^TT \mathbf{x}_i + b_h), \quad (29)$
```

where $x \in \mathbb{R}^d$, $H$ denotes the number of neurons, and $\mathcal{P} \subseteq \{1, \dots, d\}$ is a set of patch indices, and $|\mathcal{P}|$ is its cardinality. For $i \in \mathcal{P}$, $x_i$ is an $s$-dimensional patch of $x$. For all $h=1, \dots, H$, $\mathbf{w}_h \in \mathbb{R}^s$ is a filter with size $s$, and $b_h \in \mathbb{R}$ is a scalar bias, and a scalar weight.
In the network defined above, a $d$-dimensional input sequence $x$ is first mapped to $s$-dimensional patches $x_i$, which are ordered sequences of the input.
