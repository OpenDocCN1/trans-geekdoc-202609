MSS18; MSS20; De-19; AZL20; Cag24 belonging to the class of probabilistic context-free grammars (PCGs) [RS97]. These models consist of a collection of symbols and rules that prescribe sequence data starting from a single feature. Generic PCGs consist of a vocabulary of hidden (nonterminal) symbols, a vocabulary of visible (terminal) symbols and production rules that quantify the probability that either hidden symbol generates tuples of or visible symbols. The Random Hierarchy Model – which we introduced in [Cag+24], not included in this thesis – is a particular PCG, including the following additional assumptions to make it analytically tractable:

- i) The nonterminal symbols are split into $L$ finite vocabularies $(V_\ell)_{\ell=1}^L$ of finite cardinality $v$ and $\mathcal{V}_0$ denotes the vocabulary of terminal symbols.

- ii) All the production rules transform one level-$(\ell + 1)$ symbol into a string of $s$-level $\ell$ symbols,

$$\mu^{(\ell+1)} \to \mu_1^{(\ell)}, \dots, \mu_s^{(\ell)}. \quad (68)$$

- iii) There are $m$ unambiguous production rules for nonterminal symbol, i.e., two distinct nonterminals cannot generate the same $s$-tuple. These rules are randomly chosen and frozen for a given instance of the RHM. We call the $m$ strings produced by any given symbol synonyms.

- iv) All the available production rules are equally likely.

Due to assumptions $i)$ and $ii)$, the data-generating process can be represented as a regular tree graph with depth $L$ and branching ratio $s$. The leaf nodes (level $\ell=0$) correspond to the tokens of the visible data, which form strings of size $d=s^L$.

We adopt a one-hot encoding of these features, ultimately leading to a data vector $X \in \mathbb{R}^{dv}$. Note that for $\ell \ge 1$, the node variables correspond to latent variables, and there is no need to specify any choice of encoding.

The total number of data produced per cell — i.e. symbol at the root is $m \cdot m \cdots m = m^\ell$, which has exponential dependence in the dimension $d=s^\ell$. In the following, we use the notation $X_i^{(\ell)}$ to indicate the variable at layer $\ell$ and position $i \in \{1, \dots, s^{\ell-1}\}$.

In the context of unsupervised learning, a key parameter for the model $s$ can be produced at any level of the hierarchy. This implies that all possible $s^\ell$ input strings are generated, and the distribution has little structure. When $f < 1$, however, only a small fraction $f^{(d-\ell)/(s-1)}$ of all possible strings are generated by the production rules. This implies that spatial correlations between different input positions appear, reflecting the hierarchy that generates the data.

In this section, we characterize the Bayes denoising process $X^{(0)} = x(t)$ of the input variables at time $t$, we compute $p(x|x(t))$ exactly, obtaining full control of the backward diffusion process from time $t$ to time 0. In particular, given the tree structure of the model, we can compute the marginal probability of the values of all latent variables conditioned on $x(t)$ by using a message-passing algorithm. Therefore, we obtain the probability that a latent variable at level $\ell$ when performing the forward-backward diffusion process for a duration $t$, a central quantity to interpret Figure 5. The optimal denoising corresponds to reconstruct the data distribution $p(x)$ exactly. This perfect reconstruction corresponds to a diffusion model achieving perfect generalization. Although this is a strong assumption for modeling a neural network trained with empirical risk minimization, like the one considered in Section 4.2, our theoretical analysis captures the phenomenologies of our experiments.

## BELIEF PROPAGATION

For computing the marginal distributions, we use Belief Propagation (BP) [Mos01; MM09], which gives exact results for a tree graph as the Random Hierarchy Model. In this case, the leaves of the tree correspond to the input variables at the bottom layer, and the root corresponds to the class variable at the top of the hierarchy. Each rule connects variables at different levels corresponds to a factor node, as shown in Figure 7.

The forward process adds noise to the variables in the input nodes. Each of these nodes sends its value at $t=0$ to its parent node. These nodes, or *messages*, represent probabilistic estimates of the state of the sender node. Each latent node receives messages from all its children, updates its belief about its state, and sends its *upward message* to its parent node. This process is repeated iteratively through the root. Subsequently, starting from the root, each node sends a *downward message* to its children. Finally, the product of the upward and downward beliefs received at a given node represents the marginals of its state conditioned on the noisy observation. We, can use these conditional marginals to compute the mean values of the variables at all levels of the hierarchy. Assume that the production rules of the model are known by the inference algorithm, which corresponds to the optimal denoising process.

The input variables $X^{(0)}$, in their one-hot-encoding representation, undergo the diffusion process of DDPMs. The denoising is made in the leaves and the BP iteration.

## INITIALIZATION OF THE UPWARD MESSAGES

In its one-hot-encoding representation, $X^{(0)}$ is a $d$-dimensional vector: taking the symbol $a_\gamma \in \{a_1, \dots, a_q\} = Y$ corresponds to $X^{(0)} = c_\gamma$ with $c_\gamma$ a canonical basis vector. Its continuous diffusion process takes place in $\mathbb{R}^p$: given the value $X_i^{(0)} = x_i(0)$, we can compute the probability of its starting value $p(x_0|x_t)$ using Bayes formula. As derived in Section C.2, we obtain

$$p(x_i(0) = e_\gamma|x_i(t)) = \frac{1}{\sqrt{\Delta_t}} e^{c_\gamma(t)/\Delta_t}, \quad (69)$$

with $\Delta_t = (1 - \bar{\alpha}_t)/\sqrt{\bar{\alpha}_t}$ and $Z = \sum_{h=1}^q e^{c_h(t)/\Delta_t}$. This computation is performed independently for each input variable $t$, and therefore does not take into account the spatial correlations.
