## 8.2 TASK ARITHMETIC IS NOT A CONSEQUENCE OF FINE-TUNING

The objective of this work is to understand the conditions that enable task arithmetic in deep neural networks. Previous studies hypothesized that task arithmetic results from fine-tuning in the linear regime [Wort+22b; Ilh+23; Wort+24], as linear weight combinations correspond to simple function combinations. However, we will demonstrate that CLIP models do not fine-tune in the linear regime and therefore need other ways to explain task arithmetic.

## 8.3 DISENTANGLEMENT

If the linear regime is not necessary to explain task arithmetic, what are the necessary conditions that allow it? In this section, we argue that the only necessary condition to perform task arithmetic with a model $f$ is that the model is disentangled with respect to the set of fine-tuning tasks.

**Property 3 (disentanglement).** A parametric function $f : \mathcal{X} \rightarrow \mathcal{Y}$ is disentangled with respect to a set of task vectors $\mathcal{T} = \{\tau_i\}_{i\in[\mathcal{T}]}$ and the corresponding supports $\mathcal{D} = \{D_i\}_{i\in[\mathcal{T}]}$ if

```
$f(\mathbf{x};\theta_0 + \sum_{i=1}^T \alpha_i\tau_i) = \sum_{i=1}^T g_i(\mathbf{x};\alpha_i\tau_i) + g_0(\mathbf{x}),$
```

where $g_i(\mathbf{x};\alpha_i\tau_i)=0$ for $\mathbf{x} \notin D_i$ and $i=1,...,T$, and $g_0(\mathbf{x})=0$ for $\mathbf{x} \in \bigcup_{i\in[\mathcal{T}]} D_i$.

In essence, this definition captures that the function $f$ can be decomposed as a sum of spatially-located components, i.e., vanishing outside a spatial region, whose functional variation is entirely captured by $\tau_i$ (see Figure 28). Moreover, it is trivial to see that satisfying disentanglement is equivalent to satisfying task arithmetic as Property 1 on one can easily write Equation 91 as

```
$f(\mathbf{x};\theta_0 + \sum_{i=1}^T \alpha_i\tau_i) = \sum_{i=1}^T f(\mathbf{x};\alpha_i\tau_i)(\mathbf{x} \notin \bigcup_{i\in[\mathcal{T}]} D_i) + f(\mathbf{x};\theta_0)(\mathbf{x} \in \bigcup_{i\in[\mathcal{T}]} D_i),
```

and identify $g_i(\mathbf{x};\alpha_i\tau_i) = f(\mathbf{x};\alpha_i\tau_i)(\mathbf{x} \in D_i)$ and $g_0(\mathbf{x}) = f(\mathbf{x};\theta_0)(\mathbf{x} \in \bigcup_{i\in[\mathcal{T}]} D_i).
