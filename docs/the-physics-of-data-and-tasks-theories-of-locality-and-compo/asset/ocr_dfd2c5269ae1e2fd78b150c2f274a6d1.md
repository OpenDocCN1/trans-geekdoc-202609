# 6.5 CONCLUSIONS

**Figure 21** illustrates images generated at different training stages. Initially, the outputs exhibit patterns of textures. As training progresses, broader regions and vague structures emerge, but with well-defined details. By $10^4$ steps, the model starts assembling coherent features, such as object-like shapes or parts, though global consistency is still lacking.^3 Finally, images from the last checkpoint exhibit high stochastic and realistic compositions, indicating that the model successfully generates coherent scenes with well-defined textures.

To quantify these observations, we analyze the hierarchical and compositional structure of images generated using deep latent representations from a pre-trained ResNet-18 [He+16]. Early layers encode low-level features, which represent more abstract and global factors [OMS17], as also observed for CNNs trained on the RHM [CAG+24]. We compute the *Maximum Mean Discrepancy* (MMD) from ResNet embeddings of the generated images and from the ImageNet validation set. MMD-based evaluations have been recently proposed as a robust metric for assessing image quality in diffusion models [Jay+24].

Figure 21 presents MMD measured at different depths of the ResNet model as a function of the number of examples. Notably, the MMD at early layers converges first, while the MMD at deeper layers converges sequentially as more examples are introduced. This provides strong empirical evidence that diffusion models learn hierarchical structures progressively, first capturing local features and refining global compositional rules.

# 6.5 CONCLUSIONS

We have provided a theory explaining how diffusion models can learn hierarchically compositional data using a number of samples that scales polynomially with the data dimension, beating the curse of dimensionality. In particular, we showed that when learning from data generated by a simple context-free grammar, U-Nets reduce dimensionality by assigning identical representations to groups of features that share similar contexts. This process unfolds hierarchically across levels of abstraction. As a result, the framework predicts training time or dataset size leads to generated data that is coherent over progressively larger scales. We provided direct empirical evidence supporting this prediction in both text and image models.
