LEARNING HIERARCHICAL REPRESENTATION VIA NEXT-TOKEN PREDICTION It has been observed that transformers trained on next-prediction on PCGs learn a hierarchical representation of the data that reflects the structure of the latent variables [CW24; AZI23; GB+24]. Clos to our work, Cagnetta and Wyart [CW24] showed that for the prediction of the token in a sequence of fixed length, the latent structure is learned hierarchically, with a sample complexity polynomial in the context length. Our work extends this finding to diffusion models, in a setup where complete sequences can be generated. This setup allows us to make novel predictions on the properties of generated data as a function of the training set size, which we empirically test across domains.

In this section, we investigate how diffusion models learn to generate data from the Random Hierarchy Model (RHM), and measure the sample complexity required to capture the underlying rules.

# 6.2.1 Experimental setting

To begin, we generate an instance of the RHM with parameters L (depth), $s$ (branching factor), $v$ (vocabulary size), and $m$ (number of synonyms). We uniformly sample $P$ distinct training points, i.e., sentences from the grammar. Each input symbol is encoded as a onehot vector, $x \in \{0,1\}^{d \times v}$. With this dataset, we train a Discrete Denoising Probabilistic Model (DPM) [Hoo21] with uniform transition probabilities, i.e., at each time step, tokens either stay unchanged or transition to any other symbol with probability similarity.

The diffusion model architecture is a convolutional U-Net with $L$ resolution blocks in both the encoder and decoder. Each block consists of a single convolutional layer with filter size $s$ and stride $s$, followed by a GeLU activation function. Skip link the encoder and decoder layers. The model also includes two embedding and unembedding layers, implemented as convolutions with filter size 1. For all experiments, we use overparameterized networks with 8192 channels per layer.
