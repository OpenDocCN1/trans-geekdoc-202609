# 8.3 WEIGHT DISENTANGLEMENT

If the linear regime is not necessary to explain task arithmetic, what are the necessary conditions that allow it? In this section, we argue that the only necessary condition to perform task arithmetic with a model f is that the model is disentangled with respect to the set of fine-tuning tasks.

**Property 3** (disentanglement). A parametric function $f : \mathcal{X} \rightarrow \mathcal{Y}$ is disentangled with respect to a set of task vectors $\mathcal{T} = \{	au_i\}_{i\in[mathcal{T}]}$ and the corresponding supports $\mathcal{D} = \{D_i\}_{i\in[mathcal{T}]}$ if

```
$f(\mathbf{x};\theta_0 + \sum_{i=1}^T \alpha_i\tau_i) = \sum_{i=1}^T g_i(\mathbf{x};\alpha_i\tau_i) + g_0(\mathbf{x}),$
```

where $g_i(\mathbf{x};\alpha_i\tau_i)=0$ for $\mathbf{x} \notin D_i$ and $i=1,...,T$, and $g_0(\mathbf{x})=0$ for $\mathbf{x} \in \bigcup_{i\in[mathcal{T}]} D_i.$.

In essence, this definition captures that the function f can be decomposed as a sum of spatially-located components, i.e., vanishing outside a spatial region, whose functional variation is entirely captured by $\tau_i$ (see Figure 28). Moreover, it is trivial to see that satisfying disentanglement is equivalent to satisfying task arithmetic as Property 1 on one can easily write Equation 91 as

```
$f(\mathbf{x};\theta_0 + \sum_{i=1}^T \alpha_i\tau_i) = \sum_{i=1}^T f(\mathbf{x};\alpha_i\tau_i)(\mathbf{x} \notin \bigcup_{i\in[mathcal{T}]} D_i) \n\+ f(\mathbf{x};\theta_0)(\mathbf{x} \in \bigcup_{i\in[mathcal{T}]} D_i),
```

and identify $g_i(\mathbf{x};\alpha_i\tau_i) = f(\mathbf{x};\alpha_i\tau_i)(\mathbf{x} \in D_i)$ and $g_0(\mathbf{x}) = f(\mathbf{x};\theta_0)(\mathbf{x} \in D_i)$. It is important to highlight, that this additive-decomposition does not imply linearity, as the local functions $\{g_i\}_{i\in[mathcal{T]}$ are not required to be linear with respect to the parameters.

Furthermore, note that disentanglement is a property of the predictors and not related to the performance on different tasks. A model could be disentangled with respect to a set of task vectors and still perform poorly on a task, e.g., if $f(\cdot;\theta_0 + \alpha\tau)$ does not generalize for some alpha.
