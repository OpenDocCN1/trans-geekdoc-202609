In particular, Proposition 7.2 in [Bac21] states that $f^*$ in the closure of $\mathcal{H}$, regularization $\lambda \le 1$ and $P \ge \frac{\sigma^2}{\lambda}(1+\log(1/\lambda))$, one has

```
$$\mathcal{E}(\lambda, P) - \mathcal{E}(f^*) \le 16\frac{\sigma^2}{P}\text{Tr}\left((T_K + \lambda I)^{-1}T_K\right) + 16\text{inf}_{f}{\f-f^*\|_{\ell_2}^2 + \lambda\|f\|_{\mathcal{H}}^2} \frac{24}{p^2}\|f^*\|_{L_{\infty}}^2 (249)
```

where $\sigma^2$ bounds the conditional variance of the labels, i.e. $\mathbb{E}_{(x,y)\sim P}[(y-f^*(x))^2 \mid x] \le \sigma^2$.$
Then, let us consider the following standard assumptions in the kernel literature [CDV07]:

```
$$\text{Capacity:} T_K^{1/a} = \sum_{k=0}^{\infty}(\lambda_k)^{1/a} < +\infty.$
$\text{source:} \|T_K^{1/2}\|^2 = \sum_{k=0}^{\infty}(\lambda_k)^{-1}(f_k)_{\ell_2}^2 < +\infty. (250)
```

In short, the first assumption characterizes the 'size' of the RKHS (the larger $a$, the smaller the number of functions in the RKHS), while the second assumption characterizes the regularity of the target function relative to the kernel (when $r=1, f^* \in \mathcal{H}$; when $r<1, f^*$ is less smooth; when $r>1, f^*$ is smoother). Combining these assumptions with Equation 249, one gets

```
$$\mathcal{E}(\lambda, P) - \mathcal{E}(f^*) \le 16\frac{\sigma^2}{P}C_1\lambda^{-1/a} + 16C_2\lambda' \frac{24}{p^2}\|f^*\|_{L_{\infty}}. (251)
```

Optimizing for $\lambda$ leads to

```
$$\lambda_p = \frac{C_1\sigma^2}{a r C_2 P^{\frac{1}{ar+1}}}, (252)
```

and the the bounds become

```
$$\mathcal{E}(\lambda, P) - \mathcal{E}(f^*) \le C_2^2(\frac{\sigma^2}{P})^{\frac{a}{ar+1}} + \frac{5}{p^2}\|f^*\|_{L_{\infty}}. (253)
```
