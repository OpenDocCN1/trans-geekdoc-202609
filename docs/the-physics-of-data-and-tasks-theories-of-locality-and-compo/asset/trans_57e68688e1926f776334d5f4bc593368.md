# 8.4 通过线性化增强任务算术

我们已经看到线性化模型比非线性模型更解耦。然而，事后线性化会降低单任务性能。我们证明，强制模型处于其预训练初始的切空间中，确实可以通过缩小单任务准确率差距来改进任务算术。
