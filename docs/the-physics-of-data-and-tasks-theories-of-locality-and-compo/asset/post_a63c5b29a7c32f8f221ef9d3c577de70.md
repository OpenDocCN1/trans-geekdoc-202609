In order to take into account its algebraic multiplicity, we introduce the eigenvalue $\mathcal{D}(\Lambda)$, whose asymptotic form for small eigenvalues

```
$$\mathcal{D}(\Lambda) = \sum_{k,\ell} \delta(\Lambda - \Lambda_k)$$
$$\sim \sum_{k}^p \prod_{i=1}^{k-2} \delta(\Lambda - \sum_{i=1}^p \Lambda_i^{-2v-(s-1)}) \prod_{j \neq i} \delta_{k,j}$$
$$\sim \sum_{i=1}^{\infty} k_i^{-2-\delta} \delta(\Lambda - \Lambda_i^{-2v-(s-1)})$$
$$\sim \int_1^{\infty} dk k^{-2-\delta} \delta(\Lambda - k^{-2v-(s-1)})$$
$$\sim \Lambda^{-\frac{1}{2v+(s-1)}} \dots$$
```

Thus, the scaling of $\Lambda(\rho)$ can be determined self-consistently,

```
$$\rho = \frac{\Lambda^{(1)}}{\Lambda(\rho)}} d\Lambda \mathcal{D}(\Lambda) \sim \Lambda(\rho) \Lambda^{-\frac{1}{2v+(s-1)}} \Rightarrow \rho \sim \rho^{-1-\frac{1}{2v}}$$
```

Consider now a kernel of depth $L+1$ with filter sizes $(s_1, \dots, s_L)$ and $p_l=1$. For each sector $l$, we can compute the density of eigenvalues $\mathcal{D}_{(l)}(\Lambda)$. If $s_l=2$, there are two different cases:

```
$$\mathcal{D}_{(l)}(\Lambda) = \sum_{k,\ell} \delta(\Lambda - \Lambda_k^{(l)})$$
$$\sim \sum_{l_{l+1 \to L+1}} \sum_{k_{l+1 \to L+1}}^{\infty} \delta(\Lambda - \mathcal{C}_{2,l} \|k_{l_{l+1 \to L+1}}\|^{-2v-d_{eff}(l)}})$$
$$\sim \int_1^{\frac{d_{eff}(l)}{\infty}} dk k^{d_{eff}(l)-1} \delta(\Lambda - \mathcal{C}_{2,l} k^{-2v-d_{eff}(l)}})$$
$$\sim \Lambda^{-\frac{d_{eff}(l)}{2v+d_{eff}(l)}}$$
```

If $s_l \geq 3$,

```
$$\mathcal{D}_{(l)}(\Lambda) = \sum_{k,\ell} \delta(\Lambda - \Lambda_k^{(l)})$$
$$\sim \sum_{l_{l+1 \to L+1}} \sum_{k_{l+1 \to L+1}}^{\infty} \delta(\Lambda - \mathcal{C}_{s_l,l} \|k_{l+1 \to L+1}}\|^{-2v-d_{eff}(l)}})$$
$$\sim \Lambda^{-\frac{d_{eff}(l)}{2v+d_{eff}(l)}}$$
```

When summing over all layers $l$, the asymptotic behaviour of the total density of eigenvalues $\mathcal{D}(\Lambda) = \sum_l \mathcal{D}_{(l)}(\Lambda)$ is dictated by the sector with the slowest decay, i.e. the last one. Hence,

```
$$\mathcal{D}(\Lambda) \sim \Lambda^{-\frac{d_{eff}(L)}{2v+d_{eff}(L)}}$$
```

## B.5 STATISTICAL MECHANICS OF GENERALIZATION IN KERNEL REGRESSION

In [BCP20, CBP21], the authors devised a heuristic expression for the average-case mean-squared error of kernel (ridge) regression with the replica method of statistical physics [MPV87]. Denoting by $\{\phi_{\rho}(x), \lambda_{\rho\ge1\}$ the eigenfunctions and eigenvalues of the kernel and with $c_{\rho}$ the coefficients of the target function in this basis, i.e. $f^*(x) = \sum_{\rho\ge1} c_{\rho}\phi_{\rho}(x)$, one has

```
$$\mathcal{E}(\lambda, \rho) = \partial_{\lambda} (\frac{\kappa_{\lambda}}{P}) \sum_{\rho} \kappa_{\lambda}(P)^2 \mathbb{E}[c_{\rho}^2] \quad (264)$$
```

where $\lambda$ is the radius and $\kappa(P)$ satisfies the implicit equation

```
$$\frac{\kappa_{\lambda}(P)}{P} = \lambda + \frac{1}{P} \sum_{\rho} \frac{\Lambda_{\lambda,\rho}(P)/\rho}{\rho + \kappa_{\lambda}(P)/\rho} \quad (265)$$
```

In, the replica calculation used to these equations defining an energy functional $\mathcal{E}(f)$ related to the empirical MSE and assigning to the predictor $f$ a Boltzmann measure, i.e. $P(f) \propto e^{-\mathcal{E}(f)}$. When $\beta \to \infty$, the measure concentrates around the minimum of $\mathcal{E}(f)$, which coincides with the minimizer of the empirical MSE. Then, since $\mathcal{E}(f)$ depends only on the projections $c_{\rho}$, computing the average over data that appears in the definition of the generalization error, reduces to computing Gaussian integrals. While non-rigorous, this method has been successfully used in physics – to study disordered systems – and in machine learning theory. In particular, the predictions obtained with Equation 264 and 265 have been validated numerically for both synthetic and real datasets.

In Equation 264, $\kappa_\lambda(P)/P$ plays the role of a threshold: the modal contributions to the error term 0 for $\rho$ such that $\Lambda_{\rho} \gg \kappa_\lambda(P)/P$, and $\mathbb{E}[c_{\rho}^2]$ for $\rho$ such that $\Lambda_{\rho} \ll \kappa_\lambda(P)/P$. This is equivalent to saying that kernel regression can capture modes corresponding to the eigenvalues larger than $\kappa_\lambda(P)/P$ (see [jac20a; Jac20b]).

In the ridgeless limit $\lambda \to 0^+$, this threshold asymptotically approaches to the $P$-th eigenvalue of the student, resulting in the intuitive picture presented in the main text. Given $P$ training points, ridgeless regression learns only the highest eigenvalues. In particular, we assume that the kernel and target function projections follow power laws. $\Lambda_{\rho} \sim \rho^{-a}$ and $\mathbb{E}[c_{\rho}^2] \sim \rho^{-b}$. Furthermore, we can approximate the summations over $\rho$ with an integral using the Euler-Maclaurin formula. Hence,

```
$$\frac{\kappa_0(P)}{P} = \frac{\kappa_0(P)}{P} \int_0^{\infty} \frac{\sigma}{\sigma^2-1} \frac{1}{1+\sigma} a^{a-1} d\sigma + O(1). \quad (266)$$
```

Since the integration over $\sigma$ is finite and independent of $P$, we obtain $\kappa_0(P)/P = O(P^{-a})$. Similarly, we find that the mode-independent prefactor $\delta_\lambda (\kappa_\lambda(P)/P|_{\lambda \to 0}) = O(1)$.

As a result, we have

```
$$\mathcal{E}(P) \sim \sum_{\rho} \frac{P^{-2a}}{(\Lambda_{\rho} + P^{-a})^2} \mathbb{E}[c_{\rho}^2]. \quad (267)$$
```

Following the intuitive argument about the thresholding of action, we can split the summation in Equation 267 into modes where $\Lambda_{\rho} \gg \kappa_0(P)/P$, $\Lambda_{\rho} \sim \kappa_0(P)/P$ and $\Lambda_{\rho} \ll \kappa_0(P)/P$,

```
$$\mathbb{E}(P) \sim \sum_{\rho \gg P} \frac{P^{-2a}}{(\Lambda_{\rho} + P^{-a})^2} \mathbb{E}[c_{\rho}^2] + \sum_{\rho \ll P} \frac{1}{2} \mathbb{E}[c_{\rho}^2] \quad (268)$$
```

Finally, Equation 61 is obtained by noting that, under the assumption on the decay of $\mathbb{E}[c_{\rho}^2]$, for $\rho \ll P$ is subleading in $P$, whereas the contribution of the summation over $\rho \ll P$ can be merged together.
