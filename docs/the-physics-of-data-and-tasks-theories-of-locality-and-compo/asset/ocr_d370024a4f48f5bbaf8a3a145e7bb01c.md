# 3.5 EXAMPLES AND EXPERIMENTS

The source condition characterizes the regularity of the target function relative to the kernel and depends explicitly on the decay of $|f^*|^2$ with $k$, as does the right-hand side of Equation 61. This condition was built by [Bac21] to prove that kernel methods are adaptive to the smoothness of the target function: projections onto smoother eigenfunctions display a faster decay with $k$, allowing to choose a larger $r$ and leading to better generalization performance. The following Corollary Theorem 3.3.1 (proof and extension to $s \ge 2$) is presented in Section B.4, Corollary B.4.0.1 which shows that, the spectrum can be partitioned in Theorem 3.3.1, hierarchical kernels display adaptivity to targets which depend only on a subset of the input variables. Specific examples of bounds are considered in Section 3.5.

**Corollary 3.4.0.1.** (Adaptivity to spatial structure). Let $T_k$ be the kernel of a hierarchical deep CNN in Theorem 3.3.1 with $s=2$: the capacity exponent $a$ is controlled by the largest sector of the spectrum, i.e.,

```
$$\text{Tr}(T_k^*/a) < \infty \Rightarrow a < 1+2v/d_{eff}(L);\quad (62)$
```

(ii) the source exponent $r$ is controlled by the structure of the target function $f^*$, i.e., if there is $l \le L$ such that $f^*$ depends only on some meta-patch $x_{l+1\to L+1}$, then only the first $l$ of the spectrum contribute to the source condition, i.e., $|T_k^r f^*|^2_H$ reads

```
$$\sum_{i=1}^{l} \sum_{k_{i+1}\to L+1}} \left( \Lambda_{k_{i+1}\to L+1}} \right)^{-r} |f^*_{k_{i+1}\to L+1}}|^2;\quad (63)$
```

The same holds if $f^*$ is a linear combination of such functions. As a result, $d_{eff}(L)$ is large and $a \to 1$, the decay of the error is controlled by the effective dimensionality of the target $d_{eff}(L)$.
