Due to assumption i), the task can be solved with a perceptron model
followed by a softmax nonlinearity,

```
$f_v(x;W) = \sum_{\mu} W_{v,\mu}x_{\mu} \quad p_v(x;W) = e^{f_v(x;W)}\left(\sum_{\mu} e^{f_{\mu}(x;W)}\right); (398)
```

where $W \in R^{V \times (vm)}$ is the weight matrix. In this setup,
ii) is realized by initializing the weights as $W_{v,\mu} = \log\mathbb{P}[X_{s+1}=v]$-
dependently of $\mu$.

The model $f$ of Equation 398 is trained via Gradient Descent on
the empirical-entropy loss computed over a training set $X_r$
of pairs $(x, v)$, with $v$ denoting the feature in the token $X_{s+1},$,

```
\mathcal{L} = \mathbb{E}_{(x,v) \in X_r} \left[ -\log \frac{e^{f_v(x;W)}}{\sum_{\mu} e^{f_{\mu}(x;W)}} \right], (399)
```

$\mathbb{E}_{(x,v) \in X_r}$ denotes the empirical average over the training set.
Denoting the learning rate by $\eta$, the updates of the weights are

```
\Delta W_{v,\mu} = -\eta \frac{\partial f_v}{\partial W_{v,\mu}} = -\eta \mathbb{E}_{(x,v) \in X_r} \delta_{\mu,\mu}(x) - [X_{s+1}=v] \frac{e^{f_{\mu}(x;W)}}{\sum_{\mu'} e^{f_{\mu'}(x;W)}} \n\mathbb{E}_{(x,v) \in X_r} [X_{s+1}=v] \delta_{\mu,\mu}(x) - [X_{s+1}=v] \delta_{\mu,\mu}(x) \n\eta \left( \mathbb{P}[X_{s+1}=v | v_r(x_1, \dots, x_r) = (\mu_1, \dots, \mu_r)] \right) \n-[X_{s+1}=v | v_r(x_1, \dots, x_r) = (\mu_1, \dots, \mu_r)] \right), (400)
```

where, in this case we used assumption i) to replace $x_r$ with
$\delta_{\mu,\mu}(x)$ and assumption ii) to replace $e^{f_{\mu}} / \sum_{\mu'} e^{f_{\mu'}}$ with $\mathbb{P}[X_{s+1}=v]$.
The right-hand side of the last line equals the empirical-token tuple
relation $\hat{C}_P(v,\mu)$. Therefore, after one gradient step, the weights
are given by

```
$W_{v,\mu} = \log \hat{C}_P(v,\mu).$ (401)
```

The first term is independent of the input $\mu$, whereas the weights can
be thought of as a noisy measurement of the true-token corre-
tion $C(v,\mu)$. The true correlation is equal for all $\mu$'s generated by
the higher-level hidden symbol $h^{(1)}(\mu)$ and its size can be-
dated as the standard deviation over realizations of the RHM (Equation-
389).

```
$C(2) \simeq \sqrt{\frac{1-f}{v^3 m^4}} (402)
```

The empirical measurement $\hat{C}_P$ includes a sampling noise contrib-
tion, having size $(v^2 mP)^{-1/2}$. If $P \geq vm^3/(1-f)$, the $\hat{C}_P$\nin the right-hand side of Equation 401 is approximately equal to the
true-tuple correlation, thus the weights can be used to build a
representation of the hidden variables of the generative model.
