**Definition 3.2.1 (L-hierarchical CNN).** Denote the normalized ReLU function, $\sigma(x) = \sqrt{\max(0, x)}$. For each input $x \in R^d$ and a divisor $d$ of $x$, denote by $w_i$ the $s$-dimensional path of $x$, $x_i = (x_{(i-1)s_{i+1}}, \dots, x_i)$ for all $i = 1, \dots, d/s^2$. The output of a $L$-hierarchical neural network can be defined recursively as follows.

```
$f_{h,j}^{(1)}(x) = \sigma\left(w_{h,j}^{(1)T} x_i\right), \forall h \in [H_1], \forall j \in [p_1];$
```

```
$f_{h,j}^{(l)}(x) = \sigma\left(\frac{1}{\sqrt{W_{h,j}^{(l-1)}}} w_{h,j}^{(l)T} f_{h,j}^{(l-1)}(x)\right),
```

$\forall h \in [H_l], j \in [p_l], l \in [2, \dots, L];$

```
$f(x) = f^{(l+1)}(x) = \sqrt{\sum_{h=1}^{p} \frac{H_l}{h_{l-1}} f_{h,j}^{(l)}(x)}{\sqrt{P_l}}} (50)
```

$H_l$ denotes the width of the $l$-th layer, $s_l$ the filter size ($s_1 = s_3$), $p_l$ the number of paths ($p_l = p = d/s$). denote $w_{h,j}^{(1)} \in R^{s_1}$, $w_{h,j}^{(l)} \in R^{s_l}$.

Hierarchical CNNs are visualized by considering their computational skeleton, i.e. the directed acyclic graph obtained by setting Figure 2, left, with $L=3$ hidden layers and filter sizes $(s_1, s_2, s_3) = (3, 2, 2)$. The computation is an ordered tree, whose root is the output (empty circle at the top of the figure) and the leaves are the input coordinates (squares at the bottom). All other nodes represent neurons, and the neurons belonging to the same hidden layer have the same distance from the input nodes. The tree structure highlights that the post-activations $f'$ of the $l$-th layer depend only on a subset of the input variables, also known as the receptive field.

Since the first layer of a hierarchical CNN acts on $s_1$-dimensional patches of the input, it is convenient to consider each as concatenation of $p$-dimensional patches, with $s=s_1$ and $p \times s=d$. We assume that each patch is normalized to 1, so that the input is a product of $p$ $s$-dimensional unit spheres (called hypersurface) in Geiman et al. [Gel+22]:
