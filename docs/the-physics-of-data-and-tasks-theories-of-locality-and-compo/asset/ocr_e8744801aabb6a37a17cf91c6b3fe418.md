# A.4 PROOF OF THEOREM 2.4.1

Decomposing the teacher kernel $\mathcal{K}_T$ into its eigenvalues $\Lambda_q^{(t)}$ and eigenfunctions $\Phi_q^{(t)}(y)$,

```
$\mathbb{E}[|c_k|^2] = \int_{[0,1]^d} d^d x \Phi_k^{(t)}(x) \int_{[0,1]^d} d^d y \Phi_q^{(t)}(y) \left( \Lambda_0^{(t)} + \sum_{q \neq 0} \Lambda_q^{(t)} \sum_{i \in P(t)} \Phi_i^{(t)}(x) \sum_{j \in P(t)} \Phi_j^{(t)}(y) \right) \quad (163)$
```

The $q = 0$ mode of the teacher can give non-vanishing contributions to $c_0$ only, therefore it does not enter any term of the sum in $q=0$, Equation 160. Once removed the term with $q=0$, consider the y-integral:

```
$\mathcal{I}_k(x) = \int_{[0,1]^d} d^d y \sum_{m \in P(t)} \Phi_m^{(t)}(y) \sum_{q \neq 0} \Lambda_q^{(t)} \sum_{i \in P(t)} \Phi_i^{(t)}(x) \sum_{j \in P(t)} \Phi_j^{(t)}(y) \quad (164)$
```

```
$= \left( \frac{s}{t} \right)^3 \sum_{q \neq 0} \Lambda_q^{(t)} \sum_{i \in P(t)} \Phi_i^{(t)}(x) \sum_{m \in P(t)} \int_{[0,1]^d} d^d y \Phi_k^{(t)}(y) \Phi_m^{(t)}(y). . $
```

As the $t$-dimensional patches of the teacher must be contained in at least one of the $s$-dimensional patches of the student, in the nonoverlapping case we assume that $s$ is an integer multiple of $t$. Then, each of the teacher patches coincides. If the teacher patch $y_j$ is not contained in the student, we can factorize the integration over $y$ into two integrals over $y_i$ and $y_m$. These terms give vanishing contributions to $\mathcal{I}_k(x)$ since the integral of a plane wave over a period is always zero for non-zero wavevectors. If, the teacher patch $y_j$ is contained in the student patch $y_m$, denoting with $l$ the index of the element of $y_m$ which coincide with the first element of $y_{ij}$, we can factorize the student's eigenfunctions

```
$\Phi_k^{(t)}(y_m) = \Phi_{ij}^{(t)}(y_{ij}) \Phi_{k,j}^{(t)}(y_{m \setminus j}). \quad (165)$
```

Here $k^{(l)}$ denotes the $t$-dimensional patch of $k$ starting at $l$ and $k \setminus k$ the sequence of elements which are in but not in $k$. As $s$ is an integer multiple of $t$, $t = l \times s$ with $l = 1, \dots, t$. Inserting Equation 164

```
$\mathcal{I}_k(x) = \sum_{l=1/s, t=1}^t \delta(k \setminus k^{(l)}, 0) \Lambda_{k^{(l)}}^{(t)} \sqrt{d} \sum_{i \in P(t)} \Phi_i^{(t)}(x_i). \quad (166)$
```

```
$\mathbb{E}[|c_k|^2] = \sum_{l=1/s, t=1}^t \delta(k \setminus k^{(l)}, 0) \Lambda_{k^{(l)}}^{(t)}. \quad (167)$
```
