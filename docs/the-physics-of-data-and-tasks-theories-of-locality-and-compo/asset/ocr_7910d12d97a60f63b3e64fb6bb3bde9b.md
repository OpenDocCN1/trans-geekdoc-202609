# D.2.1 Forward-backward coefficients in Fourier space

Given the independence of the Fourier coefficients $X(k)$, we apply the diffusion dynamics to each Fourier coefficient independently. The noise process is given by:

```
$X(k) = \sqrt{1-\beta_t}X(k)_{t-1} + \sqrt{eta_t}\eta, \quad \eta \sim \mathcal{N}(0,1),$
```

for $t=1,2,...,T$, where $\beta_t$ are the diffusion coefficients and $\eta$ are independent standard Gaussian variables. By enrolling the recursion, the forward dynamics can be expressed as

```
$X(k)_t = \sqrt{\bar{\alpha}_t}X(k)_0 + \sqrt{1-\ar{\alpha}_t}\bar{\eta}, \quad \bar{\eta} \sim \mathcal{N}(0,1),$
```

where $\bar{\alpha}_t = \prod_{i=1}^t (1-\beta_i)$. We then reverse the process at time $t$, following the backward:

```
$X(k)_{t-1} = \frac{1}{\sqrt{\bar{\alpha}_t}}(X(k)_t + \bar{eta}_t\nabla_{X(k)}(X(k)_t)) + \sqrt{\bar{eta}_t}z, \quad z \sim \mathcal{N}(0,1),$
```

where $q(X(k)_t)$ is marginal probability density of $X(k)_t$ in the forward process and $\nabla_{X(k)}\log q(X(k)_t$ is the corresponding score function.
