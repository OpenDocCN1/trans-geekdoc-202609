# LIST OF SYMBOLS

General Machine Learning & Neural Networks

| Symbol | Definition |
| --- | --- |
| **x** | Input vector or data point, typically in $\mathbb{R}^d$. |
| **y** | Label or target value corresponding to an input $x$. |
| **d** | The dimension of the input space. |
| **p** | The number of training examples in the dataset. |
| **$	heta$** | The set of all learnable parameters (weights and biases) in a neural network. |
| $f(x; 	heta)$ | A neural network function that maps $x$ to an output, parameterized by $	heta$. |
| $w_h^{(l)}, b^{(l)}$ | The weight and bias term for neuron $h$ in layer $l$. |
| **L** | The depth (number of hidden layers) of a neural network. |
| **H** | The width (number of neurons per layer) of a network. |
| $\sigma(\cdot)$ | A non-linear activation function, such as ReLU. |
| $\ell(y, y')$ | A loss function measuring the discrepancy between prediction $y'$ and a true label $y$. |
| $\mathcal{E}$ | The generalization error, or expected loss over the true data distribution. |
| $\hat{\mathcal{E}}$ | The empirical risk, or average loss over the training set. |
| $\eta$ | The learning rate used in gradient descent. |
| $eta$ | The learning curve exponent, describing how generalization error scales with dataset size, i.e., $\mathcal{E}(P) \sim P^{-eta}$. |
| $\mathcal{H}$ | The hypothesis class, representing the set of all functions a model can express. |

Kernel Methods & Infinite-Width Networks

| Symbol | Definition |
| --- | --- |
| $\mathcal{K}(x, x')$ | A kernel function, measuring the similarity between inputs $x$ and $x'$. |
| $\mathcal{K}_{	ext{NTK}}$ | The Neural Tangent Kernel, which describes the training dynamics of infinitely wide networks. |
