## C.1 BELIEF PROPAGATION INITIALIZATION FOR THE DENOISING OF THE RHM

As discussed in Section 4.4, we define the diffusion process for the input variable $X_t^{(0)}$. In particular, its value $x(t)$ at time $t$ is

```
$x(t) = \sqrt{a_t}x(0) + \sqrt{1-a_t}\eta,\quad(276)$
```

with $\eta \sim \mathcal{N}(0, \mathbf{I}_v)$ and $x(0)$ its starting value at time $t_1$ is a one-hot-encoding vector of the factor $x(0) = e_{\mu_h}$. Given the value $x(t)$, the conditional probabilities for the values of $x(0)$ are given by Bayes rule

```
$p(x(0) = e_{\mu_h}|x(t)) = \frac{p(x(t)|x(0) = e_{\mu_h})p(x(0) = e_{\mu_h})}{\sum p(x(t)|x(0) = e_{\lambda})}\quad(277)$
```

The prior probabilities on $x(0)$ are taken to be uniform over the alphabet, e.g., $p(x(0) = e_{\lambda}) = 1/v, \lambda$, while $p(x(t)|x(0) = e_{\mu_h})$ is given by the diffusion process of Equation 276:

```
$p(x(t)|x(0) = e_{\mu_h}) = C_t \exp\left[-\frac{1}{2(1-\bar{a}_t)}\sum(x_y(t) - \sqrt{\bar{a}_t}e_{\mu_h})^2\right]\= C_t \exp\left[-\frac{||x(t)||^2 + \bar{a}_t}{2(1-\bar{a}_t)}\right]\exp\left[\frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_y(t)\right]\quad(278)$
```

where $C_t$ is the normalization constant. Putting Equation 278 into Equation 277, we obtain

```
$p(x(0) = e_{\mu_h}|x(t)) = \frac{1}{Z}e^{\frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_y(t)}\quad(279)$
```

with $Z = \sum_{\lambda=1}^v e^{\frac{\sqrt{\bar{a}_t}}{1-\bar{a}_t}x_{\lambda}(t)}$

## C.2 BELIEF PROPAGATION EQUATIONS

Given a factor-tree, the Belief Propagation (BP) equations compute iteratively the messages going from the variable nodes to the factor nodes and vice-versa, starting from the initialization conditions at the leaves and root of the tree-graph [MM09]. For the generative model defined in Section 4.3, the leaves correspond to the variables at the bottom layer while the root is the class variable at the top of the hierarchy. Each rule, connecting variables at different layers, corresponds to a factor node. The BP messages that flow from the variable nodes to the factor nodes, therefore correspond to upward messages, while those going from factor nodes correspond to downward messages.

To each variable node $X_i^{(\ell)}$ at level $\ell$, we associate the upward messages $u_i^{(\ell)}$ and downward messages $v_i^{(\ell)}$ for each possible value of the alphabet it can. To simplify the notation, here consider how messages propagate from one level to the other, and we call $Y$ the variable corresponding to the higher level and $X_{i, \ell-1}$ the lower level connected to it. The factor node connecting them is, for each possible assignment $y \rightarrow x_1, \dots, x_s$, it takes values

```
$\psi^{(\ell)}(y, x_1, \dots, x_s) = \begin{cases} 1, & \text{if } y \rightarrow (x_1, \dots, x_s) \text{ is a rule at level } \ell \\ 0, & \text{otherwise.} \end{cases}$
```

The BP upward and downward iterations are defined as follows.

- Upward iteration:
```
$\tilde{V}_y^{(\ell+1)}(y) = \sum_{x_1, \dots, x_s \in A^{\oplus}} \psi^{(\ell+1)}(y, x_1, \dots, x_s) \prod_{i=1}^s V_{x_i}^{(\ell)}(x_i), \quad (280)$
```
```
$v_y^{(\ell)}(y) = \frac{\tilde{V}_y^{(\ell)}(y)}{\sum_{y'} \tilde{V}_{y'}}^{(\ell)}(y')} \quad (281)$
```

- Downward iteration:
```
$\tilde{V}_{x_i}^{(\ell)}(x_i) = \sum_{y \in A, x_2, \dots, x_s \in A^{\ell-1}} \psi^{(\ell)}(y, x_1, \dots, x_s) v_y^{(\ell)}(y) \prod_{i=2}^s V_{x_i}^{(\ell)}(x_i) \quad (282)$
```
```
$v_{x_i}}^{(\ell)}(x_i) = \frac{\tilde{V}_{x_i}}^{(\ell)}(x_i)}{\sum_{x'} \tilde{V}_{x'}}^{(\ell)}(x')} \quad (283)$
```

$v_y^{(\ell)}(y)$ and $v_{x_i}^{(\ell)}(x)$ are fluctuating quantities that depend on the position of the node.

### C.2.1 e-process

In this process, we consider a reference configuration at the leaves variables $X_i^{(0)} = \hat{X}_i$, that we like to reconstruct, given a noisy observation of it. As a result of noise addition, our belief in the correct sequence is corrected by $\epsilon \in [0,1]$:

> $$X_i^{(0)} = \hat{X}_i \text{ with belief } 1 - \epsilon, \ X_i^{(0)} \text{ uniform over alphabet with belief } \epsilon. $$ (284)

Therefore, the initialization condition of the upward BP messages at a leaf node $X_i^{(0)}$ is

> $$\begin{cases} v_t(\hat{X}_i) &= 1 - \epsilon + \epsilon/v, \\ v_t(X_i) &= \epsilon/v, \end{cases}$$ (285)

where $v$ is the alphabet size. The initialization condition at the root node $X^{(L)}$, that corresponds to the class, is uniform over the alphabet $X^{(L)}$ has no bias.

### C.2.2 Upward iteration

We consider the upward iteration when going from the bottom layer to the above. Let $\Delta w$ the Hamming distance between two sequences $w, z$ of length $s$. In this process, we consider a reference configuration at the leaves variables $X_i^{(0)} = \hat{X}_i$, that we like to reconstruct, given a noisy observation of it. As a result of noise addition, our belief in the correct sequence is corrected by $\epsilon \in [0,1]$:

> $$X_i^{(0)} = \hat{X}_i \text{ with belief } 1 - \epsilon, \ X_i^{(0)} \text{ uniform over alphabet with belief } \epsilon. $$ (284)

Therefore, the initialization condition of the upward BP messages at a leaf node $X_i^{(0)}$ is

> $$\begin{cases} v_t(\hat{X}_i) &= 1 - \epsilon + \epsilon/v, \\ v_t(X_i) &= \epsilon/v, \end{cases}$$ (285)

where $v$ is the alphabet size. The initialization condition at the root node $X^{(L)}$, that corresponds to the class, is uniform over the alphabet $X^{(L)}$ has no bias.
