**Corollary 3.5.0.1** (generalization bound for hierarchical kernels). Let $K$ be the kernel of a deep hierarchical CNN with $s=2$. Let $f^*$ be a function depending only on a meta-patch $p_{i-1:i+1}$ or a linear combination of such functions. Furthermore, assume $f^*$ has finite-norm derivatives up to order $m$, $||\Delta^m/f^*|| < \infty$. Then, there exists a constant $C' > 0$ such that optimal-regularized regression with $K$ satisfies $\mathcal{E}(\lambda, p) - \mathcal{E}(f^*) \leq C' p^{-\beta}$

```
$$\beta = \frac{2m(2v+d_{eff}(L))}{2v+d_{eff}(L)^2} \quad (65)$
```

As an illustration, let us consider the case $p_L = p = d/2$ (the number of two-dimensional patches). Remarkably, when $p \gg 1$, $f^*$ depends only on a finite-dimensional meta-patch (or a sum of such functions) the exponent $\beta$ in **Equation 65** converges to the finite value $2m/(2m+v)+d_{eff}(L))$. In contrast, using a fully-connected kernel to learn the same target results in $\beta = 2m/(2m+p)$ - vanishing as $1/p$ when $p \gg 1$, is caused by dimensionality.

**RATES FROM BIAS VARIANCE** The same picture when estimating the decay of the error from **Equation 61**. $\Lambda(p) \sim p^{-a}$, where $\sum_k ||\mathbf{k}|^{2m}|f|^2 < \infty$ implies $||f^*|^2 \leq ||\mathbf{k}|^{2m-d_{eff}(L)}|$ for a target supported on a $d_{eff}(L)$-dimensional meta-patch. Plugging such results in **Equation 66** we obtain (details in **Section B.6.1)**

```
$$\mathcal{E}(p) \sim p^{-\beta}$ with $\beta = \frac{2m}{2v+d_{eff}(L)}$ \quad (66)$
```

Again, with $p=1$ and $d_{eff}(L)=p$, the exponent remains finite for $p \gg1$. We recover the result of **Chapter 2** with a shallow low local kernel if the target is supported on $s$-dimensional features. These results show that hierarchical kernels play significantly better with the approximation-estimation trade-off than shallow local kernels, as they are able to approximate global functions of the input without being restricted when the target function has a local structure.
