158 APPENDIX: LOCALITY DEFEATS THE CURSE OF DIMENSIONALITY

# Lemma A-3.2 (Spectra of overlapping local kernels). Let $K^{LC}$ be a local kernel defined as in Equation 34b, with $\mathcal{P}=\{1,\dots,d\}$ and constituent kernel $C$ satisfying assumptions $i, ii$ above. Then, $K^{LC}$ admits the following Mercer's decomposition,

```
$K^{LC}(\mathbf{x}, \mathbf{y}) = \Lambda_0 + \sum_{u=1}^s \left( \sum_{k \in \mathcal{F}^u} \sum_{i=1}^d \Lambda_{k,ij} \Phi_{k,i}(\mathbf{x}) \Phi_{k,j}(\mathbf{y}) \right) \quad (149)$
```

with eigenfunctions

```
$\Phi_0(\mathbf x)=1, \Phi_{k,i}(\mathbf{x})=\phi_k(\mathbf{x}) \quad \forall k \in \mathcal{F}^u \text{ with } 1 \le u \le s \text{ and } i=1,\dotsdots,d, \quad (150)$
```

and eigenvalues

```
$\Lambda_0=\lambda_0, \Lambda_{k,ij} = \frac{s-u+1}{d}\lambda_k \quad \forall k \in \mathcal{F}^u \text{ with } u \le s \text{ and } i=1,\dotsdots,d. \quad (151)$
```

Proof. We start by proving the orthonormality of the eigenfunctions. The scalar product $\Phi_{kj},\Phi_{qj}$ depends on the relation between the $i$-th and $j$-th patches,

```
$$\int_{[0,1]^d} d^d x \phi_k(\\mathbf x) \phi_q(\\mathbf x)$$
$= \delta(k^{(s-i)}, 0) \delta(k_{i+1}^{(i)}, q_1^{(j)}) \delta(q_{j+1}^{(s-j)}, 0), \quad \text{if } j \in \mathcal{P}_{i+},}, \quad (152a)$
$= \delta(k^{(s-i)}, 0) \delta(k^{(j)}, q_{i+1}^{(s-j)}), \quad \text{if } j \in \mathcal{P}_{i-}, \quad (152b)$$
$= \delta(k, 0) \delta(q, 0), \quad \text{if } j \neq \mathcal{P}_l, \quad (152c)$$
$= \delta(k, q), \quad \text{if } j = i. \quad (152d)$
```

Clearly, $(\Phi_0, \Phi_0)$ and setting one of $\mathbf k$ and $\mathbf q$ in Equation 152 yields orthogonality between $\Phi_0$ and $\Phi_{ki}$ for all $k \neq 0$ and $i=1,\dotsdot,d$. For any $\mathbf k$ and $\mathbf q \neq 0$, Equation 152 implies

```
$$\Phi_{kj},\Phi_{qj} = \delta(k,q)\delta_{i,j} \quad (153)$
```

unless $k^{(i)} \in \mathcal{F}^u$ and $\mathbf q$ is a patch of $k^{(i)}$. But such a $\mathbf q$ would have $q_1=0$ and there is no eigenfunction $\Phi_q$ with $q_1=0$, apart from $\Phi_0$. Hence, orthonormality is proven.

We prove that eigenfunctions and eigenvalues defined in Equation 150 and Equation 151 satisfy the kernel eigenproblem of $K^{LC}$. For $\mathbf k=0$,

```
$$\int_{[0,1]^d} d^d y K^{LC}(\mathbf x, \mathbf y) = \frac{1}{d} \int_{[0,1]^d} d^d y \sum_{q} \Lambda_{kq} \delta^q(\mathbf x - \mathbf y) = \Lambda_0. \quad (154)$
```
