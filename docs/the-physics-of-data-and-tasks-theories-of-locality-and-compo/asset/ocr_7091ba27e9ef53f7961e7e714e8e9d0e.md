Similarly, we can consider products of Legendre polynomials on $[-1,1]^{p}$ (see [Gei+22], appendix A). Then, any function $f$ on $\mathrm{M}S^{s+1} \times \mathrm{M}S^{s+1}$ which depends only on the $p$ scalar products between patches,

```
$f(\mathbf{x}, \mathbf{y}) = g(\mathbf{x}_{1}, \mathbf{y}_{1}, \dots, \mathbf{x}_{p}, \mathbf{y}_{p}), \quad (198)$
```

can be written as a sum of projections on Legendre polynomials

```
$\hat{P}_{k}(\mathbf{t}) := \prod_{i=1}^{p} P_{k_{i}}(t_{i}). \quad (199)$
```

Following [Gei+22], we can when fixing one of the two arguments of $f$ (say $\mathbf{x}$), $f$ becomes a function on $\mathrm{M}S^{s+1} \times \mathrm{M}S^{s+1}$ and can be written as a sum of projections on the $\hat{Y}_{k,\ell}^{\cdot}$. The two expansions are related by the following generalized Funk-Hecke formula,

```
$\left(\prod_{i=1}^{p} \int_{S^{s-1}} d\tau_{i}(\mathbf{y})\right)g(\mathbf{x}_{1},\\mathbf{y}_{1},\dots,\mathbf{x}_{p},\\mathbf{y}_{p})\hat{Y}_{k,\ell}(\mathbf{y}) = \\\hat{Y}_{k,\ell}(\mathbf{y}) \left(\frac{|S^{s-2}|}{|S^{s-1}|}\right)^{p} \left(\prod_{i=1}^{p} \int_{-1}^{1} dt_{i}(1-t_{i}^{2})^{\frac{s-2}{2}} P_{k_{i}}(t_{i})\right) g(t_{1},\dots,t_{p}).\quad (200)$
```
