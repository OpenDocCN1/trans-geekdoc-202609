# B.6.1 Rates from spectral bias ansatz

Consider a target function $f^*$ and which only depends on the meta- $x^*$ and with square-integrable derivatives up to order $m$, i.e. $|\Delta^{m/2}f^*|^2 < \infty$, with $\Delta$ the Laplace operator. More- over consider a hierarchical kernel of depth $L+1$ with filter sizes $(s_1, ..., s_L)$ and $p_l = 1$. We want to compute the asymmetric scaling of the error by using Equation 61, i.e.

```
$$\mathcal{E}(P) \sim \sum_{k,l: \Lambda_k < \Lambda(P)} |f_{k,l}|^2. \quad (269)$
```

In Section B.4, we showed that the $P$-th eigenvalue of the kernel $\Lambda(P)$ decays as

```
$\Lambda(P) \sim P^{-1-\frac{2m}{d_{att}(L)}}. \quad (270)$
```

Since by construction the target function depends only on a meta- patch of the $l$-th layer, all non-zero projections will be the on eigenfunctions of the first $l$ layers. Thus, all the $k$'s corresponding to layers with $l' > 1$ do not contribute to the sum. The sum is dominated by the $k$'s of the largest and and the set $\{k | \Lambda_k < \Lambda(P)\}$ is the set of $k_{l+1,..,L+1}^s$ with norm larger than $P^{\frac{2m-d_{att}(L)}{d_{att}(L)}}$.

Finally, we note the norm-condition on the derivatives,

```
$|\Delta^{m/2}f^*|^2 = \sum_{k} (|prod_{i=1}^k N_{k,s}) (|sum_{j=1}^k (k_i + s_j - 2))^m |f_{k,l}|^2 < \infty, \quad (271)$
```

implies $|f_{k,l}|^2 \leq ||k|_{2m-d_{att}(L)}^2$ (see Section B.3.3).

Hence, plugging everything in Equation 269 we find

```
$\mathcal{E}(P) \sim P^{\frac{2m-d_{att}(L)}{d_{att}(L)}}. \quad (272)$
```
