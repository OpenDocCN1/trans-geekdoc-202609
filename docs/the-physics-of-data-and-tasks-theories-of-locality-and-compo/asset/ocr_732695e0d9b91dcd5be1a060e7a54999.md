We call $n_{X_1}$, the number of sequences, having $X_1 = x_1$, that have been sampled by the choice of rules. The rules $n_{X_1}$ are distributed according to a multivariate hyper-geometric distribution,

```
$P\left(\{n_{X_i} \ x_i \in \mathcal{A}\right) = \frac{\binom{v^{s-1}-1}{n_{X_1}} \prod_{x_i \in \mathcal{A} \setminus \{x_1\}} \binom{v^{s-i}-1}{n_{X_i}}}{...}, \quad (311)
```

which gives averages

```
$\langle n_{X_1} \rangle = \frac{mv-1}{v^s-1}(v^{s-1}-1) = f(v^{s-1}-1), \quad (312)
```

```
$\langle n_{X_i \neq X_1} \rangle = \frac{mv-1}{v^s-1}v^{s-1}. \quad (313)
```

Award the downward messages over the choices of rules $\psi$, we obtain:

+   for $x_1 \neq \bar{X}_1$:

```
$\langle v_i(x_1) \rangle_\psi = \sum_{y} v_i(y) \langle \sum_{x_2,..,x_s \in S} \psi(y,x) \rangle_{y \leftarrow x} \prod_{i=2}^s \nu_t(x_i) \mathcal{S} \\n = \frac{m-v_i(y)}{mv-1} (\delta_{x_k \in S}) \mathcal{S} \prod_{i=2}^s \nu_t(x_i) - \frac{m-v_i(y)}{mv-1} \\n = \frac{m-v_i(y)}{mv-1} f, \n\quad (314)
```

where $\delta_{x_k \in S} \mathcal{S} = \frac{n_{X_k \neq X_1}}{v^{s-1}-1}$,

+   for $x_1 = \bar{X}_1$:

```
$\langle v_i(X_1) \rangle_\psi = \prod_{i=2}^s \nu_t(x_i) \\n = + \sum_{y} v_i(y) \langle \sum_{x_2,..,x_s \in S, x \neq y} \psi(y,x) \rangle_{y \leftarrow x} \prod_{i=2}^s \nu_t(x_i) = \mathcal{S} \\n = v_i(x_1) \prod_{i=2}^s \nu_t(x_i) + \frac{m-v_i(y)}{mv-1}(\delta_{x_k \in S}) \mathcal{S} \prod_{x_2,..,x_s \in S, x \neq y} \nu_t(x_i) \\n = v_i(x_1) \prod_{i=2}^s \nu_t(x_i) + \frac{m-v_i(y)}{mv-1} [1 - \prod_{i=2}^s \nu_t(\bar{X}_i)] \n\quad (315)
```

where $\delta_{x_k \in S} \mathcal{S} = \frac{n_{X_1}}{v^{s-1}-1}$.
