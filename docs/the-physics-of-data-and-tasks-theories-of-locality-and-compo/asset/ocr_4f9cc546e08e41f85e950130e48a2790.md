For image diffusion, we use the publicly available models from Improved Denoising Probabilistic Models [ND21], trained on the ImageNet dataset at resolution 256 x256. We use the class-unconditional model to ensure a class phase transition at intermediate diffusion time. To tokenize the images in a semantically meaningful way, we use the last-layer embeddings from a CLIP Vi-B32 [Rad+21] encoder. This procedure crops the images to the size 224 x224, which get tokenized in 7 x7 patches, each dimension 32 x 32. The embeddings at the last layer of the CLIP encoder have dimension 768.
