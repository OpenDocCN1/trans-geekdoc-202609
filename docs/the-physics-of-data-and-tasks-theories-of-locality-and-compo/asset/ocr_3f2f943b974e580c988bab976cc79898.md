# E.2 ONE-STEP GRADIENT DESCENT

We consider a simplified one-step gradient descent setting [DLS22], where a simple machine-learning model of one input token $X_{s+1}$ following an $s$-tuple of tokens $X=(X_1, \dots, X_s)$. The training set $X_p$ consists of $P$ pairs $(x, v)$, with $v$ denoting the feature in the token $X_{s+1}$. We assume that

+   i) the input token $X$ is given as the one-hot encoding of the tuple index. Each of $mv$ possible combinations of $s$ features is assigned an index $\mu = 1, \dots, mv$ and $x$ is the $mv$-dimensional sequence $x_\mu = \delta_{\mu, \mu(x)}$

+   ii) the machine-learning model is initialized on the empirical marginal probability of the token $X_{s+1}$ over the training set, $\mathbb{P}(X_{s+1} = v) := P^{-1} \sum_{(x, \lambda) \in X_p} \delta_{v, \lambda}$. This assumption is equivalent to a preprocessing step on the labels [DLS22] that removes the class imbalance of the training set.
