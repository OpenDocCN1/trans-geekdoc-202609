BACKWARD DIFFUSION WITH BP The BP sampling is equivalent to learning the backward dynamics with the true function of the RHM. In fact, given a noisy observation $\mathbf{x}_i$ at time $t$, the marginal probabilities $p(h_j^{(t)}|\mathbf{x}_i)$ at the visible nodes can be used to compute the expectation $E(h_j^{(t)}|\mathbf{x}_i)$.
