Denoting with $p_t$ the probability density of $x(t)$, we define the marginal $p_0 := p_{\text{data}}$ as the data distribution and $p_T$ as the terminal (or prior) distribution, which is simple and easy to sample.

To generate data, we reverse this process. The reverse-time SDE, derived from the Fokker-Planck equation [And82], reads:

```
$dx = [f(x, t) - g(t)^2\nabla \log p_t(x)]dt + g(t)dw,$ (14)
```

where $dt$ is an infinitesimal negative time-step, $w$ is a Brownian motion running backward in time, and $\nabla \log p_t(x)$ is the so-called *score function*. Thus, learning to sample from the distribution reduces to estimating the score at each time.

The score is learned by training a neural network $s_{	heta}(x, t)$ via matching [Hvy+09], i.e., minimizing the loss

```
$\mathbb{E}_{x(0)}[||s_{	heta}(x(0), t) - \nabla \log p_t(x(0))||^2]. .$ (15)
```

For an affine drift $f(-, t)$, the transition kernels are Gaussian, allowing for analytical expressions of the score.

# DIFFUSION PROBABILISTIC MODELS (DDPMs) In practice, the continuous-time SDE is discretized. In DDPMs [HJA20] - we define $f(x) := -\frac{1}{2}\beta(t)x$ and $g(t) :=\sqrt{\beta(t)}$ - the forward process

with a noise schedule $\{\beta_t\}_{t=1}^T$ that typically increases linearly with time or follows a cosine law. The backward process reverses this trajectory using a learned score network. Notice that the conditional score at each step is given by:

```
$x_t = \sqrt{1-\eta_t}x_{t-1} + \sqrt{\beta_t}z_{t-1}, \quad z_{t-1} \sim \mathcal{N}(0, \mathbf{I}),$ (16)
```

and averaging over the distribution, the score is

```
$\nabla_x \log p_t(x_0) = \frac{x_t - \sqrt{\bar{\alpha}_t}x_0}{\sqrt{1-\bar{\alpha}_t}}, \quad \bar{\alpha}_t = \prod_{i=1}^t (1-\beta_i),$ (17)
```

```
$\nabla_x \log p_t(x_t) = \mathbb{E}_{x_0|x_t}[\nabla \log p_t(x_t)] = \frac{x_t - \sqrt{\bar{\alpha}_t}x_0}{1-\ar{\alpha}_t}.$ (18)
```

Thus, one can train a diffusion network to directly predict $\mathbb{E}[x_0|x_t] := \mathbb{E}_{x_0|x_t}].

ARCHITECTURES A common architectural choice for the score net is the U-Net [RFB15], a convolutional neural network featuring symmetric downsampling and upsampling paths, each comprising multiple resolution blocks. Skip connections blocks that operate at the same resolution, helping to retain fine-grained details that might be lost during the downsampling process. More recently, transformer-based architectures have also been introduced as alternative backbones for diffusion models [PX23].
