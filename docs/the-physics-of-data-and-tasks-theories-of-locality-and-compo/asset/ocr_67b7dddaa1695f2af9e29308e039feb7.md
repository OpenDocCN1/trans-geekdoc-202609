# G.1 EXPERIMENTAL DETAILS

All experiments were performed using the same hardware consisting of four V100 NVIDIA GPUs with 32GB of memory each and can be reproduced in less than 350 GPU hours. The details of each experiment are the following:

+   * FINE-TUNING. All the fine-tuning experiments follow the same training protocol specified in Ilharco et al. [Ilh+23] with minor modifications to the training code to use linearized models when needed. We fine-tune all datasets starting from the same CLIP pre-trained checkpoint downloaded from the open_clip repository [Ilh+21]. fine-tune for 2,000 iterations with a batch size of 128, learning rate of 10⁻⁵ and a cosine learning schedule with 200 warm-up steps and the AdamW optimizer [LH19]. As introduced in Ilharco et al. [Ilh+22], during fine-tuning, we freeze the weights of the classification layer by encoding a standard set of zero-shot templates for each dataset. Freezing this layer does harm and ensures that no additional learnable parameters are introduced during fine-tuning [Ilh+22]. We use this exact protocol to fine-tune the non-linear and linearized models and do not perform any form of hyperparameter search in our experiments.

TUNING OF A TASK ARITHMETIC BENCHMARKS. As in Ilharco et al. [Ilh+23] we use a single coefficient α to tune the size of the task vectors used to modify the pre-trained models. This is achieved by setting a = α... in Equation 91. In both fine-tuning, and task addition benchmarks, we evaluate different coefficients α ∈ {0, 0.5, 0.1, ..., 1} and choose the value that achieves the highest target metric on a small held-out proportion of the task as specified in Ilharco et al. [Ilh+23]. Namely, maximum normalized average accuracy, and minimum target accuracy on each dataset that still retains at least 95% of the accuracy of the pre-trained model on the control task; for task addition and negation, respectively. The tuning of α is done independently for non-linear FT, linearized FT, and post-hoc linearization.
