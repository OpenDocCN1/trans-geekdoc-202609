# **B.3.1 (Spectrum of hierarchical kernels). Let $T_K$ be the integral operator associated with a $d$-dimensional hierarchical kernel of depth $L+1$, $L>1$ and filter sizes ($s_1, \dots, s_L$). Eigenvalues and eigenfunctions of $T_K$ can be associated with the layers of $L$ sectors of the kernel/network. For each $1 \leq l \leq L$, the $l$-th sector consists of $\chi_{k_{i-l+1}}^{(l)}}$ $—local eigenfunctions: functions of a single meta-patch which cannot be written as linear combinations of functions of single meta-patches. The labels $k$ of these eigenfunctions are such that there is a meta-patch $k_{i-l+1}^{(l)}}$ of $k$ with vanishing non-zero sub-meta-patches and all the $k'$ outside of $k_{i-l+1}}^{(l)}$ are 0 (because the eigenfunction is constant outside $k_{i-l+1}}^{(l)}$). The corresponding eigenvalue is degenerate with respect to the location of the meta-patch: we call it $\Lambda_{k_{i-l+1}}^{(l)}}.$

When $\Lambda_{k_{i-l+1}}^{(l)}} \to \infty$, with $k = |\Lambda_{k_{i-l+1}}^{(l)}|$,

+   i. if $s_1 = 2$,

```
$$\Lambda_{k_{i-l+1}}^{(l)}} = \mathcal{C}_{2,j} k^{-2\nu-d_{\ell}(l)} + o\left(k^{-2\nu-d_{\ell}(l)}\right),\quad(205)$
```

with $V_{NTK} = 1/2, V_{RFK} = 3/2$ and $d_{\ell}$ the effective dimensionality of the meta-patches defined in Equation 52. $\mathcal{C}_{2,j}$ is a strictly positive constant for $l \geq 2$, whereas for $l = 1$ it can take two strictly positive values depending on the parity of $k_{i-l+1}}^{(l)}$.

+   ii. if $s_1 \geq 3$, then for fixed non-zero angles $k/k$,

```
$$\Lambda_{k_{i-l+1}}^{(l)}} = \mathcal{C}_{s_l,j} \frac{|k_{i-l+1}}^{(l)}|}{k} k^{-2\nu-d_{\ell}(l)} + o\left(k^{-2\nu-d_{\ell}(l)}\right),\quad(206)$
```

where $\mathcal{C}_{s_l,j}$ is a positive function for $l \geq 2$, whereas for $l = 1$ it is a strictly positive constant which depends on the parity of $k_{i-l+1}}^{(l)}$.
