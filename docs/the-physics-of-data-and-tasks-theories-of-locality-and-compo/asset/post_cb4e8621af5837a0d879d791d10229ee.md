## A.3 MERCER'S DECOMPOSITION OF CONVOLUTIONAL AND LOCAL KERNELS

In this section, we prove the eigendecompositions introduced in Lemma 2.3.3 and Lemma 2.3.4, then extend them to overlapping-patches kernel (ref. A.3.1). We define the scalar product in input space between two (complex) functions $f$ and $g$ as

```
$\langle f, g \rangle = \int_d p(d^dx)f(\mathbf{x})g(\mathbf{x}).$
```

### PROOF OF LEMMA 2.3.3

We start by proving orthogonality of the eigenfunctions. By writing the $d$-dimensional eigenfunctions $\Phi_\rho$ in terms of the $s$-dimensional eigenfunctions $\phi_\rho$ of the constituent kernel as in Equation 38, for $\rho, \sigma \neq 1$,

```
$\langle \Phi_\rho, \Phi_\sigma \rangle = \frac{s}{d} \sum_{i \in P} \int p(d^dx)\phi_\rho(\mathbf{x}_i)\phi_\sigma(\mathbf{x}_j).$
```

Separating the term in the sum over patches where $i$ and $j$ coincide from the others, since the patches are not overlapping, the RHS can be written as

```
$\frac{s}{d} \sum_{i \in P} \int p(d^dx)\phi_\rho(\mathbf{x}_i)\phi_\sigma(\mathbf{x}_i) + \sum_{i\neq j \in P} \int p(d^dx)\phi_\rho(\mathbf{x}_i)\phi_\sigma(\mathbf{x}_j).$
```

From the orthogonality of the eigenfunctions $\Phi_\rho$, the first integral is non-zero and equal to one only when $\rho = \sigma$, while, from assumption $i$, $p^{(s)}(d^dx)\Phi_\rho(x) = 0$ for all $\rho > 1$, so that the second integral is always zero. Therefore,

```
$$\Phi_\rho\Phi_{\sigma} = \delta_{\rho,\sigma}. \quad (119)$$
```

When $\rho = 1$ and $\sigma \neq 1$, $\int p(d^4x)\Phi_1(x)\Phi_\rho(x) = 0$ from assumption $i$, i.e., $\Phi_1 = 1$ and $\int p^{(s)}(d^4x)\Phi_\rho(x) = 0$ for all $\rho > 1$. Finally, if $\rho = 1$, $\int p(d^4x)\Phi_1(x) = 1$. Then, we prove that the eigenfunctions and the eigenvalues defined in Equation 38 satisfy the kernel experiment. For $\rho = 1$,

```
$$\int p(d^4y)K^{CN}(\mathbf{x},y) = \int p(d^4y)\sum_{i,j\in P} \frac{s^2}{d_i^2} C(x_i,y_j) = \frac{s^2}{d^2} \sum_{i,j\in P} \lambda_1 = \Lambda_1, \quad (120)$$
```

where we used $\int p^{(s)}(d^4y)C(\mathbf{x},y) = \lambda_1$ from assumption $i$. For $\rho > 1$,

```
$$\int p(d^4y)K^{CN}(\mathbf{x},y)\Phi_\rho(y) = \int p(d^4y)\sum_{i,j\in P} \frac{s^2}{d_i^2} C(x_i,y_j)\sqrt{\frac{s}{d^2}} \sum_{i\in P} \Phi_\rho(y_i). \quad (121)$$
```

Splitting the sum over $l$ into the term with $l=j$ and the remaining ones, the RHS has been written as

```
$$\frac{s^2}{d^2} \sum_{i,j\in P} \left( \int p(d^4y)C(x_i,y_j)\sqrt{\frac{s}{d^2}} \Phi_\rho(y_j) \right) + \int p(d^4y)C(x_i,y_j)\sqrt{\frac{s}{d^2}} \sum_{i\neq j\in P} \int p(d^4y)\Phi_\rho(y_l). \quad (122)$$
```

Using assumption $i$), the third integral is always zero, therefore

```
$$\int p(d^4y)K^{CN}(\mathbf{x},y)\Phi_\rho(y) = \frac{s^2}{d^2} \sum_{i,j\in P} \Lambda_\rho\sqrt{\frac{s}{d^2}} \Phi_\rho(x) = \Lambda_\rho\Phi_\rho(x). \quad (123)$$
```

Finally, we prove the expansion of Equation 37 from the definition of $\mathcal{K}^{CN}$,

```
$\mathcal{K}^{CN}(x,y) = \frac{s^2}{d^2} \sum_{i,j\in P} C(x_i, y_j) \quad (124)$
= \frac{s^2}{d^2} \sum_{i,j\in P} \Lambda_{ij} \phi_p(x)\phi_p(y) = \lambda_1 \frac{s^2}{d} \sum_{i\in P} \phi_1(x)\phi_1(y) + \sum_{\rho > 1} \Lambda_\rho \left( \sqrt{\frac{s}{d}} \sum_{i\in P} \Phi_\rho(x) \right) \left( \sqrt{\frac{s}{d}} \sum_{j\in P} \Phi_\rho(y) \right) = \sum_{\rho} \Lambda_\rho \Phi_\rho(x)\Phi_\rho(y).$
```

### PROOF OF LEMMA 2.3-4

We start again by proving the orthonormality of the $d$-dimensional eigenfunctions $\Phi_{\rho,j}$ in terms of the $s$-dimensional eigenfunctions $\phi_\rho$ of the constituent kernel as Equation 40, for $\rho,\sigma \neq 1$,

```
$$\Phi_{\rho,i}(x), \Phi_{\sigma,j}(y) = \int p(d^dx)\Phi_{\rho,i}(x)\Phi_{\sigma,j}(y) = \delta_{\rho,\sigma}\delta_{i,j}, \quad (125)$$
```

from the orthonormality of the eigenfunctions $\Phi_\rho$ when $i=j$ and assumption $i$, if $\int p^{(s)}(d^dx)\phi_\rho(x)=0$ for all $\rho > 1$, when $i \neq j$. Moreover, if $\Phi_1(x)=1$, $\int p(d^dx)\Phi_{\sigma,i}(x)=0$ and $\int p(d^dx)\Phi_1(x)=1$. Then, we prove that the eigenfunctions and the eigenvalues defined in Equation 40 satisfy the kernel eigenproblem. For $\rho=1$,

```
$$\int p(d^dx)\mathcal{K}^{LC}(x,y) = \int p(d^dx)\sum_{i \in P} \frac{s}{d} \lambda_1 = \frac{s}{d} \sum_{i \in P} \lambda_1 = \Lambda_1, \quad (126)$$

where we used $\int p^{(s)}(d^sy)C(x,y)=\lambda_1$, from assumption $i$. For $\rho > 1$,

```

Splitting the sum over $j$ in the term for which $j=i$ and the remaining ones, the RHS can be written as

## A.3.1 Spectra of convolutional kernels with overlapping patches

In this section Lemma 2.3.3 and Lemma 2.3.4 are extended to kernels with overlapping patches, where $\mathcal{P}=\{1,\dots,d\}$ and $|\mathcal{P}|=d$. Such an extension requires additional assumptions, which are stated below:

- i) The d-dimensional input measure $p^{(d)}(d^d\mathbf{x})$ is uniform on the d-torus $[0,1]^d$;
- ii) The constituent kernel $\mathcal{C}(\mathbf{x},\mathbf{y})$ is translationally-invariant, isotropic and periodic,

```
$$\mathcal{C}(\mathbf{x},\mathbf{y}) = c(|||\mathbf{x}-\mathbf{y}||\), c(|||\mathbf{x}-\mathbf{y}+\mathbf{n}||\)=c(|||\mathbf{x}-\mathbf{y}||\) \forall \mathbf{n} \in \mathbb{Z}^d. \quad (134)$$
```

Assumptions (i) and (ii) imply that $\mathcal{C}(\mathbf{x},\mathbf{y})$ can be diagonalized in Fourier space, i.e., with $k$ denoting the s-dimensional wavenumber

```
$$\c(\mathbf{x}-\mathbf{y}) = \sum_{k=2:n \in \mathbb{Z}^d} \lambda_k \Phi_k(\mathbf{x})\overline{\Phi_k(\mathbf{y})} = \sum_{k=2:n \in \mathbb{Z}^d} \lambda_k e^{i\mathbf{k}^T\mathbf{x}}, \quad (135)$$
```

and the eigenvalues $\lambda_k$ depend only on the modulus of $k$, $\mathbf{k}=\sqrt{\mathbf{k}^T\mathbf{k}}$. Let us introduce the following definitions, after recalling that a s-dimensional path $x_i$ of $\mathbf{x}$ is a contiguous subsequence of $\mathbf{x}$ starting at $x_i$,

```
$$\mathbf{x} = (x_1,x_2,\dots,x_d) \Rightarrow \mathbf{x}_i = (x_i,x_{i+1},\dots,x_{i+s-1}), \quad (136)$$
```

and that inputs are 'wrapped', i.e., we identify $x_{nd}$ with $x_d$ for all $n \in \mathbb{Z}$.
