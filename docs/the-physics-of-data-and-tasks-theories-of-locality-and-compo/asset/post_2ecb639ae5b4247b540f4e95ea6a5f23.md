
Due to assumption i), the task can be solved with a perceptron model followed by a softmax nonlinearity,

```
$f_v(x;W) = \sum_{\mu} W_{v,\mu}x_{\mu} \quad p_v(x;W) = e^{f_v(x;W)}\left(\sum_{\mu} e^{f_{\mu}(x;W)}\right); (398)
```

where $W \in R^{V \times (vm)}$ is the weight matrix. In this setup, ii) is realized by initializing the weights as $W_{v,\mu} = \log\mathbb{P}[X_{s+1}=v]$-dependently of $\mu$.

The model $f$ of Equation 398 is trained via Gradient Descent on the empirical-entropy loss computed over a training set $X_r$ of pairs $(x, v)$, with $v$ denoting the feature in the token $X_{s+1}$,

```
\mathcal{L} = \mathbb{E}_{(x,v) \in X_r} \left[ -\log \frac{e^{f_v(x;W)}}{\sum_{\mu} e^{f_{\mu}(x;W)}} \right], (399)
```

$\mathbb{E}_{(x,v) \in X_r}$ denotes the empirical average over the training set. Denoting the learning rate by $\eta$, the updates of the weights are

```
\Delta W_{v,\mu} = -\eta \frac{\partial f_v}{\partial W_{v,\mu}} = -\eta \mathbb{E}_{(x,v) \in X_r} \delta_{\mu,\mu}(x) - [X_{s+1}=v] \frac{e^{f_{\mu}(x;W)}}{\sum_{\mu'} e^{f_{\mu'}(x;W)}} \n\mathbb{E}_{(x,v) \in X_r} [X_{s+1}=v] \delta_{\mu,\mu}(x) - [X_{s+1}=v] \delta_{\mu,\mu}(x) \n\eta \left( \mathbb{P}[X_{s+1}=v | v_r(x_1, \dots, x_r) = (\mu_1, \dots, \mu_r)] \right) \n-[X_{s+1}=v | v_r(x_1, \dots, x_r) = (\mu_1, \dots, \mu_r)] \right), (400)
```

where, in this case we used assumption i) to replace $x_r$ with $\delta_{\mu,\mu}(x)$ and assumption ii) to replace $e^{f_{\mu}} / \sum_{\mu'} e^{f_{\mu'}}$ with $\mathbb{P}[X_{s+1}=v]$. The right-hand side of the last line equals the empirical-token tuple relation $\hat{C}_P(v,\mu)$. Therefore, after one gradient step, the weights are given by

```
$W_{v,\mu} = \log \hat{C}_P(v,\mu). (401)
```

The first term is independent of the input $\mu$, whereas the weights can be thought of as a noisy measurement of the true-token correction $C(v,\mu)$. The true correlation is equal for all $\mu$'s generated by the higher-level hidden symbol $h^{(1)}(\mu)$ and its size can be dated as the standard deviation over realizations of the RHM (Equation-389).

```
$C(2) \simeq \sqrt{\frac{1-f}{v^3 m^4}} (402)
```

The empirical measurement $\hat{C}_P$ includes a sampling noise contribution, having size $(v^2 mP)^{-1/2}$. If $P \geq vm^3/(1-f)$, the $\hat{C}_P$ in the right-hand side of Equation 401 is approximately equal to the true-tuple correlation, thus the weights can be used to build a representation of the hidden variables of the generative model.

## E.3 EXPERIMENTAL DETAILS

# RANDOM HIERARCHY MODEL

We train the U-Net-based Discrete Denoising Diffusion Probabilistic Model (D3PM), optimizing the diffusion loss derived from a variational bound on the negative likelihood [SD+15]. Following Austin et al. [Aus+21], we use the network to predict the conditional expectation $\mathbb{E}[x(0)|x(t)]$, which parameterizes the reverse diffusion process.

The convolutional U-Net consists of $L$ resolution blocks in both the encoder and decoder, with filter size of $s$, stride of $s$, and 8192 channels. Each block uses GELU activation functions, link encoder and decoder layers with the same resolution. The model also includes embedding and unembedding layers, implemented as convolutions with filter size.

We initialize the network using the maximal-update $(\mu P)$ parameter [YH20]. This allows stable learning dynamics even in large models. The model is trained with SGD with a learning rate of 1, a batch size of 32, and momentum parameter of 0.9. The diffusion process follows a linear schedule with 1,000 noise levels. To prevent overfitting, we apply early stopping based on the validation loss, halting training when it plateaus or begins to increase.

# LANGUAGE DIFFUSION MODEL

Our experiments are based on the codebase of MD4 [Shi+24]: https://github.com/googledeepmind/md4. MD4 is a masked diffusion model. At each step $t$, non-masked tokens either remain unchanged or transition to [MASK] with probability $\eta_t$. Using a one-hot-encoding representation of $|\mathcal{V}|+1$, the forward transition matrix is given by: $Q_t = (1 - \eta_t)I + \eta_t e_M$, with the identity matrix $I$, and $e_M$ the one-hot-encoding vector corresponding to the [MASK] symbol. For the final time $T$, all tokens are masked, i.e. $x(T) = [MASK]$ for every $i \in \text{dim}(x)$. We train MD4 with batch size 64 and context size 1024 for a single epoch. All other hyperparameters are unchanged.

# DIFFUSION MODEL

Our experiments are based on the codebase of Improved DDPM [ND21]: https://github.com/openai/improved-diffusion. In particular, we train a DDPM with 128 channels, 3 resolution blocks, 4000 diffusion steps, cosine noise schedule, learning rate $10^{-4}$ and batch size 128 for 10 epochs.

## E.4 ADDITIONAL RESULTS

### E.4.1 Hierarchical representations in the U-Net

In Figure 57, we test the hypothesis that the U-Net learns to represent together inputs that differ by low-level synonyms, i.e. the choice of production rules. To do so, we introduce a transformation operator $R_\ell \mathbf{x}$, which modifies a given data set by resetting all choices of production rules from level $\ell$. This is equivalent to substituting all tuples at depth $\ell-1$ with a synonym. We define the relative sensitivity $S_{k,\ell}$ of the pre-activations $a_k$ at layer $k$ to the transformation $R_\ell$:

```
$S_{k,\ell} = \frac{\mathbf{E}_{\mathbf{x}} ||a_k(\mathbf{x}) - a_k(R_\ell(\mathbf{x}))||^2}{\mathbf{E}_{\mathbf{x}} ||a_k(\mathbf{x}) - a_k(\mathbf{y})||^2}} \quad (404)
```

Here, the numerator measures how much the activations change when synonym substitutions are applied at depth $\ell$, while the denominator normalizes by the overall variability of activations across different data points. A low value of $S_{k,\ell}$ indicates that the network is invariant to synonym substitutions at depth $\ell$, implying that it has learned the corresponding compositional rule.
