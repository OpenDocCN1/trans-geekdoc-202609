# 7.3 GENERALIZATION VS. MEMORIZATION WITH A SIMPLE GRAMMAR

In this section, we consider diffusion models trained to generate data from the Random Hierarchy Model (RHM) [Cag24], which provides a theoretical framework for interpreting the generalization-memorization dynamics in real data.

As discussed in Chapter 6:

+   - The sample complexity to learn vast data depends on the parameters of the model as $P^* \sim v^{l+1}$, which is polynomial in the dimension $l$, $P^* \sim v^{\log m/l}$. This scale can be theoretically predicted by comparing the correlations between tokens and latent features, used in deep architectures for denoising, with their sampling noise.
- For $P^*$, there are regimes of partial generalization where the generated data are consistent with the rules up to layer $\ell$. The sample complexity to learn at layer $\ell$ scales as $P_l \sim v^{\ell+1}$.
- When $P > P_l$, the number of training steps $\tau_l$ required to learn the rules at layer $\ell$ is proportional to $P_l$ having the same polynomial scaling with the dimension. Complete generalization is therefore achieved with $\tau^* \propto P^* = P_l$ number of training steps.

Notice that the sample complexity depends on the underlying distribution, e.g., the parameters of the grammar, and not on the specific number of available training samples.
