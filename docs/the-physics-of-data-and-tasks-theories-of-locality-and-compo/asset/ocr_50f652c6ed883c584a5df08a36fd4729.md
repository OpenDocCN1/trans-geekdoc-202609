# APPENDIX: A PHASE TRANSITION IN THE DIFFUSION PROCESS

We call $\Delta_{w}$ the Hamming distance between two sequences $\mathbf{w} = [w_1, \dots, w_s]$, $\mathbf{z} = [z_1, \dots, z_s]$ of length $s$.
From Equation 28s, at the bottom layer, the belief in a sequence $\mathbf{x} = [x_1, \dots, x_s]$ with $\Delta_{\mathbf{x},	ilde{x}} = k \in \{0, \dots, s\}$ from $	ilde{\mathbf{x}} = [	ilde{x}_1, \dots, 	ilde{x}_s]$ is

```
$$\mathcal{B}(k) = \binom{s}{k} \epsilon^k (1-\epsilon)^{s-k} \quad (286)$
```

The non-normalized upward messages for the variable $Y$ are given by:

```
$$\tilde{\psi}^{\dagger}(y) = \sum_{x_1,\dots,x_s} \psi(y, x_1, \dots, x_s) \prod_{i=1}^s \frac{\psi(y, x_i)}{\sum_{x \in S} \psi(y, x)} \mathcal{B}(\Delta_{x,\tilde{x}}) \quad (287)$
```

where we use the short-hand notation $\psi(y, x_1, \dots, x_s) = \psi(y, \mathbf{x})$ and we have restricted the sum over the set $S$ of sequences $\mathbf{x}$ that appear in the possible rules $y \rightarrow x_1, \dots, x_s$. In fact, if $\mathbf{x} \notin S$, then $\psi(y, \mathbf{x}) = 0$.

For $\mathbf{x} \in S$, the factor $\psi(y, \tilde{\mathbf{x}})$ is:

+   if $\Delta_{\mathbf{x},\tilde{x}} = 0$:$
  $\begin{cases} \psi(y, \tilde{x}_1, \dots, \tilde{x}_s) = 1, \ \psi(y, \tilde{x}_1, \dots, \tilde{x}_s) = 0, & \quad y \neq \tilde{y}. \end{cases} \quad (288)$

+   if $\Delta_{\mathbf{x},\tilde{x}} > 0$:$
  $\begin{cases} \psi(y, x_1, \dots, x_s) = 1, & \text{for some } \tilde{y}$ independent of $\tilde{y}$ \ \psi(y, x_1, \dots, x_s) = 0, & \quad y \neq \tilde{y}. \end{cases} \quad (289)$

We can decompose Equation 287 as

```
$$\tilde{\psi}^{\dagger}(y) = \delta_{y,y}B(0) + \sum_{k=1}^s B(k) \sum_{\substack{x \in S \ \Delta_{x,\tilde{x}}=k}} \psi(y, x). \quad (290)$
```

ANNEALED AVERAGE $\psi$ is a random quantity and we want to compute the average message $\langle\tilde{\psi}(y)\rangle$ over the possible realizations of $\psi$. We can decompose the selection of rules in two steps: selecting the set of $mv-1$ sequences $[\mathbf{x}, \mathbf{x} \neq \tilde{\mathbf{x}}]$ and associating the $\psi$ higher-level features $y$ to them.
