## F.5 SCALING ARGUMENT FOR THE MEMORIZATION TIME OF KERNEL METHODS

In this section, we analyze the training time $\tau_{mem}$ required for a kernel to learn the score of $P$ well-separated training points in the low-noise limit for a fixed noise level. This timescale corresponds to the one for diffusion models to memorize the training data.

SETTING We assume the empirical distribution is the Gaussian mixture

```
$$\rho_\sigma(x) = \frac{1}{P} \sum_{i=1}^P \mathcal{N}(x|x_i, \sigma^2 I_d) (408)
```

where the $x_i \in R^d$ are distinct training points. We work in a low-noise limit, where the noise standard deviation $\sigma$ is much smaller than the typical distance between data points, i.e., $\sigma \ll \min_{i\neq j}||x_i - x_j||$. This ensures that the Gaussian components have negligible overlap, so $\rho_\sigma$ is approximately supported on $P$ distinct neighbors.

We consider learning the score $\nabla \log\rho_\sigma(x)$ at fixed $\sigma$ with kernel regression. The dynamics of learning is governed by the spectral properties of the integral operator of the kernel $K$, defined as

```
$(Kf)(x) = \int K(x,y)f(y)d\rho_\sigma(y)$ (409)
```

with respect to the measure $p_\sigma$. The learning for a specific mode (eigenfunction) of the data scales inversely with the corresponding eigenvalue of this operator.

LOCAL EIGENFUNCTIONS In the low-noise limit, the score in the vicinity of a data point $x_i$ is dominated by the $i$-th Gaussian component:

```
\nabla_x \log p_e(x) \approx \nabla_x \log \left[ \frac{1}{P} \mathcal{N}(x|x_i, \sigma^2 I_d) \right] = \frac{x-x_i}{\sigma^2}. \quad (410)
```

This shows that the target function is linear and moves our ansatz of approximate eigenfunctions to probe the spectrum of $K$. In particular, we construct a set of vector-valued functions $\{\psi_i\}_{i\in[P]}$ centered at each data point $x_i$;

```
\psi_i(x) \equiv (x-x_i) R \left( \frac{\|x-x_i|}{\sigma} \right), \quad (411)
```

where $R : 0 \to \infty$ is a smooth cutoff function (e.g., $R(r)=e^{-r}$) that decays rapidly for $r \geq 1$. The support of $\psi_i$ is thus concentrated in the ball $B_d(x_i)$. These functions are asymptotically orthogonal $\langle\psi_i, \psi_j\rangle_{L_2(p_e)}=O(e^{-c})$ for $i \neq j$.

EIGENVALUES AND MEMORIZATION TIME We compute the eigenvalue $\lambda_i$ associated with each $\psi_i$:

```
\lambda_i = \frac{\langle\psi_i, K\psi_i\rangle_{L_2(p_e)}}{\|\psi_i\|^2_{L_2(p_e)}} \quad (412)
```

The squared norm is dominated by the integral over the $i$-th component of the mixture:

```
\|\psi_i\|^2_{L_2(p_e)} = \int |\psi_i(x)|^2 p_e(x) d^d x \simeq \frac{1}{P} \int \|x-x_i\|^2 R^2 \left( \frac{\|x-x_i|}{\sigma} \right) \mathcal{N}(x|x_i, \sigma^2 I_d) d^d x \quad (413)
```

Changing to local coordinates $u = \frac{x-x_i}{\sigma}$:

```
\|\psi_i\|^2_{L_2(p_e)} \simeq \frac{\sigma^2}{P} \int \|u\|^2 R^2(\|u\|) \mathcal{N}(u|0, I_d) d^d u \simeq \frac{\sigma^2}{P}, \quad (414)
```

where the proportionality constant depends only on $d$ and the choice of $R$. The numerator is given by the quadratic form

```
\langle\psi_i, K\psi_i\rangle_{L_2(p_e)} = \iint \psi_i(x) \cdot \psi_i(y) K(x,y) p_e(x) p_e(y) d^d x d^d y. \quad (415)
```

Given the localized support of $\psi_i$ and the non-overlapping assumption for the Gaussians, the integral is non-negligible when both $x$ and $y$ are near:

```
\langle\psi_i, K\psi_i\rangle_{L_2(p_e)} \simeq \frac{1}{P^2} \iint \psi_i(x) \cdot \psi_i(y) K(x,y) \mathcal{N}(x|x_i, \sigma^2 I_d) \mathcal{N}(y|x_i, \sigma^2 I_d) d^d x d^dy.
```

## F.5 SCALING FOR THE MEMORIZATION OF KERNEL METHODS

We now substitute the expansion of the kernel near the origin:

```
\langle\psi_i, K\psi_i\rangle_{L_2(\rho)} \simeq \frac{1}{\rho^2} \int \psi_i(x)\mathcal{N}(x, \sigma^2 I_d) d^d x - \int \psi_i(y)\mathcal{N}(y, \sigma^2 I_d) d^d y \\
+ \frac{C}{\rho^2} \iint \psi_i(x) \cdot \psi_i(y) |x-y|^{\sigma} \mathcal{N}(x, y, \sigma^2 I_d) d^d x d^dy. \quad (416)
```

The first term vanishes because $\mathcal{N}(x_c, \sigma^2 I_d)$ is an odd function with respect to the center $x_c$. The integral is zero. The leading contributions come from the second term. We again change variables to $u = (x - x_c)/\sigma$ and $v = (y - x_c)/\sigma$ obtaining

```
\langle\psi_i, K\psi_i\rangle_{L_2(\rho)} \simeq \frac{1}{\rho^2} \iint uR(\|u\|) \cdot vR(\|v\|)^{\sigma} \|u-v\|^{\sigma} \mathcal{N}(u|0, I_d) \mathcal{N}(v|0, I_d) d^du d^dv. \quad (418)
```

Collecting the powers of $\sigma$ we find:

```
\lambda_i \simeq \frac{\sigma^{2+v}}{\rho^2}. \quad (419)
```

The remaining double integral is a dimensionless constant. Combining the numerator and denominator, we obtain the eigenvalue scaling:

```
\lambda_i \simeq \frac{\sigma^{2+v}/P^2}{\sigma^2/P} = \frac{\sigma^v}{P}. \quad (420)
```

The training time required to learn these localized eigenfunctions as the inverse of the eigenvalue. This defines the memorization timescale

```
\tau_{mem} \sim \lambda_i^{-1} \sim \frac{P}{\sigma^v}. \quad (421)
```

This argument extends from contemporaneous work on random features in the proportional regime (number of neurons proportional to the input dimension) [Bon25] to any isotropic kernels. Our derivation relies only on the local behavior of the kernel and shows that random features and neural networks in the NTK limit exhibit distinct behaviors.

NUMERICAL EXPERIMENTS We confirm our theoretical scaling numerically in Figure 70 for a one-hidden layer fully-connected network in the lazy (NTK) regime [COB19]. Notably, the same experimental setting under a mean-field (feature learning) initialization [MMN18] also exhibits a memorization time consistent with our NTK-based prediction.
