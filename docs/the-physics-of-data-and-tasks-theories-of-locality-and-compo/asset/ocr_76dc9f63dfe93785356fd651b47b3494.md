# APPENDIX: THE ROLE OF DEPTH AND SPATIAL ADAPTIVITY

# B.1 HARMONIC ANALYSIS ON THE SPHERE

This appendix collects some introductory background on spherical harmonics and dot-product kernels on the sphere [SOWoo]. See [Efi14; AH12; Bac17] for a complete description. Spherical harmonics are homogeneous polynomials on the sphere $S^{d-1} = \{x \in \mathbb{R}^d \mid \|x\|=1\}$, with $\|cdot\|$ denoting the L2 norm. Given the polynomial degree $k \in \mathbb{N}$, there are $N_{k,d}$ linearly independent spherical harmonics of degree $k$ on $S^{d-1}$,

```
$N_{k,s} = \frac{2k+s-2}{k} \binom{s+k-3}{k-1}, \begin{cases} N_{0,d}=1 & \forall d, \ N_{k,d} \sim k^{d-2} \end{cases} \text{ for } k \gg 1. \quad (185)$
```

Thus, we can induce a set of $N_{k,s}$ spherical harmonics $Y_{k,f}$ for each $k$, with $f$ ranging in $1, \dots, N_{k,s}$ which are orthonormal with respect to the uniform measure on the sphere $d\tau(\mathbf{x})$,

```
$Y_{k,f}(\mathbf{x})Y_{k',f'}(\mathbf{x}) := \int_{S^{d-1}} d\tau(\mathbf{x})Y_{k,f}(\mathbf{x})Y_{k',f'}(\mathbf{x}) = \delta_{f,f'}. \quad (186)$
```

Because of the orthogonality of homogeneous polynomials with a different degree, the set $\{Y_{k,f}\}_{k,f}$ is a complete orthonormal basis for the space of square-integrable functions on the s-dimensional unit sphere. Furthermore, spherical harmonics are eigenfunctions of the Laplace-Beltrami operator $\Delta$, which is nothing but the restriction of the standard Laplace operator to $S^{d-1}$.

```
$\Delta Y_{k,f} = -k(k+s-2)Y_{k,f}. \quad (187)$
```

The Laplace-Beltrami operator $\Delta$ can also be used to characterize the differentiability of functions $f$ on the sphere via the L2 norm of power of $\Delta$ to $f$.\nBy fixing a direction $y$ in $S^{d-1}$ one can select, for each $k$, the only spherical harmonic of degree $k$ which is invariant for rotations that leave $y$ unchanged. This particular spherical harmonic is, in fact, a function of $x^T y$ and it is the Legendre polynomial of degree $k$, $P_{k,s}(\mathbf{x}^T y)$ (also referred to as Gegenbauer polynomial). Legendre polynomials can be written as a combination of the orthonormal spherical harmonics $Y_{k,f}$ [AH12].

```
$P_{k,s}(\mathbf{x}^T \mathbf{y}) = \frac{1}{N_{k,s}} \sum_{ff=1}^{N_{k,s}} Y_{k,f}(\mathbf{x})Y_{k,f}(\mathbf{y}). \quad (188)$
```
