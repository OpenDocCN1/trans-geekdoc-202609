e-PROCESS In process, instead of running a forward diffusion process, we act directly on the leaves. We introduce a noise signal ratio $\epsilon \in [0,1]$, which controls the noise level instead of the diffusion time $t$. Starting from a datum $x_0$, whose $i$-th token has value $\bar{a} \in \mathcal{V}^{(0)}$, the prior beliefs at the leaf $i$ taking values in $\mathcal{V}^{(0)}$ are defined

```
$v_{\iota}(h_i^{(0)} = \bar{a}) = 1 - \epsilon + \epsilon/v, \quad \text{for } x_{0,j} = \bar{a};
$v_{\iota}(h_i^{(0)} = a) = \epsilon/v, \quad \forall a \in \mathcal{V}^{(0)} \setminus \bar{a}.$ (342)
```

The role of $\epsilon$ is to decrease the prior belief on the starting value of a token. This process can be interpreted as an averaged forward process, where the average is made over different forward trajectories. In the example of masking diffusion (Equation 341), calling $1-\alpha_t$ the probability of a token being masked at time $t$, the prior beliefs at the leaves

```
$v_{\iota}(h_i^{(0)} = \bar{a}) = \alpha_t + \frac{1-\alpha_t}{v}, \quad \text{where } x_{0,j} = \bar{a};
$v_{\iota}(h_i^{(0)} = a) = \frac{1-\alpha_t}{v}, \quad \forall a \in \mathcal{V}^{(0)} \setminus \bar{a}.$ (343)
```

which have the same functional form as Equation 342 by identifying $\epsilon = 1-\alpha_t$. Both $\epsilon$ and $1-\alpha_t$ vary between 0 and 1 and play the role of noise-to-signal ratio in their respective processes. However, the fluctuations of the upward beliefs around their mean in the masking diffusion change the statistics of the BP messages propagating upwards and make the mapping $\epsilon = 1-\alpha_t$ inaccurate. In the example of Figure 12, the transition in the e-process is located at $\epsilon^* \approx 0.74$, while it is found that $1-\alpha_t = t'/T \approx 0.3$ for masking diffusion.

### D.1.1.3 BP sampling versus diffusion

BP SAMPLING As discussed at the end of section D.1.1.1, BP allows for sampling directly from the posterior probability $p(\hat{x}_0|x_t)$. Given a noisy observation $x_t$, and the corresponding marginal probabilities $p(h_i^{(t)}|x_t)$, the sampling proceeds as follows:

- root symbol $h_l^{(L)} = \hat{g}, \hat{g} \in \mathcal{V}^{(L)}$, is sampled according to the probability $p(h_l^{(L)}|x_t)$;
- the corresponding downward message is updated as $v_j(h_j^{(L)} = y) = \delta_{y,g}$;
- the probabilities of the production rules $y \to (a_1, \dots, a_s)$ form layer $L$ to layer $L-1$ are computed as

```
$p\left(y \to a_1, \dots, a_s | \mathbf{x}_i, h_j^{(L-1)} = \hat{g}\right)
\propto v_j^{(L)}\left(h_j^{(L)} = y\right) v_t^{(L-1)}(h_j^{(L-1)} = a_1) \dots \cdot v_t^{(L-1)}(h_j^{(L-1)} = a_s); (344)
```

- Notice the upward messages $v_j^{(L-1)} = a_j$ carry the information on the observation $\mathbf{x}_i$;
- a production rule $y \to (a_1, \dots, a_s)$ is sampled according to the probabilities of Equation 344. This gives the values $\hat{a}_j \in \mathcal{Y}^{(L-1)}$ of the latent nodes $h_j^{(L-1)}$. The corresponding downward messages are sampled as $v_j(h_j^{(L-1)} = \hat{a}) = \delta_{\hat{a},a_j}$;
- the probabilities of the production rules from layer $L$ to $L-2$ are computed as in Equation 344;
- the sampling process continuos up to the visible node $h_j^{(0)}$, giving a leaf configuration $\mathbf{x}_i$,
- the obtained sequence $\hat{\mathbf{x}}_i$ is a configuration of the RHM sampled from the posterior $p(\hat{\mathbf{x}}_i)$,

BACKWARD DIFFUSION WITH BP The BP sampling is equivalent to learning the backward dynamics with the true function of the RHM. In fact, given a noisy observation $\mathbf{x}_i$ at time $t$, the marginal probabilities $p(h_j^{(t)}|x_i)$ at the visible nodes can be used to compute the expectation $E(h_j^{(t)}|x_i)$. This expectation gives the score function $x_i$ at time $t$, which can be used in the backward dynamics to sample $x_{t-1}$ at time $t-1$, and so on.

Figure 5 compares BP sampling and backward diffusion with the exact score function in the case of masking diffusion. Both the average correlation functions and dynamical susceptibility at different masking fractions $t/T$ show the same behavior, independently of the sampling process.

Notice that the expectation values $p_{\ell}$ and $q_{\ell}$ depend on the layer $\ell$ and not on the specific position of the node $i$ inside the layer. Once $p_{\ell}$ and $q_{\ell}$ have been computed for every layer $\ell=0, \dots, L$, the average marginal probability of reconstructing the original value $\vec{a} \in \mathcal{Y}^{(\ell)}$ of the variable $h^{(\ell)}$ is given by

```
P(h^{(\ell)} = \bar{a}) = \frac{p_{\ell} q_{\ell}}{p_{\ell} q_{\ell} + (1-p_{\ell})(1-q_{\ell})} \quad (351)
```

This marginal probability is conditioned on the initialization of the leaf nodes (Equation 342) and only depends on the layer $\ell$, not on the position of the node inside the layer. Given the initialization of $q_L$, the probability of reconstructing the root node $P(h^{(L)} = \bar{a})$, is the class of the datum, is given by

```
P(h^{(L)} = \bar{a}) = p_L. \quad (352)
```

Therefore, in the limit of large depth $L \to \infty$, the value of $p_i$ is given by one of the fixed of the iterative map $F(p)$. When $F'(1) > 1$, $F(p)$ has two fixed points: $p=1$, which is repulsive, and $p=1/v$, which is attractive. This implies that, in this regime, for any noise $\epsilon >0$ at the leaf nodes, it is impossible to reconstruct the value better than random chance. When $F'(1) < 1$, the class is

```
\frac{v-1}{m} \frac{v}{v^s-1} < 1, (353)
```

a non-trivial fixed point $p^* = F(p^*)$ appears, which is repulsive, while both $p=1$ and $p=1/v$ are attractive.
