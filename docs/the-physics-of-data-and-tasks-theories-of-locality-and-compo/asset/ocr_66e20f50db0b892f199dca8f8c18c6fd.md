ii) Convolutional and local kernels from Equation 34 have non-lagging patches, i.e., $d$ is an integer multiple of $s$ and

```
$$\mathcal{P} = [1 + n \times s | n = 1, \dots, d/s] \quad (36)$
```

with $|mathcal{P}|=d/s$;

iii) The $s$-dimensional marginals on the $d$-dimensional input measure $p^{(d)}(d^4x)$ are all identical and equal to $p^{(s)}(d'x)$.

The part of assumption $i)$ regarding the eigenfunctions' properties is satisfied, for example, when the constituent kernel $C$ is isotropic and data are distributed over a $d$-dimensional torus. The request of nonoverlapping patches in assumption $ii)$ can be relaxed at the price of further assumptions, i.e., $C(x,y)=c(x-y)$ and data distributed over the torus, so that $C$ is diagonalized in Fourier space (details in Section A.3).

# Lemma 2.3.3 (Spectra of convolutional kernels). Let $K^{CN}$ be a convolutional kernel with constituent kernel $C$ satisfying assumptions $i)$, $ii)$ and $iii)$. $K^{CN}$ has the following Mercer's decomposition,

```
$K^{CN}(x,y) = \sum_{p=1}^{\infty} \Lambda_p \Phi_p(x)\Phi_p(y), \quad (37)$
```

with eigenvalues and eigenfunctions

```
$$\Lambda_1 = \lambda_1, \Phi_1(x)=1; \Lambda_p = \frac{S}{d}\lambda_p, \Phi_p(x) = \sqrt{\frac{S}{d}}\sum_{i\in\mathcal{P}} \Phi_p(x_i)$ for $\rho > 1. \quad (38)$
```

# Lemma 2.3.4 (Spectra of local kernels). Let $K^{LC}$ be a local kernel with constituent kernel $C$ satisfying assumptions $i)$, $ii)$ and $iii)$ above. Then $K^{LC}$ has the following Mercer's decomposition,

```
$$K^{LC}(x,y) = \Lambda_1\Phi_1(x)\Phi_1(y) + \sum_{\rho=1}^{\infty} \Lambda_{\rho}\Phi_{\rho,i}(x)\Phi_{\rho,j}(y), \quad (39)$
```

with eigenvalues and eigenfunctions $(\forall i\in\mathcal{P}$)

```
$$\Lambda_1 = \lambda_1, \Phi_1(x)=1; \Lambda_p = \frac{S}{d}\lambda_p, \Phi_p(x) = \Phi_p(x)$ for $\rho > 1. \quad (40)$
```

We refer the reader to Section A.3 for the proof of the lemmas and the generalization to kernels with overlapping patches.
