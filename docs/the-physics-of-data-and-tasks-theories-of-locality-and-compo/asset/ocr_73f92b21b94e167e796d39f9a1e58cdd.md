# 2.6 ASYMPOTICS OF LEARNING CURVES WITH RIDGE

$D_T(\Lambda)$ counts eigenvalues for which the target has a non-zero variance, such that:

```
$$\mathbb{E}_\rho[|c_\rho|^2] = \int c^2(\Lambda)D_T(\Lambda)d\Lambda,$$ \(47)$
```

where the function $c(\Lambda)$ is defined by $c^2(\Lambda_\rho) = \mathbb{E}[|c_\rho|^2]$ for all $\rho$ such that $\mathbb{E}[|c_\rho|^2] > 0$. The following then follows from the results of Jacot et al. [Jac20b].

**Theorem 2.6.1.** *Let us consider a positive-definite kernel $K$ with eigenvalues $\Lambda_\rho \to \infty$, $\Phi_P$ learning a (random) target function $f^n$ in kernel ridge (Equation 21) with ridge $\lambda$ from $P$ observations $f_i^* = f^*(x_i)$, with $x_i \in \mathbb{R}$ drawn from a certain probability distribution. Let us denote by $D_T(\Lambda)$ the reduced density of kernel eigenvalues with respect to the target and $(\lambda, P)$, the generalization error, and also assume that*

+   i) For any $p$ of indices $\rho_1, \dots, \rho_p$, the vector $(\Phi_P(x_1), \dots, \Phi_P(x_p))$ is a Gaussian random vector;

+   ii) The target function in the kernel basis with coefficients $c_\rho$ and $c^2(\Lambda_\rho) = \mathbb{E}[|c_\rho|^2]$, with $D_T(\Lambda) \sim \Lambda^{-(1+r)}$, $c^2(\Lambda) \sim \Lambda^q$ asymptotically for small $\Lambda$ and $r < q < r+2$;

Then the following equivalence holds in the limit $P \to \infty$ and $\lambda \to 0$ with $1/\sqrt{\lambda} \to 0$:

```
$$\mathcal(\lambda, P) \sim \sum_{\rho: \Lambda_\rho < \lambda} \mathbb{E}[|c_\rho|^2] = \int c^2(\Lambda)D_T(\Lambda)d\Lambda,$$ \(48)$
```

It is important to note that assumption $i)$ — requiring Gaussianity of the eigenbasis — is not strictly satisfied in our setting where the eigenfunctions $\Phi_P^*$ are plane waves. Nonetheless, the random variables $\Phi_P^*(x,)$ have a probability distribution with compact support. It is natural to assume that a Gaussian universality holds, i.e., that Theorem 2.6.1 applies to our problem. With this assumption, we obtain the following

**Corollary 2.6.1.1.** *Performing kernel ridge regression in a teacher-student scenario with smoothness exponents $\alpha_t$ (teacher) and $\alpha_s$ (student), with ridge $\lambda \sim P^{-\gamma}$ and $0 < \gamma < 1/2$, under the joint hypotheses of **Theorem 2.4.1** and **Theorem 2.6.1**, the exponent governing the asymptotic scaling of the generalization error with $P$ is given by:

```
$$\beta = \frac{\gamma \alpha_t}{\alpha_s + s},$ \(49)$
```

which does not vanish in the limit $d \to \infty$. Furthermore, Equation 499 depends on $s$ and not on $f$ as the prediction of Equation 42.
