# THE ROLE OF DEPTH AND SPATIAL ADAPTIVITY

We call a function on $M^{S^{r-1}}$ localized if it is constant on at least 1 of the $p$ patches. In other words, localized functions only depend on some patches of the input. The neurons of the first hidden layer are examples of localized functions, as each of them depends on only $s$-dimensional patches (such the blue rectangle in Figure 2 for $s=3$).

In general, the receptive field of a neuron in the $l$-th hidden layer with $l > 1$ is a group of $\prod_{i=2}^l s_i$ adjacent patches (as the orange rectangle of Figure 2 for $l=2$, $s_2=2$ or the green rectangle for $l=3$, $s_3=2$), which we refer to as a match-patch. Due to the correspondence with the receptive fields, each match-patch is identified with one path on the convolutional skeleton: the path that connects the output node to the hidden neuron whose receptive field coincides with the mid-patch. If such hidden neuron belongs to the $l$-th layer, the path is specified by a tuple of $L-l+1$ indices, $i_{l+1 \dots L} := i_{l+1}, \dots i_L$, where each index indicates which branch to select when descending from the root to the neuron node. With this notation, $x_{i_{1 \dots l}}$ denotes one of the $p_l$ match-patches of size $\prod_{j=2}^l s_j$ in $S^{s^{l-1}}$, each match-patch has an *effective dimensionality* which is lower than its size,

```
$d_{eff}(l) := \dim(x_{i_{1 \dots l}}) = (s_l - 1)$,$\nd_{eff}(l) := \dim(x_{i_{1 \dots L}}) = (s_l-1)\prod_{j=l+1}^L s_j$,
```

for $l \in [2, \dots, L]$. Localized functions that depend on a specific metatch inherit the latter's effective dimensionality. In general, the effective dimensionality of a localized function $f$ coincides with that of the smallest match-patch that contains all the patches that $f$ depends on.

# 3.3 HIERARCHICAL KERNELS AND THEIR SPECTRA
