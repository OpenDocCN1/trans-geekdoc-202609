SCORE FUNCTION AT LOW NOISE We consider a smaller-scale regime t→0 where only the first token has been changed by noise, to some value x_1(t) uncorrelated with x_i(0). In this case, the function that the network has to learn is E[x_1(0)|x2(0)], proportional to the correlations of the first token with the remaining sequence of length d-1. Since these correlations are invariant under exchanges of synonyms [Cag+24], they correspond to the correlations of the x_1 token with the latents at all levels representing the rest of the sequence, i.e., E[x_1|x_2,h_2^{(1)},h_2^{(2)},...,h_2^{(s)}] (Figure 19 (bb)). This function depends on a sequence of length (s-1)L, much smaller than the dimension d=sL. Knowing the latent variables allows for a significant reduction of the problem dimensionality.
