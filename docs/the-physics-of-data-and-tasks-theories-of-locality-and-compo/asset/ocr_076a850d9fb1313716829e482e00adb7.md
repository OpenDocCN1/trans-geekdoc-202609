$\mathcal{K}^{(k)}$ denotes the partial derivative of order $k_1$ with respect to $t_1$, $k_2$ with respect to $t_2$ and so on on $k_p$ with respect to $t_p$. Notice that the function $(1-t_2^2)^{\xi_2/2}$ is proportional to the probability measure of the scalar product between two points sampled uniformly on the unit sphere [AH12].

```
$|S^{d-1}| = \int_{-1}^{1} dt (1-t^2)^{\frac{d-3}{2}} S^{d-2} \Rightarrow \frac{|S^{d-1}|}{|S^{d-2}|} \int_{-1}^{1} dt (1-t^2)^{\frac{d-3}{2}} = 1.\n(234)
```

This probability converges weakly to a Dirac mass $\delta(t)$ when $d \to \infty$. Recall, in addition, that $|S^{d-1}| = 2\pi^{d/2}/\Gamma(d/2)$, where $\Gamma$ denotes the Gamma function $\Gamma(x) = \int_0^{\infty} dx x^{x-1}e^{-x}$. Thus, choosing $k_i + (s-3)/2 = d/2$, one has

```
$\lim_{k_i \to \infty} \frac{\sqrt{\pi}}{\Gamma(k_i + \frac{s}{2})} (1-t^2)^{k_i + \frac{s}{2}} = \delta(t).\\n(235)
```

As a result, if $\mathcal{K}$ is infinitely differentiable, one has the equivalence in the limit where all $k_i$ are large,

```
$\Lambda_k \sim \prod_{i=1} \frac{|S^{d_i-2}|}{|S^{d_i-1}|} (t_i)^{k_i} \frac{\Gamma(\\frac{d_i-1}{2})}{\Gamma(k_i + \frac{s}{2})} \mathcal{K}^{(k)} (0),\\n(236)
```
