# 2.3 CONVOLUTIONAL AND LOCAL KERNELS

As the functions in Equation 20, $K_{FC}^{CNK}$ is written as a combination of a lower-dimensional kernel $K_{NTK}^{FC}$ acting on patches, and the dimensionality of the constituent kernel coincides with the filter size of the corresponding network.

**Lemma 2.3.2.** Call $K_{NTK}^{LC}$ the NTK of a locally-connected network function ([Definition 2.3.2](#)) with size $s$ acting on $d$-dimensional inputs. Then

```
$K_{NTK}^{LC}(x,y) = \frac{1}{|P|} \sum_{i \in P} K_{NTK}^{FC}(x, y_i). \quad (33)$
```

Following the general structure of Equation 32 and Equation 33, we define local ($K^{LC}$) and convolutional ($K^{CN}$) kernels as sums of lower-dimensional constituent kernels $C$,

```
$K^{CN}(x,y) = |P|^{-2} \sum_{i \in P} C(x, y_i), \quad (34a)$
```

```
$K^{LC}(x,y) = |P|^{-1} \sum_{i \in P} C(x, y_i). \quad (34b)$
```

These are characterized by the dimensionality of the constituent kernel $C$, or size $s$ (for the student, or $t$ for the teacher) and a smoothness exponent the nonanalytic behavior of the kernel at small distance, $C(x,y) \sim |x-y|^{-\alpha}$ (for the student, or $a_t$ for the teacher) plus analytic behavior played in Equation 20. A exponent controls the smoothness of these functions, if $\alpha \in \mathbb{N}$, then the constituent kernel $C$ is at least $n$ times differentiable.[SGW20].

For instance, the NTK of ReLU units $K_{NTK}^{FC}$, which has a cusp at the origin, $a_t=1$ [Gei+20a]. Moreover, in $H \infty$ limit, a network initialized with random weights converges to a Gaussian process ([Neaa96; Willey7; Lee+17; Nov+194]). The covariance of the kernel, for ReLU activations, has nonanalytic behavior with $a_t=3$ [C309b].
