## Technical implementation of the adaptive sorting strategies

The modeling difficulty and system complexity of adaptive product list sorting are more than for rule-based sorting but less than prognostic sorting. The adaptive model gained trust and acceptance from business stakeholders, since it could be easily explained to them.

The technical implementation requires a database and a server. For the solution it is required to track web, sales, and product data. Such data is transferred to an open-source enterprise search platform that is the engine powering the product service.
