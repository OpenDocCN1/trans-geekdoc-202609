## MPACK

MPack 是一种恶意软件，由名为 Dream Coders 的团队于 2006 年设计，该团队主要位于俄罗斯 (Lemos, 2007)。MPack 是一个漏洞利用工具包——一种旨在利用目标计算机上软件漏洞的恶意软件，最常见于 Web 浏览器。一旦漏洞被利用，漏洞利用工具包可以在受感染的计算机上下载更多恶意软件。MPack 是已知的第一个漏洞利用工具包实例 (Malwarebytes, 2016)。

尽管使用漏洞利用工具包是非法的，但它们常常被视为商业软件。这可能包括为客户提供技术支持和为漏洞利用工具包提供软件更新 (Malwarebytes, 2016)。MPack 就是这样做的。当它最初发布时，Dream Coders 以 500 至 1,000 美元的价格出售 MPack，购买附带 Dream Coders 提供的一年技术支持 (Lemos, 2007; Leyden, 2007)。

MPack 设计为安装在服务器上，然后利用连接到该服务器的 Web 浏览器中的漏洞。一种称为 iframe 的恶意代码用于将流量导向 MPack 服务器 (Lau, 2007; Leyden, 2007)。可以使用各种方法导致目标 Web 浏览器运行 iframe 代码，例如将代码包含在垃圾电子邮件中、将代码包含在拼写劫持网站中，或者入侵合法网站并将代码嵌入这些网站 (Lau, 2007)。在某些合法网站被入侵并嵌入 iframe 代码的实例中，托管在同一服务器上的其他网站也被该代码感染。这种情况发生在这些网站所在的服务器配置不当时 (Leyden, 2007)。一旦 Web 浏览器连接到安装了 MPack 的服务器，MPack 就会确定正在使用的 Web 浏览器类型，并部署相应的漏洞利用程序，从而使使用该浏览器的计算机受到攻击。一旦它被下载到计算机上 (Lau, 2007)。

MPack 似乎曾是网络犯罪分子使用的一种流行漏洞利用工具包。2010 年，一份报告发现，三分之二的在线恶意活动是通过使用漏洞利用工具包和其他工具包造成的。MPack 被发现是使用最广泛的工具包，所使用的工具包中有 48% 是 MPack。人们怀疑，网络犯罪分子能够轻松获取 MPack 等工具包，导致了报告发布时看到的网络犯罪增加 (Messmer, 2011)。截至 2019 年，漏洞利用工具包似乎仍然受到网络犯罪分子的欢迎 (Chebyshev et al., 2019)。但是，MPack 本身似乎不再像发布后头几年那样处于反病毒社区的前沿。

## NAKAMOTO, SATOSHI

中本聪是自称是加密货币比特币（第一种此类数字货币）匿名发明者的名字。中本聪于 2008 年发表了解释比特币系统的原始文档。比特币是一种数字货币，没有实际可持有的实体货币。中本聪发明比特币，实际上是发明了一种使像比特币这样的加密货币能够存在的系统。具体来说，是使用区块链——通过密码学相互关联的去中心化公共数据条目字符串——来跟踪货币交易的系统，使比特币成为可能。比特币通过一种称为挖矿的过程生成——验证区块链中的交易。挖矿者会因挖矿而获得比特币奖励。这样一来，越多人使用这种加密货币，比特币就越普及和确立。中本聪构思出这个系统后，要让比特币运行起来只需开始进行比特币交易。第一批比特币在第二年转移，从中本聪转给 Hal Finney (Bitcoin, 2018)。

中本聪非常谨慎地保护自己的匿名性。他在 2011 年淡出公众视野，就在与比特币分道扬镳后不久。中本聪从未透露过他的现实世界身份，关于中本聪的真实身份一直有许多猜测 (Chen, 2016)。中本聪这个名字源自日语，但考虑到中本聪在线上交流中能说一口流利的英语，许多人怀疑他并非日本人。此外，他在通信和比特币源代码注释中使用某些单词的英式拼写，导致人们认为中本聪是英国人。然而，瑞士程序员 Stefan Thomas（活跃于比特币社区）整理的其他证据表明，中本聪可能居住在美国东海岸。Stefan 跟踪了中本聪在比特币论坛上所有帖子的时间戳，发现中本聪几乎从不在（美国东海岸的）夜间（大约午夜到凌晨 6:00）发帖，这导致人们相信中本聪之所以在那些时段不发帖，是因为他住在东海岸并且正在睡觉 (Wallace, 2011)。

即使那些曾与中本聪密切合作开发比特币的人也未能了解他的真实身份。Laszlo Hanyecz 就是其中之一。Hanyecz 或许最出名的是第一个使用比特币进行现实世界购物的人——从 Papa John's 购买了两份披萨。Hanyecz 在开发比特币期间定期通过电子邮件与中本聪通信——帮助调试比特币代码等等。尽管经常通信，中本聪从未向 Hanyecz 透露个人信息。Hanyecz 表示，他与中本聪的许多通信感觉很奇怪 (Bernard, 2018b)，并认为有时感觉中本聪并非一个单人 (Wallace, 2011)。其他人也推测，中本聪实际上可能是一群人的化名 (L. S., 2015; Wallace, 2011)。

曾有几个人被猜测是中本聪。《新闻周刊》声称在 2014 年找到了中本聪。一名名为 Dorian Prentice Satoshi Nakamoto 的男子居住在加利福尼亚州天普市，是一名物理学家，过去曾为美国军方进行过机密工作。根据《新闻周刊》的报道，当被问及比特币时，中本聪说：“我已不再参与那件事，也无法讨论它。它已经移交给了其他人。现在由他们负责。我已不再与之有任何关联。”

中本聪否认自己是创建比特币的中本聪 (Goodman, 2014)。许多人声称 Nick Szabo——一位密码学家，也是 1990 年代加密货币 bit gold 的创建者——才是真正的中本聪。Szabo 也否认了这些说法 (Bernard, 2018a; L. S., 2015)。Hal Finney——中本聪转账给的第一批比特币的接收者——也被许多人声称是中本聪。与其他人一样，Finney 否认了这一点 (Greenberg, 2014)。有一个人确实声称自己是中本聪——一位名叫 Craig Wright 的澳大利亚商人。Wright 于 2016 年提出这一主张，并表示他将用能够访问早期比特币密钥的证据来支持自己的主张。然而，他最终没有提供这份证据，声称自己缺乏勇气在声称自己是中本聪后，面对所受到的关注——从加密货币社区的怀疑论者到联邦调查局——而披露证据 (Bernard, 2018a)。

虽然调查中本聪的身份对某些人来说可能只是一种消遣，但有人认为，知道中本聪的真实身份对比特币的存在是有益的。比特币开发者之间已经出现（并可能将来会出现）关于如何处理这种加密货币新出现的问题（例如应对不断增长的用户基础）的争议。让比特币的实际创建者参与这些辩论，可能会提供一个最终的解决方案 (Chen, 2016)。比特币本身则持相反观点，指出知道中本聪的身份“可能与知道发明纸张的人的身份一样，与今日无关” (Bitcoin, 2018)。

中本聪参与比特币直到 2010 年，当时他与该公司分道扬镳 (Bitcoin, 2018)。此后，鲜有关于他的消息。与中本聪的真实身份一样，他离开比特币的原因也不清楚。在 2011 年 4 月 23 日中本聪最后已知的一次通信中，他回复比特币开发者 Mike Hearn 关于未来参与比特币的询问时在一封电子邮件中写道：“我已经去做其他事情了。它在可靠的人手中……” (Bernard, 2018a; Pearson, 2017)。尽管中本聪确实与比特币分道扬镳，但在离开后他仍保留了大量比特币。据估计，中本聪持有 980,000 枚比特币，按照 2017 年底左右的比特币价值计算，价值超过 170 亿美元 (Schroeder, 2017)。
