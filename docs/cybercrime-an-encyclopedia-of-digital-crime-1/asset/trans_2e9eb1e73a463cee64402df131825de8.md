微软向用户发布了一个补丁，用户可以下载该补丁以保护他们的计算机免受Code Red II蠕虫的攻击，但该补丁在病毒广为人知之前五周就已发布。这意味着许多人没有认识到紧迫性，也没有应用该补丁（Sans Institute，2001a）。许多人在Code Red 2发布之前能够安装一些防病毒软件。大多数人能够通过重启系统来删除第一波Code Red，这从计算机内存中删除了蠕虫，但删除第二个Code Red要困难得多。第二个蠕虫被设计得更加隐蔽，使其更难以检测和删除。那些感染了Code Red 2的计算机必须重新格式化，这将删除整个恶意软件程序以及后门。

Code Red蠕虫的创建者不明。许多人认为它是中国黑客的产物。另一些人则认为该蠕虫源于当年DEF CON大会的黑客。大多数人都同意这是一个编写良好、复杂的蠕虫，因此作者必须是具有计算机背景的人。最终，据估计Code Red病毒的成本为26亿美元，生产力损失达15亿美元。

## 全面国家网络安全倡议

全面国家网络安全倡议是一项加强美国应对网络事件响应的计划。该计划由乔治·W·布什总统在2008年1月宣布的《国家安全总统指令54/国土安全部总统指令23》中启动。这些文件旨在提高国家对网络威胁的网络安全水平。

2015年，奥巴马总统将恶意网络活动对国家和经济安全造成的“严重风险”描述出来（Obama，2015）。他下令审查现有的联邦网络安全政策，以保护国家基础设施。他要求制定一项全面的计划来提高国家的网络安全水平。为此，他成立了网络空间政策审查委员会，该委员会将对国家网络安全政策进行60天的审查。他们被指示与州和地方政府以及私营部门的所有关键参与者密切合作，制定一项针对美国网络安全的新的、更全面的计划。他明确表示，该计划需要保护所有人民的个人权利和公民自由。

委员会确定了三个目标。包括：

- 1. 建立针对当前紧迫威胁的第一道防线
- 2. 防御全方位威胁
- 3. 加强未来的网络安全环境

由此产生的计划是全面国家网络安全倡议。该计划围绕12项措施展开：

- 1. 将联邦企业网络作为单一网络企业进行管理，并采用可信互联连接：可信互联连接是一项整合互联网外部接入点的计划。这将提高安全性。
- 2. 在联邦企业范围内部署传感器入侵检测系统：这将有助于识别试图访问联邦计算机网络的未授权用户。这是爱因斯坦2（Einstein 2）计划的一部分，该计划由美国联邦政府使用，用于监控计算机流量并检测恶意活动。
- 3. 推动在联邦机构间部署防止入侵的系统：爱因斯坦将用于识别恶意程序，以提高网络安全性。它可以检测网络威胁并在其造成危害之前做出响应。
- 4. 协调和重新定向研发工作：希望这能使研究活动更加协调，减少研究工作的重复，从而实现更具成本效益的研究。
- 5. 连接网络运营中心以增加沟通：通过促进跨机构协作，中心可以轻松共享针对联邦机构的潜在恶意活动数据，并在攻击发起前阻止它。
- 6. 制定并实施全政府范围的网络反情报计划：需要一项计划来协调联邦机构在检测、威慑和减轻针对美国的网络威胁方面开展的所有活动。这需要包括加强网络情报教育和意识计划。
- 7. 提高机密网络的安全性。这些网络存储了关于外交问题、执法案件、国土安全行动和其他关键问题的高度敏感信息。这些网络需要防止网络犯罪分子的成功渗透。
- 8. 扩大网络安全教育：赋予人们执行新技术以防止网络犯罪发生的知识和技能至关重要。现有项目缺乏统一性和重点，因此需要网络安全专家来教授这些技能。该国需要培养一支技术熟练且精通网络安全的劳动力。
- 9. 定义并开发“领先一代”的技术和项目：开发超越当前系统的网络安全技术很重要。这样，它可以在5到10年后部署。
- 10. 定义并开发持久威慑策略和项目：规划者必须考虑网络安全的长期解决方案，而不仅仅是传统方法。
- 11. 制定全球供应链风险管理的多管齐下的方法：网络犯罪分子通过影响供应链来获得未经授权的数据访问权限，从而损害美国的机会增加。新政策必须反映当前存在的全球市场和复杂关系。
- 12. 定义联邦政府在将网络安全扩展到关键基础设施领域中的作用：许多关键基础设施由私人个人运营，他们依赖于易受网络攻击的系统的高效运行。联邦政府与关键基础设施运营商之间必须保持持续关系，以共享信息并预防犯罪。

犹他州数据中心（情报界全面国家网络安全倡议数据中心的简称）建立的目的是支持全面国家网络安全倡议。该中心于2014年建成，作为该倡议下收集数据的存储设施，包括有关电子邮件、电话通话以及美国公民互联网搜索相关数据的信息等。该设施是一个高度安全的综合体，旨在为国土安全部（DHS）员工提供技术援助。他们还负责收集有关网络威胁的情报。

国家安全局（NSA）负责监督那里的数据收集和存储。那些声称NSA对个人在线行为进行数据挖掘并“过度收集”个人信息的人认为这具有争议。他们指出，在9/11恐怖袭击后，个人数据收集和监控变得更加容易，有些人认为这违宪且非法。另一方面，支持者认为数据收集可以帮助防止未来的恐怖主义行为，包括网络犯罪。
