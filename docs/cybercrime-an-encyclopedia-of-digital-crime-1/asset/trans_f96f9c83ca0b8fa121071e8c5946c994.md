## 分布式拒绝服务攻击（DDoS）

分布式拒绝服务攻击（DDoS）是指攻击者获得对他人计算机（称为僵尸机）的控制权，并利用这些计算机向特定网站发送重复消息，导致网站无法处理，通常会导致网站崩溃。美国计算机应急响应小组（CERT）将 DDoS 攻击定义为攻击者试图阻止服务的合法用户使用该服务。对于企业来说，这可能意味着重大收入损失。

过去曾使用过不同类型的 DDoS 攻击。一种是针对目标进行过载的攻击。另一种攻击针对网络中的缺陷，然后使目标系统不堪重负。第三种攻击是网络或数据库被大量呼叫淹没，有时每小时有数百甚至数千个呼叫。最终，所有类型的攻击最终目标都是让网站暂时离线。

发起 DDoS 攻击的一种常见方法是攻击者向公司员工发送一封看似来自合法或已知发件人的电子邮件，要求员工查看一个文件。然而，收件人不知情的是，电子邮件附件中包含恶意软件，该软件会自动上传一个程序，使网络犯罪分子能够控制收件人的计算机。然后网络犯罪分子可以访问收件人可以访问的所有文件。当犯罪分子以这种方式收集密码和信息时，这被称为“社会工程学”。

在某些情况下，网络犯罪分子会使用一个程序来查找易受攻击的计算机系统（即存在某种漏洞或弱点，或未维护安全补丁的系统），并下载一个程序，使新感染的计算机成为 DDoS 主控。这意味着攻击者能够使用此系统来识别其他易受攻击的计算机系统，将恶意软件上传到这些系统，并同样控制它们。

当网络犯罪分子通过社会工程学或其他任何方法控制了许多计算机时，攻击者被称为“僵尸网络主控”，网络犯罪分子控制的计算机被称为“僵尸机”或“僵尸网络”。然后，攻击者会使用僵尸机通过电子邮件将恶意软件传播到更多系统。一旦攻击者控制了足够多的计算机，他们就可以使用受感染的计算机发送超过系统处理能力的服务请求。这可能会压垮网络并使其离线，导致计算机或在线服务不可用。僵尸网络主控还可能让僵尸机（受感染的计算机）向目标计算机发送大量随机数据，耗尽受害者的带宽，或向某个地址发送数百封垃圾电子邮件。

DDoS 攻击可能会持续一段时间，因为受感染计算机的所有者通常不知道自己的计算机已被感染，并反过来被用来攻击他人。该机器将继续感染其他计算机，增加僵尸网络主控控制的计算机大军。

当僵尸网络主控能够使用多台（数百甚至数千台）计算机向目标系统发送洪水请求时，往往很难识别攻击源。由于攻击可能来自远方，罪犯的识别变得更加困难。因此，DDoS 攻击往往悬而未决，罪犯从未被抓获或惩罚。而且，由于攻击来自如此多的来源，防范攻击也变得困难。

僵尸网络目前可以在暗网购买，通常约需 100 美元。这是一种计算机恶意软件，可用于向他人发送大量垃圾电子邮件、从计算机窃取数据或信息，或对其他计算机发起 DDoS 攻击。暗网上出售多种不同类型的僵尸网络，使恶意软件可供几乎任何人使用，无论是个人还是团体。有了僵尸网络，如果个人或团体对某个组织不满，网站或网络可以被关闭。他们可能只是不同意所传递的政治信息并希望将其关闭，或者可能是出于某种原因寻求报复的前员工。

DDoS 攻击频繁发生。2007 年，爱沙尼亚移除一座苏联战争纪念碑后，愤怒的俄罗斯民族主义者选择对爱沙尼亚和格鲁吉亚的政府网站发起 DDoS 攻击，使它们离线。2010 年，黑客组织匿名者（Anonymous）在 PayPal、Visa 和 MasterCard 宣布不再处理支持维基解密的金融捐款后，对这些组织发起了攻击（Zetter，2016）。此次攻击导致这些网站离线约 8 小时，使公司损失数百万美元。

匿名者于 2012 年再次发动攻击，这次针对支持《制止网络盗版法案》（SOPA）的团体，包括美国司法部、联邦调查局、白宫、美国电影协会、美国唱片业协会、环球音乐集团和广播音乐公司。该组织能够使这些网站离线数小时。匿名者成员进一步敦促反对该立法的人允许匿名者使用他们的计算机作为机器人来扩大攻击。

2015 年除夕夜（2016 年 1 月），对英国广播公司（BBC）发起了一次 DDoS 攻击。此次攻击由新世界黑客组织（New World Hacking）策划，该组织同一天还攻击了唐纳德·特朗普的总统竞选网站。2016 年 4 月 1 日，匿名者对唐纳德·特朗普的总统竞选网站发起了另一次 DDoS 攻击。他们试图使其酒店连锁网站离线。黑客还攻击了民主党候选人希拉里·克林顿的网站。

2016 年晚些时候，Dyn 公司（一家管理大部分互联网域名系统（DNS）的公司）的服务器遭到 DDoS 攻击。此次攻击导致 Twitter、卫报、Netflix、CNN 等网站瘫痪。这次攻击不同寻常，因为它依赖于“物联网”设备，例如数码相机和 DVR 播放器（Woolf，2016）。

## 域名系统缓存投毒

DNS 缓存投毒是一种网络攻击，网络犯罪分子将互联网域的虚假地址发送到 DNS 响应系统中，并将其存储在缓存中。如果服务器接受虚假记录，则不正确的信息会被存储在缓存中。这意味着 DNS 系统已被“投毒”。任何将来请求 IP 地址的用户都将被重定向并发送到犯罪分子控制的虚假 IP 地址。用户被发送到的虚假网站看起来像是真实网站，但实际上是犯罪分子设立的虚假网站，用于窃取受害者的个人信息。

DNS 将域名与 IP 地址关联。它们有助于传输人们可读懂并理解的电子邮件和 URL，并将其转换为计算机可读取的数据。随着时间的推移，DNS 会创建一个缓存，即数据集合，允许将来请求数据的人更快地检索该信息。DNS 服务器会缓存来自其他 DNS 服务器的信息；这样，它可以使用已收集的信息，而无需重新收集。这使系统更加高效。网络犯罪分子依赖于一个漏洞
