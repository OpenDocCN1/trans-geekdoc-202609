## Industry 4.0

The term industrial revolution is defined as the process of changing from handcraft to machine manufacturing. The new industrial revolution is called Industry 4.0. In Industry 4.0, automation and information exchange in manufacturing industries use emerging trends such as Cyber-Physical System (CPS) (Gil et al., 2019), smart agriculture (Tyagi, Sumarga Kumar Sah, et al., 2020), Internet of Things (Lakhwani, Kamlesh, et al., 2020), Machine Learning (Hiran, Kamal Kant, et al., 2021), Cloud Computing, Artificial Intelligence, Blockchain technology, and many more.

When we talk about the first industrial revolution, it used steam engine power and mechanical installation. This was followed by electricity for mass manufacturing and assembly lines in the second industrial revolution. The third industrial revolution was led by electronic chips and information technology. Now Industry 4.0 is associated with CPS.

Industry 4.0 introduces new principles for manufacturing industries, including:

- Virtualization of assembly methods by connecting sensor-generated signals with virtual plants and recreation models.
- Expanded interoperability between assembly processes through expanded availability.
- Distributed and smart decision-making plans.
- Real-time data collection.

## Cyber-Physical Systems

Cyber-Physical systems integrate the words “Cyber” and “Physical”. The term cyber is used to describe a person or thing as part of a computer, and Physical refers to physical devices. Thus, Cyber-Physical devices combine cyber capabilities with physical capabilities.

Helen Gill first introduced the word Cyber-Physical Systems (CPS) in 2006 at the US National Science Foundation. The term CPS is older and related to embedded system design. Designing computerized control algorithms is more challenging due to their tight coupling with physical systems and the need to work properly in real-time systems. CPS is also related to advanced technologies such as Industry 4.0, IoT, Wireless Sensor Network (WSN) automation, and cloud computing (Hiran, K. K., et al., 2019). Autonomous automobile systems, health monitoring systems, smart agriculture systems, and robotics manufacturing are examples of CPS (Feeney et al., 2017).

## GENERAL REFERENCE ARCHITECTURE MODEL

In this section, a prototypical architecture model for Industry 4.0 and cyber-physical systems is presented. This architecture model can be used to develop strategic plans and evaluate other organizational strategies for manufacturing processes.

### Industry 4.0 Architectures

B. Chen and J. Wan introduce a layered global architecture for Industry 4.0, presented in Figure 2. The Industry 4.0 architecture uses mixed wired/wireless communication technologies. The layered architecture is composed of four layers, described as follows (Schweichhart et al., 2016):

- 1. Physical resource layer: This is the bottom layer that includes all the physical devices used in industry, such as robotic arms, automatic vehicles, sensors, and unmanned aerial vehicles (UAVs).

- 2. Network layer: The network layer operates above the physical resource layer and includes all types of networking devices used to transfer information between the physical resource layer and the cloud application layer. These networking devices include high-speed internet, i.e., 5G technology (Ordonez-Lucena et al., 2019).

- 3. Cloud application layer: The cloud application layer is used to improve the layer above it, i.e., the terminal layer, using data mining and analysis technology. This layer also shows the cloud services domain for controlling database services (Yeboah, T., et al., 2015).

- 4. Terminal layer: All advanced industrial services for improving manufacturing production and design are included in this layer.

### Cyber-Physical System Architecture

Al-Ali introduces a layered architecture for cyber-physical systems. This architecture is made up of 5 layers, namely: physical layer, network layer, data storage layer, process-analytic layer, and application layer.

- 1. Physical layer: The physical layer consists of all physical system components, including sensors, actuators, System on Chip (SoC), tracking devices (GPS and RFID), and microcontroller computing elements. Sensors capture all real-time data and send it to the cloud service for further processing.

- 2. Network layer: The network layer consists of all networking devices and protocols for communication with cloud services, including protocols such as Wireless Fidelity (IEEE 802.11), Worldwide Interoperability for Microwave Access (IEEE 802.16), General Packet Radio Service, and 5G technology. These protocols are differentiated according to their properties such as scalability, bandwidth, speed, reliability, latency, and security. Cyber-physical systems use these protocols in many applications, such as hydropower plant monitoring systems, health monitoring systems, smart agriculture, smart cities, driverless cars, and wind power plants.

- 3. Data storage layer: The physical layer collects a lot of data from physical objects, and this data may be stored in a cloud domain of CPS. The data storage layer consists of data management services in the cloud domain, such as Hadoop, and replicas of stored data are distributed across different slave machines managed by replica management techniques.

- 4. Processing and Analytic Layer: In this fourth layer, different simulation models process stored information using dimensional modeling algorithms. Machine learning approaches for supervised and unsupervised learning, including classification, clustering, and regression models, are implemented to predict the final output value (Mahrishi, Mehul, et al., 2020).

- 5. Application layer: The application layer consists of all consumer-level interfaces used in smart agriculture, green buildings, Intelligent Transportation Systems, health monitoring, and robotics.
