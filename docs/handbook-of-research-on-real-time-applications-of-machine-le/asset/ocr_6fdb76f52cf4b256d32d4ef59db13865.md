# PROPOSED SYSTEM

This method’s main stages are data collection, pre-processing, and detection via neural network. In general, accurate semi-automatic and automatic detection methods are required. As a result of these factors, a fully automatic segmentation system based on CNN is used.

# Data Collection

We acquired our data as MRI pictures because our method is primarily focused on the detection of brain tumors. The dataset obtained included 159 photos with tumors and 99 images without tumors.
