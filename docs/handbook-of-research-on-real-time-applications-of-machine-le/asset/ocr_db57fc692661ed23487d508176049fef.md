# Recommendation System

The recommender system is one of the crucial components of CluniacChain. This system uses a clustering algorithm to categorize hospitals into several clusters, which may then be selected based on several parameters described in Table 1.

Table 1. List of parameters for the CluniacChain Recommender System

| Sr No | Parameter | Description |
| :--- | :--- | :--- |
| 1 | Specialization | Specialization of the hospital |
| 2 | Location | Lat. Long. of the hospital /geo-tracking |
| 3 | Threshold Rating | Feedback from patients |
| 4 | Average cost of treatment | Median cost treatment for any procedure |
| 5 | Capacity | Availability of seats |
| 6 | Fatalities | Fatalities in hospital |
| 7 | Recovery rate | Average survival-to-discharge rate |
