# # Methodology

An encryption and decryption algorithm is proposed focusing on the security of sensor communication channel of CPS. The information received from the sensor nodes are communicated through wire or wireless network using radio signals, which controls the decisional strategy of CPS. So, these communications must be confidential. To achieve this, original message in sensor must be encrypted to cipher text using encryption algorithm before transmitting to the controller. The controller receives the cipher text and decrypts it to the original text using decryption algorithm and perform its necessary operations, then converts its decision as cipher text and send it to actuator. To perform this encryption and decryption algorithm is established in sensors, controllers and actuators to prepare the cipher text before communicating to other channels and to convert the cipher text as original message.

To strengthen the security, secret key is evolved from the edge labels of an odd-even congruence graph to recast the plain text to cypher text and vice versa. In the proposed communication all the data are transmitted as cipher text which cannot be read by the attackers.
