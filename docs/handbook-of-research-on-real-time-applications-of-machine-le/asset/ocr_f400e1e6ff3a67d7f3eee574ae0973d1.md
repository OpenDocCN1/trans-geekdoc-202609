# Accuracy Measurement

The smallest error number between actual data and anticipated data collected is used to calculate accuracy in the experiment—the less the error value, the better the value. MAE (Mean Absolute Error) is the 13th equation that we use.

```
\( MAE = \left(\frac{1}{N}\right) \sum_{i=1}^n |F_i - A_i| \) (13)
```
