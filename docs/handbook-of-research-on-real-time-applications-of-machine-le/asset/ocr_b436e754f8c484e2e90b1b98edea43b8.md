# CIDDS

The CIDDS dataset is introduced to present an anomaly-based detection evaluation dataset (Ring et al., 2017). The dataset is created in a simulated environment of a small business.

# DoHBRw'2020

The DoHBRw dataset (MontazeriShatoori et al., 2020) is the first attack dataset to the DNS system. The dataset focuses on DNS over HTTPS (DoH), introduced by IETF in RFC8484 which aims to enhance the privacy and protection of DNS.
