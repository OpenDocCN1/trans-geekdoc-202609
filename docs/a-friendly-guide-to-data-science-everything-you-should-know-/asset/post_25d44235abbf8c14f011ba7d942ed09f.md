Now, that split has yielded two sets that have only one label present, which means these can be nodes with the appropriate label. And now if we repeat this process on the right branch of the root node we have a decision tree trained that can be used to classify new emails that come in.

When using real data to build a decision tree, the splits are never perfect, and most leaves will have records with different labels. There are a lot of different ways to control the building of a tree, which is primarily why we can end up with misclassified records in training. In reality, we don't want the tree to get too deep, which is what would happen if we insisted on each leaf having only records with the same label. We'd also end up with leaves that have only one or very small number of records. Those situations are basically overfitting (we’ll talk about it below). So we impose some limitations, like max depth and minimum number of records required in a node to split it (once we get to a node that splitting would lead to too-small nodes, we'd call it a leaf).

## Random Forest

Regression trees are built similarly, but random forest is an ensemble of many trees. The main advantage of random forest is that the result won't be dominated only by the most impactful features—instead, different features can show up as important.

The two key components of random forest are bagging—taking random samples of the data (with replacement)—and taking random subsets of the features. This ensures that many trees aren't too similar or correlated with each other. Usually the number of features included is the square root of the total number of features. After all these trees are trained, the data is run through all of them, and the outputs are either determined by majority vote (in classification) or averaging (in regression).

The main disadvantage to random forest is the weak explainability. Generally, the best thing to do is to explain the decision tree approach so they can grasp that. Then you can explain that hundreds of these trees are trained on slightly different data, and the final label is determined by majority voting or averaging.
