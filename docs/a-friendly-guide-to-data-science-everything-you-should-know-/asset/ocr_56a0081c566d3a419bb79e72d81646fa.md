Wide-column stores are superficially similar to relational models because they also store data in tables and rows; however, columns aren't strictly defined at the table level and rows can have different columns. This allows benefits of relational structure without inflexibility. As you can see in Table 12-9, representing this basically looks like a sparse relational table, but under the hood the apparently “null” values are not part of the row at all.
