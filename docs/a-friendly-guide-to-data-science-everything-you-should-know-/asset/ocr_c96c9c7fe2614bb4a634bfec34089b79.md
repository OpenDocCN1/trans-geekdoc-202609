+   - Has a natural and meaningful order.

+   - There is a natural zero.

+   - Considered the most useful type for data science.

+   - Measures like average can be computed.

+   - Examples: Height, weight, distance between two points, number of textbooks you own, temperature on the Kelvin scale

# Data Transformations

The different data types can be used in different ways, and it’s common to transform data from one data type to another to make it easier to work with. This usually involves losing some information as we step down from the most restrictive type to one less restrictive—we can go from ratio to any other type, from interval to nominal or ordinal, and from ordinal to nominal, but not the other direction.
