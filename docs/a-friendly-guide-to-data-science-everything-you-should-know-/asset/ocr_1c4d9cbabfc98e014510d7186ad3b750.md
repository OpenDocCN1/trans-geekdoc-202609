# APPENDIX A SETTING UP YOUR COMPUTER TO DO DATA SCIENCE

Once installed, you'll need to add extensions for the languages you want to work in. You don't have to add everything now, but definitely add extensions for Python and/or R and the Jupyter ones. Start by clicking the extensions tab on the left bar. It looks like Figure A-1.

![](bbox=[0.447, 0.226, 0.552, 0.263])

# Figure A-1. The extensions tab icon

You'll have to search for the ones you want to install in the bar at the top. These are recommended:

+   * Python
* Python Debugger
* Jupyter
* R
* R Debugger

There's really reason not to install all of them even if you're sure you'll use them. But you can always wait. Additionally, there are many more Python-, Jupyter-, and R-related extensions you can also install if you want to try them out.
