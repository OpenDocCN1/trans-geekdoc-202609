# Ordinal Data

Ordinal data has a lot in common with nominal data, which is why they are both called qualitative or categorical. In the case of ordinal, you can think of it as nominal with one special trait: it has a natural order, where each value comes before or after each other value. We intuitively understand T-shirt size has a natural order that is clear from the value. These would be values like S, M, L, XL, and so on. So there is an order, but there is nothing numeric about these values, and there is no such a zero value in the ordering. There is also no mathematical relationship between the sizes or their relative order—that is, XL is not twice as large as L or even S. Shoe size and grade level in school are additional ordinals. Again, they are numbers, but they aren’t related by any mathematical rules.
