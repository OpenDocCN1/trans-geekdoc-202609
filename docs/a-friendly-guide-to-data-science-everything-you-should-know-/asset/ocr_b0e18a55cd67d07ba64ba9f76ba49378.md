# SCHEMA

The term schema is also used in the database world in a different way, to mean the overall logical structure of a database, often implying a visual representation of it. In most cases, it would include table names, table columns, and relationships between the tables. For non-relational databases, it would show different objects. It's very common for developers and data scientists to look at to understand how to work with data in a particular database.
