# CALCULATING MEASURES OF LOCATION

We'll start with a subset of our exam scores with the following ten data points:

+   67, 11, 93, 53, 79, 60, 74, 93, 99, 78

The first thing we'll want to do is put them in order:

+   11, 53, 60, 67, 78, 79, 74, 93, 99

We can see that the middle values are 78 and 79, and there's an intuitively clear outlier of 11.

We can calculate the *mean* by summing all values and dividing by the count, giving us 70.7

If we want to calculate a *trimmed mean*, we can get a 10% trimmed mean by taking off the top and bottom values (both 10% of the total values) to get 74.6.

The *median* is also easy to calculate here we observed above that the middle values are 78 and 79, making the median the mean of those two, or 78.5.

The *mode* is also easy to calculate here because we're working with a small number of whole numbers. The only number that appears more than once is 93, so that's the mode. If we'd had no repeats here, we wouldn't have a mode.

Data analysts and scientists rarely have any reason to calculate things manually because we use software or code, but it's important to understand what these labels truly mean.
