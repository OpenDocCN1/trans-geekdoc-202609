# McNem’s Chi-Squared Test

Another chi-squared style of test that relaxes the requirement for independence in the actual chi-squared test is McNemar’s test for matched pairs, which looks at paired-sample data to see whether a particular value of a variable changes between the two paired measurements. This test is especially useful when the observations are not independent because it’s looking at the changes within pairs. For instance, if a college requires allomores to take a seminar on social justice issues, they may want to measure students’ opinions on several issues change after they take the seminar. They’d measure this at the beginning of the class and then again when they are juniors to see if it changed their views long term. To get the statistic for each issue, they’d create a contingency table similar to the chi-squared test for independence, but the statistic is calculated differently.
