# Real-World Data

One of the points that came up in almost all the practitioner interviews I was the difference between the data people used in their analytics coursework and what's in the real world. The key difference is messiness. I've talked about it throughout, and real-world data truly is very, very messy. The 80–20 split on time spent doing data prep vs. modeling is not an exaggeration.

So why don't you experience this in your college courses? Well, to be honest, every analytics degree program should have at least one semester dedicated to learning to work with messy data, even though most don't. The main reason you don't learn it in other classes is that they're trying to teach you something specific, and to spend only 20% of your time making the data ready doesn't make a lot of sense. But it downplays the importance of data prep and gives you a false impression of what doing data science is really like.

So bear in mind that real data will have missing data, weird outliers, and values that are simply wrong for any number of reasons—none of which you will be able to identify easily. Or you'll have one table that you want to join to another table that has really valuable data, only to find that only a fraction of the records exist in both tables. There will be challenges. You've been warned.
