# CHAPTER 1 WORKING WITH NUMBERS: WHAT IS DATA, REALLY?

One example of data interval is a timestamp, which is just a specific date and time. It's very common for these to appear in data, to indicate when a row got added to the table. You can measure time between timestamps, but we aren't going to go back to the Big Bang to get a time of 0.
