The prize is considered to have advanced the machine learning field by having so many different techniques and approaches being compared directly on the same problem, a true apples-to-apples comparison.

One interesting thing about the situation is that Netflix had planned a second iteration of the prize, but instead ceased because they got sued over privacy concerns. Although the lawsuit was later dropped, it serves as a reminder about how it's almost impossible to truly anonymize any data that relates to people.
