# # Key Takeaways and Next Up

In this chapter we looked at the need to start data science if you want to make it a career. You will develop your skills effectively if you actually practice on real projects. It's also important in any modern career search that you have a portfolio so you can demonstrate your skills beyond talking about them. There are many ways you can start coding and doing data science, from using your own computer to finding an online platform that will let you code there, like Kaggle. Finally, there are so many sources for datasets that you can surely find something about that interests you.

In the next chapter, I'll be talking more about learning and developing your skills outside of doing data science directly. The best learning resources depend on what you want to learn and how you learn. There are a huge variety of options, including blogs, joining organizations, social media, in-person events, and more.
