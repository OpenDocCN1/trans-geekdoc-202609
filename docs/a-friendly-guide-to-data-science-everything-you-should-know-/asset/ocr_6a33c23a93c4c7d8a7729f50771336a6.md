One other common transformation that I'll talk about more in Chapter 14 is a technique for creating what are called dummy variables, where we split a categorical column into separate "dummy" columns that are all Boolean. Each column would be one of the possible values of the column, and each row would have a 1 for the column that matches the value and 0 in all of the new columns.
