# Text Files

Plain text files can be opened in editors like Microsoft's Notepad or Apple's TextEdit and still be readable. It's a common way to store data, the comma-separated value (CSV) format used all the time in the data world.

A CSV file is literally a text file that is formatted with a comma separator. If the text saved contains a comma, then double quotes are put around that particular field. If the text contains double quotes, an extra double quote is added in front of it. If the text contains double double quotes...well, you get the idea.
