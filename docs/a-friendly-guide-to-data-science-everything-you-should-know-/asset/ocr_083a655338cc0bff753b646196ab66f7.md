One last consideration when considering sample size is what the consequences of the work could be. If it's potentially damaging, it's usually good to go with the bigger sample to ensure better representation. This might apply if it's part of a study that would be used to write public health policy or involve a company making significant financial decisions. This plays into ethics, which we'll discuss in a later chapter.
