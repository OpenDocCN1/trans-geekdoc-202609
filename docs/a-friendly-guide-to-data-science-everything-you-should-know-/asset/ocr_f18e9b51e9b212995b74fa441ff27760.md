One more type of column chart worth mentioning is the 100% stacked column chart. This is the same as a stacked column chart, but instead of using the raw numbers, each of the numbers is represented as a percentage of the total for that point. Figure 18-16 shows a couple of charts similar to Figure 18-13, where we can see the raw counts of absences instead of the averages.
