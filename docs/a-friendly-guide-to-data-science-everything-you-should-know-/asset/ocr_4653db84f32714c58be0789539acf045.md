# Decision Trees

Decision trees are probably the most intuitive machine learning out. Linear regression is easily explainable, but it still requires thinking about math, which will make some stakeholders shut down. A decision tree can be drawn and be intuitively understood by anyone. A couple of other reasons it's so useful that it doesn't require the data to be linear and can handle categorical features.
