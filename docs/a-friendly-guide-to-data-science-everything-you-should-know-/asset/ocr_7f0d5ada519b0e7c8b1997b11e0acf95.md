# Interval Data

Interval data is the second numeric data type and has a lot in common with ratio data, with some limitations. Interval data doesn’t have a natural zero point, and the mathematical operations you can do on it are significantly limited because of this. For instance, temperature seems like it would be ratio because we have numbers and we can have a temperature of 0. But if you think about what on Fahrenheit and Celsius scales, those two values mean entirely different things, as a temperature of 0 doesn't mean there is zero heat, so you can't count it as a true zero. Because of this, you can't say 60 is twice as hot as 30, and summing temperatures would never make sense.

It's interesting to note that unlike Fahrenheit and Celsius values, temperatures on the Kelvin scale would work as ratio data because Kelvin means no heat, and the relationships between the different values do follow mathematical rules.

IQ data is another example of interval data, even though at first glance it might seem like ratio data. There are different IQ scales, that each have a scale that defines the consistent distance between the values. These distances are not arbitrary, unlike the distances between T-shirt sizes, which cannot be quantified without additional information. However, there is no meaningful 0, which means the mathematical operations break down.
