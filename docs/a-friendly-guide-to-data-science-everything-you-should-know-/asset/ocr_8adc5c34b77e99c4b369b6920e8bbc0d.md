We can even have more metadata about some of this metadata. For instance, we would likely store information about all the people on these lists—directors, artists, authors, etc.—such as their names, gender, and agents.

Note that metadata can be stored in the same table—data and metadata can exist together, as long as it makes sense in terms of reality. Some other common metadata you see in databases includes timestamps for when record was created, a timestamp for when it was modified, and the creator of the record. Note that not all timestamps are metadata.
