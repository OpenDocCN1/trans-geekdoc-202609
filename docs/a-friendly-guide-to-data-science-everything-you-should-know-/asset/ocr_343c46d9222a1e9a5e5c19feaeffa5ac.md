# Line Charts

One of the most common charts created when the data has a time element is the line chart. Although a line chart could be created with different types of data, it's really only suitable for numeric data, and there should be a natural way the data connects. Time is common on the X-axis and the numeric value on the Y-axis. There are different variations possible with line charts, and we'll look at with some pizza sales data.
