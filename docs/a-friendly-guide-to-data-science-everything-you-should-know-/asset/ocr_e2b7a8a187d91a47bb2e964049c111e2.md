The common way to install libraries is at the command line with the command conda (with Anaconda) or pip. Note that this is not within the Python interpreter itself, but rather at the system level. With Anaconda, you have an additional option. You can run the Anaconda Navigator GUI (available in all operating systems) and select libraries to install. Otherwise, use the Anaconda Prompt in Windows and the system terminal
