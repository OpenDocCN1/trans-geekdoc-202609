# Data Science Codes of Ethics and Oaths

Some of the early efforts at formalizing data science ethics involved the concept of an oath, inspired by the Hippocratic Oath that all doctors commit commit to following. Recently, several data science (and other) organizations have created oaths they recommend data scientists follow.

Like the Hippocratic Oath, an ethical data scientist would define the things that are important for all data scientists to do to ensure the work they are doing is ethical. It would amount to a “do no harm” promise.
