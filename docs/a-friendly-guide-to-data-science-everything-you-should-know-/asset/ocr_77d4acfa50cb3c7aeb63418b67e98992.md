Overfitting comes about for a lot of different reasons, including the curse of dimensionality (discussed below), where too many features can cause it. Models can also overfit because of particular traits or tendencies of algorithms. For instance, if you let a decision tree get too deep, it can seriously overfit because it tries to account for every single quirk of the training data. Random forest is less prone to this because not every data point is in every tree that is built (among the hundreds).
