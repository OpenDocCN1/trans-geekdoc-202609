So this category refers to both fully automated collection and semi-automated tracking. Fully automated is like what you see with weather and environmental sensors positioned around a large farm tracking environmental things and Google tracking everyone’s location through their phone. The main point here is that neither side of the data collection has to do anything special for the data to be recorded, except initial setup (connecting the sensors to a network or someone having the right app on their phone). This would also include things like click behavior tracking on a website (the user is simply using the website as they normally would).
