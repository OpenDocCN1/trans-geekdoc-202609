The AUC is literally the area of what appears under the ROC line. It’s included in the charts in Figure 16-2. When comparing different runs of a model on the same data, one with a higher AUC is considered better.

One more metric’s used in models is where there is a probability given for how likely that prediction is likely to be right. For instance, in logistic regression, we get a probability and usually take a cutoff—0.5, normally—and anything above that is labeled True and anything below False. There’s a metric called *log-loss* that works with that probability directly and calculates a score based on the difference between the probability and the actual value for each instance (the actual calculation involves some log values and can be looked up online). With this metric, we’re looking for low values.
