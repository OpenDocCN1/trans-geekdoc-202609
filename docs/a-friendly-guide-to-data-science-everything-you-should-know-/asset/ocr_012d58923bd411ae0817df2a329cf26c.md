Linear regression calculates this line by minimizing the sum of all the squared errors for each point. The error is the vertical distance from the line to the point, but in regression, this is usually referred to as a *residual*. There are different ways to calculate the overall error, but the traditional linear regression, *ordinary least squares regression*, uses what's called the *sum of squared error* (SSE), which is calculated by squaring each residual and then summing all of those squares. Note that we square it because we don't want too-high values to cancel out-low values, which would happen when summing. This approach is virtually impossible to do by hand because what it effectively does is try a bunch of different lines, calculate the sum of squared error, and then pick the line with the lowest sum.
