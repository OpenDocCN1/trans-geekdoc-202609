One thing's important in mathematical operations is the order of operations, which tells you which combinations of numbers and operators will run first. This is the same as in regular math, and parentheses can be used to force some things to be done first. It's common when handwriting math to include parentheses for instant clarity, but in code, parentheses are usually only used when necessary of the order of operations.
