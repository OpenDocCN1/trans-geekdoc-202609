# What We Need to Make Predictions

Sometimes new data scientists struggle with understanding what we need to provide to a trained model to get predictions. As mentioned, we need to have values for all the features that the model trained on. Let’s say we have a model designed to predict daily sales at a store. It’s February 1st and we have a model trained on the last three years of data, up through January 31st, and we want to forecast daily sales for the next seven days. We used a variety of features, including day of the week, month of the month, holidays, and several historical sales features. We have to have all of those features for the next seven days. Imagine a table with seven rows in and a column for each feature mentioned above. Some people are surprised that we need to have “future data”—but the model is based on the values for each day, so they’re required.

That means we need to be able to have those future values. Having features that are impossible to represent the future is a mistake newbies often make. For instance, if you have a feature “yesterday’s sales,” you’d have no problem training a model with that. But you couldn’t provide it when you’re getting your predictions, because you have no idea what “yesterday’s sales” would be for day 7, since we don’t have the values One way to deal with this is to use the forecast for day 6 as the “yesterday’s sales” value in the day 7 prediction, but this isn’t always the right solution because of the uncertainty.
