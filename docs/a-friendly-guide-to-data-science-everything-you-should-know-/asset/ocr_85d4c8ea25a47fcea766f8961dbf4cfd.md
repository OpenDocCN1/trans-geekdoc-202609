One difference in the process between data analysis and data science is in the exploratory analysis and modeling step, because data scientists usually spend more time here because they are doing more complicated work. Additionally, the work that's done in the validation and evaluation step is also likely to be different from that in a data analysis project, with more emphasis and time spent on code review, it's not restricted to that. Similarly, the visualization and presentation step may involve different types of outputs, depending on the project. But keeping this process in mind will help you understand and plan any data science project you work on.
