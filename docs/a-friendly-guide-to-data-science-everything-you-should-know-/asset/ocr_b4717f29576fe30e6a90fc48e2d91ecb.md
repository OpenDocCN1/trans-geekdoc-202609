**Figure 15-13.** A sample of the kids height dataset with blue representing boys and red girls given to k-NNs

If we give this dataset to k-NNs as our “training set,” this serves as our reference set. We set $k$, the number of neighbors to consider in classification, to 3 (a common value for this). Now, if we have two new points as seen in Figure 15-14, we can see how the classification works. The first new point is in purple in the upper left and the second in green in the upper middle. We can visually identify which three reference points are nearest to the purple point and green point, which are marked by black lines. In the case of the purple point, two of the three points are red and one is blue, so we would classify the purple point as red (female). The green point has four points fairly close, although the nearest is red, the next two are both blue, so this one would be classified as blue (male).
