# Data Science Programming

The defining thing in most data science and statistics programming is the data frame, the basic structure for storing tabular data both in R and with Pandas in Python. The data frame is actually a built-in data type in R, but in Python we have to use a package called Pandas, which gives us the R-like functionality.
