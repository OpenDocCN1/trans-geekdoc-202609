# Table 11-7. Example for loop code in Python and R

```
Python    for num in range(10):
            sq_num = num * num
            print("The square of " + num + " is " + sq_num)
nR        for (num in 0:9) {
            sq_num <- num * num
            print(paste("on the ", paste0(counter,
                "The square of ", num, " is ", sq_num, sep="")))
}
```
