# MORE ON MISSING DATA

If we had left the empty cells alone instead of putting a 0 in, it wouldn't have been obvious what to do. Empty doesn't necessarily mean 0—it usually means that it's unknown, which means it could actually be a number other than 0, just not recorded properly. It's important to remember that the data alone doesn't tell you what values mean, despite what "obvious" it can feel as a human. In database systems, empty values (called null) can really mess up calculations because they don't have the human intuition to know whether we should substitute a 0 or ignore the data point or do something else. In many cases, a sum of 100 and null will come out as null, because it is impossible for the database system to know what null means.
