There are several different main classes of NoSQL databases: document store, key-value store, wide-column store, and graph. Document stores hold semi-structured "documents," usually in JSON or XML format. They are very flexible and don't have to match each other, but they're not good for complex transactions. The database mentioned in the example, MongoDB, is a document store.
