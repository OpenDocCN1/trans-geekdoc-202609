# The t-Tests

t-tests are a family of classic statistical tests and excel at small sample sizes (generally less than 30). There are several different tests, which will be described below. All of these have some basic requirements, including the data is assumed to be normal. I'm not listing all of them, but if you are planning to use these tests, you'll need to ensure your data is suited to it.
