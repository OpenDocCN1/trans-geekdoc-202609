Most data professionals view spreadsheets like Excel as the bane of their existence because of many limitations and poor use. Additionally, spreadsheets are useless with big data—the most popular spreadsheet software, Excel, can't handle more than a million rows.

Excel is the most common spreadsheet program out there, but there are some others. There are packages in both Python and R to read Excel sheets. If a sheet is more than simple rows with a header across the top and data the rest of the way down (like if someone has put a title at the top and merged cells), it can still be read programmatically, but it's more difficult. Often if you end up with an irregular spreadsheet, it can be easier to copy and paste the relevant parts into a new file and save separately. In this situation, you might even be better off saving it as a comma-separated value (CSV) file, which we'll talk about below. This seems like a natural way to store data to a lot of spreadsheet users, but there are many issues with it.
