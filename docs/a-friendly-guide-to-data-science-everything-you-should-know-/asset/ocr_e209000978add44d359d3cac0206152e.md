# False Utility, Perpetuating Bias, Technochauvinism

Many people continue to believe that data and machine learning can't be unfair, denying the role that human and systemic biases have because they're built into the data and the systems we use. This attitude has been labeled technochauvinism by Meredith Brouyssard, encapsulating a belief that a technological solution will be the best. We have to remember that in actuality, any data science system is only as good as the data into it—something is done by humans.

This means that just because a data science system "performs well" doesn't mean it is without biases. When you train on past data, your "well-performing" system is simply going to reproduce the same decisions that have always been made, and if those are biased, the system will be, as well.
