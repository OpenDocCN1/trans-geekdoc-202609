# CHAPTER 16 HOW'D WE DO? MEASURING THE PERFORMANCE OF ML TECHNIQUES

The first thing to know about regression metrics is that there is no such thing as an accuracy metric for regression, as the accuracy metric is specific to classification. We sometimes talk about accuracy in regression, but we are using the word in its general sense, not as a specific technical term.

A common metric that pops up with generalized linear models is R-squared score. It's technically the goodness-of-fit measure—R-squared score says how well the generated model fits the data and how much of the variance in the target variable is explained by the features. With linear models, it effectively compares the actual regression line to the mean line, a horizontal line across the chart through the Y-axis at the value of the mean of all the Y values in the data, but it can also be used with some nonlinear models. In the linear case, a terrible model would have a line close to the mean and a very low R-squared score. R-squared can be good for different models created on the same data because it's considered relative. That means it's not as suited to comparison across different data.

One downside of R-squared is that it assumes that all the features are important to the model. Additionally, adding a feature tends to increase the R-squared, which can lead people to add more features than necessary and end up with an overfitted model. There's a modification of R-squared score that better handles features of differing value. Adjusted R-squared score looks at what each feature brings in terms of added value, and the score only increases if the features improve the model more than what chance would. Because of this improvement, adjusted R-squared is almost less than R-squared.

There are several metrics often used in lieu of R-squared and adjusted R-squared because they aren't always the best for determining model performance on the test set.
