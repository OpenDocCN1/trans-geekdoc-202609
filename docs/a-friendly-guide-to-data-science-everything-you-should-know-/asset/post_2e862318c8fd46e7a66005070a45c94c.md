## Line and Related Charts

The standard line chart is very well-known, but there are some ways to modify it and also some related charts that can be really useful. I’ll talk about line charts, area charts, and slope charts in this section.

## Line Charts

Line charts are a very effective way to show changes over time. They’re intuitive and easy to follow, as long as you don’t try to put too many lines on one chart or do anything too fancy. The X-axis is generally time and needs to be consistently switch to monthly in the same chart. The lines don’t all have to start or end at the same point in time. As a rule of thumb, having more than four or five lines that you want to be clearly identifiable on one chart can get unwieldy.
