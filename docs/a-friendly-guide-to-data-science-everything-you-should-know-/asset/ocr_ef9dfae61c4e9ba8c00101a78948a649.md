# Tools and Platforms

There are a variety of tools and platforms you can use to do and share data science. I'll first talk about coding options and then about visualization, presentation, and sharing.

# Coding

You have three basic options for where you are going to write your code and compile your results. One is personal, whether your own computer, a computer from work, or a VM on a shared computing space like your college network. A second is on a public data science platform like Kaggle. The third is on a general cloud platform, such as Azure, AWS, or GCP. For an individual, the first two are most likely the only feasible options because they're free, whereas cloud platforms can be very expensive (it's also easy to accidentally rack up charges, even if it sounds affordable).
