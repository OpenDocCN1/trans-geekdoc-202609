# Data Leakage

Data leakage comes from one of the easiest mistakes to make in modeling—accidentally including data in the train set that shouldn’t be there. This could be from your test set (easy to do) or any other information about your target that won’t be available when running real forecasts.

Another thing that’s easy to do, especially when you’re new, is accidentally including features that are there in your train (and test) set but won’t be there when you’re running your model on unseen/future data. For instance, imagine you’re predicting daily pizza sales at a restaurant for the next week, Monday through Sunday. You create a bunch of great features, including things like previous day’s sales and previous week’s sales. That works in your test set because you are able to calculate all of those since you have complete data. When it comes to running true forecasts for the upcoming week, you may have sales all the way through Sunday night, and then you’re going to run the feature update for the coming week and then the forecasts early on Monday morning.
