This is usually done when one bar is much larger than the others (an outlier), but it's generally considered better to leave the longer bars and add labels to the other ones so the values can be seen. You may also do a second chart that shows only the non-outlier bars, where they can be distinguished easily.

You can get away with having Y-axis labels in a bar chart by adding the value at the top of the bar. This can be especially effective if there aren't very many bars.
