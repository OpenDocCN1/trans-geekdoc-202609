Semi-automated data collection involves largely automated collection but where somebody has to do a little something special, like a barcode scanner or key in values into a point-of-sale system. For instance, transactional tracking in retail is semi-automated because the cashier has to scan each of the customer’s groceries (a manual process), but all the product details are retrievable from an existing database and from that point the transaction data goes into the database(s) automatically. Forms are another example of semi-automated, because someone has to create the form and someone has to fill it out, but everything else is automated.
