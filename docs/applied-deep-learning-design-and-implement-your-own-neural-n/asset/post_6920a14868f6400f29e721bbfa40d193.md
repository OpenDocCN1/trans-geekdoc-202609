### Image segmentation

In terms of computer vision and image processing, image segmentation is defined as the process of splitting an input image into various segments. It can be termed as the extension of the object detection technique in which every object present in an image is marked through pixel-wise split segments.

Unlike the object detection technique, which only draws a bounding box around the object, the image segmentation process also helps in finding out the actual shape of an object present in the input image. The main motive of image segmentation is to change or simplify the actual representation of the input image so that the image becomes easier to understand and analyze:

![](img/7e519fee1b702b91799cdf1664598392_382_0.png)

**Figure 5.21:** Image segmentation

Image segmentation can be classified into the following two parts:

- 1. Semantic segmentation
- 2. Instance segmentation

Let us discuss both of them in detail.

### Semantic segmentation

Semantic segmentation is the process of detecting different objects in an input image and further grouping them on the basis of pre-defined categories.

For example, if we observe the following figure, when semantic segmentation is applied to the input image, it provides output _chair_ as a single category, and hence, all the chairs are colored with the same color:

![](img/7e519fee1b702b91799cdf1664598392_383_0.png)

**Figure 5.22:** Semantic segmentation

### Instance segmentation

Instance segmentation is the process of detecting different objects a bit deeper in an input image and detecting different objects within a pre-defined category.

For example, if we observe the following figure, when semantic segmentation is applied to the input image, it detects the *chair* and also divides each chair (instances) separately:

![](img/7e519fee1b702b91799cdf1664598392_383_1.png)

**Figure 5.23:** Instance segmentation

### YOLO algorithm

YOLO stands for You Only Look Once. It is the most common algorithm used for object detection. YOLO takes the entire input image as a single segment and then predicts the coordinates of the bounding boxes along with the probability of each class belonging to these boxes.

It is the most popular among all the object detection algorithms because of its speed. It can do the processing of about 45 frames per second. Let us discuss how the YOLO algorithm works.

First, it takes an input image, let us say a 100 × 100 image, as shown in Figure 5.24:

![](img/7e519fee1b702b91799cdf1664598392_384_0.png)

**Figure 5.24:** Input to YOLO

Then, the YOLO algorithm divides the input image into grids, here say a grid of 3 × 3:

![](img/7e519fee1b702b91799cdf1664598392_384_1.png)

**Figure 5.25:** 3 × 3 grid to the input image

After that, on each grid image, classification and localization are applied, and then the YOLO algorithm predicts the bounding boxes along with the class probabilities.

Now for the training purpose, we have to pass the labeled data to our model. Here, in this case, we have separated the input image into 3 x 3 grids and suppose there are three classes to which the objects belong to, namely, car, pedestrian, and motorcycle.

Now, for each grid, the output label y is a vector of eight dimensions as follows:

```
y_{target} = \begin{bmatrix} p_c \\ b_x \\ b_y \\ b_w \\ b_h \\ c_1 \\ c_2 \\ c_3 \end{bmatrix}
```

Where $p_c$ denotes the confidence of the object to be present in an image.

$c_1, c_2,$ and $c_3$ show that if an object is present in an image, it tells the object belongs to which class, such as Class 1, Class 2, or Class 3.

$b_x$ denotes the x$^{th}$ coordinate of the upper left corner of the bounding box.

$b_y$ denotes the y$^{th}$ coordinate of the upper left corner of the bounding box.

$b_h$ denotes the height of the bounding box.

$b_w$ denotes the width of the bounding box.

Now, let us take the first grid ($c_1$) from Figure 5.26:

![](img/7e519fee1b702b91799cdf1664598392_385_0.png)

**Figure 5.26:** Grid from Figure 5.24

If we observe Figure 5.26, there is no object in the grid; therefore, the value of $p_c = 0$ and the output label is given as follows:

```
y_{target} = \begin{bmatrix} 0 \\ ? \\ ? \\ ? \\ ? \\ ? \\ ? \\ ? \end{bmatrix}
```

It means there is no object in the grid, so there is no meaning of all the other values, which are marked as ?. Now, let us take another grid say (c₂) as follows:

![](img/7e519fee1b702b91799cdf1664598392_386_0.png)

But how does the YOLO algorithm understand if an object is there or not in an input image? Now, if we observe Figure 5.24, there are two cars in the input image. YOLO algorithm takes the midpoints of these two cars, and furthermore, these cars are assigned to the corresponding grids that have the mid points of these two car objects.

So, now here the grid has an object, therefore, the value of p_c = 1, and the output label is given as follows:

```
y_{target} = \begin{bmatrix} 1 \\ b_x \\ b_y \\ b_w \\ b_h \\ 0 \\ 1 \\ 0 \end{bmatrix}
```

Similarly, for all the nine grids, we can calculate the output label. Finally, we will have the output of size 3 x 3 x 8. So, our model will be trained as follows:

![](img/7e519fee1b702b91799cdf1664598392_387_0.png)

**Figure 5.28:** Model training

Both backward and forward propagation will be used to train the models. And for testing purposes, we provide a test image to the trained model and execute the forward propagation till the value of y is obtained.
