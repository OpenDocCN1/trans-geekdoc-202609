
Where S represents the training set, x_n represents the input to the neural network, and t_n represents the targeted (output) value. In this type of learning, as the inputs are applied to the neural network, the actual output values are compared with the targeted output values. Then, the learning rule is used to adjust or update the bias and weight values of the neural network. The rule for perceptron learning comes in the category of supervised learning. In the perceptron learning rule, updates of biases and weights are done using the following equation:

```
w_{new} = w_{old} + ep^{T}
bias_{new} = bias_{old} + e
```

## Gradient descent

Gradient descent is a machine learning-based optimization technique that is used to minimize the loss or error functions in a recursive manner by moving toward the direction of the global minima or steepest descent, which is defined by the negative values of the gradient.

In machine learning, the practice of gradient descent is done to update the model parameters, such as weights or biases in the neural networks.

### Fundamentals of gradient descent

A gradient is a function having a vector value that represents the tangent's slope of the plot of a function while pointing in the direction of the highest rate of increase for the function. In other words, it is the derivative that indicates the slope of the function.

Consider a 3-D graph, as shown in figure 3.15, having a cost function. The main aim is to start from the right corner (topmost) of the mountain to the dark-blue sea, that is, toward the bottom of the mountain. The arrows denote the route of steepest descent from any of the known points, that is, the direction that reduces the cost function as fast as possible.

Initiating from the topmost of the mountain, we take the first movement downhill toward the direction indicated by the descent gradient. In the next step, we recalculate the steepest descent (while passing from the coordinates of our newest point) and take one more step in the direction specified by it. We continue this process repeatedly till we get to the desired location of the graph or to that point where we are no longer required to move downhill, that is, a local minimum point. Figure 3.16 shows the process of gradient descent:

![](img/7e519fee1b702b91799cdf1664598392_157_0.png)

Figure 3.16: Process of gradient descent

It is an iterative process that takes the minimization of the function (the global minima). The following formula shows the gradient descent to update the weight factor to achieve local/global minima.

```
w' = w - \eta * \frac{\partial L}{\partial w} (3.3)
```

Where,
w' is the updated weight factor,
'w' is the current weight factor,
"-" sign denotes subtraction,
"\eta", is the small step towards global minima, that is, the learning rate,
\frac{\partial L}{\partial w}, is the direction of the fastest increase (rate of change).

The idea of gradient descent is described as follows.

Let us take a machine learning model in which a group of data points is located in a 2D space. Also, consider that the information is associated with the weight and height of a cluster of students. We want to forecast the relationship among these variables such that we can forecast the height or weight of new students. This is a simple case of a supervised deep-learning method.

Now, draw a subjective line in the space which passes over some of the plotted data points. The equation for the straight line is written as follows:

```
Y = wX + b (3.4)
```

Where w is the slope/ weight and b is its intercept/bias on the Y-axis. If the value of b = 0, then the line passes through the origin, and if b = 1 means it passes through the value of y = 1. The slope w decides the orientation of the line. Different values of w and b have different lines. The neural network tries to find the best-fit line that separates the two classes with minimum loss.

## Parameters related to the gradient descent function

The following are the parameters related to the gradient descent function.

### Epoch

Epoch is defined as the number of times the weight gets updated while moving toward the global minima. Maximum time, the users decide on the number of epochs or a number of updates required to minimize the computational complexity or to minimize the corresponding loss function.

Global minima need not be zero, but they should be minimal.

### Weight update

\( w' = w - \eta * \frac{\partial L}{\partial w} \)

The weight update algorithm for gradient descent is as follows:

```
Weight_Update_Algo(k, old_wt){
    for (till global minima is achieved) or (predefined no. of epochs)
    {
        for (each weight k)
        {
            new_wt = old_wt - ηw
            new_bias = old_bias - ηw
        }
    }
}
```

### Learning rate (η)

The learning rate is defined as the size of the steps toward the desired location. With an increase in the learning rate, more ground can be covered by using each step. But, there is a possibility of overshooting the bottommost point of the ground. Figure 3.20 shows the different types of learning rate:

More precision can be achieved by keeping a low learning rate, but determining the gradient is more time-consuming, so it takes a large amount of time to reach the bottom.
