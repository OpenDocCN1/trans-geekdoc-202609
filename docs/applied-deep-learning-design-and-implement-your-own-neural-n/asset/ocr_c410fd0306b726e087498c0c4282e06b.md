Putting $1 - a = 0$ in *equation (3.56)*, we get $a = 1$. Therefore, after substituting $a$ in *equation (3.56)*, we get the following equation:

$(1 - y) = A(1 - 1) + B(1)$

$B = (1 - y)$ (3.57)

Putting $a = 0$ in $(a - y) = A(1 - a) + B(a)$, we get:

$-y = A(1) + 0$

$A = -y$ (3.58)

Substituting the values of $A$ (from *equation 3.58*) and $B$ (from *equation 3.57*) in *equation (3.55)* \(\frac{a-y}{a(1-a)} = \frac{A}{a} + \frac{B}{1-a}\), we get the following equation:

\(\frac{a-y}{a(1-a)} = \frac{-y}{a} + \frac{1-y}{1-a}\) (3.59)

Therefore, after integrating *equation (3.59)* with respect to , we get the following equation (3.60):

\(\int \partial c^* = \int \frac{a-y}{a(1-a)} da = -y \int \frac{1}{a} da + (1 - y) \int \frac{1}{1-a} da\) (3.60)

As, \(\int \frac{1}{a} da = \log(a)\) and \(\int \frac{1}{1-a} da = -(\log(1 - a))\), substituting these values in *equation(3.60)*:

\(C = \int \frac{a-y}{a(1-a)} da = -y. \log(a) + (1 - y) * -(\log(1 - a)) + c\)

\(C = \int \frac{a-y}{a(1-a)} da = -y \log(a) - (1 - y) \log(1 - a) + c \int \frac{a-y}{a(1-a)} da = -[y. \log(a) + (1 - y) \log(1 - a)] ==\)

\(\int \frac{a-y}{a(1-a)} da == C \text{ ( i.e. Binary entropy cost function )}\) (3.61)

\(C \text{ ( that is, Binary entropy cost function )}\)

We notice that when we integrate the derivative of the cost function, we find the original binary cross-entropy function (3.61) as the output because the derivative and integration work as inverse relations to each other.
