
## Forward pass differentiation

Figure 3.36 shows forward pass differentiation for the sigmoid function:

![](img/7e519fee1b702b91799cdf1664598392_196_0.png)

**Figure 3.36:** Forward pass differentiation in computational graphs for sigmoid function

$f(w, x) = \frac{1}{1+e^{-(w_0x_0+w_1x_1+w_2x_2)}}$

The net output in forward pass differentiation in figure 3.36 is f = 0.73. Starting from the R.H.S of figure 3.36, we computed the value of f as follows:

```
Z = w_0x_0 + w_1x_1 + w_2x_2
Z = (2.00)(-1.00) + (-3.00)(-2.00) + (-3.00)(1.00)
Z = (-2.00) + (6.00) + (-3.00)
Z = (4.00) + (-3.00)
Z = (1.00) see fig.3.36
```

Furthermore, on proceeding forward in figure 3.36, the next node is *(-1) to make z as -z (-1.00). Moving forward, the next node is $e^{-z} = e^{-1} = \frac{1}{e} = \frac{1}{2.73} = 0.37$. After that, "1" is added to make it as $1 + e^{-z} = 1.37$. Finally, 1.37 is passed into the node $\frac{1}{x}$ to make it as $\frac{1}{1.37} = \frac{1}{1+e^{-z}} = 0.73 = f(w, x)$.

## Backward/reverse pass differentiation for sigmoid function

As we know that: $f(x) = e^x$

\(\frac{\partial f}{\partial x} = e^x \quad (3.63)\)

And

\( f(x) = ax \)

\( \frac{\partial f}{\partial x} = a \quad (3.64) \)

Also,

\( f(x) = \frac{1}{x} \)

\( \frac{\partial f}{\partial x} = -\frac{1}{x^2} \quad (3.65) \)

And

\( f(x) = c + x \)

\( \frac{\partial f}{\partial x} = 1 \quad (3.66) \)

From figure 3.37, we can see that the output of the sigmoid gate in backward/reverse pass differentiation using subsequent multiplication of local gradient and the upcoming gradient is 0.20.

![](img/7e519fee1b702b91799cdf1664598392_197_0.png)

Figure 3.37: Reverse pass differentiation in computational graphs for sigmoid function

\( f(w, x) = \frac{1}{1+e^{-(w_0*x_0+w_1*x_1+w_2*x_2)}} \)

Further, the output of the sigmoid gate during backward pass or differentiation is distributed over various weights ($z = w_0x_0 + w_1x_1 + w_2x_2$) through **ADD** gate. The **ADD** gate acts as gradient distributor, the **MAX** gate acts as gradient router, and the **MUL** gate acts as gradient switcher.

The output of reverse pass differentiation of the sigmoid gate in *figure 3.37* is computed as follows. Starting from the R.H.S of *figure 3.37*, we computed the UGs and LGs as follows:

**Step 1:**

$$
\frac{\partial f}{\partial f} = 1 = (UG)
$$

**Step 2:** By using *equation (3.65)*, we get the following local gradient by substituting the value of $x = 1.37$ that we computed during the forward pass in *figure 3.36*.

$$
\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}\left(\frac{1}{x}\right) = -\frac{1}{x^2} = -\frac{1}{(1.37)^2} = -0.53 = (LG)
$$

Further, the net value at this point is $T = UG \times LG = (1) \times (-0.53) = -0.53$. The value $T = -0.53$ is now considered/treated as UG for *step 3*.

**Step 3:** At this step, the value of the node is $ax = +1x..$ By using *equation (3.64)*, we get LG as follows:

$$
\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}(ax) = a = +1 = (LG)
$$

Furthermore, the net value at this point is $U = UG \times LG = T \times LG = (-0.53) \times (+1) = -0.53..$ The value $U = -0.53$ is now considered/treated as UG for Step 4.

**Step 4:** At this step, the value of the node is having the value of $x = -1$ at this point during the forward pass (refer *figure 3.36*). So, by using *equation (3.63)*, we compute the following local gradient in this step as follows:

$$
\frac{\partial}{\partial x} (\exp) = \frac{\partial}{\partial x} e^x = e^x = e^{-1} = \frac{1}{e} = \frac{1}{2.73} = 0.37 = (LG)
$$

Furthermore, the net value at this point is $V = UG \times LG = U \times LG = (-0.53) \times (0.37) = -0.20$. The value $V = -0.20$ is now considered/treated as UG for Step 5.

**Step 5:** Further moving towards the next node in the reverse direction in *figure 3.37*, we find the value of the node at this point as $ax = * -1x.$ By using *equation (3.64)*, we get the following LG: $\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}(ax) = a = -1 = (LG)$

Furthermore, the net value at this point is W = UG x LG = V x LG = (-0.20) x (-1) = 0.20. The value W = 0.20 is now considered/treated as UG for Step 5.

The output of the sigmoid gate is W = 0.20. Moreover, we can prove the same result (that is, W = 0.20) of reverse/backward pass differentiation of the sigmoid gate using differential calculus on the sigmoid activation function.

The sigmoid activation function is shown in equation (3.67):

\(\sigma(x) = \frac{1}{1+e^{-x}}\) (3.67)

Differentiating the equation (3.67) with respect to x, we get the following:

\(\frac{\partial \sigma(x)}{\partial x} = \frac{e^{-x}}{(1 + e^{-x})^2}\)
\(= \frac{e^{-x}}{1 + e^{-x}} * \frac{1}{1 + e^{-x}}\)
\(= \frac{1 + e^{-x} - 1}{1 + e^{-x}} * \frac{1}{1 + e^{-x}}\)
\(= (1 - \sigma(x)) * \sigma(x)\)
\(\frac{\partial \sigma(x)}{\partial x} = (1 - 0.73) * 0.73\)
\(\frac{\partial \sigma(x)}{\partial x} = (0.27) * 0.73\)
\(\frac{\partial \sigma(x)}{\partial x} = 0.20\)

## Activation function

An activation function is a function that decides if a node or neuron has to be activated or not by determining the weighted sum. The aim of the activation function is the initiation of the non-linear property into the output of the node or neuron.

A neural network without any activation function is actually considered as only a regression model having linearity property.

The activation function makes the backpropagation (which plays an important role in a neural network) possible because the gradients are provided with the errors to update the biases and weights.

## Need for non-linear activation functions

A neural network with no activation function is only a basic linear model of regression. It is the activation function that performs the transformation (non-linear) to the inputs to the neuron and makes it adapt to perform and learn more complex calculations. Let us discuss some of the commonly used activation functions.

## Different types of activation functions

### Linear activation function

The linear function is an activation function having a mathematical equation same as that of a straight line as follows:

y = mx (3.68)

Where x and y are the coordinates and m is a constant.

Irrespective of the number of layers present in the neural network, if all the layers possess the property of linearity, then the activation function of the final layer is a linear activation function of the input layer. The range of the linear activation function varies from [-∞, ∞]. The linear activation function is used at the output layer only. Let us take an example of the use of a linear activation function.

Example 3.5: The price calculation of a house is considered to be a regression problem. This problem is dependent upon the number of features such as the total covered area, number of rooms, number of bathrooms, and the corresponding price. It consists of dependent and independent variables. In the equation of linear function ᷑ = ᷑ ᷑ , ᷑ is the independent variable and y is the dependent variable.

The cost of the house can be low or high, so here a linear activation function is used at the output layer. Figure 3.38 depicts the curve for the linear activation function:

### Sigmoid function

It is a non-linear activation function, when plotted, depicts an S-shaped graph. Its range lies between 0 and 1. It is easy to understand and use.

The equation of the sigmoid activation function is given as follows:

P = \frac{1}{1+e^{-x}} (3.69)

Figure 3.39 depicts the plot of the sigmoid function:

![](img/7e519fee1b702b91799cdf1664598392_201_0.png)

Figure 3.39: Sigmoid activation function

It is commonly used in the case of classification (binary), where the output layer provides results as either 1 or 0. The value of the sigmoid activation function varies in the range of 0 to 1. The predicted output is as follows:

Output = \begin{cases} 1, & Result > 0.5 \\ 0, & Result \le 0.5 \end{cases}

Hence, if the resultant value is more than 0.5, the forecasted output is 1; otherwise, the forecasted output is 0.

### ReLU activation function

Rectified Linear Unit (ReLU) is the most commonly used activation function. Unlike the linear and sigmoid activation functions, which are implemented at the output layer of the neural network, ReLU is implemented at the hidden layers of the neural network.
