Table 5.2 discusses some of the differences among object detection algorithms:

| Object detection algorithm | Time of prediction per image | Features | Limitations |
|---|---|---|---|
| CNN | – | It basically separates an input image in different regions and further classifies every region in a separate class. | A large number of regions are required for making the predictions and also take more computational time (slow) |
| RCNN | 40 to 50 seconds | RCNN uses a selective search algorithm to create regions and can extract about 2,000 number of regions from an input image. | It uses three models to the final bounding box predictions and also have high computation time as every region is passed through CNN separately |
| Fast RCNN | 2 seconds | Every input image is provided to CNN once only where through which feature maps are extracted, then further selective search algorithm is used for making the predictions. It consists of a single model which is a combination of all the three models used in the RCNN. | Even fast RCNN uses a selective search algorithm which is again slow, and thus, has high computation time. |
