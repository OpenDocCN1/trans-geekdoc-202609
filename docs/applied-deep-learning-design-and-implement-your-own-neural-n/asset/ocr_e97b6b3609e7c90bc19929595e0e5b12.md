# Mount drive

Here we have used Large-scale CelebFaces Attributes Dataset to train the DCGAN model, developed and published by Ziwei Liu et al., in a paper titled From Facial Parts Responses to Face Detection: A Deep Learning Approach, 2015, referred to as, **CelebA**. It contains more than 200,000 photographs of celebrity faces along with annotations such as hats, face shape glasses, hair type, and so on. The dataset **img_align_celeba**. **zip** is publicly available on the Kaggle website, which is about 1.3 gigabytes in size. It can be downloaded by clicking on the filename and then the download icon. In order to access the dataset inside the code, first upload the dataset to Google Drive, connected to your Gmail account.

Then using the script as **Check the mounted Drive**, Google drive can be mounted to Google Colab. After execution, the preceding script shows a link and asks for an authorization access code, which can be achieved by clicking on the link. (All the steps with detailed explanations can be found on the following Web page—*Datasets in colab*).
