Where S represents the training set, x_n represents the input to the neural network, and t_n represents the targeted (output) value. In this type of learning, as the inputs are applied to the neural network, the actual output values are compared with the targeted output values. Then, the learning rule is used to adjust or update the biased and weight values of the neural network. The rule for perceptron learning comes in the category of supervised learning. In the perceptron learning rule, updates of biases and weights are done using the following equation:

```
w_{new} = w_{old} + ep^{T}
bias_{new} = bias_{old} + e
```

# Unsupervised learning

In the case of unsupervised learning algorithms, updates of biases and weights are done in reply to input to the neural network only. Here, target outputs are not available. So, how can we provide training to a neural network if we do not even know what the neural network is supposed to perform? Many unsupervised learning algorithms execute a certain type of clustering algorithm.

# Reinforcement learning

The reinforcement learning method is almost analogous to the supervised-learning. The only difference is in the place of being delivered with the true output for each of the neural network inputs; here, the learning algorithm is only provided with a grade. The score or grade can be defined as a measure of the neural network’s performance with respect to a sequence of inputs. Reinforcement learning is not as common as supervised learning. It is most suitable for control system-based applications.

# Gradient descent

Gradient descent is a machine learning-based optimization technique that is used to minimize the loss or error functions in a recursive manner by moving toward the direction of the global minima or steepest descent, which is defined by the negative values of the gradient.

In machine learning, the practice of gradient descent is done to update the model parameters, such as weights or biases in the neural networks.
