Similarly, all the values of the resulting matrix can be calculated by shifting the kernel with a stride movement of 1.

In convolution, we need to detect different features of the images, so there is a need to use multiple filters. In the case of convolution with multiple filters, the convolution is carried out independently with all the filters one by one, and then the results of all the convolutions are mixed to get the final output.
