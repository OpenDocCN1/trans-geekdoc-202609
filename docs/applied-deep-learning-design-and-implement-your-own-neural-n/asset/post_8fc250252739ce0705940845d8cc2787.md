
## 3. Forward propagation

```python
def forward_propagation(self, x):
    T = len(x)
    s = np.zeros((T + 1, self.hidden_dim))
    s[-1] = np.zeros(self.hidden_dim)
    o = np.zeros((T, self.word_dim))
    for t in np.arange(T):
        s[t] = np.tanh(self.U[:, x[t]] + self.W.dot(s[t-1]))
        o[t] = softmax(self.V.dot(s[t]))
    return [o, s]
```

## 4. Backpropagation

```python
def gradient_check(self, x, y, h=0.001, error_threshold=0.01):
    bptt_gradients = self.bptt(x, y)
    model_parameters = ['U', 'V', 'W']
    for pidx, pname in enumerate(model_parameters):
        parameter = operator.attrgetter(pname)(self)
        print "Performing gradient check for parameter %s with size %d." % (pname, np.prod(parameter.shape))
        it = np.nditer(parameter, flags=["multi_index"], op_flags=["readwrite"])
        while not it.finished:
            ix = it.multi_index
            original_value = parameter[ix]
            parameter[ix] = original_value + h
            gradplus = self.calculate_total_loss([x],[y])
            parameter[ix] = original_value - h
            gradminus = self.calculate_total_loss([x],[y])
            estimated_gradient = (gradplus - gradminus)/(2*h)
            # Reset parameter to original value
            parameter[ix] = original_value
            # The gradient for this parameter calculated using
            backpropagation
            backprop_gradient = bptt_gradients[pidx][ix]
            # calculate The relative error: (|x - y|/(|x| + |y|))
            relative_error = np.abs(backprop_gradient - estimated_gradient)/(np.abs(backprop_gradient) + np.abs(estimated_gradient))
            # If the error is too large fail the gradient check
            if relative_error > error_threshold:
                print "Gradient Check ERROR: parameter=%s ix=%s" % (pname, ix)
                print "+h Loss: %f" % gradplus
                print "-h Loss: %f" % gradminus
                print "Estimated_gradient: %f" % estimated_gradient
                print "Backpropagation gradient: %f" % backprop_gradient
                print "Relative Error: %f" % relative_error
                return
            it.iternext()
        print "Gradient check for parameter %s passed" % (pname)
```

## Introduction

In the previous chapter, we have discussed sequence prediction using RNN. RNN works well for short-term dependencies; however, it has certain limitations, as follows:

- Because of the vanishing gradient issue, if we want to use a long chain of RNN having multiple hidden layers, it becomes difficult for RNN to remember all the past information; that is, it can remember only a certain amount of information from the incidences that happened in the past. Therefore, it affects the performance of the RNN by limiting its effectiveness when it needs to go back deeper into the context.
- The other limitation of the RNN is that there is very weak control over the information which needs to be carried forward and how much information regarding past incidences needs to be forgotten.

The preceding two problems can be mitigated by using LSTM. They are a special type of RNN. Unlike RNNs, they are capable of learning long-term dependencies. Before LSTM, we will discuss GRU. Moving from RNN to LSTM, in LSTM, we replace the hidden layer node with a Gated unit, as shown in figure 7.1.

## Simple GRU

There exist two types of dependencies, short-term and long-term dependencies. For example, Rohit is known as a hit-man. He is the captain of Mumbai Indians. There exists a dependency between Rohit and Him. Another example is, five people are going with us to Himani Chamunda Temple, and all of them are good trekkers. There exists a short-term dependency between “five and people” and “people and are”; there exists a long-term dependency between five people and them. RNNs are capable of learning short-term dependencies but are unable to remember long-term dependencies due to vanishing gradients, as discussed during backpropagation in RNN.

The problem that arises here is remembering whether the subject is singular or plural / male or female to resolve dependencies. Some kind of hidden state representations are required to understand these short and long-term dependencies and remember them till the point more interesting information needs to be remembered. In GRU, there are two basic things when to remember and what to remember representing [update units \(\gamma_u\)] and [cell units \(\tilde{c}_t\)].

\(\gamma_u = 1, \gamma_u = 0, \gamma_u = 0, \gamma_u = 0 \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\gamma_u = 0 \quad (7.1)\)
\(c_t = 1, c_t = 1, c_t = 1, c_t = 1 \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots c_t = 1 \quad (7.2)\)

In the case of a Gated recurrent unit, the most important question is what a gate means in GRU. Suppose in a class of computer science, there are 50 students whose class of deep learning is scheduled at 10: 30 a.m. So, students are allowed up to 10: 30 a.m. (Time = t), and after that, they are not allowed. So it becomes a 50-dimensional bit vector in which if the bit value \(\gamma_u = 1\) means allowed to enter the class, and 0 means not allowed to enter. It may vary between 0 and 1. Gated input \(\gamma_u\) (when to remember) is stored in cell input \(\tilde{c}_t\) (what to remember).

### Potential cell update unit

\(\tilde{c}_t = tanh[(W_c (c_{t-1}, x_t) + b_c] \quad (7.3)\)

It can be visualized as the cell or memory value at time = t. In equation (7.3), the neural network is parameterized by \((W_c, b_c)\), where \(W_c\) is weight and \(b_c\) is corresponding bias with input as \((c_{t-1}, x_t)\). Here, the tanh activation function is used as its range is -1 to 1 and we are working with what to update issue.

### Update or input unit

\(\gamma_u = \sigma[(W_u (c_{t-1}, x_t) + b_u] \quad (7.4)\)

It can be visualized as a gate that allows or blocks some information. In equation (7.4), the neural network is parameterized by \((W_u, b_u)\), where \(W_u\) is weight and \(b_u\) is corresponding bias with input as \((c_{t-1}, x_t)\). Here, sigmoid activation function is used as its range is 0 to 1, and we are working with updating issue. Here, we are concerned with whether we have to update the corresponding cell value (\(\tilde{c}_t\)) or not. It depends on gated input (\(\gamma_u\)). Potential cells are not directly updated they are gated through \(\gamma_u\) to get the actual updates. Element-wise multiplication of the update unit with the cell unit will help produce the effect of gating, as shown in equation (7.5).
