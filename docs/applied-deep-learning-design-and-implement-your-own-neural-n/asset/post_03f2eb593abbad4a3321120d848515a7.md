

## Cycle GAN

Table 8.6 shows the inputs, outputs, and aims of generator and discriminator networks in Pix-to-pix GAN:

| Pix-to-pix | Generator | Discriminator |
| :--- | :--- | :--- |
| Input | Random Noise Vector (z) and input domain image (x) | Two input pairs:<br>real image pair (x, y) from source(x) and target(y) domains<br>image pair (x,y*) from source domain(x) and<br>fake generated image in domain (y) |
| Output | Realistic-looking fake generated samples in the target domain (y) | Probability score for every pixel in the patch indicating real or fake |
| Aim | Translating input images in domain x to target domain y | Correctly identify the images in the target domain y as real or fake |

Table 8.6: Inputs, outputs, and aim of generator and discriminator networks in Pix-to-Pix GAN

We discussed in Pix-to-pix GAN that image-to-image translation is a special type of conditional GAN, where instead of generating some random outputs, some kind of condition is applied to the input to generate target images. So, to translate images from one domain to another, the model needs to be trained on both the source and target image pairs. However, Cycle GAN made it possible to perform this translation in the absence of these image pair examples. So, Cycle GAN turned out as a successful unpaired image-to-image translator that can be trained in a completely unsupervised manner. Figure 8.18 shows some of the impressive results generated by Cycle GAN:

![](img/7e519fee1b702b91799cdf1664598392_590_0.png)

**Figure 8.18: Images translated from domain "X" to domain "Y" using cycle GAN**

The idea behind Cycle GAN is to complete a cycle, where an image, say from domain X is translated to some other domain Y and then back again to domain X. Now, the cycle is complete here, and therefore in an ideal situation, the (original image) and the (reconstructed image) should be the same. But if both images are not the same, then a loss value is calculated on pixel level with the aim to minimize this loss and to generate as realistic images as possible, as shown in figure 8.19:

![](img/7e519fee1b702b91799cdf1664598392_591_0.png)

**Figure 8.19: Cycle GAN**

The cycle GAN architecture shown in figure 8.20 consists of two generators networks, in order to complete the cycle in both domains, that is, GXY, translating from domain X to Y, and GYX, translating back from domain Y to X. There are two cycle-consistency losses for both forward and backward cycles in order to make updates in the corresponding generators:

![](img/7e519fee1b702b91799cdf1664598392_591_1.png)

**Figure 8.20: Architecture of cycle GAN**

To check the performance of the two generators, there are two discriminators: DX and DY, that give their feedback on the generated images in the respective domains. Therefore, in addition to the cycle-consistency loss, the adversarial loss is still there to make sure that, along with the correct translations, the images are realistic too.

Table 8.7 shows the inputs, outputs, and aims of generator and discriminator networks in cycle-GAN:

| Cycle GAN | Input | Output | Aim |
| :--- | :--- | :--- | :--- |
| Generator (GXY) | Either a real image or generated image by (GYX) in domain X | New translated samples from X to Y | Realistic new samples in domain Y |
| Generator (GYX) | Either a real image or generated image by (GXY) in domain Y | New generated samples from Y to X | Realistic new samples in domain X |
| Discriminator (DX) | Real and generated samples in domain X | Probability score to identifying real or fake samples in domain X | Correctly identify between real or fake samples in domain X |
| Discriminator (DY) | Real and generated samples in domain Y | Probability score to identifying real or fake samples in domain Y | Correctly identify between real or fake samples in domain Y |

Table 8.7: Inputs, outputs, and aim of generator and discriminator networks in cycle-GAN

## Stack GAN

In the earlier GAN, we discussed some variants of the conditional GAN, where conditioning is done with the help of either a class, a tag, or an image. Stack GAN is another special case where conditioning is done on the text description to generate photo-realistic images. There are two generator networks in Stack GAN that work in stages and are arranged in a stacked manner. This is why it is called Stacked GAN, as shown in figure 8.21:

![](img/7e519fee1b702b91799cdf1664598392_593_0.png)

**Figure 8.21: The architecture of stack GAN**

The idea behind this model is very similar to the painting approach used by the painters where the painter draws a sketch first and then adds fine details to it. Stack GAN generates images using this sketch refinement process, and it has achieved some of the highest quality images among other GANs, as shown in figure 8.22:

![](img/7e519fee1b702b91799cdf1664598392_593_1.png)

**Figure 8.22: The output of the two stages of the stack GAN**

Stack GAN is conditioned on the text description. The Stage-I generator generates low-resolution images with rough shapes and basic colors based on the input text descriptions. The output of Stage-I, which is a low-resolution image, is fed to the Stage-II generator along with the text description, which helps to generate high-resolution images with fine details, and sharp colors looking more realistic.

Table 8.8 shows the inputs, outputs, and aims of generator and discriminator networks in stack-GAN:

| Stack GAN | Input | Output | Aim |
|---|---|---|---|
| Generator Stage-I | Noise Vector (z) and Text description | Low-resolution images | To generate realistic images |
| Generator Stage-II | Low-resolution output from Stage-I and Text Description | High-resolution images | To generate realistic images |
| Discriminator (D_I) | Real and generated samples of Stage-I | Probability score to identifying real or fake samples of stage-I | Correctly identify between real or fake sample of Stage-I |
| Discriminator (D_II) | Real and generated samples of Stage-II | Probability score to identifying real or fake samples of Stage-II | Correctly identify between real or fake sample of Stage-II |

Table 8.8: Inputs, outputs, and aims of generator and discriminator networks in stack-GAN

Since the invention of the original GAN by Ian Goodfellow, the area of generative adversarial networks has remained an active area of research. GAN has shown scope in many different areas ranging from medical images, audio, video, image synthesis, 3-D imaging, and so on. So, lots of research is going on in this area, and a large number of GANs variants have been suggested by various researchers in different areas over the years. While writing this chapter, more than 400 GAN variants exist right now. It is clear from the increasing GAN count that it is not at all possible to cover all those GANs here. So, we have discussed only some of the important GANs with their contributions to the field.
