# Visualization/expansion of 3-D filter in 2-D convolution

In figures 4.55 to 4.56, the process of 2-D convolution is demonstrated with the help of an Input volume image of 7 x 7 x 3 and a filter of the size 3 x 3 x 3 with a stride of two. Here, the depth of an image is 3. So in figures 4.55 to 4.57, the image and filter are unfolded in three channels, say channel number 1, 2, and 3. The input image has three channels such as channel number 1 x[:,:,0], 2- x[:,:,1], and 3- x[:,:,2], as depth is three. It consists of two filters as w[0] and w[1] each having three channels as [w0=w0[:,:,0], 2- w0[:,:,1], and 3- w0[:,:,2]] and [w1=w1[:,:,0], 2- w1[:,:,1], and 3- w1[:,:,2]]. It means that the filter w[0] of size is embedded inside the weight parameters of the three filter channels, as shown in figure 4.55 (b). So, in figure 4.55, first block channel number -1 x[:,:,0] will get convolved with first channel of filter w0[:,:,0] and returns nine values. Similarly, x[:,:,1] will get convolved (element by element multiplication) with w0[:,:,1] and returns another set of nine values. At last x[:,:,2] will get convolved with w0[:,:,2] and returns another set of nine values. We received 27 values after convolving the same block of the input image. Finally, the final value in figure 4.55(d) as -2 is found at the position (0,0) in output volume by adding these 27 values that we got during convolution:

-1 -1 = -2 at spatial location (0,0).
