# Figure 4.52: Convolutional neural network with a single filter of size two.

It consists of a single filter with a filter size of two, that is, having two weight parameters as w1 and w2. As filter is nothing, but it is just a question, that is, embedded inside its weight parameters. For example, in figure 4.53, the filter is a question that asks the difference between two input values (x1 and x2) by embedding the filter inside the weight parameters as w1 = 1 and w2 = -1. As y = w1 x1 + w2 x2 then, y = 1 * x1 + (-1) * x2 = x1 - x2. In figure 4.52, the stride is two with no padding.
