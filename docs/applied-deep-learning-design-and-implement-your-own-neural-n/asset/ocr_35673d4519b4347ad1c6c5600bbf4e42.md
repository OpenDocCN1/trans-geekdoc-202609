# Density-based method

In this type of method, the clusters are considered as the dense region having some differences and similarities with respect to the higher dense regions in the space. The density-based methods have good ability and accuracy to merge two or more clusters. For example, Ordering Points to Identify Clustering Structure (OPTICS), Density-based Spatial Clustering of Applications with Noise (DBSCAN), and so on.

# Grid-based method

In the grid-based method, the present data space is framed into a grid-like structure consisting of a finite number of cells. The clustering operations performed on this grid are independent of the number of data objects and are fast. For example, Clustering in Quest (CLIQUE), wave cluster, Statistical Information Grid (STING), and so on.

# K-means clustering algorithm—partitioning method

K-means clustering algorithm is one of the simplest learning algorithms, which is unsupervised and can solve the clustering problem. This algorithm partitions the n number of observations into k number of seed points, in which every observation goes to the cluster, which has the adjacent mean aiding as a sample of the cluster.

The main idea behind the k-means clustering algorithm is to define k number of centers, one for an individual cluster. The main aim of the algorithm is to minimize the sum of distances between the cluster centroid and their respective data points.

The algorithm can be executed by using the following steps:

+   - Partitioning of the objects into k subsets.
+   - Identifying the mean point (cluster centroid) of the partition.
+   - Assigning each data point to a specific cluster.
+   - Calculating the distance from each point to the cluster centroid and assigning the data points to the cluster for which the distance from the cluster centroid is minimum.
+   - Determining the centroid of the new cluster again after the reallocation of data points.
