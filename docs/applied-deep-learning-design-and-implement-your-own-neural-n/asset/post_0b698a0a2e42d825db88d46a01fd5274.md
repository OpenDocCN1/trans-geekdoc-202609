
For defining the second-order derivative, we have the following three conditions:

- The second-order derivative should be $0$ in flat segments or, say, areas having constant intensity.
- The second-order derivative should not be $0$ on the onset of change in intensity (step).
- The second-order derivative should not be $0$ along the ramps.

The second-order derivative (Laplacian filters) is given as follows and derived in the following sub-section Laplacian Filter.

\( f''(x) = f(x - 1) + f(x + 1) - 2f(x) \quad (4.7) \)

## Laplacian filter

A Laplacian filter is an edge detector filter and is used to compute the second-order derivative of the spatial image by computing the rate of change of the first-order derivative.

For an image, \( f(x, y) \) of two variables, the Laplacian is given as follows:

\( \nabla^2 f(x,y) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} \quad (4.8) \)

The Laplacian filter is termed as a linear operation as a derivative of any order is linear. We know that the first-order derivative of the one-dimensional function \( f(x) \) is given as follows:

\( \frac{\partial f}{\partial x} = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h} \quad (4.9) \)

In the case of an image, the minimum intra-pixel spacing is a unit apart so that the value of \( h = 1 \). By substituting this in equation (4.9), we get the following equation.

\( f'(x) = \frac{\partial f}{\partial x} = f(x + 1) - f(x) \quad (4.10) \)

The second-order derivative for the same is given as follows:

\( \frac{\partial^2 f}{\partial x^2} = f'(x + 1) - f'(x) \quad (4.11) \)

\( f'(x + 1) = f(x + 2) - f(x + 1) \quad (4.12) \)

By substituting equation (4.10) and equation (4.12) in equation (4.11), we get the following equation:

\( \frac{\partial^2 f}{\partial x^2} = f(x + 2) - f(x + 1) - [f(x + 1) - f(x)] \)

\(\frac{\partial^2 f}{\partial x^2} = f(x+2) - 2f(x+1) + f(x)\) (4.15)

So, while considering the neighborhood of pixels, we use the following conventions:

| (x-1,y-1) | (x-1,y) | (x-1,y+1) |
|---|---|---|
| (x,y-1) | (x, y) | (x,y+1) |
| (x+1,y-1) | (x+1,y) | (x+1,y+1) |

By using the convention discussed, the argument of the function \(f\) in equation (4.15) is replaced as follows:

| x | x-1 |
|---|---|
| x+1 | x |
| x+2 | x+1 |

\(\frac{\partial^2 f}{\partial x^2} = f(x+1) - 2f(x) + f(x-1)\) (4.16)

Rearranging the values of Equation (4.16), we get the following equation (4.17):

\(\frac{\partial^2 f}{\partial x^2} = f(x+1) + f(x-1) - 2f(x)\) (4.17)

We know that the intensity value of a pixel in an image is represented as \(z = f(x, y)\), that is, it depends on the two values as \(x\) and \(y\). In differential calculus, we know that when a particular value of a variable depends on more than one variable, then to find the differential of that, we make use of partial derivatives.

To find the partial derivative with respect to \(x\), we make \(y\) constant. Similarly, for finding a partial derivative with respect to \(y\), we make \(x\) constant. By using this, equation (4.17) is updated as follows:

\(\frac{\partial^2 f}{\partial x^2} = f(x+1, y) + f(x-1, y) - 2f(x, y)\) (4.18)

Similarly, derivative w.r.t \(y\) is found by using equation (4.17) in the \(y\)-direction.

\(\frac{\partial^2 f}{\partial y^2} = f(y+1) + f(y-1) - 2f(y)\) (4.19)

Again, using partial derivative w.r.t \(y\) in equation (4.19), we get the following equation:

\(\frac{\partial^2 f}{\partial y^2} = f(x, y+1) + f(x, y-1) - 2f(x, y)\) (4.20)

To express the Laplacian filter in discrete form, we use the following equation:

\(\nabla^2 f = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}\) (4.21)

Therefore, by substituting equation (4.18) and equation (4.20) in equation (4.21), we get equation (4.22) as follows:

```
\nabla^2 f(x, y) = f(x + 1, y) + f(x - 1, y) + f(x, y + 1) + f(x, y - 1) - 4f(x, y) \quad (4.22)
```

By using equation (4.22), the standard kernel for the Laplacian filter is as follows:

| 0 | 1 | 0 |
|---|---|---|
| 1 | -4 | 1 |
| 0 | 1 | 0 |

The Laplacian filter is classified into two types: Positive Laplacian Filter and Negative Laplacian Filter.

The negative Laplacian filter consists of negative values in a cross-pattern, which is centered within the array of elements. The corners of the filters have either positive values or zeros. The center element of the filter should be positive. It is used to find out the inward edges of an image. The following filter is an example of a 3*3 negative Laplacian filter:

```
[ 0 -1 0 ]
[ -1 4 -1 ]
[ 0 -1 0 ]
```

The positive Laplacian filter consists of positive values in a cross-pattern, which is centered within the array of elements. The corners of the filters should be zeros. The center element of the filter should be negative. It is used to find out the outward edges of an image. The following filter is an example of a 3*3 positive Laplacian filter:

```
[ 0 1 0 ]
[ 1 -4 1 ]
[ 0 1 0 ]
```

If we add diagonal elements, then the Laplacian filter is represented as follows:

| 1 | 1 | 1 |
|---|---|---|
| 1 | -8 | 1 |
| 1 | 1 | 1 |
