# # CHAPTER 7
# Gated Recurrent Unit,
# Long Short-Term Memory,
# and Siamese Networks

This chapter illustrates the concepts of Gated recurrent unit (GRU), Long short-term memory (LSTM), and Siamese networks. The LSTM networks deal with the prediction of sequences. The Siamese networks are used to find text similarity and similarity among images. Furthermore, the triplet loss minimization function is described for measuring similarity. LSTM networks are a type of recurrent neural network capable of learning order dependence in sequence prediction problems.
