Let us assume that a coin is flipped a few times, and we have got the results as "$y_1,.....,y_n$" which are either "HEADS" or "TAILS". Let "p" be the probability of getting "HEADS". Suppose the coin is tossed "100" times and "40" times we get "HEADS", then "p=0.4". By using MLE, we will prove that the guess of "p=\Sigma y_i / n" is the most likely value for "p".

So, let us write the function of the likelihood.

```
$L_Y(p) = f(y_i; p) = \prod_{y \in Y} p^{\Sigma y_i}(1-p)^{n-\Sigma y_i}$ (1.28)
```

Now taking log both sides, we get:

```
$log L_Y(p) = \Sigma y_i log p + (n - \Sigma y_i)log(1 - p)$ (1.29)
```

To maximize, set the first derivative of the function to 0.

```
$\frac{\partial log L_Y(p)}{\partial p} = 0$ (1.30)
```

```
$\frac{\Sigma y_i}{p} - \frac{n-\Sigma y_i}{1-p} = 0$ (1.31)
```

Solving, we get:

```
$p = \frac{\Sigma y_i}{n}$ (1.32)
```

Equation 1.32 represents the most likely value of p for our observation.
