Simple computational graph for activation function f(x, y, z) = (x + y) * z.

Consider the following activation function as f(x, y, z) = (x + y) * z in 3D space with the values of x = -2, y = 5 and z = -4. We are trying to find ∂f/∂x and ∂f/∂y using multiplication of UG and LG.

![](bbox=[0.23, 0.215, 0.78, 0.475])

Figure 3.35: Computational graph for function

We know that:

q = x + y
\frac{\partial q}{\partial x} = 1

And

\frac{\partial q}{\partial y} = 1

Also,

f = qz
\frac{\partial f}{\partial q} = z = -4

And

\frac{\partial f}{\partial z} = q = 3
