Feature map is the output obtained by sliding the filter over the input image to compute the convolution operation. In figure 4.5, the second layer acts as a convolutional layer and consists of convolutional filters. If we correlate it as a neural network, then the first layer is the input layer (Input Image) and the second layer acts as a hidden layer (Convolution Layer 1). The neuron is just a filter that is embedded inside the weight parameters. The filter is just a question that is applied to the elements of an input layer. For example, it asks the question of each pixel of an image as to whether the pixel contains an edge element. The difference between a fully connected layer and a convolutional layer is that in the fully connected layer, each neuron is connected to each and every element of the input, and this neuron asks questions to each and every element of the input. In CNN, we are concerned about the images and pixel values in the images (intensity), which are highly correlated. The pixel values are not just random numbers. There exists a high spatial correlation between pixel elements. So, if we apply a fully connected layer on images, then first, we flatten this, and the filter embedded inside the weight parameters of the neuron asks the question to each and every input pixel, and the responses are collected. In these responses, most of the values are quite low or zero; only a few responses have high values of interest. Moreover, the flattening of input pixel values destroys spatial relationships among pixels up to a large extent. That is why to preserve spatial relationships and to retrieve only useful information, convolution layers are used in CNN. The process of convolution works in the neighborhood instead of the entire input. The hyperparameters associated with the convolutional network are the number of filters you want to apply and the size of each filter. The size of the filter is the number of parameters or weights associated. The size of the filter depends on what type of features we are looking for in our image. Sometimes, we need 3 × 3, 5 × 5, 7 × 7, and so on. Moreover, we can understand this by imagining we are in an airplane. When it just takes off from the runway, then only the airport and some ground staff are visible, that is, our local area, that is, 3 × 3 (covers local area). As we ascend, the upward view becomes more (global area). The same is the case with the size of the filters. It depends upon what we want to see. If we want to see just a local region of an image, then we need a 3 × 3 filter. Else, if we want to see a global region, then we apply 5 × 5, 7 × 7, or any other large-size filter.
