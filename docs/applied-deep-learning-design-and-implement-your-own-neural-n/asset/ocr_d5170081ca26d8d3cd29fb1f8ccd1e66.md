# Image classification

The process of image classification refers to a computer vision task of extracting
different object classes from an image:

![](bbox=[0.24, 0.19, 0.79, 0.43])

Figure 5.6: Image classification

Figure 5.6 shows an example of image classification that detects the label of cat. But
how this image classification is performed? To predict a label from an image, there
is a specific image classification pipeline to be followed, which is given as follows:

+   • **Input section**: The input section consists of a set of M images, where each
+   image is labeled as a different L number of classes. This set is termed the
+   training-set.

+   • **Learning section**: This section is used to learn or train the model as to how
+   each class looks like using the training dataset. This step is referred to as
+   classifier-training.

+   • **Evaluation section**: In this section, the evaluation of the model is performed
+   by providing the model with a new set of images known as test-dataset and
+   asking the classifier to predict the labels of different images.
