
## Visualization/expansion of 3-D filter in 2-D convolution

In figures 4.55 to 4.56, the process of 2-D convolution is demonstrated with the help of an Input volume image of 7 × 7 × 3 and a filter of the size 3 × 3 × 3 with a stride of two. Here, the depth of an image is 3. So in figures 4.55 to 4.57, the image and filter are unfolded in three channels, say channel number 1, 2, and 3. The input image has three channels such as channel number 1 x[:,:,0], 2 x[:,:,1], and 3 x[:,:,2], as depth is three. It consists of two filters as w[0] and w[1] each having three channels as [w0=w0[:,:,0], 2 w0[:,:,1], and 3 w0[:,:,2]] and [w1=w1[:,:,0], 2 w1[:,:,1], and 3 w1[:,:,2]]. It means that the filter w[0] of size is embedded inside the weight parameters of the three filter channels, as shown in figure 4.55 (b). So, in figure 4.55, first block channel number 1 x[:,:,0] will get convolved with first channel of filter w0[:,:,0] and returns nine values. Similarly, x[:,:,1] will get convolved (element by element multiplication) with w0[:,:,1] and returns another set of nine values. At last x[:,:,2] will get convolved with w0[:,:,2] and returns another set of nine values. We received 27 values after convolving the same block of the input image. Finally, the final value in figure 4.55(d) as -2 is found at the position (0,0) in output volume by adding these 27 values that we got during convolution:

- -1 + -1 = -2 at spatial location (0,0).

In a similar way in figure 4.56, the same filter is convolved with another 3 × 3 block of input volume by using the stride of two. Similarly, as we discussed the process of convolution for figure 4.56, the filter is applied on the Input block starting at position x(0,2), and output is retrieved in the output volume block at position o(0,1) as -4 (highlighted with blue), as shown in figure 4.56:

After convolving the input image of 32 × 32 × 3 with the single filter of size 5 × 5 × 3, we get the single output activation map of 28 × 28 × 1. Here, the size gets reduced as we have not padded the input image by 2, and stride is of one:

```
Output_{size with padding} = \frac{N + (2 \times P) - F}{Stride} + 1
```

The preceding formula computes the size of the activation map. So, in this case, the value of N = 32, P = 0, F = 5, stride = 1 where N is the input image size, P is padding, and F is the size of filter.

By substituting these values in the equation as [OutputSize with padding = \frac{N+(2\times P)-F}{Stride} + 1], we get the following:

```
Output_{size with padding} = \frac{32 + (2 \times 0) - 5}{1} + 1 = 28
```

Hence, the size of the activation map is (28 × 28). Furthermore, if the number of filters is two, the total number of activation maps is also two of 28 × 28 size, as shown in figure 4.61:

Figure 4.63 presents an important aspect to understand the process of convolution layer after layer:

![](img/7e519fee1b702b91799cdf1664598392_274_1.png)

Figure 4.63 [a,b,c] : (a) A 32 × 32 × 3 input image. (b) Result of first convolution layer 28 × 28 × 6. (c) Result of second convolution layer 24 × 24 × 10.

It consists of two convolution layers. During the first convolution layer, a 32 × 32 × 3 image in figure 4.63 (a) is convolved using six filters of the size 5 × 5 × 3 and return output feature map size as 28 × 28 × 6 (with pad = 0 and stride = 1) as shown in figure 4.63(b). Also, if we want to see all of them, then the depth should be matched during the next convolution. The depth of the filter should be the same as the depth of the image or the output feature or activation maps; otherwise, at the same time, your filter would not see each and every thing. For example, if the depth of the filter is not fully matched, then it may be aggregating the responses generated by the first three filters and may not know what has happened with the rest of the three filters if the total size of the image or activation map is six. As all the responses should be seen at once, this aggregation is possible if and only if the depth of the filter matches with the depth of the image or output activation maps. Further aggregation can be understood as if we are asking 50 questions to the same pixel (x,y). It means that we are applying 50 filters and getting 50 responses in return, as the first convolution layer output acts as the input for the next convolution layer. Now, these 50 responses that are retrieved after the first filter should be seen at once. That is why to aggregate all the 50 responses, the depth of the second filter should be 50. So, in figure 4.63 (b), after applying the first filter, the output activation or feature map size is 28 × 28 × 6. This acts as an input for the next convolution layer. Six responses of size 28 × 28 are generated after the first convolution layer. During the second convolution layer, all these six responses should be seen at once by the filter. So, to aggregate all the responses, the size of the filter must be 5 × 5 × 6. In figure 4.63(b), ten (10) filters of size 5 × 5 × 6 are applied in the next convolutional layer. After applying the second convolution over the output of the first convolution, the output feature or activation map size is 24 × 24 × 10, as shown in figure 4.63 (c). The size of the feature map gets reduced because there is no padding.

```
Output_{Size with padding} = \frac{28 + (2 \times 0) - 5}{1} + 1 = 24
```

Here, N = 28, P = 0, F = 5 and stride = 1.
