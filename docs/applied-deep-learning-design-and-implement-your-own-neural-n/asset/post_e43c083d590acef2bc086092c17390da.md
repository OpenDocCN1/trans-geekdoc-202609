## Sequence prediction

Sequence prediction is a method that uses existing sequence data for predicting the upcoming values in the sequence. These sequences can be in the form of symbols, such as letters in a word or numeric values in time series problems. Figure 6.47 shows an example of the sequence prediction model.

For example:

- Given alphabets: a, b, c, d, e
- Predict: f

![](img/7e519fee1b702b91799cdf1664598392_461_0.png)

Figure 6.47: Example of the sequence prediction problem

Here, we will discuss the different models for the process of sequence prediction. For that, we are using the following terminologies:

- x: Value of the input sequence, which can be bounded by a time stamp such as x(1).
- u: Value of the hidden state bounded by a time stamp such as u(1).
- y: Value of the output state bounded by a time stamp such as y(1).

Let us discuss each of the models one by one as follows.

## One-to-one sequence prediction model

The one-to-one sequence prediction model provides a single output for every single input data. Figure 6.48 shows the one-to-one sequence prediction model:

![](img/7e519fee1b702b91799cdf1664598392_461_1.png)

Figure 6.48: One-to-one sequence prediction model

Here, the internal state for the initial timestamp is equal to 0, then further the internal state changes concerning different time steps, as shown in figure 6.49:

![](img/7e519fee1b702b91799cdf1664598392_462_0.png)

Figure 6.49: One-to-one sequence prediction model over different time stamps

In such a case, while making the sequence prediction, the model produces one timestamp result for every timestamp input signal.

## One-to-many sequence prediction model

The one-to-many sequence prediction model provides multiple outputs for every single input data. Figure 6.50 shows the one-to-many sequence prediction model:

![](img/7e519fee1b702b91799cdf1664598392_462_1.png)

Figure 6.50: One-to-many sequence prediction model over different time stamps

Here, the internal state changes with every produced value of output. This type of model can be used for the process of image captioning in which an input image is provided to the model and it provides the output as a generation of words.

## Many-to-one sequence prediction model

The many-to-one sequence prediction model provides one output for multiple input data. Figure 6.51 shows the many to one sequence prediction model:

![](img/7e519fee1b702b91799cdf1664598392_463_0.png)

Figure 6.51: Many-to-one sequence prediction model over different time stamps

Here, the internal state changes when every value of input before producing the actual output value. In this type of a case, the model uses a sequence of recently produced observations to predict the further values of time stamps.

## Many to many sequence prediction model

The many-to-many sequence prediction model provides multiple outputs for multiple input data. Figure 6.52 shows the many to one sequence prediction model:

![](img/7e519fee1b702b91799cdf1664598392_463_1.png)

Figure 6.52: Many-to-many sequence prediction model over different time stamps

It is the combination of one-to-many and many-to-one models. Here, the model uses the recent sequence of observations to predict the multiple output values.

**In the case of many-to-many sequence prediction models, the number of inputs does not have to match with the total number of outputs.**

## RNN architecture

Now, to understand the working of RNN, let us discuss the basic architecture of RNN, as shown in figure 6.53:

![](img/7e519fee1b702b91799cdf1664598392_464_0.png)

**Figure 6.53: RNN architecture**

We can represent the RNN by using the following function:

```
h_{(t)} = f_c(h_{(t-1)} \times x_{(t)}) (6.3)
```

Where

- h(t) is the new state; [history vector],
- f_c is the function with parameter c,
- h(t – 1) is the old state; [previous history vector],
- x(t) is the input vector at time step t.

## Connect with realization of RNN

Let us take an example of RNN for the use case of Natural Language Processing for a better understanding of RNN. Let us say the model is provided with the following four letters as HELL, and the model has to predict the last letter as O. The common form of RNN can be explained in figure 6.54:

![](img/7e519fee1b702b91799cdf1664598392_465_0.png)

Figure 6.54: RNN input-output model

Now, let us use the preceding structure of RNN to predict the fifth letter of the word HELLO. In the preceding structure, the center box named RNN uses a Recurrence formula [equation (6.3)] on the values of the input vector and the previous state of the input vector.

So, here letter H is the first letter, and there is nothing as its previous input. Now, after that, the letter E has been provided to the RNN, in which a recurrence formula is used with the current input E and the previous input state H.

This is according to different time stamps of the input. So suppose, if at timestamp t the input to the RNN is E, then the input was H at the time stamp t-1. And then, finally, using the recurrence formula, we get the current state. The formula is given as follows:

```
h_{(t)} = f_c(h_{(t-1)}, x_{(t)})
```

Where h(t) is the current state.

h_{(t-1)} is the previous state.

x_(t) is the current input.

Now, we have all the previous inputs as well as present input states for each letter HELL; therefore, all these inputs are given to the neural network for each letter separately. Here each input is called the time stamp input.

Now, let us say the activation function we are using here is the tanh activation function, then the current state at time stamp t is given as follows:

```
h_(t) = tanh(W_(hh) * h_(t-1) + W_(xh) * x_(t)) (6.4)
```

Where W_(hh) is the weight of recurrent input [NN-1 (fully connected network taking I/P as h_(t-1) and producing output as h_(t)]; (see table 6.3). W_(xh) is the weight of the input neuron. [NN-2 (matrix multiplication converting x to h]. Both NN-1 and NN-2 have the same dimensions, so the addition between W_(hh)h_(t-1) and W_(xh)x_(t) will be possible (see table 6.3). Here, in this case, we can observe that the recurrent neuron is taking only the successive previous state to get the output. If we have longer sequences, the result can be obtained by using multiple previous states.

So from the current state, we can calculate the output state by using the following equation:

```
y_(t) = W_(hy) * h_(t)
```

W_(hy) is NN-3 that will convert state (see table 6.3), we can calculate the output:

| NN-1 | NN-2 | NN-3 |
| :--- | :--- | :--- |
| W_(hh) | W_(xh) | W_(hy) |
| Fully connected network taking Input as h_(t-1) and producing output as h_(t) | Matrix multiplication converting dimensions of “x” to “h” so the addition is possible between h’_t and h’’. | Convert h_t to y_t |
| h’_t = W_(hh) * h_(t-1) | h’’_t = W_(xh) * x_(t) | y_t = W_(hy) * h_(t) |
| x_(t) = h’_t + h’’_t | | |
| h_t = tanh(h’_t + h’’_t) | | |
| These can be realized with the Neural networks shown in figure 6.35. | | |
