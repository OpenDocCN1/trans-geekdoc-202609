Softmax activation function is as follows:

$S(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$

Applying the Softmax activation function, we get the following equation:

$p(y=1|x) = \frac{exp(w_1^T x)}{exp(w_1^T x) + exp(w_0^T x)}$

$p(y = 0|x) = \frac{exp(w_0^T x)}{exp(w_1^T x) + exp(w_0^T x)}$

\(1 - p(y = 1|x) = p(y = 0|x)\)

\(= \frac{1}{1 + \frac{exp(w_0^T x)}{exp(w_1^T x)}}\)

\(= \frac{1}{1 + exp(w_0 - w_1)^T x}\)

\(p(y = 0|x) = 0.30\)

\(p(y = 1|x) = 1 - p(y = 0|x)\)

## Perceptron

Perceptron is a linear classifier that performs binary classification. It is the improvement over the McCulloch–Pitts networks. It has only one input layer and one output layer. The perceptron takes input as real values and provides output as binary (0 or 1). Figure 3.12 shows a single-layer perceptron where weights [w1, w2, w3, w4] and inputs [x1, x2, x3, x4] are passed through the processing unit such that the neuron either gives a result as one (1) or zero (0), respectively, depending upon the weights and inputs.

![](img/7e519fee1b702b91799cdf1664598392_151_0.png)

Figure 3.12: Perceptron learning unit

The final input to the processing unit of the perceptron is given by the following:

```
I = \sum_{j=1}^n x_j * w_j \qquad (3.1)
```

where n is the size of the input vector.

### Perceptron learning rule

The perceptron working is illustrated in figure 3.12. In the figure, there are four inputs say \([x_1, x_2, x_3, x_4]\), weights \([w_1, w_2, w_3, w_4]\), and one output Y. The learning algorithm for perceptron is as follows:

- Initialize the weights of the network connections randomly.
- Randomly select a training set sample without any replacement.
- Perform the task of affine transformation to weights and inputs as \(l = \sum_i(w_{ij}x_i + b_j)\).
- Pass the outputs of the affine transformation to the activation function to determine the class labels.
- Using the perceptron learning rule, perform updates on weights.
- Repeat the preceding steps to achieve the correct value of the input.

The activation function used in the perceptron is Sign or Binary activation function. The equation for sign activation function is given as follows:

```
sign(x) = \begin{cases} -1; & \text{if } x < 0 \\ 0; & \text{if } x = 0 \\ 1; & \text{if } x > 0 \end{cases}
```

Figure 3.13 shows the sign activation function:

![](img/7e519fee1b702b91799cdf1664598392_152_0.png)

**Figure 3.13:** Sign or step activation function

The input vector to the neural network is given as follows:
\( x = (x_1, x_2, x_3, ..... ...., x_n) \)

The weight vector associated with the input vector is given as follows:
\( w = (w_1, w_2, w_3, .... ....., w_n) \)

Then, by applying affine transformation as \(\sum_{j=1}^n x_j * w_j\), we get the following equation:

\( w_1.x_1 + w_2.x_2 + w_3.x_3 + ... + w_n.x_n + w_0 \)
\( = \sum_{l=1}^n w_l.x_l + w_0 \)
\( = \sum_{l=1}^n w_l.x_l + w_0.x_0 ; \; where \; x_0 = 1 \)
\( = \sum_{l=1}^n w_l.x_l + w_0 \quad (3.2) \)

By applying the sign activation function in Equation (3.2), we get the binary classification as follows:

### Case 1:

- \( if \sum_{l=1}^n w_l . x_l . + w_0 < 0 \; OR \; \sum_{l=1}^n w_l . x_l . < w_0 \)
- \( Class \; Label = -1 \)

### Case 2:

- \( if \sum_{l=1}^n w_l . x_l . + w_0 \ge 0 \; OR \; \sum_{l=1}^n w_l . x_l . \ge w_0 \)
- \( Class \; Label = 1 \)

## Multi-layer perceptron (MLP)

A multi-layer perceptron (MLP) can also be termed as a multi-layer neural network, which consists of one or more number of hidden layers, one input, and one output layer. A single-layer perceptron can only learn linear functions, while a multi-layer perceptron can learn non-linear functions. Figure 3.14 shows a multi-layer perceptron consisting of one hidden layer, one input layer, and one output layer:

![](img/7e519fee1b702b91799cdf1664598392_154_0.png)

Figure 3.14: Multi-layer perceptron

The perceptron takes input as x1, x2,...., x3 (with a +1 bias term) and outputs y1 and y2 (summed inputs + bias). The main purpose of bias is to deliver each node with a learnable constant value (along with the normal inputs which the node usually receives). The activation function takes a single output from a neuron and executes a mathematical action on it. There are many activation functions that we are using in many interesting problems, which are discussed in the following sections.

### Types of perceptron learning

Learning rule means a method to modify the biases and weights of a neural network. It is called as training algorithm or training rule.

The main objective of the training rule is to give training to the neural network so that it can perform a task. There are various types of training or learning rules for a neural network. These fall into three broad categories of machine learning such as supervised learning algorithms, unsupervised learning algorithms, and reinforcement learning algorithms and are described as follows.

### Supervised learning

In supervised learning, the training rule is provided with a proper training set (set of examples), such as:

```
S = {(x1, t1), (x2, t2), ...... , (xn, tn)}
```
