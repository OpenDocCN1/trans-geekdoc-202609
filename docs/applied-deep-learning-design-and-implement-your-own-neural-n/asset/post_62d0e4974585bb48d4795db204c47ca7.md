
![](img/7e519fee1b702b91799cdf1664598392_510_0.png)

Figure 7.6: Input i(t) or update $\gamma_u$ Gate of LSTM

The equation for the input gate is given as follows:

$\gamma_u = \sigma[(W_u (h_{t-1}, x_t) + b_u]$

Or

$i(t) = \sigma[(W(i)[h(t - 1), x(t)] + b(i)]$

It takes input as follows:

- The output from the previously hidden layer node, that is, h(t - 1).
- Finally, current input, that is, x(t).

And the output is passed through the sigmoid function, which results in values between 0 and 1.

## Output gate

It is also a sigmoid activation function-based ANN node. It decides what and how much part of the cell state will be provided as the output of the LSTM cell and will be the input to the next hidden state of the neural network.

It is also known as the focus vector. The equation for the output gate is given as follows:

$\gamma_o = \sigma[(W_o (h_{t-1}, x_t) + b_o]$

Or

$o(t) = \sigma[W (o)[h(t - 1, x(t)] + b(o)]$

![](img/7e519fee1b702b91799cdf1664598392_511_0.png)

Figure 7.7: Output Gate of LSTM

So, finally, an LSTM cell will generate two different types of outputs:

- Cell State c(t).
- The output of the hidden layer h(t).

Now, if we observe figure 7.1, we can see that in RNN, the output of the previously hidden layer, along with the current input, is provided to the hidden layer of each of the states. But, in the case of LSTM, current input, the output of previous gated units, and the cell state of the previous gated unit are provided as input to the gated unit of LSTM architecture.

Now, we have already discussed the working of all the gates used in the LSTM cell, so the final output c(t), that is, memory cell update is given by the following equation:

```
$c_t = \gamma_u \odot \widetilde{c}_t + \gamma_f \odot c_{t-1}$
```

Or

```
$c(t) = i(t) \otimes c'(t) + f(t) \otimes c(t - 1)$
```

And finally, the output of the hidden layer is given by the following:

```
$h_t = \gamma_o \odot \tanh c_t$
```

Or

```
$h(t) = o(t) \otimes tanh(c(t))$
```

So, the previously-mentioned steps describe the forward propagation in LSTM. Now, let us discuss how the process of backpropagation takes place in LSTM.

## Backpropagation in LSTM

The main purpose of backpropagation is to train neurons in the neural network. LSTM also uses a technique named backpropagation with time, similar to RNN.

But in RNN, the process of backpropagation updates only the neurons, whereas in LSTM, the process of backpropagation, along with updating the weights of the neurons, also makes learning the Gated units.

![](img/7e519fee1b702b91799cdf1664598392_512_0.png)

Figure 7.8: Backpropagation in LSTM

We have already discussed weight updation in RNN using backpropagation over time. The process of the weight updation in LSTM is also the same as that of the RNN, so we will not discuss the weight updation process of LSTM in this chapter.

In this chapter, we will discuss the learning of internal gated cells of LSTM using backpropagation with time. So, now let us take the LSTM cell for the process of backpropagation as follows:

![](img/7e519fee1b702b91799cdf1664598392_513_0.png)

Figure 7.9: Back-propagation in LSTM Gated unit

So, here, the backpropagation trains all these gates used in the gated unit of LSTM. Let us start with the block output h(t) first. In the forward pass, we calculated block output as follows:

```
h_t = \gamma_o \odot \tanh c_t
```

Or

```
h(t) = o(t) \otimes \tanh(c(t))
```

Now, in the process of backpropagation, if we follow the path from $h(t)$ to $h(t-1)$, as shown in *figure 7.10*:

![](img/7e519fee1b702b91799cdf1664598392_514_0.png)

Figure 7.10: Path of backpropagation in LSTM

Then, the backpropagation process here will already cover the Gradient $\frac{\partial E}{\partial h(t)}$ where $E$ is the cross-entropy loss error here. Therefore, we do not have to find out this part here, and hence, we need to find the gradients for $o(t)$ and $c(t)$, that is, $\nabla o(t)$ and $\nabla c(t)$.

So, let us calculate $\nabla o(t)$ first,

$\Delta o(t) = \frac{\partial E}{\partial o(t)}$

Applying the chain rule, we get the following:

$\Delta o(t) = \frac{\partial E}{\partial o(t)} = \frac{\partial E}{\partial h(t)} \times \frac{\partial h(t)}{\partial o(t)}$
$\Delta o(t) = \frac{\partial E}{\partial o(t)} = \nabla h(t) \times tanh(c(t))$

Thus,

$\Delta o(t) = \nabla h(t) \times tanh(c(t))$

Now, let us calculate $\nabla c(t)$,

$\Delta c(t) = \frac{\partial E}{\partial c(t)}$

Applying the chain rule, we get the following:

$\Delta c(t) = \frac{\partial E}{\partial c(t)} = \frac{\partial E}{\partial h(t)} \times \frac{\partial h(t)}{\partial c(t)}$
$\Delta c(t) = \frac{\partial E}{\partial c(t)} = \nabla h(t) \times o(t) \times (1 - tanh^2(c(t)))$

Therefore,

$\Delta c(t) = \nabla h(t) \times o(t) \times (1 - tanh^2(c(t)))$

So, the updated value of \(\Delta c(t)\) is given as follows:

\(\Delta c(t)_{updated} = \Delta c(t) + \nabla h(t) \times o(t) \times (1 - tanh^2(c(t)))\)

Now, let us derive the backpropagation w.r.t. (t); in the forward pass, we calculated the cell state output as follows:

\(c(t) = i(t) \times o(t) + f(t) \times c(t - 1)\)

Here, we need to find out the derivatives, such as \(\nabla i(t), \nabla o(t), \nabla f(t)\) and \(\nabla c(t - 1)\).

First, let us calculate \(\nabla i(t)\)

\(\Delta i(t) = \frac{\nabla E}{\nabla i(t)}\)

Applying the chain rule, we get the following:

\(\Delta i(t) = \frac{\nabla E}{\nabla i(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla c(t)}{\nabla i(t)}\)

Putting \(c(t) = i(t) \times o(t) + f(t) \times c(t - 1)\) in the preceding equation, we get the following:

\(\Delta i(t) = \frac{\nabla E}{\nabla i(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla (i(t) \times o(t) + f(t) \times c(t - 1))}{\nabla i(t)}\)

Differentiating, we get the following:

\(\Delta i(t) = \frac{\nabla E}{\nabla i(t)} = \Delta c(t) \times o(t)\)

Thus,

\(\Delta i(t) = \Delta c(t) \times o(t)\)

Now, let us calculate \(\nabla o(t)\)

\(\Delta o(t) = \frac{\nabla E}{\nabla o(t)}\)

Applying the chain rule, we get the following:

\(\Delta o(t) = \frac{\nabla E}{\nabla o(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla c(t)}{\nabla o(t)}\)

Putting \(c(t) = i(t) \times o(t) + f(t) \times c(t - 1)\) in the preceding equation, we get

\(\Delta o(t) = \frac{\nabla E}{\nabla o(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla (i(t) \times o(t) + f(t) \times c(t - 1))}{\nabla o(t)}\)

Differentiating, we get the following:

\(\Delta o(t) = \frac{\nabla E}{\nabla o(t)} = \Delta c(t) \times i(t)\)

Thus,

\(\Delta o(t) = \Delta c(t) \times i(t)\)

Now, let us calculate \(\nabla f(t)\)

\(\Delta f(t) = \frac{\nabla E}{\nabla f(t)}\)

Applying the chain rule, we get the following:

\(\Delta f(t) = \frac{\nabla E}{\nabla f(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla c(t)}{\nabla f(t)}\)

Putting \(c(t) = i(t) \times o(t) + f(t) \times c(t - 1)\) in the preceding equation, we get the following:

\(\Delta f(t) = \frac{\nabla E}{\nabla f(t)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla (i(t) \times o(t) + f(t) \times c(t - 1))}{\nabla f(t)}\)

Differentiating, we get the following:

\(\Delta f(t) = \frac{\nabla E}{\nabla f(t)} = \Delta c(t) \times c(t - 1)\)

Thus,

\(\Delta f(t) = \Delta c(t) \times c(t - 1)\)

Now, let us calculate \(\nabla c(t - 1)\)

\(\nabla c(t - 1) = \frac{\nabla E}{\nabla c(t - 1)}\)

Applying the chain rule, we get the following:

\(\nabla c(t - 1) = \frac{\nabla E}{\nabla c(t - 1)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla c(t)}{\nabla c(t - 1)}\)

Putting \(c(t) = i(t) \times o(t) + f(t) \times c(t - 1)\) in the preceding equation, we get the following:

\(\nabla c(t - 1) = \frac{\nabla E}{\nabla c(t - 1)} = \frac{\nabla E}{\nabla c(t)} \times \frac{\nabla (i(t) \times o(t) + f(t) \times c(t - 1))}{\nabla c(t - 1)}\)
