 c3 ]

But the output label $y$ with two bounding boxes will be as follows:

```
y_target = [ pc 
 bx 
 by 
 bw 
 bh 
 c1 
 c2 
 c3 
 pc 
 bx 
 by 
 bw 
 bh 
 c1 
 c2 
 c3 ]
```

Where the first eight rows consisting of $p_c, b_x, b_y, b_w, b_h, c_1, c_2,$ and $c_3$ show the parameters for first anchor box and the remaining eight rows consisting of $p_c, b_x, b_y, b_w, b_h, c_1, c_2,$ and $c_3$ show the parameters for second anchor box.

Hence, the objects are further assigned to the respective anchor boxes, which show similarity with the bounding boxes.

Now, if we observe the preceding figures, we can see that the shape of anchor Box 1 is similar to the shape of the car, so anchor Box 1 is assigned to the car, and the shape of anchor Box 2 is similar to the person, so anchor Box 2 is assigned to the person.

Because we are using two anchor boxes here; therefore, the output here will be of size $3 \times 3 \times 16$.
