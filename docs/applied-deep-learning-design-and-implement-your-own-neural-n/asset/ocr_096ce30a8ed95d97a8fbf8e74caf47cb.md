# Cycle GAN

We discussed in Pix-to-pix GAN, that image-to-image translation is a special type of conditional GAN, where instead of generating some random outputs, some kind of condition is applied to the input to generate target images. So, to translate images from one domain to another, the model needs to be trained on both the source and target image pairs. However, Cycle GAN made it possible to perform this translation in the absence of these image pair examples. So, Cycle GAN is turned out as a successful unpaired image-to-image translator that can be trained in a completely unsupervised manner.
