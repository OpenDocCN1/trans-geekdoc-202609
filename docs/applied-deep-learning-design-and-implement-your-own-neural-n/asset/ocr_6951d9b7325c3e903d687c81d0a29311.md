# # Regression loss function

Regression deals with the modeling of a linear relationship between multiple independent variables and one dependent variable.

# # Mean squared error loss function

Squared error loss is the square of the difference between the actual and predicted values:

```
L = (t – p)²
```

The corresponding cost function is the mean of these values of squared errors.

The mean squared error (MSE) loss function reduces the errors made by the model by squaring them. It is given as follows:

```
MSE = 1/n Σᵢⁿ (tᵢ – pᵢ)²
```
