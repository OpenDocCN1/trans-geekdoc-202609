Where d shows that the s<sub>i</sub> is of d-dimension of real numbers:

```
y<sub>i</sub> ∈ R<sup>k</sup>
```

Where k shows that output has k-classes. Therefore,

```
U ∈ R<sup>n*d</sup>
```

And

```
V ∈ R<sup>d*k</sup>
```

And

```
W ∈ R<sup>d*d</sup>
```
