The difference between a fully connected layer and a convolutional layer is that in the fully connected layer, each neuron is connected to each and every element of the input, and this neuron asks questions to each and every element of the input. In CNN, we are concerned about the images and pixel values in the images (intensity), which are highly correlated. The pixel values are not just random numbers. There exists a high spatial correlation between pixel elements. So, if we apply a fully connected layer on images, then first, we flatten this, and the filter embedded inside the weight parameters of the neuron asks the question to each and every input pixel, and the responses are collected. In these responses, most of the values are quite low or zero; only a few responses have high values of interest. Moreover, the flattening of input pixel values destroys spatial relationships among pixels up to a large extent. That is why to preserve spatial relationships and to retrieve only useful information, convolution layers are used in CNN. The process of convolution works in the neighborhood instead of the entire input. The hyperparameters associated with the convolutional network are the number of filters you want to apply and the size of each filter. If we want to see just a local region of an image, then we need a 3 × 3 filter. Else, if we want to see a global region, then we apply 5 × 5, 7 × 7, or any other large-size filter. - **Pooling layer:** The pooling layer performs down-sampling. It extracts the information obtained from the convolutional layer and preserves the most important information required to make the prediction. The unnecessary information is not carried forward for further processing in the next layers. The hyperparameters associated with pooling are Window size and Window stride. Pooling is used to reduce the size, the feature, or activation maps. For example, a feature map obtained after convolution of the size 224 x 224 x 3 can be reduced to 112 x 112 x 3 after applying pooling with some window size and stride.

- **Fully connected layer:** This layer connects every node of one layer to every node of another layer. This layer applies the weights over the output generated from the pooling layer to predict the correct label. The main aim of the fully connected layer is to take pooled feature maps from the pooling layer and use those feature maps for the classification of the image to predict a label. The hyper-parameters associated with fully connected layers are the number of fully connected layers and the number of neurons in each and every fully connected layer.

- **Output layer:** This layer generates the final value to predict the class of an image.

## Spatial filtering

Spatial filtering is a technique used in image processing to change the pixel intensity according to the neighborhood intensities. By using the process of spatial filtering, an input image is convoluted by using a Filter F having dimensions (x, y), where x is the height of the filter and y is the width of the filter. The mathematical equation (4.1) to find out the convolution of the input image I(i, j) is given as follows:

```
I'(i, j) = I(i, j) * F(x, y)  (4.1)
```

To understand spatial filtering, we need to understand two very important concepts about image processing, that is, correlation and convolution. In the next sub-sections, we discuss these in detail.

## Correlation

Correlation is the method of moving a filter or kernel over the spatial image to calculate the Sum of Products (SoP) at each location. It is the function of the displacement of the filter across the image. The process of correlation is shown in figure 4.8:

So, we can say that the first value of the correlation output relates to the zeroth (0th) displacement of the filter, as shown in figure 4.9:

And the second correlation output value corresponds to the first displacement, as shown in figure 4.10, and so on:

![](img/7e519fee1b702b91799cdf1664598392_231_0.png)

Figure 4.10: First displacement of the filter in 1-dimension.

Suppose we have an image $I$ and a kernel/filter $F$. Then, the mathematical representation of the cross-correlation for 1-D is given as follows.

```
F.I(x) = \Sigma_{i=-N}^{N} F(i)I(x+i) \qquad (4.2)
```

The cross-correlation in a 2D spatial image is very simple. Here, we first take a kernel of a specific size and locate the filter over a local region in the spatial domain of the image, and the size of the selected region is the same as that of the filter. This process is repeated by shifting the same filter over the entire region of the image.

Similarly, the mathematical representation of the correlation for 2-D is given as follows:

```
F.I(x,y) = \Sigma_{j=-N}^{N} \Sigma_{i=-N}^{N} F(i,j)I(x+i, y+j) \qquad (4.3)
```
