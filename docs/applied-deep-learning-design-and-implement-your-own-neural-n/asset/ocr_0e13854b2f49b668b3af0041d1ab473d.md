```
\frac{\partial C}{\partial m} = \frac{2}{n} \sum_{l=1}^n (y_i - (mx_i + b)) * (-x_i)
\frac{\partial C}{\partial m} = \frac{2}{n} \sum_{l=1}^n -x_i(y_i - (mx_i + b))
\frac{\partial C}{\partial m} = -\frac{2}{n} \sum_{l=1}^n x_i(y_i - (mx_i + b)) \quad (3.15)
```

Also,

```
\frac{\partial C}{\partial b} = \frac{\partial}{\partial b} \left[ \frac{1}{n} \sum_{l=1}^n (y_i - (mx_i + b))^2 \right]
```

By applying the following rule of differential calculus \(\frac{\partial f}{\partial x}(x^n) = n.x^{n-1} \cdot \frac{\partial}{\partial x}(x)\), we get the following equation:

```
\frac{\partial C}{\partial b} = \frac{1}{n} \sum_{l=1}^n 2 (y_i - (mx_i + b))^{2-1} * \frac{\partial}{\partial b}(y_i - mx_i - b)
\frac{\partial C}{\partial b} = \frac{1}{n} \sum_{l=1}^n 2 (y_i - (mx_i + b)) * (-1)
\frac{\partial C}{\partial b} = \frac{2}{n} \sum_{l=1}^n -(y_i - (mx_i + b))
\frac{\partial C}{\partial b} = -\frac{2}{n} \sum_{l=1}^n (y_i - (mx_i + b)) \quad (3.16)
```

\(\frac{\partial C}{\partial m}\) and \(\frac{\partial C}{\partial b}\) give the slope of the curve of gradient descent. It gives the direction, and for incrementing, a step-by-step learning rate is used. The following equations are used to find the optimal minima:

```
m_{current} = m_{current} - learning rate * \frac{\partial C}{\partial m} \quad (3.17)
b_{current} = b_{current} - learning rate * \frac{\partial C}{\partial b} \quad (3.18)
```

These equations tell us what change we would bring in m (slope) so that if we put it in \(y_{predicted} = mx_i + b\), it reduces loss as much as possible. The loss function is the measure of how much the predicted value resembles the actual value. If the loss is minimum, the model behaves well.
