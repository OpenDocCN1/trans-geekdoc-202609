
Now, for the logistic activation function, the maximum bound value that we can get is 0.25 or, say, ¼. Therefore, we can write,

$$\sigma'(a(i)) \le 0.25 = \beta$$

Hence,

$$\left\| \frac{\partial S(i)}{\partial S(i-1)} \right\| \le \beta . \|W\|$$

Let us take $\|W\|$ as $\alpha$, so we can write as follows

$$\left\| \frac{\partial S(i)}{\partial S(i-1)} \right\| \le \beta . \alpha$$

Now, let us take the product terms

$$\left\| \frac{\partial S_t}{\partial S_N} \right\| = \left\| \prod_{i=N+1}^{t} \frac{\partial S(i)}{\partial S(i-1)} \right\|$$

Therefore,

$$\frac{\partial S_t}{\partial S_N} \le \prod_{i=N+1}^{t} \beta . \alpha \quad (6.18)$$

Or

$$\frac{\partial S_t}{\partial S_N} \le (\beta . \alpha)^{t-N}$$

So, now if

$$\beta . \alpha << 1$$

The gradient will vanish for the preceding equation. And if

$$\beta . \alpha >> 1$$

The gradient will explode for the preceding equation.

So, if the gradient vanishes, there will be no updates to the weights, and if the gradient explodes, we can have a very large value of the gradient, which is not acceptable while training a neural network.

So, how do we avoid these two problems? Can you tell? One way of avoiding these two problems is by using the truncated backpropagation, in which we restrict the product of terms to $T$ (< t-N) terms, as shown in figure 6.81:

![](img/7e519fee1b702b91799cdf1664598392_490_0.png)

One more trick to avoid exploding gradient problem. Suppose we have a gradient vector whose magnitude is very large; that is,

$||\partial W|| >> 1$

One way is to normalize it in such a way that its magnitude becomes less than N, that is,

$||\partial W|| < N$

Now, let us summarize the solutions to avoid vanishing and exploding gradient problems. To avoid the exploding gradient problem, we can use the following methods:

- Use truncated backpropagation with time: As discussed previously, we can use truncated BPT to avoid the exploding gradient problem as instead of starting the process of back-propagation always at the last timestamp, we can choose a smaller time stamp to say 8.
- Adjust the learning rate using some methods, such as RMS propagation.
- Clip the gradients at threshold value:

Here, we perform clipping of the gradient if it goes higher than a threshold value.

And to avoid the vanishing gradient problem, we can use the following methods:

- Use ReLU activation function: As the bound of the ReLU function is 1, it gives the output as 1 while calculating the gradient, so we can use the ReLU activation function to solve this problem.
- Adjust the learning rate using some methods, such as RMS propagation.
- Using LSTMs and GRUs:

Some neural networks, such as GRUs and LSTMs, are specially designed to solve the problem of vanishing gradients in backpropagation with time.
