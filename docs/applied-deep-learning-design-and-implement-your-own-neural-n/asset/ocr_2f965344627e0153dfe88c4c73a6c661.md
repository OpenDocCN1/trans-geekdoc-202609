# The discriminator loss

During the training of the discriminator, it is trained on both the real and fake generated samples, with a label as a = 1 (real) and a = 0 (fake), respectively. While training on a real dataset, we have a = 1 (actual value) and p̂ = D(x) (predicted value), the output of the discriminator. Substituting these values in equation (8.2), we get the following:

Loss real (D(x), 1) = [log(D(x))]

And while training on generated samples, values are a=0 (actual value) and p̂ = D(G(z)) (predicted value). Substitute these values in equation (8.2), and we get the following:

Loss fake (D(G(z)), 0) = [log(1 – D(G(z)))]

The total loss at discriminator is the combined loss, that is:

D Loss = Loss real + Loss fake

So, combining equations (8.3) and (8.4), we get the following:

D Loss = [log(D(x)) + log(1 – D(G(z)))]

# The generator loss

Similarly, for the generator, the label for an actual value is zero and p̂ = D(G(z)). Substituting these values into equation (8.2), we get the following:

# Combined loss

G Loss = [log(1 – D(G(z)))]

Both the loss equations of the discriminator and generator are combined to formulate a general equation, to maximize the discriminator loss and minimize the generator loss:

Loss = D.Loss + G.Loss

Loss = minmax[logD(x) + log(1 – D(G(z)))]

G → D

Minmax V(G, D) = minmax[logD(x) + log(1 – D(G(z)))]
