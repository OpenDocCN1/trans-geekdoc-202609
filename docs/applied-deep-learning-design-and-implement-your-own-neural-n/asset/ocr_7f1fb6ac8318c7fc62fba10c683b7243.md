# Concept of stride in CNN

While performing the convolution operation, the filter is moved across the input image from top-to-bottom, left-to-right, with a pre-defined column change on the horizontal movement, followed by a predefined row change in the vertical movement.

The predefined amount of movement, the filter possesses the input image and is known as the stride. The default stride in two dimensions is (1,1) for horizontal and vertical movement. However, we can change the stride size accordingly. The size of the stride directly links with the size of the resultant feature map:
