# Faster RCNN

This algorithm is a modified form of the Fast RCNN algorithm. The main difference between Faster RCNN and Fast RCNN is that the Faster RCNN algorithm uses the region-proposal network to generate RoI as compared to the Fast TCNN, which uses a selective search algorithm.

Region-proposal network takes input as the feature maps of the input image and provides object proposals having a score of objectness as output. Let us understand Faster RCNN in the following steps. The architecture of Faster RCNN is shown in figure 5.61:

+   - First, an input image is passed through ConvNet, which provides feature maps.
+   - Then, these feature maps are passed through the region proposal network which provides the object proposals along with the score of objectness.
+   - Furthermore, these object proposals are passed through an RoI pooling layer which converts the size of these proposals into a specified fixed size.
+   - Then, the output from the RoI pooling layer is passed through a fully connected layer having a SoftMax and regression layer to predict the bounding box, as shown in figure 5.62.
