## Forward pass

The forward pass is the process of computing the values of the mathematical equations denoted by the computational graphs. Undertaking the forward pass states that we pass the values from the variables toward the forward direction, that is, from the input (left) to the output (right).

Let us take an example by assigning some value to all the input variables. Assume that the following values have to be assigned to all of the input variables.

```
x = 1; y = 2; z = 3
```

By assigning the following values to the input variables, we can execute a forward pass and get the result in the following values of the output variables on every node.

First, we use the value of x = 1 and y = 2 and get q = 3 as follows. The computational graph looks as follows:

## Backward pass

While in the backward pass, our purpose is to calculate the gradients for every input with respect to the final value of the output. The gradients are crucial while training the neural network by using gradient descent.

Let us take an example where we are looking for the following value of gradients:

\(\frac{\partial h}{\partial x}; \frac{\partial h}{\partial y}; \frac{\partial h}{\partial z}\)

We first start the backward pass by determining the derivative of the final value of the output with respect to the final value of the output itself. Hence, it ends up as the identity derivation with the final value as one.

\(\frac{\partial h}{\partial h} = 1\)

So, the computational graph looks as follows:

![](img/7e519fee1b702b91799cdf1664598392_190_0.png)

Figure 3.31: Computational graph for the backward pass

Also, we perform the backward pass by using the * operator. Here, we computed the value of the gradients at q and z. Since h = q*z, we know that:

\(\frac{\partial h}{\partial z} = q\)

\(\frac{\partial h}{\partial q} = z\)

Also, we already know the values of z and q from the forward pass. Therefore, we get the following:

```
\frac{\partial h}{\partial z} = 3
```

And

```
\frac{\partial h}{\partial q} = 3
```

Also, we compute the value of gradients at x and y, respectively, as follows:

```
\frac{\partial h}{\partial x}; \frac{\partial h}{\partial y}
```

Even though x and h are only two hops located away in the graph (figure 3.31). So to compute the values proficiently, we will use the differentiation chain rule. By applying the chain rule, we get as follows:

```
\frac{\partial h}{\partial x} = \frac{\partial h}{\partial q} * \frac{\partial q}{\partial x}
\frac{\partial h}{\partial y} = \frac{\partial h}{\partial q} * \frac{\partial q}{\partial y}
```

But we know that the value of \frac{\partial h}{\partial y}=3, \frac{\partial q}{\partial x} and \frac{\partial q}{\partial y} are easy since q depends on x and y directly.

```
q = x + y =>> \frac{\partial q}{\partial x} = 1, \frac{\partial q}{\partial y} = 1
```

Therefore, we get the following:

```
\frac{\partial h}{\partial x} = \frac{\partial h}{\partial q} * \frac{\partial q}{\partial x} = 3 * 1 = 3
```

Also, for the input y:

```
\frac{\partial h}{\partial y} = \frac{\partial h}{\partial q} * \frac{\partial q}{\partial y} = 3 * 1 = 3
```
