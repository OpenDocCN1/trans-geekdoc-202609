# K-means clustering

Download and import a dataset *iris* by using the following link:

https://gist.github.com/netj/8836201

Type the following command on the R-console:

```
iris <- read.csv("E:/R-programs/iris.csv")
View(iris)

iris.features = iris

iris.features$variety <- NULL

View(iris.features)

results <- kmeans(iris.features, 3)

results
```
