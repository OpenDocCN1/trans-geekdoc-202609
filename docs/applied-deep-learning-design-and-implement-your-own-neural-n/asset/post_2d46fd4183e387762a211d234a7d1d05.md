f(x) = max(0, x) (3.70)

So, the aim of the ReLU function is to remove the negative values. It provides output as x if x is positive and 0 if the value of x is negative.

## Leaky ReLU activation function

ReLU is also not free from drawbacks, some of which are the following:

- ReLU is non-zero-centered.
- It is not differentiable at zero.

Apart from these drawbacks, the ReLU activation function also has a major issue named as Dying ReLU problem, where some ReLU neurons die for all inputs and remain inactive no matter what input is supplied.

Hence, no gradient flows, and if a large number of dead neurons are there in a neural network, then its performance is affected, which can be corrected by making use of Leaky ReLU such that its slope is changed left of x = 0 (that is, on negative axis), which results in a leak and leads to an extension in the range of ReLU.

Leaky ReLU is an attempt to fix the Dying ReLU problem. Instead of the function being zero when x < 0, a leaky ReLU will instead have a small negative slope of 0.01, as f(x) = 0.01x (Leaky ReLU) and f(x) = αx (Parametric ReLU). The range of ReLU is

## Tanh activation function

Tanh or tangent hyperbolic function is similar to the sigmoid activation function but works better than the sigmoid function. This function is basically the mathematically-shifted kind of the sigmoid activation function. However, both are analogous and can be derived using each other:

```
$f(x) = \tanh(x) = \frac{2}{1+e^{-2x}} - 1$ (3.71)
```

The output of tanh activation function varies from -1 to 1. Similar to the sigmoid activation function, tanh is also sigmoidal in shape.

Both tanh and sigmoid activation functions are commonly used in feed-forward nets.

## Softmax activation function

Softmax activation function turns logits into probabilities by computing the exponents of every output and normalize each of the numbers by using the sum of the calculated exponents, such that the final output vector adds up to one (1). The sum of all the probabilities is also one (1).

> “Logits” is defined as the numerical output of the final linear layer of a multi-class neural network.

The softmax function is generally applied at the last layer of the neural network. The equation for the softmax function is given as follows:

S(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}} (3.72)

Example 3.6: Let logits scores be: \vec{v} = {2.0, 1.0, 0.1}

- 1. For x = 2.0, \Sigma_j = 3.1.
  
  S(x_i) = \frac{e^2}{\sum_j e^{3.1}}
  
  S(x_i) = 0.7

- 2. For x = 1.0, \Sigma_j = 3.1.
  
  S(x_i) = \frac{e^1}{\sum_j e^{3.1}}
  
  S(x_i) = 0.2

- 3. For x = 0.1, \Sigma_j = 3.1.
  
  S(x_i) = \frac{e^{0.1}}{\sum_j e^{3.1}}
  
  S(x_i) = 0.1

## Parametric ReLU activation function

Parametric ReLU (PReLU) is another type of leaky ReLU activation function which, instead of having a predefined slope as 0.01, adjusts it by a parameter of the neural network: \(\alpha x, x < 0\). Figure 3.45 depicts the plot of the Parametric ReLU activation function:

```
\( f(x) = \begin{cases} \alpha x, x < 0 \\ x, x \ge 0 \end{cases} \) (3.74)

\( f'(x) = \begin{cases} \alpha, x < 0 \\ 1, x \ge 0 \end{cases} \)
```

## Exponential ReLU activation function

Similar to leaky ReLU, exponential ReLU has a small slope for negative values. Figure 3.46 shows the plot of the exponential ReLU activation function:
