\(= \frac{1}{1 + \frac{exp(w_0^T x)}{exp(w_1^T x)}}\)

\(= \frac{1}{1 + exp(w_0 - w_1)^T x}\)

\(p(y = 0|x) = \frac{exp(0.306)}{exp(0.306) + exp(1.166)}\)

\(p(y = 1|x) = 1 - p(y = 0|x)\)

\(p(y = 1|x) = 1 - 0.30 = 0.70\)
