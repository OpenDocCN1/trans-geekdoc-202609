
To make an update into the parameters, we need to take the gradient of the present parameters and then multiply it with the learning rate. Here, the learning rate decides how fast we go to the global minima.

## ADAGRAD

ADAGRAD descent algorithm uses an adaptive technique to update the learning rate. Depending upon the previous iterations of the change in gradient, the learning rate is updated as follows. Pseudo-code for the ADAGRAD descent algorithm is given as follows:

```
gradient_component = previous_gradient_component + (gradient * gradient)
learning_rate_change = square root(grad_component) + epsilon
adapted learning_rate = learning rate * learning_rate_change
update = adapted learning rate(alpha) * gradient of the parameters
parameter(new) = parameter(old) – update
```

where epsilon is a constant that is used to keep the rate of change of the learning rate in check.

## Vanishing and exploding gradient problems

Sometimes gradient keeps on decreasing layer by layer. When the number of layers is too large, the gradient becomes so small that it cannot be used. This problem is called as vanishing gradient problem. While on the other hand, if the gradient increases by a very large value during training such that it overshoots the global minima of the gradient curve, then this situation leads to an exploding gradient problem.

## Backpropagation in neural networks

Backpropagation algorithm is an artificial neural network algorithm in which the information flows in the forward direction, but the propagation error flows in the backward direction. The backpropagation algorithm was originally proposed in the 1970s, but it gained popularity through a publication by Rumelhart et al. in 1986. Figure 3.22 shows a back propagation neural network with a single hidden layer:

![](img/7e519fee1b702b91799cdf1664598392_169_0.png)

Figure 3.22: Backpropagation in neural network

The backpropagation includes the following components:

- Weights initialization and adjustment / updation using the gradient descent.
- Forward propagation in the network to determine the output values.
- Error calculation using the defined loss function.
- If the error is huge, we have to backpropagate and adjust the weights using gradient descent and then again propagate forward and check the error until global minima are not achieved.
- If we want to achieve good learning, we try to retain cost function as a minimum.

## Derivation of backpropagation in neural networks with loss function as binary cross entropy loss function

The main objective of the model is to minimize or optimize the loss function. The cross-entropy loss function for the linear regression is given as follows:

```
L = -\frac{1}{N} \sum_i [y_i log(a_i) + (1 - y_i) log(1 - a_i)] (3.19)
```

Where y_i is the targeted value and a_i is the predicted value:

```
z = wx_i + b
```

Also,

```
a_i = \sigma(z_i)
a_i = \frac{1}{1 + e^{-z_i}}
```

By applying the chain rule:

```
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} * \frac{\partial a}{\partial z} * \frac{\partial z}{\partial w} (3.20)
```

Now,

```
\frac{\partial z}{\partial w} = \frac{\partial}{\partial w}(wx_i + b)
\frac{\partial z}{\partial w} = x_i (3.21)
```

Therefore, by substituting equation (3.21) in equation (3.20), we get equation (3.22):

```
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} * \frac{\partial a}{\partial z} * x_i (3.22)
```

Also, as a_i = \sigma(z_i),

```
\frac{\partial a}{\partial z} = \frac{\partial}{\partial z}(\sigma(z_i))
\frac{\partial a}{\partial z} = \frac{\partial}{\partial z}\left(\frac{1}{1 + e^{-z_i}}\right)
\frac{\partial a}{\partial z} = \frac{\partial}{\partial z}\left(\frac{1}{1+e^{-z_i}}\right) (3.23)
```

We know that:

```
\frac{\partial}{\partial x}\left[\frac{f(x)}{g(x)}\right] = \frac{g(x)(\frac{\partial}{\partial x}(f(x))-f(x)(\frac{\partial}{\partial x}(g(x)))}{(g(x))^2} (3.24)
```

Similarly,

$$
\frac{\partial}{\partial z}\left(\frac{1}{1+e^{-z_i}}\right) = \frac{\left[(1+e^{-z}) * \frac{\partial}{\partial z}(1) - 1 * \frac{\partial}{\partial z}(1+e^{-z})\right]}{[(1+e^{-z})^2]}
$$

$$
= \frac{(1+e^{-z}) * 0 - \left[\frac{\partial}{\partial z}(1) + \frac{\partial}{\partial z}(e^{-z})\right]}{[(1+e^{-z})^2]}
$$

$$
\frac{\partial a}{\partial z} = \frac{\partial}{\partial z}\left(\frac{1}{1+e^{-z_i}}\right) = \frac{e^{-z}}{(1+e^{-z})^2} \quad (3.25)
$$

As from equation (3.19), we know that:

$$
L = -\frac{1}{N} \sum_i [y_i log(a_i) + (1-y_i) log(1-a_i)]
$$

Considering derivative w.r.t and base of we get the following equation:

$$
\frac{\partial L}{\partial a} = \frac{\partial}{\partial a}\left(-\frac{1}{N} \sum_i y_i log_e(a_i) + (1-y_i) log_e(1-a_i)\right)
$$

$$
\frac{\partial L}{\partial a} = -\frac{1}{N} \sum_i \left[ \left(\frac{\partial}{\partial a} (y_i log_e(a_i))\right) + \left(\frac{\partial}{\partial a} ((1-y_i) log_e(1-a_i))\right) \right] \quad (3.26)
$$

To calculate $\frac{\partial L}{\partial a}$ first differentiating the first part of the equation (3.26), that is $y_i log(a_i)$ with respect to a, we get the following:

$$
\frac{\partial}{\partial a} (y_i log_e(a_i))
$$

As
$$
\frac{\partial}{\partial x} [f(x) \times g(x)] = f(x). \frac{\partial}{\partial x} (g(x)) + \frac{\partial}{\partial x} (f(x)). g(x)
$$

$$
\frac{\partial}{\partial a} (y_i log_e(a_i)) = y_i * \frac{\partial}{\partial a} (log_e(a_i)) + \frac{\partial}{\partial a} (y_i) * log_e(a_i) \quad (3.27)
$$

As $\frac{\partial}{\partial a} (log_a x) = \frac{1}{x log_e a} \cdot \frac{\partial x}{\partial a}$ and $\frac{\partial}{\partial a} (y_i) = 0$ as $y_i$ is constant $\frac{\partial}{\partial a} (constant) = 0$

Applying this in equation (3.27), we get the following:

$$
\frac{\partial}{\partial a} (y_i log_e(a_i)) = y_i * \frac{1}{a_i * log_e(e)} * \frac{\partial a_i}{\partial a} + 0 * log_e(a_i)
$$

$$
\frac{\partial}{\partial a} (y_i log_e(a_i)) = y_i * \frac{1}{a_i * log_e(e)} * 1 + 0 * log_e(a_i)
$$

As $log_e(e) = 1$, we get the following after substituting this in the preceding equation:

$$
\frac{\partial}{\partial a} (y_i log_e(a_i)) = \frac{y_i}{a_i} + 0
$$

$$
\frac{\partial}{\partial a} (y_i log_e(a_i)) = (\frac{y_i}{a_i})$$ (3.28)

Further, differentiating the second part of equation (3.26), that is, $(1 - y_i) log_e(1 - a_i)$ with respect to a, we get as follows:

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)]
$$

As

$$
\frac{\partial}{\partial x} [f(x) \times g(x)] = f(x). \frac{\partial}{\partial x} (g(x)) + \frac{\partial}{\partial x} (f(x)). g(x)
$$

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = (1 - y_i) * \frac{\partial}{\partial a} [log_e(1 - a_i)] + \frac{\partial}{\partial a} [(1 - y_i)] * log_e(1 - a_i)
$$

As $[(1 - y_i)]$ is a constant, so $\frac{\partial}{\partial a} [(1 - y_i)] = 0$ as $\frac{\partial}{\partial a} [(constant)] = 0$, applying this, we get the following equation:

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = (1 - y_i) * \frac{\partial}{\partial a} [log_e(1 - a_i)] + 0 * log_e(1 - a_i)
$$

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = (1 - y_i) * \frac{\partial}{\partial a} [log_e(1 - a_i)] + 0
$$

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = (1 - y_i) * \frac{\partial}{\partial a} [log_e(1 - a_i)]$$ (3.29)

As $\frac{\partial}{\partial a} (log_a x) = \frac{1}{x log_e a} . \frac{\partial x}{\partial a}$, applying this in equation (3.29), we get the following:

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = (1 - y_i) * \frac{1}{(1 - a_i) * log_e e} * \frac{\partial}{\partial a} (1 - a_i)
$$

As $log_e(e) = 1$ and $\frac{\partial}{\partial a} (1 - a_i) = -1$, by substituting these in the preceding equation, we get the following equation (3.30):

$$
\frac{\partial}{\partial a} [(1 - y_i) log_e(1 - a_i)] = - \left( \frac{(1-y_i)}{(1-a_i)} \right)$$ (3.30)

Therefore, after substituting the values of equation (3.28) and equation (3.30) in equation (3.26), we get the following:

$$
\frac{\partial L}{\partial a} = - \frac{1}{N} \sum_i \left( \frac{y_i}{a_i} - \frac{(1-y_i)}{(1-a_i)} \right)$$ (3.31)
