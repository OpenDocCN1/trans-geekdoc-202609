# 2. Installing Libraries in Python

Open the Anaconda prompt and type the following commands:

+   - Numpy
+     pip install numpy
+   - Theano
+     conda install theano
+   - Keras
+     pip install keras
+   - TensorFlow
+     pip install tensorflow
+   - Pandas
+     pip install pandas
+   - SciPy
+     pip install scipy
+   - PyTorch
+     conda install pytorch -c pytorch
+   - Matplotlib
+     pip install matplotlib
+   - scikit-learn
+     pip install scikit-learn

# 3. Hello World in Python

After installation of Python, open Python and create a new file and type the following command:

```
print ("Hello World")
```

Save and run the program. You will see the following output:

```
In [2]: runfile('E:/python/hello.py', wdir='E:/python')
Hello World
```
