Figure 4.155 shows the list of random feature values for some images. The objective is that the trained model predicts this as either X or O. So for prediction, voting is done. The high responses (shown by black and green bold lies) in the trained model contribute more for voting, as shown in figures 4.155 to 4.156. The voting for X is calculated as (0.90+0.87+0.96+0.89+0.94)/5 = 0.92 (only high responses (bold black lines) are used for voting). Refer to *figure 4.157*. Similarly, voting for O is calculated as (0.65+0.45+0.44+0.53)/4 = 0.51 (only high responses (bold green lines)are used for voting). Refer to *figure 4.158*.

Finally, X has the higher voting, so X wins, which means that the image shown to the trained network is classified in category X as it has a higher probability than O (figures 4.159 and 4.160). In this way, CNN works. One more thing that is left in CNN is how it automatically trains its filters. The answer to this is **backpropagation**.
