## Multi-class classification loss function

Multi-class classification in machine learning space is defined as the problem of categorizing instances into three or more classes. (As discussed earlier, categorizing instances into two classes is termed as binary classification.)

E-mail is an example of multi-class classification as they are not just classified as no spam or spam (which was in the 1990s!). Now, we can classify e-mails into various other categories also, such as Home, Work, Promotions, Forums, Social, and so on.

## Multi-class cross-entropy loss

The multi-class cross-entropy loss function is a simplification of the binary cross-entropy loss function. The loss for input vector X and the corresponding one-hot encoded target vector t is defined as follows:

\( L(X_i, t_i) = - \sum_{j=1}^n t_{ij} * \log(p_{ij}) \)

where \( t_i \) in the preceding equation is a one-hot encoded vector (\( t_{i1}, t_{i2}, ...... t_{in} \)),

\( t_{ij} = \left\{ \begin{array}{ll} 1, & \text{if the element } i^{th} \text{is in class } j \\ 0, & \text{otherwise} \end{array} \right. \)

\( P_{ij} \) is the probability that the i\(^{th}\) element is in class j.

## KL divergence

KL divergence, also known as _Kullback-Leibler Divergence_, is a measure of the difference between the probability distribution to the other distribution.

For probability distributions R and S, KL divergence of R from S is given by the following:

\( D_{KL}\left(\frac{R}{S}\right) = \left\{ \begin{array}{ll} - \sum_x R(x) \log \frac{S(x)}{R(x)} = \sum_x R(x) \log \frac{R(x)}{S(x)}, & \text{for discrete distributions} \\ - \int R(x) \log \frac{S(x)}{R(x)} . dx = \int R(x) \log \frac{R(x)}{S(x)} . dx, & \text{for continuous distributions} \end{array} \right. \)

## Confusion matrix

In machine learning, a confusion matrix is also termed as error matrix. The confusion matrix is denoted as a table that is used to define the classification model performance on a set of test data at which we have the known true or correct values.

It also permits the conception of the algorithm performance as it also permits easy recognition of a type of confusion among classes. For example, say one class is mislabeled with respect to the other class. Most of the measures of performance are defined from the confusion matrix.

The confusion matrix is basically a summary of the results of predicted results for a classification-type problem. Here, the number of incorrect and correct predictions is described with a number of count values and then further shattered down by each of the classes.

The confusion matrix depicts the number of ways in which the model for classification is confused while making the predictions. It also gives us a vision that not only the faults being made by a classifier are important, but also the different types of errors that are made are important.

| No. of instances | Class 1 – prediction | Class 2 – prediction |
|------------------|----------------------|----------------------|
| Actual – Class A | FP                   | TN                   |
| Actual – Class B | TP                   | FN                   |

### Table 2.9: Confusion matrix syntax

Where TP depicts True Positive

FP depicts False Positive

TN depicts True Negative

FN depicts False Negative

The description of the terms linked with the confusion matrix are as follows:

- True Positives (TP): It is the case when both the actual class and predicted class is 1.
- True Negatives (TN): It is the case when both the actual class and predicted class is 0.
- False Positives (FP): It is the case when the actual class is 0, and the predicted class of data point is 1.
- False Negatives (FN): It is the case when the actual class is 1, and the predicted class of the data point is 0.

## Accuracy

Accuracy in machine learning is defined as the total number of correct predictions done by a machine learning model. It can be easily calculated using the parameters of the confusion matrix.

$$A = \frac{TN + TP}{TN + TP + FN + FP}$$

## Precision

Precision is defined as the total number of correct documents returned by the machine learning model. Like accuracy, it can also be calculated using the parameters of the confusion matrix as follows:

$$P = \frac{TP}{TP + FP}$$

## Recall or sensitivity

Sensitivity can be defined as the total number of positives or true values returned by the machine learning model. Sensitivity can be calculated by using the parameters of the confusion matrix as follows:

$$S = \frac{TP}{TP + FN}$$

## Specificity

In contrast to sensitivity, specificity is defined as the total number of negative or false values returned by our machine learning model. Using confusion matrix parameters, it can be calculated as follows:

$$Sc = \frac{TN}{TN + FP}$$

## F-measure

In the case of binary classification, the F-measure is a measure of a test’s accuracy. It is calculated from the precision and recall of the test, where the precision is the number of true positive results divided by the number of all positive results, including those not identified correctly, and the recall is the number of true positive results divided by the number of all samples that should have been identified as positive.
