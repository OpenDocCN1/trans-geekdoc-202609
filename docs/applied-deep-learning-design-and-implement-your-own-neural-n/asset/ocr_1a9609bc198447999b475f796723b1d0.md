With respect to each and every filter, there exists an activation map or feature map. Here, there are three filters. So, the number of activation maps is also three, which represents different patterns of an image. Each filter is asking a question to the pixel as, for example, are you a diagonal element, or are you a middle pixel? In return, every pixel generates a response accordingly. If, for example, a corresponding pixel is an element of diagonal, then it generates a high response during the first convolution layer (see position (1,1) or (2,2) in the first activation map on RHS). Similarly, check for the high responses for the second and third activation maps in figure 4.135. Moreover, figures 4.136 and 4.137 shows the same image as in figure 4.135 but are represented in an abstract form. Also, the responses in these activation maps are aggregated, and that aggregated value acts as an input to the next convolutional layer in CNN. The aggregation is done by aggregating the responses of the first filter, second filter, and third filter for the same pixel (x,y).
