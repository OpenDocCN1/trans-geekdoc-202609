So, as we have seen, fast RCNN addresses the problems faced by the RCNN algorithm effectively, but even the fast RCNN algorithm has certain limitations. Fast RCNN also uses a selective search algorithm which is again slow and takes time to generate RoI.

However, it generally takes around 2–3 seconds to detect objects per image; thus, much better than the RCNN algorithm. But when we talk about large datasets, even the Fast RCNN algorithm does not work that fast. So, we have another algorithm to combat this issue known as the Faster RCNN algorithm.
