
For MLE, it is convenient to maximize the log of L rather than L itself. A log is a monotonically increasing function, the following holds:

$$
\log L = \sum_{n=1}^N \log\left[\frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(\frac{-1}{2\sigma^2}(t_n - y_n)^2\right)\right]
$$

As

$$
\log (m * n) = \log m + \log n
$$

Applying equation (3.8) in equation (3.7), we get as follows:

$$
\log L = \sum_{n=1}^N \left[\log \frac{1}{\sqrt{2\pi\sigma^2}} + \log\left(\exp\left(\frac{-1}{2\sigma^2}(t_n - y_n)^2\right)\right)\right]
$$

$$
\log L = \sum_{n=1}^N \left[\log \frac{1}{\sqrt{2\pi\sigma^2}} + \frac{-1}{2\sigma^2}(t_n - y_n)^2\right]
$$

$$
(\log L) = \sum_{n=1}^N C_1 - C_2 \sum_{n=1}^N (t_n - y_n)^2
$$

Where, \( C_1 = \log \frac{1}{\sqrt{2\pi\sigma^2}} \) (constant_1) and \( C_2 = \frac{-1}{2\sigma^2} \) (constant_2). As \( t_n \) (target) and \( y_n \) (predicted) are as close to each other as possible, the value of the squared error function \( \sum_{n=1}^N(t_n - y_n)^2 \) becomes minimum. Hence, as the amount of squared error function gets reduced, the value of log-likelihood is maximum as per the equation \( (\log L) = \sum_{n=1}^N C_1 - C_2 \sum_{n=1}^N(t_n - y_n)^2 \). Finally, to minimize the value of squared error function, the values of \( t_n \) and \( y_n \) must be close to each other. Moreover, if the predicted value is near to actual value, then it leads to maximum log-likelihood.

In binary classification, we use binary cross-entropy cost function instead of squared error.

$$
L = -\frac{1}{N} \sum_{n=1}^N t_n \log(y_n) + (1 - t_n) \log(1 - y_n)
$$

Log-likelihood equivalence of binary cross-entropy is as follows:

$$
t_n \sim \text{Bernoulli}(y_n)
$$

$$
L = \prod_{n=1}^N y_n^{t_n} * (1 - y_n)^{(1-t_n)}
$$

$$
-\log(L) = - \sum_{n=1}^N t_n \log(y_n) + (1 - t_n) \log(1 - y_n)
$$

### Categorical cross-entropy loss function using Bernoulli's distribution

MLE for a dice roll is given by the following:

{1, 1, 6, 3, 2, 5, 4, 3}

t(n, k) = 1, if we rolled k on the nth roll as follows:

t(1, 1) = 1
t(2, 1) = 1
t(3, 6) = 1

PMF of categorical distributions is as follows:

$$
L = \prod_{n=1}^N \prod_{k=1}^6 w_k^{t_{nk}} \tag{3.11}
$$

$$
L = \prod_{n=1}^N \prod_{k=1}^6 w_k^{t_{nk}}
$$

Categorical cross-entropy loss is given by the following:

$$
L = \sum_{n=1}^N \sum_{k=1}^6 t_{nk} \log y_{nk} \tag{3.12}
$$

$$
\text{Loss} = - \sum_{k=1}^6 t_k \log y_k \tag{3.13}
$$

For (1, 1)

$$
\text{Loss} = (-1) \log(1) = 0
$$

For (1, 0.5)

$$
\text{Loss} = (-1) \log(0.5) = 0.65
$$

For (1, 0.25)

$$
\text{Loss} = (-1) \log(0.25) = 1.356
$$

For (1, 0)

$$
\text{Loss} = (-1) \log(0) = \infty
$$

## Gradient descent for linear regression

A problem is said to be a regression problem when the input variable is continuous or has real value. For example, weight, the salary of an employee, and so on.

Linear regression is a type of regression that fits information with the best suitable hyper-plane. It is defined as a linear approach for modeling the relationship between independent and dependent variables. Figure 3.21 shows the pattern obtained in linear regression:

![](img/7e519fee1b702b91799cdf1664598392_164_0.png)

### Figure 3.21: Linear regression

In the case of linear regression, the model aims to get the regression line (best-fit) for the prediction of the value of Y based on the given input value X. During the training period, and the model determines the cost function to compute the Root Mean Squared (RMS) error between the actual obtained value (y) and the predicted value (p).

$$
C = \text{MSE} = \frac{1}{n}\sum_{i=1}^n(y_i - y_{\text{predicted}})^2 \tag{3.14}
$$

$$
y_{\text{predicted}} = mx_i + b
$$

Substituting value of \( y_{\text{predicted}} \) in equation (3.14), we get the following:

$$
C = \text{MSE} = \frac{1}{n}\sum_{i=1}^n (y_i - (mx_i + b))^2
$$

By applying the following rule of differential calculus \(\frac{\partial f}{\partial x}(x^n) = n.x^{n-1} \cdot \frac{\partial}{\partial x}(x)\), we get the following equation:

$$
\frac{\partial C}{\partial m} = \frac{1}{n}\sum_{i=1}^n 2 (y_i - (mx_i + b))^{2-1} * \frac{\partial}{\partial m}(y_i - mx_i - b)
$$

$$
\frac{\partial C}{\partial m} = \frac{1}{n}\sum_{i=1}^n 2 (y_i - (mx_i + b)) * (-x_i)
$$

$$
\frac{\partial C}{\partial m} = \frac{2}{n} \sum_{i=1}^n (y_i - (mx_i + b)) * (-x_i)
$$

$$
\frac{\partial C}{\partial m} = \frac{2}{n} \sum_{i=1}^n -x_i(y_i - (mx_i + b))
$$

$$
\frac{\partial C}{\partial m} = -\frac{2}{n} \sum_{i=1}^n x_i(y_i - (mx_i + b)) \tag{3.15}
$$

Also,

$$
\frac{\partial C}{\partial b} = \frac{\partial}{\partial b} \left[ \frac{1}{n} \sum_{i=1}^n (y_i - (mx_i + b))^2 \right]
$$

By applying the following rule of differential calculus \(\frac{\partial f}{\partial x}(x^n) = n.x^{n-1} \cdot \frac{\partial}{\partial x}(x)\), we get the following equation:

$$
\frac{\partial C}{\partial b} = \frac{1}{n} \sum_{i=1}^n 2 (y_i - (mx_i + b))^{2-1} * \frac{\partial}{\partial b}(y_i - mx_i - b)
$$

$$
\frac{\partial C}{\partial b} = \frac{1}{n} \sum_{i=1}^n 2 (y_i - (mx_i + b)) * (-1)
$$

$$
\frac{\partial C}{\partial b} = \frac{2}{n} \sum_{i=1}^n -(y_i - (mx_i + b))
$$

$$
\frac{\partial C}{\partial b} = -\frac{2}{n} \sum_{i=1}^n (y_i - (mx_i + b)) \tag{3.16}
$$

\(\frac{\partial C}{\partial m}\) and \(\frac{\partial C}{\partial b}\) give the slope of the curve of gradient descent. It gives the direction, and for incrementing, a step-by-step learning rate is used. The following equations are used to find the optimal minima:

$$
m_{\text{current}} = m_{\text{current}} - \text{learning rate} * \frac{\partial C}{\partial m} \tag{3.17}
$$

$$
b_{\text{current}} = b_{\text{current}} - \text{learning rate} * \frac{\partial C}{\partial b} \tag{3.18}
$$

These equations tell us what change we would bring in m (slope) so that if we put it in \(y_{\text{predicted}} = mx_i + b\), it reduces loss as much as possible. The loss function is the measure of how much the predicted value resembles the actual value. If the loss is minimum, the model behaves well.

The pseudo-code to compute the gradient descent for linear regression is given as follows:

```
m_current = b_current = 0;
for i in range(iterations);
y_predicted = m_current * x + b_current;
cost = 1/n * sum(for value in y - y_predicted);
md = -2/n * sum(x * (y - y_predicted));
bd = -2/n * sum((y - y_predicted));
m_current = m_current - learning rate * md;
b_current = b_current - learning rate * bd;

print("m_curr = , b_curr=, iteration =, md =, bd =, cost= ", m_curr, b_curr, i, md, bd, cost);
```

## Different types of gradient descent algorithms

Following are the various gradient descent algorithms. It includes the vanilla descent algorithm, ADAGRAD, exploding and vanishing gradients.

### Vanilla Descent algorithm

The vanilla descent algorithm is one of the simplest gradient descent techniques. The word *vanilla* stands for purity or without any contamination. In the vanilla descent algorithm, we take small steps toward the direction of the global minima by determining the gradient of the cost function.

Pseudo-code for the vanilla descent algorithm is given as follows:

```
update = learning rate(α) * gradient of the parameters
parameter(new) = parameter(old) - update
```
