# # Vanilla LSTM

A simple LSTM architecture is termed as Vanilla LSTM. In this architecture, a single LSTM hidden layer is used along with the memory cell of that layer.

It consists of the following layers:

+   - Input layer
+   - LSTM hidden layer
+   - Dense layer
+   - Output layer
