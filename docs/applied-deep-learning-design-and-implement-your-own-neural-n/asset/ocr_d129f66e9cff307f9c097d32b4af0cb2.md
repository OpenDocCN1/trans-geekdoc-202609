# # Least-square GAN loss

LSGAN loss function is also showing lots of scope in improved GAN training. The original GAN paper uses the log loss in the min-max loss function, and LSFAN uses the L2 loss. Here, the loss incurred for real samples is less than the fake ones. This loss function penalizes those data points that are not according to the required distribution. That means larger error, meaning penalty, and finally, the larger scope for updating the weights rather than vanishing the gradient. Thereby, it guarantees better gradient information for model training.
