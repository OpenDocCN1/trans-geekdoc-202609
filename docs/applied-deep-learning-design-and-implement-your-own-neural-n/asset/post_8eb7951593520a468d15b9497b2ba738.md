The term object recognition is used to define a group of computer vision tasks that involves recognizing different types of objects in a digital image. Object recognition is one of the important applications of deep learning.

Figure 5.6 shows an example of image classification that detects the label of cat. But how this image classification is performed? To predict a label from an image, there is a specific image classification pipeline to be followed, which is given as follows:

- **Input section**: The input section consists of a set of M images, where each image is labeled as a different L number of classes. This set is termed the training-set.
- **Learning section**: This section is used to learn or train the model as to how each class looks like using the training dataset. This step is referred to as classifier-training.
- **Evaluation section**: In this section, the evaluation of the model is performed by providing the model with a new set of images known as test-dataset and asking the classifier to predict the labels of different images.

## Image classification using CNN

CNN can be used for image classification. Here are the steps to be followed while using image classification using CNN:

- First, CNN takes an input image of height, width, and number of channels say (600, 400, 3), as shown in figure 5.8, and performs the convolution operation by using n number of filters. Here we have used four convolutional filters, as shown in figure 5.8.
- Then the output from the convolution filters is provided to non-linear transformations using RELU and Max pooling.
- These convolutions, RELU, and max pooling operations are executed multiple times.
- Finally, the output is sent to SoftMax, which provides probabilities of different classes between 0 and 1.

## Object localization

Object localization deals with locating the existence of different objects in an image and further indicating the location of the objects by using a bounding box:

![](img/7e519fee1b702b91799cdf1664598392_375_1.png)

Figure 5.9: Classification with localization

In the case of object localization:

- **Input to the deep learning model**: An image having multiple objects.
- **Output from the deep learning model**: Objects with bounding boxes.

Suppose we have an input image having some objects that passed through a convolution neural network model (ConvNet), which provides results in the form of a vector of different features, which are further provided to a SoftMax classifier which classifies the different objects in the image (suppose there are four classes as cars/background/bike/pedestrians).

Now, we are looking to localize these four objects in the input image; for this, we need to change the dimension of ConvNet, such that it can provide a few more outputs that incorporate a bounding box. So, we include four new numbers to identify the coordinates ($x$ and $y$) of the upper left corner and for the height and the width of the box ($b'_x, b'_y, b'_h, b'_w$).

Where $b_x$ denotes the $x^{th}$ coordinate of the upper left corner of the bounding box. $b_y$ denotes the $y^{th}$ coordinate of the upper left corner of the bounding box. $b_h$ denotes the height of the bounding box. $b_w$ denotes the width of the bounding box.

Now, the output of the ConvNet will be the four numbers, with the probability of each of the class labels (in this case: 4). This, the target label of the output will be the following:

```
$y_{target} = \begin{bmatrix} p_c \\ b_x \\ b_y \\ b_w \\ b_h \\ c_1 \\ c_2 \\ c_3 \end{bmatrix}$
```

Where $p_c$ denotes the confidence of the object to be present in an image, which answers the real question Is object present in the image? While $c_1, c_2$ and $c_3$ shows that if an object is present in an image, it tells the object belongs to which class, such as Class 1, Class 2, or Class 3. So, basically, it shows which object it is finally.

![](img/7e519fee1b702b91799cdf1664598392_377_0.png)

Figure 5.10: Classification with localization

For example, as shown in figure 5.10, if the input image has an object car, the output target label will be the following:

```
$$y_{target} = \begin{bmatrix} 1 \\ b_x \\ b_y \\ b_w \\ b_h \\ 0 \\ 1 \\ 0 \end{bmatrix}$$
```

And in case of no object detection, the output target label will be the following:

```
$$y_{target} = \begin{bmatrix} 0 \\ ? \\ ? \\ ? \\ ? \\ ? \\ ? \\ ? \end{bmatrix}$$
```

Where ? shows the positions which do not have any information or meaning.
