The problem that arises here is remembering whether the subject is singular or plural / male or female to resolve dependencies. Some kind of hidden state representations are required to understand these short and long-term dependencies and remember them till the point more interesting information needs to be remembered. In GRU, there are two basic things when to remember and what to remember representing [update units \(\gamma_u\)] and [cell units \(\tilde{c}_t\)].

\(\gamma_u = 1, \gamma_u = 0, \gamma_u = 0, \gamma_u = 0 \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\gamma_u = 0 \quad (7.1)\)
\(c_t = 1, c_t = 1, c_t = 1, c_t = 1 \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots c_t = 1 \quad (7.2)\)

In the case of a Gated recurrent unit, the most important question is what a gate means in GRU. Suppose in a class of computer science, there are 50 students whose class of deep learning is scheduled at 10: 30 a.m. So, students are allowed up to 10: 30 a.m. (Time = t), and after that, they are not allowed. So it becomes a 50-dimensional bit vector in which if the bit value \(\gamma_u = 1\) means allowed to enter the class, and 0 means not allowed to enter. It may vary between 0 and 1. Gated input \(\gamma_u\) (when to remember) is stored in cell input \(\tilde{c}_t\) (what to remember).

# Potential cell update unit

\(\tilde{c}_t = tanh[(W_c (c_{t-1}, x_t) + b_c] \quad (7.3)\)

It can be visualized as the cell or memory value at time = t. In equation (7.3), the neural network is parameterized by \((W_c, b_c)\), where \(W_c\) is weight and \(b_c\) is corresponding bias with input as \((c_{t-1}, x_t)\). Here, the tanh activation function is used as its range is -1 to 1 and we are working with what to update issue.

# Update or input unit

\(\gamma_u = \sigma[(W_u (c_{t-1}, x_t) + b_u] \quad (7.4)\)

It can be visualized as a gate that allows or blocks some information. In equation (7.4), the neural network is parameterized by \((W_u, b_u)\), where \(W_u\) is weight and \(b_u\) is corresponding bias with input as \((c_{t-1}, x_t)\). Here, sigmoid activation function is used as its range is 0 to 1, and we are working with updating issue. Here, we are concerned with whether we have to update the corresponding cell value (\(\tilde{c}_t\)) or not. It depends on gated input (\(\gamma_u\)). Potential cells are not directly updated they are gated through \(\gamma_u\) to get the actual updates. Element-wise multiplication of the update unit with the cell unit will help produce the effect of gating, as shown in equation (7.5).
