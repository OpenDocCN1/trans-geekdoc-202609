# # Image segmentation algorithm—mask RCNN

Mask RCNN is the extended form of Faster RCNN, which is used for pixel-based image segmentation. The main goal of this algorithm is to decouple the mask-prediction and classification tasks.

Mask RCNN algorithm uses the framework of Faster RCNN; analogously, it has a branch for the mask prediction. The Mask prediction branch is basically a small network of fully connected layers that is applied to every region of interest, which predicts a segmentation mask.
