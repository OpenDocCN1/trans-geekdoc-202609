Then, the final obtained region generates the detected locations also known as the regions of interest. RCNN uses the following steps to detect objects in an input image. The architecture of RCNN is shown in figure 5.47.

- First, RCNN takes a pre-trained CNN.
- After that, the model is again trained. Training of the first layer of the model is done based on the number of classes of objects we want to detect.
- Then, the RCNN determines the region of interest for the input image by using a selective search algorithm.
- After that, reshaping of the region of interest is done, so it can be matched with the input size of CNN.
- Furthermore, training of SVM is performed for the classification of different objects and backgrounds of the image.
- Here, for every class, a binary SVM is trained.
- Then, a linear regression model is trained to generate the bounding boxes for each of the identified objects.

### Bounding box regression in RCNN

Now, let us consider we have a predicted bounding box having coordinates as follows:

```
P = (P_x, P_y, P_w, P_h)
```

Where $P_x$, and $P_y$ are center coordinates and $P_w$ and $P_h$ are width and height of bounding box, respectively.

While the coordinates of the actual bounding box are given as follows:

$g = (g_x, g_y, g_w, g_h)$

Then, the regression is configured such that it performs the scale-invariant transformation between the centers of two bounding boxes and also performs log-scale transformation with respect to the height and width of the two boxes.

![](img/7e519fee1b702b91799cdf1664598392_399_0.png)

Figure 5.48: Transformation between predicted and output bounding box

As shown in the figure, all the transformations take $P$ as the input and can be given as follows:

$g_x = P_w d_x(P) + P_x$
$g_y = P_h d_y(P) + P_y$
$g_w = P_w exp(d_w(P))$
$g_h = P_h exp(d_h(P))$

The advantage of applying these transformations is that all the bounding boxes having corresponding functions, say, $d_i$, where $i$ can be $x, y, w,$ and $h$ can be provided values between -$\infty$ to +$\infty$.

The target values can be given as follows:

$t_x = \frac{(g_x - P_x)}{P_w}$

and

$t_y = \frac{(g_y - P_y)}{P_h}$

and

$t_w = log \frac{g_w}{P_w}$

and

$t_h = log \frac{g_h}{P_h}$

The standard model of regression, which can be used to solve the issue while reducing the SSE loss, along with the regularization, is given as follows:

$L_{regr} = \sum_{i=(x,y,w,h)} (t_i - d_i(P))^2 + \partial(w)^2$

So, we understand object detection using RCNN now, but there are certain limitations of RCNN as well. Let us discuss some of them as follows:

- As RCNN extracts up to 2,000 regions from an input image using a selective search algorithm.
- After that, RCNN has to extract the feature from all the 2,000 regions of the input image.
- Now, let us say we have n number of input images, so in this case, the number of feature extraction will be for n*2,000 cases.
- And the whole RCNN process follows the following steps for object detection:
  - i. It uses a selective search algorithm to determine the region of interest.
  - ii. Furthermore, it uses CNN for feature extraction.
- iii. Then, SVM (linear) is used to detect objects.
- iv. Finally, a regression model is used for the prediction of accurate bounding boxes.

All the preceding steps make RCNN expensive and slow, as for every new image, RCNN takes almost 55–60 seconds for object detection. Now, just assume if we have a large dataset, and we want to detect objects of all the images in the dataset. It almost becomes practically impossible.

To solve this issue, we have another object detection algorithm known as Fast RCNN.

## Fast RCNN

Now, what can be done to reduce the RCNN's time of computation? We can simply run CNN only once per input image instead of running it about 2,000 times and achieve the region of interest.

Ross Girshick proposed the idea of running CNN only once per input image and then sharing the feature maps with 2,000 regions. This algorithm is termed Fast RCNN. In this, first, the input image is fed to CNN, which generated feature maps. Then, extraction of the region of interest (RoI) is done by using these feature maps.

Furthermore, a Region of Interest pooling layer (RoI) is used to reshape the regions into a specific size so they can be passed through the fully connected layer.

Let us understand Fast RCNN in the following steps. The architecture of fast RCNN is shown in figure 5.54:

- Similar to RCNN, it first takes an input image.
- Then, the input image is passed through ConvNet to generate the RoI.
- Furthermore, a RoI pooling layer is used for the reshaping of the regions of interest to a specific size.
- After that, every region is passed through the fully connected layer.
- Then, a SoftMax and linear regression layer are used in parallel to predict the bounding boxes for the detected objects.
- Therefore, unlike RCNN, which uses three separate models, the Fast RCNN algorithm uses only a single model for all the steps, including generating RoI, feature extraction, and prediction of bounding boxes.

So, as we have seen, fast RCNN addresses the problems faced by the RCNN algorithm effectively, but even the fast RCNN algorithm has certain limitations. Fast RCNN also uses a selective search algorithm which is again slow and takes time to generate RoI.

However, it generally takes around 2–3 seconds to detect objects per image; thus, much better than the RCNN algorithm. But when we talk about large datasets, even the Fast RCNN algorithm does not work that fast. So, we have another algorithm to combat this issue known as the Faster RCNN algorithm.
