# Learning by CNN

How CNN learns? So, given any image, the network has been trained, and then a set of independent filters are learnt in the first convolutional layer. So, the question arises as to what type of things we are learning? Like in figure 4.67 (a), we learn low-level features such as color blobs, edges, and so on. If we consider these low-level filters and apply them to an image, then initially, we do not get the features such as ears, eyes, and so on, but we get some points, edges, and so on. In the next convolutional layer, we aggregate these responses and get some meaningful information such as eyes, ears, nose, and so on, and again aggregating these responses in the third (next) convolutional layer, we get much more meaningful features like some parts of the face. By keeping on aggregating the responses, again and again, we see the face. Moreover, we start applying the fully connected layers and then open those FC’s. Accordingly, we get confidence for the eye, ears, nose, and so on. Finally, we get the confidence for two classes as (i) face (ii) no-face, as shown in figure 4.67 (b). When random images are shown to the learnt or trained model, then on the basis of confidence gained for these random images, few images get classified into class face, and few get classified into class no-face.
