
## Loss function in fast RCNN

Here, the loss function should be optimized for two tasks localization and classification. Therefore, the loss function is the sum of classification cost and prediction cost for the bounding boxes as follows:

```
L = L_{classif.} + L_{bound.}
```

Now, with respect to background RoI, the value of L_{bound.} can be ignored by using an indicator function which is as follows:

```
1[u \ge 1] = \begin{cases} 0 & \text{for } u < 0 \\ 1 & \text{otherwise} \end{cases}
```

Where u is the actual class label such that

```
u = [0, 1, ..., K]
```

The overall loss function for Fast CNN can be given as follows:

```
L(P, u, v, t^u) = L_{classif.}(P, u) + 1[u \ge 1] L_{bound.}(t^u, v)
```

And we know that

```
L_{classif.}(P, u) = -\log P_u \\
L_{bound.}(t^u, v) = \sum_{i=(x,y,w,h)} L_1(t_i^u - v_i)
```

The bounding box loss L_{bound.} must be calculated using robust loss functions by calculating the difference between t_i^u and v_i.

where P is the probability distribution on K+1 number of classes such that

```
P = P_0, P_1, .... , P_K
```

v denotes the actual bounding box such that

```
v = (v_x, v_y, v_w, v_h)
```

And, t^u is the correction in the predicted bounding box such that

```
t^u = (t_x^u, t_y^u, t_w^u, t_h^u)
```

Now, as a robust loss function, we have used here smooth loss function because it is very less reactive to outliers and is given as follows:

```
L_1^{Smooth} = \begin{cases} x - 0.5, & x \ge 1 \\ 0.5(x)^2, & \text{otherwise} \end{cases}
```

## Faster RCNN

This algorithm is a modified form of the Fast RCNN algorithm. The main difference between Faster RCNN and Fast RCNN is that the Faster RCNN algorithm uses the region-proposal network to generate RoI as compared to the Fast RCNN, which uses a selective search algorithm.

Region-proposal network takes input as the feature maps of the input image and provides object proposals having a score of objectness as output. Let us understand Faster RCNN in the following steps. The architecture of Faster RCNN is shown in figure 5.61:

- First, an input image is passed through ConvNet, which provides feature maps.
- Then, these feature maps are passed through the region proposal network which provides the object proposals along with the score of objectness.
- Furthermore, these object proposals are passed through an RoI pooling layer which converts the size of these proposals into a specified fixed size.
- Then, the output from the RoI pooling layer is passed through a fully connected layer having a SoftMax and regression layer to predict the bounding box, as shown in figure 5.62.

## Region proposal networks (RPN)

As we know that the feature maps from convolution layers are passed through RPNs. Then RPNs actually use the sliding window technique on these feature maps. For every sliding window, it produces K number of anchor boxes having different shapes, as shown in figure 5.63:

![](img/7e519fee1b702b91799cdf1664598392_412_0.png)

Figure 5.63: SoftMax and Linear regression layers

We have discussed anchor boxes in the previous section, and they are basically bounding boxes of different shapes. For every anchor box, RPNs predict the following:

- The probability that it is an object
- Bounding box regressions

Now, there is a possibility that after getting output from RPN, there may be some proposals that do not have classes assigned to them. So, in this case, every proposal can be cropped such that every proposal has an object.

For this purpose, we use the RoI pooling layer, which extracts feature maps of a fixed specific size from every anchor box, as shown in figure 5.64:

![](img/7e519fee1b702b91799cdf1664598392_413_0.png)

Figure 5.64: RoI pooling Layer

After that, the generated feature maps from the RoI pooling layer are passed through a fully connected layer following regression and SoftMax layer to make bounding box predictions.

## Image segmentation algorithm—mask RCNN

Mask RCNN is the extended form of Faster RCNN, which is used for pixel-based image segmentation. The main goal of this algorithm is to decouple the mask-prediction and classification tasks.

Mask RCNN algorithm uses the framework of Faster RCNN; analogously, it has a branch for the mask prediction. The Mask prediction branch is basically a small network of fully connected layers that is applied to every region of interest, which predicts a segmentation mask.

## RoI align

In mask RCNN, the RoI aligns layer is designed to address the problem of misalignment of location, which is generated by the quantization process in the RoI pooling layer. Basically, RoI Align eliminates the hash-quantization.

For example, instead of using [x/16], it uses x/16, such that the features extracted could be assigned with the original input pixels easily. Figure 5.68 shows the process of RoI alignment.
