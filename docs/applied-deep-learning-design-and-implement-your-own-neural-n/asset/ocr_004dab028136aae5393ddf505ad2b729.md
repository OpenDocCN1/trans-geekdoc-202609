In figures 4.64 to 4.65, if we convolve 10 (ten) filters of size with 5 x 5 x 3 over the input image (figure 4.64) as 32 x 32 x 3 such that we get the same sized output feature or activation maps, then we have to do padding of two on all the sides of the input image with stride equals to one. It can be formulated as follows:

```
Output_Size with padding = \frac{32 + (2 \times 2) - 5}{1} + 1 = 32
```

# # Number of parameters in a layer

Figure 4.66 represents the number of parameters associated with the layer. As the size of the filter is 5 x 5 x 3, the number of parameters is 5 x 5 x 3 + 1 = 76 (+1 for bias). The total number of such filters used for the convolution of a 32 x 32 x 3 image is ten (10). So, the total number of parameters is 76 x 10 = 760.
