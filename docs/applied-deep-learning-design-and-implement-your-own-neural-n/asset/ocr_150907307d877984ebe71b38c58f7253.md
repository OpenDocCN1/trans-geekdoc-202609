In the case of object localization:

+   • **Input to the deep learning model**: An image having multiple objects.
+   • **Output from the deep learning model**: Objects with bounding boxes.

Suppose we have an input image having some objects that passed through a convolution neural network model (ConvNet), which provides results in the form of a vector of different features, which are further provided to a SoftMax classifier which classifies the different objects in the image (suppose there are four classes as cars/background/bike/pedestrians).

Now, we are looking to localize these four objects in the input image; for this, we need to change the dimension of ConvNet, such that it can provide a few more outputs that incorporate a bounding box. So, we include four new numbers to identify the coordinates ($x$ and $y$) of the upper left corner and for the height and the width of the box ($b'_x, b'_y, b'_h, b'_w$).

Where $b_x$ denotes the $x^{th}$ coordinate of the upper left corner of the bounding box. $b_y$ denotes the $y^{th}$ coordinate of the upper left corner of the bounding box. $b_h$ denotes the height of the bounding box. $b_w$ denotes the width of the bounding box.

Now, the output of the ConvNet will be the four numbers, with the probability of each of the class labels (in this case: 4). This, the target label of the output will be the following:

```
$y_{target} = \begin{bmatrix} p_c \\ b_x \\ b_y \\ b_w \\ b_h \\ c_1 \\ c_2 \\ c_3 \end{bmatrix}$
```

Where $p_c$ denotes the confidence of the object to be present in an image, which answers the real question Is object present in the image? While $c_1, c_2$ and $c_3$ shows that if an object is present in an image, it tells the object belongs to which class, such as Class 1, Class 2, or Class 3. So, basically, it shows which object it is finally.
