# Matrix representation of an image

Almost every digital image has its own matrix. In a computer, a digital image is represented as a pixel matrix. In a digital grayscale image, each pixel is represented by an integer ranging from {0, 1, 2, ...... 255}, that is, f(x,y) = z, where (x,y) is the spatial location and z is the corresponding intensity level at position (x,y).

# Spatial filtering

Spatial filtering is a technique used in image processing to change the pixel intensity according to the neighborhood intensities. By using the process of spatial filtering, an input image is convoluted by using a Filter F having dimensions (x, y), where x is the height of the filter and y is the width of the filter. The mathematical equation (4.1) to find out the convolution of the input image I(i, j) is given as follows:

```
I'(i, j) = I(i, j) * F(x, y)  (4.1)
```
