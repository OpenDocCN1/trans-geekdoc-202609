It is given as follows:

$$Cos(x, y) = \frac{x.y}{||x|| * ||y||}$$

**Example 7.2**: Suppose we have two vectors x and y, as follows:

x = {3,2,0,5}
y = {1,0,0,0}

x.y = 3 * 1 + 2 * 0 + 0 * 0 + 5 * 0

x.y = 3

Now,

$$||x|| = \sqrt{3^2 + 2^2 + 0^2 + 5^2}$$

$$||x|| = 6.16$$

And

$$||y|| = \sqrt{1^2 + 0^2 + 0^2 + 0^2}$$

$$||y|| = 1$$

Therefore,

$$Cos(x, y) = \frac{3}{6.16 * 1}$$

$$Cos(x, y) = 0.49$$

We can also find the cosine dissimilarity between x and y, which is given as follows:

$$dis(x, y) = 1 - Cos(x, y)$$

So, in our case

$$dis(x, y) = 1 - 0.49$$

$$dis(x, y) = 0.51$$

Now, if the cosine angle is 0 degree, then the objects are 100 % similar, and if the \theta is 90 degrees, then the objects are different.

# Jaccard similarity

Jaccard similarity between a and b is given as follows:

$$Sim(a, b) = \frac{\sum_{i=1}^d a_i b_i}{\sum_{i=1}^d a_i^2 + \sum_{i=1}^d b_i^2 - \sum_{i=1}^d a_i b_i}$$
