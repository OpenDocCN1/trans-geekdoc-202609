# # Introduction

In the previous chapter, we have discussed sequence prediction using RNN. RNN works well for short-term dependencies; however, it has certain limitations, as follows:

+   - Because of the vanishing gradient issue, if we want to use a long chain of RNN having multiple hidden layers, it becomes difficult for RNN to remember all the past information; that is, it can remember only a certain amount of information from the incidences that happened in the past. Therefore, it affects the performance of the RNN by limiting its effectiveness when it needs to go back deeper into the context.
+   - The other limitation of the RNN is that there is very weak control over the information which needs to be carried forward and how much information regarding past incidences needs to be forgotten.

The preceding two problems can be mitigated by using LSTM. They are a special type of RNN. Unlike RNNs, they are capable of learning long-term dependencies. Before LSTM, we will discuss GRU.
