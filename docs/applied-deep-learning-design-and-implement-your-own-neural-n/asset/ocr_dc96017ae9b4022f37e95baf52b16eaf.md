Now, suppose the actual value of the output of forward propagation at the time \( t = 0 \) is \( 1.25 \), that is, \( x^t = 1.25 \) and we have calculated it as \( 0.77 \).

Therefore,

\(\delta_x E = 0.77 - 1.25\)
\(\delta_x E = -0.48\)

And also change in output at \( t = 1 \) is \( 0 \) as there are no more future values of \( t \). So we can write

\(\delta Out(t = 1) = -0.48 + 0\)
\(\delta Out(t = 1) = -0.48\)

The change in the cell state is given as follows:

\(\delta State(t = 1) = \delta Out(t = 1) * o(1) * \left(1 - \tanh^2(state(t = 1))\right) + \delta(state = 2) * f(2)\)
\(\delta State(t = 1) = -0.48 * 0.83 * \left(1 - \tanh^2(1.5)\right) + 0 * 0\)
\(\delta State(t = 1) = -0.070\)

Now, \(\delta a(t = 1) = \delta State(t = 1) * i(1) * (1 - (a(1))^2\)

\(\delta a(t = 1) = -0.070 * 0.9 * (1 - (0.83)^2)\)

Therefore, \(\delta a(t = 1) = -0.02\)

Also, \(\delta i(t = 1) = \delta State(t = 1) * a(1) * i(1) * (1 - i(1))\)

\(\delta i(t = 1) = -0.070 * 0.83 * 0.9 * (1 - 0.9)\)

Therefore, \(\delta i(t = 1) = -0.001\)

Also, \(\delta f(t = 1) = \delta State(t = 1) * \delta State(t = 0) * f(1) * (1 - f(1))\)

\(\delta f(t = 1) = -0.070 * 0.78 * 0.85 * (1 - 0.85)\)

Therefore, \(\delta f(t = 1) = -0.006\)

And

\(\delta o(t = 1) = \delta out(t = 1) * \tanh(State(t = 1)) * o(1) * (1 - o(1))\)
\(\delta o(t = 1) = -0.48 * \tanh(1.5) * 0.83 * (1 - 0.83)\)

Therefore, \(\delta o(t = 1) = -0.05\)
