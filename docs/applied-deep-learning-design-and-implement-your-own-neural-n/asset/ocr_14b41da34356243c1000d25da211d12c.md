# CNN LSTM

This hybrid architecture uses CNN for feature extraction. Finally, LSTM is used for sequence prediction. This hybrid model is used in time-series problems.

It consists of the following layers:

+   - Input layer
+   - CNN model
+   - LSTM model
+   - Dense layer
+   - Output layer

# Encoder decoder LSTM

This hybrid architecture uses an encoder to encode the input sequence. Then, the decoder decodes the output from the model to make it readable for the user. It is mostly used in the area of machine translation.
