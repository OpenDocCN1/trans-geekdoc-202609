Figure 4.6: Differences between the fully connected layer and CNN layer

+   **Pooling layer:** The pooling layer performs down-sampling. It extracts the information obtained from the convolutional layer and preserves the most important information required to make the prediction. The unnecessary information is not carried forward for further processing in the next layers. The hyperparameters associated with pooling are Window size and Window stride. Pooling is used to reduce the size, the feature, or activation maps. For example, a feature map obtained after convolution of the size 224 x 224 x 3 can be reduced to 112 x 112 x 3 after applying pooling with some window size and stride.

+   **Fully connected layer:** This layer connects every node of one layer to every node of another layer. This layer applies the weights over the output generated from the pooling layer to predict the correct label. The main aim of the fully connected layer is to take pooled feature maps from the pooling layer and use those feature maps for the classification of the image to predict a label. The hyper-parameters associated with fully connected layers are the number of fully connected layers and the number of neurons in each and every fully connected layer.

+   **Output layer:** This layer generates the final value to predict the class of an image.
