## Padding in CNN

We have discussed the convolution operation in the previous subsections, that is, correlation and convolution. There are some problems with simple convolution techniques used in the convolution layers.

When we apply simple convolution to an image of size m × n by using a kernel of f × f, we get the resultant image of size (m - f + 1) × (n - f + 1).

For example, suppose we have an image of size (6 * 6) and a kernel of size (3*3). Here, n = 6 and f = 3, the result of the convolution operation between them is given as follows:

```
(6 - 3 + 1 ) * (6 - 3 + 1 ) = 4 * 4
```

Therefore, the resultant matrix is of size 4 * 4 as follows:

```
[3 0 1 2 7 4]   [1 0 -1]   [-5 -4 0 8]
[1 5 8 9 3 1] * [1 0 -1] = [-10 -2 2 3]
[2 7 2 5 1 3]   [1 0 -1]   [0 -2 -4 -7]
[0 1 3 1 7 8]              [-3 -2 -3 -16]
[4 2 1 6 2 8]
[2 4 5 2 3 9]
```

Therefore, the size of the resultant image shrinks after every convolution operation is performed. We have discussed the case of the first convolution layer, but in the deep neural network, we need to use more convolution layers. So after every convolution, it shrinks, and finally, the image loses all the relevant information.

To overcome this problem, we use padding. It is the process of adding layers of zeros or pixel values similar to boundary pixels to the input image to remove the aforementioned problem. Padding is used for processing boundary pixels for convolution. Padding is used to generate the same-sized image after applying convolution. The amount by which padding is done depends on the size of the filter. If the size of the filter is u × v, then the number of rows added to the input image are p = (u - 1) both at the top and bottom of the image. Similarly, the numbers of columns added to the input image are p = (v - 1) both on the left and right side of an image. For example, consider an input image of size 5 × 5 [m × n] and size of corresponding filter is 3 × 3 [u × v]. Then, the size of resultant image after applying padding is 3 × 3 [u × v]. As the size of filter is 7 × 7 [(m + (u - 1) × (n + (v - 1)))], so (u - 1) = (3 - 1) = 2 number of rows are padded at the top and bottom. Similarly, the number of columns padded at the left and right side of the image are (v - 1) = (3 - 1) = 2 as shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_259_0.png)

Figure 4.40: Zero padding

Padding prevents the shrinking of the resultant matrix. Suppose p is the number of padding layers of zeros added to the original image. Then, a (n * n) image becomes (n + 2p) * (n + 2p) image after padding. So, after applying convolution operation by using a kernel of (f * f), we get an output image as follows:

```
(n + 2p - f + 1) × (n + 2p - f + 1) (4.26)
```

For example, consider a 5 × 5 image and a filter of size 3 × 3. So applying padding of (1+1=2) at the top, bottom, left, and right, the resultant image is 7 × 7. So after correlating this with a 3 × 3 filter we get the output image for [n = 5, p = 1, f = 3] as (n + 2p − f + 1) × (n + 2p − f + 1) = (5 + 2 × 1 − 3 + 1) × (5 + 2 × 1 − 3 + 1) = 5 × 5.

## Concept of stride in CNN

While performing the convolution operation, the filter is moved across the input image from top-to-bottom, left-to-right, with a pre-defined column change on the horizontal movement, followed by a predefined row change in the vertical movement.

The predefined amount of movement, the filter possesses the input image and is known as the stride. The default stride in two dimensions is (1,1) for horizontal and vertical movement. However, we can change the stride size accordingly. The size of the stride directly links with the size of the resultant feature map:
