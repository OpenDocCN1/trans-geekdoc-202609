## Number of parameters in a layer

Figure 4.66 represents the number of parameters associated with the layer. As the size of the filter is 5 x 5 x 3, the number of parameters is 5 x 5 x 3 + 1 = 76 (+1 for bias). ## Learning by CNN

How CNN learns? So, given any image, the network has been trained, and then a set of independent filters are learnt in the first convolutional layer. So, the question arises as to what type of things we are learning? Like in figure 4.67 (a), we learn low-level features such as color blobs, edges, and so on. If we consider these low-level filters and apply them to an image, then initially, we do not get the features such as ears, eyes, and so on, but we get some points, edges, and so on. In the next convolutional layer, we aggregate these responses and get some meaningful information such as eyes, ears, nose, and so on, and again aggregating these responses in the third (next) convolutional layer, we get much more meaningful features like some parts of the face. By keeping on aggregating the responses, again and again, we see the face. Moreover, we start applying the fully connected layers and then open those FC’s. Accordingly, we get confidence for the eye, ears, nose, and so on. Finally, we get the confidence for two classes as (i) face (ii) no-face, as shown in figure 4.67 (b). When random images are shown to the learnt or trained model, then on the basis of confidence gained for these random images, few images get classified into class face, and few get classified into class no-face.

## Convolution in 3-D

In the previous sections, we have discussed 2-D convolution. Now, let us say we have a video, and we want to extract relevant features from different frames of the video. As we know, the video is nothing but a sequence of frames (images) that are moving with respect to time. So, if the refresh rate of the video is 60 Hz, then it means that 60 frames are moving in one second, and each frame contains different information. The features associated with videos are called spatiotemporal features. The word spatiotemporal is the combination of two features—spatial, that is, (x,y), and temporal means (t), that is, time. So, to detect these spatiotemporal features in a video, we need to convolve it with a 3-D convolution:

![](img/7e519fee1b702b91799cdf1664598392_283_0.png)

Figure 4.76: [a, b] (a) 3-dimensional convolution (b) four frames each of size 512*512*3 are convolved with filters 1 and 2

Now, the filter that is to be applied is the same 3-D filter as we have used in the section Convolution in 2-D. Instead of 2-D convolution, now convolution is also 3-D, as we are moving our filter in the x, y, and z directions. In 3-D convolution, the movement of the filter is also in the direction of z along with the x and y directions.
