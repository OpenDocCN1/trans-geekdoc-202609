Now, for the logistic activation function, the maximum bound value that we can get is 0.25 or, say, ¼. Therefore, we can write,

$$\sigma'(a(i)) \le 0.25 = \beta$$

Hence,

$$\left\| \frac{\partial S(i)}{\partial S(i-1)} \right\| \le \beta . \|W\|$$

Let us take $\|W\|$ as $\alpha$, so we can write as follows

$$\left\| \frac{\partial S(i)}{\partial S(i-1)} \right\| \le \beta . \alpha$$

Now, let us take the product terms

$$\left\| \frac{\partial St}{\partial SN} \right\| = \left\| \prod_{i=N+1}^{t} \frac{\partial S(i)}{\partial S(i-1)} \right\|$$

Therefore,

$$\frac{\partial st}{\partial sN} \le \prod_{i=N+1}^{t} \beta . \alpha \quad (6.18)$$

Or

$$\frac{\partial St}{\partial sN} \le (\beta . \alpha)^{t-N}$$

So, now if

$$\beta . \alpha <<< < 1$$

The gradient will vanish for the preceding equation. And if

$$\beta . \alpha >>> > 1$$

The gradient will explode for the preceding equation.

So, if the gradient vanishes, there will be no updates to the weights, and if the gradient explodes, we can have a very large value of the gradient, which is not acceptable while training a neural network.
