MSE is given as follows:

\[ E = \frac{(x - x')^2}{2} \]

When we do the derivation of the preceding equation concerning $x$, we get the following:

\[ \delta_x E = x - x' \]

Now, suppose the actual value of the output of forward propagation at the time $t = 0$ is 0.50, that is, $x' = 0.50$, and we have calculated or predicted value as 0.53.

Therefore,

\[ \delta_x E = 0.53 - 0.50 \]
\[ \delta_x E = 0.03 \]

Now from the backward propagation at $t = 1$, we have

\[ \delta out(0) = -0.02 \]

Therefore, the change in output at $t = 0$ is -0.02. So we can write

\[ \delta Out(t = 0) = 0.03 - 0.02 \]
\[ \delta Out(t = 0) = 0.01 \]

And the change in the cell state is given as follows:

\[ \delta State(t = 0) = \delta Out(t = 0) * o(0) * \left(1 - \tanh^2(state(t = 0))\right) + \delta State(t = 1) * f(1) \]
\[ \delta State(t = 0) = 0.01 * 0.8 * (1 - \tanh^2(0.77)) - 0.07 * 0.85 \]
\[ \delta State(t = 0) = -0.05 \]

Now,

\[ \delta a(t = 0) = \delta State(t = 0) * i(0) * \left(1 - \left(a(0)\right)^2 \right) \]
\[ \delta a(t = 0) = -0.05 * 0.95 * (1 - \left(0.81\right)^2) \]

Therefore,

\[ \delta a(t = 0) = -0.17 \]

Also

\[ \delta i(t=0) = \delta State(t=0) * a(0) * i(0) * (1-i(0)) \]

\[ \delta i(t=0) = -0.05 * 0.8 * 0.95 * (1-0.95) \]

Therefore,

\[ \delta i(t=0) = -0.001 \]

Also

\[ \delta f(t=0) = \delta State(t=0) * \delta State(t=-1) * f(0) * (1-f(0)) \]

\[ \delta f(t=0) = -0.05 * 0 * 0.85 * (1-0.85) \]

Therefore,

\[ \delta f(t=0) = 0.00 \]

And,

\[ \delta o(t=0) = \delta out(t=0) * tanh(State(t=0)) * o(0) * (1-o(0)) \]

\[ \delta o(t=0) = 0.02 * tanh(0.7) * 0.8 * (1-0.8) \]

Therefore,

\[ \delta o(t=0) = 0.001 \]

Now, we know that

\[ \delta x(t=0) = W^t * \delta gates(t=0) \]

Therefore,

\[ \delta x(t=0) = \begin{bmatrix} 0.45 & 0.9 & 0.7 & 0.6 \\ 0.25 & 0.8 & 0.45 & 0.4 \end{bmatrix} * \begin{bmatrix} -0.02 \\ -0.001 \\ 0 \\ 0.001 \end{bmatrix} \]

So,

\[ \delta x(t=0) = \begin{bmatrix} -0.008 \\ -0.005 \end{bmatrix} \]

And also

\[ \delta out(-1) = U^t * \delta gates(t=0) \]
\[ \delta out(0) = [0.15 \quad 0.8 \quad 0.1 \quad 0.25] * \begin{bmatrix} -0.02 \\ -0.001 \\ 0 \\ 0.001 \end{bmatrix} \]

Therefore,

\[ \delta out(0) = -0.003 \]

## Variants of LSTM

Based on the difference between architecture, LSTMs have multiple variants. Some of them are as follows.

### Vanilla LSTM

A simple LSTM architecture is termed as Vanilla LSTM. In this architecture, a single LSTM hidden layer is used along with the memory cell of that layer.

It consists of the following layers:

- Input layer
- LSTM hidden layer
- Dense layer
- Output layer

The architecture of vanilla LSTM is shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_530_0.png)

### Stacked LSTM

In this LSTM architecture, multiple LSTM hidden layers are stacked one above the other LSTM layer. Stacked LSTM makes the model much deeper, and thus, increases the accuracy of model.

The architecture of vanilla LSTM is shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_530_1.png)

### CNN LSTM

This hybrid architecture uses CNN for feature extraction. Finally, LSTM is used for sequence prediction. This hybrid model is used in time-series problems.

It consists of the following layers:

- Input layer
- CNN model
- LSTM model
- Dense layer
- Output layer

The architecture of CNN LSTM is shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_531_0.png)

Figure 7.20: CNN LSTM

### Encoder-Decoder LSTM

This hybrid architecture uses an encoder to encode the input sequence. Then, the decoder decodes the output from the model to make it readable for the user. It is mostly used in the area of machine translation.

It consists of the following layers:

- Input layer
- Encoder model
- Decoder model
- Dense layer
- Output layer

The architecture of Encoder–Decoder LSTM is shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_532_0.png)

Figure 7.21: Encoder–Decoder LSTM

### Bidirectional LSTM

In this LSTM architecture, the input data sequence is provided, and then the model is trained in both forward and backward directions.

It consists of the following layers.

- Input layer
- Forward LSTM
- Backward LSTM
- Dense layer
- Output layer

The architecture of bidirectional LSTM is shown in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_533_0.png)

Figure 7.22: Bidirectional LSTM

A similarity measure can be defined as a metric that determines how two objects are the same. We live in a world of three dimensions, so every object has a different length, breadth, height, and mass. These similarity measures are used in Siamese networks discussed in the section Siamese Networks.
