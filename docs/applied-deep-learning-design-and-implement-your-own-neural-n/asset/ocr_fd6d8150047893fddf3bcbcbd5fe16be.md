# Figure 7.32: Siamese neural network for signature verification

The preceding figure is taken from Signature verification using Siamese neural network, 1993. The Siamese network was first adopted to verify the signatures in 1993. Here, two different neural networks were used in parallel where one neural network takes an image of a signature of a verified person, and the other signature is taken for verification purpose. Both the outputs of neural networks were combined to get the similarity measure to predict if the signature is of the verified person only or not.

In 2015, Gregory Koch studied the Siamese neural network for one-shot image recognition, in which the model using the image verification task, as shown in figure 7.33.
