## Backpropagation in RNN

Now, let us understand back-propagation in RNN to know how the process of weight updation takes place in RNN.

We know that in forward propagation, input values enter the network and then move only forward at every timestamp. But while using the backpropagation, we are moving back concerning time to update the weights, and hence, we also call backpropagation through time (BPTT). Refer to figure 6.68 for an example:

![](img/7e519fee1b702b91799cdf1664598392_473_1.png)

Now say \( y_{(t)} \) is the value we got after making the prediction, and \( Y(t) \) is the actual output value; the cross-entropy loss can be calculated as follows:

\( E(t)[Y(t), y(t)] = -Y(t)log(y(t)) \) (6.11)
\( E(t)[Y, y] = -\Sigma Y(t)log(y(t)) \) (6.12)

So, we have to calculate this loss for all the input time stamps and then add them to find the total loss. Here, the weights are the same for each timestamp. Let us brief out the steps to be followed for backpropagation in RNN:

So, observing the preceding figure properly, the total cross-entropy loss of the network is given as follows:

\( L(\theta) = \sum_{t=1}^{T} L_t(\theta) \)

And loss at timestamp t is given as follows:

\( L_t(\theta) = -log(y_{tc}) \)

Here, c is the true class at timestamp t

T is the total number of timestamps;

\(\gamma_{tc}\) is the predicted probability of a character at timestamp t.

Now, for the back-propagation, we need to find out the gradients also concerning U, V, and W.

So, first, let us look at the derivative of the loss function \(L(\theta)\) concerning V as follows:

\[
\frac{\partial L(\theta)}{\partial V}
\]

And here, V is a matrix, so we can write as following:

\[
\nabla_V L(\theta)
\]

So, we have discussed how to do this derivative in the section backpropagation in the previous chapter. So we can write the following:

\[
\frac{\partial L(\theta)}{\partial V} = \sum_{t=1}^T \frac{\partial L_t(\theta)}{\partial V} \quad (6.13)
\]

Where each term in the summation is the derivative of the loss function concerning the output layer weights. Now, let us look at the derivative of the loss function concerning W as follows:

\[
\frac{\partial L(\theta)}{\partial W}
\]

Can be given as follows:

\[
\frac{\partial L(\theta)}{\partial W} = \sum_{t=1}^T \frac{\partial L_t(\theta)}{\partial W} \quad (6.14)
\]

- Now, according to the chain rule of derivatives, the value of \(\frac{\partial L_t(\theta)}{\partial W}\) can be determined by adding the gradients of all the paths from \(L_t(\theta)\) to the value of W.
- So, can you tell what are all the paths which are connecting W to the loss function \(L_t(\theta)\)? So, here we will have t paths.
- Now, let's consider the last path \(L_4(\theta)\) here.
- So here we know that the value of \(L_4(\theta)\) depends on the value of S4;

S4 depends on the value of S3 and value of W;

S3 depends on the value of S2 and value of W;

S2 depends on the value of S1 and value of W;
And S1 depends on the value of S0 and value of W;
Where S0 is the constant starting state.

![](img/7e519fee1b702b91799cdf1664598392_481_0.png)

Figure 6.77: Dependency on previous states

So if we observe the preceding figure, we can say that the network is ordered. And when we talk about the ordered network, here the value of every state is calculated one-by-one in order, say, S1-S2-S3-S0 so on.

So, we have, according to the chain rule:

\(\frac{\partial L_4(\theta)}{\partial W} = \sum_{t=1}^{T} \frac{\partial L_t(\theta)}{\partial S4} \frac{\partial S4}{\partial W}\)

Now, \(\frac{\partial L_t(\theta)}{\partial s4}\) we have already discussed in the back-propagation section of the previous chapter. Now, let us find out the value of \(\frac{\partial S4}{\partial W}\)

So, we know that:

\(S4 = \sigma(W(S3 + B))\)

Now, here is the final derivative of S4, that is, \(\frac{\partial S4}{\partial W}\) can be divided into two parts shown as follows:

**Explicit derivative**: While calculating the explicit derivative of \(\frac{\partial S4}{\partial W}\), we can take all the other inputs as constant.

**Implicit derivative**: In this part, we sum all the indirect paths which are joining S4 to W.

So, we can write the preceding total derivative as the sum of the explicit and implicit derivatives as follows:

\(\frac{\partial S4}{\partial W} = \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial W}\)

where \(\frac{\partial^* S4}{\partial W}\) is the explicit derivative and \(\frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial W}\) is the implicit derivative. And * sign in explicit derivative indicates that we are taking the derivative concerning W only and taking all other parameters constant.

So, now we have

\(\frac{\partial S4}{\partial W} = \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial W}\)

Again \(\frac{\partial S3}{\partial W}\) can be divided into two parts, explicit and implicit, as shown in the following equation:

\(\frac{\partial S4}{\partial W} = \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3}\left(\frac{\partial^* S3}{\partial W} + \frac{\partial S3}{\partial S2} \frac{\partial S2}{\partial W}\right)\)

Where again \(\frac{\partial^* S3}{\partial W}\) is explicit derivative and \(\frac{\partial S3}{\partial S2} \frac{\partial S2}{\partial W}\) is an implicit derivative. Again, we have \(\frac{\partial S2}{\partial W}\), which can be further divided into explicit and implicit parts as follows:

\(\frac{\partial S4}{\partial W} = \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial^* S3}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial S2}\left(\frac{\partial^* S2}{\partial W} + \frac{\partial S2}{\partial S1} \frac{\partial S1}{\partial W}\right) \quad (6.14)\)

So, here \(\frac{\partial^* S2}{\partial W}\) is explicit derivative again and \(\frac{\partial S2}{\partial S1} \frac{\partial S1}{\partial W}\) is an implicit derivative.

Now, again we can write as follows:

\(\frac{\partial S4}{\partial W} = \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial^* S3}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial S2} \frac{\partial^* S2}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial S2} \frac{\partial S2}{\partial S1}\left(\frac{\partial^* S1}{\partial W}\right)\)
