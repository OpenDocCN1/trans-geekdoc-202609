# # Connect with realization of RNN

Let us take an example of RNN for the use case of Natural Language Processing for a better understanding of RNN. Let us say the model is provided with the following four letters as HELL, and the model has to predict the last letter as O. The common form of RNN can be explained in figure 6.54:

![](bbox=[0.36, 0.23, 0.63, 0.55])

Figure 6.54: RNN input-output model

Now, let us use the preceding structure of RNN to predict the fifth letter of the word HELLO. In the preceding structure, the center box named RNN uses a Recurrence formula [equation (6.3)] on the values of the input vector and the previous state of the input vector.

So, here letter H is the first letter, and there is nothing as its previous input. Now, after that, the letter E has been provided to the RNN, in which a recurrence formula is used with the current input E and the previous input state H.

This is according to different time stamps of the input. So suppose, if at timestamp t the input to the RNN is E, then the input was H at the time stamp t-1. And then, finally, using the recurrence formula, we get the current state. The formula is given as follows:

```
h_{(t)} = f_c(h_{(t-1)}, x_{(t)})
```

Where h(t) is the current state.

h_{(t-1)} is the previous state.
