# # Training dataset

A training dataset is defined as a dataset used for learning purposes or to fit weights. We train the classifier using the training dataset. However, for the training of the classifier, only training and validation datasets are available. The testing dataset must not be used during training. The training dataset is the largest among the three datasets.

When we run a training dataset through a neural network, it teaches the neural network to weigh different parameters and adjust the coefficients of weight such that the loss is minimum. The loss is the difference between actual and predicted values.

# # Validation dataset

Now, once the model is trained using the training dataset, it needs to be evaluated to check how accurate the model is. This is what the validation dataset is used for. It is used in calculating the error rate or loss of the model, which defines the accuracy of the trained model. This is the important aspect of training a model accurately. So, does a validation dataset affect a model? Yes, it does, but indirectly. By using the results of the validation dataset, the model will tune its parameters to achieve a higher accuracy rate.

# # Test dataset

A test dataset is used to deliver the final assessment of the model after the training phase. The test dataset is used once after a model is completely trained, that is, after training and validation of the model. Although the function of validation and testing dataset is almost similar, it is not a good practice to use the validation dataset for testing purposes.
