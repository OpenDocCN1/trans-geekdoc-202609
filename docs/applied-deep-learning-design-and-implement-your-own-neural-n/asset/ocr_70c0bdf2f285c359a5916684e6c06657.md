Figure 4.40: Zero padding

Padding prevents the shrinking of the resultant matrix. Suppose p is the number of padding layers of zeros added to the original image. Then, a (n * n) image becomes (n + 2p) * (n + 2p) image after padding. So, after applying convolution operation by using a kernel of (f * f), we get an output image as follows:

```
(n + 2p - f + 1) × (n + 2p - f + 1) (4.26)
```

For example, consider a 5 × 5 image and a filter of size 3 × 3. So applying padding of (1+1=2) at the top, bottom, left, and right, the resultant image is 7 × 7. So after correlating this with a 3 × 3 filter we get the output image for [n = 5, p = 1, f = 3] as (n + 2p − f + 1) × (n + 2p − f + 1) = (5 + 2 × 1 − 3 + 1) × (5 + 2 × 1 − 3 + 1) = 5 × 5.
