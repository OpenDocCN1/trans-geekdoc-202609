
The z-direction is represented by time $t$ representing temporal feature $s$ as shown in figure 4.76 (a). So, if we conclude $x$ and $y$ directions represent spatial (2-D) features, whereas the direction $z$ represents the third dimension as a temporal feature. The 3-D convolution works on a spatio temporal domain. The 3-D filter works similarly as in Convolution in 2-D. The only difference is, in 2-D convolution, it is working on a single image, that is, only a single frame. But in 3-D convolutions, it works on multiple frames that change with time, as shown in figure 4.76 (a). For more clarity, we have taken a video having four frames, each of size 512*512*3 but having different information at different time intervals $t$, as shown in figure 4.76 (b). These frames are convolved with filter 1 of the size 3*3*3 with the same padding. After applying convolution, we get four different responses with respect to each and every frame of size 512*512. In general, if $T$ is the number of frames in a video, then each and every filter generates $T$ number of responses with spatial dimensions as (H*W) as shown in figure 4.76 (b).

## Pooling layer in CNN

The pooling layer in CNN is used to reduce the size of the feature maps to speed up the computation and also makes the feature detection more robust. The pooling process performs scanning a 2-D filter over each of the channels of the feature map and finally reduces the features lying within the region of the image, which is scanned by the filter without losing much important information. Suppose we have a feature map of the size (n_h * n_w * n_c) obtained after the convolution operation. Then, after pooling, the size of the output is as follows:

$$
\frac{(n_h - f + 1)}{s} * \frac{(n_w - f + 1)}{s} * n_c
$$

Where n_h represents the height of the feature map
n_w represents the width of the feature map
n_c represents the total channels in the feature map
f represents the size of the filter used
and s represents the length of the stride

The pooling layer reduces the number of learning parameters significantly along with the computation time to train the network. Pooling is divided into the following two parts:

- Max pooling
- Average pooling

### Max pooling

Max pooling is a type of pooling process that selects and provides the maximum value of the pixel from the feature map’s region scanned by the filter. Thus, max-pooling provides the output as the most prominent feature of the feature map. Pooling does not require any parameters:
