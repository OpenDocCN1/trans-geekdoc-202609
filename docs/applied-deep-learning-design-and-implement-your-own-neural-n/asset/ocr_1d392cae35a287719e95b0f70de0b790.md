+   iii. Then, SVM (linear) is used to detect objects.
+   iv. Finally, a regression model is used for the prediction of accurate bounding boxes.

All the preceding steps make RCNN expansive and slow, as for every new image, RCNN takes almost 55–60 seconds for object detection. Now, just assume if we have a large dataset, and we want to detect objects of all the images in the dataset. It almost becomes practically impossible.

To solve this issue, we have another object detection algorithm known as Fast RCNN.

# Fast RCNN

Now, what can be done to reduce the RCNNs time of computation? We can simply run CNN only once per input image instead of running it about 2,000 times and achieve the region of interest.

Ross Girshick proposed the idea of running CNN only once per input image and then sharing the feature maps with 2,000 regions. This algorithm is termed Fast RCNN. In this, first, the input image is fed to CNN, which generated feature maps. Then, extraction of the region of interest (RoI) is done by using these feature maps.

Furthermore, a Region of Interest pooling layer (RoI) is used to reshape the regions into a specific size so they can be passed through the fully connected layer.

Let us understand Fast RCNN in the following steps. The architecture of fast RCNN is shown in figure 5.54:

+   * Similar to RCNN, it first takes an input image.
+   * Then, the input image is passed through ConvNet to generate the RoI.
+   * Furthermore, a RoI pooling layer is used for the reshaping of the regions of interest to a specific size.
+   * After that, every region is passed through the fully connected layer.
+   * Then, a SoftMax and linear regression layer are used in parallel to predict the bounding boxes for the detected objects.
+   * Therefore, unlike RCNN, which uses three separate models, the Fast RCNN algorithm uses only a single model for all the steps, including generating RoI, feature extraction, and prediction of bounding boxes.
