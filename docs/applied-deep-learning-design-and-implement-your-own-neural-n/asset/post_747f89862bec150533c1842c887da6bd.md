## Weights initialization

According to the model specifications given in the paper, all the weights are randomly initialized from a normal distribution, with a mean as 0 and a standard deviation as 0.2. These initial values are passed through the weight init() function as input and later to all convolutional, convolutional-transpose, and batch normalization layers.

## Generator network

The main function of the generator is to map the latent space vector into the training data distribution. The structure of the generator is constructed as specified in the DCGAN paper. A Generator class is made having init() and forward function.

```python
# custom weights initialization called on netG and netD
def weights_init(m):
    classname = m.__class__.__name__
    if classname.find('Conv') != -1:
        nn.init.normal_(m.weight.data, 0.0, 0.02)
    elif classname.find('BatchNorm') != -1:
        nn.init.normal_(m.weight.data, 1.0, 0.02)
        nn.init.constant_(m.bias.data, 0)
```

The init function is used to define all the layers of the generator model, and the forward function is used to pass the input through all the defined layers. There are five convolutional-transpose layers followed by a batch normalization layer and a ReLU activation function. Finally, the output of the generator is passed through tanh function. The application of the batch normalization function after each convolution-transpose layer is the critical contribution of the DCGAN paper:

```python
# Generator Code
class Generator(nn.Module):
    def __init__(self, n_gpu):
        super(Generator, self).__init__()
        self.n_gpu = n_gpu
        self.main = nn.Sequential(
            # input is Z, going into a convolution
            nn.ConvTranspose2d(latent_vec, gen_fmap*8, 4, 1, 0, bias=False),
            nn.BatchNorm2d(gen_fmap * 8),
            nn.ReLU(True),
            # state size. (gen_fmap*8) x 4 x 4
            nn.ConvTranspose2d(gen_fmap*8, gen_fmap*4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(gen_fmap * 4),
            nn.ReLU(True),
            # state size. (gen_fmap*4) x 8 x 8
            nn.ConvTranspose2d(gen_fmap, gen_fmap*4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(gen_fmap * 2),
            nn.ReLU(True),
            # state size. (gen_fmap*2) x 16 x 16
            nn.ConvTranspose2d(gen_fmap*2, gen_fmap, 4, 2, 1, bias=False),
            nn.BatchNorm2d(gen_fmap),
            nn.ReLU(True),
            # state size. (gen_fmap) x 32 x 32
            nn.ConvTranspose2d(gen_fmap, n_channel, 4, 2, 1, bias=False),
            nn.Tanh()
            # state size. (n_channel) x 64 x 64
        )
    def forward(self, input):
        return self.main(input)
```

Here, the generator is instantiated, and the weight **init()** function is applied to initialize all the weights and the layers. Finally, the generator object structure can be checked by printing the model, which is shown in the output.

```python
# Create the generator
G_network = Generator(n_gpu).to(device)

# Handle multi-gpu if desired
if (device.type == 'cuda') and (n_gpu > 1):
    G_network = nn.DataParallel(G_network, list(range(n_gpu)))

# Apply the weights_init function to randomly initialize all weights
# to mean=0, stdev=0.2.
G_network.apply(weights_init)

# Print the model
print(G_network)
```

## Discriminator network

```python
class Discriminator(nn.Module):
    def __init__(self, n_gpu):
        super(Discriminator, self).__init__()
        self.n_gpu = n_gpu
        self.main = nn.Sequential(
        # input is (n_channel) x 64 x 64
        nn.Conv2d(n_channel, dis_fmap, 4, 2, 1, bias=False),
        nn.LeakyReLU(0.2, inplace=True),
        # state size. (dis_fmap) x 32 x 32
        nn.Conv2d(dis_fmap, dis_fmap*2, 4, 2, 1, bias=False),
        nn.BatchNorm2d(dis_fmap * 2),
        nn.LeakyReLU(0.2, inplace=True),
        # state size. (dis_fmap*2) x 16 x 16
        nn.Conv2d(dis_fmap * 2, dis_fmap * 4, 4, 2, 1, bias=False),
        nn.BatchNorm2d(dis_fmap*4),
        nn.LeakyReLU(0.2, inplace=True),
        # state size. (dis_fmap*4) x 8 x 8
        nn.Conv2d(dis_fmap * 4, dis_fmap * 8, 4, 2, 1, bias=False),
        nn.BatchNorm2d(dis_fmap * 8),
        nn.LeakyReLU(0.2, inplace=True),
        # state size. (dis_fmap*8) x 4 x 4
        nn.Conv2d(dis_fmap * 8, 1, 4, 1, 0, bias=False),
        nn.Sigmoid()
        )
    def forward(self, input):
        return self.main(input)
```

The discriminator is basically a binary classification convolutional network, which classifies between _real(1)_ and _fake(0)_ images by taking images as input and giving a scalar probability, that is, 0 or 1. As mentioned in the DCGAN paper, the discriminator consists of a series of **Conv2d**, **leakyReLU**, and **BatchNorm2d** layers and, finally, the sigmoid activation function to produce the final probability.

As done in the case of the generator network, the discriminator is created, initialized with the random values through the weight **init()** function, and finally, printed to see the structure of the discriminator object.
