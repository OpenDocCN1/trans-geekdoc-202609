Where $P_x$, and $P_y$ are center coordinates and $P_w$ and $P_h$ are width and height of bounding box, respectively.

While the coordinates of the actual bounding box are given as follows:

$g = (g_x, g_y, g_w, g_h)$

Then, the regression is configured such that it performs the scale-invariant transformation between the centers of two bounding boxes and also performs log-scale transformation with respect to the height and width of the two boxes.

![](bbox=[0.297, 0.293, 0.727, 0.583])

**Figure 5.48: Transformation between predicted and output bounding box**

As shown in the predecon figure, all the transformations take $P$ as the input and can be given as follows:

$g_x = P_w d_x(P) + P_x$
$g_y = P_h d_y(P) + P_y$
$g_w = P_w exp(d_w(P))$
$g_h = P_h exp(d_h(P))$

The advantage of applying these transformations is that all the bounding boxes having corresponding functions, say, $d_i$, where $i$ can be $x, y, w,$ and $h$ can be provided values between -$\infty$ to +$\infty$.
