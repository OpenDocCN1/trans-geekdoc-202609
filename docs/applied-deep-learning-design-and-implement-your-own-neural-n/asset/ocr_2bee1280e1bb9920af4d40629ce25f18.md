The generator and discriminator networks are doing the usual tasks discussed in the previous models. The discriminator identifies real and fake images and the generator’s aim is to generate images to make the discriminator confused but on a pixel-by-pixel basis. The Pix-to-pix model is trained in both the source and target image pairs. By image pairs, it means that if a GAN is to be trained to translate day-time images to night-time images, then we need the exact same images taken at the day-time and at night-time, respectively. As this model is for general purposes, it can be trained on a wide range of image translations such as image-to-sketch, day-to-night images, aerial view-to-map view, thermal-to-colored photos, and so on, as shown in figure 8.15:

Pix-to-pix GAN uses U-Net architecture which is similar to auto-encoders architecture. Auto-encoders are artificial neural networks that can be used in computer vision for unsupervised learning. Auto-encoders consists of two main components: an encoder and a decoder. The encoder function is to extract the main features of the image and reduce it to a compressed latent representation (or bottleneck). The second component is the decoder, which takes this latent representation as input and tries to reconstruct the original image out of it.

Auto-encoders are generative models in which the encoder takes an input image and compresses or downsamples it to some representation, layer by layer.
