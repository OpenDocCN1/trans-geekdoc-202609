# Introduction

Deep learning is a type of machine learning technique in artificial intelligence (AI) that permits a system to train itself to perform tasks, such as image and speech recognition, by using multi-layered neural networks. It is also known as deep neural learning. This chapter provides a brief explanation of Python programming language along with some important libraries and datasets for deep learning. This chapter also covers the various types of loss functions related to deep learning.
