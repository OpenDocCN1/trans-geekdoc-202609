So, finally, an LSTM cell will generate two different types of outputs:

+   1. Cell State c(t).
+   2. The output of the hidden layer h(t).

Now, if we observe figure 7.1, we can see that in RNN, the output of the previously hidden layer, along with the current input, is provided to the hidden layer of each of the states. But, in the case of LSTM, current input, the output of previous gated units, and the cell state of the previous gated unit are provided as input to the gated unit of LSTM architecture.

Now, we have already discussed the working of all the gates used in the LSTM cell, so the final output c(t), that is, memory cell update is given by the following equation:

```
$c_t = \gamma_u \odot \widetilde{c}_t + \gamma_f \odot c_{t-1}$
```

Or

```
$c(t) = i(t) \otimes c'(t) + f(t) \otimes c(t - 1)$
```
