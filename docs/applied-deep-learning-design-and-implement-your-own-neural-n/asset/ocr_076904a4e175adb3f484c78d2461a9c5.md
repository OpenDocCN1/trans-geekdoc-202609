# Hinge loss function

In machine learning, hinge loss is a type of loss function that is used to train the classifiers. The loss is usually calculated in **support vector machine (SVM)** classifiers for maximum margin classification with label classes 1 and −1. Hinge loss penalizes the predictions which are wrong and also the predictions which are right but not confident.

For a target value t and predicted value p, the hinge loss is given as follows:

$L = max(0, 1 - p * t)$

It simplifies the calculations for SVM but maximizes the loss as compared to cross-entropy loss. It is often used when someone wants to make real-time decisions without much accuracy.

**Example 2:** Let us take an example of a hypothetical SVM with two items +1 and −1 (such as male and female). An SVM classifier accepts the predictor values and provides the values between −1 and +1, such as −0.2354.

Here, if the computed value of the output is a negative value, the prediction is −1, and if the value is positive, the prediction is +1. But, also, there is a term _margin_ in SVM. Suppose there is a margin of 0.2, and a set of actual and computed values is shown in **table 2.4**:

| S.No. | Target ($t_i$) | Predicted ($p_i$) | Value of cost/loss function |
|---|---|---|---|
| 1. | $t_i = -1$ | $p_i = -1$ | $L = max (0, 1 - (-1) * (-1) = 0$ (minimum) |
| 2. | $t_i = + 1$ | $p_i = + 1$ | $L = max (0, 1 - (1) * (1)) = 0$ (minimum) |
| 3. | $t_i = -1$ | $p_i = + 1$ | $L = max (0, 1 - (1) * (-1)) = 2$ |
| 4. | $t_i = + 1$ | $p_i = - 1$ | $L = max (0, 1 - (-1) * (1)) = 2$ |

**Table 2.4:** Hinge loss calculation

If we observe the preceding table, when working with SVM, if a computed output value gives a correct classification and is also larger than the margin, it means there is minimum hinge loss. But, if the computed output value gives a correct classification but is below the margin, then there is a small hinge loss.

On the other hand, if a computed value gives an incorrect classification, then there is always a large hinge loss.
