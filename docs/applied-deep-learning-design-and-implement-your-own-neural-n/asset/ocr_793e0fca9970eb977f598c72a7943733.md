# # Many-to-one sequence prediction model

The many-to-one sequence prediction model provides one output for multiple input data. Figure 6.51 shows the many to one sequence prediction model:

![](bbox=[0.29, 0.19, 0.7, 0.42])

Figure 6.51: Many-to-one sequence prediction model over different time stamps

Here, the internal state changes when every value of input before producing the actual output value. In this type of a case, the model uses a sequence of recently produced observations to predict the further values of time stamps.
