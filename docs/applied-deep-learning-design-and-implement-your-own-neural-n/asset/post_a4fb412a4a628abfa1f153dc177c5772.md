## Triplet loss

One of the suitable ways to train the Siamese neural network is to use the Triplet loss function. The Triplet loss function is a type of loss function used in deep learning techniques in which there is a need to compare an anchor input with the negative and positive input. So, we can say it is a loss function that is based on the distance, which is calculated by using the following three inputs:

- First, a data point or, say, an arbitrary image is known as the anchor (A).
- Positive input (P) where input is of the same class as of the arbitrary input (A). It is treated as close pairs.
- Finally, negative input (N), where input is of some different class as of the arbitrary input (A). It is treated as far pairs.

It can be given as follows:

```
dist(A, P) = ||x_a - x_p||^2 and dist(A, N) = ||x_a - x_n||^2
dist(A, P) <= dist(A, N)
dist(A, P) + \alpha <= dist(A, N)
dist(A, P) is at least "\alpha" less than dist(A, N) i.e dist(A, P) <= dist(A, N) - \alpha
dist(A, P) - dist(A, N) + \alpha <= 0
L(A, P, N) = max(dist(A, P) - dist(A, N) + \alpha, 0)
```

Where dist(A, P) is the similarity distance between the anchor and positive input, dist(A, N) is the similarity distance between the anchor and negative input, and \alpha is the corresponding margin.

Sometimes, the network sees hard negatives, and these are very close to each other. If dist(A, N) < dist(A, P), then these are treated as outliers.

So, finally, we have to minimize the triplet loss function by minimizing the distance from anchor to positive input, that is, dist(A, P) should come close to 0. Also, maximizing the distance from anchor to negative input, dist(A, N) should be greater than dist(A, P). So, what do the previous conditions mean? It states that, after training the Siamese neural network, the positive inputs will be close to the anchor, and the negative input will be far from the anchor. The result of triplet loss minimization is shown in figure 7.38:

![](img/7e519fee1b702b91799cdf1664598392_550_0.png)

Figure 7.38: Triplet loss minimization

So, to learn the parameters, we need an anchor, positive input, and negative input. Positive inputs are those which are similar to each other or, say, the images are of the same person, as shown in figure 7.39:

![](img/7e519fee1b702b91799cdf1664598392_551_0.png)

While the positive inputs are those which are similar to each other or, say, the images are of the same person, as shown in figure 7.40:

![](img/7e519fee1b702b91799cdf1664598392_551_1.png)

Let us take an example of minimizing the triplet loss function. Consider the following figure:

Now, we know that

L = max(dist(A, P) - dist(A, N) + α, 0)

Now, we have

dist(A, P) = 0.2

And dist(A, N) = 2.4 and say the margin value is given as α = 0.4. Therefore, by putting these values in the preceding equation, we get the following:

L = max(0.2 - 2.4 + 0.4, 0)

Therefore, L = max(-1.8, 0). Hence, L = 0.
