
## Why RNN is required?

In a feed-forward neural network, data flows in the forward direction only, starting from the input nodes, then passing through hidden nodes, and finally, moving toward the output node. The problems with the feed-forward neural network are as follows:

- No future scope.
- Decisions always depend on the current output.
- No memory of past observations.
- No cycles or loops in these neural networks.
- Cannot handle the sequential data.
- Cannot memorize the previous input data.
- Considers only the current input.

So all the upper issues can be solved by using RNN. In Figure 6.17 of an RNN, B from the X input node is going to h hidden state and A output from h hidden state is going to the Y output node, and C in the middle shows what is going on in the hidden layers. Hidden layers here produce data that is fed into the next hidden layer. This allows the model to handle sequential data effectively as it considers the current input with the previously received input:

![](img/7e519fee1b702b91799cdf1664598392_440_0.png)

Figure 6.17: Recurrent neural network

The advantages of RNN are as follows:

- It can handle sequential data effectively.
- Due to its internal memory, it can memorize the previous inputs.
- Along with the current input, it also considers the previous inputs.

## Matrix representation of fixed rule problem

```
[ 0 1 ]   [ 1 ]   [ 0 ]
[ 1 0 ] x [ 0 ] = [ 1 ]  [Orange juice]
[ 0 0 ]           [ 0 ]

[ 0 1 ]   [ 0 ]   [ 1 ]
[ 1 0 ] x [ 1 ] = [ 0 ]  [Hot coffee]
[ 0 0 ]           [ 0 ]
```

So, here if the input is hot coffee, the output from RNN is lemon water, and if the input is lemon water, then the output is Orange Juice, and if the input to RNN is Orange Juice, then the output becomes hot coffee again, and it continues like this as shown in figure 6.27. So, we will make use of a permutation matrix for achieving this cyclic notation:

![](img/7e519fee1b702b91799cdf1664598392_447_0.png)

Figure 6.27: RNN input-output model

Permutation matrix:

```
\[ \begin{bmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix} \begin{bmatrix} a \\ b \\ c \end{bmatrix} = \begin{bmatrix} c \\ a \\ b \end{bmatrix} \tag{6.1} \]
```

As we can see permutation matrix makes different permutation as \(\begin{bmatrix} a \\ b \\ c \end{bmatrix}\) will get converted into \(\begin{bmatrix} c \\ a \\ b \end{bmatrix}\) and if we provide \(\begin{bmatrix} c \\ a \\ b \end{bmatrix}\) as input then \(\begin{bmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix} \begin{bmatrix} c \\ a \\ b \end{bmatrix} = \begin{bmatrix} b \\ c \\ a \end{bmatrix}\) and further if we take \(\begin{bmatrix} b \\ c \\ a \end{bmatrix}\) as input then \(\begin{bmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix} \begin{bmatrix} b \\ c \\ a \end{bmatrix} = \begin{bmatrix} a \\ b \\ c \end{bmatrix}\). So we got a cyclic order using permutation matrix \(\begin{bmatrix} a \\ b \\ c \end{bmatrix} \rightarrow \begin{bmatrix} c \\ a \\ b \end{bmatrix} \rightarrow \begin{bmatrix} b \\ c \\ a \end{bmatrix} \rightarrow \begin{bmatrix} a \\ b \\ c \end{bmatrix}\). Similarly, in figure 6.28 permutation matrix is used on the input as the one-hot encoding of Coffee, lime juice, and orange juice to decide the next day drink.
