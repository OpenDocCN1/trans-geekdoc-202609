Here, we perform clipping of the gradient if it goes higher than a threshold value.

And to avoid the vanishing gradient problem, we can use the following methods:

+   - Use ReLU activation function: As the bound of the ReLU function is 1, it gives the output as 1 while calculating the gradient, so we can use the ReLU activation function to solve this problem.
+   - Adjust the learning rate using some methods, such as RMS propagation.
+   - Using LSTMs and GRUs:

Some neural networks, such as GRUs and LSTMs, are specially designed to solve the problem of vanishing gradients in backpropagation with time.
