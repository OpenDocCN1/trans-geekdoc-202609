In this example, DCGAN is trained on the face images, and so, for better training, all the images are resized to small and square sizes, which are centered and focused on faces only, not the background. The **dataloader** uses the composite transform to pre-process images. All types of transformations that are applied to the dataset are clubbed together in **transforms.compose()** function. After this processing, PyTorch loads the images from the disk to RAM. So, all the transforms are inside this function and are applied to the input one by one. In this example, the following transforms are applied:

+   * **transforms.Resize()**: all the input images are resized to 64 × 64 input images.
+   * **transforms.CentreCrop()**: for cropping the center of the image, that is, the faces.
+   * **transforms.ToTensor()**: input image is converted to Pytorch tensor.
+   * **transforms.Normalize()**: to learn better and faster, normalization helps to reduce the skewness of data and get it within a range. The first tuple argument represents the mean, and the second is the standard deviation value for all three channels, that is, red, green, and blue.
