Object detection can be performed by using a technique known as the *Sliding Window Technique*. In this technique, the user trains the deep learning model *ConvNet*, such that it can detect instances of different objects in an input image and further sliding windows of different sizes on top of it.

Let's discuss the Sliding window technique in detail. Suppose we have an input image of size (14*14*3) as shown in *figure 5.12*:
