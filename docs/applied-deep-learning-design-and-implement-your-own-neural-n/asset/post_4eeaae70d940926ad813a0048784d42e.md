## Calculating backpropagation of the error

The main parameters of the backpropagation are bias and weight. While performing the parameter update, the aim is to change the bias, and weights should be changed in such a manner that the loss function reaches to 0. To achieve this, the values of actual output and targeted output should be close or the same.

So, what should be the value of We if the value of l(W, B) = 0.

In other words, we can say that how will l(W, B) change when there is a change in the value of We, which can be given as the partial derivative as follows:

```
\partial l(W, B)/\partial W_e
```

By using the chain rule:

```
\frac{\partial l(W, B)}{\partial W_e} = \frac{\partial l(W, B)}{\partial y_1} * \frac{\partial y_1}{\partial i_3} * \frac{\partial i_3}{\partial W_e}
```

```
\frac{\partial l(W, B)}{\partial y_1} = \frac{\partial(0.5(O_a - y_1)^2 - 0.5(O_b - y_2)^2)}{\partial y_1}
```

```
= 2 * 0.5(O_a - y_1)^{2-1}(-1) + 0
```

```
= -(O_a - y_1)
```

```
= -(0 - 0.710)
```

```
= 0.710
```

The main purpose of using 0.5 in the loss function is to keep the calculation of the derivative simple. We know that:

```
\frac{\partial f(x)}{\partial x} = f(x) * [1 - f(x)]
```

Therefore,

\(\frac{\partial y_1}{\partial i_3} = (1 - y_1) * y_1\)
\(= (1 - 0.710) * 0.710\)
\(= 0.20\)

And also,

\(i_3 = a_1 W_e + a_2 W_g + B_c\)

Therefore,

\(\frac{\partial i_3}{\partial W_e} = 1 * a_1 * W_e^0 + 0 + 0\)
\(\frac{\partial i_3}{\partial W_e} = a_1 = 0.620\)

Substituting the value of a1 in the preceding equation, we get the following:

\(\frac{\partial l(W, B)}{\partial W_e} = 0.710 * 0.620 * 0.20\)
\(\frac{\partial l(W, B)}{\partial W_e} = 0.1\)

Similarly, calculate weights for wf, wg, and wh. We get the following:

\(\frac{\partial l(W, B)}{\partial W_f} = -0.060\)
\(\frac{\partial l(W, B)}{\partial W_g} = 0.069\)
\(\frac{\partial l(W, B)}{\partial W_h} = -0.049\)

For generalizing, we can write the error at the output neuron j as follows:

\(Error_j = -(y_j) * (1 - y_j) * (O_1 - y_1)\)

Now, the gradient at output neuron j is given as follows:

\(\frac{\partial l(W, B)}{\partial W_p} = Error_j * a_h\)

## Effect of integration on the derivative of the cost function

Consider the following cost function as C:

$$
c = \frac{(y-a)^2}{2}
							(3.41)
$$
$$
\frac{\partial c}{\partial a} = \frac{\partial}{\partial a}\left\{ \frac{(y - a)^2}{2} \right\}
$$
$$
\frac{\partial c}{\partial a} = \frac{1}{2} * \frac{\partial}{\partial a} (y - a)^2
$$
$$
\frac{\partial c}{\partial a} = 2 * \frac{1}{2} * (y - a) * (-1)
$$
$$
\frac{\partial c}{\partial a} = (a - y)
							(3.42)
$$

Now, as we know that, by chain rule:

$$
\frac{\partial c}{\partial w} = \frac{\partial c}{\partial a} * \frac{\partial a}{\partial z} * \frac{\partial z}{\partial w}
							(3.43)
$$

By substituting equations (3.42), (3.21) and $\frac{\partial a}{\partial z} = \partial'(z)$ in equation (3.43), we get the following equation (3.44):

$$
\frac{\partial c}{\partial w} = (a - y) * \partial'(z) * x
							(3.44)
$$

As $\frac{\partial a}{\partial z} = \partial'(z) = a(1 - a)$, if the activation function is considered as sigmoid by substituting this in equation (3.44), we get the following equation (3.45):

$$
\frac{\partial c}{\partial w} = (a - y) * \partial'(z) * x
							(3.45)
$$

Also,

$$
\frac{\partial c}{\partial b} = \frac{\partial c}{\partial a} * \frac{\partial a}{\partial z} * \frac{\partial z}{\partial b}
							(3.46)
$$

As:

\(\frac{\partial z}{\partial b} = \frac{\partial}{\partial b}(wx_i + b)\)

\(\frac{\partial z}{\partial b} = 1 \quad (3.47)\)

Substituting equations (3.42) and (3.47) in equation (3.46), we get the following equation (3.48):

\(\frac{\partial c}{\partial b} = (a - y) * \partial'(z) * 1 \quad (3.48)\)

\(\frac{\partial c}{\partial b} = (a - y) * \partial'(z) \quad (3.49)\)

As from equation (3.16), \(\frac{\partial c^*}{\partial b} = (a - y)\) from gradient descent for linear regression as derived earlier. Therefore, after substituting L.H.S of equation (3.42) in equation (3.49), we can write:

\(\frac{\partial c^*}{\partial b} = \frac{\partial c^*}{\partial a} * \partial'(z)\)

As \(\partial'(z) = a(1 - a)\), as sigmoid activation function is taken, so:

\(\frac{\partial c^*}{\partial b} = \frac{\partial c^*}{\partial a} * a(1 - a) \quad (3.50)\)

Replacing \(\frac{\partial c^*}{\partial b} = a - y\) in equation (3.50), we get the following equation:

\(\frac{\partial c^*}{\partial a} * a(1 - a) = a - y \quad (3.51)\)

\(\frac{\partial c^*}{\partial a} = \frac{a - y}{a(1 - a)} \quad (3.52)\)

Integrating equation (3.52) with respect to \(a\), we get the following:

\(\int \partial c^* = \int \frac{a - y}{a(1 - a)} . da \quad (3.53)\)

Now, applying partial integration to solve the equation (3.53):

\(\mathcal{C} = \int \frac{a - y}{a(1 - a)} . da \quad (3.54)\)

By applying the rule of integration using partial integration:

\(\frac{a - y}{a(1 - a)} = \frac{A}{a} + \frac{B}{1 - a} \quad (3.55)\)

\((a - y) = A(1 - a) + B(a) \quad (3.56)\)

Putting $1 - a = 0$ in *equation (3.56)*, we get $a = 1$. Therefore, after substituting $a$ in *equation (3.56)*, we get the following equation:

$(1 - y) = A(1 - 1) + B(1)$

$B = (1 - y)$ (3.57)

Putting $a = 0$ in $(a - y) = A(1 - a) + B(a)$, we get:

$-y = A(1) + 0$

$A = -y$ (3.58)

Substituting the values of $A$ (from *equation 3.58*) and $B$ (from *equation 3.57*) in *equation (3.55)* \(\frac{a-y}{a(1-a)} = \frac{A}{a} + \frac{B}{1-a}\), we get the following equation:

\(\frac{a-y}{a(1-a)} = \frac{-y}{a} + \frac{1-y}{1-a}\) (3.59)

Therefore, after integrating *equation (3.59)* with respect to a, we get the following equation (3.60):

\(\int \partial c^* = \int \frac{a-y}{a(1-a)} da = -y \int \frac{1}{a} da + (1 - y) \int \frac{1}{1-a} da\) (3.60)

As, \(\int \frac{1}{a} da = \log(a)\) and \(\int \frac{1}{1-a} da = -(\log(1 - a))\), substituting these values in *equation(3.60)*:

\(C = \int \frac{a-y}{a(1-a)} da = -y \log(a) - (1 - y) \log(1 - a) + c\)

\(\int \frac{a-y}{a(1-a)} da = C \text{ ( i.e. Binary entropy cost function )}\) (3.61)

\(C \text{ ( that is, Binary entropy cost function )}\)

We notice that when we integrate the derivative of the cost function, we find the original binary cross-entropy function (3.61) as the output because the derivative and integration work as inverse relations to each other.
