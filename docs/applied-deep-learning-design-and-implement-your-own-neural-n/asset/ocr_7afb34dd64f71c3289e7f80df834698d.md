A batch size of 128 is used, meaning that the number of training examples used in one iteration as mentioned in the paper of DCGAN. The dataset has colored images, so nc, that is, the number of channels are three, each for red, green, and blue. The input to the Generator is a latent vector, that is, nz (random vector noise) with size 100. The size of the latent vector can be varied depending on the complexity of the distribution; such as for MNIST, good results can be obtained with 16 variables, and in the case of sophisticated datasets the value can be increased to even 1000.

The size for the feature maps for both Generator and Discriminator is 64. The model is trained for 20 epochs, and it took around 90 minutes to train the model. The learning rate is set to a small value in order to have better learning. Beta1 is a hyperparameter for the Adam optimizer, which computes the moving average of the gradient, and beta1 controls the decay rates of these moving averages. These parameters are described in the DCGAN paper in much detail. The last parameter ngpu tells if GPU is available or not. If this number is greater than zero, then the code will run on GPUs; otherwise, it will run on the CPU.
