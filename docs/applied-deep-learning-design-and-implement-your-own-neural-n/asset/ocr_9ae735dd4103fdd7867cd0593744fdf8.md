+   - After that, the model is again trained. Training of the first layer of the model is done based on the number of classes of objects we want to detect.
+   - Then, the RCNN determines the region of interest for the input image by using a selective search algorithm.
+   - After that, reshaping of the region of interest is done, so it can be matched with the input size of CNN.
+   - Furthermore, training of SVM is performed for the classification of different objects and backgrounds of the image.
+   - Here, for every class, a binary SVM is trained.
+   - Then, a linear regression model is trained to generate the bounding boxes for each of the identified objects.
