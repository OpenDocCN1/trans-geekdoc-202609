
The preceding equation represents that _a_ is more similar to _c_ than _b_. The value of the similarity measure varies from 0 to 1. So, if two objects have a low or less similarity measure means they are not similar, and if the similarity measure value is greater or closer to 1, that means they are almost similar.

Now, there are certain mathematical measures where we estimate the similarity measures in the clustering process. Let us discuss some of them.

## Euclidean distance or L2 distance norm

Say the data set we are using is dense and continuous [0, 1..... , _n_]. In these types of cases, we use the Euclidean distance as a parameter here while doing the clustering.

Euclidean distance is defined as the length of the path connecting two points, say _p_ and _q_. Say we have the two points as given in Figure 7.27:

![](img/7e519fee1b702b91799cdf1664598392_536_0.png)

**Figure 7.27:** Euclidean distance metric

So, here we use Pythagoras’ theorem to calculate the Euclidean distance, which is given as follows:

```
d(x, y) = \sqrt{\sum_{i=1}^{N} (x_i - y_i)^2}
```

## Manhattan distance

Say there are four points or locations, as shown in Figure 7.28:

![](img/7e519fee1b702b91799cdf1664598392_537_0.png)

**Figure 7.28:** Manhattan distance metric

Now, we want to find out the distance between two locations; we use Manhattan distance here. Manhattan distance is defined as the sum of the absolute distance of their coordinates.

Mathematically, the Manhattan distance is given as follows:

```
D(A, B) = |x1 - x2| + |y1 - y2|
```

## Cosine similarity for sparse vector or sparse data set

It determines the normalization of two objects, therefore, finding the angle of separation θ. It judges the two input vectors rather than their magnitude. Here, the data objects are considered vectors:

![](img/7e519fee1b702b91799cdf1664598392_537_1.png)

**Figure 7.29:** Cosine angle similarity

It is given as follows:

$$Cos(x, y) = \frac{x.y}{||x|| * ||y||}$$

**Example 7.2:** Suppose we have two vectors x and y, as follows:

x = {3,2,0,5}
y = {1,0,0,0}

x.y = 3 * 1 + 2 * 0 + 0 * 0 + 5 * 0

x.y = 3

Now,

$$||x|| = \sqrt{3^2 + 2^2 + 0^2 + 5^2}$$

$$||x|| = 6.16$$

And

$$||y|| = \sqrt{1^2 + 0^2 + 0^2 + 0^2}$$

$$||y|| = 1$$

Therefore,

$$Cos(x, y) = \frac{3}{6.16 * 1}$$

$$Cos(x, y) = 0.49$$

We can also find the cosine dissimilarity between x and y, which is given as follows:

$$dis(x, y) = 1 - Cos(x, y)$$

So, in our case

$$dis(x, y) = 1 - 0.49$$

$$dis(x, y) = 0.51$$

Now, if the cosine angle is 0 degree, then the objects are 100% similar, and if the θ is 90 degrees, then the objects are different.

## Jaccard similarity

Jaccard similarity between a and b is given as follows:

$$Sim(a, b) = \frac{\sum_{i=1}^d a_i b_i}{\sum_{i=1}^d a_i^2 + \sum_{i=1}^d b_i^2 - \sum_{i=1}^d a_i b_i}$$

**Example 7.3:** Suppose we have two vectors a and b, as follows:
$a = \{1,2,3,1\}$
$b = \{3,1,2,1\}$

So, first, calculating $\sum_{i=1}^d a_i b_i$
$$
\sum_{i=1}^d a_i b_i = 1 * 3 + 2 * 1 + 3 * 2 + 1 * 1
$$
$$
\sum_{i=1}^d a_i b_i = 3 + 2 + 6 + 1
$$

Therefore,
$$
\sum_{i=1}^d a_i b_i = 12
$$

And
$$
\sum_{i=1}^d a_i^2 = 1^2 + 2^2 + 3^2 + 1^2
$$
$$
\sum_{i=1}^d a_i^2 = 1 + 4 + 9 + 1
$$

Therefore,
$$
\sum_{i=1}^d a_i^2 = 15
$$

And also,
$$
\sum_{i=1}^d b_i^2 = 3^2 + 1^2 + 2^2 + 1^2
$$
$$
\sum_{i=1}^d b_i^2 = 9 + 1 + 4 + 1
$$

Therefore,
$$
\sum_{i=1}^d b_i^2 = 15
$$

Now, we know,

\(Sim(a, b) = \frac{\sum_{i=1}^d a_i b_i}{\sum_{i=1}^d a_i^2 + \sum_{i=1}^d b_i^2 - \sum_{i=1}^d a_i b_i}\)

Putting all the values in the preceding equation, we get the following:

\(Sim(a, b) = \frac{12}{15 + 15 - 12}\)

\(Sim(a, b) = \frac{12}{18}\)

Therefore,

\(Sim(a, b) = 0.66\)

## Dice similarity

Dice similarity between \(a\) and \(b\) is given as follows:

\(Sim(a, b) = \frac{2 \sum_{i=1}^d a_i b_i}{\sum_{i=1}^d a_i^2 + \sum_{i=1}^d b_i^2}\)

Let us take the same example again.

**Example 7.4:** Suppose we have two vectors \(a\) and \(b\), as follows:

\(a = \{1, 2, 3, 1\}\)

\(b = \{3, 1, 2, 1\}\)

So, first, calculating \(\sum_{i=1}^d a_i b_i\)

\(\sum_{i=1}^d a_i b_i = 1 * 3 + 2 * 1 + 3 * 2 + 1 * 1\)

\(\sum_{i=1}^d a_i b_i = 3 + 2 + 6 + 1\)

Therefore,

\(\sum_{i=1}^d a_i b_i = 12\)

And

\(\sum_{i=1}^d a_i^2 = 1^2 + 2^2 + 3^2 + 1^2\)

\(\sum_{i=1}^d a_i^2 = 1 + 4 + 9 + 1\)

Therefore,

\(\sum_{i=1}^d a_i^2 = 15\)

And also

\(\sum_{i=1}^d b_i^2 = 3^2 + 1^2 + 2^2 + 1^2\)

\(\sum_{i=1}^d b_i^2 = 9 + 1 + 4 + 1\)

Therefore,

\(\sum_{i=1}^d b_i^2 = 15\)

Now, we know

\(Sim(a, b) = \frac{2 \sum_{i=1}^d a_i b_i}{\sum_{i=1}^d a_i^2 + \sum_{i=1}^d b_i^2}\)

Putting all values in the preceding equation, we get the following:

\(Sim(a, b) = \frac{2 * 12}{15 + 15}\)

\(Sim(a, b) = \frac{24}{30}\)

Therefore,

\(Sim(a, b) = 0.8\)

## Overlap similarity

Overlap similarity between a and b is given as follows:

\(Sim(a, b) = \frac{\sum_{i=1}^d a_i b_i}{min(\sum_{i=1}^d a_i^2, \sum_{i=1}^d b_i^2)}\)

So, for this case also, we are taking the same example.

**Example 7.5:** Suppose we have two vectors:

a = {1,2,3,1}

b = {3,1,2,1}

So, first, calculating $\sum_{i=1}^d a_i b_i$

$\sum_{i=1}^d a_i b_i = 1 * 3 + 2 * 1 + 3 * 2 + 1 * 1$

$\sum_{i=1}^d a_i b_i = 3 + 2 + 6 + 1$

Therefore,

$\sum_{i=1}^d a_i b_i = 12$

And

$\sum_{i=1}^d a_i^2 = 1^2 + 2^2 + 3^2 + 1^2$

$\sum_{i=1}^d a_i^2 = 1 + 4 + 9 + 1$

Therefore,

$\sum_{i=1}^d a_i^2 = 15$

And also

$\sum_{i=1}^d b_i^2 = 3^2 + 1^2 + 2^2 + 1^2$

$\sum_{i=1}^d b_i^2 = 9 + 1 + 4 + 1$

Therefore,

$\sum_{i=1}^d b_i^2 = 15$

Now, we know

```
Sim(a, b) = \frac{\sum_{i=1}^d a_i b_i}{min(\sum_{i=1}^d a_i^2, \sum_{i=1}^d b_i^2)}
```

Putting all values in the preceding equation, we get the following:

```
Sim(a, b) = \frac{12}{min(15,15)}
Sim(a, b) = \frac{12}{15}
```

Therefore,

```
Sim(a, b) = 0.8
```

## Siamese networks

Siamese network is another type of neural network that possesses several instances for a single model. They also show the same type of architecture. We need Siamese neural networks when dealing with a limited amount of data or do not have the complete data set.

Traditional neural networks learn the task of prediction when trained with several classes. But if we want to insert or delete some classes to the data set, it cannot be performed in the case of traditional neural networks because, in such cases, one needs to update the whole neural network and train the model on the complete data set. The following figure shows a traditional Artificial Neural Network:

![](img/7e519fee1b702b91799cdf1664598392_543_0.png)

**Figure 7.30:** Traditional ANN

While Siamese neural networks learn using a similarity function, they can be trained for two same images, which gives the advantage of classifying a new class of objects without retraining the network.

The Siamese neural network is shown in Figure 7.31. In these types of networks, we have given a pair of images, and we have to find how similar they are to each other. The solution to this is to build two identical networks, as shown in Figure 7.31:

![](img/7e519fee1b702b91799cdf1664598392_544_0.png)

**Figure 7.31:** Siamese neural network

Siamese neural network is mostly used for one-shot learning. Now, what is one-shot learning? Before moving to one-shot learning, we need to know how classification is carried out.

The process of classification involves learning a neural network-based model by providing numerous examples of different classes. Then, the trained model is used to predict the new objects of the classes being trained.

But in one-shot learning, a smaller number of examples of each class is provided to the model for training purposes. Then, the trained model is used to predict many new objects of the classes provided while training.

Siamese neural network is used in the case of one-shot learning. Siamese network is a neural network architecture having two neural networks running in parallel, which take different inputs and then their outputs are combined to make the predictions.
