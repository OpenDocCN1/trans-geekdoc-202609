# Unzip the dataset

Due to the large size of the datasets, they are generally compressed in order to save some space. But before using a dataset, it should be uncompressed. This is done using the following colab script. Using unzip command, the data is extracted and ready to use.

```
#unzip the images
!unzip "/gdrive/My Drive/img_align_celeba.zip"
```

# Checking the content of dataset

In order to check the content of the dataset, the listing command ls is used. It will list out all the contents of the dataset folder. As shown in the output, there are more than two lakh images in this dataset.

```
!ls "img_align_celeba/"
```

In order to run this code on some other dataset, all you need to do is upload a new dataset to your Google Drive, mount the drive to your colab, extract the dataset and train your model over a new dataset.

# Setting parameters

Before the training starts, some important parameters are there that need to be set, such as dataroot, which specifies the path to the root of the dataset folder, and the value of workers, which indicates the number of threads for loading the data with Data Loader, so that instead of the main program, data loading is handled by these workers.
