# # Perceptron learning rule

The perceptron working is illustrated in figure 3.12. In the figure, there are four inputs say \([x_1, x_2, x_3, x_4]\), weights \([w_1, w_2, w_3, w_4]\), and one output Y. The learning algorithm for perceptron is as follows:

+   1. Initialize the weights of the network connections randomly.
+   2. Randomly select a training set sample without any replacement.
+   3. Perform the task of affine transformation to weights and inputs as \(l = \sum_i(w_{ij}x_i + b_j)\).
+   4. Pass the outputs of the affine transformation to the activation function to determine the class labels.
+   5. Using the perceptron learning rule, perform updates on weights.
+   6. Repeat the preceding steps to achieve the correct value of the input.

The activation function used in the perceptron is Sign or Binary activation function. The equation for sign activation function is given as follows:

```
sign(x) = \begin{cases} -1; & \text{if } x < 0 \\ 0; & \text{if } x = 0 \\ 1; & \text{if } x > 0 \end{cases}
```
