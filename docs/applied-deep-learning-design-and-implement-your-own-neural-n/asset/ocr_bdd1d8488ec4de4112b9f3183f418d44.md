# # Loss function in fast RCNN

Here, the loss function should be optimized for two tasks localization and classification. Therefore, the loss function is the sum of classification cost and prediction cost for the bounding boxes as follows:

```
L = L_{classif.} + L_{bound.} \.
```

Now, with respect to background RoI, the value of L_{bound.} can be ignored by using an indicator function which is as follows:

```
1[u \ge 1] = \begin{cases} 0 & \text{for } u < 0 \\ 1 & \text{otherwise} \end{cases}
```

Where u is the actual class label such that

```
u = [0, 1, .... K]
```

The overall loss function for Fast CNN can be given as follows:

```
L(P, u, v, t^u) = L_{classif.}(P, u) + 1[u \ge 1]L_{bound.}(t^u, v)
```

And we know that

```
L_{classif.}(P, u) = -\log P_u \\
L_{bound.}(t^u, v) = \sum_{i=(x,y,w,h)} L_1(t_i^u - v_i)
```

The bounding box loss L_{bound.} must be calculated using robust loss functions by calculating the difference between t_i^u and v_i.

where P is the probability distribution on K+1 number of classes such that

```
P = P_0, P_1, .... , P_K
```

v, denotes the actual bounding box such that

```
v = (v_x, v_y, v_w, v_h)
```

And, t^u is the correction in the predicted bounding box such that

```
t^u = (t_x^u, t_y^u, t_w^u, t_h^u)
```

Now, as a robust loss function, we have used here smooth loss function because it is very less reactive to outliers and is given as follows:

```
L_1^{Smooth} = \begin{cases} x - 0.5, & x \ge 1 \\ 0.5(x)^2, & \text{otherwise} \end{cases}
```
