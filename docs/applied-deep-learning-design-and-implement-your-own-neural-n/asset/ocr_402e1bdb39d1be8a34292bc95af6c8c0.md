We have already discussed image processing concepts in Chapter 4: Convolutional Neural Networks. Image processing is different from computer vision. A brief difference between these two is given in table 5.1:

| S.no. | Computer vision | Image processing |
|---|---|---|
| 1. | Computer vision focuses on the symbolic, semantic, and geometric descriptions of the image or video. | Image processing focuses on syntax and low-level architectures. |
| 2. | Computer vision is the research field of Artificial Intelligence. | Image processing is the research field of Signal Processing. |
| 3. | Computer vision basically extracts the features from the image or video to predict the description of the objects, such as whether the object is a chair, car, and so on. | Image processing basically converts one image into another. |
| 4. | Image/ Video → Computer Vision → Symbols, Description | Image → Image |

Table 5.1: Difference between computer vision and image processing

# Computer vision tasks

In the area of computer vision, there are various tasks as follows:

+   - Object recognition
+     - Image classification
+     - Object localization
+     - Object detection
+   - Semantic segmentation
+   - Instance segmentation
+   - Image captioning

# Object recognition

The term object recognition is used to define a group of computer vision tasks that involves recognizing different types of objects in a digital image. Object recognition is one of the important applications of deep learning.
