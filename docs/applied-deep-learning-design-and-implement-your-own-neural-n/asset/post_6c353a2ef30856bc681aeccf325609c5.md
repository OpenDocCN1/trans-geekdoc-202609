

## Binary classification loss function

Binary classification is the process of assigning an object to two different classes, where the classification is usually based on a predefined rule applied to the input features. For example, the classification of an e-mail, that is, if the e-mail is spam or not based on its subject line is a type of binary classification.

## Binary cross-entropy loss function

Entropy is used to indicate uncertainty or disorder. The entropy for a random variable Y with probability distribution p(Y) is defined as follows:

```
CE = f(y) = \begin{cases} -\int p(y)logp(y) dy, & \text{if } y \text{ is continuous} \\ -\sum_y p(y) logp(y), & \text{if } y \text{ is discrete} \end{cases}
```

Where CE represents the cross-entropy. A smaller value of CE represents more certain distribution, whereas a larger value of entropy represents greater uncertainty in the distribution. The cross-entropy loss for targeted value t and predicted value p is given as follows:

```
L = -tlog(p) - (1 - t) log(1 - p) = \begin{cases} -log(1 - p), & \text{if } t = 0 \\ -log(p), & \text{if } t = 1 \end{cases}
```

Where L is the binary cross-entropy loss function. We generally use the sigmoid function to represent the binary cross-entropy loss as given in the following figure:

![](img/7e519fee1b702b91799cdf1664598392_112_0.png)

Figure 2.12: Sigmoid Curve

Example 1: Let us suppose there are two classes as C1 and C2. Label1 [0, 1] represents the label for class C1 and C2 represents the sigmoid score for the class C1.

Then, the label for class C2 is given as Label2 = (1 – Label1) and the sigmoid score is P2 = (1 – P1).

Where the sigmoid score is computed as follows:

```
P_i = \frac{1}{1 + e^{-p_i}}
```

Then, the cross-entropy loss is given as follows:

```
L = -t_i log(P_i) + (1 - t_i) log(1 - P_i)
```

Therefore, binary cross-entropy loss is given as follows:

```
L(Binary) = -t_1 log(P_1) + (1 - t_1) log(1 - P_1)
```

The mean binary cross-entropy loss is given as follows:

```
L_{mean} = \frac{1}{N} \sum_{i=1}^{N} -t_1 log(P_1) + (1 - t_1) log(1 - P_1)
```

Its illustrative example is as given in the following table 2.3:

| S.No. | Target ($t_i$) | Predicted ($p_i$) | Value of cost/loss function |
|---|---|---|---|
| 1. | $t_i = 0$ | $p_i = 0$ | CE = - 0 * log(0) + (1 - 0) * log(1 - 0)) = 0 (minimum) |
| 2. | $t_i = 1$ | $p_i = 1$ | CE = - 1 * log(1) + (1 - 1) * log(1 - 1)) = 0 (minimum) |
| 3. | $t_i = 0$ | $p_i = 1$ | CE = - 0 * log(1) + (1 - 0) * log(1 - 1)) = $\infty$ (maximum) |
| 4. | $t_i = 1$ | $p_i = 0$ | CE = - 1 * log(0) + (1 - 1) * log(1 - 0)) = $\infty$ (maximum) |

**Table 2.3:** Binary cross-entropy loss function calculation

Table 2.3 represents the values of a binary cross-entropy loss function. The loss is 0 (minimum) when both the targeted and predicted values are the same and maximum $\infty$ (maximum) when the values are different.

## Hinge loss function

In machine learning, hinge loss is a type of loss function that is used to train the classifiers. The loss is usually calculated in **support vector machine (SVM)** classifiers for maximum margin classification with label classes 1 and −1. Hinge loss penalizes the predictions which are wrong and also the predictions which are right but not confident.

For a target value t and predicted value p, the hinge loss is given as follows:

$L = max(0, 1 - p * t)$

It simplifies the calculations for SVM but maximizes the loss as compared to cross-entropy loss. It is often used when someone wants to make real-time decisions without much accuracy.

**Example 2:** Let us take an example of a hypothetical SVM with two items +1 and −1 (such as male and female). An SVM classifier accepts the predictor values and provides the values between −1 and +1, such as −0.2354.

Here, if the computed value of the output is a negative value, the prediction is −1, and if the value is positive, the prediction is +1. But, also, there is a term _margin_ in SVM. Suppose there is a margin of 0.2, and a set of actual and computed values is shown in **table 2.4**:

| S.No. | Target ($t_i$) | Predicted ($p_i$) | Value of cost/loss function |
|---|---|---|---|
| 1. | $t_i = -1$ | $p_i = -1$ | $L = max (0, 1 - (-1) * (-1) = 0$ (minimum) |
| 2. | $t_i = + 1$ | $p_i = + 1$ | $L = max (0, 1 - (1) * (1)) = 0$ (minimum) |
| 3. | $t_i = -1$ | $p_i = + 1$ | $L = max (0, 1 - (1) * (-1)) = 2$ |
| 4. | $t_i = + 1$ | $p_i = - 1$ | $L = max (0, 1 - (-1) * (1)) = 2$ |

**Table 2.4:** Hinge loss calculation

If we observe the preceding table, when working with SVM, if a computed output value gives a correct classification and is also larger than the margin, it means there is minimum hinge loss. But, if the computed output value gives a correct classification but is below the margin, then there is a small hinge loss.

On the other hand, if a computed value gives an incorrect classification, then there is always a large hinge loss.

## Regression loss function

Regression deals with the modeling of a linear relationship between multiple independent variables and one dependent variable.

### Mean squared error loss function

Squared error loss is the square of the difference between the actual and predicted values:

```
L = (t – p)²
```

The corresponding cost function is the mean of these values of squared errors.

The mean squared error (MSE) loss function reduces the errors made by the model by squaring them. It is given as follows:

```
MSE = 1/n Σᵢⁿ (tᵢ – pᵢ)²
```

### Absolute error loss function

Absolute error loss is the difference between the predicted and actual values, irrespective of the sign. It is also known as L1 loss and is given as follows:

```
L = |t - p|
```

### Huber loss

It is the combination of both mean square error and mean absolute error. It is quadratic in nature for small errors and linear for large errors. It is denoted by the delta parameter.

```
L_\delta = \begin{cases} 0.5(t - p)^2, & \text{if } |t - p| < \tau \\ \tau |t - p| - 0.5\tau^2, & \text{Otherwise} \end{cases}
```

where \(\tau\) is a parameter such that \(\tau \in \mathbb{R}^+\), and R is a real number.
