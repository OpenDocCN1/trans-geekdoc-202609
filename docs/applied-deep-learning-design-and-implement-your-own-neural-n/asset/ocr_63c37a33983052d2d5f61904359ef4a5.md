Among all of the distributions, we would like to discuss the importance of one distribution here, called **normal distribution** (or the bell-shaped curve or Gaussian distribution). This is the distribution that represents the behavior of many real-life situations, and so it is used in a wide range of applications. It may be the reason behind calling it normal distribution. For a distribution to be normally distributed, it should be bell-shaped and symmetrical around its mean, as shown in figure 8.6:

It is an example of a continuous probability distribution in which all the possible outcomes in the range (−infinity, +infinity) can be calculated. This is the simplest distribution, which is easy to understand, but there are various kinds of data that are very complex and cannot be represented with a normal distribution. That is why there are other distributions also available.

Every real-life problem that is solved by machine learning or deep learning requires data in any of form, such as text, audio, video, images, greyscale, and so on. All of these data are internally stored in numerical form and follow some probability distributions. These distributions represent the inbuilt characteristics of the datasets. Consider an example of a picture of a dog. A dog has some special features, such as floppy ears, four legs, and so on. When a dataset is created having lots of dog pictures, with all of them sharing similar special feature’s structures, then this data set would definitely follow a specific probability distribution. Similarly, a floral dataset would have some different but specific probability distribution.
