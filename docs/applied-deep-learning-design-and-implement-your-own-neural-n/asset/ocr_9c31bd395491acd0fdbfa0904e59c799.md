# Sequential data

In our daily life, sequences occur almost everywhere. A sequence can be defined as a group of elements in which every element is indexed; that is, the elements are numbered in their arriving sequence. In the case of sequential data, repetitions are allowed; that is, several elements can appear multiple times in a sequence.
