# Use of Rectified Linear unit in CNN (ReLU)

ReLU acts as an activation function that is used in CNN to change negative values to zero. We apply this to eliminate negative values from activation maps that are generated by convolution. We apply ReLU to introduce sparsity. Figures 4.146 to 4.149 show the effect of ReLU on the three activation maps that we got in figure 4.137.
