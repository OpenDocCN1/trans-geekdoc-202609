Example 1: Let us suppose there are two classes as C1 and C2. Label1 [0, 1] represents the label for class C1 and C2 represents the sigmoid score for the class C1.

Then, the label for class C2 is given as Label2 = (1 – Label1) and the sigmoid score is P2 = (1 – P1).

Where the sigmoid score is computed as follows:

```
P_i = \frac{1}{1 + e^{-p_i}}
```

Then, the cross-entropy loss is given as follows:

```
L = -t_i log(P_i) + (1 - t_i) log(1 - P_i)
```

Therefore, binary cross-entropy loss is given as follows:

```
L(Binary) = -t_1 log(P_1) + (1 - t_1) log(1 - P_1)
```

The mean binary cross-entropy loss is given as follows:

```
L_{mean} = \frac{1}{N} \sum_{1}^{N} -t_1 log(P_1) + (1 - t_1) log(1 - P_1)
```

Its illustrative example is as given in the following table 2.3:

| S.No. | Target ($t_i$) | Predicted ($p_i$) | Value of cost/loss function |
|---|---|---|---|
| 1. | $t_i = 0$ | $p_i = 0$ | CE = - 0 * log(0) + (1 - 0) * log(1 - 0)) = 0 (minimum) |
| 2. | $t_i = 1$ | $p_i = 1$ | CE = - 1 * log(1) + (1 - 1) * log(1 - 1)) = 0 (minimum) |
| 3. | $t_i = 0$ | $p_i = 1$ | CE = - 0 * log(1) + (1 - 0) * log(1 - 1)) = $\infty$ (maximum) |
| 4. | $t_i = 1$ | $p_i = 0$ | CE = - 1 * log(0) + (1 - 1) * log(1 - 0)) = $\infty$ (maximum) |
