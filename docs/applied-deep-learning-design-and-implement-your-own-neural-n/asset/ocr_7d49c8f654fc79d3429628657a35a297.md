The target values can be given as follows:

$t_x = \frac{(g_x - P_x)}{P_w}$

and

$t_y = \frac{(g_y - P_y)}{P_h}$

and

$t_w = log \frac{g_w}{P_w}$

and

$t_h = log \frac{g_h}{P_h}$

The standard model of regression, which can be used to solve the issue while reducing the SSE loss, along with the regularization, is given as follows:

$L_{regr} = \sum_{i=(x,y,w,h)} (t_i - d_i(P))^2 + \partial(w)^2$
