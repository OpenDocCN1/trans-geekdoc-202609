# Binary classification loss function

Binary classification is the process of assigning an object to two different classes, where the classification is usually based on a predefined rule applied to the input features. For example, the classification of an e-mail, that is, if the e-mail is spam or not based on its subject line is a type of binary classification.

# Binary cross-entropy loss function

Entropy is used to indicate uncertainty or disorder. The entropy for a random variable Y with probability distribution p(Y) is defined as follows:

```
CE = f(y) = \begin{cases} -\int p(y)logp(y).dy, & \text{if } y \text{ is continous} \\ -\sum_y p(y).logp(y), & \text{if } y \text{ is discrete} \end{cases}
```

Where represents the cross-entropy. A smaller value of represents more certain distribution, whereas a larger value of entropy represents greater uncertainty in the distribution. The cross-entropy loss for targeted value t and predicted value p is given as follows:

```
L = -tlog(p) - (1 - t) log(1 - p) = \begin{cases} -log(1 - p), & \text{if } t = 0 \\ -log(p), & \text{if } t = 1 \end{cases}
```
