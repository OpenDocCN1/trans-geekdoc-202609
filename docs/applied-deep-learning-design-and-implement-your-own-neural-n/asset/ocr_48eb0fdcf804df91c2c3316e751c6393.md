Statistical models consist of a group of probability distribution functions, which can be used to define different variabilities which data or random variables denote. In these types of models, defining the model invariance is done by using group theory. All types of statistical estimators and statistical hypothesis tests can be derived by using statistical models. So, statistical modeling allows us to find out the probability of happening of any event.

We discuss the two statistical assumptions regarding dice as follows.

+   - Statistical assumption for unbiased pair of dice
+   
+   The probability of the occurrence of every face (say 1, 2, 3, 4, 5, or 6) is 1/6 when both the dices are unbiased. From this assumption, we can calculate the probability of getting four on the faces of a pair of dice as follows.
+   
+   1/6 × 1/6 = 1/36
+   
+   Similarly, we can calculate the probability of occurrence of any event, such as (1 and 3), (2 and 4), (5 and 6), and so on.

+   - Statistical assumption for weighted pair of dice
+   
+   The probability of the occurrence of every face (say 1, 2, 3, 4, 5 or 6) is 1/8 when both the dice are weighted.
