# # Why RNN is required?

In a feed-forward neural network, data flows in the forward direction only, starting from the input nodes, then passing through hidden nodes, and finally, moving toward the output node. The problems with the feed-forward neural network are as follows:

+   * No future scope.
+   * Decisions always depend on the current output.
+   * No memory of past observations.
+   * No cycles or loops in these neural networks.
+   * Cannot handle the sequential data.
+   * Cannot memorize the previous input data.
+   * Considers only the current input.

So all the upper issues can be solved by using RNN. In _figure 6.17_ of an RNN, _B_ from the _X_ input node is going to _h"_ hidden state and _A_ output from _h_ hidden state is going to the _Y_ output node, and _C_ in the middle shows what is going on in the hidden layers. Hidden layers here produce data that is fed into the next hidden layer. This allows the model to handle sequential data effectively as it considers the current input with the previously received input:
