AI is divided into two broad categories: strong AI and weak AI. Strong AI systems are those which can perform human-like typical tasks. Weak AI, also known as narrow AI, is another type of machine intelligence technique that is restricted to a narrow or explicit area. It simulates human perception by automation of time-consuming tasks and by estimating data in ways that human beings sometimes cannot.

Machine learning is a subset of AI in which machines learn by experience and obtain knowledge or skills without any human involvement. Machine learning focuses on developing computer programs to access information and use the information to learn by themselves without any human intervention.

Machine learning algorithms can be divided into the following two types:

+   * Shallow learning is the process of remembering information rather than understanding it. In shallow learning, machines just remember and repeat the same things in an application.

+   * Deep learning is a type of machine learning technique in AI that permits the system to train itself to perform tasks, such as image and speech recognition, by using multi-layered neural networks. It is also known as deep neural learning.

# ## Introduction to deep learning

In deep learning, the term *deep* refers to the total number of hidden layers in the neural network. A deep neural network can have as many as 150 hidden layers compared to traditional neural networks, which possess two to three hidden layers.

Models in deep learning are trained by a large number of sets of labeled data, and then the neural architecture learns the features directly from the set of data without any type of human need for manual feature extraction.
