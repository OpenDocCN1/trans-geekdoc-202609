2. **Hidden layer**: The output from the input layer is passed through the hidden layer. Depending upon the size of the data and model, there can be many layers. Every hidden layer may have a different number of features. The hidden layers execute computations on the weighted inputs and provide the net output, which is fed as an input to the next layer with activation functions to provide the actual output.

3. **Output layer**: This is the last layer of a neural network that provides outputs corresponding to the given inputs.
