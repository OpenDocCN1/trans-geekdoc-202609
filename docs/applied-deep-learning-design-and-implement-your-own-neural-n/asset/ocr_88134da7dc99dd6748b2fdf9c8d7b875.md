# Figure 7.36: CNN classification

So, in CNN, we provide the images separately, but if we want to find out if the image is of the same person, we can use the Siamese network here, which will find out if the image is of the same person or not by using the parameter known as **similarity measure**. The Siamese network for this example is shown in figure 7.37:

![](bbox=[0.13, 0.39, 0.87, 0.66])

# Figure 7.37: Siamese network

From the two networks in the Siamese network, we get the output as $f(x(1))$ and $f(x(2))$. Therefore, the similarity distance between these two images can be given as follows:

```
$d(x(1), x(2)) = f(x(1)) - f(x(2)) < t$
```

So, here in the Siamese network, the parameter learning takes place such that if the two input pictures to a Siamese network are of the same person, then, $d(x(1), x(2))$ is within threshold value $t$.

If they are of different people, then $d(x(1), x(2)) > t$. The ROC curve is used to choose the threshold value.
