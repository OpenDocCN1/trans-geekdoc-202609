# Weights initialization

According to the model specifications given in the paper, all the weights are randomly initialized from a normal distribution, with a mean as 0 and a standard deviation as 0.2. These initial values are passed through the weight init() function as input and later to all convolutional, convolutional-transpose, and batch normalization layers.

# Generator network

The main function of the generator is to map the latent space vector into the training data distribution. The structure of the generator is constructed as specified in the DCGAN paper. A Generator class is made having init() and forward function.

```
# custom weights initialization called on netG and netD
def weights_init(m):
    classname = m.__class__.__name__
    if classname.find('Conv') != -1:
        nn.init.normal_(m.weight.data, 0.0, 0.02)
    elif classname.find('BatchNorm') != -1:
        nn.init.normal_(m.weight.data, 1.0, 0.02)
        nn.init.constant_(m.bias.data, 0)
```

The init function is used to define all the layers of the generator model, and the forward function is used to pass the input through all the defined layers. There are five convolutional-transpose layers followed by a batch normalization layer and a ReLU activation function. Finally, the output of the generator is passed through tanh function.
