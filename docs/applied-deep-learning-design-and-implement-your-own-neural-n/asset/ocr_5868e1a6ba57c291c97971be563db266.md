Now, it is very important to mention some points regarding these probability distributions:

+   The probability distributions specific to images, audio, and video datasets are very complex distributions over very large spaces.

+   Any explicit representation of these complex distributions is not known.

However, we still want to generate new samples, so what could be the approach to follow? We will begin by generating a random variable from a simple, well-understood distribution, such as the Gaussian distribution or uniform distribution, and transforms it into the target probability distribution. A number of different techniques exist that can generate more complex random variables, such as the inverse transform method, Metropolis-Hasting algorithm, rejection sampling, and others.

Using the preceding methods, we can generate a random variable that follows a given distribution by making it go through a well-designed transform function. So, in simple terms, the main purpose of the transform function is to reshape or deform the initial probability distribution to some other target probability distribution.

In GANs, the idea is to model the transform function by an appropriate deep learning model, such as a neural network or convolution neural network, that takes as input a simple N-dimensional uniform random variable and returns another N-dimensional random variable that should follow, after training, the required probability distribution. Once the architecture of the network has been designed, the training begins. After training, the network optimizes to express the correct transform function by updating the network parameters.
