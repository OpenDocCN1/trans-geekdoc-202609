Now, let us calculate backward propagation for $t = 0$ timestamp. To calculate the backward propagation for $t=0$, let us calculate the mean square error first to find out the difference between the actual output and the predicted output.

MSE is given as follows:

\[ E = \frac{(x - x')^2}{2} \]

When we do the derivation of the preceding equation concerning $x$, we get the following:

\[ \delta_x E = x - x' \]

Now, suppose the actual value of the output of forward propagation at the time $t = 0$ is 0.50, that is, $x' = 0.50$, and we have calculated or predicted value as 0.53.

Therefore,

\[ \delta_x E = 0.53 - 0.50 \]
\[ \delta_x E = 0.03 \]

Now from the backward propagation at $t = 1$, we have

\[ \delta out(0) = -0.02 \]

Therefore, the change in output at $t = 0$ is -0.02. So we can write

\[ \delta Out(t = 0) = 0.03 - 0.02 \]
\[ \delta Out(t = 0) = 0.01 \]

And the change in the cell state is given as follows:

\[ \delta State(t = 0) = \delta Out(t = 0) * o(0) * \left(1 - \tanh^2(state(t = 0))\right) + \delta(state = 1 * f(1) \]
\[ \delta State(t = 1) = 0.01 * 0.8 * (1 - \tanh^2(0.77)) - 0.07 * 0.85 \]
\[ \delta State(t = 1) = -0.05 \]

Now,

\[ \delta a(t = 0) = \delta State(t = 0) * i(0) * \left(1 - \left(a(0)\right)^2 \right] \]
\[ \delta a(t = 0) = -0.05 * 0.95 * (1 - \left(0.81\right)^2) \]
