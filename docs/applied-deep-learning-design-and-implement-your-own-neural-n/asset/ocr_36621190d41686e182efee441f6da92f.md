For a change only in the y-direction, the image gradient is given as follows:

\(\nabla f(x, y) = \left[0, \frac{\partial f}{\partial y}(x, y)\right]\)

Also, figure 4.28 shows the scenario when there is a change in both directions:

![](bbox=[0.252, 0.223, 0.694, 0.413])

Figure 4.28: Change of pixel intensity values in both directions

For the change in both x and y directions, the image gradient is given as follows:

\(\nabla f(x, y) = \left[\frac{\partial f}{\partial x}(x, y), \frac{\partial f}{\partial y}(x, y)\right]\)

So, the direction of the image gradient is given as follows:

\(\beta(\nabla f(x, y)) = \tan^{-1}\left(\frac{\frac{\partial f}{\partial y}(x, y)}{\frac{\partial f}{\partial x}(x, y)}\right)\)
