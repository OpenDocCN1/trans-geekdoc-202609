# Tanh activation function

Tanh or tangent hyperbolic function is similar to the sigmoid activation function but works better than the sigmoid function. This function is basically the mathematically-shifted kind of the sigmoid activation function. However, both are analogous and can be derived using each other:

```
$f(x) = \tanh(x) = \frac{2}{1+e^{-2x}} - 1$ (3.71)
```
