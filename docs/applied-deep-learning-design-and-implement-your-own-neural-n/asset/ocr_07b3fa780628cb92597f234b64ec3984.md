# Figure 3.21: Linear regression

In the case of linear regression, the model aims to get the regression line (best-fit) for the prediction of the value of Y based on the given input value X. During the training period, and the model determines the cost function to compute the Root Mean Squared (RMS) error between the actual obtained value (y) and the predicted value (p).

```
$$C = MSE = \frac{1}{n}\Sigma_{i=1}^n(y_i - y_{predicted})^2$$ (3.14)

$$y_{predicted} = mx_i + b$$
```

Substituting value of $y_{predicted}$ in equation (3.14), we get the following:

```
$$C = MSE = \frac{1}{n}\sum_{i=1}^n (y_i - (mx_i + b))^2$$
```

By applying the following rule of differential calculus $\frac{\partial f}{\partial x}(x^n) = n.x^{n-1} \cdot \frac{\partial}{\partial x}(x)$, we get the following equation:

```
$$\frac{\partial C}{\partial m} = \frac{1}{n}\sum_{i=1}^n 2 (y_i - (mx_i + b))^{2-1} * \frac{\partial}{\partial m}(y_i - mx_i - b)$$

$$\frac{\partial C}{\partial m} = \frac{1}{n}\sum_{i=1}^n 2 (y_i - (mx_i + b)) * (-x_i)$$
```
