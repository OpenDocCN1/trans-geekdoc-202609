## Clustering

It is a kind of learning method which is unsupervised. A learning method is said to be unsupervised in which we have to draw the references from the given datasets containing input data but do not have any labelled responses. Usually, it can be used as a process to discover the expressive structure, descriptive underlying procedures, procreative features, and grouping characteristics in the set of examples of a dataset.

Clustering is the assignment of separating the data points or population into a number of clusters so that the data points, which belong to the same groups, become more similar to other data points of the same group, and become more unlike the data points of the other groups. It is essentially an assembly of substances on the source of likeness and unlikeness among them.

## Different methods of clustering

The following are different methods of clustering:

- Partitioning method
- Hierarchical method
- Density-based method
- Grid-based method

### Partitioning method

The partition methods perform the partition of the objects into K-clusters, and then each partition is considered as one object. This technique is used in optimizing an objective measure function of similarity. **K-means Clustering Large Applications based upon Randomized Search (CLARANS)** is an example of a partition-based clustering method.

### Hierarchical method

In this method, based on the hierarchy, the clusters form a tree-type structure. Moreover, by using the previously formed clusters, new clusters are formed. Examples: **Balanced Iterative Reducing Clustering using Hierarchies (BIRCH)** and **Clustering using Representatives (CURE)**. It can be divided into two categories:

- 1. Divisive (Top-Down approach)
- 2. Agglomerative (Bottom-Up approach)

We will discuss about these two algorithms in the next sections.

### Density-based method

In this type of method, the clusters are considered as the dense region having some differences and similarities with respect to the higher dense regions in the space. The density-based methods have good ability and accuracy to merge two or more clusters. For example, Ordering Points to Identify Clustering Structure (OPTICS), Density-based Spatial Clustering of Applications with Noise (DBSCAN), and so on.

### Grid-based method

In the grid-based method, the present data space is framed into a grid-like structure consisting of a finite number of cells. The clustering operations performed on this grid are independent of the number of data objects and are fast. For example, Clustering in Quest (CLIQUE), wave cluster, Statistical Information Grid (STING), and so on.

## Clustering algorithms

The following section discusses the clustering algorithms related to different types of clustering methods.

### K-means clustering algorithm—partitioning method

K-means clustering algorithm is one of the simplest learning algorithms, which is unsupervised and can solve the clustering problem. This algorithm partitions the n number of observations into k number of seed points, in which every observation goes to the cluster, which has the adjacent mean aiding as a sample of the cluster.

The main idea behind the k-means clustering algorithm is to define k number of centers, one for an individual cluster. The main aim of the algorithm is to minimize the sum of distances between the cluster centroid and their respective data points.

The algorithm can be executed by using the following steps:

- Partitioning of the objects into k subsets.
- Identifying the mean point (cluster centroid) of the partition.
- Assigning each data point to a specific cluster.
- Calculating the distance from each point to the cluster centroid and assigning the data points to the cluster for which the distance from the cluster centroid is minimum.
- Determining the centroid of the new cluster again after the reallocation of data points.

The advantages of the K-means clustering algorithm are as follows:

- It is robust, fast, and easy to understand.
- It is efficient and measurable in large data collection.
- The clusters do not overlap with each other.

The disadvantages of the K-means clustering algorithm are as follows:

- It is not invariant with respect to non-linear transformations.
- It cannot handle data with noise and outliers.
- It does not work with categorical data.

### Agglomerative clustering algorithm [hierarchical]

This clustering algorithm is also known as the bottom-up approach. The agglomerative clustering algorithm also does not require the number of clusters to be pre-specified. At first, the bottom-up algorithms consider the data set as a ton of single clusters at the outset and further agglomerates into pairs of clusters until all clusters have been combined into a single cluster that contains data of all the clusters.

The following are the steps for the agglomerative (bottom-up) algorithm:

- 1. Start by taking all the data points in their own cluster.
- 2. Calculate Euclidean distance after each iteration and then combine two clusters having minimum distance.
- 3. Stop when the iteration reaches a combined single cluster. Otherwise, repeat Step 2.
