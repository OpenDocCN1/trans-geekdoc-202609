+   * Recall or sensitivity:
+   
+   S = \frac{TP}{TP + FN}
+   = \frac{85}{85 + 5}
+   \Rightarrow \frac{85}{90} = 0.9444

+   * Specificity:
+   
+   Sc = \frac{TN}{TN + FP}
+   \Rightarrow \frac{50}{50 + 10} \Rightarrow \frac{50}{60} = 0.8333

+   * F-measure:
+   
+   Fm = \frac{2 * Recall * Precision}{Recall + Precision}
+   = \frac{2 * 0.9444 * 0.8947}{0.9444 + 0.8947}
+   \Rightarrow \frac{1.6899}{1.8391} = 0.9188

# # Feature mapping

Feature mapping is the process of representing features on a graph along with the relevant information about the features. This process ensures that only the features with relevant information are visualized along with the useful information, and other irrelevant features are excluded from the graph.

During the initial years, the number of features was not a big concern, but nowadays, the volume of data and the features consisting of the data have increased exponentially. Therefore, it becomes essential to determine convenient methods to decrease the number of features.
