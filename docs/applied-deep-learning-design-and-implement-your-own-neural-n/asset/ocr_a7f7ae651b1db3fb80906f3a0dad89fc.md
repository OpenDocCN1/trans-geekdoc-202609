# Hands-on session on introduction to deep learning

# 1. Installation of Python

To work with Python, one needs to install it. We will discuss the installation of
Python on Windows and Linux operating systems.

# Windows OS

To install Python on Windows OS, follow these steps:

+   i. Open the Web browser and enter https://www.python.org/downloads/.
+   ii. Click on the Windows installer Python-ABC, where ABC is the version of
+   Python.
+   iii. Run the downloaded file and accept the default settings.

# Linux OS

To install Python on Linux OS, follow these steps:

+   i. Open the Web browser and enter https://www.python.org/downloads/.
+   ii. Click on the Linux installer Python-ABC zip file, where ABC is the version of
+   Python.
+   iii. Extract the zip file.
+   iv. Type the following commands on the Terminal:

```
run/configure script
make
make install
```
