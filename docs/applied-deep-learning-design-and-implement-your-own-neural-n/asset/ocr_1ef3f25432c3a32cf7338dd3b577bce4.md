# Manhattan distance

Say there are four points or locations, as shown in figure 7.28:

![](bbox=[0.35, 0.175, 0.65, 0.35])

Figure 7.28: Manhattan distance metric

Now, we want to find out the distance between two locations; we use Manhattan distance here. Manhattan distance is defined as the sum of the absolute distance of their coordinates.

Mathematically, the Manhattan distance is given as follows:

```
D(A, B) = |x1 - x2| + |y1 - y2|
```
