Moreover, gradient descent steps down the cost function in the direction of the steepest descent. The size of each step is determined by the learning rate of the gradient descent.

The slope can be divided into the following two parts:

+   1. When the slope is negative:
+   
+   \(\varphi_j = \varphi_j - (negative value)\)
+   
+   Hence, the value of \(\varphi_j\) increases.
