# # Introduction to Python

Python is an **object-oriented programming (OOP)** language that has the capability of a high-level programming language. It is a portable language, and also its syntax is easy to learn. That is why Python has become a popular language.

It was developed at *Stichting Mathematisch Centrum, Netherlands* having its first version, 0.9, in 1991. It is an open-source language that can be downloaded from **www.python.org**. It has the features of both C and *Java*. Python is an interpreted language. An interpreted language is the programming language in which the program is converted into byte code, and the byte code is executed by the virtual machine. Let us discuss some features of the Python programming language.

# # Features of Python

The features of the Python programming language are as follows:

+   - **Multi-purpose language**: It supports functional as well as object-oriented programming.
+   - **Easy to learn**: The syntax of Python is simple, making it easy to learn for beginners.
+   - **Scalable**: It supports large programs.
+   - **Open-source**: It is supported by the Python developer community, due to which errors can be easily fixed.
+   - **A large number of modules**: It has a large number of modules to cover each aspect of programming.
