# ArcTan activation function

ArcTan activation function maps the input in the range of (-π/2, π/2). The derivative of this activation function converges quadratically against for large values of input. Figure 3.44 shows the plot of the ArcTan activation function.

```
f(x) = tan^{-1}x

f'(x) = \frac{1}{x^2 + 1}

```
