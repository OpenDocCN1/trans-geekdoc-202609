# # RoI align

In mask RCNN, the RoI aligns layer is designed to address the problem of misalignment of location, which is generated by the quantization process in the RoI pooling layer. Basically, RoI Align eliminates the hash-quantization.

For example, instead of using [x/16], it uses x/16, such that the features extracted could be assigned with the original input pixels easily. Figure 5.68 shows the process of RoI alignment.
