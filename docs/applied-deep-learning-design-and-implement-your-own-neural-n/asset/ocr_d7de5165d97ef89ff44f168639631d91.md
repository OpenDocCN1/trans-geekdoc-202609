```
\frac{\partial S4}{\partial W} = \frac{\partial S4}{\partial S4} \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial^* S3}{\partial W} + \frac{\partial S4}{\partial S2} \frac{\partial^* S2}{\partial W} + \frac{\partial S4}{\partial S1} \frac{\partial^* S1}{\partial W}
```

We got the preceding equation by short-circuiting some of the parts of the equation as follows:

```
\frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial S2} \frac{\partial^* S2}{\partial W} : - \frac{\partial S4}{\partial S2} \frac{\partial^* S2}{\partial W}
```

And

```
\frac{\partial S4}{\partial S3} \frac{\partial S3}{\partial S2} \frac{\partial S2}{\partial S1} (\frac{\partial^* S1}{\partial W}) : - \frac{\partial S4}{\partial S1} \frac{\partial^* S1}{\partial W}
```

And the preceding equation can be written as follows:

```
\frac{\partial S4}{\partial W} = \frac{\partial S4}{\partial S4} \frac{\partial^* S4}{\partial W} + \frac{\partial S4}{\partial S3} \frac{\partial^* S3}{\partial W} + \frac{\partial S4}{\partial S2} \frac{\partial^* S2}{\partial W} + \frac{\partial S4}{\partial S1} \frac{\partial^* S1}{\partial W} = \sum_{N=1}^{4} \frac{\partial S4}{\partial SN} \frac{\partial^* SN}{\partial W}
```

So, finally, we can write as a derivative of the loss function as follows:

```
\frac{\partial L4(\theta)}{\partial W} = \frac{\partial L4(\theta)}{\partial S4} \frac{\partial S4}{\partial W} (6.15)
```

Now, we know that

```
\frac{\partial S4}{\partial W} = \sum_{N=1}^{4} \frac{\partial S4}{\partial SN} \frac{\partial^* SN}{\partial W}
```

Putting the preceding equation in \frac{\partial L4(\theta)}{\partial W} = \frac{\partial L4(\theta)}{\partial S4} \frac{\partial S4}{\partial W}, we get the following:

```
\frac{\partial L4(\theta)}{\partial W} = \frac{\partial L4(\theta)}{\partial S4} \sum_{N=1}^{4} \frac{\partial S4}{\partial SN} \frac{\partial^* SN}{\partial W}
```

Now, here N=4 is for our use case of predicting the alphabet; generally, for N = t, we can write as follows:

```
\frac{\partial Lt(\theta)}{\partial W} = \frac{\partial Lt(\theta)}{\partial St} \sum_{N=1}^{t} \frac{\partial St}{\partial SN} \frac{\partial^* SN}{\partial W} (6.16)
```

The preceding equation defines the back-propagation concerning time clearly. So, we have done the derivation concerning V and W, and similarly, we can calculate the derivative for U as well.
