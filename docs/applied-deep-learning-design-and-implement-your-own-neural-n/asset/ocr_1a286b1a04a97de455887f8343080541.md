# Spatial filters

The spatial filter is the filter used for filtering or passing certain frequency components. For example, a filter that passes high frequencies is known as a high-pass filter.

A spatial filter consists of two elements as follows:

+   - A neighborhood (typically a small rectangle).
+   - A predefined operation is performed on the pixels of the spatial image incorporated by the neighborhood.

The filtering process generates a new matrix of a pixel having coordinates the same as the coordinates of the neighborhood center. Spatial filters are broadly categorized as smoothing and sharpening filters, which are discussed as follows.

# Smoothing filters (low pass filters)

In image processing, smoothing filters are used for noise reduction and for blurring an image. Blurring is a pre-processing task used in the removal of a small amount of information from the input image. Blurring can also be used for noise reduction from an image.

Smoothing filters are of the following two types:

+   - Linear smoothing filter (mean filter)
+   - Non-linear smoothing filter (order statistics filter)

# Linear smoothing filter (mean filter)

Linear smoothing filter or mean filter is the average or mean of the pixels enclosed in the filter mask’s neighborhood. These filters are also known as low-pass averaging filters. These filters work by replacing every pixel’s value of the input image with the intensity levels in the filter mask’s defined neighborhood.
