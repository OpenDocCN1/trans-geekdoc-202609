## Least-square GAN loss

LSGAN loss function is also showing lots of scope in improved GAN training. The original GAN paper uses the log loss in the min-max loss function, and LSGAN uses the L2 loss. Here, the loss incurred for real samples is less than the fake ones. This loss function penalizes those data points that are not according to the required distribution. That means larger error, meaning penalty, and finally, the larger scope for updating the weights rather than vanishing the gradient. Thereby, it guarantees better gradient information for model training.

## Types of GAN

A number of different types of generative adversarial networks are there, working in slightly different ways and generating different types of outputs. In this section, we will try to explain the basics of these different GANs, how they work and how they can be used. This should give you an idea of how things are progressing in this area.

### Vanilla GAN

Vanilla GAN is the simplest type among the various GAN models. The previously-discussed introductory GAN architecture is basically a vanilla GAN model. In this model, both the discriminator and the generator use multi-layer perceptrons, competing against each other using cross-entropy loss function for training. All the other necessary information has already been discussed in the basics of GAN.

### Deep convolutional GAN

DCGAN is one of the most popular and successful GAN architecture, and that is why it is the first choice for the novice in this area, to begin with, and start a project. The DCGAN model was proposed to overcome some of the issues faced in the training of a GAN model. We have discussed the challenges faced in GAN; one of the main concerns is to have stable training. So, the authors suggested a few strategies for successfully training a high-quality generator. These are the main techniques the authors used in their model. Figure 8.9 gives the basic idea of the generator structure of the DCGAN model:

![](img/7e519fee1b702b91799cdf1664598392_581_0.png)

Figure 8.9: The structure of the generator in DCGAN

A random input vector with 100 dimensions from a uniform distribution is converted into a 64 x 64 pixels image using a series of four fractionally-stride convolutions (transposed convolution) layers in DCGAN:

- As the name itself suggests, this model uses convolutional neural network layers instead of multi-layer perceptron in both generator and discriminator networks.
- They replaced the max-pooling layer with convolutional layers with larger or fractional strides.
- Used global average pooling and removed fully-connected layers as the final layer.
- Used batch normalization in both networks.
- Used Leaky ReLu in the discriminator network.

The generator network is similar to the discriminator network, but in reverse order, except for the use of transposed convolution layer (for up-sampling the input image) instead of strided convolution layers (for down-sampling of the input image) used by the discriminator.

### Conditional GAN (cGAN)

GANs have the capability of generating new samples after training over a dataset. But how the generator is learning things and the type of images that are generated are not under control. So, it becomes a kind of brute force approach to try out random sample generation until desired results are produced. To make it possible to generate targeted-image generation, Mehdi suggested their model named Conditional Generative Adversarial Nets in the year 2014.

In this model, both the generator and the discriminator are conditioned during training with some kind of condition provided in the form of either a class label or some written description and so on, as shown in figure 8.10. This extra information in the form of class or label helps the generator network to restrict the generation of the new samples to that class or label instead of generating some random samples and makes the discriminator able to identify real samples with their labels:

![](img/7e519fee1b702b91799cdf1664598392_582_0.png)

Figure 8.10: Architecture of conditional GAN

Figure 8.11 shows that the output of the discriminator depends upon the condition given as input to it. Now, the discriminator will give output as true if the input image is real and the condition matches with the image; otherwise, false.

![](img/7e519fee1b702b91799cdf1664598392_583_0.png)

**Figure 8.11:** In conditional GAN, the discriminator checks for both whether the image is real or fake, and if real, then it matches with the input condition or not.

This is shown in figure 8.12, where if the label cat matches with the image, the output is true, but if the label does not match with the car image, the output is false:

![](img/7e519fee1b702b91799cdf1664598392_583_1.png)

**Figure 8.12:** The discriminator gives output “True” only if the input image matches with the condition, which can be a “label”, “tag”, or “class”.

Figure 8.10 shows that in the conditional GAN architecture, we can see some representational changes here, such as how our input to the generator network is a random noise vector along with the condition. Therefore, the probability distribution of the generator is represented by G(z|y), which is a conditional probability.

Now, what is conditional probability? Let us try to understand this. If x is a random variable, then p(x) is the probability of the occurrence of x. Its occurrence is independent, but if it is dependent on the occurrence of some other variables, say, y, then its probability distribution is represented as p(x | y), which means event x given y.

| :--- | :--- | :--- |
| Input | Random Noise Vector (z) with Condition or label (y) | Both Real (x) and Fake (x*) Samples with labels (y) |
| Output | Generated fake samples with the best matching label | Probability score for input to be real with a matching label |
| Aim | Generating samples that appear realistic that match their labels | Correctly identifying between real and fake sample pairs without confusion |

So, here, in conditional GAN, the generator is conditioned on some tag or class name, which forces the generator to produce images satisfying that condition. Similarly, the discriminator is also trained to identify the image-label pair correctly; otherwise, it rejects.

### Semi-supervised GAN

In supervised learning, the model is trained with the help of labeled data, where each sample of the dataset is tagged to some class or label. Therefore, these models are considered easy to train and more trustworthy in their predictions. On the other hand, in unsupervised learning, data is not labeled, so these models are difficult to train and are computationally complex. In machine learning, training versatile datasets play a very crucial role. Availability of data is not an issue nowadays, thanks to the internet, which provides us with vast and virtually limitless data in the form of text, images, audio, video, and so on. But this data is not labeled, and it is one of the main bottlenecks in training machine learning algorithms. It is not at all possible to label this much amount of data because it is a very time-consuming, tedious, and expansive process. The complexity of this process can be judged by the fact that it took nearly two and a half years to hand-annotate (label the classes) about three million images in the ImageNet dataset.

Semi-supervised learning, as the name suggests, is in the middle of both supervised and unsupervised methods and uses both labeled and unlabeled data elements for training. It uses only a small subset of labeled data (approximately 2%–3% complete dataset) and has shown great results in classifying new unlabeled data and achieved accuracy close to supervised learning models.
