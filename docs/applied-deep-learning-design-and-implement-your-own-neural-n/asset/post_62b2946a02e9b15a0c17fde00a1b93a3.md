## Representation of recurrent relationships

We can further generalize the equation in terms of recurrent equations using a classification problem known as labeling of names or text labeling. In this given sentence, we have to find the names in that. Like we can take sentences from various corpora’s available in natural toolkit (NLTK) libraries.

- S1: AB De Villiers is called as 360-degree player. 
- S2: Rohit Sharma plays very well the bowler of Pakistan whose name is Shaheen Afridi. 

So in this problem, input is the sentence that is represented as x^{<t>} = (10,000 × 1), which is converted as an input vector of, say, 10,000 dimensions.

The generalized equation is as follows:

$$h^{<t>} = g( W_{hh} \times h^{<t-1>} + W_{hx} \times x^{<t>} + b_a ) \quad (6.5)$$

It is further expanded in terms of dimensions as follows:

$$\{h^{<t>}|(100 x 1)\} = g \left( \begin{matrix} W_{hh} \\ \end{matrix} \right) \times \{h^{<t-1>}|(100 x 1)\} + \left( \begin{matrix} W_{hx} \\ \end{matrix} \right) \times \{x^{<t>}|(10000 x 1)\} + \{b_a(bias)\}$$

### Matrix augmentation for representation of recurrence relationships

$$( W_{hh(100x100)} | W_{hx(100x10000)} = W_{h(100x10100)}: [Using Horizontal Concatenation] (6.6)$$

$$( \frac{h^{<t-1>}}{(100x1)} \\ \frac{x^{<t>}}{(10000x1)} ) = (h^{<t-1>}, x^{<t>})_{(10100x1)}: [Using Vertical Concatenation] (6.7)$$

$$:: W_{h(100x10100)}[h^{<t-1>}, x^{<t>}]_{(10100x1)} = h^{<t>}(100 x 1) (6.8)$$

So using the preceding equations recurrent relationship is represented as follows:

$$h^{<t>} = g_1(W_h[h^{<t-1>}, x^{<t>}] + b_a) (6.9)$$

This arc (blue color) shows recurrence relationship using $h^{<t-1>}$ and $h^{<t>}$. In this recurrence relationship $h^{<t-1>}$ is used to find $h^{<t>}$.

$$y^{<t>} = g_2(W_y h^{<t>} + b_y) (6.10)$$

Here, $g_1$ and $g_2$ represents activation function as $g_1$ = tanh/ReLU and $g_2$ = sigmoid (generating value between 0 and 1). We are using tanh because $h^{<t-1>}$ is modified to $h^{<t>}$ using tanh.
