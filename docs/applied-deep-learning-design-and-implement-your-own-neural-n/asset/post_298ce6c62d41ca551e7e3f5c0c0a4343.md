## Divisive clustering algorithm [hierarchical]

This clustering algorithm is also known as a top-down method. In this algorithm, there is no need to pre-specify the total number of clusters. This approach of clustering requires a technique to split a cluster that contains the complete data and continues by splitting the clusters in a recursive manner until the data has been split into a group of single clusters.

Following are the steps for the divisive (top-down) algorithm:

- 1. Start by taking all the data points in a single cluster.
- 2. After every iteration, remove outsider data points from the specified (cohesive) cluster.
- 3. Stop when the iteration reaches as a single cluster that cannot be further disintegrated.

### Maximum Likelihood Estimation (MLE)

Maximum Likelihood Estimation (MLE) is the most common method for the estimation of the parameters, such as mean, variance, and so on, of a model that best describes the observation.

Let be the parameter of the model and be the observation.

The probability of \(\theta\) given \(Y\) can be calculated by using Naïve Bayes theorem.

\(P(\theta \mid Y) = \frac{P(Y|\theta)P(\theta)}{P(Y)}\) (1.24)

Let us consider that the data is **independent and identically distributed (IID)**. Here, identical distribution means that the data comes from a common distribution with the same type of parameters.

But now, we want to calculate the probability of new observations given the value of the parameter, that is, to calculate the likelihood of "\(\theta\)". For IID \(Y\), likelihood function of "\(\theta\)" can be written as the product of the probability for every data point.

\(L_Y(\theta) = \prod_{y \in Y} p(y|\theta)\) (1.25)

To calculate log-likelihood, take the log of the preceding equation 1.25:

\(L_Y(\theta) = \sum_{y \in Y} log[p(y|\theta)]\) (1.26)

Differentiate the preceding equation to calculate the maximum log-likelihood.

Let us take an example of a Bernoulli trial-coin flipping. Bernoulli distribution is a discrete probability distribution which takes the value of *success* as \(p\) and of *failure* as \(q=1-p\).

The **probability mass function (PMF)** of the distribution over possible outcomes \(l\) is given as follows:

\(f(l; p) = p^l(1 - p)^{1-l}\) (1.27)

Let us assume that a coin is flipped a few times, and we have got the results as "$y_1,.....,y_n$" which are either "HEADS" or "TAILS". Let "p" be the probability of getting "HEADS". Suppose the coin is tossed "100" times and "40" times we get "HEADS", then "p=0.4". By using MLE, we will prove that the guess of "p=\sum y_i / n" is the most likely value for "p".

So, let us write the function of the likelihood.

```
$L_Y(p) = f(y_i; p) = \prod_{y \in Y} p^{\sum y_i}(1-p)^{n-\sum y_i}$ (1.28)
```

Now taking log both sides, we get:

```
$log L_Y(p) = \sum y_i log p + (n - \sum y_i)log(1 - p)$ (1.29)
```

To maximize, set the first derivative of the function to 0.

```
$\frac{\partial log L_Y(p)}{\partial p} = 0$ (1.30)
```

```
$\frac{\sum y_i}{p} - \frac{n-\sum y_i}{1-p} = 0$ (1.31)
```

Solving, we get:

```
$p = \frac{\sum y_i}{n}$ (1.32)
```

Equation 1.32 represents the most likely value of p for our observation.
