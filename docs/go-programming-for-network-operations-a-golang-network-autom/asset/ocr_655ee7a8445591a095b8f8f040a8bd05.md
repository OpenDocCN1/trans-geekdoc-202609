# # Chapter 7.1: Forward (A)

The `net.LookupIP()` function accepts a string and returns a slice of `net.IP` objects that represent that host's IPv4 and/or IPv6 addresses.

```
```
package main

import (
  "fmt"
  "net"
)

func main() {
  ips, _ := net.LookupIP("google.com")

  for _, ip := range ips {
    fmt.Println(ip.String())
  }
}
```
```

The output below lists the A records for google.com that were returned in both IPv4 and IPv6 formats.

172.217.1.238
2607:f8b0:4000:80e::200e
