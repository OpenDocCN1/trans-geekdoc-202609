# ## Chapter 10.1: User Input

Reading user input from the terminal is often needed to read in both sensitive and non-sensitive data. This example takes in a username and a password to demonstrate the two. To keep it short, the terminal.ReadPassword() function will be used to read the sensitive password text from the terminal without local echo. The bufio.Reader.ReadString() method will be used for non-sensitive input.

This example starts by reading the non-sensitive username input by wrapping os.Stdin with the bufio.NewReader() function to return a buffered bufio.Reader object. Then, the prompt is printed and the bufio.Reader.ReadString() method is called while using a new-line character as the argument. This will return the input as a string prior to the new-line. Next, the sensitive password prompt is printed and the terminal.ReadPassword() function is called using syscall.Stdin as an argument to disable local echo and retrieve the password. Finally, the username and password are printed as validation.
