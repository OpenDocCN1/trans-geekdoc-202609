```
func main() {

    cmd := exec.Command("cat", "r.txt", "w.txt")

    stdoutpipe, _ := cmd.StdoutPipe()
    stderrpipe, _ := cmd.StderrPipe()

    _ = cmd.Start()

    stdout, _ := ioutil.ReadAll(stdoutpipe)
    stderr, _ := ioutil.ReadAll(stderrpipe)

    fmt.Printf(
        "stdout: %sstderr: %s", stdout, stderr)

    _ = cmd.Wait()
}
```

The output first displays the standard output text from the readable file (r.txt) and then the error text from the non-readable file (w.txt).

stdout: hi from r.txt
stderr: cat: w.txt: Permission denied
