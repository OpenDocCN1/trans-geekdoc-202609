# ## Chapter 10.4: Column Formatting

Command-line application output is often viewed in column format to correlate items. The tabwriter package enables easy formatting of columns using tab-terminated cells in contiguous lines.

The example starts out by allocating and initializing a new tabwriter.Writer object. The parameters, from left to right are used for output, min-width, tab-width, padding, padding-character, and custom flags (e.g., right-alignment). Next, the fmt.Fprintf function is used to format the columns and write to the tabwriter.Writer object. Finally, the tabwriter.Writer.Flush() method is used after the last call to ensure that any buffered data is written to the output.
