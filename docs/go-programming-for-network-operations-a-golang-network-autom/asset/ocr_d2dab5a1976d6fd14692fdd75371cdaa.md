# # Chapter 2.5: XML

Extensible Markup Language (XML) is a markup language commonly used as a data communication format in web services. The streamlined format is often preferred over JSON due to its compact structure.

The xml package supports reading and writing XML 1.0. Since XML forms a tree data structure, can be define in a similar hierarchy using structs in Go. The examples in the subchapters that follow will leverage structs to encode and decode XML.

This subchapter will cover the following topics:

+   - Reading XML files
- Writing XML files
