# ## Chapter 3.1: Template Elements

The building blocks of a template are its elements. Elements consist of arguments and actions that are surrounded by double curly braces. Arguments include values and actions, which are composed of statements, such as if-else, range or with.

| Element | Description |
| :--- | :--- |
| `{{.}}` | Root element |
| `{{.Var}}` | Variable |
| `{{.Var}}` | Remove whitespace on either side |
| `{{ $version :="0.1"}} {{ $version }}` | Internal variable assignment |
| `{{/* comment here */}}` | Comment |
| `Name: {{if .Name }} {{ .Name }} {{ else }} anonyomus {{end}} .` | If-else conditional |
| `{{with .Var}} {{end}}` | With statement |
| `{{range .Array}} {{end}}` | Range over slice, map or channel |
| `{{ lt 3 4 }}` | Less than (other boolean operators: eq, ne, lt, le, gt, ge) |
