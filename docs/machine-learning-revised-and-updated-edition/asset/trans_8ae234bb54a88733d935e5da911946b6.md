[2](#13811-0008.xhtml#en12r). 假设 `F` 代表流感，`N` 代表流鼻涕。使用贝叶斯法则，我们可以写出在已知某人流鼻涕的条件下，该人患流感的概率：

`P(F|N) = P(N|F)P(F)/P(N)`，

这里，`P(N|F)` 是反方向的条件概率，即已知患者患有流感的条件下，患者流鼻涕的概率。`P(F)` 是患者患流感的概率，无论他们是否流鼻涕；`P(N)` 是患者流鼻涕的概率，无论他们是否患流感。

[4](#13811-0008.xhtml#en14r). 这是由于孔多塞陪审团定理，该定理指出：在一个通过多数投票做决定的群体中，如果每个投票者以独立概率 `p` 投给正确决定，对于任意 `p` > ½（优于随机猜测），随着投票者数量的增加，多数投票正确的概率趋近于 1。这就是为什么民主优于君主制（孔多塞侯爵支持法国大革命，尽管他后来被视为叛徒并被送进监狱，最终死在狱中），但前提是投票者能够独立形成自己的观点，这也是新闻自由和言论自由等概念发挥作用的地方。
