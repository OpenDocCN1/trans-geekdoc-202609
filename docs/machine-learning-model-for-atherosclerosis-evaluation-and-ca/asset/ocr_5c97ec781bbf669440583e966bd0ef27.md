After recalibrating all models, we tested their discrimination performance in the testing cohort. The simplified final model using CCTA features (model 3) predicted MACE events with an ROC and AUC of 0.899 (0.839–0.959). In contrast, the clinical risk factors model (model 1) had an ROC AUC of 0.708 (95% CI, 0.610–0.806), and the combined clinical risk factors+CACS model (model 2) showed an ROC AUC of 0.753 (95% CI, 0.662–0.844). Thus, the clinical+CACS was only slightly superior to the clinical model (ΔAUC, 0.045 for model 2 versus model 1; P=0.308). The CCTA model performed significantly better than the clinical model and the combined clinical+CACS model (ΔAUC, 0.191 for model 3 versus model 1; ΔAUC, 0.146 for model 3

versus model 2; P<0.001 for both). When CCTA features were added to the clinical model (model 4) and the clinical+CACS model (model 5), the ROC AUC improved to 0.895(95% CI, 0.842–0.947) and 0.905 (95% CI, 0.844–0.966; P<0.001 for both; Figure 2B; Table 4).

The trend observed in the C-index parallels that of the time-dependent AUC. These findings indicate that the CCTA model exhibits a superior discriminative ability in predicting cardiovascular events, with its performance validated in the testing cohort.
