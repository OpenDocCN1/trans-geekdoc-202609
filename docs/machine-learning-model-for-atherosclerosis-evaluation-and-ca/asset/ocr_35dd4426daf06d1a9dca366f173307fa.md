The outcome panel was blinded to the findings of the CCTA. Disagreement was resolved by consensus, which included an additional senior cardiologist. If the telephone numbers were invalid and the patient could not be contacted, the patients were considered lost to follow-up. Three attempts were made using the patient's direct phone number in 1 week. If we were unsuccessful or the patient could not provide accurate information, the patients were considered lost to follow-up. The secondary end point was defined as the occurrence of death, AMI, and stroke, excluding all revascularization events.

The outcome of all prediction models is the time to MACE. Time zero is defined as the time point when the patient undergoes CCTA. All subsequent survival predictions are based on this time point.

# Feature Selection and Extraction

Potential variables were selected based on clinical experience, previous studies, and data availability. The final structured database containing 48 CCTA candidate predictive variables encompasses the presence, extent of coronary stenosis, plaque distribution across vessels, qualitative and quantitative plaque characteristics, including PV/burden and subtypes (calcified, noncalcified, fibrous, and lipid plaques; Table S1 for variable abbreviations and definitions). Multiclass nominal variables were processed using 1-hot encoding.

# Model Training and Optimization

The study outline of ML model creation and validation is shown in Figure S3. The database was randomly partitioned into a training set (70%) and a testing set (30%). An enhanced stratified data splitting strategy was implemented to maintain comparable distributions of event rates and other variables, such as time, across both data sets. Predictive models were built using the training set (70%, n=5901), and optimal features were selected. The models were internally validated with 5-fold cross-validation (Figure S4). The test set (30%, n=2530) was not used for model development but was used to evaluate the model's performance. The hyperparameters of the model were optimized using an R package called caret, combined with 5-fold cross-validation to maximize C-index (see the parameter space in Table S2).

This study employed 6 survival analysis methodologies: XGBoost, deep learning neural net, Cox Proportional Hazard, Random Survival Forests, Support Vector Machine for Survival Analysis, and Gradient Boosting Survival Analysis.23,24 The XGBoost survival prediction model is distinguished by its high computational efficiency and excellent predictive performance, as well as its robust regularization techniques and extensive hyperparameter tuning capabilities. The deep learning neural network is an advanced deep learning framework adept at processing time-series data and forecasting future events, making it particularly suitable for survival analysis. Model performance was evaluated using the Harrell concordance index (C-index). The final model is selected based on the C-index and time-dependent area under the curve (AUC), and its performance is evaluated in the testing set.

# Model Interpretation

Shapley additive explanation values were used to analyze feature importance and interrelationships, thereby optimizing

feature selection. These values reflect the average contribution of each variable to the MACE risk (positive values indicate that the variable increases MACE risk). Recursive feature elimination was used to simplify the model until a reduction in model performance was observed.

In the training set, features with the highest mean absolute impact on model predictions were ranked and validated in the testing set. Additionally, the study provided 2 case examples from the test data set where MACE events were accurately predicted, offering a detailed explanation of each feature's individual contribution to the final prediction outcomes.

# Model Performance

We constructed 5 classification models: First, to evaluate the CCTA model against current clinical practice, we built a clinical risk model (model 1) using the same ML techniques as the CCTA model. Model 1 enrolled variables from well-established risk assessment scores, including sex, age, diabetes, hypertension, hyperlipidemia, smoking, obesity, family history of CAD, and non-high-density lipoprotein cholesterol levels. Model 2 was a hybrid model that combined clinical risk factors and CACS. Model 3 was the CCTA model formulated using the 6 parameters with the highest predictive value. Model 4 was a hybrid model that combined clinical risk factors, CACS, and CCTA parameters. Model 5 combined clinical risk factors, CACS, and CCTA parameters.

The model performance was evaluated in the testing cohort based on discrimination, calibration, and reclassification capabilities. Discrimination was assessed using the time-dependent receiver operating characteristic (ROC) curve, AUC, and C-index, reflecting the model's capacity to distinguish between different categories (events and nonevents) over time. Calibration was quantitatively evaluated using the Brier score to measure the consistency between predicted probabilities and actual event outcomes. Reclassification capability was assessed using the net reclassification improvement (NRI >0), focusing on the improvement of individual risk classification. Specifically, we used time-dependent AUC to calculate the area under the ROC curve for prediction models annually over a 1- to 5-year period.

# Statistical Analysis

In the descriptive analysis, continuous variables with a normal distribution are presented as mean±SD, continuous variables with a skewed distribution are presented as median (interquartile range), and categorical variables are presented as number (percentage). The comparison of continuous variables with a normal distribution was conducted using the independent t test, continuous variables with skewed distribution were performed using the Mann-Whitney U test, and categorical variables were analyzed using the χ² test. The statistical significance between areas under the curve was determined using the DeLong method.

Exploratory subgroup analyses were performed for the primary outcome: first, by dividing the overall population into different gender groups (male and female); second, by analyzing groups with or without symptomatic chest pain.
