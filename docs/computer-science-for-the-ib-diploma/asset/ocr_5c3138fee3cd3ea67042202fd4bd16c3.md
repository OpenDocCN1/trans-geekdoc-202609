Note that the brackets can still be used even if only a single instruction is included in the IF or ELSE part.

```
Python
toPay = 0
purchaseValue= float(input("Enter the value of your goods:"))
if purchaseValue>=100:
    discount = purchaseValue * 0.2
    toPay = purchaseValue - discount
else:
    toPay = purchaseValue
print("You need to pay: ", toPay)
```

As you may have realized, the block of code can even be further expanded to include another IF statement inside the current one. (One IF statement inside another is called a "nested IF")

```
IF condition THEN
    IF condition 2 THEN
......
    ELSE
......
    ENDIF
ELSE
......
END IF
```
