# # Set methods

To add and remove elements:

```
```python
my_set = {1, 2, 3, 4, 5}
my_set.add(6) # Add 6 to the set
my_set.remove(1) # Remove 1 from the set
```
```

```
```java

```
```

To check whether elements are present in the set:

```
```python
if 2 in my_set:
    print("2 is in the set")
else:
    print("2 is not in the set")
```
```

```
```java
if (my_set.contains(2)) {
    System.out.println("2 is in the set.");
} else {
    System.out.println("2 is not in the set.");
}
```
```

+   ✦ Set union: the union of two sets is a new set containing all the elements that are in either of the original sets, effectively combining them together without any duplicate elements.
+   ✦ Set intersection: the intersection of two sets is a new set containing only the elements that are present in both of the original sets, identifying their common elements.
+   ✦ Set difference: the difference between two sets is a new set containing elements that are in the first set but not in the second set, effectively subtracting the elements of the second set from the first.
