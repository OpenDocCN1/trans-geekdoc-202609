# # Softmax

Softmax produces an output similar to Sigmoid in that both produce values in the range (0,1). Softmax produces a probability distribution for N different outcomes, where N is the number of categories for classification and the probabilities sum to 1. This makes it suitable for distribution across multiple classes, so it is commonly used for the output layer of a multiclass classification problem. # # Tanh

Tanh is similar to Sigmoid, but the output values range between -1.0 and 1.0. It is useful when your data is normalized around 0 but, like Sigmoid, it also has vanishing gradients that can be problematic. It is more common to see tanh used for hidden layers than Sigmoid, given its mean distribution is centred on 0. This centring around 0 makes learning for the next layer easier for classification.

There are a couple of mathematically equivalent ways of producing the tanh function:

```
f(x) = (e^x - e^-x) / (e^x + e^-x) or f(x) = 2 / (1 + e^-2x) - 1
```
