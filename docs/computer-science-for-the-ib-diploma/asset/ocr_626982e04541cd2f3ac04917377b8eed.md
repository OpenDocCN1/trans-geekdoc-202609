# Common mistake

Always pay attention to the logic behind the algorithms you write. Many students implement sorting algorithms incorrectly or they confuse the algorithms in between. For example, when the question is requiring the sorting of an array in ascending order by using the selection sort, a common mistake is to implement an incorrect bubble sort, or an algorithm that outputs the values in descending order instead of ascending, as required. Pay attention to the features of each of the sorting algorithms and understand the logic behind them.
