After setting up the breakpoints, the next step is to run the program in debugging mode. This is done by clicking on the Debug button (the one next to the Run button), which looks like a little bug, as shown in the image below.

![](bbox=[0.283, 0.145, 0.88, 0.328])

# Running the program in debugging mode in Eclipse

![](bbox=[0.291, 0.415, 0.66, 0.705])

# Breakpoint window in Eclipse

The code will execute as normal, but it will interrupt its execution the moment it reaches the set breakpoint.
