```
Java
if (purchaseValue>=100 && member==true) {
   discount = purchaseValue * 0.2;
   toPay = purchaseValue-discount;
} else if (purchaseValue>=100 && member==false) {
   toPay = purchaseValue*0.9;
} else {
   toPay = purchaseValue;
}
System.out.println("You should pay: " + toPay);
```

In the example above, both conditions should be met (to be a member and purchase value to be 100 or above) for the discount of 20 per cent to be applied. The second condition is checking whether both conditions are met again, but this time they should have a purchase value of 100 or above, but not be a member. The statement executed on the else branch is the statement happening if the purchase is not 100 or above.
