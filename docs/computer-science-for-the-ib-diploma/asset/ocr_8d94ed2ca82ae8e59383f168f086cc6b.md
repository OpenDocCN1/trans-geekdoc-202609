# 2 Normalize it to 2NF:

+   Entities are in 1NF.

+   There are no partial dependencies.

AuthorFirstName and AuthorLastName are dependent on AuthorID, while Title, Pages and ProofReader are dependent on the primary key (BookID). Therefore, we need to split this table as follows:

# 3 Normalize it to 3NF:

+   Entities are in 2NF.

+   There are no transitive dependencies.

The ProofReader field has repeating values, and it is not necessarily fully functionally dependent on the BookID. Therefore, to remove non-transitive dependencies, you can create a new table for proof readers.
