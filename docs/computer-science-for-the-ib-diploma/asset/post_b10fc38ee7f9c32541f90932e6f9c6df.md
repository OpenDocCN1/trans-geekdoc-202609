## Calculating optimal route - Bitmasks Dynamic Programming and 2D array processing

This is the base case, all other elements in the array are set to infinity

Transition: Iterate over all possible masks, which represent all subsets of nodes
- Consider all other nodes v that haven't been visited yet.

```
int tsp_bitmask_dp(int n) {
    int dp[1<<n][n];
    memset(dp, 0x3f, sizeof dp);
    dp[1][0] = 0;
    for (int mask = 0; mask < (1<<n); ++mask) {
        for (int u = 0; u < n; ++u) {
            if (!(mask & (1<<u))) continue;
            for (int v = 0; v < n; ++v) {
                if (mask & (1<<v)) continue;
                dp[mask | (1<<v)][v] = min(dp[mask | (1<<v)][v], dp[mask][u] + cost[u][v]);
            }
        }
    }
    return dp[(1<<n)-1][n-1];
}
```

mask XOR (1 << u): Removes node u from the set of visited nodes in mask

dp[mask XOR (1 << u)][v]: Gives the minimum cost of reaching node v from the start, having visited the set of nodes in mask minus node u

dp[mask XOR (1 << u)][v] + cost[v][u]: Total cost of reaching node u from the start, having first reached node v and then traveling from v to u

The minimum of these two values is then set as the new cost to reach u.

min_cost is the minimum value from the last row of the DP array, which contains the minimum costs of reaching the final node from all other nodes.
end_node is the index of the minimum cost, which is the last node in the optimal path.

```
int curr_mask = (1<<n) - 1;
int end_node = n-1;
path.add(end_node);
while (curr_mask > 0) {
    int min_cost = INT_MAX;
    int next_node = -1;
    for (int v = 0; v < n; ++v) {
        if (!(curr_mask & (1<<v))) continue;
        if (dp[curr_mask][v] + cost[v][end_node] == dp[curr_mask ^ (1<<end_node)][end_node]) {
            next_node = v;
            break;
        }
    }
    curr_mask ^= (1<<end_node);
    end_node = next_node;
    path.add(end_node);
}
```

Set the initial bitmask to all 1s to represent that all nodes have been visited in the final state of the path.

Check if v is part of the current mask (subset) and leads to the optimal path for 'end_node'. If yes, then it's part of the optimal route.

Update the mask by removing 'end_node' from the current subset, preparing for the next iteration of backtracking.

Set the current 'end_node' to 'v' as we move backwards through the path.
