# Operators

Operators are used to perform calculations, comparisons and other logical operations. Operators can be arithmetic operators, such as +, -, /, *, &; or Boolean operators, such as !, &&, ||; or relational operators, such as <, <, >, >=, ==, !=

+   - **Arithmetic operator**: a character that is used to perform a calculation.
+   - **Boolean operator**: a character that represents a specific logical operation that is used to produce a true or false outcome.
+   - **Relational operator**: an operator used to compare values or expressions.

| Operator in Java | Operator in Python | Meaning |
|---|---|---|
| + | + | addition |

| * | * | multiplication |
| / | / | division |
| % | % | modulus (returns the remainder) |
| < | < | smaller than |
| <= | <= | smaller than or equals to |
| > | > | greater than |
| >= | >= | greater than or equals to |
| == | == | equals to |
| != | != | not equals to |
| && | and | and |
