# IBDP subject recommender

This project aims to develop a desktop application that will allow students to input information such as their subject interests, career aspirations and recent grades to receive a recommendation of which subjects they should choose for their IB diploma. The solution will take into account IB subject requirements and the school's timetable scheduling.

# Key technologies and techniques

+   - Java programming language
+   - JavaFX GUI
+   - MySQL database to hold the school's timetable
+   - Excel file containing IB subjects that are recommended for different career paths, converted to JSON for easier use
+   - Unique algorithm: Developed to give students suggestions for their IBDP choices based on the data input
