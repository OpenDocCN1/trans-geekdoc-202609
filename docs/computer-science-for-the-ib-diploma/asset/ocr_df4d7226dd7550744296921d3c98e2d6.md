# Standard flowchart symbols

| Symbol | Name | Description |
| :--- | :--- | :--- |
| [Oval] | Terminator | Start or end of the process |
| [Parallelogram] | Input / output | Input or output of data |
| [Rectangle] | Process | Action, such as a calculation or an assignment |
| [Diamond] | Decision | True / false or yes / no decisions (selection statements) |
| [Arrow] | Flowline | Direction of data flow between shapes |
| [Circle] | Connector | Continuation of a flow through multiple pages or charts |
