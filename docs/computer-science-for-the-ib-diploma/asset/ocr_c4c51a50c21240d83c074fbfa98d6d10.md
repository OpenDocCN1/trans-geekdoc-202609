# THE FIBONACCI SEQUENCE

Each number is the sum of the two that precede it.

0 1 1 2 3 5 8 13 21
0 + 1 = 1
1 + 1 = 2
1 + 2 = 3
2 + 3 = 5
3 + 5 = 8
5 + 8 = 13
8 + 13 = 21

![](bbox=[0.635, 0.1, 0.885, 0.225])

+   - Fibonacci sequence
+   - F<sub>0</sub> = 0
+   - F<sub>1</sub> = 1
+   - F<sub>2</sub> = F<sub>1</sub> + F<sub>0</sub>
+   - ...
+   - F<sub>n</sub> = F<sub>n-1</sub> + F<sub>n-2</sub>

To find the sequence for the first n terms, the base cases are identified as being F<sub>0</sub> and F<sub>1</sub>, where the returned values would be 0 and 1 and the recursive call: F<sub>n-1</sub> + F<sub>n-2</sub>.

```
```java
public static int fib(int n) {
    if (n==0) {
        return 0;
    } else if (n==1) {
        return 1;
    } else {
        return fib(n-1) + fib(n-2);
    }
}

public static void main(String[] args) {
    Scanner read = new Scanner(System.in);
    System.out.printIn("Enter a number: ");
    int n = read.nextInt();
    for(int i = 0; i<n; i++) {
        System.out.print(fib(i) + " ");
    }
}

def fib(n):
    if n==0:
        return 0
    elif n==1:
        return 1
    else:
        return fib(n-1) +
        fib(n-2)

n = int(input("enter a number: "))
for i in range(n):
    print(fib(i), " ", end="")
