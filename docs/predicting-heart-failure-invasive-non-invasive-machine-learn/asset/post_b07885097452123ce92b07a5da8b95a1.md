## 7.4.2 Data Preprocessing

The data sets were preprocessed to handle noise, inconsistency, and missing values. The noises and inconsistencies were corrected manually. However, the missing values had to be treated before being used as they could have led to failure in classification or incorrect disease prediction [40]. Two common techniques could be applied for handling the data sets: deletion and imputation. Removing missing instances is the most used way for treating missing values, whereby cases that cannot be processed are removed. Despite the simple implementation of this method, it can remove useful information. On the other hand, the imputation method is used where missing values are replaced with estimated values. In our research, the second approach was used. Specifically, we used the nearest neighbor algorithm with k = 5 to impute missing values where a case is imputed using values from the majority of the complete five nearest cases.

## 7.4.3 Performance Measures

Five common evaluation measures were used to assess the efficiency of the prediction models. These evaluation measures were selected as they are widely used to evaluate the efficiency of prediction models. The first measure is Recall, as shown in Equation 7.1, which measures how well a binary classification predicts positive labels. The second measure is precision, as shown in Equation 7.2, which measures the probability that a positive prediction is correct. The third measure is accuracy, as shown in Equation 7.3, which measures the performance of classification. The fourth measure is specificity, as shown in Equation 7.4, which measures how well a binary classification test correctly identifies the negative cases. The last measure is the F-measure, as shown in Equation 7.5, which measures the probability that a positive prediction is correct [32].

```
Recall = t_p / (t_p + f_n)
(7.1)
```

```
Precision = t_p / (t_p + f_p)
(7.2)
```

```
Accuracy = (t_p + t_n) / (t_p + t_n + f_p + f_n)
(7.3)
```

```
specificity = t_n / (t_n + f_p)
(7.4)
```

```
F - measure = 2 x precision x recall / (precision + recall)
(7.5)
```

- Where:
  - t_p is true positive.
  - t_n is true negative.
  - f_p is false positive.
  - f_n is false negative.

## 7.5 Results

In traditional healthcare systems, doctors rely on the signs or symptoms of patients to diagnose heart diseases. However, many signs and symptoms are non-specific, leading to unwanted errors and affecting the quality of the provided health services. To overcome this issue, expert systems were developed to emulate health decision-making with improved accuracy. This involves correlating various pieces of patients’ information, followed by obtaining specific patterns. In this research, we applied five classification algorithms for predicting heart diseases based on pre-selected attributes.

For each data set, we ran the five classification algorithms using 10-fold cross-validation. The obtained results are shown in Tables 7.4 and 7.5. The results in Table 7.4 for the Cleveland data set show that all models can produce good predictions and good performance. We notice that all performance measures, except recall, suggest that NB is the most predictive for the Cleveland data set. Figure 7.8 demonstrates the receiver operating characteristic (ROC) for all models over the Cleveland data set. It is clear that SVM and NB are the most superior ones for the Cleveland data set.

The results obtained for the Statlog data set, shown in Table 7.5, are similar to those obtained for the Cleveland data set. Accuracy, Precision, and Specificity performance measures indicate that SVM is the most accurate algorithm while AUC, Recall, and F1 measures recommend NB is the most accurate one, as shown in Table 7.5. Another important issue that should be emphasized in this study is the ranking stability of the classification algorithm over both data sets and across multiple performance measures. Ranking algorithm stability means that this algorithm should always produce accurate results and rank high overall data sets across all evaluation
