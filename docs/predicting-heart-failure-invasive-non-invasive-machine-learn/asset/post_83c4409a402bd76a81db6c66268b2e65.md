## 12.2 Search Strategy

The Google Scholar database was manually searched without language restriction for articles published in the 5 years from 2017 to 2021. The literature search was primarily focused on invasive and non-invasive devices (telemonitoring) that incorporated AI for HF diagnosis and prediction. The following keywords were used as search criteria: “(machine learning OR deep learning OR artificial intelligence OR telemonitoring OR invasive devices OR non-invasive devices OR commercial devices OR implantable devices) AND heart failure.”

## 12.3 ML Algorithms

ML is considered a subfield of AI, and involves the study of statistical algorithms that can progressively learn from data and achieve a desired performance on a specific task. The rules, findings, and knowledge derived from the data using ML are expected to be non-trivial. Therefore, ML has been used in tasks that require automation, and especially in cases where humans cannot manually develop such a set of complex instructions to automate the desired tasks. Deep learning (DL) is considered a subfield of ML and focuses on learning data representations using algorithms composed of multiple processing layers. In this chapter, the following ML algorithms have been employed:

- **Random forest (RF)**: RF is a supervised learning algorithm, consisting of a group of decision trees trained using the bagging method, wherein, a combination of learning models is utilized to increase the accuracy of the overall result. Hence, RF incorporates multiple decision trees merged together to get more accurate and stable predictions [18]. The multiple decision trees incorporated to create a RF classifier, utilize class label attributes from individual decision trees to provide a more comprehensive classification [18–21].

- **Support vector machine (SVM)**: Similarly to RF, SVM utilizes logic-based classification techniques wherein the algorithm learns from a predefined set of rules developed based on the training data, and follows a logical decision making approach to classify the test data [22–25]. Contrary to RF, SVMs uses linear or non-linear classification methods to distinguish data based on features by identifying an optimal hyperplane that separates data points from different classes [22, 24, 26–28].

- **Artificial neural networks (ANNs)**: DL is an advanced subfield of ML that employs ANNs with multiple layers of abstraction (networks) to extract features from underlying data distributions [24]. ANNs are generally trained on large amounts of data using graphics processing units, making them highly effective in the classification of data. The neural networks (NNs) essentially consist of multiple interconnected processing layers that identify features from the sample data and utilize detection algorithms to classify test data based on the most useful and important features selected.

- **Bayesian networks**: These are graphical models that use probabilistic processing to represent the conditional dependences between variables (nodes). Since Bayesian networks can aptly predict the causative relationship between an event and its contributing factors, they are ideal for classifying diseases based on clinical symptoms. Bayesian networks can require large amounts of data to accurately establish probabilistic relationships between a complete set of features and predicted outcomes, hence, more simplistic models, such as the Naive Bayes, have been developed. Herein, the features are assumed to be independent and a probabilistic model is created for each feature; classification is performed by assigning each test feature to the class with the highest probability [29, 30].

- **Convolutional neural networks (CNNs)**: A feed-forward NN is a commonly used method, wherein each node in one layer is connected to all the nodes of the subsequent layer, thus supporting decision-making in each layer based on feature information from preceding layers [31]. CNNs are a type of feed-forward NN in which nodes from one layer to the next are connected through a fixed weighting pattern or kernels which extract features based on the correlation among neighboring samples [22].

- **Recurrent neural networks (RNNs)**: RNNs are another common DL architecture, wherein a feedback loop within the network is created by connecting the output of a node to the input of a node in the previous layer [22]. RNNs offer an effective modality especially for sequential data processing by exploiting the memory effect created by the feedback loops that utilize the stored information from prior inputs.
