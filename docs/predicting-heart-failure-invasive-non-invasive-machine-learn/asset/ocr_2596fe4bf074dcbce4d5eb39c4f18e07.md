This is performed by manually labeling a small portion of data and then employing unsupervised learning algorithms to extrapolate from this data. Generative adversarial networks (GAN) are a commonly used semi-supervised technique that employs two neural networks: a generator and discriminator [1, 2, 25]. Generators are trained to synthesize plausible data points as outputs, and the discriminator is a typical convolutional neural network that aims to distinguish between fake and real data [7].

# 6.2.2.3.1 Examples of Semi-Supervised Learning in Cardiology

Semi-supervised learning is a more novel technique that requires knowledge of various learning techniques. Several studies have employed this in cardiology that have focused on using semi-supervised ML algorithms to quantify chamber dimensions on echocardiography. An example are algorithms developed to automatically quantify left atrium (LA), LV volumes, and LVEF from 3D TTE images [26, 27]. One study applied this algorithm to 159 patients and found automated LVEF measurements using a semi-supervised algorithm had a strong correlation both with manual 3D volumetric measurements from three readers (r = 0.87–0.96) and with cardiac magnetic resonance (CMR) (r = 0.84–0.95) [26]. Another example is a study which included apical four- and two-chamber views from 255 patients across four centers and applied a semi-supervised ML algorithm to assess EF and LV longitudinal strain. The fully automated algorithm was compared with manual estimation, and the study found the algorithm to be feasible in 98% of studies with an average analysis time of 8 seconds per patient [27].

# 6.2.2.4 Reinforcement Learning

Reinforcement learning is a technique in which an algorithm is trained to learn an action that gains maximum reward. The algorithm is given input data and a specific outcome to optimize, learning through trial and error. This technique is seldom used in cardiology, but is more commonly used in computer gaming programs; a notable example is AlphaGo (a computer program that uses reinforcement learning to play Go) [1]. However, one example of reinforcement learning in cardiology is a study which aimed to use this technique to detect eight anatomical landmarks, including bony structures, organs, and vessel bifurcations, from 1487 3D-CT scans from 532 patients [28].

# 6.2.3 Deep Learning

Deep learning is another subfield of ML of which artificial neural networks (ANNs), recurrent neural networks (RNNs), and convolutional neural networks (CNNs) are the most commonly used techniques [25].
