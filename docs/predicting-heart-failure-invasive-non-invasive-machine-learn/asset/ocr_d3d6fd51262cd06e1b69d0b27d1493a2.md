# Table 9.1 State of the art of ML for HF diagnosis.

| Study | Target | Method | Features | Data Set | Evaluation Measures |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Yang et al. 2010 | HF diagnosis Healthy vs. HF-prone vs. HF | SVM | Blood test, HRV measurements, echocardiographic graphic and ECG features, chest radiography test, 6-minutes walk distance test and physical test. | 289 subjects 70 controls 59 HF-prone 160 with HF | Accuracy 78.79% for the control group Accuracy 87.50% for the HF-prone group Accuracy 65.85% for the HF group |
