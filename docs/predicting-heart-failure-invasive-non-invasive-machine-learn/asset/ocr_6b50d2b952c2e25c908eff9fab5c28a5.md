# Table 7.1 Heart failure data set with 14 attributes.

| Attribute | Description |
| :--- | :--- |
| age | Age of the patient in years_ |
| sex | Represented as a binary number. 1 = male, 0 = female. |
| cp | Chest pain type. Values range from 1 to 4. { 1: typical angina, 2: atypical angina, 3: non-anginal pain, 4: asymptomatic}. |
| trestbps | Resting blood pressure measured in mmHg on admission to the hospital. |
| chol | Serum cholesterol of the patient measured in mg/dl_ |
| fbs | Fasting blood sugar of the patient. If greater than 120 mg/dl the attribute value is 1 (true), else the attribute value is 0 (false). {1: true, 0_ false}. |
| restecg | Resting electrocardiographic results for the patient_ This attribute can take 3 integer values 0, 1, CT 2_{0: normal, 1: having ST-T wave abnormality, 2: showing probable or definite left ventricular hypertrophy by Estes criteria} |
| thalach | Maximum heart rate achieved of the patient. |
| exang | Exercise induced angina. Values can be {0: No CT 1: true}. |
| oldpeak | ST depression induced by exercise relative to rest. |
| slope | Measure of slope for peak exercise. Values can be 1, 2, or 3. {1: up sloping, 2: flat, 3: down sloping}. |
| ca | Number of majorvessels (0-3) colored by fluoroscopy. Attributevalues can be 0 to 3. |
| thal | Represents heart rate of the patient. It can take values 3, 6, or 7_{3: normal, 6: fixed defect, 7: reversible defect}. |
| num | Contains a numeric value between 0 and 4. Each value represents a heart disease CT absence of all of them.{ 0 <50% diameter narrowing._ (Absence of heart disease). 1 to 4: >50% diameter narrowing_ (Presence of different heart diseases) |
