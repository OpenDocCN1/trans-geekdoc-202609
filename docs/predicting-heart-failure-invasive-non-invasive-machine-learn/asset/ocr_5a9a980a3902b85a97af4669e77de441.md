(holdout) model was adopted to evaluate algorithms' performance where original data sets are partitioned into different training and testing sets. One observation is held out in each validation cycle, whereas the remaining observations act as a training set and build the classifier model. This step is repeated until all observations act as test observations. Accordingly, each iteration's performance errors are calculated, and the average performance is calculated at the end of validation.

# 7.4.1 Data Sets Description

Two data sets were used in this study. The first one was obtained from the Cleveland Clinic Foundation [38] and contained 303 records; 297 are complete and 6 have missing/unknown values. The second one was the Statlog data set available at the UCI Machine Learning Repository [39] and contains 270 completed records. Originally, the two data sets shared the same 76 features, but they were preprocessed to produce 14 attributes in an effort to reduce the number of variables. Consequently, we used these specific attributes for the two data sets described in Table 7.1 to facilitate comparison and replication studies. The statistical properties of numerical features for the Cleveland and Statlog data sets are presented in Tables 7.2 and 7.3, respectively.

This variety enables us to understand better the data set structure and its impact on classification accuracy.
