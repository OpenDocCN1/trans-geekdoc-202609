Classification supervised ML algorithms have also been studied in echocardiography to differentiate hypertrophic cardiomyopathy from physiologic hypertrophy, and constrictive cardiomyopathy from restrictive cardiomyopathy [13–15]. In CCTA, supervised ML algorithms have also been applied to automatically quantify coronary artery calcification [16]. Algorithms have also been used to identify patients with hemodynamically significant CAD by analyzing the left ventricle (LV) [17]. Another case of supervised ML algorithms is in disease prognostication. For example, algorithms have been successfully used to predict which patients with CAD will eventually undergo early revascularization [18]. A recent study evaluated 713 myocardial perfusion scans (MPSs) and associated invasive angiography to compare an ML algorithm with visual analysis by two experienced readers [18]. It found the specificity of the algorithm in predicting early both revascularization and 3-year major adverse cardiovascular events was superior (74.7 ± 4.2%) [18].

Other examples of regression-based supervised ML learning include a recent study illustrating that three-dimensional (3D) cardiac motion can predict survival in patients with newly diagnosed pulmonary hypertension [19]. In this study, 256 patients with newly diagnosed pulmonary hypertension underwent cardiac MRI, right heart catheterization and a 6-minute walk test [19]. A supervised ML algorithm was then applied to a 3D model of right ventricular motion and better predicted survival compared with conventional imaging, hemodynamic, functional, and clinical markers (AUC = 0.73 vs 0.60; p < 0.001) [19]. The study found impaired contractile motion in anatomically distinct but functionally synergistic areas of the right ventricle provided early signals as to the severity of pulmonary hypertension and hence mortality [19].

## 6.2.2.2 Unsupervised Learning

Unsupervised learning is a more advanced form of learning using unlabeled data to discover underlying relationships; it is often referred to as knowledge discovery [7]. Unsupervised learning holds great promise in clinical practice where coding large data sets can be prohibitively expensive and time-consuming. Common examples of unsupervised learning techniques include clustering, dimensionality reduction, association, and anomaly detection [2].

Clustering involves dividing objects into groups that share similar characteristics with the aim of finding subgroups within a larger data set. The most commonly used techniques include hierarchical clustering, K-means clustering, density-based spatial clustering of applications with noise, and model-based clustering [7]. Irrelevant features can compromise the efficacy, efficiency, and utility of ML algorithms and dimensionality reduction is a technique used to minimize irrelevant features by identifying the most important features in a data set [20]. Anomaly detection is a technique that identifies outliers in a data set and helps unsupervised ML algorithms remove anomalies and erroneous data entries [6].

### 6.2.2.2.1 Examples of Unsupervised Learning in Cardiology

Unsupervised learning is often combined with more advanced techniques, such as deep learning, when applied to large, complex data sets in cardiology. One example is a comprehensive unsupervised ML algorithm which was able to successfully differentiate heart failure with preserved ejection fraction (HFpEF) from healthy subjects by analyzing LV long axis myocardial velocity patterns on stress echocardiography [14]. This study built an unsupervised ML algorithm from 156 patients using 22 descriptors with 300 features collected from tissue Doppler-derived longitudinal myocardial velocity traces at rest and during exercise [14]. The algorithm found naturally occurring patterns and relationships within the details to identify a continuum of disease from normal cardiac function to patients with HFpEF [14]. The spectrum varied in age, body mass index, left ventricular mass index, and left ventricular filling pressures and symptom burden as measured by the 6-minute walk test [14].

Clustering-based algorithms are the more common examples of unsupervised learning in cardiology. One example is an unsupervised ML algorithm used to identify distinct hypertensive subgroups associated with the myocardial substrate for HFpEF [21]. The ML algorithm clustered 1273 patients into two mutually exclusive pheno-groups, based on 47 variables including clinical characteristics, cardiac structure, and function [21]. These subgroups may represent different genotypes that could benefit from targeted therapies to prevent HFpEF onset [21]. Another example is in type 2 diabetes mellitus where an unsupervised ML algorithm was applied to the echocardiographic images of 842 patients from two prospective cohorts to identify three clusters of patients from 12 echocardiographic variables [22]. Cluster 1 patients had the lowest LV mass index, the highest LV ejection fraction (LVEF), and were predominantly male; Cluster 2 patients were the oldest and had the highest strain and E/e' ratios; Cluster 3 patients had the highest LV mass index and the lowest LVEF [22]. A cluster analysis was then performed which found clusters 2 and 3 were associated with worse cardiovascular mortality and hospitalizations compared with cluster 1 (HR 2.37) [22]. Hierarchical clustering algorithms have also been studied to identify distinct clusters in diastolic heart failure. One study performed a cluster analysis and developed an ML model of LV diastolic dysfunction from 130 patients that was subsequently tested in a prospective cohort of 44 patients [23]. Speckle-tracking echocardiography (STE) was used to measure simultaneous changes in left atrial and ventricular volumes, longitudinal strains, and strain rates [23]. STE strongly correlated with conventional indices and clustered patients into three groups with differing severities of diastolic dysfunction and LV filling pressures [23]. Another example is a study that identified two distinct groups using an unsupervised, hierarchical cluster analysis of echocardiographic parameters of diastolic dysfunction in 866 patients [24]. Compared with conventional classification, the clustering algorithm improved prediction of all-cause and cardiac mortality [24]. Similarly, other studies have used unsupervised clustering-based ML algorithms to identify differences in clinical, structural, and invasive hemodynamics, which have been correlated with hospitalizations and with all-cause and cardiac mortality [3, 25].

## 6.2.2.3 Semi-Supervised Learning

Semi-supervised learning combines supervised and unsupervised learning techniques. One of the more costly and time-consuming aspects of supervised learning is accurately labeling large data sets [25]. Semi-supervised learning provides the ability to extrapolate and label a large data set from a smaller, manually labeled data set. This is performed by manually labeling a small portion of data and then employing unsupervised learning algorithms to extrapolate from this data. Generative adversarial networks (GAN) are a commonly used semi-supervised technique that employs two neural networks: a generator and discriminator [1, 2, 25]. Generators are trained to synthesize plausible data points as outputs, and the discriminator is a typical convolutional neural network that aims to distinguish between fake and real data [7].

### 6.2.2.3.1 Examples of Semi-Supervised Learning in Cardiology

Semi-supervised learning is a more novel technique that requires knowledge of various learning techniques. Several studies have employed this in cardiology that have focused on using semi-supervised ML algorithms to quantify chamber dimensions on echocardiography. An example are algorithms developed to automatically quantify left atrium (LA), LV volumes, and LVEF from 3D TTE images [26, 27]. One study applied this algorithm to 159 patients and found automated LVEF measurements using a semi-supervised algorithm had a strong correlation both with manual 3D volumetric measurements from three readers (r = 0.87–0.96) and with cardiac magnetic resonance (CMR) (r = 0.84–0.95) [26]. Another example is a study which included apical four- and two-chamber views from 255 patients across four centers and applied a semi-supervised ML algorithm to assess EF and LV longitudinal strain. The fully automated algorithm was compared with manual estimation, and the study found the algorithm to be feasible in 98% of studies with an average analysis time of 8 seconds per patient [27].

## 6.2.2.4 Reinforcement Learning

Reinforcement learning is a technique in which an algorithm is trained to learn an action that gains maximum reward. The algorithm is given input data and a specific outcome to optimize, learning through trial and error. This technique is seldom used in cardiology, but is more commonly used in computer gaming programs; a notable example is AlphaGo (a computer program that uses reinforcement learning to play Go) [1]. However, one example of reinforcement learning in cardiology is a study which aimed to use this technique to detect eight anatomical landmarks, including bony structures, organs, and vessel bifurcations, from 1487 3D-CT scans from 532 patients [28].
