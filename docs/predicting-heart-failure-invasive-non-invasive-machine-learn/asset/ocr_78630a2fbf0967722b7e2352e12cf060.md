# 6.2.1 Artificial Intelligence and Statistical Models

AI can be understood as an extension of statistical modeling, with the differences related less to methodologies and more to the respective objectives and the questions they aim to answer (Figure 6.1). Statistics is the mathematical study of data, and statistical models use data to infer relationships and extrapolate values [1]. However, statistical models emphasize understanding the relationships between data points rather than extrapolating values [2]. In comparison, the primary goal of AI is to predict future values using existing data, with less emphasis being placed on understanding the relationships between variables [3]. However, there are exceptions to this rule with some ML techniques, such as LASSO (least absolute shrinkage and selection operator) regression which allow relationships between data points to be analyzed.

At the most superficial level, AI can be divided into general and applied (or narrow) AI (Figure 6.2) [4]. General AI refers to the ability of an algorithmic system to process, learn, and solve previously unseen problems; this is yet to be achieved. Applied or narrow AI is more common and refers to algorithmic processes being developed for specific and specialized purposes [2].

# 6.2.2 Machine Learning

ML techniques vary in their objectives, applications, and architectures (Table 6.1). The type, structure, and depth of input data influence which algorithm is most appropriate in answering a research question. Some algorithms, such as supervised learning algorithms are better suited for analyzing structured data over languages, and others, including deep learning, are more suited to images with spatial resolution [5]. In brief, ML is an iterative process that involves approximating complex mathematical relationships between inputs and outputs by learning from a large data set to predict values from new, unseen data [6]. Supervised, unsupervised, semi-supervised, reinforcement, and deep learning are terms describing how ML algorithms learn from data.
