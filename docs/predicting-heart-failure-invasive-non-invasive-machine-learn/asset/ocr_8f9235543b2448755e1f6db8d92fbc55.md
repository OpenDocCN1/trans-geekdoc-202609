# 7.3 Choice of Machine Learning Algorithms

The healthcare environment generally includes rich data about patients and their treatment stored in health management systems. Such data is valuable, especially if we transfer the existing information into good practices. Machine learning algorithms are widely used to extract valuable knowledge from hidden relationships and trends among the data. In fact, machine learning algorithms have been extensively used in healthcare research as a stage of the knowledge discovery process [32], which presents favorable ways to discover the hidden relationship in the health data [33]. They have been applied to a diversity of healthcare domains to improve and accelerate decision-making [32]. Classification methods are the most widely used algorithms in the healthcare sector as they help predict patient status by classifying patient records to find the class that matches the new patient record [3]. Classification is a supervised learning technique, which requires the data to be initially labeled [33]. These data are the entered into a classification algorithm to be learned, as shown in Figure 7.1, to discover the relationship between input variables and the target variable. In this phase, the classification algorithms build the classifier from the training data. Each observation that forms the training set is referred to as a class label. When a new case is received, the constructed classification algorithm is used to classify it into one of the predefined labels, as shown in Figure 7.2.
