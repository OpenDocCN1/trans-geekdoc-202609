# ## 4.3.2 Microwave Wireless Power Transfer

Microwave power transmission (MPT) is a technique used to transfer electricity anywhere which is hard to reach (e.g. a microchip implant underneath the skin). The wireless energy transmission structure consists of three parts:

+   - Transmitter
+   - Traveling wave area (air, skin)
+   - RF/DC circuit (rectifying antenna).
