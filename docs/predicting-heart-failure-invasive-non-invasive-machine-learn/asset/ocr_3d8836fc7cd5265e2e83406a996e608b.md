# 7.3.3 K-Nearest Neighbor

K-NN is a simple classification algorithm based on predicting by similarity [36]. It
is considered a lazy algorithm because it consumes time searching for similar cases.
This algorithm's basic idea is to find within historical data a set of similar K cases to
the new case, where the final prediction is made by majority voting. Multiple param-
eters calibrate the k-NN algorithm's accuracy, which are the distance measure, the
feature importance, and optimal K value selection. In this chapter, we used
Euclidean distance as a similarity measure because it is a common one. In addition
to that, the value of K is selected by trial and error until the evaluation measures are
improved.

# 7.3.4 Random Forest

RF is an ensemble learning algorithm based on constructing a forest of DT classifi-
ers. Each DT in the forest is constructed from different training data sets. The final
prediction is usually measured by voting. The RF has several advantages, notably
computation efficacy and better accuracy than a DT without significantly increasing
computational cost. It can also predict up to thousands of explanatory variables [34].

# 7.3.5 Support Vector Machine

The main idea of SVM is to build an optimal hyperplane with a maximum margin that
can separate class labels efficiently. Maximizing the margin and producing the largest
possible distance between the hyperplane and the instances on each side have been
proven to reduce an upper bound on the expected generalization error. Since healthcare
data are often nonlinear, the SVM uses kernel functions to map data from low dimen-
sionality to higher dimensionality, facilitating optimal hyperplane [37].
