Hence, there is similarity between EHR data representation and natural language representation where the text is represented as a sequence of words or sentences. Therefore, ML models developed in the area of language understanding can readily be applied to EHR data.

In Rasmy et al. [47], a large EHR data set is used for the predictive modeling of HF onset risk. The data set included more than 150,000 HF patients and over 1,000,000 controls from about 400 hospitals. Patients are defined based on the two criteria: (i) at least three encounters with related HF had to occur within 12 months; (ii) the first HF diagnosis occurred when they were over 50 years old. For each case, 10 matched controls are identified based on the primary care hospital, sex, and age. Furthermore, the time span of the control and case data were matched by ensuring that the first visit of the controls were within one year of the first visit of the matched case and there was at least one visit a month before or any time after the diagnosis date of the matched case. Each visit is represented by the medical codes related to diagnoses, medication, and surgical procedure data. For diagnoses and surgical procedures, ICD-9 and ICD-10 were used. For medication information, the National Drug Codes (NDC) were used.

A known deep learning model called RETRAIN (reverse time attention model) has been previously used for HF prediction [48] based on a relatively small data set compared with the one used in Rasmy et al. [47]. The model was designed to predict the diagnosis of HF at the next visit. Hence at each visit, the model gives a probability score for the patient having an HF. RETRAIN is a two-branch neural attention model on top of an embedding layer. It takes as input the sequence of recorded events in the patient's EHR. First, an embedding layer is responsible for reducing the dimensionality of the input representation and converting the multi-hot vector unit to a real-valued smaller size vector representation. Then two gated recurrent unit (GRU) RNNs are derived in parallel. The first RNN (RNNα) is responsible for deriving attention weights of the visits, which is a vector α where length is the number of visits. Therefore, it is possible to infer which visits are most important for predicting HF. The second RNN (RNNβ) is used to derive the clinical code level attention. Hence, it is possible to know which event (diagnosis, medication, surgical procedure) is most relevant for the prediction of HF. These two RNNs can be applied to new patients not seen during model training. They provide good interpretability properties of the model.

In order to compare the RETRAIN model with classical ML approaches, a baseline logistic regression model using an aggregated feature vector on the temporal dimension was adapted. Each dimension represents the count of each code event in the subject's history. L1 and L2 regularization terms were evaluated in the experimental analysis. Also, the embedding from RETAIN was used as input to train the logistic regression. EHRs from multiple hospitals were gathered for the Cerner Health Facts database. For each hospital the cohort was divided into training, validation, and test sets with a ratio of 7:1:2. A regularized logistic regression model was used as a baseline model. The feature vector for the baseline was the codes' occurrence of the aggregated data on the temporal dimension. The RETAIN model achieved an AUC of 82% compared with 79% for logistic regression.
