Such data is valuable, especially if we transfer the existing information into good practices. ### 7.3.1 Decision Tree

The DT is used for classification and regression tasks that accept different input feature types [34]. The principle behind constructing a DT is quite simple. The DT model is constructed using the binary recursive partitioning technique, which iteratively divides the data into groups and then divides it up on each branch. The least-squares error is used as a loss function to determine when the process of fitting must terminate. A powerful DT algorithm known as the classification and regression trees (CART) algorithm was used in this study. The CART algorithm consists of three main stages:

- 1. Building a tree that contains coherent data in each branch.
- 2. Pruning the DT to reduce overfitting.
- 3. Using a smoothing technique to prevent sharp discontinuities between adjacent linear models at the pruned tree leaves.

### 7.3.2 Naive Bayes

The NB classifier is a probabilistic algorithm based on Bayes’ theorem, with independence assumptions [34]. It considers that the presence/absence of a particular attribute of a class is unrelated to any other attribute's presence/absence when the class variable is given. It helps to make the computation process very easy, and it has better speed and accuracy for huge data. It can also calculate the possible output based on the input and add new raw data at run time [35].

### 7.3.3 K-Nearest Neighbor

K-NN is a simple classification algorithm based on predicting by similarity [36]. It is considered a lazy algorithm because it consumes time searching for similar cases. This algorithm's basic idea is to find within historical data a set of similar K cases to the new case, where the final prediction is made by majority voting. Multiple parameters calibrate the k-NN algorithm's accuracy, which are the distance measure, the feature importance, and optimal K value selection. In this chapter, we used Euclidean distance as a similarity measure because it is a common one. In addition to that, the value of K is selected by trial and error until the evaluation measures are improved.

### 7.3.4 Random Forest

RF is an ensemble learning algorithm based on constructing a forest of DT classifiers. Each DT in the forest is constructed from different training data sets. The final prediction is usually measured by voting. The RF has several advantages, notably computation efficacy and better accuracy than a DT without significantly increasing computational cost. It can also predict up to thousands of explanatory variables [34].

### 7.3.5 Support Vector Machine

The main idea of SVM is to build an optimal hyperplane with a maximum margin that can separate class labels efficiently. Maximizing the margin and producing the largest possible distance between the hyperplane and the instances on each side have been proven to reduce an upper bound on the expected generalization error. Since healthcare data are often nonlinear, the SVM uses kernel functions to map data from low dimensionality to higher dimensionality, facilitating optimal hyperplane [37].

## 7.4 Research Methodology

The current research aims to improve the diagnosis of heart diseases by examining the patient's symptoms using data mining classification methods. A literature review was carried out to review the data mining works related to diagnosing heart diseases to achieve this goal. After that, five classifiers (NB, DT, LDA, RF, and SVM) were selected to build various classifiers. Each technique has a different way of building classifiers, ensuring that they behave differently and produce different results, underscoring the practical viability of our approach. In all conducted experiments, the leave-one-out cross-validation (holdout) model was adopted to evaluate algorithms' performance where original data sets are partitioned into different training and testing sets. One observation is held out in each validation cycle, whereas the remaining observations act as a training set and build the classifier model. This step is repeated until all observations act as test observations. Accordingly, each iteration's performance errors are calculated, and the average performance is calculated at the end of validation.
