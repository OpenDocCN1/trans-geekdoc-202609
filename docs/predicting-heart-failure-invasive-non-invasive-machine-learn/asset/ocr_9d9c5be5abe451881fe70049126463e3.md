While supervised learning techniques can provide a high degree of accuracy, the limited availability of annotated clinical data makes unsupervised [43] ML algorithms a necessity in performing real-time ECG classification based on unlabeled data using characterization methods like clustering or principal component analysis [22, 24, 44]. Also, multiple studies have proposed probabilistic models based on Bayesian networks to classify ECG, with Naive Bayes [45, 46] being one of the most commonly utilized feature assessment techniques [22, 29, 30, 37]. Supervised, instance-based ML algorithms utilizing non-parametric classifiers to compare the test and training data, such as k-nearest neighbors (k-NN), that label the test data based on the k closest training samples in the feature space [22, 23, 47-49], have also been employed by various studies.

Based on the processing algorithms utilized to identify features and perform classification, there have been multiple DL architectures introduced for the prediction of major HF clinical outcomes [22, 42,50-54; Figure 12.1]. CNNs have been shown to be highly effective in image classification [55, 56] and have been utilized widely for HF detection and diagnosis [51, 57, 58]. RNNs have shown success in identifying HF patients [50] and predicting the onset of HF [59-61]. A combination of such architectures creating multiple layers of processing can be utilized to improve performance and prediction efficacy, creating a deep neural network (DNN) [55, 62], which has shown promise in HF prediction [58, 63, 64; Figure 12.1].
