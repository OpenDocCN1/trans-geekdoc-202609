## [1.2 Big Data Revolution](#contents.xhtml#rsec1_2)

过去几年中呈指数级增长的新趋势是“大数据”。大数据是数据利用领域的一个新时代。它指的是包含结构化和非结构化数据的大型数据集，这些数据会被进一步分析以做出智能决策。根据国际数据公司（IDC）的一份报告，预计到 2025 年大数据将增加到 163 ZB \[[2](#bib.xhtml#ch00-bib-2)\]。大数据的特征是 3 个 V，即容量、速度和多样性。虽然其他研究还引入了真实性、价值和变异性作为额外特征 \[[85](#bib.xhtml#ch00-bib-85)\]。许多组织使用大数据来解决业务问题并带来创新。来自 IoT 系统、卫星、社交媒体、在线游戏等的新数据集是大数据革命的主要因素。数据集非常复杂且庞大，以至于常规软件无法处理它们 \[[205](#bib.xhtml#ch00-bib-205)\]。此外，在产生的海量数据中，缺乏对有用数据的洞察。然而，数据分析正在努力开发复杂的语言来分析这些海量数据。然而，作为一个优势，数据的增加会带来更高的准确性和更自信的决策 \[[178](#bib.xhtml#ch00-bib-178)\]，\[[194](#bib.xhtml#ch00-bib-194)\]。

此外，大数据分析是一个搜索数据库、数据挖掘并得出一些结果以改善组织绩效的过程。这些分析需要能够处理结构化、非结构化和半结构化数据，并将其转换为更易理解形式的工具。然而，隐私、保密性、可用性、速度、身份验证、高效存储和处理冗余是一些需要着手改进的大数据策略，以便在系统中取得改进。

### [1.2.1 Big data and IoT](#contents.xhtml#rsec1_2_1)

特别是，来自 IoT 设备的数据在大数据格局中发挥了重要作用。IoT 连接设备数量的增加需要先进技术来满足客户要求。此外，IoT 的普及使得大数据分析更加复杂，因为在 IoT 环境中通过异构设备收集数据。IoT 的基本概念是通过互联网连接世界上所有物理设备（即家庭、工作场所、移动车辆中），然后处理收集数据中的信息以做出有意义的决策。IoT 从不同来源生成数据（多样性），这可能有助于结构化和非结构化数据。此外，IoT 数据的数量可以从千兆字节（GB）到泽塔字节（ZB）（容量），生成的数据可以分批或流式收集（速度） \[[192](#bib.xhtml#ch00-bib-192)\]，\[[50](#bib.xhtml#ch00-bib-50)\]。因此，由于 IoT 设备产生的海量数据，我们需要一个先进的数据处理系统。IoT 数据分析可以为各种领域（如健康分析、恶意软件检测、商业市场分析和预测等）提供关于隐藏分析的重大洞察。一些 IoT 大数据应用在 [Fig. 1.6](#02chap_01.xhtml#fig1_6) 中显示。数据挖掘、机器学习、深度学习、统计分析等是一些最新的数据分析技术，用于独立分析数据 \[[101](#bib.xhtml#ch00-bib-101)\]，\[[211](#bib.xhtml#ch00-bib-211)\]。此外，IoT 分析仍未完全发展，因为大部分 IoT 生成的数据仍未被利用。此外，随着 IoT 设备数据生成的大幅增加，一个主要关注点是数据存储以及如何在单次遍历中查询如此大的数据集 \[[150](#bib.xhtml#ch00-bib-150)\]。特别是，研究人员利用大数据分析工具来解决上述挑战。[Fig. 1.7](#02chap_01.xhtml#fig1_7) 展示了导致大数据革命的因素。IoT 和大数据的融合在各个领域创造了新的机会。来自 IoT 传感器的数据随后被输入大数据框架进行探索和分析。将大数据与 IoT 集成的目的是分析大量数据并实时处理。大数据系统正在采用平台即服务（PaaS）模型，以灵活且可扩展的方式处理 IoT 数据。在某些情况下，IoT 分析和处理还与边缘计算服务协作，这将 IoT 处理分散到网络边缘 \[[162](#bib.xhtml#ch00-bib-162)\]。然而，来自边缘节点的选定数据仍然被传输到云端。显然，IoT 系统越大，它对大数据能力的业务需求就越多。以下步骤用于 IoT 大数据处理：

不幸的是，目前可用的软件无法很好地处理新兴的大数据。此外，IoT 和大数据的协作也为研究行业带来了挑战，包括数据存储和分析工具。此外，这种数据的增加需要更高的安全性，这给大数据安全专业人员带来了新的挑战。通过 Wi-Fi 和蓝牙传输的数据必须使用防泄漏技术发送。此外，分析部门应设计方法来处理 IoT 设备生成的冗余数据。
