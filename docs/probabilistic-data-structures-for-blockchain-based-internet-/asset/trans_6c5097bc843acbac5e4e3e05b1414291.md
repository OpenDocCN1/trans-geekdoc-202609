

网络流量监控对于安全网络运行非常重要。在此背景下，检测大流量（heavy hitters）是流量测量应用的一个过程。检测大流量可用于流量计费和异常检测等网络操作。大流量被定义为占总链路容量特定比例的流。换句话说，就是检测大小超过给定阈值的流。根据 Zhou 等人的说法，检测大流量是确定网络数据流中相同元素频率的过程 \[[221](#bib.xhtml#ch00-bib-221)\]。值得注意的是，网络流由 5 个元组决定，即源 IP 地址、目的 IP 地址、源端口、目的端口和协议。通常，数据流定义为 `S=p1, p2,….,pn`，其中 `pi` 由 IP 地址、端口号等组成。检测大流量已在许多领域进行了研究，例如网络流量和 IP 通话。

要使用 PDS 检测大流量，第一步是数据包处理阶段，它从网络数据包中提取网络数据流。第二步，将数据流的每个元素更新到概率性草图中。第三步，通过概率性计数计算流大小。最后，将测量间隔内流大小的估计值识别为大流量。如果某个元素的值大于或等于阈值，则相应的 IP 地址被识别为大流量。

### [16.3.1 检测 DoS 攻击](#contents.xhtml#rsec16_3_1)

如上所述，检测 DoS 攻击、异常检测、QoS 管理是实时检测大流量的重要用例。除了 HLL，还可以通过 CMS 为任何时间槽 `t` 设置阈值 `ϕ`，如果 CMS 中计数器的频率大于预定义阈值 `ϕ * N`（`N` 是总计数），则该节点可被识别为恶意节点。此外，通过使用频率计数 PDS，验证者可以检查块中地址的频率，或统计相同源地址和目的地址对的频率以生成实时响应。通过这种方式使用 CMS，每个流式更新可以在对数步数内处理。CMS 的另一个优点是，合法连接可以从观察池中删除 \[[118](#bib.xhtml#ch00-bib-118)\]。

受 \[[179](#bib.xhtml#ch00-bib-179)\] 工作的启发，[图 16.1](#20chap_16.xhtml#fig16_1) 提出了一种用于私有区块链 IoT 网络中实时检测大流量的想法。尽管 \[[179](#bib.xhtml#ch00-bib-179)\] 的作者没有使用 PDS 来检测大流量。由于私有区块链中的参与者数量通常较少，因此必须确保节点的可用性才能正确运行。显然，私有区块链网络的节点应始终可用，同时受到 DoS 攻击的保护。该提案使用了一个软件定义网络（SDN）支持的交换机来保护私有区块链中的节点免受 DDoS 攻击。在网络中，这种攻击会阻止节点参与共识机制，这可能导致计算能力的浪费。但是，DDoS 是基于流量统计通过使用 Count-Sketches 检测的 \[[135](#bib.xhtml#ch00-bib-135), [134](#bib.xhtml#ch00-bib-134), [84](#bib.xhtml#ch00-bib-84)\]。SDN 支持的交换机会过滤掉生成大流量并试图在网络中发送数据的远程节点。它监听所有传入数据包 (`p1, p2,…….., pn`)，并从每个数据包中提取源-目的地址对以计算流条目的统计信息。SDN 交换机配置了私有网络中注册区块链节点的信息（IP 地址和端口号）。SDN 网络控制器定期检查概率性计数草图以检测大流量。它将大流量流和正常流量流分别放入黑名单和白名单中。最后，来自白名单的数据包被转发到网络中的矿工节点进行验证。

### [16.3.2 检测 RFID 标签克隆](#contents.xhtml#rsec16_3_2)

在 IoT 环境中，Count-sketches 可用于检测供应链管理、航运和港口操作、水位监测等应用中的 RFID 克隆标签。在此背景下，Hazalila *et al.\[[113](#bib.xhtml#ch00-bib-113)\]* 提出了一种基于 CMS 向量和双哈希冲突一致性的轻量级抗克隆方法。CMS 使用两个独立的哈希函数来探测相同的 EPC。在对相同的 EPC 进行哈希处理时，相同的哈希函数会导致哈希冲突，这意味着标签克隆的可能性很高。实现结果表明，所提方法优于基线方法，并在检测克隆比率方面实现了更好的准确性。虽然该提案没有实现区块链技术，但 CMS 可以扩展到基于区块链的 IoT 网络。草图是分布在多个 RFID 阅读器上的标签读取的累积。每个草图包含在批量间隔期间接收到的标签读取。
