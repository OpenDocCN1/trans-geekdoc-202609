

# 关于数字资产版权证明

A. Zhuvikin [[222](#bib.xhtml#ch00-bib-222)] 提出了一种基于区块链的图像版权登记系统，该系统基于强健的图像特征。如上文所述，LSH 通过确保相似对象比不相似对象具有更高的碰撞概率，从而在高维数据集上实现易于搜索。与使用 LSH 不同，这里使用的是交叉多面体 LSH，它也将相似数据映射到相同的索引值 [[35](#bib.xhtml#bib.xhtml#ch00-bib-35)]。但是，与原始 LSH 相比，交叉多面体显著降低了空间和时间复杂度。它使用 LSH 来检索内容相似的图像，即使这些图像经过内容保留操作（例如 JPEG 压缩、缩小、放大等）后发生了变化。要共享带有版权的原始图像，首先通过执行 LSH 并使用所有者的私钥进行签名来计算强健图像特征向量。在下一步中，获得的签名与一个称为盲因子的随机整数相乘，以生成盲签名，这些盲签名会广播到网络上的所有矿工节点以进行验证。最后，使用 LSH 和盲签名构建图像索引项，以便轻松定位版权所有者。此外，提出了一种名为“带旋转和交叉多面体局部敏感哈希的单置换（OPRCP）”的混合数据查询方法，该方法在 WMSN 混合数据（音频、图像、文本）中近似最近邻搜索，同时构建查询数据结构。OPRCP 首先使用 TF-IDF 方法提取多媒体数据的特征向量，然后从获得的特征向量构建哈希表数据结构。当验证者或用户需要将查询对象映射到数据结构时，查询在特征向量化后会经历相同的哈希计算过程。作者还分析了查询时间与 LSH 最近邻搜索中查询准确性之间的关系。与原始 LSH 相比，OPRCP 在空间和时间方面改进了相似性搜索。
