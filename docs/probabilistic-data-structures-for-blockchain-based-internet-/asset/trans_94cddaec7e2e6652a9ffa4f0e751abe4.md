

值得注意的是，与传统网络相比，为物联网范式提供安全性是复杂的，因为来自各种传感器的异构数据的存在。此外，由于系统的开放性以及通过无线通信介质与互联网互连，安全性是一个突出的挑战。此外，传统的安全解决方案（包括`firewall`和`anti-virus`）由于空间和能量有限，不适用于物联网 \[[33](#bib.xhtml#ch00-bib-33)\]。因此，设计基于最优能耗的安全解决方案是物联网中需要特别关注的重要问题之一 \[[188](#bib.xhtml#ch00-bib-188)\]。文献支持各种加密协议，包括`Rivest–Shamir–Adleman (RSA)`、`Elliptic-curve cryptography (ECC)`、`Diffie Hellman (DH)`密钥交换等，以处理这些安全问题。使用加密的安全解决方案也不适合物联网，因为这些受限设备无法实现复杂的加密和解密。此外，所有这些安全协议都依赖于一对加密密钥，对于这些密钥对的生成和管理，物联网制造商依赖于集中式、受信任的第三方。此外，数字证书的检查、维护和吊销也依赖于一个称为“注册机构”的集中式方。值得注意的是，拥有一个集中式方可能成为单点故障，并成为数据隐私攻击的原因。此外，为每个物体颁发数字证书是有问题的，因为物联网对象的数量非常大。因此，需要解决授权、身份验证、可用性、不可否认性和信任等关键要求，以应对未来的物联网网络。

## 3.2 数据管理

物联网设备产生大量需要实时处理和分析的数据。当前的数据中心框架无法有效处理数据的异构性。学术界和工业界都有大量研究致力于解决物联网中的数据管理问题。根据国际数据公司的一份报告，物联网设备产生的数据预计将从2018年的33 ZB增长到2025年的79.24 ZB \[[7](#bib.xhtml#ch00-bib-7)\]。

数据管理的主要关注点之一是数据存储。物联网数据存储基本有三种类型，即本地、分布式和集中式。本地类型表示物联网传感器产生的数据将存储在物联网设备本身上。分布式处理表示数据将存储在边缘并通过分布式技术进行处理，而集中式类型表示收集的数据存储在数据中心。如前所述，物联网设备缺乏电力且存储空间有限，因此在物联网设备上存储数据是不可能的。此外，用于存储物联网设备产生的数据的数据中心应拥有足够的能源和电力资源，以便在需要时处理查询。然而，在未来，物联网设备产生的预计数据量可能会使云基础设施过载。此外，在远程集中位置存储数据在处理任何查询时可能会导致高响应时间。因此，物联网数据应存储在靠近数据生成点的分布式位置。

## 3.3 隐私

物联网系统包含多个设备，这些设备生成和交换包含隐私敏感信息的异构数据。例如，智能健康可穿戴设备和设备产生大量包含用户位置、健康状况、睡眠模式等信息的物联网数据。值得注意的是，这些数据存储在第三方云服务提供商处。此外，用户的浏览互联网兴趣行为由第三方收集，以丰富用户体验。因此，在医疗保健、电力数据、军事应用等场景中，通常需要提供隐私保护 \[[207](#bib.xhtml#ch00-bib-207)\]。隐私是设备控制何时以及与谁共享设备个人信息的能力 \[[217](#bib.xhtml#ch00-bib-217)\]。此外，收集的个人数据应由授权服务提供商访问。传统的隐私保护方法由于高能耗和处理开销，对物联网来说成本高昂。值得注意的是，依赖集中式云服务器（第三方审计员），用户不知道有多少个人信息正在与其他方共享。此外，大多数最先进的隐私框架基于集中式结构，因此由于可扩展性问题和单点故障，不适合物联网。因此，物联网系统需要一种轻量级、可扩展且分布式的隐私保障。

## 3.4 异构性

物联网连接不同复杂度和不同供应商的各种物联网实体。最近，研究人员为物联网开发了多种硬件和软件平台。物联网中的交互不依赖于某一种特定的硬件设备或软件，而是依赖于各种不同类型的智能连接设备。物联网设备的发布日期、版本、技术接口和比特率可能不同。此外，物联网系统在通信协议、数据格式和基础设施方面表现出异构性。由于许多异构事物连接到互联网，需要一种支持轻松连接、控制和通信的特定架构。此外，为了支持自动化，不同设备应具有同步时钟。此外，物联网的环境是动态的，即设备可能连接到与另一时间完全不同的一组设备。由于设备的高度异构性，物联网在网络中缺乏可扩展性、互操作性、可靠性、可用性和安全性。因此，必须在所有网络技术中部署互操作性，并考虑其模式、网络提供商和供应商。
