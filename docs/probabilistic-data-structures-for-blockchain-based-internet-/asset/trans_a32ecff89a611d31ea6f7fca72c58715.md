

该类别下的数据结构近似了高维数据的相似性搜索。有时，相似性搜索也被称为近似最近邻搜索或邻近搜索。在该类问题中，不同的感兴趣特征（例如，文本文档、图像）被视为点，并使用距离度量来识别两个对象之间的相似性。相似性搜索度量将一组集合映射到范围 \[0,1\] 内的相似性分数。具体来说，这里的目标是在高维属性空间中找到重复项或相似点的簇。近似相似性搜索的用例包括查找互联网上网页之间的相似性、定位相似的图像或音频/视频文件、数据去重、识别抄袭案例、识别恶意软件家族的变体等。在数学上，该问题定义为：对于查询 `q`，目标是定位项目 `x`，使得 `dis(q,x) ≤ (1+ϵ) * dis(q,x)^(*)`，其中，`ϵ` 是最多估计的预期误差 \[[212](#bib.xhtml#ch00-bib-212)\]。

近似相似性的基础也依赖于哈希，因为哈希将数据点转换为低维表示。哈希表查找和快速距离近似是用于执行近似最近邻搜索的两种哈希技术。前一种方法使用哈希表作为数据结构，由桶组成。每个项目 `x` 被哈希到桶 `h(x)`。然而，与传统哈希算法不同，这里哈希表旨在最大化邻近项目碰撞的概率。相比之下，后一种方法计算给定查询与参考项目哈希代码之间的距离。随后，距离最小的参考项目是最近邻的候选项。接下来，我们将介绍不同类型的近似相似性搜索 PDS。

## [13.2 Minhashing](#contents.xhtml#rsec13_2)

Andrie Border 引入了 minhashing 来检测 AltaVista 搜索引擎网页中的重复项 \[[53](#bib.xhtml#ch00-bib-53)\]，\[[54](#bib.xhtml#ch00-bib-54)\]。Minhash 基于 Jaccard 相似性概念来识别两个集合之间的相似性。两个集合的 Jaccard 相似性是两个集合交集与并集的比率，公式如下：

$$\\begin{array}{l} \\left. JS(S\_{1},S\_{2}) = \\middle| S\_{1} \\cap S\_{2} \\middle| / \\middle| S\_{1} \\cup S\_{2} \\middle| . \\right. \\\\ \\end{array}$$  

(13.1)

例如，取两个小集合，`setA = 10, 113, 2, 55, 12` 和 `setB = 10, 3, 56, 7, 9`。可以注意到，集合之间有 2 个共同项，两个集合总共有 10 个唯一项。因此，集合 A 和 B 的 Jaccard 相似性为 $\\frac{2}{9}$。虽然计算两个集合之间的交集和并集是一项昂贵的操作。但是，为了计算文档之间的相似性，文档也可以表示为集合。Shingling 是将文档转换为集合的一种流行方式。`k`-shingles 定义为给定文档的所有可能 `k` 大小的不可重复子字符串的集合。一个包含 `n` 个单词的文档，拥有 `k`-shingles 集合，消耗 `O(kn)` 空间。假设一个文档由一个小句子“Clustering large number of binary program is a difficult task”组成。那么，5 个单词长的 shingles 是：

*   Clustering large number of binary
*   large number of binary program
*   number of binary program is
*   of binary program is a
*   binary program is a difficult
*   program is a difficult task

因此，文档作为一个集合是：（“Clustering large number of binary”，“large number of binary program”，“number of binary program is”，“of binary program is a”，“binary program is a difficult”，“program is a difficult task”）。计算 Jaccard 相似性的时间复杂度是 `O(n[2])`，因为总共有 $\\frac{n(n - 1)}{2}$ 次比较。

此外，大量集合也可以由一个单一的布尔矩阵表示。要将集合表示为布尔矩阵，矩阵的行包含全集的元素，而矩阵的列包含所有集合。行 `r` 和列 `c` 的条目为 1，当且仅当行 `r` 的集合是列 `c` 的成员，否则条目为零。在这种情况下，列相似性是具有列值为 1 的行的集合的 Jaccard 相似性。为了理解这一点，考虑三个列 C1、C2、C3，其值为：从 [Table 13.1](#16chap_13.xhtml#tab13_1) $Sim(C\_{1},C\_{2}) = \\frac{2}{5}$，因为在列 C1 和 C2 中有两行，两个条目都为 1。因此，列 C1 和 C2 所代表的集合的交集为 2。此外，还有至少有一列为 1 的行。因此，所代表集合的并集为 5。因此，Jaccard 相似性为 $\\frac{2}{5}$，即 40%。同样，$Sim(C\_{1},C\_{3}) = \\frac{1}{5}$。值得注意的是，此矩阵不是稀疏的，计算这种情况下的 Jaccard 相似性非常简单。然而，使用这种表示，结果矩阵是稀疏的，即它的零比一多，这是内存的开销。从 [Table 13.1](#16chap_13.xhtml#tab13_1) $Sim(C\_{1},C\_{2}) = \\frac{2}{5}$，因为在列 C1 和 C2 中有两行，两个条目都为 1。因此，列 C1 和 C2 所代表的集合的交集为 2。此外，还有至少有一列为 1 的行。因此，所代表集合的并集为 5。因此，Jaccard 相似性为 $\\frac{2}{5}$，即 40%。同样，$Sim(C\_{1},C\_{3}) = \\frac{1}{5}$。值得注意的是，此矩阵不是稀疏的，计算这种情况下的 Jaccard 相似性非常简单。然而，使用这种表示，结果矩阵是稀疏的，即它的零比一多，这是内存的开销。Minhash 算法提供了一种快速近似两个集合 Jaccard 相似性的方法。为了实现 minhashing，为每个集合计算并保存 minhash 签名到签名矩阵中。计算出的 minhash 签名具有固定长度，并且与集合的大小无关。Minhash 的签名矩阵由 `h` 行组成，表示哈希函数的数量，以及 `c` 列，等于集合的总数。签名矩阵很有用，因为它提供了与布尔矩阵几乎相同的相似性，但存储空间要少得多。
