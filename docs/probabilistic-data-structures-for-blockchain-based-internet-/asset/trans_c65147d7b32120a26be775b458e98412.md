

许多基于物联网的应用旨在通过收集信息来改善城市居民的生活方式。随着人口水平的增加，智慧城市的需求日益增长，因为在庞大人口中管理这些有限资源是困难的 \[[195](#bib.xhtml#ch00-bib-195)\]。智慧城市被称为基于信息和通信技术的创新城市，旨在提高生活质量和城市运营效率。城市的智慧是指有效利用所有资源并以最大效率自动运行的能力。智慧城市提供许多服务，包括交通、废物管理、环境监测和交通管理，仅举几例。（参见 [图 2.3](#03chap_02.xhtml#fig2_3)。）智慧城市所需的关键特征，即互联、智能和仪表，均由物联网支持 \[[111](#bib.xhtml#ch00-bib-111)\]。因此，可以说物联网是智慧城市的支柱。这些应用的通信设备专门设计用于执行低功耗操作，但可用于需要更长通信距离的大面积区域。LoRa 技术在智慧城市应用中被高效使用。基础设施建设、交通、能源、治理、教育和公民是智慧城市的关键组成部分，而可持续性、生活质量、城市化和智慧是智慧城市的各种属性 \[[147](#bib.xhtml#ch00-bib-147)\]。可持续性定义了城市基础设施、气候变化、社会问题、废物管理、水资源管理治理等。服务质量是根据公民的情感和财务福祉计算的。城市化包括基础设施、技术和经济等方面。智慧包括智慧生活、智慧经济、智慧移动等方面。设计成本、可靠通信、运营效率、灾害韧性、系统故障、公共安全和碳排放是构建智慧城市的几个挑战。

在用户背景下，物联网应用分为四类：

*   个人物联网：这些应用由个人使用。例如，智能手表用户。

*   群组物联网：这些应用由一小群人使用。例如，在智能家居、联网汽车、智能教育等方面。

*   社区物联网：这些应用由更大群体的人使用。例如，智慧城市和智能公园等。

*   工业物联网：这些应用指物联网应用的工业子集。例如，智能工厂、智能农业等。

## [3.1 安全](#contents.xhtml#rsec3_1)

对于安全的物联网范式，数据隐私、保密性、完整性、身份验证、授权和可用性等参数很重要，需要实现。值得注意的是，物联网组件大多无人看管，因此很容易被攻破。此外，采用弱密码和使用默认密码是身份验证攻击的常见漏洞 \[[186](#bib.xhtml#ch00-bib-186)\]。此外，通过 Web 界面连接设备为结构化查询语言 (SQL) 注入和跨站点脚本等攻击打开了机会。同样，为了提供远程服务，物联网设备使用 Telnet 服务，分布式拒绝服务 (DDoS)、窃听和 TCP SYN 等攻击可以轻松发起 \[[219](#bib.xhtml#ch00-bib-219)\]。例如，2016 年 10 月 21 日的 Mirai 僵尸网络攻击感染了多个物联网设备。接下来，这些被攻击的物联网设备被用于通过发起 DDoS 攻击来淹没域名系统 (DNS) 服务提供商“Dyn”。结果，该僵尸网络使各种社交网络网站瘫痪。同样，女巫攻击和欺骗攻击等攻击可以在物联网设备上发起，以降低网络性能并破坏数据隐私。[图 3.1](#04chap_03.xhtml#fig3_1) (a) 显示了 2016-2021 年物联网的全球安全支出。因此，构建具有高安全控制的物联网设备很重要。
