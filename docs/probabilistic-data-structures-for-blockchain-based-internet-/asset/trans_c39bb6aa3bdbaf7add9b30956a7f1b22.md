

# Proof-of-Stake (PoS)

Proof-of-Stake (PoS) 是专门为解决 PoW 高能耗问题而设计的。PoS 在挖矿块时涉及的 CPU 计算较少，因此比 PoW 耗能更低。与依赖外部投资的 PoW 不同，PoS 仅使用内部投资（即加密货币）。虽然与 PoW 类似，PoS 也是为无许可区块链设计的。然而，在 PoS 中，矿工被称为验证者，块是锻造而非挖矿。其基于这样一个基础：网络中参与度更高且持有更多加密货币的节点不太可能攻击网络。要成为验证者，节点必须存入一些加密货币作为质押。质押者将新块追加到链上的概率与其账户中的质押量成正比。PoS 为网络提供安全性，因为成员的质押面临风险。不幸的是，采用这种方法会导致富者愈富，因为验证者因验证交易而获得激励，这增加了同一节点反复被选为验证者的可能性。此外，与涉及电力、CPU 计算和时间投资的 PoW 相比，仅拥有足够质押量的节点即可通过投资质押来攻击系统。显然，要发动 51% 攻击，验证者必须控制网络中至少 51% 的总数字货币，这使得 PoS 攻击更加昂贵。显然，攻击不成功将导致巨大的财务损失。PoS 的第一个用例是 PPCoin，其中持有最旧且数量最多代币的参与者拥有更多挖矿块的可能性（这也被称为基于币龄的选择）。在这里，质押等于代币数量乘以持有期 \[[119](#bib.xhtml#ch00-bib-119)\]。

## 7.1.3 委托权益证明

这也是 PoW 的一种替代方案，因为 PoW 需要大量外部资源。相比之下，委托权益证明 (DPoS) 设计上耗资更少且更环保。DPoS 基于投票系统，质押者投票选出少数几名代表（见证人），由他们负责代表质押者保障网络安全。在这里，矿工被称为见证人，他们有责任成功创建新块。节点的投票权与每个用户持有的加密货币数量成正比。见证人根据声誉选举产生，声誉由每个见证人持有的质押数量决定 \[[130](#bib.xhtml#ch00-bib-130)\]。得票最多的前 *m* 名见证人参与区块链网络的决策。值 *m* 的选择使得至少 50% 的选民认为存在足够的去中心化 \[[17](#bib.xhtml#ch00-bib-17)\]。验证块时，见证人会获得一些收益。当选的见证人逐个验证块。如果某个见证人在固定时间内未能验证，则该块将分配给队列中的下一个见证人，并选出新见证人来替换粗心的那个。要发动 51% 攻击，攻击者必须控制 51% 的选定见证人。值得注意的是，质押者在选举见证人时的参与度越高，攻击者发动攻击就越困难。

## 7.1.4 实用拜占庭容错

拜占庭容错被描述为分布式系统在网络中存在发送误导信息的攻击节点的情况下，仍能达成一致的能力。实用拜占庭容错 (PBFT) 是为优化 BFT 以在区块链网络中实现而设计的。实用拜占庭容错 (PBFT) \[[59](#bib.xhtml#ch00-bib-59)\] 是为异步环境中的拜占庭将军问题 \[[129](#bib.xhtml#ch00-bib-129)\] 而设计的。它基于这样的假设：网络中恶意节点少于总节点的 30%。换句话说，至少需要 3*f* + 1 个节点工作，其中 *f* 是故障副本的数量。基于 PBFT 的区块链最多可容忍 33% 的恶意节点。PBFT 的过程包含 3 个阶段，包括。

*   Pre-prepare：对于每个请求，领导节点广播 pre-prepare 消息，以请求网络中其他节点希望提交的值。

*   Prepare：节点广播 prepare 消息，指定它们即将提交的值。

*   Commit：如果前一阶段有 2*f* + 1 个节点同意，领导节点确认请求。

然而，在 PBFT 中，如果有事先的参与者列表，可以实现低交易延迟和低网络通信开销的共识。此外，可扩展性有限使其不适合 IoT 应用 \[[107](#bib.xhtml#ch00-bib-107)\]。

## 7.1.5 权威证明

权威证明 (PoA) \[[18](#bib.xhtml#ch00-bib-18)\] 是 PoS 模型的一种优化变体，其中网络上的权威方质押其身份以公平运行网络。Parity \[[19](#bib.xhtml#ch00-bib-19)\] 和 Geth \[[20](#bib.xhtml#ch00-bib-20)\] 已实现 PoA。PoA 假设权威方是诚实且可信的。通过质押身份，验证者不希望与负面声誉关联。与任命单一权威方不同，使用一组权威方就网络状态达成一致，最终决定必须由权威方验证。创建块时，权威方依赖于挖矿轮换方法 \[[36](#bib.xhtml#ch00-bib-36)\]。它基于这样的假设：在 *N* 个权威方中，至少 $\frac{N}{2} + 1$ 应该是可信节点。PoA 算法设计用于许可和无许可网络。然而，\[[68](#bib.xhtml#ch00-bib-68)\] 的作者证明 PoA 不适用于许可区块链，因为它面临一致性问题。与 PBFT 不同，PoA 在网络中涉及较少的消息交换，从而提高了性能。然而，使用中心化权威限制了 PoA 在某些应用中的使用。

## 7.1.6 容量证明

与 PoW 不同，在容量证明 (PoC) 中，添加新块需要专用存储，而不是使用 CPU 和 GPU 进行计算 \[[75](#bib.xhtml#ch00-bib-75)\]。采用这种共识，可以节省大量能源。PoC 也被称为压缩的工作量证明，因为所有计算都由验证者在挖矿开始前一次性预先执行，而这项工作的结果（图文件）被缓存在硬盘上。绘图过程使用 shabal 哈希机制创建 nonce 值。挖矿过程只需读取图文件。如果存储介质包含最近生成的块谜题的快速解决方案，则验证者的账户将获得激励。然而，硬盘的大小决定了创建唯一图文件所需的时间。与 PoS 不同，网络上的每个人都有公平的挖矿机会，因为存储介质以更低的价格轻松获得。
