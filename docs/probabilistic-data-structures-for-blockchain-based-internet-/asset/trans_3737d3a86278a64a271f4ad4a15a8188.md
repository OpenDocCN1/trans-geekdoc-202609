# Overview of Internet of Things

## 1.1 Understanding the Concept of Internet of Things

电子和通信技术的快速发展推动了社会的进步。数字化始于大型机计算的引入，该技术使用大型计算机连接人们。接下来是微型计算机时代，使每个人都能负担得起自己的计算设备。第一个名为高级研究计划署网络 (ARPANET) 的互联网出现在 20 世纪 60 年代末，当时连接了四所大学的计算机系统。后来，TCP/IP 协议套件的开发扩大了网络规模。然而，在 20 世纪 90 年代，计算框架变得更加个人化，直到万维网 (WWW) 的出现。1991 年，世界上第一个网站上线。互联网早期仅因 WWW（一个互连的 HTML 文档网络）而流行。这种网络最初仅用于军事和科学目的。接下来，这种静态 HTML 页面框架升级为 Web 2.0，涉及用户参与和交互（社交网络网站、博客、电子商务等）。从那以后，连接互联网的设备数量呈指数级增长。目前，我们所处的网络时代是 Web 3.0（也称为更智能的网络），它正在超越并迈向物联网。[Fig. 1.1](#02chap_01.xhtml#fig1_1) 展示了计算技术的演变。
