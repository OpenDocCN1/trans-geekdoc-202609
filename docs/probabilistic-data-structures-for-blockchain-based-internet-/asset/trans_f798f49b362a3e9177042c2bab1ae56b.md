

过去几年中，数据的产生呈指数级增长。这种巨大的数据增长对工业界和学术界在存储和查询处理方面构成了挑战。在分析大规模数据集的日志时，需要执行不同的查询操作，例如计算唯一项目、计算数据项的频率、在集合中搜索任意项目等。此外，我们还需要探测更复杂的数据集，例如图像、视频、网页等。显然，为了处理数据上的此类查询操作，将数据存储在计算机内存中是必不可少的。磁带、硬盘、固态硬盘是计算系统可用的不同类型的内存。然而，这些不同类型的内存具有不同的特性，如 [Fig. 9.1](#12chap_09.xhtml#fig9_1) 所示。例如，硬盘是机械设备，与集成在半导体芯片上的主内存相比，访问速度较慢，这使得从硬盘数据库查询变得耗时。因此，对于一个查询，处理器每次都要访问硬盘以获取所需的数据，这显然是一个缓慢的操作。此外，与主内存相比，磁盘访问成本较高（这就是为什么 1 GB 主内存比 1 GB 硬盘贵得多的原因）。

此外，进程需要在主内存中才能执行，因此它需要从二级内存交换到主内存，如 [Fig. 9.2](#12chap_09.xhtml#fig9_2) 所示。同时，对于开发者来说，主内存易于使用，因为在主内存中创建数组、链表或集合比使用 Hadoop 数据库或 Apache Solr 在二级存储中写入或读取文件要容易。这些新兴的大数据技术常用于提供准确的分析和决策。这些技术提供分布式数据存储和并行处理。尽管带有重型处理引擎（Spark、MapReduce）的分布式数据库 Hadoop 适用于批处理框架，其目标是提高作业吞吐量，而不是处理访问速度问题。值得注意的是，数据的批处理不施加任何时间约束，因此可以将其存储在磁盘上，并批量处理查询。此外，在二级存储的数据库上使用 SQL 处理查询的流行方法会导致高空间复杂度。例如，Powerdrill 是一种面向列的数据存储方法，在处理大型数据集时面临高内存和计算开销的挑战。然而，流数据需要实时处理且延迟极小，这可以通过提高访问速度来实现。此外，流数据需要单次处理。因此，对于流数据的实时处理以及单次处理数据，始终更倾向于在主内存中进行更多工作。随后，不断增长的数据库和应用程序数据集的规模要求一种紧凑的数据结构，以便得到妥善管理和处理。

当前的数据生成场景导致了新应用的发布，这些应用需要处理海量数据。传统算法假设数据能装入主内存，在处理如此大量的数据时会失效。在此背景下，流式算法（在消耗有限存储和时间的同时，通过一次或几次遍历处理数据）在研究人员中越来越受欢迎。

不幸的是，为了解决上述问题，确定性数据结构（如哈希表、数组、二叉搜索树）无法处理大型数据集，因为很难一次性将大量流式数据加载到内存中。传统数据结构无法超越线性处理。此外，对于大型数据集，确定性数据结构提供的多项式运行时间复杂度并不有利。另外，数据的 3V（容量、多样性、速度）要求实时分析和处理。此外，数据的复杂性和数据中的噪声未定义。由于数据大小事先未知，无法预测存储数据所需的内存要求。因此，需要一种有效的数据结构，能够在主内存中支持快速响应时间和高效的存储空间。为了应对这些挑战，概率数据结构（PDS）最近被许多研究人员和程序员使用。

PDS 允许直接在主内存中对数据执行基本查询操作。PDS 的用例是处理无法装入主内存的大数据。PDS 用于查询操作，例如成员检查、频率检查、相似性检查和基数检查。低内存需求和良好的处理速度是 PDS 的两个独特属性。尽管如此，PDS 的工作高度依赖于加密哈希函数，这些函数在插入数据时实现随机性和灵活性。当哈希函数应用于大型数据集时，它将数据以紧凑形式汇总，从而大幅减少存储需求，且其行为难以预测。在此，加密哈希函数还必须满足三个主要要求：

*   工作因子：为了防御暴力破解，哈希函数应在计算上代价高昂。

*   粘性状态：不可能创建具有合理输入模式的状态。

*   扩散：哈希函数的相关输出位应是每个输入位的复杂函数。

加密哈希函数进一步分类为带键哈希函数和不带键哈希函数。带键哈希函数涉及一个密钥，而对于不带键哈希函数，密钥对所有人都已知。带键哈希函数用于消息认证码（MAC）。

值得注意的是，PDS 基于不带键哈希函数。基于这一洞察，由于随机选择的哈希函数，这种数据结构的性质是随机的。此外，在大多数情况下，不需要知道集合中哪个项目被匹配，有时只需要知道是否发生匹配即可。因此，可以只存储项目的签名而不是值。此外，PDS 对于同一系列操作每次都不会产生相同的结构。因此，PDS 也被称为草图数据结构 \[[116](#bib.xhtml#ch00-bib-116)\]。值得注意的是，PDS 预期会带来特定结构的不准确性。然而，它们具有恒定的查询处理时间，并且可以轻松并行化（因为哈希具有独立性），以用于实时数据处理以实现快速响应。接下来的章节将详细讨论成员查询、基数估计、相似性搜索和频率估计 PDS，以及它们的 Python 实现。请参阅 [Fig. 9.3](#12chap_09.xhtml#fig9_3) 了解 PDS 的分类。
