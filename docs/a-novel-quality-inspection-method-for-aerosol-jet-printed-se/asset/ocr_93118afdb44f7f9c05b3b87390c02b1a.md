A VarioCAM HD Head 600 thermographic camera from InfraTec was used as the thermographic camera to capture the thermal data during the heating process caused by the current passing through the sensor. The current passing through the printed sensor can generate heat, as governed by the following equation:

```
P = I²R
```

where P, I and R are the power generated in the printed sensor, the current passing through the printed sensor and the localized resistance of the sensor, respectively.

With increased power, additional thermal energy is produced, and the temperature rises. The defective areas that demonstrate increased resistance will be heated up more quickly than the normal lines. Therefore, it can be observed by infrared thermographic imaging. Fig. 1(c) depicts the proposed thermographic pictures recorded by the infrared camera, which display potential defective spots and lines. To further evaluate the quality of the printed sensor, it was then put under a confocal microscope to examine the morphology of the printed lines. Key quality indicators can be retrieved from the microscope pictures, such as line width, height, and cross-sectional area. It was then connected to the temperature value at relevant regions from the thermographic images using machine learning (ML).

Meanwhile, the confocal microscope is used to inspect the real quality of the printed lines. The thermographic images are sent to a supervised machine learning model to predict the defective spot's locations, which is later confirmed by the microscope quality

inspection results. Predicted defective locations will be send back to the AJP machine for defect correction as shown in Fig. 1(d). The whole process continues until the part is finished.

In this research, a support vector machine (SVM) algorithm is used to differentiate defective thermal image to non-defective images, as shown in Fig. 3. The SVM algorithm is a supervised machine learning algorithm that can be used for classification and regression tasks. The main idea behind SVM is to find the best boundary, called a hyperplane, that separates the different classes in the feature space. To achieve this, SVM maps the input data into a higher dimensional space, called the kernel space, where a linear boundary can be found. The mapping is done using a mathematical function called a kernel, which can be linear, polynomial, or radial basis functions (RBF).
