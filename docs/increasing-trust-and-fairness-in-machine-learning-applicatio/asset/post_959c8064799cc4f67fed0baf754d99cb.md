## 4.2. What (If?) tool

The What (If?) tool is an interactive library that allows the scientist to visualise the results of their model, to slice, aggregate and observe on different groups. data scientist can use this library to practise the distribution of features in the dataset and also is possible to view predictions. By using this library the MLXI system freed. Firstly data scientist can use it to visualise the performance of their model, and observe whether it is behaving as expected, also for detecting bias. Secondly it is of great use when investigating specific cases, for example when client questions the model decision.

## 4.1. Survey of MLXI

MLXI implements SHAP and Anchor, two approaches to improve local interpretability for mortgage reviews with estimated risk for mortgage applications on a daily basis. A set of 22 rules was used to generate an explanation for a given case and model prediction. In order to evaluate the effectiveness of MLXI, reviewers were presented with short explanations of the model predictions that they achieved using MLXI. After presenting the survey, we conducted a quick interview to provide them with feedback that they could not get in the survey. Below, we list the most common feedback from these sessions.

## Insights

Reviewers reported that the insight into the decisions process of the model increased the trust in the model.

## Clarity (Explanation satisfaction)

Several reviewers indicated that some of the factors presented a ratio (e.g., the ratio between the house price and renovation costs) that they did not know what these features meant exactly. This could be addressed by rewarding the explanation in context with reviewers, and to include more than the text.

## Misinformation (Explanation satisfaction)

Some features might mislead the organisation. reviewers reported that they did not know how to handle the 'unknown' indicators. Some misinformation can be a good fraud indicator, however 'unknown' indicators are indicators that have no value. Providing data to the model is not helpful, if there is no context for the case.

Out of eleven reviewers were positive about the additional information provided by the explanations generated by MLXI. While stressing the importance of independent assessment MLXI provided them with much better guidance as to how to use the current explanation method, improving the quality of their assessment and saving time.
