# 4.2. Demonstration results

Statistical significance. In order to test whether MLX1 improved our user experience, we performed a parametric test to investigate whether the results were statistically significant. According to Norman (Norman, 2010), parametric tests have an advantage in our situation, since we have Likert-type scales and a small sample size. We used a t-test, as suggested by Boone and Boone (2012), for each feature-type statement on the Likert scale. The performance of the questionnaire to measure whether MLX1 positively improved the user experience compared to the current system. We set H0 to be no improvement in the current system due to MLX. Interpreting the Likert scale as an interval scale, we observed m = 3.6 and s = 0.86, leading to a t-value of 2.5839 and a p-value of 0.01367. This indicates that there is a statistically significant improvement in experience when using the explanations generated by MLX.
