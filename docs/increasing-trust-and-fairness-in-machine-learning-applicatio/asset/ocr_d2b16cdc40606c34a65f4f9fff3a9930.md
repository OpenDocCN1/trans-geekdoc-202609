# 4.3.3. Aquitas

Aequitas is the statistical library used in MLX. We have chosen to enrich the dataset with demographic data provided by the Dutch Central Bureau of Statistics (Centra Bureau voor Statistiek, or CBS), which contains information on the ratios of inhabitants of The Netherlands by 100 m. MLX allows the user to select both the feature they want to investigate, as well as the false positive rate (FPR) disparity, which shows that groups within a feature category to compare with the larger group.

The addition of migration backgrounds means we can evaluate whether the tested model is fair with its background, or whether it is unfair to include individuals in applications that might be fraudulent.

Aequitas can be used to test a model for bias with migration backgrounds, as well as to inspect a result of CBS data. This allows data scientists to gain insights into the features of the model they are evaluating for production, fulfilling guidelines 19 and 20 of the Ethical Framework, and providing extra information for the PID.

# 4.2. What (If?) tool

The What (If?) tool is an interactive library that allows the scientist to visualise the results of their model, to slice, aggregate and observe on different groups of features. The data scientist can use this library to practise the distribution of features in the dataset, and also is possible to view features with clusters, or the overall fairness metric. This allows them to adjust the attributes of an individual case and run through the model to see predictions.

By using this library the MLX system is freed. Firstly, the data scientist can use it to visualise the performance of their model, and observe whether it is behaving as expected, also for detecting bias. Secondly it is of great use when investigating specific cases, for example when a client questions the model decision of application (fulfilling guidelines 18 of the Ethical Framework).
