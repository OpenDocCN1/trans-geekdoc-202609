# 5. Conclusions and future work

In this work, we have evaluated the effectiveness of post-hoc, agnostic techniques for enhancing the interpretability of machine learning models. We considered all as global explanation techniques and reported two main findings:

+   1. Techniques that allow for predictions to be transparent and can improve trust, satisfaction, and usability of ML tools with their daily users.
2. Techniques for ML to be globally interpretable and defromary of discriminatory bias enable organisation mitigation.

The results of our research were validated in collaboration with a great financial institution in the Netherlands. A case study using a model for estimating fraud risk for mortgage applications was presented. This model produced daily reports of fraudulent cases, which were enhanced with an explanation to why they were marked as high-risk. The high-risk cases were reviewed, and with a focus on the factors mentioned in the explanation. Prior to this work, the organisation used a simple rule-based system presenting only a subset of possible features. In our work, we replaced this with an automated method of using SHAP and Aquitas to provide detailed explanations containing all possible features and to improve it in the future.

The explainable AI system implementing these local explanations techniques, dubbed MLX1, was used in an in-depth study and short interviews with eleven fraud experts. The survey captured perceptions of changes in transparency, usability, and performance. These three measures allowed for a qualitative measurement of whether MLX1 improved the reviewers ways of working with the existing AI model for mortgage fraud
