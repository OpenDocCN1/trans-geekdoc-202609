### 6.3.1 One-vs-Rest for Multiclass Classification

### 6.3.2 One-vs-One for Multiclass Classification

在一对一分类中，训练一个模型，在每一对类别之间进行二元分类。获得分类次数最多的类别通过投票被选中，并标记为最终预测的输出类别。例如，如果你有四个输出类别 `y1`、`y2`、`y3` 和 `y4`，将训练以下二元分类模型：

*   对 `y1` 和 `y2` 进行分类的模型
*   对 `y1` 和 `y3` 进行分类的模型
*   对 `y1` 和 `y4` 进行分类的模型
*   对 `y2` 和 `y3` 进行分类的模型
*   对 `y2` 和 `y4` 进行分类的模型
*   对 `y3` 和 `y4` 进行分类的模型
