## 5.2.1 线性回归

线性回归是一种线性模型，它假设输入和输出之间存在线性关系，并使用平均绝对误差等函数最小化预测输出与实际输出之间的误差成本。

### 为什么使用线性回归算法？

线性回归算法特别有用，因为：

1.  线性回归是一种易于实现且易于解释的算法。
2.  即使对于海量数据集，训练时间也较短。
3.  线性回归系数易于解释。

### 线性回归算法的缺点

线性回归算法的缺点如下：

1.  性能容易受异常值存在的影响。
2.  假设因变量和自变量之间存在线性关系，这可能导致误差增加。

### 使用 Sklearn 实现线性回归

KNN 代表 K-近邻。KNN 是一种惰性学习算法，基于查找不同数据点之间的欧氏距离。

### 为什么使用 KNN 算法？

KNN 算法特别有用，因为：

1.  KNN 算法不假设特征之间存在任何关系。
2.  适用于数据局部化很重要的数据集。
