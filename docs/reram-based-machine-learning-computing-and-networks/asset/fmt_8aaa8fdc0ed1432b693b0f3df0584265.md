
本书首先介绍了现有的存算一体（IMC）架构，例如存内处理（PIM）、近数据处理（NDP）和近数据计算（NDC）架构，范围涵盖从通用可编程多核系统到可重构阵列和定制设计的加速器。书中对各种 IMC 架构进行了全面的分析和比较。此外，随着支持 IMC 的存储器件的出现，作者介绍了 ReRAM，以及用于 ML 操作的器件建模和逻辑电路设计。由于泄漏功耗最小、功耗降低和硬件占用面积更小，ReRAM 已被广泛部署于 IMC 架构中。作者介绍了借助 ReRAM 设计交叉阵列结构，以促进矩阵乘法和卷积运算——这些是 ML 应用中计算密集型操作。更重要的是，他们提出了一种真正的存内逻辑集成架构，无需利用 I/O，从而实现更快的数据访问、更高的吞吐量和低功耗。他们还展示了多种基于 ReRAM 的 IMC 架构，可执行 ML 和数据密集型应用的其他计算，如梯度和 L2 范数的计算。深度学习架构在深度方面快速增长，导致计算复杂度呈指数级增加。作为案例研究，作者讨论了基于 ReRAM 的 IMC 如何帮助加速计算，最终为大规模深度学习网络（如残差网络 `ResNet` 和压缩感知计算）带来更高的吞吐量、高能效和更小的形态因子。

由于单个芯片或系统上的元件数量有限，为了进一步提高数据密集型计算的吞吐量，分布式计算范式已被广泛采用。在本书中，作者介绍了使用 IMC 加速器执行分布式计算的技术。3D 集成技术的出现促进了多芯片垂直堆叠，每个芯片独立运行。作者介绍了一种 3D CMOS-ReRAM 架构，其中 ReRAM 器件通过硅通孔（TSV）与顶层字线和底层位线相连。所有其他 CMOS 逻辑均实现在底层。他们还介绍了一种多层 3D 架构，其中多个 ReRAM 层被设计为数据缓冲区。

本书介绍了用于 ML 和数据密集型计算的硬件设计。研究界已表明，计算映射是一个关键环节，没有它就无法发挥 IMC 或硬件加速器设计的优势。因此，为了使设计完整，作者介绍了将 ML 设计映射到硬件加速器上的策略。他们还提供了基于 ReRAM 的 IMC 架构上针对多数据密集型应用的数据分析映射。单层前馈神经网络（SLFN）的学习和推理过程已被优化并部分映射到无源二值 ReRAM 交叉阵列上。此外，作者还将二值卷积神经网络（BCNN）分别映射到无源阵列和一选择器一 ReRAM（1S1R）阵列上，并采用了不同的映射方案。除了传统的 2D 集成，本书还介绍了如何针对新兴的基于 3D 集成的 IMC 架构高效地执行映射。

本书的编写动机源于 ML 和硬件设计社区观察到的快速进展，以及缺乏一本能同时提供这两个领域洞见和最新进展的书籍，还有 ML 算法在众多应用中的广泛采用，以及工业界对提升 ML 应用性能日益增长的需求。本书可作为计算领域研究者（ML 算法设计者）与硬件设计者之间的桥梁。

第一章介绍了针对数据密集型计算部署 ML 算法的必要性和动机，同时也介绍了 ML 处理面临的挑战和硬件需求。第二章介绍了可支持 IMC 的新兴存储器件以及 IMC 的必要性。此外，还对不同的 IMC 架构进行了全面的比较和分析。这些架构包括使用传统 DRAM 到新兴器件（如 ReRAM 和忆阻器）。第三章介绍了 ReRAM 器件建模，随后是主要用于 ML 应用中矩阵乘法的交叉阵列结构设计。此外，还介绍了 ReRAM 的多比特存储设计以及基于 ReRAM 的其他逻辑功能单元。

第四章提供了 ML 算法、计算复杂度及 ML 算法中涉及的运算类型的基本信息，包括最小二乘法（SVM、ELM）和深度学习（CNN、TNN）。本章将涉及训练量化（二值、三值、八位等）。此外，本章重点关注深度 CNN 和 TNN 的训练机制，因为它们是耗时操作，性能取决于训练效率。

第五章介绍了将 ML 设计映射到硬件加速器的多种策略。展示了基于 ReRAM 交叉阵列的 IMC 架构设计以加速 ML 应用。此外，为了适应深层 DNN 和 CNN，引入了基于 3D 堆叠的 CMOS-ReRAM 架构。本章的重点在于支持高速数据密集型计算的架构方面和电路设计。第六章介绍了针对 ReRAM 映射 ML 应用的技术、主要挑战及改进空间。展示了针对不同架构（如 ReRAM 交叉阵列、传统 2D 和 3D 架构）的不同 ML 算法的映射技术。

书中呈现了不同场景下基于 ReRAM 的 ML 加速案例研究。第七章展示了不同场景下的 `ResNet`，如带量化的 DNN 和基于 ReRAM 的 `ResNet` 加速。除了 `ResNet`，本书在第八章还介绍了用于压缩感知应用的基于 ReRAM 的加速器。针对这部分，介绍了迭代启发式算法和行生成算法等不同场景。所有案例研究章节均提供了大量实验结果和分析，有助于复现实验，并证明了 ReRAM 加速器的高效性及其在未来硬件加速器设计中的重要地位。最后一章总结了 ReRAM 加速器及其对 ML 应用的影响。此外，还展望了利用 ReRAM 器件进一步增强 ML 计算的未来方向。
