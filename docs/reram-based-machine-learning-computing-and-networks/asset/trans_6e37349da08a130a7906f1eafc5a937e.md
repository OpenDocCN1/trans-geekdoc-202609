

# 2.2 神经形态计算用非易失性存储器件

作为存储器，读/写操作对计算至关重要。与传统的状态保持单元不同，ReRAM 可以在交叉阵列中分别进行读出和调制，且具有高功率效率。因为在读/写过程中，例如一晶体管一 ReRAM (`1T1R`) 结构，只有目标单元被选中，而所有其他单元保持空闲。

## 2.2.1 电阻式随机存取存储器

ReRAM 的电阻切换特性最早于 20 世纪 60 年代被研究 [82]。ReRAM 的器件结构是一种三明治状结构，即两个金属电极之间夹着一层绝缘材料。它包括顶电极 (`TE`)、中间的氧化物层和底电极 (`BE`)。通常，ReRAM 是两端器件，具有两种电阻状态：高电阻状态 (`HRS`，或 OFF 状态) 和低电阻状态 (`LRS`，或 ON 状态)。电阻状态通过施加的电位和刺激持续时间来控制。电阻切换机制是由于氧空位的产生和漂移，导致金属氧化物中导电丝的形成/断裂。它在 `SET`/`RESET` 过程中表现出对称行为或李萨如 `I/V` 曲线。非基于电荷的 ReRAM 具有长期可塑性特征，能在一定周期内保持权重（电导）稳定，即使没有循环工作电源。

作为一种两端非易失性器件，ReRAM 交叉阵列在功率效率和切换速度方面具有固有优势。当 ReRAM 交叉阵列通过 `CMOS` 集成大规模制造时，ReRAM 器件在每个交叉点处被两根垂直的电极线夹在中间。因此，纳米级 ReRAM 的矩阵式密集阵列相对容易实现。由于非易失性和两端特性，ReRAM 实现了存内计算 (`IMC`) 且仅需极小的工作电压，基于 ReRAM 交叉阵列的处理单元在能耗、可扩展性和处理速度方面均优于采用传统冯·诺依曼架构的 `CPU` 或 `GPU`。

## 2.2.2 自旋转矩磁阻随机存取存储器

`STT-MRAM` 包含三层形成磁隧道结 (`MTJ`)：用于数据存储的自由层、用于参考的钉扎层，以及用于磁绝缘和数据读取过程的隧道势垒层 [86, 87]。隧道势垒定义了 `ON` 和 `OFF` 状态切换的能垒 (![image](images/ch02_stripin_si17.gif))。自由层的磁场方向决定了存储单元的电阻。当自由层和隧道层的磁矩平行时，`STT-MRAM` 表现为低电阻。`STT-MRAM` 在反平行构型下表现为 `HRS`。通过向自由层引入相反的磁场，`STT-MRAM` 可表现出多个电阻状态 [87]。一个绝缘畴壁被放置在两个相反的磁畴之间，并由 `STT` 现象调节。由于保持时间与 ![image](images/ch02_stripin_si18.gif) 和切换功耗相关，`STT-MRAM` 在所有 `NVM` 中具有最小的功耗，并凭借其充分利用的非易失性实现了高工作速度。

## 2.2.3 相变存储器

在 `PCM` 中，从 `HRS` 到 `LRS` 的转变表现为切换层从非晶态到晶态的相变。在 `RESET` 过程中，晶态相变材料通过电产生的热熔化为非晶相。将相变材料 `SET` 回 `LRS` 只需要较小的电流。

与 `SRAM` 和 `FLASH` 相比，`NVM` 器件在数据存储方面表现出耐久性、功耗和速度上的巨大优势。基于 ReRAM 的混合系统可同时作为存储器和处理器工作，从而消除冗余数据移动。随着点积引擎 [76, 89] 的推动，ReRAM 阵列仅利用欧姆定律和基尔霍夫电流定律，即可在极短时间内解决某些复杂任务，例如矩阵的乘法与求和运算。

`PCM` 具有与 ReRAM 相似的突触可塑性。与其他 `NVM` 器件相比，`PCM` 具有相对较大的电阻切换范围，使其成为每个事件调制尺度为 1% 的突触模拟计算的理想选择。通过使用幅度逐渐增加和持续时间定制的刺激脉冲，据报道 `PCM` 从 `LRS` 到 `HRS` 拥有超过 200 个调节电平 [90]。如 [图 2.1](#Chapter2.html#c02_fig1) 所示，`PCM` 的可塑性或权重更新具有时间依赖性。前/后突触事件的不同到达时间决定了调制方向。类似于神经突触，`PCM` 对一连串连续尖峰表现出累积行为，可按公式 (2.3) 描述：

# 2.3 神经形态计算用 NVM 器件的特性

用于计算的神经形态器件的理想特性包括线性/对称调谐、可扩展性、多电平电阻状态、长保持时间、随机行为和低能耗。

1. **线性/对称调谐**：由于权重更新遵循时间依赖机制，权重载体与刺激脉冲之间的线性和对称关系有助于减少计算操作和功耗。上述大多数 `NVM` 具有相对线性的 `I/V` 电学特性。例如，通过施加一串持续时间变化的脉冲，可以增强 `TaO[x]`/`TiO[2]` ReRAM 的线性度，如 [图 2.2](#Chapter2.html#c02_fig2) 所示。

2. **可扩展性和可堆叠性**：存储器件的向下缩放实现了高密度集成。大多数 `NVM` 器件已成功制造在约 10 nm 尺度水平。为进一步提高集成密度并缩短存储与处理之间的距离，新兴 `NVM` 器件以三维 (`3D`) 堆叠方式实现并嵌入处理器中。
