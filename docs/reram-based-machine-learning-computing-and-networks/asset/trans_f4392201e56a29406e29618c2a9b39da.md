## 第 3 章

**ReRAM 器件背景**

在本章中，我们将首先介绍电阻式随机存取存储器（`ReRAM`）器件的特性。在对 `ReRAM` 进行表征后，我们将介绍 `ReRAM` 的结构设计，随后介绍几种基于 `ReRAM` 的器件应用设计。

### 3.1 ReRAM 器件与 SPICE 模型

在本节中，我们将根据电荷粒子的扩散情况，介绍两类 `ReRAM` 器件：漂移型和扩散型。这些器件的模型及用法在文献 \[24, 133\] 中有介绍，下文将给出充分的细节描述。

#### 3.1.1 漂移型 ReRAM 器件

`ReRAM`（也称为忆阻器）的存在最早由 Leon Chua 于 1976 年预测 \[60\]，但直到近 30 年后，才在 HP 实验室首次被重新发现并用于纳米级器件 \[62\]。忆阻器这一名称源于这样一个事实：其电阻由当前及过去流过它的电流决定，仿佛它能“记住”自己的历史。这种记忆效应具体表现为流过器件电流的时间积分：当电流沿一个方向流过 `ReRAM` 时，其电阻增加；而当电流沿相反方向流动时，电阻减小；类似地，当电流停止流动时，`ReRAM` 保持其之前的电阻，从而保持或记忆（电阻）状态。该器件的两个稳定状态被定义为 `HRS` 和 `LRS`。写操作通过施加大电流实现，从而迅速改变其电阻。读取单元时，施加小电流以检测其电阻，而不显著改变其电阻。Leon Chua 提出的第四基本元件 `ReRAM` 的基础如[图 3.1](#Chapter3.html#c03_fig1)所示。2008 年，HP 实验室演示了首个 `ReRAM` 物理实现：通过沿 `TiO2` 薄膜器件移动掺杂前沿实现了忆阻效应 \[62\]。掺杂前沿两侧的材料具有不同的电阻率，总电阻计算为两个电阻串联的电阻。基于 `TiO2` 的 `ReRAM` 单元结构图如[图 3.2](#Chapter3.html#c03_fig2)所示。此外，HP 实验室在文献 \[61\] 中发布了 `ReRAM` 阵列（`ReRAM` 交叉阵列结构）的扫描电子显微镜（`SEM`）照片，如[图 3.3](#Chapter3.html#c03_fig3)所示。

一个综合的动态 `ReRAM` 模型（考虑了电荷诱导漂移效应、减速效应和强电场效应）如[图 3.4](#Chapter3.html#c03_fig4)(a)所示，包含掺杂区和非掺杂区。引入掺杂比（`w`）这一术语，以数值表示掺杂区长度（`D`）占 `ReRAM` 薄膜总厚度（`L`）的比例。由于掺杂区和非掺杂区的电阻率差异巨大，总电阻随掺杂比变化。例如，当 `w = 1` 时，`ReRAM` 处于 `LRS`，其电阻比 `w = 0` 时 `HRS` 下的电阻小近千倍。

![image](images/PBPC0390-03-f04.jpg)

图 3.4 `ReRAM` 结构及动态模型的非线性效应：(a) 边界处的减速效应；(b) 漂移速度与电场的指数关系

`ReRAM` 器件的工作原理可总结为：电荷诱导的状态（掺杂比 `w`）偏移。如[图 3.4](#Chapter3.html#c03_fig4)(a)所示，`ReRAM` 可视为串联的两个区域：掺杂区和非掺杂区。分隔两区的畴壁可由流过的电荷偏移。当正电荷流向 `ReRAM` 结右侧时，畴壁右移，掺杂比（`w`）增大，电阻相应减小；电荷反向流动时则反之。传统上，该机制可描述为广义电压控制忆阻系统 \[60\]，数学定义如下：

```
v = R(w) * i
dw/dt = f(w, v)
```

其中 `R` 为 `ReRAM` 电阻，`f` 为 `w` 和施加电压 `v` 的显式函数；`dw/dt` 为由 `w` 和外部电压 `v` 决定的归一化漂移速度。注意，互补电流控制忆阻系统可类似定义。`ReRAM` 的漂移速度是施加电流的函数，最初可用以下分段线性形式建模 \[62\]：

```
dw/dt = mu_v * (R_on / L) * i
```

此外，强电场效应代表在强电场条件（`E > E_c`）下漂移速度呈指数级增加 \[134\]。这通常发生在纳米级器件中，如新制造的 20 nm 级 `ReRAM`。如[图 3.4](#Chapter3.html#c03_fig4)(b)所示，该现象可用 `sinh` 函数近似，如文献 \[134\] 所述：

```
dw/dt = mu_v * (R_on / L) * i * sinh(E / E_c)
```

其中 `E` 为施加场强，其余变量定义见[表 3.1](#Chapter3.html#c03_tbl1)。
