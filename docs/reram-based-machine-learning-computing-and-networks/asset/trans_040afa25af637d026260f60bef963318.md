#### 实验设置

在实验中，我们实现了不同的基线以进行性能对比。每个基线的详细信息如下：

**基线 1**：通用处理器 (CPU/GPU)。通用处理器实现基于配备 `![image](images/ch06_si851.gif)` 个 `![image](images/ch06_si852.gif)` GHz 核心和 `![image](images/ch06_si853.gif)` GB 内存的计算机服务器上的优化 C 程序。Nvidia GeForce GTX 970 用作 GPU 性能对比的参考。

**基线 2**：2D CMOS-ASIC。基于提出架构的 2D CMOS-ASIC 实现采用 Verilog 完成，工作频率为 `![image](images/ch06_si854.gif)` GHz，基于 CMOS 65nm 低功耗 PDK。通过 Synopsys DC 编译器 (D-2010.03-SP2) 评估功耗、面积和频率。

**基线 3**：3D CMOS-ASIC。3D CMOS-ASIC 实现与 2D 版本相同，但具有 TSV 通信特性。TSV 面积、功耗和延迟基于模拟器 DESTINY [218] 和细粒度 TSV 模型 CACTI-3DD [242] 进行评估。顶层的缓冲区大小基于 SRAM，设置为 `![image](images/ch06_si855.gif)` MB 以存储张量核。TSV 面积估计为 `![image](images/ch06_si856.gif)`，电容为 `![image](images/ch06_si857.gif)` fF。文献 [238] 中的 TSV 模型被纳入面积和功耗评估；假设层间有 512 个垂直 TSV 以支持通信和并行计算 [239]。

**提出的 3D CMOS-ReRAM**：CMOS 评估设置和 TSV 模型与基线 3 相同。对于 ReRAM 交叉阵列设计评估，根据 [206]，ReRAM 电阻设置为 `![image](images/ch06_si858.gif)` 和 `![image](images/ch06_si859.gif)` 作为导通态和截止态电阻，SET/RESET 电压为 2V，工作频率为 `![image](images/ch06_si860.gif)` MHz。CMOS 和 ReRAM 的集成基于 [64] 进行评估。

为了评估提出的架构，我们应用 CIFAR-10 [233] 和 MNIST [232] 数据集来分析神经网络压缩和架构性能。节能神经网络首先在 MATLAB 上使用张量火车工具箱 [204] 和张量网络 [196] 进行设计。确定网络配置和压缩率后，再使用 C 程序进行全面优化作为基于 CPU 的结果。然后我们应用非均匀量化在映射到 3D CMOS-ReRAM 架构之前执行张量核量化。为了评估模型压缩，我们将我们的方法与基于 SVD 的节点剪枝方法 [243] 和通用神经网络 [53] 进行比较。还评估了能效和加速比。
