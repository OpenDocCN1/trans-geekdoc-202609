
# Tensor-Train-Based Neural Network (TNN)

To make TNN clear, this section starts with a general feedforward neural network and then extends it to the tensor-train-based neural network. For ease of illustration, this section uses a single hidden-layer neural network as an example; the same principle can be applied to multilayer neural networks [199—201].

Generally, the training of a neural network is performed based on data features `X` and labels `Y` with `N` number of training samples, `D` dimensional input features, and `C` classes. During training, one needs to minimize the error function with determined weights: `W_in` (at input layer) and `W_out` (at output layer) for a single hidden-layer neural network [2]:

```
E(W_in, W_out) = ||Y - f(X; W_in, W_out)||^2
```

where `f` is the trained model to perform predictions from input.

This section mainly discusses the inference (testing) process and presents the training process later. The output of each layer is based on matrix multiplication and activation function. For instance, the output of the first layer `H` is mathematically defined as:

```
H = σ(X W_in + b_in)
```

where `X` is the testing data. `W_in` and `b_in` are the input weights and bias, respectively. Then, the neural network output for a single hidden-layer neural network is:

```
Y_pred = H W_out + b_out
```

```
Y_pred(c) = H W_out(:, c) + b_out(c)
```

where `c` represents class index `c ∈ {1, ..., C}`. We approximate the prediction probability for each class by the output of the neural network.

## Tensor-Train-Based Neural Network Inference

For the tensor-train-based neural network, **Figure 4.9** shows the general idea. A 2D weight is folded into a 3D tensor and then decomposed into tensor cores `G_k`. These tensor cores are relatively small matrices due to the small value of rank `R`, leading to a high neural network compression rate. Then, the whole neural network will be trained in the tensor-train data format.

![Figure 4.9 Neural network weight tensorization and represented by tensor-train data format for parameter compression (from W_in to G_k)](images/PBPC0390-04-f09.jpg)

The TNN inference is a direct application of the tensor-train-matrix-by-vector operations [196,197]. We will use `W_in` to discuss the forward pass of the neural network. First, we rearrange `X` to a `d`-dimensional tensor `X_tensor`, whose `k`-th dimension is a vector of length `n_k`. Here, `n_k` and `R_k` are defined as `n_k = n_k` and `R_k = R_k`. Without consideration of the bias `b_in` and activation function, the neural network forward pass `H` in the tensor-train data format is:

```
H = X_tensor ×_1 G_1 ×_2 G_2 ... ×_d G_d
```

where `G_k`, `G_{k+1}`, and `G_{k+2}` is a slice of cores. We use a pair `(k, i_k)` to refer to an index of vector `X_k`, where `i_k ∈ {1, ..., n_k}`. Since the fully connected layer is a special case of convolutional layer with kernel size `1×1`, such tensorized weights can also be applied to other convolutional layers.

This tensor-train-matrix-by-vector multiplication complexity is `O(d R^2 n)` [196], where `R` is the maximum rank of cores `G_k` and `n` is the maximum mode size `n_k` of tensor `X_tensor`. This can be very efficient if the rank `R` is very small compared to general matrix—vector multiplication. It is also favorable for distributed computation on ReRAM devices since each core is small and matrix multiplication is associative.

## 4.4.3 Training TNN

Tensor-train-based neural network was first proposed by [196], but its training complexity significantly increases due to backpropagation (BP) under the tensor-train data format. A layer-wise training provides good performance with a reduced epoch number of backward propagation, leading to a significant training time reduction [200—202]. Moreover, to perform a successful mapping of TNN, recursive training of TNN is required for the trade-off of accuracy and compression rate. Thereby, a fast layer-wise training method is developed in this chapter for TNN.

The training process of TNN is the same as general neural network layer-wise training but with the tensor-train data format. We first discuss the general training process following the training framework from [53] and then extend it to TNN. Given a single hidden layer with randomly generated input weight, the training process is to minimize:

```
E = ||Y - H W_out||^2 + λ ||W_out||^2
```

where `H` is the hidden-layer output matrix generated from the Sigmoid function for activation, and `λ` is a user-defined parameter that biases the training error and output weights [53]. The output weight `W_out` is computed based on the LS problem:

```
W_out = H^† Y
```

where `H^†` is the pseudo-inverse of `H` and `C` is the number of classes. `H ∈ R^{N×L}` and `Y ∈ R^{N×C}`.

To build a multilayer neural network, backward propagation [199] or layer-wise training using the auto-encoder technique [200,201] can be applied. An auto-encoder layer sets the single layer output `H` the same as input `X` and finds an optimal weight to represent itself. By stacking auto-encoder layers on the final decision layer, we can build the multilayer neural network. **Algorithm 4.3** summarizes the layer-wise training with the MALS method.

### Algorithm 4.3: Layer-wise training of neural network with modified LS solver

**Input:** Input set `D = {X, Y}`, `X` is the input data and `Y` is the desired output depending on the layer architecture, activation function `σ`, number of hidden neuron nodes `L`

**Output:** Neural network weight `W` for `K`-layer neural network

1: **for** `k = 1 to K` **do**
2: **if** `k == 1` **then**
3: Factorize `X` and `Y` (e.g., `X = X_tensor` and `Y = Y_tensor`).
4: Randomly generate tensor cores `G_1`, `G_2` and other tensor cores to represent a tensor `W_in`
5: **else**
6: Randomly generate `W_in` following Steps 3, 4
7: Perform tensor-train-matrix-by-vector multiplication based on (Eq. 4.8), which is equivalent to `H = f(X W_in)`
8: Perform activation function which is equivalent to `H = σ(H)`.
9: Compute `W_out` using the MALS `W_out = argmin ||Y - H W_out||^2 + λ ||W_out||^2`.
