

# 基于张量火车的神经网络 (TNN)

为了阐明 TNN，本节从一般的前馈神经网络入手，然后将其扩展到基于张量火车的神经网络。为了便于说明，本节以单隐藏层神经网络为例；相同的原理也可应用于多层神经网络 [199—201]。

通常，神经网络的训练是基于具有 `N` 个训练样本、`D` 维输入特征和 `C` 个类别的数据特征 `X` 和标签 `Y` 进行的。在训练过程中，需要最小化具有确定权重的误差函数：单隐藏层神经网络的 `W_in`（输入层）和 `W_out`（输出层）[2]：

```
E(W_in, W_out) = ||Y - f(X; W_in, W_out)||^2
```

其中 `f` 是用于根据输入执行预测的训练模型。

本节主要讨论推理（测试）过程，稍后介绍训练过程。每一层的输出基于矩阵乘法和激活函数。例如，第一层的输出 `H` 在数学上定义为：

```
H = σ(X W_in + b_in)
```

其中 `X` 是测试数据。`W_in` 和 `b_in` 分别是输入权重和偏置。然后，单隐藏层神经网络的神经网络输出为：

```
Y_pred = H W_out + b_out
```

```
Y_pred(c) = H W_out(:, c) + b_out(c)
```

其中 `c` 表示类别索引 `c ∈ {1, ..., C}`。我们通过神经网络的输出来近似每个类别的预测概率。

## 基于张量火车的神经网络推理

对于基于张量火车的神经网络，**图 4.9** 展示了总体思路。一个二维权重被折叠成一个三维张量，然后分解为张量核 `G_k`。由于秩 `R` 的值较小，这些张量核是相对较小的矩阵，从而实现了较高的神经网络压缩率。然后，整个神经网络将在张量火车数据格式下进行训练。

![图 4.9 神经网络权重张量化并用张量火车数据格式表示以实现参数压缩（从 W_in 到 G_k）](images/PBPC0390-04-f09.jpg)

TNN 推理是张量火车矩阵乘向量运算的直接应用 [196,197]。我们将使用 `W_in` 来讨论神经网络的前向传播。首先，我们将 `X` 重排为一个 `d` 维张量 `X_tensor`，其第 `k` 维是一个长度为 `n_k` 的向量。此处，`n_k` 和 `R_k` 定义为 `n_k = n_k` 和 `R_k = R_k`。不考虑偏置 `b_in` 和激活函数的情况下，张量火车数据格式下的神经网络前向传播 `H` 为：

```
H = X_tensor ×_1 G_1 ×_2 G_2 ... ×_d G_d
```

其中 `G_k`、`G_{k+1}` 和 `G_{k+2}` 是核的切片。我们使用一对 `(k, i_k)` 来指代向量 `X_k` 的一个索引，其中 `i_k ∈ {1, ..., n_k}`。由于全连接层是核大小为 `1×1` 的卷积层的特例，这种张量化的权重也可应用于其他卷积层。

这种张量火车矩阵乘向量乘法的复杂度为 `O(d R^2 n)` [196]，其中 `R` 是核 `G_k` 的最大秩，`n` 是张量 `X_tensor` 的最大模态尺寸 `n_k`。如果秩 `R` 与一般矩阵-向量乘法相比非常小，这将非常高效。由于每个核都很小且矩阵乘法满足结合律，这也有利于在 ReRAM 设备上进行分布式计算。

## 4.4.3 TNN 训练

基于张量火车的神经网络最早由 [196] 提出，但由于张量火车数据格式下的反向传播 (BP)，其训练复杂度显著增加。逐层训练以减少的反向传播轮数提供良好的性能，从而显著减少训练时间 [200—202]。此外，为了成功映射 TNN，需要对 TNN 进行递归训练，以权衡精度和压缩率。因此，本章为 TNN 开发了一种快速逐层训练方法。

TNN 的训练过程与一般神经网络的逐层训练相同，但采用张量火车数据格式。我们首先遵循 [53] 的训练框架讨论一般训练过程，然后将其扩展到 TNN。给定一个具有随机生成的输入权重的单隐藏层，训练过程旨在最小化：

```
E = ||Y - H W_out||^2 + λ ||W_out||^2
```

其中 `H` 是由 Sigmoid 函数激活生成的隐藏层输出矩阵，`λ` 是一个用户定义的参数，用于平衡训练误差和输出权重 [53]。输出权重 `W_out` 基于最小二乘 (LS) 问题计算：

```
W_out = H^† Y
```

其中 `H^†` 是 `H` 的伪逆，`C` 是类别数量。`H ∈ R^{N×L}` 且 `Y ∈ R^{N×C}`。

要构建多层神经网络，可以应用反向传播 [199] 或使用自编码器技术的逐层训练 [200,201]。自编码器层将单层输出 `H` 设置为与输入 `X` 相同，并找到一个最优权重来表示其自身。通过在最终决策层上堆叠自编码器层，我们可以构建多层神经网络。**算法 4.3** 总结了采用改进最小二乘求解器 (MALS) 方法的逐层训练。

### 算法 4.3：采用改进最小二乘求解器的神经网络逐层训练

**输入：** 输入集 `D = {X, Y}`，`X` 为输入数据，`Y` 为根据层架构确定的期望输出，激活函数 `σ`，隐藏神经元节点数 `L`

**输出：** `K` 层神经网络的神经网络权重 `W`

1: **for** `k = 1 to K` **do**
2: **if** `k == 1` **then**
3: 对 `X` 和 `Y` 进行因子分解（例如，`X = X_tensor` 和 `Y = Y_tensor`）。
4: 随机生成张量核 `G_1`、`G_2` 和其他张量核以表示张量 `W_in`
5: **else**
6: 按照步骤 3、4 随机生成 `W_in`
7: 基于（公式 4.8）执行张量火车矩阵乘向量乘法，这等价于 `H = f(X W_in)`
8: 执行激活函数，这等价于 `H = σ(H)`。
9: 使用 MALS 计算 `W_out`：`W_out = argmin ||Y - H W_out||^2 + λ ||W_out||^2`。
