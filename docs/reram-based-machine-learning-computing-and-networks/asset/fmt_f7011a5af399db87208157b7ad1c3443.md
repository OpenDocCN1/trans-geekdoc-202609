### 6.1.4.1 Mapping matrix–vector multiplication on ReRAM-crossbar network

With the introduction of binary-memristor-crossbar network, one can perform matrix–vector multiplication [147]. It has much better nonuniformity under process variation when compared to the multiple-level-valued analog memristor crossbar. As discussed in Section 6.1.2, the key operations in machine learning (feature extraction and convolution) require a large number of matrix–vector multiplication.

As discussed earlier, the key operations (6.13) and (6.14) require a large number of matrix–vector multiplication. For instance, consider `W` as an example for mapping multiplication on crossbar. For every element in `W`, it follows, here, we take the operation of `W * x` as an example for mapping the multiplication on the crossbar. For every element in `W`, it follows

```
y_i = Σ_j W_ij * x_j
```

where `W_ij` and `x_j` are the elements in `W` and `x`, respectively.

For the crossbar structure in [Figure 6.4](#Chapter6.html#c06_fig4), the current through each BL follows

```
I_BL_i = Σ_j G_ij * V_WL_j
```

As a result, we can map `W` and `x` on `G` and `V`, respectively. By measuring the current through BL with binary digitization, one can derive the result `y` in the digital domain. The detailed operation can be referred to the work in [147].

Note that for real numbers, one needs only a few more shifted additions to complete the final process of matrix–vector multiplication with memristor crossbar. [Figure 6.5](#Chapter6.html#c06_fig5) shows that we only need four-shifted addition with 8-bit precision to calculate the final inner product. In addition, Sigmoid function can be implemented in memristor crossbar with LUT.

### 6.1.4.2 Mapping L2-norm calculation on coupled ReRAM oscillator network

In a coupled oscillator network, we use the memristor oscillator cell similar to that in Figure 3.15(a) (Rs replaced with a PMOS). By altering the gate voltage of the PMOS, we can control the oscillatory frequency as in Figure 3.15(d). Referring to previous works [209, 210], the proposed coupled-memristor-oscillator network is shown in Figure 5.8(a). Here, oscillators are directly coupled with memristors. The oscillatory frequency of each oscillator is determined by multiple input voltages. As mentioned in Figure 3.15(d), the voltage-controlled PMOS can be viewed as a voltage-controlled resistor. Figures 5.8(b) and 5.8(c) are the schematic of oscillators with single input and multiple inputs. After directly coupling, one can have an inverter and a feedback resistor with a diode-connected NMOS. These elements guarantee that the current will only pass from the oscillator network to `V_out`. An RC circuit is designed at `V_out` so that we can measure the DC voltage of `V_out`. The output voltage indicates the relative synchronization of the coupled oscillators.

To perform (4.14) on oscillator network, we only need to use two inputs for each oscillator in Figure 5.8(c). To be more specific, one can have a mapping function as follows:

```
V_in_i = α * (W_ij + x_j)
```

where `α` is a scale factor to link the oscillator input voltage, and `W_ij` and `x_j` are the elements in matrices `W` and `x`, respectively.

As mentioned in [209, 210], the coupled oscillator network can work as a degree-of-match (DOM) circuit to calculate L2-norm by fitting `V_out` to `a * V_in^2 + b * V_in + c` polynomial when there are two inputs for each oscillator in Figure 5.8(c). Therefore, the output voltage follows

```
V_out = k * ||W - x||^2 + V_offset
```

where `k` is a fitting parameter, and `V_offset` is the output voltage when `W = x`.

As such, one can use the coupled-memristor-oscillator network to the L2-norm error function in machine learning. The L2-norm result is obtained by curve fitting but not accurate computing. Compared to other implementations, such an oscillator network can complete the operation much faster because the square operation `(W_ij - x_j)^2` can be performed simultaneously by the oscillator circuit. Moreover, the accumulation is also automatically achieved by the coupled network.
