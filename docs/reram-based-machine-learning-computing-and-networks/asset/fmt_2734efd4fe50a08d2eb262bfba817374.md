
Given specific RIP upper bounds, NuMax [289] provides $\Phi$ with different ranks. With RIP constraint of 0.1, the NuMax produces a $\Phi \in \mathbb{R}^{m \times n}$ sampling matrix. Algorithm 8.1 is applied to $\Phi \in \mathbb{R}^{m \times n}$ with total 10,000 repeated local search and the convergence is illustrated in [Figure 8.6](#Chapter8.html#c08_fig6)(a). It can be observed that the relative error reduces dramatically within the first few iterations. The zoomed subfigure shows that local search on average converges within 50 iterations, where convergence is defined as less than 1e-6 error reduction in two consecutive iterations. Generally, the local optimum can be considered found in less than 100 iterations.

The global search is achieved by scattering many initial guesses in the orthogonal matrices space for $\Phi \in \mathbb{R}^{m \times n}$, and comparing the corresponding local optima. The errors under varying number of initial guesses are shown in [Figure 8.6](#Chapter8.html#c08_fig6)(b). ### 8.6.2.2 ECG recovery quality comparison

The ECG signal recovery examples under $m/n = 0.25$ are shown in [Figure 8.7](#Chapter8.html#c08_fig7). For non-data-driven sampling matrices, both the random Bernoulli and Gaussian show similar reconstruction quality. In other words, the increase of bits in random numbers will not improve recovery quality. This is because the increase of bits of random number will not gain any additional information.

![image](images/PBPC0390-08-f07.jpg)

Figure 8.7 The recovery quality comparison among different sampling matrices: (a) examples of recovered ECG signals at $m/n = 0.25$ and (b) RSNR for 1,000 ECG periods

The PRNG-based Bernoulli exhibits the lowest reconstructed signal quality. This is because, as PRNG produces 0/1 sequences with a predetermined pattern, it has self-coherence issue. For example, an 8-bit per cycle PRNG has a period of 256 $m/n = 0.25$, and when filling a sampling matrix by rows with such 0/1 sequences, all rows of the matrix will be identical.

The Reed--Muller code optimizes the sampling matrix by minimizing the correlations among different rows/columns, which helps to improve sampling performance. Being a generic sampling matrix that works with all data types, it cannot exploit the isometric property of ECG signal, which limits its performance in particular applications. Specifically, it only shows 1 dB improvement compared to random Bernoulli sampling.

The data-driven NuMax real-valued sampling exhibits the best recovery quality (highest RSNR) as shown in [Figure 8.7](#Chapter8.html#c08_fig7)(b). The proposed iterative heuristic (IH) algorithm quantizes the real-valued NuMax sampling with slight quality loss. Specifically, at the undersampling ratio $m/n = 0.25$, the IH (lv2) exhibits 8, 9 and 10 dB higher RSNR than that of Reed--Muller, Bernoulli and pseudo-Bernoulli samplings, respectively. Also, Level 3 quantization through (8.15) can preserve more information than Level 2 quantization through (8.13). The RSNR of IH (lv3) shows marginal 0.48 dB higher RSNR than IH (lv2). The IH (lv3) sampling matrix $\Phi \in \{-1, 0, 1\}^{m \times n}$ will incur additional hardware overhead compared to IH (lv2) $\Phi \in \{-1, 1\}^{m \times n}$.

[Figure 8.7](#Chapter8.html#c08_fig7)(a) gives a visual effect of quality of recovered ECG signal segments with different sampling matrices. The data-driven sampling matrices, i.e., NuMax, IH (lv2) and IH (lv3), can recover signals that tightly coincide with original signals.

#### 8.6.3 Row generation algorithm on low-D image patches

For training stage (NuMax), 6,000 patches with size of $8 \times 8$ are randomly picked throughout all images as the data set $\mathcal{X}_{train}$, which leads to around 18 million of pairwise distance vectors in set $\mathcal{D}_{train}$. For testing phase, another 6,000 patches with size of $8 \times 8$ are selected as data set $\mathcal{X}_{test}$ with no overlap with learning data set $\mathcal{X}_{train}$. The image reconstruction is performed on unseen data set $\mathcal{X}_{test}$ by solving (8.1) with 2D discrete cosine transform (DCT) bases.

The genetic algorithm [295] is adopted as the baseline solver for the MINLP in (8.5), which is compared with the proposed algorithm in Algorithm 8.3. Both algorithms are run given same amount of time, i.e., $T = 100r^2$ s where $r$ is the rank of $\Phi$ that indicates the size of the problem.
