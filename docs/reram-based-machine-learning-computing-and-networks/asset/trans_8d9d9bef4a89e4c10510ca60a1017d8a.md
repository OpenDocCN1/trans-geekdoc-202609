## 前言

随着物联网（IoT）和手持设备的出现，数据中心获取的数据量已达到近EB级（exa-scale）。由于延迟和资源利用率低效，通过传统计算技术处理如此大量的数据效率低下。随着机器学习（`ML`）的引入及其在多个应用中的成功，`ML`已被采用于大数据处理。

尽管在通过`ML`进行处理方面取得了进展，但数据在内存和存储单元之间的传输与通信被视为主要瓶颈之一。片内计算（`IMC`）被视为克服传统冯·诺依曼架构挑战的灵丹妙药。为实现高效的`IMC`，引入了`Hadoop`和`MapReduce`等框架。此类框架利用时间局部性来处理如此大量的数据。尽管与传统计算范式相比效率较高，但现有的`IMC`范式在功耗和延迟需求方面仍显不足，尤其是在数据中心和其他云计算平台中采用时。

为应对基于CMOS的`IMC`挑战，学术界和工业界均在研究新兴非易失性存储器（`NVM`）器件。观察到此类基于`NVM`的`IMC`架构因其低功耗、小面积和高密度嵌入式存储优势，能够克服摩尔定律饱和的挑战。介绍并研究了多种源自不同材料的新兴器件，包括电阻式随机存取存储器（`ReRAM`）、相变随机存取存储器（`PCRAM`）、磁阻随机存取存储器（`MRAM`）、铁电随机存取存储器（`FeRAM`）和NOR Flash，以及传统的`DRAM`。在多种新兴`NVM`器件中，`ReRAM`因其多比特存储潜力和与CMOS工艺的兼容性而最具前景。这种探索得到了`HP`和`IBM`等公司的大力支持。因此，我们相信基于`ReRAM`的`IMC`将在未来几年内随物联网产品实现商业化。
