## 6.1.2 基于 BCNN 的无源阵列推理加速

本节详细内容见文献 [222]。如前文所述，ReRAM 交叉阵列可用于执行逻辑运算，特别是基于点积的卷积。此前 CNN 的映射主要基于传统模拟 ReRAM 交叉阵列 [145, 150]。主要局限在于模拟计算中未确定状态可能存在巨大的非均匀模拟电阻，从而导致卷积误差。

此处我们将根据第 4.3.3 节的算法和网络，映射基于位运算的 CNN 推理过程。本节重点介绍所有基于位运算的 CNN 操作（如卷积、批归一化、池化和激活函数）在基于无源阵列的 XIMA 上的映射。
