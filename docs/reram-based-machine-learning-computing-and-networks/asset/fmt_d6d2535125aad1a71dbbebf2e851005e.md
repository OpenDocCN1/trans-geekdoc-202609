
尽管特征有所减少，但将神经网络应用于大量数据时，训练时间极高。为了加快训练过程，需要从两个角度解决挑战。首先，具有最小参数调整的通用增量机器学习架构被视为加快训练阶段的解决方案。所提出的单层前馈网络（SLFN）如[图 4.3](#Chapter4.html#c04_fig3)所示，主要基于增量最小二乘（LS）解。其次，分析每个学习步骤的关键复杂度，并针对硬件友好型算法进行优化，以在最小化硬件操作复杂度的前提下探索并行性，是增强训练过程的另一种解决方案。由于硬件上的计算比软件快得多，在硬件中利用并行性可显著加快训练过程。从输入数据中提取特征是在执行分类和预测操作中的关键过程，随后是学习数据分布。
