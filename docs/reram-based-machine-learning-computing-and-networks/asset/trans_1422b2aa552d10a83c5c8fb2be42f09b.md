
To accommodate multi-bit networks on the ReRAM crossbar, we customized the designs of 4-bit DAC and ADC respectively, as shown in [Fig. 7.5](#Chapter7.html#c07_fig5)(a) and (b). To save area, the DAC is implemented using a resistor-resistor (R2R) structure with a compact Opamp buffer. Compared to traditional resistor dividers, R2R uses uniform resistance values, which is beneficial for achieving better matching. The Opamp buffer adopts a feedforward structure to minimize current consumption and achieve fast settling. Under a voltage bias of approximately `1.2V` and a current bias of `100μA`, the total Opamp current consumption is less than `50μA`, achieving a `100MHz` unity-gain bandwidth. Meanwhile, an ADC scheme similar to [271] is adopted to reduce switching power, which uses an asynchronous SAR to minimize area and energy.

#### 7.3.3 In-Memory Computing Architecture

Based on the developed 4-bit ReRAM crossbar devices and novel DAC/ADC circuits, we propose a CMOS-ReRAM in-memory computing accelerator, as shown in [Fig. 7.6](#Chapter7.html#c07_fig6), where both storage and computation are implemented within the memory cells.

Figure 7.6 In-memory accelerator architecture based on 4-bit ReRAM crossbar for 4-bit quantized ResNet-50

In this architecture, data-logic pairs are laid out in a distributed manner, and data transfer between data blocks, logic blocks, and the external scheduler is maintained by a control bus. Therefore, logic blocks can read data locally and write back to the same data block after logic computation is completed [237]. Consequently, the huge communication burden between the memory and the general-purpose processor is alleviated, as most data transfers are completed within the data-logic pairs. Based on this in-memory computing architecture using the 4-bit CMOS-ReRAM accelerator, we will further introduce the strategy for mapping the proposed 4-bit quantized ResNet-50 onto it.

#### 7.5.1 Experimental Setup

In the experiments, we implemented different baselines for accuracy and performance comparison. The detailed settings for each baseline are as follows:

1.  **Proposed 4-bit CMOS-ReRAM**: We use the ReRAM model from [272] with uniformly separated resistance values ranging from `1 kΩ` to `5 kΩ`, operating at `200MHz`.

3.  **GPU**: The general-purpose GPU implementation is based on a CUDA-enabled graphics card [188] at `1.5GHz`.
4.  **State-of-the-art ReRAM-based architectures**: Two existing ReRAM-based architectures [146, 222].
5.  **Others**: Conventional CNN networks implemented on Field-Programmable Gate Array (FPGA) [273], CMOS-ASIC [230], and Micro-automata processor [274].
