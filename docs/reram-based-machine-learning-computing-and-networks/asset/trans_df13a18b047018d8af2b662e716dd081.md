

## 1.1.2 半导体存储器

正如上一节所见，在处理单元附近拥有存储元件有助于解决大量挑战。存在多种存储器，它们在功能、物理特性以及所提供的优势方面各不相同。我们首先回顾计算机体系结构中使用的存储器，这将为后续章节中描述的架构设计奠定基础。

### 1.1.2.1 存储技术

传统半导体存储器是指计算机体系结构中基于硅的晶体管器件（`CMOS`、`BTJ`、`FINFET` 等）。这些存储器用于临时或永久地存储计算指令以及数据。与硬盘驱动器（`HDD`）和光盘驱动器（`ODD`）等存储介质因机械驱动的限制而具有预定的数据访问顺序不同，半导体存储器具备随机访问的特性。无论数据位置如何，访问任意数据所需的时间几乎相同。

可以进一步将所有半导体存储器分为两类：易失性存储器和 `NVM`。在易失性存储器中，数据以电信号（如电压）的形式存储，且需要不间断的电源供应。一旦电源供应停止，器件关闭，数据随之丢失。目前，最常用的易失性存储器是静态随机存取存储器（`SRAM`）[25–27]和动态随机存取存储器（`DRAM`），其数据由电压电平指示。相反，`NVM`（非易失性存储器）即使在器件关闭时也能保留数据，因为其数据主要由非电学状态保存。例如，可编程只读存储器（`PROM`）中的位由单个存储单元的熔丝是否烧断来表示。[图 1.1](#Chapter1.html#c01_fig1) 简要介绍了易失性 `SRAM`/`DRAM`、传统非易失性存储器（`NVMs`）以及新兴 `NVMs` 的特性。存储元件按大小和访问时间排列（最左侧的元件数量/容量最小，但对处理器的访问速度最快；而向右侧元件数量/容量增大，访问时间也随之变长）。三种主要的存储技术是 `SRAM`、`DRAM` 和闪存，其详细内容将在下文介绍。

#### 静态随机存取存储器

一个典型的 `CMOS-SRAM` 单元由六个晶体管组成，如[图 1.2](#Chapter1.html#c01_fig2)所示。由 `M1` 至 `M4` 组成的触发器保存存储的位。*静态* 一词源于该单元不像动态 RAM 那样需要刷新，且只要供电，数据即可保持的事实。连接有 `WL` 和两条位线（`BLs`）的 `M5` 和 `M6` 用作访问晶体管，以选中目标单元。

![image](images/PBPC0390-01-f02.jpg)

**图 1.2** 待机状态下带有漏电路径的 6T SRAM 单元结构。`BLs` 被预充至高电平，假设 `Q` 处存储的数据为“1”。

`SRAM` 单元有三种操作状态：写入、读取和待机。对于写入操作，需将要写入的值以互补方式同时施加到两条 `BLs`（即 `BL` 和 `BLB`）上。假设我们希望向单元写入“0”，即 `Q` 为“0”且 `QB` 为“1”，则 `BL` 被拉低而 `BLB` 拉高。一旦通过将 `WL` 置“1”导通 `M5` 和 `M6`，`BL` 驱动器将覆盖先前存储的值。为了容易地覆盖自强化触发器中的先前状态，`BL` 驱动器的设计驱动能力需强于触发器中的晶体管。

对于读取操作，在读取周期开始前，两条 `BLs` 均被预充至高电平，字线（`WL`）的导通标志着读取操作的开始。由于 `Q` 和 `QB` 处电压相反，其中一条 `BL` 将被单元拉低，随后 `BL` 感测放大器检测到该 `BL` 的放电。在电压模式感测方案中，`BL` 电压差 `ΔVBL`（`Q` 减 `QB`）的符号决定存储位的值。几十毫伏量级的 `ΔVBL` 足以高效区分哪条 `BL` 正在放电。例如，假设存储位在 `Q` 处为“1”，在 `QB` 处为“0”，一旦 `WL` 有效，`QB` 将向“0”放电；当获得几十毫伏的正 `ΔVBL` 时，基于锁存器的感测放大器将通过正反馈放大该微小电压差，最终输出逻辑“1”作为结果。

当 `WL` 接地，导致两个访问晶体管关闭时，单元处于待机状态。在待机状态下，两个交叉耦合的反相器因正反馈而相互增强，只要供电，数值即可保持。关于 `SRAM` 在待机状态下的一个显著问题是严重的亚阈值漏电。亚阈值漏电是指当栅源电压小于阈值电压时晶体管的漏源电流。亚阈值电流随阈值电压呈指数级变化，这导致在深亚微米工艺节点下产生巨大的亚阈值电流。[图 1.2](#Chapter1.html#c01_fig2) 展示了一个 `SRAM` 单元中的三条漏电路径，假设 `Q` 处存储位为“1”。注意 `BL` 和 `BLB` 始终预充至 `VDD` 以便于未来的读取操作。无论存储值如何，始终会有三个晶体管消耗漏电功耗。

与其他存储技术相比，`SRAM` 能够提供最快的访问速度，但这一优势是以密度和功耗为代价的权衡结果。由于一个 `SRAM` 单元需要六个晶体管的硅面积，`SRAM` 密度非常有限，因此比其他存储技术更昂贵。此外，由于待机状态下的漏电问题，其功耗很大。因此，`SRAM` 最适用于高性能为主要考量且容量要求不大的场景，即处理器的缓存。
