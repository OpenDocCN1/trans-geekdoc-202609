
由于神经网络处理过程需要频繁读取网络权重，因此将内存读取延迟优化配置设置为生成 ReRAM 内存架构。通过采用 3D 实现，仿真结果表明，与 2D 实现相比（如[表 6.16](#Chapter6.html#c06_tbl16)所示），内存读取和写入带宽分别提高了 51.53% 和 6.51%。对于较少的隐藏节点数量，读/写带宽仍有提升，但瓶颈转移到了内存逻辑控制的延迟上。

## 大规模案例研究：ResNet 加速器

### 7.1 简介

残差网络（ResNet）是一种基于卷积神经网络（CNN）的网络，它利用残差连接 [246,247] 采用了层级更深的架构，已成为深度学习的常用网络模型。然而，将 ResNet 高效地实现到具有高吞吐率（TOPs）且低功耗（mW）等高效推理 [248–251] 的终端硬件上，极具挑战性。这要求从机器学习算法和底层硬件两个方面进行彻底的重新审视。

首先从机器学习算法的角度来看，要在终端硬件上实现深度学习，网络需要被简化。例如，ResNet-50 网络包含近 50 个卷积层，这些层主导了网络的复杂度。由于大多数卷积滤波器现在都是小尺寸（3 × 3、5 × 5 等）算子。近期工作 [252] 报告了一种直接截断量化方法。最近，一些方法 [253–255] 证明了使用低位宽权重和激活值进行量化的可行性，从而大幅降低了内存需求和计算复杂度。低位宽梯度 [256] 进一步被推广用于训练 CNN。其他工作在网络训练后执行量化，或在 CNN 上应用直通估计器 [257]。此外，二值神经网络（BNN）被引入 [222,224]，并进一步实现在基于数字电阻式随机存取存储器（ReRAM）的加速器上。虽然其中一些方法在小规模网络模型 [258–260] 上显示出了良好的性能，但尚无方法将训练量化策略应用于大规模网络（如 ResNet-50）的大规模分类任务（如 ImageNet）并保持一定的准确度。

接下来，从硬件和器件的角度来看，传统计算架构需要在存储器和处理器之间进行大量数据迁移。这导致机器学习（尤其是更深的 ResNet）在带宽和能量方面的效率都很低。最近新兴的非易失性存储器（NVM）技术显示出显著降低的待机功耗，以及存内/近存计算的可能性 [225,261–263]。例如，交叉阵列中的 ReRAM 器件 [57,62,264] 可用于存储权重，也可用于执行卷积运算。

针对本案例研究，我们利用 ImageNet [265] 基准开发了一种量化的大规模 ResNet-50 网络，并实现了高准确度。我们进一步表明，量化的 ResNet-50 网络可以在 ReRAM 交叉阵列上实现，并显著提高了吞吐率和能效。本章的发现可概括如下：

1.  我们首次采用了一种带有 `all-integer computations`（全整数计算）的训练量化策略，应用于 `large-scale`（大规模）深层 ResNet，将其量化至如此低的位宽，同时受准确度控制约束。

2.  我们提出了一种互补金属氧化物半导体（CMOS）-ReRAM 加速器的算法-硬件协同设计，并开发了新型数模转换器（DAC）/模数转换器（ADC）电路。

实验结果表明，与基于中央处理器（CPU）的实现相比，所提出的加速器可实现 ![image](images/ch07_si4.gif)加速和六个数量级的能效提升；与基于图形处理器（GPU）的实现相比，可实现 ![image](images/ch07_si5.gif)加速和四个数量级的能效提升；并比基于 CMOS-专用集成电路（ASIC）的实现 ![image](images/ch07_si6.gif)更快和 ![image](images/ch07_si7.gif)更节能。

### 7.2 带量化的深度神经网络

基于 CNN 的网络的传统直接实现将需要不必要的软硬件资源，且并行性较差。[256,266] 中的先前工作建议在训练期间使用带量化约束的神经网络。在本节中，我们提出了一种大规模 ResNet 模型的硬件友好型算法设计，该设计针对卷积、残差块、批量归一化（BN）、最大池化和激活函数具有量化并行性。不同于传统量化方法执行原始的 32 位浮点运算并附加权重/激活量化过程，我们提出了一种仅在训练和推理期间使用量化变量和计算的全整数算术。由于计算复杂度和存储规模的显著压缩，在 ReRAM 交叉阵列上进一步实现量化网络成为可能，这将在第 7.4 节中讨论。

#### 7.2.1 ResNet 基础

深层 ResNet 因其有效性，在许多应用中取得了卓越的性能。不同于传统的基于 CNN 的网络结构，ResNet 利用残差连接，通过训练极深的网络来解决退化问题。
