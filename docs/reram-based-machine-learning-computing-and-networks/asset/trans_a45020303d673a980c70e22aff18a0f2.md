## 6.1.2 BCNN-based Passive Array Inference Acceleration

Details of this section can be found in reference [222]. As mentioned previously, ReRAM crossbars can be used to perform logic operations, particularly dot-product-based convolution. Previous CNN mappings were mainly based on traditional analog ReRAM crossbars [145, 150]. The main limitation lies in the potential for significant non-uniform analog resistance in undefined states during analog computation, leading to convolution errors.

Here, we map the bitwise CNN inference process according to the algorithms and networks in Section 4.3.3. This section focuses on the mapping of all bitwise CNN operations (such as convolution, batch normalization, pooling, and activation functions) onto the passive array-based XIMA.
