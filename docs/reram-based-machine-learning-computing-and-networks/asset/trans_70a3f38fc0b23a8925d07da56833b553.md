

# 硬件评估平台

硬件评估平台实现于一台配备 4.0 GHz 核心和 16.0 GB 内存的计算机服务器上。特征提取分别由通用处理器、基于互补金属氧化物半导体 (CMOS) 的专用集成电路 (ASIC)、基于数字化 ReRAM 交叉阵列的非分布式和分布式存内计算来实现。

对于 ReRAM 交叉阵列设计评估，根据文献 [206]，ReRAM 的电阻分别设定为 1 kΩ 和 1 MΩ 作为导通态和截止态电阻。通用处理器实现基于计算机服务器上的 MATLAB 仿真。基于 CMOS 的特征提取设计采用 Verilog 以分布式架构实现，并使用 CMOS 65-nm 低功耗工艺设计套件 (PDK) 进行综合。通用处理器实现的工作频率为 4.0 GHz，而 CMOS-ASIC 特征提取设计的频率为 1.0 GHz。

对于基于所提 ReRAM 交叉阵列的存内计算，写入电压 $V_{write}$ 设定为 0.8 V，读取电压 $V_{read}$ 设定为 0.1 V，持续时间为 5 ns。此外，基于文献 [207] 的设计，在 ReRAM 交叉阵列上执行模拟计算以作比较。

在硬件实现中，基于加速 XIMA 的存内计算相比基于 CMOS 的 ASIC 实现了更好的能效。非分布式 XIMA（存储器内仅有一个数据和逻辑块）所需的 CMOS 控制总线较少，但与分布式 ReRAM 交叉阵列相比，在单层交叉阵列上具有较大的数据通信开销。尽管分布式模拟 ReRAM 交叉阵列从能量角度可实现最佳效率，但其面积相比数字化对应方案更大。

如 **表 5.1** 所示，模拟方式的 ReRAM 交叉阵列进行一次向量乘法仅消耗 2.1 µW，而所提架构需要 20.15 µW，因为大部分功耗来自计算中的 ReRAM 而非 ADC。然而，ADC 需要更多面积，因此模拟方式的 ReRAM 交叉阵列面积为 8.32 mm²，而所提方案仅为 0.05 mm²，这是由于 ReRAM 交叉阵列的高密度所致。

模拟和数字化 ReRAM 交叉阵列的计算误差在 **图 5.6** 中进行比较，其中 M 和 N 均设为 256。此处计算误差是两种方案的结果变化：带模拟 ReRAM 的 ADC 和带数字 ReRAM 的感测放大器。ReRAM 误率指施加在器件上的写入电压变化。

当 ReRAM 误率小于 0.004 时，模拟和数字化方式的 ReRAM 计算误差均极低。然而，当 ReRAM 误率大于 0.004 时，模拟方式 ReRAM 交叉阵列的计算误差迅速增加，而数字化方式 ReRAM 增加缓慢。然而，当 ReRAM 误率达到 0.01 时，模拟 ReRAM 交叉阵列的计算误率达到 0.25，远高于另一方案的 0.07。因此，与模拟方式 ReRAM 交叉阵列相比，所述架构可降低计算误差。

## 可扩展性研究

在不同 $K$ 值下，基于 CMOS 的 ASIC 与非分布式和分布式 XIMA 的硬件性能比较如 **图 5.5** 所示。从面积消耗角度来看，如 **图 5.5(a)** 所示，分布式 ReRAM 交叉阵列远优于其他实现。随着 $K$ 从 64 增加到 208，其总面积从 0.057 mm² 增加到 0.185 mm²，约为其他两种方法的 1/100。当 $K > 128$ 时，非分布式 ReRAM 交叉阵列成为最差方案。

从延迟角度来看，如 **图 5.5(b)** 所示，非分布式 ReRAM 交叉阵列最差，因为它只有一条控制总线，在计算准备上花费过多时间。非分布式 ReRAM 交叉阵列的延迟急剧增长，而分布式 ReRAM 交叉阵列和基于 CMOS 的 ASIC 实现由于并行设计，分别维持在约 21 ns 和 70 ns 左右。

对于能效，如 **图 5.5(c)** 所示，非分布式和分布式 ReRAM 交叉阵列均表现更好，因为逻辑加速器大部分时间处于关闭状态。所讨论架构在 **图 5.5(d)** 所示的能量-延迟乘积 (EDP) 中也表现最佳。在不同规格下，分布式 XIMA 在所有实现中表现最佳。EDP 从 0.12 fJ·ns 到 0.45 fJ·ns，比非分布式 ReRAM 交叉阵列好 60%，比基于 CMOS 的 ASIC 好 100%。
