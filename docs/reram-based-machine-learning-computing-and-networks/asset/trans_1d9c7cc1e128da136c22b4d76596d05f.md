
由于近似正交旋转，与 NuMax 方法相比，优化后的布尔嵌入在等距畸变 `![image](images/ch08_si338.gif)` 方面会受到一定惩罚。对于遗传算法，由于其经历的畸变高于所提算法，可以推断算法 8.3 能找到更精确的解。此外，可以观察到当欠采样率 `![image](images/ch08_si339.gif)` 增加时，遗传算法会失效，这是因为所提基于行生成的算法在行数 `![image](images/ch08_si340.gif)` 增加时所需时间呈线性增长，而遗传算法所需时间呈指数增长。而且，遗传算法提供的解是随机的，无法保证其有效性，而所提算法是确定性的。
