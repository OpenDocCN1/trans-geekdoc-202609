### 6.1.5.3 基于无源阵列的 BCNN 推理加速

#### 实验设置

##### 基线

在仿真中，我们使用 MNIST 和 CIFAR-10 基准实现了不同的基线进行比较。每个基线的详情列举如下：

**CPU：** BNN 仿真在配备 `![image](images/ch06_si341.gif)` GHz 核心和 `![image](images/ch06_si342.gif)` GB 内存的计算机服务器上，通过 Matconvnet [227] 运行。BNN 网络参考 [表 6.2](#Chapter6.html#c06_tbl2)。

**数字 ReRAM 设计：** 用于 BNN 的 ReRAM 器件模型基于 [63, 64, 139]，ReRAM 的电阻分别设置为 `![image](images/ch06_si343.gif)` M（导通态）和 `![image](images/ch06_si344.gif)` M（截止态），工作频率为 `![image](images/ch06_si345.gif)` MHz。感测放大器基于 [228] 的设计。BNN 网络同样参考 [表 6.2](#Chapter6.html#c06_tbl2)。

**其他：** 还选择了基于 GPU [188] 的位运算 CNN 实现、基于现场可编程门阵列 (FPGA) [229]、基于 CMOS-ASIC [230] 和基于模拟 ReRAM [146] 的传统 CNN 实现进行性能比较。

##### 网络

位运算 CNN（称为 BNN）的整体网络架构如 [表 6.2](#Chapter6.html#c06_tbl2) 所示。它包含六个二值卷积层、三个最大池化层和三个全连接层。

它接收一张 `![image](images/ch06_si346.gif)` 的 RGB 图像作为第一层的输入。我们使用 `![image](images/ch06_si347.gif)` 组二值滤波器，每组包含三个二值滤波器，分别处理来自 R、G 和 B 通道的数据。每个二值卷积层的宽度和高度固定为 `![image](images/ch06_si348.gif)`，步长为 `![image](images/ch06_si349.gif)`，零填充为 `![image](images/ch06_si350.gif)`。二值卷积层在输入特征图和权重之间执行位运算卷积，随后进行位运算批归一化和二值激活。请注意，全连接层的计算可视为步长为 `![image](images/ch06_si351.gif)`、零填充为 0 的卷积。因此，我们也将全连接层中的矩阵乘法视为卷积处理。

如 [表 6.2](#Chapter6.html#c06_tbl2) 所示，两个级联的卷积层形成一个卷积块，具有等效的 `![image](images/ch06_si352.gif)` 卷积窗口。与直接的 `![image](images/ch06_si353.gif)` 实现相比，这种配置以更少的权重量提供了更强大的表征能力。同时，在卷积后应用二值批归一化以加速和稳定训练。除最后一层全连接层外，我们对每个二值卷积层和全连接层都采用二值激活。最后一层全连接层的输出在不进行二值化的情况下送入 Softmax 层 [231]，以生成十个类别的概率分布。

除了 CIFAR-10，我们还展示了 MNIST 数据集 [232] 上的实验，其详细参数见 [表 6.6](#Chapter6.html#c06_tbl6)，该模型在服务器上预训练而得。与 CIFAR-10 的参数相比，我们在 MNIST 中使用传统的 `![image](images/ch06_si354.gif)` 卷积核。
