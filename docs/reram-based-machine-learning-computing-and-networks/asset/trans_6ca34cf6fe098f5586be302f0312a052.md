

# 3.2.2.2 一晶体管一 ReRAM

在 1T1R 结构中，正如文献 [145] 所示，一个 NMOS 晶体管与每个 ReRAM 器件串联连接。因此，每条字线 (WL) 通过一个晶体管和一个 ReRAM 连接到一条位线 (BL)，如[图 3.14](#Chapter3.html#c03_fig14)(b)所示。NMOS 晶体管用作电压控制选择器，以便我们可以配置每个 ReRAM 单元的连通性。1T1R 的主要优势在于避免了直接连接结构中的偷漏路径。在[图 3.14](#Chapter3.html#c03_fig14)(b)中，我们使用一个信号来控制连接到同一 WL 的晶体管。显而易见，我们只需在目标 `V_WL`、`V_BL` 上施加电压，并仅将 `V_WL` 置高；只有目标单元才能被配置。该结构的指标可总结如下：

*   对 ReRAM 器件非线性要求低，因为电压仅施加在目标单元上。
*   控制器设计比直接连接结构容易得多。

然而，1T1R 结构仍有一个缺点，即交叉阵列面积取决于晶体管，与 ReRAM 器件相比不可缩放。因此，当 ReRAM 交叉阵列尺寸较大时，这不是一个好的选择。

# 3.2.2.3 一选择器一 ReRAM

一种无偷漏路径的数字 ReRAM 交叉阵列如[图 3.14](#Chapter3.html#c03_fig14)(c)所示。在此架构中，每个漂移型 ReRAM 与一个扩散型 ReRAM（作为选择器）串联连接。与前两种实现相比，1S1R 可保持良好的可扩展性，且无需额外控制器即可消除偷漏路径。与文献 [150] 相比，选择器的 `R_OFF` 仅对数字 ReRAM 的操作产生微小影响。由于如[图 3.10](#Chapter3.html#c03_fig10)所示 `R_OFF >> R_ON`，1S1R 的静态电阻几乎等于 `R_ON`。此外，当选择器处于关断状态时，施加电压的大部分分布在选择器器件上。由于每条偷漏路径至少会连接三个 1S1R，因此工作电压 `V_OP` 只需满足以下方程即可消除偷漏路径：

```
V_OP > 3 * V_TH
```

我们将在第 3.7.5 节进一步讨论关于无偷漏路径效应的仿真结果。

# 3.3 基于 ReRAM 的振荡器

文献 [151, 152] 中观察到了 ReRAM 器件中的振荡行为，这是由漂移型 ReRAM 的成形过程实现的。最近的扩散型 ReRAM [137, 138] 显示了作为振荡器的可行性。基于 ReRAM 的振荡器可如[图 3.15](#Chapter3.html#c03_fig15)(a)所示构建。在此基于 ReRAM 的振荡器中，一个物理电阻 `R_S` 与 ReRAM 器件串联。输出电压将取决于 `R_S` 与 ReRAM 电阻 `R_R` 的比例。随着电容 `C` 的充/放电，输出电压 `V_OUT` 将趋近于 `V_DD`。为了使振荡工作，我们对结构中的 ReRAM 器件有以下要求：

*   在相对较高的电压 `V_TH` 下，ReRAM 的电阻 `R_R` 显著降低至 `R_ON`。
*   如果我们将电压降至较低值 `V_H`，`R_R` 将升高至 `R_OFF`。

![Figure 3.15](images/PBPC0390-03-f15.jpg)

**图 3.15** (a) 基于 ReRAM 的振荡器原理图；(b) 振荡器仿真结果；(c) 振荡器 DFT 分析；(d) 不同 `R_S` 值下的振荡频率

因此，如果 [图 3.15](#Chapter3.html#c03_fig15)(a) 中的所有参数都经过良好拟合，我们可以建立振荡，公式如下：

```
f = 1 / (2 * C * R_S * ln(R_OFF / R_ON))
```

其中 `R_ON` 和 `R_OFF` 分别是 ReRAM 器件的低电阻和高电阻。因此，在 (3.12) 所述条件下，`R_ON` 和 `R_OFF` 不能处于静态。当 ReRAM 从 `R_OFF` 转变为 `R_ON` 或反之亦然时，会出现负电阻效应。此外，振荡频率由 `R_S` 的值决定。根据文献 [153] 建立了用于案例研究的振荡器 ReRAM 模型，可在[图 3.15](#Chapter3.html#c03_fig15)(b)中观察到振荡结果。[图 3.15](#Chapter3.html#c03_fig15)(c) 显示了[图 3.15](#Chapter3.html#c03_fig15)(b)的离散傅里叶变换 (DFT) 分析。[图 3.15](#Chapter3.html#c03_fig15)(d) 显示了不同 `R_S` 值下的振荡频率。随着 `R_S` 增大，通过振荡器的电流减小，导致充/放电变慢，从而产生较低的振荡频率。

# 3.4 多位 ReRAM 存储的写入方案

## 3.4.1 ReRAM 数据存储

电气工程师非常熟悉包含三种基本无源电路元件——电阻、电容和电感——的电路。然而，Leon Chua 于 1971 年首次提出了第四种电路元件，描述了电荷 (`q`) 与磁通 (`φ`) 之间的关系 [60]。所谓忆阻器件的电阻取决于通过该器件的总电荷量 [60, 154]。在本章中，我们交替使用 ReRAM 和忆阻器术语。忆阻器的器件特性为许多新的应用领域打开了大门 [155–159]。最重要的应用之一正如预期的那样，是将其用作存储元件。例如，[160–162] 等文献已投入大量精力研究基于忆阻器的存储单元设计。使用忆阻器的主要优势在于，在现代芯片中，存储数据所需的晶体管数量（例如在 SRAM 中）对总晶体管数量有显著且日益增加的影响 [163]。因此，利用忆阻器实现新的存储架构将大幅降低器件总漏电流 [161]。
