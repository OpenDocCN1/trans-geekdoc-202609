

# Hao Yu

**Hao Yu** 是中国南方科技大学（SUSTech）微电子学院的教授。他的主要研究兴趣涵盖节能 IC 芯片设计和毫米波 IC 设计。他是 IEEE 高级会员和 ACM 会员。他撰写了多部著作并拥有 20 项授权专利。他是 IEEE 电路与系统学会杰出讲师，并担任 *Elsevier Integration, the VLSI Journal*、*Elsevier Microelectronics Journal*、*Nature Scientific Reports*、*ACM Transactions on Embedded Computing Systems* 和 *IEEE Transactions on Biomedical Circuits and Systems* 的副编辑。他还是多个 IC 会议的技术程序委员会成员，包括 IEEE CICC、BioCAS、A-SSCC、ACM DAC、DATE 和 ICCAD。他获得了美国 UCLA 电子工程系的博士学位。

## 简介

### 1.1 简介

在过去二十年中，计算范式经历了巨大的转变，商业单位和组织积累了近乎 EB 级（![image](images/ch01_stripin_si1.gif) 字节）的数据量。分析并响应此类海量数据的需求，促使机器学习（ML）方法在从自动驾驶到智能家居等广泛的应用中得到采用。

处理此类海量数据的主要挑战之一，是从内存中获取数据并将其写回，而不会遭遇众所周知的内存墙瓶颈。为解决此类问题，引入了存内计算（IMC）以及 Hadoop 和 MapReduce 等支持框架。这已被证明极具益处，因为这些方法解决了传统计算技术中存在的时间局部性缺乏的挑战。毫无疑问，这些技术提供了帮助，但功耗和处理延迟的挑战仍未解决，尤其是在宏观系统和数据中心中。

基于新兴非易失性器件的存内计算方法在学术界和工业界均备受关注。许多研究人员认为，由于其超低功耗和高密度嵌入式存储特性，这种架构将是打破摩尔定律的契机。包括电阻式随机存取存储器（ReRAM）、相变随机存取存储器（PCRAM）、磁阻随机存取存储器（MRAM）、铁电随机存取存储器（FeRAM）和 NOR Flash 在内的各种器件均已被讨论。由于 ReRAM 具有多电阻电平潜力且兼容 CMOS 技术，它是所有这些器件中最具前景的。IBM 和 HP 等知名公司已投资该领域，我们相信基于 ReRAM 的 IMC 将在未来 2-3 年内随物联网（IoT）产品实现商业化。本章介绍了为数据密集型计算部署 ML 算法的必要性和动机。

#### 1.1.1 内存墙和功耗墙

谷歌和 Facebook 等新型社交媒体的信息技术正在产生前所未有的 EB 级海量数据。例如，沃尔玛每小时处理一百万笔交易，并从中收集 2.5 PB 的信息 [1]；Facebook 用户每天上传 100 TB 的数据和十亿条内容 [2]。深度数据分析可能成为面向数字数据社会的未来经济增长的驱动力。主要挑战源于建立在传统计算机架构和 CMOS 技术之上的现有硬件基础设施。与数据增长相比，摩尔定律的缩放已变得缓慢。尽管有许多最近的大规模研究计划，如 EB 级计算（NSF/DARPA-美国）和人脑计划（欧盟委员会），但它们仍受限于这一奇点，因为存在内存瓶颈。

为了处理并从海量收集的数据中获取洞察，需要能够随数据扩展的并行且可扩展的基于 ML 的解决方案。作为回应，出现了多种可扩展的 ML 算法及并行框架：Hadoop [3]、Spark [4]、Flink [5,6]、Tez [7]、Google Dataflow [8]、0xdata H2O [9] 和 Petuum [10]。毫无疑问，这些框架将处理能力推向了传统方法之外，但执行这些新兴分析解决方案需要大量的计算资源，如电力和合适的处理架构。因此，数据中心开始通过配备更多计算节点来扩展，以满足不断增长的数据量 [11–14] 和 ML 算法复杂性的需求。虽然对基于 ML 的计算资源的需求随着数据规模持续增长，但半导体行业已达到缩放极限，无法再降低新芯片的功耗。基于通用同构处理器的当前服务器设计，在处理此类基于 ML 的数据密集型计算时，在性能/功耗方面不再高效 [15–22]。

在大数据分析期间，数据中心或节点中的计算系统需要通过密集的内存访问来处理存储的数据。内存访问被视为限制当前架构和数据中心性能与吞吐量的关键障碍之一。在包括网络搜索、数据挖掘和 ML 应用在内的新兴应用中，均可见密集的内存访问。微处理器需要通过密集的内存访问来处理存储的数据。然而，最先进的数据存储和处理硬件仍存在带宽墙问题（大量 I/O 拥塞），以及先进 CMOS 技术中大量静态功耗导致的功耗墙问题。因此，迫切需要可扩展、节能的大数据分析硬件设计。以下研究活动 [23,24] 试图缓解未来大数据存储和处理中的内存瓶颈问题：

*   首先，作为面向大数据计算的有前景技术，新兴非易失性 IMC 展现出作为高吞吐率、节能解决方案的巨大潜力。可在存储器内开发专用加速器。在这种情况下，数据在被处理单元读出前可先进行预处理，从而将数据迁移最小化并缓解带宽墙。此外，非易失性存储器（NVM）器件无需电荷即可保持信息，从而可显著降低漏电流，并缓解功耗墙问题。
