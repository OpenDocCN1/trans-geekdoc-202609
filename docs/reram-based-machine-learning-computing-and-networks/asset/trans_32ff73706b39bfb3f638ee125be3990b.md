

## 器件变差下的误差

在前面的讨论中，数字化 ReRAM 交叉阵列比模拟 ReRAM 交叉阵列具有更好的编程精度。[图 6.10](#Chapter6.html#c06_fig10) 展示了在不同写入电压 $V_{write}$ 下单个 ReRAM 器件编程过程的 200 次蒙特卡洛仿真，其中电压幅度服从高斯分布 ($\mu=V_{write}$, $\sigma=0.1V_{write}$)，每一列代表一个 $\Delta V_{write}$ 区域。显然，数字 ReRAM 交叉阵列（仅 $R_{on}$ 和 $R_{off}$）比模拟 ReRAM 交叉阵列能实现更好的一致性。ReRAM 器件变差下的精度对比如 [图 6.11](#Chapter6.html#c06_fig11)(b) 所示。器件变差百分比定义了最大电阻偏移，每个 ReRAM 器件遵循标准差。蒙特卡洛方法用于器件变差的生成。在 CIFAR-10 中，可以观察到当器件变差（ReRAM 电阻值）超过 8% 时，会报告较大的输出电流误差。例如，当器件变差达到 29% 时，数字 ReRAM 仍能达到 87.4% 的准确率，仅比无变差时下降 4%，优于模拟 ReRAM 的 84.8% 准确率（下降 7.6%）。在 MNIST 中，即使器件变差大于 27%，数字 ReRAM 表现也始终优于模拟 ReRAM。

## 近似计算下的误差

对于精度位直接截断的 CNN，我们采用传统方法先训练全精度（$N$ 位）CNN，然后降低网络中所有权重的精度。不同位宽权重的数值实验结果如 [图 6.11](#Chapter6.html#c06_fig11)(b) 所示。此处，逐位 CNN 中的权重为 1 位，其准确率保持不变。在 CIFAR-10 中，虽然直接截断 CNN 的全精度（$N$ 位）准确率可达 92.4%，但位宽对准确率影响很大，尤其是当位宽小于 $N$ 时。例如，当精度降至 $k$ 位时，准确率骤降至仅约 11.8%。在 MNIST 中，当位宽小于 $k$ 位时，直接截断 CNN 的准确率显著下降。结果表明，提出的逐位 CNN 表现远优于直接截断 CNN。

## 可扩展性研究

为实现 BNN 更好的能效，我们进行可扩展性研究，以寻找兼顾良好测试准确率和能效的 BNN 参数。我们以 MNIST 基准上的四层 BNN 为基线（100% 能效，如 [表 6.6](#Chapter6.html#c06_tbl6) 所示），并改变第 2 层（CONV-2，50）的输出特征图数量和第 3 层（FC-1，500）的隐藏节点数量，如 [图 6.12](#Chapter6.html#c06_fig12)(a) 和 (b) 所示。为进行公平比较，我们对每种能效配置进行 20 个周期的训练。当隐藏节点或输出特征图数量减少时，能效虽提高，但会导致更高的测试错误率。综上所述，[图 6.12](#Chapter6.html#c06_fig12)(c) 显示第 2 层的隐藏节点对测试准确率更敏感。因此，增加第 2 层的隐藏节点有利于提高准确率，而减少第 3 层的隐藏节点有利于提高能效。

所有实现方案的总功耗对比如 [表 6.7](#Chapter6.html#c06_tbl7) 所示，在 CIFAR-10 上准确率相近（91.4%）。与基于 CPU 和 GPU 的逐位 CNN 相比，提出的基于数字 ReRAM 的实现功耗最多可降低四个数量级。此外，与基于 FPGA 和 CMOS-ASIC 的传统 CNN 相比，基于数字 ReRAM 的实现功耗分别降低 $10^3\times$ 和 $10^2\times$。

此外，我们在 [图 6.14](#Chapter6.html#c06_fig14) 中分析了提出的数字 ReRAM 设计的详细功耗特性。首先，我们分别分析卷积、批归一化、池化和激活的功耗分布。[图 6.14](#Chapter6.html#c06_fig14)(a) 显示 89.05% 的功耗由卷积消耗，9.17% 用于批归一化，其余仅占 1.78%。其次，我们在 [表 6.2](#Chapter6.html#c06_tbl2) 中分析不同逐位 CNN 层的功耗分布。[图 6.14](#Chapter6.html#c06_fig14)(b) 结果显示 CONV-6 消耗功耗最多，达 25.92%，而 CONV-4 和 CONV-2 也各消耗超过 23% 的总功耗。总体而言，CONV-2 到 CONV-6 层消耗了超过 98% 的功耗。

![image](images/PBPC0390-06-f14.jpg)

**图 6.14** 逐位 CNN 的功耗：(a) 不同操作；(b) 不同层

在吞吐性能方面，我们用 GOPS（每秒十亿次操作）评估所有实现方案。提出的数字 ReRAM 可达 $10^3$ GOPS，比基于 CPU 和 GPU 的实现分别高出 $10^3\times$ 和 $10^2\times$。也比基于 FPGA 和 CMOS-ASIC 的实现分别高出 $10^2\times$ 和 $10\times$。在能效方面，数字 ReRAM 达到 $10^3$ TOPS/W，比基于 CMOS-ASIC 的 CNN 高三个数量级。在面积效率对比中，数字 ReRAM 比 CMOS-ASIC 高 $10^2\times$。数字 ReRAM 在吞吐率和效率两方面均是所有实现方案中最优的。
