
本书阐述了探索基于ReRAM的逻辑运算与NVM存内计算架构的发展思路，以及将各类ML算法映射到此类架构上的具体细节。针对基于ReRAM的IMC实现，目标是开发ReRAM上不同运算的详细映射。我们提出了两种用于运算加速的基于ReRAM的结构：`ReRAM-crossbar`和`ReRAM oscillator network`。特别是，本书总结了以下进展：

*   首先，`NVM-SPICE`用于电路级仿真。介绍了漂移型ReRAM的模型及其仿真结果。此外，还展示了成形、置位（SET）和复位（RESET）过程的测量结果。对于扩散型ReRAM，则采用子电路模型进行仿真。

*   其次，我们引入了一种用于矩阵-向量乘法的二值`ReRAM-crossbar`。由于ReRAM器件的非均匀性，所提出的二值`ReRAM-crossbar`相比传统模拟方式的`ReRAM-crossbar`能实现更精确的计算。此外，还讨论了三种交叉阵列结构，包括无源阵列、一晶体管一ReRAM（`1T1R`）和一选择器一ReRAM（`1S1R`）。

*   第三，我们描述了一种基于ReRAM的耦合振荡器网络，用于L2-范数计算。基于扩散型ReRAM的开-关切换或漂移型ReRAM的成形过程，可以构建一个简单的振荡器。当基本振荡器形成网络时，根据拟合的仿真结果，它可以执行L2-范数计算。

对于存内加速器，目标是确定架构设计。对于仅以ReRAM作为计算引擎的架构，我们详细设计了辅助CMOS逻辑，并定义了处理器与存储器之间的通信协议。对于同时以ReRAM和CMOS作为计算引擎的架构，我们开发了3D CMOS-ReRAM架构，通过引入以下两个主题，可实现更高的吞吐率和并行度：

*   首先，描述了一种分布式存内计算架构（`XIMA`）。除了传统的存储和加载指令外，我们还定义了两条新指令：`start`和`wait`。此外，所有逻辑块和数据块均成对构建，以最大程度减少数据处理通信延迟。指令队列和解码器等CMOS逻辑也已设计完成。

*   其次，展示了3D CMOS-ReRAM架构的设计空间探索。对于单层3D架构，ReRAM器件通过过孔连接顶层字线（WLs）和底层位线（BLs）。所有其他CMOS逻辑均实现于底层。对于多层3D架构，我们分别使用两个ReRAM层作为数据缓冲和逻辑实现。此外，利用`TSVs`连接不同层。

对于基于ReRAM架构的数据分析映射，目标是专注于针对特定应用的加速器详细设计。此外，算法需要经过优化，以便所有运算均可完全映射到加速器上。我们在分布式存内架构（`XIMA`）和3D CMOS-ReRAM架构上，通过多个ML算法的案例研究，展示了带宽和能效的显著提升。

*   首先，针对`XIMA`，我们加速了三种ML算法。单层前馈神经网络（`SLFN`）的学习和推理过程已被优化并部分映射到无源二值`ReRAM-crossbar`上。此外，我们将二值卷积神经网络（`BCNN`）分别映射到无源阵列和`1S1R`阵列上，并采用了不同的映射方案。而且，基于L2-范数梯度的学习和推理也在同时包含交叉阵列和耦合振荡器的ReRAM网络上实现。

*   其次，针对3D CMOS-ReRAM架构，我们也映射了优化后的`SLFN`算法。学习和推理阶段的所有运算均已实现，从而实现在线学习。此外，张量化神经网络（`TNN`）分别映射到单层和多层加速器上，并采用不同的映射方案。

对于映射到`XIMA`和3D CMOS-ReRAM加速器上的每一种ML算法，我们均在器件、架构和系统三个层面评估其性能。所有实现均展现出更高的吞吐率、带宽和并行度，且具有更好的能效。

### 1.3 本书组织

本书涵盖了从器件、架构、学习算法到系统视角的新兴ReRAM全流程内容。具体章节安排如下。第一章介绍了部署ML算法进行数据密集型计算的必要性与动机，同时也介绍了ML处理面临的硬件挑战与需求。第二章介绍了可支持IMC的新兴存储器件，并阐述了IMC的必要性。此外，还对不同的IMC架构进行了全面的比较与分析。这些架构包括从传统DRAM到ReRAM、忆阻器等新兴器件。第三章介绍了ReRAM器件建模，随后阐述了主要用于ML应用中矩阵乘法的交叉阵列结构设计。此外，还介绍了ReRAM的多比特存储设计以及基于ReRAM的其他逻辑功能单元。

第四章提供了ML算法的基本信息、计算复杂度及涉及的运算类型，包括最小二乘法（支持向量机`SVM`、极限学习机`ELM`）和深度学习（`CNN`、`TNN`）。本章将讨论训练量化（二值、三值、八位等）。此外，本章重点关注深度`CNN`和`TNN`的训练机制，因为它们是耗时操作，且性能取决于训练效率。

第五章介绍了将ML设计映射到硬件加速器的多种策略。展示了基于`ReRAM crossbar`的IMC架构设计以加速ML应用。此外，为适应深度神经网络（`DNNs`）和`CNNs`，引入了基于3D堆叠的CMOS-ReRAM架构。本章的主要重点在于架构层面和电路设计，以高速支持数据密集型计算。第六章介绍了将ML应用映射到ReRAM的技术，以及主要挑战和改进空间。阐述了不同ML算法在不同架构（如传统2D和3D架构下的`ReRAM cross`）上的映射技术。

展示了不同场景下基于ReRAM的ML加速案例研究。第七章介绍了不同场景下的`ResNet`，如带量化的`DNN`、基于ReRAM加速的`ResNet`。除`ResNet`外，本书第八章还介绍了基于ReRAM的压缩感知应用加速器。这部分展示了迭代启发式算法和行生成算法等不同场景。所有案例研究章节均包含大量实验结果与分析，有助于复现实验，并证明了ReRAM加速器的高效性及其在未来硬件加速器设计中的显著地位。最后一章总结了ReRAM加速器及其对ML应用的影响。此外，还展望了利用ReRAM器件进一步增强ML计算的未来方向。
