

# 基于ReRAM的逻辑门

## 3.5.1 或门

受文献[170, 171]启发，此处提出了一种逻辑或门。基于ReRAM的逻辑或门由两个正极性忆阻器（FPM）ReRAM组成，每个ReRAM有一个输入，ReRAM的“负”节点连接在一起并在输出端接一个负载。基于ReRAM的或门如[图3.20](#Chapter3.html#c03_fig20)(a)所示。ReRAM充当输入的分压电路，其输出电压由公式(3.20)给出[171]。

**情况 1：输入 "00"**

## 3.5.2 与门

逻辑与门的设计与或门类似，但ReRAM置于反极性忆阻器（RPM）条件下。[图3.20](#Chapter3.html#c03_fig20)(b)展示了利用ReRAM构建的与门。输出电压由公式(3.20)给出。与或门类似，与门的操作在以下三种情况下进行解释。

**情况 1：输入 "00"**

## 3.6 用于逻辑运算的ReRAM

正如引言中所述，将存储元件同时用于存储和处理（逻辑）将有助于减少面积开销并增加片上存储。在本节中，我们提出了这样一种电路，它将同时用于逻辑运算和存储目的。所设计的电路基于第3.5节设计的逻辑电路。作为一个示例，我们在此展示基于ReRAM的或门兼存储器。

[图3.21](#Chapter3.html#c03_fig21)展示了具有两个ReRAM的或门，可用于多用途，即作为用于数据存储的ReRAM，以及作为用于ReRAM中存储数据的或计算元件。ReRAM的输入由信号源![image](images/ch03_si275.gif)和![image](images/ch03_si276.gif)提供。为了执行逻辑运算（本例中为或运算），开关![image](images/ch03_si277.gif)和![image](images/ch03_si278.gif）闭合，电流源断开。或门的输出可在负载电阻![image](images/ch03_si279.gif)两端清晰观察到。负载电阻![image](images/ch03_si280.gif)可替换为另一个基于ReRAM的电路。
