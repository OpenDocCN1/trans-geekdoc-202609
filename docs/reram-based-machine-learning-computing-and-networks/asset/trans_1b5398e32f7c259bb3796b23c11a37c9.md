
虽然单隐层前馈神经网络（SLFN）能够以较小的推理和训练时间达到理想的精度，但尚未被证明能处理复杂的基准测试。例如，文献[183]中的最新研究仅展示了在加州大学欧文分校（UCI）数据集[184]上的高效性能，这距离实际问题仍有很大差距。文献[185]的研究表明，深度学习可用于训练多层神经网络。一个简单的深度学习示意图如[图 4.5](#Chapter4.html#c04_fig5)所示。在该图中，存在连接相邻节点的权重矩阵。当获得神经网络的输出时，可以更新多层神经网络中的所有权重。

深度学习的架构包括各种深度神经网络、深度卷积神经网络（DCNN）、深度置信网络和循环神经网络。在以下章节中，将描述具有二值权重和神经元的 DCNN 的细节。

### 4.3.3 二值卷积神经网络

正如第 4.3.2 节所讨论的，将 CNN 传统直接映射到硬件上，将需要大量且不必要的硬件资源，且并行性较差。文献[188]中的最新工作建议了一种在训练期间使用二值约束的 CNN。本节讨论生成一种具有位级并行性的 CNN 模型，用于卷积、批归一化、池化函数和激活函数。
