
为了适应 ReRAM 交叉阵列上的多位网络，我们分别定制了 4 位 DAC 和 ADC 的设计，如[图 7.5](#Chapter7.html#c07_fig5)(a) 和 (b) 所示。为了节省面积，DAC 采用电阻-电阻（R2R）结构并配合紧凑的 Opamp 缓冲器实现。与传统的电阻分压器相比，R2R 使用统一的电阻值，有利于获得更好的匹配性。Opamp 缓冲器采用前馈结构以最小化电流消耗并实现快速建立。在约 `1.2V` 电压偏置和 `100μA` 电流偏置下，整个 Opamp 的电流消耗小于 `50μA`，并实现了 `100MHz` 的单位增益带宽。同时，采用了类似于文献 [271] 的 ADC 方案以降低开关功耗，该方案使用异步 SAR 来最小化面积和能量。

### 7.5 实验结果

#### 7.5.1 实验设置

在实验中，我们实现了不同的基线用于精度和性能比较。每个基线的详细设置如下：

1.  **提出的 4 位 CMOS-ReRAM**：我们使用文献 [272] 的 ReRAM 模型，在 `1 kΩ` 到 `5 kΩ` 范围内具有均匀分离的电阻值，工作频率为 `200MHz`。
2.  **CPU**：通用处理器实现基于 Matconvnet [227]，运行在配备 `32` 核 `2.4GHz` 和 `128GB` RAM 的计算机服务器上。
3.  **GPU**：通用 GPU 实现基于支持 CUDA 的显卡 [188]，频率为 `1.5GHz`。
4.  **最先进的基于 ReRAM 的架构**：两种现有的基于 ReRAM 的架构 [146, 222]。
5.  **其他**：现场可编程门阵列 (FPGA) [273]、CMOS-ASIC [230] 和微自动机处理器 [274] 实现的传统 CNN 网络。
