位卷积神经网络（bitwise CNN）与直接截断 CNN（direct-truncated CNN，采用低精度位 [191]）之间的关键区别如下所述。直接截断 CNN 是在训练后阶段通过降低数值精度获得的，而此处开发的位卷积神经网络则是在二值约束下训练获得的 [188]。因此，直接截断 CNN 通常会遭受精度损失，但位卷积神经网络却能在最低精度下保留大部分精度。在推理阶段，仅保留二值化权值 `![image](images/ch04_si169.gif)`，从而实现更小的存储开销、更快的推理速度、更高的并行度以及更高的能效。

### 4.4 基于 TNN 的机器学习

前文讨论的神经网络压缩仅通过精度位截断或低秩近似 [192—195] 进行，难以在网络压缩与网络精度之间保持良好的平衡。通过利用高维空间中的自然稀疏性来表示稠密数据，张量化数据格式能够在不造成太大精度损失的情况下，显著压缩神经网络复杂度 [196]。相比之下，本节将探讨训练过程中的张量火车格式神经网络 [197]。首先介绍基于张量火车的分解与压缩。然后，基于通用神经网络的扩展，讨论张量化神经网络（TNN）。最后，进一步提出了一种采用修正交替最小二乘法（MALS）的 TNN 分层训练方法。为便于说明，我们先基于单隐藏层神经网络阐述该思路，随后将其扩展至多层神经网络。同时，还开发了一种基于张量火车的神经网络训练方法，该方法结合 MALS 方法考虑了模型压缩，并提供了复杂度分析。
