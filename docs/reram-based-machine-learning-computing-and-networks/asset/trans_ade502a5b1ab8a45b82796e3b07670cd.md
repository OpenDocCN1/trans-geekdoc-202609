
除了通信指令外，内存地址格式也不同于传统架构。要在所提架构中指定一个字节，地址包含以下标识符段。首先，需要数据-逻辑对索引段，该段由块解码器用于定位目标数据-逻辑对。其次，需要一位标志位来明确目标地址是在数据阵列中还是在存内逻辑交叉阵列中。第三，如果目标是逻辑加速器，则需要额外的段来指定层索引。最后，地址段的其余部分是每个 ReRAM 交叉阵列中的行和列索引。数据阵列和存内逻辑的地址示例如[图 5.11](#Chapter5.html#c05_fig11)所示。
