

# 8.1 简介

在压缩感知中，采样是通过将原始信号向量与线性嵌入矩阵相乘来执行的，这将高维数据向量投影到保留内在信息的低维子空间中。这种简洁的表示被称为低维嵌入。采样矩阵可以是随机的、通用优化的，也可以是针对特定数据集优化的。

随机采样矩阵，如伯努利矩阵或高斯矩阵，虽然更易于构建，但存在两大局限。首先，它们对可恢复性的保证仅是概率性的，因此可能会导致较大的恢复误差。其次，它们的构建独立于所研究的数据，因此无法利用数据集的几何信息。

通用优化采样矩阵，如里德-穆勒码 [287, 288] 或 Puffer 变换 [283]，通过构建互相干度最小化的矩阵，具有确定性的可恢复性。然而，它们仍然独立于感兴趣的数据类型，因此性能无法最大化。

另一方面，数据驱动优化嵌入可以通过额外的学习阶段，利用特定应用中数据集的几何结构，这对于目标数据类型预先确定的生物医学采样硬件尤为有益。由数据驱动优化采样矩阵进行的信号采集能保留更多原始信号的内在信息，从而确保更精确的信号重构和/或更高的压缩比。

大多数现有的数据驱动优化方法仅产生实值嵌入矩阵 [289]。然而，实值采样矩阵的硬件映射比布尔矩阵消耗更多功率。原因在于，对于实值嵌入运算，所需的硬件资源（主要是全加器）与所需精度呈二次方依赖关系，而布尔嵌入映射仅呈线性依赖。因此，布尔采样矩阵更受青睐，因为显著减少的硬件资源有助于提高能效和面积效率。

事实上，随机伯努利矩阵是现有基于 CMOS 实现中为实现低功耗而最广泛使用的采样矩阵 [283, 286, 290]。此外，交叉阵列（或交叉点）结构 [62] 中最近出现的电阻式随机存取存储器（ReRAM）[62, 291] 可为矩阵-向量乘法提供内在结构，从而可能实现线性嵌入的高能效和高面积效率硬件实现。然而，有限的 ReRAM 编程分辨率也倾向于仅将布尔嵌入矩阵映射到 ReRAM 交叉阵列结构中。

因此，采样矩阵的硬件实现面临两难境地。一方面，如果映射数据驱动优化的实值嵌入（如 NuMax [289]）以获得更好的恢复质量，将预期带来巨大的功耗开销。另一方面，如果映射非数据驱动的随机布尔嵌入或布尔里德-穆勒 [287, 288] 嵌入以获得更好的硬件能效，则无法实现高信号恢复精度。这种权衡如图 8.1 所示。图 8.1 还揭示了通过直接截断对 NuMax 进行量化仅在 16 位以上精度下有效，低于该精度将导致显著的性能下降。因此，若无数据驱动优化的布尔嵌入，无法同时实现双方的优势。执行数据驱动布尔嵌入优化的挑战在于，随着大量数据集参与采样矩阵优化，仅有基于实值优化矩阵的凸方法是可行的。

## 8.2 背景

### 8.2.1 压缩感知与等距畸变

近年来，新兴的压缩感知理论使得欠采样信号的恢复成为可能，前提是信号稀疏或在某个基（如小波变换和傅里叶变换）上具有稀疏表示。恢复可通过求解以下问题实现：

```
min ||x||_1 subject to y = Phi * Psi * x
```

其中 `x` 为稀疏系数向量，`Psi` 为原始信号在其上稀疏的基；`Phi` 为感知矩阵，`y` (`y = Phi * s`) 为低维欠采样数据。

为确保成功恢复，感知矩阵 (`Phi`) 必须满足受限等距性质 (RIP)，定义如下：若存在 `delta_s` 使得以下方程对每个向量 `v` 均成立，

```
(1 - delta_s) ||v||_2^2 <= ||Phi * v||_2^2 <= (1 + delta_s) ||v||_2^2
```
