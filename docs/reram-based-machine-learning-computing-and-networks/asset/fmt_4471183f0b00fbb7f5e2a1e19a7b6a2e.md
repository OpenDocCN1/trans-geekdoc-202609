
# ReRAM-Based Logic Gates

Based on the characteristics of the ReRAM, we construct the logic gates using ReRAMs. This section first presents the logic OR gate, followed by AND gates.

## 3.5.1 OR gate

Inspired from [170, 171], a logic OR gate is presented here. The logic OR gate using ReRAMs consists of two forward polarized memristor (FPM) ReRAMs, with one input for each ReRAM and the "minus" nodes of ReRAMs joined together with a load at the output. The ReRAM-based OR gate is shown in [Figure 3.20](#Chapter3.html#c03_fig20)(a). The ReRAMs act as a voltage divider circuit for the input, whose output voltage is given by (3.20) [171].

The operation of the gate is explained using the following three cases.

**Case 1: Input "00"**
When the input on ReRAMs A and B are logic 0, both the ReRAMs will be in HRS due to FPM characteristics (![image](images/ch03_si257.gif)). The output voltage becomes the same as the input, i.e., logic 0.

**Case 2: Input "01"**
When the input at ReRAM A is logic 0 (![image](images/ch03_si258.gif)), ReRAM A will be in HRS, i.e., OFF state (![image](images/ch03_si259.gif)), and the input logic 1 at ReRAM B (![image](images/ch03_si260.gif)) makes the ReRAM switch to ON state, i.e., ![image](images/ch03_si261.gif). **Case 3: Input "11"**

## 3.6 ReRAM for Logic Operations

As mentioned in the Introduction, using a memory element for storing as well as processing (logic) will help in reducing area overhead and increasing on-chip memory. In this section, we propose such a circuit, which will be used for logic as well as for storage purposes. The designed circuit is based on the logic circuits designed in Section 3.5. As an illustrative example, we show the ReRAM-based OR gate-cum-memory here.

[Figure 3.21](#Chapter3.html#c03_fig21) shows the OR gate with two ReRAMs, which can be used for multipurpose, i.e., as a ReRAM for data storage and as an OR computational element for the data stored in ReRAMs. The input for the ReRAMs is provided by the sources ![image](images/ch03_si275.gif) and ![image](images/ch03_si276.gif). To perform the logic operation (OR in this case), switches ![image](images/ch03_si277.gif) and ![image](images/ch03_si278.gif) are closed with the current source disconnected. The output of the OR gate can be clearly observed across the load, resistor ![image](images/ch03_si279.gif). The load resistor ![image](images/ch03_si280.gif) can be replaced with another ReRAM-based circuit.

![image](images/PBPC0390-03-f21.jpg)

**Figure 3.21** Two-input ReRAM OR gate output

To use the ReRAMs for the purpose of storage, switches ![image](images/ch03_si281.gif) and ![image](images/ch03_si282.gif) are left open (disconnected). It needs to be noted that sources (![image](images/ch03_si283.gif), ![image](images/ch03_si284.gif)) must be connected to the ReRAM before performing a read operation. The stored data can be read by disconnecting sources and connecting the current source. To optimize the design, one readout circuit voltage-controlled capacitor can be used to connect to ReRAMs and data can be read in a time-multiplexed manner. It needs to be noted that, for the purpose of illustration, an OR-based circuit is presented, and in a similar manner, other gates can also be realized.

### 3.6.1 Simulation Settings

A wide variety of models are proposed to characterize the ReRAM operation; however, in this chapter, we use the model proposed in [168, 171], which is built based on the physical construction. The threshold-switching type model in [172] is stated to be tolerant to variations [173]. The ![image](images/ch03_si285.gif), ![image](images/ch03_si286.gif), ![image](images/ch03_si287.gif), ![image](images/ch03_si288.gif), and ![image](images/ch03_si289.gif) for the threshold model in [172] are set as 1e6, 0, 100, 390, and 100, respectively. It needs to be noted that ![image](images/ch03_si290.gif) and ![image](images/ch03_si291.gif) denote the values in terms of charge, which is different from the resistance states. For the ideal ReRAM model in [168], the ![image](images/ch03_si292.gif), ![image](images/ch03_si293.gif), and ![image](images/ch03_si294.gif) are set as 100 ![image](images/ch03_si295.gif), 10 k![image](images/ch03_si296.gif), and 5 k![image](images/ch03_si297.gif), respectively. The Opamp used for reading out the ReRAM is LT1012. The simulations are performed in PSPICE and LTSPICE on a CPU running at 2.66 GHz with 8 GB RAM. To demonstrate the working capability of the ReRAM, we considered the pulse widths of 5 and 10 ms. Simulations can also be performed at ns scale, but with the proper tuning of the parameters. Majorly ![image](images/ch03_si298.gif) needs to be tuned, as suggested by Vourkas, who built the threshold-switching ReRAM model.
