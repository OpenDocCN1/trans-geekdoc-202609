
1974年，Dennard预测随着晶体管特征尺寸的缩小，开关功耗将随之降低[68]，这一趋势在2004年前后终止。尽管晶体管尺寸持续缩小，但由于漏电流的增加，晶体管的工作电压和电流降低陷入停滞。工作频率的提高和晶体管密度的增加进一步加剧了计算系统的功耗，产生大量热量并阻碍了能效。功耗的另一个挑战源于传统冯·诺依曼或普林斯顿计算架构中数据处理单元与存储单元之间密集的数据传输，即所谓的“存储墙”。在这种计算范式中，由于数据和指令都存储在同一存储空间，计算单元在某一时刻只能处理一个任务并等待存储器更新其结果，这极大地限制了吞吐量并导致空闲功耗。尽管缓存和分支预测等机制可以部分消除这些问题，但“存储墙”仍然是现代处理器技术中海量数据交换面临的重大挑战。

为突破“存储墙”，存内计算自2000年代起便被研究，并被视为减少存储器与处理单元间冗余数据移动、降低功耗的有前景途径。该概念已通过不同硬件工具实现，例如三维堆叠动态随机存取存储器（DRAM）[69]和嵌入式FLASH[70]。剪枝、量化和混合精度拓扑等软件解决方案被实施以减少信号交换的强度。

生物神经网络（NN）在能效方面优于基于中央处理器（CPU）或图形处理器（GPU）的传统冯·诺依曼计算架构，在执行密集并行计算时，每个突触事件仅消耗1–100 fJ [71,72]。目前，突触阻变随机存取存储器（ReRAM）已成功展现出低功耗（(<pJ)）特性[73]。然而，即使是两款最有前景的全基于CMOS的类脑芯片——英特尔的Loihi和IBM的TrueNorth，在能效方面仍落后于生物神经网络，每个突触事件分别消耗23.6和26 pJ [74,75]。类脑计算通过模拟器件中的突触动力学以及神经网络中的数据流/连接，实现低功耗计算。突触事件由存储器件中的离子通量直接监测并精确调节，已在基于ReRAM的系统中成功仿真[73]。如[图2.1](#Chapter2.html#c02_fig1)所示[77]，与传统冯·诺依曼计算架构相比，类脑计算架构拥有复杂度更低的外围驱动电路和更简单的权重修改过程（例如快速点积运算[76]）。类脑计算还强调对系统级神经架构的模仿，例如人工神经网络（ANN）[78]、卷积神经网络（CNN）[79]、脉冲神经网络（SNN）[75,80]和循环神经网络（RNN）[81]。与通用处理器不同，神经网络是为特定应用场景构建的。例如，CNN具有分离的层和模块化的内核，可实现快速准确的特征识别；RNN的循环输出使其适合语音识别；SNN是一种事件驱动系统，更加灵活且容错性更强。基于专用类脑计算架构的片上系统（SoC）在功耗方面通常比基于传统冯·诺依曼架构的系统低几个数量级。例如，基于异步SNN的英特尔Loihi芯片[75]在能效和面积效率方面均比单个CPU高出三个数量级。

基于冯·诺依曼架构和Si CMOS技术的传统计算机系统，虽然数据处理速度更快、计算精度远高于人脑，但在功耗方面仍显著落后。例如，谷歌开发的有监督深度学习机器AlphaGo，由多达1,202个CPU和176个GPU组成，击败了围棋世界冠军，但其能耗是人脑的1,000倍。类脑计算算法的最新进展，涉及有效解决类似人脑的复杂任务，如模式识别、数据分类和目标检测，使其接近实际应用。然而，基于Si CMOS技术出于并行性和权重自适应原因对这些类脑计算算法的硬件实现，在计算、存储和通信方面带来了巨大挑战，并导致高功耗。在类脑计算系统的硬件实现方面取得突破显得极为迫切。

### 2.2 类脑计算器件

随着当今计算变得越来越数据密集，计算范式正从以计算为中心转向以数据为中心。类脑计算（例如向量矩阵乘法）要求器件具备线性对称调谐、长保持时间、低随机行为（盲更新）和低能量调谐等特性。新兴非易失性存储器（NVM）有望满足这些要求，例如瞬时写/读（~ns）、低工作电压（<1 V）和低功耗（<pJ/突触事件）[82]。此处我们简要描述ReRAM、自旋扭矩转移磁性随机存取存储器（STT-MRAM）和相变存储器（PCM）的工作机制。

广泛使用的静态随机存取存储器（SRAM）和动态随机存取存储器（DRAM）通过电荷存储信息，需要持续的工作电压波来通过给电容充放电以维持或更新其状态。作为新兴NVM的ReRAM是非基于电荷的器件，摆脱了电容存储数据的限制。较小的工作电压（<1 V）足以驱动ReRAM运行，且维持状态无需后续功耗。

当今的深度学习应用需要前所未有的海量数据进行动态数据分析。传统CPU/GPU必须通过编程程序从缓存存储器获取数据，这通常因缺乏有用数据而导致处理器待机。由于数据交换在延迟和功耗方面代价高昂，最直接的优化方法是数据本地化，即最小化处理器与缓存之间的物理距离。ReRAM与CMOS具有良好的兼容性，使其成为三维堆叠的理想选择。三维堆叠ReRAM可安装在处理器顶部，凭借其厚度优势缩短数据传输路径并实现高密度存储。三维堆叠ReRAM存储器可大幅减少数据传输、扩大数据复用，并最终提高能效。与当前主流存储器相比，STT-MRAM在单元尺寸和能效上优于SRAM，ReRAM在功耗、读写速度和耐久性上优于FLASH。在STT-MRAM中，保持时间与工作或开关功耗存在权衡。与其他保持时间超过10年的NVM器件不同，STT-MRAM的保持时间与激励脉冲呈一一对应关系。作为RAM的替代品，STT-MRAM的长保持时间与性能无关，因此可降低保持时间（例如至秒级）以实现更低功耗。
