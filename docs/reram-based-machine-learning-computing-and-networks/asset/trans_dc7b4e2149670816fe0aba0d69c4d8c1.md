

# ReRAM 交叉阵列结构

由于 ReRAM 器件的高密度，可以构建交叉阵列结构作为 ReRAM 阵列 [59, 140–144]。这种交叉阵列结构可用作高密度数据存储的存储器。通过控制字线（WL）和位线（BL）的电压，可以对存储阵列进行读取或写入。例如，我们可以在第 `i` 条 WL 上施加 `V_write`，在第 `j` 条 BL 上施加 `0`，以将数据写入第 `i` 行、第 `j` 列的 ReRAM 单元中。

## 3.2.1 模拟与数字化 ReRAM 交叉阵列

本节将介绍传统的模拟 ReRAM 交叉阵列和数字化 ReRAM 交叉阵列。这两种结构的 I/O 接口和 ReRAM 器件电阻值的数量各不相同。

### 3.2.1.1 传统模拟 ReRAM 交叉阵列

ReRAM 是一种基于两端结器件的新兴非易失性存储器，其电阻可由外部施加电流的积分来控制。交叉阵列的结构天然支持矩阵-向量乘法，其中向量由行输入电压电平表示，矩阵由 ReRAM 电阻网格表示。为了计算矩阵-向量乘法 `y = Wx`。如[图 3.11](#Chapter3.html#c03_fig11)所示，通过将 `W` 配置到 ReRAM 交叉阵列中并将 `x` 设置为交叉阵列输入，模拟计算可直接由 ReRAM 交叉阵列实现，输出为 `y`。

![图 3.11 带有 ADC 和 DAC 的传统模拟式 ReRAM 交叉阵列](images/PBPC0390-03-f11.jpg)

然而，这种模拟 ReRAM 交叉阵列有两个主要缺点。首先，由于较大的 ReRAM 工艺变异，连续值 ReRAM 电阻的编程在实际中极具挑战性。具体而言，ReRAM 电阻由流过器件的电流积分决定，这会导致如[图 3.12](#Chapter3.html#c03_fig12)(a)所示的开关曲线。由于工艺变异，曲线可能会发生偏移，导致中间值非常难以可靠地编程，如[图 3.12](#Chapter3.html#c03_fig12)(b)所示。其次，模数转换器（ADC）和数模转换器（DAC）既耗时又耗电。在我们的仿真中，如[图 3.13](#Chapter3.html#c03_fig13)所示，在 65 nm 工艺下，模数和数模转换可能消耗高达 85.5% 的总运算能量。

![图 3.12 (a) 器件变异下的 ReRAM 开关曲线。(b) 不同 ReRAM 目标电阻的编程不准确性](images/PBPC0390-03-f12.jpg)

![图 3.13 (a) 模拟式 ReRAM 交叉阵列的功耗。(b) 模拟式 ReRAM 交叉阵列的面积消耗](images/PBPC0390-03-f13.jpg)

### 3.2.1.2 数字化 ReRAM 交叉阵列

为克服上述问题，提出了一种用于矩阵-向量乘法的全数字化 ReRAM 交叉阵列。首先，如[图 3.12](#Chapter3.html#c03_fig12)所示，导通态（ON-state）和截止态（OFF-state）比中间值可靠得多，因此只允许 ReRAM 采用二进制值，以减少 ReRAM 编程的不准确性。其次，部署了无需 A/D 转换的纯数字接口。

在 ReRAM 交叉阵列中，我们用 `V_WL[i]` 和 `V_BL[j]` 分别表示第 `i` 条 WL 和第 `j` 条 BL 上的电压。`R_LRS` 和 `R_HRS` 分别表示低电阻态（LRS）和高电阻态（HRS）的电阻。在每个感测放大器（SA）中，都有一个电阻固定且较小的感测电阻 `R_sense`。这三个电阻的关系为 `R_LRS < R_sense < R_HRS`。因此，第 `j` 条 BL 上的电压可表示为

```
V_BL[j] = (Σ_i g_ij * V_WL[i]) / (Σ_i g_ij + 1/R_sense)
```

其中 `g_ij` 是 `R_ij` 的电导。

数字化交叉阵列的关键思想在于使用比较器。由于模拟交叉阵列每列的输出电压是连续值，因此使用比较器根据施加在 SA 上的参考阈值将其数字化：

```
V_BL[j] > V_ref ? 1 : 0
```

然而，模拟电压值数字化带来的问题是信息丢失。为克服此问题，可采用三种技术。首先，使用多阈值以增加量化电平，从而保留更多信息。其次，将乘法运算分解为三个子运算，二进制交叉阵列可很好地处理这些子运算。第三，在数字化后能保留最多信息的区域精心选择阈值。

与传统的模拟 ReRAM 交叉阵列 [145, 146] 相比，数字 ReRAM 交叉阵列的优势如下：

*   它在工艺变异下具有更好的 ReRAM 器件编程精度，且无需额外的 ADC 转换。
*   由于数字 ReRAM 交叉阵列中仅配置 LRS 和 HRS，因此不需要高 HRS/LRS 比，从而可以采用低功耗（高 LRS）器件 [139]。此外，使用低功耗 ReRAM 器件时，线电阻对 IR 压降的影响很小。
*   二进制输入电压在大尺寸交叉阵列中对 IR 压降具有更好的鲁棒性。

然而，在数字 ReRAM 交叉阵列实现中，ReRAM 器件的面积和能耗会增加。这将在[第 3.5 节](#Chapter3.html#c03_sec5)中讨论。

## 3.2.2 ReRAM 交叉阵列的连接方式

ReRAM 交叉阵列有三种连接方式：直接连接 ReRAM、一晶体管一 ReRAM (1T1R) 和 1S1R。下面将详细描述这些方法及其差异。

### 3.2.2.1 直接连接 ReRAM

直接连接 ReRAM，也称为无源 ReRAM 阵列，是一种仅包含 ReRAM 器件的交叉阵列结构。每条 WL 和 BL 通过单个漂移型 ReRAM 相连。直接连接 ReRAM 的结构如[图 3.14](#Chapter3.html#c03_fig14)(a)所示，此处以 `N` 条 WL（`i ∈ [1, N]`）和 `M` 条 BL（`j ∈ [1, M]`）为例。要执行写操作，需要在 `WL[i]` 和 `BL[j]` 之间施加写电压 `V_write`。在这种情况下，连接它们的 ReRAM（`R_ij`）可以被精确配置。

![图 3.14 ReRAM 交叉阵列实现对比：(a) 含偷路的直接连接；(b) 需额外控制信号的 1T1R；(c) 无需额外控制信号的无偷路 1S1R；(d) 模拟与数字接口对比](images/PBPC0390-03-f14.jpg)

然而，这种结构存在偷路问题。在该示例中，紫色路径是我们期望的理想电流路径，但可能存在另一条由绿色标识的路径。该路径由 `R_ik`、`R_lk` 和 `R_lj` 组成，因此我们可以看到 `V_write` 也施加在了这三个 ReRAM 的串联上。在某些情况下，其中两个处于 LRS，一个处于 HRS，导致处于 HRS 的 ReRAM 器件上施加了非常大的电压。在这种情况下，该 ReRAM 的状态也可能被配置，这是我们不希望发生的。
