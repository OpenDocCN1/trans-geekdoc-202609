
# TNN 在 3D 多层 CMOS-ReRAM 加速器上的映射

为了在 3D 多层 CMOS-ReRAM 加速器上完整映射 TNN，CMOS 逻辑主要需要设计用于逻辑控制和同步，采用顶层状态机。它为计算核准备输入数据，监控 ReRAM 逻辑计算的状态，并确定神经网络的计算层。[图 6.22](#Chapter6.html#c06_fig22) 展示了 TNN 在所提议的 3D 多层 CMOS-ReRAM 加速器上的详细映射。这是一种折叠架构，利用神经网络中每一层的顺序操作。测试数据将通过硅通孔 (TSV) 从 ReRAM 存储器中收集，然后送入向量核，通过 ReRAM 层中高度并行的处理单元执行向量-矩阵乘法。ReRAM 层拥有许多分布式的 ReRAM 交叉阵列结构以并行执行乘法。随后，来自 ReRAM 的计算输出将被传输到标量核以执行累加。标量核可执行加法、减法和比较。然后，来自标量核的输出将以流水线方式发送到 Sigmoid 函数模型，用于激活矩阵的计算，该模型执行公式 (4.4) 的计算。激活矩阵将用于下一层的计算。因此，整个 TNN 推理过程可以映射到 3D 多层 CMOS-ReRAM 加速器上。

![图 6.22 CMOS 层上的数据控制与同步，包含高度并行的基于 ReRAM 的处理单元](images/PBPC0390-06-f22.jpg)

此外，为了支持 ReRAM 上的 TNN 计算，需要一个专用的索引查找表 (LUT)。由于权重矩阵实际上如图 4.8 所示被折叠成一个高维张量，因此设计了一个称为双射函数的正确索引选择函数。权重矩阵索引的双射函数也由 CMOS 层执行。基于顶层状态图，它将通过确定索引来选择张量核的正确切片。然后，相应的 ReRAM 交叉阵列区域将被激活以执行向量-矩阵乘法。

## ReRAM 层加速器

在 ReRAM 层中，本节介绍 ReRAM 层加速器的设计，该设计利用单指令多数据流 (SIMD) 方法支持数据并行性，以实现高度并行的计算。

### ReRAM 层上高度并行的 TNN 加速器

TNN 加速器的设计必须支持高度并行的张量火车矩阵-向量乘法，通过利用矩阵乘法的结合律。根据公式 (4.28)，核心张量需要与多个矩阵相乘，这与通用神经网络不同。因此，如果采用传统的串行矩阵-向量乘法，数据需要多次存储在 ReRAM 阵列中，这非常耗时。由于 TNN 中张量核的尺寸远小于通用神经网络中的权重，因此可以在 ReRAM 逻辑层中放置多个矩阵-向量乘法引擎。当输入数据加载时，核心张量的索引即可得知。例如，根据公式 (4.28) 中的求和，需要给定输入计算中间结果。公式 (4.28) 中的核心张量可以在输入数据加载前以并行方式预计算。

如[图 6.23](#Chapter6.html#c06_fig23)所示，张量核 (TC1-6) 存储在 ReRAM 逻辑层中。当输入数据到达时，逻辑层控制器首先加载每个张量核的索引。控制器将张量核中相应的数据写入 ReRAM 单元。因此，核心张量的矩阵-向量乘法可以并行执行以计算中间矩阵，同时最后一个核心正在加载过程中。获得所有中间矩阵后，它们可以与最终核心相乘，从而使 ReRAM 逻辑层中的操作变得高效。

### ReRAM 层上高度并行的点积引擎

我们进一步在 ReRAM 层上开发了数字化的基于 ReRAM 的点积引擎。张量火车矩阵-向量运算可以通过 ReRAM 层上的快速点积引擎高效加速，如[图 6.23](#Chapter6.html#c06_fig23)(b)所示。通过获取核心的正确索引，每个运算可被分解为向量-向量点积运算。此处，我们基于文献 [237] 设计了点积引擎。为便于理解，输出矩阵为 `C`，输入矩阵为 `A` 和 `B`。总体方程为 `C = A * B`，维度分别为 `M x N`、`M x K` 和 `K x N`。`C` 中的每个元素遵循：

`C[i][j] = sum(A[i][k] * B[k][j])`

其中 `A[i][k]` 和 `B[k][j]` 分别是 `A` 和 `B` 中的元素。基本实现思路是将矩阵-向量乘法分解为两个向量 `a` 和 `b` 的多个内积运算。通过采用 `a` 和 `b` 的定点表示，这种乘法可用二进制乘法表示：

`Result = sum(a_bit[m] * b_bit[n] * 2^(m+n))`

其中 `R_accel` 是来自 ReRAM 交叉阵列的加速结果。`a_bit[m]` 是位宽为 `M` 的 `a` 的二进制位，`b_bit[n]` 是位宽为 `N` 的 `b` 的二进制位。如前所述，位宽 `M` 和 `N` 在算法层面优化期间决定。基于公式 (22) 的矩阵-向量乘法可在 ReRAM 层上总结为四个步骤。

**步骤 1：索引双射**：选择正确的张量核心切片 `G_core`，其中一对索引 `(i, j)` 确定来自 `G_core` 的一个切片。在当前示例中，索引 `i_sel` 和 `j_sel` 分别代表从核心 `TC1` 和 `TC2` 中选取的两个切片。

**步骤 2：并行数字化**：需要一个 `N x M` 的 ReRAM 交叉阵列。如[图 6.23](#Chapter6.html#c06_fig23)(c)所示，每个内积由 ReRAM 交叉阵列产生。`a_vec` 设置为交叉阵列输入，`b_mat` 写入 ReRAM 单元。在 `N x M` ReRAM 交叉阵列中，每列 ReRAM 的电阻相同，但各列中的第 `k` 个电阻不同。因此，每列的输出主要取决于阶梯状的阈值电压 `V_th`。如果内积结果为 `IP_res`，则步骤 1 的输出类似于 `Out_vec`，其中包含 `Out_vec[i]` 和 `Out_vec[j]`。
