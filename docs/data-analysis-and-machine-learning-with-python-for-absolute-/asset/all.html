Chapter 1
Introduction to Data Analysis
We will start with a pretty basic understanding of data analysis in this chapter and will further try to expand your knowledge with various real life examples. Remember that data analysis is a skill with less programming prerequisites unlike its predecessors such as machine learning and data science.
What is data analysis?
Data analysis refers to the use of appropriate statistical analysis methods to analyse a large amount of collected data, integrate and refine the valuable information hidden in a large number of seemingly chaotic data, and find out the inner law of the research object.
In general, the initial data collected in the initial stage is relatively rough, and it needs to be processed by certain technical means, and finally the knowledge that is easy for users to understand should be refined.
Generally the rough data at the bottom is processed through a series of processing, and then the relevant information generated by the processing is combined with the actual business methodologies to conduct regular summary and generate knowledge that can be useful for enterprises (solutions or business forecasts). ￼
Practice has proved that data analysis is very valuable, and its applications are closely related to real life. For example, credit card approval limits, e-commerce website product recommendations to consumers, prize settings for game activities, bundled promotions in supermarkets, diagnosis and prediction of patient diseases, etc are all possible due to the data analysis trends.
Data analysis can penetrate into these business links to help realise business processes Optimisation, improve work efficiency, and can assist users to make quick judgments in order to take effective actions. ￼
Operation steps of data analysis
Data analysis has a set of relatively standardised operating steps. As a data analyst, you must master it in order to reduce work errors and improve work efficiency. The operation steps of data analysis are important to understand. ￼
1. Clear purpose
The first step in data analysis is to clarify the purpose of the analysis. Just like everyone dealing with something in life, first determine the goal, and then implement it.
For example, after an e-commerce App was launched, a large number of new users were imported in the early stage, but the user quality may not be very good (including login, payment, etc.), and data analysis was always needed to find out the reasons.
As a data analyst, it is necessary to make it clear that the purpose of this analysis is to find out the reasons why a large number of registered users have a short login time and low payment amount. You can start with the analysis from the attributes of registered users.
2. Data collection
Data is the prerequisite for data analysis.Data collection is particularly important for various reasons. According to different collection methods, data collection can be divided into online collection and offline collection. According to different collection channels, it can be divided into internal collection and external collection.
Data collected online refers to data automatically collected using Internet technology. For example, the company collects data through data burying points, and then stores the collected data in a database. In addition, the use of crawler technology to obtain web data or third-party tools to obtain online data are all online collection methods.
Under normal circumstances, Internet technology companies, Internet e-commerce companies, and Internet game companies use this method to collect user behaviour data because of its high efficiency and low error rate. Famous examples include Facebook,Google and Tiktok. Now a days every Internet gaint is collecting data to further improve their services.
The data collected offline is relatively traditional and does not require high technical requirements. For example, collecting data through traditional market survey questionnaires is a good example of offline collection. In addition, obtaining data through manual entry, authoritative data collected by publications, and obtaining data through electronic forms provided by others are all offline collection methods.
This method of collecting data is inefficient and prone to deviations. In general, traditional manufacturing companies, offline retail companies, and market research and consulting companies use this method to collect data.
The internally collected data refers to the data obtained from the company's internal database, daily financial data, sales business data, customer complaint data, operational activity data, etc. The acquisition of such data is relatively convenient, and data analysts can process and analyse internally collected data according to actual business needs.
Externally collected data means that the data is not generated internally by the enterprise, but obtained from the outside through other means. For example, web page data obtained using crawler technology, authoritative data collected from public publications, data obtained from market research and data provided by third-party platforms, etc all belong to this category.
The collection of external data is not as easy as internal collection, and most of it is fragmented and scattered data. Therefore, data analysts need to clean and integrate these data, and then analyse.
In short, no matter how the data is collected, it is a valuable asset for the enterprise. Data analysts need to deal with these data more, to study the hidden laws behind the data, to provide business decisions stand by.
3. Data processing
Generally, the raw data collected through different channels are relatively rough and disordered. At this instance, it is necessary to use data processing software for a series of processing tasks to reduce the complexity of the original data, and finally summarise it into business indicators that can be interpreted by users.
Data processing includes early dirty data cleaning, missing value filling, data grouping conversion, data sorting and filtering, later business indicator calculation, report template filling, etc. Commonly used data processing tools include spreadsheet software such as Excel, various database software, Python, R, SAS, SPSS, etc. These tools all include data processing modules to facilitate users to quickly clean the data and then analyse it.
4. Data analysis and Data mining
Based on the processed data, data analysts can analyse and mine it, draw relevant conclusions based on actual business, and provide them to the management for decision-making. Therefore, data analysts need to master the common methods of data analysis and data mining in order to lay a solid foundation for the production of later data reports.
The focus of data analysis lies in the proficiency of the business. An excellent data analyst often knows the company's business well. For example, data analysts must be very familiar with the pre-design of daily product activities, mid-term online tracking, post-effect evaluation, and final suggestions and feedback.
Of course, in addition to being proficient in business, data analysts must also master the analysis strategies and methods commonly used in data analysis. In general, data analysis strategies are divided into descriptive statistical analysis, exploratory statistical analysis, and inferential statistical analysis. ￼
Common data analysis methods include comparative analysis, group analysis, predictive analysis, funnel analysis, and A/B test analysis. Through these data analysis methods, the hidden value of data can be unearthed, thereby reducing business costs and increasing operating profits.
The focus of data mining is the understanding of models and algorithms. An excellent data analyst must have a solid mathematical foundation and proficient coding skills. The characteristics of data complexity, diversity, and dynamics will make data mining difficult. Therefore, in the data mining process, it is necessary to know what needs to be done at each step, what effect to achieve, and should adjust the plan strategy in time if there is a problem, so as to ensure the ultimate success of the entire data mining project.
The standardisation steps of data mining can use the CRISP-DM model launched by the SIG organisation in 2000.
The model defines the life cycle of a data mining project as six stages. The six stages are divided into business understanding, data understanding, data preparation, model building, model evaluation, result deployment. The data mining process does not have to be executed in full reference to this order.
Data analysts can adjust according to actual business scenarios, and through continuous testing and verification, only can they complete a complete data mining project. In addition, data mining has a cyclical nature. It does not end the mining process after one deployment. It requires continuous iterative optimisation to obtain the best results.
4. Make a data report
The final results of data analysis need to be summarised into a data report. The most common way is to report in PPT format. The production of data analysis reports is particularly important. The preparation of the data analysis report requires a clear purpose, clear structure, and justification.
The beginning part of the report is generally the table of contents and the foreword, which briefly lists the chapters that need to be stated in this report. The middle part is the main text, which mainly describes the chapters of the catalog. The end part is the summary of the report and proposes relevant suggestions and solutions .
The structure of the data analysis report is important to understand for being a better data developer. Using VBA automation you can even automate report making. We will discuss about this topic in the fourth module of this book. ￼ The catalog at the beginning is the overall outline of the data analysis report, which requires conciseness, clear structure, and logical order so that readers can quickly understand the content of the entire report.
Remember to summarise the table of contents and also remember not to divide too many chapters, and roughly include the purpose of analysis, main points of analysis, conclusions and suggestions. The foreword is a basic summary of the purpose, background, ideas, methods, and conclusions of the analysis report, and then often leads to the main content of the analysis report.
The analysis and demonstration of the main text is the core part of the data analysis report, which is explained separately according to the chapter order of the catalog, and the analysis ideas are explained in detail and demonstrated. Analysis and argumentation require clear structure, layered analysis, and reasonable evidence.
The conclusions and recommendations at the end are based on the previous analysis results. The conclusion requires accuracy, competence, and value, and must not be redundant and procrastinated. On the basis of accurate conclusions put forward your own opinions and suggestions to provide a reference for managers to make decisions.
Finally, the style of the data analysis report should be consistent, and the content can also be added with some dynamic display effects, so that readers are pleasing to it and feeling comfortable. Of course, the core of the data analysis report is analysis, conclusions and suggestions. It is not advisable to pay too much attention to the beauty of the analysis report and ignore the essence of the analysis report.
Data analysts should hold a scientific and rigorous attitude, combine business understanding with analysis and mining techniques, and obtain reliable and convincing analysis reports, which are provided to management for business decision-making.

Strategies and Statistical Analysis Methods
Data analysis refers to the use of appropriate statistical analysis methods to analyse a large amount of collected data, and extract useful information from it and form conclusions. So the question is, what are the strategies and statistical analysis methods used for data analysis?
From a macro perspective, the author divides data statistical analysis strategies into three categories, namely descriptive statistical analysis, exploratory statistical analysis, and inferential statistical analysis.
The commonly used methods of data analysis are summarised into 5 types namely comparative analysis, group analysis, Predictive analysis method, funnel analysis method and AB test analysis method. Three types of statistical analysis strategies
The three types of strategies, descriptive statistical analysis, exploratory statistical analysis, and inferential statistical analysis, are a gradual analysis step from the shallower to the deeper. To engage in data analysis, you need to master these three types of statistical analysis strategies from the field of statistics.

Through descriptive statistical analysis, data analysts can better grasp and understand the data, so that they have "numbers" in their minds. 3. Inferential statistical analysis
Inferential statistical analysis is very classic but relatively difficult. We all know that statistics is essentially to infer the overall situation based on the characteristics of the sample.
For example, with the help of random sampling, a partial sample is drawn from the population, and the average of the population is inferred from the sample Level (the method to solve the problem is the mean test in statistical inference).
According to the two attributes of the sample (that is, two variables), we need to determine whether there is a correlation between the attributes (need to use the correlation coefficient test or chi-square test in statistical inference). According to the distribution of the sample, judge whether the population obeys the normal distribution (the problem can be solved by using the normality test technique of the data).
Compared with exploratory statistical analysis, inferential statistical analysis focuses more on finding quantitative answers, usually calculating statistics and the corresponding probability P value. If the probability P value is less than 0.05 (the default comparison value), you need to reject the null hypothesis (the null hypothesis is the assumption that the event is true, such as the sample mean is equal to a certain value, there is no correlation between the two attributes, and the sample follows a normal distribution), Otherwise, the null hypothesis needs to be accepted.
In order to enable readers to grasp the method of inferential statistical analysis, a few small examples will be used to illustrate: the t test is used to infer whether there is a difference in the mean between the two samples. The two samples are inferred by the chi-square test and the Pearso correlation test Whether the attributes are irrelevant , the Shapiro normality test is used to infer whether the sample obeys normal distribution.

What is machine learning?
When it comes to machine learning, initially we need to know what the essence of learning is. Professor Herbert Simon, a famous scholar and winner of Turing Prize in 1975 and also who own Nobel Prize in Economics in 1978, once defined learning as a system that can improve its performance by executing a certain process. Process of learning is particularly important for machine learning systems.
In Simon's view, the core purpose of learning is to improve performance.In fact, for people, this definition is also applicable at many instances and situations.If we only carry out low-level repetitive learning, but fail to achieve the goal of cognitive upgrading, even if we seem to be very diligent, we are actually just a pseudo-learner whose performance is not being improved.
Simon believes that for computer systems, it is Machine Learning (ML) that is essential to improve the performance of machine systems by using data and some specific methods (such as statistical methods or reasoning methods).
In the classic textbook of Machine Learning, Tom Mitchell, a famous scholar and professor at Carnegie Mellon University, also gave a more specific (actually abstract) definition of "machine learning" as said below.
For a certain Task(T) and a certain Performance evaluation criterion(P), if a computer program is on T, taking P as the performance measure, and constantly improving itself with the accumulation of Experience (E), then we can say that this computer program has learned from E.
For example, AlphaGo, a program for learning Go( A chess game), can gain experience by playing chess with itself. Mitchell believes that for a learning problem, we need to make clear of three characteristics: first being the type of task, second being the standard to measure the improvement of task performance and finally the source of gaining experience.
In fact, the definition of machine learning is slightly different from different perspectives.For example, Vladimir Vapnik, the main proponent of Support Vector Machine (SVM), put forward in his book "The Essence of Statistical Learning Theory" that machine learning is a function estimation problem based on empirical data.
In an another classic book, The Basis of Statistical Learning, written by Trevor Hastie of Stanford University's Department of Statistics he mentions that machine learning is primarily used to extract important patterns and trends and understand the connotation expression of data, that is, to learn from data.
These three definitions of machine learning have their own emphases and merits.Mitchell's definition emphasises the effect of learning. Wanpnik's definition focuses on the operability of machine learning. However, Hasty's definition highlights the classification of learning tasks.But the common feature of the three is that they all emphasise the importance of experience and data, and they all recognise that machine learning provides a method to extract knowledge from data.

Formal Description of Supervised Learning
In this section, we will give a more formal (or academic) description of supervised learning.
Supervised learning is to learn a model by using labeled training data, and then use this model to predict new samples.In essence, the goal of supervised learning is to construct a mapping from input to output, which is represented by a model.
The model belongs to the mapping set from input space to output space, which is called hypothesis space.Assuming that the space is determined, it means that the learning scope is determined.And how to find the best mapping in the hypothesis space is the biggest motivation of supervised learning.
For supervised learning, the constructed model usually learns in the training set, adjusts the model parameters, and performs prediction verification in the test data set.Therefore, the training set is usually described by the formula using mathematical principles. ￼ Training data need to be used in the learning process, which is often given artificially.
In this training set, the expected output of the system (i.e., label information) has been given in advance. If the actual output of the model is inconsistent with the expected output (there is a gap between the two), then the model has the responsibility to "supervise" the learning system to readjust the model parameters until the error between the two is within the tolerable range.Therefore, the expected output (label information) is also called "teacher signal".
The process framework of supervised learning is roughly divided into two parts-learning and prediction.Specifically, the input data, which can be text, picture, audio, video, etc., are prepared first, and then the required features are extracted from the data to form feature vectors.
Next, these feature vectors and the tag information of the input data are sent to a learning model (specifically, a learning algorithm), and an available prediction model is polished after repeated training. Then, the same feature extraction method is applied to the new sample to obtain the feature vectors of the new sample.
Finally, taking the eigenvectors of these new samples as input, the prediction model is used to predict, and the expected Label information of the new samples is given. ￼ As mentioned earlier, if the input variables and output variables are of different types (either continuous or discrete), people usually give different names to the forecasting tasks according to the different types of input and output variables, such as classification, regression and annotation.

Over-fitting and Under-fitting
Let's talk about what is under-fitting.The concept of under-fitting is easy to understand, that is, insufficient samples, poor training, and even the features in the existing data sets (i.e., training sets) are not well learned. When it makes predictions in the face of new samples, the natural prediction effect is not much better.Sometimes, we also call under-fitting high bias.
So what is over-fitting?
Over-fitting means that the model "meticulously" reflects the features in the training data, so that it is too "excellent" in the training set.But as a result, its ability to predict unknown data (new samples) will be relatively poor, and the classifier will not know if there is any trouble.Therefore, sometimes we also call overfitting high variance.The high variance here means that the model is good in one place (training set) but not in another place (test set), which shows that the generalisation ability of the model is poor.
In addition, the so-called training data itself has errors.Too precise fitting may take the errors of these data as characteristics to learn, which leads to the more accurate fitting in the training set, the worse the prediction effect in the face of new samples.
Under-fitting is easy to overcome, such as expanding branches in decision tree algorithm, and increasing the number of training rounds in neural network, so as to learn the features contained in samples more delicately.
In comparison, it is much more difficult to overcome over-fitting.An important reason for fitting is that the model is too complex.What we need is a more simplified model to learn the features contained in the data.This corrective strategy of "returning to nature" is regularisation.

P-R Curve
When classifying, we often need to sort the prediction results of learning models. The first one is considered as the "most likely" sample, and the second one is considered as the "least likely" sample.Therefore, we often have to set a Threshold in the middle. When the predicted value is greater than this threshold, the sample is a positive sample, otherwise it is a negative sample.
According to different critical values, if each sample is predicted as a positive sample, different precision rates and recall rates will be obtained.If the precision is taken as the vertical axis and the recall is taken as the horizontal axis, a point can be drawn on the coordinate system when a critical value is set.When multiple critical values are set, a curve can be drawn in the coordinate system. ￼
P-R curve can directly show the precision and recall of classification algorithm as a whole.When comparing several classification algorithms, if the P-R curve of algorithm 1 completely "circumscribes" the P-R curve of algorithm 2, then algorithm 1 on the outside has higher precision and recall ratio (double high), which shows that algorithm 1 has better classification performance than algorithm 2.
But in a more general case, the P-R curves between algorithms are staggered with each other, so it is difficult to assert which is better or worse, and only compare them under specific precision rate and recall rate.
But what should I do if I have to compete?It is safe to compare the area under the P-R curve, and to some extent, it is said that the "double height" ratio is larger, that is, the performance is better.However, this area is not easy to estimate, so people have designed some measurement standards that comprehensively consider precision and recall.
Balance point (BEP) is such a measure.When P=R (which can be regarded as a straight line with an included angle of 45), the intersection point (BEP) will occur between this straight line and the P-R curve of each classification algorithm. The higher the BEP value of the algorithm, the better the classification performance of that algorithm.For example,the BEP of Algorithm 2 is larger than that of Algorithm 1, so it can be said that the performance of Algorithm 2 is better than that of Algorithm 1 to some extent.
The advantage of P-R curve is intuitive, but the disadvantage is that it is greatly influenced by sample distribution (such as the proportion of positive class and negative class).In contrast, ROC curve has more advantages, so it is often used as one of the important indexes for the performance evaluation of binary classifiers.Let's discuss the ROC curve and AUC closely related to it.
ROC curve
ROC curve is the abbreviation of "receiver operating characteristic curve" in English.It can be seen from its slightly odd name that the curve was not designed for the field of machine learning at first.ROC curve originated from military field at first, and then gradually applied to medicine, psychology and other fields.In the field of machine learning, ROC curve can be regarded as an improved version of confusion matrix: by constantly adjusting the threshold, different versions of confusion matrix are given, and then "connecting points into a line".
Let's trace back to the source and see how the ROC curve came from, so that we can have a deeper understanding of its uses.It is said that during the Second World War, the ROC curve was first invented by electronic engineers and radar engineers at the front line.The task of radar soldiers is very clear, that is, staring at the radar display screen to see if there are enemy planes coming (obviously, there are enemy planes and there are no enemy planes, which is a typical binary classification problem).Theoretically, as long as the enemy plane strikes, the radar will detect the corresponding signal.
However, troublemakers-all kinds of high-altitude birds will join in the fun.When they appear in the radar scanning area, the radar screen will also display the signal of foreign objects invading.At this time, it is time to test the radar soldiers. If there is a signal, "everything is in danger" and it is determined that enemy planes are coming, this will obviously increase the false alarm rate.
However, if all the signals are regarded as birds, the false negative rate will increase.Every conscientious radar soldier wants to do his best to improve the accuracy of enemy aircraft forecast.But the problem is that some radar soldiers are cautious by nature and tend to misreport. Some radar soldiers are naturally sloppy and easily missed.For the military, how to select "reliable" radar soldiers?
In fact, in terms of machine learning, every radar soldier can be regarded as a classifier to judge whether enemy planes are coming or not.So the problem evolves into, how to choose a classifier with excellent performance?
The safest way is to speak with data.The electronic engineers of the military summarised the forecast data of all radar soldiers, especially the probabilities of missing and false positives, and plotted these probabilities into a two-dimensional coordinate system.The ordinate of this coordinate system is sensitivity (TPR for short), which indicates the probability that radar soldiers can predict correctly when an enemy plane really strikes.
The abscissa is specificity (False Positive Rate, referred to as FPR), which indicates the probability that a radar soldier misjudges it as an enemy plane when a non-enemy plane strikes (such as a bird flying by).FPR and TPR are defined as below. ￼ N is the true number of negative samples. In the confusion matrix, N is the sum of TN (true negative class) and FP (false positive class), and FP is the number of negative samples misjudged by the classifier as positive samples.
P represents the true number of positive samples.In the confusion matrix, p is the sum of TP (true class) and FN (false negative class), and TP is the number of positive class samples correctly predicted by the classifier.
The above definition is a bit abstract to understand, and the following is an example.Let's assume that the radar soldiers detected 10 signals of foreign objects, among which 4 were enemy planes (P=4) and 6 were birds (N=6).Now suppose a radar soldier judges these 10 signals and judges that there are 3 enemy planes.However, one of the three enemy planes was actually a bird, but it was misjudged as an enemy plane (FP=1), and the bird triggered six alarm signals, so the false positive rate was FPR=FP/N=1/6.
In the judgment of these three enemy planes, two are indeed enemy planes (i.e., TP=2), and there are actually four enemy planes, so the true positive rate of this radar soldier is TPR=TP/P=2/4.If radar soldier is regarded as a classifier, his coordinate points on ROC curve should be (1/6,2/4).
In fact, the ROC curve generates a series of key points on the curve by constantly moving the "cut-off points" of the classifier.Let's explain the "cut-off point".Very often, when we judge whether a sample is a positive sample or a negative sample, we cannot say "yes (100%)" or "no (0%)".
Many classifiers (such as Bayesian classifier and neural network classifier) only output a classification probability, and then a cutoff point (or threshold probability) can be given. If the classification probability is greater than this cutoff point, the sample is judged as a positive sample, otherwise it is a negative sample.
For a sorted classification probability, a series of key points (FPR,TPR) on the curve will be generated by constantly moving the "cut-off point" of the classifier.These key points are just a curve, which is the ROC curve we are learning. ￼ The following is a case to further illustrate the concept of "cut-off point".Assume that there are 20 samples in the test set (10 real positive and negative samples each), and shows the output results of the binary classifier (P stands for positive class label, and N stands for negative class label).
￼The following describes the drawing process of roc curve.When the truncation point is positive Infinity, the classification model will judge all samples as negative samples, so FP and TP are naturally 0, so FPR and TPR are also 0, so the coordinates of the first point of ROC curve are (0,0).
When the cut-off point (output probability) is set to 0.9, only the samples ranked first are judged as positive samples by the classifier, and at this time TP=1.There are 10 positive samples in these 20 samples, that is, P=10, so TPR=1/10=0.1.
At the same time, among all the samples judged as positive samples, there is no false positive sample that has been "wronged", that is, FP=0.There are also 10 negative samples, that is, N=10, so NPR=0/10=0.Therefore, the coordinates of the second point of the ROC curve are (0,0.1).
Similarly, when the cutoff point is set to 0.8, only the first two samples are judged as positive samples by the classifier.Therefore, TP=2, TPR=2/10=0.2.At the same time, there are no false positive samples, namely FP=0, NPR=0/10=0.Therefore, the coordinate of the third point of the curve is (0,0.2).
By analogy, when the cut-off points are constantly adjusted, all the key points can be drawn, and then these key points are connected to form the final ROC curve, which finally stays at the point (1,1).
If these key points are dense enough, the ROC curve shown is no longer jagged, but smooth. ￼ After a long time, we introduced the drawing of ROC curve.You may ask, what is the use of this ROC curve?Simply put, ROC curve is used to evaluate the performance of different binary classification algorithms.How to evaluate the advantages and disadvantages of two classification algorithms?This will use another concept, AUC.
AUC
AUC is the abbreviation of Area Under Curve, which means "area under curve" as its name implies.The "curve" here is the ROC curve we mentioned earlier.AUC is the sum of areas under ROC curve, which can quantitatively reflect the performance of classification algorithm.
It is not complicated to calculate the AUC value, just integrate (or accumulate and sum) along the horizontal axis of ROC curve.Generally, ROC curves are located above the line yx= (if not, a better classifier can be obtained by inverting the prediction probability P of the model to 1-P).
Therefore, AUC generally ranges from 0.5 to 1.Generally speaking, the larger AUC indicates the better performance of the classifier, because it can rank the real positive samples in front and reduce the false positive rate. ￼

Chapter 8
Data Analysis in Depth
Decisions can also be made based on experience
We have talked about a lot of successful cases of data analysis, but in fact, many companies have not done data analysis, relying on experience, they are still developing very well. For example, Tumblr, a famous social networking website has not done any data analysis before, but it ranks very high in the industry. How can we explain this?
Experience is just an idea of ​​reality and is far from real reality. There is often a big difference between the experience of an enterprise and the real market.This difference exists objectively.
The president of Northwest Airlines once said vividly that for airlines, the most important problem in flight is the airplane's engine. The engine is the power of the airplane. No problems should occur to the engine. If it happens, it will be catastrophic. But for the passenger, what affects his choice of airline may be whether or not the small table in front of the seat is clean. If a passenger gets on the plane, opens the small table and finds oil stains, he will be disappointed with the service and will never take this plane again.
What we are trying to say is that no matter how good the engine is, the consumer is not directly aware of it, and what he can compare is often a matter of visual detail. In many cases, companies and consumers have different perspectives on issues, and there are differences in the criteria for evaluating good or bad. It is precisely because of this difference that companies may face great risks and costs when making decisions based on their own experience and intuition.
It is the difference between enterprise experience and market demand, so empirical decision-making cannot guarantee that the enterprise can accurately grasp the pulse of the market at any time, and there will be certain risks. The role of data analysis is to enable companies to listen to the voice of the market and guide them to operate in accordance with the characteristics and laws of the market. Such decisions can be more objective and such companies can be more stable.
Does Data analysis increases decision-making costs?
It takes money to establish departments, recruit talents, purchase systems, and integrate data. Data analysis will greatly increase the cost of decision-making. Therefore, many of us believe that only large and powerful companies can do data analysis.
Data analysis intuitively does increase the cost of decision-making. However, through data analysis, decision-making is made more objective, which not only reduces the losses caused by decision-making mistakes, but also reduces unnecessary management costs for enterprises.
Compared with the losses caused by decision-making errors, the cost of data analysis is minimal. In fact, it is often not the costs incurred by data analysis that cause the company to suffer heavy losses, but the company's decision-making errors. Many companies lack the awareness of data analysis, resulting in major decision-making mistakes, and even going nowhere. In addition to reducing the losses caused by decision errors, data analysis can also reduce unnecessary management costs for enterprises.
For example, some companies often bring all new products to the market at the same time, and continue to push if they sell well, and then withdraw those that do not sell well. But let’s do the math, how much channel resources, labor, production line, and time cost will be occupied by those who do not sell well. If you do data analysis in the early stage to determine the market's evaluation of new products, you will have choices when you launch new products and this strategy will save a lot of unnecessary management costs.
Therefore, whether a company does data analysis or not has to be counted on two principles: how much does the data analysis cost? What are the benefits of data analysis? After that weigh the two, whichever is more important.
Example :
Company A wants to invest in the development of a new product, but the market performance of the product is uncertain and there are 4 possible states. The company's marketing staff estimated the probability of occurrence of these four states and the corresponding profits.
Company B is a data analysis company that can provide support for Company A's new product decision-making. If the analysis result of B company shows that the new product presents any of the three states (1, 2, 3), then it is recommended that A company develop the new product; if it presents the status 4, then it is recommended that A company give up. The service fee for this data analysis by Company B is 40,000 US dollars. The question now is, if you are the decision maker of Company A, do you cooperate with Company B in the development of this new product?
As I said before, whether to cooperate with Company B is to compare the profit of non-cooperation and the profit of cooperation which is higher or lower.
If there is no cooperation, the profit P of the new product is equal to the weighted average profit with the probabilities in the four states as the weights.
What about Insufficient research data?
Market research does have the problem of lack of trust, but we must not give up because of few setbacks. Instead, we must find the link and cause of the problem and then avoid it. I think the problem may lie in the design or implementation.
For example, we just mentioned that for a company’s market share, different institutions provide different data. The problem may lie in the design process. These institutions may not provide you with the data sources and concept definitions that support the conclusion.
In terms of data sources, if one family has 6,000 collection sites, distributed in first-, second-, and third-tier cities, while another has only 2,000 collection sites, only distributed in first-tier cities, then the conclusion is definitely different. Which company has more reliable data depends on which company’s collection network distribution is more representative of the overall characteristics; which company’s sampling error is acceptable.
For another example, in terms of concept definition, suppose it is a research on high-end microwave ovens. If one defines a microwave oven with a price of more than 80 dollars, and another defines a computer grill microwave oven with a price of more than 200 dollars, the conclusion is definitely different.
Before the investigation, relevant concepts need to be clearly defined.In addition, in the implementation process, whether the survey time, interviewees, survey location, and quality control are reasonable and effective will also affect the quality of the survey. It should be said that research is a highly professional industry. Omissions in any link may affect the accuracy and objectivity of the survey results. Whether it is your own research or outsourcing to a research company, you must have a certain degree of research. In this way, we can distinguish good from bad and control the credibility of survey data ￼
***Organizational structure of data analysis ***
First, there is Party B (a third party) that can meet our analysis needs. Do we need to have our own analysts? Second, if necessary, should the analyst enter the existing business department or set up an independent data analysis department?
1. Does the company have its own analyst?
Let me talk about the first question first. My point is that even with Party B, we still need our own analysts. The company will face a large number of decision-making issues during its operation, such as how to set up safety stocks? How to choose the right supplier? How to achieve optimal production arrangements? How to improve the success rate of new products? How to price? How to evaluate the effect of promotional activities? If there is a decision, there must be analysis requirements. If these requirements are outsourced to Party B, the cost is relatively high.
Therefore, if it is a small and medium-sized enterprise, having its own analyst can reduce costs; if it is a large enterprise, outsourcing to a third party requires someone to contact the third party. If this person has no knowledge of data analysis, it is difficult to find a suitable third party. It is best to train your own analysts to improve the quality and efficiency of cooperation with third parties.
2. In which department the analyst is located
This is actually a matter of organisational structure. There are two organisational structures. One is that analysts are scattered across existing business departments, called a decentralised structure; the other is that analysts are concentrated in an independent data department, called a comprehensive structure.
It should be said that the two structures have their own advantages and disadvantages. The advantage of the decentralised structure is that it is close to the data sources of various departments, convenient for data retrieval, and strong in analytical autonomy. In addition, the data is scattered in various business departments, and data leakage problems rarely occur. But the problem of decentralised structure is also obvious. The root cause is the embarrassment of the tripartite caused by the contradiction between departmental interests and comprehensive analysis.
The analyst's embarrassment
Suppose I am an analyst, and I want to evaluate an investment project, and I need to make a comprehensive evaluation based on data such as environment, market, competition, product, and profit. However, the environmental data is in the strategy department, the marketing and competition data is in the marketing department, the product data is in the product department, and the cost and profit data is in the finance department. I only belong to one of these departments. Under the division of departments, I get other Departmental data is very difficult, so I can only have what kind of rice to do, and the nutritional value is naturally not too high.
Embarrassment in the business department
The information resources of various departments cannot be shared, which will result in the situation that those who understand the market do not understand the product, and those who understand the product do not understand the market, thereby affecting the effective operation of the business department. Business departments such as marketing department and product department are like multiple transportation trunk lines. If there is no independent department for information integration, it is like missing a transportation hub, and transportation at the interchange is prone to failure.
The embarrassment of high-level decision makers
Affected by the interests of this department, various departments will have the problem of reporting good news and not reporting worries and using data to compete for resources. It is difficult for the senior management to make effective assessments and optimal allocation of resources to various departments, which affects the overall control and system decision-making at the company level.
The shortcomings of the decentralised structure can be compensated by the integrated structure. The integrated structure means that all analysts are concentrated in an independent data department, and the data department is directly responsible to the general manager, which is higher or equal to other business departments. You can freely retrieve data from each business department, and provide corresponding support for the business department according to the needs of the business department. At the same time, the data department does data management and analysis at the company level, assisting the general manager to do a good job in business cooperation, resource allocation, and performance appraisal among departments.
The comprehensive structure can solve the contradiction between the departmental benefits brought by the decentralised structure and the comprehensive analysis. However, the integrated structure also has its shortcomings. Because analysts and business departments are independent of each other and are not familiar with each other, there will be deviations in the business department's understanding of analysis reports and the data department's understanding of business needs. In view of the shortcomings of the comprehensive structure, I think it can be solved by four major guarantees: standardised processes, detailed documents, reasonable presentation and smooth connection.
Standardised process:
The requirements are generally raised by the business department, and the results are returned to the business department through the data acquisition and calculation of the data department. In this process, the business department must not only provide data rules, but also the purpose of obtaining data and the indicators The definition, usefulness and value are described in detail; and the data department not only has to provide the final data, but also needs to explain the way to obtain the indicators and the calculation method. The ultimate goal is to make the two parties reach a consensus on understanding.
Detailed documents:
Two types of documents generated in the process-data requirements documents and data interpretation documents, detailed documentation is convenient for reference.
Reasonable presentation:
Let everyone see the data they want to see and understand the data intuitively. At the same time, whether it is a report, Excel, or other display methods, each indicator must be able to directly view its data interpretation document.
Smooth connection:
To ensure a smooth connection between business and data, there must be a connection person. This linker should be very familiar with the product’s strategic goals and business processes, and at the same time know the data acquisition methods and calculation methods. Perhaps it does not need to involve high-tech data ETL processing, organisation and optimisation, but must have its own calculation and calculation methods. The ability to obtain data, this interface is often the person in charge of the data department.

The value of data analysis is to provide support for corporate decision-making, which is also the responsibility of the data analysis department. How to achieve? I think we need to work hard in three aspects: data platform, data support, and data application. The following formula can be used to express the investment ratio of these three aspects: the responsibility of the data analysis department = 20% of the data platform + 30% of the data support + 50% of data applications.
  1. Data platform : The data platform is the foundation of data support and application. To build a data platform, we need to work closely with relevant departments to integrate sales, customers, finance, production, employees, management, competition and other data, and introduce CRM, ERP and other management software on this basis , Do IT architecture and system updates.
  2. Data support : Data support is to provide corresponding data according to the needs of business departments, such as users, competition, market, environment and other data.   3. Data application : Data application is the key responsibility and core value of the data analysis department. Data application areas include three aspects: strategy, investment, and marketing.
