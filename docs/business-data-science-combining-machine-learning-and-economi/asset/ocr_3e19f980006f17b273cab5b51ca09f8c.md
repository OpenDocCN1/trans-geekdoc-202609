that users spend on various websites. That is, we seek to predict consumption from browser history. We will use a log-linear model,

$$ \log(\mathrm{spend}) = \alpha + \boldsymbol{\beta}' \boldsymbol{x} + \varepsilon. \tag{3.5} $$

Here, $x$ is the vector of site-visit percentages. This model could, for example, be used to segment expected user budget as a function of browser history.

The *path plot* in Figure 3.6 illustrates Algorithm 6. The algorithm moves *right to left*, with decreasing values of $\lambda$. The *y*-axis here is $\hat{\beta}_j$, with each colored line a different $\hat{\beta}_j$, as a function of $\lambda_i$. Each vertical slice of the plot represents a candidate model. As the path proceeds, the models become increasingly complex as the $\hat{\beta}_i$ include more and larger nonzero $\hat{\beta}_k$ values (the plot header marks the number of nonzero $\hat{\beta}_k$ at certain segments).
