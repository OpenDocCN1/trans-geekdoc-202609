# **ALGORITHM 8** $K$-Fold CV Lasso

Begin by minimizing Equation 3.4 over the sequence of penalty weights $\lambda_{1} > \lambda_{2} \ldots > \lambda_{T}$ to obtain a path of candidate models $\hat{\boldsymbol{\beta}}_{1} \ldots \hat{\boldsymbol{\beta}}_{T}$. Then, for each of $k=1 \ldots . K$ folds:

+   - Using this same $\lambda_{l}$ sequence, fit the lasso path $\hat{\boldsymbol{\beta}}_{1}^{k} \ldots \hat{\boldsymbol{\beta}}_{T}^{k}$ on all data data *except* the $k$th fold, say, fold$k$.

+   - For each $\hat{\boldsymbol{\beta}}_{t}^{k}$, calculate the fitted deviance on left-out data,

```
$$ e_{t}^{k}=-\frac{2}{n_{k}} \sum_{i \in \text { fold } k} \log p\left(y_{i} \mid \boldsymbol{x}_{i}^{\prime} \hat{\boldsymbol{\beta}}_{t}^{k}\right), $$
```

where $n_{k}$ is the number of observations in fold$k$.

Set $$ \overline{e}_{t}=\frac{1}{K} \sum_{k} e_{t}^{k} \text { and } \operatorname{se}\left(\overline{e}_{t}\right)=\sqrt{\frac{1}{(K-1)} \sum_{k}\left(e_{t}^{k}-\overline{e}_{t}\right)^{2}} $$ as your estimate and sampling error for the OOS deviance at each $\lambda_{t}$. Finally, use the results to choose the “best” $\hat{\lambda}_{t}$ and use the corresponding full-sample coefficient estimates, $\hat{\boldsymbol{\beta}}_{t}$, for your modeling and predictions.

Note that there are two options for $\lambda$ selection shown in **Figure 3.8**. The obvious one, called the CV-min rule, simply selects the $\lambda_{t}$ corresponding to the minimum average OOS error. The second option, called the CV-1se rule, defines as best the biggest $\lambda_{t}$ with average OOS deviance no more than one SE (the se$(\overline{e}_{t})$) from Algorithm 8) away from the minimum. In **Figure 3.8**, this corresponds to the right-most dotted line.
