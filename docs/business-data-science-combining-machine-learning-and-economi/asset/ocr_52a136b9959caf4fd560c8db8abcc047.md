```
Set the $p$-value cutoff as $p^{\star}= \max \left\{p_{(k)}: p_{(k)} \leq q \frac{k}{N}\right\}$.
```

The *rejection region* is then the set of all $p$-values $\leq p^{*}$, and this ensures that $\mathrm{FDR} \leq q$.

Note that $p_{(k)}$ denotes the $k$th order statistic.
