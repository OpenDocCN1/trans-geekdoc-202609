# ALGORITHM 18 Principal Components Analysis

Set $\tilde{\mathbf{X}}^1 = \mathbf{X}$, your $n \times p$ data matrix. Then, for $k = 1 \ldots \min(n, p)$,

+   Find
\begin{equation}\begin{split}\boldsymbol{\varphi}_{k} = \argmax_{\boldsymbol{\varphi}_{k}} \big[ \operatorname{Var}(\tilde{\mathbf{X}}^{k}\boldsymbol{\varphi}_{k}) = \operatorname{var}\{v_{k1}, \ldots, v_{kn}\} \big],\end{split}\tag{7.10}\end{equation}
where
\begin{equation}\begin{split}\boldsymbol{v}_{k i} = \boldsymbol{\varphi}_{k}^{\prime}\mathbf{x}_{i} = \sum_{j=1}^{p}x_{ij}\varphi_{k j} \text{ and } \sum_{j=1}^{p}\varphi_{k j}^{2} = 1.\end{split}\end{equation}

+   Update rows of $\tilde{\mathbf{X}}^{k}$ via $\tilde{\mathbf{x}}_{i}^{k+1} = \tilde{\mathbf{x}}_{i}^{k} - \boldsymbol{v}_{k i} \times \boldsymbol{\varphi}_{k}^{\prime}$

There are many ways to run PCA in R. After trying many different versions with my MBA classes, the most robust seems to be `prcomp(x, scale=TRUE)`. The `scale=TRUE` argument here is important: since you're working with fitting the $x_{ij}$ directly, as in *K*-means and *K* nearest neighbor, it is good to scale the data so that you are working in terms of standard deviations of $x_j$ rather than in some other arbitrary units. To illustrate, we'll apply this to the protein consumption data:
