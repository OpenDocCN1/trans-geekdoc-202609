# 作者简介

Matt Taddy 在 2008 年至 2018 年期间担任芝加哥大学布斯商学院计量经济学与统计学教授，并在那里开发了数据科学课程体系。他还担任过多种行业职位，包括微软首席研究人员和 eBay 研究员。他于 2018 年离开芝加哥，加入亚马逊担任副总裁。
