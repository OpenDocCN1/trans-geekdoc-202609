# *Standard Usage for Some Common Notation*



| ≤ | ………. | less than or equal to | | MLE | ……. | maximum likelihood estimate |
| < | ………. | less than | | OLS | ……. | ordinary least squares, i.e., the MLE for linear regression |
| ≪ | ………. | much less than | | n | ………. | number of observations |
| = | ………. | equal to | | p | ………. | either data dimension or a random variable (as in p-value) |
| ≈ | ………. | roughly equal to | | y | ………. | response of interest |
| ∝ | ………. | proportional to | | x | ………. | inputs to a regression |
| ⊥ | ………. | independent from | | β | ………. | linear regression coefficients |
| 𝔼 | ………. | expected value (average) | | ε | ………. | independent additive errors in regression |
| p(A) | …… | probability of A | | γ | ………. | the causal treatment effect |
| f(x) | …… | generic function of x | | Σ | ………. | covariance matrix |
| 𝔼[A \| B] | … | expectation for A given B | | λ | ………. | penalty weight |
| 1_{[A]}. | …… | indicator equals 1 if A else 0 | | Σ_{i∈S}a_i | … | sum of a_i values for i in the set S |
| log(a) | … | logarithm of a with base e | | Π_{i=1}^{n}a_i | … | product of a_i values for i from 1 through n |
| e | ………. | Euler’s number ≈ 2.71828 |
| df | ………. | model degrees of freedom |
| lhd. | …… | likelihood of the observed data |
| dev | ……… | deviance, where where dev ∝ -2 log lhd |
