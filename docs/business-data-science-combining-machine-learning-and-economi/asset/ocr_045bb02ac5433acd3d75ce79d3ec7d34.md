To fit GPs in R, you can make use of the `laGP` package.[26] This package was developed to implement algorithms for fitting *approximate* GPs on massive datasets (which is great, because you can keep using `laGP` as you scale to larger applications) but also provides fast and robust routines for fitting standard GPs. Detailed examples are provided in Gramacy [2015] and in the package documentation.
