The bootstrap in Algorithm 1 mimics the process in **Figure 1.3** by replacing samples from the population with *resamples* from your sample. The *with-replacement* sampling here is essential. It implies that each observation can be chosen more than once for inclusion in the resampling. For example, if we are sampling with-replacement five items from the set $\{1, 2, 3, 4, 5\}$, possible resamples would include $\{1, 1, 3, 3, 4\}$ and $\{2, 2, 2, 3, 5\}$.
