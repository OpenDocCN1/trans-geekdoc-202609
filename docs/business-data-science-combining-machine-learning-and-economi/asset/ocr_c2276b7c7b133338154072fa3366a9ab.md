Through a well-known relationship between Poisson and multinomial distributions, it turns out that multinomial logistic regression coefficients will be—for all practical purposes—similar to those that we can get through *independent* estimation for each of the log-linear equations:

$$\mathbb{E}[y_{ik} | \boldsymbol{x_i}] = \exp(\boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k}). \qquad (4.10)$$

The trick is that we need to estimate the coefficients in Equation 4.10 using a Poisson distribution likelihood, rather than the Gaussian distributions (squared error loss) that we’ve previously used with log linear models. That is, we will assume that

$$y_{ik} \sim \text{Poisson} \left( \exp[\boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k}] \right). \qquad (4.11)$$

This leads to the Poisson deviance objective,

$$\text{dev} ( \boldsymbol{\beta_k} ) \propto \sum_{i=1}^{n} \exp ( \boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k} ) - y_{i} ( \boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k} ). \qquad (4.12)$$

Adding lasso penalty regularization, we can then estimate regression coefficients by minimizing a penalized deviance:

$$\hat{\boldsymbol{\beta}_k} = \text{argmin} \left\{ \sum_{i=1}^{n} \exp \left( \boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k} \right) - y_{i} \left( \boldsymbol{x_i}^{\prime}\boldsymbol{\beta_k} \right) + \lambda_k \sum_{j} \left| \beta_{kj} \right| \right\}. \qquad (4.13)$$

The Poisson distribution is used for *count* data: $y \in \{0, 1, 2, \ldots\}$. When you *know* that $y_{ik} \in \{0, 1\}$, this is a misspecified (i.e., incorrect) model. However, researcher₂ has demonstrated that the two models are practically interchangeable, especially for prediction purposes. Use of Equation 4.13 to estimate multinomial logit parameters is what we refer to as *distributed multinomial regression* (DMR). This Poisson approximation scheme can even lead to *improved* prediction in a lasso setting because it allows you to validate and select a different λk for each outcome class.

The biggest advantage of using DMR is that you can now estimate each $\hat{\beta_k}$ in *parallel*. To “compute in parallel” is to do many calculations at the same time on different *processors*.
