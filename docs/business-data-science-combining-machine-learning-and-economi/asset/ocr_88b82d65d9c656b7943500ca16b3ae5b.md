Logarithm in this book is always base $e$ so that $\log(a) = b \iff e^b = a$. Variables that move multiplicatively with each other\u2014e.g., as in “households with broadband access spend 75% more online”\u2014are often modeled as linear on the log scale. See Chapter 2 for details.
