It might seem like there is a lot of data here—6241 pilot viewings—but there are only 40 shows and 20 survey questions. That is, there are only two observed $y$ values for each input dimension, such that it is a small dataset with big data dimensionality problems. To relate survey results to show performance, we need to first calculate the average survey question response by show. This leads to a $40 \times 20$ design matrix $X$, and we can fit PCA on this design.
