Trees are easiest to understand in a dendrogram plot—a diagram of internal splits, ending in leaf-node decisions. To get this in R you need two steps: first plot the tree outline and second add the text.

```
> plot(genretree, col=8, lwd=2)
> text(genretree)
```

Figure 9.2 shows the resulting image. The genre at each leaf node is that with highest probability in that node. You can alternatively call text(genretree, label="yprob") to get the full set of class probabilities for each leaf.
