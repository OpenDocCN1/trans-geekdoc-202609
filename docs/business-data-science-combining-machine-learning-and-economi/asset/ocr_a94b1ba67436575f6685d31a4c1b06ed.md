Given this available data, a synthetic controls analysis first builds a model to predict $y _ {1 t}(0)$ from $\mathrm{y} _ {- 1 t}(0) = [\mathrm{y} _ {2 t}(0) \ldots \mathrm{y} _ {J t}(0)]'$. This model is estimated using the fully observed data from periods $t \leq T$ and is then used to predict the unobserved control values $y _ {1 T + 1}(0), y _ {1 T + 2}(0)$, etc. The original synthetic controls work of Abadie and Gardeazabal [2003] uses positive weights summing to one to combine the control series when predicting the treatment series. However, you should feel free to use whatever regression model works best for prediction in your application. Since there are typically many control series $(J)$ relative to the number of time periods $(T)$, it will often make sense to use a regularized regression like the AICc lasso.
