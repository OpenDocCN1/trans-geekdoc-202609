We can expand the model of Equation 7.6 for each individual dimension of x, writing

```
$\mathbb{E}[x_{ij}] = \varphi_{j1} v_{i1} + \ldots \varphi_{jk} v_{ik}, \ j = 1 \ \ldots \ p.$ (7.7)
```

Equations 7.6 and 7.7 describe the same model. The $v_{ik}$ values are attached to each observation; they are like the $x_{ij}$ inputs in regression, except that they are now unknown *latent factors* that need to be estimated.
