pstcut <- prune.tree(pstree, best=3)

This pstcut is then itself a new tree object—the tree in Figure 9.6. CV has selected PSA and penetration as the only influential variables, and PSA matters only for low-penetration tumors. We see that tumor size tends to increase with penetration but that there are some large tumors with low penetration when PSA is high.
