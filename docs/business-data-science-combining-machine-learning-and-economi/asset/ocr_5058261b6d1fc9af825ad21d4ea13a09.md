The orthogonal ML procedure finds an average elasticity of between $-3.1$ and $-3.7$, which is in the range of values we would expect for beer (or, e.g., soft drinks as in Hoch et al. [1995]).

For comparison, we have the full sample of 1.6 million observations. This is enough data that we can reliably estimate all of the necessary week/store/UPC control effects using unbiased MLE estimation, $^{18}$ and hence we can use this as a gold-standard elasticity estimate in this example.

The full sample value is inside of the 90% interval provided by orthogonal ML on the small subsample.
