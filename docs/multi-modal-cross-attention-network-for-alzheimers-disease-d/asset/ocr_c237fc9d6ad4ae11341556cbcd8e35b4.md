# 5.4. Discussion of cross-attention extending to imaging modules

In the proposed MCAD, multi-modal interaction module based on cross-attention learns to learn the interactions between imaging features and CSF features. To investigate the performance of MCAD using cross-attention in different modules, we perform experiments by comparing MCAD with a variant where cross-attention is extended to different modules that include MRI and MEG-PET features, and design "MCAD-extended". Specifically, after obtaining the features of only two modalities, the outputs are concatenated for classification. The experimental results are shown in Table 5.

Looking at Table 5, the performance of multi-modal interaction between imaging features and CSF features is better than that of the multi-modal methods with some MRI features, MEG-PET features and CSF features, especially in MCI vs. CN classification.
