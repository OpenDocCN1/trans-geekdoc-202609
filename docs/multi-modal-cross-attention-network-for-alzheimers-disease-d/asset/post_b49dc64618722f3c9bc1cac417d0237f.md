
## (1) Classification Loss

Cross entropy, a widely used objective function in classification tasks, is employed to minimize the AD classification loss from multi-modal data supervised learning as follows:

```
$L_{CE} = -\sum_{i=1}^{N_L} \frac{1}{C} \sum_{c=1}^{C} y_{ic} \log(p_{ic})$
```

where $M$ is the number of classes and $y_{ic}$ is the ground truth. The probability score for belonging to class $c$ is denoted as $p_{ic}$.

## (2) Modality loss

To fuse features from different modalities (sMRI and PET) and CSF biomarkers to share the similarity, the KL divergence is utilized to align the features of the AD and non-AD modalities by transforming the different domain. The KL divergence between the representation $I$ and $C$ is defined as:

```
$D_{KL}(I||C) = \sum_{i=1}^{d} I_i \log\frac{I_i}{C_i}$
```

where $d$ is the feature dimension. In the proposed MCAD, the modality alignment loss between the features of MRI and CSF is further considered for reducing the modality gap. The modality loss $L_M$ is calculated as:

```
$L_M = D_{KL}(I||C) + D_{KL}(C||I)$
```

Finally, in order to learn the domain-invariant discriminant features, the classification loss and modality loss are combined for model training. The loss function is defined as:

```
$L = \gamma_1 L_{CE} + \gamma_2 L_M$
```

where the hyperparameters $\gamma_1$ and $\gamma_2$ are the proportions of each representing the representative content, which is determined in experiments.

All experiments are conducted using Python 3.6 and the PyTorch library. The model is trained on a single NVIDIA GeForce 3090 GPU for 100 epochs using Adam optimizer with a batch size of 32.
