### 4.4.2 Ablation study for the objective function

An objective function is employed in this paper to optimize the generator algorithm, classification loss and fusion loss to control the distribution alignment to learn the multi-modal dependency and find the optimal combination of loss functions. We conduct experiments by ablation study of the diagnostic performance with respect to $t_1$ and $t_2$. Specifically, $t_1$ is set to 1.0 and $t_2=0.005$ is tuned to evaluate the proposed MCD with different relative coefficients of classification loss and alignment loss. We set the range of $t_2$ from 0.0001 to 0.1 as an adjustment step. The experimental results are reported in Fig. 6.

As expected, ACC, AUC and F1 values approximately follow a U-shaped curve as increasing $t_2$. When $t_2$ is small, the performance of the model gradually improves as the model begins to align the features of imaging and non-imaging modalities. When $t_2$ increases, the performance is degraded to some extent, because the model fails to pay enough attention to the classification loss; in other words, the model controls too many constraints on the distribution alignment of multi-modal data.
