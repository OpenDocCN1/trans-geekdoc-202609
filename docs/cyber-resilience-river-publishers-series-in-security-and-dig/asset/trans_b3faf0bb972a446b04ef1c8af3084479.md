
*   每个程序操作符动作与一个网络传输建立精确的一一对应关系，因此潜在动作执行结果来自*转移活动*。*转移活动*级别定义了程序操作符活动。
*   潜在关闭可达性确保不存在与循环相关的不同错误（*简单循环、并行进程的动态死锁*）。*完全关闭可达性*的概念是基于潜在可达性制定的。

发现结构正确性的附加特征与信号量操作有关[34, 132]。因此，在每个信号量中，解析标记的数量应受固定数字限制。限制解析标记数量的数字应在操作开始前定义，并应等于初始*信号量*状态下这些标记的数量。由于每个*信号量*都在一个*Petri网位置*中传输，上述特征分析归结为信号量位置的标记可达性分析，并将可达标记数与初始标记进行比较。如果拥有关于程序中信号量操作存在的后验信息，则可以分析此特征。

信息结构描述了程序对输入和输出变量操作之间的联系。在分析中，结构的使用使得能够得到特征组。一方面，这是对数据使用逻辑正确性的评估，另一方面，是对数据流控制中所有程序特征的评估。数据使用的逻辑特征包括：

*   控制转移时刻输入数据的确定性；
*   所有结果定义的明确性；
*   获得任何结果的事实、获得这些结果的方法数量等。

当用*Petri网*描述程序信息结构时，一组变量与网元素（位置或转移）相关联，输入输出上的连接由*Petri网弧*表示。这里采用了将程序代码变量与相应*Petri网位置*匹配的建模方法。为了从反汇编清单中用*Petri网*表示程序信息结构，还需要额外开发汇编命令解释器，将程序命令与相应的*Petri网位置*链接[34, 132, 133]。

> P = {*p*1, *p*2, • • •, p*n*} (1.2)

转移关联的输入函数

> *O*: *T* × *P* → {0, 1} (1.5)

I 和 O 反映了程序代码条件与事件之间的连接。

${\\overset{\\rightarrow}{\\mu}}\_{0} = (\\mu\_{\\, 0}^{\\, 1}\\,,\\mu\_{\\,\\, 0}^{\\,\\, 2}\\,,...\\,\\,,\\mu\_{\\,\\, 0}^{\\, n})^{T}$ (1.6)

对应于程序初始状态的初始标记向量。

为了对程序运行动态建模，让我们定义转移触发规则，它是通过表达式作为*Petri网*标记的函数

*I[I]*: *T* × *P* → {0, 1} 是一个特殊的关联函数，对于那些 *I[I]*(*t*, *p*) = 1 的对 (*t, p*)，它设置抑制弧。

让我们定义带零检查的*Petri网*中的转移触发规则。

##### 可达性

从标记 μ[0] 出发的标记可达性问题 μUF ∈ R(μ[0])，其中满足条件 (1.7)、[(1.8)](#Ch02.xhtml#cap_lbl0062)。同时，定义标记 μUF 可达的方式数量。该问题被解释为数字炸弹触发以及恶意代码触发的现有条件数量的定义。

$\\left\\{ \\,\\,\\,\\,\\,\\,\\,\\begin{matrix} {\\mathit{\\mu}\_{1}^{\\mathit{H}\\Pi\\mathit{B}} = \\mathit{\\mu}\_{1} + \\underset{i = 1}{\\overset{m}{\\Sigma}}{\\mathit{x}\_{i}}\_{\\,}(\\mathit{O}\\,({\\mathit{t}\_{i},}\_{}\\mathit{p}\_{1}) - I\\,(\\mathit{t}\_{i}\\,{,\\,\\mathit{p}}\_{1}\\,\\,))} \\\\ {\\mathit{\\mu}\_{2}^{\\mathit{H}\\Pi\\mathit{B}} = \\mathit{\\mu}\_{2} + \\underset{i = 1}{\\overset{m}{\\Sigma}}{\\mathit{x}\_{i}}\_{}\\,(\\mathit{O}\\,({\\mathit{t}\_{i},}\_{}\\mathit{p}\_{2}) - I\\,({\\mathit{t}\_{i,}}\_{}\\mathit{p}\_{2}\\,))} \\\\ \\ldots \\\\ {\\mathit{\\mu}\_{\\mathit{n}}^{\\mathit{H}\\Pi\\mathit{B}} = \\mathit{\\mu}\_{\\mathit{n}}+\\underset{i = 1}{\\overset{m}{\\Sigma}}{\\mathit{x}\_{i}}\_{\\,}(\\mathit{O}\\,(\\mathit{t}\_{i},\\mathit{p}\_{\\mathit{n}}) - I({\\mathit{t}\_{i,}}\_{}\\mathit{p}\_{\\mathit{n}}\\,))} \\\\ \\end{matrix} \\right.$ (1.10)

寻找 x = (x[1], X[2],.., x[m])^T，其中 x > 0, x ∈ E。

##### 持久性

给定 *Petri网* 的持久性问题，证明标记

$\\underset{i = 1}{\\overset{n}{\\Sigma}}{\\mu\_{\\mathit{i}}}\_{} = \\mathit{c}\\mathit{o}\\mathit{n}\\mathit{s}\\mathit{t}.$ (1.11)

**定义 1.1**。如果对 ∀ $\\overset{\\rightarrow}{\\mu} \\in \\,\\mathit{R}\\,({\\overset{\\rightarrow}{\\mu}}\_{0}\\,)$ 标记 *Σ*[*i* = 1 ]^(*n*)*μ*[*i*] = const.，则称该 *Petri网* 为*持久的*。该问题被解释为进程无死锁。

##### 活性

给定转移子集 T' ∈ *T* 的转移活性问题，定义从初始标记 *M*[0] 出发，子集 *T'* 中的转移是否稳定。

寻找标记 $\\overset{\\rightarrow}{\\mu} \\in \\mathit{R}({\\overset{\\rightarrow}{\\mu}}\_{0}\\,)$，其中 t[i] 为死锁。

**定义 1.2**。如果在 *Petri网* 中存在可达标记 $\\overset{\\rightarrow}{\\mu} \\in \\mathit{R}({\\overset{\\rightarrow}{\\mu}}\_{0})$ 产生该转移，则转移 *t*[i] ∈ *T* 具有**1**级活性，称为潜在活跃（存活）。

**定义 1.3**。如果对于 *Petri网* 中任意自然数 *s* ∈ *N*，都存在转移触发序列 *P*[l] (*l* ∈ *N*)，其中 *t[i]* 至少出现 *s* 次，则转移 *t[i]* ∈ *T* 具有**2**级活性。

**定义 1.4**。标记被称为 *t[i]*\-死锁 (*t[i]*2 *T*)，其中对于标记 $\\overset{\\rightarrow}{\\mu}$，转移 *t[i]* 是潜在死转移（*活性级别为* **0**）。

#### 安全性

位置 *p[i]* ∈ *P* 的位置安全性问题，定义位置 *p[i]* 是否安全。

**定义 1.5**。如果对 ∀ $\\overset{\\rightarrow}{\\mu} \\in \\mathit{R}({\\overset{\\rightarrow}{\\mu}}\_{0}\\,)$ 满足条件 *μ[j]* ≤ *k* （对于某个固定值 *k* ∈ {1,2,3,...}），则 *Petri网* 中的位置 *p[j]* ∈ *P* 称为 *k*\-受限的。

**1** \- 受限位置称为安全的。

该问题对应于每个动作 *k* = 1 时的明确控制转移。
