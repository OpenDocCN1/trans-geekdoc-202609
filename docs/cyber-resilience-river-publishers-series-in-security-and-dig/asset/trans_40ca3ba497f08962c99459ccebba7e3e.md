
目前，技术先进的公司正积极关注区块链技术，并准备将其应用于统一会计登记簿、报告、投票系统和民意调查、公证文件、货物通关（例如在海关文件层面）、政府资助和多边服务等各个领域。然而，鲜有真实案例能证实该技术的可行性，但关于其应用前景的讨论却多得多。到处都在成立工作组研究区块链技术，包括解决网络韧性问题，立法者正在准备其法律基础。

### 机器人技术

第六大趋势是机器人技术，根据牛津大学的卡尔·弗雷和迈克尔·奥斯本的说法，这意味着“系统或任务自动化达到这样一个程度：对人力的需求消失，并被其自动化版本所取代”[34, 50, 133]。机器人技术的科学基础是神经生物学和生物信息学、人工智能和高性能计算、神经形态和认知形态技术、遗传算法、神经工程及其他学科。特别是，目前的重点是设计虚拟世界与物理世界之间的接口（Virtual-to-Physical/V2P 或 Online-to-Offline/O2O），这些接口能够成倍增加由人工智能发展创造的新可能性。

根据 `ISO 8373: 2012`，机器人被理解为一种驱动机构，在两个或更多轴上编程，具有一定程度的自主性，在其工作环境中移动并执行预定任务。此外，任何执行预定动作、同时满足以下三个条件的装置（机构）均可称为机器人：

*   **感知（SENSE）**：通过传感器、麦克风、摄像头（电磁频谱的所有区域）、各种机电传感器等感知周围世界，可在此角色中发挥作用；
*   **思考（THINK）**：理解周围的物理世界并建立行为模型以执行预定动作；
*   **行动（ACT）**：以某种方式影响物理世界。

机器人技术发展有两大主要领域：工业机器人和服务机器人。

**工业机器人**正在增长（年均增长**15%**），主要得益于中国的快速经济机器人化。工业机器人市场增长率领先于全球**GDP**增长率：2011年至2016年间，工业机器人销售的年均增长率为**12%**。2016年售出29.4万台工业机器人，市场总量达到131亿美元（含软件和集成服务，市场规模超过**400亿美元**）。

**服务机器人**主要实现服务经济流程的自动化，这是全球经济的重要组成部分。因此，与工业机器人相比，服务机器人显示出更大的增长（年均**25%**），尽管其绝对数字相对较小。例如，2015年售出4.8万台专业服务机器人，2016年这一数字增长**24%**，达到**5.9**万台。专业服务机器人市场总量达到**47**亿美元。值得注意的是，俄罗斯的机器人技术发展趋势与西方相似。俄罗斯在服务机器人领域拥有良好潜力：该国工业与服务机器人的比例为1:10。一些公司，例如 `ExoAtlet` 和 `CyberTech Labs`，已进入世界市场并成功与外国机器人制造商竞争。按绝对销量计算，主要销售用于物流（~2.5万台）、军事应用（~1.1万台）、商业空间（~7千台）、田间作业和外骨骼（各~6千台）的机器人。

服务机器人发展的优先领域包括：

*   物流系统（含室内物流、室外无人及空运配送车辆）；
*   客户服务机器人；
*   工业外骨骼；
*   家务机器人（个人助理）。

预计物流机器人投资可快速收回成本，假设其每天使用24小时。根据 `IFR` 估算，在美国，考虑到机器人15年的使用寿命，投资平均在两到三年内收回。根据 `McKinsey` 研究，主要由于室外无人配送车辆领域的 `B2C` 业务，发达国家增长7-10%，发展中国家增长300%。如今，无人机和城市货物配送自主平台应用最为广泛。

投资客户服务机器人开发的相关性由以下因素决定：

*   大规模服务个性化战略；
*   人力资源成本；
*   客户服务市场的数字化程度和竞争水平；
*   应用机器学习和机器人技术分析客户行为；
*   人员职能变化；
*   推广服务机器人的知名倡议和成果，特别是在日本和中国。

此类机器人实施的主要困难在于客户期望过高和人工智能能力被夸大。除了市场挑战，行业还面临技术挑战。这些问题大多源于机器人与人类的交互，以及安全性和标准问题。

外骨骼的主要任务包括在国防、救援和紧急情况下拓展人类能力。通常，机械外骨骼被理解为一种具有明显拟人特性的主动机械装置，适合穿戴者的尺寸，并由操作员动作协调控制。应注意到机器人技术发展的总体特征，即大规模服务和生产的个性化（定制化），这催生了客户服务和生产的各种新组织形式，并降低了行业内机器人实施的总体成本，从而提高了后者的盈利能力并降低了行业准入门槛。根据 `Barclays Research`，机器人执行工作的平均成本为每小时6欧元。人类执行类似工作的成本在不同国家和地区估算不同：德国为40欧元，美国为12欧元，东欧为11欧元，中国为9欧元。同时，更成功的组织形式的区别不在于引入的机器人数量，而在于机器人与人类在高度非确定性环境中最优的交互方案。机器云学习使机器人适合开箱即用地执行任务，无需昂贵的程序员/调试工程师团队劳动。成本降低使得此前无法雇佣昂贵集成和维护工程师的中小企业开始实施机器人。根据 `Barclays Research`，到2022年，平均协作机器人成本将低于**20,000美元**。

利用大数据分析和机器学习提升机器人性能的技术和产品正在涌现。例如，使用 Amazon `AWS Greengrass service`，机器人可以根据其他机器人的经验学习如何以最佳方式执行任务。有些公司免费将机器人部署在客户现场，仅按机器人工作时间收费（机器人即服务或即用即付）。根据 `International Data Corporation (IDC)` 预测，到2019年，**30%**的专业服务机器人将按此模式运行。
