
## 系统模型与状态空间定义

*p**r**d*[1]^((*c*)) = {*p**r**d*[1[1]]^((*c*)),*p**r**d*[1[2]]^((*c*)),...,*p**r**d*[1*g*[1]]^((*c*))}, *g* ∈ *N*[2] 是被动流量扫描（输出信号）值的集合，用于识别某些基础设施对象的状态；*V*[1]  = {*V*[1[1]]^((*c*))(*t*),*V*[1[2]]^((*c*))(*t*),...,*V*[1*d*[1]]^((*c*))(*t*)}, *d* ∈ *N*[2] 是受保护基础设施对象在监控期间的状态空间；*F*^((c)) —— 转移算子，反映受保护基础设施对象在内部和外部网络攻击作用下状态变化的机制；*Φ*^((c)) —— 输出算子，描述受保护基础设施对象对内部和外部干扰产生输出信号响应的机制；*T*[1]^((*c*)) = {*T*[1[1]]^((*c*)),*T*[1[2]]^((*c*)),...,*T*[*i**p*[1]]^((*c*))}, *p*[1] ∈ *N*[2] 是由监控结果和建立受保护基础设施对象被动扫描真值而形成的值的集合。

受保护基础设施设备和用户属性在被动监控会话期间变化动态的过程结构 $t \\in \\left\\lbrack t\_{i}\\,,t\_{i} + \\vartriangle\_{i}\\,),i = \\overline{1,m})\\,, \\right.$ 我们将以映射链的形式表示：

*R*⟨*χ*[*B*^((1)), *B*^((2))](*t*),*χ*[*B*^((3))](*t*)⟩→,*R*⟨*B*[*t*]^((1)),*B*[*t*]^((2)),*B*[*t*]^((3))⟩,*R*⟨*B*[*t*]^((1)),*B*[*t*]^((2)),*B*[*t*]^((3))⟩→*B*[*t*]^((3)),*R*⟨*B*[*t*]^((1)),*B*[*t*]^((2)),*B*[*t*]^((3))⟩*B*[*t*]^((1)),*B*[*t*]^((2)),*B*[*t*]^((1)),*B*[*t*]^((2)),

*R*⟨*χ*[*B*^((1)), *B*^((2))] (*t*),*χ*[*B*^((3))] (*t*)⟩→*χ*[*B*^((1)), *B*^((2))](*t*);*B*[*t*]^((3))→*χ*[*B*^((3))](*t*) , 其中 *x*[(.)](t) − 设备、用户和受控检测系统 /*κ**A* 的状态； *R* < *x*[(.)], *x*[(.)]\> *R*⟨*x*[(.)],*x*[(.)]⟩ —— 状态间的连接；*R*⟨*B*[*t*]^((1)), *B*[*t*]^((2)), *B*[*t*]^((3)), —— 设备、用户和网络攻击检测系统传感器之间的连接，它们随时间变化并刻画上述受保护基础设施对象监控过程。

算子实现映射：

```
*F*^((*c*)) : *T*[*i*]^((*c*))×*P**r**s*[*i*]^((*c*))×*V*[*i**d*[1]]^((*c*))(*t*)→*V*[][*i*](3.2)
```

```
*Φ*^((*c*)) : *T*[*i*][]^((*c*))×*P**r**s*[*i*][]^((*c*))×*V*[*i*][*d*[1]]^((*c*))(*t*)→*P**r**d*[*i*]^((*c*))(3.3)
```

受保护基础设施对象的每个状态 *V*[*i*] 在每个时刻 *t* ∈ *T* 都由一组变量 *V*[*i**d*]^((*c*)), *d* ∈ *N*[*a*] 刻画，这些变量在网络入侵者攻击和内部干扰（例如系统和/或应用软件的组件漏洞）的影响下发生变化。

因此，在对观测处理方法 *u*(*t*) ∈ *U*[add,]、处理信息流强度 ((*λ*[1] ≤ *λ* (*t*)≤ *λ*[2]))、存储的受保护基础设施用户和设备信息量 (*V*[1] ≤ *V*(*t*) ≤ *V*[2])、收集基础设施用户和设备信息的总时间 ($\\left( \\min\_{\\mathit{d}\_{\\mathit{i}} \\in \\,\\mathit{D}\_{\\mathit{\\pi}on}}\\sum\_{i = 1}^{\\mathit{k}}\\, T\_{i}\\,\\left( d\_{i}^{c6} \\right) \\right)$) 等限制条件下，需要求解：

*   状态识别与控制泛函 \[34\]，用于在缺乏时间可观测性或受保护基础设施对象部分可观测性的复杂动态系统中：ε: *T* x *Prs* x *V* →*Prd*, *Φ*:*Prd* →*T*, *φ*: *Prd* → *T*mon, *k*:*T* →*Prd*[set,] *γ*:*T*→*T*mon, *i*:*T*mon→ *Prd*[set]；
*   网络（节点）网络攻击传感器的管理律，它能保证收集受保护基础设施对象监控数据的总时间不超过指令值，同时满足管理程序接受域和确保所需网络弹性的可能行动列表的限制。

```
$\\mathit{u}^{\*}(\\mathit{t}) = \\arg\\limits\_{\\underset{d\_{i} \\in \\{ D^{\\partial}\\}}{u{{(t)} \\in {\\{ U^{\\partial}(\\mathit{t})\\}}}}}\\left( \\underset{i = 1}{\\overset{k}{\\Sigma}}\\mathit{T}(\\mathit{u}(\\mathit{t}),\\mathit{d}\_{i}^{c6}) \\leq \\mathit{T}\_{\\Sigma}^{\\partial} \\right),\\left\\{ \\mathit{U}^{\\partial}(\\mathit{t}) \\right\\}=\\,\\mathit{u}^{\\partial}{{\\left( t \\right)|(}\\mathit{\\lambda}}\_{1} \\leq \\mathit{\\lambda}(\\mathit{t}) \\leq \\mathit{\\lambda}\_{2}\\,) \\cap (\\mathit{V}\_{1} \\leq \\mathit{V}\_{(\\mathit{t})} \\leq \\mathit{V}\_{2}) \\cap (\\mathit{N}\_{1} \\leq \\mathit{N} \\leq \\mathit{N}\_{2}).$(3.4)
```

在监控数据的二次处理中，主动对抗入侵者网络攻击并确保所需网络弹性的场景开发系统应评估 *t* = *t*[0] 时的态势，该态势由信息源状态与网络攻击系统传感器状态之间的依赖关系决定。在终止时刻，状态间的依赖关系变得不同，因此达到目标的过程可描述为依赖关系的变化：

*x*[*B*^((1)), *B*^((2))] (*t*[0]) *R*[ <  ⋅ >] *x*[*B*^((3))] (*t*[0])→*x*[*B*^((1)), *B*^((2))] (*t*[*k*]) *R*[ <  ⋅ >]*x*[*B*^((3 ))](*t*[*k*])[(3.5)](#Ch04.xhtml#bck_cap_lbl0315)

此外，从初始状态到最终状态的逻辑蕴涵与一组可能的信息动作相关联。

动作列表及其顺序由 *B*^((3)) 的行为逻辑及其设置决定。实际上，*B*^((3)) 执行控制单元的功能，准备确保所需网络弹性的某种决策。

在制定解决方案时，必须考虑所有可能导致达成目标的选择：

```
$\\mathit{P}({\\overset{\\hat{}}{\\mathit{\\tau}}}\_{req} < \\widehat{\\mathit{\\tau}} < {\\widehat{\\mathit{\\tau}}}\_{enough}) = \\mathit{P}\_{PV}\\,,$
```

其中 $\\overset{\\hat{}}{\\tau} = {\\overset{\\hat{}}{\\tau}}\_{p} + {\\overset{\\hat{}}{\\tau}}\_{pass} + {\\overset{\\hat{}}{\\tau}}\_{act} + {\\overset{\\hat{}}{\\tau}}\_{RV},\\mathit{p}\\underset{¯}{>}{\\overset{\\hat{}}{\\tau}}\_{req}\\,,$ 在可能的解决方案中决策时，应选择最优选项。

选择可能的解决方案及其背后的动作时，必须从中选择满足条件 [(3.5)](#Ch04.xhtml#cap_lbl0315) 的链。

受保护基础设施出现的信息态势由一组决策规则固定，这些规则反映了 *t* = *t*[*k*] 时 *B*^((1)), *B*^((2)), *B*^((3)) 状态之间的联系。因此，在确保受保护基础设施所需网络弹性的下一阶段，有必要根据确定潜在脆弱关键信息基础设施征兆的诊断价值来确定观测参数。

### 观测参数的选择

在关键信息基础设施的技术诊断中，用具有更大诊断价值的征兆系统来描述对象非常重要。使用非信息性特征不仅无用，而且会降低诊断过程本身的效率，干扰识别。我们假设诊断征兆价值由该征兆加入观测对象状态系统的信息显著性决定。

设有一个系统 *Pr*，它处于 *n* 种可能状态 *Pr*[*i*](*i* = 1, 2,...,*n*) 中的一种。
