

# 社会工程学与网络威胁

社会工程学是网络犯罪分子技能组合中的重要工具，*2018年俄罗斯世界杯*便证明了这一点 [5, 32–34]。在重大赛事开始前很久，网络犯罪分子就开始在群发邮件中积极利用这一话题，并创建相关的钓鱼页面（图 1.14 和 1.15）。关于彩票中奖的通知邮件，以及关于球票抽签的消息，成为这些欺诈类型之一。欺诈网页通常与真实网页非常相似：它们制作精良，甚至拥有 `SSL` 证书以增加可信度。网络骗子通过伪造官方 `FIFA` 通知来诱骗用户数据。受害者被告知安全系统已更新，因此（在封锁账户的威胁下）需要输入所有个人数据。信中的链接指向一个虚假账户，输入的信息直接落入犯罪分子手中。

在*世界杯*之前，对**11**个举办比赛城市中近**32,000**个 Wi-Fi 接入点进行了分析 [56–59]。统计了开放网络和受 `WPA2 标准` 保护的网络数量，以及它们在接入点总数中所占的百分比，方法是评估加密和认证算法。结果显示，超过**20%**的接入点使用不可靠的连接。对于犯罪分子来说，只需靠近此类接入点即可拦截流量和用户数据。约四分之三的所有接入点使用被认为最安全的 `WPA/WPA2` 加密标准。安全级别通常取决于网络所有者指定的 `WPA` 设置。破解复杂的加密密钥可能需要数年时间。此外，即使使用可靠协议（如 `WPA2`）的网络也不能被视为完全安全。上述网络易受密码攻击、密钥重置攻击等威胁（图 1.16 和 1.17）。如果在会话开始时拦截到接入点与设备之间的“握手”，就有可能拦截使用 `WPA` 加密的公共 `Wi-Fi` 热点的流量。

## 金融欺诈

2018年8月，检测到一起 APT 攻击（自2017年10月起的钓鱼活动），旨在主要从工业公司窃取资金 [[60]](#Reference.xhtml#ref0061)–[[64]](#Reference.xhtml#ref0065)。

![Figure 1.18 Typical cyber criminal techniques in the financial sector.](Images/fig00024.jpg)

**图 1.18** 金融领域典型的网络犯罪技术。

攻击者使用标准钓鱼方法，通过欺骗强迫用户打开受感染的邮件附件（图 1.18）。为此，钓鱼邮件伪装成商业报价或其他财务文件。网络犯罪分子使用合法的远程管理软件，如 `TeamViewer` 或 `Remote Manipulator System (RMS)`。结果，**400**家不同领域（生产、自然资源预招募与加工、发电等）的工业公司的**800**多台计算机被感染。

勒索软件仍然是对用户的巨大威胁。此外，出现了带有勒索要求的新型和更新型恶意软件 [6, 8, 18–20]。

### 危险的加密器

2018年8月初，在包括巴西和越南在内的20多个国家中检测到了 `KeyPass Trojan`（KeyPass 特洛伊木马）。`KeyPass` 加密了本地驱动器和受害者网络文件夹中的大部分文件（部分文件被忽略）。使用了带有32位密钥的 `AES-256` 对称加密算法（采用 `Cipher Feedback mode (CFB)` 密文反馈模式，零初始化向量）。每个文件开头最多加密 `0x500000 bytes` (~5 MB)。加密后的文件获得 `*.KEYPASS` 扩展名，并在存放文件的目录中添加了一个名为 `!!!KEYPASS_DECRYPTION_INFO!!!.txt` 的勒索要求文件。`KeyPass Trojan` 的特别之处在于“手动”控制的可能性。该 `Trojan` 允许攻击者自定义加密过程，修改加密密钥、勒索文件名称和内容、受害者标识符、加密文件扩展名以及应从加密中排除的目录列表等参数 [5, 18, 20]。

值得注意的是，`WannaCry` 疫情（图 1.19）爆发已过去近两年。已检测到针对**150**个国家的设施和公司的**75,000**多起 `WannaCry` 网络攻击。同时，该恶意软件仍然是最危险加密器中的佼佼者。

## 智能设备安全问题

如今，我们被 `smart devices`（智能设备）包围，它们是日常家用电器，如照明设备、电视、熨斗、咖啡机、温控指示器、儿童玩具，以及收集和处理住房和公用事业数据的计数器、医疗设备、监控摄像头等。智能铁路、炼油厂、城市甚至区域正在出现（图 1.20 和 1.21）。然而，这种多样性也有其缺点：智能设备越多，网络攻击面就越宽，攻击者拥有的机会就越多 [1, [65]](#Reference.xhtml#ref0066)–[[67]](#Reference.xhtml#ref0068)。由于开发标准化不足，在处理 `Internet of Things (IoT/IIoT)`（物联网/工业物联网）时，很少关注网络安全，因此更难确保智能网络系统安全。以下例子可以说明这一点。

2018年2月，`Kaspersky Lab ICS CERT` 发布了一项研究，探讨 `smart hubs`（智能中枢/智能枢纽）对网络攻击的脆弱性。中枢允许控制家中其他智能设备的工作，接收来自它们的信息，并向它们传递任务。可通过触摸屏、移动应用程序或 Web 界面进行中枢管理。如果中枢存在漏洞，可能会造成单点故障。受调查的中枢不包含任何重大漏洞，但检测到允许攻击者获得远程访问权限的逻辑错误。
