
# 设备运行条件（电源稳定性和环境参数）

| 因素 | 描述 |
| :--- | :--- |
| 影响事故损害的因素 | ― 备用反垃圾邮件服务器的可用性； |
|  | ― ISA 服务器的配置，允许在自动模式下切换到备用反垃圾邮件服务器； |
|  | ― 在紧急情况下将反垃圾邮件服务器从数据处理链中排除的可能性（伴随服务质量的部分损失）； |
|  | ― 请求平衡技术的应用； |
|  | ― 公司是否有类似的备用设备； |

---

## 标识符：1.8 (AS-HDD)

### 场景
反垃圾邮件服务器故障，存储操作系统镜像和程序的驱动器损坏

### 受影响资源
反垃圾邮件服务器 (1)

### 影响事故概率的因素
― 设备使用寿命；
― 设备运行条件（电源稳定性和环境参数）；
― 公司网络边界内部有害影响的防护等级；
― 来自互联网的故意冲击防护等级；

### 影响事故损害的因素
― 备用反垃圾邮件服务器的可用性；
― ISA 服务器的配置，允许在自动模式下切换到备用反垃圾邮件服务器；
― 请求平衡技术的应用；
― 公司是否有类似的备用设备；

## 标识符：1.17 (PRSNL)

### 场景
IT 服务人员流失（解雇、疾病、意外）

### 受影响资源
运维人员 (1)

> **注意**：该场景不会直接导致服务连续性违规，但由于对确保连续性的所有方面（包括其他场景的发展）有重大影响，因此被视为同等关键资源。

### 影响事故损害的因素
― 合格人员储备；
