

# 因诺波利斯大学信息安全专业

目前，因诺波利斯大学在**计算机科学与工程**（安全系统与网络设计硕士专业）方向培养信息安全专家。该专业基于**阿姆斯特丹大学的“系统与网络工程”专业**，并聚焦于信息安全。2013年，它被评为**荷兰**最佳IT硕士专业（Keuzegids Masters 2013），2015年荣获最佳教育专业奖（Keuzegids Masters 2015）。阿姆斯特丹大学是因诺波利斯大学的合作伙伴之一，并位列世界前50名大学（QS世界大学排名，2014/2015）。

该专业的一项基本特色是，因诺波利斯大学的学生从学习伊始即参与相关的研究和科技项目。在解决计算机安全任务时，学生可利用因诺波利斯大学从事先进IT研发的**3个研究所、14个研究实验室和5个研究中心**的科技潜力。这种合作伙伴关系还延伸至因诺波利斯大学的教学科研师资队伍，汇聚了**100多位世界级专家**。因诺波利斯大学的信息安全教育符合**国家高等职业教育标准 075 5000“信息安全”**规定的核心课程要求，涵盖以下学位方向：**计算机安全**、**信息安全组织与技术**、**复杂软件安全**、**自动化系统综合信息安全**以及**电信系统信息安全**。同时，高度重视具有高工业相关性的实际安全问题；然而，鉴于这些需求的相对新颖性，它们在大多数俄罗斯大学和专业的课程中仍未得到充分解决。这些问题包括：

- 基于开创性认知技术的计算机应急响应小组（CERT）；
- 可信认知超级计算机与超高性能技术；
- 自适应安全架构技术；
- 基于大数据与流处理的智能信息安全保障技术（**大数据** + **ETL**）；
- 可信设备网状网技术与先进系统架构；
- 软件定义网络技术（**SDN**）与网络功能虚拟化（**NFV**）；
- 硬件安全模块技术（**HSM**）；
- 可信**云**与**雾**计算、虚拟域；
- **5G和6G**代安全移动技术；
- 国家及国际网络演练的组织与实施；
- 自动化态势与对手行为建模技术（**战争博弈/WarGaming**）；
- 程序代码动态分析与分析验证技术；
- 用于数据传输的**量子技术**等。

本书《网络韧性》现行版由**谢尔盖·彼得连科**撰写，他是工学博士、因诺波利斯大学信息安全中心主任。该作者的工作对建立计算机与数据安全技术领域高素质人才的国家培训体系做出了重大贡献。本书阐述了在国际层面培养高素质专家以及建立坚实科学基础（这是有效应用网络韧性技术的前提）的责任观念。

## 致读者

**二十一世纪**伊始是全球安全最为戏剧性的时期之一，因为地球进入了和平秩序被打破、整个**威斯特伐利亚体系**面临崩塌的地带。

在社会成因、人为成因和环境威胁的层级中，信息成因的叙事地位急剧上升。这反映在国际（**联合国、欧洲安全与合作组织、独联体、上海合作组织等**）和国内层面的诸多文件中。确实，全世界都在进行一场前所未有的**技术革命**。半个多世纪以来，**信息通信技术（ICT）**一直在推动这一现象。技术最初纯粹是一个技术领域，但已转变为地缘政治竞争的关键因素，因为它们创造了无可争议的积极优势，同时也给文明的所有层面带来了威胁。

最直观的例证体现在**《俄罗斯联邦国家安全战略》（2015年）**中：“日益增长的对全球信息空间对抗的影响，正日益作用于国际局势的性质，这种对抗是由某些国家利用信息通信技术实现其地缘政治目标的愿望所引起的……”

这一论断在**《俄罗斯联邦信息安全学说》（2016年）**中得到具体化：“国家和公共安全领域的信息安全状况，其特点是针对关键信息基础设施对象的网络攻击在复杂性、规模和协调性上持续增加，针对俄罗斯联邦的情报活动日益增强，以及利用信息技术损害俄罗斯联邦主权、领土完整、政治和社会稳定的威胁日益增长。”

该领域最重要的威胁是敌对使用信息通信技术针对关键基础设施的可能性，尤其是在向第六技术阶段过渡的过程中。个人、团体和组织（包括犯罪分子）作为中介卷入在线颠覆活动。利用信息通信技术进行**“数字圣战”**的恐怖主义企图正逐渐升级。

2013年，**北约**制定了**《塔林手册》**，阐述国际法如何适用于网络冲突和网络战。2017年2月，出版了第二版，更全面地将网络空间军事化合法化。

在**网络战**中，特殊的困难在于可靠地理解计算机攻击的动机和威胁来源（国家机构、黑客社区、个人），这对于根据**《联合国宪章》第51条**确立自卫资格具有根本重要性。

俄罗斯坚持信息圈冲突预防概念。俄罗斯的立场反映在**上海合作组织（SCO）**的著名倡议——**《国际信息安全行为准则》**中，该文件于2015年由联合国秘书长作为正式文件分发。该文件供其他国家加入。目前，此类法规的主要起草工作正在**联合国国际信息安全政府专家组（GGE/IIB）2016-2017**中进行，该专家组根据**联合国大会第A/70/237号决议**“国际安全背景下信息和电信领域的发展”设立。

在**政府专家组**会议期间（纽约，8月29日—9月2日），俄罗斯分发了**联合国大会**决议草案概念**“国际安全背景下网络空间负责任的国家行为”**。
