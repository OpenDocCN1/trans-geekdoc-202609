
# 系统概况与符号定义

我们称该系统为**概况系统**，每个状态称为一个**概况**。受保护基础设施在离散时间点的不同状态由一组标准（概况）表示，而概况数量的选择由研究目标决定。对 `Pr` 系统状态的识别通过监控与其相关的系统——**符号系统**来进行。我们将用两个符号之一或二进制数（0 和 1）表示的调查结果称为**简单属性**。

从信息论的角度来看，简单特征可视为具有两种可能状态的系统。若 `k[j]` 为简单符号，则其两种状态分别用 `k[j]`（符号存在）和 ${\overline{\mathit{k}}}_{j}$（符号不存在）表示。简单符号可指示某区间内被测 PST 的存在或不存在；也可具有定性性质（如检测结果的阳性或阴性等）。

二进制符号（`m = 2`）具有两种可能状态。二进制符号 `kL` 的状态用 `*k[j1]*` 和 `*k[j2]*` 表示。例如，设符号 `*k[j]*` 与 PST `x` 的测量相关，为其建立两个诊断区间：`x ≤ 10` 和 `x > 0`。则 `*k[j1]*` 对应 `x ≤ 10`，`*k[j2]*` 表示 `x > 10`。这些状态是互斥的，因为只有一个会被实现。

显然，二进制符号可用简单符号 `k[j]` 替代，令 `*k[j1] = k[j]`，`k[j2]*` = ${\overline{\mathit{k}}}_{\mathit{j}}$。

若调查检测到对象的符号 `kj` 取值为 `*k[js,]*`，则称该值为符号 `k[j]` 的**实现**。用 `*k*[*j*]^(\*)` 表示，则有 `*k*[*j*]^(\*)` = `*k*[*j*[*s*]]`。

作为符号 `k[j]` 实现对诊断 `Pr[i]` 的**诊断权重**，我们取

$$
\mathit{Z}_{\mathit{P}\mathit{r}_{i}}\,(K_{j}^{\*}) = \mathit{Z}_{\mathit{P}\mathit{r}_{i}}\,(\mathit{k}_{j_{s}}) = \log_{2}\,\frac{\mathit{P}\left( \frac{\mathit{P}_{{\mathit{r}_{i}}{}}}{\mathit{k}_{j_{s}}} \right)}{\mathit{P}(\mathit{P}_{\mathit{r}_{i}})} \tag{3.6}
$$

其中 $\mathit{P}\left( \frac{\mathit{P}\mathit{r}_{\mathit{i}}}{\mathit{k}_{j_{s}}} \right)$ 为符号 `k[j]` 取得值 `*k[jS]*` 条件下的概况 `Pr[i]` 概率；`P(Pr[i])` 为先验概况概率。

值 `*Z*[*P**r*[*i*]](*k*[*j*[*s*]])` 在信息论著作 [76] 中被称为“信息价值”。从信息论角度看，量 `*Z*[*P**r*[*i*]](*k*[*j*[*s*]])` 是符号状态 `*k[js]*` 所包含的关于状态 `Pr[i]` 的信息。某个符号实现的诊断权重尚不能说明该检查对该符号的诊断价值。因此，在简单符号调查中，可能其取值无诊断权重，而其缺失对确定受保护基础设施对象的概况却极为重要。

我们将 `m` 位符号 `k[j]` 对概况 `Pr[i]` 的**诊断调查价值**视为 `k[j]` 符号的所有实现向概况 `Pr[i]` 提供的信息量：

$$
\mathit{Z}_{\mathit{P}\mathit{r}_{i}}(\mathit{k}_{j}) = \underset{\mathit{s} = 1}{\overset{\mathit{m}}{\Sigma}}\mathit{P}\left( \frac{\mathit{k}_{js}}{\mathit{P}{\mathit{r}_{i}}{}} \right)\mathit{Z}_{\mathit{P}\mathit{r}_{i}}(\mathit{k}_{js}) \tag{3.7}
$$

诊断调查价值考虑了符号的所有可能实现，代表单个实现贡献信息量的期望。由于 `*Z[Pri]*(*k[j]*)` 仅针对单一概况 `Pr[i]`，我们称其为基于 `k[j]` 符号的**私有诊断调查价值**。`*Z[Pri]*(*k[j]*)` 确定独立诊断调查价值，这是调查首次进行或其他调查结果未知时的情形特征。为便于后续计算，将 `*Z[Pri]*(*k[j]*)` 写为：

$$
\mathit{Z}_{\mathit{P}\mathit{r}_{i}}(\mathit{k}_{j}) = \underset{\mathit{s} = 1}{\overset{\mathit{m}}{\Sigma}}\mathit{P}\left( \frac{\mathit{k}_{js}}{\mathit{P}{\mathit{r}_{i}}{}} \right){\,\log}_{2}\left\lbrack \frac{\mathit{P}\left( \frac{\mathit{P}\mathit{r}_{i}}{\mathit{k}_{js}} \right)}{\mathit{P}(\mathit{P}{\mathit{r}_{i}}{})} \right\rbrack \tag{3.8}
$$

生成的属性空间允许识别和分类受保护基础设施潜在脆弱状态的症状，确定用于通信的网络流量参数，以及受保护基础设施对象的行为概况（具有典型交互宏参数）。

下面进一步考虑确定受保护对象基础设施脆弱状态诊断符号权重的过程。

## 参考行为概况

我们区分由违规者攻击效应引起的受保护基础设施三种不同对象状态（概况）：
- `*Pr*[1]`：表征因未知零日漏洞导致的脆弱状况的概况；
- `*Pr*[2]`：表征因防护手段配置导致的脆弱状态的概况；
- `*Pr*[3]`：表征因已知漏洞影响导致的脆弱状况的概况。

概况分析依据九个简单非特异性特征进行：
1. `TCP` 的字节频率 (`k*[1]*`)
2. `UDP` 的字节频率 (`k*[2]*`)
3. 哈希值 (`k*[3]*`)
4. 基于偏移字节的哈希值 (`k*[4]*`)
5. 基于数据包中重复的前 **4** 字节 (`k*[5]*`)
6. 前 **4** 个数据包前 **16** 字节对的哈希值 (`k*[6]*`)
7. 单向前四个数据包的长度 (`k*[7]*`)
8. 服务器到客户端首个数据包的半字节数 (`k*[8]*`)
9. 重复字节对 (`k*[9]*`)

例如，在受保护基础设施的 **450** 个网络节点中，**414** 个节点（无已知漏洞）被诊断为功能状态；在受入侵者攻击的 **36** 个被调查节点中，**10** 个处于第一脆弱状态，**12** 个处于第二，**14** 个处于第三。按特征进行的概况分析结果见 [表 3.11](#Ch04.xhtml#cap_lbl0319)。注：第一概况的特征是第一行至少有两个阴影方格（1）且其余行至少有两个白方格（0）等。特征出现频率作为其概率。

例如，对第一个符号（特征 `k[1]` 存在，不存在为 `*k*[1]`）：
$\mathit{P}\left( \frac{\mathit{k}_{1}}{\mathit{P}_{\mathit{r}_{1}}} \right) = \frac{8}{10} = 0.8;\mathit{P}\left( \frac{\mathit{k}_{1}}{\mathit{P}_{\mathit{r}_{1}}} \right) = \frac{8}{10} = 0.80;\mathit{P}\left( \frac{\mathit{k}_{1}}{\mathit{P}_{\mathit{r}_{2}}} \right) = \frac{3}{12} = 0.25;$ $\mathit{P}\left( \frac{\mathit{k}_{1}}{\mathit{P}_{\mathit{r}_{3}}} \right) = \frac{5}{14} = 0.357;\mathit{P}(\mathit{k}_{1}) = \frac{16}{36} = 0.444.$

然后，利用表达式 [(3.7)](#Ch04.xhtml#cap_lbl0317) 确定特征的独立诊断实现权重，利用等式 [(3.8)](#Ch04.xhtml#cap_lbl0318) 确定独立诊断调查价值。

计算结果见 [表 3.12](#Ch04.xhtml#cap_lbl0320)。对 `*Pr*[1]` 概况，`*k*[1]*`、`*k*[2]*`、`*k*[3]` 特征的调查诊断性最强；对 `*profile Pr*[2]` *– 由 `*k*[4]*`、`*k*[5]*`、`*k*[6]` 决定；对 `*profile Pr*[3]` – 由 `*k*[7]`、`*k*[8]`、`*k*[9]` 符号决定。对于整个概况系统，诊断调查结果值变化不大。
