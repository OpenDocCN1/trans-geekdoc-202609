# Risk-assessment process

The risk-assessment process identifies critical risk elements, and some examples are as follows:

+   1 Data classification.
+   2 Strategic/business requirements.
+   3 Application development.
+   4 Vendor relationships.
+   5 Technology landscape.
+   6 Legal/regulatory issues.
+   7 Brand/reputational issues.
+   8 Operational issues.
+   9 Financial issues.
+   10 Security and fraud issues.
