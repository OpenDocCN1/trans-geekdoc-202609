NIST SP 800–26, Security Self-Assessment Guide for Information Technology Systems, defines maturity levels for various aspects of an IT security programme:

+   - Level 1 – Control objectives have been documented in a security policy.
+   - Level 2 – Security controls have been documented as procedures.
+   - Level 3 – Procedures have been implemented.
+   - Level 4 – Procedures and security controls have been tested and reviewed.
+   - Level 5 – Procedures and security controls have been fully integrated into a comprehensive programme.
