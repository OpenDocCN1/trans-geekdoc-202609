# Table 7.1 A sample threat risk assessment (Kisssoon, 2020).

| Threat | | Risk Level | Mitigation | Mitigation in Microsoft Teams |
|---|---|---|---|---|
| Spoofing: process, machine, person | Impersonation | High | Access control authentication | Implement multi-factor authentication (MFA) using phone calls or text messages<br>• One-time-use password<br>• Conditional access policies |
| Tampering: process, memory | Malicious code | High | Integrity permissions | Advance threat protection (ATP) |
| Repudiation: process, person | Impersonation | High | Accountability<br>Fraud prevention<br>Logging<br>Signatures | Information barriers<br>• E-discovery: logging, retention: team chats, messaging, integration with MS stream for video |
| Information disclosure in process | Malicious code<br>Data leakage | High | Confidentiality<br>Permissions<br>Encryption | Safe links<br>• Data loss prevention (DLP) |
| Information disclosure: data stores, data flows | Phishing<br>Data leakage | High | Confidentiality<br>Permissions<br>Encryption | Safe links<br>• DLP |
| Denial of service | Sabotage | High | Availability | Review cloud design |
| Elevation of privileges | Impersonation | High | Access control<br>Authorization<br>Isolation | Customize policy setting: sharing of sensitive information<br>• Information barriers |
