# Unit Testing for Models

application/libraries/Foo.php

```
<?php
class Foo {
    private $bar;
    public function __construct(Bar $bar) {
        $this->bar = $bar;
    }
    public function bar($arg) {
        return $this->bar->baz($arg);
    }
}
```

The Foo depends on the class Bar.

application/libraries/Bar.php

```
<?php
class Bar {
    public function baz($arg) {
        // Very complex logic
        // ...
        return $return;
    }
}
```
