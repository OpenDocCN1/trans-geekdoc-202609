```
return $this->db->insert('news', $data);
}
```

The set_news() method has four dependencies:

+   - $this->load (the CI_loader object)
- $url_title() function
- $this->input (the CI_Input object)
- $this->db (the CI_DB object)

The url_title() is a function defined in CodeIgniter's url helper. The $this->load->helper() method loads the URL helper file, which contains functions like url_title() to help manipulate URLs. url_title() takes an input and creates a human-friendly URL. It is a simple function and has no side-effects. So we use it as-is and don't have to mock it.

> If you really want strict testing, you could mock the function using Monkey Patching, as provided by ci-phunit-test.

# Mocks with Return Map

In the set_news() method, $this->input->post() is called three times and the return values are assigned to $data. In this situation, we can use the willReturnMap() method.

```
// Create mock object for CI_Input
$input = $this->getMockBuilder('CI_Input')
    ->disableOriginalConstructor()
    ->getMock();
// Can't use $input->method(), because CI_Input has method()
$input->expects($this->any())->method('post')
    ->willReturnMap([
        // // post($index = NULL, $xss_clean = NULL)
        ['title', null, 'News Text'],
        ['text', null, 'News Text'],
    ]);
```
