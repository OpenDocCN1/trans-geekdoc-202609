# Testing a Simple MVC Application

application/tests/controllers/Pages_test.php

```
<?php
/**
 * @group controller
 */
class Pages_test extends TestCase
{
    public function test_When_you_access_home_Then_you_see_Home()
    {
        $output = $this->request('GET', '/');
        $this->assertContains('<h1>Home</h1>', $output);
    }

    public function test_When_you_access_about_Then_you_see_About()
    {
        $output = $this->request('GET', 'about');
        $this->assertContains('<h1>About</h1>', $output);
    }

    public function test_When_you_access_notfound_Then_you_get_404()
    {
        $this->request('GET', 'notfound');
        $this->assertResponseCode(404);
    }
}
```

We also added the @group tag to tell PHPUnit this test belongs to a group named controller.

**
 * @group controller
 */

This allows us to run tests in the controller group without having to run the rest of our tests.

$ phpunit.phar --group controller

When you use $this->request(), you can use the $this->assertResponseCode() method in phpunit-test. This is an assertion method to check the response code of the request.
