The untested lines are sample code to show when users are found, but the lines are not
executed, because the users' data $users is hardcoded in the method.

If this were a real application, we would probably get the users' data from the database. In case,
we can write test code using database fixtures or a mocked model.

There is no way to inject variables like $user, we can write test code to get 100% coverage in
case. Since the controller is example, 93% is good enough.
