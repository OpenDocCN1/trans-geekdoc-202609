Create the application/data directory to hold the sqlite database file.
If you set 'dsn => 'sqlite:memory:', you can use an SQLite in-memory database.

> If you choose the database connection to the SQLite in-memory database, the database ceases to exist. ci-phpunit-test does not close it, but if you close it in your test code or application code, the database will cease to exist.
