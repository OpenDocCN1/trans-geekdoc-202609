# Checking Code Coverage

Before checking coverage, we change our whitelist to exclude files like third party libraries, so
 can focus on our application code.

```
--- a/CodeIgniter/application/tests/phpunit.xml
+++ b/CodeIgniter/application/tests/phpunit.xml
@@ -15,6 +15,11 @@
      <directory suffix=".php">../libraries</directory>
      <directory suffix=".php">../helpers</directory>
      <directory suffix=".php">../hooks</directory>
      <exclude>
+      <directory suffix=".php">../views/errors</directory>
+      <file>../controllers/Dbfixture.php</file>
+      <file>../libraries/Seeder.php</file>
+      <file>../Seeder.php</file>
      </exclude>
    </whitelist>
  </filter>
  <logging>
```

Files in ../views/errors are CodeIgniter's error page templates. ../controllers/Dbfixture.php
is is basically from CodeIgniter's User Guide, and ../libraries/Seeder.php is from ci-phpunit-test.
