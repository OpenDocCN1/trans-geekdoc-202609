# PHPUnit Basics

The test_FtoC() method has two parameters ($degree and $expected). The values in the data provider method are passed to them. The first array [-40, -40.0] is passed to the method as $degree
 = -40 and $expected = -40.0.

PHPUnit repeats the test for each array in the data provider method.

```
$ phpunit.phar libraries/Temperature_converter_test.php
PHPUnit 4.8.10 by Sebastian Bergmann and contributors.
```

...
nTime: 1.15 seconds, Memory: 12.50Mb

OK (5 tests, 5 assertions)

In the output, you should see five dots and 5 tests, 5 assertions. If you add the --debug option, you can see what is happening more clearly.

```
$ phpunit.phar --debug libraries/Temperature_converter_test.php
PHPUnit 4.8.10 by Sebastian Bergmann and contributors.
```
