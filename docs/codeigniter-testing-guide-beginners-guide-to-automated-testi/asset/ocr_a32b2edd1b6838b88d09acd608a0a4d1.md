# Creating a Mock Object for CI_Loader

First we create a mock object for CI_Loader. $this->load->database() loads the database classes and opens a connection to the database. We are going to write tests without the database, so we don't want to call the real method. We have to replace it with a mock object.

If we insist on unit testing, we have to mock all methods in CI_Loader. Since we can't load a lot of classes and other files without CI_Loader, we only mock the database() method to prevent it connecting to the database. Yes, this is not unit testing, but we are avoiding extremes, so this is not a problem.

The test case and setUp() will look like this:

```
class News_model_with_mocks extends TestCase
{
    public function setUp() {
        // Reset CodeIgniter super object
        $this->resetInstance();

        // Create mock object for CI_Loader
        $loader = $this->getMockBuilder('CI_loader')
            ->setMethods(['database'])
            ->getMock();
        $loader->method('database')->willReturn($loader);

        // Inject mock object into CodeIgniter super object
        $this->load = $loader;

        if (! class_exists('CI_DB', false)) {
            // Define CI_DB class
            eval('class CI_DB extends CI_DB_query_builder {}');
        }

        $this->obj = new News_model();
    }
}
```
