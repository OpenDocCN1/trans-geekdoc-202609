The listing above is in a format unified diff. It shows the difference between two files. In short, remove the line starting with - from the original file and add the green line starting with + to the new file. *Conventions Used in This Book* for details.

We, no longer repeat "$obj = new Temperature_converter();" for each test.

tearDown()

PHPUnit also has tearDown() method which is called after a test method is run, allowing you to clean up the environment after the test.
