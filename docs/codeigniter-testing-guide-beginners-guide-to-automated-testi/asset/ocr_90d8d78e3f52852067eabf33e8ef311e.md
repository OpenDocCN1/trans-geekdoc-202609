# Getting User's Data

If we use an ID, it returns the user's data in JSON format.

```
$ curl 'http://127.0.0.1:8000/api/example/users/id/1'
("id":"1","name":"John","email":"john@example.com","fact":"Loves coding")
```

We can write a test method like the following:

```
application/tests/controllers/api/Example_id_test.php
public function test_when_get_valid_user_id_Then_returns_the_user_data()
{
    $json = {
        "id":"1","name":"John","email":"john@example.com",
        "fact":"Loves coding"
    };

$output = $this->request('GET', 'api/example/users/id/1');
$this->assertJsonStringEqualsString($json, $output);
$this->assertResponseCode(200);
}
```

In this case, the controller does not call exit(), so we don't need the try and catch blocks.
$this->assertJsonStringEqualsString() method in PHPUnit checks whether the value of
JSON string received from the request (second argument) matches the expected JSON string
(the first argument).

Run the phpunit command, and verify that the test passes.

If there is no user with the provided ID, it returns an error message.
