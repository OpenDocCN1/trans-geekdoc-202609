# ## Running All Tests

If you run the phpunit command without arguments, PHPUnit runs all test classes. Using the --debug option shows additional information which might be of use in debugging.

```
$ cd CodeIgniter/application/tests/
$ php phpunit.phar --debug
```

> To Composer users

```
$ ./phpunit.sh --debug
```

See Creating phpunit shortcut.
