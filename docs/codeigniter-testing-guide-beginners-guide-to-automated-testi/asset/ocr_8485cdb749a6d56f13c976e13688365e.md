The default_controller setting config the controller/method used when no controller is supplied. Since we've modified the default_controller value to 'pages/view', if you access http://127.0.0.1:8000/, Codeigniter calls the Pages's view() method without passing any arguments.

The special keyword (:any) used in a route key will match a URI segment containing any character except for /. So, if you access http://127.0.0.1:8000/about, Codeigniter calls the Pages controller's view() method and passes 'about' as the first argument.
