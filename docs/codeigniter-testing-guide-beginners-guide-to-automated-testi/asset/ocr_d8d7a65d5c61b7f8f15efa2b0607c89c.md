# Testing a Simple MVC Application

```
$this->load->view('templates/header', $data);
$this->load->view('pages/$.page, $data);
$this->load->view('templates/footer', $data);
}
```

The Pages controller's view() method is automatically routed to pages/view by CodeIgniter. If you access http://127.0.0.1:8000/pages/views/home, CodeIgniter calls the Pages controller's view() method and passes $data, to the view. In the file view, you can access the value of $data['title'] by using $title.

The calls to the $this->load->view() method load a view file and pass the second argument, $data, to the view. In the file view, you can access the value of $data['title'] by using $title.

# Page Templates

The views which with templates/ are page templates, views containing the header and footer to be used by our site.

application/views/templates/header.php

```
<html>
<head>
<title>CodeIgniter Tutorial</title>
</head>
<body>
n<h1><?php echo $title; ?></h1>
```

application/views/templates/footer.php

