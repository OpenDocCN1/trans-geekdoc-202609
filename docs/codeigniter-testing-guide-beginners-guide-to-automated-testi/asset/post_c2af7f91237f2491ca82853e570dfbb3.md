
## Testing REST Controllers

curl is an open source command line tool and library for transferring data. It supports many protocols, including HTTP, HTTPS, FTP, IMAP, POP3, and SMTP.

Open your terminal, navigate to the directory where CodeIgniter's index.php is located, and run the following command.

```
php -S 127.0.0.1:8000 index.php
```

## Getting All of the Data

When we send a GET request to `api/example/users`, it returns all the users' data in JSON format. Open another terminal, and type the following command. The -X or --request option specifies the HTTP method.

```
curl -X GET 'http://127.0.0.1:8000/api/example/users'
```

You should see the following JSON output:

```
[{"id":1,"name":"John","email":"john@example.com","fact":"Loves coding"},{"id":2,"name":"Jim","email":"jim@example.com","fact":"Developed on CodeIgniter"},{"id":3,"name":"Jane","email":"jane@example.com","fact":"Lives in the USA","hobbies":["guitar","cycling"]}]}]
```

You can add the -i or --include option to see the HTTP response headers.

```
curl -X GET 'http://127.0.0.1:8000/api/example/users'
HTTP/1.1 200 OK
Host: 127.0.0.1:8000
Connection: close
X-Powered-By: PHP/5.2.26
Content-Type: application/json; charset=utf-8
```

```
[{"id":1,"name":"John","email":"john@example.com","fact":"Loves coding"},{"id":2,"name":"Jim","email":"jim@example.com","fact":"Developed on CodeIgniter"},{"id":3,"name":"Jane","email":"jane@example.com","fact":"Lives in the USA","hobbies":["guitar","cycling"]}]}]

```

We write a test class for it. The controller calls exit(), so we have to catch the CIPHUnitTestException exception.

application/tests/controllers/api/Example_test.php

```php
<?php
/**
 * @group controller
 */
class Example_test extends TestCase
{
    public function test_When_get_users_Then_returns_all_user_data()
    {
        try {
            $this->request('GET', 'api/example/users');
        } catch (CIPHUnitTestException $e) {
            $output = ob_get_clean();
        }
    }

    $data = json_decode($output, true);
    $this->assertCount(3, $data);
    $this->assertResponseCode(200);
}
}
```

The $this->request('GET', 'api/example/users') throws an exception, so we catch it. The $this->request() method has turned on output buffering to capture the output of the controller, so we get the buffer contents using PHP's ob_get_clean() function in the catch block.

The value of $output is in JSON format. We can convert it to an array using the json_decode() function in PHP. We then assert the output data has three elements, and the HTTP response code is 200 (OK).

Run the phpunit command, and verify that the test passes.

## Getting User's Data

If we use an ID, it returns the user's data in JSON format.

```
$ curl 'http://127.0.0.1:8000/api/example/users/id/1'
("id":"1","name":"John","email":"john@example.com","fact":"Loves coding")
```

We can write a test method like the following:

```php
application/tests/controllers/api/Example_id_test.php
public function test_when_get_valid_user_id_Then_returns_the_user_data()
{
    $json = {
        "id":"1","name":"John","email":"john@example.com",
        "fact":"Loves coding"
    };

$output = $this->request('GET', 'api/example/users/id/1');
$this->assertJsonStringEqualsString($json, $output);
$this->assertResponseCode(200);
}
```

In this case, the controller does not call exit(), so we don't need the try and catch blocks. $this->assertJsonStringEqualsString() method in PHPUnit checks whether the value of JSON string received from the request (second argument) matches the expected JSON string (the first argument).

Run the phpunit command, and verify that the test passes.

If there is no user with the provided ID, it returns an error message.

> *http://php.net/en/json_decode

## 9.3 Adding Headers

If you add an Accept header with the -H or --header option, you can get the response in another format.

```
$ curl -X GET -i 'http://127.0.0.1:8000/api/example/users/id/1'
-H 'Accept: application/csv'
```

```
id,name,email,fact
1,John,john@example.com,Loves coding
```

We can use $this->setHeader() method to add a request header.

```php
application/tests/controllers/api/Example_test.php
public function test_When_get_users_Then_returns_csv() {
    $this->setHeader('Accept', 'application/csv');
    $output = $this->request('GET', 'api/example/users/id/1');

    $this->assertEquals(
        'id, name, email, fact
        1,John,john@example.com,Loves coding',
        '',
        $output
    );
    $this->assertResponseCode(200);
    $this->assertResponseHeader(
        'Content-Type', 'application/csv; charset=utf-8'
    );
}
```

## 9.4 Testing POST Requests

You can send a POST request with curl, specifying the POST data with the -d or --data option. It returns the response code 201 (Created).

```
curl -X POST -i 'http://127.0.0.1:8000/api/example/users \
-d 'name=John&email=john@example.com'
```

```
HTTP/1.1 201 Created
Host: 127.0.0.1:8000
Connection: close
X-Powered-By: PHP/5.5.26
Content-Type: application/json; charset=utf-8

{"id":"100","name":"John","email":"john@example.com","message":"Added a resource"}
```

If you want to send data which needs to be urlencoded, use the --data-urlencode option instead of the -d option.
