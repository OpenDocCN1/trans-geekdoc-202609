# Our First Test

Now that we know the basics, we can write test code for our Temperature_converter class.

application/tests/libraries/Temperature_converter_test.php

```
<?php
class Temperature_converter_test extends TestCase
{
    public function test_FtoC())
    {
        $obj = new Temperature_converter();
        $actual = $obj->FtoC(100);
        $expected = 37.0;
        $this->assertEquals($expected, $actual, '', 0.01);
    }
}
```

> To CodeIgniter users
in this case, ci-phpunit autoloads the Temperature_converter library, so you don't have to call the $this->load->library() method in CodeIgniter.

$this->assertEquals() method is one of PHPUnit's assertion methods. It checks whether two values are equal. The third argument allows us to supply an error message, but we set it to an empty string to the default message. The fourth argument is the accepted delta, or difference, between the first two values which should be considered equal.
