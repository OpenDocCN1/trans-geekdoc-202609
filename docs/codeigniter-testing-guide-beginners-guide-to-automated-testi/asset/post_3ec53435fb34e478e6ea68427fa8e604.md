# Assertions

PHPUnit has many assertion methods. Here is a list of common-used assertions:

- **assertEquals($expected, $actual)** checks whether two values are equal
- **assertSame($expected, $actual)** checks whether two values are equal and the same type
- **assertTrue($condition)** checks whether a condition is true
- **assertFalse($condition)** checks whether a condition is false
- **assertNull($variable)** checks whether a variable is null
- **assertInstanceOf($expected, $actual)** checks the type of an object
- **assertCount($expected, $haystack)** checks whether the number of elements in $haystack matches $expected
- **assertRegExp($pattern, $string)** checks whether $string matches the regular expression
- **assertContains($needle, $haystack)** checks whether $needle is contained in $haystack, this method works with strings ($needle is a substring of $haystack), arrays ($needle is an element of $haystack), or classes that implement Iterator (can be called using foreach())

You can see all the assertion methods in the PHPUnit Manual*.

> Testing Tip: Use Specific Assert Methods
Using specific assert methods is a good practice, because it expresses what you want to test and you get more helpful error messages.
