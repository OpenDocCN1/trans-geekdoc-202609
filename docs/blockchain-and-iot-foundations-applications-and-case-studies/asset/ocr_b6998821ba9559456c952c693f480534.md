# ARCHITECTURE OF BLOCKCHAIN

The blockchain architecture is a collection of layers showing the functions and protocols supported by each layer [1, 2, 7, 32–34]:

+   i. Data layer: It creates the blocks and has its own information, verification, timestamp, block numbers, hash values of its predecessor, and successor nodes.

+   ii. Network layer: It makes a complete network of nodes via a peer-to-peer network with no fixed topology. Nodes can verify, transmit, route for interactions.
