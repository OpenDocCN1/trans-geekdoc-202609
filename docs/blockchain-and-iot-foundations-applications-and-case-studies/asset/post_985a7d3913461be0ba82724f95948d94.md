### Middleware

- Ethereum: It is an open-source blockchain that has smart contract functionality and is also decentralized to built and run without any interference from third party.
- Ganache: It is a tool used for creating your own blockchain environment which helps in developing, deploying, and testing decentralized apps.
- Truffle: It is mainly used framework for creating, designing, and deploying smart contracts for Ethereum.
- Visual Studio Code: It is a free editor made by Microsoft for Linux and macOS. It has numerous features including syntax highlighting, debugging, intelligent completion, and snippets.
- Node.js: It is an open environment used for development of web applications and have a library that helps in developing.
