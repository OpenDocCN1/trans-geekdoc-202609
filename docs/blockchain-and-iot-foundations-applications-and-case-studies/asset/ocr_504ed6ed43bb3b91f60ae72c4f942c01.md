# RESULT ANALYSIS

The primary aim of the research is to provide a secure system that is the most trustworthy and if the data stored in the model is dependable and cannot be changed by anyone else. This blockchain-based system makes sure that the model maintains this method. Data that stored in the model can only be changed by an authorized person. Other than that, the record data can be accessed only by doctors and patients. Doctors, patients, or any other person in the system cannot make modifications unless they access to it. This makes sure that the information is private or the record of the patient cannot be accessed by everyone and stays tamper-proof. The private details of the patient are stored and a hash is created for the stored information. This hash is now stored and used when healthcare workers and patients need it. The hash is secured cryptographically. This is used to maintain security in our proposed system.

Performance-wise, we used Apache JMeter to evaluate our system. By using JMeter we simulated 100–500 users (with a period of 10 to 35 minutes) of the system's different functions. The throughput of the JMeter is defined as Data/time, which is KB/sec units. It was observed that when the amount of requests and the users increased, there was an increase in the throughput in a linear manner. Hence, results showed that the system worked efficiently. Simulations were run on our proposed model to analyze the throughput.

When the transaction number increased, the execution time of the system increased. These transactions are for the different functions present in the smart contracts. The execution times increase when 100 users use the system at the same time.
