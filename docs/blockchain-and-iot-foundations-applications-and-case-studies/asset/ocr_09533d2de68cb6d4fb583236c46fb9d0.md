# Modules DESCRIPTION

# Faculty Module

In the faculty module, the web page is designed using the MERN stack. Details like name, gender, department, date of birth (DOB), year, and section are obtained from the created student list from the MongoDB.

The student list is displayed along the date and the faculty chooses the particular department, year, and section to mark the attendance. The faculty is able to view the attendance status that they marked by the date.

# Admin Module

In the admin module, the web page is designed using the MERN stack. Details like name, gender, department, DOB, year, and section are stored in the MongoDB database. The admin can create the student list and manipulate the list. Faculty cannot modify the content of the student list. The status of the marked attendance is checked and maintained in the MongoDB database.

The report of the attendance is generated and can be downloaded in the CSV format.
