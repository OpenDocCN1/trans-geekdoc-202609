## 区块链的基本概念

构建稳健的合规网络安全应用需要对底层技术有基本的了解，在本例中即区块链技术。本节深入概述了区块链的架构，标志着去中心化、加密哈希的必要性，以及不可篡改性和透明度标准，这些特性将区块链确立为一项革命性技术。

## 区块链架构与核心原则

去中心化是区块链所提供功能的核心。这一特性有助于将数据存储在区块中。出于优化原因，每个区块会等待足够的数据，并打包大量数据（例如打包多笔交易），然后才完成区块并将其广播到区块链网络。这种架构不同于传统的中心化系统。如[图 1](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor048)所示，典型的区块链区块包含一个区块头（带有时间戳）、要存储的实际数据（例如一组或一批交易）以及前一个区块的加密哈希值。区块相互连接形成一条链。网络参与者（称为节点）验证区块。节点确保数据不可变且无法被篡改（[Tripathi 等，2023](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor122)）。

加密通常使用两种类型的密钥——公钥和私钥。这些密钥有助于在区块链网络中的节点之间实现安全通信。公钥通常用于生成地址，地址是发送和接收资金的唯一标识符。私钥用于批准并对交易进行数字签名。

例如，假设 A 方想向 B 方发送 1 个比特币（`BTC`）。A 方使用其私钥对一笔交易进行签名，指定接收方地址和他想要发送的 `BTC` 数量。A 方签署交易后，该交易会被广播到比特币网络。网络随后验证该交易并将其添加到区块链账本中。一旦添加，即被视为永久性记录，无法撤销。因此，当一个人想要创建加密货币交易时，他会使用私钥对交易进行签名。这证明了资金所有者已授权该交易，且该交易将分发给网络中的所有节点。

矿工（指网络节点组）将这些交易打包进一个区块并加上时间戳。然后使用共识机制挖掘该区块，并将其集成到网络中。[图 2](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor049) 展示了区块链的工作流程。

## 共识协议

共识协议是在分布式网络中运行的算法。这些算法帮助所有节点达成一致，达到共同的状态或决策。这对去中心化进程至关重要，主要有三个原因：

*   确保数据完整性并防止双重支付，这在加密货币相关实现中至关重要。
*   维护分布式数据库的一致性。
*   实现多个节点之间的可靠通信与协调。

节点是实施共识协议的关键组件。节点可以向区块链添加新数据，同时保持先前数据不变。节点确保区块链保持安全、加密、一致且最新，并为进一步研究提供支持。此外，它们验证交易，确保一切井然有序（Kaur 等，2021）。尽管约有 58 种共识算法在运行（[Singh 等，2022](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor118)），但[表 1](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor050) 列举了著名共识协议及其节点机制的概况。[表 2](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor051) 展示了节点扮演的各种角色。研究表明，共识协议对于维护区块链的完整性和安全性至关重要。长期未升级或未优化的旧版本算法将成为瓶颈，导致高延迟，正如在公共区块链网络中所见。这阻碍了应用在实时环境中的部署（[Taylor 等，2020](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor121)）。多项研究（[Xiao 等，2020](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor127)；[Kaur & Gupta，2021](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor096)；[Oyinloye 等，2021](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor105)；[Singh 等，2022](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor118)；[Xu 等，2023](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor128)）致力于共识协议、其优化以及寻找合适的替代方案。

### 表 1. 共识协议及其机制

| 共识协议名称 | 节点机制 |
| --- | --- |
| 工作量证明（`PoW`） | 节点相互竞争以解决复杂的数学问题。获胜节点将获得授权交易并在区块链中创建新区块的权力。 |
| 权益证明（`PoS`） | 节点根据需求用于验证交易和创建新区块。然而，这一权力是基于其持有的加密货币数量授予的。 |
| 实用拜占庭容错（`PBFT`） | 它使用固定数量的节点达成一致。即使发现某些节点是恶意的或已失效，节点仍会被选中。 |
| `Raft` | 一种无领导者的共识协议，利用大多数节点达成共识。 |
| `Paxos` | 一种为分布式系统设计的共识协议，其中节点可能失效或经历延迟。 |
| 委托权益证明（`DPoS`） | 只有少数节点通过投票过程被选为验证者，并拥有更高的机会获得添加节点的权力。 |
