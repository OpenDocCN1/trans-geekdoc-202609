# 无声的威胁：利用智能检测防范基于PDF的恶意软件

**Ravi Kirtivadan Sheth**

**Chandresh D. Parekha**

[![Orcid Image](image/orcid-logo1.png) `https://orcid.org/0009-0002-6722-9224`](https://orcid.org/0009-0002-6722-9224)

Rashtriya Raksha University, India

## 摘要

鉴于当今世界在个人和商业关系中充斥着PDF文件，这些看似无害的文档内部潜藏的恶意活动危险已急剧上升。多年来，对互联网安全构成重大威胁的是已知的PDF恶意软件。PDF恶意软件构成了一个大问题，因为它可以隐藏在PDF文件复杂的结构之中。这些文件可以包含多种类型的内容，包括文本、图像和隐藏对象。这些复杂性为黑客提供了更多机会，隐藏其绕过传统杀毒软件的恶意代码。本章的目标是开发一种基于分类的机器学习算法来检测PDF恶意软件，并通过使用随机森林分类器，取得了令人印象深刻的99.3%总体准确率。本章还重点强调了这一重要成就，以及机器学习算法检测和中和基于威胁的PDF的能力。

## 1. 引言

PDF因其可移植性和可靠性而长期流行。与`.doc`等可能跨平台显示不一致的格式不同，PDF确保在所有平台上的一致渲染。尽管外观简单，PDF却拥有复杂的底层结构，由二进制和ASCII数据的混合组成。事实上，PDF可以被视为一种独立的编程语言，查看时能够执行代码。此外，PDF支持嵌入式多媒体、JavaScript和系统命令等高级功能，使其既灵活又高效（[Martsinkevich et al., 2023](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor278)；[Issakhani et al., 2022](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor272)）。
