

# 交叉验证与模型评估

交叉验证提供了一种结构化的方法，用于估计模型在不同数据样本上的泛化能力，降低过拟合的风险。该过程涉及将数据划分为子集，在一个子集上训练模型。所提出的模型采用了 5 折交叉验证。

整合这些技术能提供对模型能力与局限性的全面视角，使从业者能够在模型选择和部署过程中做出明智决策。通过结合稳定性评分、噪声准确率和交叉验证，利益相关者能更深入地洞察模型的优势与劣势，从而在机器学习应用中促进稳健的评估与优化流程。

实现所提出的思路使用了 `CIC IDS 2017` 数据集。该数据集包含 `2830743` 条记录，其中删除了空值记录。删除空值后的记录数为 `2827876` ([Panigrahi & Borah, 2018](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor212))。

实现所提出思路的第一步是探索性数据分析 ([Oyelakin et al., 2023](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor212))。这是为了更深入地了解数据及不同特征间的关系，以及这些关系如何影响对攻击类型的准确预测。为此进行了单变量、双变量和多变量分析。单变量分析涉及绘制给定数据集中不同结果的出现频率。这通过计数图进行可视化。这有助于我们识别数据集的性质以及数据集中不同结果的比例。这成为了进行数据平衡步骤的原因。双变量分析涉及寻找数据集中不同特征之间的相关性。多变量分析涉及寻找所有特征之间的相关性，并借助热力图进行可视化。如前所述，特征选择和降维是所提出思路的主要目标。因此，为了获得不同特征重要性的洞察，执行了这一过程 ([Tukey, 1977](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor216))。

数据集包含 `79` 个特征，其中 `1` 个为输出。作为攻击名称的目标变量是分类变量。为便于计算并支持使用不同算法，进行了独热编码。这将分类变量转换为数值 ([Karthiga et al., 2021](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor212))。

进一步地，使用粒子群优化算法进行了特征选择 ([Kunhare et al., 2020](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor208))。`PSO` 在传统特征选择方法难以奏效的高维空间中极为高效。此外，它具备全局优化能力。因此，在该方法中，根据初始化的代数更新每个粒子的位置和速度。识别出局部最优，并逐步识别出全局最优。这种涉及惯性、社会成分和认知成分的协作方法，确保了用于模型的特征子集能得到更好的选择。它也易于实现。与涉及复杂数学计算的其他几种特征选择方法不同，粒子群优化——一种基于鸟类和鱼类行为的技术——更为简单。因此，它更易于实现并集成到工作流中。此外，它极具适应性，可用于实现各种目标函数，例如所提出思路中旨在减少特征数量同时提高准确率的目标函数。`PSO` 也擅长处理特征交互。特征交互是指不同特征共同产生的效应（这在探索性数据分析中已研究过），这不同于特征各自单独的效应。由于数据集包含相互交互的不同特征，因此采用 `PSO` 进行特征选择。考虑到数据集的巨大体量，最初初始化了 `10` 代。这将特征分类为不同的特征子集。然后，每个特征子集由适应度函数进行测试。实现的思路中使用 `Logistic regression` 作为适应度函数。获得了每个特征子集的准确率。此外，这对所有十代持续进行，并确定了全局最优准确率。返回全局最优准确率的特征子集被保留，其余特征被丢弃，不再进一步处理。

从探索性数据分析中，在单变量分析中，观察到数据集高度不平衡。正常模式的数量远超攻击模式。像 `Heartbleed` 这样的少数攻击计数非常少。这样的数据集无法产生准确的结果，因为它会导致向多数类偏倚。因此，进行了数据平衡 ([Mooijman et al., 2023](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor211)) 以平衡数据集。采用了同时包含过采样和欠采样的方法，以确保数据完美平衡。通过随机欠采样对多数类进行了欠采样处理。少数类通过自适应合成过采样技术 ([He et al., 2008](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor212)) 进行过采样。这产生了一个平衡的数据集，数据集最终准备好可用各种机器学习算法进行分类并观察准确率。

使用了九种不同的分类器算法对数据集进行分类。算法包括 `random forest`、`K-nearest neighbor`、`Logistic regression`、`decision tree`、`LightGBM`，以及 `Adaboost`、`Catboost`、`XGBoost` 和 `Gradient boost` 等提升算法。这些算法的评估指标为：预测准确率、精确率、`F1 score`、召回率、模型训练耗时和模型测试耗时。随后，这些模型使用 `Optuna` ([Kusumaputri & Arifin, 2022](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor209))——一种超参数优化框架——进行了超参数调优。定义了特征空间，并为上述每种机器学习算法指定了待调优的超参数（以提高准确率为目标函数）。采用并行处理以加速计算并降低计算开销。观察了每种算法的准确率、精确率、`F1 score` 和召回率。根据上述四个评估指标选出表现最好的算法，并对其进行超参数调优。
