

# 物联网安全威胁与挑战

物联网系统容易受到许多威胁，这些威胁可能会损害其性能、数据的准确性以及用户的隐私。恶意软件和勒索软件攻击构成重大风险，因为它们有能力使设备无法使用或加密数据，并要求支付费用以换取解密。未授权访问和数据泄露构成巨大风险，因为物联网设备经常采集和发送敏感信息，使其成为黑客的理想目标。拒绝服务攻击有能力使物联网网络过载，导致服务故障和中断。中间人攻击构成重大危险，因为它们涉及攻击者拦截和篡改设备间传输的数据。物联网系统的主要风险在于存在安全性差的设备（认证薄弱）、缺乏加密，以及存在已知漏洞的老旧组件（[Alotaibi & Ilyas, 2023](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor381)）。这些因素助长了各种形式的攻击，如恶意软件问题、僵尸网络和非法访问。由于连接、协议和接口不安全，物联网系统容易受到窃听、数据拦截和拒绝服务攻击等威胁。其他重大风险来自设备管理不善、对暗物联网设备认知不足、未被发现的复杂且持续的数据泄露暴露机密数据，以及 5G 和 DNS 等技术中的弱点助长了针对物联网系统的大规模攻击。

此外，缺乏强健的认证措施可能导致设备被未授权访问，而脆弱的接口和网络服务可能被利用以获取对物联网设备的控制权。如果固件和软件漏洞得不到持续更新，它们可能成为攻击者利用的潜在入口。此外，对物联网设备进行物理篡改，特别是位于公共或安全性较低环境中的设备，可能导致系统被攻破。加密方法不足可能导致数据在传输和存储过程中被未授权获取和访问。这凸显了物联网系统对强有力安全措施的关键需求。

## 6.1 物联网安全概念面临的挑战

物联网设备在设计时缺乏对安全性的首要关注。因此，存在多个物联网安全问题，可能产生危险的影响。在基本上每一个已实施或正在实施的物联网应用中，安全都是最高优先级。物联网应用正在快速扩展，现在存在于大多数当前行业领域。尽管运营商通过现有网络技术支持许多物联网应用，但其中一些应用需要其所采用的技术提供额外的安全支持。以下是与特定物联网设备相关的物联网安全挑战列表，这些挑战有可能使消费者面临数据泄露的威胁。

### 软件和固件漏洞

由于许多物联网设备无法安全地更新其固件，因此攻击者可以利用已知漏洞对其发起攻击。设备容易受到虚假或未授权的固件更改影响。在硬件、软件、网络和应用接口方面的物联网固件漏洞，可能允许物联网恶意软件以远程劫持和控制的形式构成威胁。攻击者可以利用用 C 语言编写的固件应用中的内存安全漏洞，如缓冲区溢出。物联网固件通常带有后门或硬编码的默认凭据，使攻击者能轻松访问。由于固件中加密薄弱或密钥存储不安全，敏感信息可能泄露，且可能遭受窃听攻击。大量物联网设备拥有不安全的 Web 界面，容易遭受 SQL 注入和跨站脚本攻击 (XSS)。如果物联网系统使用具有已知漏洞的过时组件、库或框架，则容易受到攻击。由于输入数据认证不充分，可能发生 SQL 注入和代码注入等注入攻击。如果访问控制无效，可能导致对物联网设备和数据的未授权访问。不安全的通信协议或加密不足可能导致中间人攻击和数据获取（[Mansour M. et al, 2023](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor402)）。

### 缺乏可见性

缺乏清晰的可见性是物联网网络中一个重要的安全障碍。大量物联网设备在后台运行，人工参与有限，其操作和数据传输神秘且难以监控。连接到网络的物联网设备数量庞大且种类繁多，可能会压垮标准安全监控解决方案，导致存在未监控区域，且缺乏对其行为的洞察。物联网设备通常使用独特或不常见的协议，这使得检查和评估其网络数据以发现潜在安全风险变得复杂。对物联网设备行为缺乏明显的洞察，可能导致难以快速检测异常、未授权访问尝试或恶意行为。部署物联网设备发现和资产管理工具，以全面了解网络内互联设备的情况。实施专为物联网环境设计的专用网络流量监控和分析解决方案，以检查和理解设备通信。部署能够收集和关联来自不同物联网设备和来源数据的安全信息和事件管理 (SIEM) 系统，以检测任何安全风险。为物联网设备实施强健的访问限制和认证措施，确保只有授权设备能连接到网络。

### 缺乏标准化

缺乏标准给物联网网络的安全带来了重大挑战。显而易见，缺乏全球公认的物联网设备通信、认证、加密和安全措施标准及协议。在缺乏广泛认可的安全标准的情况下，组织可能会采用创造性的或特定供应商的安全方法，导致其物联网安全框架出现不一致和潜在漏洞。针对认为 5G 不适合不太先进的物联网应用的观点，3GPP 标准组织已将 NB-IoT 和 LTE-M 技术（这是为物联网设备提供无线连接的更经济、不太先进的方法）整合到 5G 网络中（[Ahmed S. F. et al, 2024](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor380)）。最新的移动通信标准旨在灵活且适应性强，作为无线通信的综合解决方案。它提供适合许多应用（包括物联网）的广泛连接选项。互操作性对物联网标准化至关重要，但遗憾的是，它也可能给使用该技术的组织带来重大问题（[Cirne A. et al, 2022](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor388)）。物联网设备在连接标准方面各不相同，这可能阻碍设备间的通信。标准化的连接层是任何组织物联网战略的必要基础。
