## 2. 云计算概述

目前，客户借助互联网能够按需使用服务器、存储和应用程序等计算机资源。它为企业提供了灵活性、可扩展性，以及一种无需维护物理基础设施的更廉价（负担得起）的替代方案。

### 2.1 背景

过去，带有一些基础设施的互联网一部分通常用云来表示。如今，在线服务被称为“云”服务。与早期交易容量有限的系统不同，云计算（CC）现在支持在几秒钟内进行大量活动。这种能力使得事件预测、分析和数据预处理等任务能够高效完成。要使用云服务，用户必须保持设备连接，以访问和操作分布在全球的这些大规模处理虚拟机（Furht, B., 2010）。可参考 CC 出现前使用的旧系统来追踪其发展进程。在 CC 语境下，通过互联网提供服务的提供商被称为“云”，而“计算”涉及使用计算机处理计算或资源。正如约翰·麦卡锡 1961 年在 MIT 所建议的，如果这类计算机被作为计算的未来进行推广，最终可能会被归类为公用事业，类似于电话系统（[Garfinkel, S., 1999](#979-8-3693-9225-6.ch004.bits-pdf.xhtml#_idTextAnchor146)）。Salesforce 是最早使用“CC”术语的公司之一，成立于 20 世纪 90 年代末，最初提供其 SaaS 和客户关系管理（CRM）服务（Salesforce, 2023）。Salesforce 模型是一个著名的 CC 范例，它为用户提供开发平台，如 `Microsoft Azure`（Microsoft, 2023）和 `Google's App Engine`（Google, 2023），以及 PaaS。另一种选择是 IaaS 模型，由 `Amazon Elastic Compute Cloud (EC2)` 等公司于 2006 年引入。

### 2.2 安全顾虑

组织必须解决云中群组数据共享带来的多个安全问题，以保护其敏感数据并维护数据完整性。当众多用户或群组在云环境中协作和共享数据时，必须实施强有力的安全措施。

#### 2.2.1 数据存储

云架构由所提供的服务决定。随着客户数据现存储在云中，本地访问已丧失，这需要一个备份系统来确保云服务器上数据文件的可用性和完整性。一个主要顾虑是能够尽快检测到任何未经授权的修改或数据损坏，这是数据安全服务质量的一个长期方面。虽然云计算（CC）引入了新的复杂安全风险，但也揭示了传统加密基元不再足够。由于用户在 CC 中不直接管理其数据安全措施，立即应用安全协议具有挑战性。因此，即使在不知道数据确切内容的情况下，确保可信信息被上传到云中至关重要。此外，CC 不仅涉及第三方数据仓储；还包括以存储准确性更新动态数据（Amazon, 2023）。

用户修改云中存储数据的能力——如插入、删除、修改和添加新条目——要求在动态更新期间保持存储准确性。这种不断演变的性质需要新策略，使过时的完整性保证策略失效。此外，CC 涉及数据中心的并发、协作和分布式管理。为增强数据安全，特定用户的信息存储在多个物理位置，创建冗余并降低数据泄露风险。因此，开发一个具有现实完整性的真实世界云数据存储系统，将极大受益于用于存储正确性验证的分布式协议（Wang, Q., 2009）。[图 1](#979-8-3693-9225-6.ch004.bits-pdf.xhtml#_idTextAnchor135) 展示了如下所示的云数据存储安全模式。

#### 2.2.2 数据传输安全

云提供商使用互联网作为其通信信道来传输数据。安全有效地传输信息的能力是信息管理和其他业务运营赖以建立的基础，也是 CC 的核心。

* 它涉及将脚本注入用户浏览器，通过网站修改控制其会话，以及注入蠕虫等其他恶意行为。
* 注入缺陷：当 Web 应用程序的用户输入未经过充分验证时，可被用于修改服务器查询。
* 恶意文件执行：此攻击可针对 XML 或任何其他接受用户文件的框架，因为这些文件可能包含恶意脚本。
* 未使用加密函数保护数据传输的 Web 应用程序容易受到攻击（Saripalli and Walters, 2010）。

#### 2.2.3 应用安全

应用安全是利用硬件、软件和程序控制来保护程序免受外部威胁。集成到强大的应用安全流程中的安全要素，降低了黑客修改数据集以及窃取、篡改或删除重要数据的可能性。随着应用程序跨网络访问的频率增加，因此更容易受到各种威胁，安全在开发过程中的因素变得越来越重要。在线编写并在个人计算机或防火墙后的局域网上运行的计算机代码称为 SAAS。客户能够通过 Web 远程访问应用程序，以及能够从集中位置管理操作而非在每个客户站点管理，是其主要特征。此外，还包含用于商业产品的基于网络的软件访问和管理。应用程序、软件和服务攻击迄今为止最为常见，占导致数据泄露的所有黑客活动的 39%（Zissis & Lekkas, 2009）。

#### 2.2.4 安全与云完整性

使用云系统运行应用程序时，必须建立适当的备份机制，以确保在发生数据丢失问题时应用程序的安全。无论这是数据库条目损坏、用户信息删除，还是更严重的数据丢失，都无关紧要。通常，需要定期将数据备份到便携式介质上。

仅出于识别原因，此活动通常需要一些关于服务实现组件的元数据。特定基于云的 Web 服务的 PaaS 实例的每个唯一服务实现相关的所有 Web 服务也可能包含在该信息中。例如，Web 服务描述文档需要存在于服务实现实例中，并由云系统提供，以便根据用户请求提供给用户。用户必须检查大多数这些元数据描述，以确定服务是否适合其目的，然后再使用它（Pan,J-S.,2011）。在[表 1](#979-8-3693-9225-6.ch004.bits-pdf.xhtml#_idTextAnchor136)中，我们汇编了所有先前攻击的综合摘要。
