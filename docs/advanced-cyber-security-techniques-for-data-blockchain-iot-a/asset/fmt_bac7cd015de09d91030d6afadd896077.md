
# PDF恶意软件检测：智能方法综述

恶意软件创建者经常利用PDF文件中嵌入JavaScript的能力来运行其代码。尽管这些代码通常被包含在沙箱中以保证安全，但它们仍可利用未修补的漏洞逃逸并在用户设备上执行有害命令。恶意PDF可能包含复杂、伪装的有效载荷以逃避检测，或者一旦攻击者获得控制权，恶意软件会从互联网下载。这些危险的PDF通过多种方式分发，包括路过式下载、定向攻击或大规模电子邮件活动（[Li et al., 2021](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor275)；[Tzermias et al., 2011](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor286)）。依赖基于特征的检测的传统防病毒软件难以捕获隐藏在PDF中的此类恶意软件。随着PDF文件在个人和专业环境中的广泛使用，其中嵌入的恶意软件风险也在增加。防范PDF中的恶意软件已成为网络安全专家的首要任务（[Li et al., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor276)；[Shijo et al., 2015]；[Mohammed et al., 2021](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor280)）。网络安全专家与恶意软件创建者之间的持续博弈凸显了对更智能检测方法的需求，这些方法能够将未知威胁与其他恶意活动区分开来。不仅是基于PDF的恶意软件，现代恶意软件在当今的数字环境中也对所有数字设备（包括IoT设备）构成重大威胁（Jani, K. A., & Nirbhay, Chaubey., 2020）。恶意软件分析过程非常复杂，需要高计算加密和解密设备。随着计算机性能增强，现代密码学的弱点暴露无遗。在这种情况下，量子密码学是一个有前景的解决方案，为在线交易、通信等各种应用提供强大保护。它正在专家中获得关注，且理由充分——它是安全数据交换的未来（[Chaubey, N. K., & Prajapati, B. B., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor267)）。

2020年，研究人员提出了一种基于API函数调用的恶意软件检测新方法（[Tank et al., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor285)）。该方法能够追踪恶意软件行为，并表明特定API函数调用的存在可暗示恶意软件的存在（[Tank et al., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor285)）。

智能检测方法的使用是对抗软件病毒/恶意软件的一种非常强有力的手段。它结合了现有的尖端智能识别方法，包含机器学习模型和其他类型的先进技术。通过利用这些技术分析能力和发现漏洞，将有可能为网络安全解决方案的改进提供关键贡献，这些解决方案本质上旨在应对PDF下载环境中新出现的挑战（[Rieck et al., 2011](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor282)；[Li et al., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor276)）。

基本上，智能检测技术采用现代技术，包含机器学习、人工智能和威胁行为科学，以发现任何恶意行为倾向的迹象。随着更复杂的设备和技术出现，网络犯罪分子开发其恶意特征，并逼近不断变化的网络威胁前景。为了在不断演变的威胁形势中保持领先，需超越静态特征，采用动态分析。在多样化数据集上训练的机器学习模型将有能力仅凭其PDF基础就区分出该恶意软件的最细微指标，提供卓越的阻断功能。

在基于机器学习的技术领域，用于恶意软件检测有两类特征：静态和动态。理解PDF文件中动态与静态特征的相互作用，对于开发能有效交互和操作PDF内容的应用程序至关重要。无论提取文本、图像还是交互元素，开发人员都需要考虑PDF的静态和动态两方面，以创建全面的解决方案（[Al-Haija et al., 2022](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor265)；[Li et al., 2021](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor275)）。

虽然动态特征在检测PDF文件中的恶意软件方面显示出潜力，但它们并非PDF文件所独有，且实施安全沙箱环境会增加检测过程的复杂性。因此，我们的方法主要利用静态特征。动态和静态特征的使用需要大量的特征提取专业知识。然而，我们的目标是利用PDF文件特有的、不需要大量领域知识的特征（[Liu, R., & Nicholas, C., 2023](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor277)；[Li et al., 2019](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor274)；[He et al., 2020](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor271)）。

在论文的后续章节中，我们将对当前PDF恶意软件检测的智能工具进行详细综述。本文审视了几种方法，即机器学习算法和行为分析框架。每节将重点介绍这些方法的有效性及其在战略防御中可能发挥的作用。因此，本研究的主要目标是为对抗PDF文件中恶意软件的网络安全专家、研究人员和组织提供指导。

## 2 文献综述

针对基于PDF的恶意软件采用智能检测进行防护的文献反映了一个动态且不断发展的领域。已使用各种模型，以及静态、动态和混合方法。下表[1](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor248)简要概述了迄今为止该领域开展的工作及显著观察。深度学习方法（如深度神经网络`DNN`）在学术和工业环境中广泛使用（[Al-Haija et al., 2022](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor265)）。它们应用于恶意软件分析等领域。`DNN`在语音识别、自然语言处理和图像识别等繁重任务中表现出色。然而，已证明这些系统在敌对环境中可能难以应对复杂的逃避技术（[Li et al., 2021](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor275)）。
