
$$L_{\text{total}} = L_G + \lambda \times L_s - L_D$$

(10)

Where $\lambda$ is a hyperparameter that controls the influence of the specified framework loss. $L_D$ is subtracted because the generator aims to minimize its loss, while the discriminator aims to maximize it. By optimizing this combined function during the training phase, ID-ANWE motivates the generator to generate high-quality, diverse minority attack samples that align with the specified framework while mitigating issues like mode collapse and training instability.
