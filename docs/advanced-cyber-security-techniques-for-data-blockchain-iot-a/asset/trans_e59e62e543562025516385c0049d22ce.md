
集成的机器学习算法包括 `XGBoost`、`Catboost`、`Random Forest` 和 `LightGBM`。`XGBoost` 以其高效性和有效性著称。它具有高速度和内置正则化功能以防止过拟合，还能处理缺失值。`Catboost` 无需单独预处理数据即可处理分类变量。它能自动处理缺失数据，且对过拟合具有鲁棒性。`Random forest` 是多棵决策树的集成模型，具备处理大型数据集的能力，且对过拟合具有鲁棒性。`LightGBM` 是一种梯度提升算法，旨在处理大型数据集。它速度快且内存效率极高。基于上述原因，以及基于分类和超参数调优期间建立的评估指标所表现出的高性能，选择了上述模型进行集成。集成采用软投票方式完成，最终获得了集成模型（[Dietterich, 2000](#979-8-3693-9225-6.ch007.bits-pdf.xhtml#_idTextAnchor204)）。

随后，使用不同方法对获得的集成模型进行了测试。首先，通过改变扰动级别计算模型的稳定性得分。然后，向数据集注入合成噪声，并使用集成模型对数据集进行分类。最后，进行了五折交叉验证，以确保不存在过拟合。从而验证了模型的鲁棒性。关于所获得的各种中间结果和最终结果及其推论的详细解释，将在本章的“结果与讨论”部分阐述。
