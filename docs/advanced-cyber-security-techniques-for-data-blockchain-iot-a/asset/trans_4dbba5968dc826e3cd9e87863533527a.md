

# 网络与物理安全

由于物联网设备的安全功能薄弱，它们容易受到攻击者的攻击。它们能够轻松连接到位于偏远地区的物联网设备，并持续较长时间，以进行必要的物理修改（[Wang N. et al, 2019](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor431)）。缺乏物理安全协议的设备极易遭受攻击，对物联网安全构成严重威胁。例如，物联网设备在连接 USB 闪存驱动器时可能会感染恶意软件。设备制造商的首要责任是优先保障这些设备的物理安全，这涉及在其他方参与公司运营时建立有效的第三方风险管理协议。

物联网网络安全包括保护物联网设备建立连接的网络。这包括确保设备与网络之间以及设备内部的通信通道安全。网络安全措施通常包括部署入侵检测系统 (IDS)、防火墙和加密方法。网络安全包含监控网络流量以检测并处理任何可疑行为的任务。这可能需要利用人工智能和机器学习技术来识别可能预示安全风险的异常情况。一旦检测到威胁，即可及时启动必要的响应，以最大程度地减轻攻击的影响。

# 弱认证与数据隐私

认证是确认用户身份以授权其访问设备、网络或系统的过程。物联网设备中不充分的认证可能导致多种安全问题，使该过程至关重要。薄弱的认证措施（如默认密码或简单的 PIN 码）会导致物联网设备遭受非法访问（[Yu D. et al, 2020](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor432)）。这可能导致数据泄露、设备被未授权控制，以及可能发动更大规模的网络攻击。大量物联网设备出厂时配有默认用户名和密码，这些凭证往往极易被攻击者猜测。某些设备无法处理复杂密码或多因素认证，使其处于易受攻击的状态。如果攻击者成功入侵设备，他们可能有能力执行未授权活动或收集机密信息。

对物联网设备敏感数据保护不力可能导致未经授权的个人窃听或非法访问，从而造成隐私泄露。不安全的数据传输或存储，以及对物联网设备的物理攻击，均可能破坏数据完整性。物联网设备能够收集、保存并利用您的个人数据以提升便利性（例如“Alexa，订个披萨”）。当物联网设备在您不知情或未授权的情况下使用您的信息时，情况就变得严重了。物联网系统中与第三方共享数据引发了隐私担忧，进而破坏了用户对设备的信任。物联网薄弱的隐私安全后果包括：用户对其数据的自主权降低、敏感数据被不当使用或滥用的可能性、身份盗窃、数据泄露、个人信息被未授权访问，以及物联网设备可信度的下降（[Venkatraman & Overmars, 2020](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor430)）。目前，一个显而易见的事实是，我们通过提供个人数据来支付表面上免费的在线服务费用。

## 6.2 物联网安全解决方案

有几种最佳方式来保护物联网设备，使其安全性不受损害。[图 4](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor373) 说明了保护物联网设备或系统所需的步骤或解决方案。以下是物联网用户应遵循的做法：

1.  **更改密码和强认证**：为物联网设备设置密码时，建议使用字母数字字符和符号的组合。定期更新它们以增强安全性。
2.  **设备资产管理**：有效的设备资产管理对于确保物联网设备安全至关重要，因为它提供了对所有互联设备的完整理解和控制权。
3.  **评估闲置设备并监控网络建立**：如果有任何设备未被使用，请避免将其置于环境中。任何保持连接但未维护的设备都构成潜在的安全风险。
4.  **使用生物识别或加密密钥认证系统**：利用面部特征或指纹等特征进行认证。这些基本特征难以复制，从而增强了防止未授权访问的安全措施。
5.  **利用工业标准化和基于云的解决方案**：采用既定的安全标准，如美国国家标准与技术研究院 (NIST) 指南、联邦信息处理标准 (FIPS) 140-2 以及平台安全架构 (PSA) 认证。这些标准为确保设备安全提供了全面框架，包括安全启动、加密和认证技术。

## 6.3 案例研究

存在许多潜在威胁，可能导致物联网发生重大干扰。其中一些漏洞利用了物联网的设计。一个安全问题的典型例子称为欺骗攻击，攻击者入侵安全性较低的设备，从而访问包含受保护设备的网络。然后攻击者误导网络，使其误以为他们正在使用加密技术。其他一些攻击则利用 IP 干扰作为进入系统的手段。其中一种风险是 Smurf 攻击，这是一种拒绝服务攻击，利用 IP 欺骗向服务器发送大量数据包，阻碍其响应合法请求的能力。IP/ICMP 分片攻击是一种拒绝服务攻击，涉及将 IP 数据包分割成较小的片段，通过网络发送，然后重组它们以使网络过载。

[图 5](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor374) 和 [图 6](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor375) 给出了来自印度政府网站开源数据集的电信领域数据分析，涵盖全国范围及截至 2018 年的总移动连接数（单位：百万）。根据[图 5](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor374)，很明显，与 2014 年的数据相比，从 2014 年到 2023 年，数据使用量、光缆陆缆、移动宽带用户和移动用户均显著上升。另一方面，[图 6](#979-8-3693-9225-6.ch014.bits-pdf.xhtml#_idTextAnchor375) 证明，截至 2018 年，印度市场推出了许多移动运营商，购买量显著上升，其中 Bharati Airtel 和 Vodafone 凭借最多的移动连接数发挥了关键作用。通过这种数据分析，我们可以考虑将其与物联网应用相结合，因为这些设备无论如何都通过这些网络连接与移动运营商相连。
