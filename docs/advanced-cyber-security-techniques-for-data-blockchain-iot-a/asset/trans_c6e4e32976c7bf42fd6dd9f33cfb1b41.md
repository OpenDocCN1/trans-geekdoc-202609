
# PDF 文件结构与安全风险

许多用户将 PDF 视为简单、静态的文档，但它们实际上功能强大。您看到的内容是后台程序运行的结果。虽然人们越来越了解其他文档格式（如带宏的 Microsoft Office 文件）的风险，但往往忽视 PDF 中存在的类似风险 ([Endignoux, G., 2016)](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor269), ([Elingiusti et al., 2018)](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor268)。PDF 文件内部包含预定义的结构，可在其框架内复现文本、图像、图形和交互元素。以下是 PDF 文件基本结构的概述 ([Martsinkevich et al., 2023)](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor278), ([Endignoux, G., 2016](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor269))：

*   **Header（文件头）**：PDF 文件以文件头开头，标识其为 PDF 文档。通常，文件头部分包含 PDF 规范的版本号，指示创建文件所用的特定 PDF 标准。
*   **Body（文件体）**：PDF 文件的文件体由按顺序排列的对象组成，本质上是内容格式。对象是 PDF 文件中的主要部分，可能以某种方式呈现文本、图像、字体和其他主要内容。因此，我们应重视 PDF 文件的灵活性，这使得理解和处理复杂信息变得更加容易。
*   **Cross-Reference Table / Xref（交叉引用表）**：交叉引用表可说是 PDF 文件中最重要的元素。它存储文件中对象位置和结构的元数据，支持对这些对象的轻松导航和快速检索。
*   **Trailer（尾部）**：尾部部分通过列出关键信息（包括引用对象、交叉引用组的大小和其他基本详情），提供整个 PDF 文档的综合概览。
*   **Objects（对象）**：PDF 由表单字段和文本块等对象的排列构成。对象具有虚拟标识符，每个对象存储一个定义对象属性的字典，以及一个包含对象真实数据的流或字符串。
*   **Catalog（目录）**：目录是电子文档中的关键细节。它作为基础，被其他关键根对象引用，涵盖文档和大纲，以及文档元数据。
*   **Pages（页面）**：`Pages` 对象以树结构定义页面的结构层级。每个页面都有缩略图，其中内容流、注释和资源等其他对象直接相连。
*   **Content Streams（内容流）**：内容流包含在页面上渲染文本、图像和其他图形元素的指令。它们通常使用可移植文档格式 (PDF) 语法编码。
*   **Fonts and Resources（字体与资源）**：构成文档的字体、图像和其他元素通常放置在“资源”部分以供后续使用。例如，此类部分包含字典，指定必须按第 II 节所述方式使用的资源。
*   **Annotations（注释）**：注释（例如链接、评论和表单字段）是创建交互性并为 PDF 文档提供更多信息的对象。另一方面，位置名称主要与页面的精确区域相关联。

从 [Figure 1](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor247) 可获取 PDF 文件结构的基础知识，该图最初出自 ([Martsinkevich et al., 2023)](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor278), ([Endignoux, G., 2016](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor269))。PDF 格式的规范已公开发布，全球软件开发人员可设计出与 PDF 文件完美配合的工具和应用程序。

PDF 文档在阅读、下载或共享单个文档时非常方便。因此，PDF 的普遍使用使其成为网络犯罪的诱人目标，恶意软件经常通过利用其简单的文本排列被添加到 PDF 中。如今，越来越多的组织和个人依赖 PDF 传播高敏感度数据，保护 PDF 免遭黑客攻击已成为 PDF 安全最重要的问题。

有许多可用的文件格式，其中之一是 PDF 文件，它们用途广泛且跨所有平台具有良好的兼容性；但它们已成为恶意行为者的目标，后者利用系统中的任何漏洞。PDF 中隐藏的脚本（如特洛伊木马）及类似工具函数可能正在触发恶意代码，而攻击者可能正在针对 PDF 阅读器应用程序中的漏洞。影响可能是多方面的，包括私人数据甚至整个系统的泄露，这凸显了面向未来的安全系统的必要性。

现代网络危险（特别是 PDF）的发展程度日益加深。HP Wolf Security 近期的一份报告揭示了一个令人担忧的趋势：网络犯罪分子越来越多地利用 PDF 传播 Wiki Loader、Ursnif 和 DarkGate 等恶意软件。与 2023 年第一季度相比，2023 年第四季度 PDF 相关威胁增加了 7%。这些威胁已从网络钓鱼尝试演变为通过 PDF 文档直接分发恶意软件。事实上，2023 年第四季度分析的恶意软件中有 11% 使用 PDF 作为投递方式，而第一季度仅为 4%。一个显著的例子是 Wiki Loader 活动，它使用虚假的包裹投递 PDF 诱骗用户安装 Ursnif 恶意软件 ([Maundrill, B., 2024)](#979-8-3693-9225-6.ch010.bits-pdf.xhtml#_idTextAnchor279)。
