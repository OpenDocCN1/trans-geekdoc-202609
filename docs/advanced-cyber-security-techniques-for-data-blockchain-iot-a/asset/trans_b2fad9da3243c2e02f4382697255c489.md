
物联网设备的数据存储在云端。如前所述，云信息安全在很大程度上依赖于 SaaS（软件即服务）。第三方公司通常会备份来自物联网云的数据。备份对数据完整性构成重大风险（[B. Ondiege 等人, 2017](#979-8-3693-9225-6.ch011.bits-pdf.xhtml#_idTextAnchor310)）。

### 8 用于安全物联网的预防措施

部署强大的安全措施以防止未经授权的访问和数据泄露至关重要。以下策略为提高物联网安全性和抵御潜在危害的韧性提供了全面指导。

#### 8.1 强密码

对物联网设备使用通用且简单的密码会为潜在黑客敞开大门。抵御黑客的最佳防线是使用强健且安全的密码。请确保为每个设备创建一个新密码（[Vutukuru & Lade, 2023](#979-8-3693-9225-6.ch011.bits-pdf.xhtml#_idTextAnchor319)）。如果黑客猜中了您的一个密码，可能会危害所有使用该密码的设备。定期更新这些密码可降低非法入侵的可能性。

#### 8.2 定期改进

如果基础软件工具的版本长时间未修改，就会成为易攻击目标。这只是给了恶意人员足够的时间来审查软件中的缺陷（Kamel, Hegazi, 2018）。因此，定期更新并确保每个连接设备均为最新版本是明智之举。最好自动化整个基础设施的软件更新实施，因为这能降低遭受入侵的可能性。定期更新物联网设备上的软件有助于修复安全漏洞并提高生产力。

#### 8.3 加密

加密是提升物联网设备网络安全不可或缺的一环。加密所有传输中的数据，包括传感器和设备数据、管理、配置及部署。几乎所有现代物联网设备都能够加密网络流量，并保护信息平面和控制平面的通信。下表列出了一些额外的考量因素：

#### 表 5. 加密在网络安全中的重要性

| 方面 | 重要性 |
| --- | --- |
| 数据机密性 | 加密确保物联网设备与服务器之间交换的数据安全，且未经授权的一方无法理解（Lei Cui a b., Youyang Qu 等人, 2020）。即使数据被截获，没有加密密钥也几乎无法破译。 |
| 数据完整性 | 加密通过保证数据在传输或存储过程中未被篡改或破坏，有助于保护数据完整性。物联网设备可使用加密哈希函数或数字签名，以确保接收到的数据真实且未被修改（C. Ge, W. Susilo, 2022）。 |
| 认证 | 加密使物联网设备和用户的认证变得更加容易。设备可使用数字证书和公钥加密等技术，向彼此及网络证明其身份，从而限制非法访问（Pedro Ramos [Brandao, 2018](#979-8-3693-9225-6.ch011.bits-pdf.xhtml#_idTextAnchor300)）。 |
| 访问控制 | 加密可用于限制对物联网设备中敏感信息和资源的访问。通过加密静态或传输中的数据，组织可仅授权特定人员访问，降低数据泄露风险。 |
| 保护固件更新 | 物联网设备通常需要修复缺陷并增强功能的软件升级。加密保证这些更新安全通信和实施，防止黑客拦截并植入有害代码（[Kvarda, Hnyk, 2017](#979-8-3693-9225-6.ch011.bits-pdf.xhtml#_idTextAnchor306)）。 |

总而言之，加密是物联网网络安全的关键组成部分，可防范窃听、篡改、非法访问和数据泄露等多种威胁。
