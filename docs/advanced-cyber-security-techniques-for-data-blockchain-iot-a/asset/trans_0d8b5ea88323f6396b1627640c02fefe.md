

# 权威证明

节点/验证者通常由网络创建者预先选定。这些验证者通常是受信任的社区成员，如大型企业或组织。

#### 表 2. 区块链达成共识的典型节点角色

| 角色 | 描述 |
| --- | --- |
| 提议者 | 通过提出新状态或决策来启动共识过程。 |
| 接受者 | 评估提议并接受或拒绝它。 |
| 领导者 | 协调共识过程并确保所有节点就提议的状态或决策达成一致。 |
| 跟随者 | 通过向其他节点发送投票或消息来参与共识过程。 |
| 验证者 | 验证提议状态或决策的有效性。 |

区块链系统凭借其透明性和可追溯性特性建立了对系统的信任。由于有序链式存储机制，存储在区块中的交易数据可以使用时间戳进行追溯。哈希、数字签名、分布式共识协议和去中心化架构有助于增强安全性（[Zheng et al., 2018](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor131)）。数字签名提供了一种安全的方式来验证参与交易各方的身份。分布式共识协议致力于使所有节点就总账本的当前状态达成一致。

#### 去中心化与网络安全

**去中心化治理与安全：** 去中心化、真实性、一致性和假名性是区块链的核心特征（[Schlatt et al., 2023](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor115)）。这些特征增强了现有安全网络的安全强度。由于去中心化架构，数据副本分布在各个节点上。这使得数据篡改比现有解决方案困难得多（或不可能）。采用传统机制存储的数据容易被攻破，因为它们依赖单一受信机构进行验证和存储加密数据（[Taylor et al., 2020](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor121)）。这一特性有助于数字证书管理的网络安全背景，从而提高在线交易和通信的安全性。然而，尽管有这些增强，应注意到这些只能部分替代现有的网络安全解决方案。

**免疫 DDoS 攻击：** 区块链的去中心化特性和存储主要是公开的，且能抵御分布式拒绝服务（DDoS）攻击。DDoS 攻击的性质是通过洪水般的互联网流量来破坏可用服务。传统的 DDoS 攻击难以控制，因为它们来自多个来源。然而，由于分布式架构，不存在单点故障，使区块链网络对 DDoS 攻击具有免疫力（[Rodrigues et al., 2017](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor111)）。此外，区块链交易由网络中的多个节点验证。这使得攻击者很难用虚假交易淹没网络并使系统不堪重负。

以太坊网络在 2017 年曾遭受 DDoS 攻击。然而，攻击未遂，网络能够继续正常运行。这证明了区块链技术对 DDoS 攻击的韧性。

**数据篡改与欺诈：** 传统的中心化数据存储行为产生安全问题，且容易遭受数据篡改。然而，区块链技术防篡改，因为它除了分布式架构外还使用了密码学（[Zhang & Chen, 2019](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor130)）。

**通过去中心化应对网络安全风险：** 区块链技术通过将控制权分发给各个节点，消除了对中央控制的必要性。这增加了透明度和可追溯性，从而增强网络安全并防止数据的未经授权操纵和控制。

#### 密码学哈希

区块链技术的基本概念是密码学哈希，它连同其他共识机制一起强化了区块链的强度、完整性和可信度。向区块链添加区块会自动链接到前一个区块，并变得抗篡改。区块链技术的不可变性至关重要，因为它防止未经授权的数据篡改，并阻止威胁行为者尝试更改数据（[Adeghe et al., 2024](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor062)）。区块链中的数字签名验证交易的真实性，并保证数据未被篡改（Uikey et al., 2024）。

区块链技术使用的高级密码算法能耗密集，消耗大量处理能力。大多数现有共识机制能耗密集，导致延迟和成本增加（[Adeghe et al., 2024](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor062)）。

像 `SHA-256` 这样的哈希算法广泛用于区块链技术。它们防篡改并抵御密码学攻击。尽管如此，不断演变的网络威胁要求持续的研究和开发，以开发动态对策（[Fernández-Caramés & Fraga-Lamas, 2020](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor085)）

#### 通过不可变性确保数据完整性

区块链为数据存储提供可靠性和准确性，使其成为在多个需要精确决策的领域中的首选技术。不可变性及其防篡改特性使区块链技术相较于其他技术具有差异化优势（[S. Zhou et al., 2023](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor134)）。因此，透明性特性使其成为共享和记录数据的理想选择，特别是在协作环境中。区块相互链接形成一条链。每个区块包含其交易的唯一加密哈希值和前一个区块的哈希值。这种强链式互连实现了不可变性。数据无法在不破坏链的情况下被篡改。这一特性使区块链技术成为一种安全可靠的数据存储方式（[L. Zhou et al., 2024](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor133)）

#### 透明度与信任

区块链技术是开创性的网络安全力量，促进透明度、安全性和信任。公有链、私有链和联盟链目前是流行的区块链类型。在公有链中，账本的可见性对所有成员开放，因为每个人都可以查看同一个账本。在联盟链和私有链中，只有群组成员可以查看。使用区块链账本确保数据绝不能被篡改或破坏（[Leteane & Ayalew, 2024](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor099)）。区块链技术因其防篡改、不可变和去中心化的特性，能威慑 DDoS 和 DoS 等网络安全攻击。它无意中促进了网络参与者之间的信任，通过共识机制保护数据（[Hasan et al., 2024](#979-8-3693-9225-6.ch003.bits-pdf.xhtml#_idTextAnchor088)）

# 面向企业的区块链安全

#### 区块链强化数据完整性

包含敏感信息（如密码、身份和关键组织数据）的数据必须始终得到保护，无论处于静止、处理中还是传输中。必须在所有阶段保护此数据免受威胁行为者的未经授权的更改或篡改。因此，维护数据完整性是一项必要且复杂的工作。凭借其不可变账本和安全交易，区块链技术是一个全面的解决方案，在加强安全性和隐私的同时维护数据完整性。
