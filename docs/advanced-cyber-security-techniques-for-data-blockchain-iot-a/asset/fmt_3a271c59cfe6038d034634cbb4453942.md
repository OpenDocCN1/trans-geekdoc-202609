
# 论文综述：Wireshark 在网络分析与安全中的应用

## 摘要
本文综述了多篇研究论文，探讨了 **Wireshark** 作为领先的网络分析软件，在网络流量监控、故障排查、安全审计及教学模拟等领域的核心作用。各研究一致认为，Wireshark 凭借其深度的数据包捕获与解析能力，是当代数字环境中不可或缺的分析工具。

---

## 1. 相关研究概述

### 1.1 网络取证与协议分析
**Soepeno (2023)** 指出，Wireshark 充当虚拟领域的“数字调查员”，能够实时捕获并分析数据包，提供卓越的精度与深度。通过长达四周的网络分析，它系统性地揭示了各类协议的复杂性，积累了宝贵的数据包行为数据库，成为调查人员和分析师深入研究基于互联网操作复杂性的必备工具。

### 1.2 局域网（LAN）安全与凭证窃取
**Hussain (2024)** 的研究聚焦于数字化互联世界中局域网安全风险的上升。文章探讨了攻击者如何利用 Wireshark 捕获 **HTTP** 数据包以窃取登录凭证（IP 地址、邮箱、财务细节等）。研究指出，尽管局域网常被视为安全，但存在漏洞。Wireshark 可捕获 **HTTP**、**ARP (Address Resolution Protocol)**、**TCP (Transmission Control Protocol)** 等协议。为保障局域网安全，建议实施数据加密、防火墙、**IDS/IPS**、网络分段、使用以太网线缆、**HTTPS** 及多因素认证（MFA），并通过监控流量、端口安全和 MAC 地址白名单来缓解威胁。

### 1.3 卫星通信（VSAT）网络可行性分析
**Yusuf (2024)** 针对偏远地区互联网接入受限的问题，推荐使用 **VSAT (Very Small Aperture Terminal)**。利用 Wireshark 测量 **抖动**、**丢包率**、**延迟** 和 **吞吐量**，成功分析了 SD 65 场景下的 VSAT 网络可行性。结果为技术人员提供了有价值的诊断数据，便于维护与修复。

### 1.4 服务质量（QoS）监控与在线教育
**Hamidah (2024)** 研究了印度尼西亚 **4G** 网络在疫情期间支撑在线教育的案例。An-Najiyah Surabaya 高中通过 QoS 监控（关注丢包率、吞吐量、延迟），实现了 **2.6 Mbps 吞吐量、0% 丢包率、0.12 ms 延迟** 的优异网络质量，保障了在线学习的最优性能。

### 1.5 网络嗅探在网络安全中的主动防御角色
**Shaw (2024)** 强调网络数据包嗅探是理解网络行为、识别漏洞、增强安全的关键。研究详述了其方法论与应用，肯定了其作为主动安全工具的有效性，同时探讨了用户隐私、数据保护的伦理顾虑及法律合规性。通过案例研究证明了其在检测异常、阻止恶意活动、强化基础设施方面的价值。

### 1.6 大规模网络流量监控与协议过滤
**Paravathi (2024)** 指出，随着网络扩张和流量激增，监控用户行为对平稳运行至关重要。Wireshark 等嗅探工具能捕获并分析流量，支持对 **TCP**、**IP**、**UDP** 等协议的实现与过滤，帮助管理员定位大规模网络中的薄弱环节，应用范围涵盖网络安全至合规监控。

## 2. 工具对比分析

### 2.1 Wireshark 与 Cisco Packet Tracer 的差异
为分析 Wireshark 特性，引入 **Cisco Packet Tracer** 进行对比（Čabarkapa, 2015），详见 **表 1**。对比旨在凸显两者优劣势，明确其在网络分析与故障排查中的适用场景。

#### 表 1. Wireshark 与 Cisco Packet Tracer 对比

| 标准 | Wireshark 数据包分析器 | Cisco Packet Tracer |
| :--- | :--- | :--- |
| **用途** | 检查和剖析网络数据包的工具。 | 用于构建和模拟网络设置的仿真平台。 |
| **功能** | 提供对网络活动和安全威胁的深度洞察。 | 支持网络拓扑设计和配置仿真。 |
| **主要用例** | 诊断网络问题、分析流量模式、安全审计。 | 学习网络架构、配置虚拟网络、仿真教学。 |
| **目标受众** | 网络管理员、安全分析师、数据分析专业人士。 | 学生、教育工作者、寻求实践培训的网络工程师。 |
| **核心特性** | 强大的数据包分析、过滤和解密能力。 | 设备仿真、拓扑设计、思科设备复刻。 |
| **兼容性** | 兼容多种操作系统（Windows、macOS、Linux）。 | 仅支持 Windows 和 macOS 平台。 |
| **成本** | 开源免费。 | 教学免费；商业用途需思科订阅。 |
| **学习曲线** | 需中高阶网络协议理解。 | 面向初学者，提供引导练习和简化界面。 |
| **实际应用** | 专业网络故障排查和安全审计。 | 教学环境中的实践网络培训。 |
| **可扩展性** | 有效支撑大规模网络分析和审计。 | 因教学侧重和仿真环境，可扩展性有限。 |

**结论**：Packet Tracer 受限于仿真环境，主要用于培训，商用需付费；Wireshark 开源免费且可扩展性强，凭借丰富功能成为本研究的首选工具。
