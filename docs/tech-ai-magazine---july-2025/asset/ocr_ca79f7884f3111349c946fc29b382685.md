# # 5. Unitree G1 Humanoid AI Robot

The G1 brings impressive humanoid functionality into labs and creators' hands. Standing just over 4 ft tall and weighing 35 kg, it can run at 7 ft/s, balance under duress, and lift small objects. Outfitted with LiDAR and depth cameras, an 8-core CPU (optionally upgraded), and modular arms with dexterous hands, the G1 is a serious platform for exploration in real-world interaction and robotics research.

![](bbox=[0.381, 0.105, 0.936, 0.31])

# ## Technical Specs

+   - Stands 1.32m tall, weighs 35kg
+   - 23 degrees of freedom (upgradable to 43 in EDU version)
+   - Runs up to 2 m/s with 8-core CPU
+   - Optional NVIDIA Orin upgrade for AI processing
+   - LiDAR and depth cameras for navigation
+   - 9,000 mAh battery providing, 2 hours runtime

# ## Price

Base model starts at US $16,000. EDU packages with accessories and support go up to $20,000+, though some vendors list prices near $21,600-$27,300 including import duties

# # 6. Hengbot Sirius

Sirius is a pint-sized robot dog, light enough to carry and agile enough to charm tech enthusiasts. Built with a bionic frame and expressive joints, this one-kilogram pup can bark, dance, and respond to gestures. Developers can customize behaviors using Python or C++ and play with its onboard cameras, LEDs, and voice input. It’s a fun, programmable pet that also nudges the boundaries of toy and tool.

![](bbox=[0.381, 0.615, 0.936, 0.812])

# ## Technical Specs

+   - Weighs ~1kg with 14 degrees of freedom
+   - Bionic aluminum frame construction
+   - Comprehensive motion library: walk, dance, leap, turn
+   - Voice, gesture, and app control
+   - Programmable in Python and C++
+   - Onboard camera, microphones, and LED arrays
+   - 45 minutes active use, 2 hours standby

# ## Price

Kickstarter pre-orders start at US $659 (with a $20 deposit). Full retail is expected to rise to around $699-$1,459
