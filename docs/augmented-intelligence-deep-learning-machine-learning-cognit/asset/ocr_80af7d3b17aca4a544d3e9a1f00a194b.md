# BLENDER

For demonstration, Blender is used to design the 3D models for this study. Blender is a free and open-source software that runs on most operating systems. It comes along with the main features expected in a modelling software – 3D modelling, UV wrapping, raster graphics editing, sculpting, animating, motion graphics and rendering. It has a solid rendering engine. Blender is an open source with a community of developers who continuously improve the software and its functionality.
