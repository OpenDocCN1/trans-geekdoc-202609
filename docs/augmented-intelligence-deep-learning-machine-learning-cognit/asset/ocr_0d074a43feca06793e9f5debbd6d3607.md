Bernoulli trails help to find whether colluders will achieve success or failure in colluding the system. The binomial distribution is used to determine the probability of reputation error given by equation 6.11.

p(x) = C(n,x) p^x (1-p)^{n-x}  (6.11)

In the above equation, n = total number of hosts, x = number of host colludes, p = chance of hosts to collude, p(x)= probability of reputation error due to collusion when ‘x’ number of hosts out of ‘n’ colludes.
