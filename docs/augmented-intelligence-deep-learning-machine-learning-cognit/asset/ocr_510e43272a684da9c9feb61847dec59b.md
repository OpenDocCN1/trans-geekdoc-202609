The system design process has moved from the traditional approach where developers meet users at the early stages of system development to take a list of requirements, which becomes a checklist for the User Acceptance Test (UAT). It has become necessary that users and other stakeholders in a system being developed be involved in the whole design and development process. Feedback from users should run a complete cycle on the lifetime of the software, from the inception of the design through development and maintenance stages till the software is no more in use. Continuous feedback from software users keeps the system current and satisfies all relevant requirements. Software update becomes a recurring process over the system's lifetime.
