## 检测移动代理安全声誉系统中的投票灌票串通攻击

Priyanka Mishra¹,*

¹ 印度理工学院科塔分校，MNIT校区，印度斋浦尔

**摘要：** 当移动代理（MA）被派发到去中心化的对等（P2P）电子社区时，它被迫与不熟悉的主机进行交易。这些不熟悉的主机具有恶意性，可能篡改代理的代码、状态和数据。为了解决来自主机的完整性、机密性、可用性和真实性威胁，本文提出了一种软安全方法。在该方法下，提出了一种基于信任的声誉模型，称为MRep。该模型考虑了称为直接声誉（DR）的第一手信息，该信息通过源主机（SH）收集的信任获得。模型假设SH是预先信任的主机，拥有与目标主机的过往交易经验。目标主机（DH）是代理未来希望与之交易的目标主机。间接声誉（IDR）从与DH有过往交易历史的推荐者处获得。当这些推荐者协作给出关于DH的虚假推荐时，就会发生串通攻击。当推荐者串通分别对不诚实的DH和诚实的DH给出正面和负面评级时，分别发生投票灌票和恶意诽谤串通。该方法基于相似性过滤（SF），使用欧几里得距离（ED）和单链接聚类技术。计算连续推荐者的过往推荐值（称为“F分数”）与SH为DH给出的推荐值之间的ED。聚类将推荐者合并为两个簇。散点图给出两个簇。一个簇包含对DH给出异常高或低评级的推荐者，而另一个簇给出的评级接近SH给出的评级。伯努利试验有助于了解当系统中串通者数量增加和减少时，串通对DH最终声誉（FR）的影响。声誉误差通过二项概率分布进行计算和统计验证。验证图显示，当串通概率（p）小于0.5时，声誉误差概率p(x)随串通者数量(x)的增加而降低。当p等于0.5时，p(x)随x的增加先增加后减少，而当p大于0.5时，p(x)随串通者数量(x)的增加而增加。我们将SF与贝叶斯过滤（BF）、离群值过滤（OF）和无过滤（NF）在系统出现20%、40%、60%和80%串通时进行比较。所提出的SF方法有助于过滤投票灌票串通者。即使系统中出现80%的串通，MRep在DH的FR中的误差也更小。
