# 2.10.1. The Rationale for Biomimetic Hand Prostheses

Typical hand-prothesis has until recently been made up of metal hooks operated by a myoelectric interface. It is therefore essential to upgrade these prosthesis hands for practical and esthetic reasons. The cyber hand [45] is thus motivated by a knowledge of hand and finger kinesiology (Fig. 2.21). Since the creation of a robot with all the features of actual human beings would be difficult, the challenge is to build modifications incorporating similar and less complicated roles.
