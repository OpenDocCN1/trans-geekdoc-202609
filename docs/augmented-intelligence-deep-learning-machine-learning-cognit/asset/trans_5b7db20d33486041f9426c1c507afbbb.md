## 7.3.3. 多目标和二进制优化。

为处理多目标优化问题，建议使用多目标 CSA (MOCSA) 和二进制 CSA (BCSA)。其中 Pareto 优化是多目标决策制定领域之一，关注于解决具有多个目标函数的数学优化问题以同时改进它。它已用于需要在比较两个或多个冲突目标时做出最优决策的领域，其中最重要的是工程、经济和物流。另一方面，在计算机视觉和机器学习中，二进制优化涵盖了许多应用，其中决策变量只能取 +1 或 -1 值。本节中，表 4 讨论了 MOCSA 和 BSA 在不同工程领域的应用。
