
\times \left( 2 \mathbb{E} \left[ \bar{\chi}_{p_2+2}^{-2}(\Delta^2) \right] - (p_2-2)\mathbb{E} \left[ \bar{\chi}_{p_2+2}^{-4}(\Delta^2) \right] \right)
+ (p_2^2 - 4)(\delta_2^\top M \delta_2) \mathbb{E} \left[ \bar{\chi}_{p_2+4}^{-4}(\Delta^2) \right] \bigg), \tag{9.4.11}

- (viii) ADL^*_{2}-risk(\hat{\varphi}_n^{SSR+}(\lambda)) = ADL^*_{2}-risk(\hat{\varphi}_n^{SSR}(\lambda)) - \eta^2 \left[ \text{tr}(\Sigma_{22:1}^{-1})\right.
\left. \times \left\{ \mathbb{E} \left[ \left( 1 - (p_2-2)\chi_{p_{2n}+2}^{-2}(\Delta^2) \right)^2 I \left( \chi_{p_{2n}+2}^2(\Delta^2) < (p_2-2) \right) \right] \right\} \right.
+ \delta_2^\top M \delta_2 \left\{ 2 \mathbb{E} \left[ \left( 1 - (p_2-2)\chi_{p_{2n}+2}^{-2}(\Delta^2) \right) I \left( \chi_{p_{2n}+2}^2(\Delta^2) < p_2-2 \right) \right] \right.
\left. - \mathbb{E} \left[ \left( 1 - (p_2-2)\chi_{p_{2n}+4}^{-2}(\Delta^2) \right)^2 I \left( \chi_{p_{2n}+4}^2(\Delta^2) < (p_2-2) \right) \right] \right\} \right],

- (viii) ADL^*_{2}-risk(\hat{\varphi}_n^{\text{ridgeR}}(k)) = \eta^2 \left[ \text{tr}(\Sigma_{11:2}^{-1})\right.
+ \text{tr} \left( (I_{p_2} + k \Sigma_{22:1}^{-1})^{-2} \Sigma_{22:1}^{-1} \right) + k^2 \delta_2^\top (\Sigma_{22:1} + k I_{p_2})^{-2} \delta_2 \right],

- (ix) ADL^*_{2}-risk(\hat{\varphi}_n^{\text{EnetR}}(\lambda, \alpha)) = \eta^2 \left[ \text{tr} \left( (I_{p_2} + \lambda(1-\alpha)\Sigma_{11:2}^{-1})^{-2} \Sigma_{11:2}^{-1} \right)\right.
+ \lambda^2(1-\alpha)^2 \Delta^\top (C + \lambda(1-\alpha)I_{p_2})^{-2} \Delta
+ 2\lambda(1-\alpha) B^\top (C + \lambda(1-\alpha)I)^{-2} \Delta \right], \tag{9.4.12}

where \eta^2 = \left( \int_{-\infty}^{\infty} f(t) d\Phi(F(t)) \right)^{-2} A_{\phi}^2, \Delta = (\Delta_1, ..., \Delta_p)^\top, \text{and}
B = \left( \Delta_j \mathcal{H}_3(\lambda^2, \Delta_j^2) - \lambda \alpha \left( \Phi(\lambda \alpha - \Delta_j) - \Phi(\lambda \alpha + \Delta_j) \right) \bigg| j=1, ..., p \right)^\top.

We proceed to discuss the asymptotic distributional risk efficiency (ADRE) of the R-estimators in the next section.

## 9.5 Asymptotic Distributional L$_2$-risk Analysis

In this section, we compare the R-estimators based on the ADL$_2$-risk criterion.

### 9.5.1 Comparison of Unrestricted vs. Restricted R-estimators

First, we compare \(\hat{\rho}_n^{\text{RR}}\) with \(\hat{\rho}_n^{\text{UR}}\) using their ADL$_2$-risk difference as follows,

ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{UR}\))-ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{RR}\)) = \(\eta^2\left(\text{tr}(\Sigma_{11:2}^{-1}) - \text{tr}(\Sigma_{11}^{-1}) - \Delta^2\text{Ch}_{\min}(\mathbf{M}\Sigma_{22:1}^{-1})\right)\).

Thus, the difference is non-negative whenever

\(0 < \Delta^2 \le \frac{\text{tr}(\mathbf{M}\Sigma_{22:1}^{-1})}{\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})}\) (9.5.1)

which means \(\hat{\rho}_{1n}^\text{RR}\) outperforms \(\hat{\rho}_{1n}^\text{UR}\) for \(\Delta^2\) in the above interval; otherwise, \(\hat{\rho}_{1n}^\text{UR}\) outperforms \(\hat{\rho}_{1n}^\text{RR}\). That is, neither \(\hat{\rho}_{1n}^\text{UR}\) nor \(\hat{\rho}_{1n}^\text{RR}\) outperforms the other uniformly.

### 9.5.2 Comparison of Unrestricted vs. Preliminary Test R-estimator

Here

ADL$_2$-risk(\(\hat{\rho}_n^\text{UR}\)) - ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{PTR}(\lambda)\)) = \(\eta^2\left(\text{tr}(\Sigma_{11:2}^{-1} - \Sigma_{11}^{-1})\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \Delta^2\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})\left(2\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \mathcal{H}_{p_2+4}(\lambda^2, \Delta^2)\right)\right)\).

The expression is non-negative whenever

\(0 \le \Delta^2 \le \frac{\text{tr}(\mathbf{M}\Sigma_{22:1}^{-1})\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2)}{\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})\left(2\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \mathcal{H}_{p_2+4}(\lambda^2, \Delta^2)\right)}\). (9.5.2)

Hence, \(\hat{\rho}_{1n}^\text{PTR}\) outperforms \(\hat{\rho}_{1n}^\text{UR}\) in this interval; otherwise, \(\hat{\rho}_{1n}^\text{UR}\) outperforms \(\hat{\rho}_{1n}^\text{PTR}\). It follows that PTRE fails to dominate the URE, \(\hat{\rho}_{1n}^\text{UR}\).

### 9.5.3 Comparison of Unrestricted vs. Stein–Saleh-type R-estimators

We provide the comparison in a form of a theorem.

### Theorem 9.4 Let

\(h = \frac{\text{Ch}_{\max}(\mathbf{M})}{\text{tr}(\mathbf{M})}, \quad 0 < h \le 1.\)

Then, a sufficient condition for the asymptotic dominance of Stein–Saleh R-estimator, \(\hat{\rho}_{1n}^\text{SSR}\), over URE, \(\hat{\rho}_{1n}^\text{UR}\). That is ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{UR}\)) \(\ge\) ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{SSR}\)) for all \(\Delta^2 \in \mathbb{R}\) is that the shrinkage factor, c, is positive and it satisfies the inequality

\(2\mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] - c\mathbb{E} \left[ \chi_{p_2+2}^{-4}(\Delta^2) \right] -(c+4)h\Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \ge 0 \quad \forall \Delta^2 \in \mathbb{R}^+\) (9.5.3)

which requires that

\( p_2 \ge 3, \quad 0 < c < 2(p_2 - 2) \quad \text{and} \quad h(c+1) \le 2. \quad (9.5.4) \)

**Proof:** We have

\text{ADL}_2\text{-risk}(\hat{\rho}_{1n}^{\text{UR}}) - \text{ADL}_2\text{-risk}(\hat{\rho}_{1n}^{\text{SSR}})
= c \text{tr}(\mathbf{M}) \left( 2 \mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] - c \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right)
-c(c+4)\Delta^2 \text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1}) \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right]
= c \text{tr}(\mathbf{M}) \left( 2 \mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] - c \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right)
-c(c+4)h \text{tr}(\mathbf{M})\Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right]
= c \text{tr}(\mathbf{M}) \left( \mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] + \Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right)
-c(c+4)h \text{tr}(\mathbf{M})\Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right]
= c \text{tr}(\mathbf{M}) \mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] + c \text{tr}(\mathbf{M})\Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] (1 + h(c + 4)).
(9.5.5)

Using Eq. (9.5.3), we can rewrite Eq. (9.5.5) as

\( [2(p_2 - 2) - c] \mathbb{E} \left[ \chi_{p_2+2}^{-4}(\Delta^2) \right] + [2 - h(c+4)] \Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \ge 0. \quad (9.5.6) \)

From the above, at \(\Delta^2 = 0\), we conclude that \(c\) has to be \(\le (p_2 - 2)\) (which requires that \(p_2 \ge 3\)). Furthermore, using a rough inequality that

\( \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \ge \frac{p_2 - 2}{p_2 + 2} \mathbb{E} \left[ \chi_{p_2+2}^{-4}(\Delta^2) \right] \)

and allowing \(\Delta^2\) to be appropriately large, we conclude that for the above to be positive for all \(\Delta^2\), we must have \(h(c+4) \le 2\). This completes the proof of Eq. (9.5.4).

Consequently, by examining Eq. (9.5.4), we obtain

\text{tr}(\mathbf{M}) = \text{tr}(\mathbf{I}_{p_1} - \mathbf{\Sigma}_{11}^{-1}\mathbf{\Sigma}_{11.2}) = \text{tr}(\mathbf{I}_{p_2} - \mathbf{\Sigma}_{22}^{-1}\mathbf{\Sigma}_{22.1})
= \min(p_1, p_2). \quad (9.5.7)

Also, for \( h \ge \frac{1}{2} \), for any positive \( c \), \( h(c+4) \) cannot be \( \le \frac{1}{2} \). Thus, we redefine

\( p^* = \min(p_1, p_2) \ge 3, \quad h < \frac{1}{2}, \quad 0 < c \le \min(2h^{-1} - 4, 2(p_2 - 2)). \quad \text{(9.5.8)}\)

Therefore, we need \( h < \frac{1}{2} \) and \( p^* \ge 3 \).

### 9.5.4 Comparison of the Preliminary Test vs. Stein–Saleh-type R-estimators

\( \mathcal{H}_{p_2+2}(\lambda^2, 0) \ge \frac{q(2(p_2-2)-q)}{p_2(p_2-2)}, \quad q = \max\{(p_2-2), (2h^{-1}-4)\}, \quad \text{(9.5.9)}\)
