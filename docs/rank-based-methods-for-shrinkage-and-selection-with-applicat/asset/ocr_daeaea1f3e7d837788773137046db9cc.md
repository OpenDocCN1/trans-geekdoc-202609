Consider the LASSO R trace on the right in Figure 4.3. Two of the traces with low variance look like the hard threshold estimator from Chapter 3 while the remaining four resemble the positive-rule Saleh R-estimator. To specify these two estimators, we need to define a test statistic, \(\mathcal{L}_{n_j}, j = 1, ..., p\), which will be elaborated later in the chapter. For now, consider it a threshold quantity. Then, the hard threshold R-estimator is given by

```
\(\hat{\theta}_n^{HTR}(\lambda) = \hat{\theta}_{n_j}^{UR} I(\mathcal{L}_{n_j} > \lambda^2), \quad j = 1, ..., p.\)
```

The positive-rule Stein–Saleh R-estimator1 is given by

```
\(\hat{\theta}_n^{SSR+}(\lambda) = \hat{\theta}_n^{UR} (1 - \lambda / \sqrt{\mathcal{L}_n}) I(\sqrt{\mathcal{L}_n} > \lambda).\)
```
