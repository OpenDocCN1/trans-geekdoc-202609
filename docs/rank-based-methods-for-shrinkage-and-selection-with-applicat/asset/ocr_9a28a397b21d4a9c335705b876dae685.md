# 6.5.4 Ridge-type Subset Selector

We define ridge-type subset selector as

```
\(\hat{\boldsymbol{\beta}}_n^{\text{ridgeR}}(\lambda) = \left( \frac{\hat{\boldsymbol{\beta}}_{jn}^{\text{UR}}}{1 + \lambda C^{jj}} | j = 1, ..., p \right)^{\top} .\)
```

Thus, we may derive the two quantities of interest as

```
\(\text{ADB}(\hat{\boldsymbol{\beta}}_n^{\text{ridgeR}}(\lambda)) = \left( \frac{-\lambda C^{jj}}{1 + \lambda C^{jj}} \Delta | j = 1, ..., p \right)^{\top}\)
```

and

```
\(\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n^{\text{ridgeR}}(\lambda)) = \eta^2 \left( \left[ \text{tr}[(I + \lambda C^{-1})^{-2} C^{-1}] + \lambda^2 \Delta^{\top} (C + \lambda I)^{-1} \Delta \right] \right),\)
```

where \(\Delta = (\Delta_1, ..., \Delta_p)^{\top}.\)

# 6.5.5 Elastic Net-type R-estimator

In this case, we define the naive elastic-net R-estimator (nEnetRE) as

```
\(\sqrt{n} \hat{\beta}_n^{\text{nEnetR}}(\lambda, \alpha) = \left( \frac{\text{sgn}(\sqrt{n} \hat{\beta}_{jn}^{\text{UR}})}{[1 + \lambda(1 - \alpha) C^{jj}]} \left( |\sqrt{n} \hat{\beta}_{jn}^{\text{UR}}| - \lambda \alpha \eta \sqrt{C^{jj}} \right)^+ | j = 1, ..., p \right)^{\top}\)
\(= \underset{\beta \in \mathbb{R}^p}{\text{argmin}} \left\{ D_n(\beta) + \lambda \left[ \frac{1}{2} \alpha \eta D[\beta] + \frac{1}{2} (1 - \alpha) \beta^{\top} C \beta \right] \right\}\)
\(= \left( \eta \sqrt{C^{jj}} \frac{\text{sgn}(Z_j)}{[1 + \lambda(1 - \alpha) C^{jj}]} (|Z_j| - \lambda \alpha \epsilon)^+ | j = 1, ..., p \right)^{\top}\) (6.5.11)
```

where \(\boldsymbol{D} = \text{Diag}\left( \frac{1}{\sqrt{C^{jj}}}, j = 1, ..., p \right) \text{ and } Z_j = \frac{\sqrt{n}}{\eta \sqrt{C^{jj}}} \hat{\beta}_{jn}^{\text{UR}}.\)

This estimator ties in with the positive-rule Stein-Saleh-type R-estimator perfectly. Indeed, we have

```
\(\hat{\boldsymbol{\beta}}_n^{\text{nEnetR}}(\lambda, \alpha) = [I + \lambda(1 - \alpha)C^{-1}]^{-1} \hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda \alpha).\) (6.5.12)
```

Then,

```
\(\text{ADB}(\hat{\boldsymbol{\beta}}_n^{\text{nEnetR}}(\lambda, \alpha)) = [I_p + \lambda(1 - \alpha)C^{-1}]^{-1} [B - \lambda(1 - \alpha)C^{-1} \Delta]\)
```
