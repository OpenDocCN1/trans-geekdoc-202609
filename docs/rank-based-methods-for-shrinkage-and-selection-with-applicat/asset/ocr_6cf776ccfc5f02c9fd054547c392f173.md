-E[(1-(p_2-2)\\chi_{p_2+4}^{-2}(\\Delta^2))I(\\chi_{p_2+4}^2(\\Delta^2)<p_2-2)] \\ge 0 \\quad (7.4.1)

since

ADL_2-risk(\\hat{\\beta}_n^{SSR}) \\ge \\eta^2 \\text{tr}(c_{11.2})E[(1-(p_2-2)\\chi_{p_2+2}^{-2}(\\Delta^2))I(\\chi_{p_2+2}^2(\\Delta^2)<p_2-2)]
- \\Delta^2 \\text{Ch}_{\\min}(c_{22.1}^{-1})\\{2E[(1-(p_2-2)\\chi_{p_2+2}^{-2}(\\Delta^2))I(\\chi_{p_2+2}^2(\\Delta^2)<p_2-2)]
- E[(1-(p_2-2)\\chi_{p_2+4}^{-2}(\\Delta^2))I(\\chi_{p_2+4}^2(\\Delta^2)<p_2-2)]\\}

and

ADL_2-risk(\\hat{\\beta}_n^{SSR}) \\ge ADL_2-risk(\\hat{\\beta}_n^{\\text{ridge}_R}(k)). \\quad (7.4.2)

On the other hand, we have

ADL_2-risk \\left( \\hat{\\beta}_n^{SSR+} : c_{11.2}, c_{22.1} \\right) - ADL_2-risk \\left( \\hat{\\beta}_n^{\\text{ridge}_R}(k_{opt}) : c_{11.2}, c_{22.1} \\right)
= \\eta^2 \\left\\{ p_2 - (p_2-2)^2 E[\\chi_{p_2}^{-2}(\\Delta^2)] - \\frac{p_2 \\Delta^2}{p_2 + \\Delta^2} - R^* \\right\\} \\ge 0, \\quad \\forall \\Delta^2 \\ge 0,

where

R^* = p_2 E[(1-(p_2-2)\\chi_{p_2+2}^{-2}(\\Delta^2))I(\\chi_{p_2+2}^2(\\Delta^2)<p_2-2)]
- \\Delta^2 \\{2E[(1-(p_2-2)\\chi_{p_2+2}^{-2}(\\Delta^2))I(\\chi_{p_2+2}^2(\\Delta^2)<p_2-2)]
- E[(1-(p_2-2)\\chi_{p_2+4}^{-2}(\\Delta^2))I(\\chi_{p_2+4}^2(\\Delta^2)<p_2-2)]\\}.

Consider the risk of PRSRE. It is an increasing function of \\Delta^2. At \\Delta^2 = 0, its value is

(p_1 + 2) - p_2 E[(1-(p_2-2)\\chi_{p_2+2}^{-2}(0))I(\\chi_{p_2+2}^2(0)<p_2-2)] \\ge 0

and as \\Delta^2 \\to \\infty, it tends to p_1 + p_2. For the ridge-type, at \\Delta^2 = 0, the value is p_1 and as \\Delta^2 \\to \\infty, it tends to p_1 + p_2. Hence, the risk difference is non-negative and therefore the ridge-type outperforms PRSRE uniformly. See Saleh et al. (2018).
