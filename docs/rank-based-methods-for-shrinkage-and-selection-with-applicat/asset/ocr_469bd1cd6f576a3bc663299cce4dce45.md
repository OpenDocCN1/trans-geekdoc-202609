The following theorem gives the asymptotic uniform linearity (AUL) result similar to Jurečková (1971) for ordinary regression models.

# **Theorem 9.1** (Koul and Saleh, 1993) (AUL of Statistics). Assume Eqs. (9.1.1) and (9.1.2) hold. In addition, assume the following

+   (a) (i) \(\mathsf{E}[\varepsilon] = 0, 0 < \mathsf{E}[\varepsilon^4] < \infty\),
+   (ii) \(F\) has uniformly continuous density \(f, f > 0\) a.e.
+   (b) \(\phi\) is non-decreasing and differentiable with its derivative, \(\phi'\), being uniformly continuous on \([0, 1]\). Then, for every \(0 < M < \infty\),

\(\sup_{\|\mathbf{w}\|\le M} \left\| \mathbf{L}_n(\boldsymbol{\rho} + n^{-\frac{1}{2}}\mathbf{w}) - \hat{\mathbf{L}}_n + \mathbf{w}^{\top}\boldsymbol{\Sigma}\boldsymbol{\gamma} \right\| = o_p(1)\) (9.2.4)

where \(\hat{\mathbf{L}}_n = (\hat{L}_1, ..., \hat{L}_p)^{\top}\) with

\(\hat{L}_j = \frac{1}{\sqrt{n}} \sum_{i=j+1}^n (X_{i-j} - \bar{X}_j) \left[ \phi(F(\varepsilon_i)) - \bar{\phi} \right], \quad 1 \le j \le p\) (9.2.5)

and

\(\bar{\phi} = \int_0^1 \phi(\omega)\mathrm{d}\omega\)
\(\bar{X}_i = \frac{1}{n} \sum_{t=s+1}^n X_{t-s}\)
\(\gamma = \int_{-\infty}^{+\infty} f(t)\mathrm{d}\phi(F(t))\)
\(\boldsymbol{\Sigma} = (\sigma(i - j)), i = 1, ..., p; j = 1, ..., p\)

where

\(\sigma(k) = \text{Cov}(X_0, X_k), \quad 1 \le k \le p.\)

The above theorem covers Wilcoxon-type scores but not the normal score. Using the AUL result of Eq. (9.2.4), one may obtain

\(\sqrt{n}(\hat{\rho}_n^{\text{UR}} - \boldsymbol{\rho}) = \gamma^{-1}\boldsymbol{\Sigma}^{-1}\hat{\mathbf{L}}_n + o_p(1), \quad \gamma = \int_{-\infty}^{+\infty} f\mathrm{d}\phi(F).\) (9.2.6)

Observe that \(\hat{\mathbf{L}}_n\) is a vector of square integrable mean zero martingale with

\(\mathbb{E}\left[ \hat{\mathbf{L}}_n \hat{\mathbf{L}}_n^{\top} \right] = A_{\phi}^2 \boldsymbol{\Sigma}\)
