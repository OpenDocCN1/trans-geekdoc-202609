where \(\ell\) is the learning rate that controls the step size needed in each iteration to produce a smooth yet rapid convergence to the solution.

LASSO can be applied to rank-based logistic regression as follows,

```
\(J^{\text{RLR-LASSO}}(\boldsymbol{\beta}) = D_n(\boldsymbol{\beta}) + \lambda_1 \sum_{j=1}^p |\beta_j|,\)
(11.5.11)
```

and again in expanded form, we have

```
\(J^{\text{RLR-LASSO}}(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - f(\mathbf{x}_i^{\top}\boldsymbol{\beta})a_n(R_n(\boldsymbol{\beta})) + \lambda_1 \sum_{j=1}^p |\beta_j|.\)
(11.5.12)
```

The penalized rank estimates, \(\hat{\boldsymbol{\beta}}^{\text{RLR-LASSO}}\), are obtained by minimizing Eq. (11.5.12). The optimization technique is again gradient descent with a modified set of partial derivatives. Here we have

```
\(\frac{\partial J^{\text{RLR-LASSO}}(\boldsymbol{\beta})}{\partial \beta_j} = - \sum_{i=1}^n p_i(1 - p_i)x_{ij}a_n(R_n(\boldsymbol{\beta})) + \lambda_1 \text{sgn}(\beta_j).\)
(11.5.13)
```

The update equation for each \(\beta_j\) to compute the new parameter values is given by

```
\(\beta_j^{(t+1)} = \beta_j^{(t)} - \ell \times \frac{\partial J^{\text{RLR-LASSO}}(\boldsymbol{\beta})}{\partial \beta_j}.\)
(11.5.14)
```

Similarly, to obtain \(\hat{\boldsymbol{\beta}}_n^{\text{RLR-aLASSO}}\), we minimize the objective function

```
\(J^{\text{RLR-aLASSO}}(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - f(\mathbf{x}_i^{\top}\boldsymbol{\beta})a_n(R_n(\boldsymbol{\beta})) + \lambda_1 \sum_{j=1}^p \frac{|\beta_j|}{|\beta_j^R|}.\)
(11.5.15)
```
