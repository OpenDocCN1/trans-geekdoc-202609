(a) Begin by running the following code for the hard threshold estimator.

```
pts <- 100
eta <- 0.8
n = 64
thetaUR <- 1.0
Ln <- n*thetaUR^2/eta^2
thetaShrink <- rep(0,pts)
lambda <- rep(0,pts)
#HTR
for (lambda in 0:pts) {
  lambda2 <- lambda/5
  thetaShrink[lambda+1] <- thetaUR*
    ( Ln > lambda2*lambda2)
  lambda[lambda+1] <- lambda2
}
plot(lambda,thetaShrink, ylab="thetaHTR",
     xlab="lambda",ylim=c(-1,1),
     col="black",type="1")
points(c(-0.1,20.1),c(-0.0,-0.0),
     col="gray",type="1")
```

(b) Next, run the R code that generates a trace for the Saleh R-estimator.

```
#SR
for (lambda in 0:pts) {
  lambda2 <- lambda/5
  thetaShrink[lambda+1] <- thetaUR*
    (1- lambda2/sqrt(Ln) )
  lambda[lambda+1] <- lambda2
}
plot(lambda,thetaShrink, ylab="thetaSR",
     xlab="lambda",ylim=c(-1,1),
     col="black",type="1")
points(c(-0.1,20.1),c(-0.0,-0.0),
     col="gray",type="1")
```
