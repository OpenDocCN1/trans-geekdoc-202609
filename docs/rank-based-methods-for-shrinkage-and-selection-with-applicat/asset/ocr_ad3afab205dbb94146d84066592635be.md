Next, the Saleh-type R-estimator is a continuous version of the hard threshold estimator which removes the step function in favor of a linear function, as follows

```
\(\hat{\theta}_n^{\text{SR}}(\lambda) = \hat{\theta}_n^{\text{UR}}(1 - \frac{\lambda}{\sqrt{\mathcal{L}_n}}).\)
```

We see in the top-right plot of Figure 3.1 a line that passes through \(\lambda = \sqrt{\mathcal{L}_n}\) and then continues linearly below 0. While this alleviates the discontinuity of the hard threshold estimator, it changes sign and this may not be desirable for a variety of reasons. The positive-rule Saleh-type R-estimator truncates the shrinkage at exactly \(\lambda = \sqrt{\mathcal{L}_n}\) such that it can only have positive or negative values, depending on the original sign of \(\hat{\theta}_n^{\text{UR}}\), but it cannot switch signs. This can be formulated using the \((\cdot)^+\) notation as follows

```
\(\hat{\theta}_n^{\text{SR}+}(\lambda) = \hat{\theta}_n^{\text{UR}}(1 - \frac{\lambda}{\sqrt{\mathcal{L}_n}})^+.\)
```

The estimator trace is shown in the middle-right plot of Figure 3.1. It can be viewed as a 'soft threshold' estimator. It is reminiscent of the LASSO trace seen in earlier chapters so it is worthwhile looking at LASSO in more detail here.

We begin with an L2 loss and a LASSO penalty for the location problem. The objective function is given by

```
\(J(\theta) = \frac{1}{2n} ||\mathbf{y} - \theta 1_n||^2 + \lambda |\theta|.\) (3.3.1)
```

As described in Chapter 2, we can take the derivative and set it to 0 to obtain the estimator. This results in

```
\(\hat{\theta}_n^{\text{LASSO-LS}} = \text{sgn}(\hat{\theta}_n^{\text{LS}})(|\hat{\theta}_n^{\text{LS}}| - \lambda)^+\) (3.3.2)
```

where \(\hat{\theta}_n^{\text{LS}} = \bar{\mathbf{y}}\) is the least-squares (LS) estimate and \(\hat{\theta}_n^{\text{LASSO-LS}}\) is the penalized estimate. Next, let us redefine the objective function using \(\sigma\), which is assumed to be a known variance quantity, along with a factor of \(\sqrt{n}\), as follows

```
\(J(\theta) = ||\mathbf{y} - \theta 1_n||^2 + 2\lambda \sqrt{n\sigma} |\theta|.\) (3.3.3)
```

The only difference is that we have included additional terms in the penalty function and removed them from the loss function. This type of modification does not introduce any fundamental difference in the resulting estimator except to scale the value of \(\lambda\). Further, an estimate of \(\sigma\) can easily be obtained from the standard error, \(\hat{\sigma} = \sqrt{\text{Var}(\hat{\theta}_n^{\text{LS}})}\).
