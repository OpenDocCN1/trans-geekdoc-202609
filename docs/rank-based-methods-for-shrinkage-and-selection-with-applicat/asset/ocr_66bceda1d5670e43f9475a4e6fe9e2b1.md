+   (2) \(\int_0^1 \phi^2(u)du = 1\), i.e. the square integral in \([0,1]\) is 1

+   (3) \(\phi(1-u) = -\phi(u)\), i.e. it is skew-symmetric about \(\frac{1}{2}\).

The Wilcoxon score function, given by

\(\phi(u) = \sqrt{12}\left(u - \frac{1}{2}\right),\) (1.6.16)

satisfies the above conditions, since clearly

\(\int_0^1 \sqrt{12}\left(u - \frac{1}{2}\right)du = \sqrt{12}\left(\frac{u^2}{2} - \frac{u}{2}\right)\bigg|_0^1 = 0,\)

and

\(\int_0^1 12\left(u - \frac{1}{2}\right)^2 du = \int_0^1 12\left(u^2 - u + \frac{1}{4}\right)du = 12\left(\frac{u^3}{3} - \frac{u^2}{2} + \frac{u}{4}\right)\bigg|_0^1 = 1,\)

and

\(\phi(1-u) = \sqrt{12}\left(1 - u - \frac{1}{2}\right) = -\sqrt{12}\left(u - \frac{1}{2}\right) = -\phi(u).\)

In order to compute \(\hat{\theta}_n^R\), we minimize \(D_n(\theta)\) of Eq. (1.6.10) which involves \(R^+(\cdot)\) and \(a_n^+(\cdot)\). The function \(R_{n_i}^+(\cdot)\) ranks \(|y_i - (\theta + \beta x_i)|\) among \(|y_1 - (\theta + \beta x_1)|, ..., |y_n - (\theta + \beta x_n)|\). The corresponding signed-rank scores are generated using one of the following two ways

\(a_n^+(i) = \mathbb{E}\left[\phi^+\left(U_{n_i}\right)\right], \quad i=1, ..., n\) (1.6.17)

where the ordered \(U_{n_i} \sim U(0, 1)\), for \(i=1, ..., n\); or

\(a_n^+(R_{n_i}^+(\beta)) = \phi^+\left(\frac{R_{n_i}^+(\beta)}{n+1}\right),\) (1.6.18)

where the function,

\(\phi^+(u) = \phi\left(\frac{u+1}{2}\right),\) (1.6.19)

can be found from considering Wilcoxon score function of Eq. (1.6.16) to be

\(\phi^+(u) = \sqrt{12}\left(\frac{u+1}{2} - \frac{1}{2}\right) = \sqrt{3}u.\) (1.6.20)

The plots for the standardized \(\phi(u)\) and \(\phi^+(u)\) are provided in Figure 1.5. We see that both functions are linear with respect to \(u\), with the range \(\frac{1}{n+1} < u < \frac{n}{n+1}\).

From these plots, we can understand that \(\sum_{i=1}^n a_{n_i}(\cdot) = 0\) but \(\sum_{i=1}^n a_{n_i}^+(\cdot) \neq 0\). The residuals are weighted by these two scoring functions to form the loss functions.
