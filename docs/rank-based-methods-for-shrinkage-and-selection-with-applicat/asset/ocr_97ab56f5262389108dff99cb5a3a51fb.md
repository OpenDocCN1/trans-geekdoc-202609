Next, we divide the data set into two parts: a training set (80% of the data) and a hold-out test set (20% of the data), as in Figure 2.16. The rank estimates from the full training set can be used to determine the MSE of the training set and the test set as a baseline for our model accuracy. This requires that we set \(\lambda = 0\) in Eq. (2.8.15). Of course, we must now standardize the **X** matrix before obtaining the estimates. This is done preemptively in order to avoid problems later on of having one coefficient value dominate over the others, especially in the case of ridge due to the fact that coefficients are squared in its penalty function (James and Stein, 1961). This could happen if the range of one column is, say, 0-10^2 while another column is in the range of 0-10^6. The standardization of **X** is performed to bring the column values into the same range.
