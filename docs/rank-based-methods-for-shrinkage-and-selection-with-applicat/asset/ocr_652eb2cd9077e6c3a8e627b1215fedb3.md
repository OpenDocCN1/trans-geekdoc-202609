(△) are aLASSO, those labeled (•) are based on |t| and those labeled (▽) are LASSO. The criteria used for determining the best model is the adjusted R² statistic (James et al., 2013) given by

```
adjusted R^2 = 1 - \frac{RSS/(n-d-1)}{TSS/(n-1)}, \quad (2.7.20)
```

where

```
TSS = \sum_{i=1}^n (y_i - \bar{y})^2 \text{ and } RSS = \sum_{i=1}^n (y_i - \hat{y})^2,
```

with \(\bar{y}\) as the mean response and \(\hat{y}_i = (\hat{\theta}_n^{LS} + \sum_{j=1}^p x_{ij} \hat{\beta}_j^{LS})\) as the predicted response, with \(\hat{\theta}_n^{LS} = 0\) if the data is centered. Here, d is the number of parameters used in the model and can range from 1 to p. Typically, the adjusted R^2 value should increase as we add more parameters, then reach a maximum, and finally start to decrease as additional parameters begin to add noise to the model. As a practical matter, we will typically choose the number of parameters to maximize the adjusted R^2 statistic but there are situations where we may select fewer or greater than the optimal number if we have domain knowledge. In the absence of such knowledge, we attempt to balance under-fitting and over-fitting by maximizing the adjusted-R^2 statistic.

The best two-variable model is (F ~ Ed + C), the best three-variable model is (F ~ Ed + C + I), and so on. On the other hand, LASSO would incorrectly predict the best one-variable model is (F ~ C), correctly predict the best two-variable model is (F ~ Ed + C), incorrectly predict the best three-variable model is (F ~ C + Ed + A), and so on. They all correctly predict that the Ex variable could be removed with little or no impact since the adjusted R^2 values changes only by +0.0003 by including it. Therefore, a reasonable choice based on the adjusted R^2-values is the four-variable model (F ~ Ed + C + I + A), and aLASSO essentially found this model.

This demonstrates the oracle property of aLASSO can be very valuable for subset selection. Used in conjunction with the rank loss function, it provides a variable ordering that could be extracted from the R-aLASSO trace, assuming enough data is available, and the results could be used to perform optimal subset selection.
