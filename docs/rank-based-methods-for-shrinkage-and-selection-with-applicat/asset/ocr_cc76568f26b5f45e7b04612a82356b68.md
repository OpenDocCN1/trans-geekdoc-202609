while the eigenvalues of $(C + I_p)$ are $(\lambda_1 + 1, \lambda_2 + 1 ... , \lambda_p + 1)$. Then, we obtain the following identities

tr(F_d^T C^{-1} F_d) = \sum_{i=1}^p \frac{(\lambda_i + d)^2}{\lambda_i(\lambda_i + 1)^2},
\beta^T (C + I_p)^{-2} \beta = \sum_{i=1}^p \frac{\theta_i^2}{(\lambda_i + 1)^2}; \quad \theta = \Gamma^T \beta,
tr(F_d^T A F_d) = \sum_{i=1}^p \frac{q_{ii}(\lambda_i + d)^2}{(\lambda_i + 1)^2},

where $q_{ii} \ge 0$ is the $i$th diagonal element of the matrix $Q = \Gamma^T A \Gamma$. Also,

\(\eta^T F_d^T F_d \eta = \sum_{i=1}^p \frac{\eta_i^{*2}(\lambda_i + d)^2}{(\lambda_i + 1)^2},\)

where \(\eta_i^*\) is the $i$th element of vector \(\eta^* = \eta^T \Gamma\$. Similarly,

\(\eta^T F_d^T (C + I_p)^{-1} \beta = \sum_{i=1}^p \frac{\theta_i \eta_i^* (\lambda_i + d)}{(\lambda_i + 1)^2}.\)
