# 9.5.1 Comparison of Unrestricted vs. Restricted R-estimators

First, we compare \(\hat{\rho}_n^{\text{RR}}\) with \(\hat{\rho}_n^{\text{UR}}\) using their ADL$_2$-risk difference as follows,

ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{UR}\))-ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{RR}\)) = \(\eta^2\left(\text{tr}(\Sigma_{11:2}^{-1}-\text{tr}(\Sigma_{11}^{-1})-\Delta^2\text{Ch}_{\min}(\mathbf{M}\Sigma_{22:1}^{-1})\right)\).

Thus, the difference is non-negative whenever

\(0 < \Delta^2 \le \frac{\text{tr}(\mathbf{M}\Sigma_{22:1}^{-1})}{\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})}\) (9.5.1)

which means \(\hat{\rho}_{1n}^\text{RR}\) outperforms \(\hat{\rho}_{1n}^\text{UR}\) for \(\Delta^2\) in the above interval; otherwise, \(\hat{\rho}_{1n}^\text{UR}\) outperforms \(\hat{\rho}_{1n}^\text{RR}\). That is, neither \(\hat{\rho}_{1n}^\text{UR}\) nor \(\hat{\rho}_{1n}^\text{RR}\) outperforms the other uniformly.

# 9.5.2 Comparison of Unrestricted vs. Preliminary Test R-estimator

Here

ADL$_2$-risk(\(\hat{\rho}_n^\text{UR}\)) - ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{PTR}(\lambda)\)) = \(\eta^2\left(\text{tr}(\Sigma_{11:2}^{-1} - \Sigma_{11}^{-1})\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \Delta^2\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})\left(2\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \mathcal{H}_{p_2+4}(\lambda^2, \Delta^2)\right)\right)\).

The expression is non-negative whenever

\(0 \le \Delta^2 \le \frac{\text{tr}(\mathbf{M}\Sigma_{22:1}^{-1})\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2)}{\text{Ch}_{\max}(\mathbf{M}\Sigma_{22:1}^{-1})\left(2\mathcal{H}_{p_2+2}(\lambda^2, \Delta^2) - \mathcal{H}_{p_2+4}(\lambda^2, \Delta^2)\right)}\). (9.5.2)

Hence, \(\hat{\rho}_{1n}^\text{PTR}\) outperforms \(\hat{\rho}_{1n}^\text{UR}\) in this interval; otherwise, \(\hat{\rho}_{1n}^\text{UR}\) outperforms \(\hat{\rho}_{1n}^\text{PTR}\). It follows that PTRE fails to dominate the URE, \(\hat{\rho}_{1n}^\text{UR}\).

# 9.5.3 Comparison of Unrestricted vs. Stein–Saleh-type R-estimators

We provide the comparison in a form of a theorem.

# Theorem 9.4 Let

\(h = \frac{\text{Ch}_{\max}(\mathbf{M})}{\text{tr}(\mathbf{M})}, \quad 0 < h \le 1.\)

Then, a sufficient condition for the asymptotic dominance of Stein–Saleh R-estimator, \(\hat{\rho}_{1n}^\text{SSR}\), over URE, \(\hat{\rho}_{1n}^\text{UR}\). That is ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{UR}\)) \(\ge\) ADL$_2$-risk(\(\hat{\rho}_{1n}^\text{SSR}\)) for all \(\Delta^2 \in \mathbb{R}\) is that the shrinkage factor, c, is positive and it satisfies the inequality

\(2\mathbb{E} \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] - c\mathbb{E} \left[ \chi_{p_2+2}^{-4}(\Delta^2) \right] -(c+4)h\Delta^2 \mathbb{E} \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \ge 0 \quad \forall \Delta^2 \in \mathbb{R}^+\) (9.5.3)
