\( z = X\beta. \)

The predicted values are computed using the sigmoid function, which would be implemented in R or Python using the expression:

\( p(X) = \frac{1}{1 + \exp(-X\beta)} = \frac{1}{1 + \exp(-z)}. \)

Here, the vector, p(X), is a produced via a term-by-term application of the sigmoid function to vector, z. Next the loss is determined using the log-likelihood function

\( J(\beta) = -\frac{1}{n} \sum_{i=1}^n [y_i \log p(\mathbf{x}_i) + (1 - y_i) \log(1 - p(\mathbf{x}_i))]. \)

Finally, the \(\beta\) values are updated at each iteration \(t\) of a gradient descent-based optimization routine using

\( \beta^{(t+1)} = \beta^{(t)} - \frac{\ell}{n} X^T(p(X) - Y). \)

Here we seek to drive the second term to zero within a given accuracy tolerance using numerical techniques, and specifically we desire that at convergence

\( X^T(p(X) - Y) = \mathbf{0}. \)

For the equivalent steps in the rank-based approach, define \( p_i = p(\mathbf{x}_i) \). Starting with Eq. (12.2.8), we follow the same steps outlined above to obtain

\( \frac{\partial D_n(\beta)}{\partial \beta_j} = -x_j \sum_{i=1}^n p_i(1 - p_i) a_n(R_{n_i}(\beta)). \)

The update equation for each \(\beta_i\) to compute the new parameter values is given by

\( \beta_j^{(t+1)} = \beta_j^{(t)} - \ell \times \frac{\partial D_n(\beta)}{\partial \beta_j}. \)

Again, we note that the quantities are obtained by summing over the entire data set rather than a single observation, and that it is applied to all parameters, \(j = 1, ..., p\).
