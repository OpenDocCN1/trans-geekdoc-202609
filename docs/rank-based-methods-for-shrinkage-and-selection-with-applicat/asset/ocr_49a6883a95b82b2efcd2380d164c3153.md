As described in Chapter 3, we consider the asymptotic distributional risk of each estimator under the L2 loss denoted by

```
ADL_2-risk(\hat{\boldsymbol{\beta}}_n) = ADV(\hat{\boldsymbol{\beta}}_n) + ADB^2(\hat{\boldsymbol{\beta}}_n)
```

where ADV(\hat{\boldsymbol{\beta}}_n) is the asymptotic distributional variance and ADB^2(\hat{\boldsymbol{\beta}}_n) is the square of the asymptotic distributional bias. Hence, the ADL_2-risk of \hat{\boldsymbol{\beta}}^{\text{UR}} is given by

```
ADL_2-risk(\hat{\boldsymbol{\beta}}_n^{\text{UR}}) = \eta^2 \text{tr}(\mathbf{C}^{-1}).
```

An estimator performs better if it has a lower ADL2-risk. We will also be comparing the asymptotic distributional L2-risk efficiency (ADRE) of the various estimators. As described in Chapter 3, the relative efficiency of two estimators is given by

```
ADRE(\hat{\boldsymbol{\beta}}_n : \hat{\boldsymbol{\beta}}_n^{*}) = \frac{\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n^{*})}{\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n)}.
```

# 6.3 Model Sparsity and Detection

There are many applications where the data scientist expects sparsity in the parameter set. That is, some \boldsymbol{\beta} are non-zero while other \boldsymbol{\beta} are either zero or very close to zero. The non-zero set is considered to be significant while the rest can be neglected in order to create a compact model. In such cases, it is convenient to rewrite the multiple regression model in Eq. (6.2.1) as

```
y = X_1\beta_1 + X_2\beta_2 + \varepsilon
```

where \boldsymbol{\beta}_1 is a p_1-vector while \boldsymbol{\beta}_2 is a p_2-vector and X = (X_1, X_2) is an n \times p matrix of real numbers, where the dimension of X_1 and X_2 are n \times p_1, and n \times p_2, respectively. The question becomes one of figuring out how to find the sizes of these two \boldsymbol{\beta}-vectors.

One approach is to use the LASSO R-estimator as follows

```
\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda) = \underset{\boldsymbol{\beta} \in \mathbb{R}^p}{\text{argmin}} \{ D_n(\boldsymbol{\beta}) + \lambda \sum_{j=1}^p |\beta_j| \}
```

where

```
D_n(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - (\mathbf{x}_i - \bar{\mathbf{x}})^\top \boldsymbol{\theta}) a_n(R_{n_i}(\boldsymbol{\beta})).
```
