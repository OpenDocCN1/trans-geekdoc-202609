Assume that the true value of the output is known to be y. The output error after completing the forward path is given by y - y_F. We need to drive this error to 0 by changing \boldsymbol{\beta} in the network. The log-likelihood loss is computed using

J(\boldsymbol{\beta}) = -y \log y_F - (1 - y) \log(1 - y_F). \quad (12.5.6)
