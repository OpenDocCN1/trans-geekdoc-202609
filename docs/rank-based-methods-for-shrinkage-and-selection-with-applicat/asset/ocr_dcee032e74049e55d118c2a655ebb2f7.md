+   (b)

```
\text{ADL}_2\text{-risk}(\hat{\beta}^{\text{ridgeR}}_{\mathcal{s}_1}(\gamma_n)) \geqslant \text{ADL}_2\text{-risk}(\hat{\beta}^{\text{PTR}}_{\mathcal{s}_1}(\gamma_n))
```

accordingly as

```
\delta^*_{s_2}^\top M^* \delta^*_{s_2} \leqslant \frac{\eta^2 \text{tr}(M^*) \mathcal{H}_{p_{2n}+2}(\lambda^2; \Delta^2)}{(2\mathcal{H}_{p_{2n}+2}(\lambda^2; \Delta^2) - \mathcal{H}_{p_{2n}+4}(\lambda^2; \Delta^2))}. \quad (10.8.1)
```

+   (c) If \(p_{2n} - 2 \geqslant 3\), then

```
\text{ADL}_2\text{-risk}(\hat{\beta}^{\text{SSR}}_{\mathcal{s}_1}(\gamma_n)) \leqslant \text{ADL}_2\text{-risk}(\hat{\beta}^{\text{ridgeR}}_{\mathcal{s}_1}(\gamma_n)), \quad \forall \Delta^2 \in \mathbb{R}^+
```

when

```
\frac{\text{tr}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1})}{\text{Ch}_{max}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1})} \geq \frac{p_{2n} + 2}{2}.
```

**Proof:** It is easy to prove (a) and (b), which are left as exercises for the reader. To prove (c), we can write

```
\text{ADL}_2\text{-risk}(\hat{\beta}^{\text{SSR}}_{\mathcal{s}_1}(\gamma_n)) = \text{ADL}_2\text{-risk}(\hat{\beta}^{\text{ridgeR}}_{\mathcal{s}_1}(\gamma_n))
- (p_{2n} - 2)\eta^2 \text{tr}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1}) \left\{ (p_{2n} - 2)\mathbb{E} \left[ \chi^{-4}_{p_{2n}+2}(\Delta^2) \right] 
+ 2 \left[ 1 - \frac{(p_{2n} + 2) \delta^*_{s_2}^\top \mathbf{M}^* \delta^*_{s_2} \eta^2}{2\Delta^2 \text{tr}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1})} \right] \Delta^2 \mathbb{E} \left[ \chi^{-4}_{p_{2n}+4}(\Delta^2) \right] \right\}.
```

From the above, it follows that

```
\forall \Delta^2 \in \mathbb{R}^+, \quad \text{ADL}_2\text{-risk}(\hat{\beta}^{\text{SSR}}_{\mathcal{s}_1}(\gamma_n)) \leqslant \text{ADL}_2\text{-risk}(\hat{\beta}^{\text{ridgeR}}_{\mathcal{s}_1}(\gamma_n))
```

provided

```
\frac{\text{tr}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1})}{\text{Ch}_{max}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1})} \geq \frac{p_{2n} + 2}{2},
```

where we used

```
\Delta^2 \text{Ch}_{min}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1}) \leq \Delta^2 \frac{\delta^*_{s_2}^\top \mathbf{M}^* \delta^*_{s_2}}{\delta^*_{s_2}^\top \mathbf{C}_{22\cdot 1} \delta^*_{s_2}} \leq \Delta^2 \text{Ch}_{max}(\mathbf{M}^* \mathbf{C}^{-1}_{22\cdot 1}).
```

The next theorem gives a sufficient condition for \(p_{2n} - 2 \geqslant 3\) for which \(\hat{\beta}^{\text{SSR}}_{\mathcal{s}_1}(\gamma_n)\) dominates \(\hat{\beta}^{\text{ridgeR}}_{\mathcal{s}_1}(\gamma_n)\).
