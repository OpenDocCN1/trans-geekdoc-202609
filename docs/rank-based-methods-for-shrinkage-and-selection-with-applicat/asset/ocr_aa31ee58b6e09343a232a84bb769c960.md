# 8.7. Write a gradient descent algorithm to find the following solution

```
\(\hat{\beta}^{aLassoR}_n (d) = \underset{\beta \in R^p}{argmin} \left\{ D(\beta) + \lambda \sum_{j=1}^p \omega_j |d \hat{\beta}^{UR}_j - \theta_j| \right\},\)
```

where \(\hat{\beta}^{UR}_j\) is the \(j\)th element of R estimator under the model of Eq. (8.7.1), the weight function is

```
\(\omega_j = \frac{1}{|\hat{\beta}^*_j|^\gamma}; \gamma > 0,\)
```

and \(\hat{\beta}^*_j\) is a \(\sqrt{n}\)-consistent estimator of \(\beta\), and \(0 < d < 1\).
