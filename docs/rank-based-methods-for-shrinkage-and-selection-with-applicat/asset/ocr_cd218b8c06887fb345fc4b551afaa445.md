# (iv) Stein–Saleh-type vs. PSRE

```
ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{SSR}) - ADL_2 - risk(\hat{\boldsymbol{\beta}}_n^{SSR+})
= \eta^2 tr(C_{22:1}^{-1}) \mathbb{E}[(1-(p_2-2)\chi_{p_2+2}^{-2}(\Delta^2))^2 I(\chi_{p_2+2}^2(\Delta^2) < p_2 - 2)]
+\Delta^2 Ch_{min}(C_{22:1}^{-1})\big\{2 \mathbb{E}[(1-(p_2-2)\chi_{p_2+2}^{-2}(\Delta^2)) I(\chi_{p_2+2}^2(\Delta^2) < p_2 - 2)]
+ \mathbb{E}[(1-(p_2-2)\chi_{p_2+4}^{-4}(\Delta^2)) I(\chi_{p_2+4}^2(\Delta^2) < p_2 - 2)]\big\} \ge 0
```

for all \(\Delta^2 \ge 0\), since

```
0 < \chi_{p_2+2}^2(\Delta^2) < p_2 - 2 \Rightarrow ((p_2 - 2)\chi_{p_2+2}^2(\Delta^2) - 1) \ge 0.
```

Then, combining (iii) and (iv) we find that

```
ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{SSR+}) \le ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{SSR}) \le ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{UR}) .
```

# (v) LASSO R estimator vs. URE

```
ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{LassoR}(\lambda)) - ADL_2^* - risk(\hat{\boldsymbol{\beta}}_n^{UR}) = \eta^2 [\Delta^2 Ch_{min}(C_{22:1}^{-1}) - tr(C_{22:1}^{-1})] .
```

LASSO R-estimator performs better than the URE whenever

```
\Delta^2 \le \frac{tr(C_{22:1}^{-1})}{Ch_{min}(C_{22:1}^{-1})}.
```

Otherwise, the URE is superior. Hence, none of the estimators outperforms the other uniformly.
