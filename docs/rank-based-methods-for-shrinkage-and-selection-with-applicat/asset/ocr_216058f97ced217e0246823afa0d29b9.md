$$J^{\text{LLR}}(\boldsymbol{\beta}) = \sum_{i=1}^n [y_i (-\log p_i) + (1-y_i)(-\log(1 - p_i))], \quad (11.5.16)$$

where \(p_i = (1 + \exp(-\mathbf{x}_i^T \boldsymbol{\beta}))^{-1}\) as before. We see that there are two terms, one for the case when \(y_i = 1\) (first term) and another for the case when \(y_i = 0\) (second term). We also have a penalized version using ridge as follows:

$$J^{\text{LLR-ridge}}(\boldsymbol{\beta}) = \sum_{i=1}^n [y_i (-\log p_i) + (1-y_i)(-\log(1-p_i))] + \lambda_2 \boldsymbol{\beta}^T \boldsymbol{\beta}. \quad (11.5.17)$$

The \(\lambda_2\) parameter can be moved to the first term by defining a \(C\) parameter and setting \(C = 1/\lambda_2\) to conform to notation used in SVMs. Therefore,

$$J^{\text{LLR-ridge}}(\boldsymbol{\beta}) = C \sum_{i=1}^n [y_i (-\log p_i) + (1-y_i)(-\log(1-p_i))] + \boldsymbol{\beta}^T \boldsymbol{\beta}. \quad (11.5.18)$$

We can now reformulate this objective function by simply replacing the two log terms under the summation with generic functions, \(f_1(\mathbf{x}_i^T \boldsymbol{\beta})\) and \(f_0(\mathbf{x}_i^T \boldsymbol{\beta})\), and switching the roles of loss and penalty functions:

$$J^{\text{SVC}}(\boldsymbol{\beta}) = \boldsymbol{\beta}^T \boldsymbol{\beta} + C \sum_{i=1}^n [y_i f_1(\mathbf{x}_i^T \boldsymbol{\beta}) + (1-y_i) f_0(\mathbf{x}_i^T \boldsymbol{\beta})]. \quad (11.5.19)$$

This produces the basic objective function for a support vector classifier. The reason we may choose to do this is to provide more flexibility than the two functions that arose from the log-likelihood derivation. We can make \(f_1(\cdot)\) and \(f_0(\cdot)\) anything we want. In particular, we can choose two complementary functions that allow for larger-margin boundaries, and this is exactly what leads to support vector classifiers.

Consider two functions commonly referred to as the *hinge loss functions*:

$$f_1(\mathbf{x}_i^T \boldsymbol{\beta}) = \max(0, 1 - \mathbf{x}_i^T \boldsymbol{\beta}) \text{ and } f_0(\mathbf{x}_i^T \boldsymbol{\beta}) = \max(0, 1 + \mathbf{x}_i^T \boldsymbol{\beta}). \quad (11.5.20)$$

Then, plugging into Eq. (11.5.19) and after some rearrangement, we obtain

$$J^{\text{SVC}}(\boldsymbol{\beta}) = \boldsymbol{\beta}^T \boldsymbol{\beta} + C \sum_{i=1}^n \max[0, 1 - (2y_i - 1)(\mathbf{x}_i^T \boldsymbol{\beta})]. \quad (11.5.21)$$

Re-writing it in the form of a constrained optimization problem, we obtain

$$\min_{\boldsymbol{\beta}} \sum_{j=1}^p \beta_j^2 \quad \text{s.t.} \quad (2y_i - 1)(\mathbf{x}_i^T \boldsymbol{\beta}) > c, \forall i = 1, ..., n, \quad (11.5.22)$$

where \(c = 1\) for SVC and \(c = 0\) for logistic regression. There are many ways to solve this optimization problem, but the details are not important here.
