## 3.4 Ridge-type R-estimator of $\theta$

We examined general shrinkage estimators that used a factor, $c$, in the previous section. As a special case of a shrinkage R-estimator, let $c = 1/(1+\lambda)$, $\lambda > 0$ and use this to define a ridge-type R-estimator of the location parameter as follows

\(\hat{\theta}^{\text{ridgeR}}_n(\lambda) = \frac{1}{1 + \lambda} \hat{\theta}^{\text{UR}}_n.\)

**Theorem 3.4** Under the local alternative hypothesis, $K_{(n)}$, the ADB, ADV, and ADL$_2$-risk of the ridge-type R-estimator of $\theta$, i.e. $\hat{\theta}^{\text{ridgeR}}_n(\lambda)$, are

ADB \(\left(\hat{\theta}^{\text{ridgeR}}_n(\lambda)\right) = -\eta \frac{\lambda}{1 + \lambda} \Delta,$
ADV \(\left(\hat{\theta}^{\text{ridgeR}}_n(\lambda)\right) = \eta^2 \frac{1}{(1 + \lambda)^2},$
ADL$_2$-risk \(\left(\hat{\theta}^{\text{ridgeR}}_n(\lambda)\right) = \eta^2 \frac{1}{(1 + \lambda)^2} (1 + \lambda^2 \Delta^2).\)

**Proof:** The result can easily be found by considering $c = 1/(1 + \lambda)$ in Theorem 3.3.

Solving

\(\frac{d \text{ADL}_2\text{-risk} \left( \hat{\theta}^{\text{ridgeR}}_n(\lambda) \right)}{d\lambda} = \eta^2 \frac{2\lambda \Delta^2(1 + \lambda) - 2(1 + \lambda^2 \Delta^2)}{(1 + \lambda)^3}
= \eta^2 \frac{2\lambda \Delta^2 - 2}{(1 + \lambda)^3} = 0 \quad (3.4.1)\)

results in $\lambda_{opt} = \Delta^{-2}$. Then, for $\lambda_{opt}$, the ADL$_2$-risk is given by

\(\text{ADL}_2\text{-risk} \left( \hat{\theta}^{\text{ridgeR}}_n(\lambda_{opt}) \right) = \eta^2 \frac{\Delta^2}{1 + \Delta^2}.\)

The ADL$_2$-risk-ratio of $\hat{\theta}^{\text{UR}}_n$ and $\hat{\theta}^{\text{ridgeR}}_n(\Delta^{-2})$ is given by $\Delta^2/(1 + \Delta^2)$ for $\Delta^2 \in \mathbb{R}^+$. It follows that $\hat{\theta}^{\text{ridgeR}}_n(\lambda_{opt})$ is uniformly better than $\hat{\theta}^{\text{UR}}_n$ from

\(\text{ADRE}\left( \hat{\theta}^{\text{ridgeR}}_n(\lambda_{opt}) : \hat{\theta}^{\text{UR}}_n \right) = 1 + \frac{1}{\Delta^2}. \quad (3.4.2)\)

## 3.5 Preliminary Test R-estimator of $\theta$

In the statistical literature, the preliminary test estimation of parameters was introduced by Bancroft (1944, 1964, 1965) to estimate the parameters of a model when it is suspected that some “uncertain prior information” (UPI) on the parameter(s) of interest are available. The method involves a statistical test of UPI based on the appropriate statistics and a decision on whether the model parameters should be accepted.

Consider the UPI, as denoted here by the null hypothesis, $\mathcal{H}_0 : \theta = 0$. If we suspect $\theta$ to be 0, then the restricted R-estimator ($\hat{\theta}_n^{\text{RR}} = 0$) should be used. In practice, there may be some degree of uncertainty about this prior information, $\theta = 0$. This doubt about the UPI can be removed by using “Fisher’s recipe” of testing the hypothesis $\mathcal{H}_0 : \theta = 0$ against the alternative $\mathcal{H}_A : \theta \neq 0$, or the local alternative $K_{(n)} : \theta = n^{-1/2}\delta$ with a fixed $\delta$. As a result of this test, we choose $\hat{\theta}_n^{\text{UR}}$ or $\hat{\theta}_n^{\text{RR}}$ based on the rejection or acceptance of $\mathcal{H}_0$. Accordingly, following Bancroft (1944), we introduce the preliminary test R-estimator (PTRE) denoted by $\hat{\theta}_n^{\text{PTR}}(\alpha)$ as

$\hat{\theta}_n^{\text{PTR}}(\alpha) = \hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n > \chi_1^2(\alpha)) \quad (3.5.1)$

where $\mathcal{L}_n$ is the test statistic for testing $\mathcal{H}_0 : \theta = 0$ and defined as

$\mathcal{L}_n = \frac{n(\hat{\theta}_n^{\text{UR}})^2}{\hat{\eta}^2}. \quad (3.5.2)$

Under the null hypothesis, $\mathcal{L}_n$ has the chi-square distribution with one degree of freedom (d.f.), and $\chi_1^2(\alpha)$ is the $\alpha$-level upper critical value of a central $\chi^2$ distribution with 1 d.f. If $\alpha = 1$, $\hat{\theta}_n^{\text{UR}}$ is always chosen; if $\alpha = 0$, $\hat{\theta}_n^{\text{RR}}$ is chosen. Since $0 < \alpha < 1$, $\hat{\theta}_n^{\text{PTR}}$ in repeated samples will result in a combination of $\hat{\theta}_n^{\text{UR}}$ and $\hat{\theta}_n^{\text{RR}}$. Note that the PTRE procedure leads to the choice of only two values, namely, either $\hat{\theta}_n^{\text{UR}}$ or $\hat{\theta}_n^{\text{RR}}$. Also, the PTRE depends on the level of significance $\alpha$.

**Remark 3.1** For the test statistic, we need $\hat{\eta}$. A consistent estimator is the median absolute deviation (MAD) as discussed in Chapter 1. More generally, we showed earlier that

$\eta^2 = \frac{A_\phi^2}{\gamma^2(\phi, f)}, \quad \gamma(\phi, f) = \int_{-\infty}^{\infty} f(x) d\Phi(F(x))$.

To estimate $\gamma(\phi, f)$, we use

$\hat{\gamma}(\phi, f) = \int_{-\infty}^{\infty} f_n(x) d\Phi(F_n(x)) \quad (3.5.3)$

where \( f_n(x) \) and \( F_n(x) \) are the estimates of \( f(x) \) and \( F(x) \), respectively. Then,

```
\(\hat{\eta}^2 = \frac{A_n^2}{\hat{\gamma}^2(\phi, f)}, \quad A_n^2 = n^{-1} \sum_{i=1}^n a_n^+(i)^2.\) (3.5.4)
```

Note also that

```
\(\frac{\sqrt{n}\hat{\theta}_n^{UR}}{\hat{\eta}} \sim N(0, 1),\) (3.5.5)
```

and from Eq. (3.2.3), we know that

```
\(\frac{T_n(0)}{A_n} \sim N(0, 1).\) (3.5.6)
```

Then,

```
\(\mathcal{L}_n = \frac{T_n^2(0)}{A_n^2} = \left( \frac{\sqrt{n}\hat{\theta}_n^{UR}}{\hat{\eta}} \right)^2 + o_p(1).\) (3.5.7)
```

This result is used in the theorems to follow.
