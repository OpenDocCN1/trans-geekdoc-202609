# Table 12.1 RNN-ridge algorithm.

| Line | Content |
|---|---|
| 1 | Input: training data set X, y; |
| 2 | Set n = number of observations, p = number of variables |
| 3 | Network: number of layers (L); number of units in each layer (Uk), k = 1, ..., L |
| 4 | Number of inputs = p + 1, , number of outputs= m (m ≤ 2, binary; m > 2, multi-class) |
| 5 | Activation: layer L = sigmoid, layers 1, ..., L – 1 = relu |
| 6 | Set number of epochs (maxIter), learning rate (t), ridge parameter (λ2) |
| 7 | Momentum (γ). |
| 8 | Initialize matrices and vectors β_k^(0), k = 1, ..., L to small non-zero values |
| 9 | Set t = 0 |
| 10 | While t < maxIter do |
| 11 | Complete forward propagation through network using X and β_k^(t), k = 1, ..., L |
| 12 | Update objective D_n(β) = Σ_i=1^n (y_i – y_ti) a_n(R_n(β)) + λ_2 Σ_k=1^L β_k^T β_k |
| 13 | Use backprop to compute gradients, as follows: |
| 14 | For k = L downto 1 do |
| 15 | Compute gradients ∇β_k^(t+1) of D_n(β) |
| 16 | Gradient descent w/momentum v_DB,k^(t+1) = γv_DB,k^(t) + (1 – γ) × ∇β_k^(t+1) |
| 17 | Update estimates β_k^(t+1) = β_k^(t) – t × v_DB,k^(t+1) |
| 18 | End for |
| 19 | Update t = t + 1 |
| 20 | End while |
| 21 | Final model: β_k, k = 1, ..., L |

For example, if the true value is 1 and the quantized model prediction is 1, it is referred to as a true positive (tp). Similarly, a true value of 0 and a predicted value of 0 is called a true negative (tn). On the other hand, incorrect predictions are either false positives (fp) or false negatives (fn), i.e. the model is confused. The combination of true values along the diagonal and false values on the off-diagonals forms a confusion matrix. This matrix is very useful in telling us what type of error we are making using a particular classifier. To obtain it, we can simply quantize each predicted probability and count up the numbers in each matrix entry. Then using this information, we compute the recall and precision, which are both standard terms in binary classification (cf. James et al., 2013). Finally, the F1 score is computed using these two quantities to assess the overall effectiveness of the model.
