# 5.4.1 LASSO-type R-estimator of the \(\boldsymbol{\beta}\)

We obtain the LASSO-type R-estimator of the slope-vector as

```
\(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda) = \begin{pmatrix} \hat{\beta}_1^{\text{UR}} \left( 1 - \frac{\lambda}{\sqrt{\mathcal{L}_n}} \right)^+ \\ \vdots \\ \hat{\beta}_p^{\text{UR}} \left( 1 - \frac{\lambda}{\sqrt{\mathcal{L}_p}} \right)^+ \end{pmatrix}\)
```

where \(\mathcal{L}_j^2 = |\sqrt{\kappa_j} Q_j \hat{\beta}_j^{\text{UR}} / \eta|^2\). It can be rewritten based on \(Z_j\) as

```
\(\sqrt{n}\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda) = \left( \frac{\eta}{\sqrt{\kappa_j}Q_j}\text{sgn}(Z_j) \left( |Z_j| - \lambda \right)^+ \mid j=1, ..., p \right)^\top \quad (5.4.3)\)
```

based on Eq. (5.4.1). Hence, we have the following theorem.

**Theorem 5.8** Under the local alternatives, \(K_{(n)}\), the asymptotic distributional bias, and the lower bound of ADL\(_2\)-risk of the LASSO-type R-estimator, \(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)\), are respectively given by

```
\(\text{ADB}(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)) = \left( \frac{-\eta}{\sqrt{\kappa_j}Q_j} \left[ \Delta_j \mathcal{H}_3(\lambda^2 : \Delta_j^2) - \lambda (\Phi(\lambda - \Delta_j) - \Phi(\lambda + \Delta_j)) \right] \mid j=1, ..., p \right)^\top\)
```

and

```
\(\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)) = \eta^2 \sum_{j=1}^p \frac{1}{\kappa_j Q_j} \rho_{\text{ST}}(\lambda, \Delta_j),\)
```

where

```
\(\rho_{\text{ST}}(\lambda, \Delta_j) = 1 - \mathcal{H}_3(\lambda^2, \Delta_j^2) + \Delta_j^2(2\mathcal{H}_3(\lambda^2, \Delta_j^2) - \mathcal{H}_5(\lambda^2, \Delta_j^2)) + \lambda^2(1 - \mathcal{H}_1(\lambda^2, \Delta_j^2)) - 2\lambda(\phi(\lambda - \Delta_j) + \phi(\lambda + \Delta_j)).\)
```

The lower bound of ADL\(_2\)-risk(\(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)\)) is given by

```
\(\text{ADL}_2^{*\text{-risk}}(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)) = \eta^2 \left( \text{tr}(D_{22}^{[1]}) + \Delta^2 \text{Ch}_{\text{min}}(D_{22}^{[2]}) \right).\)
```
