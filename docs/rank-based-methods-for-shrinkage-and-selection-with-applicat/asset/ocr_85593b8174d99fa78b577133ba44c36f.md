and

```
\(ADL_2\text{-risk}(\hat{\beta}_n^{SSR}(\lambda)) = \eta^2 \left( tr(C_{11:2}^{-1}) + tr(C_{22:1}^{-1}) - \lambda tr(C_{22:1}^{-1}) X(\lambda, \Delta^2) \right. \\
\left. + \lambda(\lambda + 4) \delta_2^T \delta_2 E \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right)\)
```

where

```
\(X(\lambda, \Delta^2) = 2E \left[ \chi_{p_2+2}^{-2}(\Delta^2) \right] - \lambda E \left[ \chi_{p_2+2}^{-4}(\Delta^2) \right]\)
```

and the lower bound is

```
\(ADL_2^*\text{-risk}(\hat{\beta}_n^{SSR}(\lambda)) = \eta^2 \left[ tr(C_{11:2}^{-1}) + tr(C_{22:1}^{-1}) - \lambda tr(C_{22:1}^{-1}) X(\lambda, \Delta^2) \right. \\
\left. + \lambda(\lambda + 4) \Delta^2 Ch_{min}(C_{22:1}^{-1}) E \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right]\)
```

Hence, the ADRE expression is given by

```
\(ADRE(\hat{\beta}_n^{SSR}(\lambda) : \hat{\beta}_n^{UR}) = \left( 1 + \frac{tr(C_{22:1}^{-1})}{tr(C_{11:2}^{-1})} \right) \left[ 1 + \frac{tr(C_{22:1}^{-1})}{tr(C_{11:2}^{-1})} (1 - \lambda X(\lambda, \Delta^2)) \right. \\
\left. + \lambda(\lambda + 4) \frac{\Delta^2 Ch_{min}(C_{22:1}^{-1})}{tr(C_{11:2}^{-1})} E \left[ \chi_{p_2+4}^{-4}(\Delta^2) \right] \right]^{-1}\)
```

# 6.4.3 Positive-rule Stein–Saleh-type R-estimator

The positive-rule Stein–Saleh-type R-estimator (PRSSRE) is defined by

```
\(\hat{\beta}_n^{SSR+}(\lambda) = \begin{pmatrix} \dots & \hat{\beta}_{ln}^{UR} & \dots \\ \dots & \dots & \dots \\ (1 - \lambda \mathcal{L}_n^{-1}) I(\mathcal{L}_n > \lambda) \hat{\beta}_{2n}^{UR} \end{pmatrix}\)
```

where \(\lambda = p_2 - 2\) is the shrinkage factor. Consequently, one may obtain the ADB and \(ADL_2\)-risk of \(\hat{\beta}^{SSR+}(\lambda)\) given by

```
\(ADB(\hat{\beta}_n^{SSR+}(\lambda)) = \begin{pmatrix} 0_{p_1} \\ -\delta_2 E \left[ (1 - \lambda \chi_{p_2+2}^{-2}(\Delta^2)) I(\chi_{p_2+2}^2(\Delta^2) \le \lambda) \right] \end{pmatrix}\)
```

and

```
\(ADL_2\text{-risk}(\hat{\beta}_n^{SSR+}(\lambda)) = ADL_2\text{-risk}(\hat{\beta}_n^{SSR}(\lambda)) + \delta_2^T \delta_2 Y(\lambda, \Delta^2)\)
```
