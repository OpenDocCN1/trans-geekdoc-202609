
where

$$\mathcal{L}_{n_j} = \frac{(\sqrt{n}\hat{\vartheta}_j^\text{UR})^2}{\hat{\eta}^2\kappa_j}.$$ 
(4.8.2)

**Theorem 4.9** Under the local alternatives, \(K_{(n)}\), the asymptotic distributional bias, and ADL\(_2\)-risk of the positive-rule Saleh R-estimator, \(\hat{\vartheta}_n^{\text{SR}+}\), are respectively given by

$$\text{ADB}(\hat{\vartheta}_n^{\text{SR}+}(\lambda)) = -\eta \left(\Delta_j\mathcal{H}_3(\lambda^2,\Delta^2) - \lambda \left(\Phi(\lambda - \Delta_j)\right.\right.\left.\left. -\Phi(\lambda + \Delta_j)\right)\right| j = 1, \dots, p\right)^\top, $$

and

$$\text{ADL}_2\text{-risk}(\hat{\vartheta}_n^{\text{SR}+}(\lambda)) = \eta^2\left(\sum_{j=1}^p \left\{\kappa_j \left(1 - \mathcal{H}_3(\lambda^2,\Delta_j^2)\right)\right.\right.\left.\left. + \Delta_j^2 \left(2\mathcal{H}_3(\lambda^2,\Delta_j^2) - \mathcal{H}_5(\lambda^2,\Delta_j^2)\right)\right.\right.\left.\left. + \lambda^2(1 - \mathcal{H}_1(\lambda^2,\Delta_j^2)) - 2\lambda \left(\phi(\lambda - \Delta_j) + \phi(\lambda + \Delta_j)\right)\right\}\right). $$

To obtain the LASSO R-estimator, one minimizes the rank dispersion function (Jaeckel, 1972) with an \(L_1\) penalty as follows,

$$\hat{\vartheta}_{n_j}^{\text{LassoR}}(\lambda) = \left(\underset{\vartheta}{\text{argmin}} \left\{\sum_{j=1}^{n_j}|y_{i_j} - \vartheta|a_n^+(R_{n_j}(\vartheta_i)) + \lambda\kappa_j^\frac{1}{2}|\vartheta_i|\right\}\right| j = 1, \dots, p\right)^\top. $$

Now, consider a family of diagonal linear projections,

$$T_\text{DP}(\vartheta, \lambda) = \left(\lambda_1\hat{\vartheta}_{n_1}^\text{UR}, \dots, \lambda_p\hat{\vartheta}_{n_p}^\text{UR}\right)^\top. $$

Such estimators _keep_ or _kill_ each coordinate. Suppose we have available an oracle which would supply for us the optimal coefficients, \((\lambda_j| j = 1, \dots, p)\), for use in the diagonally linear projection scheme. These ideal coefficients are \(I(|\delta_j| > \eta\sqrt{\kappa_j})\), \(j = 1, \dots, p\). These yield the ideal asymptotic distributional L\(_2\)-risk as

$$\text{ADL}_2^*\text{-risk}(T_\text{DP}(\vartheta, \lambda)) = \sum_{j=1}^p \min(\delta_j^2, \eta^2\kappa_j). $$

Now suppose \(p_1\) of them satisfy \(\{\delta_j^2 < \eta^2| j = 1, \dots, p\}\) and \(p_2\) of them satisfy \(\{\delta_j^2 > \eta^2| j = 1, \dots, p\}\). Then we obtain \(\text{ADL}_2^*\text{-risk}(T_\text{DP}(\vartheta, \lambda))\) as

$$\text{ADL}_2^*\text{-risk}(\hat{\vartheta}_n^{\text{LassoR}}(\lambda)) = \eta^2(\text{tr}(\mathcal{K}_1) + \Delta^2\text{Ch}_{min}(\mathcal{K}_2)), $$

where

\(\Delta^2 = \eta^{-2} \delta_2^\top \mathcal{K}_2^{-1} \delta_2\)

and \(\mathcal{K} = \text{Diag}(\mathcal{K}_1, \mathcal{K}_2)\) and \(\text{Ch}_{\min}(\mathcal{K}_2^{-1})\) is the minimum eigenvalue of \(\mathcal{K}_2^{-1}\). Here, we assume that \(p_1\) parameters exceed the noise level, \(\eta \sqrt{\mathcal{K}_j}\), and \(p_2\) of them do not. Hence, the lower bound of \(\text{ADL}_2^* \text{-risk}(\hat{\theta}_n^{\text{LassoR}}(\lambda))\) is

\(\text{ADL}_2^* \text{-risk}(\hat{\theta}_n^{\text{LassoR}}(\lambda)) = \eta^2(\text{tr}(\mathcal{K}_1) + \Delta_L^2),\)

where \(\Delta_L^2 = \Delta^2 \text{Ch}_{\min}(\mathcal{K}_2)\). Thus,

\(\text{ADRE}(\hat{\theta}_n^{\text{LassoR}}(\lambda) : \hat{\theta}_n^{\text{UR}}) = \left(1 + \frac{\text{tr}(\mathcal{K}_2)}{\text{tr}(\mathcal{K}_1)}\right) \left(1 + \frac{\Delta^2 \text{Ch}_{\min}(\mathcal{K}_2)}{\text{tr}(\mathcal{K}_1)}\right)^{-1}\)

using the lower bound.

## 4.8.4 The Adaptive LASSO (aLASSO)

Adaptive LASSO is a variation of LASSO whereby

\(\hat{\theta}_n^{\text{aLassoR}}(\lambda_n) = \underset{\theta \in \mathbb{R}^p}{\text{argmin}} \left\{ \sum_{i=1}^p \sum_{j=1}^{n_i} |y_{ij} - \theta_i| a_n^+(R_{n_j}(\theta_i)) + \lambda_n \sum_{i=1}^p \hat{w}_i |\theta_i| \right\}\)

and \(\hat{w}_i, (i = 1, ..., p)\) are the weight functions, \(\hat{w}_i = |\hat{\theta}_i^{\text{UR}}|^{-\gamma}, \gamma > 0, i = 1, ..., p\). Like the positive-rule Saleh R-estimator, we can define an aLASSO-type R-estimator as

\(\hat{\theta}_n^{\text{aLassoR}}(\lambda_n) = \left( \left( \text{sgn}(\hat{\theta}_{n_j}^{\text{UR}}) \left( |\hat{\theta}_{n_j}^{\text{UR}}| - \lambda_n \hat{w}_j \right) I(\mathcal{L}_{n_j} > \lambda_n^2 \hat{w}_j^2) \right) \bigg| j = 1, ..., p \right)^\top .\) \tag{4.8.3}

We can rewrite this estimator based on \(Z_{n_i} = \sqrt{n} \hat{\theta}_{n_i}^{\text{UR}} / \eta \sqrt{\mathcal{K}_i}\) as

\(\sqrt{n} \hat{\theta}_{n_i}^{\text{aLassoR}}(\lambda_n) = \text{sgn}(\sqrt{n} \hat{\theta}_{n_i}^{\text{UR}}) \left( |\sqrt{n} \hat{\theta}_{n_i}^{\text{UR}}| - \lambda_n \hat{w}_1 \sqrt{\kappa_i} \eta \right)^+\)
\(= \eta \sqrt{\kappa_i} \text{sgn}(Z_{n_i}) (|Z_{n_i}| - \lambda_n \hat{w}_i)^+ .\)

Let \(\mathcal{A}_n^* = \{j : \hat{\theta}_{jn}^{\text{aLassoR}} \neq 0\}\) and \(\mathcal{A} = \{j : \theta_j^* \neq 0\}\) and the size of \(\mathcal{A}\) be \(p_o (< p)\).

**Theorem 4.10 (Oracle property)**

Let \(\lambda_n / \sqrt{n} \to 0\) and \(\lambda_n n^{\frac{r-1}{2}} \to \infty\). Then, adaptive LASSO must satisfy the following:

- (a) Asymptotic normality: \(\sqrt{n} (\hat{\theta}_{\mathcal{A}}^{*(n)} - \hat{\theta}_{\mathcal{A}}^*) \to^{\mathcal{D}}_{\mathcal{P}_{p_o}} N(\mathbf{0}, \eta^2 \mathcal{K}_1)\).

- (b) If \(\sqrt{n}\lambda_n \to \lambda_0 \in (0, \infty)\), then \(\lim_{n\to\infty} P(\hat{\theta}^*_{2n} = \mathbf{0}) = 1\), and

\(\sqrt{n}\gamma(\phi, f)\mathcal{X}_{p_0}\left\{(\hat{\theta}_{1n}^* - \theta^*) + n^{-\frac{1}{\gamma}}\gamma^{-1}(\phi, f)\mathcal{K}_{p_0}^{-1}\lambda_0\mathbf{b}\right\} \to \mathcal{N}_{p_0}(\mathbf{0}, A_\phi^2\mathcal{X}_1)\) \quad (4.8.4)

where \(\mathcal{K}_{p_0} = \text{Diag}(\kappa_1, \dots, \kappa_{p_0})\) and \(\mathbf{b} = \left(\frac{\text{sgn}(\theta_j^*)}{|\theta_j^*|}\Big| j = 1, \dots, p_0\right)\).

**Proof:** To prove the asymptotic normality, let \(\theta_i = \theta_i^* + \frac{u_i}{\sqrt{n}}\) and

\(\psi_n(\mathbf{u}) = \sum_{i=1}^p \sum_{j=1}^{n_i} \left| y_{ij} - (\theta^* + \frac{u_i}{\sqrt{n}}) \right| a_n^+(R_{n_i}(\theta_i^{**})) + \frac{\lambda_n}{\sqrt{n}} \sum_{i=1}^p \hat{w}_i \sqrt{n} \left( |\theta_i^* + \frac{u_i}{\sqrt{n}}| \right)\)

and

\(\psi_n(0) = \sum_{i=1}^p \sum_{j=1}^{n_i} |y_{ij} - \theta_i^*| a_n^+(R_{n_i}(\theta_i^{**})) + \frac{\lambda_n}{\sqrt{n}} \sum_{i=1}^p \hat{w}_i \sqrt{n} |\theta_i^*|.\)

Let \(\hat{\mathbf{u}}_n = \arg\min\{\psi_n(\mathbf{u})\}\); then \(\hat{\mathbf{u}}_n = \sqrt{n}(\hat{\theta}_n - \theta^*)\). Further, note that \(\Psi_n(\mathbf{u}) - \Psi_n(\mathbf{0}) = V_0^{(n)}(\mathbf{u})\) where

\(V_0^{(n)}(\mathbf{u}) = \mathbf{u}_{\mathcal{A}}^\top \mathcal{K}_{p_0}^{-1} \mathbf{u}_{\mathcal{A}} - 2\mathbf{u}_{\mathcal{A}}^\top \mathbf{W} + \frac{\lambda_n}{\sqrt{n}} \sum_{j=1}^p \hat{w}_j \sqrt{n} \left( |\theta_j^* + \frac{u_j}{\sqrt{n}}| - |\theta_j^*| \right).\)

We know that \(\mathcal{K}_n \to \mathcal{K}_{p_0}\) and \(\mathbf{W} \xrightarrow{\mathcal{D}} \mathcal{N}_p(\mathbf{0}, \eta^2\mathcal{K}_{p_0}^{-1})\). Consider the limiting behavior of the third term if \(\theta_j^* \neq 0\). Then, we have that

\(\hat{w}_j \xrightarrow{P} |\theta_j^*|^{-\gamma},\)

and

\(\sqrt{n}\left( \left| \theta_j^* + \frac{u_j}{\sqrt{n}} \right| - \left| \theta_j^* \right| \right) \xrightarrow{P} |u_j|\text{sgn}(\theta_j^*).\)

By Slutsky's theorem, we can show that

\(\frac{\lambda_n}{\sqrt{n}} \hat{w}_j \sqrt{n} \left( \left| \theta_j^* + \frac{u_j}{\sqrt{n}} \right| - \left| \theta_j^* \right| \right) \xrightarrow{P} 0.\) \quad (4.8.5)

If \(\theta_j^* = 0\), then \(\sqrt{n} \left( \left| \theta_j^* + \frac{u_j}{\sqrt{n}} \right| - \left| \theta_j^* \right| \right) = |u_j|\) and

\(\frac{\lambda_n}{\sqrt{n}} \hat{w}_j = \frac{\lambda_n}{\sqrt{n}} n^{\frac{\gamma}{2}} \left( |\sqrt{n}\hat{\theta}_j^{\text{UR}}| \right)^{-\gamma}\)

where \(\sqrt{n}\hat{\theta}_j^{\text{UR}} = O_p(1)\). Then by using Slutsky’s theorem again, we obtain that \(V_A^{(n)}(\boldsymbol{u}) \xrightarrow{\mathcal{D}} V_A(\boldsymbol{u})\) for every \(\boldsymbol{u}\), where

\(V_A(\boldsymbol{u}) = \left\{\begin{array}{ll} \boldsymbol{u}_A^\top \mathcal{K}_{p_0}^{-1} \boldsymbol{u}_A - 2\boldsymbol{u}_A^\top \boldsymbol{W}_A & u_j = 0 \forall j \notin A \\ \infty & \text{otherwise.} \end{array}\right. \quad (4.8.6)\)

Note that \(V_A(\boldsymbol{u})\) is convex, and with a unique minimum of \(V_A(\boldsymbol{u})\) is \((\mathcal{K}_1^{-1}\boldsymbol{W}_A, \boldsymbol{0})^\top\). Following the epi-convergence result by Geyer (1994) and Knight and Fu (2000), we have

\(u_A \xrightarrow{\mathcal{D}} \mathcal{K}_1^{-1}\boldsymbol{W}_A \quad \text{and} \quad u_{Ac} \xrightarrow{\mathcal{D}} \boldsymbol{0}. \quad (4.8.7)\)

Finally, \(\boldsymbol{W}_A \sim \mathcal{N}_{p_0}(\boldsymbol{0}, \eta^2 \boldsymbol{\mathcal{K}}_1)\), and the proof of asymptotic normality follows.

Before we discuss the “oracle” property of aLASSO, we partition true location vector \(\boldsymbol{\theta} = (\theta_1, ..., \theta_p)^\top\) into two subset \((\boldsymbol{\theta}_{p_0}^\top, \boldsymbol{\theta}_{p-p_0}^\top)^\top\) where \(\theta_j \neq 0\) for \(j \le p_0\) and \(\boldsymbol{\theta}_{p-p_0} = \boldsymbol{0}\).

Let \(\hat{\boldsymbol{\theta}}_n^{\text{UR}} = (\hat{\boldsymbol{\theta}}_{p_0}^{\text{UR}\top}, \hat{\boldsymbol{\theta}}_{p-p_0}^{\text{UR}\top})^\top\) is the partition of R-estimators of \(\boldsymbol{\theta}\). Basic assumption of the analysis is based on Jurečková (1969, 1971).

Accordingly, the \(p\)-dimensional rank-statistic is given by

\(\text{VD}(\theta) = (-1)\boldsymbol{T}_n(\boldsymbol{\theta}), \quad \boldsymbol{T}_n(\boldsymbol{\theta}) = \big(T_{n_1}(\theta_1), ..., T_{n_p}(\theta_p)\big) \quad (4.8.8)\)

where \(T_{n_1}(\vartheta_i) = n^{-\frac{1}{2}} \sum_{j=1}^{n_1} \text{sgn}(y_{ij} - \vartheta_i) a_{n_i}^+(R_{n_i}(\vartheta_i))\).

First, we consider the usual asymptotic linearity for rank-statistics, i.e. for any \(M > 0\),

\(\sup_{\|\hat{\theta}^* - \theta'\| < Mn^{-\frac{1}{2}}} \left\| \boldsymbol{T}_n(\boldsymbol{\theta}^* + \frac{\boldsymbol{u}}{\sqrt{n}}) - \boldsymbol{T}_n(\boldsymbol{\theta}^*) + \gamma(\phi, f)\mathcal{K}^{-1}\boldsymbol{u} \right\|^p \to 0 \quad (4.8.9)\)

where \(\boldsymbol{\mathcal{K}} = \text{Diag}(\kappa_1, ..., \kappa_p)\). Let \(\boldsymbol{u} = \sqrt{n}(\hat{\boldsymbol{\theta}}_n^* - \boldsymbol{\theta}^*)\).

Secondly, \(D_n(\theta)\) has quadratic approximation in any root-\(n\) neighborhood of \(\boldsymbol{\theta}_0\),

\(\sup_{\|\hat{\theta}^* - \theta'\| < Mn^{-\frac{1}{2}}} \left| D_n(\boldsymbol{\theta}^* + \frac{\boldsymbol{u}}{\sqrt{n}}) - D_n(\boldsymbol{\theta}^*) + \boldsymbol{T}_n(\boldsymbol{\theta}^*)^\top \boldsymbol{u} - \frac{1}{2} \boldsymbol{u}^\top \mathcal{K} \boldsymbol{u} \right|^p \to 0. \quad (4.8.10)\)
