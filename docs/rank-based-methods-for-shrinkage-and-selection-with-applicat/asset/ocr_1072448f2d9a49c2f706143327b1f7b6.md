where \( A_\phi^2 = \text{Var}(\phi(\boldsymbol{u})) \). Thus, by a routine Cramér–Wold device and Corollary 3.1 of Hall and Heyde (1981), one obtains as \( n \to \infty \),

```
\(\hat{\boldsymbol{L}}_n \to^{\mathcal{D}} \mathcal{N}_p(\mathbf{0}, A_\phi^2 \boldsymbol{\Sigma}), \quad A_\phi^2 = \int_0^1 \phi^2(u)du \tag{9.2.7}\)
```

and hence,

```
\(\sqrt{n}(\hat{\rho}_n^{\text{UR}} - \rho) \to^{\mathcal{D}} \mathcal{N}_p(\mathbf{0}, \eta^2 \boldsymbol{\Sigma}^{-1}), \quad \eta^2 = \frac{A_\phi^2}{\gamma^2}. \tag{9.2.8}\)
```

# 9.3 LASSO, Ridge, Preliminary Test and Stein–Saleh-type R-estimators

In this section, we present various R-estimators of \( \rho \). First, we consider the usual penalty R-estimators beginning with the hard threshold R-estimator (HTE). We shall refer to this estimator as the preliminary test subset selector (PTSS). It is defined by

```
\(\hat{\rho}_n^{\text{PTSS}}(\lambda) = \left( \hat{\rho}_{jn}^{\text{UR}} I(|\hat{\rho}_{jn}^{\text{UR}} > \lambda \eta \sqrt{\sigma_n^{jj}} \right) \mid j = 1, \dots, p \right)^{\top}, \tag{9.3.1}\)
```

where \( \sigma_n^{ii} \) is the (ii)-element of \( \Sigma_n^{-1} \). A continuous version of the PTSS is the Saleh-type selector

```
\(\hat{\rho}_n^{\text{SS}}(\lambda) = \left( \hat{\rho}_{jn}^{\text{UR}} \left( 1 - \frac{\lambda \eta}{|\hat{\rho}_{jn}^{\text{UR}}|} \sqrt{\sigma_n^{jj}} \right) \mid j = 1, \dots, p \right)^{\top}. \tag{9.3.2}\)
```

One of the most important penalty R-estimators is the LASSO due to Tibshirani (1996) (alternatively referred to as soft-threshold or positive-rule Saleh-type) R-estimator which is given by

```
\(\hat{\rho}_n^{\text{LassoR}}(\lambda) = \left( \text{sgn}(\hat{\rho}_{jn}^{\text{UR}})(|\hat{\rho}_{jn}^{\text{UR}}| - \lambda \eta \sqrt{\sigma_n^{jj}})^+ \mid j = 1, \dots, p \right)^{\top}, \tag{9.3.3}\)
```

where \( \hat{\rho}_n^{\text{UR}} = (\hat{\rho}_{1n}^{\text{UR}}, \dots, \hat{\rho}_{pn}^{\text{UR}})^{\top} \) and \( \sigma_n^{jj} \) is the \( j \)th diagonal element of the estimator of the matrix, \( \Sigma_n^{-1} \) defined by

```
\(\Sigma_n = (\sigma_{nij}) \quad \text{with} \quad \sigma_{nlj} = \sum_{k=1}^{n-\max\{i,j\}} (X_{k-i} - \bar{X}_i)(X_{k-j} - \bar{X}_j), \quad 1 \le i, j \le n \tag{9.3.4}\)
```
