# 3.2.2 Restricted R-estimator of \(\theta\)

If \(\theta\) is suspected to be 0, the restricted R-estimator (RRE) of \(\theta\), denoted by \(\hat{\theta}_n^{RR}\), is clearly given by

\(\hat{\theta}_n^{RR} = 0.\)

To overcome the difficulty of identical asymptotic distributions of different large-sample estimators under fixed alternatives, \(\mathcal{H}_A : \theta \neq 0\), we consider the local alternatives

\(K_{(n)} : \theta_{(n)} = \frac{1}{\sqrt{n}}\delta \quad (3.2.4)\)

where \(\delta\) is a fixed number.

# **Theorem 3.2** Under the local alternatives \(K_{(n)}\), the asymptotic distributional bias, variance and L$_2$-risk of the restricted R-estimator, \(\hat{\theta}_n^{RR}\), are respectively given by

\(\text{ADB}(\hat{\theta}_n^{RR}) = -\delta,\)

\(\text{ADV}(\hat{\theta}_n^{RR}) = 0,\)

\(\text{ADL}_2\text{-risk}(\hat{\theta}_n^{RR}) = \eta^2\Delta^2, \quad \text{where } \Delta^2 = \frac{\delta^2}{\eta^2}.\)

**Proof**: Under the local alternative hypothesis, it is known that \(\theta = \delta/\sqrt{n}\); so, based on Eq. (3.1.3), it is easy to derive that

\(\text{ADB}(\hat{\theta}_n^{RR}) = \sqrt{n}\left( \mathbb{E}[\hat{\theta}_n^{RR}] - \frac{1}{\sqrt{n}}\delta \right) = \sqrt{n}\left( 0 - \frac{1}{\sqrt{n}}\delta \right) = -\delta\)

and

\(\text{ADL}_2\text{-risk}(\hat{\theta}_n^{RR}) = n\mathbb{E}\left[ \left( 0 - \frac{1}{\sqrt{n}}\delta \right)^2 \right] = n\left( 0 - \frac{1}{\sqrt{n}}\delta \right)^2 = \delta^2.\)

If \(\Delta^2\) is defined as \(\delta^2/\eta^2\), then ADL$_2$-risk(\(\hat{\theta}_n^{RR}\)) = \(\eta^2\Delta^2.\)

Clearly, Theorem 3.2 results in the ADRE of \(\hat{\theta}_n^{RR}\) given by

\(\text{ADRE}(\hat{\theta}_n^{RR} : \hat{\theta}_n^{UR}) = \frac{1}{\Delta^2}.\)
