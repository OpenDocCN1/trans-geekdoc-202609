\(\lim_{n \to \infty} C_{n22:1} = C_{22:1}, \quad \lim_{n \to \infty} C_{n11:2} = C_{11:2}.\quad (10.4.2)\)

Our objective is now to estimate \(\hat{\beta}_{\hat{S}_1}^*\). In the next section, we provide the steps of the estimation technique in preparation for the separation of disjoint coefficients sets.

# 10.4.2 Steps Towards Estimators

We are following three steps to organize the estimation of parameters:

+   1: Use Section 10.2 to obtain the LASSO solution to Eq. (10.3.1) for the model

\(y_i = \sum_{j=1}^{p_n} x_{ij} \beta_j^* + \epsilon_i, \quad i=1, ..., n,\quad (10.4.3)\)

and accordingly arrange the \(n \times s_1\) matrix \(X_{\hat{S}_1}\) and \(n \times s_2\) matrix \(X_{\hat{S}_2^c}\), where \(s_1 = p_{1n} + o_p(1)\) and \(s_2 = p_{2n} + p_{3n} + o_p(1)\). Then, using Eq. (10.3.5), obtain \(\hat{\beta}_{1n}^{RR}\).

+   2: Define the R-estimators of \(\beta_{s_1}^*\) and \(\beta_{s_1^c}^*\) for the full model of Eq. (10.1.1) using \(X_{\hat{S}_1}\) and \(X_{\hat{S}_1^c}\). Note that we need \(p_{1n} + p_{2n} < n\) and \(p_{3n} > 2\). These matrices are used to obtain the ridge regression estimators with penalty \(\hat{\beta}_{s_1}^{*T} \hat{\beta}_{s_1^c}^*\).

+   3: Use the post-selection ridge estimators to define the preliminary-test and Stein–Saleh-type R-estimators.

**Remark 10.1** The reader must note \(X_{S_1^c}\) is of dimension \(n \times q_n\), where \(q_n = p_{2n} + p_{3n}\).

# 10.4.3 Post-selection Ridge Estimation of \(\beta_{s_1}^*\) and \(\beta_{s_2}^*\)

We suspect that \(\beta_{s_1^c}^*\) may be negligible. Step 1 in Section 10.4.2 gives \(\hat{S}_1\). So we construct ridge R-estimators (ridgeREs) of \(\beta_{s_1}^*\) and \(\beta_{s_1^c}^*\) based upon minimizing the penalized PRD function

\(Q_n(\beta^* | \hat{S}_1) = D_n(\beta^* | \hat{S}_1) + \gamma_n \hat{\beta}_{s_1}^{*T} \hat{\beta}_{s_1^c}^*, \quad |\hat{S}_1^c| = q_n, \quad q_n = p_{2n} + p_{3n},\quad (10.4.4)\)

where

\(D_n(\beta^* | \hat{S}_1) = D_n(\beta^* | \hat{S}_1 = S_1) = \sum_{i=1}^n \left( y_i - x_{i \hat{S}_1}^T \beta_{s_1}^* - x_{i \hat{S}_1^c}^T \beta_{s_1^c}^* \right) a_n(R_n(\beta)).\quad (10.4.5)\)
