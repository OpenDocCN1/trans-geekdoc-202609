# 3.10 Problems

3.1. The Wilcoxon score functions are given by

\(\phi(u) = \sqrt{12}(u - 1/2) \quad \text{and} \quad \phi^+(u) = \sqrt{3}u.\)

(a) Show that \(\phi(u) = \sqrt{12}(u - 1/2)\) is skew symmetric around \(\frac{1}{2}\). That is, \(\phi(u) + \phi(1 - u) = 0 \quad \forall u \in (0, 1).\)

(b) Scores are standardized such that \(\int_0^1 \phi(u) du = 0\) and \(\int_0^1 \phi^2(u) du = 1\). Show that \(\phi(u)\) satisfies these requirements. Then use the fact that \(\phi^+(u) = \phi((u + 1)/2)\) to obtain the score function, \(\phi^+(u)\).

3.4. In Section 3.8, the simple linear model given by

\(y_i = \theta + \beta x_i + \varepsilon_i, \quad i = 1, ..., n \qquad (3.10.1)\)

was considered. After defining \(Q_n = \sum_{i=1}^n (x_i - \bar{x}_n)^2\), it was rewritten as

\(y_i = \theta^* + \beta^* Q_n^{-\frac{1}{2}}(x_i - \bar{x}_n) + \varepsilon_i, \quad i = 1, ..., n\)

where \(\theta^* = \theta + \beta \bar{x}_n\) and \(\beta^* = Q_n^{\frac{1}{2}}\beta\). Given the unrestricted intercept estimate is \(\hat{\theta}_n^{\text{UR}}\) with variance \(\gamma^2(1 + \bar{x}_n/Q_n)\), we can improve the estimator using, for example, ridge as follows:

\(\hat{\theta}_n^{* , \text{ridge}(\lambda)} = \hat{\theta}_n^{* , \text{UR}} - \bar{x}_n \frac{1}{1 + \lambda} \hat{\beta}_n^{* , \text{UR}}.\)

In a similar manner, define the following improved estimators:

+   (i) Preliminary test (or hard threshold), \(\hat{\theta}_n^{\text{PT}}\), when \(\theta\) may be 0.
+   (ii) Saleh-type R-estimator \(\hat{\theta}_n^{\text{SR}}\).
+   (iii) Positive-rule Saleh-type R-estimator \(\hat{\theta}_n^{\text{SR+}}\).
