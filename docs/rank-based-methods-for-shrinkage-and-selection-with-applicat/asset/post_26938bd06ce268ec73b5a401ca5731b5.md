

$$\hat{\theta}_n^{\text{PTR}}(\alpha) = \hat{\theta}_n^{\text{UR}} - \hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha)). \tag{3.5.8}$$

Based on Eq. (3.1.3), the ADB of PTR is

$$\text{ADB}(\hat{\theta}_n^{\text{PTR}}(\alpha)) = \sqrt{n}\left(\mathbb{E}[\hat{\theta}_n^{\text{PTR}}(\alpha)] - \theta\right) = \text{ADB}(\hat{\theta}_n^{\text{UR}}) - \mathbb{E}\left[\sqrt{n}\hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right].$$

If we consider \(Z_n = \sqrt{n}\hat{\theta}_n^{\text{UR}}/\eta\), Eq. (3.2.3) results in \(Z_n \sim \mathcal{N}(\Delta, 1)\) under \(K_{(n)}\). Knowing that \(\text{ADB}(\hat{\theta}_n^{\text{UR}}) = 0\) and using Theorem 4 of Chapter 2 of Saleh (2006) leads to

$$\mathbb{E}\left[\sqrt{n}\hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right] = \eta \mathbb{E}\left[ZI(Z^2 \leq \chi_1^2(\alpha))\right] = \eta \Delta \mathcal{H}_3(\chi_1^2(\alpha), \Delta^2). \tag{3.5.9}$$

This completes the proof of \(\text{ADB}(\hat{\theta}_n^{\text{PTR}}(\alpha))\).

To prove \(\text{ADL}_2\)-risk of \(\hat{\theta}_n^{\text{PTR}}(\alpha)\), we proceed as follows,

$$\text{ADL}_2\text{-risk}(\hat{\theta}_n^{\text{PTR}}(\alpha)) = \mathbb{E}\left[n(\hat{\theta}_n^{\text{PTR}}(\alpha) - \theta)^2\right] = \mathbb{E}\left[n\left(\hat{\theta}_n^{\text{UR}} - \theta\right)^2\right] - 2\mathbb{E}\left[n\left(\hat{\theta}_n^{\text{UR}} - \theta\right)\left(\hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right)\right] + \mathbb{E}\left[n\left(\hat{\theta}_n^{\text{UR}}\right)^2 I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right] = \text{ADL}_2\text{-risk}(\hat{\theta}_n^{\text{UR}}) - \mathbb{E}\left[n\left(\hat{\theta}_n^{\text{UR}}\right)^2 I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right] + 2\sqrt{n}\theta\mathbb{E}\left[\sqrt{n}\hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right]. \tag{3.5.10}$$

Again, considering \(Z = \sqrt{n}\hat{\theta}_n^{\text{UR}}/\eta\), under \(K_{(n)}\) and Eq. (3.2.3), it is possible to conclude that \(Z \sim \mathcal{N}(\Delta, 1)\). Theorem 5 of Chapter 2 of Saleh (2006) leads to

$$\mathbb{E}\left[n\left(\hat{\theta}_n^{\text{UR}}\right)^2 I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right] = \eta^2 \mathbb{E}\left[Z^2 I(Z^2 \leq \chi_1^2(\alpha))\right] = \eta^2 (\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) + \Delta^2 \mathcal{H}_5(\chi_1^2(\alpha), \Delta^2)). \tag{3.5.11}$$

Based on Eq. (3.5.9),

$$2\sqrt{n}\theta\mathbb{E}\left[\sqrt{n}\hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n \leq \chi_1^2(\alpha))\right] = 2\eta^2 \Delta (\Delta \mathcal{H}_3(\chi_1^2(\alpha), \Delta^2)). \tag{3.5.12}$$

By substituting Eqs. (3.5.11) and (3.5.12) in Eq. (3.5.10), we have

$$\text{ADL}_2\text{-risk}(\hat{\theta}_n^{\text{PTR}}(\alpha)) = \eta^2 - \eta^2 (\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) + \Delta^2 \mathcal{H}_5(\chi_1^2(\alpha), \Delta^2)) + 2\eta^2\Delta^2\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) = \eta^2(1 - \mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) + \Delta^2(2\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) - \mathcal{H}_5(\chi_1^2(\alpha), \Delta^2))).$$

The first term is due to Theorem 3.1, and the proof is complete.

Thus,

$$\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}}) = \rho_{\text{PT}}^{-1}(\alpha, \Delta^2).$$

### 3.5.1 Optimum Level of Significance of PTRE

It is possible to rewrite Eq. (3.5.13) as

$$\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}}) = [1 + g(\alpha, \Delta^2)]^{-1},$$

where

$$g(\alpha, \Delta^2) = -\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) + \Delta^2(2\mathcal{H}_3(\chi_1^2(\alpha), \Delta^2) - \mathcal{H}_5(\chi_1^2(\alpha), \Delta^2)).$$

The graph of \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}})\), as a function of \(\Delta^2\) for a fixed \(\alpha\), is decreasing until it crosses the 1-line to reach a minimum at some \(\Delta^2 = \Delta_0^2(\alpha)\); then it increases toward the 1-line as \(\Delta^2 \to \infty\). The maximum value of \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}})\) occurs at \(\Delta^2 = 0\) with the value

$$\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}}) = \{1 - \mathcal{H}_3(\chi_1^2(\alpha), 0)\}^{-1} \ge 1,$$

for all \(\alpha \in A\), the set of possible values of \(\alpha\).

The value of \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}})\) decreases as \(\alpha\) increases, i.e., if \(\alpha = 0\) and \(\Delta^2\) varies, the graphs of \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(0) : \hat{\theta}_n^{\text{UR}})\) and \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(1) : \hat{\theta}_n^{\text{UR}})\) intersect at \(\Delta^2 = 1\). In general, \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha_1) : \hat{\theta}_n^{\text{UR}})\) and \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha_2) : \hat{\theta}_n^{\text{UR}})\) intersect within the interval \(0 \le \Delta^2 \le 1\); the value of \(\Delta^2\) at the intersection grows as \(\alpha\) increases. Thus, for two different \(\alpha\)-values, \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha_1) : \hat{\theta}_n^{\text{UR}})\) and \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha_2) : \hat{\theta}_n^{\text{UR}})\) will always intersect below the 1-line.

In order to obtain a PTR estimator with a minimum guaranteed efficiency, \(E_0\), we adopt the following procedure: if \(0 \le \Delta^2 \le 1\), we always choose \(\hat{\theta}_n^{\text{UR}}\), because \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}}) \ge 1\) in this interval. However, since \(\Delta^2\) is unknown generally, there is no way to choose an estimate that will uniformly be the best. For this reason, we select an estimator with minimum guaranteed efficiency, and look for a suitable \(\alpha\) from the set, \(A = \{\alpha \mid \text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}}) \ge E_0\}\). The estimator thus chosen maximizes \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha) : \hat{\theta}_n^{\text{UR}})\) over all \(\alpha \in A\), and

The solution \(\alpha^*\) obtained this way results in the PTR guaranteed efficiency \(E_0\), which may increase toward \(\text{ADRE}(\hat{\theta}_n^{\text{PTR}}(\alpha^*) : \hat{\theta}_n^{\text{UR}})\) for \(\Delta^2 = 0\) given by (3.5.15). See Table 3.2 for the optimum values.

## 3.6 Saleh-type R-estimators

In this section, we sequence through a series of R-estimators that eventually lead to the positive-rule Saleh-type R-estimator which is a LASSO-type of estimator. This is used in conjunction with the ridge-type R-estimator to produce a naive elastic net (or nENet-type) R-estimator. The theorems will be presented without proof to improve readability but they are extensions of the proofs given in earlier sections.

### 3.6.1 Hard-Threshold R-estimator of \(\theta\)

Inspired by the PTR estimator, we can effect a simplification by introducing a tuning parameter, \(\lambda^2\), to play the role of \(\chi_1^2(\alpha)\). Then we adjust \(\lambda\) until we achieve the minimum \(\text{ADL}_2\)-risk. For this purpose, we now define hard threshold R-estimator of \(\theta\) when one suspects \(\theta\) may be 0, as

\(\hat{\theta}_n^{\text{HTR}}(\lambda) = \hat{\theta}_n^{\text{UR}} I(\mathcal{L}_n > \lambda^2) \quad (3.6.1)\)

where \(I(\cdot)\) is an indicator function taking on two possible values, 0 or 1, depending on the threshold value, \(\mathcal{L}_n\), as defined earlier in Eq. (3.5.7). This HTR estimator should be considered as identical in form to PTR.
