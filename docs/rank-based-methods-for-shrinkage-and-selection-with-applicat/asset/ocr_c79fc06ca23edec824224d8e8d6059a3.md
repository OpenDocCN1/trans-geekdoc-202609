= \eta^2 \left[ \text{tr}(\mathbf{C}_{22:1}^{-1})(1 - \mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2)) + \Delta^2 \text{Ch}_{\min}(\mathbf{C}_{22:1}^{-1})(2\mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2) - \mathcal{H}_{p_2+4}(\chi^2_{p_2}(\alpha); \Delta^2)) \right] - \eta^2 \left[ \text{tr}((\mathbf{I}_{p_2} + k\mathbf{C}_{22:1}^{-1})^{-2}\mathbf{C}_{22:1}^{-1}) \right] - k^2 \boldsymbol{\delta}_2^\top (\mathbf{C}_{22:1} + k\mathbf{I}_{p_2})^{-2} \boldsymbol{\delta}_2
= \eta^2 \left[ \text{tr}(\mathbf{C}_{22:1}^{-1}) - \left\{ \text{tr}((\mathbf{I}_{p_2} + k\mathbf{C}_{22:1}^{-1})^{-2}\mathbf{C}_{22:1}^{-1}) + k^2 \boldsymbol{\delta}_2^\top (\mathbf{C}_{22:1}^{-1} + k\mathbf{I}_{p_2})^{-2} \boldsymbol{\delta}_2 \right\} - \left\{ \text{tr}(\mathbf{C}_{22:1}^{-1}) \mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2) - \Delta^2 \text{Ch}_{\min}(\mathbf{C}_{22:1}^{-1}) (2\mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2) - \mathcal{H}_5(\chi^2_{p_2}(\alpha); \Delta^2)) \right\} \right] \ge 0.

Let \(\Delta^2 = 0\). Then the difference equals

\(\text{tr}(\mathbf{C}_{22:1}^{-1}) - \text{tr}((\mathbf{I}_{p_2} + k\mathbf{C}_{22:1}^{-1})^{-2}\mathbf{C}_{22:1}^{-1}) - \text{tr}(\mathbf{C}_{22:1}^{-1})\mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); 0) \ge 0\)

and for \(\Delta^2 \to \infty\), the difference is

\(\eta^2 \left[ \text{tr}(\mathbf{C}_{22:1}^{-1}) - \text{tr}((\mathbf{I}_{p_2} + k\mathbf{C}_{22:1}^{-1})^{-2}\mathbf{C}_{22:1}^{-1}) \right] \ge 0.\)

Further, a graph of the expression in the second bracket would be below the graph of the first expression. Hence, the ADL$_2$-risk-difference is non-zero and ridge is uniformly better than \(\hat{\boldsymbol{\beta}}_n^{\text{PTR}}(\alpha)\).

Now, consider

\(\text{ADL}_2\text{-risk}\left(\hat{\boldsymbol{\beta}}_n^{\text{PTR}}(\alpha) : \mathbf{C}_{11:2}, \mathbf{C}_{22:1}\right) - \text{ADL}_2\text{-risk}\left(\hat{\boldsymbol{\beta}}_n^{\text{ridge}}(k_{\text{opt}}) : \mathbf{C}_{11:2}, \mathbf{C}_{22:1}\right)
= \eta^2 \left[ p_2(1 - \mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2)) + \Delta^2(2\mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); \Delta^2)
- \mathcal{H}_{p_2+4}(\chi^2_{p_2}(\alpha); \Delta^2)) - \frac{p_2 \Delta^2}{p_2 + \Delta^2} \right].\)

See Saleh et al. (2019).

Note that the risk of PTRTE is an increasing function of \(\Delta^2\), crossing the \(p_2\)-line to a maximum and then it drops monotonically towards the \(p_2\)-line as \(\Delta^2 \to \infty\). At \(\Delta^2 = 0\), the value of this risk is \(p_2[1 - \mathcal{H}_{p_2+2}(\chi^2_{p_2}(\alpha); 0)] < p_2\). On the other hand, for the orthogonal case, the risk of the ridge R-estimator is equal to \(\frac{p_2 \Delta^2}{p_2 + \Delta^2}\) which is an increasing function of \(\Delta^2\) below the \(p_2\)-line with a minimum value 0 at \(\Delta^2 = 0\) and it converges to \(p_2\) as \(\Delta^2 \to \infty\). Hence, the risk difference is non-negative for all \(\Delta^2 \ge 0\) and the ridge R-estimator outperforms the PTRTE uniformly.
