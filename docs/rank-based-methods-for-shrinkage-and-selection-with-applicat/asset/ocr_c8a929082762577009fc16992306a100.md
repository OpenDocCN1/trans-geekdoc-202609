# 1.5.2 Using Rank for the Location Model

To introduce rank-based methods, consider the location model

$y_i = \theta + \epsilon_i, \quad i = 1, ..., n,$

where $\epsilon_1, ..., \epsilon_n$ are i.i.d. random variables. A location model attempts to estimate the center of a given sample, $y_1, ..., y_n$, of a random variable $Y$. This could be the sample mean or median or any other similar type of estimate depending on the underlying distribution. We will describe how to address this simple case to compare two similar estimators that seek the median.

In theory, the median is obtained using an $L_1$ loss function. To estimate the location parameter, we could use the absolute value loss function given by

$B_n(\theta) = \sum_{i=1}^n |y_i - \theta|.$ (1.5.1)

The median estimate, $\hat{\theta}^{\text{median}}_n$, is obtained as

$\hat{\theta}^{\text{median}}_n = \text{argmin}_{\theta \in \mathbb{R}} \{B_n(\theta)\}.$ (1.5.2)

The gradient function is

$B'_n(\theta) = -\sum_{i=1}^n \text{sgn}(y_i - \theta).$ (1.5.3)

The absolute value loss function has a discontinuous first derivative that creates some theoretical problems since it does not satisfy certain regularity conditions.

Now consider multiplying the terms in the $L_1$ loss function by their respective ranks to form a rank-based loss function as follows

$D_n(\theta) = \sum_{i=1}^n |y_i - \theta| R^+_i(\theta),$ (1.5.4)

where $R^+_i(\theta)$ are the ranks of $|y_i - \theta|$ among $|y_1 - \theta|, ..., |y_n - \theta|$. The “+” sign indicates that we are taking the absolute value of the quantities before ranking them.
