```
+\Delta^2\text{Ch}_{\min}(\boldsymbol{C}_{22\cdot1}^{-1})(2\mathcal{H}_{p_2+2}(\chi_{p_2}^2(\alpha);\Delta^2)-\mathcal{H}_{p_2+4}(\chi_{p_2}^2(\alpha);\Delta^2)-1)\big].
```

Then, for

```
0 \le \Delta^2 \le \frac{\text{tr}(\boldsymbol{C}_{22\cdot1}^{-1})[1-\mathcal{H}_{p_2+2}(\chi_{p_2}^2(\alpha);\Delta^2)]}{\text{Ch}_{\min}(\boldsymbol{C}_{22\cdot1}^{-1})[1-2\mathcal{H}_{p_2+2}(\chi_{p_2}^2(\alpha);\Delta^2)+\mathcal{H}_{p_2+4}(\chi_{p_2}^2(\alpha);\Delta^2)]}
```

LASSO outperforms PTRE. On the other hand, outside this interval, PTRE outperforms LASSO. Hence, neither LASSO nor PTRE dominates the other uniformly.

# (vii) LASSO vs. Stein–Saleh-type

```
\text{ADL}_2^*-risk\left(\hat{\boldsymbol{\beta}}_n^{\text{SSR}}\right)-\text{ADL}_2^*-risk\left(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)\right)=\eta^2\big[\text{tr}(\boldsymbol{C}_{22\cdot1}^{-1})
- \{(p_2 - 2)\text{tr}(\boldsymbol{C}_{22\cdot1}^{-1})(2\mathbb{E}[\chi_{p_2+2}^{-2}(\Delta^2)] - (p_2 - 2)\mathbb{E}[\chi_{p_2+4}^{-4}(\Delta^2)])\}
+ (p_2^2 - 4)\Delta^2\text{Ch}_{\min}(\boldsymbol{C}_{22\cdot1}^{-1})(\mathbb{E}[\chi_{p_2+4}^{-4}(\Delta^2)] - 1)\big].
```

Hence, for

```
0 \le \Delta^2 \le \frac{\text{tr}(\boldsymbol{C}_{22\cdot1}^{-1})-\{(p_2-2)\text{tr}(\boldsymbol{C}_{22\cdot1}^{-1})(2\mathbb{E}[\chi_{p_2+2}^{-2}(\Delta^2)]-(p_2-2)\mathbb{E}[\chi_{p_2+4}^{-4}(\Delta^2)])\}}{(p_2^2-4)C h_{\min}(\boldsymbol{C}_{22\cdot1}^{-1})(1-\mathbb{E}[\chi_{p_2+4}^{-4}(\Delta^2)])}
```

LASSO outperforms Stein–Saleh-type, otherwise Stein–Saleh-type outperforms LASSO. Hence, neither LASSO nor Stein–Saleh-type outperforms the other uniformly.

# (viii) LASSO R estimator vs. PRSRE

For the last comparison in this section, we proceed with the orthonormal case.

```
\text{ADL}_2\text{-risk}\left(\hat{\boldsymbol{\beta}}_n^{\text{SSR+}}:\boldsymbol{c}_{11\cdot2},\boldsymbol{c}_{22\cdot1}\right)-\text{ADL}_2^*-risk\left(\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda)\right)

```

where

```
A = p_2 - (p_2 - 2)^2\mathbb{E}[\chi_{p_2}^{-2}(\Delta^2)]
```
