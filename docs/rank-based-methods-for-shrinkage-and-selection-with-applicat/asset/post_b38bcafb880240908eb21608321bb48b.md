## 4.3.4 Shrinkage Estimators for Multiple Location

In order to construct and evaluate different shrinkage R-estimators for the multiple location model, we can re-examine the traces of ridge and LASSO

![](img/f3b106d7e76ae3afcec8895afa28732c_189_0.png)

given above. There are two considerations to keep in mind. First, there may be sparsity in the parameters in which case we want to be able to partition the parameters into two groups. Second, there are parameters with high variance and others with low variance so we may want to split them into two groups. Combining these two objectives, we define \(\theta = (\theta_{1n}^\top, \theta_{2n}^\top)^\top\), where \(\theta_{1n}\) contains non-zero values with low variance and \(\theta_{2n}\) contains the parameters that we suspect might be 0 or have high variance.

Consider the LASSO R trace on the right in Figure 4.3. Two of the traces with low variance look like the hard threshold estimator from Chapter 3 while the remaining four resemble the positive-rule Saleh R-estimator. To specify these two estimators, we need to define a test statistic, \(\mathcal{L}_{n_j}, j = 1, ..., p\), which will be elaborated later in the chapter. For now, consider it a threshold quantity. Then, the hard threshold R-estimator is given by

```
\(\hat{\theta}_n^{HTR}(\lambda) = \hat{\theta}_{n_j}^{UR} I(\mathcal{L}_{n_j} > \lambda^2), \quad j = 1, ..., p.\)
```

The positive-rule Stein–Saleh R-estimator1 is given by

```
\(\hat{\theta}_n^{SSR+}(\lambda) = \hat{\theta}_n^{UR} (1 - \lambda / \sqrt{\mathcal{L}_n}) I(\sqrt{\mathcal{L}_n} > \lambda).\)
```

In Figure 4.5, we show traces for these two R-estimators for the multiple location model. Note the resemblance between two of the LASSOR traces (1 and 2) and the corresponding traces of hard threshold estimator, and four of the LASSOR traces (3, 4, 5 and 6) and the corresponding traces of the positive-rule Stein–Saleh estimator. The LASSOR traces of Figure 4.3 indicate that the unrestricted value should be used for some parameters while a shrinkage penalty should be applied to others. Since our objective in the remainder of this chapter is to compare different estimators using \(ADL_2\)-risk, when we suspect sparsity,

we can define the following R-estimator:

```
\hat{\boldsymbol{\theta}}_n^{\text{SSR}+}(\lambda) = \left( \hat{\boldsymbol{\theta}}_{1n}^{\text{UR}^\top}, \hat{\boldsymbol{\theta}}_{2n}^{\text{UR}^\top} (1 - \lambda \mathcal{L}_n^{-1} I(\mathcal{L}_n > \lambda)) \right)
```

where \(\hat{\boldsymbol{\theta}}_n^{\text{SSR}+}\) is the positive-rule Stein–Saleh R-estimator. Here, \(\hat{\boldsymbol{\theta}}_{1n}^{\text{UR}}\) are the unrestricted estimates that will not experience shrinkage and \(\hat{\boldsymbol{\theta}}_{2n}^{\text{UR}}\) are the parameters that will experience shrinkage. There is an assumption that there is low variance for group 1 and therefore their values do not shrink rapidly. However, for group 2 with possible sparsity, the positive-rule Stein–Saleh R-estimator is used, which applies shrinkage at a linear rate.

If we do not suspect sparsity in the parameter set, then no groups are defined and we can apply a full shrinkage model using, for example, ridge-type regression as follows

```
\hat{\boldsymbol{\theta}}_n^{\text{ridgeR}}(\lambda) = \frac{1}{1 + \lambda} \hat{\boldsymbol{\theta}}_n^{\text{UR}}
```

In the remainder of this chapter, we define an evaluate a number of penalty R-estimators for the multiple location problem. We assume that partitioning is based on some suitable criteria such as variance or the marginal theory due to Saleh et al. (2019) when we suspect sparsity. In the sections to follow, we will define the unrestricted and restricted estimators, and then use ADL$_2$-risk to compare the different rank-based penalty estimators.

## 4.4 Unrestricted R-estimator

Let \(R_{n,j}^+(\theta_j)\) be the rank of \(|y_{ij} - \theta_j|\) among \(|y_{i1} - \theta_1|, ..., |y_{in_p} - \theta_p|\). For the unrestricted R-estimator (URE) of \(\theta_j\), we minimize the Jaeckel rank dispersion function w.r.t. \(\theta_j\), that is to say, minimize

```
D_{n_j}(\theta_j) = \sum_{i=1}^{n_j} |y_{ij} - \theta_j| a_{n_j}^+(R_{n_j}^+(\theta_j)), \quad j = 1, ..., p,
```

w.r.t. \(\theta_j\). This can be accomplished by solving the equation

```
\frac{\partial D_{n_j}(\theta_j)}{\partial \theta_j} = -n_j^{-\frac{1}{2}} T_{n_j}(\theta_j) = -\sum_{i=1}^{n_j} \text{sgn}(y_{ij} - \theta_j) a_{n_j}^+(R_{n_j}^+(\theta_j)) = 0,
```

and then the URE of \(\theta_j\) is given by

```
\hat{\theta}_{n_j}^{\text{UR}} = \frac{1}{2} \left[ \sup \{ \theta_j : T_{n_j}(\theta_j) > 0 \} + \inf \{ \theta_j : T_{n_j}(\theta_j) < 0 \} \right].
```

Thus, the URE of \(\theta\) is given by

\(\hat{\theta}_n^{UR} = (\hat{\theta}_{n_1}^{UR}, \dots, \hat{\theta}_{n_p}^{UR})^\top.\)

Using Eqs. (4.4.1) and (4.4.2), let

\(D_n(\theta) = (D_{n_1}(\theta_1), \dots, D_{n_p}(\theta_p))^\top\)

and

\(T_n(\theta) = (T_{n_1}(\theta_1), \dots, T_{n_p}(\theta_p))^\top.\)

Then, using the Jurečková linearity result and the asymptotic uniform quadratic result due to Jaeckel (1972), we have as \(n \to \infty\),

\(\sup_{\|w\|<n} n^{-\frac{1}{2}} \left\| T_n(n^{-\frac{1}{2}} w) - T_n(0) + \gamma(\phi, \psi) \mathcal{K} w \right\| \xrightarrow{P} 0,\)
\(\sup_{\|w\|<n} n^{-\frac{1}{2}} \left\| D_n(n^{-\frac{1}{2}} w) - D_n(0) + w^\top T_n(0) + \frac{1}{2} \gamma(\phi, \psi) w^\top \mathcal{K} w \right\| \xrightarrow{P} 0\)

where \(\|a\| = \sum_{j=1}^p |a_j|\) and \(\mathcal{K} = \text{Diag}(\kappa_1, \dots, \kappa_p)\).

Thus, we conclude that, as \(n \to \infty\), for

\(W_n(\omega) = \omega^\top T_n(0) + \frac{1}{2} \gamma(\phi, \psi) \omega^\top \mathcal{K} \omega,\)

we have

\(\left\| \sqrt{n}(\hat{\theta}_n^{UR} - \theta) - \text{argmin}_{w \in \mathbb{R}^p} \{W_n(w)\} \right\| \xrightarrow{P} 0.\)

Hence, as \(n \to \infty\),

\(T_n(0) \xrightarrow{\mathcal{D}} \mathcal{N}_p(0, A_\phi^2 \mathcal{K}^{-1}),\)

and

\(|\sqrt{n}(\hat{\theta}_n^{UR} - \theta) - \gamma^{-1}(\phi, \psi) \mathcal{K} T_n(0)| \xrightarrow{P} 0,\)

which leads to

\(\sqrt{n}(\hat{\theta}_n^{UR} - \theta) \xrightarrow{\mathcal{D}} \mathcal{N}_p(0, \eta^2 \mathcal{K}), \quad \eta^2 = \frac{A_\phi^2}{\gamma^2(\phi, \psi)}, \quad (4.4.3)\)

with

\(\gamma(\phi, \psi) = \int_0^1 \phi(u)\psi(u)du, \psi(u) = -\frac{f_0'(F_0^{-1}(u))}{f_0(F_0^{-1}(u))}. \quad (4.4.4)\)
