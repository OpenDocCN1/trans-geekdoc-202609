(ii) We consider the score generating function \(\phi : (0, 1) \to \mathbb{R}\) which is assumed to be non-constant, non-decreasing, and square integrable on \((0, 1)\) such that

\(A_\phi^2 = \int_0^1 \phi^2(u) du - \left( \int_0^1 \phi(u) du \right)^2,\tag{6.2.3}\)

and

\(\phi(u, f) = -\frac{f'(F(u))}{f(F^{-1}(u))}, \quad 0 < u < 1.\)

The score is defined by

\(a_n(i) = \mathbb{E} \left[ \phi(U_{n_i}) \right] \quad U_{n_i} = \frac{i}{n+1}, \quad 1 \le i \le n \tag{6.2.4}\)

for \(n \ge 1\), where \(U_{n_1} \le ... \le U_{n_n}\) are the order statistics from a sample of size \(n\) from \(U(0, 1)\).

(iii) Let

\(\boldsymbol{C}_n = \frac{1}{n} \sum_{i=1}^n (\boldsymbol{x}_i - \bar{\boldsymbol{x}})(\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top,\tag{6.2.5}\)

where \(\boldsymbol{x}_i\) is the \(i\)th row of \(\boldsymbol{X}\) and

\(\bar{\boldsymbol{x}} = \frac{1}{n} \sum_{i=1}^n \boldsymbol{x}_i.\)

Next, we assume that

(a) \(\lim_{n \to \infty} \boldsymbol{C}_n = \boldsymbol{C},\) (b) \(\lim_{n \to \infty} \max(\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top \boldsymbol{C}_n^{-1} (\boldsymbol{x}_i - \bar{\boldsymbol{x}}) = 0.\tag{6.2.6}\)

For R-estimation of \(\boldsymbol{\beta} \in \mathbb{R}^p\), the rank of \(y_i - \boldsymbol{x}_i^\top \boldsymbol{\beta}\) among \(y_1 - \boldsymbol{x}_1^\top \boldsymbol{\beta}, ..., y_n - \boldsymbol{x}_n^\top \boldsymbol{\beta}\) is denoted by \(R_{n_i}(\boldsymbol{\beta})\). Note that \(R_{n_i}(\boldsymbol{\beta})\) is translation invariant.

Now, for each \(n \ge 1\), consider the set of scores \(a_n(1) \le ... \le a_n(n)\) and define the dispersion function as

\(D_n(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - (\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top \boldsymbol{\beta}) a_n(R_{n_i}(\boldsymbol{\beta})).\tag{6.2.7}\)

The unrestricted R-estimator (URE) of \(\boldsymbol{\beta}\) is defined by any central point of the set

\(\hat{\boldsymbol{\beta}}_n^{\text{UR}} = \underset{\boldsymbol{\beta} \in \mathbb{R}^p}{\text{argmin}} \{ D_n(\boldsymbol{\beta}) \}.\tag{6.2.8}\)
