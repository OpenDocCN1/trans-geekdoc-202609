# 4.3.3 Effect of Variance on Shrinkage Estimators

We now use the data from the ANOVA table to examine the effect of variance on the shrinkage characteristics of rank penalty estimators as compared to LS penalty estimators. The analysis will be used to construct suitable penalized rank estimators for the multiple location model. For this purpose, the columns in the ANOVA table can be treated as a related set of location problems and solved using linear regression. To begin our study, we examine the ridge penalty function. For this multiple location model, the LS-ridge estimator is given by
