## 6 Multiple Linear Regression Models

### 6.1 Introduction

This chapter considers rank-based shrinkage estimation for the non-orthogonal multiple linear model. This subject was studied extensively in Chapter 2 where the practical aspects for machine learning with penalized rank estimators were described. Here, we provide a theoretical treatment and investigate the comparative performance characteristics of the primary penalty estimators, namely, ridge, LASSO, elastic net and aLASSO, together with the restricted, unrestricted, preliminary test and Stein–Saleh-type R-estimators when the dimension of the parameter space is less than the dimension of the sample space. We use marginal distribution theory to evaluate the asymptotic distributional L2-risks of the R-estimators.

### 6.2 Multiple Linear Model and R-estimation

Consider the multiple regression model

$y = X\beta + \varepsilon$ (6.2.1)

where $y = (y_1, \dots, y_n)^T$ is the response vector, $X$ is an $n \times p (n > p)$ matrix of real numbers, and $\beta$ is a $p$-vector of regression coefficients. We assume the following conditions due to Jurečková (1971):

- (i) $\varepsilon = (\varepsilon_1, \dots, \varepsilon_n)^T$ are i.i.d. components with c.d.f. $F$, having absolutely continuous p.d.f. $f$ with finite Fisher information

$0 < I(f) = \int_{-\infty}^{+\infty} \left( \frac{f'(x)}{f(x)} \right)^2 f(x) \, dx < \infty.$ (6.2.2)

- (ii) We consider the score generating function \(\phi : (0, 1) \to \mathbb{R}\) which is assumed to be non-constant, non-decreasing, and square integrable on \((0, 1)\) such that

\(A_\phi^2 = \int_0^1 \phi^2(u) du - \left( \int_0^1 \phi(u) du \right)^2,\tag{6.2.3}\)

and

\(\phi(u, f) = -\frac{f'(F(u))}{f(F^{-1}(u))}, \quad 0 < u < 1.\)

The score is defined by

\(a_n(i) = \mathbb{E} \left[ \phi(U_{n_i}) \right] \quad U_{n_i} = \frac{i}{n+1}, \quad 1 \le i \le n \tag{6.2.4}\)

for \(n \ge 1\), where \(U_{n_1} \le ... \le U_{n_n}\) are the order statistics from a sample of size \(n\) from \(U(0, 1)\).

- (iii) Let

\(\boldsymbol{C}_n = \frac{1}{n} \sum_{i=1}^n (\boldsymbol{x}_i - \bar{\boldsymbol{x}})(\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top,\tag{6.2.5}\)

where \(\boldsymbol{x}_i\) is the \(i\)th row of \(\boldsymbol{X}\) and

\(\bar{\boldsymbol{x}} = \frac{1}{n} \sum_{i=1}^n \boldsymbol{x}_i.\)

Next, we assume that

- (a) \(\lim_{n \to \infty} \boldsymbol{C}_n = \boldsymbol{C},\)
- (b) \(\lim_{n \to \infty} \max(\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top \boldsymbol{C}_n^{-1} (\boldsymbol{x}_i - \bar{\boldsymbol{x}}) = 0.\tag{6.2.6}\)

For R-estimation of \(\boldsymbol{\beta} \in \mathbb{R}^p\), the rank of \(y_i - \boldsymbol{x}_i^\top \boldsymbol{\beta}\) among \(y_1 - \boldsymbol{x}_1^\top \boldsymbol{\beta}, ..., y_n - \boldsymbol{x}_n^\top \boldsymbol{\beta}\) is denoted by \(R_{n_i}(\boldsymbol{\beta})\). Note that \(R_{n_i}(\boldsymbol{\beta})\) is translation invariant.

Now, for each \(n \ge 1\), consider the set of scores \(a_n(1) \le ... \le a_n(n)\) and define the dispersion function as

\(D_n(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - (\boldsymbol{x}_i - \bar{\boldsymbol{x}})^\top \boldsymbol{\beta}) a_n(R_{n_i}(\boldsymbol{\beta})).\tag{6.2.7}\)

The unrestricted R-estimator (URE) of \(\boldsymbol{\beta}\) is defined by any central point of the set

\(\hat{\boldsymbol{\beta}}_n^{\text{UR}} = \underset{\boldsymbol{\beta} \in \mathbb{R}^p}{\text{argmin}} \{ D_n(\boldsymbol{\beta}) \}.\tag{6.2.8}\)

Equivalently, the $\hat{\boldsymbol{\beta}}_n^{\text{UR}}$ can be defined as

\(\hat{\boldsymbol{\beta}}_n^{\text{UR}} = \{\boldsymbol{\beta} \mid \boldsymbol{L}_n(\boldsymbol{\beta}) = \mathbf{0}\}\) (6.2.9)

where $\boldsymbol{L}_n(\boldsymbol{\beta})$ is obtained from the derivative of $D_n(\boldsymbol{\beta})$, i.e. Eq. (6.2.7), and given by

\(\boldsymbol{L}_n(\boldsymbol{\beta}) = \frac{1}{\sqrt{n}} \sum_{i=1}^n (\boldsymbol{x}_i - \bar{\boldsymbol{x}}) a_n(R_{n_i}(\boldsymbol{\beta})).\) (6.2.10)

Let us consider the linear rank statistics (LRS) as

\(\mathbf{L}_{n_i}(\boldsymbol{\beta}) = \frac{1}{\sqrt{n}} (\boldsymbol{x}_i - \bar{\boldsymbol{x}}) a_n(R_{n_i}(\boldsymbol{\beta})).\)

Using the properties of derivative functions, we can rewrite Eq. (6.2.9) as

\(\hat{\boldsymbol{\beta}}_n^{\text{UR}} = \left\{ \boldsymbol{\beta} \middle| \sum_{i=1}^p L_{n_i}(\boldsymbol{\beta}) = 0 \right\}\)

If we set $\|\boldsymbol{a}\| = \sum_{j=1}^p |a_j|$ for $\boldsymbol{a} = (a_1, \dots, a_p)^\top$, then it is easier to find the URE of $\boldsymbol{\beta}$ by

\(\hat{\boldsymbol{\beta}}_n^{\text{UR}} = \underset{\boldsymbol{\beta} \in \mathbb{R}^p}{\operatorname{argmin}} \{ \|\boldsymbol{L}_n(\boldsymbol{\beta})\| \}.\) (6.2.11)

Then, by the asymptotic uniform linearity (AUL) results of Jurečková (1971), for any $\varkappa > 0$ and $\varepsilon > 0$,

\(\lim_{n \to \infty} P \left( \sup_{\|\boldsymbol{w}\| \le \varkappa} \left\| \boldsymbol{L}_n(\boldsymbol{\beta} + \frac{\boldsymbol{w}}{\sqrt{n}}) - \boldsymbol{L}_n(\boldsymbol{\beta}) + \gamma(\boldsymbol{\phi}, f) \boldsymbol{C} \boldsymbol{w} \right\| \ge \varepsilon \right) = 0\) (6.2.12)

where

\(\gamma(\boldsymbol{\phi}, u) = \int_0^1 \phi(u) \phi(u, f) du.\)

Then, it is well-known that

\(\sqrt{n} \left( \hat{\boldsymbol{\beta}}_n^{\text{UR}} - \boldsymbol{\beta} \right) \xrightarrow{\mathcal{D}} \mathcal{N}_p(\mathbf{0}, \eta^2 \boldsymbol{C}^{-1}),\) (6.2.13)

where

\(\eta^2 = \frac{A_\phi^2}{\gamma^2(\boldsymbol{\phi}, f)}.\)

Also,

\(n^{\frac{1}{2}} \left\| \boldsymbol{L}_n(\hat{\boldsymbol{\beta}}_n^{\text{UR}}) \right\| \xrightarrow{P} 0.\) (6.2.14)

As described in Chapter 3, we consider the asymptotic distributional risk of each estimator under the L2 loss denoted by

ADL_2-risk(\hat{\boldsymbol{\beta}}_n) = ADV(\hat{\boldsymbol{\beta}}_n) + ADB^2(\hat{\boldsymbol{\beta}}_n)

where ADV(\hat{\boldsymbol{\beta}}_n) is the asymptotic distributional variance and ADB^2(\hat{\boldsymbol{\beta}}_n) is the square of the asymptotic distributional bias. Hence, the ADL_2-risk of \hat{\boldsymbol{\beta}}^{\text{UR}} is given by

ADL_2-risk(\hat{\boldsymbol{\beta}}_n^{\text{UR}}) = \eta^2 \text{tr}(\mathbf{C}^{-1}).

An estimator performs better if it has a lower ADL2-risk. We will also be comparing the asymptotic distributional L2-risk efficiency (ADRE) of the various estimators. As described in Chapter 3, the relative efficiency of two estimators is given by

ADRE(\hat{\boldsymbol{\beta}}_n : \hat{\boldsymbol{\beta}}_n^{*}) = \frac{\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n^{*})}{\text{ADL}_2\text{-risk}(\hat{\boldsymbol{\beta}}_n)}.

### 6.3 Model Sparsity and Detection

There are many applications where the data scientist expects sparsity in the parameter set. That is, some \boldsymbol{\beta} are non-zero while other \boldsymbol{\beta} are either zero or very close to zero. The non-zero set is considered to be significant while the rest can be neglected in order to create a compact model. In such cases, it is convenient to rewrite the multiple regression model in Eq. (6.2.1) as

y = X_1\beta_1 + X_2\beta_2 + \varepsilon

where \boldsymbol{\beta}_1 is a p_1-vector while \boldsymbol{\beta}_2 is a p_2-vector and X = (X_1, X_2) is an n \times p matrix of real numbers, where the dimension of X_1 and X_2 are n \times p_1, and n \times p_2, respectively. The question becomes one of figuring out how to find the sizes of these two \boldsymbol{\beta}-vectors.

One approach is to use the LASSO R-estimator as follows

\hat{\boldsymbol{\beta}}_n^{\text{LassoR}}(\lambda) = \underset{\boldsymbol{\beta} \in \mathbb{R}^p}{\text{argmin}} \{ D_n(\boldsymbol{\beta}) + \lambda \sum_{j=1}^p |\beta_j| \}

where

D_n(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - (\mathbf{x}_i - \bar{\mathbf{x}})^\top \boldsymbol{\theta}) a_n(R_{n_i}(\boldsymbol{\beta})).
