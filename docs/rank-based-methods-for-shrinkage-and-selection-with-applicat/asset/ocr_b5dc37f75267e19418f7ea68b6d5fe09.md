Further, the true adaptive LASSO of \(\beta\) is obtained as

\(\hat{\beta}_n^{\text{aLassoR}} = \text{argmin}_{\beta \in \mathbb{R}} \left\{ \sum_{j=1}^n |y_j - \beta(x_j - \bar{x}_n)| a_n^+(R_n(\beta)) + \lambda_n w |\beta| \right\} .\)

If \(\hat{\beta}_n^{\hat{\alpha}\text{LassoR}} \neq 0\), it belongs to the event \(A_n^*\) and if \(\hat{\beta}_n^{\hat{\alpha}\text{LassoR}} = 0\), it belongs to \(A_n^{*c}\). The aLASSO R-estimator is consistent if \(P(A_n^* = A) = 1\) where \(A\) is the event if \(\beta \neq 0\).
