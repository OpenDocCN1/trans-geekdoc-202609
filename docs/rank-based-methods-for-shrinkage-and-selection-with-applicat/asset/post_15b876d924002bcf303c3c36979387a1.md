
## 10.2 Identifiability of $\beta^*$ and Projection

Since we are dealing with a deterministic design matrix, $\mathbf{X}$, and high dimensions, $p_n > n$, we need $\beta^*$ to be identifiable and it is so if and only if it lies in a set having a one-to-one correspondence with a linear space $\mathcal{R}(\mathbf{X})$ spanned by the rows of $\mathbf{X}$. Since $\dim \mathcal{R}(\mathbf{X}) = \text{rank}(\mathbf{X}) \leq \min(n, p_n) = n$, and hence $\beta^*$ is not identifiable, it is not realistic to derive a consistent estimator of $\beta^*$ or consistent variable selection. For statistical inference, we may not need to estimate vector $\beta^*$ but only estimate $\theta$, the projection of $\beta^*$ onto $\mathcal{R}(\mathbf{X})$. We define $\beta^*$ as identifiable if $\beta_1^* \in B^*$ and $\beta_2^* \in B^*$, then $\mathbf{X}\beta_1^* = \mathbf{X}\beta_2^*$ implies $\beta_1^* = \beta_2^*$, where $B^*$ is the parameter space of $\beta^*$. The following lemma due to Shao and Deng (2012) gives the necessary and sufficient conditions for identifiability of $\beta^*$.

**Lemma 10.1** Under the model of Eq. (10.1.2), with $p_n > k_n$, $\beta^*$ is identifiable if and only if there exists a known function $\phi : \mathbb{R}^{k_n} \to \mathbb{R}^{p_n - k_n}$ such that

$$B^* = \{\beta^* : \beta^* = \mathbf{Q}_1 \xi + \mathbf{Q}_2 \phi(\xi), \quad \xi \in \mathbb{R}^{k_n}\} \tag{10.2.1}$$

where $\mathbf{Q}_1$ is a $p_n \times k_n$ and $\mathbf{Q}_2$ is a $p_n \times p_n - k_n$ matrix such that $\mathbf{Q}_2^\top \mathbf{Q}_2 = \mathbf{I}_{p_n - k_n}$, $\mathbf{Q}_1^\top \mathbf{Q}_1 = \mathbf{I}_{k_n}$, and $\mathbf{Q}_1^\top \mathbf{Q}_2 = \mathbf{0}_{k_n}$.

Indeed, Lemma 10.1 shows that an identifiable $\beta$ must be in a set having a one-to-one correspondence with $\mathcal{R}(\mathbf{X}) = \{ \beta^* = \mathbf{Q}_1 \xi, \xi \in \mathbb{R}^{k_n} \}$. Thus, we consider the projection of $\beta$ onto $\mathcal{R}(\mathbf{X})$ given by

$$\theta = \mathbf{X}^\top (\mathbf{X}\mathbf{X}^\top)^- \mathbf{X} \beta^* = \mathbf{Q}_1 \mathbf{Q}_1^\top \beta^*. \tag{10.2.2}$$

Note that $\theta \in \mathcal{R}(\mathbf{X})$ and $\theta = \beta^*$ if and only if $\beta^* \in \mathcal{R}(\mathbf{X})$. For this, $\mathbf{X}\beta^* = \mathbf{X}\theta$ and the sparse model is then given by

$$\mathbf{y} = \mathbf{X}\theta + \boldsymbol{\varepsilon} = \mathbf{X}_1 \theta_1 + \mathbf{X}_2 \theta_2 + \boldsymbol{\varepsilon}. \tag{10.2.3}$$

## 10.3 Parsimonious Model Selection

As indicated earlier, a penalized Jaeckel rank dispersion (PRD) function is often used to select a parsimonious model for the high-dimensional regression model of Eq. (10.1.1),

$$
\hat{\boldsymbol{\beta}}_n^{\text{PRD}} = \underset{\boldsymbol{\beta}^* \in \mathbb{R}^{p_n}}{\text{argmin}} \left\{ D_n(\boldsymbol{\beta}^*) + \gamma_n \mathbf{1}_{p_n}^\top | \boldsymbol{\beta}^* | \right\}, \quad \boldsymbol{\beta}^* = (\beta_1^*, \dots, \beta_{p_n}^*)^\top, \tag{10.3.1}
$$

where $\gamma_n$ is the tuning parameter, $\mathbf{1}_{p_n}$ is a $p_n$-tuple of 1, and $|\boldsymbol{\beta}^*| = (|\beta_1^*|, \dots, |\beta_{p_n}^*|)^\top$,

$D_n(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - \sum_{j=1}^{p_n} x_{ij} \beta_j) a_n(R_{n_i}(\boldsymbol{\beta})), \qquad (10.3.2)$

and $R_n(\boldsymbol{\beta})$ is the rank of $y_i - \sum_{j=1}^{p_n} x_{ij} \beta_j$ among $\{y_\alpha - \sum_{j=1}^{p_n} x_{\alpha j} \beta_j, 1 \le \alpha \le n\}$.

As before, let $\hat{\mathcal{S}}_1 \subset \{1, \dots, p_n\}$ be the active subset from Eq. (10.3.1). Then, a data-adaptive candidate subset model is produced as

$\hat{\beta}_j^{\text{PRD}} = 0 \quad \text{if and only if} \quad j \notin \hat{\mathcal{S}}_1. \qquad (10.3.3)$

Without loss of generality, we rearrange the covariates as $\mathbf{X} = (\mathbf{X}_{\mathcal{S}_1} | \mathbf{X}_{\mathcal{S}_2} | \mathbf{X}_{\mathcal{S}_3})$ where $\mathbf{X}_{\mathcal{S}_i}$ is a sub-matrix indexed by $\mathcal{S}_i \subset \{1, \dots, p_n\}$ and each $\mathbf{X}_{\mathcal{S}_i}$ is of dimension \(n \times p_{in}, i = 1, 2, 3\). We designated \(p_i = p_{in}\) to show the dependency on the sample size. In general, \(\mathcal{S}_2\) cannot be separable from \(\mathcal{S}_3\). Some post-selection R-estimations can be presented to improve prediction performance of the PRD estimator. Thus, we can collect together the variable \(\mathbf{X}_{\hat{\mathcal{S}}_j}\) from the PRD subset selection and obtain the restricted R-estimator \(\hat{\boldsymbol{\beta}}_{1n}^\text{RR}\) using the restricted model

\(y_i = \sum_{j=1}^{p_{1n}} x_{ij} \beta_j^* + \varepsilon_i, \quad 1 \le i \le n, \qquad (10.3.4)\)

where

\(\hat{\boldsymbol{\beta}}_{1n}^\text{RR} = \underset{\hat{\boldsymbol{\beta}}_{\hat{\mathcal{S}}_1}^* \in \mathbb{R}^{p_{1n}}}{\text{argmin}} \left\{ \sum_{j=1}^{p_{1n}} |L_{n_j}(\boldsymbol{\beta}_{\hat{\mathcal{S}}_1}^*, \mathbf{0})| \right\} \qquad (10.3.5)\)

and

\(L_{n_j}(\boldsymbol{\beta}_{\hat{\mathcal{S}}_1}^*, \mathbf{0}) = \sum_{i=1}^n x_{ij} a_n(R_{n_i}(\boldsymbol{\beta}_{\hat{\mathcal{S}}_1}^*)) \qquad (10.3.6)\)

with \(R_n(\boldsymbol{\beta}_{\hat{\mathcal{S}}_1}^*)\) as the rank of \(\left( y_i - \sum_{j=1}^{p_{in}} x_{ij} \hat{\beta}_j^* \right)\) among \(y_i - \sum_{j=1}^{p_{in}} x_{ij} \beta_j^*, i = 1, \dots, n\).

Further, we obtain

\(\sqrt{n} \left( \hat{\boldsymbol{\beta}}_{1n}^\text{RR} - \boldsymbol{\beta}_{\hat{\mathcal{S}}_1}^* \right) \xrightarrow{\mathcal{D}} \mathcal{N}_{p_{1n}}(\mathbf{0}, \eta^2 \mathbf{C}_{11}^{-1}), \qquad (10.3.7)\)

where

\(\mathbf{C} = \begin{pmatrix} \mathbf{C}_{11} & \mathbf{C}_{12} \\ \mathbf{C}_{21} & \mathbf{C}_{22} \end{pmatrix}. \qquad (10.3.8)\)

The next section delves deeper into the specifics of $\mathbf{C}$ and the partitions.

## 10.4 Some Notation and Separation

Based upon a subset partitioning of $S_1$, $S_2$, and $S_3$, we can also partition the true parameters $\boldsymbol{\beta}^* = (\boldsymbol{\beta}^{*\top}_1, \boldsymbol{\beta}^{*\top}_2, \boldsymbol{\beta}^{*\top}_3)^\top$, without loss of generality. Some notations are shortened for convenience such as $\boldsymbol{\beta}^*_{S_k} = \boldsymbol{\beta}^*_k, k=1, 2, 3$. Similar notations are also adopted for other sub-vectors and matrices. For example, using the same partitions, the design matrix $\boldsymbol{X} = (\boldsymbol{x}_1, ..., \boldsymbol{x}_n)^\top, \boldsymbol{x}_i \in \mathbb{R}^{p_n}, i=1, ..., n$, can be written as $\boldsymbol{X} = (\boldsymbol{X}_1, \boldsymbol{X}_2, \boldsymbol{X}_3)$. We also write $\boldsymbol{X} = (\boldsymbol{Z}, \boldsymbol{X}_3)$ with $\boldsymbol{Z} = (\boldsymbol{X}_1, \boldsymbol{X}_2)$. The row vector of $\boldsymbol{Z}$ is denoted as $\boldsymbol{z}_i = (z_{i1}, ..., z_{i(p_{1n}+p_{2n})})$, for $1 \le i \le n$. We denote $p_{kn} = |S_k|$ for $k=1, 2, 3$ and $p_n = p_{1n} + p_{2n} + p_{3n}$. In this chapter, we allow $p_n = \sum_{k=1}^3 p_{kn}$ to be very large but restrict $p_{1n} + p_{2n} \le n$ such that $\boldsymbol{C}_n = n^{-1} \boldsymbol{Z}^\top \boldsymbol{Z}$ is non-singular. In the limit, we assume $\boldsymbol{C}_n \to \boldsymbol{C}$, where $\boldsymbol{C}$ is a positive definite matrix. If $\boldsymbol{C}_n$ is singular, then a generalized inverse matrix is adopted when needed in computations. Specifically, one can use the Moore-Penrose generalized inverse for uniqueness.
