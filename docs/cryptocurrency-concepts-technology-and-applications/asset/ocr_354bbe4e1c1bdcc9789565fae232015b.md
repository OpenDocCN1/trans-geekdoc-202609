# TWO-PERIOD BINOMIAL OPTION PRICING MODEL - Call and Put Options

+   **INPUT**
+   **CALL OPTION**
+   
+   S = $ 47,000
+   u = 1.20x
+   d = 0.90x
+   X = $ 50,000
+   i = 5.00%
+   Frequency= 1
+   Periods= 2
+   
+   Frequency: ( Annual =1, Semiannual = 2, Quarterly=4)

![](bbox=[0.22, 0.17, 0.68, 0.48])

+   **FORMULAS**
+   
+   Su= S . u
+   Sd= S . d
+   Su²= S . d²
+   Cu²= Max (0, Su²- X)
+   Cd²= Max (0, Sd²- X)
+   Cud= Max (0, Sud- X)
+   p = [{(1+ i) / d]} - { (u - d) ] / [{(1+i)^Freq]
+   Cu= [ {p . Cu²} + {(1-p) Cud)] / [{(1+i)^Freq]
+   Cd= [ {p . Cud} + {(1-p) Cd²]] / [{(1+i)^Freq]
+   C= [ {p . C1} + {(1-p) C2]] / [{(1+i)^Freq]

+   **INPUT**
+   **PUT OPTION**
+   
+   S = $ 47,000
+   u = $ 1
+   d = $ 1
+   X = $ 50,000
+   i = $ 0
+   Frequency= 1
+   Periods= 2
+   
+   Frequency: ( Annual =1, Semiannual = 2, Quarterly=4)

![](bbox=[0.22, 0.51, 0.68, 0.72])

+   **FORMULAS**
+   
+   Su= S . u
+   Sd= S . d
+   Su²= S . u²
+   Pu²= Max (0, X- Su²)
+   Pd²= Max (0, X - Sd²)
+   Pud= Max (0, X - Sud )
+   p = [{(1+ i) / d]} - { (u - d) ] / [{(1+i)^Freq]
+   Pu= [ {p . Pu²} + {(1-p) Pud)] / [{(1+i)^Freq]
+   Pd= [ {p . Pud} + {(1-p) Pd²]] / [{(1+i)^Freq]
+   P= [ {p . P1} + {(1-p) P2]] / [{(1+i)^Freq]
