# Application Development Environments for Blockchains

There are dozens of open-source general-purpose blockchain development environments. With the revolutionary principles of Bitcoin, miner, proof-of-work, transaction, and permissionless [6], the Bitcoin Blockchain was the first player in 2008. The Ethereum Blockchain is a fork of Bitcoin that has been in use since its inception, using terms like Ether, Ethereum miner, proof of stake, account, and permissionless [7]. Hyperledger Blockchain is a business-oriented blockchain. Asset, chain code (smart contracts), Practical Byzantine Fault Tolerance (PBFT), membership, and approval are among the topics introduced [8].

Hundreds of blockchain development environments have been developed for specific applications or situations, including supply chain financing, financial clearance, company regulation and supervision. They have been enhanced with better infrastructure, consent mechanisms, and design patterns in order to achieve higher performance and best-fit particular cases on general-purpose blockchain development platforms. For this reason, Beihangchain, an approved blockchain with distinctive consensus algorithms, interfaces, and design, has been established. For a number of applications, including copyright protection and digital payment, the Blockchain employed an account blockchain and a trade blockchain [9]. The Hyper chain is a self-contained, controllable blockchain platform that enables enterprise-level blockchain network development. It allows businesses to use, expand, and complete a blockchain network using existing cloud platforms, and it provides real-time visual monitoring of the network's operation condition [10].
