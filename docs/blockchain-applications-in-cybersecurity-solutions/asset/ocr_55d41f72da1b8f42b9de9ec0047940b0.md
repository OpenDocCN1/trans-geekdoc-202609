# ## Creation of new Block

A Block class is defined with a constructor that accepts a timestamp, some data and the hash of the previous block. A block class used to represent a block is given below:

```
```python
class Blockchain:

    def __init__(self,ts,record,prevHash):
        self.pHash = prevHash
        self.record = record
        self.ts = ts
        self.hash = self.compute_Hash()
```
```

In the above code fragment, the parameter ts represents the timestamp that is used to store the time at which the block is created, the parameter record represents the information or transaction details that are stored inside the block and the parameter pHash represents the string that contains the hash of the previous block.

Intuitively, a hash represents the fingerprint of the main document. Each block consists of a unique hash value. The hash value of a particular block is computed by applying the hash function to all the contents of the block. The compute_Hash method is used for computing the hash of the newly generated block.
