Blockchain has layers of security that are divided into the top to bottom security levels. The blockchain structure is divided into six layers; Incentive, Consensus, Network, and Data layer [19].

The Application layer of the blockchain structure has the Mining Machine System, where the cyber security awareness of mining device manufacturers is irregular and the security code cannot be checked by the public due to its closed source system. The top layer of security is the Application layer - Which covers the security and privacy issues of centralized nodes that involve the transactions of a large amount of funds exchange. It provides security from unauthorized or unwanted access to an exchange server, as exchanges of large amounts of transactions are easy to target for hackers.
