This method internally tries to find providers from the local network as well as the wide area network. In each network, it creates a channel that is responsible for sending back a peer’s address when it is found. Since a peer can be found again and again, the method keeps a local map that stores a newly found peer. We just ignore the peer that has already been found and is on the map. If, at the end of the method, we cannot find any new peers, we publish a query event to the query event channel. The query event has the context of the initial data request (Fig. 5).
