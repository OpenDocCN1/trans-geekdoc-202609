# RESEARCH PERSPECTIVES

There are various security challenges of blockchain applications in the industry. The blockchain enabled devices must be designed so as to construct an improved user centric data empowerment. Prospective research is still needed in many areas [26 - 32], not limited to:

+   - Specific blockchain-associated issues and attacks like withholding a block attack and mining incentives.
+   - Scalability issues in blockchain-enabled industry like healthcare. As healthcare is a rising industry, as more and more people are getting aged, blockchain-enabled healthcare applications will turn into an exponentially difficult task, as the application might not run properly, with the increase in the number of patients.
+   - The necessity to deploy open source real-world datasets to enable researchers to perform research and get their results verified to disseminate their findings and observations.
+   - Issues related to security and key management to effortlessly restore compromised keys.
+   - Challenges in identity authentication.
+   - Need for proper blockchain testing methods.
+   - Challenges in controlling AI-based misbehaviours on blockchain.
