Blockchain can also be used to preserve the privacy of medical IoT data [19]. proposed a four-layer architecture to provide security for the medical data which is retrieved from the IoT devices. The data generated is stored in the databases using blockchain technology; if the third party wants to retrieve the data, they have to use a smart contract that provides the authenticity of the user. This model could provide security but lacks inefficient image retrieval systems and has storage overhead and computational complexity. To address the problems of extensive computational complexity, and storage overhead [20], proposed a modified blockchain framework that uses the cloud for storing the blocks generated, which in turn reduces the storage overhead. All the blocks that belong to one Blockchain are given a unique identifier which makes the retrieval process authenticated. The users or the doctors who want to access the data can send a request using the smart contract and the public key. In addition to the Blockchain, many cryptographic techniques were also implemented to provide security from different kinds of attacks. Similar to the above method [21], proposed a four-layered architecture that includes many technologies such as cloud for storage, Blockchain for privacy, and IoT for monitoring the health of a person. The data generated by these sensors are stored in the cloud using a NoSQL database and is hashed using blockchain technology which makes the retrieval process fast [22]. extended the usage of Blockchain to provide security to smart cities using mobile edge computing as every person has a mobile device with a cellular network area. This technique uses already existing mobile computing to generate the data and includes Blockchain to provide secure peer-to-peer communication [22]. Also proposed a similar framework for smart cities by storing the data in a blockchain to provide reliability, using somewhat homomorphic encryption for providing security, and machine learning algorithms to classify the data and use it for predictions. Most of the mentioned techniques provide security for the generated data, whereas, they have used blockchain technology to provide a reliable and secure platform to exchange the data between the device to device and the human to a device. In addition, many authors have used machine learning algorithms to classify the data into two categories: critical and non-critical, data before giving access to third-party servers. Extra security is provided by encrypting critical or non-critical data using different encryption algorithms.
