```
bc = Blockchain()

bc.chain[2].computeHash())
```

While executing the above fragment of code, it is observed that now it takes more time to generate new blocks than the one presented in 3.3.1. This is due to the mining process where the difficulty is configured as 3 which requires the hash value to start with three zeroes. When the difficulty level is increased, the algorithm takes more time to produce the blocks.

Thus the PoW mechanism enables blockchain network to control the number of blocks inserted in the chain within a stipulated time.

# CHALLENGES IN BLOCKCHAIN TECHNOLOGY

Many organizations and business persons are willing to take up this technology. However, there are challenges that hinder the adoption of blockchain technology [21]. The critical problems related to this technology are presented here.

# Scalability

Scalability is the main factor that hinders the process of adoption of blockchain. It is a well known fact that this technology can process thousands of transactions per second, however, in Bitcoin and in Ethereum, the transaction speeds are 3 to 7 transactions and 15 to 20 transactions per second respectively. This property of slow processing of the transactions renders blockchain unsuitable for large applications. Bitcoin lightening network and Ethereum plasma are considered as solutions for offering spontaneity in transactions with nominal fees.

# Network Interoperability

Most blockchains do not communicate with peer networks as they lack this feature. To address this second big concern, Ark uses Smart Bridges architecture to bridge the gap of communication between the networks. This project offers global interoperability.
