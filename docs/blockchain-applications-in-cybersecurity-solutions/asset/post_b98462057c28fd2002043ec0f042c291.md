## Implementation of proof-of-work

The section 3.3.1 described the implementation process of creating a simple blockchain. It also included the processes involved in detecting tampered content in the chain. Computers have much faster and efficient processors that easily add numerous blocks within a short span of time. This leads to spamming of blocks in the chain. Also efficient computing resources make the tampering process easier, where the hacker modifies the data stored inside a block and the hashes of all the succeeding blocks are recalculated. In this case, the data tampering goes unnoticed, because it shows a valid chain during the validation process. These problems need to be addressed while implementing simple blockchain. These issues are solved by the consensus mechanism described in section 2. This section explains how PoW is implemented using the process called mining. Mining increases the usage of computing resources, thereby, increasing the time taken to create a new block. In PoW, the mining process starts with generating random data continuously until enough number of zeroes are prefixed to the hash of the block. The number of zeroes prefixed in the hash is referred to as the difficulty level of the mining process. The random number, nonce, is included as part of the block along with the user’s data. The main objective of bitcoin is to create a new block every 10 minutes. It is possible because of the availability of faster computing resources. This necessitates more complex and difficult mining process. This is achieved by increasing the difficulty level.

## CHALLENGES IN BLOCKCHAIN TECHNOLOGY

Many organizations and business persons are willing to take up this technology. However, there are challenges that hinder the adoption of blockchain technology [21]. The critical problems related to this technology are presented here.

### Scalability

Scalability is the main factor that hinders the process of adoption of blockchain. It is a well known fact that this technology can process thousands of transactions per second, however, in Bitcoin and in Ethereum, the transaction speeds are 3 to 7 transactions and 15 to 20 transactions per second respectively. This property of slow processing of the transactions renders blockchain unsuitable for large applications. Bitcoin Lightning network and Ethereum plasma are considered as solutions for offering spontaneity in transactions with nominal fees.

### Network Interoperability

Most blockchains do not communicate with peer networks as they lack this feature. To address this second big concern, Ark uses Smart Bridges architecture to bridge the gap of communication between the networks. This project offers global interoperability.
