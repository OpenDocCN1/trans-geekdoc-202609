# The Origin of Computer Software

The MD5 hashes can be utilized and blockchain can be applied to verify the integrity of downloaded software to prevent foreign intrusion. For the firmware updates, installers, and patchers, MD5 can be utilized to stop the entry of malicious software into the computer system. New software identity compared to hashes available on the vendor website. The method of the MD5 scenario is not completely infallible as the hashes can be already compromised. Although, in the case of blockchain technology, the hashes are permanently recorded and the recorded information is not changeable. So blockchain might be more efficient to verify the software integrity by comparing the hashes.

# Private Message Security

Social applications are popular platforms and a source of collecting huge amounts of data through the interactions that occur between the users on social media platforms. As the internet is reaching every place, the world is shrinking into a global village, with an increase in social apps more people have now started joining social media. To protect their privacy, most social media platform users use weak and unreliable passwords. With the change in time and for user privacy, most messaging companies are now preparing to use blockchain technology as it gives end-to-end encryption. To form an integrated API framework, blockchain can be used to enable cross-messenger communication capabilities, as it creates a standard security protocol.

There are records of several attacks that have been executed against social platforms like some famous social media platforms such as Facebook and Twitter. If blockchain technology will be implemented well in social media apps or other messaging systems, it may prevent cyber-attacks in the future.
