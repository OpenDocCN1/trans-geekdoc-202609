This consensus process guarantees network stability and makes it impossible to exploit. They enable a blockchain ecosystem to become self-governing, open, consent-based, and credible. Blockchains can run without human involvement thanks to a collection of smart contracts. The smart contracts are set up to run on predefined blockchain nodes [12]. They can be prompted by callbacks from the blockchain system, other smart contracts, or the information systems of the participants. As smart contracts, both blockchain processes and application-related rules can typically be predetermined. The use cases and real-world tasks vary, but the benefits of employing the technology stay consistent: immutability, transparency, redundancy, and security.

Dragon chain illustrates how blockchain technology facilitates transactions between two parties in a safe, verifiable, and trustworthy manner, demonstrating the benefits of the technology [13]. The underlying system behind blockchain is a distributed peer-to-peer network. There is no centralized authority that controls the network. Each node in the network performs its work independently. A new node needs to be verified by existing nodes before it joins the blockchain network [14]. All the nodes are required to reach a consensus on a transaction before the transaction is recorded on a ledger that is shared among all the participating nodes [15]. In order to reach consensus, each participant must solve a complex puzzle and provide a proof of stake or proof of work to a server. The server checks the proof from each participant and rewards the ones with the correct proofs [16]. Once the proof has been approved by the server, the transaction is confirmed, and a new block which contains the hash code and the transaction is added to the ledger, as illustrated by Tar [17]. The new block creation process is called mining. A node gets rewarded with money for successfully mining a block first, so all the completing nodes race to process a transaction and create a new block; refer to Salman et al. (2019) [18]. Data on the blockchain is immutable, so it will never change after it is written into the ledger. One limitation of blockchain is that it relies on continuous communications between nodes in the network, so its performance will be largely impacted in areas with low bandwidth or slow connection, as explained by Zheng et al. [19].

Even though blockchain is a great solution for decentralized computing resources, data storage on a blockchain is still expensive, since the data needs to be pushed to other blockchain nodes and processed there as well. A blockchain node will need a more powerful CPU, higher bus speed, more bandwidth, and bigger storage to process all the data since there is a lot of data on the Internet now, and it is expected to get larger in the future, which will increase the cost to operate.
