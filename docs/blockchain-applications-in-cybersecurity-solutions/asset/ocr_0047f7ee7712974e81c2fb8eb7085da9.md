# Method find ProvidersAsync

While get File Node FromPath returns the file root node to a specific given hash path, this findProvidersAsync method searches for peers that are close to the current node and can provide a given key. The method takes a content-addressed identifier and a count and then returns a set of peers that have or know where to get the requested content. A content-addressed identifier is formed by a version, a content type, and the hash of the content. The count specifies how many peers we want to get. If the count is zero, the method returns an unbounded number of peers. Because the content identifier is unique for the same content, we cache the content identifier and the set of peer providers. Therefore, future calls to this method with the same identifier will be able to directly get the providers from the cache.
