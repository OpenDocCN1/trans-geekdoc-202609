## Challenges of IoT Devices

IoT devices come in a wide range of varieties. These devices communicate with other devices in different ways, such as wired or wireless communication, using different protocols depending on the end communication device. Due to the heterogeneity of the devices, there is no standardization of the communication protocols. This raises a concern in terms of the security, integrity, and confidentiality of the device and its associated data. And also, these devices are more easily prone to security attacks because of their limited resources and computational capacity. Due to the wide range of devices, IoT devices face many challenges, which are tabulated in Table 2.

## INTRODUCTION TO BLOCKCHAIN

Blockchain is a P2P (peer-to-peer) secure distributed network that maintains the transaction records of the network and exchange of digital information without a third-party intervention or a central server, or a trusted agent. It is a database structure that holds the information in chunks. The block of data is chained to the previous block of data with a given time stamp. A block is a set of transactions that are put on the chain at the same time after it has been verified by the standard users in the network. A block mainly consists of the following:

- The reference to the previous block
- The Proof of Work: nonce value (a random value generated only once at a particular time)
- The time-stamp
- The Merkle tree root for the transactions: Each of the transactions is a leaf node in the tree. Each transaction is hashed, combined, and rehashed till all the transactions are combined in one root.

Each of the nodes has a duplicated copy of the block. Hence Blockchain is a duplicated ledger of transactions that have been agreed upon by the standard nodes and distributed across nodes.

There are two types of Blockchain [6]: Public Blockchain is permissionless e.g. (Bitcoin or Ethereum), which is public, and anyone can join the network, and Permissioned Blockchain (Hyperledger Project by The Linux Foundation) [7]. Permissioned Blockchain, where the consensus of valid peers about the transaction is required and is gaining a lot of interest in applications other than financial use cases.

### Characteristics of the Blockchain

- *Immutability of data:* Once the Blockchain is formed, it is difficult to tamper with the block.
- *Transparency:* All transactions in the Blockchain can be viewed by any participant.
- **Decentralization:** The Blockchain is managed across multiple sites, making it more reliable.
- **Security:** blockchain technology mainly uses public key infrastructure and hashing techniques for authentication and integrity of the data, respectively.

## BLOCKCHAIN ARCHITECTURE

Blockchain technology was first introduced by the author Satoshi Nakamoto [8]. The main intention behind this is to make online payments without third-party server authentication. This led to the invention of the current trending bitcoin and cryptocurrencies. This technology enables the user to exchange any digital information online. It provides high security, reliability, and availability because the Blockchain is immutable and secure. Because of these features, blockchain technology is used in a wide range of applications where there is a need for security. The data in the Blockchain is maintained in the form of nodes. Each node represents a transaction or a digital data entry. Each entry is encrypted with the private key of the user and is sent to the chain; the consensus algorithm checks the validity of the transaction and adds it to the chain. Thus, all the nodes/transactions are added to the Blockchain, which forms a chain-like structure. ## Components of Blockchain

The blockchain functionality is based on basic core components such as node, transaction, block, mining, and consensus.

**Transaction:** Transaction is the basic data that is sent to the nodes for validity and is added to the chain. When new data is generated, that is considered a transaction and broadcasted to all the nodes.

**Block:** Group of transactions is called a block. The transactions are grouped based on validity and are distributed across the chain. This block contains information about the transactions/data. Every block that is added to the chain will contain the hash value of the previous block.

**Node:** Node is a component for the validity of a new transaction or digital entry. Every node in the Blockchain will have a copy of all the nodes of the chain. When a new transaction comes, the node checks its previous history and sends it to the remaining nodes to check its validity. If the transaction is valid, it is added to the chain; otherwise, it is denied.

**Mining:** Mining is the core functionality of the Blockchain. It is a process of creating a block, validating it, and adding a hash value to it. After adding the hash value, it is distributed across the network.

**Consensus:** The whole process of validating, adding, and distributing a block in the network is called consensus. Various Consensus algorithms like proof-of-work and proof-of-stake are already available that define a set of rules to maintain the Blockchain.

### Authentication of IoT device

The IoT device that should take part in the transaction should be authenticated. The Authentication process can be done via Hardware Authenticator, which can be an offline device. The Hardware Authenticator (HA) has important functions like creating the initial block, assigning a digital signature to the IoT device, and creating new blocks with a private key.

Each of the authenticated devices can take part in the transaction with another authenticated device by looking into the block database given by HA. The database has the identification of all authenticated devices and valid previous transaction records. The other already standard devices in the network validate the newly joined device. Once validation is confirmed by 51% of the standard users in the network, the new authenticated device can take part in the transaction using its private key.

**Integrity:** The hash value of the block identifies the particular block of information, and this characteristic makes the block of data immutable. The hash value of each block references the previous block of information to form a chain, and the time is recorded. Each block thus has the hash value of the previous block of data, thus making it hard to alter a particular block of data. The Overall hash value of the block is formed by considering the previous block’s hash value, the hash value of the transactional data, and Metadata. If any of the blocks of data is altered, it breaks the chain. The initial block has no valid previous hash as there is no previous block.
