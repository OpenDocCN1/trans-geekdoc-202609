Smart contracts built on Blockchain inherit the properties of Blockchain, hence will validate, capture and see that the agreement is met by multiple parties involved in the transaction without the need for a third party. Every device in the IoT gets a copy of the smart contract. On the receipt of an action to its address, a smart contract is executed. Ethereum provides the concept of smart contracts and Solidity (the programming language used to write these contracts) that enables decentralized applications. A low-latency and low-computation consumption protection model based on a smart contract has been researched [17]. Each node that has to send the block as a transaction in the network has to get registered in the smart contract. The smart contract issues a token that validates the transaction, and it is stored in the block. This token acts as proof of validity, and the block can be considered to be added to the Blockchain.
