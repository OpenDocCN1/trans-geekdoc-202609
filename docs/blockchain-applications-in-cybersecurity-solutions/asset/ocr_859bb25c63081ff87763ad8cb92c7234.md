# Fitbit Architecture

Fig. (3) is an example of how fitness wearable technology can be utilized for lifestyle applications, as shown in an architecture that includes weight, calories burned, heart rate, speed, etc. The users' activities will be tracked via sensors, and they will be able to input part of the data themselves, which will subsequently be transmitted to a smartphone and the provider's cloud service. The data is subsequently processed, making it easier for the user to comprehend. Depending on the type of display, this is transmitted back into either the associated smartphone or the wearable itself.
