## BACKGROUND AND RELATED WORK

### Background of Blockchain Technology

Blockchain is a decentralized, public ledger that tracks online transactions. A decentralized blockchain ledger maintains a shared record of all the transactions distributed over a large user network. This is a completely decentralized network, which does not require any intermediary mechanism for exchanging services. A blockchain is a series of data blocks, in which a small batch of user-made transactions is stored in each block. Both these data blocks are clustered together electronically, using a top-tier level of cryptography [9]. Both of the blocks together then form a permanent and immutable public record of each and every transaction that occurs on the network. The user is connected to a blockchain in such a way that his / her data is made accessible without revealing their identity to any other user in that blockchain. Blockchain offers users complete transparency to make things simpler [10]. Through encrypting and validating, Blockchain guarantees the confidentiality, authenticity and privacy of transactions. By adding a new block to a blockchain, a cryptographic hash generated from the previous block’s content is used to link it to the preceding block. It means the chain never breaks, and each block is registered forever [11]. Consequently, this is deliberately difficult to alter past blockchain transactions, as all subsequent blocks must be modified first. Blockchain databases are made up of many nodes, and decentralized. Administration includes the nodes: all nodes review recent blockchain additions and can add new data to the database. Consensus on the majority of nodes must be achieved for an addition to the blockchain. This consensus process guarantees network stability and makes it impossible to exploit. They enable a blockchain ecosystem to become self-governing, open, consent-based, and credible. Blockchains can run without human involvement thanks to a collection of smart contracts. The smart contracts are set up to run on predefined blockchain nodes [12]. They can be prompted by callbacks from the blockchain system, other smart contracts, or the information systems of the participants. As smart contracts, both blockchain processes and application-related rules can typically be predetermined. The use cases and real-world tasks vary, but the benefits of employing the technology stay consistent: immutability, transparency, redundancy, and security.

Dragonchain illustrates how blockchain technology facilitates transactions between two parties in a safe, verifiable, and trustworthy manner, demonstrating the benefits of the technology [13]. The underlying system behind blockchain is a distributed peer-to-peer network. There is no centralized authority that controls the network. Each node in the network performs its work independently. A new node needs to be verified by existing nodes before it joins the blockchain network [14]. All the nodes are required to reach a consensus on a transaction before the transaction is recorded on a ledger that is shared among all the participating nodes [15]. In order to reach consensus, each participant must solve a complex puzzle and provide a proof of stake or proof of work to a server. The server checks the proof from each participant and rewards the ones with the correct proofs [16]. Once the proof has been approved by the server, the transaction is confirmed, and a new block which contains the hash code and the transaction is added to the ledger, as illustrated by Tar [17]. The new block creation process is called mining. A node gets rewarded with money for successfully mining a block first, so all the competing nodes race to process a transaction and create a new block; refer to Salman et al. (2019) [18]. Data on the blockchain is immutable, so it will never change after it is written into the ledger. One limitation of blockchain is that it relies on continuous communications between nodes in the network, so its performance will be largely impacted in areas with low bandwidth or slow connection, as explained by Zheng et al. [19].

Even though blockchain is a great solution for decentralized computing resources, data storage on a blockchain is still expensive, since the data needs to be pushed to other blockchain nodes and processed there as well. A blockchain node will need a more powerful CPU, higher bus speed, more bandwidth, and bigger storage to process all the data since there is a lot of data on the Internet now, and it is expected to get larger in the future, which will increase the cost to operate.

### Types of Blockchain

Blockchains can be classified as Public Blockchain, Consortium Blockchain, or Private Blockchain based on how clients participate, and they can also be classified as primary chains or side chains based on the relationship of chains. In addition, a few blockchains can shape a system. The system's chains are linked together to form the Interchain.

### Open

Public blockchains have ledgers accessible to anyone on the internet, and the blockchain can be checked and modified by everyone. ### Smart Contracts

A Smart Contract is essentially a computer protocol that enforces negotiations between the two exchanging parties. This forms, more precisely, a contractual agreement between two parties. This immediately verifies the deal, which meets the conditions agreed. Ethereum is the largest decentralized network producing infinite Smart Contracts using a command line. When an application incorporates the following components would be called Decentralized: The program must be completely open-source, run autonomously and without managing any of its tokens. To prevent any central failure points, the application data and operating records must be stored cryptographically in a transparent, decentralized blockchain.

Clearly, the program must use a proper cryptographic token to access the code. The application will produce tokens based on a standard cryptographic algorithm, which serves as evidence of the value nodes' contribution to the application.
