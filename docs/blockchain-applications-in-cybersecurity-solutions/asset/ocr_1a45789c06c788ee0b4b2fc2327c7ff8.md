# Method 1:

In this method, the inventors of the Blockchain have framed a set of rules that makes the recalculation of hash value difficult and time-consuming in case of any modification and an attempt to recalculate the hash of the following blocks. The rule to be followed for a harder calculation of the hash in each block should have X number of leading zeroes.

# Method 2:

The second method is Consensus-based, wherein the peer-to-peer network is followed [13]. Any participant can join the network. Each of the participants gets a full copy of the Blockchain. The Blockchain is distributed across different sites. Each authenticated device sends the block of data to all the peers of the network. More than 51 percent of the peers should validate the transaction, and then the block is added to the chain. In case of any modification of the data, recalculation of the hash and getting validation by more than 50 percent of the standard devices is very difficult.
