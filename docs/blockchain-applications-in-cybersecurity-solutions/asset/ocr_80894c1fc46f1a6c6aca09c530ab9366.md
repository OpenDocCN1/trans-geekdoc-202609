There are also two types of Blockchain nodes defined by the system architecture, namely managers and agents. A manager does not participate in mining, and is considered a lightweight Blockchain node. A single smart contract is deployed by the agent node to manage the access control permission of IoT devices. This specific smart contract comprises all of the capabilities of an access management system in one package. As soon as an IoT device receives an access request, it sends the request to the hub, which is connected directly to a Blockchain node, for example, to a miner that works together with the smart contract to determine whether the requestor is authorized to access the resource. In a proof-of-concept implementation, Blockchain technology has been used as a distributed access management technology for IoT.

Researchers identified two primary problems with IoT access control in [13]. The first is that of centralized architecture, and the second has to do with handling static policies. Using machine learning algorithms in conjunction with a blockchain architecture, the authors propose a framework for ensuring complete distributed access control while managing dynamic access policies based on machine learning algorithms. Utilizing a Smart Contract concept, this framework implements a resource owner's (RO) access control policy to manage access to a resource that he owns. It is important to remember that in order for the Policy Contract to properly execute, the requester must meet policies regarding accessing the data in question, thus allowing the Policy Contract to generate and issue an authorization token allowing him access to the resource. Every time the Policy Contract is interacting with something; a transaction is generated, which is recorded in the Blockchain register. The resource owner will also receive feedback information about the system's current state after the contract is executed by using Reinforcement Learning (RL) algorithms. The feedback information can be used to dynamically improve security parameters such as trust and integrity. A Proof of Concept is required to validate the proposed model.

IoT Chain is a Blockchain-based architecture called by the authors in [14] for securing End to End access management to IoT resources. Resources that are stored on the resources servers will be encrypted and signed and will be stored on a proxy server that the owners of the resources will own. It is, therefore, the client who requests access to the protected resources on behalf of a third party. Upon requesting the decryption key, it checks the Blockchain to verify if the client has been authorized before requesting the decryption key.
