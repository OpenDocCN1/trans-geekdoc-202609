# A Multi-Chain Decentralized Application and Smart Contract Platform

EtherCore [15] is a multi-chain decentralised application and smart contract platform that hosts a variety of real-world apps. EtherCore is a network foundation for your blockchain business that is highly distributed, fault-tolerant, and mission-critical. To tackle the paradox issue for a public blockchain platform, EtherCore includes ProgPoW, Proof-of-Authority, and a Programmatic Proof-of-Work consensus method. Users and developers may enjoy the decentralised internet without any network capacity constraints by using secure, stable, and scalable consensus rules. Thousands to millions of transactions per second can be processed on the EtherCore Mainnet [15].

# *EtherCore Features:*

**Secure** – ProgPoW, a Programmatic Proof-of-Work consensus method that is considered the most ASIC-resistant and GPU-friendly algorithm, is EtherCore's mainnet consensus algorithm. EtherCore is a secure and irreversible platform thanks to its strong decentralisation, which is powered by GPU miners at the grassroots.

# Fast

EtherCore is a fast blockchain technology, with a 14-second transaction confirmation time on the mainnet and a 1-second average confirmation time on the sidechain, allowing for real-time blockchain explanation. It is feasible to have dynamic block capacity for both the Mainnet and the Sidechain, ensuring that DApp developers and users have ample network capacity on demand. EtherCore offers faster storage options for storing data in real-time, and the sidechain will be able to serve as a cache for Mainnet because it has 1000 times the processing power of the original Ethereum blockchain.
