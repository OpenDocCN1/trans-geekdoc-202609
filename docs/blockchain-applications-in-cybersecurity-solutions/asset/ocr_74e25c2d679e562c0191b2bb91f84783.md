This section describes the detailed implementation, including encryption and decryption, access control using Smart Contracts, migration of the application to Remote IPFS, and the key-value memory cache.



To protect the privacy of our IPFS data, we use encryption and decryption. To generate public-private key pair, we first used OpenSSL commands. A file was encrypted and uploaded to IPFS using the public key. The hash code we received for the file was used to retrieve the file from IPFS after it had been successfully added to IPFS. Ultimately, we decrypted the file with the private key obtained from the pair of keys previously generated. It is expected that the downloaded file will contain the same contents as the original.
