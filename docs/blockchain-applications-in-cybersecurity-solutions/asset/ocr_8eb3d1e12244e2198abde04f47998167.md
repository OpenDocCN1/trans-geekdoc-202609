# Implementation of proof-of-work

The section 3.3.1 described the implementation process of creating a simple blockchain. It also included the processes involved in detecting tampered content in the chain. Computers have much more faster and efficient processors that easily add numerous blocks within a short span of time. This leads to spamming of blocks in the chain. Also efficient computing resources make the tampering process easier, where the hacker modifies the data stored inside a block and the hashes of all the succeeding blocks are recalculated. In this case, the data tampering goes unnoticed, because it shows a valid chain during the validation process. These problems need to be addressed while implementing simple blockchain. These issues are solved by the consensus mechanism described in section 2. This section explains how PoW is implemented using the process called mining. Mining increases the usage of computing resources, thereby, increasing the time taken to create a new block. In PoW, the mining process starts with generating random data continuously until enough number of zeroes are prefixed to the hash of the block. The number of zeroes prefixed in the hash is referred to as the difficulty level of the mining process. The random number, nonce, is included as part of the block along with the user’s data. The main objective of bitcoin is to create a new block every 10 minutes. It is possible because of the availability of faster computing resources. This necessitates more complex and difficult mining process. This is achieved by increasing the difficulty level.
