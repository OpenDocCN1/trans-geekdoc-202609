## Chain Validation

Blockchain is popular because of the high security provided. The integrity of the data in the Blockchain is maintained high using the process of mining. Mining the chain includes adding a new block to the chain by recalculating the hashes of the existing blocks and checking for the validity of the newly calculated hash value with the previous existing hash values. If there is any discrepancy in the hash values, that can be identified easily using the process of mining. The process of identifying the modified/tampered block can be done in two ways. One, using the present block hash, by comparing the present block hash with the recently computed present block hash. If these two values are equal, then the data is not modified/tampered with. Else the data is tampered with. Two, using the previous block hash, by comparing the previous hash of the present block with the computed hash of the previous block. Similarly, if these two hash values are the same, then there is no modification; else, the data is tampered with. The process of chain validation is represented in Figs. (9 and 10) as follows.

## CONCLUSION & FUTURE WORKS

Many smart devices like smartwatches, and smart home devices are emerging in the present digital world. This paper presents an overview of the Fitbit devices along with the type of data generated from those devices. In addition to this, various challenges of IoT security have also been discussed. Privacy and security are the primary concerns regarding IoT devices as it stores sensitive data about the person using them. Due to the advancement of high computational units, the servers can be hacked if they are protected with traditional security algorithms and centralized architecture. The proposed model provides security and privacy of the data and a single point of attack using blockchain technology, and any anomaly can also be detected using the same. The proposed model consumes more energy which is not ideal. This can be solved by implementing lightweight blockchains that consume less energy. In future works, the proposed model can be implemented for real-time data.
