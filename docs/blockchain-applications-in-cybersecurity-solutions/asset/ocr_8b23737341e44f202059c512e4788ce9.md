# BLOCKCHAIN ARCHITECTURE

Blockchain technology was first introduced by the author Satoshi Nakamoto [8]. The main intention behind this is to make online payments without third-party server authentication. This led to the invention of the current trending bitcoin and cryptocurrencies. This technology enables the user to exchange any digital information online. It provides high security, reliability, and availability because the Blockchain is immutable and secure. Because of these features, blockchain technology is used in a wide range of applications where there is a need for security. The data in the Blockchain is maintained in the form of nodes. Each node represents a transaction or a digital data entry. Each entry is encrypted with the private key of the user and is sent to the chain; the consensus algorithm checks the validity of the transaction and adds it to the chain. Thus, all the nodes/transactions are added to the Blockchain, which forms a chain-like structure.
