
首先，让我们探讨通过部分或完全去中心化 MEC（多接入边缘计算）来利用移动终端用户设备的潜力。我们介绍了在融合光纤-无线移动网络的光-无线接口处使用 AI 增强型 MEC 服务器进行计算卸载。假设与文献 [[28](#11_Chapter01.xhtml#ref1_28)] 相同的默认网络参数设置和仿真设置，我们考虑 `1 ≤ N[Edge] ≤ 4` 个 AI 增强型 MEC 服务器，每个服务器关联 8 个终端用户，其中 `1 ≤ N[PD] ≤ 8` 个部分去中心化的终端用户可以通过改变其计算卸载概率来灵活控制卸载任务的数量。剩余的 `8 − N[PD]` 个为完全中心化的终端用户，它们仅依赖边缘计算（即其计算卸载概率等于 1）。注意，当 `N[Edge] = 4` 时，所有终端用户均可将计算任务卸载到边缘节点。反之，当 `N[Edge] < 4` 时，一个或多个边缘节点不可用于计算卸载，其关联的终端用户将退回使用本地计算资源（即完全去中心化）。[图 1.6](#11_Chapter01.xhtml#fig1_6) 展示了不同 `N[Edge]` 和 `N[PD]` 下部分去中心化终端用户的平均任务完成时间随计算卸载概率的变化。我们从 [图 1.6](#11_Chapter01.xhtml#fig1_6) 中观察到，对于给定的 `N[Edge]`，增加 `N[PD]`（即更高程度的去中心化）能有效降低平均任务完成时间。具体而言，对于 `N[Edge] = 4`，高去中心化程度（`N[PD] = 8`）允许终端用户通过将计算卸载概率最优调整为 0.7，使平均任务完成时间最多减少 89.5%。

## 1.5.2 众包：扩展 HO 劳动力

为了在去中心化触觉互联网中实现 DAO，可利用以太坊建立用于远程物理任务执行的 HO-TOR 会话，其中智能合约有助于建立和维护可信的 HART 成员资格，并允许每个 HART 成员全局知晓所有参与的 HO、TOR 以及充当遵循广泛使用的网关导向方法（见 [第 1.3.1 节](#11_Chapter01.xhtml#sec1_3_1)）的自主代理的 MEC 服务器。HO 远程执行给定的物理任务，直到最近的 `n` 个触觉反馈样本中有 `k` 个被误预测。此时，HO 立即停止远程操作并通知代理。代理将中断的任务分配给附近的可用 HO，后者随前往任务点并完成物理任务。对于 `n = 5`，[图 1.7](#11_Chapter01.xhtml#fig1_7) 描绘了不同 `k` 和 `f[human]/f[robot]` 下的平均任务完成时间随样本误预测概率的变化，其中 `f[human]` 和 `f[robot]` 分别表示人类和机器人执行物理任务的能力（以每秒操作数为单位）。我们观察到，对于 `k = 1`，随着样本误预测概率从 0 增长到 0.25，任务完成时间增加；而对于 `k = 3`，任务完成时间几乎保持不变。此外，请注意，随着人类能力增强（即 `f[human]/f[robot]` 增加），由此产生的任务完成时间会减少，直到触及平台期，因为移动会产生额外延迟。

# 1.6 区块链、AI 与人类智能：前行之路

如今，AI、机器学习、机器人和物联网正在融合，创造出一波新的变革浪潮，因为它们开始利用加密货币、首次代币发行 (ICO)、虚拟资产以及万物代币化。这种创新融合与人类事业的结合引发了对失业、机器人统治者以及未来整体的担忧 [[33](#11_Chapter01.xhtml#ref1_33)]。

在文献 [[28](#11_Chapter01.xhtml#ref1_28)] 中，我们涉及了将研究重点从 AI 转移到智能放大 (IA) 的重要性，即利用信息技术增强人类决策。然而请注意，在不确定性增加的动态任务环境和复杂度极高的现实情境中，IA 变得困难。IA 也称为“认知增强”或“机器增强智能”，将在增强人类的创造力、理解力、效率和智能方面发挥关键作用。

### 1.6.1 基于认知辅助的智能放大

边缘计算是一种广泛研究的方法，可增加众包的实用性，可用于通过提供认知辅助，逐步指导人类完成物理任务执行过程。从技术上讲，这可以通过为非专业 DAO 成员配备增强现实 (AR) 头显（例如具有 WiFi 连接功能的 HoloLens 2）来轻松实现，该头显可实时从其最近的 AI 增强型 MEC 服务器接收工单信息。

### 1.6.2 HITL 混合增强智能

人类面临的许多问题往往具有高不确定性、高复杂性和开放性。为解决此类问题，可引入人类交互和参与。因此，这催生了用于先进人机协作的 HITL（人在回路）混合增强智能概念 [[34](#11_Chapter01.xhtml#ref1_34)]。HITL 混合增强智能被定义为一种需要人类交互的智能模型，允许解决那些难以通过机器学习轻松训练或分类的问题和需求。总体而言，机器学习在理解非结构化现实环境和处理不完整信息及复杂时空相关任务方面不如人脑。因此，机器无法独自完成人类社会中的所有任务。相反，AI 与人类智能更应被视为高度互补的关系。
