
在文献[[27](#13_Chapter03.xhtml#ref3_27)]中，介绍了一种基于深度学习机制的数据传播方案，用于 CC-IoV（云中心互联网车辆）。该机制包含三个阶段，综合考虑了车辆移动性和可共享数据类型。第一阶段基于能量估算机制，规定了可参与数据分发的车辆标准。在下一阶段，利用维纳过程模型通过计算车辆连接概率来发现稳定且真实的连接。在最后阶段，定义了基于卷积神经网络（CNN）的评估设计，对车辆对之间的社会关系进行评级。此外，利用 CNN 识别最合适的车辆对，确保以最小延迟和更高的可用数据率进行数据共享。

### 3.2.2 基于区块链的 CC-IoV

本部分分为三个小节，说明如下。

#### 3.2.2.1 基于区块链的 IoV

在文献[[28](#13_Chapter03.xhtml#ref3_28)]中，作者提出了一种半自动化的按需保险覆盖机制，利用区块链作为分布式账本，用于保险公司与消费者之间保险单智能合约的管理。用户只需使用移动应用程序即可激活、停用或修改盗窃、意外、乘客或天气等保险覆盖类型，与每种覆盖类型相关的所有状态数据通过电子设备传输至服务器，该设备负责收集传感器数据。修改保险或取消保险索赔时，传感器数据起着至关重要的作用。所有这些修改均依据智能合约进行，并存储在区块链上，提供不可篡改且可审计的记录。

在文献[[29](#13_Chapter03.xhtml#ref3_29)]中，作者提出了一种解决方案，以应对车辆通信中的安全数据共享问题。通过集成区块链来记录交通状况、处罚或奖励的消息交易，建立了一个信任等级。交通管理局（TMA）是负责维护车辆身份隐私的关键角色。信任等级通过签名阈值构建；如果签署消息的车辆数量超过阈值，则该消息被视为可信。同时引入了激励机制，以促使贡献者保持诚实。周期性广播消息且无转发策略会导致网络拥塞和延迟。

在文献[[30](#13_Chapter03.xhtml#ref3_30)]中，作者提出了一种基于区块链的车辆网络架构，以获取去中心化网络的优势。在网络中启用区块链可实现用户间的可信数据共享。由于应用中的数据种类繁多，区块链被分类为不同的区块链。车辆与其他网络设备协作生成区块，其密钥对嵌入交易中。这导致频繁的区块生成，进而引发网络中的数据流量泛滥；此外，该架构对于“谁来以及如何验证交易和区块”这一问题仍未给出答案。

在文献[[31](#13_Chapter03.xhtml#ref3_31)]中，作者为 IoV 提出了一种基于区块链的安全网络架构，车辆可在其中安全地通信、共享网络资源及信息。所提出的算法允许在分布式存储系统上存储多份数据副本，使数据比传统的中心化机制更安全。该方案包含初始化、加密及数据迁移。此外，算法还包含带有解密和数据上传的区块构建过程。在初始化阶段，IoV 网络为每个用户生成唯一 ID 以实现安全通信。之后，当用户想要传输数据时，IoV 网络启用加密过程。然后网络构建区块，该区块具有与主键关联的哈希值，并在哈希值验证通过后广播该区块。IoV 网络的所有节点将新区块添加到其区块链中。最后，用户遵循基于公共区块链账本方法的解密过程，可检索其所需数据。然而，该框架增加了数据检索延迟，但它提供了安全性、可靠性及连接车辆间的信任，并通过分布式控制系统利用 IoV 应用辅助其决策。

#### 3.2.2.2 基于区块链的 CCN

在文献[[32](#13_Chapter03.xhtml#ref3_32)]中，作者提出了一种密钥管理方案，通过将密钥存储在区块链上，对命名数据网络（NDN）中的角色进行认证。这确保了真实性，并建立了对内容生产者的信任等级。每个节点（包括设备和应用）均使用其名称前缀和公钥以交易形式注册，该交易由一组私有区块链节点验证，随后交易被添加到区块链中。用户通过其区块高度、交易哈希及有效/无效状态进行认证。每次认证都必须与站点管理员建立链接，这既耗时又会引入延迟。

在文献[[33](#13_Chapter03.xhtml#ref3_33)]中，作者提出了一种 CCN 中的安全数据共享机制，同时也保护隐私。区块链被集成以建立信任等级和可审计账本。网络中的每个用户均凭其唯一 ID 和密钥对注册。节点将内容指针放入交易中，这些交易经由通过具有共同社交兴趣的用户群投票选出的一组矿工节点验证后，被放置在区块链上。验证区块的矿工可从提供者处获得内容作为奖励。消费者可通过“通过”提供者设定的访问控制策略来获取内容，这会引入额外的网络开销和延迟。

在文献[[34](#13_Chapter03.xhtml#ref3_34)]中，作者提出了一种由区块链保障的标识符管理机制。区块链以混合方式使用，同时采用公有链和私有链。新节点可凭其密钥对在私有链上注册，并可参与交易验证以及区块的创建或验证。在 NDN 环境中，内容可在不暴露生产者 ID 的情况下传递给消费者，使实体免受拒绝服务（DoS）攻击。但无法检查恶意节点或一组恶意节点加入网络，因为任何节点均可凭密钥对注册。

在文献[[35](#13_Chapter03.xhtml#ref3_35)]中，作者提出了一种基于区块链的内容分发机制，增强了面向信息中心网络（ICN）的信任。内容提供者通过名称解析执行器（NRE）在逻辑区块链主机（LBH）上以交易形式注册其内容对象，并针对交易 ID 在 LBH 上获得已注册的有效载荷。消费者通过发现消息请求内容对象，该消息经过 NRE 然后是父 NRE，直到到达注册交易的 NRE。通过内容路由器建立一条反向路径，内容被发送给消费者。采取了一种对抗措施以确保交易是区块链的一部分，这得益于不可篡改且可审计的分布式账本（即区块链）而确保了信任。仅存储通往内容提供者的路由，这导致了内容分发延迟。
