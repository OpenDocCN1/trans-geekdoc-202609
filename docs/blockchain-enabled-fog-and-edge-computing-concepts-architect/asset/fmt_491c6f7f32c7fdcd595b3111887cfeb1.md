
# 8.4 BLOCKCHAIN FOR EDGE AND FOG

IoT应用越来越广泛。预计将以智能方式连接大量异构设备以提供多样化服务。为连接这些设备并提供所需服务，IoT系统在基础设施和设计方面面临诸多挑战，包括网络覆盖、海量流量负载、安全与隐私、高系统可用性与可靠性、QoS、数据存储与处理以及能源限制。虽然有许多解决方案可解决各个问题，但最佳途径是将现代技术和范式纳入IoT系统，以克服这些挑战并实现最高系统效率。

分布式数据存储和管理是解决数据存储和QoS问题（如边缘和雾计算机制）的一个有前景的解决方案。此外，区块链是一种重要的范式，可用于分布式系统以增强IoT系统的安全性和隐私性。这些范式的结合使IoT网络能够克服其挑战并实现高系统性能。

在考虑将区块链与IoT系统集成时，一个重要问题是这些交互将在何处发生。雾计算可在促进这种集成方面发挥关键作用。事实上，其分布式计算资源处于一个潜在位置，可在该位置进行IoT计划的挖掘。这三种技术的结合发挥了各自的优势 [[6]](#19_Chapter08.xhtml#ref8_6)[[12]](#19_Chapter08.xhtml#ref8_12)[[18]](#19_Chapter08.xhtml#ref8_18)[[19]](#19_Chapter08.xhtml#ref8_19)（[图 8.5](#19_Chapter08.xhtml#fig8_5)）。

## 8.4.1 Advantages

为克服IoT挑战，应为IoT网络部署新范式。分布式边缘、雾计算和区块链是近期可推动IoT系统实现高性能并满足这些应用主要要求的范式。这些范式的结合保证了最佳系统性能。

### IoT-based edge and fog computing

重要的技术进步导致IoT应用扩展，将导致智能设备产生的数据量激增。因此，由于连接到IoT的设备数量快速增长且多样化，集中式传统网络架构面临巨大挑战，难以满足新的和未来的服务需求。雾和边缘计算已被用于应对这些挑战，通过在分布式基础设施中将数据存储和处理靠近数据源，以实现更好的服务质量和体验。

雾计算由位于网络边缘的许多互联计算源组成。基于异构技术，所有雾节点相互连接、聚合，并被视为一个单一逻辑实体，能够同时执行分布式服务。它们形成一个中间层，可在需要时与云通信。

基于IoT的雾计算系统具有以下优势：

*   能够存储和处理海量数据并运行大型应用程序的重要计算能力。这种架构更适合可扩展网络，如IoT。
*   通过减少单向重传次数（到同一云服务器），缓解网络核心的数据流量和开销。
*   实现更高的延迟效率：许多位于网络不同区域且靠近IoT设备的雾节点的存在，通过提供快速、高质量的本地化服务（低延迟），满足实时交互和对延迟敏感的应用程序的需求，在边缘提供丰富的服务。
*   系统轻量化
*   更好的网络灵活性和可用性，因为所有雾节点相互连接并协同工作，应正常持续提供服务；如果某些雾节点故障，计算应快速转移并在其他节点上继续。

### IoT-based blockchain and edge and fog computing

另一个可为IoT系统增加价值的新范式是区块链。它可以用安全可靠的数据系统补充IoT。区块链技术被定义为用于记录已批准事件和交易的P2P分布式账本。换句话说，它可被描述为包含所有经验证用户之间已批准和共享数据的分布式数据库。这些用户反过来应批准新添加的信息。未经验证，不得向区块链数据库添加数据或中断数据。如今，区块链除支持加密货币系统外，还支持包括通信网络在内的许多应用。

为IoT网络部署区块链范式，允许基于分布式边缘和雾单元以可信方式管理去中心化，致力于避免异构网络安全攻击。它有助于实现更多可扩展性、提供隐私，并解决与IoT模式相关的可靠性问题。区块链与基于IoT的边缘和雾计算相结合，可实现多种收益，包括：

*   得益于区块链的分布式特性，更好地管理去中心化计算资源和系统灵活性，从而实现所需的可扩展性水平并提高系统可用性；以及
*   通过提供隐私、信任和可靠性，并抵御可能影响IoT数据系统的异构攻击，提高系统安全性。
