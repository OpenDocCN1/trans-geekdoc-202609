
在此背景下，Cisco 引入了雾计算作为云计算的延伸 [[4](#17_Chapter06.xhtml#ref6_4)]。ARM、Cisco、DELL、Intel 和 Microsoft 对未来及雾计算的效用持有相同愿景。它们成立了 OpenFog 联盟，旨在加速雾计算基础设施的开发与部署 [[5](#17_Chapter06.xhtml#ref6_5)]。雾计算和边缘计算都关注将数据处理移近终端设备；在本章中，我们使用“雾计算”这一术语，尽管两者根据算力放置位置的不同存在差异（参见[第 6.2 节](#17_Chapter06.xhtml#sec6_2)）。借助雾计算，数据处理在更靠近边缘的位置执行，只有摘要或异常数据被发送到云端进行进一步处理或存储 [[6](#17_Chapter06.xhtml#ref6_6)]。这为处理时间敏感型数据提供了必要支持，因为在这些场景中需要实时决策。就云计算而言，数据传输所需时间较长；因此，决策制定无法再保持足够的及时性。雾计算是云计算的一个强大替代方案，可在雾节点处理所有生成的数据。它是位于云端和终端设备之间的一层，作为一座桥梁提供存储、计算和网络服务（[图 6.1](#17_Chapter06.xhtml#fig6_1)）。这通过将处理移至用户附近，并在网络边缘或物联网-雾-云连续体中任何能最好满足应用需求的位置处理数据，从而支持视频流和游戏等广泛的物联网 (IoT) 应用。确实，雾计算继承并扩展了云计算的优势 [[7](#17_Chapter06.xhtml#ref6_7)]。同样重要的是物联网设备生成数据的隐私和安全，这是赢得应用用户信心的关键因素。确实，*每个*系统中都存在漏洞，包括雾计算。黑客总是试图利用网络、机器（雾节点）和应用的弱点和漏洞以获取未经授权的访问。在雾计算背景下提供安全和隐私具有挑战性，因为云计算的现有机制无法直接应用。Khan 和 Salah [[8](#17_Chapter06.xhtml#ref6_8)] 调查了网络中各层级（即低层级、中间层级和高层级）的安全问题及其影响。一旦发生攻击，服务会受到干扰，通信会被中断。例如，分布式拒绝服务 (DDoS) 构成最严重的安全问题之一，牵涉网络中的所有层级。Vlajic 和 Zhou [[9](#17_Chapter06.xhtml#ref6_9)] 报告称物联网设备代表了 DDoS 攻击的温床；他们提出区块链作为一种赋能解决方案来应对这些攻击。最近，许多研究 [[10](#17_Chapter06.xhtml#ref6_10),[11](#17_Chapter06.xhtml#ref6_11),[12](#17_Chapter06.xhtml#ref6_12),[13](#17_Chapter06.xhtml#ref6_13)] 得出结论，区块链可能是将物联网设备数据外包和传输给服务提供商时提高安全性的合适解决方案之一。

确实，区块链可被视为一项惊艳的创新技术，它彻底改变了我们开展业务的方式。该技术可定义为一种分布式数字账本，它利用点对点网络技术，在无需受信任的中心实体的情况下，以安全、按时间顺序且不可篡改的方式记录所有已发生的交易。更具体地说，区块链技术基于四个主要概念：分布式账本、共识机制、加密算法和智能合约。文献 [[14](#17_Chapter06.xhtml#ref6_14),[15](#17_Chapter06.xhtml#ref6_15)] 描述了最早旨在利用密码学保护区块链安全的贡献之一；作者设计了一个系统，其中文档的时间戳无法被更改。更重要的是，区块链通过降低安全风险，确保其用户有可能安全地进行交易，这比当前系统更具优势。正如工业界（如 IBM [[16](#17_Chapter06.xhtml#ref6_16)] 和 Microsoft [[17](#17_Chapter06.xhtml#ref6_17)]）和政府兴趣的剧增所证明的那样，它在金融和非金融应用中有许多用途。这项技术引发了一波新的经济浪潮，并将对几乎所有行业领域产生重大影响，从而将其推向聚光灯下。

节点、计算、去中心化和分布式本质等概念为区块链和雾计算所共有。此外，在不同的研究中，这两种技术都被指定用于满足物联网需求，其中区块链是应对安全和隐私问题的关键赋能者，而雾计算是应对计算、存储和网络服务的关键赋能者。本章的主要贡献是讨论区块链与雾计算的融合，旨在安全地共享数据并防止未经授权的用户访问数据。本章其余部分的结构如[图 6.1](#17_Chapter06.xhtml#fig6_1)所示。

## 6.2 借助雾计算和边缘计算实现云到物的连续体

目前，新的分布式架构促进了智能设备的涌现，并利用 5G 通信技术实现其组网和部署。其用途聚合了不同类型应用进步带来的数据指数级增长，应用范围涵盖智能交通、电子健康应用、零售，以及为机器人技术和增强现实开发的其他应用。这些设备在地理空间上分布；它们持续生成和消耗海量数据。为了及时处理这些数据，需要一种新架构来扩展云架构。为此特定目的，边缘计算（增强型数据 GSM 环境）和雾计算（或移动或虚拟云云小单元）被提议以互补方式协同工作，以提高提供给消费者的服务质量 (QoS) 和体验质量 (QoE) [[18](#17_Chapter06.xhtml#ref6_18)]（[图 6.2](#17_Chapter06.xhtml#fig6_2)）。

![Figure 6.2  Hierarchical architecture (cloud-fog-IoT devices), the smart devices (vehicles, phones, robots, surveillance video, etc.) could offload their workloads on fog nodes located in near proximity on the edge which provides an intermediate layer between the devices layer and cloud layer. IoT, Internet of Things.](images/fig6_2_B.jpg)

*图 6.2*  分层架构（云-雾-物联网设备），智能设备（车辆、手机、机器人、监控视频等）可将其工作负载卸载到位于边缘附近的雾节点上，该节点在设备层和云层之间提供了一个中间层。IoT，物联网。

雾节点和边缘节点被部署以确保不同数据源之间的交换，并处理网络中海量的事务切换。与中心化架构相反，去中心化架构最适合物联网应用，并带来了额外的有利特性，尤其是对移动应用。数据卸载到雾节点和边缘节点后，计算、控制、存储和网络将实时执行。这些节点不如云节点健壮，但优于物联网设备。需要高性能资源的关键数据处理和繁重或复杂的计算任务将被传输到云计算。此外，雾计算的处理结果将被传输到云数据中心以进行更好的数据分析。
