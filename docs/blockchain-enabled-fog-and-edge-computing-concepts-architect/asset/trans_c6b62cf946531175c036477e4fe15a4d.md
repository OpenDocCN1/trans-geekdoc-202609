

# 区块链技术概述

区块链是通信和网络安全领域的一项新兴创新技术。2008 年，在其萌芽状态下，区块链被提议为一种名为“比特币”的点对点加密货币。随着其概念和组件的发展，区块链可被定义为一种去中心化的分布式公共账本，能够在无需第三方的情况下，以高度安全且可验证的方式确保数据交换和管理。区块链可以存储任何有价值的东西，从原始数据到金融交易。该技术已成功取代各类组织中的经济交易系统，并有潜力在不同行业中重塑异构业务模型。它承诺提供一个安全的分布式框架，以促进所有用户和第三方之间的信息共享、交换和集成 [16](#16_Chapter05.xhtml#ref5_16)。根据谁有权访问账本，区块链主要分为三种类型，如 [图 5.1](#16_Chapter05.xhtml#fig5_1) 所示：

![Figure 5.1 Blockchain classification schema.](images/fig5_1_B.jpg)

*图 5.1 区块链分类架构。*

* **公有链**：因比特币和以太坊的兴起而最为人所知。公有链完全去中心化、公开可用，且可免费下载和使用，因此任何人都可以参与其中。例如：比特币[¹](#16_Chapter05.xhtml#fn5_1)加密货币、莱特币[²](#16_Chapter05.xhtml#fn5_2)、以太坊[³](#16_Chapter05.xhtml#fn5_3)。
* **私有链**：属于个人或组织的私有财产。所有权利和权限由单一实体掌控，例如希望保持其数据私密性的公司（如用于商业和数字合约的 Monax[⁴](#16_Chapter05.xhtml#fn5_4)）。
* **混合链、联盟链或联邦链**：具有部分去中心化的特征，因为参与节点是预先选定的，决策由授权节点集合定义。它们主要用于银行业（如用于商业的 R3[⁵](#16_Chapter05.xhtml#fn5_5) 和用于保险的 B3i[⁶](#16_Chapter05.xhtml#fn5_6)）。

在实践中，区块链实际上是一个数据库，因为它是一个存储带时间戳和结构化数据（称为“区块”）的数字链。一旦数据被记录在区块链中，它就变得不可破坏。由于区块链结构本身的特性，很难篡改或删除已记录的数据。区块相互链接，形成一条连续的链。同样，数据库也在称为“表”的数据结构中存储信息。然而，虽然区块链是一个数据库，但数据库不一定是区块链。它们不能互换使用，因为尽管它们都存储信息，但它们的设计不同[⁷](#16_Chapter05.xhtml#fn5_7)。

## 5.4.1 什么是区块链结构？

区块链是一个有序的反向链接列表，由携带称为“交易”数据集的区块组成，这些交易由称为“矿工节点”的实体创建并提交。例如，在临床数据管理领域，一笔交易可能是向数据库添加新患者、登记下一次预约或记录新的临床处方。每个区块通过其区块头的哈希值进行标识，并包含其他信息，这些信息对于其他节点轻松验证其正确性至关重要 [17](#16_Chapter05.xhtml#ref5_17)。此外，每个区块在“前一区块哈希”字段中引用前一个区块，也称为“父区块”。因此，前一区块哈希代表指向前一区块的指针。

如 [图 5.2](#16_Chapter05.xhtml#fig5_2) 所示，标准交易是一种包含可验证值和元数据的结构：用于指示创建时间的时间戳、一个或多个作为发送方地址引用的输入、一个或多个作为接收方地址引用的输出、交易大小，以及发送方的签名以证明发送方是交易的创建者。

## 5.4.2 区块链如何工作？

矿工是区块链的主要用户；他们使用唯一地址访问链上的账户。每个矿工拥有账本的共享副本，并拥有根据区块链规则（挖矿共识算法）添加区块、从而丰富分布式数据库的权利。共识是固定的，并根据区块链的性质及其用户需求而不断丰富。典型算法可定义如下：

1. 矿工创建的新交易被广播给所有网络节点。
2. 每个连接的节点持续监听网络，将新交易收集到一个区块中。
3. 在每一轮中，根据系统定义的选定共识协议，一个节点获得广播其区块的权利。
4. 其他节点仅在交易有效（例如：未花费、合法、具有有效签名等）时才接受新区块。
5. 节点通过在其创建的下一个区块中包含当前区块哈希来验证并表示接受。

如步骤 3 所述，区块不是随机广播的；矿工遵循通常硬编码在系统中的共识协议。在实践中，**工作量证明** 是最流行且稳定的算法。在 **PoW** 算法中，矿工计算一个哈希值，该值根据网络环境（如节点数量、添加区块所需时间）不断变化。算法要求该哈希值必须等于或小于系统固定的某个给定值。

参与者使用称为“随机数”的随机值持续寻找该值，直到达到目标。一旦找到所需的随机数，他们就可以发布结果。该协议的关键在于：搜索过程对于构建区块的矿工必须是适度困难的，但对于验证区块的矿工来说必须易于检查。

然而，最近也提出了其他几种共识算法，例如**权益证明**、**认证证明**和**概念证明** [18](#16_Chapter05.xhtml#ref5_18)，[19](#16_Chapter05.xhtml#ref5_19)，[20](#16_Chapter05.xhtml#ref5_20)。

前述算法是简化的；在实际的区块链使用中，交易不会被直接处理，等待在池中的过程称为“交易池”。因此，每个节点的未确认交易池由合法和不一致的交易组成。分布式交易随后在队列或交易池中等待，直到被挖矿节点添加到区块链中 [21](#16_Chapter05.xhtml#ref5_21)，[22](#16_Chapter05.xhtml#ref5_22)。

## 5.4.3 区块链的关键特性是什么？

区块链具有以下属性：不可篡改（共识机制）、可追溯（共享账本）、去中心化（点对点网络）和伪匿名（伪身份）。在 [23](#16_Chapter05.xhtml#ref5_23)，[24](#16_Chapter05.xhtml#ref5_24) 中，作者详述了每个特性并解释了其背后的发展机制。

* **去中心化**：没有中央权威机构来制定规则。相反，所有经过认证的节点根据其权限访问账本。由于共识机制，信息透明且按时间顺序保存在区块中。
* **不可篡改**：区块链系统可被视为可信的，因为账本内容经所有方同意，且更新后的副本在节点间扩散。这种机制使得恶意用户极难篡改或操纵，除非他们控制了大多数节点。
