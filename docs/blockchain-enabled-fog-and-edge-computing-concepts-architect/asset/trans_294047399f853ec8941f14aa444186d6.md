

# 区块链的基本机制：密码学

密码学是区块链的基本机制之一。众所周知，密码学的词源源自两个希腊词“cryptos graphein”，分别指“隐藏”和“书写”[[32](#17_Chapter06.xhtml#ref6_32)]。在不安全的环境中，引入密码学是为了确保只有经过批准和认证的实体才能使用多种技术从签名和加密的消息中提取数据。数据完整性、数据机密性、认证、匿名性和隐私保护是密码学实现的主要需求。为了实现安全私密的平台，区块链平台使用密码算法来满足上述需求。非对称密码学（也称为“公钥密码学”）主要用于构建数字签名以对交易进行签名。Rivest-Shamir-Adleman (RSA) 和椭圆曲线 Diffie-Hellman (ECDHA) 是区块链平台中使用的最有趣的密码方案。

## 密码学哈希

密码学哈希[[33](#17_Chapter06.xhtml#ref6_33)]是一种机制，用于在发行者将数据交易广播到网络之前对其进行加密。安全哈希算法 (`SHA256`) 是一种著名的哈希算法，已在多个密码系统中实现，它依赖于对输入参数进行哈希并将其转换为 256 位大小的输出。它是单向函数；即每个输入有且仅有一个哈希目标作为结果，并且无法仅根据哈希来预测和推断输入。此外，`SHA-256d`（对数据应用两次 `SHA256` 函数）用于增加复杂性和挖矿时间（比特币、Peercoin 实现了 `SHA-256d`）。`Scrypt`（由莱特币实现）和 `Ethash`（由以太坊实现）也是作为哈希函数的其他算法[[34](#17_Chapter06.xhtml#ref6_34)]。

### 6.3.4.2.1 签名交易

在区块链网络中，通过验证交易发送者是否为数据的真实合法所有者，以及交易数据在网络中是否被修改或篡改，来建立不同实体之间的信任和可靠性。非对称密码学通过一对密钥（公钥和私钥）绑定到网络中的每个实体。公钥在区块链网络的所有实体间共享，相反，私钥需要对其他实体保密，无论网络中建立了何种信任。基于区块链的系统具有自主性，可使用 `ECDSA` 或带有 `secp256k1` 的 `RSA` 为每笔交易生成一个由 27-34 个 alphanumeric 字符组成的唯一地址，称为全局唯一标识符 (`GUID`)[[35](#17_Chapter06.xhtml#ref6_35)]。根据[[36](#17_Chapter06.xhtml#ref6_36)]，区块链可分配的地址数量估计为 1.46 × 10^48，这增强了 IPv6 提供的地址空间。每笔交易都有一个发送方和一个接收方。公钥用于使用 pay-to-pub key hash (`P2PKH`) 方法[[35](#17_Chapter06.xhtml#ref6_35)]生成与交易关联的地址。私钥是一个 64 位 alphanumeric（256 位十六进制格式），用于对交易进行签名，且具有不可否认性，这意味着交易发行者无法否认其对数据的所有权。

## 6.3.4.3 智能合约

智能合约的概念由 Nick Szabo 于 1994 年提出，早于任何区块链技术的出现。它以传统合同相同的方式定义协议周围的规则和惩罚，但也能自动强制执行这些义务。智能合约是部署到区块链上的代码和数据；第一个基于区块链技术的智能合约于 2015 年部署在以太坊上。智能合约可以执行计算、存储信息，并自动向其他账户发送资金。更具体地说，它提供许多函数/原语（例如 `transfer token`、`store document` 和 `buy token`），可由用户调用。智能合约是不可变的（在区块链上）；因此，用户可以信任它执行从简单的加密货币转账到更复杂操作的各种操作。在以太坊上，智能合约可以使用 `Solidity` 语言（图灵完备语言）实现，并使用 `RemixIDE` 部署[[38](#17_Chapter06.xhtml#ref6_38)]。

## 6.3.5 隐私

重要的是要注意，数据传输必须在私密环境中进行，以确保交易元数据（发送方和接收方地址及内容）不被泄露。因此，我们可以区分两种隐私类型：保护交易内容和保护参与者身份，这两者都是核心需求。

1. 交易与其发行者之间的关系应以无法追踪真实身份并切断其关联性的方式进行管理。文献[[36](#17_Chapter06.xhtml#ref6_36)]指出了一些分析策略，如反洗钱 (`AML`) 或了解你的客户 (`KYC`)，这些策略应用于公共区块链网络，能够追踪交易路径并提取关于区块链的一些基本信息，回答谁在使用区块链技术以及用于什么目的等重要问题。

2. 隐私交易是指保护网络中不同节点间交换的交易价值。基于区块链的应用包含一些关键信息，如患者病历、财务记录等，这些信息需要防范具有欺诈或窃取意图的恶意对手。这意味着区块链技术应管理每个实体的可访问性和认证。

区块链的总体目标是通过实施不同技术来提高上述隐私级别，以满足前述需求。

区块链使用的不同技术中包括环签名。Rivest 等人[[39](#17_Chapter06.xhtml#ref6_39)]首次引入环签名，作为一种可用于掩盖和隐藏交易发行者真实身份并使其匿名的技术。它基于从一组用户的公钥中选择一组用户来构成一个环。过程如下：当用户尝试签名交易时，他们使用自己的私钥和环中所有用户的公钥（称为“RingSign”步骤）。然后，下一步是由验证者验证交易的有效性（称为“RingVerify”步骤）。使用此技术，交易发行者无法被触达和追踪。正如[[36](#17_Chapter06.xhtml#ref6_36)]所述并如[图 6.6](#17_Chapter06.xhtml#fig6_6)所示，用户分别拥有公钥和私钥，环由一组用户的公钥组成。用户使用环中的所有属性对消息进行签名。因此，验证者无法预测谁是该情形下消息交易的真实所有者，因为所有用户概率均等。

`Monero`[[40](#17_Chapter06.xhtml#ref6_40)]是一个实现了 `CryptoNote` 的分布式加密货币应用，后者使用环签名和一次性密钥来隐藏交易的源地址和目标地址。后来该方案升级为使用可追踪环签名，以防止双重支付攻击并使交易内容匿名。
