## 6.1 简介

信息技术无处不在，已成为我们日常活动不可或缺的一部分。各种复杂的设备及其应用正在快速演进。这些设备为在不同领域的广泛应用中切实发挥作用提供了新机遇，例如家庭自动化、医疗保健、智慧农业、供应链与物流、智慧城市、智能电网、网联汽车和可穿戴设备。这些应用产生海量数据，通常传输到中心化的云服务器进行处理和存储。根据思科互联网业务解决方案集团专家预测，联网设备数量预计将在2030年达到5000亿[[1]](#17_Chapter06.xhtml#ref6_1)。

当前的云计算框架，如Amazon Web Services和Google App Engine，可以支持计算密集型应用。然而，鉴于联网设备产生的海量数据的速率、分布和规模，在云端处理所有数据将变得不切实际。特别是对于具有严格延迟和高服务质量（QoS）要求的应用，云计算无法充分满足这些要求；例如，道路安全和自动驾驶应用要求延迟低于50毫秒[[2]](#17_Chapter06.xhtml#ref6_2)，而智能工厂的要求甚至更严格，延迟要求[[3]](#17_Chapter06.xhtml#ref6_3)。

此外，将所有数据发送到云端会导致网络流量爆炸性增长。通常这并不高效，因为数据中存在大量冗余。考虑到巨大的流量数据可能超过网络容量，这甚至是不可能的。为了克服云计算的局限性并成功支持广泛的应用，提出了一种新的计算范式，将数据处理从核心网络移至网络边缘，靠近设备和用户。
