# # 1.2 矩阵及其运算

由 m × n 个数 a_{ij} (i=1,2,…,m; j=1,2,…,n) 排成的 m 行 n 列的数表

称为 m 行 n 列矩阵，简称 m × n 矩阵。为表示它是一个整体，总是加一个括弧，并用大写黑体字母表示它，记作

A = {a_{ij}}_{m×n}

这 m × n 个数称为矩阵 A 的元素，简称为元，数 a_{ij} 位于矩阵 A 的第 i 行第 j 列，称为矩阵 A 的 (i, j) 元。

元素是实数的矩阵称为实矩阵，元素是复数的矩阵称为复矩阵。

行数与列数都等于 n 的矩阵称为 n 阶矩阵或 n 阶方阵。

只有一行的矩阵

A = [a_1, a_2, …, a_n]

称为行矩阵，又称行向量。

只有一列的矩阵

B = [b_1; b_2; …; b_m]

称为列矩阵，又称列向量。

两个矩阵行数相等、列数也相等时，就称它们是同型矩阵。

如果 A = (a_{ij}) 与 B = (b_{ij}) 是同型矩阵，并且它们的对应元素相等，即

a_{ij} = b_{ij} (i=1,2,…,m; j=1,2,…,n)

那么就称矩阵 A 与矩阵 B 相等，记作

A = B

元素都是零的矩阵称为零矩阵，记作 O。注意不同型的零矩阵是不同的。
