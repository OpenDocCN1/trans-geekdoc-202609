Using the definition of subgaussian norm (recall Proposition 2.6.6(i) and Remark 2.6.3), inequality (9.5) becomes

p(s) := P{ | ||Ax||₂ - ||Ay||₂ | / ||x - y||₂ ≥ s } ≤ 4 exp( - c s² / K⁴ )   ∀ s > 0.   (9.9)

(The constant 4 instead of 2 will give us a little more room for maneuver.)

# Case 1: s ≤ 2√m.

Let’s use the result of Step 2. To apply it, multiply both sides of the inequality that defines p(s) by ||Ax||₂ + ||Ay||₂, and recall the definition (9.7) of Δ to get

p(s) = P{ |Δ| ≥ s (||Ax||₂ + ||Ay||₂) } ≤ P{ |Δ| ≥ s ||Ax||₂ }.

We know from (9.4) that ||Ax||₂ ≈ √m with high probability. So it makes sense to consider two cases: the likely case where ||Ax||₂ ≥ √m/2 and thus |Δ| ≥ s√m/2, and the unlikely case where ||Ax||₂ < √m/2 (and where we drop the clause about Δ, only increasing the probability). This leads to

p(s) ≤ P{ |Δ| ≥ s√m/2 } + P{ ||Ax||₂ < √m/2 } := p₁(s) + p₂(s).

The result of Step 2 handles the likely case:

p₁(s) ≤ 2 exp( - c s² / K⁴ ),

and the result (9.4) of Step 1 together with the triangle inequality handle the unlikely case:

p₂(s) ≤ P{ | ||Ax||₂ - √m | > √m/2 } ≤ 2 exp( - c s² / K⁴ ).

Adding up the two, we get the desired bound

p(s) ≤ 4 exp( - c s² / K⁴ ).

# Case 2: s > 2√m.

By triangle inequality, | ||Ax||₂ - ||Ay||₂ | ≤ ||A(x - y)||₂, so p(s) ≤ P{ ||Au||₂ ≥ s } (where u = (x - y)/||x - y||₂ as before) ≤ P{ ||Au||₂ - √m ≥ s/2 } (since s > 2√m) ≤ 2 exp( - c s² / K⁴ ) (by the result (9.4) of Step 1 for u instead of x).

Therefore, in either case we obtain the desired bound (9.9).
