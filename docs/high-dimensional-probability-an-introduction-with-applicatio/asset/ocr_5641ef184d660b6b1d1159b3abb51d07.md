T = √s B₁ⁿ as in (9.22), use the truncated ℓ¹ ball Tₙ,ₛ = √s B₁ⁿ ∩ B₂ⁿ. This relaxation is pretty tight – try Exercise 9.25 to show

conv(Sₙ,ₛ) ⊂ Tₙ,ₛ ⊂ 2 conv(Sₙ,ₛ).

This tightening gives a logarithmic improvement to (9.24), showing that

m ≳ s log(en/s)

observations suffice for sparse recovery (see Exercise 9.26).

For more practice, find the Gaussian width of Tₙ,ₛ and Sₙ,ₛ (Exercises 9.26–9.27), prove the neat Garnaev-Gluskin theorem about slicing the ℓ¹ ball (Exercise 9.28), and discover Lasso – a popular method for sparse regression that is just a special case of (9.20) with the ℓ¹ norm (Exercise 9.21).

# 9.4.3 Example: low-rank recovery

Here is one more example of a high-dimensional linear problem: recover an d × d matrix X (instead of a vector) from m linear observations:

yᵢ = ⟨Aᵢ, X⟩,  i = 1, …, m,  (9.25)

where Aᵢ are known, independent random matrices, and the inner product is ⟨A, B⟩ = tr(Aᵀ B) as in (4.7).

Normally, you would need d² observations – one per entry. To get away with fewer, we need some structure in X. A common one is low rank. Just like sparsity counts nonzero entries, rank counts nonzero singular values.

So let’s try to argue like in Section 9.4.2. The rank – the ℓ⁰ norm of the singular values – is a highly nonconvex matrix function. To fix this, we make a convex relaxation by replacing it with the ℓ¹ norm, or the sum of the singular values, known as the nuclear norm:

‖X‖_* := Σᵢ₌₁ᵈ sᵢ(X).

We looked at the nuclear norm back in Exercise 7.18 – if you skipped it, now is a good time to go back and try it.

Since every vector x with at most s nonzero entries and ‖x‖₂ ≤ 1 satisfies ‖x‖ ≤ √s, every matrix with rank at most r and ‖X‖_F ≤ 1 satisfies ‖X‖_* ≤ √r (consider the vector of singular values to make the connection). So it makes sense to consider T = √r B_* as our prior, where B_* is the unit ball of the nuclear norm:

B_* := { X ∈ ℝ^{d×d} : ‖X‖_* ≤ 1 }.

The recovery program (9.18) becomes

find X' : yᵢ = ⟨Aᵢ, X'⟩ ∀ i = 1, …, m;  ‖X'‖_* ≤ √r,  (9.26)
