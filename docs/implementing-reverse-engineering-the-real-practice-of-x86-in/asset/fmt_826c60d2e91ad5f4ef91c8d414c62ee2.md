```
add esp, 44     ; 0000002cH

```

The `MOV` instruction will move the stack cookie stored at `[ESP+0x2C]` to `ECX`.

The `POP` instruction restores the value of `ESI` from the stack.

The `XOR` instruction will XOR the stack cookie moved to `ECX` with `ESP`, and the result of XOR will be stored back in the `ECX` register. On the call to the `security_check_cookie` procedure, this `ECX` value is compared with the stack cookie stored in the `.data` section.
