
# 第 9 章 – Python 中的循环

## While 循环

Python 的 `while` 语句是该语言中最通用的迭代结构。简单来说，只要顶部的测试表达式持续计算为真值，它就会反复执行一块（通常缩进的）语句。之所以称为“循环”，是因为控制流不断回到语句的开头，直到测试变为假。一旦测试变为假，控制流就会传递给 `while` 代码块后面的语句。最终效果是：只要顶部的测试为真，循环体就会反复执行。如果测试一开始就是假，循环体永远不会运行，`while` 语句会被跳过。

### 通用格式

在其最复杂的形式中，`while` 语句由一个包含测试表达式的头部行、一个包含一条或多条通常缩进语句的循环体，以及一个可选的 `else` 部分组成，该部分在控制流离开循环且未遇到 `break` 语句时执行。Python 会持续计算顶部的测试表达式，并执行嵌套在循环体中的语句，直到测试返回假值：

```
while test:          # 循环测试
    statements       # 循环体
else:                # 可选的 else
    statements       # 如果未通过 break 退出循环则运行
```

### 示例

为了演示，让我们看几个基本的 `while` 循环实际运行的例子。

第一个例子由一个嵌套在 `while` 循环中的 `print` 语句组成，它会永远打印一条消息。回想一下，`True` 只是整数 `1` 的一个定制版本，始终代表布尔真值；由于测试永远为真，Python 会一直执行循环体，直到你强制停止它的执行。这种行为通常被称为**无限循环**——它并非真正永恒，但你可能需要按 `Ctrl-C` 组合键来强制终止它：

```
>>> while True:
...     print('Type Ctrl-C to stop me!')
```

下一个示例不断切除字符串的第一个字符，直到字符串为空（因此为假）。直接这样测试对象很常见，而不是使用更冗长的等价形式（`while x != '':`）。本章稍后，我们将看到其他使用 `for` 循环更直接地遍历字符串项目的方法。

```
>>> x = 'spam'
>>> while x:              # 当 x 不为空时
...     print(x, end=' ')
...
spam pam am m
```

请注意此处使用的 `end=' '` 关键字参数，它将所有输出放在一行上并用空格分隔。这可能会让你的输入提示符在输出结束时处于奇怪的状态；按 `Enter` 键可重置。Python 2.X 读者：同样请记住，要在这些打印语句中使用尾随逗号代替 `end`。

以下代码从 `a` 的值计数到 `b`（不包括 `b`）。稍后我们将看到使用 Python `for` 循环和内置 `range` 函数来实现这一点的更简单方法：

```
>>> a=0; b=10
>>> while a < b:          # 编写计数器循环的一种方式
...     print(a)
...     a += 1
```

最后，请注意 Python 没有某些语言所谓的“do until”循环语句。不过，我们可以通过在循环体底部放置测试和 `break` 来模拟一个，这样循环体至少会运行一次：

```
while True:
    ...循环体...
    if exitTest(): break
```

要完全理解此结构的工作原理，我们需要进入下一节并了解 `break` 语句。

## break、continue、pass 和循环 else

现在我们已经看到了一些 Python 循环的实际运行，是时候研究两个仅在嵌套在循环内时才有用途的简单语句了——`break` 和 `continue` 语句。在研究这些特性时，我们也将在这里学习循环 `else` 子句，因为它与 `break` 紧密相关，以及 Python 的空占位符语句 `pass`（它本身不专门与循环相关，但属于简单单词语句的一般范畴）。

在 Python 中：

*   `break`：跳出最近的外层循环（越过整个循环语句）。
*   `continue`：跳到最近的外层循环的顶部（即循环的头部行）。
*   `pass`：什么都不做：它是一个空语句占位符。
*   循环 `else` 代码块：仅当循环正常退出时运行（即未遇到 `break`）。

### 通用循环格式

考虑到 `break` 和 `continue` 语句，`while` 循环的通用格式如下所示：

```
while test:
    statements
    if test: break        # 立即退出循环，跳过 else（如果存在）
    if test: continue     # 立即跳到循环顶部，进行测试
else:
    statements            # 如果我们没有遇到 'break' 则运行
```

`break` 和 `continue` 语句可以出现在 `while`（或 `for`）循环体的任何位置，但通常嵌套在 `if` 测试中进一步编写，以响应某些条件采取行动。让我们看几个简单的例子，了解这些语句在实践中是如何结合在一起的。

### Pass

首先：`pass` 语句是一个无操作占位符，当语法需要一条语句但你没有什么有用的可说时使用。它常用于为复合语句编写空主体。例如，如果你想编写一个每次循环什么都不做的无限循环，可以用 `pass` 来做：

```
while True: pass!
```

由于主体只是一条空语句，Python 会卡在这个循环中。`pass` 对语句的作用大致相当于 `None` 对对象的作用——一个显式的“无”。请注意，这里 `while` 循环的主体与头部在同一行，位于冒号之后；与 `if` 语句一样，这仅在主体不是复合语句时有效。这个示例什么都不做，永远持续下去。这可能不是有史以来最有用的 Python 程序（除非你想在寒冷的冬天给笔记本电脑加热！）；说实话，在本书的这个早期阶段，我想不出更好的 `pass` 例子。稍后我们将看到 `pass` 在其他地方发挥作用——例如，忽略 `try` 语句捕获的异常，以及定义带有属性的空类对象，这些属性的作用类似于其他语言中的“结构体”和“记录”。`pass` 有时也被编写为“稍后填入”，以临时存根函数体：

```
def func1(): pass  # 稍后在此添加真实代码
def func2(): pass
```

我们不能留空主体，否则会得到语法错误，所以我们写 `pass`。

**版本差异说明：** Python 3.X（但不是 2.X）允许编码为 `...`（字面上是三个连续的点）的省略号出现在语句可以出现的任何地方。由于省略号本身不执行任何操作，这可以作为 `pass` 语句的替代品，特别是对于稍后要填入的代码——一种 Python 的“TBD”（待定）：

```
def func1(): ...  # pass 的替代方案
def func2(): ...
func1()           # 调用时什么都不做
```

省略号也可以出现在语句头部的同一行，如果不需要特定类型，可能用于初始化变量名：

```
def func1(): ...  # 在同一行也有效
def func2(): ...
>>> X = ...       # None 的替代方案
>>> X
Ellipsis
```

此功能是 Python 3.X 中新增的——远远超出了 `...` 在切片扩展中的原始用途——因此仍有待观察它是否会普及到足以在这些角色中挑战 `pass` 和 `None`。

### Continue

`continue` 语句导致立即跳转到循环顶部。它有时可以让你避免语句嵌套。下一个示例使用 `continue` 跳过奇数。这段代码打印每一个小于 10 且大于或等于 0 的偶数。记住，`0` 代表假，`%` 是取模（求余）运算符，所以这个循环向下计数到 0，跳过不是 2 的倍数的数字——它打印 `8 6 4 2 0`：

```
x = 10
while x:
    x = x - 1
    if x % 2 != 0: continue  # 奇数？- 跳过打印
    print(x, end=' ')
```

由于 `continue` 接下来跳到循环顶部，你不必将 `print` 语句嵌套在 `if` 测试中；只有在 `continue` 未运行时才会到达 `print`。如果这听起来像其他语言中的“goto”，那应该是。Python 没有“goto”语句，但既然 `continue` 让你能在程序中跳来跳去，你可能听过的许多关于“goto”的可读性和可维护性警告也适用于此。`continue` 可能应该谨慎使用，尤其是当你刚开始学习 Python 时。例如，如果将 `print` 嵌套在 `if` 下，最后一个示例可能会更清晰：

```
x = 10
while x:
    x = x - 1
    if x % 2 == 0:        # 偶数？- 打印
        print(x, end=' ')
```

### Break

`break` 语句导致立即退出循环。由于如果到达 `break`，循环内后面的代码不会执行，你有时也可以通过使用 `break` 来避免嵌套。例如，这里有一个简单的交互式循环，它使用 `input` 输入数据，并在用户在姓名提示符处输入 "stop" 时退出：

```
>>> while True:
...     name = input('Enter name:')
...     if name == 'stop': break
...     age = input('Enter age: ')
...     print('Hello', name, '=>', int(age) ** 2)
...
Enter name: bob
Enter age: 40
Hello bob => 1600
Enter name: sue
Enter age: 30
Hello sue => 900
Enter name: stop
```

请注意，这段代码在将年龄输入平方之前，使用 `int` 将其转换为整数；正如你所记得的，这是必要的，因为 `input` 将用户输入作为字符串返回。你会注意到 `input` 在文件结束时也会引发异常（例如，如果用户在 Windows 上输入 `Ctrl-Z` 或在 Unix 上输入 `Ctrl-D`）；如果这很重要，请用 `try` 语句包装输入。

### 循环 Else

当与循环 `else` 子句结合使用时，`break` 语句通常可以消除其他语言中使用的搜索状态标志的需求。例如，以下代码通过搜索大于 1 的因子来确定正整数 `y` 是否为质数：

```
x = y // 2
while x > 1:
    if y % x == 0:        # 余数
        print(y, 'has factor', x)
        break             # 跳过 else
    x -= 1
else:                     # 正常退出
    print(y, 'is prime')
```

它不是设置一个标志在循环退出时测试，而是在找到因子的地方插入 `break`。这样，循环 `else` 子句可以假设只有在未找到因子时才会执行；如果你没有遇到 `break`，该数字就是质数。跟踪这段代码看看它是如何工作的。

如果循环体从未执行，循环 `else` 子句也会运行，因为在这种情况下你也不会运行 `break`；在 `while` 循环中，如果头部的测试一开始就是假，就会发生这种情况。因此，在前面的示例中，如果 `x` 最初小于或等于 1（例如，如果 `y` 是 2），你仍然会得到 "is prime" 消息。

此示例确定质数，但只是非正式地。根据严格的数学定义，小于 2 的数不被视为质数。为了完全精确，此代码对于负数也会失败，对于没有小数位的浮点数则会成功。另请注意，由于 `/` 迁移到了“真除法”（我们需要整数除法来截断余数，而不是保留它们！），其代码在 Python 3.X 中必须使用 `//` 而不是 `/`。如果你想尝试这段代码，请务必查看将它包装在函数中以供重用的练习。
