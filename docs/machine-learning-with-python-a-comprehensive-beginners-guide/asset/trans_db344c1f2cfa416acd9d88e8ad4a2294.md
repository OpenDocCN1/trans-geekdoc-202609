

# Python 运算符指南

## 算术运算符

在深入探讨运算符之前，您需要理解 Python 通过其内置计算引擎处理数学表达式。您可以轻松编写脚本来自动化任务，例如计算税费、小费、折扣或房租。以下是运算符、其功能和符号（注意：因为它们是数学运算，其符号与数学中的一致）：

| 运算符 | 功能 | 符号 |
| :--- | :--- | :--- |
| **加法** | 将左操作数和右操作数的值相加 | `+` |
| **减法** | 从左操作数的值中减去右操作数的值 | `-` |
| **乘法** | 将左操作数和右操作数的值相乘 | `*` |
| **除法** | 用右操作数除以左操作数的值 | `/` |
| **取模** | 返回左操作数除以右操作数/分母的余数 | `%` |
| **幂运算** | 执行指数计算 | `**` |
| **整除** | 执行向下取整除法 | `//` |

> **注意**：核心运算符是减法、乘法、除法和加法。它们通过配套表达式输入，并按其清理后的十进制数的相反顺序排列。

### 示例

**减法**：
```
>>> 50 - 5
45
```

**除法**：
```
>>> 25 / 5
5.0
```

使用除法时，请注意取模运算符（`%`）给出执行除法的余数：
```
>>> 27 % 5
2
```

分母将在清除小数后返回余数：
```
>>> 23 / 8
2.875
```

**指数运算**：通过将基数提升到 `**` 运算符后数字指定的幂来调用：
```
>>> 4 ** 3
64
```

**加法**：
```
>>> 6 + 7
13
```

**乘法**：
```
>>> 5 * 7
35
```

## 赋值运算符

这些运算符在将值赋给变量时很有用：

| 运算符 | 功能 |
| :--- | :--- |
| `=` | 将右操作数的值赋给左操作数 |
| `+=` | 加法赋值：将左操作数和右操作数相加，并将结果赋给左操作数 |
| `-=` | 减法赋值：从左操作数减去右操作数，并将结果赋给左操作数 |
| `*=` | 乘法赋值：将左操作数和右操作数相乘，并将结果赋给左操作数 |
| `/=` | 除法赋值：用右操作数除以左操作数，并将结果赋给左操作数 |
| `%=` | 取模赋值：取左操作数对右操作数的模，并将结果赋给左操作数 |
| `**=` | 幂赋值：对左操作数执行指数计算，并将结果赋给左操作数 |
| `//=` | 整除赋值：对左操作数执行向下取整除法，并将结果赋给左操作数 |

### `=` 运算符

您在前面章节中选择变量的精彩属性时已经见过此运算符。

**示例**：
```python
a = c
a = b + c
a = 8
a = 8 + 6
s = "I adore Python."
```

### `+=` 加法赋值

“加法赋值”（`+=`）运算符是表达 `x = x + a` 的另一种方式，因此您将得到语句 `x += a`。

### `-=` 减法赋值

“减法赋值”（`-=`）运算符类似于表达式 `x = x - a`，并用语句 `x -= a` 表示。

### `*=` 乘法赋值

“乘法赋值”（`*=`）运算符等同于表达式 `x = x * a`，并用 `x *= a` 表示。

### `/=` 除法赋值

“除法赋值”（`/=`）运算符类似于 `x = x / a`，并用语句 `x /= a` 表示。

### `%=` 取模赋值

“取模赋值”（`%=`）运算符是表达 `x = x % a` 的另一种方式，您将得到表达式 `x %= a`。

### `//=` 整除赋值

“整除赋值”（`//=`）等同于表达式 `x = x // a`，并采用形式 `x //= a`。

## 关系/比较运算符

关系运算符比较运算符左侧和右侧的值，并返回关系为 `True` 或 `False`。以下是 Python 中的关系运算符：

| 运算符 | 含义 |
| :--- | :--- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于或等于 |
| `<=` | 小于或等于 |

**示例**：
```
>>> 8 == 6 + 2
True
>>> 6 != 6
False
>>> -1 > 0
False
>>> 7 >= 5
True
```

## 逻辑运算符

Python 支持 3 个逻辑运算符：`or`、`and`、`not`。

### `x or y`
如果第一个参数 `x` 为假，则评估第二个参数 `y`。否则，评估 `x`。

### `x and y`
如果 `x` 为假，则评估 `x`。否则，如果 `x` 为真，则评估 `y`。

### `not x`
如果 `x` 为假，则返回 `True`。如果 `x` 为真，则返回 `False`。

**示例**：
```
>>> (8 > 9) and (2 < 9)
False
>>> (2 > 1) and (2 > 9)
False
>>> (2 == 2) or (9 < 20)
True
>>> (3 != 3) or (9 > 20)
False
>>> not (8 > 2)
False
>>> not (2 > 10)
True
```

## Python 运算符优先级

Python 运算符按以下顺序或优先级进行评估：

| 优先级 | 描述 | 运算符 |
| :--- | :--- | :--- |
| 1 | 指数运算 | `**` |
| 2 | 补码、一元正号和负号 | `~`, `+`, `-` |
| 3 | 乘法、除法、取模和整除 | `*`, `/`, `%`, `//` |
| 4 | 加法和减法 | `+`, `-` |
| 5 | 右移和左移位运算 | `>>`, `<<` |
| 6 | 按位与 | `&` |
| 7 | 按位异或和按位或 | `^`, `\|` |
| 8 | 比较运算符 | `<=`, `<`, `>`, `>=` |
| 9 | 相等运算符 | `==`, `!=` |
| 10 | 赋值运算符 | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, `**=` |
| 11 | 身份运算符 | `is`, `is not` |
| 12 | 成员运算符 | `in`, `not in` |
| 13 | 逻辑运算符 | `not`, `and`, `or` |
