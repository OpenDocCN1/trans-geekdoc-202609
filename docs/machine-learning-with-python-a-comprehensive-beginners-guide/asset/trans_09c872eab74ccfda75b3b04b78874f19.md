

# 第 2 章 – Python 实战

## 安装 Python (Windows)

开始使用 Python 的一部分工作是在 Windows 上安装 Python。安装的第一步是从下面的链接下载您首选版本的安装包：

https://www.python.org/downloads/

访问此链接，您将被定向到一个页面。在该页面上，您需要在 Python 2 和 3 的两个最新版本之间进行选择：`Python 3.5.1` 和 `Python 2.7.11`。反之，如果您在寻找特定版本，可以浏览页面以找到早期版本的下载链接。通常，您会选择下载最新版本，即 `Python 3.5.1`（于 2015 年 12 月 7 日发布）——或者下载 Python 2 的最新版本 `2.7.11`。但是，您下载的版本必须取决于您想要进行的项目类型，虽然 Python 3 是该语言的现在和未来，但诸如第三方工具或兼容性之类的问题可能要求您下载 Python 2。

下载完成后，您可以通过点击下载的 `.exe` 文件继续安装。标准安装将包含 `IDLE`、`pip` 和文档。

## 安装 Python (Mac)

如果您使用的是 Mac，可以从以下链接下载安装包：

https://www.python.org/downloads/mac-osx/

学习的进程正进一步深入 Python 编程语言。实际上，Python 是一种适应性强且功能强大的语言，可从多个角度使用。这仅意味着当代码或声明要在逐行的基础上进行尝试，或者当您在探究其特性时，Python 可以被智能地使用。令人难以置信的是，Python 可以用于脚本模式，特别是当您想要解释整个声明文档或应用程序时。然而，使用 Python 需要极度小心——特别是当您正在接触或连接它时。这种谨慎对每种编程语言同样适用。

为了以交互方式使用 Python，可以使用命令行窗口或 `IDLE 开发环境`。既然您是编程或使用 Python 的初学者，将会有不同的步骤来介绍您如何连接和配合 Python 编程语言。以下是与 Python 快速交互的基本操作特性：

## 命令行交互

对于初学者来说，与命令行交互是使用 Python 的最简单方法。通过查看 Python 对在 `>>>` 提示符下输入的每条完成命令的反应，就可以简单地想象 Python 是如何工作的。命令行可能不是与 Python 交互的最受青睐方式，但多年来，它已被证明是初学者探究 Python 如何工作的最简单方法。

### 使用命令行启动 Python

如果您使用的是 macOS、GNU/Linux 和 UNIX 框架，应运行 `Terminal` 工具以访问命令行。另一方面，如果您使用的是 Windows，可以通过右键点击开始菜单并启动 `Windows PowerShell` 来访问 Python 命令行。

由于编程指令需要输入命令，当您需要 Python 为您做某事时，您将通过输入它知道的命令来指令它，以获得类似的输出。命令的细微调整可能会给出理想的输出；请小心。有了这个，Python 将把这些命令翻译成您的计算机或设备能够理解和执行的指令。

让我们看看一些指南，以了解 Python 是如何工作的。请注意，您可以使用 `print` 命令来打印通用程序 "Heydays, Savants!"。

1.  首先，打开 Python 的命令行。
2.  然后，在 `>>>` 提示符下，输入以下内容（不要在 print 和括号之间留空格）：
    `print ("Heydays, Savants!")`
3.  现在，您应该按回车键，以便告诉 Python 您已完成该命令。

命令行窗口将立即显示 `Heydays, Savants!`。同时，Python 的反应正如它在书面安排中被告知的那样，它可以与之关联。

另一方面，要查看当您要求它使用 `print` 命令的错误语法打印相同字符串时它将如何错误地反应，请在 Python 命令提示符下输入并回车以下命令：

`Print("Heydays, Savants!")`

结果将是：

`Syntax error: invalid language structure`

这是当您使用无效或片段说明时会得到的情况的一个例子。请注意，Python 是一门**大小写敏感**的编程语言，因此每当您收到误解消息时，可能是因为您用大写字母写了 `print`。

显然，除了 print 命令外，您还可以直接在引号内输入您的声明，如下所示：

`"Primes, Savants!"`

请注意，声明是指令发出后您希望显示的词语；不过，能填入的词语不限于此处给出的示例。

### 如何退出 Python 命令行

要退出 Python，您可以输入以下任一命令：

`quit()` 或 `exit()`。

随后，按住 `Control-Z` 然后按 `Enter`；Python 应该会退出。

您对 Python 编程的熟悉程度现在应该变得有趣了；还有很多部分需要学习，耐心会有回报。

## IDLE 的区域：Python 的集成开发环境 (IDE)

Python 最迷人的部分之一是 `IDLE`（集成开发和学习环境）工具。尽管这个特定工具包含在 Python 的安装包中，但您也可以下载越来越复杂的第三方 IDE。`IDLE` 工具为您提供了一个越来越有效的平台来编写代码并引人入胜地使用 Python。

要访问 `IDLE`，您可以浏览到您找到命令行图标的相同文件夹，或开始菜单（正如您从命令行交互中了解到的）。当您点击 `IDLE` 图标时，您将被引导至 `Python Shell 窗口`。这将带我们进入与 `Python Shell 窗口` 交互的部分。

## 与 Python Shell 窗口连接

当您位于 `Python Shell 窗口` 时，您将看到一个下拉菜单和一个类似于您在命令行窗口中看到的 `>>>` 提示符（讨论的主要连接）。有一个特定的 `IDLE` 编辑功能用于处理过去的命令。现在，您将使用相同的 `IDLE` 编辑菜单来回溯您过去的命令，剪切、复制和粘贴过去的语句，并在所有事情中，进行任何形式的编辑。

显然，`IDLE` 与命令行交互相比更像是一个飞跃。令人难以置信的是，`Python Shell 窗口` 的菜单下拉列表中有以下菜单项：

`File`、`Windows`、`Help`、`Shell`、`Options`、`Edit` 和 `Debug`。

这些菜单中的每一个都有不同的功能。`Shell` 和 `Debug` 菜单在制作大型项目时使用，因为它们为该过程提供获取功能。然而，虽然 `Shell` 菜单让您有机会重启 shell 或查看 shell 的日志以获取最新重置，`Debug Menu` 则有大量有价值的东西用于跟踪异常的源文件并高亮显示出错的行。通过 `Debugger` 选项，您将能够引入一个智能调试器窗口，它将使您能够单步执行并查看 Python 上运行的项目。

窗口的 `Options` 菜单使您能够编辑和设置 `IDLE` 以适应您自己的 Python 工作偏好。此外，在 `Help` 菜单中，您可以选择 `Python Help` 和文档。

使用 `File Window` 菜单，您将能够创建新文档、打开模块、打开旧文件，以及通过访问此菜单时自然创建的基本项目来保存您的会话。通过 `New File` 选项，您将能够创建代码，您所要做的就是点击它。当您这样做时，您将被带到一个带有简单标准文字处理器的新窗口，您可以在其中输入或修改代码。您会看到文件是 `untitled`（未命名），不要惊慌，这是文件的初始名称，保存代码时会更改。

`File window` 菜单的一件很棒的事情是它拒绝将 `Shell` 和 `Menu` 选项放在一起，所以菜单栏仅与 `Shell Window` 略有不同。发生的情况是，在 `Shell Window` 中，引入了两个新菜单，即：`Run` 和 `Format` 菜单。

每当您想要运行在文件窗口中编写的代码时，输出将单独在 `Shell Window` 上给出。

在本节开始时，您被告知 Python 可以在脚本模式下使用。如何做到这一点？获取结果的方法在这一点上非常不同。在脚本模式下工作时，您得到的结果不会像在交互或关联模式下那样是自动的。您必须从代码中调用它们。要在此模式下获得输出，请通过代码内的 `print()` 函数运行脚本或编译它。

为了结束本节，您已经了解了 Python 编程语言的两种基本模式：交互或关联模式和脚本模式。无论情况如何，请认识到根本的变化在于一个结果是基于命令获取的，而另一个是自动的。

# 第 3 章 – 运行 Python 程序

学习 Python 编程在这一章变得非常成功。作为介绍的一部分，本章将讨论 Python 如何运行其程序。这至关重要，特别是在这个阶段，因为您必须首先理解程序以及它们是如何运行的，然后才能知道如何编写它们。拥有程序如何编译和运行的基本信息将使您在充分学会它们后能够毫无问题地快速理解代码。

如果不给予 Python 程序适当的理解，当我们正式接触 Python 时可能会产生混淆。从本书开始到这一章，希望您多多少少已经掌握了 50% 的 Python 编程语言基础。

在这里，将略微从将 Python 编程视为一种改良语言转向将其视为一种使用解释器进行广泛程序编译的编程。从真实意义上讲，Python 有一个名为 `Interpreter`（解释器）的特殊包。解释器是一种执行其他程序的程序。当编写代码以运行特定程序时，解释器将为其提供在不同平台上使用的能力，以防开发者希望将程序连接在一起。

令人惊讶的是，当您通过指定代码编写 Python 程序时，Python 解释器将您的程序作为代码读取，然后完成其中包含的指令。可以说，解释器就像您的代码和机器上的计算机硬件之间的一层编程逻辑。没有解释器，Python 将难以读取和转换代码为程序——那时它的用处何在？

在引入 Python 编程的过程中，解释器被引入并赋予了其功能。当 Python 包安装在您的机器上时，它会产生各种部分；无论如何，一个解释器和一个帮助库。您应该回顾标准帮助库的有用性；它们已在描述和第 1 章中讨论过。

解释器的全部生产力取决于您如何使用它：Python 解释器可能表现为可执行程序或连接到另一个程序的一组库。同样，解释器根据您运行的 Python 类型拥有不同种类的 Python：解释器本身可能作为 `C` 程序、一组 `Java` 类或其他东西执行。

无论您采取的代码、结构、增强方式如何，您编写的 Python 代码应始终由解释器控制。这就是 Python 运行其项目的方式。为了启用对代码的完整读取，您必须在 PC 上安装 Python 解释器。这种特定的安装与您安装软件时内置的“不可见”安装截然不同。这是“真正的”解释器，它更像是一个扩展，以确保程序编码和编程连接的平滑、快速和高效运行。

总之，以下是 Python 解释器可以运行和引入的阶段：

*   **对于所有 Windows 用户**，您将获得并运行一个自安装可执行文件，将 Python 放在他们的机器上。要做到这一点，只需双击并在所有提示和后续问题上回答 `Yes` 或 `Next`。
*   **对于所有 Linux 和 MacOS 客户端**，他们的电脑上可能已经预装了可用的 Python。这是当今这些平台的标准部分。
*   **其他一些 Linux 和 Mac OS X 客户端**，通常是 Unix 用户，Python 的集合完全来自其完整的源代码分发包。这考虑到他们内置的编程和功能至关重要。
*   **关于 Linux 用户**，他们也可以找到 `RPM` 文件和带有特定但可变安装包的 Mac OS X。
*   **其他阶段**要求不同于目前给出的那些，它们拥有对它们重要的既定方法。例如，Python 可用于手机、平板电脑、游戏机和 iPod，但它们的安装细节差异很大。

尽管如何获取 Python 本身已提供（请参阅第 1 章），您也可能通过其他分发渠道找到它，但请始终在安装前验证 Python 是否已存在于您的工作站上，以避免问题。

如果您在 `Windows 7` 及更早版本上工作，通常会在开始菜单中发现 Python。在 Unix 和 Linux 上，Python 很可能位于您的 `/user` 注册表树中。

为了本节和下一节的目的，假设您已准备好 Python，甚至从第一部分就已准备好。

在研究了 Python 项目的内容以及如何安装它们之后，讨论项目如何执行是合适的。通过 Python 程序执行的解释，您将知道代码是什么以及如何运行它们。

有趣的是，仅从开发者的角度或 Python 解释器的角度来看，理解程序如何运行完全取决于您从哪个角度看；这些观点实际上为 Python 编程提供了不同的评估。我们将在下面探讨这两种观点：

### 从开发者的视角

从开发者的视角来看，Python 程序只是一个包含 Python 语句的文本文件。例如，以下名为 `script0.py` 的文件是最简单的 Python 脚本之一，它仅将其完整的功能性 Python 程序作为：

```
print('What's up world')
print(2 ** 100)
```

此文件包含两个 Python `print` 声明，它们基本上将一系列词语（what's up world）和一个数字语句结果（2 的 100 次方）打印到输出流。目前，该语言的结构不应是您的担忧，您将在本书的最后部分更好地理解它。这里的基本担忧是理解 Python 程序如何运行。

请在您的文字处理器上运行此代码以获得成功的理解。根据 Python 工作的一般指南，程序文件被赋予以 `.py` 结尾的名称；事实上。实际上，这种命名方案仅对被“导入”的文件是必需的，但您很可能注意到大多数 Python 文件都有 `.py` 名称。这是为了确保一致性和快速理解。

现在，您应该已将这些声明写入您的脚本文件。如果您已完成，您应该指示 Python 执行该文件。通过执行，仅意味着从头到尾、持续地运行文件中的每个声明。

综合您的编写来看，当您执行文件时，您会在电脑上的某个地方看到两个 `print` 声明的结果——通常默认在您运行程序时所在的同一个窗口中：`primes intellectuals`。

例如，这是我在 Windows 工作站的命令提示符窗口命令行从我的端运行此脚本时发生的情况，以确保它没有任何愚蠢的语法错误：

```
C:\code> python script0.py
What's up world!
```

对于我们的目的，我们刚刚运行了一个打印字符串和数字的 Python 脚本。确实，我们不会凭此代码赢得任何编程荣誉，但它足以掌握程序执行的基础。

### 从 Python 解释器的角度

从 Python 解释器的角度来看，理解本节中的中介对于脚本语言来说是真正标准的，而且通常这就是大多数 Python 开发者作为初学者所需要知道的一切。所需要的只是将代码写入脚本文件并通过翻译器运行那些文件。

在作为 Python 扩展的翻译器内部，当您告诉 Python “去”运行时，会发生更多事情。即使理解 Python 内部结构对于 Python 编程并非严格要求，但对 Python 运行时结构的基本理解可以帮助您掌握程序如何执行的总体蓝图。

当您指示 Python 运行您的脚本时，在您的代码真正开始疯狂运行之前，Python 会做几个步骤；将代码收集成所谓的“字节码”，然后引导至所谓的“虚拟机”。与原始方式相比，这在工具上更简单。

总而言之，您已经知道了 Python 程序如何运行以及如何执行。希望您不认为在没有适当的实践跟进的情况下就非常理解这一点；不做就学，编程就没有功效。

## Python 标点符号中使用的引号

在 Python 的标点符号中，有大量通过使用引号完成的指令。实际上，Python 允许使用引号来表示字符串字面量。无论您使用单引号、双引号还是三引号，都必须以相同的类型开始和结束字符串，以确保程序按指定执行。请注意，只有当您的字符串跨越多行时，才会使用三引号。

## Python 中的声明编写

给 Python 翻译器执行和运行的指令排列称为语句 `Statements`。例如，当您给变量赋值，例如 `my_variable = "feline"`，您刚刚拥有了一个赋值表达式。但是，赋值的语言结构不在于它有多长或带有引号，赋值表达式也可以像 `c = 3` 这样短。

Python 中不同类型的语句包括：`if` 语句、`for` 语句、`while` 声明等。

## 多行声明的语言结构

如前所述，声明被称为指令。这些指令可能跨越多行；因此称为多行声明。在编写代码时，您需要将长声明分成多行。为此，您可以将语句包裹在圆括号、方括号和花括号内。基于编写风格，此过程是处理多行语句的首选风格。

另一方面，还有通过在每行末尾使用斜线（`\`）来显示行继续的方式来包裹多行。当您编写自己的代码时，对多行语法的理想理解变得简单。

## 缩进的句子结构

通常，空格用于表示代码块。这类似于在 `C`、`C++` 等其他编程语言中使用大括号。Python 是按空格排列的。使用 Python，代码块是按空格排列的，而不是按风格或偏好，而是作为一种严格的语言要求。许多开发者得出结论，这一准则结合其他准则使 Python 代码越来越易读和合理。

基于识别和结构，当您查看 Python 程序时，可以轻松识别代码块，因为它们开始于相同的向右距离。如果必须更深嵌套，您可以简单地将另一个块进一步向右缩进。

例如，这里是一个定义鞋子成本的程序片段：

```
def cost_of_shoes($5):
    cost = 5 * $
    if 3 >= 15:
        cost -= 4
    elif days >= 2:
        cost -= 10
    return cost
```

重要的是要注意，您应始终确保缩进空间在块内是一致的。当您使用 `IDLE` 和其他 `IDE` 添加代码时，当您输入需要空格的语句时，Python 会自动在后续行上提供空格。根据 Python 的原则，空格等同于向右 4 个空格；请坚持这一点。

创建缩进后，您可能想知道如何结束它。简单来说，每个缩进的结束就是块的结束。

Python 排除的第三个也是最后一个句法部分，对于大多数其他类 `C` 语言的学习者来说可能看起来是最重要的一点，即不需要在代码中编写任何无关内容来语法上访问括号代码块的开始和结束。您不需要像在类 `C` 语言中那样包含 `start/end`、`then/end if` 或包围括号块：

```
if (x > y) {
    x = 1;
    y = 2;
}
```

在 Python 中，相反，您始终如一地缩进给定单个嵌套块中的所有代码，给予它们相同的向右距离。请注意，Python 使用代码的物理空格来了解块在哪里开始和停止：

```
If a > b:
    a = 1
    b = 2
```

缩进意味着，现在，两个嵌套声明周围的空白字符。Python 不在乎您缩进的程度（您可以使用空格或制表符），也不在乎您如何缩进；您可以选择使用任意数量的空格或制表符。也就是说，一个嵌套块的缩进可能与另一个截然不同。通用的语法规则仅仅是所有缩进语句必须缩进相同的向右距离。这是因为如果不这样做，您将得到一个语法错误，并且您的代码将无法运行，直到您修复其缩进以使其保持一致。在经历执行阶段之前，请检查一切。

## 注释的语言结构

编写程序时，有时您想在代码内放置一些注释，以描述该语句的作用；这种东西称为注释。当您想要审查或返回程序以查找缺陷或更改时，注释最有价值；它更容易追踪。此外，对于希望查看您源代码的其他开发者，注释将使其更容易。

您如何在程序内编写和构建注释是以井号（`#`）符号开始该行。对于 Python 解释器，井号符号告诉 Python 解释器在运行代码时忽略注释。如果您的注释是多行的，可以在每行开头使用井号符号。或者，您也可以用三引号包裹多行注释。

## Python 标识符的语言结构

在 Python 程序内，`Python Identifiers`（Python 标识符）是给 `class`（类）、`module`（模块）、`function`（函数）、`variable`（变量）或其他对象的名称。这是您将在 Python 中用于编写代码的任何实体都应被适当命名或给予正确识别，因为它们将构成程序的一部分。

以下是您应该了解的 Python 命名约定：

标识符可以是大写字母、小写字母、下划线和数字（0-9）的组合。因此，以下是有效的标识符：`theMovement`、`my_movement`、`move_1` 和 `print_what_is_world`。

以下是关于 Python 标识符的特别提示：

*   在标识符中，不允许使用特殊字符，例如 `%`、`@` 和 `$`。
*   请注意，`3life` 无效，而 `life3` 有效，因为标识符不应以数字开头。
*   通常，Python 是一门**大小写敏感**的语言。这是标识符的典型特征，这也是为什么 `Happy` 和 `glad` 是 Python 中两个特定的标识符。
*   Python `keywords`（关键字）不能用作标识符。
*   创建 `class`（类）时，`Class` 标识符必须以大写字母开头，但其余标识符小写。
*   标识符中不同单词的分隔符是下划线。
*   您应始终选择即使在很长一段时间后对您仍有意义的标识符。这就是为什么将变量设为 `c = 2` 很容易的原因。
*   为了未来的目的，建议您使用更长但更有意义的变量名，例如 `consider = 2`，这在任何混淆点都会变得更容易。

综上所述，Python 的语法已由 `modules`（模块）管理，您将在需要它们的地方用到。这是因为您将分别获得关于它的所有内容，而不是将其组装在一起。学习时别忘了运行项目。
