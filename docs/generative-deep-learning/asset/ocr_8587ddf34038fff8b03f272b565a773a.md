The key idea behind contrastive learning is simple. We train two neural networks: a text encoder that converts text to a text embedding and an image encoder that converts an image to an image embedding. Then, given a batch of text–image pairs, we compare all text and image embedding combinations using cosine similarity and train the networks to maximize the score between matching text–image pairs and minimize the score between incorrect text–image pairs. # CLIP Is Not Generative

Note that CLIP is not itself a generative model—it cannot produce images or text. Is it closer to a discriminative model, because the final output is a prediction about which text description from a given set most closely matches a given image (or the other way around, which image most closely matches a given text description).
