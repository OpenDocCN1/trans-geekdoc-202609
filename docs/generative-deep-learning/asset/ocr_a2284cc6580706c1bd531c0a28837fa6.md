# Architecture

The solution consists of three distinct parts, as shown in Figure 12-3, that are trained separately:

+   V
+     A variational autoencoder (VAE)
+   M
+     A recurrent neural network with a mixture density network (MDN-RNN)
+   C
+     A controller
