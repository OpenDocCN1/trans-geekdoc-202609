# The Energy Function

The energy function Eθ(x) is a neural network with parameters θ that can transform an input image x into a scalar value. Throughout this network, we make use of an activation function called swish, as described in the following sidebar.

# Swish Activation

Swish is an alternative to ReLU that was introduced by Google in 2017² and is defined as follows:

swish(x) = x · sigmoid(x) = x / (e^{-x} + 1)

Swish is visually similar to ReLU, with the key difference being that it is smooth, which helps to alleviate the vanishing gradient problem. This is particularly important for energy-based models. A plot of the swish function is shown in Figure 7-3.
