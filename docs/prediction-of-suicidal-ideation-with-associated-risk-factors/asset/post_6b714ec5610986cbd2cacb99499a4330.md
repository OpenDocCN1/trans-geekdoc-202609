The K-Nearest Neighbour also be known as the distance-based machine learning algorithm, mostly used for classification problems. It aims to locate all of the neighbors around a new point to determine which class it belongs to (Sainn et al., 2013).

### 2.5.3. XGBoost

XGBoost is a decision-tree based ensemble machine learning algorithm. XGBoost and Gradient Boosting Machines (GBMs) are ensemble tree methods, XGBoost improves upon the base GBM framework through systems optimization and algorithmic enhancements. In this algorithm, trees are created in sequential format (Chen and Guestrin, 2016).

### 2.5.4. Random forest

Random forest is an ensemble machine learning method based on classification and decision regression trees. It is based on well-known ensemble learning methods of classification type: boosting and bagging (Belgu and Callik, 2018).

### 3.3. Evaluation of performance

Table 3 displays the performance metrics of all the algorithms. All algorithms achieved a respectable accuracy around 90%. On the performance metric, it is observed that KNN achieved the highest accuracy of 91.45%. Furthermore, it is noteworthy that RF and CatBoost exhibited comparable efficiency, with accuracies of 90%. Of all, the decision tree exhibited a lower accuracy of 80.34. Regarding F1, KNN scored the highest at 91.26, while the other algorithms produced similar results with values around 90%. In the Area Under Operating Curve (AUC) performance for binary classification, it evaluates a model's performance by ability to distinguish between positive and negative classifications. In Fig 2, the KNN model achieved an AUC of .953, showing high precision in distinguishing between depressive and negative classifications. This underscores the model's ability to accurately rank instances from the two classes. The Random Forest, with an AUC of .921, closely trails the KNN and RF models and exhibit excellent classification capabilities. The CatBoost model, with an AUC of .886, showcases decent performance, potential for improvement in classification abilities compared to the previous models. The Decision Tree model, showing an AUC of .863, falls slightly behind the other models in performance.
