

## 5.9 Shapley 值

可以通过假设实例的每个特征值都是“游戏”中的“玩家”，而预测是“收益”来解释预测。Shapley 值——一种来自联盟博弈论的方法——告诉我们如何公平地在特征之间分配“收益”。

### 5.9.1 总体思路

假设以下场景：

你已训练一个机器学习模型来预测公寓价格。对于某套公寓，它预测的价格为 € –300,000，你需要解释这个预测。该公寓面积为 50 m²，位于 2 楼，附近有公园，且禁止养猫：

![](img/9328bf422a53c0f374079f63527c081f_163_0.png)

图 5.43：面积为 50 m²、位于 2 楼、附近有公园且禁止养猫的公寓预测价格为 € –300,000。我们的目标是解释这些特征值中的每一个是如何对预测做出贡献的。

所有公寓的平均预测值为 € –310,000。与平均预测相比，每个特征值对预测贡献了多少？

对于线性回归模型，答案很简单。每个特征的效应是特征权重乘以特征值。这仅因模型的线性性质才成立。对于更复杂的模型，我们需要不同的解决方案。例如，LIME 建议使用局部模型来估计效应。另一个解决方案来自合作博弈论：由 Shapley (1953)42 提出的 Shapley 值，是一种根据玩家对总收益的贡献来分配收益给玩家的方法。玩家在联盟中合作，并从这种合作中获得一定的利润。

玩家？游戏？收益？这些与机器学习预测和可解释性有什么联系？“游戏”是数据集中单个实例的预测任务。“收益”是该实例的实际预测值减去所有实例的平均预测值。“玩家”是实例的特征值，它们协作以获取收益（= 预测某个值）。在我们的公寓示例中，特征值 park-nearby、cat-banned、area-50 和 floor-2nd 共同协作以实现 € –300,000 的预测。我们的目标是解释实际预测值（€ –300,000）与平均预测值（€ –310,000）之间的差异：差值为 -€ –10,000。

答案可能是：park-nearby 贡献了 € –30,000；area-50 贡献了 € –10,000；floor-2nd 贡献了 € –0；cat-banned 贡献了 -€ –50,000。贡献加总为 -€ –10,000，即最终预测值减去平均预测的公寓价格。

### 如何计算单个特征的 Shapley 值？

Shapley 值是某个特征值在所有可能联盟中的平均边际贡献。现在都清楚了吗？

在下图中，我们评估了 cat-banned 特征值在被添加到 park-nearby 和 area-50 的联盟时的贡献。我们通过从数据中随机抽取另一套公寓并使用其楼层特征值，来模拟只有 park-nearby、cat-banned 和 area-50 处于联盟中。floor-2nd 的值被随机抽取的 floor-1st 所替换。然后，我们预测该组合公寓的价格（€ –310,000）。第二步，我们通过用随机抽取公寓的猫允许/禁止特征的随机值替换 cat-banned，将其从联盟中移除。在示例中是 cat-allowed，但也可能再次是 cat-banned。我们预测 park-nearby 和 area-50 联盟的公寓价格（€ –320,000）。cat-banned 的贡献为 € –310,000 - € –320,000 = -€ –10,000。此估计值取决于作为“捐赠者”提供猫和楼层特征值的随机抽取公寓的值。如果我们重复此采样步骤并对贡献求平均，将获得更好的估计值。

![](img/9328bf422a53c0f374079f63527c081f_164_0.png)

图 5.44：在添加到 park-nearby 和 area-50 联盟时，估计 cat-banned 对预测贡献的一次采样重复。

我们对所有可能的联盟重复此计算。Shapley 值是所有可能联盟的所有边际贡献的平均值。计算时间随特征数量呈指数级增长。保持计算时间可控的一个解决方案是仅对可能联盟的少数样本计算贡献。

下图显示了确定 cat-banned 的 Shapley 值所需的所有特征值联盟。第一行显示没有任何特征值的联盟。第二、第三和第四行显示不同大小的联盟，由 "|" 分隔。总体而言，以下联盟是可能的：

- 无特征值
- park-nearby
- area-50
- floor-2nd
- park-nearby+area-50
- park-nearby+floor-2nd
- area-50+floor-2nd
- park-nearby+area-50+floor-2nd。

对于这些联盟中的每一个，我们计算有和没有 cat-banned 特征值时的预测公寓价格，并取差值得到边际贡献。Shapley 值是边际贡献的（加权）平均值。我们用公寓数据集中的随机特征值替换不在联盟中的特征的特征值，以从机器学习模型获得预测。

![](img/9328bf422a53c0f374079f63527c081f_165_0.png)

图 5.45：计算 cat-banned 特征值精确 Shapley 值所需的全部 8 个联盟。

如果我们为所有特征值估计 Shapley 值，就能得到特征值之间预测（减去平均值）的完整分布。

### 5.9.2 示例与解释

特征值 j 的 Shapley 值解释为：与数据集的平均预测相比，第 j 个特征的值对该特定实例的预测贡献了 $\phi_j$。

Shapley 值适用于分类（如果我们处理的是概率）和回归。

我们使用 Shapley 值来分析预测宫颈癌的随机森林模型的预测：

![](img/9328bf422a53c0f374079f63527c081f_165_1.png)

图 5.46：宫颈癌数据集中一名女性的 Shapley 值。预测值为 0.57，该女性的癌症概率高于平均预测值 0.03 的 0.54。已诊断的性传播疾病（STDs）数量对概率的增加影响最大。贡献之和等于实际预测与平均预测之差（0.54）。

对于自行车租赁数据集，我们也训练一个随机森林来根据天气和日历信息预测某一天租出的自行车数量。针对特定一天的随机森林预测生成的解释如下：

```
Actual prediction: 2409
Average prediction: 4518
Difference: -2108
```

![](img/9328bf422a53c0f374079f63527c081f_166_0.png)

图 5.47：第 285 天的 Shapley 值。预测租出 2409 辆自行车，这一天低于平均预测值 4518 的 -2108。天气状况和湿度产生了最大的负面贡献。当天的气温产生了正面贡献。Shapley 值之和等于实际预测与平均预测之差（-2108）。

请务必正确解释 Shapley 值：Shapley 值是某个特征值在不同联盟中对预测的平均贡献。Shapley 值 不是 从模型中移除特征时预测的差异。

### 5.9.3 Shapley 值详解

本部分深入探讨了好奇读者所需的 Shapley 值定义和计算。如果你对技术细节不感兴趣，请跳过本部分，直接前往“优势和劣势”。

我们关心每个特征如何影响数据点的预测。在线性模型中，计算个体效应很容易。以下是单个数据实例的线性模型预测形式：

```
\hat{f}(x)=\beta_0+\beta_1 x_1+\dots+\beta_p x_p
```

其中，x 是我们要计算贡献的实例。每个 x_j 是一个特征值，j = 1,...,p。\beta_j 是与特征 j 对应的权重。

第 j 个特征对预测 \hat{f}(x) 的贡献 \phi_{j,i} 为：

```
\phi_{j,i}(\hat{f})=\beta_j x_j-E(\beta_j X_j)=\beta_j x_j-\beta_j E(X_j)
```

其中，E(\beta_j X_j) 是特征 j 的平均效应估计值。贡献是特征效应减去平均效应的差值。太好了！现在我们知道每个特征对预测贡献了多少。如果对单个实例求和所有特征贡献，结果如下：
