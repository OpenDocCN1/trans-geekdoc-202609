

## 5.7 局部代理模型（LIME）

局部代理模型是用于解释黑盒机器学习模型个别预测的可解释模型。局部可解释模型-无关解释（LIME）³⁷ 是一篇论文，其中作者提出了局部代理模型的具体实现。代理模型经过训练以近似底层黑盒模型的预测。LIME 不训练全局代理模型，而是专注于训练局部代理模型以解释个别预测。

这个想法非常直观。首先，忘记训练数据，想象你只有黑盒模型，可以向其中输入数据点并获得模型预测。你可以随意探测这个黑盒。你的目标是理解机器学习模型为何做出某个预测。LIME 测试当你将数据的变体输入机器学习模型时，预测会发生什么变化。LIME 生成一个新数据集，包含扰动样本和黑盒模型对应的预测。在该新数据集上，LIME 训练一个可解释模型，该模型按采样实例与感兴趣实例的接近度进行加权。可解释模型可以是可解释模型章节中的任何模型，例如 Lasso 或决策树。学习到的模型应该在本地对机器学习模型的预测进行良好近似，但不必是良好的全局近似。这种准确性也称为局部忠实度。

从数学上讲，带有可解释性约束的局部代理模型可以表示为：

```
|\text{explanation}(x)=\arg\min_{\{g \in \{G\}\}} L(f,g,\text{pi\_x})+\Omega(g)|
```

实例 x 的解释模型是模型 g（例如线性回归模型），它最小化损失 L（例如均方误差），该损失衡量解释与原始模型 f（例如 xgboost 模型）预测的接近程度，同时保持模型复杂度（\Omega(g)）较低（例如倾向于使用更少的特征）。G 是可能解释的家族，例如所有可能的线性回归模型。接近度量（\text{pi\_x}）定义了我们为解释考虑的围绕实例 x 的邻域大小。在实践中，LIME 仅优化损失部分。用户必须确定复杂度，例如通过选择线性回归模型可以使用的最大特征数量。

训练局部代理模型的步骤：

- 选择你感兴趣的实例，即你想要解释其黑盒预测的实例。
- 扰动你的数据集并获取这些新点的黑盒预测。
- 根据新样本与感兴趣实例的接近度对其进行加权。
- 在带有变体的数据集上训练加权的可解释模型。
- 通过解释局部模型来解释预测。

在当前的 R 和 Python 实现中，例如，可以选择线性回归作为可解释代理模型。事先，你必须选择 K，即你希望在可解释模型中拥有的特征数量。K 越低，模型越容易解释。K 越高，潜在地能产生忠实度更高的模型。有几种方法可以训练恰好具有 K 个特征的模型。一个好的选择是 Lasso。具有高正则化参数（\lambda）的 Lasso 模型会产生没有任何特征的模型。通过逐个重新训练 Lasso 模型并缓慢降低（\lambda），特征会获得不等于零的权重估计。如果模型中有 K 个特征，则已达到所需的特征数量。其他策略是特征的前向或后向选择。这意味着你要么从全模型（= 包含所有特征）开始，要么从仅包含截距的模型开始，然后测试添加或删除哪个特征会带来最大改进，直到达到具有 K 个特征的模型。

如何获取数据的变体？这取决于数据类型，可以是文本、图像或表格数据。对于文本和图像，解决方案是开启或关闭单个单词或超像素。对于表格数据，LIME 通过单独扰动每个特征来创建新样本，从特征的均值和标准差所指定的正态分布中抽样。

### 5.7.1 表格数据的 LIME

表格数据是以表格形式出现的数据，每一行代表一个实例，每一列代表一个特征。LIME 样本不是围绕感兴趣的实例采样，而是从训练数据的质心采样，这存在问题。但这增加了某些样本点预测结果与感兴趣的数据点不同的概率，并且 LIME 至少可以学习到一些解释。

图 5.33：表格数据的 LIME 算法。A) 给定特征 x1 和 x2 的随机森林预测。预测类别：1（深色）或 0（浅色）。B) 感兴趣的实例（大点）和从正态分布中采样的数据（小点）。C) 对感兴趣实例附近的点分配更高权重。D) 网格的符号显示了从加权样本中局部学习模型的分类。白线标记决策边界（P(class=1) = 0.5）。

一如既往，魔鬼藏在细节中。围绕一个点定义有意义的邻域很困难。LIME 目前使用指数平滑核来定义邻域。平滑核是一个函数，它接受两个数据实例并返回一个接近度量。核宽决定邻域有多大：小核宽意味着实例必须非常接近才能影响局部模型，较大的核宽意味着较远的实例也会影响模型。如果你查看 LIME 的 Python 实现（file lime/lime/tabular.py），你会看到它使用指数平滑核（在归一化数据上），且核宽是训练数据列数平方根的 0.75 倍。这看起来像一行无害的代码，但它就像坐在你客厅里，在你祖父母给你的好瓷器旁边的一头大象。最大的问题是，我们没有好方法来找到最佳核或宽度。那 0.75 又是从哪里来的呢？在某些场景中，你可以通过更改核宽轻易地推翻你的解释，如下图所示：

图 5.34：实例 x = 1.6 预测的解释。黑盒模型依赖于单个特征的预测显示为粗线，数据分布用毯图显示。计算了三个具有不同核宽的局部代理模型。生成的线性回归模型取决于核宽：对于 x = 1.6，该特征具有负效应、正效应还是无效应？

示例中只显示了一个特征。在高维特征空间中情况会更糟。距离度量是否应该平等对待所有特征也非常不明确。特征 x1 的一个距离单位是否等同于特征 x2 的一个单位？距离度量相当任意，不同维度（即特征）的距离可能根本不可比。

#### 5.7.1.1 示例
