## 第 3 章 数据集

在本书中，所有模型和技术都应用于可在线免费获取的真实数据集。我们将针对不同任务使用不同的数据集：分类、回归和文本分类。

### 3.1 自行车租赁（回归）

该数据集包含华盛顿特区自行车租赁公司 Capital-Bikeshare 的每日租赁自行车数量，以及天气和季节信息。数据由 Capital-Bikeshare 友好地公开提供。Fanaee-T 和 Gama（2013）13 添加了天气数据和季节信息。目标是根据天气和日期预测将租出多少辆自行车。数据可从 UCI 机器学习库下载。

数据集中添加了新特征，本书示例中未使用所有原始特征。以下是使用的特征列表：

- 自行车数量（包括临时用户和注册用户）。该计数在回归任务中用作目标。
- 季节，可以是春季、夏季、秋季或冬季。
- 指示该天是否为节假日。
- 年份，可以是 2011 年或 2012 年。
- 自 01.01.2011（数据集中的第一天）以来的天数。此特征引入是为了考虑随时间的变化趋势。
- 指示该天是工作日还是周末。
- 当天的天气情况。可为以下之一：
  - 晴朗、少云、局部多云、多云
  - 雾 + 云、雾 + 破碎云、雾 + 少云、雾
  - 小雪、小雨 + 雷雨 + 散云、小雨 + 散云
  - 大雨 + 冰粒 + 雷雨 + 雾、雪 + 雾
- 摄氏温度。
- 相对湿度（百分比，0 到 100）。
- 风速（千米每小时）。

对于本书中的示例，数据经过轻微处理。处理用的 R 脚本可与最终的 RData 文件一起在本书的 Github 仓库中找到。

13. Fanaee-T, Hadi, and Joao Gama. "基于集成探测器和背景知识的事件标记." 人工智能进展. Springer Berlin Heidelberg, 1–15. doi:10.1007/s13748-013-0040-3. (2013).

### 3.3 宫颈癌风险因素（分类）

宫颈癌数据集包含用于预测女性是否会患宫颈癌的指标和风险因素。特征包括人口统计数据（如年龄）、生活方式和病史。数据可从 UCI 机器学习库下载，并由 Fernandes, Cardoso, and Fernandes（2017）15 描述。

本书示例中使用的数据特征子集为：

- 年龄（岁）
- 性伴侣数量
- 首次性交（年龄，岁）
- 怀孕次数
- 是否吸烟
- 吸烟年限（年）
- 是否使用激素避孕药
- 使用激素避孕药年限（年）
- 是否使用宫内节育器（IUD）
- 使用宫内节育器年限（年）（IUD）
- 患者是否曾患性传播疾病（STD）
- 性传播疾病诊断次数
- 首次性传播疾病诊断以来的时间
- 最近一次性传播疾病诊断以来的时间
- 活检结果："健康" 或 "癌症"。目标结果。

活检是诊断宫颈癌的金标准。对于本书中的示例，活检结果被用作目标。每列的缺失值通过众数（最常见的值）进行填补，这可能是一个糟糕的解决方案，因为真实答案可能与值缺失的概率相关。由于问题涉及非常私密的性质，可能存在偏差。但这不是一本关于缺失值填补的书，因此众数填补对于示例来说将不得不凑合使用。

要使用此数据集复制本书中的示例，请在本书的 Github 仓库中查找预处理 R 脚本和最终 RData 文件。

## 第 4 章 可解释模型

实现可解释性的最简单方法是仅使用创建可解释模型的算法子集。线性回归、逻辑回归和决策树是常用的可解释模型。

在接下来的章节中，我们将讨论这些模型。不会详细介绍，只讲基础，因为已经有大量书籍、视频、教程、论文和其他材料可用。我们将专注于如何解释模型。本书更详细地讨论了线性回归、逻辑回归、其他线性回归扩展、决策树、决策规则和 RuleFit 算法。它还列出了其他可解释模型。

本书解释的所有可解释模型都在模块级别可解释，k-最近邻方法除外。下表概述了可解释模型类型及其属性。如果特征与目标之间的关联是线性建模的，则该模型为线性模型。具有单调性约束的模型确保特征与目标结果之间的关系在特征的整个范围内始终朝同一方向发展：特征值的增加要么始终导致目标结果的增加，要么始终导致目标结果的减少。单调性对于模型解释很有用，因为它使关系更容易理解。一些模型可以自动包含特征之间的交互来预测目标结果。您可以通过手动创建交互特征，在任何类型的模型中包含交互。交互可以提高预测性能，但过多或过于复杂的交互会损害可解释性。有些模型仅处理回归，有些仅处理分类，还有些则两者都处理。

根据此表，您可以为任务选择合适的可解释模型，可以是回归（regr）或分类（class）：

| 算法 | 线性 | 单调 | 交互 | 任务 |
|---|---|---|---|---|
| 线性回归 | 是 | 是 | 否 | regr |
| 逻辑回归 | 否 | 是 | 否 | class |
| 决策树 | 否 | 部分 | 是 | class, regr |
| RuleFit | 是 | 否 | 是 | class, regr |
| 朴素贝叶斯 | 否 | 是 | 否 | class |
| k-最近邻 | 否 | 否 | 否 | class, regr |
