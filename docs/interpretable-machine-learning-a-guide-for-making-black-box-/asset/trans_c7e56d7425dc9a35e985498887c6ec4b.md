## 5.6 全局代理

全局代理模型是一种可解释模型，经过训练用于近似黑盒模型的预测。我们可以通过解释代理模型来对黑盒模型得出结论。通过使用更多机器学习来解决机器学习可解释性问题！

### 5.6.1 理论

工程中也使用代理模型：如果感兴趣的结果昂贵、耗时或以其他方式难以测量（例如，因为它来自复杂的计算机仿真），可以改用该结果的廉价快速代理模型。工程中使用的代理模型与可解释机器学习中使用的代理模型之间的区别在于，底层模型是机器学习模型（而不是仿真），且代理模型必须是可解释的。（可解释）代理模型的目的是尽可能准确地近似底层模型的预测，同时保持可解释性。代理模型的概念可以以不同名称找到：近似模型、元模型、响应面模型、仿真器、……

关于理论：实际上，理解代理模型不需要太多理论。我们希望在 g 可解释的约束下，用代理模型预测函数 g 尽可能紧密地近似我们的黑盒预测函数 f。对于函数 g，可以使用任何可解释模型——例如来自可解释模型章节的模型。

例如线性模型：

```
[g(x) = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p]
```

或决策树：

```
[g(x) = \sum_{m=1}^M c_m I\{x \in R_m\}]
```

训练代理模型是一种与模型无关的方法，因为它不需要任何关于黑盒模型内部工作原理的信息，只需要访问数据和预测函数。如果底层机器学习模型被另一个替换，你仍然可以使用代理方法。黑盒模型类型和代理模型类型的选择是解耦的。

要获得代理模型，请执行以下步骤：

- 1. 选择数据集 X。这可以是用于训练黑盒模型的同一数据集，也可以来自相同分布的新数据集。你甚至可以根据应用程序选择数据的子集或点网格。
- 2. 对于所选数据集 X，获取黑盒模型的预测。
- 3. 选择可解释模型类型（线性模型、决策树、……）。
- 4. 在数据集 X 及其预测上训练可解释模型。
- 5. 恭喜！你现在有了一个代理模型。
- 6. 衡量代理模型在多大程度上复制了黑盒模型的预测。
- 7. 解释代理模型。

你可能会发现一些代理模型方法有额外步骤或略有不同，但大体思路通常如这里所述。

衡量代理模型多大程度复制黑盒模型的一种方法是 R 平方度量：

```
[R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{\sum_{i=1}^n (\hat{y}_i - \hat{y})^2}{\sum_{i=1}^n (\hat{y}_i - \bar{\hat{y}})^2}]
```

其中，$\hat{y}_{-(i)}$ 是代理模型第 i 个实例的预测，$\hat{y}^{(i)}$ 是黑盒模型的预测，$\bar{\hat{y}}$ 是黑盒模型预测的均值。SSE 代表误差平方和，SST 代表总平方和。R 平方度量可以解释为代理模型捕获的方差百分比。如果 R 平方接近 1（= 低 SSE），则可解释模型很好地近似了黑盒模型的行为。如果可解释模型非常接近，你可能希望用可解释模型替换复杂模型。如果 R 平方接近 0（= 高 SSE），则可解释模型无法解释黑盒模型。

请注意，我们尚未讨论底层黑盒模型的模型性能，即它在预测实际结果时表现好坏。黑盒模型的性能在训练代理模型中不起作用。代理模型的解释仍然有效，因为它对模型而不是现实世界发表声明。但当然，如果黑盒模型较差，则代理模型的解释就无关紧要了，因为黑盒模型本身就无关紧要了。

我们也可以基于原始数据的子集构建代理模型，或重新加权实例。这样，我们改变了代理模型输入的分布，从而改变了解释的焦点（此时它不再真正全局）。如果我们按特定数据实例局部加权数据（实例越接近所选实例，权重越高），我们就得到一个局部代理模型，可以解释该实例的个别预测。有关局部模型的更多信息，请阅读下一章。

### 5.6.2 示例

为了演示代理模型，我们考虑一个回归示例和一个分类示例。

首先，我们训练一个支持向量机，根据天气和日历信息预测每天租借的自行车数量。支持向量机可解释性不高，因此我们使用 CART 决策树作为可解释模型来训练一个代理模型，以近似支持向量机的行为。

在第二个示例中，我们使用随机森林预测宫颈癌的概率。我们再次使用原始数据集训练决策树，但将随机森林的预测作为结果，而不是数据中的实际类别（健康 vs. 癌症）。

### 5.6.3 优势

代理模型方法是 **灵活的**：可解释模型章节中的任何模型都可以使用。这也意味着你不仅可以替换可解释模型，还可以替换底层黑盒模型。假设你创建了某个复杂模型，并向公司不同团队解释它。一个团队熟悉线性模型，另一个团队可以理解决策树。你可以针对原始黑盒模型训练两个代理模型（线性模型和决策树），并提供两种解释。如果你发现了性能更好的黑盒模型，则不必更改解释方法，因为你可以使用同一类代理模型。

我认为该方法非常 **直观** 且简单直接。这意味着它易于实现，也易于向不熟悉数据科学或机器学习的人解释。

借助 **R 平方度量**，我们可以轻松衡量代理模型近似黑盒预测的效果。

### 5.6.4 劣势

你必须意识到，你得出的是 **关于模型而非数据的结论**，因为代理模型从未看到实际结果。

目前不清楚最佳的 **R 平方截断值** 是多少，才能确信代理模型足够接近黑盒模型。解释方差 80%？50%？99%？

我们可以衡量代理模型与黑盒模型的接近程度。假设我们不够接近，但足够接近。可能发生这样的情况：可解释模型在 **一个数据子集上非常接近，但在另一个子集上差异很大**。在这种情况下，简单模型的解释对所有数据点都不一样好。

你作为代理模型选择的可解释模型 **带有其所有优势和劣势**。

有些人认为，总的来说，**不存在固有可解释的模型**（甚至包括线性模型和决策树），并且拥有可解释性的幻想甚至可能很危险。如果你持有此观点，那么当然这种方法不适合你。

### 5.6.5 软件

示例中我使用了 `iml` R 包。如果你能训练机器学习模型，那么你应该能够自己实现代理模型。只需训练一个可解释模型来预测黑盒模型的预测即可。
