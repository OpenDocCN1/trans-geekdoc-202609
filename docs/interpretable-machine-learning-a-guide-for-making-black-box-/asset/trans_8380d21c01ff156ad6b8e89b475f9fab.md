## 4.5 决策规则

决策规则是一个简单的 IF-THEN 语句，由一个条件（也称为前件）和一个预测组成。例如：IF 今天下雨 并且 是四月（条件），THEN 明天会下雨（预测）。单个决策规则或多个规则的组合可用于进行预测。

决策规则遵循一般结构：IF 满足条件 THEN 进行某个特定预测。决策规则可能是最可解释的预测模型。它们的 IF-THEN 结构在语义上类似于自然语言和我们的思维方式，前提是条件由可理解的特征构成，条件的长度较短（少数特征=值对通过 AND 组合），且规则数量不多。在编程中，编写 IF-THEN 规则非常自然。机器学习中新的地方在于，决策规则是通过算法学习得来的。

想象使用算法来学习预测房子价值（低、中或高）的决策规则。该模型学习到的一个决策规则可能是：如果房子面积大于 100 平方米且有花园，则其价值为高。更正式地表述：IF size>100 AND garden=1 THEN value=high。

让我们拆解一下这个决策规则：

- size>100 是 IF 部分的第一个条件。
- garden=1 是 IF 部分的第二个条件。
- 这两个条件通过 'AND' 连接以创建一个新条件。两个条件都必须为真，规则才能适用。
- 预测结果（THEN 部分）是 value=high。

一个决策规则在条件中至少使用一个特征=值语句，通过 'AND' 添加更多语句没有上限。一个例外是默认规则，它没有显式的 IF 部分，并在没有其他规则适用时生效，但关于这一点稍后详细说明。

决策规则的有用性通常用两个数字来概括：支持度和准确度。

**规则的支持度或覆盖度**：规则条件适用的实例百分比称为支持度。以预测房子价值的规则 size=big AND location=good THEN value=high 为例。假设 1000 栋房子中有 100 栋面积大且位置好，则该规则的支持度为 10%。预测（THEN 部分）对支持度的计算不重要。

**规则的准确度或置信度**：规则的准确度是衡量规则对适用条件的实例预测正确类别的准确程度的指标。例如：假设在适用规则 size=big AND location=good THEN value=high 的 100 栋房子中，85 栋价值为 high，14 栋价值为 medium，1 栋价值为 low，则该规则的准确度为 85%。

通常准确度和支持度之间存在权衡：通过向条件添加更多特征，可以获得更高的准确度，但会损失支持度。

要创建一个用于预测房子价值的良好分类器，你可能需要学习不仅仅一条规则，而是也许 10 条或 20 条规则。那么事情可能会变得更复杂，你可能会遇到以下问题之一：

- 规则可能重叠：如果我想预测房子的价值，且有两条或更多规则适用，但它们给出了相互矛盾的预测，该怎么办？
- 没有规则适用：如果我想预测房子的价值，但没有任何规则适用，该怎么办？

组合多个规则有两种主要策略：决策列表（有序）和决策集合（无序）。这两种策略对重叠规则问题有不同的解决方案。

决策列表为决策规则引入了顺序。如果第一条规则的条件对某个实例为真，则我们使用第一条规则的预测。如果不为真，则转到下一条规则并检查它是否适用，依此类推。决策列表通过仅返回列表中适用的第一条规则的预测来解决重叠规则问题。

决策集合类似于规则的民主，只是有些规则可能拥有更高的投票权。在一个集合中，规则要么是互斥的，要么有解决冲突的策略，例如多数投票，该策略可以由单个规则的准确度或其他质量指标加权。当多个规则适用时，可解释性可能会受到影响。

决策列表和集合都可能遇到没有规则适用于某个实例的问题。这可以通过引入默认规则来解决。默认规则是在没有其他规则适用时生效的规则。默认规则的预测通常是未被其他规则覆盖的数据点中出现频率最高的类别。如果一组或一系列规则覆盖了整个特征空间，我们称之为 exhaustive。通过添加默认规则，一组或列表自动变为 exhaustive。

从数据中学习规则有很多种方法，而本书远未涵盖所有方法。本章向你展示其中三种。这些算法被选为涵盖学习规则的广泛一般性思路，因此这三种算法都代表了非常不同的方法。

- 1. OneR 从单个特征学习规则。OneR 的特点是其简单性、可解释性及其作为基准的用途。
- 2. 顺序覆盖是一种通用过程，它迭代地学习规则并删除被新规则覆盖的数据点。许多规则学习算法使用此过程。
- 3. 贝叶斯规则列表使用贝叶斯统计将预挖掘的频繁模式组合成决策列表。使用预挖掘模式是许多规则学习算法使用的常见方法。

让我们从最简单的方法开始：使用单个最佳特征来学习规则。

### 4.5.1 从单个特征学习规则 (OneR)

Holte (1993) 提出的 OneR 算法是最简单的规则诱导算法之一。从所有特征中，OneR 选择携带关于感兴趣结果最多信息的特征，并从该特征创建决策规则。

尽管名为 OneR，代表 "One Rule"，但该算法生成的规则不止一条：它实际上是为所选最佳特征的每个唯一特征值生成一条规则。更好的名称可能是 OneFeatureRules。

该算法简单且快速：

- 1. 通过选择适当的区间将连续特征离散化。
- 2. 对于每个特征：
  - 创建特征值与（分类）结果之间的交叉表。
  - 对于特征的每个值，创建一条规则，预测具有该特定特征值的实例中最常见的类别（可从交叉表中读取）。
  - 计算该特征规则的总误差。
- 3. 选择总误差最小的特征。

OneR 始终覆盖数据集的所有实例，因为它使用所选特征的所有级别。缺失值可以被视为额外的特征值，也可以事先填补。

OneR 模型是只有一个分割的决策树。分割不一定像 CART 那样是二进制的，而是取决于唯一特征值的数量。

让我们看一个 OneR 如何选择最佳特征的示例。下表显示了一个关于房屋的人造数据集，包含其价值、位置、大小以及是否允许宠物的信息。我们有兴趣学习一个简单模型来预测房子的价值。

| 位置 | 大小 | 宠物 | 价值 |
|---|---|---|---|
| 良好 | 小 | 是 | 高 |
| 良好 | 大 | 否 | 高 |
| 良好 | 大 | 否 | 高 |
| 差 | 中等 | 否 | 中等 |
| 良好 | 中等 | 仅允许猫 | 中等 |
| 良好 | 小 | 仅允许猫 | 中等 |
| 差 | 中等 | 是 | 中等 |
| 差 | 小 | 是 | 低 |
| 差 | 中等 | 是 | 低 |
| 差 | 小 | 否 | 低 |

OneR 在每个特征与结果之间创建交叉表：

| | value=低 | value=中等 | value=高 |
|---|---|---|---|
| 位置=差 | 3 | 2 | 0 |
| 位置=良好 | 0 | 2 | 3 |

| | value=低 | value=中等 | value=高 |
|---|---|---|---|
| size=大 | 0 | 0 | 2 |
| size=中等 | 1 | 3 | 0 |
| size=小 | 2 | 1 | 1 |

| | value=低 | value=中等 | value=高 |
|---|---|---|---|
| pets=否 | 1 | 1 | 2 |
| pets=仅允许猫 | 0 | 2 | 0 |
| pets=是 | 2 | 1 | 1 |

对于每个特征，我们逐行查看表格：每个特征值是规则的 IF 部分；具有该特征值的实例中最常见的类别是预测，即规则的 THEN 部分。例如，具有 small、medium 和 big 级别的 size 特征会产生三条规则。对于每个特征，我们计算生成规则的总误差率，即误差之和。location 特征的可能值为 bad 和 good。位置差的房子中最常见的值是 low，当我们使用 low 作为预测时，会犯两个错误，因为有两栋房子价值为 medium。位置好的房子预测值为 high，同样犯了两个错误，因为有两栋房子价值为 medium。使用 location 特征的错误率为 4/10，size 特征为 3/10，宠物特征为 4/10。size 特征产生误差最低的规则，将用于最终的 OneR 模型：

```
IF size=small THEN value=low
IF size=medium THEN value=medium
IF size=big THEN value=high
```

OneR 偏好具有许多可能级别的特征，因为那些特征更容易过拟合目标。想象一个仅包含噪声而不包含信号的数据集，这意味着所有特征都取随机值，对目标没有预测价值。有些特征的级别比其他特征多。级别更多的特征现在可以更容易地过拟合。为数据中的每个实例都有单独级别的特征将完美预测整个训练数据集。一个解决方案是将数据分为训练集和验证集，在训练数据上学习规则，并在验证集上评估选择特征的总误差。

平局是另一个问题，即当两个特征导致相同的总误差时。OneR 通过要么选择误差最低的第一个特征，要么选择卡方检验 p 值最低的特征来解决平局。
