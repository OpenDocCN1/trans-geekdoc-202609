## 第 7 章 神经网络解释

本章目前仅在此 Web 版本中提供。电子书和印刷版将随后推出。

以下章节侧重于神经网络的解释方法。这些方法可视化神经网络学习到的特征和概念，解释单个预测并简化神经网络。

深度学习非常成功，尤其是在涉及图像和文本的任务中，例如图像分类和语言翻译。深度神经网络的成功故事始于 2012 年，当时 ImageNet 图像分类挑战<sup>74</sup> 由深度学习方法获胜。从那以后，我们目睹了深度神经网络架构的寒武纪大爆发，趋势是朝着更深、拥有越来越多权重参数的网络发展。

要使用神经网络进行预测，数据输入会经过许多层与学习到的权重相乘，并经过非线性变换。单个预测可能涉及数百万个数学运算，具体取决于神经网络的架构。我们人类不可能跟踪从数据输入到预测的确切映射。我们需要考虑数以百万计以复杂方式相互作用的权重，才能理解神经网络的预测。为了解释神经网络的行为和预测，我们需要特定的解释方法。这些章节假设您熟悉深度学习，包括卷积神经网络。

我们当然可以使用与模型无关的方法，例如局部模型或部分依赖图，但有两个理由说明考虑专门为神经网络开发的解释方法是有意义的：首先，神经网络在其隐藏层中学习特征和概念，我们需要专门的工具来揭示它们。其次，可以利用梯度来实现比从"外部"审视模型的与模型无关的解释方法更具计算效率的解释方法。此外，本书中大多数其他方法旨在解释表格数据的模型。图像和文本数据需要不同的方法。

- **特征可视化**：神经网络学习了哪些特征？基于示例的解释章节中的**对抗样本**与特征可视化密切相关：我们如何操纵输入以获得错误的分类？
- **概念**（进行中）：神经网络学习了哪些更抽象的概念？

- **模型蒸馏**（进行中）：我们如何用更简单的模型来解释神经网络？

### 7.1 学习到的特征

卷积神经网络从原始图像像素中学习抽象特征和概念。特征可视化通过激活最大化来可视化学习到的特征。网络解剖使用人类概念为神经网络单元（例如通道）贴标签。

深度神经网络在隐藏层中学习高级特征。这是它们最大的优势之一，并减少了对特征工程的需求。假设您想使用支持向量机构建图像分类器。原始像素矩阵不是训练 SVM 的最佳输入，因此您会根据颜色、频率域、边缘检测器等创建新特征。使用卷积神经网络时，图像以其原始形式（像素）输入网络。网络多次转换图像。首先，图像经过许多卷积层。在这些卷积层中，网络在其层中学习新的且越来越复杂的特征。然后，转换后的图像信息经过全连接层并转变为分类或预测。

#### 7.1.1 特征可视化

将学习到的特征显式化的方法称为特征可视化。神经网络单元的特征可视化是通过找到最大化该单元激活的输入来完成的。

"单元"是指单个神经元、通道（也称为特征图）、整个层或分类中的最终类概率（或相应的 pre-softmax 神经元，推荐使用）。单个神经元是网络的原子单位，因此为每个神经元创建特征可视化将获得最多信息。但有一个问题：神经网络通常包含数百万个神经元。查看每个神经元的特征可视化将花费太长时间。通道（有时称为激活图）作为单元是特征可视化的不错选择。我们可以更进一步，可视化整个卷积层。将层作为单元用于 Google 的 DeepDream，它会反复将一层的可视化特征添加到原始图像中，从而得到输入的类似梦境的版本。

##### 7.1.1.1 通过优化实现特征可视化

从数学角度来看，特征可视化是一个优化问题。我们假设神经网络的权重是固定的，这意味着网络已经训练。我们正在寻找一张新图像，以最大化单元（此处为单个神经元）的（平均）激活：

```
\img^*=\arg\max_{\{img\}}h_{\{n.x,y,z\}}(img)
```

函数 h() 是神经元的激活，_img_ 是网络的输入（一张图像），x 和 y 描述神经元的空间位置，n 指定层，z 是通道索引。对于层 n 中整个通道 z 的平均激活，我们最大化：

```
\img^*=\arg\max_{\{img\}}\sum_{\{x,y\}}h_{\{n.x,y,z\}}(img)
```

在这个公式中，通道 z 中的所有神经元都具有相同的权重。或者，您也可以最大化随机方向，这意味着神经元将被不同的参数（包括负方向）相乘。通过这种方式，我们研究神经元在通道内的相互作用。您还可以最小化激活（这相当于最大化负方向），而不是最大化激活。有趣的是，当您最大化负方向时，您会为同一单元获得非常不同的特征：
