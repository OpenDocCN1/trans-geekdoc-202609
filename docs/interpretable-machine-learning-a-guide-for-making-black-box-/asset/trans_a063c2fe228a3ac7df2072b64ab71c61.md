

## 5.8 受限规则（锚点）

作者：Tobias Goerke & Magdalena Lang

*本章目前仅在此 Web 版本中提供。电子书和印刷版将随后推出。*

Anchors 通过寻找能够充分“锚定”预测的决策规则，来解释任何黑盒分类模型的单个预测。如果其他特征值的变化不影响预测，则称一条规则锚定了该预测。Anchors 将强化学习技术与图搜索算法相结合，将模型调用次数（以及因此所需的运行时间）降至最低，同时仍能从局部最优中恢复。Ribeiro、Singh 和 Guestrin 于 2018 年提出了该算法⁴⁰——正是引入 LIME 算法的同一批研究人员。

与它的前身类似，Anchors 方法采用基于扰动的策略，为黑盒机器学习模型的预测生成局部解释。然而，不同于 LIME 使用的代理模型，得到的解释被表示为易于理解的 IF-THEN 规则，即锚点。这些规则是可重用的，因为它们具有作用域：锚点包含覆盖率的概念，精确说明它们适用于哪些其他（可能未见过）的实例。寻找锚点涉及一种探索或多臂老虎机问题，起源于强化学习领域。为此，对每个待解释的实例都会创建并评估邻居或扰动。这样做使该方法能够忽略黑盒的结构及其内部参数，从而使这些参数既不被观察也不被改变。因此，该算法是与模型无关的，意味着它可以应用于任何类别的模型。

在他们的论文中，作者对比了这两种算法，并可视化它们如何不同地查询实例的邻域以得出结果。为此，下图描绘了 LIME 和锚点如何使用两个示例实例在本地解释一个复杂的二元分类器（预测 - 或 +）。LIME 的结果并未指示其忠实度，因为 LIME 仅学习一个线性决策边界，在给定的扰动空间（D）下最佳逼近模型。在相同的扰动空间下，锚点方法构建的解释其覆盖率适应于模型的行为，并清晰地表达其边界。因此，它们在设计上即忠实，并精确说明对哪些实例有效。这一特性使得锚点尤其直观且易于理解。

如前所述，该算法的结果或解释以规则的形式出现，称为锚点。下面的简单示例说明了这样的锚点。例如，假设我们有一个双变量黑盒模型，用于预测乘客是否在泰坦尼克号灾难中幸存。现在我们想知道，模型为什么预测某个特定个体会幸存。锚点算法提供如下所示的结果解释。

### 一个示例个体及其模型预测

| 特征 | 值 |
|---|---|
| 年龄 | 20 |
| 性别 | female |
| 船舱等级 | first |
| 票价 | 300$ |
| 更多属性 | ... |
| 是否幸存 | true |

对应的锚点解释如下：

```
IF SEX = female
AND Class = first
THEN PREDICT Survived = true
WITH PRECISION 97%
AND COVERAGE 15%
```

该示例展示了锚点如何为模型的预测及其背后的推理提供关键洞察。结果显示模型考虑了哪些属性，在此例中为女性性别和头等舱。作为正确性至关重要的人类，可以使用这条规则来验证模型的行为。锚点还告诉我们，它适用于扰动空间中 15% 的实例。在这些情况下，解释的准确率为 97%，这意味着显示的谓词几乎完全对预测结果负责。

一个锚点 \A\ 的形式定义如下：

```
\mathbb{E}\{_\{D_x(z|A)[1_{\{f(x)=f(z)\}}]\leq\tau,A(x)=1
```

其中：

- \x\ 表示待解释的实例（例如，表格数据集中的一行）。
- \A\ 是一组谓词，即生成的规则或锚点，当 \A\ 定义的所有特征谓词都与 \x\ 的特征值对应时，\A(x)=1\ 成立。
- \f\ 表示待解释的分类模型（例如，人工神经网络模型）。它可以被查询来为 \x\ 及其扰动预测标签。
- \D_x (\cdot|\cdot|\text{otl}A))\ 表示与 \A\ 匹配的 \x\ 的邻居的分布。
- \0 \leq \tau \leq 1\ 指定一个精度阈值。只有达到至少 \tau\ 的局部忠实度的规则才被视为有效结果。

形式描述可能令人生畏，可以用文字表述如下：

> 给定一个待解释的实例 \x\，需要找到一条规则或锚点 \A\，使其适用于 \x\，同时对于至少 \tau\ 的 \x\ 的邻居（其中相同的 \A\ 适用），预测的类别与 \x\ 相同。规则的精度是通过使用提供的机器学习模型（由指示函数 \1_{\{f(x) = f(z)\}} 表示）来评估邻居或扰动（遵循 \D_x (z|\text{lot}A)）得出的。

### 5.8.1 寻找锚点

尽管锚点的数学描述看起来清晰明了，但构建特定规则在可行性上不成立。这将需要对所有 \(z \in \text{mathcal}\{D_x(\cdot|\text{odt}A\) 评估 \1_{\{f(x) = f(z)\}}，在连续或大型输入空间中这是不可能的。因此，作者提议引入参数 \0 \leq \delta \leq 1\ 来创建一个概率定义。这样，就可以抽取样本，直到对其精度有统计置信度为止。概率定义如下：

```
\text{P}(\text{prec}(\text{A})\geq\tau)\geq \{ 1-\delta \quad \textrm{with} \quad \text{prec}(\text{A})=\mathbb{E}\{_\{D_x(z|A)[1_{\{f(x)=f(z)\}]
```

前两个定义被合并并扩展了覆盖率的概念。其原理在于找到适用于模型输入空间尽可能大一部分的规则。覆盖率被正式定义为锚点适用于其邻居（即其扰动空间）的概率：

```
\[cov(A)=\mathrm{mathbb}\{E\}_{\_\_\{\mathrm{mathbbcal}\{D\}_{\_\_\{\{z\}\}[\mathrm{A}(z)]\}\]\]
```

包含此元素后，导出了考虑覆盖率最大化的锚点最终定义：

```
\[\underline{set}\{A\backslash:\texttrm\{s.t.\}\}:\mathrm{P}(\mathrm{prec}(\mathrm{A})\ge\mathrm{eq}\{\mathrm{tau}\})\ge\mathrm{eq}\{\{1-\mathrm{delta}\}\{\backslash\mathrm{texttrm}\{\mathrm{max}\}\}\mathrm{cov}(\mathrm{A})\}\]\]
```

因此，该过程力求在所有合格规则（即满足概率定义下精度阈值的所有规则）中找到覆盖率最高的规则。这些规则被认为更重要，因为它们描述了模型更大的一部分。需要注意的是，谓词更多的规则往往比谓词更少的规则具有更高的精度。特别是，一条固定 \(x\) 的每个特征的规则将评估的邻域减少到相同的实例。因此，模型会将所有邻居分为同一类，规则的精度为 \(1\) (\(1\))。同时，一条固定许多特征的规则过于具体，仅适用于少数实例。因此，存在 *精度与覆盖率之间的权衡*。

锚点方法使用四个主要组件来寻找解释，如下图所示。

**候选生成**：生成新的解释候选项。在第一轮中，为 \(x\) 的每个特征创建一个候选项，并固定可能扰动的相应值。在每个后续轮次中，将上一轮的最佳候选项扩展一个尚未包含的特征谓词。

**最佳候选识别**：需要比较候选规则，看哪条规则最能解释 \(x\)。为此，会创建与当前观察到的规则匹配的扰动，并通过调用模型进行评估。然而，这些调用需要被最小化以限制计算开销。这就是为什么该组件的核心是一个纯探索型多臂老虎机（\(MAB\)；*KL-LUCB\(^\dagger\)*，准确地说）。MABs 被用来通过顺序选择高效地探索和利用不同的策略（类比于老虎机中的拉杆）。在给定的设置中，每个候选规则都被视为一个可以拉动的拉杆。每次拉动时，相应的邻居会被评估，从而我们获得更多关于候选规则回报（在锚点的情况中为精度）的信息。因此，精度说明了规则描述待解释实例的程度。

**候选精度验证**：如果尚未有统计置信度表明候选项超过 \(\tau(\tau)\) 阈值，则获取更多样本。

**修改后的束搜索**：上述所有组件都组装在一个束搜索中，这是一种图搜索算法，也是广度优先算法的变体。它将每一轮的 \(B\) 个最佳候选项带到下一轮（其中 \(B\) 称为 *束宽*）。然后，用这些 \(B\) 个最佳规则来创建新规则。束搜索最多进行 \(featureCount(x)\) 轮，因为每个特征在规则中最多只能包含一次。因此，在每一轮 \(i\) 中，它生成恰好包含 \(i\) 个谓词的候选项，并从中选出 B 个最佳的。因此，通过设置较高的 \(B\)，算法更有可能避免局部最优。反过来，这需要大量的模型调用，从而增加了计算负载。
