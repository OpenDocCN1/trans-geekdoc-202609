

从优点来看，逻辑回归模型不仅是一个分类模型，还能给出概率。
相比于只能提供最终分类结果的模型，这是一个巨大的优势。知道一个实例属于某个类别的概率是 99% 而非 51%，这有着巨大的不同。

逻辑回归也可以从二分类扩展到多类分类。这时它被称为多项回归。

## 4.3 GLM、GAM 及其他

线性回归模型最大的优势同时也是最大的劣势在于：预测被建模为特征的加权和。此外，线性模型还带有许多其他假设。坏消息是（嗯，其实也不算新闻）这些假设在现实中常常被违背：给定特征下的结果可能服从非高斯分布，特征之间可能存在交互作用，特征与结果之间的关系可能是非线性的。好消息是，统计学界已经开发出多种修改方法，将线性回归模型从一把简单的刀变成了一把瑞士军刀。

本章绝非扩展线性模型的权威指南。相反，它旨在概述广义线性模型（GLM）和广义加性模型（GAM）等扩展内容，并为您提供一点直觉。阅读后，您应当对如何扩展线性模型有一个扎实的概览。如果您想先了解更多关于线性回归模型的内容，且尚未阅读过，我建议您阅读线性回归模型那一章。

让我们回顾一下线性回归模型的公式：

```
y = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p + \epsilon
```

线性回归模型假设，实例的结果 y 可以表示为其 p 个特征的加权和，并带有一个服从高斯分布的单独误差项（\epsilon）。通过将数据强行套入这个公式的束带中，我们获得了大量的模型可解释性。特征效应是可加的，即不存在交互作用，且关系是线性的，即某特征每增加一个单位，就可以直接转化为预测结果的增加或减少。线性模型使我们能够将特征与预期结果之间的关系压缩为一个数字，即估计权重。

但简单的加权和对许多现实世界的预测问题来说过于局限。在本章中，我们将了解经典线性回归模型的三个问题以及如何解决它们。还有许多其他可能违反假设的问题，但我们将关注下图所示的三个问题：

![](img/9328bf422a53c0f374079f63527c081f_55_0.png)

图 4.8：线性模型的三个假设（左侧）：给定特征下结果的高斯分布、可加性（即无交互作用）以及线性关系。现实通常不遵循这些假设（右侧）：结果可能服从非高斯分布，特征可能存在交互作用，且关系可能是非线性的。

所有这些问题都有解决方案：

- **问题**：给定特征下的目标结果 y 不服从高斯分布。
- **示例**：假设我想预测某一天我会骑自行车多少分钟。作为特征，我有天气类型、天气等等。如果我使用线性模型，它可能会预测出负分钟数，因为它假设高斯分布不会在 0 分钟处停止。此外，如果我希望用线性模型预测概率，我可能会得到负概率或大于 1 的概率。
- **解决方案**：广义线性模型（GLM）。

- **问题**：特征存在交互作用。
- **示例**：平均而言，小雨对我骑行意愿有轻微的负面影响。但在夏季高峰时段，我欢迎下雨，因为那时所有晴天骑行者都待在家里，自行车道就归我一个人了！这是时间与天气之间的交互作用，纯可加模型无法捕捉这一点。
- **解决方案**：手动添加交互项。

- **问题**：特征与 y 之间的真实关系不是线性的。
- **示例**：在 0 到 25 摄氏度之间，温度对我骑行意愿的影响可能是线性的，这意味着从 0 度升到 1 度引起的骑行意愿增加，与从 20 度升到 21 度引起的增加相同。但在更高温度下，我的骑行动力会趋于平缓甚至下降——我不喜欢在太热的时候骑车。
- **解决方案**：广义加性模型（GAM）：特征转换。

本章介绍了这三个问题的解决方案。线性模型的许多其他扩展已被省略。如果我试图在这里面面俱到，本章就会迅速变成一本关于已经在许多其他书籍中有所涉及的话题的“书中之书”。但既然您已经来到这里，我为线性模型扩展制作了一个小问题加解决方案概览，您可以在本章末尾找到它。解决方案的名称旨在作为搜索的起点。

### 4.3.1 非高斯结果 - GLM

线性回归模型假设，给定输入特征下的结果服从高斯分布。这一假设排除了许多情况：结果也可以是一个类别（癌症 vs. 健康）、一个计数（子女数量）、事件发生的时间（机器故障时间），或者是一个具有少数极高值的高度偏态结果（家庭收入）。线性回归模型可以扩展以建模所有这些类型的结果。这种扩展称为**广义线性模型**，简称 **GLM**。在整个章节中，我将使用 GLM 来指代这个通用框架及其框架中的特定模型。任何 GLM 的核心概念是：保留特征的加权和，但允许非高斯结果分布，并通过一个可能是非线性的函数将该分布的预期均值与加权相连接。例如，逻辑回归模型假设结果服从伯努利分布，并使用逻辑函数将预期均值与加权相连接。

```
g(E_Y(y|x)) = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p
```

GLM 由三个部分组成：链接函数 g、加权和 X^T\beta（有时称为线性预测器）以及来自指数族的概率分布（定义 E_Y）。

指数族是一组分布，可以用相同的（参数化）公式来表示，该公式包含一个指数、分布的均值和方差以及其他一些参数。我不会深入数学细节，因为这是一个非常庞大的独立领域，我不想涉足其中。Wikipedia 上有指数族分布的整洁列表。列表中的任何分布都可以用于您的 GLM。根据您想要预测的结果类型，选择合适的分布。结果是某物的计数吗（例如，家庭中居住的儿童数量）？那么泊松分布可能是一个不错的选择。结果总是正数吗（例如，两个事件之间的时间）？那么指数分布可能是一个不错的选择。

让我们将经典线性模型视为 GLM 的一个特例。经典线性模型中高斯分布的链接函数就是恒等函数。高斯分布由均值和方差参数化。均值描述我们平均期望的值，方差描述数值围绕该均值变化的程度。在线性模型中，链接函数将特征的加权和与高斯分布的均值相连接。

在 GLM 框架下，这一概念推广到任何分布（来自指数族）和任意链接函数。如果 y 是某物的计数，例如某人在特定一天喝的咖啡数量，我们可以使用泊松分布和自然对数作为链接函数的 GLM 来对其进行建模：

```
\ln(E_Y(y|x)) = x^T \beta
```

逻辑回归模型也是一种 GLM，它假设伯努利分布，并使用 logit 函数作为链接函数。逻辑回归中使用的二项分布的均值是 y 为 1 的概率。

```
x^T\beta = \ln\left(\frac{...}{...}\right)
```

如果我们求解这个方程使 P(y=1) 在一侧，就得到逻辑回归公式：

```
P(y=1) = \frac{1}{1+\exp(-x^T\beta)}
```
