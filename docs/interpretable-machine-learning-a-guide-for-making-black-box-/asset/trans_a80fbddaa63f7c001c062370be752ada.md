## 5.4 特征交互

当预测模型中的特征相互交互时，预测无法表示为特征效应之和，因为一个特征的效应取决于另一个特征的值。亚里士多德的断言“整体大于部分之和”在存在交互时适用。

### 5.4.1 特征交互？

如果机器学习模型基于两个特征进行预测，我们可以将预测分解为四项：常数项、第一个特征的项、第二个特征的项以及两个特征之间的交互项。

两个特征之间的交互是在考虑单个特征效应后，通过变化特征而引起的预测变化。

例如，一个模型使用房屋大小（大或小）和位置（好或坏）作为特征来预测房屋价值，从而产生四种可能的预测：

| 位置 | 大小 | 预测 |
|---|---|---|
| 好 | 大 | 300,000 |
| 好 | 小 | 200,000 |
| 坏 | 大 | 250,000 |
| 坏 | 小 | 150,000 |

我们将模型预测分解为以下部分：常数项（150,000）、大小特征的效应（如果为大则 +100,000；如果为小则 +0）以及位置的效应（如果为好则 +50,000；如果为坏则 +0）。这种分解完全解释了模型预测。没有交互效应，因为模型预测是大小和位置的单个特征效应之和。当你将小房子变大时，预测始终增加 100,000，与位置无关。此外，好位置和坏位置之间的预测差异是 50,000，与大小无关。

现在让我们看一个带有交互的示例：

| 位置 | 大小 | 预测 |
|---|---|---|
| 好 | 大 | 400,000 |
| 好 | 小 | 200,000 |
| 坏 | 大 | 250,000 |
| 坏 | 小 | 150,000 |

我们将预测表分解为以下部分：常数项（150,000）、大小特征的效应（如果为大则 +100,000，如果为小则 +0）以及位置的效应（如果为好则 +50,000，如果为坏则 +0）。对于此表，我们需要一个额外的交互项：如果房屋很大且位置好，则 +100,000。这是大小和位置之间的交互，因为在这种情况下，大房子和小房子之间的预测差异取决于位置。

估计交互强度的一种方法是衡量预测的变化有多少取决于特征之间的交互。这种测量称为 H-statistic，由 Friedman 和 Popescu (2008)32 引入。

### 5.4.2 理论：Friedman 的 H-statistic

我们将处理两种情况：首先，双向交互度量，它告诉我们模型中的两个特征是否以及在多大程度上相互交互；其次，总交互度量，它告诉我们一个特征是否以及在多大程度上在模型中与所有其他特征交互。理论上，可以测量任意数量特征之间的任意交互，但这两种是最有趣的情况。

如果两个特征不交互，我们可以按如下方式分解偏依赖函数（假设偏依赖函数以零为中心）：

$\text{PD}_{\{jk\}}(x_{\cdot j}, x_{\cdot k}) = \text{PD}_{\cdot j}(x_{\cdot j}) + \text{PD}_{\cdot k}(x_{\cdot k})$

同样，如果一个特征与任何其他特征都没有交互，我们可以将预测函数 $\hat{f}(x)$ 表示为偏依赖函数之和，其中第一个加项仅取决于 j，第二个加项取决于除 j 之外的所有其他特征：

$\hat{f}(x) = \text{PD}_{\cdot j}(x_{\cdot j}) + \text{PD}_{\{\cdot j\}}(x_{\{\cdot j\}})$

这种分解表达了不带交互（特征 j 和 k 之间，或分别 j 与所有其他特征之间）的偏依赖（或完整预测）函数。接下来，我们测量观察到的偏依赖函数与不带交互的分解函数之间的差异。我们计算偏依赖输出的方差（以测量两个特征之间的交互）或整个函数的方差（以测量一个特征与所有其他特征之间的交互）。交互解释的方差量（观察到的 PD 与无交互 PD 之间的差异）被用作交互强度统计量。如果根本没有交互，该统计量为 0；如果 $\text{PD}_{\{jk\}}$ 或 $\hat{f}$ 的所有方差都由偏依赖函数之和解释，则该统计量为 1。两个特征之间的交互统计量为 1 意味着每个单个 PD 函数都是常数，对预测的影响仅通过交互产生。H-statistic 也可以大于 1，这更难解释。这种情况发生在双向交互的方差大于二维偏依赖图的方差时。

从数学上讲，Friedman 和 Popescu 提出的用于特征 j 和 k 之间交互的 H-statistic 为：

$\text{H}^2_{\cdot\{jk\}} = \sum_{i=1}^n [\text{PD}_{\{jk\}}(x_{\{j\}}^{(i)}, x_k^{(i)}) - \text{PD}_{\cdot j}(x_{j}^{(i)}) - \text{PD}_{\cdot k}(x_{k}^{(i)})]^2 / \sum_{i=1}^n \text{P}$

测量特征 j 是否与任何其他特征交互时亦然：

$\text{H}^2_{\cdot\{j\}} = \sum_{i=1}^n [\hat{f}(x^{(i)}) - \text{PD}_{\cdot j}(x_{j}^{(i)}) - \text{PD}_{\{\cdot j\}}(x_{\{\cdot j\}}^{(i)})]^2 / \sum_{i=1}^n \hat{f}^2(x^{(i)})$

评估 H-statistic 代价高昂，因为它遍历所有数据点，并且在每个点上都必须评估偏依赖，而这反过来又是用所有 n 个数据点完成的。在最坏的情况下，我们需要 2n^2 次对机器学习模型预测函数的调用来计算双向 H-statistic（j vs. k），以及 3n^2 次调用来计算总 H-statistic（j vs. all）。为了加快计算，我们可以从 n 个数据点中采样。这的缺点是增加了偏依赖估计的方差，从而使 H-statistic 不稳定。因此，如果你使用采样来减少计算负担，请确保采样足够多的数据点。

Friedman 和 Popescu 还提出了一个检验统计量，用于评估 H-statistic 是否显著不同于零。原假设是不存在交互。为了在原假设下生成交互统计量，你必须能够调整模型，使其在特征 j 和 k 或所有其他特征之间没有交互。这对于所有类型的模型都不可能。因此，此检验是特定于模型的，而不是与模型无关的，因此在此不予介绍。

交互强度统计量也可应用于分类场景，前提是预测为概率。
