在第二个示例中，我们想要解释一个使用反事实解释来预测连续结果的模型。Anna 想要出租她的公寓，但不确定要收多少租金，因此她决定训练一个机器学习模型来预测租金。当然，因为 Anna 是数据科学家，这就是她解决问题的方式。在输入了大小、位置、是否允许宠物等所有细节后，模型告诉她可以收 900 欧元。她期望收 1000 欧元或更多，但她信任她的模型，并决定调整公寓的特征值，看看如何提高公寓的价值。她发现，如果公寓大 15 m2，可以出租超过 1000 欧元。有趣，但不可操作的知识，因为她不能扩大她的公寓。最后，通过仅调整她控制下的特征值（内置厨房 是/否，允许宠物 是/否，地板类型等），她发现如果她允许宠物并安装隔热更好的窗户，她可以收 1000 欧元。Anna 直觉地使用了反事实来改变结果。

反事实是人性化的解释，因为它们相对于当前实例是对比性的，并且因为它们是选择性的，这意味着它们通常专注于少量特征更改。但是反事实受到“罗生门效应”的影响。《罗生门》是一部日本电影，其中一名武士的谋杀案由不同的人讲述。每个故事都同样好地解释了结果，但故事之间相互矛盾。同样的情况也可能发生在反事实中，因为通常有多个不同的反事实解释。每个反事实讲述了如何达到某个结果的不同“故事”。一个反事实可能会说更改特征 A，另一个反事实可能会说保持 A 不变但更改特征 B，这是一种矛盾。这个多重真理问题可以通过报告所有反事实解释或通过设立标准来评估反事实并选择最佳反事实来解决。

谈到标准，我们如何定义一个好的反事实解释？首先，反事实解释的用户定义了实例预测中的相关变化（= 替代现实）。一个明显的第一个要求是，反事实实例应尽可能接近地产生预定义的预测。并不总是可以找到具有预定义预测的反事实。例如，在具有两个类别的分类设置中，一个罕见类别和一个常见类别，模型可能总是将实例分类为常见类别。更改特征值使得预测标签从常见类别翻转到罕见类别可能是不可能的。因此，我们希望放宽反事实预测必须与预定义结果精确匹配的要求。在分类示例中，我们可以寻找一个反事实，其中罕见类别的预测概率从当前的 2% 提高到 10%。那么问题是，特征中的最小变化是什么，使得预测概率从 2% 变为 10%（或接近 10%）？

另一个质量标准是，反事实在特征值方面应尽可能与实例相似。两个实例之间的距离可以例如用曼哈顿距离或 Gower 距离来衡量（如果我们同时具有离散特征和连续特征）。反事实不仅应靠近原始实例，还应尽可能少地更改特征。为了衡量反事实解释在此度量上的优劣，我们可以简单地计算更改特征的数量，或者用花哨的数学术语，测量反事实与实际实例之间的 (L_0) 范数。

第三，生成多个多样化的反事实解释通常是可取的，以便决策主体获得生成不同结果的多种可行方式。例如，继续我们的贷款示例，一个反事实解释可能只建议将收入翻倍以获得贷款，而另一个反事实可能建议搬到附近的城市并小幅增加收入以获得贷款。可以指出，虽然第一个反事实对某些人可能可行，但后者对某些人可能更具可操作性。因此，除了为决策主体提供获得所需结果的不同方式外，多样性还使“多样化”的个人能够更改对他们方便的特征。

最后一个要求是，反事实实例应具有可能的特征值。为租赁示例生成公寓大小为负数或房间数设置为 200 的反事实解释是没有意义的。当反事实根据数据的联合分布是可能时，情况会更好，例如，拥有 10 个房间和 20 m2 的公寓不应被视为反事实解释。理想情况下，如果平方米数增加，也应提出房间数增加。

## 6.1.1 生成反事实解释

生成反事实解释的一种简单且天真的方法是通过试错进行搜索。这种方法涉及随机更改感兴趣实例的特征值，并在预测出所需输出时停止。就像 Anna 尝试寻找她可以收取更高租金的公寓版本的例子一样。但是，比试错更好的方法有很多。首先，我们根据上述标准定义一个损失函数。此损失函数以感兴趣的实例、一个反事实和所需的（反事实）结果作为输入。然后，我们可以使用优化算法找到最小化此损失的反事实解释。许多方法以这种方式进行，但在损失函数的定义和优化方法上有所不同。

在以下内容中，我们重点介绍其中两种：首先是 Wachter et al. (2017) 提出的方法，他们将反事实解释作为一种解释方法引入；其次是 Dandl et al. (2020) 提出的方法，它考虑了上述所有四个标准。

### 6.1.1.1 Wachter et al. 方法

Wachter et al. 建议最小化以下损失：

```
L(x,x',y',\lambda)=\lambda\cdot(\hat{f}(x')-y')^2+d(x,x')
```

第一项是反事实 x' 的模型预测与所需结果 y' 之间的二次距离，用户必须预先定义 y'。第二项是待解释实例 x 与反事实 x' 之间的距离 d。损失衡量反事实的预测结果与预定义结果的距离，以及反事实与感兴趣实例的距离。距离函数 d 定义为每个特征的加权曼哈顿距离，权重为每个特征的中位数绝对偏差 (MAD) 的倒数。

```
d(x,x')=\sum_{j=1}^p |x_j-x'_j| \cdot MAD_j
```

总距离是所有 p 个特征级距离的总和，即实例 x 与反事实 x' 之间特征值的绝对差。特征级距离按数据集中特征 j 的中位数绝对偏差的倒数进行缩放，定义如下：

```
MAD_j=median{|x_{1,j}-median{|x_{1,j}|}|}
```

向量的中位数是使向量中一半值大于它、另一半值小于它的值。MAD 是特征方差的等效量，但不是使用均值作为中心并对平方距离求和，而是使用中位数作为中心并对绝对距离求和。所提议的距离函数相对于欧几里得距离的优势在于，它对异常值更具鲁棒性。使用 MAD 进行缩放是必要的，以将所有特征带到相同的尺度 - 测量公寓大小是以平方米还是平方英尺都不应该重要。

参数 \lambda 在预测距离（第一项）与特征值距离（第二项）之间进行权衡。给定 \lambda 时求解损失并返回一个反事实 x'。\lambda 的较高值意味着我们偏好预测接近所需结果 y' 的反事实，较低值意味着我们偏好在特征值上与 x 非常相似的反事实 x'。如果 \lambda 非常大，将选择预测最接近 y' 的实例，无论它与 x 相距多远。最终，用户必须决定如何平衡反事实预测匹配所需结果的要求与反事实与 x 相似的要求。该方法的作者建议，不要为 \lambda 选择一个值，而是选择一个容差 \epsilon，规定反事实实例的预测允许与 y' 的最大偏差。此约束可以写成：

```
|\hat{f}(x') - y'| \leq \epsilon
```
