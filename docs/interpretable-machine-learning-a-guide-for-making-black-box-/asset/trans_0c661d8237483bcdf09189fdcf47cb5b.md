

不幸的是，情况有点混乱。但让我们来看看各个单独的解释，先从狗开始。Vanilla Gradient 和 Vanilla Gradient + SmoothGrad 都高亮了狗，这说得通。但它们也高亮了书周围的一些区域，这很奇怪。Grad-CAM 只高亮了书的区域，这完全说不通。而且从这里开始，情况变得更加混乱。Vanilla Gradient 方法似乎对汤碗和章鱼（或者，正如网络所认为的，鳗鱼）都失效了。两张图片都像是盯着太阳看太久后留下的残影。（请不要直接看着太阳看）。SmoothGrad 很有帮助，至少高亮区域更清晰了。在汤的示例中，一些食材被高亮，比如鸡蛋和肉类，但也包括筷子周围的区域。在章鱼图片中，主要高亮的是动物本身。

对于汤碗，Grad-CAM 高亮了鸡蛋部分，出于某种原因，还有碗的上半部分。Grad-CAM 对章鱼的解释更加混乱。

在这里你已经可以看到评估我们是否信任这些解释的困难。作为第一步，我们需要考虑图像的哪些部分包含与图像分类相关的信息。但然后我们还需要思考神经网络可能用于分类的内容。也许汤碗是基于鸡蛋和筷子的组合被正确分类的，正如 SmoothGrad 暗示的那样？或者也许神经网络识别了碗的形状加上一些食材，正如 Grad-CAM 所建议的？我们只是不知道。

而这正是所有这些方法的重大问题。我们没有解释的基准真理。我们只能在第一步中拒绝那些显然说不通的解释（即使在这一步中我们也没有强烈的把握。神经网络中的预测过程非常复杂）。

### 7.2.7 优势

解释是可视化的，我们能快速识别图像。特别是，当方法只高亮重要像素时，就能立即轻松识别图像中的重要区域。

基于梯度的方法通常比模型无关方法计算得更快。例如，LIME 和 SHAP 也可以用于解释图像分类，但计算成本更高。

有很多方法可供选择。

### 7.2.8 劣势

与大多数解释方法一样，很难知道一个解释是否正确，而且评估的很大一部分只是定性的（“这些解释看起来差不多对，让我们赶紧发表论文吧。”）。

像素归因方法可能非常脆弱。Ghorbani 等人 (2019) 表明，向图像引入小的（对抗性）扰动，这些扰动仍然会导致相同的预测，可能会导致作为解释被高亮的像素截然不同。

Kindermans 等人 (2019) 也表明，这些像素归因方法可能高度不可靠。他们向输入数据添加了一个常数偏移，意味着他们给所有图像添加了相同的像素变化。他们比较了两个网络，原始网络和“偏移”网络（其中第一层的偏差被更改以适应恒定像素偏移）。两个网络产生相同的预测。梯度对两者也相同。但解释发生了变化，这是一种不想要的属性。他们研究了 DeepLift、Vanilla Gradient 和 Integrated Gradients。

论文“显著性图的健全性检查”调查了显著性方法是否对模型和数据不敏感。不敏感是非常不可取的，因为这意味着“解释”与模型和数据无关。对模型和训练数据不敏感的方法类似于边缘检测器。边缘检测器只是简单地高亮图像中强烈的像素颜色变化，与预测模型或图像的抽象特征无关，且不需要训练。测试的方法包括 Vanilla Gradient、Gradient x Input、Integrated Gradients、Guided Backpropagation、Guided Grad-CAM 和 SmoothGrad（基于 vanilla gradient）。Vanilla gradients 和 Grad-CAM 通过了不敏感检查，而 Guided Backpropagation 和 Guided Grad-CAM 失败。然而，健全性检查论文本身也受到了 Tomsett 等人 (2020) 89 的一些批评，他们撰写了一篇名为“显著性指标的健全性检查”的论文（当然）。他们发现评估指标缺乏一致性（我知道，这变得相当元了）。所以我们回到了原点……评估视觉解释仍然很困难。这对从业者来说非常困难。

总的来说，这是一个**非常不令人满意的局面**。我们得再等一等，等待更多关于这个话题的研究。而且，请不要再发明新方法，而是更多地审视如何评估这些方法。

### 7.2.9 软件

像素归因方法有几种软件实现。就示例而言，我使用了 tf-keras-vis。最全面的库之一是 iNNvestigate，它实现了 Vanilla gradient、Smoothgrad、Deconvnet、Guided Backpropagation、PatternNet、LRP 等更多方法。许多方法在 DeepExplain Toolbox 中实现。

## 第8章 晶球展望

可解释机器学习的未来是什么？本章是一种投机性的思维练习，对可解释机器学习的发展做出主观猜测。我以相当悲观的**短篇故事**开篇此书，并希望以更乐观的展望结束。

我将我的“预测”基于三个前提：

- 1. **数字化：** 任何（**有趣**）的信息都将被**数字化**。想想电子现金和在线交易。想想电子书、音乐和视频。想想关于我们环境、人类行为、工业生产流程等等的所有感官数据。万物数字化的驱动因素包括：廉价计算机/传感器/存储、规模效应（胜者通吃）、新商业模式、模块化价值链、成本压力等等。

- 2. **自动化：** 当一项任务可以被自动化，并且**自动化**的成本低于长期执行该任务的成本时，该任务将被**自动化**。即使在计算机出现之前，我们也有一定程度的自动化。例如，织布机自动化了纺织，蒸汽机自动化了马力。但计算机和数字化将自动化提升到了一个新水平。仅仅因为你可以编写for循环、编写Excel宏、自动化电子邮件回复等等，就能看出个人可以自动化多少事情。售票机自动化了火车票的购买（不再需要售票员），洗衣机自动化了洗衣，定期转账自动化了支付交易，等等。自动化任务腾出了时间和金钱，因此有巨大的经济和个人动力来自动化事物。我们目前正在观察语言翻译、驾驶，以及小程度上甚至科学发现的自动化。

- 3. **错误规格：** 我们无法完美地指定一个包含所有约束的目标。想想瓶中精灵，它总是字面意思地实现你的愿望：“我想成为世界上最富有的人！” -> 你变成了世界上最富有的人，但作为副作用，你持有的货币因通货膨胀而崩溃。“我想余生都快乐！” -> 接下来的5分钟你感到非常快乐，然后精灵杀死了你。“我希望世界和平！” -> 精灵杀死了所有人。我们错误地指定目标，要么是因为我们不知道所有约束，要么是因为我们无法测量它们。让我们以公司作为不完美目标规格的例子。公司的简单目标是为股东赚钱。但这种规格没有捕捉到我们真正追求的包含所有约束的真实目标：例如，我们不欣赏一家公司为了赚钱而杀人、毒害河流，或者仅仅印制自己的货币。我们发明了法律、法规、制裁、合规程序、工会等，来修补不完美的目标规格。另一个你可以亲自体验的例子是 <u>Paperclips</u>，这是一款你扮演一台机器、目标是生产尽可能多回形针的游戏。**警告：** 它很上瘾。我不想透露太多，但总而言之，事情很快就会失控。在机器学习中，目标规格的不完美来自不完美的数据抽象（有偏的人群、测量误差、...）、无约束的损失函数、对约束缺乏了解、训练数据和应用数据之间分布的转移等等。

数字化正在推动自动化。不完美的目标规格与自动化相冲突。我认为这种冲突部分通过解释方法来调解。

我们预测的舞台已经搭好，水晶球也已准备就绪，现在让我们来看看这个领域可能走向何方！
