

我们对特征进行边缘化。这是通过从特征的边缘分布中采样值来实现的。只要特征之间相互独立，这样做就是可行的。当特征相互依赖时，我们可能会采样出对该实例来说没有意义的特征值。但我们仍会使用这些值来计算特征的 Shapley 值。一种解决方案可能是将相关特征一起置换，并为它们获取一个共同的 Shapley 值。另一种改进是条件采样：特征是根据已经在团队中的特征进行条件采样的。虽然条件采样解决了不切实际数据点的问题，但引入了一个新问题：得到的值不再是我们博弈中的 Shapley 值，因为它们违反了对称性公理，如 Sundararajan 等人（2019）45 所发现，并由 Janzing 等人（2020）46 进一步讨论。

### 5.9.6 软件与替代方案

Shapley 值在 R 语言的 iml 和 fastshap 包中均有实现。

SHAP（Shapley 值的一种替代估计方法）将在下一章中介绍。

另一种方法称为 breakDown，它在 breakDown R 包47 中实现。BreakDown 也会显示每个特征对预测的贡献，但会逐步计算。让我们重复使用博弈类比：我们从空团队开始，添加对预测贡献最大的特征值，并迭代直到所有特征值都被添加。每个特征值贡献多少取决于“团队”中已有的相应特征值，这是 breakDown 方法的主要缺点。它比 Shapley 值方法更快，对于没有交互作用的模型，结果是相同的。

## 5.10 SHAP（SHapley Additive exPlanations）

*本章目前仅在此 Web 版本中提供。电子书和印刷版将随后推出。*

SHAP（SHapley Additive exPlanations）由 Lundberg 和 Lee（2016）提出，是一种解释个别预测的方法。SHAP 基于博弈论上最优的 Shapley 值。

SHAP 拥有独立章节而非作为 Shapley 值的子章节，主要有两个原因。首先，SHAP 的作者提出了 KernelSHAP，这是一种受局部代理模型启发的、用于 Shapley 值的替代性、基于内核的估计方法。他们还提出了 TreeSHAP，这是一种用于基于树的模型的高效估计方法。其次，SHAP 包含许多基于 Shapley 值聚合的全局解释方法。本章将解释这些新的估计方法和全局解释方法。

我建议先阅读关于 Shapley 值和局部模型（LIME）的章节。

### 5.10.1 定义

SHAP 的目标是通过计算每个特征对预测的贡献来解释实例 x 的预测。SHAP 解释方法从联盟博弈论中计算 Shapley 值。数据实例的特征值充当联盟中的玩家。Shapley 值告诉我们如何将“回报”（即预测）公平地分配给各个特征。玩家可以是单个特征值，例如表格数据。玩家也可以是一组特征值。例如，解释图像时，可以将像素分组为超像素，并将预测分配给它们。SHAP 带来的一项创新是，将 Shapley 值解释表示为一种加性特征归因方法，即线性模型。该观点将 LIME 和 Shapley 值联系起来。SHAP 将解释规定为：

```
g(z') = \phi_0 + \sum_{j=1}^M \phi_j z_j'
```

其中 g 是解释模型，（\(z' \in \{0,1\}^M\)）是联盟向量，M 是最大联盟大小，而 (\(\phi_j\)) 是特征 j 的特征归因，即 Shapley 值。我称之为“联盟向量”的东西在 SHAP 论文中被称为“简化特征”。我认为之所以选择这个名称，是因为例如对于图像数据，图像并未在像素级别表示，而是聚合为超像素。我认为将 z 视为描述联盟是有帮助的：在联盟向量中，条目 1 表示相应的特征值“存在”，0 表示“缺失”。如果你了解 Shapley 值，这应该对你很熟悉。计算 Shapley 值时，我们模拟只有部分特征值在“参与”（“存在”），而另一些则不参与（“缺失”）。将联盟表示为线性模型是计算 (\(\phi_i\))'s 的一个技巧。对于感兴趣的实例 x，联盟向量 x' 是一个全 1 向量，即所有特征值都“存在”。公式简化为：

```
g(x') = \phi_0 + \sum_{j=1}^M \phi_j
```

您可以在 Shapley 值章节中找到类似表示法的此公式。关于实际估计的更多内容将在后面介绍。在深入估计细节之前，让我们先讨论一下 (\(\phi_i\))'s 的属性。

Shapley 值是唯一满足效率、对称性、虚拟和可加性属性的解。SHAP 也满足这些属性，因为它计算的是 Shapley 值。在 SHAP 论文中，您会发现 SHAP 属性与 Shapley 属性之间存在差异。SHAP 描述了以下三个可取属性：

### 1) 局部准确性

```
f(x) = g(x') = \phi_0 + \sum_{j=1}^M \phi_j x_j'
```

如果定义 (\(\phi_0 = E_X(\hat{f}(\{x\})\)) 并将所有 (\(x_{-j}'\)) 设置为 1，这就是 Shapley 效率属性。只是名称不同并使用联盟向量。

```
f(x) = \phi_0 + \sum_{j=1}^M \phi_j = E_X(\hat{f}(X)) + \sum_{j=1}^M \phi_j
```

### 2) 缺失性

```
x_j' = 0 \rightarrow \phi_j = 0
```

缺失性表示缺失特征的归因为零。请注意，\(x_j'\) 指的是联盟，其中值 0 表示特征值的缺失。在联盟表示法中，待解释实例的所有特征值 \(x_j'\) 应为 '1'。出现 0 表示该特征值对感兴趣的实例来说是缺失的。这一属性不属于“常规”Shapley 值的属性。那么我们为什么需要它来用于 SHAP 呢？Lundberg 将其称为“次要记账属性”。从理论上讲，缺失特征可以拥有任意 Shapley 值而不会损害局部准确性属性，因为它乘以 \(x_j'=0\)）。缺失性属性强制要求缺失特征获得 0 的 Shapley 值。在实践中，这仅对恒定特征相关。

### 3) 一致性

令 \((f_x(z')=f(h_x(z'))\) 和 \((z_{\{\setminus \{ j\}\}})\) 表示 \(z_j'=0\))。对于任何满足以下条件的两个模型 f 和 f'：

```
|f_x'(z') - f_x'(z_{\{\setminus \{ j\}\}})| \geq |f_x(z') - f_x(z_{\{\setminus \{ j\}\}})|
```

针对所有输入 \((z' \in \{0,1\}^M)\)

```
\phi_j(f', x) \geq \phi_j(f, x)
```

一致性属性表示，如果模型发生变化，使得特征值的边际贡献增加或保持不变（无论其他特征如何），Shapley 值也会增加或保持不变。根据一致性，Shapley 属性线性性、虚拟性和对称性随之得出，如 Lundberg 和 Lee 的附录中所述。

### 5.10.2 KernelSHAP

KernelSHAP 估计实例 x 中每个特征值对预测的贡献。KernelSHAP 包含 5 个步骤：

- 采样联盟 \((z_k' \in \{0,1\}^M, k \in \{1, \dots, K\})\)（1 = 特征存在于联盟中，0 = 特征缺失于联盟中）。
- 通过先将 \((z_k')\) 转换回原始特征空间，然后应用模型 f 来获取每个 \((z_k')\) 的预测：\((f(h_x(z_k')))\)
- 使用 SHAP 内核计算每个 \((z_k')\) 的权重。
- 拟合加权线性模型。
- 返回 Shapley 值 \((\phi_k)\)，即线性模型中的系数。

我们可以通过连续抛硬币来创建随机联盟，直到得到一串 0 和 1。例如，向量 (1,0,1,0) 表示我们有一个由第一个和第三个特征组成的联盟。K 个采样联盟成为回归模型的数据集。回归模型的目标是联盟的预测。（“等等！”，你说，“模型并未在这些二进制联盟数据上训练，无法对其进行预测。”）要从特征值联盟得到有效的数据实例，我们需要一个函数 \((h_x(z')=z)\)，其中 \((h_x:\{0,1\}^M \rightarrow \mathbb{R}^p)\)。函数 \((h_x)\) 将 1 映射到我们想要解释的实例 x 中的相应值。对于表格数据，它将 0 映射到我们从数据中采样的另一个实例的值。这意味着我们将“特征值缺失”等同于“特征值被数据中的随机特征值替换”。对于表格数据，以下图表可视化了从联盟到特征值的映射：
