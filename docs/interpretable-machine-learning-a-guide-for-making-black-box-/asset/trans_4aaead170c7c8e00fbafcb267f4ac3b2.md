MMD-critic 比较数据分布和选定原型的分布。这是理解 MMD-critic 方法的核心概念。MMD-critic 选择能最小化两个分布之间差异的原型。高密度区域中的数据点是很好的原型，特别是当点从不同的“数据簇”中选择时。由原型无法很好解释的区域中的数据点将被选为批评。

### 6.3.1 理论

MMD-critic 过程在高层次上可以简要总结为：

- 1. 选择你想要找到的原型和批评的数量。
- 2. 使用贪心搜索寻找原型。选择原型，使得原型的分布接近数据分布。
- 3. 使用贪心搜索寻找批评。在原型分布与数据分布不同的地方，将点选为批评。

使用 MMD-critic 为数据集寻找原型和批评，我们需要一些要素。作为最基本的要素，我们需要一个 **核函数** 来估计数据密度。核函数是根据两个数据点之间的接近程度对它们进行加权的函数。基于密度估计，我们需要一个度量来告诉我们两个分布有多么不同，以便我们能确定所选原型的分布是否接近数据分布。这通过测量 **最大均值差异 (MMD)** 来解决。同样基于核函数，我们需要 **见证函数** 来告诉我们在特定数据点处两个分布有多么不同。借助见证函数，我们可以选择批评，即原型分布与数据分布偏离且见证函数取较大绝对值的数据点。最后一个要素是寻找良好原型和批评的搜索策略，这通过简单的 **贪心搜索** 来解决。

让我们从 **最大均值差异 (MMD)** 开始，它测量两个分布之间的差异。原型的选择创建了原型的密度分布。我们想要评估原型分布是否与数据分布不同。我们使用核密度函数对两者进行估计。最大均值差异测量两个分布之间的差异，即函数空间上根据两个分布的期望之差的上确界。都清楚吗？就我个人而言，当我看到如何用数据计算某事时，我对这些概念理解得更好。下面的公式展示了如何计算平方 MMD 度量 (MMD2)：

```
\[ MMD^2 = \frac{1}{m^2} \sum_{i,j=1}^{m} k(z_i, z_j) - \frac{2}{mn} \sum_{i,j=1}^{m,n} k(z_i, x_j) + \frac{1}{n^2} \sum_{i,j=1}^{n} k(x_i, x_j) \]
```

k 是一个测量两个点相似度的核函数，但稍后再详细介绍。m 是原型 z 的数量，n 是我们原始数据集中数据点 x 的数量。原型 z 是从数据点 x 中选取的。每个点都是多维的，即可以有多个特征。MMD-critic 的目标是最小化 MMD2。MMD2 越接近零，原型分布对数据的拟合就越好。将 MMD2 降为零的关键是中间项，它计算原型与所有其他数据点之间的平均接近度（乘以 2）。如果这一项等于第一项（原型之间的平均接近度）加上最后一项（数据点之间的平均接近度），那么原型就完美地解释了数据。试试看，如果将所有 n 个数据点用作原型，公式会发生什么变化。

核函数的一种选择是径向基函数核：

```
\[ k(x, x') = \exp(-\gamma \|x - x'\|^2) \]
```

其中 \|x-x'\|^2 是两个点之间的欧几里得距离，\gamma 是缩放参数。核函数的值随两个点之间的距离减小，范围在零和一之间：当两个点相距无限远时为零；当两个点相等时为一。

我们将 MMD2 度量、核函数和贪心搜索结合在一个寻找原型的算法中：

- 从原型的空列表开始。
- 当原型数量低于选定的数量 m 时：
  - 对数据集中的每个点，检查将该点添加到原型列表时 MMD2 减少了多少。将使 MMD2 最小化的数据点添加到列表中。
- 返回原型列表。

寻找批评的最后一个要素是见证函数，它告诉我们在特定点处两个密度估计有多么不同。它可以使用以下公式估计：

```
\[ \text{witness}(x) = \frac{1}{n}\sum_{i=1}^{n} k(x, x_i) - \frac{1}{m}\sum_{j=1}^{m} k(x, z_j) \]
```

对于两个数据集（具有相同的特征），见证函数为你提供了评估点 x 更适合哪个经验分布的方法。要找到批评，我们寻找见证函数在负向和正向上的极值。见证函数中的第一项是点 x 与数据之间的平均接近度，第二项分别是点 x 与原型之间的平均接近度。如果点 x 的见证函数接近于零，数据和原型的密度函数就很接近，这意味着原型的分布在点 x 处类似于数据的分布。点 x 处负的见证函数意味着原型分布高估了数据分布（例如，如果我们选择了一个原型，但附近只有少量数据点）；点 x 处正的见证函数意味着原型分布低估了数据分布（例如，如果 x 周围有许多数据点，但我们没有在附近选择任何原型）。

这一步与原型的找到方式无关。我也可以手动选择一些原型，并使用这里描述的过程来学习批评。或者，原型可以来自任何聚类程序，例如 k-medoids。

这就是 MMD-critic 理论的重要部分。还有一个问题：**MMD-critic 如何用于可解释机器学习？**

MMD-critic 可以以三种方式增加可解释性：帮助更好地理解数据分布；构建可解释模型；使黑盒模型可解释。

如果在数据上应用 MMD-critic 来寻找原型和批评，它将提高你对数据的理解，尤其是当你有带有边缘情况的复杂数据分布时。但是，使用 MMD-critic 你可以做到更多！
