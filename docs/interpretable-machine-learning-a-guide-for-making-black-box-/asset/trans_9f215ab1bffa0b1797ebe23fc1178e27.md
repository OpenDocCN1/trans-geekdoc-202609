

### 6.1.3 优点

反事实解释的阐释非常清晰。如果根据反事实更改实例的特征值，预测将变为预定义的预测。没有额外的假设，背后也没有魔法。这也意味着它不像 LIME 等方法那么危险，因为在 LIME 中，不清楚我们可以将局部模型外推到多远以进行阐释。

反事实方法创建一个新实例，但我们也可以通过报告哪些特征值发生了变化来总结一个反事实。这为我们提供了报告结果的两种选择。你可以报告反事实实例，也可以突出显示感兴趣的实例与反事实实例之间更改了哪些特征。

反事实方法不需要访问数据或模型。它只需要访问模型的预测函数，例如，也可以通过 Web API 来实现。这对于受第三方审计的公司，或者在不披露模型或数据的情况下为用户提供解释的公司很有吸引力。公司出于商业秘密或数据保护原因，有保护模型和数据的利益。反事实解释在解释模型预测和保护模型所有者利益之间取得了平衡。

该方法也适用于不使用机器学习的系统。我们可以为任何接收输入并返回输出的系统创建反事实。预测公寓租金的系统也可以由手写规则组成，反事实解释仍然有效。

反事实解释方法相对容易实现，因为它本质上是一个损失函数（带有单个或多个目标），可以使用标准优化器库进行优化。必须考虑一些额外细节，例如将特征值限制在有意义的范围内（例如，仅正数的公寓面积）。

### 6.1.4 缺点

对于每个实例，你通常会找到多个反事实解释（拉舒蒙效应）。这很不方便——大多数人更喜欢简单的解释，而不是现实世界的复杂性。这也是一个实际挑战。假设我们为一个实例生成了 23 个反事实解释。我们是否全部报告？只报告最好的？如果它们都相对“好”但非常不同呢？这些问题必须在每个项目中重新回答。拥有多个反事实解释也可能有好处，因为人类可以选择与其先前知识相符的解释。

### 6.1.5 软件和替代方案

Dandl 等人提出的多目标反事实解释方法已在 Github 仓库中实现。

在 Python 包 Alibi 中，作者实现了一个简单的反事实方法，以及一个使用类原型来提高算法输出可解释性和收敛性的扩展方法^58。

Karimi 等人（2019）^59 也在 Github 仓库中提供了其算法 MACE 的 Python 实现。他们将适当反事实所需的标准转换为逻辑公式，并使用可满求度求解器来查找满足这些标准的反事实。

Mothilal 等人（2020）^60 开发了 DiCE（多样化反事实解释），以基于行列式点过程生成一组多样化的反事实解释。目前，DiCE 仅适用于可微分模型，因为它使用梯度下降进行优化。

查找反事实的另一种方法是 Laugel 等人（2017）^61 的生长球体算法。他们在论文中没有使用反事实一词，但该方法非常相似。他们还定义了一个损失函数，该函数倾向于特征值变化尽可能少的反事实。他们不直接优化该函数，而是建议首先在感兴趣的点周围绘制一个球体，对球体内的点进行采样，并检查采样点中的哪一个是否产生所需的预测。然后他们相应地收缩或扩展球体，直到找到一个（稀疏的）反事实并最终返回。

Ribeiro 等人（2018）62 的锚点（Anchors）是反事实的对立面，请参见关于范围规则（锚点）的章节。

## 6.2 对抗样本

对抗样本是带有小的、故意的特征扰动的实例，会导致机器学习模型做出错误预测。我建议先阅读关于反事实解释的章节，因为这些概念非常相似。对抗样本是旨在欺骗模型而不是解释模型的反事实样本。

我们为什么对对抗样本感兴趣？它们不就是机器学习模型毫无实际意义的奇特副产品吗？答案是明确的“不”。对抗样本使机器学习模型易受攻击，如以下场景所示。

一辆自动驾驶汽车因为忽略停车标志而与另一辆车相撞。有人在标志上贴了一张图片，对人类来说，它看起来像是带有少许污垢的停车标志，但却是为汽车的标志识别软件设计成看起来像禁止停车标志的。

垃圾邮件检测器未能将一封电子邮件分类为垃圾邮件。这封垃圾邮件被设计成看起来像正常邮件，但意图是欺骗收件人。

机场的机器学习扫描仪扫描行李中的武器。开发了一把刀，通过让系统认为它是一把雨伞来避免被检测到。

让我们来看看创建对抗样本的一些方法。

### 6.2.1 方法和示例

创建对抗样本有很多技术。大多数方法建议最小化对抗样本与待操纵实例之间的距离，同时将预测转移到所需（对抗性）结果。有些方法需要访问模型的梯度，这当然只适用于基于梯度的模型，例如神经网络；而其他方法只需要访问预测函数，这使得这些方法与模型无关。本节的方法专注于使用深度神经网络的图像分类器，因为该领域有大量研究，对抗图像的可视化非常具有教育意义。图像的对抗样本是带有故意扰动像素的图像，旨在在应用时欺骗模型。这些示例令人印象深刻地展示了用于目标识别的深度神经网络可以被对人类看似无害的图像轻易欺骗。如果你还没有见过这些示例，你可能会感到惊讶，因为预测的变化对人类观察者来说是无法理解的。对抗样本就像机器的光学幻觉。
