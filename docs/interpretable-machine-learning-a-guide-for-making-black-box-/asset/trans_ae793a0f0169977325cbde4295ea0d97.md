

**可解释机器学习**是指使机器学习系统的行为和预测对人类可理解的方法和模型。

一个 **数据集** 是机器学习所用数据的表格。数据集包含特征和待预测的目标。当用于诱导模型时，数据集被称为训练数据。

一个 **实例** 是数据集中的一行。"instance" 的其他名称有：(数据) 点、示例、观测值。一个实例由特征值 \(x^{\wedge}(i)\) 和（如果已知）目标结果 \(y_i\) 组成。

**特征** 是用于预测或分类的输入。特征是数据集中的一列。在整本书中，特征被假定为可解释的，这意味着很容易理解它们的含义，例如给定日期的温度或某人的身高。特征的可解释性是一个很大的假设。但如果难以理解输入特征，那么理解模型在做什么就更难。包含所有特征的矩阵称为 X，单个实例的表示为 \(x^{\wedge}(i)\)。所有实例的单个特征向量是 \(x_j\)，特征 j 和实例 i 的值是 \(x^{\wedge}(i)_j\)。

**目标** 是机器学习要预测的信息。在数学公式中，目标通常称为 y，或者针对单个实例称为 \(y_i\)。

**机器学习任务** 是带有特征和目标的数据集的组合。根据目标的类型，任务可以是分类、回归、生存分析、聚类或异常检测等。

**预测** 是机器学习模型根据给定特征 "猜测" 目标值应该是什么的内容。在本书中，模型预测表示为 \(\hat{f}(x^{\wedge}(i))\) 或 \(\hat{y}\)。

## 第 2 章 可解释性

可解释性没有数学定义。我喜欢 Miller (2017)³ 给出的一个（非数学）定义是：**可解释性是人类能够理解决策原因的程度。** 另一个定义是：**可解释性是人类能够一致预测模型结果的程度**⁴。机器学习模型的可解释性越高，有人理解为何做出某些决策或预测就越容易。如果一个模型的决策比另一个模型的决策更容易让人类理解，那么该模型的可解释性更好。我将“可解释”和“可说明”这两个术语互换使用。像 Miller (2017) 一样，我认为有必要区分可解释性/可说明性与解释的术语。我将使用“解释”来指代对单个预测的解释。请参见关于解释的章节，了解我们人类认为什么是好的解释。

### 2.1 可解释性的重要性

如果机器学习模型表现良好，**我们为什么不直接信任模型**并忽略它做出某个决定的**为什么**？“问题在于，单一指标（如分类准确率）对大多数现实世界任务来说是不完整的描述。”（Doshi-Velez 和 Kim 2017 5）

让我们深入探讨可解释性如此重要的原因。在进行预测建模时，你需要做出权衡：你只是想知道**什么**吗？例如，客户流失的概率或某种药物对患者的有效性。或者你想知道**为什么**做出了预测，并可能以预测性能下降为代价来换取可解释性？在某些情况下，你并不在乎做出了什么决策，只需知道在测试数据集上的预测性能良好即可。但在其他情况下，了解“为什么”可以帮助你更多地了解问题、数据以及模型可能失败的原因。有些模型可能不需要解释，因为它们用于低风险环境，这意味着错误不会造成严重后果。（例如，电影推荐系统）或者该方法已经过广泛研究和评估（例如，光学字符识别）。对可解释性的需求源于问题形式化中的不完整性（Doshi-Velez 和 Kim 2017），这意味着对于某些问题或任务来说，仅获得预测（即**什么**）是不够的。模型还必须解释它是如何得出预测的（即**为什么**），因为正确的预测只能部分解决你的原始问题。以下原因推动了对可解释性和解释的需求（Doshi-Velez 和 Kim 2017 以及 Miller 2017）。

**人类的好奇心与学习：** 人类对环境有一个心理模型，当发生意外情况时会更新该模型。这种更新是通过为意外事件寻找解释来完成的。例如，一个人感到意外地生病并问：“我为什么感觉这么病？”。他了解到每次吃那些红色浆果时都会生病。他更新了自己的心理模型，并决定浆果导致了疾病，因此应该避免。当在研究中使用不透明的机器学习模型时，如果模型只给出预测而没有解释，科学发现将完全隐藏。为了促进学习并满足人们对机器为何做出某些预测或行为的好奇心，可解释性和解释至关重要。当然，人类不需要对发生的每件事都有解释。对大多数人来说，不了解计算机的工作原理也是可以接受的。意外事件会让我们产生好奇心。例如：为什么我的电脑意外关机？

与学习密切相关的是人类在世界中**寻找意义**的愿望。我们希望协调知识结构中元素之间的矛盾或不一致。

在许多学科中，方法正在从定性方法转向定量方法（例如，社会学、心理学），并且也转向机器学习（生物学、基因组学）。科学的目标是获取知识，但许多问题是使用大型数据集和黑盒机器学习模型来解决的。模型本身而非数据成为知识的来源。可解释性使得可以提取模型所捕获的这些额外知识。

机器学习模型承担需要安全措施和测试的现实世界任务。想象一辆自动驾驶汽车基于深度学习系统自动检测骑自行车的人。你希望系统学习到的抽象是 100% 无误的，因为碾压骑自行车的人相当糟糕。解释可能会揭示，最重要的学习特征是识别自行车的两个轮子，这个解释能帮助你思考边缘情况，例如侧面挂有部分遮挡车轮的挎包的自行车。

默认情况下，机器学习模型会从训练数据中汲取偏见。这可能会使你的机器学习模型变成歧视代表性不足群体的种族主义者。可解释性是检测机器学习模型中偏见的有用调试工具。你训练用于自动批准或拒绝信贷申请的机器学习模型，可能会歧视一个历史上被剥夺选举权的少数群体。你的主要目标是只向最终会还款的人发放贷款。在这种情况下，问题表述的不完整性在于，你不仅希望尽量减少贷款违约，而且还有义务不基于某些人口特征进行歧视。这是问题表述（以低风险且合规的方式发放贷款）的一部分额外约束，而机器学习模型优化所使用的损失函数并未涵盖这一点。

将机器和算法融入我们日常生活的过程需要可解释性来提高社会接受度。人们会将信念、欲望、意图等归因于事物。在一项著名的实验中，Heidegger 和 Simmel (1944) 向参与者展示了图形视频，其中一个圆形打开一扇“门”进入一个“房间”（这其实只是一个矩形）。参与者描述图形的动作，就像描述人类代理人的行为一样，将意图甚至情感和个性特征归因于图形。机器人是个好例子，比如我的吸尘器，我给它取名为“Doge”。如果 Doge 卡住了，我会想：“Doge 想继续清洁，但因为卡住了而向我寻求帮助。” 后来，当 Doge 完成清洁并搜索充电桩时，我会想：“Doge 有充电的愿望，并打算找到充电桩。” 我也会归因个性特征：“Doge 有点笨，但以一种可爱的方式。” 这些是我的想法，尤其是当我发现 Doge 在认真给房子吸尘时打翻了一盆植物。能够解释其预测的机器或算法会获得更多接受。请参见关于解释的章节，该章节认为解释是一种社会过程。

解释被用来管理社交互动。通过创造对某事的共同意义，解释者会影响解释接收者的行为、情感和信念。为了与我们互动，机器可能需要塑造我们的情感和信念。机器必须“说服”我们，以便实现其预定目标。如果我的机器人吸尘器不能在某种程度上解释其行为，我不会完全接受它。吸尘器通过解释它卡住了，而不是仅仅无评论地停止工作，来创造对例如“事故”（比如再次卡在浴室地毯上）的共同意义。有趣的是，解释机器的目标（建立信任）与接收者的目标（了解预测或行为）之间可能存在错位。也许 Doge 卡住的完整解释可能是电池电量非常低、其中一个轮子工作不正常，以及存在一个导致机器人反复去同一地点
