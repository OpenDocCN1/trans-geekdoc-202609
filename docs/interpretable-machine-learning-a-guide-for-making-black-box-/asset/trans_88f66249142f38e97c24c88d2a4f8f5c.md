## Lasso 示例

我们将使用 Lasso 预测自行车租赁量。我们预先设定希望在模型中拥有的特征数量。首先将数量设为 2 个特征：

| 特征 | 权重 |
|---|---|
| seasonSPRING | 0.00 |
| seasonSUMMER | 0.00 |
| seasonFALL | 0.00 |
| seasonWINTER | 0.00 |
| holidayHOLIDAY | 0.00 |
| workingdayWORKING DAY | 0.00 |
| weathersitMISTY | 0.00 |
| weathersitRAIN/SNOW/STORM | 0.00 |
| temp | 52.33 |
| hum | 0.00 |
| windspeed | 0.00 |
| days_since_2011 | 2.15 |

Lasso 路径中前两个具有非零权重的特征是温度（"temp"）和时间趋势（"days_since_2011"）。

现在，让我们选择 5 个特征：

| 特征 | 权重 |
|---|---|
| seasonSPRING | -389.99 |
| seasonSUMMER | 0.00 |
| seasonFALL | 0.00 |
| seasonWINTER | 0.00 |
| holidayHOLIDAY | 0.00 |
| workingdayWORKING DAY | 0.00 |
| weathersitMISTY | 0.00 |
| weathersitRAIN/SNOW/STORM | -862.27 |
| temp | 85.58 |
| hum | -3.04 |
| windspeed | 0.00 |
| days_since_2011 | 3.82 |

请注意，"temp" 和 "days_since_2011" 的权重与两个特征的模型不同。其原因是，通过减小 lambda，即使模型中已有的特征也会受到较少的惩罚，并可能获得更大的绝对权重。Lasso 权重的解释与线性回归模型中权重的解释相对应。你只需要注意特征是否进行了标准化，因为这会影响权重。在此示例中，特征由软件进行了标准化，但权重已自动转换回以匹配原始特征量表。

## 线性模型中稀疏性的其他方法

可以使用广泛的方法来减少线性模型中的特征数量。

预处理方法：

- 手动选择特征：你可以随时使用专家知识来选择或丢弃某些特征。最大的缺点是它无法自动化，并且你需要找到懂数据的人。

- 单变量选择：一个例子是相关系数。你只考虑特征与目标之间相关性超过某个阈值的特征。缺点是它仅单独考虑特征。有些特征在线性模型考虑了其他一些特征之前可能不会显示相关性。使用单变量选择方法，你会错过这些特征。

逐步方法：

- 前向选择：使用一个特征拟合线性模型。对每个特征都这样做。选择效果最好的模型（例如 R 平方最高）。现在，对于剩余特征，通过将每个特征添加到当前最佳模型来拟合不同版本的模型。选择表现最好的那个。继续直到达到某个标准，例如模型中特征的最大数量。

- 后向选择：与前向选择类似。但不是添加特征，而是从包含所有特征的模型开始，尝试删除哪个特征可以获得最高的性能提升。重复此过程直到达到某个停止标准。

我推荐使用 Lasso，因为它可以自动化，同时考虑所有特征，并可以通过 lambda 控制。它也适用于分类的逻辑回归模型。

## 4.1.8 优点

将预测建模为**加权和**使预测的生成方式变得透明。并且通过 Lasso，我们可以确保使用的特征数量保持较小。

许多人使用线性回归模型。这意味着在许多地方，它被**接受**用于预测建模和推断。存在**高水平的集体经验和专业知识**，包括线性回归模型的教学材料和软件实现。线性回归可以在 R、Python、Java、Julia、Scala、Javascript 等中找到……

从数学上讲，估计权重很简单，并且你有**找到最优权重的保证**（前提是线性回归模型的所有假设都被数据满足）。

连同权重，你还会得到置信区间、检验和坚实的统计理论。线性回归模型还有许多扩展（参见<u>关于 GLM、GAM 及更多内容的章节</u>）。

## 4.1.9 缺点

线性回归模型只能表示线性关系，即输入特征的加权和。每个**非线性或交互都必须手工制作**，并明确作为输入特征提供给模型。

线性模型在预测性能方面也常常**不太好**，因为可以学习的关系受到很大限制，通常过度简化了复杂现实的运作方式。

权重的解释**可能不直观**，因为它取决于所有其他特征。与结果 y 高度正相关的特征和另一个特征可能在线性模型中获得负权重，因为，考虑到另一个相关特征，它在高维空间中与 y 呈负相关。完全相关的特征甚至使得无法找到线性方程的唯一解。示例：你有一个预测房屋价值的模型，具有房间数量和房屋大小等特征。房屋大小和房间数量高度相关：房子越大，房间越多。如果将这两个特征都放入线性模型，可能会发生房屋大小是更好的预测因子并获得大正权重的情况。房间数量最终可能会获得负权重，因为，在房子大小相同的情况下，增加房间数量可能会使其价值降低，或者当相关性太强时，线性方程会变得不稳定。

## 4.2 逻辑回归

逻辑回归对具有两种可能结果的分类问题建模概率。它是线性回归模型针对分类问题的扩展。

### 4.2.1 线性回归用于分类的问题是什么？

线性回归模型对回归问题效果良好，但对分类问题会失效。为什么呢？在两个类别的情况下，你可以将一个类别标记为 0，另一个标记为 1，然后使用线性回归。从技术上讲它可以工作，大多数线性模型程序都会输出权重。但这种方法有几个问题：

线性模型不输出概率，而是将类别视为数字（0 和 1），并拟合最佳超平面（对于单个特征，它是一条直线），以最小化点与超平面之间的距离。因此，它只是在点之间进行插值，你无法将其解释为概率。

线性模型还会外推，并给出低于零和高于一的值。这表明可能存在更智能的分类方法。

由于预测结果不是概率，而是点之间的线性插值，因此没有一个有意义的阈值可以用来区分一个类别和另一个类别。Stackoverflow 上对此问题给出了很好的说明。

线性模型不扩展到多类分类问题。你将不得不从给下一个类别标记 2 开始，然后是 3，依此类推。类别可能没有任何有意义的顺序，但线性模型会在特征与类别预测之间强加一种奇怪的结构。特征值越高且权重为正，它对预测较高编号类别的贡献就越大，即使碰巧获得相似编号的类别并不比其他类别更接近。
