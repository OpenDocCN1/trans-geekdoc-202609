## 有影响力的实例

有影响力的实例是指移除后会对训练好的模型产生强烈影响的数据实例。当从训练数据中移除某个特定实例并重新训练模型时，模型参数或预测变化越大，该实例的影响力就越大。一个实例对训练好的模型是否有影响，还取决于其对于目标 y 的值。下图展示了线性回归模型中的一个有影响力的实例。

## 为什么有影响力的实例有助于理解模型？

有影响力的实例用于可解释性的核心思想是将模型参数和预测追溯到其起源：训练数据。学习器，即生成机器学习模型的算法，是一个函数，它接受由特征 X 和目标 y 组成的训练数据并生成一个机器学习模型。例如，决策树的学习器是一个选择分割特征及其分割值的算法。神经网络的学习器使用反向传播来寻找最佳权重。

![](img/9328bf422a53c0f374079f63527c081f_211_1.png)

图 6.13: 学习器从训练数据（特征加目标）中学习模型。模型对新数据进行预测。

我们询问如果在训练过程中从训练数据中移除实例，模型参数或预测会如何变化。这与其他可解释性方法形成对比，那些方法分析当我们操纵待预测实例的特征时预测如何变化，例如部分依赖图或特征重要性。使用有影响力的实例时，我们不将模型视为固定不变，而是视为训练数据的函数。有影响力的实例帮助我们回答关于全局模型行为和个别预测的问题。哪些实例对模型参数或整体预测影响最大？哪些实例对特定预测影响最大？有影响力的实例告诉我们模型可能在哪些实例上出现问题，哪些训练实例应检查错误，并让我们了解模型的鲁棒性。如果单个实例对模型预测和参数有强烈影响，我们可能不会信任该模型。至少这会促使我们进一步调查。

我们如何找到有影响力的实例？我们有两种衡量影响力的方法：第一种方法是从训练数据中删除实例，在缩减的训练数据集上重新训练模型，并观察模型参数或预测的差异（可以是单个实例，也可以是整个数据集）。第二种方法是基于模型参数的梯度近似参数变化，从而对数据实例进行加权。删除方法更容易理解，并为加权方法提供了动机，因此我们先从前者开始。

## 6.4.1 删除诊断

统计学家在有影响力的实例领域已经进行了大量研究，特别是针对（广义）线性回归模型。当你搜索“influential observations”时，最初的搜索结果是关于 DFBETA 和 Cook 距离等度量的。**DFBETA** 衡量删除实例对模型参数的影响。**Cook 距离**（Cook, 1977）衡量删除实例对模型预测的影响。对于这两种度量，我们都需要反复重新训练模型，每次省略一个单独的实例。将包含所有实例的模型的参数或预测与从训练数据中删除一个实例后的模型的参数或预测进行比较。

DFBETA 定义如下：

```
\[DFBETA_{\{i\}}=\beta-\beta^{\{-i\}}\]
```

其中 \(\beta\) 是在所有数据实例上训练模型时的权重向量，而 \(\beta^{\{-i\}}\) 是在没有实例 i 的情况下训练模型时的权重向量。我说，这相当直观。DFBETA 仅适用于具有权重参数的模型，例如逻辑回归或神经网络，但不适用于决策树、树集成、一些支持向量机等模型。

Cook 距离最初是为线性回归模型发明的，且存在针对广义线性回归模型的近似方法。训练实例的 Cook 距离定义为移除第 i 个实例后预测结果的平方差的（缩放）总和。

```
\[D_i=\frac{\sum_{j=1}^n(\hat{y}_j-\hat{y}_j^{(-i)})^2}{p\cdot MSE}\]
```

其中分子是移除第 i 个实例后模型预测与不移除时预测的平方差，在数据集上求和。分母是特征数量 p 乘以均方误差。无论移除哪个实例 i，分母对所有实例都相同。Cook 距离告诉我们当从训练数据中移除第 i 个实例时，线性模型的预测输出会变化多少。

我们可以对任何机器学习模型使用 Cook 距离和 DFBETA 吗？DFBETA 需要模型参数，因此此度量仅适用于参数化模型。Cook 距离不需要任何模型参数。有趣的是，Cook 距离通常只出现在线性模型和广义线性模型的上下文中，但移除特定实例前后模型预测差值的想法非常通用。Cook 距离定义的一个问题是 MSE，它对所有类型的预测模型（例如分类）都不一定有意义。

对模型预测影响的最简单影响度量可以写作如下：

```
\[Influence^{(-i)}=\frac{1}{n}\sum_{j=1}^n|\hat{y}_j-\hat{y}_j^{(-i)}|\]
```

这个表达式基本上是 Cook 距离的分子，区别在于将绝对差值相加而不是平方差值。这是我做出的选择，因为这在后面的示例中更合理。删除诊断度量的一般形式包括选择一个度量（例如预测结果）并计算在所有实例上训练的模型与删除实例后的模型之间该度量的差异。

我们可以轻松地分解影响，以解释第 i 个训练实例对实例 j 预测的影响：

```
\[Influence_j^i(-i)=|\hat{y}_j-\hat{y}_j^{(-i)}|\]
```

这也适用于模型参数的差异或损失的差异。在接下来的示例中，我们将使用这些简单的影响度量。

## 删除诊断示例

在接下来的示例中，我们训练一个支持向量机来根据风险因素预测宫颈癌，并衡量哪些训练实例对整体和特定预测影响最大。由于癌症预测是一个分类问题，我们将影响度量为癌症预测概率的差异。当从模型训练中移除某个实例时，如果预测概率在数据集中平均显著增加或减少，则该实例具有影响力。对所有 858 个训练实例的影响度量需要先在所有数据上训练一次模型，然后每次移除一个实例重新训练 858 次（等于训练数据的大小）。

影响力最大的实例的影响度量约为 0.01。影响力为 0.01 意味着如果移除第 540 个实例，预测概率平均会变化 1 个百分点。考虑到癌症的平均预测概率为 6.4%，这相当显著。所有可能删除情况的影响度量平均值为 0.2 个百分点。现在我们知道哪些数据实例对模型影响最大。这对于调试数据已经很有用。是否存在有问题的实例？是否存在测量错误？有影响力的实例是首先应检查错误的实例，因为其中的每个错误都会强烈影响模型预测。

除了模型调试之外，我们能学到什么来更好地理解模型吗？仅打印出前 10 个最有影响力的实例并不十分有用，因为这只是一个具有许多特征的实例表格。所有以实例作为输出的方法只有在我们有一种良好的表示方式时才有意义。但当我们问：什么区分了有影响力的实例和无影响力的实例？时，我们可以更好地了解哪种实例具有影响力。我们可以将这个问题转化为一个回归问题，并将实例的影响建模为其特征值的函数。我们可以自由选择可解释机器学习模型章节中的任何模型。对于这个示例，我选择了一棵决策树（如下图所示），该决策树显示 35 岁及以上女性的数据对支持向量机影响最大。在数据集中的所有女性中，858 人中有 153 人年龄超过 35 岁。在部分依赖图章节中，我们看到 40 岁以后癌症预测概率急剧增加，特征重要性也将年龄检测为最重要的特征之一。影响分析告诉我们，在预测较高年龄的癌症时，模型变得越来越不稳定。这本身就是宝贵信息。这意味着这些实例中的错误可能对模型产生强烈影响。
