

\[val_x(S) = \int \hat{f}(f)(x_1, \dots, x_p) \, d\lambda_{bb}(x_{\backslash S}) - E_X(\hat{f}(f)(X))\]

实际上，对于不包含在 S 中的每个特征，你都要执行多次积分。具体示例：机器学习模型使用 4 个特征 x1、x2、x3 和 x4，我们要评估由特征值 x1 和 x3 组成的联盟 S 的预测：

\[val_x(S) = val_x(\{x_1, x_3\}) = \int \int \hat{f}(f)(x_1, X_2, x_3, X_4) \, d\lambda_{bb} \, d\lambda_{bb}\]

这与线性模型中的特征贡献很相似！

不要被“value”这个词的多种用法搞混：特征值是特征和实例的数值或类别值；Shapley 值是特征对预测的贡献；值函数是玩家（特征值）联盟的回报函数。

Shapley 值是唯一满足**效率**、**对称性**、**虚拟**和**可加性**属性的归因方法，这些属性共同可被视为公平回报的定义。

**效率** 特征贡献之和必须等于 x 的预测值与平均预测值之差。

\[\sum_{j=1}^p \phi_j = \hat{f}(f)(x) - E_X(\hat{f}(f)(X))\]

**对称性** 如果两个特征值 j 和 k 对所有可能联盟的贡献相同，则它们的贡献应相同。如果

\[val(S \cup \{x_j\}) = val(S \cup \{x_k\})\]

对所有

\[S \subseteq \{x_1, \dots, x_p\} \setminus \{x_j, x_k\}\]

则

\[\phi_j = \phi_k\]

**虚拟** 特征 j 不会改变预测值——无论它被添加到哪个特征值联盟中——其 Shapley 值应为 0。如果

\[val(S \cup \{x_j\}) = val(S)\]

对所有

\[S \subseteq \{x_1, \dots, x_p\}\]

则

\[\phi_j = 0\]

**可加性** 对于联合回报为 val+val<sup>+</sup> 的博弈，相应的 Shapley 值如下：

\[\phi_j + \phi_j^+\]

假设你训练了一个随机森林，这意味着预测是许多决策树的平均值。可加性属性保证，对于某个特征值，你可以分别计算每棵树的 Shapley 值，对它们求平均，从而得到该特征值在随机森林中的 Shapley 值。

## 5.9.3.2 直觉

理解 Shapley 值的一种直观方式是以下说明：特征值以随机顺序进入一个房间。房间中的所有特征值都参与游戏（= 对预测做出贡献）。某个特征值的 Shapley 值是该特征值加入时，房间中已存在的联盟所获得的预测平均变化。

## 5.9.3.3 估计 Shapley 值

为了计算精确的 Shapley 值，必须对特征值的所有可能联盟（集合）在有和没有第 j 个特征的情况下进行评估。当特征超过少数几个时，精确解会变得不切实际，因为可能联盟的数量随特征增加而呈指数增长。Strumbelj 等人（2014年）^43 提出了一种基于蒙特卡洛采样的近似方法：

\[\hat{\phi}_j = \frac{1}{|M|} \sum_{m=1}^M \left( \hat{f}(x^{\{m\}}_{-+j}) - \hat{f}(x^{\{m\}}_{-j}) \right)\]

其中，\(\hat{f}(x^{\{m\}}_{-+j})\) 是对 x 的预测，但随机数量的特征值被随机数据点 z 的特征值所替换，特征 j 的相应值除外。x 向量 \((x^{\{m\}}_{-j})\) 与 \((x^{\{m\}}_{-+j})\) 几乎相同，但值 \((x_{-j\{m\}})\) 也来自采样的 z。这些 M 个新实例中的每一个都是由两个实例组装而成的“弗兰肯斯坦怪物”。

## 单个特征值的近似 Shapley 值估计：

- 输出：第 j 个特征值的 Shapley 值
- 所需：迭代次数 M、感兴趣的实例 x、特征索引 j、数据矩阵 X 和机器学习模型 f
- 对于所有 m = 1,...

首先，选择感兴趣的实例 x、特征 j 和迭代次数 M。每次迭代中，从数据中随机选择一个实例 z，并生成特征的随机顺序。通过结合感兴趣实例 x 和样本 z 的值来创建两个新实例。实例 \(x_{+j}\) 是感兴趣的实例，但在特征 j 之前的顺序中的所有值都被替换为样本 z 的特征值。实例 \(x_{-j}\) 与 \(x_{+j}\) 相同，但额外将特征 j 替换为来自样本 z 的特征 j 的值。计算黑盒预测的差异：

\[\phi_{j\{m\}} = \hat{f}(x^{\{m\}}_{+j}) - \hat{f}(x^{\{m\}}_{-j})\]

对所有这些差异求平均，得到：

\[\phi_j(x) = \frac{1}{|M|} \sum_{m=1}^M \phi_{j\{m\}}\]

求平均值隐式地按 X 的概率分布对样本进行加权。

必须对每个特征重复此过程，以获得所有 Shapley 值。

## 5.9.4 优势

预测与平均预测之间的差异在实例的特征值之间被**公平分配**——这是 Shapley 值的效率属性。这一属性将 Shapley 值与 LIME 等其他方法区分开来。LIME 不保证预测在特征之间得到公平分配。Shapley 值可能是提供完整解释的唯一方法。在法律要求可解释性的情况下——例如欧盟的“解释权”——Shapley 值可能是唯一合乎法律的方法，因为它基于坚实的理论并公平地分配效应。我不是律师，因此这仅反映我对要求的直觉。

Shapley 值允许**对比性解释**。与其将预测与整个数据集的平均预测进行比较，不如将其与子集甚至单个数据点进行比较。这种对比性也是局部模型（如 LIME）所不具备的。

Shapley 值是唯一具有**坚实理论**的解释方法。公理——效率、对称性、虚拟、可加性——为解释提供了合理的基础。LIME 等方法假设机器学习模型在局部呈线性行为，但没有理论说明为什么这应该奏效。

将预测解释为特征值进行的博弈，这令人震惊。

## 5.9.5 劣势

Shapley 值需要**大量计算时间**。在 99.9% 的实际问题中，只有近似解是可行的。精确计算 Shapley 值在计算成本上很高昂，因为特征值有 2^k 个可能联盟，并且特征的“缺失”必须通过绘制随机实例来模拟，这会增加 Shapley 值估计的方差。通过对联盟进行采样并限制迭代次数 M 来处理联盟的指数数量。减小 M 可减少计算时间，但会增加 Shapley 值的方差。关于迭代次数 M 没有好的经验法则。M 应该足够大以准确估计 Shapley 值，但又足够小以便在合理时间内完成计算。理论上可以根据切尔诺夫边界来选择 M，但我尚未看到任何关于针对机器学习预测的 Shapley 值这样做的论文。

Shapley 值**可能被误解**。某个特征值的 Shapley 值并不是从模型训练中移除该特征后的预测值差异。Shapley 值的解释是：给定当前的特征值集合，某个特征值对实际预测与平均预测之间差异的贡献即为估计的 Shapley 值。

如果你寻求稀疏解释（包含少量特征的解释），Shapley 值就是错误的解释方法。使用 Shapley 值方法创建的解释**始终使用所有特征**。人类更喜欢选择性解释，例如 LIME 产生的解释。对于外行需要处理的解释，LIME 可能是更好的选择。另一个解决方案是 Lundberg 和 Lee（2016年）^44 引入的 SHAP，它基于 Shapley 值，但也可以提供包含少量特征的解释。

Shapley 值为每个特征返回一个简单值，但**不像 LIME 那样提供预测模型**。这意味着它不能用于对输入变化引起的预测变化做出陈述，例如：“如果我每年多赚 300 美元，我的信用评分将提高 5 点。”

另一个劣势是，如果你想为新数据实例计算 Shapley 值，**你需要访问数据**。仅访问预测函数是不够的，因为你需要数据来用从数据中随机抽取的实例的值替换感兴趣实例的部分。只有当你能创建看起来像真实数据实例但并非训练数据中实际实例的数据实例时，才可以避免这一问题。
