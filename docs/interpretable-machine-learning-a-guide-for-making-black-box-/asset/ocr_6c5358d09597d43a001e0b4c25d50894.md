# 5.9.2 Examples and Interpretation

The interpretation of the Shapley value for feature value j is: The value of the j-th feature contributed \phi(phi_j) to the prediction of this particular instance compared to the average prediction for the dataset.

The Shapley value works for both classification (if we are dealing with probabilities) and regression.
