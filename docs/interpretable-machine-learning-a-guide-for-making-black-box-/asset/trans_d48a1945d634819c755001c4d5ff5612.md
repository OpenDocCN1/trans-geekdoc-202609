由于两个特征的 ALE 估计仅显示特征的二阶效应，因此解释需要特别注意。二阶效应是在考虑了特征的主效应之后，特征的额外交互效应。假设两个特征不相互作用，但每个特征对预测结果都有线性效应。在每个特征的 1D ALE 图中，我们会看到一条直线作为估计的 ALE 曲线。但是当我们绘制 2D ALE 估计时，它们应该接近于零，因为二阶效应仅是交互作用的额外效应。ALE 图和 PD 图在这一点上有所不同：PDP 始终显示总效应，ALE 图显示一阶或二阶效应。这些是不依赖于底层数学的设计决策。你可以在部分依赖图中减去低阶效应以获得纯主效应或二阶效应，或者，你可以通过不减去低阶效应来获得总 ALE 图的估计值。

累积局部效应也可以计算为任意更高阶（三个或多个特征的交互作用），但如 PDP 章节中所论证，只有最多两个特征才有意义，因为更高阶的交互作用无法可视化甚至无法进行有意义的解释。

## 类别特征的 ALE

累积局部效应方法--按定义--需要特征值具有顺序，因为该方法沿某个方向累积效应。类别特征没有任何自然顺序。要为类别特征计算 ALE 图，我们必须以某种方式创建或找到一个顺序。类别的顺序会影响累积局部效应的计算和解释。

一种解决方案是根据其他特征的相似性对类别进行排序。两个类别之间的距离是各特征距离之和。特征级距离比较两个类别中的累积分布（也称为 Kolmogorov-Smirnov 距离，适用于数值特征）或相对频数表（适用于类别特征）。一旦我们获得了所有类别之间的距离，我们就使用多维尺度法将距离矩阵降为一维距离度量。这给出了基于相似性的类别顺序。

为了更清楚地说明这一点，这里有一个例子：假设我们有两个类别特征“season”和“weather”以及一个数值特征“temperature”。对于第一个类别特征（season），我们想要计算 ALE。该特征具有类别“spring”、“summer”、“fall”、“winter”。我们开始计算类别“spring”和“summer”之间的距离。距离是特征 temperature 和 weather 上的距离之和。对于 temperature，我们取所有季节为“spring”的实例，计算经验累积分布函数，对季节为“summer”的实例做同样的处理，并用 Kolmogorov-Smirnov 统计量测量它们的距离。对于 weather 特征，我们计算所有“spring”实例中每种天气类型的概率，对“summer”实例做同样的处理，并将概率分布中的绝对距离相加。如果“spring”和“summer”具有非常不同的温度和天气，则总类别距离较大。我们对其他季节对重复该过程，并通过多维尺度法将生成的距离矩阵降为单维。

## 5.3.4 示例

让我们看看 ALE 图的实际效果。我构建了一个部分依赖图失效的场景。该场景包含一个预测模型和两个强相关特征。预测模型大多是线性回归模型，但在我们从未观察到实例的两个特征组合上，它会做一些奇怪的事情。

![](img/9328bf422a53c0f374079f63527c081f_116_0.png)

FIGURE 5.14: 两个特征和预测结果。模型预测两个特征之和（阴影背景），但如果 x1 大于 0.7 且 x2 小于 0.3，模型始终预测 2。该区域远离数据分布（点云），不影响模型性能，也不应影响其解释。

这是一个现实且相关的场景吗？当你训练模型时，学习算法会最小化现有训练数据实例的损失。在训练数据分布之外，可能会发生奇怪的事情，因为模型在这些区域做奇怪的事情不会受到惩罚。离开数据分布称为外推，也可用于欺骗机器学习模型，这在对抗性示例章节中有所描述。请看我们的小例子，了解部分依赖图与 ALE 图相比的表现。

![](img/9328bf422a53c0f374079f63527c081f_117_0.png)

FIGURE 5.15: 使用 PDP（上行）和 ALE（下行）计算的特征效应比较。PDP 估计值受模型在数据分布之外的奇怪行为影响（图中出现陡峭跳跃）。ALE 图正确地识别出机器学习模型在特征和预测之间具有线性关系，忽略没有数据的区域。

但看到我们的模型在 x1 > 0.7 且 x2 < 0.3 时表现奇怪，难道不有趣吗？嗯，有点有趣，也没那么有趣。因为这些可能在物理上不可能或至少极不可能的数据实例，通常查看这些实例是无关紧要的。但如果你怀疑你的测试分布可能略有不同，并且有些实例实际上处于该范围内，那么将此区域纳入特征效应计算会很有趣。但必须是有意识地决定纳入尚未观察到数据的区域，而不应是像 PDP 这样的所选方法的副作用。如果你怀疑模型以后将与分布不同的数据一起使用，我建议使用 ALE 图并模拟你预期的数据分布。

FIGURE 5.16: 基于温度、湿度和风速的自行车预测模型 ALE 图。温度对预测有很强的影响。随着温度升高，平均预测上升，但在 25 摄氏度以上又下降。湿度有负面影响：当高于 60% 时，相对湿度越高，预测越低。风速对预测影响不大。

让我们看看温度、湿度和风速与所有其他特征之间的相关性。由于数据还包含类别特征，我们不能只使用 Pearson 相关系数，该系数仅在两个特征都是数值时才有效。相反，我训练一个线性模型，例如，基于另一个特征作为输入来预测温度。然后我测量线性模型中另一个特征解释的方差量并取平方根。如果另一个特征是数值型，那么结果等于标准 Pearson 相关系数的绝对值。但这种基于模型的“方差解释”方法（也称为 ANOVA，即 ANalysis Of VAriance 的缩写）即使另一个特征是类别型的也有效。“方差解释”度量始终介于 0（无关联）和 1（温度可以从另一个特征完美预测）之间。我们计算温度、湿度和风速与所有其他特征的解释方差。解释方差（相关性）越高，PD 图可能存在的问题就越多。下图可视化了天气特征与其他特征的相关性有多强。
