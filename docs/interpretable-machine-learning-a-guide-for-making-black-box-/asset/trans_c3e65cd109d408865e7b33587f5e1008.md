M-Plots 避免对不太可能的数据实例进行预测平均，但它们会将一个特征的效果与所有相关特征的效果混合。ALE 图通过计算——同样基于特征的条件分布——**预测差异而不是平均值**来解决这个问题。对于 30 m² 的居住面积效果，ALE 方法使用所有约 30 m² 的房屋，获取将这些房屋假设为 31 m² 时的模型预测减去假设为 29 m² 时的预测。这给了我们居住面积的纯效果，而不会将其效果与相关特征的效果混合。使用差异阻断了其他特征的效果。以下图形直观地展示了 ALE 图的计算方式。

- **M-Plots**: "让我向你展示对于在该特征上具有接近 v 值的数据实例，模型平均预测什么。该效果可能是由于该特征，但也可能是由于相关特征。"
- **ALE 图**: "让我向你展示对于该窗口内的数据实例，在围绕 v 的特征的小"窗口"中模型预测如何变化。"。

## 5.3.2 理论

PD、M 和 ALE 图在数学上有何不同？三种方法的共同点是，它们将复杂的预测函数 f 归约为仅依赖一个（或两个）特征的函数。三种方法都通过平均其他特征的效果来归约函数，但它们在计算的是预测平均值还是**预测差值**以及平均是在边缘分布还是条件分布上进行方面有所不同。

部分依赖图在边缘分布上平均预测值。

```
\begin{align*}\hat{f}\{_{x_S,PDP}(x_S)\&=E_{\{X_C\}}\left[\hat{f}(x_S,X_C)\right]\\...
```

这是预测函数 f 在特征值（x_S）处的值，对集合 (x_C) 中所有特征进行平均。平均意味着计算集合 C 中特征上的边缘期望 E，即按概率分布加权的预测积分。听起来很花哨，但要计算边缘分布上的期望值，我们只需取所有数据实例，强制它们在集合 S 的特征上具有某个网格值，并对这个操纵后的数据集的预测值求平均。此过程确保我们在特征的边缘分布上进行平均。

M-plots 在条件分布上平均预测值。

```
\begin{align*}\hat{f}\{_{x_S,M}(x_S)\|&=E_{\{X_C|X_S\}}\left[\hat{f}(X_S,X_C)|X_S=x_S\right]\\...
```

与 PDPs 相比，唯一的变化是我们按特定特征的每个网格值对预测进行条件平均，而不是在每个网格值处假设边缘分布。在实践中，这意味着我们必须定义一个邻域，例如，在计算 30 m² 对预测房屋价值的影响时，我们可以对 28 到 32 m² 之间所有房屋的预测值求平均。

ALE 图对预测的变化求平均并在网格上累加（有关计算的更多内容稍后介绍）。

```
\begin{align*}\hat{f}\{_{x_S,ALE}(x_S)=\&int_{\{z\in\{0,1\}\}}\wedge\{x_S\}E_{\{X_C|X_S\}}\left[\hat{f}(X_S,x_C)|X_S=z_S\right]dz...
```

该公式揭示了与 M-Plots 的三个不同之处。首先，我们对预测的变化求平均，而不是对预测值本身求平均。变化被定义为梯度（但在实际计算中，后来被替换为区间上的预测差值）。

```
\hat{f}\{^S(x_s,x_c)=\frac{\Delta}{\delta x}\hat{f}\{_{x_s,X_C}) \{\Delta_{}} \{x_S \} ]
```

第二个不同之处是对 z 的额外积分。我们在集合 S 的特征范围上累加局部梯度，这给出了特征对预测的效果。对于实际计算，z 被一系列间隔的网格所取代，我们在该网格上计算预测的变化。ALE 方法不直接平均预测值，而是计算特征 S 上条件预测差值，并对特征 S 进行导数积分以估计效果。嗯，这听起来很愚蠢。求导和积分通常会相互抵消，就像先减去再加上同一个数字。为什么在这里有意义呢？导数（或区间差异）隔离了感兴趣特征的效果并阻断了相关特征的效果。

ALE 图相对于 M-plots 的第三个不同之处是，我们从结果中减去一个常数。这一步将 ALE 图居中，使数据上的平均效果为零。

仍然存在一个问题：并非所有模型都带有梯度，例如随机森林没有梯度。但正如你将看到的，实际计算不需要梯度，而是使用间隔。让我们深入探讨 ALE 图的估计。

## 5.3.3 估计

首先，我将描述如何对单个数值特征估计 ALE 图，随后是对两个数值特征和单个分类特征进行估计。为了估计局部效果，我们将特征划分为许多间隔并计算预测的差异。该过程近似了梯度，也适用于没有梯度的模型。

首先我们估计未居中的效果：

```
hat{Accumulated Local Effects}
```

让我们从右侧开始分解这个公式。Accumulated Local Effects 这个名称很好地反映了该公式的所有单独组成部分。其核心，ALE 方法计算预测差异，即用网格值 z 替换感兴趣的特征。预测差异是该特征在某个间隔内对单个实例产生的效果。右侧的求和对间隔内所有实例的效果进行累加，该间隔在公式中作为邻域 (N_j(k)) 出现。我们将该和除以该间隔内的实例数，以获得该间隔的平均预测差异。间隔内的这个平均值由 ALE 名称中的 Local 项涵盖。左侧求和符号意味着我们在所有间隔上累加平均效果。例如，位于第三个间隔的特征值的（未居中）ALE 是第一、第二和第三个间隔效果的总和。ALE 中的 Accumulated 一词反映了这一点。

这个效果被居中，使平均效果为零。

```
hat{ALE}(x) = hat{...}
```

ALE 的值可以解释为与数据平均预测相比，特征在某个值处的主效应。例如，在 (x_j=3) 处 ALE 估计值为 -2 表示，当第 j 个特征取值 3 时，预测值比平均预测低 2。

特征分布的分位数被用作定义间隔的网格。使用分位数确保每个间隔内的数据实例数量相同。分位数的缺点是间隔长度可能差异很大。如果感兴趣的特征偏斜度很高（例如许多低值和只有少数非常高的值），这可能会导致一些奇怪的 ALE 图。

## 两个特征交互作用的 ALE 图

ALE 图还可以显示两个特征的交互效果。计算原理与单个特征相同，但我们使用矩形单元而不是间隔，因为我们需要在两个维度上累加效果。除了调整总体平均效果外，我们还调整两个特征的主效应。这意味着两个特征的 ALE 估计的是二阶效应，不包括特征的主效应。换句话说，两个特征的 ALE 仅显示两个特征的额外交互效应。我省略了 2D ALE 图的公式，因为它们很长且难以阅读。如果你对计算感兴趣，我将你引向该论文的公式 (13) -- (16)。我将依赖可视化来对二阶 ALE 计算建立直觉。
