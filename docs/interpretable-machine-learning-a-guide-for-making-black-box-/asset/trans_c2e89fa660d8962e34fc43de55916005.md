

## 第5章 模型无关方法

将解释与机器学习模型分离（= 模型无关的解释方法）具有某些优势（Ribeiro, Singh, and Guestrin 2016 [26]）。模型无关的解释方法相对于模型特定的解释方法的巨大优势在于其灵活性。当解释方法可以应用于任何模型时，机器学习开发人员可以自由地使用他们喜欢的任何机器学习模型。任何基于机器学习模型解释构建的东西（例如图形或用户界面）也变得独立于底层机器学习模型。通常，为了解决任务，不仅评估一种，而是评估许多类型的机器学习模型，并且在可解释性方面比较模型时，使用模型无关的解释更容易，因为相同的方法可以用于任何类型的模型。

模型无关解释方法的一种替代方案是仅使用可解释模型，这通常有一个巨大的缺点，即与其他机器学习模型相比会损失预测性能，并且将自己限制在一种模型类型上。另一种替代方案是使用模型特定的解释方法。这种方法的缺点是它也会将你绑定到一种模型类型，并且切换到其他东西会很困难。

模型无关解释系统的理想方面是（Ribeiro, Singh, and Guestrin 2016）：

- **模型灵活性：** 解释方法可以与任何机器学习模型一起使用，例如随机森林和深度神经网络。
- **解释灵活性：** 你不局限于某种特定的解释形式。在某些情况下，线性公式可能很有用，而在其他情况下，带有特征重要性的图形可能更有用。
- **表征灵活性：** 解释系统应能够使用与被解释模型不同的特征表示。对于使用抽象词嵌入向量的文本分类器，使用单个词的存在来进行解释可能更可取。

### 整体视图

让我们从高层次上看看模型无关的可解释性。我们通过收集数据来捕捉世界，并进一步通过使用机器学习模型学习预测数据（针对任务）来对其进行抽象。可解释性只是帮助人类理解的顶层之一。

图 5.1：可解释机器学习的全景。现实世界在以解释形式到达人类之前要经过许多层。

最底层是**世界**。这可能字面上就是大自然本身，比如人体的生物学及其对药物的反应，也可能是更抽象的事物，如房地产市场。世界层包含所有可观察且感兴趣的事物。最终，我们希望了解世界并与之交互。

第二层是**数据**层。我们必须对世界进行数字化，以便计算机可以处理它并存储信息。数据层包含从图像、文本、表格数据等任何内容。

通过基于数据层拟合机器学习模型，我们得到**黑盒模型**层。机器学习算法使用现实世界的数据进行学习，以进行预测或发现结构。

在黑盒模型层之上是**可解释性方法**层，它帮助我们处理机器学习模型的不透明性。特定诊断中最重要的特征是什么？为什么某笔金融交易被分类为欺诈？

最后一层由**人类**占据。看！人类正在向你挥手，因为你正在阅读这本书并帮助为黑盒模型提供更好的解释！人类最终是解释的消费者。

这种多层抽象也有助于理解统计学家和机器学习从业者在方法上的差异。统计学家处理数据层，例如规划临床试验或设计调查。他们跳过黑盒模型层，直接进入可解释性方法层。机器学习专家也处理数据层，例如收集皮肤癌图像的标记样本或爬取维基百科。然后他们训练一个黑盒机器学习模型。可解释性方法层被跳过，人类直接处理黑盒模型的预测。可解释机器学习融合了统计学家和机器学习专家的工作，这太棒了。

当然，这个图并不能捕捉一切：数据可能来自模拟。黑盒模型还输出可能甚至不会到达人类，而只供其他机器使用的预测，等等。但总体而言，这是一个有用的抽象，用于理解可解释性如何成为机器学习模型之上的这一新层。

### 5.1 部分依赖图 (PDP)

部分依赖图（简称 PDP 或 PD 图）显示一个或两个特征对机器学习模型预测结果的边际影响（J. H. Friedman 2001 [27]）。部分依赖图可以显示目标与特征之间的关系是线性的、单调的还是更复杂。例如，当应用于线性回归模型时，部分依赖图始终显示线性关系。

回归的部分依赖函数定义为：

\[
\hat{f}_{x_S}(x_S) = E_{x_C} \left[ \hat{f}(x_S, x_C) \right] = \int \hat{f}(x_S, x_C) d\mathbb{P}(x_C)
\]

$x_S$ 是应绘制部分依赖函数的特征，$x_C$ 是机器学习模型 $\hat{f}$ 中使用的其他特征。通常，集合 S 中只有一个或两个特征。S 中的特征是我们想要知道其对预测影响的特征。特征向量 $x_S$ 和 $x_C$ 合起来构成总特征空间 x。部分依赖通过对集合 C 中特征的分布进行边缘化机器学习模型输出来工作，这样函数就显示了我们感兴趣的集合 S 中的特征与预测结果之间的关系。通过对其他特征进行边缘化，我们得到一个仅依赖于集合 S 中特征（包括与其他特征的交互作用）的函数。

部分函数 $\hat{f}_{x_S}$ 通过在训练数据中计算平均值来估计，也称为蒙特卡洛方法：

\[
\hat{f}_{x_S}(x_S) = \frac{1}{n} \sum_{i=1}^n \hat{f}(x_S, x_C^{(i)})
\]

部分函数告诉我们，对于特征 S 的给定值，预测的平均边际效应是什么。在此公式中，$x_C^{(i)}$ 是我们不感兴趣的特征在数据集中的实际特征值，n 是数据集中的实例数量。PDP 的一个假设是集合 C 中的特征与集合 S 中的特征不相关。如果此假设被违反，部分依赖图中计算的平均值将包含非常不可能甚至不可能的数据点（参见缺点）。

对于输出概率的分类问题，部分依赖图显示给定集合 S 中特征不同值时某个类别的概率。处理多类问题的一个简单方法是为每个类别绘制一条线或一个图。

部分依赖图是一种全局方法：该方法考虑所有实例，并对特征与预测结果之间的全局关系给出说明。

### 类别特征

到目前为止，我们只考虑了数值特征。对于类别特征，部分依赖非常容易计算。对于每个类别，我们通过强制所有数据实例具有相同的类别来获得 PDP 估计值。例如，如果我们查看自行车租赁数据集并对季节的部分依赖图感兴趣，我们会得到 4 个数字，每个季节一个。要计算“夏季”的值，我们将所有数据实例的季节替换为“夏季”并对预测进行平均。
