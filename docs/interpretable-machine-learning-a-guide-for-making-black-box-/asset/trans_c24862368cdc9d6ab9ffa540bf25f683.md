## 6.4.2 影响函数

你：我想知道一个训练实例对特定预测有多大影响。

研究者：你可以删除该训练实例，重新训练模型，并测量预测的差异。

你：太好了！但你有没有一种不需要重新训练就能行的方法？这太耗时了。

研究者：你是否拥有一个关于其参数两次可微的损失函数的模型？

你：我使用了逻辑损失训练了一个神经网络。所以是的。

研究者：那么你可以使用影响函数来近似该实例对模型参数和预测的影响。影响函数是衡量模型参数或预测在多大程度上依赖于某个训练实例的指标。该方法不是删除实例，而是通过一个非常小的步长在损失中加权该实例。这种方法涉及使用梯度和 Hessian 矩阵来近似当前模型参数周围的损失。损失加权与删除实例类似。

你：太好了，这就是我要找的！

Koh 和 Liang（2017）建议使用影响函数——一种稳健统计方法——来衡量实例如何影响模型参数或预测。与删除诊断类似，影响函数将模型参数和预测追溯到负责的训练实例。然而，该方法不是删除训练实例，而是近似当实例在经验风险（训练数据上的损失之和）中被加权时模型会发生多大变化。

影响函数方法需要访问模型参数的损失梯度，这仅适用于部分机器学习模型。逻辑回归、神经网络和支持向量机符合条件，而基于树的方法（如随机森林）则不符合。影响函数有助于理解模型行为、调试模型并检测数据集中的错误。

以下部分解释了影响函数背后的直觉和数学。

### 影响函数背后的数学

影响函数背后的关键思想是，以无穷小的步长 (\epsilon) 加权训练实例的损失，从而得到新的模型参数：

```
\hat{\theta}_{-\{\epsilon,z\}}=arg\min_{\theta}\{\frac{1}{n}\sum_{i=1}^{n} L(z_i,\theta)+\epsilon L(z,\theta)\}
```

其中 (\hat{\theta}) 是模型参数向量，(\hat{\theta}_{-\{\epsilon,z\}}) 是将 z 加权一个非常小的数值 (\epsilon) 后的参数向量。L 是训练模型所用的损失函数，(z_i) 是训练数据，z 是我们想要加权以模拟其移除的训练实例。这个公式背后的直觉是：如果我们将训练数据中的某个特定实例 (z_i) 稍微加权 (\epsilon)，并相应地降低其他数据实例的权重，损失会变化多少？为了优化这个新的组合损失，参数向量会是什么样子？参数的影响函数，即将训练实例 z 加权对参数的影响，可以按如下方式计算。

```
I_{\text{up.params}}(z)=\left.\frac{d \hat{\theta}_{-\{\epsilon,z\}}}{d \epsilon}\right|_{\epsilon=0}=-H_{\hat{\theta}}^{-1} \nabla_{\theta} L(z, \hat{\theta})
```

最后的表达式 (\nabla_{\theta} L(z, \hat{\theta})) 是针对加权训练实例的参数损失梯度。梯度是训练实例损失的变化率。它告诉我们当我们稍微改变模型参数 (\hat{\theta}) 时，损失会变化多少。梯度向量中的正项意味着相应模型参数的微小增加会增加损失，负项意味着参数增加会减少损失。第一部分 (H_{\hat{\theta}}^{-1}) 是逆 Hessian 矩阵（损失对模型参数的二阶导数）。Hessian 矩阵是梯度的变化率，或者说作为损失，它是损失变化率的变化率。它可以使用以下公式估计：

```
H_{\theta}=\frac{1}{n}\sum_{i=1}^{n} \nabla^2_{\theta} L(z_i, \theta)
```

更通俗地说：Hessian 矩阵记录了在某一点损失的弯曲程度。Hessian 是一个矩阵而不仅仅是一个向量，因为它描述了损失的曲率，而曲率取决于我们观察的方向。如果参数很多，实际计算 Hessian 矩阵会非常耗时。Koh 和 Liang 提出了一些高效计算的技巧，这超出了本章的范围。上述公式描述的模型参数更新，相当于在估计模型参数周围形成二次展开后，执行一次单步 Newton 迭代。

这个影响函数公式背后有什么直觉？该公式来自围绕参数 (\hat{\theta}) 形成二次展开。这意味着我们实际上不知道，或者计算实例 z 被移除/加权时损失究竟如何变化太复杂了。我们使用当前模型参数设置处的陡峭程度（= 梯度）和曲率（= Hessian 矩阵）信息来局部近似该函数。有了这个损失近似，我们可以计算如果加权实例 z，新的参数大约会是什么样子：

```
\hat{\theta}_{-\{z\}}\approx\hat{\theta}-\frac{1}{n} I_{\text{up.params}}(z)
```

近似参数向量基本上是原始参数减去 z 的损失梯度（因为我们想要降低损失），由曲率缩放（= 乘以逆 Hessian 矩阵）并由 1/n 缩放，因为这是单个训练实例的权重。

下图展示了加权的工作原理。x 轴显示 (\theta) 参数的值，y 轴显示加权实例 z 对应的损失值。这里的模型参数仅为 1 维，以便演示，但实际中通常是高维的。我们只朝着实例 z 损失改善的方向移动 1/n。我们不知道删除 z 时损失会真正如何变化，但利用损失的一阶和二阶导数，我们在当前模型参数周围创建这个二次近似，并假设实际损失的表现就是这样。
