图 5.48：函数 (h_x) 将联盟映射到有效实例。对于存在特征 (1)，(h_x) 映射到 x 的特征值。对于缺失特征 (0)，(h_x) 映射到随机采样的数据实例的值。

\(f(h_x(z'))=E_{X_C}[f(x)]\)

从边际分布采样意味着忽略存在特征和缺失特征之间的依赖结构。因此 KernelSHAP 与所有基于排列的解释方法存在相同的问题。估计对不太可能的实例赋予了过大的权重。结果可能变得不可靠。但从边际分布采样是必要的。如果缺失特征值是从条件分布中采样的，那么得到的值就不再是 Shapley 值。得到的值将违反 Shapley 的虚拟元素（Dummy）公理，该公理指出，对结果不做出贡献的特征应具有零的 Shapley 值。

与 LIME 的最大区别在于回归模型中实例的加权方式。LIME 根据实例与原始实例的接近程度对实例进行加权。联盟向量中 0 越多，LIME 中的权重越小。SHAP 根据联盟在 Shapley 值估计中将获得的权重对采样实例进行加权。小型联盟（少量 1）和大型联盟（即大量 1）获得最大的权重。其背后的直觉是：如果我们能孤立地研究特征的效果，我们就能最多地了解单个特征。如果联盟由单个特征组成，我们可以了解该特征对预测的孤立主效应。如果联盟由除一个特征外的所有特征组成，我们可以了解该特征的总效应（主效应加上特征交互）。如果联盟由一半特征组成，我们对单个特征的贡献了解甚少，因为存在许多包含一半特征的可能联盟。为了实现符合 Shapley 的加权，Lundberg 等人提出了 SHAP 内核：

```
{\pi_{i-\{x\}}(z')=\frac{1}{\binom{M-1}{|z'|}}}
```

这里，M 是最大联盟大小，|\{z'\}| 是实例 z' 中存在特征的数量。Lundberg 和 Lee 表明，使用该内核权重的线性回归会得出 Shapley 值。如果在联盟数据上将 SHAP 内核与 LIME 结合使用，LIME 也将估计 Shapley 值！

我们可以对联盟采样稍微聪明一些：最小和最大的联盟占据了大部分权重。通过使用部分采样预算 K 来包含这些高权重联盟，而不是盲目采样，我们可以获得更好的 Shapley 值估计。我们从所有包含 1 个和 M-1 个特征的可能联盟开始，总共 2 乘以 M 个联盟。当还剩下足够预算时（当前预算为 K - 2M），我们可以包含包含两个特征和 M-2 个特征的联盟，以此类推。从剩余的联盟大小中，我们使用重新调整的权重进行采样。

我们有数据、目标和权重。构建加权线性回归模型所需的一切：

```
{\mathbf{g}(z')=\phi_0+\sum_{\{j=1\}^M}\phi_jz_j'}
```

我们通过优化以下损失函数 L 来训练线性模型 g：

```
{\mathbf{L}(f,g,\pi_{i-\{x\}})=\sum_{\{z' \in Z\}}[f(h_{-\mathbf{x}}(z'))-g(z')]^2\pi_{i-\{x\}}(z')]}
```

其中 Z 是训练数据。这是我们通常为线性模型优化的老旧乏味的平方误差之和。模型的估计系数，即 (\phi_j) 的值，就是 Shapley 值。

由于我们处于线性回归设置中，也可以使用标准的回归工具。例如，我们可以添加正则化项以使模型稀疏。如果在损失 L 中添加 L1 惩罚，我们可以创建稀疏解释。（不过我不太确定得到的系数是否仍然是有效的 Shapley 值）

## 5.10.3 TreeSHAP

Lundberg 等人（2018）提出了 TreeSHAP，这是一种用于基于树的机器学习模型（如决策树、随机森林和梯度增强树）的 SHAP 变体。TreeSHAP 被引入作为 KernelSHAP 的一种快速、特定于模型的替代方案，但结果表明它可能产生反直觉的特征归属。

TreeSHAP 使用条件期望 \(E_{X_{\setminus S} \mid X_C}(f(x) \mid x_S)\) 而不是边际期望来定义值函数。条件期望的问题是，对预测函数 f 没有影响的特征可能会得到不为零的 TreeSHAP 估计。当特征与实际对预测有影响的另一个特征相关时，可能会出现非零估计。

TreeSHAP 快多少？与精确 KernelSHAP 相比，它将计算复杂度从 \(O(TL2^M)\) 降低到 \(O(TLD^2)\)，其中 T 是树的数量，L 是任何树中最大的叶节点数，D 是任何树的最大深度。

TreeSHAP 使用条件期望 \(E_{X_{\setminus S} \mid X_C}(f(x) \mid x_S)\) 来估计效应。我将为您提供一些直觉，说明如何为单棵树、一个实例 x 和特征子集 S 计算预期预测。如果我们对所有特征进行条件设定——如果 S 是所有特征的集合——那么实例 x 所落入的节点的预测就是预期预测。如果我们不对任何特征进行条件设定——如果 S 为空——我们将使用所有终端节点预测的加权平均值。如果 S 包含一些但不是所有特征，我们将忽略不可达节点的预测。不可达意味着导致该节点的决策路径与 \(x_S\) 中的值矛盾。从剩余的终端节点中，我们按节点大小（即该节点中的训练样本数）对预测进行加权平均。按每个节点的实例数加权的剩余终端节点的平均值，就是给定 S 时 x 的预期预测。问题是，我们必须为特征值的每个可能子集 S 应用此过程。TreeSHAP 在多项式时间内而非指数时间内进行计算。基本思路是同时将所有可能的子集 S 推下树。对于每个决策节点，我们必须跟踪子集的数量。这取决于父节点中的子集和分割特征。例如，当树中的第一个分割基于特征 x3 时，所有包含特征 x3 的子集都会进入一个节点（即 x 所去的节点）。不包含特征 x3 的子集会以较低的权重进入两个节点。不幸的是，不同大小的子集具有不同的权重。算法必须跟踪每个节点中子集的总权重。这使得算法复杂化。有关 TreeSHAP 的详细信息，我参考原始论文。该计算可以扩展到更多树：得益于 Shapley 值的可加性属性，树集成的 Shapley 值是各个单棵树 Shapley 值的（加权）平均值。

接下来，我们将查看 SHAP 解释的实际应用。
