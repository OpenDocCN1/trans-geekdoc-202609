图 6.3: Szegedy et al. (2013) 的 AlexNet 对抗样本。左列的所有图像都被正确分类。中间列显示添加到图像上的（放大的）误差，以生成右列的图像，这些图像都被（错误地）分类为"鸵鸟"。"神经网络的有趣特性"，Szegedy et al. 图 5，CC-BY 3.0。

这些对抗样本是通过最小化关于 r 的以下函数生成的：

```
|loss(\hat{f}(x+r), l) + c||r||
```

在这个公式中，x 是一张图像（表示为像素向量），r 是创建对抗图像的像素更改（x+r 生成一张新图像），l 是期望的结果类别，参数 c 用于平衡图像之间的距离和预测之间的距离。第一项是对抗示例的预测结果与期望类别 l 之间的距离，第二项衡量对抗示例与原始图像之间的距离。此表述几乎与用于生成反事实解释的损失函数相同。对 r 有其他约束，以便像素值保持在 0 和 1 之间。作者建议使用 box-constrained L-BFGS 来解决此优化问题，这是一种使用梯度的优化算法。

## 受干扰的熊猫：快速梯度符号方法

Goodfellow et al. (2014)^64 发明了用于生成对抗图像的快速梯度符号方法。梯度符号方法使用底层模型的梯度来查找对抗示例。原始图像 x 通过对每个像素添加或减去一个小误差（epsilon）来操纵。是添加还是减去（epsilon）取决于像素的梯度符号是正还是负。沿梯度方向添加误差意味着图像被故意更改，以便模型分类失败。

以下公式描述了快速梯度符号方法的核心：

```
|x' = x + \epsilon \cdot \sign(\nabla_x J(\theta, x, y))|
```

其中，\nabla_x J 是模型损失函数相对于原始输入像素向量 x 的梯度，y 是 x 的真实标签向量，\theta 是模型参数向量。从梯度向量（其长度与输入像素向量相同）中，我们只需要符号：如果增加像素强度会增加损失（模型犯的错误），则梯度符号为正（+1）；如果减少像素强度会增加损失，则梯度符号为负（-1）。当神经网络将输入像素强度和类别得分之间的关系视为线性时，就会出现这种漏洞。特别是，偏好线性的神经网络架构，例如 LSTM、maxout 网络、带有 ReLU 激活单元的网络，或其他线性机器学习算法（如逻辑回归）都容易受到梯度符号方法的影响。攻击是通过外推法进行的。输入像素强度与类别得分之间的线性关系导致对异常值的易受攻击性，即模型可能被通过将像素值移动到数据分布之外的区域而欺骗。我原本预期这些对抗示例会特定于特定的神经网络架构。但事实证明，您可以重用对抗示例来欺骗在相同任务上训练但架构不同的网络。

Goodfellow et al. (2014) 建议将对抗示例添加到训练数据中以学习稳健模型。

## 一只水母……不，等等。一个浴缸：1像素攻击

Goodfellow 及其同事（2014）提出的方法需要更改许多像素，哪怕只是少量更改。但是，如果您只能更改一个像素呢？您能欺骗机器学习模型吗？Su. et al. (2019) 表明，通过更改单个像素确实可以欺骗图像分类器。

![](img/9328bf422a53c0f374079f63527c081f_196_0.png)

图 6.4：通过故意更改单个像素，在 ImageNet 上训练的神经网络可能会被欺骗，预测错误的类别而不是原始类别。

与反事实类似，1像素攻击寻找一个修改后的示例 x'，它与原始图像 x 很接近，但将预测更改为对抗结果。但是，接近度的定义不同：只能更改一个像素。1像素攻击使用微分进化来找出应更改哪个像素以及如何更改。微分进化松弛地受到物种生物进化的启发。一群称为候选解的个体一代接一代地重组，直到找到解决方案。每个候选解编码一个像素修改，并由五个元素的向量表示：x 坐标和 y 坐标以及红色、绿色和蓝色（RGB）值。搜索例如从 400 个候选解（= 像素修改建议）开始，并使用以下公式从父代生成新一代的候选解（子代）：

```
[x_i(g+1) = x_{r1}(g) + F * (x_{r2}(g) - x_{r3}(g))]
```

其中，每个 x_i 是候选解的一个元素（x 坐标、y 坐标、红色、绿色或蓝色之一），g 是当前代，F 是缩放参数（设置为 0.5），r1、r2 和 r3 是不同的随机数。每个新的子代候选解本身也是一个具有位置和颜色五个属性的像素，这些属性中的每一个都是三个随机父代像素的混合物。

如果其中一个候选解是对抗示例（即被分类为错误类别），或者达到用户指定的最大迭代次数，则停止子代的创建。

## 一切都是烤面包机：对抗性补丁

我最喜欢的方法之一将对抗示例带入物理现实。Brown et al. (2017) 设计了一个可打印的标签，可以粘在物体旁边，使其在图像分类器看来像烤面包机。出色的工作！

![](img/9328bf422a53c0f374079f63527c081f_197_0.png)

图 6.5：一张贴纸，导致在 ImageNet 上训练的 VGG16 分类器将香蕉图像归类为烤面包机。Brown et al. (2017) 的作品。

此方法与迄今介绍的对抗示例方法不同，因为要求对抗图像必须非常接近原始图像的限制已被移除。相反，该方法用可以采取任何形状的补丁完全替换图像的一部分。补丁图像在不同背景图像上进行优化，补丁在图像上的位置也不同，有时移动，有时大小或旋转不同，以便补丁在多种情况下都有效。最终，此优化后的图像可以打印并用于在野外欺骗图像分类器。

## 切勿将 3D 打印的海龟带到枪战中——即使你的电脑认为这是个好主意：强健对抗示例

下一种方法实际上是给烤面包机增加了另一个维度：Athalye et al. (2017)67 3D 打印了一只海龟，该海龟从几乎所有可能角度看都被设计成深度神经网络眼中的步枪。是的，你没看错。一个对人类来说像海龟的实体物体，对计算机来说却像步枪！

![](img/9328bf422a53c0f374079f63527c081f_197_1.png)

图 6.6：Athalye et al. (2017) 创建了一个 3D 打印物体，被 TensorFlow 的标准预训练 InceptionV3 分类器识别为步枪。

作者们找到了一种方法，为 2D 分类器创建 3D 对抗示例，该示例对变换（例如旋转海龟、缩放等的所有可能性）具有对抗性。当图像旋转或视角改变时，快速梯度方法等其他方法不再有效。Athalye et al. (2017) 提出了期望超过变换（EOT）算法，这是一种生成对抗示例的方法，即使在图像变换时也有效。EOT 背后的主要思想是跨多种可能的变换优化对抗示例。与最小化对抗示例与原始图像之间的距离不同，EOT 在给定的可能变换选定分布下，将两者之间的期望距离保持在某个阈值以下。变换下的期望距离可以写为：

```
[\mathbb{E}_{t \sim T}[d(t(x'), t(x))]]
```

其中，x 是原始图像，t(x) 是变换后的图像（例如旋转），x' 是对抗示例，t(x') 是其变换版本。除了处理变换分布外，EOT 方法遵循将查找对抗示例表述为优化问题的熟悉模式。我们试图找到一个对抗示例 x'，它最大化在可能变换分布 T 上所选类别 y_{tl}（例如"步枪"）的概率：

```
[\arg\max_{x'} \mathbb{E}_{t \sim T}[\log P(y_{tl}(x'))]]
```

约束是，对抗示例 x' 与原始图像 x 在所有可能变换之间的期望距离保持在某个阈值以下：

```
[\mathbb{E}_{t \sim T}[d(t(x'), t(x))] < \epsilon \text{ and } \epsilon \in [0,1]]
```

我认为我们应该担心这种方法所带来的可能性。其他方法基于对数字图像的操纵。然而，这些 3D 打印的强健对抗示例可以插入任何真实场景，并欺骗计算机错误地分类对象。让我们反过来想：如果有人制造了一把看起来像海龟的步枪会怎样？

## 蒙眼对手：黑盒攻击

想象一下以下场景：我通过 Web API 让你使用我出色的图像分类器。你可以从模型获得预测，但无法访问模型参数。坐在沙发上，你可以发送数据，我的服务会返回相应的分类。大多数对抗攻击不是为这个场景设计的，因为它们需要访问底层深度神经网络的梯度来查找对抗示例。Papernot 和同事（2017）表明，无需内部模型信息且无需访问训练数据即可创建对抗示例。这种（几乎）零知识攻击称为黑盒攻击。

工作原理：

- 1. 先使用少量来自与训练数据相同领域的图像，例如，如果要攻击的分类器是数字分类器，则使用数字图像。需要领域知识，但不需要访问训练数据。
- 2. 从黑盒获取当前图像集的预测结果。
- 3. 在当前图像集上训练代理模型（例如神经网络）。
- 4. 使用启发式方法创建新一组合成图像，该启发式方法检查当前图像集应朝哪个方向操纵像素，以使模型输出具有更大的方差。
- 5. 重复步骤 2 至 4 预定义的 epoch 数量。
- 6. 使用快速梯度方法（或类似方法）为代理模型创建对抗示例。
- 7. 使用对抗示例攻击原始模型。
