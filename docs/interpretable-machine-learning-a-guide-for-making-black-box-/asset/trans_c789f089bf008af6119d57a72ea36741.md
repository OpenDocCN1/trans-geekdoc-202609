

## 7.2.3 Grad-CAM

Grad-CAM为CNN决策提供可视化解释。与其他方法不同，梯度不会一直反向传播回图像，而是（通常）传播到最后一个卷积层，以生成一个粗略的定位图，突出图像的重要区域。

Grad-CAM的全称是Gradient-weighted Class Activation Map。顾名思义，它基于神经网络的梯度。与其他技术一样，Grad-CAM为感兴趣的决策给每个神经元分配一个相关性评分。感兴趣的决策可以是类预测（我们在输出层中找到它），但理论上也可以是神经网络中的任何其他层。Grad-CAM将这些信息反向传播到最后一个卷积层。Grad-CAM可以与不同的CNN一起使用：带有全连接层，用于结构化输出，如图片标题和多任务输出，以及用于强化学习。

让我们从对Grad-CAM的直观考虑开始。Grad-CAM的目标是理解卷积层在图像的哪些部分“查看”某个分类。作为提醒，CNN的第一个卷积层将图像作为输入，并输出编码学习特征的特征映射（参见学习特征章节）。更高级别的卷积层做同样的事情，但以前一个卷积层的特征映射作为输入。为了理解CNN如何做决策，Grad-CAM分析在最后几个卷积层的特征映射中哪些区域被激活。最后一个卷积层中有k个特征映射，我将它们称为A_1, A_2, ..., A_k。我们如何从特征映射中“看到”卷积神经网络是如何做出某个分类的？在第一种方法中，我们可以简单地可视化每个特征映射的原始值，对特征映射求平均，并将其叠加到我们的图像上。这没有帮助，因为特征映射编码了**所有类别**的信息，但我们对特定类别感兴趣。Grad-CAM必须决定最后几个卷积层中k个特征映射中的每一个对我们感兴趣的类别c有多重要。我们必须在对特征映射求平均之前，用梯度对每个特征映射的每个像素进行加权。这给我们提供了一个热图，突出显示对感兴趣的类别产生正面或负面影响的区域。这个热图被送入ReLU函数，这是一种花哨的说法，意思是我们将所有负值设置为零。Grad-CAM使用ReLU函数删除所有负值，理由是我们只对对选定类别c有贡献而不对其他类别有贡献的部分感兴趣。“像素”一词在这里可能具有误导性，因为特征映射比图像小（因为池化单元），但被映射回原始图像。然后我们将Grad-CAM图缩放到[0,1]区间以进行可视化，并将其叠加到原始图像上。

```
[\L^c_{\{Grad-CAM\}} \in \mathbb{R}^{\{u \times v\}} = \underbrace\{\text{ReLU}\}_{\text{Pick positive values}} \left(\sum_{\{k\} \text{ alpha\_k } \wedge c \text{ A}^k \right)]
```

这里，u是宽度，v是解释的高度，c是感兴趣的类别。

- 1. 将输入图像正向传播通过卷积神经网络。
- 2. 获取感兴趣类别的原始得分，即softmax层之前神经元的激活值。
- 3. 将所有其他类别的激活设为零。
- 4. 将感兴趣类别的梯度反向传播到完全连接层之前的最后一个卷积层：\(\frac{\delta\{y^c\}}{\delta\{A^k\}}\)。
- 5. 按类别的梯度对每个特征映射“像素”进行加权。索引i和j指宽度和高度维度：\(\alpha_k^c = \overbrace\{\frac{1}{Z} \sum_{\{i\}} \sum_{\{j\}}\}^c \{ \text{global average pooling\} } \underbrace\{ \frac{\delta y \wedge c}{\delta A_{\{ij\}} \wedge k} \} \{ \text{gradients via backprop\} }\) 这意味着梯度被全局池化。
- 6. 计算特征映射的平均值，按像素按梯度加权。
- 7. 对平均特征映射应用ReLU。
- 8. 为了可视化：将值缩放到0到1之间的区间。放大图像并将其叠加到原始图像上。
- 9. Guided Grad-CAM的额外步骤：将热图与引导式反向传播相乘。

## 7.2.4 Guided Grad-CAM

从Grad-CAM的描述中你可以推测，定位非常粗略，因为最后几个卷积特征映射的分辨率远低于输入图像。相比之下，其他归因技术会一直反向传播到输入像素。因此，它们更详细，可以显示对预测贡献最大的单个边缘或斑点。两种方法的融合称为Guided Grad-CAM。而且它非常简单。你为图像同时计算Grad-CAM解释和另一种归因方法（例如Vanilla Gradient）的解释。然后使用双线性插值对Grad-CAM输出进行上采样，然后将两个图逐元素相乘。Grad-CAM就像一个透镜，专注于像素级归因图的特定部分。

## 7.2.5 SmoothGrad

Smilkov et al. 2017^84提出的SmoothGrad的想法是通过添加噪声并对这些人工噪声梯度求平均，使基于梯度的解释不那么嘈杂。SmoothGrad不是一种独立的解释方法，而是任何基于梯度的解释方法的扩展。

SmoothGrad的工作原理如下：

- 1. 通过向感兴趣的图像添加噪声生成多个版本。
- 2. 为所有图像创建像素归因图。
- 3. 对像素归因图求平均。

是的，就这么简单。为什么这有效？理论是导数在小尺度上波动很大。神经网络在训练期间没有动力保持梯度平滑，它们的目标是正确分类图像。对多个图求平均“平滑了”这些波动：

```
|R_{sg}(x) = \frac{1}{n} \sum_{i=1}^n R(x+g_i),|
```

这里，(g_i \sim N(0, \sigma^2))是从高斯分布中采样的噪声向量。“理想”噪声水平取决于输入图像和网络。作者建议噪声水平为10%-20%，这意味着(\frac{1}{n}\sum_{i=1}^n R(x+g_i),|)应在0.1和0.2之间。极限(x_min)和(x_max)指图像的最小和最大像素值。另一个参数是样本数n，建议使用n = 50，因为超过该值收益递减。
