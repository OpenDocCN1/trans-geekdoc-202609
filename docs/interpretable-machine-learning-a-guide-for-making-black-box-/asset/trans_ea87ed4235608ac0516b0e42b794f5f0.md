## 1.2 什么是机器学习？

机器学习是一组计算机用来根据数据进行预测或改进行为的方法。

例如，要预测房子的价值，计算机会从过去的房屋销售中学习模式。本书关注的是监督机器学习，它涵盖了所有这类预测问题：我们拥有已知目标结果的数据集（例如过去的房屋价格），并希望学习预测新数据的结果。监督学习不包括聚类任务（= 无监督学习）——我们没有特定的目标结果，只是想找到数据点的簇。也不包括增强学习等内容——代理通过在环境中行动（例如计算机玩俄罗斯方块）来学习优化某种奖励。监督学习的目标是学习一个预测模型，将数据的特征（例如房屋大小、位置、楼层类型……）映射到输出（例如房屋价格）。如果输出是类别型的，该任务称为分类；如果是数值型的，则称为回归。机器学习算法通过估计参数（例如权重）或学习结构（例如树）来学习模型。算法由一个被最小化的得分或损失函数来指导。在房屋价值的例子中，机器将估计的房价与预测房价之间的差异最小化。训练有素的机器学习模型随后可用于对新实例进行预测。

房价估算、产品推荐、街道标志检测、信用违约预测和欺诈检测：所有这些示例的共同点是它们都可以通过机器学习解决。任务不同，但方法相同：步骤 1：数据收集：越多越好。数据必须包含你想要预测的结果以及用于预测的附加信息。对于街道标志检测器（“图像中是否有街道标志？”），你会收集街道图像，并标记是否可见街道标志。对于信用违约预测器，你需要关于实际贷款的历史数据、客户是否违约的信息，以及有助于预测的数据，例如收入、过去的信用违约等。对于自动房屋估值程序，你可以收集过去房屋销售的数据以及房地产信息，如大小、位置等。步骤 2：将这些信息输入机器学习算法，生成标志检测模型、信用评级模型或房屋估值器。步骤 3：使用模型处理新数据。将模型集成到产品或流程中，例如自动驾驶汽车、信贷申请流程或房地产市场网站。

机器在许多任务中都超越了人类，例如下棋（或者最近的围棋）或预测天气。即使机器在某项任务中与人类一样好或稍差，在速度、可重复性和可扩展性方面仍有巨大优势。一旦实现的机器学习模型完成任务的速度远快于人类，能可靠地提供一致的结果，并且可以无限复制。在另一台机器上复制机器学习模型又快又便宜。训练一个人类完成一项任务可能需要数十年（尤其是在他们年轻时）并且成本非常高。使用机器学习的一个主要缺点是，关于数据和机器解决的任务的洞察力隐藏在越来越复杂的模型中。你需要数百万个数字来描述深度神经网络，并且无法完全理解模型。其他模型，例如随机森林，由数百个决策树组成，它们“投票”来进行预测。要了解决策是如何做出的，你必须查看每棵树的投票和结构。不管你多聪明或工作记忆多好，这都行不通。表现最好的模型通常是多个模型的混合（也称为集成），即使每个单一模型可以解释，它们也无法解释。如果你只关注性能，你会自动得到越来越不透明的模型。只需看看 kaggle.com 机器学习竞赛平台上获胜者的采访：获胜模型大多是模型集成，或者非常复杂的模型，如提升树或深度神经网络。

## 1.3 术语

为了避免因歧义造成混淆，以下是本书中使用的术语定义：

一个 **算法** 是机器为实现特定目标所遵循的一组规则。算法可以被视为一种配方，定义了输入、输出以及从输入到输出所需的所有步骤。烹饪食谱是算法，其中原料是输入，烹饪好的食物是输出，而准备和烹饪步骤是算法指令。

**机器学习** 是一组允许计算机从数据中学习以进行并改进预测（例如癌症、每周销售额、信用违约）的方法。机器学习是从“正常编程”（必须将所有指令明确给计算机）向“间接编程”（通过提供数据来进行）的范式转变。

![](img/9328bf422a53c0f374079f63527c081f_14_0.png)

一个 **学习器** 或 **机器学习算法** 是用于从数据中学习机器学习模型的程序。另一个名称是“诱导器”（例如“树诱导器”）。

一个 **机器学习模型** 是学习得到的、将输入映射到预测的程序。这可以是线性模型或神经网络的一组权重。对于这个不太具体的单词“model”，其他名称有“预测器”，或者取决于任务的“分类器”或“回归模型”。在公式中，训练好的机器学习模型称为 \hat{y} 或 \hat{f}(x)。

![](img/9328bf422a53c0f374079f63527c081f_14_1.png)

图 1.1：学习器从带标签的训练数据中学习模型。该模型用于进行预测。

一个 **黑箱模型** 是不揭示其内部机制的系统。在机器学习中，“黑箱”描述的是无法通过查看其参数来理解的模型（例如神经网络）。黑箱的对立面有时被称为 **白盒**，在本书中称为可解释模型。与模型无关的可解释性方法将机器学习模型视为黑箱，即使它们并非如此。
