
## 作者序

这本书最初是我在临床研究担任统计学家时的一个业余项目。我每周工作4天，在我的"休息日"里，我会做业余项目。最终，可解释机器学习成为我的业余项目之一。起初我并没有写书的打算。相反，我只是对可解释机器学习感兴趣，并寻找好的学习资源。考虑到机器学习的成功和可解释性的重要性，我原本以为会有大量关于此主题的书籍和教程。但我只找到了相关的研究论文和散布在互联网上的几篇博客文章，却没有一本好的概览著作。没有书，没有教程，没有概览论文，什么都没有。这个空白激励我开始写这本书。最终，我写成了自己希望在开始学习可解释机器学习时就能找到的那本书。我写这本书的意图有两个：自我学习，并将这些新知识与他人分享。

我获得了德国慕尼黑大学（LMU Munich）的统计学学士和硕士学位。我关于机器学习的大部分知识是通过在线课程、竞赛、业余项目和专业活动自学的。我的统计学背景是进入机器学习领域的绝佳基础，尤其是对于可解释性而言。在统计学中，一个主要的重点是构建可解释的回归模型。完成统计学硕士学位后，我决定不攻读博士学位，因为我不喜欢写硕士论文。写作让我感到过于紧张。因此，我在一家金融科技初创公司担任数据科学家，并在临床研究担任统计学家。在行业工作了三年后，我开始写这本书，几个月后我开始了可解释机器学习的博士学位研究。通过写这本书，我重新找回了写作的乐趣，这帮助我培养了对研究的热情。

本书介绍了许多可解释机器学习的技术。在前几章中，我介绍了可解释性的概念，并说明为什么可解释性是必要的。书中甚至还有一些短篇故事！本书讨论了解释的不同属性以及人类认为什么是好的解释。然后我们将讨论本质上可解释的机器学习模型，例如回归模型和决策树。本书的主要焦点是模型无关的可解释性方法。模型无关意味着这些方法可以应用于任何机器学习模型，并且是在模型训练后应用的。与模型的独立性使模型无关的方法非常灵活和强大。有些技术解释个别预测是如何做出的，例如局部可解释模型无关解释（LIME）和Shapley值。其他技术描述了模型在数据集上的平均行为。在这里，我们学习部分依赖图、累积局部效应、置换特征重要性以及许多其他方法。一个特殊的类别是基于示例的方法，它们产生数据点作为解释。反事实解释、原型、有影响力的实例和对抗样本是本书讨论的基于示例的方法。本书最后对可解释机器学习的未来可能是什么样子进行了一些反思。

你不需要从头到尾读完这本书，可以前后跳跃，专注于你最感兴趣的技术。我只建议你从导论和可解释性章节开始。大多数章节遵循相似的结构，并专注于一种解释方法。第一段总结了该方法。然后我试图在不依赖数学公式的情况下直观地解释该方法。然后我们查看该方法的理论，以深入了解其工作原理。这里你无法避开，因为理论将包含公式。我相信，新方法最好通过示例来理解。因此，每种方法都应用于真实数据。有人说统计学家是非常挑剔的人。对我来说，这是真的，因为每一章都包含关于相应解释方法的优缺点的批判性讨论。本书不是对这些方法的宣传，而应该帮助你决定某种方法是否适合你的应用。在每章的最后一节，将讨论可用的软件实现。

机器学习得到了研究和工业界许多人的高度关注。有时机器学习在媒体上被过度炒作，但有许多真实且有影响力的应用。机器学习是产品、研究和自动化的强大技术。今天，机器学习被用于例如检测欺诈性金融交易、推荐观看的电影和分类图像。机器学习模型是否可解释通常至关重要。可解释性帮助开发者调试和改进模型，建立对模型的信任，证明模型预测的合理性，并获得洞察。对机器学习可解释性需求的增加是机器学习使用增加的自然结果。本书已经成为许多人的宝贵资源。教学指导者使用本书向学生介绍可解释机器学习的概念。我收到了各种硕士和博士生的电子邮件，他们告诉我本书是他们论文的起点和最重要的参考。本书帮助了生态学、金融学、心理学等领域的应用研究人员，他们使用机器学习来理解自己的数据。工业界的数据科学家告诉我，他们在工作中使用《可解释机器学习》一书，并向同事推荐它。我很高兴许多人能从本书中受益，并成为模型解释方面的专家。

我会推荐这本书给想要了解如何使其机器学习模型更具可解释性的技术概览的从业者。它也推荐给对该主题感兴趣的学生和研究人员（以及任何其他人）。为了从本书中受益，你应该已经具备机器学习的基本理解。你还应具备大学入学水平的数学理解，才能跟上本书中的理论和公式。然而，在没有数学的情况下，也应该能够理解每章开头对方法的直观描述。

希望你喜欢这本书！

## 第1章 导论

本书向你解释如何使（监督）机器学习模型可解释。各章包含一些数学公式，但即使没有公式，你也应该能够理解方法背后的思想。本书不是为那些想从零开始学习机器学习的人准备的。如果你是机器学习新手，有很多书籍和其他资源可以学习基础知识。我推荐 Hastie、Tibshirani 和 Friedman (2009) ¹ 编写的书籍《统计学习方法》，以及 Andrew Ng 在在线学习平台 coursera.com 上的《机器学习》在线课程，以开始学习机器学习。这本书和课程都可以免费获取！

机器学习模型解释方面的新方法以惊人的速度发表。跟上所有发表的内容将是疯狂且根本不可能的。这就是为什么你在这本书中找不到最新颖和花哨的方法，而是既成的方法和机器学习可解释性的基本概念。这些基础为你使机器学习模型可解释做好准备。内化基本概念还能让你更好地理解和评估任何在arxiv.org上发表的关于可解释性的新论文，就在你开始读这本书后的过去5分钟内（我可能在夸大发表速度）。

本书以一些（反乌托邦的）短篇故事开头，这些故事不是理解本书所必需的，但希望能娱乐你并让你思考。然后本书探讨了机器学习可解释性的概念。我们将讨论什么时候可解释性很重要，以及有哪些不同类型的解释。本书中使用的术语可以在术语章节中查阅。大部分解释的模型和方法都使用真实数据示例来呈现，这些示例在数据章节中描述。使机器学习可解释的一种方法是使用可解释模型，例如线性模型或决策树。另一种选择是使用模型无关的解释工具，这些工具可以应用于任何监督机器学习模型。模型无关方法章节讨论了部分依赖图和置换特征重要性等方法。模型无关方法通过更改机器学习模型的输入并测量预测输出的变化来工作。作为解释返回数据实例的模型无关方法在基于示例的解释章节中讨论。所有模型无关方法都可以根据它们是解释所有数据实例的全局模型行为还是个别预测进行进一步区分。以下方法解释模型的整体行为：部分依赖图、累积局部效应、特征交互、特征重要性、全局代理模型以及原型与批评。要解释个别预测，我们有局部代理模型、Shapley值解释、反事实解释（及其密切相关的：对抗样本）。有些方法可用于解释全局模型行为和个别预测的两个方面：个别条件期望和有影响力的实例。

本书以对可解释机器学习未来可能是什么样子的乐观展望结束。

你可以从头到尾读完本书，也可以直接跳转到你感兴趣的方法。

希望你阅读愉快！
