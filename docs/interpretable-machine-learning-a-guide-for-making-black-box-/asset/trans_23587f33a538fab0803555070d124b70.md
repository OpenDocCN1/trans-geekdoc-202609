### 4.2.2 理论

分类的解决方案是逻辑回归。与其拟合直线或超平面，不如说逻辑回归模型使用逻辑函数将线性方程的输出压缩在 0 和 1 之间。逻辑函数定义如下：

```
\text{logistic}\{\eta\} = \frac{1}{1+\exp(-\eta)}
```

它看起来如下：

![](img/9328bf422a53c0f374079f63527c081f_49_0.png)

图 4.6：逻辑函数。它输出 0 到 1 之间的数字。当输入为 0 时，输出为 0.5。

从线性回归到逻辑回归的步骤相当直接。在线性回归模型中，我们使用线性方程建模了结果与特征之间的关系：

```
\hat{y}^{(i)} = \beta_0 + \beta_1 x^{(i)}
```

对于分类，我们更喜欢 0 到 1 之间的概率，因此将方程右侧包装到逻辑函数中。这强制输出仅采用 0 到 1 之间的值。

```
P(y^{(i)}=1) = \frac{1}{1+\exp(-(\beta_0 + \beta_1 x^{(i)} + \dots + \beta_p x^{(i)}_p))}
```

让我们再次回顾肿瘤大小示例。但这次我们不使用线性回归模型，而是使用逻辑回归模型：

使用逻辑回归分类效果更好，在两种情况下都可以使用 0.5 作为阈值。加入更多点并不真正影响估计曲线。

### 4.2.3 解释

逻辑回归中权重的解释与线性回归中权重的解释不同，因为逻辑回归的结果是 0 到 1 之间的概率。权重不再以线性方式影响概率。加权和由逻辑函数转换为概率。因此，我们需要重新表述解释用的公式，使得公式右侧仅包含线性项。

```
\log\left(\frac{P(y=1)}{1-P(y=1)}\right) = \log\left(\frac{P(y=1)}{P(y=0)}\right) = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p
```

我们将 log() 函数中的项称为“优势比”（事件发生概率除以事件不发生概率），对其取对数后称为对数优势比。

该公式表明逻辑回归模型是对数优势比的线性模型。太好了！但这听起来并没有帮助！稍微调整一下各项后，你可以弄清楚当某个特征（x_j）变化 1 个单位时预测如何变化。为此，我们可以先对等式两边应用 exp() 函数：

```
\frac{P(y=1)}{1-P(y=1)} = \text{odds} = \exp(\beta_0 + \beta_1 x_1 + \dots + \beta_p x_p)
```

然后我们比较将某个特征值增加 1 时会发生什么。但我们不是看差异，而是看两个预测值的比率：

```
\frac{\text{odds}_{x_{j+1}}}{\text{odds}} = \frac{\exp(\beta_0 + \beta_1 x_1 + \dots + \beta_j(x_j+1) + \dots + \beta_p x_p)}{\exp(\beta_0 + \beta_1 x_1 + \dots + \beta_j x_j + \dots + \beta_p x_p)}
```

我们应用以下规则：

```
\frac{\exp(a)}{\exp(b)} = \exp(a-b)
```

并且我们消去许多项：

```
\frac{\text{odds}_{x_{j+1}}}{\text{odds}} = \exp(\beta_j(x_j+1) - \beta_j x_j) = \exp(\beta_j)
```

最终，我们得到一个简单的形式，即特征权重的 exp() 值。特征变化一个单位会使优势比（乘法）变化 \(\exp(\beta_j)\) 倍。我们也可以这样解释：(x_j) 变化一个单位会使对数优势比增加相应权重的值。大多数人解释优势比，因为思考某个事物的 log() 已知对大脑来说比较困难。解释优势比本身也需要一些适应。例如，如果你的优势比为 2，这意味着 y=1 的概率是 y=0 的两倍。如果你有一个权重（= 对数优势比）为 0.7，那么将相应特征增加一个单位会将优势比乘以 exp(0.7)（约等于 2），优势比变为 4。但通常你不需要处理优势比，而只将权重解释为优势比。因为实际上计算优势比需要为每个特征设定一个值，只有当你想查看数据集中某个特定实例时才有意义。

以下是不同特征类型的逻辑回归模型的解释：

- 数值特征：如果将特征 (x_j) 的值增加一个单位，估计优势比会变化 \(\exp(\beta_j)\) 倍
- 二元分类特征：特征的两个值中有一个是参考类别（在某些语言中，是编码为 0 的那个）。将特征 (x_j) 从参考类别更改为另一个类别会使估计优势比变化 \(\exp(\beta_j)\) 倍。

包含多于两个类别的分类特征：处理多类别的一个解决方案是独热编码，即每个类别有自己的列。对于具有 L 个类别的分类特征，你只需要 L-1 列，否则会过度参数化。第 L 个类别则是参考类别。你可以使用任何可用于线性回归的其他编码。然后每个类别的解释等同于二元特征的解释。

截距 (\(\beta_0\))：当所有数值特征为零且分类特征处于参考类别时，估计优势比为 \(\exp(\beta_0)\)。截距权重的解释通常不相关。

我们使用逻辑回归模型根据某些风险因素预测宫颈癌。下表显示了估计权重、相关优势比以及估计值的标准误。

表 4.1：在宫颈癌数据集上拟合逻辑回归模型的结果。显示了模型中使用的特征、它们的估计权重和相应的优势比，以及估计权重的标准误。

| | 权重 | 优势比 | 标准误 |

数值特征（“确诊性传播疾病数量”）的解释：当所有其他特征保持不变时，确诊性传播疾病（性传播疾病）数量的增加会使癌症与非癌症的优势比变化（增加）2.27 倍。请记住，相关性不代表因果关系。

分类特征（“激素避孕药 是/否”）的解释：与未使用激素避孕药的女性相比，使用激素避孕药的女性患癌症与非癌症的优势比低 0.89 倍，前提是所有其他特征保持不变。

与线性模型一样，解释总是伴随着“所有其他特征保持不变”的条件。

### 4.2.5 优点和缺点

线性回归模型的许多优缺点也适用于逻辑回归模型。逻辑回归已被许多人广泛使用，但它在表达能力受限（例如，交互项必须手动添加）方面存在困难，且其他模型可能具有更好的预测性能。

逻辑回归模型的另一个缺点是，解释更加困难，因为权重的解释是乘法而非加法。

逻辑回归可能会遭受完全分离问题。如果存在一个可以完美分离两个类别的特征，逻辑回归模型将无法再进行训练。这是因为该特征的权重将不收敛，因为最优权重将是无穷大。这确实有点不幸，因为这样的特征非常有用。但如果你有一个简单的规则可以分离两个类别，就不需要机器学习了。完全分离问题可以通过引入权重惩罚或定义权重的先验概率分布来解决。
