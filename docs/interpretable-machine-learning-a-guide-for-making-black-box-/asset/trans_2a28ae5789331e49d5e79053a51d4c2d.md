

## 广义可加模型 (GAMs)

为什么不“简单地”允许（广义）线性模型学习非线性关系？这就是 GAMs 的背后动机。GAMs 放宽了关系必须是简单加权和的限制，而是假设结果可以由每个特征的任意函数之和来建模。从数学上看，GAM 中的关系如下：

```
g(E_Y(Y|x)) = β_0 + f_1(x_1) + f_2(x_2) + ... + f_p(x_p)
```

该公式与 GLM 公式类似，区别在于线性项（β_j x_j）被更灵活的函数（f_j(x_j)）所取代。GAM 的核心仍然是特征效应之和，但你可以选择允许某些特征与输出之间存在非线性关系。线性效应也被该框架涵盖，因为对于需要线性处理的特征，你可以将其 f_j(x_j) 仅限制为 x_j β_j 的形式。

最大的问题是如何学习非线性函数。答案被称为“样条”或“样条函数”。样条是可以组合起来以近似任意函数的函数。有点像堆叠乐高积木来构建更复杂的东西。定义这些样条函数的方法有很多，令人困惑。如果你有兴趣了解定义样条的所有方法，我祝你旅途顺利。我在这里不会深入细节，只是要建立直觉。对我个人理解样条帮助最大的是可视化单个样条函数，并查看数据矩阵是如何修改的。例如，要用样条建模温度，我们从数据中删除温度特征，并用比如说 4 列来替换它，每列代表一个样条函数。通常你会有更多的样条函数，我只是为了说明目的才减少了数量。这些新样条特征中每个实例的值取决于该实例的温度值。连同所有线性效应一起，GAM 然后也估计这些样条权重。GAMs 还为权重引入了一个惩罚项，以使它们保持接近零。这有效地减少了样条的灵活性并减少了过拟合。然后通过交叉验证调谐一个常用于控制曲线灵活性的平滑度参数。忽略惩罚项，用样条进行非线性建模就是花哨的特征工程。

### 4.3.4 优点

线性模型的所有这些扩展本身都像是一个小宇宙。无论你在线性模型中遇到什么问题，可能都能找到一个修复它的扩展。

大多数方法已使用数十年。例如，GAMs 几乎有 30 年的历史。许多来自工业界的研究人员和从业者对线性模型非常有经验，这些方法在许多社区中被接受为建模的现状。

除了进行预测之外，你还可以使用这些模型进行推断，对数据得出结论——前提是模型假设未被违反。你可以获得权重的置信区间、显著性检验、预测区间等等。

统计软件通常具有非常好的界面来拟合 GLMs、GAMs 和更多特殊的线性模型。

许多机器学习模型的不透明性来自：1) 缺乏稀疏性，这意味着使用了许多特征；2) 以非线性方式处理的特征，这意味着需要不止一个权重来描述效应；3) 特征之间交互的建模。假设线性模型具有高度可解释性但通常对现实欠拟合，本章描述的扩展提供了一种平稳过渡到更灵活模型的好方法，同时保留了一些可解释性。

### 4.3.5 缺点

作为优点，我说过线性模型生活在自己的宇宙中。你可以扩展简单线性模型的**方式数量之多令人难以承受**，不仅如此，初学者也是如此。实际上，存在多个平行宇宙，因为许多研究人员和从业者社区为多少有点相同的方法有自己的名称，这可能非常令人困惑。

对线性模型的大多数修改使模型**可解释性降低**。任何不是恒等函数的链接函数（在 GLM 中）都会使解释复杂化；交互作用也会使解释复杂化；非线性特征效应要么不够直观（如对数变换），要么无法再用单个数字总结（例如样条函数）。

GLMs、GAMs 等等**依赖于**关于数据生成过程的**假设**。如果这些假设被违反，权重的解释就不再有效。

随机森林或梯度树提升等基于树的集成在许多情况下的性能优于最复杂的线性模型。这部分是我自己的经验，部分来自 kaggle.com 等平台上获胜模型的观察。

### 4.3.6 软件

本章的所有示例都是使用 R 语言创建的。对于 GAMs，使用了 `gam` 包，但还有许多其他包。R 拥有难以置信数量的包来扩展线性回归模型。无任何其他分析语言可比拟，R 是每种可以想象的线性回归模型扩展的家园。你会发现例如 GAMs 在 Python 中的实现（如 `pyGAM`），但这些实现不够成熟。

### 4.3.7 更多扩展

如所承诺，以下是你可能遇到的线性模型问题列表，以及你可以复制并粘贴到喜欢的搜索引擎中的解决方案名称。

我的数据违反了独立同分布（iid）的假设。
例如，对同一患者进行重复测量。
搜索 **混合模型** 或 **广义估计方程**。

我的模型存在异方差误差。
例如，在预测房屋价值时，昂贵房屋的模型误差通常更高，这违反了线性模型的同方差性。
搜索 **稳健回归**。

我的数据中有强烈影响模型的异常值。
搜索 **稳健回归**。

我想要预测事件发生前的时间。
时间至事件数据通常伴随着删失测量，这意味着对于某些实例来说，没有足够的时间来观察事件。例如，一家公司想要预测其制冰机的故障，但只有两年的数据。有些机器在两年后仍然完好，但以后可能会故障。
搜索 **参数生存模型**、**Cox 回归**、**生存分析**。

我想要预测的结果是一个类别。
如果结果有两个类别，请使用 **逻辑回归模型**，它对类别的概率进行建模。
如果你有更多类别，请搜索 **多项式回归**。
逻辑回归和多项式回归都是 GLMs。
