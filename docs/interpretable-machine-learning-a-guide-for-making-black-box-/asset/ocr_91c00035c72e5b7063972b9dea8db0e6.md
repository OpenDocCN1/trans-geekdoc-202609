# 5.5.6 Software and Alternatives

The iml R package was used for the examples. The R packages DALEX and vip, as well as the Python library alibi, scikit-learn and rfpimp, also implement model-agnostic permutation feature importance.

An algorithm called PIMP adapts the feature importance algorithm to provide p-values for the importances.
