(5.6) `dS_t = μS_t dt + σS_t dw_t, t ∈ [0, T]`

其中 `S_t` 是时刻 `t` 的股价，`μ` 是常数漂移项，`σ` 是常数波动率，`{w_t}` 是标准布朗运动，且对任意 `t ≥ 0` 有 `w_t ~ N(0, t)`。随机分析的一个基本定理指出，由（5.6）生成的样本路径 `{S_t : t ≥ 0}` 几乎处处不可微，因此我们不能使用通常的黎曼积分来解释股价演化的无穷小动态。实际上，（5.6）是一类称为随机微分方程（SDEs）的典型示例。为了求解它，我们需要一套针对这类随机函数微积分的链式法则：即著名的 Itô's lemma。这条链式法则与普通的 Newton–Leibniz 链式法则不同，因为我们现在处理的是随机函数。
