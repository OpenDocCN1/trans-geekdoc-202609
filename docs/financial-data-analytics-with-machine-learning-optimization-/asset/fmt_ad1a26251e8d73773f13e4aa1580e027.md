Therefore, we aim to describe the key message contained in `yᵢ` by not more than `T` key terms from the dictionary of `d₁, d₂, …, dₖ`. `K`‐SVD can be regarded as a generalized `K`‐means clustering problem because the problem degenerates to the latter if `T = 1`, or more precisely, `||xᵢ||₀ = 1`; indeed, in `K`‐means clustering, (i) the observed matrix `Y ∈ ℝ^(p×n)` is the transpose of the data matrix (with features); (ii) the dictionary matrix `D = (c₁, …, cₖ) ∈ ℝ^(p×K)`, where `cₖ ∈ ℝᵖ` is the `k`‐th centroid; and (iii) the sparse coefficient matrix `X = (x₁, …, xₙ) ∈ ℝ^(K×n)`, where `xᵢⱼ` takes the value of 1 if the predicted label of `yᵢ` is Class `j` or is equal to zero otherwise, for `i = 1, …, n` and `j = 1, …, K`, such that `||xᵢ||₀ = 1`.
