

4. 2b). **M-step**: 为了最大化 `Q` 关于 `μ_m` 和 `π_m`，其中 `m = 1, ..., M`，且需满足约束条件 `∑_{m=1}^{M} π_m = 1`，我们需要考虑以下拉格朗日（函数）：

`Q_λ = Q + λ(∑_{m=1}^{M} π_m - 1).`

对 `Q_λ` 关于 `μ_{mk}` 进行求导，其中 `m = 1, ..., M`，`k = 1, ..., K`，并将导数设为零，则得到

```
∂Q_λ/∂μ_{mk} = ∑_{i=1}^{n} p_{mi}^{(t)} (x_{ik}/μ_{mk} - (1 - x_{ik})/(1 - μ_{mk})) = 0,
```

这意味着

[(6.13)](#c06.xhtml#R_c06-disp-0020)`μ_{mk} = (∑_{i=1}^{n} p_{mi}^{(t)} x_{ik}) / (∑_{i=1}^{n} p_{mi}^{(t)}).`

另一方面，对 `Q_λ` 关于 `π_m` 进行求导并将导数设为零，则得到

```
∂Q_λ/∂π_m = ∑_{i=1}^{n} p_{mi}^{(t)}/π_m + λ = 0,
```

这意味着

[(6.14)](#c06.xhtml#R_c06-disp-0022)`-λπ_m = ∑_{i=1}^{n} p_{mi}^{(t)}.`
