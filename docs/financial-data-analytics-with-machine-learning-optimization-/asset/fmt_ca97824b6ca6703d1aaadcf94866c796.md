
**Example 8.1** 假设 `L ~ N(μ, σ²)`。通过求解方程 `p = F_L(l) = Φ((l - μ)/σ) = p` 关于 `l`，我们得到 `V@R_L(p) = μ + σ Φ⁻¹(p)`。

**Example 8.2** 假设投资组合的日损失分布 `F_L` 服从均值为 0、标准差为 `$20M` 的正态分布。那么 1 天的 `V@R_L(0.95) = ($20M)(1.645) = 32.9M`，1 天的 `V@R_L(0.99) = ($20M)(2.326) = $46.52M`。如果进一步假设每日损失相互独立，那么 `N` 天期间的损失服从均值为 0、标准差为 `$20√N M` 的正态分布。因此，10 天的 `V@R_L(0.95)` 为 `(√10)($32.9M) = $104.04M`，252 天的 `V@R_L(0.99)` 为 `(√252)($46.52M) = $738.48M`。

V@R 风险度量询问损失会有多严重，而 *Expected Shortfall* (ES) 询问：如果情况变糟，预期损失是多少？从数学上讲，损失变量 `L` 在置信水平 `p` 下的期望短fall `ES_L(p)` 定义为

```
ES_L(p) := (1 / (1 - p)) ∫_p^1 V@R_L(x) dx
```
