

**Phillip Yam** 获得香港大学精算学一等荣誉学士学位及 MPhil 学位。在获得 Croucher Foundation（香港）颁发的两项奖学金支持下，他获得了剑桥大学数学三一部分（Part III）的 MASt（高级研究硕士）学位，数学成绩优异，以及牛津大学数学 DPhil 学位。在攻读研究生学位期间，他获得了剑桥大学数学 E. M. Burnett 奖，以及维也纳大学 Erwin Schrödinger 国际数学与物理研究所的初级研究奖学金。

Phillip 目前是香港中文大学（CUHK）定量金融与风险管理科学跨学科主修课程的联合主任，以及统计学系的正教授。他同时也是 CUHK 科学学院助理院长（教育）及该学院科学教育推广中心的院士。他已获聘为波恩大学豪斯多夫数学研究所的研究员，并担任纽约市哥伦比亚大学统计学系以及德克萨斯大学达拉斯分校 Naveen Jindal 管理学院的访问教授。他在精算学、应用数学、数据分析、工程、金融数学、运营管理和统计学等领域发表了约一百篇期刊论文，并长期担任这些领域多个期刊的编委。与 Alain Bensoussan 和 Jens Frehse 合著了关于平均场博弈与平均场类型控制理论的第一本专著。他的研究项目“Comonotone-independence Bayes Classifier (CIBer)”在 2023 年第 48 日内瓦国际发明展上获得银牌。除学术研究外，他还为多家金融机构和保险公司提供咨询服务，并在这些行业建立了紧密联系；他的许多学生也在国际投资银行和保险公司工作。

**Kaiser Fan** 在 Phillip Yam 教授的指导下，获得香港中文大学风险管理科学一等荣誉学士学位及 MPhil 学位。作为一名数据科学家，他的研究兴趣包括数据分析和机器学习，尤其是深度学习。他为本书的编程以及许多示例和插图做出了贡献。

# 序言

在金融领域，没有比获取利润更重要的事情，任何引起人们关注的创新都必须至少带来与现有方法同等水平的利润；事实上，这始终是相关课程随时间更新的主要驱动力。例如，随着 1970 年代期权定价和投资组合选择的发展，1980 年代中期至 2000 年代的金融培训大量涉及 Itô 随机微积分和偏微分方程。另一方面，Robert Engle 在 1980 年代初提出了 GARCH 等波动率模型，以更好地估计参数，促进衍生品定价和投资组合管理，各种学术课程迅速跟进，更加注重金融计量经济学。1994 年 John Nash 获得诺贝尔经济学奖后，博弈论的定量分析，特别是寻找均衡点的数值算法，在学术界获得了更多的重要性和关注；这一趋势延续至今，在过去十多年里，向平均场博弈的语境进一步复杂化和推广。在 2000 年代，随着行为金融学在社会上越来越受到关注，人们希望了解更多实验行为经济学和金融领域的方法，特别是市场如何利用统计方法来理解不同人类行为的影响并据此制定广告策略，这解释了为什么案例研究和基础统计在过去几十年的金融课程中普遍存在。

最近，注意力已转向人工智能。机器学习和深度学习的革命性发展为金融带来了数据分析的新元素，特别是包括 `InsurTech`、`FinTech` 和 `RegTech` 等热门领域。为了跟上这一趋势，课程设计应予以修订，以全面涵盖金融或商业数据分析，而统计学无疑是其中的核心；这正是我们想要撰写本书的原因。在这个领域的少数书籍中，涉及使用 Python 或 `R` 进行标准统计的金融分析以及金融工程中的统计应用，通常侧重于传统统计工具的可能金融应用，但某些实际问题可能需要超越传统统计的工具，我们旨在本书中解决一些相关问题。另一个重要动机无疑是过去十年来学生对我们教学材料的积极反馈，我们已将其作为本书的基础。
