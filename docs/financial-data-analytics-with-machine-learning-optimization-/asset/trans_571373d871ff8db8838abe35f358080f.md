

## (IV) 应用 `K`‐NN 算法

虽然 `K`‐NN 可用于一般分类或回归任务，但它在人脸识别领域应用广泛。通常，给定一个人脸观测值，我们旨在利用训练数据集中 `K` 个最相似人脸的信息，推断该人的某些特征，例如年龄和种族。一般步骤描述如下，假设总共有 `M` 个可能的类别标签：

1. 对于训练数据集中大小为 `n` 的第 `i` 个人脸，提取其预先指定的 `p` 个特征列表的值，这些特征可能由主成分或更广泛的字典学习确定（如[第 14.1 节](#c14.xhtml#c14-sec-0002)中讨论），并将其存储为此人脸的特征向量 `x_i = (x_i1, ..., x_ip)^T`，其中 `i = 1, ..., n`。

2. 识别新添加人脸的特征向量 `x_{n+1}`。

3. 使用以下（带符号的）余弦相似度量作为标准，识别训练集中 `K` 个最近的人脸：`Sim(x_i, x_j) := (sum_{l=1}^p x_il x_jl) / (sqrt(sum_{l=1}^p x_il^2) * sqrt(sum_{l=1}^p x_jl^2)) = (x_i^T x_j) / (||x_i||_2 ||x_j||_2)`，其中该相似度量正好是 `cos(theta_ij)`，`theta_ij` 是 `x_i` 和 `x_j` 之间的夹角。换句话说，我们确定与 `x_{n+1}` 方向最接近的 `K` 个特征向量，并将其存储在集合 `P_K` 中。
