Note that in [Section 9.1](#c09.xhtml#c09-sec-0002), we defined `h_j = (h_1j, ..., h_pj)^⊤` such that `H = (h_ij)` and `y = H^⊤ x̃`; therefore, `x̃ = H y`, or equivalently, `x̃_i = Σ_{j=1}^p h_ij y_j`, for `i = 1, ..., p`. The `i`‐th residual information of `x̃_i`, resulting from using only the first `m` PCs is then:

```
Var(x̃_i - Σ_{j=1}^m h_ij y_j) = Var(Σ_{j=m+1}^p h_ij y_j) = Σ_{j=m+1}^p h_ij^2 λ_j ≤ Σ_{j=m+1}^p λ_j.
```
