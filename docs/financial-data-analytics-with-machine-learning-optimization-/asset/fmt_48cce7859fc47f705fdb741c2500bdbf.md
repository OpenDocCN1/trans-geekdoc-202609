
3. The sample covariance matrix is positive semi-definite. It suffices to show that the SSCP (Sum of Squares and Cross Products) matrix `S ⪰ 0`. Note that `S = Σ(i=1 to n) (x_i - x̄)(x_i - x̄)^⊤ = (X - 1_n x̄^⊤)^⊤ (X - 1_n x̄^⊤) ⪰ 0`, by using Property 16, where `1_n` denotes an `n`-dimensional vector whose all entries are 1.

## (V) Eigenvalues and eigenvectors

For any `p × p` matrix `A`, the determinant `|A - λI_p|` is a polynomial in `λ` of degree `p`. The `p` roots of the polynomial equation `|A - λI_p| = 0`, denoted by `λ_1, ..., λ_p` (counting multiplicity), are called the *eigenvalues* (or *latent roots*) of `A`. As a result, each `A - λ_i I_p` is a singular matrix, hence there exists a nonzero vector `h_i` such that `(A - λ_i I_p)h_i = 0` (or equivalently `Ah_i = λ_i h_i`); `h_i` is called an *eigenvector* of `A` corresponding to `λ_i`. If `h_i` is taken to have a unit length, i.e. `h_i^⊤ h_i = 1`, then it is called a *normalized (unit) eigenvector* of `A`.

Some important properties of eigenvalues and eigenvectors are as follows:

1. If `A` is a real symmetric matrix, then all its eigenvalues are real.
