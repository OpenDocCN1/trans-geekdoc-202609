

4. **Fisher's F-distribution:** 如果 \(x \sim \chi^2_u\) 和 \(y \sim \chi^2_v\) 是独立的，那么 \(\frac{x/u}{y/v} \sim F_{u,v}\)，是一个参数为 \(u\) 和 \(v\)（按顺序）的 \(F\)-分布。此外，如果 \(x_1, \dots, x_m\) 是 iid \(N(\mu_1, \sigma_1^2)\) 且与 \(y_1, \dots, y_n\) 是 iid \(N(\mu_2, \sigma_2^2)\) 独立，那么 \(\frac{s_x^2 / \sigma_1^2}{s_y^2 / \sigma_2^2} = \frac{s_x^2 \sigma_2^2}{\sigma_1^2 s_y^2} \sim F_{m-1,n-1}\)；事实上，由于 \(\frac{(m-1)s_x^2}{\sigma_1^2} \sim \chi^2_{m-1}\) 和 \(\frac{(n-1)s_y^2}{\sigma_2^2} \sim \chi^2_{n-1}\) 是独立的，

\[
\frac{s_x^2 / \sigma_1^2}{s_y^2 / \sigma_2^2} = \frac{s_x^2 \sigma_2^2}{\sigma_1^2 s_y^2} \sim F_{m-1,n-1}.
\]

特别地，如果 \(t \sim t_\nu\)，那么 \(t^2 \sim F_{1,\nu}\)。
