

此外，由于均方误差具有二次性，`c_k(t)` 是 `∑_{x∈S_k(t)} ||x - c_k||_2^2` 的唯一最小值。由于 `k` 是任意的，此结果对所有聚类均成立，进而通过对所有聚类求和可得 `L_{t,2} ≤ L_{t,1}`。

现在，由于对所有 `t` 均有 `L_{t,2} ≤ L_{t,1} ≤ L_{t-1,2}`，且 `L_{t,2} ≥ 0` 按定义成立，我们可以根据 *单调收敛定理* 得出目标函数收敛的结论。由于样本点数量有限，`S` 因此是有界的，*Heine–Borel 定理* 保证极限点存在且为局部极小值点。此外，再次利用样本量有限的事实，可能的聚类场景总数也是有限的。回顾 Lloyd 算法的性质，每次聚类和质心的更新都会使目标函数值不大于上一步的值，因此我们通常可以在有限步数内达到最优聚类并保持不变。达到最优聚类所需的步数取决于初始种子的选择。

## (II) `K`‐means 聚类的示例

`K`‐means 聚类方法在 Python 中使用 `sklearn` 库提供的 `KMeans()` 函数实现，在 `R` 中使用内置函数 `kmeans()` 实现。我们首先通过 Python 中的 [程序 14.1](#c14.xhtml#c14-sec-3001) 和 `R` 中的 [程序 14.2](#c14.xhtml#c14-sec-3002) 使用 Fisher 的鸢尾花数据来说明其用法。

对于鸢尾花数据，Python 中的 [程序 14.1](#c14.xhtml#c14-sec-3001) 和 `R` 中的 [程序 14.2](#c14.xhtml#c14-sec-3002) 的输出结果均给出了大小为 38、50 和 62 的 3 个聚类。`km_iris` 中给出的其他项目包括：

1. Python 中的 `cluster_centers_` 和 `R` 中的 `centers`：这 3 组所有 4 项测量的均值向量；

2. Python 中的 `labels_` 和 `R` 中的 `cluster`：基于 `K`‐means 聚类为每个数据点分配的聚类标签；请注意，这些组标签的编号是任意的，例如，标签 1 可能代表这 3 组中的任何一组；

3. Python 中的 `inertia_` 和 `R` 中的 `tot.withinss`：聚类内平方和总和；有关更多详细信息和讨论，请参见下一项 (III) 和 [附录 *14.A.1](#c14.xhtml#c14-sec-0010)。

最后，我们可以使用 Python 中的 [程序 14.3](#c14.xhtml#c14-sec-3003) 和 `R` 中的 [程序 14.4](#c14.xhtml#c14-sec-3004) 生成 `K`‐means 聚类标签与底层“真实”物种的分类表。
