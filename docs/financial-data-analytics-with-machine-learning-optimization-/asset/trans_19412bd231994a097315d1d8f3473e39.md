

# 距离矩阵与 AGNES 聚类算法

上述讨论的所有度量都是统计关联或“相似性”的度量，因此它们也被称为 *association measures*。然而，这与聚类中通常使用的“dissimilarity”概念不一致。因此，我们还引入了随机距离矩阵的概念：给定一个 `p` 维随机向量 `bold x equals left-parenthesis normal x 1 comma ellipsis comma normal x Subscript p Baseline right-parenthesis Superscript down-tack`，一个随机矩阵 `bold upper A colon equals left-parenthesis normal a Subscript i j Baseline right-parenthesis element-of double-struck upper R Superscript p times p` 被称为距离矩阵，如果其元素满足：

`normal a Subscript i j Baseline colon equals 1 minus StartAbsoluteValue asso left-parenthesis normal x Subscript i Baseline comma normal x Subscript j Baseline right-parenthesis EndAbsoluteValue comma for i comma j equals 1 comma ellipsis comma p comma`

其中 `asso left-parenthesis normal x Subscript i Baseline comma normal x Subscript j Baseline right-parenthesis` 是 `normal x Subscript i` 和 `normal x Subscript j` 之间选定的关联度量。其经验对应物是 `bold-italic upper A colon equals left-parenthesis a Subscript i j Baseline right-parenthesis element-of double-struck upper R Superscript p times p`，其中

`a Subscript i j Baseline colon equals 1 minus StartAbsoluteValue ModifyingAbove asso With Ì‚ left-parenthesis bold-italic x Subscript i Baseline comma bold-italic x Subscript j Baseline right-parenthesis EndAbsoluteValue comma for i comma j equals 1 comma ellipsis comma p comma`

其中 `ModifyingAbove asso With Ì‚ left-parenthesis bold-italic x Subscript i Baseline comma bold-italic x Subscript j Baseline right-parenthesis` 是 `normal x Subscript i` 和 `normal x Subscript j` 之间相应的样本关联度量，例如上述提到的那些。

这个距离矩阵在以下层次聚类算法中起着至关重要的作用，称为 *Agglomerative Nesting* (AGNES)，最初在 `[[12]]` 中提出，我们将使用它来聚类特征。该算法的实现依赖于两个不相交特征簇之间的距离度量的额外概念，假设它们的索引集分别为

`d Subscript complete Baseline left-parenthesis script upper G 1 comma script upper G 2 right-parenthesis colon equals max Underscript i element-of script upper G 1 comma j element-of script upper G 2 Endscripts a Subscript i j Baseline period`

作为层次聚类的自底向上方法，AGNES 算法从所有 `p` 个特征作为单例开始，因此初始化的簇是 `StartSet 1 EndSet comma ellipsis comma StartSet p EndSet`。然后我们迭代地将具有最小完全链接的两个簇合并为一个，这在每次迭代中将簇的总数减少一个，直到任何两个簇之间的完全链接大于预设阈值 `delta element-of left-bracket 0 comma 1 right-bracket`，或只剩下一个簇（这意味着所有特征都被视为 comonotonic）。AGNES 算法的伪代码如下所示，算法 12.1。
