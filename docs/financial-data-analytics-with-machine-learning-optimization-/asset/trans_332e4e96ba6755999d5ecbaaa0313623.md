

作为附注，香农熵的概念与费舍尔统计推断有着密切的联系。给定一个来自离散随机变量 `x` 的大小为 `n` 的随机样本 `x1, ..., xn`，似然度为 `∏(i=1 to n) p(xi)`，因此样本的平均负对数似然度为 `-(1/n) Σ(i=1 to n) ln p(xi)`。根据大数定律，当样本量 `n` 趋于无穷大时，该平均值的极限为 `-(∫ ln p(x)) = -(Σ(x∈X) p(x) ln p(x))`，这正好等于 `H(x) · ln 2`，因此似然度在渐近意义上等于 `((1 / (2^H(x) · (1 + o_p(1))))^n)`。此外，在信息论中，使用熵进行数据压缩有着强烈的动机。为了使用二进制编码来压缩存储在 `n` 维随机样本 `(x1, ..., xn) ∈ X^n` 中的信息，当 `n` 足够大时，平均只需使用 `n H(x)` 位即可。有关更多详细信息，请参见 [附录 13.A.1](#c13.xhtml#c13-sec-0015)。
