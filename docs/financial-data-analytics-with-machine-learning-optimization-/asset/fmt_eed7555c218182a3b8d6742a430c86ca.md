We first note that `A†A` and `AA†` share the same set of non‐zero eigenvalues; indeed, for `A†Auᵢ = λᵢuᵢ` and `AA†vⱼ = θⱼvⱼ`, for `λᵢ, θⱼ ≠ 0` (that is to say, `uᵢ` is an eigenvector for `A†A` corresponding to the non‐zero eigenvalue `λᵢ`; similarly `vⱼ` is an eigenvector for `AA†` corresponding to the non‐zero eigenvalue `θⱼ`), then `A†(AA†)uᵢ = A†(λᵢuᵢ)`, hence

```
(AA†)(A†uᵢ) = λᵢ(A†uᵢ).
```
