

**Lemma 6.2** 假设 `{x_n}` 是一个具有有限状态空间 `S = {s_1, ..., s_K}` 和转移矩阵 `P` 的不可约且非周期性马尔可夫链。对于任意两个状态 `s_i, s_j ∈ S`，令 `T_{i,j} := min{n ≥ 1 : x_n = s_j | x_0 = s_i}`。则平均命中时间 `τ_{i,j} := E(T_{i,j})` 是有限的。特别是，`P(T_{i,j} < ∞) = 1`。

任何在任意两个状态之间都具有有限平均命中时间的不可约马尔可夫链都被称为 *正复现*。

*Proof.* 根据 [Corollary 6.1](#c06.xhtml#c06-fea-0008)，我们可以找到一个整数 `M`，使得对于每一对 `i, j`，只要 `m ≥ M` 就有 `p_{i,j}^{(m)} > 0`。令 `α := min_{i,j} {p_{i,j}^{(M)}} > 0`。固定任意两个状态 `s_i` 和 `s_j`，并假设链从 `s_i` 开始。则

```
P(T_{i,j} > M) ≤ P(x_M ≠ s_j | x_0 = s_i) ≤ 1 - α.
```
