

这个猜测的解确实可以通过识别问题（[9.9](#c09.xhtml#c09-disp-0041））的最优解来证明其正确性，依据是在*低阶近似*背景下著名的*Eckart–Young–Mirsky 定理*，该定理有不同版本，分别基于*Frobenius 范数*或*谱范数*。然而，它们各自的证明并非简单的彼此类比，这里我们只呈现该定理的 Frobenius 范数版本，这与问题（[9.9](#c09.xhtml#c09-disp-0041））的设置相呼应。有兴趣的读者可以参阅[附录 *9.A.3](#c09.xhtml#c09-sec-0021)以获取谱范数版本。

因此，我们对 `P` 和 `Q` 的各自猜测是正确的；确实，得到的 `R̂ = P Q^⊥` 正是问题（[9.9](#c09.xhtml#c09-disp-0041））的极小化器。

请注意，问题（[9.9](#c09.xhtml#c09-disp-0041））的最优解存在*过拟合*问题；也就是说，它对训练集中的已知数据拟合得太好，以至于失去了适应新数据集（例如测试数据集）的灵活性，从而失去了预测能力。为了避免过拟合，我们采用常用的*正则化*技术，通过将 `P` 和 `Q` 中平方矩阵项的和与一些惩罚参数相加来实现。也就是说，我们为某些对角矩阵 `Λ₁ ∈ ℝ^(m×m)` 和 `Λ₂ ∈ ℝ^(n×n)`，将 `tr(Λ₁ P P^⊥) + tr(Λ₂ Q Q^⊥)` 添加到原始目标函数（[9.10](#c09.xhtml#c09-disp-0043)）中，这些矩阵充当拉格朗日乘数。

一般来说，为了优化 `J`（等价地，求解（[9.12](#c09.xhtml#c09-disp-0045)），无论是否正则化），我们不再像之前描述的那样通过 SVD 做出猜测，而是可以保持 `P` 不变，然后改变 `Q`，或者反过来。这将每个迭代问题简化为标准的最小二乘问题，并重复直到收敛。这种方法在文献中通常被称为*交替投影*，基于通常的不动点论证。

除了上述描述的隐因子方法之外，还有一种称为*邻域模型*的方法，这可能在直觉上更简单。基于每对订阅者评分向量之间的余弦系数，计算每对订阅者的相似度得分。得分越大，这两个订阅者在电影品味上就越接近。然后我们的目标是寻找一组与特定感兴趣用户接近的订阅者。为了预测感兴趣订阅者对一部电影的评分，我们可以使用相当数量的共享了对该电影看法的相似订阅者的评分的加权和。关于此方法的更多细节可以在[[11](#c09.xhtml#c09-bib-0011)]中找到。
