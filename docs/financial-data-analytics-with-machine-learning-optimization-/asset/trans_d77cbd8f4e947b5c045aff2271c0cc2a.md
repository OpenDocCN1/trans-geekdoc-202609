

事实上，Python 和 `R` 已经拥有各种内置函数，可以一次性完成模型拟合的整个过程（如上文所述），例如 Python 的 `pmdarima` 库中的 `auto_arima()` 函数，以及 `R` 的 `forecast` 库中的 `auto.arima()` 函数。具体来说，给定用户输入的 `p_max, d_max, q_max` 以及所选的信息准则，这些函数会拟合所有 ARIMA(`p, d, q`) 模型，其中 `p = 0, ..., p_max`，`d = 0, ..., d_max`，`q = 0, ..., q_max`，并根据指定的信息准则返回最佳拟合模型。有趣的是，当 `p_max = q_max = 5` 且 `d_max = 2` 时，通过 `R` 运行 [程序 7.10](#c07.xhtml#c07-gra-00010) 的输出表明，ARIMA(`2, 1, 2`) 模型在 AIC 方面表现最佳，这与我们之前的结论一致。然而，通过 Python 运行 [程序 7.9](#c07.xhtml#c07-gra-0009) 确定，在 AIC 方面的最佳模型是 ARIMA(`2, 1, 3`)，其 AIC 值为 8,295.22，低于 [程序 7.7](#c07.xhtml#c07-gra-0007) 中 ARIMA(`2, 1, 2`) 的 8,299.16。鉴于此，我们将对这两个模型进行进一步分析，如下所示：
