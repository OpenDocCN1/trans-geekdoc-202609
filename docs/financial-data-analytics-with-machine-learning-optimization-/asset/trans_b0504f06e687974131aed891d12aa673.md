

7. 由于 `uᵢ` 的样本均值被取为零，`uᵢ` 的方差可以通过平方回报 `uᵢ²` 的样本均值来估计。对于这些平方回报，存在一些正自相关，这意味着对于较小的 `k` 值，`Corr(uᵢ₊ₖ², uᵢ²) > 0`。

8. 回报的通用随机模型为 `uᵢ = μᵢ + σᵢzᵢ`，其中 `zᵢ` 遵循均值为 0、方差为 1 的分布且为 iid。这种模型的一个特例是 `uᵢ = μδt + σ√(δt)zᵢ`，其中 `zᵢ` 遵循 iid `N(0, 1)`，这就是著名的 Black–Scholes–Merton 模型。
