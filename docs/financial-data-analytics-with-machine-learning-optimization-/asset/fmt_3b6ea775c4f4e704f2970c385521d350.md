
A `p × p` symmetric matrix `A` is called *positive definite* (usually denoted by `A ≻ 0`) if for any nonzero `p × 1` vector `x`, `xᵀAx > 0`; if `xᵀAx = 0` for some nonzero `p × 1` vector `x`, while `xᵀAx ≥ 0` still holds for any `x ∈ ℝᵖ`, we say that `A` is *positive semi-definite*, denoted as `A ⪰ 0`, where `0` denotes a zero vector.

1. If `A ≻ 0`, then `A⁻¹ ≻ 0`.

2. For any `n × p` matrix `B`, `BᵀB ⪰ 0`; indeed, for any nonzero `p × 1` vector `x`, let `y = Bx`, which is an `n × 1` vector, then `xᵀBᵀBx = yᵀy = Σᵢ₌₁ⁿ yᵢ² ≥ 0`.
