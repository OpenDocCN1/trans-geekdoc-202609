
# 合单调簇的形成

让我们通过应用 AGNES 算法 12.1 来详细阐述合单调簇的形成，其中 `δ = 0.1`。首先，我们考虑标签 0 的情况，而标签 1 的情况类似。算法开始时，将单元素集合作为单独的簇，即 `Y₀ = {{1}, ..., {6}}`。由于特征 1 和 3 的对在所有簇对中具有最小的完全链接，即 `d_complete({1}, {3}) = 0.0028 < δ`，它们首先被合并，从而得到修订后的 `Y₀ = {{1, 3}, {2}, {4}, {5}, {6}}`。在下一步中，特征 4 和 5 的对具有最小的完全链接，即 `d_complete({4}, {5}) = 0.0061 < δ`，因此它们被合并，得到第二次修订后的 `Y₀ = {{1, 3}, {2}, {4, 5}, {6}}`。在这些簇中，`{1, 3}` 和特征 2 的对具有最小的完全链接，即 `d_complete({1, 3}, {2}) = max{0.0317, 0.0416} = 0.0416 < δ`；它们随后被合并，第三次修订后的 `Y₀` 变为 `{{1, 2, 3}, {4, 5}, {6}}`。由于任何簇对的完全链接均大于 `δ = 0.1`，AGNES 算法停止。通过相同的程序，标签 `y = 1` 的合单调簇集合 `Y₁` 可以显示为与 `Y₀` 在 `δ = 0.1` 下相同。接下来，我们使用经验版本的 ([12.15](#c12.xhtml#c12-disp-0034)) 来计算每个合单调簇的条件联合 pmf，如下所示：
