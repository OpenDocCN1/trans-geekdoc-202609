
In cost complexity pruning, one avoids overfitting by focusing not only on the original classification error `R(T)` but also the tree complexity. This is achieved by adding a “penalty” term to the original classification error `R(T)` so that the objective now is to construct a tree that minimizes

(13.16) `R_α(T) = R(T) + αT := (1/n) Σ(l=1 to T) Σ((x_i, y_i) ∈ T_l) 1_{y_i ≠ ȳ_T_l} + αT.`

Here, `α` is a hyperparameter which controls the effect of the model complexity. Given `α ≥ 0`, we aim to find a subtree `T(α)` of `T`, denoted as `T(α) ⊆ T`, that minimizes `R_α(T)`, namely:

(13.17) `T(α) := arg min_{T̃ ⊆ T} R_α(T̃) = arg min_{T̃ ⊆ T} (R(T̃) + αT̃).`
