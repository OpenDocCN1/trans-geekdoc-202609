

3. **Kendall's** `τ_b` [\[13\]](#c12.xhtml#c12-bib-0013): 这种非参数指标基于*一致对*的概念，用于量化两个特征之间的依赖关系。一对观测值 `(x_ui, x_uj)` 和 `(x_vi, x_vj)`，其中 `u ≠ v`，若 `(x_ui - x_vi)(x_uj - x_vj) > 0`，则称为*一致*；若 `(x_ui - x_vi)(x_uj - x_vj) < 0`，则称为*不一致*；若 `(x_ui - x_vi)(x_uj - x_vj) = 0`，则称为*相等*。`x_i` 和 `x_j` 之间的 Kendall's `τ_b` 系数计算公式为：`τ_b := (C - D) / √((n_0 - n_i)(n_0 - n_j))`，其中 `C` 和 `D` 分别表示一致对和不一致对的总数，`n_0 := (n choose 2)` 是观测值可能对的总数，而 `n_k := Σ(m : s_k,m ∈ X_k) t_km(t_km - 1) / 2`，其中 `t_km` 是特征 `x_k` 取值为 `s_k,m` 的相等对的总数。
