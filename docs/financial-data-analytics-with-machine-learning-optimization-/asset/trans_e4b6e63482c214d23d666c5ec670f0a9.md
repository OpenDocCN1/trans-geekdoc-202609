

我们在此讨论，金融和计量经济学中出现的、具有指数增长（或衰减）的时间序列数据，如何自然地符合本福德定律，至少是近似符合，并将其严格的数学证明推迟到 [小节 *4.4.3](#c04.xhtml#c04-sec-0010)。令 `X(t)` 表示某国在时间 `t` 时的名义国内生产总值（GDP），并在离散时间环境下对该过程的演化建模如下：

[(4.9)](#c04.xhtml#R_c04-disp-0025)
```
X(t + 1) = (1 + G_t)X(t), for t = 1, 2, ..., 
```

其中假设 `G_t` 为独立同分布（iid）的随机变量，每个 `G_t` 代表从 `t` 到 `t + 1` 期间整体经济活动的增长率。对这一简单模型的一个批评可能是，增长率 `G_t` 并不完全独立于当前的 GDP 水平 `X(t)` 或时间 `t`，因为发达经济体和老龄化人口往往增长较慢；然而，只要整个时间段不跨越数十年，采用 iid 假设的近似仍然相当合理，且本福德定律很可能成立。这一主张的正式陈述基于 [定理 4.1](#c04.xhtml#c04-fea-0002) 及其证明，以及随后在 [小节 *4.4.3](#c04.xhtml#c04-sec-0010) 中的讨论。同样，此类动态建模也可以解释本福德定律在股票价格、公司营收和利润、产品销售单位等方面的出现。更多讨论可见 [\[25\]](#c04.xhtml#c04-bib-0025)。

多年来，许多研究表明本福德定律可以检测政府机构的经济欺诈数据。例如，[\[36\]](#c04.xhtml#c04-bib-0036) 发现，在欧元区国家中，希腊的经济数据偏离本福德定律最为严重，且这种偏差在首位数字及前几位首位数字的组合中均持续存在。作者还指出，这种数据操纵的可能性后来已得到欧盟委员会的证实。

本福德定律对于监测选举公平性也非常有用，从而能够通过筛选各种官方选举统计数据来检测选举舞弊。话虽如此，这种检测受到各自隐私保护规则的复杂化影响。最近的例子包括 2009 年伊朗总统选举 [\[38\]](#c04.xhtml#c04-bib-0038) 以及 2017–2018 年土耳其的总统和议会选举 [\[21\]](#c04.xhtml#c04-bib-0021）。不幸的是，由于缺乏对为何该现象在大多数选举数据中出现的突出且明确的解释，本福德定律在选举监测中的有效性尚未得到严格确立 [\[8\]](#c04.xhtml#c04-bib-0008)。
