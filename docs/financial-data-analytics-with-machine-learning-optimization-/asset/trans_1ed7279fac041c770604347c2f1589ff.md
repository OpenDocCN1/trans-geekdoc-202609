4. 如果不对 `L` 施加任何分布假设，则可以通过将观察到的损失样本 `L_(1), ..., L_(n)` 按降序排列来估计 `ES_L(p)`。假设样本中没有并列值，则 [(8.9)](#c08.xhtml#R_c08-disp-0040) `ES_L(p) ≈ (1 / n(1 - p)) Σ(k=1 to K-1) L_(k) + (1 - (K - 1) / n(1 - p)) L_(K)`，其中 `K = ⌈n(1 - p)⌉` 是大于或等于 `n(1 - p)` 的最小整数。我们注意到，该公式仅是样本经验分布在置信水平 `p` 下的预期短缺。它为每个有序样本点 `L_(k)` 分配相等权重，并对最后一项进行连续性修正。
