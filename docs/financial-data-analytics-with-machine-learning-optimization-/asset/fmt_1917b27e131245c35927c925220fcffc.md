
It is well-known that `x ∈ MDA(Φ_α)` if and only if `x ∈ RV_{-α}`; in addition, the right endpoint of `x` is infinity. On the other hand, if `x ∈ MDA(Λ)`, then `x ∈ RV_{-∞}` but the converse may not hold in general. To characterize distributions in `MDA(Λ)`, we introduce the notion of *von Mises functions*. A von Mises function `F_#` with a right endpoint `x_0` is a distribution function such that there exist `z_0 < x_0` and `c > 0` and

```
1 - F_#(x) = c(x) exp {-∫_{z_0}^{x} 1/f(u) du, for all z_0 < x < x_0}
```

where `f` is a positive absolutely continuous function on `(z_0, x_0)` with *Radon–Nikodym derivative* `f'` such that `lim_{u ↑ x_0} f'(u) = 0`; and `c(x)` is a function such that `lim_{x → x_0} c(x) = c`. A distribution `F` with a right endpoint `x_F ≤ ∞` is in `MDA(Λ)` if and only if there exists a von Mises function `F_#`, with `x_F` as its right endpoint, and a point `z_0 < x_F` such that for all `x ∈ (z_0, x_F)`,

```
1 - F(x) = 1 - F_#(x) = c(x) exp {-∫_{z_0}^{x} 1/f(u) du}
```
