
As \(n \to \infty\), \(q_n(\theta)\) is dominated by the first term corresponding to the likelihood since the prior distribution is independent of the sample size \(n\), hence \(\hat{\theta}_M\) approaches the MLE \(\hat{\theta}_{\text{MLE}}\) in general. This allows us to replace \(\hat{\theta}_M\) by the more easily computable quantity \(\hat{\theta}_{\text{MLE}}\) in Laplace's approximation, and still obtain meaningful estimates. Now, by applying ([12.21](#c12.xhtml#c12-disp-0072)) and replacing \(\hat{\theta}_M\) by \(\hat{\theta}_{\text{MLE}}\), we have:

```
f_M(x) = ∫ h(θ) e^(n g_n(θ)) dθ ≈ (2π/n)^(k/2) * h(θ̂_MLE) e^(n g_n(θ̂_MLE)) / |-∇_θ ∇_θ q_n(θ̂_MLE)|^(1/2)
       ≈ L̂(2π/n)^(k/2) * π_M(θ̂_MLE) |-∇_θ ∇_θ q_n(θ̂_MLE)|^(-1/2),
```
