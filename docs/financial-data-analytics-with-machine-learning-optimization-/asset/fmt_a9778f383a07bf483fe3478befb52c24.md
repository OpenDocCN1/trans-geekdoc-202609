
Once we set `f` as a periodic function on `[0, 1]`, we can talk about its *Fourier coefficients*, each of which is defined by

`f̂(n) = ∫₀¹ f(t)e⁻²πⁱⁿᵗ dt, for any n ∈ ℤ.`

Moreover, as `f(t)` is real-valued, `f̂(-n) = f̄(n)`. According to the celebrated *Parseval's theorem* [\[34](#c04.xhtml#c04-bib-0034), [39\]](#c04.xhtml#c04-bib-0039), whenever `f ∈ L²[0, 1]`, i.e., `f` is square-integrable with `∫₀¹ f²(x) dx < ∞`, the infinite sum of `∑ₙ₌₋∞⁺∞ f̂(n)e²πⁱⁿᵗ` (almost everywhere) converges to `f(t)` under the `L²` norm, and the convergence is pointwise at all points `t` at which `f(t)` is continuous [\[45\]](#c04.xhtml#c04-bib-0045). For the purpose of computing probabilities, since by Cauchy–Schwarz inequality `||g||₁ ≤ ||g||₂` on `[0, 1]` for any `g ∈ L²[0, 1]`, so `L²`-convergence implies `L¹`-convergence in `L²[0, 1]`. Furthermore, the mapping `F: f ∈ L²[0, 1] ↦ {f̂(n)}ₙ∈ℤ` is a Hilbert space isomorphism in light of *Parseval's identity* [\[34](#c04.xhtml#c04-bib-0034), [39\]](#c04.xhtml#c04-bib-0039):

```
∫₀¹ f²(t) dt = ∑ₙ₌₋∞⁺∞ |f̂(n)|².
```
