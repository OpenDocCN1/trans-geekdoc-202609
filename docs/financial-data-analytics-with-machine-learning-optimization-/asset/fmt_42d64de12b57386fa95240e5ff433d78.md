1. We first sort the values in decreasing order and then index the sorted values with numbers `1, ..., n` as their primary ranking. For each group of ties, i.e. members have the same value, the rankings of all members in that group are equal to the average primary rankings of those values.

2. Without cause of ambiguity, we shall use the index sets to represent the corresponding sets of features, e.g., `{1, 2, 3}` stands for `{x₁, x₂, x₃}`.

3. This total number can be shown by a standard combinatorial argument: we first focus on observations in `Xₗ,₁⁽ⁱ⁾` with an arbitrary class label `cₖ`, then any classification would result in one of the following three scenarios:

   * (i) All of these observations are classified into `Xₗ₊₁,₁⁽ⁱ⁾`, so that the class `cₖ` is only present in `Xₗ₊₁,₁⁽ⁱ⁾`;
   * (ii) All of these observations are classified into `Xₗ₊₁,₂⁽ⁱ⁾`, so that the class `cₖ` is only present in `Xₗ₊₁,₂⁽ⁱ⁾`; and
   * (iii) Some of the observations are classified into `Xₗ₊₁,₁⁽ⁱ⁾`, while others fall into `Xₗ₊₁,₂⁽ⁱ⁾`, so that the class `cₖ` is present in both subsets.
