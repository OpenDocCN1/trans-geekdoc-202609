This result can be verified using Python and `R` by slightly modifying the respective codes, which is left as a programming exercise for readers. To see this mathematically, suppose that the initial seeds in the direct `K`‐means clustering (with input data points `x1, …, xn`) are `c1(0), …, cK(0)`. Then for the PCA‐incorporated version of `K`‐means clustering, using `yi = H⊥xi`, `i = 1, …, n` as the input data, where `H` is a `p × p` orthogonal matrix of loading vectors for PCs (also see [Chapter 9](#c09.xhtml)), we set `H⊥c1(0), …, H⊥cK(0)` as the initial seeds.
