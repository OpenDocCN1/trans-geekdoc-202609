

换句话说，对于任意两个状态，当 `n >= N` 时，`n` 步过渡密度总是正的。最后，考虑任何 `(s1, s2) ∈ S × S`，以及任何 `f ∈ b+(S)`，且满足 `f(s2) > 0`。由于 `f` 的连续性，存在一个开集 `s2 ∈ S` 包含 `s2`，使得 `min_{s ∈ S} f(s) > 0`。因此，我们得出结论：

```
sup_{s ∈ S} f(s1) = ∫_S f(s) μ^(n)(s | s1) ds >= ∫_S f(s) μ^(n)(s | s1) ds > 0
```

当 `n >= N` 时，该结论成立。

### 6.A.4 定理 6.6 的证明

修正任意 `s0 ∈ S`。对于 `n ∈ N`，定义 `π^(n): b(S) → R` 为

```
π^(n)(f) := (1/n) Σ_{i=0}^{n-1} f^i(s0), f ∈ b(S)
```
