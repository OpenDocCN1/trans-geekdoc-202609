

# 另一方面，关于谱聚类

另一方面，对于谱聚类，位于 `R^p` 的样本点集合被视为一个 *完全图*，其中每个样本特征向量代表一个顶点，任何两个顶点之间的边由一个权重表示。基于所选相似度度量计算出的权重形成一个相似度矩阵，由于相似度度量的对称性，该矩阵必然是对称的。此外，该相似度矩阵大多是半正定的 [\[20\]](#c14.xhtml#c14-bib-0020)；例如，如果两个观测特征向量 `x_i` 和 `x_j` 之间的相似度度量（带符号）由它们内接角的余弦给出，即 `<x_i, x_j> / (||x_i||_2 · ||x_j||_2)`，那么相应的相似度矩阵显然是半正定的。通过谱分解（回顾 [第 1.2 节](#c01.xhtml#c01-sec-0007) 以了解介绍），我们可以获得该相似度矩阵对应于 `m` 个最大特征值（所有特征值均为正）的前 `m (m >> K)` 个特征向量。

# 二分 K-means

我们介绍另一种 `K`‐means 的变体，但在层次聚类领域中，称为 *二分* `K`*`‐means*`，其中所需的聚类数量 `K` 如常预先确定。首先将整个样本视为一个单一聚类，然后使用经典的 `K`‐means 方法（`K = 2`）将其分为两个聚类。在随后的每个迭代步骤中，对具有最大平方误差和（SSE）的聚类（相对于其对应的质心）执行相同的二分法，因此每经过一个新步骤，聚类数量增加 1。该过程持续进行，直到出现明显的停止标准，即已经存在 `K` 个聚类。

# (III) K-means 聚类的应用

`K`‐means 聚类，尤其是 Lloyd 算法，非常容易应用于大型数据集。除了在本章开头提到的市场研究中客户分类的直接应用外，我们还将讨论它在其他领域的一些有趣应用，例如计算机科学中的 *图像处理* 和特征学习中的 *字典学习*。

这里，我们首先使用数据集 `Credit Card Customer Data.csv` 来说明 `K`‐means 聚类在客户凭证分类中的应用。

通过 Python 运行 [程序 14.17](#c14.xhtml#c14-sec-3017) 的输出结果显示，`R(K)` 统计量在 `K = 3` 时达到最大值 747.539，表明 `km_cCred3` 是最合适的 `K`‐means 聚类方案。[图 14.6a](#c14.xhtml#c14-fig-0006) 和 [14.6b](#c14.xhtml#c14-fig-0006) 显示了通过 Python 运行 [程序 14.18](#c14.xhtml#c14-sec-3018) 生成的信用卡总数与平均信用卡限额的散点图，以及每个特征变量的箱线图。特别是，对于散点图，每个橙色星号代表相应聚类的质心。对于箱线图，添加了一个额外的特征变量 `Total_interactions`，表示客户与银行互动的总次数。
