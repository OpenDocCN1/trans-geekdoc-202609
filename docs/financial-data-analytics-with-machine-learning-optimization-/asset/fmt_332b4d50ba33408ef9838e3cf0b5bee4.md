
We show the local optimality of Lloyd's algorithm as follows. For any time step `t`, we denote the value of the objective function ([14.2](#c14.xhtml#c14-disp-0002)) after Steps 2 and 3 in Algorithm 14.1 by `L_{t,1}` and `L_{t,2}`, respectively. By the nature of Step 2, we clearly have `L_{t,1} <= L_{t-1,2}`. For Step 3 of the centroid updating, we fix an arbitrary cluster `S_k^(t)`, and focus on the mean squared error for this cluster only. Note that the following sum of squares is a function of `c_k`,

```
\sum_{x \in S_k^{(t)}} \|x - c_k\|_2^2 = \sum_{x \in S_k^{(t)}} (x - c_k)^T (x - c_k) = \sum_{x \in S_k^{(t)}} (x^T x - 2 x^T c_k + c_k^T c_k),
```

whose first order condition implies that

```
\sum_{x \in S_k^{(t)}} (-2x + 2c_k) = 0 \iff c_k^* = \frac{\sum_{x \in S_k^{(t)}} x}{|S_k^{(t)}|} = c_k^{(t)}.
```
