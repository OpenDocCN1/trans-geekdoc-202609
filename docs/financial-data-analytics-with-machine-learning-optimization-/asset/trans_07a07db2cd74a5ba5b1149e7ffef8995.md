## (VII) 极值 Copulae

最后，我们介绍极值 copulae 家族，其首次构建可追溯至 [15](#c08.xhtml#c08-bib-0015)、[22](#c08.xhtml#c08-bib-0022)。如果存在一个 copula `C_F`，使得

```
(C_F(u_1^(1/n), ..., u_d^(1/n)))^n → C(u_1, ..., u_d) as n → ∞
```

对于所有 `(u_1, ..., u_d) ∈ [0, 1]^d`，则称 copula `C` 为 *极值 copula*。Copula `C_F` 被认为处于 copula `C` 的 *吸引域* 中。一个密切相关的概念是 *最大稳定性：* 一个 `d` 维 copula `C` 是 *最大稳定* 的，如果它满足

```
C(u_1, ..., u_d) = (C(u_1^(1/m), ..., u_d^(1/m)))^m
```
