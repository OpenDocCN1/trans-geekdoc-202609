### 11.2.2 用于应对非线性的核技巧

如前所述，某些数据集本质上仅为非线性可分，例如 [Figure 11.8](#c11.xhtml#c11-fig-0008)a 所示的数据集。但是，如果我们能够将原始空间转换为更高维的空间，那么数据点在新的转换空间中可能变得线性可分。这种转换方法称为 `kernel trick`。

[Figure 11.8](#c11.xhtml#c11-fig-0008) 说明了一个具有二维特征向量 `x = (x1, x2)^⊥` 的数据集，用蓝色点和绿色叉号标记。[Figure 11.8](#c11.xhtml#c11-fig-0008)a 中所示的原始数据点无法被任何直线分开。但是，如 [Figure 11.8](#c11.xhtml#c11-fig-0008)b 所示，在特征向量中添加一个由 `K(x1, x2) = x1^2 + x2^2` 给出的额外维度后，现在可以使用一个平面来完美分隔蓝色点和绿色叉号。
