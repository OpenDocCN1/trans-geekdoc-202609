[4](#c10.xhtml#R_c10-note-0004) The golden‐section search method initializes by calculating the values of `g(λ := S(β^(k) + Δ̂))` at the two initial endpoints `a₀ = λ₀^(1) = 0` and `b₀ = λ₀^(2) = 1`. For the `i`‐th iteration, set `λᵢ^(1) := φaᵢ₋₁ + (1 − φ)bᵢ₋₁` and `λᵢ^(2) := (1 − φ)aᵢ₋₁ + φbᵢ₋₁` where `φ = (√5 − 1) / 2` is the golden ratio, and calculate `g(λᵢ^(1))` and `g(λᵢ^(2))`. If `g(λᵢ^(1)) < g(λᵢ^(2))`, then set `aᵢ = aᵢ₋₁` and `bᵢ = λᵢ^(2)`; otherwise, set `aᵢ = λᵢ^(1)` and `bᵢ = bᵢ₋₁`. This procedure is repeated until the distance between the endpoints after the `j`‐th iteration falls below a pre‐specified threshold value `ε`, and the minimizer `λ̂` can then be taken as their midpoint `(aⱼ + bⱼ) / 2`. This method is often used to minimize functions whose derivatives or gradients cannot be obtained explicitly, as they are actually not explicitly required in the algorithm.
