

尽管如此，我们确实可以从 [表 12.1](#c12.xhtml#c12-tbl-0001) 中观察到，单元格 `(s₁₁, s₂₂)`、`(s₁₂, s₂₁)` 和 `(s₁₃, s₂₂)` 的频率高于其他单元格。数据点的这种非均匀分布表明 `x₁` 和 `x₂` 之间存在某种隐藏的关联，而上述任意编码方案无法准确反映这一点。这表明，必须采用更系统的编码方法，以尽可能揭示 `x₁` 和 `x₂` 之间的隐藏连接。为此，我们提出以下启发式方案：

1. 找出 `x₁` 和 `x₂` 的值组合中频率最高的组合，并将相应的特征值编码为 1；

2. 在 `x₁` 和 `x₂` 未编码的值中，找出频率最高的组合，并将相应的值编码为下一个未分配的整数；

3. 重复步骤 2，直到某个特征变量只剩下一个未编码的值，然后自动将下一个未分配的整数赋给它。如果两个特征变量都满足此条件，则将相同的整数分配给两个特征变量的值。否则，如果剩余的特征变量有两个或更多未编码的值，则按其对应边际频率的降序依次对其剩余值进行编码。

按照此方案，我们首先注意到 `(s₁₂, s₂₁)` 的频率最大为 250，因此将 `s₁₂` 和 `s₂₁` 编码为 1。由于 `s₂₂` 现在成为 `x₂` 中唯一尚未编码的值，因此将其编码为 2。由于 `x₁` 仍有两个未编码的值，即 `s₁₁` 和 `s₁₃`，我们按 [表 12.1](#c12.xhtml#c12-tbl-0001) 底行列出的边际频率降序对其进行编码，因此 `s₁₁` 编码为 2，`s₁₃` 编码为 3。在此编码方案下，我们可以计算得出：
