

具体地，令 `n_tail` 表示观测数据集（大小为 `n`）中大于 `x̂_min` 的数据点数量，其截断距离记为 `K*(x̂_min)`。我们生成总共 `M` 个（通常范围为 1,000 到 10,000）自助样本，每个样本大小为 `n`，其中每个样本点按以下方式独立生成：以 `n_tail / n` 的概率，该点由具有缩放参数 `β̂` 和支持 `x ≥ x̂_min` 的幂律分布生成；否则，以 `1 - n_tail / n` 的概率，该点从原始观测数据集中低于 `x̂_min` 的部分均匀抽取。然后我们计算第 `m` 个自助样本的截断 KS 距离，记为 `K_m(x̂_min)`，其中 `m = 1, ..., M`，并将此检验的 `p` 值定义为在 `K*(x̂_min)` 处自助样本截断 KS 距离的经验生存函数：

```
p-value := |{m : K_m(x̂_min) > K*(x̂_min)}| / M.
```

直观地，低于预设显著性水平 `α` 的小 `p` 值表明观测数据集的截断 KS 距离大于大多数自助样本中的截断 KS 距离，从而在显著性水平 `α` 下拒绝原假设，即数据集的上尾遵循拟合的幂律分布。另请参见 [5](#c04.xhtml#c04-bib-0005) 以获取关于该检验的详细讨论。
