

2. 计算 `q_p(i)`，即自由度为 `p` 的卡方分布的第 `i` 个分位数，这意味着 `P(χ_p^2 < q_p(i)) = (i - 0.5) / n`，在进行连续性修正后；

3. 将 `d_(i)^2` 与 `q_p(i)` 进行对比绘图。如果这些点与水平轴呈 `π / 4` 角度的直线非常接近，则原始的 `u_i` 很可能来自多元正态分布。

让我们说明如何使用卡方 Q-Q 图来判断 `u = (u_1, u_2, u_3)^⊥` 是否服从三元正态分布；请参阅 [程序 3.13](#c03.xhtml#c03-gra-00013)（Python）和 [3.14](#c03.xhtml#c03-gra-00014)（`R`）。首先，我们使用最近 180 天的数据计算每日收益率的样本均值向量和样本方差-协方差矩阵 `S`。然后，我们计算 `S` 的逆矩阵、广义平方距离以及自由度为 3 的卡方分布的分位数。请注意，Python 没有用于查找矩阵逆的内置函数，但我们可以使用 `numpy.linalg` 中的 `inv()` 函数来实现这一点。从 [图 3.7](#c03.xhtml#c03-fig-0007) 的 Q-Q 图来看，过去 180 天存储为 `u_180` 的收益率向量的分布与多元正态分布没有显著差异，除了尾部部分。我们可以再次使用 KS 检验来检验 `d_i^2 ~ χ_p^2` 是否成立。
