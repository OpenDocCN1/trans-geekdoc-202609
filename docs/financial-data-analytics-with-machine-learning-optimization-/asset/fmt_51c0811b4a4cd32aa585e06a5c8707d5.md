It then suffices to find a lower bound for the function `h(t)`. The first‐order condition of `h'(t) = -a^2 + (p λ_max) / (1 - 2t λ_max) = 0` gives `t = t_1 := (1 / (2 λ_max)) * (1 - (p λ_max) / a^2) < 1 / (2 λ_max)`. Furthermore, since `h(t)` is strictly convex (as `h''(t) = (2 p λ_max) / (1 - 2t λ_max)^2 > 0`), we see that `h(t)` attains its minimum over `[0, 1 / (2 λ_max)]` at `t_1^* := max(t_1, 0)`.
