
# 决策树不纯度度量与属性选择

一旦选择了不纯度度量，它将在整棵树（甚至整个随机森林，见 [第 13.9 节](#c13.xhtml#c13-sec-0011)）的构建过程中始终如一地使用。我们的目标是选择一个属性 `x^(j_i)`，使得 `ΔIm(x^(j_i))` 在每个父节点处最大，或者等价地，选择在分割后最能减少不纯度度量的属性。

我们现在考虑一个简单的例子来说明这些替代不纯度度量的计算。我们有一个大小为 12 的数据集，其中 6 个属于 Group 1，其余 6 个属于 Group 2。我们在两个二进制属性 `A` 和 `B` 之间进行选择，根据 [表 13.2](#c13.xhtml#c13-tbl-0002) 中的信息将根节点分割为两个子节点。

我们首先使用 Gini 指数作为不纯度度量。在父节点处，

`G(parent) = 1 - (6/12)^2 - (6/12)^2 = 0.5`

在子节点处，使用属性 `A`，我们得到：

`G(N1) = 1 - (4/7)^2 - (3/7)^2 = 0.4898`
`G(N2) = 1 - (2/5)^2 - (3/5)^2 = 0.48`

因此，属性 `A` 的优劣度为：

`ΔG(A) = G(parent) - (4+3)/12 * G(N1) - (2+3)/12 * G(N2) = 0.014`

同样，对于属性 `B`，两个子节点处的 Gini 指数分别为：

`G(N1) = 1 - (1/5)^2 - (4/5)^2 = 0.32`
`G(N2) = 1 - (5/7)^2 - (2/7)^2 = 0.408`

因此，属性 `B` 的优劣度为：

`ΔG(B) = G(parent) - (1+4)/12 * G(N1) - (5+2)/12 * G(N2) = 0.1285`
