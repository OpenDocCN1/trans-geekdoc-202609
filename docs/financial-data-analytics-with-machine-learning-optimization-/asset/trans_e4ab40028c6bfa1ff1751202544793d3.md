`l(1/n l(x⁽ⁿ⁾)) ≤ H(x) + ε.`

By using similar arguments or otherwise, we can easily show that `liminfₙ→∞ E(1/n l(x⁽ⁿ⁾)) ≥ H(x)`, and hence `limₙ→∞ l(1/n l(x⁽ⁿ⁾)) = H(x)`; as a result, one only needs `nH(x)` bits on average to code sequences in `Xⁿ` when `n` is sufficiently large.

### 13.A.2 使用熵求解 Wordle

Wordle 是由 Josh Wardle 开发的一款基于网页的单词游戏，由《纽约时报》定期发布，作为其读者的单词谜题。玩家有六次机会猜测一个五个字母的单词，每次猜测都会给出反馈：每个猜测的字母会被标记为绿色、黄色或灰色。绿色表示相应的字母出现在目标单词的正确位置；黄色表示相应的字母在目标单词中但位置不正确；而灰色表示相应的字母不在目标单词中。作为一条特殊规则，如果猜测中出现多个特定字母的副本，假设有 `m` 个，例如 RADAR 中的 A 和 R（两个字母的 `m` 均为 2）或 MUMMY 中的 M（`m` = 3），那么首先将位置正确的字母（假设有 `m₀` 个）标记为绿色，然后在剩余副本中将最左边的 `(m - m₀)₊` 个标记为黄色，其余的显示为灰色；请参见 [Figure 13.19](#c13.xhtml#c13-fig-0019) 以获取示意图，读者可以尝试根据上述规则恢复每次尝试中每个位置的颜色。
