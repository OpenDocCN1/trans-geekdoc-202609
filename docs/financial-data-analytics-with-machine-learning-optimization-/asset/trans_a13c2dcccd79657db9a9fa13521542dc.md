

使用此定义来找到 `μ_q` 依赖于对 `x_1, ..., x_n` 进行排序。例如，要找到经验中位数 `μ_0.5`，我们首先将 `x_i` 按升序排列为 `x_(1) ≤ ... ≤ x_(n)`。如果 `n` 是奇数，则 `μ_0.5` 简单地是 `x_((n+1)/2)`，即排序序列中正好位于中间的数字。同样，如果 `n` 是偶数，则 `μ_0.5` 可以是区间 `[x_(n/2), x_(n/2+1)]` 中的任何数字。
