

如[第 8 章](#c08.xhtml)中所讨论，copulae 可用于建模底层特征变量的一般依赖结构。虽然许多 copulae 现成可用，但 `CIBer` 专注于利用 comonotonic copula。读者此时可能会自然地提出一个问题：为什么选择 comonotonic copula 而不是其他替代方案？为了解决这个问题，让我们提供一项全面的模拟研究，以证明将 comonotonic copula 作为首选的合理性。

我们通过将 `CIBer` 与其他三个基于 Archimedean copula 的分类器（即 Gumbel、Frank 和 Clayton copulae）进行比较，来研究 `CIBer` 中 comonotonicity 作为建模 copula 的鲁棒性。为了模拟现实世界数据集的多样性，对于每个特征变量 ![normal x Subscript i](images/c12-i0533.png)<math display="inline" overflow="scroll"><msub><mi mathvariant="normal">x</mi><mi>i</mi></msub></math>，我们从预选的常见分布列表中随机选择一个分布。为了简单起见，一方面我们只考虑一个簇，其中类标签 ![c 1](images/c12-i0534.png)<math display="inline" overflow="scroll"><msub><mi>c</mi><mn>1</mn></msub></math> 中的所有五个特征变量都具有强依赖性。另一方面，类标签 ![c 2](images/c12-i0535.png)<math display="inline" overflow="scroll"><msub><mi>c</mi><mn>2</mn></msub></math> 中的那些特征变量具有弱依赖性，但相同类型的 copulae 管理着两种依赖结构。尽管这种设置有利于这三个基于 Archimedean copula 的分类器，我们将证明 `CIBer` 对它们的表现相当出色。模拟程序在算法 12.3 中描述。
