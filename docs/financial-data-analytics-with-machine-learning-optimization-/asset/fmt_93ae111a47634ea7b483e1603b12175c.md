Before we finish this section, we make some remarks on some relevant syntax and coding practice.

The `tensorflow` library has been widely used for deep learning in Python and `R`. It was first developed by the `Google Brain` team for their own internal use [\[1\]](#c15.xhtml#c15-bib-0001), and then it was released for public use in 2015. However, `tensorflow` itself is built from Python, C++, and CUDA (Compute Unified Device Architecture)

The `generate_dataset()` function receives two parameters, the `price` parameter takes in the training dataset as well as the test dataset, while the `seq_len` accepts an integer indicating the moving window width of input features, which is 10 in our stock price prediction example. This function returns two `numpy` arrays, the observations ![bold-italic x](images/c15-i0129.png)<math display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">x</mi></mrow></math> and the label ![y](images/c15-i0130.png)<math display="inline" overflow="scroll"><mrow><mi>y</mi></mrow></math> for the dataset.
