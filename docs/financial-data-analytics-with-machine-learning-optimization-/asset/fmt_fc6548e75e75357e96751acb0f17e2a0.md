where `z_{1 - α/2}` is the upper tail percentile of the standard normal distribution such that `Φ(z_{1 - α/2}) = 1 - α/2`. Therefore, the (approximate) `100(1 - α)%` confidence interval of `C_0` is

[`Ĉ_{T,n} - z_{1 - α/2} * σ_{C_T} / √n, Ĉ_{T,n} + z_{1 - α/2} * σ_{C_T} / √n`]

If we want `P(|Ĉ_{T,n} - C_0| ≤ ε) ≈ 1 - α` for some `ε > 0`, we choose sample size `n` such that `z_{1 - α/2} * σ_{C_T} / √n = ε`, which is equivalent to `n = (σ_{C_T}² / ε²) * z_{1 - α/2}²`.
