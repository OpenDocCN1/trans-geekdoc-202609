```math
\begin{array}{ll}
\text{Cases 1 and 2:} & [s - T + j,\ s + j]; \\
\text{Case 3:} & [s + t^* - T + j,\ s + j]; \\
\text{Case 4:} & [s - T + j,\ s + t_1^* - T + j] \cup [s + t_2^* - T + j,\ s + j].
\end{array}
```

接下来，我们在每个检查窗口内应用所提议的理论，以确定当前日 `s` *是否* 是该窗口内的最佳交易日。虽然对于至少一个 `T + 1` 个检查窗口（即从第 `s - T + j` 天到第 `s + j` 天，其中 `j = 0, ..., T`）会成立，我们按如下方式执行相应的交易操作：对于固定的 `p ∈ (0, 1)` 和 `q > 1`，我们有以下操作：

*   回顾从第 `(j + 1)` 个检查窗口开始的历史滚动最大价格 `M̃_{s,j} := max_{s - T + j ≤ τ ≤ s} S_τ`，`j = 0, ..., T`。如果存在 `j = 0, ..., T` 使得以下两个条件同时满足，则我们在第 `s` 天进行卖出操作：

    1.  (S1) `{S_s > p M̃_{s,j} and S_{s-1} < p M̃_{s,j}}` 或 `{S_s < p M̃_{s,j} and S_{s-1} > p M̃_{s,j}}` 中仅有一个成立（不能同时成立）；并且

    2.  (S2) `s` 落在该检查窗口的 *行动期* 内，且对应于 ([7.39](#c07.xhtml#c07-disp-0063)) 中四种可能情况中的恰好一种。
