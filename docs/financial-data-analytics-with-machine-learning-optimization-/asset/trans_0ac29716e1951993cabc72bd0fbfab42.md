

对于 `j ≠ l`，`E((x_j - μ)(x_l - μ)ᵀ)` 中的每个元素都为零，因为每个元素都是 `x_j` 的一个分量与 `x_l` 的一个分量之间的协方差，根据随机样本的定义，它们相互独立。因此，

`Var(x̄) = (1/n²) Σ(j=1 to n) E((x_j - μ)(x_j - μ)ᵀ).`

由于 `Σ = E((x_j - μ)(x_j - μ)ᵀ)` 是每个 `x_j` 的共同总体协方差矩阵，我们有

`Var(x̄) = (1/n²) Σ(j=1 to n) E((x_j - μ)(x_j - μ)ᵀ) = (1/n²) · n · Σ = (1/n) Σ.`
