
1. **(1)** When `a² > p λ_max`, we have `t₁ > 0`, hence `t₁* = t₁`, and `h(t)` takes the minimum of `h(t₁) = -p/2 ln(p λ_max / a²) - (a² - p λ_max) / 2 λ_max`;

2. **(2)** When `a² ≤ p λ_max`, we have `t₁ ≤ 0`, thus `t₁* = 0`, and `h(t)` takes the minimum of `h(0) = 0`.

Combining the scenarios above, we see that `h(t) ≥ -p/2 ln(p λ_max / a²) - (a² - p λ_max) / 2 λ_max` for all `0 ≤ t < 1 / 2 λ_max`, which leads to the following lower bound for ([14.21](#c14.xhtml#c14-disp-0074)): for all `i = 1, ..., n`,

```
P(x_i ∈ B_G(S_i)) ≥ 1 - e^(h(t))
≥ 1 - (p λ_max / a²)^(-p/2) exp(-(a² - p λ_max) / 2 λ_max)
≥ 1 - (p / a)^(-p) exp(-(a² - p²) / 2p),
```

where the final inequality follows from the fact that `λ_max ≤ p` by the property of the correlation matrix `V_ik`.
