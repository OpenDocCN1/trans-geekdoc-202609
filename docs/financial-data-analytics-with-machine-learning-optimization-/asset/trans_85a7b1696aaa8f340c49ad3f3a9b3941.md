

尽管吉布斯采样中看似不存在接受概率，且其参数更新机制与梅特罗波利斯-哈斯廷斯算法（或其单分量变体）似乎截然不同，但两者之间存在着密切的联系，因为前者中一个循环内的每个更新子步骤 `i` 实际上是后者中的一个步骤，其对应的接受概率为 `α_i ≡ 1`。要理解这一点，我们考虑时间 `t` 时循环中的第 `i` 个更新步骤，其中联合分布 `π(θ̄ x₁, …, xₙ | θ₋ᵢ = θ₋ᵢ⁽ᵗ⁾)` 是目标分布，其中 `θ₋ᵢ⁽ᵗ⁾ := (θ₁⁽ᵗ⁺¹⁾, …, θᵢ₋₁⁽ᵗ⁺¹⁾, θᵢ₊₁⁽ᵗ⁾, …, θᵣ⁽ᵗ⁾)⊤`。分别用 `θ⁽ᶦ,ᵗ⁾ := (θ₁⁽ᵗ⁺¹⁾, …, θᵢ₋₁⁽ᵗ⁺¹⁾, θᵢ⁽ᵗ⁾, θᵢ₊₁⁽ᵗ⁾, …, θᵣ⁽ᵗ⁾)⊤` 和 `θ̃⁽ᶦ,ᵗ⁾ := (θ₁⁽ᵗ⁺¹⁾, …, θᵢ₋₁⁽ᵗ⁺¹⁾, θᵢ⁽ᵗ⁺¹⁾, θᵢ₊₁⁽ᵗ⁾, …, θᵣ⁽ᵗ⁾)⊤` 表示更新前后的参数向量。在这个第 `i` 个子步骤中，通过将提议转移密度 `q` 选择为 `πᵢ(θᵢ | θ₋ᵢ⁽ᵗ⁾, x₁, …, xₙ)`，该子步骤的接受概率（[6.29](#c06.xhtml#c06-disp-0100）) 则变为：
