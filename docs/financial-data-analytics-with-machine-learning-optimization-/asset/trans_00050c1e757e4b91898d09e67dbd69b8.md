

### Case 4: if `φ(t; -λ, ε_B)` admits two distinct roots `s₂* < s₁*`, then by defining `t₁* := (T - s₁*)⁺` and `t₂* := (T - s₂*)⁺`, the optimal buying time is given by `τ_B* := inf{t ∈ [0, t₁*] ∪ [t₂*, T] : S_t = q_m_t} ∧ T`.

在 [附录 7.A.3](#c07.xhtml#c07-sec-0026) 中，我们展示了一个表格，其中包含 `φ` 在 `ε` 和 `λ` 的各种值组合下的根 `s*`（`s₁*` 和 `s₂*`）。对于 `φ` 被评估的任何中间值，随后可以对相应的根进行插值。

### 7.5.1 使用优质指数的交易策略

假设在某个日历年内，我们希望交易一只或多只股票，而不涉及其任何衍生品，以最大化我们的利润。这个问题本质上是时间不一致的，因为我们的目标可能会日复一日地改变。在以下内容中，我们将介绍一类利用连续最佳卖出和买入时间的交易策略，这些策略具有不同的赔率，如在 [提议 7.1](#c07.xhtml#c07-fea-0004) 和 [7.2](#c07.xhtml#c07-fea-0006) 中介绍。

一般而言，虽然股票回报预计是非平稳的，但其变化在较短的时间范围内通常是温和的。为了说明，这里我们将 `T` 设置为 4，以便每个交易周期包含 `T + 1 = 5` 个交易日，即一周。这促使我们假设 `μ` 和 `σ` 在整个交易周期内保持不变，并分别用 `μ_{t_{k,0}}` 和 `σ_{t_{k,0}}` 表示从第 `t_{k,0}` 天到第 `t_{k,T} := t_{k,0} + T` 天的第 `k` 个交易周期的估计值。我们将参数估计的讨论推迟到后续小节，而在此处我们专注于讨论我们提出的交易机制，该机制相当反直觉，并不那么立即直截了当。然而，它受到我们提出的理论的启发，并与之保持一致。
