## 12.2 贝叶斯渐近推断

如前一节所示，尽管我们阐明了可信度估计器的贝叶斯性质，但过多限制（包括其简单线性）限制了其在更广泛范围内的应用。我们需要一个更广义的 *贝叶斯决策理论*，它可以允许（i）更大的损失函数家族，而不仅仅是平方损失；（ii）相应贝叶斯估计器的显式近似，尤其是当先验不是似然的共轭先验时；以及（iii）用于进一步统计推断（如假设检验）的近似后验分布。
