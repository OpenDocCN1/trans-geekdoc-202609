
# 奇异值分解（SVD）

从数学角度看，*奇异值分解*（SVD）是方阵对称矩阵特征值分解的推广，现应用于一般的 `m` × `n` 矩形矩阵。它在机器学习领域有着广泛的应用，例如在营销科学中常见的推荐系统中。SVD 断言如下（参见 [\[6\]](#c09.xhtml#c09-bib-0006)）：给定一个 `m` × `n` 矩阵 `A`，存在矩阵 `U`、`Σ` 和 `V`，使得

[(9.14)](#c09.xhtml#R_c09-disp-0061) `A = U Σ V^T`

或等价地

(9.15) `A V = U Σ`

其中：

1. `U = (u₁, ..., uₘ)` 是一个 `m` × `m` 矩阵，其中每个 `uᵢ` 是对应于 `AA^T` 的第 `i` 大特征值的单位特征向量，其中 `i = 1, 2, ..., m`。向量 `uᵢ` 被称为 `A` 的*左奇异向量*，且它们彼此正交；

2. `V = (v₁, ..., vₙ)` 是一个 `n` × `n` 矩阵，其中每个 `vᵢ` 是对应于 `A^T A` 的第 `i` 大特征值的单位特征向量，其中 `i = 1, 2, ..., n`。向量 `vᵢ` 被称为 `A` 的*右奇异向量*，且它们彼此正交；

3. `Σ = diag(σ₁, ..., σᵣ)` 是一个 `m` × `n` 对角矩阵，其中 `r = rank(A)`，且 `σᵢ = √λᵢ(A^T A) > 0` 是 `A^T A` 的第 `i` 大特征值的平方根，被称为 `A` 的*奇异值*。
