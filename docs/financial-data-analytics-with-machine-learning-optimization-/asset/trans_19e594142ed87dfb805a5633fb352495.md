

令 $x_1, \ldots, x_n$ 为非退化独立同分布随机变量，并记其最大值为 $M_n := \max\{x_1, \ldots, x_n\}$。若存在 $a > 0$ 和 $b \in \mathbb{R}$，使得对所有 $x \in \mathbb{R}$ 均有 $F(x) = G(ax + b)$，则称两个分布函数 $F(x)$ 和 $G(x)$ 属于 *同类型*。 *Fisher–Tippett 定理* [\[18\]](#c08.xhtml#c08-bib-0018) 是极值理论（EVT）的基石结果之一，它断言：若存在归一化常数 $a_n > 0$ 和 $b_n \in \mathbb{R}$（$n = 1, 2, \ldots$）以及某个非退化分布函数 $H$，使得

[(8.17)](#c08.xhtml#R_c08-disp-0078)
$$
a_n^{-1}(M_n - b_n) \xrightarrow{d} H \quad \text{as } n \to \infty,
$$

则 $H$ 必须属于以下三种分布函数之一的同类型分布类：对 $\alpha > 0$，

(i) Fréchet: $\Phi_\alpha(x) = \begin{cases} 0, & x \le 0 \\ \exp\{-x^{-\alpha}\}, & x > 0 \end{cases}$;

(ii) Gumbel: $\Lambda(x) = \exp\{-e^{-x}\}, \quad x \in \mathbb{R}$;

(iii) Weibull: $\Psi_\alpha(x) = \begin{cases} \exp\{-(-x)^\alpha\}, & x < 0 \\ 1, & x \ge 0 \end{cases}$。
