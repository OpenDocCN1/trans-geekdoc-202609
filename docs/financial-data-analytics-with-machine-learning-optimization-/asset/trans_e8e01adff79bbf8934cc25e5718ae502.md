## *7.5 KELLY FRACTION

所有股票交易策略都追求一个最终目标：以尽可能低的价格买入，并在可行的最高价格卖出，以最大化交易利润。然而，没有水晶球，在固定投资期限内的最高和最低股票价格，直到规划期限的终点时间到达之前，永远无法确定地预测。为此，一个更合理且可实现的目标是找到一个交易价格，在某种差异概念下，尽可能接近不可预见的目标价格。这种问题表述被归类为最优预测问题 [\[27](#c07.xhtml#c07-bib-0025), [28\]](#c07.xhtml#c07-bib-0026)，这是 `Stochastic Analysis` 中 `optimal stopping theory` 的一个分支。为了方便讨论，我们假设基础股票价格过程 ![left-brace normal upper S Subscript t Baseline right-brace Subscript 0 less-than-or-equal-to t less-than-or-equal-to upper T](images/c07-i0527.png)<math display="inline" overflow="scroll"><msub><mrow><mo stretchy="false">&#123;</mo><msub><mi mathvariant="normal">S</mi><mi>t</mi></msub><mo stretchy="false">&#125;</mo></mrow><mrow><mn>0</mn><mo>&#8804;</mo><mi>t</mi><mo>&#8804;</mi><mi>T</mi></mrow></msub></math> 遵循具有恒定回报率 ![mu](images/c07-i0528.png)<math display="inline" overflow="scroll"><mrow><mi>&#956;</mi></mrow></math> 和恒定波动率 ![sigma](images/c07-i0529.png)<math display="inline" overflow="scroll"><mrow><mi>&#963;</mi></mrow></math> 的 Black–Scholes 模型：
