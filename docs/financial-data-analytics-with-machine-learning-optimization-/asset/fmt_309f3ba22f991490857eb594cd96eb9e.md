
# Mutual Information

Mutual information has a standalone position in information theory as it measures the mutual dependence between two distributions represented by two random variables of `x` and `y`. It is defined as `I(x, y) := H(y) - H(y|x)`, yet it is symmetric, i.e. `I(x, y) = H(x) - H(x|y) = I(y, x)`; indeed, from ([13.7](#c13.xhtml#c13-disp-0021)), we have `I(x, y) := H(y) - H(y|x) = H(y) - H(x, y) + H(x) = H(x) - H(x, y) + H(y) = H(x) - H(x|y) = I(y, x)`.
