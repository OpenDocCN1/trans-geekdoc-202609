特别是，对于 AR(![p](images/c07-i0105.png)<math display="inline" overflow="scroll"><mrow><mi>p</mi></mrow></math>)（或 MA(![q](images/c07-i0106.png)<math display="inline" overflow="scroll"><mrow><mi>q</mi></mrow></math>））模型，其 ACF（或 PACF）随滞后 ![k](images/c07-i0107.png)<math display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math> 指数衰减（可能呈正弦波形），而其 PACF（或 ACF）在滞后 ![k greater-than p](images/c07-i0108.png)<math display="inline" overflow="scroll"><mi>k</mi><mo>&#62;</mo><mi>p</mi></math>（或 ![k greater-than q](images/c07-i0109.png)<math display="inline" overflow="scroll"><mi>k</mi><mo>&#62;</mo><mi>q</mi></math>）之后截断/消失；后者结果称为 `cut-off property`。它们的样本对应物也表现出类似趋势，数值说明请参见 [Figure 7.4](#c07.xhtml#c07-fig-0004)。特别是，对于 AR(2) 模型，当 ![k greater-than 2](images/c07-i0110.png)<math display="inline" overflow="scroll"><mi>k</mi><mo>&#62;</mo><mn>2</mn></math> 时，样本 PACF 值与 0 的偏差不显著，这证明了其 PACF 在滞后 2 处的截断性质，同样的论证也适用于 MA(2) 模型的 ACF。这些性质的数学细节已在各种经典时间序列教材中得到充分讨论，包括 [\[15](#c07.xhtml#c07-bib-0014), [39\]](#c07.xhtml#c07-bib-0037) 等。虽然上述性质适用于纯 AR 和 MA 模型，但也可用于确定一般 ARMA 模型中 ![p](images/c07-i0111.png)<math display="inline" overflow="scroll"><mrow><mi>p</mi></mrow></math> 和 ![q](images/c07-i0112.png)<math display="inline" overflow="scroll"><mrow><mi>q</mi></mrow></math> 的取值，即分别通过观察样本 PACF 和 ACF 图的截断点来确定。ACF 和 PACF 对于 ARMA 模型的性质摘要请参见 [Table 7.1](#c07.xhtml#c07-tbl-0001)。

ARIMA 模型是一种有用的工具，广泛应用于多个学科，包括但不限于金融预测、经济分析、运筹学和气候建模。在此，让我们以最近的热门话题——`Bitcoin` 的价格预测为例，说明其在金融领域的应用。Bitcoin 是一种数字加密货币，使个人能够在无需银行或支付处理器等可信第三方存在的情况下相互转移货币价值。它是第一个完全由其用户驱动、无中央机构的去中心化点对点支付网络。Bitcoin 网络监控加密货币在数字钱包之间的流动，以防止欺诈和双重支出。Bitcoin 代表了一种创新的新型数字货币，具有抗审查性，任何拥有互联网接入的人都可以使用。新的比特币通过一种称为“挖矿”的过程发行，其中计算机解决复杂的数学问题以在区块链中发现新区块。矿工随后因验证交易和保障网络安全而获得新的比特币作为奖励。
