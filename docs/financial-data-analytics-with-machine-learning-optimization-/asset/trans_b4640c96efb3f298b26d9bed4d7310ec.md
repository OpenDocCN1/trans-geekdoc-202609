

在这一部分，我们记集合 `ℕ∞ := ℕ ∪ {∞}`。我们还采用约定 `min ∅ = ∞`。

### 6.A.3.1 定理 6.2 的证明

定义 `N₁: S → ℕ∞` 为

[(6.34)](#c06.xhtml#R_c06-disp-0134)
```
N₁(s) := min {m : fⁿ(s) > 0 for any n ≥ m and f ∈ f_{b+} (S) with f(s) > 0}.
```

由于马尔可夫链的非周期性以及 [命题 6.1](#c06.xhtml#c06-fea-0016)(ii)，对于每个 `s ∈ S`，均有 `N₁(s) < ∞`。

固定 `s₀ ∈ S` 并令 `N₁(s₀) = m`。我们声称存在一个包含 `s₀` 的开集 `U_{s₀} ⊂ S`，使得对任意 `s ∈ U_{s₀}`，均有 `N₁(s) ≤ N₁(s₀)`。确实，根据 `N₁(s)` 的定义，对于每个 `n ≥ m`，

[(6.35)](#c06.xhtml#R_c06-disp-0135)
```
fⁿ(s₀) = ∫_S μⁿ(s | s₀) g(s) ds > 0
```
