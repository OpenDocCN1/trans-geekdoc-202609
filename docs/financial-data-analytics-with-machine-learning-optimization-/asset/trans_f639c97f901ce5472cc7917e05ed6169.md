

1.  如果 `A` 是一个 `r × p` 的确定性矩阵，那么 `y = Ax` 是一个 `r × 1` 随机向量，其均值为 `E(y) = Aμ`，协方差矩阵为 `Var(y) = AΣAᵀ`；此外，对于另一个 `r × 1` 随机向量 `z = Bx`，其中 `B` 是另一个 `r × p` 常数矩阵，`y` 和 `z` 的协方差为 `Cov(Ax, Bx) = AΣBᵀ`。

2.  `x` 的相关系矩阵 `R = (ρᵢⱼ)` 可以通过其协方差矩阵 `Σ = (σᵢⱼ)` 根据公式 `R = D⁻¹ᐟ²ΣD⁻¹ᐟ²` 计算得出，其中 `D` 是由 `diag(σ₁₁, …, σₚₚ)` 表示的对角矩阵，且 `D⁻¹ᐟ² := diag(1/√σ₁₁, …, 1/√σₚₚ)`。
