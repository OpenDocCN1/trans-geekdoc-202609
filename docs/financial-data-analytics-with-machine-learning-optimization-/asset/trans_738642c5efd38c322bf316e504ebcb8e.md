

2. Vega 参数为 `γ = σ` 时：[(5.21)](#c05.xhtml#R_c05-disp-0103)

```
{
  d y_t = r y_t dt + (S_t^(θ/2) + σ · θ/2 · S_t^(θ/2 - 1) y_t) dw_t;
  d S_t = r S_t dt + σ S_t^(θ/2) dw_t,
}
```

初始条件为 `y_0 = ∂S_0 / ∂σ = 0` 和 `S_0`。

**示例 5.10（CEV 模型的延续，参考 [示例 5.9](#c05.xhtml#c05-fea-0032)，现采用路径微分方法）**

在 CEV 框架下，取 `θ = 2, 1.8` 和 1，考虑一个欧式看涨期权，参数为 `S_0 = 10, K = 8, σ = 0.3, r = 0.05`，且 `T = 1`。我们现在使用标准欧拉–丸山方案对通过路径微分得到的 SDE 系统进行数值校准，以计算 delta 和 vega。实现通过 [程序 5.31](#c05.xhtml#c05-gra-00031)（Python，另参考 [程序 5.32](#c05.xhtml#c05-gra-00032) 使用 `R`），分别采用 ([5.20](#c05.xhtml#c05-disp-0102)) 和 ([5.21](#c05.xhtml#c05-disp-0103))。

根据 [图 5.8](#c05.xhtml#c05-fig-0008)（Python）和 [图 5.9](#c05.xhtml#c05-fig-0009)（`R`），在 Black–Scholes 框架下，当 `θ = 2` 时，delta 和 vega 的近似值随着迭代次数 `n` 的增加分别收敛于 delta 和 vega 的真实值。

同样，我们可以在 [图 5.10](#c05.xhtml#c05-fig-0010)（Python，另参考 [图 5.11](#c05.xhtml#c05-fig-0011) 使用 `R`）中观察到 `θ = 1.8` 的类似收敛结果，并在 [图 5.12](#c05.xhtml#c05-fig-0012)（Python，另参考 [图 5.13](#c05.xhtml#c05-fig-0013) 使用 `R`）中观察到 `θ = 1` 的类似收敛结果。我们将编写通过路径微分方法得到的 SDE 系统的 Milstein 方案留给读者作为练习；如预期，相应的收敛速度会更快。

假设我们只关心近似一个带有收益 `f_γ(S_T)` 的衍生品的希腊字母 `∂f_γ(S_T) / ∂γ`。对于有限差分法，我们必须同时模拟恰好三个不同 SDE 动力学中的两个，具体取决于使用前向差分还是中心差分，即：股票价格 `S_t` 的三个动力学，分别对应 `γ - h`、`γ` 和 `γ + h`，其中 `h > 0` 为某个足够小的期望值。对于路径微分法，仍需同时模拟两个动力学，即 `∂S_T / ∂γ` 和 `S_t` 的动力学。一般来说，路径微分通常更快且足够准确，同时其内存效率至少与有限差分法相当。
