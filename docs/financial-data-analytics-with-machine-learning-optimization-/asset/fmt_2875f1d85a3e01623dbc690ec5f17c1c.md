
As `x` and `x̃` are iid, this inequality reduces to `2 E(g₁(x)g₂(x)) ≥ 2 E(g₁(x)) E(g₂(x))`, which immediately implies that `Cov(g₁(x), g₂(x)) ≥ 0`. Now, let `x := h(u, γ₁)` and `z := h(1 − u, γ₂)`. For any fixed `γ`, `h(θ, γ)` increases in `θ`, so both `ĥ(h(u, γ₁) | u = u)` and `−ĥ(h(1 − u, γ₂) | u = u)` are increasing in `u`. By the first assertion, we just established that

```
Cov(ĥ(x | u), −ĥ(z | u)) = Cov(ĥ(h(u, γ₁) | u), −ĥ(h(1 − u, γ₂) | u)) ≥ 0.
```
