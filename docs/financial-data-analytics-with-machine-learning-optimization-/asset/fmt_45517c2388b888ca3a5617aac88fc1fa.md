
where $\hat{L}:=e^{n g_n(\hat{\theta}_{\text{MLE}})}=f_{\mathcal{M}}(x|\hat{\theta}_{\text{MLE}})$ is the maximized likelihood. Therefore, the comparison among the candidate models $\mathcal{M}$'s reduces to comparing the marginal likelihood $f_{\mathcal{M}}(x)$ of the observed data $x$ under each of the models. We should select the one with the largest marginal likelihood, or equivalently the largest log‐marginal likelihood $\ln f_{\mathcal{M}}(x)$, which is approximately:

$$
\begin{aligned}
\ln f_{\mathcal{M}}(x) &\approx \ln \hat{L} - \frac{k}{2} \ln n + \left(\frac{k}{2} \ln(2\pi) + \ln \pi_{\mathcal{M}}(\hat{\theta}_{\text{MLE}}) - \frac{1}{2} \ln \left| -\nabla_{\theta} \nabla_{\theta}^T q_n(\hat{\theta}_{\text{MLE}}) \right|\right) \\
&= -\frac{1}{2} \left( -2 \ln \hat{L} + k \ln n \right) + O_p(1).
\end{aligned}
$$

This explains why $\text{BIC}:=-2 \ln \hat{L} + k \ln n$ is used as a criterion for model selection under the Bayesian framework; indeed, the model with the smallest BIC has the largest log‐marginal likelihood, and so should be favourably selected. For a more detailed discussion, we refer to [\[14\]](#c12.xhtml#c12-bib-0014) and references therein.
