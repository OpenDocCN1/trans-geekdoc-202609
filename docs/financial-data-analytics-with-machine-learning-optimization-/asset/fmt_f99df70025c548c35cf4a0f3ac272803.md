Refer to [Figure 15.11](#c15.xhtml#c15-fig-0011) for the different notations. Suppose that the algorithm is at the stage of `t`-th iteration. At the output layer, `k = 1, 2, ..., 100`,

∂L/∂w_k^o = -(y - ŷ_t) * ∂ŷ_t/∂w_k^o = -(y - ŷ_t) * ∂/∂w_k^o [ReLU(ô_x^o)] = -(y - ŷ_t) * 1_(0,∞)(ô_x^o_t) * ŷ_k,t^2,

where the indicator function `1_(0,∞)(x) = 1` when `x ≥ 0`, otherwise equals 0 when `x < 0`, is the sub‐differential of the ReLU function. The first and second moments of the gradients are respectively: for `k = 1, 2, ..., 100`,

m_k,t^o = β1 * m_k,t-1^o - (1 - β1) * (y - ŷ_t) * 1_(0,∞)(ô_x^o_t) * ŷ_k,t^2,
v_k,t^o = β2 * v_k,t-1^o + (1 - β2) * (y - ŷ_t)^2 * 1_(0,∞)(ô_x^o_t) * (ŷ_k,t^2)^2.
