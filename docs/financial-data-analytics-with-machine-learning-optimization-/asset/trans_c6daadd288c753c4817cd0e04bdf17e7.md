where `x₀` is a known initial “seed”, the integer `m` is usually selected to be a large prime number, and `c` is chosen to be small `(0 < c < m)` in comparison with `m`. However, the value of `(a xₖ + c) (mod m)` is very sensitive to a slight change of `xₖ`; meanwhile, any tiny difference in the value of `a xₖ + c` can lead to a substantial deviation in the later sequential values. After a long run, the sequence of numbers `xₙ`'s will notably be uncorrelated with the original seed `x₀` or any other `xₖ`'s obtained in the previous iteration steps. We can then take the fraction `xₖ / m` as a sample observed value of the uniform random variable on `[0, 1]`.
