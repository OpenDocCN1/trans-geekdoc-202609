
2. Yellow, if (i) `ω̃_j ≠ ω_j*`, (ii) `∏_{l=1}^{5} (ω̃_j − ω_l*) = 0`, and (iii) `∑_{l=1}^{j−1} 1_{ω̃_j = ω̃_l} ≤ ∑_{l=1}^{5} 1_{ω̃_j = ω_l*, ω̃_l ≠ ω_l*} = m − m₀`;

The key iteration step in the algorithm is to find the “best” guess in the sense that it can narrow down the range of candidate words for the next step as much as possible on average.
