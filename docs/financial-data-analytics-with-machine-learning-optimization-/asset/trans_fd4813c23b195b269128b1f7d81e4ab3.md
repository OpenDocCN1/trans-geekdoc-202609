where `z_{1 - α/2}` 是标准正态分布的上尾百分位数，使得 `Φ(z_{1 - α/2}) = 1 - α/2`。因此，`C_0` 的（近似）`100(1 - α)%` 置信区间为

[`Ĉ_{T,n} - z_{1 - α/2} * σ_{C_T} / √n, Ĉ_{T,n} + z_{1 - α/2} * σ_{C_T} / √n`]

如果我们希望对某个 `ε > 0` 有 `P(|Ĉ_{T,n} - C_0| ≤ ε) ≈ 1 - α`，则选择样本量 `n` 使得 `z_{1 - α/2} * σ_{C_T} / √n = ε`，这等价于 `n = (σ_{C_T}² / ε²) * z_{1 - α/2}²`。
