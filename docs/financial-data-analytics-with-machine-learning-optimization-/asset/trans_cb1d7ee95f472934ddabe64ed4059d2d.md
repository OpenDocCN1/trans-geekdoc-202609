[4](#c10.xhtml#R_c10-note-0004) 黄金分割搜索方法通过计算两个初始端点 `a₀ = λ₀^(1) = 0` 和 `b₀ = λ₀^(2) = 1` 处的 `g(λ := S(β^(k) + Δ̂))` 值来初始化。对于第 `i` 次迭代，设置 `λᵢ^(1) := φaᵢ₋₁ + (1 − φ)bᵢ₋₁` 和 `λᵢ^(2) := (1 − φ)aᵢ₋₁ + φbᵢ₋₁`，其中 `φ = (√5 − 1) / 2` 为黄金比例，并计算 `g(λᵢ^(1))` 和 `g(λᵢ^(2))`。如果 `g(λᵢ^(1)) < g(λᵢ^(2))`，则设置 `aᵢ = aᵢ₋₁` 和 `bᵢ = λᵢ^(2)`；否则，设置 `aᵢ = λᵢ^(1)` 和 `bᵢ = bᵢ₋₁`。该过程重复进行，直到第 `j` 次迭代后端点之间的距离低于预设阈值 `ε`，此时极小值点 `λ̂` 可取为其中点 `(aⱼ + bⱼ) / 2`。该方法常用于对导数或梯度无法显式求取的函数进行最小化，因为算法中实际上并未显式要求这些量。
