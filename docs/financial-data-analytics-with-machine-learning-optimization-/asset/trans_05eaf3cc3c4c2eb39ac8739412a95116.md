

现在我们将所有新构造的 `v_i` 和 `u_j` 包含在矩阵 `V` 和 `U` 中，方法是令 `V = (V_r ; v_(r+1), ..., v_n)` 和 `U = (U_r ; u_(r+1), ..., u_m)`，因此 `V` 和 `U` 都是方阵。同时，通过向 `Σ_r` 添加 `m - r` 行新的零行和 `n - r` 列新的零列来形成 `m × n` 矩阵 `Σ`。这些定义导致对于 `i = r + 1, ..., n` 有 `A v_i = 0`，结合 ([9.18](#c09.xhtml#c09-disp-0068))，我们得出 `A V = U Σ`。最后，由于 `V` 由构造是正交的，我们也有 `A = U Σ V^T`。

总结一下，`u` 和 `v` 构成以下四个基本空间的基：

*   `u_1, ..., u_r` 构成 `A` 的列空间的一组标准正交基；
*   `u_(r+1), ..., u_m` 构成零空间 `N(A^T)` 的一组标准正交基；
*   `v_1, ..., v_r` 构成 `A` 的行空间的一组标准正交基；
*   `v_(r+1), ..., v_n` 构成零空间 `N(A)` 的一组标准正交基。
