
In particular, with `x ∈ X`, the maximum is attained at `λ = 0`, while for `x ∉ X`, `g_i(x) > 0` for some `i`, such that in general `λ⊥g(x)` is increasing in `λ_i` without bound. Hence, we have

[(11.30)](#c11.xhtml#R_c11-disp-0071)

```
m := min_{x ∈ X} f(x) = min_{x ∈ R^p} max_{λ ≥ 0} (f(x) + λ⊥g(x)) = min_{x ∈ R^p} max_{λ ≥ 0} L(x, λ).
```

By using the max‐min inequality ([11.28](#c11.xhtml#c11-disp-0064)), which holds true for unbounded domains, we see that

```
min_{x ∈ R^p} max_{λ ≥ 0} (f(x) + λ⊥g(x)) ≥ max_{λ ≥ 0} min_{x ∈ R^p} (f(x) + λ⊥g(x)).
```

```

```
