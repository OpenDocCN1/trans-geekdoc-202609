

类似于上述方式，如果 `y` 是连续变量，而 `x` 是另一个具有分布函数 `F_x(x)` 的任意类型变量，我们可以使用给定 `x` 的 `y` 的条件密度 `f(y|x)` 来定义给定 `x` 的 `y` 的 *条件微分熵* 为：

`h(y|x) := -∫_X ∫_Y f(y|x) ln f(y|x) dy dF_x(x).`

例如，考虑双变量正态对 `x, y`，使得两者都具有共同的边缘分布 `N(μ, σ²)`，并且它们还具有相关系数 `ρ ∈ (-1, 1)`；显然，`y|x=x ~ N(μ(1-ρ) + ρx, σ²(1-ρ²))`，那么条件微分熵 `h(y|x)` 可以从 ([13.5](#c13.xhtml#c13-disp-0007)) 得到为：

`h(y|x) = 1/2 [1 + ln(2πσ²(1-ρ²))],`

这小于 `h(y) = 1/2 [1 + ln(2πσ²)]`。同样，这表明熵有所减少。
