主成分分析与推荐系统

`Principal Component Analysis` (PCA) 是一种经典的多元统计技术，用于对一组底层随机变量进行降维。它用于寻找原始变量的线性组合，使得即使在降维后，原始数据中的信息也“本质上”得以保留。作为一种推广，推荐系统中的协同过滤方法用于保留二维随机数组中包含的基本信息。在深入探讨其细节之前，我们首先来看 PCA 在识别从美国债券市场提取的利率期限结构的重要因素方面的一个有趣应用。
