

# —唐乃璋

前恒生银行首席风险官兼执行委员会成员；前上海商业银行有限公司副首席执行官兼首席风险官；前中信银行国际董事、副首席执行官、替代首席执行官、首席风险官及资产管理副主席；香港银行学会董事（2019–2021）；香港中文大学金融学系实践教授

`Financial Data Analytics` 是一本非常出色的著作，内容广泛，涵盖了许多有趣的主题。它凭借详细的数学推导、实用示例、真实数据集以及 Python 和 `R` 中现成可用的程序代码的独特结合，在同类书籍中脱颖而出。它还包含了作者近期研究的许多新颖结果。无论您是相关领域的研究人员、金融行业的从业者，还是准备参加精算师学会或英国精算师学会考试的学生，`Financial Data Analytics` 无疑都是一本宝贵的参考书。

# —杨海良

精算师学会准会员及英国精算师学会荣誉会员；《Insurance: Mathematics and Economics》编辑；西交利物浦大学 `Department of Financial and Actuarial Mathematics` 教授

在我于摩根大通和随后的中信证券的职业生涯中，我参与并见证了各种数据分析工具如何彻底改变金融行业。`Financial Data Analytics` 是这一趋势的完美体现，它从理论视角和实践方面讨论了数据分析中广泛的现代工具，并为真实案例提供了 Python 和 `R` 中可直接实现的程序代码。这种组合在少数几本数据分析书籍中非常独特；它不仅反映了作者广泛的理论知识，还展示了他们与金融和保险行业的紧密联系。我实际上有机会验证书中提到的一些盈利策略，它们的表现确实令人印象深刻。这本书远不止是学者的学术专著；它无疑是从业者探索自身金融炼金术的启发性指南。

# 关于作者

**Yongzhao Chen (Sam)** 获得香港大学精算学学士学位（一等荣誉）和精算学博士学位。他目前是香港恒生大学数学、统计学和保险学系助理教授。他的研究兴趣包括精算学，尤其是可信性理论和数据分析。

**Ka Chun Cheung** 获得香港大学精算学学士学位（一等荣誉）和博士学位。他曾担任精算学课程主任，目前是香港大学计算与数据科学学院统计学和精算学系系长兼正教授。他是精算师学会准会员，并当选为国际统计学会成员。他担任《Insurance, Mathematics and Economics》和《Journal of Industrial and Management Optimization》的编辑委员会成员。他目前的研究兴趣包括精算学的各种主题，包括最优再保险、随机序、依赖结构和极值理论。
