
3. **Kendall's** `τ_b` [\[13\]](#c12.xhtml#c12-bib-0013): this non‐parametric metric quantifies the dependence between two features based on the concept of *concordant pairs*. A pair of observations `(x_ui, x_uj)` and `(x_vi, x_vj)`, `u ≠ v`, is said to be *concordant` if `(x_ui - x_vi)(x_uj - x_vj) > 0`; *discordant* if `(x_ui - x_vi)(x_uj - x_vj) < 0`; and tied if `(x_ui - x_vi)(x_uj - x_vj) = 0`. The Kendall's `τ_b` coefficient between `x_i` and `x_j` is computed by: `τ_b := (C - D) / √((n_0 - n_i)(n_0 - n_j)),` where `C` and `D` denote the respective total numbers of concordant and discordant pairs, `n_0 := (n choose 2)` is the total number of possible pairs of observations, and `n_k := Σ(m : s_k,m ∈ X_k) t_km(t_km - 1) / 2` with `t_km` being the total number of tied pairs having the value `s_k,m` for the feature `x_k`.
