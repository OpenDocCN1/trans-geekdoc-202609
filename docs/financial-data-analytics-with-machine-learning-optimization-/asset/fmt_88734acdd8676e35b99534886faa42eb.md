
# Box–Muller 变换

虽然 *inverse function transform* 方法对于一般分布模拟来说看起来很基础，但这种方法的一个直接局限是，很多时候逆累积分布函数 `F_x^{-1}` 无法显式表示，如果没有这个，程序编码就无法方便地实现。对于正态分布尤其如此，因为正态累积分布函数的逆函数无法写成有限个初等函数的和。幸运的是，可以采用一种称为 *Box–Muller transformation* 的替代方法，从而可以轻松生成一对标准正态随机变量。

考虑以下变换，其中 `u_1` 和 `u_2` 是独立的均匀分布随机变量，取值于区间 `[0, 1]`：

```
z_1 := √(-2 ln u_1) cos(2π u_2) and z_2 := √(-2 ln u_1) sin(2π u_2),
```

然后 `z_1` 和 `z_2` 独立地服从 `N(0, 1)` 分布。为了验证这一点，我们首先将 `u_1` 和 `u_2` 用 `z_1` 和 `z_2` 表示如下：

```
{
u_1 = exp{-(z_1² + z_2²)/2} =: exp{-q/2},
u_2 = (1/(2π)) arctan{z_2/z_1}, if z_1 ≠ 0,
}
```
