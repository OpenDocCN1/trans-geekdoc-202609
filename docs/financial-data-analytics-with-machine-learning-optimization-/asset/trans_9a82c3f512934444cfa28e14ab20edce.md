## 4.6 齐夫定律与 COVID-19 数据

齐夫定律在流行病学数据中的出现具有重要意义，因为它提供了一种在医疗保健管理中标记数据以供进一步分析的实用手段。调查通常成本高昂，只有在有充分理由怀疑数据存在欺诈时才应启动。中央政府从许多不同的来源汇编数据，例如地方政府或直接来自医疗机构，因此有明确的需求来自动化和简化欺诈检测程序。此外，使用齐夫定律进行欺诈检测的理由在于中央政府对公民信息的垄断；如果政府不公布相关数据的地区细分，地方当局就很难按照齐夫定律伪造数据。通过长期监控数据且不详细发布，中央政府可以确定数据中预期的齐夫模式，从而开发自动化欺诈检测系统。
