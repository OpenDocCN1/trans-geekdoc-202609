## 示例 5.11 示例 5.9 在 Black–Scholes 模型中的延续，theta 仅等于 2，采用路径微分法和似然比法

与示例 5.9 的设置相同，我们使用似然比法来估计 Black–Scholes 框架下欧洲看涨期权的 delta 和 vega。此外，我们将结果与路径微分法得到的结果进行比较。两种方法得到的估计值与在 Programme 5.33 中通过 Python（resp. 通过 Programme 5.34 通过 `R`）实现的模拟次数进行了绘图。

图 5.14（通过 Python）和 5.15（通过 `R`）分别说明了使用路径微分法和似然比法的估计器的收敛性。我们观察到，随着路径（模拟）数量的增加，两种方法都逐渐趋近于位于真实值的蓝色虚线，这验证了路径微分法和似然比法。然而，路径微分法中两个希腊字母的近似相比似然比法表现出更优越的收敛性能。

为了应用这种似然比法，需要对终端状态密度相对于感兴趣参数的敏感性具有显式表达式。通常，这在实践中可能无法立即实现。尽管如此，大多数证券价格由 SDEs 建模，通过使用 `Malliavin Calculus` [2](#c05.xhtml#c05-bib-0002)，[13](#c05.xhtml#c05-bib-0013)，仍然可以将密度写为涉及这些 SDEs 的所谓 `Malliavin derivatives` 的期望泛函的函数。在此基础上，似然比法可以在更多场景中使用。也就是说，从上述说明来看，路径微分法表现出更好的性能。有趣的是，其哲学与 `Jacobian flow` 的概念密切相关，因此与 SDEs 的 Malliavin 可微性紧密相连。

最后但同样重要的是，Malliavin 微积分可以通过著名的 `Clark–Ocone formula` 来表达各种最优投资组合选择问题中的对冲投资组合权重，这再次涉及 Malliavin 导数，但这次是关于终端收益的。由于篇幅限制，我们无法在本书中涵盖随机分析的这个精彩主题，并邀请读者查阅 [1](#c05.xhtml#c05-bib-0001)、[12](#c05.xhtml#c05-bib-0012) 及其中的参考文献以了解详情。
