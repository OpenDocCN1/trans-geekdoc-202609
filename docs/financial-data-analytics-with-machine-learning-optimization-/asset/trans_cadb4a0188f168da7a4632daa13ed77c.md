

假设 `F` 是一个 `d` 维正态分布函数，其均值向量为 `μ`，协方差矩阵为 `Σ`。根据不变性性质，其 Copula 在标准化后保持不变，因此我们可以简单地取 `μ = 0`，并将 `Σ` 作为其对应的相关系数矩阵 `Pρ`。*高斯 Copula* 定义为该 `d` 维正态分布的 Copula：

`C_{Pρ}^{Gauss}(u) = Φ_{Pρ}(Φ^{-1}(u_1), ..., Φ^{-1}(u_d)), for u_i ∈ [0, 1], i = 1, ..., d`

其中 `Φ_{Pρ}` 是均值为 `μ = 0` 且协方差矩阵为 `Pρ` 的 `d` 维正态分布的联合累积分布函数，而 `Φ` 是标准正态分布的累积分布函数。Copula 密度可按如下方式求得：

(8.13) `c_{Gauss}(u) = 1 / |Pρ|^{1/2} exp{-1/2 z^T (Pρ^{-1} - I_d) z},`

其中 `z = (Φ^{-1}(u_1), ..., Φ^{-1}(u_d))^T`，`I_d` 是 `d × d` 单位矩阵。

高斯 Copula 在 2008 年之前广泛用于进行压力测试或信用风险分析，但由于正态分布通常会低估极端损失的概率，有人认为它导致了 2007–2008 年信贷紧缩。让我们将带有经验边缘分布的高斯 Copula 应用于我们的股票数据 `stock_1999_2002.csv` 作为示例。
