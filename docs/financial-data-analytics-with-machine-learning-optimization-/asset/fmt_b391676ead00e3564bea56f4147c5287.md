[1](#c10.xhtml#R_c10-note-0001) The estimate is obtained by minimizing the `L²`‐loss function `L(β) = (y − X̃β)⊤(y − X̃β) = y⊤y − y⊤X̃β − β⊤X̃⊤y + β⊤X̃⊤X̃β`, whose first order condition `∇βL = −2X̃⊤y + 2X̃⊤X̃β = 0` gives `X̃⊤(X̃X̃β̂) = X̃⊤y`. Note that this is a regression without regularization especially when `X` is not so sparse. Otherwise, for a sparse `X`, we add an additional regularizer of `∑{i : xi is sparse} λi|βi|` to the objective function; further discussion can be found in [Chapter 11](#c11.xhtml).
