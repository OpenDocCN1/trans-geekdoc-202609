

1. 对于每个标签 `c_k`，计算经验无条件概率 `P̂(c(x) = c_k) = |{i : c(x_i) = c_k}| / n`。

2. 对于每个特征变量 `x_j` 和特征值 `x*_j`，计算每个类别 `c_k` 的经验条件概率：`P̂(x_j = x*_j | c(x) = c_k) = |{i : x_ij = x*_j, c(x_i) = c_k}| / |{i : c(x_i) = c_k}|`。

3. 新观测值 `x*` 被分类为属于类别 `c_k̂`，其中 `k̂ = arg max_(k=1,...,M) (∏_(j=1)^p P̂(x_j = x*_j | c(x) = c_k) P̂(c(x) = c_k))`。
