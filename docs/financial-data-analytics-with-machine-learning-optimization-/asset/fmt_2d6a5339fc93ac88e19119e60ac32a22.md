
Using this definition to find `μ_q` relies on sorting `x_1, ..., x_n`. For instance, to find the empirical median `μ_0.5`, we first sort the `x_i`'s in ascending order `x_(1) ≤ ... ≤ x_(n)`. If `n` is odd, then `μ_0.5` is simply `x_((n+1)/2)`, the number exactly in the middle of the sorted sequence. Similarly, if `n` is even, the `μ_0.5` can be any number in the interval `[x_(n/2), x_(n/2+1)]`.

An alternative method to find `μ_q`, rather than dealing with time-consuming sorting, is to note that it minimizes the function

```
f_q(μ) := Σ(i=1 to n) ρ_q(x_i - μ), where ρ_q(r) := qr - r * 1_{r < 0},
```

which can be seen directly from ([6.18](#c06.xhtml#c06-disp-0035)). We can minimize `f_q` using MM algorithm by constructing a suitable surrogate function. To this end, we first construct a surrogate function for the component function `ρ_q` at an arbitrary non-zero point, say `r*`. As `ρ_q` is V-shaped, an obvious choice would be a convex quadratic function that touches `ρ_q` at both `|r*|` and `-|r*|`.
