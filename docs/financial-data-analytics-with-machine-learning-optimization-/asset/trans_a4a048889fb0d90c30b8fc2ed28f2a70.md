

状态 `s ∈ S` 的周期可以类似地定义如下。对于任意 `s ∈ S`，令 `I_S(s) := {n : f(s) > 0 for any f ∈ B⁺(S), f(s) > 0} ⊆ ℕ₀ := {0, 1, 2, ...}`。状态 `s` 的周期 `d(s)` 定义为：

```
d(s) := { gcd(I_S(s)) if I_S(s) ≠ ∅; 0 otherwise }
```

若对于所有 `s ∈ S` 均有 `d(s) = 1`，则称不可数状态马尔可夫链 `{xₙ}` 为 *非周期性*。

以下命题总结了不可数状态空间马尔可夫链周期的一些性质。其结构与有限状态马尔可夫链的相同，证明可参见 [附录 6.A.2](#c06.xhtml#c06-sec-0038)。

#### [命题 6.1](#c06.xhtml#R_c06-fea-0016)

1. 若 `s₁ ↔ s₂`，则 `d(s₁) = d(s₂)`。

2. 在 [假设 6.1](#c06.xhtml#c06-fea-0012) 下，对于每个 `s ∈ S`，存在依赖于 `s` 的 `Nₛ ∈ ℕ`，使得当 `n ≥ Nₛ` 时，对于任意满足 `f(s) > 0` 的 `f ≥ 0`，均有 `f(s) > 0`。
