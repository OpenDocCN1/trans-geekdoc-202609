

转移概率矩阵 `P′` 对应于以下转移机制：给定 `x_n = s_i`，下一步的建议状态 `s_j` 根据 `P`（即为方便选择的马尔可夫链的转移矩阵）的第 `i` 行绘制，因此 `α_{i,j}` 也可以轻松计算。然后我们以 `α_{i,j}` 的概率接受该建议并设置 `x_{n+1} = s_j`；否则，设置 `x_{n+1} = s_i`。回顾 [定理 6.4](#c06.xhtml#c06-fea-0030)，对于可计数状态空间上的马尔可夫链，其转移概率矩阵 `P′` 既不可约又非周期性，`x_n` 的极限分布唯一存在，并由平稳分布 `π` 给出，正如所要求的那样。

在不可计数状态空间 `S` 的情况下，即使对于非紧空间（如 `R^p`，满足适当的轻尾要求），接受概率的表达式与 ([6.27](#c06.xhtml#c06-disp-0098)) 类似。设 `π(·): S → R_+` 为目标概率密度，`q(·|·): S × S → R_+` 为预先指定的联合连续且严格正的转移密度（核）。则接受概率采用以下形式：

[(6.29)](#c06.xhtml#R_c06-disp-0100) `α_{u,v} = min{ π(v)q(u|v) / π(u)q(v|u), 1 }` 对于任何 `u, v ∈ S`。
