
*Proof of Theorem 4.1*: Let `x₁, …, xₖ` be iid continuous random variables on `[0, 1)` with a common density `f ∈ L²[0, 1]` and consider `w := Σᵢ₌₁ᵏ xᵢ (mod 1)`. Then it is clear that `w` is also a continuous random variable on `[0, 1)` and its density function `h`, by [Lemma 4.2](#c04.xhtml#c04-fea-0008), has Fourier coefficients `ĥ(n) = (f̂(n))ᵏ` for `n ∈ ℤ`. In order to show that `w` approaches to a uniform distribution on `[0, 1)`, it suffices to show that `h → 1` in the `L²`-norm on `L²[0, 1]` as `k → ∞`. Indeed, by Parseval's identity:

```
‖h − 1‖₂² = ∫₀¹ (h(t) − 1)² dt = Σₙ≠₀ |ĥ(n)|² = Σₙ≠₀ |f̂(n)|²ᵏ = Σₙ≠₀ |f̂(n)|² |f̂(n)|²ᵏ⁻² ≤ (supₙ≠₀ |f̂(n)|)²ᵏ⁻² · Σₙ≠₀ |f̂(n)|².
```
