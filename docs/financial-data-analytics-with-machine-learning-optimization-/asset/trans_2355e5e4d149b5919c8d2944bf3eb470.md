

where `(xᵢ, yᵢ)` are iid copies of `(x, y)`. In practice, the value of `b* = -Cov(x, y) / Var(y)` is not known *a priori*, but it can be estimated using the simulated sample `(xᵢ, yᵢ)` by using the sample correlation coefficient,

```
b̂* = -Σᵢ₌₁ⁿ (xᵢ - x̄)(yᵢ - ȳ) / Σᵢ₌₁ⁿ (yᵢ - ȳ)²,
```

and the estimator `ψ̂_C` becomes `x̄ + b̂*(ȳ - μ_y)`.

**[示例 5.3](#c05.xhtml#R_c05-fea-0010) *([示例 5.1](#c05.xhtml#c05-fea-0002) 的延续)*** 我们选择 `y := (1 - u)²·⁵` 作为控制变量，其均值可以显式计算：

```
μ_y = ∫₀¹ (1 - x)²·⁵ dx = -∫₀¹ (1 - x)²·⁵ d(1 - x) = 1 / 3.5 = 2/7.
```
