

考虑一个投资组合，并设 `L` 为其在 1 天时间范围内的价值损失。我们说，该投资组合在置信水平 `p ∈ (0, 1)` 下的 1 天风险价值，记为 `V@R_L(p)`，等于 `V`，如果我们有 `100p`% 的把握，即次日损失不会超过 `V` 美元。通常，置信水平 `p` 取值接近 1，例如 `p = 0.99`。如果用 `F_L` 表示损失变量 `L` 的累积分布函数（cdf），那么 `V@R_L(p)` 就是损失分布的 `p`-分位数：

```
V@R_L(p) = F_L^(-1)(p) = min { l ∈ ℝ : F_L(l) ≥ p }.
```

特别是，如果 `F_L` 是连续且严格递增的，那么 `V@R_L(p)` 仅仅是方程 `F_L(l) = p` 的唯一解，另请参见 [图 8.1](#c08.xhtml#c08-fig-0001)。

![图 8.1 `V@R_L(x)` 示意图。](images/c08f001.png)

[**图 8.1**](#c08.xhtml#R_c08-fig-0001) `V@R_L(x)` 示意图。

请注意，`N` 天的 `V@R_L(x)`，记为 `V@R_L(N, x)`，等于 `√N · V@R_L(x)`，前提是 `N` 天期间每日变化服从独立同分布的正态分布；此计算也隐含假设 `E(L) = 0`。
