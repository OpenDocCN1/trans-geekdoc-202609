
where `u_i := F_0(x_i)`, `i = 1, ..., n` are sample from `U(0, 1)`. Therefore `D_n` is a distribution-free statistic. When testing the null hypothesis `H_0: F(x) ≡ F_0(x)` against all possible alternatives `H_1: F(x) ≠ F_0(x)`, for some specified distribution function `F_0`, the null hypothesis `H_0` is rejected if the observed value of `D_n` is greater than some chosen critical value. To form a confidence band based on a sample of size `n` at the critical level `α`, one can use the equation `P(D_n ≥ d_α) = α` such that

```
1 - α = P(sup_x |F̂_n(x) - F(x)| ≤ d_α)
      = P(|F̂_n(x) - F(x)| ≤ d_α, for all x)
      = P(F̂_n(x) - d_α ≤ F(x) ≤ F̂_n(x) + d_α, for all x).
```
