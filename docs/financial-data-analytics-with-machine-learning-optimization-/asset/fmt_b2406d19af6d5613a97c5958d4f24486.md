If `A` is an `r × p` deterministic matrix, then `y = Ax` is an `r × 1` random vector with mean `E(y) = Aμ` and covariance matrix `Var(y) = AΣAᵀ`; moreover, for another `r × 1` random vector `z = Bx`, where `B` is another `r × p` constant matrix, the covariance of `y` and `z` is `Cov(Ax, Bx) = AΣBᵀ`.

2.  The correlation matrix `R = (ρᵢⱼ)` of `x` can be computed from its covariance matrix `Σ = (σᵢⱼ)` by the formula `R = D⁻¹ᐟ²ΣD⁻¹ᐟ²`, where `D` is the diagonal matrix denoted by `diag(σ₁₁, …, σₚₚ)`, and `D⁻¹ᐟ² := diag(1/√σ₁₁, …, 1/√σₚₚ)`.
