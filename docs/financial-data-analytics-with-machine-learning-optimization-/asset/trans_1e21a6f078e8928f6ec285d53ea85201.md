

测试的总体准确率为 `(2 + 195) / 200 = 98.5%`，之所以很高，仅仅是因为该疾病的罕见性。事实上，大部分正确预测都来自真阴性；然而，该测试的精确率仅为 `2 / 4 = 50%`，而召回率（TPR）仅为 `2 / 3 = 66.7%`。综合起来，这些使得 `F1`‐分数变为 `4 / 7 = 57.14%`；此外，该测试的 FPR 为 `2 / 197 = 1.02%`。

TPR 和 FPR 的另一个用途是判断分类算法是否足够有效。特别是，一个高效的分类器应尽可能最大化 TPR，同时理想情况下降低 FPR。这种相互关系可以通过使用受试者工作特征（ROC）曲线来更好地理解。

考虑 [表 10.3](#c10.xhtml#c10-tbl-0003)，它显示了一个包含 20 个观测值 `(x_i1, x_i2)` 及其对应标签 `y_i` 的训练数据集，其中 `i = 1, ..., 20`。其中 10 个观测值的 `y_i = 1`（属于正类），其余的 `y_i = 0`（属于负类）。最后一列显示了由 `(x_i1, x_i2)` 上的逻辑回归给出的预测概率 `π̂_i = P̂(y_i = 1 | x_i1 = x_i1, x_i2 = x_i2)`。这些观测值按 `π̂_i` 的降序排列。

设概率阈值 `u`（Sub[section 10.4.2](#c10.xhtml#c10-sec-0007)）从正无穷变化到 0。我们可以观察 TPR 和 FPR 作为 `u` 的函数的变化情况。请注意，将分类算法应用于数据集会为概率阈值 `u` 的每个值生成一个分类器；本质上，它生成了一组分类器。例如，对于极端场景 `u ≥ 1`，[表 10.3](#c10.xhtml#c10-tbl-0003) 中的所有观测值都被简单地分类为负类，因为显然所有 `π̂_i ≤ 1 < u`。没有观测值被分类为正类，这使得 `TPR = FPR = 0`，从而得到以下混淆矩阵（[表 10.4](#c10.xhtml#c10-tbl-0004））。
