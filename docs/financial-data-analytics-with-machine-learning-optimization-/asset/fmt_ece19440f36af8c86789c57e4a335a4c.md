4. If we do not impose any distributional assumption on `L`, we can estimate `ES_L(p)` by sorting the sample of observed losses: `L_(1), ..., L_(n)` in descending order. Assuming that there is no tie in the sample, then [(8.9)](#c08.xhtml#R_c08-disp-0040) `ES_L(p) ≈ (1 / n(1 - p)) Σ(k=1 to K-1) L_(k) + (1 - (K - 1) / n(1 - p)) L_(K)`, where `K = ⌈n(1 - p)⌉` is the smallest integer greater than or equal to `n(1 - p)`. We note that this formula is simply the expected shortfall of the empirical distribution of the sample at the confidence level `p`. It assigns equal weights for each ordered sample point `L_(k)`, with a continuity correction for the final least term.
