
Differentiating the Lagrangian with respect to `p_j` yields:

∂L(p_(K), λ)/∂p_j = Σ(i=1 to n) (y_ij / p_j) - λ, for j = 1, ..., k

and equating each of these with zero, we obtain λ = Σ(i=1 to n) (y_ij / p_j), hence

p̂_j = Σ(i=1 to n) (y_ij / λ)

Since summing all p̂_j's is always equal to 1, we have

1 = Σ(j=1 to K) p̂_j = Σ(j=1 to K) Σ(i=1 to n) (y_ij / λ)

which gives λ = n. Therefore, the maximum likelihood estimators p̂_j's are given by:

p̂_j = (1/n) Σ(i=1 to n) y_ij = (1/n) Σ(i=1 to n) 1{x_i = A_j}, for j = 1, ..., K

as expected.
