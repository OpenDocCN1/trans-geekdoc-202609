

要从随机变量 `x` 生成样本，该变量在其支持集 `X_f` 上具有密度 `f(x)`，我们可以提出一个候选密度 `g(x)`，其支持集为 `X_g`，使得 `X_f ⊆ X_g`，从中抽取样本要容易得多，该密度“包络” `f(x)`；更准确地说，只要存在一个有限常数 `M > 1`，使得对所有 `x ∈ X_f` 都有 `f(x) ≤ M g(x)`。下面的算法说明了拒绝采样的一般步骤：

1. 生成 `x_i ~ g(x)`；

2. 生成 `u_i ~ U(0, 1)`，若 `u_i ≤ f(x_i) / (M g(x_i))` 则接受 `x_i`，否则拒绝 `x_i`；

3. 重复步骤 1) 和 2) 共 `N` 次，仅保留被接受的 `x_i` 作为生成的样本。
