作为补充说明，超参数 p ∈ (0, 1) 和 q > 1 应谨慎选择，通常基于对股票历史表现的初步分析，例如通过优度指数 λₜ。基于这一基本原则对这些超参数的实际调整留给读者作为项目。我们还注意到，上述估计程序不同于知晓并使用未来的精确价格，后者需要更多信息，甚至包括带噪声的观测值。相反，对于我们提出的方法，只需知道趋势即可，我们也可以通过分析包含在不同来源中的历史信息来猜测趋势，包括交易量以及社交媒体和新闻，使用文本挖掘等工具，而不仅仅是数值方法。
