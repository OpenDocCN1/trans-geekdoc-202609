## NOTES

1. [1](#c09.xhtml#R_c09-note-0001) As a usual practice, bond prices are typically calculated semiannually.

2. [2](#c09.xhtml#R_c09-note-0002) Another commonly used unit of measurement in practice is `basis point` (BP); 100 BPs equal 1 percent.

3. [3](#c09.xhtml#R_c09-note-0003) To see this, first note that, each `h_k` is actually an eigenvector of the symmetric matrix `S` with respect to the distinct eigenvalue `λ_k`. Therefore, by Property 23 in [Section 1.2](#c01.xhtml#c01-sec-0007), `Cov(y_i, y_j) = h_i^T S h_j = h_i^T (λ_j h_j) = λ_j (h_i^T h_j) = 0`, for `i, j = 1, 2, ..., p`; also see [Section 9.2](#c09.xhtml#c09-sec-0003).

4. [4](#c09.xhtml#R_c09-note-0004) Recall that `x̃_i`'s have been de‐meaned (or centralized), such that `E(x̃_i) = 0` for all `i = 1, 2, ..., p`, so does `E(y_j) = 0` for all `j = 1, 2, ..., p`.

5. [5](#c09.xhtml#R_c09-note-0005) Unlike the examples in the stock trading context where we assumed 252 trading days in a year, the interest is accrued on every calendar day.
