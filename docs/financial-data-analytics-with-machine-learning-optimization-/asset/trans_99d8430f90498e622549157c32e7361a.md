## 图像分割

图像处理的一个典型示例是 `image segmentation`，它是指将图像分割为 `K` 个不同的段，以便后续数据处理更加容易，例如使用 `Photoshop` 等照片编辑软件。在此上下文中实现 `K`‐means 时，我们通常采用 `CIE 1976 Lab color space`（又称 `L*a*b*` 通道），而不是常规的 RGB 通道。该色彩空间也以三元组表示一个像素，即明度 `L*`、绿红分量 `a*` 和蓝黄分量 `b*`。与 RGB 设置相比，这三个坐标的数值变化能更好地反映人类感知到的颜色变化幅度。

要根据颜色进行分割，我们可以忽略明度分量 `L*`，而从每个像素中提取剩余的 `a*` 和 `b*`，形成一个二维点样本，其大小等于图片中像素的总数。然后使用 `K`‐means 算法或其之前提到的变体对该样本进行聚类，最终落入同一簇的像素将被分配相应质心的相同 `a*` 和 `b*` 值。[Figure 14.7](#c14.xhtml#c14-fig-0007) 展示了使用 `K`‐means 聚类（`K = 5`）进行图像分割的示意图。![FIGURE 14.7 Image segmentation using upper K‐means clustering.](images/c14f007.png)

## 照片去噪与字典学习

我们可能已经受益的另一个示例是 `photo denoising`，这是一种帮助照片去除由电子引起的亮度或颜色随机噪声的机制，从而使照片更具美感。如今它已非常普遍，我们几乎察觉不到它的存在，这要归功于加速该过程的 `dictionary learning` 技术。

字典学习与 PCA 类似：给定一个数据集，我们希望提取一些称为 `atoms` 的基本元素，使得几乎所有特征向量都可以用这些基本构建块来表示。这些原子的集合被称为 `dictionary`。正是在这个阶段，`K`‐means 聚类或其扩展 `K`‐SVD (`K`‐SVD) [\[2\]](#c14.xhtml#c14-bib-0002) 被实现。

这里我们简要总结 `K`‐SVD：设 `Y ∈ R^(p×n)` 为 `n` 个观测图像信号的矩阵，每个信号具有 `p` 维特征，而 `D ∈ R^(p×K)` 为 `dictionary`，其中第 `k` 列 `d_k` 是要学习的第 `k` 个原子，`k = 1, ..., K`。
