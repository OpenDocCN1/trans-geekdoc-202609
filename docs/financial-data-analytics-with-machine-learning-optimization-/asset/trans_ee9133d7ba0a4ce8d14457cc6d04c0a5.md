## (V) 特征值和特征向量

对于任何 `p × p` 矩阵 `A`，行列式 `|A - λI_p|` 是关于 `λ` 的 `p` 次多项式。多项式方程 `|A - λI_p| = 0` 的 `p` 个根，记为 `λ_1, ..., λ_p`（计重数），称为 `A` 的 *特征值*（或 *潜在根*）。因此，每个 `A - λ_i I_p` 都是奇异矩阵，因此存在非零向量 `h_i` 使得 `(A - λ_i I_p)h_i = 0`（或等价地 `Ah_i = λ_i h_i`）；`h_i` 称为与 `λ_i` 对应的 `A` 的 *特征向量*。如果 `h_i` 被取为单位长度，即 `h_i^⊤ h_i = 1`，则它被称为 `A` 的 *归一化（单位）特征向量*。
