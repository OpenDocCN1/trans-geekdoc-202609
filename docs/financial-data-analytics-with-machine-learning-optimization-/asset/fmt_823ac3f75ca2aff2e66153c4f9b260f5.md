
Consider a portfolio in which a constant portion of wealth `ω` is invested in the stock and the remaining portion `1 - ω` is invested in the bond. Let `{X_t}` be the wealth process at time `t`. Then the number of stocks bought at time `t` is `ω X_t / S_t`, while the units of bond bought is `(1 - ω) X_t / B_t`. By ([7.29](#c07.xhtml#c07-disp-0049)) and ([7.32](#c07.xhtml#c07-disp-0053)), the wealth process `{X_t}` then satisfies the dynamics `dX_t = (ω X_t / S_t) dS_t + ((1 - ω) X_t / B_t) dB_t`. Thus `{X_t}` satisfies the SDE:

```
dX_t / X_t = ω dS_t / S_t + (1 - ω) dB_t / B_t = (ω μ + (1 - ω) r) dt + ω σ dw_t
```

whose solution, given an initial wealth `X_0`, is simply:

```
X_t = X_0 exp((ω μ + (1 - ω) r - ω²σ² / 2) t + ω σ w_t)
```

Therefore, the (one period) expected logarithmic return of the portfolio wealth is equal to:

```
E(ln X_t - ln X_0) = (ω μ + (1 - ω) r - ω²σ² / 2) t
```
