

`tν`-分布的尾部比任何正态分布的尾部都更厚。原则上，当 `ν → ∞` 时，它会变为正态分布，而 `tν`-分布通常用于模拟具有厚尾特征的证券数据。对于常见证券，`ν` 的值范围在 3 到 6 之间，如文献 [[11](#c03.xhtml#c03-bib-0011)] 所指出；具体来说，Harry Markowitz 指出自由度约为 4 时能得到最佳估计，这与标准普尔 500 指数股票收益率的观测结果一致。我们可以绘制 `tν` Q-Q 图来查看拟合效果是否更好。首先，我们需要估计自由度 `ν`。一种简单的方法是将从样本 `uᵢ` 中计算出的样本过度峰度 `ζ̂₂` 与理论值 `6 / (ν − 4)` 进行匹配，由此可得到 `ν = 6 / ζ̂₂ + 4` 的估计值。`tν`-分布的 `p`-th 分位数通过设置 `P{T ≤ tν(p)} = p` 得到，记作 `qₚ := tν(p)`。在 [Programmes 3.9](#c03.xhtml#c03-gra-0009)（Python）和 [3.10](#c03.xhtml#c03-gra-00010)（在 **R** 中）中，我们可以分别使用 `t_QQ_plot()` 和 `t.QQ.plot()` 函数来生成 `tν` Q-Q 图。
