
Thirdly, if the objective function `f: R^p → R` is twice differentiable and the Hessian matrix `∇_x ∇_x^T f(x)` is uniformly bounded from above (in the sense that there is a symmetric matrix `B` such that `B - ∇_x ∇_x^T f(x)` is still positive semidefinite for any `x`), then we can construct a surrogate function based on the second-order Taylor expansion of `f` at the current iterate `x^(t)`:

```
f(x) = f(x^(t)) + ∇_x f(x^(t))(x - x^(t)) + 1/2 (x - x^(t))^T ∇_x ∇_x^T f(z) (x - x^(t))
     ≤ f(x^(t)) + ∇_x f(x^(t))(x - x^(t)) + 1/2 (x - x^(t))^T B (x - x^(t))
     =: g(x, x^(t)).
```
