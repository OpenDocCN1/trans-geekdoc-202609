## 14.2 ![upper K](images/c14-i0379.png)<math display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math>‐NEAREST NEIGHBOUR

Having obtained clustering results, the next stage is the cluster prediction of new observations. One of the most popular approaches is the ![upper K](images/c14-i0380.png)<math display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math>*‐Nearest Neighbour algorithm* (![upper K](images/c14-i0381.png)<math display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math>‐NN), an example of *lazy‐learning*

**(I)** ![bold-italic upper K](images/c14-i0384.png)<math display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">K</mi></mrow></math>**‐NN classification**

In the ![upper K](images/c14-i0385.png)<math display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math>‐NN algorithm, the distance metric (or dis‐similarity) between the unlabelled observation and each existing one in the dataset is computed. The labels of the nearest (or most similar) ![upper K](images/c14-i0386.png)<math display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math> data points are then collected and counted, and the resulting class with the highest frequency is used to label the observation in question; see [Figure 14.8](#c14.xhtml#c14-fig-0008) for an illustration.
