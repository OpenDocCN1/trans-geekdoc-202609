
Therefore, the posterior distribution for `μ | y, h, φ, η ~ N(α̃_μ, β̃_μ^2)` is still a normal distribution, where

```
α̃_μ := β̃_μ^2 * (h_1 * (1 - φ^2) + (1 - φ) * Σ_{t=1}^{T-1} (h_{t+1} - φ * h_t) / ν_η + α_μ / β_μ^2);
β̃_μ^2 := ((1 - φ^2 + (T - 1) * (1 - φ)^2) / ν_η + 1 / β_μ^2)^{-1};
```

also, note that this conditional density depends on `y` through `h`.
