

第三，如果目标函数 `f: R^p → R` 是二次可微的，且黑塞矩阵 `∇_x ∇_x^T f(x)` 从上方一致有界（即存在一个对称矩阵 `B`，使得对于任意 `x`，`B - ∇_x ∇_x^T f(x)` 仍然是半正定的），那么我们可以基于 `f` 在当前迭代点 `x^(t)` 处的二阶泰勒展开构造一个代理函数：

```
f(x) = f(x^(t)) + ∇_x f(x^(t))(x - x^(t)) + 1/2 (x - x^(t))^T ∇_x ∇_x^T f(z) (x - x^(t))
     ≤ f(x^(t)) + ∇_x f(x^(t))(x - x^(t)) + 1/2 (x - x^(t))^T B (x - x^(t))
     =: g(x, x^(t)).
```
