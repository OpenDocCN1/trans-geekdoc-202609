### 5.2.3 Stratified Sampling

Let `y = h(x)` where `x` is a random variable with the density function `p(x)` on the domain `X` of `x`. We now want to estimate the unknown parameter:

```
θ = E(y) = E(h(x)) = ∫_X h(x) p(x) dx
```

Instead of estimating `θ` by the estimator

```
θ̂ = (1/n) Σ_{j=1}^n h(x_j)
```

with an arbitrarily chosen random sample `x₁, ..., x_n ~ p`, the idea of `stratified sampling` is to first partition the domain `X` into several separate regions, and then take a random sample from each region, after assigning some suitable weights, to finally estimate `E(h(x))`. More precisely, suppose that `X` is partitioned as:

```
X = ⋃_{j=1}^J X_j, where X_i ∩ X_j = ∅ whenever i ≠ j
```
