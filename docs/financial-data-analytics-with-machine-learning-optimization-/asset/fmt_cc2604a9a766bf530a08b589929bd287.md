
The gradient descent method described above is not recommended when the sample size `n` is large, as this results in a high demand of computational effort for the sum `σ∑(i∈I(n)(t)) y_i x_i` in each iteration. As a popular alternative, `stochastic gradient descent` (SGD) method can be used; also see Appendix `11.A.1` for a brief introduction. In SGD, the parameter is updated by considering only one single datum in each iteration; and we repeat the procedures, aiming to obtain the ultimate estimate for `ω`. If the data happen to be truly linearly separable, that is, there exists `ω* ∈ R^(p+1)` such that `sgn((ω*)^T x_i) = y_i` for all `i`, then the convergence to optimal weights of `ω` via stochastic gradient descent method can be guaranteed. To this end, by comparing `ω^(t)` and `ω^(t+1)`, the respective parameters before and after each update, the loss function dealing with SGD at the `(t+1)`‐th step is actually reduced.
