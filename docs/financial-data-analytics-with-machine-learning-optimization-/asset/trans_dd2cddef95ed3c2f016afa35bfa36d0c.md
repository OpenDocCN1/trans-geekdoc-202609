

# 分类树中的信息增益

*信息增益*在分类树每次分支时，为选择合适的属性起着至关重要的作用。在每个决策节点，都会计算观测值经验分布的熵，并通过判断其信息增益是否足够大（即分割后随机性（由熵衡量）的减少是否显著）来决定该节点是否应继续分割。

在每个节点中，在 `p` 个特征中，若分割能带来最大的可能信息增益，则会选择一个 `x^(j)`，而这个信息增益实际上就是节点子样本的标签 `y` 与该测试属性 `x^(j)` 之间的互信息。更准确地说，设 `x^(j_i)` 为附带子样本 `S^(i)` 的节点 `i` 上的选定属性。`x^(j_i)` 的信息增益 `IG(S^(i), x^(j_i))`（作为在 ([13.13](#c13.xhtml#c13-disp-0037)) 中定义的优度量的一个特例）被定义为：将 `S^(i)` 相对于 `x^(j_i)` 分割前后的平均熵之差：
