

接下来我们讨论并说明，如何使用 `R` 包 `recommenderlab` 来展示推荐系统如何作为一种重要的营销分析工具。例如，电影网站希望分析从访问者处获得的集体数据（例如观看历史和电影评分），然后根据从整个群体中获得的偏好预测，为他们推荐新电影供其观看。通常，这个 `R` 包为测试和开发推荐算法提供了基础架构，并支持评级（例如 1 到 5 星）和一元（0 或 1）数据集。我们首先简要描述使用该包通过 *SVD with column‐mean imputation* 方法训练推荐系统背后的数学原理。该方法由 `recommenderlab` 中的参数 `method="SVD"` 切换，其中评级矩阵 `R` 首先按每个订阅者进行归一化（即，减去均值，然后对每一行按标准差重新缩放），而生成的归一化矩阵的缺失项由其对应的列均值填补，即现有评分的电影平均值。然后程序应用 SVD 来查找 `p` 个最大奇异值 `σ1, …, σp` 及其对应的奇异向量 `Up` 和 `Vp`。在预测阶段，给定一个测试评级矩阵 `R(test)`，其列数（电影）与 `R` 相同，但行数（订阅者）可能不同，并回顾 `Rp = Up Σp Vpᵀ`，我们首先期望 `R(test)` 接近 `U(test) Σp Vpᵀ`。因此，我们简单地取 `U(test) = R(test) Vp (Σp)⁻¹`，然后订阅者归一化的预测评级矩阵由 `Rp(test) = U(test) Σp Vpᵀ = R(test) Vp (Σp)⁻¹ Σp Vpᵀ = R(test) Vp Vpᵀ` 给出。最后，我们对 `Rp(test)` 进行反归一化以给出预测结果。
