

与 PCA 不同，PCA 中的基本元素必须相互正交，而对原子来说这并非必要；事实上，字典矩阵的大小通常大于我们想要表示的数据矩阵。要检查一张新图像，我们只需调用字典及其所谓的 `representation`，即原子的线性组合形式，这能够实现对照片的快速且鲁棒的处理。作为一个简单的例子，考虑一组 `l` 张灰度（训练）图片，每张图片的大小为 `h × w`。[2](#c14.xhtml#c14-bib-0002) 建议将每张图片划分为 `m` 个不重叠的较小图像块，每个块包含 `p` 个像素，使得 `h × w = m × p`。然后将每个块展平为一个一维向量 `y_i^(train) ∈ R^p`，其中 `i = 1, ..., n = l × m`，观测训练矩阵由 `Y^(train) = (y_1^(train), ..., y_(l×m)^(train))` 给出；有了这个前提，假设 `D^(train) ∈ R^(p×K)`，其中 `K > p` 用于超完备字典，是 K-SVD 训练得到的字典。以与训练阶段相同的方式将一张新的灰度测试图像划分为 `m` 个块，得到观测测试矩阵 `Y^(test) = (y_1^(test), ..., y_m^(test)) ∈ R^(p×m)`。我们的目标是通过 K-SVD 找到观测测试图像信号矩阵 `Y^(test)` 的低秩近似 `Ỹ ∈ R^(p×m)`。然后，我们在稀疏编码步骤中采用选定的匹配追踪算法，在给定训练字典 `D^(train)` 的情况下找到稀疏系数矩阵 `X^(test)`。低秩近似为 `Ỹ = D^(train) X^(test)`，然后可以通过反转训练阶段的块划分步骤从中重建图像。这种方法与第 9.11 节中讨论的用于推荐系统的电影评分预测高度相似，并且特别适用于填充图像中的缺失像素。
