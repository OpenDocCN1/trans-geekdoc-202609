
The transition probability matrix `P′` corresponds to the following transition mechanism: given that `x_n = s_i`, a proposal state `s_j` for the next move is drawn in accordance with the `i`-th row of `P`, the transition matrix of a conveniently chosen Markov chain, so that `α_{i,j}` can also be easily computed. We then accept this proposal and set `x_{n+1} = s_j` with the probability of `α_{i,j}`; otherwise, we set `x_{n+1} = s_i`. Recall [Theorem 6.4](#c06.xhtml#c06-fea-0030), this Markov chain over a countable state space, with transition probability matrix `P′` being irreducible and aperiodic, the limiting distribution of `x_n` uniquely exists and is given by the stationary distribution `π`, as requested.

In the case of an uncountable state space `S`, even for a non-compact space such as `R^p` (with appropriate light tail requirements), the expression of the acceptance probability is analogous to ([6.27](#c06.xhtml#c06-disp-0098)). Let `π(·): S → R_+` be the target probability density, and `q(·|·): S × S → R_+` be a pre-specified jointly continuous and strictly positive transition density (kernel). Then the acceptance probability takes the following form:

[(6.29)](#c06.xhtml#R_c06-disp-0100) `α_{u,v} = min{ π(v)q(u|v) / π(u)q(v|u), 1 }` for any `u, v ∈ S`.
