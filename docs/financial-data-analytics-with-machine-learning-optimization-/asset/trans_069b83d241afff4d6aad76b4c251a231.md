本节以关于正态-Wishart 分布在精算科学中实际应用的评论作为结尾。在可信度理论中，它们已被广泛用于分层模型的制定，例如每笔索赔损失严重度模型，这有助于通过将估计的年均索赔频率与估计的每笔索赔平均损失严重度相乘来确定纯保费，以估计年度总损失的均值。此外，这些模型还可以促进对每个个体方差的高效估计，从而为保单持有人的风险保费定价提供合理依据；例如见 [\[12\]](#c01.xhtml#c01-bib-0012)。与此同时，随着时髦的 *演化可信度理论* 的兴起，该理论允许时间变化的均值和方差，引入时间结构对于提升正态-Wishart 模型的实用价值是不可避免的。一个可能的解决方案已在更近期的研究 [\[3\]](#c01.xhtml#c01-bib-0003) 中在半参数演化设定下提出，允许基于保单持有人的过去索赔历史同时估计每个时间点的均值和方差；该公式包含上述静态正态-Wishart 模型类作为一个有趣的特例，因此可以被视为在存在时间依赖结构时的可行扩展。我们期待更多研究进展沿此方向涌现。
