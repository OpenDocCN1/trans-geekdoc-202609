

我们在不同章节中以相对独立的方式介绍了各种在金融数据分析中有用的工具。实际上，并不存在单一的“万能钥匙”能够在任何单一问题的各个方面都效果最好，所有方法都有其自身的优缺点。为此，理解它们之间的异同，并为特定情境选择最合适的方法至关重要。以在[第 7 章](#c07.xhtml)中讨论的 Kelly 比例校准中漂移 `μ` 的估计为例：借助布林带的交易策略确实能够取得不错的表现，弥补 `μ` 在现实生活中估计不够准确的不足，但仍可通过使用[第 12 章](#c12.xhtml)中 CIBer 的回归版本进一步改进。特别是，由于 CIBer 除了能够处理各种证券价格和控制指数的数值信息外，还能处理金融报告中的分类数据，因此它能得出更好的 `μ` 估计，进而即使在没有布林带协助的情况下，也能制定出更多盈利的交易策略。

我们已到达本书的末尾，但绝非我们探索金融数据分析之旅的终点。我们希望本书能培养我们的读者建立所有方法之间联系的思维，并通过使用广泛的方法多角度分析每个问题，这无疑将涉及未来几代人制定的更高级技术。尽管如此，在这场快速演变中的核心要素，包括数学、统计学和元编程的重要性，将随着时间的推移而保持不变。
