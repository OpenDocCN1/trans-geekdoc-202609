
For if both `p` and `n` are very large, computing the inverse of Hessian `X^T R(k) X` for each iterative step becomes costly. Supposing that the initial seed `β(0)` is already quite close to the maximum point to be sought, we can replace `X^T R(k) X` by an approximated value, for instance, replacing `H(β(k)) = X^T R(k) X` simply by `H(β(m)) = X^T R(m) X` for some `m << k`, meaning that we only update the Hessian matrix once after quite a number of steps. Such a shortcut approach is a special case of the *quasi‐Newton method* (see [\[17\]](#c10.xhtml#c10-bib-0017)). This method can be useful yet it can lead to some limitations, namely as the iteration proceeds, some of the `π_i(k)`'s approach rapidly to 0 or 1, and their values may then be incorrectly recorded by the computer program as 0 or 1 due to a limited number of floating digits used. At that point, the Hessian `H(β(k))` becomes singular and the iteration ([10.26](#c10.xhtml#c10-disp-0076)) turns to be ill‐conditioned; also see [Figure 10.14](#c10.xhtml#c10-fig-0014).
