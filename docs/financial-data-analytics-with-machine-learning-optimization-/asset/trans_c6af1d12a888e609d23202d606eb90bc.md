## 8.8 通过共轭函数进行依赖建模

在本节中，我们将使用 `d` 表示底层多元风险的维度，使用 `p` 表示上下文中概率的临界水平。共轭函数用于在多元分布函数中建模和提取边缘随机变量之间的依赖结构。从数学上讲，一个 `d` 维共轭函数只是一个定义在超立方体 [0, 1]^d 上的 `d` 维分布函数，其 `d` 个边缘分布服从 [0, 1] 上的均匀分布。共轭函数之所以相关，主要是因为著名的 Sklar 定理 [[41]](#c08.xhtml#c08-bib-0041)，该定理断言，对于任何具有边缘分布 `F1, ..., Fd` 的 `d` 维联合分布函数 `F`，总是存在一个 `d` 维共轭函数 `C: [0, 1]^d → R`，使得对于任何 `x1, ..., xd ∈ R`，

[(8.10)](#c08.xhtml#R_c08-disp-0041)

```
F(x1, ..., xd) = C(F1(x1), ..., Fd(xd)).
```

如果所有边缘分布都是连续的，则这样的共轭函数是唯一的；在这种情况下，在 ([8.10](#c08.xhtml#c08-disp-0041)) 中的这个唯一共轭函数可以显式表示为

(8.11)

```
C(u1, ..., ud) = F(F1^(-1)(u1), ..., Fd^(-1)(ud)), for u1, ..., ud ∈ [0, 1].
```
