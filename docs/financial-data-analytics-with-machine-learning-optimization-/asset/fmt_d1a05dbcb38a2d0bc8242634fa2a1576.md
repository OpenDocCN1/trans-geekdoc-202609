
在之前（简化）的示例中，我们通过假设投资组合收益率服从均匀分布或正态分布来计算 V@R。只要分布函数的逆函数可以解析计算，就可以对其他分布进行类似计算；但这在实践中通常不可行。还有一种基于历史数据计算 V@R 的方法。假设今天是第 `n` 天，我们定义 `v_i` 为市场变量（股票价格或指数）在第 `i` 天的值，其中 `i = 0, 1, 2, ..., n`。过去 `n` 天的每日收益率为我们提供了第 `n` 天收益率的 `n` 种可能情景。基于第 `i` 种情景，明天价值 `v_{n+1}` 的预测值 `v̂_{n+1}(i)` 由以下公式给出：

`v̂_{n+1}(i) = v_n × v_i / v_{i-1}`

其中 `i = 1, ..., n`。从这 `n` 个 `v_{n+1}` 的估计值中，我们可以将其 1 天 V@R 估计为集合 `{v̂_{n+1}(1), ..., v̂_{n+1}(n)}` 的经验分位数。让我们通过 `stock_1999_2002.csv` 中的数据来说明这一点。假设我们在 2002 年 12 月 31 日花费 40,000 美元购买汇丰银行股票，30,000 美元购买中电控股股票，以及 30,000 美元购买长江和记股票。以下程序使用历史模拟计算该投资组合的 1 天 V@R，分别参见 [Programmes 8.1](#c08.xhtml#c08-gra-0001) 和 [8.2](#c08.xhtml#c08-gra-0002) 中的 Python 和 `R`。
