
Generally, if `x_t` satisfies a more generic SDE `dx_t = a(x_t)dt + b(x_t)dw_t` with an initial value `x_0 = x`, we can simulate paths of `x_t` using the following `discretization schemes` [\[10\]](#c05.xhtml#c05-bib-0010): for `m = 0, 1, ..., M - 1` and `δt = T/M`,

1.  **Euler–Maruyama Scheme**:

    `x̂_{(m+1)δt} = x̂_{mδt} + a(x̂_{mδt})δt + b(x̂_{mδt})√δt · z_m, z_m's iid ~ N(0, 1),`

    which can be seen by direct discretization of the SDE. The simulation method ([5.11](#c05.xhtml#c05-disp-0073)) is just a special case of this scheme.

2.  **Milstein Scheme**: 

    `x̂_{(m+1)δt} = x̂_{mδt} + a(x̂_{mδt})δt + b(x̂_{mδt})√δt · z_m + b(x̂_{mδt}) (∂b/∂x)(x̂_{mδt}) (δt/2)(z_m² - 1), z_m's iid ~ N(0, 1),`
