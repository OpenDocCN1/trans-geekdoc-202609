

根据 [Lemma 4.1](#c04.xhtml#c04-fea-0004) 和 `f ∈ L²[0, 1]`，我们有：

`sup_{n ≠ 0} |f̂(n)| < 1` 和 `∑_{n ≠ 0} |f̂(n)|² = ∫₀¹ f²(t) dt < ∞`

因此很明显，当 `k → ∞` 时，`||h - 1||₂² → 0`。

[Theorem 4.1](#c04.xhtml#c04-fea-0002) 可以推广到涉及随机变量商和幂的情况；事实上，类似于 ([4.12](#c04.xhtml#c04-disp-0032))，很容易看出

```
log₁₀((x/y)̄) = log₁₀(x̄) − log₁₀(ȳ) (mod 1)   and   log₁₀(x̄ⁿ) = n log₁₀(x̄) (mod 1).
```

下面的引理与 [Lemma 4.2](#c04.xhtml#c04-fea-0008) 类似，其证明是直接的。

[**Lemma 4.3**](#c04.xhtml#R_c04-fea-0012) 设 `x` 是 `[0, 1)` 上的连续随机变量，其概率密度为 `f ∈ L²[0, 1]`，并令 `z = mx (mod 1)`，其中 `m ∈ ℤ` 为固定值。则 `z` 是连续的，并具有密度 `h`，使得

1. `ĥ(n) = f̂(mn)` 对所有 `n ∈ ℤ` 成立；

2. 如果 `m = −1`，则简单地有 `ĥ(n) = f̂(−n) = f̂(n)̄`。
