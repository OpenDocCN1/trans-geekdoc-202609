

通过反向传播训练模型，同时也引入了 Adam 方法（参见 [第 15.5 节](#c15.xhtml#c15-sec-0006)）。不同符号请参考 [图 15.11](#c15.xhtml#c15-fig-0011)。假设算法处于第 `t` 次迭代阶段。在输出层，`k = 1, 2, ..., 100`，

∂L/∂w_k^o = -(y - ŷ_t) * ∂ŷ_t/∂w_k^o = -(y - ŷ_t) * ∂/∂w_k^o [ReLU(ô_x^o)] = -(y - ŷ_t) * 1_(0,∞)(ô_x^o_t) * ŷ_k,t^2，

其中，指示函数 `1_(0,∞)(x) = 1` 当 `x ≥ 0` 时成立，否则当 `x < 0` 时等于 0，它是 ReLU 函数的次微分。梯度的一阶矩和二阶矩分别为：对于 `k = 1, 2, ..., 100`，

m_k,t^o = β1 * m_k,t-1^o - (1 - β1) * (y - ŷ_t) * 1_(0,∞)(ô_x^o_t) * ŷ_k,t^2，
v_k,t^o = β2 * v_k,t-1^o + (1 - β2) * (y - ŷ_t)^2 * 1_(0,∞)(ô_x^o_t) * (ŷ_k,t^2)^2。
