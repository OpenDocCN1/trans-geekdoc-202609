

交易期限的设计会对交易策略产生重大影响。以预承诺策略为例：一个日历年可以被划分为若干个相对较短的交易期限，这些期限以不重叠的方式预先固定，即第 `k` 个交易期限从第 `t(k,0) = (k - 1)(T + 1)` 天延续至第 `t(k,T) = k(T + 1) - 1` 天，然后在每个交易期限内，我们关于在日 `s = t(k,0), ..., t(k,T)` 是否进行交易的决策，取决于函数 `φ(s - t(k,0); λ(t(k,0)), ε(S, t(k,0)))` 在 [提议 7.1](#c07.xhtml#c07-fea-0004) 中的根（用于卖出）以及函数 `φ(s - t(k,0); -λ(t(k,0)), ε(B, t(k,0)))` 在 [提议 7.2](#c07.xhtml#c07-fea-0006) 中的根（用于买入）。请注意，我们可能会持有股票直到某个交易期限结束，此时我们会重新评估是卖出还是持有以进入下一个周期。

然而，采用上述策略时，在一个交易期限内最多只会发生一次买入交易或一次卖出交易，且对于期限的剩余部分将不再考虑任何操作。因此，我们可能会错过该剩余期间的潜在利润；事实上，该策略的表现可能不如直接持有标普500指数。这暗示预承诺策略可能无法在任何时间不一致性问题上表现得极其出色。例如，考虑一种在 10 天交易期限内买入并持有股票的预承诺策略。假设由于随机性，股票在接下来的五天里持续下跌，那么在第 5 天，我们可能会通过立即卖出股票来撤销在时间 0 时做出的投资决策，以避免更大的损失，而这会导致我们在时间 0 时最初追求利润最大化的目标落空。作为替代方案，我们可以通过定义若干个更频繁的交易期限来制定另一种交易策略，以应对这一时间不一致性问题，具体如下：一旦我们在第 `k` 个交易期限内的日 `s` 执行了一笔交易，我们就将随后的交易日设为 `t(k+1,0) = s + 1`，即随后的第 `(k + 1)` 个交易期限的开始；否则，如果在这个交易期限内没有进行任何交易，那么其结束日 `t(k,T)` 的随后交易日将被设为第 `(k + 1)` 个交易期限的开始，即 `t(k+1,0) = t(k,T) + 1`。
