The class of Archimedean copulae is broad and covers many commonly used copulae as special cases. Below is a partial list; more examples can be found in [Table 4.1](#c04.xhtml#c04-tbl-0001) of [[35]](#c08.xhtml#c08-bib-0035).

1. *Ali–Mikhail–Haq* family: introduced in [[2]](#c08.xhtml#c08-bib-0002), the generator of this family is given by `ψ(t, θ) = ln((1 − θ)/t + θ), θ ∈ [0, 1)`.

2. *Clayton* family: introduced in [[13]](#c08.xhtml#c08-bib-0013), the generator of this family is given by

    `ψ(t, θ) = (1/θ)(t^(−θ) − 1), θ ∈ [−1, ∞) \ {0}`.

    The function inverse of this generator function is the Laplace transform of a Gamma distribution with a shape parameter `1/θ` and a scale parameter `θ`, thus the Clayton copula model has a *Gamma-distributed frailty representation* [[42]](#c08.xhtml#c08-bib-0042).

3. *Frank* family: first appeared in [[20]](#c08.xhtml#c08-bib-0020), the generator of this family is given by

    `ψ(t, θ) = −ln((e^(−θt) − 1)/(e^(−θ) − 1)), θ ∈ (0, ∞)`.

    In the bivariate case, it is the only Archimedean family which is *radially symmetric*, meaning that its copula and survival copula are the same.

4. *Gumbel* family: introduced in [[24]](#c08.xhtml#c08-bib-0024), the generator of this family is given by `ψ(t, θ) = (−ln t)^θ, θ ∈ [1, ∞)`.

5. *Joe* family: discussed in [[29](#c08.xhtml#c08-bib-0029), [30]](#c08.xhtml#c08-bib-0030), the generator of this family is given by `ψ(t, θ) = −ln(1 − (1 − t)^θ), θ ∈ [1, ∞)`.
