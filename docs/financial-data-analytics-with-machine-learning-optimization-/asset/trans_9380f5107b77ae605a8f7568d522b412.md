

需要注意的是，在（[7.20](#c07.xhtml#c07-disp-0035)）和（[7.21](#c07.xhtml#c07-disp-0036)）中用于更新方差率和协方差的参数估计值应当相同，以便模型具有方便性和可处理性。让我们通过以下示例来说明这一点。首先，我们计算 HSBC、CLP 和 CK 在 1999–2002 年期间的每日百分比收益率的相关矩阵；有关在 Python 和 `R` 中的实现，请参见 [Programmes 7.25](#c07.xhtml#c07-gra-00025) 和 [7.26](#c07.xhtml#c07-gra-00026)。

从输出中，我们注意到 HSBC 和 CK 之间的相关性相对较强，而 CLP 与 HSBC 和 CK 的相关性相对较弱。接下来，我们考虑不进行标准化的 DCC-GARCH(1,1) 模型。为此，`u1`、`u2` 和 `u3` 的当前值，即 `ui,0` 的值，以及协方差矩阵中的元素将被用作递归关系（[7.13](#c07.xhtml#c07-disp-0018)）和（[7.21](#c07.xhtml#c07-disp-0036)）的初始条件。然而，计算 `ω, α` 和 `β` 的公共值可能会很繁琐。相反，我们可以采用以下方便的数值方案，该方案在大多数实际情况下仍然足够准确。我们首先分别将 GARCH(1,1) 模型拟合到 `u1`、`u2` 和 `u3`，这将返回 `ω`、`α` 和 `β` 的三组不同的估计参数，然后使用这三组估计参数的平均值作为 `ω`、`α` 和 `β` 的组合估计值。然后我们相应地更新方差率和相关性。这确保了得到的相关矩阵是正定的；请参见通过 Python 的 [Programme 7.27](#c07.xhtml#c07-gra-00027) 和通过 `R` 的 [Programme 7.28](#c07.xhtml#c07-gra-00028)。
