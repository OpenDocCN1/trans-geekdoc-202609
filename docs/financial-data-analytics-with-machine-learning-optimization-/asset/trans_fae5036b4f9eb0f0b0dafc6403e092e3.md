

特别是，当 `x ∈ X` 时，最大值在 `λ = 0` 处取得，而对于 `x ∉ X`，存在某个 `i` 使得 `g_i(x) > 0`，因此一般来说 `λ⊥g(x)` 在 `λ_i` 上无界递增。因此，我们有

[(11.30)](#c11.xhtml#R_c11-disp-0071)

```
m := min_{x ∈ X} f(x) = min_{x ∈ R^p} max_{λ ≥ 0} (f(x) + λ⊥g(x)) = min_{x ∈ R^p} max_{λ ≥ 0} L(x, λ).
```

通过使用最大-最小不等式（[11.28](#c11.xhtml#c11-disp-0064)），该不等式对无界域成立，我们可以看到

```
min_{x ∈ R^p} max_{λ ≥ 0} (f(x) + λ⊥g(x)) ≥ max_{λ ≥ 0} min_{x ∈ R^p} (f(x) + λ⊥g(x)).
```

如果我们定义 `dual Lagrangian`

```
D(λ) := min_{x ∈ R^p} (f(x) + λ⊥g(x)),
```
