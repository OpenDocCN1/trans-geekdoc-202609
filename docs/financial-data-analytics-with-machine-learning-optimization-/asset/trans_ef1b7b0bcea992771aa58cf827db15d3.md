

另一方面，由于 `normal gamma 1` 和 `normal gamma 2` 本身相互独立，且它们也与 `normal u` 相互独立，因此 `h(normal u, normal gamma 1)` 和 `h(1 - normal u, normal gamma 2)` 在给定 `normal u` 的条件下仍然条件独立，故给定 `normal u` 时的条件协方差为

`Cov(x, z | u) = Cov(h(u, γ₁), h(1 - u, γ₂) | u) = 0`

最后，根据塔性质，

`Cov(x, z) = E[Cov(x, z | u)] + Cov(E[x | u], E[z | u]) ≤ 0`

关于该方法的应用，读者可参考 [11](#c05.xhtml#c05-bib-0011)、[15](#c05.xhtml#c05-bib-0015)、[16](#c05.xhtml#c05-bib-0016) 了解更多讨论。同时，为了保持表述和比较的一致性，我们将继续使用 [示例 5.1](#c05.xhtml#c05-fea-0002) 的目标积分。[示例 5.2](#c05.xhtml#c05-fea-0008) 作为反例，表明该方法的误用可能导致估计精度下降。虽然许多其他教材侧重于 [命题 5.1](#c05.xhtml#c05-fea-0004) 等优点，例如实现方便，但 [示例 5.2](#c05.xhtml#c05-fea-0008) 提示在实际操作中应格外谨慎。

## [示例 5.2](#c05.xhtml#R_c05-fea-0008) *([示例 5.1](#c05.xhtml#c05-fea-0002) 的延续)*

我们首先模拟 `u₁, …, u₅,₀₀₀`，然后通过 `vᵢ = 1 - uᵢ`（`i = 1, …, 5,000`）计算反变样本。估计量如下（[5.1](#c05.xhtml#c05-disp-0016)）：

```
θ̂ = (1 / (n / 2)) Σ(i=1 to n/2) [uᵢ³(1 - uᵢ)²·⁵ + vᵢ³(1 - vᵢ)²·⁵] / 2
```
