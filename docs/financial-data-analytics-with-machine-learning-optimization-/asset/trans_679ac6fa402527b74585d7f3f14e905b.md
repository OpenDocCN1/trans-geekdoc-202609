

### 3. (A3) 均匀（强）凸性

对于某个 `μ > 0`，`(11.21)(θ − θ′)ᵀ(∇_θ L(θ) − ∇_θ L(θ′)) ≥ μ‖θ − θ′‖₂²`，对任意 `θ, θ′ ∈ ℝᵠ` 成立，其中 `L(θ) := 𝔼[ℓ(θ; x)]`。

假设 `(A3)` 保证函数 `L(θ)` 具有唯一的最小化器 `θ*`，使得 `∇_θ L(θ*) = 0`。假设 `(A1)` 和 `(A3)` 隐式地假设 `μ < C`。在这三个假设下，`Robbins–Monro theorem` 表明，当学习率 `{η_t}` 的选取方式使得

```
(11.22) ∑_{t=0}^∞ η_t = ∞ and ∑_{t=0}^∞ η_t² < ∞,
```

则当 `t → ∞` 时，使用 SGD 的 `θ^(t) → θ*` 几乎必然成立。一个更一般的结果，称为 `Kiefer–Wolfowitz theorem` [[15](#c11.xhtml#c11-bib-0015)]，断言当更新规则 `([11.17](#c11.xhtml#c11-disp-0040))` 中的梯度 `∇_θ L(θ)` 通过中心有限差分法进行数值近似，且有限差分的步长 `{α_t}` 的选取方式使得 `∑_{t=0}^∞ η_t α_t < ∞` 时，相同的收敛性成立。
