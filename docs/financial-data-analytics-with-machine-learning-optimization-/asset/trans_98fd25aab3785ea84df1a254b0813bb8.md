

共单调性的概念是 CIBer 的核心。除了我们在 [第 8 章](#c08.xhtml) 中介绍的内容之外，让我们讨论一些进一步的属性。作为精算科学、金融和经济学中广泛使用的概念，共单调性描述了几个随机变量之间可能存在的强正相关性：每当一个随机变量的实现值发生变化时，其余所有变量都会沿同一方向跟随。从数学上讲，随机向量 `x = (x₁, ..., x_p)^T` 被称为 *共单调* 的，如果存在 `R^p` 的一个 *共单调子集* `C`，使得 `P(x ∈ C) = 1`。这里，如果 `C` 是全序的，即对于任何 `x, y ∈ R^p` 的所有 `i`，要么 `x_i ≤ y_i`，要么 `x_i ≥ y_i`，则称 `C` 为共单调。可以证明，共单调性的以下表征是等价的：

1. 随机向量 `x = (x₁, ..., x_p)^T` 是共单调的；

2. 存在一个随机变量 `w` 和递增函数 `h₁, ..., h_p`，使得 `(x₁, ..., x_p) =ᵈ (h₁(w), ..., h_p(w))`;

3. 对于任何 `u ~ U(0, 1)`，`(x₁, ..., x_p) =ᵈ (F⁻¹_{x₁}(u), ..., F⁻¹_{x_p}(u))`，其中广义逆 `F⁻¹_{x_j}(u) := inf{x_j ∈ R : F_{x_j}(x_j) ≥ u}`，`j = 1, 2, ..., p`;
