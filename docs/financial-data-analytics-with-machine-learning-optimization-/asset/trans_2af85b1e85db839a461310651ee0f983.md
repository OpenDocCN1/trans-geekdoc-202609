

作为最后的评论，请注意，在实践中选择合适的主成分（PCs）数量可能是一个相当微妙的决定。对于极端场景，请考虑一个投资组合，其权重为所有 `i = 1, …, p` 的 `ωᵢ = c hᵢₚ / σᵢ`，其中 `c` 为一个公共常数。由于最后一个主成分采用 `yₚ = Σᵢ hᵢₚ x̃ᵢ` 的形式，由于其与 `yⱼ` 的不相关性，我们可以看到对于所有 `j = 1, …, p − 1` 都有 `δⱼ = c Σᵢ hᵢₚ hᵢⱼ = c hₚ⊥ᵀ hⱼ = 0`；因此，当主成分的数量 `m` 小于 `p` 时，`ΔΠ ≈ ζ`。由于最后一个主成分不太可能出现在任何截断的主成分程序中，因此使用任何常见的 PCA 程序都无法准确估计投资组合价值的变化。然而，在大多数金融应用中，投资者只关注由主要风险因素 `y₁, …, yₘ`（其中 `m ≪ p`）控制且与之相关的证券，这些证券对市场产生了大部分影响。那些与 `j ≥ m + 1` 的 `yⱼ` 相关的证券几乎不被考虑，因为其影响可忽略不计，因此在普通投资者的投资计划中起着非常有限的作用。因此，相应的 `|δⱼ|` 将会相当小。不幸的是，仅关注少数几个主要金融风险因素，因此也仅关注少数几个投资工具，可能会导致系统性风险增加，这主要由 `j ≥ m + 1` 的风险因素 `yⱼ` 组成。
