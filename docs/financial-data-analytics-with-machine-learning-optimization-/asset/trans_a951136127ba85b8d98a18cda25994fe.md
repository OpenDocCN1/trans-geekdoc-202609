# Mathematical and Statistical Preliminaries

本章对高等微积分、线性代数以及概率与统计的基础知识进行了快速回顾，作为后续章节内容的背景知识。熟悉相关术语的读者建议从 [第 3 章](#c03.xhtml) 开始阅读，并在需要时随时回到本章作为参考。

随着计算技术的飞速发展和数据存储的丰富，我们经常会收集大量包含大量特征变量的信息和观测数据。包含 `p` 个变量和 `n` 个观测值的数据集可以排列成 `n times p` 数据矩阵的形式：

```
X = (x11 ... x1p
     ... ... ...
     xn1 ... xnp)
   = (x1^T
      ...
      xn^T),
```

其中，第 `j` 行 `x_j^T`（`j = 1, ..., n`）表示第 `j` 个观测值，即列向量 `x_j` 的转置。数据科学家认为存在一种数据生成机制，使得每个多元观测样本都是从共同但通常未知的联合概率分布中随机抽取的。从统计学角度来看，数据矩阵 `X` 是以下随机矩阵的实现：

```
X = (x11 ... x1p
     ... ... ...
     xn1 ... xnp)
   = (x1^T
      ...
      xn^T),
```
