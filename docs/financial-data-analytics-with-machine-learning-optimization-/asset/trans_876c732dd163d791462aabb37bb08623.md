

# 线性分类器

线性分类器旨在寻找一个 `(p-1)` 维超平面，以将给定的数据点集合分为两类。在数学上，假设每个数据点由一个 `p` 维特征向量 `x = (x1, ..., xp) ∈ R^p` 及其标签 `y ∈ {-1, +1}` 表示，该标签表示其所属的类别。线性分类器是由方程 `f(x) = x^T ω + b = 0` 定义的超平面，其中 `ω ∈ R^p` 是权重向量，`b ∈ R` 是偏置。如果 `f(xi) > 0`，则数据点 `(xi, yi)` 被归类为属于“`+1`”类别；如果 `f(xi) < 0`，则被归类为属于“`-1`”类别。如果 `f(xi) · yi > 0`，则该数据点被该超平面正确分类；但如果 `f(xi) · yi < 0`，则被错误分类。

[图 11.1](#c11.xhtml#c11-fig-0001) 说明了一个由二维特征向量组成的数据集 `{(xi1, xi2, yi)}_{i=1}^n`，该数据集由直线线性分离：

[(11.1)](#c11.xhtml#R_c11-disp-0001) `f(x) = b + ω1x1 + ω2x2 = 0.`

给定其特征向量 `x`，如果观测值位于分离直线 ([11.1](#c11.xhtml#c11-disp-0001)) 的上方（resp. 下方），则将其归类为类别 `+1`（resp. `-1`）。在本章中，我们将介绍两种传统的二元线性分类器，即 `perceptron` 和 `support vector machine` (SVM)。

![FIGURE 11.1 线性分类器示例，用于二维特征向量，蓝色点（resp. 橙色叉号）的标签为正 1（resp. 负 1）。](images/c11f001.png)

[**FIGURE 11.1**](#c11.xhtml#R_c11-fig-0001) 线性分类器示例，用于二维特征向量，蓝色点（resp. 橙色叉号）的标签为 `+1`（resp. `-1`）。

两种方法都是减少错误分类数据数量的过程。直观地讲，算法通过将分离超平面向错误分类的数据倾斜来改进该超平面，以减少它们到超平面的距离。在训练期间，选择一个 `loss function` 作为误分类的度量。损失函数值越大，预测的准确性越低。Perceptron 和 SVM 在损失函数的选择上有所不同。此外，SVM 可以执行非线性分类，而 perceptron 大多仅限于线性分类。
