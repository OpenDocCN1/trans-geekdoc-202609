
1. For each label `c_k`, compute the empirical unconditional probability `P̂(c(x) = c_k) = |{i : c(x_i) = c_k}| / n`.

2. For each feature variable `x_j` and a feature value `x*_j`, compute the empirical conditional probability for each class `c_k`: `P̂(x_j = x*_j | c(x) = c_k) = |{i : x_ij = x*_j, c(x_i) = c_k}| / |{i : c(x_i) = c_k}|`.

3. The new observation `x*` is classified as belonging to the class `c_k̂`, where `k̂ = arg max_(k=1,...,M) (∏_(j=1)^p P̂(x_j = x*_j | c(x) = c_k) P̂(c(x) = c_k))`.
