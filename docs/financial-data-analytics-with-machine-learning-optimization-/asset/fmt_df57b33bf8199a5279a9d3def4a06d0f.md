
Let us discuss the convergence of the SGD scheme to an optimal perceptron when the data truly are linearly separable, say by `ω* ∈ R^(p+1)` which is not unique in general (see [Figure 11.5](#c11.xhtml#c11-fig-0005)). In this case, there exists a strictly positive constant `γ` such that `y_i(ω*^T x_i) ≥ γ` for all `i`. Let `R > 0` be any constant such that `||x_i||_2^2 ≤ R^2` for all `i`; such an `R` can always be found as we only have finitely many data. For simplicity, we initialize the weights at 0, i.e. `ω^(0) = 0`.

After a certain number of iterations, if there are no more misclassified points, the numerical scheme stops, and by definition, a perceptron classifier that correctly classifies all data is attained. Otherwise, if there are still misclassified points, modification of weights will still be carried out, and we now want to demonstrate that there is a ceiling for such a number of iterations, and so the optimal classifier should ultimately be obtained.
