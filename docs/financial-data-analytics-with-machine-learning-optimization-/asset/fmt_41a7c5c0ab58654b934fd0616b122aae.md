## Theorem 4.2

Let `x_1, ..., x_k` be independent and identically distributed continuous random variables on `[0, 1)` with a common probability density `f ∈ L^2[0, 1]`, also let `v := x_1 + ... + x_j - x_{j+1} - ... - x_k (mod 1)`. Then, `v` also approaches a uniform distribution on `[0, 1)` as `k → ∞`.

### Proof

Let `h` be the density of `v`. As before, it suffices to show `||h - 1||_2^2 → 0` as `k → ∞`; to this end, using [Lemmas 4.2](#c04.xhtml#c04-fea-0008) and [4.3](#c04.xhtml#c04-fea-0012), we have

```
||h(t) - 1||_2^2 = Σ_{n≠0} |ĥ(n)|^2 = Σ_{n≠0} |f̂(n)|^2 j · |f̂(n)|^2 k-2j = Σ_{n≠0} |f̂(n)|^2 k,
```

which converges to 0 as `k → ∞` by the last few lines of arguments used in the proof for [Theorem 4.1](#c04.xhtml#c04-fea-0002).
