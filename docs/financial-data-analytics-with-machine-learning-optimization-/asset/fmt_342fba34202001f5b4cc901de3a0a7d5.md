
By [Lemma 4.1](#c04.xhtml#c04-fea-0004) and `f ∈ L²[0, 1]`, we have:

`sup_{n ≠ 0} |f̂(n)| < 1` and `∑_{n ≠ 0} |f̂(n)|² = ∫₀¹ f²(t) dt < ∞`

therefore it is clear that `||h - 1||₂² → 0` as `k → ∞`.

[Theorem 4.1](#c04.xhtml#c04-fea-0002) can be generalized to one involving quotients and powers of random variables; indeed, similar to ([4.12](#c04.xhtml#c04-disp-0032)), it is easy to see that

```
log₁₀((x/y)̄) = log₁₀(x̄) − log₁₀(ȳ) (mod 1)   and   log₁₀(x̄ⁿ) = n log₁₀(x̄) (mod 1).
```

The following lemma is similar to [Lemma 4.2](#c04.xhtml#c04-fea-0008) and its proof is immediate.

[**Lemma 4.3**](#c04.xhtml#R_c04-fea-0012) Let `x` be a continuous random variable on `[0, 1)` with a probability density `f ∈ L²[0, 1]`, and let `z = mx (mod 1)`, for a fixed `m ∈ ℤ`. Then `z` is continuous and has density `h` such that

1. `ĥ(n) = f̂(mn)` for all `n ∈ ℤ`;

2. if `m = −1`, we simply have `ĥ(n) = f̂(−n) = f̂(n)̄`.
