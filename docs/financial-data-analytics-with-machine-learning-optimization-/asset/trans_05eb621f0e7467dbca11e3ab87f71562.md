

与其在每次迭代时都使用 `S` 中相同的前 `M` 个数据来近似损失函数的梯度，更常见的做法是先对数据进行随机打乱。这有助于防止学习到的模型对 `S` 中前 `M` 个数据的特定模式产生过拟合，从而导致泛化能力较差。所使用的批次必须从 `S` 中随机选择。实现此目的的一种方法是 *随机打乱*。在这种方法中，我们首先随机打乱数据以获得 `S̃ = {(x̃ᵢ, ỹᵢ) | i = 1, ..., n}`，其中 `(x̃ᵢ, ỹᵢ) := (x_{π(n)}, y_{π(n)})` 是 `{1, 2, ..., n}` 上某个随机排列 `π` 到自身的映射。然后，我们将 `S̃` 分成 `B` 个批次，每个批次的大小均为 `M`，因此 `B = ⌈n / M⌉`，对于 `j = 1, ..., B`，第 `j` 个批次由 `{(x̃ᵢ, ỹᵢ) | i = (j − 1)M + 1, ..., jM}` 给出。这些 `B` 个批次将用于在接下来的 `B` 次迭代步骤中近似损失函数的梯度，如上文所述。在所有 `B` 个批次都用完后，整个过程将重复进行。

在实践中，常用的批次大小为 `M = 2⁵ = 32 > 30`，三十是大数定律产生足够好的近似结果的经验法则数值。值得提及的小批量 SGD 有两个特殊情况：

1.  常见的随机梯度下降（SGD）是 `M = 1` 时的特例，即每次迭代中随机选取一个样本点用于更新参数估计；

2.  （整个）批量梯度下降也是小批量 SGD 的一个特例，但此时批次大小 `M = n`，因此一次性使用所有训练数据。
