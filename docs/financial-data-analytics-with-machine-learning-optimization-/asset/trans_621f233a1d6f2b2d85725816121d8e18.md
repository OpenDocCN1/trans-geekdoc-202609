We remark that if `n < p`, `A` does not admit a density; nevertheless, in that case, we still denote its distribution by `W_p(Σ, n)`; see more detailed discussion in [[7](#c01.xhtml#c01-bib-0007)].

Let `x_i ~ N_p(μ, Σ), i = 1, ..., n`, be iid multivariate normal random vectors. The following important result gives the sampling distribution of the sample covariance matrix `S`.

[**Proposition 1.2](#c01.xhtml#R_c01-fea-0008)** The sample mean `x̄ = 1/n Σ(i=1 to n) x_i` is independent of the sample covariance matrix `S = 1/(n-1) Σ(i=1 to n) (x_i - x̄)(x_i - x̄)ᵀ`, and `S ~ W_p(1/(n-1) Σ, n-1)`.
