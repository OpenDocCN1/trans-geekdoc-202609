

# Newton's Method for Logistic Regression MLEs

让我们采用 Newton's method，类似于 ([10.23](#c10.xhtml#c10-disp-0068))，用于寻找 logistic regression 的 MLEs。为简化记号，将 `−ln L(β)`（定义见 ([10.14](#c10.xhtml#c10-disp-0034))) 记作 `−l(β)`。从初始种子 `β^(0)` 开始，我们迭代构造近似序列，其中 `k = 0, 1, …`：

[(10.25)](#c10.xhtml#R_c10-disp-0073)

```
β^(k+1) = β^(k) − [∇_β ∇_β^T (−l(β^(k)))]^−1 ∇_β (−l(β^(k)))
        = β^(k) − (H(β^(k)))^−1 ∇_β l(β^(k))
```
