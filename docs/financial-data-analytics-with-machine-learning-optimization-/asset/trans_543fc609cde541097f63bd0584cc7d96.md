

一般而言，假设训练数据集的大小为 `n`，包含 `M` 种不同类型的手写“数字”，以允许 `M` 不一定等于 10 的可能性。由于数据集中存在多个数字，我们希望确定每个数字最具“代表性”的图像。同时，我们还将尝试估计某个特定数字的代表图像被显示的先验概率。为此，我们考虑 `M` 个不同的参数向量 `μ_m`，`m = 1, ..., M`；此处 `m` 充当索引，而非所选特定数字的实际值。用 `π_m`，`m = 1, ..., M`，表示选择 `μ_m` 的先验概率。自然，这些概率之和应为 1。在以下内容中，我们将参数集合表示为 `θ := (μ_1, ..., μ_M, π_1, ..., π_M)`，并受约束 `∑_{m=1}^{M} π_m = 1`。特定图像的像素向量 `x` 是可观测部分，而作为超随机向量的参数向量 `z`，用于生成该图像，则是未知的。在此，`z` 充当隐藏/隐性向量，且只能取 `M` 个（向量）值 `μ_1, ..., μ_M`。我们将 `μ_m` 的分量视为伯努利随机向量 `i_m = (i_{m1}, ..., i_{mK})^T` 各分量的成功概率，其中 `i_{mk}` 表示如果抽取第 `m` 种数字，则同一图像中第 `k` 个像素的颜色（1 表示黑色，0 表示白色）。在当前建模框架中，假设所有像素向量均为独立同分布。

牢记这一点，给定 `z = μ_m = (μ_{m1}, ..., μ_{mK})^T`，生成具有观测像素向量 `x` 的图像的条件概率为：

[(6.9)](#c06.xhtml#R_c06-disp-0013)

```
f(x | z = μ_m; θ) = ∏_{k=1}^{K} (μ_{mk})^{x_k} (1 - μ_{mk})^{1 - x_k}.
```
