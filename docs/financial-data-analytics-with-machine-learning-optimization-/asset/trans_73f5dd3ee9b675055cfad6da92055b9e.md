

下面的陈述是[定理 4.1](#c04.xhtml#c04-fea-0002)的一个变体，在此变体中，除了允许随机几何增长外，还允许随机折扣，也就是说，我们允许([4.11](#c04.xhtml#c04-disp-0030))中的那些 `r_i` 也取负值。因此，这些解释了受([4.10](#c04.xhtml#c04-disp-0027))动态支配的 COVID-19 数据中本福德定律的出现。

## 定理 4.2

设 `x_1, ..., x_k` 为区间 `[0, 1)` 上独立同分布的连续随机变量，具有共同概率密度 `f ∈ L^2[0, 1]`，并令 `v := x_1 + ... + x_j - x_{j+1} - ... - x_k (mod 1)`。那么，当 `k → ∞` 时，`v` 也趋近于 `[0, 1)` 上的均匀分布。

### 证明

设 `h` 为 `v` 的密度。与之前一样，只需证明当 `k → ∞` 时 `||h - 1||_2^2 → 0`；为此，利用[引理 4.2](#c04.xhtml#c04-fea-0008)和[4.3](#c04.xhtml#c04-fea-0012)，我们有

```
||h(t) - 1||_2^2 = Σ_{n≠0} |ĥ(n)|^2 = Σ_{n≠0} |f̂(n)|^2 j · |f̂(n)|^2 k-2j = Σ_{n≠0} |f̂(n)|^2 k,
```

当 `k → ∞` 时，这趋于 0，这由证明[定理 4.1](#c04.xhtml#c04-fea-0002)中使用的最后几行论证得出。
