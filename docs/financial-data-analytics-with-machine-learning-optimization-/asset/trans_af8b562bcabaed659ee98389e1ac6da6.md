

这些三个分布函数称为 *极值分布*。我们说，随机变量 `x` 属于极值分布 `H = Φ_α, Λ` 或 `Ψ_α`（即分别为 Fréchet、Gumbel 或 Weibull 分布）的 *最大吸引域*（MDA），记作 `x ∈ MDA(H)`，如果存在常数 `a_n > 0` 和 `b_n ∈ ℝ`，其中 `n = 1, 2, ...`，使得条件 ([8.17](#c08.xhtml#c08-disp-0078)) 成立。

这些 MDA 涵盖了金融、保险和定量风险管理中感兴趣的大多数分布。例如，`MDA(Φ_α)` 中的分布包括柯西分布、Pareto 分布、Burr 分布、指数为 `α < 2` 的稳定分布和对数伽马分布；`MDA(Λ)` 中的分布包括指数型、Weibull 型、伽马分布、正态分布、对数正态分布、在有限点 `x_F < ∞` 处呈指数行为、*Benktander-type I* 和 *Benktander-type II* 分布；`MDA(Ψ_α)` 中的分布包括均匀分布、在有限点 `x_F < ∞` 处呈幂律行为以及 beta 分布。这里，`x_F` 代表 Gumbel 或 Weibull 分布的有限端点。

可测函数 `h : ℝ₊ → ℝ₊` 被称为在 `∞` 处具有指数 `α ∈ ℝ \ {0}` 的 *正则变化*，记作 `h ∈ RV_α`，如果对于所有 `t > 0`，

```
lim_{x → ∞} h(tx) / h(x) = t^α.
```
