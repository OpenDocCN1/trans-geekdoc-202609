

在 1881 年，美国数学家西蒙·纽康布（Simon Newcomb，1835–1909）对对数表做出了一项奇特的观察。他注意到，书籍的前几页比后几页更脏、磨损更严重；那些首位数字较小的数字被查阅用于计算的次数比首位数字较大的数字更多，他据此制定了一条经验法则：以数字 `d` 开头的数字的比例并非均匀分布，而是由 `log₁₀(1 + 1/d)` 决定，其中 `d = 1, 2, ..., 9`。这一现象在 1881 年的《美国数学杂志》一文中被提及，但当时他无法为自己的主张提供严谨的数学证明。

后来在 1938 年，物理学家弗兰克·本福德（Frank Benford）做出了与纽康布相同的观察。他从河流面积、死亡率、棒球统计数据、杂志文章中的数字以及许多其他广泛的数据集中汇编了一张包含 `20,229` 个数字的表格。他的结果在很大程度上与纽康布之前观察到的模式一致。这种反直觉的自然规律，而非均匀分布，便以他的名字命名。

毫无疑问，许多数字集合不遵循本福德定律，例如随机数和来自其他统计分布的数字。1996 年，来自佐治亚理工学院的西奥多·希尔（Theodore Hill）表明，如果采样分布是随机选择的，使得样本从每个分布中抽取，即从不确定的分布中抽取样本，那么合并样本的首位数字频率最终会收敛到本福德定律，尽管这对于从固定分布中取出的单个样本可能不成立。

理解这种经验性本福德定律的另一种方法是将所有数值视为与进制无关，且相同的法则适用于任何不同于十进制的其他进制系统。我们预期，即使在更改度量单位后，该法则仍应保持有效，而更改度量单位是通过乘以某个缩放数来实现的。这种特性称为缩放不变性。例如，100 米可以转换为 0.1 千米或 `10,000` 厘米，但无论使用何种度量约定，首位数字 1 都保持不变。1961 年，罗格斯大学的数学家罗杰·平克姆（Roger Pinkham）证明了缩放不变性蕴含本福德定律。作为示例，考虑来自 `U[1, 10)` 分布的一组数字，使得每个首位数字 `d` 的预期频率为 1/9。我们通过乘以因子 2 来更改单位。[表 4.1](#c04.xhtml#c04-tbl-0001) 显示了新获得数字的结果首位数字及其相应的预期频率（概率）。它清楚地表明，经过这种简单的缩放后，分布的均匀性丢失了，预期 `5/9` 的结果数字以 1 作为其首位数字。因此，均匀分布不能是缩放不变的。

## 4.2 缩放不变性与本福德定律

考虑一个 `σ`-有限度量

`μ(a, b) := ∫ₐᵇ f_μ(x) dx, 1 ≤ a < b < ∞,`

如果对于任何 `α > 1`，

`μ(αa, αb) = μ(a, b), for any 1 < a < b < ∞.`

则称其为缩放不变。
