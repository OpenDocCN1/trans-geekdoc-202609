## 1.2 矩阵理论

在开始我们的旅程之前，让我们先回顾一下初级矩阵理论中的一些基本符号和概念。读者可以参考 [\[11](#c01.xhtml#c01-bib-0011), [18](#c01.xhtml#c01-bib-0018), [19\]](#c01.xhtml#c01-bib-0019) 以获取关于初级水平矩阵理论的更详细介绍；更高级的主题在 [\[8](#c01.xhtml#c01-bib-0008), [20](#c01.xhtml#c01-bib-0020), [21\]](#c01.xhtml#c01-bib-0021) 中讨论，包括各种矩阵求解器算法和与奇异值分解相关的技术。

**(I) 行列式**

设 `A` 和 `B` 为两个 `p` 乘 `p` 的方阵，并让 `|A|` 表示 `A` 的 `行列式`。基本性质包括以下内容：

1.  `|A^T| = |A|`.
