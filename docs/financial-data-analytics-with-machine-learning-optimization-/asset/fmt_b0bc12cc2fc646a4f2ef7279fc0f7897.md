
Recall that in determining whether the current day `s` is in the action period ([7.39](#c07.xhtml#c07-disp-0063)) within the `(j + 1)`-th examination window from day `s - T + j` to day `s + j`, the parameters `λ_{s - T + j}`, `ε_{S, s - T + j}`, `ε_{B, s - T + j}` involve the estimates of `μ_{s - T + j}` and `σ_{s - T + j}` on day `s - T + j`, and the performance of this newly proposed trading strategy is certainly linked to the accuracy of these estimations. In this subsection, we assess its performance from the viewpoint of `backtesting`.

Regarding the estimation of `μ`, let's say for a given trading day `t`, being the beginning of some `(j + 1)`-th examination window, we can obtain a better estimate by also using future returns as well as historical ones. To this end, the following `two-stage approach` is introduced: we obtain a preliminary estimate `μ̃_t` in the first step, by calculating the weighted geometric return over 3 consecutive trading days starting from the previous day `t - 1`:

(7.41) `μ̃_t = ∏_{i=-1}^{1} (1 + u_{t + i})^{ω_i} - 1`

where `∑_{i=-1}^{1} ω_i = 1`; for the current backtesting, we rely more on the return of the following day, by taking `ω_{-1} = 0.1`, `ω_0 = 0.3`, and `ω_1 = 0.6`.
