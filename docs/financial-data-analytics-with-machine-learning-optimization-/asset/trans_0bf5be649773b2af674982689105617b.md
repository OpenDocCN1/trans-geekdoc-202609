

在进行第 `k` 次猜测之前，对于每个具体的猜测，我们可以计算在假设它们是正确单词的情况下，词库中五个字母单词导致每种可能的颜色向量实现的比例。更严谨地说，我们考虑随机颜色向量 `c(ω̃(k))`，它明显取决于猜测 `ω̃(k)`，而随机性来自未知的目标单词。`c(ω̃(k))` 的概率质量函数则是词库 `W^(k-1)` 中的单词所占的比例，如果这些单词是目标单词，就会导致颜色向量的某个特定实现。例如，颜色向量 (Green, Green, Green, Green, Green)^⊤ 只能在目标单词恰好与猜测相同时出现，因此我们有

```
P(c(ω̃(k)) = (Green, Green, Green, Green, Green)^⊤) = 1 / n^(k-1) =: p1(ω̃(k))
```

其中，为了方便起见，我们系统地为每个颜色向量的实现分配从 1 到 243 的索引。然后可以计算该随机变量的熵为：

```
H(c(ω̃(k))) := - Σ(i=1 to 243) pi(ω̃(k)) log2 pi(ω̃(k))
```

为了找到一个多功能单词，该单词可以通过颜色信号为后续猜测提供尽可能多的信息，第 `k` 次猜测的最佳单词是最大化熵的单词，而不是像分类树算法中那样最大化“信息增益”。
