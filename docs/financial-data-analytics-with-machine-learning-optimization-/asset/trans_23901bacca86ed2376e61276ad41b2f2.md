2. 如果状态 `s_j` 有一个周期 `d(j)`，则存在一个依赖于 `s_j` 的整数 `N`，使得对于所有整数 `n ≥ N`，`p(j, j)(nd(j)) > 0`。也就是说，返回到状态 `s_j` 可以发生在 `d(j)` 的所有足够大的倍数处。此主张的证明基本上与以下 [Lemma 6.1](#c06.xhtml#c06-fea-0002) 的证明相同，因此此处省略。

如果每个状态的周期均为 1，则称有限状态马尔可夫链为 *aperiodic*。很容易看出，如果马尔可夫链是正则的，即对于某个 `n`，`P^n` 的所有元素均严格为正，那么 `P^(n+1), P^(n+2), ...` 也是如此，因此马尔可夫链是 *aperiodic*。在接下来的内容中，我们证明逆命题也成立：具有有限状态空间的不可约且 *aperiodic* 的马尔可夫链是正则的。我们首先提出一个引理，其证明取自 [\[1\]](#c06.xhtml#c06-bib-0001)。
