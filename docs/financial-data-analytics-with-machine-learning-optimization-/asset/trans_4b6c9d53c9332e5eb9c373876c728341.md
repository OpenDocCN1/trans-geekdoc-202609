## 9.8 通过 PCA 进行人脸识别

一般而言，PCA 也有助于识别一组非常高维随机变量背后的主要因素。同样的原理可用于图像识别，即从一类照片中选取关键特征；更多讨论请参见 [\[2](#c09.xhtml#c09-bib-0002), [8](#c09.xhtml#c09-bib-0008), [10](#c09.xhtml#c09-bib-0010), [18](#c09.xhtml#c09-bib-0018), [21](#c09.xhtml#c09-bib-0021), [22\]](#c09.xhtml#c09-bib-0022)。当然，图像识别在商业中发挥着至关重要的作用，例如提供更具针对性的客户服务，从而促进网上私人银行的发展。例如，如 [图 9.5](#c09.xhtml#c09-fig-0005) 所示，人脸识别可用于验证客户身份，从而即时检索和审查其保单及背景信息。这在无需人工干预且能实现高精度的同时，以最少的人力丰富了网上银行的潜在用途。人脸识别通常比简单的用户名和密码登录更安全。借助这项技术，未来的客户只需拍摄相关文件照片，然后在线提交即可获得服务。图像识别引擎将上传的图像转换为所需信息以供进一步处理，随后成功申请可在几秒钟内实现。简而言之，金融公司和客户可以实现双赢：客户的管理成本可大幅降低，而公司则能获得更准确的信息。
