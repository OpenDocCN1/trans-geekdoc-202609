

让我们来讨论马尔可夫链在不可数状态空间上的类似结果。令 `b+(S)` 为定义在 `S` 上的所有非负、有界且连续的实值函数的集合。马尔可夫链 `{x_n}` 被称为 *regular*，如果存在 `n ∈ ℕ`，使得对于任何不恒等于零的 `f ∈ b+(S)`，对所有 `s ∈ S` 都有 `P^n f(s) > 0`。给定任意两个状态 `s_1, s_2 ∈ S`，我们说 `s_2` 可从 `s_1` *accessible*（可达），（再次）记作 `s_1 → s_2`，如果存在 `n ∈ ℕ`，使得对于任何满足 `f(s_2) > 0` 的 `f ∈ b+(S)`，都有 `P^n f(s_1) > 0`。在这种情况下，我们说 `s_2` 可在 `n` 步内从 `s_1` 可达。同样，若 `s_1 → s_2` 且 `s_2 → s_1`，则称两个状态 *communicate*（相连），记作 `s_1 ↔ s_2`。类似于有限或可数状态空间的情况，状态间的相连构成一个等价关系，其证明可见 [附录 6.A.1](#c06.xhtml#c06-sec-0037)。若每个状态都与其他所有状态相连，则称马尔可夫链为 *irreducible*（不可约）。

为了简化整体处理，我们施加以下技术假设。

## Assumption 6.1

1. `S` 是 `R^p` 的某个 `p ∈ ℕ` 的紧子集。

2. 对于任何 `n ≥ 0`，定义在 `S × S` 上的 `(x_n, x_{n+1})` 的过渡密度是联合绝对连续的。

**Remark 6.1** 本小节证明中的相同论证可以扩展到非紧连续状态空间 `S`，特别是当过渡密度具有轻尾时。
