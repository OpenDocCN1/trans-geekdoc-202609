
Hence, we have `P(T > M) ≤ 1 - α²`. Similarly, given everything that has happened up to time `M`, we have a conditional probability of at least `α²` of having `x₂ₘ = x′₂ₘ = s₁` no matter where the chains are at time `M`, so that

`P(x₂ₘ ≠ x′₂ₘ | T > M) ≤ 1 - α²`

Hence,

```
P(T > 2M) = P(T > M) P(T > 2M | T > M)
          ≤ (1 - α²) P(T > 2M | T > M)
          ≤ (1 - α²) P(x₂ₘ ≠ x′₂ₘ | T > M)
          ≤ (1 - α²)²
```

By iterating this argument, we arrive at, for any `ℓ`,

`P(T > ℓM) ≤ (1 - α²)^ℓ → 0, as ℓ → ∞`

and so `P(T = ∞) = 0`. In other words, the two chains will meet eventually with probability 1.
