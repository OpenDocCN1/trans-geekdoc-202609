
1.  *Folded* `Z` *\-statistic* for each possible digit: (4.7) `Z_{i, folded} = |AP_i - EP_i| / sqrt(EP_i * (1 - EP_i) / n) d→ N⁺(sqrt(2/π), 1 - 2/π)` for `i = 1, ..., K`, where `N⁺` denotes the *folded normal distribution*.

2.  *Chi-square Goodness-of-fit Test Statistics* for all possible digits at once: (4.8) `Σ_{i=1}^{K} (n * AP_i - n * EP_i)² / (n * EP_i) d→ χ²_{K-1}`.

The density of a folded normal distribution on `[0, ∞)`, denoted by `N⁺(μ, σ²)`, is given by:

```
f(x) = 1 / sqrt(2πσ²) * exp(-(x - μ)² / (2σ²)) + 1 / sqrt(2πσ²) * exp(-(x + μ)² / (2σ²)), 0 ≤ x < ∞.
```

In light of the Central Limit theorem, since `sqrt(n) * (AP_i - EP_i) / sqrt(EP_i * (1 - EP_i)) d→ N(0, 1)`, the folded normal density can be computed in Python with `2*norm.pdf(x)` and in `R` with `2*dnorm(x)`, respectively.
