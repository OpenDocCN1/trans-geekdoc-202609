

分类树是一个无环图，其中每个内部节点代表一个属性，该属性由 `x` 的某些特征组件指定的特定定量关系来表征，从节点发出的分支表示决策规则的结果。具体来说，为简单起见，对于二元分类树，树的每个分支节点都会检查 `x` 的某个特定特征组件，例如 `x^(j)`：如果 `x^(j)` 的值低于某个阈值 `t^(j)`，则选择左分支路径；否则，选择右分支。沿着树向下，随着此过程的继续，数据集被划分为越来越小的子集。如果某个叶节点中的所有标签 `y_i` 基本上属于同一类别，则模型停止构建任何新分支，即停止在某个叶节点。这样的叶（终端）节点随后被识别为在 `Y` 中给出“纯”类标签 `c_k`。从根节点到叶节点的路径表示一条分类规则。树的深度是路径的最大长度，即从根节点到某个叶节点的最大分支数。自然，人们可能会提出以下问题：

1. 每个节点应检查哪个特征，并根据什么标准选择该特征？

2. 对于二元分类树，每一步的选择阈值 `t^(j)` 是多少？一般来说，如果一个属性可以取多于两个值，甚至是一个连续值，我们应该构建多少个分支？

本章将解决这两个问题；此处的部分讨论也摘录到我们的文章 [2](#c13.xhtml#c13-bib-0002) 中作为单独的用户指南。

## 13.2 CONCEPTS OF ENTROPIES

为了找到高度准确且具有强预测能力的分类规则，我们需要指定一个适当的不纯度度量，以便在树的每个节点处选择合适的特征进行分割。特别是，我们希望在每次分割后最大化信息增益。那么如何量化信息增益呢？在贪婪算法的指导下，一种方法是最大化每次分割后数据的熵减少量。每次分割后熵值（平均）越小，信息增益就越大。在深入细节之前，我们先介绍一些常用的信息论量。

### (I) Shannon and Differential Entropies

1948 年，Claude Shannon（参见 [13](#c13.xhtml#c13-bib-0015)、[14](#c13.xhtml#c13-bib-0016））将热力学中的熵概念引入了信息理论。为了纪念他，信息语境下通常使用的熵常被称为 *Shannon entropy*，是衡量分布（非均匀分布）集中偏差的常见选择。在信息理论中，Shannon entropy 在定义通信信道容量方面至关重要，它衡量信道在信息传输中的效率。

设 `x` 为一个离散随机变量，取值于 `X`，概率质量为 `p(x_i) = P(x = x_i)`，其中 `i` 为有限多个值。其（无条件）Shannon entropy，记为 `H(x)`，定义为：

[(13.2)](#c13.xhtml#R_c13-disp-0002)`H(x) := -Σ log₂ p(x) = -Σ p(x) log₂ p(x)`
