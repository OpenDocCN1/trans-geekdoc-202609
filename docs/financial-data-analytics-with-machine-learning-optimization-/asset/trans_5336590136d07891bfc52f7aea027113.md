

2. 对于 `t = 2, ..., T-1`，`h_t` 依赖于 `h_{-t}` 并仅通过 `h_{t-1}` 和 `h_{t+1}` 影响 `h_{-t}`，且满足：

```
p(h_t | h_{-t}, μ, φ, ν_η) = p(h_t | h_{t-1}, h_{t+1}, μ, φ, ν_η)
∝ p(h_t | h_{t-1}, μ, φ, ν_η) · p(h_{t+1} | h_t, μ, φ, ν_η)
∝ exp { - (h_t - μ - φ(h_{t-1} - μ))² / (2 ν_η) - (h_{t+1} - μ - φ(h_t - μ))² / (2 ν_η) }
∝ exp { - 1/(2 ν_η) [ (h_t - μ)² - 2 h_t φ(h_{t-1} - μ) + φ²(h_t - μ)² - 2(h_{t+1} - μ)φ h_t ] }
∝ exp { - 1/(2 ν_η) [ (1 + φ²) h_t² - 2 μ h_t - 2 μ φ² h_t - 2 φ(h_{t+1} - μ + h_{t-1} - μ) h_t ] }
```

这是一个正态密度 `p_script`，均值为 `α̃_t`，方差为 `β̃_t²`，其中：

```
α̃_t := μ + φ((h_{t+1} - μ) + (h_{t-1} - μ)) / (1 + φ²)
β̃_t² := ν_η / (1 + φ²)
```
