

在代价复杂度剪枝中，人们不仅关注原始分类误差 `R(T)`，还关注树的复杂度，从而避免过拟合。这是通过在原始分类误差 `R(T)` 中添加一个“惩罚”项来实现的，因此目标现在是构建一棵使以下式子最小化的树

(13.16) `R_α(T) = R(T) + αT := (1/n) Σ(l=1 to T) Σ((x_i, y_i) ∈ T_l) 1_{y_i ≠ ȳ_T_l} + αT.`

这里，`α` 是一个控制模型复杂度影响的超参数。给定 `α ≥ 0`，我们的目标是找到 `T` 的一棵子树 `T(α)`，记作 `T(α) ⊆ T`，使其最小化 `R_α(T)`，即：

(13.17) `T(α) := arg min_{T̃ ⊆ T} R_α(T̃) = arg min_{T̃ ⊆ T} (R(T̃) + αT̃).`
