

我们如下展示 Lloyd 算法的局部最优性。对于任意时间步 `t`，我们用 `L_{t,1}` 和 `L_{t,2}` 分别表示算法 14.1 中第 2 步和第 3 步之后目标函数（[14.2](#c14.xhtml#c14-disp-0002)）的值。根据第 2 步的性质，显然有 `L_{t,1} <= L_{t-1,2}`。对于第 3 步的质心更新，我们固定一个任意簇 `S_k^(t)`，并仅关注该簇的均方误差。请注意，下述平方和是 `c_k` 的函数，

```
\sum_{x \in S_k^{(t)}} \|x - c_k\|_2^2 = \sum_{x \in S_k^{(t)}} (x - c_k)^T (x - c_k) = \sum_{x \in S_k^{(t)}} (x^T x - 2 x^T c_k + c_k^T c_k),
```

其一阶条件意味着

```
\sum_{x \in S_k^{(t)}} (-2x + 2c_k) = 0 \iff c_k^* = \frac{\sum_{x \in S_k^{(t)}} x}{|S_k^{(t)}|} = c_k^{(t)}.
```
