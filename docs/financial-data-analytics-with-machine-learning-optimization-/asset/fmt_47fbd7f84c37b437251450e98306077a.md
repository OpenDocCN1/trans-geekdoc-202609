
To conclude the claim that `AV = UΣ`, we only have to pick `n - r` more `v_i`'s and `m - r` more `u_j`'s from the null spaces `N(A)` and `N(A^⊥)`, respectively. Each set of these can be chosen to be the respective orthonormal bases for those two null spaces. Note that by then, they would be orthogonal to the first `r` `v_i`'s (being in the row space of `A`) and `u_j`'s (being in the column space of `A`) respectively. For instance, for `v_{r+1}, ..., v_n` from `N(A)`, `i = r + 1, ..., n`, and `j = 1, ..., r`, we have

```
⟨v_i, v_j⟩ = v_i^⊥(A^⊥u_j) = (Av_i)^⊥u_j = 0,
```

by definition. Similarly,

```
σ_j⟨u_j, u_i⟩ = ⟨Av_j, u_i⟩ = v_j^⊥A^⊥u_i = v_j^⊥0 = 0.
```
