
More precisely, let `x₁, …, xₙ` be an observable `p`-dimensional random sample of size `n` from a population with a common “mixed joint density” function `f(x; θ)`, where `θ` is a `k`-dimensional vector of parameters. Note that if all components of the random observation `x` are continuous (resp. discrete), then `f` is just the joint density function (resp. joint probability mass function) as usual, yet this is not always the case. For if some components of `x` are continuous while the others are discrete (or even categorical), `f` is taken as a mixed joint density function. As an example, let `x = (x₁, x₂)ᵀ` be a 2-dimensional random vector and `θ = (θ₁, θ₂, θ₃)ᵀ` be a 3-dimensional vector of positive parameters, such that `x₁ ~ Poi(θ₁)` and `x₂ = Σᵢ₌₁ˣ¹ Gᵢ`, where `Gᵢ ~ᵢᵢᵈ Gamma(θ₂, θ₃)` with the pdf `θ₃^θ₂ / Γ(θ₂) · x^(θ₂ - 1) · e^(-θ₃x)`, for `i = 1, 2, …`. ```
f(x₂ | x₁; θ) = θ₃^(x₁θ₂) / Γ(x₁θ₂) · x₂^(x₁θ₂ - 1) · e^(-θ₃x₂),
