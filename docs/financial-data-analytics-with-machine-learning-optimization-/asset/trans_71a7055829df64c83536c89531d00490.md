

# 贝叶斯参数估计方法

贝叶斯参数估计方法是一种概率方法，在此方法中采用最优决策规则，这与通常的最大似然估计（MLE）方法形成对比。与 MLE 相比，MLE 得到的 `θ̂` 最大化了获得给定训练数据集样本的概率，而贝叶斯方法则评估了 `θ` 在样本下取各种值的条件概率；有关比较的示意图，请参见 [图 1.1](#c01.xhtml#c01-fig-0001)。确实，对于 `贝叶斯推断`，训练阶段使用输入数据更新我们对 `θ` 概率的先验信念，从而得到后验概率，如 [图 1.1](#c01.xhtml#c01-fig-0001)b 所示。

贝叶斯推断的理论基础是 `贝叶斯定理` 的扩展形式：设 `A₁, …, Aₙ` 为互斥事件，且 `∪ᵢ₌₁ⁿ Aᵢ = A`。那么，对于任何事件 `B ⊆ A`，我们有

(1.10) `P(A₍ⱼ₁,…,ⱼₖ₎ | B) = P(B | A₍ⱼ₁,…,ⱼₖ₎) P(A₍ⱼ₁,…,ⱼₖ₎) / Σᵢ₌₁ⁿ P(B | Aᵢ) P(Aᵢ) = Σᵅ₌₁ᵏ P(B | Aⱼₐ) P(Aⱼₐ) / Σᵢ₌₁ⁿ P(B | Aᵢ) P(Aᵢ)`

其中 `A₍ⱼ₁,…,ⱼₖ₎ = ∪ᵅ₌₁ᵏ Aⱼₐ`。
