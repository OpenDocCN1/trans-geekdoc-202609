

注意，训练集 `X` 是一个 `(112 · 92) × (9 · 40) = 10,304 × 360` 矩阵，导致一个奇异的 `10,304 × 10,304` 矩阵 `XX⁺`。从 [第 1 章](#c01.xhtml) 的 [第 1.2 节](#c01.xhtml#c01-sec-0007) 中，我们知道 `XX⁺` 和 `X⁺X` 的最大 360 个（非零）特征值相同。对于 `i = 1, …, 360`，令 `uᵢ` 为 `X⁺X` 的第 `i` 个特征向量，则 `XX⁺` 的第 `i` 个特征向量由 `hᵢ = Xuᵢ` 给出；同时，奇异矩阵 `XX⁺` 的其余特征值 `λ₃₆₁, …, λ₁₀,₃₀₄` 简单地为零。利用这一点，我们只需考虑 `X⁺X` 的谱分解即可。我们在 [程序 9.19](#c09.xhtml#c09-sec-3019) 中通过 Python 实现了这一点。

从 Python 中 [程序 9.19](#c09.xhtml#c09-sec-3019) 的输出可以看出，107 个主成分足以保留总方差中包含的 90% 的所有信息。注意，训练集已标准化，因此总方差等于 `p = h · w = 10,304`。可以在 [程序 9.20](#c09.xhtml#c09-sec-3020) 中找到通过 `R` 的类似实现。

在 Python 中，`sklearn` 中的 `PCA` 也可以直接使用参数 `n_components=0.9` 来保留 90% 的信息；另请参见 Python 中的 [程序 9.21](#c09.xhtml#c09-sec-3021) 和 `R` 中的 [9.22](#c09.xhtml#c09-sec-3022)。对于 `R`，由于训练数据集已经过归一化，我们使用两个参数 `center=FALSE` 和 `scale=FALSE` 调用 `prcomp()` 函数。

训练集和测试集都通过投影到这 107 个主成分进行转换。然后，我们比较每个测试观测值与训练数据集中所有观测值之间的欧氏距离。训练数据集中与查询人脸图像产生最短距离的观测值被认为与该测试观测值匹配。
