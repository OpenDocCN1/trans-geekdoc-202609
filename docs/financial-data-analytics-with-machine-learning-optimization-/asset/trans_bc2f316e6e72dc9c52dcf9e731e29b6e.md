Empirical studies found that this value of ![lamda](images/c07-i0053.png)<math display="inline" overflow="scroll"><mrow><mi>&#955;</mi></mrow></math> gives a reasonable volatility estimate for most common stocks [\[18\]](#c07.xhtml#c07-bib-0017).
