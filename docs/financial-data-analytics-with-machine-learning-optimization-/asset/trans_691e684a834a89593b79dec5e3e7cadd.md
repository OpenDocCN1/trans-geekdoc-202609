

众所周知，`x ∈ MDA(Φ_α)` 当且仅当 `x ∈ RV_{-α}`；此外，`x` 的右端点为无穷大。另一方面，如果 `x ∈ MDA(Λ)`，则 `x ∈ RV_{-∞}`，但逆命题一般不成立。为了刻画 `MDA(Λ)` 中的分布，我们引入了 *冯·米塞斯函数* 的概念。具有右端点 `x_0` 的冯·米塞斯函数 `F_#` 是一个分布函数，使得存在 `z_0 < x_0` 和 `c > 0` 以及

```
1 - F_#(x) = c(x) exp {-∫_{z_0}^{x} 1/f(u) du, for all z_0 < x < x_0}
```

其中 `f` 是 `(z_0, x_0)` 上的一个正绝连续函数，具有 *Radon–Nikodym 导数* `f'`，且 `lim_{u ↑ x_0} f'(u) = 0`；而 `c(x)` 是一个满足 `lim_{x → x_0} c(x) = c` 的函数。具有右端点 `x_F ≤ ∞` 的分布 `F` 属于 `MDA(Λ)` 当且仅当存在一个以 `x_F` 为右端点的冯·米塞斯函数 `F_#`，以及一个点 `z_0 < x_F`，使得对所有 `x ∈ (z_0, x_F)`，

```
1 - F(x) = 1 - F_#(x) = c(x) exp {-∫_{z_0}^{x} 1/f(u) du}
```
