### 10.6.3 混淆矩阵和 ROC 曲线

在评估分类器性能时，分类表中显示的准确性并不是一个非常稳健的度量，有时可能具有误导性。为了弥补其不足，我们可以引入其他度量，例如 `precision`、`recall`（又称 `True Positive Rate` (TPR)）、`False Positive Rate` (FPR) 和 `F1` `score` ![FIGURE 10.7 Using the cleansed dataset d3 from Programme 10.11, lift charts of ranking versus cumulative percentage and proportion, respectively.](images/c10f007.png)

[**FIGURE 10.7**](#c10.xhtml#R_c10-fig-0007) 使用来自 [Programme 10.11](#c10.xhtml#c10-sec-3011) 的清洗数据集 `d3`，分别绘制排名与累积百分比和比例的提升图。

![TABLE 10.1  Confusion matrix for a medical test.](images/c10-i0343.png)

[**TABLE 10.1**](#c10.xhtml#R_c10-tbl-0001)  医疗测试的混淆矩阵。

基于 [Table 10.1](#c10.xhtml#c10-tbl-0001)，该测试的精确率、召回率（又称真阳性率，TPR）、FPR（假阳性率）和 `F1`‐score 定义如下：

`Precision := TP / (TP + FP)`

是阳性结果中正确测试结果的比例；

`Recall (a.k.a. TPR) := TP / (TP + FN)`

是所有实际为阳性的观测值中被正确分类为阳性的观测值的比例；

`FPR := FP / (TN + FP)`

定义为所有阴性观测值中被错误分类为阳性的观测值的比例（另请参见 [Figure 10.8](#c10.xhtml#c10-fig-0008) 以了解 TPR 和 FPR 定义的示意图）；

`F1 := 2 / (1 / Precision + 1 / Recall) = (2 × Precision × Recall) / (Precision + Recall)`

是精确率和召回率的调和平均数。其优势可以通过考虑如 [Table 10.2](#c10.xhtml#c10-tbl-0002) 中所示的罕见疾病测试来体现。
