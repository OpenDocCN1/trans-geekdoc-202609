
# 诊断分析与主成分回归（PCR）

## 诊断分析

对于诊断分析，我们本质上考虑将丢弃的杂项项 $\sum_{j=N+1}^{K} \beta_j P_j(\boldsymbol{x}_i)$ 与特异性噪声项 $\epsilon_i$ 合并，这意味着它们相加成为另一个误差项 $\tilde{\epsilon}_i$。只要正态 $\epsilon_i$ 与粗体 $\boldsymbol{x}_i$ 独立，正态 $\epsilon_i$ 就与 $\mathrm{P}_k(\boldsymbol{x}_i)$ 不相关，对所有 $k = 1, \ldots, K$ 成立。因此，正态 $\tilde{\epsilon}_i$ 也与 $\mathrm{P}_j(\boldsymbol{x}_i)$ 不相关，对那些 $j = 1, \ldots, N$ 成立，并且与 MANOVA（多元方差分析，参见 [\[12\]](#c10.xhtml#c10-bib-0012)）中关于各系数显著性诊断的相同理论仍可应用。

## 主成分回归（PCR）示例

作为 PCR 的示例，我们再次使用在 [小节 10.2](#c10.xhtml#c10-sec-0003) 中描述的 Boston 房价数据集。我们首先将房价数据集按 8 比 2 的比例分为训练数据集和测试数据集，然后对训练数据集的相关系矩阵应用 PCA。[方案 10.24](#c10.xhtml#c10-sec-3024) 展示了 Python 中 PCA 的应用。如在 [方案 9.3](#c09.xhtml#c09-sec-3003) 中讨论的，我们在将训练数据集输入 Python 中的 `PCA()` 类之前先标准化每个特征变量，并且我们还将使用相同的样本均值和样本标准差来标准化测试数据集中的相应特征变量。

![FIGURE 10.12 Scree plot of the Boston housing training dataset in Python, generated in Programme 10.24.](images/c10f012.png)

[**FIGURE 10.12**](#c10.xhtml#R_c10-fig-0012) Scree plot of the Boston housing training dataset in Python, generated in [Programme 10.24](#c10.xhtml#c10-sec-3024)。

从 [方案 10.24](#c10.xhtml#c10-sec-3024) 的输出中，我们观察到前 9 个主成分可以解释超过 95% 的总方差；[图 10.12](#c10.xhtml#c10-fig-0012) 进一步证明了这一说法，并显示在前 9 个主成分之后总方差仅略微下降。因此，可以采用前 9 个主成分来拟合多元线性回归模型。

在 [方案 10.26](#c10.xhtml#c10-sec-3026) 中，我们通过 Python 比较 PCR 模型与完整数据集的多元线性回归模型，通过基于测试数据集计算相应的均方根误差（RMSEs，与之前定义的残差均方误差不同）：

![FIGURE 10.13 Scree plot of the Boston housing training dataset in R, generated in Programme 10.27.](images/c10f013.png)

[**FIGURE 10.13**](#c10.xhtml#R_c10-fig-0013) Scree plot of the Boston housing training dataset in `R`, generated in [Programme 10.27](#c10.xhtml#c10-sec-3027)。

如预期，PCR 的 RMSE 略高于完整数据集的多元线性回归模型，因为最终我们确实忽略了原始 Boston 房价数据集中的一些信息，只选择了 13 个主成分中的 9 个。

类似地，在 **R** 中采用的 `pls`（主成分最小二乘）包中的 `pcr()` 函数可以执行 PCR。从 [图 10.13](#c10.xhtml#c10-fig-0013) 中，我们观察到第五个主成分是碎石图的拐点，表明前 5 个主成分可用于 PCR。比较 [图 10.12](#c10.xhtml#c10-fig-0012)（Python）和 [10.13](#c10.xhtml#c10-fig-0013)（`R`）中的各自输出，尽管由于绘制的训练数据集的随机子样本导致曲线形状存在微小差异，但它们的一些关键特征，例如拐点的位置确实非常相似。此外，两个方案选择的主成分数量之差是由于 Python 和 `R` 之间选择标准的差异；而 Python 选择解释超过 95% 总方差的主成分，`R` 仅将拐点设置为所选主成分的最大数量。

回顾在 [第 10.4 节](#c10.xhtml#c10-sec-0005) 的 MNIST 示例中，使用通用多项逻辑回归模型拟合时，有 $28 \times 28 = 784$ 个特征变量，导致巨大的 $7{,}056$ 个系数权重和 9 个偏差。让我们通过将主成分分析（PCA）的降维技术从线性回归扩展到多项逻辑回归来跨越一步。为此，如前所述，我们选择解释 95% 总方差的主成分数量。由于像素特征变量在 0 到 255 之间具有相同的灰度，我们仅通过用各自的特征均值对训练特征数据矩阵中的每个特征变量进行中心化来标准化它们；我们不使用各自的标准差对每个特征变量进行重新缩放。此过程直接通过 Python 中的 [方案 10.28](#c10.xhtml#c10-sec-3028) 中的 `PCA()` 执行。
