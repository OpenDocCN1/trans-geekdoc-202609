

# 极值 Copula 与 Max-Stable 性质

对于所有整数 `m ≥ 1` 以及所有 `(u₁, …, u_d) ∈ [0, 1]^d`，极值 Copula 显然属于自身的吸引域，因此它本身就是一个极值 Copula。事实上，这两个概念是等价的：一个 Copula 是极值 Copula 当且仅当它是 Max-Stable 的。
