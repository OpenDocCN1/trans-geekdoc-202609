

从 [Programme 6.16](#c06.xhtml#c06-pre-00016) 得到的结果表明，两种方法都能产生近乎完美的拟合，但它们对 `β` 的估计略有不同；事实上，特征向量是线性相关的（请参见 [Programme 6.18](#c06.xhtml#c06-pre-00018) 中的相关系数矩阵，Python 实现），这导致 `β` 估计的不稳定。MLE 的 0.9926 准确率略高于 MH 中位数估计的 0.9897。在 [Programme 6.17](#c06.xhtml#c06-pre-00017)（通过 Python）中，我们绘制了 `β` 的模拟路径。

现在，让我们转向 `R` 中的相应实现。同样，我们从 Metropolis–Hastings 算法的构建开始；请参见以下 [Programme 6.19](#c06.xhtml#c06-pre-00019)。

![](images/c06-gra-0026.png)

作为一个说明，在 `R` 环境中，我们无法像在 Python 中那样保存和检索参数。因此，我们修改了主函数 `MCMC_logistic()`，使其返回一个包含以下内容的列表：（i）`beta_hist` 用于系数参数 `β` 的历史估计值，用于模拟路径；（ii）`n_accept` 用于整体模拟的接受总次数；（iii）`num_it` 用于迭代总次数；以及（iv）`burn_in` 用于要丢弃的第一批马尔可夫链样本的数量。接下来，我们将 [Programme 6.19](#c06.xhtml#c06-pre-00019) 应用于 HSI 数据集，并将相应的估计与从 `glmnet()` 获得的 MLE 进行比较；请参见 [Programme 6.20](#c06.xhtml#c06-gra-00020) 中的 `R` 代码和结果。

![](images/c06-gra-0027.png)

在 `R` 的 `glmnet()` 函数中，`λ` 被设置为 0，以便在二元逻辑回归的目标函数中不添加惩罚项，这与 Python 中 [Programme 6.16](#c06.xhtml#c06-pre-00016) 中 `LogisticRegression()` 的参数 `penalty=None` 类似。`glmnet` 采用梯度下降算法来估计系数 `β`，但在初始点选择不理想的情况下，如果直接将 `λ` 设置为 0 来估计 `β`，该算法可能会出现收敛错误。为解决此问题，我们首先在 `λ = 10⁻⁴` 时估计 `β`，得到的估计值应非常接近原始目标函数的极小值点，然后将其用作估计的初始点，此时 `λ` 可以设置为 0。MLE 方法和带有中位数估计的 MH 算法都达到了相同的训练准确率 0.9926471。
