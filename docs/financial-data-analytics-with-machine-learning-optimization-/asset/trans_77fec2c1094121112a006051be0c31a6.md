

此外，诸如 `Benford's Law` [\[16\]](#f10.xhtml#cintro-bib-0016) 和 `Zipf's Law` [\[6\]](#f10.xhtml#cintro-bib-0006) 等数据分析技术已被用于检测潜在的会计缺陷和不规则行为。这些统计现象作为审计师和调查人员识别业务数据中异常的工具，从而有助于财务报告的完整性和透明度。

为此，在当代背景下，财务数据分析本质上是为金融行业的个人和企业提供工具和理解，重点在于在金融的各个方面实现详细结果和优化，例如盈利能力和风险降低。

上述历史上的问题调查方法共享一种共同的哲学：它们通过数学模型建立财务目标与可用数据之间的变量之间的联系。这种方法有效地将问题的维度从无限减少到有限；为此，只需通过统计方法估计少数（可能非常庞大）参数。展望未来，随着机器学习的近期出现，财务分析也出现了新的可能性；例如，一些（门控）循环神经网络，如 `long-short term memory` (LSTM) 模型，已被证明与证券价格预测和市场异常识别相关。总的来说，深度学习采用不同的方法，利用深度神经网络替代上述那些数学模型。深度神经网络的挑战在于其黑盒特性，需要探索简洁的数学描述来理解其内部工作原理。这种对全面理解的追求是在可解释 AI 的背景下进行的，这将是未来十年的一个关键焦点。特别是，我们热切期待在可预见的未来，在财务数据分析领域沿着这个方向出现新的发展。

## 图书组织

本书分为三个不同的部分，每个部分侧重于主题的不同方面。

[第 I 部分](#p01.xhtml) 作为基础，涵盖数学、统计学和编程的基本知识。[第 1 章](#c01.xhtml) 和 [第 2 章](#c02.xhtml) 回顾了一些理解后续章节所必需的基本数学概念和编程技术。涵盖的主题包括矩阵分析、概率论、基础贝叶斯统计，以及 Python 和 `R` 的简要介绍，并通过 CAPM 与 ANOVA 诊断的应用进行演示。[第 3 章](#c03.xhtml) 介绍了用于分析和评估财务数据分布的统计诊断技术。[第 4 章](#c04.xhtml) 深入探讨了数据分析在金融取证中的应用，并探讨了检测欺诈活动的技术，包括异常检测和法务会计。[第 5 章](#c05.xhtml) 介绍了数值金融中模拟的样本生成和方差减少技术的一些典型方法，重点介绍了著名的蒙特卡洛方法，并通过期权的一些希腊字母计算进行说明。[第 6 章](#c06.xhtml) 介绍了模型推断中参数估计、迭代优化和复杂概率分布生成的几种有用的数值算法。[第 7 章](#c07.xhtml) 探讨了连续时间证券数据的建模和分析，涵盖了不同的分层时间序列模型，并通过善拟指数（凯利公式）对日历效应进行分析，介绍了一些有利可图的交易策略。金融中的风险度量概念在 [第 8 章](#c08.xhtml) 中得到探讨。它涵盖了根据巴塞尔协议规定的流行风险度量，如风险价值和预期短缺，以及一些先进的建模方法，如 `extreme value theory` 和用于依赖结构的 copulae 使用。

随着我们从 [第 I 部分](#p01.xhtml) 进入 [第 II 部分](#p02.xhtml) 和 [第 III 部分](#p03.xhtml)，我们将重点从基本概念和数据清洗技术转移到探索财务数据分析中常用的各种线性和非线性模型。[第 II 部分](#p02.xhtml) 介绍了更先进的建模技术，提供了关于线性模型、降维和分类方法的见解。我们通过在 [第 9 章](#c09.xhtml) 中介绍 `Principal Component Analysis` (PCA) 用于降维和特征提取来拉开 [第 II 部分](#p02.xhtml) 的序幕。推荐系统的协同过滤技术也进行了讨论。回归学习中常用的几种模型，如多项式回归、逻辑回归、泊松回归和主成分回归，以及模型选择和诊断中的实际考虑，在 [第 10 章](#c10.xhtml) 中进行了讨论。[第 11 章](#c11.xhtml) 探讨了金融中线性分类器的使用，包括感知机和支持向量机。随机梯度下降法和二次规划等多功能技术也得到了涵盖。

[第 III 部分](#p03.xhtml) 与 [第 II 部分](#p02.xhtml) 具有相同的侧重点，但重点在于更丰富的非线性模型，这些模型在有效分析现实世界财务数据方面与线性模型一样发挥着至关重要的作用。[第 12 章](#c12.xhtml) 介绍了贝叶斯建模技术；特别是，将讨论几种贝叶斯分类器，包括作者最近开发的一种原创且高效的方法，称为 `Comonotone-Independence Bayes classifier` (CIBer)。

最后但同样重要的是，为了方便读者，本书中展示的 Python 和 `R` 代码、采用的数据集以及未来更新，都可以通过 GitHub 上的链接 [`https://github.com/kaiser1999/Financial-Data-Analytics/`](https://github.com/kaiser1999/Financial-Data-Analytics/) 轻松获取；读者也可以通过 [图 1](#f10.xhtml#cintro-fig-0001) 中的二维码跳转到该链接。
