
**Example 5.7** Consider an Asian call option with `S₀ = 10, K = 8, r = 0.05, σ = 0.3`, and `T = 1`. Under the Black–Scholes framework, `σ(S̃ₘ⁽ⁱ⁾) ≡ σ` in `[5.11](#c05.xhtml#c05-disp-0073)` for `m = 0, …, M − 1` and `i = 1, …, n = 100, 000`. We use the two discretization schemes discussed above to estimate the current price of this Asian call option by using different values of `M ∈ {10, 100, 1000}`. We shall first lay down the code for the simulation of the Asian call option in [Programme 5.19](#c05.xhtml#c05-gra-00019) via Python and in [Programme 5.20](#c05.xhtml#c05-gra-00020) via `R`. Note that for the sake of fair comparison between the two schemes in this example, we also compute an “exact” price for every candidate value of `M` via the standard Monte Carlo approach, as a benchmark of comparison. Readers may verify on their own, by choosing larger values of `M` and `n` in the programmes, that the “exact” theoretical price of the continuous arithmetic Asian option in question lies within the range of `2.19 ± 0.01`.
