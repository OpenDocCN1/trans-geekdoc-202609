

where `p<sub>ij</sub>` 是组 `i` 和 `j` 之间单次两两比较的 `p` 值。然后，如果 `∑<sub>i,j</sub> p<sub>ij</sub> < α`，我们将在显著性水平 `α` 下拒绝各组两两均值同时相等的原假设。

接下来，我们将通过 Python 和 `R` 说明单因素方差分析（one-way ANOVA）和 Tukey HSD 对三个股票市场指数（即 S&P500、HSI 和 FTSE）的应用；需要注意的是，对于本示例，我们将优先阐述 `R` 中的实现，并辅以其 Python 对应代码。数据文件 `SPX.csv`、`HSI.csv` 和 `FTSE.csv` 分别为 S&P500、HSI 和 FTSE 的调整后收盘价，时间跨度为 1984 年 1 月 4 日至 2021 年 4 月 26 日。特别是，将分析两个时间段的数据，即 (i) 2005 年至 2007 年；以及 (ii) 2018 年至 2020 年。

![](images/c02-gra-0022.png)

对于 `R` 中的 [Programme 2.13](#c02.xhtml#c02-gra-00013)，`as.Date()` 函数将数据框索引名称中的日期字符串转换为日期时间对象，其中参数 `format="%d/%m/%Y"` 表示输入字符串的日期格式为（两位数字）/ 月（两位数字）/ 年（四位数字）。之后，立即应用 `format()`，参数为 `"%Y"`，表示仅返回年份，并将其作为名为 `Year` 的新列增强到相应的股票市场指数数据框中。对数收益率，即连续价格比值的对数，由 `log()` 函数计算，然后通过 `diff()` 函数对连续项求差。需要注意的是，第一天（1984 年 1 月 4 日）的对数收益率不可用，因为我们没有前一天的调整后收盘价。因此，我们在对数收益率列表的开头补充 `NA`，并将其放入名为 `log_return` 的新列中。然后，我们通过 `[-1,]` 删除第一天的数据。

对于 `Remove_Outlier()` 函数（在 `R` 中定义于 [Programme 2.13](#c02.xhtml#c02-gra-00013) 或在 Python 中定义于 [Programme 2.14](#c02.xhtml#c02-gra-00014)），我们采用的约定是：任何低于下四分位数减去 1.5 倍四分位距，或高于上四分位数加上 1.5 倍四分位距的数据点均被视为异常值。如果每个股票市场指数都服从标准正态分布，那么 25%（即 75%）分位数在 `N(0, 1)` 下代表分位数值 −0.6745（即 0.6745）。以四分位距的 1.5 倍作为 `outlier_factor`，`lower_bound`（即 `upper_bound`）代表分位数值 −0.6745 + 1.5 ⋅ (0.6745 − (−0.6745)) = −2.6960（即 2.6960）。因此，在 `N(0, 1)` 下，我们选择中间部分 `Φ(2.6960) − Φ(−2.6960) = 0.9930`，其中 `Φ(⋅)` 是标准正态分布的累积分布函数（cdf）。因此，如果股票市场指数服从比 `N(0, 1)` 更重尾的分布，那么异常值大约占数据集的 1% 以上。
