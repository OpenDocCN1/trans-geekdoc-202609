where `C` 是决定最大化几何间隔与确保大多数 `x_i` 落在分离超平面正确一侧之间权衡的超参数。对于足够大的 `C` 值，铰链损失函数变得可忽略，因此 SVM 基本上忽略误分类，试图找到具有最大几何间隔的最优解。当我们降低 `C` 的值时，犯分类错误的代价变得更高，因此 SVM 试图通过牺牲几何间隔大小来减少错误。然而，更大的间隔更有利于泛化。因此，`C` 调节了在训练数据上分类良好（最小化经验风险）与对未来样本分类良好（泛化，具有更好的外部拟合）之间的平衡。

### 11.2.4 应用于信用评分

银行从贷款中获得利息，银行审查贷款申请人的信用评分并据此批准申请至关重要。让我们使用信用评分数据集 [\[9\]](#c11.xhtml#c11-bib-0009)

对于 [Programme 11.5](#c11.xhtml#c11-sec-3005) 中的 Python，SVM 模型通过 `sklearn` 库提供的 `SVC` 函数实现。特别是，`SVC` 需要两个参数，即定义为 `γ = 1 / (2 σ²)` 的 `gamma`，以及用于使用由 `exp(-γ ||x_i - x_l||²)` 定义的径向基函数作为核函数的 `kernel="rbf"`。根据所得结果，较小（resp. 较大）的 `σ` 值会产生较高（resp. 较低）的训练准确率和较低（resp. 较高）的测试准确率。确实，较大 `σ` 的 SVM 模型不太可能导致过拟合，因此泛化能力更好。[Figure 11.12](#c11.xhtml#c11-fig-0012)a 显示了针对 RBF 核的不同 `σ` 值，SVM 模型的训练和测试准确率。很明显，当 `σ` 超过 50 时，训练准确率趋于平稳，因此对于这个特定数据集，我们可以选择这个拐点处的 `σ` 值。这一选择还可以通过测试准确率在 `σ = 50` 处的平稳行为得到进一步证明，如 [Figure 11.12](#c11.xhtml#c11-fig-0012)b 所示。

![FIGURE 11.12 基于 Programme 11.5 通过 Python，针对信用评分数据集，不同 sigma 值的 RBF 核的 SVM 模型训练和测试准确率图。](images/c11f012.png)

同样，在 [Programme 11.6](#c11.xhtml#c11-sec-3006) 通过 `R` 中，SVM 模型通过库 `e1071` 提供的 `svm()` 函数实现。特别是，我们通过参数 `kernel="radial"` 采用 RBF 核，其中 `gamma`、`γ` 参数定义与 Python 中的 `SVC` 等效。[Figure 11.13](#c11.xhtml#c11-fig-0013) 中的结果与 Python 中的结果一致。
