

我们观察到，与给定 `(μ, σ²)` 时的原始条件分布 `N(μ, σ²)` 相比，该预测分布的方差中出现了额外因子 `βₙ⁻¹`；这反映了关于 `μₙ` 收敛于 `μ` 的额外不确定性。回顾一下，`βₙ⁻¹` 是给定 `x = x` 时 `μ` 的后验方差，随着样本量 `n` 的增加，它会减小到零，该预测分布的方差也是如此。这意味着当 `n → ∞` 时，`βₙ⁻¹ → 0`，且 `x` 的方差将减小为 `β⁻¹ = σ²`，这与 `μₙ` 收敛于 `μ` 的真实值相呼应。总而言之，这表明随着 `n → ∞`，`xₙ₊₁` 的预测分布将收敛于真实分布。

作为示例，我们重新审视 [图 1.4](#c01.xhtml#c01-fig-0004) 中的示例，其中样本是从 `N(2, 1)` 中绘制的，并且我们对均值使用先验分布 `N(-1, 1)` 进行了贝叶斯推断。在 [图 1.5](#c01.xhtml#c01-fig-0005) 中，我们绘制了不同样本量 `n` 值下 `xₙ₊₁` 的预测分布，即 `N(μₙ, sₙ² := β⁻¹ + βₙ⁻¹)`（实线），以及真实分布 `N(2, 1)`（虚线），可以清楚地看到，随着 `n` 的增加，前者收敛于后者。
