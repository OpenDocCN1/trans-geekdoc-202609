
### 11.2.1 Primal and Dual Problems in SVM

One can observe that ([11.9](#c11.xhtml#c11-disp-0018)) is indeed a Quadratic Programming (QP) problem. To solve this (primal) problem of finding the optimal parameters `ω*` and `b*` in ([11.9](#c11.xhtml#c11-disp-0018)), we can adopt the duality approach for QP problems by maximizing the dual Lagrangian (the corresponding dual problem); see Appendix \*11.A.2.3 for more details. To this end, we first write down the Lagrangian:

`L(ω, b, λ₁, ..., λₙ) = 1/2 ωᵀω − Σᵢ₌₁ⁿ λᵢ{yᵢ(xᵀᵀω + b) − 1}, λᵢ ≥ 0, i = 1, ..., n.`

The partial derivative of this Lagrangian with respect to `ω` and `b` are respectively given by:

`∇_ω L(ω, b, λ₁, ..., λₙ) = ω − Σᵢ₌₁ⁿ λᵢ yᵢ xᵢ;`
`∂L(ω, b, λ₁, ..., λₙ)/∂b = −Σᵢ₌₁ⁿ λᵢ yᵢ.`

When we equate these partial derivatives to zero, we obtain

`ω = Σᵢ₌₁ⁿ λᵢ yᵢ xᵢ and Σᵢ₌₁ⁿ λᵢ yᵢ = 0.`

[(11.9)](#c11.xhtml#R_c11-disp-0018)
`minimize ω, b`
`1/2 ωᵀω,`
`subject to yᵢ(xᵀᵀω + b) ≥ 1, for all i = 1, ..., n.`
