

考虑简单情况，即输入 `x` 和输出 `y` 均在 `ℝ` 中，且 `x` 与 `y` 之间的函数关系为 `y = f(x)`，例如 [图 15.14](#c15.xhtml#c15-fig-0014)a 所示。我们用阶梯函数近似该函数（参见 [图 15.14](#c15.xhtml#c15-fig-0014)b），使得每个“阶梯”都可视为形式为 `𝟙[xᵢ, xᵢ₊₁]` 的简单函数，其中 `xᵢ < xᵢ₊₁`。这些简单函数的线性组合显然可以通过减小实轴底层划分的网格大小，以任意精度近似 `f`。

![FIGURE 15.14 Illustration of approximating a function by simple functions.](images/c15f014.png)

考虑两个斜率非常陡峭的 Sigmoid 函数 `h₁` 和 `h₂`，使得对于一个很小的 `δ > 0`，`h₁` 在任何 `x ≤ −δ` 时保持为 0，但在 `x = −δ / 2` 处线性达到 1，之后保持不变。同样，`h₂` 在任何 `x ≤ δ / 2` 时保持为 0，但在 `x = δ` 处达到 1 并保持不变，如 [图 15.15](#c15.xhtml#c15-fig-0015)a 和 [15.15](#c15.xhtml#c15-fig-0015)b 所示。然后，函数 `h := h₁ − h₂` 可以近似给出我们所需的 [图 15.14](#c15.xhtml#c15-fig-0014)b 中的任何一个简单函数，如 [图 15.15](#c15.xhtml#c15-fig-0015)c 所示。

![FIGURE 15.15 Construction of a simple function.](images/c15f015.png)

[**FIGURE 15.15**](#c15.xhtml#R_c15-fig-0015) Construction of a simple function.

因此，对于输入 `x` 被传入两个分别具有激活函数 `h₁` 和 `h₂` 的 Sigmoid 神经元，如果我们在下一层的神经元中对它们应用权重 `+1` 和 `−1`，就可以获得一个简单函数所需的近似。通过组合几个类似的组件，如 [图 15.16](#c15.xhtml#c15-fig-0016) 所示，我们可以近似任意函数 `f`。最后，请注意，通过适当缩放逻辑函数或双曲正切函数的定义域，其中任何一个都可以很好地近似 `h₁` 或 `h₂`。因此，定理的主张成立，这在一定程度上证明了深度神经网络的有效 `representational power of deep neural networks`。

## 15.9 LONG SHORT‐TERM MEMORY (LSTM)

`Long Short‐Term Memory` (LSTM) 模型是一种 `recurrent neural network` (RNN)。这种 DNN 旨在学习和存储时间序列中的长期依赖关系。它最初由 Hochreiter 和 Schmidhuber [[10](#c15.xhtml#c15-bib-0010)] 提出。此后，LSTM 已广泛应用于各种序列到序列任务，例如自然语言处理、语音识别和时间序列预测；另请参见 [[6](#c15.xhtml#c15-bib-0006), [11](#c15.xhtml#c15-bib-0011), [15](#c15.xhtml#c15-bib-0015), [22](#c15.xhtml#c15-bib-0022)]。

LSTM 的关键成分是使用记忆单元，使网络能够学习和记住长期依赖关系。每个记忆单元由三个主要组件组成：输入门、遗忘门和输出门；参见 [图 15.17](#c15.xhtml#c15-fig-0017) 以及 [[10](#c15.xhtml#c15-bib-0010)] 中的更多信息。这些门控制单元内部的信息流，使单元能够有选择地从其内部状态存储、更新和检索信息。这种门控机制有助于缓解 `vanishing gradient problem`，这是传统 RNN 中的常见问题 [[2](#c15.xhtml#c15-bib-0002)]。输入门决定新输入数据在多大程度上存储在单元状态中。遗忘门决定单元状态的哪些部分应被遗忘或保留，使网络能够学习何时丢弃无关信息。最后，输出门根据单元的当前状态控制单元的输出；更多讨论可见 [[7](#c15.xhtml#c15-bib-0007), [10](#c15.xhtml#c15-bib-0010), [23](#c15.xhtml#c15-bib-0023)]。
