

*   Case 3: 如果 `φ(t; λ, ε_S)` 承认一个唯一根 `s*`，且当 `s < s*` 时 `φ(s; λ, ε_S) < 0`；当 `s > s*` 时 `φ(s; λ, ε_S) > 0`，则通过定义 `t* := (T - s*)⁺`，最优卖出时间由 `τ_S* := inf {t ∈ [t*, T] : S_t = p M_t} ∧ T` 给出。当 `λ` 较大时，`s*` 将趋近于 0，此时 `t*` 接近 `T`，由此产生的最优卖出策略与买入并持有策略基本无异。请参见 [Figure 7.19](#c07.xhtml#c07-fig-0019) 中的灰色虚线；

*   Case 4: 如果 `φ(t; λ, ε_S)` 承认两个不同的根 `s₂* < s₁*`，则通过定义 `t₁* := (T - s₁*)⁺` 和 `t₂* := (T - s₂*)⁺`，最优卖出时间由 `τ_S* := inf {t ∈ [0, t₁*] ∪ [t₂*, T] : S_t = p M_t} ∧ T` 给出。特别是，随着 `λ` 取值变得更负，`t₁*` 和 `t₂*` 彼此趋近。最终，这缩小了这两个数之间的差距，使得该情况退化为 Case 1。请参见 [Figure 7.19](#c07.xhtml#c07-fig-0019) 中的黄色点划线。
