
In the remainder of this subsection, we discuss the case when the state space of the Markov chain is uncountable. In this circumstance, a probability measure `π` is said to be *stationary* if it is invariant with respect to the transition operator `í’«`: for any `f ∈ b(S)`, the integral `π(f) := ∫_S f(s) π(ds)` satisfies `π(í’« f) = π(f)`. The following [Theorem 6.6](#c06.xhtml#c06-sec-0027) is an analogy of [Theorem 6.3](#c06.xhtml#c06-fea-0026), which asserts that any irreducible and aperiodic Markov chain with an uncountable state space admits a stationary distribution. Its proof is relegated to [Appendix \*6.A.4](#c06.xhtml#c06-sec-0042).

**Theorem 6.6 *(Existence of Stationary Distribution with an Uncountable State Space)*** Under [Assumption 6.1](#c06.xhtml#c06-fea-0012), every irreducible and aperiodic Markov chain with an uncountable state space admits a stationary distribution.

Now, let us provide [Theorem 6.7](#c06.xhtml#c06-fea-0040), which serves an analogy of [Theorem 6.4](#c06.xhtml#c06-fea-0030). It states that the stationary distribution of an irreducible and aperiodic Markov chain with an uncountable state space is unique. We recall that the total variation distance for general state spaces can still be defined as in ([6.21](#c06.xhtml#c06-disp-0079)) for discrete state space. The proof of [Theorem 6.7](#c06.xhtml#c06-fea-0040), which makes use of the idea of “*almost-coupling*” to adapt the proof of [Theorem 6.4](#c06.xhtml#c06-fea-0030) for the uncountable state spaces case, can be found in [Appendix \*6.A.5](#c06.xhtml#c06-sec-0043).

**[Theorem 6.7](#c06.xhtml#R_c06-fea-0040) *(Markov Chain Convergence Theorem: Continuum State Space)*** Let `{x_n}` be an irreducible, aperiodic Markov chain with an uncountable state space `S` such that [Assumption 6.1](#c06.xhtml#c06-fea-0012) is fulfilled. For `n ∈ ℕ₀`, let `μ^(n)` be the distribution of `x_n` (i.e., `μ^(n)(A) = P(x_n ∈ A)` for any measurable subset `A` of `S`) with an initial distribution `μ^(0)`. Then `μ^(n) → π` in total variation distance for any stationary distribution `π` of `{x_n}`, i.e., `lim_{n→∞} d(μ^(n), π) = 0`.
