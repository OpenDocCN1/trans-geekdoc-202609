# CHAPTER 12

Bayesian Learning

在本章中，我们介绍另一类重要的半参数模型学习方法，称为 `Bayesian inference`，或者如果我们专注于模型校准，则称为 `Bayesian learning`。虽然 Bayesian inference 遵循半参数建模的许多常规步骤，包括模型规范、评估标准选择和参数估计，但它在所采用的标准方面与其他方法不同。确实，Bayesian inference 所使用的标准是达到各种参数值的概率，这作为先前提到的标准（例如损失函数最小化和最大似然估计）的替代方案。我们将重点介绍一些在 `FinTech` 和 `InsurTech` 中用于数据分析的有用的基于 Bayesian 的工具。
