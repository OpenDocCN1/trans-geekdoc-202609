
As a remark, the concept of Shannon entropy has an intimate connection with Fisherian statistical inference. Given a random sample `x1, ..., xn` of size `n` from a discrete random variable `x`, the likelihood is `∏(i=1 to n) p(xi)`, hence the average negative of log‐likelihood of the sample is `-(1/n) Σ(i=1 to n) ln p(xi)`. By the weak law of large numbers, as the sample size `n` goes to infinity, the limit of this average is `-(∫ ln p(x)) = -(Σ(x∈X) p(x) ln p(x))`, which is exactly `H(x) · ln 2`, thus the likelihood is asymptotically equal to `((1 / (2^H(x) · (1 + o_p(1))))^n)`. In addition, in information theory there is a strong motivation to use entropy for data compression. To compress the information stored in an `n`‐dimensional random sample `(x1, ..., xn) ∈ X^n` of a common random variable `x` by using binary codes, on average with `n` large enough, it suffices to use `n H(x)` bits.
