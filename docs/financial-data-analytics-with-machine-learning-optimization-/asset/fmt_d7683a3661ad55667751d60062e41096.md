
In this part, we denote the set `ℕ∞ := ℕ ∪ {∞}`. We also take the convention that `min ∅ = ∞`.

### 6.A.3.1 Proof of Theorem 6.2

Define `N₁: S → ℕ∞` by

[(6.34)](#c06.xhtml#R_c06-disp-0134)
```
N₁(s) := min {m : fⁿ(s) > 0 for any n ≥ m and f ∈ f_{b+} (S) with f(s) > 0}.
```

By the aperiodicity of the Markov chain and [Proposition 6.1](#c06.xhtml#c06-fea-0016)(ii), `N₁(s) < ∞` for every `s ∈ S`.

Fix `s₀ ∈ S` and let `N₁(s₀) = m`. We claim that there exists an open set `U_{s₀} ⊂ S` containing `s₀` such that `N₁(s) ≤ N₁(s₀)` for any `s ∈ U_{s₀}`. Indeed, by the definition of `N₁(s)`, for every `n ≥ m`,

[(6.35)](#c06.xhtml#R_c06-disp-0135)
```
fⁿ(s₀) = ∫_S μⁿ(s | s₀) g(s) ds > 0
```
