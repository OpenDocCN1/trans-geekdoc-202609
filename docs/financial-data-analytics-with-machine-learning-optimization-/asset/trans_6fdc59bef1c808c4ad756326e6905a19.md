

# 4.4 增长数据中的本福德定律

## 4.4.1 宏观经济和社会科学数据

在 [Programme 4.3](#c04.xhtml#c04-gra-0003) 通过 Python（或 [Programme 4.4](#c04.xhtml#c04-gra-0004) 通过 `R`）中，`Benford_Analysis()` 函数以相同方式定义，具有四个输入参数，即：`Count` 作为每个数字实际频率的 Python `pandas` 数据框（或 `R` `table`）；`EP` 为所选测试中每个数字的预期比例，按本福德定律计算；`DIGITS` 为测试感兴趣的可能首位数字集合；以及 `x_label` 为在条形图的 `x` 轴上打印的所选测试名称。此外，此 `Benford_Analysis()` 函数还导出一个频率图，显示实际数字频率如何偏离根据本福德定律的预期频率（由蓝色折线表示）。特别是，违反本福德定律的数字（使用折叠 `upper Z` `Z` 统计量具有小的 `p` 值（`< 0.05`））将被标记为红色。最后，所有数字一次性的卡方拟合优度检验的 `p` 值也会返回。

作为 Nigrini“五位数测试”的示例，我们将执行所有五个测试，而不考虑它们与本福德定律的个体一致性。对于这五个 Nigrini 数字测试中的每一个，我们首先从数据集中提取感兴趣的数字频率，然后构建一个 Python `pandas` 数据框（或 `R` `table`），其中包含数据集数值中观察到的相应实际频率，以及根据本福德定律预测的预期比例（EP），依据 ([4.3](#c04.xhtml#c04-disp-0016))，([4.4](#c04.xhtml#c04-disp-0017))，([4.5](#c04.xhtml#c04-disp-0018)) 和 ([4.6](#c04.xhtml#c04-disp-0019))。

虽然首位数字和第二位数字测试得出结论，即与本福德定律至少存在可接受的一致性，但为了说明目的，我们也继续讨论其余三个数字测试。对于前两位数字测试（另见 [Figure 4.5](#c04.xhtml#c04-fig-0005)），卡方拟合优度检验的 `p` 值为 0.028652，表明数据集与本福德定律具有边缘可接受的一致性。有趣的是，前两位数字测试中没有数字被使用折叠 `upper Z` `Z` 统计量的检验拒绝。对于前三位和末两位数字的测试（另见 [Figures 4.6](#c04.xhtml#c04-fig-0006) 和 [4.7](#c04.xhtml#c04-fig-0007)），相应的卡方拟合优度检验的小 `p` 值分别为 0.007938 和 0.004605，表明拒绝本福德定律：特别是，末两位测试案例底部列出的五个数字和前三位测试案例中列出的 24 个数字被使用折叠 `upper Z` `Z` 统计量的检验拒绝。
