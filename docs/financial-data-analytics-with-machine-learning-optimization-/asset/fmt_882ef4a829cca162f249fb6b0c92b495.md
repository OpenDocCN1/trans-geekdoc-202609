
Clearly, as the bandwidth `h<sub>n</sub>` decreases, the estimator `m̂(x₀)` tends to be less biased but more volatile. Thus, a larger `h<sub>n</sub>` is more likely to result in a smoother estimate `m̂(x₀)`, while a smaller `h<sub>n</sub>` may lead to a more oscillatory `m̂(x₀)`. Altogether, this phenomenon is sometimes called the `bias‐variance tradeoff` in the context of statistical machine learning. The optimal bandwidth that minimizes the sum of `(bias)² + variance` is then of the order of `n^(-1/5)`.

Alternatively, the Nadaraya–Watson estimator can also be motivated using the kernel density estimator of an unknown density function `fₓ(x)`, also known as the `Rosenblatt–Parzen kernel density estimator` (see [\[21](#c14.xhtml#c14-bib-0021), [24\]](#c14.xhtml#c14-bib-0024)):

[(14.12)](#c14.xhtml#R_c14-disp-0038)

```
f̂ₓ(x) = (1 / (n hₙ)) Σᵢ₌₁ⁿ K((x - xᵢ) / hₙ).
```
