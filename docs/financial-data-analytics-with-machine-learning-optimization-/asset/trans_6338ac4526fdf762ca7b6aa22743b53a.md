

接下来，我们考虑在贝叶斯推断中应用 Metropolis–Hastings 算法，该算法有助于在给定数据的情况下更新参数的后验分布。该过程可表述如下：设 `x1, ..., xn` 为来自同一分布的 `n` 个独立实现，该分布具有 `r` 个未知参数 `θ = (θ1, ..., θr) ∈ R^r`，这些参数最初共同服从先验分布 `π(θ)`，一旦收集更多数据，该分布将被修订为后验分布 `π(θ | x1, ..., xn)`。我们的目标是构建一个适当的马尔可夫链 `{θ^(t) = (θ1^(t), ..., θr^(t))^T}`，其平稳分布为后验分布 `π(θ | x1, ..., xn) ∝ π(θ) L(x1, ..., xn | θ)`，其中 `L` 是样本的似然函数。
