
### 3. (A3) Uniform (strong) convexity

For some `μ > 0`, `(11.21)(θ − θ′)ᵀ(∇_θ L(θ) − ∇_θ L(θ′)) ≥ μ‖θ − θ′‖₂², for any θ, θ′ ∈ ℝᵠ`, where `L(θ) := 𝔼[ℓ(θ; x)]`.

Assumption `(A3)` warrants that the function `L(θ)` has a unique minimizer `θ*` such that `∇_θ L(θ*) = 0`. Assumptions `(A1)` and `(A3)` implicitly assume that `μ < C`. Under these three assumptions, `Robbins–Monro theorem` states that when the learning rates `{η_t}` are chosen in such a way that

```
(11.22) ∑_{t=0}^∞ η_t = ∞ and ∑_{t=0}^∞ η_t² < ∞,
```

then as `t → ∞`, `θ^(t) → θ*` almost surely using SGD. A more general result, known as `Kiefer–Wolfowitz theorem` [[15](#c11.xhtml#c11-bib-0015)], asserts that the same convergence holds true when the gradient `∇_θ L(θ)` in the updating rule of ([11.17](#c11.xhtml#c11-disp-0040)) is numerically approximated by the central finite difference method, with step sizes of the finite differencing `{α_t}` chosen in a way that `∑_{t=0}^∞ η_t α_t < ∞`.
