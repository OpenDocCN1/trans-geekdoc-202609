
Next, we consider an application of the Metropolis–Hastings algorithm in Bayesian inference, where it helps to update the posterior distribution of parameters given the data. The procedure can be stated as follows: let `x1, ..., xn` be `n` independent realizations from the same distribution with `r` unknown parameters `θ = (θ1, ..., θr) ∈ R^r` which initially jointly follow a prior distribution `π(θ)` that will be revised to the posterior distribution `π(θ | x1, ..., xn)` once more data are collected. Our objective is to construct an appropriate Markov chain `{θ^(t) = (θ1^(t), ..., θr^(t))^T}` whose stationary distribution is the posterior distribution `π(θ | x1, ..., xn) ∝ π(θ) L(x1, ..., xn | θ)`, where `L` is the likelihood function of the sample.
