### 11.2.3 用于处理噪声的软间隔 SVM

在前一小节中，我们关注的是数据点在其原始空间中不可线性分离，但经过变换（例如高次多项式）后可以分离的情况。在本小节中，我们关注带有噪声的数据集，如 [图 11.11](#c11.xhtml#c11-fig-0011) 所示。

在处理噪声时，我们会对位于分离边界错误一侧的数据点施加一些惩罚。为此，我们为 SVM 引入了一个 *铰链损失函数*：
