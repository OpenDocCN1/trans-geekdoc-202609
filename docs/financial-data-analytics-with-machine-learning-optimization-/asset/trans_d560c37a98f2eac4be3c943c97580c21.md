

回想一下，在判断当前日期 `s` 是否处于从日期 `s - T + j` 到日期 `s + j` 的第 `(j + 1)` 个检查窗口的行动期（[7.39](#c07.xhtml#c07-disp-0063)）时，参数 `λ_{s - T + j}`、`ε_{S, s - T + j}`、`ε_{B, s - T + j}` 涉及日期 `s - T + j` 上 `μ_{s - T + j}` 和 `σ_{s - T + j}` 的估计值，而这种新提出的交易策略的性能当然与这些估计值的准确性相关。在本小节中，我们将从 `backtesting` 的角度评估其性能。

关于 `μ` 的估计，假设对于某个交易日 `t`，它是某个 `(j + 1)` 个检查窗口的开始，我们可以通过同时使用未来收益和历史收益来获得更好的估计。为此，引入了以下 `two-stage approach`：第一步，通过计算从前一天 `t - 1` 开始的 3 个连续交易日的加权几何收益率，获得初步估计 `μ̃_t`：

(7.41) `μ̃_t = ∏_{i=-1}^{1} (1 + u_{t + i})^{ω_i} - 1`

其中 `∑_{i=-1}^{1} ω_i = 1`；对于当前的 backtesting，我们更依赖于次日的收益，取 `ω_{-1} = 0.1`、`ω_0 = 0.3` 和 `ω_1 = 0.6`。
