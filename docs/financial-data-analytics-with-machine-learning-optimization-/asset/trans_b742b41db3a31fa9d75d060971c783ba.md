Similar to classification trees, we build a regression tree by searching greedily via a top‐down approach. Starting from the root node, we determine the best splitting attribute that minimizes the squared loss function, and we iterate the search followed by a child node. In the following, we only focus on the most common scenario of binary splitting, yet this is not necessary for regression trees, and the treatment below can easily be adapted for the general case when a parent node is split into three or more child nodes.
