
Also under Slater condition, since each `g_k` is convex (and hence continuous), `X_ε` is a nonempty compact and convex subset of `ℝ^p`. We denote by `m_f := min_{x ∈ ℝ^p} f(x)`, and `m_ε := min_{x ∈ X_ε} f(x)` for any `ε > 0`. Since `f` is continuous and for any `ε > 0`, the set `X_ε` is compact, `m_ε` is well‐defined and finite. It is obvious that

(11.33) `m ≥ m_{ε'} ≥ m_ε ≥ m_f, 0 < ε' < ε,`

and since `f` is continuous,

[(11.34)](#c11.xhtml#R_c11-disp-0078) `lim_{ε → 0} m_ε = m.`

For `ε > 0`, we define

`Λ_ε := {λ ∈ ℝ^K : λ ≥ 0, ||λ||_∞ ≤ (m - m_f)/ε},`

where `||·||_∞` denotes the (uniform) `∞`‐norm. Note that `Λ_ε` is convex and compact; and it shortly becomes clear with this definition.
