

在利息力 `δ` 下，如果 (i) `P_A(δ; 0) = P_L(δ; 0)` 且 (ii) 对于足够接近 0 的 `ε` 有 `P_A(δ + ε; 0) ≥ P_L(δ + ε; 0)`，则基金对利息力的微小变化 `ε` 具有免疫性。利用泰勒级数展开，这些条件可转化为 `P'_A(δ; 0) = P'_L(δ; 0)` 和 `P''_A(δ; 0) ≥ P''_L(δ; 0)`，即资产的麦考利久期（resp. 凸度）应分别等于（resp. 大于）负债的麦考利久期（resp. 凸度）。若我们用 `P(δ; t) := P_A(δ; t) - P_L(δ; t)` 表示两者在时刻 `t` 的时间价值之差，则上述条件可改写为 `P'(δ; 0) = 0` 和 `P''(δ; 0) ≥ 0`。
