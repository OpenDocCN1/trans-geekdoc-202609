

注意，只要能找到一个与 `x` 呈负相关的随机变量 `z`，即 `Cov(x₁, z₁) < 0`，就可以得到 `Var(ψ_A) < Var(x) / n = Var(μ̂_x)`。生成满足上述所有要求的 `(x, z)` 对的一种简单方法是取 `(x, z) := (F_x⁻¹(u), F_x⁻¹(1 - u))`，其中 `u` 是 `[0, 1]` 上的均匀随机变量。例如，当 `x ~ U(0, 1)` 时，只需取 `(x, z) = (u, 1 - u)`，其中 `u ~ U(0, 1)`；当 `x ~ N(μ, σ²)` 时，可以取 `(x, z) = (x, 2μ - x)`。这些变量对 `(x, z)` 称为 *antithetic*。下面的定理表明，antithetic 变量确实呈负相关。

**Proposition 5.1** 给定一个在 `θ ∈ (0, 1)` 中随 `θ` 增加的函数 `h(θ, γ)`，带有参数 `γ`，如果 `u ~ U(0, 1)`，且 `γ₁` 和 `γ₂` 是独立随机变量，则

```
Cov(h(u, γ₁), h(1 - u, γ₂)) ≤ 0
```
