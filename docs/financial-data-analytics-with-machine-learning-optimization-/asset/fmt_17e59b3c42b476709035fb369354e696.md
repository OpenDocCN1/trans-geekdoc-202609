
For any `s ∈ 𝒮`, since `𝒮⁰f = f` for all `f ∈ 𝒮_{b}⁺(𝒮)`, we have `s ↔ s`, and so the relation *communication* is reflexive. The symmetric property is also clear by its very definition. To show that communication is transitive, let `s₁, s₂, s₃ ∈ 𝒮` with `s₁ ↔ s₂` and `s₂ ↔ s₃`. For any `f ∈ 𝒮_{b}⁺(𝒮)` with `f(s₃) > 0`, using the fact that `s₂ ↔ s₃`, there exists `n₁ ∈ ℕ₀` independent of `f` such that `𝒮ⁿ¹f(s₂) > 0`. Let `g := 𝒮ⁿ¹f` and using the fact that `s₁ ↔ s₂`, we infer the existence of `n₂ ∈ ℕ₀` independent of `f` and `n₁` such that

```
0 < 𝒮ⁿ²g(s₁) = 𝒮ⁿ¹⁺ⁿ²f(s₁).
```

This implies that `s₁ → s₃`. The fact that `s₃ → s₁` can be shown similarly. Therefore, communication is indeed an equivalence relation.
