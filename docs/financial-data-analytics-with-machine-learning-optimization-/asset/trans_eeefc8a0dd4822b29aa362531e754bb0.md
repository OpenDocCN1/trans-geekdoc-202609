### 12.5.3 分类特征的联合编码

一般来说，分类特征更难处理，因为它们具有纯粹可区分的性质且缺乏自然顺序。因此，关联度量无法直接应用于它们，共单调性概念也无法立即应用。为了解决这个问题，受 *最优传输* 理论的启发，我们为分类特征引入了一种新的编码方案，该方案通过利用各种分组特征值的频率来“提升”分类特征之间固有的依赖关系。这种编码方案能够一次性处理多个分类特征，被称为 *联合编码*。

让我们通过一个简单的例子来说明联合编码的过程和有效性。考虑一个样本数据集的列联表，其中每个数据点包含两个分类变量 ![normal x 1](images/c12-i0421.png)<math display="inline" overflow="scroll"><msub><mi mathvariant="normal">x</mi><mn>1</mn></msub></math> 和 ![normal x 2](images/c12-i0422.png)<math display="inline" overflow="scroll"><msub><mi mathvariant="normal">x</mi><mn>2</mn></msub></math>。相应的列联表显示在 [表 12.1](#c12.xhtml#c12-tbl-0001)。
