

4. The `t`-EV copula: The name `t`-EV was proposed in [[16](#c08.xhtml#c08-bib-0016)], where the bivariate `t`-EV copula is derived. The multivariate `t`-EV copula is derived in [[36](#c08.xhtml#c08-bib-0036)]. Let `Tν` be the cumulative distribution function of the univariate `t`-distribution with `ν > 0` degrees of freedom. For the bivariate case, with a correlation coefficient `ρ ∈ [-1, 1]`, the copula is defined as `C(u₁, u₂; ρ, ν) = exp[ln(u₁u₂)B(ln u₁ / ln(u₁u₂); ρ, ν)]`, where the function:

```
B(w; ρ, ν) = wT_{ν+1}(√(ν+1)/√(1-ρ²)[(w/(1-w))^(1/ν) - ρ]) + (1-w)T_{ν+1}(√(ν+1)/√(1-ρ²)[((1-w)/w)^(1/ν) - ρ]).
```

5. *Tawn* copula: For the bivariate case, it is defined as `C(u₁, u₂) = u₁u₂exp(-α ln(u₁)ln(u₂)/ln(u₁u₂))`, where `α ∈ (0, 1)`. When `α = 0`, the independence copula can be achieved, but it is not possible to attain complete dependence.
