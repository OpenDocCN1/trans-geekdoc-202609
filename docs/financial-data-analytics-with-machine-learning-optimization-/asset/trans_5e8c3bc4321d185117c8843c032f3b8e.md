

由于现实中并非所有特征变量都必然是共单调的，在分类问题中，更合适且更现实的方法是首先将特征变量划分为若干子组，然后将每组内的特征变量视为共单调，而一组中的全部特征与另一组中的特征相互独立。然而，寻找最优划分的穷举搜索时间会随涉及的特征数量迅速增长。因此，我们必须部署一种高效的启发式搜索来逼近这个最优划分，而无需遍历所有可能性。结果表明，该解决方案是一种聚类方法。原则上，两个具有某个预设“距离”较小值的特征被视为共单调，并应被聚类到同一组中。用于测量共单调依赖关系的一些流行距离度量包括 `Normalized Mutual Information` `U`、`Pearson's` `r`、`Kendall's` `τ_b` 和 `Spearman's` `ρ`。我们引入了另一种基于 Kendall's `τ_b` 的度量，专门为 CIBer 构建。应当注意的是，距离度量的选择因情况而异，我们始终旨在选择能带来最佳性能的度量。让我们以其自然经验形式列出这些度量，其中 `x_i` 和 `x_j` 是任何两个不同的特征，具有观测对 `(x_1i, x_1j), …, (x_ni, x_nj)`：

1. **Normalized Mutual Information (NMI)** `Û` [15](#c12.xhtml#c12-bib-0015), [21](#c12.xhtml#c12-bib-0021)：它使用信息论中的熵来量化两个特征之间的依赖关系：

```
Û := 2 · Î(x_i; x_j) / (Ĥ(x_i) + Ĥ(x_j)).
```
