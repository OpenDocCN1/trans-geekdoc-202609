Archimedean copula 类非常广泛，涵盖了许多常用 copula 作为特例。以下是部分列表；更多示例可参见 [[35]](#c08.xhtml#c08-bib-0035) 中的 [表 4.1](#c04.xhtml#c04-tbl-0001)。

1. *Ali–Mikhail–Haq* 族：引入自 [[2]](#c08.xhtml#c08-bib-0002)，该族的生成子由 `ψ(t, θ) = ln((1 − θ)/t + θ), θ ∈ [0, 1)` 给出。

2. *Clayton* 族：引入自 [[13]](#c08.xhtml#c08-bib-0013)，该族的生成子由

    `ψ(t, θ) = (1/θ)(t^(−θ) − 1), θ ∈ [−1, ∞) \ {0}`。

    该生成子的反函数是形状参数为 `1/θ`、尺度参数为 `θ` 的 Gamma 分布的拉普拉斯变换，因此 Clayton copula 模型具有 *Gamma 分布的脆弱性表示* [[42]](#c08.xhtml#c08-bib-0042)。

3. *Frank* 族：首次出现于 [[20]](#c08.xhtml#c08-bib-0020)，该族的生成子由

    `ψ(t, θ) = −ln((e^(−θt) − 1)/(e^(−θ) − 1)), θ ∈ (0, ∞)`。

    在双变量情况下，它是唯一 *径向对称* 的 Archimedean 族，意味着其 copula 和生存 copula 相同。

4. *Gumbel* 族：引入自 [[24]](#c08.xhtml#c08-bib-0024)，该族的生成子由 `ψ(t, θ) = (−ln t)^θ, θ ∈ [1, ∞)` 给出。

5. *Joe* 族：讨论于 [[29](#c08.xhtml#c08-bib-0029), [30]](#c08.xhtml#c08-bib-0030)，该族的生成子由 `ψ(t, θ) = −ln(1 − (1 − t)^θ), θ ∈ [1, ∞)` 给出。
