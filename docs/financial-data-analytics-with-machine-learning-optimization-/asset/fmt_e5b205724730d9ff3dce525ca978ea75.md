
To generate samples from a random variable `x` with a density `f(x)` over its support `X_f`, we can propose a candidate density `g(x)` with a support `X_g` such that `X_f ⊆ X_g`, from which it is much easier to draw samples, that “envelopes” `f(x)`; more precisely, as long as there exists a finite constant `M > 1` such that `f(x) ≤ M g(x)` for all `x ∈ X_f`. The following algorithm explains the general procedure of the rejection sampling:

1. Generate `x_i ~ g(x)`;

2. Generate `u_i ~ U(0, 1)`, and accept `x_i` if `u_i ≤ f(x_i) / (M g(x_i))`, otherwise reject `x_i`;

3. Repeat steps 1) and 2) for `N` times, and only keep those accepted `x_i`'s as the generated sample.
