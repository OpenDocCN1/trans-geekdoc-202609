

要完成 `AV = UΣ` 的论证，我们只需分别从零空间 `N(A)` 和 `N(A^⊥)` 中再选取 `n - r` 个 `v_i` 和 `m - r` 个 `u_j` 即可。这些向量集合可以分别选为这两个零空间的标准正交基。需要注意的是，到那时，它们将分别与前 `r` 个 `v_i`（位于 `A` 的行空间中）和 `u_j`（位于 `A` 的列空间中）正交。例如，对于来自 `N(A)` 的 `v_{r+1}, ..., v_n`，其中 `i = r + 1, ..., n`，`j = 1, ..., r`，我们有

```
⟨v_i, v_j⟩ = v_i^⊥(A^⊥u_j) = (Av_i)^⊥u_j = 0,
```

根据定义。同样地，

```
σ_j⟨u_j, u_i⟩ = ⟨Av_j, u_i⟩ = v_j^⊥A^⊥u_i = v_j^⊥0 = 0.
```
