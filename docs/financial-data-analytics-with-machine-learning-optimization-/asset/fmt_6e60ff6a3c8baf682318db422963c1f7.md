
# 泊松回归模型

保险单持有人在发生受保的或然事件后，会向保险公司提交索赔申请，以补偿其财务损失。保险行业必须在指定时间内对索赔的随机到达进行建模。泊松回归通常用于对这类计数数据进行建模，假设响应变量 `y` 服从泊松分布，其风险率（或平均到达率）为 `λ`。作为广义线性模型（GLM）的代表性示例，泊松响应 `y` 属于指数分布族（EDF）；实际上，`y` 的概率质量函数（pmf）可以表示为：

```
f_y(y) = e^(-λ) * (λ^y / y!) = exp(y * ln(λ) - λ - ln(y!))
```

因此，自然参数为 `θ = ln(λ)`，尺度参数为 `φ = 1`，且 `b(θ) = e^θ`。根据公式（[10.10](#c10.xhtml#c10-disp-0029)），规范链接函数满足：

```
g^(-1)(θ) = b'(θ) = e^θ
```

由此可得：

```
λ = E(y | x = x) = exp(x^T β)
```

样本的似然函数可以表示为：

```
L(β; x_1, ..., x_n, y_1, ..., y_n) = ∏(i=1 to n) [λ_i^(y_i) * e^(-λ_i) / y_i!] = ∏(i=1 to n) [exp(y_i * x_i^T β) * exp(-e^(x_i^T β)) / y_i!]
```
