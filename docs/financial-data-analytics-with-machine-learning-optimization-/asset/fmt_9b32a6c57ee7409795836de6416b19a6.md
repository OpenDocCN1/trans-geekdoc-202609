**Lemma 4.1** Assume that `f ∈ L²[0, 1]` is a probability density function. Then,

1. `f̂(0) = 1`;

2. `|f̂(n)| < 1` whenever `n ≠ 0`; indeed, `sup_{n ≠ 0} |f̂(n)| < 1`.

*Proof.* The first claim is obvious since `∫₀¹ f(t) dt = 1`. For a fixed `n` and a continuous density `f`, we first note that for any `θ ∈ [0, 1]`:

```

```
