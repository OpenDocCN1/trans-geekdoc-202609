

对于小样本量 `n`，我们对真值 `μ` 等于 `μₙ` 的置信度相当低，具体而言，后验方差 `βₙ⁻¹` 并不太小。随着 `n` 的增加，这种置信度会提高，并且当 `n → ∞` 时最终变得确定，此时 `βₙ⁻¹ → 0`，进一步意味着对于任何 `ε > 0`，根据 *Chebyshev's inequality*，有 `P(|μ - μₙ| > ε | x = x) → 0`。这也与使用 MLE 得出的结论一致。这样，我们可以将 *Bayesian inference* 视为对 MLE 的补充。

其次，从 ([1.18](#c01.xhtml#c01-disp-0065))，后验均值 `μₙ` 确实是样本均值 `x̄ₙ` 和先验均值 `μ₀` 的加权平均，其各自的权重分别与 `nβ` 和 `β₀` 成正比：`μₙ = (nβx̄ₙ + β₀μ₀) / (nβ + β₀)` 中 `x̄ₙ` 的权重，即 `nβ / (nβ + β₀)`，在精算科学中被称为 *credibility factor*。对于任何固定的 `σ₀²`（或等价地，`β₀`），当 `n` 较大时，`μₙ` 对 `x̄ₙ` 的依赖程度始终高于对 `μ₀` 的依赖，这意味着对于足够大的样本，先验分布的选择不会显著影响 `μ` 的后验估计。

让我们用一个具体的例子来说明这一观点。我们从 `N(2, 1)` 中生成一个大小为 `n` 的随机样本，并对均值 `μ = 2` 进行 Bayesian inference，先验分布为 `N(-1, 1)`，假装我们不知道均值。[Figure 1.4](#c01.xhtml#c01-fig-0004) 展示了 `μ` 的后验分布，后验均值和方差分别用 `μₙ` 和 `σₙ²` 表示。我们可以观察到，随着 `n` 的增加，均值的后验分布逐渐远离先验分布并趋近于真值 2。
