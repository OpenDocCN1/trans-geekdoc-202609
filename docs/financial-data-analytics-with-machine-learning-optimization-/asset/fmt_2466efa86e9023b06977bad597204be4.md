
where $\xi = 1 + \exp(\boldsymbol{x}_i^\top \boldsymbol{\beta}_2) + \cdots + \exp(\boldsymbol{x}_i^\top \boldsymbol{\beta}_k)$, and the group $y = c_1$ serves as the baseline. Consider the likelihood function

(10.16)
$$
L(\boldsymbol{\beta}_2, \boldsymbol{\beta}_3, \ldots, \boldsymbol{\beta}_k \mid \boldsymbol{x}_1, \boldsymbol{x}_2, \ldots, \boldsymbol{x}_n) := \prod_{i=1}^{n} \left( \xi_i^{-1} \prod_{j=2}^{k} \exp(\boldsymbol{x}_i^\top \boldsymbol{\beta}_j)^{\mathbb{1}_{\{y_i = c_j\}}} \right)
$$

where for $j = 2, \ldots, k$,

$$
\mathbb{1}_{\{y_i = c_j\}} = 
\begin{cases} 
0, & \text{if } y_i \neq c_j; \\
1, & \text{if } y_i = c_j.
\end{cases}
$$

These $\boldsymbol{\beta}_j$'s can be estimated by maximum likelihood estimation, numerically via the Gauss–Newton algorithm similar to those in [Section 10.1](#c10.xhtml#c10-sec-0002) for binary responses. In particular, the IRLS in [Appendix 10.A.2](#c10.xhtml#c10-sec-0019) can also be extended.

In `R`, there is a built-in function `multinom()`, in the `nnet` (standing for neural network) library, which estimates the parameters in a multinomial logistic regression model. Referring to [Programme 10.16](#c10.xhtml#c10-sec-3016), this example uses Fisher's famous Iris flower dataset ![FIGURE 10.6 Photo of an Iris virginica flower; original picture from https://en.m.wikipedia.org/wiki/File:Iris\_virginica.jpg.](images/c10f006.png)

There are $28 \times 28 = 784$ feature variables with $784 \times (10 - 1) = 7,056$ coefficient weights and $10 - 1 = 9$ biases.
