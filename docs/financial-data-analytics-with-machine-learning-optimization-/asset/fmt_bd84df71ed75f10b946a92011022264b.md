
Next, for $\epsilon > 0$, define the $\epsilon$-coupling time as

$$T_\epsilon := \min \left\{ n : \|x_n - x_n'\|_2 \leq \epsilon \right\}.$$

By [Corollary 6.2](#c06.xhtml#c06-fea-0020), we can find an integer $M$ such that

$$\mu^n f(s) = \int_S f(s') \mu^{(n)}(s' | s) \, ds' > 0,$$

simultaneously for all $s \in \mathcal{S}$ and for any $f \in \mathcal{C}_b^+(\mathcal{S})$ that is not identically zero, whenever $n \geq M$. On the other hand, by the compactness of $\mathcal{S}$, we have

$$\alpha := \min_{s, s' \in \mathcal{S}} \mu^{(M)}(s' | s) > 0.$$
