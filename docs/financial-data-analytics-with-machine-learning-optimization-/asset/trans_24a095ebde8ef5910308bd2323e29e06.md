

显然，随着带宽 `h<sub>n</sub>` 的减小，估计器 `m̂(x₀)` 往往偏差较小但波动更大。因此，较大的 `h<sub>n</sub>` 更有可能产生更平滑的估计 `m̂(x₀)`，而较小的 `h<sub>n</sub>` 可能导致 `m̂(x₀)` 更具振荡性。总的来说，这种现象在统计机器学习的语境中有时被称为 `bias‐variance tradeoff`。使 `(bias)² + variance` 之和最小化的最优带宽的阶数为 `n^(-1/5)`。

或者，纳达拉亚–沃森估计器也可以使用未知密度函数 `fₓ(x)` 的核密度估计器来推导，也称为 `Rosenblatt–Parzen kernel density estimator`（参见 [\[21](#c14.xhtml#c14-bib-0021), [24\]](#c14.xhtml#c14-bib-0024)）：

[(14.12)](#c14.xhtml#R_c14-disp-0038)

```
f̂ₓ(x) = (1 / (n hₙ)) Σᵢ₌₁ⁿ K((x - xᵢ) / hₙ).
```
