

接下来，对于 $\epsilon > 0$，定义 $\epsilon$-耦合时间为

$$T_\epsilon := \min \left\{ n : \|x_n - x_n'\|_2 \leq \epsilon \right\}.$$

根据 [Corollary 6.2](#c06.xhtml#c06-fea-0020)，我们可以找到一个整数 $M$，使得

$$\mu^n f(s) = \int_S f(s') \mu^{(n)}(s' | s) \, ds' > 0,$$

对于所有 $s \in \mathcal{S}$ 以及任何不恒等于零的 $f \in \mathcal{C}_b^+(\mathcal{S})$ 均成立，只要 $n \geq M$。另一方面，由于 $\mathcal{S}$ 的紧性，我们有

$$\alpha := \min_{s, s' \in \mathcal{S}} \mu^{(M)}(s' | s) > 0.$$
