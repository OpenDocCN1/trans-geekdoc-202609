

*Proof.* 根据 [定理 6.1](#c06.xhtml#c06-fea-0004)，存在一个整数 `N`，使得对于所有 `i` 和所有 `n ≥ N`，都有 `p_{i,i}^{(n)} > 0`。考虑任意两个状态 `s_i, s_j ∈ S`。由于该链是不可约的，我们可以找到某个整数 `n_{i,j} ≥ 0`，使得 `p_{i,j}^{(n_{i,j})} > 0`。令 `M_{i,j} = N + n_{i,j}`。对于任何 `m ≥ M_{i,j}`，我们有

```
P(x_m = s_j | x_0 = s_i) ≥ P(x_{m-n_{i,j}} = s_i, x_m = s_j | x_0 = s_i)
= P(x_m = s_j | x_{m-n_{i,j}} = s_i) P(x_{m-n_{i,j}} = s_i | x_0 = s_i) > 0.
```

因此，对于所有 `m ≥ M_{i,j}`，都有 `p_{i,j}^{(m)} > 0`。该推论通过取

```
M := max{M_{1,1}, M_{1,2}, ..., M_{1,K}, M_{2,1}, ..., M_{K,K}}.
```
