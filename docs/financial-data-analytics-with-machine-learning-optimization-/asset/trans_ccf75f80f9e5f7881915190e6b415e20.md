

# 优化随机梯度下降算法

在传统的随机梯度下降（SGD）算法中，学习率是固定且统一的，用于所有参数的更新。这远非完美，尤其是对于出现频率较低的参数，其更新速度相对较慢。因此，更好的方法是考虑参数的当前值，并相应地调整学习率。大致而言，对于不常遇到的参数，其学习率应大于常遇到参数的学习率。基于此，本节将介绍三种常用的 SGD 变体。

我们首先假设 `E(w(t))` 是关于参数 `w(t) = (w₁(t), ..., wₚ(t))ᵀ` 的损失函数，在 `t` 次更新之后。对于 `i = 1, ..., p`，也记 `gᵢ(t) := ∂E/∂wᵢ(w(t))`，并令 `η` 为初始学习率。

## I. AdaGrad

自适应梯度方法（AdaGrad）通过将初始学习率 `η` 除以梯度平方和的平方根来调整学习率。从 `wᵢ(t)` 到 `wᵢ(t+1)` 的更新公式如下：

```
wᵢ(t+1) = wᵢ(t) - η / √(Σₛ₌₁ᵗ gᵢ(s)² + ε) · gᵢ(t), i = 1, 2, ..., p
```

其中 `ε` 是一个很小的数，用于避免除以零。

这种方法特别适合处理稀疏数据集，其中常遇到和不常遇到参数的更新率变得可比；确实，随着梯度项的累积，学习率会减小，到那时参数将不再更新。

## II. RMSprop

为了避免学习率消失（由截断引起）的可能性，Geoffrey Hinton 建议将公式（15.3）中历史梯度平方和替换为移动平均值 [8]。这种修正后的方法称为均方根传播（RMSprop）；它从定义时间 `t` 处梯度的二阶矩开始：

```
vᵢ(t) := γvᵢ(t-1) + (1 - γ)gᵢ(t)²
```
