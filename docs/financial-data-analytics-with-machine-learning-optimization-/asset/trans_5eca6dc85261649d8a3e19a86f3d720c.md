To minimize `L` using gradient descent, it is more reasonable to update the model parameters by using only a portion of the dataset `S` (or training set), and the corresponding method is often referred to as `mini‐batch stochastic gradient descent` (mini‐batch sgd). To explain this, we consider a more general setting: given a training set `S = {(x_i, y_i)}_{i=1}^n`, and a particular learning method parameterized by `θ ∈ R^q`, consider the loss function

```
L_n(θ) = (1/n) Σ_{i=1}^n ℓ(θ; y_i, x_i),
```

for some `ℓ: R^q × R × R^p → R`, where, for simplicity, we assume the true labels `y_i`'s are real‐valued, the feature vectors `x_i` are `p`‐dimensional, and the model parameter `θ` is `q`‐dimensional. The `i`‐th individual loss is `ℓ(θ; y_i, x_i)`, where `y_i` is the true label of `x_i`. By the `Law of Large Numbers`, the gradient of the loss function `L_n(θ)` can be approximated by:

```
∇_θ L_n(θ) = (1/n) Σ_{i=1}^n ∇_θ ℓ(θ; y_i, x_i) ≈ E[∇_θ ℓ(θ; y, x)],
```
