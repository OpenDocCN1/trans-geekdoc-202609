

一般来说，令 `X = (x1, x2, ..., xn) ∈ R^(p×n)` 为包含 `n` 个样本点的数据矩阵（为简化起见，假设均值为零），其中每个 `xi ∈ R^p`，`i = 1, 2, ..., n`。PCA 的主要目标是压缩 `X` 中的信息，使每个样本点被有效投影到 `R^k`（其中 `k < p`），同时将信息损失最小化。

令 `W = (ω1, ..., ωk) ∈ R^(p×k)` 为满足以下条件的投影矩阵：

```
∥ωi∥₂ = 1, i = 1, ..., k, and ωiᵀωj = 0 for i ≠ j.
```

此时，压缩后的数据矩阵 `Z` 形式为 `Z = WᵀX`。从该压缩数据矩阵出发，我们可以通过 `X̃ = WZ = WWᵀX` 近似恢复原始数据矩阵。现在的问题是如何确定 `W`，以使由此产生的近似误差最小化。换句话说，我们的目标是求解以下优化问题：

[(9.1)](#c09.xhtml#R_c09-disp-0012)

```
min_W ∥X - X̃∥_F = min_W ∥X - WWᵀX∥_F,
subject to WᵀW = I_k,
```
