```math
Cov(z_i, z_j) = E\left[\left(\sum_{k=1}^{n} b_{ik}(x_k - \mu)\right)\left(\sum_{l=1}^{n} b_{jl}(x_l - \mu)\right)^\top\right]
= \sum_{k=1}^{n}\sum_{l=1}^{n} b_{ik}b_{jl}E\left[(x_k - \mu)(x_l - \mu)^\top\right]
= \sum_{k=1}^{n}\sum_{l=1}^{n} b_{ik}b_{jl}(\delta_{kl}\Sigma)
= \sum_{k=1}^{n} b_{ik}b_{jk}\Sigma
= \delta_{ij}\Sigma,
```

and so `z_j ~ N_p(0, Σ)`, for `j = 1, 2, ..., n - 1`, and the `z_i`'s are mutually independent. By virtue of ([1.9](#c01.xhtml#c01-disp-0051)) and the very definition of the Wishart distribution, we can then see that `A ~ W_p(Σ, n - 1)`, and therefore `S ~ W_p(1/(n - 1) Σ, n - 1)`. The independence of `S` and `x̄` is inherited from the independence of `A` and `z_n`, also due to ([1.9](#c01.xhtml#c01-disp-0051)).
