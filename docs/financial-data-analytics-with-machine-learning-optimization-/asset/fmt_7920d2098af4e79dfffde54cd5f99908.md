
To explain the algorithm, we denote by `W(0) := W` the initial word bank, and `W(k), k = 1, 2, ...`, the shortlisted collection of words after the `k`-th guess and the color information revealed so far, also denote `n(k) := |W(k)|`. Let us now mathematically define the action of “narrowing down the range of possible words” in a recursive manner. Suppose that the `k`-th guess `ω̃(k) = (ω̃₁(k), ..., ω̃₅(k)) ∈ W(k-1)` returns the color vector `c(k) = (c₁(k), ..., c₅(k))`. Then,

(13.23)
```
W(k) = { ω = (ω₁, ..., ω₅) ∈ W(k-1) | ωⱼ = ω̃ⱼ(k) if cⱼ(k) = Green;
         Conditions (i), (ii) and (iii) are fulfilled if cⱼ(k) = Yellow;
         ∏_{l=1}^{5} (ωₗ - ω̃ⱼ(k)) ≠ 0 if cⱼ(k) = Gray for all j = 1, ..., 5 }
```
