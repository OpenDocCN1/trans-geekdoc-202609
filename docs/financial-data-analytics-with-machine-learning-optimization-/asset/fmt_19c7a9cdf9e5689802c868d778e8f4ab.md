
正如单位正方形左上角代表完美分类器一样，单位正方形的其他角也有各自的解释；参见 [Figure 10.11](#c10.xhtml#c10-fig-0011)。例如，在左下角，分类器将所有观测值识别为负；由于没有观测值被分类为正，因此 `TPR = FPR = 0`。另一方面，右上角对应另一种极端场景：相应的分类器将所有观测值识别为正；此时所有正观测值都被正确分类，而所有负观测值都被误分类，因此 `TPR = FPR = 1`。连接原点和右上角的对角线有另一个重要解释。假设我们以概率 `p` 随机将观测值分类为正，以概率 `1 - p` 分类为负。设 `n₁` 和 `n₂` 分别为患病和未患病的观测值总数。由于无论观测值为正还是负，它都会以概率 `p` 被分类为正，从 [Table 10.5](#c10.xhtml#c10-tbl-0005) 可知，当 `n₁` 和 `n₂` 都趋于无穷大时，TPR 和 FPR 的比率都趋近于 `p`。换句话说，主对角线上点 `(p, p)` 与以概率 `p` 随机将任何观测值分类为正的算法相关联。因此，如果分类算法的 ROC 曲线位于这条主对角线下方，则其性能甚至比随意的随机分类还要差。

## 10.7 Principal Component Regression

给定数据集 `S = {(xᵢ, yᵢ) : xᵢ ∈ ℝᵖ and yᵢ ∈ ℝᵠ, i = 1, ..., n}`，主成分回归（PCR，简称，又称光谱回归）在对输入协变量族 `xᵢ = (xᵢ₁, xᵢ₂, ..., xᵢₚ)` 进行降维的同时预测 `y`。使用 PCR 的一个优势是消除输入协变量集中的多重共线性，特别是当两个或多个 `xⱼ` 彼此接近共线时。通常，除了线性结构外，`y` 和协变量 `x` 之间还可以存在由以下给出的函数关系：

```
yᵢ = f(xᵢ) + εᵢ, i = 1, 2, ..., n,
```

其中 `f: ℝᵖ → ℝᵠ` 是待估计的未知函数。
