# CHAPTER 7  

时间变化波动率矩阵与凯利比例

波动率和相关性是定量金融、金融统计和风险管理中的基本概念。它们作为预测股票价格风险趋势、定价期权和衍生品、计算投资组合的风险价值（V@R）、确定 CAPM 中的贝塔系数等方面的参数。在本章中，首先我们解释如何使用历史证券价格数据来估计波动率和相关性。特别是，我们考虑一些常见的模型，如 `exponentially weighted moving average` (EWMA)、`autoregressive conditional heteroscedasticity` (ARCH) [11](#c07.xhtml#c07-bib-0010) 和 `generalized ARCH` (GARCH) [3](#c07.xhtml#c07-bib-0002)。这些模型的有效性将通过真实金融数据来说明。这些模型的一个重要特征是，波动率和相关性不是恒定的，而是随时间快速变化。允许这种变化的模型比假设波动率恒定的模型（如著名的 Black–Scholes–Merton 模型 [2](#c07.xhtml#c07-bib-0001））更接近现实。在本章的第二部分，我们将介绍作者的一些原创研究结果，这些结果涉及在规划期限内以有利时机出售（或购买）股票时可能使用 `Kelly fraction`。还将讨论其对表面日历效应的影响。在开始这段旅程之前，让我们先介绍一些相关技术概念的符号和定义。

## 7.1 波动率的波动

在证券价格的经典 Black–Scholes–Merton 模型下，股票价格在短时间内的百分比变化被假设为正态分布，即

```
δSₜ/Sₜ ~ N(μδt, σ²δt),
```

其中 `δSₜ := Sₜ₊δₜ − Sₜ` 是股票价格 `Sₜ` 在 `[t, t + δₜ]` 期间的变化，`μδt` 是平均百分比变化，`σ√δt` 是该百分比变化的标准差。要将此模型应用于实际数据，请定义股票的第 `i` 个每日百分比变化为

```
uᵢ := (Sᵢ − Sᵢ₋₁)/Sᵢ₋₁ ~ N(μτ, σ²τ), i = 1, ..., n,
```
