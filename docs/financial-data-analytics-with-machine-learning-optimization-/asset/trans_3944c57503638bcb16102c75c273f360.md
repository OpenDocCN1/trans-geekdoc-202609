

# 11.A.1.1 梯度下降法

在机器学习中，人们通常通过选择最优参数值来最小化某个损失函数，从而获得所需的模型，该损失函数通常表现为大量个体损失的总和或平均值。梯度下降法及其随机版本（称为随机梯度下降，SGD）是搜索局部最小值时最常用的两种迭代优化算法。我们将在本附录中简要讨论这些算法，而有关更详细的讨论，请参阅我们的另一篇论文 [[8](#c11.xhtml#c11-bib-0008)]，以及其他教材，如 [[14](#c11.xhtml#c11-bib-0014), [17](#c11.xhtml#c11-bib-0017), [22](#c11.xhtml#c11-bib-0024)]。梯度下降算法的一般步骤如下：

1. 从随机种子开始；然后
2. 按当前点处损失函数梯度负值的比例修改当前参数估计值。

要最小化的损失函数通常可能具有多个局部最小值。尤其是在训练各种深度神经网络时，情况尤其如此。因此，初始猜测的选择对于寻找和定位最终局部最小值至关重要。

在梯度下降算法的第 2 步中，梯度的负值指向下一个猜测的方向，而修改的步长将由超参数 `η` 决定，称为学习率。对于学习率 `η` 和损失函数 `L(θ): R^q → R`（关于参数 `θ ∈ Θ ⊂ R^q`），梯度下降法更新 `θ` 的值如下：

(11.16)
Step Size (Signed) = η · ∇_θ L(θ);
Next Move = Last Move - Step Size.

数学上，我们有

(11.17)
θ^(t+1) = θ^(t) - η · ∇_θ L(θ)|_{θ=θ^(t)}.

如果学习率 `η` 设置得太大，通常无法达到目标附近的最优点，因为它可能会跳到远离初始种子的点（参见 [图 11.14](#c11.xhtml#c11-fig-0014)a）。另一方面，如果学习率设置得太小，则需要更多的迭代才能达到最优点（参见 [图 11.14](#c11.xhtml#c11-fig-0014)b）。在实践中，通常使用学习率 `η = 0.001`。一般来说，采用一个趋于零的学习率序列 `{η_t}` 更可取。文献中提出了几种技术，说明如何动态调整这些学习率以获得最佳结果。为简单起见，我们在其余讨论中采用常数学习率。
