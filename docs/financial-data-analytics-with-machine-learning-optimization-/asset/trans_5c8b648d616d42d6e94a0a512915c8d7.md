### 13.8.1 医疗保险示例

我们现在考虑另一个示例，目标是根据客户的两个特征变量（即其 `Age` 和 `Weight`）来预测医疗保险公司收取的 `Premium Price`。

![FIGURE 13.15 A regression tree for the medical premium data via Python, generated in Programme 13.15.](images/c13f015.png)

[**FIGURE 13.15**](#c13.xhtml#R_c13-fig-0015) A regression tree for the medical premium data via Python, generated in [Programme 13.15](#c13.xhtml#c13-sec-3015).

![FIGURE 13.16 A regression tree for the medical premium data via R, generated in Programme 13.16.](images/c13f016.png)

[**FIGURE 13.16**](#c13.xhtml#R_c13-fig-0016) A regression tree for the medical premium data via `R`, generated in [Programme 13.16](#c13.xhtml#c13-sec-3016).

比较 [图 13.15](#c13.xhtml#c13-fig-0015) 和 [13.16](#c13.xhtml#c13-fig-0016) 中的结果，分别来自通过 Python 的程序 13.15 和通过 `R` 的程序 13.16，Python 中的 `sklearn` 和 `R` 中的 `rpart` 找到的决策规则略有不同，因为它们对分割标准的选择不同，其中 `sklearn` 选择最小化平方误差的分割，而 `rpart` 选择最大化 ANOVA 中组间平方和的分割。基于这两个回归树模型，我们获得以下解释：

1. `Age` 是确定客户 `Premium Price` 的最相关因素。年龄低于 29.5 岁的客户通常会被收取较低的保费。年龄在 29.5 至 46.5 岁之间的客户会被收取中等保费，而年龄超过 46.5 岁的客户会被收取较高的保费。

2. 鉴于客户年龄低于 29.5 岁或介于 29.5 至 46.5 岁之间，其 `Weight` 几乎对所收取的保费不起作用。

3. 鉴于客户年龄超过 46.5 岁，其体重将影响其 `Premium Price`。体重超过 94.5 kg 的客户会被收取较高的保费。
