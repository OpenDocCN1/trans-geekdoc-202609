
# 主要内容

如果我们简单地使用训练数据集中比特币价格的平均值来预测测试数据集中的价格，则外部样本预测的均方误差（MSE）为 19.722。相比之下，当我们采用如 [Figure 15.21](#c15.xhtml#c15-fig-0021) 所示架构的 6-8-8-1 LSTM 模型时，MSE 降低至 19.171，表明 LSTM 模型相比于简单常数值能够实现更好的预测性能，甚至略微优于使用 Python 拟合的 ARIMA(2,1,3) 模型（MSE 为 19.249）以及使用 **R** 拟合的 ARIMA(2,1,2) 模型（MSE 为 19.261）。另一方面，基于训练数据集中比特币价格平均值的内部样本预测 MSE 为 25.927。当我们评估 LSTM 模型的内部样本预测时，MSE 降低至 25.491，这与相应的外部样本预测具有相似的降低幅度。因此，通过在第二个 LSTM 层应用 dropout，可以提升该网络的表达能力。为了可视化测试数据集随时间变化的价格预测，以下 [Programme 15.21](#c15.xhtml#c15-sec-3021)（通过 Python）绘制了在 [Figure 15.22](#c15.xhtml#c15-fig-0022) 中获得的预测结果，该结果来自在 [Programme 15.20](#c15.xhtml#c15-sec-3020)（通过 Python）中拟合的 LSTM 模型。

作为结束语，该示例表明在存在 dropout 时性能最佳，且没有 dropout 层的 LSTM 模型可能并不总是适用于预测任务，因为存在过拟合的潜在风险。尽管如此，它们在检测 *market anomalies* 或捕捉金融数值数据中的异常模式方面仍然有效，这涉及从当前回溯到过去的长时间序列中所包含的更复杂信息。这种可能的成功通常依赖于采用有效且稳健的特征提取程序，例如 *theory of rough paths* 中的签名方法；有关更多讨论，请参见 [\[16](#c15.xhtml#c15-bib-0016), [17](#c15.xhtml#c15-bib-0017), [19\]](#c15.xhtml#c15-bib-0019)，我们可能在未来的书籍 [\[3\]](#c15.xhtml#c15-bib-0003) 中进一步探讨。
