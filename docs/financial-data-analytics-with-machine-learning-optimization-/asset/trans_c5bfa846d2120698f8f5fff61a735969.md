

考虑一个投资组合，其中财富的固定比例 `ω` 投资于股票，剩余部分 `1 - ω` 投资于债券。设 `{X_t}` 为时刻 `t` 的财富过程。那么，时刻 `t` 购买的股票数量为 `ω X_t / S_t`，而购买的债券单位数为 `(1 - ω) X_t / B_t`。根据 ([7.29](#c07.xhtml#c07-disp-0049)) 和 ([7.32](#c07.xhtml#c07-disp-0053))，财富过程 `{X_t}` 满足动态 `dX_t = (ω X_t / S_t) dS_t + ((1 - ω) X_t / B_t) dB_t`。因此 `{X_t}` 满足以下随机微分方程（SDE）：

```
dX_t / X_t = ω dS_t / S_t + (1 - ω) dB_t / B_t = (ω μ + (1 - ω) r) dt + ω σ dw_t
```

给定初始财富 `X_0`，其解为：

```
X_t = X_0 exp((ω μ + (1 - ω) r - ω²σ² / 2) t + ω σ w_t)
```

因此，投资组合财富的（一期）对数收益率期望等于：

```
E(ln X_t - ln X_0) = (ω μ + (1 - ω) r - ω²σ² / 2) t
```
