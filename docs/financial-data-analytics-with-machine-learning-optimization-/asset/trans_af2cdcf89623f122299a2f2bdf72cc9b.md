## 4.3 商业报告中的本福德定律

近年来，将本福德定律作为一种欺诈检测方法的使用越来越普遍，其动机是监管机构可用于检查的数据量不断增加，需要自动化的欺诈检测方法来有效扫描这些数据。这一点尤为重要，因为监管机构的调查往往非常昂贵，无论是时间还是金钱，而且计算机辅助检查能够拨开迷雾，让监管机构只需关注最可疑的交易，这更为有利。因此，本福德定律可以作为一种非常有用的经验定律，用于筛查数据中可能存在的任何异常。如果检测到异常，可能并非由于欺诈活动，而会启动更全面的调查以查明其原因。在最早的研究中，有人提出利用首位数字频率和本福德定律作为欺诈检测的基准，即 [\[49\]](#c04.xhtml#c04-bib-0049)，其中作者指出，社会经济或财务数据往往是通过人工干预，为了支持关键政策规划而带有偏见地起草的。他进一步指出，创造虚构数据的一种常见方式是由于人类对自然对称性的直觉和偏见，导致涉及的数字分布均匀。相比之下，大多数现实的社会经济或财务数据在不同计量单位下都遵循尺度不变性，这最终导致数字近似遵循本福德定律。西弗吉尼亚大学的学者 *Mark J. Nigrini* 将利用本福德定律进行会计欺诈检测的方法命名为“数字分析”，这是“法务审计”中的一种特殊定量方法。特别是，他描述道：

> “*本福德定律为审计师提供了表格数据中预期的数字频率。通过检查数字和数字频率，审计师可以获得使用传统分析程序和抽样方法可能遗漏的数据洞察。数字和数字模式可能指向数字捏造、系统性欺诈、数据错误或数据中的偏差。目前正在开展先进测试的研究，以检测数据子集中的异常。*”
