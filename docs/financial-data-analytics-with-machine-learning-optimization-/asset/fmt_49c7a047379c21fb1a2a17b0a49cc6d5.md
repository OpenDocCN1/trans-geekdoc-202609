
在[Programme 11.8](#c11.xhtml#c11-sec-3008)中，通过`R`语言，`outer()`函数接受三个主要参数：(i) 第一个输入数组（向量）`x` ∈ `R^Q`，作为`X`；(ii) 第二个输入数组（向量）`y` ∈ `R^K`，作为`Y`；以及(iii) 要在`outer()`中作为`FUN`采用的函数`f: R × R → R`。该函数的输出是一个二维网格矩阵`O = (o_ij)` ∈ `R^(Q×K)`，其元素为`o_ij = f(x_i, y_j)`，其中`i = 1, ..., Q`，`j = 1, ..., K`。

另一方面，同样在**R**中，`solve.QP()`函数旨在求解以下形式的二次规划（QP）问题：

```
minimize 1/2 x^T P x - q^T x
subject to G x ≥ h
```

其中，前`meq`个约束被视为等式约束，即`G_1 x = h_1, ..., G_meq x = h_meq`；而其余约束被视为不等式约束，即`G_(meq+1) x ≥ h_(meq+1), ..., G_K x ≥ h_K`。

## 11.A.2.2 Minimax Theorem and Duality

在本小节中，我们首先回顾著名的*von Neumann's Minimax theorem*（冯·诺伊曼极小极大定理），并从中推导关于约束最小化问题对偶性的一般结果。这些结果将在下一小节中应用于求解二次规划问题的特殊情况。读者也可以参考凸分析方面的教材以获取更多讨论，例如[\[2](#c11.xhtml#c11-bib-0002), [4\]](#c11.xhtml#c11-bib-0004)。
