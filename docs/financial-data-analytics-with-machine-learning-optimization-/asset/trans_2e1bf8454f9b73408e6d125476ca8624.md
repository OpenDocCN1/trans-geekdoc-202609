

求解系统 ([9.8](#c09.xhtml#c09-disp-0038)) 时，企业需要获取其自身各业务线相对于所有这些 `N` 种基础资产的绩效数据，以及市场上其他公开交易证券的相应灵敏度。原则上，对于前者，企业可以利用从自身财务报表数据中提取的内部业务信息来确定这些系数。因此，获取 `P_t` 的所有信息相对容易，`P_t` 具体是指我们的投资组合 `Π_t` 对每个单独基础资产 `r_t^k`（`k = 1, …, N`）的价值的灵敏度。例如，从现金流角度考虑一个简单的情况，令 `r_τ^k` 为在时间 `τ` 对第 `k` 种资产进行投资的平均年回报率，现金流为 `c_τ^k`，并假设该资产在到期日 `T` 之前不可交易。那么，所有 `N` 种资产组合在时间 `t` 的现值由 `Π_t = (1 + r_f)^(T - t) Σ(k=1 to N) Σ(τ=t to T) c_τ^k (1 + r_τ^k)^(T - τ)` 给出，其中 `r_f` 是确定性的无风险利率。事实上，这种情形在现实中并不罕见；例如，考虑购买政府债券。另一个例子是公共基础设施的建设，在建设阶段每年都需要注入资金，而利润要在几年后设施投入使用并开始产生收入时才能实现。在这种情况下，可以很容易地计算灵敏度为 `∂Π_t / ∂r_t^k = (1 + r_f)^(T - t) c_t^k (T - t) (1 + r_t^k)^(T - t - 1)`，其中 `k = 1, …, N`。在实际操作中，尽管 `Π_t` 的形式可能更复杂，投资者应当对自身项目有相当透彻的了解，从而合理了解投资组合对基础资产依赖的函数形式，如上述所示。到那时，他们就可以轻松估计相对于任何自变量的灵敏度。
