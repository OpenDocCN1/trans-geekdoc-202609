请注意，对于任何可行解 (ω, b)，我们总能找到一个与原超平面平行且参数为 (ω, b′) 的替代分离超平面，且该超平面位于两组数据的中间。简单的几何告诉我们，该替代分离超平面对应的几何间隔大于原可行超平面的几何间隔。最后，正如脚注所指出的，分离超平面的定义在参数向量重新缩放下保持不变，我们可以假设对所有 i = 1, 2, …, n 都有 yᵢ(xᵢᵀω + b) ≥ 1，这样对于最接近分离超平面的两个点取等号，因此 γ = 1 / ‖ω‖₂。现在，问题 [11.7](#c11.xhtml#c11-disp-0015) 可转换为：
