

虽然在没有关于 `x` 的额外知识时，无条件熵可能有用，但在实践中，更常见的情况是我们通常从其他源变量中事先掌握了一些更多的知识。直觉上，我们期望随着这种额外知识的增加，随机性的水平会降低，熵也随之降低。例如，在语言模型中“预测”下一段文本的出现，一旦已知当前单词，下一个单词的可能范围就会大大缩小。这一概念可以形式化如下。让我们考虑最简单的情况，只有一对离散随机变量 `(x, y)`，其联合概率质量函数为 `P(x = x, y = y) = p(x, y)`，其中 `x ∈ X` 且 `y ∈ Y`。我们想要考察了解关于 `x` 的某些知识如何影响 `y` 的随机性，进而改变 `y` 的熵。使用条件概率的概念 `p(y | x) = P(y = y | x = x)`，我们定义给定 `x` 时 `y` 的 `条件熵` 为：

```
H(y | x) := -∑_{x ∈ X} ∑_{y ∈ Y} p(x, y) log₂ p(y | x).
```

在特殊情况下，当 `y` 完全由 `x` 决定时，即对于某个已知函数 `f`，`y = f(x)`，`p(y | x)` 在 `y = f(x)` 时取值为 1；否则取值为 0。因此，`H(y | x) = -∑_{x ∈ X} ∑_{y = f(x)} p(x, y) log₂ p(y | x) = -∑_{x ∈ X} 0 = 0`。另一方面，从 `H(y | x)` 的定义出发，我们可以用条件概率 `p(y | x)` 表示 `p(x, y)`，然后交换求和顺序以得到：
