

回顾，分类树对特征向量空间 `D` 划分为 `D₁, ..., Dₘ`，对应预测标签 `c₁, ..., cₘ`。这进而诱导数据集 `S` 划分为 `S₁, ..., Sₘ`，其中 `Sₖ = {(x, y) ∈ S : x ∈ Dₖ}`。一般而言，对于给定样本 `S = {(xᵢ, yᵢ)}ᵢ₌₁ⁿ`，我们旨在构建一棵分类树 `T`，其终端叶节点数记为 `T`（参见 [图 13.5](#c13.xhtml#c13-fig-0005) 以作说明），以最小化分类误差：

[(13.14)](#c13.xhtml#R_c13-disp-0046)

```
R(T) := (1/n) Σₗ₌₁ᵀ Σ₍xᵢ,yᵢ₎∈Tₗ 1{yᵢ ≠ ȳ_Tₗ},
```

其中 `Tₗ` 为第 `l` 个终端节点上的数据点集合，`l = 1, ..., T`，而 `ȳ_Tₗ` 是使用 `Tₗ` 中所有数据点对特定标签进行的多数投票：

(13.15)

```
ȳ_Tₗ := arg max_{c∈Y} Σ₍xᵢ,yᵢ₎∈Tₗ 1{yᵢ = c},
```
