

我们可以继续寻找第二个主成分 `y₂ = h₁₂x₁ + ... + hₚ₂xₚ = h₂ᵀx`，其中 `h₂ = (h₁₂, ..., hₚ₂)ᵀ`，使得其方差 `Var(y₂) = h₂ᵀSₕ₂` 在以下条件下最大化：(i) `h₂ᵀh₂ = 1`；以及 (ii) `h₂ᵀh₁ = 0`。后一个条件意味着 `h₁` 和 `h₂` 互相 *正交*（或者等价地，`y₁` 和 `y₂` 在统计上不相关）。

第三个主成分可以以类似的方式找到，该过程可以一直持续到最后第 `p` 个主成分。这给出了 PCA 的基本思想，且优化过程通过线性代数有一个优美的解。特别是，这些载荷实际上是相关矩阵或 `x` 的方差-协方差矩阵中，第 `j` 个主成分的 *归一化特征向量*，记为 `hⱼ = (h₁ⱼ, ..., hₚⱼ)ᵀ`，其中 `j = 1, 2, ..., p`，而第 `j` 个主成分 `yⱼ` 的方差是相应的 *特征值* `λⱼ = Var(yⱼ) = hⱼᵀSₕⱼ`。这一论点在 [附录 9.A.1](#c09.xhtml#c09-sec-0017) 中详细讨论，而读者可以参考 [第 1 章](#c01.xhtml) 的 [第 1.2 节](#c01.xhtml#c01-sec-0007) 以了解谱分解的基本理论。

最大化转换变量 `yⱼ` 方差的原因是，我们希望尽可能多地保留 `x₁, ..., xₚ` 中的信息。从概念上讲，变异代表信息，因此我们希望线性转换变量的方差尽可能大，并且“尽可能早”地实现，以便保留 `x` 中的原始信息。第 `j` 个特征值 `λⱼ = Var(yⱼ)` 表示在第 `j` 个主成分中保留的信息量。
