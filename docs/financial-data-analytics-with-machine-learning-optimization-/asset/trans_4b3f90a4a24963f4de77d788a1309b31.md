

这里，我们简要描述了在 `K`‐NN 中核方法的实现。设变换为 `Φ: R^p → R^q`，使得样本 `{x_1, ..., x_n}` 映射为 `{Φ(x_1), ..., Φ(x_n)}`。设 `K(·, ·)` 为核函数，则对于任意 `x_i` 和 `x_j`，其定义方式如下：

```
d(Φ(x_i), Φ(x_j)) = K(x_i, x_j),
```

其中 `d(·, ·)` 是定义在 `R^q` 上的距离函数。如我们在 [第 11.2 节](#c11.xhtml#c11-sec-0003) 中介绍的那样，核 `K(·, ·)` 通常是直接提出的，而不是变换 `Φ`。可以证明，在此框架下的 `K`‐NN 实现能大大提升性能，尤其是在特征不可线性分离的低维环境中。

## 预聚类

在实现 `K`‐NN 算法之前，可以先对样本进行聚类（例如，通过 `K`‐means）；参见 [\[26\]](#c14.xhtml#c14-bib-0026)。大致来说，给定一个已聚类的样本和一个新观测值 `x`，我们先计算其到每个聚类中心的距离，并相应地将 `S(i)` 表示为第 `i` 近的聚类。考虑到这些聚类，`K` 个最近邻可以按如下方式选取：计算新加入的观测值 `x` 与 `S(1)` 中每个点之间的距离，并逐一将距离 `x` 小于预设阈值的点按距离升序纳入 `x` 的邻域点集合。对 `i = 2, 3, ...` 重复此过程，直到 `x` 的邻域点集合中包含 `K` 个点。然后 `x` 获得其预测标签 `i_0`，使得 `S(i_0)` 在该 `K` 个点的列表中拥有最多的元素。
