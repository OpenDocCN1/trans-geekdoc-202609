
Suppose that we sort `n` financial observations `x1, ..., xn` in descending order, and there are `nu` observations greater than `u`. Assume that the previous theorem of *Gnedenko–Pickands–Balkema–de Haan* (“*Gnedenko's theorem*” in short hereafter) is applicable to the underlying distribution of this sample, then for a large enough `u`, we can estimate `P(x > u + y | x > u)` by `1 - Gξ,β(y)`, and `1 - F(u)` by `nu / n`. As a result, the unconditional probability is approximately given by

```
P(x > u + y) ≈ (1 - F(u))(1 - Gξ,β(y)) = (nu / n)(1 + ξ(y / β))^(-1 / ξ), for all y > 0,
```

which implies that for large `x > u`,

```
P(x > x) ≈ (nu / n)(1 + ξ((x - u) / β))^(-1 / ξ),
```

and so

[(8.2)](#c08.xhtml#R_c08-disp-0019) `P(x ≤ x) ≈ 1 - (nu / n)(1 + ξ((x - u) / β))^(-1 / ξ).`

In particular, if we take `u = β / ξ`, then `P(x > x) ≈ (nu / n)(ξ / β)^(-1 / ξ) x^(-1 / ξ)`, which satisfies the usual Power Law.
