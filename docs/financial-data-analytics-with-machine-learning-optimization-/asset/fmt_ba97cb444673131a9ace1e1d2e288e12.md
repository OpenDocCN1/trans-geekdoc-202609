
4. **Fisher's F-distribution:** If \(x \sim \chi^2_u\) and \(y \sim \chi^2_v\) are independent, then \(\frac{x/u}{y/v} \sim F_{u,v}\), an \(F\)-distribution with parameters \(u\) and \(v\) in order. Furthermore, if \(x_1, \dots, x_m\) are iid \(N(\mu_1, \sigma_1^2)\) and are independent of \(y_1, \dots, y_n\) being iid \(N(\mu_2, \sigma_2^2)\), then \(\frac{s_x^2 / \sigma_1^2}{s_y^2 / \sigma_2^2} = \frac{s_x^2 \sigma_2^2}{\sigma_1^2 s_y^2} \sim F_{m-1,n-1}\); indeed, since \(\frac{(m-1)s_x^2}{\sigma_1^2} \sim \chi^2_{m-1}\) and \(\frac{(n-1)s_y^2}{\sigma_2^2} \sim \chi^2_{n-1}\) are independent,

\[
\frac{s_x^2 / \sigma_1^2}{s_y^2 / \sigma_2^2} = \frac{s_x^2 \sigma_2^2}{\sigma_1^2 s_y^2} \sim F_{m-1,n-1}.
\]

In particular, if \(t \sim t_\nu\), then \(t^2 \sim F_{1,\nu}\).
