我们的目标是找到参数 $\omega$、$\alpha$、$\beta$，使得函数

[(7.16)](#c07.xhtml#R_c07-disp-0021) $l(\omega, \alpha, \beta; \boldsymbol{u}) = \sum_{i=1}^{n}\left(-\ln(\nu_i) - \frac{u_i^2}{\nu_i}\right)$

取得最大值。请注意，参数是通过 $\nu_i$ 隐式地进入函数 ([7.16](#c07.xhtml#c07-disp-0021)) 的，而 $\nu_i$ 满足递推关系 ([7.13](#c07.xhtml#c07-disp-0018))，因此这是一个相当复杂的极值问题。让我们用 HSBC 股票数据进行数值说明，使用 $u_i = \frac{S_i - S_{i-1}}{S_{i-1}}$（即股票价格的百分比变化）来拟合 GARCH(1, 1) 模型并获得 $\omega$、$\alpha$、$\beta$ 的相应极大似然估计；有关 Python 和 `R` 代码，请参见 [程序 7.15](#c07.xhtml#c07-gra-00015) 和 [7.16](#c07.xhtml#c07-gra-00016)。
