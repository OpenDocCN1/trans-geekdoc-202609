5. Let `x₁, ..., xₙ` be iid `Nₚ(μ, Σ)` random vectors. Then the squared generalized distance (a.k.a. the `Mahalanobis distance`) `dᵢ² = (xᵢ − x̄)ᵀS⁻¹(xᵢ − x̄) ~ χ²ₚ` approximately for a large value of `n` (relative to `p`). This is a direct consequence of an application of `Slutsky's theorem` by replacing `μ` by `x̄` and `Σ` by `S` in Property 4 above.
