

为了确定 `x₁` 和 `x₂` 之间依赖关系的强度，我们计划为它们可能取的特征值分配数值，然后计算关联度量。由于该数据集的特性，即大量重复观测 `(s₁ᵢ, s₂ⱼ)`，Pearson's `r̂` 比其他度量更合适。此外，它也是一种有用的关联度量，对编码的任何仿射变换具有不变性。我们首先考虑 `x₁` 和 `x₂` 的任意编码方案，即，对于 `x₁` 的值，我们将 `s₁ᵢ` 编码为 `i`，其中 `i = 1, 2, 3`；而对于 `x₂` 的值，我们将 `s₂ⱼ` 编码为 `j`，其中 `j = 1, 2`。在这种编码方案下，我们有

```
x̄₁ = (1 × 240 + 2 × 300 + 3 × 180) / 720 = 1.91667 and x̄₂ = (1 × 320 + 2 × 400) / 720 = 1.55556,
```

**TABLE 12.1** 包含两个分类特征变量 `x₁` 和 `x₂` 的样本数据集的列联表。

yielding

```
∑ᵢ₌₁⁷²⁰ (x₁ᵢ − x̄₁)(x₂ᵢ − x̄₂) = −16.66667,
∑ᵢ₌₁⁷²⁰ (x₁ᵢ − x̄₁)² = 415, ∑ᵢ₌₁⁷²⁰ (x₂ᵢ − x̄₂)² = 177.77778.
```

我们计算经验 Pearson's `r̂` 如下：

```
r̂ = −16.66667 / √(415 × 177.77778) = −0.06136,
```

这与 0 非常接近，因此没有暗示 `x₁` 和 `x₂` 之间存在可能的（线性）关系。
