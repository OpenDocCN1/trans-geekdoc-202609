
Note that the error `S(β)` may not be decreasing for every iteration in the Gauss–Newton algorithm but could be oscillating instead. Yet for any sufficiently small `λ > 0`, it always holds that `S(β^(k) + λΔ) < S(β^(k))` in the neighbourhood of a minimum point of `S`, for `Δ̂ = β^(k+1) − β^(k)`. Thus the modified version of the Gauss–Newton algorithm incorporates a small enough factor `λ` (learning rate) in each consecutive update. For each iteration, to choose a suitable `λ ∈ (0, 1)` which minimizes the error `S(β^(k) + λΔ̂)`, we can simply apply some popular search algorithms such as the *golden‐section search method*
