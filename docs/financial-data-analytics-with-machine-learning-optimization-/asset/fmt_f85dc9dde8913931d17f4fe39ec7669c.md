
# Power Law

In modelling empirical data, one useful law is the *Power Law*, first properly proposed by *Vilfredo Pareto* in 1897 [\[37\]](#c08.xhtml#c08-bib-0037). This law is said to hold if the survival function of a random variable `y` is proportional to a power function: `P(y > x) ∝ x^(-α)` for some `α > 0`; it also provides a good model for estimating the tail probability of rare events. Let `F` be the cdf of a random variable `x`, i.e., `P(x ≤ u) = F(u)`, then given `x > u`, the conditional probability of `u < x ≤ u + y` is

```
F_u(y) := P(x - u ≤ y | x > u) = (F(u + y) - F(u)) / (1 - F(u)).
```

It has been shown ([\[4](#c08.xhtml#c08-bib-0004), [23](#c08.xhtml#c08-bib-0023), [38](#c08.xhtml#c08-bib-0038)]) that for a large class of distributions `F`, `F_u(y) → G_{ξ,β}(y)` uniformly in `y > 0` as `u → ∞`, where

```
G_{ξ,β}(y) = { 1 - (1 + ξy/β)^(-1/ξ), ξ ≠ 0
             { 1 - exp(-y/β),       ξ = 0
```

and is called the *generalized Pareto distribution* with a shape parameter `ξ` and a scale parameter `β > 0`, in which `y ≥ 0` when `ξ ≥ 0`, or `0 ≤ y ≤ -β/ξ` when `ξ < 0`. For common financial data, `ξ > 0` and it falls in the range from 0.1 to 0.4, see [\[27\]](#c08.xhtml#c08-bib-0027) for details. For more introduction to extreme value theory (EVT), we refer to [\[25](#c08.xhtml#c08-bib-0025), [40](#c08.xhtml#c08-bib-0040)].
