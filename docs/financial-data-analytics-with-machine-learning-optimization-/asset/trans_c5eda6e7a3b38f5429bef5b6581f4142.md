

通常在统计语境中，马尔可夫链的状态空间 `S` 是不可数的，例如 `S = R^p`。隐含假设 `S` 配备了合适的拓扑和适当的 `σ`-域，以及后者上的一个测度。在 `S = R^p` 的情况下，这些分别对应于*博雷尔集*的拓扑、定义有*勒贝格测度*的*博雷尔* `σ`-域。当状态空间不可数时，转移概率无法用矩阵形式表示。相反，可以通过使用*转移算子* `T_n: B_b(S) → B_b(S)` 来表述马尔可夫性质，该算子定义为

```
T_n f(s) := E[f(x_{n+1}) | x_n = s], for any f ∈ B_b(S), s ∈ S,
```

其中 `B_b(S)` 表示定义在 `S` 上的所有有界连续实值函数的集合。在不深入不必要的技术细节的情况下，我们隐含假设从 `x_n` 到 `x_{n+1}` 的对 `(x_n, x_{n+1})` 的转移密度（给定 `x_n` 的条件概率）具有足够的正则性。借助转移算子，*马尔可夫性质*可以表述为

```
P(x_{n+1} ∈ A_{n+1} | x_n = s, x_{n-1} ∈ A_{n-1}, ..., x_1 ∈ A_1) = T_n 1_{A_{n+1}}(s),
```
