## *14.3 KERNEL REGRESSION

虽然 `K`‐means 聚类主要关注将可区分的簇分开，但对于新数据点的标签预测仍存在难题，这是聚类分析的最终目标。这就是 `K`‐NN 回归在上一节中所做的工作。`K`‐NN 回归的一个明显缺点是缺乏选择 `K` 的明确指导方针。一种常用的替代方法是考虑所有数据点，对应于 `K = ∞` 的情况。鉴于此，我们将重新审视功能回归分析中核回归这一多功能工具，其中我们研究一种称为 `Nadaraya–Watson estimator` 的特定回归器的特例（参见 [19, 27]），它类似于 `K = ∞` 时 `K`‐NN 回归的公式。这大大丰富了 `K`‐NN 的内容及其实际应用。

请回顾，回归分析的基本任务是使用特征向量 `x ∈ R^p` 预测响应向量 `y ∈ R^q`。在此场景中，一个关键的感兴趣量是条件均值 `E(y | x = x)`。为了简单起见，在本节中我们仅讨论 `p = q = 1` 的最简单情况的渐近理论，而一般情况的论证基本相同，但涉及更繁琐的符号。一般回归框架采用以下形式：

```
y = m(x) + ε,
```
