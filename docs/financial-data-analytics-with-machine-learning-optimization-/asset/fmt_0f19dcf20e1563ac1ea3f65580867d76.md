
# 信息增益示例

作为说明信息增益概念的示例，我们考虑一个样本大小为 15 的节点，`S^(1) = {(x_i^(1) = R, x_i^(2) = S, y_i ∈ {N, Y}) | i = 1..15}`，来自信用违约数据集，其中 9 个未违约（N），其余 6 个违约（Y）。属性 `x^(1)` 指的是“风险等级”（R），可以是“高风险”（H）或“低风险”（L）。第二个属性 `x^(2)` 是“性别”（S），可以是“女性”（F）或“男性”（M）。在 15 个样本点中，来自 Class N 的 6 个样本点和来自 Class Y 的 3 个样本点具有属性 `x^(1) = L`，其余样本点属于高风险等级类别，即 `x^(1) = H`；另一方面，来自 Class N 的 5 个样本点和来自 Class Y 的 4 个样本点具有属性 `x^(2) = F`，其余样本点属于男性类别，即 `x^(2) = M`；有关 15 个样本的标签和属性，请参见 [表 13.1](#c13.xhtml#c13-tbl-0001)。
