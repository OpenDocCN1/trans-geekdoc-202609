

## 引理 6.1 的证明

令 $\widetilde{\mathcal{A}}$ 为所有形式为 $c_1 a_1 + \cdots + c_n a_n$ 的有限线性组合的集合，其中 $a_i \in \mathcal{A}$，系数 $c_i \in \mathbb{Z}$，且令 $m^* = c_1^* a_1^* + \cdots + c_n^* a_n^*$ 为 $\widetilde{\mathcal{A}}$ 中最小的可能正元素。若 $m^* > 1$，则由于 $\mathcal{A}$ 不是格，必然存在至少一个元素（记为 $\tilde{a}$）属于 $\mathcal{A}$ 且不能被 $m^*$ 整除。在这种情况下，$\tilde{a}$ 除以 $m^*$ 的余数仍然是 $a_1^*, \ldots, a_n^*$ 与 $\tilde{a}$ 的线性组合，且仍为 $\tilde{A}$ 中的正元素，但它小于 $m^*$，这与 $m^*$ 的最小性矛盾。因此，$m^* = 1$。现在，我们定义 $M := |c_1^*| a_1^* + \cdots + |c_n^*| a_n^*$，并取 $N := M^2$。对于任意 $n \geqslant N$，我们写 $n = qM + r$，其中商 $q \geqslant M$，余数 $0 \leqslant r < M$。则

$$
n = qM + r = qM + r m^* = \sum_{i=1}^{n} \left( q |c_i^*| + r c_i^* \right) a_i^*.
$$
