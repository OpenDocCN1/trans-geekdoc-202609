
Unlike PCA where the basic elements have to be mutually orthogonal, this is not a must for atoms; in fact, dictionary matrices are usually of a larger size than the data matrix we want to represent. To examine a new image, it suffices for us to only call up the dictionary along with the so-called `representation`, in the form of a linear combination of the atoms, which allows a fast and robust processing of the photos. As a simple example, consider a collection of `l` grayscale (training) pictures where each picture is of size `h × w`. It is suggested in [2](#c14.xhtml#c14-bib-0002) that partitioning each picture into `m` non-overlapping blocks of smaller images, each of which has `p` number of pixels such that `h × w = m × p`. Each of these blocks is then flattened into a one-dimensional vector `y_i^(train) ∈ R^p`, for `i = 1, ..., n = l × m`, then the observed training matrix is given by `Y^(train) = (y_1^(train), ..., y_(l×m)^(train))`; with this in mind, suppose that `D^(train) ∈ R^(p×K)`, where `K > p` for an over-complete dictionary, is the trained dictionary of `K`-SVD. A new grayscale test image partitioned into `m` blocks in the same manner as in the training stage yields the observed test matrix `Y^(test) = (y_1^(test), ..., y_m^(test)) ∈ R^(p×m)`. We aim to find a low-rank approximation `Ỹ ∈ R^(p×m)` of the matrix `Y^(test)` of observed test image signals through `K`-SVD. We then adopt a chosen matching pursuit algorithm in the sparse coding step to find the sparse coefficient matrix `X^(test)` given the trained dictionary `D^(train)`. The low-rank approximation is then `Ỹ = D^(train) X^(test)`, from which the reconstructed image can be built by reversing the block-partitioning steps in the training stage. This approach bears a high resemblance to the prediction of movie ratings for recommender systems discussed in Section 9.11, and is particularly useful for filling in missing pixels in images.
