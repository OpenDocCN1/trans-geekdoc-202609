### 5.2.3 分层抽样

设 `y = h(x)`，其中 `x` 是在 `x` 的定义域 `X` 上具有密度函数 `p(x)` 的随机变量。我们现在想要估计未知参数：

```
θ = E(y) = E(h(x)) = ∫_X h(x) p(x) dx
```

与使用任意选择的随机样本 `x₁, ..., x_n ~ p` 通过估计量

```
θ̂ = (1/n) Σ_{j=1}^n h(x_j)
```

来估计 `θ` 不同，`分层抽样` 的想法是首先将定义域 `X` 划分为若干个独立区域，然后在分配一些合适的权重后，从每个区域中抽取随机样本，以最终估计 `E(h(x))`。更准确地说，假设 `X` 被划分为：

```
X = ⋃_{j=1}^J X_j, where X_i ∩ X_j = ∅ whenever i ≠ j
```
