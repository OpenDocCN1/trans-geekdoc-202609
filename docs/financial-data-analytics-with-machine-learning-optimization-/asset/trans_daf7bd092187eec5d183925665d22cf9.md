### 6.4.1 Metropolis–Hastings Algorithm

A time-reversible Markov chain whose stationary distribution is some desired `π`, such as the posterior distribution of parameters given the observations of some feature vectors, can be constructed systematically by the celebrated *Metropolis–Hastings algorithm*. For discrete state spaces, we start by proposing (guessing) transition probabilities `pᵢⱼ`, which are formally called *proposal transition probabilities*. If the `pᵢⱼ`'s already satisfy time reversibility condition ([6.25](#c06.xhtml#c06-disp-0093)), the corresponding Markov chain is the one we want. Otherwise, either `πᵢpᵢⱼ > πⱼpⱼᵢ` or `πᵢpᵢⱼ < πⱼpⱼᵢ` for some pairs of `i` and `j`. Without loss of generality, suppose that `P(xₙ = sⱼ, xₙ₋₁ = sᵢ) = πᵢpᵢⱼ > πⱼpⱼᵢ = P(xₙ = sᵢ, xₙ₋₁ = sⱼ)`, meaning that there is a higher probability of moving from `sᵢ` to `sⱼ` than from `sⱼ` to `sᵢ`. We then introduce a probability `αᵢⱼ` to reduce the probability of moving from state `sᵢ` to state `sⱼ` such that `πᵢpᵢⱼαᵢⱼ = πⱼpⱼᵢ`, hence

```
αᵢⱼ = (πⱼpⱼᵢ) / (πᵢpᵢⱼ).
```
