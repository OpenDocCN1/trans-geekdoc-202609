# CHAPTER 10

Regression Learning

`Regression Learning` (a.k.a. `Regression Analysis`) 毫无疑问是最广泛使用的统计工具之一，其预测能力主要取决于自变量或协变量的适当选择，可能在变换之后。其“回归”名称最初由英国统计学家 `Francis Galton` 于 1885 年提出 [[7]](#c10.xhtml#c10-bib-0007)，其背景随后由其弟子 `Karl Pearson` 在 1903 年进一步巩固 [[18]](#c10.xhtml#c10-bib-0018)。一般来说，回归分析估计响应（因变量）和自变量之间的关系，这种关系并不完全已知，而是受到由噪声数据引起的某些随机误差的影响。举其在金融中的直接应用，Markowitz 于 1952 年提出的著名资本资产定价模型（CAPM）[[16]](#c10.xhtml#c10-bib-0016) 确实是一个代表性示例。在本章中，我们将从这个传统模型出发，重新探讨简单和多元线性回归模型，包括多项式回归的特例，然后讨论几种常用的广义线性模型，即 `logistic regression` 和 `Poisson regression`，以及它们在金融中的应用和模型选择与评估等问题的实际考虑。此外，呼应第 9 章中的 PCA 讨论，我们还将介绍密切相关的 `principal component regression` 并说明其实际应用。
