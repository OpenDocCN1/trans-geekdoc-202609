

4. 对于每个类别标签 `c_k`，`k = 1, ..., M`，我们为带有特征向量 `x_(n+1)` 的新照片计算以下权重：[(14.9)](#c14.xhtml#R_c14-disp-0029)

`w_k(x_(n+1)) := Σ_(x ∈ P_K, c(x) = c_k) 1 / (1 - Sim(x_(n+1), x))`

5. 然后将新照片分类为使权重最大化的标签 ([14.9](#c14.xhtml#c14-disp-0029))，即 `k^ = arg max_k w_k(x_(n+1))`。

让我们在 [Programme 14.23](#c14.xhtml#c14-sec-3023) 中通过 Python 说明这一想法，使用与面部识别中 [Programme 9.23](#c14.xhtml#c14-sec-3023) 相同的数据集。请注意，来自 `sklearn.neighbors` 库的 Python 函数 `KNeighborsClassifier()` 用于执行 `K`‐NN，并且该函数需要三个输入参数，即 `n_neighbors=K` 用于超参数 `K` 的值，即考虑的最近邻数量；`metric="cosine"` 用于使用上述第 3 项中描述的余弦相似度量；以及 `weight="distance"` 用于按距离的倒数对点进行加权，如 ([14.9](#c14.xhtml#c14-disp-0029)) 中所述。回顾一下，[Programme 9.23](#c14.xhtml#c14-sec-3023) 中的照片未打乱，并且排列方式使得每个个体有 9 张人脸且按顺序排列，并存储在 `y_train` 中。[Programme 14.23](#c14.xhtml#c14-sec-3023) 演示了 `K`‐NN 的实现，采用了通常采用的超参数 `K = 3`，并使用 [Section 9.8](#c09.xhtml#c09-sec-0009) 中获得的 107 个主成分作为特征。它实现了 `39 / 40 = 97.5%` 的高准确率，并且第 34 个个体只有一次错误识别。确实，该个体的输出权重向量仅包含两个正权重，分别在第 34 位和第 39 位为 0.3079 和 0.6921，并且预测标签确定为 39，因为它具有更大的权重。

我们也重新访问 MNIST 数据集，这次使用 `K`‐NN 算法。为简单起见，我们选择 `K = 3`，与前一个示例相同。与之前一样，我们首先执行标准直接 `K`‐NN 算法作为基准。从通过 Python 在 [Programme 14.24](#c14.xhtml#c14-sec-3024) 中获得的输出结果来看，`K`‐NN 算法在 `K = 3` 时在测试数据集上的预测准确率为 0.9705，高于通过 Python 在 [Programme 10.17](#c14.xhtml#c14-sec-3017) 中编码的逻辑回归模型获得的 0.9256。此外，由于 `K`‐NN 是一种惰性算法，即在需要进行预测之前不处理训练数据集，因此 Python 程序的运行时间仅约 6 秒，远快于 [Programme 10.17](#c14.xhtml#c14-sec-3017) 中的逻辑回归（1 分钟）和 [Programme 14.19](#c14.xhtml#c14-sec-3019) 中的 `K`‐means 聚类（15 秒）。而通过 `R` 在 [Programme 14.25](#c14.xhtml#c14-sec-3025) 中的实现，使用 `class` 库中的 `knn()` 函数，得到的测试准确率相似，为 0.9716，但耗时更长，运行时间超过一小时。
