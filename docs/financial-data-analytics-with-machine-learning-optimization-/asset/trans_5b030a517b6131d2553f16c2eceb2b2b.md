

# 潜在因子推荐系统方法

回到潜在因子方法，在完成最小化均方误差 `J` 的优化程序后，订阅者对电影的偏好 `p̂ᵢ,ₖ` 和电影的性质 `q̂ⱼ,ₖ` 都可以被估计。`m × n` 矩阵 `R̂ = P̂Q̂ᵀ` 然后存储所有订阅者对所有电影的预测评分。例如，`R̂` 的第 `i` 行是行向量，列出了第 `i` 位订阅者对所有电影 `j = 1, 2, …, n` 的预测评分。值得注意的是，`R̂` 的这些预测评分对于未知评分 `rᵢ,ⱼ = 0` 应该是非零的；而对于任何 `rᵢ,ⱼ ≠ 0`，相应的估计值 `r̂ᵢ,ⱼ` 应该大约等于该已知评分 `rᵢ,ⱼ`。通过将这些估计评分按降序排序，我们的推荐系统应该能够为第 `i` 位订阅者显示最符合其口味的顶级推荐。此外，如果我们想要预测测试数据的所有评分，例如对于新加入的用户 `m + 1`，基于他已知的一些评分 `rₘ₊₁,ⱼ`，那么我们求解 `p̂ₘ₊₁ = (p̂ₘ₊₁,₁, …, p̂ₘ₊₁,ₚ)ᵀ` 以最小化 `Σⱼ₌₁ⁿ(rₘ₊₁,ⱼ − Σₖ₌₁ᵖ p̂ₘ₊₁,ₖ q̂ⱼ,ₖ)²`。这里，`Q̂` 已经使用现有用户 `1, …, m` 的训练数据获得，并且不受仅一个新用户 `m + 1` 或几个新用户的影响。换句话说，用户 `m + 1` 评分的最佳近似值，列向量 `r̂ₘ₊₁ = Q̂p̂ₘ₊₁ := (Σₖ₌₁ᵖ p̂ₘ₊₁,ₖ q̂ⱼ,ₖ)ⱼ₌₁ⁿ`，只是 `rₘ₊₁ := (rₘ₊₁,₁, …, rₘ₊₁,ₙ)ᵀ` 在 `Q̂` 的列空间上的投影。当然，如果订阅者 `m + 1` 真的刚刚加入服务，通常会弹出一些随机推荐，以便了解这个新用户会做出什么选择，然后可以先学习更多非零值的 `rₘ₊₁,ⱼ`。之后，上述描述的程序就可以实施了。
