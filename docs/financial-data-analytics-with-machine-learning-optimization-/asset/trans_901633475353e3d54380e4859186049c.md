

*证明.* 令 `{x_n}` 为具有有限状态空间的不可约且非周期性马尔可夫链。根据 [定理 6.3](#c06.xhtml#c06-fea-0026)，存在至少一个平稳分布，因此我们只需证明最多存在一个平稳分布。令 `π` 和 `π′` 为马尔可夫链的两个平稳分布。假设马尔可夫链以初始分布 `μ⁽⁰⁾ = π′` 开始。那么，根据 `π′` 的平稳性假设，对所有 `n` 均有 `μ⁽ⁿ⁾ = π′`。另一方面，根据 [定理 6.4](#c06.xhtml#c06-fea-0030),

```
0 = lim_{n→∞} d_TV(μ⁽ⁿ⁾, π) = lim_{n→∞} d_TV(π′, π) = d_TV(π′, π).
```

这意味着 `π = π′`. ![](images/box.png)

我们总结 [定理 6.3](#c06.xhtml#c06-fea-0026) 和 [6.4](#c06.xhtml#c06-fea-0030)：如果马尔可夫链具有有限状态空间且不可约且非周期性，则它具有唯一的平稳分布 `π`，且链在时间 `n` 时的分布 `μ⁽ⁿ⁾` 随着 `n → ∞` 趋近于 `π`，与初始分布 `μ⁽⁰⁾` 无关。通过引用 ([6.22](#c06.xhtml#c06-disp-0086))，([6.23](#c06.xhtml#c06-disp-0088)) 和 ([6.24](#c06.xhtml#c06-disp-0089))，我们可以看到这种收敛在 `n` 中大多是指数级快的；另请参见 *Doeblin's theorem*.
