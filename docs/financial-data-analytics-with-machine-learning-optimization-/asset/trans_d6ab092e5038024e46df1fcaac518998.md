```math
D(P\|Q) = -\sum_{x=0}^{n} P(x) \ln \left( \frac{n!}{x!(n-x)!} \cdot \frac{x!(n-x)!}{n!} \cdot \frac{\beta^x (1-\beta)^{n-x}}{\alpha^x (1-\alpha)^{n-x}} \right)
= -\ln \left( \frac{\beta}{\alpha} \right) \sum_{x=0}^{n} x P(x) + \ln \left( \frac{1-\beta}{1-\alpha} \right) \sum_{x=0}^{n} (x-n) P(x)
= n \alpha \ln \left( \frac{\alpha}{\beta} \right) + n (\alpha - 1) \ln \left( \frac{1-\beta}{1-\alpha} \right).
```
