

在传统的线性回归模型中，响应变量 `y` 被假设服从正态分布，而预测变量 `x1, ..., xp` 与 `y` 之间的函数关系是线性的。然而，许多现实世界的应用要求模型能够容纳不同类型的响应变量和非线性关系。丰富回归分析的潜在应用，广泛的 `Generalized Linear Models` (GLMs) 类在这些场景中很普遍。在这些模型中，响应变量遵循所谓的 `exponential dispersion family` (EDF) 中的分布，其均值通过 `link function` 与 `linear predictor` 或 `systematic component` `η = x̃ᵀβ` 相连接，后者是特征（解释）变量 `x1, ..., xp` 的标准版本的线性组合。

让我们更详细地了解 GLM。为简单起见，我们只考虑一维设置。我们首先简要介绍 EDF 的一些基本性质。EDF 中分布的 pdf（或离散情况下的 pmf）采用以下一般形式：

[(10.8)](#c10.xhtml#R_c10-disp-0023)
```
f(y; θ, φ) = exp((yθ - b(θ)) / φ + S(y, φ)),
```

其中 `θ` 被称为 `natural parameter`，`b(θ) ∈ C²` 和 `S(y, φ)` 是已知函数。从 ([10.8](#c10.xhtml#c10-disp-0023)) 可以看出，EDF 是指数族的一个子类，其中 `θ` 的充分统计量等于 `y` 除以尺度参数 `φ`。金融和保险分析中许多常用的分布属于 EDF，包括但不限于正态分布、伽马分布、泊松分布和二项分布。从 ([10.8](#c10.xhtml#c10-disp-0023))，我们可以轻易推导出 `y` 的 mgf：
