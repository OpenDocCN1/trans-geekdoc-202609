

这些考虑促使我们定义上尾完全单调性（参见 [\[26\]](#c08.xhtml#c08-bib-0026)）如下。若随机向量 `x` 具有 copula `C` 和生存 copula `Ĉ`，则称其为 *上尾完全单调的*，如果对于任意 `w₁, …, w_d ∈ [0, ∞)`，

```
lim_{u ↓ 0} Ĉ(uw₁, …, uw_d) / u = min{w₁, …, w_d}.
```

则称这样的 copula `Ĉ` 为 *上尾完全单调 copula*。

上尾完全单调性与风险价值（Value-at-Risk）的渐近可加性密切相关。考虑一个包含 `d` 个损失变量 `x₁, …, x_d` 的投资组合。我们旨在考察总损失 `s = x₁ + … + x_d` 的风险价值。假设对于某些 `1 ≤ m ≤ d`，`x₁, …, x_m ∈ MDA(Φ_α)`

1. `x_j ∈ MDA(Φ_{α′})`⁶ 且 `α′ > α`;

2. `x_j ∈ MDA(Λ)`⁶;

3. `x_j` 具有有限端点。

在上述设定下，我们最近的工作 [\[11\]](#c08.xhtml#c08-bib-0011) 表明，对于此类投资组合，风险价值是渐近可加的：

```
V@R_p(s) ≍ ∑_{i=1}^{d} V@R_p(x_i)  p ↑ 1.
```

此外，还有两种其他情形，其中风险价值的这种渐近可加性依然成立：

1. 非负随机变量 `x₁, …, x_m` 位于 `MDA(Λ)`⁶ 且具有无限端点，并且它们是上尾完全单调的，而其他非负 `x_{m+1}, …, x_d` 具有有限端点。

2. 所有非负随机变量 `x₁, …, x_d` 具有有限端点并且它们是上尾完全单调的。

## (VI) Archimedean Copulae

Archimedean copulae 构成一个结合类的 copulae。对于大多数常用的 Archimedean copulae，可以轻松获得显式公式，而对于其他类别的 copulae（例如常用的高斯 copula）则并非如此。此外，Archimedean copulae 可以轻松用于在任意高维度中建模依赖风险，这是它们在实践中受欢迎的另一个原因。
