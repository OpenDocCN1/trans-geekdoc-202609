
for some constant `C_p > 0` depending on the dimension `p` and the geometric shape of `S` only. Hence, `P(T_ε > M) ≤ 1 - C_p α² ε^(p-1)`, where the bound is clearly in `(0, 1)` for a sufficiently small `ε > 0`.

Given that `T_ε > M`, the Markov chains can be considered to start afresh no matter where it restarts, hence

```
P(∥x₂ᴹ - x'₂ᴹ∥₂ > ε | T_ε > M) ≤ 1 - C_p α² ε^(p-1).
```

Consequently,

```
P(T_ε > 2M) = P(T_ε > M) · P(T_ε > 2M | T_ε > M)
          ≤ (1 - C_p α² ε^(p-1)) · P(∥x₂ᴹ - x'₂ᴹ∥₂ > ε | T_ε > M)
          ≤ (1 - C_p α² ε^(p-1))².
```

By a recursive argument, we see that for any `l ∈ ℕ`,

```
P(T_ε > lM) ≤ (1 - C_p α² ε^(p-1))^l → 0 as l → ∞,
```

which implies that `P(T_ε = ∞) = 0` for any `ε > 0`.
