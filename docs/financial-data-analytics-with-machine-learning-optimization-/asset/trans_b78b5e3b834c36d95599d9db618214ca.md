

当样本量 `n` 较大时。这里假设数据 `(x₁, y₁), ..., (xₙ, yₙ)` 是 `(x, y)` 的独立同分布实现。再次根据大数定律，当 `M << n` 足够大时，理论期望 `E(∇_θ ℓ(θ; y, x))` 可以由 `S` 中大小为 `M` 的一小部分来近似，即，

```
E[∇_θ ℓ(θ; y, x)] ≈ (1/M) Σ_{m=1}^M ∇_θ ℓ(θ; y_m, x_m).
```

因此，当 `M` 和 `n` 均较大时，以非常高的概率，

```
∇_θ L_M(θ) ≈ (1/M) Σ_{m=1}^M ∇_θ ℓ(θ; y_m, x_m),
```

这就是小批量 SGD 的主要哲学：用个体损失梯度的部分平均值来替代总损失的梯度。
