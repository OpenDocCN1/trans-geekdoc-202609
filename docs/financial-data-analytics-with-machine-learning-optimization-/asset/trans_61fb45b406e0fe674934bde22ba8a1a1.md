

最后，我们在极值 copula 下对 V@R 得到了与 Archimedean copula 下类似的渐近结果。当损失变量 `x₁, …, x_d` 具有相同分布且其依赖结构由极值 copula 给出时，[\[10\]](#c08.xhtml#c08-bib-0010) 建立了以下关于当概率水平趋近于 1 时总损失 `s = x₁ + … + x_d` 的 Value-at-Risk 的结果：

1. 如果 `x₁ ∈ MDA(Φ_β)`，则 `V@R` 是 (i) 当 `β > 1` 时渐近次可加；(ii) 当 `β < 1` 时渐近超可加；(iii) 当 `β = 1` 时渐近可加。

2. 如果 `x₁ ∈ MDA(Λ)` 且具有无限右端点，则 `V@R` 是渐近次可加。

3. 如果 `x₁` 具有有限端点，则 `V@R` 是渐近可加。

我们使用 `R` 包 `evd` 来模拟具有给定边缘分布的极值 copula。例如，我们从相应的分布中生成 `10⁷` 个数据点，并绘制在 Gumbel–Hougaard copula 下给定边缘分布的 V@R 比率 `V@R_p(s) / Σ_{i=1}^d V@R_p(x_i)`。在我们的模拟研究中，我们简单地设置 `α = 1.5`。有关说明，请参见 [Figures 8.27](#c08.xhtml#c08-fig-0027)–[8.29](#c08.xhtml#c08-fig-0029)。

人们相信，上述 1) 到 3) 的结论在很大程度上仍然有效，即使对于异质分布以及当变量之间的依赖结构由表现出某种正依赖的一般 copula 建模时也是如此，这将是一个有趣的未来研究项目。

最后但同样重要的是，我们简要介绍一下时髦的 vine copula，它在金融领域得到了广泛应用，例如在投资组合优化应用中有效建模尾部风险（有关详细讨论请参见 [\[1\]](#c08.xhtml#c08-bib-0001)）。Vine 是一种用于标记高维概率分布中约束的图形工具。它是一组嵌套的连接树，其中一棵树的边缘成为下一棵要构建的树的节点。作为所有约束均为二维或条件二维的特殊情况，正则 vines（又称 R-vines）越来越流行，因为联合概率的计算是以逐对顺序的方式进行的。确实，当约束与条件双变量 copula 相关联时，我们施加 vine copula，这样任何多变量密度都可以表示为 R-vine 上的边缘密度和条件 copula 密度的乘积。可以将 vine copula 解释为表征随机变量簇之间依赖结构的 copula。为此，我们将在 [Chapter 12](#c12.xhtml) 中介绍的 Comonotone-Independence Bayes classifier (CIBer) 可以被视为 vine copula 的一个特例，因为那里的依赖结构是以全或无的方式处理的，即要么是共单调性，要么是独立性。由于篇幅限制，我们将不详细介绍其公式和应用。
