

与普通回归一样，逻辑回归中自变量（特征变量）也可能包含分类变量。在 [第 13 章](#c13.xhtml) 中，通过使用决策树，我们将看到 `ln_MV>9.4776` 是将 `HSI = 0` 或 1 的股票进行分类的重要指标。基于此，我们提议使用一个虚拟（分类）变量 `g := 1 + 1_{ln MV > 9.4776}`，并在此基础上加上其他五个财务变量（`MV` 除外）及其交互项来拟合逻辑回归。这种原始阈值逻辑回归模型显示在 [程序 10.13](#c10.xhtml#c10-sec-3013) 中。

`CFTP*g` 的系数具有最大的 `p` 值（0.9721），而 `CFTP` 的系数位居第二（0.9607）。我们可以在下一次回归拟合中排除 `CFTP` 和 `CFTP*g`；修订后的模型请参见 [程序 10.14](#c10.xhtml#c10-sec-3014)。

在 [程序 10.14](#c10.xhtml#c10-sec-3014) 中，系数 `DTE*g` 具有最大的 `p` 值（0.7147），而 `DTE` 本身的系数也位居第二（0.6745），因此我们在下一次尝试中排除 `DTE` 和 `DTE*g`。我们继续排除具有大 `p` 值的变量，经过几轮后，我们最终得到了如 [程序 10.15](#c10.xhtml#c10-sec-3015) 所示的最终模型。这个阈值模型比 [程序 10.12](#c10.xhtml#c10-sec-3012) 中的模型更简单，但其分类能力依然与之前一样好，其表达式为：

```
ln(π̂ / (1 - π̂)) = -18.6304 + 12.9236 g + 1.4036 DY - 1.2860 (g * DY),
```

或者等价地，

```
ln(π̂ / (1 - π̂)) = { -5.6944 + 0.1176 DY, for ln MV ≤ 9.4776 ;
                    7.2416 - 1.1684 DY, for ln MV > 9.4776 ; }
```

其中 `π` 是在给定特征的情况下 `HSI = 1` 的概率。当 `ln_MV > 9.4776` 时，截距比 `ln_MV ≤ 9.4776` 时的截距更大。因此，当 `ln_MV` 较大时，`HSI = 1` 的概率看起来更高，这也是合理的。
