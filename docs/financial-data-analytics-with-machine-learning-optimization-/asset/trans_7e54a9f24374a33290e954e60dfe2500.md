## 11.A.1.3 SGD 的收敛性

在本节中，我们简要介绍关于 SGD 收敛性的著名 Robbins–Monro 定理 [\[19\]](#c11.xhtml#c11-bib-0020)；更多讨论可见 [\[8\]](#c11.xhtml#c11-bib-0008)。为此，我们将单个损失写为 `l(θ; x)`，其中 `x ∈ R^p` 是一个随机变量，`θ ∈ R^q` 是我们希望调整以最小化单个损失之和（或平均值）的模型参数。我们假设

1. **(A1)** (`Lipschitz continuity`) 单个损失函数 `l: R^q × R^p → R` 是连续可微的，且其梯度函数 `∇_θ l(θ; x)` 是带有正 Lipschitz 常数 `C` 的 Lipschitz 连续函数：对于任何 `θ, θ' ∈ R^q`，(11.19)

```
‖∇_θ l(θ; x) − ∇_θ l(θ'; x)‖_2 ≤ C ‖θ − θ'‖_2 ;
```

2. **(A2)** (`L^2`‐boundedness) (11.20)

```
E[‖∇_θ l(θ; x)‖_2^2] < ∞ , for every θ ∈ R^q ;
```
