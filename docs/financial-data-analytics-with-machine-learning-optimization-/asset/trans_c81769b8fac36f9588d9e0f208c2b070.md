

# 马尔可夫链的平稳分布

A *stationary distribution* of a Markov chain with a transition probability matrix `P` and a finite state space `S = {s₁, ..., sₖ}` is a probability distribution `π = (π₁, ..., πₖ)` that satisfies `πP = π`, that is, `∑ᵢ₌₁ᴷ πᵢpᵢⱼ = πⱼ` for `j = 1, ..., K`. The term “stationary” comes from the property that if a Markov chain distributes according to a stationary distribution initially, then the chain will follow the same distribution at all future time points.

By definition, when the limiting distribution `(π₁, ..., πₖ)`, defined by

```
πⱼ = limₙ→∞ P(xₙ = sⱼ | x₀ = sᵢ) = limₙ→∞ pᵢⱼ⁽ⁿ⁾,
```

exists, it is always a stationary distribution. However, the converse is not true. For instance, for the periodic Markov chain with the following transition probability matrix:

```
P = (0 1; 1 0),
```

there cannot be a limiting distribution; on the other hand, `π = (1/2, 1/2)` is clearly its stationary distribution.
