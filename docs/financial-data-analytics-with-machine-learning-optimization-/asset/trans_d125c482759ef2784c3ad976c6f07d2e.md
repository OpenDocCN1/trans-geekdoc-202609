

# Power Law

在建模经验数据时，一个有用的定律是 *Power Law*，该定律最早由 *Vilfredo Pareto* 于 1897 年正式提出 [\[37\]](#c08.xhtml#c08-bib-0037)。如果随机变量 `y` 的生存函数与幂函数成正比，即 `P(y > x) ∝ x^(-α)`（其中 `α > 0`），则认为该定律成立；它还为估计罕见事件的尾概率提供了良好的模型。设 `F` 为随机变量 `x` 的累积分布函数（cdf），即 `P(x ≤ u) = F(u)`，则在给定 `x > u` 时，`u < x ≤ u + y` 的条件概率为

```
F_u(y) := P(x - u ≤ y | x > u) = (F(u + y) - F(u)) / (1 - F(u)).
```

已证明（[\[4](#c08.xhtml#c08-bib-0004), [23](#c08.xhtml#c08-bib-0023), [38](#c08.xhtml#c08-bib-0038)]），对于大类分布 `F`，当 `u → ∞` 时，`F_u(y)` 在 `y > 0` 上一致收敛于 `G_{ξ,β}(y)`，其中

```
G_{ξ,β}(y) = { 1 - (1 + ξy/β)^(-1/ξ), ξ ≠ 0
             { 1 - exp(-y/β),       ξ = 0
```

这被称为具有形状参数 `ξ` 和尺度参数 `β > 0` 的 *generalized Pareto distribution*，其中当 `ξ ≥ 0` 时 `y ≥ 0`，或当 `ξ < 0` 时 `0 ≤ y ≤ -β/ξ`。对于常见的金融数据，`ξ > 0` 且取值范围在 0.1 到 0.4 之间，详情请参见 [\[27\]](#c08.xhtml#c08-bib-0027)。有关极值理论（EVT）的更多介绍，请参阅 [\[25](#c08.xhtml#c08-bib-0025), [40](#c08.xhtml#c08-bib-0040)]。
