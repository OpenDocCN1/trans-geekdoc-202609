

更准确地说，令 `x₁, …, xₙ` 为来自具有“混合联合密度”函数 `f(x; θ)` 的总体的可观测 `p` 维随机样本，样本量为 `n`，其中 `θ` 是参数的 `k` 维向量。注意，如果随机观测值 `x` 的所有分量均为连续（resp. 离散），则 `f` 与通常情况一样是联合密度函数（resp. 联合概率质量函数），但情况并非总是如此。因为如果 `x` 的某些分量为连续而其他分量为离散（甚至为分类），则 `f` 被视为混合联合密度函数。例如，令 `x = (x₁, x₂)ᵀ` 为 2 维随机向量，`θ = (θ₁, θ₂, θ₃)ᵀ` 为正参数的 3 维向量，使得 `x₁ ~ Poi(θ₁)` 且 `x₂ = Σᵢ₌₁ˣ¹ Gᵢ`，其中 `Gᵢ ~ᵢᵢᵈ Gamma(θ₂, θ₃)`，其概率密度函数为 `θ₃^θ₂ / Γ(θ₂) · x^(θ₂ - 1) · e^(-θ₃x)`，适用于 `i = 1, 2, …`。则在给定 `x₁ = x₁` 时，`x₂` 的密度为 Gamma`(x₁θ₂, θ₃)`，这是基于伽马随机变量的可加性性质：

```
f(x₂ | x₁; θ) = θ₃^(x₁θ₂) / Γ(x₁θ₂) · x₂^(x₁θ₂ - 1) · e^(-θ₃x₂),
```
