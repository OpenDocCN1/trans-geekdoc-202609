

凭借贝叶斯定理，给定样本 `x_1, ..., x_n` 时，`x_{n+1}` 的预测分布仅仅是给定样本时特征观测值 `x_{n+1}` 的条件分布，因此它是带权重 `f_{μ|x}(μ|x)` 的条件分布 `N(μ, σ²)` 的加权平均，即，

[(1.20)](#c01.xhtml#R_c01-disp-0069)

```
f̂_x(x) := f_{x_{n+1}|x}(x|x) = ∫_{-∞}^{∞} f_{μ|x}(μ|x) f_N(x|μ, σ²) dμ,
```

其中 `f_N` 是均值为 `μ`、方差为 `σ²` 的正态密度。回顾 `μ|x = x̃ ~ N(μ_n, β_n^{-1})`，([1.20](#c01.xhtml#c01-disp-0069)) 变为：

(1.21)

```
f̂_x(x) ∝ ∫_{-∞}^{∞} exp(-β_n/2 (μ - μ_n)² - β/2 (x - μ)²) dμ,
```
