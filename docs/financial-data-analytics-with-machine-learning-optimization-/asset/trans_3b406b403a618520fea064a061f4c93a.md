

(8.14) `M(u) := min(u₁, ..., u_d), for u₁, ..., u_d ∈ [0, 1].`

它对应于极端正相关性的情况（有时称为`complete dependence`）。随机变量 `x₁, ..., x_d` 具有共单调 copula 当且仅当它们是共同随机性来源的递增变换，即 `x_i = f_i(w)`，对于每个 `i`，存在一个递增函数 `f_i : ℝ → ℝ`，且 `w` 是一个共同随机变量。

## (V) 上尾共单调 Copula⁵

尽管其简单性和良好的解析可处理性，但在整个定义域上的全局共单调性过于限制，在定量金融和风险管理中的应用范围有限。尽管如此，仅在极端上尾发生的共单调性是一个更现实的建模选择，这引导我们考虑普遍的 `upper tail comonotonicity` 概念，其中生存 copula `Ĉ` 满足：

`Ĉ(F̄₁(x₁), ..., F̄_d(x_d)) ≈ min{F̄₁(x₁), ..., F̄_d(x_d)}`

仅对 `x_i` 的所有足够大的值成立。具有此属性的 Copulae 无论边际分布如何，都应该表现得使得

`Ĉ(u₁, ..., u_d) ≈ min{u₁, ..., u_d},`

对 `u_i` 的所有足够小的值成立。此外，为了确保数学可处理性并便于其实际实施，对 `Ĉ` 施加进一步的正则性条件是有吸引力的。一个合理的要求是尺度不变性，即关于 `u_i` 的可比收敛速度，具体为：

`Ĉ(u w₁, ..., u w_d) ≈ min{u w₁, ..., u w_d}, u ↓ 0, for any w₁, ..., w_d ∈ [0, ∞).`
