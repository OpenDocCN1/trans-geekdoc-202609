
A Markov chain with a finite state space and a transition probability matrix `P` is said to be *regular* if all entries in `P^n` are strictly positive for some integer `n ≥ 0`. We aim to show that if the Markov chain `{x_n}` is regular and has a finite state space `S = {s_1, s_2, ..., s_K}`, then the limiting distribution, `(π_1, ..., π_K)` defined by

```
π_j = lim_{n→∞} P(x_n = s_j | x_0 = s_i) = lim_{n→∞} p_{i,j}^{(n)}, j = 1, ..., K,
```

exists, and these limits do not depend on the choice of the initial state `i`.
