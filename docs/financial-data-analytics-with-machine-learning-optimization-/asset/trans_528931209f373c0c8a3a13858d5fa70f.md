

where $\hat{L}:=e^{n g_n(\hat{\theta}_{\text{MLE}})}=f_{\mathcal{M}}(x|\hat{\theta}_{\text{MLE}})$ 是最大化似然。因此，候选模型 $\mathcal{M}$ 之间的比较归结为比较在每个模型下观测数据 $x$ 的边缘似然 $f_{\mathcal{M}}(x)$。我们应选择边缘似然最大的模型，或者等价地，选择对数边缘似然 $\ln f_{\mathcal{M}}(x)$ 最大的模型，其近似为：

$$
\begin{aligned}
\ln f_{\mathcal{M}}(x) &\approx \ln \hat{L} - \frac{k}{2} \ln n + \left(\frac{k}{2} \ln(2\pi) + \ln \pi_{\mathcal{M}}(\hat{\theta}_{\text{MLE}}) - \frac{1}{2} \ln \left| -\nabla_{\theta} \nabla_{\theta}^T q_n(\hat{\theta}_{\text{MLE}}) \right|\right) \\
&= -\frac{1}{2} \left( -2 \ln \hat{L} + k \ln n \right) + O_p(1).
\end{aligned}
$$

这解释了为什么 $\text{BIC}:=-2 \ln \hat{L} + k \ln n$ 被用作贝叶斯框架下模型选择的准则；事实上，BIC 最小的模型具有最大的对数边缘似然，因此应被优先选择。有关更详细的讨论，我们参考 [\[14\]](#c12.xhtml#c12-bib-0014) 及其中的参考文献。
