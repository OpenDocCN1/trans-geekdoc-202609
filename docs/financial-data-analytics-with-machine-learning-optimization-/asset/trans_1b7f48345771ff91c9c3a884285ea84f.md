

# 11.A.2.3 QP 问题的原始与对偶公式

通过使用 11.A.2.2 小节中引入的对偶性结果，我们在此利用拉格朗日乘数法对 QP 问题（([11.23](#c11.xhtml#c11-disp-0051))，约束条件为 ([11.24](#c11.xhtml#c11-disp-0052))）进行重新表述；关于该方法的进一步讨论，请参见 [\[3\]](#c11.xhtml#c11-bib-0003)。拉格朗日 `L`，其中 `λ₁ ∈ ℝᴷ`，`λ₂ ∈ ℝᴹ`，定义如下：

[(11.43)](#c11.xhtml#R_c11-disp-0102)

```
L(x, λ₁, λ₂) = 1/2 xᵀPx + qᵀx + r + λ₁ᵀ(Gx - h) + λ₂ᵀ(Ax - b)
             = 1/2 xᵀPx + (q + Gᵀλ₁ + Aᵀλ₂)ᵀx - λ₁ᵀh - λ₂ᵀb + r,
```

其中 `λ₁ ≥ 0` 且 `λ₂ ∈ ℝᴹ`。

```
∇ₓL(x, λ₁, λ₂) = Px + (q + Gᵀλ₁ + Aᵀλ₂) = 0,
```
