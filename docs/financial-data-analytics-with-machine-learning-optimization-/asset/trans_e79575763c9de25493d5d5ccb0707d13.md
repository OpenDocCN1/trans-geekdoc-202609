

一旦我们将 `f` 设定为 `[0, 1]` 上的周期函数，就可以讨论其 *傅里叶系数*，每个系数定义为

`f̂(n) = ∫₀¹ f(t)e⁻²πⁱⁿᵗ dt, for any n ∈ ℤ.`

此外，由于 `f(t)` 是实值函数，`f̂(-n) = f̄(n)`。根据著名的 *Parseval's theorem* [\[34](#c04.xhtml#c04-bib-0034), [39\]](#c04.xhtml#c04-bib-0039)，只要 `f ∈ L²[0, 1]`，即 `f` 是平方可积的且 `∫₀¹ f²(x) dx < ∞`，无穷级数 `∑ₙ₌₋∞⁺∞ f̂(n)e²πⁱⁿᵗ`（几乎处处）在 `L²` 范数下收敛于 `f(t)`，并且在所有 `f(t)` 连续的点 `t` 处收敛是逐点的 [\[45\]](#c04.xhtml#c04-bib-0045)。出于计算概率的目的，由于根据柯西–施瓦茨不等式，对 `[0, 1]` 上的任何 `g ∈ L²[0, 1]` 都有 `||g||₁ ≤ ||g||₂`，因此 `L²`-收敛意味着在 `L²[0, 1]` 中的 `L¹`-收敛。此外，映射 `F: f ∈ L²[0, 1] ↦ {f̂(n)}ₙ∈ℤ` 是希尔伯特空间同构，这是基于 *Parseval's identity* [\[34](#c04.xhtml#c04-bib-0034), [39\]](#c04.xhtml#c04-bib-0039)：

```
∫₀¹ f²(t) dt = ∑ₙ₌₋∞⁺∞ |f̂(n)|².
```
