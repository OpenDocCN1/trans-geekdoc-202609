
Notice that the training set `X` is a `(112 · 92) × (9 · 40) = 10,304 × 360` matrix, leading to a singular `10,304 × 10,304` matrix `XX⁺`. From [Section 1.2](#c01.xhtml#c01-sec-0007) of [Chapter 1](#c01.xhtml), we know that the largest 360 (non‐zero) eigenvalues of `XX⁺` and `X⁺X` are the same. For `i = 1, …, 360`, denote by `uᵢ` the `i`‐th eigenvector of `X⁺X`, then the `i`‐th eigenvector of `XX⁺` is given by `hᵢ = Xuᵢ`; meanwhile, the remaining eigenvalues `λ₃₆₁, …, λ₁₀,₃₀₄` of the singular `XX⁺` are simply zero. Taking advantage of this, we need only consider the spectral decomposition of `X⁺X` instead. We implement this in [Programme 9.19](#c09.xhtml#c09-sec-3019) via Python.

From the outputs of [Programme 9.19](#c09.xhtml#c09-sec-3019) in Python, 107 PCs suffice to preserve 90% of all information contained in the total variance. Notice that the training set is standardized, so the total variance is then equal to `p = h · w = 10,304`. A similar implementation via `R` can be found in [Programme 9.20](#c09.xhtml#c09-sec-3020).

In Python, the `PCA` in `sklearn` can also be used directly with the argument `n_components=0.9` to preserve 90% of information; also see [Programmes 9.21](#c09.xhtml#c09-sec-3021) in Python and [9.22](#c09.xhtml#c09-sec-3022) in `R`. For `R`, since the training dataset has already been normalized, we call the `prcomp()` function with the two arguments `center=FALSE` and `scale=FALSE`.

Both the training and test datasets are transformed by projecting onto these 107 PCs. We then compare the Euclidean distances between each test observation against all in the training dataset. The observation from the training dataset that yields the shortest distance with the query face image is said to be a match with that test observation.
