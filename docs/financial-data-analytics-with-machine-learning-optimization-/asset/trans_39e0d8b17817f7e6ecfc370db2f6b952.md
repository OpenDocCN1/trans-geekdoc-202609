

直觉上，在三种候选策略中，当 `k_s > 1` 时，策略 `K_L` 最为激进；当 `k_s` 接近 `-4` 时，它变得最为保守；策略 `K_IC` 和 `K_AC` 的激进程度介于这两种边界情况之间。

对于当天 `s` 的交易，我们根据投资组合的当前持仓说明所采取的交易如下；假设上一笔交易是在 `δt` 个日历天前进行的

*   如果在上一笔交易中借入了 `n_{s-δt} > 0` 单位股票并进行了卖空，因此目前持有 `n_{s-δt}` 单位股票的空头头寸，那么我们从市场买回这些 `n_{s-δt}` 股股票以 `close the short-selling position`。假设卖空年利率为 10%

*   如果在上一笔交易中购买了 `n_{s-δt} > 0` 股股票，因此目前持有 `n_{s-δt}` 单位股票的多头头寸，那么我们将这些 `n_{s-δt}` 股股票卖给市场以 `close the long position`，并收到现金所得款项 `n_{s-δt}S_s`。请注意，如果在上一笔交易开仓时借入了现金金额 `K ≥ 0`（当使用策略 `K_IC` 或 `K_L` 之一时更常发生），那么假设借款年利率为 10%，我们偿还累积值为 `K(1 + 0.1/365)^{δt}` 的贷款，通过平掉多头头寸获得的净所得款项为 `n_{s-δt}S_s - K(1 + 0.1/365)^{δt}`。之后，我们以 10% 的卖空利率借入 `n_s > 0` 单位股票并将其卖回市场，从而 `open the short-selling position`。再次说明，`n_s` 是根据所使用的策略 `K_IC`、`K_AC` 或 `K_L` 计算得出的。

此外，对于在当天 `s` 开仓或平仓 `n_s > 0` 单位股票的每笔交易，佣金费用为 USD `max(0.013n_s, 2.05)`
