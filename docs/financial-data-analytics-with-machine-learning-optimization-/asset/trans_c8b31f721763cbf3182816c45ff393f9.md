Note that `Σ₂₁ = Σ₁₂ᵀ`. We summarize below some useful properties about the marginal and conditional distributions of the multivariate normal distribution.

1.  If `x ~ Nₚ(μ, Σ)`, then the marginal distribution of any `q`-component subset of `x` is `q`-variate normal. Without loss of generality, it suffices to show that `x₁ ~ N_q(μ₁, Σ₁₁)`. Let `B = [I_q 0]` be a `q × p` matrix. By Property 1 in [Subsection 1.4.2](#c01.xhtml#c01-sec-0011), `x₁ = Bx ~ N_q(Bμ, BΣBᵀ) = N_q(μ₁, Σ₁₁)`.

2.  `x₁` and `x₂` are independent if and only if `Σ₁₂ = 0`.
