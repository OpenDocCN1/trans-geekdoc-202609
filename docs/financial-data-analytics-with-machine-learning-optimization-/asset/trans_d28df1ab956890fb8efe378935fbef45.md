

CAPM 在现代金融中应用广泛。例如，CAPM 中 `β` 因子与证券预期收益率之间的线性关系（[10.2](#c10.xhtml#c10-disp-0002），又称 *证券市场线*（SML）），常被用于判断资产是否定价合理。通常，几乎每个行业的 `β_i` 均保持在均衡水平附近，若某只股票在最近一段时间内的 `r_i` 样本均值过高（resp. 过低），则该股票将承受整体下行（resp. 上行）压力，使其价格回归至 SML 上对应的均衡水平。在实际市场中，这类调整通常在相对较短的时间内完成。此外，*Jensen 指数* [\[11\]](#c10.xhtml#c10-bib-0011) `J := μ̂ − (r_f + β̂(μ̂_m − r_f))`，其中 `μ̂_m` 为市场指数 `r_m` 的经验均值，是一个广为人知的绩效评估参考指标，它通过市场数据观察到的股票预估收益 `μ̂` 与 CAPM 中 SML 预测的“自然”收益 `r_f + β̂(μ̂_m − r_f)` 之间的差异，来检测任何可能的误定价。*Sharpe 比率* 是 `β_i` 的经验实现，`β̂_i = (μ̂_i − r_f) / σ̂_i`，衡量第 `i` 只股票的杠杆效应，即其对底层市场风险变化的敏感度。若某股票的 `β̂_i` 等于（resp. 小于）市场贝塔 `β_m`（或其经验对应值 `β̂_m = (μ̂_m − r_f) / σ̂_m`），则该股票被称为 *有效*（resp. *无效*）；同样，若 `β̂_i > β̂_m`，则该股票被认为比市场组合更有效。最后，确定性等价定价公式常被用于评估公司的（单期）未来项目，其由 CAPM 推导而来。为计算具有随机终端回报 `Q` 的项目的现值 `P`，我们将 CAPM 应用于其回报率 `r = (Q − P) / P` 的期望：

[(10.3)](#c10.xhtml#R_c10-disp-0003) `𝔼(r) = (𝔼(Q) − P) / P = r_f + β(μ_m − r_f).`
