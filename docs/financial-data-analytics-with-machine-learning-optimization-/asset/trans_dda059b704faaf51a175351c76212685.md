## 混合类型、缺失值和数据缩放

在实践中，数据集通常包含缺失值和混合类型的变量。处理缺失数据最简单的方法是删除所有不完整的观测值。Python 函数 `dropna()` 和 `R` 函数 `complete.cases()` 可用于选择所有完整的观测值并排除其他观测值。然而，仅使用完整的观测值可能会放弃大量隐藏信息，更严重的是，会导致子样本的有偏抽样，尤其是当缺失机制是 *missing not at random* 时。处理它们的一种更好但更复杂的方法是继续计算距离，但仅使用两个观测值中都可用的变量，或者我们可以插补缺失的观测值。

另一个问题是，变量的范围可能差异很大，使用原始尺度不可避免地会给大数值变量分配更多权重。因此，在进行聚类分析之前，我们应该将变量重新缩放到 ![left-bracket 0 comma 1 right-bracket](images/c14-i0147.png)<math display="inline" overflow="scroll"><mo stretchy="false">\[</mo><mn>0</mn><mo>,</mo><mn>1</mn><mo stretchy="false">\]</mo></math> 区间。
