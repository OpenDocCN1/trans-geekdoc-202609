
It is known that if the objective function `f` is strictly convex, then under some mild conditions the MM algorithm will converge to the unique minimum point (if it exists) no matter the initial seed `x₀` chosen. If convexity is lacking, but all stationary points are isolated, then the MM algorithm will converge to one of them, depending on the position of the initial guess. The performance and the rate of convergence of the MM algorithm depend on how well the surrogate function `g(·, x⁽ᵗ⁾)` approximates `f`, and how easy the minimization of the surrogate function is. In what follows, we highlight several commonly used approaches to construct appropriate surrogate functions. More detailed discussions can be found in [18](#c06.xhtml#c06-bib-0018), [19](#c06.xhtml#c06-bib-0019), [20](#c06.xhtml#c06-bib-0020) and the references therein.

Firstly, suppose that the objective function `f: ℝ₊ᵖ → ℝ` has the form `f(x) := h(cᵀx)` for some `c ∈ ℝ₊ᵖ` and a convex function `h: ℝ₊ → ℝ`. By Jensen's inequality, given the current iterate `x⁽ᵗ⁾ ∈ ℝ₊ᵖ`,

```
f(x) = h(cᵀx) = h(∑ᵢ₌₁ⁿ (cᵢxᵢ⁽ᵗ⁾)/(cᵀx⁽ᵗ⁾) · (cᵀx⁽ᵗ⁾/xᵢ⁽ᵗ⁾)xᵢ) ≤ ∑ᵢ₌₁ⁿ (cᵢxᵢ⁽ᵗ⁾)/(cᵀx⁽ᵗ⁾) h((cᵀx⁽ᵗ⁾/xᵢ⁽ᵗ⁾)xᵢ),
```
