

回顾从第 `j+1` 个检查窗口开始的历史滚动最低价格 `m̃_{s,j} := min_{s-T+j ≤ τ ≤ s} S_τ`，其中 `j = 0, ..., T`。如果存在 `j = 0, ..., T` 使得以下两个条件同时满足，则在第 `s` 天进行买入操作：

1. (B1) 要么 `S_s > q m̃_{s,j}` 且 `S_{s-1} < q m̃_{s,j}`，要么 `S_s < q m̃_{s,j}` 且 `S_{s-1} > q m̃_{s,j}`，但不能两者都成立；且
2. (B2) `s` 落在该检查窗口对应的四种可能情况中恰好一种的 *action period* 中（见 [7.39](#c07.xhtml#c07-disp-0063)）。

下面，以初始资金 USD `100,000` 为例，我们提出以下三种基于 Kelly 比例的候选策略，每笔交易的赔率各不相同：

1. 策略 `K_IC`：每笔交易使用相同的资金量（USD `100,000`）；
2. 策略 `K_AC`：每笔交易使用所有累积资金；
3. 策略 `K_L`：每笔交易使用杠杆调整后的累积资金。具体来说，在第 `s` 天，杠杆 `k_s` 定义为：

   ```
   k_s := min{max{μ_s / (σ_s √256), -4}, 5}
   ```

   每笔交易使用的金额为 `(0.8 + 0.2 k_s) Π_s`，其中 `Π_s` 是第 `s` 天的累积资金，而需借入的额外金额 `min{0.2(k_s - 1)Π_s, 0}` 的年利率为 10%，将在下文进一步说明。
