

让我们假设禁止卖空，并且当两项投资的预期收益率相同时，投资者是风险厌恶的，他们更倾向于选择风险较低的那一项。在这种情况下，投资组合只是 `p` 种资产的组合，其非负权重向量 `ω ∈ [0, 1]^p` 的总和为 1（不允许卖空），投资者必须选择其期望的投资组合，使其预期投资组合收益率至少为 `μ_P`。等价地，投资组合应满足 `μ_P ≤ μ^⊤ω`，但风险水平尽可能低，风险由投资组合收益率的方差来衡量。Markowitz [[16](#c11.xhtml#c11-bib-0016)] 将最优投资组合选择问题制定为一个 QP 问题：

(11.45)
```
minimize ω ∈ [0, 1]^p 1/2 ω^⊤ Σ ω,
```

(11.46)
```
subject to
    i) μ^⊤ω ≥ μ_P;
    ii) 1^⊤ω = 1;
    iii) ω ≥ 0,
```

其中，`1 ∈ ℝ^p` 是一个值为 1 的列向量，`0 ∈ ℝ^p` 是一个值为 0 的列向量。读者也可以参考 [[7](#c11.xhtml#c11-bib-0007)] 以了解更多关于投资组合选择的讨论。

对于这个问题，带有拉格朗日乘数 `λ₁ ≥ 0`、`λ₂ ∈ ℝ` 和 `λ₃ ≥ 0` 的拉格朗日函数 `L(ω, λ₁, λ₂, λ₃)` 由以下公式给出：

```
L(ω, λ₁, λ₂, λ₃) = 1/2 ω^⊤ Σ ω + λ₁(μ_P − μ^⊤ω) + λ₂(1^⊤ω − 1) + λ₃(0 − ω).
```
