
# 正态性检验方法

## Q-Q 图与 Shapiro–Wilk 检验

正态 Q-Q 图是检验单变量正态性的图形方法，且非常有效。除此之外，还有其他正式的统计检验方法用于检验正态性；例如，该 Q-Q 图可以正式形式化为 *Shapiro–Wilk* (SW) 检验 [\[15\]](#c03.xhtml#c03-bib-0015)，这是一种检验样本是否服从正态分布的正式方法。相应的检验统计量是 `W = (Σ aᵢ x₍ᵢ₎)² / Σ (x̄ - x₍ᵢ₎)²`，其中 `x₍ᵢ₎` 是 `x₁, ..., xₙ` 的有序样本值，行向量 `a = mᵀ V⁻¹ / c`，其中欧几里得 2-范数 `c = ||mᵀ V⁻¹||₂ = (mᵀ V⁻¹ V⁻¹ m)¹ᐟ²`，向量 `m` 是从标准正态分布中抽取的 iid 随机变量的序统计量的期望值列向量；最后，`V` 是这些正态序统计量的协方差矩阵；更多讨论请参见 [Appendix 3.A.1](#c03.xhtml#c03-sec-0009)。在 [Programme 3.3](#c03.xhtml#c03-gra-0003) 中通过 Python（resp. [Programme 3.4](#c03.xhtml#c03-gra-0004) 通过 `R`），我们说明了该检验在 HSBC、CLP 和 CK 股票日算术收益率上的应用。然而，使用 Shapiro–Wilk 检验的一个缺点是找到 `m` 和 `V` 的精确理论值并不那么直接。还有其他更简单的正态性检验方法可用。

## Kolmogorov–Smirnov 检验

*Kolmogorov–Smirnov* (KS) 检验可用于检验随机样本是否来自特定分布。检验统计量是 `Dₙ = supₓ |Fₙ(x) - F(x)|`，其中 `Fₙ(x)` 和 `F(x)` 分别是基于容量为 `n` 的随机样本的经验分布函数和理论分布函数。注意，`√n Dₙ` 的分布收敛于标准化 *Brownian bridge* 的绝对最大值分布。
