

那么，共有 `m_{l,1}^{(i)}` 个类别时，关于它们在两个子集中的分布，总共有 `3^{m_{l,1}^{(i)}}` 种可能的场景。但是，以下两种场景不应计入：(i) 所有 `m_{l,1}^{(i)}` 个类别仅出现在 `X_{l+1,1}^{(i)}` 中；以及 (ii) 所有 `m_{l,1}^{(i)}` 个类别仅出现在 `X_{l+1,2}^{(i)}` 中，因为实际上并未进行分类。具体来说，子集 `X_{l+1,1}^{(i)}` 或 `X_{l+2,1}^{(i)}` 中有一个为空，而另一个则等于 `X_{l,1}^{(i)}`。因此，可能的场景总数为 `3^{m_{l,1}^{(i)}} - 2`，正如所声称的那样。

# CHAPTER 13

分类与回归树及随机森林

## 13.1 分类（决策）树

在 [Chapter 10](#c10.xhtml) 中介绍的二元逻辑回归和多元 Logit 模型旨在基于特征变量的线性组合对观测值进行分类。对于普通从业者，尤其是出于监管目的，这些模型可能难以解释，因此需要更透明且简单的分类规则。*分类（决策）树* 是一种贪心算法方法，用于生成一组简单规则，以机械地将观测值分类到不同类别中。它在数据挖掘中非常有用，并具有许多潜在的金融应用。例如，它可以用于制定信贷审批决策的简单规则以及确定金融压力。作为监督学习中最流行的方法之一，分类树最初由 Breiman、Friedman、Olshen 和 Stone 在其享有盛誉的著作 [\[1\]](#c13.xhtml#c13-bib-0001) 中开发；从 1980 年开始，它一直是活跃的研究领域，相关进展可见于 [\[8\]](#c13.xhtml#c13-bib-0008)。自 21 世纪初以来，它在各个学科中得到更广泛的应用，包括但不限于金融和保险领域；例如，请参见 [\[6](#c13.xhtml#c13-bib-0006), [7](#c13.xhtml#c13-bib-0007), [12](#c13.xhtml#c13-bib-0013), [15](#c13.xhtml#c13-bib-0017), [18\]](#c13.xhtml#c13-bib-0020)。
