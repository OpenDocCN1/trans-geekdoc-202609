

对于固定的 `p`，我们的任务是近似矩阵 `P` 和 `Q`，这两个矩阵包含总共 `(m + n) × p` 个未知参数。大小为 `m × n` 的乘积矩阵 `P Q^T` 可以与存储在 `R` 中的订阅者评分进行比较。虽然 `R` 是稀疏的（因为每个订阅者只查看或评分了整个电影数据库的一小部分），但我们的算法旨在最小化已知评分 `r_i,j` 与使用 `∑(k=1 to p) p_i,k q_j,k` 预测的相应评分之间的平均偏差。换句话说，目标是最小化以下均方误差（MSE）：

(9.9)
```
J(p_i,k, q_j,k; 1 ≤ i ≤ m, 1 ≤ j ≤ n, 1 ≤ k ≤ p) := ∑(i=1 to m) ∑(j=1 to n) (r_i,j - ∑(k=1 to p) p_i,k q_j,k)^2
= ∑(i=1 to m) ∑(j=1 to n) (r_i,j - p_i^T q_j)^2 = tr((R - R̂)^T (R - R̂)) = ||R - R̂||_F,
```
