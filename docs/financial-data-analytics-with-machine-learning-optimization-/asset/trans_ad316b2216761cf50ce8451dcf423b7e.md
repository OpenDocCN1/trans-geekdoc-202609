

让我们解释通过主成分分析（PCA）实现人脸识别的具体过程。数据集 `X` 是一个 `(h · w) × n` 矩阵，其中每个观测值 `x_i` 是一个形状为高度 `h` 乘以宽度 `w` 的人脸图像，被展平为长度为 `h · w` 的一维向量。特征变量，即人脸图像的各个像素，在局部上高度相关，因为像素的邻域通常具有相似的值，因为它们共享相似的颜色。因此，可以采用 PCA 进行降维。在人脸识别的背景下，为了分类，我们计算查询人脸图像 `x_*` 与数据库 `x_1, …, x_n` 及其对应标签 `y_1, …, y_n` 之间的欧几里得距离。假设选择了前 `m` 个主成分，其对应的载荷为 `H^(1) = (h_1, …, h_m) ∈ R^(h · w) × m`，则该查询人脸图像的预测标签由 `y_* = y_k` 给出，其中

```
k = arg min_{i = 1, …, n} d((H^(1))^⊤ x_i, (H^(1))^⊤ x_*) = arg min_{i = 1, …, n} Σ_{j = 1}^m (h_j^⊤ (x_i - x_*))^2.
```

这种方法论实际上与将在 [第 14 章](#c14.xhtml) 中讨论的 `K`‐最近邻技术共享相同的哲学。 *AT&T 人脸数据库*

在 `R` 中，`pixmap` (PIXel MAPs) 库用于处理位图图像。特别是，`read.pnm()` (Portable Any Map) 函数被采用来读取图像；请参见 `R` 环境中 [程序 9.18](#c09.xhtml#c09-sec-3018) 中的相应实现。
