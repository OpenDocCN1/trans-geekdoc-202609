
Another natural variant is to decide the update of each single parameter individually, and to utilize the updated parameter values immediately to infer the update of the next parameter component. This alternative approach is the well-known `Gibbs Sampling`; see [\[3](#c06.xhtml#c06-bib-0003), [26\]](#c06.xhtml#c06-bib-0026) for more detailed discussions. As before, we let `x₁, …, xₙ` be `n` independent realizations from the same distribution with `r` unknown parameters, `θ = (θ₁, …, θᵣ)ᵀ`. For each parameter `θᵢ`, we specify a one-dimensional conjugate prior `πᵢ(θᵢ)` together with the likelihood function `L(x₁, …, xₙ | θ₁, …, θᵢ₋₁, θᵢ, θᵢ₊₁, …, θᵣ)` (being conjugate to this prior), where `θ₁, …, θᵢ₋₁, θᵢ₊₁, …, θᵣ` are treated as given.
