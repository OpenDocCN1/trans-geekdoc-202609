
# 梯度下降法

梯度下降法的流行源于其实现简单且具有良好的收敛性。事实上，可以证明，如果损失函数 `L(θ): R^q → R` 是凸且可微的，并且具有 `K`-Lipschitz 梯度，即 `||∇L(θ₁) − ∇L(θ₂)||₂ ≤ K||θ₁ − θ₂||₂` 对于任何 `θ₁, θ₂ ∈ R^q` 成立，那么在固定学习率 `η ≤ 1/K` 下，有

[(11.18)](#c11.xhtml#R_c11-disp-0041)

```
L(θ⁽ᵗ⁾) − L(θ*) ≤ ||θ⁽⁰⁾ − θ*||₂² / (2ηt), t = 1, 2, ...
```

其中 `θ*` 是最小值。这意味着梯度下降法可以保证以 `O(1/t)` 的速率收敛，其中 `t` 是迭代次数。如果进一步假设 `K` 满足更强的正则性条件，例如强凸性，则收敛速度可以得到改善。
