从图中观察到，当 `n` 较小时，预测区间带波动较大。系数估计 `β̂` 对靠近（或远离）观测到的 `xₙ` 的 `x` 值具有较高（或较低）的置信度，从而导致更窄（或更宽）的预测区间。同时，随着样本量 `n` 的增加，区间带在 `x ∈ (0, 1)` 上均匀收窄至真实底层值。

## 12.4 BAYESIAN CLASSIFIERS

到目前为止，我们只提到了线性贝叶斯模型。现在我们转向非线性贝叶斯模型。贝叶斯方法在监督学习的许多分类算法中起着至关重要的作用，分类阈值是给定特征向量取观测值时某个标签的条件概率，使用贝叶斯定理（1.10）计算。它在各个领域有着广泛的应用，例如文本文档分类和垃圾邮件过滤器。
