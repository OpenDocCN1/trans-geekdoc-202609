
## 5.2.2.1 Multiple Control Variates

We next consider the high-dimensional setting: let `y` be a `p`-dimensional random vector with a known expectation `μ_y ∈ R^p`. For any `b ∈ R^p`, the random variable `z := x + b^T(y - μ_y)` is an unbiased estimator of the unknown `θ := E(x)`. By similar arguments to the above, we consider the variance of this estimator:

[(5.3)](#c05.xhtml#R_c05-disp-0031)
```
Var(z) = Var(x + b^T(y - μ_y)) = Var(x) + b^T Var(y) b + 2 b^T Cov(x, y),
```

where we have used the short-handed notation

```
Cov(x, y) := (Cov(x, y_1), ..., Cov(x, y_p))^T.
```

Differentiating ([5.3](#c05.xhtml#c05-disp-0031)) with respect to `b` and setting it to zero vector yields

```
∇_b Var(z) = 2 Var(y) b + 2 Cov(x, y) = 0 at b* := -Var(y)^{-1} Cov(x, y).
```
