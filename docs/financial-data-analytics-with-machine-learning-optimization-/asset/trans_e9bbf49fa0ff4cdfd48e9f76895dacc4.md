```
m̂ = (Σᵢ Kernel(x, xᵢ) / Σⱼ Kernel(x, xⱼ)) tᵢ.
```

在更通用的 `Kernel Regression`（将在下一节中介绍）的背景下，我们将看到该公式具有与核回归中特定场景的著名的 `Nadaraya–Watson estimator` 相同的形式。为此，尽管核回归不包括 `K`‐NN 回归作为特例，但它确实试图解决后者的上述缺点。

## (III) 增强算法

`K`‐NN 的另一个特征是其对噪声的敏感性。样本中的孤立点可能对分类和回归结果产生剧烈影响。这些异常值可以通过 *a priori* 过滤和选择程序来消除。同时，`K` 的选择也可能显著影响结果，如 [Figure 14.8](#c14.xhtml#c14-fig-0008) 所示。为了弥补这些缺陷，让我们对原始的 `K`‐NN 算法引入一些修改。

### 集成（学习）方法

一般来说，集成方法旨在通过考虑多个独立模型来提高学习模型的性能。输出通常是从这些模型集合的投票结果中推断出来的。根据分配给每个模型的权重，如果所有模型共享相同的权重，则投票称为 *uniform voting*，否则称为 *weighted voting*。这一一般概念也可以应用于 `K`‐NN，用于分类或回归。我们首先随机选择多个特征子集，并相应地针对新添加的观测值拟合 `K`‐NN 模型。分类（resp. 回归）的预测标签随后由这些模型输出的投票（resp. 加权平均）来确定。这也被称为 *Random Subspace Ensemble* `K`‐NN*; 有关详细信息，另见 [\[12\]](#c14.xhtml#c14-bib-0012)。

### 核方法

这里的核方法（参见 [\[25\]](#c14.xhtml#c14-bib-0025)）是指在 [Section 11.2](#c11.xhtml#c11-sec-0003) 中讨论的径向基函数的核技巧，并应与 `K`‐NN 回归或核回归中的核函数区分开来。回顾在核技巧下，每个样本 `x ∈ ℝᵖ` 都被映射到更高维的特征空间，即 `ℝᵠ`（其中 `q > p`），以解开重叠的簇，希望在 `ℝᵠ` 中实现样本的线性可分性。
