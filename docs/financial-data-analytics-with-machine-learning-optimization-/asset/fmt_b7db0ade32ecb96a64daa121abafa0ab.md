
注意，对于每个新的 `t` 值，我们必须在第 1 步中生成一组新的 `p` 个正态随机数。一旦我们有了 `p` 个模拟样本路径 `u(i, t+1), ..., u(i, t+K)`，我们就可以通过取相应收益的适当平均值来评估这些样本路径中不同衍生品的价格，每个收益都沿着一条模拟样本路径进行评估。

其他模型可以以类似方式模拟。例如，我们可以将标准化的 `t(ν)` 分布与 GARCH(1, 1) 模型结合：`u(i) / σ(i) ~ t(ν)` 和 `σ(i)^2 = ω + α u(i-1)^2 + β σ(i-1)^2`。这被称为 `t`-GARCH(1, 1) 股票价格模型。或者，也可以使用 `EWMA(λ)` 模型，而不是 GARCH(1, 1) 模型，来同化波动率的演变动态。

