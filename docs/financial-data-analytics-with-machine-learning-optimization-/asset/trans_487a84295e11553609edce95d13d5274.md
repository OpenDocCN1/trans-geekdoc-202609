

## 5.2.2.1 多控制变量

接下来我们考虑高维情况：设 `y` 为已知期望 `μ_y ∈ R^p` 的 `p` 维随机向量。对于任意 `b ∈ R^p`，随机变量 `z := x + b^T(y - μ_y)` 是未知 `θ := E(x)` 的无偏估计量。根据与上述类似的论证，我们考虑该估计量的方差：

[(5.3)](#c05.xhtml#R_c05-disp-0031)
```
Var(z) = Var(x + b^T(y - μ_y)) = Var(x) + b^T Var(y) b + 2 b^T Cov(x, y),
```

其中我们使用了简写记号

```
Cov(x, y) := (Cov(x, y_1), ..., Cov(x, y_p))^T.
```

对 ([5.3](#c05.xhtml#c05-disp-0031)) 关于 `b` 求导并令其等于零向量，可得

```
∇_b Var(z) = 2 Var(y) b + 2 Cov(x, y) = 0 at b* := -Var(y)^{-1} Cov(x, y).
```
