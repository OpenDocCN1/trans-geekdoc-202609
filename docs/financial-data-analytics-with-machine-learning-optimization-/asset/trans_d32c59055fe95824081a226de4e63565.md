## 14.1.1 K-Means 聚类的变体

### (I) 不同的距离 / 不相似度度量

K-Means 聚类以及其他聚类方法都基于观测值之间的距离（或 `dis-similarity`）度量。因此，正确定义任意两个观测值之间的度量非常重要。考虑到我们数据集中变量的不同类型，这些度量也应以量身定制的方式定义。在下文中，为了方便起见，首先假设我们的数据集中有 `p` 个相同类型的变量，样本量为 `n`，第 `i` 个观测值 `x_i = (x_i1, ..., x_ip)^T`，`i = 1, ..., n`。在混合变量类型的情况下，我们只需将不同类型的不同度量组合起来即可。

#### 连续变量

如果所有变量都是连续的，通常使用以下 `q`-范数作为距离度量：

```
d_q(x_i, x_j) := ||x_i - x_j||_q = (Σ_{k=1}^p (x_ik - x_jk)^q)^(1/q).
```

这包括众所周知的 `Euclidean distance` (`q = 2`)、`Manhattan distance` (`q = 1`) 和 `Minkowski distance` (`1 ≤ q ≤ ∞`) 作为特例。

#### 序数变量

如果所有变量都是序数的，我们可以分别对每个变量的 `n` 个观测值进行排序，然后将观测值重新缩放到 `[0, 1]`，如下所示：

```
z_ik = (r_ik - 1) / (M_k - 1), i = 1, ..., n, k = 1, ..., p,
```

其中 `r_ik` 是第 `i` 个观测值的第 `k` 个分量变量的排名，`M_k` 是第 `k` 个变量可能取值的数量，分子中的额外项 `-1` 是为了确保排名最低为 1 的观测值可以重新缩放到 0。经过重新缩放变换后，我们可以将分量变量视为连续变量，并使用上述提到的 `p`-范数来测量它们的距离。
