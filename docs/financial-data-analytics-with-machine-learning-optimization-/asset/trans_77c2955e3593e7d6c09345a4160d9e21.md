

这里，`x` 被 `M > 1` 上界限制，使得对 `k ∈ K_M` 的求和仅从 0 到 `⌊log₁₀ M⌋ - 1`，即求和是针对 [Figure 4.1](#c04.xhtml#c04-fig-0001) 中所有 `⌊log₁₀ M⌋` 个蓝色空框进行的，并且当 `z` 落在区间 `(⌊log₁₀ M⌋, ⌈log₁₀ M⌉]` 时，还有一个额外的余项，即 [Figure 4.1](#c04.xhtml#c04-fig-0001) 中的红色阴影框。这些蓝色空框代表了 `k = 0, ..., ⌊log₁₀ M⌋ - 1` 时的区间 `(log₁₀ n + k, log₁₀ (n + 1) + k)`。请注意，任何位于 `(⌊log₁₀ M⌋, ⌊log₁₀ M⌋ + 1)` 中的可能红色阴影框都不会对求和产生贡献，且项 `ν_{n, remainder}` 的大小可能小于蓝色空框。
