

为此，我们首先引入所有人工聚类的不同可能分组：令 `B_k := B_aδ(μ|_k)` 和 `F_l = {x_i | F(x_i) = l}`。利用这些，我们定义

1. `A_1`: 对于每个 `l ∈ A_1`，人工聚类 `F_l` 包含一个球中的所有点，但不包含任何其他球中的点，即，恰好存在一个 `k = 1, ..., K`，使得 `B_k ⊆ F_l`，但对于任何 `k' ≠ k`，`B_k' ∩ F_l = ∅`。

2. `A_2`: 对于每个 `l ∈ A_2`，人工聚类 `F_l` 包含一个球中的部分点（但不是所有点），且不包含任何其他球中的点，即，恰好存在一个 `k = 1, ..., K`，使得 `B_k ∩ F_l = ∅` 但 `B_k ⊈ F_l`，而对于所有 `k' ≠ k`，`B_k' ∩ F_l = ∅`。

3. `A_3`: 对于每个 `l ∈ A_3`，人工聚类 `F_l` 包含来自多个球 `B_k` 的点。

4. `A_4`: 对于每个 `l ∈ A_4`，人工聚类 `F_l` 与所有球 `B_k` 互不相交。
