
1. `∇_A tr(AB) = B^T`

2. `∇_A tr(ABA^T C) = CAB + C^T A B^T`

3. `∇_A^T tr(ABA^T C) = B^T A^T C + B A^T C`

We prove only the first statement, while the second and third statements can follow directly from the chain rule. Recall that the components of `A` and `B` are denoted as `(a_ij)` and `(b_ij)`, respectively. Since

```
tr(AB) = Σ_{l=1}^p Σ_{k=1}^p a_lk b_kl,
```

we then have, for any `i, j = 1, ..., p`,

```
∂tr(AB)/∂a_ij = ∂/∂a_ij Σ_l Σ_k a_lk b_kl = b_ji,
```

which confirms the assertion of Property 12.
