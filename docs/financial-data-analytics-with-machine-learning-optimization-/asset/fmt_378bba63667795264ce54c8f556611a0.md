```

```

```
∂E/∂νₖ₀ = ∂E/∂oₖ · ∂oₖ/∂νₖ₀ = ∂E/∂o'ₖ · ∂o'ₖ/∂oₖ · ∂oₖ/∂νₖ₀ = −(yₖ − o'ₖ).
```
