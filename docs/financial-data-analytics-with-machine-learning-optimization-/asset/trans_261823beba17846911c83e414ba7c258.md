

*定理 4.1 的证明*：令 `x₁, …, xₖ` 为 `[0, 1)` 上的独立同分布连续随机变量，其共同密度为 `f ∈ L²[0, 1]`，并考虑 `w := Σᵢ₌₁ᵏ xᵢ (mod 1)`。显然，`w` 也是 `[0, 1)` 上的连续随机变量，其密度函数 `h` 根据 [Lemma 4.2](#c04.xhtml#c04-fea-0008) 的傅里叶系数为 `ĥ(n) = (f̂(n))ᵏ`，其中 `n ∈ ℤ`。为了证明 `w` 在 `k → ∞` 时趋近于 `[0, 1)` 上的均匀分布，只需证明 `h → 1` 在 `L²[0, 1]` 上的 `L²`-范数中收敛。确实，根据 Parseval 恒等式：

```
‖h − 1‖₂² = ∫₀¹ (h(t) − 1)² dt = Σₙ≠₀ |ĥ(n)|² = Σₙ≠₀ |f̂(n)|²ᵏ = Σₙ≠₀ |f̂(n)|² |f̂(n)|²ᵏ⁻² ≤ (supₙ≠₀ |f̂(n)|)²ᵏ⁻² · Σₙ≠₀ |f̂(n)|².
```
