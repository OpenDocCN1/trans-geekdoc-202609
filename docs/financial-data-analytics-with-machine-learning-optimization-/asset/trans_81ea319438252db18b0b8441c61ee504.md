

此外，欧洲看涨期权的 `delta` 预计为正，因为看涨期权的价格随标的资产当前价格的上涨而上涨。当 `S_t << K`，即当看涨期权远处于虚值时，看涨期权大多毫无价值，其 delta 接近 0。另一方面，管理人员可以构建一个具有正 delta 的投资组合，以押注标的资产价格的更大幅度上涨。更具体地说，要计算在 Black–Scholes 框架下欧洲看涨期权的 Greeks，我们首先回顾其著名公式（另请参见 [示例 5.6](#c05.xhtml#c05-fea-0026)）：在时间 `t` 时，其价格为

`C_t = S_t Φ(d_+) - e^(-r(T-t)) K Φ(d_-)`
