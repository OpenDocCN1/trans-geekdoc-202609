

要理解感知机的工作原理，我们首先确定一些符号。数据集中第 `i` 个数据点表示为 `(x_i, y_i)`，其中 `x_i = (x_i0, x_i1, ..., x_ip)^⊤`，且 `x_i0 = 1`，而 `(x_i1, ..., x_ip)^⊤ ∈ R^p` 是一个 `p` 维特征向量；`y_i = +1` 或 `-1`，表示该数据点的标签。感知机模型旨在学习一个线性函数 `f: R^(p+1) → R`，若 `f(x_i) > 0`，则将 `x_i` 分类为 `+1` 类（预测标签 `ŷ_i = 1`）；若 `f(x_i) < 0`，则分类为 `-1` 类（预测标签 `ŷ_i = -1`）。若 `f(x_i) = 0`，则视为未确定，这种情况在实际中几乎不会发生。换言之，学习器为 `f(x) = ω^⊤ x`，其中 `ω` 是待估计的参数向量。若 `y_i = 1` 且 `f(x_i) > 0`，或 `y_i = -1` 且 `f(x_i) < 0`，则数据点 `(x_i, y_i)` 被正确分类。在这两种情况下，`f(x_i) · y_i > 0`。同样，若 `f(x_i) · y_i < 0`，则数据点 `(x_i, y_i)` 被误分类。
