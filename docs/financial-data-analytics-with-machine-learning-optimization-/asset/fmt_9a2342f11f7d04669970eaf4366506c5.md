## 11.A.2.4 Quadratic Programming in Markowitz Portfolio Selection

Consider a financial market with `p` financial assets, and let their daily logarithmic returns on day `t` be `r_t`. These returns are often assumed to be iid random vectors following a `p`‐variate Gaussian distribution with a mean vector `μ ∈ ℝ^p` and a covariance matrix `Σ ∈ ℝ^(p×p)`:

`r_t ~ iid N_p(μ, Σ), for t = 1, 2, ...`
