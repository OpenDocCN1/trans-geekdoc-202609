## NOTES

### 1. PCM

PCM 是信号处理中的一种方法，用于以数字方式表示模拟信号，其中模拟信号首先被采样，然后每个样本由预定义的 bin 集合离散化。最后，离散化的样本被编码为二进制代码。

### 2. NP‐hard Problem

在 `computational complexity theory` 中，NP-hard（非确定性多项式时间难）问题的特征如下：如果为 NP-hard 问题开发出多项式时间算法，那么对于所有其他可以在多项式时间内检查解的问题，我们也可以开发多项式时间算法来求解该问题。NP-hard 问题的典型示例是 `Travelling Salesman problem`。

### 3. Infinity Norm

当 `q = ∞` 时，`d∞(xᵢ, xⱼ) := max(k=1,...,p) |xᵢₖ − xⱼₖ|`。

### 4. Laplacian Matrix

实际上，而不是相似矩阵 `A`，其一般形式的问题是寻找其对应的拉普拉斯矩阵 `L := D − A` 的最小特征值，其中 `D` 是度矩阵。在当前情况下，将样本点集合视为完全图，我们有 `D = p · I`，因此一般问题归结为寻找 `A` 的最大特征值。通过直接考虑 `L`，一般问题确实与 `Lagrangian mechanics` 领域中著名的 `Laplace spring‐mass system` 相关联。

### 8. Lazy Learning

惰性学习方法在查询到达后才开始处理输入。确实，如下文所述，`K`‐NN 的每个查询只需要一个小邻域的观测值，即与新添加观测值最接近的 `K` 个。读者可参阅 `[1](#c14.xhtml#c14-bib-0001)` 了解更多详情。

### 9. Python and R Functions

据我们所知，也许 Python 函数 `KNeighborsClassifier()` 包含一些调整数据结构的高级方法，以减少查找最近邻所需的计算次数，而 `R` 函数 `knn()` 倾向于暴力搜索，因此必须计算测试数据点到所有现有数据点的距离。

### 10. Statistical Approximation

这是统计学中常用的一种技术，即未知分布的特征（如期望值或方差）可以根据未知分布的样本（如样本均值和样本方差）的经验对应物进行近似；有关原理的详细讨论，请参见 `[23](#c14.xhtml#c14-bib-0023)`。

### 12. Clustering Stability

对于固定的 `L`，当样本量足够大时，算法获得的最优聚类簇在形状上将变得稳定，因此属于簇 `l` 的任何点都具有严格为正的概率 `p·l`；请参见 `[22](#c14.xhtml#c14-bib-0022)`。

### 13. K-means Clustering

在 `K`‐means 聚类中，由于其最小化 MSE 的特性，我们通常有 `A₄ = ∅`；确实，分区应在数据点更密集的位置进行，而不是在完全没有点的位置，以尽可能减少 MSE。然而，对于其他聚类算法，情况可能并非如此。
