$$q_{\text{Tukey}, i j} = \frac{\bar{x}_{i}^{(1)} - \bar{x}_{j}^{(1)}}{S_p \sqrt{\frac{1}{N_i} + \frac{1}{N_j}}}, \quad \text{for all } i \neq j$$

其中 $\bar{x}_{i}^{(1)}$ 和 $\bar{x}_{j}^{(1)}$ 分别是组 $i$ 和组 $j$ 的样本均值。

接下来，对于任意一对 $i \neq j$，统计量 ([2.1](#c02.xhtml#c02-disp-0002)) 在 $H_0$ 下服从 $t$-分布。由于组内样本具有独立同分布正态性，对于每个组 $k = 1, \dots, |C|$，样本均值服从正态分布，即 $\bar{x}_{k}^{(1)} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{N_k}\right)$，而缩放后的样本方差服从卡方分布，即 $\frac{(N_k - 1)S_k^2}{\sigma^2} \sim \chi^2_{N_k - 1}$。正态性假设保证了这两个统计量的独立性。此外，由于组间样本独立，组 $i$ 和组 $j$ 的各自样本均值之差也服从正态分布：

$$\bar{x}_{i}^{(1)} - \bar{x}_{j}^{(1)} \sim \mathcal{N}\left(0, \sigma^2 \left(\frac{1}{N_i} + \frac{1}{N_j}\right)\right);$$
