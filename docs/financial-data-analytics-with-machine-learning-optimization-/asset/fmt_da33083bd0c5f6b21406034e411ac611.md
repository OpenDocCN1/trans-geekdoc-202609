### 1.4.3 Wishart Distribution

The Wishart distribution is a multivariate extension of the chi-square distribution. Recall Property 2 of [Subsection 1.4.1](#c01.xhtml#c01-sec-0010), namely if `x₁, …, xₙ` are iid distributed as `N(μ, σ²)`, then

```
∑(i=1 to n) ((xᵢ − x̄)² / σ²) = ((n − 1)s² / σ²) ~ χ²(n − 1)
```
