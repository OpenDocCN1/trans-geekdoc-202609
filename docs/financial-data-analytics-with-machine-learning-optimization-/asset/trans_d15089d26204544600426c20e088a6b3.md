

特别是，当 `Σ_P = Σ_Q` 时，从 `Q` 到 `P` 的相对熵在 `μ_P` 和 `μ_Q` 越远时会变得更大。另一方面，当 `μ_P = μ_Q` 时，每当 `Σ_P ≠ Σ_Q` 时变化的方向就不那么直接了。考虑方差为 `σ_P^2` 和 `σ_Q^2` 的一维情况，以及任意相关系数 `ρ`。从 `Q` 到 `P` 的相对熵则简化为：

```
D(P‖Q) = 1/2 (σ_P^2 / σ_Q^2 - ln(σ_P^2 / σ_Q^2) - 1)
```

如果比率 `σ_P^2 / σ_Q^2` 远离 1，则该值会变得更大。

### ii) 交叉熵：

两个离散分布 `P` 和 `Q` 之间的 *交叉熵* 定义为

[(13.8)](#c13.xhtml#R_c13-disp-0029)
```
H(P, Q) := H(P) + D(P‖Q)
```

其中 `H(P) := -∑_{x ∈ 𝒳} P(x) ln P(x)` 表示 `P` 的重新缩放熵。通过简化 ([13.8](#c13.xhtml#c13-disp-0029))，一个等价定义是：

```
H(P, Q) = -∑_{x ∈ 𝒳} P(x) ln Q(x).
```

只要 `P` 是固定的，`H(P)` 就是一个与 `Q` 无关的常数，因此相对熵与交叉熵之间存在等价关系。对于连续分布，可以通过将求和替换为积分来定义类似的熵概念。在实际应用中，交叉熵通常作为深度学习中的目标函数，用于衡量标签的样本分布与预测分布之间的相似性。
