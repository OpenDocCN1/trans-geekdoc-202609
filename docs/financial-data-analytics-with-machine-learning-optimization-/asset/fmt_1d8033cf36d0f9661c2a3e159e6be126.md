
A set `X ⊆ ℝᵖ` is said to be *convex* if for any two points `x₁, x₂ ∈ X`, the line segment joining them is still contained in `X`, that is, `αx₁ + (1 − α)x₂ ∈ X` for any `α ∈ (0, 1)`. A set `X ⊆ ℝᵖ` is said to be *compact* if `X` is closed and bounded.

In the proof below, we demonstrate that under the assumptions of [Theorem 11.1](#c11.xhtml#c11-fea-0002), a saddle point `(x₀, y₀)` of `f` always exists, which by definition is a point that satisfies

```
max_{y ∈ Y} f(x₀, y) = f(x₀, y₀) = min_{x ∈ X} f(x, y₀);
```

moreover, the existence of a saddle point in fact implies the validity of ([11.26](#c11.xhtml#c11-disp-0057)):

```
max_{y ∈ Y} min_{x ∈ X} f(x, y) = max_{y ∈ Y} f(x₀, y) = f(x₀, y₀) = min_{x ∈ X} f(x, y₀) = min_{x ∈ X} max_{y ∈ Y} f(x, y).
```

Here, the leftmost expression corresponds to the lower path in blue in [Figure 11.18](#c11.xhtml#c11-fig-0018), while the rightmost term corresponds to the upper path in red in the same figure. Both paths settle at the same point `(x₀, y₀)`. Nevertheless, in general, even if the saddle point of `f` does not exist, the minimax theorem still remains valid.
