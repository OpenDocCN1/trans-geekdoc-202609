
Generally speaking, it is often difficult to obtain an analytic solution to the system ([10.5](#c10.xhtml#c10-disp-0015)). Instead, it is more relevant to solve it numerically. To this point, the `Gauss–Newton method` is one of the commonly used numerical algorithms, and we introduce a modified version here. Readers may refer to [Appendix `10.A.1`](#c10.xhtml#c10-sec-0018) for a formal derivation of the Gauss–Newton method.

Define `n` functions called residuals; `r_i(β) := (y_i - f(x_i; β))^2`, for `i = 1, ..., n`. The minimization of `S(β)` is equivalent to minimizing the following sum of squares:

```
S(β) ∝ 1/2 Σ(i=1 to n) r_i^2(β) = 1/2 ⟨r(β), r(β)⟩.
```
