

在本小节的其余部分，我们讨论马尔可夫链状态空间不可数的情况。在这种情况下，概率测度 `π` 被称为 *静态* 的，如果它相对于转换算子 `í’«` 不变：对于任何 `f ∈ b(S)`，积分 `π(f) := ∫_S f(s) π(ds)` 满足 `π(í’« f) = π(f)`。以下 [定理 6.6](#c06.xhtml#c06-sec-0027) 是 [定理 6.3](#c06.xhtml#c06-fea-0026) 的类比，它断言任何不可约且非周期的具有不可数状态空间的马尔可夫链都存在静态分布。其证明推迟至 [附录 \*6.A.4](#c06.xhtml#c06-sec-0042)。

**定理 6.6 *(具有不可数状态空间的静态分布存在性)*** 在 [假设 6.1](#c06.xhtml#c06-fea-0012) 下，每个具有不可数状态空间的不可约且非周期的马尔可夫链都存在静态分布。

现在，让我们提供 [定理 6.7](#c06.xhtml#c06-fea-0040)，它作为 [定理 6.4](#c06.xhtml#c06-fea-0030) 的类比。它指出具有不可数状态空间的不可约且非周期的马尔可夫链的静态分布是唯一的。我们回顾，一般状态空间的全变距仍可以像在 ([6.21](#c06.xhtml#c06-disp-0079)) 中为离散状态空间定义的那样定义。[定理 6.7](#c06.xhtml#c06-fea-0040) 的证明利用了“*近似耦合*”的思想，以调整 [定理 6.4](#c06.xhtml#c06-fea-0030) 的证明以适应不可数状态空间的情况，可以在 [附录 \*6.A.5](#c06.xhtml#c06-sec-0043) 中找到。

**[定理 6.7](#c06.xhtml#R_c06-fea-0040) *(马尔可夫链收敛定理：连续状态空间)*** 设 `{x_n}` 为具有不可数状态空间 `S` 的不可约非周期马尔可夫链，使得 [假设 6.1](#c06.xhtml#c06-fea-0012) 得到满足。对于 `n ∈ ℕ₀`，设 `μ^(n)` 为 `x_n` 的分布（即，对于 `S` 的任何可测子集 `A`，`μ^(n)(A) = P(x_n ∈ A)`），初始分布为 `μ^(0)`。那么对于 `{x_n}` 的任何静态分布 `π`，`μ^(n)` 在全变距意义下收敛于 `π`，即 `lim_{n→∞} d(μ^(n), π) = 0`。
