
Often in statistical contexts, the state space `S` of a Markov chain is uncountable, say `S = R^p` for example. It is implicitly assumed that `S` is endowed with a suitable topology and an appropriate `σ`-field, together with a measure on the latter. In the case of `S = R^p`, these correspond to the topology of *Borel sets*, the *Borel* `σ`-field on which the *Lebesgue measure* is defined. When the state space is uncountable, the transition probability cannot be expressed in a matrix form. Instead, the Markov property can be formulated by making use of the *transition operator* `T_n: B_b(S) → B_b(S)` defined by

```
T_n f(s) := E[f(x_{n+1}) | x_n = s], for any f ∈ B_b(S), s ∈ S,
```

where `B_b(S)` denotes the collection of all bounded and continuous real-valued functions defined on `S`. Without wading too deep into unnecessary technical details, we implicitly assume sufficient regularity of the transition density (conditional probability given `x_n`) of the pair `(x_n, x_{n+1})` from `x_n` to `x_{n+1}`. With the transition operator, the *Markov property* can be formulated as

```
P(x_{n+1} ∈ A_{n+1} | x_n = s, x_{n-1} ∈ A_{n-1}, ..., x_1 ∈ A_1) = T_n 1_{A_{n+1}}(s),
```
