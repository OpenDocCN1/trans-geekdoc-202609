

# 1. Gumbel–Hougaard copula (Logistic Model)

Gumbel–Hougaard copula 是一种 Archimedean copula，其生成函数为 `ψ(t, θ) = (-ln t)^θ`，同时也是一种极值 copula。通常定义为：

```
C(u₁, …, u_d; α) = exp[−((−ln u₁)^α + … + (−ln u_d)^α)^(1/α)]
```

其中 `α ≥ 1`。参数 `α` 衡量依赖程度，范围从 `α = 1` 时的独立性，到 `α → ∞` 时的完全依赖（对应于 comonotonic copula）。

# 2. Galambos copula (Negative Logistic Model)

Galambos copula 是一种极值 copula，定义为：

```
C(u₁, …, u_d; α) = exp[−(Σ_{I ⊆ {1,…,d}} (−1)^{|I|} (Σ_{i ∈ I} |ln u_i|^{−α})^{−1/α})]
```

其中 `α ∈ (0, ∞)`。当 `α → ∞` 时，表示完全依赖，对应于 comonotonic copula；而当 `α → 0` 时，表示独立性。该多元极值 copula 由 [21] 作为极值极限得到，类似于 (8.17) 中多元 Pareto 分布的多元情况；更多讨论见 [31]。在极值文献中，如 [14]，此 copula 有时被称为 *negative logistic model*。
