

# V@R 的计算

V@R 的计算基于损失分布的知识。测试 V@R 估计值的准确性非常重要。一个重要的现实检验是回溯测试。设置信任水平为 `p` 的 1 天 V@R 为 `$V`。如果在某一天组合价值的损失大于 `$V`，则我们称发生了例外情况。如果 V@R 模型准确，那么在任何一天组合价值的损失大于 `$V` 的概率为 `q = 1 - p`。假设在 `n` 天的时间范围内，我们观察到这 `n` 天中发生了 `m` 次例外情况，其中比例 `m / n > q`。我们是否应该因为模型对 V@R 产生了低估而拒绝该模型？可以通过使用以下二项式检验来正式检验 [[34](#c08.xhtml#c08-bib-0034)]：

`H₀` (原假设)：在任何一天发生例外情况的概率为 `q`；

`H₁` (备择假设)：在任何一天发生例外情况的概率大于 `q`。

请注意，这是一个单侧检验，因为我们现在观察到 `m / n > q`，并且我们更关注 V@R 的低估，而对高估较少关注。在 `H₀` 下，在 `n` 天中至少出现 `m` 次例外情况的概率为

(8.4)
```
P₀ = Σ(k=m to n) (n choose k) q^k (1 - q)^(n - k).
```

如果 `P₀ < α`，我们在显著性水平 `α` 下拒绝 `H₀`，因为较小的 `q` 倾向于给出较小的 `P₀`；通常，我们取 `α = 0.05`。让我们设置 `n = 250` 天，`p = 0.99`，因此 `q = 0.01`。我们在 Python 中的 [程序 8.11](#c08.xhtml#c08-gra-00011) 和在 `R` 中的 [程序 8.12](#c08.xhtml#c08-gra-00012) 中计算了 `m = 0, ..., 10` 时的 `P₀`。
