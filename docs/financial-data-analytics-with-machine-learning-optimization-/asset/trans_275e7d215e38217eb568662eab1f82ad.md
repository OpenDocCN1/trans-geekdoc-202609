

从 [Figure 14.3](#c14.xhtml#c14-fig-0003) 可以看出，`ln_MV` 在视觉上是 `K`‐means 聚类中最重要且最有用的决策变量。在第三列中，以 `ln_MV` 作为横轴变量，成分股与非成分股（分别为红色三角形和黑色圆点）之间的边界似乎比其他列中使用其他变量作为横轴时更为清晰。然而，仔细观察后可以发现，这两类股票并不像前一示例中不同种类的鸢尾花那样分离明显，因为许多红色三角形实际上隐藏在黑色圆点的云团中。这解释了在此情况下 `K`‐means 聚类的分类性能相对较差，误分类率高达 `(159 + 21) / 680 = 26.47%`（Python）和 `(152 + 24) / 680 = 25.88%`（`R`）。尽管如此，这一结果并不令人惊讶；事实上，作为一种无监督学习方法，当不同类别标签的数据重叠时，`K`‐means 聚类更可能产生较差的结果。

## (III) 对合适的 `K` 的选择

一个直接的问题是，在 `K`‐means 聚类中选择适当的聚类数量 `K`。幸运的是，有一个有用的统计量可供我们选择合适的 `K`。回顾，我们的目标是在数据集中找到清晰可分的组，使得同一组内的记录尽可能同质，而不同组之间尽可能不同。

组内变异和组间变异可以分别通过 `KMeans()` 模型训练得到的 `inertia_` 组件和 `get_bcss()` 函数在 Python 中获得。它们在 `R` 中分别作为 `kmeans()` 模型训练得到的 `tot.withinss` 和 `betweenss` 组件可用。直观地说，回顾聚类的目标，这两种变异可以结合起来给出一个有用的统计量。首先，我们重新审视鸢尾花数据集，并说明如何计算这两个统计量；[Programme 14.7](#c14.xhtml#c14-sec-3007)（Python，对应 [Programme 14.8](#c14.xhtml#c14-sec-3008) 在 `R` 中）演示了如何调和在 [Programme 14.1](#c14.xhtml#c14-sec-3001)（对应 [Programme 14.2](#c14.xhtml#c14-sec-3002) 在 `R` 中）中的相应数值结果。
