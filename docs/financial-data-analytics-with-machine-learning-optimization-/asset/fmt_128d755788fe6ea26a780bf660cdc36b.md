
4. 2b). **M-step**: To maximize `Q` with respect to `μ_m` and `π_m`, for `m = 1, ..., M`, subject to the constraint `∑_{m=1}^{M} π_m = 1`, we have to consider the following Lagrangian (function):

`Q_λ = Q + λ(∑_{m=1}^{M} π_m - 1).`

By differentiating `Q_λ` with respect to `μ_{mk}` for `m = 1, ..., M`, `k = 1, ..., K`, and setting the derivative to zero, we then have

```
∂Q_λ/∂μ_{mk} = ∑_{i=1}^{n} p_{mi}^{(t)} (x_{ik}/μ_{mk} - (1 - x_{ik})/(1 - μ_{mk})) = 0,
```

which implies that

[(6.13)](#c06.xhtml#R_c06-disp-0020)`μ_{mk} = (∑_{i=1}^{n} p_{mi}^{(t)} x_{ik}) / (∑_{i=1}^{n} p_{mi}^{(t)}).`

On the other hand, by differentiating `Q_λ` with respect to `π_m` and setting the derivative to zero, we obtain

```
∂Q_λ/∂π_m = ∑_{i=1}^{n} p_{mi}^{(t)}/π_m + λ = 0,
```

which implies that

[(6.14)](#c06.xhtml#R_c06-disp-0022)`-λπ_m = ∑_{i=1}^{n} p_{mi}^{(t)}.`
