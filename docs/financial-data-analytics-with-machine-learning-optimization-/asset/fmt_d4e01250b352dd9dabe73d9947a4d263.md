
To understand how perceptrons work, we first lay down some notation. The `i`‐th datum in a dataset is represented by `(x_i, y_i)`, in which `x_i = (x_i0, x_i1, ..., x_ip)^⊤`, where `x_i0 = 1` and `(x_i1, ..., x_ip)^⊤ ∈ R^p` is a `p`‐dimensional feature vector; and `y_i = +1` or `-1`, which represents the label of this datum. The perceptron model is to learn a linear function `f: R^(p+1) → R`, which classifies `x_i` in the category `+1` (predicted label `ŷ_i = 1`) if `f(x_i) > 0` or in the category `-1` (predicted label `ŷ_i = -1`) if `f(x_i) < 0`. If `f(x_i) = 0`, we consider it as undetermined, which barely happens in practice. In other words, the learner is `f(x) = ω^⊤ x`, where `ω` is a vector of parameters to be estimated. A datum `(x_i, y_i)` is correctly classified if `f(x_i) > 0` with `y_i = 1` or `f(x_i) < 0` with `y_i = -1`. In both cases, `f(x_i) · y_i > 0`. Similarly, a datum `(x_i, y_i)` is misclassified if `f(x_i) · y_i < 0`.
