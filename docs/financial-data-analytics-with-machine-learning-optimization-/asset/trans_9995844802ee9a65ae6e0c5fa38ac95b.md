## 12.5 共单调-独立贝叶斯分类器 (CIBER)

为了弥补前一节中讨论的朴素贝叶斯的缺点，我们引入了一个变体 [\[5\]](#c12.xhtml#c12-bib-0005)，该变体结合了共单调性，如 [第 8 章](#c08.xhtml) 中的 [第 8.8 节](#c08.xhtml#c08-sec-0015) 简要介绍的那样。我们的目标是更好地恢复和建模特征变量之间的依赖结构，同时不过度复杂化条件联合概率的计算。这种变体被称为 *共单调-独立贝叶斯分类器*，简称 *CIBer*。这种新分类器可以有效处理具有数值的离散特征变量，也称为“离散特征”。然而，在金融和保险领域，离散、连续和分类三种类型的特征变量同时存在的情况很常见。为此，我们引入了一种统一的特征工程方案：通过对连续特征变量进行分箱，并对分类特征变量采用 *联合编码* 方法（我们将在 [12.5.2 节](#c12.xhtml#c12-sec-0008) 和 [12.5.3 节](#c12.xhtml#c12-sec-0009) 中讨论），将所有特征变量转换为离散特征，作为新分类器的输入。
