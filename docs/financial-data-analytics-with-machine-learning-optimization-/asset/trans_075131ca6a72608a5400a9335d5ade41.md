

The higher-order terms of `O_p(δt^(3/2))` refer to terms that contain `δt` of power strictly greater than 1. Now if we take everything to the limit (to the infinitesimal), the higher-order terms go away and ([5.7](#c05.xhtml#c05-disp-0055)) follows.

With Itô's lemma in hand, we are now ready to solve the SDE in ([5.6](#c05.xhtml#c05-disp-0053)). Consider an *Ansatz* `x_t := S_0 e^(αt + βw_t)` with constants `α` and `β`. By Itô's lemma,

```
d x_t = d(S_0 e^(αt + βw_t)) = (α S_0 e^(αt + βw_t) + β²/2 S_0 e^(αt + βw_t)) dt + β S_0 e^(αt + βw_t) d w_t
      = (α + β²/2) x_t dt + β x_t d w_t .
```

So `x_t := S_0 e^(αt + βw_t)` is a solution to the following SDE:

```
{ d x_t = (α + β²/2) x_t dt + β x_t d w_t ,
  x_0 = S_0 .
}
```

Comparing this with the stock price equation, the solution of ([5.6](#c05.xhtml#c05-disp-0053)) is

[(5.8)](#c05.xhtml#R_c05-disp-0059)
```
S_t = S_0 exp{ (μ − σ²/2) t + σ w_t } .
```
