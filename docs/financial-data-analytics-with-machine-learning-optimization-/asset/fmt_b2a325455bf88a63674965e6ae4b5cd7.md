## 8.8 DEPENDENCE MODELLING VIA COPULAE

In this section, we shall use `d` for the dimension of the underlying multivariate risks, and `p` for the critical level of the probability in context. Copulae are used to model and extract the dependence structure among marginal random variables in multivariate distribution functions. Mathematically speaking, a `d`-dimensional copula is simply a `d`-dimensional distribution function on the hyper-cube [0, 1]^d whose `d` marginal distributions follow a uniform distribution on [0, 1]. The main reason why copulae are relevant is due to the celebrated Sklar's theorem [[41]](#c08.xhtml#c08-bib-0041), which asserts that for any `d`-dimensional joint distribution function `F` with marginal distributions `F1, ..., Fd`, there always exists a `d`-dimensional copula `C: [0, 1]^d → R` such that for any `x1, ..., xd ∈ R`,

[(8.10)](#c08.xhtml#R_c08-disp-0041)

```
F(x1, ..., xd) = C(F1(x1), ..., Fd(xd)).
```

Such a copula is unique if all the marginal distributions are continuous; in this case, this unique copula in ([8.10](#c08.xhtml#c08-disp-0041)) can be expressed explicitly as

(8.11)

```
C(u1, ..., ud) = F(F1^(-1)(u1), ..., Fd^(-1)(ud)), for u1, ..., ud ∈ [0, 1].
```
