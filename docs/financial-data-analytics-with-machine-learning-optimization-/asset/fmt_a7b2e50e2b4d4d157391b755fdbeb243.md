
To this end, we first introduce different possible groupings to the collection of all artificial clusters: let us denote `B_k := B_aδ(μ|_k)` and `F_l = {x_i | F(x_i) = l}`. Using these, we define

1. `A_1`: for every `l ∈ A_1`, the artificial cluster `F_l` contains all the points in one ball but no more points from any other ball, i.e., there is exactly one `k = 1, ..., K` such that `B_k ⊆ F_l` but `B_k' ∩ F_l = ∅` for any `k' ≠ k`.

2. `A_2`: for every `l ∈ A_2`, the artificial cluster `F_l` contains the points from one ball but not exactly all its points, and it contains no points from any other ball, i.e. there is exactly one `k = 1, ..., K` such that `B_k ∩ F_l = ∅` but `B_k ⊈ F_l`, while `B_k' ∩ F_l = ∅` for all `k' ≠ k`.

3. `A_3`: for every `l ∈ A_3`, the artificial cluster `F_l` contains points from more than one ball `B_k`.

4. `A_4`: for every `l ∈ A_4`, the artificial cluster `F_l` is disjoint from all balls `B_k`'s.
