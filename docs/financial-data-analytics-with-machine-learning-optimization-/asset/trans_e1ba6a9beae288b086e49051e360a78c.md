

# 使用递推关系模拟股票价格

我们将通过 Python 在 [Programme 5.17](#c05.xhtml#c05-gra-00017) 中（或通过 `R` 在 [Programme 5.18](#c05.xhtml#c05-gra-00018) 中），利用 ([5.9](#c05.xhtml#c05-disp-0065)) 的递推关系来模拟 HSBC、CLP 和 CK 的股票价格。由于 `μ` 和 `Σ` 的时间单位均为一天，我们直接取 `δt = 1`。在每个程序开始时，预留设置初始（随机）种子的空间，可确保每次生成同一组伪随机数，这有助于检查和调试程序。

在 [Programme 5.17](#c05.xhtml#c05-gra-00017) 中，随机种子生成器的命令行位于“for 循环”之外，以确保生成的伪随机数处于相同的随机种子下。对于生成序列的末端项，根据第 [5.1](#c05.xhtml#c05-sec-0002) 节中提到的 ergodic theory，可将其视为 iid 样本。若将命令放在“for 循环”内部，算法每次回到循环时都会生成新种子，导致生成的数字不再具有伪独立结构。

基于这些模拟股票价格，我们可以校准投资组合或相关衍生产品的价格。此处仅模拟了这些股票价格的一条样本路径，如 [Figures 5.4](#c05.xhtml#c05-fig-0004) 和 [5.5](#c05.xhtml#c05-fig-0005) 所示。原则上，我们可以模拟任意数量的路径，并据此构建投资组合的（经验）损失分布，从而校准 V@R。

例如，根据无套利定价理论 [\[3](#c05.xhtml#c05-bib-0003), [20\]](#c05.xhtml#c05-bib-0020)，具有支付 `H_T(ω)` 的金融衍生品在时刻 0 的价格 `V_0` 由以下公式给出：

`V_0 = E^Q[e^(-rT) H_T]`

其中，`Q` 是风险中性概率测度 [\[3](#c05.xhtml#c05-bib-0003), [20\]](#c05.xhtml#c05-bib-0020)，`r` 是无风险利率，`T` 是衍生品到期时间，`ω` 表示关于基础证券的所有随机终端信息，`H_T` 是终端支付。一般而言，`V_0` 的表达式大多难以求解。然而，若 `ω` 易于计算生成，则蒙特卡洛方法可提供一种替代的近似解：

```
V̂₀(n) = (1/n) Σ(i=1 to n) e^(-rT) H_T(ωᵢ)
```

其中，`ωᵢ`（`i = 1, ..., n`）为不同的终端样本点。
