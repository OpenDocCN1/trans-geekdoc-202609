

每小时对数收益率首先通过 Python 在 [Programme 11.9](#c11.xhtml#c11-sec-3009) 中计算。训练集中的收益率用于计算样本协方差矩阵 `P`，并通过 EWMA 估计均值向量 `μ`（如 [第 7.2 节](#c07.xhtml#c07-sec-0003) 所示），其中均值向量定义为 `μ_t = λr_t + (1 - λ)μ_{t-1}`，`t = 2, ..., n`，且按惯例 `λ = 0.94` 与 `μ_1 = r_1`。假设投资者希望实现至少 `μ_P = 15%` 的年化收益率。

从 Python 中 [Programme 11.10](#c11.xhtml#c11-sec-3010) 的输出结果来看，选定了 27 只股票纳入最优投资组合。相比之下，其余 `375 - 27 = 348` 只证券的权重均低于 `10^{-2}` 的阈值，因此被完全舍弃。

最后，作为对比，我们考虑对 S&P500 投资组合采用买入持有策略，初始投资金额同样为 100,000 美元，详见 [Programme 11.11](#c11.xhtml#c11-sec-3011)。

从 [Figure 11.20](#c11.xhtml#c11-fig-0020) 可以看出，最优投资组合的表现优于 S&P500 投资组合。然而，即使不计入交易成本和市场摩擦，最优投资组合在测试期结束时（即 2022 年 1 月 7 日市场收盘时）也仅获得微弱的正收益，金额为 106.567 美元。总的来说，通过二次规划进行投资组合选择的表现虽然绝非最差，但大多平平。这就是为什么我们不指望那些在实际交易中采用这种方法的人能获得非常理想的回报。
