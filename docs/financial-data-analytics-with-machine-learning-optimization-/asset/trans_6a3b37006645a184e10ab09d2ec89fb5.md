```math
Var(m̂₂(x₀)) = (1 / (n hₙ)²) Σ(i=1 to n) E[(K((x₀ - x₁) / hₙ) ε₁)²]
            = (1 / (n hₙ²)) E[K²((x₀ - x₁) / hₙ) σ²(x₁)]
            = (1 / (n hₙ²)) ∫(R) K²((x - x₀) / hₙ) σ²(x) fₓ(x) dx
            = (1 / (n hₙ)) ∫(R) K²(z) σ²(x₀ + hₙ z) fₓ(x₀ + hₙ z) dz
            = (1 / (n hₙ)) (∫(R) K²(z) σ²(x₀) fₓ(x₀) dz + O(hₙ))
            = (1 / (n hₙ)) σ²(x₀) fₓ(x₀) ∫(R) K²(z) dz + o(1 / (n hₙ))
```
