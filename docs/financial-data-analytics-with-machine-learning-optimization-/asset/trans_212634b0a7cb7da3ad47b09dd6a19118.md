

常数 `1/2` 的加入是为了使总变差距离 `d_TV` 的取值在 0 到 1 之间。如果 `d_TV(ν^(1), ν^(2)) = 0`，则 `ν^(1) = ν^(2)`。对于另一种极端情况，即 `d_TV(ν^(1), ν^(2)) = 1`，`ν^(1)` 和 `ν^(2)` 互为单态，这意味着 `S` 可以划分为两个不相交的子集 `S'` 和 `S''`，使得 `ν^(1)` 将其所有概率质量集中在 `S'` 上，而 `ν^(2)` 将其所有概率质量集中在 `S''` 上。如果 `ν^(1), ν^(2), ...` 和 `ν` 是定义在 `S` 上的概率分布，那么当 `n → ∞` 时，若满足以下条件，则称 `ν^(n)` 在总变差意义下收敛于 `ν`：

```
lim_{n → ∞} d_TV(ν^(n), ν) = 0.
```
