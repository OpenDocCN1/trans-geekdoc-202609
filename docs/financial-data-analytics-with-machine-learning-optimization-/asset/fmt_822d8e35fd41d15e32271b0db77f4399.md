
*   Case 3: if `φ(t; λ, ε_S)` admits a unique root `s*` with `φ(s; λ, ε_S) < 0` when `s < s*`; and `φ(s; λ, ε_S) > 0` when `s > s*`, then by defining `t* := (T - s*)⁺`, the optimal selling time is given by `τ_S* := inf {t ∈ [t*, T] : S_t = p M_t} ∧ T`. When `λ` is large, `s*` will get close to 0, then `t*` is close to `T`, and the resulting optimal selling is essentially no different from buy-and-hold. See the grey dotted line in [Figure 7.19](#c07.xhtml#c07-fig-0019);

*   Case 4: if `φ(t; λ, ε_S)` admits two distinct roots `s₂* < s₁*`, then by defining `t₁* := (T - s₁*)⁺` and `t₂* := (T - s₂*)⁺`, the optimal selling time is given by `τ_S* := inf {t ∈ [0, t₁*] ∪ [t₂*, T] : S_t = p M_t} ∧ T`. In particular, as `λ` gets more negative in value, `t₁*` and `t₂*` approach to each other. Ultimately, this closes the gap between these two numbers, making this case reduce to Case 1. See the yellow dash-dotted line in [Figure 7.19](#c07.xhtml#c07-fig-0019).
