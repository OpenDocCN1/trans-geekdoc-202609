

注意输出中的拟合值具有 `r` 列，且样本量为 `n` 的第 `i` 个观测值属于第 `j` 组的概率（最终输出）为

`o′ij = exp(oij) / Σ(k=1 to r) exp(oik), i = 1, 2, ..., n, j = 1, 2, ..., r.`

与线性输出情况下在 [第 15.3 节](#c15.xhtml#c15-sec-0004) 中寻找权重和偏置的最小二乘估计不同，我们在此旨在最小化所谓的 `categorical cross‐entropy loss function`：

`E := -1/n Σ(i=1 to n) Σ(j=1 to r) 1{yi = cj} ln o′ij.`

通常情况下，若 `o′ij` 在第 `i` 行的 (`o′i1`, `o′i2`, ..., `o′ir`) 中最大，则预测第 `i` 个观测值属于组 `j`。显然，`o′ij` 最大当且仅当 `oij` 最大。对于 `R` 而言，我们根据 `iris.nn$fit` 中每行所有 `j = 1, ..., r` 中的最大 `o′ij` 将标签分配给 `pred` 列，值得注意的是，所得模型在 150 个案例中没有错误，错误率为 0%！
