

一个具有有限状态空间和转移概率矩阵 `P` 的马尔可夫链，如果存在某个整数 `n ≥ 0` 使得 `P^n` 中的所有元素均严格为正，则称其为 *regular*。我们的目标是证明，如果马尔可夫链 `{x_n}` 是 regular 且具有有限状态空间 `S = {s_1, s_2, ..., s_K}`，则极限分布 `(π_1, ..., π_K)` 存在，且由

```
π_j = lim_{n→∞} P(x_n = s_j | x_0 = s_i) = lim_{n→∞} p_{i,j}^{(n)}, j = 1, ..., K,
```

定义，并且这些极限不依赖于初始状态 `i` 的选择。
