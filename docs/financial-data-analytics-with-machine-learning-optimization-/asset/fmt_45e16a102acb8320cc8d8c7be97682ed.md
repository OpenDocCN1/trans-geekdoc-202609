
In general, let `X = (x1, x2, ..., xn) ∈ R^(p×n)` be a data matrix of `n` sample points (assuming mean zero for simplicity) such that each `xi ∈ R^p`, for `i = 1, 2, ..., n`. The main goal of PCA is to compress the information in `X` so that each sample point is effectively projected onto `R^k` with `k < p`, while the loss of information is minimized.

Let `W = (ω1, ..., ωk) ∈ R^(p×k)` be a projection matrix which satisfies

```
∥ωi∥₂ = 1, i = 1, ..., k, and ωiᵀωj = 0 for i ≠ j.
```

Then, the compressed data matrix `Z` takes the form `Z = WᵀX`. From this compressed data matrix, we can retrieve the original data matrix approximately by using `X̃ = WZ = WWᵀX`. The question now is how to determine `W` so that the induced approximation error can be minimized. In other words, we aim to solve the following optimization problem:

[(9.1)](#c09.xhtml#R_c09-disp-0012)

```
min_W ∥X - X̃∥_F = min_W ∥X - WWᵀX∥_F,
subject to WᵀW = I_k,
```
