
For `j ≠ l`, each entry in `E((x_j - μ)(x_l - μ)ᵀ)` vanishes because each entry is the covariance between a component of `x_j` and that of `x_l`, and they are independent by the definition of random sample. Therefore,

`Var(x̄) = (1/n²) Σ(j=1 to n) E((x_j - μ)(x_j - μ)ᵀ).`

Since `Σ = E((x_j - μ)(x_j - μ)ᵀ)` is the common population covariance matrix for each `x_j`, we have

`Var(x̄) = (1/n²) Σ(j=1 to n) E((x_j - μ)(x_j - μ)ᵀ) = (1/n²) · n · Σ = (1/n) Σ.`
