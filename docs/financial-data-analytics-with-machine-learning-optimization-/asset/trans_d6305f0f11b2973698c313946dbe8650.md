如前所述，Lloyd 算法对初始化相当敏感，因为不同的初始种子可能导致相当不同的聚类结果，因为该算法只能得到 ([14.2](#c14.xhtml#c14-disp-0002)) 的局部最小值，而不是全局最小值。为了获得更稳健的性能，我们可以采用类似蒙特卡罗的方法，即使用随机初始种子多次重复聚类过程。然后我们比较不同初始种子得到的结果，并选择平方和最小的一组种子。作为一种权衡，这种方法当然需要更长的计算时间。
