

为了解释该算法，我们用 `W(0) := W` 表示初始词库，用 `W(k), k = 1, 2, ...` 表示在第 `k` 次猜测后以及迄今揭示的颜色信息之后的候选词集合，同时记 `n(k) := |W(k)|`。现在让我们以递归的方式在数学上定义“缩小可能单词范围”的操作。假设第 `k` 次猜测 `ω̃(k) = (ω̃₁(k), ..., ω̃₅(k)) ∈ W(k-1)` 返回颜色向量 `c(k) = (c₁(k), ..., c₅(k))`。那么，

(13.23)
```
W(k) = { ω = (ω₁, ..., ω₅) ∈ W(k-1) | ωⱼ = ω̃ⱼ(k) if cⱼ(k) = Green;
         Conditions (i), (ii) and (iii) are fulfilled if cⱼ(k) = Yellow;
         ∏_{l=1}^{5} (ωₗ - ω̃ⱼ(k)) ≠ 0 if cⱼ(k) = Gray for all j = 1, ..., 5 }
```
