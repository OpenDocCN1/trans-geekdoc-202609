其中函数 `Im(·)` 是预先指定的不纯度度量，例如上述三种之一。同样，每个不纯度度量都定义在标签的概率分布上，这里涉及的概率分布是引用自 ([13.10](#c13.xhtml#c13-disp-0032)) 的条件概率分布。为了避免产生太多歧义，我们略微滥用 `Im(S(i, v))` 的记法，将其作为来自子样本 `S(i, v)` 的标签的条件概率分布的不纯度度量。此外，为了方便起见，我们将节点的名称与同一节点处的子样本的名称视为相同。
