

已知，如果目标函数 `f` 是严格凸的，那么在某些温和条件下，无论初始种子 `x₀` 如何选择，MM 算法都会收敛到唯一的最小点（如果存在）。如果缺乏凸性，但所有驻点都是孤立的，那么 MM 算法将收敛到其中一个驻点，具体取决于初始猜测的位置。MM 算法的性能和收敛速度取决于代理函数 `g(·, x⁽ᵗ⁾)` 逼近 `f` 的程度，以及代理函数的最小化是否容易。在下文中，我们将重点介绍几种常用的构建适当代理函数的方法。更详细的讨论可以在 [18](#c06.xhtml#c06-bib-0018)、[19](#c06.xhtml#c06-bib-0019)、[20](#c06.xhtml#c06-bib-0020) 及其中的参考文献中找到。

首先，假设目标函数 `f: ℝ₊ᵖ → ℝ` 具有形式 `f(x) := h(cᵀx)`，其中 `c ∈ ℝ₊ᵖ` 和凸函数 `h: ℝ₊ → ℝ`。根据 Jensen 不等式，给定当前迭代 `x⁽ᵗ⁾ ∈ ℝ₊ᵖ`，

```
f(x) = h(cᵀx) = h(∑ᵢ₌₁ⁿ (cᵢxᵢ⁽ᵗ⁾)/(cᵀx⁽ᵗ⁾) · (cᵀx⁽ᵗ⁾/xᵢ⁽ᵗ⁾)xᵢ) ≤ ∑ᵢ₌₁ⁿ (cᵢxᵢ⁽ᵗ⁾)/(cᵀx⁽ᵗ⁾) h((cᵀx⁽ᵗ⁾/xᵢ⁽ᵗ⁾)xᵢ),
```
