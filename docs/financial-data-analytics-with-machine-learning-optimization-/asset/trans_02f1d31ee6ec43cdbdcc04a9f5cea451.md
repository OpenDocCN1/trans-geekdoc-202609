

让我们在证明主定理 4.1 之前，先考虑这些傅里叶系数的一些基本性质。

**Lemma 4.1** 假设 `f ∈ L²[0, 1]` 是一个概率密度函数。那么，

1. `f̂(0) = 1`;

2. 当 `n ≠ 0` 时，`|f̂(n)| < 1`；实际上，`sup_{n ≠ 0} |f̂(n)| < 1`。

*Proof.* 第一个结论显而易见，因为 `∫₀¹ f(t) dt = 1`。对于固定的 `n` 和连续密度 `f`，我们首先注意到，对于任何 `θ ∈ [0, 1]`：

```
|∫₀¹ f(t) e^(-2πint) dt| = |e^(2πinθ) ∫₀¹ f(t) e^(-2πint) dt| = |∫₀¹ f(t) e^(-2πin(t-θ)) dt|,
```

有了这个想法，由于这总是可以通过任意平移来实现，因此不失一般性，我们可以假设 `f(0) = f(1) > 0` 且 `t = 0` 是连续点。那么，

```
∫₀¹ f(t) e^(-2πint) dt = ∫₀^δ f(t) e^(-2πint) dt + ∫_(1-δ)¹ f(t) e^(-2πint) dt + ∫_δ^(1-δ) f(t) e^(-2πint) dt.
```
