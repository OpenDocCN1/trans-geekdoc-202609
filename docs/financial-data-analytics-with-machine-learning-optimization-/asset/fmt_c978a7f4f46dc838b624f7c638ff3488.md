
The period of a state `s ∈ S` can be defined analogously as follows. For any `s ∈ S`, let `I_S(s) := {n : f(s) > 0 for any f ∈ B⁺(S), f(s) > 0} ⊆ ℕ₀ := {0, 1, 2, ...}`. The period `d(s)` of `s` is defined as:

```
d(s) := { gcd(I_S(s)) if I_S(s) ≠ ∅; 0 otherwise }
```

An uncountable state Markov chain `{xₙ}` is said to be *aperiodic* if `d(s) = 1` for all `s ∈ S`.

The following proposition summarizes some properties of periods of a Markov chain with an uncountable state space. It shares the same structure as those for finite state Markov chains, and its proof can be found in [Appendix 6.A.2](#c06.xhtml#c06-sec-0038).

#### [Proposition 6.1](#c06.xhtml#R_c06-fea-0016)

1. If `s₁ ↔ s₂`, then `d(s₁) = d(s₂)`.

2. Under [Assumption 6.1](#c06.xhtml#c06-fea-0012), for every `s ∈ S`, there exists `Nₛ ∈ ℕ` depending on `s` such that `f(s) > 0` for any `f ≥ 0` with `f(s) > 0` whenever `n ≥ Nₛ`.
