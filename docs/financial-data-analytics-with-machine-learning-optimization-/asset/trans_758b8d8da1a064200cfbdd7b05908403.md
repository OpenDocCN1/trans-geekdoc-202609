# CHAPTER 8  

风险度量、极端值与 Copula

金融机构通常每天管理数百甚至数千个证券和衍生品组合。拥有一个能够概括金融资产组合总风险的单一数值非常重要，以便衡量金融机构所面临的整体潜在风险。*Value-at-Risk*（V@R，风险价值）试图提供这样一个指标（度量）。它由 J.P. Morgan [\[32\]](#c08.xhtml#c08-bib-0032) 首创，并被 *Basel Committee*（巴塞尔银行监管委员会）[\[7\]](#c08.xhtml#c08-bib-0007) 采用，用于制定全球银行的资本要求。与 V@R 密切相关的是 *Expected Shortfall*（ES，预期损失），其依据 *Basel III*（巴塞尔 III 协议）进行应用。
