## 1.2 MATRIX THEORY

Before we embark on our journey, let us first recall some basic notations and concepts in introductory matrix theory. Readers may refer to [\[11](#c01.xhtml#c01-bib-0011), [18](#c01.xhtml#c01-bib-0018), [19\]](#c01.xhtml#c01-bib-0019) for more detailed introductions to matrix theory at an elementary level; more advanced topics are discussed in [\[8](#c01.xhtml#c01-bib-0008), [20](#c01.xhtml#c01-bib-0020), [21\]](#c01.xhtml#c01-bib-0021), including various algorithms for matrix solvers and techniques related to singular value decomposition.

**(I) Determinant**

Let `A` and `B` be two `p` times `p` square matrices and let `|A|` denote the `determinant` of `A`. Basic properties include the following:

1.  `|A^T| = |A|`.
