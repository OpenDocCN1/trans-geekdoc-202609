We want to examine, on average, the number (length) of bits `l(x^(n))` required to code an arbitrary message of `x^(n) ∈ X^n`. By assuming the alphabets `x1, ..., xn` arrive identically and independently, the problem can be reformulated as computing `E(l(x^(n)))`, where `x^(n) = (x1, ..., xn)` is the random message. We then decompose `X^n` into the typical set `A_ε^(n)` and its complement `A_ε^(n)̄`. From the discussion above, it suffices to use at most `n(H(x) + ε) + 1` bits to represent all sequences of alphabets `x^(n) ∈ A_ε^(n)`. On the other hand, by direct counting, we can certainly use at most `n log_2 |X| + 1` bits to code all sequences in `A_ε^(n)̄`.
