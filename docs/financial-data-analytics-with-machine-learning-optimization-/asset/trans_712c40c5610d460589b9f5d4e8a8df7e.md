ANN 的一个主要问题是权重的解取决于初始种子。每次运行 `nnet()` 时，我们可能会获得不同的结果。这在 [Figure 15.6](#c15.xhtml#c15-fig-0006) 中得到说明，其中实线曲线表示损失函数。

误差函数 `E`，虽然取决于 ANN 的权重 `(w_ji)_i,j`，但在 `w_ji` 的多维空间中包含大量局部极小值。由于 `nnet()` 随机分配一组初始参数 `w_ji`（`Xavier initialization` [\[5\]](#c15.xhtml#c15-bib-0005)）并使用反向传播来最小化误差函数，估计的 `w_ji` 可能只是误差函数的局部极小值。因此，我们通常在 Python 中多次运行 `MLPRegressor()`（或在 `R` 中运行 `nnet()`），使用不同的初始种子集，以尝试获得“全局最优”权重。请参见 [Programme 15.7](#c15.xhtml#c15-sec-3007)（Python 中）或 [Programme 15.8](#c15.xhtml#c15-sec-3008)（`R` 中），了解函数 `MLPRegressor()`（Python 中）或 `nnet()`（`R` 中）的改进版本。

这个新构建的函数可以指定试验次数并保存最佳结果；请参见 [Programme 15.9](#c15.xhtml#c15-sec-3009)（Python 中）或 [Programme 15.10](#c15.xhtml#c15-sec-3010)（`R` 中）作为示例。

## 15.4 带有逻辑输出的 ANN

在上一节中，输出是隐藏层神经元值的线性函数，并且是一个实数。在分类问题中使用此功能时，例如鸢尾花和 HSI 示例，我们必须将输出四舍五入到其最近的整数。但是，我们可以使用 Python 中的默认选项 `linout=False`（或 `R` 中的 `linout=FALSE`）（而不是现在的 `linout=True`），然后 `r` 个不同的逻辑函数用于连接输出层的神经元和最终输出。这可以解释为具有某些特征的观测值属于 `r` 个组中某一特定组的概率。让我们看看如何在 [Programme 15.11](#c15.xhtml#c15-sec-3011)（Python 中）或 [Programme 15.12](#c15.xhtml#c15-sec-3012)（`R` 中）中使用此逻辑输出选项。
