

显然，从上面的表达式可以看出，获得更准确估计的一种常见方法是增加模拟次数 `n`，因为这会减小样本均值估计量的方差。另一种方法是巧妙地寻找一个替代随机变量 `z`，使其与 `x` 具有相同的理论均值但方差更小，即 `μz := E(z) = E(x) = μx` 且 `Var(z) ≤ Var(x)`，这样我们就有 `Var(μ̂z) = 1/n Var(z) ≤ 1/n Var(x) = Var(μ̂x)`，随后可以使用 `μ̂z = 1/n Σ(i=1 to n) zi` 作为 `μx` 的估计量，以实现更高的精度。本节稍后将介绍两种寻找更有效 `z` 的常见方法。

**[示例 5.1](#c05.xhtml#R_c05-fea-0002)** 假设我们希望估计积分 `I := ∫(0 to 1) x³(1 - x)²·⁵ dx`，并使用 `n = 10,000` 个生成的样本。我们观察到 `I` 可以表示为 `E(u³(1 - u)²·⁵)`，其中 `u ~ U(0, 1)`。因此，我们可以先模拟 `u1, ..., u10,000`，然后计算以下估计量：

```
θ̂ = 1/n Σ(i=1 to n) ui³(1 - ui)²·⁵.
```
