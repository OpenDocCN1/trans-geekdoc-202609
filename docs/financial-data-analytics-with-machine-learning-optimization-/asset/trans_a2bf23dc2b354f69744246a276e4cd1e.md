

对 `p_j` 求拉格朗日函数的导数可得：

∂L(p_(K), λ)/∂p_j = Σ(i=1 to n) (y_ij / p_j) - λ, for j = 1, ..., k

并令各导数均为零，可得 λ = Σ(i=1 to n) (y_ij / p_j)，故

p̂_j = Σ(i=1 to n) (y_ij / λ)

由于所有 p̂_j 之和恒等于 1，故有

1 = Σ(j=1 to K) p̂_j = Σ(j=1 to K) Σ(i=1 to n) (y_ij / λ)

由此可得 λ = n。因此，最大似然估计量 p̂_j 为：

p̂_j = (1/n) Σ(i=1 to n) y_ij = (1/n) Σ(i=1 to n) 1{x_i = A_j}, for j = 1, ..., K

这与预期一致。
