

在少数例外中，中国（不含湖北）和俄罗斯的低 `R²` 可以通过幂律指数的变化来解释，如 [图 4.9](#c04.xhtml#c04-fig-0009) 的对数-对数图所示。这是因为 [\[5\]](#c04.xhtml#c04-bib-0005) 中概述的 `x_min` 估计程序定位的是第二个幂律结束的点，而不是幂律指数首次变化的点，从而导致结果不准确。如果可以将地区分为两个同质子群，例如城市和农村地区，使得每个子群都具有相似的组内增长轨迹，那么这些变化点可能会得到解释。特别是，对俄罗斯数据的进一步分析表明，第一个幂律适用于该国欧洲部分的主要发达城市和海港，而对中国（不含湖北）的类似分析表明，第一个幂律主要出现在沿海省份，这些省份更发达。因此，变化点可以与该地点的发展水平和地理位置相关联来证明，这反过来又解释了相对较低的 `R²` 值。

另一方面，当湖北被纳入中国的分析时，低 `R²` 就不能再用变化点来解释；湖北的病例远多于其余省份。然而，这种差异可能由中国政府干预后完全不同的增长轨迹来解释。病毒在 2020 年 1 月在湖北失控传播了三周，直到政府采取的非凡检疫措施在春节前夕生效，这有效地阻止了病毒通过 `Chunyun`（又称 `春运`）传播到其他省份。

齐夫定律的适用性也可以通过对数-对数图直观评估。[图 4.9](#c04.xhtml#c04-fig-0009) 和 [4.10](#c04.xhtml#c04-fig-0010) 展示了所考虑国家的地区 COVID-19 病例的对数-对数图。同样，除了中国和俄罗斯之外，所有国家的图表都大致呈线性，这总体上支持齐夫定律。使用 OLS 或希尔估计法估计的各国 `β` 值大多在 1 左右，呼应了基于 [\[14\]](#c04.xhtml#c04-bib-0014) 构建以及我们在 [第 4.5 节](#c04.xhtml#c04-sec-0019) 中的讨论所提出的理论论点，后者预测幂律指数为 `β = 1`；然而，仍然存在一些偏差，某些估计值变化相当大，且与 1 有显著不同。例如，加拿大的 OLS 估计 `β` 值小至 0.34，而英国的估计值则大至 2.24。这种差异是由于加拿大的病例高度集中在魁北克省和安大略省，这两个省份合计占加拿大 COVID-19 病例的 84%。另一方面，英国的两个最大地区仅占所有病例的 30%。
