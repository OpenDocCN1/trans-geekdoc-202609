
where `(xᵢ, yᵢ)` are iid copies of `(x, y)`. In practice, the value of `b* = -Cov(x, y) / Var(y)` is not known *a priori*, but it can be estimated using the simulated sample `(xᵢ, yᵢ)` by using the sample correlation coefficient,

```
b̂* = -Σᵢ₌₁ⁿ (xᵢ - x̄)(yᵢ - ȳ) / Σᵢ₌₁ⁿ (yᵢ - ȳ)²,
```

and the estimator `ψ̂_C` becomes `x̄ + b̂*(ȳ - μ_y)`.

**[Example 5.3](#c05.xhtml#R_c05-fea-0010) *(Continuation of [Example 5.1](#c05.xhtml#c05-fea-0002))*** We choose `y := (1 - u)²·⁵` as the control variate, whose mean can be computed explicitly:

```
μ_y = ∫₀¹ (1 - x)²·⁵ dx = -∫₀¹ (1 - x)²·⁵ d(1 - x) = 1 / 3.5 = 2/7.
```

As before, we repeat the simulation procedure for 1,000 times, and in [Programme 5.11](#c05.xhtml#c05-gra-00011) (resp. [Programme 5.12](#c05.xhtml#c05-gra-00012)), we also report the mean and the (sample) variance of the estimates obtained in Python (resp. `R`). We can clearly see that the sample (bootstrapped) variance is smaller than that obtained in [Example 5.1](#c05.xhtml#c05-fea-0002).
