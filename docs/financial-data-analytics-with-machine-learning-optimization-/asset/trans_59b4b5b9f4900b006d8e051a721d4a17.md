

在 Python ([Programme 14.1](#c14.xhtml#c14-sec-3001)) 中，这个平方和可以通过函数 `bcss` 调用；而在 `R` ([Programme 14.2](#c14.xhtml#c14-sec-3002)) 中，该值存储在 `km_iris$betweenss` 中。

牢记所有这些量之后，我们介绍以下 `Calinski–Harabasz index` [\[4\]](#c14.xhtml#c14-bib-0004)：

其中 `BCSS` 和 `WCSS` 均被视为 `K` 的函数。显然，`BCSS` 描述了不同簇之间的离散程度，而 `WCSS` 描述了每个簇内部点的离散程度。良好的聚类应当是前者较大而后者较小的情况。请注意，作为组间与组内平方和之比（并除以各自的自由度），该指标类似于单变量分析中的 `F` 检验统计量。我们旨在寻找一个 `K` 值，使 `WCSS` 尽可能小且 `BCSS` 尽可能大，从而使 `R(K)` 尽可能大。在 [Appendix \*14.A.1](#c14.xhtml#c14-sec-0010) 中，我们将说明为什么在大多数实际场景中，`R(L)` 确实会在其真实簇数（即 `L = K`）时达到最大值，并讨论在某些特殊情况下使用它的陷阱。

在 [Programme 14.9](#c14.xhtml#c14-sec-3009) 中通过 Python（或 [Programme 14.10](#c14.xhtml#c14-sec-3010) 通过 `R`），我们演示如何使用自定义函数 `kmstat()` 在 Python 和 `R` 中计算 `R(K)`。该函数旨在返回 `K` 的最优选择，以及相应的最大化 `R(K)` 统计量和相应的聚类模型。我们还在 Python 和 `R` 中介绍了另一个函数 `best_km()`，它对不同的 `K` 值多次执行 K-均值聚类，并生成相同的两个输出，即具有最大 `R(K)` 统计量的最佳试验。分别参见通过 Python 的 Programme 14.9 和通过 `R` 的 Programme 14.10。

此外，再次使用 Iris 数据集，我们将在 [Programme 14.11](#c14.xhtml#c14-sec-3011) 中通过 Python（或 [Programme 14.12](#c14.xhtml#c14-sec-3012) 通过 `R`）尝试多个 `K` 值，并确定函数 `R(K)` 达到最大值的特定 `K` 值。

在 [Programme 14.11](#c14.xhtml#c14-sec-3011) 中通过 Python（或 [Programme 14.12](#c14.xhtml#c14-sec-3012) 通过 `R`），我们在 `best_km()` 函数中输入几个 `K` 值，并发现 `K = 3` 使 `R(K)` 达到最大值 561.6278，因此 `K = 3` 可能是一个合适的选择。聚类标签也保存在 `km_iris3` 中，交叉表格正好与 [Programme 14.3](#c14.xhtml#c14-sec-3003) 通过 Python（或 [Programme 14.4](#c14.xhtml#c14-sec-3004) 通过 `R`）显示的相同。

作为另一个示例，我们还将 `best_km()` 应用于清洗后的 2002 年 HSI 数据集 `fin‐ratio_cleansed.csv`（由 [Programme 10.11](#c10.xhtml#c10-sec-3011) 通过 `R` 生成），输出如 [Programme 14.13](#c14.xhtml#c14-sec-3013) 通过 Python（或 [Programme 14.14](#c14.xhtml#c14-sec-3014) 通过 `R`）所示。

如预期，`K = 2` 使 `R(K)` 达到最大值 330.7535，这似乎与数据集的可能实际标签数量一致。尽管类别数量相同，但分类结果可能与 HSI 中的股票类别不一致。为了找出这些簇的特征，我们使用 [Programme 14.15](#c14.xhtml#c14-sec-3015) 通过 Python（或 [Programme 14.16](#c14.xhtml#c14-sec-3016) 通过 `R`）。[Figure 14.4](#c14.xhtml#c14-fig-0004) 中生成的箱线图有效地说明了每个簇的特征。
