
# Latent-Factor Method for Recommender Systems

Going back to the latent-factor method, upon completion of the optimization procedure that minimizes the MSE `J`, both the subscribers' tastes on movies `p̂ᵢ,ₖ` and the nature of movies `q̂ⱼ,ₖ` can be estimated. The `m × n` matrix `R̂ = P̂Q̂ᵀ` then stores the predicted ratings of all movies by all subscribers. For instance, the `i`-th rows of `R̂` are row vectors that list the predicted ratings on all movies `j = 1, 2, …, n` by the `i`-th subscriber. Notably, these predicted ratings of `R̂` should be non-zero for those unknown ratings `rᵢ,ⱼ = 0`; while for any `rᵢ,ⱼ ≠ 0`, the corresponding estimate `r̂ᵢ,ⱼ` should be roughly equal to that known rating `rᵢ,ⱼ`. By sorting these estimated ratings in descending order, our recommender system should be able to show the `i`-th subscriber top recommendations that best fit their taste. Furthermore, if we want to predict all ratings for the testing data, say for a newly joined user `m + 1`, based on some known ratings `rₘ₊₁,ⱼ`'s of his, then we solve for `p̂ₘ₊₁ = (p̂ₘ₊₁,₁, …, p̂ₘ₊₁,ₚ)ᵀ` that minimizes `Σⱼ₌₁ⁿ(rₘ₊₁,ⱼ − Σₖ₌₁ᵖ p̂ₘ₊₁,ₖ q̂ⱼ,ₖ)²`. Here, `Q̂` has already been obtained using the training data from the existing users `1, …, m`, and it is not affected by just one new user `m + 1` or a few more. In other words, the best approximant for the ratings of the user `m + 1`, the column vector `r̂ₘ₊₁ = Q̂p̂ₘ₊₁ := (Σₖ₌₁ᵖ p̂ₘ₊₁,ₖ q̂ⱼ,ₖ)ⱼ₌₁ⁿ`, is just the projection of `rₘ₊₁ := (rₘ₊₁,₁, …, rₘ₊₁,ₙ)ᵀ` onto the column space of `Q̂`. Certainly, if subscriber `m + 1` really just joins the service, normally some random recommendations will be popped up, so as to see what choices this new user would make, then more non-zero values of `rₘ₊₁,ⱼ`'s can be learnt first. Afterwards, the procedure described above could then be implemented.
