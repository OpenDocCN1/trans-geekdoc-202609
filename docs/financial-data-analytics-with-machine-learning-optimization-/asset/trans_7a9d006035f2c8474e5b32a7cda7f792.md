

1.  `x_t ∈ R^p` 表示当前时间步 `t` 的输入特征向量；

2.  矩阵 `W_f, W_i, W_c~, W_o ∈ R^(q×p)` 分别对应用于遗忘门、输入门、单元输入和输出门的输入 `x_t` 的权重；

3.  矩阵 `V_f, V_i, V_c~, V_o ∈ R^(q×p)` 分别对应来自自身一步延迟的单元输出激活值 `h_(t-1)` 的权重，用于遗忘门、输入门、单元输入和输出门；

4.  向量 `b_f, b_i, b_c~, b_o ∈ R^q` 分别对应遗忘门、输入门、单元输入和输出门的偏置；

5.  激活函数 `g_1, g_2, σ ∈ R^q` 分别用于单元输入、单元输出和所有其他门。通常，双曲正切函数 `tanh` 被选用于 `g_1` 和 `g_2`；而逻辑函数可用于 `σ`。

在 LSTM 模型中，单元以顺序方式连接，形成循环神经网络。单个单元接收来自前一时间步的单元状态 `c_(t-1) ∈ R^q` 和单元输出 `h_(t-1) ∈ R^q` 作为输入，同时也接收来自当前时间的输入向量 `x_t`。这种连接允许信息从一个单元流向下一个单元，使模型能够捕捉序列数据中的长期依赖关系。要初始化 LSTM 模型，单元状态 `c_0` 和单元输出 `h_0` 通常使用独立标准正态分布进行初始化，这是 Xavier 初始化的常见做法。[Figure 15.18](#c15.xhtml#c15-fig-0018) 说明了此架构。

LSTM 通过引入不同的变体得到了进一步改进，例如 `Gated Recurrent Unit` (GRU) [\[4\]](#c15.xhtml#c15-bib-0004)，它通过合并输入门和遗忘门来简化 LSTM 架构。另一个值得注意的变体是 `Bidirectional LSTM` (BiLSTM) [\[21\]](#c15.xhtml#c15-bib-0021)，它同时从正向（从开头开始）和反向（从结尾开始）处理输入序列，捕捉来自自上而下和自下而上上下文的信息。
