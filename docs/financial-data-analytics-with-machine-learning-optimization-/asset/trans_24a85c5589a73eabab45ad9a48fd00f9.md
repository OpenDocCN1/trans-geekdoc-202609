## 3.5 股票价格的经验特性

毫无疑问，对股票价格进行建模是 `Quantitative Finance` 和 `Econometrics` 中最活跃的研究领域之一。在过去几个部分中，我们演示了一些建模股票价格的原始方法。然而，在现实中，股票价格受许多因素影响，例如利率以及各种经济和政治因素；例如，请参阅 [\[3](#c03.xhtml#c03-bib-0003), [10\]](#c03.xhtml#c03-bib-0010) 以获取更多讨论。尽管复杂，但关于股票价格存在一些经验发现和行业内广泛接受的惯例。以下是最显著的一些列表；更全面的说明可以在 [\[3\]](#c03.xhtml#c03-bib-0003) 中找到。

1.  我们通常不直接对股票价格本身进行建模，而是对股票的（每日）收益率进行建模。收益率有两种类型：

4.  虽然 Black–Scholes–Merton 模型假设分布为正态分布，但在许多情况下，其分布通常被认为比正态分布具有更肥的尾部。更肥的尾部意味着比正态分布提供的更大损失（或利润）的概率更高；有关此方面建模的更多详细信息，请参见 [\[5\]](#c03.xhtml#c03-bib-0005)。在计算风险价值（V@Rs）时，这一点尤为重要；更多详细信息可见 [Chapter 8](#c08.xhtml)。

5.  ![normal u Subscript i](images/c03-i0152.png)<math display="inline" overflow="scroll"><msub><mi mathvariant="normal">u</mi><mi>i</mi></msub></math> 的标准差与 ![normal u Subscript i](images/c03-i0153.png)<math display="inline" overflow="scroll"><msub><mi mathvariant="normal">u</mi><mi>i</mi></msub></math> 的均值相比较大。经验研究表明，在正常时期，每日收益率的标准差通常在 0.95% 到 3.15% 之间，但在 2020 年上半年——疫情年份——美国市场的标准差在 2% 到 8% 之间！

6.  这种标准差当然会随时间变化，并取决于许多未知且不可控的因素，因此 Black–Scholes–Merton 模型对于长期建模并不十分可靠；更复杂的时间序列模型将在 [Chapter 7](#c07.xhtml) 中介绍。
