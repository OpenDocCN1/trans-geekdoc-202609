

假设我们将 `n` 个金融观测值 `x1, ..., xn` 按降序排列，且有 `nu` 个观测值大于 `u`。假设前面的 *Gnedenko–Pickands–Balkema–de Haan* 定理（以下简称“*Gnedenko 定理*”）适用于该样本的基础分布，那么对于足够大的 `u`，我们可以用 `1 - Gξ,β(y)` 估计 `P(x > u + y | x > u)`，并用 `nu / n` 估计 `1 - F(u)`。因此，无条件概率近似为

```
P(x > u + y) ≈ (1 - F(u))(1 - Gξ,β(y)) = (nu / n)(1 + ξ(y / β))^(-1 / ξ), for all y > 0,
```

这意味着对于大 `x > u`，

```
P(x > x) ≈ (nu / n)(1 + ξ((x - u) / β))^(-1 / ξ),
```

因此

[(8.2)](#c08.xhtml#R_c08-disp-0019) `P(x ≤ x) ≈ 1 - (nu / n)(1 + ξ((x - u) / β))^(-1 / ξ).`
