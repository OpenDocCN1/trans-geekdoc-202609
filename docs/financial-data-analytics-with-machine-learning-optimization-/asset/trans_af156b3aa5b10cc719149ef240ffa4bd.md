3.  *齐次性：* 将投资组合的规模按因子 `k` 改变，应导致风险度量乘以 `k`。`ρ(k L_A) = k ρ(L_A)`

4.  *次可加性：* 两个投资组合合并后的风险度量不应大于各自投资组合组件的风险度量之和。`ρ(L_A + L_B) ≤ ρ(L_A) + ρ(L_B)`

前三个条件足够自然，而第四个条件意味着多元化有助于降低固有风险。满足所有四个条件的风险度量被称为 *连贯的*，见 [\[3\]](#c08.xhtml#c08-bib-0003)。

回顾在 [示例 8.3](#c08.xhtml#c08-sec-0005) 和 [8.4](#c08.xhtml#c08-sec-0006) 中，两笔贷款分别的 1 年 `99%` V@R 分别为 `$2M + $2M = $4M`，这小于 `$5.8M`，即投资组合的 V@R。这意味着 V@R 不总是满足次可加性条件，但在 *椭圆分布* 中它仍然是次可加的。

**提议 8.1 *(ES 的次可加性)*** 设 `x` 和 `y` 为两个随机变量，设 `ES_x(p)`（即 `ES_y(p)`）表示 `x`（即 `y`）在置信水平 `p ∈ (0, 1)` 下的预期短缺。则

```
ES_{x+y}(p) ≤ ES_x(p) + ES_y(p).
```

*证明。* 注意 `ES_x(p)` 承认以下表达式（见 [\[17\]](#c08.xhtml#c08-bib-0017)）：

```
ES_x(p) = V@R_x(p) + 1/(1-p) E((x - V@R_x(p))_+).
```
