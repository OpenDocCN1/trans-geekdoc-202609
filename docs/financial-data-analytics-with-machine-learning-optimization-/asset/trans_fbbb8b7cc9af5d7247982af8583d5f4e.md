

从定义来看，总是清楚 `H(x) ≥ 0`。如果 `x` 是退化的，那么 `H(x) = 0`，并且 `x` 中没有歧义。如果 `x` 是取值 0 或 1 的伯努利分布，则有 `H(x) ∈ [0, 1]`，且当且仅当 `x` 取 0 和 1 的可能性相等时，`H(x) = 1`。一般来说，如果 `x` 是一个取 `n` 个不同值的离散随机变量，对应的概率为 `p_i`，其中 `i = 1, 2, ..., n`，当所有 `i` 的 `p_i ≡ 1/n` 时，香农熵达到最大，对应的熵 `H(x)` 为 `log₂ n`。这一结论可通过应用 Jensen 不等式得出。
