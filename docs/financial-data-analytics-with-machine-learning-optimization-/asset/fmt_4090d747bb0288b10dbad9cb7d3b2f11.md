### 5.2.2 Control Variates

Let `y` be a random variable with a known mean `E(y) = μ_y`. Instead of conditioning, we can refine the random variable `x` directly, so as to reduce the variance of the estimator. For any constant `b ∈ ℝ`, the random variable `z := x + b(y - μ_y)` is clearly an unbiased estimator of `μ_x`. For the `control variate technique`, we aim to pick a `b` such that `Var(z) < Var(x)`. To this end, note that

[`(5.2)`](#c05.xhtml#R_c05-disp-0025)
`Var(z) = Var(x + b(y - μ_y)) = Var(x) + b² Var(y) + 2b Cov(x, y).`

Differentiating [`(5.2)`](#c05.xhtml#c05-disp-0025) with respect to `b` and equating this derivative to zero yields that

`d Var(z) / db = 2b Var(y) + 2 Cov(x, y) = 0 at b* := -Cov(x, y) / Var(y).`
