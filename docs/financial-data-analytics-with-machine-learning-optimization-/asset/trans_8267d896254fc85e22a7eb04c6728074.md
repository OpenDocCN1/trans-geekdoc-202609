```math
\sqrt{n h_n} \left( \frac{\hat{m}_1(x_0)}{\hat{f}_x(x_0)} - h_n^2 \left( \frac{1}{2} m''(x_0) + m'(x_0) \frac{f'_x(x_0)}{f_x(x_0)} \right) \int_{\mathbb{R}} K(z) z^2 dz - o(h_n^2) \right) \xrightarrow{p} 0
```

接下来，我们考虑 $\frac{\hat{m}_2(x_0)}{\hat{f}_x(x_0)}$ 的渐近性质。由于 $\mathbb{E}(\epsilon_1 | x_1) = 0$，

```math
\begin{aligned}
\mathbb{E}\left( \hat{m}_2(x_0) \right) &= \frac{1}{h_n} \mathbb{E}\left( K\left( \frac{x_0 - x_1}{h_n} \right) \epsilon_1 \right) \\
&= \frac{1}{h_n} \mathbb{E}\left( \mathbb{E}\left( K\left( \frac{x_0 - x_1}{h_n} \right) \epsilon_1 \mid x_1 \right) \right) \\
&= \frac{1}{h_n} \mathbb{E}\left( K\left( \frac{x_0 - x_1}{h_n} \right) \mathbb{E}\left( \epsilon_1 \mid x_1 \right) \right) \\
&= 0
\end{aligned}
```
