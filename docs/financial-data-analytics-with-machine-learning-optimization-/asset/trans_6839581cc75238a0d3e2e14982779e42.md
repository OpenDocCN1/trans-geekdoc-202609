

# Logistic Regression Decision Threshold

在逻辑回归中，普通用户可能会采用带有特征向量 `x` 的观测值，并将其分类到组 `c₁`，前提是预测概率满足 `P̂(y = c₁ | x) ≥ 0.5`。然而，0.5 的决策阈值并不总是合适。例如，在罕见疾病的医疗诊断中，如果决策阈值设置得过高，相当数量的感染患者可能会收到阴性诊断结果，从而延误治疗。另一方面，如果阈值设置得过低，诊断将变得毫无意义。选择一个合适的判定概率 `u` 至关重要，使得当预测概率大于 `u` 时，具有特征向量 `x` 的患者被分类为阳性；否则为阴性。

另一个来自金融的例子是，通过二元逻辑回归估计客户违约概率并分类其信用状况。对于贷款申请，决策阈值 `u` 可以适当选择如下：首先，考虑以下关于放贷潜在损失的表格：

| 决策 ∖ 借款人 | 未违约（实际 `y = 0`） | 违约（实际 `y = 1`） |
| --- | --- | --- |
| 接受（预测 `y = 0`） | 正确 | 错误（成本 = `$u₂`） |
| 拒绝（预测 `y = 1`） | 错误（成本 = `$u₁`） | 正确 |

存在两种误分类成本 `u₁` 和 `u₂`，它们不必相等。令 `p(x) = P(违约 | x)` 和 `1 − p(x) = P(未违约 | x)`。因此，拒绝未违约借款人的预期损失为 `u₁(1 − p(x))`；而接受违约借款人的预期损失为 `u₂p(x)`。平均而言，如果 `u₁(1 − p(x)) < u₂p(x)`，或者等价地 `p(x) > u₁ / (u₁ + u₂) =: u`，则拒绝申请是合理的，这是一个理想的 *决策阈值*。在特殊情况下，当 `$u₁` 等于 `$u₂` 时，`u` 简单地为 `1/2`。
