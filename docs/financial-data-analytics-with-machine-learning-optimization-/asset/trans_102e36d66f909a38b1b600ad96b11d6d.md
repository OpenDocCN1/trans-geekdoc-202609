# 第 3 章

## 金融数据的统计诊断

`Black–Scholes–Merton` 模型的简单版本假设股票在不同日子的收益服从独立同分布正态分布，但在现实中，使用真实证券数据时，我们发现正态性假设通常无效，因为收益的分布具有更厚的尾部特性。在本章后半部分，我们将用其他更厚尾部的分布来替代价格比值对数的正态分布，然后研究这些新模型的有效性。

### 3.1 相对股票价格变化的正态性假设

Black–Scholes–Merton 模型 [[1]](#c03.xhtml#c03-bib-0001) 的基本假设是，在长度为 `delta t` 的短时间段内，股票价格的百分比变化服从正态分布；这意味着，近似地，
