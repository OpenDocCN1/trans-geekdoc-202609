## Theorem 6.4 (马尔可夫链收敛定理：有限状态空间)

Let `{x_n}` be an irreducible and aperiodic Markov chain with a finite state space `S = {s_1, ..., s_K}`, a transition matrix `P`, and an arbitrary initial distribution `μ^(0)`. Then for any distribution `π` which is stationary for `P`, we have

`μ^(n) →_TV π`

where `μ^(n)` is the distribution of `x_n` initialized by `μ^(0)`.

*Proof.* When studying the behavior of `μ^(n)`, we may assume that `(x_0, x_1, ...)` has been obtained by the simulation method:

```
x_0 = ψ_{μ^(0)}(u_0) ~ μ^(0), x_n = φ(x_{n-1}, u_n) ~ P(x_n = · | x_{n-1}), n = 1, 2, ...
```

where `ψ_{μ^(0)}` is a valid initiation function
