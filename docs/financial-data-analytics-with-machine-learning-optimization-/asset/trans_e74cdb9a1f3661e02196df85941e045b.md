We remark that since `π_i = exp(x_i^T β) / (1 + exp(x_i^T β)) ∈ (0, 1)`, for all `i = 1, ..., n`, the matrix `X^T R X` is positive definite, hence the Hessian `H` is invertible. The procedure of finding `β` via ([10.26](#c10.xhtml#c10-disp-0076)) is commonly called *Iteratively Reweighted Least Squares* (IRLS). As the changes in the values of `β(k)`'s tend to reduce in order as the log‐likelihood `l` (as well as the likelihood `L`) approaches its global maximum, we may terminate the iteration when the percentage change of `β(k)` is smaller than a prescribed threshold `ε > 0`, i.e., stopping at the iteration step `k + 1` when

(10.27)
```
||β(k+1) - β(k)||_2 / ||β(k)||_2 < ε.
```
