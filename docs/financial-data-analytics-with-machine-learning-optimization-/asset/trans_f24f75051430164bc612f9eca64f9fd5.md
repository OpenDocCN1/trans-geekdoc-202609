

方程（[8.10](#c08.xhtml#c08-disp-0041)）表明，联合分布函数总是可以分解为由 copula 函数连接的底层边缘分布。因此，copula `C` 捕获了边缘随机变量之间如何相互依赖的所有信息。这一事实，即 copula 完全反映了依赖结构，体现在其不变性属性上：在边缘分布的任何严格单调变换下，copula 保持不变。反之，对于任何具有 `d` 个参数和边缘分布 `F₁, …, F_d` 的 copula `C`，方程（[8.10](#c08.xhtml#c08-disp-0041)）右侧的函数定义了一个联合分布函数，其边缘分布分别为 `F₁, …, F_d`。这一事实为我们提供了一种有用的方法，通过各种 copula 的选择，从给定的边缘分布构建多变量分布函数。有关 copula 的理论和实际方面的进一步讨论，请参阅 [28](#c08.xhtml#c08-bib-0028)、[31](#c08.xhtml#c08-bib-0031)、[33](#c08.xhtml#c08-bib-0033)、[35](#c08.xhtml#c08-bib-0035)。

除了方程（[8.10](#c08.xhtml#c08-disp-0041)）将联合下尾概率与 copula 相关联之外，人们还可以考虑其上尾对应物，其表述如下。对于任何随机向量 `x`，

```
P(x₁ > x₁, …, x_d > x_d) = Ĉ(F̄₁(x₁), …, F̄_d(x_d)), x ∈ ℝᵈ
```

其中 `Ĉ` 称为 `x` 的 *生存 copula*，`F̄ᵢ` 是随机变量 `xᵢ` 的生存分布，`i = 1, …, d`。

在金融领域，copula 已被证明在金融的各个领域都很有用，包括但不限于定量风险管理、投资组合管理与优化以及金融衍生品定价。其应用的一个典型示例是对公司的压力或稳健性进行测试，这在 2007–2008 年全球金融危机期间经济极度衰退时发挥了特别关键的作用。此外，各种金融产品（如债券和贷款）的损失分布估计也涉及将 copula 作为重要工具。

许多投资者在熊市中会表现出被称为 *flight-to-quality* 的行为，即从风险较高的股票或房地产转向“更安全”的现金或债券以寻求避风港；因此，他们倾向于在短时间内摆脱大部分风险资产，这解释了为什么在熊市中股票之间的依赖性比在牛市中更强，这可能对整体经济产生灾难性影响；事实上，一天内出现数百万巨额损失的新闻在金融头条上出现的频率远高于在类似时间跨度内出现同等水平巨额利润的新闻。

接下来，我们将介绍几种常用的 copula。

## (I) 独立 copula

*独立 copula* 可以说是最简单的 copula。顾名思义，它对应于边缘变量相互独立的情况。该 copula 可以表示为：

```
Π(u) = ∏_{i=1}^{d} uᵢ
```

随机变量独立当且仅当其 copula 为独立 copula，这是一个基本事实。在本节后面，我们将看到独立 copula 也是具有生成函数 `ψ(x, θ) = −ln x` 的 Archimedean copula。
