
# 11.A.2.3 Primal and Dual Formulations of QP Problems

By using the duality result introduced in Subsection 11.A.2.2, here we reformulate the QP problem of ([11.23](#c11.xhtml#c11-disp-0051)) with the constraint of ([11.24](#c11.xhtml#c11-disp-0052)) by using the Lagrangian multiplier approach; see [\[3\]](#c11.xhtml#c11-bib-0003) for further discussions on this approach. The Lagrangian `L`, with `λ₁ ∈ ℝᴷ`, `λ₂ ∈ ℝᴹ`, is given by:

[(11.43)](#c11.xhtml#R_c11-disp-0102)

```
L(x, λ₁, λ₂) = 1/2 xᵀPx + qᵀx + r + λ₁ᵀ(Gx - h) + λ₂ᵀ(Ax - b)
             = 1/2 xᵀPx + (q + Gᵀλ₁ + Aᵀλ₂)ᵀx - λ₁ᵀh - λ₂ᵀb + r,
```

where `λ₁ ≥ 0` and `λ₂ ∈ ℝᴹ`.

```
∇ₓL(x, λ₁, λ₂) = Px + (q + Gᵀλ₁ + Aᵀλ₂) = 0,
```
