此处附带了用于当前股票价格预测 MLP 模型的详细 Python 编程代码；请参见 [程序 15.18](#c15.xhtml#c15-sec-3018)。

在结束本节之前，我们对一些相关语法和编码实践进行说明。

`tensorflow` 库已广泛用于 Python 和 `R` 中的深度学习。它最初由 `Google Brain` 团队开发用于内部使用 [\[1\]](#c15.xhtml#c15-bib-0001)，随后于 2015 年向公众开放。然而，`tensorflow` 本身是由 Python、C++ 和 CUDA（统一设备架构）构建的。

`generate_dataset()` 函数接收两个参数，`price` 参数用于输入训练数据集和测试数据集，而 `seq_len` 接收一个整数，表示输入特征的移动窗口宽度，在我们的股票价格预测示例中该值为 10。该函数返回两个 `numpy` 数组，即数据集的观测值 ![bold-italic x](images/c15-i0129.png)<math display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">x</mi></mrow></math> 和标签 ![y](images/c15-i0130.png)<math display="inline" overflow="scroll"><mrow><mi>y</mi></mrow></math>。
