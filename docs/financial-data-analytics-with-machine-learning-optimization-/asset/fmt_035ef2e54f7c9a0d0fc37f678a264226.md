
Recall that the standard Student's `t`-distribution with `ν` degrees of freedom has a finite mean because for `ν > 1`, `lim (t → ∞) (1 + t²/ν)^((1 - ν)/2) = 0`, hence

`ES_t(p) = 0 - ν / ((1 - ν)(1 - p)) · Γ((ν + 1)/2) / (√(νπ) Γ(ν/2)) · (1 + q_p²/ν)^(-(ν + 1)/2) (1 + q_p²/ν)`

`= (ν + q_p²) / (ν - 1) · τ_ν(q_p) / (1 - p),`

where `τ_ν(·)` is the density function of the standard Student's `t`-distribution with `ν` degrees of freedom. Therefore, the expected shortfall on `L` is:

(8.6) `ES_L(p) = μ + σ √((ν - 2)/ν) · (ν + q_p²) / (ν - 1) · τ_ν(q_p) / (1 - p).`
