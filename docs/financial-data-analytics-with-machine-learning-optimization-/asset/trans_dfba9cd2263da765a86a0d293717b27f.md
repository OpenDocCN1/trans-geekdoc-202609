

特别是，考虑到 `K`‐NN 分类的多数投票特性，参数 `K` 通常被选择为奇数以避免平局，但分类结果可能会随 `K` 的变化而改变。以 [图 14.8](#c14.xhtml#c14-fig-0008) 为例，即将未标记的观测值（中心的绿色点）分类为蓝色方形或红色菱形之一。当 `K = 3` 时，最近的三个观测值包含两个蓝色方形和一个红色菱形，因此该观测值将被分类为蓝色方形。然而，当 `K = 9` 时，分类结果变为红色菱形，因为在最近的 9 个观测值中有 4 个蓝色方形和 5 个红色菱形。

在符号上，我们假设一个包含 `n` 个数据点并划分为 `c` 个类别的数据集，`{x_i^(k)}`，`k = 1, ..., c` 和 `i = 1, 2, ..., n_k`，其中 `n_k` 是第 `k` 个类别中的数据点数量。对于 `K` 的一般值，我们根据 `K` 个最近数据点中出现频率最高的类别标签来分类 `x`。对于 `k = 1, ..., c` 和 `i = 1, 2, ..., n_k`，定义 `r_x(x_i^(k))` 为 `x_i^(k)` 与 `x` 之间所有欧几里得距离（即 `||x - x_i^(k)||_2`）的升序排序排名。然后，在 `K` 个最近数据点中，类别 `k` 中的观测值数量为 `K_k := |K_k|`，其中 `K_k := {i : r_x(x_i^(k)) <= K}` 表示这些点的集合。`x` 的分类结果 `m_x` 则为多数类：

```
m_x := arg max_{k = 1, ..., c} K_k.
```
