作为旁论，冯·诺伊曼极小极大定理实际上与经济学中至关重要的 `Nash equilibrium` 概念密切相关，该概念是 `noncooperative game theory` 的核心。定义两名玩家进行博弈时的联合满意度函数为 `J(x, y)`，其中 `x ∈ X` 和 `y ∈ Y` 分别是玩家 1 和玩家 2 独立采用的策略。我们称一对策略 `(x*, y*) ∈ X × Y` 为 `Nash equilibrium`，如果

```
max_{x∈X} J(x, y*) = J(x*, y*) and max_{y∈Y} J(x*, y) = J(x*, y*).
```

根据定义，Nash equilibrium 代表了博弈的一个稳定解，因为如果玩家以这种方式进行博弈，任何一方都没有动机单方面更改为另一种策略，因为每个玩家的策略都是对其对手所采用策略的最佳响应。博弈论的一个基本结果指出，在以下假设下，每个此类博弈的 Nash equilibrium 总是存在：

1. **(A1)** `X` 和 `Y` 都是有限维空间的非空紧凸子集；

2. **(A2)** `J(x, y)` 对于每个 `y ∈ Y` 在 `x` 中是凹的，并且对于每个 `x ∈ X` 在 `y` 中也是凹的；

3. **(A3)** `J(x, y)` 是联合连续的。
