

### 11.2.1 SVM 中的原问题与对偶问题

可以观察到，([11.9](#c11.xhtml#c11-disp-0018)) 确实是一个二次规划（QP）问题。为了求解这个（原问题）中寻找最优参数 `ω*` 和 `b*` 的问题，如在 ([11.9](#c11.xhtml#c11-disp-0018)) 中所示，我们可以采用 QP 问题的对偶方法，通过最大化对偶拉格朗日函数（即相应的对偶问题）来求解；有关更多细节，请参见附录 \*11.A.2.3。为此，我们先写出拉格朗日函数：

`L(ω, b, λ₁, ..., λₙ) = 1/2 ωᵀω − Σᵢ₌₁ⁿ λᵢ{yᵢ(xᵀᵀω + b) − 1}, λᵢ ≥ 0, i = 1, ..., n.`

该拉格朗日函数对 `ω` 和 `b` 的偏导数分别为：

`∇_ω L(ω, b, λ₁, ..., λₙ) = ω − Σᵢ₌₁ⁿ λᵢ yᵢ xᵢ;`
`∂L(ω, b, λ₁, ..., λₙ)/∂b = −Σᵢ₌₁ⁿ λᵢ yᵢ.`

当将这些偏导数设为零时，我们得到

`ω = Σᵢ₌₁ⁿ λᵢ yᵢ xᵢ and Σᵢ₌₁ⁿ λᵢ yᵢ = 0.`

[(11.9)](#c11.xhtml#R_c11-disp-0018)
`minimize ω, b`
`1/2 ωᵀω,`
`subject to yᵢ(xᵀᵀω + b) ≥ 1, for all i = 1, ..., n.`
