
3. 如果 `s₁` 可以在 `m` 步内访问 `s₂`，那么 `s₁` 也可以在 `m + n d(s₁)` 步内访问 `s₂`，对于任何足够大的 `n ≥ 0` 都成立。

以下结果表明，非周期且不可约的马尔可夫链是正则的；它们类似于有限状态空间情况下的 [定理 6.1](#c06.xhtml#c06-fea-0004) 和 [推论 6.1](#c06.xhtml#c06-fea-0008)。它们的证明见 [附录 *6.A.3](#c06.xhtml#c06-sec-0039)。

**定理 6.2** 设 `{xₙ}` 为一个具有不可计数状态空间的非周期马尔可夫链。在 [假设 6.1](#c06.xhtml#c06-fea-0012) 下，存在 `N ∈ ℕ`，使得对于任何 `n ≥ N` 和任何 `s ∈ S`，都有 `fⁿ(s) > 0`，对于任何 `f ∈ ℬ₊(S)` 且 `f(s) > 0` 成立。

**[推论 6.2](#c06.xhtml#R_c06-fea-0020)** 设 `{xₙ}` 为一个具有不可计数状态空间的非周期且不可约的马尔可夫链。在 [假设 6.1](#c06.xhtml#c06-fea-0012) 下，存在 `N ∈ ℕ`，使得对于任何 `n ≥ N` 和任何 `s₁, s₂ ∈ S`，都有 `fⁿ(s₁) > 0`，对于任何 `f ∈ ℬ₊(S)` 且 `f(s₂) > 0` 成立。
