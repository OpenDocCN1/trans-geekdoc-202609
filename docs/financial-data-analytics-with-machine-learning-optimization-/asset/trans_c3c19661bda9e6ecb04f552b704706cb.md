## 9.11 推荐系统

推荐系统，常见于 `Meta`、`Amazon` 和 `Netflix`，有助于预测订阅者会给某个项目的“评分”或“偏好”。近年来，它越来越流行，并被广泛应用于电影、音乐、新闻、图书、研究文章、搜索查询、社交标签甚至杂货等多个领域。推荐系统可用于营销科学研究和商业信息学，以制定更好的商业解决方案以最大化公司利润。还有针对娱乐企业、餐馆、服装、金融服务、保险产品、浪漫伴侣寻找（在线约会）和 `X`（原 `Twitter`）页面的推荐系统。

在本节余下部分，我们将介绍一种常用推荐系统背后的理论与 PCA 之间的基本联系。为了说明这一点，假设我们创办了一家提供在线电影观看服务的初创公司。该公司已吸引了 `i = 1, 2, ..., m` 名订阅者，并获得了 `j = 1, 2, ..., n` 部电影。每位订阅者在观看后被邀请对电影进行评分，评分范围为 `r = 1, 2, ..., 5`（当然也允许连续评分），其中 `r = 1` 表示最差，`r = 5` 表示最佳。这些评分存储在一个 `m × n` 稀疏 `FIGURE 9.15 Netflix Prize, October 2006. 请注意，对于订阅者尚未观看或评分的电影，评分仍保持在 `r = 0`。基于这些数据，我们希望构建一个推荐系统来了解每位订阅者的口味，从而可以对特定订阅者尚未观看的电影的评分进行预测，并推荐任何未来的电影。

这里我们介绍一种称为 *latent‐factor method*（矩阵分解）的流行方法，用于 *collaborative filtering*。

另一方面，这些隐藏特征也可用于描述订阅者对不同电影的偏好。对于订阅者 `i`，我们希望评估一系列得分 `p_i,k`，针对所有隐藏特征 `k = 1, 2, ..., p`，这些特征最能描述第 `i` 位订阅者对电影的品味。这些得分将集体存储在另一个 `m × p` 矩阵 `bold-italic upper P = (p_i,k)_{m × p}` 中，该矩阵也需要被估计。
