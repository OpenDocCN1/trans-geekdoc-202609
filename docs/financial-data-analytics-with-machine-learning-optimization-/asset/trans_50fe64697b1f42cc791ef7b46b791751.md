## 11.2 支持向量机

`Support vector machines` (SVMs) choose a separating hyperplane which maximizes the margin between the two classes. In other words, the distance from the hyperplane to the nearest data point from each category is maximized. There are a number of monographs that discuss this tool in detail, such as [\[1](#c11.xhtml#c11-bib-0001), [10](#c11.xhtml#c11-bib-0010), [11](#c11.xhtml#c11-bib-0011), [23\]](#c11.xhtml#c11-bib-0023).

![FIGURE 11.7 An example of an SVM model for two‐dimensional feature vectors.](images/c11f007.png)

[**FIGURE 11.7**](#c11.xhtml#R_c11-fig-0007) An example of an SVM model for two‐dimensional feature vectors.

For choosing the hyperplane, SVM does not make use of all the available data. Instead, only the points, called `support vectors`, that are closest to the hyperplane are relevant; see [图 11.7](#c11.xhtml#c11-fig-0007). Support vectors are used to define the hyperplane, and at the same time, they are the most difficult to be classified correctly; they carry the most important information for the classification problem.
