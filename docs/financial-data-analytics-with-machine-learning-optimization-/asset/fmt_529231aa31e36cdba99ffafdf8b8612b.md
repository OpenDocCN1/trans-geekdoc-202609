
# Dropout 正则化技术

Dropout 首先在 [\[9\]](#c15.xhtml#c15-bib-0009) 提出，是一种正则化技术，其效果本质上与回归中的正则化相同，如 [Chapter 11](#c11.xhtml) 所述。它通常用于深度神经网络，以防止过拟合并提高对外部样本的泛化能力。在训练阶段，一部分单元会被随机选中，通过将其对应的输出设为零来停止工作；换句话说，它们暂时从处理过程中“退出”。这为系统引入了随机性，同时减少了 LSTM 单元之间的相互依赖，从而迫使网络学习更强健、更具泛化能力的表示。通过随机丢弃单元，Dropout 防止单个单元过度依赖特定的输入模式或与其他单元共适应。这鼓励网络学习更多样化和独立的特征，增强其对未见数据的泛化能力。

通俗地说，为了启发式地理解 Dropout 的概念，可以想象一个有许多工人的工厂。他们协作完成一个“庞大”的生产流程，因此每个工人的小任务相对简单，而每个工人不需要只负责一项服务，而是可以负责几项；尽管如此，每个工人仍然负责一项简单的任务。这个庞大的生产流程由大量小任务组成，每个部分由少数几名工人负责。当然，不同的工人有不同的优势和劣势，他们会影响最终产出的整体质量。例如，一个粗心的工人可能在生产早期出错，后续阶段的其他工人可能会使情况恶化，无法挽救最终产出的整体质量。因此，作为经验法则，为了提高生产质量，一个成功的工厂应该有能够与任何其他工人协作的员工，尽管他们当时相对较弱，后者可以通过向有能力的工人学习来培训。同样，在 LSTM 中，如果一个 LSTM 单元输出“错误”值，由于高度连接的网络结构，所有后续 LSTM 单元都无法避免做出更差的预测。这意味着不同单元具有不同的预测能力；如上述工厂类比所示，如果大多数较弱的单元可以通过较小的分组训练从更有能力的单元中学习，模型可以变得更稳定。借助 Dropout 层机制，每个单元都有机会学习与不同层中大约 `1 - d` 的其他单元密切协作，其中 `d` 是 Dropout 比率。这通常会提高每个单元的整体性能，并打破共适应问题，使单元之间的依赖性降低，从而通过鼓励它们全力运作来减少每个单元的任何可能冗余。

# 双层 LSTM 模型构建

我们将构建一个两层 LSTM 模型，第一层和第二层分别包含 `p` 和 `q` 个一维张量 LSTM 记忆单元，用于比特币价格预测。特别是，两层中的一维张量记忆单元数量 `p` 和 `q` 被称为超参数。LSTM 模型有大量超参数需要确定。其他超参数包括，例如，输入序列的长度 `T`，以及每个 LSTM 层的 Dropout 比率 `d`。为了选择正确的超参数集，唯一可用的选项是逐一尝试。然而，这种方法可能非常耗时且低效。在实践中，我们可以限制可能候选者的集合，并通过比较从验证数据集计算出的相应损失，在其中获得一个次优集。验证数据集应独立于训练数据集，且不得用于训练。在此示例中，我们考虑以下超参数选择：(i) `T = 5, 10, 15`；(ii) `p, q = 8, 16, 32`，对应于每个 LSTM 层的记忆单元数量；以及 (iii) `d1, d2 = 0, 0.2, 0.4`，分别对应于第一层和第二层 LSTM 层的 Dropout 比率。我们将随机抽取 10% 的训练数据作为验证数据（在 Python 中，调用 `fit()` 时通过指定 `validation_split=0.1` 来完成），候选集（`T = 10`，`q = 16`，`r = 32`，`d1 = 0`，和 `d2 = 0.4`）在验证数据集上实现了最低的 MSE。因此，我们将基于验证数据的 MSE 为 LSTM 模型采用这一组超参数。最后，我们将使用 `tensorflow` 和完整的训练数据集训练我们的 LSTM 模型。
