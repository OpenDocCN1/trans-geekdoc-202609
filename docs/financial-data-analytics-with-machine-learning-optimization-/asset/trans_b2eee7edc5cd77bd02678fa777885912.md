y_t &= x_t^\top \beta + v_t \\
v_t &= -\phi_1 v_{t-1} - \phi_2 v_{t-2} - \cdots - \phi_m v_{t-m} + \varepsilon_t \\
\varepsilon_t &= \sqrt{h_t} e_t, \quad e_t \overset{\text{iid}}{\sim} N(0, 1) \implies \varepsilon_t \overset{\text{iid}}{\sim} N(0, h_t) \\

这个模型有时被称为 AR(`m`)-GARCH(`p`, `q`) 模型。在 SAS 中，有一个 AUTOREG 过程可以拟合该模型，而 `R` 中的 `rugarch` 包也可以实现此目的。然而，Python 中没有功能相同的成熟库，因此我们需要按照上述顺序方式进行拟合。该过程允许我们将 GARCH(`1`, `1`) 模型拟合到股票价格的百分比变化上。

## 7.4.6 GARCH(`1`, `1`) 模型的扩展

在本小节中，我们介绍两种常用的 GARCH(`1`, `1`) 模型扩展。我们将分析在 `R` 中获得的结果，而对于 Python，仅提供校准程序。

### 7.4.6.1 杠杆 GARCH(`1`, `1`) (L-GARCH)

*杠杆 GARCH* (L-GARCH) 模型也称为 *阈值 GARCH* (T-GARCH) 模型，或 *Glosten, Jagannathan 和 Runkle GARCH* (GJR-GARCH) 模型 [[14](#c07.xhtml#c07-bib-0013)]。为了考虑股票价格负向波动对波动率的非对称影响，我们将 GARCH(`1`, `1`) 模型扩展为以下 GJR-GARCH(`1`, `1`) 模型：

[(7.24)](#c07.xhtml#R_c07-disp-0043)

```math
\sigma_n^2 = \omega + \beta \sigma_{n-1}^2 + \alpha u_{n-1}^2 + \theta I_{n-1} u_{n-1}^2
```
