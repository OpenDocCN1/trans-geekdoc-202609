
# Newton's Method for Logistic Regression MLEs

Let us adopt Newton's method, similar to ([10.23](#c10.xhtml#c10-disp-0068)), to the finding of MLEs for logistic regression. Denote `−ln L(β)` (as defined in ([10.14](#c10.xhtml#c10-disp-0034))) by `−l(β)` for the sake of notational simplicity. With an initial seed `β^(0)`, we construct iteratively the sequence of approximants, with `k = 0, 1, …`:

[(10.25)](#c10.xhtml#R_c10-disp-0073)

```
β^(k+1) = β^(k) − [∇_β ∇_β^T (−l(β^(k)))]^−1 ∇_β (−l(β^(k)))
        = β^(k) − (H(β^(k)))^−1 ∇_β l(β^(k))
```
