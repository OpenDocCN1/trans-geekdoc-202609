

这个结果可以用于指导 `h_n` 的最优选择，以最小化相应估计器 `m̂(x_0)` 的均方误差；回顾一下

`MSE(m̂(x_0)) = [Bias(m̂(x_0))]^2 + Var(m̂(x_0)) ≤ C_1^2 h_n^4 + C_2 / (n h_n),`

我们的目标是确定作为 `h_n` 函数而最小化该上界的 `h_n` 阶数。根据一阶条件，`4 C_1^2 h_n^3 - C_2 / (n h_n^2) = 0`，由此可得 `h_n* = (C_2 / (4 n C_1^2))^(1/5) = O(n^(-1/5))`。结合该上界的凸性，因为其二阶导数对所有 `h_n > 0` 均满足 `12 C_1^2 h_n^2 + 2 C_2 / (n h_n^3) > 0`，我们可以得出结论：选择阶数为 `O(n^(-1/5))` 的 `h_n` 可以尽可能地减少并界定模型的 MSE，如前所述。
