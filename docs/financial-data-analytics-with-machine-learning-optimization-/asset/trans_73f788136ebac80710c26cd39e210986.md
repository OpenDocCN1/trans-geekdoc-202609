

1. **(1)** 当 `a² > p λ_max` 时，有 `t₁ > 0`，因此 `t₁* = t₁`，且 `h(t)` 在 `h(t₁) = -p/2 ln(p λ_max / a²) - (a² - p λ_max) / 2 λ_max` 处取得最小值；

2. **(2)** 当 `a² ≤ p λ_max` 时，有 `t₁ ≤ 0`，因此 `t₁* = 0`，且 `h(t)` 在 `h(0) = 0` 处取得最小值。

综合上述情形，对于所有 `0 ≤ t < 1 / 2 λ_max`，均有 `h(t) ≥ -p/2 ln(p λ_max / a²) - (a² - p λ_max) / 2 λ_max`，由此可得 ([14.21](#c14.xhtml#c14-disp-0074)) 的下界如下：对于所有 `i = 1, ..., n`，

```
P(x_i ∈ B_G(S_i)) ≥ 1 - e^(h(t))
≥ 1 - (p λ_max / a²)^(-p/2) exp(-(a² - p λ_max) / 2 λ_max)
≥ 1 - (p / a)^(-p) exp(-(a² - p²) / 2p),
```

其中最后一个不等式源于相关矩阵 `V_ik` 的性质 `λ_max ≤ p`。
