

注意，对于所有五个家族，参数 `θ` 值越大，表示依赖性越强；所有家族（Frank copula 除外）在 `θ` 取其各自范围的最小值时都会退化为独立 copula，而对于 Frank copula，`θ` 趋近于 0 的极限情况对应于独立 copula。这五个 copula 家族的双变量情况的散点图（每个基于 2,000 个模拟点）在 [图 8.20](#c08.xhtml#c08-fig-0020) 和 [图 8.21](#c08.xhtml#c08-fig-0021) 中描绘。

了解以上所有内容后，我们来考察当概率水平趋近于 1 时，由 Archimedean copula 给出依赖性的风险组合 `x₁, …, x_d` 的总损失的风险价值（Value-at-Risk）的渐近行为。更准确地说，我们假设

```
P(x₁ > x₁, x₂ > x₂, …, x_d > x_d) = ψ^[−1](Σᵢ₌₁^d ψ(F̄ᵢ(xᵢ)))
```

其中 `F̄ᵢ` 是 `xᵢ` 的生存函数，`ψ: [0, 1] → [0, ∞)` 是一个 *regularly varying* 的生成器。

1. 当 `α* > 1` 时，`V@R` 渐近次可加：

```
lim sup (p→1) V@R_p(s) / Σⱼ₌₁^d V@R_p(xⱼ) ≤ 1;
```

2. 当 `0 < α* < 1` 时，`V@R` 渐近超可加：

```
lim inf (p→1) V@R_p(s) / Σⱼ₌₁^d V@R_p(xⱼ) ≥ 1;
```
