因此，

```
P(T > 2M) = P(T > M) P(T > 2M | T > M)
          ≤ (1 - α²) P(T > 2M | T > M)
          ≤ (1 - α²) P(x₂ₘ ≠ x′₂ₘ | T > M)
          ≤ (1 - α²)²
```

通过迭代这一论证，我们得到，对于任何 `ℓ`，

`P(T > ℓM) ≤ (1 - α²)^ℓ → 0, as ℓ → ∞`
