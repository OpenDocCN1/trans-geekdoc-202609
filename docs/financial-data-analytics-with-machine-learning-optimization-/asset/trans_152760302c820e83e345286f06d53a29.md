

接下来，对于 `u = 0.95`，只要 `π̂ᵢ > 0.95`，任何观测值都会被分类为正例。然后，10 个正例观测值中只有一个（`i = 1`）会被正确分类，因此 `TPR = 1 / 10 = 0.1`（其中 `TP = 1` 且 `FN = 9`）。另一方面，没有假阳性，即 `FP = 0`，因此 `FPR = 0`。

从上述 `u` 的两个特定值可以看出，随着概率阈值 `u` 的降低，TPR 和 FPR 通常都会增加。ROC 曲线如 [图 10.9](#c10.xhtml#c10-fig-0009) 所示，说明了当概率阈值 `u` 从 1 变化到 0 时，TPR（`y` 轴）和 FPR（`x` 轴）的变化情况。一般来说，随着样本量 `n` 的增加，ROC 曲线会变得更加平滑。事实上，给定按 `π̂ᵢ` 降序排列的观测值，绘制 ROC 曲线的一般步骤如下：从原点 `(0, 0)` 开始，按顺序查看观测值的标签。如果 `π̂ᵢ = 1`（或 0），则垂直方向上移 `1 / n₁` 的大小（或水平方向右移 `1 / n₀` 的大小），其中 `n₁` 和 `n₀` 分别是类别 1 和类别 0 中的观测值数量。当对所有观测值重复此过程时，最终会到达 `(1, 1)`。该步骤也表明了曲线的凹性。

[图 10.10](#c10.xhtml#c10-fig-0010) 展示了两个不同的 ROC 曲线，用于检验两个二元逻辑回归在两个不同数据集上的性能。红色虚线显示的是更容易分为两组的数据集的 ROC 曲线，因此较高的 TPR 对应较小的 FPR。相比之下，蓝色实线 ROC 曲线对应的是相对较难清晰分离的分类。一般来说，易于分离的数据集或非常可靠的分类算法的 ROC 曲线倾向于靠近单位正方形的左上角。当所有正例观测值都能被正确分类（`TPR = 1`）且没有负例观测值被误分类为正例（`FPR = 0`）时，无论 `u` 取何值，相应的 ROC 曲线都会退化为单位正方形左上角的单个点。

此外，ROC 曲线可用于比较应用于同一数据集的不同分类算法的性能。一种可能的方法是比较 ROC 曲线的 *Area Under Curve*（AUC），AUC 越大，算法的性能越好。
