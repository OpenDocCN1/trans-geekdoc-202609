
For a fixed `p`, our task is to approximate the matrices `P` and `Q`, which contain a total of `(m + n) × p` unknown parameters. The product matrix `P Q^T` of size `m × n` can be compared to the subscriber's ratings stored in `R`. While `R` is sparse (since each subscriber has only viewed or rated a small portion of the entire movie database), our algorithm aims to minimize the deviation of the average between the known ratings of `r_i,j`'s and the corresponding ratings predicted by using `∑(k=1 to p) p_i,k q_j,k`. In other words, the objective is to minimize the following mean squared error (MSE):

(9.9)
```
J(p_i,k, q_j,k; 1 ≤ i ≤ m, 1 ≤ j ≤ n, 1 ≤ k ≤ p) := ∑(i=1 to m) ∑(j=1 to n) (r_i,j - ∑(k=1 to p) p_i,k q_j,k)^2
= ∑(i=1 to m) ∑(j=1 to n) (r_i,j - p_i^T q_j)^2 = tr((R - R̂)^T (R - R̂)) = ||R - R̂||_F,
```
