Turning back to the optional selling problem ([7.30](#c07.xhtml#c07-disp-0050)), we can interpret the mathematical result as saying one should buy a stock and hold it until the end of the investment horizon at `T` when `α ≥ 1/2`; otherwise, one should sell it at once when `α < 1/2`. Detailed proofs and variants of the problem can be found in \[[9, 10, 17, 29, 36–38](#c07.xhtml#c07-bib-0036)\]. Nonetheless, for this buy-and-hold or sell-at-once strategy, as it is dependent on a single index, the ultimate benefit can only be achieved on the average. Instead, in the following trading strategy, we focus on the optimal stopping time in a `probabilistic` manner (more along `pathwise sense`), which is more realistic and likely leads to a more profitable strategy. To this end, we first formally state both the corresponding optimal selling and buying problems as follows:

1. (*Selling problem*) For a fixed `p ∈ (0, 1)`, find the optimal selling (stopping) time `τ_S*` which maximizes the probability: [(7.33)](#c07.xhtml#R_c07-disp-0057) `sup₀≤τ_S≤T ℙ(S_τ_S ≥ p M_T)`, where `M_t := sup₀≤τ≤t S_τ` is the running maximum stock price over `[0, t]`.

2. (*Buying problem*) For a fixed `q > 1`, find the optimal buying (stopping) time `τ_B*` which maximizes the probability: [(7.34)](#c07.xhtml#R_c07-disp-0058) `sup₀≤τ_B≤T ℙ(S_τ_B ≤ q m_T)`, where `m_t := inf₀≤τ≤t S_τ` is the running minimum stock price over `[0, t]`.
