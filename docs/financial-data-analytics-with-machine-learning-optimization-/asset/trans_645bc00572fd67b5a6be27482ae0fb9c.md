

对于 `x_min` 的估计，我们回顾在 [第 3.1 节](#c03.xhtml#head-2-19) 中介绍的 Kolmogorov–Smirnov (KS) 距离概念，然后遵循 [[5]](#c04.xhtml#c04-bib-0005) 中提出的方法。考虑经验与理论幂律分布之间超出 `x_min` 的截断 KS 距离，定义如下：

(4.20)`K(x_min) := max_{x ≥ x_min} |F̂(x) − F(x)|`

其中 `F̂(x)` 是高于 `x_min` 的数据的经验分布，`F(x)` 是高于 `x_min` 的数据的最佳拟合幂律分布；另请参见 [[7]](#c04.xhtml#c04-bib-0007)。为了估计 `x_min`，[[5]](#c04.xhtml#c04-bib-0005) 建议将估计值 `x̂_min` 取为 `K(x_min)` 的极小值，该值可通过 **R** 包 `poweRlaw` 数值求得。

得到估计值 `x̂_min` 后，估计 ([4.13](#c04.xhtml#c04-disp-0050)) 中参数 `β` 的两种最常见方法是普通最小二乘法 (OLS) 和 Hill 估计量。如 [[16]](#c04.xhtml#c04-bib-0016) 所述，虽然 OLS 是经验文献中最常用的方法，但它往往会低估幂指数。另一种称为 Hill 估计量的替代估计量由 [[17]](#c04.xhtml#c04-bib-0017) 提出，定义为

(4.21)`β̂_Hills := (n_tail − 1) / Σ_{i=1}^{n_tail − 1} (ln(z_i) − ln(z_n_tail))`

[[5]](#c04.xhtml#c04-bib-0005) 提出了一种检验方法，用于检验高于估计最小阈值 `x̂_min` 的数据的底层分布是否为具有估计尾指数 `β̂` 的幂律分布；同样，这可以使用包 `poweRlaw` 实现。该检验受 *bootstrapping* 概念的启发（另请参见 [第 8 章](#c08.xhtml) 中的替代讨论），其含义是检验统计量（即截断 KS 距离 `K(x̂_min)`）的分布由从拟合分布中抽取的自举样本的截断 KS 距离的经验分布近似。
