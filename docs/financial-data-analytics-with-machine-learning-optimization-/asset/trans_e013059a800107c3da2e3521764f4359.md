## 15.3 具有线性输出的 ANN

给定训练数据集中的输入 `x` 和输出 `y`，我们的目标是找到权重 `w<sub>ji</sub>`，使得平方误差之和：

```
E := 1/2 (y - o')^T (y - o')
```

最小化，其中 `o'` 是 ANN 的预测标签；特别是，如果生成线性输出，则 `o' = o`，即没有额外激活的直接输出。通常，目标函数 `E` 具有许多局部最小值，通常使用反向传播算法（一种常规随机梯度下降方法的迭代形式）来寻找“近似全局”最小值。在 Python 中，`sklearn` 库中的 `MLPRegressor()`（*多层感知机回归器*）函数可以实现单层甚至多层 ANN，由参数 `hidden_layer_sizes` 指定。特别是，隐藏层中使用参数 `activation` `="logistic"` 的逻辑激活函数，并且隐藏层中使用参数 `hidden_layer_sizes=2` 的 2 个隐藏神经元（如果使用 4-3-2-1 模型，可以设置 `hidden_layer_sizes=(3,2)`，但是所有隐藏层中使用的激活函数是统一相同的）。在 **R** 中，ANN 可以使用库 `nnet` 中的内置函数 `nnet()` 实现。我们接下来通过 Python 和 **R** 分别在程序 15.1 和 15.2 中使用鸢尾花数据集来说明 ANN 的构建。
