

考虑 `z = x + y (mod 1)`，其中 `x` 和 `y` 是定义在 `[0, 1)` 上的连续随机变量，其概率密度函数分别为 `f` 和 `g`。那么 `z` 也是一个连续随机变量，且具有密度 `h`，使得

```
h(t) = ∫₀¹ f(u) g(t - u) du = (f * g)(t),
```

这是 `f` 和 `g` 在有界范围上的通常卷积。对于 `n ∈ ℤ`，傅里叶系数 `ĥ(n)` 可以计算为 `f̂(n)` 和 `ĝ(n)` 的乘积：

**Lemma 4.2** 设 `f`、`g` 和 `h` 分别为 `x`、`y` 和 `z = x + y (mod 1)` 的连续概率密度函数，其中 `x` 和 `y` 是定义在 `[0, 1]` 上的连续随机变量。则 `ĥ(n) = f̂(n) ĝ(n)`。
