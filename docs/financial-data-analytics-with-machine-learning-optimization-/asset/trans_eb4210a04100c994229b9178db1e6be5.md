

让 `x` 是一个离散随机变量，其概率质量函数为 `p(x)`，其中 `x ∈ X`，`x` 的 Gini 系数 `G` 定义为：

[(13.11)](#c13.xhtml#R_c13-disp-0035)

```math
G(x) := 1 - \sum_{x \in X} p^2(x)
```

## 2. Misclassification Error

离散随机变量 `x` 的误分类误差定义为：

(13.12)

```math
\text{Misclassification Error}(x) := 1 - \max_{x \in X} p(x)
```

[Figure 13.4](#c13.xhtml#c13-fig-0004) 说明了当 `x` 是成功概率为 `p` 的伯努利随机变量时，熵、Gini 系数和误分类误差的各自行为。简单的微积分告诉我们，对于所有这些不纯度度量，最大值都在 `p = 1 - p = 1/2` 处达到，即两种结果等可能出现时。此时，二叉树的相应节点处于“最不纯”状态。

与熵的情况类似，对于取 `n` 个可能值的离散随机变量 `x`，当所有概率质量 `p(x) ≡ 1/n` 时，所有不纯度度量都达到各自的最大值，即所有结果都等可能出现；各种不纯度度量的相应最大值为：(1) 对于熵，它是 `H(x) = log₂ n`；(2) 对于 Gini 系数，它是 `G(x) = 1 - 1/n`。
