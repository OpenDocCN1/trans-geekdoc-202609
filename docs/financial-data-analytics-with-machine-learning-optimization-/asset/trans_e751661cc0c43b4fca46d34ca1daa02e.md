

本书探讨了针对现实场景并具有高获利潜力的当代金融数据分析实用技术，全书共15章，涵盖该领域广泛的重要和前沿主题。例如，我们将探讨投资策略、金融取证以及深度学习在金融中的即时应用。我们还将批判性地讨论机器学习工具的优缺点。虽然我们提醒注意深度学习等新方法的潜在陷阱，但我们还提出了一种新颖的特征工程方案，作为CIBer的一部分（参见[第12章](#c12.xhtml)），以克服现有方法在输入特征方面的局限性，并且该方案也取得了有前景的分类性能。全书提供了大量示例，我们重点介绍了来自现实金融市场的几个典型数据集，以便于模型之间的直观比较，让读者能够对其优缺点形成自己的判断，并因此将合适的数据分析方法应用于自己的数据集。Python和`R`的可执行详细程序代码也随相应示例一起提供。包括量化分析师和基金经理在内的从业者可以从本书中了解数据分析的最新进展，并帮助制定有效的投资策略或促进更好的产品设计。这些最新知识还可以进一步帮助他们在不同的业务学科中进行新颖的应用研究。我们还希望高年级学生和研究生能够加深对该领域的理解，并发现本书对其未来的学术研究有用。同时，本书内容还涵盖了不同公共专业考试中预测分析模块的大部分大纲，包括但不限于`精算师学会`的风险建模统计（SRM）考试和预测分析（PA）考试，使其成为这些专业考试合适的主要或补充阅读材料。

为了从本书中获益最大，建议读者具备扎实的概率与统计、线性代数和高等微积分背景，最好达到大二水平。对于本书的某些部分，具备实分析和复分析的一些基本知识将有助于全面理解它们。特别是，某些用星号标记的章节需要更高水平的数学理解，在初次阅读时可以省略。无论如何，为了读者的方便，一些相关的基础知识在[第1章](#c01.xhtml)中进行了回顾。熟悉Python或`R`等编程语言也非常有帮助。为了使本书更加自包含，[第2章](#c02.xhtml)中提供了这两种编程语言的快速概述。此外，对更复杂的投资策略和衍生品定价感兴趣的读者还需要伊藤随机微积分和连续鞅论的基础背景，鉴于该主题的技术性，这是不可避免的。

在撰写本书过程中，我们的多学科背景证明是有帮助的；我们都接受了精算科学、经济学与金融、数学、概率与统计方面的多样化培训，我们的研究还涉及数据分析在各种应用领域中的应用。我们与行业从业者建立了长期的研究合作关系，我们的许多本科生和研究生、朋友和同事也在金融和保险领域的世界领先公司工作。在香港这个传统的全球金融中心长大也为我们提供了实用的金融知识，这有利于我们的务实研究，而我们在解决研究和实际问题时并不受常规方法的束缚。此外，我们的研究生凯撒·范（Kaiser Fan）还通过以量身定制且富有启发性的方式实现示例中的大多数程序代码，做出了独特的贡献。

随着本书的出版，我们欢迎读者的宝贵反馈和评论。由于范围和时间的限制，我们无法详细探讨所有主题，并对任何遗漏的信息表示歉意。虽然我们从广泛的文献中汲取了灵感，并试图引用所有文献，但有些可能仍然在无意中被我们遗漏，我们对任何疏忽深表歉意。我们还从亚洲、澳大利亚、欧洲和北美著名大学的金融数据分析或同等课程中受益，包括教学材料和课程设计。

虽然我们相信本书提供了金融数据分析的宝贵工具集，但我们故意省略了区块链，因为它们已转向成为互联网和网络安全问题，而不是金融信息的分析工具。同时，我们即将出版一本关于深度学习及其在金融中某些应用的书籍，我们在本书的结尾章节中简要提及这一点。希望读者会喜欢当前的书籍，并关注即将发布的新书。

Sam Chen, Ka Chun Cheung, and Phillip Yam  

香港，2023年12月
