The packages from Entropy and developer Marc Liyanage are complete, well-maintained, and well-documented.

To obtain the PHP installation package, go to http://www.entropy.ch/software/macosx/php/ and look for the section titled “Installation Instructions.” Once there, follow the link to download PHP 5 for your version of Mac OS X. It is possible that this version of PHP will be a few versions behind the current Linux/UNIX build files or Windows installer.

When the download is complete, mount the disc image and double-click the *.pkg file. Perform the following installation steps to complete the process:

+   1. The PHP installer launches automatically, as shown in Figure 4.1. Click Continue to move to the next step.
