Then you have the opportunity to select the destination folder for the Apache files. By default this is C:\Program Files\Apache Software Foundation\Apache 2.2\—this location shouldn't cause you any problems. If you want to change it, click the Change button before you click the Next button.

Finally, Apache is ready to install. Click the Install button to start files copying to and setting up on your system.

When the installation operation is complete, the Apache server and monitor program will start and you will see a new icon in your system tray.

You can verify that Apache has started successfully by opening a web browser and visiting http://localhost/. The default Apache page will display, as shown in Figure 1.8.
