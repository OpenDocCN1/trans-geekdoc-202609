## 为 PHP 代码添加注释

编写时看似清晰的代码，六个月后试图修改时可能变得一团糟。在编写代码时添加注释，可节省日后时间，并让其他程序员更容易与您的代码协作。

_注释_ 是脚本中 PHP 引擎忽略的文本。注释可使代码更易读，或对脚本进行注释。

单行注释以两个正斜杠（`//`）开头——这是首选样式——或者以单个井号（`#`）开头。PHP 引擎会忽略这些标记之间以及行末或 PHP 闭合标记之前的所有文本：

```
# this is a comment
```

多行注释以正斜杠后跟星号（`/*`）开始，以星号后跟正斜杠（`*/`）结束：

```
/*
* this is a comment
* none of this will
* be parsed by the
* PHP engine
*/
```
