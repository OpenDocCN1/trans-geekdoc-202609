# ## Installing Apache

Click the button in the Windows DVD installation menu to begin installing Apache 2.2. At the screen shown in Figure 1.6, click the Next button to continue.

You must accept the license terms on the next screen to continue the installation operation, after which you will see some release notes. Click the Next button after you read the notes and you will see a request for you to enter your server information, as shown in Figure 1.7.
