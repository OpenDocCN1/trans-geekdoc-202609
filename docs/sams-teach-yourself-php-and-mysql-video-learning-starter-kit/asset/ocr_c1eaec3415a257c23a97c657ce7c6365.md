# FIGURE 1.7 Entering your Apache server details.

Enter your server's domain and hostname, and your email address.
If you are installing on a personal workstation, use localhost and
localdomain for your server information. Leave the radio button
selected on the Recommended option to install Apache on port 80.

The next screen asks you to choose a setup type, either typical or
custom. The typical setup is just fine, so leave the radio button selected
on that option and click Next to continue.
