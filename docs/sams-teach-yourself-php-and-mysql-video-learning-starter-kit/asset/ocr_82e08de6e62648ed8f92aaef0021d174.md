Many web hosting services offer PHP and MySQL access for customers who need them. If you’re uncertain about this, inquire with your service whether they offer PHP and MySQL or not, and if so how to use them on your service.

However, since you’re only going to be trying out simple exercises, and not presumably making your work available to the entire World Wide Web for now, a better solution for your learning environment might be to install the needed software on your computer using the DVD in this package. You don’t even need to be connected to the Internet to do this.

Since the instructions for Windows PC and Macs are somewhat different, we’ve included quick step-by-step instructions in two separate sections, one for Windows and one for Mac OS X. Just choose the one that’s right for you.

NOTE: The following installation guidelines are designed to get you up and running as quickly and efficiently as possible, using the software included on the DVD.

Should you have difficulties along the way, or if you want to download the most recent versions of PHP, MySQL or Apache from the Internet, more detailed instructions, with extended explanatory and trouble-shooting information, are available in the chapters immediately following this one.

# # Installing PHP, MySQL, and Apache on Windows

The setup files included on the DVD are suitable for Windows XP, 2003, and Vista. Earlier versions of Windows are not supported.

To launch the software installation program (Figure 1.10) doubleclick on the “Software” icon or file in the DVD’s main folder.
