**Vision** Vision helps in analyzing videos and images to gain valuable insights. Vision APIs are divided into five parts (computer vision, content moderator, video indexer, face API, and emotion API) (also see Figure 2.2):

+   a. **Computer vision API** uses image-processing algorithms to process the images intelligently. It can do the following:
+      - It can analyze an image by understanding the content within the image. For example, if it's a drawing or a picture, colors in the image.
+      - It uses optical character recognition technology to understand the text in the image.
