# # Evolution of Machine Learning

Without these early intellectual minds, there’d be no computing “machines,” much less machine learning.

+   **1642**
+   A 19 year old, Blaise Pascal invented the first mechanical calculator for his father, who was a tax collector. It could add, subtract, multiply, and divide.

+   **1679**
+   German mathematician and philosopher Gottfried Wilhelm Leibniz devised the system of binary code that laid the foundation for modern computing.

+   **1770**
+   A moving, mechanical device designed to imitate a human, called The Turk.
