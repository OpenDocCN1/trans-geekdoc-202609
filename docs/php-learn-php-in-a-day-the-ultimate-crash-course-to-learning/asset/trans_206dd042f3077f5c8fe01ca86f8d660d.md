## 预定义函数

### Echo、Print、exit、die

#### Echo

`Echo` 是 PHP 中允许我们输出字符串数据的语言结构。PHP 会自动将数值变量转换为字符串。我们已经在本书前面的示例中使用过 `echo`，所以你现在应该已经熟悉这个函数了。

`Print` 是另一个执行与 `echo` 相同操作的语言结构，但它更古老且稍慢一些。因此，通常最好使用 `echo`。
