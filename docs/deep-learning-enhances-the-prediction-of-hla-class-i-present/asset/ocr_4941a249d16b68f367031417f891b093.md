# Model training

We train models using the PyTorch framework on N A600 GPU clusters for 75 epochs with a total batch size of 26 (2 hours of training time). The binding model is initialized using the pretrained ESM-2B model parameter and all weights are fine-tuned. The training is initialized randomly at the start of training. Our models are trained using mixed-precision (fp16) using the Adam optimizer, with a learning rate of 1e-4 that is constant throughout training.

# Calculation of entropy

Shannon entropy (it is, sequence conservation) at each HLA anchor residue position was calculated using the following formula:

```
$S = -\sum_{i} p(x_i) \log p(x_i)$
```

where n is the number of unique amino acids at any given position, $x_i$ is the unique amino acid, and $p(x_i)$ is the probability by dividing the number of peptides with amino acid $x_i$ at that given position, by the total number of peptides in the dataset.

# Study participants

Study participants were recruited from outpatient clinics in Boston area and from outside Boston. The Institutional Review Board of Massachusetts General Hospital approved the use of cells derived from human blood. PBMCs from healthy individuals with HLA-A*02:01 or non-HLA-A2positive donors were selected. PBMCs were collected by Ficoll gradient using dextrose or sucrose particles. They were centrifuged and stored in liquid nitrogen for use. HLA I typing was performed for all patients as described previously$^{28}$.

# Peptide synthesis

Peptides were synthesized on an automated peptide synthesizer using Fmoc chemistry$^{2}$ on 2-chlorotrityl resin. The terminal amino acids were removed using the protected amino acids in DMF. Unprotected sites were removed from the block resin using DCM and DCM (95:5 v/v). Amino acids were coupled (using optimized peptide to generate the required number of cycles) for the full-length peptide. The removal of protecting groups was performed using 20% piperidine in DMF after each coupling cycle.

# Peptide synthesis and analysis

Amino acids were activated with HATU and DIPEA in DMF. The peptides were assembled and the resin was washed with DMF and DCM and metanned three times each. The peptides were cleaved from the supported support and dried using diethyl ether-cold-cold-cocktail (TFA/isopropyl alcohol/water (94:2.5:0.5) v/v).
