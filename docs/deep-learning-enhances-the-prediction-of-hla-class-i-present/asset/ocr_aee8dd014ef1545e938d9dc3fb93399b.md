# Article

# Data availability

All data required to train and evaluate the models HLA I-peptide stability and elicit are available in the Mendeley Data repository. Sequences for the major histocompatibility complex identified from IMGT can also be found in the released code. Full protein sequences, including accession codes, are also available in Mendeley Data repository.

# Code availability

The code used to train and run our predictions is available via Zenodo at https://doi.org/10.5281/zenodo.1421959 (ref. 58).
