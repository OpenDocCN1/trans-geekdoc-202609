**Extended Data Fig. 1/ MUNIS outperforms the state-of-the-art predictors in classifying HLA-A binders using a test set with no overlap with the training set. (a) Average precision and (b) ROC-AUC of all predictors in classifying binders non-binders versus the subset of the data with no epitope overlap with any of the tools’ training datasets (“cleansed epitope overlap set”), n= 24. Box plots are presented with medians as center lines, 25th and 75th percentiles

as lower and upper quartiles, and 1,5 interquartile range from the quartiles as whiskers (not shown). (c) Per allele pairwise comparisons of MUNIS and other predictors classifying HLA I binders using the cleaned evaluation set. Each point is model performance on one allele. Pvalues for pairwise comparisons between MUNIS and each predictor were calculated using the two-sided Wilcoxon rank sum test (not shown if p > 0.1).
