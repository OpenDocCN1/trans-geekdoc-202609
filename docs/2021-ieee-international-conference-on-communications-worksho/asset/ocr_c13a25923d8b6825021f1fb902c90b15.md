# A. Driver layer

The driver layer is the entry point of interaction with the system. The driver may have more than one heterogeneous vehicle (e.g., 2-wheeler, 3-wheeler, 4-wheeler), according to which price is decided. The driver can request the BC parking for reservation by providing vehicle id, vehicle type, arrival date and time, and location. The system identifies and predicts available lots in each parking area as per driver request. The system responds to this predicted information. By analyzing reliable preference, services, and price, the driver can confirm the reservation. Payment is performed using BC-based either, where the driver uses cryptographic wallet. This is encrypted using the private key, cryptography and time stamp. Drivers can make payment to the BC layer, which is validated by performing consensus mechanisms. After validation of payment, the driver can park the vehicle to the located spot
