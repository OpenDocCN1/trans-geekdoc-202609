# C. BC Layer

BC layer is involved to enhance the security of system roles and sensitive information. All the parking service providers are connected to the BN which each parking provider acts as a block and local copy of the public ledger. The new parking service provider can join the BN with authentication. For adding a new node, the parking service provider needs to compute the nonce value. The parking service provider finds nonce to get a chance to the BN. Each starts a smart contract to change parking status according to the reservation among the ente. Parking service providers are responsible to verify and validate each new entry and transaction. The driver can book parking as per, for which the system will build a block. When a user requests parking, ESC checks availability by performing intelligence and computation on the AI. If the driver confirms the reservation, payment is done using a BC-based wallet and using consensus mechanisms. BC-based ESC is responsible for validation of driver and transaction lot. If the transaction is valid, the particular parking lot is reserved. Getting to the parking reservation, the public ledger will be updated with its license id, vehicle type, transaction id, parking lot number, but this is made for a specific-time only. # D. Parking Service Provider Layer

Each parking area has a parking service provider who acts as a block in BN. The parking service provider can join BN for fair and transparent parking allocation. Parking service provider updates information about unpaid parking. The BC, as reported, can reserve a suitable parking lot, where parking service providers (i.e., people) are responsible to verify and validate each entry and transaction. Each parking service provider contains copy of the public ledger and smart contract for validation. Using consensus mechanisms, the public ledger is updated with value. Parking service providers are responsible to update the data when drivers occupy or leave the parking lot. Each post contains cryptographic wallet which is encrypted using the private key, cryptographic hash, timestamp, game value.
