## 4. 讨论

实验结果证实了我们方法的准确性和鲁棒性。主要有三个原因：首先，基于 Transformer 提取的特征更丰富，包括图像本身的局部灰度信息，以及上下文等全局信息。其次，下采样图像具有更强的语义信息，适合传统配准方法。后续配准获得了更好的粗匹配初始结果。第三，根据 K-means++ 聚类方法，构建原始图像与待配准子图像之间的关系，并获得代表性子图像以减少时间和空间消耗。
