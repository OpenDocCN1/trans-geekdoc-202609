where $\alpha_1$ and $\alpha_2$ indicate the loss balance hyper-parameter and are set to 1 by default, $N$ denotes the number of anchors in a mini-batch, and $S_n$ is a binary value ($S_n = 1$ for positive anchors and $S_n = 0$ for negative anchors). The vectors $B_n^{pb}$ and $B_n^{gt}$ denote the locations of the $n$-th predicted box and the corresponding ground truth, respectively. The values $p_n^{pb}$ and $p_n^{gt}$ indicate the predicted classification score and the true label of the $n$th object, respectively. In our experiments, the regression loss $L_{reg}$ is set as the smooth L1 loss, the TDIoU loss, etc. The classification loss $L_{cls}$ is set as the focal loss [17], as follows:

$$L_{focal}(p_t)=-\alpha_t(1-p_t)^\gamma\log(p_t) \tag{32}$$

where $(1-p_t)^\gamma$ and $\alpha_t$ are two modulation factors that satisfy the following conditions:

$$p_t=\begin{cases}p_n^{pb},&p_n^{gt}=1\\1-p_n^{pb},&\text{otherwise}\end{cases}\qquad\text{and}\qquad \alpha_t=\begin{cases}\alpha,&p_n^{gt}=1\\1-\alpha,&\text{otherwise}\end{cases} \tag{33}$$

where $\alpha$ and $\gamma$ are two hyper-parameters, which are set to 0.25 and 2, respectively, by default.
