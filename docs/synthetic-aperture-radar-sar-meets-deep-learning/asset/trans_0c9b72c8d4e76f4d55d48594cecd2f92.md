
### 3.4.2. 跟踪稳定性

中央位置误差（CLE）反映了跟踪方法的稳定性 [15]；即 CLE 越小，跟踪方法越稳定，CLE 定义如下：

CLE = sqrt((x_R - x_G)^2 + (y_R - y_G)^2) (10)

其中 (x_R, y_R) 表示跟踪结果的中心位置，(x_G, y_G) 表示阴影真实值的中心位置。

### 3.4.3. 跟踪速度

每秒帧数（FPS）表示跟踪速度，定义如下：

FPS = N / t (11)

其中 t 表示总跟踪时间，N 为 Video-SAR 序列中的图像数量。
