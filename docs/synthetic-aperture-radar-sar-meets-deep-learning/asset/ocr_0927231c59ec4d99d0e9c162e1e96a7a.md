Among them, the adversarial loss is expressed as follows:

$\mathcal{L}_{GAN}(Q, D_Z) = \mathbb{E}_{y^{(i)}z^{(i)}}[\log D_Z(y^{(i)},z^{(i)})] + \mathbb{E}_{y^{(i)}}[\log(1 - D_Z(y^{(i)},Q(y^{(i)})))]$. (6)

In order to make the generated color distribution closer to the color distribution of the reference image, we defined the $\mathcal{L}_1$ loss in the Lab space, which is expressed as follows:

$\mathcal{L}_1(Q) = \mathbb{E}_{y^{(i)}z^{(i)}}[\|Q(y^{(i)}) - z^{(i)}\|_1]$. (7)

Therefore, the total loss function of the Colorization GAN model is as follows:

$\mathcal{L}_{GAN^2} = \arg\min_{Q}\max_{D}\mathcal{L}_{GAN}(Q(y^{(i)}),z^{(i)}) + \beta_2\mathcal{L}_1(Q,y^{(i)})$. (8)

where $\beta_2$ is a weighted value.
