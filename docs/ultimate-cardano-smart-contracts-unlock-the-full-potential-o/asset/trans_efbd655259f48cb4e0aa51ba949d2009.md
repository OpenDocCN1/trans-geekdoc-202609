
Cardano 区块链的核心组件是 Cardano 节点，其源代码位于 GitHub。[^(14)](#c08.xhtml#ftn14) 您可以下载并编译源代码、运行静态二进制文件，或使用 Docker 容器。Demeter.run 也有一个扩展来配置 Cardano 节点，步骤如下：

1.  访问 [https://demeter.run/](https://demeter.run/)
2.  选择您要部署的项目。我们将为 *[第 5 章，交易构建器](#c05.xhtml)* 中已创建的工作区启用此扩展。
3.  一旦工作区在 *[图 8.4](#c08.xhtml#fig8_4)* 中完成配置，您必须通过向下滚动页面选择“Connected Extensions”来启用 Cardano 节点。

    ![](images/Figure-8.4.jpg)

    **图 8.4：** Demeter.run Cardano 工作区

4.  选择“Browse Extensions”（浏览扩展）。
5.  找到“Nodes”框，选择 `Deploy`，然后选择 `Provision Resource`。
6.  向下滚动，选择 `Preprod`，并选择页面底部的 `Create Resource` 按钮。
7.  当您返回 `Project Overview` 时，应该能看到节点扩展已连接，如 *[图 8.5](#c08.xhtml#fig8_5)* 所示。

    ![](images/Figure-8.5.jpg)

    **图 8.5：** Demeter.run Cardano 节点已连接

8.  选择您之前配置的工作区。
9.  选择工作区上的 `Visual Studio Code` 图标以启动 Visual Studio Web 客户端。
10. 从汉堡菜单中，选择 `Terminal` -> `New`。

## Ogmios

Ogmios[^(16)](#c08.xhtml#ftn16) 是 Cardano 开发者最广泛使用和最流行的工具之一，并且拥有优秀的文档。它是一个转换层，通过 REST API 或 Web RPC 接口暴露 Cardano 节点的功能。Ogmios 是开源的，可以从 GitHub[^(17)](#c08.xhtml#ftn17) 下载、构建并本地安装，或通过 Docker 容器使用。我们将使用 Demeter.run 部署托管版本，以便我们能快速演示如何使用示例与其交互。

要添加 Ogmios 扩展：

1.  进入 `Project` 页面，向下滚动，并选择 `BROWSE EXTENSIONS`，如 *[图 8.6](#c08.xhtml#fig8_6)* 所示。

    ![](images/Figure-8.6.jpg)

    **图 8.6：** Demeter.run 项目视图

2.  选择 Ogmios Deploy。
3.  选择 `Create Resource` 和 `Preprod` 网络。
4.  选择 v5 作为版本并点击 `CREATE RESOURCE` 按钮。
5.  您将看到实例正在运行，如 *[图 8.7](#c08.xhtml#fig8_7)* 所示。

    ![](images/Figure-8.7.jpg)

    **图 8.7：** Demeter.run Ogmios 运行中

现在，让我们使用像 Hoppscotch[^(18)](#c08.xhtml#ftn18) 这样的 Web 工具来试用 `Ogmios` API。

1.  访问 URL：[https://hoppscotch.io/realtime/websocket](https://hoppscotch.io/realtime/websocket)。
2.  粘贴 Ogmios 的公共 https 主机名，并在地址前加上 `wss://` 前缀。
3.  选择 `Connect`。
4.  然后粘贴以下查询并选择 `Send`：

```
{
"type": "jsonwsp/request",
"version": "1.0",
"servicename": "ogmios",
"methodname": "Query",
"args": {
"query": "ledgerTip"
}
}
```

5.  您应该会看到成功的结果，如 *[图 8.8](#c08.xhtml#fig8_8)* 所示。

    ![](images/Figure-8.8.jpg)

    **图 8.8：** Hoppscotch Ogmios 成功
