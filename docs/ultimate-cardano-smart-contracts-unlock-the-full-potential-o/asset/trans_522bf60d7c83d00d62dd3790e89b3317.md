
Ouroboros Classic 是于 2017 年 7 月发布的首个 Ouroboros 协议。[^(26)](#c02.xhtml#ftn26) 该论文将该协议定义为 `PoW` 的节能竞争对手，引入了分析 `PoS` 的数学框架，并引入了一种新颖的激励机制，以在 `PoS` 环境下奖励参与者。[^(27)](#c02.xhtml#ftn27) Ouroboros 与其他区块链协议的区别在于，其领导者选择算法能够在安全保证下生成无偏随机性。[^(28)](#c02.xhtml#ftn28) 让我们更详细地研究一下。

> Ouroboros 将 Cardano 上的时间划分为纪元，每个纪元又被划分为时隙。时隙是可以创建区块的短时间段，将时隙分组为纪元是根据动态变化的权益分布调整领导者选举过程的核心。每个时隙会选举出一位时隙领导者，负责向链中添加区块并将其传递给下一位时隙领导者。为了防范旨在颠覆协议的对抗性尝试，每位新的时隙领导者必须将接收到的链的最后几个区块视为暂态的：仅位于预先指定数量的暂态区块之前的链才被视为已确定。[^(29)](#c02.xhtml#ftn29)

# Ouroboros BFT

Ouroboros Byzantine Fault Tolerance（`BFT`）是基于 Ouroboros Classic 的简化协议[^(30)](#c02.xhtml#ftn30)，主要用于协助 Cardano 最重要的里程碑之一——Shelley 发布。它将网络过渡到联邦模型，以避免要求所有节点始终在线。[^(31)](#c02.xhtml#ftn31)

# Ouroboros Praos

Praos 在当前时间戳和特定纪元的随机数上引入了可验证随机函数（`VRF`）。[^(32)](#c02.xhtml#ftn32) 给定私钥和输入，`VRF` 会输出一个伪随机数和一个证明。[^(33)](#c02.xhtml#ftn33) 相应的公钥可以验证该证明和随机数。此外，这种方法除了提议的时隙领导者之外，防止任何人提前知道特定时隙的时隙领导者。这对于避免 `DDoS` 或针对性攻击非常重要，因为在这些攻击中时隙领导者会被提前公开。[^(34)](#c02.xhtml#ftn34)

# Ouroboros Genesis

比特币 `PoW` 共识协议的优势在于，任何参与者仅使用创世区块即可加入网络并参与其中。这是任何区块链的一项非常重要的功能，因为它不依赖于网络正确状态的任何可信概念或检查点。Ouroboros Genesis 通过使用一种新颖的链选择规则，解决了 Ouroboros `PoS` 协议的这一局限性，该规则允许新参与者或离线参与者仅使用创世区块加入网络。[^(35)](#c02.xhtml#ftn35) 这种方法称为“从创世引导”，Ouroboros Genesis 论文证明了在使用这种方法时仍能保留先前的安全保证。该论文还提供了协议通用可组合性的证明，表明即使在不同的协议配置中使用，它仍能保持其安全属性。[^(36)](#c02.xhtml#ftn36)

# Ouroboros Crypsinous

Ouroboros Crypsinous 是首个经过正式分析的隐私保护 `PoS` 区块链协议。[^(37)](#c02.xhtml#ftn37) 该论文利用 SNARKs 和密钥私有前向安全加密，使用一种新颖的币演化技术，证明网络能够抵御自适应攻击。[^(38)](#c02.xhtml#ftn38) 该协议不打算在 Cardano 主结算层实施，但可用于侧链，如 Midnight（一条隐私保护区块链）。

# Ouroboros Chronos

Ouroboros Chronos 通过一种新颖的时间同步机制，展示了区块链协议如何安全地同步时钟，从而摆脱对外部时间服务的依赖。[^(39)](#c02.xhtml#ftn39) 该论文旨在使账本更能抵御针对时间信息的攻击。[^(40)](#c02.xhtml#ftn40)

# Ouroboros 协议生命周期

让我们走一遍 Ouroboros 协议生命周期，提供一个分步示例，说明所有部分如何组合在一起。

## 时间

Cardano 区块链中的第一个区块是创世区块，从区块链的角度来看，这是时间的开始。Cardano 使用时隙的概念，时隙大约每秒发生一次，每个时隙最多可创建一个区块。预期的出块频率为 0.05，这意味着平均每 20 秒将产生一个区块。[^(41)](#c02.xhtml#ftn41) 只有时隙领导者可以为给定时隙创建区块。每个纪元恰好有 432,000 个时隙，相当于每 5 天。

## 注册

参与 Cardano 网络的第一步是注册与要质押的 Ada 关联的权益密钥。这通常指将 Ada 注册到特定的股份池运营商（`SPO`）。质押金额用于计算奖励并按比例分配回质押地址。`SPO` 将处理（除其他事项外）股份池注册流程，如*[图 2.5](#c02.xhtml#fig2_5)*所示：

1.  与网络账本同步。
2.  获取当前时隙。
3.  获取全局随机预言机。

## 质押

1.  在每个纪元开始时，每个股份池运营商查询区块链以获取两个纪元前某个区块的权益分布。
2.  使用由上一纪元前 ⅔ 个时隙生成的 `VRF`，利益相关者通过其私钥可在当前纪元产生输出，以确定他们是否可以成为时隙领导者。[^(42)](#c02.xhtml#ftn42)
3.  如果 `VRF` 输出值低于特定阈值，他们就可以成为该区块的时隙领导者。
4.  时隙领导者职责：[^(43)](#c02.xhtml#ftn43)
    1.  组装应包含在区块中的交易。
    2.  在区块中包含从 VRF 输出获得的随机值 (v) 和证明 (π)。
    3.  生成新私钥并删除旧私钥，使得无法使用旧私钥伪造签名。
    4.  向网络广播新区块。
5.  奖励在纪元结束时计算，然后在下一个区块中分配给奖励地址。

# 结论

本章介绍了密码学，重点关注公钥哈希算法。我们了解了这如何扩展为称为数字签名的概念，它支撑着当今的加密货币。通过链接数字签名，区块链可以为像比特币这样的数字货币的流动创建所有权证明。我们深入研究了工作量证明，以及挖掘区块如何激励矿工保持诚实并防止网络攻击。然后我们研究了节能的权益证明，以及如何降低与预测随机数生成相关的风险，还有概率性最终性和绝对最终性之间的差异与权衡。最后，我们回顾了 Ouroboros 协议家族以及当今 Cardano 主网上的当前协议生命周期。利用我们对密码学和 `PoS` 区块链工作原理的了解，我们将在下一章探讨如何使用交易转移价值。

# 要点回顾

*   使用公钥加密需要生成一对公钥和私钥。
*   如果交易由私钥签名，区块链上的任何人都可以使用相应的公钥进行验证。
*   比特币通过签名前一笔交易的哈希值并包含下一位所有者的公钥来进行数字化转移。
