# [半形式化方法](#toc.xhtml#s363a)

正如我们所见，在设计和构建无许可且去中心化的区块链时，存在许多陷阱。**IOG**（**IOHK**）通过将半形式化规范、Haskell 规范和 Haskell 实现代码关联起来，缓解了这些问题，如*[图 14.1](#c14.xhtml#fig14_1)*所示。

![](images/Figure-14.1.jpg)

**图 14.1：** 证据链[⁹](#c14.xhtml#ftn9)

账本的半形式化规范定义了转换类型和转换规则，这使其具有形式化特性，但未经过机器检查。[^(10)](#c14.xhtml#ftn10) 通过创建 Haskell 规范，可以运行测试用例，将规范可执行文件的输出与实现可执行文件生成的输出进行比较。如果两个输出匹配，我们就可以合理地高度确信实现代码实现了半形式化规范。**IOG** 持续改进形式化验证流程，并最近发布了一篇题为“*Formal specification of the Cardano blockchain ledger, mechanized in Agda*（Cardano 区块链账本的形式化规范，在 Agda 中实现机械化）”的论文。[^(11)](#c14.xhtml#ftn11) 目标是今后使用 Agda 创建形式化规范，进行中的版本位于 GitHub 上。[^(12)](#c14.xhtml#ftn12)

# [IACR](#toc.xhtml#s364a)

国际密码学研究协会（**IACR**）是一个非营利科学组织，致力于推进密码学及相关领域的发展。[^(13)](#c14.xhtml#ftn13) 它组织三场领先的会议，供该领域的学者发表和评审科学论文：

*   Crypto（密码学会议）
*   Eurocrypt（欧洲密码学会议）
*   Asiacrypt（亚洲密码学会议）

**IACR** 还举办四场额外的专业会议、一个研讨会，以及一系列密码学培训学校。[^(14)](#c14.xhtml#ftn14) 《密码学杂志》是 **IACR** 的旗舰期刊，为现代信息安全领域的原创成果发表提供了论坛。[^(15)](#c14.xhtml#ftn15)

# [社会公益潜力](#toc.xhtml#s365a)

Cardano 为无银行账户者提供银行服务的使命，可追溯到 Charles Hoskinson 于 2014 年的 TED 演讲，那时 Cardano 甚至尚未诞生。[^(16)](#c14.xhtml#ftn16) Cardano 诞生于一个愿景：一个没有中介的世界，个人掌控自己的数据以及交易方式。[^(17)](#c14.xhtml#ftn17) 这引起了 Cardano 社区许多人的共鸣，也是为什么与 World Mobile 等公司存在巨大协同效应的原因，后者致力于连接未连接的人群。[^(18)](#c14.xhtml#ftn18) 立志成为世界的金融操作系统，[^(19)](#c14.xhtml#ftn19) Cardano 拥有巨大的社会公益潜力。

# [World Mobile](#toc.xhtml#s366a)

全球有近 30 亿人未接入网络，其中 40% 的发展中国家人口无法接入移动网络。[^(20)](#c14.xhtml#ftn20) World Mobile 正在为电信创建一个共享经济，这仅因区块链而成为可能。[^(21)](#c14.xhtml#ftn21) 用户可以购买 World Mobile 节点，并从网络交易费和代币质押中获得 World Mobile 代币 (WMT)，这激励了网络建设。该移动网络是一个 Cardano 侧链，使用去中心化标识符（**DID**s）进行配置和计费。[^(22)](#c14.xhtml#ftn22) World Mobile 已在坦桑尼亚和桑给巴尔等国家部署了网络。[^(23)](#c14.xhtml#ftn23)

# [Empowa](#toc.xhtml#s367a)

由于借贷成本高昂（45%），非洲大多数人无法负担购房，这反过来又导致住房供应短缺。[^(24)](#c14.xhtml#ftn24) Empowa 是一个去中心化的房地产开发和收藏品平台，为非洲服务不足的社区提供小额融资。[^(25)](#c14.xhtml#ftn25) Empowa 已利用 Cardano 区块链为莫桑比克的经济适用房提供融资。[^(26)](#c14.xhtml#ftn26)

# [监管与合规风险](#toc.xhtml#s370a)

美国的监管环境对位于那里的所有区块链公司来说都特别困难且充满挑战。这就是为什么大多数区块链公司或基金会将总部设在美国境外、对加密货币友好的司法管辖区（如瑞士）的原因。随着合法用例的实现和区块链优势的倡导，监管清晰度在过去几年中有所改善，并将继续改善。

合规风险，特别是 KYC（了解你的客户）和 AML（反洗钱）法规，并不总是与假名的、去中心化的、无许可的区块链兼容。Cardano 区块链是一个工具箱，拥有许多工具，可以满足各种功能性和非功能性需求，包括在需要时的 KYC 和 AML。因此，请始终了解用户的监管环境，并相应地定制解决方案。此外，请注意，某些司法管辖区可能有报告要求，或完全禁止持有加密货币资产。

# [技术采用](#toc.xhtml#s371a)

区块链似乎遵循着与手机、互联网和社交媒体等其他颠覆性创新相似的轨迹，如*[图 14.2](#c14.xhtml#fig14_2)*所示。创新者最先进入这个领域，开创并推动技术的首次迭代。随后是早期采用者，他们看到了潜力并宣传其优势。接下来，预期早期大众将到来，这将开启大规模采用的新时代。

![](images/Figure-14.2.jpg)

**图 14.2：** 技术采用曲线

不幸的是，事情并非如此发展，而是出现了“鸿沟”。早期的兴趣和热情消退，许多人将该技术视为昙花一现的时尚而抛弃。但建设者们在这一阶段坚持建设，坚信这项新技术具有巨大潜力。在未来的某个时刻，会诞生出能够实现这项新技术独特价值主张的“杀手级”应用。它从根本上改变了社会对先前无法解决的问题的解决方案的看法。此时，早期大众到来，大规模采用发生。到了晚期大众阶段，该技术不再新颖，被接受为新常态。最后，将会有落后者，他们仍对该技术持怀疑态度，但别无选择，只能使用它以与世界其他地方保持联系。
