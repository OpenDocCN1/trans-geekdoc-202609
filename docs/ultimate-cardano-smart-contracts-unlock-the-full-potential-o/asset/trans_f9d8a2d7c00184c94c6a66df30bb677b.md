## Plutus 规范

Cardano 上的第一代脚本是**原生脚本**，[¹](#c04.xhtml#ftn1) 随后是 Plutus。原生（阶段 1）脚本功能非常有限，并在账本内部执行。Plutus 是一种图灵完备的脚本语言，它在账本外部执行，但需要成功的评估才能花费由 Plutus 脚本锁定的 UTXO。[³](#c04.xhtml#ftn3) 账本必须支持多个 Plutus 脚本版本，因此每个脚本都在脚本本身中包含版本号。这样，账本就知道如何评估每个版本的脚本。*表 4.1* 总结了撰写时已知的 Plutus 版本，本书将仅关注 **PlutusV2** 和 **Plutus Core 版本 1.0.0**。

| **时代** | **账本语言 (ID)** | **Plutus Core 版本** | **协议版本** | **日期** |
| --- | --- | --- | --- | --- |
| Alonzo | PlutusV1 (0) | 1.0.0 | 5.0 | 2021 年 9 月 |
| Vasil | PlutusV2 (1) | 1.0.0 | 7.0 | 2022 年 6 月 |
| Valentine | PlutusV2 (1) | 1.0.0 | 8.0 | 2023 年 2 月 |
| Conway | PlutusV3 (2) | 1.1.0 | 9.0 | 即将推出 |

**表 4.1：** Plutus 版本

Plutus 规范的目标是创建一种简单的脚本语言，能够在 Cardano 节点上以最小（且受限）的计算占用进行评估。与拥有冗长复杂证明的以太坊虚拟机不同，Plutus 抽象状态机简短而简洁。[⁴](#c04.xhtml#ftn4) 在构建高度稳定的区块链以最小化硬分叉升级时，这是一个非常理想的特性。Plutus 脚本使用一种称为无类型 Plutus Core 或 **UPLC** 的语言编写，它源自 System F，一种** Lambda 演算**形式。[⁵](#c04.xhtml#ftn5) 幸运的是，智能合约 Plutus 开发使用**高级编程**语言，它们为我们编译并生成 **UPLC**。

> **注意**：学习 **UPLC** 或 Lambda 演算并非编写 Cardano 智能合约的必要条件。本节其余内容为可选，但可能有助于希望了解生成的 UPLC 代码如何映射到 Plutus Core 规范的读者。有关 Lambda 演算的介绍，请观看视频"*Lambda Calculus - Fundamentals of Lambda Calculus & Functional Programming in JavaScript*。"[⁶](#c04.xhtml#ftn6)

## UPLC 基本类型

**UPLC** 使用简单的语言语法，具有一组有限的原子类型，如 *表 4.2* 所列：

| **类型** | **语法** |
| --- | --- |
| `integer` | `-?[0-9]+` |
| `bytestring` | `#([0-9A-Fa-f][0-9A-Fa-f])*` |
| `string` | `UTF-8 字符，用双引号 "` `"` 括起` |
| `bool` | `True \| False` |
| `unit` | `()` |
| **类型** | **表示** |
| `Data` | `data Data = Constr Integer [Data] \| Map [(Data, Data)] \| List [Data] \| I Integer \| B ByteString` |

**表 4.2：** UPLC 原子类型

除了原子数据类型外，UPLC 中还包含两种类型的运算符，如 *表 4.3* 所示：

| **运算符 op** | **\|op\|** | **表示** |
| --- | --- | --- |
| `list` | `1` | `[list(t)] = [t]` |
| `pair` | `2` | `[pair(t1,t2)] = [t1] x [t2]` |

**表 4.3：** UPLC 类型运算符

关键字 `con` 定义常量，后跟类型声明和值。*表 4.4* 提供了一些用法示例：[⁷](#c04.xhtml#ftn7)

| **类型** | **示例** |
| --- | --- |
| `unit` | `con unit ()` |
| `bool` | `con bool False` |
| `integer` | `con integer 123` |
| `bytestring` | `con bytestring #abc123` |
| `string` | `con string "GM Cardano"` |
| `pair` | `con pair<bool, integer> [True, 123]` |
| `list` | `list<bytestring> [#0d, #f3]` |

**表 4.4：** UPLC 类型示例[⁸](#c04.xhtml#ftn8)

Lambda 函数使用关键字 `lam`，接收一个变量名并返回一个项，该项可以是常量、函数或任何类型的格式良好的值。UPLC 程序不得包含任何自由变量，因此被视为“封闭项”。[⁹](#c04.xhtml#ftn9) 例如，`(program 1.0.0 (lam x x))` 是一个有效程序，但 `(program 1.0.0 (lam x y))` 不是。请注意，所有 Plutus 脚本都必须包含 `program` 和 `version`。

Plutus Core 没有算术运算符，而是使用内置函数进行算术运算。一些 `builtin` 函数是针对 Cardano 区块链的特定领域函数，而其他 `builtin` 函数可能会随着时间的推移而添加。我们将要回顾的最后两项是 `force` 和 `delay` 指令。`force` 指令应用于多态函数，以强制实例化类型参数。[^(10)](#c04.xhtml#ftn10) `delay` 指令用于分支条件的**惰性求值**，从而保留类型抽象。[^(11)](#c04.xhtml#ftn11) **惰性求值**允许更高效的代码执行，因为值仅在被使用时才计算。这也允许创建无限数据结构，这在 C 等语言中是不可能创建的。

## 简洁二进制对象表示 (CBOR)

**CBOR** 是一种在互联网标准 RFC 8949 中定义的二进制编码格式。[^(13)](#c04.xhtml#ftn13) 在上一章*交易*中，我们查看了 Cardano 账本 **CDDL** 规范，[^(14)](#c04.xhtml#ftn14) 它定义了交易的格式。当交易提交到网络时，整个交易和所有相关数据都会被**序列化**并以 **CBOR** 编码。我们将详细检查一笔交易并**反序列化**它，以查看 UPLC Plutus 代码和相关数据（兑换脚本和数据）。
