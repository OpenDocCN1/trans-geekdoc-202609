
在前面的示例中，我们有一组代币，每个代币代表锁定在 UTXO 中的价值。`Game Monetary Policy ID` 是一个唯一的铸造策略 ID，玩家持有 100 个 Gold、1,000 个 Silver 和 10,000 个 Bronze 代币。因此，用户可以在单笔交易中花费最多 100 个 Gold、最多 1,000 个 Silver 和最多 10,000 个 Bronze 代币。由于该玩家只有 1 个 Dracula 代币，因此他们只能向另一位玩家发送（花费）1 个 Dracula 代币。代币包中始终需要最少数量的 Ada，在本例中为 1,646,420 lovelace。

# 铸造策略

Cardano 上有两种不同类型的铸造策略：

*   使用 `cardano-cli` 工具创建的原生脚本铸造策略，使用私钥和公钥。
*   作为 Plutus 脚本的铸造策略。

`cardano-cli` 方法[³](#c07.xhtml#ftn3)最早用于智能合约引入之前，但由于这是一种经过验证且安全的技术，至今仍在使用。将 `cardano-cli` 与原生脚本结合使用，提供了指定时间锁和多重签名条件的能力[⁴](#c07.xhtml#ftn4)。

铸造策略的编写方式类似于我们编写验证器脚本的方式。验证器脚本与铸造策略的区别在于，铸造策略使用 `minting` 脚本目的且不使用 datum。`minting` 脚本目的允许铸造策略作为交易的一部分铸造或销毁原生代币。铸造策略的自定义逻辑中仅定义了铸造或销毁的条件。

# 同质化代币

您可能希望创建一个具有 1,000,000 个代币固定供应量的**货币策略**。铸造策略将仅允许一次性铸造 1,000,000 个代币，每个代币具有相同的名称。这使得每个代币都能相互替代或交易，类似于当今法币的运作方式。

# 非同质化代币

非同质化代币（**NFT**）是指每个代币都是唯一且独特的。在 Cardano 上创建唯一代币有两种方法。

*   **选项 1**：时间锁，代币只能在特定日期和时间之前铸造。
*   **选项 2**：铸造策略逻辑检查输入中必须被花费的 UTXO 是否存在。

第二种选项更受青睐，因为它利用了 Cardano UTXO 架构的独特属性。一旦 UTXO 被花费，它就永远不能再次被花费，也不会存在另一个具有相同哈希值的 UTXO。通过将此条件硬编码到铸造策略中，并确保仅铸造一个代币，我们保证了代币的唯一性。时间锁方法用于智能合约功能可用之前，但在创建大型 NFT 收藏时仍在使用。

# 代币注册表

代币注册表[⁵](#c07.xhtml#ftn5)用于存储铸造策略 ID 和代币名称的链下元数据。铸造策略 ID 是一个十六进制哈希值，因此拥有关于特定铸造策略和代币的可读信息映射非常有帮助。注册表提供了一个 API，钱包和其他应用程序可以使用它来查找代币图片 URL、小数精度和其他元数据。随着 CIP-68 采用率的提高，对中心化链下代币注册表的需求将随着时间的推移逐步淘汰。有关注册代币的分步指南，请访问以下 URL：

[https://github.com/cardano-foundation/cardano-token-registry/wiki](https://github.com/cardano-foundation/cardano-token-registry/wiki)

# NFT 元数据标准

在铸造 NFT 时，您可以利用可包含在 Cardano 网络上任何交易中的交易元数据。第一个 Cardano 元数据标准记录在 CIP-25[⁶](#c07.xhtml#ftn6) 中，该标准指定了 NFT 元数据的标准字段。CIP-25 元数据与以太坊 ERC-721 代币元数据的一个显著区别在于，CIP-25 元数据链接到铸造交易，而不是铸造策略。因此，使用 CIP-25 查找元数据的过程是查看特定铸造策略的原始铸造交易。

# CIP-68

CIP-25 的缺点是它是在原始铸造交易中创建的，不可更新，也无法被 Plutus 脚本访问。CIP-68[⁸](#c07.xhtml#ftn8) 通过使用参考代币的概念解决了这个问题，该参考代币在创建 **NFT** 或 **FT** 时同时生成。参考代币可以锁定在不可花费的脚本地址以实现不可变性，或者如果需要可更新性，则锁定在支出脚本地址。元数据存储在包含在参考代币 UTXO 输出中的 datum 中。因此，Plutus 脚本可以通过读取 datum 值来访问它。随着 2022 年 9 月 Vasil 硬分叉的实施，**参考输入**被引入，允许 Plutus 脚本将 UTXO 输入作为只读包含，而无需花费它。因此，任意数量的交易（甚至并行）都可以包含只读的 CIP-68 参考代币 UTXO，而不会出现任何并发问题。

在*[图 7.2](#c07.xhtml#fig7_2)*中，我们可以看到铸造交易如何生成用户代币和参考代币，它们通过相同的代币名称和铸造策略 ID 关联。代币名称以 222 为前缀表示 NFT 代币，以 100 为前缀表示参考代币。对于同质化代币，使用前缀 333。值得注意的是，参考代币与 NFT 或 FT 代币不需要同时铸造。

# 选币

选币是确定需要哪些 UTXO 输入以覆盖 UTXO 输出成本（包括网络费用）的过程。在选币过程中，我们需要注意以下一些约束条件[⁹](#c07.xhtml#ftn9)：

*   交易的最大大小限制，其中每个 UTXO（无论作为输入还是输出）都会增加整体交易大小。
*   非常小的 UTXO（**粉尘**）的累积，它们无法花费，因为无法将足够多的它们组合在一起以覆盖交易成本。
*   UTXO 不能部分花费；它必须作为交易的一部分被完全花费。
