

# 在去中心化共识中利用计算周期解谜的概念

在去中心化共识中利用计算周期解谜的概念最早由**Wei Dai**的b-money于1998年提出。[⁵](#c01.xhtml#ftn5) 这种方法的优势在于它不需要中心化机构来创造货币。"*2005年，***Hal Finney*** *提出了‘可重复使用的工作量证明’概念*[⁶](#c01.xhtml#ftn6)*，该系统结合了b-money的理念与***Adam Back****的计算困难Hashcash谜题，创造了一种加密货币的概念。*”[⁷](#c01.xhtml#ftn7) 遗憾的是，这种方法仍然依赖受信任的后端，[⁸](#c01.xhtml#ftn8) 因此未能实现无需信任的去中心化货币目标。

# 比特币白皮书

2008年，化名**中本聪**发表了"*比特币：一种点对点的电子现金系统*"，旨在通过一种去中心化的点对点电子现金系统解决双重支付问题，如*[图 1.2](#c01.xhtml#fig1_2)*所示。在这篇里程碑式的论文中，中本聪提出了"*一种利用工作量证明记录交易公共历史的点对点网络，只要诚实节点控制了大部分CPU算力，攻击者要篡改这份记录在计算上就会变得不可行。*”[⁹](#c01.xhtml#ftn9) 这是通过对网络交易进行时间戳记录，并"*将它们哈希进一个基于哈希的工作量证明的持续链中，形成一份无需重做工作量证明就无法更改的记录。最长链不仅作为所见事件序列的证明，也作为它来自最大CPU算力池的证明。只要大部分CPU算力由不合谋攻击网络的节点控制，它们就会生成最长链并超越攻击者。*”[^(10)](#c01.xhtml#ftn10)

![](images/Figure-1.2.jpg)

**图 1.2：** 比特币账本

比特币的**工作量证明**实施具有创新性，因为它同时解决了两个问题。首先，它提供了一个简单且中等效果的共识算法，允许网络中的节点共同就比特币账本状态的一组规范更新达成一致。[^(11)](#c01.xhtml#ftn11) 其次，它提供了一种允许自由参与共识过程的机制，解决了谁有资格影响共识的政治问题，同时防止了女巫攻击。[^(12)](#c01.xhtml#ftn12)

2009年1月3日，第一个比特币区块被挖出，一个无需许可且无需信任的数字货币新时代由此诞生。在后续关于*密码学与共识算法概述*和*交易*的章节中，我们将更详细地探讨比特币白皮书。

# 以太坊白皮书

**Vitalik Buterin**于2014年发布的以太坊白皮书，介绍了一种利用区块链技术创建更通用的分布式计算平台的新方式。特别是，他描述了智能合约的概念，它可以被视为包含价值的加密“*盒子*”，仅在满足特定条件时才会解锁。[^(13)](#c01.xhtml#ftn13) 与比特币脚本不同，以太坊智能合约将是图灵完备的，并能访问全局状态和持久化存储，如*[图 1.3](#c01.xhtml#fig1_3)*所示。运行在以太坊虚拟机（**EVM**）中的智能合约将具备价值感知能力，并能读取合约账户中的以太币（ETH）数量。

![](images/Figure-1.3.jpg)

**图 1.3：** 以太坊账本

以太坊的全局状态包含两种账户类型：由私钥控制的外部拥有账户，以及由其智能合约代码控制的合约账户。[^(14)](#c01.xhtml#ftn14) 智能合约是自执行的，因为它们在单个节点内包含所需的所有信息。通过使用全局状态，以太坊具有优势：它不需要重演所有先前的交易来确定网络的当前状态。它只需将最新区块中的当前交易应用到节点上存储的最后一个全局状态即可。

以太坊中的交易是指一个签名数据包，它存储了从外部拥有账户发送的消息。合约可以向其他合约发送消息，其中消息是虚拟对象，从未被序列化，仅存在于以太坊执行环境中。[^(15)](#c01.xhtml#ftn15) 由于使用了全局状态，以太坊也被认为是非确定性的。相比之下，比特币和Cardano是确定性的，因为它们在交易中仅使用本地状态。

以太坊智能合约因其图灵完备的脚本特性，存在无限循环的风险。为解决此问题，以太坊采用了Gas费概念，即执行智能合约（或智能合约链）时消耗的费用。提交交易时，必须包含其将消耗的最大Gas量，以防范无限循环代码执行。

# Charles Hoskinson的白板视频

**Charles Hoskinson**广受欢迎的白板视频（观看量超100万）[^(16)](#c01.xhtml#ftn16) 介绍了Cardano是第三代区块链的概念，其中比特币为第一代，以太坊为第二代。Cardano构建于第一代和第二代区块链之上，并解决了各自的一些关键痛点，即：

*   可扩展性
*   互操作性
*   可持续性

## 可扩展性

Charles指出，比特币和以太坊均无法扩展至数十亿用户，要提高可扩展性，必须聚焦三个关键领域：

*   **TPS**：每秒交易数。
*   **网络**：使用和共享网络所需的带宽。
*   **存储**：需持久保存的区块链大小。

Cardano创建、发布并推出了Ouroboros，一种可证明安全的权益证明协议，以提高**TPS**。该协议所需资源远少于工作量证明，因此可引入并行性和侧链以提高**TPS**。加密压缩算法结合侧链，将减少需传输和存储的区块链大小，从而改善**网络**和**存储**的可扩展性。侧链的概念允许Cardano基础层充当结算层，而侧链充当计算层。在扩展至数十亿用户时，在结算层向所有节点广播、中继和存储每笔交易是不可行也不切实际的。

## 互操作性

Cardano旨在解决的另一个领域是区块链如何与其他区块链和遗留系统交互。特别是，Charles预见了一个多条区块链共存的未来，Cardano能与它们互操作，使价值能在它们之间流动。此外，还需要具备感知并与传统金融系统交易的能力。为此，区块链需要具备以下能力：

*   **元数据**：交易背后的故事。
*   **归属**：发送方和接收方的身份。
*   **合规**：KYC（了解你的客户）和反洗钱。
