# 成员制组织 (Intersect)

Intersect 于 2023 年 7 月推出，是 Cardano 的成员制组织（**MBO**）。利用社区治理，Intersect 将优先分配 Cardano 国库资金，用于 Cardano 区块链的未来维护和开发。为实现这一目标，Intersect 专注于五大关键领域[^(21)](#c13.xhtml#ftn21)：

* 支持社区和 Cardano 生态系统的增长。
* 根据 CIP-1694[^(22)](#c13.xhtml#ftn22) 文档管理和倡导链上治理。
* 监督 Cardano 技术路线图的交付。
* 促进 Cardano 系统稳定性的连续性。
* 协调 Cardano 核心技术的开源开发。

Intersect 是一家位于美国怀俄明州的非营利性公司。怀俄明州拥有关于去中心化自治组织（**DAO**）法律结构的有利立法[^(23)](#c13.xhtml#ftn23)，因此 Intersect 选择在该州注册成立[^(24)](#c13.xhtml#ftn24)。Intersect 设有董事会，他们每月开会，会议记录发布在 Intersect 网站上[^(25)](#c13.xhtml#ftn25)。任何 Ada 持有者都可以加入 Intersect[^(26)](#c13.xhtml#ftn26)，成为会员后可在 Discord 上获取社区公告、委员会工作组和会议信息。

# CIP-1694

Cardano 现已进入 Cardano 路线图的 Voltaire 时代，该时代将利用链上治理使 Cardano 网络成为一个自我维持的系统[^(27)](#c13.xhtml#ftn27)。CIP-1694 记录了链上治理系统应如何运作，以及被称为最小可行治理（**MVG**）的初始引导阶段所需条件。CIP-1694 最重要的方面是确认链上投票发生时，1 Ada 等于 1 票。

CIP-1694 中记录了三个治理机构，每个机构在治理过程中都发挥关键作用[^(28)](#c13.xhtml#ftn28)：

* 委托代表（**DRep**）
* 质押池运营商（**SPO**）
* 宪法委员会（**CC**）

这些治理机构将根据提案类型投票批准或拒绝链上提案。链上治理工具目前（截至撰写时）正在 Sanchonet 测试网上进行测试[^(29)](#c13.xhtml#ftn29)。需要工具来让 **DRep** 和 **SPO** 能够轻松便捷地参与链上治理。

# 委托代表 (DRep)

要让 Ada 持有者对链上提案进行投票，他们需像将质押的 Ada 委托给质押池运营商一样委托其投票权。任何 Ada 持有者均可提交链上提案，但通常拥有委托 Ada 投票权的 **DRep** 会进行投票。**DRep** 将对提案投票，结果将显示该提案是否已被 **DRep** 治理机构批准。

# 质押池运营商 (SPO)

**SPO** 通过运营处理和分发 Cardano 区块链区块的节点，在维护网络安全方面发挥关键作用。因此，当涉及硬分叉的链上提案出现时（这反过来又需要升级网络节点），他们将拥有投票权[^(30)](#c13.xhtml#ftn30)。他们还参与关于宪法委员会变更的投票。与 **DRep** 类似，集体 **SPO** 投票权用于确定投票是否已被 **SPO** 治理机构批准。

# 宪法委员会 (CC)

**CC** 是一组当选成员，任期固定。**CC** 的职责仅在于就特定提案的合宪性进行投票[^(31)](#c13.xhtml#ftn31)。例如，如果宪法规定国库必须始终持有流通 Ada 的 0.125%，则 **CC** 将反对违反这一阈值的国库提款提案。**CC** 可随时通过不信任投票解散，该投票仅限 **DRep** 和 **SPO** 参与。**CC** 法定人数参数将用于确定投票是否已被 **CC** 治理机构批准。

CIP-1694 中记录了七项治理行动，如*表 13.1*所示：

| **治理行动** | **目的** | **可投票实体** |
| --- | --- | --- |
| 不信任动议 | 用于解散 CC | DRep, SPO |
| 新 CC 或 CC 阈值变更 | 选举 CC 成员或更改 CC 法定人数要求或任期限制 | DRep, SPO |
| 宪法更新 | 修改宪法 | DRep, CC |
| 硬分叉发起 | 批准硬分叉 | DRep, SPO, CC |
| 协议参数变更 | 批准协议参数变更 | DRep, CC |
| 国库提款 | 批准从国库提款 | DRep, CC |
| 信息 | 创建仅包含链上信息的记录 | DRep, CC |

# Project Catalyst

Cardano 生态系统中最有趣的方面之一是 Project Catalyst。Project Catalyst 最初作为一项实验启动，根据 Ada 持有者的投票向项目提供资助。已进行 11 轮资助，第 1 轮于 2020 年 9 月宣布[^(43)](#c13.xhtml#ftn43)。资助金额从第 1 轮到第 9 轮不断增加，目前每轮资助设定为 5 亿 Ada。利用 IdeaScale 平台[^(44)](#c13.xhtml#ftn44)，Project Catalyst 声称是世界上最大的去中心化创新基金之一[^(45)](#c13.xhtml#ftn45)。
