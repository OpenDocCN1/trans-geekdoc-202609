
### 7.2.1.1.Mobile Device Management (MDM)

Implementing MDM systems in an organisation allows the organisation to monitor in a remote manner the performance and functions of mobile devices. An MDM system is based in the client/server architecture, of which the main components are the agent and the server respectively. [Figure 7.2](#chapter7.xhtml#fig7.2) shows the general architecture of such a system, where an MDM gateway (relay server) is configured within the DMZ to enable mobile devices to get access to the corporate network whilst the server is monitoring their performance. The MDM agent is installed in the mobile device, and it transmits information about the user account and the status of the device whilst the server enforces the policies implemented to comply with the internal regulations from the organisation (Vignesh and Asha, 2013).

### 7.2.1.2.Mobile Application Management (MAM)

IT administrators use this model to install, monitor, control, update, audit or remove customized applications created for the organisation in a remote manner. This feature allows IT administrators to take control of the applications allowed on each mobile device with the use of whitelists and blacklists (Kale, 2013). The main purpose of this solution is to control whether the applications installed on a mobile device fit with the policies of the organisation and to monitor in real time the performance of the customized applications. The solution balances three main features, which are performance, ease of use and security. In addition, customized applications and embedded systems are monitored to avoid exposing or compromising sensitive personal information from the current user/owner.

### 7.2.1.3.Mobile Information Management (MIM)

This model has great applicability in private cloud environments. The MIM system ensures the protection of and avoids any leakage of information, which is considered a crucial asset for the organisation. The model also demonstrates the limitations of installing trusted applications in mobile devices to control the data. The MIM solution comes across with the integration of MAM APIs into mobile devices, hence IT administrators can monitor whether information used by the user/owner is considered essential enough for the organisation to take the necessary measures to protect it. If the organisation protects the data, it will do so without getting involved with personal data.

### 7.2.2.Security concerns

Upon an analysis of the mind map shown in [Fig. 7.3](#chapter7.xhtml#fig7.3), it can be concluded that BYOD brings flexibility to organisations. This is accomplished thanks to the deployment of cloud environments, customized applications that can be installed on the endpoint devices, and the ability to allow employees to work remotely, saving them time. However, to reach the demanded levels of information assurance while avoiding any data leakage, strategic plans are required. These include resource optimisation and management, as well as the establishment of internal procedures and policies that can be controlled with suitable governance practices to keep the balance between flexibility, performance and security. As mentioned above, when BYOD is discussed, the use of wireless devices is also discussed, and so is wireless and mobile security. The protection of devices when connecting to public Wi-Fi networks, the encryption of sensitive information, the protection of phone and video calls against `eavesdropping` or `man-in-the-middle` attacks (MITM), and the protection of email and SMS services are all essential to the organisation. The high use of wireless personal devices increases in parallel their exposure to the cyber risks which are mentioned below:

•`Social engineering` is when attackers take advantage of the lack of security awareness among employees to extract sensitive information.

•`Phishing` is sending emails with malicious links that could lead to credential harvesting or unauthorized malware downloading to users while pretending to be a known contact.

•`Spear-phishing` is the sending of phishing emails to a specific target (e.g. emails including the name of the owner).

•`Malware` is the abbreviated term for “malicious software”. Such software can be installed in a device to take control of it, to steal information or to launch future cyber attacks (e.g. trojans, worms, rootkits, viruses, ransomware).

•`Device theft` is considered a risk to the organisation despite it being out of the control of the owner. This is due to all the information stored in the device.

•`Insider threats` can happen because of frustrated employees or can be performed by cyber crime organisations. They occur when a person gets unauthorized access to the main computers used by an organisation.

•`Man-in-the-middle attacks` happen when attackers intercept messages between client and server in order to eavesdrop on information or manipulate it.

•`Shoulder surfing` is when an attacker is able to see the user typing out their credentials and acknowledging personal information such as banking or contact information on their personal devices. Despite being simple, it can cause great harm to organisations.

### 7.2.3.BYOD security challenges

There has been significant growth in the development of mobile devices in the last few years. Nowadays smartphones have features comparable to those of laptops. These outstanding features have enhanced functionality, therefore the use of smartphones by employees for professional purposes has been accepted by many organisations. In addition, these devices have become more accepted in the workplace as they now come with stronger security applications and features. Unfortunately, technological organisations are competing fiercely for market share and therefore, when developing devices and software applications, they tend to focus on innovation and ease of use rather than on security and reliability (Eslahi *et al*., 2014).

When talking about information security, it is necessary for cyber security practitioners, senior management and users in general to achieve security while maintaining performance and ease of use of computer systems in a professional environment. This is a complex endeavour. Following [Fig 7.4](#chapter7.xhtml#fig7.4), there are three components that must be appropriately balanced in computer systems, which are security, ease of use and performance. If software applications are developed to enhance business productivity and to improve organisational performance, their user interfaces must be easy to use, and during data processing they must follow the necessary protocols and functions to assure confidentiality, integrity and availability. For instance, if a system has more of the strongest security mechanisms, its performance is likely to degrade steadily, making the user interface less simple to use.
