
Word macros that can launch fileless malware are a more sophisticated threat as an exploit is run in memory without the need to save a payload. Payloads may also be delivered using steganography to hide code in images which are generally ignored by Antivirus programs. Visiting a website’s images causes images with steganographic content to be automatically downloaded into a user’s internet cache, providing another means from which code could be extracted. This will be discussed later.

If a firewall is configured correctly, there are no inbound rules generally required other than for incoming email to an email gateway server configured for that purpose, and the only outbound rules allowed should be:

• DNS outbound using UDP DNS port 53 only. (Generally, from a DNS Caching server only).

• HTTPS outbound through a proxy server.

• Email outbound from a Microsoft Exchange Server, or an email gateway.

• NTP outbound for time synchronisation.

• ICMP outbound for diagnosing connectivity issues.

This chapter is therefore limited to these protocols and their related TCP/UDP ports.

### 1.2.Scope of Discussion on Data Exfiltration Methods

According to Rashid *et al*. (2017) an advanced persistent threat (APT) attack follows three distinct phases.

Stage 1: Reconnaissance, attack staging and initial host infection.

Stage 2: Network intrusion, remote control, data discovery, persistence.

Stage 3: Staging server selection, data preparation and data exfiltration.

This chapter focuses on the last stage where access is obtained to a user’s workstation or a server. Therefore,

• Data exfiltration by air-gapped methods is excluded from this discussion.

• Data exfiltration via USB devices is also excluded. Obviously stealing data using USB devices, either as backup media or otherwise is perhaps the easiest way to get substantial amounts of data from an organisation but this involves deception and unauthorised physical access which are outside the scope of this chapter. Also, it is assumed that the use of USB storage devices has been restricted either by a system Group Policy (GPO) or centrally managed antivirus endpoint management system like Sophos EMS. Where USB devices need to be used it would be assumed that they are encrypted and that their loss would not pose a threat.

• It is assumed that user access rights are set correctly, and that users do not have local administrative rights. The focus will be on methods that are theoretically possible using tools which are native to the operating system or that could be possible without installing programs — effectively living off the land (Symantec, 2017).

• Stolen Laptop. This is outside the scope of this discussion, though the following quote must not be forgotten: “The data leaks posed by accidents exceed the risks posed by vulnerable software” (Kaspersky, 2014).

• Wireless vulnerabilities like man-in-the-middle attacks are excluded as wireless connections to a corporate network are assumed to be unacceptable.

### 1.2.1.*Web server attack — SQL injection*

Structured Query Language injection occurs when code is input in forms. If the data entered is not validated, then any code placed in a search box is sent to the SQL engine with two possible undesirable outcomes. The first is that a buffer overflow is caused resulting in shell access using the SQL connect permissions and the second is that answers to unintended queries can be retrieved. To extract data, many queries might be required to establish a database’s structure. This sounds complex but has happened on many occasions, as is clear from the reported hacks.

The reality is and has always been that anything internet facing with an external IP address will be under attack, so web server operating systems need to be hardened and web interfaces need to be robust. Forensic investigations of web attacks on web servers such as Apache can be difficult because even if full forensic logging is turned on, if the attacker is using the TOR browser, then it will be the TOR endpoint IP address that is logged, not the attacker’s IP address.

Web servers must therefore be patched and scanned for vulnerabilities regularly, and when accessing confidential information, two-factor authentication should be used where possible.

### 1.2.2.*Cross Site Scripting*

Cross Site Scripting (XSS) involves appending a JavaScript string to the end of a URL. This is then sent in an email to a user who is meant to think that clicking on that URL will only lead him to a familiar site. This perception is reinforced by the fact that the displayed URL does not show the appended string. When a user clicks on the link they are taken to the site as expected but a JavaScript script also runs. This can be set to pop-up a window asking for credentials, a hook that launches a command and control attack.

According to the European Union Agency for Network and Information Security (ENISA), XSS attacks grew 39% in Q1 of 2017, and XSS vulnerabilities are thought to have grown by 166% in 2017 (ENISA, 2017, p. 36). There are various types of XSS attacks, the most common being a reflected attack whereby no change is made to the web server. Cross Site Scripting attacks are also a common way of stealing cookies for session hijacking and getting user credentials.

Preventing web attacks requires a combination of technology and awareness. XSS attacks commonly happen when users follow links in emails and on the internet to familiar websites. One effective way to prevent XSS attacks is to examine links before clicking on them. Many Antivirus solutions examine weblinks for suspicious content at the end of a web address, as do all the main browsers now, including Internet Explorer 11, Microsoft Edge, Google Chrome and Mozilla Firefox. Trustwave’s Blended Threats is an example of an option deployed on the Trustwave Secure Email Gateway that rewrites links in emails so that they can be verified by Trustwave. The primary precaution to avoid the consequences of rogue content is not to have systems that are vulnerable, which is largely achieved by keeping systems patched with the latest security updates.

Cutting edge firewalls that have XSS detection built into IDS/IPS features should be deployed as these can prevent XSS attacks and filter out Denial-of-Service (DoS) attacks. GeoIP filters, which can be used to block traffic from specific geographic locations, are now also a common feature of firewalls. They are seldom used, and their use should be considered.

### 1.2.3.*PowerShell exploits*

PowerShell exploits are fileless malware using PowerShell, PSExec or WMI that run simple scripts and shellcode directly in memory. They are increasingly being used in attacks by both targeted threat actors and cyber criminals as they avoid detection and make forensic investigations harder (Symantec, 2017). Symantec refer to these attacks as “living off the land” and “fileless attack methods”.
