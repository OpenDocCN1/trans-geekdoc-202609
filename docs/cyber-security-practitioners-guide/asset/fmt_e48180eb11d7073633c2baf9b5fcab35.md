
McAfee DLP is a utility that can scan, identify and classify data without user intervention. Policies can be defined around how it alerts users to policy violations (MacAfee, 2017). The attraction here is not having to classify data every time data is saved.

Symantec DLP is another utility that can scan and automatically detect sensitive documents and images. Network Prevent for Web can be deployed at network egress points and integrates with proxy servers using the Internet Content Application Protocol (ICAP, 2018). Symantec DLP can monitor the use of sensitive data and goes as far as digitally shredding documents (Symantec, 2018). McAfee, Sophos, Trend Micro, Kaspersky, and Symantec all follow the ICAP standard. They all provide real-time content filtering, though it is not necessarily implemented in any of their products. It must be noted that the ICAP protocol and feeds are also legitimately used for advertising as well as virus checking and language translation (ICAP 2018).

SonicWall Capture Client is a workstation agent designed to detect ransomware by Sentinel One. Should an attack happen it can roll back the attack (SonicWall, 2017).

### 1.9.2.*Detect and block using a proxy*

Trustwave Secure Web Gateway (SWG) is Trustwave’s ‘Zero-Malware’ web-proxy solution (Trustwave, n.d.). Because the secure web gateway uses its own DNS settings, a gateway firewall can be configured such that DNS outbound on UDP port 53 is only possible from the Secure Web Gateway device.

### 1.9.3.*Detect and block using a next-generation firewall*

Sophos XG UTMs and Zyxel USG UTMs are examples of all-in-one firewalls, web proxy, and network monitoring solutions. These are ideal for very small organisations.

### 1.9.4.*Detect and alert using network traffic analysis*

Darktrace and Snort are network-based anomaly detection systems which identify unusual network traffic. These were discussed in [Section 1.5.2](#chapter1.xhtml#sec1.5.2).

### 1.9.5.*Detecting sensitive data*

Many of the tools that are designed to assist with data classification are designed with large companies in mind. An example is Spirion (formerly IdentityFinder) which is a tool that can be used to search file shares for sensitive data (Spirion, 2018).

Unlike traditional security systems (e.g. IDS, IPS and firewalls), which are supposed to act when an attacker enters the enterprise, data exfiltration countermeasures are expected to work when an attacker is on the way out with sensitive data (Ullah *et al*., 2017). Firewalls are generally designed to keep attackers from getting in, not from getting out when they are inside. This is very similar to what Houdini did; he exploited the fact that locks at the time were designed to prevent people from entering areas, not from getting out of them.

GlobalVelocity (GlobalVelocity, n.d.) is a DLP solution for protecting data in the cloud. The challenge for companies using cloud providers is not knowing the level of protection in place and having limited control over how DLP products might be configured.

Microsoft Intune is an example of a cloud-based DLP solution whereby the configuration is done by the company whose systems are being hosted rather than by the cloud provider. The Office365 Enhanced Protection and Mobility Suite offers several security mechanisms to protect data. Rules can be set up in Office365 to detect the exfiltration of credit card data and social security and national insurance numbers. The DLP rules can be set for all country formats or specific countries, thus catering for various formats of national insurance numbers. However, setting countries unnecessarily in the rules could obviously increase the rate of false positives.

### 1.10.Recommendations to Protect Against Data Theft

The following recommendations should be considered to protect against data theft:

• Uninstall Microsoft OneDrive using a group policy (GPO) if it is not required in an organization.

• Use a proxy server that can block web storage websites.

• Instant messaging systems should be blocked by the organisation’s web proxy.

• Consider blocking Ping (ICMP) and NTP outbound from workstations.

• Companies should consider a default deny on a proxy server for website browsing and only websites needed for business purposes should be added as needed.

• Primary and secondary internal DNS servers should not be configured to resolve external DNS names, as good web proxy servers can be configured to use external DNS cache servers. This not only improves security, it also reduces the load on the internal DNS servers. For WSUS and AV to get updates, a dedicated DNS server should be used.

• Limiting the size of email attachments and the number of attachments that can be attached to an email are practical steps to restrict the amount of data that can be stolen by email.

Supply chain vulnerabilities must also be considered. To quote the National Cyber Security Centre’s annual report:

*“2017 saw some significant examples of supply chain attacks, including the compromise of a large number of managed service providers (MSPs), enabling access to commercially sensitive data from them and their clients. At least two software companies had their products (MeDoc and CCleaner) compromised at source, resulting in their customers being infected with malware when downloading the software/updates.”* (NCSC, 2018)

Minimizing the amount of sensitive information that an organisation holds clearly minimizes any impact from a data leak. This principle is at the heart of information governance and GDPR strategies with respect to personal data. The same principle must apply to all confidential and sensitive information, that regardless of the measures that are put in place to protect data, unnecessary data should not be collected as this increases the impact of any breach.

The deployment of end-to-end encryption systems such as GalaxKey or WhatsApp on a system makes it very difficult for monitoring systems to identify data in an email or text message as the monitoring system will have no way of decrypting the data it is trying to monitor. However, the use of these systems for specific occasions where a high level of confidentiality is required makes perfect sense.

To quote Rashid *et al.*: “Due to the diversity of attack vectors no single security control provides protection against all of these vectors. Multiple detection mechanisms must be used together in a multi-layered approach” (Rashid *et al.*, 2017). The result is often referred to as defence in depth, but as any practitioner knows, this leads to unintended conflicts between products. Antivirus updates can be blocked by firewalls and one-time links which are often used for password resets are claimed by proxy servers, to name just a couple of the possible issues. Setting exclusions and resolving conflicts has become a regular part of an IT system manager’s day.

One interesting approach to reducing the impact of data leaks is the concept of Zero Trust, where everything is untrusted (Vijayan, 2018). The concept is that any threat is limited to the data on one desktop; however, this means that the reporting and monitoring of devices becomes difficult. Microsoft has addressed this issue for a user of Office365 with the Enterprise Security and Mobility suite, which does cater for this, as Microsoft Intune registers and validates that connecting devices are patched and safe to connect to. For companies not using Office365, Centrify provides a similar Zero Trust framework (Centrify, 2018). In an office environment where all services are cloud services, the use of Zero Core clients that have a Citrix or terminal server that is imbedded in firmware is a strategy that removes the threat from viruses at the endpoints.
