
•**Wireless Network**: A wireless network is a set of connected devices that are not connected by cables of any kind. These networks use access points to get access to the network or use some wireless techniques such as ad-hoc and Bluetooth (`Zheng et al.`, 2013). These networks usually are cost effective and easily deployed.

Also, there are two kinds of topology which can connect the networks. The two kinds of networks are infrastructure and infrastructure-less networks.

•**Ad-hoc Network**: An ad-hoc network is an infrastructure-less network. It is a crucial enabler of next-generation communications. Such networks can be formed and reconfigured dynamically and they can be mobile, standalone or internet-worked with other networks (`Panaousis`, 2012). For instance, the Mobile Ad-hoc Network (MANET) is the most important one of these networks.

•**Mobile Ad-Hoc network (MANET)**: A mobile ad-hoc network is a set of mobile nodes that communicate with radio links. MANET network infrastructure is not defined and there is no centralized administration that controls the other activities (`Aarti and Tyagi`, 2013). MANETs are established by a group of autonomous nodes that communicate with each other by establishing a multi-hop radio network and maintaining connectivity in an infrastructureless manner. They allow data, voice and video communications over a wireless channel (`Thomas et al.`, 2010). The main role of MANETs is to enable wireless and mobile communication services without using the expensive service-provider network and without having a previously set-up infrastructure.

There are several uses of these networks in real life; for example, they are used in disaster and emergency operations.

The security requirements of wireless ad-hoc networks are very important. One of MANET’s big issues is that it is not a centrally-controlled network. Many applications on a network such as MANET need to be built with more care because the attacks on them may be internal or external. For example, connected vehicles currently connect to each other wirelessly with the Vehicular Ad-hoc Network (VANET). VANET is a wireless communication system that uses mobile cars as communication nodes to determine positioning and movement for the connected vehicles. Wireless networks like VANET validate every message circulating in their network without assessing the source’s quality or the content’s accuracy. As a result, VANET is inherently vulnerable to false messages being spread in the network by messages-poofing and denial-of-service (DoS) attacks (`Sharma et al.`, 2017). So security concerns should be given further attention.

### 11.2.Cyber Security on Mobile Devices

It is expected that, in 2020, more than 50 billion devices will connect to the Internet (`Hammi et al.`, 2017). Most of these devices should be wireless. 5G networks will make global life incredible, because they will enable the ICT to be faster, more reliable and more easily deployed. 5G networks consist of many types of networks. The significant parts of 5G networks are the wireless networks, such as mobile ad-hoc networks and wireless sensor networks. Houses, doors and windows are connected to the network; fridges, light systems and even personal coats are wirelessly connected to the network as well. For example, the sensor chip fixed inside a coat can automatically send the health information of a patient to the hospital if his situation is critical. Also, CCTV cameras and self-driving cars use wireless technology to connect with the network.

All of the above technologies will not be useful without security. Sometimes the absence of security may be a life or death matter. For instance, self-driving cars should be strongly protected against hackers, because any malicious breach would cause a disaster. According to Morgan (2017), the cost of cyber security reached $84 billion in 2015, and it is expected to reach $170 billion in 2020. So most businesses are paying lots of attention to security concerns. For these reasons we are undertaking this research.

Cyber security is the term used to describe the processes and technologies designed to protect computers, networks, data and programs from unauthorized access, damage or attack. According to the Telegraph, the cost of cyber attacks to UK businesses in 2017 reached $34 billion. To ensure cyber security, the corresponding efforts need to be made throughout an information system. The main elements of cyber security include applications security, information security, network security, disaster recovery and end-user education.

Unfortunately, conventional multimedia traffic management algorithms are developed mainly to guarantee delay while usually neglecting security requirements. A security-critical VoIP and multimedia service architecture is proposed, which jointly considers traffic analysis, security requirements, and traffic scheduling for multimedia applications. Many previous researchers (`Nagendra and Sekhar`, 2014; `Ali et al.`, 2014; `Binod and Hyuk`, 2010) adopted security algorithms that were weak enough to deal with the constraints of the quality of service (QoS) in such a way as to make the delay within limits. Also, using multiple keys for encryption and decryption will make the probability of the encrypted data being decrypted by a hacker very low, because even if the hacker knows what the first key is, it is not likely that he also knows what the other keys are. `Matesanz et al.` (2012) shows the most common threats to ad-hoc networks and reviews several proposals that attempt to minimize some of these threats, showing their ability to protect these networks in light of their vulnerabilities and the threats that might arise. Some of these threats are described below.

*Address Spoofing*: This attack occurs when the malicious node intentionally selects an allocated or a free IP address. In the first case, the node takes an IP address which has been allocated to the victim, and once it has done so, hijacks the victim’s traffic. In the other case, the node allocates the free IP address to itself so that it can join the network. Once in the network, the node collects important information which can be used to execute some attacks, like denial of service attacks.

*Address Space Consumption*: This attack occurs when the attacker consumes the address space by demanding a huge number of IP addresses. The attacker could request the assignment of IP addresses to fake nodes so as to prevent other nodes from being configured and connecting to the mobile ad-hoc networks.

*Address Conflict Threat*: This attack occurs when the malicious node assigns an additional address to a client which is already in use. This would produce many problems in the mobile ad-hoc networks and lead to an address conflict (`Sandoval and García`, 2012).

*Denial of Service Threat*: This threat occurs when, in an auto-configuration process, the attacker acts as a requester and sends AREQ messages to several nodes simultaneously, causing an overload of traffic.

*Multiple Identities (Sybil)*: This kind of attack is possible when a repudiation system exists to state the legality of nodes in the network. The attacker could cause the isolation of valid nodes by creating messages to blacklist those nodes. Blackmail is a type of Sybil attack.
