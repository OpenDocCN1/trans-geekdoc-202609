
Many security tools are available open source for Linux. Bro is another tool for network analysis and security monitoring (Bro, 2018). Snort is an open source intrusion prevention system capable of real-time traffic analysis and packet logging. Pfsense is an increasingly popular open source firewall (Pfsense, 2018).

### 1.7.Methods and Models for Security and Privacy

From Ullah *et al*. (2017) it is apparent that many of the methods proposed in academic studies for detecting and preventing data loss have not been trialed by real companies and remain academic ideas and that the practicalities of implementing some of the ideas have been overlooked.

The data classification model chosen will depend on the types of data an organisation holds. For many organisations this is just confidential, personal data, and unclassified data. In a military context, top secret data would be on a need-to-know basis, so a higher-ranking officer might not have access to some data that lower ranks working on projects might have. “Need to Know” or “Least Privilege” are security practices that are common in many organisations.

Document management systems like iManage (iManage, 2018) and Laserfiche are good ways to protect documents as, with these systems, documents are stored in a repository rather than on file shares, thus adding another layer of security. Further access permissions are then set with the document management system providing a further layer of protection.

### 1.7.1.*Methods for security reengineering*

Email is the lifeblood of many organisations, however when it comes to agreeing to contracts with other parties it is soon seen how inefficient it becomes. Multiple versions of draft documents which are stored by all parties do not just clog up email systems but file storage and message archives too. Several products that make this experience better are portal-based. Some also provide the ability to compare documents online and this means that the whole collaborative experience can be achieved online. Examples of this are Objective-Connect, iDeals data rooms and Workshare. SharePoint can also be configured to provide this functionality.

Products like iDeals, Workshare, and Objective-Connect provide secure online virtual data rooms where companies can share documents with other parties. These systems provide a more efficient way for companies to collaborate when compared to email. The use of portals has become common for large companies, councils and universities, removing the need to send large attachments by email. Some of the products available to provide this functionality are Objective Connect (Objective, 2017), which allows users to share and version documents with others in its portal, iDeals which features document sharing with very restrictive viewing, and DeltaView’s Workshare which provides document comparison within its portal.

Blackberry UEM is an alternative approach to providing mobile access to an Exchange Server. This is a full MDM solution which can provide connectivity with mobile devices and devices running Blackberry’s iOS or Android app. It uses outbound ports only, thus eliminating the threats that go with having inbound ports configured (Blackberry, 2018).

### 1.7.2.*Privacy-enhancing technologies and trustworthy information systems*

A common technique is to tag documents with keywords, then use an AV tool such as ClamAV to generate signatures. The signature can then be added to a proxy server such as Squid to block these from leaving the organization (Rashid *et al*., 2017).

Boldon James provides tools to add metadata tags to documents (Boldon James, 2018). These can work with Data Loss Prevention systems such as Forcepoint, Intel Security and Symantec DLP.

Tukan’s GREENmod (TukanIT, 2018) is another tool. This integrates with McAfee Threat Intelligence Exchange/Data eXchange Layer (TIE/DXL), and McAfee DLP (McAfee, 2017), also to prevent data exfiltration.

Safetica is an example of a Data Leak Prevention product which deploys agents on workstations (Safetica Endpoint Client) which communicate with a Safetica Management Server. This is an example of perhaps what will be a suite of new products to protect against data loss. Data can be tagged depending on folder location or file type and using DLP rules, which look at tags and file contents. Sensitive data can be prevented from being attached to emails or transferred to web storage, and even screenshots of sensitive data can be prevented. Safetica also provides the ability to see an overview of all web browsing, all sent email, all file activity and all printing by a user.

### 1.8.What Kinds of Products Are There to Prevent Data Theft?

The approaches to detecting and preventing data exfiltration fall into 5 categories:

1.Block data being exfiltrated at a firewall. Several firewall manufacturers now offer a DLP bolt-on which uses deep packet inspection to provide protection against data loss. The protection is based on rules that have been set to detect phrases and number patterns.

2.Use an agent that applies centrally managed policies and blocks leaks at the endpoint. This approach enables a great deal of flexibility in terms of integration with Active Directory, file tagging, reporting and alerting a user that they are doing something which is not permitted. Safetica is an example of a system that deploys a workstation agent.

3.Use of a proxy server that has built-in data-loss detection and prevention capabilities. The Trustwave Secure Web Gateway (SWG) is a good example of this.

4.Next generation firewalls that are both firewall and web proxies.

5.Traffic monitoring. Based on an analysis of normal network traffic, AI is used to detect abnormal network traffic. This is the principle used by Darktrace.

We will discuss these three approaches and some of the products using these approaches, and test them accordingly.

### 1.9.Detect and Block Using a Firewall

It is important to configure firewalls in the right arrangement from day one as the architecture of a network is hard to change later without service disruption and risk.

It is interesting to note that the separation of the internal network from the DMZ and the internet by 2 firewalls, as in [Fig. 1.2](#chapter1.xhtml#fig1.2), is now a requirement by some banks under PCI DSS questionnaire D. The three-legged firewall, as in [Fig. 1.3](#chapter1.xhtml#fig1.3), which has been a cost-saving option for smaller companies for several years, is therefore falling foul of security standards. If multiple firewalls are used, a DLP solution would normally be required on the internal firewall only.

Quality switches like the CISCO SG500 series now have access control lists either based on a MAC address or an IP address. These switches are effectively firewalls. Complex rules can now be set on many network switches and unused ports can be shut down. ‘Sticky Macs’ is a feature whereby a switch learns and remembers connected MAC addresses and should an MAC address violation occur the affected port can be automatically shut down.

### 1.9.1.*Detect and block using an agent or app at the endpoint*

Safetica and Infoblox are full data loss prevention solutions which defend against planned or accidental data leaks and malicious insider actions by deploying a centrally managed agent on workstations.
