### 4.2.3.*Design approach*  

Whilst there has been a significant amount of research pertaining to video and network surveillance, there appears to be limited work within the public domain in reference to threat detection through proximity sensors.  

Determining human movement within an area can present specific challenges and the outcome depends on the methods used to monitor movement patterns. Fong *et al.* (2007) argue that the detection of suspicious patterns in physical environments, using multiple reference points to detect human movement patterns, can provide an increased threat detection method within a business environment.  

It is evident that the physical environment can play a pivotal role when determining movement patterns. As an example, an area with natural barriers such as an office space with multiple meeting rooms, or a doctor’s practice with private consultancy surgeries, can provide reference points and natural transient areas.  

Conventional access control and monitoring systems can leverage the design of a building, incorporating monitoring points at key access areas. Fong *et al.* (2007) define a logical security model based on an access-controlled door-entry system, which can log entry and exit metrics to determine movement patterns.  

Whilst it can be argued that this type of design is able to provide movement detection metrics through control points, it does not address the inherent risk of tailgating. There can also be an apparent lack of controls attributed to a one-dimensional access control solution, which can be easily circumvented, intentionally or not.  

A key aspect of any anomaly detection technique is the nature of the input data. Input is generally a collection of data instances (also referred to as object, record, point, vector, pattern, event, case, sample, observation, or entity) (see Tan *et al.*, 2005).  

Assuming movement is monitored through access control logs, determining anomalies based on entry and exit times may prove challenging. Fong *et al.* (2007) describe ‘known penetration scenarios’, which are essentially sequences of actions that are able to identify human movement as it shifts from a normal to a compromised state. By detailing an anomaly detection model, one can detect threats based on the data mined from a generic access control database.  

One of the primary objectives of the research project is to identify anomalous behaviour patterns using data derived from a generic data source. However, as the target organisation (Dakota) operates an open plan environment, the technology adopted for the research project will be based on proximity sensors.  

The researcher has taken a holistic approach to anomaly detection, creating an algorithm that is adaptive by design. This decision is based on the apparent lack of controls through a one-dimensional access control solution.  

As an example, processing access control data requires a physical device, with sensors on each side of the door to detect entry into and exit from the controlled zone. This method has an intrinsic risk of tailgating as a door opened by one member of staff can allow access to others without the need for those others to be authenticated. As staff enter a door in groups only one card is registered on the access log, which can distort the data when those individuals leave the controlled zones using their access cards.  

Leveraging data derived from the location tracking technology that is seamless with respect to the individual being monitored can be considered important, particularly in an open space environment that does not have access-controlled entry/exit points.  

The data is therefore key to the algorithm and its attributes should be understood before the security model is constructed. Data attributes can be described as binary, categorical (qualitative), or continuous (quantitative). Each data instance might consist of only one attribute (univariate) or multiple attributes (multivariate). In the case of multivariate data instances, all attributes might be of the same type or might be a mixture of different data types (see Chandola *et al.*, 2009).  

The nature of the data attributes determines the anomalous detection method applied. Input data can also be categorized based on the relationship present among data instances (see Tan *et al.*, 2005). The algorithm will require multiple data instances measuring time, duration and date, etc. These can be described as continuous and will be associated with the individual and the location (categorical).

Murenin *et al.* (2017) explore human movement and interaction patterns between employees within an office environment. This may provide a valuable insight when determining natural human movement patterns within an office environment. Murenin *et al.* (2017) extracted data from various entry points within a typical office building and analysed access control logs within controlled zones. Leveraging employee data, including job function and sector location, and cross-referencing this against the specific physical characteristics of the building, a threat model was created.  

Whilst this research focuses on anomalous employee behaviour within an office building using proximity monitoring data, there are other threat detection solutions, based on a variety of different technologies, that may also be considered.
