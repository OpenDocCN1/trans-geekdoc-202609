# Create Custom Processor Configuration

To create a processor configuration, use the dlhdl.ProcessorConfig object. For more information, see dlhdl.ProcessorConfig. To learn about modifiable parameters of the processor configuration, use setModuleProperty and setModuleProperty.

```matlab
hPCNew = dlhdl.ProcessorConfig;
hPCNew.TargetFrequency = 300;
hPCNew.setModuleProperty('conv', 'KernelDataType', 'int8');
hPCNew.setModuleProperty('conv', 'ConvThreadNumber', 64);
hPCNew.setModuleProperty('fc', 'KernelDataType', 'int8');
hPCNew.setModuleProperty('fc', 'FCThreadNumber', 16);
```

# Deploy Quantized Network Example

This example shows how to train, compile, and deploy a dldl.Workflow object that has quantized Alexnet as the network using the Deep Learning Toolbox™ Support Package for Xilinx FPGA and SoC. Quantization helps reduce the memory requirement of a deep neural network by quantifying weights, biases and activations of network layers to 8-bit scaled integer data types. Use MATLAB™ to retrieve the prediction results from the target device.

# Load Pretrained Series Network

To load the pretrained series network AlexNet,

```matlab
snet = alexnet;
```

To view the layers of the pretrained series network, enter:

```matlab
analyzeNetwork(snet);
```

The first layer, the image input layer, requires input images of size 227-by-227-by-3, where 3 is the number of color channels.

```matlab
inputSize = snet.Layers(1).InputSize;
inputSize = 1x3
227 227 3
```

# Define Training and Validation Data Sets

This example uses the logos dataset. The set consists of 320 images. Create an augmentedImageDatastore to use for training and validation.

```matlab
curDir = pwd;
newDir = fullfile(matlabroot,'examples','deeplearning_shared','data','logos dataset.zip');
copyfile(newDir,curDir,'f');
unzip('logos_dataset.zip');
```

```matlab
imds = imageDatastore('logos dataset', ...
    'IncludeSubFolders',true,
    'LabelSource','fold');

[imdsTrain,imdsValidation] = splitEach(imds,'randomized');
```

# Replace Final Layers

The last three layers of the pretrained network are configured for 1000 classes. These three layers must be fine-tuned for the new classification problem. Extract all the layers, except the last three, from the pretrained network.

```matlab
layersTransfer = snet.Layers(1:end-3);
```

Transfer the layers to the new classification task by replacing the last three layers with a fully connected layer, a softmax layer, and a classification output layer. Set the fully connected layer to have the same size as the number of classes in the data.

```matlab
numClasses = numel(categories(imdsTrain.Labels));
```

```matlab
layers = [
    layersTransfer
    fullyConnectedLayer(numClasses,'WeightLearnFactor',20,'BiasLearnFactor',20)
    softmaxLayer
    classificationLayer];
```

# Train Network

The network requires input images of size 227-by-227-by-3, but the images in the datastore have different sizes. Use an augmented datastore to automatically resize the training images. Specify additional augmentation operations to perform on the training images, such as randomly flipping the images along the vertical axis and translating them up to 30 pixels horizontally and vertically. Data augmentation helps prevent the network from overfitting and extracting details of the training images.

```matlab
pixelRange = [-30 30];
imageAugmenter = imageDataAugmenter(
    RandReflection,'true',
    RandXdTranslation',pixelRange,
    RandYTranslation',pixelRange);
imgdsTrain = augmentedImageDataStore(inputSize(1:2),imdsTrain,
    'DataAugmentation',imageAugmenter);
```

To automatically resize the images without performing further data augmentation, use an augmented image datastore without specifying any preprocessing operations.

```matlab
imgdsValidation = augmentedImageDataStore(inputSize(1.2),imdsValidation);
```

Specify the training options. For transfer learning, keep the features from the early layers of the pretrained network (the transferred layers). To slow down learning in the transferred layers, set the initial learning rate to a small value. Specify the mini-batch size and validation data. The software validates the network every Validation iterations during training.

```matlab
options = trainingOptions('sgd',
    'MinBatchSize',10,
    'MaxEpochs',6,
    'InitialLearnRate',1e-4,
    'Shuffle','every-epoch', ...);
```
