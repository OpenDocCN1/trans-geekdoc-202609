# Compile the MNIST Series Network

To compile the MNIST series network, run the compile function of the dlhdl.Workflow object.
d = hw.compile;

# Program Bitstream on FPGA and Deploy Network Weights

To deploy the network on the Intel Arria 10 hardware, run the deploy function of the dlhdl.Workflow object. This function uses the output of the compile function to program the FPGA board by using the programming file. It also downloads the network weights and biases. The deploy function starts programming the FPGA device, displays progress messages, and the time it takes to deploy the network.

```
hW.deploy
### FPGA bit programming has been skipped as the same bitstream is already loaded on the t
### Loading weights to FC Processor. Current time is 28-Jun-2020 13:45:67
```

# Run Prediction for Example Image

To load the example image, execute the predict function of the dlhdl.Workflow object, and then display the FPGA result:

```
inputImg = imread('five_28x28.pgm');
imshow(inputImg);
```
