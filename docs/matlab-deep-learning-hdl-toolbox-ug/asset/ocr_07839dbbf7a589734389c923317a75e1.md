# Generate Custom Processor IP

The dhldl.buildProcessor API builds the dhldl.ProcessorConfig object to generate a custom processor IP and related code that you can use in your custom reference designs.

+   1. Create a dhldl.ProcessorConfig object.

+   2. Setup the tool path to your design tool. For example, to setup the path to the Vivado design tool, enter:

```
hdilsetuptath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.bat');
```

+   3. Generate the custom processor IP.

```
dhldl.buildProcessor(hPC);
```
