Code generation is now supported for a 2-D grouped convolution layer that has the NumGroups property set as 'channel-wise'.
These limitations apply when generating code for a network using this layer:
 Filter size must be 1-14 and square. For example [1 1] or [14 14]. When the NumGroups is set as 'channel-wise', filter size must be 3-14.
 Stride size must be 1-12 and square.
 Padding size must be in the range 0-8. |
