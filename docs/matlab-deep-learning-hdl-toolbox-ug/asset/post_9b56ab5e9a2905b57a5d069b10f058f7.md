# Create Workflow Object

Create an object of the dhldl.Workflow class. When you create the object, specify the network and bitstream name. Make the saved pretrained neural network, snet, as the network. Make sure that bitstream name matches the data type and the board you are targeting. In this example the target FPGA board is the Xilinx ZCU102 board. The bitstream uses a single data type.

```matlab
hw = dhldl.Workflow('Network', snet, 'Bitstream', 'zcu102_single', 'Target', hTarget);
```
