
## Image Classification Using DAG Network Deployed to FPGA

This example shows how to train, compile, and deploy a dhldl.Workflow object as the network object by using the Deep Learning HDL Toolbox™ Support Package for Xilinx FPGA and SoC. Use MATLAB® to retrieve the prediction results from the target device.

## Required Products

For this example, you need:

- Deep Learning Toolbox™
- Deep Learning HDL Toolbox™
- Deep Learning Toolbox Model for ResNet-18 Network
- Deep Learning HDL Toolbox Support Package for Xilinx FPGA and SoC Devices
- Image Processing Toolbox™

## Load Pretrained Series Network

To load the pretrained series network ResNet-18, enter:

```matlab
snet = resnet18;
```

To view the layers of the pretrained series network, enter:

```matlab
analyzeNetwork(snet);
```

The first layer, the image input, requires input images of size 227-by-227-by-3, where 3 is the number of color channels.

## Define Training and Validation Data Sets

This example uses the MathWorks MerchData set. This is small data set containing 75 images of MathWorks merchandise, belonging to five different classes (cap, cube, playing cards, screwdriver, and torch).

```matlab
curDir = pwd;
unzip('MerchData.zip');
imds = imageDatastore('MerchData',
'IncludeSubfolders',true,
'LabelSource','foldernames');
[imds.train,imdsValidation] = splitEachLabel(imds,0.7,'randomized');
```

## Replace Final Layers

The fully connected network and classification layer of the pretrained network are configured for 1000 classes. These two layers fc1000 and ClassificationLayer_predictions in ResNet-18 contain information on how to combine the features that the network extracts class probabilities and predicted labels. These two layers must be fine-tuned for the new classification problem. Extract all the layers, except the last two, from the pretrained network.

```matlab
lgraph = layerGraph(snet)
lgraph = LayerGraph with properties;
```

## Train Network

The network requires images of size 224-by-224-by-3, but the images in the image datastores have different sizes. Use an augmented image datastore to automatically resize the images. Specify additional augmentation operations to perform on the training images, such as randomly flipping the images along the vertical axis and translating them up to 30 pixels horizontally and vertically. Data augmentation helps prevent the network from overfitting and memorizing the details of the training images.

```matlab
pixelRange = [-30 30]
imageAugmenter = imageDataAugmenter(
'RandReflection',true, ...
'RandTranslation',pixelRange, ...
'RandTranslation',pixelRange)
```

To automatically resize the validation images without performing further data augmentation, use an augmented image datastore specifying any additional processing operations.
augindsTrain = augmentedImageDatastore(InputSize(1:2),imdsTrain, ...
'DataAugmentation',imageAugmenter)
augsValidation = augmentedImageDatastore(InputSize(1:2),imdsValidation)

Specify the training options. For transfer learning, keep the features from the early layers of the pretrained network (the transferred layers). To slow down learning in the transferred layers, set the initial learning rate to a small value. Specify the min-batch size and validation data. The software validates ValidationFrequency iterations during training.

```matlab
options = trainingOptions('sgdm', ...
'MiniBatchSize',6, ...
'MaxEpochs',10e-4, ...
'Shuffle','every-epoch',augsValidation, ...
'ValidationFrequency',3, ...
'Verbose',false, ...
'Plots','training-progress');
```

Train the network that consists of the transferred and new layers. By default, trainNetwork uses a GPU if one is available (Parallel Computing Toolbox™ and a supported GPU device.) information. use "GPU Support by Release (Parallel Computing Toolbox). Otherwise, the network uses a CPU (requires MATLAB Coder Interface for deep learning Libraries). You can also specify the execution environment by using 'ExecutionEnvironment' name-value of trainingOptions.

netTransfer = trainNetwork(augindsTrain, Igraph, options);

## Create Target Object

Use the dlhdTarget class to create a target object with a custom name for your target device to the host computer. Interface options are JTAG and Ethernet. To use JTAG, Install Xilinx Vivado™ Design Suite 2019.2. To set the Xilinx Vivado toolpath, enter:

```matlab
$ dlhdtoolpath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin')
target = dlhd.Target('Xilinx', 'Interface', 'Ethernet');
```

## Create Workflow Object

Use the dlhd.Workflow class to create an object. When you create the object, specify the network and the bitstream name. Specify the pretrained alexnet neural network as network. Make sure that the bitstream matches the data type and the FPGA board that you are targeting. In this example, the FPGA board is the Xilinx ZCU102 SoC board. The bitstream uses a single data type.

```matlab
hw = dlhd.Workflow('Network', netTransfer, 'Bitstream', 'zcu102_single', 'Target', hTarget);
```
