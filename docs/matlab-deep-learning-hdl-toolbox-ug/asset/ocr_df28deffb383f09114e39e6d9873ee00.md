# Create Target Object

Create a target that has a custom name for your target device and an interface to connect your target device to the host computer. Interface options JTAG and Ethernet.

hTarget = dlhdld.Target('Xilinx', 'Interface', 'Ethernet');

# Create Workflow Object

Create an object of the dlhdld.Workflow class. When you create the class, specify the network and the bitstream. Use the saved pretrained neural network, snet, and the network. Make sure that the bitstream matches the data type of the FPGA you are targeting. In this example the FPGA board is the Xilinx ZCU102 SOC. The board uses a custom data type.

```
hw = dlhdld.Workflow('network', snet, 'Bitstream', 'zcu102_single', 'Target',hTarget);
% If running on Xilinx Z706 board, instead of the above command
% uncomment the command below.
hw = dlhdld.Workflow('Network', snet, 'Bitstream', 'zc706_single', 'Target',hTarget);
```

# Compile the Laneset series Network

To compile the laneset series network, run the function of the dlhdld.Workflow object.

```
dn = hw.compile;
```
