# Deploy Quantized Network Example

This example shows how to train, compile, and deploy a dldl.Workflow object that has quantized Alexnet as the network by using the Deep Learning Toolbox™ Support Package for Xinx FPGA and SoC. Quantization helps reduce the memory requirement of a deep neural network by quantifying weights, biases and activations of network layers to 8-bit scaled integer data types. Use MATLAB™ to retrieve the prediction results from the target device.

# Required Products

For this example, you need:

+   * Deep Learning Toolbox ™
* Deep Learning HDL Toolbox ™
* Deep Learning Model Quantization Library
* Deep Learning HDL Toolbox Support Package for Xinx FPGA and SoC
* MATLAB Coder Interface for Deep Learning Libraries.

# Load Pretrained Series Network

To load the pretrained series network AlexNet,

```
snet = alexnet;
```

To view the layers of the pretrained series network, enter:

```
analyzeNetwork(snet);
```

The first layer, the image input layer, requires input images of size 227-by-227-by-3, where 3 is the number of color channels.

```
inputSize = snet.Layers(1).InputSize;
inputSize = 1x3
227 227 3
```

# Define Training and Validation Data Sets

This example uses the logos dataset. The set consists of 320 images. Create an augmentedImageDatastore to use for training and validation.

```
curDir = pwd;
newDir = fullfile(matlabroot,'examples','deeplearning_shared','data','logos dataset.zip');
copyfile(newDir,curDir,'f');
unzip('logos_dataset.zip');

```

```
imds = imageDatastore('logos dataset', ...
    'IncludeSubFolders',true,
    'LabelSource','foldnames');

[imdsTrain,imdsValidation] = splitEach(imds,'randomized');
```
