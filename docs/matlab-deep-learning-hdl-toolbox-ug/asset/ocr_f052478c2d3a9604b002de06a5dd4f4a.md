# Set up HDL Toolpath

Set up the path to your installed Xilinx™ Vivado™ Design Suite 2019 executable if it is not already set up. For example, to set the toolpath, enter:

```
$ hdsetoolpath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Vivado\2019.2\bin');
```

# Create Target Object

Create a target object for your target device with a vendor name and to connect your target device to the host computer. Interface options are JTAG (default) and Ethernet. Vendor options are Intel or Xilinx. Use the installed Xilinx Vivado Design Suite over an Ethernet connection to program the device.

```
hT = dlhd.target('Xilinx', 'Interface', 'Ethernet');
```

# Create Workflow Object

Create an object of the dlhd.Workflow class. When you create the object, specify the name and the bitstream name. Specify the saved-trained series network, trainedNetNoCar, as the network. Make sure the bitstream matches the data types and the FPGA board you are targeting. In this example, the target FPGA is the Zynq UltraScale+ MPSoC ZCU102 board. The bitstream matches

```
hw = dlhd.Workflow('Network', trainedNetNoCar, 'Bitstream', 'zcu102_single', 'Target', hT);
```
