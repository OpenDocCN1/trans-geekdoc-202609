# Create Target Object

Create a target object for your target device with a vendor name and to connect your target device to the host computer. Interface options are JTAG (default) and Ethernet. # Create Workflow Object

Create an object of dlhd.Workflow class. When you create the object, specify the name and the bitstream. Make sure the bitstream matches the data types and FPGA board. In this example, the target FPGA is the Zynq UltraScale+ MPSOC CU102 board.

```matlab
hw = dlhd.Workflow('Network', trainedNetNoCar, 'Bitstream', 'zcu102', 'Target', hT);
```
