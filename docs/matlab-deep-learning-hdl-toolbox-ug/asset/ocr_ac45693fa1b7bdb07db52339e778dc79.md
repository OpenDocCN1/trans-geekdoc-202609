# Vehicle Detection YOLO v2 Deployed to FPGA

This example shows how to train and deploy a look only once (YOLO) v2 object detector.

Deep learning is a powerful learning technique that you can use to train robust object detectors. Several techniques for object detection exist, including Faster-CNN and you only look (YOLO) v2. This example trains a YOLO v2 detector using the trainYOLOV2bObjectDetector function.

# Load Dataset

This example uses a small vehicle dataset that contains 295 images. Many of these images come from the Caltech Cars 1999 and 2001 data sets, available at the Caltech Computational website, created by Pietro Persona and with permission. Each image contains one or two labeled instances of a vehicle. A small dataset is useful for exploring the YOLO v2 training procedure, but in practice, more labeled images are needed to train a robust detector. Unzip the images and load the vehicle ground truth.

```
unzip vehicleDataset.zip
data = load(vehicleDatasetGroundTruth.mat');
vehicleDataset = data.vehicleDataset;
```

The vehicle data is stored in a two-column table, where the first column contains the image file paths and the second column contains the vehicle bounding boxes.

```
% Add the path to the local data folder.
vehicleDataset.imageFilename = fullfile(pwd,vehicleDataset.imageFilename);
```

Split the dataset into training and test sets. Select 60% of the data for training and the rest for testing the detector.

```
rng = randperm(height(vehicleDataset));
shuffledIndices = rng;
idx = floor(0.6 * length(shuffledIndices));
trainingDataTbl = vehicleDataset(shuffledIndices(1:idx),:);
testDataTbl = vehicleDataset(shuffledIndices(idx+1:end),:);
```

Use imageDataset and boxLabelDataset to create datastores for loading the image and label during training and evaluation.

```
imdsTrain = imageDataset(trainingDataTbl:,,'imageFilename');
bldsTrain = boxLabelDataset(trainingDataTbl:,,'vehicle');
```

```
imdsTest = imageDataset(testDataTbl:,,'imageFilename');
bldsTest = boxLabelDataset(testDataTbl:,,'vehicle');
```

Combine image and label datastores.

```
trainingData = combine(imdsTrain,bldsTrain);
testData = combine(imdsTest,bldsTest);
```
