# Quantize Network for FPGA Deployment

This example shows how to quant learnable parameters in the convolution layers of a neural network, and validate the quantized network. Rapidly prototype the quantized network by using MATLAB simulation or an FPGA. For this example, you need:

- Deep Learning Toolbox™
- Deep Learning HDL Toolbox
- Deep Learning Model Quantization Library
- Deep Learning HDL Support Package for FPGA and SoC Devices
- MATLAB Interface for Deep Learning Libraries.

# Load Pretrained Network

To load the pretrained AlexNet network and analyze the architecture:

```matlab
snet = getNetwork;
analyzeNetwork(snet)
```

# Define Calibration and Validation Sets

This example uses the latest dataset. The data set consists of 320 images. Each image is 227-by-227 in size and has three channels (RGB). Create an augmented datastore to use for calibration and validation. Expedite calibration and validation by reducing the data set to 20 images. The MATLAB simulation workflow has a maximum limit of five images when validating the quantized network. The FPGA validation workflow has a maximum limit of five images when validating the quantized network. Reduce the validation data to a single image.

```matlab
curDir = pwd;
newDir = fullfile(matlab,'examples','deeplearning_shared','data','alex_dataset.zip');
copyfile(newDir,curDir,'f');
unzip('dataset.zip');
imageData = datastore('FileExtensions','*.JPG','LabelSource','foldern');
calibrationData,validationData = split(imageData,0.5,randomize);
validationDataReduced = validationData.subset(20);
validationDataSimulation = validationData.subset(1);
```

# Create Quantized Network Object

Create a dlquantizer object and specify the network to quantify. Specify the execution environment for FPGA for one object. Use the MATLAB simulation on the second dlquantizer object:

```matlab
dQuantObj_simulation = dlquantizer(net,'ExecutionEnvironment','FPGA','Simulation','on');
dQuantObj_FPGA = dlquantizer(net,'ExecutionEnvironment','FPGA');
```

# Calibrate Quantized Network

Use the calibrate function to exercise the network with sample inputs and collect the range information. The calibrate function exercises the network and collects the dynamic ranges of the weights and biases. The calibrate function returns a table. Each row of the table contains information for a learned parameter of the quantized network.

```matlab
dQuantObj_simulation.calibrate(calibrationData_reduced)
```
