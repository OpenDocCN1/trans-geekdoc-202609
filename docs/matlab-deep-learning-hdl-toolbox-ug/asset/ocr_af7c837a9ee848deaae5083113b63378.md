# Create Target Object

Use the dhdl.Target to create a target object with a custom name for your target device and an interface to connect your target device to the host computer. Interface options are JTAG and Ethernet. Use to JTAG, Install Xilinx™ Vivado Design Suite 2019.2. To set the Xilinx Vivado toolpath, enter:

```
% dhdlsetuppath('TargetName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.exe')
```

```
hTarget = dhdl.Target('Xilinx', 'Interface', 'Ethernet');
```

# Create Workflow Object

Use the dhdl.Workflow to create an object. When you create the object, specify the network and the bitstream. Save the pretrained neural network as a network. Make sure the bitstream matches the data types and the FPGA board you are targeting. In this example, the FPGA board is the Xilinx ZCU102 SoC board. The bitstream uses a single type

```
hw = dhdl.Workflow('Network', trainedSN, 'Bitstream', 'zcu102_single', 'Target',hTarget)
hw =
```

Workflow with properties:

```
Network: [1x DAGNetwork]
Bitstream: 'zcu102_single'
ProcessorConfig: []
Target: [1x dhdl.Target]
```

# Compile the Modified SqueezeNet DAG network

To compile the trainedSN DAG network, run the compile method of the dhdl.Workflow object.

dn = hw.compile
