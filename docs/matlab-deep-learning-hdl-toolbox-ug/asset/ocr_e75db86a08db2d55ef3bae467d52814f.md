# # Deep Learning Processor Map

During custom processor generation, AXI registers are created to enable MATLAB or other master devices to control and progress the deep learning (DL) processor core.

The DL processor IP core is generated using HDL Coder IP core generation workflow. The generated IP core contains a standard set of registers. For more information, see "Custom IP Generation" (HDL Coder).

For the list of register offsets, see the Register Address Mapping table in the generated deep learning (DL) processor core.
