# Program the Bitstream onto FPGA and Deploy Network Weights

To deploy the network on the Zynq UltraScale+ MPSOC CU102 hardware, run the deploy function of dhdl.Workflow object. This function uses the output of the compile function to program the FPGA board by using the programming file.The function also downloads the network weights and biases. The deploy function uses the Xilinx Vivado tool and the supported tool version starts programming the FPGA device using the bitstream, displays messages and the time it takes to deploy the network.

```
hw.deploy;
```
