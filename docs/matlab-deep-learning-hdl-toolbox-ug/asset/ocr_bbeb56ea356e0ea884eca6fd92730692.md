# Identify and Display the Bottle Neck Layer

Remove the NumFrames, Total latency, and Frames/s from the profiler's results table. This includes removing the module level and network profiler results. Retain only the network layer profiler objects. The bottle neck layer identified display the bottleneck layer index, time, and information.

```
speed('Network',:) = {};nspeed(' conv_module',:) = [];
speed(' fc_module',:) = [];
speed = removefields(speed, {'NumFrames','Total Latency(cycles)','Frame/s'});
```

```
% then sort the profiler's results in descending order
sortrows(speed, 'Latency(cycles)','descend');
```

```
% the first row in the profile table is the bottleneck layer. Thus the
following
layerSpeed = speed(1);
layerName = strip(layerSpeed.Properties.RowNames{1},'');
for idx = 1:length(snet.Layers)
curLayer = snet.Layers(idx)
if strcm(curLayer.Name, layerName)
bleneckLayer = curLayer;
break;
```
