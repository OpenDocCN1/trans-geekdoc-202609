# Calibrate the Quantized Object

Use the calibrate function to exercise the network with sample inputs and collect the range information. The calibrate function exercises the layers and collects the dynamic ranges of the weights and biases in the convolution and fully connected layers of the dynamic ranges of the activations in all layers of the network. The calibrate function returns a table. Each row of the table contains range information for a learnable parameter of the quantized network.

```
dquantobj.calibrate(augTrain5)
```

# Create Target Object

Use the dhdl.Target to create a target object with a custom name for your target device and an interface to connect your target device to the host computer. Interface options are JTAG and Ethernet. Use JTAG,XInstall Vivado™ Design 2019.2. To set the Xilinx Vivado object,:

```
# hdsettooltip('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.')
hTarget = dhdl.Target('Xilinx', 'Interface', 'Ethernet');
```

Use the dhdl.Workflow to create an object. When you create the object, specify the network and the bitstream name. Specify the saved pretrained neural network as the network. Make sure that the bitstream name matches the data type and the FPGA you are targeting. In this example, the FPGA board is the Xilinx ZCU102 SoC board. The bitstream uses a single data type.

```
hw = dhdl.Workflow('Network', dquantobj, 'Bitstream', 'zcu102 int8', 'Target', hTarget);
```
