Load an image from the attached testImages, resize the image to match the network image input dimensions, and the run function of the dhdll.Workflow to retrieve and display the defect from the FPGA.

```matlab
wi = uint32(320)
he = uint32(240)

img=imread(filename)
img = imresize(img, wi)

```

```matlab
% Extract ROI for preprocessing
[Iori, imgPacked, num, bbox] = myNDet_Preprocessing(img)

% row-major = column-major conversion
imgPacked2 = zeros([128,128,4],'uint8');
for c = 1:4
  for i = 1:128
    for j = 1:128
      imgPacked2(i,j,c) = imgPacked(i-1)*128 + (j-1) + (c-1)*128*128
    end
  end
```

```matlab
% Classify detected nodes using CNN
scores = zeros(2,4)
for i = 1:num
  [scores(:,i), speed] = HW.predict(imgPacked2(:,:,i)),'Profile','on')
  end
```

## Create Workflow Object for trainedBlemDet Network

Create an object of the dhdll.Workflow class. When you create the object, specify the network and the bitstream name. Specify the saved pretrained trainedBlemDetNet as the network. Make sure that the bitstream matches the data type and the FPGA board that you are targeting. In this example target FPGA board is the Xilinx ZCU102 SOC board. The bitstream uses a single data type.

```matlab
hW = dhdl.Workflow('Network','snet_blemdetnet','Bitstream','zcu102_single','Target',hT)
```

```

```
