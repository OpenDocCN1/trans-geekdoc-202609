# Program Bitstream onto FPGA and Download Network Weights

To deploy the network on Xilinx ZCU102 hardware, run the deploy function of the dldld.Workflow. This function uses the output of the compile function to program the FPGA board by using the programming file. It also downloads the network weights and biases. The deploy function starts programming the FPGA device, displays progress messages, and the time it takes to deploy the network.

```
hw.deploy

### FPGA bitstream programming has been skipped as the same bitstream is already loaded on the t
### Deep learning network programming has been skipped as the same network is already loaded on on
```
