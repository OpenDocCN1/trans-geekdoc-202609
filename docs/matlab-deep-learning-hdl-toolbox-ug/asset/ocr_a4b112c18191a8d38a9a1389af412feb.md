# Get Started with Deep Learning FPGA Deployment on Intel Arria 10 SoC

This example shows how to create, compile, and deploy a dhldl.Workflow object that has a handwritten character detection series network object using the Deep Learning HDL Toolbox Support Package for Intel FPGA and SoC. Use MATLAB® to retrieve the prediction results from the target device.

# Prerequisites

+   - Intel Arria™ 10 SoC development kit
- Deep Learning HDL Toolbox™ Support Package for Intel FPGA and SoC
- Deep Learning HDL Toolbox™
- Deep Learning Toolbox™

# Load the Pretrained SeriesNetwork

To load the pretrained series network, that has been trained on the Modified National Institute Standards of Technology (MNIST) database, enter:

```
snet = getDigitsNetwork();
```

To view the layers of the pretrained series network, enter:

```
analyzeNetwork(snet)
```

# Create Target Object

Create a target object with a custom name for your target device and an interface to connect your target device to the host computer. Interface uses JTAG and Ethernet. To use JTAG, install Intel Quartus™ Prime Standard Edition 18.1. Set the path to your installed Intel Quartus Prime executable if it is not already set. For example, to set the toolpath:

```
% hsettoolpath('TargetName', 'Altera Quartus II', 'ToolPath', 'C:\altera\18.1\quartus\bin64');
hTarget = dlhl.Target('Intel')
hTarget =
    Target with properties:
    Vendor: 'Intel'
    Interface: JTAG
```

# Create Workflow Object

Create an object of the dhldl.Workflow class. When you create the object, specify the network and the bitstream. Save the pretrained MNIST neural network, snet, as the network. Make sure that the bitstream name matches the data type and the FPGA board you are targeting. In this example, the target FPGA is the Intel Arria 10 SoC and the bitstream uses a single data type.

```
hW = dhldl.Workflow('network', 'Bitstream', 'arrival1@soc_single', 'Target',hTarget)
```
