# Investigate Activations in Specific Channels

Each tile in the activations grid is the output of a channel in the maxpool_1 layer. White pixels represent strong positive activations and black pixels represent strong negative activations. A channel that is mostly gray does not activate as strongly as the input image. The position of a pixel in the activation of a channel corresponds to the same position in the original image. A white pixel at a location in a channel indicates that the channel is strongly activated at that.

Resize the activations in channel 33 to be the same size as the original image and display the activations.

```
actl33 = actl(:,:,:,22);
actlch33 = mat2gray(actlch33);
actlch33 = imresize(actlch33,imgSize);
```

```
I = imtile({{im,actlch33}});
imshow(I)
```

# Find Strongest Activation Channel

Find interesting channels by programmatically investigating channels with large activations. Find the channel that has the largest activation by using the max function, resize the channel output, and display the activations.

```
[maxValue,Index] = max(max(max(actl)));
actlchMax = actl(:,:,:,maxValue);
actlchMax = mat2gray(actlchMax);
actlchMax = imresize(actlchMax,imgSize);
```

```
I = imtile({{im,actlchMax}});
imshow(I)
```
