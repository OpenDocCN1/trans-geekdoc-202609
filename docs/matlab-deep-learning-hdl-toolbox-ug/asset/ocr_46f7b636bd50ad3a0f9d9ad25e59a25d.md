# Replace Final Layers

The last three layers of the pretrained network are configured for 1000 classes. These three layers must be fine-tuned for the new classification problem. Extract all the last layers, except the last three, from the pretrained network.

```
layersTransfer = snet.Layers(1:end-3);
```

Transfer the layers to the new classification task by replacing the last three layers with a fully connected layer, a softmax layer, and a classification output layer. Set the fully connected layer to have the same size as the number of classes in the data.

```
numClasses = numel(categories(indsTrain.Labels));
```

```
numClasses = 32
layers = [
    layersTransfer
    fullyConnectedLayer(numClasses,'WeightLearnRateFactor',20,'BiasLearnRateFactor',20)
    softmaxLayer
    classificationLayer];
```

# Train Network

The network requires input images of size 227-by-227-by-3, but the images in the image datastore have different sizes. Use an augmented datastore to automatically resize the training images. Specify additional augmentation operations to perform on the training images, such as randomly flipping the images along the vertical axis and translating them up to 30 pixels horizontally and vertically. Data augmentation helps prevent the network from overfitting and extracting details of the training images.

```
pixelRange = [-30 30];
imageAugmenter = imageDataAugmenter(
    RandReflection,'true',
    RandXdTranslation',pixelRange,
    RandYTranslation',pixelRange);
imgdsTrain = augmentedImageDataStore(inputSize(1:2),imgdsTrain,
    'DataAugmentation',imageAugmenter);
```

To automatically resize the images without performing further data augmentation, use an augmented image datastore without specifying any additional preprocessing operations.

```
imgdsValidation = augmentedImageDataStore(inputSize(1.2),imgdsValidation);
```

Specify the training options. For transfer learning, keep the features from the early layers of the pretrained network (the transferred layers). To slow down learning in the transferred layers, set the initial learning rate to a small value. Specify the mini-batch size and validation data. The software validates the network every Validation iterations during training.

```
options = trainingOptions('sgd',
    'MinBatchSize',10,
    'MaxEpochs',6,
    'InitialLearnRate',1e-4,
    'Shuffle','every-epoch', ...);
```
