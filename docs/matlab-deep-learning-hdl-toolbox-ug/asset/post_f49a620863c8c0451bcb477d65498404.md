## Deploy Deep Learning Network to FPGA

Before deploying a network, you must first establish a connection to the FPGA board. The dhdl1.Target object represents this connection between the host computer and the FPGA. Create two target objects, one connection through the JTAG interface and one for connection through the Ethernet interface. To use the JTAG connection, install Xilinx™ Vivado™ Design Suite 2019.2 and set the path to your installed Xilinx Vivado executable if it is not already set up.

```matlab
% hdlsettooltipath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.exe')
hTargetJAG = dhdl1.Target('Xilinx', 'Interface', 'JTAG')
```

To deploy the network, assign the target object to the dhdl1.Workflow object and execute the deploy method. The deployment happens in two stages. First, the bitstream is programmed onto the FPGA. Then, the network is transferred to the onboard memory.

Select the JTAG interface and time the operation. This operation may take several minutes.

Changing from JTAG to the deploy function reprograms the bitstream, which accounts for most of the elapsed time. Reprogramming is due to different methods that are used to program the bitstream for different hardware interfaces. The Ethernet interface configures the ARM processor and uses a persistent programming method so that the bitstream is reprogrammed each time.

## Create Network for Quantization

This example shows how to fine-tune a pretrained AlexNet for classification. AlexNet is trained on over million images and can classify images into many categories. As a result, the model has learned features for a wide range.

## Load Training Data

Unzip and load the image datastore.

```matlab
unzip('dataset.zip');
```

```matlab
imds = imageastore('dataset', 'IncludeSubfolders', true, 'LabelSource', 'fold');
```

Divide the data into training and validation sets. Use 70% of the images for training and 30% for validation.

```matlab
[imdsTrain, imdsValidation] = splitEachLabel(imds,0.7,'random');
```

## Load Pretrained Network

Load the pretrained AlexNet network. If Deep Learning Toolbox Model for AlexNet is not installed, the software provides a download link. AlexNet is trained on over million images and can classify images into 1000 classes, such as keyboard, mouse, and many animals.

```matlab
snet = alexnet;
```

Use analyzeNetwork to display an interactive visualization of the network architecture and detailed information about the network layers.

```matlab
analyzeNetwork(snet)
```

## Input Layer

The first layer, of input layer, requires inputs of size 227-227-by-3, where 3 is the number of color channels.

```matlab
inputSize = snet.Layers(1).InputSize

inputSize = I×3

227     227     3
```

## Replace Layers

The last three layers of the pretrained network are configured for 100 classes. These three layers must be fine-tuned for the classification problem. All layers, except the last three, from the pretrained network.

```matlab
LayersTransfer = snet.Layers(1:end);
```

Transfer the layers to the new classification task by replacing the last three layers with a fully connected layer, a softmax layer, and a classification output layer. Specify the size of new fully connected layer according to the new data. Set the fully connected to have the same size as the number of classes in the new data. To learn faster in the new layers than the transferred layers, increase the LearnRateFactor and BiasRateFactor of the fully connected layer.

```matlab
numClasses = numel(categories(imdsTrain.Labels))
```
