To deploy the neural network on the FPGA board, create a dhlwl.Workflow object that has the pretrained network snet as the network and the bitstream for your FPGA board. This example uses the bitstream 'zcu102_single' which has single data type and is configured for the ZCU102 board. To run this example on a different board, use the bitstream

```
hw = dhlwl.Workflow('Network', snet, 'Bitstream', 'zcu102_single');
```

Compile the artwork for deployment to the FPGA.

```
hw.compile:
```
