# Replace Layers

The fully connected and classification layer of the pretrained network are not configured for 1000 classes. These two layers fc1000 and ClassificationLayer_predictions for ResNet-18, contain information on how to combine the features that the network extracts into class probabilities and predicted labels. These two layers must be fine-tuned for the new classification problem. Except all layers, the last two, from the pretrained network.

```mat
lgraph = LayerGraph(snet)
lgraph = LayerGraphWithProperties(
Layers: {[71x1 nnet.cnn.Layer]}
Connections: {[78x2 table]}
InputNames:{data'}
OutputNames:{ClassificationLayer_predictions})
```

numClasses = num(category(classes))

```mat
newLearnableLayer = fullyConnectedLayer(numClasses,
'Name','new fc',

lgraph = replaceLayer(lgraph, 'fc1000',newLearnableLayer)
newLayer = classificationLayer('Name','new.classout')
lgraph = replaceLayer(lgraph,'ClassificationLayer_predictions',newLayer);
```

# Train Network

The network requires input images of size 224-by-22-by-3, but the images have different sizes. Use an augmented image datastore to automatically resize the training images. Specify additional augmentation operations to perform on the training images, such as randomly flipping the images along the vertical axis and randomly translating them up to 30 pixels horizontally and vertically. Data augmentation helps prevent the network from overfitting and memorizing the exact details of the training images.

```mat
pixelRange = [-30 30];
imageAugmenter = augmenter('RandReflection',true,
'RandTranslation',pixelRange,
'RandRotation',pixelRange);
```

To automatically resize the validation images without performing further data augmentation, use an augmented image datastore without specifying any preprocessing operations.

```mat
augdsTrain = augmentedImageDatastore(inputSize(2),imdsTrain, ...
'DataAugmentation',imageAugmenter);
augdsValidation = augmentedImageDatastore(inputSize(2),imdsValidation);
```

# Classify Images on an FPGA Using a Quantized DAG Network

Select the training options. For transfer learning, keep the features from the early layers of the pretrained network (the transferred weights). To slow down learning in the transferred layers, set the initial learning rate to a small value. Specify the mini-batch size and validation data. The software validates the network every Frequency during training.

```mat
options = trainingOptions('sgdm',
  'MiniBatchSize',10,
  'MaxEpochs',6,
  'InitialLearnRate',1e-4,
  'Shuffle','every-epoch',
  'ValidationData',augmentsValidation,
  'ValidationFrequency',3,
  'Verbose',false,
  'Plots','training-progress')
```

Train the network that connects the transferred and new layers. By default, trainNetwork uses a GPU if one is available (Parallel Computing Toolbox) and a supported GPU device. For more information, see “GPU Support by Release” (Parallel Computing Toolbox). Otherwise, the network can also specify the execution environment by using the 'ExecutionEnvironment' name-value argument of trainOptions.

```mat
netTransfer = trainNetwork(augmentsTrain,Lgraph,options)
```

# Create Target Object

Use dhdl.Target to create a target object with a custom name for your target device and an interface to connect your target device to the host computer. Interface options are JTAG and Ethernet. To set the Xilinx Vivado object, use:

```mat
hTarget = dhdl.Target('ToolName', 'Xilinx', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.', 'Interface', 'Ethernet');
```

Use dl.Workflow to create an object. When you create the object, specify the network and the bitstream name. Make sure that the bitstream name matches the data type and FPGA you are targeting. In this example, the FPGA board is the Xilinx ZCU102. The bitstream uses a single data type.

```mat
hw = dl.Workflow('Network', dquantobj, 'Bitstream', 'zcu102int8', 'Target', hTarget);
```

To compile the netTransfer DAG network, use compile method of dl.Workflow object. You can optionally specify the maximum number of input frames.

```mat
dn = hw.compile('InputFrameLimit');
```
