# Program the Bitstream from FPGA and Download Network Weights

To deploy the network on the Zynq UltraScale+ MPSoC ZCU102 hardware, run the deploy function of the dhldl.workflow. This function uses the output of the compile function to program the FPGA board by using the programming file.The function also downloads the network weights and biases. The deploy function for the Xilinx Vivado tool and the supported tool version. It then starts the FPGA device by using the bitstream, displays messages and the time it takes to deploy the network.

```
hw.deploy
```
