
# Classify ECG Signals Using DAG Network Deployed To FPGA

Unzip ECGData.zip in physionet-ECG data-master. Load the data file into your MATLAB workspace.

```matlab
unzip(fullfile(tempdir, 'physionet ECG data-master','ECGData.zip'),..
    fullfile(tempdir, 'physionet ECG data-master'))
load(fullfile(tempdir, 'physionet ECG data-master','ECGData.mat'))
```

ECGData is a structure array with two fields: Data and Labels. The Data field is a 162-65536 matrix where each row is an ECG recording sampled at 128 herz. Labels are for each row of Data. The three diagnostic categories are: 'ARR', 'CHF', 'NSR'.

To store the preprocessed data of each category, create an ECG data directory dataDir inside tempdir. Then create subdirectories in 'data' named after each ECG category. The helper function helperCreateECGdirectories does this. helperCreateECGdirectories accepts ECGData, the name of an ECG data directory, and the name of a parent directory as input arguments. You can replace tempdir with another directory where you have permission. You can find the source code for this helper function in the Supporting Functions section at the end of this example.

```matlab
%parentDir = tempdir;
parentDir = pwd;
dataDir = 'data';
helperCreateECGdirectories(ECGData,parentDir,dataDir)
```

Plot a representative of each ECG category. The helper function helperPlotReps accepts ECGData as input. You can find the source code for this helper function in the Supporting Functions section at the end of this example.

```matlab
helperPlotReps(ECGData)
```

### ### Create Time-Frequency Representations

After making the folders, create time-frequency representations of the ECG signals. These representations are called scalograms. A scalogram is the absolute value of the CWT coefficients of a signal.

To create the scalograms, precompute a CWT filter bank. Precomputing the CWT filter bank is the preferred method when using the CWT of many signals using the same parameters.

Before generating the scalograms, examine one of them. Create a CWT filter bank using cfilterbank for a signal with 1000 samples. Use the filter bank to take the CWT of the first 1000 samples of the signal and obtain the scalogram from the coefficients.

```matlab
Fs = 120;
fb = cfilterbank('Signallength',1000,...
    'SamplingFrequency',Fs,...
    'VoicesPerOctave',12);
sig = ECGData.Data(1:1000);
[cfs,frq] = wt(fb,sig);
t = (0:999)/Fs;figure;pcolor(t,frq,abs(cfs))
set(gca,'yscale','log');shading,interp;axis tight
title('Scalogram');xlabel('Time (s)');ylabel('Frequency (Hz)')
```

# Divide into Training and Validation Data

Load the scalogram as an image datastore. The imageDatastore function automatically labels the images by folder names and stores the data as an imageDatastore object. An image datastore enables you to store large image, including data that does not fit in memory, and efficiently reads batches of images during training of a CNN.

```matlab
allImages = imageDatastore(fullfile(parentDir,dataDir),..
    'IncludeSubfolders',true,
    'LabelSource','foldnames');
```

Randomly divide the images into two groups, one for training and the other for validation. Use 80% of the images for training, and the remainder for validation. For reproducibility, set the random seed to the default value.

```matlab
rng default
[imgsTrain,imgsValidation] = splitEachLabel(allImages,0.8);
disp(['Number of training images: ',num2str(numel(imgsTrain.Files))]);
disp(['Number of validation images: ',num2str(numel(imgsValidation.Files))]);
```

# SqueezeNet

SqueezeNet is a deep CNN whose architecture supports images of size 227-by-227-3. Even though the image dimensions are different for GoogleLeNet, you do not have to generate new RGB images at SqueezeNet dimensions. You can use the original RGB images.

Load a custom SqueezeNet neural network.

```matlab
sqz = squeezeet;
```

Extract the graph from the network. Confirm SqueezeNet has fewer layers than GoogleLeNet.

```matlab
graphSqz = layerGraph(sqz);
disp('Number of Layers: ',num2str(numel(graphSqz.Layers)));
disp(graphSqz.Layers(end).InputSize)
```

# Modify SqueezeNet Parameters

To retain SqueezeNet to classify new images, make changes similar to those for GoogleLeNet. Inspect the last six network layers.

```matlab
graphSqz.Layers(end-5:end)
```

ans =
| 'new dropout' | Dropout | 60% dropout |
| 'new conv' | Convolution | 1x1 convolutions with stride [1 1] |
| 'relu_conv10' | ReLU | ReLU |
| 'pool10' | Global Average Pooling | Global average pooling |
| 'prob' | Softmax | softmax |
| 'newclassout' | Classification Output | | |

Replace the 'dropout' layer, the last dropout layer in the network, with a dropout layer of probability 0.6.

```matlab
tmpLayer = graphSqz.Layers(end);
newDropoutLayer = dropoutLayer(0.6,'Name','new dropout');
graphSqz = replaceLayer(graphSqz,tmpLayer.Name,newDropoutLayer);
```

Unlike GoogleLeNet, the learnable layer in SqueezeNet is a 1-by-1 convolutional layer, 'conv10', and not fully connected. Replace 'conv10' with a new convolutional layer with a number of filters equal to the number of classes. As done with GoogleLeNet, increase the learning rate of the new layer.

```matlab
numClasses = numel(categories(imgsTrain.Labels));
tmpLayer = graphSqz.Layers(end-4);
```

# Prepare Data for SqueezeNet

The RGB images have dimensions appropriate for the GoogleNet architecture. Create augmented image datastores that automatically resize the existing RGB images for the SqueezeNet architecture. For more information, see augmentedImageDatastore.

```matlab
augimsTrain = augmentedImageDatastore({227 227},imgsTrain);
augimsValidation = augmentedImageDatastore({227 227},imgsValidation);
```

# Set Training Options and Train SqueezeNet

Create a set of training options to use SqueezeNet. Set the random to the default value and train the network. The training process usually takes 1-5 minutes on a desktop CPU.

```matlab
ilr = 3e-4;
miniBatchSize = 10;
maxEpochs = 15;
valFreq = floor(numel(augimsTrain.Files)/miniBatchSize);
opts = trainingOptions('sgdm',
'MiniBatchSize',miniBatchSize,
'MaxEpochs',maxEpochs,
'InitialLearnRate',ilr,
'ValidationData',augimsValidation,
'ValidationFrequency',valFreq,
'Verbose',1,
'ExecutionEnvironment','cpu',
'Plots','training-progress');
```

```matlab
rng default
trainedSN = trainNetwork(augimsTrain,graphSqz,opts);
```
