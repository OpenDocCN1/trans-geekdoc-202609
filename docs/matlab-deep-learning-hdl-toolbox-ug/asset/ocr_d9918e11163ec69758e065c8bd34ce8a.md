# Create Target Object

Create a target object with a name for your target device and an interface to connect your target device to the host computer. Use JTAG and Ethernet. To use FPGA, install Xilinx™ Vivado Design Suite 2020.1. To set the Xilinx Vivado toolpath, enter:

```
% setuppath('ToolName','Xilinx Vivado','ToolPath','C:\Xilinx\Vivado\n2020.1\bin\vivado.bat');
```

To the target object, enter:

```
hTarget = dlhdld.Target('Xilinx','Interface','Ethernet');
```

Alternatively, you can use the JTAG interface.

```
% hTarget = dlhdld.Target('Xilinx','Interface','JTAG');
```

# Create DlQuantizationOptions Object

Create a dlQuantizationOptions object. Specify the target bitstream and target board interface. The default metric function is a Top-1 accuracy metric function.

```
options_FPGA = dlquantizationOptions('Bitstream','zcu102_int8','Target',hTarget);
options_simulation = dlquantizationOptions;
```

To use a custom metric, specify the metric function in the dlquantizationOptions object.

```
% options_FPGA = dlquantizationOptions('MetricFcn',(x)xComputeAccuracy(x,s,validationData);
% options_simulation = dlquantizationOptions('MetricFcn',(x)xComputeAccuracy(x,s,validationData);
```
