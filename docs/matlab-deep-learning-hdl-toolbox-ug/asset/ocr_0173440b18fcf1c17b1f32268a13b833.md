# Train Network

The network requires images of size 224-by-224-by-3, but the images in the image datastores have different sizes. Use an augmented image datastore to automatically resize the images. Specify additional augmentation operations to perform on the training images, such as randomly flipping the images along the vertical axis and translating them up to 30 pixels horizontally and vertically. Data augmentation helps prevent the network from overfitting and memorizing the details of the training images.

```
pixelRange = [-30 30]
imageAugmenter = imageDataAugmenter(
'RandReflection',true, ...
'RandTranslation',pixelRange, ...
'RandTranslation',pixelRange)
```

To automatically resize the validation images without performing further data augmentation, use an augmented image datastore specifying any additional processing operations.
augindsTrain = augmentedImageDatastore(InputSize(1:2),imdsTrain, ...
'DataAugmentation',imageAugmenter)
augsValidation = augmentedImageDatastore(InputSize(1:2),imdsValidation)

Specify the training options. For transfer learning, keep the features from the early layers of the pretrained network (the transferred layers). To slow down learning in the transferred layers, set the initial learning rate to a small value. Specify the min-batch size and validation data. The software validates ValidationFrequency iterations during training.

```
options = trainingOptions('sgdm', ...
'MiniBatchSize',6, ...
'MaxEpochs',10,le-4, ...
'Shuffle','every-epoch',augsValidation, ...
'ValidationFrequency',3, ...
'Verbose',false, ...
'Plots','training-progress');
```

Train the network that consists of the transferred and new layers. By default, trainNetwork uses a GPU if one is available (Parallel Computing Toolbox™ and a supported GPU device.)
