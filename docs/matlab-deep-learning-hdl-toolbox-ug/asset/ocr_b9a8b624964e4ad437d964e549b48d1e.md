# Create Bitstream Configuration

To create a processor configuration, use the dlhdl.ProcessorConfig. For more information, use dlhdl.ProcessorConfig. To learn about modifiable parameters of the processor configuration, use getModuleProperty and setModuleProperty.

To reduce the use of custom bitstream, modify the KernelDataType for the conv, fc, and adder modules. Modify the ConvThreadNumber to reduce DSP slice count. Reduce the InputMemorySize and OutputMemorySize for the conv module to reduce BAM count.

```
hPC_custom = dlhdl.ProcessorConfig;
hPC_custom.setModuleProperty('conv', 'KernelDataType', 'int8');
```
