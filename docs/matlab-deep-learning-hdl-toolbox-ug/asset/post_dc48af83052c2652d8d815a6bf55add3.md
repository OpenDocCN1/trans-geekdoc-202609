# Create Target Object

Create a target for your target device and an interface to connect your target device to your computer. Interface options are JTAG (default) and Ethernet. Vendor options are Intel or Xilinx. Use the installed Xilinx Vivado Design Suite or an Ethernet connection to program the device.

```mat
hTarget = dhldl.Target('Xilinx', 'Interface', 'Ethernet');
```

# Create Workflow Object

Create an object of the dhldl.Workflow class. When you create it, specify the name and the bitstream name. Specify the saved pre-trained series network, trainedNetCoCar, as the network. Make sure the bitstream name matches the data type and the FPGA board that you are targeting. In this example, the target FPGA board is the Zynq UltraScale+ MPSoC ZCU102 board. The bitstream uses a single data type.

```mat
hW=dhldl.Workflow('Network', snet, 'Bitstream', 'zcu102_single', 'Target', hTarget)
```

# Custom Learning Processor Generation to Meet Performance Requirements

This example shows how to create a custom processor configuration and estimate the performance of a pretrained network. You can then modify parameters of the custom configuration and re-estimate the performance. Once you have achieved your performance requirements you can generate a custom bitstream using the custom processor configuration.

# Load Pretrained Series Network

To load the pretrained series network LogoNet, enter:

```mat
snet = getLogoNetwork();
```
