The profiler returns these parameters and their values:

+   - **LastLatency(cycles)**: Total number of clock cycles for previous frame execution.
- **Clock frequency**: Clock frequency information is retrieved from the bitstream that was used to deploy the network to the target board. For example, the profiler returns * The clock **frequency** of the DL processor is `220MHz`. The clock frequency of 220 MHz is retrieved from the zcu102 bitstream.
- **LastLatency(seconds)**: Total number of seconds for previous frame execution. The time is calculated as `LastLatency(cycles)/Clock Frequency`. For example the `conv_module LastLatency(seconds)` is calculated as `2242115/(220*10^6)`.
- **FramesNum**: Total input of frames to the network. This value will be used in the calculation of Frames/s.
- **Total Latency**: Total number of clock cycles to execute all the network layers and modules for FramesNum.
- **Frames/s**: Number of frames processed in one second by the network. Total Frames/s in the example is calculated as `(1*220*10^6)/2369630`.
