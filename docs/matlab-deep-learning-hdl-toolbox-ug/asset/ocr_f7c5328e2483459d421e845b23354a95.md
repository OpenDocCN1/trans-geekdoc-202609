# Vehicle Detection DAG Network Based YOLO v2 Deployed to FPGA

This example shows how to train and deploy a you only once (YOLO) v2 object detector.

Deep learning is a powerful machine learning technique that you can use to train robust object detectors. Several techniques for object detection exist, including Faster R-CNN and you only once (YOLO) v2. This example trains a YOLO v2 vehicle detector using the

trainYOLOv2objectDetector function.

# Load Dataset

This example uses a small vehicle dataset that contains 295 images. Many of these images come from the Caltech Cars 1999 and 2001 datasets, available at the Computational Vision website, created by Pietro Perona and with permission. Each image contains one or two labeled instances of a vehicle. A small dataset is useful for exploring the YOLO v2 training, but in practice, more labeled images are needed to train a robust detector. Unzip the vehicle ground truth data.

```
unzip DatasetImages.zip
data = load('vehicleGroundTruth.mat');
vehicleDataset = data.vehicleDataset;
```

The vehicle data is stored in a two-column table, where the first column contains the image file paths and the second column contains the vehicle bounding boxes.

```
% Add the fullpath to the local data folder.
vehicleDataset.imageFilename = fullfile(pwd,vehicleDataset.imageFilename);
```

Split the dataset into training and test sets. Select 60% of the data for training and the rest for the trained detector.

```
rng(0);
shuffledIndices = randperm(height(vehicleDataset));
idx = floor(0.6 * length(shuffledIndices));
trainingDataTb = vehicleDataset(shuffledIndices(1:idx));
testDataTb = vehicleDataset(shuffledIndices(idx+1:end));
```

Use imageastore and labelastore to create datastores for loading the image and label data during training and evaluation.

```
mdsTrain = imageastore(trainingDataTb(:,,'imageFilename'));
bldsTrain = labelastore(trainingDataTb(:,'vehicle'));
mdsTest = imageastore(testDataTb(:,,'imageFilename'));
bldsTest = labelastore(testDataTb(:,'vehicle'));
```

Combine image and label datastores.

```
trainingData = combine(mdsTrain,bldsTrain);
testData = combine(mdsTest,bldsTest);
```
