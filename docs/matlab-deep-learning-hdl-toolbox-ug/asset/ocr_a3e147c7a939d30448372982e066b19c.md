# Program Bitstream onto FPGA and Download Network Weights

Deploy the network on the Xilinx ZCU102 SoC hardware, run the deploy function of the dl1.workflow object. This function uses the output of the compile function to program the FPGA board by using the programming file. It also deploys the network weights and biases. The deploy function starts programming the FPGA device, displays progress messages, and the time it takes to deploy the network.

hw.deploy


# Run Prediction for One Image

Load an image from the attached images, resize the image to match the network input layer dimensions, and run the prediction from the dl1.workflow object to retrieve and display the defect prediction from the FPGA.

```
wi = uint32(320);
he = uint32(240);
ch = uint32(3);

filename = fullfile(pwd, 'ok1.png');
img=imread(filename);
img = resize(img, [he, wi]);
img = mat2ocv(img);
```
