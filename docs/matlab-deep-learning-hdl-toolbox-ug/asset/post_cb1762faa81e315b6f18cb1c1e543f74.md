# Create dquantizer Object

Create a dquantizer object and specify the network to quantize. Specify the execution environment as FPGA.

```
dlQuantObj = dquantizer(netTransfer, 'ExecutionEnvironment', 'FPGA');
```

# Calibrated Network Quant

The dquantizer object uses calibration data to collect dynamic ranges for the learnable parameters of the convolution and fully connected layers of the network.

For best quantization, the calibration data must be a representative of all inputs predicted by the LogoNet network. Expedite the calibration process by reducing the calibration data set to 20 images.

```matlab
imageData = imageDatastore(fullfile(curDir, 'logos dataset'), ... 
'IncludeSubfolders',true, 'FileExtensions', '.JPG', 'LabelSource', 'folder');
```

```matlab
imageData_reduced = imageData.subset(1:20);
dlQuantObj.calibrate(imageData_reduced)
```

# Create Target Object

Create a target object with a custom name for your target device and to connect to your
target device to the host connector: Interface supports JTAG and Ethernet. To use JTAG, install
Xilinx™ Vivado™ Design Suite 2020.1. To set the Xilinx Vivado toolpath:

```matlab
% hsetuptoolpath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2020.1\bin\vivado.')
```

To create the target object, enter:

```matlab
hTarget = dhldl.Target('Xilinx','Interface','Ethernet');
```

Alternatively, you can use the JTAG interface.

```matlab
% hTarget = dhldl.Target('Xilinx', 'Interface', 'JTAG');
```

# Create Workflow Object

Create an object of the dhldl.workflow class. When you create the class, an instance of
dligquantizer object, the bitstream name, and target information are specified. Specify
dlQuantObj as network. Make sure that the bitstream name matches the data type and the
FPGA board that you are targeting. In this example, the target FPGA board is the Xilinx ZCU102 SOC
board and the bitstream uses int8 data type.

```matlab
hW = dhldl.Workflow('Network', dlQuantObj, 'Bitstream', 'zcu102 int8', 'Target',hTarget);
```

# Program Bitstream onto FPGA and Download Network Weights

Deploy the network on the Xilinx ZCU102 hardware, run the deploy function of the dhldl.Workflow object. This function uses the output of the compile function to program the FPGA board using the programming file. It also downloads the network weights and biases. The deploy function starts programming the FPGA device, displays progress messages, and the time it takes to deploy the network.

```matlab
HW.deploy
```
