# Profile Network for Performance Improvement

This example shows how to improve the performance of the deployed deep learning network, by identifying neck layers from the profile results.

# Prerequisites

+   - Xilinx ZCU102 SoC development kit.
- Deep Learning HDL Toolbox™ Support Package for Xilinx™ FPGA and SoC
- Deep Learning Toolbox™
- Deep Learning HDL Toolbox™

# Load the Pretrained SeriesNetwork

To the pretrained digits series network, enter:

```
snet = getDigitsNetwork();
```

```
% To view the layers of the pretrained series network, enter:
snet.Layers
```

15x1 Layer array with layers:

| 'imageinput' | Image Input | 28x28x1 images with 'zerocenter' normalization |
|---|---||
| 'conv_1' | Convolution | 8x3x1 convolutions with stride [1] and padding |
| 'batchnorm_1' | Batch Normalization | Batch normalization with 8 channels |
| 'relu' | ReLU | ReLU |
| 'maxpool_1' | Max Pooling | 2x2 max pooling with stride [2] and padding |
| 'conv_2' | Convolution | 16x3x8 convolutions with stride [1] and padding |
| 'batchnorm_2' | Batch Normalization | Batch normalization with 16 channels |
| 'relu_2' | ReLU | ReLU |
| 'maxpool_2' | Max Pooling | 2x2 max pooling with stride [2] and padding |
| 'conv_10' | Convolution | 32x3x16 convolutions with stride [1] and padding |
| 'batchnorm_3' | Batch Normalization | Batch normalization with 32 channels |
| 'relu_3' | ReLU | ReLU |
| 'fc' | Fully Connected | 10 fully connected layer |
| 'softmax' | softmax | softmax |
| 'classout' | Classification Output | crosisententropy with '0' and 9 other classes |

# Create Target Object

Create a target object that has a custom name for your target device and an interface to connect your target device to the computer interface. Use JTAG and Ethernet. For Ethernet interface, enter:

```
hTarget = dlhad.Target('Xilinx', 'Interface', 'Ethernet');
```

Use the JTAG interface, install Xilinx "Vivado" Design Suite 2019.2. Set the path to your installed Xilinx Vivado executable if it is not already set. For example, to set the toolpath,

```
% dlsettoolpath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.')
```

For JTAG interface, enter:

```
% hTarget = dlhad.Target('Xilinx', 'Interface', 'JTAG');
```
