# Classify Images on an FPGA Using a Quantized DAG Network

In this example, you use Deep learning HDL Toolbox to deploy a quantized deep convolutional neural network and classify an image. The example uses the pretrained ResNet-18 convolutional neural network to demonstrate transfer learning, quantization, and deployment for the quantized network. You use MATLAB® to retrieve the predictions.

ResNet-18 has been trained over a million images and can classify images into 1000 object categories (such as coffee, mug, pencil, and many animals). The network has learned feature representations for a wide range of images. The network takes an image as input and outputs a label for the object in the image with the probabilities for each of the object categories.

# Transfer Learning using ResNet-18

To perform classification on a new set of images, you fine-tune a pretrained ResNet-18 convolutional neural network by transfer learning. In transfer learning, you can take a pretrained network and as a starting point to learn a new task. Fine-tuning a network with transfer learning is usually much faster and easier than training a network with randomly initialized weights from scratch. You can quickly transfer learned features to a new task using a smaller number of training images.

# Load Pretrained SeriesNetwork

To load the pretrained series network ResNet-18, enter:

```
snet = resnet18;
```

To view the layers of the pretrained series network, enter:

```
analyzeNetwork(snet);
```

The first layer, the image input layer, requires input images of size 227-by-227-by-3, where 3 is the number of color channels.

```
inputSize = snet.Layers(1).InputSize;
```

# Define Training and Validation Data Sets

This example uses the MathWorks MerchData data set. This is a small data set containing 75 images of MathWorks merchandise, belonging to five different classes (cap, cube, playing cards, screwdriver, and torch).
