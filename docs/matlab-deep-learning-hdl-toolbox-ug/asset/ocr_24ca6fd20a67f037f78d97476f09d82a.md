# Replace Layers

The last three layers of the pretrained network are configured for 100 classes. These three layers must be fine-tuned for the classification problem. All layers, except the last three, from the pretrained network.

```
LayersTransfer = snet.Layers(1:end);
```

Transfer the layers to the new classification task by replacing the last three layers with a fully connected layer, a softmax layer, and a classification output layer. Specify the one of new fully connected layer according to the new data. Set the fully connected to have the same size as the number of classes in the new data. To learn faster in the new layers than the transferred layers, increase the LearnRateFactor and BiasRateFactor of the fully connected layer.

numClasses = numel(categories(imdsTrain.Labels))
