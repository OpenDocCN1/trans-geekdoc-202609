# Generate Custom Processor and Bitstream

Use the new custom configuration to build and generate a custom processor and bitstream.
Use the custom bitstream to deploy the LogoNet network to your target FPGA board.

```
% hdlsetuptopath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.
% dhld.buildProcessor(hPCNew)
```

To learn how the generated bitstream file, see "Generate Custom Bitstream" on page 9-2.

The generated bitstream in this example is similar to the zcu102_int8 bitstream. To deploy the quantized LogoNet network using the zcu102_int8 bitstream, see "Obtain Prediction Results for Quantized LogoNet Network".
