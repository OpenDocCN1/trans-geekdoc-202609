### Calibration

### Workflow

Collect the dynamic ranges of the weights and biases in the convolution and fully connected layers of the quantized network and the dynamic ranges of the activations in all layers.

The calibrate method uses the collected dynamic ranges to generate an exponents file. The dldhl.Workflow class compile method uses the exponents file to generate a configuration file that contains the weights and biases of the quantized network.

## Code Generation and Deployment

To generate code for and deploy your quantized deep learning network, create an object of class dhlfl.Workflow. Use this object to accomplish tasks such as:

- Compile and deploy the quantized deep learning network on a target FPGA or SoC board using the deploy function.
- Estimate the speed of the quantized deep learning network in terms of number of frames per second by using the estimate function.
- Execute the deployed quantized deep learning network and predict the classification of input images by using the predict function.
- Calculate the speed and profile of the deployed quantized deep learning network by using the predict function. Set the Profile parameter to on.

The compile function optimizes networks for deployment by identifying network layers that you can execute in a single operation and then fuse together.

- Batch normalization layer (batchNormalizationLayer) and 2-D convolution layer (convolution2DLayer).
- 2-D zero padding layer (nnet.keras.ZeroPadding2DLayer) and 2-D convolution layer (convolution2DLayer).
- 2-D zero padding layer (nnet.keras.ZeroPadding2DLayer) and 2-D max pooling layer (maxPooling2Layer).

This code output is an compiler optimization in the compiler log.
Optimizing series network: Used 'nnet.keras.Layer.BatchNormalizationLayer' into 'nnet.cnn.Convolution20'.

The compile function splits a network into legs during compilation. A leg is a subset of the network that you can convert into a series network. The compile function groups the legs based on the output format of layers. The layer output format is defined as the data format of the deep learning process module that processes conv, fc, or adder. For example, in this image, the compile function groups all the layers in Leg 2 because they have a common output format. To learn about the output formats, see "Supported Layers" on page 70.
