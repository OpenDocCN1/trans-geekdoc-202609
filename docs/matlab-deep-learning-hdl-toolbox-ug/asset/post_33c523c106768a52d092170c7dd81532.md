# Program Bitstream onto FPGA SoC and Download Network Weights

To deploy the network on the Xilinx ZCU102 hardware, run the deploy function of the dhl.Workflow object. This function uses the output of the compile function to program the FPGA by using the programming file. It also downloads the network weights and biases. The deploy function starts the FPGA device, displays progress messages, and the time it takes to deploy the network.

# Image Category Classification by Using Deep Learning

This example shows you how to create, compile, and deploy a ddl. Workflow object with alexnet the network object by using the Deep Learning HDL Toolbox™ Support Package for Xilinx FPGA and SoC. Use MATLAB® to retrieve the prediction results from the target device. Alexnet is a pretrained neural network that has been trained on over a million images and can classify into 1000 object categories (such as keyboard, coffee, mug, pencil and land). You can also use VGG-19 and Darknet-19 as the network objects.

# Prerequisites

- Xilinx ZCU102 SoC development kit
- Deep Learning HDL Toolbox™ Support Package for Xilinx FPGA and SoC
- Deep Learning Toolbox™ Model for Alexnet
- Deep Learning Toolbox™

# Load the Pretrained Series Network

To load the pretrained series network alexnet:

```matlab
snet = alexnet;
```

To load the pretrained series network vgg19:

```matlab
snet = vgg19;
```

To load the pretrained series network darknet19:

```matlab
snet = darknet19;
```

To view the layers of the pretrained series network, enter:

```matlab
analyzeNetwork(snet)
% The saved network contains 25 layers including input, ReLU, cross channel max pool, fully connected, and softmax output layers.
```

# Create Object

Use dlhl.Target to create a target object with a custom name for your target device and an interface to connect your target device to the host device. Interface options are JTAG and Ethernet. Use JTAG, Install Xilinx Vivado™ Design Suite 2019.2. Use the Xilinx Vivado target, output:

```matlab
dlhlsettoolpath('TargetName','Xilinx Vivado', 'ToolPath', 'C:\Xilinx\Vivado\2019.2\bin\vivado.')
hTarget = dlhl.Target('Xilinx', 'Interface', 'Ethernet');
```

# Create Workflow Object

Use dlhl.Workflow to create an object. When you create the object, specify the network and the bitstream name. Make sure the bitstream name matches the data type and the FPGA board that you are targeting. In this example, the target FPGA board is the Xilinx ZCU102 SoC board. The bitstream uses a single type, enter:

```matlab
hw = dlhl.Workflow('Network', 'snet', 'Bitstream', 'zcu102_single', 'Target',hTarget);
```

# Compile the Analytics network

To compile the Analytics network run, run the compile method of the dlhl.Workflow object. You can optionally specify the maximum number of input frames.

```matlab
dn = hw.compile('InputFrameLimit', 15) 
```
