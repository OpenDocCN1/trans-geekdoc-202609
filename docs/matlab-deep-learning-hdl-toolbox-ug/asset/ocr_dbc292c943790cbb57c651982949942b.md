# Customize Bitstream Configuration to Meet Resource Use Requirements

The users want to deploy a digit recognition network with a target performance of 500 frames per second (FPS) to a Xilinx ZCU102 Z4AG device. The target device resource counts are:

+   - Digital signal processor (DSP) slice count - 240
- Block random access memory (BRAM) count -128

The reference (shipping) zcu102_int8 bitstream configuration is for a Xilinx ZCU102 Z9EG device. The default board resource counts are:

+   - Digital signal processor (DSP) slice count - 2520
- Block random access memory (BRAM) count -912

The default board resource counts exceed the user resource budget and are on the higher end of the cost spectrum. You can achieve target performance and resource budget by quantizing the target deep learning network and customizing the default bitstream configuration.

In this example we create a custom bitstream configuration to match your resource budget and performance requirements.

# Prerequisites

+   - Deep Learning Toolbox™ Support Package for Xilinx FPGA and SoC
- Deep Learning Toolbox™
- Deep Learning HDL Toolbox™
- Deep Learning Toolbox Model Quantization Library

# Load Pretrained Network

To load the pretrained series network, which has been trained on the National Institute Standards of Technology (MNIST) database, enter:

```
snet = getDigitsNetwork;
```

# Quantize Network

To quantify the MNIST biased digits network, enter:

```
dquantobj = quantize(snet,'ExecutionEnvironment','FPGA');
Image = imageatastore('five_28.pgm','Labels','five','five');
dquantobj.calibrate(Image)
```
