# Logo Recognition Network

This example shows how to create, compile, and deploy a `dhldl.Workflow` that has Logo Recognition Network as the network object using the Deep Learning HDL™ Support Package for Xilinx FPGA and SoC. Use MATLAB® to retrieve the prediction results from the target device.

# The Logo Recognition Network

Logos assist users in brand identification and recognition. Many companies incorporate their logos in advertising, documentation materials, and promotions. The logo recognition network (logonet) was developed in MATLAB® and can recognize 32 logos under various lighting conditions and camera motions. Because this network focuses only on recognition, you can use it in applications where localization is not required.

# Prerequisites

- Xilinx ZCU102 SoC development kit
- Deep Learning HDL Toolbox™ Support Package for Xilinx FPGA and SoC
- Deep Learning Toolbox™
- Deep Learning HDL Toolbox™

# Load the Pretrained Series Network

To load the pretrained series network logonet, enter:

```matlab
snet = getLogoNetwork();
```

To view the layers of the pretrained series network, enter:

```matlab
analyzeNetwork(snet)
```

# 10 Featured Examples

![](img/747bfd4f288a7e0917a1f27637cc5c2d_89_0.png)

## Create Target Object

Create a target object that has a custom name for your target device and an interface to connect your target device to the host computer. Interface options are JTAG and Ethernet. To use the Xilinx Vivado tool, set the Xilinx™ Vivado™ Design Suite 2019.2.

```matlab
% dlhsetlooppath('ToolName', 'Xilinx Vivado', 'ToolPath', 'C:Xilinx\Vivado\2019.2\bin')
```

To the target object, enter:

```matlab
hTarget = dlhl.Target('Xilinx', 'Interface', 'Ethernet');
```

## Create Workflow Object

Create an object of the `dlhl.Workflow` class. When you create the object, specify the network and the bitstream name. Make sure that the bitstream name matches the data type and the FPGA board that you are targeting. In this example the target FPGA board is the Xilinx ZCU102 SOC board. The bitstream uses a single data type.

```matlab
hw = dlhl.Workflow('network', snet, 'Bitstream', 'zcu102 single', 'Target', hTarget);
% if running on Xilinx ZC706 board, instead of the above command,
% uncomment the command below.
```

```matlab
% hw = dlhl.Workflow('Network', snet, 'Bitstream', 'zc706_single', 'Target', hTarget);
```

## Compile the Logo Recognition Network

To compile the logo recognition network, run the compile function of the `dlhl.Workflow` object.

# Program Bitstream to FPGA and Download Network Weights

To deploy the network on the Xilinx ZCU102 SoC, run the deploy function of the FPGA board by `dldhl.Workflow` function uses the output of the compile function to program the FPGA board by the programming file. It also downloads the network weights and biases. The deploy function starts programming the FPGA device, displays progress messages, and the time it takes to deploy the network.

```matlab
hw.deploy
```
