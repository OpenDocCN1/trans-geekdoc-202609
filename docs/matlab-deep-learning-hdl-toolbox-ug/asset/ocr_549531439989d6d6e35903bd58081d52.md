Changing from JTAG to the deploy function reprograms the bitstream, which accounts for most of the elapsed time. Reprogramming is due different methods that are used to program the bitstream for different hardware interfaces. The Ethernet interface configures the ARM processor and uses a persistent programming method so that the bitstream is reprogrammed each time the board is turned on. When deploying deep learning networks using the same bitstream we can skip the bit programming, which further speeds up network deployment.
