Here, \(\tilde{x}\) is the corrupted data, the input data with noise. Then, forward propagation to the hidden layer and the output layer can be represented as follows:

\[ z_j = \sigma\left(\sum_{i=1}^{N} w_{ji}\tilde{x}_i + c_j\right) \]

\[ y_i = \sigma\left(\sum_{j=1}^{M} w_{ij}z_j + b_i\right) \]

Here, \(c_j\) denotes the bias of the hidden layer and \(b_i\) the bias of the visible layer. Also, \(\sigma\) denotes the sigmoid function. As seen in the preceding diagram, corrupting input data and mapping to a hidden layer is called **Encode** and mapping to restore the encoded data to the original input data is called **Decode**. Then, DA's evaluation function can be denoted with a negative log likelihood function of the original input data and decoded data:

\[ E := -\ln L(\theta) = -\sum_{i=1}^{N}\left\{x_i\ln y_i + (1-x_i)\ln(1-y_i)\right\} \]
