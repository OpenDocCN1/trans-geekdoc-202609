

移动操作系统负责其运行，包括硬件和软件资源的管理、维护和管理，包括处理器和内存。此外，操作系统运行应用程序并管理蜂窝和无线网络连接，包括蓝牙和 Wi-Fi、GPS 导航以及多媒体功能。最流行的移动操作系统是 Android 操作系统和 Apple 的 iOS。

*   Android 操作系统是世界上使用最广泛的移动操作系统，是一个开源操作系统。它基于经过修改的 Linux 内核，由 Google 开发。^([^(415)](#fn415))

*   iPhone 操作系统或 iOS 是第二流行的操作系统，由 Apple 开发。iOS 基于类 Unix 操作系统，包含 Mac OS X 操作系统的几个元素。iOS 仅适用于 Apple 设备。^([^(416)](#fn416))

运行在移动操作系统之上的是一系列应用程序或应用。最初，应用程序旨在激励生产力，例如日历和电子邮件应用程序。随着移动设备的普及，应用程序的需求迅速扩展到“每个人和每件事都有相应的应用程序”。这些应用程序或应用是专门的软件，可以轻松让移动用户执行特定任务。`Application Program Interface (API)` 是操作系统的一个功能，允许应用程序请求服务，并可以相互交互和获取数据。允许第三方应用程序之间共享内容的 API 示例包括 LinkedIn 的 API、Facebook 的 API、Twitter API、Google Maps 和 YouTube。一个很好的示例是 Facebook 的 API。Facebook 的 API 允许用户登录、启用社交媒体用户，并从 Facebook 应用程序发布内容。它还允许开发者访问用户的个人资料身份，并从 Facebook 平台获取数据以管理广告和执行其他任务。用户通常不了解 Facebook 可以使用的数据范围。Facebook 的 Graph API（关于特定对象的特定标签或数据列表）被 Cambridge Analytica 用于收集 Facebook 用户的个人信息，访问他们的社交生活，并将其作为政治竞选活动（如 2016 年美国总统选举和英国脱欧公投竞选活动）的目标。

从积极的一面来看，API 将应用程序组件集成到现有架构中，并帮助企业与客户协作，通过基于云的应用程序从旧基础设施中收集数据并与他们共享数据。

为了能够开发应用程序，开发者使用一种名为 `Software Development Kit (SDK)` 的一站式解决方案软件，它是工具、API、指南、库、程序和其他实用程序的集合，可帮助开发者为特定平台创建应用程序。提供 SDK 工具包的公司包括 Google、Facebook 和 Microsoft。

### [8.3.3 平台架构](#contents.xhtml#re_h-8-8)

最广泛部署的两个移动操作系统是 Google 的 Android 操作系统和 Apple 的 iOS。Android 是最终用户部署最广泛的智能手机操作系统。^([^(417)](#fn417))

`Android` 是由 Google、开放手持联盟和其他公司开发的开源操作系统。要使用 Android 操作系统，移动设备制造商必须满足兼容性定义文档 (CDD) 指定的要求，并获得 Google 的许可。Android 操作系统由七个主要层组成。^([^(418)](#fn418))

*   `Linux kernel layer`：位于堆栈底部，被视为 Android 生态系统的核心，负责系统的平稳运行。该层在设备硬件和 Android 应用程序软件堆栈的上层之间提供接口。它管理核心系统服务，如虚拟内存、外围硬件接口、网络以及大量设备驱动程序，如蓝牙、相机、显示器、内存、电源管理、内存管理和键盘。^([^(419)](#fn419))

*   `Hardware abstraction layer (HAL)`：为特定硬件组件提供接口。它由多个模块组成，例如相机模块或蓝牙模块。^([^(420)](#fn420))

*   `Android runtime (ART)`：是 Android 操作系统与应用程序之间的软件层。它为运行用 Kotlin（Java 虚拟机的编程语言）和其他 Java 语言应用程序编写的应用程序提供执行环境。此外，ART 的前身 Dalvik 在与 ART 运行时也应正常工作。ART 还管理内存，并为开发者在使用 Java 语言开发应用程序时提供一组核心库。^([^(421)](#fn421))

*   `Native C/C++ libraries`：为支持网络和数据库等通用任务的 Android 应用程序提供标准 Java 库。示例包括用于存储和共享数据的 SQLite 库、用于浏览网页的 Webkit 库、用于安全通信的安全套接字层 (SSL) 库，以及控制音频子系统的音频管理器库。除了这些标准库之外，还为 Android 开发者设计了基于 Java 的库。^([^(422)](#fn422))

*   `Java API framework`：通过简化核心模块化系统组件和服务的重用，为创建 Android 应用程序提供构建块。它还管理应用程序资源和用户界面，包括：^([^(423)](#fn423)) 

    *   Activity Manager，用于管理应用程序的生命周期并提供常见的导航（如返回按钮）。

    *   Content，用于使应用程序能够访问/共享/发布来自其他应用程序的数据。例如，联系人应用程序。

    *   Notification Manager，用于使应用程序能够显示自定义警报。

    *   Resource Manager，用于提供对非代码资源（如颜色字符串、图形和用户界面布局）的访问。

    *   View System，用于构建应用程序的用户界面，包括按钮、列表、文本框和网络浏览器。

*   `System application layer`：为电子邮件、短信、日历、互联网浏览、联系人等提供核心应用程序和第三方应用程序。第三方应用程序可以成为用户的默认应用程序（系统的设置应用程序除外）。^([^(424)](#fn424))

*   `Hardware and power management`：系统内置的组件。每个组件都有特定的界面设计用于用户交互。

`Apple’s iOS` 基于 NeXTSTEP 操作系统。NeXTSTEP 是由史蒂夫·乔布斯离开 Apple 后创立的公司 NeXT 创建的。当乔布斯回到 Apple 时，NeXTSTEP 成为 macOS 和 iOS 的基础。NeXTSTEP 基于 Unix，并使用卡内基梅隆大学的 Mach 内核创建。^([^(425)](#fn425))

*   `Core OS layer`：包含大多数其他技术依赖的低级功能，例如 XNU 内核，它是 Darwin OS 的一部分，用于 macOS 和 iOS 操作系统，并且是整个 iOS 的基础。XNU 包含 Berkeley Software Distribution (BSD)，它提供可移植的操作系统接口，还包括文件管理器、本地身份验证、整个系统的安全服务、系统实用程序和蓝牙框架。^([^(426)](#fn426))
