

民主总统候选人希拉里·克林顿和其他民主党人遭到了包含虚假信息的广告和具有说服力的 Facebook 材料的攻击，其目的是改变选票并在易受攻击的州制造投票集团，最终导致社会动荡和意外的选举结果，即唐纳德·特朗普当选，并最终导致国家和国际权力平衡可能发生变化。

我们不仅在 2016 年美国大选中看到了这些黑客攻击活动。^([^(82)](#fn82))

2018 年发现的新证据表明，一家名为剑桥分析公司的英国政治咨询公司以及其他公司收集个人信息，以改变 2016 年美国总统大选和英国脱欧公投的结果并影响选民行为。^([^(83)](#fn83))

这种行为操纵的一个例子发生在威尔士的小镇埃布瓦尔。据美国全国公共广播电台报道，该镇压倒性地赞成脱欧。利用后来消失的 Facebook 新闻动态以及来自 Google 和 YouTube 的广告，人们被说服相信移民和难民人口已经淹没了该城市，尽管该镇实际上是该国移民率最低的地方之一。尽管欧盟在该镇投入了大量资金，但人们开始相信它对他们毫无作为。广告和假新闻引发了人们特定的人类情感及其后续行为。^([^(84)](#fn84))

使用心理统计技术来操纵行为，成为 Facebook、Twitter 甚至 Google 企业贪婪的结果之一。心理统计分析强调消费者的生活方式。它用于了解影响消费习惯、爱好、观点、态度、兴趣和生活方式的认知过程，我们从谁那里购买，以及我们为什么选择购买东西。

2018 年，英国的保护监管机构因 Facebook 在剑桥分析公司丑闻中所扮演的角色而对其处以 50 万英镑的罚款。2019 年晚些时候，在对 Facebook 的调查显示其在未经用户知情的情况下向剑桥分析公司提供了 8700 万 Facebook 用户个人数据的访问权限后，美国联邦贸易委员会（FTC）对 Google 处以 50 亿美元的罚款。FTC 发现，Facebook 通过在用于广告的双因素（`2FA`）身份验证中收集的电话号码，违反了反欺骗行为的规则。^([^(85)](#fn85))

剑桥分析公司通过使用移动应用程序收集数据，并通过跟踪位置和联系人/地址列表来获取额外信息。使用的一个应用程序名为“Cruz Crew”，由美国参议员德克萨斯州泰德·克鲁兹连任竞选活动使用。^([^(86)](#fn86))

此外，在第四阶段，我们继续经历较旧形式的网络犯罪，包括银行恶意软件、比特币钱包盗窃、移动设备黑客攻击以及通过勒索软件进行的敲诈。

面对新旧威胁，在第四阶段，我们看到网络犯罪已从黑客攻击和身份盗窃发展为更复杂、组织更严密的全球威胁。网络犯罪现在类似于一场无声的全球战争。它不分国界，关乎地球上的每个国家。

假新闻的传播是选举干预的关键部分，一直是社交媒体的巨大收入来源。只有通过政府监管、教育和持续监控，才能阻止这种虚假信息的使用。到目前为止，我们只能得出结论：'真理'一词已经失去了意义。取而代之的是“替代性真相或事实”。

我们最初喜爱 Google 和 Facebook，因为它们是“免费”的；我们现在明白，社交媒体远非免费。我们现在必须把自己不仅视为用户，还视为收入来源，我们的私人信息是一种可以买卖的商品。社交媒体可能最初是为了让我们走在一起而设计的，但现在它却让我们分裂。

2016 年至 2017 年间，一种名为 `Petya` 的加密勒索软件及其更新版本 `NotPetya` 出现。两者都旨在加密并锁定受感染计算机的硬盘。只有支付赎金才能恢复文件访问权限。恶意软件通常作为电子邮件附件到达受害者的计算机上。`Petya` 只有在成功诱骗受害者从垃圾邮件中下载其文件时才能运行。它针对 Windows 操作系统（`OS`），感染主引导记录，加密硬盘的文件系统并阻止计算机启动。网络犯罪分子经常要求受害者通过比特币支付赎金以重新获得访问权限。^([^(87)](#fn87))

2016 年，我们经历了 `Mirai` 恶意软件。这种类型的恶意软件将运行 Linux 的物联网设备变成远程控制的“僵尸”。^([^(88)](#fn88))

2017 年，名为 `WannaCry` 的勒索软件利用全球 Windows 计算机中的一个漏洞。与 `Mirai` 类似，该勒索软件能够加密计算机的文件，然后锁定用户，使他们无法访问自己的信息。此时，需要以比特币加密货币支付赎金，才能允许用户访问自己的信息。

`WannaCry` 入侵了英国国家医疗服务体系（`NHS`）的计算机，使整个医疗记录系统瘫痪。医护人员无法登记患者、访问医疗记录或开具药物，延误了关键手术，并给数百万患者和工作人员造成混乱。^([^(89)](#fn89))

EternalBlue 漏洞利用是一种利用软件漏洞的代码，在此情况下为 MS Windows 操作系统。据称，它于 2016 年从国家安全局（`NSA`）被盗，并由一个名为 Shadow Brokers 的黑客组织泄露。随后，它被用于 `WannaCry` 勒索软件。^([^(90)](#fn90))

`WannaCry` 和 `NotPetya` 并未针对个人，而是攻击了最大系统、银行、国家机构和部门的关键基础设施。这些攻击并非来自孤立的犯罪分子，而是由情报或网络战机构设计的。^([^(91)](#fn91))

2018 年，欧盟实施了打击网络犯罪的立法。通用数据保护条例（`GDPR`）取代了数据保护指令 95/46/EC。^([^(92)](#fn92))

2018 年，万豪国际宣布，黑客入侵了其喜达屋预订系统，并窃取了全球 5 亿客户的信息。^([^(93)](#fn93))

2019 年，过去曾面临众多网络安全问题的 Facebook 再次遭遇泄露。由于名为 Upguard 的网络安全公司未能充分保护未受保护的 Facebook 个人数据库，超过 5.4 亿条 Facebook 用户记录在亚马逊的云计算服务上公开曝光。

2019 年，美国联邦紧急事务管理局（`FEMA`）在一份管理警报中宣布，2017 年加州山火以及哈维、厄尔玛和玛丽亚飓风中 230 万灾民的机密个人信息已被泄露。^([^(94)](#fn94))

2019 年，我们见证了人工智能（`AI`）和机器学习（`ML`）算法的增长，这些算法彻底改变了名为“深度伪造”的可信音频和视频的创建。这项技术提供了在视频片段或图像中交换一个人脸的能力。深度伪造视频可以让任何人做或说任何事情，而且不易被检测。这种强大技术的影响范围从无害的恶搞到对受害者的欺凌和敲诈，并使得在重大选举活动中用于政治攻击的 X 级视频得以创建。越来越难以识别这些伪造品，并说服他人它们不可信。因此，人工智能的力量为网络犯罪分子提供了另一种武器。
