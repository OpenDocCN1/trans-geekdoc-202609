

# 协议数据单元（PDU）

*协议数据单元（PDU）* 是一个术语，用于描述数据包在 OSI 模型不同层级传输时的名称（[图 5.17](#c5.xhtml#f5.17））。当 *PDU* 到达 *传输层* 时，它被称为 *TCP 段* 或 *UDP 数据报*（大多数应用程序使用 TCP 协议）；当该单元进入 *网络层* 时，它被称为 *数据包*，当它移动到 *数据链路层* 时，它被称为 *帧*。我们将在本章后面讨论 OSI 模型时，连同段、数据包和帧一起讨论。

# 媒体访问控制地址

*媒体访问控制地址* 或 *物理地址* 是由制造商分配给每个计算设备网络接口卡（NIC）的唯一 48 位识别号码。MAC 地址不会改变；它被硬编码到 NIC 中或存储在只读存储器（ROM）中。MAC 地址的唯一性由 IEEE 注册，IEEE 向制造商收费分配 MAC 地址块。尽管如此，地址可以使用制造商提供的软件进行配置。^([^(274)](#fn274))

MAC 地址由 12 位十六进制数字组成，即 48 位或 6 字节。前 3 字节（24 位或 2^(24)）代表由 IEEE 分配的组织唯一标识符（OUI）或制造商代码。接下来的 3 字节（24 位或 2^(24)）用于识别来自其制造商的 NIC。^([^(275)](#fn275))

# 网络地址转换（NAT）

*网络地址转换（NAT）* 允许路由器等网络设备通过用公共 IP 地址替换私有 IP 来将私有 IP 网络连接到互联网。NAT 在互联网（公共 IP）和本地网络（私有 IP）之间充当“接待员或调度员”。使用此方法，只需要一个 IP 地址即可将整个本地计算设备组连接到互联网。^([^(276)](#fn276))

# 网络接口卡

*网络接口卡*，也称为 *网络接口控制器* 或 *网络适配器*，是一种计算机硬件，允许计算设备通过有线或无线连接连接到网络。NIC 卡的地址是设备的 MAC 地址。

## 5.1.6 使用网络实用程序

*网络实用程序* 是分析、诊断和配置计算机网络许多方面并开始处理解决方案的软件工具。一些最常见的开源实用程序包括：

*   **Angry IP Scanner**：跨平台网络扫描仪。^([^(277)](#fn277))

*   **CISCO Packet Tracer**：网络模拟，用于在实施前测试网络环境。它可能跨不同平台工作。

*   **iPerf3**：网络问题解决、性能测量和调优（Microsoft Windows、MacOS、Linux）。^([^(278)](#fn278))

*   **Netstat** 或 **网络统计**：在大多数操作系统上提供网络活动的基本统计信息。^([^(279)](#fn279))

*   **Nmap**：用于未经授权设备和开放端口的网络扫描仪和监视器（支持跨平台）。^([^(280)](#fn280))

*   **PuTTY**：用于访问和配置网络设备（Microsoft Windows、MacOS、Linux）。^([^(281)](#fn281))

*   **Wireshark**：收集和解释网络流量（支持跨平台）。^([^(282)](#fn282))

此外，常见操作系统（OS）中包含的一些关键网络实用程序如下：

*   **arp**

    *   *arp* 实用程序命令用于显示和修改地址解析协议（ARP）缓存，并列出任何设备的 IP 和 MAC 地址。命令 *arp-a* 显示 MAC 地址。

        要使用此命令，在 Windows 中，转到“搜索”，键入 `cmd` 以获取命令提示符屏幕；然后键入命令 `arp`。

        在 Unix 或 Linux 中，转到 *终端应用程序* 并键入 `arp`。

*   **ipconfig**

    *   *Internet 协议配置* 是一个实用程序，用于显示 TCP/IP 配置信息以及如何设置或显示网络接口的 IP 地址和子网掩码的信息。一旦我们在命令提示符屏幕中键入 `ipconfig`，操作系统将返回包含 IPv4 和 IPv6 地址、子网和默认网关的信号，这些是连接到互联网的连接。此命令还可以验证计算机是否具有正确的 IP 配置。

        要使用 `ipconfig`，在 Windows 中，转到“搜索”，键入 `cmd` 以获取命令提示符屏幕；然后键入命令。输入 `ipconfig/all` 命令将获取完整的 TCP/IP 配置；`ipconfig/flushdns` 清除带有名称解析问题的 DNS 缓存。如前所述，DNS 服务器将域名转换为数值地址。根据操作系统或浏览器，DNS 会暂时存储关于先前 DNS 搜索的信息。我们使用此命令来“刷新 DNS”，以隐藏搜索行为/历史，发现诸如操纵和 DNS 欺骗等安全原因，并解决错误或旧 IP 以及更新 IP 信息等技术问题。Linux 已用 `ip` 替换了 `ifconfig`。例如，`ip-4 a` 用于查看 IPv4 信息，`ip-6` 用于查看 IPv6 信息。^([^(283)](#fn283))

*   你也可以使用 `ifconfig` 命令查看所有网络连接的设备，包括它们的 IP 和 MAC 地址。

*   **ping**

    *   此命令用于确认与 TCP/IP 和本地计算机的网络连接。该命令还提供关于任何数据包丢失的报告。你可以在 Windows `cmd` 提示符和 Unix 或 Linux 上的 *终端应用程序* 中使用 `ping`。

*   **netstat**

    *   此命令显示网络连接中传入和传出活动的信息。*Netstat* 将显示所有活动的 TCP/IP 连接，并可用于 Windows、终端应用程序、Unix 或 Linux。

*   **tracert**

    *   此命令类似于 ping，但 `tracert` 提供了更多关于到达目的地的数据包路由的详细信息，并还测量传输延迟，包括“跳数”、交换机、路由器和 DNS 信息。

        要使用 tracert，在 Windows `cmd` 中，输入 `tracert`；在 Unix 或 Linux 上，使用终端应用程序命令并输入 `traceroute`。

        *中继器* 是一种网络设备，它接收并再生同一网络上的信号。中继器不理解帧、数据包或标头，不能执行智能路由，只能再生和复制信号。中继器在 OSI 模型的第 1 层——物理层上运行。

# 路由器

*路由器* 是虚拟或物理网络设备，通过在不同 IP 网络之间转发数据包来充当调度员的功能。此外，路由器评估数据包并选择发送它们的最佳路由。

# 服务器

*服务器* 是接受并响应客户端通过网络发出的请求的计算机硬件或软件。客户端创建请求并将其发送到服务器，服务器然后将请求的信息返回给客户端。服务器运行在远程计算设备上，为客户端提供服务，而客户端是运行在本地计算设备上的程序，用于从服务器请求服务（[图 5.19](#c5.xhtml#f5.19)）。
