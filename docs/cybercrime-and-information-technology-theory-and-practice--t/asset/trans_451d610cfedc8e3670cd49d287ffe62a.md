

特洛伊木马恶意软件得名于荷马的史诗《伊利亚特》。当希腊人试图攻陷特洛伊城时，他们很难进入这座坚固的城市。希腊人欺骗特洛伊人，给他们一座巨大的木马，并假装在特洛伊人将木马拖入城中后乘船离开。夜间，藏在木马内的希腊士兵爬出，为其余希腊军队打开城门，随后他们攻占了城市。同样，特洛伊木马是一种恶意软件（malicious software），它伪装成正常软件，但内部包含隐藏的破坏性元素。

当你收到一封电子邮件并点击一个看似无害的附件时，你可能会不知不觉地安装一个程序，该程序会感染你计算机或网络中的文件。这个附件被称为特洛伊木马。大多数情况下，特洛伊木马会保持隐藏，直到采取特定操作，例如访问网上银行网站或在线支付账单。此时，特洛伊木马会激活恶意代码并执行其指令，窃取密码或转账。特洛伊木马可能被编程为在完成任务后自行删除。

`Mydoom`，是最具破坏性的病毒或蠕虫之一，出现于2004年。^([^(70)](#fn70))

另一种毁灭性的蠕虫是 `Sober` 电子邮件蠕虫及其变体。`Sober` 蠕虫是一类计算机蠕虫。它们通常是独立程序，无需人工交互即可在网络中复制。该蠕虫可能通过电子邮件、伪造网页、伪造弹出广告或伪造广告传入，并包含诸如性、爱情甚至计算机病毒警告等主题行。“执行后，`Sober` 将自身复制到 Windows 系统文件夹中的几个文件之一，作为 `.exe` 文件，名称由以下字符串构建：sys, host, dir, explorer, win, run, log, 32, disc, crypt, data, diag, spool, service, smss32。”^([^(71)](#fn71))

在此期间，三项显著的技术进步变得如此普遍，以至于改变了人们的互动方式。这些技术是于2007年首次推出的 Apple iPhone***,*** 和于2008年推出的 Android 操作系统（OS）。第三项发展是云计算**，**尽管 John McCarthy 在20世纪60年代首次引入了这种技术的一个更基础的版本。^([^(72)](#fn72))

2006年，Amazon 推出了其 Web Service AWS，其他云*\-*计算提供商，如 Google、IBM 和 Microsoft 随后跟进。云计算是通过互联网分发数据库、存储、应用程序和分析等计算服务。云计算为全球企业和个人提供灵活性、节省成本、时间和资源，使其较少依赖传统数据中心和支持团队。然而，云计算的一个主要担忧是安全性和数据隐私问题。根据所使用的云计算模型，数据可能不再完全属于企业或个人。云服务提供商将用户数据存储在其自身服务器上，并对数据拥有完全访问权限，无论数据是否机密。此外，数据的物理存储通常跨越不同国家的多个服务器，这使得网络犯罪分子更容易操纵与云的连接或攻击数据中心。

以希腊诸神之王宙斯命名的 `Zeus` 病毒于2007年被识别。与其他特洛伊木马恶意软件类似，它针对 Microsoft Windows，网络犯罪分子利用它窃取在线金融交易。`Zeus` 创建一个僵尸网络，并收集大量信息，包括密码、配置文件和在线凭据。僵尸网络或“机器人”是已被恶意软件感染并被远程编程用于欺诈目的的基于互联网的计算设备。

此外，`Zeus` 病毒会损坏计算机，同时与服务器通信并控制服务器。`Zeus` 感染了美国超过360万台计算机。^([^(74)](#fn74))

2009年，经济与临床健康信息技术法（HITECH）引导美国医疗保健提供者扩大安全电子病历（EMR）的使用。一旦个人医疗信息上线，网络犯罪分子就开始针对这些医疗记录。他们意识到，虽然从金融机构窃取的数据在泄露被发现并更改密码后就变得无用，但病史无法更改，并伴随一生。

2010年，`Stuxnet` 蠕虫出现。`Stuxnet` 是由美国和以色列政府创建的网络战工具，旨在破坏伊朗的核计划。^([^(75)](#fn75))

### [Phase IV](#contents.xhtml#re_h-2-9)

第四阶段始于2011年之后，并延续至今。这一阶段包括国家赞助的网络攻击、间谍活动、对政府隐私和机密性的泄露，以及通过社交媒体平台的说服操纵公众舆论。此外，在这个阶段我们看到假新闻的兴起和个人隐私的消亡。我们现在生活在监控时代，令人毛骨悚然地类似于乔治·奥威尔在其小说《1984》中的描述。

2011年是大规模数据泄露的一年。Epsilon Data Management（其客户包括 Eddie Bauer、Ethan Allen 和 TD Ameritrade）损失了大量数据。索尼的 PlayStation Network 和 Qriocity 服务也遭到攻击，引起公众对数据安全、隐私以及政府在防止此类攻击中作用的关注。^([^(76)](#fn76))

2013–14 年，Yahoo 遭遇了其历史上最大的安全漏洞，影响了超过十亿用户。^([^(77)](#fn77))

另一个著名的国家赞助攻击例子发生在2014年的索尼影业娱乐（SPE）。该公司检测到大规模网络入侵，随后遭到要求，要求其不要发行新的动作喜剧电影《采访》。这部电影是一部讽刺片，讲述美国人被派往朝鲜刺激其总统金正恩的故事。索尼声称这部电影不是政治攻击，仅旨在娱乐。索尼员工受到身体伤害的威胁，除非他们签署一份谴责该电影的文件。索尼没有屈服于要求，并按计划发行了电影。后来证实，朝鲜政府对这次攻击及随后的要求负有责任。^([^(78)](#fn78))

2015年，一个名为“影响团队”的黑客组织入侵了 Ashley Madison 的数据库，并窃取了3700万用户的个人信息。Ashley Madison 是一个专门用于婚外情的网站。^([^(79)](#fn79))

此外，网络安全攻击继续影响医疗保健行业。健康保险公司 Anthem Inc. 和 Primera Blue Cross 遭遇了大规模数据泄露。网络窃贼窃取了约9100万份患者记录，包括社会安全号码、医疗数据和财务信息。^([^(80)](#fn80))

2016年，随着美国总统选举的临近，该国经历了一波政治网络犯罪，其特征是操纵社交媒体以及窃取或购买个人档案。在这种情况下，来自其他国家的网络犯罪分子根据其政治倾向、教育程度、观点以及其他使其易受说服和脆弱的因素来选择目标。这种黑客活动操纵社交媒体数据，未经选民同意攻击选民，使用社交媒体机器人、制造宣传和推广假新闻。由于大多数美国成年人（62%）在社交媒体上获取新闻，大量看到这些故事的人接受它们并相信它们是真实的。^([^(81)](#fn81))
