

# 计算机安全中的网络攻击

在计算机安全中，网络攻击分为主动攻击和被动攻击。^([^(302)](#fn302))

![FIGURE 6.8 Active and passive attacks.](images/fig6.8.jpg)

**FIGURE 6.8** Active and passive attacks.

主动攻击的示例包括漏洞利用、DoS、DDoS、恶意软件、网络钓鱼以及暴力破解攻击（如密码破解、病毒和蠕虫）。被动攻击包括系统监视，例如记录每一次按键的按键记录器、可以窃听电子邮件的恶意软件，以及其他通信，如语音录音和元数据分析。

攻击可能发生在组织网络内部，也可能来自外部来源，例如黑客。[Figure 6.8](#c6.xhtml#f6.8) 展示了主动攻击和被动攻击。

网络攻击是针对计算系统、网络和个人计算设备的故意利用和恶意行为。网络犯罪分子使用广泛的技术来造成最大程度的干扰并增加其利润。

攻击向量在网络安全中是指用于获得未经授权的访问或渗透目标计算系统的方法。

提供官方已知安全漏洞和暴露参考及描述的数据库称为通用漏洞披露（CVE）。^([^(303)](#fn303))

网络犯罪分子或黑客访问未经授权计算系统的主要原因包括网络战、不满员工、报复、滋事、间谍活动、经济利益、娱乐、黑客爱好者、智力挑战、黑客行动主义、企业间的恶意竞争、网络性能缓慢（DoS 攻击）以及勒索。

这些攻击是什么样子？以下是一些最常见的网络攻击类型。

## 6.3.1 Adware

广告软件，或广告支持软件，被视为不受欢迎的软件，旨在强制用户查看或点击屏幕上的广告。广告软件是一种潜在的不需要程序（PUP），意味着它是一种轻微威胁，低于恶意软件的分类。这种不需要的软件通常放置在 Web 浏览器中，以便为其开发者创造收入，或者作为用户界面中的第三方赞助商，敦促用户安装它。广告软件存在于所有计算设备平台上，通常是安全、合法且不具恶意的。然而，网络犯罪分子可能利用广告软件开发者，并可能将其作为恶意软件感染的入口。^([^(304)](#fn304))

## 6.3.2 Denial-of-Service Attacks

拒绝服务（DoS）攻击是指黑客使计算机资源对用户不可访问的攻击。当目标是使网络过载时，有多种方法可以开始攻击。DoS 攻击的两种常见方法是通过耗尽资源来淹没网络服务和使网络服务崩溃。执行 DoS 攻击的一种方法是开发一个小病毒，其唯一目的是向目标发送大量消息。此外，攻击者可以通过创建错误或缓冲区溢出（例如 ping of death）来破坏系统的可用性。任何针对服务可用性的攻击都被归类为拒绝服务攻击。

DoS 仅使用单个计算设备来执行攻击。[Figure 6.10](#c6.xhtml#f6.10) 演示了 DoS 攻击。

![FIGURE 6.10 A DoS attack.](images/fig6.10.jpg)

**FIGURE 6.10** A DoS attack.

拒绝服务攻击有多种形式，可分为应用层攻击（按每秒请求数衡量）、协议攻击（按每秒数据包数衡量）和容量或基于容量的攻击（按每秒比特数衡量）。^([^(305)](#fn305))

[Figure 6.11](#c6.xhtml#f6.11) 解释了三种拒绝服务攻击类型，并为每个类别提供示例。

![FIGURE 6.11 Types of denial-of-service attacks.](images/fig6.11.jpg)

**FIGURE 6.11** Types of denial-of-service attacks.

拒绝服务攻击不需要像恶意软件这样的特定程序来运行，而是利用网络通信应用程序的安全漏洞。

DoS 攻击的目标不是渗透计算系统、服务器或网络以获取机密信息，而是通过向用户发送大量请求来切断用户对资源的访问。由于每个计算设备都有操作限制，网络犯罪分子向目标服务器发送大量请求，用其无法处理的流量使其过载。计算系统最终使服务对合法用户不可用。以下是一些常见的 DoS 攻击：

*   互联网控制消息协议（ICMP）或 ping 泛洪攻击。当黑客发送 ICMP 回显请求或 ping 以淹没计算系统时，就会发生这种类型的攻击。^([^(306)](#fn306))

*   SYN 泛洪攻击发生在攻击者利用 TCP 连接序列的弱点，不支持三次握手时。每个使用 TCP 建立的连接都需要三次握手，这是每个连接的基础。在正常连接中，三次握手发生在客户端和服务器之间。首先，客户端发送 SYN 数据包，服务器回复确认，例如 SYN-ACK。服务器发送回确认 ACK 数据包，随后是数据。握手完成（参见 [Figure 6.12](#c6.xhtml#f6.12)）。

    另一方面，攻击者发送同步（SYN）数据包以开始握手。服务器响应确认（SYN-ACK），但攻击者不回复确认 ACK 数据包。结果，三次握手未完成，服务器的连接端口无法处理进一步的请求（参见 [Figure 6.13](#c6.xhtml#f6.13)）。攻击者将继续发送越来越多的请求，以防止任何其他人连接到服务器或网络。防御 SYN 泛洪攻击包括软件定义网络（SDN）范式。^([^(307)](#fn307))

*   Smurf 攻击是一种拒绝服务攻击，利用互联网协议（IP）和 ICMP 的弱点，使用名为“smurf”的源代码。黑客使用此源代码广播大量 ICMP 数据包，通过使用伪造的 IP 地址发出请求。

    黑客首先创建一个伪造（假）网络数据包，其源地址设置为他想要攻击的服务器的真实 IP 地址。接下来，黑客向路由器的 IP 广播地址发送 ICMP 回显请求（ping），要求网络设备或节点发送回复。每个设备都向伪造地址发送 pinged 回复数据包，导致目标 IP 地址被淹没，并建立一个无限循环，因为目标和接收者是相同的。因此，目标网络被攻击者大量 ping 淹没。^([^(308)](#fn308))

*   缓冲区溢出发生在黑客修改计算机内存或溢出缓冲区限制时，覆盖内存位置以控制程序执行，并将恶意代码插入程序内存中。^([^(309)](#fn309))

*   黑客的目标是在系统将执行的内存位置中插入恶意代码。缓冲区是临时存储区域，例如 RAM，其中数据在计算设备中保存。为了缓解缓冲区溢出攻击，地址空间布局随机化（ASLR）已被用作成功的防御。^([^(310)](#fn310))
