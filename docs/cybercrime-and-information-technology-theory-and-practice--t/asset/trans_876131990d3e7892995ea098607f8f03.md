

# Access Point (AP)

Access Point (AP) 或 Wireless Access Point (WAP) 是一种网络设备，包含无线电发射器和接收信号，使其他计算设备能够连接到网络并相互通信 ([Figure 5.9](#c5.xhtml#f5.9))。访问点可以通过以太网电缆或 Wi-Fi 信号连接路由器、交换机和集线器。它可以解决网络问题，例如，当我们想要在特定区域启用 Wi-Fi 访问，但不在路由器范围内时。解决方案是安装一个访问点，并从访问点到服务器布设一根以太网电缆。这种小型有线连接允许无线网络在指定区域广播。访问点在 OSI 模型的第 2 层——数据链路层运行。我们将在本章后面讨论 OSI 模型。

# Bridge

桥接器是一种网络设备，用于连接两个或多个网络或网段。桥接器负责通过检查传入流量并决定是转发还是过滤（阻止）来调节流量，从而减少不必要的流量。桥接器还可以存储 MAC 地址。

# Data Packets

数据包是在 TCP/IP 网络上发送的数据单元，目标是高效、可靠地传输数据。当我们通过互联网发送内容时，数据会被分成小块（使用特定的字节大小），以确保每个部分都能成功传输，并适应各种带宽。通过将数据分成多个部分，数据包可以避免因同时传输而引起的网络拥塞，并可以通过不那么拥塞的路径重新路由。当电子邮件离开计算设备时，网络会将其拆分为数据包。当数据包到达目的地时，它们会被重新组装并按顺序组合成一个文件。可以将其视为邮寄拼图。每个拼图块通过哪条路线邮寄并不重要，只要所有拼图块都到达目的地，收件人就能将形状组合成一幅图像。当我们接收电子邮件或网页时，情况则相反。我们将在与 OSI 模型相关的部分进一步讨论数据包。

数据包包含传送信息和发送方的实际数据。数据包的精确构成因协议而异，但典型的数据包包含三个部分：头部、有效载荷和尾部或页脚。例如，在互联网协议第 6 版 (IPv6) 中，每个数据包的第一部分是 IPv6 头部。IPv6 将在本章后面描述。IPv6 头部的主要组件如下。^([^(261)](#fn261))

## Version

Version 指示 IP 的版本。头部大小为 4 位。

## Traffic Class

Traffic Class 指定 IPv6 数据包的类或优先级设置。其大小为 8 位。

*   **Flow label**: 指定数据包属于特定序列。示例包括语音和视频等实时数据。大小为 20 位。

*   **Payload length**: 定义 IPv6 有效载荷的长度（以八位字节为单位）。八位字节是衡量数字信息的单位，由 8 位组成。大小为 16 位。

*   **Next header**: 指示第一个扩展头部或协议数据单元 (PDU) 的类型。这可能是 TCP、用户数据报协议 (UDP) 或其他协议。大小为 8 位。

*   **Hop limit**: 指定 IPv6 数据包在被释放前可以经过的最大链路数。大小为 8 位。

*   **Source address**: 源 IPv6 主机地址。大小为 128 位。

*   **Destination of IPv6 address**: 存储目标主机。大小为 128 位。

有效载荷将实际数据传送到目的地，而尾部包含关于数据包目的地的信息。

# Dynamic Host Configuration Protocol (DHCP)

动态主机配置协议 (DHCP) 是负责向客户端计算机分配动态 IP 地址及其他相关配置信息的客户端或服务器。

# Domain Name System (DNS)

域名系统 (DNS) 是整个互联网 IP 地址的目录。DNS 将人们可以记住的域名转换为 IP 地址，或将主机名映射到 IP 地址。换句话说，DNS 允许人们在搜索时使用单词代替 IP 地址。例如，当我们在浏览器中输入 [www.CISCO.com](http://www.CISCO.com) 时，浏览器会要求 DNS 查找 IP 地址。DNS 将返回 CISCO 域名的 IP 地址 (72.163.4.185)，浏览器将连接到该 IP 地址。用户可以在 Windows 命令提示符或 Linux 终端中输入 `C:\> nslookup` 来查找 IP 地址或网站。查找 IP 地址的另一种方法是使用 ARIN WHOIS IP Address Database Search^([^(262)](#fn262))

除了将域名转换为 IP 地址之外，DNS 还具有反垃圾邮件防御功能，包括资源公钥基础设施 (RPKI) 等路由安全功能，用于保护互联网的路由基础设施和防火墙。^([^(263)](#fn263))

另一种为与 SPF 相同目的而创建的标准是域密钥识别邮件 (DKIM)。^([^(264)](#fn264))

网络犯罪分子使用网络钓鱼攻击，创建看起来真实的假网站，诱使用户点击网站上的链接，然后泄露个人信息。这些假域名冒充合法网站，但拥有完全不同的 IP 地址。

DNS 至关重要，因为它保护用户和企业免受网络钓鱼攻击。因此，用户计算机与 DNS 系统之间的通信对于将正确的 IP 地址分配给域名至关重要。通常，互联网服务提供商 (ISP) 会自动分配其默认 DNS 服务器，但可以将系统的 DNS 设置更改为其他免费且安全的服务，例如 Google Public DNS。^([^(265)](#fn265))

# Gateway

网关或协议转换器是网络设备（节点），可以作为软件、硬件或两者的组合，用于连接两个不同的网络。网关是网络之间的入口或出口点。网关从一个网络获取数据，对其进行解释，并将其传输到另一个网络。网关通常很复杂，由于位于网络边缘，它们集成到路由器、防火墙、服务器或其他能够使流量进出网络的设备中。如果没有网关，我们将无法与本网络之外的设备、节点或网络进行通信。
