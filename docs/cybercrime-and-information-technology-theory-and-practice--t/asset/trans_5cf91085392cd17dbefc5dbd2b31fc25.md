

# Standards

标准是组件和系统制造商制定的一套规则，用于定义如何在不同环境下进行通信。例如，基于以太网的网络由 IEEE 802.3 标准定义，该标准由 IEEE 发布；而蓝牙设备由 Bluetooth Low Energy 5.1 定义，这是一种用于短距离交换数据的无线技术标准。

# Switches

交换机是多端口设备，用于连接网络中的计算设备并充当控制器。交换机与集线器不同，因为它们处理数据包的方式不同，即执行错误检查，并且不转发带有错误的数据包。因此，交换机提高了效率和性能。此外，交换机是七层 OSI 模型中数据链路层或第二层的设备（见 OSI 模型），它允许网络上的设备相互通信，也可以与其他网络通信。交换机在 OSI 模型的第 2 层——数据链路层上运行（[Figure 5.20](#c5.xhtml#f5.20)）。

# Virtualization in computing

计算机虚拟化或 VM 是一种技术，通过分配功能并使单台机器充当多个模拟设备，来创建基于软件或虚拟的服务（如操作系统和服务器）。虚拟化是一种节省成本的方法。虚拟机监控程序是创建和管理虚拟机的软件（[Figure 5.21](#c5.xhtml#f5.21)）。

## [5.2 Types of Networks](#contents.xhtml#re_h-5-9)

为了满足不断变化的需求和需求，已经设计了不同类型的网络。

最常见的网络类型（[Figure 5.21](#c5.xhtml#f5.21））如下：

![FIGURE 5.21 A Typical Network.](images/fig5.21.jpg)

**FIGURE 5.21** A Typical Network.

*   **CAN (Campus Area Network)**: 顾名思义，这种类型的网络专为校园、学院、学校和大学等教育机构设计。CAN 网络比 LAN 大，比广域网（WAN）小（[Figure 5.22](#c5.xhtml#f5.22)）。

*   **PAN (Personal Area Network)**: 它是一种短程网络，顾名思义，为一个人服务。例如，使用移动设备上的应用程序（如腕式健身追踪器、心率监测器或计步器）与蓝牙设备配合使用是一种 PAN。当一个人连接任何两个设备（例如手机和计算设备）或共享电子邮件、照片、短信等时，这也在个人区域网络中完成（[Figure 5.23](#c5.xhtml#f5.23)）。

*   **LAN**: 它是一种中程网络，覆盖单个房间、建筑物或一组建筑物、办公室、工厂或学校内的区域，允许共享数据、文件和资源。LAN 可能连接学校或建筑物中的所有计算机，并可能包含有线和无线设备（[Figure 5.24](#c5.xhtml#f5.24)）。

*   **MAN (Metropolitan Area Network)**: 它是一种长程网络，提供的通信范围比 LAN 大，比 WAN 小。示例包括全市范围的网络；政府机构通常拥有和管理 MAN（[Figure 5.25](#c5.xhtml#f5.25)）。

*   **WAN (Wide Area Network)**: 它是最大的区域通信网络。它可以跨越大型地理区域，并可以连接一个国家内的多个网络，从地区到地区或遍及全球。最大的 WAN 是互联网，连接全球数百万个网络。WAN 连接可以通过租用光纤线路和卫星链路实现。

*   **WLAN (Wireless Local Area Network)**: 它类似于传统的 LAN，但使用高频无线电波而不是以太网电缆来无线连接和通信（[Figure 5.26](#c5.xhtml#f5.26)）。

*   **Virtual Local Area Network (VLAN)**: 它是一个或多个 LAN 中不同节点的逻辑连接，而不是物理连接。此外，LAN 被配置为仿佛物理连接一样进行通信。^([^(284)](#fn284))

*   **VPN (Virtual Private Network)**: 它是互联网上过境流量的点对点安全网络连接。重要的是，VPN 通过加密个人隧道并包围用户身份来建立一定的隐私。更具体地说，它将用户的流量通过 VPN 服务器进行路由，并掩盖用户的原始 IP 地址，充当中间人。因此，路由到 VPN 服务器、掩盖 IP 地址和私有隧道加密的混合使得网络犯罪分子、政府和 ISP 更难进行窃听（[Figure 5.27](#c5.xhtml#f5.27)）。

## [5.3 Network Topology](#contents.xhtml#re_h-5-10)

网络拓扑显示网络的布局及其节点和链路如何结构化以转发、接收、发送和存储数据。网络拓扑由两个类别组成：物理拓扑（包含设备、维护和线缆）和逻辑拓扑（描述网络传输方式以及数据流动方式）。

正确的拓扑通过在网络中高效分配资源来提高性能，并有助于查找错误。以下是最常见的网络拓扑类型。

*   总线网络拓扑或线性拓扑是指所有网络节点和计算设备都连接到一根中心连续电缆上的单一方向。更具体地说，数据向一个方向移动并遵循中心电缆的路由。总线网络拓扑具有简单的布局，是较小网络的一种经济有效的方法。然而，这种拓扑可能易受攻击，因为网络基于一根中心电缆，如果电缆失效，整个网络将瘫痪（[Figure 5.28](#c5.xhtml#f5.28)）。

*   当网络节点和计算设备具有多个路径或重叠连接时，使用网状拓扑。网状拓扑有两种类型：全连网状拓扑（网络中的每个节点都连接到其他每个节点，见 [Figure 5.29](#c5.xhtml#f5.29)）和部分网状拓扑（[Figure 5.30](#c5.xhtml#f5.30），其中仅选定的节点相互连接，其他节点仅连接到网络中的一台或两台设备，见 [Figure 5.30](#c5.xhtml#f5.30)）。网状拓扑提供可靠性和鲁棒性，因为它提供冗余以避免故障；一个链路不会导致网络或数据传输中断，也不会影响其他链路。尽管如此，全连网状拓扑可能因布线成本而昂贵。其实施也耗时且劳动密集。另一方面，部分网状拓扑提供的冗余较少，实施成本较低。

*   点对点拓扑是两个直接相互连接的节点之间最简单的通信连接。示例包括两台计算机之间的连接（[Figure 5.31](#c5.xhtml#f5.31)）、两台路由器之间的连接（[Figure 5.32](#c5.xhtml#f5.32)）以及两个段之间的连接（[Figure 5.33](#c5.xhtml#f5.33)）。
