### [ASCII、EBCDIC 和 UNICODE](#contents.xhtml#re_h-1-12)

ASCII 是 American Standard Code for Information Interchange 的缩写。**.** 该标准建立于 20 世纪 60 年代，如今已很少使用，最初是为了作为使用英文字母的计算机之间的通用语言而创建的。原始 ASCII 代码将 128 个字符表示为标准数值，包括小写和大写字母、符号、数字、标点符号和控制字符。每个字符都被分配一个 0 到 127 之间的数字，并包含 7 位代码，这意味着七位中有 128 个不同的字符，包括设置为 0 或 1 的七个数字，即真或假，是或否，开或关。除了可打印字符外，ASCII 代码还包含控制文本处理方式的不可打印字符。^([⁵](#fn5))

另一种编码系统是扩展二进制编码十进制交换码（Extended Binary Coded Decimal Interchange Code，EBCDIC），由国际商业机器公司（IBM）在 20 世纪 50 年代末和 60 年代初开发。^([⁶](#fn6))

### [布尔代数、逻辑门和真值表](#contents.xhtml#re_h-1-14)

如上所述，我们通过代表 1 和 0 的电线将位发送到计算机。计算机使用逻辑门使这些 1 和 0 能够执行更复杂的操作。

逻辑门是基于布尔函数的设备，用于在任何数字系统中实现逻辑操作。计算机内部的微型电子电路是最基本的构建块，根据逻辑函数，使用一个或多个输入来产生单个输出（1 或 0）。简单来说，逻辑门控制电流通过电路的流动。某些电路可能只有几个逻辑门，而另一些电路（如微处理器中的电路）可能有数百万个逻辑门。当计算机使用数百万个逻辑门时，就可以执行高度复杂的操作。

逻辑门是计算机和其他现代数字电子设备的基础。它们用于微处理器和微控制器，并嵌入到移动设备和物联网设备等系统应用中，这些设备集成了硬件电路和软件编程技术。

要理解逻辑门**，**我们需要了解乔治·布尔（George Boole）的工作，他是布尔代数的发明者。他的数学是计算机科学的基础。乔治·布尔是 19 世纪中叶的英国数学家，他开发了超越亚里士多德数学逻辑的逻辑陈述。布尔于 1847 年撰写了《逻辑的数学分析》（*The mathematical analysis of logic*）*。*^([⁷](#fn7))

在布尔代数中，变量的值仅表示为真或假，而在普通代数中，变量的值涉及数字、变量和操作。此外，布尔操作根据一组规则，接受特定输入并产生特定输出。逻辑门实现基本逻辑功能，是数字集成电路的重要构建块。

三个基本逻辑门是 NOT、AND 和 OR。其他门包括 XOR、NAND、NOR 和 XNOR。所有门都由符号和真值表表示。真值表帮助我们理解电路的工作原理。以下是三个基本逻辑门及其符号和真值表。

*   NOT 门是最简单的逻辑门，也称为反相器。NOT 门只有一个输入和一个输出。输出是输入的反向，因此如果输入是 0，输出必须是 1，反之亦然。该门将真翻转为假，将假翻转为真。
