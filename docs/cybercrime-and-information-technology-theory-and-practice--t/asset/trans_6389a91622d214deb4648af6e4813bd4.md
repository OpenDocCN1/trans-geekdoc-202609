

The `Ping of Death`: 此攻击类似于 `Smurf` 攻击。当黑客通过向目标发送具有 IP 头部允许最大值的大数据包来操纵 IP 协议时，就会发生此攻击。当目标计算设备尝试重新组装这些大数据包时，数据包会使网络资源过载，导致缓冲区溢出，从而使网络变慢或操作系统崩溃。这会导致合法数据包无法提供服务。^([^(311)](#fn311))

`分布式拒绝服务 (DDoS)` 攻击更为先进。当多个计算系统协调发起同步攻击时，就会发生此攻击。黑客利用安全漏洞控制多台计算机，并将其转变为僵尸网络或僵尸（僵尸计算机）。随后，黑客使用这些僵尸攻击其他计算机或网络。僵尸网络可以由少量僵尸或数千个僵尸组成，分布在世界各地。这些受感染的计算机通过命令和控制服务器进行管理。DDoS 攻击为黑客提供了访问大量受损计算设备的机会。[图 6.14](#c6.xhtml#f6.14) 演示了典型的 DDoS 攻击。

除了上述可被 DDoS 利用的 DoS 攻击之外，最常见的 DDoS 攻击包括：

*   `用户数据报协议 (UDP) 洪水攻击` 类似于 `ping 洪水攻击`。攻击者向目标网络发送大量 UDP 数据包。由于 UDP 协议是无连接的，因此在数据传输发生之前，不需要在源和目标之间建立任何链路。此类攻击的目标是向远程主机的随机端口发送数据。由于没有建立连接，目标计算机无法找到发送数据的应用程序，并告知发送方目标不可达。此过程会消耗主机资源，最终可能导致拒绝服务。为了防御 UDP 洪水攻击，防火墙会阻止恶意 UDP 数据包，并结合使用 IP 路由技术，以防止攻击者使计算系统不堪重负。^([^(312)](#fn312))

*   `Slowloris 攻击` 发生在攻击者通过发送大量 HTTP 请求使目标服务器不堪重负，以至于服务器无法再建立任何连接时。攻击者使用的是合法的 HTTP 请求。因此，服务器被迫无限期地保持现有连接打开。为了保持连接打开且活跃，攻击者会定期向服务器发送部分请求（HTTP 头部），表示：“嘿，服务器，我还在这里。”因此，这些未完成的请求会耗尽带宽，并影响服务器响应其他流量请求的能力。^([^(313)](#fn313))

*   `零日 DDoS 攻击` 或 `0-day` 是一个统称，用于指代所有利用尚未被发现的漏洞的未知新型 DDoS 攻击。由于这些类型的攻击不为人所知，因此具有极强的破坏性，因为目标没有防御。换句话说，新攻击可以被称为向量的零日漏洞。^([^(314)](#fn314))

#### [6.3.2.1 著名的 DDoS 攻击](#contents.xhtml#re_h-6-8)

*   2020 年 Amazon Web Services 大规模 DDoS 攻击。该攻击持续了 3 天，峰值达到每秒 2.3 太字节。^([^(315)](#fn315))

*   2018 年针对 GitHub（软件开发托管平台）的 DDoS 攻击。GitHub 瞬间遭受了每秒 1.35 太字节的流量攻击。^([^(316)](#fn316))

*   2016 年，Mirai 恶意软件感染了运行 Linux 的物联网 (IoT) 设备，将其转变为远程控制的僵尸，从而发起 DDoS 攻击。^([^(317)](#fn317))

*   2013 年，反垃圾邮件组织 `spamhaus.org` 遭受了 DDoS 攻击，攻击流量估计每秒超过 300 吉比特。^([^(318)](#fn318))

#### [6.3.2.2 DoS 攻击工具](#contents.xhtml#re_h-6-9)

一些最常见且免费的 DoS 攻击工具如下：

*   `DoSHTTP`，一款易于使用且功能强大的 DoS 工具，可生成 HTTP 洪水攻击

*   `High Orbit Ion Cannon (HOIC)`，旨在同时使用 HTTP（超文本传输协议）攻击多个 URL

*   `HTTP Unbearable Load King (HULK)`，一款为每个 Web 服务器请求生成唯一需求的 DoS 攻击工具

*   `Layer 7 DDoS Simulator (DDOSIM)`，一款模拟具有完整 TCP 连接的多个僵尸主机的 DoS 攻击工具

*   `Low Orbit Ion Cannon (LOIC)`，一款开源的网络压力测试和 DoS 攻击应用程序

*   `R-U-Dead-Yet`，一款 HTTP POST DoS 攻击工具

*   `Tor’s Hammer`，一款使用 HTTP POST 请求进行低速攻击的攻击工具

*   `XOIC`，一款适用于任何具有 IP 地址的服务器的 DoS 攻击应用程序

### [6.3.3 恶意软件](#contents.xhtml#re_h-6-10)

恶意软件是“恶意软件”的缩写，包括计算机病毒、蠕虫、特洛伊木马、勒索软件、间谍软件以及其他类型的破坏性软件或代码。恶意软件在用户不知情的情况下，会损害或渗透计算设备或系统以执行特定的破坏行为。Java 脚本通常用于将恶意软件放置在受害者的计算设备上。^([^(319)](#fn319))

*   `病毒` 是一种恶意代码或程序，在首次执行后会从一台计算机复制并传播到另一台计算机。计算机病毒需要 `宿主程序` 和 `用户操作`。通常，病毒会附加到计算机程序、文件或文档上。例如，恶意宏感染可以附加到 Word 或 PDF 文件上。为了使此代码感染计算设备，用户必须运行受感染的程序，然后执行的代码可以将病毒传递给设备。

*   `特洛伊木马` 以著名的木马命名，该木马欺骗了特洛伊人，并使古希腊人得以攻陷特洛伊城。特洛伊木马是伪装成合法软件的脚本或计算机程序。相反，它们是各种威胁的载体。例如，当用户无意中从被认为安全的网站下载实用程序、游戏或电影并运行它，或打开包含受感染文件的附件时，可能会发生以下情况：

*   可能会打开后门，为黑客提供未经授权的远程访问。

*   会发生利用软件或硬件弱点的漏洞攻击。

*   会安装有害软件或删除文件。

      一些特洛伊木马的例子是 `Zeus` 或 `Zbot 特洛伊木马` 恶意软件，该软件攻击了美国交通部。^([^(320)](#fn320))

*   `勒索软件` 攻击发生在黑客使用恶意软件（通常是恶意软件或网络钓鱼垃圾邮件）锁定和加密受害者的数据，直到受害者支付加密货币赎金为止。即使支付后，数据也可能无法使用。

      CISA、FBI 和 HHS（美国卫生与公众服务部）发布了勒索软件报告警报。^([^(321)](#fn321))

*   勒索软件通常预示着漫长网络攻击链或网络杀伤链的结束。攻击者通常花费许多天或几周时间，在受害者的网络中为勒索软件奠定基础。
