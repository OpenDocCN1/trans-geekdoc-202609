

# Hub

一个 `hub`（集线器）连接计算设备，并通过向其他连接的计算设备广播数据包，在专用网络或局域网（`LAN`）中充当连接点（[图 5.13](#c5.xhtml#f5.13)）。由于数据包将留在本地网络中，集线器不执行过滤或路由。在专用网络中使用多个集线器的缺点是，当两个或多个设备同时发送数据时，可能会发生 `collision`（冲突）。另一个弱点是，当可用带宽在连接的设备之间拆分时，速度会变慢。集线器在 OSI 模型的第 1 层——物理层运行。带宽定义为单位时间内通过网络路径传输的最大数据速率，以每秒比特为单位。

# IP Address

`Internet Protocol address`（`IP 地址`）是分配给 TCP/IP 网络上每个计算设备的唯一标识符。IP 地址有两个主要功能：它标识主机或网络接口标识以及位置寻址。当计算设备向另一台设备发送数据时，数据头包含发送设备的 IP 地址以及目标设备的 IP 地址信息。IP 地址就像计算机的物理家庭地址，决定邮件应投递到哪里。1982 年，当 TCP/IP 成为 ARPANET 的官方协议时，IP 地址首次出现。如前所述，现代 TCP 的第一个版本由 Cerf 和 Kahn 于 1973 年编写。

第一个和第二个互联网协议，IPv1 和 IPv2，从未定义；IPv3 和 IPv5 是实验性的。互联网协议 4，IPv4，是第一个公开使用的版本，并带有 43 亿（`2^(32)`）个地址的理论限制。迄今为止，IPv4 是部署最广泛的版本。但是，随着互联网的指数级增长，IPv4 的 IP 地址已耗尽，尤其是在移动设备和 IoT 设备出现之后。因此，在 1998 年，互联网工程任务组（`IETF`）创建了 IPv6 来解决这个问题。^([^(266)](#fn266))

负责分配和维护全球 IP 地址的组织是互联网号码分配机构（`IANA`）。^([^(267)](#fn267))

- `IPv4`，首次部署于 1983 年，使用 32 位地址，可处理 4,294,967,296（`2^(32)`）个唯一地址。它仍然是最广泛使用的 IP 版本。^([^(268)](#fn268))
- `IPv6` 使用 128 位地址，理论上可提供 `2^(128)` 个唯一地址。它提供约 340 万亿万亿万亿个组合，称为 undecillion，或 sextillion 或 dodekillion，等于 `10^(36)`。与以点分十进制表示法编写的 IPv4 不同，IPv6 使用十六进制表示法编写。IPv6 为美国华盛顿州雷德蒙德的微软公司提供的 IP 地址示例是 `2a01:111: f400:5254::2`。

## [5.1.5 IPv6 的基本解剖结构](#contents.xhtml#re_h-5-7)

IPv6 将地址分为两个 64 位段，并由八个 16 位十六进制值或块组成，用冒号（`:`）分隔。

例如，如果将十六进制 `2001` 转换为二进制，结果为 `0010 0000 0000 0001`，如果将十六进制 `1234` 转换为二进制，结果为 `0001 0010 0011 0100`。有关十六进制和二进制的更多信息，请参阅 [第 1 章](#c1.xhtml#c1)。下图演示了 IPv6 在十六进制中的结构。左侧四个值或块指示网络 ID，由管理员分配。右侧四个值或块指示主机或接口 ID，手动或自动配置（例如 `DHCPv6` 或随机生成的数字）。如果将每个值或块视为地址，街道在左侧网络端，房屋号码在右侧。[图 5.15](#c5.xhtml#f5.15) 表示 IPv6 地址的许多不同配置之一。

![FIGURE 5.15 IPv6 structure.](images/fig5.15.jpg)

**FIGURE 5.15** IPv6 结构。

更具体地说，网络 ID 侧分为两个较小的部分，即 48 位的 `routing prefix`（路由前缀）和 16 位的 `Subnet ID`（子网 ID）（见图）。`routing prefix` 包含全球网络地址，由 ARIN 或 ISP 分配。此部分用于互联网上的路由。第二部分，`subnet`（子网），由客户端在内部网络上创建，并由网络管理员控制。`subnet` 或 `a subnetwork`（子网）是较大网络结构的一个段，或是网络中的网络。`Subnetting`（子网划分）已被管理员用于使网络更高效，允许流量行进更短的距离。最后一部分，`Interface ID`（接口 ID），是连接到网络的主机或节点的唯一标识符。^([^(269)](#fn269))

IPv6 的前两个块显示 IP 地址来自哪个块。块编号上方的数字指示 ARIN 的特定 IPv6 分配块。^([^(270)](#fn270))

由于 IPv6 规范异常冗长，该协议允许我们通过省略前导零来缩短地址。例如，在块 5 中，十六进制 `0054` 可以变为 `54`。

如果在连续块（如块 6 和 7）中有连续的零，则可以省略它们并用双冒号 `(: :)` 替换。然后，IPv6 看起来像这样：`2001:0:1234:5678:54::FEFC`。

在 IP 世界中，有两种类型的 IP 地址：`static and dynamic`（静态和动态）。`static IP`（静态 IP）在设备退役前不会改变。这种类型的 IP 由互联网服务提供商（`ISP`）或网络管理员分配。

- `static IP` 地址分配给重要的外部计算设备、服务器（Web 服务器、电子邮件服务器、网络内共享的打印机）或需要使用 IP 地址以便其他设备能快速连接到它的网站。另一个示例是虚拟专用网络（`VPN`）。由于虚拟专用网络（`VPN`）信任特定 IP，静态 IP 地址提供了一种更轻松的方式来定位设备、更轻松地设置它，并通过 DNS 服务器获得更好的支持。这使得使用 VPN 远程工作更加容易，并在使用互联网语音协议（`VoIP`）和视频会议进行通信时提供更好的可靠性。然而，与这些优势一起，`static IP` 最显著的缺点是安全性降低。黑客等网络犯罪分子知道互联网上每个服务器的位置，而静态 IP 使攻击更容易，因为它无法伪装。另一个缺点是 ISP 通常对 `static IP` 地址收取更多费用。
