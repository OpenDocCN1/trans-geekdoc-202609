

## II. 传输层（OSI 模型中的第 4 层）

此层实现主机与主机之间的数据通信。传输协议示例包括 `TCP` 和 `UDP`。这两种传输协议均在 `IP`（互联网协议）之上运行，用于将称为数据包的数据位从物联网设备发送到不同的路由器。

### DTLS

`DTLS`（数据报传输层安全协议）是一种提供卓越安全性的通信协议。该协议已被 `CoAP`（受限应用协议）和 `IPsec`（互联网协议安全）用于在 IP 网络上的两个通信点之间进行身份验证、完整性保护和加密。^([^(379)](#fn379))

### UDP

`UDP`（用户数据报协议）是一种更快的通信协议，但可靠性较低。该协议的工作方式与 `TCP` 类似，将数据分割为称为数据报或数据包的较小单元。这两种协议均基于 `IP` 构建，并都在互联网上从一个 IP 地址发送数据到另一个 IP 地址。与 `TCP` 不同，`UDP` 不保证数据传输，且开销更小，不提供数据包已接收的确认。这加快了连接速度并降低了延迟，但降低了可靠性。使用此协议时，计算设备向另一台设备发送数据包而不保证传输；这是一种“发送即忘记”的方法。`UDP` 比 `TCP` 更快，因为它省去了错误检查和恢复服务等功能。它选择速度而非完整性，接收到的数据可能与发送的数据不完全一致。`UDP` 更快，而 `TCP` 更可靠。`UDP` 用于流式游戏、直播和视频。

### TCP

`TCP` 是一种更可靠的基于连接的主机到主机协议。其速度比 `UDP` 慢，但 `TCP` 的更高可靠性保证了更少的错误。发送的数据包会被跟踪，因此传输过程中不会丢失或损坏数据。与 `UDP` 不同，`TCP` 要求接收方和发送方进行通信并建立连接，确认数据包已接收。如果接收方未确认数据包，则会重新发送。因此，这种来回通信使得 `TCP` 比 `UDP` 更慢。

## III. 互联网层（OSI 模型中的第 3 层）

在此层中，路由器在源主机和目标主机之间传输数据包。物联网设备使用逻辑 IP 寻址与路由器通信，以在不同网络之间传递信息数据包。以下是路由器使用的一些协议：

### IPv4

`IPv4`（互联网协议）使用 32 位地址，可处理 4,294,967,296（`2^(32)`）个唯一地址。由于 `IPv4` 地址目前正在耗尽，该协议正在切换到 `IPv6`。

### IPv6

`IPv6`（互联网协议）使用 128 位地址，理论上可提供 `2^(128)` 个唯一地址。

### RPL

`RPL`（低功耗和损耗网络路由协议）适用于无线网络和低功耗物联网设备。它是一种简单且互操作的网络协议，且资源受限。^([^(380)](#fn380))

### 6LoWPAN

`6LoWPAN`（低功耗无线个人区域网络标准）使物联网设备能够通过无线网络传输 `IPv6` 数据包。^([^(381)](#fn381))

## IV. 网络接入层（OSI 模型中的第 1-2 层）

此层监督物联网设备如何通过以太网有线电缆或无线无线电波技术（使用 Wi-Fi 标准）物理连接到网络。除此连接外，物联网设备还连接到介质访问控制（`MAC`）及其协议。`MAC` 地址是分配给每个设备的唯一识别号，用于将设备连接到网络。此地址由制造商烧录到每个设备的硬件中。此层中的一些协议包括以下内容：

### Bluetooth

`Bluetooth` 是一种低功耗、短距离无线通信协议，已成为物联网生态系统中电池供电传感器和执行器等资源受限设备的核心无线技术。`Bluetooth` 最初由蓝牙专业兴趣小组构思为一种无线替代方案，并使用 2.4 GHz 工业、科学和医疗（`ISM`）频段（2,400 至 2,483.5 MHz）。其范围为 100 米。^([^(382)](#fn382))

### 蜂窝技术

`Cellular technology` 启用移动通信并解决低功耗物联网通信问题。例如，低功耗广域网（`LPWAN`）使用现有蜂窝技术广泛应用于无线传感器和执行器等低功耗物联网设备。蜂窝技术包括第四代蜂窝无线（`4G LTE`）长期演进，以及新兴的第五代蜂窝无线（`5G`）。`LTE-advance`（`LTE-A`）专为蜂窝网络中的物联网通信而设计。^([^(383)](#fn383))

### Dash7

`Dash7` 是一种用于无线传感器、执行器和消息传递应用的无线通信协议。该协议由 `DASH7` 联盟开发，并基于 `ISO/IEC 18000-7`。^([^(384)](#fn384))

### Ethernet

`Ethernet` `IEEE 802.3` 是一整套标准和协议族，定义了局域网（`LAN`）中的有线连接，包括布线、信号、连接器、协议规则等方面的标准。更准确地说，它定义了有线 `Ethernet` 网络的物理层和数据链路层的 `MAC` 地址（硬件地址）。^([^(385)](#fn385))

### NFC

`NFC` 是一组短距离无线通信协议，使用电磁场实现与其他设备的通信和无线数据传输。^([^(386)](#fn386))

### RFID

`RFID` 是一种使用射频波从远处读取电子标签的无线技术。^([^(387)](#fn387))

### Wi-Fi IEEE 802.11

`Wi-Fi IEEE 802.11` 是一种基于 `IEEE` 无线通信标准 `802.11` 的无线网络协议。`Wi-Fi` 联盟负责认证 `Wi-Fi` 产品，包括一些最新标准，如 `802.11ax Wi-Fi 6`、`802.11ac Wi-Fi 5` 和 `802.11n Wi-Fi 4`。^([^(388)](#fn388))

### ZigBee

`ZigBee` 是一种基于 `IEEE 802.15` 标准的低功耗、低数据速率、近距离（即个人区域网络）无线通信协议。^([^(389)](#fn389))

## [7.4 物联网设备的网络注意事项](#contents.xhtml#re_h-7-17)

除协议和标准外，物联网生态系统还需要 `bandwidth`、`interoperability`、`power usage` 和 `range` 才能成功部署。

### I. 带宽

带宽定义了单位时间内通过网络路径传输的数据的最大速率。“在物理层通信中，带宽一词与电磁信号的频谱宽度或通信系统的传播特性相关。”^([^(390)](#fn390))

### II. 互操作性

互操作性是指物联网设备与其他现有设备（如使用标准和协议的设备和系统）协同工作和良好交互的能力。鉴于可以连接的大量不同物联网生态系统，互操作性差可能会导致严重问题。制造商采用标准和协议一直是提供良好互操作性的长期既定方法。

### III. 功耗
