

当代可移动无线通信设备的需求日益增加，它可以将多种通信标准集成到单一系统中。由于空间有限，在此类设备中同时容纳两个或多个天线是困难的。“这表明现代天线除了实现双频或多频操作外，还需要具备其他任务，例如紧凑尺寸、简单结构以及易于与系统集成” [[1](#ch25.xhtml#ref25_1)]。由于其简单、低剖面且价格低廉的独特品质，微带贴片天线非常受欢迎。它们与单片微波集成电路兼容且易于安装 [[2](#ch25.xhtml#ref25_2)]。全球微波接入互操作性（WiMAX）是一种非常流行的无线通信系统，最近受到了研究人员的大量关注，并已在移动设备中实现。天线应覆盖多个频段并能够提供一致的全向辐射模式，以增强性能并使天线在复杂多变的 WiMAX 环境中有用 [[3](#ch25.xhtml#ref25_3)]。此外，低频段（2500 至 2690 MHz）、中频段（3300 至 3700 MHz）和高频段（5250 至 5850 MHz）是 WiMAX 被分配的三个主要频段 [[4](#ch25.xhtml#ref25_4)]。文献中最近提出了许多用于 WiMAX 和超宽带（UWB）的多频带天线。例如，在 [[5](#ch25.xhtml#ref25_5)] 中，作者提出了一种用于 7.5 GHz 无线通信的矩形贴片天线，其回波损耗低，天线尺寸较大 32 × 28.1 mm²，且仅有一个频段。一种用于多频带应用的可携式共面波导（CPW）馈电天线在 [[6](#ch25.xhtml#ref25_6)] 中被提出，天线尺寸相当小但结构复杂。

[[7](#ch25.xhtml#ref25_7), [8](#ch25.xhtml#ref25_8), [9](#ch25.xhtml#ref25_9), [10](#ch25.xhtml#ref25_10), [11](#ch25.xhtml#ref25_11), [12](#ch25.xhtml#ref25_12), [13](#ch25.xhtml#ref25_13) 和 [14](#ch25.xhtml#ref25_14)] 中也有多频带无线应用的设计。在参考文献 [7](#ch25.xhtml#ref25_7)、[8](#ch25.xhtml#ref25_8)、[9](#ch25.xhtml#ref25_9) 和 [10](#ch25.xhtml#ref25_10) 中，尽管所建议的天线具有良好的品质但尺寸较大。

因此，通过文献分析确定，构建天线以支持三频特性并具有更好的增益，这已作为本研究工作的目标。在本文中，我们的目标是设计一种小型化单极子三频矩形贴片天线，用于 WiMAX 和 C 频段应用。天线设计在地平面上结合了三条带状线和一个寄生元件以实现多频带特性。目标是覆盖 WiMAX 在 3.5 和 5.5 GHz 的频率，以及 C 频段在 7.5 GHz。使用高频结构仿真器（`HFSS`），研究了参数对阻抗带宽的影响。根据仿真结果，所提出的天线设计适用于 WiMAX 和 C 频段应用。这意味着天线在指定频率范围内表现出所需的性能特性，例如适当的阻抗匹配和辐射特性。

## 2. 天线结构和尺寸

## 3. 参数分析

为了使天线最优，选择 `Fw`、`Lg` 和 `W4` 进行研究。对于不同的 `Fw` 值，[图 25.4](#ch25.xhtml#fig25_4) 显示了回波损耗。当馈电线宽度（`Fw`）设置为 2.9 mm 时，上 WiMAX 频段和 C 频段频率相比于一些期望频率略微向较低频率偏移。这意味着天线在这些频段的谐振频率略低于预期。因此，可能存在一些阻抗失配，这可能导致更高的回波损耗（源反射的信号较弱）和这些频率下天线效率降低。另一方面，当馈电线宽度（`Fw`）增加到 3.1 mm 时，天线表现出低回波损耗。这意味着天线与期望频率匹配更好，从而改善信号传输和接收特性。阻抗匹配可能对这些频率最佳，导致信号反射最小。然而，当 `Fw` 精确设置为 3 mm 时，天线显示出最佳的整体性能。它不仅提供良好的回波损耗，还提供适当的阻抗匹配。
