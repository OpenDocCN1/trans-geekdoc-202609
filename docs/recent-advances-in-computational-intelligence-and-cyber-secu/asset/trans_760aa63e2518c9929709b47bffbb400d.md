## 3.2. 预测和推荐程序

在本节中，我们首先介绍模糊集的核心概念 [[4](#ch1.xhtml#ref1_4), [17](#ch1.xhtml#ref1_17)]，这些概念用于在所提出的方法中完成预测和推荐程序。

### 3.2.1. 定义 1

对于模糊数 (`FN`) *ã*，在模糊集 *ã* 中 μ*[Ā]*(*x*) 的 λ-截集，*x* ∈ 0, 1，*ã[Ā]* = [*a*[λ], aλ^+ ]，其中 *a*[λ] 表示下界，aλ^+ 表示上界。现在区间定义为

(2)

*a**λ* = {*x**μ*[*a*]*ã*(*x*)>*λ*,*x*∈*R*}

### 3.2.2. 定义 2

我们通过三元组 (*a*^−, *a*, *a*^+) 定义三角形 `FN` = *ã* 的隶属函数 (`MF`)μ*[Ā]* 为

(3)

$${lin}\_{a}(x) = \\left\\{ \\begin{matrix} 0 & {x < a\_{0}^{-}} \\\\ \\frac{x - \\overline{a}}{a - a\_{0}} & {a\_{0} < x < a} \\\\ \\frac{a^{+} - x}{a^{+} - a} & {a < x < a^{+}} \\\\ 0 & {a^{+} < x} \\\\ \\end{matrix} \\right.$$

### 3.2.3. 定义 3

对于任意 *ãb̃* ∈ *f*^(\*)[+](*R*) 即 *R* 上所有有限正 `FN` 的集合，且 0 < δ ∈ *R* 我们有

(4)

*ã* + *b̃* = *U*[*λ* ∈ (0, 1)]*λ*\[*a**λ*^−+*b**λ*^−,*a**λ*^++*b**λ*^+\]

(5)

*λ**ã* = *U*[*λ* ∈ (0, 1)]\[*δ**a**λ*^−,*δ**a**λ*^+\]

(6)

$$\\widetilde{a} \\times \\widetilde{b} = {\\underset{\\lambda \\in 0,1}{\\cup}\\lambda}\\left\\lbrack {a\\lambda^{-} \\times b\\lambda^{-},a\\lambda^{+} \\times b\\lambda^{+}} \\right\\rbrack$$

多准则推荐系统将偏好纳入多个准则或维度，从而提供有关项目和用户的更多信息。有关多准则推荐系统的更多文献请参阅 Adomavicius 和 Kwon 的先前研究 [[4](#ch1.xhtml#ref1_4), [17](#ch1.xhtml#ref1_17)]。稀疏性一直是许多协同过滤 `RSs` 的主要缺点，这会显著影响项目推荐的准确性。`CF` 算法在评分数量较少时生成效率低下的推荐。`CF` 推荐算法需要足够数量的评分数据。聚类以及基于模糊规则的方法已在本次工作中用于解决此问题。聚类技术旨在提高推荐代理的效率 [[4](#ch1.xhtml#ref1_4), [17](#ch1.xhtml#ref1_17)]。*e 模糊逻辑方法被证明在解决 `CF` 基于推荐系统中的稀疏性问题方面是有效的 [[2](#ch1.xhtml#ref1_2), [3](#ch1.xhtml#ref1_3), [21](#ch1.xhtml#ref1_21)]。此外，Adomavicius 和 Kwon 提出的 [[4](#ch1.xhtml#ref1_4), [17](#ch1.xhtml#ref1_17)] 技术在本次工作中用于建立用户相似性（见公式 (7)），之后将其作为基于模糊的相似性计算技术应用。*e 建议方法的部署实现了两个用户的平均相似度，根据

(7)

$$\\sin\\left( {u,u^{\\prime}} \\right) = \\frac{1}{k + 1}{\\sum\\limits\_{c = 0}^{k}\\sin\_{c}}\\left( {u,u^{\\prime}} \\right)$$

推荐系统最初在在线推荐阶段发现活跃或目标用户以及活跃或目标酒店。*e 评分预测以及推荐的任务在下一阶段进行。*e 第一个任务包括根据特定活跃用户确定的优先级预测与酒店列表相关联的评分的每种算法。在第二阶段，系统包括排名，为活跃用户列出尚未评分的项目列表，之后提供 Top-N 推荐，包括推荐列表中的前 N 家酒店。
