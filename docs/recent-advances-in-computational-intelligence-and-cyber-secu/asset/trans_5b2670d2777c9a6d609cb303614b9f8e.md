# 8 通过集成 SVM-GA 进行糖尿病分类与预测

Vishal Verma^([⁸](#fn8))

## Abstract

糖尿病是全球性的健康问题。据信，全球约有 4.22 亿人患有此病。当身体因缺乏胰岛素或无法正确使用胰岛素而无法调节血糖时就会发生。鉴于其慢性特性，及早识别糖尿病变得非常重要，以便在正确的时间进行治疗。机器学习（ML）已成为糖尿病预测的有价值工具，许多研究人员已采用 ML 技术进行准确预测。其中，支持向量机（SVM）是研究人员用于早期预测糖尿病的最流行、最广泛使用的算法之一。在本文中，研究人员提出了一种集成 SVM-遗传算法（GA）方法，并将其性能与多种 ML 方法进行了评估，例如 SVM、随机森林、K 近邻（KNN）、决策树（DT）、额外树分类器（ETC）、朴素贝叶斯（NB）、XG boost 和梯度提升。我们采用 PIMA 印第安人糖尿病数据集（PIDD）进行此比较分析。该研究结果表明，所提出的集成 SVM-GA 方法在准确率、精确率、召回率和曲线下面积（AUC）方面优于其他方法。

**关键词：** SVM，遗传算法，机器学习，糖尿病预测，医疗保健

## 1. Introduction

糖尿病是一种非传染性疾病，影响着世界上最多的人群。据世界卫生组织称，2019 年约有 200 万人死于糖尿病[[1](#ch8.xhtml#ref8_1)]。糖尿病是一种慢性疾病，因为它还会影响多个身体器官并增加患其他慢性疾病如中风、心脏病发作和肾脏疾病的风险[[2](#ch8.xhtml#ref8_2)]。需要对患者进行定期监测和治疗以获得更好的治疗效果[[3](#ch8.xhtml#ref8_3)]。每个国家的政府都在其总国内生产总值（GDP）中花费了很大一部分用于医疗保健。政府和个人都将预算的相当大比例分配用于慢性病治疗[[4](#ch8.xhtml#ref8_4)]。人们主要有三种糖尿病类型：1 型糖尿病（T1D）、2 型糖尿病（T2D）和妊娠糖尿病（GD）。在 T1D 中，胰腺无法产生胰岛素或产生非常少的胰岛素。在 T2D 中，身体无法正确使用胰岛素，且多见于 45 岁以上人群，而 GD 多见于怀孕期间[[5](#ch8.xhtml#ref8_5)]。这一切都是由于恶劣的气候条件、人口、生活不卫生和错误的饮食习惯造成的。

由于医疗保健行业的不断进步，已出现不同革命。互联网和电子健康记录（EHR）数据的易得性也在迅速增长。我们研究人员的孜孜不倦的努力在医疗保健领域展现出巨大潜力，包括利用各种基于 ML 的技术进行糖尿病的预测和分类[[6](#ch8.xhtml#ref8_6)]。分类模型可用于根据症状和生理特征对不同类型的糖尿病进行分类。有许多用于疾病分类和预测的基于 ML 的技术和算法。一些用于分类和预测的流行 ML 算法包括 SVM、NB、KNN、逻辑回归（LR）、DT 和随机森林（RF）。
