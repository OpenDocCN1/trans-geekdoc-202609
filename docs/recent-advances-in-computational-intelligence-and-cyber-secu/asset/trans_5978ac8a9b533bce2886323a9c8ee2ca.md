

电子健康记录（EHR）系统彻底改变了医疗保健的工作方式。它们将患者记录数字化，使管理医疗信息变得更容易 [[1](#ch2.xhtml#ref2_1)]。这意味着医生和护士可以快速访问患者的重要细节，从而提升了决策和患者护理能力。EHR 系统还使授权人员轻松共享信息，改善了护理协调方式。与此同时，一些问题也随之而来，例如互操作性（使不同的 EHR 系统协同工作）、数据准确性（保持信息正确）、数据隐私（保护个人隐私）和数据安全（确保未经授权的人无法获取数据） [[2](#ch2.xhtml#ref2_2)]。互操作性会使不同系统难以顺畅共享信息，从而影响患者护理 [[3](#ch2.xhtml#ref2_3)]。数据录入错误或系统问题会破坏数据的准确性，导致医疗错误。而且，当患者数据集中存储时，它可能面临泄露和未经授权访问的风险，这对患者隐私不利 [[4](#ch2.xhtml#ref2_4)]。医疗数据泄露对患者和医疗提供者来说都是非常糟糕的消息。为了解决这些问题，本综述论文探讨了区块链技术可能带来的帮助。区块链是一种安全且去中心化的系统，用于存储和共享 EHR 数据 [[6](#ch2.xhtml#ref2_6)]。它使记录几乎无法篡改，并让患者对其健康信息拥有更多控制权。探索区块链如何与 EHR 系统协同工作可能是一场变革，解决医疗保健中的这些棘手挑战，并改善患者护理、隐私和数据安全。

本文将突出以下问题：
* RQ1. 探讨 EHR 系统对医疗行业的影响，以及它们如何改变我们提供医疗保健和增强患者护理的方式。
* RQ2. 探讨 EHR 系统的主要挑战，特别是当涉及到使这些系统有效协作、维护数据准确性、保护个人信息和确保强大安全时。
* RQ3. 研究区块链技术是否可以成为增强 EHR 系统中数据安全并保护患者隐私的实用解决方案。
* RQ4. 研究实际影响并评估在医疗机构中大规模实施区块链技术用于 EHR 系统的可行性。

## 2. EHR：电子健康记录系统

EHR 就像您完整医疗历史和健康信息的数字版本 [[7](#ch2.xhtml#ref2_7)]。把它想象成一个高科技文件，以电子方式存储您有关健康和治疗的一切信息。相比传统健康记录数据，电子健康记录的设计更易于使用和方便 [[8](#ch2.xhtml#ref2_8)]。这种数字格式相比老式的纸质医疗记录有诸多优势 [[9](#ch2.xhtml#ref2_9)]。

*简单访问*：授权的医疗保健提供者可以轻松从多个地点访问您的完整病史、检查结果和治疗计划——得益于 EHR。这意味着您的医疗团队将能够更好地组织您的护理。
*效率*：EHR 为用户提供更高的效率，因为它们在日常任务如预约安排和账单处理方面提供了便利。用于医疗数据管理的文书工作已减少，使医疗保健提供者更易于以数字格式管理您的记录。
*更好的患者护理*：电子健康记录可以为医疗保健提供者提供做出明智决策所需的工具。他们可以看到您的完整健康状况和病史，从而做出更准确的诊断和治疗计划。
*改善协作*：医疗专业人员和不同医院可以协作提供更多医疗服务。EHR 旨在与其他医疗系统和组织共享信息，使您的数据在您穿梭于医疗系统时更容易随身携带。
*隐私*：相比其他形式的医疗数据管理系统，EHR 提供更好的隐私。它们设有强大的安全措施，如加密和访问控制，以防止外部入侵并保护您的敏感信息安全。
*精细决策*：EHR 为医疗决策者提供各种有用的工具。它们可以提供预防性护理提醒、潜在药物相互作用警报，并遵循临床指南。所有这些都有助于您的医疗保健提供者基于可靠证据做出决策。这种分析也有助于为特定疾病或药物的未来研究保存数据模式。
*数据洞察*：由于其适应性，EHR 可用于管理公共卫生计划和跟踪医疗趋势。这对于管理慢性疾病、追踪疾病和总体改善公共卫生至关重要。

电子健康记录确实带来了一些独特的挑战 [[10](#ch2.xhtml#ref2_10)]。这些挑战包括对您数据隐私的担忧、确保不同系统之间无缝兼容的必要性，以及培训医疗专业人员有效使用新技术的需要。EHR 已成为当代医疗保健不可或缺的一部分。它们被广泛用于医院、诊所和医疗机构，以改善患者护理并优化医疗运营效率 [[11](#ch2.xhtml#ref2_11)]。

### 3.1 当前 EHR 系统中的安全问题

EHR 系统中存储了大量私密且敏感的患者数据，包括检查结果、病史和个人信息。保护这些信息至关重要。然而，EHR 系统供应商和医疗机构必须解决的重要安全问题仍然存在。

1. *数据泄露*：当未经授权的个人获得 EHR 系统访问权限时，他们可能会窃取患者数据。这些泄露可能导致身份盗窃和医疗欺诈等严重问题。可悲的是，医疗领域是网络攻击的主要目标 [[12](#ch2.xhtml#ref2_12)]。网络犯罪分子发现健康数据在暗网上比金融信息更有价值，因为它可用于欺诈和长期窃取他人身份。
2. *未经授权访问*：未经授权访问是指医疗机构内部的人员，如员工或承包商，未经适当许可进入患者记录。这可能是由于有人不小心、好奇或怀有恶意意图 [[13](#ch2.xhtml#ref2_13)]。未经授权访问侵犯了患者隐私，并可能导致数据被不道德甚至非法使用。这是信任和隐私的破坏。
