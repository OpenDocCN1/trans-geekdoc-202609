

## 1. 引言

每个互联网服务提供商（ISPs）都有自己的 DNS 服务器，为客户端提供名称解析和反向查询服务。DNS 服务器使用端口 `53` 的用户数据报协议（`UDP`）和传输控制协议（`TCP`）来执行其活动。作为 DNS 请求，目标端口为 `53`，源端口为 `1023` 以上的任意端口；对于 DNS 响应，源端口为 `53`，目标端口为 `1023` 以上的任意端口。当两个 DNS 服务器传输其区域文件时，源端口和目标端口均为端口 `53`（`TCP`）。

互联网呈指数级增长，这对所有系统和网络管理员实现信息安全目标——保密性、完整性和可用性——来说是一个巨大的挑战。这就是为什么需要持续的网络监控、分类和安全分析。入侵检测系统（`IDS`）和入侵防御系统（`IPS`）要么基于内容，要么基于行为，无法防御各种攻击 [[1](#ch10.xhtml#ref10_1), [2](#ch10.xhtml#ref10_2), [3](#ch10.xhtml#ref10_3) 和 [4](#ch10.xhtml#ref10_4)]。

如今，大多数研究人员使用网络流流量来减轻或对抗各种类型的攻击和恶意流量。网络流记录包含可用于各种目的的各种信息，其中一个重要目的是对网络进行安全分析。我们捕获了为期 1 个月的时间段的网络流数据。然后应用数据可视化从数据集中获得某些模式。在应用机器学习（`ML`）模型后，比较了 K-最近邻（`KNN`）和朴素贝叶斯（`NB`）机器学习分类器之间的单独性能以找出准确率 [[5](#ch10.xhtml#ref10_5), [6](#ch10.xhtml#ref10_6), [7](#ch10.xhtml#ref10_7) 和 [8](#ch10.xhtml#ref10_8)]。

## 2. 问题陈述

为了识别针对 DNS 服务的良性和恶意流量，以提高服务质量、安全性和效率，我们必须分析网络中的模式。流量量、流量类型、流量的源和目标等。

我们的重点是使用数据科学和各种 ML 语言开发一个工作模型，以可视化、分析和预测网络中的流量类型以及这些流量对 ISP 网络的影响。

作为对潜在危险的保险政策。利用一系列供应商提供了一层额外的保护，这是其好处之一。这导致网络具有增强的保护级别，因为可能能够通过由一个供应商提供的由于已知故障而提供的<|message|>安全设备的攻击将无法通过由其他供应商提供的 security 设备。

## 5. 数据集上的机器学习应用部分

### 5.1 朴素贝叶斯（NB）

朴素贝叶斯分类器是一组基于 `Bayes’ Theorem` 的分类算法。它不是单一算法，而是一系列算法，其中所有算法都共享一个共同原理，即即将被分类的每对特征彼此独立。它是一种简单但出人意料的强大的预测建模算法。该模型由两种可以直接从训练数据计算的概率组成：（1）每个类别的概率；以及（2）给定每个 x 值的每个类别的条件概率。一旦计算完成，概率模型就可以使用贝叶斯定理对新数据进行预测。NB 分类器专门为二元分类问题而设计。它非常容易构建，并且在处理海量数据时在许多情况下优于一些复杂的方法 [[9](#ch10.xhtml#ref10_9)]。
