# 26 用于各种无线应用的具有 DGS 的紧凑型触角矩形槽天线

Parimal Tiwari^([^(26)](#fn26))

## Abstract

本文研究的紧凑型矩形槽天线由触角型结构和接地平面缺陷组成，可实现 GNSS、无线局域网、WiMAX、长期演进、C 波段和 X 波段等无线应用。该蚀刻采用 50 Ω 微带线在 FR4 介质基板上完成。该天线覆盖的频率为 (1.4–1.8)/1.6 GHz、(2.1–3.5)/2.4 GHz、(5.4–6.3)/5.8 GHz、(7.0–7.3)/7.2 GHz 和 (9.2–11.6)/9.9 GHz。所设计原型天线的相应带宽分别为 25%、58%、16%、4% 和 24%。为验证所提设计，采用制造商和矢量网络分析仪进行了制作和测试，并提供了测量结果。制作的原型通过测量验证了仿真结果的准确性。随后各节中讨论并验证并呈现了各种尺寸的参数分析、表面电流分布和辐射方向图，以证明所提设计更优。

**关键词：** GNSS, WLAN, WiMAX, 缺陷接地结构 (DGS), 微带, 辐射方向图, FR4

## 1. Introduction

为无线通信系统设计的用于多频段工作的天线受到了广泛关注。其中，微带天线已成为多种无线应用的首选。与传统天线相比，微带贴片天线具有诸多优势，包括重量轻、成本效益高、易于制造和可适应性。此外，它们可以与单片集成电路无缝集成 [[1](#ch26.xhtml#ref26_1), [2](#ch26.xhtml#ref26_2), [3](#ch26.xhtml#ref26_3), [4](#ch26.xhtml#ref26_4), [5](#ch26.xhtml#ref26_5), [6](#ch26.xhtml#ref26_6), [7](#ch26.xhtml#ref26_7), [8](#ch26.xhtml#ref26_8), [9](#ch26.xhtml#ref26_9), [10](#ch26.xhtml#ref26_10), [11](#ch26.xhtml#ref26_11), [12](#ch26.xhtml#ref26_12), [13](#ch26.xhtml#ref26_13) 和 [14](#ch26.xhtml#ref26_14)]。典型的微带贴片天线具有辐射发生的贴片、基板和接地结构。基板位于接地和贴片之间。通常，采用铜或金等导电材料构建辐射贴片。馈电结构负责连接辐射贴片，并蚀刻在介电基板上。微带贴片天线可设计成多种形状，如方形、圆形、矩形、三角形、椭圆形等 [[4](#ch26.xhtml#ref26_4)]。
