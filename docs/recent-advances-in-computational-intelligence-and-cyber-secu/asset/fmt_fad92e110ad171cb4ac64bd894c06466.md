
*Γ*[*k*] ≈ log *k* + *γ*

By substituting the approximate value of `Γ[k]` in Equation (18) and making Equation (18) equal to zero, it is obtained the optimal number of the active subcarrier

(21)

$$k \approx \frac{MN_{FFT}}{G(M + 1)}.$$

### 3.2 Average bit-error rate

In the presence of channel estimation errors in which a mismatched ML detector is used for data detection, the condition pair-wise error probability (CPEP) can be expressed by [[9](#ch27.xhtml#ref27_9)] Equation (22) as

(22)

$$\text{P}_{r}\left( X_{g}\rightarrow{\hat{X}}_{g} \mid {\hat{H}}_{g} \right) = Q\left( \frac{\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}{}^{2}}{\sqrt{2\sigma_{e}^{2}X_{g}^{H}\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}{}^{2} + 2N_{0}\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}{}^{2}}} \right)$$

where `σ²[e]` is the estimation error variance of the vector of the channel frequency response `H[g]`, `(⋅)^(H)`, `⋅` and `Q(⋅)` represents the Hermitian transposition, the Frobenius norm and the Gaussain *Q—*function, respectively.

(23)

$$\begin{array}{l} {X_{g}^{H}\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}^{2} = {\sum\limits_{i = 1}^{n}\left| {X_{g}(i)} \right|^{2}}\left| {\left( {X_{g}(i) - {\hat{X}}_{g}(i)} \right){\hat{H}}_{g}(i)} \right|^{2}} \\ \left. \Rightarrow X_{g}^{H}\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}{}^{2} = \frac{1}{n}X_{g}{}^{2}\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}{}^{2} \right. \\ \end{array}$$

So, the CPEP can be expressed again as

(24)

$$\text{P}_{r}\left( X_{g}\rightarrow{\hat{X}}_{g} \mid {\hat{H}}_{g} \right) = Q\left( \sqrt{\frac{\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}^{2}}{2\sigma_{e}^{2}\left( X_{g} \right)^{2}/n + 2N_{0}}} \right)$$

Then, the unconditional pair-wise error probability (UPEP) can be obtained by

(25)

$$\text{P}_{r}\left( X_{g}\rightarrow{\hat{X}}_{g} \right) = E_{{\hat{H}}_{g}}\left\{ {Q\left( \sqrt{\frac{\left( {X_{g} - {\hat{X}}_{g}} \right){\hat{H}}_{g}^{2}}{2\sigma_{e}^{2}\left( X_{g} \right)^{2}/n + 2N_{0}}} \right)} \right\}$$

where `E[Ĥ[g]]` {.} denotes the expectation operation with respect to the estimated channel frequency response. To obtain the closed-form expression for the UPEP, the approximate Gaussian *Q—*function can be applied. To enhance the accuracy, the approximate Gaussian *Q—*function is proposed in [[20](#ch27.xhtml#ref27_20)], given by

(26)

To the approximate UPEP, Equation (26) is applied to Equation (25),

(27)

$$\begin{array}{l} {\text{P}_{r}\left( X_{g}\rightarrow{\hat{X}}_{g} \right) = E_{{\hat{H}}_{g}}\left\{ {0.168e^{- 0.876q{({X_{g} - {\hat{X}}_{g}})}{{\hat{H}}_{g}^{2}}} \right.} \\ \left. {+ 0.144e^{- 0.525q{({X_{g} - {\hat{X}}_{g}})}{{\hat{H}}_{g}{}^{2}} + 0.002e^{- 0.603q{({X_{g} - {\hat{X}}_{g}})}{{\hat{H}}_{g}{}^{2}}} \right\} \\ \end{array}$$

where `q` = *n*/(2*σ*[e]²(*X*[g])²/*n*+2*N*[0]). Using Equation (27), the expectation can be calculated according to the spectral theorem in [[9](#ch27.xhtml#ref27_9)] and the UPEP upper bound can be calculated as

where `I[n]` denotes n-dimensional identity matrix `K̂[n]` = `E{ Ĥ[g] Ĥ[g]^(H) }` = **K**[*n*] + *σ*[e]²**I**[*n*] Then, based on the UPEP derived above, an upper bound on the average bit error rate (ABER) can be obtained as,

(29)

## 4. Results and Discussion

In order to address the challenges posed by non-linearity in single mode fiber, the optical-OFDM-IM scheme has been employed for efficient long-haul optical link transmission. As depicted in [Figure 27.1](#ch27.xhtml#fig27_1), a transmitter and receiver simulation structure has been constructed using `MATLAB`. The block model was simulated using the Split-Step Fourier Method (SSFM) to solve the Nonlinear Schrödinger Equation (NLSE). This simulated structure can be utilized to mitigate impairments such as dispersion effects and non-linearity in optical fiber communication systems. The simulation employed a consistent Fast Fourier Transform (FFT) size for the OFDM frame and a constant step-size protocol, following the SSFM approach [[21](#ch27.xhtml#ref27_21)].

[Table 27.2](#ch27.xhtml#tab27_2) summarizes the simulation attributes for the optical fiber channel and OFDM system. In order to compensate for carrier frequency offset, it is imperative to maintain perfect system synchronization in addition to having 500 independent channels. The transmitter utilizes a pseudo random binary sequence (PRBS) generator to generate data bits, and employs binary phase shift keying (PSK) and M-ary quadrature amplitude modulation (QAM) schemes for bit mapping.
