
实现此目的最常见的方式是使用本体，它是‘一个[shared]概念化的明确规范’[6]，可以被视为一种正式定义的信息模型。这与蒂姆·伯纳斯-李于2001年提出的语义网[13]理念一致，提出互联网从文档之网演进为机器可读且可理解的数据之网。语义网的基石技术是资源描述框架¹（RDF），一种用于描述本体的轻量级（元数据）数据模型，以及 SPARQL 协议和 RDF 查询语言²（SPARQL），两者均由万维网联盟（W3C）标准化。

1. https://www.w3.org/RDF/
2. https://www.w3.org/TR/sparql11-overview/

为了能够构建利用来自多个物联网系统数据的创新应用，跨越现有的“物联网孤岛”，这些系统不仅能够交换原始数据，还必须对其含义有共同的理解。不幸的是，即使当今的物联网系统愿意向他人开放其数据和资源，其语义上不兼容的信息模型——对资源和操作流程提供不同的描述甚至不同的理解——也成为一个问题。因此，语义互操作性，被定义为“计算机系统以无歧义、共享的含义交换数据的能力”[14]，是“跨大型垂直应用的数据交换和服务创建”的关键，这是物联网演进的下一步[15]。

实现语义互操作性的挑战在于找到一种提供这种无歧义、共享事物含义的方法，即弥合两个（或多个）平台之间的语义鸿沟。图3.4展示了语义互操作性的可能方法及其分为三类。所示方法是对[16]中提出的方法的扩展，并形成了一个解决方案空间，其中每种语义互操作性方法都可以定位。原文中解决方案空间的范围从核心信息模型方法——所有通信平台都同意使用一个共享模型——到 Mapping between *Platform-Specific Information Models* 方法——每个平台可以自由使用自己喜欢的信息模型，互操作性仅通过它们之间的映射实现。我们定义了另外两种扩展此范围的方法，称为 *Arbitrary Information Model (+ Domain-Specific Models)*，它们并不能从总体上解决语义互操作性问题，但已提供解决语义互操作性所需的机制，因此允许在不同层面上解决它。

我们还根据三种类型的（语义）互操作性对这些方法进行了分类：*by chance*、*by standardization* 和 *by mapping*。语义互操作性 *by chance* 意味着每个平台可以自由使用自己喜欢的模型，但仅与偶然使用相同模型的任何其他平台互操作。语义互操作性 *by standardization* 指的是关于所用模型至少部分内容存在某种协议或标准化，而（语义）互操作性 *by mapping* 指的是使用映射逻辑在不同模型之间进行转换。

## IoT-EPI Projects approaches addressing IoT platforms interoperability

### 4.1. IoT-EPI Platforms - Architectural mapping

物联网平台的采用由诸如增加云服务和合作伙伴生态系统发展的经济因素驱动。在此背景下，设备制造商提供内置解决方案和模型，并通过物联网 SDK 提供易用性，允许使用多个门户和应用程序使物联网平台和设备完全配置。与服务提供商的关系随着物联网套件内的集成以及服务提供商的各种产品而变得越来越重要。

在设备发现领域，标准化发展正在加速，以支持异构设备通信和互操作的能力。标准是实现互操作性的关键，降低成本并刺激增长。然而，标准化流程复杂，需要很长时间才能演进和被采用，并且成熟稳定的标准占据主导地位仍需一些时间，因此供应商和买家不得不过度投资于多个标准。

在这种复杂环境中，IoT-EPI 项目正在开发互操作性解决方案，解决物联网架构中的不同层，并提供在不同物联网平台之间提供互操作性的机制，以解决各种用例和应用。

在以下段落中，我们简要讨论物联网架构层与 IoT-EPI 项目提供的活动和解决方案的映射关系。

AGILE 为物联网构建模块化硬件和软件网关，重点关注物理层、网络通信、处理、存储和应用层。AGILE 软件模块解决的功能包括设备管理、通信网络（如区域和传感器网络）以及分布式存储解决方案。该项目考虑了提供稳健安全管理系统所需的所有模块。

bloTope 提供架构和关于开放标准及用例实现的建议，使利益相关者能够轻松创建新的物联网系统和服务，并利用先进的系统-of-系统（SoS）能力快速利用可用信息，用于连接智能对象。bloTope 还开发并提供标准化开放 API 以实现互操作性。该项目涵盖物联网架构全部八层，并在跨域环境中验证互操作性解决方案。

BIG IoT 开发通用的、统一的物联网平台 Web API。作为项目的一部分，8 个合作伙伴物联网平台正在与生态系统集成，另外多个平台通过社区建设流程加入。该项目通过解决安全管理、API、服务集成、外部系统服务、应用和企业业务，重点关注物联网架构的上层。

INTER-IoT 项目通过关注物联网架构的六层并提供涵盖 QoS 和设备管理、服务集成、外部系统服务、存储和虚拟化的模块，解决开放的跨层框架、相关方法论和工具，以实现异构物联网平台之间的自愿互操作性。该项目涵盖所有网络通信层和完整的安全管理套件。

**symbloTe** 提供抽象层，实现对各种物联网平台及感知/执行资源统一视图。应用程序可以使用实现语义物联网引擎的 symbloTe 核心服务，找到由 symbloTe 启用平台提供的适当资源，随后直接访问平台的虚拟资源进行数据采集和执行。该项目重点关注从物理层到应用层的物联网架构七层，并提出完整的安全管理系统。

**TagItSmart!** 提供一套工具和使能技术，可通过提供的 API 集成到不同的物联网平台，使价值链各环节的用户能够充分利用条件依赖型功能代码的力量，将大众市场产品与数字世界连接起来，覆盖多个应用领域。

**VICINITY** 重点关注一个平台和生态系统，为物联网基础设施提供“互操作性即服务”，并涵盖物联网架构的五层上层。工作考虑服务集成、业务逻辑、虚拟化、存储、API、工具、外部系统服务、应用、数据分析和云服务。
