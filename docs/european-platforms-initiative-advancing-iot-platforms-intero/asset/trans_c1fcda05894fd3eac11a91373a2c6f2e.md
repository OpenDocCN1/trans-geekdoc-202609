
跨平台的语义翻译。它还提供了一种方法论（INTER-METH）来指导并简化实施。INTER-IoT 开放框架（INTER-FW）提供了一套用于各特定层互操作性的工具，可通过 API 访问。此外，INTER-IoT 还为每个层解决方案提供虚拟化版本，以利用 Docker 实现快速部署。

INTER-IoT 解决方案可应用于任何需要互联和/或互操作性的应用领域和跨领域。INTER-IoT 将促进可互操作的物联网生态系统的形成，使公司和开发者更容易设计物联网设备、智能对象或服务，并支持其快速面向更广泛的客户群推向市场。从长远来看，应用程序能够连接并与异构智能对象交互的能力将成为新产品和服务的重要推动因素。

## 4.5.2. INTER-IoT 架构

INTER-IoT 提出了一种新颖的分层导向互操作性解决方案，以在不同物联网系统和平台之间提供任一层以及跨层的互操作性。与更通用的全局方法相比，INTER-IoT 分层方法在提供互操作性方面具有更大的潜力。它促进了紧密的双向集成、更高性能、完全模块化、高适应性和灵活性，并提供更高的可靠性。

这种分层导向的解决方案通过 INTER-LAYER 实现，即针对特定层的若干互操作性解决方案。每个互操作性基础设施层与相邻层具有紧密耦合并提供接口。接口将由元级框架控制以提供全局互操作性。每个互操作性机制都可通过 API 访问。互操作性基础设施层可通过接口进行通信和互操作。这种跨层设计使得能够实现更深入、更完整的集成。

## 4.5.3. 层与互操作性方面

### 设备层 (D2D)
在设备层面，D2D 解决方案将允许无缝纳入新型物联网设备并使其与已有的设备互操作。D2D 解决方案是一个模块化网关，支持广泛的协议以及原始转发。它由仅处理网络接入和通信协议的物理部分，以及处理所有其他网关操作和服务的虚拟部分（网关虚拟化）组成。当连接丢失时，虚拟部分仍保持功能，能够响应 API 和中间件请求。网关采用模块化方法，允许添加可选服务模块以适应特定情况，从而实现智能对象生态系统的快速增长。

### 网络层 (N2N)
N2N 解决方案实现无缝的网络到网络互操作性，允许透明的智能对象移动性并提供信息路由支持。它还将允许卸载和漫游，这意味着通过网络实现网关和平台的互联。互操作性通过创建虚拟网络实现，采用 SDN 和 NFV 范式，并在 N2N API 的支持下进行。N2N 解决方案将允许设计和实现完全互联的生态系统，并解决智能对象移动性问题。

### 中间件层 (MW2MW)
在中间件层面，INTER-IoT 解决方案将为异构物联网平台中的物联网设备实现无缝的资源发现和管理系统。中间件层的互操作性通过建立抽象层并将物联网平台附加到其上来实现。该层包含的不同模块提供服务来管理对象的虚拟表示，创建抽象层以访问其所有功能和信息。这些服务可通过通用 API 访问。该层的互操作性将允许在大型多平台物联网系统中对智能对象进行全局利用。

### 应用与服务层 (AS2AS)
INTER-IoT 将实现不同物联网平台之间异构服务的使用。我们的方法将允许发现、编目、使用甚至组合来自不同平台的服务。AS2AS 还将提供 API 作为集成工具箱，以促进开发集成现有异构物联网服务的新应用。

### 语义与数据层 (DS2DS)
INTER-IoT 确保不同物联网平台和通常采用不同数据格式和本体、无法直接共享信息的异构数据源之间对数据和信息的统一解释。INTER-IoT 的 DS2DS 方法是首个为异构物联网平台提供 **通用语义和语法互操作性** 的解决方案。它基于一种新颖的方法，即将物联网平台的本体语义翻译到/自 INTER-IoT 使用的通用中央本体，而不是直接的平台到平台翻译。这种技术大幅减少了实现通用语义互操作性所需的潜在语义翻译组合数量。INTER-IoT 语义互操作性工具可与任何词汇表或本体一起工作。INTER-IoT 自己的模块化中央本体，名为 GOIoTP，适用于所有物联网平台、设备和服务，可在 http://docs.inter-iot.eu/ontology 获取。此外，语法转换器允许不同数据格式（如 JSON、XML 等）之间的互操作性。尽管 INTER-IoT 的试点部署采用核心信息模型与扩展方法来实现语义互操作性，但 INTER-IoT 支持其试点方法与核心信息模型之间的任何解决方案。

### 跨层
INTER-IoT 还保证必须存在于所有层中的非功能性方面：信任、安全、隐私和服务质量（QoS）。此外，INTER-IoT 为每个层提供解决方案的虚拟化版本，以提供快速、简便部署的可能性。安全性在每个单独层内得到保证，外部 API 访问通过加密通信、身份验证和安全令牌进行保护。INTER-IoT 符合新的欧洲数据隐私法，并在信息高度敏感的电子健康特定情况下，符合医疗器械法规。

关于第 3.1.1 节中描述的架构互操作性模式，INTER-IoT 支持全部六种互操作性模式：
- 跨平台访问，通过 AS2AS 服务或通过 MW2MW 实现。
- 跨应用域访问，只要 INTER-IoT 为域无关且通过 DS2DS 解决方案具有通用语义互操作性。
- 平台独立性，通过 AS2AS 服务组合和 DS2DS 语义与语法转换实现。
- 平台规模独立性，通过 INTER-IoT AS2AS 实现。
- 高层服务外观，通过 INTER-IoT AS2AS 服务实现。
- 平台到平台交互，INTER-IoT 设计上的主要目标。通过 D2D 和/或 MW2MW 解决方案实现。

上述所有模式均为架构模式。INTER-IoT 从不同视角或分析角度识别了主要的互操作性模式：从语义视角，关于语义互操作性，以及从中间件互操作性视角（与语法和功能互操作性相关）。INTER-IoT 拥有与此方法相匹配的自身宏模式和微模式。

最后，关于三种主要的互操作性类型（功能、语法、语义），INTER-IoT 都能实现。任何具有不同数据格式和本体的平台之间的通用语法和语义互操作性可通过 INTER-IoT DS2DS 解决方案实现。此外，其他 INTER-IoT 层（D2D & N2N）可提供智能元素之间的功能互操作性，实现网络连接。

## 4.6. symbIoTe

**symbIoTe**（**跨物联网环境的智能对象共生**）的主要目标是设计一个跨物联网平台的 **灵活且安全的互操作性中间件**，以促进跨平台物联网应用的快速开发、平台协作以及动态自适应智能空间。这通过以下方式实现：1）面向由平台提供商注册的已连接（虚拟化）智能对象（即物联网资源）的 **语义物联网搜索引擎**，2）用于跨平台统一安全使用这些资源的 **抽象层**，3）用于快速跨平台应用开发的高级、特定领域的 API（“Enablers”），4）**物联网平台联合**，即在两个平台之间建立的促进其安全交互、协作和资源交换的关联，5）提供同地设备和网关互操作性的 **动态且自配置** 智能空间，以及 6）物联网平台、网关和智能设备之间的 **安全互操作协议**。这支持中小企业和物联网市场的新进入者在较短的开发周期内构建创新的物联网服务。
