## VICINITY

![](img/084215b3209e41ed4c28b3829663f1e4_88_0.png)

| IoT平台 | 平台性质 | 简要描述 |
|---|---|---|
| LinkSmart | 开源 | 最初在 Hydra 项目中开发的 IoT 中间件。它允许开发者通过易于使用的 Web 服务将异构物理设备纳入其应用程序，以便控制任何设备。 |
| IoTivity | 开源 | IoTivity 是一个开源软件框架，可实现无缝的设备到设备连接，以满足物联网的新兴需求。 |
| SiteWhere | 开源 | 物联网开放平台提供了一套 API，可通过 MQTT、AMQP、Stomp 和其他协议连接设备，实现设备的自注册以及使用批处理对设备进行操作。 |
| Eclipse Kura | 开源 | Eclipse Kura 是一个基于 Java/OSGi 的 IoT 网关框架，包括用于访问硬件输入/输出、网络配置管理以及与 M2M/IoT 集成平台通信的一套 API。此外，Eclipse Kura 支持 Apache Camel 路由，以便在 IoT 网关级别引入业务逻辑。 |
| TinyMesh | 商业 | 面向 TinyMesh 兼容设备的自管理且自愈的网状网络平台，可实现网络中度量和性能的收集。 |
| Gorenje Cloud services | 商业 | 基于云的 IoT 平台，用于控制和维护 Gorenje 家用电器。 |
