# 4.6.3. Interoperability Aspects

The symbloTe approach defines four interoperability levels, as depicted in Figure 4.11. We also refer to them as compliance levels, when considering them from the perspective of an IoT platform wanting to become interoperable. In all four levels, interoperability is achieved by offering a unified and secure way to advertise, find and consume IoT resources, but in each level, a different interoperability scenario is enabled offering various degrees of details about the involved resources.

Level 1 enables interactions between IoT applications and virtualized IoT resources (both sensors and actuators), i.e., applications can find and use resources across platforms through uniform interfaces.
