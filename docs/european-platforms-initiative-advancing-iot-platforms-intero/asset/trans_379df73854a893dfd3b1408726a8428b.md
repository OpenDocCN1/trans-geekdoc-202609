## 4.6.1. symbIoTe 架构

symbIoTe 架构 [24] 以分层 IoT 栈为核心，将智能空间内的各种设备（传感器、执行器和 IoT 网关）与云连接起来。智能空间共享可用的本地资源（连接性、计算和存储），而在云中运行的平台服务则实现 IoT 平台联合，并以灵活的访问控制向第三方开放 Interworking API¹⁸。该架构包含四个分层域，如图 4.10 所示。

18. Interworking Interface 是 symbIoTe 定义的接口，可将平台资源作为云域中的 RESTful IoT 服务开放。

1) 应用域使平台能够注册希望通过 Interworking API 广告并使其可访问的 IoT 设备，而 symbIoTe 通过其核心服务提供跨平台搜索 IoT 设备的手段。我们还构建特定领域的后端服务（Enablers），利用底层平台提供的基础设施提供增值服务，例如在不同平台获取的传感器数据之上进行数据分析。Enablers 简化了跨平台和特定领域的应用程序开发流程（特别是针对移动和 Web IoT 应用）。

云域通过开放 API（Interworking API）以统一且属性受控的方式 [25] 为第三方提供平台所暴露的虚拟化 IoT 设备的访问。此外，它还构建用于 IoT 平台联合的服务，实现平台间的紧密协作和资源交换，符合平台特定的业务目标和定义的服务等级协议（SLAs）。

智能空间域提供本地空间中共置 IoT 设备和网关的发现和互操作服务，而智能设备域则涉及智能设备在不同空间移动时保持其身份的漫游能力。

## 4.6.2. IoT 平台互操作性方法

symbIoTe 允许灵活的 IoT 平台互操作机制（**平台联合**内的直接平台对平台交互、**智能空间**内的平台对平台交互），这是通过在引入的架构域中逐步部署 symbIoTe 功能实现的，以便平台提供商可以选择合适的互操作解决方案并仅将其平台与所选功能集成。这实际上影响了平台在 symbIoTe 启用生态系统内与其他平台的互操作性和协作水平。目前设想的解决方案对现有 IoT 平台的影响最小，因为它主要需要开发一个小型互操作模块。此外，symbIoTe 增加了一层安全层，提供了一种分布式且有效的机制，用于在异构 IoT 平台联合中对资源进行受控访问。

## 4.6.3. 互操作性方面

symbIoTe 方法定义了四个互操作性级别，如图 4.11 所示。当从希望实现互操作的 IoT 平台角度考虑时，我们也将其称为合规级别。在所有四个级别中，互操作性都是通过提供统一且安全的方式来广告、查找和消费 IoT 资源来实现的，但在每个级别中，都启用了不同的互操作场景，提供有关所涉及资源的各种详细程度。

级别 1 使 IoT 应用与虚拟化 IoT 资源（传感器和执行器）之间能够交互，即应用可以通过统一接口在不同平台间查找和使用资源。此外，平台可以集成 symbIoTe 组件以实现灵活的属性-based 访问控制。级别 2 通过形成 **联合** 使 IoT 平台能够紧密协作。联合可以被视为核心服务的封闭和分布式版本，即平台只能向联合成员广告和交换资源。**级别 3** 启用 **动态智能空间**：在网关级别采用新资源，以及在共置智能空间中 symbIoTe 启用的 IoT 设备（例如移动设备和 Arduino 板）之间的直接交互，即使它们连接到不同的网关并由不同的 IoT 平台管理。这使得共置和邻近 IoT 网关之间的资源迁移成为可能，以防止供应商锁定。**级别 4** 提供对 **IoT 设备漫游** 的支持，这些设备在移动过程中保持其唯一身份，并且无论其当前位置如何，都可以通过核心服务始终找到。级别 1 可以直接映射到 *语义和语法互操作性*，如 IERC《互操作性白皮书》[26] 中定义。级别 2、3 和 4 与 *组织互操作性* 相关。symbIoTe 在此提出了一种原创方法，通过将特定的互操作概念置于云或智能空间中，实现更精细的组织互操作性粒度。

## 4.6.4. 方法的独特性与具体特征

symbIoTe 的第一个独特特征是其语义互操作性解决方案，遵循第 3.1.2 节中介绍的 *Core Information Model with Extensions* 方法。*核心信息模型*（CIM）是用于描述注册到 symbIoTe 的资源的中心信息模型，并在所有平台之间共享。它的设计尽可能抽象和极简，同时又足够具体以建立最小的相互理解。这样，CIM 即可在所有平台之间实现有限的开箱即用互操作性。要实际将资源注册到 symbIoTe，平台使用 *平台特定信息模型*（PIMs），它们是 CIM 的扩展，包含平台特定术语。由于每个 PIM 都是 CIM 的扩展，因此即使使用不同 PIM 的平台之间也能确保基本互操作性。这种灵活性超越了现有技术水平，预计将获得平台所有者的高度认可，尤其是中小企业，因为将其平台信息模型适配到 symbIoTe 的过程大大简化，同时仍可使用其现有信息模型。

此外，symbIoTe 制定了策略，以实现使用不同 PIM 的平台之间更高级别的互操作性。它基于使用 SPARQL 查询重写和数据转换的声明式映射在不同 PIM 之间进行转换。这一概念对 IoT 解决方案的语义互操作性具有巨大潜力，因为信息模型标准化的过程通常冗长繁琐，同时也限制了平台的灵活性。

第二个独特特征与由核心服务提供的已实现的 *IoT 资源语义搜索引擎* 相关，该搜索引擎让 IoT 应用开发者能够为各种跨平台和跨域应用找到合适的 IoT 资源。搜索引擎使用并支持列出的 symbIoTe 信息模型。

第三个独特性与平台间更紧密协作的 *平台联合* 内的直接平台对平台交互相关。在此，symbIoTe 更进一步，提供丰富平台交互的新功能：资源交换、信任和 SLA 管理，以及在联合平台间支持智能设备漫游。

第四个独特性与 *安全视角* 相关。symbIoTe 实现了灵活、分布式且有效的机制，用于在异构 IoT 平台联合中对资源（传感器和执行器）进行受控访问。所设想的方法论以强大的基于属性的访问控制机制为根基。一个特定的访问策略（定义为属性的组合，即用户的属性、角色、详细信息）被分配给每个资源，而对该资源的访问只能授予拥有与上述策略匹配的属性集的用户。
