INTER-IoT open framework (INTER-FW) offers a set of tools for interoperability at each specific layer which can be accessed through an API. Furthermore, INTER-IoT offers a virtualized version of each layer solution to facilitate a quick implementation with Docker.

INTER-IoT solution can be applied to any application domain and across domains in which there is a need for interconnection and/or interoperability.
