# Figure 6.20 The PHP Function Reference

Within the documentation, a function is syntactically represented in a style similar to that for the actual function declaration. Here's an example with htmlspecialchars():

```
htmlspecialchars ( string $string , int $flags = ENT_COMPAT | ENT_HTML401 ,
string $encoding = ini_get("default_charset") , bool $double_encode = true ) :
string
```

First comes the function name. The parameters follow in round brackets. Each parameter is preceded by the data type that the function expects. mixed stands for any data type.
