# 11.3.3 Destructor

The __destruct() destructor method is always used when an object is resolved. It also reacts, for example, when the object is resolved with unset(object) (see Figure 11.12).

```
<?php
class Computer {
public $CPU = "The CPU";
public function __destruct() { echo "Destructor active"; }
}
$MyComputer = new Computer();
unset($MyComputer);
echo "$MyComputer->CPU<br />";
?>
```
