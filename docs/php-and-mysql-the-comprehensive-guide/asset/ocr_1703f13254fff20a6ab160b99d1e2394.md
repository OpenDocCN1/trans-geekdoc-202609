# Nesting Loops

Loops can be nested as desired in PHP. You simply write one loop in the statement block of the other loop.

```
for ($i = 1; $i <= 10; $i++) {
    echo "Row $i: ";
    for ($j = 1; $j <= 10; $j++) {
        echo $j * $i . " ";
    }
    echo "<br />";
}
```

In practice, nested loops are used, for example, if you want to manipulate a graphic with PHP. To recolor every pixel of an image, use a for loop that goes through all horizontal pixel columns and a nested for loop that goes through all pixel rows. With these two nested for loops, you can catch every pixel of the image. Another area of application is multidimensional arrays, which you will become familiar with in Chapter 8.
