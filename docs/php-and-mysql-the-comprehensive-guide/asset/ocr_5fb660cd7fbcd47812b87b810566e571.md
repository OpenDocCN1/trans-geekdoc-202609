# Listing 5.32 "continue" in Use ("continue.php")

continue, like break, can also be given a numerical value, which, in the case of nested loops or switch statements, tells you which loop to continue with. The following example shows this using two nested loops (see Figure 5.27).

```
<?php
for ($i = 1; $i <= 10; $i++) {
    echo "Row $i: ";
    $j = 1;
    while (true) {
        echo $j * $i . " ";
        $j++;
        if ($j > 5) {
            echo "<br />";
            continue 2;
        }
    }
}
?>
```
