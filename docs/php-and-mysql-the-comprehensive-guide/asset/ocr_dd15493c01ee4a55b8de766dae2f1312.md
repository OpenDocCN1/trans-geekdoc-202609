Figure 11.27 Overloading with "__call()"

One disadvantage of __call() is that it intercepts all undefined methods (see Figure 11.28). Here is an example:

```
<?php
class Computer {
public function __call($name, $parameter) {
echo "Elements of function $name:<br />";
foreach ($parameter as $element) {
echo $element ."<br />";
}
}
}

$MyComputer = new Computer();
$MyComputer->fans("CPU", "Main");
$MyComputer->drives("C", "D", "E");
?>
```
