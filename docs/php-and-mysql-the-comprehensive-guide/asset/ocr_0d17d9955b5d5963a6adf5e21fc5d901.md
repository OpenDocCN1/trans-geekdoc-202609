**Tip**
If you do not specify an index when assigning a value, the element is added to the end
of the array and assigned the highest numerical index:
`$name[] = value;`

# 8.1.3 Delete Elements

To delete an element, use `unset()`. However, you can also use this to remove the entire
array, as shown in Figure 8.4.

```
<?php
$days = array("Saturday", "Sunday", "Monday", "Tuesday");
unset($days[0]);
print_r($days);
unset($days);
print_r($days);
?>
```

# 8.1.4 Associative Arrays

An associative array is an array whose indices consist of strings or descriptive names.
Here is a simple example:

```
$stockprices = array("IBM" => 232, "Miemens" => 34, "Rheinwerk" => 340);
```

The index is assigned to a name using =>. Be careful: this is easy to confuse with the ->
operator in object-oriented programming!
