# 28.4.1 Server

There are several versions of the WebSocket Protocol, and one of the server's tasks is to support each of these correctly; s we will see later, the browser does this more or less automatically. But instead of implementing everything ourselves, we rely on an established package called Ratchet. Under the funny URL http://socketo.me (see Figure 28.5), there is information about the package and a demo to try it out online, but no direct download.

Currently, Ratchet can only be installed with the Composer package manager. In Chapter 38, you will find more information on this; among other things, you will also learn how to install Composer on your system. For the following explanations, we assume that this has already been done.
