# 25.4 Settings

The php.ini configuration file contains the options for file operations listed in Table 25.4.

| Parameters | Description | Default Value |
| :--- | :--- | :--- |
| allow_url_fopen | Specifies whether URLs may also be opened via fopen()* | "1" |
| auto_detect_line_endings | Specifies whether the line endings of a file (\r, \n or \r\n) should be determined automatically | "Off" |
| realpath_cache_size | Size of the cache for realpath() calls | "16K" |
| realpath_cache_ttl | Lifetime of a cache entry for realpath() | "120" |
\*More information on this can be found in Chapter 26.
