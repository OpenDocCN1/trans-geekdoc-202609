# 39.2 Compile

The script has automatically created a directory with the name of the extension (here, _book_; uppercase letters are converted to lowercase letters by _ext_skel.php_) and created some files there, including the following:

+   * config.m4

Among other things, this file sets up a new configuration switch for PHP:

```
...
PHP_ARG_ENABLE([book],
[whether to enable book support],
[AS_HELP_STRING([--enable-book],
[Enable book support])],
[no])
...
```
