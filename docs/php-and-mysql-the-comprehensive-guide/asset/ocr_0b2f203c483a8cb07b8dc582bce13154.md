# 11.4.4 "__toString()"

The __toString() method is used when an object is explicitly converted into a string. This explicit conversion takes place with (string) in front of the object name:

```
(string) $object;
```

Incidentally, the return value of this conversion is the previous data type (i.e., object) and the signature or number of the object.
