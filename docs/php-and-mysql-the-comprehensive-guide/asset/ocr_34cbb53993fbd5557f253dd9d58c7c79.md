# Named Parameters

Named parameters or named attributes are a new option since PHP 8 to directly assign a value to individual parameters in the call of a function without having to adhere to the specified order or define all optional parameters up to the desired parameter.

The latter is illustrated by the example from the PHP 8 innovations using the htmlspecialchars() PHP function. In the documentation, the function has four attributes:

```
htmlspecialchars ( string $string , int $flags = ENT_COMPAT | ENT_HTML401 ,
string $encoding = ini_get("default_charset") , bool $double_encode = true ) :
string
```

If you now want to change the fourth parameter for htmlspecialchars(), but not the two before it, then simply access the fourth parameter, $double_encode, directly with the named parameter:

```
htmlspecialchars($string, double_encode: false);
```

To do this, we write the variable name of the parameter without $ and the value for the parameter after a colon. The only order to be followed is this: first the unnamed parameters, then the named ones. And, of course, mandatory parameters—those without a default value—must not be missing.
