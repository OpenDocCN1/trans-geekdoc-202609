# Note

When used in constructs where switch is used within the loop, the use of continue without an associated loop number will generate a warning as of PHP 7.3 (see Figure 5.28), as only the switch would exit, but not the loop.

![](bbox=[0.16, 0.196, 0.755, 0.448])

# Figure 5.28 Warning if "continue" Is Used in "switch"

There is therefore a risk of an endless loop here.

```
<?php
$i = 1;
while ($i < 10) {
    switch ($i) {
        case $i < 5:
            echo "Nothing ...<br />";
            continue;
        case $i >= 5:
            echo "$i<br />";
    }
    $i++;
}
?>
```
