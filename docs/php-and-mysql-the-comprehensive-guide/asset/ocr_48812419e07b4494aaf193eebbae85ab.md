```
class htmlspecialchars_filter extends php_user_filter {
    function filter($in, $out, &$consumed, $closing): int
    {
        while ($bucket = stream_bucket_make_writeable($in)) {
            $bucket->data = htmlspecialchars($bucket->data);
            $consumed += $bucket->datalen;
            stream_bucket_append($out, $bucket);
        }

        return PSFS_PASS_ON;
    }
}
```

With stream_filter_register(), you can register the class with the system under a name of your choice:

```
stream_filter_register(
    "string.htmlspecial",
    "htmlspecialchars_filter"
);
```

The stream_get_filters() function can be used to check whether the filter has actually been registered with the system. Then you can also use the filter.
