# ## Taking URLs Apart

If you need the individual parts of a URL—domain, host name, and so on—you can use parse_url(URL). You simply pass the URL as a string and receive an associative array with all the components it contains.

```
<?php
$url = "http://www.rheinwerk-verlag.de/index.php?Index+1%3DValue+1%26Index+2%3DValue+2";
$items = parse_url($url);
print_r($items);
?>
```
