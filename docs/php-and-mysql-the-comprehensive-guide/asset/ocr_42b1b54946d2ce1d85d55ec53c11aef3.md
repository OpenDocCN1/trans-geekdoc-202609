If you specify true as the second parameter for print_r(), you will receive the information about the variable or expression as the return value. This is useful if you do not want to send the output to the browser immediately:

```
$infos = print_r($days, true);
```

> Note
> As another special feature when dealing with objects, var_dump() only outputs public properties of objects. var_export() and print_r() also output private and protected properties. var_export() has another advantage: it returns reusable PHP code if you specify true as the second parameter.
