# Nested

You can nest if case distinctions into one another as you wish. The only condition is that you can still find your way through your tangled thoughts. The following example (see also Figure 5.15) shows a nested case distinction, which also illustrates the complexity of nesting.

```
$age = 20;
if ($age > 3) {
echo "At $age, the child has outgrown infancy.";
if ($age > 18) {
if ($age <= 21) {
echo "Already an adult?";
} else {
echo "Adult.";
}
} elseif ($age >= 10) {
echo "A teenager";
} else {
echo "A small child";
}
```
