The application consists of two parts: first, an include file in which a check is carried out for the existence of the session variable. If this variable does not exist, then a redirect is made to the login page. The special feature is that the current URL is appended so that a direct redirect to the original page is possible after login. The following listing shows the code for this.

```
<?php
session_start();

if (!isset($_SESSION["login"]) || $_SESSION["login"] != "ok") {
    $url = $_SERVER["SCRIPT_NAME"];
    if (isset($_SERVER["QUERY_STRING"])) {
        $url .= "?" . $_SERVER["QUERY_STRING"];
    }
    header("Location: login.php?url=" . urlencode($url));
}
?>
```
