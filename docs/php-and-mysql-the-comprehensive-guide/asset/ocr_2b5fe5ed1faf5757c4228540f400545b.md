# Binary Data

MySQL, like other databases, is able to store binary data such as files. Before we show you how to do this, let's start with a few brief general remarks. As a rule, there is already a database on the web server that can handle binary files very efficiently and securely: the file system. In practice, it is therefore often the case that the database only contains references to the files, such as their name and path. Nevertheless, it is also possible to store files in the database. It stores these as *binary large objects* (BLOBs).

MySQL supports some data types for the use of such BLOBs with different maximum sizes (see Table 19.1).

| Name | Maximum Size in Bytes (Approx.) |
| :--- | :--- |
| TINYBLOB | 256 |
| MEDIUMBLOB | 655.536 |
| BLOB | 1.677.216 |
| LONGBLOB | 4.294.967.296 |
