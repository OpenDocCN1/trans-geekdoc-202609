> **Note**
> Of course, this does not mean that all emails that you send from your desktop computer will not reach the recipient. It is always the IP address of the sending server that counts. So if you use your provider's mail server, its IP address is decisive (and usually not suspicious).

> **Tip**
> For testing, we recommend the smtp4dev tool from https://github.com/rnwood/smtp4dev. It's free, open-source and cross-platform development SMTP server. For Unix/Linux, PHP expects sendmail in any case. For users of qmail or postfix, this is not a problem at first, because both offer special wrappers that make the application think it is communicating with a sendmail server.
