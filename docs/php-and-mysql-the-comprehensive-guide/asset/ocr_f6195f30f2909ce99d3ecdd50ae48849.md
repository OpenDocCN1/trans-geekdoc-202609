# Multiple Return Values

With `return`, you only receive one return value. An array is generally used to obtain multiple values. You will learn more about arrays in Chapter 8. The following small example generates a multiplication series and returns it as an array (see Figure 6.8).

![](bbox=[0.143, 0.516, 0.722, 0.732])

# Figure 6.8 The Multiplication Series as an Array

```
<?php
function multiplication($a) {
    $products = [];
    for ($i = 1; $i <= 10; $i++) {
        $products[$i] = $a * $i;
    }
    return $products;
}
```
