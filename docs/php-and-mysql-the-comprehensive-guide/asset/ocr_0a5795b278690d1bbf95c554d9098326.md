4. Now the server still has to respond to calls. To do this, it needs the POST data from the call. We use the new php://input functionality instead of $HTTP_RAW_POST_DATA to read the data. A check helps here to avoid producing an error message when calling directly. Use the service(data) method to execute the server:

```
$data = file_get_contents("php://input") ?? "";
$server->service($data);
```
