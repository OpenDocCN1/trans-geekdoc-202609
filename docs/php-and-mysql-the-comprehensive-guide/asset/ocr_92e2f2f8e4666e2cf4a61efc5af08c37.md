```
$a = 2;
$n = 4;
$result = $a ** $n;
```

According to these lines, the $result variable has the value 16. The second operand is always the exponent; that is, this calculation corresponds to 2⁴.

As usual, it is also available in short form:

```
$result = 2;
$result **= 4;
```

# Connect Strings

In many programming languages, the plus symbol is used not only to connect numbers, but also to connect strings (see Figure 5.1). This is not the case in PHP. Instead, the dot (.) is used:

```
<?php
$a = "Everything new ";
$b = "May makes.";

$result = $a . $b;
echo $result;
?>
```
