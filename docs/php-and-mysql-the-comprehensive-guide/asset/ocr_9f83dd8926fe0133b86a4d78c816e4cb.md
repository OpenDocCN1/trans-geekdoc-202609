# # "protected"

If you use private, then a property or method only applies to the one class in which it is defined. protected has the same external protective effect as private, but such a property or method also applies to all classes in the class hierarchy.

```
<?php
class Computer {
    protected $CPU = "3 GHZ Mobile";
}

class Laptop extends Computer {
    public function getCPU() {
        return "The following CPU is on board: ".$this->CPU;
    }
}

$MyLaptop = new Laptop();
echo $MyLaptop->getCPU();
?>
```
