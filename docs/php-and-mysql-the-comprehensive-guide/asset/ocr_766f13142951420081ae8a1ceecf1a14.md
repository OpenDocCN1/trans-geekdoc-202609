# With Condition

Until now, you have only used switch, but switch also allows you to specify conditions for individual cases. For example, you can check ages in categories.

```
switch ($age) {
case $age >= 10 && $age < 30:
echo "You are between 10 and 29.";
break;
case $age >= 30 && $age < 50:
echo "You are between 30 and 49.";
break;
case $age >= 50 && $age < 70:
echo "You are between 50 and 69.";
break;
default:
echo "You do not fit into any of the categories.";
}
```

# Comparison between "if" and "switch"

When do you use if, and when is it better to use switch? There is no general answer to this question. In practice today, switch is mainly used to check values. Conditions are usually checked with if.

The syntax of switch takes a little getting used to. It is actually slightly shorter than an if case distinction with curly brackets, but switch requires the break statement.
