> > **Tip**
> > To obtain the highest error level regardless of the version, you can use error_reporting (-1). The -1 parameter takes all error levels. Since PHP 5.4, E_ALL behaves in the same way; that is, future error levels are also automatically taken into account.

Any errors that occur can be intercepted relatively easily with set_error_handler (function name, error). The first parameter of this function specifies a function name for the handler. The handler then receives the error type as a number, the error string, the error file, and the line in which the error occurred. The second parameter is optional and allows you to specify the error level to be intercepted—here, for example, E_WARNING. In the following listing, you catch all E_WARNING errors and let the others through. Figure 11.35 shows one result.

```
<?php
function error_handler($errno, $errstr, $errfile, $errline) {
    switch ($errno) {
        case E_WARNING:
            echo "WARNING: [$errno] $errstr<br />";
            break;
        default:
            echo "No E_WARNING error";
            break;
    }
    return true;
}
set_error_handler("error_handler", E_WARNING);
```
