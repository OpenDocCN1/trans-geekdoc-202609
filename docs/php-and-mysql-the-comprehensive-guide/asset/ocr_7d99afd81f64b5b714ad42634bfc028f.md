# 11.3.9 Constants

Constants should be familiar from Chapter 4. In PHP, there are also constants within classes. You define these constants with the const keyword and then access them with the double colon (::). This works inside and outside the class.

```
<?php
class Computer {
const sec = "15 seconds";
public function start() {
return "Computer starts in " . Computer::sec;
}
}
$MyComputer = new Computer();
echo $MyComputer->start() ."<br />";
echo "And again in " . Computer::sec;
?>
```
