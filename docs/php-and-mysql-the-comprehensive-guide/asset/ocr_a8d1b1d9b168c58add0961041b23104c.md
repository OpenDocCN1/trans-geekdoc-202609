# Last Inserted Autovalue

The old problem: If a table has an autovalue (or, in the case of PostgreSQL, a SERIAL data type with an automatically created sequence), it is of course interesting to find out what ID the newly created value has. There are two ways to do this:

+   - You use the SELECT command to query the CURRVAL property of the sequence.
+   - You determine the oid and then the autovalue from this (using SELECT).

We show the second option. Conveniently, the pg_last_oid() function returns the oid value of the last query (the return value of pg_query() is passed as a parameter). The following code example inserts a value into the test table and determines the corresponding ID.

```

$oid = pg_last_oid($result);
$result = pg_query($db,
    "SELECT id FROM my_table WHERE oid=$oid");
$row = pg_fetch_row($result);
$id = $row[0];
echo "Entry with ID $id added.";
```
