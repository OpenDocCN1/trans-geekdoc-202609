> **Note**
> Because the parameter value is passed *by reference*, you cannot pass a value directly in `mysqli_stmt_bind_param()` but need a variable regardless.

Finally, execute the SQL command: with OOP access, using the `execute()` method; in a procedural approach, by calling the `mysqli_stmt_execute()` function .

The complete example is provided in the following listing.

```
```php
<?php
if ($db = mysqli_connect("localhost", "user", "password", "PHP")) {
    $sql = "INSERT INTO table (field) VALUES (?)";
    $command = mysqli_prepare($db, $sql);
    mysqli_stmt_bind_param($command, "s", $value);
    $value = "value3";
    if (mysqli_stmt_execute($command)) {
        echo "Data entered.<br />";
    } else {
        echo "Error!";
    }
    mysqli_close($db);
} else {
    echo "Error!";
}
?>
```
