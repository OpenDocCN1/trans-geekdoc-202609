The new class *extends* an existing class. This means that it adopts all the properties and methods of this class and then defines its own.

Consider the following small example.

```
<?php
class Computer {
    public $CPU = "The CPU";
    public function start() {
        return "Computer is started.";
    }
}

class Laptop extends Computer {
    public $Display = "15 inch";
}

$MyLaptop = new Laptop();
$MyLaptop->CPU = "2.5 GHz Mobile";
echo "CPU: $MyLaptop->CPU<br/>";
echo "Display: $MyLaptop->Display";
?>
```
