> Tip
> The output of the homepage is even faster (and without a while loop) if you use file_get_contents(). This function also supports streams.

If you have a file handle, you can display metadata about the stream. Depending on the stream type, this may be different information. The stream_get_meta_data() function returns all this data as an array (see Figure 26.2). Let’s take a look at this when the PHP homepage is read in (again) in the following listing.

```
<?php
$file = fopen("https://www.php.net/", "r");
echo "<pre>";
echo htmlspecialchars(
    print_r(stream_get_meta_data($file), true)
);
echo "</pre>";
fclose($file);
?>
```
