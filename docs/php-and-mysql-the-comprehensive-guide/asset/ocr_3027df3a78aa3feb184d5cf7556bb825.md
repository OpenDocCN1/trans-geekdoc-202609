# 11.4.8 Automated Reading of Objects

You can read the properties of an object automatically. The best method is the foreach loop. It runs through all the properties of an object and returns their values. Its basic syntax is as follows:

```
foreach (object as value) {
statements;
}
```

In practice, the whole thing looks like this: The foreach loop goes through all the properties. You save the values in the $value variable, and these are then output within the loop (see Figure 11.45).

```
<?php
class Computer {
public $CPU = "The CPU";
public $RAM = 1024;
}
$MyComputer = new Computer();
foreach ($MyComputer as $value) {
echo $value ."<br />";
}
?>
```
