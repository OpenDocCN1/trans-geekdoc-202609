The rest is relatively simple: put together an INSERT statement, call exec(), and you're done. As a special treat, the administration form for the new entry is linked. Of course, this has no place in a production system, but here it demonstrates the use of lastInsertRowID().

if (isset($_POST["Name"]) &&
isset($_POST["Email"]) &&
isset($_POST["Heading"]) &&
isset($_POST["Comment"])) {
try {
$db = new SQLite3("guestbook.db");
$sql = vsprintf("INSERT INTO guestbook
(heading,
entry,
author,
email,
date)
VALUES ('%s', '%s', '%s', '%s', '%s')",
[
$db->escapeString($_POST["Heading"]),
$db->escapeString($_POST["Comment"]),
$db->escapeString($_POST["Name"]),
$db->escapeString($_POST["Email"]),
time()
]);
if ($db->exec($sql)) {
$id = $db->lastInsertRowID();
echo "Entry added."
<a href="gb-edit.php?id=$id">Edit</a>");
} else {
echo "Error!";
}
} catch (Exception $ex) {
echo "Error: " . $ex->getMessage();
}
}
