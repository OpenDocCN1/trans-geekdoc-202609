# 11.4.2 "spl_autoload_register()"

The spl_autoload_register(function) registers a function, that reacts to all calls to classes that are not directly available. You can then react accordingly.

```
<?php
function autoloader($class) {
    echo "The class $class does not exist!";
}

spl_autoload_register('autoloader');
$MyComputer = new Computer();
?>
```
