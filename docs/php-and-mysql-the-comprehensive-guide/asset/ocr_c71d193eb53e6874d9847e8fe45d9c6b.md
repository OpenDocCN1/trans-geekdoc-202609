} else {
   echo "Variable not set";

# Listing 4.9 "isset()" ("isset.php")

In the preceding example, the variable is set and is therefore output. But what if you do not assign a value to the variable at all?

```
$test;
if (isset($test)) {
   echo $test;
} else {
   echo "Variable not set";
}
```

In this case, the alternative text variable is not set.

> **Note**
> isset() also returns false if a variable has the value NULL (no value).

# "empty()"

A similar test to `isset()` is performed by `empty()`. `empty(Variable)` checks whether a variable is empty (see Figure 4.6). However, an empty variable is also an empty string or 0. This is the difference from `isset()`.

```
<?php
$test = "";
if (empty($test)) {
   echo "Variable is empty";
} else {
   echo $test;
}
?>
```
