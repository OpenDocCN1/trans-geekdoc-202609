The return format is an associative array. The key is the original; the value is the target of the conversion. For the third parameter, quotation_marks, choose from the three already known options (see the earlier section on converting special characters).

```
<?php
$table = get_html_translation_table();
foreach ($table as $key => $value) {
	echo htmlentities($key) . " becomes " . htmlentities($value) .
	"<br />";
}
?>
```

# Remove Tags

The strip_tags(String, Protected) function strips PHP and HTML tags from a string without replacing them. In the Protected string, enter the tags one after the other that you want to save before replacing them. Be careful: the tags must not be in XHTML notation, and only the opening tag is possible! Upper- and lowercase letters, on the other hand, make no difference.

In the following example, the paragraph (<p> and </p>) is removed, but the line break (<br />) is retained:

```
$a = "<p>Text in paragraph with<br /> line break</p>";
echo strip_tags($a, "<BR>");
```

# 7.6.4 URLs

A URL—that is, a web address—allows additional information to be attached. This information follows the file name and a question mark. However, there is a specific format for this.16 To create this format, use urlencode(String). To convert a URL back, use urldecode(URL). Figure 7.19 shows an example.

```
<?php
$rheinwerk = "http://www.rheinwerk-verlag.de/index.php?";
$anhang = "Index 1=Value 1&Index 2=Value 2";
echo $rheinwerk . urlencode($anhang);
?>
```
