# 6.1.1 Parameters

Functions resemble black boxes. The functionality is contained in the statements within the function. The external caller does not need to know exactly what the statements look like, but they should be able to pass information to the function. This works with parameters.

You write the parameters in the function between the round brackets. The parameter names are treated like variable names and are available within the function:

```
function Name($Parametername1, $Parametername2) {
 statements;
}
```

When you call the function, you must pass values for the parameters to the function:

```
Name(Value1, Value2);
```
