The while loop has only one "built-in" functionality—namely, the condition:

```
while (condition) {
statements;
}
```

The loop is executed as long as the condition is true. However, for the loop to terminate at some point, part of the condition must change. The for loop provides the run-through statement for this purpose; in the while loop, you have to create it yourself.

Take a look at the following example.

```
```php
<?php
$i = 1;
while ($i < 10) {
    echo "$i<br />";
    $i++;
}
?>
```
