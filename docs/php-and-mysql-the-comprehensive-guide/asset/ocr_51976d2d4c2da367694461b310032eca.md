# ## 26.2.2 HTTP Streams

Does it make sense to open an HTTP address using `fopen()`? If it is a matter of reading the data on the website, definitely. It also follows from this which file mode must be specified for `fopen()`: "r", of course, because you can only read the data, not write it. The following script reads in the PHP homepage and outputs it (see Figure 26.1); remember to activate OpenSSL as described earlier.

```
```html
<h1>The PHP homepage</h1>
<?php
$file = fopen("https://www.php.net/", "r");
while (!feof($file)) {
    $line = fread($file, 4096);
    echo $line;
}
fclose($file);
?>
