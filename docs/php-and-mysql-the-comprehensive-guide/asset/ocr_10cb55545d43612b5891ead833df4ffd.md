+   - The constructor generally receives the element that is to be run through and saves it in a property.
+   - current() returns the value of the part element currently being run through.
+   - next() jumps to the next subelement.
+   - rewind() jumps to the first subelement.
+   - key() returns the key of the current subelement, which is usually also stored in a property.
+   - valid() determines whether partial elements are still present.
