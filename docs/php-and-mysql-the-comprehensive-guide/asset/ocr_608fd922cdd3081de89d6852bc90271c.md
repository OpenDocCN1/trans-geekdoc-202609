# 37.2.2 Reading HTTP Headers

The $_SERVER superglobal array contains many of the environment and server variables, but not all of them. This does not allow complete access to the HTTP header. However, if PHP is integrated into the web server, then the scripting language is close enough to the "heart" of the HTTP request and response so that complete access is possible.

PHP provides the apache_request_headers() and apache_response_headers() functions, which can be used to determine the HTTP headers of the request and the response as an associative array (see Listing 37.2). The one header shown in Figure 37.3 is generated by PHP; all other headers are generated by Apache after PHP has finished its work.
