# ## 37.2.4 Integrate Other Server Technologies

If other scripts are to be integrated, PHP usually uses one of the following constructs: include, include_once, require, or require_once. However, this fails if the file included in this way does not contain any PHP or HTML code. In an increasingly heterogeneous world, it may well be that although the main website runs under PHP, parts of it have still been implemented in Perl or another technology.

At this point, Listing 37.4 provides a very simple example. Imagine that you have "inherited" a Perl website but want to convert it to PHP. However, there is a script that you simply cannot rebuild in PHP and therefore want to continue using.
