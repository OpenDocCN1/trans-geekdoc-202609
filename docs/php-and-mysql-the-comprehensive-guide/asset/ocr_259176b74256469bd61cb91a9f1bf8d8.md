```
for ($i = 0; $i < 10; $i++) {
    echo "$i<br />";
}
```

# Listing 5.21 The "for" Loop ("for.php")

Here, variable $i is initialized with the value 0 in the start statement. It is the counter variable. The condition is that $i remains less than 10. In the statement block, $i and a line break are output. The run-through statement increases $i by 1 using an increment. Can you imagine what the loop outputs? That’s right: the numbers from 0 to 9, as shown in Figure 5.20.

# Endless Loops

The run-through statement is used to ensure that the condition is no longer fulfilled at some point. If this does not work—that is, the condition is always fulfilled—then the loop is executed endlessly (see Figure 5.21).

```
for ($i = 0; $i < 10; $i--) {
    echo "$i<br />";
}
```
