You are offered two installers on the download page: The smaller one downloads all the required packages from the internet, while the larger one has everything included and can be used offline.

> > **Note**
> > As of MySQL version 8, there is a new way of encrypting passwords. Using it is recommended in principle, but it also requires that the remote site use at least version 8 of the MySQL client libraries. PHP is compatible in all current versions.

Among other things, you will be asked to enter a password (as secure as possible!) for the MySQL administrator user; this user is called root. You can also run MySQL automatically as a service when Windows starts. If you do this and look at Windows Task Manager after the installation, you will see that a MySQL service is actually running (see Figure 19.2).
