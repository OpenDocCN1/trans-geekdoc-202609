# 9.1.3 Convert Numbers

Humans generally calculate generally use the decimal number system based on 10 digits. However, a number can also be represented in other number systems. The most important are as follows:

+   Hexadecimal

In this system, the digits range from 0 to 15. The two-digit numbers are represented by letters: from A for 10 to F for 15.
