As a solution, we combine the trick for correct sorting with the uasort(Array, sort function) function, which allows its own sorting function (see Figure 5.5). The sort function always compares two elements of the array and returns either 0 (equal), 1 (parameter a greater than b), or -1 (parameter b greater than a) as the result of the comparison.

```
```php
<?php
$collection = array("Monet", "chagal", "Dali", "Manet");

uasort($collection, "sort");

function sortFunction($a, $b) {
    $a_low = strtolower($a);
    $b_low = strtolower($b);

    if ($a_low == $b_low) {
        return 0;
    } elseif ($a_low > $b_low) {
        return 1;
    } else {
        return -1;
    }
}

echo "$collection[0] und $collection[3]";

?>
