# "is_null()"

The is_null(Variable) function is also one of the auxiliary and test functions. It tests whether a variable has the value NULL (no value).

```
<?php
$test = null;
if (is_null($test)) {
    echo "Variable is NULL";
} else {
    echo "Variable is not NULL, but " . $test;
}
?>
```
