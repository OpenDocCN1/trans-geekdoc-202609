# 29.4 EXIF

There are thousands of application examples for XML. In principle, XML is used wherever data needs to be stored and exchanged. In this section, XML is used to store image information. Meta information for digital cameras is stored in Exchangeable Image File Format (EXIF).2

Our application should allow the user to upload an image. Part of its EXIF data is then read and packed into an XML file. A second script accesses the XML file and reads a small part of the data.

# 29.4.1 Preparation

In order for PHP to access EXIF data, you need the corresponding extension. Under Linux, configure PHP with --enable-exif. Under Windows, simply comment out the following line by removing the semicolon:

```
extension=php_exif.dll
```

2 EXIF is a standard for storing information about a camera and photo and shooting parameters. However, there are a number of other metadata formats, such as Adobe's Extensible Metadata Platform (XMP), that are partly based on XML.
