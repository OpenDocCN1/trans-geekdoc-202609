# Listing 19.10 All Query Data as an Object ("mysqli-read-object-oop.php")

Last but not least, a third method should be introduced (don't worry, there are others): reading as a numeric array. This is useful, for example, if you need to read tables whose structure you do not know. Or if you have a query such as SELECT COUNT() where it is difficult to determine the column name (unless you use an alias). At this point, it is easy to access the table data via the numerical index. This method is also very fast. The corresponding PHP function is called mysqli_fetch_row(), and the method is analogous to fetch_row().

```
```php
<?php
if ($db = mysqli_connect("localhost", "user", "password", "PHP")) {
    $sql = "SELECT * FROM my_table";
    if ($result = mysqli_query($db, $sql)) {
        echo "<ul>";
        while ($row = mysqli_fetch_row($result)) {
            echo "<li>" . htmlspecialchars($row[0]) .
                ": " . htmlspecialchars($row[1]) . "</li>";
        }
    }
}
