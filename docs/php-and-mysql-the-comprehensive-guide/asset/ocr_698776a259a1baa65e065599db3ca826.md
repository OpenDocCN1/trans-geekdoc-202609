And even beyond these two points, which always apply, language constructs have some special features. For example, echo() can accept several parameters, such as

```
`echo "Hello ", "PHP 8.3";`
```

or

```
`echo ("Hello "), ("PHP 8.3");`
```

However, this fails if the parameters are enclosed in round brackets (see Figure 6.22):

```
`echo ("Hello ", "PHP 8.3");`
```
