# ## 8.4.3 Connect

To connect two or more arrays, use array_merge(Array1, Array2 ...). You simply specify the arrays one after the other. They then appear as shown in Figure 8.16.

```
<?php
$days = array("Saturday", "Sunday", "Monday", "Tuesday");
$stockprices = array("IBW" => 232, "Miemens" => 34, "Rheinwerk" => 340);
$new = array_merge($days, $stockprices);
print_r($new);
?>
```
