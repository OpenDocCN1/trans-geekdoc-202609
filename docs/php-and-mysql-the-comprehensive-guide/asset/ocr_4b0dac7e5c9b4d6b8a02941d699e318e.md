# "global"

If you want to use a global variable in a function, you must explicitly define it with the global keyword. This lets the PHP interpreter know that it has to get the global variable (see Figure 6.7).

```
<?php
$global = "Global variable";
function output() {
global $global;
echo $global;
}
output();
?>
```
