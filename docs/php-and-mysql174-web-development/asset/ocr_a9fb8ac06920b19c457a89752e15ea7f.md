The feof() function takes a file handle as its single parameter. It returns true if the file pointer is at the end of the file. Although the name might seem strange, you can remember it easily if you know that feof stands for End Of File.

In this case (and generally when reading from a file), you read from the file until EOF is reached.

# Reading a Line at a Time: fgets(), fgets(), and fgetcsv()

In this example, you use the fgets() function to read from the file:

```
$order= fgets(\$fp);
```

This function reads one line at a time from a file. In this case, it reads until it encounters a newline character (\n) or EOF.

You can use many functions to read from files. The fgets() function, for example, is useful when you're dealing with files that contain plain text that you want to deal in chunks.

An interesting variation on fgets() has the following prototype:
fgetcsv(resource fp, int length[, string allowable_tags]);

This function is similar to fgets() except that strips out any PHP and HTML tags found in the string. If you want to leave in any particular tags, you can include them in the allowable_tags string. You would use fgetcsv() for safety when reading a file written by somebody else or one containing user input. Using unrestricted HTML code in the file could mess up your carefully formatted planning. Allowing unrestricted PHP or JavaScript could give a malicious user an opportunity to create a security problem.

The function fgetcsv() is another variation on fgets(). It has the following prototype:
fgetcsv( resource fp, int length [, string delimiter[, string enclosure[, string escape]])

This function breaks up lines of files when you have used a delimiter character, such as the tab character (as suggested earlier) or a comma (commonly used by spreadsheets and other applications). If you want to reconstruct the variables of order separated rather than as a line of text, fgetcsv() allows you to do this simply. You can call it in the same way as you call fgets(), but you pass the delimiter you used to separate fields. For example,

```
$order= fgetcsv(\$fp, 0, "\t");
```

This code would retrieve a line from the file and break it up wherever a tab (\t) was encountered. The results are returned in an array ($order in this example). We cover arrays in more detail in Chapter 3.
