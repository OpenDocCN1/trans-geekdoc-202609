# Getting Information with SHOW

Previously, you used

```
mysql> SHOW TABLES;
```

to get a list of tables in the database.

The statement

```
mysql> SHOW DATABASES;
```

displays a list of available databases. You can then use the SHOW TABLES statement to see a list of tables in one of those databases:

```
mysql> SHOW TABLES FROM bookora;
```

When you use SHOW TABLES without specifying a database, it defaults to the one in use.

When you know what the columns are, you can get a list of the columns:

```
mysql> SHOW COLUMNS FROM Orders FROM bookora;
```

If you leave off the database name, the SHOW COLUMNS statement will default to the database currently in use. You can also use the table.`column` notation:

```
mysql> SHOW COLUMNS FROM bookora.Orders;
```

One other variation of the SHOW statement can be used to see what privileges a user has. For example, if you run

```
mysql> SHOW GRANTS FOR 'bookora';
```

you get the following output:

| Grants for bookora@* |
|---|
| GRANT USAGE ON '*' TO 'bookora'@'%' IDENTIFIED BY PASSWORD |
| '*1ECE6E4864143A8A2E191D00740D35CEE9EB80A85' |
| GRANT SELECT, INSERT, UPDATE, DELETE ON `bookora`.* TO 'bookora'@'%' |

2 rows in set (0.00 sec)

The GRANT statements are not necessarily the ones that were executed to give privileges to a particular user, but rather similar equivalent statements that would produce the user's current level of privilege.
