The final event we listen to our jQuery script is the submit event, which is triggered when the form is submitted. Our selector specifies this listener should be limited to the form whose ID is myForm and this is as follows:

```
$('#myForm').on('submit', function(event) {
  var first_name = $(first_name).val();
  var last_name = $(last_name).val();

  console.log("The form was submitted;" + first_name + " " + last_name + "!");
  alert("Hello, " + first_name);
});
```

As this listener is simplistic for example purposes, and only extracts the final value of each input field before displaying an alert using the native JavaScript alert function. It updates the HTML page to reflect that the form was submitted.

# Using jQuery and AJAX with PHP

Along with all the powerful HTML document manipulation available to us an entire suite of functionality to communicate asynchronously with backend web servers. This functionality is built into the implementation of JavaScript within the web browser, but using jQuery makes it easier because browser tends to do things slightly differently and jQuery kindly abstracts details away into a consistent API. The result is you can expect your jquery to function similarly across the entirety of browser implementations, with few (and not really) exceptions.

To get started with AJAX and jQuery, we are going to build a simple web-based real-time chat application. This application will allow multiple users to currently with each other from their browsers, and receive these messages without refreshing the browser window at all.
