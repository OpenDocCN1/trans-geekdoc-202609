Part 2 of the script sets up some variables that you will use to draw the graph.

Working out the values for these sets of variables can be tedious, but a bit of foresight about how you want the finished image to look will make the drawing process much easier. We arrived at the values used by sketching the desired effect on a piece of paper and estimating the required proportions.

The $width is the total width of the canvas you use. You also set up the left and right margins ($left_margin and $right_margin, respectively); the "fatness" and spacing between the bars ($bar_height and $bar_spacing) and the font, font size, and label position ($font_name, $title_size, $main_size, $small_size, and $text_indent).

Given these values, you can make a few calculations. You want to draw a baseline that all the bars stretch out. You can work out the position for this baseline by using the left margin an allowance for the text labels for the x coordinate and gain an estimate from the sketch for the y coordinate. You could get the width of the longest name instead if flexibility is important.

You also work out two important values: first, the distance on the graph that represents one unit:
$bar_unit = ($width-$x+$right_margin)) / 100; // one "point" on the graph
