errors also are often called parser errors when discussing interpreted languages, such as PHP, or compiler errors when discussing compiled languages, such as C or Java.

If you break the English language's syntax rules, it is a pretty good chance that people will still know what you intended to do. This is often not the case with programming languages. If a script does not follow the rules of PHP's syntax—if it contains syntax errors—the PHP parser will not be able to process some or all of it. People are good at inferring information from partial or conflicting data.

Among many other rules, the syntax of PHP requires that statements end with semicolons; strings are enclosed in straight quotation marks, and parameters passed to functions are separated by commas and enclosed in parentheses. If you break these rules, your PHP script is unlikely to work and will generate an error message the first time you try to execute it.

One of PHP's greatest strengths is the useful error message it provides when things go wrong. A PHP error usually tells you what went wrong, which line the error occurred in, and why the error was found.

An error message reveals the following:

```
Parse error: syntax error, unexpected '''; (T_ENCAPSED_AND_WHITESPACE), expecting ',' or ')' in /var/www/pmd5/chapter26/error.php on line 2
```

This error was produced by the following script:

```
<?php
$date = date('m.d.y');
?>
```

You can see that we attempted to pass a string to the date() function but accidentally missed the opening quotation mark that would mark the beginning of the string.

Simple syntax errors as this one are usually the easiest to find. Additionally, errors can be hard to find if they result from a combination of multiple files. They can also be difficult to find if they occur in a large file. Seeing parser error on line 1001 of a 1000-line file is enough to spoil your day, but it should provide a subtle hint that you should try to write more modular code.

In general, syntax errors are the easiest type of error to find. If you make a syntax error and try to execute the code of PHP, PHP will give you a message telling you where to find your mistake.
