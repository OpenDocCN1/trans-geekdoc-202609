# Namespaces

Namespaces are a way of grouping a set of classes and/or functions. They can be used to collate a set of related pieces into a library.

Prior to namespaces, the only option for grouping classes or functions by name was to prefix them. For example, you might have a library of classes used for email-related functions, and named them all beginning with the prefix Mail. Namespaces provide a better solution for collation of related code, and in addition solve two common problems.
