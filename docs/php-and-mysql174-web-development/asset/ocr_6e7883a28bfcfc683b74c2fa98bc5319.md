The code in Listing 6.2 creates TLA Consulting's page and gives output similar to that previously generated in Figure 5.2. The code in Listing 6.2 does the following:

+   1. Uses require to include the contents of page.php, which contains the definition of the class Page.

+   2. Creates an instance of the class Page. The instance is called $homepage.

+   3. Sets the content, consisting of some text and HTML tags to appear in the page. (This implicitly invokes the __set() method.)

+   4. Calls the operation Display() within the object $homepage to cause the page to be displayed in the viewer's browser.

Listing 6.2 home.php—This Page Uses the Page Class to Do Most of the Work Involved in Generating the Page

```
<?php
require("page.php");

$homepage = new Page();

$homepage->content = <!--
<section>
<h2>Welcome to the home of TLA Consulting.</h2>
<p>Please take some time to know us.</p>
<p>We specialize in serving your business needs
and hope to hear from you soon.</p>
</section>-->

$homepage->Display();
?>
```

You can see in Listing 6.2 that you need to do very little to generate new pages using this Page class. Using the class in this way means that all your pages will be similar.

If you want some sections of the site to use a variant of the standard page, you could copy page.php to a new file page2.php and make some changes. This time you update or fix parts of page.php, you need remember to make the same changes to page2.php.

A better course is to use inheritance to create a new class that inherits most of its functionality from Page but overrides the parts that need to be different. For the TLA site, it is a requirement that the services page includes a second navigation bar. The strip shown in Listing 6.3 does this by creating a new class ServicesPage that inherits from Page. This row contains the buttons and links you want in the second row. Because you want this class to behave in the same way, you override only the part you changed: the Display() operation.
