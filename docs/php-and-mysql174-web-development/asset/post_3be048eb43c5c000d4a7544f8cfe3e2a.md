The advantage of printf() is that you can use a more useful conversion specification to specify that $total is a floating-point number and it should have two decimal places after the decimal point, as follows:

```
printf("Total amount of order is %.2f", $total);
```

Given this formatting, 12.4 stored in $total, this statement will print 12.40.

You can have multiple conversion specifications in the format string. If you have n conversion specifications, you will usually have n arguments for the format string. Each conversion specification will be replaced by a reformatted argument in the order they are listed. For example:

```
printf("Total amount of order is %.2f (with shipping %.2f)",
$total, $total_shipping);
```

Here, the first conversion specification uses the variable $total, and the second uses the variable $total_shipping.

Each conversion specification follows the same format, which is
`%[ 'padding_character'] [-width] [.precision] type`

All conversion specifications start with a % symbol. If you want to print a % symbol, you need to use %%%. By default, only values that are negative show a sign (in

The padding_character is optional. It is used to pad your variable to the width you have specified. An example would be to add leading zeros to a number like a counter. The default padding character is a space. If you are specifying a space or zero, you do not need to prefix it with the apostrophe ('). For any other padding character, you need to prefix it with an an

The – symbol is optional. It specifies that the data in the field will be left-justified rather than right-justified, which is the default.

The width specifier tells printf() how much room (in characters) to leave for the variable to be substituted in.

The precision specifier should begin with a decimal point. It should contain the number of places after the decimal point you would like deplayed.

## Joining and Splitting Strings with String Functions

Often, you may want to look at parts of a string individually. For example, you might want to look at words in a sentence (for spellchecking) or split a domain name or address into its component parts. PHP provides several string functions (and regular expression functions) that allow you to do this.

In this example, Bob wants any customer feedback from bigcustomer.com to go directly to him, so you can split the email address typed into parts to find out whether or not works for Bob.

## Using explode(), implode(), and join()

The first function you use for this purpose, explode(), has the following prototype:
`explode(string separator, string input [, int limit]);`

This function takes a string input and splits it on specified separator. The pieces are returned in array. You can limit the number of pieces with the optional limit.

To get the name from the customer's email address in the script, you can use

```
$email_array = explode('@', $email);
```

This call to explode() splits the customer's email into two parts: the username, which is stored in $email_array[0], and the domain name, which is stored in $email_array[1].

## Joining and Splitting Strings with String Functions

Now you can test the domain name to determine the customer's origin and then send the feedback to the appropriate person:

```
if ($email_array[1] == "bigcustomer.com") {
  $toaddress = "bob@example.com";
} else {
  $toaddress = "feedback@example.com";
}
```

If the domain is capitalized or mixed case, this approach will not work. You could avoid this problem by first converting the domain to uppercase or lowercase and checking for a match, as follows:

```
if (strtolower($email_array[1]) == "bigcustomer.com") {
  $toaddress = "bob@example.com";
} else {
  $toaddress = "feedback@example.com";
}
```

You can reverse the effects of explode() using either implode() or join(), which are identical. For example,

```
$new_email = implode('@', $email_array);
```

This statement takes array elements from $email_array and joins them with the string passed in.

## Using strtok()

Unlike explode(), which breaks a string into all its pieces at one time, strtok() gets pieces (called tokens) from a string at a time. strtok() is a useful alternative to using explode() for processing words from one string at a time.

The prototype for strtok() is

```
string strtok(string input, string separator);
```

The separator can be either a character or a string of characters, but the input string is split on each of the characters in the separator rather than on the whole separator string (as explode does).

Calling strtok() is not as simple as it seems in the prototype. To get the first token from a string, you call strtok() with the string you want tokenized and a separator. To get the subsequent tokens from the string, you just pass a single parameter—the separator. The function keeps its internal pointer to its place in the string. If you want to reset the pointer, you can pass the string into it again.
