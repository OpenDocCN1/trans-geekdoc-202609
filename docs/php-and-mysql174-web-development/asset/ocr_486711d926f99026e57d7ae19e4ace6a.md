On these servers, you likely will not have access to php.ini, and you will not be able to set all the options you would like. In extreme cases, services will not even allow you to create directories outside of your document root directory, depriving us of a safe place to put our include design. Fortunately, most of these companies want to remain in business, and an insecure design is not a good way to keep customers.

To be certain, and can do a number of things as you look into a service and deploy your web applications here:

+   - Before you select a shared hosting service, look through their support listings. Better services will have online documentation that shows exactly how your private space is configured. You can get a feel for what restrictions and support you will have by browsing through these.

+   - Look for hosting services give you entire directories, not just a document root. Although some will state you a complete directory hierarchy, as one in which public_html is where you place your content and executable PHP scripts.

+   - Try to find out values they have used in php.ini. Many who will probably not print these on a web page or email the file, you can ask their support personnel questions about what safe mode is on, and which functions and classes are disabled. You can also use the ini_get function to set setting values. Sites not using safe mode or with any functions at all will worry you more than those with some reasonable sounding configuration.

+   - Look at what versions of the various pieces of software they are running. Are they the most recent ones?

+   - Look for services that offer trial periods, money-back guarantees, or some other way of seeing firsthand your web applications run before committing to use them for a longer period of time.

+   - Although some developers still prefer a shared hosting environment because they don't want to deal with system administration tasks, seriously consider using one of the many excellent cloud providers such as Amazon AWS, or platform as a service (PaaS) providers such as Heroku. Performing your operations in such an environment is significantly simplified over to manage actual machines, and there are many excellent tutorials available online. These services make keeping up with newer versions software very simple.
