# Closing a File

After you've finished using a file, you need to close it. You should do this by using the
fclose() function as follows:

```
fclose($fp);
```

This function returns true if the file was successfully closed or false if it wasn't. This process
is much less likely to go wrong when opening a file in the first place, so in this case we have
chosen not to test it.
