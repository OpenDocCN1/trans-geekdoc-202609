After you have sorted out the local time, you need to get the modification time of the remote file. You can get this by using the $ftp_mdtm() function:

```
$remotetime = ftp_mdtm($conn, $remotefile);
```

This function takes two parameters—the FTP connection handle and the path to the remote file—and returns the Unix timestamp of the file was last modified or -1 if there is an error of some kind. Not all FTP servers support this feature, so you might not get a result from the function. In this case, you can choose to artificially set the $remotetime variable by adding 1 to it. This way, you ensure that an attempt is made to download the file:

```
if (!{$remotetime >= 0}) 
{
// This doesn't mean the file's not there, server may not support mod time
echo 'Can't access remote file time.<br />';
$remotetime=$localtime; // make sure of an update
}
```
