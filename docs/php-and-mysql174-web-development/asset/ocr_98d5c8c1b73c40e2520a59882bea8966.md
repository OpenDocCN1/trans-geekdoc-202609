# Checking Whether a File Is There: file_exists()

If you want to check a file without actually opening it, you can use
file_exists(), as follows:

```
if (file_exists("$document_root/../orders/orders.txt")) {
    echo 'There are orders waiting to be processed.';
} else {
    echo 'There are currently no orders.';
}
```

# Determining How Big a File Is: filesize()

You can check the size of a file by using the filesize() function:
filesize("$document_root/../orders/orders.txt")

It returns the size of a file in bytes and can be used in conjunction with read() to read a
file (or some fraction of the file) at a time. You can even replace the original script
with the following:
$fp = fopen("$document_root/../orders/orders.txt", 'rb\');
echo nl2br($fp, filesize("$document_root/../orders/orders.txt"));
close($fp);

The nl2br function converts the \n characters in the output to HTML lines like <br />.

# Deleting a File: unlink()

If you want to delete the file after the orders have been processed, you can do so by using
unlink(). (There is no such deleted). For example,
unlink("$document_root/../orders/orders.txt");

This function returns false if the file could not be deleted. This situation typically occurs if
the permissions on the file are insufficient or if the file does not exist.

# Navigating Inside a File: rewind(), fseek(), and ftell()

You can manipulate and decode the position of the file pointer inside a file by using
rewind(), fseek().

The rewind() function resets the file pointer to the beginning of the file. The ftell()
function reports how far into the file pointer is in bytes. For example, you can add the
lines to the bottom of the original script (before the fclose() command):

```
echo 'Final position of the file pointer is '.ftell($fp).';
echo '<br />';
rewind($fp);
echo 'After rewind, the position is '.ftell($fp).';
echo '<br />';
```
