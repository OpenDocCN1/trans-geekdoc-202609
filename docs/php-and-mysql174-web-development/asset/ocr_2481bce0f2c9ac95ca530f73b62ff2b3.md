Imagine we are somewhere in the `bob\html\page` namespace, and there just happens to be a globally declared Class. If you wanted to access this, you could do so by using the backslash in front of the class name, like this:

```
$services = new \Page();
```

# Importing and Aliasing Namespaces

The use statement is used to import and alias namespaces. For example, if we want to use code from the `bob\html\page` namespace, we could do the following:

```
use bob\html\page;
$services = new \Page();
```

This code enables us to use the shortcut or alias page to mean the namespace `bob\html\page`. We could also alias it as something completely different:

```
use bob\html\page as www;
$services = new www\Page();
```
