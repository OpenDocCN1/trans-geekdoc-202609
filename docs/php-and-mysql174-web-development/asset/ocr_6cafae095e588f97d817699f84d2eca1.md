# Joining and Splitting Strings with String Functions

Often, you may want to look at parts of a string individually. For example, you might want to look at words in a sentence (for spellchecking) or split a domain name or address into its component parts. PHP provides several string functions (and regular expression functions) that allow you to do this.

In this example, Bob wants any customer feedback from bigcustomer.com to go directly to him, so you can split the email address typed into parts to find out whether or not works for Bob's blog.

# Using explode(), implode(), and join()

The first function you use for this purpose, explode(), has the following prototype:
explode(string separator, string input [, int limit]);

This function takes a string input and splits it into pieces on a specified separator string. The pieces are returned in an array. You can limit the number of pieces with the optional limit parameter.

To get the name from the customer's email address in the script, you can use the

```
$email_array = explode('@', $email);
```

This call to explode() splits the customer's email address into two parts: the username, which is stored in $email_array[0], and the domain name, which is stored in $email_array[1].
