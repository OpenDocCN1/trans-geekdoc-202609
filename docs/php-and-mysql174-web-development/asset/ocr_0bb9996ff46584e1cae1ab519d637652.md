# Chapter 3 Using Arrays

The function you write needs to have a particular signature. For each element in the array, `array_walk()` takes the key and value stored in the array, and anything you passed as `userdata`, calls your function like this:

```
yourfunction(value, key, userdata)
```

For most users, you will use only the values in the array. For some, you might also need to pass a parameter to your function using the parameter `userdata`. Occasionally, you might be interested in the key of each element as well as the value. You can, with `my_print()`, choose to ignore the key and `userdata` parameter.

For a slightly complicated example, you can write a function that modifies the values in the array and requires a parameter. Although you may not be interested in the key, you need to accept it to the third parameter:

```
function my_multiply(&$value, $key, $factor) {
$value *= $factor;
}
array_walk($array, 'my_multiply', 3);
```

This code defines a function, `my_multiply()`, that will multiply each element in the array by a supplied factor. You use the optional parameter to `array_walk()` to take a parameter to the function and use it as the multiplication factor. Because you need this, you must define the function, `my_multiply()`, with three parameters: an element's value (`$value`), an array element's key (`$key`), and the factor (`$factor`). You can choose to ignore the key.

A subtle point to note is that $value is passed. The ampersand (`&`) before the variable name in the definition of `my_multiply()` means that `$value` will be passed by reference. Passing by reference allows the function to alter the contents of the array.

We address passing by reference later in Chapter 5. If you are not familiar with the term, now just note that to pass by reference, use an ampersand before the variable name in the function declaration.

# Counting Elements in an Array: count(), sizeof(), and array_count_values()

You used the function `count()` in an earlier example to count the number of elements in an array of orders. The function `sizeof()` is an alias to `count()`. This function returns the number of elements in an array passed to. You get a count for the number of elements if you pass an empty array or a variable that has not been set.

The `array_count_values()` function is more complex. If you use `array_count_values($array)`, this counts how many times each unique value occurs in the array named `$array`. The function returns an associative array containing a frequency table.

This array contains all the unique values from $array as keys. Each key has a numeric value that tells you how many times the corresponding key occurs in `$array`.
