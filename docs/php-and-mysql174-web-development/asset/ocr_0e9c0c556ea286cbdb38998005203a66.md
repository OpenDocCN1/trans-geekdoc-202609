# Downloading the File

At this stage, you try to download the file from the server...

```
echo 'Getting file from server...<br />';
$fp = fopen($localfile, 'wb');
if (!$success = ftp_get($conn, $fp, $remotfile, FTP_BINARY)) {
    echo 'Error: ';
    echo 'Could not download file.\';
    fclose($fp);
    ftp_quit($conn);
    exit;
}
close($fp);
echo 'File downloaded successfully.';
```

You open a local file using fopen(), as you learned previously. After you have done this, you call the function ftp_get(), which attempts to download the file and store it in a local file. This function takes four parameters. The first three are straightforward: the FTP connection, the local file, and the path to the remote file. The fourth parameter is the FTP mode.

The two modes for an FTP transfer are ASCII and binary. The ASCII mode is used for transferring text files (that consists of ASCII characters), and the binary mode is used for transferring everything else. Binary mode modifies a file unmodified, whereas ASCII mode for Unix translates carriage returns and line feeds into the appropriate characters for your system\n on Unix for Windows, and \r for Macintosh.

PHP's FTP library comes with two predefined constants, FTP_ASCII and FTP_BINARY, which represent these two modes. You need to decide which mode fits your file type and pass the corresponding constant to ftp_get() as the fourth parameter. In this case, transferring a zipped file, so use the FTP_BINARY mode.

The ftp_get() function returns true if everything goes well or false if an error is encountered. You store the result in $success and let the user know how it went.

After the download has been attempted, you close the local file using the fclose() function.

An alternative to ftp_get(), ftp_get(), which has the following prototype:

```
int ftp_get(int ftp_connection, string localfile_path,
 remotfile_path, int mode)
```

This function works in the same way as ftp_get() but does not require the local file to be open. You pass it the filename of the file you would like to write rather than a file handle.

Note that there is no equivalent to the FTP command mget, which can be used to download multiple files. You must instead make multiple calls to ftp_get() or ftp_get().
