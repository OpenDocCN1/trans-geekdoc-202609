Likewise, especially for certain events like the click of an <a> HTML element, the default listener of the event may take actions you don't want to occur. For example, consider the following code:

```
$('a').on('click', function(event) {
  var link = $(event.target).attr('href');
  console.log("The link clicked a URL of: " + link);
});
```

Logically speaking, you could use this snippet of code to listen for a click event, extract the href attribute from the source of that click event, and then display the value of that attribute in the browser's console. You would be right, however, if the code would not function as expected because there is a default behavior associated with clicking on this (changing the browser's location to the specified URL). This is because you correctly listened for the event, the event continued to bubble up through the HTML document, and the default behavior of the event was eventually triggered. To prevent this, you must prevent the event from bubbling up through the document using the preventDefault() method in every event object. The following code includes this method and would function correctly:

```
$('a').on('click', function(event) {
  event.preventDefault();
});
```

```
var link = $(event.target).attr('href');
console.log("The link clicked a URL of: " + link);

```

# Table 23.1 Useful jQuery Events

| Event | Type | Description |
| --- | --- | --- |
| change | Form Event | Triggered when a given form element changes value |
| click | Mouse Event | Triggered when a given element is clicked |

| focus | Form Event | Triggered when a form element receives focus, prior to actually being focused |
| focus | Form Event | Triggered when a form element is focused |
