# # Using Text and Fonts to Create Images

Let's look at a more complicated example of creating images. It is useful to be able to create buttons or other images for your website automatically. You can easily build simple buttons based on a rectangle of background color using the techniques we've already discussed. You can generate more complicated effects programmatically, too, but you can generally do it easily in a plain program. This also makes it easier to get an artist to draw the artwork and leave programmers to programming.

In this example, you generate buttons using a blank button template. This allows you to have features such as beveled edges and so on, which you might find are a good deal easier to create using Photoshop, the GIMP, or some other graphics tool than in PHP HTML and CSS. With the image library in PHP, you can begin with a base image and draw on top of that.

You also use TrueType fonts in this example so that you can use antialased text. The TrueType font functions have their own quirks, which we will discuss.

The basic process is to take text and generate a button with text on it. The text will be centered both horizontally and vertically on the button, and will be rendered in the largest size font that will fit on the button.
