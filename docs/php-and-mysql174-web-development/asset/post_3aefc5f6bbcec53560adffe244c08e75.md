
For example, the following code echoes the value 4 to the browser:

```php
$test = "Hello world";
echo strpos($test, "o");
```

This code passes only in a single character as the needle, but it can be a string of any length.

The optional offset parameter specifies a-at-point within the haystack to start searching.

```php
echo strpos($test, "o", 5);
```

This code echoes false to the browser because PHP has started looking for the character o at position 5 and does not return the one at 4.

strrpos() function is almost identical but returns the position of the last occurrence of the needle in the haystack.

In any of these cases, if the needle is not in the string, strpos() or strrpos() will return false. This can be problematic false in a weakly typed language such as PHP is in many contexts equivalent to 0—that is, the first location in string.

You can avoid this problem by using the === operator to return values:

```php
$result = strpos($test, "H");
if ($result === false) {
    echo "Not found";
} else {
    echo "Found at position .$result";
}
```

## Replacing Substrings: str_replace() and substr_replace()

Find-and-replace functionality can be extremely useful with strings. You can use findreplace for personalizing documents generated by PHP—for example, replacing <name> with a person's name and <address> with his or her address. You can also use it for censoring particular terms, such as in a discussion forum, or even in the Smart Forum application. You can use string functions or regular expressions for this purpose.

The most used string function for replacement is str_replace(), as discussed earlier in this chapter. It has the following prototype:

```php
str_replace(mixed needle, mixed_needle, mixed haystack, int &$count = null);
```

This function replaces all the instances of needle in haystack with new_needle and returns the new version of haystack. The optional fourth parameter, count, contains the number of replacements made.

You can pass all parameters as arrays, and the str_replace() function works remarkably intelligently. You can pass an array of words to be replaced, an array of words to replace them (with respectively), and an array of strings to apply these rules. This function returns an array of revised strings.

For example, because people can use the Smart Form to complain, they might use some colorful words. As a programmer, if you have an array $offcolor that contains a number of offensive words. Here is an example using str_replace() with an array:

```php
$feedback = str_replace($offcolor, '$@', $feedback);
```

The function substr_replace() finds and replaces a substring of string based on its position. Here is its following prototype:

```php
string substr_replace(mixed string, mixed replacement, mixed start, mixed length = null);
```

This function replaces part of the string with the string replacement. Which part is depends on the values of the start and optional length parameters.

The start value represents an offset into the string where replacement would begin. If it is zero or positive, it is an offset from the beginning of the string; for example, this line of code replaces the last character in $test:

```php
$test = substr_replace($test, 'X', -1);
```

The length value is optional and represents the point at which PHP will stop replacing. If you don't supply this value, the string will be replaced from start to the end of the string.

If length is zero, the replacement string will actually be inserted into the string without overwriting the existing string. A positive length represents the number of characters that you wanted with the new string; a negative length represents the point at which you would like to stop replacing characters, counted from the end of the string.

Similar to str_replace() function, you can also use substr_replace() by passing in a set of arrays.

## Introducing Regular Expressions

PHP has historically supported two styles of regular expression syntax: POSIX and Perl. Both types are compiled into PHP by default, since PHP version 5.3 the POSIX style has been deprecated.

So far, all the pattern matching you've done using the string functions. You have been limited to exact matches or exact substrings. If you want to do more complex pattern matching, you should use regular expressions. Regular expressions are difficult to grasp at first but can be extremely useful.

## Chapter 4 String Manipulation and Regular Expressions

### The Basics

A regular expression is a way of describing a pattern in a piece of text. The exact (literal) matches you've seen so far are a form of regular expression. For example, earlier searched for regular expression terms as "shop" and "delivery".

Matching regular expressions in PHP is more like a `strstr()` match than an equal comparison because you are matching a string somewhere within another string. (It can be anywhere within unless you specify otherwise.) For the string "shop" matches the regular expression "shop", it also matches the expressions "h", "ho", and so on.

You can use special characters to indicate a meta-meaning in addition to matching characters exactly. For example, with special characters you can indicate that a pattern must occur at the start or end of a string, that part of a pattern can be repeated, or characters in a pattern must be of a particular type. You can also match on literal occurrences of special characters.

### Delimiters

With PCRE regular expressions, each expression must be contained within a pair of delimiters. You may choose any character that is not a letter, a number, a backslash, or whitespace. The delimiter at the start and end of the string.

### Character Classes and Types

Using character sets immediately gives regular expressions more power than exact matching. Character sets can be used to match any character of a particular type.

First, you can use the . character as a wildcard for any single character except a newline (\n). For example, the regular expression ./matches the strings "cat", "sat", and "mat", among others. This kind of wildcard is often used for filename matching in operating systems.

With regular expressions, however, you can be more specific about the type of character you would like to match and actually specify a character that must belong.
