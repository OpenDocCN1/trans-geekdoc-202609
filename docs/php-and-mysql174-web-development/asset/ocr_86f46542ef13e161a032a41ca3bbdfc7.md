In Part 3 of the script, you use the basic image, allocate the colors, and then begin to draw the graph.

You fill in the background for the graph using this use

```
imagefilledrectangle($im, 0, 0, $width, $height, $bg_color);
```

The imagefilledrectangle() function, as you might imagine, draws a filled-rectangle. The first parameter is as, the image identifier. You must pass it the x and y coordinates of the start point and the end point of this rectangle. These points correspond to the upper-left corner and lower-right corner, respectively. In this case, you fill the entire canvas with the background color, which is the last parameter, and it's white.

You then call

```
imageline($im, 0, 0, $width-1, $height-1, $line_color);
```

to draw a black outline around the edge of the canvas. This draws an outlined rectangle instead of a filled one. The parameters are the same. Notice that the rectangle is drawn to $width-1 and $height-1 a canvas of width by height from (0,0) to these values. If you draw it to $width and $height, the rectangle would be outside the canvas area.

You use the same logic for the bars as in the preceding script to center and write the title on the graph.

```
imageline($im, $x, $y-5, $x, $height-15, $line_color);
```

The imageline() function draws a line on the image you specify ($im) from one set of coordinates ($x, $y-5) to another ($x, $height-15), in the color specified by $line_color.

In this case, you draw the bar from a little above where you want to draw the first bar, to a little above the bottom of the canvas.
