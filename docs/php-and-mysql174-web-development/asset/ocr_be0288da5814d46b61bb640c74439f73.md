# Table 12.7 SHOW Statement Syntax

| Variation | Description |
|---|---|
| SHOW DATABASES [like_or_where] | Lists available databases. |
| SHOW TABLES [FROM database] [like_or_where] | Lists tables from the database currently in use, or from the database called *like_or_where*. |
| SHOW [FULL] COLUMNS table [FROM database] [like_or_where] | Lists all the columns in a particular table currently in use, or from the database specified. |
| SHOW INDEX table [FROM database] | Shows details of all the indexes on a particular table from the database currently in use, or from the database called database if specified. SHOW KEYS is an alias for SHOW INDEX. |
| SHOW [GLOBAL | SESSION] STATUS [like_or_where] | Gives information about number of system items, such as the number of threads running. The LIKE clause is used to match the names of these items, so, for example, 'Thread%' matches the items, 'Threads_cached', 'Threads_connected', and 'Threads running'. |
| SHOW [GLOBAL|SESSION] VARIABLES [like_or_where] | Displays the names and values of the MySQL system variables, such as the version number. |
| SHOW [FULL] PROCESSLIST | Displays all running processes in the system—that is, the queries that are currently being executed. Most users will see their own threads, but if they have the PROCESS privilege, they can see everybody's processes—including passwords if they are in queries. The queries are truncated to 100 characters by default. Using the keyword FULL displays all the queries. |
| SHOW TABLE STATUS [FROM database] [like_or_where] | Displays information about each of the tables in the database currently being used, or the database called if it is specified, optionally with a wildcard match. This information includes the table type and the time each table was updated. |
| SHOW GRANTS for user | Shows the GRANT statements to give the user specified in user current level of privilege. |
| SHOW PRIVILEGES | Shows the different privileges that the server supports. |
| SHOW CREATE DATABASE | Shows a CREATE DATABASE statement that would create the specified database.
