When reading this class, note that DisplayStyles(), DisplayHeader(), and DisplayFooter need to display a large block of static HTML, with no PHP processing. Therefore, you simply use an end PHP tag (?>), your HTML, and then re-enter PHP with an open tag (<?php inside the functions.

Two other operations are defined in this class. The operation DisplayButton() outputs a single menu button. If the button is to point to the page you are on, you will display an inactive button, which looks slightly different and does not link anything. This way, you can keep the page layout consistent and provide visitors with a visual location.

The operation isURL() determines whether the URL for a button points to the current page. You can use several techniques to see this information. Here, you use the string function strpos() to see whether the URL is contained in one of the server variables. The statement strpos($_SERVER['PHP_SELF'], $url) returns a number if the string in $url is contained in the global variable $_SERVER['PHP_SELF'] or false if it is not.
