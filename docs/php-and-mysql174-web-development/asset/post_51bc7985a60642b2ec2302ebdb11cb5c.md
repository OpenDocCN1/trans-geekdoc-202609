foreach ($products as $current) {

## Arrays with Different Indices

In the $products array, you allowed PHP to give each item the default index. This meant that the first item you became item 0; the second, item 1; and so. PHP also supports arrays in which you can associate any scalar key or index you use with each value.

## Initializing an Array

The following code creates an array with product names as keys and as values:

$prices = array('Tires'=>100, 'Oil'=>10, 'Spark Plugs'=>4);
The symbol between the keys and values (=>) is simply an equal sign immediately followed by a greater than symbol.

## Accessing the Array Elements

Again, you access the contents using the variable name and a key, so you can access the information stored in the array as $prices['Tires'], $prices['Oil'], and $prices['Spark Plugs'].

The following code creates an array with $prices. Instead of creating an array with three elements, this creates an array with only one element and adds two more:

```php
$prices = array('Tires'=>100);
$prices['Oil'] = 10;
$prices['Spark Plugs'] = 4;
```

Here is another slightly different but equivalent piece of code. In this version, you do not explicitly create an array at all. When you add the first element to it:

```php
$prices['Tires'] = 100;
$prices['Oil'] = 10;
$prices['Spark Plugs'] = 4;
```

## Using Loops

Because the indices in an array are not numbers, you cannot use a simple counter for a for loop to work with the array. However, you can use the foreach loop or the list() and each() constructs.

# Chapter 3 Using Arrays

The foreach loop has a slightly different structure when using non-numerically indexed arrays. You can use it exactly as you did in the previous example, or you can incorporate the keys as well:

```php
foreach ($prices as $key => $value) {
    echo $key." - " . $value."<br />";
}
```

The following code lists the contents of the $prices array using the each() construct:

```php
while ($element = each($prices)) {
    echo $element['key']. - " . $element['value'];
    echo "<br />";
}
```

In Chapter 1, we looked at while loops and the echo statement. The preceding code uses the each() function, which we have not yet covered. This function returns the current element in an array and makes the next element the current one. Because we are calling each() within a while loop, it returns every element in the array and stops when the end of the array is reached.

In this code, the variable $element is an array. When you call each(), it gives you an array with four values and the four indices to the array locations. The locations key and value contain the key of the current element, and the locations value and index contain the value of the current element. Although the one you choose makes no difference, we chose to use the named locations rather than the numbered ones.

## Array Operators

There is a more elegant and common way of doing the same thing. The construct list() can be used to split an array into a number of values. You can separate each set of values that the each() function gives you like this:

```php
while (list($product, $price) = each($prices)) {
    echo $product."." .$price."<br />";
}
```

This line uses each() to take the current element from $prices, return it as an array, and make the next element. It also uses list() to turn the 0 and index elements from the array returned by each() into two new variables $product and $price.

When you are using each(), note that the array keeps track of the current element. If you want to use the array in the same script, you need to reset the current element back to the start of the array using the function reset(). To loop through the $prices array again, you can type the following:

```php
reset($prices);
while (list($product, $price) = each($prices)) {
    echo $product."." .$price."<br />";
}
```

This code sets the current element back to the start of the array and allows you to go through again.

## Array Operators

One set of special operators applies only to arrays. Most of them have an analogue in the scalar operators, as you can see by looking at Table 3.1.

Table 3.1 PHP Array Operators

| Operator | Name | Example | Result |
|---|---|---|---|
| + | Union | $a + $b | Union of $a and $b. The array $b is appended to $a, but any keys are not added. |
| == | Equality | $a = $b | True if $a and $b$ contain the same elements. |
| === | Identity | $a === $b | True if $a$ and $b$ contain the same elements, with the same types, in the same order. |
| != | Inequality | $a != $b | True if $a$ and $b$ do not contain the same elements. |
| <> | Inequality | $a <> $b | Same as !=. |
| !== | Non-identity | $a !== $b | True if $a$ and $b$ do not contain the same elements, with the same types, in the same order. |

The operators are mostly fairly self-evident, but union requires $a$ further explanation. The union operator tries to add elements of $b$ to the end of $a$. If elements in $b$ have the same keys as elements already in $a$, they will not be added. That is, no elements of $a$ will be overwritten.

You will notice that the array operators in Table 3.1 have all equivalent operators that work on scalar variables. As long as you remember that + performs addition on scalar types and union on arrays—even if you have no interest in the arithmetic behind that behavior—the behaviors should make sense. You cannot compare arrays to scalar types.

## Multidimensional Arrays

Arrays do not have to be a simple list of keys and values; each location in the array can hold another array. You can, create a multidimensional array, where each location in the array can hold another array.

```php
$matrix = array(
    array(1, 2, 3),
    array(4, 5, 6),
    array(7, 8, 9)
);
```

You can access elements in a multidimensional array using two sets of indices. For example, to get the value 5 from the second row and second column, you would use:

```php
echo $matrix[1][1];
```

To iterate through a multidimensional array, you can use nested loops:

```php
foreach ($matrix as $row) {
    foreach ($row as $element) {
        echo $element . " ";
    }
    echo "<br />";
}
```
