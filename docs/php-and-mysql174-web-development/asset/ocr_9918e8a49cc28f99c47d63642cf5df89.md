For example, the following code echoes the value 4 to the browser:

```
$test = "Hello world";
echo strpos($test, "o");
```

This code passes only in a single character as the needle, but it can be a string of any length.

The optional offset parameter specifies a point within the haystack to start searching.

```
echo strpos($test, "o", 5);
```

This code echoes ? to the browser because PHP has started looking for the character o at position 5 and does not return the one at 4.

strpos() function is almost identical but returns the position of the last occurrence of the needle in the haystack.

In any of these cases, if the needle is not in the string, strpos() or strr() will return false. This can be problematic false in a weakly typed language such as PHP is in many contexts equivalent to 0—that is, the first location in string.

You can avoid this problem by using the === operator to return values:

```
$result = strpos($test, "H");
if ($result === false) {
    echo "Not found";
} else {
    echo "Found at position .$result";
}
```

# Replacing Substrings: str_replace() and substr_replace()

Find-and-replace functionality can be extremely useful with strings. You can use findreplace for personalizing documents generated by PHP—for example, replacing <name> with a person's name and <address> with his or her address. You can also use it for censoring particular terms, such as in a discussion forum, or even in the Smart Forum application. You can use string functions or regular expressions for this purpose.

The most used string function for replacement is str_replace(), as discussed earlier in this chapter. It has the following prototype:

```
str_replace(mixed needle, mixed_needle, mixed haystack, int &count));
```

This function replaces all the instances of needle in haystack with new_needle and returns the new version of haystack. The optional fourth parameter, count, contains the number of replacements made.
