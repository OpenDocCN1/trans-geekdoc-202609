# ## What Is SQL?

SQL stands for Structured Query Language. It's the most standard language for accessing relational database management systems (RDBMS). SQL is used to store data and retrieve it from a database. It is used in database systems such as MySQL, Oracle, PostgreSQL, Sybase, and Microsoft SQL Server, among others.
