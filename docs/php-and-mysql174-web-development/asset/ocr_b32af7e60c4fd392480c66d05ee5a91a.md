The USER command, surprisingly, creates a user. The general form of this command is as follows:

```
CREATE USER user_info [PASSWORD] password IDENTIFIED BY [auth_plugin] [AS auth_string]
```

The clauses in brackets are optional. There are a number of placeholders in this syntax, too.
The user_info placeholder contains a user_name, optionally followed by a hostname, separated by an @ symbol, in quotes, like the following: `laura@localhost`.

The user_name is the name you want to log in as MySQL. Remember that it does not have to be the same as a system name. The user_info in MySQL also contains a hostname. You can use this to differentiate between, say, laura (interpreted as laura@localhost) and laura@where.com. This capability is quite useful because users from different domains have the same name. It also increases security because you specify where users can connect, and from which tables or databases they can access a particular location.

The password placeholder should be the password you want to log in with. The usual rules for selecting passwords apply. We will discuss security later, but a password should not be easily guessable. This means a password should not be a dictionary word or the same as the username. Ideally, it should contain a mixture of upper- and lowercase and nonalphabetic characters.

An alternative to passwords, MySQL 5.5.7 you have been able to use an authentication plugin. To use this, you would specify the alternate IDENTIFIED WITH [auth_plugin] syntax. We will not cover authentication plugins in this book, but you can read about them in the MySQL manual if you need this. The GRANT command gives a user account if it does not yet exist, skipping straight to GRANT as a shortcut.

The general form of the GRANT command is

```
GRANT privileges [columns]
ON item
to user_info
IDENTIFIED BY password | IDENTIFIED WITH [auth_plugin] [AS auth_string]
[REQUIRE ssl_options]
[ GRANT OPTION | options ]
```

Some of these clauses are the same as in the CREATE USER statement, and work exactly the same way. Let’s look at the new clauses introduced here.
