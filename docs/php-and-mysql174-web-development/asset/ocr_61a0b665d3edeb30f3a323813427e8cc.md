# Closing the Connection

After you have finished with the FTP connection, you should close it using the ftp_quit\()
function:

```
ftp_quit($conn);
```

You should pass this handle for the FTP connection.

# Uploading Files

If you want to go the other way—that is, copy files from your server to a remote machine—you
can use two functions that are basically opposite of ftp_fget() and ftp_get(). These
function are called ftp_fput() and ftp_put().). They have the following prototypes:

```
int ftp_fput(int ftp_connection, string remotefile_path, int fp, int mode)
ftp_put(int ftp_connection, string remotefile_path,
        string localfile_path, int mode)
```

The parameters are the same as for _get equivalents.

# Avoiding Timeouts

One problem you might face when transferring files via FTP is exceeding the maximum execution-
tion. You will know when this happens when PHP give you an error message. This error
is especially likely to occur if your server is running over a slow or congested network, or if you
d downloading a large file, such as a movie clip.

The default value of the maximum execution time for all PHP scripts is defined in php.ini
by Default, it is set to 30 seconds. This is designed to catch scripts that are running out of
control. However, when you are transferring files via FTP, if your link to the rest of the world is
slow or if the file is large, the transfer could take longer than this.

Fortunately, you can modify the maximum execution time for a particular script by using the
set_time_limit() function. Calling this function resets the maximum number of seconds
script is allowed to run, starting from the time the function is called. For example, if you call
set_time_limit(90);
script will be able to run for another 90 seconds from the time the function is called.

# Using Other FTP Functions

A number of other functions are useful in PHP. The function ftp_size() can tell you the
size of a file on a remote server. It has the following prototype:

```
int ftp_size(int ftp_connection, string remotefile_path)
```

This function returns the size of the remote file in bytes or -1 if an error occurs. It is not
supported by all FTP servers.
