# Making Decisions with Conditionals

You can build complicated logical processes by nesting if statements within each other.
In the following code, the summary will be displayed only if the condition totalqty == 0 is true, and each line in the summary will be displayed only if its condition is met:

```
if ($totalqty == 0) {
    echo "You did not order anything on the previous page!<br />";
} else {
    if ($tireqty > 0) {
        echo htmlspecialchars($tireqty).'. tires<br />\';
    }
    if ($oilqty > 0) {
        echo htmlspecialchars($oilqty).'. bottles of oil<br />\';
    }
    if ($sparkqty > 0) {
        echo htmlspecialchars($sparkqty).'. spark plugs<br />\';
    }
}
```

# elseif Statements

For many of the decisions you make, you have two options. You can create a sequence of many using the elseif statement, which is a combination of else and an if statement. When you provide a sequence of conditions, the program can check each until it finds one that is true.

Bob provides a discount for large orders of tires. The discount scheme works like this:

+   - Fewer than 10 tires purchased—No discount
- 10-49 tires purchased—5% discount
- 50-99 tires purchased—10% discount
- 100 or more tires purchased—15% discount

You can create to calculate the discount using conditions and if and elseif statements. In this case, you need to use the AND operator (&&) to combine two conditions into:

```
if ($tireqty < 10) {
    $discount = 0;
} elseif ($tireqty >= 10) && ($tireqty <= 49) {
    $discount = 5;
} elseif ($tireqty >= 50) && ($tireqty <= 99) {
    $discount = 10;
} elseif ($tireqty >> 100) {
    $discount = 15;
}
```

Note that you are free to use elseif or else—versions with or without a space are both correct.
