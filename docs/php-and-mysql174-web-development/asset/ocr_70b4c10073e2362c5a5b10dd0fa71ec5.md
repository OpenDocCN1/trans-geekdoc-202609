This call says, "For given font size $font_size, with text slanted on an angle of zero degrees, using the TrueType font DejaVu tell me the dimensions of the text in $button_text."

The function returns an array containing the coordinates of the corners of the bounding box. The contents of the array are shown in Table 21.1.

Table 21.1 Contents of the Bounding Box Array
| Array Index | Contents |
|---|---|n| 0 | x coordinate, lower-left corner |
| 1 | y coordinate, lower-left corner |
| 2 | x coordinate, lower-right corner |
| 3 | y coordinate, lower-right corner |
| 4 | x coordinate, upper-right corner |
| 5 | y coordinate, upper-right corner |
| 6 | x coordinate, upper-left corner |
| 7 | y coordinate, upper-left corner |

To remember the contents of the array are, just remember that the numbering starts at the bottom-left corner of the bounding box and works its way around counterclockwise.

There is one tricky thing about the values returned from the imagettfbbox() function. They are coordinate values, specified from an origin. Unlike coordinates for images, which are relative to the top-left corner, they are specified to a baseline.

Look at Figure 21.6. You will see that we have drawn a line along the bottom of most of the text. This is known as the baseline. Some letters hang below the baseline, such as y in this example. Parts of the letters are called descenders.

The left side of the baseline is specified as the origin of measurements—that is, x coordinate and 0 and y coordinate. Coordinates above the baseline have a positive x coordinate, and coordinates below the baseline have a negative x coordinate.

In addition, text might actually have values that sit outside the bounding box. For example, the text might actually start at an x coordinate of -1.

What all this adds up to is that care is required when you're performing calculations with these numbers.

You work out the width and height of the text as follows:

```
$right_text = $bbox[2]; // right co-ordinate
$left_text = $bbox[0]; // left co-ordinate
$width_text = $right_text; // how wide is it?
$height_text = abs($bbox[1]); // how tall is it?
```
