```
while ($font_size > 8 &&
```

You test two of conditions here. The first is that the font is still readable; there's no point in making it smaller than 8-point type because the button becomes too difficult to read. The second set of conditions will ensure the text fit inside the drawing space you have available for it.

Next, you check to whether the iterative calculations found an acceptable font size and report an error if:

```php
if ($height_text > $height_image_wo_margins ||
  $width_text > $width_image_wo_margins)
{
  // no readable font size will fit on button
  echo '<p>Text will not fit on button.</p>';
}
```

## Positioning the Text

If all is well, you work out a base position for the start of the text. This is the midpoint of the available space.

```php
$text_x = $width_image/2.0 - $width_text/2.0;
$text_y = $height_image/2.0 - $height_text/2.0;
```

Because of the calculations with the baseline relative coordinate system, you need to add some corrections:

```php
if ($left_text < 0)
{
  $text_x += abs($text_text); // add factor for left overhang
}
```

```php
$above_line_text = abs($bbox[7]); // how far above the baseline;
```

## Writing the Text onto the Button

After that, it's smooth sailing. You set up the text color, which will be white:

```php
$white = imagecolorallocate($im, 255, 255, 255);
```

## Drawing Figures and Graphing Data

You can use the imagetftext() function to actually draw the text onto the button:
```php
imagetftext($im, $font_size, 0, $text_x, $text_y, $White,
$font_name, $button_text);
```

This function takes a lot of parameters. In order, they are the image identifier, font size in points, the angle you want to draw the text, the starting x and y coordinates of the text, the text color, the font name, and finally, the actual text to go on the button.

> Note
The font file needs to be available on the server and is not required on the client's machine because the client will use it as an image.

## Finishing Up

Finally, you can output the button to the browser:
```php
header('Content-type: image/png');
imagepng($im);
```

Then it's time to clean up resources and end the script:
```php
imagedestroy($im);
```

In this example, you run a poll on your website to test whom users will vote for a fictitious election. You store the results of the poll in a MySQL database and draw a bar chart of the results using the image functions.

Graphing is the other thing functions are primarily used for. You can chart any data you want-sales, web hits, or whatever takes your fancy.

```php
$stmt->execute();
$stmt->free_result();

// Get current results of poll
$query = "SELECT candidate, num_votes FROM poll_results";
$r_stmt = $db->prepare($query);
$r_stmt->execute();
$r_stmt->store_result();
$r_stmt->bind_param('is', $candidate, $num_votes);
$num_candidates = $r_stmt->num_rows;

// Calculate total number of votes so far
$total_votes = 0;
while ($r_stmt->fetch()) {
  $total_votes += $num_votes;
}
$r_stmt->data_seek(0);
```
