
# Listing 18.3 directory_submit.php–Script to Verify URL and Email Address

```php
<!DOCTYPE html>
<html>
<head>
    <title>Site Submission Results</title>
</head>
<body>
    <h1>Site Submission Results</h1>

<?php

// Extract form fields
$url = $_POST['url'];
$email = $_POST['email'];

// Check the URL
$url_parts = parse_url($url);
$host = $url_parts['host'];

if (!($ip = gethostbyname($host))) {
    echo 'Host for URL does not have valid IP address.';
    exit;
}

echo 'Host ('.$host.') is at IP ''.$ip.'<br/>';

// Check the email address
$email = explode('@', $email);
$emailhost = $email[1];

if (!getmxr($emailhost,$mxhostsarr)) {
    echo 'Email address is not at valid host.';
    exit;
}

echo 'Email is delivered via: <br/>';
<ul>
foreach ($mxhostsarr as $mx) {
    echo '<li>'.$mx.'.</li>';
}
echo '</ul>';

// If reached here, all ok
echo '<p>All submitted details are ok.</p>';
echo '<p>Thank you for submitting your site.
nIt will be visited by one of our staff members soon.</p>';
// In real case, add to db of waiting sites...
?>
</body>
</html>
```

Let's go through the interesting parts of this script.

First, you take the URL from the $_POST superglobal and apply the parse_url() function to it. This function returns an associative array of the different parts of an URL. The available pieces of information are the scheme, user, pass, host, port, query, and fragment. Typically, you don't need all these pieces, but here's an example of how they make up an URL.

Consider the following example URL: `http://nobody:secret@example.com:80/script.php?variable=value=anchor`.

The values of each of the parts of the array are:

- scheme: http
- user: nobody
- pass: secret
- host: example.com
- port: 80
- path: /script.php
- query: variable=value
- fragment: anchor

In directory_submit.php script, you want only the host information, so you pull it out of the array as follows:

```php
$url = parse_url($url);
$host = $url['host'];
```

After you've done this, you can get the IP address of host, if it is in the domain service (DNS). You can do this by using the gethostbyname() function, which returns the IP if there is one or false if not:

```php
$ip = gethostbyname($host);
```

You can also go the other way by using the gethostbyaddr() function, which takes an IP as a parameter and returns the hostname. If you call these functions in succession, you might end up with a different hostname from the one you began with. This can mean that a site is using a virtual hosting service where one physical machine and IP address host more than one domain name.

If the URL is valid, you then go on check the email address. First, you split it into username and hostname with a call to explode():

```php
$email = explode('@', $email);
$emailhost = $email[1];
```

When you have the host port of the address, you can check to see whether there is a place for mail to go by using the getmxr() function:

```php
getmxr($emailhost,$mxhostsarr);
```

This function returns the set of Mail Exchange (MX) records for an address in the array at $mxhostsarr.

An MX record is stored at the DNS and is looked up as a hostname. The machine listed in the MX record isn't necessarily the machine where the mail will eventually end up. Instead, it's a machine that knows where to route to that. (There can be more than one; hence, this function returns an array rather than a hostname string.) If you don't have an MX record in the DNS, there's nowhere for the mail to go.

If all checks are okay, you can put this data in a database for later review by a staff member. We don't perform functionality in this script, but you can see in the comment at the end of the script just where, but would be simple to use for quick checks of validity.

In addition to the functions you just used, you can use the more generic function checkdnsr(), which takes a hostname and simply returns true if any record of it appears in the DNS. The output of this function would not give you anything to directly display to the user, as with the getmxr() function used in the script, but would be simple to use for quick checks of validity.

# Backing Up or Mirroring a File

File Transfer, or FTP, is used to transfer files between hosts on a network. Using PHP, you can use fopen() and the various functions with FTP as you can with HTTP connections, to transfer files to and from an FTP server. However, a set of FTP-specific functions also comes with the standard PHP install.

These functions are not built into the standard install by default. To use them under Unix, run the PHP configure program with the --enable-ftp option and then rerun make. If you are using the Windows install, FTP functions are enabled automatically.

For more details on configuring PHP, see Appendix A, “Installing Apache, PHP, and MySQL.”

# Using FTP to Back Up or Mirror a File

The FTP functions are useful for copying files from and to other hosts. One common use you might make of this capability is back up your website or mirror files at another location. Let's look at a simple example using the FTP functions to mirror a file. This script is shown in Listing 18.4.

# Listing 18.4 ftp_mirror.php–Script to Download New Versions of a File from an FTP Server

```php
<!DOCTYPE html>
<html>
<head>
  <title>Mirror Update</title>
</head>
<body>
  <h1>Mirror Update</h1>

<?php
  // set variables - change these to suit application
  $host = 'apache.cs.utah.edu';
  $user = 'anonymous';
  $password = 'me@example.com';
  $remotile = '/apache.org/http/httpd-2.4.16.tar.gz';
  $localfile = '/path/to/files/httpd-2.4.16.tar.gz';

  // connect to host
  $conn = ftp_connect($host);

  if (!$conn) {
    echo 'Error: Could not connect to '.$host;
    exit;
  }

  echo 'Connected to '.$host.'<br />';

  // log in to host
  $result = ftp_login($conn, $user, $password);
  if (!$result) {
    echo 'Error: Could not log in as '.$user;
    ftp_quit($conn);
    exit;
  }

  echo 'Logged in as '.$user.'<br />';

  // Turn on passive mode
  ftp_pasv($conn, true);

  // Check file times to see if an update is required
  echo 'Checking file time...<br />';
  if (file_exists($localfile)) {
    $localtime = filetime($localfile);
    $remotime = ftp_mdtm($conn, $remotile);
    if ($remotime < 0) {
      // This doesn't mean the file's not there, server may not support time
      echo 'Can\'t access remote time.<br />';
      $remotime = 0;
    } else {
      // make sure of an update
      echo 'Remote file updated ';
      echo date('G:i-M-Y', $remotime);
    }
    echo '<br/>';
  } else {
    $localtime = 0;
    echo 'Local file updated ';
    echo date('G:i-M-Y', $localtime);
    echo '<br/>';
  }

  if ($remotime <= $localtime) {
    echo 'Local copy is up to date.<br />';
    exit;
  }

  // download file
  echo 'Getting file from server...<br />';
  $fp = fopen($localfile, 'wb');

  if (!$success = ftp_fget($conn, $fp, $remotile, FTP_BINARY)) {
    echo 'Error: Could not download file.';
    ftp_quit($conn);
    exit;
  }

  fclose($fp);
  echo 'File downloaded successfully.';

// close connection to host
ftp_close($conn);

?>
</body>
</html>
```
