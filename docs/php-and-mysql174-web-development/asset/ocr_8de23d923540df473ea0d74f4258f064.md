# Listing 5.4 footer.php—The Reusable Footer for All TLA Web Pages

```
<!-- footer -->
<footer>
<p>&copy; TLA Consulting Pty Ltd.<br />
Please see our
<a href="legal.php">legal information page</a>.</p>
</footer>

<body>
n</html>
```

This approach gives you a consistent-looking website very easily, and you can make a new page
in the same style by typing something like this:

```
<?php require('header.php'); ?>
Here is the content for this page
<?php require('footer.php'); ?>
```

Most importantly, after you have created many pages using this header and footer,
can easily change the header and footer files. Whether you are making a minor text change or
completely redesigning the look of the site, you will need to make the change only once. You do
not need to separately every page in the site because each page is loading in the header
and footer files.

The example shown here uses only HTML in the body, header, and footer. This need not
be the case. Within these files, you could use PHP statements to dynamically generate parts of
the page.

If you want to be sure that a file will be treated as plain text or HTML, and not have any PHP
, you may want to use readfile() instead. This function echoes the content of a file
without parsing it. This can be an important safety precaution if you are using user-provided text.
