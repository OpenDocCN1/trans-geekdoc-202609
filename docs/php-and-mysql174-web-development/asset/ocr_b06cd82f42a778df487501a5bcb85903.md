# Matching and Replacing Substrings with String Functions

The prototype for strstr() is as follows:

```
string strstr(string haystack, string needle, bool before_needle=false);
```

You pass the function haystack to be searched and a needle to be found. If an exact match of the needle is found, the function returns the haystack from the needle onward; otherwise, it returns false. If the needle occurs more than once, the returned string will start from the first occurrence of needle. If the before_needle parameter is set to true, the function will return the position of the first point to the needle.

For example, in the Smart Form application, you can decide where to send the email as follows:

```
$address = 'feedback@example.com'; // the default value

// Change the address if the criteria are met
if (strstr($feedback, 'shop')) {
$address = 'retail@example.com';
else if (strstr($feedback, 'delivery')) {
$address = 'fulfillment@example.com';
else if (strstr($feedback, 'bill')) {
$address = 'accounts@example.com';
}
```

This code checks for keywords in the feedback and sends the mail to the appropriate person. For example, if the customer feedback still hasn't received delivery of my last order, sending "delivery" will be detected and the feedback will be sent to feedback@example.com.

There are two variants of strstr(). The first variant is str(), which is nearly identical but not case sensitive. This variation is useful for this application because the customer might type "delivery", "Delivery", "DELIVERY", or some other mixed-case variation.

The second variant is strchr(), which is similar, but returns the haystack from the last occurrence of the needle. It searches only for a single character (the first character of the string passed in needle), which is somewhat of a gotta.

# Finding the Position of a Substring: strpos() and strstrpos()

The functions strpos() and strstrpos() operate in a similar fashion to strstr(), except instead of returning a string, returning the numerical position of a needle within a haystack. The PHP manual recommends using strpos() instead of strstr() to check for the presence of a string within a string because it runs faster.

The strpos() function has the following prototype:

```
int strpos(string haystack, string needle, int offset=0);
```

The integer returned represents the position of the first occurrence of the needle within the haystack. The first character is 0 as usual.
