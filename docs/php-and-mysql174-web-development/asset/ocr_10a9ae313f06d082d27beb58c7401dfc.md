# Escape Sequences

Escape sequences are parts of a pattern that begin with the backslash character (\). These fall into several categories.

First, backlash may be used to escape one of the meta characters, as discussed in the previous sections.

Second, backlash is used as the start of a set of character sequences to represent non-printing characters. We've already seen several of these in other contexts, such as \n (newline), \r (carriage return), and \t (tab). A couple of other ones are \cx to represent Control-x (where x is any character) and \e to represent escape.

Third, backlash is used as the start of a set of generic character types. The possible types are listed in Table 4.8.

# Table 4.8 Generic Character Types in PCRE Regular Expressions

| Character Type | Meaning |
|---|---|
| \d | A decimal digit |
| \D | Anything but a decimal digit |
| \h | Horizontal whitespace |
| \H | Anything but horizontal whitespace |
| \s | Whitespace |
| \S | Anything but whitespace |
| \v | Vertical whitespace |
| \V | Anything but whitespace |
| \w | "Word" characters |
| \W | Anything but "word" characters |
