To work, the get_random_word() function needs a dictionary.
The spell checker comes with a dictionary of words, typically located at /usr/dict/
words, as it is, and at /usr/share/dict/words. If you don't find it in one of these places,
most systems you can find words by typing

# locate dict/words

If you are using some other system or not to install ispell, don't worry! You can
down word lists as using ispell from://wordlist.sourceforge.net/. Just change the
location of your word list in the get_random_word() function.

This site also dictionaries in many other languages, so if you would like a random,\Norwegian or Esperant word, you can download one of these dictionaries. These filesnare formatted with each word on a separate line, separated by newlines.

To get a random word from this file, you pick a random location between 0 and the filesize,
and read from the file. If you read from the random location to the next newline,
y will most likely get only a partial word, so you skip the line you open to find and take the
ext word as your word by calling fgets() twice.

The function has two clear best. The first is if you reach the end of the file while looking
for a word, you go back to the beginning:

```
if (feof($fp)) { // if at end, go to start
    fseek($fp, 0);
}
```

The second is that you can seek for a word of a particular length: You each word that you
pull from the dictionary, and if it is not between $min length and $max length, you keep
searching. At the same time, you also draw words with apostrophes (single quotation marks)
in them. You could escape them out using the word, but just getting the next word is
easier.
