# Using jQuery in Web Applications

Loading the base jQuery library is all that is needed to give the full power of the jQuery core to your web application! Next, let's discuss some of of the basic concepts and abilities of jQuery usage.

# Basic jQuery Techniques and Concepts

We will start our discussion of using jQuery by presenting some of the fundamental concepts of the framework. For starters, by default jQuery creates a jQuery namespace containing the full scope of functionality available to the core.

You miss this jQuery namespace handle any time you want to do something with the jQuery library. That being said, having to type jQuery every time is a bit cumbersome, so by default the framework also creates a alias to the jQuery namespace as the $ symbol. We will use this alias throughout this chapter, as it is most commonly used in jQuery development.

However please note if you use jQuery in conjunction with other JavaScript frameworks that also try to make use of the $ symbol as alias for their framework, you can still use jQuery by setting it up to run in "no conflict" mode. This is done by calling the noConflict() method that returns an instance you can assign to any variable or alias to choose:

```
var newjQuery = jQuery.noConflict();
```

With out of that way, let's move on to the two fundamental concepts of jQuery development: selectors and events.

# Using jQuery Selectors

Selectors can be thought of a type of query language that allows you to identify pieces of your HTML documents that, based on criteria, either perform manipulations or attach logic to events triggered by them. This quasi-language is extremely powerful, allowing you to quickly reference HTML elements of a web page by various attributes of elements.

To understand how selectors work, let's start with a simple HTML document for discussion:

# List 23.1 simple_form.html—A Simple Form to Reference for Work with Selectors

```
<!DOCTYPE html>
<html>
<head>
  <title>Sample Form</title>
</head>
<body>
  <form id="myForm">
    <label for="first_name">First Name</label><br>
    <input type="text" name="name[first]"
    id="first_name" class="name"/><br>
```
