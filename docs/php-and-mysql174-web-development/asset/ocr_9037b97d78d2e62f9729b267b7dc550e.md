The HTML in Listing 23.1 as an example, let's look at a few different ways you can use jQuery to select various elements. If you want to select a single element the best approach is to do so by id attribute of the element:

```
var last_name = \$('#last_name');
```

This introduces you to our first selector syntax, the # operation, which indicates the string that follows is the id attribute of the target HTML element. If you want to select a group of elements, select both the first name and last name input fields, you can combine selectors together and separate by each:

```
var nameElements = \$('#first_name #last_name');
```

This code would return into nameElements an array of nodes that would be the HTML elements with the id attribute of first_name and last_name, respectively.

Typically, when selecting elements, you wouldn't necessarily use the # operator to select out each element if you want to select. A more common way would be used to select a group of elements, regardless of their HTML element ID), that belong to the same class. You can do this using the class selector:

```
var nameElements = \$('.name');
```

Since both input elements in our example HTML document have been assigned the name class (using the class attribute of their respective HTML element), the following two selectors in this example are equal. Selectors can also be based on HTML attributes that aren't the id or class attributes as shown below:

```
var nameElements = \$('input[type='text']');
```

This selector introduces a new syntax that allows you to search for HTML elements that have an arbitrary value for an arbitrary attribute. In this case, we are selecting all <input> HTML elements in the document that have a type attribute that equals text.
