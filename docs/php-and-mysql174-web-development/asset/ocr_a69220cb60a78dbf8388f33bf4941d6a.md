# Using PHP on the Command Line

You can easily write or download many small programs and run them on the command line. If you are on a Unix system, these programs are usually written in a shell scripting language or Perl. If you are on a Windows system, they are usually written as a batch file.

You probably first came to PHP for a web project, but the same text processing facilities make it a strong web language it a strong command-line utility program.

There are three ways to execute a PHP script at the command line: from a file, through a pipe, or directly on the command line.

To execute a PHP script in a file, make sure the PHP executable (php or php.exe depending on your operating system) is in your path and call it with the name of the script as an argument.
Here's an example:

```
php mys.php
```

The file myscript.php is just a normal PHP file, so it contains any normal PHP syntax within PHP tags.

To pass through a pipe, you can run any program that generates a valid PHP script as output and pipe it to the php executable. The following example uses the program echo to give a one-line program:

```
echo '<?php for($i=1; $i<10; $i++) echo $i; ?> | php
```

Again, the PHP code is enclosed in PHP tags (<?php ?>). Also note that this is the command-line program echo, not the PHP language construct.
