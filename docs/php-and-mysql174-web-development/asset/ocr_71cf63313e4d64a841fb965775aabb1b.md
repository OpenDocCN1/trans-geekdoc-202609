# Finding Substrings with Regular Expressions

Finding substrings is the main application of the regular expressions you just developed.

There are a number of PCRE regular expression functions in PHP. The simplest, preg_match(), is the one we will use in this example. It has the following:

```
int preg_match(string pattern, string subject, array matches, int flags=0, int offset=0)]
```

This function searches the subject string, looking for the regular expression in pattern. If a match is found, the full match will be stored in $matches[0], and each of the subsequent array elements will store a match for each matched subprocess.

The only possible value to flag is the constant PREG_OFFSET_CAPTURE. If this is set, the matches array will take a different format. Each element in the array will consist of an array of matched subprocesses, and the offset within the subject string where they were found.

The offset parameter is used to start searching the subject string from the specified offset.

The preg_match() function returns 1 if a match was found, 0 if a match was not found, and FALSE if an error occurred. This means you need to use identity (==) to test what is returned, to avoid confusion between 0 and FALSE.
