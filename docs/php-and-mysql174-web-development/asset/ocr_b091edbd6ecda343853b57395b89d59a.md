The script itself is reasonably straightforward; in fact, it doesn't use any functions you've seen before, just new applications of those functions.

```
if (!($contents = file_get_contents($url))) {
```

returns the entry of the file located at URL, stored in $contents.

The file functions do a lot in PHP. The example here lists a file via HTTP, but you could interact with other servers via HTTPS, FTP, or other protocols exactly the same way. For some tasks, you might need to take a more specialized approach. For example, FTP functionality is available in the specific FTP functions, and not available via `fopen()` and other file functions. Additionally, for some HTTP or HTTPS tasks, you may need to use the cURL library. With cURL, you can log in to a website and mimic a user's progress through a few pages.
