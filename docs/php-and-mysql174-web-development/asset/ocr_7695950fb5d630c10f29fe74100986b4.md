# Chapter 26 Debugging and Logging

| Value | Name | Meaning |
| --- | --- | --- |
| 128 | E_COMPILE_WARNING | Report nonfatal errors in compilation |
| 256 | E_USER_ERROR | Report user-triggered errors |
| 512 | E_USER_WARNING | Report user-triggered warnings |
| 1024 | E_USER_NOTICE | Report user-triggered notices |
| 2048 | E_STRICT | Report uses deprecated and unrecommended behavior; not included in E_ALL but very useful for code refactoring. Suggests changes for interoperability. |
| 4096 | E_RECOVERABLE_ERROR | Report catchable fatal errors. |
| 8192 | E_DEPRECATED | Report warnings about code that will not work in future PHP releases. |
| 16384 | E_USER_DEPRECATED | Report warnings generated by the PHP function trigger_error(). |
| 32767 | E_ALL | Report all errors and except except reported in E_Strict |

Each constant represents a type of error that can be reported or ignored. If, for instance you set the error level as E_ERROR, only fatal errors will be reported. These constants can be combined using bitwise arithmetic, to produce different error levels.

The default error level—report all errors except notices—is specified as follows:

```
E_ALL & -E_NOTICE
```

This expression consists of two the predefined constants combined using bitwise arithmetic operators. The operands are the bitwise AND and the tilde (-) is the bitwise NOT operator. This expression can be read as E_ALL AND NOT_NOTICE.

E_ERROR is itself a combination of all the other error types except E_STRICT. It could be replaced by the other levels combined using the bitwise OR (|):

```
E_ERROR | E_WARNING | E_PARSE | E_NOTICE | E_CORE_ERROR | E_CORE_WARNING |
E_COMPILE_ERROR | E_COMPILE_WARNING | E_USER_ERROR | E_USER_NOTICE
```

Similarly, the default error reporting level could be specified by all levels except E_NOTICE combined with OR:

```
E_ERROR | E_WARNING | E_PARSE | E_CORE_ERROR | E_CORE_WARNING | E_COMPILE_ERROR |
E_COMPILE_WARNING | E_USER_ERROR | E_USER_WARNING | E_USER_NOTICE
```
