| G | Hour of the day in 24-hour format without leading zeros. The range is from 0 to 23. |
| h | Hour of the day in 12-hour format with leading zeros. The range is from 01 to 12. |
| H | Hour of the day in 24-hour format with leading zeros. The range is from 00 to 23. |
| i | Minutes past the hour with leading zeros. The range is from 00 to 59. |
| I | Daylight savings time, represented as a Boolean value. This code format returns 1 if the date is in daylight and 0 if it is not. |
| j | Day of the month as a number without leading zeros. The range is from 1 to 31. |
| l | Day of the week in full-text format. The range is from Sunday to Saturday. |
| L | Leap year, represented as a Boolean value. This code format returns 1 if the date is a leap year and 0 if it is not. |
| m | Month of the year as a two-digit number without leading zeros. The range is from 01 to 12. |
| M | Month of the year in three-character abbreviated text format. The range is from Jan to Dec. Month of the year as a number without leading zeros. The range is from 1 to 12. |
| N | Day of the week as a single digit; ISO-8601 compliant. The range is from 1 (Monday) to 7 (Sunday). |
| o | ISO-8601 year number. This has the same value as Y, except that the ISO week number x) belongs to the previous or next year, where Y is used instead. |

| S | Ordinal suffix for two-character format. It can be st, nd, rd, or depending on the number it follows. |
| t | Total number of days in the month's month. The range is from 28 to 31. |
| T | Time zone of the server in three-character format—example, EST. |
| U | Total seconds from January 1, 1970 at 00:00:00, to the current time; also known as a Unix timestamp for this date. |
| W | Day of the week as a single digit. The range is from 0 (Sunday) to 6 (Saturday). Week number in the week, with weeks beginning on a Monday; ISO-8601 compliant. |
| Y | Year in two-digit format—example, 15. Year in four-digit format—example, 2015. |
| Z | Day of the year as a number. The range is 0 to 365. Offset for the current time zone in seconds. The range is -43200 to 43200.
