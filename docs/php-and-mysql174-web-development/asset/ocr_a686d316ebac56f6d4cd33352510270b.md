nonzero values evaluate to true and zero values to false. Say that you have initialized two
variables as:

```
$a = 5;
$b = 7;
```

If you test $a = $b, the result will be true. Why The value of $a = $b is the value
assigned to the left side, which in this case is7. Because 7 is a nonzero value, the expression
evaluates to true. If you intended $a == $b; which evaluates to false, you have
introduced a logical error in your code that are extremely difficult to find. Always check your
use of these two operators and check that you have used the one you intended to use.

Using the assignment operator rather than the equals operator is an easy mistake
and, will probably make it many times in your programming career.

# Other Comparison Operators

PHP also supports a number of comparison operators. A summary of all the comparison
operators is shown in Table 1.3. One operates is the identical operator (===), which returns
if only the two operands are both equal and of the same type. For example, o=='0' will
true, but 0!='0' will not because 0 is an integer and the other is a string.

| Operator | Name | Use |
|---|---|--|

# Logical Operators

The logical operators combine the results of logical conditions. For example, you might be
interested in a case where the value of a variable, $a, is between 0 and 100. You would need
test both the conditions $a >= 0 and $a <= 100, using the AND operator, as follows:

```
$a >= 0 && $a <= 100
```
