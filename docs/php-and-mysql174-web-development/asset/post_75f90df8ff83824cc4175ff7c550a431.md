
# Interacting with the File System

In addition to viewing and getting information about directories, you can interact with get information about files on the web server. You previously looked at writing and reading from files. A large number of functions related to the filesystem are available, which you can read out in more detail at http://php.net/manual/en/book.filesystem.php.

## Getting File Information

As an example of the types of information you can get about each file, let's first alter the part of the directory browsing script that reads files follows, to link another script you'll create momentarily. Instead of simply printing the file name in a bulleted list, print the file name as a link within a bulleted list:

```php
echo '<a href="filedetails.php?file='.$file.'"></a>'; own```

You can then create the filedetails.php to provide further information about a file. The contents of this file are shown in Listing 17.6.

One warning about the script that follows in Listing 17.6: Some of the functions used posix_getpwuid(), fileowner(), and filegroup() are not supported under Windows, or are not supported locally.

Listing 17.6 filedetails.php—File Statuses and Their Results

```php
<!DOCTYPE html>
<html>
<head>
<title>File Details</title>
</head>
<body>
<?php

if (!isset($_GET['file'])) {
  echo "You have not specified a file name.";
} else {
$uploads_dir = '/path/to/uploads/';

// strip off directory information for security
$file = basename($_GET['file']);

$safe_file = $uploads_dir.$file;
}
echo '<h1>Details of File: '.$safe_file.'</h1>';
echo '<h2>File Last Accessed: '.date('d J Y H:i', filetime($safe_file)).'<br/>';
echo 'File Last Modified: '.date('d J Y H:i', filetime($safe_file)).'<br/>';

$user = posix_getpwuid(fileowner($safe_file));
echo 'File Owner: '.$user['name'].'<br/>';

$group = posix_getgrgid(filegroup($safe_file));
echo 'File Group: '.$group['name'].'<br/>';

echo 'File Permissions: '.decoct(fileperms($safe_file)).'<br/>';
echo 'File Type: '.filetype($safe_file).'<br/>';
echo 'File Size: '.filesize($safe_file).' bytes<br/>';

echo '<h2>File Tests:</h2>' . ('is_dir: '.is_dir($safe_file) ? 'true' : 'false').'<br/>' . 'is_executable: '.is_executable($safe_file) ? 'true' : 'false').'<br/>' . 'is_file: '.is_file($safe_file) ? 'true' : 'false').'<br/>' . 'is_link: '.is_link($safe_file) ? 'true' : 'false').'<br/>' . 'is_readable: '.is_readable($safe_file) ? 'true' : 'false').'<br/>' . 'is_writable: '.is_writable($safe_file) ? 'true' : 'false').'<br/>';
?>
</body>
</html>
```

Let's examine each of the functions used in Listing 17.6. As mentioned previously, the basename() function gets the name of the file without the directory. (You can also use the dirname() function to get the directory name without the filename.

The atime() and mtime() functions return the timestamp of the time the file was last accessed and last modified. We reformatted the timestamp using the date() function to make it more readable. These functions return the same value on some operating systems (in the example) depending on what information the system stores.

The owner() and filegroup() functions return the user ID (uid) and group ID (gid) of the file. These IDs can be converted to names using the posix_getpwuid() and posix_getgrgid(), respectively, which makes them a bit easier to read. These functions use the uid or gid as a parameter and return an associative array of information about the user or group, including the name of the user or group, as we have used in this script.

The permissions() function returns the permissions on the file. We reformatted them as an octal number using the decoct() function to put it into a format more familiar to Unix users.

The filetype() returns some information about the type of file being examined. The possible results are fifo, char, dir, block, link, file, and unknown.

The filesize() returns the size of the file in bytes.

The second set of functions—is_dir(), is_executable(), is_file(), is_readable(), and is_writable()—all test the named attribute of the file. The stat() function returns an associative array of information about the file. If you want to clear the cached file status, you should call clearstatcache().

## Changing File Properties

In addition to viewing file properties, you can alter them if the user has proper permissions.

The chgrp() function changes the group of a file. It can be used to change groups of which the user is a member.

The chmod() function changes the permissions on a file. The permissions you pass to it are in the usual Unix form: chmod('somefile.txt', 0777);

The chown() function changes the owner of a file. It can be used only if the user is running root.

## Creating, Deleting, and Moving Files

You can use the file system functions to create, move, and delete files if the user has proper permissions.

First, and most simply, you can create a file, or change the time it was last modified, using the touch() function. This function works similarly to the Unix touch. The function has the following prototype:

```php
bool touch (string file, [int time , int atime])
```

If the file exists, its modification will be changed either to the current time or the time in the second parameter if it is specified. If the file does not exist, it will be created. The access time of the file will also change, by default to the current system time or alternatively to the timestamp you specify in the atime parameter.

You can delete files using the unlink() function. (Note that this function is not called delete()—there is no delete().) You use it like:

```php
unlink($filename);
```

You can copy and rename files with the copy() and rename() functions, as follows:

```php
copy($source_path, $destination_path);
rename($oldfile, $newfile);
```
