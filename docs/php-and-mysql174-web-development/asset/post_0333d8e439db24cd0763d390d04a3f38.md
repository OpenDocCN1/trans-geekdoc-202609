### # Is SSL Working?

At this stage, SSL should not be working on your machine, because we have not created the SSL certificates and keys that go along with it. Apache is configured and ready to go, but the underlying certificates that secure your data are not yet present.

You can create self-signed certificates for development purposes using OpenSSL; if you are going to use your site in production, you should use legitimately signed SSL certificates from a Certificate Authority. For example, Let's Encrypt is a free, automated, and open certificate Authority (CA), for the public benefit by the Internet Security Research Group (ISRG). Learn more at https://letsencrypt.org.

To create a self-signed certificate, use the following command to create a certificate and place both in a location that Apache expects:

```
# openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout /usr/local/apache2/conf/server.key \
-out /usr/local/apache2/conf/server.crt
```

The certificate and key creation script will ask some information about country, state, company name, and domain; you can make dummy information or use real information, as you'd like. After the restart, you will have a dummy self-signed certificate for 365 days, placed in /usr/local/apache2/conf along with its matching key.

The Apache SSL module has its own configuration file, located at /usr/local/apache2/conf/extra/httpd-ssl.conf. You can leave it untouched and just restart Apache for all changes to take effect, or you can continue to modify the configuration as you need. For documentation on the Apache httpd-ssl.conf modifications, please see http://apache.org/docs/2.4/mod_ssl.html.

In Apache 2.4, all you need to enable SSL is to uncomment the following lines in httpd.conf:

```apache
LoadModule ssl_module modules/mod_ssl.so
Include conf/extra/httpd-ssl.conf
```

After the changes, restart the server to see if it works with SSL. You can use configtest to check whether the configuration is set up properly:

```
# cd /usr/local/apache2/bin
# sudo ./apachectl configtest
Syntax OK
# sudo ./apachectl start
```

If it worked correctly, you will see something similar to Figure A.3 when you connect to the server with a web browser. Check both cases to ensure that everything is working.
