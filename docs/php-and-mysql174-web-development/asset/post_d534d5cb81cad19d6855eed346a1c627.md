
# Closing the Connection

After you have finished with the FTP connection, you should close it using the ftp_quit() function:

```
ftp_quit($conn);
```

You should pass this handle for the FTP connection.

# Uploading Files

If you want to go the other way—that is, copy files from your server to a remote machine—you can use two functions that are basically opposite of ftp_fget() and ftp_get(). These functions are called ftp_fput() and ftp_put(). They have the following prototypes:

```
int ftp_fput(int ftp_connection, string remotefile_path, int fp, int mode)
ftp_put(int ftp_connection, string remotefile_path, string localfile_path, int mode)
```

The parameters are the same as for _get equivalents.

# Avoiding Timeouts

One problem you might face when transferring files via FTP is exceeding the maximum execution-time. You will know when this happens when PHP gives you an error message. This error is especially likely to occur if your server is running over a slow or congested network, or if you are downloading a large file, such as a movie clip.

The default value of the maximum execution time for all PHP scripts is defined in php.ini. By default, it is set to 30 seconds. This is designed to catch scripts that are running out of control. However, when you are transferring files via FTP, if your link to the rest of the world is slow or if the file is large, the transfer could take longer than this.

Fortunately, you can modify the maximum execution time for a particular script by using the set_time_limit() function. Calling this function resets the maximum number of seconds the script is allowed to run, starting from the time the function is called. For example, if you call set_time_limit(90); script will be able to run for another 90 seconds from the time the function is called.

# Using Other FTP Functions

A number of other functions are useful in PHP. The function ftp_size() can tell you the size of a file on a remote server. It has the following prototype:

```
int ftp_size(int ftp_connection, string remotefile_path)
```

This function returns the size of the remote file in bytes or -1 if an error occurs. It is not supported by all FTP servers.

# Next 421

A handy use of ftp_size() is to work out the maximum execution time set for a particular transfer. Given the file size and speed of your connection, you can take a guess as to how long the transfer ought to take and use the set_time_limit() function accordingly.

You can get and display list of files in a directory on a remote FTP server using the following code:

```
$listing = ftp_list($conn, dirname($remotfile));
foreach ($listing as $filename) {
  echo $filename.'br />';
}
```

This code uses the ftp_list() function to get a list of files in a particular directory. In terms of FTP functions, anything that you can do from an FTP command, you can do with the FTP functions, with the exception of mget (multiple get). For mget, you could use ftp_list() to get a list of files and then fetch them as needed.

For a complete list of PHP functions corresponding to each FTP command, please see the PHP online manual at http://php.net/manual/en/book.ftp.php.

# Getting the Date and Time from PHP

Way back in Chapter 1, "PHP Crash Course," described using the date() function to get and format the date from PHP. Here, we discuss this function and some of PHP’s date functions in little more detail.

# Understanding Timezones

Some will argue the easiest way to deal with timezones in a web application is just not deal with them at all, because of the inevitable heartbreak timezones bring. Instead, you have the option of storing all your dates and times in a single, standard timezone (such as UTC) and converting them as needed to your own timezone (this can be tricky when you don’t actually know where your servers are located or in a different timezone).

In this chapter, you'll learn about the date(), time(), and strtotime() functions among others and it is important to note that these functions use the timezone specified by the date.timezone setting in php.ini. By default, the value of date.timezone is not set, so PHP uses the system default. We recommend setting a value for date.timezone, one of the timezones listed at http://php.net/manual/en/timezones. If you use a standard timezone such as UTC for all dates and times, you could use anywhere to update or insert a date in a table. However, if you go the route of storing dates and times in a standard format but want to convert them on the fly, you could also use the MySQL function called CON_TZ() to do so.

# Using the date() Function

As you might, the date() takes two parameters: the first one is a string format, and the second optional is a Unix timestamp. If you don't specify a timestamp, date() will default to the current date and time and returns a formatted string representing the appropriate date. A typical call to the date() function could be

```
echo date('j F Y');
```
