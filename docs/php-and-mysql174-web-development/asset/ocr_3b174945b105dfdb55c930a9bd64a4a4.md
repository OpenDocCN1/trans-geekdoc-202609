# Comparing Strings

So far, we've just shown how to use the operator == to compare two strings for equality. You can do some slightly more sophisticated comparisons using PHP. We've divided the comparisons into two categories for you: partial matches and others. We deal with the others first and then get into partial matching, which we need to further develop the Smart Form example.

# Performing String Ordering: strcmp(), strcasecmp(), and strnatcmp()

The strcmp(), strcasecmp(), and strnatcmp() functions can be used to order strings. This capability is useful when you are sorting data.

The prototype for strcmp() is
int strcmp(string str1, string str2);

The function expects to receive two strings, which it compares. If they are equal, it will return 0. If str after (or is greater than) str2 in lexicographic order, strcmp() will return a number greater than zero. If str is less than str2, strcmp() will return a number less than zero. This function is case sensitive.

Note that this is quite unintutive in some ways, testing for true/false as the return value will not give you the results you expect. If the strings match, the function returns 0, and you would write code like this:

```
if (strcmp($a,$b)) {

}
```

you will find that the if will be executed when the strings do not match.

The function strcasecmp() and its non-case sensitive twin, strnatcmp() compare strings according to a 'natural ordering', 2 which is more like a human would do. For example, strcmp() would order the string 2 as greater than the string 12 because it is lexicographically greater. strnatcmp() would order the other way around. You can read more about natural ordering at http://www.naturalordersort.org/

# Testing Length with strlen()

You can check the length of a string by the strlen() function. If you pass a string, this function will return its length. For example, the result of this code is 5:

```
echo strlen("hello");
```
