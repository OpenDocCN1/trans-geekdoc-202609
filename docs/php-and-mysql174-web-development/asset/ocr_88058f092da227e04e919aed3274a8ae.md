Part 4 of the script goes through the candidates from the database query results by one, works out the percentage of votes, and draws the bars and labels for each candidate.

Again, you add labels using imagettext() and draw the bars as filled rectangles imagefilledrectangle():
imagefilledrectangle($im, $x, $y-2, $bar_length, $bar_height, $bar_color);

You add outlines for the 100% mark using imagrectangle():
imagrectangle($im, $bar_length+1, $y-2,
($x+(100)*$bar_height), $bar_height, $line_color);

After you have drawn all the bars, you output the image using imagepng() and clean up after yourself using imagedestroy().

This long-ish script can be easily adapted to suit your needs or to generate polls via an interface. One important feature that this script is missing is any sort of anticheating mechanism. Users would quickly discover that they can vote repeatedly and make the result meaningless.

You can use a similar approach to draw line graphs, and even pie charts, if you are good at mathematics.
