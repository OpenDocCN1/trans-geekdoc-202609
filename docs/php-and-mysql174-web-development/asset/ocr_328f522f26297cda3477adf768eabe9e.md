produces this result:

```
+--------------------+
| Name               | |
+--------------------+
| Julie Smith         | |
| Alan Wong          | |
+--------------------+
2 rows in set (0.00)
```

However, if you provide two parameters, the first specifies the row number from which to start, and the second one specifies the number of rows to return.

This query illustrates the use of LIMIT:

```
SELECT Name
FROM Customers
LIMIT 2,3;
```

This query can be read as, "Select name from customers, and then return 3 rows, starting from row 2 in the output." Note that rows are zero indexed; that is, the first row in the output is row two. This feature is very useful for Web applications, as when the customer is browsing products in a catalog, and you want to show 10 items on each page. Note, however, that LIMIT is not part of ANSI SQL. It is a MySQL extension, making your SQL incompatible with many other RDBMS.

# Using Subqueries

A subquery is a query that is nested inside another query. Although most subquery functionality can be obtained with careful use of joins and temporary tables, subqueries are easier to read and write.

# Basic Subqueries

The most common use of subqueries is to use the result of one query in a comparison in another query. For example, if you wanted to find the order in which the amount was ordered the largest of any of the orders, you could use the following query:

```
SELECT CustomerID, Amount
FROM Orders
WHERE Amount = (SELECT MAX(Amount) FROM Orders);
```

This query gives the following results:

```
+-----------------------+
| CustomerID | Amount |
+-----------------------+
|      2      | 74.98 |
+-----------------------+
1 row in set (0.03)
```
