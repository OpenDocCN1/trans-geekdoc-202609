Under Windows, PNGs and JPEGs are automatically supported as long as you have the
php_gd2.dll extension registered. You can do this by copying the php_gd2.dll file from your
PHP installation directory to your system. You must also uncomment the following line in your
php.ini file by removing the ";" at the beginning of the line:

```
extension=php_gd2.dll
```

If you Unix want to work with PNGs, you need to download and install libpng
http://www.libpng.org/pub/png/libpng.html and zlib from http://www.zlib.net.

You need to configure PHP with the following options:

```
--with-png-dir=/path/to/libpng
--with-zlib-dir=/path/to/zlib
```

If you Unix want and to work with JPEGs, you need to download the JPEG library from
http://www.ij.org/; reconfigure PHP with the following option and compile it:

```
--with-jpeg-dir=/path/to/jpeg-6
```

Finally, you will need, to configure PHP using --with-gd.

# Understanding Image Formats

The GD library supports PNG, JPEG, GIF, and many other formats. You can learn more about
GD at http://libgd.github.io/. Let's take a look at a few of these image formats in the next few
sections.

# JPEG

JPEG (pronounced "jay-peg") stands for Joint Photographic Experts Group and is really the name
of standards rather than a specific format. The file format when we mean the JPEG
is officially JFIF, which corresponds to one of the standards used by JPEG.

In case you are not familiar with them, JPEGs are usually used to store photographic or other
images with many colors or gradations of color. This format uses low compression; that is,
squeeze a photograph into a smaller file, image quality is lost. Because JPEGs should
contain what are essentially analog images, with gradations of color, the human eye can
toler loss of quality. This format is not suitable for line drawing, text, or solid blocks
of color.

You can read more about JPEG/JFIF at the official JPEG site at http://www.jpeg.org.
