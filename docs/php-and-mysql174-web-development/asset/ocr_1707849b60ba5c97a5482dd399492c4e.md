The array elements will now appear in the order Oil, Spark Plugs, Tires.

You can sort values by numerical order, too. If you have an array containing the prices of Bob's products, you can sort it into ascending numerical order as:

```
$prices = array(100, 10, 4);
sort($prices);
```

The prices will now appear in the order 4, 10, 100.

Note that the sort() function is case sensitive. All capital letters come before lowercase letters. So A is less than Z, but Z is less than a.

The function also has an optional second parameter. You may pass one of the constants SORT_REGULAR (the default), SORT_NUMERIC, SORT_STRING, SORT_LOCALE_STRING, SORT_NATURAL, SORT_FLAG_CASE.

The ability to specify the sort type is useful when you are comparing strings that might contain numbers, for example, 2 and 12. Numerically, 2 is less than 12, but as strings '12' is less than '2'

Passing the LOCALE_STRING constant will sort the array as strings depending on the current locale, and sort orders are different in different locales.\ SORT_NATURAL causes a natural order to sort. You can also get this by using the natsort() function. Natural sort order is a combination of string and numeric sorts to be more intuitive. Using a sort string for 'file1', 'file2', and 'file10' would order them 'file1', 'file10', 'file2'. With a natural sort, they would be ordered as 'file1', 'file2', 'file10', which is more intuitive—or more natural—for humans.

The constant SORT_CASE is used in conjunction with SORT_STRING or SORT_NATURAL. We use the bitwise operator to combine them, as:

```
sort($products, SORT_STRING | SORT_FLAG_CASE);
```

This makes the sort() function ignore, so 'a' and 'A' are treated as equivalent.

# Using as and ksort() to Sort Arrays

If you are using an array with descriptive keys to store items and their prices, you need to use different kinds of sort functions to keep keys and values as they are sorted.

The following code creates an array containing the three products and their associated prices and then sorts the array into ascending price:

```
$prices = array('Tires'=>100, 'Oil'=>10, 'Spark Plugs'=>200);
asort($prices);
```

The function asort() orders the array according to the value of each element. In the array, the values are and the keys are the textual descriptions. If, instead of sorting by price, you want to sort by description, you can use ksort() rather than value.
