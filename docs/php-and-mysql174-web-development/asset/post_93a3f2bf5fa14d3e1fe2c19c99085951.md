## Opening a File for Reading: `fopen()`

Again, you open the file using `fopen()`. In this case, you open the file for reading only, so you use the mode `'rb'`.

```php
$fp = fopen($document_root/../orders/orders.txt', 'rb');
```

## Knowing When to Stop: `feof()`

In this example, you use a `while` loop to read from the file until the end of the file is reached. The while loop tests for the end of the file using the `feof()` function:

```php
while (!feof($fp))
```

The feof() function takes a file handle as its single parameter. It returns true if the file pointer is at the end of the file. Although the name might seem strange, you can remember it easily if you know that feof stands for End Of File.

In this case (and generally when reading from a file), you read from the file until EOF is reached.

## Reading a Line at a Time: `fgets()`, `fgets()`, and `fgetcsv()`

In this example, you use the `fgets()` function to read from the file:

```php
$order = fgets($fp);
```

This function reads one line at a time from a file. In this case, it reads until it encounters a newline character (`\n`) or EOF.

You can use many functions to read from files. The `fgets()` function, for example, is useful when you're dealing with files that contain plain text that you want to deal in chunks.

An interesting variation on `fgets()` has the following prototype:
`fgetcsv(resource $fp, int $length[, string $allowable_tags])`

This function is similar to `fgets()` except that strips out any PHP and HTML tags found in the string. If you want to leave in any particular tags, you can include them in the `allowable_tags` string. You would use `fgetcsv()` for safety when reading a file written by somebody else or one containing user input. Using unrestricted HTML code in the file could mess up your carefully formatted planning. Allowing unrestricted PHP or JavaScript could give a malicious user an opportunity to create a security problem.

The function `fgetcsv()` is another variation on `fgets()`. It has the following prototype:
`fgetcsv(resource $fp, int $length [, string $delimiter[, string $enclosure[, string $escape]])`

This function breaks up lines of files when you have used a delimiter character, such as the tab character (as suggested earlier) or a comma (commonly used by spreadsheets and other applications). If you want to reconstruct the variables of order separated rather than as a line of text, `fgetcsv()` allows you to do this simply. You can call it in the same way as you call `fgets()`, but you pass the delimiter you used to separate fields. For example,

```php
$order = fgetcsv($fp, 0, "\t");
```

This code would retrieve a line from the file and break it up wherever a tab (`\t`) was encountered. The results are returned in an array ($order$ in this example). We cover arrays in more detail in Chapter 3.

The length parameter should be greater than the length in characters of the longest line in the file you are trying to read, or 0 if you do not want to limit the line length.

The enclosure parameter specifies what each field in a line is surrounded by. If not specified, it defaults to `"` (a double quotation).

## Reading the Whole File: `readfile()`, `passthru()`, `file()`, and `file_get_contents()`

Instead of reading from a file at a time, you can read the whole file in one. Here are four different ways you can do this.

The first uses `readfile()`. You can replace almost the script you wrote previously with one line:

```php
readfile("$document_root/../orders/orders.txt");
```

The second uses `passthru()`. You can replace almost the script you wrote previously with one line:

```php
passthru("$document_root/../orders/orders.txt");
```

The third uses `file()`. You can replace almost the script you wrote previously with one line:

```php
$filearray = file("$document_root/../orders/orders.txt");
```

The fourth uses `file_get_contents()`. You can replace almost the script you wrote previously with one line:

```php
$content = file_get_contents("$document_root/../orders/orders.txt");
```

The `file()` function reads the entire file into an array. Each line of the file is stored in a separate element. Note that this function was not binary safe in older versions of PHP.

The `file_get_contents()` function is identical to `readfile()` except that it returns the content as a string instead of outputting the directly.

## Reading a Character: `fgetc()`

Another option for file processing is to read a single character at a time from a file. You can do this by using the `fgetc()` function. It takes a file pointer as its only parameter and returns the next character in the file. You can replace the while loop in the original script with one that uses `fgetc()`, as:

```php
while (!feof($fp)) {
    $char = fgetc($fp);
    if (!feof($fp)) {
        echo ($char=="\n" ? "<br />" : $char);
    }
}
```

This is just to clear the formatting. If you output the file with newlines between records, the file will be printed on a single line. (Try it and see) Web browsers do not render whitespace, such as newlines, so you need to replace them with HTML linebreaks (<br /> instead). You can use the ternary operator to do this.

A minor side effect of using `fgetc()` instead of `fgets()` is that `fgetc()` returns the EOF character, whereas `fgets()` does not. You need to test `feof()` again after you've read the character because you don't want to echo the EOF to the browser.

## Reading an Arbitrary Length: `fread()`

The final way you can read from a file is to use the `fread()` function to read an arbitrary number of bytes from the file. This function has the following prototype:

```php
string fread(resource $fp, int $length);
```

It reads $length$ bytes, to the end of the file or network packet, whichever comes first.
