# Understanding Scope 149

+   * The special superglobal variables are visible both inside and outside functions.
(See Chapter 1, "PHP Course,\") for more information on these variables.)"

+   * Using require() and include() statements do not affect scope. If the statement is
used within a function, function scope applies. If it is not inside a function, global scope
aplies.

+   * The keyword global can be used to manually specify that a variable defined or used
within a function will have global scope.

+   * Variables can be manually deleted by calling unset($variable_name). A variable is no
longer in scope if it has been unset.

The following examples may help to clarify scope.
The following code produces no output. Here, we declare a variable $var inside the
fn(). Because this is declared inside a function, it has function scope and\exists only where it is declared until the end of the function. When you refer to
$var outside the function, the new variable called $var is created. This new variable has global
scope and will be visible until the end of the file. Unfortunately, if the only statement you use
with this $var variable is echo, it will never have a value.

```
function fn() {
$var = "contents";n}
fn();
echo $var;
```

The following example is the inverse. Here, you declare a variable outside the function and
then to use it within a function:

```
<?php
function fn() {
echo 'inside the function, at first $var = ''.$var.'<br />';
$var = 2;
echo 'then, inside the function, $var = ''.$var.'<br />';
}
$var = 1;
fn();
echo 'outside the function, $var = ''.$var.'<br />;
?>
```

inside the function, at first $var =
then inside the function, $var = 2
outside the function, $var = 1
