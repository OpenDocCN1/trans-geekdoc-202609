# Multidimensional Arrays

To display the contents of this array, you could easily access each element in order like this:

```
echo |'.$products[0][0].|'.$products[0][1].|'.$products[0][2].<br />
echo |'.$products[1][0].|'.$products[1][1].|'.$products[1][2].<br />
echo |'.$products[2][0].|'.$products[2][1].|'.$products[2][2].<br />
```

Alternatively, you could use a nested another for loop to achieve the same result:

```
for ($row = 0; $row < 3; $row++) {
    for ($column = 0; $column < 3; $column++) {
        echo |'.$products[$row][$column];<br />
    }
}
```

Both versions of this code produce the same output in the browser:

```
|TIR|Tires|100|OIL|10|
|SPK|Spark Plugs|4|
```

The only difference between the two examples is that your code would be shorter if you use the second version with a large array.

You might prefer to create column names instead of numbers, as shown in Figure 3.3. To store the set of products, with the columns as they are in Figure 3.3, you would use the following code:

```
$products = array(
    'Code' => 'TIR',
    'Description' => 'Tires',
    'Price' => 100,

    'Code' => 'OIL',
    'Description' => 'Oil',
    'Price' => 10,

    'Code' => 'SPK',
    'Description' => 'Spark Plugs',
    'Price' => 54

);
```

This is easier to work with if you want to retrieve a single value. Remember that the description is stored in the Description column is easier than remembering it is stored in column 1. Using descriptive indices, you do not need to remember that an item is stored at [x] [y]. You can easily find your data by referring to a location with meaningful row and column names.

You do, however, lose the ability to use a simple for loop to step through each column in turn. Here is one way to write this array:

```
for ($row = 0; $row < 3; $row++) {
    echo |'.$products[$row]['Code'].|'.$products[$row]['Description'];
}
```
