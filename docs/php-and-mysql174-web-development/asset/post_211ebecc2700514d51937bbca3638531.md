## Brief Introduction to jQuery

jQuery is an extremely popular JavaScript framework in use today. JavaScript frameworks as which perform the important job of creating a unified API for programming in JavaScript regardless of the framework being used by the user. Without such a framework, the peculiarities and differences of each individual browser and version of that browser would be accounted for every time you write JavaScript in your application. Frameworks like jQuery address this problem for you, which allows you to focus on the logic of your application rather than on the wide array of browsers your users could possibly use.

The jQuery framework is not only powerful in its own right, but is amazingly extendable through an entire collection of high-quality plugins based on the framework. These plugins provide the functionality a developer could need in applications. For the purposes of this chapter we focus on jQuery Core functionality, and specifically the AJAX functionality it provides.

## Using jQuery in Web Applications

Getting jQuery as a tool for building a web application is extremely easy. Since it is just a JavaScript library, you simply need to include the library using the HTML `script` tag.

There are two basic approaches to use this when you do:

- Download and include the jQuery library as part of your web application, then reference the relevant jQuery file using a standard `<script>` tag.
- Use the jQuery CDN to load JavaScript into your application requiring no files to exist locally in your project. Your `<script>` tag will reference an external URL.

For the sake of portability, we use the latter approach throughout this chapter.

Thus, enabling jQuery support in your web application is simply a matter of including the jQuery library within an HTML document using a `<script>` tag as follows, which references the current version of jQuery at the time of:

```
<script src="//code.jquery.com/jquery-2.2.3.min.js"></script>
```

You will not need to specify a protocol (e.g., http://) when including the jQuery library. This was an intentional omission indicating to the browser that this resource should be loaded using the protocol defined by the parent document. Thus, if the page was loading using the // protocol this will be used to load the library as well. By taking this approach you can avoid potential security warnings raised by browsers attempting to load, for example, insecure resources during a secure request.

## Basic jQuery Techniques and Concepts

We will start our discussion of using jQuery by presenting some of the fundamental concepts of the framework. For starters, by default jQuery creates a jQuery namespace containing the full scope of functionality available to the core.

You need this jQuery namespace handle any time you want to do something with the jQuery library. That being said, having to type jQuery every time is a bit cumbersome, so by default the framework also creates an alias to the jQuery namespace as the $ symbol. We will use this alias throughout this chapter, as it is most commonly used in jQuery development.

However please note if you use jQuery in conjunction with other JavaScript frameworks that also try to make use of the $ symbol as alias for their framework, you can still use jQuery by setting it up to run in "no conflict" mode. This is done by calling the noConflict() method that returns an instance you can assign to any variable or alias to choose:

```
var newjQuery = jQuery.noConflict();
```

## Using jQuery Selectors

Selectors can be thought of as a type of query language that allows you to identify pieces of your HTML documents that, based on criteria, either perform manipulations or attach logic to events triggered by them. This quasi-language is extremely powerful, allowing you to quickly reference HTML elements of a web page by various attributes of elements.

To understand how selectors work, let's start with a simple HTML document for discussion:

### List 23.1 simple_form.html—A Simple Form to Reference for Work with Selectors

```html
<!DOCTYPE html>
<html>
<head>
  <title>Sample Form</title>
</head>
<body>
  <form id="myForm">
    <label for="first_name">First Name</label><br>
    <input type="text" name="name[first]"
    id="first_name" class="name"/><br>
    <label for="last_name">Last Name</label><br>
    <input type="text" name="name[last]"
    id="last_name" class="name"/><br>
    <button type="submit">Submit Form</button>
  </form>

  <hr>

  <div id="webConsole">
    <h3>Web Console</h3>
  </div>

  <script src="//code.jquery.com/jquery-2.2.3.min.js"></script>
</body>
</html>
```

The HTML in Listing 23.1 as an example, let's look at a few different ways you can use jQuery to select various elements. If you want to select a single element the best approach is to do so by id attribute of the element:

```javascript
var last_name = $('#last_name');
```

If you want to select multiple elements that share the same class, you use the class selector:

```javascript
var elements = $('.name');
```

If you want to select elements by their HTML tag name, you use the tag selector:

```javascript
var inputs = $('input');
```

You can also select elements based on their attributes using attribute selectors:

```javascript
var firstInput = $('input[name="name[first]]');
```

Finally, you can combine selectors to find more specific elements:

```javascript
var specificInput = $('#myForm .name');
```
