# Formatting Strings

You need to clean up user strings (typically from an HTML form interface) before you can use them. The following sections describe some of the functions you can use.

# Trimming Strings: chop(), ltrim(), and trim()

The first step in tidying up is to trim any whitespace from the string. Although this step is not compulsory, it can be useful if you are going to store the string in a file or database, or if you're going to compare it to other strings.
PHP provides three useful functions for this purpose. In the beginning of the script when you give name to the input variables, you can use the trim() function to tidy up your data as follows:

```
$name = trim($_POST['name']);
$email = trim($_POST['email']);
$feedback = trim($_POST['feedback']);
```

The trim() function starts from the start of a string and returns the resulting string. It trims characters by default newlines and carriage returns (\n and \r), horizontal and vertical tabs (\t and \x0B), of-string characters (\0), and spaces. You can also pass a second parameter to a list of characters to trim instead of this default list. Depending on your particular purpose, you might like to use the ltrim() or rtrim() functions instead. They are similar to trim(), taking the string as a parameter and returning the formatted string. The difference between these is that trim() removes whitespace from the start and end of a string, ltrim() removes whitespace from the start (or left) only, and rtrim() removes whitespace from the end (or right).

You may also use the chop() for rtrim(). Perl has a similar function but they behave slightly differently, so be cautious in your assumptions if you are coming to PHP from a Perl background.
