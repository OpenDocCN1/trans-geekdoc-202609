Most protocols and other Internet standards are described in documents Requests for
Comments (RFCs). These protocols are defined by the Internet Engineering Task Force (IETF).
The RFCs are widely available on the Internet. The base source is the RFC Editor at
http://www.rfc-editor.org.

If you have problems working with a given protocol, the documents that define them are
t authoritative sources and are useful for troubleshooting your code. They are, however,
very detailed and often run to hundreds of pages.

Some examples of well-known RFCs are RFC2616, which describes the HTTP/1.1 protocol, and
RFC822, which describes the format of Internet email messages.

In this chapter, we look at aspects of PHP that use of these protocols. Specifically, we
sending mail with SMTP, reading mail with POP3 and IMAP4, connecting to other web
servers via HTTP, and transferring files with FTP.

# Sending and Reading Email

The main way to send mail in PHP is to use the simple mail() function. We discussed the
of this function in Chapter 4, "String Manipulation and Regular Expressions," so we won't visit
it here again. This function uses the Simple Mail Transfer Protocol (SMTP) to send mail.

You can use a variety of freely available classes to add to the functionality of mail(). SMTP is
off for sending mail. The Internet Message Access Protocol (IMAP4), described in RFC2060,
and Post Office Protocol (POP3), described in RFC1939 or STD0053, are used to read mail from
a mail server. These protocols cannot send mail.

IMAP is used to read and manipulate mail messages stored on a server and is
sophisticated than POP3, which is generally used to download mail messages to a client
de delete them from the server.

PHP includes over thirty functions that can be used with IMAP4, all of which are described
at at http://php.net/manual/en/book.imap.php.
