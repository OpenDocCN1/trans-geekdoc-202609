# ### The tables_priv, columns_priv, procs_priv, and procs_priv Tables

The tables_priv, columns_priv, procs_priv, and proxies_priv tables are used to store table-level privileges, column-level privileges, privileges regarding stored routines, and proxy-related privileges, respectively.

These tables have a slightly different structure than the user and db tables. The schemas for the tables_priv, columns_priv, procs_priv table, and proxies_priv table are shown in Tables 12.3, 12.4, 12.5, and 12.6, respectively.
