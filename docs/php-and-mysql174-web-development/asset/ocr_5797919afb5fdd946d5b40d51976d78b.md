# Logging In to MySQL

As a result of leaving off the semicolon, you can have new lines in the middle of a command. We used this scheme to make the examples easier to read. You can see how we have used this approach because MySQL provides a continuation symbol; it's an arrow that looks like this:

```
mysql -h grant select
->
```

# Logging In to MySQL

To log in to MySQL, go to a command-line interface on your machine and type the following:

```
mysql -h hostname username -p
```

The mysql command invokes the MySQL monitor, which is a command-line client that connects you to the MySQL server.

- -h switch switches the host which you want to connect—that is, the machine on which the MySQL server is running. If you are running this on the same machine as the MySQL server, you can leave out this switch and the hostname parameter. If you not, you should replace the hostname parameter with the name of the machine where the MySQL server is running.

- -u switch specifies the username you want to connect as. If you do not specify, the default will be the username you are logged in to the operating system.

If you have installed MySQL on your own machine or server, you need to log in as root and create the database we use in this section. Assuming that you have a clean install, root is the only user you'll have to use. If you are using MySQL on a machine administered by somebody else, use the username that gave you.

- -p switch tells the server you want to connect using a password. You can leave it out if the password has not been set for user you are logging in.

If you are logging in as root and not have a password for root, we strongly recommend that you visit Appendix right. Without a root password, your system is insecure.

You don't need to include the password on line. The MySQL server will ask you for it. In fact, it's better if you don't include here. If you enter the password on the command line, it will appear as plain text on the screen and will be quite simple for other users to discover.

After you the previous command, you should get a response something like this:

```
Enter command:
```

(If this command doesn't work, verify that the MySQL server is running and the mysql command is somewhere in your path.)
