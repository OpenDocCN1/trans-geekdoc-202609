# Using Operators

Operators are symbols that you use to manipulate values and variables by performing an operation on them. You need to use some of these operators to work out the totals and tax on the customer's order.

We've already mentioned two operators: the assignment operator (=) and the string concatenation operator (.). In the following sections, we describe the complete list.

In general, operators take one, two, or three arguments, with the majority taking two. For example, the assignment operator takes two: the storage location on the left side of the the = symbol and an expression on the right side. These arguments are called operands—that is, the things that are operated upon.

# Arithmetic Operators

Arithmetic operators are straightforward; they are just the normal mathematical operators. PHP's arithmetic operators are shown in Table 1.1.

# Table 1.1 PHP's Arithmetic Operators

| Operator | Name | Example |
|---|---|---|n| + | Addition | $a + $b |
| - | Subtraction | $a - $b |
| * | Multiplication | $a * $b |
| / | Division | $a / $b |
| % | Modulus | $a % $b |

With these of operators, you can store the result of the operation, as in this example:
$result = $a + $b;

Addition and subtraction work as you would expect. The result of these operators is to add or subtract, the values stored in the $a and $b variables.

You can also use the subtraction (-) as a unary operator—that is, an operator that takes one argument or operand—to indicate negative numbers, in this example:
$a = -1;

Multiplication and division also work much as you would expect. Note the use of the asterisk as the multiplication operator than than regular multiplication, and the forward slash as the division operator rather than the regular division symbol.

The modulus operator returns the remainder calculated by dividing the $a by the $b variable. Consider this code fragment:

```
$a = 27;
$b = 10;
$result = $a&$b;
```
