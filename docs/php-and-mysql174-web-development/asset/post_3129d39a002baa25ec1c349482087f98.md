
echo '||.$products[$row]['Price']|';br />';

}

Using a for loop, you can step through the outer, numerically indexed $products array. Each row in the $products array is an array with indices. Using the each() and list() functions in a while loop, you can step through these inner arrays. Therefore, you can use a while loop inside a for loop:

```php
for ($row = 0; $row < 3; $row++) {
    while (list($key, $value) = each($products[$row])) {
        echo '||.$value;';
    }
    echo '<br />';
}
```

You do not need to stop at two dimensions. In the same way that array elements can hold new arrays, those arrays, in turn, can hold more arrays.

A three-dimensional array has height, width, and depth. If you are comfortable thinking of a two-dimensional array as a table with rows and columns, imagine a pile or deck of tables. Each element is referenced by its layer, row, and column.

From the code that defines this array, you can see that a three-dimensional array is an array containing arrays of arrays:

```php
$categories = array(
    array(array('CAR_TIR', 'Tires', 100 ),
          array('CAR_OIL', 'Oil', 10 ),
          array('CAR_SPK', 'Spark Plugs', 4)),
    array(array('VAN_TIR', 'Tires', 120 ),

          array('TRK_OIL', 'Oil', 15 ),
          array('TRK_SPK', 'Spark Plugs', 6 ))

```

Because this array has only numeric indices, you can use loops to display its contents:

```php
for ($layer = 0; $layer < 3; $layer++) {
    echo 'Layer'.$layer.'<br />';
    for ($row = 0; $row < 3; $row++) {
        for ($column = 0; $column < 3; $column++) {
            echo '|'.$categories[$layer][$row][$column];
        }
        echo '<br />';

}
```

Because of the way multidimensional arrays are created, you could create five-, or even six-dimensional arrays. There is no language limit to the number of dimensions, but it is difficult for people to visualize constructs with more than three dimensions. Most real-world problems match logically with constructs of three or fewer dimensions.

## Sorting Arrays

Sorting data stored in an array is often useful. You can easily take a one-dimensional array and sort it into order.

## Using sort()

The following code showing the sort() function results in the array being sorted into ascending alphabetical order:

```php
$products = array('Tires', 'Oil', 'Spark Plugs');
sort($products);
```

The array elements will now appear in the order Oil, Spark Plugs, Tires.

You can sort values by numerical order, too. If you have an array containing the prices of Bob's products, you can sort it into ascending numerical order as:

```php
$prices = array(100, 10, 4);
sort($prices);
```

The prices will now appear in the order 4, 10, 100.

Note that the sort() function is case sensitive. All capital letters come before lowercase letters. So A is less than Z, but Z is less than a.

The function also has an optional second parameter. You may pass one of the constants SORT_REGULAR (the default), SORT_NUMERIC, SORT_STRING, SORT_LOCALE_STRING, SORT_NATURAL, SORT_FLAG_CASE.

The ability to specify the sort type is useful when you are comparing strings that might contain numbers, for example, 2 and 12. Numerically, 2 is less than 12, but as strings '12' is less than '2'.

Passing the LOCALE_STRING constant will sort the array as strings depending on the current locale, and sort orders are different in different locales. SORT_NATURAL causes a natural order to sort. You can also get this by using the natsort() function. Natural sort order is a combination of string and numeric sorts to be more intuitive. Using a sort string for 'file1', 'file2', and 'file10' would order them 'file1', 'file10', 'file2'. With a natural sort, they would be ordered as 'file1', 'file2', 'file10', which is more intuitive—or more natural—for humans.

The constant SORT_CASE is used in conjunction with SORT_STRING or SORT_NATURAL. We use the bitwise operator to combine them.
