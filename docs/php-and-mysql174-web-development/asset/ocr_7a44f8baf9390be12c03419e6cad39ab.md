# for and foreach Loops

The way that you used the while loops in the preceding section is very common. You set a counter to begin with. Before each iteration, you test the counter in a condition. And at the end of each iteration, you modify the counter.

You can write this style of loop in a more compact form by using a for loop. The basic structure of a for loop is

```
for(expression1; condition; expression2)
expression3;
```

+   * expression1 is executed once at the start. Here, you usually set the initial value of a counter.
* condition expression is tested before each iteration. If the expression returns false, iteration stops here. Here, you usually test the counter against a limit.
* expression2 is executed at the end of each iteration. Here, you usually adjust the value of the counter.
* expression3 is executed once per iteration. This expression is usually a block of code and contains the body of the loop.

You can rewrite the while loop example in Listing 1.3 as a for loop. In this case, the PHP code becomes

```
<?php
for ($distance = 50; $distance <= 250; $distance += 50) {
  echo "<tr>
    <td style="text-align:right;"">$distance."</td>
    <td style="text-align:right;"">($distance / 10)."</td>
  </tr>\n";
}

```

Both the while and for loops are functionally identical. The for loop is somewhat compact, saving two lines.

Both these loop types are equivalent, neither is better or worse than the other. In a given situation, you may find one much more intuitive.

As a side note, you can combine variables with a for loop to iterate through a series of repetitive field fields. If, for example, you form fields with names such as name1, name2, name3, and so, you can process them like this:

```
for ($i=0; $i < count($names); $i++) {
  $temp=$name[$i];
  echo htmlspecialchars($temp).'<br />'; // or whatever processing you want to

```

By dynamically creating the names of the variables, you can access each of the fields in the turn.
