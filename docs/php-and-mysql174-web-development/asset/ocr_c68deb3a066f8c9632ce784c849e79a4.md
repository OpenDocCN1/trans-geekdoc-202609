# Building User Authentication and Personalization

In this project, you get users to register at your website. After they've done that, you can track what they're interested in and show them appropriate content. This behavior is called personalization.

This particular project enables users to build a set of bookmarks on the web and suggests other links they might find interesting based on their past behavior. More generally, user personalization can be used in any web-based application to show users the content they want in the format they want it.

In this project, you start by looking at a set of requirements similar to those you might get from a client. You develop these requirements into a set of solution components, build a design to connect those components together, and implement each of the components.

In this project, you implement the following functionality:

+   * Logging in and authenticating users
* Managing passwords
* Recording user preferences
* Personalizing content
* Recommending content based on existing knowledge about a user

# Solution Components

For this project, your job is to build a prototype for an online bookmarking system, to be called PHPbookmark.
