Unsurprisingly, you can simply select by name elements based on the element type. For example, if you wanted to return the entire body of an HTML document you could use the following syntax:

```
var documentBody = $('body');
```

In addition to the ability to select specific elements a number of pseudo-selectors on attributes or element name, jQuery supports to select elements in a more programmatic fashion. We will not be covering every pseudo-selector (nor every specific selector syntax in general) in this chapter, but there are a few more useful and common syntaxes available:

```
var firstInput = $('first');
```

This code returns the first HTML <html> element found in the document. If you wanted to limit the search to the first <html> element found within our specific HTML form you could do this as well by combining two selectors:

```
var firstInput = $('myForm input:first');
```

Another selector, especially working with HTML tables, can be seen in the selectors that allow you to select every other result of a given overall selector. For example, we know from previous examples that the following selector will return every <tr> tag in a given HTML document:

```
var tableRows = $('tr');
```

By adding the pseudo-selector :even or :odd, we can return every other row into our selector, based on if it counting as an "even" or an "odd" row

```
var oddRows = $('odd');
```

```
var evenRows = $('even');
```

Selectors can also be used on foundational JavaScript objects such as the document object available by default (representing the entire document). Simply pass the object into jQuery as you would a selector:

```
var jQueryDocSelector = $('document');
```

Finally, while not technically a "selector," this approach can be used to create new HTML elements in memory which can be manipulated and added to the existing HTML document—essentially changing the contents on the page without refreshing the page. For example, say you wanted to create a new <p> HTML element. You could do so quickly as follows:

```
var newParagraph = $('<p>');
```

Using this technique, you could theory construct entire segments of an HTML document, or even an HTML document:

```
var newParagraph = $('<p>This Is some <strong>Strong Text</strong></p>');
```
