Let's examine what you do differently in this script.

$db = new PDO($dsn, $user, $pass);

This function accepts a connection string, also called a DSN or data source name, that contains all the parameters to connect to the database. You can see this if you look at the format of the connection string:

```
$dsn = mysql:host=$host;dbname=$db_name";
```

You will note that the database connection is contained in a try:catch block. If a problem occurs, PDO will throw an exception. Near the bottom of the script you will see the catch block for errors:

```
catch (PDOException $e) {
    echo "Error: .$e->getMessage();
    exit;
}
```

The type of exception thrown is a PDOException, and as you can see from the code it includes a message about the type of error that occurred.

Assuming everything has gone well, you set up a query and execute it as follows:

```
$query = "SELECT ID, Author, Title, Price\nFROM BOOKS WHERE $searchtype = :searchterm";
$stmt = $stmt->prepare($query);\n$stmt->bindParam(':searchterm', $searchterm);\n$stmt->execute();
```

This is similar to how we set up and executed a prepared statement using the mysqli extension. Here is where we use a named parameter for replacement. (You can use these with mysqli, and can use query-style replacement with PDO).

You can check the number of books returned:

```
echo "<p>Number of books found: .$stmt->rowCount().</p>";
```

Note that in PDO this is a method rather than an attribute, and as such requires the parentheses().
