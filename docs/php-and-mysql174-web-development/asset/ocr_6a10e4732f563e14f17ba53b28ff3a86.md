```
foreach ($products as $current) {
    echo $current."";
}
```

This code stores each element in turn the variable $current and prints it out.

# Arrays with Different Indices

In the $products array, you allowed PHP to give each item the default index. This meant that the first item you became item o; the second, item i; and so. PHP also supports arrays in which you can associate any scalar key or index you use with each value.

# Initializing an Array

The following code creates an array with product names as keys and as values:

$prices = array('Tires'=>100, 'Oil'=>10, 'Spark Plugs'=>4);
The symbol between the keys and values (=>) is simply an equal sign immediately followed by a greater than symbol.

# Accessing the Array Elements

Again, you access the contents using the variable name and a key, so you can access the information stored in the array as $prices['Tires'], $prices['Oil'], and $prices['Spark Plugs'].

The following code creates an array with $prices. Instead of creating an array with three elements, this creates an array with only one element and adds two more:

```
$prices = array('Tires'=>100);
$prices['Oil'] = 10;
$prices['Spark Plugs'] = 4;
```

Here is another slightly different but equivalent piece of code. In this version, you do not explicitly create an array at all. When you add the first element to it:

```
$prices['Tires'] = 100;
$prices['Oil'] = 10;
$prices['Spark Plugs'] = 4;
```

# Using Loops

Because the indices in an array are not numbers, you cannot use a simple counter for a for loop to work with the array. However, you can use the foreach loop or the list() and each() constructs.
