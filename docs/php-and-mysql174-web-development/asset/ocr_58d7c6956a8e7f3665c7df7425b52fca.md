# Chapter 27 Building User Authentication and Personalization

As you can see, this file is a container for the other five files you will use in this application. We structured the project like this because the functions fall into logical groups. Some of these groups might be useful for other projects, so we put each function group into a different file so you know where to find it when you want it. We constructed the bookmark_fns.php file because you will use most of the functions in most of the scripts. Including one file in each script is easier than having five require statements in each script.

In this particular case, you use functions from the file output_fns.php. They are all straightforward functions that output plainly HTML. This file includes the four functions used in login.php—that is, do_html_header(), display_site_info(), display_login_form(), and do_html_footer(), others.

Although we will go through all these functions in detail, let's look at one as an example. The code for do_html_header() is shown in Listing 27.4.
