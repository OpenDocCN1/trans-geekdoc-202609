# Chapter 23 Integrating JavaScript and PHP

The $.get() method, we simply pass the URL we are requesting (in the form of a generic JavaScript object), and the callback to use when the request returns successfully. If an error occurs while performing the request, the $.get() method silently fails.

One might think, there is a corresponding-the $.post() method that functions in an identical fashion (except performing an HTTP POST request):

```
// Simplified POST requests
$.post('/example.php', {
  postParam' : 'paramValue',
  function(data, textStatus, jqXHR) {
    console.log(data);
  }
});
```

There are two additional methods that can be useful under certain circumstances beyond the simple HTTP and HTTP POST. The first is the $.getJSON() method, which dynamically loads a JavaScript document from the server and executes it in a single command:

```
$.getJSON('/path/to/my.js', function() {
  // my.js has been loaded and any functions / objects defined can now be used
});
```

In a similar fashion, the $.JSON() method performs an HTTP GET request to the specified URI, parses the return value as a JSON document, and makes it available to the callback function:

```
// Load a JSON document via HTTP GET
$.JSON('/example.php', {
  'jsonParam' : 'paramValue',
  function(data, textStatus, jqXHR) {
    console.log(data.status);
  }
});
```
