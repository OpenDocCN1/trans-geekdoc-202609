# 27.7 filled_out() Function from data_valid_fns.php—Function Checks that the Form Has Been Filled Out

```
function filled_out($form_vars) {
    // test that each variable has a value
    foreach ($form_vars as $key => $value) {
        if (!isset($value)) || ($value == '')) {
            return false;
        }
    }
    return true;
}
```
