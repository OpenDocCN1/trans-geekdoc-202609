If the URL is valid, you then go on check the email address. First, you split it into username
hostname with a call to explode():

```
$email = explode('@', $email);
$emailhost = $email[1];
```

When you have the host port of the address, you can check to see whether there is a place for
mail to go by using the getmxr() function:

```
getmxr($emailhost,$mxhostsarr);
```

This function returns the set of Mail Exchange (MX) records for an address in the array\upply at $mxhostsarr.

An MX record is stored at the DNS and is looked up as a hostname. The machine listed in
the MX record isn't necessarily the machine where the mail will eventually end up. Instead,
it's a machine that knows where to route to that. (There can be more than one; hence, this
function returns an array rather than a hostname string.) If you don't have an MX record in
the DNS, there's nowhere for the mail to go.

If all checks are okay, you can put this data in a database for later review by a staff
member. We don't perform functionality in this script, but you can see in the comment at
the end of the script just where, but would be simple to use for quick checks of validity.

In addition to the functions you just used, you can use the more generic function checkdnnr(),
which takes a hostname and simply returns true if any record of it appears in the DNS. The
output of this function would not give you anything to directly display to the user, as with the
getmxr() function used in the script, but would be simple to use for quick checks of validity.

# Backing Up or Mirroring a File

File Transfer, or FTP, is used to transfer files between hosts on a network. Using PHP,
y can use fopen() and the various functions with FTP as you can with HTTP connect-
s, to transfer files to and from an FTP server. However, a set of FTP-specific
functions also comes with the standard PHP install.

These functions are not built into the standard install by default. To use them under Unix,
ner run the PHP configure program with the --enable-ftp option and then rerun make.
If you are using the Windows install, FTP functions are enabled automatically.

For more details on configuring PHP, see Appendix A, “Installing Apache, PHP, and MySQL.”
