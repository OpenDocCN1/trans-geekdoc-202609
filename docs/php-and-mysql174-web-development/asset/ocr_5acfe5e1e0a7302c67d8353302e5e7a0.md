The ftp_mirror.php script is quite generic. You can see that it begins by setting up some variables:
$host = 'apache.cs.utah.edu';
$user = 'anonymous';
$password = 'me@example.com';
$remotefile = '/apache.org/http/httpd-2.4.16.tar.gz';
$localfile = '/path/to/files/httpd-2.4.16.tar.gz';

The $host variable should contain the name of the FTP server you want to connect to, and the $user and $password correspond to the username and password you would like to log in.

Many FTP sites support what is called anonymous login—that is, a freely available username that anybody can use to connect. No password is required, but it is common courtesy to supply your email address as a password so that the system's administrators can see where their users are coming from. We followed this convention here.
