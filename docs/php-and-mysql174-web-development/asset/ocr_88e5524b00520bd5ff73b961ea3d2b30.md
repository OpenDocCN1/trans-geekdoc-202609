# Constructors

Most classes have a special type of operation called a `constructor`. A constructor is called when an object is created, and it also normally performs useful initialization tasks as setting attributes to sensible values or creating other objects needed by this object.

# Destructors

The opposite of a constructor is a `destructor`. They allow you to have some functionality that will be executed before a class is destroyed, which will occur automatically when all references to a class have been unset or out of scope.

Similar to the way constructors are named, the destructor for a class must be named `__destruct()`. Destructors cannot take parameters.

# Instantiating Classes

After you have declared a class, you need to create an object—a particular individual that is a member of the class—to work with. This is also known as `creating an instance of or instantiating a class`. You create an object by using the `new` keyword. When you do, you need to specify what your object will be an instance of and provide any parameters required by the constructor.
