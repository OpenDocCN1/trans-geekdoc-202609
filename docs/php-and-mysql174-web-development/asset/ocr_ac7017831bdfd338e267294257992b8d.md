To ensure that you are not vulnerable, this script uses the `is_uploaded_file()` and `move_uploaded_file()` functions to make sure that the file you are processing has been uploaded and is not a local file such as `/etc/passwd`.

Please note that unless you upload handling script carefully, a malicious visitor could provide his or her temporary filename and convince your script to handle that file as though it were the uploaded file. Because many file upload scripts echo the uploaded data back to the user or store it somewhere that it can be loaded, this could lead to people being able to access any file that the web server can read. This could include sensitive files as `/etc/passwd` and PHP source code including your database passwords.
