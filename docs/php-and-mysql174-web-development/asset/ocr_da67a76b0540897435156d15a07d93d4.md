# Checking and Filtering Input Data

We begin the script by stripping any whitespace that the user might have inadvertently entered at the beginning or end of his search term. You can do this by applying the function trim() to the value of $\_POST['\'searchterm\'] when giving it a shorter name:

```
$searchterm = trim($_POST['\'searchterm\']);
```

The next step is to verify that the user has entered a search term and selected a search type after trimming whitespace from the ends of $_searchterm. Note that if you arrange these lines in the opposite order, you could encounter situations in which a user's search term is not empty and therefore not create an error message; instead, it is all whitespace, so it is deleted by trim()

```
if (!$searchtype || !$searchterm) {
echo '<p>You have not entered search details.<br/>
Please go back and try again.</p>';
exit;
}
```

We then check the $searchterm variable to make sure it contains a valid value, even though it's coming from an HTML <select> element:

```
switch ($searchtype) {
case 'Title':
case 'Author':
case 'ISBN':
break;
default:
echo '<p>That is not a valid search type. <br/>
Please go back and try again.</p>';
}
```

You might ask why you should bother checking data that is filled in. It's important to remember that there might be more than one interface to your database. For example, Amazon has many affiliates who use its search interface. Also, it's sensible to screen data in any case of security problems that arise because of users coming from different points of entry.

When you plan to use any data input by a user, you need to filter it appropriately for any controls (As you might remember we discussed in this Chapter 4, "String Manipulation and Regular Expressions"). You need to validate when submitting any user input to a database as MySQL.

In this case we do two things. First, we whitelist the search type, as shown above. In order to protect against problematic input in the search term field, we use a MySQL construct known as a prepared statement. We'll talk about this in a moment.
