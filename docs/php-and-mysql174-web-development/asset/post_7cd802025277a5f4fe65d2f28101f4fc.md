# Testing Variable Status

PHP has several functions for testing the status of a variable. The first is isset(), which has the following prototype:

```php
bool isset(mixed $var, mixed $var[])
```

This function takes a variable name as an argument and returns true if it exists and false otherwise. You can also pass in a comma-separated list of variables, and isset() will return true if all the variables are set.

You can wipe a variable out of existence by using its companion function, unset(), which has the following prototype:

```php
void unset(mixed $var, mixed $var[])
```

This function gets rid of the variable if it is passed.

The empty() function checks whether a variable exists and has a nonzero value; it returns true or false accordingly. It has the following prototype:

```php
bool empty(mixed $var)
```

Let's look at an example using this code to test:

```php
if (isset($tireqty)) {
    echo 'tireqty is set.<br />';
}
if (!isset($tireqty)) {
    echo 'tireqty is not set.<br />';
}

if (empty($tireqty)) {
    echo 'tireqty is empty.<br />';
}
if (!empty($tireqty)) {
    echo 'tireqty is not empty.<br />';
}
```

Refresh the page to see the results. The variable $tireqty should return true from isset() regardless of what value you entered in that field. Whether empty() depends on what you entered at all. The variable $tireqty does not exist, so it generates a blank (false) result from isset() and a (true) result from empty(). These functions are handy when you need to make sure the user filled out the appropriate fields.

# Interpreting Variables

You can achieve the equivalent of casting a variable by calling a function. The following three functions can be for this task:

- intval(mixed $var, int $base=10)
- floatval(mixed $var)
- strval(mixed $var)

Each accepts an input and returns the variable's value converted to the appropriate type. intval() allows you to specify the base when converting strings to integers.

# Making Decisions with Conditionals

Control structures are structures within a language that allow you to control the flow of execution through a program or script. You can group them into conditional (branching) and repetition structures (loops). The constructs that tell your program to make decisions are called conditionals.

# if Statements

You can use if statement to make a decision. You should give if statement a condition to use. If the condition is true, the following block of code will be executed. Conditions in if must be surrounded by parentheses ().

For example, if a visitor orders no items, no bottles of oil, and no plugs, it is probably because she accidentally clicked Submit button before she had filling out the form. Rather than telling the visitor "Processed," the page could give her a more useful message. When the visitor orders no items, you might like to say, "You did not order anything on the previous page!" You can do this easily by using the following statement:

```php
if($totalqty == 0) {
    echo 'You did not order anything on the previous page!<br />';
}
```

The condition you are using here is $totalqty == 0. Remember that equals operator (==) behaves differently from the assignment operator (=). The condition $totalqty == 0 will be true if $totalqty is equal to zero. If $totalqty is not equal to zero, the condition will be false. When the condition is true, the statement will be executed.

# Code Blocks

Often you have more than one statement you want executed according to the actions of a conditional statement such as if. You can group of statements together as a block. To declare a block, you enclose it in braces:

```php
if ($totalqty == 0) {
    echo '<p style="color:red">';
    echo 'You did not order anything on the previous page!';
    echo '</p>';
}
```

The three lines enclosed in curly braces are now a block of code. When the condition is true, all three lines are executed. When the condition is false, all three lines are ignored.

> Note As mentioned, PHP does not know how you lay out your code. However, you should indent your code for readability purposes. Indenting is useful to enable you to see at a glance which lines will be executed only if conditions are met, which statements are grouped into blocks, and which statements are parts of loops or functions. In the previous examples, you can see that the statement depending on the if statement and the statements making up the block are indented.

# else Statements

An else statement allows you to define an alternative action to be taken when the condition in an if statement is false. Say you want to show customers when they do not order anything. On the other hand, if they make an order, instead of a warning, you want to show them what they ordered. If you rearrange the code and add else statement, you can display a warning or a summary:

```php
if ($totalqty == 0) {
    echo 'You did not order anything on the previous page!<br />';
} else {
    echo htmlspecialchars($tireqty).' tires<br />';
    echo htmlspecialchars($oilqty).' bottles of oil<br />';
    echo htmlspecialchars($sparkqty).' spark plugs<br />';
}
```

# Making Decisions with Conditionals

You can build complicated logical processes by nesting if statements within each other. In the following code, the summary will be displayed only if the condition $totalqty == 0 is true, and each line in the summary will be displayed only if its condition is met:

```php
if ($totalqty == 0) {
    echo "You did not order anything on the previous page!<br />";
} else {
    if ($tireqty > 0) {
        echo htmlspecialchars($tireqty).'. tires<br />';
    }
    if ($oilqty > 0) {
        echo htmlspecialchars($oilqty).'. bottles of oil<br />';
    }
    if ($sparkqty > 0) {
        echo htmlspecialchars($sparkqty).'. spark plugs<br />';
    }
}
```

# elseif Statements
