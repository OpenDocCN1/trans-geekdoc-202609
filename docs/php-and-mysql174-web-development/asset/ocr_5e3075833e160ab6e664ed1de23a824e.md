# Installing Apache, PHP, and MySQL Under UNIX

The third flag tells the location of apxs2 (the Apache Extension tool), which is used to build Apache modules, of which PHP will be one. The need to configure the location of apxs2 within the PHP build process is so that the appropriate Apache module version of PHP can be built, resulting in the need to pre-configure and install at least a basic version of Apache before building.

The next set of configuration flags point the PHP configuration tool to the location of the libraries installed previously (JPEG, PNG, zip, and IMAP). The --with-kerberos and --with-imap-flags are additional flags related to the IMAP library; depending on the precompiled package you use on your system, you may not need these flags or you may need additional flags. The configuration process will tell you which flags are missing.
