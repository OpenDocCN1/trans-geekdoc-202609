Each call to $stmt->fetch() (or, in the procedural version, mysqli_stmt_fetch()) retrieves the next row from the result set and populates the four bind variables with the values from that row, and we can display them.

There are other approaches to fetching data from a query result other than using mysqli_stmt_fetch(). To use these, we must first extract a result resource from the statement. You can do this using the mysqli_stmt_get_result() function, as follows:

```php
$result = $stmt->get_result();
```

This function returns an instance of the mysqli_result object, which itself has a number of useful functions for extracting the data. Probably the most useful:

- mysqli_fetch_array() (and related mysqli_fetch_assoc()), which returns the next row from the result set as an array. The mysqli_fetch_assoc() version uses the column names as keys, although you can also get this behavior from mysqli_fetch_array(). The mysqli_fetch_array() function takes a second parameter for the type of array to return. Passing MYSQL_ASSOC will get you the column names as keys, passing MYSQL_NUM will result in numbered keys, and MYSQL_BOTH will give you an array containing two sets of the data, one with column names as keys and one with numerical keys.
- mysqli_fetch_all() returns all of the rows returned by the query as an array of arrays where each of the inner arrays is one of the rows returned.
- mysqli_fetch_object() returns the next row from the result set as an object, where each value is stored in an attribute the name of the column.

# Disconnecting from the Database

You can free your result set by calling each

```php
$result->free();
```

or

```php
mysqli_free_result($result);
```

You can then use

```php
$db->close();
```

or

```php
mysqli_close($db);
```

to close a database connection. Using this command isn't strictly necessary because the connection will be closed when script execution finishes anyway.

# Listing 11.4 insert_book.php—This Writes Books into the Database

```php
<!DOCTYPE html>
<html>
<head>
<title>Book-O-Rama Entry Results</title>
</head>
<body>
<h1>Book-O-Rama Entry Results</h1>
<?php

if (!isset($_POST['ISBN']) || !isset($_POST['Author']) ||
    !isset($_POST['Title']) || !isset($_POST['Price'])) {
    echo "<p>You have not entered all the required details.<br />Please go back and try again.</p>";
    exit;
}

// create variable names
$isbn=$_POST['ISBN'];
$author=$_POST['Author'];
$title=$_POST['Title'];
$price=$_POST['Price'];
$price = floatval($price);

$db = new mysqli('localhost', 'bookoram', 'books');

if ($db->connect_error) {
    echo "<p>Error: Could not connect to database.<br />Try again later.</p>";
    exit;
}

$query = "INSERT INTO Books VALUES (?, ?, ?, ?)";
$stmt = $db->prepare($query);
$stmt->bind_param("ssd", $isbn, $author, $title, $price);
$stmt->execute();

if ($stmt->affected_rows > 0) {
    echo "<p>Book inserted into the database.</p>";
} else {
    echo "<p>An error occurred.<br />The item was not added.</p>";
}

$db->close();
?>
</body>
</html>
```

If you look at the code for insert_book.php, you can see that much of it is similar to the script you wrote to retrieve data from the database. First, we check that all the form fields were filled in and then, because the price is stored in the database as a float, we make sure it is:

```php
$price = floatval($price);
```

This also takes care of currency symbols that the user might have typed into the form. Again, we connect to the database by instantiating the mysqli object and setting up a query to send to the database. In this case, the query is an SQL INSERT:

```php
$query = "INSERT INTO Books VALUES (?, ?, ?, ?)";
$stmt = $db->prepare($query);
$stmt->bind_param("sssd", $isbn, $author, $title, $price);
$stmt->execute();
```

In this case, we're passing four parameters into our prepared statement, where s represents one of the strings, and d represents a double.

# Using Other PHP-Database Interfaces

PHP supports libraries for connecting to a large number of databases, including Oracle, Microsoft SQL Server, and PostgreSQL.

In general, the principles of connecting and querying of these databases are much the same. The internal function names vary, and different databases have slightly different functionality, if you can connect to MySQL, you should be able to adapt your knowledge to any of the others.

If you want to use a database that doesn't have a specific library available in PHP, you can use the generic ODBC functions. ODBC, which stands for Open Database Connectivity, is standard for connections to databases. It has the most limited functionality of any of the function sets, for fairly obvious reasons. If you need to be compatible with everything, you can't exploit the special features of anything.

In addition to the libraries that come with PHP, the data access extension called PDO allows you to use the same interface for many different databases.
