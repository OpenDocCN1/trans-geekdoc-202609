# Outputting the Final Graphic

You can output an image either directly to the browser or to a file.

In this example, you output the image to the browser. This is a two-stage process. First, you need to tell the web browser that you are outputting an image rather than text or HTML. You do this by using the header() function to set the MIME type of the image:

```
header('Content-type: image/png');
```

Normally, when you retrieve a file in your browser, the MIME type is the first thing the web servers sends. For an HTML or PHP page (post execution), the first thing it is

```
Content-Type: text/html
```

This tells the browser how to interpret the data that follows.
 this case, you tell the browser that you are sending an image instead of the usual HTML output. You can do this by using the header() function, which sends HTTP header strings. An important point to note is that the header() function it cannot be executed if PHP sends an HTTP header automatically as soon as anything is output to the browser. However, if you have any echo statements, or any whitespace before your opening PHP tag, HTTP headers will be sent and you will get a warning message from PHP when you try to call header(). However, you can send multiple HTTP headers with multiple calls to the header() function in the same script, although they must all appear before any output is sent to the browser.

After you sent the header data, you output the image data with a call to

```
imagepng($im);
```

This call sends the output to the browser in PNG format. If you wanted to sent it in a different format, you could call imagejpeg($im)—JPEG support is enabled. You would also need to send the corresponding header first, as shown here:

```
header('Content-type: image/jpeg');
```

The second option you can use, as an alternative to all the previous ones, is to write the image to a file instead of the browser. You can do this by adding the following second parameter to imagepng($im, $filename) (or a similar function for the other supported formats):

```
imagepng($im, $filename);
```

Remember that all the usual rules about writing to a file from PHP apply (for example, having permissions set up correctly).

# Cleaning Up

When you're done with an image, you should return the resources you have been using to the server by destroying your identifier. You can do this with a call to imagedestroy():

```
imagedestroy($im);
```
