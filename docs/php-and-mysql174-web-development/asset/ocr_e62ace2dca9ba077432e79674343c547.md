Also note that we specified a NULL value for the CustomerID column when adding the other customers. You might recall that when Smith and Ingrid joined when you set up the database, you created CustomerID as the primary key for the Customers table, so this might seem strange. However, you specified the field as AUTO_INCREMENT. This means that, if you insert a row with a NULL value or no value in this field, MySQL will generate the next number in the auto increment sequence and insert it automatically. This behavior is pretty useful.

You can also insert multiple rows at at once. Each row should be in its own set of parentheses, and each set of parentheses should be separated by a comma.

Only a few other variants are possible with INSERT. After the word insert, you can add LOW_PRIORITY, DELAYED, or HIGH_PRIORITY. The LOW_PRIORITY keyword means the system may wait until insert is not being read from the data. The DELAYED keyword means that your insert will be buffered. If the server is busy, you can continue running queries rather than waiting for this INSERT operation to complete. The HIGH_PRIORITY keyword only takes effect if you started mysql with the --low-priority-updates option. It effectively cancels that for the current query. If this option is not set, it has no effect.

Immediately after this, you can optionally specify IGNORE. If you try to insert any rows that would cause a duplicate key, they will be ignored. Another alternative is to specify ON DUPLICATE KEY UPDATE expression at the end of the INSERT statement. can be used to change the duplicate value using a normal UPDATE statement (covered in later chapter).
