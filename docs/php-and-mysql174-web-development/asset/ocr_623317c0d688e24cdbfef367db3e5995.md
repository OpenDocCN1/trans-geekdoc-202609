# Creating a Canvas Image

To begin building or changing an image in PHP, you need to create an image identifier. There are two basic ways to do this. One is to create a blank canvas, which you can do with a call to the imagecreatetruecolor() function, and do so in this script with the following:

```
$im = imagecreatruecolor($width, $height);
```
