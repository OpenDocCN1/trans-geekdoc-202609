## Logging In

If users type their details into the form at login.php (see Figure 27.3) and submit it, they will be taken to the script called member.php. This script logs them in if they have this form. It also displays any relevant bookmarks to users who are logged in. It is the center of the rest of the application. This script is shown in Listing 27.11.

Let's look at the login() and check_valid_user() functions a little more closely. The login() function is shown in Listing 27.12.

## Listing 27.12 login() Function from user_auth_fns.php—This Function Checks a User's Details Against the Database

```
function login($username, $password) {
  // check username and password with db
  // if yes, return true
  // else throw exception

  // connect to db
  $conn = db_connect();

  // check if username is unique
  $result = $conn->query("select * from user
where username='$username.'
and password = sha1('.$password.')");
```

```
if (!$result) {
    throw new Exception('Could not log in.');
}

if ($result->num_rows>0) {
    return true;
} else {
    throw new Exception('Could not log in.');
}
```

As you can see, the login() function connects to the database and checks that there is a user with the username and password supplied. It returns true if there is or throws an exception if it is not or the user's credentials could not be checked. The check_valid_user() function does not connect to the database, but instead checks that the user has a registered session—that is, the user has already logged in. This function is shown in Listing 27.13.

## Listing 27.13 check_valid_user() Function from user_auth_fns.php—Function Checks That the User Has a Valid Session

```
function check_valid_user() {
    // see if somebody is logged in and notify them if
    if (isset($_SESSION['valid_user'])) {
        echo "Logged in as ".\$_SESSION['valid_user'].".<br>";
    } else {
        // they are not logged in
        do_html_heading('Problem:');
        echo 'You are not logged in.<br>';
        do_html_url('login.php', 'Login');
        do_html_footer();
        exit;
    }
}
```
