Listing 27.19 get_random_word() Function from user_auth_fns.php—This Function Gets a Random Word from Dictionary

```php
function get_random_word($min_length, $max_length) {
    // generate a random word
    $word = '';
    // return it
    // return a random word
    // in dictionary
    $dictionary = '/usr/dict/words';
    $fp = @fopen($dictionary, 'r');
    if (!$fp) {
        return false;
    }
    $size = filesize($dictionary);

    // pick a random location
    $rand_location = rand(0, $size);
    fseek($fp, $rand_location);

    // read from the file
    $word = fgets($fp); 
    while ((strlen($word) < $min_length) || (strlen($word) > $max_length) || strstr($word, "'"))) {
        if (feof($fp)) { // at end, go to start
            fseek($fp, 0);
        }
        $word = fgets($fp); // skip the line
    }

    $word = trim($word); // trim the \n
    return $word;
}
```

To work, the get_random_word() function needs a dictionary. The spell checker comes with a dictionary of words, typically located at /usr/dict/words. If you don't find it in one of these places, don't worry! You can find word lists as wordlist.sourceforge.net/. Just change the location of your word list in the get_random_word() function.

This site also dictionaries in many languages, so if you would like a random Norwegian or Esperant word, you can download one of these dictionaries. These files are formatted with each word on a separate line, separated by newlines.

To get a random word from this file, you pick a random location between 0 and the filesize, and read from the file. y will likely get only a partial word, so you skip the line you open to find and take the next word as your word

The function has two clear best. The first is if you reach the end of the file while looking for a word, you go back to the beginning:

```php
if (feof($fp)) { // at end, go to start
    fseek($fp, 0);
}
```

The second is that you can seek for a word of a particular length: You each word that you pull from the dictionary, and if it is not between $min length and $max length, you keep searching. At the same time, you also draw words with apostrophes (single quotation marks) in them. You could escape them out using the word, but just getting the next word is easier.
