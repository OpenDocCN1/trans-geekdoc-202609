# Form Variables

Within your PHP script, you can access each form as a PHP variable whose name relates to the name of the form. You can recognize variable names in PHP because they start with a dollar sign ($). (Forgetting the dollar sign is a common programming error.)

Depending on your PHP version and setup, you can access the data variables in different ways. In recent versions of PHP, but all of these ways have been deprecated, so be careful if you use PHP in the post that has changed.

You may access the contents of the form tireqty in the following way:

```
$_POST['tireqty']
```

$_POST is an array containing data submitted via an HTTP POST request—that is, the form was set to POST. There are three of these may contain form data: `$_POST`, `$_GET`, and `$_REQUEST`. One of the `$_GET` or `$_POST` arrays holds the details of all the form variables. Which array is used depends on whether the method used to submit the form was GET. In addition, a combination of all data via GET or POST is also available through `$_REQUEST`.

If the form was submitted via the POST method, the data entered into the tireqty box will be stored in `$_POST['tireqty']`. If the form was submitted via GET, the data will be in `$_GET['tireqty']`. In either case, the data will also be available in `$_REQUEST['tireqty']`.

These are some of the superglobal. We will revisit the superglobals when we discuss variable scope in the next chapter.

Let’s look at an example that creates easy-to-use copies of variables.

To copy one value into another, use the assignment operator, which in PHP is an equal sign (==). The following statement creates a new variable $tireqty and copies the contents of `$_POST['tireqty']` into the new variable:

```
$tireqty = $_POST['tireqty'];
```
