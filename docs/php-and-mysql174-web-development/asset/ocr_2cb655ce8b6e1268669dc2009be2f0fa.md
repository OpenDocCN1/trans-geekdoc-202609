You have already seen that reset() returns the pointer to the first element of the array.
Similarly, end($array_name) sends the pointer to the end of the array. The first and
 elements in the array are returned by reset() and end(), respectively.

To move through an array in reverse order, you could use end() and prev(). The prev()
function is the opposite of next(). It moves the current pointer back once and returns the
new element.

For example, the following code displays an array in reverse order:

```
$value = end($array);
while ($value) {
echo "$value<br />";
$value = prev($array);
}
```

For example, you can declare $array like this:

```
$array = array(1, 2, 3);
```

In this case, the output would appear in a browser as:

```
3
2
1
```

Using end(), current(), reset(), end(), next(), pos(), and prev(), you can write your
own code to navigate through an array in any order.

# Applying Any Function to Each Element
in an Array: array_walk ()

Sometimes you want to work with or modify every element in an array in the same
way. The function array_walk() allows you to do this. The prototype of array_walk() is as
fallows:

```
array_walk($array, callable func(, mixed $userdata)
```

Similar to the way we used usort earlier, array_walk() expects you to define a function
of yours. As you can, array_walk() takes three parameters. The first, $arr, is the array to
be processed. The second, $func, is the name of the user-defined function that will be applied
to each element in the array. The third parameter, $userdata, is optional. If you use it, it will
passed through your function as a parameter. We'll see how this works shortly.

A handy user-defined function might help display each element with some specified
formatting. The following code displays each element on a new line by calling the user-defined
function $my_print() with each element of $array:

```
function my_print($value) {
echo "$value<br />";
}

array_walk($array, 'my_print');
```
