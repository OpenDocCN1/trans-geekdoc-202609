# Opening a File

Table 2.1 Summary of File Modes for `fopen()`

| Mode | Mode Name | Meaning |
|---|---|---|
| r | | Open the file for reading, beginning from the start of the file. |
| r+ | Read | Open the file for reading and writing, beginning from the start of the file. |
| w | Write | Open the file for writing, beginning from the start of the file. If the file already exists, delete the existing contents. If it does not exist, try to create it. |
| w+ | Write | Open the file for writing and reading, beginning from the start of the file. If the file already exists, delete the existing contents. If it does not exist, try to create it. |
| x | Cautious write | Open the file for writing, beginning from the start of the file. If the file already exists, it will not be opened, `fopen()` will return false, and PHP will generate a warning. |
| x+ | Cautious write | Open the file for writing and reading, beginning from the start of the file. If the file already exists, it will not be opened, `fopen()` will return false, and PHP will generate a warning. |
| a | Append | Open the file for (appending) only, beginning from the end of the existing contents, any. If it does not exist, try to create it. |
| a+ | Append | Open the file for (appending) and reading, beginning from the end of the existing contents, any. If it does not exist, try to create it. |
| b | Binary | Used in conjunction with one of the other modes. You might want to use this mode if your system differentiates between binary and text files. Windows systems differentiate: Unix systems do not. The PHP developers recommend always use this option for maximum portability. |
| t | Text | Used in conjunction with one of the other modes. This is an option only in Windows systems. it is not recommended except before you have your code to work with the `b` option.|

The right file mode to depends how the system will be used. We used `'w'` in this example which allows only one order to be stored in the file. Each time a new order is taken, it overwrites the previous order. This usage is probably not very sensible, you would be better off appending your order (and binary mode, as recommended):

```
$fp = fopen("document_root/../orders.txt", 'ab');
```

The third parameter of `fopen()` is optional. If you want to search the `include_path` (set in your PHP configuration; see Appendix A, "Installing Apache, PHP, and MySQL") for a file. To do this, set the parameter to `true`. If you tell PHP to search the `include_path`, you do not need to provide a directory name or path:

```
$fp = fopen('orders.txt', 'ab', true);
```
