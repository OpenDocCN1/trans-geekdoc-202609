# Using the return Keyword

The keyword return stops the execution of a function. When a function ends either all statements have been executed or the keyword return returns to the statement after the function call.

If you call the following function, the first echo statement will be executed:

```
function test_return() {
    echo "This statement will be executed";
    return;
    echo "This statement will never be executed";
}
```

Obviously, this is not a very useful use to use return. Normally, you want to return from the middle of a function only in response to a condition being met.

An error is a common reason to use a return to stop execution of a function before the end. For instance, if you write a function to find out which two numbers is greater, you might want to exit any of the numbers is:

```
function larger($x, $y) {
    if (!isset($x)) || (!isset($y))) {
        echo "This function requires two numbers.";
        return;
    }
    if ($x->=$y) {
        echo $x.\<br/>";
    } else {
        echo $y.\<br/>";
    }
}
```

The built-in error isset tells you whether a variable has been created and given a value. This code gives an error message and returns if either of the parameters has not been set with a value. You test it by isset(), meaning "NOT isset", so if the statement can be read as "if x is not set or if y is not set" the function returns if either of these conditions is true.

If the return statement is executed, the subsequent lines of code in the function will be ignored. Program execution returns to the point at which the function was called. If both parameters are set, the function will echo the larger of the two.
