# # Getting Information About the PHP Environment

A number of functions can be used to find out about how PHP is configured, which can be very useful when tracking configuration issues or to verify that a required configuration or extension is included in your PHP installation.

# ## Finding Out Extensions Are Loaded

You can easily see what function sets are available and what functions are available in each of those by using get_loaded_extensions() and get_extension_funcs() functions.

The get_loaded_extensions() function returns an array of all the function sets currently available to PHP. Given the name of a particular function or extension, get_extension_funcs() returns an array of the functions in that set.

The script in 24.1 lists all the extension functions available to your PHP installation by using these two functions (also refer Figure 24.1).

+   Listing 24.1 list_functions.php—Lists the Extensions Available to PHP and the Functions for Each Extension

```
<?php
echo 'Function sets supported in this install: <br />';
$extensions = get_loaded_extensions();
foreach ($extensions as $each_ext) {

echo $each_ext.'<br />';
echo '<ul>';
$ext_funcs = get_extension_funcs($each_ext);
foreach($ext_funcs as $func) {

echo '<li>'.$func.'</li>';
}
echo '</ul>';
}
?>
```
