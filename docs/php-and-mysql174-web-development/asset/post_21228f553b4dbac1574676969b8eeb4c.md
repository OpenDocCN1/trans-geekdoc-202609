
In the following sections, we discuss PHP's advanced OO features.

## Using Per-Class Constants

PHP

```php
<?php
class Math
{
    const pi = 3.14159;
}
echo "Math::pi = " ..Math::pi;
?>
```

You can access the per-class constant using the :: operator to specify the class constant belongs to, as done in this example.

## Implementing Static Methods

PHP allows the use of static keyword. It is applied to methods to allow them to be called without instantiating the class. This is the method equivalent of the per-class constant idea. For example, consider the Math class created in the preceding section. You could add a squared() function to and invoke it without instantiating the class as follows:

```php
<?php
class Math
{
    static function squared($input)
    {
        return $input*$input;
    }
}
echo Math::squared(8);
?>
```

Note that you cannot use the $this keyword inside a static method because there may be no object instance to refer to.

## Checking Class Type and Type Hinting

The instanceof keyword allows you to check the type of an object. You can check whether an object is an instance of a particular class, whether it inherits from a class, or whether it

```php
($b instanceof B) would be true.
($b instanceof A) would be true.
($b instanceof Displayable) would be false.
```

All these examples assume A, B, and `Displayable` are in the current scope; otherwise, an error will be triggered.

Additionally, you can use class type hinting. Normally, when you pass a parameter to a function in PHP, you do not pass the type of parameter. With type hinting, you can specify the type of class that ought be passed, and if that is not the type actually passed in, an error will be triggered. The type checking is equivalent to `instanceof`. For example, consider the following function:

```php
function check_hint(B $someclass) {
    //...
}
```

This example shows that `$someclass` needs to be an instance of class B. If you then pass in an instance of class A as

```php
check_hint($a);
```

you will get the following fatal:

**Fatal error:** Argument 1 must be an instance of B

Note that if you had hinted A and passed in an instance of class A and B, no error would have occurred because B inherits from A.

You can also use type hinting for interfaces, arrays, and callable, meaning the passed item must be a function. Although this works for interfaces, note that it does not work for traits.

## Late Static Bindings

In an inheritance hierarchy with multiple implementations of the same function, we can use late static bindings to specify which class's method to use.

Consider the following simple example (based on one in the PHP manual):

```php
<?php
class A {
    public static function whichclass() {
        echo __CLASS__;
    }
}
```

```php
public static function test() {
    self::whichclass();
}
```

```php
class B extends A {
    public static function whichclass() {
        echo __CLASS__;
    }
}
```

```php
A::test();
B::test();
```

What would you expect the output to be B? You might be surprised that the code outputs A, twice. This is because, A overrides the whichclass() method, when the test() method is called by B, it is executed in the context of the parent class, A. How can we get the test() to use B's implementation of whichclass(), that is, to use the implementation inside the class we are actually using?

The answer is late static bindings. In the previous example, if we change this line of code:
`self::whichclass();`

to
`static::whichclass();`

the code will not output A and then B. The static modifier makes PHP use the class that was actually created at runtime, the "late" part of the name.

## Cloning Objects

The clone keyword, which allows you to copy an existing object, can also be used in PHP. For example,
`$c = clone $b;`

creates a copy of $b of the same class, with the same attribute values.

You can also change this behavior. If you need default behavior from clone, you need to create a method in the base class `__clone()`. This method is similar to a constructor or destructor in that you do not call it. It is invoked when the clone keyword is used as shown here. Within the `__clone()` method, you can define exactly the copying behavior you want.

The nice thing about `__clone()` is that it will be called after an exact copy has been made using the default behavior, so at that stage you are able to change only the things you want to change.

The most common functionality to add `__clone()` is code to ensure that attributes of the class that are handled as references are copied correctly. If you set out to clone a class that contains an object, you are probably expecting a second copy of that object rather than a second reference to the same one, so it would make sense to add this to `__clone()`.

You may choose to change nothing but perform some other action, such as updating an underlying database record relating to the class.

## Using Abstract Classes

PHP offers abstract classes, which cannot be instantiated, as well as abstract methods, provide the signature for a method but no implementation. For instance,

```php
abstract class A {
    abstract function operationX($param1, $param2);
}
```

Any class that contains abstract methods must itself be abstract. The main use of abstract methods and classes is in class hierarchy where you want to make sure subclass contains; this can also be done with an interface.

```php
abstract operationX($param1, $param2);
```

## Overloading Methods with __call()

We previously looked at a number of class methods with special meanings whose names begin with double underscore (_), such as __get(), __set(), __construct(), and __destruct(). Another example is __call(), which is used in PHP to implement method overloading.

Method overloading is common in many object-oriented languages but not as useful in PHP because you need to use flexible types and (easy-to-implement) optional function. To use it, you implement a __call() method, as in this example:

```php
public function __call($method, $p) {
    if ($method == "display") {
        if (is_object($p[0])) {
            $this->displayObject($p[0]);
        } else if (is_array($p[0])) {
            $this->displayArray($p[0]);
        } else {
            $this->displayScalar($p[0]);
        }
    }
}
```

`__call()` method should take two parameters. The first contains the name of the method being invoked, and the second contains an array of the parameters passed to that method. You can then decide for yourself which method to call. In this case, if an object is passed to display(), you call the underlying displayObject() method; if an array is passed, you call displayArray(); if something else is passed, you call displayScalar().

To invoke this code, you would first instantiate the class containing __call() method (name it overload) and then invoke the display() method, as in this example:

```php
$ov = new overload();
$ov->display(array(1, 2, 3));
$ov->display('cat');
```

The first call to display() invokes displayArray(), and the second invokes displayScalar(). Note that you do not need an underlying implementation of the display() method to work.

PHP 5.3 introduced a simple magic method named __callStatic(). It works similarly to __call() except that it will be invoked when an inaccessible method is invoked via a static context, for example,
`overload::display();`

## Using __autoload()

Another of the special functions in PHP is __autoload(). It is not a class method but a stand-function; so, you declare it outside any class declaration. If you implement it, it will be automatically called when you attempt to instantiate a class that has not been declared.

The main use of __autoload() is to try to include require any files needed to instantiate the required class. Consider this example:

```php
function __autoload($name)
{
  include_once $name.".php";
}
```
