multidimensional array into reverse order. Because you provide the comparison function, you can write a comparison function that returns the opposite values. To sort into reverse order, the function needs to return 1 if $sx is less than $sy and -1 if $sx is greater than $sy. For example,

```
function reverse_compare($sx, $sy) {
    if ($sx[2] == $sy[2]) {
        return 0;
    } else if ($sx[2] < $sy[2]) {
        return 1;
    } else {
        return -1;
    }
}
```

Calling usort($products, 'reverse_compare') would now result in the array being placed in descending order by price.

# Reordering Arrays

For some applications, you might want to manipulate the order of the array in other ways than a sort. The function shuffle() randomly reorders the elements of your array. The function array_reverse gives you a copy of your array with all the elements in reverse order.

# Using shuffle()

Bob wants to feature a small number of his products on the front page of his site. He has a large number of products but would like randomly selected items shown on the front page. So that repeat visitors do not get bored, he would like the three chosen products to be different for each visit. He can easily accomplish this if all products are in an array. Listing 3.1 displays three randomly chosen pictures by shuffling the array into a random order and displaying the first.

Listing 3.1 bobs_front_page.php—Using PHP to Produce a Dynamic Front Page for Bob's Auto Parts

```
<?php
$pictures = array('brakes.png', 'headlight.png',
    'spark.plug.png', 'steering_wheel.png',
    'tire.png', 'wiper_blade.png');

shuffle($pictures);
?>
<!DOCTYPE html>
<html>
<head>
<title>Bob's Auto Parts</title>
```
