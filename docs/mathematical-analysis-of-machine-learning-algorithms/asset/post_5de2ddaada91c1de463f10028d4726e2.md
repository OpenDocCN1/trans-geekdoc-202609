
Moreover,

$$\ln N_{\infty}(\epsilon, \mathcal{G}, n) \le d \ln \max[2, en/(d\epsilon)].$$

**Proof.** Let \(U\) be a random variable distributed uniformly over \([0,1]\). Then for all \(a \in (0,1)\): \(\mathbb{E}_U \mathbf{1}(U \le a)=a\). Thus for all \(\phi, \phi' \in \mathcal{G}\),

$$\mathbb{E}_{\mathcal{D}}|\phi(Z)-\phi'(Z)|^p = \mathbb{E}_{\mathcal{D}}|\mathbb{E}_U[\mathbf{1}(U \le \phi(Z))-\mathbf{1}(U \le \phi'(Z))]|^p \le \mathbb{E}_{\mathcal{D}}\mathbb{E}_U|\mathbf{1}(U \le \phi(Z))-\mathbf{1}(U \le \phi'(Z))|^p.$$

The last inequality used Jensen's inequality. Therefore

$$\ln N(\epsilon, \mathcal{G}, L_p(\mathcal{D})) \le \ln N(\epsilon, \mathcal{G}_{\text{subgraph}}, L_p(\mathcal{D} \times U(0,1))).$$

This leads to the first desired bound.

The second bound can be proved by discretizing \(U\) into intervals with thresholds \(\min(1, \epsilon(2k + 1))\) for \(k = 0,1,\dots\) with no more than \(\lceil(2\epsilon)^{-1}\rceil \le 1/\epsilon\) thresholds. This gives an \(\epsilon\) cover of \(U\) in Euclidean distance. We can then approximate \(\mathbb{E}_U\) by average over the thresholds to get \(\epsilon L_\infty\) cover with the discretization. Let the set of thresholds be \(U'\). If \(\mathcal{D}\) contains \(n\) data points, then \(\mathcal{D} \times U'\) contains at most \(n|U'| \le n/\epsilon\) points, and one may apply Sauer's lemma to obtain a cover on these points. This implies the second bound.

## 5.5 Convex Hull Class

Convex hull of a function class is frequently encountered in applications, and is related to \(L_1\) regularization. We can define the convex hull of a function class as follows.

### Definition 5.12

The convex hull of a function class \(\mathcal{F}=\{f(\theta,x):\theta\in\Theta\}\) is defined as

$$\operatorname{CONV}(\mathcal{F}) = \left\{\sum_{j=1}^m w_j f(\theta_j,x): m>0, \|w\|_1=1, w_j \ge 0, \theta_j \in \Theta\right\}.$$

We also include the closure of the finite sum functions with respect to an appropriate topology in the convex hull.

Note that for any \(q=[q_1,\ldots,q_d]\in B_1\), let \(q^k\in Q\) so that \(\|q-q^k\|\leq\epsilon\), then

$$\left[\mathbb{E}_{Z\sim\mathcal{D}}\left\|\sum_{j=1}^{d}q_j^k f_j(Z)-\sum_{j=1}^{d}q_j f_j(Z)\right\|^p\right]^{1/p}\leq\epsilon A.$$

Therefore \(\left\{\sum_{j=1}^{d}q_j^k f_j:k=1,\ldots,N\right\}\) is an \(\epsilon A\) \(L_p\) cover of \(\operatorname{CONV}(\mathcal{F})\). The result follows.

The result is linear in the dimension \(d\). However, for high-dimensional problems, one would like to obtain a bound that is logarithmic in the dimensionality \(d\). The following result gives such a bound for \(L_2\) cover, but with a polynomial dependency on \(1/\epsilon\) instead of logarithmic dependency on \(1/\epsilon\).

### Theorem 5.14

Consider any class \(\mathcal{F}=\{f_1,\ldots,f_d\}\), and assume that for a distribution \(\mathcal{D}\), \(\sup_{f\in\mathcal{F}}\|f\|_{L_2(\mathcal{D})}\leq A\). Then

$$\ln N(\epsilon,\operatorname{CONV}(\mathcal{F}),L_2(\mathcal{D}))\leq \left\lceil A^2/\epsilon^2\right\rceil\ln\left[e+ed\epsilon^2/A^2\right].$$

**Proof.** For simplicity, we assume that \(A=1\). Given any \(f=\sum_j\alpha_j f_j\in\operatorname{CONV}(\mathcal{F})\), with \(\sum_j\alpha_j=1\) and \(\alpha_j\geq 0\), we can regard \(p_\alpha\) as a probability measure on \(\{1,\ldots,d\}\) with \(p_\alpha(j)=\alpha_j\) \((j=1,\ldots,d)\). Now, let \(j_1,\ldots,j_k\) be \(k\) iid samples from \(p_\alpha\), then \(f=\sum_j\alpha_jf_j=\mathbb{E}_{j_s}f_{j_s}\).

$$\begin{aligned}
\mathbb{E}_{j_1,\ldots,j_k}\left\|\frac{1}{k}\sum_{s=1}^{k}f_{j_s}-f\right\|_{L_2(\mathcal{D})}^{2}
&=\operatorname{Var}_{j_1,\ldots,j_k}\left(\left\|\frac{1}{k}\sum_{s=1}^{k}f_{j_s}\right\|_{L_2(\mathcal{D})}\right)\\
&=k^{-2}\sum_{s=1}^{k}\operatorname{Var}_{j_s}(\|f_{j_s}\|_{L_2(\mathcal{D})})\\
&\leq k^{-2}\sum_{s=1}^{k}\mathbb{E}_{j_s}(\|f_{j_s}\|_{L_2(\mathcal{D})}^{2})\leq 1/k.
\end{aligned}$$

It means that there exists \(j_1,\ldots,j_k\) such that

$$\left\|\frac{1}{k}\sum_{s=1}^{k}f_{j_s}-f\right\|_{L_2(\mathcal{D})}\leq 1/\sqrt{k}.$$

Now, consider

$$Q_k=\left\{\frac{1}{k}\sum_{j=1}^{d}n_jf_j:\sum_{j=1}^{d}n_j=k;\ n_j\geq 0\right\}.$$

Since \(k^{-1}\sum_{s=1}^{k}f_{j_s}\in Q_k\), we know that \(Q_k\) is a \(1/\sqrt{k}\) cover of \(\operatorname{CONV}(\mathcal{F})\). Take \(k=\lceil1/\epsilon^2\rceil\), we know that \(Q_k\) is an \(\epsilon\) cover. Moreover, since

$$|Q_k|\leq {d+k-1\choose k}\leq e^k(1+d/k)^k,$$

we obtain the bound in the theorem.

We can also estimate the \(L_2\) covering number for the convex hull of a parametric function class, such as VC-subgraph class. Specifically, in a parametric function class, the covering number is given by

$$\ln N(\epsilon,\mathcal{F},L_2(\mathcal{D})) \le V \ln(c/\epsilon), \tag{5.2}$$

where \(c\) is a constant, and \(V\) is the dimensionality (such as VC dimension) of the function class \(\mathcal{F}\).

The convex hull of (5.2) is referred to as the VC-hull class. Its covering number estimate can be obtained as follows.

### Theorem 5.15

Consider a function class \(\mathcal{F}\) with covering number given by (5.2) for some \(c>0\) and \(V>0\). Let \(A = \sup_{f\in\mathcal{F}} \|f\|_{L_2(\mathcal{D})}\), then we have

$$\ln N(\epsilon,\mathrm{CONV}(\mathcal{F}),L_2(\mathcal{D})) \le 10(2c/\epsilon)^{2V/(V+2)} \ln \max[12A/\epsilon,\,3+3(2c/\epsilon)^V]$$

for all \(\epsilon \le 2c\).

**Proof.** We let \(\mathcal{F}_\epsilon\) be an \(\epsilon/2\) cover of \(\mathcal{F}\) in \(L_2(\mathcal{D})\). Then any \(\epsilon/2\) cover of \(\mathrm{CONV}(\mathcal{F}_\epsilon)\) gives an \(\epsilon\) cover of \(\mathrm{CONV}(\mathcal{F})\). Moreover, we consider \(\mathcal{F}_{\epsilon'}\) as an \(\epsilon'/2\) cover of \(\mathcal{F}_\epsilon\) for some \(\epsilon' \ge \epsilon\), and decompose each \(f_j \in \mathcal{F}_\epsilon\) as

$$f = f' + \Delta f,$$

where \(f' \in \mathcal{F}_{\epsilon'}\) and \(\|\Delta f\|_{L_2(\mathcal{D})} \le \epsilon'/2\). Let \(\Delta \mathcal{F}_\epsilon = \{\Delta f : f \in \mathcal{F}_\epsilon\}\), then using this decomposition, we know that

$$\mathrm{CONV}(\mathcal{F}_\epsilon) \subset \mathrm{CONV}(\Delta \mathcal{F}_\epsilon) + \mathrm{CONV}(\mathcal{F}_{\epsilon'}).$$

It follows that

$$\ln N(\epsilon,\mathrm{CONV}(\mathcal{F}),L_2(\mathcal{D})) \le \ln N(\epsilon/2,\mathrm{CONV}(\mathcal{F}_\epsilon),L_2(\mathcal{D})) \le \ln N(\epsilon/4,\mathrm{CONV}(\mathcal{F}_{\epsilon'}),L_2(\mathcal{D})) + \ln N(\epsilon/4,\mathrm{CONV}(\Delta \mathcal{F}_\epsilon),L_2(\mathcal{D})).$$

Since

$$|\mathcal{F}_{\epsilon'}| \le (2c/\epsilon')^V,$$

we have from Theorem 5.13

$$\ln N(\epsilon/4,\mathrm{CONV}(\mathcal{F}_{\epsilon'}),L_2(\mathcal{D})) \le (2c/\epsilon')^V \ln(12A/\epsilon).$$

Moreover, since

$$|\Delta \mathcal{F}_\epsilon| \le |\mathcal{F}_\epsilon| \le (2c/\epsilon)^V,$$

we have from Theorem 5.14 that

$$\ln N(\epsilon/4,\mathrm{CONV}(\Delta \mathcal{F}_\epsilon),L_2(\mathcal{D})) \le (3\epsilon'/\epsilon)^2 \ln[e + e(2c/\epsilon)^V (\epsilon/\epsilon')].$$

Now let \(\epsilon'/2c = (\epsilon/2c)^{2/(V+2)}\), and we have

$$\ln N(\epsilon/4,\mathrm{CONV}(\mathcal{F}_{\epsilon'}),L_2(\mathcal{D})) + \ln N(\epsilon/4,\mathrm{CONV}(\Delta \mathcal{F}_\epsilon),L_2(\mathcal{D})) \le (2c/\epsilon')^V \ln(12A/\epsilon) + (3\epsilon'/\epsilon)^2 \ln[e + e(2c/\epsilon)^V (\epsilon/\epsilon')] \le (2c/\epsilon)^{2V/(V+2)} \ln(12A/\epsilon) + 9(2c/\epsilon)^{2V/(V+2)} \ln[e + e(2c/\epsilon)^V].$$

This proves the theorem.

Note that for a finite class \(d = |\mathcal{F}| < \infty\), its VC dimension is no more than \(\log_2 d\) because any \([\log_2 |\mathcal{F}|] + 1\) points cannot be shattered. It means that we can take \(V = \log_2 d\), and obtain a result

$$\ln N(\epsilon, \operatorname{CONV}(\mathcal{F}), L_2(\mathcal{D})) = O\left(\epsilon^{-2\log_2 d / \log_2(4d)}\log_2 d\,\ln(1/\epsilon)\right).$$

which is slightly better in its dependency on \(\epsilon\) than that of Theorem 5.14, which has an entropy growth rate of \(O(\epsilon^{-2})\).

Using a similar proof technique, but with a more careful analysis, it is possible to get rid of \(\ln(1/\epsilon)\) in Theorem 5.15, and obtain the following result. The details can be found in van der Vaart and Wellner (1996).

### Theorem 5.16

Let \(A = \sup_{f\in\mathcal{F}} \|f\|_{L_2(\mathcal{D})}\). If \(\ln N(\epsilon, \mathcal{F}, L_2(\mathcal{D})) \leq V\ln(cA/\epsilon)\) for some \(c \geq 1\) and \(V > 0\), then when \(\epsilon \leq 1\), we have

$$\ln N(\epsilon, \operatorname{CONV}(\mathcal{F}), L_2(\mathcal{D})) \leq K(c,V)(A/\epsilon)^{2V/(V+2)}$$

for some \(K(c,V)\) that depends on \(c\) and \(V\).

The convex hull of a parametric function class has entropy growth rate with a polynomial \((1/\epsilon)^r\) dependency on \(1/\epsilon\). Since \(r < 2\), the entropy integral

$$\int_0^\infty \sqrt{\ln N(\epsilon, \operatorname{CONV}(\mathcal{F}), L_2(\mathcal{D}))}\,d\epsilon < \infty.$$

Therefore the convex hull of a parametric function class is a Donsker class, for which the central limit theorem holds for the corresponding empirical process.

### Example 5.17

Consider neural networks with \(x \in \mathbb{R}^d\). Let \(h(z) = 1/(1 + \exp(-z))\) be the sigmoid activation function. Let

$$\mathcal{F} = \{h(\theta^\top x): \theta \in \mathbb{R}^d\} \cup \{-h(\theta^\top x): \theta \in \mathbb{R}^d\}$$

be the function class of one-layer neurons, then \(\mathcal{F}\) is a VC subgraph class with \(\operatorname{VC}(\mathcal{F}) = d + 1\). Thus it has parametric covering number

$$N(\epsilon, \mathcal{F}, L_2(\mathcal{D})) \leq (c/\epsilon)^{d+1}$$

uniformly for all distributions \(\mathcal{D}\). The \(L_1\) regularized two-layer neural network of the form

$$\mathcal{G} = \left\{\sum_{j=1}^{m} w_j h(\theta_j^\top x)\ \middle|\ \|w\|_1 \leq A\right\}$$

has entropy number of

$$\ln N(\epsilon, \mathcal{G}, L_2(\mathcal{D})) = O\left(\epsilon^{-2(d+1)/(d+3)}\right).$$
