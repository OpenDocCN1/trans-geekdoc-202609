\[\frac{1}{|\mathcal{P}'|}\sum_{q'\in\mathcal{P}'} KL(p(\cdot|\hat{q},q_0)\|\,p(\cdot|\hat{q},q')) = \frac{1}{|\mathcal{P}'|}\sum_{q'\in\mathcal{P}'} \mathbb{E}_{\mathcal{S}_n\sim p(\cdot|\hat{q},q_0)} \ln\left(\frac{p(\mathcal{S}_n,\hat{q},q_0)}{p(\mathcal{S}_n|\hat{q},q')}\right)\]

\[\le \cdots \le \sum_{t=1}^{n}\beta_t^2.\]

This implies the bound.

By using Lemma 13.21 to replace Theorem B.6 with α = 1, we obtain the following straightforward generalization of Theorem 12.15 from Fano’s inequality.

# Theorem 13.22

Consider a finite distribution family 𝒫_Z = {q¹,…,q^N}. Assume for some q̂ ∈ 𝒫_A, if for all time step t, and history 𝒮_{t−1},

\[\frac{1}{N^2}\sum_{q∈𝒫_Z}\sum_{q'∈𝒫_Z} KL\big(q(·|\hat{q}(𝒮_{t−1}),𝒮_{t−1})\|\,q'(·|\hat{q}(𝒮_{t−1}),𝒮_{t−1})\big) ≤ β_t^2.\]

Let Q be a loss function on Θ × 𝒫_Z, and

\[m = \sup_{θ∈Θ} \Big|\{k : Q(θ,q^k) < ε\}\Big|.\]

If m ≤ N/2 and

\[\ln(N/m) ≥ \ln 4 + 2\sum_{t=1}^{n}β_t^2,\]

then

\[\frac{1}{N}\sum_{j=1}^{N} \Pr_{θ,𝒮_n∼p(·|\hat{q},q^j)}\big(Q(θ,q^j) < ε\big) ≤ 0.5,\]

where the probability also includes possible randomization in 𝒜. If Q(·,·) is non-negative, then this implies that r_n(\hat{q},𝒫_Z,Q) ≥ 0.5ε.
