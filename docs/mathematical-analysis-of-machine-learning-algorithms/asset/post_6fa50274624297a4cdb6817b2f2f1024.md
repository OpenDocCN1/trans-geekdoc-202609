
## 4.3 Uniform Convergence with Uniform L1 Covering Number

Using the same notations as Chapter 3, we consider a function class

$$\mathcal{G} = \{\phi(w,z): w \in \Omega\},$$

with $\phi(w,\mathcal{S}_n)$ and $\phi(w,\mathcal{D})$ defined in (3.5) and (3.6). We can obtain the following uniform convergence bounds, which are analogous to the results of Theorem 3.14. Here we simply replace the $L_1(\mathcal{D})$-lower bracketing number with the $L_1$ uniform covering number. It is also possible to relax the requirement of uniform covering number by assuming the bound holds with large probability. We do not consider such analysis, for simplicity.

**Theorem 4.12** *Assume that $\phi(w,z) \in [0,1]$ for all $w$ and $z$. Then given $\delta \in (0,1)$, with probability at least $1 - \delta$, the following inequality holds:*

$$\forall w \in \Omega: \phi(w,\mathcal{D}) \leq \phi(w,\mathcal{S}_n) + \epsilon_n(\delta),$$

*where*

$$\epsilon_n(\delta) = \inf_{\epsilon>0} \left[ 2\epsilon + 3\sqrt{\frac{\ln(3N_1(\epsilon,\mathcal{G},2n)/\delta)}{2n}} \right].$$

*Moreover, for any $\gamma \in (0,1)$, with probability at least $1-\delta$, the following inequality holds:*

$$\forall w \in \Omega: (1 - \gamma)^2\phi(w,\mathcal{D}) \leq \phi(w,\mathcal{S}_n) + \epsilon_n(\delta),$$

*where*

$$\epsilon_n(\delta) = \inf_{\epsilon>0} \left[ 2\epsilon + \frac{(5 - 4\gamma)\ln(3N_1(\epsilon,\mathcal{G},n)/\delta)}{2\gamma n} \right].$$

*Proof* Let $\mathcal{F} = \{f(z)=\phi(w,z)-0.5: w \in \Omega\}$. Given $\mathcal{S}_n$, we consider an $\epsilon$-$L_1(\mathcal{S}_n)$ cover $\mathcal{F}_\epsilon(\mathcal{S}_n)$ of $\mathcal{F}$, of size no more $N = N_1(\epsilon,\mathcal{G},n)$. We may assume that $f(Z_i) \in [-0.5,0.5]$ for $f \in \mathcal{F}_\epsilon(\mathcal{S}_n)$. From Corollary 2.27 (with $a_i = 0.5$) and the union bound, we obtain the following uniform convergence result over $\mathcal{F}_\epsilon(\mathcal{S}_n)$. With probability $1 - \delta$,

$$\forall f \in \mathcal{F}_\epsilon(\mathcal{S}_n): f(\sigma,\mathcal{S}_n) \leq \sqrt{\frac{\ln(N/\delta)}{2n}}.$$

$$\forall w\in\Omega:\quad \phi(w,\mathcal{S}'_n)\le \phi(w,\mathcal{S}_n)+2\epsilon+\sqrt{\frac{2\ln(2N/\delta_1)}{n}}.$$

The standard additive Chernoff bound implies that for all $w\in\Omega$, with probability at least $1-\delta_2$,

$$\phi(w,\mathcal{D})\le \phi(w,\mathcal{S}'_n)+\sqrt{\frac{\ln(1/\delta_2)}{2n}}.$$

Therefore in Lemma 4.11, we can take symbols as defined, together with $\delta_1=2\delta/3$ and $\delta_2=\delta/3$ to obtain the desired bound.

Similarly, we consider $\mathcal{F}=\{f(z)=\phi(w,z):w\in\Omega\}$. Given $S_n$, we consider an $\epsilon$-$L_1(S_n)$ cover $\mathcal{F}_\epsilon(S_n)$ of $\mathcal{F}$, of size no more $N=N_1(\epsilon,\mathcal{G},n)$. We assume that $f(Z_i)\in[0,1]$ for all $f\in\mathcal{F}_\epsilon(S_n)$. From Corollary 2.27 and the union bound, we obtain the following uniform convergence result over $\mathcal{F}_\epsilon(S_n)$. With probability at least $1-\delta$,

$$\forall f\in\mathcal{F}_\epsilon(S_n):\quad f(\sigma,S_n)\le\sqrt{\frac{2\sum_{Z\in S_n}f(Z)^2\ln(N/\delta)}{n^2}}$$
$$\le \gamma'\frac{1}{n}\sum_{Z\in S_n}f(Z)+\frac{\ln(N/\delta)}{2\gamma'n}.$$

The first inequality used Corollary 2.27. The second inequality used $\sqrt{2ab}\le \gamma'a+b/(2\gamma')$ and $f(Z)^2\le f(Z)$. Since for all $f\in\mathcal{F}$, we can find $f'\in\mathcal{F}_\epsilon(S_n)$ so that $\frac{1}{n}\sum_{Z\in S_n}|f(Z)-f'(Z)|\le\epsilon$. It follows that

$$f(\sigma,S_n)\le f'(\sigma,S_n)+\epsilon$$
$$\le \gamma'\frac{1}{n}\sum_{Z\in S_n}f'(Z)+\frac{\ln(N/\delta)}{2\gamma'n}+\epsilon$$
$$\le \gamma'\frac{1}{n}\sum_{Z\in S_n}f(Z)+\frac{\ln(N/\delta)}{2\gamma'n}+(1+\gamma')\epsilon.$$

Now, with $\psi(f,S_n)=\tilde{\psi}(f,S_n)=\gamma'\frac{1}{n}\sum_{Z\in S_n}f(Z)$, we obtain from Lemma 4.8 the following uniform convergence result. With probability at least $1-\delta_1$ over $(S_n,S'_n)\sim\mathcal{D}^{2n}$,

$$\forall w\in\Omega:\quad (1-\gamma')\phi(w,S'_n)\le (1+\gamma')\phi(w,S_n)+2(1+\gamma')\epsilon+\frac{\ln(2N/\delta_1)}{\gamma'n}.$$

Let $\gamma'=\gamma/(2-\gamma)$, then it is easy to check algebraically that $(1-\gamma')/(1+\gamma')=1-\gamma$ and $1/(\gamma'(1+\gamma'))=(2-\gamma)^2/(2\gamma)$. We thus obtain

$$\forall w\in\Omega:\quad (1-\gamma)\phi(w,S'_n)\le \phi(w,S_n)+2\epsilon+\frac{(2-\gamma)^2\ln(2N/\delta_1)}{2\gamma n}. \tag{4.1}$$

The standard multiplicative Chernoff bound in (2.11) implies that with probability 1 − δ₂,

$$(1-\gamma)^2\phi(w,\mathcal{D})\le (1-\gamma)\phi(w,\mathcal{S}'_n)+(1-\gamma)\ln(1/\delta_2)/(2\gamma n).$$

Therefore in Lemma 4.11, we can use symbols as displayed here, together with δ₁ = 2δ/3 and δ₂ = δ/3 to obtain the desired bound.

Using Lemma 3.11, the following oracle inequalities can be obtained from Theorem 4.12. The result is analogous to Corollary 3.15, with a similar proof. We will thus leave the proof as an exercise.

### Corollary 4.13

If φ(w,z) ∈ [0,1]. Let G = {φ(w,z) : w ∈ Ω}. With probability at least 1 − δ, the approximate ERM method (3.3) satisfies the (additive) oracle inequality:

E_{Z∼D} φ(ŵ, Z) ≤ inf_{w∈Ω} E_{Z∼D} φ(w, Z) + ε′ + inf_{ε>0} [ 2ε + √( 8 ln(4 N₁(ε, G, n)/δ) / n ) ] .

Moreover, we have the following (multiplicative) oracle inequality for all γ ∈ (0,1): with probability at least 1 − δ,

(1 − γ)² E_{(X,Y)∼D} φ(ŵ, Z) ≤ inf_{w∈Ω} (1 + γ) E_{(X,Y)∼D} φ(w, Z) + ε′ + inf_{ε>0} [ 2ε + (6 − 3γ) ln(4 N₁(ε, G, n)/δ) / (2γn) ] .

### Example 4.14

Consider the linear classifier example in Example 4.6. Since ln N∞(ε, G, n) ≤ d ln(2n), it follows that for the ERM method, we have the following oracle inequalities. With probability at least 1 − δ,

E_D 1( f(ŵ, X) ≠ Y ) ≤ inf_{w∈R^d} E_D 1( f(w, X) ≠ Y ) + √[ 8( ln(4/δ) + d ln(2n) ) / n ] .

Moreover, by optimizing the multiplicative bound over γ from the set γ ∈ { i/n : i ∈ [n] }, and taking a union bound, we can obtain the following inequality. With probability at least 1 − δ, E_D 1( f(ŵ, X) ≠ Y ) ≤ err_* + C [ √{ err_* ln(δ^{−1}) + d ln(n) / n } + ( ln(δ^{−1}) + d ln(n) ) / n ] , where C is an absolute constant and err_* = inf_{w∈Ω} E_D 1( f(w, X) ≠ Y ).

## 4.4 Vapnik–Chervonenkis Dimension

Let $\mathcal{G}=\{\phi(w,z):w\in\Omega\}$ be a $\{0,1\}$-valued binary function class of $z\in\mathcal{Z}$ indexed by $w\in\Omega$. Given an arbitrary set of $n$ samples $S_n=\{Z_1,\ldots,Z_n\}\in\mathcal{Z}^n$, we are interested in the number of functions (uniform $L_\infty$ cover of the function class at $\epsilon=0$) that $\mathcal{G}(S_n)=\{[\phi(w,Z_1),\ldots,\phi(w,Z_n)]:w\in\Omega\}$ can achieve. We introduce the following definition of Vapnik and Chervonenkis (1971).

**Definition 4.15** (VC Dimension) We say that $\mathcal{G}$ shatters $S_n$ if the number of elements $|\mathcal{G}(S_n)|$ is $2^n$. That is, we can always find $w\in\Omega$ so that $\phi(w,z)$ matches any arbitrary possible choice of $\{0,1\}^n$ values at the $n$ points. The maximum $n$ such that $\mathcal{G}$ shatters at least one instance of $S_n\in\mathcal{Z}^n$, denoted by $\operatorname{VC}(\mathcal{G})$, is called the VC dimension of $\mathcal{G}$.

Note that the maximum number of functions in $\mathcal{G}(S_n)$ is $2^n$. If $n>d$, then for any $n$ samples $S_n$, $\mathcal{G}(S_n)$ contains fewer than $2^n$ elements. Surprisingly, if a binary-valued function class $\mathcal{G}$ has VC dimension $d$, then when $n>d$, the size of set $\mathcal{G}(S_n)$ can grow only polynomially in $n$. This gives an $O(d\ln n)$ upper bound on the uniform entropy of the function class $\mathcal{G}$ with a finite VC dimension (see Vapnik and Chervonenkis, 1968, 1971; Sauer, 1972).

**Lemma 4.16** (Sauer’s Lemma) If $\operatorname{VC}(\mathcal{G})=d$, then we have for all $n>0$ and empirical samples $S_n=\{Z_1,\ldots,Z_n\}\in\mathcal{Z}^n$,

$$|\mathcal{G}(S_n)|\leq\sum_{\ell=0}^{d}\binom{n}{\ell}\leq\max(2,en/d)^d.$$

*Proof* First, we prove the statement under the assumption that $|\mathcal{G}(S_n)|$ is upper bounded by the number of subsets of $S_n$ (including the empty set) that are shattered by $\mathcal{G}$. Under this assumption, since any subset shattered by $\mathcal{G}$ cannot be larger than $d$ by the definition of VC dimension, and the number of subsets of size $\ell$ is $\binom{n}{\ell}$, we know that the number of subsets shattered by $\mathcal{G}$ cannot be more than $\sum_{\ell=1}^{d}\binom{n}{\ell}$. When $n\geq d$, we have (see Exercise 4.1)

$$\sum_{\ell=0}^{d}\binom{n}{\ell}\leq(en/d)^d.\tag{4.2}$$

When $n\leq d$, we have $\sum_{\ell=0}^{d}\binom{n}{\ell}\leq 2^d$. This implies the desired result.

In the following, we only need to prove the statement that $|\mathcal{G}(S_n)|$ is upper bounded by the number of subsets of $S_n$ that are shattered by $\mathcal{G}$. This can be proved by induction on $n$. When $n=1$, one can check that the claim holds trivially.

Now assume that the claim holds for all empirical samples of size no more than $n-1$. Consider $n$ samples $\{Z_1,\ldots,Z_n\}$. We define

$$\phi(w,S_k)=[\phi(w,Z_1),\ldots,\phi(w,Z_k)],$$
$$\mathcal{G}_{n-1}(S_n)=\{[\phi(w,S_{n-1}),1]:[\phi(w,S_{n-1}),0],[\phi(w,S_{n-1}),1]\in\mathcal{G}(S_n)\}.$$
