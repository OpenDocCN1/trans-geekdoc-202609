∀ f ∈ F_{γ/2}(S_n ∪ S'_n):  (1 − γ')/n ∑_{i=1}^n L'(f(X'_i), Y'_i) ≤ (1 + γ')/n ∑_{i=1}^n L'(f(X_i), Y_i) + ln(2N/δ₁)/(γ' n).

Since for all f ∈ F, we can find f' ∈ F_e(S_n) so that |f(x) − f'(x)| ≤ γ/2, it follows that

(1 − γ')/n ∑_{i=1}^n L(f(X'_i), Y'_i) ≤ (1 − γ')/n ∑_{i=1}^n L'(f'(X'_i), Y'_i) ≤ (1 + γ')/n ∑_{i=1}^n L'(f'(X_i), Y_i) + ln(2N/δ₁)/(γ' n) ≤ (1 + γ')/n ∑_{i=1}^n \tilde L(f(X_i), Y_i) + ln(2N/δ₁)/(γ' n).

Note that the first and the last inequalities used (4.6). Let γ' = γ/(2 − γ), then it is easy to check algebraically that (1 − γ')/(1 + γ') = 1 − γ and 1/(γ'(1 + γ')) = (2 − γ)^2/(2γ). We thus obtain

∀ f ∈ F:  \underbrace{(1 − γ)/n ∑_{i=1}^n L(f(X'_i), Y'_i)}_{ψ_{val}} ≤ \underbrace{1/n ∑_{i=1}^n \tilde L(f(X_i), Y_i)}_{ψ_{trn}} + \underbrace{(2 − γ)^2 ln(2N/δ₁)/(2γ n)}_{ε_n^1(δ₁)}.

The standard multiplicative Chernoff bound in (2.11) implies that with probability 1 − δ₂,

\underbrace{(1 − γ)(1 − γ) E_{(X,Y)~D} L(f(X),Y)}_{ψ_{ust}} ≤ \underbrace{(1 − γ)/n ∑_{i=1}^n L(f(X'_i), Y'_i)}_{ψ_{val}} + \underbrace{(1 − γ) ln(1/δ₂)/(2γ n)}_{ε_n^2(δ₂)}.

Therefore in Lemma 4.11, we can use symbols as displayed, together with δ₁ = 2δ/3 and δ₂ = δ/3 to obtain the desired bound.

Similar to Corollary 4.13, one may also obtain an oracle inequality from Theorem 4.21, which we will not state here.
