# Definition 9.3

A symmetric function $k(x,x')$ is called a positive-definite kernel on $\mathcal{X}\times\mathcal{X}$ if for all $\alpha_1,\dots,\alpha_m\in\mathbb{R}$ and $x_1,\dots,x_m\in\mathcal{X}$, we have $\displaystyle\sum_{i=1}^m\sum_{j=1}^m\alpha_i\alpha_j k(x_i,x_j)\ge0$.

# Definition 9.4

Given a symmetric positive-definite kernel, we define a function space $\mathcal{H}_0$ of the form $\displaystyle\mathcal{H}_0=\left\{f(x):f(x)=\sum_{i=1}^m\alpha_i k(x_i,x)\right\}$, with inner product defined as $\displaystyle\|f(x)\|_{\mathcal{H}}^2=\sum_{i=1}^m\sum_{j=1}^m\alpha_i\alpha_j k(x_i,x_j)$.

The completion of $\mathcal{H}_0$ with respect to this inner product, defined as $\mathcal{H}$, is called the RKHS of kernel $k$.

We note that the RKHS norm of $f(x)$ in Definition 9.4 is well defined. That is, different representations lead to the same norm definition. The proof is left as an exercise.

# Proposition 9.5

Assume that for all $x\in\mathcal{X}$, $\displaystyle\sum_{i=1}^m\alpha_i k(x_i,x)=\sum_{i=1}^{m'}\alpha_i' k(x_i',x)$, then $\displaystyle\sum_{i=1}^m\sum_{j=1}^m\alpha_i\alpha_j k(x_i,x_j)=\sum_{i=1}^{m'}\sum_{j=1}^{m'}\alpha_i'\alpha_j' k(x_i',x_j')$.

We have derived kernel methods from linear models using the kernel trick. The following result shows that the reverse is also true. That is, there exists a feature representation of any RKHS. The result is a consequence of Mercer’s theorem (Mercer, 1909).

# Theorem 9.6

A symmetric kernel function $k(x,x')$ is positive-definite if and only if there exists a feature map $\psi(x)$ so that it can be written in the form of (9.3). Moreover, let $\mathcal{H}$ be the RKHS of $k(\cdot,\cdot)$, then any function $f(x)\in\mathcal{H}$ can be written uniquely in the form of (9.1), with $\|f(x)\|_{\mathcal{H}}^2=\langle w,w\rangle$.

It is worth noting that although a decomposition (9.3) exists for a positive-definite kernel function, such decomposition may not be unique. Therefore it is possible to have different feature representations of an RKHS.
