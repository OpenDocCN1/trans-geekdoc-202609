Moreover,

$$\ln N_{\infty}(\epsilon, \mathcal{G}, n) \le d \ln \max[2, en/(d\epsilon)].$$

Proof Let $U$ be a random variable distributed uniformly over $[0,1]$. Then for all $a \in (0,1)$: $\mathbb{E}_U \mathbb{1}(U \le a)=a$. Thus for all $\phi, \phi' \in \mathcal{G}$,

$$\mathbb{E}_{\mathcal{D}}|\phi(Z)-\phi'(Z)|^p = \mathbb{E}_{\mathcal{D}}|\mathbb{E}_U[\mathbb{1}(U \le \phi(Z))-\mathbb{1}(U \le \phi'(Z))]|^p \le \mathbb{E}_{\mathcal{D}}\mathbb{E}_U|\mathbb{1}(U \le \phi(Z))-\mathbb{1}(U \le \phi'(Z))|^p.$$

The last inequality used the Jensen inequality. Therefore

$$\ln N(\epsilon, \mathcal{G}, L_p(\mathcal{D})) \le \ln N(\epsilon, G_{\text{subgraph}}, L_p(\mathcal{D} \times U(0,1))).$$

This leads to the first desired bound.

The second bound can be proved by discretizing $U$ into intervals with thresholds $\min(1, \epsilon(2k + 1))$ for $k = 0,1,\dots$ with no more than $\lceil(2\epsilon)^{-1}\rceil \le 1/\epsilon$ thresholds. This gives an $\epsilon$ cover of $U$ in Euclidean distance. We can then approximate $\mathbb{E}_U$ by average over the thresholds to get $\epsilon L_\infty$ cover with the discretization. Let the set of thresholds be $U'$. If $\mathcal{D}$ contain $n$ data points, then $\mathcal{D} \times U'$ contains at most $n|U'| \le n/\epsilon$ points, and one may apply Sauer's lemma to obtain a cover on these points. This implies the second bound.

# 5.5 Convex Hull Class

Convex hull of a function class is frequently encountered in applications, and is related to $L_1$ regularization. We can define the convex hull of a function class as follows.

**Definition 5.12** The convex hull of a function class $\mathcal{F}=\{f(\theta,x):\theta\in\Theta\}$ is defined as

$$\operatorname{CONV}(\mathcal{F}) = \left\{\sum_{j=1}^m w_j f(\theta_j,x): m>0, \|w\|_1=1, w_j \ge 0, \theta_j \in \Theta\right\}.$$

We also include the closure of the finite sum functions with respect to an appropriate topology in the convex hull.
