
$$\forall w \in \Omega:\quad -\Lambda(\lambda,w) \le -\phi(w,\mathcal{D}) + \frac{\lambda\sigma^2}{2}.$$

Then we obtain from Theorem 10.18 the following generalization bound. For any $\lambda > 0$, with probability at least $1-\delta$,

$$\mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,\mathcal{D}) \le \mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,S_n) + \left[\lambda\mathrm{KL}(\widetilde{q}\|q_0) + \frac{\sigma^2}{2\lambda n} + \lambda\ln(1/\delta)\right].$$

Assume that $\phi(w,Z)$ satisfies a uniform Bennett-style bound on the logarithmic moment generating function in Lemma 2.20, and the variance condition of (3.13), then we can obtain a fast rate result.

## Corollary 10.20
*Under the assumptions of Theorem 10.18, and assume that there exists $b>0$ so that*

$$-\Lambda(\lambda,w) \le -\phi(w,\mathcal{D}) + \lambda\psi(\lambda b)\operatorname{Var}_{Z\sim\mathcal{D}}(\phi(w,Z)),$$

where $\psi(z)=(e^z-z-1)/z^2$. Assume further that the variance condition of (3.13) holds. Then with probability at least $1-\delta$,

$$\left(1-\frac{c_1\psi(b/(\lambda n))}{\lambda n}\right)\mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,\mathcal{D})$$
$$\le \mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,S_n)+\left[\lambda\mathrm{KL}(\widetilde{q}\|q_0)+\frac{c_0^2\psi(b/(\lambda n))}{\lambda n}+\lambda\ln(1/\delta)\right].$$

*We also have the expected generalization error bound:*

$$\left(1-\frac{c_1\psi(b/(\lambda n))}{\lambda n}\right)\mathbb{E}_{S_n}\mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,\mathcal{D})$$
$$\le \mathbb{E}_{S_n}\mathbb{E}_{w\sim\widetilde{q}(\cdot\mid S_n)}\phi(w,S_n)+\left[\lambda\mathbb{E}_{S_n}\mathrm{KL}(\widetilde{q}\|q_0)+\frac{c_0^2\psi(b/(\lambda n))}{\lambda n}\right].$$

*Proof*  We have

$$\Lambda(1/(\lambda n),w) \ge \phi(w,\mathcal{D})-\frac{1}{\lambda n}\psi(b/(\lambda n))\operatorname{Var}_{Z\sim\mathcal{D}}(\phi(w,Z)) \qquad \text{(assumption on }\Lambda\text{)}$$
$$\ge \phi(w,\mathcal{D})-\frac{1}{\lambda n}\psi(b/(\lambda n))(c_0^2+c_1\phi(w,\mathcal{D})) \qquad \text{(variance condition)}$$
$$=\left(1-\frac{c_1\psi(b/(\lambda n))}{\lambda n}\right)\phi(w,\mathcal{D})-\frac{c_0^2\psi(b/(\lambda n))}{\lambda n}.$$

This estimate, together with Theorem 10.18, implies the desired bounds. □

The result can be compared to the stability analysis of the Gibbs algorithm in Theorem 7.19, and to the local Rademacher complexity analysis in Theorem 6.41.

## Example 10.21
Consider the least squares problem in Example 3.18 with either a convex or a nonconvex but realizable function class. Let

$$\phi(w,z)=(f(w,x)-y)^2-(f_{\mathrm{opt}}(x)-y)^2.$$

We can take b = M², c₀ = 0, and c₁ = 4M². Let λ = 4M²/n, and note that ψ(b/(λn)) = ψ(0.25) < 0.6. We obtain the following bound from Corollary 10.20. With probability at least 1 − δ,

0.4 𝔼_{w∼\hat{q}(·|S_n)} φ(w,𝒟) ≤ 𝔼_{w∼\hat{q}(·|S_n)} φ(w,𝒮_n) + \frac{4M²}{n} [KL(\hat{q}||q₀) + ln(1/δ)] .

For least squares regression with sub-Gaussian noise, one can also perform a more direct calculation of logarithmic moment generating function with a slightly improved result. See Proposition 12.21.

A more recent development of the information theoretical approach to generalization analysis is to rewrite the expected generalization result in Theorem 10.18 in terms of the mutual information between a learning algorithm 𝒜 and the training data 𝒮_n. Using the notations of Theorem 10.18, we can define the mutual information of 𝒜 and 𝒮_n as follows:

I(𝒜,𝒮_n) = 𝔼_{𝒮_n} 𝔼_{w∼\hat{q}(·|S_n)} ln \frac{\hat{q}(w|𝒮_n)}{\hat{q}(w)}, \quad \hat{q}(w) = 𝔼_{𝒮_n} \hat{q}(w|𝒮_n).

We note that the mutual information optimizes the expected KL-divergence in Theorem 10.18 over prior q₀:

I(𝒜,𝒮_n) = inf_{q₀} 𝔼_{𝒮_n} KL(\hat{q}||q₀).

The following result is a direct consequence of Theorem 10.18 with q₀(w) = \hat{q}(w).

## Corollary 10.22
Under the assumptions of Theorem 10.18, we have the following expected generalization bound for all λ > 0:

𝔼_{𝒮_n} 𝔼_{𝒜} Λ(λ,𝒟) ≤ 𝔼_{𝒮_n} 𝔼_{𝒜} \frac{1}{n} \sum_{i=1}^{n} φ(w,Z_i) + λ I(𝒜,𝒮_n),

*where 𝔼_𝒜 denotes the expectation over the randomization of algorithm 𝒜; that is, w ∼ \hat{q}(·|𝒮_n).*

Similar to Example 10.19, we have the following result for sub-Gaussian loss functions. This is the result that is often stated in the literature.

## Example 10.23
Assume that sup[φ(w,z) − φ(w,z′)] ≤ M. Then we have the sub-Gaussian inequality

Λ(λ) ≤ \frac{λ² M²}{8}.

We obtain from Corollary 10.22,

𝔼_{𝒮_n} 𝔼_{𝒜} φ(w,𝒟) ≤ 𝔼_{𝒮_n} 𝔼_{𝒜} \frac{1}{n} \sum_{i=1}^{n} φ(w,Z_i) + inf_{λ>0} [ λ I(𝒜,𝒮_n) + \frac{M²}{8 λ n} ] = 𝔼_{𝒮_n} 𝔼_{𝒜} \frac{1}{n} \sum_{i=1}^{n} φ(w,Z_i) + M \sqrt{\frac{I(𝒜,𝒮_n)}{2n}}.

We may also derive fast rate results for the mutual information generalization bound as follows.

## Example 10.24
Under the conditions of Corollary 10.20, we obtain

$$\left(1-\frac{c_1\psi\left(b/(\lambda n)\right)}{\lambda n}\right)\mathbb{E}_{S_n}\mathbb{E}_{A}\phi(w,\mathcal{D})$$
$$\leq \mathbb{E}_{S_n}\mathbb{E}_{A}\frac{1}{n}\sum_{i=1}^{n}\phi(w,Z_i)+\left[\lambda I(\mathcal{A},S_n)+\frac{c_0^2\psi\left(b/(\lambda n)\right)}{\lambda n}\right].$$

We now consider the Gibbs algorithm of (7.9), which we restate using notations of this section as follows:

$$\hat{q}(w\mid S_n)\propto q_0(\theta)\exp\left(-\frac{1}{\lambda n}\sum_{i=1}^{n}\phi(w,Z_i)\right). \tag{10.12}$$

We have the following oracle inequality for the Gibbs algorithm.

## Corollary 10.25
*The following expected oracle inequality holds for the Gibbs distribution (10.12):*

$$\mathbb{E}_{S_n}\mathbb{E}_{w\sim\hat{q}}\Lambda\left(\frac{1}{\lambda n},w\right)\leq\inf_q\left[\mathbb{E}_{w\sim q}\phi(w,\mathcal{D})+\lambda\mathrm{KL}(q\Vert q_0)\right],$$

where $\Lambda(\cdot)$ is defined in Theorem 10.18.

*Proof*  From Proposition 7.16, $\hat{q}$ is the solution of the following regularized empirical risk minimization problem:

$$\hat{q}=\arg\min_q\left[\mathbb{E}_{\theta\sim q}\frac{1}{n}\sum_{i=1}^{n}\phi(w,Z_i)+\lambda\mathrm{KL}(q\Vert q_0)\right]. \tag{10.13}$$

Therefore for any $q$, we obtain from Theorem 10.18,

$$\mathbb{E}_{S_n}\mathbb{E}_{w\sim\hat{q}}\Lambda\left(\frac{1}{\lambda n},w\right)\leq\mathbb{E}_{S_n}\left[\mathbb{E}_{w\sim\hat{q}}\frac{1}{n}\sum_{i=1}^{n}\phi(w,Z_i)+\lambda\mathrm{KL}(\hat{q}\Vert q_0)\right]$$
$$\leq\mathbb{E}_{S_n}\left[\mathbb{E}_{w\sim q}\frac{1}{n}\sum_{i=1}^{n}\phi(w,Z_i)+\lambda\mathrm{KL}(q\Vert q_0)\right]$$
$$=\mathbb{E}_{w\sim q}\phi(w,\mathcal{D})+\lambda\mathrm{KL}(q\Vert q_0).$$

The first inequality used Theorem 10.18. The second inequality used (10.13). The last equation used the fact that $Z_i\sim\mathcal{D}$. This implies the result. □

We note that, similar to the analysis of least squares using Corollary 10.20 of Theorem 10.18, we may use Corollary 10.25 to obtain a simpler oracle inequality than that of the local Rademacher complexity. One interesting application, which we state in the following, is a simple analysis of conditional density estimation for Gibbs algorithms.

## Corollary 10.26
*Consider the conditional density estimation problem with a density class $\{p(Y\mid w,X):w\in\Omega\}$. Let $\lambda=1/(\alpha n)$ for some $\alpha\in(0,1)$, and $\phi(w,Z)=-\ln p(Y\mid w,X)$ in (10.12). Then*

$(1-α)\mathbb{E}_{S_n∼\mathcal{D}^n}\mathbb{E}_{w∼\hat q}\mathbb{E}_{X∼\mathcal{D}}D_α(p(·|w,X)\|p_*(·|X))$  
$\leq \inf_q\left[α\mathbb{E}_{w∼q}\mathbb{E}_{X∼\mathcal{D}}\mathrm{KL}(p_*(·|X)\|p(·|w,X)) + \frac{\mathrm{KL}(q\|q_0)}{n}\right]$

where $D_α$ is the $α$-divergence defined in (B.3), and $p_*(Y|X)$ is the true conditional density of $\mathcal{D}$.

**Proof**  Consider $φ'(w,Z)=\ln p_*(Y|X)-\ln p(Y|w,X)$. Then the Gibbs algorithm does not change if we replace $φ(w,Z)$ with $φ'(w,Z)$. By applying Corollary 10.25 with $φ(w,Z)$ replaced by $φ'(w,Z)$, we note that

$Λ(1/(λn),w)=-\frac{1}{α}\ln\mathbb{E}_{(X,Y)∼\mathcal{D}}\left(\frac{p(Y|w,X)}{p_*(Y|X)}\right)^α$  
$=-\frac{1}{α}\ln\left[1-(1-α)\mathbb{E}_{X∼\mathcal{D}}D_α(p(·|w,X)\|p_*(·|X))\right]$  
$\geq\frac{1-α}{α}\mathbb{E}_{X∼\mathcal{D}}D_α(p(·|w,X)\|p_*(·|X)).$

Moreover, $\mathbb{E}_{\mathcal{D}}φ'(w,Z)=\mathbb{E}_{X}\mathrm{KL}(p_*(·|X)\|p(·|w,X))$. The desired bound follows directly from Corollary 10.25.

## Example 10.27

The squared Hellinger distance is $α$-divergence with $α=0.5$. Consider the following Gibbs algorithm with log-likelihood loss and $λ=2/n$:

$\hat q(w|S_n)\propto q_0(θ)\exp\left(0.5\sum_{i=1}^{n}\ln p(Y_i|w,X_i)\right).$

Corollary 10.26 implies that

$\mathbb{E}_{S_n∼\mathcal{D}^n}\mathbb{E}_{w∼\hat q}\mathbb{E}_{X∼\mathcal{D}}\left(H(p_*(·|X)\|p(·|w,X))\right)^2$  
$\leq\inf_q\left[\mathbb{E}_{w∼q}\mathbb{E}_{X∼\mathcal{D}}\mathrm{KL}(p_*(·|X)\|p(·|w,X))+\frac{2\mathrm{KL}(q\|q_0)}{n}\right].$

One may also obtain high-probability oracle inequalities for the Gibbs algorithm. For example, we have the following result.

## Theorem 10.28

Assume that $\sup_{w,z,z'}|φ(w,z)-φ(w,z')|\leq M$. Let $q_0$ be a distribution on $Θ$. Let $\hat q$ be the Gibbs distribution of (10.12). Then with probability at least $1-δ$,

$\mathbb{E}_{w∼\hat q}φ(w,\mathcal{D})\leq\inf_q\left[\mathbb{E}_{w∼q}φ(w,\mathcal{D})+λ\mathrm{KL}(q\|q_0)\right]+\frac{M^2}{8λn}+2M\sqrt{\frac{\ln(2/δ)}{2n}}.$

**Proof**  Let $Δ(Ω)$ denote the set of posterior distributions $\hat q(·|S_n)$. We note that with $h(q)=λ\mathrm{KL}(q\|q_0)$, Theorem 10.18 (with $Δ_n(h)=0$) implies that

$ε_n^h(Δ(Ω),\mathcal{D})=\mathbb{E}_{S_n∼\mathcal{D}^n}\sup_{q∈Δ(Ω)}\left[\mathbb{E}_{w∼q}φ(w,S_n)-λ\mathrm{KL}(q\|q_0)\right]\leq\frac{M^2}{8λn},$

with a calculation similar to Example 10.19. We obtain the desired bound from Corollary 6.21.
