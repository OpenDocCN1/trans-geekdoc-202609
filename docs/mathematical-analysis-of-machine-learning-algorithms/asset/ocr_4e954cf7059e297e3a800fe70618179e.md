the set of arms (or actions) is \(\mathcal{A}\), which is finite: \(|\mathcal{A}| = K\). Each time, we pull one arm \(a \in \mathcal{A}\). We also know a feature vector \(\psi(a) \in \mathcal{H}\) (where \(\mathcal{H}\) is an inner product space) so that the expected reward is a linear function:

\[\mu(a) = \theta_*^\top \psi(a),\]

with an unknown parameter \(\theta_* \in \mathcal{H}\) to be estimated. In this section, we present an arm-elimination algorithm for stochastic linear bandits in Algorithm 16.2 with regret depending linearly on \(\dim(\lambda,\psi(\mathcal{A}),T)\) and logarithmically on \(K\). Here \(\dim(\lambda,\psi(\mathcal{A}),T)\) is defined in Proposition 9.36. The lower-order term also depends on the quantity \(\operatorname{entro}(\lambda,\psi(\mathcal{A}),T)\) in Proposition 15.8.

```
**Algorithm 16.2** Arm Elimination for Stochastic Linear Bandit

**Input:** \(\mathcal{A},\{\psi(a):a\in\mathcal{A}\}\)

1. Let \(\mathcal{A}_0=\mathcal{A}\)
2. for \(\ell=1,2,\ldots,L\) **do**
3. &nbsp;&nbsp;Set parameters \(\lambda_\ell,T_\ell,\beta_\ell,n_\ell,\eta_\ell\)
4. &nbsp;&nbsp;Use Algorithm 9.1 (with \(\lambda=\lambda_\ell,n=n_\ell,\eta=\eta_\ell\)) to obtain a policy
   \(\sum_{i=1}^{m_\ell}\pi_{\ell,i}(a=a_{\ell,i})\) with \(m_\ell\le n_\ell\) examples \(\{a_{\ell,s}\in\mathcal{A}_{\ell-1}\}\)
5. &nbsp;&nbsp;For each \(i=1,\ldots,T_\ell\), pull \(a_{\ell,i}\) for \(J_\ell=\lceil T_\ell\pi_{\ell,i}\rceil\) times, and observe rewards \(r_{\ell,i,j}\in[0,1]\) \((j=1,\ldots,J_\ell)\)
6. &nbsp;&nbsp;Let \(\theta_\ell=\arg\min_\theta\sum_{i=1}^{m_\ell}\sum_{j=1}^{J_\ell}[(\theta^\top\psi(a_{\ell,i})-r_{\ell,i,j})^2+\lambda_\ell\|\theta\|_2^2]\)
7. &nbsp;&nbsp;Let \(a_\ell=\arg\max_{a\in\mathcal{A}_{\ell-1}}\theta_\ell^\top\psi(a)\)
8. &nbsp;&nbsp;Let \(\mathcal{A}_\ell=\{a\in\mathcal{A}_{\ell-1}:\theta_\ell^\top\psi(a)\ge\theta_\ell^\top\psi(a_\ell)-\beta_\ell\}\)
```

# **Theorem 16.14**

*Assume that we know* \(\|\theta_*\|_2\le B\). Let \(a_*\in\arg\max_{a\in\mathcal{A}}\mu(a)\). Given \(\eta>0\), for each \(\ell\ge1\), we set

\[\lambda_\ell=\alpha^2/(B^2T_\ell),\qquad T_\ell=2^{\ell-1},\]
\[n_\ell=\lceil 8\operatorname{entro}(\lambda_\ell,\psi(\mathcal{A}_\ell))\rceil,\qquad \eta_\ell=\min(0.1,0.1/\dim(\lambda_\ell,\psi(\mathcal{A}))),\]
\[\beta_\ell=2\left(\alpha+\sqrt{\frac{\ln(2K(\ell+1)^2/\delta)}{2}}\right)\sqrt{\frac{4\dim(\lambda_\ell,\psi(\mathcal{A}))}{T_\ell}}.\]

in *Algorithm 16.2*. We also define \(\beta_0=0.5\). It follows that \(\forall\ell\ge0\), \(a_*\in\mathcal{A}_\ell\) and

\[\sup\{\mu(a_*)-\mu(a):a\in\mathcal{A}_\ell\}\le 2\beta_\ell.\]

*This implies that after iteration* \(L\), *and we have pulled total number of* \(T\le (2^L-1)+\sum_{\ell=1}^{L}n_\ell\) *arms, with probability at least* \(1-\delta\):

\[\operatorname{REG}_T\le 2\sum_{\ell=1}^{L}(n_\ell+T_\ell)\beta_{\ell-1}.\]
