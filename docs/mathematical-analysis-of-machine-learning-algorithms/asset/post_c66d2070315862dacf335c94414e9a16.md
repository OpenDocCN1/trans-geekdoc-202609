
Proof We prove the following statement by induction from $h = H$ to $h = 1$.

$[f^h(x^h) - V_{\pi_f}^h(x^h)] = \mathbb{E}_{\{(x^{h'},a^{h'},r^{h'})\}_{h'=h}^H \sim \pi_f | x^h} \sum_{h'=h}^H \mathcal{E}^{h'}(f, x^{h'}, a^{h'}). \tag{18.1}$

When $h = H$, we have $a^H = \pi_f^H(x^H)$ and

$\mathcal{E}^H(f, x^H, a^H) = f^H(x^H, a^H) - \mathbb{E}_{r^H | x^H, a^H}[r^H] = f^H(x^H) - V_{\pi_f}^H(x^H).$

Therefore $(18.1)$ holds. Assume that the equation holds at $h+1$ for some $1 \le h \le H-1$. Then at $h$, we have

$\mathbb{E}_{\{(x^{h'},a^{h'},r^{h'})\}_{h'=h}^H \sim \pi_f | x^h} \sum_{h'=h}^H \mathcal{E}^{h'}(f, x^{h'}, a^{h'}) = \mathbb{E}_{x^{h+1}, r^h, a^h \sim \pi_f | x^h}[\mathcal{E}^h(f, x^h, a^h) + f^{h+1}(x^{h+1}) - V_{\pi_f}^{h+1}(x^{h+1})] = \mathbb{E}_{x^{h+1}, r^h, a^h \sim \pi_f | x^h}[f^h(x^h, a^h) - r^h - V_{\pi_f}^{h+1}(x^{h+1})] = \mathbb{E}_{a^h \sim \pi_f | x^h}[f^h(x^h, a^h) - V_{\pi_f}^h(x^h)] = [f^h(x^h) - V_{\pi_f}^h(x^h)].$

The first equation used the induction hypothesis. The second equation used the definition of Bellman error. The third equation used Proposition 18.7. The last equation used $a^h = \pi_f(x^h)$ and thus, by definition, $f^h(x^h, a^h) = f^h(x^h)$. $\square$

## Assumption 18.12

Given a candidate value function class $\mathcal{F}$ of functions $f = \{f^h(x^h, a^h) : \mathcal{X} \times \mathcal{A} \to \mathbb{R}\}$, with $f^{H+1}(\cdot) = 0$, we assume that (realizable assumption)

$Q_* = f_* \in \mathcal{F}.$

Moreover, we assume that $f^1(x^1) \in [0,1]$ and $r^h + f^{h+1}(x^{h+1}) \in [0,1]$ $(h \ge 1)$.

Bellman error plays an important role in the analysis of reinforcement learning algorithms. For a value function-based approach to reinforcement learning, we would like to approximate Bellman error by minimizing least squares loss

$(f^h(x^h, a^h) - r^h - f^{h+1}(x^{h+1}))^2. \tag{18.2}$

By taking conditional expectation with respect to $(x^h, a^h)$, we obtain $\mathbb{E}_{r^h, x^{h+1} | x^h, a^h}(f^h(x^h, a^h) - r^h - f^{h+1}(x^{h+1}))^2 = \mathcal{E}^h(f, x^h, a^h)^2 + \mathbb{E}_{r^h, x^{h+1} | x^h, a^h}\left(\underbrace{r^h + f^{h+1}(x^{h+1}) - (\mathcal{T}^\sharp f)(x^h, a^h)}_{f\text{-dependent zero-mean noise}}\right)^2.$

A candidate value function class $\mathcal{F}$ is complete with respect to another candidate value function class $\mathcal{G}$ if for any $h \in [H]$, $f \in \mathcal{F}$, there exists $g \in \mathcal{G}$ so that for all $h \in [H]$, $$ g^h(x^h,a^h)=(\mathcal{T}^h f)(x^h,a^h)=\mathbb{E}_{r^h,x^{h+1}|x^h,a^h}\big[r^h+f^{h+1}(x^{h+1})\big]. $$ We say $\mathcal{F}$ is complete if $\mathcal{F}$ is complete with respect to itself.

Note that if $\mathcal{F}$ is complete with respect to $\mathcal{G}$, then we may use the solution of $$ \min_{g^h\in\mathcal{G}^h}\sum_{s=1}^t\big(g^h(x_s^h,a_s^h)-r_s^h-f^{h+1}(x_s^{h+1})\big)^2 $$ to estimate $(\mathcal{T}^h f)(x^h,a^h)$, which can be used to cancel the variance term in (18.2). ## Theorem 18.14

Assume that assumption 18.12 holds, $\mathcal{F}$ is complete with respect to $\mathcal{G}$, and $g^h(\cdot)\in[0,1]$ for all $g\in\mathcal{G}$. Consider (18.3), and let $$ \mathcal{F}_t=\Big\{f\in\mathcal{F}:\sup_{g\in\mathcal{G}}\sum_{h=1}^H\sum_{s=1}^t L^h\big(f,g,x_s^h,a_s^h,r_s^h,x_s^{h+1}\big)\le\beta_t^2\Big\}, $$ where $$ \beta_t^2\ge4\epsilon t(4+\epsilon)H+2\ln\big(16M(\epsilon,\mathcal{F},\|\cdot\|_\infty)^2M(\epsilon,\mathcal{G},\|\cdot\|_\infty)/\delta^2\big), $$ with $M(\cdot)$ denotes the $\|\cdot\|_\infty$ packing number, and $\|f\|_\infty=\sup_{h,x,a}|f^h(x,a)|$. Then with probability at least $1-\delta$, for all $t\le n$, $Q_*\in\mathcal{F}_t$ and for all $f\in\mathcal{F}_t$, $$ \sum_{s=1}^t\sum_{h=1}^H\mathcal{E}^h(f,x_s^h,a_s^h)^2\le4\beta_t^2. $$

Proof Let $\mathcal{F}_\epsilon$ be an $\epsilon\|\cdot\|_\infty$ packing subset of $\mathcal{F}$ of size $M_1$, and let $\mathcal{G}_\epsilon$ be an $\epsilon\|\cdot\|_\infty$ packing subset of $\mathcal{G}$ of size $M_2$. For all $f\in\mathcal{F}$ and $g\in\mathcal{G}$ (or $g\in\mathcal{F}$), we introduce the simplified notations $$ \epsilon_s^h(f)=r_s^h+f^{h+1}(x_s^{h+1})-(\mathcal{T}^h f)(x_s^h,a_s^h), $$ $$ \Delta_s^h(f,g)=\big((\mathcal{T}^h f)(x_s^h,a_s^h)-g^h(x_s^h,a_s^h)\big). $$ We have the following sub-Gaussian inequality (see Lemma 2.15) for any fixed $f_\epsilon\in\mathcal{F}_\epsilon$, $h\in[H]$, and $\rho\in\mathbb{R}$: $$ \ln\mathbb{E}_{r^h,x^{h+1}|x_s^h,a_s^h}\exp(\rho\epsilon_s^h(f_\epsilon))\le\frac{\rho^2}{8}. $$

Using this logarithmic moment generating function, we can now obtain the following statement from Theorem 13.11, by taking a uniform bound over $\mathcal{G}_\epsilon \times \mathcal{F}_\epsilon$, and consider both under- and overestimation (for the absolute value on the left-hand side). With probability at least $1-\delta/2$, for all $f_\epsilon \in \mathcal{F}_\epsilon$, $g_\epsilon \in \mathcal{G}_\epsilon$ and $t \ge 0$,

$$\underbrace{\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f_\epsilon,g_\epsilon)\epsilon_s^h(f_\epsilon)}_{A}\leq \sum_{s=1}^{t}\sum_{h=1}^{H}\frac{\Delta_s^h(f_\epsilon,g_\epsilon)^2}{8}+\ln(4M_1M_2/\delta). \tag{18.4}$$

In the following, for each $f \in \mathcal{F}$, we choose $f_\epsilon \in \mathcal{F}_\epsilon$ so that $\|f-f_\epsilon\|_\infty \leq \epsilon$. Similarly, for each $g \in \mathcal{G}$, we choose $g_\epsilon \in \mathcal{G}_\epsilon$ so that $\|g-g_\epsilon\|_\infty \leq \epsilon$. Then

$$\begin{aligned}
\left|\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g)\epsilon_s^h(f)\right|
&\leq \left|\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g_\epsilon)\epsilon_s^h(f_\epsilon)\right|+2\epsilon\sum_{s=1}^{t}\sum_{h=1}^{H}|\Delta_s^h(f,g)|\\
&\leq \left|\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g_\epsilon)\epsilon_s^h(f_\epsilon)\right|+4H\epsilon t.
\end{aligned}$$

The first inequality used $|\epsilon_s^h(f)-\epsilon_s^h(f_\epsilon)|\leq 2\epsilon$. The second inequality used the $\epsilon$-covering property $|\Delta_s^h(f,g)-\Delta_s^h(f,g_\epsilon)|\leq 2\epsilon$, $|\epsilon_s^h(f_\epsilon)|\leq 1$, and $|\Delta_s^h(f,g)|\leq 1$. We also have

$$\begin{aligned}
A &\leq \frac{1}{8}\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f_\epsilon,g_\epsilon)^2+\ln(4M_1M_2/\delta)\\
&\leq \frac{1}{8}\sum_{s=1}^{t}\sum_{h=1}^{H}\bigl(\Delta_s^h(f,g)+2\epsilon\bigr)^2+\ln(4M_1M_2/\delta)\\
&\leq \frac{1}{4}\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g)^2+\epsilon^2Ht+\ln(4M_1M_2/\delta).
\end{aligned}$$

The first inequality used (18.4). The second inequality used the $\epsilon$-covering property $|\Delta_s^h(f,g)-\Delta_s^h(f,g_\epsilon)|\leq 2\epsilon$. The last inequality used standard algebra inequalities $|a+2\epsilon|^2/8\leq (a^2/4)+\epsilon^2$ to simplify the terms.

That is, we have shown that with probability at least $1-\delta/2$, for all $f\in\mathcal{F}$ and $g\in\mathcal{G}$ and $t\geq 0$,

$$\left|\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g)\epsilon_s^h(f)\right|\leq \frac{1}{4}\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_s^h(f,g)^2+\epsilon tH(4+\epsilon)+\ln(4M_1M_2/\delta). \tag{18.5}$$

Similarly, with probability at least $1-\delta/2$, for all $f\in\mathcal{F}$ and $t\geq 0$,

$$\left|\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_{s}^{h}(f,f)\epsilon_{s}^{h}(f)\right|\le\frac{1}{4}\sum_{s=1}^{t}\sum_{h=1}^{H}\Delta_{s}^{h}(f,f)^{2}
+ \epsilon t H(4+\epsilon)+\ln(4M_{1}/\delta).\tag{18.6}$$

We have with probability at least $1-\delta$, both (18.5) and (18.6) hold. We obtain with probability at least $1-\delta$, for all $t\ge0$, $f\in\mathcal{F}$, $g\in\mathcal{G}$,

$$\left|\sum_{h=1}^{H}\sum_{s=1}^{t}[\Delta_{s}^{h}(f,f)-\Delta_{s}^{h}(f,g)]\epsilon_{s}^{h}(f)\right|
\le\frac{1}{4}\sum_{h=1}^{H}\sum_{s=1}^{t}[\Delta_{s}^{h}(f,f)^{2}+\Delta_{s}^{h}(f,g)^{2}]+0.5\beta_{t}^{2}.\tag{18.7}$$

Therefore

$$\sum_{s=1}^{t}\sum_{h=1}^{H}L^{h}(f,g,x_{s}^{h},a_{s}^{h},r_{s}^{h},x_{s}^{h+1})
=\sum_{s=1}^{t}\sum_{h=1}^{H}[\Delta_{s}^{h}(f,f)^{2}-\Delta_{s}^{h}(f,g)^{2}+2[\Delta_{s}^{h}(f,f)-\Delta_{s}^{h}(f,g)]\epsilon_{s}^{h}(f)]
\ge\sum_{s=1}^{t}\sum_{h=1}^{H}[0.5\Delta_{s}^{h}(f,f)^{2}-1.5\Delta_{s}^{h}(f,g)^{2}]-\beta_{t}^{2},\qquad\text{(by (18.7))}$$

and

$$\sum_{s=1}^{t}\sum_{h=1}^{H}L^{h}(Q_{*},g,x_{s}^{h},a_{s}^{h},r_{s}^{h},x_{s}^{h+1})
=\sum_{s=1}^{t}\sum_{h=1}^{H}[\Delta_{s}^{h}(Q_{*},Q_{*})^{2}-\Delta_{s}^{h}(Q_{*},g)^{2}+2[\Delta_{s}^{h}(Q_{*},Q_{*})-\Delta_{s}^{h}(Q_{*},g)]\epsilon_{s}^{h}(f)]
\le\sum_{s=1}^{t}\sum_{h=1}^{H}[1.5\Delta_{s}^{h}(Q_{*},Q_{*})^{2}-0.5\Delta_{s}^{h}(Q_{*},g)^{2}]+\beta_{t}^{2}.\qquad\text{(by (18.7))}$$

Taking sup over $g\in\mathcal{G}$, and note that $\Delta_{s}^{h}(Q_{*},Q_{*})=0$, and that $\mathcal{F}$ is complete with respect to $\mathcal{G}$, we obtain

$$\sup_{g\in\mathcal{G}}\sum_{s=1}^{t}\sum_{h=1}^{H}L^{h}(Q_{*},g,x_{s}^{h},a_{s}^{h},r_{s}^{h},x_{s}^{h+1})\le\beta_{t}^{2},$$

$$\sup_{g\in\mathcal{G}}\sum_{s=1}^{t}\sum_{h=1}^{H}L^{h}(f,g,x_{s}^{h},a_{s}^{h},r_{s}^{h},x_{s}^{h+1})\ge0.5\sum_{s=1}^{t}\sum_{h=1}^{H}\underbrace{\Delta_{s}^{h}(f,f)^{2}}_{\mathcal{E}^{h}(f,x_{s}^{h},a_{s}^{h})^{2}}-\beta_{t}^{2}.$$

In the two displayed inequalities, the first implies that $Q_{*}\in\mathcal{F}_{t}$. The second implies that if $f\in\mathcal{F}_{t}$, then

$$\beta_{t}^{2}\ge0.5\sum_{s=1}^{t}\sum_{h=1}^{H}\mathcal{E}^{h}(f,x_{s}^{h},a_{s}^{h})^{2}-\beta_{t}^{2},$$

which implies the second result of the theorem.
