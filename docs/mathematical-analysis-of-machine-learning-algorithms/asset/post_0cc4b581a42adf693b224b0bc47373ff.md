
Using this representation, we have

$$\hat f(x)=\begin{bmatrix}\langle\hat w,\psi(x,1)\rangle\\ \vdots\\ \langle\hat w,\psi(x,q)\rangle\end{bmatrix}=\sum_{i=1}^{n}\begin{bmatrix}\langle[\psi(X_i,1),\ldots,\psi(X_i,q)]\tilde{\alpha}_i,\psi(x,1)\rangle\\ \vdots\\ \langle[\psi(X_i,1),\ldots,\psi(X_i,q)]\tilde{\alpha}_i,\psi(x,q)\rangle\end{bmatrix}=\sum_{i=1}^{n}k(x,X_i)\tilde{\alpha}_i.$$

and

$$\langle\hat w,\hat w\rangle=\sum_{i=1}^{n}\left\langle[\psi(X_i,1),\ldots,\psi(X_i,q)]\tilde{\alpha}_i,\sum_{j=1}^{n}[\psi(X_j,1),\ldots,\psi(X_j,q)]\tilde{\alpha}_j\right\rangle=\sum_{i=1}^{n}\sum_{j=1}^{n}\tilde{\alpha}_i^{\mathsf T}K(X_i,X_j)\tilde{\alpha}_j.$$

This implies that $Q_1(\hat w)=Q_2(\tilde\alpha)$. Similarly, there exists $\tilde w$ such that $Q_1(\tilde w)=Q_2(\hat\alpha)$. Therefore $Q_1(\hat w)=Q_2(\tilde\alpha)\ge Q_2(\hat\alpha)=Q_1(\tilde w)$. This implies that $\tilde w$ is a solution of (9.15), which proves the result.

In order to obtain generalization analysis using Rademacher complexity for vector-valued functions, we can employ the following generalization of Theorem 6.28. The proof is similar to that of Lemma 6.29.

### Theorem 9.30

Consider $L(p,y)$ that is $\gamma_1$-Lipschitz in $p$ with respect to the $L_1$-norm:

$$|L(p,y)-L(p',y)|\le \gamma_1\|p-p'\|_1.$$

Consider

$$\mathcal G=\left\{L([f_1(x),\ldots,f_q(x)],y):f_j(x)\in\mathcal F_j\ (j=1,\ldots,q)\right\},$$

then

$$R(\mathcal G,\mathcal S_n)\le \gamma_1\sum_{j=1}^{q}R(\mathcal F_j,\mathcal S_n).$$

For vector kernel method, we may consider the hard-constrained version using feature representation:

$$\hat w=\underset{w\in\mathcal H}{\arg\min}\ \frac{1}{n}\sum_{i=1}^{n}L(\langle w,\psi(X_i,\cdot)\rangle,Y_i)\quad\text{subject to }\langle w,w\rangle\le A^2. \tag{9.17}$$

We have the following estimate of Rademacher complexity.

### Lemma 9.31

Let

$$\mathcal G=\left\{L(\langle w,\psi(x,\cdot)\rangle,y):\langle w,w\rangle\le A^2\right\},$$

then with $\gamma_1$ defined in Theorem 9.30,

$$R(\mathcal{G},\mathcal{S}_n) \le \frac{\gamma_1 A}{n}\sum_{j=1}^{q}\sqrt{\sum_{i=1}^{n} k_{j,j}(X_i,X_i)}$$

and

$$R_n(\mathcal{G},\mathcal{D}) \le \gamma_1 A\sum_{j=1}^{q}\sqrt{\frac{1}{n}\mathbb{E}_{\mathcal{D}} k_{j,j}(X,X)}.$$

**Proof.** We can set $\mathcal{F}_j=\{\langle w,\psi(x,j)\rangle\mid\langle w,w\rangle\le A^2\}$. From Theorem 9.20, we obtain

$$R(\mathcal{F}_j,\mathcal{S}_n)\le \frac{A}{n}\sqrt{\sum_{i=1}^{n} k_{j,j}(X_i,X_i)}.$$

and

$$R_n(\mathcal{F}_j,\mathcal{D})\le A\sqrt{\frac{1}{n}\mathbb{E}_{\mathcal{D}}k_{j,j}(X,X)}.$$

We can now apply Theorem 9.30 to obtain the desired bound. $\square$

If $k_{j,j}(x,x)\le B^2$ for all $j$ and $x$, then Corollary 9.31 implies a bound

$$R(\mathcal{G},\mathcal{S}_n)\le \frac{\gamma_1 qAB}{\sqrt{n}}.$$

One drawback of this bound is that the Rademacher complexity becomes linear in $q$, which is usually suboptimal when $q$ is large. For such problems, one needs a more sophisticated estimation of Rademacher complexity.

### Example 9.32

Consider the structured SVM loss function (Tsochantaridis et al., 2005) for $q$-class classification problem, with $y\in\{1,\ldots,q\}$, and for $f\in\mathbb{R}^q$,

$$L(f,y)=\max_{\ell}\left[\gamma(y,\ell)-(f_y-f_\ell)\right],$$

where $\gamma(y,y)=0$ and $\gamma(y,\ell)\ge 0$. This loss tries to separate the true class $y$ from alternative $\ell\ne y$ with margin $\gamma(y,\ell)$. It is Lipschitz with respect to $\|f\|_1$ with $\gamma_1=1$. Therefore for problems with $k_{\ell,\ell}(x,x)\le B^2$ for all $x$ and $\ell$, we have from Corollary 9.31 that

$$R(\mathcal{G},\mathcal{S}_n)\le \frac{qAB}{\sqrt{n}}.$$

For the structured SVM loss, a better bound on Rademacher complexity, stated in Proposition 9.33, can be obtained from the covering number estimate of Theorem 5.20. The bound depends on $q$ only logarithmically, and we leave its proof as an exercise.

### Proposition 9.33

Consider a loss function $L(f,y)$ that is $\gamma_\infty$-Lipschitz in $p$ with respect to the $L_\infty$-norm:

$$|L(p,y)-L(p',y)| \leq \gamma_\infty\|p-p'\|_\infty.$$

Let $\mathcal{F}=\{f(x)=[f_1(x),\ldots,f_q(x)]: f_\ell(x)=\langle w,\psi(x,\ell)\rangle,\ \langle w,w\rangle\leq A^2\}$. Assume that $\sup_{x,\ell}\|\psi(x,\ell)\|\leq B^2$. Let $\mathcal{G}=\{L(f,y):f\in\mathcal{F}\}$. Then there exists a constant $c_0>0$ such that

$$R(\mathcal{G},S_n)\leq \frac{c_0\gamma_\infty AB\ln n\sqrt{\ln(nq)}}{\sqrt{n}}.$$

One may also consider the soft-regularized version of structured SVM

$$\hat{w}=\arg\min_w\left[\frac{1}{n}\sum_{i=1}^{n}L(\langle w,\psi(X_i,\cdot)\rangle,Y_i)+\frac{\lambda}{2}\langle w,w\rangle\right],$$

and analyze it using the stability analysis of Chapter 7. In fact, it can be easily checked that $L(\langle w,\psi(x,\cdot)\rangle,y)$ is $B$-Lipschitz in $w$ when $\sup_{x,\ell}\|\psi(x,\ell)\|_2\leq B$. Theorem 7.8 implies that for the structured SVM problem, we have an expected generalization bound of

$$\mathbb{E}_{S_n}\mathbb{E}_{D}L(\langle\hat{w},\psi(X)\rangle,Y)\leq\inf_w\left[\mathbb{E}_{D}L(\langle w,\psi(X)\rangle,Y)+\frac{\lambda}{2}\langle w,w\rangle\right]+\frac{B^2}{\lambda n}.$$

The structured SVM example shows that for some vector-valued estimation problems, stability analysis can be used to obtain results that may be more difficult to obtain using the theory of empirical processes.

## 9.5 Refined Analysis: Ridge Regression

Although the Rademacher complexity analysis leads to useful generalization results, they are not always tight. Moreover, to obtain a faster rate, we need to employ local Rademacher complexity analysis, as discussed in Section 6.5.

For the ridge regression problem,

$$\hat{w}=\arg\min_w\left[\frac{1}{n}\sum_{i=1}^{n}(w^\top\psi(X_i)-Y_i)^2+\lambda w^\top w\right], \tag{9.18}$$

we show that it is possible to obtain faster rates more directly. Here we use the vector notation $u^\top v=\langle u,v\rangle$ for convenience.

For simplicity, we will consider the realizable case in that there exists $w_*$ such that

$$Y=w_*^\top\psi(X)+\epsilon, \tag{9.19}$$

where $\epsilon$ is a zero-mean stochastic noise that may depend on $X$.

The following basic result is useful in the theoretical analysis of ridge regression.

It follows that if $\operatorname{Var}(\epsilon_i\mid X_i)\leq\sigma^2$, then

$$\begin{aligned}
\mathbb{E}\left[(\hat{w}^{\mathsf T}\psi(X)-w_*^{\mathsf T}\psi(X))^2\mid\{X_i\}_{1}^{n}\right]
&=\frac{1}{n^2}\sum_{i=1}^{n}\mathbb{E}\left[(a_i\epsilon_i)^2\mid X_i\right]+\lambda^2\left[\psi(X)^{\mathsf T}\hat{\Sigma}_{\lambda}^{-1}w_*\right]^2\\
&\leq\frac{1}{n^2}\sum_{i=1}^{n}a_i^2\sigma^2+\lambda^2\left[\psi(X)^{\mathsf T}\hat{\Sigma}_{\lambda}^{-1}w_*\right]^2\\
&\leq\frac{\sigma^2}{n}\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}^2+\lambda^2\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}^2\|w_*\|_{\hat{\Sigma}_{\lambda}^{-1}}^2\\
&\leq\left((\sigma^2/n)+\lambda\|w_*\|_2^2\right)\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}^2.
\end{aligned}$$

The first equality used (9.20), and the fact that $\epsilon_i$ are independent and zero-mean random variables. The first inequality used $\mathbb{E}[\epsilon_i^2]\leq\sigma^2$. The second inequality used (9.21) and the Cauchy–Schwarz inequality. The last inequality used $\|w_*\|_{\hat{\Sigma}_{\lambda}^{-1}}^2\leq\|w_*\|_2^2/\lambda$.

Moreover, if each $\epsilon_i$ is sub-Gaussian, then

$$\begin{aligned}
\ln\mathbb{E}\left[e^{\mu(\hat{w}^{\mathsf T}\psi(X)-w_*^{\mathsf T}\psi(X))}\mid\{X_i\}_{1}^{n}\right]
&=-\mu\lambda\psi(X)^{\mathsf T}\hat{\Sigma}_{\lambda}^{-1}w_*+\ln\mathbb{E}\left[e^{(\mu/n)\sum_{i=1}^{n}a_i\epsilon_i}\mid\{X_i\}_{1}^{n}\right]\\
&\leq-\mu\lambda\psi(X)^{\mathsf T}\hat{\Sigma}_{\lambda}^{-1}w_*+\frac{\mu^2\sigma^2}{2n^2}\sum_{i=1}^{n}a_i^2\\
&\leq\mu\lambda\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}\|w_*\|_{\hat{\Sigma}_{\lambda}^{-1}}+\frac{\mu^2\sigma^2}{2n}\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}^2\\
&\leq\mu\sqrt{\lambda}\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}\|w_*\|_2+\frac{\mu^2\sigma^2}{2n}\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}^2.
\end{aligned}$$

The first equality used (9.20). The first inequality used the sub-Gaussian noise assumption. The second inequality used (9.21) and the Cauchy–Schwarz inequality. The last inequality used $\|w_*\|_{\hat{\Sigma}_{\lambda}^{-1}}\leq\|w_*\|_2/\sqrt{\lambda}$. This implies that $\hat{w}^{\mathsf T}\psi(X)-w_*^{\mathsf T}\psi(X)$ is sub-Gaussian. The desired probability bounds follow from the standard sub-Gaussian tail inequalities in Theorem 2.12.

Lemma 9.34 implies that the model confidence at an arbitrary test data point $X$ is proportional to $\|\psi(X)\|_{\hat{\Sigma}_{\lambda}^{-1}}$. This means that for ridge regression, one can obtain a confidence interval at any data point $X$. In particular, if we are interested in estimating $w_*^{\mathsf T}\psi(X_i)$ for all $X_i$ in the training data, then by taking the union bound over $\{X_1,\ldots,X_n\}$, we obtain with probability $1-\delta$,

$$\frac{1}{n}\sum_{i=1}^{n}(\hat{w}^{\mathsf T}\psi(X_i)-w_*^{\mathsf T}\psi(X_i))^2=O\left(\left(\lambda\|w_*\|_2^2+\frac{\sigma^2\ln(n/\delta)}{n}\right)\operatorname{trace}\left(\hat{\Sigma}_{\lambda}^{-1}\hat{\Sigma}_0\right)\right).$$

One can also use a generalization of the $\chi^2$ tail probability bound to obtain a bound on the training prediction error more directly without paying a $\ln n$ penalty due to the union bound.
