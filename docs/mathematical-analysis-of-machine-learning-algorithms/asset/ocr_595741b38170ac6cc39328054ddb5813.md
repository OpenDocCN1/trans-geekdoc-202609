A strongly convex function may not be differentiable. An example is the one-dimensional function $\phi(w)=|w|+0.5w^2$, which is $\lambda=1$ strongly convex, but not differentiable at $w=0$. The following definition is frequently used in theoretical analysis. It can be applied even for nonconvex functions.

**Definition A.5**  A function $\phi(w)$ (which may not necessarily be convex) on $\Omega$ is $L$-smooth if it is differentiable and for all $w,w'\in\Omega$, $$\|\nabla\phi(w')-\nabla\phi(w)\|_2\leq L\|w-w'\|_2.$$ We say $\phi(w)$ is $G$-Lipschitz if for all $w\in\Omega$, $$\|\nabla\phi(w)\|_2\leq G.$$

**Proposition A.6**  If $\phi(w)$ is $L$-smooth, then for any $w,w'\in\Omega$, $$\nabla\phi(w')\leq \phi(w)+\nabla\phi(w)^\top(w'-w)+\frac{L}{2}\|w-w'\|_2^2,$$ and $\|\nabla^2\phi(w)\|_2\leq L$. If $\phi$ is $G$-Lipschitz, then for any $w,w'\in\Omega$, $$|\phi(w)-\phi(w')|\leq G\|w-w'\|_2.$$

# A.2 Basic Properties

We list some results for convex functions that are useful in the analysis of this book.

**Proposition A.7**  If $\phi(w)$ is $L$-smooth on $\mathbb{R}^d$, then for all $w,w'\in\mathbb{R}^d$, $$\|\nabla\phi(w')-\nabla\phi(w)\|_2^2\leq 2L\left[\phi(w)-\phi(w')-\nabla\phi(w')^\top(w-w')\right].$$

*Proof*  Let $$\widetilde{\phi}(w)=\phi(w)-\phi(w')-\nabla\phi(w')^\top(w-w').$$ Then $\widetilde{\phi}(w)$ is $L$-smooth, and $\widetilde{\phi}(w)\geq 0$ due to convexity. Let $\eta=1/L$, then $$0\leq \widetilde{\phi}(w-\eta\nabla\phi(w))$$ $$\leq \widetilde{\phi}(w)-\eta\nabla\phi(w)^\top\nabla\widetilde{\phi}(w)+\frac{\eta^2L}{2}\|\nabla\widetilde{\phi}(w)\|_2^2$$ $$=\widetilde{\phi}(w)-\frac{1}{2L}\nabla\widetilde{\phi}(w)^\top\nabla\widetilde{\phi}(w).$$ The second inequality used Proposition A.6. This implies the desired bound. □
