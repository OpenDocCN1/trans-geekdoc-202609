We have

$$\begin{aligned}
\sum_{i=1}^{n}L(f^{(t)}(X_i),Y_i)
&=\sum_{i=1}^{n}L\big((1-\eta_t)f^{(t-1)}(X_i)+\eta_t\psi(\theta_t,X_i),Y_i\big)\\
&\le \sum_{i=1}^{n}\left[L(f^{(t-1)}(X_i),Y_i)+\eta_t g_i\big(\psi(\theta_t,X_i)-f^{(t-1)}(X_i)\big)\right]\\
&\quad+\frac{\eta_t^2\gamma}{2}\sum_{i=1}^{n}\big(\psi(\theta_t,X_i)-f^{(t-1)}(X_i)\big)^2\\
&\le \sum_{i=1}^{n}\left[L(f^{(t-1)}(X_i),Y_i)+\eta_tg_i\big(f(X_i)-f^{(t-1)}(X_i)\big)\right]+\frac{n\eta_t^2\gamma B^2}{2}+\frac{n\eta_t^2\gamma}{2}4B^2\\
&\le \sum_{i=1}^{n}L(f^{(t-1)}(X_i),Y_i)+\eta_t\big(L(f(X_i),Y_i)-L(f^{(t-1)}(X_i),Y_i)\big)+\frac{5n\eta_t^2\gamma B^2}{2}.
\end{aligned}$$

The first inequality used $\gamma$-smoothness of $L(f,y)$ with respect to $f$, so that $L(f',y)\le L(f,y)+L_1'(f,y)(f'-f)+0.5\gamma(f'-f)^2$. The second inequality used (10.18). The third inequality used the convexity of $L(f,y)$ with respect to $f$, so that $L(f,y)+L_1'(f,y)(f'-f)\le L(f',y)$. Let

$$\beta_t=\frac{1}{n}\sum_{i=1}^{n}L(f^{(t)}(X_i),Y_i)-\frac{1}{n}\sum_{i=1}^{n}L(f(X_i),Y_i),$$

then we have shown with $\eta_t=2/(t+1)$,

$$\beta_t\le\frac{t-1}{t+1}\beta_{t-1}+\frac{10\gamma B^2}{(t+1)^2}.$$

Now multiply by $t(t+1)$, and we have

$$(t+1)t\beta_t\le(t-1)t\beta_{t-1}+10\gamma B^2.$$

By summing over $t=1,2,3,\ldots,T$, we obtain the desired bound. $\square$

Algorithm 10.3 can be extended to solve hard-constrained $L_1$ regularization problem of the form $\lVert w\rVert_1\le A$. However this requires knowing $A$ in advance. One may also use gradient boosting to solve the sparse approximation problem in the more general setting without specifying $A$. While results can be obtained for the original gradient boosting algorithm in Algorithm 10.2, a stronger convergence result can be obtained for a slight modification referred to as the fully corrective gradient boosting algorithm (see Shalev-Shwartz et al., 2010).

# **Theorem 10.32** (Shalev-Shwartz et al., 2010) *Assume that $L(p,y)$ is convex and $\gamma$ smooth in $p$. Then at time $T$, the solution $f^{(T)}$ of Algorithm 10.4 satisfies*

$$\sum_{i=1}^{n}L(f^{(T)}(X_i),Y_i)\le\inf_{f\in\mathcal{F}_{L_1}(\Psi)}\left[\sum_{i=1}^{n}L(f(X_i),Y_i)+\frac{2\gamma\lVert f\rVert_1^2B^2}{T}\right],$$

where $B^2=\sup_{\theta}\sum_{i=1}^{n}\psi(\theta,X_i)^2$.
