# **Theorem 18.9**  *The optimal $Q$-function $Q_*$ satisfies the Bellman equation:*

$$Q_*^h(x^h,a^h)=\mathbb{E}_{r^h,x^{h+1}\mid x^h,a^h}\left[r^h+V_*^{h+1}(x^{h+1})\right].$$

*The optimal value function satisfies*

$$V_*^h(x^h)=\max_{a\in\mathcal{A}}Q_*^h(x^h,a),$$

and the optimal value function can be achieved using a deterministic greedy policy $\pi_*$:

$$\pi_*^h(x^h)\in\arg\max_{a\in\mathcal{A}}Q_*^h(x^h,a).$$

Theorem 18.9 motivates the following definition of Bellman error for reinforcement learning.

# **Definition 18.10** We say $f$ is a candidate $Q$-function if $f=\{f^h(x^h,a^h):\mathcal{X}\times\mathcal{A}\to\mathbb{R}:h\in[H+1]\}$, with $f^{H+1}(\cdot)=0$. Define

$$f^h(x^h)=\arg\max_{a\in\mathcal{A}}f^h(x^h,a),$$

and define its greedy policy $\pi_f$ as a deterministic policy that satisfies

$$\pi_f^h(x^h)\in\arg\max_{a\in\mathcal{A}}f^h(x^h,a).$$

Given an MDP $M$, we also define the Bellman operator of $f$ as

$$(\mathcal{T}^h f)(x^h,a^h)=\mathbb{E}_{r^h,x^{h+1}\mid x^h,a^h}\left[r^h+f^{h+1}(x^{h+1})\right],$$

and its Bellman error as

$$\mathcal{E}^h(f,x^h,a^h)=f^h(x^h,a^h)-(\mathcal{T}^h f)(x^h,a^h),$$

where the conditional expectation is with respect to the MDP $M$.

Theorem 18.9 implies that

$$\mathcal{E}^h(Q_*,x^h,a^h)=0,\quad \forall h\in[H].$$

The following theorem shows that the difference of the true value of policy $\pi_f$ and the candidate value function $f^1(x^1)$ are close if (and only if) the average Bellman error is small along the path generated by $\pi_f$. Since Bellman error can be evaluated on real data, we can use this decomposition to design reinforcement algorithms and obtain their regret bounds.

# **Theorem 18.11**  *Consider any candidate value function $f=\{f^h(x^h,a^h):\mathcal{X}\times\mathcal{A}\to\mathbb{R}\}$, with $f^{H+1}(\cdot)=0$. Let $\pi_f$ be its greedy policy. Then*

$$\left[f^1(x^1)-V_{\pi_f}^1(x^1)\right]=\mathbb{E}_{(x,a,r)\sim\pi_f\mid x^1}\left[\sum_{h=1}^{H}\mathcal{E}^h(f,x^h,a^h)\right].$$
