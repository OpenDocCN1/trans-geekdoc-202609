We have

$$\begin{aligned}
\mathbb{E}\sum_{t=2}^{T}\left[V_*^1(x_t^1)-V_{\pi_t}^1(x_t^1)\right]
&=\mathbb{E}\sum_{t=2}^{T}[f_{\mathcal{M}_*}-f_{\mathcal{M}_t}]+\mathbb{E}\sum_{t=2}^{T}\sum_{h=1}^{H}\epsilon^h(\mathcal{M}_t,x_t^h,a_t^h)\\
&\le \mathbb{E}\sum_{t=2}^{T}[f_{\mathcal{M}_*}-f_{\mathcal{M}_t}]+\sqrt{\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\epsilon,\mathcal{M},T)\sum_{t=2}^{T}\left(\epsilon H+\mathbb{E}\sum_{s=1}^{t-1}\sum_{h=1}^{H}L_s^h(\mathcal{M}_t)\right)}\\
&\le \mathbb{E}\sum_{t=2}^{T}[f_{\mathcal{M}_*}-f_{\mathcal{M}_t}]+\frac{1}{\lambda}\mathbb{E}\sum_{t=2}^{T}\sum_{s=1}^{t-1}\sum_{h=1}^{H}\hat L_s^h(\mathcal{M}_t)+\frac{\lambda}{4}\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\epsilon,\mathcal{M},T)\\
&\qquad+\sqrt{\epsilon HT\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\epsilon,\mathcal{M},T)}\\
&\le \frac{T}{\lambda}\kappa(\lambda,H,T,\mathcal{M})+\frac{\lambda}{4}\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\epsilon,\mathcal{M},T)+\sqrt{\epsilon HT^2\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\epsilon,\mathcal{M},T)}.
\end{aligned}$$

The first equality used Theorem 18.38. The first inequality follows from the definition of Bellman eluder coefficient in Definition 18.39. The second inequality follows from simple algebra. The last inequality follows from Lemma 18.46.

We note that in Theorem 18.47, $\kappa$ behaves like the sample complexity caused by covering numbers. By optimizing $\lambda$, the resulting regret bound becomes

$$O\left(\sqrt{T\,\mathbb{E}\mathcal{C}_{Q-\mathrm{Hel}}(\cdot)\cdot\kappa(\cdot)}\right).$$

This is comparable to the result for the value-targeted approach. However, as we have pointed out, the Hellinger Bellman eluder coefficient is never larger than value-targeted Hellinger Bellman eluder coefficient. Therefore it can be applied to more general settings. We also observe from Lemma 18.45 that instead of using the KL ball to define $\kappa(\cdot)$, we may also use the Hellinger-ball, with a logarithmic penalty in terms of $\rho$. To achieve this in the general setting, we may simply add a small constant to each conditional probability model to avoid negative infinity model log-likelihood, so that $\rho$ is not large.
