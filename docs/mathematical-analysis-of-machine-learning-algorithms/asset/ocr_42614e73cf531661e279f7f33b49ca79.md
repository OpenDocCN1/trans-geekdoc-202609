# **Proposition 14.3** *Consider Algorithm 14.2, with s chosen uniformly at random from 0 to T − 1. If Zₜ = (Xₜ, Yₜ) ∼ 𝒟 are iid observations, then we have*

$$\mathbb{E}_{S_{T-1}}\,\mathbb{E}_{Z\sim\mathcal{D}}\mathbf{1}(\hat{y}(w_s,X)\ne Y) \\ \le \inf_{\gamma>0,w}\left[2\mathbb{E}_{Z\sim\mathcal{D}}\max\left(0,1-\gamma^{-1}\min_{\ell\notin\mathcal{Y}_t}w^\top[\psi(X,Y)-\psi(X,\ell)]\right)+\frac{\lVert w\rVert_2^2\sup\{\lVert\psi(X,Y)-\psi(X,Y')\rVert_2^2\}}{\gamma^2T}\right].$$

*where the prediction rule* $\hat{y}(w,x)\in\arg\max_{\ell}w^\top\psi(x,\ell)$ *is consistent with Algorithm 14.2.*

**Proof**  We simply note that

$$\mathbb{E}_{S_{T-1}}\sum_{t=1}^{T}\mathbb{E}_{Z\sim\mathcal{D}}\mathbf{1}(\hat{y}(w_{t-1},X)\ne Y)=\mathbb{E}_{S_T}\sum_{t=1}^{T}\mathbf{1}(\hat{y}(w_{t-1},X_t)\ne Y_t),$$

and

$$\sum_{t=1}^{T}2\mathbb{E}_{Z\sim\mathcal{D}}\max\left(0,1-\gamma^{-1}\min_{\ell\notin\mathcal{Y}_t}w^\top[\psi(X,Y)-\psi(X,\ell)]\right) \\ =\mathbb{E}_{S_T}\sum_{t=1}^{T}2\max\left(0,1-\gamma^{-1}\min_{\ell\notin\mathcal{Y}_t}w^\top[\psi(X_t,Y_t)-\psi(X_t,\ell)]\right).$$

Now, a straightforward application of Theorem 14.2 implies that

$$\mathbb{E}_{S_{T-1}}\sum_{t=1}^{T}\mathbb{E}_{Z\sim\mathcal{D}}\mathbf{1}(\hat{y}(w_{t-1},X)\ne Y) \\ \le \inf_{\gamma>0,w}\left[2T\mathbb{E}_{Z\sim\mathcal{D}}\max\left(0,1-\gamma^{-1}\min_{\ell\notin\mathcal{Y}_t}w^\top[\psi(X,Y)-\psi(X,\ell)]\right)+\frac{\lVert w\rVert_2^2\sup\{\lVert\psi(X,Y)-\psi(X,Y')\rVert_2^2\}}{\gamma^2}\right].$$

This implies the desired result. □

From Chapter 13, we know that one can further employ martingale tail probability bounds to obtain a high-probability result of the following form: with probability at least $1-\delta$ over $S_T$,

$$\sum_{t=1}^{T}\mathbb{E}_{Z\sim\mathcal{D}}\phi(w_{t-1},Z)\le\sum_{t=1}^{T}\phi(w_{t-1},Z_t)+\epsilon(\delta). \tag{14.3}$$

We may combine this bound with (14.2), and obtain the following probability bound for the randomized estimator $s$, uniformly chosen from 0 to $T-1$. With probability at least $1-\delta$ over $S_T$,

$$\mathbb{E}_s\,\mathbb{E}_{Z\sim\mathcal{D}}\phi(w_s,Z)\le\frac{\epsilon(\delta)+\epsilon(S_T)}{T}.$$
