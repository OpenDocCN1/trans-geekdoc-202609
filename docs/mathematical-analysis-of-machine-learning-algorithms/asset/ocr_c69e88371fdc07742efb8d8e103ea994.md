We introduce the following definition, which plays a role similar to the concept of covering (see Example 17.32).

**Definition 18.44**  Given a model class $\mathcal{M}$ and true model $M_*$, we define the KL ball and Hellinger ball around the true model $M_*$ as

$\mathcal{M}_{\mathrm{KL}}(\epsilon)=\left\{M\in\mathcal{M}:\sup_{x^h,a^h}\mathrm{KL}\left(P_{M_*}^h(\cdot\mid x^h,a^h)\parallel P_M^h(\cdot\mid x_s^h,a_s^h)\right)^2\leq \epsilon^2\right\},$

$\mathcal{M}_{H}(\epsilon)=\left\{M\in\mathcal{M}:\sup_{x^h,a^h}H\left(P_{M_*}^h(\cdot\mid x^h,a^h)\parallel P_M^h(\cdot\mid x_s^h,a_s^h)\right)^2\leq \epsilon^2\right\}.$

We have the following result, which shows that as long as we avoid negative-infinity model log-likelihood, the Hellinger ball and KL ball are equivalent up to a log-factor specified by $\rho$.

**Lemma 18.45**  *Let*

$\rho=\sup_{M\in\mathcal{M}}\sup_{h\in[H]}\sup_{x^h,a^h,x^{h+1}}\ln\frac{dP_{M_*}(x^{h+1}\mid x^h,a^h)}{dP_M(x^{h+1}\mid x^h,a^h)}.$

We have

$\mathcal{M}_{H}\left(\epsilon/\sqrt{3+\rho}\right)\subset\mathcal{M}_{\mathrm{KL}}(\epsilon)\subset\mathcal{M}_{H}(\epsilon).$

Moreover, for any $M\in\mathcal{M}_{H}(\epsilon)$, we have

$|f_{M_*}-f_M|\leq H\epsilon.$
