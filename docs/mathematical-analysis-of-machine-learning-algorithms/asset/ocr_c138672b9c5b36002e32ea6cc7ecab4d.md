If \(b \leq \hat r/\alpha\), then

\[\epsilon_n(\mathcal{F}^h(b),\mathcal{D}) \leq \epsilon_n(\mathcal{F}^h(\hat r/\alpha),\mathcal{D}) \leq \hat r = \bar r_n^h(\alpha,\mathcal{F},\mathcal{D}).\]

Otherwise, let \(r'=ab>\hat r=r_n^h(\alpha,\mathcal{F},\mathcal{D})\). By the definition of \(r_n^h(\alpha,\mathcal{F},\mathcal{D})\), we have

\[\epsilon_n(\mathcal{F}^h(b),\mathcal{D})=\epsilon_n(\mathcal{F}^h(r'/\alpha),\mathcal{D})\leq r'=ab.\]

By combining the two situations, we obtain the desired bound. \(\square\)
