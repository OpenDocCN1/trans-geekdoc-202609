The following example gives an application of $m > 1$.

# Example 12.13

In Theorem 12.11, if we take $\Theta = [1, N]$ for $N > 2$, $Q(\theta, \mathcal{D}_j) = |\theta - j|$, and $\epsilon = 1$, then we have $m = 2$. Note that $2/N \le \ln 2 / \ln(N/2)$, we obtain the following result:

$\frac{1}{N} \sum_{j=1}^{N} \Pr_{Z \sim \mathcal{D}_j} (|\mathcal{A}(Z) - j| < 1) \le \frac{I(j, Z) + \ln 2}{\ln(N/2)}$.

The following result shows that if the distributions $\{\mathcal{D}_j\}$ are close to each other, then the mutual information $I(j, Z)$ in Theorem 12.11 is small.

# Lemma 12.14

*The mutual information $I(j, Z)$ in Theorem 12.11 satisfies the inequality*

$I(j, Z) \le \frac{1}{N^2} \sum_{j=1}^{N} \sum_{k=1}^{N} \mathrm{KL}(\mathcal{D}_j||\mathcal{D}_k) \le \sup_{j,k} \mathrm{KL}(\mathcal{D}_j||\mathcal{D}_k)$.

# Proof

We have

$I(j, Z) = \frac{1}{N} \sum_{j=1}^{N} \mathbb{E}_{Z \sim \mathcal{D}_j} \ln \frac{p_{\mathcal{D}_j}(Z)}{\frac{1}{N} \sum_{k=1}^{N} p_{\mathcal{D}_k}(Z)}$

$\le \frac{1}{N^2} \sum_{j=1}^{N} \sum_{k=1}^{N} \mathbb{E}_{Z \sim \mathcal{D}_j} \ln \frac{p_{\mathcal{D}_j}(Z)}{p_{\mathcal{D}_k}(Z)}$,

where the inequality used Jensen's inequality and the convexity of $-\ln z$.
