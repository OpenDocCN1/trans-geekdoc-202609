We can introduce a random variable $Z'$ with the same marginal distribution as $Z$, but independent of $j$:

$$p(Z')=\frac{1}{N}\sum_{j=1}^{N}p_j(Z').$$

Now, consider an arbitrary and possibly random estimator $\hat{\theta}=\mathcal{A}(Z)$. Let $\hat{\theta}'=\mathcal{A}(Z')$. By the data processing inequality for KL-divergence (see Theorem B.4), with input $(j,Z)$ and binary output $h(j,Z)=\mathbb{1}(Q(\hat{\theta},D_j)<\epsilon)$, where $\mathbb{1}(\cdot)$ is the indicator function, we obtain

$$\mathrm{KL}\bigl(\mathbb{1}(Q(\hat{\theta},D_j)<\epsilon)\,\|\,\mathbb{1}(Q(\hat{\theta}',D_j)<\epsilon)\bigr)\leq \mathrm{KL}((j,Z)\,\|\,(j,Z'))=I(j,Z).$$

Now let $q=\Pr(Q(\hat{\theta},D_j)<\epsilon)$ and $q'=\Pr(Q(\hat{\theta}',D_j)<\epsilon)$, then our inequality can be rewritten as

$$\mathrm{KL}(q\|q')=q\ln\frac{q}{q'}+(1-q)\ln\frac{1-q}{1-q'}\leq I(j,Z).$$

Since $\hat{\theta}'$ is independent of $j$, and

$$\left|\{j:Q(\hat{\theta}',D_j)<\epsilon\}\right|\leq m$$

for each $\hat{\theta}'$, we obtain

$$q'\leq m/N.$$

If $q\leq m/N$, we have proved the desired inequality. Otherwise, since $\mathrm{KL}(q\|q')$ as a function of $q'$ is decreasing in $[0,q]$, we have

$$q\ln\frac{q}{m/N}+(1-q)\ln\frac{1-q}{1-m/N}\leq I(j,Z).$$

Since $q\ln q+(1-q)\ln(1-q)\geq-\ln 2$, we obtain

$$-\ln 2+q\ln\frac{N}{m}+(1-q)\ln\frac{N}{N-m}\leq I(j,Z).$$

This implies that

$$q\leq\frac{I(j,Z)+\ln 2}{\ln(N/m)}.$$

We thus obtain the desired bound. $\square$

**Example 12.12**  In Theorem 12.11, if we take $\Theta=\{1,\ldots,N\}$, $Q(\theta,D_j)=\mathbb{1}(\theta\neq j)$, and $\epsilon=1$, then we have $m=1$. Note that $1/N\leq\ln 2/\ln(N)$, we obtain the following result

$$\frac{1}{N}\sum_{j=1}^{N}\Pr_{Z\sim D_j}(\mathcal{A}(Z)=j)\leq\frac{I(j,Z)+\ln 2}{\ln N}.$$

This implies Fano’s inequality of Theorem 12.10.
