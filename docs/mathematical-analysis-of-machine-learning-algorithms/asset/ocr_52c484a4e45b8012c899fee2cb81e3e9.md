SGD is independent of m as m → ∞, and the training process occurs in an infinitely small neighborhood of the initialization in terms of the L∞-norm as m → ∞. Assume for simplicity that h(z) is a smooth function with derivative h′(z), then we can perform a Taylor expansion in a small neighbor around [ũ, θ̃] to obtain a linear approximation around the initialization.

In the following discussion, we let w = [u, θ] and ŵ = [ũ, θ̃]. Let B∞(ŵ, r) = {w: ‖w − ŵ‖∞ ≤ r}. Let

$$f_{\mathrm{nn}}(w, x) = \frac{1}{\sqrt{m}} \sum_{j=1}^{m} u_j h(\theta_j^{\top} x),$$

and we can define its NTK approximation as

$$f_m^{\mathrm{NTK}}(w, x) = \tilde{f}_m^{\mathrm{NTK}}(x) + \frac{1}{\sqrt{m}} \sum_{j=1}^{m} \Big[ (u_j - \tilde{u}_j) h(\tilde{\theta}_j^{\top} x) + \tilde{u}_j h'(\tilde{\theta}_j^{\top} x) (\theta_j - \tilde{\theta}_j)^{\top} x \Big]. \tag{11.6}$$

When w ∈ B∞(ŵ, r) for a sufficiently small r, we have f_m^{NTK}(w, x) ≈ f_nn(w, x) and ∇_w f_m^{NTK}(w, x) ≈ ∇_w f_nn(w, x). More formally, we may impose the following assumption for μ and h.

# Assumption 11.14

For any x, δ ∈ (0, 1) and ε > 0, there exist A0 > 0, r0 > 0, and m0 > 0 such that when m > m0, with probability at least 1 − δ over random initialization, the following events hold uniformly for w ∈ B∞(ŵ, r0):

+   - |\tilde{f}_m^{NTK}(x)| ≤ A0
+   - ||∇_w f_m^{NTK}(w, x)||_2 + ||∇_w f_nn(w, x)||_2 ≤ A0
+   - |f_m^{NTK}(w, x) − f_nn(w, x)| ≤ ε
+   - ||∇_w f_m^{NTK}(w, x) − ∇_w f_nn(w, x)||_2 ≤ ε
+   - ||∇_w f_m^{NTK}(w, x)||_∞ + ||∇_w f_nn(w, x)||_∞ ≤ m^{-1/4}

The following result is not difficult to verify. We leave it as an exercise.

# Proposition 11.15

Assumption 11.14 holds for both ReLU and for sigmoid activation functions with Gaussian initialization ŵ ∼ N(0, σ²I).

Next, we will examine the property of f_m^{NTK}(w, x) when m → ∞. Observe that the NTK approximation of the neural network is linear in the model parameter w = [u, θ], with random features m^{-1/2} h(θ̃_j^⊤ x) and m^{-1/2} ũ_j h'(θ̃_j^⊤ x) x.
