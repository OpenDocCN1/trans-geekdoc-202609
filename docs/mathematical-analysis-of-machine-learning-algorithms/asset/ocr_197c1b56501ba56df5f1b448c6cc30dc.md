*Proof*  Given $S_n=\{Z_1,\ldots,Z_n\}$, let $Q=\{\phi_1,\ldots,\phi_m\}$ be a maximal $\epsilon$ $L_1(S_n)$ packing of $\mathcal{G}$. $Q$ is also an $L_1$ $\epsilon$ cover of $\mathcal{G}$. Consider the empirical distribution, denoted by $S_n$, which puts a probability of $1/n$ on each $Z_i$. We have for $j\ne k$,

$$\Pr_{Z\sim S_n}[\phi_j(Z)=\phi_k(Z)]=1-\mathbb{E}_{Z\sim S_n}|\phi_j(Z)-\phi_k(Z)|<1-\epsilon.$$

Now consider random sample with replacement from $S_n$ for $T$ times to obtain samples $\{Z_{i_1},\ldots,Z_{i_T}\}$. We have

$$\Pr(\{\forall\ell:\phi_j(Z_{i_\ell})=\phi_k(Z_{i_\ell})\})<(1-\epsilon)^T\le e^{-T\epsilon}.$$

That is, with probability larger than $1-e^{-T\epsilon}$,

$$\exists\ell:\phi_j(Z_{i_\ell})\ne\phi_k(Z_{i_\ell}).$$

Taking the union bound for all $j\ne k$, we have with probability larger than $1-\binom{m}{2}\cdot e^{-T\epsilon}$, for all $j\ne k$,

$$\exists\ell:\phi_j(Z_{i_\ell})\ne\phi_k(Z_{i_\ell}).$$

If we take $T=\lceil\ln(m^2)/\epsilon\rceil$, then $e^{-T\epsilon}\binom{m}{2}\le 1$. Then there exist $T$ samples $\{Z_{i_\ell}:\ell=1,\ldots,T\}$ such that $\phi_j\ne\phi_k$ for all $j\ne k$ when restricted to these samples. Since $\operatorname{VC}(\mathcal{G})=d$, we obtain from Sauer’s lemma,

$$m\le\max\{2,eT/d\}^d\le\max\{2,e(1+\ln(m^2)/\epsilon)/d\}^d.$$

The theorem holds automatically when $m\le 2^d$. Otherwise,

$$\ln m\le d\ln(1/\epsilon)+d\ln(\epsilon e/d)+(2e/d)\ln(m).$$

Let $u=d^{-1}\ln m-\ln(1/\epsilon)-\ln\ln(4/\epsilon)$ and let $\epsilon\le1$. We can obtain the following bound by using the upper bound of $\ln m$:

$$\begin{aligned} u&\le-\ln\ln(4/\epsilon)+\ln\left((\epsilon e/d)+2e\left(u+\ln(1/\epsilon)+\ln\ln(4/\epsilon)\right)\right)\\ &\le\ln\frac{2e(u+0.5+\ln(1/\epsilon)+\ln\ln(4/\epsilon))}{\ln(4/\epsilon)}\\ &\le\ln(4u+7), \end{aligned}$$

where the last inequality is obtained by taking sup over $\epsilon\in(0,1]$. By solving this inequality we obtain a bound $u\le3$. This implies the desired result. $\square$

It is possible to prove a slightly stronger result using a refined argument in the proof of Theorem 5.5.

**Theorem 5.6** (Haussler, 1995)  *Let $\mathcal{G}$ be a binary-valued function class with $\operatorname{VC}(\mathcal{G})=d$. Then*

$$\ln M(\epsilon,\mathcal{G},L_1(S_n))\le 1+\ln(d+1)+d\ln(2e/\epsilon).$$
