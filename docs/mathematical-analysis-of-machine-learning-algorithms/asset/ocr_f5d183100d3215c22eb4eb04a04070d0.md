$$\Omega=\left\{w:\|w\|_2\leq\sqrt{2/\lambda}\right\}$$

$$\mathbb{E}_{S_n}\phi(\mathcal{A}(S_n),\mathcal{D})\leq \inf_{w\in\mathbb{R}^d}\phi(w,\mathcal{D})+\frac{\mathbb{E}_X\left(\|\psi(X)\|_2+\sqrt{2\lambda}\right)^2}{\lambda(n+1)}.$$
