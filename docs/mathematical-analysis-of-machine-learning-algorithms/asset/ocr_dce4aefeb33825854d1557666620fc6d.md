Uniform $L_\infty$ covering number bounds for general regularized linear function classes were obtained in Zhang (2002). These bounds are useful in large-margin analysis, and in vector-valued prediction problems.

# Exercises

5.1 Consider the function class $\mathcal{F}$ of monotone functions from $\mathbb{R} \to [0,1]$. Show that for any distribution $\mathcal{D}$ on $\mathbb{R}$,

$$\ln N_{[]}(\epsilon, \mathcal{F}, L_1(\mathcal{D})) \le \left\lceil \frac{2}{\epsilon} \right\rceil \ln \left\lceil \frac{2}{\epsilon} \right\rceil.$$

Hint: discretize both $\mathbb{R}$ and $[0,1]$ into regular grids and use piecewise constant approximations.

5.2 For Exercise 5.1, a more involved argument can be used to show that

$$\ln N_{[]}(\epsilon, \mathcal{F}, L_p(\mathcal{D})) \le \frac{K_p}{\epsilon},$$

where $K_p$ is a constant that depends on $p$ (see van der Vaart and Wellner, 1996, Theorem 2.7.5). Use this result to bound the bracketing numbers of real-valued function class with bounded total variation:

$$\mathcal{F} = \{f: V(f) \le B\}, \quad V(f) = \sup_{x_0 \le x_1 \le \cdots \le x_m} \sum_{i=1}^{m} |f(x_i) - f(x_{i-1})|.$$

5.3 Assume that $\phi(z) \in [0,1]$ for all $g \in \mathcal{G}$. Show that for $p \ge 1$, 

$$\ln N(\epsilon, \mathcal{G}, L_p(\mathcal{D})) \le \ln N(\epsilon^p, \mathcal{G}, L_1(\mathcal{D})).$$

5.4 Consider the following set in $\mathbb{R}^d$:

$$\Omega = \{x: \|x\|_p \le 1\},$$

where $1 \le p < 2$. Show that there are constants $C_p$ and $r_p$ such that

$$\ln N(\epsilon, \Omega, \|\cdot\|_2) \le C_p \epsilon^{-r_p} \ln d.$$

5.5 Consider the set

$$\Omega = \left\{ x = [x_1, x_2, \dots] \in \mathbb{R}^\infty : \sum_{i=1}^{\infty} i \cdot x_i^2 \le 1 \right\},$$

with metric induced by the $L_2$-norm $\|x\|_2 = \sqrt{\sum_{i=1}^{\infty} x_i^2}$. Derive an upper bound and a lower bound for $\ln N(\epsilon, \Omega, \|\cdot\|_2)$.
