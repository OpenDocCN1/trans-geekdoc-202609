# Example 6.10

One advantage of Corollary 6.9 is that it allows us to introduce an unknown distribution dependent offset term $h'(w)$ into the definition of uniform convergence complexity because the learning algorithm in (6.1) does not depend on $h'(w)$. As a simple example, we may take $h'(w)=\gamma\phi(w,\mathcal{D})$ and obtain

$$(1-\gamma)\mathbb{E}_{S_n}\phi(\hat{w},\mathcal{D})\leq\inf_{w\in\Omega}\left[\phi(w,\mathcal{D})+\mathbb{E}_{S_n}h(w,S_n)\right]+\epsilon'+\tilde{\epsilon}_n^h(\mathcal{G},\mathcal{D}).$$

We are now ready to define (one-sided) offset Rademacher complexity. Note that the offset function in Rademacher complexity is more restrictive than the more general offset function considered in the uniform convergence complexity (6.2). This is because we would like to use symmetrization argument, which works only for this special form of offset function.

# Definition 6.11

Consider a function class $\mathcal{G}=\{\phi(w;Z):w\in\Omega\}$, and let $h$ be an offset function of the following form:

$$h(w,S_n)=\frac{1}{n}\sum_{i=1}^{n}h(w,Z_i),\qquad h(w,z)=h_0(w)+h_1(w,z). \tag{6.3}$$

Given $S_n=\{Z_1,\ldots,Z_n\}$, the (one-sided) empirical Rademacher complexity of $\mathcal{G}$ with offset $h$ decomposition (6.3) is defined as

$$R_n^h(\mathcal{G},S_n)=\mathbb{E}_{\sigma}\sup_{w\in\Omega}\left[\frac{1}{n}\sum_{i=1}^{n}\sigma_i\left[\phi(w,Z_i)+0.5h_1(w,Z_i)\right]-0.5h(w,S_n)\right],$$

where $\sigma_1,\ldots,\sigma_n$ are independent uniform $\{\pm1\}$-valued Bernoulli random variables. Moreover, the expected Rademacher complexity is

$$R_n^h(\mathcal{G},\mathcal{D})=\mathbb{E}_{S_n\sim\mathcal{D}^n}R_n^h(\mathcal{G},S_n).$$

We note that the standard Rademacher complexity can be regarded as a special case of the offset Rademacher complexity with $h(\cdot)=h_0(\cdot)=h_1(\cdot)=0$:

$$R(\mathcal{G},S_n)=R_n^0(\mathcal{G},S_n),\qquad R_n(\mathcal{G},\mathcal{D})=R_n^0(\mathcal{G},\mathcal{D}).$$
