By summing over t = 1 to t = T, we obtain

$$\sum_{t=1}^{T} \ln \hat{p}(Y_t, | x_t, \mathcal{S}_{t-1}) = \ln \mathbb{E}_{w \sim p_0} \prod_{t=1}^{T} p(Y_t | w, X_t)$$ $$= \sup_q \left[ \mathbb{E}_{w \sim q} \ln \prod_{t=1}^{T} p(Y_t | w, X_t) - \mathbb{E}_{w \sim q} \ln \frac{q(w)}{p_0(w)} \right],$$

where the second equality used Proposition 7.16. This implies the desired result.

The following result is a direct consequence of Theorem 15.3.

# Corollary 15.4 If Ω = {w₁, …} is discrete, then

$$- \sum_{t=1}^{T} \ln \hat{p}(Y_t, | X_t, \mathcal{S}_{t-1}) \le \inf_{w \in \Omega} \left[ - \sum_{t=1}^{T} \ln p(Y_t | w, X_t) - \ln p_0(w) \right].$$

Proof Given any w' ∈ Ω, if we choose q(w) = 1 when w = w', and q(w) = 0 when w ≠ w', then

$$-\mathbb{E}_{w \sim q} \sum_{t=1}^{T} \ln p(Y_t | w, X_t) + \mathbb{E}_{w \sim q} \ln \frac{q(w)}{p_0(w)} = - \sum_{t=1}^{T} \ln p(Y_t | w', X_t) - \ln p_0(w').$$

This implies the result.

If |Ω| = N is finite, and p₀(w) = 1/N is the uniform distribution on Ω, then we have

$$- \sum_{t=1}^{T} \ln \hat{p}(Y_t, | X_t, \mathcal{S}_{t-1}) \le \inf_{w \in \Omega} \left[ - \sum_{t=1}^{T} \ln p(Y_t | w, X_t) + \ln N \right].$$

This means that we have a constant regret which is independent of T. If we use online to batch conversion, then by taking expectation, we have $$- \frac{1}{T} \mathbb{E}_{\mathcal{S}_T} \sum_{t=1}^{T} \mathbb{E}_{Z \sim \mathcal{D}} \ln \hat{p}(Y | X, \mathcal{S}_{t-1}) \le \inf_{w \in \Omega} \left[ -\mathbb{E}_{Z \sim \mathcal{D}} \ln p(Y | w, X) + \frac{\ln N}{T} \right].$$ Therefore the statistical convergence rate of the Bayesian posterior averaging algorithm for density estimation problems is naturally ln N / T.
