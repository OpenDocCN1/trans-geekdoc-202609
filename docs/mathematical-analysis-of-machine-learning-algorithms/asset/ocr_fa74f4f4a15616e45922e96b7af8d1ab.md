can be regarded as the analogy of ERM sample complex caused by covering numbers. If we define the following ball in L∞ metric:

𝓕(ε) = { f ∈ 𝓕 : supₓ,ₐ,ᵣ |ΔL(f, x, a, r)| ≤ ε }

then we may take p(f) = p₀(f) 𝟙(f ∈ 𝓕(ε)) / p₀(𝓕(ε)) to obtain κ ≤ ε − ln p₀(𝓕(ε)). We thus obtain

# **Theorem 17.33**  _Consider K ≥ 2 and d ≥ 1. There exists a bandit problem with {0,1}-valued rewards, such that the realizable condition holds with |𝒜| = K, |𝓕| = Kᵈ, so that the expected regret of any bandit algorithm q̂ is at least_

min(0.027T, 0.06√(KdT)).

**Proof**  We would like to apply Theorem 13.24 with m = K. We consider finite 𝒳 = {1, …, d} with d different contexts. Consider the class of all possible deterministic policies 𝒢 = {τ : 𝒳 → [K]}, which contains |𝒢| = Kᵈ policies. For each policy τ, we define its value function

fᵀ(x, a) = { 0.5 + ε, if a = τ(x); 0.5, otherwise. }

where ε ∈ (0, 0.1] will be specified later. For each j, we assume also that

fⱼᵀ(x, a) = { 0.5, if x = j; fᵀ(x, a), otherwise. }

We now consider the {0,1}-valued reward distribution

qᵀ(r | x, a) = Bernoulli(fᵀ(x, a)),    qⱼᵀ(r | x, a) = Bernoulli(fⱼᵀ(x, a)).

Given a (random) policy π that returns a distribution π(a | x) for all x ∈ 𝒳, we can define

qᵀ(r | π, x) = 𝔼ₐ∼π(·|x) qᵀ(r | x, a),

and similarly for qⱼᵀ(r | π, x). Let τ ∼ⱼ τ′ if τ(x) and τ′(x) differs at most at x = j. Assume that we choose context in 𝒳 uniformly at random. Let θ = θ(· | x) be a policy learned from a bandit algorithm. We can decompose the regret of θ as

Q(θ, qᵀ) = 1/d ∑ⱼ₌₁ᵈ 𝔼ₐ∼θ(·|xⱼ) 𝟙(a ≠ τ(j)) = ∑ⱼ₌₁ᵈ Qⱼ(θ, qᵀ),

where

Qⱼ(θ, qᵀ) = ε/d 𝔼ₐ∼θ(·|j) 𝟙(a ≠ τ(j)).
