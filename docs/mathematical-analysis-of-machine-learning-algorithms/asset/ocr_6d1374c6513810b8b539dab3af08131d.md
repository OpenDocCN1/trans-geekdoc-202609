Proof Given any measurable set A, let p = P(A) and q = Q(A). By the data processing inequality, with h(z) = 𝟙(z ∈ A), we have

D_f(P||Q) ≥ q f(p/q) + (1 - q) f((1 - p)/(1 - q))
= q f(1 + s (p - q)/q) + (1 - q) f(1 + s (q - p)/(1 - q))|_{s=1}
= g(0) + g'(0) + ∫_0^1 g''(s)(1 - s) ds
= (p - q)^2 ∫_0^1 [1/q f''(p(s)/q) + 1/(1 - q) f''((1 - p(s))/(1 - q))] (1 - s) ds
≥ c_f (p - q)^2,

where we have used Taylor expansion, and g(0) = g'(0) = 0. Therefore,

1/c_f D_f(P||Q) ≥ sup_A (P(A) - Q(A))^2 = ||P - Q||_{TV}^2.

This proves the desired bound.

This result implies the following inequalities. The bound of TV-norm in KL-divergence is often referred to as Pinsker's inequality.

||P - Q||_{TV}^2 ≤ 1/4 χ^2(P||Q),
||P - Q||_{TV}^2 ≤ 1/2 KL(P||Q),
||P - Q||_{TV}^2 ≤ H(P||Q)^2.
