## 机器学习算法的数学分析

机器学习的数学理论不仅可以解释当前的算法，还可以为未来激发有原则的方法。这本自成体系的教材向人工智能的学生和研究人员介绍了用于分析机器学习算法的主要数学技术，并附有动机和应用。涵盖的主题包括 iid 设定下监督学习算法的分析、神经网络的分析（例如神经切向核和平均场分析），以及顺序决策设定下机器学习算法的分析（例如在线学习、bandit 问题和强化学习）。学生将学习用于这些机器学习问题理论分析的基本数学工具，以及如何将其应用于各种具体算法的分析。

这本教材非常适合具有基本机器学习方法背景知识，但希望获得足够的技术知识以理解理论机器学习研究论文的读者。

TONG ZHANG 是香港科技大学计算机科学与数学的讲座教授，其研究重点是机器学习、大数据及其应用。IEEE、美国统计协会和数理统计学会的会士，Zhang 曾担任 NeurIPS、ICML 和 COLT 等主要机器学习会议的主席或领域主席，并担任过包括 *PAMI*、*JMLR* 和 *Machine Learning* 在内的多本顶尖机器学习出版物的副主编。
