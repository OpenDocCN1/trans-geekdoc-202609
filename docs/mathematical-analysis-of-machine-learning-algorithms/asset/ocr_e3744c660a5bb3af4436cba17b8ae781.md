# Example 6.48

In Example 6.45, assume that

$$\ln N_2(\epsilon,\mathcal{G},n)\le c/\epsilon^p$$

for some $p<2$. Then it can be shown from Theorem 6.25 that (we leave it to Exercise 6.9) $r_n(b)=O((\sqrt{b})^{1-0.5p}/\sqrt{n})$. This implies that

$$\bar r_n^h(\alpha,\mathcal{G},\mathcal{D})=O\left(n^{-1/(1+p/2)}\right).$$

In comparison, we may apply the uniform $L_1$ entropy analysis with

$$\ln N_1(\epsilon,\mathcal{G},n)\le c/\epsilon^p.$$

The multiplicative Chernoff bound in Corollary 4.13 has a suboptimal complexity of

$$\inf_{\epsilon>0}\left[\epsilon+\frac{c}{\epsilon^p n}\right]=O\left(n^{-1/(1+p)}\right).$$

# Example 6.49

Consider a function class $\mathcal{F}$ and the ERM method for least squares regression:

$$\hat f=\mathop{\arg\min}_{f\in\mathcal{F}}\frac{1}{n}\sum_{i=1}^{n}(f(X_i)-Y_i)^2,$$

where $Z_i=(X_i,Y_i)$ are iid samples from $\mathcal{D}$. Assume that $|f(X)-Y|\in[0,1]$ for all $X$ and $Y$. Example 3.18 implies that the loss function $\phi(f,Z)=[(f(X)-Y)^2-(f_*(X)-Y)^2]$ satisfies the variance condition if the true regression function $f_*\in\mathcal{F}$. Assume also that the empirical covering number of $\mathcal{F}$ satisfies

$$\ln N_2(\epsilon,\mathcal{F},n)\le\frac{c}{\epsilon^p} \tag{6.9}$$

for some constant $c>0$ and $p>0$. We consider the following two situations: $p\in(0,2)$ and $p\ge 2$.

Let $h(f)=\phi(f,\mathcal{D})$ with $h_0(f)=0$.

+   - $p\in(0,2)$. The conditions of Corollary 6.44 hold with $c_0=0$. This implies the following bound (see Exercises 6.9) on the rate function with constant $\alpha$:

$$\bar r^h(\alpha,\mathcal{F},\mathcal{D})=O\left(n^{-2/(2+p)}\right).$$

We thus have with probability at least $1-\delta$,

$$\mathbb{E}_{\mathcal{D}}L(\hat f(X),Y)\le\mathbb{E}_{\mathcal{D}}L(f_*(X),Y)+O\left(n^{-2/(2+p)}+\frac{\ln(1/\delta)}{n}\right).$$

+   - $p>2$. The entropy integral of Theorem 6.25 implies that

$$R_n(\mathcal{F}^h(b),\mathcal{D})\le\frac{\tilde c_1}{n^{1/p}}$$
