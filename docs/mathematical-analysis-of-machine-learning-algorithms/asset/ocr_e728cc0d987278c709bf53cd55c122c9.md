# ## 8.4 Bayesian Model Selection and Averaging

We have studied the Gibb’s algorithm in Section 7.4. We showed that the algorithm is algorithmically stable, which can be used to show that it has good generalization performance in expectation. In this section, we further show that the Gibbs algorithm can be used for model selection.

We consider a family of Gibbs algorithms $\mathcal{A}(\theta,\mathcal{S}_n)$, and for each $\theta$, the algorithm chooses a random $f\in\mathcal{F}(\theta)$ according to the probability

$$p(f\mid\theta,\mathcal{S}_n)=\frac{p_0(f\mid\theta)\exp\left(-\beta\sum_{Z\in\mathcal{S}_n}\phi(f,Z)\right)}{\exp(\Gamma(\theta\mid\mathcal{S}_n))}, \tag{8.5}$$

where $p_0(f\mid\theta)$ is a known prior on the model class $\mathcal{F}(\theta)$, and

$$\Gamma(\theta\mid\mathcal{S}_n)=\ln\mathbb{E}_{f\sim p_0(\cdot\mid\theta)}\exp\left(-\beta\sum_{Z\in\mathcal{S}_n}\phi(f,Z)\right).$$

Now, assume that we are further given a prior $p_0(\theta)$ on $\theta\in\Theta$, then the following algorithm is the Bayesian formula for Gibbs model selection, which randomly selects a model $\theta\in\Theta$ according to the posterior formula:

$$p(\theta\mid\mathcal{S}_n)\propto p_0(\theta)\exp\left(\Gamma(\theta\mid\mathcal{S}_n)\right). \tag{8.6}$$

After selecting $\theta$, we then randomly select $f\in\mathcal{F}(\theta)$ according to (8.5).

Using the Bayesian formula, we obtain the joint posterior for both $\theta$ and $f$ as:

$$\begin{aligned}p(\theta,f\mid\mathcal{S}_n)&=p(\theta\mid\mathcal{S}_n)p(f\mid\theta,\mathcal{S}_n)\\
&\propto p_0(\theta)p_0(f\mid\theta)\exp\left(-\beta\sum_{Z\in\mathcal{S}_n}\phi(f,Z)\right). \tag{8.7}\end{aligned}$$
