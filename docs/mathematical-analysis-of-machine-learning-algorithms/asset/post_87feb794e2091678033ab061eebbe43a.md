
and the bonus function satisfies the following *uniform eluder condition*:

$$\sup_{\{(x_t^h,a_t^h)\}_{t=1}^T}\sum_{t=1}^{T}\min\left(1,b_t^h(x_t^h,a_t^h)^2\right)\leq \dim\left(T,\mathcal{B}^h(\epsilon)\right).$$

We note that the uniform eluder condition of Assumption 18.22 is related to the coverage coefficient of Definition 9.42 (also see the conditional versions in Definition 17.35 and Definition 18.30), and the assumption is stronger than Bellman eluder coefficients. However, the following example shows that linear MDP satisfies Assumption 18.22.

## Example 18.23

Consider a linear MDP in Definition 18.15 such that

$$\|\theta^h\|_{\mathcal{H}^h}+\int\|\nu^h(x,x^{h+1})\|_{\mathcal{H}^h}\,d\mu^{h+1}(x^{h+1})\leq B^h.$$

If $\mathcal{F}^h$ is any function class that contains

$$\widetilde{\mathcal{F}}^h=\left\{\langle w^h,\phi^h(x^h,a^h)\rangle:\ \|w^h\|_{\mathcal{H}^h}\leq B^h\right\},$$

then the proof of Proposition 18.18 implies that (18.9) holds. Note that if $r^h\in[0,1]$, then $(\mathcal{T}^h g^{h+1})(x^h,a^h)\in[0,2]$. Therefore at any time step $t$, we may consider a subset of $\mathcal{F}^h$ that satisfies the range constraint on historic observations, and in the meantime, impose the same range constraints in $\widetilde{\mathcal{F}}^h$ as

$$\widetilde{\mathcal{F}}^h=\left\{\langle w^h,\phi^h(x^h,a^h)\rangle:\ \|w^h\|_{\mathcal{H}^h}\leq B^h,\ \langle w^h,\phi^h(x_s^h,a_s^h)\rangle\in[0,2]\ \forall s\in[t-1]\right\}.$$

If moreover, each $f^h(x^h,a^h)\in\mathcal{F}^h$ can be written as $\langle\widetilde{w}^h(f^h),\phi^h(x^h,a^h)\rangle$ so that $\|\widetilde{w}^h(f^h)-\widetilde{w}^h(\widetilde{f}^h)\|_2\leq\widetilde{B}^h$ (here we assume that $\widetilde{\phi}^h$ may or may not be the same as $\phi^h$), then Lemma 13.9 can take

$$b_t^h(x^h,a^h)=\left\|\phi^h(x^h,a^h)\right\|_{(\Sigma_t^h)^{-1}},\tag{18.11}$$
$$\Sigma_t^h=\frac{\epsilon}{(\widetilde{B}^h)^2}I+\sum_{s=1}^{t-1}\widetilde{\phi}^h(x_s^h,a_s^h)\widetilde{\phi}^h(x_s^h,a_s^h)^\top,$$

so that (18.10) holds. By using Lemma 13.9, we have

$$\sum_{t=1}^{T}\min\left(1,\|\widetilde{\phi}^h(x_t^h,a_t^h)\|_{(\Sigma_t^h)^{-1}}^2\right)\leq\sum_{t=1}^{T}\frac{2\|\widetilde{\phi}^h(x_t^h,a_t^h)\|_{(\Sigma_t^h)^{-1}}^2}{1+\|\widetilde{\phi}^h(x_t^h,a_t^h)\|_{(\Sigma_t^h)^{-1}}^2}\leq\ln\left|\left(\frac{(\widetilde{B}^h)^2}{\epsilon}\right)\Sigma_T^h\right|.$$

Using Proposition 15.8, we can set $\dim(T,\mathcal{B}^h(\epsilon))=\operatorname{entro}(\epsilon/((\widetilde{B}^h)^2T),\widetilde{\phi}^h(\cdot))$.

With the stronger assumptions in Assumption 18.22, we can solve the corresponding RL problem using Algorithm 18.2, which is computationally simpler than Algorithm 18.1. At each time step $t$, the algorithm forms upper confidence bounds of the optimal $Q$ function for $h=H,H-1,\ldots,1$, and then plays the greedy policy according to the upper confidence bounds. This requires explicit bonus term $b_t^h(\cdot)$. We call this algorithm *least squares value iteration* (with UCB)

to be consistent with (Jin et al., 2020). However, the algorithm is also referred to as *fitted Q-learning* in the literature.

## Algorithm 18.2 Least Squares Value Iteration with UCB (LSVI-UCB)

**Input:** ε > 0, T, {𝓕ʰ}, {𝓑ʰ(ε)}

1. for t = 1, 2, …, T do
   Let fₜᴴ⁺¹ = 0
   for h = H, H − 1, …, 1 do
     Let yₛʰ = rₛʰ + fₜʰ⁺¹(xₛʰ⁺¹), where fₜʰ⁺¹(xₛʰ⁺¹) = maxₐ fₜʰ⁺¹(xₛʰ⁺¹, a)
     Let
     f̂ₜʰ = arg min_{fʰ ∈ 𝓕ʰ} ∑_{s=1}^{t−1}(fʰ(xₛʰ, aₛʰ) − yₛʰ)².
     Find βₜʰ > 0 and bonus function bₜʰ(·) that satisfies (18.10)
     Let fₜʰ(xʰ, aʰ) = min(1, max(0, f̂ₜʰ(xʰ, aʰ) + βₜʰbₜʰ(xʰ, aʰ)))
   Let πₜ be the greedy policy of fₜʰ for each step h ∈ [H]
   Play policy πₜ and observe trajectory (xₜ, aₜ, rₜ)
return randomly chosen πₜ from t = 1 to t = T

## Lemma 18.24

*Consider Algorithm 18.2 under Assumption 18.2. Assume also that Q*ₕ ∈ 𝓕ʰ, Q*ₕ ∈ [0, 1], rʰ ∈ [0, 1], fʰ ∈ [0, 2] for h ∈ [H], and f ∈ 𝓕ʰ. Given any t > 0, let βₜᴴ⁺¹ = βᴴ⁺¹(ε, δ) = 0, and for h = H, H − 1, …, 1,*

βₜʰ = βʰ(ε, δ) ≥ 4(1 + βʰ⁺¹) ε/√T + √ε + √(24(1 + βʰ⁺¹(δ))ε + 12 ln(2H Mₜʰ(ε)/δ)),

*where (with ‖f‖∞ = supₓ,ₐ,ₕ fʰ(x, a))*

Mₜʰ(ε) = M(ε/T, 𝓕ʰ, ‖·‖∞) M(ε/T, 𝓕ʰ⁺¹, ‖·‖∞) M(ε/T, 𝓑ʰ⁺¹(ε), ‖·‖∞).

*Then with probability at least 1 − δ, for all h ∈ [H], and (xʰ, aʰ) ∈ 𝓧 × 𝓐,*

Q*ₕ(xʰ, aʰ) ≤ fₜʰ(xʰ, aʰ),

|fₜʰ(xʰ, aʰ) − (𝒯ʰfₜʰ⁺¹)(xʰ, aʰ)| ≤ 2βʰ(ε, δ)bₜʰ(xʰ, aʰ).

**Proof** Let 𝓕̄ₑʰ⁺¹ be an (ε/T)‖·‖∞ packing of 𝓕ʰ⁺¹, and 𝓑̄ₑʰ⁺¹ be an (ε/T)‖·‖∞ packing of 𝓑ʰ⁺¹(ε). Then

𝓕̄ₑʰ⁺¹ = 𝓕ₑʰ⁺¹ + βʰ⁺¹𝓑ₑʰ⁺¹

is a (1 + βʰ⁺¹)(ε/T)‖·‖∞ cover of {fₜʰ⁺¹(·)}. Given fₜʰ⁺¹, let f̄ₜʰ⁺¹ ∈ 𝓕̄ₑʰ⁺¹ so that ‖f̄ₜʰ⁺¹ − fₜʰ⁺¹‖∞ ≤ ε̄ = (1 + βʰ⁺¹)(ε/T). Let ȳₛʰ = rₛʰ + f̄ₜʰ⁺¹(xₛʰ⁺¹), and

\tilde{f}_t^h = \arg \min_{f^h \in \mathcal{F}_h} \sum_{s=1}^{t-1} \left(f^h(x_s^h, a_s^h) - \bar{y}_s^h\right)^2.

Then we have

\begin{aligned}
\left(\sum_{s=1}^{t-1}\left(\hat{f}_t^h(x_s^h, a_s^h) - \bar{y}_s^h\right)^2\right)^{1/2} &\le \left(\sum_{s=1}^{t-1}\left(\hat{f}_t^h(x_s^h, a_s^h) - y_s^h\right)^2\right)^{1/2} + \sqrt{t}\bar{\epsilon}\\
&\le \left(\sum_{s=1}^{t-1}\left(\tilde{f}_t^h(x_s^h, a_s^h) - y_s^h\right)^2\right)^{1/2} + \sqrt{t}\bar{\epsilon}\\
&\le \left(\sum_{s=1}^{t-1}\left(\tilde{f}_t^h(x_s^h, a_s^h) - \bar{y}_s^h\right)^2\right)^{1/2} + 2\sqrt{t}\bar{\epsilon}.
\end{aligned}

The first and the third inequalities used triangle inequalities. The second inequality used the fact that \hat{f} is the ERM solution of the least squares problem. We can apply Theorem 13.15 to \bar{y}_s^h, with f_* in Theorem 13.15 replaced by \mathbb{E}[y_s^h|x_s^h,a_s^h]=(\mathcal{T}^h \bar{f}_t^{h+1})(x_s^h,a_s^h) and \epsilon' = 2\bar{\epsilon} and \sigma = 1. By taking a union bound over \bar{f}_t^{h+1} \in \mathcal{F}_\epsilon^{h+1} and h \in [H], we obtain with probability at least 1 - \delta

\begin{aligned}
\left(\sum_{s=1}^{t-1}\left(\hat{f}_t^h(x_s^h,a_s^h) - (\mathcal{T}^h \bar{f}_t^{h+1})(x_s^h,a_s^h)\right)^2 + \epsilon\right)^{1/2}
&\le \left(\sum_{s=1}^{t-1}\left(\hat{f}_t^h(x_s^h,a_s^h) - (\mathcal{T}^h \bar{f}_t^{h+1})(x_s^h,a_s^h)\right)^2\right)^{1/2} + \sqrt{t}\bar{\epsilon} + \sqrt{\epsilon}\\
&\le \sqrt{t}\bar{\epsilon} + \sqrt{\epsilon} + \sqrt{8t\left(\frac{\epsilon}{T}+2\bar{\epsilon}\right)\left(1+\frac{2\epsilon}{T}+4\bar{\epsilon}\right)+12\ln\frac{2HM_T^h(\epsilon)}{\delta}} \le \beta_t^h.
\end{aligned}

The first inequality used the triangle inequality. The second inequality used Theorem 13.15 with \epsilon' = 2\bar{\epsilon} (and union bound over \bar{f}_t^{h+1} and h \in [H]). The last inequality is algebra.

Now by using the definition of b_t^h(\cdot), we obtain

|\hat{f}_t^h(x^h,a^h) - (\mathcal{T}^h \bar{f}_t^{h+1})(x^h,a^h)| \le \beta_t^h b_t^h(x^h,a^h).

Therefore the definition of f_t^h in the algorithm implies that
0 \le f_t^h(x^h,a^h) - (\mathcal{T}^h f_t^{h+1})(x^h,a^h) \le 2\beta_t^h b_t^h(x^h,a^h). \quad (18.12)

This proves the second desired bound. By using induction from h = H, H - 1, ..., 1, with Q_*^{H+1} = f_t^{H+1} = 0, we obtain that when f_t^{h+1}(\cdot) \ge Q_*^{h+1}(\cdot),
f_t^h(x^h,a^h) - Q_*^h(x^h,a^h) \ge (\mathcal{T}^h f_t^{h+1})(x^h,a^h) - Q_*^h(x^h,a^h) = \mathbb{E}[f_t^{h+1}(x^{h+1}) - Q_*^{h+1}(x^{h+1})|x^h,a^h] \ge 0.

The first inequality used (18.12). The next equality used the Bellman equation for Q_*. The last inequality used the induction hypothesis at h + 1. This proves the first desired inequality.

## Theorem 18.25

Consider Algorithm 18.2, and assume that all conditions of Lemma 18.24 hold. Then

$$\mathbb{E}\sum_{t=1}^{T}\left[V_*^1(x_t^1)-V_{\pi_t}^1(x_t^1)\right]\leq \delta T+2\sqrt{dHT\sum_{h=1}^{H}\beta^h(\epsilon,\delta)^2+2Hd}.$$

where $d=H^{-1}\sum_{h=1}^{H}\dim\left(T,\mathcal{B}^h(\epsilon)\right)$.

**Proof** From Lemma 18.24, we know that for each $t$, with probability at least $1-\delta$ over the observations $\{(x_s,a_s,r_s):s=1,\ldots,t-1\}$, the two inequalities of the lemma hold (which we denote as event $E_t$). It implies that under event $E_t$, $f_t^h$ satisfies the following inequalities for all $h\in[H]$:

$$\mathbb{E}_{x_t^1}V_*^1(x_t^1)\leq \mathbb{E}_{x_t^1}f_t^1(x_t^1), \tag{18.13}$$

$$\mathbb{E}_{x_t^h,a_t^h}\left|\mathcal{E}^h(f_t,x_t^h,a_t^h)\right|\leq 2\mathbb{E}_{x_t^h,a_t^h}\beta^h(\epsilon,\delta)b^h(x_t^h,a_t^h). \tag{18.14}$$

We thus obtain

$$\mathbb{E}\sum_{t=1}^{T}\left[V_*^1(x_t^1)-V_{\pi_t}^1(x_t^1)\right]\leq \delta T+\mathbb{E}\sum_{t=1}^{T}\left[f_t^1(x_t^1)-V_{\pi_t}^1(x_t^1)\right]\mathbf{1}(E_t)$$

$$=\delta T+\sum_{t=1}^{T}\mathbb{E}\sum_{h=1}^{H}\mathcal{E}^h(f_t,x_t^h,a_t^h)\mathbf{1}(E_t)$$

$$\leq \delta T+2\sum_{t=1}^{T}\mathbb{E}\sum_{h=1}^{H}\left[\beta^h(\epsilon,\delta)\min\left(1,b^h(x_t^h,a_t^h)\right)+\min\left(1,b^h(x_t^h,a_t^h)\right)^2\right]$$

$$\leq \delta T+2\sqrt{\sum_{t=1}^{T}\sum_{h=1}^{H}\beta^h(\epsilon,\delta)^2}\sqrt{\mathbb{E}\sum_{t=1}^{T}\sum_{h=1}^{H}\min\left(1,b^h(x_t^h,a_t^h)\right)^2}$$

$$\quad+2\mathbb{E}\sum_{t=1}^{T}\sum_{h=1}^{H}\min\left(1,b^h(x_t^h,a_t^h)\right)^2$$

$$\leq \delta T+2\sqrt{T\sum_{h=1}^{H}\beta^h(\epsilon,\delta)^2}\sqrt{\sum_{h=1}^{H}\dim\left(T,\mathcal{B}^h(\epsilon)\right)}+2\sum_{h=1}^{H}\dim\left(T,\mathcal{B}^h(\epsilon)\right).$$

The first inequality used (18.13). The first equality used Theorem 18.11. The second inequality used (18.14) and $|\mathcal{E}^h(f_t,x_t^h,a_t^h)|\leq 2$. The third inequality used the Cauchy–Schwarz inequality. This proves the desired bound.
