Consequently, the approximate ERM method of (3.7) satisfies

$$\mathbb{E}_{S_n}\phi(\hat{w},\mathcal{D}) \leq \inf_{w\in\Omega} \phi(w,\mathcal{D}) + \epsilon' + 2R_n(\mathcal{G},\mathcal{D}).$$

**Proof**  Let $S'_n=\{Z'_1,\ldots,Z'_n\}\sim\mathcal{D}^n$ be $n$ iid samples from $\mathcal{D}$ that are independent of $S_n$. We have

$$\begin{aligned}
\epsilon_n(\mathcal{G},\mathcal{D})
&=\mathbb{E}_{S_n\sim\mathcal{D}^n}\sup_{w\in\Omega}[\phi(w,\mathcal{D})-\phi(w,S_n)]\\
&=\mathbb{E}_{S_n\sim\mathcal{D}^n}\sup_{w\in\Omega}[\mathbb{E}_{S'_n\sim\mathcal{D}^n}\phi(w,S'_n)-\phi(w,S_n)]\\
&\leq\mathbb{E}_{(S_n,S'_n)\sim\mathcal{D}^{2n}}\sup_{w\in\Omega}[\phi(w,S'_n)-\phi(w,S_n)]\\
&=\mathbb{E}_{(S_n,S'_n)\sim\mathcal{D}^{2n}}\mathbb{E}_{\sigma}\sup_{w\in\Omega}\frac{1}{n}\sum_{i=1}^{n}[\sigma_i\phi(w,Z'_i)-\sigma_i\phi(w,Z_i)]\\
&\leq\mathbb{E}_{(S_n,S'_n)\sim\mathcal{D}^{2n}}[R(\mathcal{G},S_n)+R(\mathcal{G},S'_n)] = 2R_n(\mathcal{G},\mathcal{D}).
\end{aligned}$$

This proves the desired bound.

One reason to introduce Rademacher complexity is that it can be estimated on the training data. Moreover, for many problems, it is often not difficult to estimate this quantity theoretically. The following example demonstrates this.

**Example 6.5**  Consider a (binary-valued) VC class $\mathcal{G}$ such that $\mathrm{VC}(\mathcal{G})=d$. Consider $n\geq d$. Then Sauer’s lemma implies that for any $S_n$, the number of functions of $\phi\in\mathcal{G}$ on $S_n$ is no more than $(en/d)^d$. We thus obtain (see Theorem 6.23)

$$R(\mathcal{G},S_n)\leq\sqrt{\frac{2d\ln(en/d)}{n}}.$$

This implies that the approximate ERM method of (3.7) satisfies

$$\mathbb{E}_{S_n}\phi(\hat{w},\mathcal{D})\leq\inf_{w\in\Omega}\phi(w,\mathcal{D})+\epsilon'+2\sqrt{\frac{2d\ln(en/d)}{n}}.$$

A better bound can be obtained using Theorem 5.6 and Theorem 6.25, which removes the $\ln n$ factor. Also see Example 6.26.
