$\bar{g}(S_{n+1}) \le L\epsilon + 2.5L\epsilon\ln(1/\delta)$.

The proof requires the following result from Boucheron et al. (2003).

# **Proposition 7.25**  *Consider a functional $\tilde{g}(S)$, where $S=[Z_1,\ldots,Z_m]\sim\mathcal{D}^m$ contains $m$ iid samples from $\mathcal{D}$. Let $S^{(i)}=[Z_1,\ldots,Z_{i-1},Z'_i,Z_{i+1},\ldots,Z_m]$, where $S'=\{Z'_i\}\sim\mathcal{D}^m$ are iid samples from $\mathcal{D}$ that are independent of $S$. Define*

$$V_+(S)=\mathbb{E}_{S'}\left[\sum_{i=1}^{m}\bigl(\tilde{g}(S)-\tilde{g}(S^{(i)})\bigr)\mathbf{1}\{\tilde{g}(S)>\tilde{g}(S^{(i)})\}\middle|S\right].$$

*Assume that there exist positive constants $a$ and $b$ such that*

$$V_+(S)\le a\tilde{g}(S)+b,$$

*then for $\lambda\in(0,1/a)$,*

$$\ln\mathbb{E}_S\exp(\lambda\tilde{g}(S))\le \lambda\mathbb{E}_S\tilde{g}(S)+\frac{\lambda^2}{1-a\lambda}\bigl(a\mathbb{E}_S\tilde{g}(S)+b\bigr).$$

Note that for the sake of simplicity, in the following proof our notation assumes that $g(S_n,z)$ is invariant to the order of elements in $S_n$. The analysis itself holds without this assumption, but directly working with the general version requires a more complex notation, which creates unnecessary difficulty for understanding the main argument. We will thus write the proof with this assumption so that the key idea of the proof is easier to follow. Consider a fixed $S_{n+1}=\{Z_1,\ldots,Z_{n+1}\}$, we define for $i\le m\le n$,

$$S_m^{(i)}=\{Z_1,\ldots,Z_{i-1},Z_{n+1},Z_{i+1},\ldots,Z_m\},$$

and with this notation, we have $S_{n+1}^{(i)}=S_n^{(i)}$.

Now for all $1\le m'\le m\le n$, we define

$$\bar{g}_{m',m}(S_{n+1})=\frac{1}{m'}\sum_{i=1}^{m'}\left[g(S_{n+1}^{(i)},Z_i)-\mathbb{E}_{S_m^{(i)}}g(S_{n+1}^{(i)},Z_i)\right].$$

It follows that $\bar{g}(S_{n+1})=\bar{g}_{n,n}(S_{n+1})$.

Given $m'<m\le n$, we denote by $\tilde{S}_{m'}$ a uniformly selected subset of $S_m$ of size $m'$. It is easy to see by symmetry that

$$\begin{aligned}\bar{g}_{m,m}(S_{n+1})&=\frac{1}{m}\sum_{i=1}^{m}\left[g(S_{n+1}^{(i)},Z_i)-\mathbb{E}_{S_m^{(i)}}g(S_{n+1}^{(i)},Z_i)\right]\\&=\mathbb{E}_{\tilde{S}_{m'}}\frac{1}{m'}\sum_{Z_i\in\tilde{S}_{m'}}\left[g(S_{n+1}^{(i)},Z_i)-\mathbb{E}_{S_m^{(i)}}g(S_{n+1}^{(i)},Z_i)\right].\end{aligned}$$

Therefore Jensen’s inequality implies that

$$\begin{aligned}\ln\mathbb{E}_{S_{n+1}}\exp(\lambda'\bar{g}_{m',m}(S_{n+1}))&\le \ln\mathbb{E}_{S_{n+1}}\mathbb{E}_{\tilde{S}_{m'}}\exp\left(\frac{\lambda'}{m'}\sum_{Z_i\in\tilde{S}_{m'}}\left[g(S_{n+1}^{(i)},Z_i)-\mathbb{E}_{S_m^{(i)}}g(S_{n+1}^{(i)},Z_i)\right]\right)\\&=\ln\mathbb{E}_{S_{n+1}}\exp(\lambda'\bar{g}_{m',m}(S_{n+1})).\end{aligned}$$
