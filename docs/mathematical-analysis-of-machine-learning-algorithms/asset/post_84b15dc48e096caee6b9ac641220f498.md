
$\mathcal{F}=\{f(w,x):w\in\Omega\}$ and a test loss $L(f(x),y)$. However, instead of minimizing the test loss directly, we try to minimize a surrogate training loss:

$$\frac{1}{n}\sum_{i=1}^{n}\widetilde{L}(f(\hat{w},X_i),Y_i)\leq \inf_{w\in\Omega}\left[\frac{1}{n}\sum_{i=1}^{n}\widetilde{L}(f(w,X_i),Y_i)\right]+\epsilon',$$ (4.4)

where we assume that the surrogate is an upper bound of training loss under small $L_\infty$ perturbation of size $\gamma>0$:

$$\widetilde{L}(f,y)\geq\sup_{|f'-f|\leq\gamma}L(f',y).$$\tag{4.5}

In this case, one would like to bound the test loss using surrogate training loss. An example for binary classification problem ($y\in\{\pm\}$) is to take the test loss as the binary classification error $L(f(x),y)\leq\mathbb{1}(f(x)y\leq 0)$, and $\widetilde{L}(f(x),y)=\mathbb{1}(f(x)y\leq\gamma)$ as the margin error with margin $\gamma>0$. The $L_\infty$ covering number can be used to obtain a result similar to Theorem 4.12, with a similar proof.

## Theorem 4.21
Assume that $\widetilde{L}(f(w,x),y),L(f(w,x),y)\in[0,1]$ for all $w$ and $(x,y)$, and both (4.4) and (4.5) hold. Then given $\delta\in(0,1)$, with probability at least $1-\delta$, the following inequality holds for all $w\in\Omega$:

$$\mathbb{E}_{(X,Y)\sim\mathcal{D}}L(f(w,X),Y)\leq\frac{1}{n}\sum_{i=1}^{n}\widetilde{L}(f(w,X_i),Y_i)+3\sqrt{\frac{\ln\left(3N_\infty(\gamma/2,\mathcal{F},2n)/\delta\right)}{2n}}.$$

Moreover, with probability at least $1-\delta$, the following inequality holds for all $w\in\Omega$:

$$(1-\gamma)^2\mathbb{E}_{(X,Y)\sim\mathcal{D}}L(f(w,X),Y)\leq\frac{1}{n}\sum_{i=1}^{n}\widetilde{L}(f(w,X_i),Y_i)+\frac{(5-4\gamma)\ln\left(3N_\infty(\gamma/2,\mathcal{F},2n)/\delta\right)}{2\gamma n}.$$

**Proof**  Given $S_n=\{(X_1,Y_1),\ldots,(X_n,Y_n)\}$ and $S'_n=\{(X'_1,Y'_1),\ldots,(X'_n,Y'_n)\}$, we consider a $\gamma/2$-$L_\infty(S_n)$ cover $\mathcal{F}_{\gamma/2}(S_n\cup S'_n)$ of $\mathcal{F}$, of size no more $N=N_\infty(\gamma/2,\mathcal{F},2n)$. Let

$$L'(f,y)=\sup_{|f'-f|\leq\gamma/2}L(f',y),$$

then for any $f,f'$ such that $|f-f'|\leq\gamma/2$, we have

$$\widetilde{L}(f,y)\geq L'(f',y)\geq L(f,y).$$\tag{4.6}

We obtain from Corollary 2.27 (with $a_i=0.5$) the following uniform convergence result over $\mathcal{F}_{\gamma/2}(S_n\cup S'_n)$. With probability $1-\delta$,

$\forall f \in \mathcal{F}_{\gamma/2}(S_n \cup S'_n):\quad \frac{1}{n}\sum_{i=1}^{n}\sigma_i\left[L'(f(X_i),Y_i)-0.5\right] \leq \sqrt{\frac{\ln(N/\delta)}{2n}}.$

Lemma 4.8 (which is valid even when $\mathcal{F}$ in the lemma depends on $S_n \cup S'_n$) with $\psi=0$ implies that with probability at least $1-\delta_1$,

$\forall f \in \mathcal{F}_{\gamma/2}(S_n \cup S'_n):\quad \frac{1}{n}\sum_{i=1}^{n}L'(f(X_i'),Y_i') \leq \frac{1}{n}\sum_{i=1}^{n}L'(f(X_i),Y_i)+\sqrt{\frac{2\ln(2N/\delta_1)}{n}}.$

Since for all $f\in\mathcal{F}$, we can find $f'\in\mathcal{F}_{\gamma/2}(S_n\cup S'_n)$ so that $|f(x)-f'(x)|\leq\gamma/2$, it follows that

$$\begin{aligned}
\frac{1}{n}\sum_{i=1}^{n}L(f(X_i'),Y_i')&\leq \frac{1}{n}\sum_{i=1}^{n}L'(f'(X_i'),Y_i')\\
&\leq \frac{1}{n}\sum_{i=1}^{n}L'(f'(X_i),Y_i)+\sqrt{\frac{2\ln(2N/\delta_1)}{n}}\\
&\leq \frac{1}{n}\sum_{i=1}^{n}\widetilde{L}(f(X_i),Y_i)+\sqrt{\frac{2\ln(2N/\delta_1)}{n}}.
\end{aligned}$$

Note that the first and the last inequalities used (4.6). The standard additive Chernoff bound implies that for all $w\in\Omega$, with probability at least $1-\delta_2$,

$$\mathbb{E}_{(X,Y)\sim\mathcal{D}}L(f(X),Y)\leq \frac{1}{n}\sum_{i=1}^{n}L(f(X_i'),Y_i')+\sqrt{\frac{\ln(1/\delta_2)}{2n}}.$$

Therefore in Lemma 4.11, we can take symbols as defined, together with $\delta_1=2\delta/3$, and $\delta_2=\delta/3$, to obtain the desired bound.

Similarly, we obtain from Corollary 2.27 the following uniform convergence result over $\mathcal{F}_{\gamma/2}(S_n\cup S'_n)$. With probability $1-\delta$, $\forall f\in\mathcal{F}_{\gamma/2}(S_n\cup S'_n)$,

$$\begin{aligned}
\frac{1}{n}\sum_{i=1}^{n}\sigma_iL'(f(X_i),Y_i)&\leq \sqrt{\frac{2\sum_{i=1}^{n}L'(f(X_i),Y_i)^2\ln(N/\delta)}{n^2}}\\
&\leq \gamma'\frac{1}{n}\sum_{i=1}^{n}L'(f(X_i),Y_i)+\frac{\ln(N/\delta)}{2\gamma'n}.
\end{aligned}$$

Then Lemma 4.8 (which is valid even when $\mathcal{F}$ in the lemma depends on $S_n\cup S'_n$) implies the following uniform convergence result. With probability at least $1-\delta_1$ over $(S_n,S'_n)\sim\mathcal{D}^{2n}$,

$\forall f \in \mathcal{F}_{\gamma/2}(S_n \cup S'_n):\quad (1 - \gamma')/n \sum_{i=1}^n L'(f(X'_i), Y'_i) \leq (1 + \gamma')/n \sum_{i=1}^n L'(f(X_i), Y_i) + \ln(2N/\delta_1)/(\gamma' n)$.

Since for all $f \in \mathcal{F}$, we can find $f' \in \mathcal{F}_{\gamma/2}(S_n \cup S'_n)$ so that $|f(x) - f'(x)| \leq \gamma/2$, it follows that

$(1 - \gamma')/n \sum_{i=1}^n L(f(X'_i), Y'_i) \leq (1 - \gamma')/n \sum_{i=1}^n L'(f'(X'_i), Y'_i) \leq (1 + \gamma')/n \sum_{i=1}^n L'(f'(X_i), Y_i) + \ln(2N/\delta_1)/(\gamma' n) \leq (1 + \gamma')/n \sum_{i=1}^n \tilde L(f(X_i), Y_i) + \ln(2N/\delta_1)/(\gamma' n)$.

Note that the first and the last inequalities used (4.6). Let $\gamma' = \gamma/(2 - \gamma)$, then it is easy to check algebraically that $(1 - \gamma')/(1 + \gamma') = 1 - \gamma$ and $1/(\gamma'(1 + \gamma')) = (2 - \gamma)^2/(2\gamma)$. We thus obtain

$\forall f \in \mathcal{F}: \underbrace{(1 - \gamma)/n \sum_{i=1}^n L(f(X'_i), Y'_i)}_{\psi_{val}} \leq \underbrace{1/n \sum_{i=1}^n \tilde L(f(X_i), Y_i)}_{\psi_{trn}} + \underbrace{(2 - \gamma)^2 \ln(2N/\delta_1)/(2\gamma n)}_{\epsilon_n^1(\delta_1)}$.

The standard multiplicative Chernoff bound in (2.11) implies that with probability $1 - \delta_2$,

$\underbrace{(1 - \gamma)(1 - \gamma) E_{(X,Y)\sim D} L(f(X),Y)}_{\psi_{ust}} \leq \underbrace{(1 - \gamma)/n \sum_{i=1}^n L(f(X'_i), Y'_i)}_{\psi_{val}} + \underbrace{(1 - \gamma) \ln(1/\delta_2)/(2\gamma n)}_{\epsilon_n^2(\delta_2)}$.

Therefore in Lemma 4.11, we can use symbols as displayed, together with $\delta_1 = 2\delta/3$ and $\delta_2 = \delta/3$ to obtain the desired bound.

Similar to Corollary 4.13, one may also obtain an oracle inequality from Theorem 4.21, which we will not state here.

## Example 4.22
Consider binary classification with classifier $f(w, X) \in \mathbb{R}$ and $Y \in \{\pm1\}$. The classification loss is

$L(f(X), Y) = \mathbb{I}(f(X)Y \leq 0)$,

and the margin loss for $\gamma > 0$ is

$\tilde L(f(X), Y) = \mathbb{I}(f(X)Y \leq \gamma)$.
