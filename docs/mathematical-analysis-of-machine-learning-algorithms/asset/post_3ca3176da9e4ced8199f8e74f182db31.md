
## Appendix A Basics of Convex Analysis

We informally review some basic concepts of convex functions used in this book. For readability, we avoid nonessential technical conditions that may be needed for mathematical rigor. A more formal and rigorous treatment of convex analysis can be found in (Rockafellar, 2015).

### A.1 Definitions

**Definition A.1** A set $\Omega$ in a vector space is a convex set if for all $w,w'\in\Omega$ and $\alpha\in[0,1]$, $\alpha w+(1-\alpha)w'\in\Omega$. A real-valued function $\phi(w)$ of $w$ is a convex function on a convex set $\Omega$ if its epigraph $\{(w,t)\in\Omega\times\mathbb{R}: t\ge\phi(w)\}$ is a convex set.

We also say that a function $\phi(w)$ is concave if $-\phi(w)$ is convex.

**Proposition A.2** *A function $\phi(w)$ is convex on $\Omega$ if and only if for all $\alpha\in(0,1)$ and $w,w'\in\Omega$,*
$$\phi(\alpha w+(1-\alpha)w')\le\alpha\phi(w)+(1-\alpha)\phi(w').$$

**Proposition A.3** *A function $\phi(w)$ is convex on $\Omega$ if for all $w\in\Omega$, there exists a vector $g$ such that for all $w'\in\Omega$,*
$$\phi(w')\ge\phi(w)+g^\top(w'-w).$$
*Here $g$ is referred to as a subgradient in convex analysis, which may not necessarily be unique.*

*If a convex function $\phi(w)$ is differentiable at an interior point $w\in\Omega$, then $g=\nabla\phi(w)$ is unique.*

Without causing confusion, we will use $\nabla\phi(w)$ to denote an arbitrary subgradient of a convex function $\phi(w)$ in this book. An example of nonunique subgradient is given by the one-dimensional convex function $\phi(w)=|w|$, for which any $g\in[-1,1]$ is a subgradient at $w=0$.

**Definition A.4** Given $\lambda>0$, a function $\phi(w)$ is $\lambda$-strongly convex in $w$ if for all $w,w'\in\Omega$,
$$\phi(w')\ge\phi(w)+\nabla\phi(w)^\top(w'-w)+\frac{\lambda}{2}\|w-w'\|_2^2.$$

A strongly convex function may not be differentiable. An example is the one-dimensional function $\phi(w)=|w|+\frac12 w^2$, which is $\lambda=1$ strongly convex, but not differentiable at $w=0$. The following definition is frequently used in theoretical analysis. It can be applied even for nonconvex functions.

**Definition A.5** A function $\phi(w)$ (which may not necessarily be convex) on $\Omega$ is $L$-smooth if it is differentiable and for all $w,w'\in\Omega$,
$$\|\nabla\phi(w')-\nabla\phi(w)\|_2\le L\|w-w'\|_2.$$
We say $\phi(w)$ is $G$-Lipschitz if for all $w\in\Omega$,
$$\|\nabla\phi(w)\|_2\le G.$$

**Proposition A.6** If $\phi(w)$ is $L$-smooth, then for any $w,w'\in\Omega$,
$$\phi(w')\le\phi(w)+\nabla\phi(w)^\top(w'-w)+\frac{L}{2}\|w-w'\|_2^2,$$
and $\|\nabla^2\phi(w)\|_2\le L$. If $\phi$ is $G$-Lipschitz, then for any $w,w'\in\Omega$,
$$|\phi(w)-\phi(w')|\le G\|w-w'\|_2.$$

### A.2 Basic Properties

We list some results for convex functions that are useful in the analysis of this book.

**Proposition A.7** If $\phi(w)$ is $L$-smooth on $\mathbb{R}^d$, then for all $w,w'\in\mathbb{R}^d$,
$$\|\nabla\phi(w')-\nabla\phi(w)\|_2^2\le 2L\left[\phi(w)-\phi(w')-\nabla\phi(w')^\top(w-w')\right].$$

*Proof* Let
$$\widetilde{\phi}(w)=\phi(w)-\phi(w')-\nabla\phi(w')^\top(w-w').$$
Then $\widetilde{\phi}(w)$ is $L$-smooth, and $\widetilde{\phi}(w)\ge0$ due to convexity. Let $\eta=1/L$, then
$$0\le\widetilde{\phi}(w-\eta\nabla\widetilde{\phi}(w))$$
$$\le\widetilde{\phi}(w)-\eta\nabla\widetilde{\phi}(w)^\top\nabla\widetilde{\phi}(w)+\frac{\eta^2L}{2}\|\nabla\widetilde{\phi}(w)\|_2^2$$
$$=\widetilde{\phi}(w)-\frac{1}{2L}\|\nabla\widetilde{\phi}(w)\|_2^2.$$
The second inequality used Proposition A.6. This implies the desired bound. $\square$

**Proposition A.8** *If $\phi(w)$ is convex on a closed convex set $\Omega$ and*
$$w_*=\arg\min_{w\in\Omega}\phi(w),$$
*then there exists a subgradient $\nabla\phi(w_*)$ such that for all $w\in\Omega$,*
$$\nabla\phi(w_*)^\top(w-w_*)\ge0.$$
*Moreover, if $\phi(w)$ is $\lambda$-strongly convex, and there exists a real number $g\ge0$ such that for all $w\in\Omega$,*
$$\nabla\phi(w)^\top(w_*-w)\ge -g\|w-w_*\|_2,$$
*then $\|w_*-w\|_2\le g/\lambda$.*

*Proof* The first result follows from the theory of convex optimization (Boyd and Vandenberghe, 2004; Rockafellar, 2015), which says that $w_*$ is a minimizer of $\phi(w)$ on $\Omega$ if there exists a subgradient $\nabla\phi(w_*)$ such that
$$\forall w\in\Omega:\ \nabla\phi(w_*)^\top(w-w_*)\ge0.$$

Using the definition of strong convexity, we obtain
$$\phi(w_*)\ge\phi(w)+\nabla\phi(w)^\top(w_*-w)+\frac{\lambda}{2}\|w_*-w\|_2^2,$$
$$\phi(w)\ge\phi(w_*)+\nabla\phi(w_*)^\top(w-w_*)+\frac{\lambda}{2}\|w_*-w\|_2^2\ge\phi(w_*)+\frac{\lambda}{2}\|w_*-w\|_2^2.$$

Summing up the two inequalities, we obtain
$$0\ge\nabla\phi(w)^\top(w_*-w)+\lambda\|w-w_*\|_2^2\ge -g\|w-w_*\|_2+\lambda\|w-w_*\|_2^2.$$

This implies the second bound.

We also use the following result regularly in the book.

**Proposition A.9 (Jensen's Inequality)** *Assume that $\phi(w)$ is a convex function on $\Omega$. Consider $w_1,\ldots,w_m\in\Omega$, and nonnegative numbers $\alpha_1,\ldots,\alpha_m\in\mathbb{R}$ so that $\sum_{i=1}^m\alpha_i=1$. Then*
$$\phi\left(\sum_{i=1}^m\alpha_iw_i\right)\le\sum_{i=1}^m\alpha_i\phi(w_i).$$

More generally, let $p$ be a probability measure on $\Omega$, then $\phi(\mathbb{E}_{w\sim p}w)\le\mathbb{E}_{w\sim p}\phi(w)$.

*Proof* Let $w=\sum_{i=1}^m\alpha_iw_i$. Using convexity, we know that for each $i$,
$$\phi(w_i)\ge\phi(w)+\nabla\phi(w)^\top(w_i-w),$$
where $\nabla\phi(w)$ is a subgradient of $\phi$. Multiply by $\alpha_i$ and sum over $i$, we obtain
$$\sum_{i=1}^m\alpha_i\phi(w_i)\ge\phi(w)+\nabla\phi(w)^\top\sum_{i=1}^m\alpha_i(w_i-w)=\phi(w).$$

This finishes the proof. The more general inequality can be proved similarly.

This result implies that the hinge loss
$$\phi(w)=\sup_{y}\max[0,b_y-x_y^\top w]$$
is convex on $\mathbb{R}^d$, where $(x_y,b_y)\in\mathbb{R}^d\times\mathbb{R}$.

**Proposition A.15** *Let $\phi(z)$ be a convex function on $\mathbb{R}^q$, and let $A$ be a $q\times d$ matrix. Then $\phi(Aw)$ is a convex function on $\mathbb{R}^d$.*

**Proposition A.16** *If $\phi(z)$ is convex on $\Omega$, then $t\phi(z/t)$ is convex on $\{(z,t): z/t\in\Omega,\ t\in\mathbb{R}_+\}$.*

*Proof* We have
$$(\alpha t+(1-\alpha)t')\phi\left(\frac{\alpha z+(1-\alpha)z'}{\alpha t+(1-\alpha)t'}\right) = (\alpha t+(1-\alpha)t')\phi\left(\frac{\alpha t(z/t)+(1-\alpha)t'(z'/t')}{\alpha t+(1-\alpha)t'}\right) \le \alpha t\phi(z/t)+(1-\alpha)t'\phi(z'/t').\qquad\text{(Jensen's inequality)}$$

This proves the convexity of $t\phi(z/t)$.

### A.4 Matrix Trace Functions

We can also directly form convex functions for symmetric matrices.

**Definition A.17** *Let $f(z)$ be a real-valued function. For a symmetric matrix $W$ with decomposition $W=U^\top\Lambda U$, where $\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_d)$ is a diagonal matrix and $U$ is an orthogonal matrix, we define*
$$f(W)=U^\top f(\Lambda)U,$$
*where $f(\Lambda)=\operatorname{diag}(f(\lambda_1),\ldots,f(\lambda_d))$.*

*If $f(z)$ is differentiable with derivative $f'(z)$, then it is not difficult to check that*
$$\left.\frac{d}{dt}\operatorname{trace}(f(W+t\Delta W))\right|_{t=0}=\operatorname{trace}(f'(W)\Delta W).$$

**Theorem A.18** *Let $S_{[a,b]}^d$ be the set of $d\times d$ symmetric matrices with eigenvalues in $[a,b]$. If $f:[a,b]\to\mathbb{R}$ is a convex function, then*
$$\operatorname{trace}(f(W))$$
*is a convex function on $S_{[a,b]}^d$. This implies that for $W,W'\in S_{[a,b]}^d$,*
$$\operatorname{trace}(f(W'))\ge\operatorname{trace}(f(W))+\operatorname{trace}(f'(W)(W'-W)),$$
*where $f'(z)$ is the derivative of $f(z)$.*

This proves the first desired result. For the second result, we note that
$$D_f(P\parallel Q)=\mathbb{E}_{z\sim Q}\left[f\left(\frac{p(z)}{q(z)}\right)-f(1)-g\left(\frac{p(z)}{q(z)}-1\right)\right],$$
which is zero only when $p(z)/q(z)=1$ almost everywhere.

The following result shows that $f$-divergence is jointly convex in $P$ and $Q$.

**Proposition B.3** *Given any $\alpha\in[0,1]$, probability measures $P$, $P'$, $Q$, $Q'$, we have*
$$D_f(\alpha P+(1-\alpha)P'\parallel\alpha Q+(1-\alpha)Q')\le\alpha D_f(P\parallel Q)+(1-\alpha)D_f(P'\parallel Q').$$

*Proof* This is a direct consequence of the fact that the function $q f(p/q)$ is jointly convex in $(p,q)\in\mathbb{R}_+\times\mathbb{R}_+$ (see Proposition A.16).

The following data-processing inequality of $f$-divergence is very useful for establishing lower bounds for statistical estimation.

**Theorem B.4 (Data Processing Inequality)** *Let $W$ and $Z$ be two random variables on $\Omega$. Let $h:\Omega\to\Omega'$ be a data processing map which can be a random function. Then*
$$D_f(h(W)\parallel h(Z))\le D_f(W\parallel Z).$$

*Proof* Let $W$ and $Z$ be distributed according to probability measures $P(W)d\mu$ and $Q(Z)d\mu$, respectively. Let $W'=h(W)$ and $Z'=h(Z)$. Let $P(W,W')$ and $Q(Z,Z')$ be the joint distributions of $[W,W']$ and $[Z,Z']$. By the definition of data processing, the conditional distribution satisfies
$$Q(Z'=x'|Z=x)=P(W'=x'|W=x).$$
