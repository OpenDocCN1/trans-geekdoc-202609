Then there exists a subgradient $\nabla\phi(w_*)$ such that for all $w\in\Omega$,

$$\nabla\phi(w_*)^\top(w-w_*)\ge 0.$$

Moreover, if $\phi(w)$ is $\lambda$-strongly convex, and there exists a real number $g\ge 0$ such that

$$\nabla\phi(w)^\top(w_*-w)\ge -g\|w-w_*\|_2,$$

then $\|w_*-w\|_2\le g/\lambda$.

*Proof*  The first result follows from the theory of convex optimization (Boyd and Vandenberghe, 2004; Rockafellar, 2015), which says that $w_*$ is a minimizer of $\phi(w)$ on $\Omega$ if there exists a sub-gradient $\nabla\phi(w_*)$ such that

$$\forall w\in\Omega:\ \nabla\phi(w_*)^\top(w-w_*)\ge 0.$$

Using the definition of strong convexity, we obtain

$$\phi(w_*)\ge\phi(w)+\nabla\phi(w)^\top(w_*-w)+\frac{\lambda}{2}\|w_*-w\|_2^2,$$

$$\phi(w)\ge\phi(w_*)+\nabla\phi(w_*)^\top(w-w_*)+\frac{\lambda}{2}\|w_*-w\|_2^2\ge\phi(w_*)+\frac{\lambda}{2}\|w_*-w\|_2^2.$$

Summing up the two inequalities, we obtain

$$0\ge\nabla\phi(w)^\top(w_*-w)+\lambda\|w-w_*\|_2^2\ge -g\|w-w_*\|_2+\lambda\|w-w_*\|_2^2.$$

This implies the second bound.

We also use the following result regularly in the book.

# **Proposition A.9 (Jensen’s Inequality)**

*Assume that $\phi(w)$ is a convex function on $\Omega$. Consider $w_1,\ldots,w_m\in\Omega$, and nonnegative numbers $\alpha_1,\ldots,\alpha_m\in\mathbb{R}$ so that $\sum_{i=1}^m\alpha_i=1$. Then*

$$\phi\left(\sum_{i=1}^{m}\alpha_iw_i\right)\le\sum_{i=1}^{m}\alpha_i\phi(w_i).$$

More generally, let $p$ be a probability measure on $\Omega$, then $\phi(\mathbb{E}_{w\sim p}w)\le\mathbb{E}_{w\sim p}\phi(w)$.

*Proof*  Let $w=\sum_{i=1}^{m}\alpha_iw_i$. Using convexity, we know that for each $i$,

$$\phi(w_i)\ge\phi(w)+\nabla\phi(w)^\top(w_i-w),$$

where $\nabla\phi(w)$ is a sub-gradient of $\phi$. Multiply by $\alpha_i$ and sum over $i$, we obtain

$$\sum_{i=1}^{m}\alpha_i\phi(w_i)\ge\phi(w)+\nabla\phi(w)^\top\sum_{i=1}^{m}\alpha_i(w_i-w)=\phi(w).$$

This finishes the proof. The more general inequality can be proved similarly.
