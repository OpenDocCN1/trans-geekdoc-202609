$$Q(	heta,q)=\sum_{j=1}^{d}Q_j(	heta,q),$$

*where $Q_j \ge 0$ are all nonnegative. For any $j$ and $\tau$, let $\tau^{-[j]}$ be the index that differs with $\tau$ only by one coordinate $j$. Assume there exists $\epsilon,\beta \ge 0$ such that*

$$\forall\tau:\quad [Q_j(\theta,q^{\tau})+Q_j(\theta,q^{\tau^{-[j]}})]\ge\epsilon.$$

*Assume for some $\hat q \in \mathcal{P}_{\mathcal{A}}$,*

$$\sup_{q,q'\in\mathcal{P}_{\mathcal{Z}}}\sup_{\mathcal{S}_{t-1}}\mathrm{KL}\big(q(\cdot|\hat q(\mathcal{S}_{t-1}),\mathcal{S}_{t-1})\|q'(\cdot|\hat q(\mathcal{S}_{t-1}),\mathcal{S}_{t-1})\big)\le\beta_t^2.$$

*If $\sum_{t=1}^n \beta_t^2 \le (d/32 - 1)$, then $r_n(\hat q,\mathcal{P}_d,Q) \ge d\epsilon/16$.*

*Proof* Consider drawing $\tau_i \in \{\pm1\}^d$ from uniform distribution $i=1,\dots,N$, where $N = \lfloor\exp(d/16)\rfloor$. For any fixed $1 \le i < j \le N$, using the Chernoff bound with $|\tau_i - \tau_j| \in [0,2]^d$ and $\mathbb{E}\|\tau_i - \tau_j\|_1 = d$, we obtain

$$\Pr\big(\|\tau_i - \tau_j\|_1 \le d/2\big) \le \exp(-d/8).$$

Therefore

$$\Pr\big(\exists i \ne j : \|\tau_i - \tau_j\|_1 \le d/2\big) \le N(N-1)\exp(-d/8) < 1.$$

It follows there exists a subset of $T$ of $\{\pm1\}^d$ with $N$ members so that for $\tau_i \ne \tau_j \in T$,

$$\frac12\|\tau_i - \tau_j\|_1 \ge d/4.$$

This implies that $$Q(\theta,q^{\tau_i})+Q(\theta,q^{\tau_j}) \ge d\epsilon/4.$$ It follows that $$m = \sup_{\theta\in\Theta}\big|\{k: Q(\theta,q^{\tau_k}) < d\epsilon/8\}\big| = 1.$$ Since the condition of the corollary implies that $$\ln(N) \ge \ln 4 + 2\sum_{t=1}^n \beta_t^2,$$ the desired result is a direct consequence of Theorem 13.22.
