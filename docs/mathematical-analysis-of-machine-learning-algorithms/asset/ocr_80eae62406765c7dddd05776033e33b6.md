This result implies that the hinge loss

$\phi(w)=\sup_{y}\max[0,b_y - x_y^{\top} w]$

is convex on $\mathbb{R}^d$, where $(x_y,b_y)\in\mathbb{R}^d\times\mathbb{R}$.

# Proposition A.15

Let $\phi(z)$ be a convex function on $\mathbb{R}^q$, and let $A$ be a $q\times d$ matrix. Then

$\phi(Aw)$

is a convex function on $\mathbb{R}^d$.

# Proposition A.16

If $\phi(z)$ is convex on $\Omega$, then $t\phi(z/t)$ is convex on $\{(z/t,t)\in\Omega\times\mathbb{R}_+\}$.

Proof We have

$(\alpha t+(1-\alpha)t')\phi\left(\frac{\alpha z+(1-\alpha)z'}{\alpha t+(1-\alpha)t'}\right)$
$= (\alpha t+(1-\alpha)t')\phi\left(\frac{\alpha t(z/t)+(1-\alpha)t'(z'/t')}{\alpha t+(1-\alpha)t'}\right)$
$\le \alpha t\phi(z/t)+(1-\alpha)t'\phi(z'/t').\qquad\text{(Jensen's inequality)}$

This proves the convexity of $t\phi(z/t)$.

# A.4 Matrix Trace Functions

We can also directly form convex functions for symmetric matrices.

# Definition A.17

Let $f(z)$ be a real-valued function. For a symmetric matrix $W$ with decomposition $W=U^{\top}\Lambda U$, where $\Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_d)$ is a diagonal matrix, and $U$ orthogonal matrix, we define

$f(W)=U^{\top}f(\Lambda)U,$

where $f(\Lambda)=\operatorname{diag}(f(\lambda_1),\dots,f(\lambda_d))$.

If $f(z)$ is differentiable with derivative $f'(z)$, then it is not difficult to check that

$\left.\frac{d}{dt}\operatorname{trace}(f(W+t\Delta W))\right|_{t=0}=\operatorname{trace}(f'(W)\Delta W).$

The following result is useful in some of the theoretical analysis in the book.

# Theorem A.18

Let $S_{[a,b]}^d$ be the set of $d\times d$ symmetric matrices with eigenvalues in $[a,b]$. If $f(z):[a,b]\to\mathbb{R}$ is a convex function, then

$\operatorname{trace}(f(W))$

is a convex function on $S_{[a,b]}^d$. This implies that for $W,W'\in S_{[a,b]}^d$,

$\operatorname{trace}(f(W'))\ge\operatorname{trace}(f(W))+\operatorname{trace}(f'(W)(W'-W)),$

where $f'(z)$ is the derivative of $f(z)$.
