### 1: PHP 注释可以嵌套吗？

**答案：**

### 2: echo 和 print 有什么区别？

**答案：**
echo 和 print 都是用于在控制台打印的 PHP 语言结构。主要区别在于 echo 不返回任何值，而 print 返回值。这使得 echo 比 print 更快。

### 3: PHP 中有哪些不同类型的错误？

**答案：**
PHP 有三种不同类型的错误：

- a) 通知：非平凡且非关键的错误，不会导致脚本终止。例如，使用尚未定义的变量。
- b) 警告：例如，尝试包含不存在的文件。默认情况下，这些错误会显示给用户。
- c) 致命错误：这些会导致脚本终止。例如，调用不存在的函数。

这些可列出如下 –

- E_ERROR: 导致脚本终止的致命错误
- E_WARNING: 运行时警告，不会导致脚本终止
- E_PARSE: 编译时解析错误。
- E_NOTICE: 由于代码错误引起的运行时通知
- E_CORE_ERROR: PHP 初始启动（安装）期间发生的致命错误
- E_CORE_WARNING: PHP 初始启动期间发生的警告
- E_COMPILE_ERROR: 指示脚本存在问题的致命编译时错误。
- E_USER_ERROR: 用户生成的错误消息。
- E_USER_WARNING: 用户生成的警告消息。
- E_USER_NOTICE: 用户生成的通知消息。
- E_STRICT: 运行时通知。
- E_RECOVERABLE_ERROR: 可捕获的致命错误，指示危险错误
- E_ALL: 捕获所有错误和警告

## 正则表达式

### 106：什么是贪婪正则表达式匹配？PHP 正则表达式是贪婪的吗？如何解决这个问题？

回答：
正则表达式也称为 regex。正则表达式中的标准量词是贪婪的，意味着它们会尽可能多地匹配，只在必要时回溯以匹配正则表达式的其余部分。我们在正则表达式内使用“?”来抑制这种行为。

### 107：preg_replace 和 ereg_replace 有什么区别？

回答：
ereg_replace 使用基本版本的正则表达式，而 preg_replace 使用 Perl 兼容的正则表达式。

### 108：你能写一个 PHP 正则表达式来检查电子邮件地址是否有效吗？

回答：
```
/^[^@\s]+@([-a-z0-9]+\.)+[a-z]{2,}$/i
```

### 109：你能写一个 PHP 函数从 HTML 文档中提取 URL 吗？

回答：
```
function pc_link_extractor($s) {
    $a = array();
    if (preg_match_all('/<a\s+.*?href=[\"\' ]?([^\"\' >]*)[\"\' ]?[^>]*>(.*)<\/a>/i', $s, $matches, PREG_SET_ORDER)) {
        foreach($matches as $match) {
            array_push($a,array($match[1],$match[2]));
        }
    }
    return $a;
}
```

### 110：如何使用 PHP 的正则表达式从字符串 'http://xyz@a...' 中提取字符串 'abc.com'？

回答：
可以将 "/.*(@(.*))$/" 作为正则表达式模式与 preg_match() 函数一起使用。例如：

```
preg_match("/.*(@(.*))$/","http://xyz@abc.com",$data);
echo $data[1];
```

### 9: 你会形容自己是内向的人还是外向的人吗？

### 回答：

这两种性格各有其有益的品质，你的答案可能取决于你从事的工作类型。然而，成功的领导者可能是内向者，也可能是外向者，同样，可靠的团队成员也可能是其中任何一种。这个问题的重要方面在于，你要具备足够的自我觉察，以准确地描述自己。

### 10: 你不具备哪些积极的性格特质？

### 回答：

如果面试官问及你的弱点或缺乏积极特质等棘手问题，最好保持回答轻松简单——例如，首先表达你对自身能力的巨大信心，然后（相当谦虚地）承认自己偶尔需要更谦逊一些。

### 11: 你学到的最大教训是什么？

### 回答：

虽然这是一个非常宽泛的问题，但面试官更感兴趣的是听听你对这一价值观的重视程度。你最大的教训可能与导师、父母或教授曾经告诉过你的某事有关，或者你可能从你所在领域的顶尖专家写的一本书中领悟到了这一点。无论这个教训是什么，最重要的是你能举例说明如何将其融入你的生活。

### 12: 你是否遇到过一种情况，其中你的某个优势在不同环境下变成了劣势？

### 回答：

能够回答这个问题很重要，这表明你有自我觉察，但你要确保该弱点相对较小，并且在大多数情况下它仍然是一种优势。例如，你可能是个爱读书的人，能找到的任何东西都会读，但开车上班时阅读广告牌可能是个危险的主意。

### 13: 谁是你生活中最有影响力的人？

### 回答：

举一个具体例子（并点名）那个对你影响巨大的人，并讲述一个关于你们之间有意义交流的相关轶事。如果他们的影响与你的职业生活相关固然很好，但这个问题也为讨论你个人生活中的启发提供了可能。面试官想看看你是否能与他人建立牢固的联系，并在他人的引导下工作。

### 14: 你认为自己是“注重细节”还是“宏观把握”型的人？

### 回答：

这两种都是很好的品质，最好能在你的回答中结合两者。选择一种作为你的主要类型，并将其与你的经验或简历中的具体项目相关联。然后，解释另一种类型如何也融入你的工作。

### 15: 你最大的恐惧是什么？

### 回答：

公开且毫无尴尬地透露你最大的恐惧，是向雇主展示自信的好方法。选择一个你正在努力克服的恐惧，比如对失败的恐惧——对面试官来说，像你这样有着如此清晰目标和行动计划的人，失败似乎是不可能的。虽然选择蜘蛛这种简单答案很诱人，但请避开这些，因为它们并不能真正告诉面试官关于你的任何相关信息。

### 16: 你喜欢什么样的挑战？

### 回答：

你喜欢的挑战应体现你的某种主动性或成长潜力，并应与你的职业目标一致。雇主会在此评估一致性，他们会批判性地分析你期待的挑战如何与你的最终目标相关联。

### 17: 谈谈一次你尴尬的经历。你是如何处理的？

### 回答：

没有人想在求职面试中提起自己尴尬的时刻，这里最好避免讲轶事。然而，不要回避提供一个简短的概述，然后展示你能一笑置之的能力。向面试官表明这不是一件对你产生重大影响的事件。

### 18: 你最大的弱点是什么？

### 回答：

这是求职面试中最常见的问题之一，因此你应该提前准备好答案。试着想出一个你拥有的弱点，这个弱点在不同环境下实际上可能是一种优势——例如：“我非常注重细节，喜欢确保事情做得正确，因此我有时在将任务委派给他人方面会有困难。”然而，不要试图掩饰明显的弱点——如果你在该领域缺乏实践经验，请提及你期待着有机会进一步提升自己的知识。

### 19: 在工作环境中，哪三个形容词最能描述你？

### 回答：

虽然这三个形容词可能已经出现在你的简历某处，但不要害怕再次使用它们，以突出你的最佳品质。这是一个向面试官推销自己，并指出你拥有而其他候选人没有的特质的机会。使用你能想到的最具体、最准确的词汇，并简要阐述你如何体现每一个特质。

### 20: 在个人生活中，哪三个形容词最能描述你？

### 回答：

理想情况下，描述你个人生活的三个形容词应该与描述你职业生活的形容词相似。雇主欣赏一致性，虽然他们可能理解你在办公室之外有不同的个性，但最好是在工作和非工作时间都遵循类似的原则。

### 21: 你是哪类员工？

### 回答：

这是一个突出你一些最大优势的机会。描述你的一些才能，如专注、自我驱动、注重细节、充满热情、勤奋、善于分析或以客户服务为导向。这里避开你的弱点，专注于你能为公司带来的所有美好事物。

### 22: 谈谈你工作中最快乐的一天。

### 回答：

你工作中最快乐的一天应包括你最大的职业成功之一，以及它让你的感受。专注于你取得了什么，并务必详细阐述这项成就对你来说有多有回报或多么令人满意。

### 23: 谈谈你工作中最糟糕的一天。

### 回答：


那可能是有史以来最糟糕的一天，因为你犯了很多错误，或者因为你刚和好朋友吵了一架，但请务必保持回答的专业性。尝试使用工作场所中发生的不可控事件作为例子（例如团队中重要成员意外离职，破坏了团队与客户的会议），并着重描述无法掌控局面的挫败感。保持简洁，并务必以反思你从这一天学到的内容作为结尾。

### 24: 你热衷于什么？

### 回答：

尽可能保持回答的专业性，但也可以适当讨论你热衷的个人议题（例如环境问题或在施粥所做志愿者）。关注非争议性议题，并让你的热情展现出来，说明是什么启发了你对该话题的热爱，以及你如何保持积极参与。此外，如果你选择个人热情，请确保它不会影响你的工作可用性或生产力。

### 25: 你最常收到的批评是什么？

### 回答：

对这个问题给出诚实、坦率的回答可以大大给面试官留下深刻印象（当然，前提是要说明你正在做出哪些改进），但请确保批评内容是次要的，或与你的职业无关。

### 26: 你在哪种工作环境中最能取得成功？

### 回答：

在参加面试前，请务必研究公司和具体职位。根据你将要从事的工作量身定制回答，并解释为什么你更喜欢那种环境而非其他环境。但是，适应性也非常重要，因此要对其他环境保持灵活性。

### 27: 你是一个情绪化的人吗？

### 回答：

最好专注于你的积极情绪——热情、幸福感、动力——并远离可能让你显得不稳定的其他极端情绪。虽然你想展示对工作的兴奋，但请始终保持冷静和理智，让面试官知道你不是那种让情绪左右自己、影响工作的人。

### 28: 你如何做决定？

### 回答：

这是一个绝佳的机会，可以凭借你的果断、自信和组织能力给面试官留下深刻印象。请务必概述你的决策流程，并强调权衡各选项的重要性，以及相信直觉的价值。如果你能娴熟而从容地回答这个问题，面试官就会信任你作为一名员工的能力。

### 29: 对你来说，最难做出的决定是什么？

### 回答：

说明你与决策之间的关系，以及你做选择时通常采取的流程概述。如果有一种你经常难以处理的特定类型决策，例如涉及其他人群体的决策，请务必解释那种决策对你来说为何困难，以及你目前如何致力于提升相关技能。

### 30: 做艰难决定时，你如何收集信息？

### 回答：

做出艰难选择时，最好从尽可能多的来源收集信息。引导面试官了解你如何从不同领域的人那里获取信息：首先征求所在领域专家的建议，了解同事或其他客户的反馈，并分析性地回顾自己的过往经历。

### 31: 谈谈你做过的一个结果不理想的决定。

### 回答：

诚实和透明是面试官会赞赏的优秀品质——概述你做出的选择、做出该选择的原因、错误决策的结果，以及最后（也是最重要的！）你从中吸取的教训。让面试官有理由相信你未来不会再做出类似的决定。

### 32: 你能快速做决定吗？

### 回答：

你可能能够快速做决定，但请务必传达你做出审慎、彻底决策的能力。讨论快速做决定的重要性以及你如何做到这一点，以及每项决定首先必须基于充分信息的必要性。

### 33: 什么是客户服务？

### 回答：

客户服务可以是许多事情——这个问题最重要的考量在于你要有一个有创意的答案。通过给出超越基本定义、展示你真正思考过何为照顾客户的个人观点的自信回答，来展现你跳出常规思维的能力。你对客户的深思熟虑将不言自明。

### 34: 谈谈你曾为客户付出超出职责范围努力的一次经历。

### 回答：

重要的是你要提供一个你确实付出了超额努力的例子——要小心不要将你觉得费了很大劲的事情与雇主本就期望你完成的工作混淆。提供客户的问题、你如何解决它，以及你处理完情况后客户的反应。

### 35: 你如何赢得客户的信任？

### 回答：

这是一个非常开放的问题，允许你向面试官展示你的客户服务技能。可能的答案有很多，最好选择你有丰富经验的内容，例如“通过透明地处理情况”、“提供奖励”或“注重良好沟通”。提供你取得成功的具体例子。

### 36: 谈谈一次客户感到不安或激动的经历——你是如何处理的？

### 回答：

与处理与其他员工的争端类似，回答这个问题最重要的部分是先设定场景，提供你特定冲突解决风格的逐步指南，最后描述冲突是如何解决的。在回答关于你自身冲突解决风格的问题时，请务必强调双方坦诚沟通和理解的重要性，以及达成妥协或其他解决方案的意愿。

### 37: 你什么时候可以为客户破例？

### 回答：

当符合公司政策或在主管指示下时，通常可以为客户破例。展示你对应考虑破例的情境类型的理解，例如客户经历了特定困难、订单出现问题，或客户提出请求时。

### 38: 当客户和老板同时需要你时，你会怎么做？

### 回答：

虽然你的客户和老板对你有不同的需求，且都对你作为员工的成功至关重要，但最好始终优先处理客户的事务——不过，关键是向老板解释客户为什么急需你，然后向老板保证你会尽快处理他的或她的需求（除非是绝对紧急的事情）。

### 39: 客户服务中最重要的方面是什么？

### 回答：

许多人可能简单地说客户满意度是客户服务中最重要的方面，但能够阐述客户服务情境中其他重要技巧也很重要。解释为什么客户服务是商业的关键部分，并务必以有理有据、深思熟虑的方式详细阐述你认为最重要的方面。

### 40: 对客户设定低期望还是高期望更好？

### 回答：

你可以任意回答这个问题（当然，前提是确定公司对此事没有明确立场）。但是，无论你如何回答，都必须展示出彻底的思考过程，以及对你所选选项非常清晰的理由。列出各方优缺点，并包括最终支持你所选答案的关键点。

### 41: 你的技能如何与公司的 X 目标相匹配？

### 回答：

如果你在面试前研究过公司，回答这个问题应该不成问题。确定公司的几个主要目标，并解释你拥有的哪些具体技能有助于实现这些目标。同时，思考你的经验和技能可以如何转化为帮助公司扩张的方式。





基于这些目标，并实现更远大的目标。如果您之前的公司有类似目标，请举例说明您如何帮助公司实现该目标。

### 42: 您认为这份工作包括哪些内容？

回答：

请务必在面试前充分了解该职位。阅读您能找到的所有职位描述（最好是直接来自雇主网站或招聘信息），并记下关键的职责、义务和所需经验。对面试官来说，几乎没有比面试者对自己应聘的工作一无所知更不令人印象深刻的了。

### 43: 关于这份工作或公司，您还有什么想了解的吗？

回答：

如果您事先了解过公司，这是一个展示您在面试前下功夫研究的绝佳机会。询问与公司使命相关的当前行业趋势的问题，并与面试官进行有趣、相关的交谈。此外，在离开前弄清楚您需要知道的关于特定职位的任何其他事项——这样，如果面试官打电话给您发出录用通知，您就可以准备好回答。

### 44: 您是这个职位的最佳候选人吗？

回答：

是的！请提供具体细节，说明是什么让您有资格担任此职位，并务必讨论（并展示）您对新机会、这份工作和公司的无拘无束的热情和激情。

### 45: 您如何为这次面试做准备？

回答：

这个问题的关键在于确保您已经做好准备！请务必在面试前研究公司、他们的目标和服务，并尽可能多地了解特定职位。了解公司历史和当前组织中的关键人物也很有帮助。

### 46: 如果您被这里录用，第一天会做什么？

回答：

虽然许多人会以一种无聊的方式回答这个问题，走一遍标准的第一天流程，但这个问题实际上是一个绝佳的机会，向面试官展示您为何会是一位出色的雇员。除了参加培训或定向等事情之外，请强调您会多么享受与主管和同事见面，或者您会花大量时间提问并了解您的新环境。

### 47: 您浏览过我们公司的网站吗？

回答：

很明显，您在来面试之前应该已经浏览过公司网站并对其做了一些初步研究。如果出于某种原因您没有，请不要说浏览过，因为面试官可能会通过询问关于它的具体问题来揭穿您。如果您确实浏览过公司网站，此时可以提及您在那里看到的特别感兴趣的事情，或您特别支持的某个价值观。

### 48: 您简历中的X经验与此职位有何关联？

回答：

许多申请人的简历上会有一些与所问具体工作不明确相关的经验。但是，请做好被问及这种看似不相关经验的准备，并准备好回答，考虑到两者可能共享的类似技能或培训。

### 49: 您为什么想要这个职位？

回答：

请保持此回答积极，关注这份特定工作的那些方面，这些方面将使您能够进一步提升技能、提供新经验，或让您有机会做自己特别喜欢的事情。不要告诉面试官您找工作已很长时间，或薪资非常有吸引力，否则您会显得缺乏动机且投机取巧。

### 50: 您的背景与此职位有何关联？

回答：

理想情况下，这从您的简历中应该很明显。但是，在您的经验与职位关系较松散的情况下，请确保在面试前很好地研究了工作和公司。这样，您就可以明智地将您拥有的经验和技能与新职位所需的类似技能相关联。具体说明您的技能将如何转化，并使用“准备”和“学习”等词语来描述您的背景。您的潜在职位应被描述为一个“机会”和“成长与发展”的机会。

### 51: 您对我们公司的X使命有何感受？

回答：

在面试前研究公司很重要——如果您已经做了，这个问题就不会让您措手不及。最好的回答是简单、切题，并显示出对手头使命的了解。提供几条简短的陈述，说明您为什么相信使命的重要性，并注明您有兴趣有机会与一家支持该使命的公司合作。

最后祝好运！
