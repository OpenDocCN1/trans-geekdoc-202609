# 155: Does PHP provide HTTP authentication when it is run as a CGI?

Answer:
No, this functionality is available only when it is running as an
Apache module.

# 156: How can you send an email using PHP?

Answer:
PHP contains one function called mail() to send an email. This
uses the SMTP mail server to send the message.

# 158: Can you access Microsoft Access database with PHP?

Answer:
One needs to have Microsoft's ODBC drivers for Microsoft Access
database for accessing it with PHP.

# 159: Can $_SERVER['HTTP_REFERER'] be blank?

Answer:
Yes, $_SERVER['HTTP_REFERER'] can be blank as not all
browsers set this. And this needs to be set only when referrer is a
link.

# 161: What's the basic difference between md5() and crc32()?

Answer:
The length of the hash generated for md5() is 160 bits and for
crc32(), it is 32 bits.
