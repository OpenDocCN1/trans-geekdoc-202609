# 142: What precaution needs to be taken in case one needs to use configuration files for PHP (.ini)?

Answer:
One should avoid storing the configuration file in web root
directory. If that is necessary, one needs to protect that using
.htaccess file by mentioning who can access that file. Additionally,
sensitive data should always be encrypted.

# 143: What is email injection attack?

Answer:
An email injection attack occurs when a hacker uses the email
form to send email in an undesired way. This can have multiple
impacts such as eating out bandwidth, getting blocked as a
spammer etc.
