## PHP 基础

### 1: PHP 注释可以嵌套吗？

**答案：**
PHP 支持 C、C++ 和 Perl 风格的注释。PHP C 风格注释不能嵌套。

### 2: echo 和 print 有什么区别？

**答案：**
echo 和 print 都是用于在控制台打印的 PHP 语言结构。主要区别在于 echo 不返回任何值，而 print 返回值。这使得 echo 比 print 更快。

### 3: PHP 中有哪些不同类型的错误？

**答案：**
PHP 有三种不同类型的错误：

- a) 通知：非平凡且非关键的错误，不会导致脚本终止。例如，使用尚未定义的变量。
- b) 警告：例如，尝试包含不存在的文件。默认情况下，这些错误会显示给用户。
- c) 致命错误：这些会导致脚本终止。例如，调用不存在的函数。

这些可列出如下 –

- E_ERROR: 导致脚本终止的致命错误
- E_WARNING: 运行时警告，不会导致脚本终止
- E_PARSE: 编译时解析错误。
- E_NOTICE: 由于代码错误引起的运行时通知
- E_CORE_ERROR: PHP 初始启动（安装）期间发生的致命错误
- E_CORE_WARNING: PHP 初始启动期间发生的警告
- E_COMPILE_ERROR: 指示脚本存在问题的致命编译时错误。
- E_USER_ERROR: 用户生成的错误消息。
- E_USER_WARNING: 用户生成的警告消息。
- E_USER_NOTICE: 用户生成的通知消息。
- E_STRICT: 运行时通知。
- E_RECOVERABLE_ERROR: 可捕获的致命错误，指示危险错误
- E_ALL: 捕获所有错误和警告

### 4: 可以从 PHP 脚本中知道屏幕分辨率吗？如果可以，如何做到？如果不可以，为什么？

**答案：**
由于 PHP 是一种服务器端脚本语言，它无法知道客户端详细信息。PHP 能够了解浏览器的原因是，该信息通过 HTTP 头部发送到 Web 服务器。

### 5: 函数 unlink 和 unset 有什么区别？

**答案：**
unlink 是用于文件系统处理、用于删除文件的函数，而 unset 是用于销毁变量的函数。

### 6: 在 PHP 中如何将整个文件读入字符串？

**答案：**
可以使用 file_get_contents 将整个文件读入单个字符串。

### 7: PHP4 和 PHP5 之间最重要的区别是什么？

**答案：**
PHP4 不支持 OOP，但 PHP5 支持 OOP。

### 8: PHP 中的类型转换是什么？

**答案：**
类型转换意味着 PHP 在变量声明时不需要显式定义类型。变量的类型由变量使用的上下文决定。也就是说，如果将字符串值赋给变量 $var，$var 就变成字符串。如果随后将整数值赋给 $var，它就变成整数。

### 9: 如何使用 PHP 对多维数组进行排序？

**答案：** 这可以通过 PHP 中的 array_multisort 函数完成。

### 10: 如何判断值是否在数组中？

**答案：** 这可以通过 PHP 中的 in_array() 函数完成

### 11: 如何找出传递到函数中的参数数量？

**答案：** func_num_args() 函数返回传入的参数数量。

### 12: PHP 是否支持按引用传递？

**答案：** 是的，PHP 支持按引用传递。

### 13: print 和 printf 有什么区别？

**答案：** Print 是语言结构，而 printf 是函数。Printf 允许格式化输出，而 print 不允许。

### 14: 如何在 PHP 中找到字符串的 MD5 哈希值？

**答案：** md5() 函数计算 PHP 中字符串的 MD5 哈希值。

### 15: 什么是 Zend 引擎？

**答案：** Zend 引擎是开源脚本引擎，通常因其在 Web 自动化语言 PHP 中发挥的重要作用而闻名。

### 16: 应该使用单引号字符串还是双引号字符串？

**答案：**
对于变量替换，我们需要使用双引号字符串。如果不需要，出于速度考虑，我们应该使用单引号字符串。

### 17: 如何重定向 PHP 页面？

**答案：** 这可以通过 PHP 函数 header() 完成。

### 18: urlencode() 函数的用途是什么？

**答案：** Urlencode() 返回给定字符串的 URL 编码版本。URL 编码的字符串可以安全地用作 URL 的一部分。

### 19: PHP 语言结构区分大小写吗？

**答案：** 不，PHP 结构不区分大小写。

### 20: PHP 变量名区分大小写吗？

**答案：** 是的，PHP 变量区分大小写。

### 21: 如何在 PHP 中从数组中选取随机值？

**答案：** 这可以通过 PHP 中的 array_rand() 函数实现。

### 22: 如何在 PHP 中获取数组的大小？

**答案：** 可以使用 PHP 中的 count() 函数获取数组的大小。

### 23: 如何在 PHP 中访问远程对象？

**答案：** 我们可以通过使用 CORBA 扩展访问远程对象。

### 24: PHP 字符串是不可变的吗？

**答案：** 不，PHP 字符串不是不可变的，它们可以被修改。

### 25: PHP 支持哪些数据库？

**答案：**
MySQL、MSSQL、Sybase、oracle、mSQL、FrontBase 是 PHP 支持的数据库。

### 26: JAVASCRIPT 和 PHP 之间的基本区别是什么？

**答案：**
JavaScript 是客户端脚本语言，而 PHP 是服务器端脚本语言。

### 27: 如何在 PHP 中查找两个字符串之间的相似性？

**答案：**
我们可以使用 similar_text() 函数计算两个字符串之间的相似性。

### 28: 如何在 PHP 中查找字符的 ASCII 值？

**答案：**
可以在 PHP 中使用 ord() 方法获取字符的 ASCII 值。

### 29: 在 PHP 中格式化实数需要使用哪个函数？

**答案：**
PHP 提供了一个名为 number_format() 的函数来格式化实数。

### 30: 假设你有一个字符串，其中包含多个换行符。如何将所有换行符替换为 HTML 换行符？

PHP 有一个名为 nl2br 的函数，用于为换行符插入 HTML 换行符。
