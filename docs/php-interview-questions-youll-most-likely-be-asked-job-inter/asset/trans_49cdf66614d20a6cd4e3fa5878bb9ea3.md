## 表单、Cookie 和会话管理

### 183：如何在 PHP 中防止表单劫持？

用户输入净化（客户端数据验证）、表单提交键验证、防止 SQL 注入攻击等是防止 PHP 中表单劫持的重要因素。

### 184：PHP 将 Cookie 和会话数据存储在哪里？

回答：
PHP 将 Cookie 存储在客户端机器上，将会话数据存储在服务器上。

### 185：GET 和 POST 方法有什么区别？

回答：
GET 方法提交的数据显示为网页 URL 的一部分，因此用于传输小量非敏感数据。POST 方法用于传输敏感和/或大量数据。

### 186：如何编写表单标签以正确上传使用 PHP 的文件？

回答：
为了使上传正常工作，我们需要将 method 设置为 POST，将 enctype 设置为“multipart/form-data”。

### 187：如何使用 PHP 获取浏览器属性？

回答：
可以在 PHP 中使用 echo $_SERVER['HTTP_USER_AGENT'] 获取浏览器属性。此外，还可以使用 get_browser 函数。

### 188：如何使用 PHP 删除 Cookie？

回答：
可以将 Cookie 设置为过去的时间来实现这一点。

### 189：什么是持久 Cookie？

回答：
持久 Cookie 是存储在浏览器机器上的永久 Cookie。持久 Cookie 可用于跟踪长期信息。

### 190：如何读取已设置的 Cookie 的值？

回答：
在设置 Cookie 的请求期间，Cookie 的值在 $_COOKIE 中不可用。换句话说，setcookie() 函数不会更改 $_COOKIE 的值。但是，在后续请求中，每个 Cookie 都存储在 $_COOKIE 中。

### 191：如何更改 PHP 中的默认会话时间？

回答：
PHP 中的默认会话时间为 1440 秒，可以在 PHP.ini 文件中更改。

### 193：可以将会话数据存储在数据库中而不是纯文件中吗？这样做的优势是什么？

### 194：在 PHP 中一次可以有多个活动会话对象吗？

### 195：当需要在页面之间保留数据时，应如何处理多页面表单？

### 196：您知道表单重新提交问题吗？如何解决这个问题？

### 197：如果禁用了客户端 Cookie，会话会怎样？

回答：
会话是一种在服务器端工作的 Cookie。为了使会话在服务器端工作，服务器端和客户端浏览器都应启用 Cookie。但是，即使客户端禁用了 Cookie，会话也可以工作。这是通过使用 URL 会话传递实现的。

### 198：PHP 中的会话是什么意思？

回答：
会话是特定用户的页面请求之间持久化信息的机制。调用 session_start() 后，$_SESSION 超全局中存储的数据将继续可由通过 Cookie、POST 变量或 GET 参数标识的客户端在未来的页面请求中访问。

### 199：要使用我们自己的会话处理函数，需要使用哪个函数？

回答：
需要使用 session_set_save_handler 来使用我们自己的会话处理函数。

可以计算数据的 MD5 哈希值，并在收到相同数据时对其进行验证。
