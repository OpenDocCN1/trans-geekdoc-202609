# 'http://xyz@a...' using regular_expression of PHP?

Answer:

We can use the preg_match() function with "/.*(@(.*))$/" as the regular expression pattern. For example:

```
preg_match("/.*(@(.*))$/","http://xyz@abc.com",$data);
echo $data[1];
```
