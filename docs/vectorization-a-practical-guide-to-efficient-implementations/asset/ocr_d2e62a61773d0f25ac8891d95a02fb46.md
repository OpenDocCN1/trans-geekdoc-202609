# 5.1.2 Changing Elements Using the where Operation

Other than using pre-existing masking operations to replace values, more often, we need to replace/mask values based on conditions. For example, given a grey-scale image of size 256 x 256, we would like to apply a threshold to the image, such that pixel values above this threshold are marked as the foreground (bright), and pixel values below this threshold are marked as the background (dark), so that the processed image can be used for subsequent tasks such as image segmentation. We can do this by using np.where(condition, x, y), where condition is our boolean or binary mask.

```
import numpy as np
import matplotlib.pyplot as plt
import skimage # pip install scikit-image==0.21.0
image = skimage.data.coins()

# image thresholding to remove background
image_thresh = np.where(image > 150, image, 0)

# plot the images
fig, axs = plt.subplots(1, 2)
axs[0].imshow(image, cmap="gray")
axs[0].set_title("Original")
axs[1].imshow(image_thresh, cmap="gray")
axs[1].set_title("Thresholded")
```

The code generates the plots as illustrated in Figure 5.3. The where(condition, x, y) syntax of the where operations implemented in NumPy, Tensorflow, and PyTorch is helpful for such “thresholding”-like operations, where it conditionally replaces the value in x using values from y, where x, y, and condition need to be broadcastable to each other. In the specific case of masking, we would typically replace the elements at the index corresponding to the True values in conditions with some masking values such as 0s.
