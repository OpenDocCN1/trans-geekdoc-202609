# 7.2.3 Column-wise Broadcasting

Similarly, for column-wise broadcasting, in NumPy using dense matrices, this can be done with broadcasting

```
mat_dense + array_c[:, np.newaxis]
```

On sparse matrices, suppose we have a `csc` matrix `mat_csc` of size `M x N` and a vector `array_c` of size `N`. If we want to broadcast the vector to all the columns of the sparse matrix (see also Figure 7.10), we can do

```
mat_csc.data += np.take(array_c, mat_csc.indices)
```

Again, for other types of sparse matrices, first convert to `csc_matrix` with `tocsc()`, make the broadcasting calculation, and then convert it back to the original format if needed. This can be implemented as

```
def R_plus_cv(R, cv):
    """Sparse matrix plus a column vector"""
    R = R.tocsc()
    R.data += np.take(cv, R.indices)
    return R
```
