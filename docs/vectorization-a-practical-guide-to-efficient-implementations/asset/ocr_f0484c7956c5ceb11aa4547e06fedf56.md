# ## 7.2 Sparse Matrix Broadcasting

There are many cases where we want to add, subtract, or normalize over columns, rows, or the entire matrix, without affecting the missing data. In this section, we are going to consider several cases of sparse matrix broadcasting.

# ### 7.2.1 Scalar Broadcasting

Unlike numpy, simply adding a scalar on the sparse matrix with mat_csc + 1 will give us the error.

> NotImplementedError: adding a nonzero scalar to a sparse matrix is not supported

Fortunately, the actual data of the matrix is stored in .data attribute as a numpy.ndarray. Therefore, we can simply modify the .data attributes,

```
mat_csc.data += 1
```
