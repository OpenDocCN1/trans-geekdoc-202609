NumPy, Tensorflow (through `tf.experimental.numpy`), and PyTorch also implement a special where operation, `nonzero`, and its flat version `flatnonzero` (only in NumPy). # 3.2 Slicing

In Section 3.1, we have looked at ways to retrieve a single element using different indexing systems. However, sometimes, we would also like to select a segment or an interval of values from an array. This is known as **slicing**. In Python, we can “slice” an array by selecting elements between a start and an end index of a list `l` using the syntax `l[start:stop]`. For example, let `l = [1, 3, 5, 7, 9]`, and we would like to select all elements starting from index 1 to index 4 (excluded), using `l[1:4]`, which returns `[3, 5, 7]`. Similar to **slicing** is the concept of **striding**: instead of selecting all consecutive elements between two indices, **striding** selects elements between two indices by consistently skipping over a certain number of elements, with the syntax `l[start:stop:step]`. For example, suppose we would like to select every other element between index 1 and index 4 (excludes) (i.e. skipping 1 element when selecting between the indices, or selecting every second element. We can use `l[1:4:2]`, which returns `[3, 7]`. Additional commonly used slicing and striding syntaxes in Python are listed in Table 3.1.
