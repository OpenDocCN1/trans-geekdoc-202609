covers a variety of use cases. This is a common operation in many machine learning applications such as convolutional neural networks. In image classification using a convolutional neural network, it is typical to represent the input images either as (batch_size, height, width, channels) (Tensorflow convention) or (batch_size, channels, height, width). Notice that the two conventions represent a set of images, but the dimensions of the tensors are not in the same order. To convert from the Tensorflow convention to the PyTorch convention, we can leverage the transpose operations.

```
import numpy as np
image_tf = np.random.rand(8, 32, 15, 3)
image_torch = np.transpose(image_tf, axes=[0, 3, 1, 2])
```

Though it takes two lines, we can also use np.swapaxes

```
image_torch = np.swapaxes(image_tf, 1, 3) # (8, 3, 15, 32)
image_torch = np.swapaxes(image_torch, 2, 3) # (8, 3, 32, 15)
```

Note PyTorch torch.Tensor has torch.Tensor.t() method for matrix transpose (<=2 dimensions). NumPy's np.ndarray has np.ndarray.T for tensor transpose, which essentially reverses the ordering of the dimensions. This probably corresponds to the typical mathematical notation for transpose, i.e. <sup>T</sup>. The transpose of a 1D array is still a 1D array, as there are no additional dimensions to swap with.

e) NumPy's np.ndarray.flatten method will always return a copy of the data. To return a view (if possible), use np.ravel instead. PyTorch's torch.flatten is more similar to np.ravel which will return a view if possible. Tensorflow's tf.experimental.numpy.flatten method will also return a view if possible as its underlying implementation uses tf.reshape. Note that it is also important to pay attention to the concept of order when flattening arrays.
