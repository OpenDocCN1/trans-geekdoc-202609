## 7 Sparse Matrix

As a data scientist who developed the recommender system for a media streaming platform, I often worked with sparse data. In the most classic examples of recommender systems such as Netflix or MovieLens dataset, we have data on the ratings of specific items by the users. For example, a customer may give a 4.5-star rating on a movie. However, given there are millions or even billions of users, and tens of thousands of titles on Netflix (or millions to billions in the context of e-commerce like Amazon and Alibaba), it is not possible for every user to give a rating on every single piece of content. Oftentimes, we will have most of the users rating on several items, and most of the items will only have some tens to hundreds of users to rate them. If we imagine this as a matrix where the rows represent the user IDs, whereas the columns represent the item ID, then we have a very large matrix, but only with a small percentage of it filled in. Most of the entries in this matrix will be empty (see Figure 7.1, for example). This matrix, with most of the values missing or empty, is called a **sparse matrix**. The task of a recommender system is often to predict the ratings on these missing entries in order to make recommendations to users on new items.

We can, in theory, fill these missing values with zeros and use `numpy.ndarray` or `pandas.DataFrame` to represent it. But every 0 we store in our memory or disk is probably a waste of memory or storage space. Also, if we fill these missing values with 0s, then we would not be able to distinguish cases where a user literally rates a book with 0 stars (although most rating systems probably do not allow it, perhaps also consider other types of data where a value of 0 is distinguished from missing values). Therefore, it makes more sense to store only the entries of the matrix where it contains actual data collected from the users. Sparse matrix data structures are designed exactly for this purpose. Sparse matrices can be implemented in various ways, using different indexing and data value storage logics.

## 7.1 Scipy's Sparse Matrix Classes

scipy [Virtanen et al., 2020] implements seven different sparse matrix data structures under its `scipy.sparse` API [Virtanen et al., 2023]. Each sparse matrix data structure has its pros and cons. All seven types can be constructed from dense arrays (with 0s assumed to be empty for numerical data and an empty string “” assumed to be empty for string data). All seven types are inter-convertible from each other. Some are good for slicing the matrix and doing arithmetic operations, while others are better used for constructing the data matrix from other data structures. In the following sections, we will analyze each one of them.

### 7.1.1 Coordinate Sparse Matrix (coo_matrix)

`coo_matrix` is the best and fastest format for constructing a new sparse matrix using large arrays and row/column indices. This is probably the most intuitive way to store a sparse matrix: by storing its row/column coordinates, as well as the data at these corresponding coordinates. Once the sparse matrix is constructed, one can easily cast it from `coo_matrix` to other sparse matrix formats.
