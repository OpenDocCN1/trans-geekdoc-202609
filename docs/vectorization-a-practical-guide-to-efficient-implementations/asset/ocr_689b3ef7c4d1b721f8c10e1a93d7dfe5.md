y_masked = y * mask + masked_value * (1 - mask)

+   Line 5 gets the index of the top-k values

+   Line 7 initializes the mask which will indicate the values to keep as 1s and values to discard as 0s.

+   Line 9 does an in-place replacement to put 1s at indices where the values will be kept.

+   Line 12 applies the masking. mask is binary (1s and 0s). The element-wise multiplication y * mask will set all masked/discarded values to be zeros first. Then, the masked_value * (1 - mask) will then set the masked entries to the masked_value (i.e. when the value is to be masked, value:= 0 + masked_value = masked_value; otherwise, value:= value + 0 = value).
