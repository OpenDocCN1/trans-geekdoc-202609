# Table 6.1 List of string transformation operations in Python, NumPy, Pandas, and Tensorflow.

| Operation | Python | NumPy | Pandas | Tensorflow |
|---|---|---|---|---|
| Strip space/newline | strip | np.char.strip | pd.Series.str.strip | tf.strings.strip |
| Substring | slicing | Use np.char.find, then slicing | pd.Series.str.slice | tf.strings.substr |
| Upper casing | upper | np.char.upper | pd.Series.str.upper | tf.strings.upper |
| Lower casing | lower | np.char.lower | pd.Series.str.lower | tf.strings.lower |
| Join | join | np.char.join | pd.Series.str.join | tf.strings.join, tf.strings.reduce:join |
| Split | split | np.char.split | pd.Series.str.split | tf.strings.split |
| Length | len | np.char.str_len | pd.Series.str.len | tf.strings.length |
| Formatting | format, f-string | np.char.mod | pd.Series.map, pd.Series.apply | tf.strings.format |
| Convert to string | str, format, f-string | np.ndarray.astype( str) | pd.Series.astype(str) | tf.strings.as_string |
| String to number | int, float | np.ndarray.astype( <int, float>) | pd.to_numeric, pd.Series.astype(dtype) | tf.string.to_number |
| Replace Contains, is substring | replace, regex in, regex | np.char.replace np.char.count(...) > 0 | pd.Series.str.replace pd.Series.str.contains, pd.Series.str.match, pd.Series.str.fullmatch | tf.strings.regex_replace tf.strings.regex_full_match |
