We can ask several questions about the behaviors of the users and the items from this dataset:

+   1. How many viewing hours each user has on an average?
+   2. How many movies does each user watch on an average?
+   3. How many hours does each user spend on each movie?

To answer these questions, we first need to group the feature values from the same users or items together and then compute summary statistics on the features within the groups. For instance, for the question of how many viewing hours each user has on average, we need to first identify how many total viewing hours user 1 has, then user 2 has, then user 3 has, ... etc. In Pandas, this is often done by using the `.groupby(...) .agg()` pattern applied on a `pandas.DataFrame`.
