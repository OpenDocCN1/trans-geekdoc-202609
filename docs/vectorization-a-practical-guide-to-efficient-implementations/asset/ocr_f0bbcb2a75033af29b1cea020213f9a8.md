We can easily verify that the results are identical to the dense operation X.numpy() @ b_mat.numpy().T

```
array([[ 8.],
 [ 0.],
 [ 2.],
 [ 2.],
 [ 2.],
 [10.]])
```

An operation that tf.SparseTensor cannot perform is the sparse-to-sparse matrix multiplication. This can be done with the csr matrix, using sparse_csr_matrix_ops.sparse_matrix_sparse_mat_mul [Abadi et al., 2023c]. For example, let's compute XX^T.

```
res = sparse_csr_matrix_ops.sparse_matrix_sparse_mat_mul(
 a=csr_sparse, b=csr_sparse, type=tf.float32, transpose_b=True,
 )
# converting back to dense
res = sparse_csr_matrix_ops.csr_sparse_matrix_to_dense(
 res, type=tf.float32
 )
```

We can easily verify that the result is the same as using the dense matrix multiplication procedure X.numpy() @ X.numpy().T:

```
array([[4., .0, 0., 0., .0, 2.],
 [0., 1., 0., 0., .0, 0.],
 [0., .0, 1., 1., .0, 2.],
 [0., 0., 1., 1., .0, 2.],
 [0., 0., 0., 0., 4., .0],
 [2., .0, 2., 2., .0, 9.]], dtype=float32)
```
