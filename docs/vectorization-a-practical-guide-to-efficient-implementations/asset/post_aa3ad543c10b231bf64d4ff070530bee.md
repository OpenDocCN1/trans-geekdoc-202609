

Furthermore, to sample multiple items simultaneously without replacement, instead of obtaining the argmax of the perturbed logits, we can obtain top-k indices from the list of perturbed logits for all classes.

In the following code sample, we will implement a function that solves the negative sampling problem when training a multi-label classification model, where the positive labels may include multiple classes. For example, in object detection tasks, a single image may contain multiple objects (e.g. an apple and a cup on a table), so the label will be ["apple", "cup", "table"]. We would like to create negative labels so that the model can learn the image does not contain certain items, such as ["cat", "cereal", "spoon", "fork"]. Since an image may contain a variable number of objects, we therefore use a ragged sparse tensor to represent the labels (recall in Chapter 8). We also assume the labels are already converted from string to 1-based indices (recall in Chapter 6).

```python
import numpy as np
import tensorflow as tf

def gumbel_max_sample_without_replacement(
     true_labels: tf.SparseTensor,
     num_neg_samples: int,
     vocab_size: int,
     vocab_freq: tf.Tensor = None,
     shuffle: bool = True,
 ):
 """
 Use Gumbel-Max trick to select negative samples.
 * true_labels: (batch_size, None)
 * Positive / label class indices, 1-based indexing
 num_neg_samples:
 Number of negative samples to take
 * vocab_size:
 Number of items in the categorical variable
 * vocab_freq:
 The distribution of the classes to take samples from.
 Does not have to be normalized.
 If None, assuming uniform sampling.
 * shuffle:
 Whether or not to shuffle the results so that the
 positive labels are not always at the beginning of
 the resulting sample.
 """
 # Default to uniform sampling if vocab_freq is None
 if vocab_freq is None:
     vocab_freq = tf.ones((vocab_size,), tf.float32)
 # Compute proba for the batch
 true_proba = tf.sparse.to_indicator(
     true_labels, vocab_size + 1
 )
 true_proba = true_proba[:, :1]  # get rid of OOV bucket
 true_proba = tf.cast(true_proba, tf.float32)
 neg_proba = (1.0 - true_proba) * vocab_freq
 # Gumbel-Max trick: perturbed logits
 z = -tf.math.log(
     -tf.math.log(
         tf.random.uniform(tf.shape(neg_proba), 0, 1)
     )
 )
 z += tf.math.log(neg_proba + 1e-8)
 # set true targets as -inf, so it won't be sampled
 z = tf.where(
     tf.greater(true_proba, 0.5), -np.inf, z
 )
 # Take negative samples
 _, neg_samples = tf.math.top_k(
     z, num_neg_samples, sorted=False
 )  # (batch size, num_neg_samples)
 # offset by 1, since we use 1-based indexing
 neg_samples = tf.cast(neg_samples, tf.int64) + 1
 # Concat to make the full sample: positive + negative
 samples = tf.concat([
     tf.sparse.to_dense(true_labels),
     -neg_samples
 ], axis=1)
 # shuffle
 if shuffle:
     # generating random ordered indices
     r = tf.random.uniform(tf.shape(samples))
     r = tf.argsort(r, axis=1)
     # Apply the shuffled indices
     samples = tf.gather(samples, r, axis=1, batch_dims=1)
 # Convert to sparse
 samples = tf.sparse.from_dense(samples)
 # Left align
 row_indices = samples.indices[:, 0]
 row_counts = tf.unique_with_counts(
     row_indices, out_idx=tf.int64
 ).count
 column_indices = tf.ragged.range(row_counts).flat_values
 indices = tf.transpose(tf.stack([row_indices, column_indices]))
 binary_labels = tf.SparseTensor(
     indices=indices,
     values=tf.where(samples.values > 0, 1.0, 0.0),
     dense_shape=samples.dense_shape,
 )
 samples = tf.SparseTensor(
     indices=indices,
     values=tf.abs(samples.values),
     dense_shape=samples.dense_shape,
 )
 return samples, binary_labels
```

- Lines 29–30: When `vocab_freq` is None, we assume we want to take the negative samples uniform randomly. Hence, we initialize the `vocab_freq` to be an array of 1s.
- Lines 33–35 convert the labels from sparse indices to the binary representation of the data, where the values at the label indices will be set to `True` and everything else is set to `False`. Since we use 1-based indexing, we need `vocab_size` + 1 number of buckets.
- Line 36 removes the out-of-vocabulary (oov) bucket. During training time, we should not expect any oov items.
- Line 37 casts from boolean dtype to float dtype, since we will use the binary representations to implement the Gumbel-Max trick later on. Values at the label indices will be set to `1.0` and everything else is set to `0.0`.
- Line 38 creates an array of sampling probabilities for the negative classes. Here, the positive classes will have a sampling probability of `0.0`, while everything else has a probability proportional to the `vocab_freq`. The `neg_proba` is the unnormalized probability. We will not normalize `neg_proba` since it will not matter for our Gumbel-Max formulation, as we have seen in our derivations of Equations 10.2 and 10.3.
- Lines 41–45 take an array of random samples from the standard Gumbel distribution based on Equation 10.4.
- Line 46 completes the implementation of perturbed logits formulation, by adding the `log(p_i)` term. Inside the `tf.math.log` operation, we add a small smoothing factor to make sure we can take the log on the positive labels as well, which currently is set to zero.
- Lines 48–50 set the perturbed logits for the positive labels to $-\infty$. Although the perturbed logits at the positive labels were set to a small value, which after log transformation, become a negative number with large magnitude, there is still a chance that positive values will be sampled, if some of the negative samples have unnormalized probability less than our smoothing factor $10^{-8}$. Therefore, these lines will make sure the positive labels will never be sampled in practice.
- Lines 53–55 take top-k negative samples based on the Gumbel-Max formulation.
- Line 57 shifts the indices by 1 so that the indices of the negative samples align with the indices of the input positive labels.
- Lines 59–62 concatenate the two tensors, one containing the positive label indices (which is first converted to a dense tensor), and one containing the negative sample indices (which are denoted as negative numbers). Since we are using 1-based indexing, all valid entries of the resulting tensor `samples` should be nonzeros. Also, since the positive labels vary in length for each example in the batch, there will be some “gaps” between positive labels and negative samples (which will be padded as 0s. See Figure 10.5a for an illustration of the `samples` tensor), which will be corrected later on.

This can be seen as another Gumbel-Max trick implementation, with the sampling probabilities of each class being equal to each other. Therefore, we only need to take samples from a uniform distribution to sort the entries in the array, skipping the log and double negative log transformation steps.
- Line 73 converts the dense tensors (after shuffling, if needed) to sparse tensors. Still, the original concatenated dense tensors have zero entries, which become “gaps” when converted to dense tensors.
- Lines 76–81 implement indices that are used to left-align the sparse tensors, as we have seen in Chapter 8. The same indices can be applied to both `samples` and `binary_labels`, therefore, I opted to reimplement the logic rather than calling a preexisting function.
- Lines 82–86 create the `binary_labels` left-aligned sparse tensor to indicate which entries within the final `samples` tensor will be positive labels, and which ones will be negative samples. We determine the value of the label (1 or 0) based on the sign of the entries in `samples`.
- Lines 87–91 create the left-aligned `samples` tensor and convert the sampled class indices to positive values by taking the absolute value. See Figure 10.5 for an illustration.

Finally, we can verify the implementation by examining the sampling frequency of the negative samples via a simulation

```python
from collections import Counter
import numpy as np

def simulate_gumbel_max(
    batch_size=1024,
    max_num_pos_samples=5,
    num_neg_samples=10,
    vocab_size=100,
    num_iter=100,
    vocab_freq=None,
):
    """Get sampling frequency of each negative class."""
    """Initialize the counter"""
    neg_sample_freq = Counter()
    for _ in range(num_iter):
        true_labels = []
        # Generate positive samples iteratively
        for num_pos in np.random.choice(
            np.arange(1, max_num_pos_samples+1),
            size=batch_size,
            replace=True
        ):
            pos_samples = np.random.choice(
                np.arange(1, vocab_size+1),
                size=num_pos,
                replace=False,
            )
            true_labels.append(pos_samples)
        # Convert to left aligned sparse
        true_labels = tf.ragged.constant(
            true_labels, dtype=tf.int64
        ).to_sparse()
```
