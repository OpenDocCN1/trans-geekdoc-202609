# 3.1.3 Boolean Indexing

Instead of using integers to select elements from the tensor, we can also use a tensor of boolean indicators whose shape is identical to the input tensor to select the desired elements. This way of indexing is helpful for us to select elements based on logical conditions. Let’s suppose again we have a 2D matrix X, and we would like to select all the odd values from the tensor.

```
import numpy as np

X = np.array([
    [5, 2, 8, 3],
    [4, 9, 6, 7],
    [8, 11, 12, 10]
])

# Boolean condition of odd elements
# same shape as X
condition = X % 2 == 1

# Extract the odd elements
X[condition]
# array([5, 3, 9, 7, 11])
```

In Chapter 5, we will introduce the concept of masking. In fact, selecting elements from a tensor-based on a boolean condition can also be considered as a boolean masking operation (i.e. removing unselected elements).

On the other hand, we can also find the indices of the boolean conditions, using the .where operation. Consider the same 2D matrix as above, we can find the indices of the odd numbers in the matrix using

```
import numpy as np

X = np.array([
    [5, 2, 8, 3],
    [4, 9, 6, 7],
    [8, 11, 12, 10]
])

# indices of odd elements
row_index, col_index = np.where(X % 2 == 1)

# row_index: array([0, 0, 1, 1, 2])
# col_index: array([0, 3, 1, 3, 1])
```
