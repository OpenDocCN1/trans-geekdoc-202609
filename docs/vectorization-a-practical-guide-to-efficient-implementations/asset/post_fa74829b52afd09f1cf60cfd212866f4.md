To find the pair of squares, I would first segment the image into multiple patches and then iterate over all combinations of pairs of patches to compute some distance metric against the template. Some combinations would be between one of the squares in the fiducial marker and some lighting artifacts, but only one of them would be a pair of squares matching exactly to the template. This pair should have the smallest distance to the template image. The core template-matching distance metric I found was the Hausdorff Distance [Dubuisson and Jain, 1994].

The original Hausdorff Distance is expressed by the following formula:

max(h(A,B), h(B,A))

where h(A,B) = max(d(Ai,B)) = max_i (min_j ||A_i - B_j||), and || . || is the Euclidean distance. To implement this formula through vectorization, the key here is to compute the Euclidean distance term ||A_i - B_j||, \forall i, j. This creates a matrix of shape (n, m), where n, m are the number of pixels or points in image A and B, respectively. Recall that for a pair of 2D points, the Euclidean distance is defined as

D_{ij} = ||A_i - B_j||
= \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}
= \sqrt{x_i^2 + x_j^2 - 2x_ix_j + y_i^2 + y_j^2 - 2y_iy_j}
= \sqrt{(x_i^2 + y_i^2) + (x_j^2 + y_j^2) - 2(x_ix_j + y_iy_j)}
= \sqrt{A_i \cdot A_i^T + B_j \cdot B_j^T - 2A_i \cdot B_j^T}

Under the square root, the first term is an inner product between row vector $A_i$ and itself; similarly, the second term is an inner product between row vector $B_i$ and itself. Alternatively, the two terms can be seen as the diagonal entries of the matrix products $AA^T$ and $BB^T$, respectively. The third term is the combination of the dot product between each point in matrix A and each point in matrix B. We can therefore implement the Hausdorff distance in the following as

```
import numpy as np
def HausdorffDist(A, B):
    """
    Compute the Hausdorff distance between two point clouds.
    Let A and B be subsets of metric space (Z, dZ),
    the Hausdorff distance between A and B, denoted by dH(A,
    B),
    is defined by:
    dH(A, B) = max(h(A, B), h(B, A)),
    where h(A, B) = max(min(d(a, b)))
    and d(a, b) is a L2 norm
    dist_H = hausdorff(A, B)
    A: First point sets (M1 x N, with M1 observations in N
    dimension)
    B: Second point sets (M2 x N, with M2 observations in N
    dimension)
    ** A and B may have different number of rows, but must
    have the same
    number of columns.
    """
    # Find pairwise distance: (A - B)^2 = A^2 + B ^2 - 2AB
    A_sq = np.einsum('ij,ij->i', A, A)[:, None]
    B_sq = np.einsum('ij,ij->i', B, B)
    AB = np.dot(A, B.T)
    D_mat = A_sq + B_sq - 2 * AB
    D_mat = np.sqrt(D_mat)
    # Find DH
    d_AB = np.min(D_mat, axis=0)
    d_BA = np.min(D_mat, axis=1)
    dH = np.maximum(
    np.max(d_AB),
    np.max(d_BA)
    )
    return(dH)
```

- 1. In Line 19, we can compute the \(A^2\) term as batchwise dot product for each row of \(A\) against itself using the einsum notation "ij, ij->i". Notice we want this to be a column vector by expanding the second dimension, making it shape \((n, 1)\) to facilitate later broadcasting.
- 2. In Line 20, we similarly compute \(B^2\). This is a row vector and will be treated as shape \((1, m)\) implicitly during broadcasting in the later step.
- 3. Line 21 implements the third term as a pair-wise dot product between combinations of rows of \(A\) and \(B\). This forms a matrix of shape \((n, m)\).
- 4. Line 22 implements the pairwise distance by combining all three terms together via broadcasting. This forms a matrix of shape \((n, m)\).
- 5. Line 23 takes the square root of the pair-wise distance matrix, resulting in the final Euclidean distance matrix \(D\).
- 6. Lines 25 and 26 implement the \(d(A, B)\) and \(d(B, A)\) terms. Notice that we implement the asymmetric function by taking the minimum value along different dimensions of the matrix \(D\).
- 7. Lines 27-30 implement the final Hausdorff distance formula.

## Table 4.3 List of linear algebraic routines in NumPy, Tensorflow, and PyTorch.

| Operation | NumPy | Tensorflow | PyTorch |
|---|---|---|---|
| Matrix inverse<sup>a)</sup> | np.linalg.inv | tf.linalg.inv | torch.linalg.inv |
| Moore-Penrose pseudo-inverse<sup>b)</sup> | np.linalg.pinv | tf.linalg.pinv | torch.linalg.pinv |

Notes:

- a) This method finds the square matrix inverse (if the matrix is invertible). Mathematically, let the matrix be $X \in \mathbb{R}^{m \times n}$ (real valued) or $X \in \mathbb{C}^{m \times n}$ (complex valued). Then, the inverse of the square matrix $X^{-1}$ is defined as the $XX^{-1} = X^{-1}X = I$, where $I$ is the identity matrix. The method can be applied in batches, i.e. we can have the input tensor X be of shape (... , m, m) and the `.linalg.inv` method will find the inverse using the matrices formed by the last two dimensions, resulting inverse tensors of the same shape as X.
- b) The Moore-Penrose pseudo-inverse generalizes to non-square matrices. Mathematically, let $X \in \mathbb{R}^{m \times n}$ or $X \in \mathbb{C}^{m \times n}$. Then, the pseudo-inverse is defined as $X^+ = (X^T X)^{-1} X^T$, where $X^+$ is the Hermitian of X (complex conjugate, then transpose; for real matrices, this will simply be $X^T$). [Barata and Hussein, 2012]. Like the `.linalg.inv` method, `.linalg.pinv` can also operate on batches of matrices by solving along the last two dimensions of the input tensor.
- c) Suppose we have a square matrix $X \in \mathbb{R}^{m \times n}$. If $v$ is a unit vector and $\lambda$ is a scalar value, which satisfies the equation $Xv = \lambda v$, then $v$ is the eigenvector and $\lambda$ is the eigenvalue for the matrix X. The `.linalg.eig` method returns the eigenvalues (not ordered) and eigenvectors whose each column is a unit eigenvector. The original X can be recovered via $X = \lambda v v^T$, or (eigenvalues * eigenvectors) `@` `.linalg.inv (eigenvectors)` `@` `.linalg.inv (eigenvectors)`. Like the inverse methods, `.linalg.eig` can also operate on batches of matrices by solving along the last two dimensions of the input tensor.
- d) Singular value decomposition (SVD) is commonly used for classic machine learning algorithms like principal component analysis (PCA). It is defined as $X = U \Sigma V^T$ (for complex matrices, $V^T$ would become the Hermitian $V^H$), where $U \in \mathbb{R}^{m \times m}$ is the left singular factors, $\Sigma \in \mathbb{R}^{m \times n}$ is the singular value matrix whose diagonal values are the singular values, $V \in \mathbb{R}^{n \times n}$ is the right singular factor matrix. Matrices $U$ and $V$ both have the property $UU^T = U^T U = I_m$ and $VV^T = V^T V = I_n$. Therefore, $XX^T = (U \Sigma V^T)(V \Sigma^T U^T) = U \Sigma (V^T V) \Sigma^T U^T = U \Sigma \Sigma^T U^T$, and $X^T X = (V \Sigma^T U^T)(U \Sigma V^T) = V \Sigma^T (U^T U) \Sigma V^T = V \Sigma^T \Sigma V^T$ (Zhang, 2015). Notice that this becomes the eigenvalue problem. We can therefore solve for $U, V, \Sigma$ by performing eigendecomposition on $XX^T$ and $X^T X$. The `.linalg.svd` method returns $U, s$, and $V\_hermitian$ (corresponding to $U$, diagonal entries of $\Sigma$ arranged in descending order, and $V^T$). We can recover the original matrix via U @ (s * np.eye(U.shape[0], Vh.shape[0])) @ V_hermitian. Like all other linear algebra routines, `.linalg.svd` operates on the last two axes of the input tensor. As an example to illustrate:

```
import numpy as np

# Create a cloud of points inside of 3D ellipsoid
n = 2000 # number of points
a, b, c = .10, 6, 1 # axes lengths
# randomly generate
x, y, z = [np.random.uniform(-d, d, n) for d in (a, b, c)]
inside = ((x/a)**2 + (y/b)**2 + (z/c)**2) <= 1.0

# Use SVD to decompose the matrix
X = np.vstack(([x[inside], y[inside], z[inside]])).T
X = X - X.mean(axis=0)
# s returns the standard deviation, sorted descendingly
U, s, Vh = np.linalg.svd(X)

# Recover
X_recovered = U @ (s * np.eye(U.shape[0], Vh.shape[0])) @ Vh
assert np.allclose(X, X_recovered)
```
