14 * A matrix of shape M x N where the element at (i, j) is A[i] - B[j]
15 """

+   Lines 16 and 17 prepare the broadcasting in Line 18. `np.asarray` makes sure that the inputs are NumPy arrays; this means, the function can also accept lists or tuples as inputs. `flatten` makes sure the inputs are one-dimensional arrays. This implies that if the input A is of shape (1, M), we will first convert it to shape (M, ). This then would allow us to use `[:, np.newaxis]` to add a singleton dimension at the second dimension, making it of shape (M, 1). # 2.12.4 Construction of Magic Squares

A magic square is a square matrix of size n x n, with its entries filled with numbers between 1 and n^2, such that each row, column, and the main diagonal have identical sums [Arroyo, 2018]. We can easily verify that when n = 2, this matrix is impossible to construct: given numbers 1, 2, 3, 4, if we want to make sure each row of the matrix to have identical sum, then the sum needs to be 5, and the two ways we can construct them are with (1, 4) and (2, 3). However, regardless of how we arrange them, we cannot make the columns sum to 5 (see two examples in Figure 2.9a,b). Similarly, if we want to make sure each column of the matrix has an identical sum, we again use (1, 4) and (2, 3) pairing for each column. But regardless of how we arrange them, we cannot make sure the rows can be summed to 5 (see two examples in Figure 2.9c,d).
