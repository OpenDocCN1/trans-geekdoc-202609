Let’s examine several basic patterns of using regex in Python in the following examples. But I would like to encourage interested readers to refer to official Python documentation on regex (such as this one “Regular Expression HOWTO” [Kuchling, 2023]) to learn more about this topic.

```
import re

# Example 1: remove punctuation
text = "How is it going? I'm good!"
result = re.sub(r'''[[\.\,?!\ \-\:\;/\\\[\]']''', '', text)
# 'How is it going Im good'

# Example 2: tokenize: spaces and newline
text = """The quick brown fox jumps
over the lazy dog"""
result = re.split(r'\s+', text)
# ['The', 'quick', 'brown', 'fox', 'jumps', 'over',
# 'the', 'lazy', 'dog']

# Example 3: find occurrences of the pattern
text = "The human genome has 3 billion base pairs, "
"making the text file storing it as large as "
"12 GB on disk."
result = re.findall(r'\d+', text)
# ['3', '12']
```

+   • Lines 2–5, Example 1: In this example, we attempt to remove punctuations characters, including period .,question mark ?, exclamation mark !, comma ,, colon :, semicolon ;, double quote ", and apostrophe '. We achieve this by replacing (re.sub or substituting) the character in our list with an empty string. The backslash character \\ is called the escape character, which will make sure the regex treats the character following the backslash as a string character, rather than a special pattern-matching metacharacter, such as .
