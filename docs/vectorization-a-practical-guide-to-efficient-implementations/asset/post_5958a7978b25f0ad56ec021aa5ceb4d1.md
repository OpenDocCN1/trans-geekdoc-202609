
c) Alternatively tf.random.uniform(start, end, shape, dtype=tf.int32) can also be used to draw integers given a range.

d) PyTorch also has the method torch.range, which is end inclusive. This means, torch.range(1, 5) = (1, 2, 3, 4, 5), while all other range methods are end-exclusive. i.e. range(1, 5) = (1, 2, 3, 4).

e) An alternative method to np.eye is np.identity. np.identity only returns matrices with the entries at the main diagonal to be 1s. In contrast, np.eye can return matrices with off-diagonal entries to be 1s. The corresponding methods in Tensorflow tf.eye and PyTorch torch.eye are actually much more similar to np.identity where the matrices returned only have the main diagonal entries set to 1s. Most of these initializers are used in similar ways, where a `shape` and optionally, a `dtype` (discussed in the following section) arguments are needed to construct the tensor. There are four basic categories of tensor initializers:

- 1. **Static value initializers**: Where all the entries of the initialized tensors are filled with a single static value. They include “zeros,” “ones,” “empty,” and “full” initializers.
- 2. **Random value initializers**: Where the entries of the initialized tensors are filled with random values drawn from some distribution, e.g. random uniform, random normal, or random int.
- 3. **Range value initializers**: Where the entries of the initialized tensors are ordered and are within a predefined range of values. They include range and `linspace` initialization operations.
- 4. **Special matrix initializers**: Where they initialize special matrices such as diagonal or identity matrices of various sizes.

### 2.2.1 Tips on Specifying the dtypes During Tensor Initialization

Most tensor initializers listed in the previous section should accept an argument dtype where the user can specify the dtypes of the tensors after construction. Using the zeros initializer as an example:

- For NumPy, x = np.zeros(5, dtype=np.float32) will initialize an array of np.float32 zeros.
- For TensorFlow, x = tf.zeros(5, dtype=tf.float32) will initialize an array of tf.float32 zeros.
- For PyTorch, x = torch.zeros(5, dtype=torch.float32) will initialize an array of torch.float32 zeros.
- Both Tensorflow and PyTorch dtypes are compatible with native Python dtypes. So it is also possible to specify the dtypes using native Python dtypes, although care needs to be taken to make sure desired precision is used. For example, x = tf.zeros(5, dtype=float) is equivalent to x = tf.zeros(5, dtype=tf.float32), which is equivalent to x = tf.zeros(5, dtype=np.float32) (yes, Tensorflow dtypes is also compatible with NumPy's dtypes in many cases), even though native Python's float represents 64-bit floats. However, in PyTorch, x = torch.zeros(5, dtype=float) is equivalent to x = torch.zeros(5, dtype=torch.float64) (using np.float64 will, however, throw an error).

### 2.2.2 Tips on Casting

Casting means to convert one data type to another data type.

- To cast between data types in NumPy, use `x.ndarray.astype(np.dtype)`. For example, x = np.array([1, 2, 3]).astype(np.float32) gives array([1., 2., 3.], dtype=float32)
- To cast between data types in TensorFlow, use `tf.cast(x, tf.dtype)`
- To cast between data types in PyTorch, use `x.type(torch.dtype)`
