# ## 7.7.1 Matrix Factorization

Let the user-item rating matrix $R$ be of shape $N \times M$, where there are $N$ users and $M$ items. $R$ can be approximated by $\hat{R}$, which is a product of two smaller matrices $U$ ($N \times K$) and $W$ ($M \times K$), i.e.

$R \approx \hat{R} = UW^T$

where $U$ is usually called the user matrix (encoding $N$ users), whereas $W$ is the item matrix (encoding $M$ items). $K$ is the number of latent features, which is usually between 10 and 50. Note that our data is arranged as row vectors rather than column vectors that are more commonly used in mathematical derivations.

At prediction time, suppose we want to find the rating for $i$th user and $j$th item, then we only need to calculate

$\hat{r}_{ij} = \vec{u}_i \cdot \vec{w}_j^T$

where $\vec{u}_i, \vec{w}_j$ are length $K$ vectors of user $i$ and item $j$, respectively.

# ## Interpretation

Suppose we have $K = 5$ explicit features, where

+   - $K = 1$ Action/adventure
+   - $K = 2$ Comedy
+   - $K = 3$ Romance
+   - $K = 4$ Horror
+   - $K = 5$ Animation

then,

+   - $u_{i,1}$ means how much user $i$ likes Action/adventure
+   - $u_{i,2}$ means how much user $i$ likes Comedy
+   - $w_{j,1}$ means how much movie $j$ contains Action/adventure
+   - $w_{j,2}$ means how much movie $j$ contains Comedy

Then, the dot product

$\hat{r}_{ij} = \vec{u}_i \cdot \vec{w}_j^T = \|\vec{u}_i\| \|\vec{w}_j\| \cos \theta \propto \text{Similarity}(i,j)$

means how much user $i$ is correlated with movie $j$.

However, in practice, the features are usually **latent**.

# ## 7.7.2 Parameter Updates with ALS

The loss function for this regression problem is the sum-squared error

$J = \sum_{i,j \in \Omega} (r_{ij} - \hat{r}_{ij})^2 = \sum_{i,j \in \Omega} (r_{ij} - \vec{u}_i \vec{w}_j^T)^2$
