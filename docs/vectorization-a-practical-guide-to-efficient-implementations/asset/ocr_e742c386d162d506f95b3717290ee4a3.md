# 4.8 Case Study: Fitting Single Exponential Curves

In my previous studies, I have often found the need to fit exponential curves in the form of y = a exp(bx) + c to describe my data or to forecast a time series trend. I initially used scipy's curve fitting implementation scipy.optimize.curve_fit, but found that the results are sensitive to the initial guesses when the provided data points are noisy. Then, I later discovered the mathematical treatise “Regressions et Equations Integrales” (translated to English as “Regression and Integral Equations”) by Jean Jacquelin [Jacquelin, 2014]. I cannot read French, but the math formula translated well enough such that I was able to follow them step by step. (At the time of the writing, however, I discovered that Joseph R. Fox-Rabinovitz translated Jean Jacquelin's treatise into English; interested readers can find this work at https://scikit-guess.readthedocs.io/en/latest/appendices/references.html#regressions-et-equations-integrales, along with a version of implementation for the methods described in the original paper.) In my description below, I will follow the formulation of the exponential curve as y = a exp(bx) + c instead of y = a + b exp(cx) in the original paper.

> > **Note**
> 
> Many people would argue that more sophisticated machine learning and deep learning algorithms are simply glorified curve fitting. Still, curve fitting may have served as the first introduction to machine learning to many people, including myself.

Suppose we have two vectors, x and y, storing the xy-coordinates of the data points. We initialize S_0 = 0 and build an array of S iteratively, as

$S_k = S_{k-1} + \frac{1}{2}(y_k + y_{k-1})(x_k - x_{k-1})$ (4.1)

Then, to solve b, or the coefficient inside the exponential, we construct the equation

$\begin{bmatrix} \dot{} \\ b \end{bmatrix} = N^{-1}M = \begin{bmatrix} \sum_k(x_k - x_0)^2 & \sum_k(x_k - x_0)S_k \\ \sum_k(x_k - x_0)S_k & \sum_k S_k^2 \end{bmatrix}^{-1} \begin{bmatrix} \sum_k(y_k - y_0)(x_k - x_0) \\ \sum_k(y_k - y_0)S_k \end{bmatrix}$ (4.2)
