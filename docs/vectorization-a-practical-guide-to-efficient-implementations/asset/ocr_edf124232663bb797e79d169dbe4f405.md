PyTorch implementation is below

```
import torch

class Autoencoder(torch.nn.Module):
    def __init__(self, num_items, emb_size):
        super().__init__()
        self.embed = torch.nn.Embedding(
            num_items, emb_size, padding_idx=0
        )
        self.bias = torch.nn.Parameter(torch.zeros([1, emb_size]))
        self.decoder = torch.nn.Sequential(
            torch.nn.ReLU(),
            torch.nn.Linear(emb_size, num_items),
            torch.nn.Sigmoid()
        )

    def forward(self, items, weights=None):
        if weights is None:
            # equal weights
            weights = torch.ones([items.shape[0], 1], dtype=torch.float32)

        # Implement the sparse dense layer (batch_size, emb_size)
        embed = self.embed(items)
        # Apply weights
        embed *= weights[:, :, None]
        # Sum together embeddings
        embed = embed.sum(dim=1)

        # Add bias
        y = embed + self.bias

        # Hidden layer activation
        z = self.decoder(y)

        return z
```

+   • __init__ (Lines 4-14): This method initializes the model class. Unlike the Keras model, we initialize the embedding lookup using torch.nn.Embedding which takes in a dense tensor with 0 paddings (pad_idx=0). The bias term is also specified in this method instead of in a separate method as in Keras. The rest of the layers after the hidden layer are combined together into a single Sequential layer (Keras also has this container layer class, so one can potentially choose to group these layers together as well in the Keras implementation).

+   • forward (Lines 16-34): This method implements the main logic of the autoencoder. Instead of using sparse inputs, this method assumes both items and weights use dense tensors with 0 paddings to represent left-aligned jagged tensors.
