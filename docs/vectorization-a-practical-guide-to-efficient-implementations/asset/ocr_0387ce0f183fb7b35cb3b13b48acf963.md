# 5.2.1 Case Study: Padding in Convolutional Neural Networks

Understanding padding is quite useful when implementing convolutional neural networks . There are two typical padding modes in a convolutional layer: `valid` and `same`. `valid` simply means there is no padding added, and convolution results are smaller than the input. `same` means adding some zero padding to the heights and widths of the convolutional dimensions such that the result of the convolution has the same heights and widths as the input. See Figure 5.12 for an example that compares the differences between the two. See also the below code example to verify the shapes of `same` vs. `valid` padding in convolutional operations.
