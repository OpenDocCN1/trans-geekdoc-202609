# Table 4.1 Examples of tensor multiplication operations in NumPy, Tensorflow, and PyTorch.

| Operation | NumPy | Tensorflow | PyTorch |
|---|---|---|---|
| Dot product<sup>a)</sup> | np.dot | tf.experimental.numpy.dot | torch.dot |
| Complex conjugate dot product<sup>b)</sup> | np.vdot | tf.experimental.numpy.vdot | torch.vdot |
| Inner product<sup>c)</sup> | np.inner | tf.experimental.numpy.inner | torch.inner |
| Outer (cross) product<sup>d)</sup> | np.outer | tf.experimental.numpy.outer | torch.outer |
| Matrix multiplication | np.matmul | tf.matmul | torch.matmul |
| Tensor dot product | np.tensordot | tf.tensordot | torch.tensordot |

Notes:

a) NumPy’s `np.dot` can support dot product between 1D vectors, 2D matrices (which is equivalent to `np.matmul`), or N-D tensor to tensor multiplications. In contrast, `torch.dot` only supports 1D vectors. Tensorflow implements the equivalent operation under the `tf.experimental.numpy` module.

b) `np.vdot` operation applies complex conjugate to the first input before taking the dot product, whereas `np.dot` does not perform complex conjugation. Mathematically, i.e. for two complex vectors $a, b$, $\text{dot}(a, b) = (x_a + i y_a) \cdot (x_b + i y_b)$, where $i$ is the imaginary number. By contrast, $\text{vdot}(a, b) = \bar{a} \cdot b = (\bar{x}_a + i \bar{y}_a) \cdot (x_b + i y_b) = (x_a - i y_a) \cdot (x_b + i y_b)$, where the overline (...) indicates complex conjugates. Note that this definition of dot product between two complex vectors (i.e. `vdot()`) is consistent with MATLAB’s implementation, and perhaps many engineering applications such as Discrete Fourier Transform. However, the mathematical convention for the dot product between two complex vectors uses $(a, b) = \sum_i a_i \bar{b}_i$ instead, where the second argument is complex conjugated. Thus, special attention needs to be paid when translating from mathematics to code when using this function, as the results arising from these two conventions are complex conjugate of each other. When used on multi-dimensional tensors, `np.vdot` will flatten the tensors into 1D vectors before executing the operation. Similar to `torch.dot`, `torch.vdot` only supports 1D vectors for complex conjugate dot products. Tensorflow implements the equivalent operation under the `tf.experimental.numpy` module.

c) `np.inner` operates on a pair of 1D vectors, or at least treating the last dimension of a tensor as 1D vectors. There used to be a function `numpy.core.umath_tests.inner1d` which performs batchwise inner product along rows of a pair of matrices, however, it was deprecated in newer versions of NumPy. Instead, one can use `np.sum(a * b, axis=1)`, or `einsum` operation (which we will introduce in Section 4.4) `np.einsum('ij, ij->i', a, b)`, to achieve the same effect. Note that this einsum operation is not the same as `np.inner` $(a, b)$ as `np.inner` will result in matrix multiplication $a \cdot b^T$ rather than a batchwise operation. We can verify the distinction using the following example:

```
1  a = np.random.rand(5, 8)
2  b = np.random.rand(5, 8)
3  z1 = np.sum(a * b, axis=1) # shape (5, 8)
4  z2 = np.inner(a, b) # shape (5, 5)
5  np.allclose(
6      z2,
7      np.matmul(a, b.T)
8  )
```

d) `np.outer` will flatten any tensors with more than one dimension into vectors before performing the cross product. `torch.outer` only supports 1D vector inputs and will throw an error when receiving multi-dimensional inputs. Tensorflow implements the `outer` operation under the `tf.experimental.numpy` module.
