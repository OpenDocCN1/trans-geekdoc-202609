With the current settings, our model has only ~18 million parameters, which is several magnitudes smaller than the smallest 7B parameter LLaMA model [Touvron et al., 2023a].

Let us train the model using WikiText2 [Merity et al., 2016], which is accessible through `torchtext.datasets.WikiText2` (a copy of the dataset is available on the book supplement repository: https://github.com/sapphire008/vectorization-book-supplement/tree/main/wikitext2, in case `torchtext` fails to get this dataset from a remote source). This corpus has about 2.3 million tokens in the training set. Though it is several magnitudes smaller than the 1 billion+ tokens used to train a full-sized LLaMA [Touvron et al., 2023a], it is sufficient for our purpose of illustrating the concepts.
