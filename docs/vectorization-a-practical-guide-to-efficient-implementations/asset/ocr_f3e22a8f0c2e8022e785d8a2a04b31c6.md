```
1 !pip install memory_profiler==0.61.0
2 %load_ext memory_profiler
```

We also save the above script into a file (which we call memory_allocation_example.py), then we measure the memory trace of each function in the notebook as follows:

```
1 from memory_allocation_example import sum_of_square_vectorized
2 X = np.linspace(-50, 50, 100_000).tolist()
3 %mprun -f sum_of_square_vectorized sum_of_square_vectorized(X)
```

This gives us the following line-by-line memory trace of the function call:

| Line # | Mem usage | Increment | Occurrences | Line Contents |
|---|---|---|---|---|
| 4 | | | | def sum_of_square_vectorized(X) : |
| 5 | 104.3 MiB | 104.3 MiB | 1 | x = np.asarray(X) |
| 6 | 105.1 MiB | 0.8 MiB | 1 | x_sq = np.square(x) # x \*\* 2 |
| 7 | 105.4 MiB | 0.3 MiB | 1 | res = x_sq.sum() |
| 8 | 105.4 MiB | 0.0 MiB | 1 | return resx |

We can also use %timeit magic function to measure the speed of the function:

```
1 %timeit sum_of_square_vectorized(X)
```

which gives

```
3.91 ms ± 64.7 µs per loop (mean ± std. dev. of 7 runs, 100
~ loops each)
```
