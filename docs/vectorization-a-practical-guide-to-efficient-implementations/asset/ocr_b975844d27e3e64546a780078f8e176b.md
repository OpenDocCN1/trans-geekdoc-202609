# 7.2.2 Row-wise Broadcasting

Suppose we have the csr sparse matrix mat_csr of size M x N and a row vector array_r of length M. We want to add (subtract, multiply, or divide) each row of the sparse matrix by the row vector elementwise. Recall in Chapter 2, in NumPy with dense matrices (mat_dense), we can simply do this via broadcasting

```
mat_dense + array_r[np.newaxis, :]
```

With the Sparse matrix, we again can access the .data attribute. We can also access the column indices of each data point via the .indices attribute (see Figure 7.9), then the equivalent sparse matrix row-wise broadcasting is then

```
mat_csr.data += np.take(array_r, mat_csr.indices)
```

For other types of sparse matrices, first, convert to csr_matrix with tocsc(), make the broadcasting calculation, and then convert it back to the original format if needed. This can be implemented as

```
1 def R_plus_rv(R, rv):
2     """Sparse matrix plus a row vector"""
3     R = R.tocsr()
4     R.data += np.take(rv, R.indices)
5     return R
```
