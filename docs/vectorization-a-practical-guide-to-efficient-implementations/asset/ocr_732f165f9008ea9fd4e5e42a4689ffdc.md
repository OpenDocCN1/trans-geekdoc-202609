We can represent a 2D matrix as a Python list of lists, e.g. X = [[5, 2, 8, 3], [4, 9, 6, 7], [8, 11, 12, 10]]. If we want to retrieve the element 4 from the matrix, then we need to use the X[1][0] syntax. If X is a NumPy, Tensorflow, or PyTorch tensor, then we should instead use X[1, 0] syntax to retrieve the same element.

To reference an element in higher-dimensional tensors, we can use a list of integers (i_0, i_1, ..., i_d, ..., i_D), where i_d is the dth dimension/axis of the tensor X. We can then retrieve the element at a specific index using the list-of-integers indexing syntax, e.g. X[3, 2, 5, 8]. Note that it is also legitimate to use negative integers for indexing in this case.

Furthermore, using the integer indexing system, we can also reference/select multiple elements in a tensor, using the syntax [[axis_0_index_0, axis_0_index_1, ..., axis_0_index_k], [axis_1_index_0, axis_1_index_1, ..., axis_1_index_k], ..., [axis_d_index_0, axis_d_index_1, ..., axis_d_index_k]]. Notice that indices of the same axis/dimension are grouped together and specified as a list; the order of the indices follows the corresponding order of the elements to be retrieved. For example, we would like to select elements both at (1, 3) and at (2, 2) from X we defined in Figure 3.2, we can do X[[1, 2], (3, 2)]. Note that indexing of multiple elements simultaneously is only allowed in NumPy and PyTorch, but not in Tensorflow or base Python lists. If X is a tf.Tensor, then X[[1, 2], (3, 2)] will throw the following error:

```
TypeError: Only integers, slices (`:`), ellipsis (`...`), ← tf.newaxis (`None`) and scalar tf.int32/tf.int64 tensors ← are valid indices, got (1, 2)
```
