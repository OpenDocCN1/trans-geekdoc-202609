It is important to understand that we cannot use flat indices directly on an un-flattened multidimensional tensor in NumPy, Tensorflow, or PyTorch. For example, if X is a 2D matrix, then X[0] does not retrieve the first element but rather the entire first row of the matrix. This is called *slicing*, which we will look into more carefully in Section 3.2 in this chapter. To retrieve the first element according to the flat index, we need to either flatten the matrix, i.e `X.flatten()[0]`, or use `np.take` which we will discuss in Section 3.4.1.

Indexing elements using a flat index only requires the linear values (from 0 to N − 1, where N is the number of elements in the tensor), the shape of the tensor, and the order of traversal (e.g. C or F ordering). In contrast, indexing using a multi-index requires D × N values, where D is the dimension of the tensor. Thus, flat indices require less memory when enumerating the elements of the tensor while the dimensionality information can be disregarded. As we will see later in the chapter, operations such as gather and scatter on multi-dimensional tensors are usually performed on flat indices. However, multi-indices can encode the grouping of the elements. Slicing and groupwise reduction (e.g. sum over rows) are performed using multi-indices. Therefore, depending on the type of data manipulation needed, one may use a flat index at certain steps of the algorithm, but then switch to use a multi-index in another part. In Chapter 7, we will also see additional examples of how sparse matrices leverage both flat index and multi-index to store sparse data and how we can perform specialized operations on this data structure.
