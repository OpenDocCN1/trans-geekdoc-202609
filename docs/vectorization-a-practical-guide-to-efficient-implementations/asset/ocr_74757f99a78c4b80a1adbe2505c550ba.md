We may see that the ordering of padding proceeds as the order of the `constant_values` list of tuples: it first pads the row start and end, then the column start and end. Higher dimensional tensor paddings follow the same axes ordering. See Figure 5.7 for an illustration.

In reflect padding mode (NumPy: `reflect`, Tensorflow `REFLECT`, PyTorch: `reflect`), the paddings are added as if a mirror is being put at the border values of the tensor. That is, at padding index -1,-2,... (start of the dimension), values at index 1, 2, ... are used; at padding index N, N + 1, ... (end of the dimension), values at N - 1, N - 2, ... are used. Like `constant` mode, padding is added step-by-step by following the order of the axes of the tensor. `reflect` padding is useful before performing Fourier transform, for example, in the case of audio signal processing.
