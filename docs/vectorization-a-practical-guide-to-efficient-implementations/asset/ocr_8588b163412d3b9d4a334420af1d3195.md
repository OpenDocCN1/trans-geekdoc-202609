Interconversions between dense and sparse tensors are similar to those in Scipy, using methods such as `coo_sparse_tensor.to_dense()` to convert from sparse to dense tensors, and `dense_tensor.to_sparse()` to convert from dense to sparse (default to coo format). Conversion between each sparse tensor format is similar, using `to_sparse_{format}`, even directly from dense tensors. Table 7.3 details the comparisons of these five supported sparse matrices in PyTorch:

# Table 7.3 PyTorch Sparse tensor comparisons.

| Type | Construction | Interconversion | Sparse Dimensions |
|---|---|---|---|
| coo | torch.sparse_coo_tensor(indices, values, size, nnz) | .to_sparse_coo() | >= 2 |
| csr | torch.sparse_csr_tensor(crow_indices, col_indices, values) | .to_sparse_csr() | 2 |
| csc | torch.sparse_csc_tensor(col_indices, row_indices, values) | .to_sparse_csc() | 2 |
| bsr | torch.sparse_bsr_tensor(crow_indices, col_indices, values) | .to_sparse_bsr() | 2 |
| bsc | torch.sparse_bsc_tensor(col_indices, row_indices, values) | .to_sparse_bsc() | 2 |
