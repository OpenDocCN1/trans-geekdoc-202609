This will result in the shape of the output tensor being (batch_size, 1, 1, 1) which will help us broadcast the min/max values back into the input tensor. If keepdims=False (default), then the output tensor will be of shape (batch_size,), which cannot be broadcasted to the input tensor (batch_size, height, width, channel).

## 2.12.2 Pearson's Correlation

Pearson's correlation measures the linear relationship between two variables $X$ and $Y$ and is defined as

\(r = \frac{\text{COV}(X, Y)}{\sigma(X)\sigma(Y)}\)

\(= \frac{\sum_i(x_i - \bar{x}) \cdot (y_i - \bar{y})}{\sqrt{\sum_i(x_i - \bar{x})^2} \cdot \sqrt{\sum_i(y_i - \bar{y})^2}}\)

\(= \frac{\sum_i \tilde{x}_i \cdot \tilde{y}_i}{\sqrt{\sum_i \tilde{x}_i^2} \cdot \sqrt{\sum_i \tilde{y}_i^2}}\)

\(= \sum_i \left( \frac{\tilde{x}_i}{\sqrt{\sum_p \tilde{x}_p^2}} \cdot \frac{\tilde{y}_i}{\sqrt{\sum_q \tilde{y}_q^2}} \right)\)

where \(\tilde{x}_i = x_i - \bar{x}\) and \(\tilde{y}_i = y_i - \bar{y}\)

We use vectorization to implement Pearson's correlation between multiple pairs of variables in the following:

```
import numpy as np

def faster_corr(X, Y):
    """
    A faster way to compute Pearson's correlation
    between corresponding rows of two matrices
    """
    # zero means
    X = X - np.mean(X, axis=1, keepdims=True)
    Y = Y - np.mean(Y, axis=1, keepdims=True)
    # L2 normalization
    X = X / np.sqrt(np.sum(X**2, axis=1, keepdims=True))
    Y = Y / np.sqrt(np.sum(Y**2, axis=1, keepdims=True))
    R = np.sum(X*Y, axis=1)

    return R
```

- Lines 9 and 10 remove the mean of each variable. We set keepdims=True to result in vectors of shape (batch_size, 1) to help with subsequent broadcasted subtraction with the original input of shape (batch_size, num_variables). Note that since we are treating each row as each variable, we should set the order=C when initializing the two matrices so that each row is contiguously stored in the memory.
- Lines 12 and 13 perform L2 normalization by dividing the mean-removed variables by their respective L2 norm. We again set keepdims=True to result in a vector of shape (batch_size, 1) to help with subsequent broadcasted division with the mean-removed variables of shape (batch_size, num_variables). This step should output a set of unit-length vectors along each row of the matrix.
- Line 14 implements the last step of the Pearson correlation equation, which essentially performs dot products between corresponding pairs of vectors from each normalized input.

## 2.12.3 Pair-wise Difference

```
import numpy as np

def pairwise_diff(A, B):
    """
    Calculate the pair-wise difference between
    each element of the two vectors of length N and M,
    respectively, and return a matrix of shape M x N.

    Parameters:
    * A: vector of length M
    * B: vector of length N

    Returns:
    * A matrix of shape M x N where the element at (i, j) is A[i] - B[j]
    """
    A = np.asarray(A).flatten()[:, np.newaxis] # shape (M, 1)
    B = np.asarray(B).flatten()[np.newaxis, :] # shape (1, N)
    return A - B # Resulting shape (M, N)
```

- Lines 16 and 17 prepare the broadcasting in Line 18. `np.asarray` makes sure that the inputs are NumPy arrays; this means, the function can also accept lists or tuples as inputs. `flatten` makes sure the inputs are one-dimensional arrays. This implies that if the input A is of shape (1, M), we will first convert it to shape (M, ). This then would allow us to use `[:, np.newaxis]` to add a singleton dimension at the second dimension, making it of shape (M, 1). Similarly, when we make sure B is of shape (N, ), we then use `[np.newaxis, :]` to add a singleton dimension along the first dimension, making it of shape (1, N).

- Line 18 computes the pair-wise difference via broadcasting, i.e. tensor of shape (M, 1) broadcasted to a tensor of shape (1, N), resulting in a tensor of shape (M, N).

## 2.12.4 Construction of Magic Squares

A magic square is a square matrix of size n x n, with its entries filled with numbers between 1 and n^2, such that each row, column, and the main diagonal have identical sums [Arroyo, 2018]. We can easily verify that when n = 2, this matrix is impossible to construct: given numbers 1, 2, 3, 4, if we want to make sure each row of the matrix to have identical sum, then the sum needs to be 5, and the two ways we can construct them are with (1, 4) and (2, 3). However, regardless of how we arrange them, we cannot make the columns sum to 5 (see two examples in Figure 2.9a,b). Similarly, if we want to make sure each column of the matrix has an identical sum, we again use (1, 4) and (2, 3) pairing for each column. But regardless of how we arrange them, we cannot make sure the rows can be summed to 5 (see two examples in Figure 2.9c,d).

A magic square can be classified into three categories: odd ($n = 2k + 1$), doubly even ($n = 2(2k) = 4k$), and singly even ($n = 2(2k + 1) = 4k + 2$) [Kraitchik, 1942]. These three categories of magic squares use three different algorithms to construct. The magic constant of the magic square is the row or column sum of the entries, given by the formula $\sigma(M) = \frac{n(n^2+1)}{2}$. For a $3 \times 3$ magic square, the magic constant is

$$\sigma(3) = \frac{3 \times (3^2 + 1)}{2} = 15$$

The oldest third-order magic square is probably the one from “Luo Shu,” an ancient Chinese book used for fortune-telling, as shown in Figure 2.10. It also came with a pithy formula that goes like the following: “2 (right) and 4 (left) on the shoulders, 6 (right) and 8 (left) on the feet, 3 on the left, 7 on the right, 9 be the hat, 1 be the shoe, and 5 at the center” (and I am mostly remembering this from the novel “The Legend of the Condor Heroes” written by Jin Yong who cited this pithy formula for the magic square in “Luo Shu”).

### Odd-Order Magic Squares Construction by Siamese Method

Siamese method is probably the best-known method for constructing magic squares of odd orders [Kraitchik, 1942; De La Loubere, 1693]. The rules for constructing a magic square are the following:

- 1. Start at the position of the topmost row and central column of the matrix. Fill this position with 1.
- 2. We then continue filling the matrix by going diagonally upward and right.
  - 1. If we run out of rows, we go back to the bottom-most row and fill in the values in the corresponding column.
  - 2. If we run out of columns, we go back to the leftmost column and fill in the values in the corresponding row.
  - 3. If we run out of both rows and columns (i.e. when going from the upper right corner), or the subsequent position is already occupied, we then fill the position right below the current element by going down 1 row, keeping the same column.
