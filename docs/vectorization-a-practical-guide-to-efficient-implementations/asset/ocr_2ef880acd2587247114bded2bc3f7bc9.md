Notice for string and byte type arrays (`A_string` and `A_bytes` respectively), the `dtype` of the displayed array has additional information. Using the string array `A_string` as an example, other than `np.str_` corresponds to the notation of `U` (and a `<` prefix), the `1` following the dtype notation indicates the maximum length of the strings in the array. For example, let us construct an array with strings of variable lengths:

```
A_string = np.array(["1", "12", "123", "1234", "12345"])
# array(['1', '12', '123', '1234', '12345'], dtype='<U5')
```

Notice now that `dtype` becomes <U5, which indicates the maximum length of the strings in the array is 5.

The data types of the array can be inter-converted via `.astype` method from `np.ndarray`. For example, to convert an array of object into an array of bytes, we can do

```
A_object = np.array(["a", "b", "c", "d"], dtype=np.object_)
# array(['a', 'b', 'c', 'd'], dtype=object)
A_object.astype(np.bytes_)
# array([b'a', b'b', b'c', b'd'], dtype='|S1')
```

# ## 6.1.2 Pandas String

Pandas [McKinney, 2010] can handle strings either as an `object` type or as its native implementation of string data type `pd.StringDtype` [McKinney, 2023b]. There are several ways to initialize a Pandas column with string data.

```
import pandas as pd
feature = ["a", "b", "c", "d"]
df = pd.DataFrame({
    "feature1": pd.Series(feature, dtype=pd.StringDtype),
    "feature2": pd.Series(feature, dtype="string"),
    "feature3": pd.Series(feature, dtype=str),
    "feature4": pd.Series(feature, dtype="str"),
    "feature4": pd.Series(feature, dtype=object),
    "feature5": pd.Series(feature, dtype="object")
})
```

Inspecting the DataFrame information with `df.info()`, we have

```
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 4 entries, 0 to 3
```
