d) segment_sqrt_n is a special function that was motivated by previous natural language modeling studies that attempted to summarize embeddings of tokens within a sentence, i.e. representing a sentence as a bag of words (e.g. pretrained feed-forward Neural-Net Language Model, or NNLM [Bengio et al., 2003], from TFHub [Google, 2023]). These studies found that taking the square root of the sum of the embeddings is more effective in representing sentences than averaging the embeddings of the tokens together. Similar to the groupwise mean reduction solution, this can also be implemented using np.divide.reducat in NumPy or torch.scatter_add in PyTorch. We illustrate an implementation in the following code block using PyTorch:

```
import torch

def torch.scatter_reduce_sqrt_n(arr, segment_ids, **kwargs) :
  # Initialize accumulators
  numerator = torch.zeros(segment_ids.max() + 1)
  denom = torch.zeros_like(numerator)
  # Compute groupswise sum
  gsum = numerator.scatter_add_(0, segment_ids, arr)
  # Compute groupwise count
  indicator = torch.ones_like(arr)
  gcount = denom.scatter_add_(0, segment_ids, indicator)
  # Compute the sum / sqrt_n
  return gsum / torch.sqrt(gcount)
```

e) These operations compute the segment-wise minimum and maximum values. A caveat with the Tensorflow operations using unsorted segment ids, i.e. tf.math.unsorted_segment_max and tf.math.unsorted_segment_min, is that if we skip over some integer ids with the intention to create zero entries, we will find that these skipped entries will have -\( \infty \) (e.g. 3.4028235e+38) or +\( \infty \) (e.g. +3.4028235e+38) filled, respectively, instead of having zeros. So, care needs to be taken when using these operations.
