c) The atleast_nd functions help ensure the inputs are of the expected shape. These operations are often helpful when we need to perform broadcasting operations (i.e. element-wise operations between lower and higher dimensional tensors), which we will discuss in the upcoming section. They are somewhat equivalent to and are often used as shortcuts for the expand_dims operations. Suppose we would like a scalar value to be at least three-dimensional. Then, we can either implement using expand_dims as

```
import numpy as np

x = np.array(6)
y = np.expand_dims(x, axis=0) # np.array([[6]])
y = np.expand_dims(y, axis=0) # np.array([[[6]]])
y = np.expand_dims(y, axis=0) # np.array([[[[6]]]])
```

Or simply as

```
import numpy as np

x = np.array(6)
y = np.atleast_3d(x) # np.array([[[6]]])
```

One nice feature about these functions is that we do not need to know beforehand how many expand_dims operations we need to make before reaching the desired number of dimensions. So in the above example, by using np.atleast_3d, I can also let the input x = np.array([6]) without modifying any subsequent code to ensure the shape of y to be always at least three-dimensional, which gives the input shape a lot of flexibility. On the other hand, the name atleast suggests that, when the input x is of a higher dimension, all the dimensions will be kept as is:

```
import numpy as np

x = np.array([[[[[6]]]]]) # 5-dimensional
y = np.atleast_3d(x) # still 5-dimensional
```
