tf.gather_nd support slice gathering using multi-index. For instance,

```
```python
import tensorflow as tf
X = tf.random.uniform((4, 5, 6))
# Multi-indexing the first 2 dimensions,
# using last dimension as the slice/block dimension
index = tf.constant([
    [0, 3],
    [1, 2],
    [3, 0],
    [2, 2],
]) # (4, 2)

# Gather 4 slices from the 3D tensor
y = tf.gather_nd(X, index) # (4, 6)
```
```

index.shape[1] number of leading dimensions in X is extracted using the multi-index, and the remaining lagging dimensions are left as the slice dimensions. If index.shape[1] == X.ndim, then 1D vectors are created by extracting single elements from the input X. Otherwise, a (X.ndim - index.shape[1] + 1)-dimensional tensor is created.

tf.gather_nd can also be used to gather slices arranged over a multi-dimensional batch.

```
```python
import tensorflow as tf
X = tf.random.uniform((2, 3, 5, 4))
index = tf.experimental.numpy.random.randint(
    0, 4, (2, 3, 4, 2)
)

batch_dims = 2
y = tf.gather_nd(X, index, batch_dims=batch_dims)
```
```

In this example, we treat the first two dimensions of the index and X as the batch dimensions. Then, for each location within the batch, we take 4 of 2D points from each 5 x 4 matrix. See Figure 3.12 for an illustration.

Tensorflow's documentation on tf.gather_nd [Abadi et al., 2023b] provides even more examples. Readers are encouraged to study these examples carefully to understand the operation even further.

tf.gather_nd (as well as similar operations in NumPy and PyTorch) that gathers elements at indices rather than entire slices in a batch are quite useful for extracting heterogeneous regions of interests (ROIs) from high-dimensional data, such as medical imaging (e.g. fMRI brain structures) or video data (e.g. for moving objects), where sequences of 2D or 3D images are organized over time.
