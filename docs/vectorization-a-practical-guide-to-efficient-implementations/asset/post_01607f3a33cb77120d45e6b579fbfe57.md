The formula indicates that we need to iterate over all potential combinations of $i$ and $j$. This can be done via broadcasting between a row vector and a column vector, both initialized by `np.arange`. Based on Equation 2.3, we can implement the Siamese method as the following:

```python
def _odd_order_magic(n: int):
    """Make Siamese odd-order magic squares via Latin
    squares."""
    # Initialize p (i / j), used for
    # broadcasting later -> shape n x 1
    p = np.arange(n)[:, None]
    # make L_b
    L_b = np.mod(p + p.T - (n - 1) // 2, n)
    # make L_u
    L_u = np.mod(p + 2 * p.T - n + 1, n)
    # make the magic square
    S = n * L_b + L_u + np.ones_like(L_b)
    return S
```

- Line 5 initializes a column vector using `np.arange`. We are trying to use broadcasting to construct a mesh that helps us iterate over all pairs of $(i,j)$ $[(0,0), (0,1), (0,2), \dots, (n-1, n-1)]$.

- Line 7 makes the Latin square $L_b$ using the formula in Equation 2.3. Notice that `(n - 1) // 2` is doing an integer division, since we know that input n is already an odd integer. This will keep all the results as integers. Otherwise, NumPy will cast everything into `float64`. `np.mod(L_b, n)` will make sure the resulting value of `b` is an integer between 0 and n - 1 (inclusive). You may notice that the values from line 10 may sometimes be negative. For example, given a third-order Siamese magic square (n = 3), when i = 0, j = 0, the corresponding b = -1, u = -2. However, mod (-1, 3) = 2, mod (-2, 3) = 1. The modulus operation helps cast the negative values to a value between 0 and 2 (inclusive).

- Line 9 implements the formula in Equation 2.3 to make Latin square $L_u$.

- Line 11 implements the definition of the Siamese odd-order magic squares (Equation 2.2).

## Doubly-Even Order Magic Squares

Manuel Moschopoulos in the 1300s illustrated a very elegant way of constructing doubly even magic squares, which I will call the "X" method:

- 1. Fill the square matrix from $n$ to 1 row-wise.
- 2. Draw Xs through the main diagonals of each $4 \times 4$ block.
- 3. For each grid where the Xs touch, replace the number with the complement $n^2 + 1 - x_{ij}$.

Note that Wolfram Alpha [Weisstein, 2023] illustrated a similar version of the X-method for constructing doubly even magic squares, whose source is unknown. Google search results seem to suggest this method was due to Philippe de la Hire’s 1705 Latin translation of Manuel Moschopoulos’ work on magic squares. This complementary method simply fills the square matrix from 1 to n instead of n to 1, which yields a complementary magic square. It also appears MATLAB implements this method.

We can again use the idea of reshaping and broadcasting to implement this algorithm. Figure 2.14 illustrates the process step by step.

```python
def __doubly_even_order_magic(n: int):
    """Use X method to construct doubly even magic
    squares."""
    # e.g. n=8, (64,)
    S = np.arange(n**2, 0, -1)
    # Split into 4x4 blocks (2, 4, 2, 4)
    S = S.reshape((n//4, 4, n//4, 4))
    # Create the X mask
    X = np.eye(4, dtype=S.dtype) * (n**2 + 1)
    X = X + np.fliplr(X)
    # (1, 4, 1, 4)
    X = X[None, :, None, :]
    # Subtract under absolute value
    S = np.abs(S - X)
    # Reshape (n, n)
    S = S.reshape((n, n))

    return S
```

- 1. Line 4 initializes the values of the square matrix in descending order, from n² to 1.
- 2. Line 6 splits the matrix into blocks of shape (4, 4), for each row (axis=0) and column (axis=3). This forms a tensor of size (k, 4, k, 4), where k = n/4.
- 3. Lines 8 and 9 create the 4 × 4 matrix with diagonal and anti-diagonal entries filled with n² + 1, which forms the X-shape. This is used to compute the complementary values against each block of 4 × 4.
- 4. Line 11 adds dimensions at axis=0 and axis=3, making the tensor shape (1, 4, 1, 4). This is used for broadcasting in the next step.
- 5. Line 13 takes the difference under the absolute value. This replaces the entries touched by the "X" with the complementary values.
- 6. Line 15 reshapes the tensor back into a matrix of shape (n, n).

## Singly Even Order Magic Squares

Lastly, we will construct singly even order magic squares via the "LUX" method due to John Horton Conway [Erickson, 2009; Weisstein, 2023]. Through its implementation in NumPy, I am hoping the readers of the book can appreciate the efficiency and power of this library in handling complex data manipulations. "LUX" is referring to the order of filling out a 2 × 2 grid, as illustrated in Figure 2.15. The three variants of filling order form the shape of "L," "U," and "X," respectively. Let n = 2m = 2(2k + 1), where k ≥ 1, then,

- 1. Starting with an odd-order square matrix m × m, we can determine what shape to fill for each of the grids that represents a 2 × 2 block:
    - Fill k rows of the matrix with L shapes.
    - Fill the k + 1th row with L shapes, except the middle one with an U shape.
    - Fill the k + 2th row with U shapes, except the middle one with an L shape.
    - Fill the rest of the rows (if any left) with X shapes
- 2. The order of the numbers to be filled is determined by the Siamese method, which starts at the top-center grid as the first block to fill. We can derive the mapping between the values in the Siamese odd-order magic matrix and the values within the 2 × 2 matrix to be filled by "LUX" as u = 4(v − 1) + i, where v is the corresponding Siamese odd order magic square and i is the indexed value of the 2 × 2 block determined by one of the three variants of the filling order.

```python
def __singly_even_order_magic(n: int):
    """Use LUX method to construct singly even magic squares."""
    # Compute size constants
    m = n // 2 # odd
    k = (m - 1) // 2
    # Initialize the 3 filling variants
    L = np.array([([4, 1], [2, 3])])
    U = np.array([([1, 4], [2, 3])])
    X = np.array([([1, 4], [3, 2])])
    # Create k-rows of L-filled blocks
    M_L = np.full((k, m, 2, 2), L)
    # Create a row of L-filled blocks,
    # except the middle column is filled with U
    M_LU = np.concatenate([
        np.full((1, k, 2, 2), L),
        U[None, None, :, :],
        np.full((1, k, 2, 2), L),
    ], axis=1)
    # Create a row of U-filled blocks,
    # except the middle column is filled with L
    M_UL = np.concatenate([
        np.full((1, k, 2, 2), U),
        L[None, None, :, :],
        np.full((1, k, 2, 2), U),
    ], axis=1)
    # Fill the rest the k-1 rows with X
    M_X = np.full((k-1, m, 2, 2), X)
    # Combine all the sub-blocks (m, m, 2, 2)
    M = np.concatenate([
        M_L, M_LU, M_UL, M_X
    ], axis=0)
    # Initialize the Siamese odd order magic square
    S = _odd_order_magic(m)
    # Apply the Siamese mapping formula
    M += 4 * (S[:, :, None, None] - 1)
    # Reshaping back to n x n
    M = np.swapaxes(M, 1, 2).reshape((n, n))
    return M
```

- 1. Lines 4 and 5 compute some constants that we will use later on to construct the matrices.
- 2. Lines 7-9 initialize the L, U, X ordering as 2 × 2 matrix blocks.
- 3. Line 11 creates k rows of L filled blocks. We can treat it as a block of k × m matrix, with each matrix filled with 2 × 2 block, resulting in a tensor of shape k × m × 2 × 2.
- 4. Lines 14-18 create 1 row of L-filled blocks except with the middle entry being U-filled. We do this via concatenation of Concat([[ L, ...], [U], [L, ...] ]). This results in a tensor of shape 1 × m × 2 × 2.
- 5. Lines 21-25 create 1 row of U-filled blocks except with the middle entry being L-filled. Similar to the above step, we do this via concatenation of Concat([[ U, ...], [L], [U, ...] ]). This results in a tensor of shape 1 × m × 2 × 2.
- 6. Line 27 creates k - 1 rows of X-filled blocks. When n = 6, k = 1, then k - 1 = 0, which means we do not add the X blocks below. np.full can handle zero dimensions while keeping the tensor to the desired shape. This creates a tensor with shape (k - 1) × m × 2 × 2.
- 7. Lines 29-31 combine the sub-blocks of tensors into a single tensor via concatenation along the first dimension. This creates a tensor of shape m × m × 2 × 2.
- 8. Line 33 initializes the m × m odd-order Siamese magic matrix, which we need in order to apply the value mapping formula.
