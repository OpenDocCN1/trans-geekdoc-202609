
- counts of the number of occurrences of the item in the unique set. In NumPy and PyTorch, this is to set `return_counts=True`. In TensorFlow, this is to call `tf.unique_with_counts` and use the third returned output. In the case study where we implement a function to sort rows of a matrix, we will use `np.unique` to sort the rows lexicographically.

- d) These operations get the maximum or minimum values (or the index of it) of an array. They correspond to the mathematical notations max, min, argmax, and argmin.

- e) The top-k operation returns the top-k values from an array along with the indices of the top-k values. Although NumPy does not have a ready-to-use function to extract top-k values, as we will see in one of the studies in Section 10.2, we can use `np.argpartition` to implement the top-k operation.

- f) `np.partition` is unique to NumPy. It partitions an array into two parts, based on the kth value of the final sorted array (but not actually doing the sorting on the whole array). The values in the left partition are all smaller, while the values in the right partition are all larger than this value. See Figure 10.1 in the following case study section for an illustration. `np.argpartition` gets the indices to partition and reorder the array.

- g) Given a sorted array, the `searchsorted` operation finds the index where a new value can be inserted while the sorting order of the new array is still maintained (i.e. still from smallest to largest). If the value is equal to one of the values already existing in the array, then it is either inserted to the left or right of the original number, depending on the argument set for `side="left"` or `side="right"`, respectively. The implementations of the `searchsorted` method by NumPy, Tensorflow, and PyTorch vectorize the search for multiple insertion values simultaneously. To illustrate,

```
import numpy as np

X = np.array([1, 3, 6, 8, 10])
insertion_values = np.array([2, 5, 9, 10, 11])
insertion_indices = np.searchsorted(X, insertion_values)
# array([1, 2, 4, 4, 5])
# Insert the values based on the search sorted indices
y = np.insert(X, insertion_indices, insertion_values)
# array([ 1, 2, 3, 5, 6, 8, 9, 10, 10, 11])
```

## 10.2 Case Study: Top-k Using argsort and argpartition

Both Tensorflow (tf.math.top_k) and PyTorch (torch.topk) implement a method that returns the top-k largest elements along with the indices from an array. For Tensorflow,

```
import tensorflow as tf
X = tf.constant([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = tf.math.top_k(X, k=3)
# top_values: <tf.Tensor: shape=(3,), dtype=int64, numpy=array([9, 8, 5])>
# top_indices: <tf.Tensor: shape=(3,), dtype=int32, numpy=array([4, 5, 3], dtype=int32)>
```

and for PyTorch

```
import torch
X = torch.tensor([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = torch.topk(X, k=3)
# top_values: tensor([9, 8, 5])
# top_indices: tensor([4, 5, 3])
```

At the time of writing this chapter, NumPy does not have a ready-to-use function to retrieve the top-k values and indices. However, it is possible to use sorting to achieve the same goal. A naive approach is to use np.argsort to determine the indices of the top values, then use np.take to retrieve the top values.

```
import numpy as np
def top_k_argsort(X, k=3):
    """Get top-k values and indices along the last dimension."""
    top_indices = np.argsort(X)[..., -k:][..., ::-1]
    top_values = np.take_along_axis(X, top_indices, axis=-1)
    return top_values, top_indices
X = np.array([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = top_k_argsort(X)
# top_values: array([9, 8, 5])
# top_indices: array([4, 5, 3])
```

- Line 5: np.argsort first gets the index used to sort each of the arrays. Since it sorts the values in ascending order (from smallest to largest), we then slice out the last k indices for the top-k values along the last dimension of the input, using [..., -k]. Then, [..., ::-1] reverses the top-k indices so that it is now arranged from largest to smallest.

- Line 6: np.take_along_axis applies the sorting order obtained from top_indices to the input, along the last dimension.

However, this would involve sorting the entire sequence. The time complexity of this approach is O(n log n), where n is the size of the sequence. In contrast, another strategy to retrieve top-k values is using np.argpartition to return the unordered top-k values first, and then sort the top-k values and indices using np.argsort. Since np.argpartition runs in O(n) [Harris et al., 2023] time complexity, the overall time complexity is then O(n + k log k), where k << n.

```
import numpy as np

def top_k_argpartition(X, k=3):
    """Get top-k values and indices along the last dimension."""
    # Unsorted top k values and indices
    top_indices = np.argpartition(X, -k, axis=-1)[..., -k:]
    top_values = np.take_along_axis(X, top_indices, axis=-1)

    # Sort based on top_values
    indices = np.argsort(top_values, axis=-1)[..., ::-1]
    top_indices = np.take_along_axis(top_indices, indices, axis=-1)
    top_values = np.take_along_axis(top_values, indices, axis=-1)

    return top_values, top_indices

X = np.array([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = top_k_argpartition(X)
# top_values: array([9, 8, 5])
# top_indices: array([4, 5, 3])
```

- Line 6 partitions the array by the kth largest value. np.argpartition will get the indices of the array after the partitioning. Here, we use -k to specify the kth largest value instead of the kth smallest value. See Figure 10.1 for an illustration of how np.partition works (np.argpartition gets the indices to be used for partitioning instead of the partitioned results, similar to how np.argsort gets the sort indices rather than the sorted results). Then, we slice out only the indices for the top-k largest values, [..., -k:].

![](img/e891acaacd4fb5b80dab2ed824618203_368_0.png)

Figure 10.1. Schematic illustration of the effect of partitioning the array. The algorithm first determines the kth largest value as specified, which we denote as the "pivot" (as in quicksort). Then, it moves any value less than the pivot to the left of the pivot and moves any value greater than the pivot to the right of the pivot. As a result, all values to the left of the pivot are smaller than the pivot, and all values to the right of the pivot are greater than the pivot. Within the two partitions, however, the values are not ordered.

- Line 7 takes the top-k values from the original inputs. At this point, neither top_indices nor top_values are sorted.

- Lines 10-12 sort the top_values and apply the sorting order to top_indices.

import numpy as np
import time
