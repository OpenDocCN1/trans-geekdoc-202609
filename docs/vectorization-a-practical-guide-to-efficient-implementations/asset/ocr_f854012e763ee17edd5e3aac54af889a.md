However, we can use Tensorflow's `tf.scatter_nd` method to achieve the same effect. More concretely, consider, step by step,

+   For `index[0, 0] = 1`, we have a value at the corresponding index `input[0, 0] = 2`. We would like to put this value into a new tensor at the position such that `X[0, 1] = 2` (Figure 3.20b). Given the target tensor has shape `(4, 10)`, the multi-index `[0, 1]` can be converted into a flat index 1. Therefore, this is the same as assigning a flat vector `X_flat[1] = 2`, and then reshaping the flat vector back into a 2D matrix.

+   For the subsequent figures, Figure 3.20c–e, we are simply iterating over the elements of `index`, extracting the corresponding value from the `input`, and scatter it to the corresponding position on `X`.

Notice that the final output matrix has many zero entries. A matrix with many zero entries is called a sparse matrix, which we will introduce in more detail in Chapter 7.
