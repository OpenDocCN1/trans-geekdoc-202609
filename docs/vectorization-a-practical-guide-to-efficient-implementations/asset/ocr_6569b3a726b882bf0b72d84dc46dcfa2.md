In NumPy (i.e. this is not allowed in Tensorflow or PyTorch), the constant\_values argument can also be a pair of values ((start\_value, end\_value) for all dimensions) or a list of tuples of values ([(start\_value\_0, end\_value\_0), (start\_value\_1, end\_value\_1), ...]), as illustrated in the following examples:

```
import numpy as np
# shape (3, 4)
X = np.array([
    [7, 1, 4, 4],
    [5, 7, 6, 4],
    [7, 3, 1, 2],
])
# padding starts with 0 and ends with -1 for each dimension
y = np.pad(X, [(0, 1), (2, 0)], mode="constant", constant_values=(0, -1))
# array([[ 0,  0,  7,  1,  4,  4],
#        [ 0,  0,  5,  7,  6,  4],
#        [ 0,  0,  7,  3,  1,  2],
#        [ 0,  0, -1, -1, -1, -1]])
# padding row start with 0, row end with -1
# padding column start with -2, column end with -3
y = np.pad(
    X, [(1, 1), (1, 1)], constant_values=[(0, -1), (-2, -3)]
)
```
