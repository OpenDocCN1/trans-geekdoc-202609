The following code snippet implements the Scaled Dot-Product Attention using Tensorflow and Keras.

```python
import tensorflow as tf
from keras.activations import softmax

def scaled_dot_product_attention(
    query, key, value, mask=None, causal=True, dropout=0.0
):
    """
    Use the dense layer output from query, key, value,
    respectively, as input for attention

    Parameters:
    ----------
    * query: (..., l_q, depth_src)
    * key: (..., l_k == l_v, depth_src)
    * value: (..., l_v == l_k, depth_out)
    * mask: Float tensor of 0s and 1s, with
    shape broadcastable to (..., l_q, l_k).
    * causal: bool. Whether or not to apply causal attention masking.
    * dropout: dropout rate.

    - depth_*: depth num_heads = embed_dim, which
    can be different, but are usually the same.
    - l_*: are lengths of input sequences which can be different,
    but are usually the same

    Returns:
    ----------
    * attention: attention score (..., l_q, depth_out)
    * weights: weights of the value when summing the value (..., l_q, l_k)
    """
    # Cosine/dot product similarity
    # Q K.T, (..., l_q, l_k)
    logit_score = tf.matmul(query, key, transpose_b=True)

    # scale by dimension of key
    d_k = tf.cast(tf.shape(key)[-1], tf.float32)
    scaled_logit_score = logit_score / tf.sqrt(d_k)  # (..., l_q, l_k)

    # Masking the region by a large negative number (est. -inf)
    if mask is not None:
        scaled_logit_score += mask * -1e9  # (..., l_q, l_k)

    if causal:
        l_q = tf.shape(query)[-2]
        l_k = tf.shape(key)[-2]
        # creates an upper triangular mask to retain lower triangular
        # matrix
        causal_mask = 1 - tf.linalg.band_part(
            tf.ones((l_q, l_k), tf.float32), -1, 0
        )
        scaled_logit_score += causal_mask * -1e9

    # weights: softmax normalization
    weights = softmax(scaled_logit_score, axis=-1)
    # Add dropout
    weights = tf.nn.dropout(weights, dropout)

    # attention (..., l_q, depth_out)
    attention = tf.matmul(weights, value)

    return attention, weights
```

- Lines 13 and 14: Key and value must have the same length, i.e. l_k == l_v.
- Line 33 implements the dot product part of the attention, between Key and Query QK^T. The logit_score has shape (batch_size, [num_heads,] l_q, l_k), where optionally, num_heads is the number of heads in the case of multi-headed attention.
- Line 36 gets the embedding size of the key d_k from the input key.
- Line 37 computes the scaled dot product QK^T / sqrt(d_k).
- Lines 40 and 41: This handles a case where an additional binary mask is applied on top of the dot product attention. We apply the masking by adding the masked region with a large negative number. This is because, after applying the softmax activation the logit score of large negative numbers will become near 0. For example, softmax([1, -3, 2, -1e9, 5]) = 1.7142441e-02, 3.1397477e-04, 4.6597987e-02, 0.00000000e+00, 9.3594557e-01]. We choose to add the large negative number on the logit scores instead of performing softmax first, and then applying the binary mask because we want to make sure that the weights of the attention mask after applying softmax still sum to 1. Note that the mask is assumed to have or can be broadcasted to shape (batch_size, [num_heads,] l_q, l_k).
- Lines 42-49 implement the causal masking. Here, we use tf.linalg.band_part to create an upper triangular mask to retain the diagonal and lower triangular part of the matrix. Note that this implementation can handle cases where the value length does not equal to query length. The mask has the shape (l_q, l_k).
- In Line 49, we again apply the masking by adding a large negative number to the logit scores to the masked region. We take advantage of the broadcasting rule here as we know the scaled_logit_score has shape (batch_size, [num_heads,], l_q, l_k), and we apply identical upper triangular masking to all batches and all heads of the attention scores.
- Line 52 applies softmax on the last dimension of the batch of attention mask, such that the attention weights between key and query sums to 1.
- Line 54 adds a dropout layer. During inference time, we need to set dropout = 0 to make sure the outputs are deterministic.
- Line 57 creates the attention-weighted sequence by multiplying the weights and value together. Here weights has shape (batch_size, [num_heads,] l_q, l_k) and value has shape (batch_size, [num_heads,], l_v, depth_out), knowing also that l_k == l_v. Recall that tf.matmul operates on the last two dimensions of the tensors. Then, attention has shape (batch_size, [num_heads,], l_q, depth_out).

## 5.3.2 Variable-Length Range via Masking

This case study creates a helper function that we will be using in Section 5.3.3 where we implement the Length Regulator module of FastSpeech2 [Ren et al., 2020].

Suppose we have a long sequence like the following [1, 1, 2, 2, 2, 2, 2, 3, 3, 3] where each value indexes which group the current value belongs to. We can observe that there are 2 of 1s, 5 of 2s, and 4 of 3s. We would like to be able to enumerate the elements within each group by giving each number a within-group index [0, 1, 0, 1, 2, 3, 4, 0, 1, 2, 3] as a horizontal concatenation of 3 range arrays [0, 1], [0, 1, 2, 3, 4], and [0, 1, 2, 3], each having a different length. We can then flatten this ragged tensor, using `tf.ragged.range([2, 5, 4]).flat_values`, and obtain the within-group index we wanted before.

But what if we do not have such a convenient initializer in the library we are using? We can construct something similar to this using the idea of indexing and masking. The general strategy of our implementation is the following (see also Figure 5.15):

- We will first construct a single range array (i.e. [0, 1, 2, ..., n] via `np.arange`) up to the maximum desired array length based on the input.
- Then, we mask out elements of the range array where its value is beyond the desired range and replace it with a padding value (e.g. -1). The mask can be constructed by broadcasting the range array row vector with the array length column vector together.
- Lastly, to return the desired 1D vector, we first flatten the matrix and then remove any padding values.

Here is an implementation using NumPy:

```python
from typing import List
import numpy as np

def ragged_range(n: List[int], pad=-1, flatten=True):
    """Implement ragged matrix using a dense matrix with paddings."""
    # Find the maximum length
    n = np.array(n)
    max_n = np.max(n)
    # Construct and repeat arrange
    r = np.arange(max_n)[None, :]
    # Masking with broadcasting
    mask = r > n[:, None]
    r = np.where(mask, pad, r)
    # Flatten
    if flatten:
        # Flatten
        r = np.ravel(r)
        # Remove padding values
        r = np.compress(r != pad, r)

    return r
```

- Line 7 ensures that the list input `n` that specifies the desired lengths of the range arrays is an `np.ndarray` which will later be used for broadcasting.
- Line 8 determines the maximum size of the range array.
- Line 10 creates the initial range array, up to the maximum array length.
- Line 12 creates the mask to retain values less than the size of the array specified by `n`. This is done by broadcasting the column vector of array lengths and the row vector of the range array initialized in Line 10. The resulting mask is a matrix of size `(len(n), max_n)`. Note that we are sacrificing memory spaces in exchange for subsequent opportunities for vectorization. In some worst-case scenarios, one range array may be much longer than the rest of the range arrays. In this case, the majority of the elements are padding values, or the matrix is sparse (a concept that we will discuss in Chapter 7).
- Line 13 uses `np.where` to replace values according to the `mask`. If the `mask` value is `True`, then we replace the value in `r` with the `pad` value, e.g. `-1`; otherwise, we retain the value inside `r`.
- Lines 15-19 implement the logic when we need to return a flat array. Otherwise, we will simply return the matrix with each row being a ranged array with paddings.
- Line 17 flattens the 2D matrix to a 1D vector.
- Line 19 removes the padding values.
