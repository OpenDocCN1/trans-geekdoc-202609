
## 3 Tensor Indexing

An **index** is a reference that points to the location of the value in an arrangement of an _N_-dimensional tensor. **Indexing** is the operation to select or manipulate an element or a group of elements within a tensor using such a reference system. In this chapter, we will introduce various ways of indexing. We will also illustrate how indexing can be used to manipulate elements in a tensor through several case studies.

### 3.1 Get Values at Index

### 3.1.1 Integer Indexing

In Python, elements of a list (e.g. l) at a specific index can be accessed by the syntax l[index], where index is an integer starting from 0 (i.e. 1st index). For example, let l = [2, 3, 5, 7, 11] be a list of integers. Then, the third item (index=2) can be retrieved by l[2], returning 5. Here, the variable index can also be negative numbers, which access the element starting from the end of the list. For example, l[-1] accesses the last element in the list and l[-2] accesses the second to last element. In general, given a list of length N and a negative integer index, then l[index] = l[N+index]. See Figure 3.1 for an illustration. 1D arrays in NumPy (np.ndarray), TensorFlow (tf.Tensor), and PyTorch (torch.Tensor) all follow such indexing conventions as well.

For 2D matrices, the indices of the elements are represented by a pair (tuple) of integers, in the format of (row, column). As illustrated in Figure 3.2, the value 7 resides in the second row and fourth columns of the 3 × 4 matrix and can be referenced by the index (1, 3). It is worthwhile to point out that this convention is different from the Cartesian coordinates (x, y), where x is the horizontal position, and y is the vertical position. To reference the same value 7 in this matrix, we would instead use (3, 1) using the Cartesian coordinate system. (We may also treat (x, y) as the (column, row) convention.)

We can represent a 2D matrix as a Python list of lists, e.g. X = [[5, 2, 8, 3], [4, 9, 6, 7], [8, 11, 12, 10]]. If we want to retrieve the element 4 from the matrix, then we need to use the X[1][0] syntax. If X is a NumPy, TensorFlow, or PyTorch tensor, then we should instead use X[1, 0] syntax to retrieve the same element.

To reference an element in higher-dimensional tensors, we can use a list of integers (i_0, i_1, ..., i_d, ..., i_D), where i_d is the dth dimension/axis of the tensor X. We can then retrieve the element at a specific index using the list-of-integers indexing syntax, e.g. X[3, 2, 5, 8]. Note that it is also legitimate to use negative integers for indexing in this case.

Furthermore, using the integer indexing system, we can also reference/select multiple elements in a tensor, using the syntax [[axis_0_index_0, axis_0_index_1, ..., axis_0_index_k], [axis_1_index_0, axis_1_index_1, ..., axis_1_index_k], ..., [axis_d_index_0, axis_d_index_1, ..., axis_d_index_k]]. Notice that indices of the same axis/dimension are grouped together and specified as a list; the order of the indices follows the corresponding order of the elements to be retrieved. For example, we would like to select elements both at (1, 3) and at (2, 2) from X we defined in Figure 3.2, we can do X[[1, 2], (3, 2)]. Note that indexing of multiple elements simultaneously is only allowed in NumPy and PyTorch, but not in TensorFlow or base Python lists. If X is a tf.Tensor, then X[[1, 2], (3, 2)] will throw the following error:

```
TypeError: Only integers, slices (`:`), ellipsis (`...`), tf.newaxis (`None`) and scalar tf.int32/tf.int64 tensors are valid indices, got (1, 2)
```

For example, if X = np.array([1, 2, 3, 4]) is a 1D vector, and we would like to retrieve the first and third elements, then we can do X[[0, 2]] which results [1, 3]. This works in both NumPy and PyTorch, but not in TensorFlow. If X is a tf.Tensor, then X[[0, 2]] throws the following error:

Since TensorFlow considers [0, 2] an index of a single element from a 2D matrix, rather than selecting multiple elements from a 1D vector. As we will see later in the chapter, in TensorFlow, we can instead use tf.gather to get multiple elements from a tensor.

### 3.1.2 Flat Index vs. Multi-index

For matrices (2D) or higher-dimensional tensors, there are in general two conventions to represent the indices of the elements: **flat index** (a.k.a. linear index) and **multi-index**. The examples we have seen in Section 3.1.1 were using multi-index, which points to the spatial coordinate of the elements across multiple dimensions and represents the indices as a list of integers (each one corresponding to each dimension of the tensor). In contrast, flat indices enumerate the elements from 0 up to the number of elements in the tensor and represent each index as a single integer. As illustrated in Figure 3.3, suppose we have a 3 × 4 2D matrix, which has 12 elements. The flat index enumerates the elements one by one using indices from 0 to 11. In Chapter 2, we briefly discussed the “C” order and “F” order conventions when introducing reshaping operations. So depending on the ordering convention used by the matrix, there are two ways to specify the indices, either along the rows (row-major “C” ordering) or along the columns (column-major “F” ordering). In the case of “C” ordering, flat indices [0, 1, 2, ⋯, 11] correspond to (0, 0), (0, 1), (0, 2), ⋯, (1, 0), (1, 1), ⋯, (2, 3), where the indices along the second dimension increase first; in the case of “F” ordering, flat indices [0, 1, 2, ⋯, 11] correspond to (0, 0), (1, 0), (2, 0), ⋯, (0, 1), (1, 1), ⋯ , (2, 3), where the indices along the first dimension increase first. Another way to examine the differences between the two conventions is to look at the multi-index at a specific flat index. For example, the element at flat index 6 corresponds to

In general, we can convert between flat index and multi-index when given the element ordering convention "C" or "F" and the shape of the tensor. NumPy implements two functions to help the interconversion between the two indexing systems. `np.ravel_multi_index(multi_index, shape, order)` converts multi-indices to flat indices. Vice versa, `np.unravel_index(flat_indices, shape, order)` converts flat indices to multi-indices given tensor shape and order. For example, to convert from flat index to multi-index,

```
import numpy as np

shape = [2, 3, 3, 2]
flat_index = np.arange(0, np.prod(shape), 3)

r_multi_index = np.unravel_index(
    flat_index, shape, order="C"
)

print(np.stack([flat_index] + list(r_multi_index)).T)
# [[ 0  0  0  0  0]
#  [ 3  0  0  0  1]
#  [ 6  0  1  0  0]
#  [ 9  0  1  1  1]
#  [12  0  2  0  0]
#  [15  0  2  1  1]
#  [18  1  0  0  0]
```
