Figure 9.15 Implementation logic for ffill. (a) Illustration of the input data with missing values; (b) creation of the backtracking offset value logic. In the current example, there are four groups of empty entries. Groups 1 and 2 have only single entries of empty values, while Groups 3 and 4 have two empty entries. Therefore, for Groups 1 and 2, the offset only needs to backtrack 1 value (looking back 1), while for Groups 3 and 4, each subsequent index within the group needs to backtrack 1 more, i.e. -1, -2, ..., etc. (c) Given the set of all indices of the matrix, we apply the backtracking logic at each empty entry. (d) Iterative illustration of using gather to recreate a matrix with empty value filled. Notice that the beginning two values of the second row cannot be filled using the ffill method.
