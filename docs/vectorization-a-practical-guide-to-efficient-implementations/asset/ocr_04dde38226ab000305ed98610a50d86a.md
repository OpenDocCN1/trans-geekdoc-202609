+   d) Like the `divide` method, PyTorch also does not implement the safe reciprocal operation, but one can use `torch.nan_to_num` to fill the `NaN`s or `inf`s.

+   e) `exp1p(x)` is useful for computing the expression \(e^x - 1\) more accurately compared to `exp(x) - 1` when \(x \to 0\). A well known example is to compute annualized interest rate, \((1+x)^{t/y} - 1\), which can be expressed as \(\exp(t/y * \log1p(x)) - 1\), and implemented as `exp(t / y * np.log1p(x)) - 1` (see notes on example below).

+   f) Tensorflow does not implement log bases other than e, but one can use e.g. `math.log(x) / tf.math.log(base)` to convert bases.

+   g) `log1p(x)` is useful for computing the expression \(\log(1 + x)\) more accurately compared to `log(1 + x)` when \(x \to 0\). Well-known examples include computing annualized interest rate, \((1+x)^{t/y} - 1\) which can be expressed as \(\exp(t/y * \log1p(x)) - 1\), and implementation of inverse hyperbolic functions. For example, \(\text{arctanh}(x) = \frac{1}{2} \log(\frac{1+x}{1-x})\) can be implemented as \(0.5 * (\log1p(x) - \log1p(-x))\).

+   h) `logaddexp` is useful for computing the expression \(\log(\exp(x_1) + \exp(x_2))\) more accurately when x is extremely large or extremely small. This is a special case of `logsumexp` (see notes below).

+   i) `logsumexp` is a more general implementation of the above `logaddexp`, which can operate on more than two numbers, computing the expressions \(\log(\sum_i \exp(x_i))\). Notice that the summation expression is the normalization term for the softmax loss function in maximum-likelihood estimation \(p_j = \text{softmax}(x)_j = \frac{\exp(x_j)}{\sum_i \exp(x_i)}\), and the log probabilities then have form \(\log(p_j) = x_j - \log(\sum_i \exp(x_i))\). NumPy does not have a native implementation of this function, but it can be found in Scipy's `scipy.special.logsumexp`, using the so-called log-sum-exp trick [Wikipedia, 2023]:

![](bbox=[0.126, 0.511, 0.4, 0.56])

where \(x_{\max} = \max(x_0, x_1, \dots, x_p)\). A naive implementation is

```
import numpy as np
def logsumexp(x):
    x_max = np.max(x)
    return np.log(np.exp(x - x_max).sum()) + x_max
```
