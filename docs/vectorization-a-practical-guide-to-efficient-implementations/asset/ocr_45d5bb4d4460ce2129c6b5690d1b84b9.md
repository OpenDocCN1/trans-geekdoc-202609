Notice that in PyTorch's implementation, we need to add an additional dimension. This is because PyTorch's reflect padding is implemented in a way to specifically deal with tensors between two and five dimensions [Paszke et al., 2023], where the “reflection” can only be created:

+   - on the last dimension of 2D tensors;
+   - on either the last one or two dimensions for 3D tensors;
+   - on either the last two or three dimensions for 4D tensors;
+   - on the last three dimension for 5D tensors.

Also, only float values can be used for reflect padding operations in `torch.nn.functional.pad`.

In symmetric padding mode (NumPy: `symmetric`, Tensorflow: `SYMMETRIC`), padding values are added such that the resulting tensor is symmetric along each dimension. This is as if putting a mirror at the edge of the tensor along each dimension; unlike reflect mode, the border values will also be reflected in the mirror.
