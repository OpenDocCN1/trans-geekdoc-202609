# ## 6.1.3 Tensorflow Bytes

Tensorflow has the `tf.string` data type, but all the data stored in `tf.Tensor`
becomes bytes. For example,

```
import tensorflow as tf
string_array = ["lorem", "ipsum", "dolar"]
tf_string_array = tf.constant(string_array)
# tf.Tensor([b'lorem' b'ipsum' b'dolar'], shape=(3,), 
# ~ dtype=string)
```

The `tf.Tensor.numpy` method can convert Tensorflow's `tf.Tensor` to
a NumPy array. For float and integer types, the conversions typically have no
issues retaining the data as float and integer of the corresponding precisions (i.e.
`tf.int64 -> np.int64`, `tf.int32 -> np.int32`, `tf.float32 -> np.float32`, `tf.float64 -> np.float64`). But when converting a byte
string to a NumPy array, we will get an array of bytes in NumPy instead of typical
string representations (U or S). This can sometimes be inconvenient if we were
to implement further string processing on the text, where some methods are
specifically implemented against string types instead of byte types. For example,
suppose we would like to replace values using a dictionary, where the keys of
the dictionary are specified using strings. However, the values we would like to
replace are specified in bytes. If caution is not exercised, the program may not be
able to achieve the goal of replacing values at all.

```
import tensorflow as tf
mapping = {"A": "1", "B": "2", "C": "5"}
values = tf.constant([["A", "C", "B"]) # should result ["1", "5", "2"]
```
