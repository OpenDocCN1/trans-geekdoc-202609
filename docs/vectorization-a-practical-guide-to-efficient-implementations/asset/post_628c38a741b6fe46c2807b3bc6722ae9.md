
```python
# Use Gumbel-Max negative sampling
samples, binary_labels = gumbel_max_sample_without_replacement(
    true_labels,
    num_neg_samples=num_neg_samples,
    vocab_size=vocab_size,
    vocab_freq=vocab_freq,
    shuffle=False,
)

# Extract negative labels only
neg_samples = samples.values.numpy() * (
    1 - binary_labels.values.numpy()
)
neg_samples = neg_samples[neg_samples > 0]
neg_samples = neg_samples.astype(int).tolist()
neg_sample_freq.update(neg_samples)

return neg_sample_freq
```

## 10.6 Case Study: Sorting Articles Around Anchored Advertisements

Suppose we created a website that recommends news articles to readers. To monetize our website, we would like to insert some advertisements among the news articles that we recommend. Figure 10.8 illustrates the effect we would like to achieve. Our imaginary product manager has set the following requirements for the illustrated effect:

- 1. Anchored ads may occur at any position. This could be an output from a separate machine learning model.
- 2. The number of anchored ads may differ between each user.
- 3. News articles need to be sorted based on the priority scores for each item.
- 4. Separately, ads also need to be sorted based on their own priority scores, independent of the scoring of the news.
- 5. Ads can only occur in the prespecified anchor positions, while the news can only occur in the rest of the free positions.
- 6. The final output should display up to eight news contents including both ads and news, even though we may be provided more news and ads to sort. We also assume that there is always enough content to make up eight total displayable items.

The following code block implements a vectorized operation to rearrange the news and ads among each other. The general strategy is to sort news and ads separately based on their respective priority scores and then rearrange the two pieces into the same matrix, using masking and gathering.

![](img/e891acaacd4fb5b80dab2ed824618203_388_0.png)

**Figure 10.8** Illustration of arranging news articles around anchored ads.

```python
import tensorflow as tf

def arrange_ads_among_news(
    news_scores,
    ads_scores,
    ads_positions,
    news_vocab=None,
    ads_vocab=None,
    k=8
):
    """
    Arrange ads within a series of news articles for a batch of users.

    Inputs:
    * news_scores: (batch_size, news_vocab_size) Tensor
      Scores for each news, corresponding to each news in news_vocab
    * ads_scores: (batch_size, ads_vocab_size) Tensor
      Scores for each ad, corresponding to each ad in ads_vocab
    * ads_positions: (batch_size, None) Left Aligned SparseTensor
      List of allowed ads positions for each user
    * news_vocab: (news_vocab_size,) array
      List of vocabulary for news. If None, the function returns
      the indices in the concatenated vocab space
    * ads_vocab: (ads_vocab_size,) array
      List of vocabulary for ads. If None, the function returns
      the indices in the concatenated vocab space
    * k: int
      Number of total contents to keep.
    """
    # Sort the news and ads
    # switch to 1-based indexing
    news_items = tf.argsort(news_scores, direction="DESCENDING") + 1
    # padding at the beginning of each row
    news_items = tf.pad(news_items, [(0, 0), (1, 0)])
    news_items = tf.cast(news_items, tf.int64)
    ads_items = tf.argsort(ads_scores, direction="DESCENDING") + 1
    ads_items = tf.pad(ads_items, [(0, 0), (1, 0)])
    ads_items = tf.cast(ads_items, tf.int64)

    # Compute unanchored positions mask
    anchored_indices = tf.transpose(
        tf.stack([ads_positions.indices[:, 0], ads_positions.values])
    )

    # remove any anchor positions beyond the max number of contents to keep
    anchored_indices = tf.boolean_mask(
        anchored_indices, anchored_indices[:, 1] < k, axis=0
    )

    # Use sparse tensor to indicate the anchored positions
    anchored_mask = tf.sparse.SparseTensor(
        indices = anchored_indices,
        values = tf.ones_like(anchored_indices[:, 0]),
        dense_shape=(tf.shape(news_scores)[0], k)
    )
    anchored_mask = tf.sparse.to_dense(anchored_mask)
    # Create the indices matrix for ads
    anchored_positions = tf.cumsum(anchored_mask, axis=1) * anchored_mask
    # Gather along axis=1
    output_index_ads = tf.gather(
        ads_items, anchored_positions, batch_dims=1, axis=1
    )
    # Create the indices matrix for news
    free_mask = 1 - anchored_mask
    free_positions = tf.cumsum(free_mask, axis=1) * free_mask
    output_index_news = tf.gather(
        news_items, free_positions, batch_dims=1, axis=1
    )
    # Combine the two sets of indices together
    news_vocab_size = tf.cast(tf.shape(news_scores)[1], tf.int64)
    output_index = tf.where(
        free_mask > 0,
        # convert back to 1 based indexing
        output_index_news-1,
        # index of ads in the combined vocab
        news_vocab_size + output_index_ads - 1
    )
    if news_vocab is not None and ads_vocab is not None:
        # Create the string outputs
        vocab = tf.concat([news_vocab, ads_vocab], axis=0)
        output = tf.gather(vocab, output_index)
        return output, free_mask
    else:
        # return the indices in the combined space
        return output_index, free_mask
```

- Lines 32-38 sort the news and ads separately and get the corresponding sorting indices (i.e. we use an integer representation of the items). We changed to a 1-based indexing system to prepare for subsequent masking operations. We also padded the beginning of each row by a 0 so that the subsequent `gather` operation can still pretend it is gathering using a 0-based indexing system (more details below).

- Lines 41-43 determine the multi-index of the anchored positions in the final output matrix. The row/column indices correspond to the batch indices of the original sparse tensor; the column indices of the anchored positions corresponds to the values of the original sparse tensor. See Figure 10.9 for an illustration.

- Lines 49–53 create a sparse indicator matrix, using the anchored_indices we determined from the previous steps. - Line 57 calculates the anchored sorting positions using the anchored_mask. The nonzero values in this matrix are indices corresponding to the values ads_items. To illustrate the math operations implemented here, suppose the mask for a row is [0, 0, 1, 0, 1, 0, 0, 0] where 1s indicate where the advertisements are. The first occurrence of 1 should correspond to the ads with the highest priority score, while the second occurrence of the 1 should correspond to the ads with the second highest priority score, etc. Therefore, we want to denote the positions of sorting in this array as [0, 0, 1, 0, 2, 0, 0, 0], where 0s are padding indices, while 1 and 2 indicate the priority of the ads that should be inserted at those positions. This transformation is achieved by cumsum(mask) * mask. More concretely, we can interpret this array as a form of ledgers in the following way: for the first two elements, the ledgers are 0 paddings, so we should retrieve the padding item from the sorted ads_items (i.e. ads_items[0] = 0 which is a padding). The third element is a ledger of 1, meaning we should take the ads with the highest priority, i.e. ads_items[1]. The fourth element is a padding value again. The fifth element 2 indicates that we should retrieve the ads with the second highest priority, i.e. ads_items[2]. The rest are all paddings again.
- Lines 59–61 use the anchored_positions derived from the previous step to look up the ads item indices. This will yield a dense matrix where the ads will be placed at the anchored positions.
