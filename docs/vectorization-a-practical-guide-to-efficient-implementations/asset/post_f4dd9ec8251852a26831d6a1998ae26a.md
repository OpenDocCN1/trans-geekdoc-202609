
## 9.6 Case Study: EmbeddingBag

PyTorch has a convenient neural network layer class `torch.nn.EmbeddingBag`
EmbeddingBag which can summarize the embeddings from the same group of
values, e.g. a sequence of embeddings for events occurring on the same date.
In Chapter 8, we looked at a case study that leveraged the idea of sparse matrix
multiplication and used sparse tensor inputs to look up and add the embeddings
together. In this case study, we will generalize the embedding lookup and
summarization process in TensorFlow. We will implement four summarization
modes, "mean", "max", "sum", and "sqrt_n", to combine the embeddings
from the same group (i.e. values from the same row of a batch of variable-length
categorical values). The following code block implements the EmbeddingBag
layer using TensorFlow and Keras.

```
import tensorflow as tf
from keras import Model, Input
from keras.layers import Layer, Embedding

class EmbeddingBag(Layer):
    """
    Keras EmbeddingBag class that summarizes embeddings of a sparse input.

    Inputs:
        * num_items: number of embeddings to create.
        * emb_size: size of embeddings.
        * mode: mode summarization mode,
          one of ["mean", "max", "sum", "sqrt_n"].
        * init_weights: NumPy array of embedding values. To keep using the
          initialized values, set 'trainable=False' to prevent the
          embedding values being updated during training.
        * **kwargs: additional keyword arguments to pass to the Keras
          Embedding layer.
    """
    def __init__(
        self,
        num_items,
        emb_size,
        mode="mean",
        init_weights=None,
        name="embedding_bag",
        **kwargs
    ):
        super(EmbeddingBag, self).__init__(name=name)
        assert mode in ("mean", "max", "sum", "sqrt_n")
        self.mode = mode
        self.emb_size = emb_size
        self.embedding = Embedding(
            num_items, emb_size, **kwargs
        )
```

- __init__ (Lines 20-39): This method initializes the EmbeddingBag layer class. It leverages Keras' built-in Embedding layer to create the embedding lookup table (Lines 33-35). Additionally, we allow the embedding values to be created from a set of pretrained weights, by specifying and loading the weights of the Embedding layer. To keep using the same embedding values during training without further updates, users can set trainable=True when initializing the layer.

- call (Lines 41-84): This method takes two data inputs, x which is a sparse tensor of the integer index representation of categorical values, and weights which is a sparse tensor of weights for each category, with shape and number of elements identical to that of x.

  - Lines 46-48 if weights is not specified, then we default all embeddings having identical weights of 1.

  - Lines 51-52 perform the embedding lookup and apply the weights of the category.

  - Lines 56-82 apply the groupby and aggregate operations of the embedding vectors using the mode specific groupby and aggregate operations. Note that for "mean", "sum", and "sqrt_n", we use tf.sparse.segment_<mean/sum/sqrt_n> operations. This is because when x is a sparse input, there may be rows within the batch that have empty entries, and we would like to represent the sequence with empty entries with a vector of all zeros. By specifying the num_segments=tf.shape(x)[0], we are guaranteed to return a dense tensor of shape (batch_size, emb_size). If we do not specify the num_segments argument, then if an empty row is the last row of the batch, we will be missing its representation. For "max" mode, we use tf.math.segment_max since there is no corresponding operation under the tf.sparse module. For the same reason, when implementing the "max" mode, we need to append zero vectors to the batch such that the output summarized embedding tensor has an expected shape of (batch_size, emb_size). To illustrate:

```
import tensorflow as tf
# 6 valid values total
x = tf.ragged.constant([[1, 3], [2], [], [6, 8, 9], []]).to_sparse()
# After embedding lookup, we have a matrix of (7, 8)
emb = tf.random.uniform((len(x.values), 8))
# Summarized correctly: (5, 8)
emb_sum_correct = tf.sparse.segment_sum(
    emb, x.indices[:, 1], x.indices[:, 0], num_segments=tf.shape(x)[0]
)
# Summarized incorrect: (4, 8)
emb_sum_wrong = tf.sparse.segment_sum(
    emb, x.indices[:, 1], x.indices[:, 0]
)
# Summarized wrong using tf.math.segment_max: (4, 8)
emb_max_wrong = tf.math.segment_max(
    emb, x.indices[:, 0]
)
# Need to pad the empty entries occurring at the end
pad_size = tf.shape(x)[0] - tf.shape(emb_max_wrong)[0]
emb_max_correct = tf.pad(emb_max_wrong, [[0, pad_size], (0, 0)])
```
