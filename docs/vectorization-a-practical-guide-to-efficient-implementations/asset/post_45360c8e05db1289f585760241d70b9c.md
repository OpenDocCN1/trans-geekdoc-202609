## 5.1.4 Use Arithmetic Operations as Boolean Operations to Apply and Combine Masks

As introduced in Chapter 2, there are four major boolean operations, AND, OR, NOT, and XOR. When a mask tensor is expressed as booleans, we could take advantage of boolean operators &, |, ~, and ^, or dedicated operations such as Tensorflow's logical_and, logical_or, logical_not, and logical_xor. However, masks can be created as numerical tensors instead of boolean tensors, so type casting is needed. If both our masks and data are already in numerical dtypes, it may be simpler and easier to combine and apply the masks using only numerical operations.

To illustrate how boolean operations can be expressed as arithmetic operations, suppose we have two masks mask_a = [1, 0, 0, 1, 0] and mask_b = [0, 0, 0, 1, 1]. If we convert them to boolean masks, then mask_a_bool = [True, False, False, True, False] and mask_b_bool = [False, False, False, True, True].

The NOT operation on mask_a_bool results in B = [False, True, True, False, True], or converting to binary, [0, 1, 1, 0, 1]. Notice that this is simply 1 - mask_a. Therefore 1 - mask can be used for the NOT operation.

The AND operation between mask_a_bool and mask_b_bool results in B = [False, False, False, True, False]. The AND operation yields True if and only if both elements from the two arrays at the corresponding index are True, or numerically, 1. We can multiply the two numerical masks together, yielding S = [0, 0, 0, 1, 0]. Notice that this corresponds well to the boolean mask B given 0 corresponds to False and 1 corresponds to True.

The OR operation between mask_a_bool and mask_b_bool results in B = [True, False, False, True, True]. The OR operation yields True when either element from the two arrays at the corresponding index is True, or numerically corresponding to 1. We can add the two numerical masks together, yielding S = [1, 0, 0, 2, 1]. This corresponds well to the combined boolean mask, where 0 corresponds to False and any value greater than 0 corresponds to True. To retain the binary (0 and 1 only) nature of the combined mask, we can clip the value of the combined numerical mask to have a max value of 1, with np.minimum(S, 1) = [1, 0, 0, 1, 1].

Lastly, the XOR operation between mask_a_bool and mask_b_bool results in B = [True, False, False, False, True]. The XOR operation yields True when and only when the values of the two elements are not the same (True vs. False or False vs. True) and yields False otherwise (True vs. True or False vs. False). Using the AND, OR, and NOT operators, XOR is equivalent to a ^ b = (a | b) & ~(a & b). So the more difficult way is to use the above arithmetic versions of the AND, OR, and NOT boolean operations to reconstruct XOR. However, a simpler way is to use subtraction and absolute value, i.e. np.abs(a - b) = np.abs([1, 0, 0, 0, -1]) = [1, 0, 0, 0, 1].

The following code snippet implements the arithmetic version of the boolean operations.

```python
import numpy as np

def combine_mask(a, b=None, operation="not"):
    if operation == "not":
        assert b is not None, f"b is required for {operation}"
    if operation == "not": # b is ignored
        return 1 - a
    elif operation == "and":
        return a * b
    elif operation == "or":
        return np.minimum(a + b, 1)
    elif operation == "xor":
        return np.abs(a - b)
    else:
        raise(ValueError(f"Unrecognized operation {operation}."))
```

## 5.1.5 Select Elements Based on Masking

The masking methods we have introduced so far all replace the values within the tensors while retaining the shape and dimensions of the input tensor. However, there are cases where we would like to discard the masked elements and therefore reduce the size of the input. NumPy’s np.compress (or equivalently Tensorflow’s tf.boolean_mask and PyTorch’s torch.masked_select) is used for such purpose. In the simplest case, boolean masking is the same as using boolean indices to select elements. For example,

```python
import numpy as np

X = np.array([5, 3, 2, 6, 9])
mask = np.mod(X, 2) == 0 # even number
assert np.allclose(
    X[mask], # array([2, 6])
    np.compress(mask, X) # array([2, 6])
)
```

For a more advanced example, suppose we have a 2D square matrix of size (N, N) and we would like to remove all the diagonal entries so that it becomes

## 5.1.6 Case Study: Top-k Masking

Suppose we have a batch of arrays (e.g. a 2D matrix). For each array, we would like to retain only the top three values, while setting all the other entries to be zeros (see Figure 5.5a). We can do this by creating a binary mask and applying the binary mask to the original matrix. The binary mask should have 1s at indices where the value of the original matrix is among the top three values, and 0s otherwise (see Figure 5.5b).

The code snippet below implements the top-k masking operation using NumPy.

```python
import numpy as np
def top_k_masking(y, top_k, masked_value=0):
    """Mask the input and retain only top_k values."""
    # Get top k indices
    index = np.argsort(y) [..., -top_k:][..., ::-1]
    # Initialize the zeros mask
    mask = np.zeros_like(y)
    # scatter the indices (in-place)
    np.put_along_axis(mask, index, 1, axis=-1)
    # Adjust values such that the masked elements
    # are replaced with masked_value
    y_masked = y * mask + masked_value * (1 - mask)
    return y_masked
```

- Line 5 gets the index of the top-k values
- Line 7 initializes the mask which will indicate the values to keep as 1s and values to discard as 0s.
- Line 9 does an in-place replacement to put 1s at indices where the values will be kept.
- Line 12 applies the masking. mask is binary (1s and 0s). The element-wise multiplication y * mask will set all masked/discarded values to be zeros first. Then, the masked_value * (1 - mask) will then set the masked entries to the masked_value (i.e. when the value is to be masked, value:= 0 + masked_value = masked_value; otherwise, value:= value + 0 = value).
