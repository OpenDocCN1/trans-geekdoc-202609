```
else:
    raise(ValueError(f"Unrecognized order: {order}"))
    # (num_indices, 1)
    flat_index = np.asarray(flat_index)[:, None]
    shape = np.asarray(shape)
    # Compute multi-index
    return flat_index // eta % shape
```

+   - Lines 3–10 implement the array \(\eta\) depending on the order. Notice that the last element of `eta` is 1 when `order="C"` while the first element of it is 1 when `order="F"`.
+   - Lines 13 and 14 make sure the `flat_indices` and `shape` are both arrays in order to implement our formula in Equation 3.1.
+   - Line 17 implements the index conversion formula.
