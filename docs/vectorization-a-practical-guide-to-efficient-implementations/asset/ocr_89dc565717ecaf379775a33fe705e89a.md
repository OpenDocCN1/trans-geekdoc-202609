Line 23 reshapes the 1D vector into a (num_blocks, 2) matrix. This is because there should always be a start and end of the block. Since the input array is already sorted, the end of the block should always occur after the start of the block, given a single block.

Lines 25–27 perform a filtering for block size. There are two modes of this: either counting the number of elements or the number of intervals. The number of intervals can be computed by end_index - start_index, while the number of elements can be computed by end_index - start_index + 1. I use the flag interval to switch between the two cases: if interval=True, then I do not need to add the 1; if interval=False, then I do need to add 1; hence, the expression int (~interval).
