To further illustrate the relationship between the flat index and multi-index, we may derive the patterns of converting between these two indexing systems based on the above example. Let a tensor have shape \((n_0, n_1, \dots, n_d, \dots, n_{D-1})\), thus it has \(r = \prod_{i=0}^{D-1} n_i\) elements, where \(D\) is the number of dimensions of the tensor. Then, to convert from flat index \([r_0, r_1, \dots, r_j, \dots]\), we can use the formula:

\(i_d^{(j)} = \left\lfloor \frac{r_j}{\eta_d} \right\rfloor \mod n_d\) (3.1)

where \(n_{d<D-1} = \prod_{i=d+1}^{D-1} n_i, \eta_{D-1} = 1\) when using row-major ("C") ordering, and \(n_{d>0} = \prod_{i=0}^{d-1} n_i, \eta_0 = 1\) when using column-major ("F") ordering; \([\cdot]\) is the floor division or integer division operation. We can implement our discovery as the following:
