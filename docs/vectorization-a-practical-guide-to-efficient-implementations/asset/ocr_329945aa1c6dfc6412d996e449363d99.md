c) The append operation is similar to concatenation. When axis=None, then the inputs are first flattened before being concatenated.

```
# one dimensional vectors
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
c = np.append(a, b, axis=None)
# results
# array([1, 2, 3, 4, 5, 6])
```

```
# two dimensional matrices
x = np.array([[1, 2, 3], [4, 5, 6]])
y = np.array([[-1, -2, -3], [-4, -5, -6]])
z = np.append(x, y, axis=None)
# results
# array([ 1, 2, 3, 4, 5, 6, -1, -2, -3, -4, -5, -6])
```

However, if axis is specified (e.g. axis=0), then this function may act as concatenation.

```
# one dimensional vectors
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
# specifying axis=1 will throw AxisError:
# axis 1 is out of bounds for an array of dimension 1
c = np.append(a, b, axis=0)
# results
# array([1, 2, 3, 4, 5, 6])
```

```
# two dimensional matrices
x = np.array([[1, 2, 3], [4, 5, 6]])
y = np.array([[-1, -2, -3], [-4, -5, -6]])
# concatenate along axis=0
z = np.append(x, y, axis=0)
# results
# array([[ 1, 2, 3],
#        [ 4, 5, 6],
#        [-1, -2, -3],
#        [-4, -5, -6]])
```

```
# concatenate along axis=1
z = np.append(x, y, axis=1)
# results
# array([[ 1, 2, 3, -1, -2, -3],
#        [ 4, 5, 6, -4, -5, -6]])
```
