# Table 3.1 List of slicing and striding operations with example usages in 1D arrays.

| Operations | Syntax | Example |
|---|---|---|
| Slicing between two indices | start:stop | l[1:4] -> [3, 5, 7] |
| Slicing using negative indices (translated to start+n and stop+n) | start:stop | l[-4:-1] -> [3, 5, 7] |
| Slicing from a start index to the last element | start: | l[2:] -> [5, 7, 9] |
| Slicing from the first element to a stop index | :stop | l[:3] -> [1, 3, 5] |
| Striding | start:stop:step | l[1:4:2] -> [3, 7] |
| Selecting all elements | : | l[:] -> [1, 3, 5, 7, 9] |
| Selecting all elements except the last | :-1 | l[:-1] -> [1, 3, 5, 7] |
| Selecting all elements except the last N element(s) | :-N | l[:-2] -> [1, 3, 5] |
| Reversing array | ::-1 | l[::-1] -> [9, 7, 5, 3, 1] |
| Striding from the first element to a stop index | :stop:step | l[:4:2] -> [1, 5] |
| Striding from a start index to the last element | start::step | l[1::2] -> [3, 7] |
| Striding from first to last element | ::step | l[::2] -> [1, 5, 9] |
| Striding from last to first element | ::-step | l[::-2] -> [9, 5, 1] |
