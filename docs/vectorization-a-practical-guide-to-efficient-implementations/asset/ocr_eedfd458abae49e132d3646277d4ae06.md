# 5 Masking and Padding

Our discussions on vectorized operations have thus far assumed that we are dealing with data that can be consistently represented by a multidimensional dense tensor given a certain shape. For example, a stack of images can be represented by a dense tensor of shape `(batch_size, width, height, channel)`. Tabular data that contains several numerical columns can be represented as a matrix of shape `(batch_size, num_columns)`. However, in various real-world machine learning applications, we also frequently need to deal with data that comes in varying sizes. For example, a collection of audio recordings may have variable durations. So to make our operations vectorizable across our collection of data, we need to seek ways to reconfigure our data so that it can be represented by a tensor with a single consistent shape. This can be achieved by **padding** the sequences of audio recordings to the same predefined length. On the other hand, the audio recording may have silent periods, which we do not want the model to pay attention to during the learning process. We can therefore use **masking** to tell the model to concentrate the learning on the parts that contain audio we would like to model. Therefore, masking and padding are important techniques to vectorize our machine learning modeling operations when dealing with variable-sized data.
