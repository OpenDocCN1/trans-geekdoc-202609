c) Alternatively tf.random.uniform(start, end, shape, dtype=tf.int32) can also be used to draw integers given a range.

d) PyTorch also has the method torch.range, which is end inclusive. This means, torch.range(1, 5) = (1, 2, 3, 4, 5), while all other range methods are end-exclusive. i.e. range(1, 5) = (1, 2, 3, 4).

e) An alternative method to np.eye is np.identity. np.identity only returns matrices with the entries at the main diagonal to be 1s. In contrast, np.eye can return matrices with off-diagonal entries to be 1s. The corresponding methods in Tensorflow tf.eye and PyTorch torch.eye are actually much more similar to np.identity where the matrices returned only have the main diagonal entries set to 1s. To illustrate

```
1 import numpy as np
2 np.eye(2, dtype=int)
3 # array([[1, 0],
4 #        [0, 1]])
5 np.eye(3, k=1, dtype=int)
6 # array([[0, 1, 0],
7 #        [0, 0, 1],
8 #        [0, 0, 0]])
9 np.identity(3)
10 # array([[1., 0., 0.],
11 #        [0., 1., 0.],
12 #        [0., 0., 1.]])
```
