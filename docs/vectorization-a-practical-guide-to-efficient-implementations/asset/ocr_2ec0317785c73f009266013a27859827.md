j) You may wonder why we even need to have a specific function for computing the square of a number, instead of simply using `x ** *`. This is all about performance. It turns out that is faster to compute `x * x` than `pow(x, 2)`. Having a specialized square function is convenient for implementing something like `this_is_a_variable_with_super_long_name,e.g. See this issue [Paszke et al., 2023a] in PyTorch's repository.

k) Python complex numbers can be constructed as `<real> + <imag>j`, e.g. `1 + 2j` (notice no spaces between `2` and `j`). This is why I typically do not use `j` as indices when writing a for-loop since it may be confused with Python's reserved variable for the imaginary number.
