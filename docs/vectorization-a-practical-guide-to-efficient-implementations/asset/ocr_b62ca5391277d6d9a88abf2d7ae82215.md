To illustrate the math operations implemented here, suppose the mask for a row is [0, 0, 1, 0, 1, 0, 0, 0] where 1s indicate where the advertisements are. The first occurrence of 1 should correspond to the ads with the highest priority score, while the second occurrence of the 1 should correspond to the ads with the second highest priority score, etc. Therefore, we want to denote the positions of sorting in this array as [0, 0, 1, 0, 2, 0, 0, 0], where 0s are padding indices, while 1 and 2 indicate the priority of the ads that should be inserted at those positions. This transformation is achieved by cumsum(mask) * mask. More concretely, we can interpret this array as a form of ledgers in the following way: for the first two elements, the ledgers are 0 paddings, so we should retrieve the padding item from the sorted ads_items (i.e. ads_items[0] = 0 which is a padding). The third element is a ledger of 1, meaning we should take the ads with the highest priority, i.e. ads_items[1]. The fourth element is a padding value again. The fifth element 2 indicates that we should retrieve the ads with the second highest priority, i.e. ads_items[2]. The rest are all paddings again.
