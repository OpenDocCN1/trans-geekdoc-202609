# 11.1 Language Modeling with Transformer

Prior to the introduction of the transformer architecture [Vaswani et al., 2017], deep learning-based natural language modeling has been relying on previously introduced sequence representation architectures such as recurrent neural networks (RNNs) and convolutional neural networks (CNNs). However, these architectures have a limitation: When learning from a long sequence of text/documents, they tend to remember only the most recently encountered tokens and forget those encountered earlier (e.g. the beginning of a paragraph). Deep learning researchers assess an architecture’s capability to learn from input signals using a metric called **receptive field** size, a concept borrowed from vision neuroscience. If a model can memorize and learn from a long sequence (in 1D sequence modeling) or a large area (in 2D/3D computer vision problems), then it is said to have a large receptive field. Having a limited receptive field creates problems for tasks like language translation or question-answering, where the text input (i.e. prompt) can be very long (e.g. hundreds of words).
