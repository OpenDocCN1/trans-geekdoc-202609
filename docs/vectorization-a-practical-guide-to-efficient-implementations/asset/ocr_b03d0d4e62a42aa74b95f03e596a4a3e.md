**Figure 10.3** Illustration of using `np.unique` to sort rows of a matrix. In this example, we have a 7 x 3 matrix A where we want to sort its rows. Note that row 0 and row 4 are duplicated. After `np.unique` along `axis=0`, the rows are deduplicated to produce the matrix, and then sorted lexicologically (i.e. first by column 0, then by column 1, ..., etc.), which produces unique matrix U. We can see that the first row of U came from row 0 of A; the second row of U came from row 2 of A; the third row of U came from row 3 of A, and so on. Hence we have a mapping between the rows in A and U (which is the `row_index` on the left and the `unique index` on the right of the unique matrix U at corresponding rows). As we also specified `return_inverse=True`, `np.unique` returns a set of reverse indices to indicate from which indices in U can recover the original matrix A. This is illustrated as the `unique index` on the right side of the original matrix A. For examples, we can use row 0 from the unique matrix U as the first row of the original matrix A; we can use row 5 from U as the second row of A; we can use row 1 from U as the third row of A, and so on. The ordinal value of the `unique index` indicates the lexicological order of the rows. So if we would like to sort the original matrix A according to the lexicological ordering, then we should sort the rows according to the ordinal values of the reverse indices. In other words, we would like to place the rows in the order of the `unique index`. As shown in the `A_sorted` matrix, rows from the original matrix are sorted according to the ordinal values of the `unique index`.
