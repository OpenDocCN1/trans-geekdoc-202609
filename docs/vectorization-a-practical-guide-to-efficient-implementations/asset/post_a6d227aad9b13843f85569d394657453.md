
```
3 unique, index = np.unique(feature, return_inverse=True)
4 # unique = array(["a", "b", "c"], dtype="<U1")
5 # index = array([0, 1, 2, 1, 0])
```

Here, the `unique` array would be the vocabulary of the categorical feature,
while the `index` would be the corresponding index. It can be easy to verify that
using the `unique` vocabulary and index of the category, we can reconstruct the
feature

```
6 # code continues from above
7 recovered_feature = np.take(unique, index)
8 assert np.all(feature == recovered_feature)
```

The disadvantage of using `np.unique`, however, is that the indices determined
may not be reproducible: if the order of the original list is changed, then it is no
longer guaranteed the same string value will be mapped to the same integer index
value. For instance,

```
1 import numpy as np
2
3 feature_a = ["a", "b", "c", "b", "a"]
4 feature_b = ["c", "b", "a", "b", "b"]
5
6 _, index_a = np.unique(feature_a, return_inverse=True)
7 # array([0, 1, 2, 1, 0])
8 _, index_b = np.unique(feature_b, return_inverse=True)
9 # array([2, 1, 0, 1, 1])
```

Pandas also has the method `pd.factorize` which can achieve similar effects.

## 6.4.3 Scikit-learn sklearn.preprocessing.LabelEncoder

None of the encoding methods we have discussed so far allow us to easily reuse the mapping between the string value and the indices, a requirement when making inferences on new data during production. The sklearn.preprocessing.LabelEncoder class allows us to create and save the mapping for later use.

```python
from sklearn.preprocessing import LabelEncoder
vocabulary = [chr(ii+97) for ii in range(26)]
feature_train = ["b", "a", "c", "d", "z"]
# Create the encoder
feature_lookup = LabelEncoder()
feature_lookup.fit(vocabulary)
# Transform during training
index_train = feature_lookup.transform(feature_train)
# array([1, 0, 2, 3, 25])
# New data during inference
feature_test = ["f", "g", "a", "b", "h"]
index_test = feature_lookup.transform(feature_test)
# array([5, 6, 0, 1, 7])
```

Notice that both feature_train and feature_test features have the string value a and b in them. The corresponding index_train and index_test indices are both 0 and 1, respectively. This demonstrates that sklearn.preprocessing.LabelEncoder can (re)produce consistent string value to index mappings.

## 6.4.4 Tensorflow tf.lookup

Tensorflow's tf.lookup offers yet another suite of tools to convert string values of features into indices. tf.lookup has methods that build hash tables, so it can be used for a more general purpose not limited to string to integer mapping. One key feature of tf.lookup, in my opinion, is the ability to handle new feature values that are out of vocabulary (OOV). This is something missing from the three libraries we have discussed so far. In my everyday practice, I often reserve index 0 for OOV vocabularies and start the index from 1. Another option is to still use 0 as the first index and use the index len (vocabulary) as the OOV indices (which we can also use -1 as an equivalent alternative). To illustrate the usage, suppose we have a list of the alphabet that we would like to map to integer indices:

```python
import tensorflow as tf
# Create a list to store all the alphabet
alphabet_lookup = tf.constant([chr(ii+97) for ii in range(26)])
# Last value in the list is oov
values = tf.constant(["b", "a", "c", "d", "z", "1"])
# Create the lookup hash table
table = tf.lookup.StaticHashTable(
    tf.lookup.KeyValueTensorInitializer(
        keys=alphabet_lookup,
        # index starts from 1
        values=list(range(1, len(alphabet_lookup)+1)),
        key_dtype=tf.string,
        value_dtype=tf.int64,
    ),
    default_value=0, # oov
)
# Map the values
index = table.lookup(values)
# <tf.Tensor: shape=(6,), dtype=int64, numpy=array([ 2, 1, 3, 4, 26, 0])>
```

tf.lookup can also create lookup tables by loading from a text file.

```python
import os
import tempfile
import tensorflow as tf
# Create a list to store all the alphabet and save to a file
alphabet_lookup = [chr(ii+97) for ii in range(26)]
_, file_path = tempfile.mkstemp()
with open(file_path, "w") as fid:
    fid.write("\n".join(alphabet_lookup))
# Last value in the list is oov
values = tf.constant(["z", "a", "c", "q", "h", "3"])
# Create the vocabulary lookup
table = tf.lookup.StaticHashTable(
    tf.lookup.TextFileInitializer(
        filename=file_path,
        # each line of the text file is a feature value
        key_index=tf.lookup.TextFileIndex.WHOLE_LINE,
        # use the line number as the index of the value
```
