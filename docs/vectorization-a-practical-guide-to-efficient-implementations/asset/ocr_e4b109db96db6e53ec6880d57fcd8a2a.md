**Figure 4.4** Illustration of tensordot operations when axes=2. (a) For a pair of 2D matrices each having a shape of (2, 3), the tensor dot product along axes=2 is equivalent to tensor double contraction a : b = Tr(ab^T), which yields a scalar; (b) after adding one leading dimension, making the first tensor a have shape (2, 2, 3), the tensor dot product becomes 1 matrix contraction operations, for each matrix within a against matrix b; (c) after adding one trailing dimension, making the second tensor b have shape (2, 3, 2), the tensor dot product becomes a set of matrix contraction operations for each combination of matrices between a and b. The matrices in a are taken along the axes 1 and 2, making axis=0 the batch dimension. The matrices in b are taken along the axes 0 and 1, making axis=2 the batch dimension. The resulting tensordot product has shape (2, 2).

+   • np.tensordot (a, b, 1) is equivalent to either np.tensordot (a, b, [[1], [0]]) when a is a matrix and b is at least a 1D vector (but it can also be greater dimensions), or np.tensordot (a, b, [[0], [0]]) when a and b are both vectors. More generally, axes=[[-1], [-1]] will cover both cases.

+   • np.tensordot (a, b, 2) is equivalent to np.tensordot (a, b, [[0, 1], [0, 1]]) when a and b are both 2D matrices, or more generally, np.tensordot (a, b, [[-2, -1], [0, 1]]) for arbitrary tensors with a number of dimensions greater than or equal to 2.

We can similarly derive a general rule here: let the first input tensor a have shape (m, n, ..., s_i, ....) and the second input tensor b have shape (p, q, ..., s_{p_i}, ..., r_j, ...), and let s_i == r_j, for i, j ∈ 1, 2, ..., k, where k is the number of dimensions to contract. We then specify the axes argument as axes=[[..., i, ...], [..., j, ...]] to indicate contractable dimensions. Then, the elements along the corresponding contractable dimensions are multiplied together element-wise and then summed together to obtain a single scalar. The operation is repeated (i.e. vectorized) over all combinations of dimensions that are not contracted, and the resulting tensor has shape (m, n, ..., p, q, ...).
