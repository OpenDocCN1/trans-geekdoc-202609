Each entry of the event_timestamp feature corresponds to a specific time of occurrence of the event in the event_type feature. Notice, we are missing multiple entries in the event_timestamp feature. One strategy to guess the time of the event occurrence is to look for the nearest timestamp, either before or after the missing value. See Figure 9.15 for the detailed strategy for fflll that we implemented below using Tensorflow, along with the line-by-line explanation of the code below.

import tensorflow as tf
def fflll(x):
  """Forward filling the values of a 2D matrix row"""
  # Track indices for all values
  r, c = tf.cast(tf.shape(x), dtype=tf.int64)
  flat_indices = tf.range(r * c)
  indices = tf.stack([
    flat_indices // c,
    flat_indices % c
  ], axis=0)
  indices = tf.transpose(indices)

  # Indices of consecutive integers
  empty_indices = tf.where(x == "")
  f = (empty_indices[1:, 1] - empty_indices[:-1, 1]) == 1
  f = tf.concat(([False], f), 0) != tf.concat((f, [False]), 0)
  f = tf.where(f)
  f = tf.reshape(f, (-1, 2))

  # Compute backtracking offset values
  offset_indices = tf.ragged.range(f[:, 0], f[:, 1] + 1).flat_values
  offset_values = tf.ragged.range(f[:, 1] - f[:, 0] + 1).flat_values
