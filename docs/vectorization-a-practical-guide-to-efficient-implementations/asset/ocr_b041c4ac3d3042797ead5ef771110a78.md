9. Line 35 applies the value mapping formula we defined previously, by broadcasting the \( m \times m \) Siamese magic matrix to the \( m \times m \times 2 \times 2 \) tensor \( M \) we obtained from Step 7 above. Notice that we expanded two additional dimensions at `axis=2` and `axis=3`.

10. Line 37 reshapes the tensor back into the \( n \times n \) matrix. We first swap the second and third axes, making \( m \times m \times 2 \times 2 \) becomes \( m \times 2 \times m \times 2 \). Then, we reshape to \( n \times n \).

Finally, we can put the three cases of constructing magic squares under a single function:

```
import numpy as np

def magic(n: int):
    """Construct magic squares of order n."""
    n = int(n) # make sure n is integer
    if n < 3: # check value of n
        raise ValueError("n must be > 2."))
    if n % 2 == 1: # odd case
        return _odd_order_magic(n)
    elif n % 4 == 0: # doubly even
        return _doubly_even_order_magic(n)
    else: # assume singly even
        return _singly_even_order_magic(n)
```
