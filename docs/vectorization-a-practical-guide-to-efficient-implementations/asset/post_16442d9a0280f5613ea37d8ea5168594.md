## 4 Linear Algebra

In Chapter 2, we introduced element-wise operations on tensors or a pair of tensors. Specifically, when multiplying two tensors element-wise, we are performing the mathematical operation called Hadamard Product, which is expressed as \( X \cdot Y \). In this chapter, we will first examine operations associated with matrix and tensor multiplications, which are expressed as \( X \cdot Y \) or simply \( XY \) mathematically. We will then look at several additional common linear algebra routines, such as finding the matrix inverse and eigenvalue decomposition. Performing multiplication between vector, matrix, and higher dimensional tensors, finding matrix inverse, and computing eigenvalue decomposition are common tasks when implementing machine learning models that are typically described using mathematical terms.

## 4.1 Tensor Multiplications

Let us start our discussion with an overview of the tensor multiplication operations. Table 4.1 provides a summary of commonly used tensor multiplication operations implemented by the NumPy, Tensorflow, and PyTorch libraries.
We will then dedicate the following two sections to discussing `matmul` (Section 4.2) and `tensordot` (Section 4.3) operations.

## 4.2 The matmul Operation

The `np.matmul` operations perform general matrix multiplications that are applied over multidimensional batches.

- When the input tensors are 2D matrices of shapes \( (n, k) \) and \( (k, m) \), then it is the conventional matrix multiplication resulting in a matrix of shape \( (n, m) \).

Table 4.1 Examples of tensor multiplication operations in NumPy, Tensorflow, and PyTorch.

| Operation | NumPy | Tensorflow | PyTorch |
|---|---|---|---|
| Dot product<sup>a)</sup> | np.dot | tf.experimental.numpy.dot | torch.dot |
| Complex conjugate dot product<sup>b)</sup> | np.vdot | tf.experimental.numpy.vdot | torch.vdot |
| Inner product<sup>c)</sup> | np.inner | tf.experimental.numpy.inner | torch.inner |
| Outer (cross) product<sup>d)</sup> | np.outer | tf.experimental.numpy.outer | torch.outer |
| Matrix multiplication | np.matmul | tf.matmul | torch.matmul |
| Tensor dot product | np.tensordot | tf.tensordot | torch.tensordot |

Notes:

a) NumPy’s `np.dot` can support dot product between 1D vectors, 2D matrices (which is equivalent to `np.matmul`), or N-D tensor to tensor multiplications. In contrast, `torch.dot` only supports 1D vectors. Tensorflow implements the equivalent operation under the `tf.experimental.numpy` module.

b) `np.vdot` operation applies complex conjugate to the first input before taking the dot product, whereas `np.dot` does not perform complex conjugation. Mathematically, i.e. for two complex vectors $a, b$, $\text{dot}(a, b) = (x_a + i y_a) \cdot (x_b + i y_b)$, where $i$ is the imaginary number. By contrast, $\text{vdot}(a, b) = \bar{a} \cdot b = (\bar{x}_a + i \bar{y}_a) \cdot (x_b + i y_b) = (x_a - i y_a) \cdot (x_b + i y_b)$, where the overline (...) indicates complex conjugates. Note that this definition of dot product between two complex vectors (i.e. `vdot()`) is consistent with MATLAB’s implementation, and perhaps many engineering applications such as Discrete Fourier Transform. However, the mathematical convention for the dot product between two complex vectors uses $(a, b) = \sum_i a_i \bar{b}_i$ instead, where the second argument is complex conjugated. Thus, special attention needs to be paid when translating from mathematics to code when using this function, as the results arising from these two conventions are complex conjugate of each other. When used on multi-dimensional tensors, `np.vdot` will flatten the tensors into 1D vectors before executing the operation. Similar to `torch.dot`, `torch.vdot` only supports 1D vectors for complex conjugate dot products. Tensorflow implements the equivalent operation under the `tf.experimental.numpy` module.

c) `np.inner` operates on a pair of 1D vectors, or at least treating the last dimension of a tensor as 1D vectors. There used to be a function `numpy.core.umath_tests.inner1d` which performs batchwise inner product along rows of a pair of matrices, however, it was deprecated in newer versions of NumPy. Instead, one can use `np.sum(a * b, axis=1)`, or `einsum` operation (which we will introduce in Section 4.4) `np.einsum('ij, ij->i', a, b)`, to achieve the same effect. Note that this einsum operation is not the same as `np.inner` $(a, b)$ as `np.inner` will result in matrix multiplication $a \cdot b^T$ rather than a batchwise operation. We can verify the distinction using the following example:

```
1  a = np.random.rand(5, 8)
2  b = np.random.rand(5, 8)
3  z1 = np.sum(a * b, axis=1) # shape (5, 8)
4  z2 = np.inner(a, b) # shape (5, 5)
5  np.allclose(
6      z2,
7      np.matmul(a, b.T)
8  )
```

d) `np.outer` will flatten any tensors with more than one dimension into vectors before performing the cross product. `torch.outer` only supports 1D vector inputs and will throw an error when receiving multi-dimensional inputs. Tensorflow implements the `outer` operation under the `tf.experimental.numpy` module.

- When the inputs are tensors with >2 dimensions, then the last two dimensions are used as the multiplication dimensions, while other dimensions are treated as batch dimensions and either must be identical or can be broadcasted to each other. For example, if we have tensors of shapes (a, b, n, k) and (1, 1, k, m), then the dimension of the output tensor is (a, b, n, m).

- If the first input is a 1D vector, then it is treated as a row vector with singleton dimensions added before the vector length dimension as (1, ..., 1, n) and follows the broadcasting rules. However, after multiplication, the extra added dimensions are removed. For example, a vector of length (k,) is multiplied with a tensor of shape (a, b, n, k), then the resulting tensor has shape (a, b, n).

- If the second input is a 1D vector, then it is treated as a column vector with singleton dimensions added after the vector length dimensions as (m, 1, ..., 1). However, after multiplication, the extra added dimensions are removed. For example, a tensor of shape (k, a, b, n) is multiplied with a vector of length (k,), then the resulting tensor has shape (a, b, n).

- If both inputs are 1D vectors, then it is equivalent to a dot product.

Unlike NumPy and PyTorch, tf.matmul requires the two inputs to have at least two dimensions, so it will throw an error if any of the inputs are vectors. Additionally, Tensorflow's implementation of tf.matmul allows transpose (is_transpose) and conjugate (is_adjoint, which is the transpose and complex conjugate) preprocessing on the two inputs before performing the matrix multiplication step. Suppose we would like to multiply two matrices of shapes (5, 3) and (5, 3).

```
import tensorflow as tf
a = tf.complex(
    tf.random.uniform((5, 3)),
    tf.random.uniform((5, 3))
)
b = tf.complex(
    tf.random.uniform((5, 3)),
    tf.random.uniform((5, 3))
)
# This will throw an error because of shape mismatch
tf.matmul(a, b)
# This will pass, with shape (5, 5)
tf.matmul(a, b, transpose_b=True)
# This will pass, with shape (3, 3)
tf.matmul(a, b, adjoint_a=True)
```

Furthermore, tf.tensordot can also be used for matrix multiplication, using, for instance, tf.tensordot(a, b, 1) given two matrix inputs.
