
```python
# Hidden layer activation
y = self.hidden_activation(y)

# Decode to produce output
z = self.output_layer(y)
z = self.output_activation(z)

return z

@property
def model(self):
    inputs = {
        "items": Input((None,), sparse=True, dtype=tf.int64),
        "weights": Input(
            (None,), sparse=True, dtype=tf.float32,
        ),
    }
    model = Model(inputs, self.call(inputs))

    return model
```

- **__init__ (Lines 9–25):** This initializes the model class. It saves several model configuration parameters and initializes the activation and output dense layers.

- **build (Lines 27–37):** This method creates the two weights, embedding, which is the embedding lookup table, and bias, which is the bias term added to the dense layer. Note that both weights are trainable (trainable=True). The use of the build method is the preferred way to initialize additional trainable weights in Keras.

- **call (Lines 39–61):** This method implements the main logic of the autoencoder model.

  - Lines 40–44 retrieve the item indices (integer representation of the items) and the corresponding weights. If weights is not available from the inputs dictionary, then we assume the weights are all equal to 1.

  - Lines 47–49 perform the embedding lookup using tf.nn.embedding_lookup_sparse. This produces the hidden layer outputs. Here, we assumed that the inputs we retrieved from the previous steps are left-aligned sparse tensors. Alternatively, if we choose to use dense representations of the item indices with paddings (which necessarily needs to be 1-based indexing since 0 will be used as padding by default), then we can also use keras.layers.Embedding layer and set mask_zero=True upon initialization. This would be how we would implement the embedding lookup in PyTorch as well.

  - Line 52 adds the bias term.

  - Lines 55–59 finish up the implementation of the autoencoder by applying an activation function and passing the results of the hidden layer to an output layer, which will then be activated by another activation function.

- **model property (Lines 63–73):** This property is used to check if our implementation can be compiled as a graph. We can print the model architecture using print(model.model.summary()) which gives us the following:

PyTorch implementation is below

```python
import torch

class Autoencoder(torch.nn.Module):
    def __init__(self, num_items, emb_size):
        super().__init__()
        self.embed = torch.nn.Embedding(
            num_items, emb_size, padding_idx=0
        )
        self.bias = torch.nn.Parameter(torch.zeros([1, emb_size]))
        self.decoder = torch.nn.Sequential(
            torch.nn.ReLU(),
            torch.nn.Linear(emb_size, num_items),
            torch.nn.Sigmoid()
        )

    def forward(self, items, weights=None):
        if weights is None:
            # equal weights
            weights = torch.ones([items.shape[0], 1], dtype=torch.float32)

        # Implement the sparse dense layer (batch_size, emb_size)
        embed = self.embed(items)
        # Apply weights
        embed *= weights[:, :, None]
        # Sum together embeddings
        embed = embed.sum(dim=1)

        # Add bias
        y = embed + self.bias

        # Hidden layer activation
        z = self.decoder(y)

        return z
```

- **__init__ (Lines 4-14):** This method initializes the model class. Unlike the Keras model, we initialize the embedding lookup using torch.nn.Embedding which takes in a dense tensor with 0 paddings (pad_idx=0). The bias term is also specified in this method instead of in a separate method as in Keras. The rest of the layers after the hidden layer are combined together into a single Sequential layer (Keras also has this container layer class, so one can potentially choose to group these layers together as well in the Keras implementation).

- **forward (Lines 16-34):** This method implements the main logic of the autoencoder. Instead of using sparse inputs, this method assumes both items and weights use dense tensors with 0 paddings to represent left-aligned jagged tensors. In Lines 22-26, we first pass the list of items through the embedding lookup, then apply the weights along the first two dimensions (batch and sequence), and finally pool the sequence dimension with summation.
