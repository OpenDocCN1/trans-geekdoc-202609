# Table 2.3 List of common mathematical operations in Python, NumPy, Tensorflow, and PyTorch.

| Math Operation | Python | NumPy | Tensorflow | PyTorch |
|---|---|---|---|---|
| Addition | + | + (np.add) | + (tf.add) | + (torch.add) |
| Subtraction | - | - (np.subtract) | - (tf.subtract) | - (torch.subtract) |
| Multiplication | * | * (np.multiply) | * (tf.multiply) | * (torch.multiply) |
| Division | / | / (np.divide)^a | / (tf.divide) | / (torch.divide) |
| Safe division | N/A | np.divide^a | tf.math.divide_no_nan | N/A^b) |
| Integer division | // | np.floor_divide | tf.math.floordiv | torch.floor_divide |
| Reciprocal | N/A | np.reciprocal | tf.math.reciprocal | torch.reciprocal |
| Safe reciprocal | N/A | np.reciprocal^c) | tf.math.reciprocal_no_nan | N/A^b) |
| Remainder | % (math.remainder) | % (np.remainder, np.mod) | tf.math.floormod | torch.remainder |
| Power | ** (math.pow) | np.power | tf.math.pow | torch.pow |
| Exponential | math.exp | np.exp | tf.exp | torch.exp |
| exp(x) - 1^1 | math.expm1 | np.expm1 | tf.math.expm1 | torch.expm1 |
| log base e | math.log | np.log | tf.math.log | torch.log |
| log base 2 | math.log2 | np.log2 | N/A^b) | torch.log2 |
| log base 10 | math.log10 | np.log10 | N/A^b) | torch.log10 |
| log(1 + x)^b) | math.log1p | np.log1p | tf.math.log1p | torch.log1p |
| log(exp(x_1) + exp(x_2))^b) | math.logaddexp | np.logaddexp | tf.experimental.numpy.logaddexp | torch.logaddexp |
| log(sum(exp(x)))!) | N/A | scipy.special.logsumexp | tf.math.reduce_logsumexp | torch.logsumexp |

Notes:
a) NumPy does not implement a safe divide operation, but one can use np.divide(a, b, out=np.zeros_like(b), where=b!=0) to achieve the same effect as tf.divide_no_nan
b) PyTorch does not implement the safe divide operation, but one can use torch.nan_to_num to fill the NaNs or infs in the quotient to zeros. NumPy also has a similar function np.nan_to_num.
c) Like the np.divide method, NumPy does not implement the safe reciprocal operation, but one can use np.reciprocal(x, out=np.zeros_like(x), where=x!=0) to achieve the same effect.
