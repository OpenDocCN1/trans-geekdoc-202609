Gaussian error linear unit (GELU) [Hendrycks and Gimpel, 2016], Mish [Misra, 2020], sigmoid linear unit (SiLU) [Hendrycks and Gimpel, 2016], and Swish [Ramachandran et al., 2017]. Their mathematical formulations are as follows:

ReLU(x) = max (x, 0)

ELU(x) = \left\{ \begin{array}{ll} \alpha \exp(x) - 1 & \text{if } x \le 0 \\ x & \text{if } x > 0 \end{array} \right.

GELU(x) = x \cdot \frac{1}{2} \left[ 1 + \text{erf}(x/\sqrt{2}) \right]

Mish(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\log(\exp(x) + 1))

SiLU(x) = x\sigma(x)

Swish_\beta(x) = x\sigma(\beta x)

Notice that Swish_{\beta=1}(x) \equiv \text{SiLU}(x).

The following code block implements these activation functions. Figure 11.9 illustrates several variants of activation functions.

```
import math
import torch
import torch.nn.functional as F

def relu(x):
    return torch.clamp(x, 0)

def elu(x, alpha=1.0):
    return torch.where(x > 0, x, alpha * torch.exp(x) - 1)

def gelu(x):
    return x * 0.5 * (1 + torch.erf(x / math.sqr(2.0)))

def mish(x):
    return x * torch.tanh(F.softplus(x))

def swish(x, beta=1):
    return x * torch.sigmoid(beta * x)
```

Others have attempted to reformulate the linear layer completely to unlock more learning power. Specifically, linear gated units (GLUs) pass the input through two learnable dense layers and activate one with a nonlinear activation function, then multiply together with the other linear unit to generate the activated output. GLU is formulated as the following:

GLU(x, W, V, b, c) = \sigma(xW + b) \otimes (xV + c)
