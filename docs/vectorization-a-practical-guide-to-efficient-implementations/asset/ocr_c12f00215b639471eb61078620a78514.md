# 7.1.8 Comparisons Between Different Sparse Matrix Formats

Table 7.1 summarizes the ways to construct and update the seven sparse matrices. In addition to constructing from dense matrices with 0s being treated as the empty entries, there are more efficient ways to construct these matrices by directly specifying the indices and the corresponding data values (as well as other needed properties) with respect to each data structure. For example, to construct a coo_matrix, one can directly specify the row, col, data, and shape of the sparse matrix, i.e. coo_matrix((data, (rows, cols)), [shape=(M, N)]). Moreover, for dok_matrix, lil_matrix, and dia_matrix, I have included some in-place methods to update the matrix, which are not found in scipy’s documentation.

In addition to using .to<format> methods to convert between different sparse matrix formats, we can also leverage the .asformat() method. This can be convenient if we would like to implement a function that does some operation in another format but still would like to retain the original format when returning the result. For example,

```
def function_retaining_sparse_format(A):
    # Convert to csr_matrix
    B = A.tocsr() # this makes a copy
    # Do something on B ...
    # Convert back to the original format
    return B.asformat(A.format)
```
