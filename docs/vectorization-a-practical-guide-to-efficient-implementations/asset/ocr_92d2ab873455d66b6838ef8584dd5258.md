We also assume that each token is represented by one embedding vector, but may correspond to multiple (or at least 1) time-steps in the mel-spectrogram which we know from the dataset labeling process. With these observations and assumptions, the Length Regulator module serves as an adaptor to repeat/tile the token embedding vectors over the period of pronunciation in the mel-spectrogram. See Figure 5.16 for an example.

For a batch of variable-length text inputs, the Length Regulator module will then return a tensor of shape `[batch_size, time_length, num_channels]` and a corresponding binary mask for masking out the paddings later on. We will leverage the knowledge of indexing and scattering to implement the vectorized Length Regulator module.
