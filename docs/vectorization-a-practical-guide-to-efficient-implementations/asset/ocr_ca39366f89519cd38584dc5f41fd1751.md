# Table 2.2 List of data types in Python, NumPy [Harris et al., 2023a], Tensorflow [Abadi et al., 2023b], and PyTorch [Paszke et al., 2023b].

| dtype | Python | NumPy | Tensorflow | PyTorch |
|---|---|---|---|---|
| Boolean | bool | np.bool_ | tf.bool | torch.bool |
| 8-bit int<sup>a,b)</sup> | N/A | np.int8 | tf.int8 | torch.int8 |
| 16-bit int (short)<sup>a)</sup> | N/A | np.int16 (np.short) | tf.int16 | torch.int16 (torch.short) |
| 32-bit int (int)<sup>a,b)</sup> | int | np.int32 (np.intc) | tf.int32 | torch.int32 (torch.int) |
| 64-bit int (long) | N/A | np.int64 (np.int_) | tf.int64 | torch.int64 (torch.long) |
| 8-bit unsigned int<sup>a,b)</sup> | N/A | np.uint8 | tf.uint8 | torch.uint8 |
| 16-bit unsigned int<sup>a,b)</sup> | N/A | np.uint16 (np.ushort) | tf.uint16 | torch.uint16 |
| 32-bit unsigned int | N/A | np.uint32 (np.uintc) | tf.uint32 | N/A |

Notes:
a) Tensorflow implements a quantized version of these integer dtypes, which are used for model size compression.
* tf.int8: tf.qint8
* tf.int16: tf.qint16
* tf.int32: tf.qint32
* tf.uint8: tf.quint8
* tf.int16: tf.quint16
b) PyTorch implements a quantized version of these integer dtypes, which are used for model size compression. It is interesting to note that PyTorch does not implement torch.int8 and torch.quint16 like Tensorflow but implements an additional quantized 4-bit integer type (torch.quint4x2, which is an 8-bit integer)
* torch.int8: torch.qint8
* torch.uint8: torch.quint8
* torch.int16: torch.qint8
* torch.int32: torch.qint32
* _.torch.quint4x2
