# ## 5.2.2 Case Study: Truncate or Pad Sequence to Desired Length

Suppose we have two batches of sequences,X and y.X has shape (batch_size, seq_len_1) and y has shape (batch_size, seq_len_2).We do not know beforehand which sequence is longer, however, we would like to have y with sequence lengths identical to that of X. The following code uses the idea of padding and slicing to align the lengths of X and y.

```
import numpy as np
def align_lengths(X, y):
    """Align y to the length (axis=1) of X."""
    # Get the desired length
    X_len = X.shape[1]
    # Compute pad_size.
    # No padding (pad_size=0) if y length is enough
    pad_size = max(X_len - y.shape[1], 0)
    # Pad if not enough
    y = np.pad(y, [(0, 0), (0, pad_size)])
    # Truncate if y is too long
    y = y[:, :X_len]
    return y
```

+   - Line 5 gets the desired length that we would like y to have.
+   - Line 8 computes the desired padding size. If X is longer, then we need to pad the difference between X and y; but if X is shorter, we should not pad (pad_size=0).
+   - Line 10 does the padding based on the pad_size we calculated. This will handle cases where y is shorter than X but has no effect when y is the same length or longer than X.
+   - Line 12 truncates any extra elements in y. If y is indeed longer than X, then after truncation, y should be the same size as X. If y is the same length as X or is shorter than X, padding from the previous step will first bring y to the same length as X. Then slicing up to the length X will have no effect.

We can quickly test out our implementation:

```
X1 = np.random.rand(16, 50)
X2 = np.random.rand(16, 30)
y = np.random.rand(16, 37)
y1 = align_lengths(X1, y)
assert np.allclose(X1.shape, y1.shape)
print(y1.shape)
```
