
| Operation | NumPy | TensorFlow | PyTorch |
|---|---|---|---|
| QR decomposition$^{(e)}$ | np.linalg.qr | tf.linalg.qr | torch.linalg.qr |
| Linear least squares$^{(f)}$ | np.linalg.lstsq | tf.linalg.lstsq | torch.linalg.lstsq |

- e) QR decomposition is defined as \(X = QR\), where \(X \in \mathbb{R}^{m \times n}\), \(Q \in \mathbb{R}^{m \times n}\) is a matrix whose columns are orthonormal to each other (unit vectors, whose dot products between the columns are zeros), and \(R \in \mathbb{R}^{n \times n}\) is a upper triangular matrix. The `.linalg.qr` method returns Q and R and can recover the original matrix by \(Q @ R\). Like all other linear algebra routines, `.linalg.qr` operates on the last two axes of the input tensor.

- f) `.linalg.lstsq` solves the least squares problem for linear equations in the form \(X\Theta = Y\), where \(X \in \mathbb{R}^{m \times k}\) is the feature vectors (the independent variable) that contains k features with m observations, \(\Theta \in \mathbb{R}^{k \times n}\) is the slope term of the linear equation, and \(Y \in \mathbb{R}^{m \times n}\) is the observation outcome (the dependent variable), for n dimensions. It minimizes the square loss between the left- and right-hand side of the equation, i.e. \(||X\Theta - Y||_2^2 = \sum_i \sum^m (x_i \cdot \theta_j - y_j)^2\). As an example, suppose we would want to estimate the linear equation \(y = 2x + 5\) from a set of data points with random noise:

```python
import numpy as np
x = np.random.randn(100)
Y = 2 * x + 5 + np.random.randn(100)
# Two features, one feature for the input data x,
# and another feature as constant, independent of the data.
X = np.vstack([x, np.ones_like(x)]).T
theta, res, rank, s = np.linalg.lstsq(X, Y)
print(theta)
# array([ 2.04210113, 5.07653151])
```

```python
import numpy as np
def fit_exp_with_offset(x, y):
    """
    Fitting y = a * exp(b * x) + c
    using a non-iterative method based on
    Regressions et Equations Integrales by Jean Jacquelin
    x and y are vectors of coordinates of the data points.
    They need to be sorted in ascending order,
    e.g. (0, 0), (0, 1), ... (1, 0), .... (3, 4), (3, 5), ...
    """
    # Start algorithm
    S = np.zeros_like(x)
    S[1:] = 0.5 * (y[:-1] + y[1:]) * np.diff(x)
    S = np.cumsum(S)
    # for k in range(1, len(S)):
    #     S[k] = S[k-1] + 1/2 * (y[k] + y[k-1]) * (x[k] -
    #      x[k-1])
    M = np.empty((2, 2))
    N = np.empty((2, 1))
    # Getting b
    M[0, 0] = np.sum((x - x[0])**2)
    M[0, 1] = np.sum((x - x[0]) * S)
    M[1, 0] = M[0, 1]
    M[1, 1] = np.sum(S**2)

    N[0, 0] = np.sum((y - y[0]) * (x - x[0]))
    N[1, 0] = np.sum((y - y[0]) * S)

    B = np.matmul(np.linalg.inv(M), N)
    b = B[1, 0]

    # Getting a and c
    theta = np.exp(b * x)
    M[0, 0] = len(x)
    M[0, 1] = np.sum(theta)
    M[1, 0] = M[0, 1]
    M[1, 1] = np.sum(theta**2)

    N[0, 0] = np.sum(y)
    N[1, 0] = np.sum(y * theta)

    AC = np.matmul(np.linalg.inv(M), N)
    c = AC[0, 0]
    a = AC[1, 0]

    return a, b, c
```

- Lines 13–15 build the vector S, following the formula described by Equation 4.1 but with vectorization. This is equivalent to the for-loop method that I commented below, in Lines 16 and 17.
- Lines 19 and 20 initialize two empty matrices to store the intermediate matrices used to find the three parameters.
- Lines 23–26 implements the M term in Equation 4.2.
- Lines 28 and 29 implements the N term in Equation 4.2.
- Line 31 implements the multiplication of the two terms in Equation 4.2.
- Line 32 extracts b as the second element of the column vector produced by the above matrix multiplication step.
- Line 35 computes the intermediate variable θ.
- Lines 36–39 implements the M term in Equation 4.3.
- Lines 41–42 implements the N term in Equation 4.3.
- Line 44 implements the multiplication of the two terms in Equation 4.3.
- Lines 45 and 46 extract a and c from the column vector produced by the above matrix multiplication step.
- Line 48 returns the three parameters a, b, c.

## 5 Masking and Padding

Our discussions on vectorized operations have thus far assumed that we are dealing with data that can be consistently represented by a multidimensional dense tensor given a certain shape. For example, a stack of images can be represented by a dense tensor of shape `(batch_size, width, height, channel)`. Tabular data that contains several numerical columns can be represented as a matrix of shape `(batch_size, num_columns)`. However, in various real-world machine learning applications, we also frequently need to deal with data that comes in varying sizes. For example, a collection of audio recordings may have variable durations. So to make our operations vectorizable across our collection of data, we need to seek ways to reconfigure our data so that it can be represented by a tensor with a single consistent shape. This can be achieved by **padding** the sequences of audio recordings to the same predefined length. On the other hand, the audio recording may have silent periods, which we do not want the model to pay attention to during the learning process. We can therefore use **masking** to tell the model to concentrate the learning on the parts that contain audio we would like to model. Therefore, masking and padding are important techniques to vectorize our machine learning modeling operations when dealing with variable-sized data.

### 5.1 Masking

**Masking** is a data filtering technique that allows the model to focus on relevant parts of the data that we determined heuristically while allowing our vectorization functions to operate on tensors with a consistent data shape. We will first look at several special types of masks implemented by our vectorization libraries. Then, we will look at four techniques to perform the masking operation.
