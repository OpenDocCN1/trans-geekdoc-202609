## 11.3 Layer Normalization

Normalization can help stabilize neural network training by reducing the likelihood of exploding or vanishing gradients and improving model generalization. Different normalization schemes have been explored previously, though most attempted to standardize the inputs or outputs of the network layer such that the mean of the values are centered around 0 and the variance becomes 1.

> \(\tilde{x}_i = \frac{x_i - E[x_j]}{\sqrt{\text{Var}[x_j] + \epsilon}} \gamma + \beta\) (11.1)

where \(\gamma\) and \(\beta\) are learnable parameters for each dimension to be normalized; \(\gamma\) can be considered as the learned standard deviation, while \(\beta\) can be considered as the learned mean. \(\epsilon\) is a smoothing value that prevents division by zero. Depending on which dimensions are normalized, the normalization schemes were given different names. Specifically, given an input tensor of shape `(batch_size, sequence_length, num_channels)`,

- **Batch normalization**: Standardizes each feature/channel/embedding value across the batches. Hence, \(\gamma\) and \(\beta\) are vectors of shape `(num_channels, )`.
- **Layer normalization**: Standardizes within the batch. It has two formulations: the input tensor is normalized either across both sequence and channel dimensions (Variant 1, see Figure 11.3b) or across only the channel dimensions within each sequence (Variant 2, see Figure 11.3c). Different from batch normalization which applies a scalar value for each channel, layer normalization uses an element-wise affine transformation (i.e. scale and shifting). Hence, \(\beta\) and \(\gamma\) are tensors of shape identical to the plane that the normalization is computed over.

![](img/e891acaacd4fb5b80dab2ed824618203_404_0.png)

**Figure 11.3** Comparison of normalization scheme. (a) Batch normalization normalizes across the batch within each channel/feature dimension, (b) layer normalization normalizes the channel by sequence within each batch, (c) an alternate formulation of layer normalization is to normalize within the batch and sequence across only the channels; this is the default behavior for the implementation of LayerNormalization in Keras and it is a popular usage pattern of layer normalization. This is also the normalization scheme for RMSNorm, (d) group normalization is similar to layer normalization, but further separates channel dimensions into groups and normalizing within the group, (e) instance normalization normalizes within each batch by channel instance, e.g. each sequence.

In the first variant of layer normalization, \(\beta\) and \(\gamma\) are matrices of shape (`seq_len`, `num_channels`); in the second variant, \(\beta\) and \(\gamma\) are vectors of shape (`num_channels`, ).

- Group normalization: Divides the channel dimension into groups, and normalizes within the group. In this normalization scheme, \(\gamma\) and \(\beta\) are learned for each group of the channel.
- Instance normalization: Normalizes within each channel/feature. This can be seen as a special case of Group Normalization where the group size is 1.

Figure 11.3 illustrates the differences between various normalization schemes (which are inspired by Figure 2 of “Group Normalization” white paper from Facebook AI Research [Wu and He, 2018]).

RMSNorm, or root-mean-square normalization [Zhang and Sennrich, 2019], modifies the formulation in Equation 11.1; it no longer computes the mean, but only aims to normalize the variance of the inputs. The normalization formulation for RMSNorm is then

$$\tilde{x}_i = \frac{x_i}{\sqrt{\frac{1}{n}\sum_j x_j^2 + \epsilon}} \gamma$$ (11.2)

Let us implement both layer normalization and RMS normalization for comparison

```
import torch
from torch import nn

class LayerNorm(nn.Module):
    def __init__(self, nchannels, epsilon=1e-5):
        super().__init__()
        self.epsilon = epsilon
        self.gamma = nn.Parameter(torch.ones(nchannels), requires_grad=True)
        self.beta = nn.Parameter(torch.zeros(nchannels), requires_grad=True)

    def forward(self, x):
        num = x - x.mean(dim=-1, keepdims=True)
        denom = torch.var(x, dim=-1, keepdims=True)
        denom = torch.sqrt(denom + self.epsilon)
        return num / denom * self.gamma + self.beta

class RMSNorm(nn.Module):
    def __init__(self, nchannels, epsilon=1e-5):
        super().__init__()
        self.epsilon = epsilon
        self.gamma = nn.Parameter(torch.ones(nchannels), requires_grad=True)

    def forward(self, x):
        denom = (x ** 2).mean(dim=-1, keepdims=True)
        denom = torch.sqrt(denom + self.epsilon)
        return x / denom * self.gamma
```

- LayerNorm (Lines 5–16):
  - `__init__` (Lines 6–10): Initializes the layer. Here, we initialize two learnable parameters, gamma and beta, with a size equal to the number of channels for element-wise scaling and shifting.
  - `forward` (Lines 12–16): Implements the standardization formulation as described in Equation 11.1. Note that in the current implementation, we normalize over the last dimension, which is the channel/embedding dimension of the input.

- RMSNorm (Lines 19–28):
  - `__init__` (Lines 20–23): Initializes the layer. In contrast to LayerNorm, we only initialize the scaling parameter gamma.
  - `forward` (Lines 25–28): Implements the root-mean-square normalization formulation in Equation 11.2. Similar to the above LayerNorm implementation, we also normalize over the channel/embedding dimension of the input.

### 11.4.1 Sinusoidal Positional Encoding

In the original transformer paper [Vaswani et al., 2017], the authors used position encodings added on top of the input embedding vectors of each word token to allow the attention model to disambiguate words from different positions along the sequence. Specifically, given a sequence of word tokens, the transformer model looks up the corresponding embeddings of each vector and then forms a tensor of shape (`batch_size`, `seq_len`, `emb_size`). Then, for each sequence position by embedding position, an encoding value is added based on the formulation:
