and should have a high similarity score; otherwise, the movies are different and should have a low similarity score. Jaccard Similarity is defined as

Sim_{Jaccard}(X, Y) = \frac{|X \cap Y|}{|X \cup Y|} = \frac{|X \cap Y|}{|X| + |Y| - |X \cap Y|}
(8.1)

where |·| represents the cardinality of the set. In the context of evaluating the performance of object detection algorithms, the Jaccard Similarity metric is also known as the Intersection-Over-Union (IOU) metric. In IOU, X and Y are coordinates of the pixels within the bounding boxes drawn around the object, either by the algorithm prediction or by the label. Jaccard Similarity metric can also be used to search for similar items. In the case where we have a library of movies and each movie's metadata (e.g. tags and genres), we can compute the Jaccard Similarity score between each pair of movies, store the results in a matrix, and then look up the scores to rank the contents whenever a user searches for similar contents to a given title. To build such a matrix, we need to use the knowledge we have gained from Chapter 6 on encoding string values to index representations, and from the previous case study on converting index representations to binary indicator representations. The following code block implements the pairwise computation of Jaccard Similarity given a sparse binary representation of the item attributes, where we assume each item is a row of the sparse matrix, and each value along the column is an attribute of the content.

```
import numpy as np

def jaccard_similarities(mat):
    """
    Compute pairwise Jaccard similarities
    between rows of a coo sparse matrix
    """
    nnz = mat.getnnz(axis=1)
    # pair-wise binary intersection |X n Y|
    # sparse matrix multiplication
    sim = mat * mat.T
    sim = sim.astype(float)

    # for rows
    xx = np.repeat(nnz, sim.getnnz(axis=1))
    # for columns
    yy = nnz[sim.indices]

    # |X U Y| = |X| + |Y| - |X n Y|
    sim.data /= xx + yy - sim.data

    return sim
```
