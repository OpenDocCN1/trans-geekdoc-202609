Notes:
a) The symbols ~, &, |, and ^ represent bit-wise operations, "NOT," "AND," "OR," and "XOR," respectively. When using these symbols with pure Python's boolean variables or NumPy's boolean arrays, the effect is the same as the function operations. However, if we are applying it on integers or floats, e.g. `np.array(1) & np.array(2)` = 0 is not the same as `np.logical_and(1, 2)` = True.

Notes:

c) Suppose we have a vector x = [1, 3, 6, 7]. Then, the adjacent difference of the vector yk = xk - xk-1, ∀k = 2, 3, ..., n results y = [3 - 1, 6 - 3, 7 - 6] = [2, 3, 1]. This is equivalent of doing `x[1:] - x[:-1]`. Notice that the resulting array y has a length of 1 less than the length of x.
