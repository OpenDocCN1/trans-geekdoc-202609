For 1D tensors, tf.gather(X, index) and torch.gather(X, dim=0, index=index) are equivalent to np.take(X, index). In this case, setting axis=None or axis=0 has the same effect. For Tensorflow, axis=None pairing with batch_dims=0 (both are the default) would result axis=0, where the elements are taken along the first (and the only) dimension of the 1D vector. PyTorch requires the user to specifically set dim=0 (setting dim=None would throw an error). For NumPy, setting axis=None signals the function to flatten the 1D vector, which results in itself. Then, the values are taken along the same vector.

```python
import numpy as np
import tensorflow as tf
import torch
X = np.arange(10)
index = [3, 5]
y_np = np.take(X, index)
y_tf = tf.gather(X, index)
y_torch = torch.gather(
    torch.tensor(X), 0, torch.tensor(index)
)
# all returns [3, 5]
```

For multi-dimensional tensors, tf.gather(X, index) is equivalent to np.take(X, index, axis=0). Again, when batch_dims=0 by default, axis is set to 0 (axis=0), thus tf.gather(X, index) is equivalent to tf.gather(X, index, axis=0). For PyTorch's torch.gather, to return the entire slice, it is necessary to repeat the indices across the batching dimensions (thus in this case, it is recommended to use slicing directly):

```python
import numpy as np
import tensorflow as tf
import torch
X = np.arange(20).reshape(4, 5)
index = np.array([[1, 3]])
y_np = np.take(X, index, axis=1)
y_tf = tf.gather(X, index, axis=1)
y_torch = torch.gather(
    torch.tensor(X),
    0,
    torch.tensor(np.repeat([index], X.shape[1], axis=0).T)
)
# all returns:
# [[ 5, 6, 7, 8, 9],
# [15, 16, 17, 18, 19]]
# In contrast, if we do not repeat the index
y_torch_index = torch.gather(
    torch.tensor(X), 0, torch.tensor(index[:, None]))
# tensor([[ 5],
#   [15]])
```

When specifying an integer value to the `axis` argument, `tf.gather(X, index, axis=...)` is equivalent to `np.take(X, index, axis=...)`. `index` can also be multi-dimensional and will be handled the same way as `np.take`:

```python
import numpy as np
import tensorflow as tf
X = np.arange(30).reshape(3, 5, 2)
slice_index = [[0, 3], [1, 1]]
block_np = np.take(X, slice_index, axis=1)
block_tf = tf.gather(X, slice_index, axis=1)
assert np.allclose(
    block_np, block_tf
)
```

tf.gather can also be used like `np.take_along_axis` (as well as `torch.take_along_dims`) to vectorize the gathering of elements over batches by specifying `batch_dims` to a value greater than 0. The difference though is that `tf.gather` only allows batching at the initial dimensions whereas `np.take_along_axis` allows the batch dimensions at arbitrary dimensions. For instance,

```python
import numpy as np
import tensorflow as tf
import torch
X = np.random.randint(0, 10, size=(4, 3, 5))
reorder_index = np.random.randint(0, 5, size=(4, 3, 5))
y_np = np.take_along_axis(X, reorder_index, axis=2)
y_torch = torch.take_along_dim(
    torch.tensor(X), torch.tensor(reorder_index), axis=2
)
y_tf = tf.gather(X, reorder_index, axis=2, batch_dims=2)
```

When it comes to broadcasting, `tf.gather` will broadcast any dimensions not covered by the leading `batch_dims` batch dimensions and the `axis` dimension (hence, treating the rest of the dimensions as slices rather than single elements), while `np.take_along_axis` would require us to add additional singleton dimensions to signal broadcasting, i.e.

```python
import numpy as np
import tensorflow as tf
import torch
X = np.random.randint(0, 10, size=(4, 3, 5, 6))
# 3rd dimension as the broadcasting dimension
reorder_index = np.random.randint(0, 5, size=(4, 3, 1, 7))
# Returns a tensor of shape (4, 3, 5, 7)
y_np = np.take_along_axis(
    X, reorder_index, axis=3
)
y_torch = torch.take_along_dim(
    torch.tensor(X),
    torch.tensor(reorder_index),
    axis=3
)
y_tf = tf.gather(
    # taking out the singleton dimension
    X, reorder_index[..., 0, :], axis=3, batch_dims=2
)
```

A heuristic on the expected output shape of `tf.gather` can therefore be derived (and also based on [Abadi et al., 2023a]) and implemented as

```python
np.concatenate([
    inputs.shape[:axis],
    index.shape[batch_dims:],
    inputs.shape[axis+1:]
]).astype(int)
```

## 3.4.4 N-Dimensional Gather

Both NumPy and PyTorch use arrays of multi-indices to select multiple elements/slices. Tensorflow implements a special operation, `tf.gather_nd` to achieve the same purpose. The `tf.gather_nd` operation uses multi-index to gather elements from multiple index dimensions instead of using flat index to gather from a single dimension like the `tf.gather` operation. As a simple example,

```python
import numpy as np
import tensorflow as tf
import torch
X = np.array([
    [1, 3, 2, 4],
    [6, 8, 7, 9],
])
# 2D indices
index = np.array([
    [0, 1],
    [0, 3],
    [1, 0],
    [1, 2],
])
# gather_nd
y_tf = tf.gather_nd(X, index)
# For numpy and torch, use indexing
y_np = X[index.T[0], index.T[1]]
y_torch = torch.tensor(X)[index.T[0], index.T[1]]
# array([3, 4, 6, 7])
```

See Figure 3.11 for an illustration.
`tf.gather_nd` operation is unique to Tensorflow since Tensorflow only
allows scalars and slices for indexing, and directly using an array of multi-indices
to select multiple elements will throw an error:

```python
import tensorflow as tf
X = tf.constant([
    [1, 3, 2, 4],
    [6, 8, 7, 9],
])
# 2D indices
index = tf.constant([
    [0, 1],
    [0, 3],
    [1, 0],
    [1, 2],
])
# This throws an error
X[index[:, 0], index[:, 1]]
```

will get the following error:

```
TypeError: Only integers, slices (`:`), ellipsis (`...`),
`tf.newaxis` (`None`) and scalar `tf.int32`/`tf.int64` tensors
are valid indices, got `<tf.Tensor: shape=(4,),
dtype=int32, numpy=array([0, 0, 1, 1], dtype=int32)>`
```

tf.gather_nd support slice gathering using multi-index. For instance,

```python
import tensorflow as tf
X = tf.random.uniform((4, 5, 6))
# Multi-indexing the first 2 dimensions,
# using last dimension as the slice/block dimension
index = tf.constant([
    [0, 3],
    [1, 2],
    [3, 0],
    [2, 2],
]) # (4, 2)

# Gather 4 slices from the 3D tensor
y = tf.gather_nd(X, index) # (4, 6)
```

index.shape[1] number of leading dimensions in X is extracted using the multi-index, and the remaining lagging dimensions are left as the slice dimensions. If index.shape[1] == X.ndim, then 1D vectors are created by extracting single elements from the input X. Otherwise, a (X.ndim - index.shape[1] + 1)-dimensional tensor is created.

tf.gather_nd can also be used to gather slices arranged over a multi-dimensional batch.

```python
import tensorflow as tf
X = tf.random.uniform((2, 3, 5, 4))
index = tf.experimental.numpy.random.randint(
    0, 4, (2, 3, 4, 2)
)

batch_dims = 2
y = tf.gather_nd(X, index, batch_dims=batch_dims)
```

In this example, we treat the first two dimensions of the index and X as the batch dimensions. Then, for each location within the batch, we take 4 of 2D points from each 5 x 4 matrix. See Figure 3.12 for an illustration.

Tensorflow's documentation on tf.gather_nd [Abadi et al., 2023b] provides even more examples. Readers are encouraged to study these examples carefully to understand the operation even further.

tf.gather_nd (as well as similar operations in NumPy and PyTorch) that gathers elements at indices rather than entire slices in a batch are quite useful for extracting heterogeneous regions of interests (ROIs) from high-dimensional data, such as medical imaging (e.g. fMRI brain structures) or video data (e.g. for moving objects), where sequences of 2D or 3D images are organized over time.
