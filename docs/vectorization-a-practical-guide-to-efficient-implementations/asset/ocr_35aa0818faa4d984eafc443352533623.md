# 3 Tensor Indexing

An **index** is a reference that points to the location of the value in an arrangement of an _N_-dimensional tensor. **Indexing** is the operation to select or manipulate an element or a group of elements within a tensor using such a reference system. In this chapter, we will introduce various ways of indexing. We will also illustrate how indexing can be used to manipulate elements in a tensor through several case studies.

# 3.1 Get Values at Index

# 3.1.1 Integer Indexing

In Python, elements of a list (e.g. 1) at a specific index can be accessed by the syntax l [index], where index is an integer starting from 0 (i.e. 1st index). For example, let l = [2, 3, 5, 7, 11] be a list of integers. Then, the third item (index=2) can be retrieved by l [2], returning 5. Here, the variable index can also be negative numbers, which access the element starting from the end of the list. For example, l [-1] accesses the last element in the list and l [-2] accesses the second to last element. In general, given a list of length N and a negative integer index, then l [index] = l [N+index]. See Figure 3.1 for an illustration. 1D arrays in NumPy (np.ndarray, Tensorflow (tf.Tensor), and PyTorch (torch.Tensor) all follow such indexing conventions as well.

For 2D matrices, the indices of the elements are represented by a pair (tuple) of integers, in the format of (row, column). As illustrated in Figure 3.2, the value 7 resides in the second row and fourth columns of the 3 × 4 matrix and can be referenced by the index (1, 3). It is worthwhile to point out that this convention is different from the Cartesian coordinates (x, y), where x is the horizontal position, and y is the vertical position. To reference the same value 7 in this matrix, we would instead use (3, 1) using the Cartesian coordinate system. (We may also treat (x, y) as the (column, row) convention.)
