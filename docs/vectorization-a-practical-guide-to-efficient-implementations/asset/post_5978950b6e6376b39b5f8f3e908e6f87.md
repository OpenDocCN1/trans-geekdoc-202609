We can imagine that we are sorting from [321, 312, 132] to [132, 312, 321]. However, combining the columns into a single integer number only works for integer cases, it proved to be more difficult if we are sorting integers with an arbitrary number of digits. Still, sorting the whole row as a single representation will not help us generalize to float and string data types. While np.sort can only sort along a single dimension, we can use np.lexsort to sort based on multiple columns. The following code is an implementation of sorting rows using NumPy’s np.lexsort.

```
import numpy as np

def sort_rows_lex(A, col=None):
    """Return sorted A, and index, such that A_old[index] = A_new"""
    if col is None:
        col = np.s_[::-1] # build a whole slice
    else:
        col = col[::-1]
    # Sort by columns.
    # lexsort by last columns first, and first columns last
    index = np.lexsort(A[:, col].T)
    # Apply the resulting sorting
    A_sorted = A[index, :]
    return A_sorted, index
```

- Lines 5–8 parse the `col` argument. If it is `None`, then we build the whole slice `np.s_[:]` object; otherwise, we will select the columns based on the array of indices provided by `col`. Here, we also reversed the `col` with `[::-1]`, because `np.lexsort` will sort based on the last columns first and the first columns last. To keep our function intuitive, we reverse the indices in this preprocessing step, such that the user of the function can still provide the order of columns to be sorted in ascending order (e.g. `col=[1, 3, 2]` to tell the function to sort column 1 first, then column 3, then column 2, and ignore column 0.)
- Line 11 performs the lexsort. We slice the input `A` based on the columns we want to sort on. We then transpose the matrix since `np.lexsort` operates by a list/tuple of columns. This returns the sorted index.
- Line 13 applies the sorted index to the original input `A` using slicing syntax.

We can see that the first row of U came from row 0 of A; the second row of U came from row 2 of A; the third row of U came from row 3 of A, and so on. Hence we have a mapping between the rows in A and U (which is the `row_index` on the left and the `unique index` on the right of the unique matrix U at corresponding rows). As we also specified `return_inverse=True`, `np.unique` returns a set of reverse indices to indicate from which indices in U can recover the original matrix A. This is illustrated as the `unique index` on the right side of the original matrix A. For examples, we can use row 0 from the unique matrix U as the first row of the original matrix A; we can use row 5 from U as the second row of A; we can use row 1 from U as the third row of A, and so on. The ordinal value of the `unique index` indicates the lexicological order of the rows. So if we would like to sort the original matrix A according to the lexicological ordering, then we should sort the rows according to the ordinal values of the reverse indices. In other words, we would like to place the rows in the order of the `unique index`. As shown in the `A_sorted` matrix, rows from the original matrix are sorted according to the ordinal values of the `unique index`.

An alternative solution is to use np.unique which can detect unique rows of a matrix. It can also return the indices from the unique set of rows to reconstruct the original matrix, by specifying return_inverse=True. This is implemented below

```
import numpy as np

def sort_rows_unique(A, col=None):
    """Return sorted A, and index, such that A_old[index] = A_new"""
    if col is None:
        col = np.s_[:] # build a whole slice
    # Sort each row
    _, index = np.unique(A[:, col], axis=0, return_inverse=True)
    # Apply the resulting sorting
    A_sorted = A[np.argsort(index), :]
    return A_sorted, index
```

- Lines 5–6 create the whole slice object if col is None, indicating that we are sorting based on all columns.
- Line 8 uses np.unique to find the reverse index which can be used to reconstruct the original inputs using the unique set (returned as _ in this particular example). The unique set is already lexicologically sorted by columns 0, 1, 2, ..., etc.
- Line 10: np.argsort on the reverse index creates the correct index to be applied to the original input to create the lexicologically sorted unique set, but without dropping the duplicated entries. See Figure 10.3 for an illustration of how this works.
