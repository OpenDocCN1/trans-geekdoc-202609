f) Sum All vs. Identity (an operation that gives output identical to input, not to be confused with a mathematical identity matrix). "Sum All" can only be expressed using the explicit mode, whereas "Identity" has an explicit mode "ij->ij" as well as the implicit mode "ij". This is because when there is no value to the right of the arrow, the equation is always interpreted as summing into a constant; by contrast, when there is no right arrow (i.e. in implicit mode), summation only happens when indices are repeated.

```
```python
X = np.random.rand(4, 5)
# Identity function
np.allclose(
    X,
    np.einsum("ij->ij", X)
)
np.allclose(
    X,
    np.einsum("ij", X)
)
# Sum all elements
np.allclose(
    X.sum(),
    np.einsum("ij->", X)
)
```
