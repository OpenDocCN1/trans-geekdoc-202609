This corpus has about 2.3 million tokens in the training set. Though it is several magnitudes smaller than the 1 billion+ tokens used to train a full-sized LLaMA [Touvron et al., 2023a], it is sufficient for our purpose of illustrating the concepts. We will also use BERTTokenizer to map the string values of each token from this text corpus to integer values. The data preparation steps are implemented as below:

import torchtext
from torchtext.transforms import BERTTokenizer
from tqdm import tqdm

def sample_sentence(element, max_context_size=64):
    """Take a sentence, and subset the tokens into input and next word."""
    l = len(element)
    start = np.random.randint(0, 1-3)
    end = np.random.randint(start, 1-1)
    if end - start > max_context_size:
        start = end - max_context_size
    sentence = element[start:end]
    sentence = np.array(sentence).astype(int).tolist()
    next_word = element[end]
    next_word = int(next_word)
    return sentence, next_word

def collate_fn(elements):
    """Collect data into padded batches."""
    sentence, next_word = zip(*elements)
    sentence = torch.nested.nested_tensor(
        list(sentence)).to_padded_tensor(padding=-1)
    sentence = sentence.long() + 1
    next_word = torch.tensor(next_word) + 1 # index offset by 1
    return sentence, next_word


VOCAB_FILE="https://huggingface.co/bert-base-uncased/resolve/main/vocab.txt"

    vocab_path=VOCAB_FILE, do_lower_case=True, return_tokens=False
)

    ."wikitext2", split="train")
    ).map(tokenizer).filter(lambda x: len(x) > 5).map(sample_sentence)
eval_dataset = torchtext.datasets.WikiText2(
    ."wikitext2", split="valid")
    ).map(tokenizer).filter(lambda x: len(x) > 5).map(sample_sentence)

    train_dataset, batch_size=32, collate_fn=collate_fn

## 11.7 A Word on AI Safety and Alignment

Before we close the chapter, I would like to add some thoughts on AI safety and alignment. The advent of LLMs such as LLaMA and GPT, along with other generative models such as DALL-E and Stable Diffusion, has intensified the debate on AI safety among both academics and practitioners in the industry. These technologies, while groundbreaking, have raised significant concerns. Associated topics of the debate include but are not limited to:

- **Demographic biases:** One of the critical issues is demographic bias, where AI models may exhibit prejudices based on gender, race, or ethnicity. This is often (though not only) a result of training data reflecting existing societal biases. For instance, a language model might generate stereotypical or discriminatory content if it is trained on biased data, leading to concerns about reinforcing negative stereotypes. Perhaps the most infamous example was that in 2015, Google's photo service used AI to mistakenly label a photo of a black person as “gorilla” [BBC News, 2015].

- **Content toxicity:** Another area of concern is content toxicity. AI models can inadvertently generate harmful or offensive content, especially if they are exposed to toxic data during training. This raises questions about the responsibility of AI developers in filtering and moderating training data and the mechanisms needed to prevent the propagation of harmful content. The hate-speech generating GPT-4Chan model, a GPT-3 model trained on toxic comments from the internet forum 4Chan, sparked much controversy in 2022 [Gault, 2022].
