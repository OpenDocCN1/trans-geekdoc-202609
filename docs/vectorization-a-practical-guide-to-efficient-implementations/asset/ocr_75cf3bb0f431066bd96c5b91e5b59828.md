A typical use of multiprocessing is to perform in-memory batch data processing. Suppose we want to compute the min–max normalized score for a bunch of users:

import pandas as pd
df = pd.DataFrame({
    "id": [
        "A", "A", "A", "A", "B", "B", "B", "B", "B",
        "C", "C", "C", "C", "C", "C", "C", "C", "C"
    ],
    "scores": [
        98, 97, 100, 80, 78, 80, 82, 81, 61, 51, 72,
        70, 82, 80, 75, 62, 67, 53
    ]
})

```

We can define the following user-defined function (UDF) to be used to compute each user's normalized score:

```
```python
def apply_func(pdf):
    """Compute the min-max normalized score"""
    min_val = pdf['scores'].min()
    max_val = pdf['scores'].max() + 1e-6
    pdf['scores'] = (pdf['scores'] - min_val) / (max_val - min_val)
    return pdf
