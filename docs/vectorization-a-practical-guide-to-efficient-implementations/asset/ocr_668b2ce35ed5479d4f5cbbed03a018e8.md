When using Keras with Tensorflow, keras.layers.StringLookup, building on top of tf.lookup, offers additional ways to incorporate string to integer indices lookup tables inside a Keras model. It also provides further post-processing to transform the integer indices into common labeling schemes such as one-hot encoding or Term Frequency-Inverse Document Frequency (TF-IDF).

# 6.4.5 TorchText torchtext.vocab

Since PyTorch torch.Tensor does not handle strings and bytes, the library itself does not provide a way to handle the transformation from string values to integer indices and relies on custom preprocessing. TorchText is a library currently in pre-release (at the time of writing, the most recent version is 0.16) that implements text pre-processing utilities for NLP tasks. torchtext.vocab.vocab is the method to convert string values to integer indices based on a lookup table from a predefined dictionary which maps between the string value and the frequency of occurence of the value. It sorts the order of the index based on the frequency, with the lowest frequency as the starting index.

```

# A dictionary that maps between vocabulary and frequency of
~ occurrence
# This creates a->0, b->1, c->2
vocab = {"a":1, "b": 2, "c":10}
# Special tokens to insert at the beginning of the
~ vocabulary
```
