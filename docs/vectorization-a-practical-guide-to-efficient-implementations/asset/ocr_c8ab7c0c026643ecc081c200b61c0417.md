# 6.7 Data Serialization and Deserialization

The current section is not regarding how to manipulate string values in the data, but rather how to turn an entire dataset into a string or byte representation, which we call data "serialization." Within the context of machine learning data management, serialization is the process of converting structured data into a stream of byte strings so it can be further compressed and consumed by any downstream processes. In production machine learning systems that use microservices, data hosting services are separate from the model inference services. Hence, there is a need to transfer data from one service to another service via the network. In cloud environments, model training needs to load data from the cloud disk to the virtual machine instance which has access to costly resources such as GPUs. Therefore, the service needs to be able to load the data from the remote disk quickly, so that the training instance can fully utilize the GPUs for training rather than waiting for data to be downloaded. On the other hand, the process of reversing the serialization process, or turning byte strings back into structured data, is called deserialization.
