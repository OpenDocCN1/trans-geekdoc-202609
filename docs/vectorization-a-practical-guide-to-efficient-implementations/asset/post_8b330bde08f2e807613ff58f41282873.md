## 9.8 Case Study: Filling of Missing Values in a Sequence

Pandas implement a well-known `.fillna` method for its `pandas.DataFrame` and `pandas.Series` classes to fill in missing values represented by NaNs. In addition to filling the missing values with a constant value like 0, it can also do sequence-based filling based on the value either before or after it, corresponding to the `ffill` and `bfill` methods, respectively. In many neural network implementations, we may sometimes need to fill in missing entries such that a set of features all have exactly the same lengths. Consider the following example with a pair of features `event_type` and `event_timestamp`:


Each entry of the event_timestamp feature corresponds to a specific time of occurrence of the event in the event_type feature. Notice, we are missing multiple entries in the event_timestamp feature. One strategy to guess the time of the event occurrence is to look for the nearest timestamp, either before or after the missing value. See Figure 9.15 for the detailed strategy for ffill that we implemented below using Tensorflow, along with the line-by-line explanation of the code below.

```
import tensorflow as tf
def ffill(x):
  """Forward filling the values of a 2D matrix row"""
  # Track indices for all values
  r, c = tf.cast(tf.shape(x), dtype=tf.int64)
  flat_indices = tf.range(r * c)
  indices = tf.stack([
    flat_indices // c,
    flat_indices % c
  ], axis=0)
  indices = tf.transpose(indices)

  # Indices of consecutive integers
  empty_indices = tf.where(x == "")
  f = (empty_indices[1:, 1] - empty_indices[:-1, 1]) == 1
  f = tf.concat(([False], f), 0) != tf.concat((f, [False]), 0)
  f = tf.where(f)
  f = tf.reshape(f, (-1, 2))

  # Compute backtracking offset values
  offset_indices = tf.ragged.range(f[:, 0], f[:, 1] + 1).flat_values
  offset_values = tf.ragged.range(f[:, 1] - f[:, 0] + 1).flat_values
  offset_values = -(offset_values+1)
  offsets = -tf.ones_like(empty_indices[:, 0])
  offsets = tf.tensor_scatter_nd_update(
      offsets, offset_indices[:, None], offset_values
  )
  # Replace the empty indices with offsets
  flat_empty_indices = empty_indices[:, 0] * c + empty_indices[:, 1]
  update_indices = tf.stack(
      [flat_empty_indices, tf.ones_like(flat_empty_indices)], axis=0
  )
  update_indices = tf.transpose(update_indices)
  indices_offset = tf.tensor_scatter_nd_add(
      indices, update_indices, offsets
  )
  # Address any remaining -1s. These are empty values starting at
  # the beginning that cannot be filled. So use original indices,
  # which is index 0
  indices_offset = tf.maximum(indices_offset, 0)
  # Finally, use tf.gather_nd to create the ffilled matrix
  y = tf.gather_nd(x, indices_offset) # flat
  y = tf.reshape(y, (r, c))
  return y
```

- Lines 8–12 create the multi-index of each value of the matrix, in the form of `[[r0, c0], [r1, c1], ...]`.
- Line 15 finds the multi-index where the values are missing/empty. The function can also be generalized to fill integer and float values by looking for corresponding padding values such as NaN.
- Lines 16–19 find the start and end indices (e.g. 2, 3, 4, 5 -> [2, 5]) of the segment of empty entries. Recall we implemented the same logic in a case study in Chapter 3.
