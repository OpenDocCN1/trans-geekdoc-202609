- 2. values: This property stores the flattened values of the original input. Its order corresponds to the order of the indices along the row dimension (axis=0). That is, the number of rows in indices tells us how many valid entries are in the sparse matrix. By looking at the values only, there is no way we can tell the fourth and sixth rows of the original input are empty. In other words, there is no “padding” value to represent the fourth or sixth row. Empty rows can be a challenge in data preprocessing sometimes. We will look at this issue more carefully in Chapter 9 when discussing segment-wise group-by-aggregate operations.

- 3. dense_shape: The shape of the sparse matrix indicates there should be six rows in the matrix, but based on indices, there are only four rows, since the fourth and sixth rows of the matrix are empty. Therefore, it is necessary to look at the dense_shape when determining how many rows there are in the matrix, instead of either counting the distinct number of values from indices[:, 0] or using the maximum of indices[:, 1].

We can observe that the only difference between X_filtered and X_left_aligned is on the second column of the indices property. To emphasize, indices[:, 1] skips certain integer values within each row, while X_filtered recreated indices[:, 1] so that it enumerates the array values within the row using consecutive integers. Recall in Chapter 5 that if we know how many elements there are for each row of the array, then we can use tf.ragged.range to create the enumerating indices. To determine the number of elements for each row, we can first replace the values of the original matrix with 1s using SparseTensor.with_values, and then sum across the row using tf.sparse.reduce_sum. The following is the implementation that left-aligns a sparse tensor:

```python
import tensorflow as tf

def sparse_left_align(X: tf.SparseTensor):
    # Compute row lengths
    row_lengths = X.with_values(tf.ones_like(X.values()))
    row_lengths = tf.sparse.reduce_sum(row_lengths, axis=1)
    row_lengths = tf.cast(row_lengths, tf.int64)
    # Create the flattened array enumeration index
    array_indices = tf.ragged.range(row_lengths, dtype=tf.int64)
    array_indices = array_indices.flat_values
    # Recreate the SparseTensor
    indices = tf.stack([X.indices[:, 0], array_indices])
    indices = tf.transpose(indices)
    y = tf.SparseTensor(
        indices=indices,
        values=X.values,
        dense_shape=X.dense_shape,
    )
    return y
```

- Lines 5–7 compute the lengths of each row. An alternative or perhaps more efficient way to compute the array length of each row is by using tf.unique_with_counts (which is what tft.sparse_tensor_left_align used in the original implementation), which will be introduced in Chapter 10.

- Lines 9 and 10 create the flattened enumeration of the arrays, using consecutive integers starting from 0.

- Lines 12–18 recreate the left-aligned sparse tensor. It replaces the second column of indices with the new array enumeration indices.

Recall that tf.SparseTensor corresponds to Scipy’s coo_matrix format. In the later Case Study: Batchwise Set Operations, we will see another implementation of an algorithm that left-aligns a sparse tensor using Scipy’s csr_matrix.
