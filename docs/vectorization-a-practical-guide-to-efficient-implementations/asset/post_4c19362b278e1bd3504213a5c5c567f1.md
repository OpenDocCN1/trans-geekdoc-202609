To further illustrate the relationship between the flat index and multi-index, we may derive the patterns of converting between these two indexing systems based on the above example. Let a tensor have shape \((n_0, n_1, \dots, n_d, \dots, n_{D-1})\), thus it has \(r = \prod_{i=0}^{D-1} n_i\) elements, where \(D\) is the number of dimensions of the tensor. Then, to convert from flat index \([r_0, r_1, \dots, r_j, \dots]\), we can use the formula:

\(i_d^{(j)} = \left\lfloor \frac{r_j}{\eta_d} \right\rfloor \mod n_d\) (3.1)

where \(n_{d<D-1} = \prod_{i=d+1}^{D-1} n_i, \eta_{D-1} = 1\) when using row-major ("C") ordering, and \(n_{d>0} = \prod_{i=0}^{d-1} n_i, \eta_0 = 1\) when using column-major ("F") ordering; \([\cdot]\) is the floor division or integer division operation. We can implement our discovery as the following:

```python
def ind2sub(flat_index, shape, order="C"):
    """Convert flat index to multi-index."""
    if order == "C":  # row-major
        eta = np.cumprod(shape)[1:][::-1]
        eta = np.concatenate([[1], eta])[:-1]
    elif order == "F":  # column-major
        eta = np.cumprod(shape)[:-1]
        eta = np.concatenate([[1], eta])
    else:
        raise(ValueError(f"Unrecognized order: {order}"))
    # (num_indices, 1)
    flat_index = np.asarray(flat_index)[:, None]
    shape = np.asarray(shape)
    # Compute multi-index
    return flat_index // eta % shape
```

- Lines 3–10 implement the array \(\eta\) depending on the order. Notice that the last element of `eta` is 1 when `order="C"` while the first element of it is 1 when `order="F"`.
- Lines 13 and 14 make sure the `flat_indices` and `shape` are both arrays in order to implement our formula in Equation 3.1.
- Line 17 implements the index conversion formula.

We can quickly verify our implementation against `np.unravel_index` as the following:

```python
import numpy as np
shape = np.array((2, 3, 3, 2))
flat_index = np.arange(np.prod(shape))
# Use numpy unravel_index
r_multi_index = np.vstack(np.unravel_index(flat_index, shape, order="C")).T
c_multi_index = np.vstack(np.unravel_index(flat_index, shape, order="F")).T
# Call our own implementations
r_sub = ind2sub(flat_index, shape, order="C")
c_sub = ind2sub(flat_index, shape, order="F")
assert np.allclose(r_multi_index, r_sub)
assert np.allclose(c_multi_index, c_sub)
```

On the other hand, to convert the multi-index of a 4D tensor to a flat index using `np.ravel_multi_index`, e.g.,

```python
import numpy as np
coordinates = [ # point coordinates
    (0, 1, 1, 0),
    (0, 2, 0, 1),
    (1, 0, 1, 0),
    (1, 1, 1, 1),
]
# one array for each dimension
multi_indices = np.array(coordinates).T.tolist()
shape = [2, 3, 3, 2]

# C-order
r_flat_index = np.ravel_multi_index(
    multi_indices, dims=shape, order="C"
)
print(np.concatenate([r_flat_index[:, None], coordinates], axis=1))
# [ [8 0 0 1 0]
# [13 0 2 0 1]
# [20 1 0 1 0]
# [27 1 1 1 1]]

# F-order
c_flat_index = np.ravel_multi_index(
    multi_indices, dims=shape, order="F"
)
print(np.concatenate([c_flat_index[:, None], coordinates], axis=1))
# [ [8 0 0 1 0]
# [22 0 2 0 1]
# [ 7 1 0 1 0]
# [27 1 1 1 1]]
```

We may discover the pattern of conversion like the following:

$$r_j = \sum_d i_d^{(j)} n_d$$ (3.2)

where $n_{d<D-1} = \prod_{i=d+1}^{D-1} n_i, n_{D-1} = 1$ when using row-major ("C") ordering, and $n_{d>0} = \prod_{i=0}^{d-1} n_i, n_0 = 1$ when using column-major ("F") ordering; this is identical to the previous definition in Equation 3.1. We can implement our findings as the following:

```python
def sub2ind(multi_index, shape, order="C"):
    """Convert multi-index to flat index."""
    if order == "C": # row-major
        eta = np.cumprod(shape[1:][::-1])
        eta = np.concatenate([[1], eta])[::-1]
    elif order == "F": # column-major
        eta = np.cumprod(shape)[:-1]
        eta = np.concatenate(([1], eta))
    else:
        raise(ValueError(f"Unrecognized order: {order}"))
    # (num_indices, d)
    multi_index = np.asarray(multi_index)
    return np.sum(multi_index * eta, axis=1)
```

- Lines 3–10 are identical to that of ind2sub, where we determine the array eta.
- Line 13 makes sure the input multi_index is an array.
- Line 15 implements the formula in Equation 3.2.

> The function names ind2sub and sub2ind are from MATLAB.

It is important to understand that we cannot use flat indices directly on an un-flattened multidimensional tensor in NumPy, Tensorflow, or PyTorch. For example, if X is a 2D matrix, then X[0] does not retrieve the first element but rather the entire first row of the matrix. This is called *slicing*, which we will look into more carefully in Section 3.2 in this chapter. To retrieve the first element according to the flat index, we need to either flatten the matrix, i.e `X.flatten()[0]`, or use `np.take` which we will discuss in Section 3.4.1.

Indexing elements using a flat index only requires the linear values (from 0 to N − 1, where N is the number of elements in the tensor), the shape of the tensor, and the order of traversal (e.g. C or F ordering). In contrast, indexing using a multi-index requires D × N values, where D is the dimension of the tensor. Thus, flat indices require less memory when enumerating the elements of the tensor while the dimensionality information can be disregarded. As we will see later in the chapter, operations such as gather and scatter on multi-dimensional tensors are usually performed on flat indices. However, multi-indices can encode the grouping of the elements. Slicing and groupwise reduction (e.g. sum over rows) are performed using multi-indices. Therefore, depending on the type of data manipulation needed, one may use a flat index at certain steps of the algorithm, but then switch to use a multi-index in another part. In Chapter 7, we will also see additional examples of how sparse matrices leverage both flat index and multi-index to store sparse data and how we can perform specialized operations on this data structure.

## 3.1.3 Boolean Indexing

Instead of using integers to select elements from the tensor, we can also use a tensor of boolean indicators whose shape is identical to the input tensor to select the desired elements. This way of indexing is helpful for us to select elements based on logical conditions. Let’s suppose again we have a 2D matrix X, and we would like to select all the odd values from the tensor.

```python
import numpy as np

X = np.array([
    [5, 2, 8, 3],
    [4, 9, 6, 7],
    [8, 11, 12, 10]
])

# Boolean condition of odd elements
# same shape as X
condition = X % 2 == 1

# Extract the odd elements
X[condition]
# array([5, 3, 9, 7, 11])
```

In Chapter 5, we will introduce the concept of masking. In fact, selecting elements from a tensor-based on a boolean condition can also be considered as a boolean masking operation (i.e. removing unselected elements).

On the other hand, we can also find the indices of the boolean conditions, using the .where operation. Consider the same 2D matrix as above, we can find the indices of the odd numbers in the matrix using

```python
import numpy as np

X = np.array([
    [5, 2, 8, 3],
    [4, 9, 6, 7],
    [8, 11, 12, 10]
])

# indices of odd elements
row_index, col_index = np.where(X % 2 == 1)

# row_index: array([0, 0, 1, 1, 2])
# col_index: array([0, 3, 1, 3, 1])
```
