def forward(self, x):
    x = self.ffn1(x)
    x = F.gelu(x)
    x = self.ffn2(x)
    return x

class FFNSwiGLU(nn.Module):
    """
    SwiGLU feedforward layer.
    * input_dim: input dimension
    * hidden_dim: hidden dimension
    """
    def __init__(self, input_dim, hidden_dim):
        super().__init__()
        self.linear_gate = nn.Linear(input_dim, hidden_dim, bias=False)
        self.sw_i_gate = nn.Linear(input_dim, hidden_dim, bias=False)
        self.output = nn.Linear(hidden_dim, input_dim, bias=False)

    def forward(self, x):
        linear_term = self.linear_gate(x)
        swi_term = self.sw_i_gate(x)
        swi_term = F.silu(swi_term)
        return self.output(swi_term * linear_term)

Building a complete LLM would also require a dedicated team of research scientists and machine learning engineers, along with extensive fine-tuning and artificial intelligence (AI) safety alignment work to avoid generating toxic content. However, the goal of this book is to offer materials that are reproducible on a single machine or a Google Colab instance with limited computing resources. This approach ensures that every reader can execute the proposed solutions. By understanding the theory behind the transformer model and applying it to build a small-scale language model, readers can gain an appreciation for the effort and complexity involved in creating sophisticated AI models like ChatGPT.
