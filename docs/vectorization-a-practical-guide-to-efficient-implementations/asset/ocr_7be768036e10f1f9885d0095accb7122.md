In general, we can convert between flat index and multi-index when given the element ordering convention "C" or "F" and the shape of the tensor. NumPy implements two functions to help the interconversion between the two indexing systems. `np.ravel_multi_index(multi_index, shape, order)` converts multi-indices to flat indices. Vice versa, `np.unravel_index(flat_indices, shape, order)` converts flat indices to multi-indices given tensor shape and order. For example, to convert from flat index to multi-index,

```
import numpy as np

shape = [2, 3, 3, 2]
flat_index = np.arange(0, np.prod(shape), 3)

r_multi_index = np.unravel_index(
    flat_index, shape, order="C"
)

print(np.stack([flat_index] + list(r_multi_index)).T)
# [[ 0  0  0  0  0]
#  [ 3  0  0  0  1]
#  [ 6  0  1  0  0]
#  [ 9  0  1  1  1]
#  [12  0  2  0  0]
#  [15  0  2  1  1]
#  [18  1  0  0  0]
```
