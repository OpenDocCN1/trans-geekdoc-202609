import numpy as np

Pandas handles null values in string and object columns differently. string columns have a special placeholder <NA> for missing values, while object uses None.

```
import pandas as pd
feature = ["a", "b", "c", None, "d"]
df = pd.DataFrame({
"feature1": pd.Series(feature, dtype="string"),
"feature2": pd.Series(feature, dtype="object")
})
# display the table
# feature1 feature2
# 0 a a
# 1 b b
# 2 c c
# 3 <NA> None
# 4 d d
# Check the two missing values
print(df["feature1"] [3] is None) # False
print(df["feature2"] [3] is None) # True
```

### 6.1.3 Tensorflow Bytes

Tensorflow has the `tf.string` data type, but all the data stored in `tf.Tensor` becomes bytes. For example,

```
import tensorflow as tf
string_array = ["lorem", "ipsum", "dolor"]
tf_string_array = tf.constant(string_array)
# tf.Tensor([b'lorem' b'ipsum' b'dolor'], shape=(3,),
# dtype=string)
```

The `tf.Tensor.numpy` method can convert Tensorflow's `tf.Tensor` to a NumPy array. For float and integer types, the conversions typically have no issues retaining the data as float and integer of the corresponding precisions (i.e. `tf.int64 -> np.int64`, `tf.int32 -> np.int32`, `tf.float32 -> np.float32`, `tf.float64 -> np.float64`). But when converting a byte string to a NumPy array, we will get an array of bytes in NumPy instead of typical string representations (U or S). This can sometimes be inconvenient if we were to implement further string processing on the text, where some methods are specifically implemented against string types instead of byte types. For example, suppose we would like to replace values using a dictionary, where the keys of the dictionary are specified using strings. However, the values we would like to replace are specified in bytes. If caution is not exercised, the program may not be able to achieve the goal of replacing values at all.

```
import tensorflow as tf
mapping = {"A": "1", "B": "2", "C": "5"}
values = tf.constant([["A", "C", "B"]]) # should result ["1", "5", "2"]
# although the following does not throw the error
replaced_values = [mapping.get(v, "") for v in values.numpy()]
# the replaced results are incorrect
# ["", "", ""]
```

Therefore, additional casting is needed. Typically, we can use the `.astype(str)` method to cast from bytes to string. To illustrate,

```
tf_string_array = tf.constant(["A", "B", "C"], dtype=tf.string)
# <tf.Tensor: shape=(3,), dtype=string, numpy=array([b'A', b'B', b'C'],
# dtype=object)>

# Numpy array of bytes (object dtype)
np_string_array_bytes = tf_string_array.numpy()
# array([b'A', b'B', b'C'], dtype=object)

# Casting to string
np_string_array_str = tf_string_array.numpy().astype(str)
# array(['A', 'B', 'C'], dtype='<U1')
```

This may seem inconvenient, but Tensorflow's `bytes` data type can be quite versatile. In the last section of the chapter (Section 6.7), we will examine how Tensorflow can represent structured data using byte strings.

## 6.3 Case Study: Parsing DateTime from String Representations

We may be familiar with Python's `datetime` library which allows us to handle timestamps easily via intuitive application programming interfaces (APIs). For example, we would like to convert a local timestamp to a Coordinated Universal Time (UTC) timestamp like the following:

```
import datetime
datetime_local = datetime.datetime.strptime(
    "2023-05-07 17:32:25-08:00", '%Y-%m-%d %H:%M:%S%z'
)
datetime_utc = datetime_local.astimezone(datetime.timezone.utc)
# datetime.datetime(2023, 5, 8, 1, 32, 25, tzinfo=datetime.timezone.utc)
```

Pandas also provides vectorized ways to manipulate timestamps easily as well with its `pd.Timestamp` class [McKinney, 2023a]. However, deep-learning libraries like Tensorflow and PyTorch do not have a built-in timestamp class (at the time of writing), so it is more typical to handle timestamp features using strings when attempting to model time series data. The following function implements a way to convert an array of timestamp strings in the format of `year-month-date hour:minute:second timezone`, or using `datetime.strftime` expression `%Y-%m-%d %H:%M:%S%Z`, into a series of integers representing year, month, date, hour, minute, seconds, zone, respectively.

```
def _parse_timestamps(
    timestamps_array: tf.Tensor, utc: bool = False
):
    """
    Parse timestamp strings, assuming %Y-%m-%d %H:%M:%S%Z.
    For example: 2023-05-07 17:32:25-08:00
    """
    # use substring to extract time components
    year = tf.strings.to_number(
        tf.strings.substr(timestamps_array, 0, 4),
        out_type=tf.int64
    )
    month = tf.strings.to_number(
        tf.strings.substr(timestamps_array, 5, 2),
        out_type=tf.int64
```
