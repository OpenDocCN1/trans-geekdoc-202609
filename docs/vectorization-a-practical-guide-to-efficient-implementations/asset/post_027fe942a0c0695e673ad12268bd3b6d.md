  - "difference": This is similar to performing "XOR" operation on two boolean vectors, except that it is directional (i.e. exists in set 1, but does not exist in set 2, not vice versa). Recall in Chapter 5 when performing the arithmetic version of "XOR" operations, we subtract the two binary values together and take the absolute value, in which case we convert both -1 (0 - 1 or False vs. True) and +1 (1 - 0 or True vs. False) results as +1 (True). However, by definition, set.difference keeps the element if it is True (exists) in set 1 and False (not exists) in set 2, while elements that correspond to False in set 1 and True in set 2 are not kept (unlike XOR which would keep elements in both cases). Therefore, in the arithmetic version of the set difference, we clip the resultant value to a minimum of 0 instead.

Given array lengths [1, 5, 3, 2], we can compute the ragged indices from the flat indices that enumerate the valid entries of the sparse matrix. By induction, we can conclude that the offsets for each block are computed as cumsum([0, 1, 5, 3]) = [0, 1, 6, 9]. Then, the offset can be subtracted from each block (as if broadcasting) of the flat_indices to obtain the ragged_indices. To broadcast, we can simply repeat the offsets by each array length, i.e. 0 repeated one time, 1 repeated five times, 6 repeated three times, and 9 repeated two times.

def batch_wise_intersection(x, y, pad=None):
    batch_size = x.shape[0]
    res = [[]] * batch_size
    for ii in range(batch_size):
        # take intersection
        r = set(x[ii, :]).intersection(set(y[ii, :]))
        if pad is not None:
            # remove padding
            r = r.difference(set([pad]))
