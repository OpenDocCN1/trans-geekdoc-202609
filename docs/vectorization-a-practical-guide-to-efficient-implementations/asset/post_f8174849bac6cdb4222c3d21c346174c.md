## 3.7 Case Study: Batchwise Scatter Values

As we have seen in Section 3.6, PyTorch implements a version of the scattering operation `torch.scatter` that is the reverse operation of its gather operation `torch.gather`. Tensorflow does not implement `tf.scatter` which allows batched application of scattering by flat indices. However, as we will see in one of the case studies in Chapter 9, batchwise scattering is often needed to implement group by aggregate logic.

Suppose we have the following data (see also Figure 3.20a),

```
import tensorflow as tf
index = tf.constant([
    [1, 3, 6, 2, 4],
    [2, 4, 8, 9, 5],
    [6, 5, 0, 1, 3],
    [3, 7, 2, 5, 4],
], dtype=tf.int64)
inputs = tf.constant([
    [2, 5, 6, 2, 8],
    [6, 1, 7, 0, 4],
    [9, 5, 4, 5, 1],
    [0, 6, 8, 3, 7],
])
```

We would like to scatter the inputs to a new target matrix based on the batch of indices specified by the `index`. This is easily done in PyTorch with

```
import torch
output = torch.scatter(
    torch.zeros((4, 10), dtype=int),
    1,
    torch.tensor(index.numpy(), dtype=int),
    torch.tensor(inputs.numpy(), dtype=int),
)
# tensor([[0, 2, 2, 5, 8, 0, 6, 0, 0, 0],
#         [0, 0, 6, 0, 1, 4, 0, 0, 7, 0],
#         [4, 5, 0, 1, 0, 5, 9, 0, 0, 0],
#         [0, 0, 8, 0, 7, 3, 0, 6, 0, 0]])

```

However, we can use Tensorflow's `tf.scatter_nd` method to achieve the same effect. More concretely, consider, step by step,

- For `index[0, 0] = 1`, we have a value at the corresponding index `input[0, 0] = 2`. We would like to put this value into a new tensor at the position such that `X[0, 1] = 2` (Figure 3.20b). Given the target tensor has shape `(4, 10)`, the multi-index `[0, 1]` can be converted into a flat index 1. Therefore, this is the same as assigning a flat vector `X_flat[1] = 2`, and then reshaping the flat vector back into a 2D matrix.

- For the subsequent figures, Figure 3.20c–e, we are simply iterating over the elements of `index`, extracting the corresponding value from the `input`, and scatter it to the corresponding position on `X`.

Notice that the final output matrix has many zero entries. A matrix with many zero entries is called a sparse matrix, which we will introduce in more detail in Chapter 7.

With the above logic, we can implement the following code that specifically handles the 2D matrix case. Interested readers can further generalize this implementation to higher-dimensional tensors, or perhaps find alternative methods to achieve the same goal.

```
import tensorflow as tf

def scatter_batch_2d(index, inputs):
    # Determines the length of each row for the output
    row_length = tf.cast(tf.reduce_max(index), tf.int32) + 1
    row_length = tf.maximum(tf.shape(inputs)[1], row_length)
    # start and end index of each row
    # row 0: inc[0]:inc[1], row 1: inc[1]:inc[2], ...
    inc = row_length * tf.range(tf.shape(inputs)[0]+1)
    # Compute flat indices for each element
    indices = tf.cast(index, index.dtype) + tf.reshape(inc[:-1], (-1, 1))
    # Flatten to column vector
    indices = tf.reshape(indices, (-1, 1))
    # Flatten updates
    updates = tf.reshape(inputs, (-1,))
    shape = (inc[-1], )
    out = tf.scatter_nd(indices, updates, shape)
    # reshape: (batch_size, row_length)
    out = tf.reshape(out, (tf.shape(index)[0], -1))
    return out
```

- Lines 5 and 6 compute the length of each row of the output. This is determined as the larger of the maximum index values from `index` and the number of columns of the `inputs`. In essence, we would like to return an output that has just enough number of columns to accommodate all the indices; we also want to return no fewer than the number of columns from the input. Note that this is in preparation for a case study in Chapter 9. Alternatively, we can specify an argument `output_shape` to let the user control the size of the output.

- Line 9 computes the start and end indices for each row as a 1D vector. In the above example, we will have `inc = [0, 10, 20, 30, 40]`, where `0:10` is the slice for the first row, `10:20` is the slice for the second row, etc.

- Line 11 offsets the row-specific flat indices by the start of the row index. For example, if an index 4 occurs on the second row of the original index matrix, then the corresponding flat index will be `4 + inc[1] = 4 + 10 = 14`.

- Line 13 flattens the indices with offset, as a column vector.

- Lines 15-17 scatter the 1D array of values to the target 1D array, given the indices.

- Line 19 reshapes the 1D tensor back to the desired 2D matrix, with shape `(batch_size, row_length)`.
