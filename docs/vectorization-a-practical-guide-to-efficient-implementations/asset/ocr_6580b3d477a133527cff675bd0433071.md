```
y2 = align_lengths(X2, y)
assert np.allclose(X2.shape, y2.shape)
print(y2.shape)
```

A practical use case of the above algorithm is to align a generated sequence to some desired length. For example, a ground-truth speech audio sample has two words, lasts one seconds and contains 16,000 data points (i.e. 16 kHz sampling rate). However, the generated sample due to series of upsampling by factors of [16, 16, 32] from the two words creates a sequence of 2 x 16 x 16 x 32 = 16,384 data points. In order to learn from the audio sample by calculating a loss between the prediction and the ground-truth, we can use the above algorithm to align the two sequences (e.g. truncate the generated sequence to 16,000 data points. It is worth noting that many practical applications of machine learning that deal with sequence data, the predicted sequence y should in general be of similar length as the template or input sequence X. If the predicted sequence is significantly longer or shorter than expectation, it is important to understand if upsampling steps are implemented correctly, or hyper-parameters for upsampling are chosen appropriately.
