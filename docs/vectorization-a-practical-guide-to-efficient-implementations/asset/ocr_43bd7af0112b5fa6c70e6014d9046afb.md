# 10.2 Case Study: Top-k Using argsort and argpartition

Both Tensorflow (tf.math.top_k) and PyTorch (torch.topk) implement a method that returns the top-k largest elements along with the indices from an array. For Tensorflow,

```
import tensorflow as tf
X = tf.constant([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = tf.math.top_k(X, k=3)
# top_values: <tf.Tensor: shape=(3,), dtype=int64, numpy=array([9, 8,
~ 5])>
# top_indices: <tf.Tensor: shape=(3,), dtype=int32, numpy=array([4, 5,
~ 3], dtype=int32)>
```

and for PyTorch

```
import torch
X = torch.tensor([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = torch.topk(X, k=3)
# top_values: tensor([9, 8, 5])
# top_inidces: tensor([4, 5, 3])
```

At the time of writing this chapter, NumPy does not have a ready-to-use function to retrieve the top-k values and indices. However, it is possible to use sorting to achieve the same goal. A naive approach is to use np.argsort to determine the indices of the top values, then use np.take to retrieve the top values.

```
import numpy as np
def top_k_argsort(X, k=3):
    """Get top-k values and indices along the last dimension."""
    top_indices = np.argsort(X) [..., -k:][..., ::-1]
    top_values = np.take_along_axis(X, top_indices, axis=-1)
    return top_values, top_indices
X = np.array([1, 3, 2, 5, 9, 8, 4])
top_values, top_indices = top_k_argsort(X)
# top_values: array([9, 8, 5])
# top_indices: array([4, 5, 3])
```
