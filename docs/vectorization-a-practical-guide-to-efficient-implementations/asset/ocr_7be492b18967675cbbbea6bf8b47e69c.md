... consecutive integers. Recall that tf.SparseTensor uses the coordinate format, corresponding to coo_matrix in Scipy's implementation.

+   2. values: This property stores the flattened values of the original input. Its order corresponds to the order of the indices along the row dimension (axis=0). That is, the number of rows in indices tells us how many valid entries are in the sparse matrix. By looking at the values only, there is no way we can tell the fourth and sixth rows of the original input are empty. In other words, there is no “padding” value to represent the fourth or sixth row. Empty rows can be a challenge in data preprocessing sometimes. We will look at this issue more carefully in Chapter 9 when discussing segment-wise group-by-aggregate operations.

+   3. dense_shape: The shape of the sparse matrix indicates there should be six rows in the matrix, but based on indices, there are only four rows, since the fourth and sixth rows of the matrix are empty. Therefore, it is necessary to look at the dense_shape when determining how many rows there are in the matrix, instead of either counting the distinct number of values from indices[:, 0] or using the maximum of indices[:, 1].
