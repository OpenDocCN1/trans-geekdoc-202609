where

+   - Q, K, V are the query, key, and value sequence.
+   - d_k is the “depth” or embedding dimensions of the keys.
+   - softmax(·) is the softmax activation function, defined as σ(xᵢ) = exp(xᵢ) / Σⱼ exp(xⱼ).

In Equation 5.1, query and key first perform a dot product QK^T before scaled by the square root of the depth of the key √d_k. Then, the computed attention score is transformed with the softmax function to convert into probabilities and applied to the value sequence via tensor multiplication.

In addition, there are two major flavors of this attention mechanism:

+   - **Self-attention**: key, query, and value are all the same sequence inputs. The attention weights are computed within the sequence itself, between pairs of its own elements.
+   - **Cross-attention**: key, query, and value are not the same sequence. Here, elements in the key and query sequences need to have identical embedding or so-called depth dimensions, while key and value need to have identical sequence lengths. Attention weights are computed between two distinct sequences represented by key and query and applied to a third sequence represented by value.

There are two major flavors of self-attention (see Figure 5.13):

+   - **Bidirectional self-attention**: A single token within the sequence can attend to not only the tokens coming before it (and itself) but also the tokens coming after it. This type of self-attention is implemented as part of the Encoder layers of the Transformer model, where all the contexts surrounding the current token help inform the model.
+   - **Causal self-attention**: A single token within the sequence can only attend to the tokens coming before it (and itself). This type of self-attention is implemented as part of the Decoder layers of the Transformer model, where only the historical token sequences are used to predict the tokens coming next.
