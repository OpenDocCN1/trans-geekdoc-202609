For 1D tensors, tf.gather(X, index) and torch.gather(X, dim=0, index=index) are equivalent to np.take(X, index). In this case, setting axis=None or axis=0 has the same effect. For Tensorflow, axis=None pairing with batch_dims=0 (both are the default) would result axis=0, where the elements are taken along the first (and the only) dimension of the 1D vector. PyTorch requires the user to specifically set dim=0 (setting dim=None would throw an error). For NumPy, setting axis=None signals the function to flatten the 1D vector, which results in itself. Then, the values are taken along the same vector.
