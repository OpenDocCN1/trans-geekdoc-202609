But, since index values for both news and ads start from 1 in those two matrices, if we naively combine the matrices together, we may end up having two indices 1s in this output_index matrix, which can confuse news vs. ads items. So we offset the ads indices by the vocabulary size of the news. We also convert the indexing back to 0-based in the final output_index matrix. That way, news index values are [0, 1, ..., <news_vocab_size - 1>], and ads index values are [<news_vocab_size>, <news_vocab_size + 1>, ..., <news_vocab_size + ads_vocab_size - 1>]. This is as if we are indexing using a combined vocabulary, vocab = concat([news_vocab, ads_vocab]). See Figure 10.11 for an illustration of the transformation.
