# array([[0, 5, 0, 0, 8, 7],

# 5.2 Padding

Padding adds elements to our data tensor to make sure the data are consistently represented in a desired shape. Like masking, the added data is intended to be ignored by the model while the data passes through our vectorized operations.

NumPy [Harris et al., 2023] and Tensorflow [Abadi et al., 2023] both implement three types of padding modes, `constant`, and `reflect`, and `symmetric` (with differences in how the modes are named or spelled); PyTorch also implements `constant` and `reflect` (with limitations), but not `symmetric`; it also implements two additional modes, `replicate` (which simply repeats the border values, equivalent to NumPy's `edge` mode) and `circular` (equivalent to NumPy's `warp` mode). NumPy implements several additional modes, such as padding with `mean`, `median`, `maximum`, or `minimum` values along each dimension.

In constant padding mode (NumPy: "constant", Tensorflow: "CONSTANT", PyTorch: "constant"), constant values are added at the beginning or the end of the tensor along certain dimensions. In NumPy and Tensorflow, we can specify the number of values to pad and pad either before or after the tensor along the dimensions, using the format [(start_axis_0, end_axis_0), (start_axis_1, end_axis_1), ..., (start_axis_n, end_axis_n)]. However, PyTorch's torch.nn.functional.pad has a different implementation and requires the padding to be specified in the reverse order and as a flattened array, i.e. [start_axis_n, end_axis_n, ..., start_axis_0, end_axis_0]. For example, given a 3 x 4 matrix, we would like to add three more zeros along its rows at the beginning and two more zeros along its columns at the end, we then do

```
import numpy as np
import tensorflow as tf
import torch.nn.functional as F
# shape(3, 4)
X = np.array([
    [7, 1, 4, 4],
    [5, 7, 6, 4],
    [7, 3, 1, 2],
])
# padding zeros -> shape (6, 6)
y_np = np.pad(X, [(3, 0), (0, 2)], mode="constant", constant_values=0)
```
