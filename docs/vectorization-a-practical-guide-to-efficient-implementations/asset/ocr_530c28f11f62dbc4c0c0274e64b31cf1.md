Both NumPy and PyTorch also implement wrap or circular mode, respectively. In this mode, values in the padding are the wrapping of the tensor along its dimensions. That is, for padding values at indices -1, -2, ..., use tensor values at N - 1, N - 2, ...; for padding values at indices N, N + 1, ..., use tensor values at 0, 1, .... For PyTorch's implementation at the time of writing this chapter (torch==2.0.1), in addition to the same limitation as the reflect and replicate modes, the circular padding mode only supports padding one dimension (i.e. the last dimension of the tensor) at a time.
