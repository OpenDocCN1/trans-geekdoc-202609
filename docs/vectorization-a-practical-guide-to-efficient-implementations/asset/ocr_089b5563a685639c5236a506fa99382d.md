c) Diagonal extraction vs. Trace. Even though the two expressions are similar, the Trace operation should return the sum of the diagonal as a scalar, while diagonal extraction should return the diagonal entries as a vector.

```
X = np.random.rand(8, 8)
np.allclose(
    np.trace(X),
    np.einsum("ii->", X)
)
np.allclose(
    np.diag(X),
    np.einsum("ii->i", X)
)
```

d) Transpose and Swapaxes. These two are similar operations in einsum. The implicit mode takes advantage of the assumption that the axes of the returned tensor will be sorted alphabetically.

```
# Tranpose of matrix
X = np.random.rand(4, 5)
np.allclose(
    np.transpose(X),
    np.einsum("ij->ji", X)
)
np.allclose(
    np.transpose(X),
    np.einsum("ji", X)
)
# Swapaxes
Y = np.random.rand(4, 5, 6)
np.allclose(
    np.swapaxes(Y, 0, 2),
    np.einsum("ijk->kji", Y)
)
np.allclose(
    np.swapaxes(Y, 0, 2),
    np.einsum("kji", Y)
)
```
