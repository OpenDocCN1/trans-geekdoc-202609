Let’s examine several basic patterns of using regex in Python in the following examples. But I would like to encourage interested readers to refer to official Python documentation on regex (such as this one “Regular Expression HOWTO” [Kuchling, 2023]) to learn more about this topic.

```
import re

# Example 1: remove punctuation
text = "How is it going? I'm good!"
result = re.sub(r'''[[\.\,?!\ \-\:\;/\\\[\]']''', '', text)
# 'How is it going Im good'

# Example 2: tokenize: spaces and newline
text = """The quick brown fox jumps
over the lazy dog"""
result = re.split(r'\s+', text)
# ['The', 'quick', 'brown', 'fox', 'jumps',
# 'over',
# 'the', 'lazy', 'dog']

# Example 3: find occurrences of the pattern
text = "The human genome has 3 billion base pairs, "
"making the text file storing it as large as "
"12 GB on disk."
result = re.findall(r'\d+', text)
# ['3', '12']
```

- Lines 2–5, Example 1: In this example, we attempt to remove punctuations characters, including period ., question mark ?, exclamation mark !, comma ,, colon :, semicolon ;, double quote ", and apostrophe '. We achieve this by replacing (re.sub or substituting) the character in our list with an empty string. The backslash character \ is called the escape character, which will make sure the regex treats the character following the backslash as a string character, rather than a special pattern-matching metacharacter, such as . (matching any character other than newline \n), + (matching at least 1 occurrence), * (matching any number of occurrences, including 0 occurrences), and ? (matching 0 or 1 occurrences of the preceding pattern character, but no more than 1). Alternatively, one can also use string.punctuations from Python's built-in string package for the list of punctuation characters, i.e. re.sub(rf'''[{string.punctuation}]''', '', text).

- Lines 7-12, Example 2: In this example, we attempt to locate all white space characters (which may occur consecutively) and split by the white space characters. The pattern \s indicates that we are trying to find white space characters (newlines as well as spaces and tabs). Then the + metacharacter tells re.split that it is possible to have 1 or more than 1 white space characters occurring consecutively to delimit the tokens in the sentence, so we would like to split the sentence such that all white space characters are removed from the final list of tokens. An alternative to this regex pattern is to use re.findall(r' ([\w*])\w ', text) instead. Here, \w will match an alphanumerical character. Therefore, [\w*]\w will match a string that starts and ends with alphanumerical characters, which effectively breaks the original long string into a list of shorter strings by removing any non-alphanumerical characters such as spaces and newlines.

- Lines 14-19, Example 3: In this example, we try to extract some patterns from a sentence. Specifically, we want to find all occurrences of numbers in the sentence, i.e. "3" and "12". The \d+ pattern indicates that what we would like to find are one or more (+) digits (\d) that are grouped together. re.findall will return all the occurrences that match the pattern.

## 6.7 Data Serialization and Deserialization

The current section is not regarding how to manipulate string values in the data, but rather how to turn an entire dataset into a string or byte representation, which we call data "serialization." Within the context of machine learning data management, serialization is the process of converting structured data into a stream of byte strings so it can be further compressed and consumed by any downstream processes. In production machine learning systems that use microservices, data hosting services are separate from the model inference services. Hence, there is a need to transfer data from one service to another service via the network. In cloud environments, model training needs to load data from the cloud disk to the virtual machine instance which has access to costly resources such as GPUs. Therefore, the service needs to be able to load the data from the remote disk quickly, so that the training instance can fully utilize the GPUs for training rather than waiting for data to be downloaded. On the other hand, the process of reversing the serialization process, or turning byte strings back into structured data, is called deserialization.

Tensorflow uses Protocol Buffers [Google, 2023] (protobuf) to serialize the structured data into a sequence of bytes. The serialized byte strings can then be compressed and stored in the TFRecord format, a row-based data storage format that supports distributed data processing, transformation, shuffling, and batching via the tf.data API. Suppose we have the following batch of data with three features:

```
import os
import tempfile
import tensorflow as tf
inputs = [
    {"student_id": "a-153249", "num_classes_taken": 5, "gpa": 3.97},
    {"student_id": "b-132429", "num_classes_taken": 3, "gpa": 3.51},
    {"student_id": "a-293841", "num_classes_taken": 4, "gpa": 4.00},
    {"student_id": "c-912431", "num_classes_taken": 4, "gpa": 3.91},
    {"student_id": "c-924145", "num_classes_taken": 3, "gpa": 3.20},
]
```

We recognize that student_id is a string feature, num_classes_taken is an integer feature, and gpa is a float feature. We can then put this data, one row at a time, into the tf.train.Example protobuf,

```
# Create the Features protobuf
examples = []
for x in inputs:
    # Create the dictionary
    feature = {
        "student_id": tf.train.Feature(
            bytes_list=tf.train.BytesList(
                value=[bytes(x["student_id"], "utf-8")]
            )
        ),
        "num_classes_taken": tf.train.Feature(
            int64_list=tf.train.Int64List(value=[x["num_classes_taken"]])
        ),
        "gpa": tf.train.Feature(
            float_list=tf.train.FloatList(value=[x["gpa"]])
        )
    }

    # Create the Examples protobuf
    example = tf.train.Example(features=tf.train.Features(feature=feature))
    examples.append(example)

# print the last example
# print(example)

# features {
#   feature {
#     key: "student_id"
#     value {
#       bytes_list {
#         value: "c-924145"
#       }
#     }
#   }
#   feature {
#     key: "num_classes_taken"
#     value {
#       int64_list {
#         value: 3
#       }
#     }
#   }
#   feature {
#     key: "gpa"
#     value {
#       float_list {
#         value: 3.2
#       }
#     }
#   }
# }
```

In the example, the protobuf for the byte string needs to encode the data types using separate protobuf definitions, i.e. string features need to be cast to bytes first and then encoded by tf.train.BytesList, integer features need to be encoded by tf.train.Int64List, and float features need to be encoded by tf.train.FloatList. Notice that the value assigned for each feature is a list with a single element. This is because these protobuf types actually encode a list of values of a certain type rather than a single value. Suppose {num_classes_taken: [5, 3, 4]}, then we can encode this feature as int64_list=tf.train.Int64List(value=[5, 3, 4]).

To write our string representations of the data into a TFRecord, we can first serialize the protobuf string into bytes, and then write into a compressed TFRecord. To understand how exactly TFRecord is formatted to store the data in a serialized format, see the implementation from the Ray Data library [Moritz et al., 2023].

```
# Create a temporary TFRecord file
base_dir = tempfile.TemporaryDirectory()
file_path = os.path.join(base_dir.name, "temp.tfrecord")
options = tf.io.TFRecordOptions(compression_type="GZIP") # gzip compressed
with tf.io.TFRecordWriter(file_path, options=options) as writer:
  for example in examples:
    serialized_example = example.SerializeToString()
    writer.write(serialized_example)
```
