```
import numpy as np
image_tf = np.random.rand(8, 32, 15, 3)
image_torch = np.transpose(image_tf, axes=[0, 3, 1, 2])
```

Though it takes two lines, we can also use np.swapaxes

```
image_torch = np.swapaxes(image_tf, 1, 3) # (8, 3, 15, 32)
image_torch = np.swapaxes(image_torch, 2, 3) # (8, 3, 32, 15)
```

NumPy's np.ndarray has np.ndarray.T for tensor transpose, which essentially reverses the ordering of the dimensions. This probably corresponds to the typical mathematical notation for transpose, i.e. <sup>T</sup>. The transpose of a 1D array is still a 1D array, as there are no additional dimensions to swap with.

### Figure 2.7 Vector to matrix broadcasting.

Note that the mathematical operation between a scalar and an array makes no sense,

```
1 + [2 4 6]
```

However, after broadcasting, the equivalent mathematical operation becomes

```
[1 1 1] \oplus [2 4 6] = [3 5 7]
```

where \oplus denotes element-wise addition operation. Similarly, I will use

- \ominus to denote element-wise subtraction
- \odot to denote element-wise multiplication
- \oslash to denote element-wise division

Likewise, a vector can also be broadcasted to a matrix (Figure 2.7). The operation between a vector and a matrix also makes no mathematical sense,

```
[1 3 4 6] + [1 2 3 4 \n 2 3 4 5 \n 3 4 5 6]
```

The equivalent broadcasting operations become

```
[1 3 4 6 \n 1 3 4 6 \n 1 3 4 6] \oplus [1 2 3 4 \n 2 3 4 5 \n 3 4 5 6] = [2 5 7 8 \n 3 6 8 11 \n 4 7 9 12]
```

A tensor with singleton dimensions (.shape [axis]=1) is broadcastable to another tensor with non-singleton dimensions, as long as the rest of the dimensions are also broadcastable. For example, broadcasting between a column vector of shape (1,N) and a matrix of size (M,N) (Figure 2.8),

```
[1 \n 3 \n 6] + [1 2 3 4 \n 2 3 4 5 \n 3 4 5 6]
```

has the equivalent broadcasting operations

```
[1 1 1 1 \n 3 3 3 3 \n 6 6 6 6] \oplus [1 2 3 4 \n 2 3 4 5 \n 3 4 5 6] = [2 3 4 5 \n 5 6 7 8 \n 9 10 11 12]
```

In general, a scalar (ndim=0) can always be broadcasted to any higher-dimensional tensors. A lower dimensional tensor (ndims > 0) can be broadcasted to a higher dimension tensor as long as the size of some or all trailing (right-aligned) axes of the lower dimensional tensors is either a singleton (i.e. .shape[axis]=1) or match the size of the higher dimensional tensors at the corresponding trailing axes. To define this more concretely, suppose the lower dimensional tensor X has shape (a1, a2, a3, ..., an), ai != 0, \forall i and the higher dimensional tensor Y has shape (b1, b2, ..., bm), bj != 0, \forall j, where n <= m, then for X to be broadcasted to Y, we necessarily need to have

```
{
    a_n \in {b_m, 1},
    a_{n-1} \in {b_{m-1}, 1},
    ...
    a_{n-k} \in {b_{m-k}, 1},
    ...
    a_1 \in {b_{m-n+1}, 1}
}
```

The broadcasted operation will result in a tensor Z of shape (c1, c2, ..., cm) that takes the larger size of either X or Y, and the number of dimensions will be Y.ndim which is larger than X.ndim. That is,

```
{
    c_m = max(a_n, b_m)
    c_{m-1} = max(a_{n-1}, b_{m-1})
    ...
    c_{n-k} = max(a_{n-k}, b_{m-k})
    ...
    c_{m-n+1} = max(a_1, b_{m-n+1})
    c_{m-n} = b_{m-n}
    c_{m-n-1} = b_{m-n-1}
    ...
    c_{m-n-p} = b_{m-n-p}
    ...
    c_1 = b_1
}
```

For examples,

- A scalar, e.g. 5 with no dimensions (ndim=0), can be broadcasted to a tensor of shape (3, 6, 5, 7), which produces a tensor of shape (3, 6, 5, 7).
- A tensor of shape X of shape (5, 7) can be broadcasted to another tensor Y of shape (3, 6, 5, 7), since the last two dimensions of X and Y are matching. The resultant tensor Z has shape (3, 6, 5, 7).
- A tensor X of shape (5, 7) cannot be broadcasted to another tensor Y of shape (7, 6, 2), since the last two dimensions of X and Y are not matching, nor any of the axes of X is a singleton.
- A tensor X of shape (1, 7) can be broadcasted to another tensor Y of shape (3, 6, 5, 7), since the last dimension of the two tensors are matching, and the second to last dimension of X is a singleton. The resultant tensor Z has shape (3, 6, 5, 7).
- A tensor X of shape (6, 1, 7) can be broadcasted to another tensor Y of shape (3, 1, 5, 7), since the last dimension of the two tensors are matching, the second to last dimension of X is a singleton, and the third to last dimension of Y is a singleton. The resultant tensor Z will have a shape of (3, 6, 5, 7).
- A tensor X of shape (0, 7) cannot be broadcasted to another tensor Y of shape (3, 6, 5, 7), since the first axis of X is 0, which is neither a singleton nor matching to the last dimension of Y, i.e. 5.
- Here is an odd example for 0-size tensors. When attempting to broadcast tensor X of shape (0, 7) (i.e. empty, 0-size tensor) to another tensor of shape (1, 7), the operation will not throw an error. However, the resulting tensor Z will also be of shape (0, 7), i.e. an empty tensor like X. This is why we need to avoid operations with empty or 0-size tensors in our broadcasting rule.

> Note that the underlying mechanism of broadcasting is not in reality repeating the elements to be broadcasted many times by copying the same data over and over again, as it will not be memory efficient.

### 2.12.1 Image Normalization

An example application of scalar to tensor broadcasting is the min–max normalization of images. Given image \( I \),

\(\text{Normalize}(I_i) = \frac{I_i - \min(I)}{\max(I) - \min(I)}, \forall i\) (2.1)

where \( i \) is the index of the image pixels. We can implement the above as

```
import numpy as np

def normalize_image(image):
    """Normalize image pixel values to be between 0 and 1"""
    # image shape (height, width, channel)
    min_val = np.min(image) # scalar
    max_val = np.max(image) # scalar
    normalized_img = (image - min_val) / (max_val - min_val + 1e-6)
    return normalized_img
```

- Lines 6 and 7 compute the global minimum and maximum values, which are scalars.
- Line 8 implements Equation 2.1. The denominator adds a small \(\epsilon = 10^{-6}\) to prevent division by zero error. If minimum and maximum values are zeros, then all pixels in the image should have values of zero. In this case, the normalized image will also be all zeros.

If we have a batch of images, we use vector broadcasting, which is implemented as

```
import numpy as np

def normalize_image_batch(images):
    """Normalize image pixel values to be between 0 and 1"""
    # image shape (batch_size, height, width, channel)
    # min / max (batch_size, 1, 1, 1)
    min_val = np.min(images, axis=(1, 2, 3), keepdims=True)
    max_val = np.max(images, axis=(1, 2, 3), keepdims=True)
    normalized_img = (images - min_val) / (max_val - min_val + 1e-6)
    return normalized_img
```
