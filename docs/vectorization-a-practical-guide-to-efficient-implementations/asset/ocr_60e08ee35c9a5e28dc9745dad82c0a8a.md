More often than not, subsequent transformer-based models may use only either the encoder or decoder part of the transformer for specific tasks. For instance, bidirectional encoder representation from transformers (BERT) [Devlin et al., 2019] is an encoder-only pretrained language model from Google. Many sequence representers also tend to use encoder architecture, e.g. FastSpeech2 and Whisper, whose hidden states are then decoded by downstream architectures that may not necessarily be a transformer block, e.g. convolutional layers. By contrast, the GPT model family uses decoder-only architecture, where causal attention is used. The choice of specific architecture is tightly associated with the training tasks used by different models, which we will discuss in Section 11.5.

# 11.1.2 Training of Transformer Models

Self-supervised pretraining has been an effective technique in building models solving NLP tasks. Researchers would gather a large text corpus with billions to trillions of tokens to build models that “understand” text so that they can be fine-tuned downstream to solve NLP-specific tasks like text classification or sentiment analysis, which usually has less human-labeled data available. What they typically do is pretraining the model using the “Cloze” task (i.e. fill in the blank) [Devlin et al., 2019], in which a word in a sentence is blanked out, and the model learns to predict the word in the blank. It is said that the model learns via a self-supervised fashion, where the data used to generate both the input and the label come from the same sentence, without a human deciding what the inputs and the labels are. Indeed, text data are “self-labeling” (as explained by Yann Lecun). Similar to text data, time series or time-associated events data are also self-labeling. Let’s say, we can use the last seven days of historical data to forecast the next event, e.g. whether or not it is raining tomorrow. At the inference time, we do not know what tomorrow’s weather is going to be, so we do not have the label at the moment. But, we only need to wait to see the weather on the next day, and the label is automatically generated, without a human deliberately deciding what it is.

Going back to the context around NLP, the BERT model that uses encoder-only transformer architecture with bidirectional attention is trained using the Cloze task. The goal of BERT is to learn a sequence representation, such that it can be used in downstream tasks that would utilize the entirety of the sentence inputs.
