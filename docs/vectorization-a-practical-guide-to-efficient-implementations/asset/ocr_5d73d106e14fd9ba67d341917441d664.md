+   e) QR decomposition is defined as \(X = QR\), where \(X \in \mathbb{R}^{m \times n}\), \(Q \in \mathbb{R}^{m \times n}\) is a matrix whose columns are orthonormal to each other (unit vectors, whose dot products between the columns are zeros), and \(R \in \mathbb{R}^{n \times n}\) is a upper triangular matrix. The `.linalg.qr` method returns Q and R and can recover the original matrix by \(Q @ R\). Like all other linear algebra routines, `.linalg.qr` operates on the last two axes of the input tensor.
+   f) `.linalg.lstsq` solves the least squares problem for linear equations in the form \(X\Theta = Y\), where \(X \in \mathbb{R}^{m \times k}\) is the feature vectors (the independent variable) that contains k features with m observations, \(\Theta \in \mathbb{R}^{k \times n}\) is the slope term of the linear equation, and \(Y \in \mathbb{R}^{m \times n}\) is the observation outcome (the dependent variable), for n dimensions. It minimizes the square loss between the left- and right-hand side of the equation, i.e. \(||X\Theta - Y||_2^2 = \sum_i \sum^m (x_i \cdot \theta_j - y_j)^2\). As an example, suppose we would want to estimate the linear equation \(y = 2x + 5\) from a set of data points with random noise:

```
```python
import numpy as np
x = np.random.randn(100)
Y = 2 * x + 5 + np.random.randn(100)
# Two features, one feature for the input data x,
# and another feature as constant, independent of the data.
X = np.vstack([x, np.ones_like(x)]).T
theta, res, rank, s = np.linalg.lstsq(X, Y)
print(theta)
# array([ 2.04210113, 5.07653151])
