1.4 What is Cryptography?

Cryptography is a means of protecting communications in the face of third parties with malicious intent—that is, third parties that intend to steal your information or overhear your conversation—by using encryption and decryption. Among the computational algorithms that cryptography employs are SHA-256, which would be the hashing method that Bitcoin employs; a public key, which is similar to digital information of the user that is got to share with everybody; and a secret key, which is similar to electronic signatures of the user that is kept private.

Bitcoin Transactions and Cryptography

A typical bitcoin transaction details include who you want to transfer bitcoin to and how many bitcoin you want to send. Following that, the data is processed via a hashing method. The SHA-256 algorithm is used by Bitcoin, as previously stated. The output is subsequently signed using the user's private key, which allows the user to be uniquely identified. The cryptographically signed output is subsequently sent around the network for verification by other users. The sender's public key is used to do this.

Miners are users who examine a transaction to see if it is genuine or not. The transaction, along with numerous others, is then uploaded to the network, where the data can no longer be modified.

1.7 Blockchain

Blockchain technology is a method of storing data in such a manner that it is hard or impossible to alter, hack, or defraud it. A blockchain is a digital log of transactions that is copied and distributed throughout the blockchain's complete network of computer systems. Each block on the chain comprises a number of trades, and each time a new action takes place on the database, a note of that event is added to the Ledger of each participant.

Blockchain is a sort of distributed ledger technology in which information is recorded using a hash, which is an immutable electronic signature.

The Properties of Distributed Ledger Technology

Secure

Each record is encrypted separately.

Immutable

Any records that have been verified are irrevocable and cannot be modified.

Programmable

A blockchain may be programmed (Smart contracts, etc.)

Unanimous

The legitimacy of each record is agreed upon by all network participants.

Anonymous

Participants' identities are either anonymous or pseudonymous.

Timestamped

A block contains a transaction timestamp.

Distributed

For total transparency, all network members get a shared ledger.

This implies that if a single block in a chain is modified, it will be instantly clear that the chain has been tampered with. Hackers would have to modify every block to the blockchain across all distributed copies of the chain if they intended to destroy a blockchain system.

Blockchains like Cryptocurrencies are continuously expanding as new blocks are added to the blockchain, increasing the integrity of the Ledger dramatically.
