Earlier, we discussed the summarization of security and IT as they applied to physical tools like computers, smartphones, tablets, and even smart watches. Consumerization applies equally well to services, networks, and cloud resources. Using tablets became life as personal conveniences and quickly became professional workhorses, so too the social networks created for personal connection become conduite of business and security communications. The use of social media will begin to perv security and emergency coordination in the same way consumerization has made physical consumer products into the everyday days of IT and security organizations.

The line between personal and professional has become thin to nonexistent—and this is a good thing for security professionals and public safety.

# SOCIAL MEDIA FOR EMERGENCY MANAGEMENT (#SMEM)

Official public agencies like DHS and the UN are not the only groups catching the social wave. Unrelated groups involved in one way or another with security and have spontaneously adopted social media as a way to communicate among them. #SMEM, or social media for emergency management, is a hashtag shared unoially by security and first-responder organizations as both a real-time communications tool and a sort of professional network for exchanging practices. Education used to be available only in a formal educational setting has now become available to anyone with a Twitter account. Given that training and turnover are two of the perennial concerns of the security profession, this is a welcome learning forum for all of our colleagues.

# POWER SHIFT

No one can foresee what new technologies will be used for once they have set loose in the world. They have an uncanny way of shape shifting as they are created for one thing but find utility for many others. The Internet, for example, was originally created by and for researchers to exchange scientific information.
