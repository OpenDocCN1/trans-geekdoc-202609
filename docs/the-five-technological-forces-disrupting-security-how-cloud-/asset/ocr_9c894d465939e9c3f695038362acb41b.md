The initial outcomes of unsupervised learning may be useful or not, in the sense that the groupings may provide any practical knowledge that allows you to manage risk. For example, if an unsupervised algorithm was applied to access control records for a large building, it might find two major groupings: people who go in and 10 times a day (smokers) and people who go in and twice a day (nonsmokers). These observations are interesting, if not obvious, but highly relevant to security management. On the other hand, we might find other classifications that provide entirely new insights about groups of people, locations, or times of day closer scrutiny. That's what's fun about unsupervised learning: it feels like the computer is a genius and can just figure out.

Supervised learning describes methods of data analysis where the investigator is pursuing a particular hypothesis and wants to know whether different groupings of data are useful for predicting the outcome or target value of an interest. Supervised learning works by training an algorithm on set of data that we have explained the relationships to be normative or predictive for future sets. Neural networks are often programmed this way, for example, make associations between inputs and outputs, specifying an exact mathematical or functional relationship between them. The algorithm compares attributes to known outcomes or behaviors and draws inferences about which attributes are relevant predictors of those outcomes or target values. Once the algorithm has been trained, it can be applied to new data sets and predict which elements of that set will behave like the data in the training set. Video object identification, for example, can use this general approach to learn what objects look like. The security application is usually to find bad actors, but it could just be well to identify equipment failures, as in many industrial settings.

Reinforcement learning is an iterative process where an algorithm seeks to maximize some value based on rewards for being right. Think of a laboratory mouse to press a button in order to get food. The difference is that these algorithms can do much more quickly and on larger sets of data and choices than human. One of the classic uses of this in a commercial context is elevator scheduling, where the goal is to move the greatest number of people as quickly as possible with little energy as possible. One could extend this to managing the rate at which people were allowed through a turnstile feeding an elevator lobby so that it not only never overcrowdedded but also didn't keep people needlessly waiting.
