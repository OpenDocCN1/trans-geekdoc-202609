# MOBILE FIRST

All of these examples show that the “mobile-first” design strategy is changing development priorities for security products, in nearly every vertical market. The mobile-first approach nerfs the old order of software development priorities, where desktop versions of applications were the primary design consideration and subsequent adaptation to mobile platforms was often less than an afterthought. Instead, mobile first says that new features should originate on the small screen and then migrate to larger devices. To see why mobile first is so important, consider the way that new features were traditionally developed and released. The primary design thinking focused on the desktop browser experience. Mobile apps then started their lives as an attempt to shrink down the user experience, using responsive design techniques as best they could. This process variably resulted in compromises and the removal of features. As mobile apps matured, the feature sets grew until they reached some approximation of the full-size version, but it never felt like a good fit. This strategy ultimately recreates the desktop on a smaller screen, but it does not capture the unique advantages of the mobile platform.

Mobile platforms have many capabilities that desktops do not, and they dramatically change the user experience and utility than can be delivered. As a result, the mobile design operates from a completely different viewpoint than the desktop frame of reference. Geolocation—the use of GPS and other positioning technologies—is biggest differentiator between mobile and fixed frames of reference. Location is clearly a relevant piece of information for security applications, usually leveraged with geofencing or the ability to detect whether a smartphone is within a certain geographical boundary. Most residential apps, for example, provide a geofencing option to automatically arm or disarm an alarm system. In commercial security, mobile credentials can be position-aware, so that they provide the added layer of security being activated when they are near the property for which they are valid.
