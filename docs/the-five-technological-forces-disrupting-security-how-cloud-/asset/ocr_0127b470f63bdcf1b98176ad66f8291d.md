In what's undoubtedly getting to be a familiar refrain by now, the cloud is changing the dynamics of that marketplace and therefore changing what will be available to all end users of security systems. Just as we saw with offerings like AI as a service and big data as a service, there are a growing number of real-time analytics services available in the cloud as a service. This makes them all more affordable. More importantly it reduces, although it does not eliminate completely, the need for staff with deep training on how to assemble all of these tools.

That's important, because for all the promise of these technologies, the limiting factor for adoption is still the problem of finding qualified people to handle them.
