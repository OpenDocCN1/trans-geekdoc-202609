The first lesson from big data analytics in cybersecurity is how to speed up the process of consolidating and correlating threat information. To do that, we had to ditch traditional databases, learn how to digest unstructured data, and move to clustered computing environments that provide much higher throughput when needed. Not coincidentally, many of the underlying tools used for threat intelligence are the same as that power the largest search engines. The engines of this new generation of tools mark a departure from use of tradition security information and event management (SIEM) tools, which begs the question of who will supply the next generation of tools for big data in physical security.

The second takeaway is that more data do not always equate to better information or informed action. Other things being equal, 100-fold increase in raw data will result in 100-fold increase in false alarms. No security organization can function with that additional load unless there is a corresponding improvement in the algorithms under the hood. This is unlikely to happen without the use of machine learning and an approach that includes enterprise-specific training data that learn the unique signatures of its own complement of data collection techniques. What this means that organizations will have to adapt a new generation of solutions that are better informed by data science, because the old filtering and alarm management frameworks cannot keep pace.

The third lesson is that all security equipment needs to be treated like the network it is. Malware is discriminate about what it attacks, and many security devices run the same operating systems that have been successfully attacked in an IT context. This observation forces the issue of either strictly isolating security networks (which is a head-in-the-sand approach) or engaging in deeper cooperation with IT (which is probably not a bad idea anyway). Among other precautions, this implies continuous monitoring of security equipment for infections, outdated firmware, and aberrant behavior.

The final lesson may be that common cyber enemy will forge awareness that there is no longer a choice about convergence. That discussion has been going for a long time, but most organizations have not achieved much of anything near a complete integration between physical security and logical security. Identity was an initial point of integration between the two because both domains need to authenticate users, whether for building access or network access.
