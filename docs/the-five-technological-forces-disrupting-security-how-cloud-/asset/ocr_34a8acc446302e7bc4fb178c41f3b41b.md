In the aggregate, however, sensor data are a high-velocity data source. It is a nonstop, real-time information flow that must be quickly indexed in order to have any preventive device. The current generation of sensors IP protocols that connect each sensor to the Internet, either directly or via a gateway. This connection provides a pathway to cloud-based security analytics platforms that can extract meaning from this sea of data.

These tandem developments in sensor connectivity and cloud computing have enabled the security of data at a larger scale than ever before possible. The concentrated data streams from all the remote locations in a large chain, for example, can provide the basis for deeper analysis of events at each individual location. In a broader municipal security setting, event data from private businesses and public spaces could be aggregated to form a larger data set with deeper connections and parameters. The resulting analytics could yield far more valuable intelligence than the sum of its individual parts. Cloud-based security systems now consume these rich, multisourced data streams, putting them in a position to deliver higher value intelligence back to their customers.

Additional high-velocity sources are becoming available for physical security due to the ubiquity of smartphones and wearable IoT technologies. One of the most interesting is the capture of Bluetooth and Wi-Fi signals that smartphones use to discover other devices in their neighborhood. These can be aggregated for a variety of security purposes. The monitoring of “presence” tops the list because smartphones are a decoy for the number of people in a room or public space. Indoor positioning systems can use these signals for trilateration of smartphone locations and populate map showing traffic patterns and occupancy throughout a building.

As IoT devices continue to grow in number, more of these high-velocity sources will be available for security analytics.

# LESSONS FROM CYBER SECURITY

Cyber security is lighting the path for the development of big data applications in physical security. There are tens of millions of website attacks per day and billions of malware exploits, to say nothing of personalized phishing attacks and just plain old-user error. Sorting through all of this is daunting enough, until you consider it's mixed with trillions of legitimate messages at the same time. This turns into a problem of gargantuan data collection and real-time analysis.
