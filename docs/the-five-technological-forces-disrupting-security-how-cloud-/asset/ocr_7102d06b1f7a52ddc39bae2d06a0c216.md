# Standards Organizations and Consortia 121

The SIA Committee recently established the cloud, mobility, and IoT subcommittee to examine interoperability, authentication, identity, and cyber-security issues for the adoption of IoT in the physical security. The rationale for developing this subcommittee was based on the following observations:

+   - IoT devices will be the growing source of data in physical security systems.
- Security systems can harvest this value only if there are norms to build secure IoT deployments that operate with security management tools.
- IoT devices will introduce new communication protocols that need to be integrated into security systems and services.
- IoT can enhance physical security only if cybersecurity risks are properly mitigated.

The committee is also examining standardization of mobile credentials, specifically the use of digital credentials with access control readers via Bluetooth low energy (BLE). In broad terms, these standards would play a similar role to the Wieand and card-to-reader standards that have been part of the industry for the past several decades. In the absence of standards for mobile credentials, the industry is at risk of having multiple proprietary protocols, which retard adoption, add cost, and ultimately not serve the interests of end users. The standards created by this project could form the basis of mobile-to-reader interaction for the next 20–30 years.

# Industrial Internet Consortium (IIC)

The Industrial Internet Consortium was founded in 2014 as a not-profit partnership dedicated to advancing the growth of IoT for commercial and industrial applications. Their goals are to drive innovation with industry-specific use cases, develop a reference architecture for interoperability, influence the global standards process, and facilitate innovative approaches to IoT security. The IIC has published a number of IoT reference frameworks that are relevant to both manufacturers and system integrators (and, therefore, to security organizations).

The IIC has organized its activities around five vertical industry groups: health care, energy, transportation, smart cities, and manufacturing. All of these verticals intersect with security, particularly at the framework level where the IIC has created two publications to be influential in end-user organizations in all of these market segments.

The Industrial Internet Reference Architecture² is a standard-based approach to guide system architects building IoT systems in common framework.
