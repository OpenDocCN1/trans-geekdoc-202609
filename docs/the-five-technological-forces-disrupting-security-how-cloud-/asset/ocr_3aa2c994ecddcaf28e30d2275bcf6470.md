Analytics may well prove to be a better meeting ground for physical and logical security, but once again only if the ROI is there. Merged data sets and real-time data streams would provide arguably better situational intelligence for any algorithmic approach. Getting there will require real work, but it's not difficult- today as it was once. Across nearly every industry you can think of, the software developers have converged on APIs that use the representative state transfer (REST) model for exchanging information between systems. This widely understood programming interface makes it much easier for application stacks from disparate industries or departments to achieve functional integration. I see users doing all the time for everything from real-estate management to health club membership to security analytics. The fact that the same API will work for all of these different types of system integration provides that we are getting closer to at least partial, purpose-built convergence between IT and security.

Our big data analytics will thank us.

AI has made impressive strides in recent years: medicine, finance, robotics, science, photography, and almost any subject area where problems can be represented as data (which is almost everything). The term AI is used in many ways, some more precise than others. The classic concept of AI is that it's synonymous with conscious machines, like HAL from 2001: A Space Odyssey—computers that think, feel, create, and in some sense exert their own free will. Back in the 1970s, it meant building a software model of the world or a particular domain that could be used to reason about things in that domain. If we fast-forward to the present, the notion of building an all-knowing AI system has been supplanted with the idea that it's better to create many micro intelligences that are each good at one specific task.
