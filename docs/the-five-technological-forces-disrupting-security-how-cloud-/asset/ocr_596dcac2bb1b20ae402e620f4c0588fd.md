However, this model is not practical for the vast majority of businesses with few IT staff. Even worse, it throws away the cost and management benefits of public clouds.

As a business phenomenon transforming the physical security industry, public clouds will be the assumed model throughout this book. Private clouds have their place, but they don't fundamentally change the business or computing models, so they are less relevant to this discussion.

First, almost by definition, public clouds are the most frequently used deployment model for publicly available services. Large system integrators need this type of deployment model to operate a business efficiently, particularly for large enterprise clients. Smaller installation companies need this model to compete with the bigger players.

Second, the demand for mobile access to cloud services favors a public cloud solution. With a public cloud service, every mobile application deployed to a customer's phone can connect with the same services points (URLs) upon download. Using a private cloud service, by contrast, forces a configuration burden on each and every mobile instance.

Last and perhaps most importantly, only public cloud deployments ever scale to the size needed to enjoy the economies of scale that deliver the cost advantages of cloud computing.
