Anomaly detection is also now becoming a possibility for physical security systems that can harness the power of big data and cloud computing together.

Anomaly detection is a classification problem. For example, in the case of three shoes and a banana, it's the fruit that is different. In that case, it seems obvious that you can tell by inspection how and why one element in the data set is different from the others. We know this because we have preexisting classifications for everything in the data set: footwear and fruits. In real-world data sets, there may be no obvious classification scheme in place. Normal and abnormal are relative terms, and what's abnormal one day can be the next. This is why fixed classification may work for some problems, but not for others. Big data sets are more challenging because a classification scheme that is even off will end up producing an unacceptable number of false positives or negatives. Fine-tuning is of the essence.

Analytics are catching up with anomaly in big data with the same kinds of learning techniques we've discussed elsewhere in this section. Fine-tuning is beyond the reach of human observers with data sets this large, so we need to rely on machine learning to do it. If we go back to our IoT example of capturing smartphone signatures from Bluetooth and Wi-Fi signals and imagine using this technique in a large public place, it's clear that the data volume and patterns will exceed anyone's guess about what to look for. Algorithms could quickly spot anomalous behavior, like lingering when everyone is moving or moving when everyone is standing. Neither of these may be worrisome in its own right, but they can help focus our attention for further investigation.

The relevance of this high-volume, high-velocity analytics for physical security is increasing as inexpensive IoT sensors, ubiquitous video, and mobile tagging are multiplying at our disposal.
