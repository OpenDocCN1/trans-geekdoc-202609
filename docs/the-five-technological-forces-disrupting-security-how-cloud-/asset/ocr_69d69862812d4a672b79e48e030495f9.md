There was a break in the cloud.

# LEADING INDICATORS

All the current data suggests that cloud computing has crossed over the tipping point for enterprise applications and irreversibly changed the delivery model for corporate software purchases. Numerous sources place cloud-based software penetration rates at well over 50% of new enterprise software sales.

The security industry finally appears to move in the same direction, albeit a slower pace. According to a recent poll in Security Systems News, over 52% of respondents said that the cloud is here to stay in security applications. One integrator said, "cloud is clearly inevitable, and the integrators are experiencing with it will be the victors."

# THE BARRIERS ARE DOWN

Many of the barriers present in the first decade of cloud computing have now come down. Information security for cloud applications, while a frequent topic of discussion, is just as worrisome for keeping their applications housed inside corporate data centers. Concerns about data retention and audit compliance have become a more routine checklist item that now cloud providers voluntarily submit to external reviews and attendance.
