While the security industry was following its own product road maps for video, the rest of the technology was pursuing a different path toward better analytics. Massive quantities of video that have been uploaded to the likes of YouTube, Facebook, Vine, and others were crying out for analytics that would make them searchable and commercially useful. With the explosion in the number of cameras in smartphones and now cars, drones, home automation systems, and other IoT devices, the human stockpile of video is growing at an unimaginable rate. Because of all these videos are stored in the cloud, a new generation of analytics is growing in accuracy and utility while dropping in cost at the same time.

New analytics solutions are now available from companies like Google via their Cloud Video Intelligence API, and they are completely independent of any particular security system or camera vendor. If you have some video data, you can submit via the API, and it will return analytics for a list of characteristics, depending on what you've asked it to do. Want to count how many people passed through a scene? Ask it to do for that. You can do that too. It also provides many other analytics like loitering, falling, movements, and tracking, growing among a list of capabilities that are constantly improving.

There are two significant aspects to developments like this. The first is that you can pick and choose which public API you would like to use for any given analytics task. You don't need to restrict yourself to the solutions provided by a single vendor, and you can change APIs or service providers you use for different types of analytics. The effect is to create an on-demand analytics marketplace where the best algorithm wins. The second significant aspect of kinds of analytics is that they have volumes of data that a single surveillance system—or even a traditional surveillance vendor—could capture on its own. Think of it this way; when you have millions of hour of cat, you become very good at identifying cats. What's also happening in this cloud-based consumption model is that the algorithm behind the API gets better every day because it is continually trained against more and more data.
