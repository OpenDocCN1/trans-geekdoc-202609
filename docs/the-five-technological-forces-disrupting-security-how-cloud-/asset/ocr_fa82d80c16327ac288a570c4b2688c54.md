Most security organizations would get very little benefit from running out and installing, say, a distributed storage cluster and an analytics engine. They are both raw tools that need to be customized, programmed, and integrated with data sources before they can produce useful results. They are typically not activities most security system integrators are equipped to perform, nor would it be cost effective to do so on a one-off basis. Security organizations need a finished product that does something useful on the day it is commissioned. Raw tool sets don’t do that out of the box. How useful are a stack of boards and a bucket of nails when what you really want is a house?
