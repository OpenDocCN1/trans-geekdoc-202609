Security applications of these basic concepts include the following:

+   * Is the number of alarms today above or below the mean?

* Do my properties compare with each other?

Regression and trending—a single number like a mean or median is not enough to tell the whole story. Sometimes, a set of data needs to be evaluated to see how it changes over time. Linear regression is a statistical technique for modeling the relationship between a dependent variable (Y) and one or more independent variables (X). In this mathematical model, the goal is to find a straight line (or curve) that fits a scattered set of data points on an X-Y plot. The equation for the line tells you the value of interest changes over time. With this information, you can now predict what its value might be, 3 months from now. While this method may require simplifying assumptions about the data, it can be a good approximation of a trend, and sometimes, that's all we need. The proverbial frog in the heating pot of water could use this method to see that if he doesn't jump out now, there's trouble ahead.

Security applications of regression include the following:

+   * Are losses going up or down over time? At what rate?
* Are alarms rising or falling?
* False alarms growing or declining as a percentage?
* Did error rates decline after we invested in new equipment?
* Did our new policy reduce the incidence of tailgating?
