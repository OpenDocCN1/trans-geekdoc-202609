# WHERE ARE THE SOLUTIONS?

The question then becomes: where can I find complete big data solutions for physical security? Who are the software vendors that will be creating solutions truly ready to use?

Unfortunately, as of this writing, my research turns up no big data products for the commercial security market. There are, however, point solutions that attack specific problems with data analytics. Point-of-sale transactions coupled with surveillance video generate data sets for detecting fraud and theft for cash register transactions. Some video analytics techniques look like big data problems when applied at scale. They are divorced from the other security data streams in the enterprise, and they act only on a single organization's security data, limiting their ability to learn from larger data sets.

It is hard to imagine big data solutions for commercial security will emerge as traditional on-premise licensed software. Instead, they are far more likely to be launched cloud services. To put this in context, this is not a prediction for the security industry. There are virtually no new categories of software emerging under the enterprise licensing model in any industry. In finance, not in CRM, not in ERP, not in retail, not in health care, and not even in so-called desktop software. They are all being created or converted to cloud-based SaaS products.

The same is true for the analytics that will power big data solutions for physical security. IBM, a leader in this space, offers its Watson analytics engine as a SaaS service. AWS provides dozens of big data components and solutions, all available on a monthly subscription basis. Even companies that have been traditional leaders in licensed analytics software are transitioning to SaaS delivery models. This shift shows the way forward for big data solutions in physical security.

These cloud platforms show where products emerge, but they are just tools. They need to be shaped into useful instruments for the security market. New applications will arrive from a number of different providers, such as

+   - existing security solutions that add analytics as an option,
- start-ups with general analytics applied to specific verticals,
- custom development for very large end users or industries,
- segment-specific solutions for, for example, critical infrastructure,
- residential crossovers that already aggregate big data.
