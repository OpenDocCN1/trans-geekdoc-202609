Bluetooth is familiar to most of us because of its prevalence in consumer products from cars to headphones to electric toothbrushes. Since the Bluetooth Smart (low energy) version was introduced in 2010, the standard has become attractive for IoT devices that require long-battery lifetimes. Bluetooth is also emerging as the dominant technology for mobile credential exchanges that use smartphones instead of a traditional access control card or fob. Bluetooth use is growing in other commercial security applications, such as sensor networks, doors locks, and readers. Its 90% penetration rate in smartphones guarantees it long life shelf for both personal and commercial systems.

Wi-Fi is so common and well-known that I hesitate to explain it all. However, it is important and enduring standards for physical security systems and will be for a long time to come. Wi-Fi is fast and secure, but it is not a low-power network like many of the others we have addressed in this context. Wi-Fi provides system integrators, an IP connectivity option that does not require pulling cables. Commercially available products such as door controllers, readers, wireless locks, and network cameras all leverage this advantage. Security organizations and facility managers benefit from less disruptive installations, with the potential for cost savings due to reduced labor.

So far, the wireless technologies we have discussed are short-range local area network solutions. LPWAN is a new class of area networks that provide low-cost, low-power connectivity over ranges similar to cellular technology (approximately 10 miles from the nearest tower). There are currently multiple standards, both proprietary and open, which include LoRaWAN, Sigfox, NB-FI, and Weightless. Any of these networks can simplify the design of security systems by eliminating the need for any local network infrastructure. Sensors and actuators can operate directly on these wide area networks, this capability is especially useful for smart cities, campuses, and other environments where larger distances are a consideration.
