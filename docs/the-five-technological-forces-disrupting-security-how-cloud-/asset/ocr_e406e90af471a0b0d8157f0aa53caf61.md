This sort of hype and confusion is typical during the early stages of new technologies. Unfortunately, it slows down adoption, while prospective customers sort out competing claims and fake news.

Fast-forwarding to the present, a quick look at conference topics or product marketing literature indicates that nearly everyone in the industry has become a cloud evangelist. Hardly any company has a cloud store of some sort.

# INTERNET PROTOCOL BLAZES THE TRAIL

Internet protocols (IP) define the Internet, which course enables the cloud.
These protocols emerged while creating ARPANET, a Department of Defense precursor to the public Internet that linked the computers at research facilities across the country into a single network to share data and computing tasks.
Since the first widely distributed protocols in 1974, the collection of technical specifications for the Internet sits at roughly 10,000 documents (and counting).

As in most industries, IP protocols first gained the attention of the physical security (not cloud computing itself). Used mostly for point-to-point connections on local area networks (LANs), the IP protocol suite enabled security software to communicate with peripheral devices on networking cables rather than older, clumsier types of wiring. While this was a big step forward in terms of cost and convenience, it did nothing to the fundamental architecture of security systems. You still had a local PC running client-server software to control local panels, cameras, and other peripherals.

The IP-based products of the early 2000s improved the wiring of security systems, but they did not necessarily change the topology or structure. In an era when Microsoft dominated the industry, nearly all security applications required users to install client software. These systems were usually accessible only on the corporate network or by dial-up VPN. Security systems arrived at the doorstep of IP's promised land—and stopped.

Today, IP devices pervade the industry. Thick clients on PCs are all dead. IP cameras outsell analog cameras. The remaining on-premise server systems provide browser-based interfaces for access control and video management accessible on the local network, albeit not from a cloud service. On the whole, the industry has made a complete transition to IP communications, with only a few holdouts.
