# Table 10.1 Some Authorize.net Response Fields

| Field | Name |
|---|---|
| 0 | Response Code |
| 1 | Response Subcode |
| 2 | Response Reason Code |
| 3 | Response Reason Text |
| 4 | Authorization Code |
| 5 | AVS Response |
| 6 | Transaction ID |
| 7 | Invoice Number |
| 8 | Description |
| 9 | Amount |
| 10 | Method |
| 11 | Transaction Type |
| 12 | Customer ID |
| 13–31 | Customer Information |
| 38 | CCV/CVV Response Code |
| 50 | Last Four Digits of Card |
| 51 | Card Type |

The full breakdown is available in the Authorize.net manual. The most important of these is really the *response code*. The possible values are:

+   - Approved
+   - Declined
+   - Error
+   - Held for Review

In short, if the first element returned by the response has a value of 1, the payment was authorized. If it's not 1, then a problem occurred. The specific type of problem will be reflected by the *response reason code* and the *response reason text*. Again, the Authorize.net AIM manual and online documentation lists all the possible codes and messages.
