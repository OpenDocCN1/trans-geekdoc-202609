```
AS gc ON gc.id=sc.general_coffee_id LEFT OUTER JOIN sales ON
(sales.product_id=sc.id AND sales.product_type='coffee' AND ((NOW()
BETWEEN sales.start_date AND sales.end_date) OR (NOW()) >
sales.start_date AND sales.end_date IS NULL))) WHERE
c.product_type="coffee";
```

To be clear, the SELECT...UNION...SELECT query is the same as the one
in the get_shopping_cart_contents() stored procedure, except that the
user_session_id value is now part of the selection, instead of part of the
WHERE condition. Figure 9.11 shows two SELECT queries run on this VIEW
table, with the latter automatically reflecting changes in the carts table (due to
customer actions).
