To repeat what's already been said, the $(); syntax in jQuery is a way of executing some JavaScript once the page has been loaded. The specific code to be executed is placed within an anonymous function.

The anonymous function selects every element on the page that has a class of calendar. To that selection, the datepicker() method is invoked, thereby converting them into Datepickers. Passed to the datepicker() method are two properties. The first, dateFormat: "yy-mm-dd", indicates the format that the selected date should be in. This format matches what is usable in the database queries. The second property, minDate:0, indicates that the earliest date that can be selected is the current date (zero days from now).
