# # Updating list_coffees.html

For list_coffees.html to take advantage of the new function, you just need to
replace this line:

```
echo "<option value=\"{$row['sku']}\">{$row['name']}</option>\n";
```

with:

```
echo '<option value="" . $row['sku'] . "">' . $row['name']. 
get_sale_price($type, $row['price'], $row['sale_price']) . '</option>';
```

> tip
> 
> In the downloadable code, you'll
> see this modified view file,
> named list_coffees2.html, to
> avoid confusion.

You'll notice that I purposefully switched from using double to single quotation
marks here. When you use which quotation marks is a personal preference,
but because a function call cannot be integrated into double quotation marks
anyway, I thought a switch to single quotation marks would be logical.
