As you would expect, much of this functionality will be like the category.php script.

+   1. Create a new PHP script in your text editor or IDE to be named page.php and stored in the Web root directory.

+   2. Include the configuration file:
+   
+   ```php
+   <?php
+   require('./includes/config.inc.php');
+   ```

+   3. Require the database connection:
+   
+   ```php
+   require(MYSQL);
+   ```

+   4. Validate the page ID:
+   
+   ```php
+   if (isset($_GET['id']) && filter_var($_GET['id'], FILTER_VALIDATE_INT,
+   array('min_range' => 1))) {
+   }
+   ```
+   
+   This is the same validation used with the category ID. If your version of PHP
+   does not support the Filter extension, you could use:
+   
+   ```php
+   if (isset($_GET['id']) && ((int) $_GET['id'] >= 1)) {
+   ```

+   5. Get the page info:
+   
+   ```php
+   $q = 'SELECT title, description, content FROM pages WHERE id='
+   . $_GET['id'];
+   $r = mysqli_query($dbc, $q);
+   ```
+   
+   A simple query retrieves three fields from the pages table for one record.
