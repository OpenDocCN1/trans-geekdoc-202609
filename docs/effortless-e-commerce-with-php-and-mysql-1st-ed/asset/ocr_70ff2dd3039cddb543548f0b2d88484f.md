Since the MAX_FILE_SIZE hidden form input is a recommendation that's easy to circumvent, it's best to check the file's size using PHP, too.

> A stricter way of validating a PDF's type is to read in the file's binary data and make sure it matches the PDF specification.

Next, the file's type is validated. The first part of the conditional checks if the type is not equal to application/pdf, which is the MIME type the browser will associate with an uploaded PDF.
