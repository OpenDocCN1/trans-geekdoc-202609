```
if (!$live) {

```

For a nonlive site, it's best to immediately be notified of any problems. Here, the error message will be printed within a <DIV> that's been assigned a class of error. # 9. If the site is live, send the error in an email:

```
} else {
    error_log($message, 1, $contact_email, 'From:admin@example.com');
}
```

The error_log() function can log errors in different ways. Its first argument is the error message. The second is a destination type, with 1 meaning email (the default of zero would send the message to the operating system's log). The third argument is the destination itself; with an email, this is the "to" email address. The fourth argument is only for sending emails and is for adding any additional headers, such as the "from" email address.

**note**

Hopefully, in a fully tested, live site, customers will never see even the generic error message, because all the bugs will have been squashed already.
