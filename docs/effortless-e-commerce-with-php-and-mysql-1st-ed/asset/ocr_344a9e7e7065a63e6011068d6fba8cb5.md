# # Creating the View Files

The checkout.php script uses three view files:

+   - checkout.html
+   - checkout_cart.html
+   - emptycart.html

The first file is included if there are products in the shopping cart. The second file is included by the first (which is why there’s no reference to it in checkout.php). The third has already been defined.
