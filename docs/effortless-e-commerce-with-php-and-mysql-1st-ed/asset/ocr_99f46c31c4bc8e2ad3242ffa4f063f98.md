# 8. Display the content if the user's account is current:

```
```php
if (isset($_SESSION['user_not_expired'])) {
    echo "<div>{$row['content']}</div>"
;
} elseif (isset($_SESSION['user_id'])) { // Logged in but not current.
    echo '<p class="error">Thank you for your interest in this content, but
your account is no longer current. Please <a href="renew.php">renew
your account</a> in order to view this page in its entirety</p>';
    echo "<div>{$row['description']}</div>"
;
} else { // Not logged in.
    echo '<p class="error">Thank you for your interest in this content.
You must be logged in as a registered user to view this page in its
entirety.</p>';
    echo "<div>{$row['description']}</div>"
;
}
```
```

This conditional dictates what is shown on the page, based upon the user viewing it. Only logged-in users with current accounts—those who have a $_SESSION['user_not_expired'] value—can see the content itself. The other user types see only the description, along with a message appropriate to their situation.
