The move_uploaded_file() function will transfer only files uploaded via HTTP POST, so it can't be manipulated to move other files around on the server. Its first argument is the file to move, which is represented by the file's temporary name (something like /tmp/php4902). The second argument is the file's destination, which includes both the directory and file name.

Next, three pieces of information about the file are stored in the session for later reference. This includes the file's new name, its size, and its original name. Then a message is displayed indicating that the file has been handled.

If the file could not be moved, an error message is triggered and the uploaded file is removed (so it's not cluttering up the temporary directory).
