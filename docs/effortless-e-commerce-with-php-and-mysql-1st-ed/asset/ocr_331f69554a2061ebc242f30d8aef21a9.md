# 9. Create the first and last name inputs:

```
<fieldset>

'text', $Billing_errors, $Values); ?</div>
<div class="field"><label for="cc_last_name"><strong>Last Name </strong></label><br /><?php create_form_input('cc_last_name',
'text', $Billing_errors, $Values); ?</div>
```

The rest of this form is largely like the shipping form, except that each input is prefaced with cc_. An important addition is that each call to create_form_input() includes the fourth argument. The fourth argument indicates where an existing value should exist: in $_SESSION or $_POST. The value of the $Values variable will have been determined in the billing.php script (as you've already seen).
