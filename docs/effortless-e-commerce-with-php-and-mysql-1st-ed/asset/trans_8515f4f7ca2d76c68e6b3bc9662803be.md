## 显示 PDF 内容

与 HTML 内容一样，在网站上显示 PDF 内容需要两个脚本。第一个 pdfs.php 仅列出目录中的每个 PDF，并提供查看 PDF 本身的链接。第二个 view_pdf.php 检索并显示特定 PDF，但只有在验证用户后才会显示。
