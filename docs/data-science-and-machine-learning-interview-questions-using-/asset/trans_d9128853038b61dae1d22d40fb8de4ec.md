### [Q2: 解释如何执行正态性检验。](#toc.xhtml#c05q2a)

*答：* 正态性检验是以高斯分布形式检验数据分布的检验。

每种检验对输入和输出都有以下假设：

**输入假设：**

*   每个样本中的观测值是独立同分布的。

**输出假设：**

*   H0：样本服从高斯分布
*   H1：样本不服从高斯分布

其中包含三种类型的检验。

所有三种类型均作为 scipy 的一部分受支持。

```
import scipy.stats as ss

# Shapiro-Wilk 检验
stat, p = ss.shapiro(data)

# D’Agostino’s K^2 检验
stat, p = ss.normaltest(data)

# Anderson-Darling 检验
result = ss.anderson(data)
```

**结论：** 如果计算出的 p 值 < alpha，我们可以得出拒绝原假设的结论，否则无法拒绝。

### [Q3: 解释如何执行相关性检验？](#toc.xhtml#c05q3a)

*答：* **皮尔逊相关系数**

检验两个数据集之间是否存在线性关系。

**输入假设：**

所有这些均针对观测值：

*   它们是独立同分布的
*   它们服从正态分布
*   它们具有相同的方差

**输出假设：**

*   H0：两个样本相互独立。
*   H1：两个样本存在依赖关系。

```
import scipy.stats
corr, p = scipy.stats.pearsonr(data1, data2)
```

根据 corr 和 p 的值，我们可以判断两列之间是否存在关系。

**斯皮尔曼等级相关和肯德尔等级相关。**

两者具有相同的输入和输出假设。

检验数据集之间是否存在单调关系。

**输入假设：**

所有假设均针对观测值：

*   它们是独立同分布的
*   它们可以被排序

**输出假设：**

*   H0：两个样本相互独立
*   H1：样本之间存在依赖关系

**斯皮尔曼等级相关**

```
import scipy.stats
corr, p = scipy.stats.spearmanr(data1, data2)
```

**肯德尔等级相关**

```
import scipy.stats
corr, p = scipy.stats.kendalltau(data1, data2)
```

根据 corr 和 p 的值，我们可以判断两列之间是否存在关系。

**卡方检验**

检验两个分类变量之间的独立性：

**输入假设：**

*   观测值相互独立。
*   就列联表而言，每个单元格需要 25 个或更多样本。

**输出假设：**

*   H0：两个样本相互独立。
*   H1：样本之间存在依赖关系。

```
import scipy.stats
stat, p, dof, expected = scipy.stats.chi2_contingency(table)
```
