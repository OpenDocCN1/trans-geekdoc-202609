## Q11：解释 Python 之禅。

**答：** 资深 Python 专家 Tim Peters 简练地将 BDFL（仁慈的终身独裁者）关于 Python 设计的指导原则浓缩为 20 条格言，其中只有 19 条被记录了下来。

### Python 之禅

- 优美胜于丑陋。
- 显式胜于隐式。
- 简单胜于复杂。
- 复杂胜于繁琐。
- 扁平胜于嵌套。
- 稀疏胜于稠密。
- 可读性很重要。
- 特殊情况不足以打破规则。
- 尽管实用性胜过纯粹性。
- 错误绝不应默默通过。
- 除非显式地将其屏蔽。
- 面对歧义，拒绝猜测的诱惑。
- 应该有一种——且最好只有一种——显而易见的解决方法。
- 尽管这种方法起初可能并不显而易见，除非你是荷兰人。
- 做总比不做强。
- 尽管不做往往比*盲目地*去做要好。
- 如果实现难以解释，那是个坏主意。
- 如果实现容易解释，那可能是个好主意。
- 命名空间是个绝妙的主意——让我们多多利用它！

## Q18：解释 ALL 和 ANY。

**答：** `ALL` 仅在所有条件均为 TRUE 时返回 TRUE。

`ANY` 只要有一个条件为 TRUE 就返回 TRUE。

```
lst = range(20)
print(all(value > 18 for value in lst)) # 返回 false，因为 range 从 0 开始

lst = range(21, 100)
print(all(value > 18 for value in lst)) # 返回 true，因为 range 从 21 开始
print(any(value > 18 for value in lst)) # 返回 true，因为 22 大于 18 且为 true
print(any(value < 18 for value in lst)) # 返回 false，因为不存在满足给定条件的值
# condition
```

## Q20：解释 Python 支持的数据类型集合？

**答：** Python 支持四种数据类型集合：

### 列表

- 以类似于其他编程语言中数组的方式存储数据。
- 它是可变的，可以添加、减少或删除项目。
- 索引从零开始。
- `[]` 用于表示该集合是列表。
- 可以是同质的，也可以是异质的，即存储相同或不同数据类型的数据。
- 可以包含重复项。

### 元组

- 不可变集合，即无法更改元素。
- 用 `()` 表示。
- 同样可以是同质的和异质的，即存储相同或不同数据类型的数据。
- 可以包含重复项。

### 集合

- 集合中没有重复项。
- 使用 `{}` 符号。

### 字典

- 以键值对的形式存储数据。
- 用 `{}` 表示，每个项目之间有 `:` 分隔。
- 键必须是不可变对象。

## Q23：解释列表的 CRUD（创建、更新和删除）操作。

**答：** ### 创建

```
lst = [11, 22, 33, 44]
```

上述语句创建了一个名为 lst 的列表。

### 创建空列表

```
lst = []
```

上述语句创建一个空列表。

### 在列表中添加单个元素

```
lst.append(55)
```

### 添加另一个列表的元素

```
lst.extend([44, 44, 33])
```

### 连接列表

连接是将两个列表合并。

以下代码将两个列表相加，并创建一个包含两个列表所有元素的新列表 c。

```
a = [1, 2, 3, 4]
b = [5, 65]
c = a + b
print(c) # 输出 1,2,3,4,5,65
```

### 使用值移除元素

```
a = [1, 2, 3, 4]
a.remove(3)
print(a) # [1, 2, 4]
```

在上述代码中，值为 3 的元素被移除。

### 使用索引删除元素

```
a = [1, 2, 3, 4]
del a[2] # 移除索引 2 处的元素
print(a) # [1, 2, 4]
```

### 清空列表

```
a = [1, 2, 3, 4]
a.clear()
print(a) # 打印 []
```

### 列表长度

要打印列表的大小，使用 `len` 函数。

```
a = [1, 2, 3, 4]
print(len(a)) # 打印 4
```

## Q24：解释字典中的操作。

**答：** ### 创建

```
sdict = {1: 'one', 2: 'two'}
```

上述语句创建一个包含两个项目的字典，键为 1 和 2，对应的值分别为 one 和 two。

### 创建空字典

```
sdict = {}
```

### 添加键值对

```
sdict = {}
sdict[3] = 'three'
```

上述语句在字典中添加一个项目，键为 3，值为 three。

### 从另一个字典添加或更新元素

从另一个字典添加新元素。

```
dict1 = {1: 'one', 2: 'two'}
dict2 = {5: 'five'}
dict1.update(dict2)
print(dict1) # 打印 1:one,2:two,5:five
```

从另一个字典更新现有元素。

```
dict1 = {1: 'one', 2: 'two', 5: 'FIVE'}
dict2 = {5: 'five'}
dict1.update(dict2)
print(dict1) # 1:one 2: two 5: five
```

在上述示例中，键 5 的值从 FIVE 替换为 five。

因此，更新取自 dict2。

### 清空字典

```
dict1 = {1: 'one', 2: 'two', 5: 'FIVE'}
dict1.clear()
print(dict1) # 打印 {}
```

### 字典长度

`len(dict)` 获取字典的长度
