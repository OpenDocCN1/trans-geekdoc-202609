## Q54: Explain steps involved in reading and writing a file?

**Ans:** In both cases, three steps are involved:

1.  Opening the file.
2.  Reading or writing the file using corresponding functions (`read` or `write`).
3.  Closing the file.

**Write example:**

```python
a = open('hello.txt', 'a')  # opens a file in write mode
a.write('welcome to files with python')  # writes this line in file
a.close()  # closes the file
```

The above code writes the welcome message to `hello.txt` file.

**Read example:**

```python
a = open('hello.txt', 'r')  # opens a file in read mode
text = a.read()  # reads the entire contents of file in memory
print(text)  # prints the read text
a.close()  # closes the file
```

## Q55: Explain the term “with statement”?

**Ans:** The `with` statement would be useful whenever there are related operations block on each other.

```python
with expression [as variable]:
    with-block
```

In the above statement, we see that `with` block would be used within the context of variable opened with the help of `with` statement.

```python
with open('output.txt', 'w') as f:
    f.write('|Python!')
```

In the above example, the file would be closed as soon as the scope of `with` block gets over, the advantage being not to close the file explicitly using `close` block.

## Q56: Explain the preferred way of reading a big file?

**Ans:**
```python
with open("sampleread.txt", "r+") as ip:
    for singleLine in ip:
        print(singleLine)
```

The above code opens the file in read mode with the help of `with` statement. So, as soon as file operations get over, the file would be automatically closed.

Further, the above code loads only a single line in memory at a time thus saving memory or making it possible to run this program even with a computer having a lower memory footprint.

## Q57: Explain modules in Python.

**Ans:** Modules, both inbuilt and user-defined, are ways of writing reusable sets of code or reusing common sets of code.

Python provides a set of many inbuilt modules like `math`, `os`, `sys`, etc.

To use a module, we will have to import the same with the help of `import` statement or `from ... import` statement.

## Q58: Explain different ways of importing modules.

**Ans:** Modules can be imported using `import` statement or `from ... import` statement.

The difference lies in the fact whether we want the entire module or a particular part of it.

The `from ... import` statement is preferred when we want to import a particular module.

```python
from math import pi
print(pi)
```

The `import` statement is preferred when the entire module is to be imported.

```python
import math
print(math.pi)
```

As you can see in the `import` statement we have to use the module name wherever we want to get variables or methods from modules.

## Q63: Explain exception handling in Python.

**Ans:** Exception handling is supported with the help of `try...except` block.

Any statements which can logically cause problems would be placed in the `try` block.

In case of an exception occurring, corresponding handling is done in the `except` block.

A single `try` can contain multiple `except` blocks.

![Image](OEBPS/images/39.jpg)

In the above example, we place the code of accepting input from the user and type casting the same to `int` within the `try` block. We have two `except` blocks: one catching a specific exception and another generic `Exception`. Based upon the exception raised, the corresponding `except` block would be called.

To print the complete details of an Exception we make use of an alias i.e., `except Exception as e:` makes an alias of the exception.

In case of no exception, the `else` block would be executed.
