## 3.2. 数据集

所提出的天线设计使用 HFSS 软件实现，该软件允许创建天线模型。随后，基于仿真天线模型生成数据集。机器学习算法将使用此数据集进行预测。在 HFSS 上进行仿真后，将存储生成的数据。存储的结果包含 301 条记录，每条记录包含 1375 个特征。这些特征代表天线的各种特性和属性，捕获了用于进一步分析和基于机器学习的预测的重要信息。在 HFSS 中，通过改变 RDRA 的长度 (R_L)、宽度 (R_W) 和高度 (R_H) 以及馈线的馈入宽度 (W_f) 来生成数据集。之后，生成总共 413,876 条记录的新数据集，并将其划分为 6 个不同的特征：RDRA 的长度 (R_L)、宽度 (R_W) 和高度 (R_H)、馈线的馈入宽度 (W_f)、谐振频率以及谐振频率处的反射系数 (S_11)。使用机器学习算法，为预测最优参数选择了参数范围，如表 4 所示。最佳机器学习算法的选择取决于在使用从 HFSS 收集的数据集训练机器学习算法后，具有最大 R² 分数和最小均方误差 (MSE) 值。将使用该机器学习技术预测此数据集的 S_11 值。R² 分数值表示回归模型的准确性。R² 分数和 MSE 的数学公式如方程 (7) 和 (8) 所示：

```
R^2 = 1 - (Sum of squares residuals / Total sum of squares)
```

```
MSE = (1/n) * sum((Yi - Yj)^2)
```

其中，Yj 是预测值，Yi 是观测值，n 是数据点数量。

## 4. 结论

所提出的天线设计集成了两个 PIN 二极管开关，使其能够在多个频段上发挥功能。该天线设计针对宽频带和窄频带进行了优化，采用了不同的开关配置。因此，天线实现了 4 dB 的增益。所提出天线的 TR 和 TS 分别为 76.84% 和 91.08%。关于机器学习算法性能，XGB 算法在 OFF-OFF、OFF-ON、ON-OFF 和 ON-ON 配置中分别达到最高 R² 分数 96%、91.5%、94.6% 和 99.8%，证明了其在准确预测天线行为方面的有效性。数值、仿真和测量结果之间达成了良好的一致性。所提出的天线可用于 Sub 6 GHz 应用。
