# 3.2. Dataset

The proposed antenna design is implemented using the HFSS software, which allows for the antenna model creation. Subsequently, a dataset is generated based on the simulated antenna model. ML algorithms will utilize this dataset for prediction purposes. After conducting the simulation on HFSS, the resulting data is stored. The stored results

consist of 301 records, each containing 1375 features. These features represent various characteristics and properties of the antenna, capturing important information for further analysis and ML-based predictions. In HFSS, the dataset is generated by changing the length (R_L), width (R_W), and height (R_H) of RDRA, and feed width (W_f) of feedline. After this, a new dataset is generated of total 413,876 records and it is divided into 6 different features: length (R_L), width (R_W), and height (R_H) of RDRA, feed width (W_f) of feedline, resonant frequency, and reflection coefficient (S_11) at the resonant frequency. Using ML algorithms, the range of parameters is chosen for predicting the optimum parameters, as shown in Table 4. The best ML algorithm is selected depending on having the greatest R² score and minimum Mean Square Error (MSE) values after the ML algorithm have been trained using the dataset collected from the HFSS. The S_11 value for this dataset will be predicted using that ML techniques. The R² score value indicates the accuracy of our regression model. The mathematical formulation of the R² score and MSE is given Eqs. (7) and (8):

```
R^2 = 1 - (Sumofsquaresresiduals / Totalsumofsquares)
```

```
MSE = (1/n) * sum((Yi - Yj)^2)
```

Where, Yj is predicted values, Yi is observed values, and n is number of data points.
