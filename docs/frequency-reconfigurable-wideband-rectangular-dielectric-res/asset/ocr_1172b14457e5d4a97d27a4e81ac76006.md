# 3. Optimization through machine learning algorithm

ML approaches are employed for the optimization of antenna design parameters. Using the antenna parameters, S11 may be predicted for ML. There are five ML methods employed in this work: Extreme Gradient Boosting (XGB), K-Nearest Neighbor (KNN), Decision Tree (DT), Random Forest (RF), and Artificial Neural Network (ANN). These ML algorithms were chosen because they can perform regression for non-linear data. Data produced from the HFSS software is non-linear [17–21].

# 3.1. Methodology for ML algorithm in antenna

The utilization of ML algorithm in the process of designing antennas is depicted in Fig. 10. The figure illustrates a flow chart that provides a comprehensive outline of the entire procedure. The flow chart can be described through the following sequential steps: Step-1: The initial stages of designing the antenna and creating a dataset using an electromagnetic (EM) simulator. By systematically changing the antenna’s geometry, the dataset is developed. In this work, the dataset is produced by altering the length, width, and height of the RDRA and the feed width of the feedline. The output of S11, is recorded for one or more frequencies. Step-2: The training of the ML algorithm uses approximately 80 % of the dataset. This makes it possible for the algorithm to identify and learn patterns in the data. Step-3: Subsequently, the trained ML technique is applied to evaluate its performance on the remaining 20 % of the dataset. The approach advances to the next stages if the testing outcomes are satisfactory. However, if the testing outcomes are unsatisfactory, the procedure returns to Step-1 to reconstruct the dataset.
