# 用于亚6 GHz应用且采用机器学习优化的频率可重构宽带矩形介质谐振器天线

Jayant Kumar Rai, Pinku Ranjan *, Rakesh Chowdhury

电气与电子工程系，ABV-印度信息技术与管理学院，瓜廖尔，中央邦，印度

## 文章信息

关键词:
- 介质谐振器天线 (DRA)

- 机器学习 (ML)
- 5G

## 摘要

本文提出了一种基于机器学习(ML)方法的用于5G(亚6 GHz)应用的频率可重构宽带矩形介质谐振器天线(RDRA)。ML概念首次与可重构DRA相结合。提出了一种新方法以实现宽带和频率可重构性。通过电子方式(PIN二极管开关)实现频率可重构性，并以四种不同配置运行，提供最大76.84%的宽调频范围。混合结构及高阶模式$TE_{111}$和$TE_{211}$模式的激发是实现宽带运行的原因。极限梯度提升(XGB)机器学习算法在所有配置中对$S_{11}$预测的准确率超过90%。

## 1. 引言

频率可重构天线的理念旨在无需修改天线物理结构的情况下实现工作频率的动态变化。这些天线可以根据不断变化的系统要求调整其工作频率，或扩展多个频段。频率可重构天线在5G环境中至关重要，可应对下一代无线设备不断变化的需求和挑战。在亚6 GHz频段中，蜂窝、Wi-Fi、Bluetooth和IoT等多种技术并发使用。得益于频率可重构天线，单一天线可覆盖多个频率，并可提供高效的频谱利用。它们改善了频谱利用率、兼容性、多频段能力和成本效益，所有这些都有利于无线通信[1]。一种称为介质谐振器天线(DRA)的先进天线技术提供了多种理想特性，例如出色的辐射效率、显著增益和可变多模能力。由于这些特性，DRA是需要应用中频率灵活性和可重构性的天线设计的绝佳选择。此外，DRA中有多种馈电机制可用，例如同轴探头、微带馈电、孔耦合和平面波导(CPW)，且其可能存在多种形式(矩形、圆柱形、变形等)。介质谐振器(DR)在特定频率下表现出谐振行为，并且可通过改变DR尺寸来调谐谐振频率。调谐能力使DRA能够在某个频带内工作。此外，DR具有大带宽，使其能够在宽广的频率范围内支持多个频段。基于DR构建的频率可重构天线可以覆盖大带宽频率范围，使其能够适应各种无线通信协议和应用。DRA的小尺寸外形允许其集成到空间受限的设备中，而不会牺牲性能。通过将频率可重构性纳入DRA，可以开发出具有增强灵活性和性能的紧凑型宽带天线。传统DRA因其出色的辐射效率和与集成电路的兼容性而显示出潜力[2–6, 22–23]。

为设计频率可重构DRA，开展了各种研究，例如在[9]中，利用电容芯片或变容二极管创建了矩形差分馈电DRA，提供窄带调频。所述配置之一具有宽调频范围，但通过将三个PIN二极管与矩形DRA相结合并在九种状态中运行六种状态，增加了复杂性[10]。在[11]中，由CPW供电的矩形DRA使用两个PIN二极管从窄带过渡到宽带运行，提供低调频范围和额外复杂性。在[12]中，通过将三矩形DRA与两个PIN二极管相结合，产生更复杂的单带或双带频率可重构性，在ON状态下之一或两个状态中生成。在[13]中，带有三个集成PIN二极管的四个矩形DR提供单频带频率可重构性，但仅在两个或更多ON状态下。在[12]和[13]中，由于元件数量和偏置线，复杂性增加。在[14]中，带有两个PIN二极管的频率敏捷混合DRA在某个频率范围内创建可重构圆偏化波；然而，其调频范围有限。拟议天线与以往工作的对比如表1所示。

### 2.2. 数学建模

本研究中提出的天线是一种混合天线，结合了不同特性以增强其性能。该天线的谐振频率由两层介质的存在决定：环氧FR4(4.4)和氧化铝(Al2O3)。有效高度Heff和有效介电常数εreff是表征拟议天线行为的关键参数。根据[16]，有效高度(Heff)和有效介电常数(εreff)由公式(1)和(2)给出：

H_eff = H + H_S

ε_reff = H_eff / (H/ε_RDRA + H_S/ε_sub)

根据[3]，使用超越方程来计算基模TE111的谐振频率

k . tan(k * d / 2) = √((εreff - 1)k0² - kz²)

其中，kx、ky和kz是波数，它们满足以下方程

kx² + ky² + kz² = (εreff)k0²

其中，kx = π/b 且 ky = π/b

根据[1]，可重构天线参数调频范围(TR)和总频谱(TS)由公式(5)和(6)给出：

TR(%) = 2 × ((fol - fal) / (fon + fol)) × 100

其中，fol = 谐振下限频率，foh = 谐振上限频率

TS(%) = 2 × ((fmax - fmin) / (fmax + fmin)) × 100
