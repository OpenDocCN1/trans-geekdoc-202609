# 摘要

尽管数据驱动的工业4.0具有巨大潜力且数据广泛可用，但数据分析仍局限于手动数据，而非知识的合成。虽然制造业中的员工知识往往是隐藏的，但很少能被形式化和有效利用。为了弥补这一差距，我们开发了一条自然语言处理（NLP）流水线来处理来自机器的文本信息。我们为其提供了这一生产流程以减少停机时间。生成的形式化知识可以作为优化制造工艺的基础。

**关键词**：自然语言处理；预测性维护；知识提取；机器学习；生产计划

## 1. 引言

工业4.0 被广泛认为是制造业的一项发展，它基于工业环境中数据和模型的无处不在、分析和应用。其基础是从“愚笨数据”中推导出知识的能力。目前，该方案已有效地应用于表格数据、数据模式或控制序列。在这种背景下，制造业中使用的自然语言具有更高的表达力，并能够传递知识 [2]。然而，制造业中缺乏对这种知识的有效形式化和分析 [18]。制造业并没有挖掘自然语言中表达的内容，仅利用了来自常规工业4.0系统的数值数据。标准化的问卷、故障报告和大纲仅被限制在有限的范围内。由于制造业面临许多挑战，存在各种无法预见的影响因素，导致了宝贵自然数据的流失。因此，自然语言处理（NLP）作为一种将自然语言形式化以提炼知识的艺术 [14]，可以作为一种非常有价值的方法，并具有巨大的潜力。为了有效利用制造业中自然对话和文本中固有的知识——特别是那些结构无法更改的数据——本文提出了一种用于该应用的新型NLP流水线。基于开发的NLP流水线，本文展示了一个使用真实工业数据的案例研究，并说明性地展示了结果。特别地，对操作人员数字记录的、描述制造故障的评论进行了分析，通过NLP技术提高了结果的准确性。该方法可以通过添加预测的正交校正器来处理文本编写的评论。

本文的结构如下：第2节讨论了自然语言的现状以及其在制造业中极少数的应用之一。基于知识保持的状态，第3节引入了相关方法。第4节通过案例研究进行测试。第5节对发现进行了讨论，第6节是简要的总结和展望。

### 2.1 现代自然语言处理

在制造业公司中，文本数据通常以无组织的形式存在。关于与机器学习（ML）结合的NLP方法直接相关的文献相对较少。由于车间的数据获取以及尽管有强大的NLP算法但数据稀缺，NLP的应用仍处于生产领域。为了在生产环境中应用NLP并最终利用非结构化的文本和口语人类知识，对方法和要求的通用理解至关重要。

在NLP的开始，文本文档必须经过排序、处理和过滤 [14]。文本在准备阶段进行预处理。预处理的示例包括删除未知字符、单词和词干。词还原（Lemmatization）描述了如“best”和“good”等单词的分组。准备之后，进行分词。向量化是用于表示的单词嵌入（例如`Word2Vec`、`fastText`）或基于频率的向量化（例如独热编码、`TF-IDF`）。这种向量化允许NLP处理文档并训练模型。可以确定评估指标并调整算法或模型。使用NLP处理文本数据的典型过程如图1所示。

`BERT`是一种深度意义的算法，它利用单词的左侧和右侧上下文，从而区分如“seat、bank或money”之类的词。通过`TF-IDF`得分，可以在不考虑单词位置的情况下计算单词与文档之间的相关性，单词在文档中出现的频率不是文档系列 [4]。

预训练模型被用于`GPT`算法。`GPT-3`是一个在所有结构中具有1750亿参数的深度神经网络。图中了`Transformer` [24]。它通过基于标记的标记进行预测。标记表示为`Nigram`或语言。因此，`GPT-3`还可以解决以前无法解决的NLP任务。

这些算法没有在生产内的文本数据上进行训练，使用了不同的术语。这提出了在没有先验知识的情况下对文本进行向量化的挑战，具体的步骤如表1所示。

### 2.2 文献综述

NLP主要位于非工业部门，因为那里已经有了大量的文本集合。在接下来，我们描述了工业领域的一些NLP方法，以识别其工业应用现有解决方案的可能性。一种方法是训练一个缩小的语言模型，目标是处理出现在对话中的文本 [7]。我们在本研究中使用了机器学习（ML）方法，从文本中过滤相关特征并自动进行总结。另一种应用描述了通过机器学习算法对人类可理解及信息性文本进行数据驱动的编辑。在这里，作者使用了2017年芬兰地方选举自动报告的案例 [15]

文本在制造业中非常普遍，但由于其复杂性，通常仅用于计算分析 [18]。由于约 80% 的平均知识以文本形式存在，制造业是自然语言处理（NLP）方法的稀有用例 [10]。可研究的可用知识和数据合并约占项目设计的 70% [16]。因此，NLP 方法的应用可能会提高工业效率并节省时间。

文本数据需要在大规模范围内识别并提取 (0)。这包括选择合适的数据和文本，这些文本要有意义，并为后续算法做出可行的预测、分类或决策提供见。其次，应对数据进行清洗 (1)。这包括删除标点符号、标签、空格和其他字符。将文本转换为向量是另一个挑战，可能会提高准确性（步骤 2）。在生产背景下，拼写检查和自动纠正是有实用的补充，可以作为防止拼写错误的选项。在完成以下分词（步骤 3）之后：将句子缩短为更短的句子，即每句一个单词会更好，因为这些常规词很少或没有信息（步骤 4）。下一步是文本的词形还原，将单个术语转换为其基础形式（步骤 5）。文本通过 `NLTK` 或 `Word2Vec` 等算法进行处理。还有其他算法（步骤 7），任务范围从维护决策选择和课程分析到停机预测。

在制造业领域，准确地说是在机器维护方面，利用 NLP 和 ML 有若干机会。通过结合 NLP 和 ML 理解过去日志的语言可能有助于提取隐藏知识，为维护决策提供竞争优势 [4]。此外，通过搜索技术援助报告中存储的类似内容来检索新问题的潜在解决方案 [2]，以及利用 NLP 寻找故障根源可能是无价的。NLP 过程可以基于制造环境中常见的可靠、中心化知识数据库。在管理领域，NLP 可能适用于员工和申请人管理，用于识别和分类简历。

通过集成的基于内容的推荐引擎进行问题解决管理，以增强车车的知识管理 [21]。这可以扩展到公司内部以及与外部世界进行交互，也是此类应用的潜在领域。应用通常用于这些目的。

然而，由于对针对性不那么强的文本和语言进行了许多分析 [19]，NLP 在制造业中的应用无法对文本知识进行端到端的预测，而是侧重于描述良好的任务。然而，克服 NLP 在制造业中的低效率问题，可以实现一种可迁移且适用的 NLP 流，用于基于文本数据的端到端预测或分类。

## 4. 案例研究

接下来，我们描述了一个使用 NLP 进行制造业停机预测的案例研究。我们开发了一个根据人员注释和事件 (A&E) 预测机器停机的管道。这些信息可以供部门管理分配维护或清洁订单，或为人员分配不同任务。案例研究中使用的数据来自一个消费品生产设施 (0)。该设施的产品属于同一业务单元。个体操作员负责产品生产的不同步骤。部门内的各个线路在某些机器或其他层级方面也存在差异。然而，生产数据由线路事件系统 (LEDS) 收集并存储在中心数据库中。除了生产元数据外，所有生产事件的数据还包含各种错误。在拼写错误中，存在注释、多余的标点符号和空格。数据质量在使用前需要进行准备（步骤 2）。所有原始文本都去除了标点符号，因为它不提供内容信息。所有文本都转换为小写并分词（步骤 3）。停用词不仅不经常使用，而且是噪声示例，在频率分析后会被移除。在真实数据中，有 32,635 个轻级错误事件、41,880 个中级错误事件和 23,319 个严重错误事件。我们对对事件描述进行了分类。这种方法（步骤 5）提供了额外的帮助，但很有用。预处理之后，我们将文本转换为特征向量（步骤 6）。我们在本中使用了两种方法：`TF-IDF` 和词袋 (BoW)。BoW 是一种选择特征以创建实例类型类别的方法。在 NLP 中，BoW 是出现次数的衡量。每个文档由文本的长度和频率以及相应维度的向量表示。此外，我们将数据集分为训练集和测试集，分布为 80/20%，我们使用梯度提升决策树 (GBDT) 算法 `XGBoost` [5] 和 `LightGBM` [11] 对模型进行分类，如图 3 所示。`XGBoost` 算法迭代树，并相对于损失函数的极限进行拟合，关于前一个树的输出。`XGBoost` 和 `LightGBM` 的优势在于通过离线计算实现的扩展性和速度，以及它们处理数据稀疏性的能力。数据稀疏性可能由缺失值或特征编码引起，并可能导致传统算法中出现长序列 [5, 12]。我们将模型定义为具有此类目标的多分类器。我们发现使用交叉验证中的网格搜索来调整超参数并寻找最佳假设。我们使用了准确率最高的方法进行评估。我们还考虑了 F1 分数以及一对 ROC-AUC (ROC-AUC-OVO)。此外，我们还对数据使用零率分类器来从基准分类（步骤 7）设置我们模型的性能。

实验结果如表 2 所示。`XGBoost` 和 `LightGBM` 的准确率分别为 57.21% 和 55.48%，F1 分数分别为 57.09 和 55.13，ROC AUC 为 74.11 和 73.77。使用 `TF-IDF` 得到的 F1 分数为 58.28% (62.06%)，ROC AUC 为 77.52% (79.77%)，而 `Word2Vec` 得到的 F1 分数为 43.57% (46.15%) 和 ROC AUC 为 60.92% (62.85%)。基准分类结果为 34%。

我们发现与词袋或 `Word2Vec` 相比，`TF-IDF` 产生了更好的性能。这表明更复杂的准确的向量化算法性能卓越。因此，精细向量化和复杂算法的方法得到了加强。在使用词袋时，`XGBoost` 和 `LightGBM` 显示出非常的性能。在使用 `TF-IDF` 时，`LightGBM` 模型提供了更好的结果。与零分类相比，两种模型的性能都有显著提高。

## 5. 总结与展望

在我们的案例中，我们使用了梯度提升机器学习算法来预测机器停机的严重性。基于此，可以看出与店主之间的停机评论愿意根据我们的请求提供明确回复。然而，预测对于直接用于操作来说缺乏高准确性。数据的性质和信息内容对预测的准确性起着主要作用。凭借 100,000 个观测值，该数据集对于特定的 NLP 问题来说足够大。该任务通过划分为训练集和测试集建立。一些缺失的特征会对停机产生影响，例如关于产品的随机性。未来，自动修正以及对异常值的过滤会对结果产生积极影响。为了纠正，应使用特定的词表。部署方法在数据集上进行训练。需要进一步的实验。更大的数据集会导致更全面的方法。因此，建议读者保持标准的格式，引入特定的词表并进行早期数据收集。

## 6. 总结与展望

简而言之，制造业对 NLP 的需求显而易见。随着对知识和简单 NLP 流水线的意识增强，可以得到解决。因此，本文提出了一种基于文本描述的制造业 NLP 流水线案例。停机预测是监督学习应用的第一步。后续研究可以阐明使用无监督学习和强化学习的兴趣。此外，研究可以通过增加大量数据集的强化学习进行增强。未来，NLP 在制造业中的全面应用有望带来更好的决策。
