# IV. USER ASSOCIATION PROBABILITY

In this section, we describe association probability is defined as the probability that a TUE is served by a particular tier. To derive the association probability, we first measure the distribution of distance $y_v$, between the TUE and the serving BS, that the TUE associates to $v$. Consider $Y_v$ as the random variable which denotes the statistical distance from the TUE to the closest BS of $\Omega$. As the BS deployment is through PPP, [20], using null probability probability density function (PDF) of $Y_v$ it is

```
$f_v(y_v) = \lambda_v e^{-\lambda_v y_v^{\alpha_v}}, \forall v \in \{M, S\}. \quad (7)$
```
