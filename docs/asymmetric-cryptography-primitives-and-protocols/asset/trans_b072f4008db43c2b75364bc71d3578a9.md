
现在我们可以看到，![image](images/d.jpg) 在 `g[1] = g`、`g[2] = g^α`、`u = g^β`、`υ = g^γ` 的情况下，在游戏 0 和游戏 1 之间进行插值。如果 `γ = αβ`，则 ![image](images/d.jpg) 模拟游戏 0。如果 `γ` 是随机的，则 ![image](images/d.jpg) 模拟游戏 1。因此，其优势正好是 `Pr[S[0]] – Pr[S[1]]`，从而得证。

**声明 1.4.** – `| Pr[S[1]] − Pr[S[2]] | 可忽略不计。`

根据差异引理，我们有 `| Pr[S[1]] − Pr[S[2]] | ≤ Pr[E]`，其中 `E` 是事件 `ℓ = 0` 或 `r = r′`，这里 `l, r′ ←[R] ![image](images/z1.jpg)[q]`，观察到 `E` 发生的概率可忽略不计，因为 `q` 是指数级的。

**声明 1.5.** – `| Pr[S[2]] − Pr[S[3]] | 可忽略不计。`

由于该声明是信息论层面的，我们将证明即使 ![image](images/a.jpg) 是一个全能对手（例如可能能够计算离散对数），该陈述依然成立。为证明该声明，令 `F` 为对手 ![image](images/a.jpg) 查询至少一个通过有效性检查的非法密文的事件。根据 `F` 的定义，我们有 `S[2] ∧ ¬F = S[3] ∧ ¬F`。因此，由差异引理可得 `| Pr[S[2]] − Pr[S[3]] | ≤ Pr[F]`。现在我们推导 `Pr[F]` 的最大界。回顾 `ℓ = log[g1] g[2]`。对于每个查询 `C[i] = (u[i], v[i], w[i], e[i])`，我们记 `r[i] = log[g1] u[i]`，![image](images/i22.jpg) 和 `z[i] = log^(g1) e[i]`。Dec 中的有效性检查等式，即 ![image](images/i23.jpg) `e[i]`，等价于 ![image](images/i24.jpg) 因此，![image](images/a.jpg) 可以使其第一个查询为非法，同时通过猜测 ![image](images/i25.jpg) 且满足 `r[1] ≠ ![image](images/rp1.jpg)` 使得 `r[1]a + ![image](images/rp1.jpg)ℓb = z[1]` 来通过有效性检查。现在我们观察到，![image](images/a.jpg) 关于 `a, b` 的信息仅来自公钥，即 ![image](images/i26.jpg)，因此对于全能对手，它可能知道 `log[g1] c = a + ℓb`。但由于 `r[1] ≠ ![image](images/rp1.jpg)`，我们有 `r[1]a + ![image](images/rp1.jpg)ℓb` 与 `a + ℓb` 线性无关，因此它只能以 `1/q` 的概率正确猜测 `z[1]`。

对于第 `i` 个查询，![image](images/a.jpg) 可以通过类似的猜测使其非法，但现在它从之前未通过检查的非法查询中获得了关于 `a, b` 的更多信息。更精确地说，对于一个被拒绝的非法查询 `C[j] = (u[j], v[j], w[j], e[j])`，其中 `j < i`，![image](images/a.jpg) 了解到 ![image](images/i27.jpg) 这从受限于其对 `a+ℓb` 的认知的 `q` 个可能的 `(a, b)` 对中排除了一个可能性。在第 `i` 个查询之前，最多有 `i − 1` 个这样的查询。因此，![image](images/a.jpg) 正确猜测 `z[i]` 的概率至多为 `1/(q (i 1))`。令 `k` 为查询总数。由并集界可知，`Pr[F]` 至多为 `k/(q − k + 1)`。由于 `k` 是 `λ` 的多项式而 `q` 是指数级的，该量可忽略不计。

**声明 1.6.** – `Pr[S[3]] = 1/2.`

为证明该声明，只需证明在游戏 3 中，给定视图中所有已知指数的情况下，消息掩码项的指数是均匀随机的。这等价于证明给定 `ℓ, x + ℓy`（来自 `pk`）、`r, r′`（来自挑战密文）及其解密查询答案中的一些信息的情况下，`xr + ℓyr′` 是均匀随机的。忽略后者，这成立是因为 `xr+ℓyr′` 与 `x + ℓy` 线性无关，因为 `r ≠ r′` 且 `ℓ = 0`。我们进一步论证，即使给定其解密查询的答案，也不会获得关于 `x, y` 的额外信息。现在，由于在游戏 3 中，我们拒绝所有通过有效性检查的非法查询，剩余的查询要么不通过检查，要么不是非法查询。在第一种情况下，检查不涉及 `x, y`（因此无关于它们的信息）。在后一种情况下，我们有 ![image](images/i28.jpg) 且 ![image](images/a.jpg) 了解 `log[g1] m[i] = z[i] r[i]x ℓr[i]y`。但这与 `x + ℓy` 线性相关。因此，没有关于 `x, y` 的额外信息。
