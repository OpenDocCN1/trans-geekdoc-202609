# 7 基于属性的加密

**Romain GAY**

## 7.1 简介

在本章中，我们介绍具有对加密明文进行细粒度访问控制的加密方案，这与传统公钥加密方案实现的全有或全无访问形成对比。这些方案被称为基于属性的加密方案（ABE）。具体而言，在 ABE 方案中，初始化算法生成一个公钥和一个所谓的主密钥。任何人都可以使用公钥加密与访问策略相关联的明文，该策略可以表示为布尔公式等形式。还有一个额外的算法，输入主密钥和一个属性，生成用户私钥（针对该特定属性）。解密算法接收密文和用户私钥，当且仅当用户私钥的属性满足密文中嵌入的公式时，才能成功恢复明文。如果对手获取了一些本不应能解密的用户私钥，加密明文的机密性仍然得到保障。

我们在此介绍基于配对群（详见[第 5 章](#c05.xhtml)）的 ABE 方案。我们采用模块化方法，从一个称为谓词编码的简单统计学原语开始构建 ABE，该原语仅满足弱安全性概念（仅在一个用户私钥被攻破时安全），然后将其通用地转换为密钥 ABE，即加密算法需要主密钥（而非仅需公钥）的 ABE。最后，将这种密钥 ABE 再转换为公钥加密的 ABE。[图 7.1](#c07.xhtml#c7-fig-1) 描述了这种两步法。结合现有的谓词编码实例化时，这种通用构造可产生适用于不同访问策略类别的 ABE，例如布尔公式或基于身份的加密（IBE）。为完整性起见并展示模块化方法的通用性，我们也提供了此类谓词编码。

*本章结构*：第一节回顾配对群基础及所用计算假设（更多细节见[第 5 章](#c05.xhtml)）。第二节给出谓词编码的定义，并给出 IBE 和布尔公式的具体构造。第三节展示如何将谓词编码通用地转换为密钥 ABE，再转换为 ABE（即加密算法为公钥的）。最后简要回顾 ABE 的历史。
