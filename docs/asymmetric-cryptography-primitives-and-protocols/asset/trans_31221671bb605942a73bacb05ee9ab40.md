

首个基于格的追踪者追踪方案由 Ling 等人 (2014) 提出。该方案处于有界模型中，其安全性依赖于 LWE 问题的一个新变体的困难性，称为 `k`-LWE。这是 Boneh 和 Freeman (2011) 引入的 `k`-SIS 问题的一个类比。Boneh-Freeman 从 SIS 到 `k`-SIS 的归约在 `k` 上遭受指数级损失，而 Ling 等人 (2014) 的作者们对其进行了改进和扩展，将其变为从 LWE 到 `k`-LWE 的归约，在 `k` 上仅有多项式损失。因此，由此产生的 TT 方案与底层的 LWE 加密一样有效。

正如 Gafni 等人 (1999) 最初观察到的，当 TT 方案与撤销方案结合时最为有用；这种追踪与撤销方法包含首先发现被泄露的解密密钥，然后撤销其解密能力，从而使盗版解码器失效。我们可以列举该类别中的一些方案 (Naor 和 Pinkas 2001; Tzeng 和 Tzeng 2001; Naor 等人 2001; Dodis 和 Fazio 2002, 2003; Kim 等人 2003; Dodis 等人 2005; Boneh 和 Waters 2006; Ngo 等人 2013)。

最近，构建追踪与撤销方案的新研究路线已经出现 (Nishimaki 等人 2016; Kowalczyk 等人 2016; Agrawal 和 Rosen 2017; Agrawal 等人 2017; Goyal 等人 2018a, 2019a, 2019b)。Nishimaki 等人 (2016) 从函数加密方案给出了追踪与撤销的通用构造。函数加密 (Sahai 和 Waters 2005; Boneh 等人 2011) 是公钥加密的一种推广，允许对加密数据进行细粒度访问。我们注意到，Nishimaki 等人 (2016) 中最强的构造基于不可区分混淆 (Barak 等人 2001) 的存在，目前我们还没有基于成熟困难性假设的候选构造。人们也可以用有界共谋函数加密方案来实例化 NWZ 编译器，该方案可以基于标准假设，如公钥加密的存在 (![image](images/g1.jpg)orbunov 等人 2012) 或带误差学习 (LWE) 的亚指数时间困难性 (![image](images/g1.jpg)oldwasser 等人 2013; Agrawal 和 Rosen 2017)。对于追踪与撤销，这产生了一种支持公开黑盒可追踪性和自适应安全性的构造，此外还支持诚实用户的匿名性和指数级大小的身份空间。然而，其构造的通用性导致了具体效率的损失。例如，当基于 Gorbunov 等人 (2012) 的有界共谋 FE 时，所得方案的密文大小至少增长为 `O((r + t)⁵ poly(λ))`，其中 `r` 是撤销用户列表的最大规模，`t` 是最大联盟规模。通过依赖带误差学习，这种膨胀可以改进为 `O((r + t)⁴ poly(λ))`，但代价是依赖繁重的机制，如属性基加密 (Gorbunov 等人 2013) 和全同态加密 (Goldwasser 等人 2013)。此外，该构造还必须依赖复杂度杠杆来实现自适应安全性，以及具有亚指数错误率的带误差学习。Agrawal 和 Rosen (2017) 的有界共谋 FE 导致了更好的渐近界 `O((r + t)³ poly(λ))`，但遭受巨大的多项式因子损害，影响了具体效率。Agrawal 等人 (2017) 的论文重新审视了函数加密与追踪与撤销系统之间的联系，并观察到有界共谋追踪与撤销方案所需的 FE 概念比 Nishimaki 等人 (2016) 考虑的要弱得多：与其说是针对多项式大小电路的 FE，不如说弱变体的 `内积` 函数加密 (IPFE) (Abdalla 等人 2015; Agrawal 等人 2016) 就足够了。因此，Agrawal 等人 (2017) 在标准假设下，即 DCR、LWE 和 DDH 假设下，提出了具有黑盒确认功能的高效追踪与撤销方案，其密文和密钥大小在撤销列表大小 `r` 和最大联盟大小 `t` 之和上是 `线性` 的。在全共谋模型下构建实用的追踪与撤销方案仍然是一个挑战。

在接下来的章节中，我们将讨论设计 BE 和 TT 方案中最相关的技术。

## 6.4. 基于树的方法

组合广播加密方案主要基于树结构或指纹码。基于树的方案支持撤销，但在处理追踪叛徒方面能力有限，而基于码的方案提供可追踪性，但很少支持撤销。

### 子集覆盖框架

子集覆盖框架由 Aiello 等人 (1998) 和 Naor 等人 (2001) 提出（这也等价于独占集系统的概念 (Kumar 和 Russell 2003)）。这是设计高效追踪与撤销系统的有力工具。它捕捉了先前提出的 TT 系统的思想，并构成了所谓的 NNL 方案的基础，该方案用于称为 AACS 的 HD-DVD 内容保护系统 (AACS LA n.d.)。

在子集覆盖框架中，系统中的用户集合 `N` 由一组子集 `S[i]` 覆盖，使得 `∪[i]S[i] ⊃ N` 且 `S[i] ∩ N ≠ ∅`。这种覆盖不是 `N` 的划分，集合 `S[i]` 反而相互重叠。每个子集 `S[i]` 对应一个长期密钥 `L[i]`，属于 `S[i]` 的每个用户都会获得这个长期密钥（或以等价方式，获得允许其推导出该长期密钥的某些材料）。因此，系统中的每个用户 `u` 都会获得一组长期密钥 `L[ik]`，它们共同构成其私钥，记为 `sk[u]`。

为了广播内容 `M`，中心使用标准的混合方案：首先随机抽取一个会话密钥 `K`，用它来加密内容（使用加密方案 `E'`），然后在多个长期密钥下进行封装（使用另一个加密方案 `E`）。选择长期密钥 `L[ik]`（`k = 1,..., l`），使得相应的子集 `S[i1], ..., S[il]` 仅覆盖有权解密的用户集合。因此，中心广播如下形式的密文：
