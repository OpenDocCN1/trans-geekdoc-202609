## 7.3. Predicate encodings

### 7.3.1. Definition

**DEFINITION 7.1 (Predicate Encoding).** Let `p` be a prime, `|ct|`, `|usk|`, `n, s ∈ ℕ` and `P ⊆ {P : {0, 1}^s → {0, 1}}`. A predicate encoding with respect to `(p, |ct|, |usk|, n, P)` is a tuple of polynomial-time deterministic algorithms `(EncCt, EncKey, Decode)` that fulfills the syntax, correctness and security properties described below.

#### 7.3.1.1. Syntax

- `EncCt(P) → C`. Given as input a predicate `P ∈ P`, it outputs a matrix `C ∈ Z[p]^{n × |ct|}`.
- `EncKey(att) → K`. Given as input an attribute `att ∈ {0, 1}^s`, it outputs a matrix `K ∈ Z[p]^{n × |usk|}`.
- `Decode(P, att) → d`. Given as input a predicate `P ∈ P` and an attribute `att ∈ {0, 1}^s`, it outputs a vector `d ∈ Z[p]^{|ct|}`.

#### 7.3.1.2. Correctness

For all `P ∈ P` and `att ∈ {0, 1}^s` such that `P(att) = 1`, writing `C = EncCt(P) ∈ Z[p]^{n × |ct|}` and `K = EncKey(att) ∈ Z[p]^{n × |usk|}` we have: `d^T C^T K = (1, 0, ..., 0)`.

#### 7.3.1.3. Security

For all `P ∈ P` and `att ∈ {0, 1}^s` such that `P(att) = 0`, the vector `(1, 0, ..., 0) ∈ Z[p]^{|ct|}` is not in the column span of `C^T K`.

### 7.3.2. Constructions

We present two constructions of predicate encodings. The first one corresponds to IBE, where the predicate is simply the equality between two identities that belong to a large space. The second is a predicate encoding for predicates that are represented by read-once monotone span programs (we recall the definition of the latter), which capture Boolean read-once formulae.

#### 7.3.2.1. Identity-based encryption

Let `p` be a prime, `|ct| = 1`, `|usk| = 1`, `n = 2`, `s = ⌊log(p)⌋` and `P = {P_id : {0, 1}^s → {0, 1}}` is the set of predicates `P_id` defined for all `id ∈ {0, 1}^s` as `P_id(id') = 1` if `id = id'`, `P_id(id') = 0` otherwise. We present a predicate encoding with respect to `(p, |ct|, |usk|, n, P)`, where we interpret any bit string `id ∈ {0, 1}^s` as an integer in `Z[p]` in the straightforward way.

- `EncCt(id)`: Given `id ∈ Z[p]`, it outputs the matrix `[[1], [id]]` such that for all `α, υ[1], υ[2] ∈ Z[p]`.
- `EncKey(id)`: Given `id ∈ Z[p]`, it outputs the matrix `[[υ[1] + id·υ[2]], [υ[2]]]` such that for all `α, υ[1], υ[2] ∈ Z[p]`.
- `Decode(id, id')`: If `id = id'`, it outputs the vector `[1]`.

**Correctness**: Let `id ∈ Z[p]`, `C = EncCt(id)`, `K = EncKey(id)` and `d = Decode(id, id')`. For all `α, υ[1], υ[2] ∈ Z[p]`, we have `d^T C^T K = 1`.

**Security**: Consider the map `H[υ[1],υ[2]] : Z[p] → Z[p]` defined for all `υ[1], υ[2] ∈ Z[p]` as `H[υ[1],υ[2]](id) = υ[1] + id·υ[2]`. #### 7.3.2.2. Read-once monotone span programs

We start by recalling the definition of read-once monotone span programs.

**DEFINITION 7.2 (Read-Once MSP).** Let `p` be a prime, `ℓ, s ∈ ℕ` and `M ∈ Z[p]^{ℓ × s}`. We say `x ∈ {0, 1}^s` satisfies `M` if the vector `(1, 0, ..., 0) ∈ Z[p]^ℓ` is in the column span of `M[x]`, which denotes the collection of vectors `(M[i])_{i∈[s], x[i]=1}` where `M[i]` denotes the `i`-th column of `M`. That is, `x` satisfies `M` if there exist constants `{ω[i]}_{i∈[s]}` such that `Σ_{i: x[i]=1} ω[i] M[i] = (1, 0, ..., 0)^T`. Observe that the constants `{ω[i]}_{i∈[s]}` can be computed in time polynomial in the size of the matrix `M` via Gaussian elimination.

As we will see later, MSP are convenient to use in the context of ABE, and they capture the predicates that can be expressed as Boolean formulae. Namely, every Boolean formula `ϕ` that is monotone (only uses positive literals) and read-once (each variable is used as a literal at most once) can be turned efficiently into a matrix `M[Q]` (whose size grows with the size of `φ`) such that for all `x ∈ {0, 1}^s`, we have `ϕ(x) = 1` if and only if `x` satisfies `M` (as per Definition 7.2).

We recall a useful lemma regarding the statistical security of MSP, whose proof is given in Karchmer and Wigderson (1993).

**LEMMA 7.2 (Security of MSP).** Let `M ∈ Z[p]^{ℓ × s}` and `x ∈ {0, 1}^s` that does not satisfy `M` (as per Definition 7.2). The following distributions are identical: `{ω ← Z[p]^ℓ : ω^T M[x]}` and `{ω ← Z[p]^ℓ : ω^T M[x] + (1, 0, ..., 0)}`.

We now present a predicate encoding for read-once MSP, that is, with respect to `(p, |ct|, |usk|, n, P)` where `p` is a prime, `ℓ, s ∈ ℕ`, `n = ℓ+s`, `|ct| = s`, `|usk| = s+1` and `P = {P_M : {0, 1}^s → {0, 1}}` is the set of predicates `P_M` defined for all `M ∈ Z[p]^{ℓ × s}` as follows. `P_M` takes as input an attribute `x = (x[1], ..., x[s]) ∈ {0, 1}^s`, and outputs 1 if `x` satisfies `M` as per Definition 7.2.

- `EncCt(M)`: Given `M ∈ Z[p]^{ℓ × s}`, it outputs the matrix `[[I_s], [M]]` such that for all `i ∈ [s]`, `C[i] = e_i` and `C[ℓ+i] = M[i]` where `M[i]` denotes the `i`-th column of `M`.
