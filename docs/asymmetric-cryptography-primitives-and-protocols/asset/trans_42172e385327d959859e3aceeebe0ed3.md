
Cramer和Shoup（2003）证明了如果底层KEM是IND-CCA安全的，且底层SKE方案是IND-OT-CCA安全的，那么混合加密构造就是一个IND-CCA安全的PKE方案。此外，Herranz等人（2010）研究了混合加密构造所达到的安全概念与底层KEM/SKE方案的安全概念之间的关系。特别地，他们证明了如果底层KEM是IND-CCA1安全的（分别为IND-CPA），且底层SKE方案是IND-OT安全的，那么混合加密构造就是IND-CCA1（分别为IND-CPA）安全的。Hofheinz和Kiltz（2007）给出了混合加密的另一个结果：如果底层KEM在*受限CCA安全*意义上是安全的（这是一种严格弱于IND-CCA安全的安全概念），且底层SKE方案在（一次性）认证加密（Bellare和Namprempre 2000）意义上是安全的（同时考虑IND-OT安全性和一次性真实性），那么混合加密构造仍然能达到IND-CCA安全。我们注意到，同时达到IND-OT安全性和一次性真实性的SKE方案自动达到IND-OT-CCA安全性；因此，在一次性认证加密意义上安全的要求强于IND-OT-CCA安全性。

Abe等人（2005）展示了另一种不同于上述的混合加密范式，称为Tag-KEM/DEM框架。该框架定义了一种称为tag-KEM的新原语。其语法与上述普通KEM的区别在于，生成KEM密文时允许来自SKE/DEM部分的反馈输入。该框架的优点之一是底层SKE方案只需是IND-OT安全的，而构造tag-KEM通常比构造普通KEM更困难。

这些关于混合加密的结果使我们在设计IND-CCA安全的PKE方案时，能够专注于合适KEM的设计。

### 1.3.2. Naor–Yung构造及其扩展

我们描述一种由Naor和Yung（1990）提出的经典方法，用于从IND-CPA方案和*非交互零知识*（NIZK）证明系统（Blum等人 1988）构造IND-CCA1安全的PKE。在该构造中，明文在独立的密钥和随机数下被加密两次，然后使用NIZK来证明两个密文加密的是同一个明文。其直觉是：如果对手能以某种方式获得两个独立加密同一明文的密文，那么本质上它已经知道该明文了。因此，解密预言机对对手应当是无用的。

#### 1.3.2.1. 与Cramer–Shoup PKE的联系

值得一提的是，Cramer–Shoup PKE（Cramer和Shoup 1998, 2003）可以被视为受Naor–Yung范式启发。首先，Cramer–Shoup方案可以粗略地看作是在多个可能的私钥下对消息进行加密。这类似于利用两个私钥的Naor–Yung范式。其次，Cramer–Shoup PKE中的有效性检查具有类似于验证密文“格式良好”的NIZK证明的功能。此外，正如[第1.2.5节](#c01.xhtml#sec1-2-5)前面提到的，Cramer和Shoup（2002）基于HPS给出了其方案的一个推广。HPS可以被视为一类称为子集成员问题的特定NP语言的特殊类型的NIZK证明系统（其中，与DDH相关的问题即为一个特例）。我们在[第1.3.4节](#c01.xhtml#sec1-3-4)中简要综述基于HPS的进一步结果。

### 1.3.3. Fujisaki–Okamoto及RO模型中的其他变换

接下来我们描述在RO模型中实现IND-CCA安全PKE的最流行和通用的通用变换之一，称为Fujisaki-Okamoto（FO）变换。

设（`KG`、`Enc`、`Dec`）为一个PKE方案，其明文空间为{0, 1}^(*λ*)，`Enc`的随机数空间为{0, 1}^(*ℓ*)，其中*ℓ* = *ℓ*(*λ*)为某个多项式。设（`E`、`D`）为一个SKE方案。设`H` : {0, 1}^∗ → {0, 1}^(*ℓ*)和`G` : {0, 1}^(*λ*) → {0, 1}^(*λ*)为哈希函数（将被建模为随机预言机）。给定这些要素，由FO变换构造的PKE方案Π[FO] = （`KG`[FO]、`Enc`[FO]、`Dec`[FO]）如[图 1.9](#c01.xhtml#c1-fig-9)所示。Π[FO]的明文空间与底层SKE方案相同。

Fujisaki和Okamoto（2013）证明了如果底层PKE方案满足CPA下的单向性，以及一个自然属性：即对于由`KG`生成的任意*pk*，加密算法`Enc`(*pk,* ·)的输出（当其随机数随机选择时）的最小熵足够高（这通常是大多数PKE方案默认满足的），且底层SKE方案是IND-OT安全的，则所得PKE方案Π[FO]在将`H`和`G`建模为随机预言机的RO模型中是IND-CCA安全的。
