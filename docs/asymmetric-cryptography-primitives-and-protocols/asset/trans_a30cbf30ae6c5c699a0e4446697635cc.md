

#### 7.4.2.3. 章节注释与历史

– `KeyGen`(`msk`, `att`)：`EncKey`(`att`) → `r` ← `Z_p`, `usk` = `g_2^r`。它输出 `usk`。

– `Dec`(`mpk`, `ct`, `usk`)：解析 `ct` = (`[V]_1`, `[w]_1`, `P`) 其中 `[w]_1 ∈ G_1`。`Decode`(`P`, `att`) → `d ∈ Z_p^2`，我们将其写为 `d = (d_ct, d_usk)` 其中 `d_ct, d_usk ∈ Z_p`。它输出 `e([V]_1, d_ct) / e([w]_1, d_usk)`。

**正确性**：令 `P` 和 `att` 使得 `P`(`att`) = 1。加密 `Enc`(`mpk`, `P`) 输出 `ct` = (`[U_1 b s | ··· | U_n b s]_1`, `C`, `[b s]_1`, `P`) 其中 `C = EncCt`(`P`)。用户密钥生成 `KeyGen`(`msk`, `att`) 输出 `[a r]_2 [K]_2` 其中 `K = EncKey`(`att`)。解密计算 `e([U_i b s]_1, [a r]_2) / e([b s]_1, [K]_2) = e([a]_1, [b s]_2)^r / e([b]_1, [s]_2)^r` 其中 `α = k^⊤ b s`, `u[i] = (a r)^⊤ U[i] b s` 且最后的等式由谓词编码的正确性得出。

**安全性**：我们证明如果 DDH 在 `G_1` 和 `G_2` 中成立，且谓词编码是安全的，则该 ABE 是安全的。即，我们证明对于所有进行 `q` 次用户密钥查询的可接受 PPT 对手 `A`，存在 PPT 算法 `B_1`、`B_2` 和一个可忽略函数 `ν`，使得对于所有 `λ ∈ N`，`Adv_A^ABE(λ) ≤ Adv_B1^DDH(λ) + Adv_B2^DDH(λ) + ν(λ)` 表示上述 ABE 方案。

我们通过一系列混合游戏进行证明，如下所述。对于任意 `i ∈ [n]`，我们用 `Adv[i]` 表示对手 `A` 和 `Game[i]` 的随机币下，`Game[i]` 在与对手 `A` 交互时输出 1 的概率。

– `Game[0]`(`1^λ`)：这对应于安全定义的游戏（见定义 7.3）；因此，我们有 `Adv[0] = Adv_A^ABE(λ)`。为完整起见，我们在此描述该游戏。它运行 `Setup`(`λ`) → (`mpk`, `msk`) 其中 `msk` = (`[k]_2`, `[a]_2`, `U_i`)。它将 `mpk` 发送给对手 `A`。当 `A` 向其预言机 `O_KeyGen` 发送查询 `att` 时，游戏计算 `[a r]_2 [K]_2` 并将 `usk` 返回给 `A`。在某一时刻，`A` 发送一个谓词 `P`，此时游戏采样 `b ←_R {0, 1}`，计算 `Enc`(`msk`, `mpk`, `P`) → `ct` = (`[U_1 b s | ··· | U_n b s]_1`, `C`, `[b s]_1`, `P`)，`kem` = `[k^⊤ b s]_T`。它设置 `kem[0] = [k^⊤ b s]_T` 和 `kem[1] ←_R G_T`。它将 (`ct`, `kem[b]`) 返回给 `A`。在某一时刻，`A` 发送猜测 `b'`，此时游戏结束，若 `b' = b` 则输出 1，否则输出 0。

– `Game[1]`(`1^λ`)：此游戏同 `Game[0]`，不同之处在于挑战密文按如下方式计算（与 `Game[0]` 的差异已高亮显示）。给定 `P`，它计算 `[z]_1 ←_R G_1`。根据 `G_1` 中的 DDH 假设，这些游戏在计算上不可区分，该假设表明 (`[b]_1`, `[b s]_1`) ≈_c (`[b]_1`, `[z]_1`) 其中 `s ←_R Z_p`。即，存在 PPT 算法 `B_1` 使得 `|Adv[1] - Adv[0]| ≤ Adv_B1^DDH(λ)`。

– `Game[2]`(`1^λ`)：此游戏同 `Game[1]`，不同之处在于 `mpk` 和挑战密文按如下方式计算（与 `Game[1]` 的差异已高亮显示）：`mpk` = (`[b]_1`, (`[U_i b]_1`)[i∈[n]], `[k^⊤ b]_T`)，`ct` = (`[U_1 z | ··· | U_n z]_1`, `C`, `[z]_1`, `P`)，`kem` = `[k^⊤ z]_T` 其中 `(b | z) ←_R GL_2`，而 `Game[1]` 中为 `b ←_R Z_p^2, z ←_R Z_p^2`。回顾 `GL_2` 表示 2 次一般线性群，即 `Z_p` 上 2×2 非奇异矩阵的群。由于随机选择 `(b | z)` 导致 `(b z)` 奇异的概率小于 `2/p`，这两个游戏的统计距离小于 `2/p`。

– `Game[3]`(`1^λ`)：此游戏同 `Game[2]`，不同之处在于挑战密文和用户密钥按如下方式计算（与 `Game[2]` 的差异已高亮显示）：`[a]_2 ←_R G_2^2` 且 `a = a_∥ + α b^⊥`。`[a r]_2 [K]_2` 其中 `b^⊥` 为满足 `b^⊤ b^⊥ = 0` 且 `z^⊤ b^⊥ = 1` 的向量。`Game[3]` 和 `Game[2]` 具有相同的分布，这源于以下两个分布相等：`([a]_2, [a r]_2)` 和 `([a_∥ + α b^⊥]_2, [a_∥ r + α r b^⊥]_2)` 其中 `b^⊥` 为满足 `b^⊤ b^⊥ = 0` 且 `z^⊤ b^⊥ = 1` 的向量。存在一个后处理算法，给定按第一个分布分布的输入，产生按 `Game[2]` 指定分布的输出；而给定按第二个分布分布的输入，同一后处理算法产生按 `Game[3]` 指定分布的输出。即，后处理算法在接收输入后，采样 `r ←_R Z_p` 并直接生成 `A` 的视图。

最后，我们证明 `Game[3]` 中的安全性可归约为上述 ABE 的*密钥*变体的安全性。即，我们构建一个归约 `B_3` 使得 `Adv[3] ≤ Adv_A^sk-ABE(λ)`，其中 `sk-ABE` 是通过转换谓词编码 (`EncCt`, `EncKey`, `Decode`) 获得的密钥 ABE（使用循环群 `G_2`；见[图 7.2](#c07.xhtml#c7-fig-2)）。事实上，`Game[3]` 中引入的向量 `U_i` 和标量 `α ∈ Z_p`（上文高亮部分）充当 `sk-ABE` 方案的密钥。我们现在描述 `B_3`。它从其安全游戏接收公钥 `mpk` = `G_1`。它采样 `(b | z) ←_R GL_2`, `k ←_R Z_p^2` 并发送 `mpk` = (`[b]_1`, (`[U_i b]_1`)[i∈[n]], `[k^⊤ b]_T`) 给 `A`。它计算 `b^⊥` 为满足 `b^⊤ b^⊥ = 0` 且 `z^⊤ b^⊥ = 1` 的向量。每当 `A` 就 `att` 查询其预言机 `O_KeyGen` 时，`B_3` 查询其自身预言机以获取 `[K]_2`，其中 `K = EncKey`(`att`) 是 `sk-ABE` 的全局参数，而 `r ←_R Z_p` 为每次 `usk` 生成新采样，且 `K = EncKey`(`att`)。归约 `B_3` 将 `[a_∥ r + α r b^⊥]_2 [K]_2` 发送给 `A`，它可以计算该值因为它知道值 (`U_i`)[i∈[n]] 和 `a_∥`。当 `A` 发送挑战 `P` 时，`B_3` 将其转发给其自身安全游戏以接收 `ct` = (`u[1] | ··· | u[n]`) `C` 其中 `C = EncCt`(`P`) 且 `kem` = `[γ]_2`，其中 `γ = α` 或 `γ ←_R Z_p`，取决于 `sk-ABE` 安全游戏选取的随机比特。然后，`B_3` 发送 `[U_i z]_1` 和 `kem` = `[k^⊤ z + γ]_T`，它可以计算这些值因为它知道 `k`, `b`, `z` 和 (`U_i`)[i∈[n]]。显然，`B_3` 生成的输出对应于 `A` 在 `Game[3]` 中的视图，且其输入按 `sk-ABE` 的安全游戏分布。因此，我们有 `Adv[3] ≤ Adv_A^sk-ABE(λ)`。最后，根据几页前证明的 `sk-ABE` 的安全性，我们知道存在 PPT 对手 `B_2` 和可忽略函数 `ν` 使得 `Adv_A^sk-ABE(λ) ≤ Adv_B2^DDH(λ) + ν(λ)`。总体而言，我们得到 `Adv_A^ABE(λ) ≤ Adv_B1^DDH(λ) + Adv_B2^DDH(λ) + ν(λ) + 2/p`。
