Homomorphic filtering reduces the low-frequency component of an image in spatial domain to have a high-pass filtering \(f(x, y)\) that transforms to the frequency domain by first converting the product term to addition. It can be achieved by using the logarithm of both sides then applying Fourier transform as shown below [35, 36].

\(\ln[f(x, y)] = \ln[i(x, y)] + \ln[r(x, y)] (10.8)\)

\(\mathfrak{F}[\ln[f(x, y)]] = \mathfrak{F}[\ln[i(x, y)]] + \mathfrak{F}[\ln[r(x, y)]] (10.9)\)

Let

\(\mathfrak{F}(u, v) = I(u, v) + R(u, v) (10.10)\)

Next, to have better illumination high-pass filtering is required.

\(G(u, v) = H(u, v) \cdot \mathfrak{F}(u, v) (10.11)\)

Now, filtered image \(G(u, v)\) is transferred to spatial domain using inverse Fourier transform.

\(g(x, y) = \mathfrak{F}^{-1}[G(u, v)] (10.12)\)

\(g(x, y)\) is not in its original form, therefore, to eliminate the logarithm, an exponential function is used. Figure 10.8 shows the result of applying homomorphic filtering.

### 10.3.4 Discrete wavelet transform

In discrete wavelet transform (DWT), the signal is filtered through a set of digital filters at different scale. It decomposes the image into a sequence of different frequency components. In an image \(N\) level of decomposition can be performed that results in \(3N + 1\) different frequency bands such as, LL, LH, HL and HH. Low-low (LL) frequency components give average information of an image and other frequency components give directional information like low-high (LH), high-low (HL), and high-high (HH) gives horizontal, vertical, and diagonal coefficients, respectively [39, 40].

![](img/75406d5bb714dfd3e68fbbc717bd8f67_245_0.png)

Figure 10.8. Output of homomorphic filtering. (a) Input mammogram image, (b) homomorphic filter output result.

2-D scaling function \(\varphi(x, y)\) and 2-D wavelet function \(\xi^H(x, y), \xi^V(x, y)\) and \(\xi^D(x, y)\) are separable in nature [41]. A function and wavelet function are said to be separable if it can be expressed as

\(\varphi(x, y) = \varphi(x) \varphi(y)\) (10.13)
\(\xi^H(x, y) = \xi(x) \varphi(y)\) (10.14)
\(\xi^V(x, y) = \phi(x) \xi(y)\) (10.15)
\(\xi^D(x, y) = \xi(x) \xi(y)\) (10.16)

\(\phi(x, y)\) gives coefficient of image approximation and intensity variation in different directions found by \(\xi^H(x, y)\), \(\xi^V(x, y)\) and \(\xi^D(x, y)\)

Scaled and translated basis function can be defined as

\(\phi_{j,m,n}(x, y) = 2^{j/2} \phi(2^j x - m, 2^j y - n)\) (10.17)
\(\psi^i_{j,m,n}(x, y) = 2^{j/2} \psi^i(2^j x - m, 2^j y - n)\) (10.18)
\(i = \{H, V, D\}\) (10.19)

The DWT of an \(M \times N\) dimensional image \(f(x, y)\) can be represented as

\(W_\phi(j_0, m, n) = \frac{1}{\sqrt{MN}} \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) \varphi_{j_0, m, n}(x, y)\) (10.20)
\(W_\xi^i(j, m, n) = \frac{1}{\sqrt{MN}} \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) \xi^i_{j,m,n}(x, y)\) (10.21)

![](img/75406d5bb714dfd3e68fbbc717bd8f67_246_0.png)

where \(i = \{H, V, D\}\) refer to the decomposition direction of the wavelet and \(j_0\) is an arbitrary start scale. \(W_\phi(j_0, m, n)\) represents approximation of image \(f(x, y)\) at scale of \(j_0\) and \(W_\psi^i(j, m, n)\) denotes the horizontal, vertical and diagonal coefficients at scale \(j \ge j_0\). DWT is very important in resolution enhancement as well as preserving the high frequency component.

A proper selection of thresholding can denoise the image because many times small value thresholding cannot remove noise and a larger value may cause loss of image detail as well.

Image thresholding can segment an image to obtain the specific feature. It is very difficult to identify the microcalcification in a mammogram using thresholding technique because of its low contrast. Thresholding can also be used for noise attenuation in the spatial domain as well as in frequency domain [42]. Thresholding can be of two types, hard thresholding and soft thresholding.

In hard thresholding pixel value below some threshold is set to zero. It is used to obtain the binary image from the grayscale image. It is defined as

\(f'(m, n) = \begin{cases} f(m, n), & \text{if } |f(m, n)| > t \\ 0, & \text{otherwise} \end{cases} \quad (10.22)\)

Hard thresholding causes ringing effect in the denoised image, soft thresholding method can be a solution to this problem. In soft thresholding, values for both positive and negative coefficients are being shrunk towards zero. It is defined as

\(f'(m, n) = \begin{cases} f(m, n) - t, & \text{if } |f(m, n)| > t \\ f(m, n) + t, & \text{if } |f(m, n)| < -t \\ 0 & \text{if } |f(m, n)| \leqslant t \end{cases} \quad (10.23)\)

Generally, soft thresholding is a better option to minimize the MSE. These wavelet thresholding techniques filter each wavelet coefficient from the detailed sub-bands by using the threshold function to get the modified wavelet coefficients.

## 10.4 Convolutional neural network

Convolutional neural network (CNN) is a deep learning trainable architecture that is a feed-forward neural network consisting of multiple trainable nonlinear transformation stages. It extracts the feature vector in every stage, which represents the input and output vector, respectively. CNN includes the feature extractor in the training process, which modifies the weights during the training process.

CNN consists of two networks one that extracts a feature of the input image and the second classifies the extracted feature [43]. CNN has three types of network layers, which are convolution, pooling, and fully connected layers. The convolution kernel \(h(m, n)\) is also known as the convolution filter passing over the image \(x(m, n)\) and feature map values are calculated as follows.

\(G(m, n) = x(m, n) * h(m, n)\)
\(= \sum_j \sum_k h(i, j)x(m - j, n - k)\)

where ‘m’ and ‘n’ are the pixel coordinates and * is a convolution operator. Convolution is a proficient method of feature extraction with minimum data set redundancy. The convolution kernel is a feature identifier that filters the important feature of the image and produces a convolution map about the distribution of these features. The neurons figure out how to assemble the data to gain a higher-order feature of the image in the next convolutional layers [44]. Since convolution operation shrinks the image, when the kernel moves through the image, the impact of the outskirts pixels on the feature map is very small compared to the center pixels, it might decrease the spatial resolution of the image. CNN uses image padding to minimize this problem. Another method to reduce the feature map size is stride. The stride function is just like a sliding window, that controls the amount of movement of the convolution kernel to the input image. Usually, we shift the kernel by one pixel, but step size can be increased if a small feature map or less overlapping of the receptive field is required. The second layer of CNN is the pooling layer. It reduces the feature map size of the input matrix. There are two pooling mechanisms used in practice which are max pooling and average pooling.

The convolutional layer typically includes a non-linear activation function. Non-linearity is important to model the complex function. Rectified linear unit (ReLU) activation function is generally used because it shows a better convergence rate as compared to the other activation function. It is defined as

\(R(x) = max(0, x)\)

The last hidden layer of CNN is known as fully connected layers [45]. The output of this layer is a column vector, and each row of the column vector corresponds to a different class. Classification of these different classes depends on the probability estimation of each class. Practically, input to the fully connected layer must be as small as possible, whereas pooling and stride reduce the size of the data matrix of fully-connected layers.
