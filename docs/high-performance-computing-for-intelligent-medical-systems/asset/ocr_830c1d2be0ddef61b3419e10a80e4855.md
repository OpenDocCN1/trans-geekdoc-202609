b. Laying of eggs by Cuckoos:
Levy flight method given by equation (8.5) is used by the Cuckoo to generate
a new solution S_new from the current solution S.

```
S_{new} = S + \alpha \oplus Levy(\lambda) \quad (8.5)
```

where step size = \alpha > 0, \oplus = entry-wise multiplication Levy(\lambda) produces a
random walk where exploration is controlled by Levy distribution and
exploitation of search space is determined by producing step length randomly
in the range 1 < \lambda \leqslant 3.

c. New generation selection
The host bird replaces the host eggs with cuckoo eggs to denote the updating
of the old solution with better solutions. If the better cuckoo egg is found, it
will signify the worst solution which will be neglected by the host bird and
the bird will build a new host. This process of building a new host represents
the production of the new solution. The host bird finds the cuckoo eggs with
a probability of \rho_a which plays a major role in search space by denoting both
local and global search, that is, \rho_a = 0.25 corresponds to 25% exploitation
and 75% denotes exploration.
