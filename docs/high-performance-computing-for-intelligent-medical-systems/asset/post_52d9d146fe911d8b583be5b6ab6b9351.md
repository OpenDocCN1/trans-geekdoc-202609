
TP is tested using this standard deviation based threshold point search method. Therefore 10 threshold point and results of them are given in the experimental results. The steps of the TP based feature extraction technique are provided below.

Step 1: Load signals which are $S^C$, $C$, $I$, $R$ and $S^F$.

```
feat$_{S^C}^{TP}$ = TP($S^C$) (2.11)
feat$_{C}^{TP}$ = TP($C$) (2.12)
feat$_{I}^{TP}$ = TP($I$) (2.13)
feat$_{R}^{TP}$ = TP($R$) (2.14)
feat$_{F}^{TP}$ = TP($S^F$) (2.15)
```

Step 2: Apply TP and extract 512 features each signal. TP function is given in Algorithm 2.1.
where feat$_{S^C}^{TP}$, feat$_{C}^{TP}$, feat$_{I}^{TP}$, feat$_{R}^{TP}$ and feat$_{F}^{TP}$ are TP features of the generated signals in the preprocessing phase. TP(.) is ternary pattern function and it extracts 512 features from each signal.

Step 3: Concatenate features of each signal to obtain final TP features.

```
feat$^{TP}$ = feat$_{S^C}^{TP}$|feat$_{C}^{TP}$|feat$_{I}^{TP}$|feat$_{R}^{TP}$|feat$_{S^F}^{TP}$ (2.16)
```

## 2.4.3 Feature reduction

In this phase, we utilized an NCA [47] based novel feature reduction method which generates weights of the features. The generated weights and tangent sigmoid function based method is applied onto features for reduction. Tangent sigmoid function is a widely used activation function in the literature. The mathematical description of it is shown in equation (2.17).

```
tansig($l$) = \(\frac{e^l - e^{-l}}{e^l + e^{-l}}\) (2.17)
```

where $l$ represents input parameter of the tangent sigmoid and tansig( . ) is tangent sigmoid function. The pseudo code of the proposed feature reduction technique is given in Algorithm 2.2.

### Algorithm 2.2: The pseudo code of the proposed NCA and tangent sigmoid based feature reduction method

```
Input: Concatenated features ($feat^C$) with length of M, reduction factor is k
Output: Reduced features ($feat^R$) with length of M/k.
1: $w = NCA(feat^C)$ // Generates weights (w) using NCA
2: $counter = 1$; // Define counter. This counter is used as index of the reduced feature.
3: for i=1 to M step by k do
4:   $p = 0, d = 0$; // Define variable to calculate weighted mean value.
5:   for j=0 to k-1 do
6:     $p = p + w(i + j) * feat^C(i + j)$;
7:     $d = d + w(i + j)$;
8:   end for j
9:   $feat^R(counter) = tansig \left( \frac{p}{d} \right)$;
10: $counter = counter + 1$;
11: end for i
```

As seen in the Algorithm 2.2, NCA is employed to generate weights of the features. The NCA is generally utilized as feature selection approach. The weights generated are used for feature ranking. NCA is a non-parametric method and it uses distance metrics to generate weights. The generated weights are used to calculate weighted average value of the features then the tangent sigmoid function is applied to the average values calculated. In this study, TP and SVD features are reduced separately.

## 2.4.4 Feature concatenation

In the feature concatenation phase, the reduced TP and SVD features are concatenated to obtain final features. After the concatenation process, the length of the final feature is obtained as 80.

feat$^F$ = feat$^R_{TP}$|feat$^R_{SVD}$ (2.18)

where feat$^R_{SVD}$, feat$^R_{TP}$ and feat$^F$ are reduced SVD features, reduced TP features and final features, respectively.

## 2.4.5 Classification

In the classification phase several classifiers are employed. These classifiers are SVM [42, 43], LDA [48, 49], KNN [48, 49] and ANN [50]. The used SVM uses medium Gaussian kernel. The employed SVM has a Gaussian kernel function, with a box constraint level one, multi-kernel scale 8.9. Covariance structure of the used LDA is full. In the KNN, $k$ is selected as 10 and distance metric is chosen as Euclidean distance. In the used KNN, distance weights are calculated by using squared inverse. To obtain testing results of all of the samples, 10-fold cross validation is employed.

## 2.5 Results and discussions

### 2.5.1 Dataset

In this article, a basic hand movements dataset is utilized. This dataset is publicly available and widely used for hand movement recognition experiments and it can be downloaded from the UCI website [51]. This dataset consists of sEMG signals of five subjects consisting of three females and two males who are 20–22 years old. A two-channel Delsys Bagnoli™ Handheld EMG set was located on the arm. To acquire the sEMG data, six basic hand movements were presented by subjects. The used hand movements are cylindrical (CY), hook (HO), lateral (LA), palmar (PA), spherical (SP), and tip (TI). This dataset contains 180 sEMG signals for each hand and person because each movement was repeated 30 times. The frequency of the sEMG data is 500 Hz and the sEMG signals are stored with 6 s. Therefore, each signal has 3000 values [51].
