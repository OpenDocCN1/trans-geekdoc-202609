CNN consists of two networks one that extracts a feature of the input image and the second classifies the extracted feature [43]. CNN has three types of network layers, which are convolution, pooling, and fully connected layers. The convolution kernel h(m, n) is also known as the convolution filter passing over the image x(m, n) and feature map values are calculated as follows.

```
G(m, n) = x(m, n) * h(m, n)
= \sum_j \sum_k h(i, j)x(m - j, n - k)
```

where ‘m’ and ‘n’ are the pixel coordinate and * is a convolution operator.
Convolution is a proficient method of feature extraction with minimum data set redundancy. The convolution kernel is a feature identifier that filters the important feature of the image and produces a convolution map about the distribution of these features. The neurons figure out how to assemble the data to gain a higher-order feature of the image in the next convolutional layers [44]. Since convolution operation shrinks the image, when the kernel moves through the image, the impact of the outskirts pixels on the feature map is very small compared to the center pixels, it might decrease the spatial resolution of the image. CNN uses image padding to minimize this problem. Another method to reduce the feature map size is stride. The stride function is just like a sliding window, that controls the amount of movement of the convolution kernel to the input image. Usually, we shift the kernel by one pixel, but step size can be increased if a small feature map or less overlapping of the receptive field is required. The second layer of CNN is the pooling layer. It reduces the feature map size of the input matrix. There are two pooling mechanisms used in practice which are max pooling and average pooling.

The convolutional layer typically includes a non-linear activation function. Non-linearity is important to model the complex function. Rectified linear unit (ReLU) activation function is generally used because it shows a better convergence rate as compared to the other activation function. It is defined as

```
R(x) = max(0, x)
```

The last hidden layer of CNN is known as fully connected layers [45]. The output of this layer is a column vector, and each row of the column vector is corresponding to a different class. Classification of these different classes depends on the probability estimation of each class. Practically, input to the fully connected layer must be as small as possible, whereas pooling and stride reduce the size of the data matrix of fully-connected layers. During the training process, we calculate the MSE between the restored image and degraded image to optimize the output. In this training model, stochastic gradient descent (SGD) is used for parameter optimization. This can be represented as in [46]

```
w_n^{(i+1)} = w^{(i)} - \beta \cdot \frac{\delta \xi}{\delta w} \quad \forall i = 1, 2, 3....
```
