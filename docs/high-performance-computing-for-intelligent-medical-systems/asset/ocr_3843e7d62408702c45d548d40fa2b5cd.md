All features are fed as input for the different classifiers and default parameters are used for classification. Tenfold cross-validation is applied for evaluating the effectiveness of the proposed system, in tenfold cross-validation, input data is divided randomly into ten parts, one is for testing and the remainder are for training. Each part is trained ten times, similarly each part is tested ten times.
