
- b. Laying of eggs by Cuckoos:
Levy flight method given by equation (8.5) is used by the Cuckoo to generate a new solution S_new from the current solution S.

```
S_{new} = S + \alpha \oplus Levy(\lambda) \quad (8.5)
```

where step size = \alpha > 0, \oplus = entry-wise multiplication. Levy(\lambda) produces a random walk where exploration is controlled by Levy distribution and exploitation of search space is determined by producing step length randomly in the range 1 < \lambda \leqslant 3.

- c. New generation selection
The host bird replaces the host eggs with cuckoo eggs to denote the updating of the old solution with better solutions. If the better cuckoo egg is found, it will signify the worst solution which will be neglected by the host bird and the bird will build a new host. This process of building a new host represents the production of the new solution. The host bird finds the cuckoo eggs with a probability of \rho_a which plays a major role in search space by denoting both local and global search, that is, \rho_a = 0.25 corresponds to 25% exploitation and 75% denotes exploration.

## Steps of CS-BMA

- 1. Initialize the parameters: \rho_a = 0.25, D = 2 dimension, P = 8, Max_generation = 4, generation = 1, MB size = 16 x 16.
- 2. First population NP = 5 where search space is (2P + 1) x (2P + 1).
- 3. Calculate MAD between the candidate MB and the MBs in the reference frame, Bi such that i \in 1 to NP.
- 4. While (generations<Max_generation) do
- 5. The new population of size NP, using Levy flight method V_i is generated which uses equation (8.5).
- 6. By using the fitness approximation approach, MAD is calculated for each V_i by and check the following For i = 1 to NP = 5
  error measure for least value is checked
  i.e. if MAD(V_i) < MAD(B_i)
  B_i = V_i
  end if
  end for
- 7. \rho_a a fraction of the worst solution is swapped with modified solutions obtained by using randomly selected walks.
- 8. Generation is incremented by 1.
- 9. end while
- 10. The lowest value of MAD corresponding to some position in search space is selected for MV calculation.
- 11. end.

## 8.9.8 ABC-DE

## 8.9.10 ‘Deterministically starting-GA’ (GA_Det)

More et al [64] postulated a BMA called ‘Deterministically Starting-GA’ (GA_det) based on the property of adaptive convergence and early deterministic population of GA. This BMA is fruitful for x265 standard type video codec and it adopts the concept of survival of the fittest. The reduction of search points for the best matching MB is the motto of this BMA. Predicted and bi-directional frames are taken to have three reference frames. The early population that is created is taken to be at different spatio-temporal positions in the frames and at pre-specified HEX locations and all are a function of pre-encoded coding units. The newly designed BMA is beneficial for deployment of x265 video codec standard structure. In x265 CODEC’s framework, GA_Det reduces the search point at selected classes of videos which are used for experiment (figure 8.13).

## 8.9.11 Enhanced Grey-wolf optimizer-BMA (EGWO-BMA)

Betka et al [65] suggested a Grey wolf optimizer (GWO) algorithm for solving the problem of ME using the unique learning automata (LA) concept. By doing so, that is, adding the concept of LA, the exploration and exploitation facility of GWO are refined, and also the identification of objective function is done if unimodal or multi-model. Full exploitation of possible regions within the search window is required by a unimodal function. The exploration feature is useful for the multi-model objective function.

The structure found employing LA is then used in appropriate areas to produce new results. In the formation process, two methods are needed. In the first one, the function is updated by exploiting a Gaussian distribution for unimodal function; in the second one, the distribution is randomly explored to support exploration in multimodal function. Then block-based ME is improved by applying EGWO. The EGWO seeks better solutions to all benchmarks than regular GWO. And, six test videos are evaluated by the EGWO algorithm which is compared with many efficient methods. The results highlight that the EGWO experiences only deterioration in efficiency of nearly -0.71 relating to PSNR, which is better than most of the BMAs. Moreover, it achieves a better degree of efficiency with very few search points, that is, tests 10.34 MBs in the target frame per candidate MBs in the candidate frame and displays the appropriateness of EGWO for accurate optimization with complications.
