**Specificity:** Specificity belongs to negative class, and it is defined as the percentage of the correctly identified actual negative events. It can expressed as,
SPE(%) = TN / (TP + FP) × 100%
(1.16)

**Negative predicted value:** It is defined as the ratio of the total number of real negative events to the total number of negative events. It can be computed as
NPV(%) = TN / (TN + FN) × 100%
(1.17)

**False negative rate:** It is defined as when an actual is positive and how often the classifier predicted negative. It can be computed as
FNR(%) = FN / (TP + FN) × 100%
(1.18)

**False positive rate:** It is defined as when an actual event is negative and how often the classifier predicted positive. It can be given as
FPR(%) = FP / (FP + TN) × 100%
(1.19)

True positive (TP): It is the number of correctly identified HPT subjects by the proposed model.
False positive (FP): It is the number of normal samples classified incorrectly by the proposed model.
False negative (FN): It is the number of incorrectly identified HPT subjects by the proposed model.
True negative (TN): It is the number of correctly identified normal subject by the proposed model.
