# # Chapter 2
# Computational intelligence in surface electromyogram signal classification
Turker Tuncer, Sengul Dogan, Fatih Ertam and Abdulhamit Subasi

The objective of this book chapter is to introduce a solution for disabled people based on a man–machine interface, which can work on data processed by computational intelligence techniques. The model utilizes computational intelligence techniques for hand movement classification. On this basis, a novel computational intelligence approach, which is called a spider network for the recognition of basic hand movements employing surface electromyogram signals is presented. The main components of the spider network are pre-processing, feature extraction, feature reduction, and classification. In the preprocessing phase, the surface electromyogram signals from two different channels are concatenated. In the feature extraction phase, Discrete Cosine Transform (DCT) and Fast Fourier Transform (FFT) are applied to concatenated signals to obtain frequency coefficients of the surface electromyogram signal. Besides, Singular Value Decomposition and Ternary Pattern are utilized. The extracted features are divided into two groups according to feature extractors. To select distinctive features, Neighborhood Component Analysis is employed as a weight generator. By using these weights and tangent sigmoid activation function, the features are reduced. In the classification phase, Linear Discriminant Analysis, Artificial Neural Network, k-nearest neighbor, and Support Vector Machine are employed for the classification task. The proposed model is optimized and validated based on the accomplishment of the built framework, which can produce accurate, and consistent solutions for the surface electromyogram based prosthetic device control, intending to help amputees or congenitally deficient limbs. The proposed model achieved 100% classification accuracy in hand movement classification.
