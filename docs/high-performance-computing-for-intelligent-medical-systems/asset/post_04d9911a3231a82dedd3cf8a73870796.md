## 2.6 Conclusions and suggestions

A novel feature extraction framework called SN is presented in this chapter. The main aim of the SN is to combine efficient methods in order to classify signals with a high accuracy rate. The proposed SN uses DCT, FFT, TP, SVD, and a novel NCA-based feature reduction method to achieve high success rates. Several classifiers are also used to create different cases with several parameters. The results obtained were compared to the other state-of-the-art methods and the developed model achieved an average accuracy of 100.0%. This result is approximately 1.45% higher than the previous studies. The computational complexity of the developed model is equal to _O(n)_. Moreover, the developed method is a cognitive method because it does not use any optimization technique. The effective methods are used together to achieve high accuracy rates. According to the experimental results, a cognitive, lightweight, and high accurate feature extraction framework is presented. The proposed SN resulted in high performance using conventional classifiers. Although the used dataset in the experiments is small, the proposed method can be tested on big datasets. ANN achieved better performance and it proved that the proposed SN could achieve a high success rate using a large dataset. Hence, a deep feature extraction method is presented for the recognition of basic hand movements using sEMG signals. The proposed SN is the first framework for basic hand movement recognition as far as we know. Novel physiotherapy devices and smart mechanical hands and gloves can be developed using the proposed SN for amputees. The proposed SN is also an extendable method. The main aim of the SN is to combine effective methods such as FFT, DCT, SVD, TP, NCA to achieve better classification performance. The proposed SN framework can be applied to other signals such as ECG, EEG, and speech, etc.
