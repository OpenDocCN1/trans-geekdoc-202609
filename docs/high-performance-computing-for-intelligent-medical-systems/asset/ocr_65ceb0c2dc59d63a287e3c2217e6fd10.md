# 13.4.2 Intracranial tumor's temperature control

The primary aim is to automatically control the minimum temperature of brain tissues of a tumor patient who received interstitial hyperthermia treatment (IHT) [72]. In IHT, a catheter array is embedded in the tumor tissue during neurosurgery. The catheters work as temperature sensors as well as actuators. Tumor's temperature control using PID optimization techniques is shown in figure 13.4. The model for tumor tissues temperature control was established in [72] and can be represented by:

G_p(s) = \frac{Y(s)}{U(s)} = \frac{K e^{-sL}}{1 + sT} \quad (13.4)
