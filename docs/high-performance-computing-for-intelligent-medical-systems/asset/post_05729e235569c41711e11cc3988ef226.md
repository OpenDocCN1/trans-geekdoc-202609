### 9.4.5 Bagging ensemble method

Bagging is an ensemble of machine learning algorithms. We can use these machine learning algorithms in a multiple dataset. So we can use it for a Parkinson’s medical dataset for a multiple weak model to aggregate the predictions and get the final prediction (figure 9.6). It reduces variance and avoids over-fitting [17].

The main objective of this chapter is to prepare a classification framework which focuses on important features and their consistency values for each test. We evaluated many machine learning classification algorithms. We used Bagging ensemble method as the proposed method. The proposed work is demonstrated by achieved methodology in figure 9.7. All the proposed work is divided in three parts (I, II and III). These are described by following details:

- I. Experiment-I evaluated the prediction of a previous Parkinson’s dataset and compared Decision Tree, Naïve Bayes, RF, Extra Tree and Bagging Ensemble method.

- II. Features importance is the selection process by which we find out the available important features in the whole dataset. We used these important features in prediction by selected machine learning algorithms and improved the outcomes.

### 9.4.6 Features selection method in Parkinson’s disease

- Chi Square method
- Measure Feature Importance by Extra Tree and Measure Feature Selection by Heat Map Matrix

- III. Experiment-III evaluated the prediction of newly prepared Parkinson’s dataset after features selection and compare Decision Tree, Naïve Bayes, RF, Extra Tree and Bagging Ensemble Method.
