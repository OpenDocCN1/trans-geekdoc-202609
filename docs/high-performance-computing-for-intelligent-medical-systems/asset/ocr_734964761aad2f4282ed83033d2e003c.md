It consists of several skip connections between analysis layers and synthesis path layers. It is based on an approach to a serial ensemble. The very first system segments the entire tumor, then, the core of the tumour is segmented by the second system and, eventually, the output of the second stage is used in the third stage, which is the enhancing stage. The voxel-based image segmentation is initially performed by shallow CNN [123]. In [120] authors suggested the use of CNN multi-path architecture for voxel classification. One route uses a 32 × 32 2D patch and the other uses fully connected 5 × 5 patch-size input with a middle pixel similar to a 32 × 32 patch. There is a patch collection so that the labels are equiprobable. L1 and L2 regularizations overcome overfitting.

The depth of such a DL model increased. For instance, researchers of [124] made use of a DL model where FC layer has separate HGG and LGG layers. A cascaded CNN has been proposed in [125]. The model utilized a two-path deep CNN model initially, after which, the outputs are used with other 2D CNNs. Wang et al [123] also used residual connections with both pathways of a two-path deep CNN model, and trained using varying input image sizes. A dilated CNN type residual network has also been used for training with image patches in [126].

The authors in [127] implemented brain tumour segmentation using U-net architecture. The authors in [128] changed the 3D input U-net and reduced the network depth to three. In [129], the authors suggested new architectures of encoder-decoders that worked well on several problems with the biomedical image segmentation. For deep segmentation tasks, various CNN approaches using single-path have also been implemented in [130-134]. Ensemble CNNs are more efficient than single CNNs, as was the case in [135], where authors introduced a seven-network ensemble that uses DeepMedic, FCN, and U-net and variations in the three networks.

The authors in [136] had implemented the set of 10 architectures based on the encoder–decoder and the auto-encoder-stream for additional details and regularisation purposes. The authors’ method suggested in [137] was expanded in [138]. They use U-net and Densenet combinations with an architecture like U-net that includes dense dilated convolution blocks. Three networks, which are WNet, TNet and ENet, were used by the authors in [123] to build a cascaded framework. These networks use axial, coronal, sagittal viewing angles to produce the final segmentation output.
