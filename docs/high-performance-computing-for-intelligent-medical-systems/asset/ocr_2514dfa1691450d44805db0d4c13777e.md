# 4.4.3 Convolutional neural network model

Convolutional neural networks are specialized kinds of networks for processing data using specified and grid-like topologies. Examples include time series (like the PPG segments here we use), which can be thought of as one-dimensional data, and images, which can be considered two-dimensional data. CNNs have been enormously successful in various practical applications. They use convolution instead of common matrix multiplications in at least one layer. In traditional fully-connected networks, every output unit interacts with every input unit. This makes them prone to overfitting. CNNs, however, have sparse interactions. It is achieved by making the kernels smaller than the input [17].

In this section, we propose an end-to-end architecture based on CNN networks. We apply segments separately to the network. The network will extract abstractions of the input signal in successive layers. Then, the network uses these extracted representations to carry out the estimation procedure [24].
