# 8.3.3 JPEG-LS

The standard denoted by JPEG-LS summarizes lossless and near-lossless compression procedures for compressing grayscale, bi-level, and color images [51]. Several significant improvements including ease of implementation, lower memory requirement, and lesser complexity are possessed by JPEG-LS. The compression attained by JPEG-LS is very comparative with the methods that are based on more computationally challenging coding practices, like arithmetic coding, despite the simplicity of the coding procedures. Since JPEG-LS provides state-of-the-art lossless compression efficiency, for some medical applications requiring lossless compression, it is especially suitable.

# 8.3.4 JPEG-XR

To compress continuous-tone images like photographic images, the JPEG-XR standard was introduced [62]. Two features of JPEG-XR are the key features that are very important for medical image compression, namely the JPEG-XR standard that supports depths up to 32 bits for the input image. Second, both lossy and lossless compression is provided by JPEG-XR standard with the identical signal flow path.

# 8.3.5 H.265

The Joint Collaborative Team on Video Coding (JCT-VC) suggested another name High-Efficiency Video Coding (HEVC) to H.265 video coding standard which is jointly recognized by the ITU-T Video Coding Experts Group (VCEG) and the ISO/IEC Moving Picture Expert Group (MPEG) [67]. In the case of efficiency in the coding of materials/images captured by the camera, HEVC/H.265 shows better results than the existing coding standard up to 50% reduced bit-rate while keeping the same perceptual quality [67]. In 1993, a new and improved video coding standard, namely Digital Imaging and Communications in Medicine (DICOM), was released. This standard is a very well-accepted standard for medical image data processing. It has transformed radiology exercises to digitally equipped data from the film-based workflow.

Three-dimensional information is available in a video signal which is modeled in spatial and temporal domains. The compression of videos is done by eliminating the redundant information available in both domains. Experimental evidence revealed that transform domain coding techniques are suitable to exploit spatial redundancies much better than predictive coding techniques, whereas the temporal redundancies can be exploited using predictive coding like Differential Pulse Code Modulation (DPCM) and Adaptive Differential Pulse Code Modulation (ADPCM).
