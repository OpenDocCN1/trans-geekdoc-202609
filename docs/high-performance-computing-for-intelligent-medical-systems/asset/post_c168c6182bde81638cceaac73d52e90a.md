- **Curse of dimensionality:** When the input dimension increases, machine-learning problems become exceedingly difficult. It is because the range of input configurations will increase exponentially. This problematic phenomenon is known as the curse of dimensionality [17].

![](img/75406d5bb714dfd3e68fbbc717bd8f67_115_0.png)

Most of the time, the challenge posed by the curse of dimensionality is statistical. When the dimension increases, fewer training samples fall into the exploding number of cells (or defined subspaces) in the input space. Therefore, the number of training samples for various areas in the input space decreases rapidly with increasing dimension. Less training data results in poorer performance inevitably. In such situations, the machine learning algorithm might simply assume that the output corresponding to a new input equals the value for the nearby points, while the further distance between training samples in a high dimensional space reduces the accuracy of such a simplification [17, 21].

As our results in the following sections indicate more clearly, the same problem might have occurred here. Since the input dimension (250) is very high, the LSTM model shows unsatisfactory performance. In the following models, we try to implement strategies to mitigate this problem.

## 4.4.2 PCA-LSTM model

To find out a solution for the difficulties that the LSTM network had with high-dimension input vectors, we apply Principal Component Analysis (PCA) method. It is an approach to reduce the input dimension.

There are two common ways to illustrate PCA. It can be obtained by the orthogonal projection of the data onto a new space with a lower dimension. The new space is named the principal subspace. The projection is carried out in such a way as to maximize the variance of the projected data.

Another illustration considers PCA as a technique to map our data to a new space with a lower dimension while minimizing the projection cost. Projection cost, here, refers to the mean squared distance between primary data and their projected counterparts [22].

- **Proposed model based on PCA and LSTM networks:** In this section, we apply PCA to the input data. It organizes the information into principal components. We choose 64 components with the highest amount of information (corresponding to the dimensions with the maximum amounts of variance) to represent our data. Then, we use the new data set to train and evaluate another LSTM network with the same architecture as the previous network.

- **Performance:** The new training, validation, and testing sets were used to train and evaluate the LSTM network. Since the input dimension was much lower than the dimension of the original data (64 compared to 250), the network converged much faster during the training phase. Table 4.2 and figure 4.7 show the performance of the LSTM network using different metrics. These results confirm a higher estimation precision for the LSTM network based on the new data. Since the training procedure is now easier, we could expect the performance would improve. However, the accuracy is still not high enough to meet the requirements of the AAMI standard.

- **Information loss:** Discarding vectors where the data variance is lower will cost us some information loss. This procedure can be considered as a simplistic feature selection approach. Since the process is uncontrolled, it might result in

## 4.4.3 Convolutional neural network model

Convolutional neural networks are specialized kinds of networks for processing data using specified and grid-like topologies. Examples include time series (like the PPG segments here we use), which can be thought of as one-dimensional data, and images, which can be considered two-dimensional data. CNNs have been enormously successful in various practical applications. They use convolution instead of common matrix multiplications in at least one layer. In traditional fully-connected networks, every output unit interacts with every input unit. This makes them prone to overfitting. CNNs, however, have sparse interactions. It is achieved by making the kernels smaller than the input [17].

In this section, we propose an end-to-end architecture based on CNN networks. We apply segments separately to the network. The network will extract abstractions of the input signal in successive layers. Then, the network uses these extracted representations to carry out the estimation procedure [24].
