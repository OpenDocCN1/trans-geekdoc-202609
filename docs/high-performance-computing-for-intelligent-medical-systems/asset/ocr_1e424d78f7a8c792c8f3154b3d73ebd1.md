# 9.4.2 Naïve Bayes

Naïve Bayes is a very fast predictor. In this chapter we take Parkinson's medical dataset for prediction (figure 9.4). Naïve Bayes performed fast prediction on a class of test data and categories of a numeric medical dataset [14].

# 9.4.3 Random forest

RF is a uniform split test predictor for a medical dataset. Random tree judges the next and best split of a tree in the selected variables (figure 9.5). RF (TD: Training Data; DT : Decision Tree) compares irrelevant and correlated variables [15].

# 9.4.4 Extra tree

Extra tree has two different keys compare to random tree:

+   - split tree without replacement;
+   - nodes split are not best splits;
+   - it is used for averaging improved accuracy in prediction;
+   - It also controls the over-fitting [16].
