When examining the open-text feedback, it is essential to understand the customer’s undertones or patients’ emotions. It is possible to use a set of techniques called sentiment analysis [92]. Sentiment analysis uses machine learning, and it can be supervised or unsupervised. Advanced sentiment analysis even understands irony and sarcasm. We can also run aspect-based sentiment analyses to find the reasons behind the positive or negative responses. The simplest way is to review: positive, negative, or neutral. This is called free-text classification based on polarities and high accuracy rates can be found also by this method [93]. Split or stratified classifications could give even more information to support improvements [93].

It is noticeable that health consumers can give responses and ideas of usability aspects of feedback systems. User acceptance issues deal typically with flexibility of feedback delivery systems. It is important that feedback delivery is fast enough, the system and its guidelines and outlook are understandable enough, and system use is easy enough for all kinds of users. Aspects of patient privacy are such issues that require special attention because patients are not eager to use applications if they have doubts and questions in this area. Feedback gives material in evolving the system better ‘fit for use’.
