The frequency response of LPF \(K(\omega')\) is given as

\(K(\omega') = \left\{ \begin{array}{ll} (s_1 s_2)^2, & |\omega'| < \omega_{ph} \\ (s_1 s_2)^2 \frac{1}{\theta} . \frac{\omega' - \omega_{ph}}{\omega_s - \omega_{ph}}, & \omega_{ph} \leqslant \omega' \\ (s_1 s_2) \frac{1}{2} \theta . \frac{\pi - \omega' + \omega_{ph}}{\omega_s - \omega_{ph}}, & -\omega_s \leqslant \omega' \leqslant -\omega_{ph} \\ 0, & |\omega'| \geqslant \omega_s \end{array} \right.\) (1.1)

The frequency response of HPF \(H(\omega')\) is given as,

\(H(\omega') = \left\{ \begin{array}{ll} (2 s_3 s_4)^{1/4} \theta . \frac{\pi - \omega' - \omega_0}{\omega_s - \omega_{ph}}, & \omega_0 \leqslant \omega' < \omega_1 \\ (2 s_3 s_4)^{\frac{1}{2}}, & \omega_1 \leqslant \omega' < \omega_2 \\ (2 s_3 s_4)^{\frac{1}{2}} \frac{1}{\theta} . \frac{\omega' - \omega_2}{\omega_3 - \omega_2}, & \omega_2 \leqslant \omega' \leqslant \omega_3 \\ 0, \omega' \in [0, \omega_0) \bigcup (\omega_3, 2 \pi) & \end{array} \right.\) (1.2)

where, phase frequency \((\omega_{ph})\) is given as,

\(\omega_{ph} = \frac{(1 - \beta) \pi}{s_1} + \frac{\epsilon}{s_1}\) (1.3)

\(\omega_s = \frac{\pi}{s_2}, \omega_0 = \frac{(1 - \beta)\pi + \epsilon}{s_2}, \omega_1 = \frac{s_1\pi}{s_2s_3}, \omega_2 = \frac{\pi - \epsilon}{s_2}, \omega_3 = \frac{\pi + \epsilon}{s_3}\)

**Quality factor (Q)** is used to control the frequency resolution. It is the proportion of focal recurrence and the band width, it can be computed as,

\(Q = \frac{(2 - \beta)}{\beta}\) (1.4)

For proper and smoothed reconstruction of the signal \(\beta\) is always less than 1.

**Dilation factor (R)** is used to control the size of the wavelet and can be expressed as,

\(R = \frac{s_3}{s_4} \times \frac{1}{1 - (\frac{s_1}{s_2})}\) (1.5)

For proper recovery of the information and to reduce the losses, \(R\) should be greater than 1.

## 1.2.3 Feature extraction

In this chapter, features are extracted from the subbands of decomposed ECG signal using the FAWT method.

Eight features are extracted from subbands which are represented as [45]:

- 1. **Variance (VAR):** Variance is defined as the expectation of the squared deviation from its mean. It can be given as,

\(VAR = \frac{1}{N - 1} \sum_{i=1}^N (x_i - \mu)^2\) (1.6)

- 2. **Integrated ECG (IECG):** It is used in the onset detection index in the subband and the sum of absolute value of these subbands is defined as \(IECG\), it can be expressed as,

\(IECG = \sum_{i=1}^N |x_i|\) (1.7)

- 3. **Mean absolute value (MAV):** It is an average of absolute value of a subband and it can be computed as,

\(MAV = \frac{1}{N} \sum_{i=1}^N |x_i|\) (1.8)

- 4. **Mean (\(\mu\)):** It is an average value of a subband extracted from FAWT, it can be expressed as,

\(\mu = \frac{1}{N} \sum_{i=1}^N x_i\) (1.9)

- 5. **Simple square integral (SSI):** It expresses the energy contained by subband and it can be computed as,

Figure 1.3. Subbands for normal and HPT class ECG signal.

SSI = \(\sum_{i=1}^N |x_i^2|\) (1.10)

- 6. Root mean square (RMS): It is defined as squared mean of subband and can be given as,

RMS = \(\sqrt{\frac{1}{N} \sum_{i=1}^N x_i^2}\) (1.11)

- 7. Standard deviation (STD): It is the dispersion of signal with respect to the mean, it can be formulated as,

STD = \(\frac{1}{N-1} \sum_{i=1}^{N-1} (x'_{i+1} - x'_i)^2\) (1.12)

- 8. Log detector (LOG): It provides an estimate of blood force exerted on the walls of arteries, logarithmic change of nonlinear detector is defined as LOG detector. It can be computed as,

LOG = \(e^{\frac{1}{N} \sum_{i=1}^N x_i^2}\) (1.13)

where, \(x_i\) is the \(i\)th subband with \(N\) number of samples.

## 1.2.4 Classification techniques

Classifiers are used to categorize input data into two or more classes. The feature matrix is provided as an input for classifiers. In this chapter, four different classifiers are used to classify HPT and normal signals. In the case of decision tree classifiers, three kernel functions are used, namely simple tree, complex tree and medium tree. An ensemble tree classifier is used following kernel namely bagged tree, boosted tree, subspace discriminant, and subspace k-NN. Linear, medium Gaussian and coarse Gaussian types of kernel functions are used in SVM. In k-NN, six kernel functions are used, namely the cosine, fine, coarse, medium, cubic and weighted kernels. Details of these classifiers can be found in [46–49].

- 1. **Decision tree classifiers (DTC):** It is a tree-structured supervised machine learning classifier where internal nodes represent the characteristics of a given input feature, branches represent decision rules and each leaf node represents the output. DTC is used to separate a complicated decision-making process into a set of simpler decisions. The performance of the DTC is based on the type of given input features.

- 2. **Ensemble tree (ET):** ET classifier is based on the principle of ensemble, that is, the stronger learner is always generated from the group of various weak learners. In this classifier multiple decisions are combined together for producing better classification results.

- 3. **Support vector machine (SVM):** In SVM two classes can be separated using linear and hyper plane. SVM is the robust prediction method and it depends upon the statistical learning framework. Two types of kernel functions are used in SVM, namely Gaussian and linear.

- 4. **K-nearest neighbor (K-NN):** It is a nonparametric, supervised machine learning classification technique. K-NN algorithm stores all the given input features and classifies a new feature point based on the similarity. It can be more effective for large input data.

## 1.2.5 Performance parameters

The performance of the proposed method is analyzed by computing quality parameters, namely specificity (SPE), sensitivity (SEN) and accuracy (ACC), false-negative rate (FNR), negative predicted value (NPV) and false positive rate (FPR) [50].

**Accuracy:** It is the ratio of the total number of true identified events to the total number of events. It can be computed as,

ACC(%) = \(\frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}} \times 100\%\) (1.14)

**Sensitivity:** Sensitivity belongs to positive class, and it is defined as the percentage of the correctly identified actual positive events. It can be given as

SEN(%) = \(\frac{\text{TP}}{\text{TP} + \text{FN}} \times 100\%\) (1.15)

**Specificity:** Specificity belongs to negative class, and it is defined as the percentage of the correctly identified actual negative events. It can be expressed as,
SPE(%) = TN / (TN + FP) × 100%
(1.16)

**Negative predicted value:** It is defined as the ratio of the total number of real negative events to the total number of negative events. It can be computed as
NPV(%) = TN / (TN + FN) × 100%
(1.17)

**False negative rate:** It is defined as when an actual is positive and how often the classifier predicted negative. It can be computed as
FNR(%) = FN / (TP + FN) × 100%
(1.18)

**False positive rate:** It is defined as when an actual event is negative and how often the classifier predicted positive. It can be given as
FPR(%) = FP / (FP + TN) × 100%
(1.19)

True positive (TP): It is the number of correctly identified HPT subjects by the proposed model.
False positive (FP): It is the number of normal samples classified incorrectly by the proposed model.
False negative (FN): It is the number of incorrectly identified HPT subjects by the proposed model.
True negative (TN): It is the number of correctly identified normal subject by the proposed model.
