# D. Mixed ML classifiers.

kNN classifier is a simple and efficient ML technique that can divide a feature vector into different categories by using a distance metric. Application in voice pathology detection has also been reported. Examples of some of the features that have been used with kNN are: HNR, shimmer, turbulent noise index, jitter, and normalized first harmonic energy. The use of these features with kNN on the MEEI data set resulted in accuracy of 96.1% [125]. The authors of [126] have used kNN with HNR and energy spectrum features to diagnose pathologies such as adductor, vocal fold nodules, laryngeal paralysis, polyp, and Edema. They extracted HNR features using four different frequency ranges after which they were combined to form a single feature vector. The resulting single vector was extracted for all voice samples and concatenated to represent the HNR features of the specific class. Another feature vector used by the authors is the normalized energy produced by the use of 21 bandpass filters. The second collection of features is an intentional effort to mimic the neural structure of the human auditory system. The two unique features of the kNN classifier showed very similar performance, that is, 94.28% and 92.38% accuracy for HNR and normalized energy characteristics, respectively. Research has shown that these two features can aid in the identification of laryngeal pathologies. It is also computationally less expensive as it needs only short duration signals. While other simple frequency and acoustic features extraction techniques work better with longer period signals, making them more computationally expensive.

Random forest (RF) or decision tree has also been used for speech features for the binary classification of pathological voice signals. The idea of RF is to combine a lot of binary decisions that are made using different bootstrap samples of the original data with random subsets to get an accurate predictor. The advantages of the RF method are that it is robust when additional trees are added and that the error of generalization is of limited value. For example, [127] researchers have developed a combined feature vector using 28 separate speech feature vectors, that is, 10 MFCC features, kurtosis, fundamental frequency, jitter, energy, shimmer coefficients, power factor, amplitude, timing, minimum and maximum signal values using the voice samples in the SVD data collection. The training of these combined and class-specific feature vectors produced 100% accuracy. However, there is a need to analyze a dataset where several pathologies are present.

K-means clustering is an unsupervised technique that assigns hard cluster numbers to data points by iteratively deciding the best value of cluster centers. The Euclidean distance metric is used to evaluate pixels with identical properties after which they are grouped into clusters. The [128] researchers have introduced a k-means clustering concept on the features extracted from the voice samples in the MEEI data collection. Features are measured using non-negative matrix factoring and adaptive time–frequency distribution. Pathological voice is non-uniform or non-stationary in nature and thus affects its distribution over time. Consequently, the crucial problem seen with such a short-length signal extraction technique is the loss of information that is more likely to occur when signals are chopped off.
