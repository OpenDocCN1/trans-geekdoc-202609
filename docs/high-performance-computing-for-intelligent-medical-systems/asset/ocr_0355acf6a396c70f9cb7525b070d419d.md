2-D scaling function \(\varphi(x, y)\) and 2-D wavelet function \(\xi^H(x, y), \xi^V(x, y) \ \& \ \xi^D(x, y)\) are separable in nature [41]. A function and wavelet function are said to be separable if it can be expressed as

```
\(\varphi(x, y) = \varphi(x) \varphi(y)\) (10.13)
\(\xi^H(x, y) = \xi(x) \varphi(y)\) (10.14)
\(\xi^V(x, y) = \phi(x) \xi(y)\) (10.15)
\(\xi^D(x, y) = \xi(x) \xi(y)\) (10.16)
```

\(\phi(x, y)\) gives coefficient of image approximation and intensity variation in different directions found by \(\xi^H(x, y)\), \(\xi^V(x, y)\) and \(\xi^D(x, y)\)

Scaled and translated basis function can be defined as

```
\(\phi_{j,m,n}(x, y) = 2^{j/2} \phi(2^j x - m, 2^j y - n)\) (10.17)
\(\psi^i_{j,m,n}(x, y) = 2^{j/2} \psi^i(2^j x - m, 2^j y - n)\) (10.18)
\(i = \{H, V, D\}\) (10.19)
```

The DWT of an \(M \times N\) dimensional image \(f(x, y)\) can be represented as

```
\(W_\phi(j_0, m, n) = \frac{1}{\sqrt{MN}} \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) \varphi_{j_0, m, n}(x, y)\) (10.20)
\(W_\xi^i(j, m, n) = \frac{1}{\sqrt{MN}} \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) \xi^i_{j,m,n}(x, y)\) (10.21)
```
