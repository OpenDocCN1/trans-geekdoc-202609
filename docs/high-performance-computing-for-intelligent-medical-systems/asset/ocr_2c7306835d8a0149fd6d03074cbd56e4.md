# 2.3 Background

In this study, DCT, FFT, SVD, TP, and different machine learning techniques are used to create an SN. Brief explanations about these methods are given in this section.

# 2.3.1 Discrete cosine transform

The DCT is one of the widely used transformations for signals and images. It helps to obtain transformation coefficients of the signals using cosine based equations. The JPEG algorithm, as the mostly known image compression method, uses DCT. In this study we used 1D-DCT because sEMG signals are used for hand movement recognition [37].

# 2.3.2 Fast Fourier transform

Coley and Tukey proposed FFT in 1965 to decrease processes of the Discrete Fourier Transform (DFT). This process led to a rapid rise in DFT applications in digital signal processing and other fields. It has also led to the development of other algorithms. All these algorithms are known as FFT algorithms. The number of operations required for the DFT account has been greatly reduced and ease of operation is provided with FFT. FFT is an effective and economical algorithm for calculating DFT. It is one of the phenomena of signal processing. Hence, we used it in the proposed SN [38].

# 2.3.3 Singular value decomposition

SVD is a matrix factorization method and it generates three components from a matrix. Generally, the singular values have been utilized to construct feature vectors. It is a widely used method in signal processing, image processing, face recognition, perceptual hashing and Google page rank algorithms [39, 40].
