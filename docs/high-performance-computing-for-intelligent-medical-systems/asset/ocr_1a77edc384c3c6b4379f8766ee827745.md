Figure 10.9 shows the image denoising process using a wavelet transform. Thresholding is a very important process in image denoising. A proper selection of thresholding can denoise the image because many times small value thresholding cannot remove noise and a larger value may cause loss of image detail as well.

Image thresholding can segment an image to obtain the specific feature. It is very difficult to identify the microcalcification in a mammogram using thresholding technique because of its low contrast. Thresholding can also be used for noise attenuation in the spatial domain as well as in frequency domain [42]. Thresholding can be of two types, hard thresholding and soft thresholding.

In hard thresholding pixel value below some threshold is set to zero. It is used to obtain the binary image from the grayscale image. It is defined as

```
f'(m, n) = \begin{cases} f(m, n), & \text{if } |f(m, n)| > t \\ 0, & \text{otherwise} \end{cases} \quad (10.22)
```

Hard thresholding causes ringing effect in the denoised image, soft thresholding method can be a solution to this problem. In soft thresholding, values for both positive and negative coefficients are being shrink towards zero. It is defined as

```
f'(m, n) = \begin{cases} f(m, n) - t, & \text{if } |f(m, n)| > t \\ f(m, n) + t, & \text{if } |f(m, n)| < -t \\ 0 & \text{if } |f(m, n)| \leqslant t \end{cases} \quad (10.23)
```

Generally, soft thresholding is a better option to minimize the MSE. These wavelet thresholding techniques filter each wavelet coefficient from the detailed sub-bands by using the threshold function to get the modified wavelet coefficients.
