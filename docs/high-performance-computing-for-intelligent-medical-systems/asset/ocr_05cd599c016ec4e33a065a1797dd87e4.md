In this study, we used the regression model to estimate confirmed cases of COVID-19. We have used linear, logarithmic and polynomial regression models for best fitting curve. These regression models generate equations for different parameters of COVID-19 dataset and calculate confirmed Covid cases due to no. of days. The proposed functional model is calculated as:

```
y = 2215 × x – 90346   R² = 0.647   (6.7)
y = 69059 ln(x) – 20360   R² = 0.309   (6.8)
y = 0.438x³ – 57.48x² + 2106 × x – 16643   R² = 0.997   (6.9)
```

Equations 6.7–6.9 represent linear, logarithmic and polynomial regression models for best fitting curve. Equation (6.7), represents the linear regression model by high parameter values with low R2 values (R2 < 1) and equation (6.8), represents that the logarithmic regression model is very poor because it has major deviation from the best fit line/curve. In equation (6.9), we find the three-order polynomial regression model measured better results compared with equations (6.7) and (6.8); the three-order polynomial regression model represents high R2 value near 1.
