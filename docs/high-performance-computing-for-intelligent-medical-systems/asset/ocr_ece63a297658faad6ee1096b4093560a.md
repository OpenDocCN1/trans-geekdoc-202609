# 1.2.4 Classification techniques

Classifiers are used to categorize input data into two or more classes. The feature matrix is provided as an input for classifiers. In this chapter, four different classifiers are used to classify HPT and normal signals. In the case of decision tree classifiers, three kernel functions are used, namely simple tree, complex tree and medium tree. An ensemble tree classifier is used following kernel namely bagged tree, boosted tree, subspace discriminant, and subspace k-NN. Linear, medium Gaussian and coarse Gaussian types of kernel functions are used in SVM. In k-NN, six kernel functions are used, namely the cosine, fine, coarse, medium, cubic and weighted kernels. Details of these classifiers can be found in [46–49].

+   1. **Decision tree classifiers (DTC):** It is a tree-structured supervised machine learning classifier where internal nodes represent the characteristics of a given input feature, branches represent decision rules and each leaf node represents the output. DTC is used to separate a complicated decision-making process into a set of simpler decisions. The performance of the DTC is based on the type of given input features.

+   2. **Ensemble tree (ET):** ET classifier is based on the principle of ensemble, that is, the stronger learner is always generated from the group of various weak learners. In this classifier multiple decisions are combined together for producing better classification results.

+   3. **Support vector machine (SVM):** In SVM two classes can be separated using linear and hyper plane. SVM is the robust prediction method and it depends upon the statistical learning framework. Two types of kernel functions are used in SVM, namely Gaussian and linear.

+   4. **K-nearest neighbor (K-NN):** It is a nonparametric, supervised machine learning classification technique. K-NN algorithm stores all the given input features and classifies a new feature point based on the similarity. It can be more effective for large input data.

# 1.2.5 Performance parameters

The performance of the proposed method is analyzed by computing quality parameters, namely specificity (SPE), sensitivity (SEN) and accuracy (ACC), false-negative rate (FNR), negative predicted value (NPV) and false positive rate (FPR) [50].

**Accuracy:** It is the ratio of the total number of true identified events to the total number of events. It can be computed as,

ACC(%) = \(\frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}} \times 100\%\) (1.14)

**Sensitivity:** Sensitivity belongs to positive class, and it is defined as the percentage of the correctly identified actual positive events. It can be given as

SEN(%) = \(\frac{\text{TP}}{\text{TP} + \text{FN}} \times 100\%\) (1.15)
