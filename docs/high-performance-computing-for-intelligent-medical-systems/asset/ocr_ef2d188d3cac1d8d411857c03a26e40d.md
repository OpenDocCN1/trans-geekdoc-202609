# Steps of GA_det- BMA

+   i. The size of the window is 8x8, No. of generations, that is iterations = 10. Initial population size = 12 as displayed in figure 8.13 and probability of deciding the candidate MB is considered to be 0 with Roulette Wheel.
+   ii. A deterministic approach is used for encoding.
+   iii. Fitness function values are calculated.
+   iv. Probabilities and cumulative distribution function of cost values are calculated.
+   v. A new set of the population is generated.
+   a. The final population is updated as per values found in the Roulette Wheel approach and selects the best coordinates for the new population known as the mating pool.
+   b. if, iterations < 5; crossover operation is selected else.
+   c. If, iteration = 5; mutation is applied.
+   vi. Limiting criteria:
+   a. If (last iteration's minimum SAD – current minimum SAD) < 0.1% of their average; jump to step b else if the iteration number <10; go-to step ii.

# 8.9.11 Enhanced Grey-wolf optimizer-BMA (EGWO-BMA)

Betka et al [65] suggested a Grey wolf optimizer (GWO) algorithm for solving the problem of ME using the unique learning automata (LA) concept. By doing so, that is, adding the concept of LA, the exploration and exploitation facility of GWO are refined, and also the identification of objective function is done if unimodal or multi-model. Full exploitation of possible regions within the search window is required by a unimodal function. The exploration feature is useful for the multi-model objective function.
