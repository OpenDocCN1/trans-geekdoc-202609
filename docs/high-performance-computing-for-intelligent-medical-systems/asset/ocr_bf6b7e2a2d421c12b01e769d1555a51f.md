overwhelm the lower accuracy of the other class and thus a skewed result for
the dominant class. Per class accuracy analysing and then estimating the
proportion of pixels correctly labelled for each group is an alternative to this
concept of accuracy [25]. This test can be used in the case of a class
imbalance for sample data set. A decline in the confidence measurement of
specific classes is the downside of average class precision. Fewer cases of a
given class can lead to a substantial variance in the reliability of the results
in comparative analyses.

```
Accuracy = \frac{TP + TN}{TP + FP + FN + TN} (12.1)
```

where TP stands for true positives, FN for false negatives, TN are the
number of true negatives, and FN is the number of false negatives.

# B. Precision

As specified in equation (12.2), precision is reflecting the relation of
disease pixels in automatic segmentation results measures that corresponds
to the pixels of the ground reality disease. Precision is a valuable measure of
performance segmentation as it reacts to over-segmentation. The over-
segmentation leads to low accuracy values.

```
Precision = \frac{TP}{TP + FP} (12.2)
```

# C. Sensitivity

This value reflects the true positive rates reported in test data. It indicates
the number of times the test provided a positive outcome when the sample
did indeed have a condition [26]. Defined in equation (12.3)

```
Sensitivity = \frac{TP}{TP + FN} (12.3)
```

# D. Specificity

This specificity value indicates the true negative rates reported by the test
data. It refers to the proportion of negative samples identified by the test
that are actually negative [26]. The specificity is described in equation (12.4):

```
Specificity = \frac{TN}{TN + FP} (12.4)
```

# E. F1 measure

The measure F1 specifically states the harmonic mean of precision and
recall and is suitable for contour matching the predicted segmentation with
ground truth segmentation.

```
F_1 = \frac{2TP}{2TP + FP + FN} (12.5)
```
