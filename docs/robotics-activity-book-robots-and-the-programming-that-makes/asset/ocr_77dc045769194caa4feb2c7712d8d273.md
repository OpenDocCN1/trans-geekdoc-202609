# ROBOT BODIES

When designing how a robot should look, engineers consider how the robot will move, what size it should be, where it will need to go, and how quickly or smoothly it should move. Some robots look like humans because they are designed to do work that humans do, but engineers are just as likely to design robots that look like animals, or like nothing seen before!
