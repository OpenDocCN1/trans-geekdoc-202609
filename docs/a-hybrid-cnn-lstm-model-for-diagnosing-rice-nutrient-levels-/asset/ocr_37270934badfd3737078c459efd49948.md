To evaluate the recognition effect of the ResNet101-SE-LSTM model, we used the accuracy (Acc), precision (Pre), recall (Rec) and F1-scores (F1) as the evaluation metrics for measuring the model performance. The calculations of Acc, Pre, Rec and F1 are shown in equations (1-4).

$Acc = \frac{TP + TN}{TP + FP + FN + TN}$ (1)

$P_{re} = \frac{TP}{TP + FP}$ (2)

$R_{ec} = \frac{TP}{TP + FN}$ (3)

$F_1 = \frac{2P_{re}R_{ec}}{P_{re} + R_{ec}}$ (4)

where TP represents that positive instances are predicted to be positive, FN represents that positive instances are predicted to be negative, FP represents that negative instances are predicted to be positive, and TN represents that negative instances are predicted to be negative.

# ## 2.7 Machine identification methods based on rice physiological traits

To distinguish the developmental differences of different N and K interactions, we collected data for the classical plant physiological traits and extended the test data using Monte Carlo samplers (Metropolis and Ulam 1949). These physiological traits included the dry matter weight, N and K contents and accumulation in plant tissues (leaf, stem and sheath, and panicle), total above-ground biomass, specific leaf weight, green leaf weight, leaf area index, plant height and tiller numbers. Two machine learning models, Support Vector Machine (SVM) and random forest, were trained for diagnosing the rice nutrient levels under the interaction of the N and K treatments. The results were compared with the diagnostic results of CNN-LSTM to indirectly evaluate the feasibility of the CNN-LSTM model.
