RF model bagging many decision trees by using the bootstrapping method. Different with RF, advanced GBM using gradient boosting to create a model in a stepwise manner by optimizing an objective function, and the residual of each tree constructed was smaller than that of the previous predictor, which bring a gradient descent of residuals of predictors in GBM (Dorogush et al., 2018; Hong, 2020; Ke et al., 2017). So HCP-Models built by advanced GBM algorithms may bring higher predictive accuracy than RF in the task of regression. Furthermore, CatBoost, and XGBoost models obtained higher predictive accuracy than LightGBM, with the higher test R², lower test RMSE, MAE and MAPE.
