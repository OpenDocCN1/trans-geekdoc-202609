describes the motion of the body using the reference placement $\boldsymbol{X}$ and the time \(t \in [0, T]\) (Steinmann, 2015). Here, the time \(t\) and the furthest considered point in time \(T \in (0, \infty]\) live on the affinely extended real number line. The current placement \(\boldsymbol{x}\) is then defined as

```
$$ \boldsymbol{x} = \boldsymbol{\chi}(\boldsymbol{X}, t), \quad (2.2) $$
```

from which the current placement \(Y_t\) of the body follows as (Steinmann, 2015)

```
$$ Y_t = \{ \boldsymbol{x} = \boldsymbol{\chi}(\boldsymbol{X}, t) \mid \boldsymbol{X} \in Y_0 \text{ and } t \in [0, T] \}. \quad (2.3) $$
```

Consequently, a tensor field \(\Lambda\) of order \(n \in \mathbb{N}_{\ge 0}\) on the material body can be described in terms of the reference placement \(Y_0\) (Haupt, 2002), such that

```
$$ \Lambda_{\mathrm{L}} : Y_0 \times [0, T] \rightarrow (\mathbb{R}^d)^{\otimes n}, \quad (2.4) $$
```

as well as in terms of the current placement \(Y_t\), such that

```
$$ \Lambda_{\mathrm{E}} : Y_t \times [0, T] \rightarrow (\mathbb{R}^d)^{\otimes n}. \quad (2.5) $$
```

Here, the parameterizations \(\Lambda_{\mathrm{L}}\) and \(\Lambda_{\mathrm{E}}\) represent the Lagrangian and the Eulerian description of the tensor field \(\Lambda\), respectively. Also, using the relations (Steinmann, 2015)

```
$$ \Lambda_{\mathrm{E}}(\boldsymbol{x}, t) = \Lambda_{\mathrm{L}}(\boldsymbol{\chi}^{-1}(\boldsymbol{x}, t), t) \quad \text{and} \quad \Lambda_{\mathrm{L}}(\boldsymbol{X}, t) = \Lambda_{\mathrm{E}}(\boldsymbol{\chi}(\boldsymbol{X}, t), t), \quad (2.6) $$
```

one parameterization may be converted into the other. The temporal change of a tensor \(\Lambda_{\mathrm{L}}(\boldsymbol{X}, t)\) parameterized by the reference placement \(\boldsymbol{X}\) is defined through the material time derivative (Haupt, 2002)

```
$$ \dot{\Lambda}_{\mathrm{L}}(\boldsymbol{X}, t) = \frac{\partial \Lambda_{\mathrm{L}}}{\partial t}(\boldsymbol{X}, t). \quad (2.7) $$
```
