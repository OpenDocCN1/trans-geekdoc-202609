\(\boldsymbol{n}_3 \cdot \boldsymbol{n}_1 = 0, \quad \text{and} \quad \boldsymbol{n}_3 \cdot \boldsymbol{n}_2 = 0,\) (A.18)

and the intersection \(\mathcal{E}_1^{\text{A}} \cap \mathcal{E}_2^{\text{A}} \cap \mathcal{E}_3^{\text{A}}\) does not only contain the zero element \(\mathbf{0}\). Hence, the condition (A.11) is violated. To show this, we consider the alternative description of the spaces \(\mathcal{E}_r^{\text{A}}\)

\(\mathcal{E}_r^{\text{A}} = \{ \boldsymbol{B} \in \text{Sym}_0(3) \mid \boldsymbol{B}\boldsymbol{n}_r = \alpha \boldsymbol{n}_r \quad \text{for some} \quad \alpha \in \mathbb{R} \}\) (A.19)

which is equivalent to equation (A.13) and characterizes the space \(\mathcal{E}_r^{\text{A}}\) via all tensors \(\boldsymbol{B} \in \mathcal{E}_r^{\text{A}}\) that have the layering direction \(\boldsymbol{n}_r\) as an eigenvector. Then the tensor

\(\boldsymbol{B} = \boldsymbol{n}_1 \otimes \boldsymbol{n}_1 + \boldsymbol{m}_2 \otimes \boldsymbol{m}_2 - 2\boldsymbol{n}_3 \otimes \boldsymbol{n}_3,\) (A.20)

where the layering direction \(\boldsymbol{m}_2\) is constructed by orthogonalization, such that

\(\boldsymbol{m}_2 = \boldsymbol{n}_2 - (\boldsymbol{n}_1 \cdot \boldsymbol{n}_2)\boldsymbol{n}_1,\) (A.21)

is an element of the intersection \(\mathcal{E}_1^{\text{A}} \cap \mathcal{E}_2^{\text{A}} \cap \mathcal{E}_3^{\text{A}}\). This is true because it holds that

tr(\(\boldsymbol{B}\)) = 0, \(\boldsymbol{B}\boldsymbol{n}_1 = \boldsymbol{n}_1, \quad \boldsymbol{B}\boldsymbol{n}_2 = \boldsymbol{n}_2, \quad \boldsymbol{B}\boldsymbol{n}_3 = \boldsymbol{n}_3,\) (A.22)

and therefore condition (A.11) is violated. In other words, the effective properties \(\bar{\mathbb{A}}\) of a rank-3 CLM with incompressible coating and rigid core, where one layering direction \(\boldsymbol{n}_3\) is orthogonal to the other two layering directions \(\boldsymbol{n}_1\) and \(\boldsymbol{n}_2\), is always singular. Particularly, if all three layering directions are mutually orthogonal, the effective properties \(\bar{\mathbb{A}}\) of a rank-3 CLM are singular.
