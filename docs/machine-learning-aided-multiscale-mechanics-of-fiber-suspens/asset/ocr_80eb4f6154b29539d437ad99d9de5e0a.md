Subsequently, the average effective shear rate $\dot{\gamma}_A^{\text{FFT}}(\bar{\tau}_{12})$ was compared to the average effective shear rate $\dot{\gamma}_A^{\text{lit}}(\bar{\tau}_{12})$ given in Traxl et al. (2020) via the deviation $d_{num}$, which we define as

$$d_{num} = \frac{|\dot{\gamma}_A^{lit}(\bar{\tau}_{12}) - \dot{\gamma}_A^{FFT}(\bar{\tau}_{12})|}{\dot{\gamma}_A^{lit}(\bar{\tau}_{12})}.$$ (3.47)

The resulting effective shear rate-stress curves for the FFT-based method is in very good agreement with the results from Traxl et al. (2020), see Figure 3.3a. This is emphasized by the deviation $d_{num}$, which lies below 2.3% for all investigated effective loads $\overline{\underline{\tau}}$, see Figure 3.3b.
