# 60 — Decentralized applications

The transaction fee in Ethereum is determined through gas and gas prices. Gas reflects resource consumption and thus, the costs of processing a transaction. A transaction sender selects the gas price (value in Ether). The gas is multiplied by the gas price to calculate the fee of a particular transaction. It is more likely that miners will consider a transaction with a higher fee while building the next.

As the Hedera Hashgraph network services are available only through APIs, users cannot directly create and submit transactions. They would rather pay for the API calls instead of paying fees for transactions. The API pricing is transparent,* and the fees vary according to the type of API call. The crypto transfer API was priced in 2021 at 0.0001 USD, allowing micro-transactions (<0.01 USD) to be economically and technologically practical. A smart contract or a creation of a file in the Hedera DL costs 0.05 USD.

A separate entity Corda Network Foundation was set up to govern the development and networks. In Corda, the networks are semi-private and permitted. A node must obtain a certificate from the network operator to join a network. A network operator would charge reasonable costs for providing network and administration services, which is funded by the Foundation. In Corda, the participants pay an annual participation fee and transaction fees. Transaction fees are charged for notarization by Corda Network notary and are structured in two models: Pay-As-You-Go and Up-front package. The total fee depends on the number of transactions, but Corda provides a transparent and predictable transaction pricing.

IOTA represents transaction fees in terms of MIOTA (or another digital, or fiat) with transaction fees paid in terms of hash power,† The sender of a transaction has to establish the PoW for two previously unconfirmed transactions. This, mining is distributed among transaction senders and not among dedicated mining nodes. In IOTA, transactions only become truly valid (finalized) when other transactions reference them. Currently, a special node operated by the IOTA Foundation, confirms them.
