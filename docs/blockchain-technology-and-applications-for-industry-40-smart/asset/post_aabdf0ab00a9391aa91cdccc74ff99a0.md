# List of notions

Ledger
A book, a list, or other collection of financial accounts and/or transactions.

51% Attack
A potential attack on a blockchain network, where a single entity is able to control the majority of the hash power, potentially causing a network disruption. In such a scenario, the attacker would have enough mining power to intentionally exclude or modify the ordering of transactions.

6-blocks Confirmation
A period of time (commonly around 60 min) necessary for adding new blocks behind a solved block that contains some transaction. After this period, the transaction is considered confirmed because creating a new version of the blockchain that will not contain a given transaction becomes too difficult, because too expensive in computing power.

Altcoins
Artificial Neural Networks
A computing system is based on a collection of connected units called artificial neurons, which loosely model the neurons in a biological brain.

Bitcoin
The most popular cryptocurrency, running on a blockchain created in January 2009 by an anonymous person Satoshi Nakamoto.

Bitcoin/Digital Wallet
A software program for holding and trading Bitcoin which uses to access the person's private key (secret), public address (identifier) and transaction signatures that need to be securely stored; the wallet comes in many forms – desktop, mobile, and hardware.

Blockchain
A distributed ledger consists of a series of transactions where each block (except the first and the last) is linked with the previous and next block by means of cryptography, making an unbreakable chain.

Blockchain Fork
A situation within the community (members of the network) that occurs when the network exists two or more versions of the blockchain.

Blockchain Mining
A peer-to-peer process aimed to secure and verify transactions of given cryptocurrency (such as Bitcoin).

Border Gateway Protocol
Protocol for routing of IP packets; it is a standardized exterior protocol designed for routing and reachability information among autonomous systems.

Branch Tip
A tip that represents the last individual transaction in a branch (see IOTA bundle).

# List of notions

Byzantine Tolerant System
A system that is tolerant (i.e. resistant) to Byzantine Fault; in the strict sense, a BFT system is capable of functioning properly as long as the number of corrupted elements is less or equal to two-thirds of the overall number.

Byzantine Generals Problem
A class of failures where some components/elements may be corrupted in the sense (appearance, behavior) that prevent other system's components from reaching agreement among themselves.

Car-to-Car
Communication that takes place between vehicles with the aim of sharing information that can be used for traffic control or to warn drivers of dangers.

Consensus mechanism
A mechanism (set of rules and protocols) that ensures that all participants dispose duplicate copies of the distributed database (i.e., distributed ledger).

Coordinator (in the context of Tangle)
A mechanism implemented by IOTA Foundation with the aim to protect against double-spending (as Tangle is not fully developed, the overall number of nodes and hash power in IOTA network are relatively low); the Coordinator mechanism assumes the assurance of a milestone transaction every minutes.

Cryptocurrency
A digital currency in encryption techniques to regulate the generation of units and verify the transfer of funds, operating independently of a central authority; most of cryptocurrencies are based on blockchain technology.

Cumulative Weight
A metric using the Random Walk algorithm for tip selection in the Tangle; the cumulative weight of a transaction in the Tangle is the total number (plus 1) of all transactions which come after, and at the same time, approved directly or indirectly.

Decentralized Application
A computer application that runs on a decentralized computing system. Daps have been popularized by distributed ledger technologies such as the Ethereum blockchain; Smart contracts are a key part of Daps.

Delay Attack
A partition attack that exploits weaknesses of Gateway Protocol; in Delay Attack, the propagation of blocks towards a victim is effectively slowed down; the main goal is to keep the victim uninformed about a new block for almost 20 min, which is achieved through a Man-in-the-Middle attack where attacker modifies messages from victim to the victim's peer node; as the inquiring messages are wrong (due to modifications performed by an attacker), the victim node is unable to get from the network the freshest block (in order to add it on its copy of the blockchain); the victim wastes its computing power and time, instead of using it for solving the next block; consequently, the victim loses its possible earnings.

# List of notices —

Denial of Service Attacks
Cyber-attack that makes unavailable a host (computer, machine, network resource) connected to the Internet; typically accomplished by flooding the targeted host with excessive requests with the aim to overload the system and prevent legitimate requests from being fulfilled.

Difficulty
The algorithm implemented within Bitcoin blockchain that regulates the level of difficulty for solving the PoW task (block solving), that in average, the frequency of block solving is one every 10 minutes (i.e. 2016 solved blocks for 14 days); as a parameter, it is defined as Difficulty = 1/target_value, showing how many times it is more difficult to find a 256-bit long hash below current target value (determined by parameter_value) to find a hash below a 256-bit reference value (determined by parameter_target_value) which has 22 leading zeros.

Difficulty Target
Name of a 32-bit field in header that contains parameter_value represented via 24-bit mantissa and 8-bit exponent; content of this field in hexadecimal is known as bits.

Digital Twin
A digital replica of potential and actual assets (physical twin), processes, places, systems, and devices that can be used for various purposes.

Directed Acyclic Graph
A finite directed graph with no directed cycles.

Distributed Ledger
A consensus of replicated, shared, and synchronized digital data geographically across multiple sites, countries, or institutions.

Double Hash (or Hash-hash)
Generally, double hashing is a computer programming technique to resolve hash collisions by a secondary hash of the key as an offset when a collision occurs; in the Bitcoin blockchain, double-hashing is realized through double use of SHA-256 hashing function, that is, f(x) = sha256(sha256).
