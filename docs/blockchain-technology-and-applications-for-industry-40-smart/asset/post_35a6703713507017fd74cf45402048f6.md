# Blockchain

Blockchain is a reliable transaction register (or ledger) containing all transactions up to this very moment. It is a big and continuously growing file comprising a list of records called blocks (or blocks of transactions) where each block in the list is linked (i.e., chained) with the previous and the next block, using cryptography (see Fig. 1.1). The key conditions that are besides transaction data, each block has a header that contains a cryptographic hash of the block's header, a timestamp that transactions relate to, and six other fields (if the Bitcoin blockchain [1] is concerned; see Fig. 1.2).

The key point of the whole system is that no one can delete or modify any of these transactions, and this is the main reason blockchain has become a hot topic. It offers absolute permanence and reliability of the recorded data, so that no hacker can get into this blockchain database and change the fact, for instance, John Smith possesses 20 BTCs. Such properties of BTC are accomplished by two most significant factors:

- 1. Decentralization
- 2. The algorithm for the verification of transactions, which is closely related to the blockchain structure

The concept of decentralization is achieved when the list of all transactions (blockchain) is stored in many computers worldwide, where each of these computers (nodes) contains a file of the complete blockchain (which should be identical to the blockchain file of any other node). Unlike centralized banking systems where bank keeps customers' transaction data on its servers (well protected and backed up), the nodes keeping a blockchain to ordinary people over all the world, who have accepted to take part in this DL voluntary. There is neither a central authority nor a central server mutually independent, except that their computers hold the nodes that maintain a blockchain. Nodes are always connected using a protocol for inter-node communication, creating a global peer-to-peer (P2P) network. However, this network is like any other P2P network working over the Internet.

A fresh copy of the file of blockchain is kept on the disk of each node. Besides, some nodes (miners) can also verify the newest transactions (e.g., in BTCs) between any two people in the world. Furthermore, there are many other computers with only a transaction verification function. They are also called miners, although they are not nodes.

Let us take the following example: A wants to send 100 EUR (in BTCs) to B: in the beginning, a computer (or a smartphone) of A announces to the network that A wants to transfer 100 EUR to B. At that moment, this is called an invalidated transaction, and it is not written in the register yet.

The first thing for a miner to do next is check if A has enough and something more for the provision). Now, the miner checks this by passing through the complete blockchain, seeing all transactions that person A has ever had, and calculating if there is enough money available. There is no such category as the account state, the amount of money A possesses is counted again, based on all the transactions A has ever up to that moment. That is a very favorable trait, making the blockchain additionally safe. If one wanted to manipulate another person's account, one would have to change the past.
