

# 1.4 哈希图 (Hashgraph)

事件 $Y_i$ 被委派为事件 $X_{n-1}$ 共识时间戳的一个候选者。最后，所有合格的节点（即特权节点）都存储在一个时间戳数组中，从最旧的开始排序，中间的时间戳（中位数值）被宣布为事件 $X_{n-1}$ 的共识时间戳。如果数组中有两个中间时间戳（即候选者数量为偶数），则选择后一个。
