# 3 Distributed ledgers and internet of things

Integration of distributed ledger technology and the Internet of Things is fundamental for many applications and use cases beyond decentralized finance (DeFi) applications. The application domains include, among others, smart cities, smart robotics, smart industry and logistics, mobility, and energy or waste management. Some of these application domains are discussed in more detail in Section 4.

| Application layer |
| Web and mobile applications, user interfaces, APIs |
| Platform layer |
| Data storage, analytics, cloud |
| Communication layer |
| Fixed, mobile, wireless networks; gateways |
| Perception layer |
| Sensors, actuators, embedded systems |

**Fig. 3.1:** Basic IoT architecture.

A basic cloud-centric IoT architecture is depicted in Fig. 3.1. The perception layer comprises sensors, actuators, and embedded devices that are integrated into things. The perception layer interacts with the real world, ensures basic signal and data processing, and assures some form of connectivity (personal-area with Bluetooth or wired connections, local-area with WiFi, or wide-area, e.g., Narrow-band IoT (NB-IoT)). The embedded device can touch directly or via a communication gateway to the communication layer, which is a public (Internet) or private IP network. The platform and the application layer are two sets of cloud-based services that enable the collection, storage, data processing, and the development of applications based on IoT data. Integration of IoT and DLT has been seen as a remedy for the fundamental challenges of IoT architectures. The challenges, as centralized ecosystems, cost of the connectivity, disrupted business models, security, and lack of functional values, need to be addressed to continue with successful IoT deployments.

The great expectation imposed on the distributed ledger technology originated from the distributed and decentralized nature of DLT. For example, a decentralized approach to IoT networking was expected to solve many of the issues mentioned above. "Blockchain technology is the missing link to cope with the future challenges in the IoT" [46], which can reduce costs, build trust, accelerate transactions, provide scalability, remove single points of failure, keep an immutable record of the history of smart devices, enable machine-to-machine transactions, micropayments, and so on.
