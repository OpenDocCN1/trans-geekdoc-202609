# Denial of Service Attacks

Cyber-attack that makes unavailable a host (computer, machine, network resource) connected to the Internet; typically accomplished by flooding the targeted host with excessive requests with the aim to overload the system and prevent legitimate requests from being fulfilled.

# Difficulty

The algorithm implemented within Bitcoin blockchain that regulates the level of difficulty for solving the PoW task (block solving), that in average, the frequency of block solving is one every 10 minutes (i.e., 2016 solved blocks for 14 days); as a parameter, it is defined as Difficulty = 1/target\_value, showing how many times it is more difficult to find a 256-bit long hash below current target value (determined by parameter\_value) to find a hash below a 256-bit reference value (determined by parameter\_target\_value) which has 22 leading zeros.

# Difficulty Target

Name of a 32-bit field in header that contains parameter\_value represented via 24-bit mantissa and 8-bit exponent; content of this field in hexadecimal is known as bits.

# Digital Twin

A digital replica of potential and actual assets (physical twin), processes, places, systems, and devices that can be used for various purposes.

# Directed Acyclic Graph

A finite directed graph with no directed cycles.

# Distributed Ledger

A consensus of replicated, shared, and synchronized digital data geographically across multiple sites, countries, or institutions.

# Double Hash (or Hash-hash)

Generally, double hashing is a computer programming technique to resolve hash collisions by a secondary hash of the key as an offset when a collision occurs; in the Bitcoin blockchain, double-hashing is realized through double use of SHA-256 hashing function, that is, f(x) = sha256(sha256).

# Double Spending Problem

A potential flaw in a digital cash scheme where the same single digital token can be spent more than once; if two transactions (one of is tricky) are sent into the network using the same private key of a fraudulent sender (a buyer in two different transactions), but sent to different receiving addresses (sellers in different transactions); as two transactions propagate through the network, one part of the network will accept one transaction and the other part another.

# Ethash

A PoW mining algorithm implemented by the Ethereum network and Ethereum-based cryptocurrencies; it Ethash is a hash function that belongs to the same (Keccak) family of hash functions, but differs from SHA-3; Ethash was developed with a strong focus on protection from Application Specific Integrated Circuits miners, who were primarily mining Bitcoins.
