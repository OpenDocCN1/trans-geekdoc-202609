Within such an arranged environment, a blockchain can be used to distribute bytecode to robots and other agents. One the agent informs the network about changes of its state during the execution of the bytecode/commands (e.g., "rotated 60° clockwise", "gripped the box" or "moved backward for 10 m"), and the actual state is stored in the blockchain. In this way, if the agent halts for any reason, its state can quickly recover the halt.

# 2. Optimization of task execution through economic incentives

With the blockchain's incentive mechanism, agents earn incentives (e.g., the blockchain's native tokens/cryptocurrency) when giving tasks with minimal resources, or penalized if they behave uneconomically. These mechanisms can be used for the optimization of various production processes where robots are involved.

# 3. Task dispatching for maximal efficiency

The use of smart contracts based on the blockchain can create an environment with market rules. The task dispatching, that is, selecting agents to execute different tasks is regulated by the market, where various agents/robots compete for tasks to be assigned and where the assignment of specific tasks to the appropriate agents is performed by distributed consensus, namely, a task-dispatching code stored in the blockchain (in the form of a smart contract) imposes a rollout in a customer (or a specialized agent) first sends to the dispatcher of the smart contract, a request to perform a task, after which, the dispatcher informs the agents about the new request. Then, each of the concerned agents sends to the blockchain via P2P network (see Fig. 4.1)) its agreement to perform the task with the information on the new (e.g., in native tokens of the blockchain) is ready for handling the agreement. The blockchain validators then order the agreements received from agents according to the fees the agent offers. The first agreement, that is, the one with the highest fee is confirmed by the smart contract code, while the corresponding agent (the winner) receives details of the task that is to be executed.

In a competitive environment, the agents provided with a cost optimization strategy will offer more for new tasks, to be selected by validators, as they have more money (i.e., tokens) earned from the earlier tasks, for example, through receiving rewards for the realization of these tasks (i.e., optimal) behavior during the realization of these tasks (see the previous item).
