# 作者简介

**Nir Shtein** 是一位多才多艺的工程师、讲师、公开演讲者和作家，深耕开源软件 (OSS)、Kubernetes、Golang、DevOps 和后端工程领域。他通过讲座、文章和播客传授知识，曾担任学院讲师、技术负责人、团队负责人和软件工程师等多个领导职务。

在职业生涯中，Nir 从大型企业转型至充满活力的早期初创公司，拥抱学术角色，并开发了独特的开源项目。他积极参与加速器项目，进一步丰富了自己的专业经验。

多年来，Nir 在国际范围内发表演讲，并撰写了多篇触达全球受众的文章。他为众多开源项目做出贡献，其中最成功的项目用户超过 100,000 名。

除了专业成就，Nir 还指导过许多人，帮助他们进入高科技行业并开启职业生涯。工作之余，他喜欢阅读、听播客、运动、烹饪和探索新地方，不断寻求新的体验和知识。

# 前言

欢迎踏上一段精彩旅程，探索使用 Go 编程语言的微服务架构世界。本书旨在面向希望拓宽理解、掌握微服务全貌的开发者。它强调整体理解胜过具体技术细节，尤其是在 AI 能够自动化许多简单任务的时代。

本书的目标是提供微服务架构及其实际应用的全景视角，而非深入每一个细节。本书旨在为您提供基础知识和技能，以便使用 Go 开发健壮的服务、设计可扩展的系统，并确保其成功部署到生产环境。

全书将探索 Go 编程的基础知识，深入研究高级主题，并驾驭构建和部署微服务的复杂性。我们将重点阐述微服务、Go、RESTful API 和 Kubernetes 之间的紧密联系，涵盖服务通信、API 设计、容器编排、安全性和可观测性等关键领域。

读完本书后，您将牢固掌握使用 Go 架构和实现微服务的方法，做好准备应对将服务高效推向生产环境的挑战。本书不仅是一本指南，更是一块垫脚石，助您继续提升技能，在不断演变的软件开发世界中探索新天地。
