

# Go 语言基础语法

## 循环

Go 语言中有多种循环方式；它们都使用 `for` 关键字。使用 `break` 跳出循环，使用 `continue` 进入下一次迭代。

```go
func main() {
	// for 循环：包含初始化、条件、后置语句
	for i := 0; i < 5; i++ {
		println(i)
	}

	// for 循环：仅包含条件，类似 "while"
	i := 0
	for i < 5 {
		println(i)
		i++
	}

	// for 循环：无条件，类似 "while true"
	i = 0
	for {
		println(i)
		i++
		if i >= 5 {
			break
		}
	}

	// for 循环：配合 continue
	for i := 0; i < 5; i++ {
		if i%2 == 0 {
			continue
		}
		println(i)
	}

	// for 循环：配合 range
	s := []int{1, 2, 3}
	for k, v := range s {
		println(k, v)
	}
}
```

注意 Go 中没有 `while` 关键字。实现 while 循环只需使用 `for`（带或不带条件）。

最后一个 `range` 示例是 Go 特有的。`range` 关键字让我们可以遍历数组、切片、映射等可迭代类型。

## 数组

Go 中声明数组有两种方式：

```go
func main() {
	// 声明一个包含 5 个整数的数组
	var a = [5]int{1, 2, 3, 4, 5}
	// 声明一个长度自动推断的数组
	var b = [...]int{1, 2, 3}
}
```

第一个示例（`var a = [5]int{1, 2, 3, 4, 5}`）显式指定长度为 5。第二个示例（`var b = [...]int{1, 2, 3}`）由编译器推断长度。当然，也可以不使用 `var` 关键字，直接用 `:=` 简短声明。

Go 数组只能存储同一类型元素，且长度不可变。

## 切片

切片与数组非常相似，但更加灵活。切片长度可在运行时动态改变，是 Go 的核心优势之一。声明切片的方式如下：

```go
mySlice := []string{"nir", "david"}
```

语法与数组几乎相同，但无需声明大小（或用 `...` 推断）。另一种声明方式是使用 `make` 关键字：

```go
mySlice := make([]type, length, capacity)
```

`length` 表示切片当前包含的元素数量，`capacity` 表示底层数组从切片第一个元素起的容量。`capacity` 始终大于或等于 `length`。

用于获取数组、切片长度和容量的两个内置函数是 `len`（长度）和 `cap`（容量）。

```go
slice := make([]int, 2, 5)
fmt.Println(slice)  // [0 0]
fmt.Println(len(slice))  // 2
fmt.Println(cap(slice))  // 5
```

切片/数组的一个便捷操作是切片截取。示例如下：

```go
myArray := [5]int{1, 2, 3, 4, 5}
slice = myArray[1:4] // 从索引 1 到 4（不包含 4）
fmt.Println(slice) // [2 3 4]
```

## 函数

Go 函数支持返回多个不同类型的参数：

```go
func myFunction(amount int, prefix string) string {
	return fmt.Sprintf("%s: %d", prefix, amount)
} // Input: 5, "nir" | Output: "nir: 5"

func multipleReturns(prefix string, amount int) (string, int) {
	amount++
	return fmt.Sprintf("%s: %d", prefix, amount), amount
} // Input: "nir", 5 | Output: "nir: 6", 6

func namedReturnValues(prefix string, amount int) (result string, newAmount int) {
	amount++
	result = fmt.Sprintf("%s: %d", prefix, amount)
	newAmount = amount
	return
} // Input: "nir", 5 | Output: "nir: 6", 6
```

第一个示例（`myFunction`）展示了使用 `func` 和 `return` 关键字的简单函数。第二个示例（`multipleReturns`）展示多返回值函数。第三个示例（`namedReturnValues`）展示具名返回值函数（单个具名返回值也合法）。

Go 函数的一个重要特性是 `defer`。`defer` 关键字注册的函数会在外层函数执行完毕后执行。示例如下：

```go
func functionWithDefer() {
	defer fmt.Println("This will be printed last")
	fmt.Println("This will be printed first")
} 
// Output: 
// This will be printed first
// This will be printed last

func functionWithMultipleDefers() {
	defer func() {
		fmt.Println("This will be printed last")
	}()
	defer fmt.Println("This will be printed second")
	fmt.Println("This will be printed first")
}
// Output:
// This will be printed first
// This will be printed second
// This will be printed last
```

示例直观地说明了 `defer` 的执行顺序（后进先出）。

在 Go 中，函数是一等公民，可作为参数传递、作为返回值返回、赋值给变量。这支持高阶函数和函数式编程模式。

## 映射

Go 映射用于存储键值对数据。`map` 的零值是 `nil`。映射持有对底层哈希表的引用。声明映射及常用操作如下：

```go
fruitsPrices := map[string]int{
	"orange": 10,
	"apple":  20,
	"banana": 15,
}

fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 orange:10]

// 添加键值对
fruitsPrices["mango"] = 25
fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 mango:25 orange:10]

// 删除键值对
delete(fruitsPrices, "orange")
fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 mango:25]

// 获取值
fmt.Println(fruitsPrices["apple"]) // Output: 20

// 获取不存在的键（返回类型零值）
fmt.Println(fruitsPrices["grapes"]) // Output: 0 (int 的零值)

// 检查键是否存在
price, ok := fruitsPrices["grapes"]
fmt.Println(price, ok) // Output: 0 false

// 遍历映射
for fruit, price := range fruitsPrices {
	fmt.Printf("%s: %d\n", fruit, price)
} // Output: apple: 20 banana: 15 mango: 25 (顺序不固定)

fmt.Println(len(fruitsPrices)) // Output: 3

// 创建空映射
emptyMap := make(map[string]int)
fmt.Println(emptyMap) // Output: map[]
```

## Switch 语句

使用 `switch` 语句从多个代码块中选择一个执行。Go 中不需要 `break` 关键字；每个 `case` 默认自动终止。若需穿透到下一个 `case`，使用 `fallthrough` 关键字。典型示例：

```go
func main() {
	printString("b") // b
	printString("a") // a b
}

func printString(str string) {
	switch str {
	case "a":
		println("a")
		fallthrough
	case "b":
		println("b")
	default:
		println("default")
	}
}
```

若无 `case` 匹配，则执行 `default` 分支。

## 常量

常量使用 `const` 关键字声明，作用域与变量相同。运行时常量不可修改。常量类型包括数字、字符（rune）、字符串、布尔值。（关于 rune 详见参考资料 5）。示例：

```go
const str string = "const string"

const (
	_ = iota
	one
	two
	three
)

func main() {
	println(str)       // string
	// str = "new string" // 编译错误：cannot assign to str
	println(one)   // 1
	println(two)   // 2
	println(three) // 3
}
```

首先，声明常量字符串很直观。示例中显式写了 `string` 类型，其实可省略。

其次是 `iota` 示例。`iota` 是 Go 中的常量生成器，初始值为 0，每行递增 1，常用于声明枚举常量，保持代码可读性。
