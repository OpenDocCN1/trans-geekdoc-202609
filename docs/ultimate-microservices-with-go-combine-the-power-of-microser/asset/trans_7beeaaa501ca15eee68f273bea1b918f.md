

# 第 1 章 微服务简介

本章探讨微服务从替代架构演变而来的历程，重点介绍其优势与劣势。我们还将审视微服务日益增长的流行度，以及 Go 语言与微服务之间的协同效应，展示 Go 的简洁性和高效性如何契合基于微服务的应用程序。

# 第 2 章 Go 语言的易用性

本章深入剖析 Go 语言诞生的原因、核心原则以及 Go 开发者的典型体验。我们将探讨 Go 的简洁性、极简设计、对云环境的适用性、可维护性，以及从入门到生产环境的平滑过渡。此外，我们还将考察 Go 充满活力的生态系统，包括其社区和广泛的支持网络。

# 第 3 章 Go 语言核心要点

本章将为你提供成为 Go 编程语言熟练者所需的核心知识和工具。

# 第 4 章 开启 Go 语言之旅

本章在前文基础之上，深入探讨 Go 语言的进阶主题与原则。我们将探索若干 Go 最佳实践、技巧、泛型以及上下文。

# 第 5 章 释放 Go 语言的并发威力

本章继续探索 Go 语言的进阶主题，释放该语言强大的并发特性。我们将深入 Goroutine 和 Channel 的世界。此外，我们还将涵盖发布/订阅模式、Channel 关闭原则、避免 Goroutine 泄漏的策略等内容。

# 第 6 章 微服务的核心要素

本章深入微服务架构的核心组件，揭示将标准架构转变为面向微服务架构的关键要素。

# 第 7 章 构建 RESTful API

本章在上一章奠定的基础上，深入探讨 RESTful API 的开发。我们将从 RESTful 方法及其约束的概述入手。我们将讨论使用 Go 实现的基本 API 能力，包括文档编写、版本控制、缓存等。

# 第 8 章 Kubernetes 简介

本章介绍 Kubernetes，为开发者提供基本工具和知识，以高效使用这一强大的容器编排平台。

# 第 9 章 部署到生产环境

本章从开发者而非运维的视角出发，专注于安全交付生产服务。我们将探讨开发者在部署过程中面临的挑战与障碍。

# 第 10 章 生产环境的后续步骤

本章探讨将应用部署到生产环境后的关键阶段：维护服务与管理潜在故障。我们将探索监控与可观测性策略，利用日志、指标和追踪深入洞察系统行为。

# 第 1 章：微服务简介

# 简介

在本章中，我们将探索微服务的世界，这是一种彻底改变了现代软件构建与部署方式的革命性架构风格。微服务提供了一种粒度更细的软件开发方法，将应用程序拆解为更小、独立的服务，每个服务负责特定功能。这种模块化结构促进了敏捷性、可扩展性和弹性，使组织能够快速适应不断变化的市场需求和技术进步。

在本章及全书中，我们将概述本书两大核心主题——微服务架构与 Golang 编程语言——的趋势与耦合关系。我们将看到它们的强相关性、成因及方式。

本章将简要概述构建架构的当代方法——微服务架构。我们将把它与其他架构进行对比，并了解何时使用该架构有益，以及微服务在何种情况下会产生不利影响。
