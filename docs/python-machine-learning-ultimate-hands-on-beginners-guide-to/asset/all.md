Machine Learning What is Machine Learning? Machine learning as a term encompasses a concept that is simple enough to understand, but extremely difficult and complex in its execution: the ability of a computer, or a "machine", to "learn", or get better at a specific type of task using data that they receive, without being explicitly programmed. This means that the programmer must be able to code in such a way to enable this behavior, as this independence from hard – coding is highly reliant on the programmer's algorithm. Machine learning is usually done by creating a set of algorithms that process incoming data and use this data as basis for predictions or decisions, actions that would normally be hard – coded in a static program. This allows for adaptation, and the program will begin to react in a different manner depending on the data received, as compared to traditional static programs where following a certain series of inputs will always result in the same result. This model – creation from inputted data is useful in many cases where static traditional programs would be impractical or impossible if a favorable result is desired, such as in the creation of electronic – mail spam filters, detection of possible malicious intruders attempting to breach the security of a network, or in cases where the programmer is attempting to implement some level of computer vision. This adaptability has been used to enhance various functions of computers and has been growing in complexity through the years. However, machine learning is far from a new concept in data science, and in fact, machine learning as a concept has been condensed by prominent data scientist Tom Mitchell into the line of: "A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P if its performance at tasks in T, as measured by P, improves with experience E". As machine learning is a fairly well – developed concept, there are many things that programmers are capable of implementing through it, and there are two general "tasks" that machine learning algorithms carry out. 

Machine Learning Tasks The "tasks" of machine learning refer to what the algorithm is supposed to do, and through what method it "learns". As such, there are two general categories of machine learning tasks: 

Learning Given that machine learning has the word learning in it, learning would be the major task of any machine learning algorithm. There are multiple methods of machine learning, however, depending on what the aim of the programmer is, as well as what kind of data the algorithm is meant to parse. The following should give the reader an overview of a few of the more popular and major categories of machine learning. Supervised Learning Supervised learning is a method wherein the computer is fed information, usually in the format of a paired input – output data and uses this information to construct a model which will result in improved predictions or in a more favorable output method. It does this by inferring training data through the given "training examples", which then allows the machine learning algorithm to eventually produce an inferred function using the given examples, that will be used to map more examples and will optimally result in determining the classes of unseen instances, which requires the algorithm to be able to generalize results from the training data to unseen examples in a more reasonable way. Note that the paired teaching data is usually referred to as the "vector" for the input half of the pair, and the output portion is referred to as the "supervisory signal" Steps in Creating a Flowchart to Solving a Supervised Learning Problem The first step in creating an algorithm to solve a supervised learning problem is to determine the data type of the training examples to be used. For example, when writing a program in order to conduct handwriting data analysis, the programmer has to decide if they wish to use individual characters, single words, or even entire lines at once in order to train the program. Once the type of data has been determined, the next step is to gather a sufficient sample size of data in order to create the training set to be used for the algorithm. This means that multiple input objects should be gathered, and their expected output counterparts should also be readied. Once the training set has been completed, the programmer needs to then figure out how exactly they wish their input features to be represented. This means that the input will be converted into a vector, with a number of variables describing it. While it is impossible to perfectly describe the object due to the "curse of dimensionality", the programmer should be able to include a sufficient number of descriptive variables for the computer to have a proper idea of the object. Once this has been completed, the programmer can then determine how they wish their learning function to be structured and how they want to create their algorithm, by using methods such as support vector machines or decision – tree creation, algorithm methods that will be discussed in a later chapter. Once this has been completed, the programmer can then begin to run the simulation to train their program. Note that certain supervised learning algorithms need a number of control parameters to be determined by the user, and further adjustment may be necessary in order to optimize performance. Once the algorithm has been tested and the program has been trained, the programmer can then try and test their function on a test set differing from the training set, and check as to whether or not their program is able to come up with the reasonably expected output results. Curse of Dimensionality While the "curse of dimensionality" sounds like a very complex concept, and one that comes from a science fiction or fantasy novel at that, it merely refers to how it is difficult to measure three – dimensional physical objects in the high – dimensional space that data scientists and mathematicians work in, and the various phenomena that arise from this fact. This problem is caused by the fact that as the number of dimensions increase, the volume of the space increases at a rapid space, so much so that data becomes difficult to gather. One example of how this affects data scientists is the organization of data in high – dimensional space: due to the large amount of data points, many objects look dissimilar though they are similar in reality, which renders many common data organization methods and strategies useless or impractical. Semi – Supervised Learning A subset of the supervised learning method, also known as optimal experimental design, it combines elements of supervised learning and unsupervised learning, as unlabeled data entries are included in the training set given to the program. This means that the program learns to calibrate itself through inductive or transductive learning methods, where given the rest of the training set, it infers the proper labels for the unclassified data sets. In fact, the proportion tends to be skewed in favor of unlabeled data sets, with a small portion of the total training set being labeled sets, and the rest being unlabeled data. This can be likened to a math teacher giving worksheets to their students, where the first few problems are already solved, with the solution and answer given, and the rest of the worksheet is left blank. Students learn from the examples, and extrapolate the proper method to solve them through the given problems. This method cuts down on costs, as finding or acquiring labeled data is often a resource drain, as it requires a human expert to convert data into a type useable and accessible by a computer. Semi – supervised learning as a method has also been shown to result in higher accuracy in results. Active Supervised Learning Active supervised learning is a type of supervised learning where the program is given the ability to actively ask the user questions regarding the label of the data sets. This method uses a combination of labeled and unlabeled data sets, and due to the high cost of manually labeling each data set, the active supervised learning method can be used instead. This allows the computer to attempt to learn using the training set, but if the margin of error in labeling of a particular data set is too high for the program to "tolerate", then the algorithm usually asks the user in order that it may properly self – correct. This active participation by a human user is the reason that this method is referred to as the active supervised learning method, and unlike most other methods where little to no human interaction is required once the algorithm starts to run, this method needs a human to be able to fully complete its training set. Reinforcement Learning Reinforcement learning is a unique method of supervised learning, in that training sets are not provided. Instead, what happens is that the program is left to carry out actions in an environment, and it learns based on a rewards and incentives method, where if their action is correct, then it is reinforced. This allows the program to find different results, and the focus is taken off of correcting sub – optimal results, but rather finding the method that results in the best performance. This method is often carried out by feedback – intensive activities, such as when playing games against a human user or even driving cars. Reinforcement learning is how some programs such as OpenAI have been able to beat human players in video games, and how Google has been able to develop an autonomous, self – driving car. This learning method often uses the Monte Carlo heuristic method, which allows the computer to calculate probabilities in a resource – starved environment. 

Unsupervised Learning In unsupervised learning, the algorithm is made to parse through totally unlabeled sets of data in order to train itself. This means that there is a higher possibility for errors as to compared to the supervised learning method earlier discussed. Unsupervised learning is generally used more for clustering data and values and sees the most use in statistical analysis where there is a need for density estimation functions. Unsupervised learning is more weighted to finding out probabilities of outcomes, such as the probability of Y for any particular X value, and this is why statisticians are the ones that make the most use of this particular machine learning task. However, when it comes to more conventional requirements such as training a program to recognize or predict particular outcomes given a set condition, it would most likely be more effective to make use of a supervised learning method rather than the unsupervised counterpart. 

Machine Learning Applications Learning deals with managing possible future input: while requiring, for the most part, input – output pairs, the machine learning process is there to teach the program what to do with future input. When it comes to machine learning applications, this is where the output of the machine learning program is addressed. There are multiple application types, too many to discuss here, thanks to the versatility and flexibility machine learning offers to users. However, there are a few major types, the following which we will discuss here. 

Classification In data science, more specifically in the fields of statistics and machine learning, classification is a type of problem where a particular observation, or data point, is placed into a category where it belongs, on the basis of similar characteristics, which in this case is based on the training set fed to the program, which contains instances or observations which the program can identify the membership of the said data points. One common example of a classification output in action would be an electronic mail spam filter, which classifies our electronic mail into one of two categories: "spam" (unwanted e – mail), and non – spam (legitimate e – mail messages). A more advanced type of classification in machine learning is how some new programs are trying to provide diagnostic services, and they provide diagnoses based on recorded symptoms of the patient as well as certain factors such as age, sex, and race, which allows the program to better predict the likely diagnosis. Classification is mainly a type of pattern recognition, and is usually created through a supervised learning method, where the algorithm is taught using a set of data points where properly identified and categorized learning is already available. Classifiers are algorithms that implements the classification method, but the term "classifier" is also used in order to refer to a mathematical function that directs and categorizes input data into a certain category, but for the purposes of this guide, classifiers are classification method algorithms. Classifiers are usually created by splitting data points into certain variables, which may have various properties, such as categorical properties of blood types \*"A -", "O +", "AB +"), ordinal (tall, regular, short), or even integer – valued (such as for spam filters which count for the number of occurrences of particular words). Some other classifiers are built using comparative observation, which have a function that compares distance or similarity between the two. 

Clustering Much like classification, clustering involves grouping together particular data points or observations based on a list of characteristics that would make them belong in the same category. However, clustering tends to be of a broader scope, and less clear – cut as compared to how classification decides to segment its categories. Clustering, or cluster analysis is mostly used by statisticians and data scientists, especially when it comes to solving problems of information retrieval, data compression, or density estimation functions. As was briefly explained earlier, the clustering function is usually created through an unsupervised machine learning algorithm, as compared to classification functions created through supervised learning. This is because clustering does not emphasize specificity as much and works more to gather similar objects together rather than individually define each object into a specific class. 

Density Estimation In what is basically a sub – type of clustering, the density estimation output method is an estimate built based on various observations, of an underlying probability density function, which is often unobservable. This function usually takes random samples from a population, and using the random sample, the unobservable density function that is to be estimated tends to be the density distribution of the larger population. 

Dimensionality Reduction Dimensionality reduction is a type of output that tries to reduce the complexity of objects and simplifies the input by mapping them into a lower – dimensional space, which eventually allows the user to simplify the objects and allow them to undergo feature selection or extraction, which is the process of identifying the most relevant attributes, or "features", in order to be better able to build a model. This is useful especially since there tends to be a problem in the increase of available dimensions and as such, sparser relevant data when objects are placed in high – dimensional space, so dimensionality reduction is often a necessary factor to making objects more accessible and useable. 

Regression Analysis Regression, a word that many people hear and immediately fear due to its complexity, is a statistical process that people use in order to estimate and define relationships between and among various variables. Regression as a whole refers to multiple techniques that allow us to model the relationship between a dependent variable and one or multiple independent variables, known as predictors. Regression analysis is very useful for helping us understand how the criterion variable, or the dependent variable as it is commonly known, is affected and changes whenever some independent variable changes, while the other independent variables, if any, remain fixed. Regression analysis is also used to help estimate the conditional expectation of the criterion variable given the predictors, so we know what the criterion variable's value the predictors will be once they are fixed. However, there are also those that use regression analysis to focus on some location parameters of the dependent variable's distribution in relation to the independent variables. Notably, due to the characteristics of regression analysis, where the data points fluctuate depending on what is being controlled for, the outputs tend to be in a continuous form rather than in a discrete form, matching the changes in real – time.

Linear Regression Linear regression is a type of linear algorithm, a linear approach that is often used to model the relationship between a dependent variable (a variable that has a scalar response) and one or more independent variables (also referred to as explanatory variables). Depending on whether or not there is only one or multiple independent variables, linear regression can be called simple or multiple linear regression. However, both these types are different from what is called the multi – variate linear regression, as this deals with multiple dependent variables (scalar response variables) and the previous two only deal with a singular scalar response variable. For linear regression algorithms, these relationships are modeled through various predictor functions, where the parameters are unknown, but they are extrapolated from the data, where the machine learning aspect comes in. These models are called linear models. Linear regression focuses mainly on the probability distribution of the response of the scalar variable given how the predictor variables (the independent variables) value changes, as opposed to other mathematical models that try to map the joint probability distribution of all the variables involved. Linear regression analysis is one of the most popular types of regression analysis, due to the fact that models that have a linear dependency on their unknowns are easier to work with as compared to models whose parameters are related to each other in a non – linear fashion. In addition, the linear nature allows for easier determination of the various statistical attributes of the estimators. Linear regression is most commonly used for two general categories. The first is prediction: forecasting and error minimization problems tend to have a linear regression solution, as a linear regression analysis is helpful in creating a predictive model if the user has an established set of observations when it comes to the dependent and independent variables, and linear regression can be used to extrapolate from there. Once a model has been created, more examples of explanatory variables can be collected, and even without an observed reponse value, the model should be able to create a reasonable prediction of the value of the response. The second major use of linear regression is to explain variation in response variables, where such variation can be attributed to the variation in the values of the independent variables, allowing the user to quantify the strength of the link, or the relationship between the dependent and independent variables, and even determine whether or not they are related at all, or if some independent variables have a redundant function. The K – nearest neighbors algorithm is also used for classification and regression of various data points, and the input in these cases consist of k closest examples in the feature's space. The output, however is dependent on whether or not the K – N N method is being used to classify things or as a regression method. If the K – N N is being used for classification, the output of the K – N N is a class category, as the object will be classified by the majority of its neighbors, being assigned to the class that is most common among the k nearest neighbors, for k being a small assigned integer. In fact, if k is set to be equal to one, then the object in question will simply adopt the class of its neighbor. However, for K – N N regression, the output is the so – called "property value" of the object. The object's "property value" is taken by taking the average of the values of the nearest k neighbors. The K – N N method is known as a type of instance – based learning, or so – called lazy learning, as the function only approximates from local values or objects, and computation does not happen until the classification itself is to be done. This means that the K – N N algorithm itself is counted among the easiest to use and among the simplest of machine learning algorithms. However, the K – N N algorithm can be modified by adding a weighting scheme, for example, the closer the neighbor is to the object in question, the greater weight it is given. A common weighting scheme follows the formula 1 / d, where d is the distance from the object to its neighbor. The neighbors themselves are taken from objects whose class has been identified (if using K - N N for classification) or the property value is known (if using K – N N for regression purposes). TensorFlow The previous codes and data types were all carried out mainly through the use of scikit – learn, but what about TensorFlow? TensorFlow is a google – created software library initially created for proprietary use, but eventually released for public download and use under an open – source license in 2015. TensorFlow focuses mainly on data – flow programming and is a symbolic math library that is used for machine learning that makes use of neural network functions. Though TensorFlow can also be used much like scikit – learn, as it also contains numerical and scientific functions, its main advantage is in its capability in creating neural networks. However, before we can move to that, we first have to learn what a tensor is. 

Tensors A tensor is, reduced to its simplest form, a multidimensional data array. So TensorFlow is literally named after the flow of tensors, or the continuous flow of operations on multidimensional data arrays which neural networks perform. That bit of trivia aside, let's dig a little deeper into the subject of tensors. What one has to remember is that computations by neural networks are done on data flow graphs, where nodes represent mathematical formulae and operations being carried out by the machine, and the edges are the multi – dimensional operators, or tensors that contain all the relevant data. Before we go even deeper, however, it is important to review a few concepts in linear algebra and vector calculus, as these are keys to understanding tensors and why they are so crucial to neural networks. Plane Vectors When a person hears the word vector, they may think of the physics meaning, a quantity that has both a magnitude and a direction. However, in data and computer science, vectors are referring to something a bit different in concept. While similar, the programmer sees a vector as a type of matrix, an ordered collection of numbers but with only one column, though it may have multiple rows. In this case, if the data is plotted out, it looks one dimensional. In a way, one can still imagine these vectors as a scalar value that was given direction, fulfilling its definition as we know it from basic physics. However, mathematical vectors have a strange characteristic in while their value / magnitude remains fixed and absolute, their direction is totally relative based on a given point of reference. Now what about plane vectors? Plane vectors are what one may consider the simplest type of tensor, and they have much the same characteristics as the standard vector. However, plane vectors are found in vector space, a collection of other vectors that can interact with each other through mathematical operations. For example, we have a 2 x 1 vector. This means that the vector has a pairing of two real numbers, a part of two – dimensional space. This leads us to the conventional ray vector on the (x , y) plane, and we can plot it easily. In a two – dimensional space, understanding this vector is easy due to the fact that we are used to working with the cartesian coordinate system, and we can simply assign an origin with coordinates (0, 0) to determine the direction of our created vector. The X coordinate is found on the first value of the vector, and the Y coordinate is found on the second row value. However, as vectors grow larger, it becomes more complicated. Take for example a vector of size 3 x 1, which can now be visualized as being on an (x , y , z) coordinate plane, or three – dimensional space. This time we can create a three - dimensional figure where we can assign values to the positions they hold in the vector space, representing them on the coordinate plane. It gets more and more complicated to visualize, however, as the amount of dimensions of the vector go up, and this is where the curse of dimensionality begins to kick in as explained in an earlier chapter. However, one has to remember that the entire point in having a vector is allowing one to perform mathematical operations on them. One convenient way of carrying out operations is simply expressing vectors as base vectors or unit vectors, simplifying the process. Unit vectors are vectors that only have a value of one. These are usually denoted by lower case letters with circumflexes, affectionately nicknamed "hats". These unit vectors are convenient especially when attempting to express a two – dimensional or three – dimensional vector as a sum of multiple orthogonal components, such as the x –, y- , and z- axes.Note as well that vectors themselves are the sum of their component vectors, and they can be expressed as such if the need arises. Returning to tensors as a whole, in addition to plane vectors, co – vectors and linear operators are also certain specialized types of tensors. Remember that a vector is a scalar value that has been assigned a single direction. A tensor is something that is considered to be the mathematical representation of a physical object that has a magnitude and more than one direction, which while difficult to fathom, is a concept that is integral to understanding how all this works. Scalars are represented by a single number, the magnitude. Vectors are represented with a sequence of numbers, corresponding to the dimensions they exist in, such as two – dimensional vectors having two assigned values, and three – dimensional vectors having three assigned values. Tensors, however, are represented by an array of 3R numbers in three – dimensional space. In this case, the "R" in 3R represents the rank of the tensor. For example, a second – rank tensor is represented by 3 raised to two, or nine numbers. So to put it mathematically, scalars will always only require one number in an N – dimensional space, vectors will be defined by N values in N – dimensional space, and tensors will be defined by N^R values in N – dimensional space. This makes scalar values be considered as tensors, as they are rank 0 tensors, as anything raised to the 0th power results in 1. Scalars are represented by a number, vectors can be represented by a set of number, and tensors are represented by an array of numbers. How is this important, however? Tensors are special because of how component vectors and basis vectors combine. Basis vectors transform between reference frames, but the component vectors transform along with them in such a manner as to keep their combination the same and maintain a consistent value. 

What is a Neural Network? A neural network, more properly known as an artificial neural network, commonly abbreviated as (ANN), is a processing method or device loosely modeled after the operation of mammalian brains, specifically our human brains. Neural networks tend to be organized in layers, with each layer consisting of multiple nodes, each with its own activation function. Input patterns are presented to the network through the input layer, which transmits the information to other, "hidden" layers that carry out the actual data processing through weighted connections. Once the data has been processed, they are transmitted to the output layer of the ANN. What makes the artificial neural network similar to how human brains work is the learning process, where the connections and weights between layers are modified as input is received, meaning that the more information is fed to the neural network, the more it is capable of reaching a reasonable output, much like a child that is constantly shown pictures of dogs will learn how a dog looks like. Neural networks have numerous types of learning rules, but for now, we will cover the most basic one, the delta rule. The delta rule is one of the most common rules, as it is utilized by a type of neural network known as backpropagational neural networks, or B P N Ns, which are among the most common types of neural networks. Backpropagation stands for the backwards propagation of error. The delta rule allows for a supervised learning process that happens each time the network undergoes a cycle, or an "epoch", which is whenever a new input pattern is received. Whenever an epoch starts, there is a forward flow of output, but a backwards weight adjustment happens afterwards. To simplify the process, it is as if when the neural network receives an input pattern, it simply hazards a guess as to what it may be. Once it does this, it is able to see how far away its answer was from the correct one and makes adjustments to the connections in order to be able to make a better guess the next time it receives a similar input pattern. Once the neural network has "learned" enough from controlled input where the output is known, then it may be employed as an analytical tool to parse data that is no longer labeled. In order to carry out this function, the programmer must specify that it is no longer carrying out training runs, and the neural network will continue to function solely in forward propagation mode, where new input is presented to the input pattern and received as normal, and processed similarly as in the training mode, but there is no more backpropagation and the output is simply displayed. This output from the forward propagation run is then the data model that is used for analysis and interpretation by the user. The reason that neural networks are not kept on an eternal "training run" is that there is a chance that it will become too specialized and "learn" to respond to a specific type of input alone, which if likened to a human equivalent, becomes rote memorization instead of actual pattern recognition. If ever this over – training happens, the neural network loses much of its value as it no longer recognizes anything but the single input, and this type of ANN is refered to as a "grandmothered" network. What's the difference between Neural Networks and Conventional Computers? First the reader has to remember how a conventional computer works, and how it processes information. Conventional, or "serial" computers have central processors that have access to specific memory locations which store both data and instructions. Computations are carried out by these processors by reading the instruction and data from the specific memory address, which is then executed and the results saved in yet another memory location. The standard computing system has a sequential and logical method, and a variable's state can be tracked and be given a defined value at any point in the process, from beginning to end. However, neural networks do not contain any central processors, but rather have a multitude of small simple ones, that do not do much on their own, and in fact often simply take the sum of the input from other processors (or "nodes"). Neural networks do not access instructions in the conventional way, as they respond in parallel to input rather than in a sequential method like conventional computers. One of the biggest things as well is that there is no dedicated data storage or memory address for neural networks, but instead information is contained in the "state" of the network, where the knowledge is the network itself, which then becomes more than simply the sum of its parts.
