# # Hashing

Another integral major cryptographic function is integrity hashing. Hash algorithms (also known as hash functions or simply hashes) are used to create unique output results for unique inputs. They use "one-way" cryptographic functions, which create and output a representative set of characters or bits (the hash, hash result, or message digest) of unique content. Hash functions create digital fingerprints of the content that they hash. Hashing functions can be used to cryptographically sign and verify the integrity of content, subjects, and other cryptographic objects. When the integrity hash (often simply as a hash or message digest) is cryptographically tied to a particular cryptographic identity (e.g., user, device, or service), it is known as a digital signature. A verified digital signature allows the receiver of signed content to have confidence that the contents have not been altered since the signing of the content by the authenticated signer. Secure, trusted hash functions have four important traits:

+   * For every unique input, one output result must be generated. This type of protection is called collision resistance.
