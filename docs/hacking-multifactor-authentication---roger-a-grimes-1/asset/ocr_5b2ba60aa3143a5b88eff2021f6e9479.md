# Access Control Token Tricks

Chapter 6 begins a detailed look into dozens of examples of how to hack various multifactor authentication solutions. Specifically, we'll look into hacking the access control token, which is likely one of the oldest and most popular methods. Attacking the access control token usually means the attacker doesn't care about what type of authentication was used, it be a single-factor password or multifactor, biometric, super-MFA device. An access control hacker only cares about re-creating or stealing the access control token, which in most cases is given after a successful logon.

# Access Token Basics

Access control, in general, is a system or set of defined processes, people, and policies implemented to prevent unauthorized subjects from accessing protected resources. In the real world, it's the keys to your house and it's guarded gate. It is barbed-wire fence. It is every building key entry system. Digital access control systems attempt to do the same with digital systems needing security domains for trusted and secure operations.

As you learned in Chapter 2, “Authentication Basics,” when a subject successfully authenticates, most authentication systems then generate and transmit an access control (aka access token) to the subject, or accurately the processes running on behalf of the subject. The token can come in many forms. It is often in the form of a plaintext “cookie” when a user logs on to a website or service, and on Microsoft Windows systems it is often in the form of an NT token or Kerberos token. It can even be a temporary memory variable set in a way to allow the operating system or application to know that the user has successfully authenticated.

The purpose of an access control token is to allow subsequent decisions requiring authentication subjects to be more quickly made without requiring a subject to completely authenticate again, especially during the session or overall action. Imagine, if every time you clicked on a different page in the same authenticated website you had to completely authenticate again, over and over, or every time you opened a document in Microsoft Word from your own folders that you had to type in your logon name and password again.
