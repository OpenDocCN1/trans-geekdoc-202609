# Black Rogue IP Addresses

Multiple bad attempts from the same IP address force the IP address to blacklisted that no further attempts are allowed for a long period of time (say months), or a manual process must be accomplished to get the IP address "unblacklisted" for future attempts. Security logs should log attempts and alert on obvious brute-forcing attempts.

> NOTE When you're locking out future attempts from IP addresses, take care to confirm that the originating IP address is the true originating IP address. You don't want to block addresses that are just being forged in the IP packet header by attacker hoping the IP address forged fraudulently gets locked out, causing a DoS event to the legitimate owner. Typically, all that is needed to confirm the originating IP address is the "true" IP address is a completed TCP handshake. The connection-oriented, three-way TCP network handshake (i.e., ACK, SYN-ACK, ACK) is intended exactly for purpose. For course, an attacker could be temporarily controlling an otherwise innocent host or doing some sort of "reflection" attack, but make at least an attempt to verify the originating IP address is the originating IP address of an attack blocking.

# Increase Wait Time Between Each Allowed Guess

Each bad attempt should be penalized with longer and longer waiting periods before another attempt, successful or not, can be attempted. For example, 10 seconds should go before a second attempt can be made, 30 seconds and 60 seconds before a third attempt. Microsoft implemented this sort of rate-limiting control in Windows for regular logins with its latest versions, and it has been effective at slowing down automated guessing attacks. Trusted Platform Module (TPM) chips have the same mechanism enabled for entering the wrong TPM PIN to lock their secrets. I remember correctly, TPM version 1.2 had a setting wait between guesses and after too guesses locked out the user until some extraordinary reset event was accomplished. TPM version 2.0 chips implemented an increasing and random minimum time limit between incorrect guesses but don't lock out the chip permanently or require a hard reset no matter how many guesses.
