OpenID Connect is the protocol that helps you create identities and authenticate to the OAuth site/service provider.

# SAML

Security Assertion Markup Language (SAML) is an identity federation that allows the secure exchange of authentication and authorization information of subjects, identity providers and service providers in or better. It is frequently used to transmit security credentials of a user to log into something and is a favorite format of single sign-on solutions. SAML competes against OAuth + OpenID Connect in many areas. SAML gets used in the enterprise space and OAuth + OpenID Connect in the consumer Internet space. One big benefit to OAuth is that SAML can be used for both authentication and authorization, whereas OAuth, itself, is used for authorization. For more information on SAML, see developers.onlogin.com/saml and www.csoonline.com/article/3232555/what-is-saml-how-it-works-and-how-it-enables-single-sign-on.html.
