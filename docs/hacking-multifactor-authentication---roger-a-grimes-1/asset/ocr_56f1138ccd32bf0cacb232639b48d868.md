# Login.gov

Login.gov (login.gov) is a website that allows "secure and private online access to participating government programs.\ It's the tens of millions of Americans access their public government resources. In 2017, a hacker reported an MFA bypass using (hackrone.com/reports/264090). He was able to start the registration process, then sent him a confirmation email. The website expected the user to click the link to confirm their registration and told him he had only 24 hours to do so. Then he noticed it did not require him to confirm that the registration code was tied to a specific email address, that it could be used multiple times, and that it did not expire in 24 hours. Using the initially provided authentication, he was able to log in to involved websites without any authentication the authentication code. Login.gov took two months to fix the bug after it was reported. See mustafemalkan.com/bypass-two-factor-authentication-on-login-gov/ for more details.
