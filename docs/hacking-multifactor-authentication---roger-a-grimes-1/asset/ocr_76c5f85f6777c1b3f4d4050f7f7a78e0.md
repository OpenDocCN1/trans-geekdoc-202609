Third, all password managers have bugs. You can type your name and password all long every day and never have a problem. But every password manager I've tested has bugs. Most of the time they work; sometimes they don't.

Sometimes these bugs can be “fatal.” I've read about many password user who suddenly had their password manager program lock up or error out and the user was abruptly locked out and unable to use it. Because the user often doesn't know their login, they can't log on to a website they use with the password manager. They effectively become become out from all websites they use with the password manager, until they recover the password manager or reset all their passwords, individually, one at a time. It is also uncommon for a password manager to get a security bug that attackers may be able to take advantage of until they got patched. # Single Sign-On (SSO) and Proxies

Single-Sign-On (SSO) and proxy programs are similar to password managers, but usually more complex. Unlike password managers, most of which run in a single local location on behalf of a user, these programs run in a centralized, shared location on behalf of many users. The idea is that a user can log on to the SSO program, and the SSO program will handle logging on to the rest of the programs the user needs to authenticate to (or as many as it can or will be allowed). Most SSO solutions are installed and focused on helping one organization’s user to connect to other resources the organization needs everyone to connect to.
