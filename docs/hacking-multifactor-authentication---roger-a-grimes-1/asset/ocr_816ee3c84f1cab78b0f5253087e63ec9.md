Figure 10.14: Help Desk user with elevated groups of Super Admin as shown by whoami /groups

The Help Desk user is IS Super Admin user. This occurred Active Directory had no way of knowing that the Super Admin user account should not have a UPN of helpdesk@victim.com. Active Directory gets told by Windows that a successful smart card logon has occurred and the UPN of helpdesk@victim.com is part of that transaction. AD looks it up and finds the user with the associated UPN, and then gives that user the access control token of the Super Admin user, including groups and privileges.
