Many networks simply take the sent information as valid, trusting that the sending source performed all the critical verification steps first. This is an unfortunate and optimistic stance by default. It is ripe for abuse.

Additionally, many URL links sent via SMS are often harder to inspect for security issues without completely loading the web page and being exposed to content itself. SMS URLs are often "shortened" to some innocuous-looking link that makes it hard to figure out where it ultimately leads. So, a URL link might say something like bit.ly/Ytacoe and, when open, might redirect to something looks like thisbadwebsite.com/virus.php. Most phishing via SMS messages includes shortened URLs that are intended to hide the destination.

Security people aren't fans of URL shortening services in general, but when paired with limited pre-inspection capabilities of SMS and lack of authentication, there are even more reasons to be skeptical. Users cannot "hover" over an SMS URL to find out where it goes to, and SMS applications do not contain as many anti-malicious controls as the typical browser does (although many times, SMS URLs are opened up in the user's browser anyway). As our online world is increasingly connected by one cell phone, phishing is growing in popularity with attackers.

# SIM Swap Attacks

Before I discuss SIM swap attacks, I need to make sure everyone understands what a SIM is.

Subscriber Identity Module (SIM)

Most mobile devices that accept cell phone calls and messages have several globally unique numbers associated and stored on them. Each cellular device and network can have different requirements and often store many pieces of various information, but most have at least a few minimum types of unique numbers.

One is an International Mobile Subscriber Identity (IMSI) number. An IMSI contains three parts:

+   - Three-digit Mobile Country Code (MCC), which identifies the mobile device it registered in

+   - Three-digit Mobile Network Code (MNC), which identifies the device's registered provider (visit the following for example codes: www.roamingzone.com/mnc)

+   - Nine-digit Mobile Station Identification Number (MSIN), which identifies a specific subscriber no matter device they use
