# 26 Hacking Multifactor Authentication

There are more efficient password hash databases called rainbow tables. Rainbow tables convert all the much longer password hashes ahead of time to an intermediate representative, to a much shorter format, and do the same for the captured hash. For example, using the very long hash (as shown earlier), the intermediate representation may match D9DE79EAA. Unlike a true cryptographic hash, the intermediate represent may match for many different password hashes, but the correct hash is included in the list of password hashes represented by the shorter representative form. For example, a few thousand password hashes have the same intermediate form. When the rainbow table converts the targeted password hash to its intermediate form, it still has to search a much smaller pool of possible password hashes. It can take all the password hashes with the same intermediate form as the targeted hash, and then calculate its full password hash form and find out which those thousand actually matches the full password hash of the targeted password—and without having to search through billions of much longer password hashes.

So, a smart password hash cracker will use a rainbow table program that incorporates a dictionary attack. There are handful to dozens of rainbow table programs for password hash types. Figure 1.7 shows a popular rainbow table program called Ophcrack (ophcrack.sourceforge.io).
