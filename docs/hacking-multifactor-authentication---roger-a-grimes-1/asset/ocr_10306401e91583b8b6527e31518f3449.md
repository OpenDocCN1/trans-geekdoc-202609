> NOTE Another site similar to HaveBeenPwned is HPI Identity Leak Checker (sec.hpi.de/ilc/). You enter your email address and it sends you a report listing where your email address and other personal information has been compromised that it knows. It will tell you if information beyond your logon information has been compromised, such as Social Security number, telephone number, and banking details.

Many other free and commercial tools are available that may notify you if your password ends up on one of the dumps or data breaches. For example, I use a password manager called iPassword (ippassword.com), which notifies me when a website on my personal logon list gets compromised. In 2018, I proactively noticed when a data breach was involving Facebook (see Figure 1.2). When it first alerted me, I was so shocked that it included Facebook that I thought something was wrong with the password manager. I looked around on various IT security websites and found was out about a Facebook breach. About three hours later the news confirming the breach began to pour into every major media website. My password manager was out to its hours earlier, and I had already changed my password before the news broke.

There are many ways for hackers to locate your password if it is already in an existing breach. One way is for them to just use the API that attaches to Troy Hunt's website. Troy doesn't know who is or isn checking his website for password breach checks, plus he doesn't store the user's password in a way that anyone, hacker or not, can just pull up individual plaintext passwords. His site can be used to see if a particular user's or company's password exists in a known password dump. If it is, then the hacker can try some of the more popular, larger, dump sites and get the full logon information, including the password.
