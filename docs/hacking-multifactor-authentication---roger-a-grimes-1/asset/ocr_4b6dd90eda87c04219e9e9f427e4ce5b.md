# Hacked DNS Record(s)

Known as domain hijacks, the most common type of DNS hacking is when an intruder takes control of a DNS administrator's account or the authoritative DNS server and changes the IP address of a DNS record to point to another rogue location. The hacker takes over the user account of the legitimate DNS record owner at the DNS service and makes the change, or they take control over the entire DNS server. There have been decades of these types of attacks, and they continue to be very popular.

# DNS-Changing Malware

Hundreds of malware programs are around that, if run on a computer, will attempt to change the computer's DNS settings. They will either maliciously modify the hosts file to particular queries to wanted locations or change the user's default DNS server to point to their DNS server, which then serves malicious IP addresses to DNS queries.
