Ultimately, Microsoft is asking the same questions that a human-based technical support person, could, in an automated way. Eventually, the user must answer enough questions successfully to automatically recover the account. The questions are so thorough that I'm not sure if a user could successfully recover their account by calling and talking to a human Microsoft technical support person. The support person would likely ask the same questions and be guided by the same policies to determine the user's legitimacy—although any time a human is involved, a good social engineer can possibly win over policy.

Google's advanced recovery process eventually asked me to verify my identity using the prereistered device and the Google Authenticator app. As I pursued to fail authentication attempts, Google eventually displayed a code on my computer screen, the number 23, and then sent me to pick the Google Authenticator app on my phone three different one-and two-digit values and asked me to pick the value that displayed on my computer screen. When I choose the correct value on my phone screen, I was successfully authenticated on my computer. This sort of authentication was possible because I used two previously used devices from locations Google had previously detected. The future of authentication will use both of factors (device and location) as primary determinations of adaptive risk.
