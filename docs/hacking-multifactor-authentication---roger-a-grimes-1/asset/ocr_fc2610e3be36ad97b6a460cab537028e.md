# Introduction

**Chapter 11: Fake Authentication Attacks** Chapter 11 covers a type of MFA attack that can be used successfully against most MFA. It involves taking the user to a bogus web page and faking the entire authentication transaction, accepting anything the end user types in or provides, as successful. Learn how authentication attacks can be prevented.

**Chapter 12: Social Engineering Attacks** Social engineering attacks are responsible for the most malicious breaches of any hacker attacks methods. Social engineering can be used to get around any MFA solution. Chapter 12 covers many of the popular social engineering attacks against popular MFA solutions.

**Chapter 13: Downgrade/Recovery Attacks** Most of the popular MFA solutions allow a lesser secure method to be used to recover the associated account in the event of a problem with the MFA method. Chapter 13 covers how to use downgrade/recovery attacks to bypass and disable legitimate MFA solutions.

**Chapter 14: Brute-Force Attacks** Many MFA solutions require users to type in PINs and other codes and do not have a mitigating "account lockout" feature enabled to prevent an attacker from guessing over or until they find that information. In fact, it is so common for relatively new MFA solutions to forget this important safety feature, Chapter 14 shows, it is almost commonplace more than.

**Chapter 15: Buggy Software** Security is as buggy as any other software. MFA solutions are no exception. Chapter 15 discusses why we have buggy software and dozens of examples of buggy MFA solutions, including a single bug that can lead to tens of millions of MFA devices being immediately vulnerable.

**Chapter 16: Attacks Against Biometrics** There is not a biometric MFA solution that cannot be hacked or a biometric trait that cannot be mimicked. Chapter 16 describes many such attacks, including attacks facial and fingerprint recognition, and discusses mitigations against copying and reuse attacks.

**Chapter 17: Physical Attacks** A common dogma says that if an attacker has physical access of your device, it's game over. This is especially true of MFA. Chapter 17 will cover multiple physical attacks, ranging from using a multimillion-dollar electron microscope to use a $55 of compressed air.

**Chapter 18: DNS Hijacking** Chapter 18 discusses how hijacking the name resolution service attached to an MFA solution can lead to the whole solution failing. Some MFA providers dispute whether this sort of attack should be considered a real attack against the MFA solution since it doesn't attack the MFA directly but allows MFA compromises.

**Chapter 19: API Bases** Many MFA solutions have application programming interfaces (APIs). Chapter 19 shows how APIs can be used to compromise a single MFA scenario or a million victims at the same time.
