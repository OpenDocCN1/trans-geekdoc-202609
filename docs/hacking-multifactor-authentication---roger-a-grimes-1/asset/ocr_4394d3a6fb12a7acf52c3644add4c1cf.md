# Increasing Sophisticated Automation

Hackers and malware writers have been using automation for decades to perform their attacks. But the automation actions and the sophistication have been increasing significantly the last few years. For example, ransomware used to exploit a computer, immediately lock it up, and ask for $300 in ransom to decrypt. Now when ransomware program breaks into a computer, it "dial home" to let its creator/spreader know that it's in a new victim's environment so that ransomware can investigate further. It usually downloads updated versions of itself or new malware. As traditional ransomware gains sophistication, it would look for admin passwords on the first exploited machine and use what it found to break into additional computers within the network. It used to be that ransomware would remotely access computers and run scripts and other malware programs (like TrickBot) to find additional passwords used by employees and customers. The hackers would disable antivirus defense, delete backups, and copy data off the network. Now the entire process became part of ransomware's coding; no human attackers needed to be involved.
