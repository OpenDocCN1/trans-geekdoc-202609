# Cell Phone User Account Hijacking

Attackers will also compromise a user's cell phone user account portal using any valid hacking method that works to gain access to the web-based console that allows any supported cell phone to send SMS messages from the portal. Figure 8.13 shows an example web-based SMS-sending portal.

![](bbox=[0.095, 0.237, 0.718, 0.609])

Figure 8.13: SMS-sending web portal

Once the attacker has achieved access, they can send SMS messages to other people and they will appear to come from the victim's phone. A message will appear on the victim's cell phone in the SMS path and message history, but it will appear to a regular sent message. It does not proactively notify the cell phone user that a message was sent, it doesn't cause a sound notification, and the message is not highlighted in any way. Unless the victim happens to be staring at their phone's SMS message history right at the moment the message was sent, it probably not be discovered right away. And users seeing the rogue message would be confused about how it happened. During those minutes of ignorance or confusion, the attacker could be pushing an active deception scheme against the victim's trusted relationships.
