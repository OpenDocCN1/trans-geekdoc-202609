The answers you should use for each site; agree, treat them as you would passwords. In some cases, I am able to use the same answer for each question on the same site, and when possible I do. But the most of every answer for each question must be different—they check.
The biggest complication, and it's not great, that is answering your personal-account recovery questions wrong and uniquely means you'll definitely have to write them down. You will likely not remember them, months, or years later, when you might have to use them. I will write the questions and the answers down in my password manager in the section devoted to each login and site. You can write them down in a separate-protected document if you like. In either case, never write the entire answer in full text so that if the manager or document gets compromised, the full-text answer is not visible. For example, the fake answer in pizzazzvSvad2@M1, I might write down ppSvad@M1 and have to memorize the pp stands for something. Of course, if a bad person compromises your password manager or password document, it's pretty much gone away. They already have the keys to the kingdom. But it can't hurt to use abbreviations as long as you don't forget what the abbreviations are. In any case, stop feeling to answer the questions correctly if you're allowed to supply the answers. Make up the answers, store or write them down securely, and get rid of the risk.

# **Protect Master Codes**

If you have to have master codes as backup authentication, securely store them. I store them in my password manager, where I can easily access them on my phone if I need. If it printed out or downloaded, do not store the account identifier (e.g., email address) they are linked in full text along with the codes. That makes it too easy for unauthorized discoverers. At least make the attackers work for it.
