# Devices/Hardware

Any of the devices involved in authentication can be maliciously compromised. Devices include computers, phones, authentication devices, storage, memory, network interfaces, antennas, and any other physical device involved in the authentication process. They can be compromised to steal authentication secrets, stealing the access control token, eavesdrop, steal data, and redirect the user or authentication process to a fraudulent site or service. If a hardware device is compromised, it is difficult (although not impossible) for the authentication process to be trusted. This is not to say that some hardware isn't more hacking-resistant than others.
