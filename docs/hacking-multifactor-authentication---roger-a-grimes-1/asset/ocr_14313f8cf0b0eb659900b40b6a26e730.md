# Chapter 16 Attacks Against Biometrics 351

Why doesn't Microsoft enable anti-spoofing by default? The answer is proved foolish. One, they don't know for sure that your hardware supports it, although they likely require vendors to include a way to verify it using an API if they really wanted. Second, and more importantly, enabling anti-spoofing causes high false rejection rates and slower acceptance. That's the double-edged sword with all biometrics. As you decrease acceptance rates, you unavoidably cause higher rejection rates and slower processing. I've yet to a metric vendor that did not struggle with this issue. Companies using Windows with facial recognition should probably enable anti-spoofing. Of those at use are probably fine without it.

# Twins Spoof Face ID

If you want to see a set of identical twins Face ID, (NSFW because of crude language): www.youtube.com/watch?v=GFtOUpyqx4. They aren't the most perfect-looking set of identical twins I can imagine. They have different attributes on their faces and look to me, 100 percent perfect clones of each other. So, why did it work? Apple allowed the false-acceptance rate of Face ID to be higher than Windows Hello so more legitimate users were able to quickly log on using Face ID if they set it.

Conversely, I saw Microsoft's Windows Hello not faked by out of nearly perfect set of identical twins. Here's a video of a test against Windows Hello: www.youtube.com/watch?v=JINL246P9g. Windows Hello failed.

# Spoofing 2D Smartphones

In 2019, Dutch researchers tested 110 different smartphones by holding up a simple 2D face picture. It worked on 42 of the phones, but not the Apple Touch: zdnet.com/article/facial-recognition-does-work-as-intended-on-42-of-110-tested-smartphones.
