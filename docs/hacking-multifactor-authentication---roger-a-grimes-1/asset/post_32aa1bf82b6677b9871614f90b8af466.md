## DNS Record Types

DNS servers can contain dozens of different DNS records, most of which convert a domain name to its associated IP address, although they can also point to other DNS records and hostnames (and other information). Table 18.1 shows common DNS record types.

| DNS record type | Description |
|---|---|
| A | Host record; most common DNS record type; lists a DNS hostname and its associated IP address (IPv4) |
| AAAA | IPv6 host record |
| MX | Mail Exchange record; lists the DNS name/or IP address of the mail server for a particular DNS subdomain |
| CNAME | Canonical name; alias record; links a hostname to another hostname for the same device |
| NS | Name server record; lists IP address for DNS server that is authoritative for one or more domains |
| PTR | Pointer record; for reverse lookup; converts IP addresses to domain names |
| TXT | Text record; allows any type of free text to be registered for a particular host (e.g., in SPF, DKIM, DMARC anti-spam protocols) |

You may hear people asking for specific types of records. Most operating systems with a built-in command-line tool, nslookup, which you can use to conduct industrial, manual DNS queries. For example, as shown in Figure 18.2, used nslookup to ask for all DNS records associated with knowbase.com. Alternately, there are many graphical representations of DNS queries out on the Internet that anyone can use, including this: mxtoolbox.com.

For more information on DNS and DNS record types, visit en.wikipedia.org/wiki/Domain_Name_System and ns1.com/resources/dns-records-explained.

For more information on IP addresses, visit en.wikipedia.org/wiki/IP_address.

## Look-Alike Domains

The most common type of DNS hijacking is tricking users into joining a rogue domain that looks similar to a legitimate they trust by one type of social engineering. For example, a hacker might register domains to deceive users by accidentally clicking on them using common misspellings or typing mistakes. The latter is known as “domain squatting” where the owner of the rogue domain is counting on missing the legitimate domain and being redirected to the rogue site. If the rogue site looks decently legitimate, the misguided user may never realize their mistake and interact with the site as trusted. Another example is shown in Figure 18.3. ## Hacked DNS Record(s)

Known as domain hijacks, the most common type of DNS hacking is when an intruder takes control of a DNS administrator's account or the authoritative DNS server and changes the IP address of a DNS record to point to another rogue location. The hacker takes over the user account of the legitimate DNS record owner at the DNS service and makes the change, or they take control over the entire DNS server. There have been decades of these types of attacks, and they continue to be very popular.

## DNS-Changing Malware

Hundreds of malware programs are around that, if run on a computer, will attempt to change the computer's DNS settings. They will either maliciously modify the hosts file to particular queries to wanted locations or change the user's default DNS server to point to their DNS server, which then serves malicious IP addresses to DNS queries.
