Is Google To Ban The Binance Exchange API “Hack”?

March 12, 2019 by Paul Costello — Leave a Comment

This is a follow up to the article on the Binance Exchange API “hack” based on what we now know.

Binance was quick to stress their exchange was not hacked, but to be honest, you would expect that to be their first reaction, to prevent a meltdown. I use the term “hack” as a very general term for nefarious computer activities, which this occasion appears to be a very elaborate phishing scam.

It appears that the fake Binance site stole the credentials also hacked the 2FA security. The fake site requested 2FA via the Google Authenticator, and then, during the 60-second timeout for this security feature, it suspiciously logged into the real Binance site and activated API control over the affected account.
