At this point, the Help Desk user can do anything the Super Admin can do. They can add their regular Help Desk account to privileged groups; verify, modify, and copy files they not normally have access to; and eavesdropping trojans and other malware. They can modify operating systems and Active Directory itself.

And to make matters, Microsoft Windows and Active Directory will track all Windows Event Log events committed by the Help Desk user as if they were committed by Super Admin. After committing any unauthorized actions, the Help Desk user could swap the UPNs and log out. Unless UPN updates are logged and the importance of those particular actions were noticed, it would be difficult to see exactly what happened if he suspected it had happened. In most environments, this sort of skugguggery would occur without anyone being the wiser.

When I first saw this trick, Microsoft and Active Directory did not protect the UPN attributes as well as they do today. But if you have a help desk admin full Control over user accounts, as is still a common assignment for help desk admins, they could also change the UPN value of any user, including higher privileged users. Today, Microsoft protects the UPN field more strictly, and although a regular user account can still be assigned the ability to change UPN fields explicitly, if it doesn't correct AD just undo the permission.

Today, a more likely scenario is one changing the UPN field to another admin's UPN value so that everything is tracked to the other admin. So, it would be less privilege escalation and about hiding malicious tracks. For instance, using this trick would allow one admin to use the elevated custom group memberships of another admin without creating an alert of an unauthorized group membership occurring (as it could if the rogue admin just added themselves to a new elevated group). Or suppose the second admin has permissions on a second trusting forest. This trick would allow the malicious admin to acquire access to the second forest without having to ask for permission to the second forest.
