# Multi-Factor Authentication Security Tool

As I've mentioned a few times in this book, I work for KnowBe4, Inc. (knowbe4.com). Last year, after the huge success of my "12 Ways to Hack MFA" presentations, KnowBe4 asked me to write an e-book (info.knowbe4.com/12-way-to-hack-two-factor-authentication), which eventually led to the writing of this book. The 40-page e-book covers only 18 to hack MFA, whereas KnowBe4 created a part of their website dedicated to hacking MFA (www.knowbe4.com/how-to-hack-multi-authentication). You can check it for updates.

But my favorite thing KnowBe4 did to the topic was to create the Multi-Factor Authentication Security Assessment (MASA) tool: www.knowbe4.com/multi-factor-authentication-assessment. Created a year before this book, it doesn't contain every way I know of to hack an MFA solution/service, anyone can figure out how an MFA solution they are using or considering can be hacked. This checklist review tool/service was basically my brain on the subject year ago. When you run the tool, it asks a series of dozen or questions, so it can figure out exactly what type of MFA solution you are inquiring about. Then it spits out a report describing how your submitted MFA solution can be hacked. It starts with a summary page (see Figure 21.10 for an example). The cover page is followed by a deconstruction of each possible hack, much like the ones in this chapter in the last section, including a ton of other related information from the e-book. It's not perfect. It doesn't include every attack listed in this book. But it was a labor of love and I think useful to anyone who runs it to get a quick analysis of how their submitted MFA solution might be attacked.
