Many existing, legitimate services use HaveBeenPwned's APIs to perform bulk compromised account lookups. For example, KnowBe4, has free called Breached Password Test (www.knowbe4.com/breached-password-test) that utilizes HaveBeenPwned's API to look for logins related to the person's company who runs the test. That way, if someone has hundreds to thousands of user accounts and passwords they need, the APIs allow all to be tested far more quickly. Many open source hacking tools work with HaveBeenPwned's API as well to look up compromised accounts and passwords. For example, the hacker reconnaissance tool (tools.kali/information-gathering/recon), modules that contain the abbreviation hipb for HaveBeenPwned allow users to confirm whether or not particular accounts and passwords have been involved in a known breach, and it does this by using HaveBeenPwned's API. Nearly every API has rules, usage connection points, commands, and syntax to learn in order to be able to successfully and efficiently use it. To use HaveBeenPwned's API, users must first obtain a HaveBeenPwned API license key. A HIPB API key is a 32-digit hexadecimal for every different user, such as:

```
b163c0e184a147e5ad83c11d817aaf
```

Then to use the API to look up accounts that may possibly been breached, the user connects to HaveBeenPwned's API URL and uses a command that looks like this:

GET havebeenpwned.com/api/v3/breachedaccount/roger@banneretcs.com hipb-api-key:b163c0e184a147e5ad83c11d817aaf

The API query essentially, "To see if any breached logins have the login identity, roger@banneretcs.com, and here is my unique API key to provide to use the API." The HaveBeenPwned service will return all the documented breach cases involving login login identity align with the name of the breaches.

Then, whatever script or program interfaces with the HaveBeenPwned API simply uses that command string over and over, varying the account name being looked up until the sought identity accounts have been queried. There are many other commands and types of lookups anyone can perform using the API's commands and syntax.
