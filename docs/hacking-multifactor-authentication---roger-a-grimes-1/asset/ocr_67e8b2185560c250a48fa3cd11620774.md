# Knowledge-Based Authentication

Most of today's authentication is based on the subject or user supplying information only then the underlying authentication system knows. Most user and device authentication uses password-based authentication, the most popular form of knowledge-based authentication (KBA). KBA is often used to log on computers, devices, networks, and websites, and to connect to networks and join domains.

The KBA secrets can be memorized by users, then stored in a database or in a document. Both sides of the client-server authentication have previously agreed on using a common KBA piece of information, as providing a password or PIN, or some secret over port.

# Passwords

Passwords are generally least a few characters long, but they can easily be a few tens of characters long. Passwords can be typed in users, by interfacing systems, and along by intermediate processes. A single log and password may be involved in multiple processes. For example, in a Windows system, users can log on to their computer using their password. That password can be used and stored locally (in the Security Account Manager [SAM] database on the local hard drive), or it can be a network-based login (Active Directory or Azure Directory). The Windows operating system has dozens, if not well a hundred, local logins going on and between the various operating systems. Those log names and passwords are built in or stored by a process called the Local Authority Subsystem Service (LSASS). Users can connect to local areas or to remote resources over the Internet using other log names and processes (or have the operating system do it on behalf). Domain-joined Windows computers will log on to Active Directory or Azure Directory by using their own log names and passwords. Through much of the time we talk about passwords, we are actually referring to users manually using password authentication.

Expected password for systems varies greatly, from six to many hundred characters. Passwords for administrative accounts are typically on the longer side, 8 to 16 characters.
