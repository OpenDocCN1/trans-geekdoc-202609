# Hacking Multifactor Authentication

The bancos trojans quickly moved to the MitB method, where the trojan intercepted and modified the user's typed responses to the bank or used a second hidden browser session to conduct a fraudulent transaction. The bank's method of using a one-time code to confirm the transaction didn't work, because the trojan could just modify the user's typed commands (say, the user thinks they are transferring $40 to their kid) to something else (say, transferring $400 to a Russian bank account), and the bank would have no knowing of the user intend to commit the later transaction. The bank would send a code that was valid for the $40 transfer and the user would type it in their screen, thinking they were initiating a $40 transfer. The user had no knowing of that the transaction bank was seeing and the transaction they were trying to do completely different.

Bancos updated the SMS message to include the details of the transaction (i.e., date, time, transaction amount, amount, recipient) with the one-time code that was cryptographically linked to the other transaction details. Now, the critical details of what the bank was seeing to the user, who could verify the transaction before they typed the one-time code into the bank's website. This frustrated banking trojans for a long time until SIM swapping attacks came around (covered in the next chapter).

# Mobile Attacks

As our computer world has become a more mobile world, malware and trojans that bypass MFA have migrated to mobile. Many trojans bypass MFA in the standard form of trojan horse programs: the user gets tricked into installing it and then performs malicious behavior. Android and Apple have created heavily "app stores," which cut down the malicious programs that enter the ecosystem. Still, bad programs do not stay away. Apple is considered to have one of the hardest app stores to steal malware, but it still helps. Here's a new article about malware in Apple's app: www.wired.com/story/app-store-malware-click-fraud. Chances of a user downloading a trojan malware program increase-exponentially if they download that program outside of the official app stores. Tens of millions of phones have been compromised by trojans when users have them from the Internet or other supposedly "safe" but unofficial app stores. Here's a new article detailing defection rates from trojan Android apps outside the Google Play Store: www.wired.com/2016/12/never-ever-ever-download-apps-outside-google-play. Never download any app from an untrusted vendor, especially outside the phone ecosystem's official app store.
