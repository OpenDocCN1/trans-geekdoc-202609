# ## Password Guessing

Most password guessing is accomplished using automated tools built for just such purpose. There are dozens, possibly over a hundred tools (names like Bruth, THC Hydra, Web Brute, Bert, SqlPing, Wuzz, AirCrack-NG) all over the Internet that are used to automate the process of guessing passwords. You simply pick the target for the login you are targeting, start with your favorite password dictionary (list of passwords to try), load a list of login names, and point the tool toward a victim. If your software has a login screen asking for a password, there's a tool to take advantage of. Figure 1.5 shows THC Hydra version working in the demo.

# ## Brute-Force Guessing

The hardest and longest way is to brute-force guess. Brute-force guessing means that the guesses either intend sequentially from the first to the last (say a, aa, aaa ... z, zz, zzz, . ) or absolutely randomly (e.g., a57Rt1sv, bb, NM*R3#, frog). Brute-force guessing runs through all possible password dictionary entries without any sort of intelligence the likelihood of a particular password guess actually being the correct password. If you've got the luxury of time and as many guesses as possible without being stopped, brute-force guessing will get you to the right password at some future point in time.

# ## Dictionary Attacks

But brute-force guessing is almost the highest cost in terms of number of guesses needed and time required to be successful. If the password was created by a human, you're always better off using some sort of intelligence about the probabilities of what a human-created password most looks like (as discussed earlier). The average password user uses a “root word” as at least part of their password. The average human working vocabulary is 10,000 words on the upper side. That would be someone who is a prolific reader or a professional editor. Most people's vocabularies are close to 3,000 to 4,000 words. So good password guess would start with trying the most 10,000 common words in the intended target's vocabulary before trying all over 170,000 words you might find in the Oxford English dictionary.
