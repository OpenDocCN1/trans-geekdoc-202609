## MitM Is Possible

A MitM attack resembling what Kevin Mitnick did in Chapter 6, “Access Control Token Tricks,” is very likely possible. Bloomberg Anywhere is touted as the solution for accessing Bloomberg Terminal from nearly any PC, as long as you have your B-Unit handy. No location pre-registration information is required for the device. This means that everything from the legitimate Bloomberg Anywhere site to the user can be proxied, and vice versa.

Just like the Chapter 6 LinkedIn MFA bypass example, the hacker could send the victim a fake email or otherwise convince them to interface with a fake, look-alike website (which is really just an evil MitM proxy). Then, when the user types their login name and password, the proxy could just record those values and pass them to the real Bloomberg Anywhere site. The site flashing from the real website could be passed to the user on the proxy site like other bit of information. The B-Unit would have no way of knowing that the light was coming from a fake proxy website. The user would use their fingerprint to authenticate to the B-Unit. The B-Unit would generate a four-digit code, which the user would type back into the proxy website, which in turn would send to the real site. Now the hacker would be in control of the victim’s Bloomberg Anywhere session.

## Endpoint Compromise

As any MFA solution, if the user's endpoint is "pwned", it's over. If the user's computer is controlled by a hacker or malware program, they can do whatever the user can. It doesn't take admin or root access. The malware or hacker can wait until they have detected a period of inactivity but make sure they send "keep-alive" moves to the Bloomberg Any terminal, because it locks out after 60 minutes. So, the attacker could keep the terminal always active and unlocked, and have unlimited access until the victim was away andor asleep.
