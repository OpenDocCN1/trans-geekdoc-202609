# Brute-Force Attack Methods

There are two main ways to conduct brute-force attacks: manual and automated.

# Manual

Manual brute-force guessing is a human being taking guesses at one time. For example, perhaps you have to guess a four-digit PIN. Human can sit there and try four-digit combination after four-digit combination. Manual, human-based guessing has a benefit that any known information about the victim, such as their birthday, their children's birthdays, favorite numbers, or anyone previously used PINs can be used to try to figure out the correct PIN than brute-force guessing alone.

The biggest problem with human-based, manual guessing is that in a short amount of time a limited number of guesses most humans remember what combinations they already tried and what combinations did not. After a few dozens, the average human attacker is likely to start making duplicate guesses using previous values without realizing it. Computer-based, automated tools are great at guessing really fast and in keeping track of what was previously tried that did not work so they won't waste time trying them again.
