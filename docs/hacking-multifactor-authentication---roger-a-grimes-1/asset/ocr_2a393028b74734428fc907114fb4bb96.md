# Who This Book Is For

This book is primarily aimed at anyone who is in charge of or managing their organization's computer security and, in particular, logon authentication. It is for anyone who is considering, buying, or using multifactor authentication for the first or the tenth time. It is for developers and vendors who make multifactor authentication solutions. Prior to this book there has not a single place where anyone, customer or vendor, could go learn about all the common ways multifactor authentication can be hacked. Now there is that source, although I'm sure I haven't covered every hacking method, defense, and caveat. But I tried.

It is mostly for the people who have heard the great promises that multifactor authentication will give and somehow equate those with a larger falsehood, that using MFA "I can't get hacked! Nothing could be further from the truth. This book is your counter anyone tries to convince you that using MFA you don't have to worry about hacking anyone. That isn't and will never be true.

It also dispels the naive notion that we really want 100 percent security. We don't. Society wants a solution that impacts the least and provides "Just OK protection." It is a hard reality that both administrators and developers learn in the marketplace of computer security products. Some of the best, really secure computer products never get purchased by more than a few companies, and end up on the heap of unused products.

In this, book reminds us of the famous quote given by John Nicholson's character, Colonel Nathan Jessup, in the 1992 movie A Few Good Men "You can't handle the truth! You may not like to hear that we don't want the best security, but ignore what the user want at your peril. So, the purpose of this book is not only about developers and customers learning all the ways to hack MFA, but also about when layered security is just too much security.
