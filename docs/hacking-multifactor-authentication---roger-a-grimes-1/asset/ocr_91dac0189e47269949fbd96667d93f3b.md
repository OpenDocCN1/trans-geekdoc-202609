# Chapter 18 DNS Hijacking

12. The authoritative DNS server returns the requested IP address, the original querying DNS server then returns to the original requesting client (to any intermediate DNS servers still involved in answering the query).

> NOTE This is a simple explanation of a common type of DNS query, and in real life the query may be far more complex.

All of this happens in a few seconds or less. The user types a hostname, and fairly quickly their application is redirected to the right computer or site around the world. It is quite amazing when you think about.

All the servers below the TLD servers will cache the DNS entry they were involved in for a set of period of time limited to the shortest of the maximum DNS cache allowed by the service or attached to the DNS query answer (which usually has a preconfigured cache timeout value as well). Cached answers are always faster than if the DNS service has to execute additional DNS queries and answers. Figure 18.1 gives a graphical example of our theoretical DNS query.
