# Comparison

When requested, comparisons are made between the newly acquired traits and the stored biometric traits. Comparisons are done during initial enrollment, to make sure the new acquisition doesn't match an existing store, different subject, and during subsequent authentications.

It is always done using data analysis and is not a direct comparison of acquired optical images or sound. For example, when two faces are compared it doesn't done image as a human would analyze it. Instead, it's done using data points and measurements of the new candidate image of the same data points.

Another good is fingerprints. The actual fingerprints, even if stored and available for later retrieval, are not used in the comparison. Collected fingerprints are specific points where the friction ridges begin end, along with identified shapes and artifacts. Structured fingerprints more like a star constellation (e.g., Orion's belt or the Big Dipper) than a picture of a fingerprint. The more points are compared and found to be the same, the more accurate the fingerprint match will likely be. Unfortunately, it is not always possible to collect all that the fingerprint recognition system would collect during acquisition, because people are always placing differing areas of varying points during each fingerprint submission. Why many initial fingerprint collections will ask the submitter to press their fingerprint several different times in different ways—collect as many different data points as they can to better represent the overall fingerprint. A fingerprint collection system is essentially comparing “star constellations” looking for partial overlapping matches where different data points match.

# Authentication

If requested, the system will make a determination of whether someone is authenticated on the preponderance of evidence over the various data points. If successfully authenticated, a person will be allowed to access the protected system or resource. If accessing a digital access control system, as used in an operating system or web, the authenticated user will be assigned an access control token, as you learned in Chapter 6, "Access Control Tokens."
