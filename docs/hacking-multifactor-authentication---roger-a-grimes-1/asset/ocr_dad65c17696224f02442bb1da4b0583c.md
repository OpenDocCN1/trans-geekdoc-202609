The first computers used the ASCII character set. It could only support 128 English characters. The first 32 ASCII characters are "control characters" like line feed and end-of-text delimiters. The rest cover uppercase and lowercase English letters, the 10 numbers, and common symbols you find on your keyboard like !@#$%^&*. But a limit of 128 characters is a bit restrictive for non-English speakers.

Early on, Windows used what is known as the American Standards Institute (ANSI) character set. It supported only 218 characters, which was better than 128-character ASCII, but it wasn't built to handle more complex languages like Cyrillic and Chinese. With Windows 2000, Microsoft began to use Unicode. Unicode represents every known language, ancient and ancient, and it can represent millions of different characters.

Since 2009, the World Wide Web (essentially the Internet) uses a character set as UTF-8 (Unicode Transformation 8-bit). It's a subset of over 1 million characters. Consequently, most of the world, including DNS (which officially only uses ASCII), actually uses UTF-8. When you type a character into your browser, behind the scenes the computer is dealing with the typed in character as its Unicode number. It's the way the web and web work work the scenes.

Many websites and applications support of UTF-8 with what is known as Punycode (en.wikipedia.org/wiki/Punycode). Punycode is a Unicode version for hostnames.

You may also see IDN (internationalized domain names; en.wikipedia.org/wiki/Internationalized_domain_), which is a method for converting and displaying domain names between languages using Punycode and IDN characters

Hackers use Punycode and IDN characters to look like other characters to create-alike domain names. These types of attacks are known as homograph attacks (en.wikipedia.org/wiki/IDN_homograph_attack). They not only fool users but get beyond by expensive defenses. For example, the Unicode Latin "a" (U+0061) and Cyrillic "а" (U+0430) may look the same in a browser but all different characters are represented in different. Any DNS address containing one versus the other can point to different IP addresses, even though they look the same when sent in an email or displayed in a browser.
