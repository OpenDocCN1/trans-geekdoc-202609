Behind the scenes of the Internet, if not hundreds of billions, of API calls are made every day between various services. Without hyperbolic, it is the way Internet works at a programming level. A common programmer says “If you have to do it more than once, automate it.” APIs allow interlacing and automation.

Many of today's protocols and APIs use Extended Markup Language (XML) to communicate messages, formats, and data between two communicating parties. XML was designed to work and be familiar to programmers who used XML, because each line of data is encompassed between "opening" <section> and "closing" </section>. This makes that using XML both human and machine-readable if the programmer chooses not to encode the enclosed information further. You can read more about XML here: en.wikipedia.org/wiki/XML.
