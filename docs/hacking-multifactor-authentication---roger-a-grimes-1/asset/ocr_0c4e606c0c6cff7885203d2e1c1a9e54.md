# Abusing Master Codes

MFA services understand that users doesn't always have access to the primary, default MFA solution, but they still want users to be able to access the protected service. Many of these services offer permanent, non-expiring, “master,” “backup,” or “travel codes. These codes can be set up when the MFA solution is first established and can be generated any time thereafter, as as when the user knows they are going on vacation.

Google calls them backup codes (see Figure 13.4). When you enable them, Google displays ten 8-digit backup codes, which you can screenshot, download, or print. Microsoft calls them “recovery codes” and generates one at a time (see Figure 13.5).
