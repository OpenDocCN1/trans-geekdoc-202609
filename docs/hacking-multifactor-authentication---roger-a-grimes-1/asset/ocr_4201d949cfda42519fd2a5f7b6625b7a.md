# Hacking Multifactor Authentication

NOTE If you use a lot of passwords and don't use a password manager (which I'll discuss in a moment), never write your complete password in any document, password-protected or not, where a hacker could view it or steal it. Instead, write passwords using simple shorthand codes that you know. For example, if your password is FrogFB and FrogrogTW33 for Facebook, only write down FFB and FTW33. If you never write your complete password anywhere, no one can easily steal it. Of course, that means you have to remember your shorthand codes stood for. Remember that it's best to avoid easy-to-recognize patterns.

# PINS

PINs are essentially KBA passwords, usually composed only of numerals (although they can contain additional types of character sets). They are most commonly used with building entry and exit control systems, smartcards, ATM/banking cards, credit cards, cell phones, and other portable computers. The average PIN is only up to six characters.

Because PINs are short and consist of fewer characters than a password, PIN authentication typically have strict 'lockout' policies, where too many incorrect PIN attempts invalidate the PIN or device to be used. Some devices accepting PINs, like a Windows PC with an enabled Trusted Platform Module (TPM) chip, will not completely lock out account after bad PIN attempts but will instead make the user wait longer and between attempts. After more than a few bad PIN attempts, each bad attempt can have the subject several minutes before being allowed to try again. This is known as login/login throttling. Other devices may 'brick' the device, meaning the device is rendered inactive until an administrator or technician resets it.

On the good side, PINs are easy to remember and use. It's good for people who are easily guess and hack. PINs are easy for people to 'shoulder surfing' when using hidden cameras and/or more easy figuring out when we 'wear patterns'.

A reasonable person could easily assume that the PIN includes those numbers in one combination or another, and that submitting it requires a #keypress at the end of the sequence. Without repeating characters, if the PIN is only four characters, there are only 24 (4! = 24) possible solutions; if the PIN is five characters, there are only 120 (5! = 120) possible solutions.

Note: The "!" mathematical symbol stands for all numbers multiplied against each other. For example, 5! = 5 x 4 x 3 x 2 x 1 = 120.
