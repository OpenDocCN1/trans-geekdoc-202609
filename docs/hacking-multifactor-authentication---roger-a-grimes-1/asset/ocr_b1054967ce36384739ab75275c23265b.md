# Encryption

Encryption is a popular method for subjects to keep something secret. Using encryption, plaintext content is rearranged to create a coded message that the intended parties can later decode to understand. The process used to reverse an encrypted message back to its original, plaintext form is called decryption. The documented process and steps used to encrypt or decrypt a message are referred loosely as a cipher, or a cipher algorithm, which is usually represented mathematically. A single subject may want to keep secret to themselves, or the secret may be shared between a selected group of people or devices. The secret can be any type of content, including the identities of participating parties and any involved transactions and objects.

# Key

Every ciphers the plaintext content using a series of previously agreed-upon characters or symbols as the key. In the classical world, digital encryption keys are a long series of seemingly randomly generated ones. A digital key looks something like 101010101011100101010101, varying by composition and length. The key is applied to the plaintext message in a series of steps described by the mathematics of the cipher to create the encrypted message. The key must be kept secret to keep the encrypted text known only to the participating subjects.

If done correctly, both the key and the encrypted message usually range in size from 128 to 4,096 bits, although they can be smaller or larger in complex scenarios. Whether a particular length of bits is considered secure depends on many factors, including the cipher algorithm, the speed at which all the key bit positions (the key space) can be guessed, and any “tricks” that can be used to cut down the brute-force guessing methods. String algorithms that are harder to “crack” can use smaller key sizes, whereas conversely, weaker algorithms often require longer key sizes for equal protection. Bit lengths for new keys using the same algorithms to grow over time to compensate for greater computational power and cracking factors. Cryptographic attacks only get better over time, which weakens the protective power provided by the length of the key.
