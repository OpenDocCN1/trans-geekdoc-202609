# Chapter 6 Access Control Tokens Tricks

# Network Session Hijacking Techniques and Examples

As I shared earlier, it's easier to steal the legitimately accessed control token than it is to reproduce or guess it. Tokens can be stolen and reused locally or from over a network. Session hijacking over a network is a popular attack against MFA solutions and one that we will explore in more detail here.

Network session hijacking requires that the attacker intercept the access control token somewhere between the client and server. In the earlier days of networking, most networks used shared media as Ethernet. Ethernet networks can be wired or wireless. A pure Ethernet network cannot listen to the traffic between any others on the same local network. No switching. Normally, an Ethernet node simply ignores or discards any packet on the same network that does not directly involve it (or is a broadcast) because it doesn't involve them. Eavesdropping Ethernet devices, maliciously or otherwise, don't discard that information. Instead, they read every packet that passes through their interface. So, in the early days, without any additional network security protections, it was easy for any participating network to listen and even maliciously manipulate others' network traffic.

# Firesheep

For at least two decades, the world has been full of legitimate and malicious tools that "listen" to other node's traffic. If that contained an unprotected access control token from another node, as was often the case, the malicious listener could intercept and copy it. There were dozens of hacking tools that focus on stealing other's access control tokens of shared media networks.

One of the most popular tools, focusing mostly on website cookies, is Firesheep(en.wikipedia/Firesheep). Released in 2010, it was a browser extension that was installed on a popular Internet browser Mozilla Firefox. It took the world by storm because it showed how easy access control theft was.

To use Firesheep, you enabled it in the Firefox program and it would immediately listen for and collect many unprotected access tokens as it could. Then all you had to double click one of the collected tokens, as represented in the program, and it would immediately log you in as the person it was collected from. It was simple.

It was stunning to see if you were not already aware of how easy access control theft was to accomplish. Many testers use coffeeshops, airports, and other areas where lots of people were using shared public networks, and steal as many access control tokens as possible. It was a great way to woo your friends and make them think you were some great hacker. The technique was frequently used by corporate security employees to show senior management how easy network session hijacking was accomplish. It dropped and opened pockets.
