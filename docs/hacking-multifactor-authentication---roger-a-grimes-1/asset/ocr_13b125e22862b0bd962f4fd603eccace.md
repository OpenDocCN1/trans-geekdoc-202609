# Hacking Multifactor Authentication

Dozens of free and commercial tools exist that allow anyone, including hackers, not to look up inclusions of people's login names and passwords in the various password dumps, but also to readily return the associated password in plaintext. When a malicious hacker wants to attack a target, they can just pull one of their favorite hacking open source intelligence (OSINT) tools to use in a name or domain URL, and the tool will do the searching and return everything it finds. One popular OSINT tool for researching password databases is recon-ng (see Figure 1.3).

![](bbox=[0.09, 0.25, 0.57, 0.43])

```
recon-domains/credsentials/pwnedlist/account_creds
recon-domains/credsentials/pwnedlist/api usage
recon-domains/credsentials/pwnedlist/domain creds
recon-domains/credsentials/pwnedlist/domain ispwned
recon-domains/credsentials/pwnedlist/leak lookup
recon-domains/credsentials/pwnedlist/leaks dump
recon-contacts/hibp breach
recon-contacts/hibp paste
```

+   1] Recon modules

**Figure 1.3:** The recon-ng OSINT tool, which contains modules for doing mass searches of password dump databases

The recon-ng OSINT tool is one of the most popular tools for researching password data- but there are dozens. One great central collection of OSINT tools is Awesome OSINT (github.com/jivoal/awesome-osint), see Figure 1.4. It contains more than one hundred OSINT tools, including many that search for passwords.

In summary, there are billions of people's passwords out on the Internet, possibly yours, and finding and using them just isn't that. This is one of the problems with using pass- words for authentication. We will cover several more in the section "Password Problems and Attacks," later in this chapter.

> **NOTE** My advice is to use these password checking tools to see if you or your organization's login name and passwords are out on the Internet or dark web. Don t let hackers be the only ones checking. If you find any compromised account, the associated users change their compromised passwords unless they know for sure that the passwords they are using are not the same ones at the time of the compromised.
