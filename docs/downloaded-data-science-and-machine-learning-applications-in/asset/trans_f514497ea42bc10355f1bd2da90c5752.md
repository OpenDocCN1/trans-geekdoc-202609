## 4.2 支持向量机（SVM）

支持向量机的概念最早于20世纪60年代初提出，但直到20世纪90年代，其应用才变得流行，因为它在分类问题上能够超越人工神经网络方法（Zendehboudi 等，2018）。SVM是带有核函数的机器学习算法，用于回归（SVR；图10.5a）和分类（SVC；图10.5b）分析，如图10.5所示。SVM已广泛应用于回归、分类和预测等各种任务。SVM的主要优点之一是能够处理含噪声数据和高维数据（Furey 等，2000）。此外，最简单的SVM结构能够对两个线性可分的类别集进行分类，其考虑的是与两个类别距离最大化的线性超平面。

考虑一个二维空间类别（类别1和2）的分类SVM，它可以作为线性分类来处理，如图10.5b所示。假设有n个输入数据，表示为 a = {a1, a2, ..., an}，以及一个介于−1和+1之间的标签变量yn，该变量有助于对输入变量进行分类。在这种情况下，当yn = +1时，第i个输入可归入类别1；当yn = −1时，归入类别2。给定一个垂直于决策边界的向量w（如图所示），决策函数可以表示为：

$c(a,w,e)=w\cdot a+e=\sum_{i=1}^{n} w_i a_i + e$ (10.10)

其中c是决策函数，a表示输入向量，w表示垂直于分割线的向量，e为偏置。

图10.5 SVM架构，显示了：（a）高维空间中的回归SVM/RVM；（b）监督支持向量利用最优超平面在两个非线性数据之间建立线性关系。

SVM分类问题对应最大化两个类别之间的间隔（Zendehboudi 等，2018）。为了帮助最小化这个问题，引入拉格朗日乘子（α_i ≥ 0），将有约束问题转化为无约束问题。此外，当类别无法通过线性超平面线性分离时，SVM可以利用核中的Sigmoid、多项式和径向基函数等变换，对高维空间中的任何给定输入进行分类（Zendehboudi 等，2018）。考虑到核函数，将向量x_i和x_j引入目标函数。由于优化依赖于样本向量的点积，到特征空间的转换可以简化为寻找核函数K(x_i, x_j)。目标函数的数学表达式可以表示为：

```
G = \sum_{i=1}^n \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n y_i \alpha_i K(x_i, x_j) y_j \alpha_j 
(10.11)
```

### 4.2.1 机器学习（ML）在岩石物理储层预测中的应用

Al-Anazi 和 Gate（2012）利用SVM分析了有限测井数据比例对非均质砂岩储层中Phi和K预测的贡献。为了验证，将SVM的支持向量回归（SVR）与多层感知器（MLP）神经网络进行了对比，结果表明SVR优于MLP。

Wong 等人（2005）还使用高斯径向基激活函数SVM预测了澳大利亚西部近海非均质储层的Phi。该模型没有定义权衡参数管理的复杂度与观测误差之间的相对平衡，以最小化处理时间。作者将该模型与BPNN进行了比较，验证了其结果，确立了SVM作为表征非均质储层的替代性监督ML范式的优势。

Gholami 等人（2012）也进行了一项对比研究，使用SVM和GRNN预测南帕尔斯气田气井的K。他们采用独立成分分析（ICA）来选择相关测井数据。结果显示，岩心渗透率与预测渗透率之间具有良好的相关性，相关系数为0.97。此外，将SVM与GRNN的结果进行比较，SVM比GRNN更快、更准确地实现了油气储层渗透率预测。正如 Asante-Okyere 等人（2020b）所报道，SVM在岩石物理性质领域表现出更优的性能。表10.3列出了SVM在岩石物理性质预测领域的应用。
