# 3.4 GMDH Modelling

In building the GMDH model, the most influential input parameters are usually automatically selected that have an influence on the target variable. Three input variables that have the most influence on the target are CLSWI, OCP, and LSWIR. The number of layers and neurons used are 2 and 2, respectively, for GMDH model computations. The final architecture obtained was after a series of optimisation processes by observing the network performance.
