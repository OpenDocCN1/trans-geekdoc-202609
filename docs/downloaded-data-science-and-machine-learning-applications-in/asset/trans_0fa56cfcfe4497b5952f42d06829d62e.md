## 5.4 使用Shapley值模型无关度量的特征分析

使用所有特征训练极端随机树（Extra Trees）模型来进行井漏预测，并使用了与PFI分析相同的训练和测试数据集。由于机器学习模型应具有可解释性，以帮助理解模型如何进行特定预测，因此模型无关度量很有帮助。Shapley值起源于博弈论，有必要阐明其在监督机器学习可解释性中的应用。博弈代表数据集中特定事件的预测分配。收益是特定实例的实际预测与所有实例的平均预测之间的差值。该实例的特征值协同作用，以实现井漏预测中的收益。

图2.9以特征重要性图的形式将Shapley值可视化为绝对值。SHAP特征重要性遵循一个简单的原理：绝对值高的特征是最重要的特征。计算每个属性在整个数据中Shapley值的绝对平均值，以评估全局重要性。泵压和流量特征变量非常重要，其中泵压最为重要，在x轴上平均使目标变量改变56.35桶/小时。该图还显示，进尺、钻进时间和钻压与目标变量的相关性较低，其中纳入钻压与PFI结果不一致。基于这一结果，需要进一步调查以确定哪些特征与目标变量无关。Shapley值重要性是排列特征重要性的一种替代方法。这两种重要性度量存在显著差异。模型性能的下降决定了排列特征的相关性，而Shapley值主要基于特征来源的幅度。特征重要性图信息丰富，但在显著性之外没有提供其他信息。蜂群图（bee swarm plot）是一种信息更丰富的图，被用于分析。

![](img/80b94770dd572ad559c67fa9921bb887_40_0.png)

图2.9 SHAP特征重要性，以平均绝对Shapley值度量。

图2.10和图2.11分别将训练数据和测试数据的Shapley值以绝对值形式可视化为蜂群汇总图。y轴由特征决定，x轴由Shapley值决定。具有特征效应的特征重要性被组合成全局解释，从而为每个实例获得Shapley值特征矩阵。在汇总图中，可以识别出特征值与对目标影响之间正负关系的初步迹象。由所有训练数据点组成的数据点在y轴上以散乱方式重叠。这种可视化方式描绘了每个特征的Shapley值分布。特征按重要性降序排列。从图中可以看出，低特征值用蓝色表示，高特征值用红色表示。在分析泵压的影响时，可以观察到低值预测高井漏值，而高值预测低井漏值。泵压数据点的分布也表明了一种解释整个模型行为的全局解释。该分析证实，这种相关性本身不能称为因果关系。这一结论强调了模型无关技术在理解其他特征在井漏预测中的影响方面的重要性和必要性。从蜂群图可以观察到，大约12个特征可以在全局层面解释预测是如何做出的。

蜂群图的结果证实了那些在训练和测试结果中都具有高重要性，并在Shapley值中体现其重要性的特征。

Shapley值基于博弈论坚实的理论基础，并计算合理分配给目标变量的特征值。该方法也有助于统一可解释机器学习。其快速计算能力允许计算全局模型解释所需的多个Shapley值。由于Shapley值代表了全局解释的最小元素，这使得全局解释与局部解释兼容。

## 5.6 模型优化

采用贝叶斯优化（BO）算法对模型参数进行调优，以提高模型性能。图2.12中的结果显示了使用Shapley值识别出的前13个特征的极端随机树模型以及BO–ET模型的性能。将结果与Sabah等人（2021）的结果进行了比较。这一比较是必要的，因为该作者使用了与本研究相同的数据，但在预测钻井液漏失时采用了不同的技术和模型。值得一提的是，尽管机器学习模型依赖于所使用的数据，但本研究中用于训练模型的大部分数据可能与其他研究不完全相似。然而，预计大部分数据将是相同的。因此，这种比较主要基于输入特征的使用方式及其对目标变量的解释，而非贬低其他研究者的结果。

### 误差分析

![](img/80b94770dd572ad559c67fa9921bb887_43_0.png)

图2.12 基于RMSE和MAE比较表现最佳模型与Sabah等人（2021）模型的估计误差。

通过所进行的误差分析，观察到基于Shapley值选择的特征显著降低了模型误差。初始极端随机树模型的平均绝对误差（MAE）为12.6桶/小时，而基于Shapley值选择特征的MAE为0.3桶/小时。这一结果意味着MAE降低了约97%。

同样，使用全部16个特征的极端随机树模型的RMSE为24.0桶/小时。基于Shapley值选择特征的RMSE记录为1.4桶/小时。这同样意味着该误差指标降低了约94%。通过超参数调优，BO–ET能够将极端随机树的平均绝对误差（MAE）和均方根误差（RMSE）分别降低到0.2和1.2桶/小时。极端随机树模型的优越性主要归因于构建该模型所用的偏差-方差概念，这使其对异常值具有鲁棒性。基于所有评估标准，可以确定Shapley值选择的特征高度相关，能够对目标变量进行全局泛化，并提高模型效率。

## 5.7 敏感性分析

图2.13显示了估计井漏数据与实际井漏数据的核密度估计（KDE）。估计值用蓝色表示，实际值用绿色表示。根据测试数据，BO–ET与真实数据更为接近。这一研究表明，BO–ET能够比其他模型捕获更广泛的值范围。这一观察结果使其适合用于利用相关钻井参数评估其他井的钻井液漏失情况。因此，敏感性分析验证了上述评估指标。
