# 3.2 Input and Target Dataset

A simulation study was carried out to obtain a simulation dataset for input and output for training and testing to establish a mapping relationship. Table 7.2 shows the reservoir parameters that were used in running the carbonate simulation model. Additionally, Table 7.3 shows the initial run whose result was used as the base case for the sensitivity run for varied low salinity water ranges between 200–3000 ppm. The total dataset obtained within the low salinity water ranges was 1385 sample points, with 1,107 used for training and the rest used for testing the model. Furthermore, Fig. 7.4a shows the average pressure for the base case and CO₂-LSWAG scenarios.
