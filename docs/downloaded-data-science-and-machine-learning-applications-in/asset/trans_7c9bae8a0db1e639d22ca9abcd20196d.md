## 5. 岩性与岩相分析

许多学者（如Meshri，1986；Pettijohn，1983；Yu，2008）都对沉积环境及其非均质性（表10.4）进行了研究，但Qiu（2000）除外。这些作者认为，沉积环境及其非均质性的比较可以通过研究其岩相来进行最佳分类。在20世纪90年代初，Walker和James（1992）强调，岩相分析在研究盆地充填时至关重要。岩性与岩相分析有助于将储层岩石序列细分为相应的岩石地层单元，从而帮助绘制沉积区域之间的图件、进行对比并分析其物源。由于岩相建模的复杂性，Tang（2008）概述了岩相建模的两种基本方法：利用经验方程（如Archie方程）、多元统计和神经网络。近年来，后者受到了更多关注，一些研究人员使用多元统计和神经网络进行岩相建模（如Bestagini等，2017；Miller等，2019；Tran，2020）和岩性识别（如Al-Anazi和Gates，2010；Al-Mudhafar，2017a；Alzubaidi等，2021）。

### 5.1 人工智能在岩性与岩相分析中的应用

Rafiq等（2016）提出了微地震岩相分析的概念，该概念能够将偏心储层分割为离散的岩相，以响应微地震，并结合微地震与三维地震数据的联合解释。该方法最初由Eaton等（2014）提出，并已被作者们加以改进。他们的发现与三维地震数据中的主要弯曲不规则性相关。通过将微地震岩相分析与从测井和岩心数据中获取的裂缝相结合，作者们划分了储层段，标记了构造和沉积趋势。De Matos等（2007）提出了两种新的半自动替代方法用于地震岩相分析。他们使用Kohonen自组织映射（SOM）聚类作为一种先进的方法来绘制地震岩相图、评估其数量，并借助小波变换算法选择每个定向地质段中的地震道特征。为了验证他们的结果，两种方法都被使用，并利用了巴西近海Campos盆地Namorado深水油田的合成和真实地震数据。对于多个地震数据集，结果证实了SOM聚类具有良好的预测效果。结果还表明，通过利用小波变换技术所注意到的地震道特征，地震岩相分析得到了改进。Avseth和Mukerji（2002）将电缆测井数据整合到地震岩相分类中。该研究的输入数据包括GR、RHOB、地震速度和阻抗。岩相
