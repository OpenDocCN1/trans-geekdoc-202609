
就精度而言的横波声波测井。评估标准表明了模型拟合留出数据的可能性。模型的准确性、精确性和可靠性进一步通过留出数据上的MAE、MAPE、RMSE和R²进行评估。研究结果概述如下：

-   1. 对输入数据进行了充分论证，以理解其对声波速度的影响。
-   2. Extra-Trees模型在精度、稳健性和拟合概率方面优于随机森林和决策树模型。
-   3. BO算法对Extra-Trees模型的精度产生了虽微小但有意义的改进。
-   4. 在多输出回归预测中，砂岩层段的预测Vs（横波速度）在测试数据上表现出最高的误差。
-   5. 砂岩层段的误差源于储层中不同地层流体的影响。通过使用来自井A和井B的所有数据重新训练模型，该误差得以最小化。
-   6. 将模型部署到井C后，预测的Vs和Vp与三种不同地层类型中不同流体饱和度的影响相匹配。

所提出的方法为地热、流体封存和油气行业提供了一种更便宜、更省时的替代方案，无需在每口已钻探的井中运行声波测井工具。它还提供了一种在先前未测量Vs和Vp的旧井中测量这些参数的方法。
