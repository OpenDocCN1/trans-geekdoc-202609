# 前言

问候，受启发的机器学习荣耀读者。

当我于 2021 年初开始这项事业时，几乎每个人似乎都在写 Substack。作为一个平台，Substack 迅速增长，一度占据了公众视野的几个焦点时刻。目前只有少数 Substack 作者仍能从人群中脱颖而出。像所有拥有社区的时事通讯或写作项目一样，受众决定了持续成功的成败。这系列每周文章被汇编成了一部手稿。每篇文章都经过编辑，从原始形式转变为更适合出版的格式。Substack 作为一个平台，提供了极大的自由度来包含链接和嵌入式内容，但这些无法转化为书面页面。

我注意到的一件事是，前几篇文章比系列末尾的文章长得多。看来当我开始笼统谈论机器学习时，我想表达的相关内容要多得多。鉴于每周的文章都是为独立阅读而写，我的所有参考资料都以直观的脚注方式处理。任何旁注、链接或对其他作者的致谢都发生在章节末尾的脚注中。

这个高度技术驱动的领域变化迅速。我包含了出版日期作为参考坐标。

# Substack 第 1 周：机器学习投资回报率

发布于 2021 年 1 月 29 日

在机器学习工作上要具有战略眼光。

> 要
> 具
> 战
> 略
> 眼
> 光

认真说，这七个字（原文七个单词）应指引你在机器学习旅程中的下一步。请花一点时间，让这个方向（强有力的指引）沉淀下来，并反思它对你的组织真正意味着什么。你必须花一点时间，从为组织构建战略价值倒推，回到你正在开展的实际机器学习工作中。在这项工作内部，你会迅速发现，要将机器学习工作投入运营以产生战略价值，将依赖于一份可靠的投资回报率（ROI）计划。确保你从一开始就以此为终极目标，以增加成功的几率。在不了解潜在投资回报率或潜在损失的情况下，在任何类型的组织内采取机器学习所能实现规模的行动，是极其可疑的。这就是为什么你必须从头到尾在机器学习工作上保持战略性。
