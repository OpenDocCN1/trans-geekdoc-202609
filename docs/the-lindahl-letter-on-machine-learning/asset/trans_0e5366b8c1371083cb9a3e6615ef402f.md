
# 使用 API 服务支持机器学习用例可带来诸多益处

大多数此类 API 过去已支持并将继续支持多种不同的工作。这意味着，尽管模型交付并非针对您的特定用例进行专门定制，但其已通过时间的验证。您可以节省模型训练和持续维护的所有成本。如果您经营的是一家小公司，还能获得在真实工作条件下利用所有其他数据来调整和奠定模型基础的益处。这些 API 服务不会高度专业化，采用这种方式启动机器学习用例时，您基本上是“拿来即用”。成本按单位或在大多数情况下按使用批次计算，具有可预测性。这意味着您必须预测每月将调用 API 的次数，以预估成本并维持您的 ROI 模型。

## 类别 2：“您可以所在之地”，或您可在其中拓展业务版图的生态系统

云端的成本预测计算器优劣不一。当您开始在云端拓展业务版图时，计算和存储资源将开始联合发力，给您的组织带来成本。随着数据量增加和针对这些数据运行的计算资源增多，您的成本模型将发生变化。本段前几句话虽未提及机器学习，但包含了对其的考量。您需要处理、流水线传输、转换、修改数据或用于训练模型的数据总量，都将在您的云版图中引入成本。有人可能因对云端训练数据过于兴奋，而租用大量酷炫硬件以加速进程。这在当时对他们而言可能看似是云端的绝佳用法；但最终可能代价高昂。或许短期爆发式地投入以启动并将机器学习用案和模型部署到生产环境是值得的。在这种情况下，整个训练设置需尽快关闭以控制成本。若保持开启，训练将持续增加成本。您会发现云端可提供一些非常强大的专用硬件用于机器学习工作。其中部分定价比其他部分更合理。

## 类别 3：“自行构建”，如开源和自研工具解决方案

视您的设置而定，此类别可能不产生任何显著的云成本。许多初创公司和其他组织可能在小型物理机或机架上进行训练。当您自行构建时，只需核算硬件成本及任何其他相关成本，如托管位置、备份方式、电力和网络。

# Substack 第 17 周：评估机器学习就绪度

发布于 2021 年 5 月 21 日

踏上机器学习之旅的初期，往往充满趣味与激动。人们可能试图向您推销各种事物的益处。您可以在学术文献中找到关于生产环境机器学习就绪度的解读和清单 [1]。存在大量清单和其他评估标准。我在任何机器学习旅程伊始首先质疑的，恰巧是公司处理的基本用例。您需要从一些草稿式的勾勒开始，明确公司究竟试图做什么或实际上正在做什么。也许他们在销售产品或提供某种服务。在获得该初步勾勒后，下一个问题关乎您的数据存储、KPI 和客观指标。我在脑海中勾勒公司试图实现的用例，以及他们如何报告和监控该用例。这两者之间，正是您的机器学习就绪度将展现之处。也许通过与 `AWS`、`GCP` 或 `Azure` 进行简单的 API 集成，就能在不投入大量精力的情况下启动。这完全可能是答案，且启动过程可能非常迅速。

除了针对机器学习领域用例的基本 API 驱动集成外，您将开始打开通往一些有趣且极佳的高度专业化和定制化工作的大门。这也是难度开始增加之处，您的数据可用性将决定机器学习就绪度。利用内部工具自行构建或遵循某种模式构建，最终将演变为数据探索，随后进行 `MLOps` 规划。

将评估机器学习就绪度的工作浓缩为以下五个入手问题：

1.  您究竟试图做什么？（用例问题）
2.  您如何收集和存储数据？
3.  您的用例与数据收集/存储是否对齐？
4.  您应与供应商合作，还是已准备好在内部推动此事？
5.  您是否考虑过 ROI、KPI 综合指标以及所需的预算级投入？

# Substack 第 18 周：机器学习能预测彩票吗？

发布于 2021 年 5 月 28 日

上周在 DATAx 大会的 Argyle Digital 专题讨论会 “语言艺术——打造推进 NLP 的有效技巧” 中发言，我度过了愉快的时光。您可通过此链接免费观看专题讨论会视频：`https://twitter.com/nelslindahl/status/1395842590256160772`

视频亦可在此查看：`https://vimeo.com/553105304`

机器学习能预测彩票吗？尝试预测彩票并非新尝试。人们已从多种角度考量过此问题。您可在 Google 搜索该问题，结果颇有意思。我最终观看了 Raj Ramesh 于 2018 年在 YouTube 发布的一个视频 [1]。我接下来的搜索方向是寻找相关学术成果。这包括在 Google Scholar 快速浏览几圈，然后前往 ArXiv 查看是否有预印本 [2]。确实存在一些研究，似乎围绕一个称为 “彩票假设” 的概念。这些研究无法帮助您利用机器学习或人工智能预测彩票。它们实际上似乎在解释为何过拟合引入的运气成分虽有趣但存在问题。

许多人（引用量达 349 次）喜欢引用 MIT CSAIL 的 Jonathan Frankle 和 Michael Carbin 的一篇论文，题为 “The Lottery Ticket Hypothesis: Finding Sparse, Trainable Neural Networks”（彩票假设：寻找稀疏可训练神经网络），该论文于 2018 年提交预印本，并于 2019 年国际学习表征会议论文集正式发表 [3]。摘要指出：“我们阐述了彩票假设：稠密、随机初始化的前馈网络包含子网络（中奖彩票），这些子网络在单独训练时，能在相似的迭代次数内达到与原网络相当的测试准确率。我们找到的中奖彩票赢得了初始化彩票：它们的连接拥有使训练特别有效的初始权重。”

这究竟告诉我们机器学习如何预测彩票？
