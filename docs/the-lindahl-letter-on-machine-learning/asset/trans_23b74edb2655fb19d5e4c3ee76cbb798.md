# Substack 第 5 周：让 ROI 驱动基于事实的决策过程

**发布于 2021 年 2 月 26 日**

企业中机器学习的用例比比皆是。基于跨众多不同企业利用的海量用例，许多步骤和流程都是可定义且可重复的 [1]。你必须开始理清这些用例如何实现运营化。在这个过程中，正是让 ROI 引导你进行基于事实的决策的最佳时机。进入这种良性循环，关键在于启用已定义且可重复的流程，以满足组织机器学习战略声明所需的方式部署机器学习。一个战略声明可以简单到“在工作流的支付环节之前，始终提供机器学习驱动的替代购买推荐”。你可以开始从该战略出发，正向和反向双向推进。为实现该战略列出预算项会相当容易。这也是推荐引擎基于相当标准化的模型提供替代方案的一个著名用例。

实现基于事实意味着让数据驱动你的决策过程。你可以获取一份当前现存的、常用的机器学习常见用例清单。基于这些常见用例，你应该能够快速将它们与你的工作流关联起来，并开始就将机器学习应用于工作流所需的成本进行一些 ROI 分析。一般来说，从 `GCP`、`Azure` 或 `AWS` 使用机器学习 API 的启动时间非常短 [2]。构建自己的基础设施并设置好通过流水线机器学习设置将其连接到工作流以服务训练好的机器学习模型，则需要更长的时间。你也无法获得那些公司在其 API 设置上进行的规模化、调优和投资带来的优势。然而，如果你需要偏离模型设计初衷所解决的用例性质，通用 API 并不具备针对你用例的任何定制化功能。一些用于评估机器学习成本的优秀模型已经存在 [3]。这些模型正在生产环境中实际使用，一项调查中超过一半的受访者表示他们能够证明从所做工作中获得了实际 ROI [4]。

# Substack 第 6 周：将持续成本和成功标准作为机器学习战略的一部分加以理解

**发布于 2021 年 3 月 5 日**

开始着手你的机器学习资产清单。你需要知道组织在哪里以及为什么应用了机器学习。很有可能机器学习内嵌在一路部署下来的某些事物中。说真的，你需要把这份清单建立起来。这就是战略开始成型的地方。一项针对 1,870 家组织的最新调查发现，根据 80% 受访者的说法，实际落地的机器学习战略还有很长的路要走 [1]。你可以阅读关于该调查研究的新闻稿，并在填写表格后下载它 [2]。

要了解你机器学习战略的持续成本和成功标准，你需要掌握当前正在发生的事情以及未来将要发生的事情的脉搏。我们都有有限的时间和精力去弄清事情。这是你想要从一开始就确保做对的事情。你的机器学习和人工智能战略拥有巨大的潜在上行空间，搞砸它可能会产生多年的连锁反应。有时过早入场会让做难事变得几乎不可能。目前，企业中的机器学习正从早期阶段迈向规划和部署的合理化、实证考量阶段。

网上有人公布的实际训练成本非常高昂 [3]。任何使用云系统进行训练的人，对几十万美元的成本大概率会有强烈反应。我通常的训练成本一直归因于我个人电脑系统的电费，或其他那些成本没有直接记在我的信用卡账单上的环境中。我开始阅读 Brad Cordova 在 Medium 上关于机器学习惊喜的系列文章 [4]。其中甚至引用了一篇题为“机器学习系统中的隐性技术债”的论文，让我在这个寒冷的周日早晨感到非常欣慰 [5]。
