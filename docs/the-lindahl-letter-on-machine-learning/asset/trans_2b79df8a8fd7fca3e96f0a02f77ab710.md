### 核心 ML 框架对比

先看第一个：**TensorFlow**。TensorFlow 拥有 154,162 颗星，人们确实在广泛使用它。它有 2,933 位贡献者，意味着近 3,000 人在为 TensorFlow 贡献代码。从此点来看，转到 **PyTorch**，可以看到指标大幅下降。星标数从约 154,000 降至仅 47,000。

贡献者数量也显著下降，降至约 1,785 人。在 PyTorch 示例中，它们确实有 4,620 个分支，老实说我不知道为什么要查看那么多分支。没人想管理任何事物的 4,000 个分支。在迭代方面，那是无法管理的。

我当然更理解 TensorFlow 这边的情况，但这并不意味着 **scikit-learn**（拥有约 44,000 颗星和 1,936 位贡献者）没有吸引力。由此可见，目前用于机器学习的三大主要项目绝对已被广泛采用。人们正在使用它们、为它们创建分支、制作版本，并且现在正在软件开发的广阔天地中真正深入研究它们。

## 总结

我们涵盖了什么？

好吧，我们涵盖了规模究竟是什么的初步概念，对吧？我们谈到了 Bucket 1、Bucket 2 和 Bucket 3，那些图表讲过有一阵子了，可能已经失去了含义。

- **Bucket 1 是 API**。它是你现在可以出去直接获取的东西，但你可以连接到它并开始在工作流中使用它。
- **Bucket 2 包含那些生态系统中的事物**，我们将在该生态系统中构建你的机器学习，使用它们的工具。
- **Bucket 3 将是当你处理本地构建的事物时、当你使用那些开源工具时、当你在自己的环境中构建时，究竟能发生什么的展望**。
