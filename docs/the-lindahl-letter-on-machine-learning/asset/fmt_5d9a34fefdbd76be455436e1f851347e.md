# Substack Week 43: Practical machine learning

**发布日期**: November 19, 2021

多年来，我修读了大量 Coursera 上与机器学习相关的课程 [1]。实验室和学习体验变得如此先进，令人惊叹；你可以在云端启动一个真实的环境，在那里你可以真正利用机器学习和精选数据集进行操作。这是过去五年实用机器学习蓬勃发展的方式之一 [2]。在撰写此句时，约翰霍普金斯大学的实用机器学习课程已有 141,649 人注册。了解机器学习并投入到实际用例中，最终将代表实用机器学习最小的用例。随着时间的推移，最普遍的用例将是机器学习内置于人们正在使用的产品中。Google 的开发者已将公式建议功能发布到 Google Sheets 产品中 [3]。多年来，Microsoft 的开发者一直致力于将机器学习构建到与 Office 相关的产品中。其中一些利用机器学习扩展了 Microsoft Excel [4]。你可以看看 Yannic Kilcher 发布的视频，或热门机器学习课程的学习人数。你会很快意识到，大约 10,000 人的受众会出现在许多机器学习内容中。向会议提交论文的研究人员数量和深度关注机器学习的受众，远少于 LinkedIn 上目前开放的机器学习职位数量，后者在美国的搜索结果约为 153,481 个 [5]。

除了机器学习领域的直接专业知识外，Google Sheets 或 Microsoft Excel 等产品的用户，得益于实用机器学习应用于现实场景，正在体验增强型体验。当机器学习被积极分发到电子表格世界时，应用机器学习的发生率将以远超一个数量级的指数级增长。截至 2021 年 6 月，美国使用 Office 365 的公司数量超过 700,000 家 [6]。许多人将 Microsoft Excel 用于各种用途。这确实改变了职场中应用机器学习的动态，以及普通人的动态。由公司构建并内置到产品中的机器学习项目所产生的用例，其覆盖面将远大于基于这些主要行业驱动业务工具的任何东西。在这两个我正在考虑的用例之间——人们从事机器学习，以及人们从产品中的实用机器学习中受益——这真正是机器学习的黄金时代。

花一些时间思考实用机器学习，让我好奇机器学习在该领域的下一步是什么。我对人们将用应用机器学习做什么新奇的事情感到好奇。越来越多的产品将把它内置到其核心功能中。

# Substack Week 44: Machine learning salaries

**发布日期**: November 26, 2021

我们正迅速接近 The Lindahl Letter 在 Substack 上满一年，该事件将发生在 2022 年 1 月 21 日。半年似乎是一段很短的时间，但在机器学习的世界里，发生了太多事情。仅大语言模型的进步就足以真正改变机器学习领域的格局。机器学习模型的普遍性部分体现在市场上，以及它们如何在线自由共享。这两点都改变了机器学习薪资。你必须分别考虑 OpenAI 等公司的顶级构建者与机器学习更实际应用之间的差异。在这种情况下，机器学习薪资的分布是双峰的。

在 Indeed 上，你可以很快看到机器学习工程师的平均薪资目前为 $140,107 [1]。上周我分享了 LinkedIn 上列出的 152,352 个机器学习职位 [2]。像其他事物一样，你会看到薪资的变化，以及真正被要求的技能。任何告诉我他们是“全栈机器学习工程师”的人总能引起我的注意。这是一件有趣的事。围绕构建机器学习模型并将其适配到新用例的一些技能高度专业化。在某些方面，这更像是艺术而非科学，而方程式的这一部分可能导致机器学习薪资的巨大差异。你可以回顾一篇精彩的 2018 年《纽约时报》文章，他们在文中讨论了 OpenAI 的一些人工智能研究人员及其薪资 [3]。就说这些薪资足以让任何晚到派对的人质疑为什么他们没有早点参加。每年获得一百万美元进行研究太棒了。基于技术与现代性的已知交集，你会认为会有更多此类薪酬的例子存在。

我花了一些时间寻找其他巨额机器学习薪资的例子，发现在 Indeed 和 LinkedIn 上通过简单搜索公开共享的薪资范围中有更多例子。看起来你有一个强烈的双峰分布：一小簇百万美元级别的薪资（或处于那个范围内），还有一大簇薪资将低于每年约 $250,000。我的评估是，随着时间的推移，我们将继续看到这种双峰分布，处于未来技术曲线最前沿的人将获得高得多的薪酬。实用机器学习的普遍普及将使其余群体回归到信息技术领域的常见薪资范围内，除非资源需求激增，否则这将把平均薪资从 $140,107 降低约 20%。
