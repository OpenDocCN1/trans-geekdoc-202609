

# Zend PHP 认证模拟测试书

## 前言

随着 PHP 使用范围的扩大，面向专业开发人员的全球认可的资质认证计划的需求变得越来越重要。由全球 PHP 领导者 Zend Technologies 推出的 Zend 工程师认证计划，终于创建了一个专业称号，代表着 PHP 世界中始终如一的高质量技能和知识。

本书由 Zend 教育委员会的四位成员撰写和编辑，他们也协助创建了实际的 Zend 认证考试，书中包含了涵盖考试每个主题的 200 道题目。

《Zend 认证模拟测试书》是一份宝贵的资源，可用于测试您在考试各个领域的准备情况，从基础到最高级的主题无不涵盖。

每道题目都附带清晰的答案，并提供了关于题目主题、目标和最终结果的解释。回答本书中的问题将使您能够清晰、快速地识别出您在 PHP 哪些方面很强，以及在哪些方面需要进一步学习，以便能够通过考试！

**Zend Technologies, Inc.** (http://www.zend.com) 是 PHP 公司。由 PHP 的创造者和持续创新者创立，它是 Zend Engine（PHP 的核心）的开发者。

Zend 专注于企业级产品和服务，使组织能够开发、部署和管理业务关键型 PHP 应用程序。

**NanoBooks** 是由 *php|architect* 的出版商创建的优秀、深度的资源，后者是全球首屈一指的专注于 PHP 专业人士的杂志。

NanoBooks 专注于提供高质量的内容，包含深度分析和专业知识，围绕单一、明确定义的主题，没有大部头、昂贵书籍中的冗余内容。
