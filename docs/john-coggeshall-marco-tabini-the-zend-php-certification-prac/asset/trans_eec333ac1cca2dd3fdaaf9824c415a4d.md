# 前言

拥有 PHP 认证项目有许多优势。首当其冲的是，它允许雇主——尤其是非技术类雇主——为他们的 PHP 招聘决策设定一定的标准；他们会知道，获得认证的人员已经通过了一系列考核来获得证书，并能清楚地展示他们对 PHP 及其相关技术的掌握程度。

这不仅意味着 Zend 认证工程师将自动符合此类标准并在就业市场上拥有即时优势，而且认证过程还允许越来越多的企业采用 PHP。这反过来将为 PHP 开发人员带来一个更加充满活力的就业市场——使他们更容易以 PHP 开发人员最喜欢做的事情为生。我毫不怀疑，由于 Zend PHP 认证考试的存在，我们将看到 PHP 持续普及的增长。

几周前，我终于抽出时间参加了 Zend PHP 认证考试。尽管我编写了一些考题，并且几个月前作为考试教育顾问委员会成员参与了考题审核，但我惊讶地发现自己有点紧张——我想不仅是因为考试通常都会让我产生这种影响，还因为我记得考题非常全面，这很可能是因为考试作者本身就是 PHP 社区的领军人物，他们想要拟定最优秀的考题。在不使考试过于困难的前提下，这确保了每个问题都经过深思熟虑、彻底的同行评审和精心构建；这注定会让任何潜在的考生——尤其是像我这样参与了如此严谨过程的人——有点紧张！

我很高兴地说我通过了考试——但我承认有些问题相当难。

我认为，总体而言，考试是公平的，但与许多其他认证测试不同，它要全面得多。没有经验的 PHP 开发人员真的无法通过这项考试，我认为这很棒。它真正认证的是那些在现实世界中拥有开发基于 PHP 的 Web 应用程序经验的 PHP 开发人员。

我相信这本书将对准备认证考试大有裨益。Marco 和 John 都是 Zend PHP 认证顾问委员会的成员，了解考试的性质及其目标。两位作者在 PHP 方面也拥有多年的经验，这从书的内容中便可窥见一斑。本书非常好地涵盖了您将接受测试的各个主题，并提供了与考试中非常相似的问题。每章末尾提供的答案将使您很容易验证自己的优势和劣势。

我祝愿大家在认证过程中一切顺利，并希望你们很快能加入日益壮大的 Zend 认证工程师大家庭。

Andi Gutmans

*联合创始人兼技术副总裁，Zend Technologies*
*Zend 认证工程师*

# 作者简介

**John Coggeshall** 是 Zend Technologies 的技术顾问，为全球客户提供专业服务。他于 1997 年开始接触 PHP，是三本已出版书籍和 100 多篇关于 PHP 技术文章的作者，发表于 php|architect、SAMS Publishing、Apress 和 O'Reilly 等业内知名机构。

John 还是 PHP 核心的活跃贡献者，`tidy` 扩展的作者，Zend 教育顾问委员会成员，以及全球 PHP 相关会议的常邀演讲者。他的网站 `http://www.coggeshall.org/` 是任何 PHP 开发人员的绝佳资源。

**Marco Tabini** 是 php|architect（`http://www.phparch.com`）的出版人，这是面向 PHP 专业人士的首选杂志。他是四本书的作者或合著者，也是协助编写 Zend 认证考试的主题专家（SME）小组成员之一。他定期维护一个博客，网址为 `http://blogs.phparch.com`，在那里他讨论开源软件的商业模式。
