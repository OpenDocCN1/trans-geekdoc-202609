Looking at interference as a secondary user, instead of using this as an objective function, the cognitive engine could use this concept as a constraint on the objective space. A map of known primary user signals [20] would represent frequencies that are absolutely off limits for transmission. Therefore, the cognitive engine would not simply try to avoid interference-prone spectrum, but it would be forced not to use the spectrum.
