As a quick side note, the normal representations of BER formulas tend to use the Q-function, all of the equations listed here use the complementary error function *erfc*. We use this because of a few simple approximations of *erfc* from [16, 17]. To review:

```
$Q(x) = \frac{1}{2}erfc\left(\frac{x}{2}\right) = \frac{1}{\sqrt{2\pi}}\int_{x}^{\infty} exp\left(-t^2/2\right) dt \quad (4.2)
```

For $x \ge 3:

```
$erfc(x) = \frac{\exp(-x^2)}{\sqrt{\pi}}\left(1 - \frac{1}{2x^2} + \frac{(1)(3)}{2^2x^4} - \frac{(1)(3)(5)}{2^3x^6} + \dots\right) \quad (4.3)
```

For $x < 3:

```
$erfc(x) = 1 - \frac{2}{\sqrt{\pi}}\sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{n!(2n+1)} \quad (4.4)
```

Each of these equations is easily coded into a simple algorithm to iterate over a finite number of terms in the series. A very close approximation can be achieved with 10 terms for (4.3) and 40 terms for (4.4). Figure 4.1 shows the exact plot of the *erfc* function compared to the estimate for $0 \le x \le 5$ along with the percent error. There is a small spike in the estimation at $x = 3$ of $0.01\%$ to a discontinuity at the point where one ends and the other picks up. This can be adjusted by changing the formulas used and by increasing the number of terms in the series for (4.4). Decker addresses the problem of using his approximation for values smaller than three in his paper [16]. So although (4.4) is capable of representing the complementary error function for increasingly large values of $x$, the number of terms in the series must grow as well. Equation (4.3) represents the *erfc* for large values of $x$ in a simpler series for a more efficient calculation.
