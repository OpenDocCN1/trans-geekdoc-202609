A development slightly beyond the weighted sum utility function is the linear-logarithmic, or Cobb-Douglas, function in (4.22), where $U$ is the utility, $q_i$ is the value of quantity or objective $i$, and $eta_i$ is an adjustment coefficient for quantity $i$.

```
$U = \sum_{i=1}^{n} \beta_i \ln q_i \quad (4.22)$
```

The linear-logarithmic utility function, like the weighted-sum, assumes additivity but is slightly more useful because it shapes the results using the logarithmic function. One important element of the weighted-sum is that the linear relationships often find optimal at the extreme edges. The logarithmic function provides convexity to the optimization curve that helps avoid this problem.

In the linear-logarithmic function, $eta_i$ is equivalent to the weights $w_i$ in (4.21). The change of notation is here for consistency with the literature. The weights are important because, as we have discussed, different users and applications have preferences in the quality of service provided by the communications system. This concept leads to the use of consumer preference in economics, where the preferences indicate a trade-off in the amount of any one objective such that the consumer is indifferent to which point is selected. Different users and applications have different requirements, and will therefore be represented by different indifference curves in the objective space. Objectives in the waveform analysis can show both substitutive and complementary affects. For example, an application may be willing to substitute bits for higher data rates, but at some point the BER can go so high before requiring coding, or retransmission, or the application can no longer handle the errors. At this point, BER becomes complementary to throughput because no data rate can make up for the high numbers of bit errors.
