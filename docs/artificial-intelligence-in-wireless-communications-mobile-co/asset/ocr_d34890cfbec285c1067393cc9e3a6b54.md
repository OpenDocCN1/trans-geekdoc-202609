**Figure 8.9** Performance curves for interference test (2) showing objective plots for (a) BER, (b) SINR, and (c) interference power. The SINR objective plot (b) shows the mistake where the later generations calculated a very small SINR at the solution chosen.

We used the parameters in Table 8.16 to run the next test. The cognitive engine found that a BPSK signal with a 10.72-dBm transmit power will produce a 0 BER (in other words, a value too small to be represented), which indicates a very large SINR (see Figure A.1 to confirm this). However, with the use of the multiobjective search space, different objectives can produce a more acceptable solution. In this case, we use the SINR objective as the pressing agent in the optimization. When the SINR objective is not used, the power is minimized to 0.1 mW. The results in Figure 8.11 show that using the SINR objective balances the incorrect information that leads to the poor decision based only on the BER. The resulting waveform achieved the desired performance of interference avoidance (see Figure 8.12), low BER, and mid-ranged bandwidth and power.

The problem that the cognitive engine faces is misinformation from the sensor that measures the received signal strength and noise power.
