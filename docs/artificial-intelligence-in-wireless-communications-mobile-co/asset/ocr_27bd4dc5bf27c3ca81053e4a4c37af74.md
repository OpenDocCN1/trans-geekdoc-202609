# C.1 Introduction to OProfile

OProfile is an open source, GPL tool for measuring software performance
[1]. Built specifically for Linux, OProfile uses the Linux kernel to read the
processor's hardware counters as a measure of software complexity. It has
low overhead on the system and resides as a separate process to monitor the
performance of the entire system, which means a developer does not have to
add specific hooks to enable profiling as other profilers require. As the website
points out, the profilers monitor all system activity including “hardware and
software interrupt handlers, kernel modules, shared libraries, and
applications.” More importantly to application and library developers, the
profiler keeps track of performance per symbol of each process, which means
a developer can analyze the performance of individual functions and routines
within the code. We use this last feature to understand the complexity of each
t modulators used in the GNU Radio.
