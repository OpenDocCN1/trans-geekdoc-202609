### Simulation of an SINR Sensor

### F.1 Sensor Design

A transmitted signal, $s[k]$, contains a sequence of known data symbols, $s[k]$ such as a training sequence, preamble, or access code. The received signal, $r[k]$, is shown in (F.1) and includes the transmitted signal, interference signals in the channel, and AWGN noise. Not represented in this equation is that the interferers’ amplitude is adjusted by some pathloss of the propagation channel. $r(t) = s[k] + \sum (i[k]) + n[k]$.

Correlating the received signal with the known data symbols when the received signal is the known sequence. The correlation can be implemented as an FIR filter the length of the known sequence and where taps are the values of the known sequence. A similar autocorrelation is done using the known sequence to get the peak value for determining the pathloss. Equation (F.2) gives the peak value the cross-correlation where $K$ is the length of the known sequence, and (F.3) gives the peak of the autocorrelation process.

$m_x = \sum_{k=0}^{K-1} r[k]$

$m_a = \sum_{k=0}^{K-1} s[k]$

The known sequence is then adjusted in amplitude for pathloss by the ratio $m_x/m_a$. The adjustment is based on the assumption that pathloss does not significantly change over the duration of the known sequence, which is usually a few dozen long. The Radio access code is 64 bits long. Subtracting the adjusted known sequence from the received signal leaves the interference plus noise (F.4). Subtracting the results of (F.4) from the received signal leaves the transmitted signal (F.5). These equations are valid for k over the length of the known sequence, once the cross-correlation detects a received sequence.

$r_{n+i}[k] = r[k] - \frac{m_x}{m_a}$

$r_s[k] = r[k] - r_{n+i}[k]$

The signal power is the average magnitude squared of $r_s$ (F.6), and the interference noise power is the average magnitude squared of $r_{n+i}$ (F.7).

$s = \frac{1}{K} \sum_{k=0}^{K-1} |r_s[k]|^2$

$i + n = \frac{1}{K} \sum_{k=0}^{K-1} |r_{n+i}[k]|^2$

Equation (F.8) is the estimated SINR.

$SINR = 10 \log_{10} \left( \frac{s}{i+n} \right)$

### F.2 Simulation

The simulations were done using the MATLAB script below. The script requires the communications toolbox. The first look at SNR without any interference, Figure F1 plotted the results versus the SNR. Each point is the average of 100 simulations using 64-bit random known sequence. The figure shows high precision in calculating the SNR. There is a constant offset of about 35 dB due to the use of root-raised pulse filtering on symbols that is not subtracted out of the signal and adds a bit of extra energy to the calculation. The purpose of this sensor is to calculate properly the signal power and the signal to noise power in the presence of interference.

**Figure F.1** Estimated SINR with no interference. The next simulation, both the signal and noise power are kept the same while the interference amplitude is adjusted from 0 to peak-peak. The SNR of the AWGN channel was set to 20 dB and the simulations are averaged 100 times for each interference setting. Figure F.2 shows the estimates of SINR, which starts at 0 dB when the interference is not present and slopes downward to about 1 dB when the signal power is the same as the transmitter. Figure F.3 shows the estimation of the signal power, which remains relatively constant for any power of interference. The standard deviation shows the estimates are within 1 dB from the actual value when the interference power is at its highest. These simulation results show that this type of sensor will properly provide cognitive engine with the required estimates of the signal, interference, and noise powers.

#### F.3.1 SINR Calculation Function

```matlab
function [S,I] = corr_sir(SNR, iamp)
% Return the signal power (S) and interference noise power (I)
% and estimated pathloss (l) given a specified SNR (in dB) and amplitude
% of an interference signal

Ns = 1000;           % size of data
K = 64;               % size of known sequence (in bits)
sps = 8;               % number of samples per symbol
fd = 1;                % symbol rate
fs = sps*fd;            % sample rate
rc_alpha = 0.35;     % raised cosine filter rolloff

% Create training sequence
train = randint(1,K)
train_mod = pskmod(train, 2)
t = rcosflft(train_mod, fd, fs, 'fir/sqrt', rc_alpha)

% Create source signal including the training sequence
xs = [randint(1, N), train, randint(1, N)]
xs_mod = pskmod(xs, 2)
s = rcosflft(xs_mod, fd, fs, 'fir/sqrt', rc_alpha)

% Create interference signal
xi = randint(length(xs), 1)
xi_mod = pskmod(xi, 4)
i = iamp*rcosflft(xi_mod, fd, fs, 'fir/sqrt', 0.25)

% Received signal is sum of source, interference, and noise
r = awgn(s + i, SNR, 'measured')
r = 0.1*r; % crude pathloss

% Autocorrelate training sequence to get max correlation value
autocor = xcorr(t,t)
autocor = ceil(length(autocor)/2) : length(autocor);
[mauto, indauto] = max(autocor);

% Correlate against known training sequence and find peak
sigcor = xcorr(r, t)
sigcor = sigcor(ceil(length(sigcor)/2) : length(sigcor))
sigcor = abs(sigcor)
[m,ind] = max(sigcor);
```
