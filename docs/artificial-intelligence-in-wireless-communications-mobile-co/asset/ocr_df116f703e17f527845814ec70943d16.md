# D.5 Cognitive Controller Configuration

The cognitive controller configuration script lists the components attached to the controller as well certain pieces of information to interact with the component. Most of the components are distributed processes that the controller communicates with a TCP socket. For each of these, the source and destination address (either an IP address or the domain name of the node) are listed along the source and destination ports. The source port is generally left as 0 so the socket selects a free port. The destination port must match the port the component is listening to and is arbitrary.
