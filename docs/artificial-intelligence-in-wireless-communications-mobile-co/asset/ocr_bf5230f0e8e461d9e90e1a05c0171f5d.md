To test the latest version of the cognitive engine, we use operating frequencies between 2.405 to 2.415 GHz with three interfering nodes. Two of the interference nodes are 1-MHz QPSK signals generated from the Centre for Telecommunications Value-Chain Research (CTVR) ISR software radio [2] and the third is a 1-MHz wide OFDM signal generated by the Anritus MG3700A generator. The signals were generated at 2.4075 GHz (IRIS QPSK 1), 2.410 GHz (IRIS QPSK 2), and 2.4125 GHz (signal generator OFDM). The cognitive radio node has the waveform capabilities described in Table 8.23.

When asked to design a waveform using the same objectives as Table 8.18, the cognitive engine produced a 200-kbps QPSK signal with a 12-dbm transmit power. At this point, the performance of the cognitive engine is well understood in building signals that can produce high data rates with low BER.
