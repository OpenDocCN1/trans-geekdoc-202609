Each of the equations below provides the formula for BER calculation of a particular modulation given an AWGN channel.
GMSK (noncoherent demodulator):

```
$P_e = \frac{1}{2}\exp(-\alpha\gamma) \quad (4.8)$
```

$\alpha$ is an adjustment factor to the energy based on the bandwidth product (BT) factor of the Gaussian filter [18]. Table 4.1 provides estimates of $\alpha$ over some values of BT based on the work of Murota and Hirade [19].
BPSK:

```
$P_e = \frac{1}{2}erfc(\sqrt{\gamma}) \quad (4.9)$
```

$M$-PSK ($M > 2$):

```
$P_e = \frac{1}{\log_2(M)}erfc\left(\sin\left(\frac{\pi}{M}\right)\sqrt{\log_2 M}\sqrt{\gamma}\right) \quad (4.10)$
```

DBPSK:

```
$P_e = \frac{1}{2}\exp(-\gamma) \quad (4.11)$
```
