# 6.5.2 S-Box Transformation

Suppose the 6-bit input to a S-Box is: $b_5 b_4 b_3 b_2 b_1 b_0$.

The substitution/choice by S-Boxes is performed as follows:

+   The decimal number formed by two bits $b_5 b_0$ (0...3) is used to choose the S-Box Row Number $n$.

+   The decimal number formed by four bits $b_4 b_3 b_2 b_1$ (0...15) is used to choose the S-Box column number $m$.

+   The decimal number stored in the S-Box at the intersection $(n, m)$ forms the 4-bit output.

+   The S-Boxes are designed so that if two inputs to an S-Box differ in one bit, the outputs must differ in at least 2 bits. Also, all transformations are reversible.
