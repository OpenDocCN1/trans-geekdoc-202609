# 6.6.2.2 Linear Cryptanalysis

This cryptanalysis is based on the finding that if we XOR some of the
bits of plaintext and XOR some of the bits of corresponding cipher-text and
then we have the XOR of the result of the two, then we get a bit that would
form the XOR of some of the bits of the key.

+   - Consider an n -bit plaintext and m -bit key.

+   - Let the bits of a plaintext block be labeled as $p[1],p[2],...p[n]$; the bits
of a cipher-text block be labeled as $c[1],c[2],...c[n]$; and the key bits be
labeled as $k[1],k[2],...k[m]$

+   - Let us denote

$P[\alpha_1,\alpha_2,...,\alpha_a] = P[\alpha_1] \oplus P[\alpha_2] \oplus ... \oplus P[\alpha_a]$ where $1 \\leq a \leq n$
$C[\beta_1,\beta_2,...,\beta_b] = C[\beta_1] \oplus C[\beta_2] \oplus ... \oplus C[\beta_b]$ where $1 \\leq b \leq n$
$K[\gamma_1,\gamma_2,...,\gamma_c] = K[\gamma_1] \oplus K[\gamma_2] \oplus ... \oplus K[\gamma_c]$ where $1 \\leq c \leq n$

+   - The goal of linear cryptanalysis is to determine linear equations of the
form:

$P[\alpha_1,\alpha_2,...,\alpha_a] \oplus C[\beta_1,\beta_2,...,\beta_b] = K[\gamma_1,\gamma_2,...,\gamma_c]$
