# Class A:

Format: N • H • H • H

In Binary: 10 is the leading bit pattern, also called the high order bit
0xxx xxxx • xxxx xxxx • xxxx xxxx • xxxx xxxx
      N

Where x = 0 or 1

In Decimal: 0–127 • 0–255 • 0–255 • 0–255
             N

Subnet Mask: 255 • 0 • 0 • 0

Purpose: reserved for governments or large organizations
127 is reserved for loopback address and testing
Number of bits of network / number of bits of host = 7 / 24
Maximum number of supported hosts = $2^{24}-2$ = $2^{24}-2$
