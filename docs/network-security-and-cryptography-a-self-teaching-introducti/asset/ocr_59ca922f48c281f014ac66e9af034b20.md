# 6.1 INTRODUCTION

In this chapter we will study some modern symmetric ciphers like the Data Encryption Standard (DES) and the International Data Encryption Algorithm (IDEA). Though simple DES is no longer considered secure, there are highly secure schemes involving multiple applications of DES like Triple-DES. IDEA is considered highly secure and is in extensive use.
