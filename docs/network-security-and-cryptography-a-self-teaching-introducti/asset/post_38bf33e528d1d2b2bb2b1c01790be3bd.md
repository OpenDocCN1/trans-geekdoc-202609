## 7.1 INTRODUCTION

Public-Key Cryptography is based on the concept of two keys for each user, that is a Private Key which is kept secret by the user and a Public Key that is made available to all other users in the cryptystem. Though both keys belonging to a user are related to each other, one cannot determine the private key of another user by knowing its related public key.

## 7.2 REQUIREMENTS OF PUBLIC-KEY CRYPTOGRAPHY

1. Each user generates a pair of keys: for example, a user “N” may generate Public Key $PU_A$ and Private Key $PR_A$.

2. The Private Key $PR_A$ is kept private (secret) by the user “A,” and the Public Key $PU_A$ is made available to all other users in the cryptosystem.

3. A Public Key can be easily obtained by adversaries. Though the Private Key $PR_A$ is related to the Public Key $PU_A$, by just knowing the Public Key $PU_A$ it is computationally infeasible to generate Private Key $PR_A$. Thus, an adversary will not be able to determine the Private Key from the Public Key.

4. The Encryption/Decryption of a message can be performed by using a companion-pair ($PU_A, PR_A$) in any order. This implies that if a message is encrypted using Public Key $PU_A$, then it can be decrypted using Private Key $PR_A$; and if a message is encrypted using Private Key $PR_A$, then it can be decrypted using companion Public Key $PU_A$.

## 7.3 DATA CONFIDENTIALITY USING PUBLIC-KEY CRYPTOGRAPHY

1. Any user (say “B”) sending a secure Message $M$ to user “X” encrypts the message using N’s Public Key and then transmits the resulting ciphertext to user “X”.

$C = E_{PU_A}[M]$

2. At the recipient end, the user “X” can easily decrypt the ciphertext $C$ using its private key $PR_X$.

$M = D_{PR_X}[C = D_{PR_X}[E_{PU_A}[M]]]$

3. It is computationally infeasible for an adversary, knowing the ciphertext $C$ and Public Key $PU_A$, to decrypt $C$ (which has been generated using public key $PU_A$). Even the sender cannot decrypt $C$.

## 7.4 RSA ALGORITHM

- It is a Public Key Algorithm that was developed in 1997 by a team of three computer scientists from MIT. It is named after its developers, Rivest, Shamir, and Adleman (popularly known as RSA).

- The algorithm can be used for data confidentiality as well as for digitally signing the messages to assure source authentication, data integrity, and source non-repudiation.

- The strength of the algorithm lies in the extent of difficulty encountered in factoring a large composite number into its prime factors.

### 7.4.1 Main Components

- Determination of Keys
- Encryption Algorithm
- Decryption Algorithm

### 7.4.1.1 Determination of Keys

A User (Say “A”) computes its private key and public key as follows:

- Choose two prime numbers $p$ and $q$. (The larger the prime numbers, the more difficult it would be to break the cipher).
- Compute $n = pq$
- Compute $\Phi(n) = (p - 1)(q - 1)$
- Choose an integer $e$ such that $e$ is less than $\Phi(n)$ and relatively prime to $\Phi(n)$, that is $GCD(e, \Phi(n)) = 1$. Note that $e$ will always be odd, since $\Phi(n)$ is even.
- Compute $d$ as the multiplicative inverse of $e \pmod{\Phi(n)}$:
$ed \equiv 1 \pmod{\Phi(n)}$
Thus, $e$ and $d$ form multiplicative inverses of each other $\pmod{\Phi(n)}$.
- The pair $(e, n)$ forms the Public Key of the user “A”, which is made public and distributed to other users in the cryptystem.
- The pair $(d, n)$ forms the Private Key of the user “A,” which keeps secret; it is not known to anyone except “A”.

### 7.4.1.2 Encryption Algorithm

If any user in the cryptystem (say “B”) intends to send a message $M$ ($0 \le M < n$) to “A,” then “B” encrypts the message using Public Key $(e, n)$ and sends the ciphertext $C$ to “A”:

$C = M^e \pmod n$

### 7.4.1.3 Decryption Algorithm

User “A” receives the ciphertext $C$ and recovers the message $M$ by decrypting it using its own Private Key $(d, n)$:

$M = C^d \pmod n$

Prove that Decrypted Value of ciphertext at the recipient end is an exact copy of plaintext at the sender end.

Proof
$Decrypted Value = C^d \pmod n$
$= (M^e)^d \pmod n$
$= M^{ed} \pmod n$

Since $d = e^{-1} \pmod{\Phi(n)}$, $ed = k\Phi(n) + 1$ for some integer $k$.
$Decrypted Value$ at recipient end $= M^{k\Phi(n)+1} \pmod n$

The value of $M$ has two possibilities:
- Case 1: $M$ relatively prime to $n$, that is $GCD(M, n) = 1$
- Case 2: $M$ not relatively prime to $n$, that is $GCD(M, n) \neq 1$

**Case 1:**
$GCD(M, n) = 1$, that is $M$ is relatively prime to $n$. Then $M^{\Phi(n)} \equiv 1 \pmod n$ (by Euler’s Theorem).
Raising both sides of the congruence to power $k$:
$(M^{\Phi(n)})^k \equiv 1^k \pmod n$
Multiplying both sides by $M$:
$M^{\Phi(n)+1} \equiv M \pmod n$

**Case 2:**
$GCD(M, n) \neq 1$, that is $M$ is not relatively prime to $n$. Under this condition there are two possibilities:
1. $M$ not relatively prime to $p$. Since $M$ cannot have both $p$ and $q$ as its factors, $M$ will be relatively prime to $q$, that is $GCD(M, q) = 1$.
2. $M$ not relatively prime to $q$. Therefore, $M$ will be relatively prime to $p$, that is $GCD(M, p) = 1$.

**Case 2(a):**
Since $M$ is relatively prime to $q$:
$M^{\Phi(q)} \equiv 1 \pmod q$ (by Fermat's Theorem).
Raising both sides of the congruence to power $\Phi(p)$:
$[M^{\Phi(q)}]^{\Phi(p)} \equiv 1^{\Phi(p)} \pmod q$ (for some integer $k$)
$M^{\Phi(n)} \equiv 1 \pmod q$
For some integer $j$, we will have:
$M^{\Phi(n)} = jq + 1$
Multiplying both sides of the above congruence by $M = cp$ (where $n=pq$):
$M^{\Phi(n)+1} = jcp + cp = jn + M$
$M^{\Phi(n)+1} \equiv M \pmod n$

**Case 2(b):**
$q$ divides $M$, and $GCD(M, p) = 1$.
Proof is similar to Case 2(a).

Example 7.1: (RSA)

Let $p = 11, q = 23$
$N = p \times q = 11 \times 23 = 253$
$\Phi(n) = (p-1) \times (q-1) = 10 \times 22 = 220$
Choose $e = 13$ which is less than $\Phi(n)$ and relatively prime to $\Phi(n)$
Then $d = e^{-1} \pmod{\Phi(n)}$
$d = 13^{-1} \pmod{220} = 17$
Public Key = $(e, n) = (13, 253)$
Private Key = $(d, n) = (17, 253)$
Suppose a Message $M = 2$ to be sent by another user to this user.
$C = M^e \pmod n$
$= 2^{13} \pmod{253}$
$= 8192 \pmod{253} = 96$
$M = C^d \pmod n$
$= 96^{17} \pmod{253}$
