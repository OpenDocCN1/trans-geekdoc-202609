# 7.6.1 Determination of Private Key and Public Key (by User “A")

+   1. Choose a large prime number $p$ such that $\Phi(p)$ has a large prime factor.

+   2. Choose $g$: a primitive root of $p$

+   3. Choose an integer $x$ such that $1 < x < \Phi(p)$.

+   4. Compute $y = g^x mod p$.

+   5. The triplet $(x, g, p)$ forms the Private Key and the triplet $(y, g, p)$ forms the Public Key of User “A”.

+   6. User “A” keeps the private key $(x, g, p)$ secret and makes the public key $(y, g, p)$ available to all users with whom “A” intends to communicate.

# 7.6.1.1 Encryption

When any (User “B”) possessing Public Key $(y, g, p)$ intends to send a message $M$ $(0 \le M < p)$ to User “A”, User “B” proceeds as follows:

+   1. Choose a random integer $k$ such that $(1 < k < \Phi(p))$.

+   2. Knowing public key, $(y, g, p)$ of intended recipient “A”, User “B” computes the cipher-text, which comprises a pair of integers:

> $g^k mod p, My^k mod p$

3. User “B” transmits the cipher-text to the intended recipient, User “A”.

4. The first component of the cipher-text, that is, $g^k mod p$, is called Clue. It contains a clue of the random value $k$, which is not known to the intended recipient of the cipher-text. The intended recipient will use the clue for extraction of plaintext from the second component of the cipher-text.

# 7.6.1.2 Decryption

User “A” receives the cipher-text $(g^k mod p, My^k mod p)$.

“A” proceeds to decrypt the received cipher-text using its private key $(x, g, p)$.

+   1. Compute $(-x) mod \Phi(p) = \Phi(p) - x = p - 1 -x$

+   2. Compute $(g^k mod p)^{-x} mod \Phi(p) = g^{-kx} mod p$

+   3. Compute $M = ((My^k mod p) 	imes (g^{-kx} mod p))$
