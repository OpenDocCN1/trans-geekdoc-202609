5. If there is success in step (3), then Eve offers the valid variant x to A for signatures.

6. “A” will readily sign the message x using its private key, append the digital signature to the message, and hand over the signed message to “Eve” for transmission.

| X |
| $E_{Pr_A}[H(M)]$ |

7. Eve replaces the message x with message y, leaving the digital signature intact, and transmits the resulting message to the intended recipient.
