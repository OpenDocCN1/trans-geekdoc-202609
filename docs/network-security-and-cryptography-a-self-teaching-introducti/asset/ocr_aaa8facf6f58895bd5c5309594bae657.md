# 7.7.8 Strength of ECC-Based Schemes

+   - Let $E_p(a, b)$ be an Elliptic Curve where $p$ is a large prime number.
- Let $G \in E_p(a, b)$ be the Base Point chosen, and $n$ is the Order of Base Point $G$. The Base Point $G$ is chosen so that its Order $n$ should be very large.
- Let $n_i$ be an integer such that $(1 < n_i < n)$.
- Knowing $n_i$ and $G$, it is easy to compute $P_i = n_iG$.
- But, knowing $P_i$ and $G$, it is very difficult (computationally infeasible) to determine $n_i$. This is equivalent to taking discrete logarithms. This provides the strength to ECC-based Schemes.
