# Example 7.3

Prove that the keys $K_A$ and $K_B$ computed by users “A” and “B” respectively are equal.

Solution:

The Proof is as follows:
$K_A = (Y_B)^{X_A} \bmod p$
$(g^{X_B} \bmod p)^{X_A} \bmod p$
$(g^{XBXA}) \bmod p$
$(g^{X_A} \bmod p)^{X_B} \bmod p$
$(Y_A)^{X_B} \bmod p$
$K_B$
