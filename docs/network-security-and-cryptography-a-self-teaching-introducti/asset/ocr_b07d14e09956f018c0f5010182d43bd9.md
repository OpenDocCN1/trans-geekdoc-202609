# 10.6 AUTHENTICATION PROCEDURES DEFINED IN X.509

Notation used: A [I]; Where $I$ is set of data signed by user “A."

One-Way Authentication:

```
A[t_A, r_A, ID_B, SgnData, E_PUB[K_AB]]
```

![](bbox=[0.125, 0.219, 0.753, 0.335])

+   where
$t_A$: Time Stamp
$r_A$: Nounce
$ID_B$: B's Identification
SgnData: Signed Data
$PU_B$: B's Public Key
$K_{AB}$: Session Key to be used from A to B

Two-Way Authentication

```
A[t_A, r_A, ID_B, SgnData, E_PUB[K_AB]]
B[t_B, r_B, ID_A, SgnData, E_PUB[K_AB]]
```

![](bbox=[0.125, 0.583, 0.753, 0.7])

The Nonce $r_A$ is bounced back by $B$ to $A$ to indicate that $B$ has responded to $A$ as message.

+   where $t_A$, $t_B$: Time Stamps
$r_A$, $r_B$: Nonces
$ID_A$: A's Identification
$ID_B$: B's Identification
SgnData: Signed Data
