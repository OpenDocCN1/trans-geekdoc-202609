# 2. Feistel Processing: It comprises 16 identical rounds of the Feistel Network, followed by a 32-bit swap. Each round $i$ has a 48-bit sub-key $K$, drawn from the overall 56-bit key. The right-side input to a round is not changed and it is output as left-side input to the next round. The left-side input to a round is transformed by taking its XOR with the output of round function $F$ that operates on the right-side input acted. A detailed description of the round function is given subsequently. The Decryption algorithm is exactly the same as the Encryption Algorithm, except that the sub-keys are applied in the reverse order; $K_{16}$ is applied to Round 1, sub-key $K_{15}$ is applied to Round 2, and so on, with sub-key $K_1$ applied to Round 16 of decryption.
