**2. Substitution/Choice (by Use S-Boxes):** DES uses 8 specially designed S-Boxes as non-linear components. Each box has 4 rows indexed $(0 \dots 3)$ and 16 columns indexed $(0 \dots 15)$ of decimal numbers $(0 \dots 15)$. The numbers are distributed in each row in a random manner and none of the digits is repeated in a row; that is, each of the 16 digits $(0 \dots 15)$ appears precisely in a row.

## 6.5.2 S-Box Transformation

Suppose the 6-bit input to a S-Box is: $b_5 b_4 b_3 b_2 b_1 b_0$.

The substitution/choice by S-Boxes is performed as follows:

- The decimal number formed by two bits $b_5 b_0$ (0...3) is used to choose the S-Box Row Number $n$.

- The decimal number formed by four bits $b_4 b_3 b_2 b_1$ (0...15) is used to choose the S-Box column number $m$.

- The decimal number stored in the S-Box at the intersection $(n, m)$ forms the 4-bit output.

- The S-Boxes are designed so that if two inputs to an S-Box differ in one bit, the outputs must differ in at least 2 bits. Also, all transformations are reversible.

## Example 6.3

Suppose the 6-bit input to the S-Box as shown in Figure 6.7 is: 011011.

- 1. Find the 4-bit output of the S-Box.

- 2. How many bits of output will the concatenation of 4-bit outputs from S-Boxes generate?

### Solution

1. Row Number $n = (01) = 1$
Column Number $m = (1101) = 13$
Decimal Number stored at location (1, 13) is 11.
Therefore, the 4-bit output of the S-Box will be: 1011

2. The concatenation of 4-bit outputs from 8 S-Boxes will generate 32-bit output.

## 6.5.4 DES Decryption

The DES decryption uses the same algorithm as encryption that the application is in reverse order. Any round $i$ of the decryption algorithm gets sub-key $K_{17-i}$ as input. Thus, round 16 of the decryption algorithm gets sub-key $K_1$ as input. The output of round 16 will be the original plaintext that generated the cipher-text.
