# 4.3.2 Properties of Z_n

The properties of Z_n are summarized in Table 4.1.

| TABLE 4.1 Properties of Z_n |
| Property | Expression |
| Commutative Laws | (w + x) mod n = (x + w) mod n
(w x) mod n = (x w) mod n |
| Associative Laws | [(w + x) mod n+y] mod n = [w (x+y) mod n] mod n
[(w x) mod n y] mod n = [w (x y) mod n] mod n |
| Distributive Laws | [w(x+y) mod n = [(w x) mod n+(w y) mod n] mod n |
| Identities | (0+w) mod n = w mod n
(1 w) mod n = w mod n |

Additive Inverse For each w in Z_n, there exists an additive inverse of w such that (w + x) = 0 mod n

Multiplicative Inverse For w in Z_n, if w is relatively prime to n, then there exists a multiplicative inverse of w such that (wx) = 1 mod n

# Thus Z_n forms an Integral Domain.
