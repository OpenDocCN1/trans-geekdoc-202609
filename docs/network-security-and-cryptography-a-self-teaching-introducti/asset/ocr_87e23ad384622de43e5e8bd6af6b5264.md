# 10.1 INTRODUCTION

A Public Key, as the name suggests, is to be made available to all users in the cryptosystem.

The Public Key Infrastructure (PKI) is the infrastructure that is necessary for making the public keys available to all users in a convenient, secure, and efficient manager.

RFC 2822 defines PKI as the hardware, software, people, policies, and procedures to create, store, manage, distribute, and revoke Public Key Certificates. ITU-T Recommendations X.500 defines a Directory Service for management of public key certificates.

X.509, which forms part of X.500, defines the formats for Public Key Certificates. The certificates are issued under the digital signatures of designated Certification Authorities (CAs).
