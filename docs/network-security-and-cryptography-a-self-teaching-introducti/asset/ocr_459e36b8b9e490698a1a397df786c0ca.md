# Example 4.44

Solve the following simultaneous congruence using the Chinese Remainder Theorem:

```
$X = 2 \pmod 3\nX = 3 \pmod 5\nX = 2 \pmod 7$
```

```
$m_1 = 3, m_2 = 5, m_3 = 7\na_1 = 2, a_2 = 3, a_3 = 2\nm = m_1 \times m_2 \times m_3 = 3 \times 5 \times 7 = 105\nM_1 = m / m_1 = 35\nM_2 = m / m_2 = 21\nM_3 = m / m_3 = 15$
```

$y_1 = M_1^{-1} \pmod{m_1} = (35)^{-1} \pmod 3$
