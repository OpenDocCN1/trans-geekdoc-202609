**Decryption:** The recipient will know the row-size of the message rectangle-used by the sender from the key-size.

+   - In Example 5.9, since the key-size is 4, the recipient will know that the row-size of the message rectangle is 4. The received cipher-text is divided into four equal parts. Each part represents a column of the encrypted plaintext. So, the columns are written as per the key to form the message rectangle, which would be exactly the same as it was at the sender.

+   - Then, the message is read off from the rectangle row-size, and that forms the plaintext. The dummy letters (if any) at the end can be made out by the recipient and ignored.

The cipher can be made more secure by performing transpositions repeatedly, using the same key more than once. The number of transpositions must be known to the intended recipient to enable the deciphering of the received cipher-text.
