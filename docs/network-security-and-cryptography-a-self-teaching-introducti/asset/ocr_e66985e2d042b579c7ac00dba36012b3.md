$: Q(n, k) = [n \times (n-1) \times (n-2) \times \dots \times (n-(k-1))] / n^k$

$= [(n/n) \times (1-1/n) \times (1-2/n) \times \dots \times (1-(k-1)/n)]$

$= [1 \times (1-1/n) \times (1-2/n) \times \dots \times (1-(k-1)/n)]$

$= [(1-1/n) \times (1-2/n) \times \dots \times (1-(k-1)/n)]$

Since $(1-x) < e^{-x}$ for all $x > 0$

$.: (1-1/n) < e^{-1/n}$

$.: (1-2/n) < e^{-2/n}$

Likewise $(k-1/n) < e^{-(k-1)/n}$

$.: [(1-1/n) \times (1-2/n) \times \dots \times (1-(k-1)/n)] < [e^{-1/n} \times e^{-2/n} \times \dots \times e^{-(k-1)/n}]$

$e^{-1/n[1+2/n+\dots+(k-1)/n]}$

$< e^{(k(1-2)/n}$

Since $1+2+3+\dots+(k-1) \= k(k-1)/2$

$.: Q(n, k) < e^{k(k-1)/2n}$

$P(n, k) > e^{k(k-1)/2n}$

$e^{k(k-1)/2n} = 0.5$

$.: e^{k(k-1)/2n} = 2$

$.: k(k-1)/2n = \log 2$

$.: k(k-1) = 2n \log 2$

If $k$ is large then $k(k-1) \approx k^2$
