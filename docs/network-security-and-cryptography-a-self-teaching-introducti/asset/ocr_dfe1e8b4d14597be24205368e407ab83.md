In this case reverse transformation back to $J$ is not feasible, as demonstrated as follows in Table 4.8:

TABLE 4.8 Reverse Transformation from Set $L$ to Set $Z_s$

| Set $L$ | Set $Z_s$ |
|---|--|
| 0 | 0 or 2 or 4 or 6 |
| 4 | 1 or 3 or 5 or 7 |

Thus, the multiplication of $Z_s$ elements with an integer that is not relatively prime to integer value $n$ is not reversible.

# Some Important Congruences

+   - $(a+b)=(a+c)\mod n \Rightarrow b=c\mod n$  (4.4)

+   - $(a\times b)=(a\times c)\mod n \Rightarrow b=c\mod n$, provided $a$ is relatively prime to $n$  (4.5)

Proof:

+   1. $(a+b)=(a+c)\mod n \Rightarrow b=c\mod n$

+   - The additive inverse $(-a)$ exists for each $a \in Z_n$

+   - Add $(-a)$ on both sides of the above congruence

+   - $[(-a)+(a+b)]=[(-a)+(a+c)]\mod n$

+   - Thus, $b=c\mod n$
