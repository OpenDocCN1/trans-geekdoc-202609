+   • Hashing the MAC value using an embedded Hash function (MD-5 or SHA-1).

+   • Truncating the HMAC output by selecting the lowest 96 bits.

# 12.3.4 Algorithm for Generation of Integrity Check Value (ICV)

+   • ICV supports MD5 and SHA-1 as an embedded and Hashing function.

+   • A secret key K, shared between the sender and the recipient, is used for generating ICV, so that no adversary can modify the message on route. The secret key K is chosen to be size > n bits, where n is the output message-digest size of function H. For MD5, n equals 128 bits and for SHA-1, it is 160 bits.

+   • Depending upon the Hashing function H used, the ICV-generating algorithm is designated as:

HMAC-MD5-96: Hashed MAC using embedded Hash-Functions MD5 and selecting lowest 96 bits of the output.
