# Functions at the Receiving End

+   1. At the receiving end, the segments are reassembled. Then the reassembled message is processed to remove $R64$ transformation.

+   2. The recipient uses its private key $PR_b$, and RSA to decrypt the encrypted session key $K_s$.

+   3. The recipient subsequently uses the session key $K$, to decrypt the compressed message $Z(M)$.

+   4. Finally, the recipient decompresses the received message.
