The second moment is handled the same way.

```
$E[X^2] = \sum_{k=0}^{\infty} k^2 P(k) = \sum_{k=0}^{\infty} \frac{\lambda^k}{k!} e^{-\lambda} = 0 + \sum_{k=1}^{\infty} \frac{\lambda^k}{(k-1)!} e^{-\lambda}$
```

Since, $k=k-1+1$

```
$E[X^2] = \sum_{k=1}^{\infty}(k-1)^2 \frac{\lambda^{k-1}}{(k-1)!} \lambda e^{-\lambda} = \lambda^2 e^{-\lambda} \sum_{k=1}^{\infty} \frac{\lambda^{k-2}}{(k-2)!} + \lambda e^{-\lambda} \sum_{k=1}^{\infty} \frac{\lambda^{k-1}}{(k-1)!} = \lambda^2 + \lambda$
```

Hence

```
$Var(X) = E[X^2] - E^2[X] = \lambda^2 + \lambda - \lambda^2 = \lambda$
```

as expected.

# 2.5.1 Uniform Distribution

This distribution, also known as rectangular distribution, is very important for performing pseudo random number generation in simulation. It is also useful for describing quantifying noise that is generated in pulse-code modulation. It is a distribution in which the density is constant. ```
