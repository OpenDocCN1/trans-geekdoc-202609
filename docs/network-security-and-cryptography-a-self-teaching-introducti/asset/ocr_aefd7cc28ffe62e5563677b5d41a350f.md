# 3. Digital Signature (Using the RSA Algorithm)

User “A” can encrypt a message $X$ ($0 < M < n$) by using its private key $(d, n)$.

$Y = X^d \mod n$

The cipher-text Y can be decrypted by a recipient using the public key $(e, n)$ of “A”.

$Y \mod n = (X^d \mod n)^e \mod n$

= $X \mod n$

= $X$ (Original Plaintext message)
