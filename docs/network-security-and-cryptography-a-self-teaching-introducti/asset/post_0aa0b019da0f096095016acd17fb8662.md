## 7.7.2 Elliptic Curves in Cryptography (ECC)

The Elliptic Curve Cryptography (ECC) makes use of Elliptic Curves with finite sets. The ECC quadratic equations draw the values of their variables and coefficients from a finite set of integers.

There are two types of Elliptic Curves used in Cryptography:

- 1. **Prime Curves**: A prime curve is defined over a prime field $Z_p = \{0, 1, 2, 3, \dots, (p-1)\}$ where $p$ is a large prime number.

A Prime Curve makes use of a quadratic congruence, whose variables and coefficients draw their values from the set of residues $(mod p)$, that is, $Z_p$ where $p$ is a prime number.

- 2. **Binary Curves**: A Binary Curve is defined over Galois Field (GF) $(2^n)$ where $n$ is an integer. It is a finite field with $2^n$ values.

## 7.7.4 Prime Elliptic Curve Set

- A Prime Elliptic Curve $E(a, b)$ is the set of all $(x, y)$ pairs of non-negative integers that satisfy the congruence $(7.2)$.
- The set represents a finite set of points occurring on the Elliptic Curve $E(a, b)$. It also includes $p$ point $O$ (at infinity), called the zero point.
- If $x^3 + ax + b$ does not have any repeated factor, then the set $E_p(a, b)$ forms an Abelian Group with respect to addition $(+)$ operation, with $O$ as an Additive Identity Element.

## 7.7.6 Rules for Addition (+) Operation over $E_p, (a, b)$

Let $P, Q$ be the points in $E_p(a, b)$, such that $P: (x_p, y_p)$ and $Q: (x_q, y_q)$. The addition within $E_p(a, b)$ follows the following rules:

1. $O$ is an additive identity element: $P+O = P$.
2. $(-P) = (x_p, -y_p)$ will have the additive inverse of $P$: $P+(-P) = O$.
3. $R = P+Q = (x_r, y_r)$ will be the point from the Elliptic Curve Set $E_p(a, b)$. The $x_r, y_r$ coordinates of $R$ are determined as follows:
$x_r = (\lambda^2 - x_p - x_q) \mod p$
$y_r = (\lambda(x_p - x_r) - y_p) \mod p$
where $\lambda = \frac{y_q - y_p}{x_q - x_p} \mod p$ if $x_p \neq x_q$, and $\lambda = \frac{3x_p^2 + a}{2y_p} \mod p$ if $P=Q$.

## Order of a Point

Let $G$ be a point in the set $E_p(a, b)$. The order of a point $G$ is defined as the least integer $n$ that satisfies $nG = O$. The set $\langle G, 2G, \dots, nG \rangle$ represents a set of distinct points from $E_p(a, b)$.

## Base Point

In ECC-based Crypto, a point $G \in E_p(a, b)$ is chosen as a Base Point. The Base Point is chosen so that its Order should be large; the larger the order, the more secure the ECC Scheme will be.

## Example 7.8

Determine Order of Point $P = (0, 6)$ in Elliptic Curve $E_7(1, 1).

Solution:
Here $a=1, b=1, p=7$.
$E_7(1, 1) = \{(0, 1), (0, 6), (2, 2), (2, 5), O\}$
To determine $2P = P + P$:
$\lambda = \frac{3 \times 0^2 + 1}{2 \times 6} \mod 7 = \frac{1}{12} \mod 7 = \frac{1}{5} \mod 7 = 3$.
$x_r = (3^2 - 0 - 0) \mod 7 = 9 \mod 7 = 2$.
$y_r = (3(0 - 2) - 6) \mod 7 = (-6 - 6) \mod 7 = -12 \mod 7 = 2$.
$2P = (2, 2)$, which belongs to $E_7(1, 1)$.

Now $3P = P + 2P$ where $P=(0, 6)$ and $Q=(2, 2)$:
$\lambda = \frac{2 - 6}{2 - 0} \mod 7 = \frac{-4}{2} \mod 7 = -2 \mod 7 = 5$.
$x_r = (5^2 - 0 - 2) \mod 7 = 23 \mod 7 = 0$.
$y_r = (5(0 - 0) - 6) \mod 7 = -6 \mod 7 = 1$.
$3P = (0, 1)$ also belongs to $E_7(1, 1)$.

Now $P=(0, 6)$ and $3P=(0, 1) = -P$.
$4P = 3P + P = (-P) + P = 0$.
Since $4P = 0$, the order of point $(0, 6)$ is 4.
