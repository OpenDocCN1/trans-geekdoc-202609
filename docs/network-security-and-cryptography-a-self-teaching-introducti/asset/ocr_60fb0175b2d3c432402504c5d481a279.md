# 2. Message Authentication and Confidentiality (MAC linked to Plaintext)

![](bbox=[0.162, 0.169, 0.778, 0.329])

**Figure 8.6** A schematic diagram of the Message Authentication and Confidentiality (MAC linked to plaintext).

+   - At the recipient end, MAC $K_r$ is generated as a function of plaintext $M$ and key $K_p$. The MAC is appended to the plaintext.
- The resulting package, comprising plaintext and MAC, is then encrypted using a secret key $K_n$ and the resulting cipher-text is transmitted. The outer encryption by $K_i$ ensures data confidentiality.

# 3. Message Authentication and Confidentiality (MAC linked to cipher-text)

![](bbox=[0.162, 0.573, 0.778, 0.743])

**Figure 8.7** A schematic diagram of the Message Authentication and Confidentiality (MAC linked to cipher-text).

+   - The plaintext is first encrypted using symmetric encryption and key $K_n$. MAC is then generated as a function of the cipher-text and key $K_p$. The MAC is appended to the cipher-text. The MAC is thus linked to the cipher-text.
