# 6.7.4.5 Counter (CTR) Mode

The Counter (CTR) Mode is an extremely simple scheme, but it is secure as other schemes. A Counter, equal in size to the plaintext block, is used for Encryption and Decryption. Its value is initialized to the same value on both ends. For each subsequent block of plaintext, the counter is incremented by one. It uses only the Encrypt Algorithm both at Sender and Receiver ends. CTR mode has no feedback.

# 6.7.4.5.1 Encryption and Decryption of CTR

# Encryption of CTR

CTR uses the encryption function of the underlying block cipher ($E_k$) for both encryption and decryption. The encrypting algorithm needs to wait for a complete N-bit block of data before encryption. The relationship between the plaintext and the cipher-text blocks $i$ is given by $C_i = P_i \oplus E_k$.
