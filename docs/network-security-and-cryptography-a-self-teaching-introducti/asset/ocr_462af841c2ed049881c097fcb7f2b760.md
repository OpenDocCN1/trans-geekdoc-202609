Depending upon the weighted sum, the Key Legitimacy Field is assigned one of the following values:

+   - Key ownership not trusted (when weighted sum is low)
- Key ownership marginally trusted (when weighted sum is high but < 1)
- Complete trust in key ownership (when weighted sum = 1)

Thus, when the value of the weighted sum reaches one, the binding between the public key and its owner is considered to be complete and trustworthy.

# 11.5 S/MIME (SECURE/MULTIPURPOSE INTERNET MAIL EXTENSION)

S/MIME is an extension of the RFC822 framework that addresses some of the limitations and problem areas of SMTP (Simple Mail Transfer Protocol).
