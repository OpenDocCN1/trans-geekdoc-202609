
Hence,

$N_b = \frac{E(B)}{X} = \frac{1}{1-\rho}$

## 2.20 M/Ek/1 QUEUEING SYSTEM

In this case, the service time distribution is an Erlang distribution with parameters $\mu$ and $k$, that is,

$f_X(x) = \frac{\mu(\mu x)^{k-1}}{(k-1)!}e^{-\mu x}, \quad x \geq 0$

with mean and variance

$E[X] = \frac{k}{\mu}, \quad Var[X] = \frac{k}{\mu^2}$

This should be regarded as another special case of the M/G/1 system so that the Pollaczek-Khintchine formula in Equation (2.198) applies. Thus,

$E[W_q] = \frac{1+k}{2k}\frac{\lambda}{\mu-\lambda} = \frac{1+k}{2k}\frac{\rho}{\mu(1-\rho)}$

$E[N_q] = \lambda E[W_q] = \frac{1+k}{2k}\frac{\lambda^2}{\mu(\mu-\lambda)} = \frac{1+k}{2k}\frac{\rho^2}{1-\rho}$

$E[T] = E[W_q] + \frac{1}{\mu}$

$E[N] = \lambda E[T]$

where $\rho = \lambda / \mu$.

Consider two M/M/1 queues in tandem, as shown in Figure 2.31. This is an example of an open queueing network. The state diagram is shown in Figure 2.32. From the state diagram, we can obtain the balance equations.
Let

$p_{i,j} = Prob[i \text{ jobs at server 1 and } j \text{ jobs at server 2}]$

FIGURE 2.32 The state diagram for M/M/1 queues in tandem.

For state (0,0),

$\lambda p_{0,0} = \mu_2 p_{0,1}$ (2.214)

For state (i,0), $\quad i > 0$,

$\lambda p_{i-1,0} + \mu_2 p_{i,1,0} - (\lambda + \mu_1) p_{i,0} = 0$ (2.215)

For state (0,j), $\quad j > 0$,

$\mu_1 p_{i,j-1} + \mu_2 p_{0,j+1} - (\lambda + \mu_2) p_{0,j} = 0$ (2.216)

For state (i,j),

$\lambda p_{i-1,j} + \mu_1 p_{i+1,j-1} + \mu_2 p_{i,j+1} - (\lambda + \mu_1 + \mu_2) p_{i,j} = 0$ (2.217)

Since queue 1 is unaffected by what happens at queue 2, the marginal probability of $i$ jobs at queue 1 is

$p_i = (1 - \rho_1) \rho_1^i, \quad \rho_1 = \frac{\lambda}{\mu_1}$ (2.218)

Similarly, for queue 2

$p_j = (1 - \rho_2)\rho_2^j, \quad \rho_2 = \frac{\lambda}{\mu_2} \quad (2.219)$

A simple product solution for this two-node network is

$p_{i,j} = (1 - \rho_i)(1 - \rho_j)\rho_i^i\rho_j^j, \quad \rho_i = \frac{\lambda}{\mu_i}, \quad \rho_j = \frac{\lambda}{\mu_j} \quad (2.220)$

The average number of customers in the system is given by

$E(N) = \sum_{i,j} (i+j)p_{i,j} = \sum_{i} \frac{\lambda}{\mu_i}(1 - \frac{\lambda}{\mu_i}) + \sum_{j} \frac{\lambda}{\mu_j}(1 - \frac{\lambda}{\mu_j}) \quad (2.221) = \frac{\lambda}{\mu_1 - \lambda} + \frac{\lambda}{\mu_2 - \lambda}$

From this we find average time a customer spends in the system is given by

$E(W) = \frac{E(N)}{\mu_1 - \lambda} + \frac{1}{\mu_2 - \lambda} \quad (2.222)$

### 2.21.2 Queueing System with Splitting

Splitting a Poisson distribution is shown in Figure 2.33. Suppose that a proportion $p$ of departures from an M/M/1 system (or an M/M/infty) joined a second system, and the remainder depart altogether. The input to the second system is a Poisson distribution with rate $p\lambda$. Let $X_1(t)$ be the number of departures from the first system and $Y_2(t)$ be the number of arrivals to the second system by time $t$. Then

$P(Y_2(t) = k|X_1(t) = n) = \binom{n}{k}p^k(1-p)^{n-k} \quad (2.223)$

## 2.22 JACKSON NETWORKS

A Jackson network has a steady state solution in product form. Such product-form queuing networks can be open or closed. The nature of such networks allows us to decouple the queues, analyze them separately as individual systems, and then combine the results. For example, consider a series of $k$ single-server queues with exponential service time and Poisson arrivals, as shown in Figure 2.35. Customers entering the system join a queue at each stage. Each queue can be analyzed independently of other queues. Each queue has an arrival and a departure rate of $\lambda$. If the $i$th server has a service rate of $\mu_i$, the utilization of the $i$th server is

$\rho_i = \frac{\lambda}{\mu_i} \quad (2.227)$

and

$Prob[n \text{ customers in the i-th queue}]=P(n_i)=(1 - \rho_i)\rho_i^{n_i} \quad (2.228)$

![](img/d3b56042c756fbcc011ff06f1b9f53f0_132_1.png)

FIGURE 2.35 $k$ M/M/1 queues in series.

The joint probability of queue lengths of $k$ queues is the product of individual probabilities.

$P(n_1, n_2, ..., n_k) = (1-\rho_1)\rho_1^{n_1}(1-\rho_2)\rho_2^{n_2}\cdots(1-\rho_k)\rho_k^{n_k} = P_1(n_1)P_2(n_2)\cdots P_k(n_k)$

This is known as the Jackson theorem after J. R. Jackson who proved the property. The queuing network is therefore a product-form network. A network to which Jackson's theorem is applicable is known as the Jackson network. In general, for a product-form network

$P(n_1, n_2, ..., n_k) = \frac{1}{G}\prod_{i=1}^k \rho_i^{n_i}$

where $G$ is a normalization constant and is a function of the total number in the system.
