If $n$ is sufficiently large and an arbitrary reversible substitution is performed between the plaintext and cipher-text, then the statistical characteristics of the plaintext get masked to a great extent, making crypt-analysis difficult to perform.

For example, a 4-bit input produces one of 16 possible input states, which is mapped by the substitution cipher into one of 16 unique possible states, where each of them is represented by 4 cipher-text bits.
