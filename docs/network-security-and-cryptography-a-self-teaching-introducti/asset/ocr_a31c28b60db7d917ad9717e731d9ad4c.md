# 2.6 TRANSFORMATION OF A RANDOM VARIABLE

It is required in system analysis that we obtain the PDF $f_y(y)$ of the output random variable $Y$, given that the PDF $f_x(x)$ for the input random variable $X$ is known and the input-output transformation function

$Y = g(X)$

is provided. If we assume that $g(X)$ is continuous or piecewise continuous, then $Y$ will be a random variable. Our goal is to get $f_y(y)$. We begin with the distribution of $Y$.
