# ## 8.1 INTRODUCTION

This chapter covers the concepts and the mechanisms needed to provide Message Authentication, namely, Message Authentication Codes, Hash Functions, and Digital signatures, followed by detailed coverage of popular algorithms for the generation of Message Digests (Hash Values) and Digital Signatures. The chapter also provides in detail the mathematical concepts of the 'Birthday Attack' on Digital Signatures.

# ## 8.2 WHAT IS MESSAGE AUTHENTICATION?

+   - Message Authentication is a service that assures the recipients of messages about the identity of senders.
