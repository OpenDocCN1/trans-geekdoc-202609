# When an integer passes Miller-Rabin’s Test, why does it return “Likely to be prime” and not “Certainly Prime”?

+   - If $n$ is prime then it passes the Miller-Rabin Test for all possible values of “a” ($1<a<(n-1)$). But it is only a one-way implication.

+   - Any integer $n$ passes the Miller-Rabin Test, there is a likelihood that $n$ may not be prime, since a composite number may also pass the Miller-Rabin Test for certain values, but not for all possible values of “a” ($1<a<(n-1)$).

+   - If an integer $n$ passes the Miller-Rabin Test for one value of “a” $(1<a<(n-1))$ then the probability $n$ is not prime is less than $\frac{1}{4}$ and the probability that $n$ is prime greater than $\frac{1}{4}$.

+   - If an integer passes the Miller-Rabin Test with $t$ random values of “a,” then the probability that $n$ is prime greater than $(1-\frac{1}{4})^t$.
