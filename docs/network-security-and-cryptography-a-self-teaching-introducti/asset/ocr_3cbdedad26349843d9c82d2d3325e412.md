Where,
$P$ : Plaintext Block, $X_1, X_2$ : Intermediate Cipher-Text Blocks, $C$ : Final Cipher-Text Block

$X_1 = E_{K_1} [P]$ (6.5)

$X_2 = E_{K_2} [X_1] = D_{K_2} [E_{K_1}, [P]]$ (6.6)

$C = E_{K_k} [X_2] = D_{K_k} [E_{K_k}, [P]]]$ (6.7)

The plaintext goes through the following steps of process:

+   1. Transformation by Encrypt ($E$) function using key $K_1$ The output is intermediate cipher-text $X_1$
2. Transformation by Decrypt ($D$) function using key $K_2$ It gets $X_1$ as input and generates intermediate cipher-text $X_2$ as output.
3. Transformation by Encrypt ($E$) function using key $K_1$ It takes $X_2$ as input and generates final cipher-text $C$ as output.
