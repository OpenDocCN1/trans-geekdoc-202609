## 4.7.6 Addition Inverse of GF (2³)

Since addition in GF (2³) is performed (mod2), the additive inverse of any integer "w" belonging to GF (2³) will be "w" itself, since (w + w)mod2 = 0.

## 4.7.8 Multiplication over GF (2ⁿ)

The multiplicative inverse of a polynomial f(x) mod m(x), that is f(x)⁻¹ mod m(x), is determined by Euclid's Extended Algorithm:

Euclid(f(x), m(x)) = f(x)⁻¹ mod m(x) where f(x) is a polynomial of degree ≤ n-1 and m(x) is irreducible polynomial of degree n.

Step 1: (A_1, A_2, A_3) = (1, 0, m(x)); (B_1, B_2, B_3) = (0, 1, f(x))
Step 2: If B_3 = 0 then return f(x)⁻¹ mod m(x) does not exist
Step 3: If B_3 = 1 then return B_2 = f(x)⁻¹ mod m(x)
Step 4: Q = A_3 div B_3
Step 5: (T_1, T_2, T_3) = (A_1 - Q*B_1, A_2 - Q*B_2, A_3 - Q*B_3)
Step 6: (A_1, A_2, A_3) = (B_1, B_2, B_3)
Step 7: (B_1, B_2, B_3) = (T_1, T_2, T_3)
Step 8: GOTO Step 2

Example 4.20: Let f(x) = x² + 1 and m(x) = x³ + x² + 1. Determine f(x)⁻¹ mod m(x).

Solution: For f(x) = x² + 1 and m(x) = x³ + x² + 1, Table 4.16 illustrates the computation of f(x)⁻¹ mod m(x).

Table 4.16 Computational of Multiplicative Inverse of f(x) mod m(x)

| A_0, A_1, A_2 | B_0, B_1, B_2 | T_0, T_1, T_2 | Q = A_i div B_j |
|---|---|---|---|
| (1, 0, m(x)) | (0, 1, f(x)) | - | - |
| (1, 0, x²+1) | (0, 1, x²+1) | (1, x, x²+1) | x |
| (0, 1, x²+1) | (1, x, x²+1) | (1, 1, x) | 1 |
| (1, x, x²+1) | (1, x+1, x) | (x, x²+x, 1) | x+1 |
| (1, x+1, x) | (x, x²+x, 1) | - | - |

In the last iteration of Table 4.16 B_i = 1, the value of B_s = x²+x+1 represents the multiplicative inverse of f(x) mod m(x).
∴ f(x)⁻¹ mod m(x) = x²+x+1.

## 4.8 FERMAT'S LITTLE THEOREM

Fermat's Theorem states that if $p$ is a prime number and $a$ is a positive integer not divisible by $p$ then $a^{p-1} \equiv 1 \pmod p$ will hold.

Proof:

- $Z_p^* = \{1, 2, ... (p-1)\}$

Since $a$ is a positive integer not divisible by $p$, $(a \pmod p) \in Z_p^*$ and thus will be relatively prime to $p$. If each element of $Z_p^*$ is multiplied by $(a \pmod p)$, we get a set $L$ that has exactly same set of integers as $Z_p^*$.

## 4.8.1 Corollary of Fermat's Theorem

$a^p \equiv a \pmod p$ where $p$ is a prime number and $a$ is any positive integer.

There are two possibilities:

1. Case I: Integer relatively prime to $p$, that is, does not divide $a$.

Then by Fermat's Little Theorem, $a^{p-1} \equiv 1 \pmod p$

Multiplying both sides of the above congruence by integer $a$,
$a^p \equiv a \pmod p$

Let $a = cp$ for some integer $p$.
Then $a^p \equiv (cp)^p \mod p = 0 \pmod p$
Also, $a \pmod p = (cp) \pmod p = 0 \pmod p$
$herefore a^p \equiv a \pmod p$
