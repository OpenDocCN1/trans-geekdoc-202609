# Example 7.5

Prove that the message received at the recipient end is the same as the message sent.

# Solution:

The Proof is as follows:

```
The message decrypted at the recipient end    = ((My^k \mod p) \times (g^{-ks} \mod p)) \mod p
= ((Mg^{ks} \mod p) \times (g^{-ks} \mod p))
= (Mg^{ks} g^{-ks}) \mod p
= M \mod p
= M (Same as the message sent)
```

Thus, the recipient is able to extract the original plaintext message from the cipher-text.
