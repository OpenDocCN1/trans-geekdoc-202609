$P_B$ will be a point from $E_p(a, b)$. User “B” keeps $n_B$ secret and sends $P_B$ to User “A.”

It can be verified that the secret keys $K_A$ and $K_B$ computed by “A” and “B” respectively are:

```
$K_A = n_A 	imes P_B = n_A(n_B 	imes G) = n_B(n_A 	imes G) = n_B 	imes P_A = K_B$
```

# 7.7.10 Strength of ECC Key-Exchange Algorithm

$E_p(a, b), G$, and $n$ are global parameters, known to all users in the system. It is presumed that an adversary will also have access to these parameters. In addition, it is presumed that an adversary can access $P_A$ and $P_B$ from the communication media. But, an adversary needs knowledge of either $n_A$ or $n_B$ which are known only to User “A” and User “B” respectively. And computing $n_A$ from $P_A$ and computing $n_B$ from $P_B$ are considered very difficult (or infeasible), since $n$ is very large. Thus, an adversary would not be able to determine the secret key.

# 7.7.11 ECC-Based Encryption/Decryption Scheme

+   1. Selection of Suitable Global Parameters: Suitable Global Parameters are chosen, which are shared among all users in the cryptystem:
$E_p(a, b)$: Elliptic Cover Set, where $p$ is a large number and $a, b$ are coefficients of the congruence.
$Y^2 = (x^3 + ax + b) \pmod p$
G: Base point in $E_p(a, b)$ such that its order will be very high.
n: Order of Base Point G in $E_p(a, b)$

+   2. Determination of Keys by the Users: Each user (User “A”) in the cryptystem determines its Private Key and Public Key as follows:
* “A” selects a large integer $n_A$ as its Private Key, which “A” keeps private (secret).
