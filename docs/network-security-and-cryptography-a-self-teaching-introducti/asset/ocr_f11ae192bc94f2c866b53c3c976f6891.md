Big Data analytics is the process of analyzing and mining Big Data. It can produce operational and products knowledge at an unprecedented scale and specificity. The technological advances in storage, processing, and analysis of Big Data can include the following:

+   1. Rapidly decreasing cost of storage and CPU power in recent years;
2. Flexibility and cost-effectiveness of datacenters and cloud computing for elastic computation and storage;
3. Development of new frameworks such as Hadoop, which allow users to take advantage of these distributed computing systems storing large quantities of data through flexible parallel processing.

# 14.2.1 Big data analysis can transform security analytics in the following ways:

+   1. Accumulate data from various internal organizational sources as well as external sources to make a consolidated view of the required data into something called a vulnerability database.
2. Perform in-depth analytics on the data using security intelligence, hence uncovering unique patterns that could be the source of many security issues.
3. One-dimensional view of all the related information.
4. Real-time analysis of streaming data and uses previous results as feedback back to the system as a whole.
