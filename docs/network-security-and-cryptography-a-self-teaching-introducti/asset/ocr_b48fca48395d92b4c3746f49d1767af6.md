# MATHEMATICAL FOUNDATIONS FOR CRYPTOGRAPHY * 165

Example 4.20

Let $f(x) = x^2 + 1$ and $m(x) = x^3 + x^2 + 1$. Determine $f(x)^{-1} mod m(x)$.

# Solution

For $f(x) = x^2 + 1$ and $m(x) = x^3 + x^2 + 1$.

Table 4.16 illustrates the computation of $f(x)^{-1} mod m(x)$

TABLE 4.16 Computational of Multiplicative Inverse of $f(x) \bmod m(x)$

| $A_0, A_1, A_2$ | $B_0, B_1, B_2$ | $T_0, T_1, T_2$ | $Q = A_i \text{ div } B_j$ |
| --- | --- | --- | --- |
| $(1, 0, m(x))$ | $(0, 1, f(x))$ | - | - |
| $(1, 0, x^2+x+1)$ | $(0, 1, x^2+1)$ | $(1, x, x^2+x+1)$ | $x$ |
| $(0, 1, x^2+x+1)$ | $(1, x, x^2+x+1)$ | $(1, 1, x)$ | $1$ |
| $(1, x, x^2+x+1)$ | $(1, x+1, x)$ | $(x, x^2+x, 1)$ | $x+1$ |
| $(1, x+1, x)$ | $(x, x^2+x, 1)$ | - | - |

In the last iteration of Table 4.16 $B_i = 1$, the value of $B_s = x^2+x+1$ represents the multiplicative inverse of $f(x) \bmod m(x)$

$\therefore \ f(x)^{-1} \bmod m(x) = x^2+x+1$.
