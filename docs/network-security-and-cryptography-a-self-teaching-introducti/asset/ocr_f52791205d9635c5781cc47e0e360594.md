# 14.4.11 Advanced Encryption Standard (AES)

AES is based on a design principle known as a substitution-permutation network, a combination of both substitution and permutation, and is fast in both software and hardware. Unlike its predecessor DES, AES uses a Rijndael cipher, which has a fixed block size of 128 bits, and a key size of 128, 192, or 256 bits, and is defined in three versions, 10, 12, and 14 rounds respectively.

There are three steps performed in AES:

+   - encryption
- decryption
- key generation
