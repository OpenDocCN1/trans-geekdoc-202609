# ## 14.5.6 Types of Security Attacks That Can Compromise the Smart Grid Security:

+   * Passive Attacks: They aim to learn and use the system information without affecting the system resources. The attack target is only transmitted information in order to learn the system configuration, architecture, and normal behavior.

+   * Active Attacks: They are planned to affect the system operation through data modification or introducing false information into the system.

# ## 14.5.7 Cybersecurity Attacks in a Smart Grid:

+   * Eavesdropping: This is a passive attack described as an unauthorized interception of an on-going communication without the consent of the communication parties.
