Example 7.1: (RSA)

Let $p = 11, q = 23$
$N = p 	imes q = 11 	imes 23 = 253$
$\Phi(n) = (p-1) 	imes (q-1) = 10 	imes 22 = 220$
Choose $e = 13$ which is less than $\Phi(n)$ and relatively prime to $\Phi(n)$
Then $d = e^{-1} \pmod{\Phi(n)}$
$d = 13^{-1} \pmod{220} = 17$
Public $Key = (e, n) = (13, 253)$
Private $Key = (d, n) = (17, 253)$
Suppose a Message $M = 2$ to be sent by another user to this user.
$C = M^e \pmod n$
$= 2^{13} \pmod{253}$
$= 8192 \pmod{253} = 96$
$M = C^d \pmod n$
$= 9617 \pmod{253}$
$= ((963 \pmod{253}) 	imes (963 \pmod{253}) 	imes (963 \pmod{253}) 	imes (963 \pmod{253}) 	imes (963 \pmod{253}) 	imes (962 \pmod{253})) \pmod{253}$
Now,
$963 \pmod{253} = 88436 \pmod{253} = 248$
$962 \pmod{253} = 9216 \pmod{253} = 108$
:$. $M = (2485 	imes 108) \pmod{253}$
$= ((2482 \pmod{253}) 	imes (2482 	imes 108) \pmod{253}$
$= ((9216 \pmod{253}) 	imes (9216 \pmod{253}) 	imes 248 	imes 108) \pmod{253}$
$= (25 	imes 25 	imes 248 	imes 108) \pmod{253}$
$= (16740000) \pmod{253} = 2$

We are able to extract the original message $M = 2$.
