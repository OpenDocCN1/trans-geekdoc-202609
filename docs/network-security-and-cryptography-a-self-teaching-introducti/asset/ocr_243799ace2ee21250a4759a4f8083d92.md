Each integer except 0 in GF ($2^s$) has a unique multiplicative inverse.
Thus, GF($2^s$) satisfies the properties of a finite field of order $2^s$.
The Advanced Encryption Standard (AES) makes use of GF ($2^8$) finite fields with reducing polynomial $m(x) = x^3 + x^4 + x + 1$, which is an irreducible polynomial of order 8.
