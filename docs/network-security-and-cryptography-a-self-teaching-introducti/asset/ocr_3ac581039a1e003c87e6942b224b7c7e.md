**Figure 6.19** s-Bit Cipher Feedback (CFB) Mode encryption/decryption.

# Encryption of CFB

$S_s(X)$: Most significant $s$ bits of shift register $X$
$C_i = P_i \oplus S_s(E_k(IV))$

# Decryption of CFB

**First Step (for Cipher-text $C_i$)**

$Plaintext = C_i \oplus S_s(E_k(IV))$
$P_i \oplus S_s(E_k(IV)) \oplus S_s(E_k(IV)) = P_i$

**Subsequent Steps (for Cipher-text $C_i$)**

$Plaintext = C_i \oplus S_s(E_{t-1}(IV))$
$P_i \oplus S_s(E_{t-1}(IV)) \oplus S_s(E_{t-1}(IV)) = P_i$
