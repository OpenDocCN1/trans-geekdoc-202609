# Example 4.2

Let

$a = (1, 3, 2)$
$b = (3, 1, 2)$
$c = (2, 3, 1)$

$a \cdot (b \cdot c) = (1, 3, 2) \cdot (1, 2, 3) = (1, 3, 2)$
$(a \cdot b) \cdot c = (3, 2, 1) \cdot (2, 3, 1) = (1, 3, 2)$
$a \cdot (b \cdot c) = (a \cdot b) \cdot c = (1, 3, 2)$ holds.

$(A_n)$ **Identity Elements**: The identity element is $e = (1, 2, 3, ... , n) \in S_n$, which satisfies $e \cdot a = a \cdot e = a$ for each $a \in S_n$.

# Example 4.3

Let

$a = (3, 1, 2)$ and $e = (1, 2, 3)$

$e \cdot a = (3, 1, 2)$
$a \cdot e = (3, 1, 2)$

Thus,

$e \cdot a = a \cdot e = (3, 1, 2)$

$(A_n)$ **Inverse Element**: for each element $a \in S_n$, there exists an element $a' \in S_n$, which satisfies $a \cdot a' = a' \cdot a = e$.

Let $a = (3, 1, 2)$

Now,

$(2, 3, 1) \cdot (3, 1, 2) = (1, 2, 3) = e$

Therefore,

$a' = (2, 3, 1)$
