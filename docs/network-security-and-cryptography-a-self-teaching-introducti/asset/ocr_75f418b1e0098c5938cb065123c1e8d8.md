# Cloud Computing consists of two ends:

+   - Front end: It includes the user's computer and the software required to access the cloud network.

+   - Back end: It consists of various computers, servers, and database systems that create the cloud.

The user can access applications in the cloud network from anywhere by connecting to the cloud using the Internet. Some of the real-time applications which use Cloud Computing are Gmail, Google Calendar, and Dropbox, and so on.
