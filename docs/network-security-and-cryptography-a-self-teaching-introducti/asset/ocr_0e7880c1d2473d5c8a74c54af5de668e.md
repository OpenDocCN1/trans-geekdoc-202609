# 8.7 SECURE HASH ALGORITHM (SHA-1)

SHA-1 design is based on the MD4 algorithm. The algorithm takes as input message of less than $2^{64}$ bits and produces a 160-bit message digest. The input is processed in 512-bit blocks. The overall structure of processing is similar to MD5 as shown earlier. The processing consists of the following steps:

+   **Step 1: Append Padding Bits:** The message is padded with 1...512 bits such that its length after padding is congruent to 448 mod 512. Padding is always added even if the message length is already congruent to 448 mod 512. Padding consists of a single 1-bit followed by the necessary 0-bits.

+   **Step 2: Append Message Length:** A 64-bit representation of unpadded message is appended to the padded message, making its overall length an exact multiple of 512. Let the overall length be $512L$ and the $L$ blocks of 512 bits be represented by $Y_0, Y_1, ..., Y_{L-1}$. Equivalently, each 512-bit block can be viewed as 16 32-bit words. The message contains $N$ words, where $N = 16 	imes L$. Let the Message $M$ be represented as $M[0 \dots N-1]$ words.

+   **Step 3: Initialize the MD Buffer:** A 160-bit Buffer is used to hold the intermediate and final results of the Hash Function. The buffer can be represented as five 32-bit registers $(A, B, C, D, E)$. These five registers are initialized to the following HEX values:

```
A = 64752301
B = EFCDAB89
C = 98BADCFE
D = 10325476
E = C3D2E1F0
```
