## Abelian Group:

A Group is called an *Abelian Group* if it is a Group (i.e., obeys axioms 1 through 4 obeyed by a group) and also obeys the following additional axiom:

- $(A_3)$ **Commutative:** $a \bullet b = b \bullet a$, for all $a, b \in G$

The Set of all *integers (positive, negative, and 0)* is an Abelian Group under "Addition" with 0 as the identity element. The Set of non-zero real numbers is an Abelian Group with respect to "Multiplication", with 1 as the identity element. The element 0 is not included in the group, since it does not have a multiplicative inverse.

For "Addition" the identity element is 0, and the additive inverse of an element $a$ is $-a$. *Subtraction* is defined by $a - b = a + (-b)$.

For "Multiplication" the identity element is 1, and the multiplicative inverse of an element $a$ is $a^{-1}$.

**Division** is defined as $a / b = ab^{-1}$.

### 4.2.1.1 exponentiation within a Group

Exponentiation in a Group is defined as repeated application of the Group Operator.

For example, if element $a \in \{G, \+\}$ then $a^k = a \bullet a \bullet a \dots$ ($k$ times), with $a^0 = e$ (the identity element) and $a^{-n} = (a^n)^{-1}$.

```
For $\{G,+\\}$, \quad a^k = a + a + a + \dots + a \quad (k \text{ times})
\quad kn
\quad a^0 = 0n = 0 \quad (additive identity element)
For $\{G, \times\}$, \quad a^k = a \times a \times a \times \dots \times a \quad (k \text{ times})\
\quad a^k
\quad a^0 = 1 \quad (multiplicative identity element)
```

### 4.2.1.2 Cyclic Group

A Group $\{G,\bullet\}$ is said to be cyclic if each element in $G$ is generated as $a^k$, where $k$ is an integer and $a$ is a fixed element from $G$. The element $a$ is called the Generator of the Cyclic Group $G$. A Cyclic Group is always an abelian group; it may be a finite abelian group or an infinite abelian group.

The set of all integers is an infinite cyclic group with respect to addition, with element 1 as the group generator. All positive integers are defined as $(1)^n$. For example, $5=1+1+1+1+1 (5 \text{ times})$. In addition, all negative integers are generated as $(-1)^n$. For example, $-3=(-1)^3=(-1)+(-1)+(-1)$; 0 is generated as $(1)^0$, that is, by adding 0 zeros.

### 4.2.2 Ring

A Ring $R$ is denoted as $\{R,+\times\}$ where $R$ is a set of elements, $+$ is an addition operation, and $\times$ is a multiplication operator. It obeys the following axioms:

- $(M_1)$ **Axiom $(A_1)$ to $(A_3)$**: $R$ is an *Abelian Group* with respect to "Addition".
- $(M_2)$ **Closure under Multiplication**: If $a$ and $b$ are in $R$ then $a \times b$ in $R$.
- $(M_3)$ **Associative under Multiplication**: $(a \times b) \times c = a \times (b \times c)$ for all $a,b,c$ in $R$.

**Commutative Ring:** A Ring $R$ is said to be a Commutative Ring if it is a Ring (i.e. obeys all axioms obeyed by a Ring) and also obeys the additional axiom:

- $(M_4)$ **Commutative under Multiplication**: $a \times b = b \times a$ for all $a,b$ in $R$.

A Ring is a set in which we can perform addition, subtraction, and multiplication without leaving the set. Set of all integers (positive, negative, and zero) is a Commutative Ring.

**Integral Domain:** An Integral Domain is a Commutative Ring, obeying the following axioms:

- $(M_0)$ **Multiplicative Identity**: There exists an element 1 in $R$ such that $1 \times a = a$ for all $a \in R$.
- $(M_1)$ **Non-Zero Divisor**: If $a,b \in R$ and $a \times b = 0$, then either $a=0$ or $b=0$.

The Set of all integers (positive, negative, and zero) is an Integral Domain.

### 2.4.3 Field

A Field $F$, denoted as $\{F,+,\times\}$, is a set of elements with two binary operators, Addition (+) and Multiplication ($\times$), which obeys the following axioms:

- $(M_0)$ **Axioms $(A_1)$ to $(M_0)$**: $F$ satisfies previously.
- $(M_1)$ **Multiplicative Inverse**: For each element $a \in F$ (except 0), there exists a multiplicative inverse $a^{-1}$ in $F$ such that $a \times a^{-1} = 1$.

A Field is a set of elements in which we can perform addition, subtraction, multiplication, and division without leaving the set. The Division is defined as $a/b$ where $b \neq 0$.

## Example 4.5

The following are examples of fields:

- 1. A set of rational numbers. A rational number is a number of the form $a/b$, where $a$ and $b$ are integers with $b \neq 0$.
- 2. A set of real numbers.
- 3. A set of complex numbers.

The set of integers does not form a field, since the multiplicative inverse of an integer is not an integer, but a real number.

## 4.3 MODULAR ARITHMETIC

If an integer $a$ (positive, negative, or 0) is divided by a positive integer $n$, then we get an integer quotient $q$ and an integer remainder $r$ such that:

$a=nq+r$, for $0 \leq r < n$ and $q=(a/n)$

The remainder $r$ is called *residue*.

## Example 4.6

- 1. For $a=11, n=7 \Rightarrow q=1, r=4$
- 2. For $a=-11, n=7 \Rightarrow q=-2, r=3$
- 3. For $a=-21, n=5 \Rightarrow q=-5, r=4$

**Modulus** - If an integer $a$ is divided by a positive integer $n$ such that $a=nq+r$, for $0 \leq r < n$ and $q=(a/n)$, then $r=a \bmod n$.

## Example 4.7

- 1. $11 \bmod 7=4$
- 2. $-11 \bmod 7=3$
- 3. $-23 \bmod 5=2$

**Congruent Modulo** - Two integers $a$ and $b$ are said to be congruent modulo $n$, if $a \bmod n = b \bmod n$. It is expressed as

$a \equiv b \bmod n$

## Example 4.8

- 1. $23 \equiv 2 \pmod{7}$
- 2. $18 \equiv 3 \pmod{5}$
- 3. $-18 \equiv 2 \pmod{5}$
- 4. $-23 \equiv 5 \pmod{7}$

**Divisor:** A non-zero integer $b$ is said to divide an integer $a$ (expressed as $b|a$), if there exists an integer $m$ such that $a = mb$. Here, $b$ is called a divisor of $a$. If $b$ divides $a$, the remainder is 0.

## Example 4.9

Positive divisors of 105 are 3, 5, 7, 15, 21, 35, and 105.

**Some Properties of Divisors**

- 1. If $a|1$, then $a=\pm 1$
- 2. If $a|b$ and $b|a$, then $a=\pm b$
- 3. Any integer $b \neq 0$ divides 0
- 4. If $b|g$ and $b|h$, then $b|(mg+nb)$, where $m$ and $n$ are some integers

**Properties of the Modulo Operator**

- 1. $a \equiv b \pmod{n} \Rightarrow n|(a-b)$
- 2. $a \equiv b \pmod{n} \Rightarrow b \equiv a \pmod{n}$
- 3. $a \equiv b \pmod{n}$ and $b \equiv c \pmod{n} \Rightarrow a \equiv c \pmod{n}$

**Properties of Modular Arithmetic**

- 1. $[(a \pmod{n}) + (b \pmod{n})] \pmod{n} = (a+b) \pmod{n}$
- 2. $[(a \pmod{n}) \timestimes (b \pmod{n})] \pmod{n} = (a-b) \pmod{n}$
- 3. $[(a \pmod{n}) \timestimes (b \pmod{n})] \pmod{n} = (a \times b) \pmod{n}$
- 4. Exponentiation is performed by repeated multiplication $\pmod{n}$, that is, $[a^k] \pmod{n} = [(a \pmod{n}) \timestimes (a \pmod{n}) \timestimes \dots k \text{ times}] \pmod{n}$
