# Base Point

+   - In an ECC-based Crypto Scheme, a point $G \in E_p(a, b)$ is chosen as a Base Point.

+   - The Base Point is so chosen that its Order should be very high.

+   - This would make the set of distinct points $[G, 2G, ..., nG]$ very large; and this set forms the cipher-text space of the ECC Scheme.

+   - The larger cipher-text, the more secure the ECC Scheme will.

# Example 7.8

Determine Order of Point $P = (0, 6)$ in Elliptic Curve $E_{\gamma}(1, 1)$.

Solution:

Here $a=1, b=1, p=7$\n$E_{\gamma}(1, 1) = \{(0, 1), (0, 6), (2, 2), (2, 5), O\}$\n$P = (0, 6)$

To determine $2P = P + P$:$\n\lambda = (3 \times 0 + 1 + 2 \times 6) \mod 7 = (1/12) \mod 7$\n$= (1 \times 12 - 1) \mod 7 = (1 \times 3) \mod 7 = 3$\n$x_r = (\lambda^2 - x_p - x_q) \mod p = (9 - 0 - 0) \mod 7 = 2$\n$y_r = (\lambda(x_p - x_r) - y_p) \mod p = ((3(0 - 2) - 6) \mod 7 = 6$\n$= (-12) \mod 7 = 2$

$2P=(2, 2)$, which belongs to set $E_{\gamma}(1, 1)$.\nNow $3P = P + 2P + Q$ where $P=(0, 6)$ and $Q=(2, 2)$\n\lambda = (2/-4) \mod 7 = (-1/2) \mod 7 = (6 \times 2 - 1) \mod 7$\n$= (6 \times 4) \mod 7 = 3$\n$x_r = (\lambda^2 - x_p - x_q) \mod p = (9 - 0 - 2) \mod 7 = 0$\n$y_r = (\lambda(x_p - x_r) - y_p) \mod p = ((3(0 - 0) - 6) \mod 7 = 1$\n$= (-6) \mod 7 = 1$

$3P=(0, 1)$ also belongs to set $E_{\gamma}(1, 1)$.\nNow $P=(0, 6)$ and $3P=(0, 1) = -P$
