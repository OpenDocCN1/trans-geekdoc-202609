The Poisson process is related to the exponential distribution. If the interarrival times are exponentially distributed, the number of arrival-points in a time interval is given by the Poisson distribution and the process is a Poisson arrival process. The converse is also true—if the number of arrival-points in any interval is a Poisson process, the interarrival times are exponentially distributed.
