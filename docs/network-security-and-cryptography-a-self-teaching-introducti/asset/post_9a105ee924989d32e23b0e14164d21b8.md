## 13.1 INTRODUCTION

In an open networked environment, System Security deals with the protection of vital information that is made available to authorized users on the NET against security attacks by intruders. This chapter will give an overview of system security.

## 13.2 INTRUDERS

An intruder (also called a hacker) is an individual who performs security attacks on others’ domains in a networked computing environment. The intruder may attempt to read privileged data (like password cracking), perform unauthorized modification of data, or disrupt normal functioning of a system. There are three classes of intruder:

- 1. Masquerader: An individual who is not an authorized user of a system, but who penetrates the access control mechanism of the system to exploit the access rights of an authorized user. The Masquerader is likely to be an outsider.
- 2. Misfeasar: A legitimate user who exceeds access rights by increasing the range of his or her privileges. Obviously, a Misfeasar is an insider.
- 3. Clandestine User: An individual who seizes supervisory control of a system and uses this control to evade auditing or to bypass access control or to suppress audit collection.

## 13.3 INTRUSION DETECTION

Intrusion detection refers to determining whether an intruder has attempted to gain access or has gained access. 

### 13.3.1 Intrusion Detection

Intrusion detection relies on the following:

- Threshold Detection: This involves counting occurrences of events.
- Profile-Based Detection: This is based on developing a profile of users. If the number of clones created by the virus exceeds some threshold, it triggers an alarm.
- Rule-Based Detection: This involves defining a set of rules.
- Anomaly Detection: This looks for deviations from established patterns.
- Penetration Identification: This is used to detect if a user is performing a penetration.

## 13.4 PASSWORD MANAGEMENT

A password is the biggest defense against intruders. Each user is assigned a password, known only to its owner.

## 13.5 MALIOUS PROGRAMS

These are malicious programs used to attack system security. There are two classes of these:

- 1. **Virus**: Fragment of a program that attaches itself to another program and executes secretly when the host program is run. It can perform functions like erasing files.
- 2. **Worm**: A self-contained program that when executed may produce more copies of itself.

### 13.5.2 Different Phases in the Lifetime of a Virus

During its lifetime, a virus goes through four phases:

- **Dormant Phase**: A virus initially hibernates till it is activated by an event like a date, presence of file, or disk exceeding some limit. A virus may not have this state.
- **Propagation Phase**: A virus places an identical copy of itself into another program or into some system areas on the disk. Each infected program will now contain a copy of the virus that will further enter a propagation phase, thus multiplying exponentially.
- **Triggering Phase**: The virus is triggered to perform the intended function. This triggering may be caused by an event like the number of clones created by the virus.
- **Execution Phase**: The intended function is performed.

**Types of Virus:**

- **Parasitic Virus**: It attaches itself to executable files and replicates when the infected program is executing.
- **Memory-Resident Virus**: It lodges itself in RAM as part of a resident system program. Then infects every program that is executed.
- **Boot Sector Virus**: It infects a master boot record or boot record and spreads when the system is booted from the infected disk.
- **Stealth Virus**: Designed to hide itself from anti-virus software.
- **Polymorphic Virus**: A virus that mutates (undergoes change) with every infection, making detection by its signature difficult.
