where $f_y(y)$ is the marginal probability density function of $Y$. Note that $f_x(x|Y=y)$ is a function of $x$ with $y$ fixed. Similarly, the conditional probability density functions of $Y$ given $X$ is

```
$f_y(y|X=x)=\frac{f_{xy}(x,y)}{f_x(x)} \quad (2.42)$
```

where $f_x(x)$ is the marginal PDF of $X$. By combining Equations (2.40) and (2.42), we get

```
$f_y(y|X=x)=\frac{f_x(x|Y=y)f_y(y)}{f_x(x)} \quad (2.43)$
```

which is Bayes' theorem for continuous random variables. If X and Y are independent, combining Equations (2.40) and (2.42) gives

```
$f_x(x|Y=y)=f_x(x) \quad (2.44a)$
```

```
$f_y(y|X=x)=f_y(y) \quad (2.44b)$
```

indicating that one random variable has no effect on the other.
