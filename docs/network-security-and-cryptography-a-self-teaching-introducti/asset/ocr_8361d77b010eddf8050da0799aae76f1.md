If all time averages are equal to their corresponding ensemble averages, then the stationary process is ergodic, that


An ergodic process is one for which time and ensemble averages are interchangeable.

The concept of ergodicicity is a very powerful tool and it is always assumed in many engineering applications. This due to the fact that it is impractical to have a large number of sample functions to work with. Ergodicity suggests that if a random process is ergodic, only one sample function is necessary to determine the ensemble averages. This seems reasonable because infinite time each sample function of a random process would take on, at one or another, all the possible values of the process. We will use throughout this that the random processes we will encounter are ergodic and WSS.

Basic quantities such as dc, rms value, and average power can be defined in terms of time averages of an ergodic process as follows:
