# 2.22 JACKSON NETWORKS

A Jackson network has a steady state solution in product form. Such product-form queuing networks can be open or closed. The nature of such networks allows us to decouple the queues, analyze them separately as individual systems, and then combine the results. For example, consider a series of k single-server queues with exponential service time and Poisson arrivals, as shown in Figure 2.35. Customers entering the system join a queue at each stage. Each queue can be analyzed independently of other queues. Each queue has an arrival and a departure rate of λ. If the ith server has a service rate of $\mu_i$, the utilization of the ith server is

```
$$\rho_i = \frac{\lambda}{\mu_i} \qquad (2.227)$
```

and

```
$Prob[n, \text{ customers in the ith queue}]=P(n_i)=(1 - \rho_i)\rho_i^{n_i} \qquad (2.228)$
```
