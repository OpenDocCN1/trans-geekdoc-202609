# 4.13 PRIMALITY TESTING

Most of the Public Key Cryptographic Systems make use of very large prime numbers. It is a major issue to choose very prime numbers larger than 2 are odd integers. In cryptography, it is a major problem to determine whether a large odd integer is a prime number or not. Many probabilistic algorithms exist that determine with a very high degree of certainty whether a given odd integer is likely to be prime or not.

# 4.13.1 Miller and Rabin's Method

The Miller-Rabin Method determines whether a given odd number is likely to be prime or not. It works as follows:

+   1. Choose a large odd integer n

+   2. Determine integer $k$ and $q$, which satisfy $(n-1)=2^k q$, where $q$ is an odd integer. For a given value of $n$, the values of $k$ and $q$ will be unique.
Let $p_0=2^0 q, p_1=2^1 q, p_2=2^2 q, \dots, p_{k-1}=2^{k-1} q$ and $p_k=2^k q$.
Choose a random number $a$ such that $1<a<n-1$.

Now, the series:

```
$a^{p_0} \pmod{n}, a^{p_1} \pmod{n}, \dots, a^{p_{k-1}} \pmod{n}, a^{p_k} \pmod{n}$
```

that is, $\{a^{p_j} \pmod{n} \mid 0 \le j \le k\}$

$X_0, X_1, X_2, \dots, X_{k-1}, X_k$
