
The second moment is handled the same way.

```
$E[X^2] = \sum_{k=0}^{\infty} k^2 P(k) = \sum_{k=0}^{\infty} \frac{\lambda^k}{k!} e^{-\lambda} = 0 + \sum_{k=1}^{\infty} \frac{\lambda^k}{(k-1)!} e^{-\lambda}$
```

Since, $k=k-1+1$

```
$E[X^2] = \sum_{k=1}^{\infty}(k-1)^2 \frac{\lambda^{k-1}}{(k-1)!} \lambda e^{-\lambda} = \lambda^2 e^{-\lambda} \sum_{k=1}^{\infty} \frac{\lambda^{k-2}}{(k-2)!} + \lambda e^{-\lambda} \sum_{k=1}^{\infty} \frac{\lambda^{k-1}}{(k-1)!} = \lambda^2 + \lambda$
```

Hence

```
$Var(X) = E[X^2] - E^2[X] = \lambda^2 + \lambda - \lambda^2 = \lambda$
```

as expected.

## 2.5 CONTINUOUS PROBABILITY DISTIONS

In this section, we consider five continuous probability distributions: uniform, exponential, Erlang, hyperexponential, and Gaussian distributions.

### 2.5.1 Uniform Distribution

This distribution, also known as rectangular distribution, is very important for performing pseudo random number generation in simulation. It is also useful for describing quantifying noise that is generated in pulse-code modulation. It is a distribution in which the density is constant. It models random events in which every value between a minimum and maximum value is equally likely. A random variable X has a uniform distribution if its PDF is given

```
$f_X(x) = \begin{cases} \frac{1}{b-a} & a \le x \le b \\ 0, & \text{otherwise} \end{cases} \quad (2.57)$
```

which is shown in Figure 2.8. The mean and variance are given by

```
$E(X) = \frac{b+a}{2} \quad (2.58a)$
```

$Var(X) = \frac{(b-a)^2}{12} \quad (2.58b)$

![](img/d3b56042c756fbcc011ff06f1b9f53f0_77_0.png)

A special uniform distribution for which $a=0, b=1$, called the standard uniform distribution, is very useful in generating random samples from any probability distribution function. Also, if $Y=Asin X$, where $X$ is a uniformly distributed random variable, the distribution of $Y$ is said to be a sinusoidal distribution.

### 2.5.2 Exponential Distribution

This distribution, also known as *negative exponential distribution*, is important because of its relationship to the Poisson distribution. It is frequently used in simulation of queueing systems to describe the interval or interdeparture times of customers at a server. Its frequent use is due to the lack of conditioning of remaining time on past time expended. This peculiar characteristic is known variably as Markov, *forgetfulness*, or *lack of memory* property. For a given Poisson process, the time interval $X$ between occurrence of events has an exponential distribution with the following PDF

$f_X(x) = \lambda e^{-\lambda x} u(x) \quad (2.59)$

which is portrayed in Figure 2.9. The mean and the variance of X are

```
$E(X) = \frac{1}{\lambda}\quad (2.60a)$
```

```
$Var(X) = \frac{1}{\lambda^2}}\quad (2.60b)$
```

![](img/d3b56042c756fbcc011ff06f1b9f53f0_78_0.png)

FIGURE 2.9 PDF for an exponential random variable.

### 2.5.3 Erlang Distribution

This is an extension of the exponential distribution. It is commonly used in queuing theory to model an activity that occurs in phases, with each phase being exponentially distributed. Let $X_1, X_2, \cdots, X_n$ be independent, identically distributed random variables having exponential distribution with mean $1/l$. Their sum $X = X_1 + X_2 + \cdots X_n$ has n-stage Erlang distribution. The PDF of X is

```
$f_X(x) = \frac{\lambda^k x^{k-1} e^{-\lambda x}}{(n-1)!}}\quad (2.61)$
```

with mean

```
$E(X) = \frac{n}{\lambda}}\quad (2.62a)$
```

and variance

```
$Var(X) = \frac{n}{\lambda^2} \quad (2.62b)$
```

### 2.5.4 Hyperexponential Distribution

This is another extension of the exponential distribution. Suppose $X_1$ and $X_2$ are two exponentially distributed random variables with means $1/\lambda_1$ and $1/\lambda_2$ respectively. If the random variable $X$ assumes the value $X_1$ with probability $p$, and the value of $X_2$ with probability $q=1-p$, then the PDF of X is

$f_X(x) = p\lambda_1 e^{-\lambda_1 x} + q\lambda_2 e^{-\lambda_2 x} \quad (2.63)$

This is known as a two-stage hyperexponential distribution. Its mean and variance are given by

$E(X) = \frac{p}{\lambda_1} + \frac{q}{\lambda_2} \quad (2.64)$

$Var(X) = \frac{p(2-p)}{\lambda_1^2} + \frac{q(2-q)}{\lambda_2^2} - \frac{2pq(1-p)}{\lambda_1\lambda_2} \quad (2.65)$

### 2.5.5 Gaussian Distribution

This distribution, also known as *normal distribution*, is the most important probability distribution in engineering. It is used to describe dephenomena with symmetric variations above and below the mean $m$. A random variable $X$ with its PDF

$f_X(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left[-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2\right] \quad -\infty < x < \infty \quad (2.66)$

where the mean

$E(X) = \mu \quad (2.67a)$

and the variance

$Var(X) = \sigma^2 \quad (2.67b)$

are themselves incorporated in the PDF. Figure 1.9 shows the Gaussian PDF. It is a common practice to use the notation $X \sim N(\mu, \sigma^2)$ to denote a normal variable $X$ with mean $\mu$ and variance $\sigma^2$. When $\mu=0$ and $\sigma=1$, we have $X=N(0,1)$, the normalized or standard distribution which is widely tabulated. It is important that we note the following points about the normal distribution, which make the distribution most prominent in probability and also in communication:

- The binomial probability function with parameters $n$ and $p$ is approximated by a Gaussian PDF with $\mu=np$ and $\sigma^2=np(1-p)$ for large $n$ and finite $p$.
- The Poisson probability function with parameter $\lambda$ can be approximated by a normal distribution with $\mu=\sigma^2=\lambda$ for large $\lambda$.
- The normal distribution is useful in characterizing uncertainty with estimated values. In other words, it is used in performing statistical analysis on simulation output.
- The justification for the use of normal distribution comes from the *central limit theorem.* The *central limit theorem* states that the distribution of the sum of $n$ random variables from any distribution approaches a normal distribution as $n$ becomes large.

Thus, the normal distribution is used to model the cumulative effect of any small disturbances, each which contributes to the stochastic variable $X$. It has the advantage of being mathematically tractable. Consequently, any statistical analyses such as those of regression and variance have been deriving a density function. In several communication applications, we assume that noise is Gaussian distributed in view of the central limit theorem, because noise is due to the sum of several random parameters.
