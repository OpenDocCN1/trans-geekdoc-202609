# Example 4.45

Solve the simultaneous congruence using the Chinese Remainder Theorem:

$X = 1 \bmod 2$

$X = 1 \bmod 3$

$X = 1 \bmod 5$

$X = 1 \bmod 7$

# Solution

$m_1 = 2, m_2 = 3, m_3 = 5, m_4 = 7$

$a_1 = 1, a_2 = 1, a_3 = 1, a_4 = 1$

$m = m_1 \times m_2 \times m_3 \times m_4 = 2 \times 3 \times 5 \times 7 = 210$
