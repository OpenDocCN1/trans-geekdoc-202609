# 8.3.7.2 Digital Signature without Encryption Using a Secret Value

![](bbox=[0.196, 0.492, 0.804, 0.638])

FIGURE 8.9 A schematic diagram of a Digital Signature without encryption using a Secret Value.

The hash value is not encrypted. A secret value, which is shared with the recipient, is appended to the message before hashing it. The recipient also appends the same secret value to the message before hashing at the recipient end as shown here.
