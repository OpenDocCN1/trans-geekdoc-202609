# 2.4.2 Binomial Distribution

This is an extension of the Bernoulli distribution. A random variable follows a Binomial distribution when: (a) the $n$ Bernoulli trials are involved, (b) the $n$ trials are independent of each other, and (c) the probabilities of the outcome remain constant as $p$ for success and $q=1-p$ for failure. The random variable $X$ for Binomial distribution represents the number of successes in $n$ Bernoulli trials.
