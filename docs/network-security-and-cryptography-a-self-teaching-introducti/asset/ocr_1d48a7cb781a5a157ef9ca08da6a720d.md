# 4.7 GALOIS FINITE FIELDS

The Galois Fields are named in honor of mathematician Évariste Galois, who invented the finite fields. There are two kinds of Galois Fields:

+   - Galois Fields of order $p^n$ denoted as $GF(p^n)$, where $p$ is a prime number and $n$ is a positive integer. A special case that is of interest from a cryptography point of view where $n=1$, that is, $GF(p)$ where order of the finite field is $p$.

+   - Galois Fields of order $2^n$ denoted as $GF(2^n)$ where $n$ is a positive integer
