# 8.5.2 Symmetric Encryption Approaches

This approach involves the use of a trusted Key Distribution Center (KDC). Each party in the network shares a secret key (called a Master Key) with the KDC. The KDC is responsible for issuing one-time Session Keys to the network. A Session Key is meant for a single session use only. Supposing party $A$ wishes to have a session with party $B$ as depicted here. While $K$ is a secret key shared between the KDC and $A$ and $B$, and $K_s$ is the secret key shared between the KDC and $B$, $N_i$, $N_1$ and $N_2$ are Nonce values used over for preventing Replay Attacks. $K_s$ is the session key issued for one session only.

# 8.5.3 Needham Schroeder Protocol

+   1. $A ightarrow KDC: ID_A || ID_B || N_1$
2. $KDC ightarrow A: E_{K_A}[K_s || ID_B || N_1 || E_{K_B}[K_s || ID_A]]$
3. $A ightarrow B: E_{K_B}[K_s || ID_A]$
4. $B ightarrow A: E_{K_A}[N_2]$
5. $A ightarrow B: E_{K_s}[f[N_2]]$

The protocol has a drawback. If an opponent $(X)$ is able to compromise an old session key, then it can use Step 3, impersonate $A$, and trick $B$ into using the old session key. Now, if $X$ can intercept the Step 4 message, it can send the response of Step 5. Now, $X$ can send fraudulent messages to $B$, who in turn will consider the messages as coming from $A$. Denning proposed the inclusion of a time stamp in Step 2 and Step 3 to remove the weakness of the Needham Schroeder Protocol.

# 8.5.4 Denning Protocol

+   1. $A ightarrow KDC: ID_A || ID_B || N_1$
2. $KDC ightarrow A: E_{K_A}[K || ID_B || T || E_{K_B}[K || ID_A || T]]$
3. $A ightarrow B: E_{K_B}[K || ID_A || T]$
4. $B ightarrow A: E_{K_A}[N_1]$
5. $A ightarrow B: E_{K_s}[f[N_1]]$
