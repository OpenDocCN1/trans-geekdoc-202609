# 9.2 CENTRALIZED AUTHENTICATION SERVICE

In a distributed client-server environment like the Internet, a client can log-on, authenticate itself once, and then access many services without authenticating itself repeatedly. This is made possible by a centralized authentication service provided by KERBEROS. In Greek Mythology, KERBEROS means “Three-Headed Dog.”
