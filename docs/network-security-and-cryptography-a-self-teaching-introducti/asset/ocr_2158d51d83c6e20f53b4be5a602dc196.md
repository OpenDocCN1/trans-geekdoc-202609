# 4.7.8 Multiplication over GF (2ⁿ)

The multiplicative inverse of a polynomial $f(x) \mod m(x)$, that is $f(x)^{-1} \mod m(x)$, is determined by Euclid's Extended Algorithm:

```
Euclid(f(x),m(x)) = / $f(x)^{-1} \mod m(x)$ /
```

> /where $f(x)$ is a polynomial of degree $\le n-1$ /
/and $m(x)$ is irreducible polynomial of degree $n$ /

+   Step 1: $(A_1, A_2, A_3) \leftarrow (1,0,m(x)); (B_1, B_2, B_3) \leftarrow (0,1,f(x))$nStep 2: If $(B_3=0)$ then return $f(x)^{-1} \mod m(x)$ does not exist
Step 3: If $(B_3=1)$ then return $B_2 = f(x)^{-1} \mod m(x)$
Step 4: $Q=A_3$ DIV $B_3$
Step 5: $(T_1, T_2, T_3) \leftarrow (A_1-Q_1, A_2-Q_2, A_3-Q_3)$
Step 6: $(A_1, A_2, A_3) \leftarrow (B_1, B_2, B_3)$
Step 7: $(B_1, B_2, B_3) \leftarrow (T_1, T_2, T_3)$
Step 8: GOTO Step 2
