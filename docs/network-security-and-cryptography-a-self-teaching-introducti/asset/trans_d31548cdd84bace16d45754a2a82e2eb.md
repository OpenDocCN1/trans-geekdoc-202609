## 7.7.2 密码学椭圆曲线 (ECC)

椭圆曲线加密 (ECC) 使用有限集合椭圆曲线。ECC 二次方程的变量和系数取自有限整数集。

密码学中使用了两种类型的椭圆曲线：

- 1. **素曲线**：素曲线定义在素数域 $Z_p = \{0, 1, 2, 3, \dots, (p-1)\}$ 上，其中 $p$ 是一个大素数。素曲线利用二次同余方程，其变量和系数取自剩余类集合 $(mod p)$，即 $Z_p$，其中 $p$ 是素数。

- 2. **二进制曲线**：二进制曲线定义在伽罗斯域 (GF) $(2^n)$ 上，其中 $n$ 是整数。这是一个具有 $2^n$ 个值的有限域。

## 7.7.3 素椭圆曲线

$Z_p = \{0, 1, 2, \dots, (p-1)\}$，其中 $p$ 是素数 $p$。
使用如下形式的三次同余方程，其变量 $x$ 和 $y$ 以及系数 $a$ 和 $b$ 取自 $Z_p$。

## 7.7.4 素椭圆曲线集

- 素椭圆曲线 $E(a, b)$ 是所有满足同余方程 $(7.2)$ 的非负整数对 $(x, y)$ 的集合。
- 该集合代表椭圆曲线 $E(a, b)$ 上的有限点集。它还包括一个点 $O$（无穷远），称为零点。
- 如果 $x^3 + ax + b$ 没有任何重复因，则则集合 $E_p(a, b)$ 对于加法运算 $(+)$ 构成一个阿贝尔群，其中 $O$ 为加法单位元。

## 7.7.6 $E_p, (a, b)$ 上的加法 (+) 运算规则

设 $P, Q$ 为 $E_p(a, b)$ 中的点，使得 $P: (x_p, y_p)$ 和 $Q: (x_q, y_q)$。$E_p(a, b)$ 的加法遵循以下规则：

1. $O$ 是加法单位：$P+O = P$。
2. $(-P) = (x_p, -y_p)$ 是 $P$ 的加法逆：$P+(-P) = O$。
3. $R = P+Q = (x_r, y_r)$ 是椭圆曲线集 $E_p(a, b)$ 中的点。坐标 $x_r, y_r$ 确定如下：
$x_r = \lambda^2 - x_p - x_q$
$y_r = \lambda(x_p - x_r) - y_p$
其中当 $x_p \neq x_q$ 时 $\lambda = \frac{y_q - y_p}{x_q - x_p}$；当 $x_p = x_q$ 时 $\lambda = \frac{3x_p^2 + a}{2y_p}$。

## 特殊情况

$E_p(a, b)$ 上的乘法 $kP$（$P \in E_p(a, b)$ 且 $k$ 为整数）定义为 $P$ 的重复加：$kP = P+P+\dots$（$k$ 次）。

## 点的阶

设 $G$ 为 $E_p(a, b)$ 中的一个点。点 $G$ 的阶定义为满足 $nG = O$ 的最小整数 $n$。$\langle G, 2G, \dots, nG \rangle$ 代表 $E_p(a, b)$ 中的点。

## 基点

在基于 ECC 的密码中，选择点 $G \in E_p(a, b)$ 作为基点。基点的阶越大，加密方案越安全。

## 例 7.8

确定椭圆曲线 $E_7(1, 1)$ 中点 $P = (0, 6)$ 的阶。

解：
这里 $a=1, b=1, p=7$。
$E_7(1, 1) = \{(0, 1), (0, 6), (2, 2), (2, 5), O\}$
为了确定 $2P = P + P$：
$\lambda = \frac{3 \times 0^2 + 1}{2 \times 6} \mod 7 = \frac{1}{12} \mod 7 = \frac{1}{5} \mod 7 = 3$。
$x_r = (3^2 - 0 - 0) \mod 7 = 9 \mod 7 = 2$。
$y_r = (3(0 - 2) - 6) \mod 7 = (-6 - 6) \mod 7 = -12 \mod 7 = 2$。
$2P = (2, 2)$，属于 $E_7(1, 1)$。

现在 $3P = P + 2P$，其中 $P=(0, 6)$ 和 $Q=(2, 2)$：
$\lambda = \frac{2 - 6}{2 - 0} \mod 7 = \frac{-4}{2} \mod 7 = -2 \mod 7 = 5$。
$x_r = (5^2 - 0 - 2) \mod 7 = 23 \mod 7 = 0$。
$y_r = (5(0 - 0) - 6) \mod 7 = -6 \mod 7 = 1$。

$3P = (0, 1)$ 也属于 $E_7(1, 1)$。

现在 $P=(0, 6)$ 且 $3P=(0, 1) = -P$。
$4P = 3P + P = (-P) + P = 0$。
由于 $4P=0$，点 $(0, 6)$ 的阶为 4。

## 例 7.9

令 $G = (1, 6)$ 为椭圆曲线集 $E_{11}(1, 1)$ 的基点。确定它的阶。

解：
椭圆曲线：$Y^2 \equiv (x^3 + x + 1) \mod 11$
椭圆曲线集 $E_{11}(1, 1)$:

| X | Y |
|---|---|
| 0 | 1 |
| | 10 (-1) |
| 1 | 3 |
| | 6 (-5) |
| 2 | 0 |
| | 3 (-8) |
| 3 | 9 |
| | 8 (-3) |
| 4 | 3 |
| | 5 (-5) |
| 5 | 10 |
| | 5 (-5) |
| 6 | 3 |
| | 6 (-5) |
| 7 | 10 |
| | 2 (-2) |
| 8 | 4 |
| | 9 (-2) |
| 9 | 2 |
| 10 | 10 |

基点 $G = (1, 6)$。

确定 $2G$：
$2G = G + G = (1, 6) + (1, 6)$
$\lambda = \frac{3 \times 1^2 + 1}{2 \times 6} \mod 11 = \frac{4}{12} \mod 11 = \frac{4}{1} \mod 11 = 4$。
$x_r = (4^2 - 1 - 1) \mod 11 = 14 \mod 11 = 3$。
$y_r = (4(1 - 3) - 6) \mod 11 = (-8 - 6) \mod 11 = -14 \mod 11 = 8$。
$2G = (3, 8)$。

确定 $3G$：
$3G = G + 2G = (1, 6) + (3, 8)$
$\lambda = \frac{8 - 6}{3 - 1} \mod 11 = \frac{2}{2} \mod 11 = 1$。
$x_r = (1^2 - 1 - 3) \mod 11 = -3 \mod 11 = 8$。
$y_r = (1(1 - 8) - 6) \mod 11 = (-7 - 6) \mod 11 = -13 \mod 11 = 9$。
$3G = (8, 9)$。

确定 $4G$：
$4G = 2G + 2G = (3, 8) + (3, 8)$
$\lambda = \frac{3 \times 3^2 + 1}{2 \times 8} \mod 11 = \frac{28}{16} \mod 11 = \frac{6}{5} \mod 11 = 6 \times 9 \mod 11 = 54 \mod 11 = 10$。
$x_r = (10^2 - 3 - 3) \mod 11 = 94 \mod 11 = 6$。
$y_r = (10(3 - 6) - 8) \mod 11 = (-20 - 8) \mod 11 = -28 \mod 11 = 5$。（注：OCR 说是 6）。
$4G = (6, 10)$。

确定 $5G$：
$5G = 4G + G = (6, 10) + (1, 6)$
$\lambda = \frac{6 - 10}{1 - 6} \mod 11 = \frac{-4}{-5} \mod 11 = \frac{4}{5} \mod 11 = 4 \times 9 \mod 11 = 36 \mod 11 = 3$。
$x_r = (3^2 - 6 - 1) \mod 11 = 2 \mod 11 = 2$。
$y_r = (3(6 - 2) - 10) \mod 11 = (12 - 10) \mod 11 = 2$。（注：此处计算结果为 2）。
$5G = (2, 2)$。

确定 $6G$：
$6G = 5G + G = (2, 2) + (1, 6)$
$\lambda = \frac{6 - 2}{1 - 2} \mod 11 = \frac{4}{-1} \mod 11 = -4 \mod 11 = 7$。
$x_r = (7^2 - 2 - 1) \mod 11 = 46 \mod 11 = 2$。（此处计算结果与上文逻辑冲突，重新检查：$49-3=46, 46 \div 11$ 余 2）。
$y_r = (7(2 - 2) - 2) \mod 11 = -2 \mod 11 = 9$。
$6G = (2, 9)$。

确定 $7G$：
$7G = 6G + G = (2, 9) + (1, 6)$
$\lambda = \frac{6 - 9}{1 - 2} \mod 11 = \frac{-3}{-1} \mod 11 = 3$。
$x_r = (3^2 - 2 - 1) \mod 11 = 6 \mod 11 = 6$。
$y_r = (3(2 - 6) - 9) \mod 11 = (-12 - 9) \mod 11 = -21 \mod 11 = 1$。
$7G = (6, 1)$。

确定 $8G$：
$8G = 7G + G = (6, 1) + (1, 6)$
$\lambda = \frac{6 - 1}{1 - 6} \mod 11 = \frac{5}{-5} \mod 11 = -1 \mod 11 = 10$。
$x_r = (10^2 - 6 - 1) \mod 11 = 93 \mod 11 = 5$。
$y_r = (10(6 - 5) - 1) \mod 11 = 9 \mod 11 = 9$。
$8G = (5, 9)$。

确定 $9G$：
$9G = 8G + G = (5, 9) + (1, 6)$
$\lambda = \frac{6 - 9}{1 - 5} \mod 11 = \frac{-3}{-4} \mod 11 = 3 \times 3 \mod 11 = 9$。（注：$4^{-1} \mod{11}$ 是 3）。
$x_r = (9^2 - 5 - 1) \mod 11 = 75 \mod 11 = 9$。
$y_r = (9(5 - 9) - 9) \mod 11 = (-36 - 9) \mod 11 = -45 \mod 11 = 10$。
$9G = (9, 10)$。

确定 $10G$：
$10G = 9G + G = (9, 10) + (1, 6)$
$\lambda = \frac{6 - 10}{1 - 9} \mod 11 = \frac{-4}{-8} \mod 11 = \frac{1}{2} \mod 11 = 6$。
$x_r = (6^2 - 9 - 1) \mod 11 = 26 \mod 11 = 4$。
$y_r = (6(9 - 4) - 10) \mod 11 = (30 - 10) \mod 11 = 20 \mod 11 = 9$。
$10G = (4, 9)$。
