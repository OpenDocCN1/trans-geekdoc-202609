The covariance of $X(t)$ and $Y(t)$ is given by

```
$C_{XY}(t_1, t_2) = E[X(t_1) - m_x(t_1)][Y(t_2) - m_y(t_2)] = R_{XY}(t_1, t_2) - m_x(t_1)m_y(t_2) \quad (2.109)$
```

Just like random variables, random processes $X(t)$ and $Y(t)$ are uncorrelated if

```
$C_{XY}(t_1, t_2) = 0 \quad$ for all $t_1$ and $t_2$ \quad (2.110)$
```

which implies that

```
$R_{XY}(t_1, t_2) = m_x(t_1)m_y(t_2) \quad$ for all $t_1$ and $t_2$ \quad (2.111)$
```

Finally, for ergodic random processes $X(t)$ and $Y(t)$,

```
$R_{XY}(\tau) = \lim_{T\to\infty} \frac{1}{2T} \int_{-T}^{T} x(t)x(t+\tau)dt = R_{XY}(\tau) \quad (2.113)$
```

Thus, two random processes $X(t)$ and $Y(t)$ are:

+   1. **Independent** if their joint PDF factors;
2. **Orthogonal** if $R_{XY}(t_1, t_2) = 0$ for all $t_1$ and $t_2$; and
3. **Uncorrelated** if $R_{XY}(t_1, t_2) = m_x(t_1)m_y(t_2)$ for all $t_1$ and $t_2$.
