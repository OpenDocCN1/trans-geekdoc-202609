# Solution

As an M/M/1 queue, we obtain the mean arrival rate as

$\lambda = 1$ customer/minute

and the mean service rate as

$E(S) = \frac{1}{\mu} = 50$ seconds/customer = $\frac{50}{60} = \frac{5}{6}$ minute/customer

Hence, the traffic intensity is

$ho = \frac{\lambda}{\mu} = (1)(50/60) = \frac{5}{6}$

# A. The mean queue size

$E[N_q] = \frac{ho^2}{1-ho} = \frac{(5/6)^2}{1-5/6} = \frac{0.694}{0.167} = 4.156$ customers

# B. The mean waiting time is

$E[W] = \frac{ho}{\mu(1-ho)} = \frac{5/6(5/6)}{1-5/6} = 4.158$ minutes

# C. If the mean service time $E(S) = 55$ seconds/customer = $55/60$ minutes/customer, then

$ho = \frac{\lambda}{\mu} = (1)(55/60) = 0.917$$

$E[N_q] = \frac{ho^2}{1-ho} = \frac{(55/60)^2}{1-55/60} = \frac{0.840}{0.083} = 10.120$ customers

$E[W] = \frac{ho}{\mu(1-ho)} = \frac{55/60(55/60)}{1-55/60} = \frac{0.840}{0.083} = 10.120$ minutes

We expect the queue size and waiting time to increase if it takes a longer time for customers to be served.
