5. $Ticket_{igs}$: The ticket issued by $TS$ to enable client $C$ to approach server $TGS$. It is encrypted using key $K_{igs}$, which is shared between AS and $TGS$ so that the client cannot alter the ticket; only $TGS$ can decrypt it successfully. The ticket is reusable during a session or until its life expires, whichever is earlier; thus, $C$ can use the ticket repeatedly for obtaining permission from $TGS$ to access the required application servers.

# The Ticket $Ticket_{igs}$ contains the following information:

+   1. $K_e$: The session key to be shared between Client $C$ and $TGS$.
2. $ID_e$: Identification of Client $C$.
3. $AD_e$: Network Address (IP Address) of Client workstation, from message 1 was received.
4. $ID_e$: Identification of $TGS$ itself, $TGS$ to assure that the token has been decrypted successfully.
5. $TS_e$: Timestamp to assure $TGS$ that it is not a replay Ticket.
6. $Lifetime_e$: Ticket's Lifetime.
