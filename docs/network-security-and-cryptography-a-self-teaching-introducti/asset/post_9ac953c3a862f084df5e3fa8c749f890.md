
## 4.5 EUCLID’S ALGORITHM TO DETERMINE GCD

- Let $a$ and $b$ be two integers.
- The Greatest Common Div (GCD) of $a$ and $b$, denoted by GCD $(a,b)$, is defined as a positive integer $c$ that satisfies the following two conditions:
  1. $c$ should be a divisor of both $a$ and $b$.
  2. Any divisor of $a$ and $b$ should also be divisor of $c$.
- Alternatively, $GCD(a,b)$ can be defined as:
  $GCD(a,b) = \max(k, \text{such that } k|a \text{ and } k|b)$
  $GCD(a,b) = GCD(a,-b) = GCD(-a,-b)$
- Thus, $GCD(a,b) = GCD(|a|,|b|)$
- Also, $GCD(a,0)=|a|$, since all non-zero integers are divisors of 0.
- Since $GCD(a,b)$ is independent of the sign of $a$ and $b$, we restrict our discussion to the GCD of positive integers only.

### Algorithm
GCD(a,b) for $a > b \ge 0$

Step 1: $A \leftarrow a; B \leftarrow b$
Step 2: If $B=0$ then return $A = GCD(a,b)$
Step 3: $R = A \text{ mod } B$
Step 4: $A \leftarrow B$
Step 5: $R \leftarrow B$
Step 6: go to 2

### Example 4.13
Compute GCD (1044, 216).

### Solution
Table 4.9 demonstrates the computational of GCD (1044, 216) as follows:

Table 4.9 Computation of GCD (1044, 216)

| A | B | R = A mod B |
|---|---|---|
| 1044 | 216 | 180 |
| 216 | 180 | 36 |
| 180 | 36 | 0 |
| 36 | 0 | - |

When B = 0, A = 36. Therefore, GCD (1044, 216) = 36.

## 4.6 EXTENDED EUCLID'S ALGORITHM

- The Extended Euclid's Algorithm is used to determine the Multiplicative Inverse of a positive integer $x$ modulus $m$, that is, $x^{-1} (\bmod m)$ to exist, $GCD(x,m)$ must be equal to one, that is, $x$ and $m$ must be relatively prime to each other.

### Pseudo Algorithm
Determine\_Mult\_Inv(x,m) /* Determine $x_1 \bmod m$*/

Step 1: $(A_1, A_2, A_3) \leftarrow (1, 0, m); (B_1, B_2, B_3) \leftarrow (0, 1, x)$
Step 2: If $(B_3 = 0)$ then Return $A_3 = \text{GCD}(b, m); x^{-1} \bmod m$ does not exist
Step 3: If $(B_1 = 1)$ then Return $B_3 = \text{GCD}(b, m); B_2 = x^{-1} \bmod m$
Step 4: $Q = A_3 \text{ DIV } B_3$
Step 5: $(T_1, T_2, T_3) \leftarrow (A_1 - QB_1, A_2 - QB_2, A_3 - QB_3)$
Step 6: $(A_1, A_2, A_3) \leftarrow (B_1, B_2, B_3)$
Step 7: $(B_1, B_2, B_3) \leftarrow (T_1, T_2, T_3)$
Step 8: GOTO Step 2

**Proof:**
At all the stages in the above algorithm, the following will hold:
$mA_1 + xA_2 = A_1$
$mB_1 + xB_2 = B_3$
$mT_1 + xT_2 = T_3$

Now, when $B_3 = 1$
Then $mB_1 + xB_2 = 1$
$\cdot xB_2 = 1 - mB_1 \quad (\cdot \text{Sign means therefore})$
$=1 + (-B_1)m$
$\cdot xB_2 = 1 \bmod m$
$\cdot B_2 = x^{-1} \bmod m$

Thus, the Extended Euclid Algorithm stands proven.

## 4.7 GALOIS FINITE FIELDS

The Galois Fields are named in honor of mathematician Évariste Galois, who invented the finite fields. There are two kinds of Galois Fields:

- Galois Fields of order $p^n$ denoted as $GF(p^n)$, where $p$ is a prime number and $n$ is a positive integer. A special case that is of interest from a cryptography point of view where $n=1$, that is, $GF(p)$ where order of the finite field is $p$.
- Galois Fields of order $2^n$ denoted as $GF(2^n)$ where $n$ is a positive integer.

### 4.7.1 GF($p$):
$Z_p = \{0,1,2,3,...p-1\}$ is a Galois Field of order $p$, where $p$ is a prime number.
Proof: For each integer $n$, the set residue (mod p) forms an integral domain of size $n$. But $Z_p$ may not be a field, since a multiplicative inverse exists only for those elements of $Z_p$ that are relatively prime to $p$. But all elements in $Z_p$ (except 0) are relatively prime to $p$. Therefore, multiplicative inverses (mod p) exist for all elements of $Z_p$ (except 0). Thus, $Z_p$ satisfies all the properties of a Field.

### 4.7.2 Set $Z_p$:
$Z_p = \{1,2,3,4,...p-1\}$ is set of residues (excluding 0) where $p$ is a prime number. Each element in $Z_p$ has its unique multiplicative inverse (mod p).

### 4.7.3 Galois Finite Fields of Order $2^n$
- A Galois Field $GF(2^n)$ is a finite field of order $2^n$. It comprises $2^n$ distinct integers.
- There exists $2^n$ distinct polynomials of degree $\le n-1$ that are used to represent the integers in the $GF(2^n)$.
