#  7.5.2 Global Parameters

The Diffie-Hellman Key Exchange Algorithm makes use of two global parameters that are made public among the users:

+   1. A large prime number $p$ and

+   2. A primitive root $g$ of $p$.

If two “A” and “B” wish to exchange a secret key, they proceed as follows:

User A:

+   1. Chooses a random number $X_A$ ($0 < X_A < \Phi(p)$)

+   2. Computes $Y_A = g^{X_A} \bmod p$

+   3. Keeps $X_A$ secret and transmits $Y_A$ to User “B.”

On receiving the message from “A,” User “B” responds as follows:

User B:

+   4. Chooses a random number $X_B$ ($0 < X_B < p - 1$)

+   5. Computes $Y_B = g^{X_B} \bmod p$

+   6. Keeps $X_B$ secret and transmits $Y_B$ to use “A.”

User A:

+   7. Now user “A” computes the key $K_A = (Y_B)^{X_A} \bmod p$

+   8. Similarly, user “B” computes the key $K_B = (Y_A)^{X_B} \bmod p$
