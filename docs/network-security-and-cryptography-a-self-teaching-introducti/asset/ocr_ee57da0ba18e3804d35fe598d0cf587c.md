Whenever a user logs on at a workstation by entering its user ID and requests a service on the Internet, the client module $C$ on the user’s workstation performs the following sequence of authentication dialogue with the Kerberos Servers:

**Message (1): Request Ticket-Granting Ticket:** This message is sent by the Client Module $C$ to the Authentication Server (AS). By this message, the Client Module $C$ requests AS on behalf of the User, for granting a “Ticket-Granting-Ticket.” The “Ticket” is required to authenticate the user to the server TGS.

```
$C\toAS: ID_C \| ID_{tgs} \| TS_1$
```
