# 6.5.4 DES Decryption Algorithm

The DES decryption uses the same algorithm as encryption except that the application is in the reverse order. The cipher-text generated by the application is input to round 1 of the decryption algorithm, which gets sub-key $K_{16}$ as input. Any round $i$ of the decryption algorithm gets sub-key $K_{17-i}$ as input. Thus, round 16 of the decryption algorithm gets sub-key $K_1$ as input. The output of round 16 will be the original plaintext that generated the cipher-text.

# 6.6 AVALANCHE

A desirable property of any Encryption Algorithm is that a small change in either the Plaintext or the Key should produce a significant change in the Ciphertext, so that the space of possible plaintexts and Keys that an adversary should need for an attempted cipher-break would be very large. In fact, for a one-bit change in the plaintext or key, many bits should change in the cipher-text. This effect is called the *Avalanche Effect*. In DES, if two inputs to an S-box differ by exactly one, the outputs must differ in at least two bits.

# Plaintext – Cipher-Text Transformations in DES

+   - Plaintext/Cipher-text Block Size in DES = 64 bits
- Therefore, size of Plaintext Space = $2^{64}$
- And size of Cipher-text Space = $2^{64}$
- Let us denote the Plaintext space by set X and the cipher-text space by set Y.

+   - For a given key $K$, the transformation from Plaintext Space to Ciphertext Space will be one-to-one, that is, reversible.
- This implies that for each plaintext pair $(P_1, P_2)$ belonging to set $X$ that $P_1 
eq P_2$, there will be cipher-texts $C_1 = E_K[P_1]$ and $C_2 = E_K[P_2]$ belonging to set $Y$ that will satisfy $C_1 
eq C_2$, and for each cipher-pair $(C_1, C_2)$ belonging to set $Y$ that $C_1 
eq C_2$, there will be plain-texts $P_1 = D_K[C_1]$ and $P_2 = D_K[C_2]$ belonging to set $X$ that will satisfy $P_1 
eq P_2$.
