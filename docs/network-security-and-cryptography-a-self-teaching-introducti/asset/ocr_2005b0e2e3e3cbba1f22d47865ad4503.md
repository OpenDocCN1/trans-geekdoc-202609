# Where

+   $PR_a$: Public Key of the sender “A"
H$H$: Hash function using SHA that generates 160-bit message digest
EP: Public key encryption using $DSS$ or $RSA$
$\circledR$: Pre-pending of Digital Signature $E_{PR_a}[H(M)]$ to message $M$
$Z$: Zip compression
$R64$: Radix-64 Transformation
SEG: Segmentation to segments of length $\le 50,000$ bytes
Reass: Reassembly of message segments
$R64^{-1}$: Inverse of $R64$ Transformation
$Z^{-1}$: ZIP Decompression
DP: Decryption of signature using public key $PU_a$ of the sender
