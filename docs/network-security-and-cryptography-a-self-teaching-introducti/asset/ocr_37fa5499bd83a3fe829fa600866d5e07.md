# Example 6.1

Prove that decryption is the reverse of encryption.

# Solution

Plaintext input to Encryption $LE_0 \parallel RE_0$,

Encryption

Input to Round 1: $LE_0 \parallel RE_0$,

Output of Round 1:

```
$LE_1 = RE_0$
RE_1 = LE_0 \oplus F(RE_0, K_1)$
```

Output of Round i:

```
$L_i = RE_{i-1}$
RE_i = LE_{i-1} \oplus F(RE_{i-1}, K_i)$
```

Output of Round 16:

```
$LE_{16} = RE_{15}$
RE_{16} = LE_{15} \oplus F(RE_{15}, K_{16})$
```

Decryption

Input of Round 1:

```
$RD_0 = LE_{16} = RE_{15}$
LD_0 = LE_{16} \oplus F(RE_{15}, K_{16})$
```

Output of Round 1:

```
$LD_1 = RD_0 = RE_{15}$
LD_1 = LD_0 \oplus F(RD_0, K_{16})$n$= LD_0 \oplus F(RE_{15}, K_{16})$n$= LE_{15} \oplus F(RE_{15}, K_{16}) + F(RE_{15}, K_{16})$
$= LE_{15}$
```

Output of Round i:

```
$LD_i = RE_{16-i}$
LD_1 = LE_{16-i}$
```
