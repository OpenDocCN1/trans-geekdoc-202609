# Encryption of OFB

The Encryption Algorithm is identical to the Cipher Feedback (CFB)
Mode:

First Step (for $P_i$)

Let $S_i(X)$ be defined as the most significant $s$ bits of shift register $X$
$C_i = P_i \oplus S_i(E_k(IV))$

For Subsequent Steps (for Plaintext Block $P_i$)
Let $X_{i-1}$ be the contents of the shift Register after Step $i-1$
$C_i = P_i \oplus S_i(E_k(X_{i-1}))$

# Decryption of OFB

The decryption algorithm of OFB is exactly the same as the decryption
algorithm of the CFB Mode:

First Step (for Cipher-text $C_i$)

$S_i(X)$ : Most significant $s$ Bits of shift register $X$
Plaintext = $C_i \oplus S_i(E_k(IV))$
$= P_i \oplus S_i(E_k(IV)) \oplus S_i(E_k(IV)) = P_i$

First Subsequent Steps (for Cipher-text $C_i$)

Plaintext = $C_i \oplus S_i(E_{i-1}(IV)) \oplus S_i(E_{i-1}(IV)) = P_i$

# 6.7.4.4.2 Advantages and Limitations of OFB

# The advantages of OFB are:

+   Like CFB, OFB mode is also suitable for a stream cipher, and thus has
the following advantages of a stream cipher:

+   It eliminates requirement of padding, whereas in the Block Cipher
t last block may need padding.

+   Each Character of plaintext can be encrypted and transmitted when
ready. On the other end, each character can be decrypted and used
immediately upon reception. Thus, this mode is suitable for real-time
applications.
