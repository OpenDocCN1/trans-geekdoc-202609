# 7.7.3 Prime Elliptic Curves

$Z_p = \{0, 1, 2, \dots, (p-1)\}$ where $p$ is a prime number $p$.$
A cubic congruence of the following form is used, whose variables $x$ and $y$ and coefficients $a$ and $b$ draw their values from $Z_p$.

# 7.7.4 Prime Elliptic Curve Set

+   - A Prime Elliptic Curve $E(a, b)$ is the set of all $(x, y)$ pairs of non-negative integers that satisfy the congruence $(7.2)$.
- The set represents a finite set of points occurring on the Elliptic Curve $E(a, b)$. It also includes $p$ point $O$ (at infinity), called the zero point.
- If $x^3 + ax + b$ does not have any repeated factor, then the set $E_p(a, b)$ forms an Abelian Group with respect to addition $(+)$ operation, with $O$ as an Additive Identity Element.

# Example 7.7

Let us consider an elliptic curve defined by the equation:
$Y^2 \equiv (x^3 + x + 1) \mod 11$

| $Y$ | $Y^2 \mod 11$ |

| 1 | 1 |
| 2 | 4 |

Here $p = 11, a = 1, b = 1$.
