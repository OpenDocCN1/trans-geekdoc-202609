To prove this, suppose in an experiment with $n$ trials, event $A$ occurs $n_A$ times, while event $B$ occurs $n_B$ times. Then event $A$ or $B$ occurs $n_A + n_B$ times, and

```
$P(A \text{ or } B) = \frac{n_A + n_B}{n} = \frac{n_A}{n} + \frac{n_B}{n} = P(A) + P(B) \quad (2.7)$
```

This result can be extended to the case when all events in an experiment are $A

```
$n_A + n_B + n_C + \dots + n_Z = n$
```

Dividing by $n$ and assuming $n$ is large, we obtain

```
$P(A) + P(B) + P(C) + \dots + P(Z) = 1 \quad (2.8)$
```

which indicates that the probabilities of mutually exclusive events must add up to unity. A special case of this is when two events are complimentary, that is, if event $A$ occurs $B$ must not occur, and vice versa. In this case,

```
$P(A) + P(B) = 1 \quad (2.9)$
```

or

```
$P(A) = 1 - P(B) \quad (2.10)$
```

For example, in tossing a coin, the event of a head appearing is complementary to that of a tail appearing. Since the probability of either event is $\frac{1}{2}$, their probabilities add up to 1.

The sum of the probability of any event A and its complement must be equal to 1, that is,

```
$P(A) + P(\overline{A}) = 1 \quad (2.11)$
```

Or

```
$P(\text{not } A) = P(\overline{A}) = 1 - P(A) \quad (2.12)$
```
