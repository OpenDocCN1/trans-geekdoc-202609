# 2.13.3 Birth-and-Death Processes

Birth-death processes describe the stochastic evolution in time of a random variable value increases or decreases by one in a single event. These are discrete-space Markov processes in which the transitions are restricted to neighboring states only. A typical example is shown in Figure 2.14. For example, the number of jobs in a queue with a single server and the individual arrivals can be represented as a birth-death process. An arrival to the queue (birth) causes the state to change by +1, while a departure (death) causes the state to change by -1. Although the birth-death processes are used in modeling population, they are useful in the analysis of communication networks. They are also used in physics, sociology, and economics.
