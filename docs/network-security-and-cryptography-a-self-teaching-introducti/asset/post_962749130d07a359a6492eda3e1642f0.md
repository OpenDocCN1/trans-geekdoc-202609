
# Example 4.10

Prove that $[(a \bmod n) + (b \bmod n)] \bmod n=(a+b) \bmod n$

# Solution

Let $a = kn + r_a$, where $k$ is some integer and $r_a$ is the remainder; $b = tn + r_b$, where $t$ is some integer and $r_b$ is the remainder.

By definition $r_a = a \bmod n$ and $r_b = b \bmod n$.

```
$(a+b) \bmod n = (kn + r_a + tn + r_b) \bmod n
```

```
=[(k+t)n + r_a + r_b] \bmod n
```

```
$(r_a + r_b) \bmod n$, since $[(k+t)n] \bmod n = 0
```

```
$(a \bmod n + b \bmod n) \bmod n
```

Thus, $[(a \bmod n) + (b \bmod n)] \bmod n = (a+b) \bmod n$.
Similarly, we can have proof of other properties of modular arithmetic.

## 4.3.1 Residue Classes (mod $n$)

The $n$ operator maps all integers onto the finite set $\{0,1,...,(n-1)\}$.
Let us denote this set as $Z_n$, that is, the set of non-negative integers less than $n$.

```
$Z_n = \{0,1,...,(n-1)\}$.
```

This set is also known as the *Set of Residues* (mod $n$) or *Residue Classes* (mod $n$).

Each integer in $Z_n$ represents a Residue Class (mod $n$).
We can label the Residue Classes Modulo $n$ as:

- [0] = {...,-2n, -n, 0, n, 2n,...}
- [1] = {...,-2n+1, -n+1, 1, n+1, 2n+1,...}
- [2] = {...,-2n+2, -n+2, 2, n+2, 2n+2,...}

And so on ...

## Example 4.11

The Residue Classes (mod n) are:

```
[0] = {..., -8, -4, 0, 4, 8, ...}
[1] = {..., -7, -3, 1, 5, 9, ...}
[2] = {..., -6, -2, 2, 6, 10, ...}
[3] = {..., -5, -1, 3, 7, 11, ...}
```

Thus, of all the integers in a Residue Class, the smallest positive integer represents the modulo class.

## 4.3.2 Properties of $Z_n$

The properties of $Z_n$ are summarized in Table 4.1.

| TABLE 4.1 Properties of $Z_n$ | Property | Expression |
| :--- | :--- | :--- |
| Commutative Laws | $(w + x) \bmod n = (x + w) \bmod n$; $(w \times x) \bmod n = (x \times w) \bmod n$ |
| Associative Laws | $[(w + x) \bmod n+y] \bmod n = [w (x+y) \bmod n] \bmod n$; $[(w \times x) \bmod n y] \bmod n = [w (x \times y) \bmod n] \bmod n$ |
| Distributive Laws | $[w(x+y) \bmod n = [(w \times x) \bmod n+(w \times y) \bmod n] \bmod n$ |
| Identities | $(0+w) \bmod n = w \bmod n$; $(1 \times w) \bmod n = w \bmod n$ |

Additive Inverse: For each $w$ in $Z_n$, there exists an additive inverse of $w$ such that $(w + x) = 0 \bmod n$.

Multiplicative Inverse: For $w$ in $Z_n$, if $w$ is relatively prime to $n$, then there exists a multiplicative inverse of $w$ such that $(w \times x) = 1 \bmod n$.

## Thus $Z_n$ forms an Integral Domain.

## 4.3.3 Multiplication within Set $Z_n$

- $Z_n = \{0, 1, ..., (n-1)\}$
- Let $K$ be any integer from the set $Z_n$.
- If all elements of $Z_n$ are multiplied by $K$, we get a set $L$ of $n$ integers.
- If $K$ is relatively prime to $n$, then the set $L$ will be a permutation of $Z_n$ and the multiplication within the set will be reversible, as demonstrated:

Let $K=5$ and $n=8$.
$Z_n = \{0, 1, 2, 3, 4, 5, 6, 7\}$
$L = (KX) \pmod 8 = (0, 5, 2, 7, 4, 1, 6, 3)$, for $J=0...7$.

Each element of $Z_n$ appears only once in $L$. Thus, set $L$ is a permutation of $Z_n$. Mapping from $Z_n$ to set $L$ for $K=5$ and $n=8$ is indicated as follows in Table 4.5:

TABLE 4.5 Mapping from $Z_n$ to Set $L$ for $K=5$ and $n=8$

| Set $Z_n$ | Set $L$ |
| :--- | :--- |
| 0 | 0 |
| 1 | 5 |
| 2 | 2 |
| 3 | 7 |
| 4 | 4 |
| 5 | 1 |
| 6 | 6 |
| 7 | 3 |

In this case reverse transformation from set $L$ to set $Z_n$ is feasible, shown in Table 4.6 as follows:

TABLE 4.6 Reverse Transformation from Set $L$ to Set $Z_n$

| Set $L$ | Set $Z_n$ |
| :--- | :--- |
| 0 | 0 |
| 1 | 5 |
| 2 | 2 |
| 3 | 7 |
| 4 | 4 |
| 5 | 1 |
| 6 | 6 |
| 7 | 3 |

Thus, the multiplication of $Z_n$ elements, with an integer relatively prime to $n$, is reversible. If $K$ is not relatively prime to $n$ then set $L$ will be a subset of $Z_n$, and the multiplication will not be reversible. Some of the elements of $Z_n$ will appear repetitively in $L$ as demonstrated in the following:

Take $K=4$ and $n=8$.
$Z_s = \{0, 1, 2, 3, 4, 5, 6, 7\}$
$L = (KX) \bmod 8 = (0, 4, 4, 0, 4, 0, 4, 0)$, for $J=0...7$.

Set $L$ has only two elements of $Z_s$, that is, 0 and 4, which are repeated again and again. Mapping from set $Z_s$ to set $L$ for $K=4$ and $n=8$ is indicated as follows Table 4.7:

TABLE 4.7 Mapping from Set $Z_s$ to Set $L$ for $K=4$ and $n=8$

| Set $Z_s$ | Set $L$ |
| :--- | :--- |
| 0 | 0 |
| 1 | 4 |
| 2 | 0 |
| 3 | 4 |
| 4 | 0 |
| 5 | 4 |
| 6 | 0 |
| 7 | 4 |

In this case reverse transformation back to $J$ is not feasible, as demonstrated as follows in Table 4.8:

TABLE 4.8 Reverse Transformation from Set $L$ to Set $Z_s$

| Set $L$ | Set $Z_s$ |
| :--- | :--- |
| 0 | 0 or 2 or 4 or 6 |
| 4 | 1 or 3 |
