In order to find the probability of $k$ successes in $n$ trials, we first define different ways of combining $k$ out of $n$ things, which is

```
$C_k^n = \left(\frac{n!}{k!(n-k)!}ight) \quad (2.47)$
```

Note that $\left(inom{n}{k}ight) = \left(inom{n}{n-k}ight)$. Hence, the probability of having $k$ successes in $n$ trials is

```
$P(k) = \left(inom{n}{k}ight) p^k (1-p)^{n-k} \quad (2.48)$
```

since there are $k$ successes with probability $p$ and $n-k$ failures each with probability $q=1-p$ and all the trials are independent of each other. If we let $x=k$, where $k=0, 1, 2, \dots, n$, the PDF of the Binomial random variable X is

```
$f_x(x) = \sum_{k=0}^n P(k)\delta(x-k) \quad (2.49)$
```

From $f_x(x)$, we can obtain the mean and variance for X as

```
$E(X) = np \quad (2.50a)$
```

```
$Var(X) = npq(1-p) \quad (2.50b)$
```

# 2.4.3 Geometric Distribution

The geometric distribution is related to Bernoulli trials. A geometric random variable represents the number of Bernoulli trials required to achieve the first success. Thus, a random variable X has a geometric distribution if it takes the values of $1, 2, 3, \dots$ with probability

```
$P(k) = pq^{k-1}, \quad k=1, 2, 3, \dots \quad (2.51)$
```

where $p$ = probability of success $(0 < p < 1)$ and $q=1-p$ = probability of failure. This forms a geometric sequence so that

```
$\sum_{k=1}^\infty pq^{k-1} = \frac{p}{1-q} = 1 \quad (2.52)$
```
