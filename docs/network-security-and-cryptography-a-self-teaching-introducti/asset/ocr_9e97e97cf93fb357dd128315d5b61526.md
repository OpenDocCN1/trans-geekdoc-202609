# 4.9 EULER'S TOTIENT FUNCTION

Euler's Totient Function $\phi(n)=(p-1)(q-1)$ of a positive integer $n$ is defined as the number of non-negative integers less than $n$ and relatively prime to $n$.

For a prime $p$, $\phi(n)=p-1$, since all positive integers less than $p$ will be relatively prime to $p$.

# Example 4.22
