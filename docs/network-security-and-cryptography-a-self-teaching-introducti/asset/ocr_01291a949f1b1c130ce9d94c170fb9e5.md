The effectiveness of this model can be obtained in the usual manner. The probability that an arriving customer joins the queue is

```
$Prob[queueing=P_o = \sum_{n=k}^{\pi} \frac{\pi_n k^n\rho^n}{n!}] = \frac{p_o(k\rho)^k}{k!} \sum_{n=k}^{\infty} \rho^{n-k} = \frac{k^k\rho^k}{k!} \left( \frac{P_o}{1-\rho} \right)$
```

or

```
$P_o = \frac{k^k\rho^k}{k!} \left( \frac{P_o}{1-\rho} \right) \quad (2.173)$
```

This formula is known as Erlang's C formula. It is widely used in telephony; it gives the probability that no trunk (or server) is available for an arriving call.
