# 5.2.2 Mono-Alphabetic Cipher

In the mono-alphabetic cipher, each plaintext letter is mapped onto a cipher-text letter. To make the encryption process reversible, the mapping from plaintext alphabets to cipher-text alphabets is one-to-one, that is, mapping is unique both ways. To implement this scheme, a look-up table is created defining the mapping from plaintext alphabets to cipher-text alphabets, and that table acts as a key for encryption and decryption. The table is kept confidential between the sender and the intended recipients. Table 5.2 may form the encryption/decryption key:

Table 5.2 Encryption/Decryption key

| Plaintext Alphabet | Cipher-Text Alphabet | Plaintext Alphabet | Cipher-Text Alphabet |

| B | J | O | D |
| C | N | P | I |
| D | A | Q | W |
| E | C | R | L |
| F | K | S | Q |
| G | S | T | O |
| H | F | U | Z |
| I | B | V | M |
| J | H | W | Y |
| K | U | X | T |
| L | V | Y | R |
| M | P | Z | X |

The mapping between plaintext and cipher-text alphabets is one-to-one. For example, the letter “C” in plaintext maps only to the letter “N” in cipher-text, and the letter “N” in cipher-texts maps only to the letter “C” in plaintext.
