# Example 4.46

Solve the following simultaneous congruence using the Chinese Remainder Theorem:

+   $X = 3 \mod 5$
$X = 2 \mod 7$
$X = 1 \mod 3$

# Solution

$m_1 = 5, m_2 = 7, m_3 = 3$\n$a_1 = 3, a_2 = 2, a_3 = 1$\n$m = m_1 \times m_2 \times m_3 = 5 \times 7 \times 3 = 105$\n$M_1 = m / m_1 = 21$\n$M_2 = m / m_2 = 15$\n$M_3 = m / m_3 = 35$

Since $GCD(M_1, m_1) = 1$\n$M_1 y_1 = 1 \mod m_1$, where $y_1$ is the multiplicative inverse of $M_1 (\mod m_1)$.
