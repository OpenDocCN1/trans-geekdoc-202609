# 8.8.3.6 Determination of Keys by the Authorized Signer

Let private key be x = 3

Then Public $y = g^x \mod p = 4^3 \mod 23 = 64 \mod 23 = 18$

Signing of A message by the authorized signer

Let the $h$ value of the message to be signed $m = 5$ ($0 \le m < q$)

Let the random integer chosen by the signer $k = 3$ ($1 < k < q$)

$r = (g^k \mod p) \mod q = (4^3 \mod 23) \mod 11 = (18) \mod 11 = 7$

$s = k^{-1} (m+r) \mod q = (3^{-1} (5 + 7.3)) \mod 11 = (4 	imes 26) \mod 11$

$= (4 	imes 4) \mod 11 = 5$

Digital Signature = $\{r, s\} = \{7, 5\}$

Verification of the Signature by the authorized Recipient

$t = s^{-1} \mod q = 5^{-1} \mod 11 = 9$

$v = ((g^m 	imes y^r) \mod q$

$= ((4^5 	imes 18^7)^9 \mod 23) \mod 11$

$= ((12 	imes 6)^9 \mod 23) \mod 11$

$= ((3)^9 \mod 23) \mod 11$

$= ((4 	imes 4 	imes 4) \mod 23) \mod 11$

$= (18) \mod 11 = 7$

Thus, $v = r = 7$ and signature stands verified.
