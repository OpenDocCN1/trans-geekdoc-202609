# 2.13.2 Markov Processes

If the future state of a process depends only on the present (and is independent of the past), the process is called a Markov process. A Markov process is made possible only if the state time has a memoryless (exponential) distribution. This requirement often limits the applicability of Markov processes.

Formally, a stochastic process X(t) is a Markov process if

```
Prob[X(t)=x|X(t_n)=x_n,X(t_{n-1})=x_{n-1},...,X(t_0)=x_0]=Prob[X(t)=x|X(t_n)=x_n]
t_0 < t_1 < ... < t_n                                              2.115
```
