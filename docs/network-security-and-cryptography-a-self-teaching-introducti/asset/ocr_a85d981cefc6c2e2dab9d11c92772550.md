# 12.5.2 Security Association Selectors (SA Selectors)

The SA selectors are used to filter the outgoing traffic map onto a particular Security Association (SA). The security parameters in an outgoing packet are compared against the security parameters defined in SPD entries to determine a matching SPD entry. The matching SPD entry will have a pointer to an SA; this pointer is included in the IPSec header of the outgoing packet. The pointer forms the Security Parameter Index (SPI). At the receiving end, the SPI will enable the recipient to select the SA under which the packet is to be processed.

# 12.5.3 Combining of Security Associations

An SA supports either AG or Sep, but not both. But consider a situation wherein a sender needs services from AH and ESP. In that case, more than one SA can be combined as a bundle of SAs. The corresponding SPD entry will have pointers to multiple SA definitions which the IP traffic, covered by the SA-bundle, is to be processed. The SAs in a bundle may have the same end-point or different end-points.

# 12.5.4 IPSec Protocol Modes

IPSec supports the following modes of operation:

+   * Transport Mode
* Tunnel Mode
* Wildcard Mode

# Transport Mode

In Transport Mode, protection is provided only to the layers above the Internet Layer (i.e., Transport Layer and above). The original IP Header of the packet is left clear (not encrypted) so that the routers can access the destination IP address for the purpose of routing. But the packet remains vulnerable to traffic analysis.
