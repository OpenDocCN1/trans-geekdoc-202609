The fields SPI, Sequence Number, and Next Header are the same as that for AH.

**Padding:** The Padding is used to prevent Traffic Analysis Attacks.

**Pad Length:** Number of Padding Bytes.

**Authentication data:** It compromises ICV as in AH.
The ESP Header compromising SPI and Sequence Number is not encrypted, since information in the ESP Header (like SPI) is required at the recipient end for selection of the Security Association to decrypt the encrypted fields. Figure 12.4 shows the schematic diagram of the ESP Packet Format.
