## 6.7.1.4 “Meet-in-the-Middle” Attack on Double DES

This attack is performed as:

- **Step 1**: Take a pair of plaintext and ciphertext, say $(P, C)$.
- **Step 2**: Use all possible values of key $K_1$ to encrypt the plaintext, and save the output values $(X)$ in the following table. The table will have $2^{56}$ values of $X$ for each possible value of $K_1$.

| $K_1$ | $X$ |
|---|---|
| | |

- **Step 3**: Sort the table in ascending or descending order of $X$ so that the table can be used for binary search of $X$ values.
- **Step 4**: Decrypt $C$ using the next value of $K_2$. This will produce a value of $X$.
- **Step 5**: Carry out a binary search in the previous table to find a match for the value $X$ generated in Step 4.
- **Step 6**: If a match is found for $X$, the value of $K_1$ (which matches $X$), along with the value of $K_2$ selected at Step 4, form the likely key-pair. Now take another plaintext-ciphertext pair $(P_i, C_i)$, and encrypt the plaintext $P_i$ using the likely key-pair. If the ciphertext generated by the key-pair matches with $C_i$, then $(K_1, K_2)$ is the key-pair with a very high probability. To confirm it more, test with more plaintext-ciphertext pairs. If the test passes with all chosen pairs, quit as the key-pair is confirmed; if the test fails, go back to Step 4.

If no match is found, go back to Step 4 and repeat Steps 4 to 6 with the next value of key $K_2$.

## 6.7.1.5 Effort Required for “Meet-in-the-Middle” Attack on Double DES

The effort required for the “Meet-in-the-Middle” attack can be divided into two parts:

1. **Creation of $K_1$ vs. $X$ Table**: The attacker needs to try all possible values of the 56-bit key $K_1$, so the effort required will be order $2^{56}$.
2. **Decryption of ciphertext using $K_2$ and finding a match with $X$ values stored in the table**: On average, the attacker may need half the possible values of $K_2$. This requires an effort of order $\frac{2^{56}}{2} = 2^{55}$.

The total effort required will be of the order of $2^{56} + 2^{55}$, which is the order of $2 \times 2^{56} = 2^{57}$.

This effort is slightly more than the effort required for breaking a Single DES by Brute Force Attack (i.e., $2^{55}$). Thus, Double DES is almost as insecure as Single DES.

The total effort required will be of the order of $2^{56} + 2^{55}$ that is, the order of $2 \times 2^{56} = 2^{57}$. This effort is slightly more than the effort required for breaking a Single DES by Brute Force Attack (i.e., $2^{55}$). Thus, Double DES is almost as insecure as Single DES.

## 6.7.2 Triple DES

It makes of three blocks of DES with two 56-bit keys, $K_1$ and $K_2$. It is a relatively popular alternative to DES, and it has been adopted for the key management standards.
