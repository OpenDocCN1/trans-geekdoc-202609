# 11.3.1 Segmentation and Reassembly

Almost all facilities put a max limit on the message size. To accommodate this restriction, PGP automatically fragments a message after applying the R64 conversion. At the other end the segments are assembled prior to processing.

# 11.4 CONCEPT OF THE PUBLIC KEY RING AND PRIVATE KEY IN PGP

In PGP, an email user can have any number of private keys and corresponding public keys. The private keys owned by a user are kept in their private key ring. The corresponding public keys are sent to other users, which are kept on their public key ring. Thus, each PGP user has a private Key ring and a Public Key ring.
