# CENTRALIZED AUTHENTICATION SERVICE • 401

Authenticator is encrypted using $K_{c,TGS}$, it ensures TGS that the message is from C alone. After decrypting the Ticket and the Authenticator, TGS compares the values of $ID$ and $AD$, specified in the Ticket, and in the Authenticator, $K_{AD}^{-1}$. Also, it compares the network address $AD$, with the source network address of the received message. If all match, TGS is assured of the User's authentication.

Message (4): Issue of Service-Granting Ticket: This message is sent by the TGS to C in response to the request for a Service-Granting-Ticket (Message (3)). The message contains Ticket, (to be used by C for its authentication to server V) and a session key $K_{cv}$ (to be shared between C and V). The message is encrypted using $K_c$ so that only C can decrypt it.

where

+   $K_{cv}$: Session key to be shared between C and V.
$ID_c$: Identification of target server V.
$TS_c$: Time Stamp.
$Lifetime_c$: Lifetime of Ticket.
$Ticket_v = E_{K_{cv}}[ID_c || AD_c || ID_v || TS_3 || Lifetime_v]$

The Ticket is encrypted using $K_c$ that is shared between TGS and V so that only V can decrypt it.

# The dec dec Ticket contains the following information:

+   A. $K_{cv}$: The session key to be used between Client C and V
B. $ID_c$: User Identification on Client C
C. $AD_c$: Network Address of Client workstation
D. $ID_v$: Identification of V itself
E. $TS_c$: Time stamp
F. $Lifetime_c$: Ticket's Lifetime
