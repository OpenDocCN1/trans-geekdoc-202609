# 8.8.1.3 Signature Verification

Figure 8.17 illustrates the Signature verification. The recipient of the signed message verifies the Signature as follows:

+   - Computes the Hash Value of the received message $M$.

+   - Decrypts the Sign using the sender's public key $(e, n)$ and extracts the hash value of the message that was computed at the sender end.

$H(M) = (Sign)^n \mod n = ((H(M))^d \mod n$

+   - Compares the hash value of the message computed at the recipient end with the one computed at the sender end. If both match exactly, the signature is considered to be verified.
