# 8.5.16 Weak Collision Resistance

Suppose $X=\{x_1, x_2, ..., x_k\}$ is a set of $k$ messages. What must be the minimum size $k$ of the set that for a given message $x$ in the set, the probability of at least one message in the set with same hash value as $x$ is greater than $1/2$?

Let the number of possible variants of the Hash value = $n$ (assuming each hash value is equally likely).

The probability that the hash value of $x$ matches with the hash value of $x_j$

The probability that the hash value of $x$ does not match with hash value of $x_j = 1 - 1/n$.

The probability that the hash value of $x$ does not match with the hash value of any of the remaining $(k-1)$ messages = $(1-1/n)^{k-1}$.

$R[n, k]$ be the Probability that the hash value of $x$, matches with the hash value at least one of the remaining $(k-1)$ messages.

$R[n, k] > 1 - e^{-(k-1)/n}$

For $R[n, k]$ to be greater than 0.5

```
$1 - e^{-(k-1)/n} = 0.5$
```

```
$: e^{(k-1)/n} = 2$
```

```
$: (k-1)/n = \log 2$
```

```
$: k = n \times \log 2 + 1$
```

```
$: k = 0.693n + 1$
```

Let me be the size of the hash value.

Then $n = 2^m$

$k = 0.693 \times 2^m + 1 = 2^m$ for a significantly large value of $2^m$.
