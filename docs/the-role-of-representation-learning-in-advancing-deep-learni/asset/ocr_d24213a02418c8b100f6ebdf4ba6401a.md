Therefore, the complexity of constructing a single tree level \( T_{l+1} \) is \( O(H_l W_l) \), linear in the number of nodes from the previous level.

Now, let's determine the complexity of constructing the entire tree. Without loss of generality, we only consider operations associated with the attention mechanism. This is not a problem, since the complexity of the attention mechanism dominates that of the other operations. This attention operation is repeated \( L - 1 \) times, where \( L \) is the number of tree levels. The total number of operations is then proportional to:

```
\sum_{l=0}^{L-2} (K_h K_w)^2 \frac{H_l W_l}{K_h K_w} = K_h K_w \sum_{l=0}^{L-2} \frac{H_0 W_0}{K_l^l K_w^l}
= H_0 W_0 K_h K_w \sum_{l=0}^{L-2} \left( \frac{1}{K_h K_w} \right)^l
= H_0 W_0 K_h K_w \frac{1 - \left( \frac{1}{K_h K_w} \right)^{L-1}}{1 - \frac{1}{K_h K_w}}
= H_0 W_0 (K_h K_w)^2 \frac{1 - \left( \frac{1}{K_h K_w} \right)^{L-1}}{K_h K_w - 1}
\le H_0 W_0 \frac{(K_h K_w)^2}{K_h K_w - 1}
```

The last inequality comes from the fact that \( K_h K_w > 1 \) and \( L \ge 1 \).

We conclude that the complexity of constructing the entire tree is \( O \left( H_0 W_0 \frac{(K_h K_w)^2}{K_h K_w - 1} \right) = O(H_0 W_0) = O(N_E) \), linear in the number of input (encoder) tokens.

First let's determine the complexity of constructing a single tree level \( T_{l+1} \) from the previous level \( T_l \). This involves the following operations:

+   1. First stage operations: These operations are identical to those in the one-stage encoder, which, as shown in Section D.2.1, have a complexity of \( O \left( \frac{H_l W_l}{K_h K_w} (K_h K_w)^2 \right) = O(H_l W_l) \).
