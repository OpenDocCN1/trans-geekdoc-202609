# Iterative Combinatorial Auctions

Our CA model consists of $m$ indivisible items and $n$ bidders. We denote the set of bidders as $\mathcal{N}$ and the bundle space as $\mathcal{X} = \{0, 1\}^m$. For $x = (x_1, \dots, x_m) \in \mathcal{X}$, $x_j = 1$ if and only if the $j$-th item is part of the bundle $x$.

We denote $v = (v_1, \dots, v_n)$ as the true value profile of all bidders, with $v_i$ being a function that maps a bundle $x \in \mathcal{X}$ to a value in $\mathbb{R}^{\ge 0}$ for bidder $i$. The value of the empty bundle (zero vector) is always 0. Bidders may lie in their value reports. We use the notation $\hat{v}$ (and $\hat{v}_i$) such that $\hat{v}_i(x)$ is the reported value of bidder $i$ for bundle $x$. Further, we use a third notation $\tilde{v}_i$ to refer to the estimated value function of bidder $i$, which is produced by a machine learning algorithm.

An allocation is denoted as $a \in \mathcal{X}^n$, where $a_{i,j} = 1 \Longleftrightarrow$ bidder $i$ receives item $j$. Any feasible allocation requires that every item is assigned to at most one bidder. The social welfare of an allocation $a$ with respect to the true value-function is defined as $V(a) = \sum_{i \in \mathcal{N}} v_i(a_i)$. An allocation that maximizes the social welfare is $a^* = \arg\max_{a \in F} \sum_{i \in \mathcal{N}} v_i(a_i)$, where $F$ is the set of all feasible allocations. We call $a^*$ a perfect allocation in terms of the true value profile $v$. The economic efficiency of an allocation $a$ is measured in relation to the social welfare of a perfect allocation $a^*$ by $\frac{V(a)}{V(a^*)}$. In the further course of this chapter, we will simply write efficiency to refer to the economic efficiency. Similarly we define the estimated social welfare with respect to the estimated value functions of bidders $\tilde{v}_i$ as $\tilde{V}(a) = \sum_{i \in \mathcal{N}} \tilde{v}_i(a_i)$. 

An iterative combinatorial auction (ICA) mechanism defines the interaction between the bidders and the auctioneer, the allocation of the items and the computation of the payments. In our case, the auctioneer can iteratively ask the bidders to report their value $\hat{v}(x)$ for some bundle $x$. We also say “querying/sampling bundle $x$ from bidder $i$” instead of “asking bidder $i$ to report their value for bundle $x$.”

We further denote the set of reported bundle-value pairs of bidder $i$ as $B_i = \{(x, \hat{v}_i(x)) \mid x \in \mathcal{X}, \text{and bidder } i \text{ has reported their value for } x\}$. The tuple $B = (B_1, \dots, B_n)$ gathers the reported bundle-value pairs from all bidders. We define the reported social welfare as $\hat{V}(a|B) = \sum_{\forall i \in \mathcal{N} : (a_i, \hat{v}_i(a_i)) \in B_i} \hat{v}_i(a_i)$.
