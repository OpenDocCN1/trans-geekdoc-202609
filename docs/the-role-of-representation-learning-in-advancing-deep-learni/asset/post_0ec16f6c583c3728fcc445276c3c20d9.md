
## 5.2.3 Transformer Architecture

The vision transformer [67] has achieved great success in many computer vision tasks. It has also been successfully applied to SISR tasks [39]. However, due to self-attention scaling quadratically with input size, the success for using vision transformers in SISR has been limited. The Swin-transformer [172] is a hierarchical transformer architecture, that, thanks to its sliding window local self-attention, is able to scale to much larger input sizes. Many works have applied the Swin-transformer in SISR [163, 124, 42, 313], significantly improving the state-of-the-art.

In this chapter, we build on the success of the Swin-transformer. In combination with the flexibility of INRs, we are able to design a super-resolution model that can be used for a large range of domains.

## 5.3 Method

### 5.3.1 Implicit Neural Representations

The initial step in our framework involves converting raw discrete data into a continuous space. This is achieved by fitting a neural network to each feature within a data point. The neural network's inputs are normalized coordinates, and the outputs correspond to features such as amplitude in audio, RGB values in images, or voxel occupancy in 3D shapes. Given a data point $D$ with a set of coordinates $X$ and feature values $Y$, the network aims to minimize the L2 loss between each network output and the corresponding feature $\{(\theta(\mathbf{x}_i), \mathbf{y}_i \mid i \in D\}$, as outlined in Equation (5.1).

```
\min_{\theta} \mathcal{L}(X, Y) = \min_{\theta} \sum_{i \in D} \|\theta(\mathbf{x}_i) - \mathbf{y}_i\|_2^2
```

The network consists of a sequence of linear layers, represented as $\mathbf{Wx} + \mathbf{b}$, where $\mathbf{W}$ is a learnable weight matrix and $\mathbf{b}$ is a bias vector. Before activation, each layer output is scaled by a constant factor $\omega_0$. We follow the approach of [245], using a sinusoidal activation function, resulting in the form of Equation (5.2). Where $\mathbf{a}^{(l)}$ is the activation of the l-th layer.

```
\mathbf{a}^{(l)} \mapsto \sin(\omega_0 \cdot (\mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}))
```

These networks are referred to as Sinusoidal Representation Networks (SIREN). Although other nonlinearities are explored in [237, 226], we empirically found no significant differences in convergence speed or reconstruction quality, so we adhered to the sinusoidal activation.

**Figure 5.2:** Functa architecture [73]: The encoded Functas are added as shift modulations after each layer.

**Functa Representation.** INR networks have been shown to fit the underlying data with minimal error [245]. However, the training time and space complexity make this approach impractical, especially when fitting an entire 3D scene, which can take several GPU hours for each scene. Instead of fitting a different neural network for each data point, we use a shared base network and represent a data point through frequency shift modulations of each layer's output. These shift modulations are derived by an encoder network m = ψ(ϕ), which is a single linear layer in the form of Wϕ + b (see Figure 5.2). We refer to the inputs ϕ to the encoder as Functas. The forward pass of each layer is thus modified to Equation (5.3). After training, a data point is fully represented by its Functa vector, which can have equal or lower space complexity, as shown in [73, 71, 72]. The base network is only needed for decoding.

```
a^(l) ↦ sin(ω_0 · (W^(l) a^(l-1) + b^(l) + m^(l)))           (5.3)
```

**Meta Learning.** Training this system involves two tasks: identifying the correct inputs (e.g., Functas) for the encoder to produce the correct shift modulations, and finding the optimal parameters for the encoder \(\psi\) and base network \(\theta\) so that the Functas can be fitted with minimal gradient steps. This allows for the transformation of a large collection of data into the continuous space rapidly. We achieve this by dividing the training process into an inner and outer loop. In the inner loop, we fit a batch of Functas for a few gradient steps, freezing the base network \(\theta\) and the encoder \(\psi\), thus only altering the Functas. In the outer loop, we unfreeze the base network and encoder, perform another forward pass with the fixed batch of Functas, and compute double gradients through the computational graph. This corresponds to a variant of Model-Agnostic Meta Learning (MAML) [91, 73], where instead of efficiently learning new tasks, the model learns to assimilate new data points quickly. The learning process is detailed with pseudo code in Algorithm 3.1 in the Appendix.

**Spatial Functa.** Bauer et al. [16] show that perturbing a single element in the Functa vector affects the entire data point. This indicates that individual elements of the vector do not correspond to specific spatial regions in the data. However, many architectures rely on spatial biases, and many tasks require spatial information to be solved. For this reason, Bauer et al. [16] propose to use a spatially arranged representation of individual Functa whose features capture local signal information in the data point. While [16] evaluate their approach on images only, we extend it to 1D and 3D. For audio, we slice samples into temporal segments; for images, into 2D patches; for videos, into temporal segments and 2D patches; for manifold and LiDAR data, into angular sectors; and for 3D shapes, into cubes. We then fit a different Functa to each slice, resulting in a spatial Functa representation with local biases. Additionally, we find that spatial Functa are able to fit the underlying data point better, a property beneficial for strong super-resolution performance. This approach also allows the memory-intensive MAML training to be applied to larger inputs, since gradients can be computed for individual slices of the spatial Functa.

**Backbone.** The Swin Transformer architecture [172] and its variants [163, 124, 42] have become popular for single image super-resolution tasks. In our work, we adapt the Swin architecture to transform a spatial Functa representation of any dimensionality.

The primary concept of Swin's shifting window attention is to divide the data into multiple windows and apply self-attention within each local window. While this reduces the network's receptive field to the local window, subsequent layers shift the window partition, allowing the network to capture dependencies across neighboring windows and propagate information throughout the network (see Figure 5.4). Originally, a pixel patch was encoded as one token, and a window contained multiple tokens [172]. Later work tokenized each pixel directly [124, 42]. In our approach, we apply the shifting window mechanism directly to the spatial Functa representation, with each spatial Functa serving as a token, representing a slice of the original discrete data.

![](img/c742333bcb21933724ca00794dbfb657_82_0.png)

The overall FunctaFormer network $H_{FF}$ follows the layout of [163] and consists of three segments: shallow feature extraction $H_{SF}$, deep feature extraction $H_{DF}$, and residual reconstruction $H_{RR}$. Shallow feature extraction is a simple convolutional layer applied over the entire data. In the second stage, deep features are extracted using several consecutive Residual Swin Transformer Blocks. Finally, for residual reconstruction, the shallow and deep features are merged before applying another convolutional layer $H_{FF}(D_{LQ}) = H_{RR}(H_{SF}(D_{LQ}) + H_{DF}(H_{SF}(D_{LQ}))$. Thanks to the consistent dimensionality of the Functa regardless of source and target resolution, we are able to utilize residual learning. The model learns the residual between the low-quality and high-quality Functa $D_{REC} = D_{LQ} + D_{FT}$, leading to the training loss displayed in Equation (5.4).
