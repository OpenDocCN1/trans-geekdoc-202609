# 6.4 Conclusion

In this chapter, we proposed a novel tree-based encoder-decoder architecture designed to address the scalability limitations (in terms of input size) of traditional transformer-based models. Our experiments reveal that the tree transformer is able to deliver competitive performance while using an encoder based on local attention as well as a drastically reduced number of tokens during cross-attention. While we see this chapter as a proof of concept, future work might transfer these ideas to the setting of NLP, potentially enabling context windows multiple magnitudes larger than currently possible.
