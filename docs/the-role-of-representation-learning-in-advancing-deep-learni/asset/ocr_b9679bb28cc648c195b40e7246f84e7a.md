# ## 6.2 Related Work

The transformer architecture, originally introduced by [271], and its adaptions have become a fundamental architecture in deep learning [305, 66, 35, 64, 27, 264]. The attention mechanism allows the model to perform weighted aggregation of some inputs. However, this comes at a high computational cost, with quadratic computational complexity in the number of tokens for self-attention and linear computational complexity for cross-attention.

For this reason, hierarchical formulations of the transformer architecture have been proposed, based on the idea of efficient local processing of information at different levels of abstraction. Most of this work has been focused on encoder-only or decoder-only architectures, both for NLP [200, 123, 18] and vision [171, 113, 113]. In the setting of encoder-decoder architectures, [90] proposed a method to reduce the complexity of cross attention. In their formulation, [90] uses a full self-attention encoder to build a tree, where the decoder is then able to parse the tree, reducing the complexity of cross-attention from $O(N_D \cdot N_E)$ to $O(N_D \ln N_E)$, with the number of decoder tokens $N_D$ and the number of encoder tokens $N_E$. Our work builds on top of this by also reducing the complexity of the encoder and enabling an interpretable version of the tree parsing.

# ## 6.3 Methodology

This chapter proposes a tree-based architecture for object detection to address the limitations of standard transformers in handling large inputs. The model constructs a hierarchical tree representation of the input image. A decoder then traverses this tree, selecting the nodes used to generate the predictions. We conducted all experiments in the setting of object detection, using the COCO 2017 object detection dataset [168]. Object detection is suitable for evaluating the performance of our proposed architecture, because it requires the model to locate information in different parts of the input and at different scales.
