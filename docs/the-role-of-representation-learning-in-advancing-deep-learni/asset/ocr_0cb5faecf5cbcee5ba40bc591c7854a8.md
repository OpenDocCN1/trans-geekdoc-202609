This allows for the transformation of a large collection of data into the continuous space rapidly. We achieve this by dividing the training process into an inner and outer loop. In the inner loop, we fit a batch of Functas for a few gradient steps, freezing the base network \(\theta\) and the encoder \(\psi\), thus only altering the Functas. In the outer loop, we unfreeze the base network and encoder, perform another forward pass with the fixed batch of Functas, and compute double gradients through the computational graph. This corresponds to a variant of Model-Agnostic Meta Learning (MAML) [91, 73], where instead of efficiently learning new tasks, the model learns to assimilate new data points quickly. The learning process is detailed with pseudo code in Algorithm 3.1 in the Appendix.

**Spatial Functa.** Bauer et al. [16] show that perturbing a single element in the Functa vector affects the entire data point. This indicates that individual elements of the vector do not correspond to specific spatial regions in the data. However, many architectures rely on spatial biases, and many tasks require spatial information to be solved. For this reason, Bauer et al. [16] propose to use a spatially arranged representation of individual Functa whose features capture local signal information in the data point. While [16] evaluate their approach on images only, we extend it to 1D and 3D. For audio, we slice samples into temporal segments; for images, into 2D patches; for videos, into temporal segments and 2D patches; for manifold and LiDAR data, into angular sectors; and for 3D shapes, into cubes. We then fit a different Functa to each slice, resulting in a spatial Functa representation with local biases. Additionally, we find that spatial Functa are able to fit the underlying data point better, a property beneficial for strong super-resolution performance. This approach also allows the memory-intensive MAML training to be applied to larger inputs, since gradients can be computed for individual slices of the spatial Functa.
