# Parsers

The parser is the core component for selecting the relevant information from the tree. There are different ways for selecting a subset of the nodes, which we will describe below. For details on the parsers as well as the complete algorithms, please refer to section D.1.2.

# Best-Node Parser

The best-node parser employs a top-down approach to select nodes. Starting at the highest level of the tree, the parser computes attention scores between each node and a query vector (derived from its decoder embeddings). The node with the highest score is selected, and its siblings are added to the list of selected nodes. For the next levels, the parser focuses on the children of the selected node and repeats this process until the leaf node level is reached. By selecting nodes from all levels, the parser can select high-level information for some areas while focusing on low-level details for other areas.
