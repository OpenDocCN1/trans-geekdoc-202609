# ## 5.4.3 Experimental Setup

To establish a baseline across all data modalities, we evaluate the test sets using simple interpolation algorithms such as nearest neighbor and linear interpolation. This is implemented using PyTorch's built-in interpolation function `torch.nn.functional.interpolate`. The modes are either `nearest-exact` or one of `linear`, `bilinear`, or `trilinear`, depending on the input dimension of the underlying data modality. In every task, downsampling is always performed linearly, either by a factor of x2, x3, or x4 in each spatial dimension.
