# D.3 Details on Decoder Computational Complexity

Let \(\mathcal{T} = \{T_l\}_{l=0}^{L-1}\) be the tree representation of an input image \(I\), where \(T_l \in \mathbb{R}^{H_l \times W_l \times d_{model}}\) corresponds to the node embeddings at level \(l\). Given the way the tree is constructed, we have that \(H_l = H_0 / K_h^l\) and \(W_l = W_0 / K_w^l\), \(\forall l \in \{0, ..., L-1\}\). Additionally, \(L = \min \left\{ \log_{K_h}(H_0), \log_{K_w}(W_0) \right\}\). Finally, let \(N_E = H_0 W_0\) be number of input encoder tokens and let \(N_D\) be the number of decoder tokens.

# Parsing Complexity

We analyze the complexity of Algorithm 4.2 by examining the operations within each iteration:

+   1. Children\(\left(\cdot\right)\): This is an indexing operation with a complexity of \(O(1)\).

+   2. Computation of \(K\): Projecting the node embeddings involves matrix-vector multiplication. Assuming a naive implementation this has a complexity of \(O\left(K_h K_w d^2_{model}\right)\), where \(K_h K_w\) is the number nodes being projected. This complexity is independent of the number of input encoder tokens \(N_E\).

+   3. Similarity Scores: Computing the similarity scores between the query vector \(\bar{\mathbf{q}}\) and the projected node embeddings \(K\) involves dot products. This has a complexity of \(O\left(K_h K_w d_{model}\right)\), also independent of \(N_E\).

+   4. arg max operation: Finding the node with the maximum similarity score has a complexity of \(O\left(K_h K_w\right)\).

These operations are repeated \(L\) times, where \(L\) is the number of levels in the tree. Therefore, the overall parsing complexity is:

```
\(O\left(L\left(K_h K_w\right) d^2_{model}\right) = O \left(\min \left\{ \log_{K_h} H_0, \log_{K_w} W_0 \right\} \left(K_h K_w\right) d^2_{model}\right)\)
\(= O \left(\min \left\{ \log_{K_h} H_0, \log_{K_w} W_0 \right\}\right)\)
\(= O\left(\ln \min\{H_0, W_0\}\right)\)
```
