# 2.3. METHODS

+   • $\tilde{x} \in \arg \max_{x \in H_{\tilde{s}}} ||x - \tilde{s}||$:
+   \(\Longrightarrow dist_{\tilde{s}} = ||\tilde{x} - \tilde{s}||\)
+   \(\Longrightarrow dist_{\tilde{s}} < dist_{s^*}\)
+   \(\Longrightarrow \tilde{s} \notin \arg \max_{s \in S} dist_s\)
+   \(\Longrightarrow x \notin \tilde{B}_{new}\)

+   • $\tilde{x} \notin \arg \max_{x \in H_{\tilde{s}}} ||x - \tilde{s}||$: This trivially violates the conditions to be an element of \(B_{new}\). However, $\tilde{x}$ could be closest to more than one element of \(S\). Let us therefore assume, that $\tilde{x}$ is also closest to \(s'\) in S and $\tilde{x} \in \arg \max_{x \in H'_{s'}} ||x - s'||$. But then we can just apply the first case again with \(s'\) instead of $\tilde{s}$ and hence we get $\tilde{x} \notin B_{new}$. 

In both cases we get $\tilde{x} \notin B_{old} \Longrightarrow \tilde{x} \notin B_{new}$, which implies \(B_{new} \subseteq B_{old}\).

Secondly, we prove \(B_{old} \subseteq B_{new}\): We assume that \(x \notin B_{new}\) and $\tilde{x}$ is closest to $\tilde{s}$ in \(S\). Again two cases can be distinguished:

+   • $\tilde{x} \notin \arg \max_{x \in H_{\tilde{s}}} ||x - \tilde{s}||$:
+   Then there must exists \(x' \in H_{\tilde{s}}\), s. t. \(||x' - \tilde{s}|| > ||\tilde{x} - \tilde{s}||\).
+   \(\Longrightarrow d'_{x'}^{in} > d_{\tilde{x}}^{in} \Longrightarrow \tilde{x} \notin \arg \max_{x \in \mathcal{X} \setminus S} d_x^{in} \Longrightarrow \tilde{x} \notin B_{old}\)

+   • $\tilde{x} \in \arg \max_{x \in H_{\tilde{s}}} ||x - \tilde{s}||$, but $\tilde{s} \notin \arg \max_{s \in S} dist_s$:
+   There exists a \(s^* \in \arg \max_{s \in S} dist_s\) with corresponding \(x^* \in \arg \max_{x \in H_{s^*}} ||x - s^*||\).
+   Obviously we have \(dist_{\tilde{s}} < dist_{s^*}\).
+   \(\Longrightarrow ||\tilde{x} - \tilde{s}|| < ||x^* - s^*|| \Longrightarrow d_{\tilde{x}}^{in} < d_{x^*}^{in} \Longrightarrow \tilde{x} \notin B_{old}\)

This implies \(B_{old}\) is a subset of \(B_{new}\). Together with \(B_{new} \subseteq B_{old}\), we can derive \(B_{new} = B_{old}\).

As already mentioned at the beginning of this section, \(B_{new}\) cannot be computed in polynomial time. The problem is the constraint \(x \in H_{s^*}\), demanding that \(\mathcal{H}_{S^*}\) has to be known. Building this set requires computing for every \(x \in \mathcal{X} \setminus S\) its distance to each set \(S\), so that we can compute whether \(x\) is closest to \(s^*\). As the set \(\mathcal{X} \setminus S\) is of exponential size, deriving \(H_{s^*}\) takes exponential time.
