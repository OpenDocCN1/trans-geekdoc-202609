**Intermediate Rewards** The environment encourages the use of Gymnasium's Wrapper interface to implement custom reward structures for a given puzzle. Such custom reward structures can provide an easier game setting, compared to the sparse reward only provided when finishing a puzzle.

**Puzzle Module** The PuzzleEnv object creates an instance of the class Puzzle. A Puzzle is essentially the glue between all Pygame surface tasks and the C back-end that contains the puzzle logic. To this end, it initializes a Pygame window, on which shapes and text are drawn. The Puzzle instance also loads the previously compiled shared library containing the C back-end code for the relevant puzzle.

The PuzzleEnv also converts and forwards keyboard inputs (which are for example given by an RL agent's action) into the format the C back-end understands.
