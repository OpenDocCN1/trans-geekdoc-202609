**Shifting Window.** For self-attention, we employ the shifting windows mechanism introduced with the Swin Transformer [172]. In the first layer, the image is divided into non-overlapping windows of a fixed size (see Figure 5.4). In the subsequent layer, the windows are shifted by a certain stride (typically half the window size). The authors of [172] developed this method for 2D vision tasks. In our work, we adapt the shifting window mechanism to work with arbitrary input dimensions while maintaining the correct spatial bias. This is necessary in order to work with different dimensionalities of spatial Functa. We provide implementation details in Section C.1.

# 5.4 Experiments

In this study, we conduct a comprehensive series of five distinct experiments. First, we aim to identify the optimal spatial dimension for each data modality by determining the most effective slicing window for our SIREN model. Second, we seek to establish the ideal Functa sizes corresponding to these optimal slicing windows. Third, we create a baseline for all data modalities using simple interpolation algorithms. Fourth, we perform an ablation study to investigate the correlation between the SIREN slicing dimensions and our FunctaFormers window size. Finally, leveraging the insights gained from the ablation study, we train models on x2, x3, and x4 degraded data and compare their performance against state-of-the-art methods, where applicable.

# 5.4.1 Datasets

To evaluate the multimodality of our framework, we train and test our models on six distinct data modalities: images, data on a manifold, 3D-shapes, audio, video, and LiDAR. Despite the inherent differences among these diverse data modalities, our model varies only in the number of input and output neurons. We provide an overview of all datasets, with additional details in Section C.3.

**Images.** We train on DF2K, which combines the DIV2K [6] and FlickR2K [165] datasets. For comparison against current state-of-the-art methods on super-resolution tasks, we utilized the SET5 [19], SET14 [299], Urban100 [126], Manga109 [186], and BSD100 [184] image sets.
