# ### 6.3.1 Tree Encoder

The encoder is responsible for constructing a hierarchical tree representation of the input image. It takes as input the leaf node embeddings generated by the backbone. Starting from these leaf nodes, the encoder builds the remaining levels of the tree in a bottom-up fashion, aggregating the information into more abstract tokens at the higher levels. We divide the process into two stages, see fig. 6.2 for an overview of the process. In stage I, the nodes at each level are generated based on the nodes from the previous level. This is achieved by grouping the nodes into non-overlapping windows and aggregating them into a single parent node. We then repeat this process until we have built the whole tree, sharing the weights for the aggregation function. In stage II, the embeddings of the nodes in the tree can be refined based on the n-hop neighborhood of each node.

This process is repeated recursively until the top level is reached. In stage II, the embeddings in the tree get refined based on their local neighborhood.

# ### 6.3.2 Tree Decoder

The decoder performs cross-attention on the tree provided by the encoder in order to generate final prediction for the class and bounding boxes of objects using the output head. Part of the decoder is a parser, which, given the tree and the current decoder tokens, selects the relevant tokens from the tree in an efficient manner.
