The sliding-window parser employs a two-step process to select nodes. First, it identifies the most relevant level in the tree. Starting at the highest level, it computes attention scores between each node and a query vector and selects the node with the highest score. It then descends the tree, level by level, computing attention scores between the children of the previously selected node and the query vector and selecting the best-scoring child. Once the attention score of the highest scoring child is lower than that of the parent, the level of the parent is selected. Once the level is identified, the parser expands its search area to encompass the children of both the best-scoring node and its one-hop neighbors. This broader scope helps to include semantically related nodes that may have been separated during the construction of the tree. Within this expanded area, the parser selects a window of nodes of size \(\tilde{K}\) with the highest cumulative attention scores. Unlike the Best-Node Parser, the Sliding Window parser does not include any nodes along the path, only the nodes selected by the sliding window.

## Multi-Path Parsers

The parsers described so far are restricted to a single path through the tree, limiting their exploration to a single region of the input image. This can be an issue, since different decoder tokens might attend to different parts of an image.

To address this, we introduce multi-path versions of the best-node and sliding-window parsers. The algorithms of the multi-path parsers remain largely unchanged. The main difference is in the way the attention scores are computed. Instead of using a single query vector (\(\bar{\mathbf{q}}\)) aggregated over all decoder tokens, we now select a subset of \(n_{paths}\) query vectors. Specifically, we select the \(n_{paths}\) query vectors with the highest attention scores at the highest level in the tree. We then parse the tree for each path individually and select the union of all chosen nodes for cross-attention.

## 6.4 Conclusion

In this chapter, we proposed a novel tree-based encoder-decoder architecture designed to address the scalability limitations (in terms of input size) of traditional transformer-based models. Our experiments reveal that the tree transformer is able to deliver competitive performance while using an encoder based on local attention as well as a drastically reduced number of tokens during cross-attention. While we see this chapter as a proof of concept, future work might transfer these ideas to the setting of NLP, potentially enabling context windows multiple magnitudes larger than currently possible.
