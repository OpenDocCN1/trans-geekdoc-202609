# Disentangling Adversarial Variational Autoencoder

# B.1 Datasets

We provide a short summary of each dataset, including samples and the respective data generating ground truth factors.

# B.1.1 Shapes3D

The Shapes3D dataset [30] includes the following ground truth factors: floor hue, wall hue, object hue, scale, shape and orientation.

# B.1.2 DSprites

The DSprites dataset [187] includes the following ground truth factors: shape, scale, orientation, x-position and y-position.
