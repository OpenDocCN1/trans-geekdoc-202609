
## DL-ICA

We present the iterative machine learning-based elicitation algorithm, which was proposed by Bero et al. [24] in Algorithm 2.1. The goal of this algorithm is to find an allocation \(a\) without having the bidder to submit bids for all possible bundles.

The algorithm can be divided into an initial phase (Line 1) and an iterative phase. In the initial phase, the mechanism samples a certain number of bundles for each bidder. The bidders then have to report their value for each of the chosen bundles to the mechanism. In round \(t\) of the iteration phase, the mechanism uses a machine learning algorithm \(\mathcal{A}\) to generate the estimated social welfare function \(\tilde{V}^t\) based on the already queried bundles \(B^{t-1}\). The winner determination problem (WDP) is then solved to find an allocation \(a^t\) that maximizes the estimated social welfare function \(\tilde{V}^t\). Finally, each bidder is asked to report his value for the bundle \(a_i^t\) allocated to him, if the bidder hasn't been asked \(a_i^t\) before.

### Algorithm 2.1 Machine learning-based elicitation
```
Input: Machine learning algorithm \(\mathcal{A}\)
\(B^0 \leftarrow\) set of bundle value pairs of initial bundles
\(t \leftarrow 0\)
while \(\exists i \in \mathcal{N}\) with \(a_i^t \notin B_i^{t-1}\) do
  \(t \leftarrow t + 1\)
  Infer social welfare function: \(\tilde{V}^t \leftarrow \mathcal{A}(B^{t-1})\)
  Determine allocation: \(a^t \in \arg\max_{a \in F} \tilde{V}^t(a)\)
  for each bidder \(i\) do
    if \(a_i^t \notin B_i^{t-1}\) then
      Query value \(\hat{v}_i(a_i^t)\) from bidder \(i\)
      \(B_i^t \leftarrow B_i^{t-1} \cup (a_i^t, \hat{v}_i(a_i^t))\)
    else
      \(B_i^t \leftarrow B_i^{t-1}\)
    end if
  end for
end while
Output: Final set of bundle-value pairs \(B^T\), where \(T = t\)
```

The machine learning algorithm \(\mathcal{A}\) is treated as a black box. In particular, \(\mathcal{A}\) tries to estimate the (true) value function of every bidder by building a machine learning model for every bidder and training it on the set of already queried bundles of that bidder \( B_i \). Let \( \tilde{v}_i^t \) be the estimated value function for bidder \( i \) computed by \( \mathcal{A} \) in iteration t. The estimated value functions of the bidder are then summed up to build the social welfare function \( \tilde{V}^t(a) = \sum_{i \in \mathcal{N}} \tilde{v}_i^t(a_i) \). Bero et al. [24] used kernelized SVR for their models. Weissteiner and Seuken [285] modified the algorithm by using Deep Neural Networks instead of SVR. Neural networks can in general capture more complex functions than linear or quadratic kernels.

The WDP has the goal of allocating the items of an auction in such a way, that the social welfare of the auction is maximized. In every iteration \( t \) we are interested in finding a maximal allocation \( a^t \) with respect to the estimated social welfare function \( \tilde{V}^t \). This can be formulated as:

```
\(\arg \max_{a \in \mathcal{X}^n} \sum_{i \in \mathcal{N}} \tilde{v}_i^t(a_i^t)\)
\(\text{s.t.} \sum_{i \in \mathcal{N}} a_{ij} \le 1, \quad \forall j \in \mathcal{M}\)
\(a_{ij} \in \{0, 1\}, \quad \forall j \in \mathcal{M}, \forall i \in \mathcal{N}\)
(2.1)
```

Weissteiner and Seuken [285] have shown that the presented WDP can be modeled as neural networks with ReLU activation function into a MIP. For every bidder, a fully connected multi-layer perceptron (MLP) with ReLU activation functions is used to learn the bidder's value function. The output layer does not have an activation function. Let \( d_k^i \) represent the dimension of layer k. Let further \( W^{i,k} \) be the matrix containing the weights employed to compute the values of the layer \( k + 1 \) and \( b^{i,k} \) the bias we add in the computation for layer \( k + 1 \) in the neural network for bidder \( i \). Then the output \( o^{i,k+1} \in \mathbb{R}^{d_{k+1}^i} \) of layer \( k+1 \) is computed as \( o^{i,k+1} = \max \{0, W^{i,k} \cdot o^{i,k} + b^{i,k} \} \). The presented MLP can then be expressed as a nested function, where the output of the function corresponds to the output layer of the neural network. For a one-hidden-layer perceptron and input vector \( x \), the function would be \( \tilde{v}_i(x) = W^{i,2} \cdot (\max \{0, W^{i,1} \cdot x + b^{i,1} \}) + b^{i,2} \).

Although the ReLU activation functions induce nonlinearity in our MLPs, a MLP with ReLU activation functions can still be presented in a linear way. For every layer k, we now introduce three new vectors \( y^{i,k}, z^{i,k}, s^{i,k} \), all of size \( d_k^i \). Then \( y^{i,k} \) is a binary vector, while \( z^{i,k} \) and \( s^{i,k} \) lie in the real number space. Let \( h^{i,k} = W^{i,k-1} \cdot o^{i,k-1} + b^{i,k-1} \). The vectors are set in the following way. If \( h_j^{i,k} \ge 0 \), we set \( z_j^{i,k} = h_j^{i,k} \), \( y_j^{i,k} = 1 \) and \( s_j^{i,k} = 0 \), if it is negative, \( z_j^{i,k} \) and \( y_j^{i,k} \) are both 0 and \( s_j^{i,k} = -h_j^{i,k} \).

### Lemma 2.2
We present Lemma 2.2 from Weissteiner and Seuken [285], which shows how one can encode the output values of a layer using a set of linear constraints.

**Lemma 2.2.** Let \( W^{i,k-1} \cdot o^{i,k-1} + b^{i,k-1} \in \mathbb{R}^{d_k^i} \) be fixed for \( a \in \{1, ..., K_i\} \) (where \( K_i + 1 \) denotes the number of layers including input and output layer). Furthermore, let \( z^{i,k}, s^{i,k} \in \mathbb{R}^{d_k^i}, y^{i,k} \in \mathbb{R}^{d_k^i} \). Consider the following linear constraints:

```
z^{i,k} - s^{i,k} = W^{i,k-1} \cdot o^{i,k-1} + b^{i,k-1} \tag{2.2}

0 \le z^{i,k} \le y^{i,k} \cdot L \tag{2.3}

0 \le s^{i,k} \le (1 - y^{i,k}) \cdot L \tag{2.4}
```

The polytope defined by (2.2) - (2.4) is not empty and every element \( (z^{i,k}, s^{i,k}, y^{i,k}) \) of this polytope satisfies \( z^{i,k} = o^{i,k} \).

Here, \( L \) denotes a big constant, that is guaranteed to be large enough to satisfy that every element in \( z^{i,k} \) and in \( s^{i,k} \) for all \( k \in \{1, ..., K_i\} \) is smaller than \( L \).

Using Lemma 2.2, we can reformulate the WDP 2.1 into a MIP, so it can be efficiently solved using a linear program solver:

```
arg max_{a \in \mathcal{X}^{n, z^{i,k}, s^{i,k}, y^{i,k}}} \sum_{i \in \mathcal{N}} z^{i, K_i}

s.t. \forall i \in \mathcal{N}

z^{i, 0} = a_i,

\left\{\begin{aligned}
z^{i,k} - s^{i,k} &= W^{i,k-1} \cdot z^{i,k-1} + b^{i,k-1} \\
0 \le z^{i,k} \le y^{i,k} \cdot L \\
0 \le s^{i,k} \le (1 - y^{i,k}) \cdot L \\
y^{i,k} \in \{0, 1\}^{d_k^i}
\end{aligned}\right\} \forall k \in \{1, ..., K_i\} \tag{2.5}

a_{ij} \in \{0, 1\}, \quad \forall j \in \mathcal{M}

\sum_{i \in \mathcal{N}} a_{ij} \le 1, \quad \forall j \in \mathcal{M}
```

We omit the proof for the equivalence of the WDP (2.1) and the MIP (2.5) and refer to [285].

## The PVM Algorithm

The Vickrey-Clarke-Groves auction (VCG) is a famous auction type for combinatorial auctions. One big advantage of VCG is its strategyproofness, which means that bidding truthfully represents a dominant strategy. In style of VCG, Bero et al. [24] have presented the auction mechanism Pseudo-VCG (PVM), which computes an allocation and payments for a CA instance. PVM executes Algorithm 2.1 n + 1 times, once for the main economy, n-times for the n marginal economies, where one bidder does not participate in the auction. After determining the best allocation under the set of elicited bundles returned by Algorithm 2.1 for every economy, it chooses the allocation with the highest social welfare and then computes the payments according to the VCG-payment rule.

### Algorithm 2.3 Pseudo-VCG Mechanism (PVM) by Bero et al. [24]
```
Run Algorithm 1 n + 1 times to get B^(-0), B^(-1), ..., B^(-n)
B^* <- (U_{i=1}^n B^(-i)) U B^(-0)
Determine allocations a^(-0), a^(-1), ..., a^(-n), where
a^(-i) in arg max_{a in F} V(a|B^(-i)) forall i in {emptyset, 1, 2, ..., n}
Allocate items according to:
a^pvm in arg max_{a in {a^(-0), a^(-1), ..., a^(-n)}} V(a|B^(-i))
Charge each bidder i according to:
p_i^pvm = sum_{j in N, j != i} v_j(a^(-i)) - sum_{j in N, j != i} v_j(a^pvm)
```

Notice, that the allocations a^(-0), a^(-1), ..., a^(-n) can only assign bundles to bidders, which the mechanism has already queried in Algorithm 2.1 from this bidder. In other words, if bidder i gets bundle x in the allocation a^(-j), then x must be in the set B_i^(-j). As the sets B^(-0), B^(-1), ..., B^(-n) might differ, there is no guarantee, that the social welfare of the main economy is the largest, unlike as in VCG.
