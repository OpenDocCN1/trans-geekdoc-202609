
compute a bundle $x^* = \arg \max_{x \in H_y} |y - \tilde{v}_i(x)|$ for which its estimated value $\tilde{v}_i(x)$ is closest to $y$ in Y, but their distance is maximized. Further, we have $dist_y = \max_{x \in H_y} |y - \tilde{v}_i(x)| = |y - \tilde{v}_i(x^*)|$. The next bundle to query is then

$$ x^* = \arg \max_{x \in H_{y^*}} |y^* - \tilde{v}_i(x)| $$
with $y^* \in \arg \max_{y \in Y} dist_y$
(2.11)

We state that the two definitions (2.11) and (2.7) are in fact equivalent.

**Lemma 2.10.** Let $B_{new} = \{x' | x' \in \arg \max_{x \in H_{y^*}} |x - y'| \wedge s \in \arg \max_{y \in Y} dist_y\}$ be the set of all bundles, which can be queried next according to the new Formulation (2.11) and $B_{old} = \{x' | x' \in \arg \max_{x \in \mathcal{X} \setminus S} d_x^{out}\}$ the same set, but based on the old Definition (2.6). Then $B_{new} = B_{old}$.

*Proof of Lemma 2.10.* The proof is the same as for Lemma 2.6, just with slight changes. Instead of the already queried bundles $S$ we use their labels $Y$, $d_x^{out}$ replaces $d_x^{in}$ and the norms between $x$ and $s$ are substituted by norms between $y$ and $\tilde{v}_i(x)$.

As before with GALI, the Optimization Problem (2.11) cannot be computed in polynomial time. The problem is the constraint $x \in H_{y^*}$, which demands that $H_{y^*}$ has to be known. Unfortunately, building this set requires computing for every $x \in \mathcal{X} \setminus S$ and for every $y \in Y$ the distance $|y - \tilde{v}_i(x)|$. As the set $\mathcal{X} \setminus S$ is of exponential size, deriving $H_{y^*}$ takes exponential time.

## Implementation with ILPs

We show how we can again can use ILPs to compute $H_{y^*}$. In order to solve the presented Optimization Problem (2.11), we have to compute $x^* \in \arg \max_{x \in H_y} |y - \tilde{v}_i(x)|$ for every label $y \in Y$ without having to build $H_y$. This can be done by solving the following optimization problem for every $y \in Y$.

$$ \arg \max_{x \in \mathcal{X}} |y - \tilde{v}_i(x)| $$
s.t. $|y - \tilde{v}_i(x)| \le |y' - \tilde{v}_i(x)| \quad \forall y' \in Y . y' \neq y$
(2.12)

As before in GALI, the Optimization Problem (2.12) is not directly of a linear kind due to the Euclidean norm and the value function $\tilde{v}_i(x)$. In the following sections we derive a linear formulation depending on the chosen machine learning model for the value function \(\tilde{v}_i(x)\). We are going to present solutions for two different models, a linear model and a fully-connected multi-layer neural network.

## Solution for Linear Model

We first treat the case where the machine learning model is a simple linear model and call this approach **GALO** (linear).

In the linear model the estimated value function is of the form \(\tilde{v}_i(x) = w^Tx + w_0\), where \(w = (w_1, ..., w_m) \in \mathbb{R}^m\) and \(w_0 \in \mathbb{R}\). The function is obviously linear caused by the Euclidean norm. The nonlinearity is only caused by the Euclidean norm.

Let \(C\) be a large constant. The following ILP erases the nonlinearity while staying equivalent to (2.12).

```
arg max \ r \\
s.t. \\
y - \tilde{v}_i(x) \le r \\
\tilde{v}_i(x) - y \le r \\
y' - \tilde{v}_i(x) + C \cdot b_{y'} \ge r \\
\tilde{v}_i(x) - y' + C \cdot (1 - b_{y'}) \ge r \quad \forall y' \in Y \\
b_{y'} \in \{0, 1\} \quad \forall y' \in Y \\
r \in \mathbb{R}
```

Before we can prove Theorem 2.12, we introduce Lemma 2.11 which will be helpful for the equivalence proof.

**Lemma 2.11.** Let \(b_{y'} \in \{0, 1\}\). Let further \(C\) be a large enough constant. Then it holds that $|y' - \tilde{v}_i(x)| \ge r$, if and only if \(y' - \tilde{v}_i(x) + C \cdot b_{y'} \ge r\) and \(\tilde{v}_i(x) - y' + C \cdot (1 - b_{y'}) \ge r\).

*Proof of Lemma 2.11.* We make a case distinction.

- $y' \ge \tilde{v}_i(x)$: We choose $b_{y'} = 0$ and $C \ge y' - \tilde{v}_i(x) + r$.
  $$
  \begin{aligned}
  |y' - \tilde{v}_i(x)| \ge r
  &\iff y' - \tilde{v}_i(x) \ge r \\
  &\iff y' - \tilde{v}_i(x) + (y' - \tilde{v}_i(x) + r) \cdot 0 \\
  &\quad \ge r \wedge \tilde{v}_i(x) - y' + (y' - \tilde{v}_i(x) + r) \cdot 1 \ge r \\
  &\iff y' - \tilde{v}_i(x) + C \cdot b_{y'} \\
  &\quad \ge r \wedge \tilde{v}_i(x) - y' + C \cdot (1 - b_{y'}) \ge r
  \end{aligned}
  $$

- $\tilde{v}_i(x) > y'$: We choose $b_{y'} = 1$ and $C \ge \tilde{v}_i(x) - y' + r$
  $$
  \begin{aligned}
  |y' - \tilde{v}_i(x)| \ge r
  &\iff \tilde{v}_i(x) - y' \ge r \\
  &\iff y' - \tilde{v}_i(x) + (\tilde{v}_i(x) - y' + r) \cdot 1 \\
  &\quad \ge r \wedge \tilde{v}_i(x) - y' + (\tilde{v}_i(x) - y' + r) \cdot 0 \ge r \\
  &\iff y' - \tilde{v}_i(x) + C \cdot b_{y'} \\
  &\quad \ge r \wedge \tilde{v}_i(x) - y' + C \cdot (1 - b_{y'}) \ge r
  \end{aligned}
  $$

### Theorem 2.12. _The Integer Linear Program (2.13) is equivalent to the Optimization Problem (2.12)._

_Proof of Theorem 2.12._ The proof is divided into two steps. In the first part we show the equivalence of the constraints:

$$
\begin{aligned}
|y - \bar{v}_i(x)| \le |y' - \bar{v}_i(x)| \quad (\forall y' \in Y)
&\Longleftrightarrow |y - \bar{v}_i(x)| \le r \le |y' - \bar{v}_i(x)| \land r \in \mathbb{R} \quad (\forall y' \in Y) \\
y - \bar{v}_i(x) \le r \land \bar{v}_i(x) - y \le r
&\Longleftrightarrow |y' - \bar{v}_i(x)| \ge r \quad (\forall y' \in Y) \\
r &\in \mathbb{R}
\end{aligned}
$$

Lemma 2.11
$$
\left. \begin{aligned}
y - \bar{v}_i(x) \le r \land \bar{v}_i(x) - y \le r \\
y' - \bar{v}_i(x) + C \cdot b_{y'} \ge r \\
\bar{v}_i(x) - y' + C \cdot (1 - b_{y'}) \ge r \\
b_{y'} \in \{0, 1\} \\
r \in \mathbb{R}
\end{aligned} \right\} \quad (\forall y' \in Y)
$$

Since the constraint of the linear program and the original optimization problem can be mutually derived from each other, the sets of feasible solutions of the two approaches are equal. Now we get to the second part. We’d like to show that \(r = |y - \bar{v}_i(x)|\) for any feasible \(x\).

Let \(x\) be feasible. Hence, there exists \(r \in \mathbb{R}\) satisfying the constraints

$$
\begin{aligned}
y - \bar{v}_i(x) &\le r \\
\bar{v}_i(x) - y &\le r \\
y - \bar{v}_i(x) + C \cdot b_y &\ge r \\
\bar{v}_i(x) - y + C \cdot (1 - b_y) &\ge r
\end{aligned}
$$

The first two constraints imply $|y - \bar{v}_i(x)| \le r$, the last two $|y - \bar{v}_i(x)| \ge r$ (through Lemma 2.11). It follows $|y - \bar{v}_i(x)| = r$. We have now proven, that the sets of feasible solutions are equal for both, the ILP (2.13) and the Optimization Problem (2.12), and that for all these feasible solutions $|y - \bar{v}_i(x)| = r$. Therefore, maximizing $r$ and maximizing $|y - \bar{v}_i(x)|$ produces the same results.

With help of the ILP, we can now introduce the algorithm which generates the initial bundle-value pairs for a bidder. The algorithm is similar to Algorithm 2.9. To prevent overfitting, we need enough starting bundle-value pairs before training our model on it. The bundles for these pairs can either be generated uniformly at random or with the just presented GALI technique. The input k defines how many starting bundles are needed. After that, the bundles are determined as in Algorithm 2.9 in an iterative way. Every round we call the machine learning algorithm M, which takes a training set and their labels as inputs, trains a model on this data and returns the trained model. In this case, the model would be a linear one. Using the ILP (2.13) we can then determine the next bundle to sample.

```
Algorithm 2.13 Generate Initial Bids based on GALO
Input: c0, k
Input: Machine learning algorithm M
generate k initial bids based on uniform sampling or using Algorithm 2.9
→ S, Y
count ← 0
while count ≤ c0 − k do
    ṽi ← M(S, Y)
    for each y ∈ Y do
        compute xy ∈ arg maxx∈Hy |y − ṽi(x)| (ILP (2.13))
        disty ← ||ṽi(xy) − y||
    end for
    choose y* ∈ arg maxy∈Y disty
    S ← S ∪ {xy*}
    ask bidder to submit value for bundle xy*, add value to Y
    count ← count + 1
end while
Output: (S, Y)
```
