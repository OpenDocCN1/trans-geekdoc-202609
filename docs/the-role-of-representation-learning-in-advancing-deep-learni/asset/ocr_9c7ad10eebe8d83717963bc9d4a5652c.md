Within this expanded area, the parser selects a window of nodes of size \(\tilde{K}\) with the highest cumulative attention scores. Unlike the Best-Node Parser, the Sliding Window parser does not include any nodes along the path, only the nodes selected by the sliding window.

# Multi-Path Parsers

The parsers described so far are restricted to a single path through the tree, limiting their exploration to a single region of the input image. This can be an issue, since different decoder tokens might attend to different parts of an image.

To address this, we introduce multi-path versions of the best-node and sliding-window parsers. The algorithms of the multi-path parsers remain largely unchanged. The main difference is in the way the attention scores are computed. Instead of using a single query vector (\(\bar{\mathbf{q}}\)) aggregated over all decoder tokens, we now select a subset of \(n_{paths}\) query vectors. Specifically, we select the \(n_{paths}\) query vectors with the highest attention scores at the highest level in the tree. We then parse the tree for each path individually and select the union of all chosen nodes for cross-attention.

# Ablations

For the following experiments, we use the two-stage tree encoder with variable n-hop neighborhoods, the best performing configuration from the previous section. We compare best-node and sliding window parsers both in the single-path and in the multi-path setting. While the best-node parser performs better than the sliding window parser in the single-path setting, the sliding window parser clearly achieves the strongest score in the multi-path setting (Table 6.5). We find however that, despite the mediocre performance, the best-node parser is able to navigate the tree well. We visualize this behavior in Figure 6.4.
