# ## E.5.2 Optional Parameters

We display the optional parameters for all supported puzzles in Table E.5.43. If none are supplied upon initialization, a set of default parameters gets used for the puzzle generation process.

**Table E.5.43:** For each puzzle, all optional parameters a user may supply are shown and described. We also give the required data type of variable, where applicable (e.g., `int` or `char`). For parameters that accept one of a few choices (such as difficulty), the accepted values and corresponding explanation are given in braces. As an example: a difficulty parameter is listed as d{int} with allowed values {0 = easy, 1 = medium, 2 = hard}. In this case, choosing medium difficulty would correspond to d1.

| Bridges | `7x7l5e2x2d0` | `{int}x{int}`<br>`i{int}`<br>`e{int}`<br>`n{int}`<br>`d{int}` | grid width ×<br>grid height<br>percentage of island squares<br>expansion factor<br>max bridges per direction<br>difficulty {<br>0 = easy<br>1 = medium<br>2 = hard} | 3 · w · h · (w + h + 8) |
