**Functa Representation.** INR networks have been shown to fit the underlying data with minimal error [245]. However, the training time and space complexity make this approach impractical, especially when fitting an entire 3D scene, which can take several GPU hours for each scene. Instead of fitting a different neural network for each data point, we use a shared base network and represent a data point through frequency shift modulations of each layer's output. These shift modulations are derived by an encoder network m = ψ(ϕ), which is a single linear layer in the form of Wϕ + b (see Figure 5.2). We refer to the inputs ϕ to the encoder as Functas. The forward pass of each layer is thus modified to Equation (5.3). After training, a data point is fully represented by its Functa vector, which can have equal or lower space complexity, as shown in [73, 71, 72]. The base network is only needed for decoding.

```
a^(l) ↦ sin(ω_0 · (W^(l) a^(l-1) + b^(l) + m^(l)))           (5.3)
```
