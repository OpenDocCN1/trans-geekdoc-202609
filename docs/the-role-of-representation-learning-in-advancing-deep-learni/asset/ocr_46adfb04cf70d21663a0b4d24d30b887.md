In Figure 5.6 we can see a clear correlation between spatial size and reconstruction quality, with smaller spatial windows giving better results. Although this could be expected, since more features need to be represented by the same size network of 3 layers with 64 hidden units. However, every Functa is proportional to the window size, giving every data point the same representational capacity. If the base network is just a mapping between Functa and Features there should be no correlation between spatial size and reconstruction quality. Thus, we conclude that the base network plays an important role in the representation and distillation of the data and that it is able to perform better on lower window sizes. One can also see that the increase in reconstruction quality towards lower window sizes is less significant in Audio than Image and Manifold data. We explain this difference by the spatial differences between the data modalities. 1/60 in audio represents 1000 features or 83ms of data, whereas for images this represents only 12 features or a patch of shape 2 x 2 x 3. **Functa Size Ablation.** Next, we investigate the correlation between Functa size and reconstruction quality across different base network sizes. For this purpose, we define two base models: a Large (denoted by L) and a Small (denoted by S) version. The large version contains 10 layers with 128 hidden units each, and the small version contains 3 layers with 64 hidden units. We ensure that the slice used for each data modality represents the same amount of underlying values, despite the different dimensions. Based on the results from the previous ablation study, we choose 48 as the number of underlying values. This corresponds to a slicing window of 4 x 4 x 3 x 1 for shapes, 4 x 4 x 3 for images, 6 x 8 x 1 for manifolds, and 48 x 1 for audio. We sweep over Functa sizes in the range [2, 256], keeping the learning rate, batch size, optimizer, and number of steps the same as in the spatial dimension ablation study.

With results in Figure 5.7, we observe that with small slicing dimensions, the network can achieve a near-zero reconstruction error across all data modalities, with larger Functa sizes strongly correlating with better reconstruction quality. In particular, larger models start to diverge compared to smaller models once the Functa size exceeds the represented window size of 48. Most data modalities exhibit an S-curve, with reconstruction quality saturating beyond a Functa size of 256, except for images in the small model.
