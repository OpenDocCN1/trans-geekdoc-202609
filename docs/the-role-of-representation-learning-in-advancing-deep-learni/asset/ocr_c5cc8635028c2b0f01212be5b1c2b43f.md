parsing complexity can be expressed as \(O(\ln \sqrt{N_E})\), logarithmic in the square root of the number of encoder tokens.

# Cross-Attention Complexity

The Best-Node Parser selects \((L-1)(K_h K_w - 1)\) background nodes (siblings of the best-scoring node at each level) and \(K_h K_w\) leaf nodes, resulting in a total of \(L(K_h K_w - 1) + 1\) selected nodes. Therefore, the complexity of the cross-attention operation is:

```
\(O(N_D L) = O(N_D \ln \min\{H_0, W_0\})\)
\(= O(N_D \ln \sqrt{N_E})\)
```

# D.3.2 Sliding Window Parser

# Parsing Complexity

We analyze the complexity of Algorithm 4.3 by examining the operations within each iteration. Similar to the Best-Node Parser, the initial steps involve extracting the children of a node, projecting the node embeddings (i.e. computing \(K\)), calculating similarity scores and finding the node with maximum score. These operations, as detailed in D.3.1, have a combined complexity of \(O((K_h K_w) d_{\text{model}}^2)\). In addition to these steps, the Sliding Window Parser performs the following operations:

+   1. AreaOfInterest(\(\cdot\)): This is an indexing operation with a complexity of \(O(1)\).

+   2. Computation of \(\tilde{K}\): Projecting the node embeddings in the expanded search area has a complexity of \(O(K_h K_w d_{\text{model}}^2)\), similar to the computation of \(K\).

+   3. SelectNodes(\(\cdot\)): This involves:
+   (a) 2D convolution: This operation slides a window of size \(\tilde{K}_h \times \tilde{K}_w\) across the attention scores to identify the region with the highest cumulative score. The complexity is \(O((3K_h - \tilde{K}_h + 1)(3K_w - \tilde{K}_w + 1)(\tilde{K}_h \tilde{K}_w)) = O(1)\), constant with respect to \(N_E\).
+   (b) Finding the window with the maximum cumulative score has a complexity of \(O((3K_h - \tilde{K}_h + 1)(3K_w - \tilde{K}_w + 1)) = O(1)\), also constant with respect to \(N_E\).
