# ## 3.5 Conclusion

In this chapter, we have shown that when training a classifier using a pre-trained backbone, the transition point from diversity to uncertainty-based active learning methods occurs early. Based on these results, we present TCM, a simple, yet effective hybrid strategy that outperforms all other methods when compared on a wide range of data regimes and datasets. By using TypiClust for the first few steps and then switching to Margin, TCM selects informative instances in both low and high data regimes. Using the simple heuristics laid out by TCM, practitioners can apply active learning easily and effectively to their use case.
