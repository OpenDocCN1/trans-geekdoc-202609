# 6.3.3 Complexity Analysis

Table 6.6 compares the computational complexity of the proposed algorithms with that of standard global self-attention and default cross-attention. The main contributing factors for the improved complexity of the encoder are the local operations involved in building the tree. The decoder is able to parse the tree in sub-linear time thanks to its structure, at the same time selecting a sub-linear number of tokens for cross-attention. The derivations for the computational complexities can be found in sections D.2 and D.3.

In this section, we compare the performance of our Tree Transformer model against two baselines: a Backbone-Decoder baseline and a standard Encoder-Decoder Transformer.
