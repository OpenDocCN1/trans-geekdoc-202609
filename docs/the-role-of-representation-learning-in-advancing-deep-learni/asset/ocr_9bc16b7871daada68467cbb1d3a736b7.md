The tree decoder parses the tree and selects relevant nodes for cross-attention for the decoder tokens. Finally, the output head predicts bounding boxes and class labels.

The self-attention and cross-attention components part of the widely used transformer architecture enable the network to capture contextual information from its input. Although this architecture is extremely powerful, its complexity is quadratic for self-attention and linear for cross-attention. These scaling properties not only restrict the maximum processable sequence length but also indirectly limit model size, as computational resources must be allocated between processing longer sequences or employing larger, more complex models. This trade-off seems rather unintuitive, since information retrieval and logical processing get mixed. Architectures such as Perceiver IO [134] and DETR [35] avoid this problem by separating these two processes to the encoder and the decoder, respectively. In this chapter, we build on top of DETR by introducing a novel tree-based encoder-decoder architecture designed to address the scalability limitations in information retrieval for transformers. Inspired by recent work on tree cross-attention [90], our model first employs an encoder to construct a hierarchical tree representation of the input. Our encoder avoids global self-attention, achieving a reduced complexity of O(NE). Subsequently, a decoder parses this tree, selecting nodes relevant to the task at hand.
