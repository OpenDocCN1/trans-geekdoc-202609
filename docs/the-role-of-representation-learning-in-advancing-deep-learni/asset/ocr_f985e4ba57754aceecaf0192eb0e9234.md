All together the resulting ILP for GALO (NN) looks as follows:

```
arg max r
x \in \mathcal{X}
s.t.
y - z^K \le r
z^K - y \le r
y' - z^K + C \cdot b_{y'} \ge r
z^K - y' + C \cdot (1 - b_{y'}) \ge r \quad \forall y' \in Y
b_{y'} \in \{0, 1\} \forall y' \in Y
r \in \mathbb{R}
z^0 = x
z^k - q^k = W^{k-1} \cdot z^{k-1} + b^{k-1}
0 \le z^k \le y^k \cdot L
0 \le q^k \le (1 - y^k) \cdot L
y^k \in \{0, 1\}^{d_k}
\forall k \in \{1, ..., K\}
```

We have shown that the ILP for the linear model defined in (2.13) is equivalent to the Optimization Problem (2.12). The additional constraints in (2.14) only ensure that \(\tilde{v}_i(x)\) is expressed in a linear way. They do not affect the set of feasible solutions in any way. Hence, the ILP (2.14) is also equivalent to the Optimization Problem (2.12).

Finally, to generate the initial bids for bidder \(i\), we can adapt Algorithm 2.13 to a neural network by solving ILP (2.14) instead of ILP (2.13) in line 6.
