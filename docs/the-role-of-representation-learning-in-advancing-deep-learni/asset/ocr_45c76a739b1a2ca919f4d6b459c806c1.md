way. If \( h_j^{i,k} \ge 0 \), we set \( z_j^{i,k} = h_j^{i,k} \), \( y_j^{i,k} = 1 \) and \( s_j^{i,k} = 0 \), if it is negative, \( z_j^{i,k} \) and \( y_j^{i,k} \) are both 0 and \( s_j^{i,k} = -h_j^{i,k} \).

We present Lemma 2.2 from Weisteiner and Seuken [285], which shows how one can encode the output values of a layer using a set of linear constraints.

**Lemma 2.2.** Let \( W^{i,k-1} \circ o^{i,k-1} + b^{i,k-1} \in \mathbb{R}^{d_k^i} \) be fixed for \( a \in \{1, ..., K_i\} \) (where \( K_i + 1 \) denotes the number of layers including input and output layer). Furthermore, let \( z^{i,k}, s^{i,k} \in \mathbb{R}^{d_k^i}, y^{i,k} \in \mathbb{R}^{d_k^i} \). Consider the following linear constraints:

```
z^{i,k} - s^{i,k} = W^{i,k-1} \circ o^{i,k-1} + b^{i,k-1} \tag{2.2}

0 \le z^{i,k} \le y^{i,k} \cdot L \tag{2.3}

0 \le s^{i,k} \le (1 - y^{i,k}) \cdot L \tag{2.4}
```

The polytope defined by (2.2) - (2.4) is not empty and every element \( (z^{i,k}, s^{i,k}, y^{i,k}) \) of this polytype satisfies \( z^{i,k} = o^{i,k} \).

Here, \( L \) denotes a big constant, that is guaranteed to be large enough to satisfy that every element in \( z^{i,k} \) and in \( s^{i,k} \) for all \( k \in \{1, ..., K_i\} \) is smaller than \( L \).

Using Lemma 2.2, we can reformulate the WDP 2.1 into a MIP, so it can be efficiently solved using a linear program solver:

```
arg max_{a \in \mathcal{X}^{n, z^{i,k}, s^{i,k}, y^{i,k}}} \sum_{i \in \mathcal{N}} z^{i, K_i}

s.t. \forall i \in \mathcal{N}

z^{i, 0} = a_i,

\left\{\begin{aligned}
z^{i,k} - s^{i,k} &= W^{i,k-1} \cdot z^{i,k-1} + b^{i,k-1} \\
0 \le z^{i,k} \le y^{i,k} \cdot L \\
0 \le s^{i,k} \le (1 - y^{i,k}) \cdot L \\
y^{i,k} \in \{0, 1\}^{d_k^i}
\end{aligned}\right\} \forall k \in \{1, ..., K_i\} \tag{2.5}

a_{ij} \in \{0, 1\}, \quad \forall j \in \mathcal{M}

\sum_{i \in \mathcal{N}} a_{ij} \le 1, \quad \forall j \in \mathcal{M}
```

We omit the proof for the equivalence of the the WDP (2.1) and the MIP (2.5) and refer to [285].
