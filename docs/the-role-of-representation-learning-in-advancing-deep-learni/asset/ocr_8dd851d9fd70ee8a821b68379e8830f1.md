# D.1.1 Problem Description

Object detection aims to locate and identify objects within an image. This involves determining both the position of each object and its corresponding class label. Formally, we can represent the object detection process as a function f that maps an input image I to a set Y of bounding boxes and their associated class labels:

```
f : \mathbb{R}^{H \times W \times C} \to \mathcal{Y}
I \mapsto Y := \left\{ (\mathbf{b}_i, c_i) \in [0; 1]^4 \times [n_C] : i \in [n_O] \right\}
```
