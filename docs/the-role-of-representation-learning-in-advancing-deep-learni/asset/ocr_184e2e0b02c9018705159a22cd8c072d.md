# 5.2.3 Transformer Architecture

The vision transformer [67] has achieved great success in many computer vision tasks. It has also been successfully applied to SISR tasks [39]. However, due to self-attention scaling quadratically with input size, the success for using vision transformers in SISR has been limited. The Swin-transformer [172] is a hierarchical transformer architecture, that, thanks to its sliding window local self-attention, is able to scale to much larger input sizes. Many works have applied the Swin-transformer in SISR [163, 124, 42, 313], significantly improving the state-of-the-art.

In this chapter, we build on the success of the Swin-transformer. In combination with the flexibility of INRs, we are able to design a super-resolution model that can be used for a large range of domains.

# 5.3.1 Implicit Neural Representations

The initial step in our framework involves converting raw discrete data into a continuous space. This is achieved by fitting a neural network to each feature within a data point. The neural network's inputs are normalized coordinates, and the outputs correspond to features such as amplitude in audio, RGB values in images, or voxel occupancy in 3D shapes. Given a data point $D$ with a set of coordinates $X$ and feature values $Y$, the network aims to minimize the L2 loss between each network output and the corresponding feature $\{(\theta(\mathbf{x}_i), \mathbf{y}_i \mid i \in D\}$, as outlined in Equation (5.1).

```
\min_{\theta} \mathcal{L}(X, Y) = \min_{\theta} \sum_{i \in D} \|\theta(\mathbf{x}_i) - \mathbf{y}_i\|_2^2
```

The network consists of a sequence of linear layers, represented as $\mathbf{Wx} + \mathbf{b}$, where $\mathbf{W}$ is a learnable weight matrix and $\mathbf{b}$ is a bias vector. Before activation, each layer output is scaled by a constant factor $\omega_0$. We follow the approach of [245], using a sinusoidal activation function, resulting in the form of Equation (5.2). Where $\mathbf{a}^{(l)}$ is the activation of the l'th layer.

```
\mathbf{a}^{(l)} \mapsto \sin(\omega_0 \cdot (\mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}))
```
