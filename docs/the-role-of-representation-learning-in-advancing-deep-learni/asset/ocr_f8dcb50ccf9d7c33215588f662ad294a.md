At first glance, these diverse data modalities, ranging from 1D to 3D spaces and represented in various forms, appear inherently different. This diversity poses a challenge for developing a unified SR approach applicable across modalities. However, Implicit Neural Representations (INRs) offer a promising solution by modeling data as continuous functions parameterized by a neural network. In an INR, the input to the network consists of coordinates—such as time, Cartesian coordinates, or polar coordinates—and the output is the corresponding feature value at that point. For instance, in the case of an image, the network outputs pixel color values for given spatial positions.

By leveraging INRs, the SR task can be reframed as transforming the INR fitted on low-resolution data to generate high-resolution output during inference. This perspective abstracts the SR problem away from the specifics of any particular data modality, allowing for a unified architecture that is adaptable to any data modality.
