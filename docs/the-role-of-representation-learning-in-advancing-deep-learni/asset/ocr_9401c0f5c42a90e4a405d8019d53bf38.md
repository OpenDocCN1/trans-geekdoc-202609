The measurements are evenly spaced between \(\lambda \in [\pi/2, -\pi/2]\) and \(\phi \in [0, 2\pi)\) with step-sizes \([0.25^\circ, 0.25^\circ]\). We down-sampled the grid from \(721 \times 1440\) to \(180 \times 360\) using bi-linear interpolation. We treat each time-step as a different sample. The train-, validation- and test-split is done at 10 000, 2200 and 2200 respectively. Similar work transforms the polar coordinates to cartesian coordinates by letting \(\mathbf{x} = (\cos \lambda \cos \phi, \cos \lambda \sin \phi, \sin \phi)\) [73]. However, we leave ours in polar form as we already have the shape data modality with 3D Cartesian coordinates. In addition we min-max normalize the data to the range [0, 1] using the all-time minimum- and maximum temperatures measured in the dataset.

**3D Shapes.** For our work with 3D shapes, we utilized the ShapeNet Core [38] dataset, which is a curated and richly annotated subset of the comprehensive ShapeNet dataset. ShapeNet Core comprises 52 456 3D shapes, representing a total of 55 object categories. The models are provided in three formats: mesh, voxelized hollow, and voxelized solid. For our purposes, we use the voxelized solid representation. We only use the first 4 categories, namely Tables, Cars, Chairs and Airplanes. With 8443, 7497, 6778 and 4045 samples respectively. The dataset is split into training, validation, and test sets with 45 000, 3728, and 3728 samples, respectively. To optimize storage and ensure compatibility with our processing requirements, we downsample the voxel grid resolution from \(128 \times 128 \times 128\) to \(64 \times 64 \times 64\). This downsampling makes the data mod12 divisible and reduces disk space usage. We employed trilinear interpolation for downsampling using the `torch.nn.functional.interpolate` function with trilinear mode. We also evaluated `scipy.ndimage.zoom` as done in [73], but observed no significant visual differences compared to the PyTorch method. However, the PyTorch implementation proved computationally more efficient, as it avoids polynomial fitting. After interpolation, voxels with a value > 0.05 are considered as occupied.
