# B.1.4 Mpi3d Toy

The Mpi3d Toy dataset [103] includes the following ground truth factors: object color, object shape, object size, camera height, background color, first degree of freedom, second degree of freedom. It consists of low-quality renders of the experimental setup.

# B.1.5 Mpi3d Real

The Mpi3d Real dataset [103] includes the same ground truth factors as Mpi3d Toy. It consists of real pictures of an experimental setup.
