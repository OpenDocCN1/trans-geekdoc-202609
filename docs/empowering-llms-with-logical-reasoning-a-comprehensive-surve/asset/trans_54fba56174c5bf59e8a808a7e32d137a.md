

扩展大语言模型（LLMs）的推理能力以建模逻辑来应对不确定性，并开发能够同时满足多个逻辑约束的算法。这些进展对于提高 LLM 在需要精确逻辑的应用中的可靠性和稳健性至关重要，并将最终弥补交互式 LLM 与现实场景中复杂推理需求之间的差距。
