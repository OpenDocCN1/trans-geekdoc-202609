# 2 Logical Question Answering

Leveraging language models (LLMs) for complex reasoning problems is a key focus of recent researches [Lao et al., 2023; Zhang et al., 2024]. Numerous studies have explored methods to enhance the logical reasoning capabilities of LLMs, which can be categorized into several branches, including reliance on external solvers, prompting techniques without further training and fine-tuning. Many benchmarks are developed to evaluate the logical reasoning performance of models.

# 2.1 Solver-Aided Approach: Translation via LLM and Solver

The solver-aided approach refers to parsing natural language (NL) problems into symbolic (SL) expressions, and then solving them via external solvers. The general flow of solver-aided methods can be summarized into three steps, as shown in Figure 2. These methods use LLMs to translate NL into symbolic language (such as logic programming (LP) language, first-order logic (FOL), constraint satisfaction (CSP), and boolean satisfiability (SAT) formulation) that can be recognizable by solvers. Then they use an external solver to solve the problem and use LLMs to translate the answer provided by NL into natural language to generate the final answer based on some algorithms such as majority vote.
