# ## 3.1 Negative Consistency

Logical consistency is fundamentally about avoiding contradictions. Negative consistency, can be interpreted in two ways. On the one hand, an LLM cannot hold itself simultaneously while one of p is true - (p ∨ ¬p) ∧ (¬p ∧ p) [Kashmer et al., Ghosh et al., 2023]. On the other hand, it can be seen as an anomaly in data augmentation [As Hajishiro, 2022].
