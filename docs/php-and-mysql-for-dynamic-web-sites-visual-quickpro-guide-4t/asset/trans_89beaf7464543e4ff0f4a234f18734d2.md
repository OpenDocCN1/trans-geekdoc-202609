### 介绍常量

常量与变量一样，用于临时存储值，但除此之外，常量和变量在许多方面有所不同。首先，要创建常量，你需要使用 `define()` 函数，而不是赋值运算符（`=`）：

```
define ('NAME', value);
```

请注意，根据经验法则，常量名称通常使用全大写，尽管这不是强制要求。最重要的是，常量不像变量那样使用初始美元符号（因为常量不是变量）。

常量只能被赋予 *标量* 值，如字符串或数字：

```
define ('USERNAME', 'troutocity');  
define ('PI', 3.14);
```

与变量不同，常量的值一旦定义就不能更改。

要访问常量的值（例如当你想打印它时），不能将常量放在引号内：

```
echo "Hello, USERNAME"; // 不会生效！
```

使用该代码，PHP 会按字面意思打印 *Hello, USERNAME* ![Image](graphics/circle-a.jpg)，而不是 `USERNAME` 常量的值（因为没有迹象表明 `USERNAME` 不是字面文本）。相反，要么单独打印常量：

```
echo 'Hello, ';  
echo USERNAME;
```

![Image](graphics/01_figure_18_a.jpg)

![Image](graphics/circle-a.jpg)常量不能放在带引号的字符串中。

要么使用连接运算符：

```
echo 'Hello, ' . USERNAME;
```

PHP 运行时带有几个预定义常量，这很像本章前面使用的预定义变量。这些常量包括 `PHP_VERSION`（正在运行的 PHP 版本）和 `PHP_OS`（服务器的操作系统）。下一个脚本将打印这两个值，以及用户定义常量的值。

### 单引号与双引号

在 PHP 中，理解单引号与双引号的区别很重要。对于 `echo` 和 `print`，或给字符串赋值时，你可以使用任意一种，正如迄今为止使用的示例所示。但这两种引号之间存在关键差异，且何时使用哪种也有讲究。你已经见过这种差异，但这是一个重要到足以值得进一步讨论的概念。

在 PHP 中，*单引号内的值将被视为字面量*，而*双引号内的值将被解析*。换句话说，将变量和特殊字符（**[表 1.2](#ch01.html#ch01table02)**）放在双引号内将导致打印出它们所代表的值，而不是它们的字面值。例如，假设你有

```
$var = 'test';
```

**表 1.2. 转义序列**

![Image](graphics/01tab02.jpg)

代码 `echo "var is equal to $var";` 将打印 *var is equal to test*，但代码 `echo 'var is equal to $var';` 将打印 *var is equal to $var*。使用转义的美元符号，代码 `echo "\$var is equal to $var";` 将打印 *$var is equal to test*，而代码 `echo '\$var is equal to $var';` 将打印 *\$var is equal to $var* ![Image](graphics/circle-a.jpg)。
