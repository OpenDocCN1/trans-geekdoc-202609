### 步骤详解

**3. 创建检查表单提交的条件语句并包含数据库连接脚本：**

```php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
    require (MYSQL);
}
```

由于 `mysqli_connect.php` 脚本的完整路径在配置文件中定义为常量，因此该常量可作为 `require()` 的参数。这种方法的好处是，网站中任何位置存储的文件（甚至子目录中的文件）都可以使用这段相同的代码成功包含连接脚本。

**4. 清理输入数据并建立标志变量：**

```php
$trimmed = array_map('trim', $_POST);
$fn = $ln = $e = $p = FALSE;
```

第一行代码将 `$_POST` 中的每个元素都通过 `trim()` 函数处理，并将返回结果赋值给新的 `$trimmed` 数组。关于此行的解释可见 [第 13 章](#ch13.html#ch13) “[安全方法](#ch13.html#ch13)”，当时曾用 `array_map()` 处理待发送邮件的数据。简而言之，`trim()` 函数将应用于 `$_POST` 中的每个值，免去了逐个应用 `trim()` 的麻烦。

第二行将四个变量初始化为 `FALSE`。这行代码只是以下写法的简写：

```php
$fn = FALSE;
$ln = FALSE;
$e = FALSE;
$p = FALSE;
```

**5. 验证名和姓：**

```php
if (preg_match ('/^[A-Z \'.-]{2,20}$/i', $trimmed['first_name'])) {
    $fn = mysqli_real_escape_string ($dbc, $trimmed['first_name']);
} else {
    echo '<p class="error">Please enter your first name!</p>';
}

if (preg_match ('/^[A-Z \'.-]{2,40}$/i', $trimmed['last_name'])) {
    $ln = mysqli_real_escape_string ($dbc, $trimmed['last_name']);
} else {
    echo '<p class="error">Please enter your last name!</p>';
}
```

表单的大部分验证将使用正则表达式（详见 [第 14 章](#ch14.html#ch14) “[Perl 兼容正则表达式](#ch14.html#ch14)”）。对于名字值，假设其仅包含字母、句点（如首字母缩写）、撇号、空格和连字符。此外，值的长度应在 2 到 20 个字符之间。为确保值仅包含这些字符，使用了脱字符（`^`）和美元符号（`$`）分别匹配字符串的开头和结尾。使用 Perl 兼容正则表达式时，整个模式必须放在定界符（正斜杠）内。

如果满足此条件，`$fn` 变量将被赋值为提交值经 `mysqli_real_escape_string()` 处理后的版本；否则 `$fn` 仍为 `FALSE` 并打印错误消息。

**7. 验证密码：**

```php
if (preg_match ('/^\w{4,20}$/', $trimmed['password1']) ) {
    if ($trimmed['password1'] == $trimmed['password2']) {
        $p = mysqli_real_escape_string ($dbc, $trimmed ['password1']);
    } else {
        echo '<p class="error">Your password did not match the confirmed password!</p>';
    }
} else {
    echo '<p class="error">Please enter a valid password!</p>';
}
```

密码长度必须在 4 到 20 个字符之间，且只能包含字母、数字和下划线。在 Perl 兼容正则表达式中，`\w` 恰好代表这一组合。此外，第一个密码（`password1`）必须与确认密码（`password2`）匹配。
