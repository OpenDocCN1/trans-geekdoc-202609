

为了创建表、添加记录以及从数据库请求信息，需要某种*客户端*来与 MySQL 服务器通信。本书后面将使用 PHP 脚本充当此角色，但能够使用另一种界面也是必要的。虽然有大量可用的客户端应用程序，但我将重点介绍两种：*mysql 客户端*和基于 Web 的 phpMyAdmin。第三种选择是 MySQL Query Browser，本书不作讨论，但可在 MySQL 网站（**[www.mysql.com](http://www.mysql.com)**）找到，以防您对这两种选择不满意。

本章其余部分假设您有权访问正在运行的 MySQL 服务器。如果您在自己的计算机上工作，请参阅[附录 A](#app01.html#app01)“[安装](#app01.html#app01)”，了解安装 MySQL、启动 MySQL 和创建 MySQL 用户的说明（所有这些都必须已完成，才能完成本章）。如果您使用托管服务器，您的 Web 主机应提供数据库访问权限。根据托管情况，可能会提供 phpMyAdmin，但无法使用命令行 mysql 客户端。

### 使用 mysql 客户端

mysql 客户端通常随 MySQL 软件的其余部分一起安装。虽然 mysql 客户端没有漂亮的图形界面，但它是一个可靠、标准的工具，易于使用，并且在许多不同的操作系统上表现一致。

mysql 客户端从命令行界面访问，无论是 Linux 或 Mac OS X 中的 Terminal 应用程序 ![Image](graphics/circle-a.jpg)，还是 Windows 中的 DOS 提示符 ![Image](graphics/circle-b.jpg)。如果您不习惯命令行交互，可能会觉得此界面具有挑战性，但很快就会变得容易使用。

![Image](graphics/04_figure_01_a.jpg)

![Image](graphics/circle-a.jpg)Mac OS X 中的终端窗口。

![Image](graphics/04_figure_02_b.jpg)

![Image](graphics/circle-b.jpg)Windows DOS 提示符或控制台（尽管默认是黑底白字）。

要从命令行启动应用程序，请输入其名称并按 Return 或 Enter 键：

```
mysql
```

根据服务器（或您的计算机），您可能需要输入完整路径才能启动应用程序。例如：

`/Applications/MAMP/Library/bin/mysql`（Mac OS X，使用 MAMP）

`C:\xampp\mysql\bin\mysql`（Windows，使用 XAMPP）

调用此应用程序时，可以添加参数以影响其运行方式。最常见的参数是要用于连接的用户名、密码和主机名（计算机名、URL 或 IP 地址）。您可以像这样建立这些参数：

```
mysql -u username -h hostname –p
```

**`-p`** 选项将导致客户端提示您输入密码。如果您愿意，也可以直接在 **`-p`** 提示符后输入密码来指定密码——但它将是可见的，这是不安全的。**`-h`** **`hostname`** 参数是可选的，除非没有它无法连接到 MySQL 服务器，否则可以省略。

在 mysql 客户端中，每条语句（SQL 命令）都需要以分号结尾。这些分号向客户端指示查询已完成并应运行。分号不是 SQL 本身的一部分（这是一个常见的混淆点）。这也意味着您可以在 mysql 客户端中跨多行继续同一 SQL 语句，这使得阅读和编辑更加容易（如果需要的话）。

作为访问和使用 mysql 客户端的快速演示，以下步骤将展示如何启动 mysql 客户端、选择要使用的数据库以及退出客户端。在执行这些步骤之前，

- MySQL 服务器必须正在运行。
- 您必须拥有具有适当访问权限的用户名和密码。

这两个概念都在[附录 A](#app01.html#app01)中解释。

作为旁注，在以下步骤和本书其余部分中，我将继续提供在 Windows 和 Mac OS X 上使用 mysql 客户端的图像。虽然外观不同，但步骤和结果将完全相同。简而言之，不要担心为什么一张图片显示 DOS 提示符而下一张显示终端。

### 使用 mysql 客户端

**1.** 从命令行界面访问您的系统。

在 Unix 系统和 Mac OS X 上，这只是打开终端或类似应用程序的问题。

如果您使用 Windows 并在计算机上安装了 MySQL，请从开始菜单选择“运行”（或按 Windows 键+R），在窗口中输入 **`cmd`** ![Image](graphics/circle-c.jpg)，然后按 Enter（或单击 OK）以弹出 DOS 提示符。

![Image](graphics/04_figure_03_c.jpg)

![Image](graphics/circle-c.jpg)在 Windows 的“运行”提示符中执行 `cmd` 是访问 DOS 提示符界面的一种方法。

**2.** 使用适当的命令调用 mysql 客户端 ![Image](graphics/circle-d.jpg)。

```
/path/to/mysql/bin/mysql -u username -p
```

![Image](graphics/04_figure_04_d.jpg)

![Image](graphics/circle-d.jpg)输入实用程序的完整路径以及适当的参数以访问 mysql 客户端。

此步骤中的 **`/`*`path`*`/`*`to`*`/`*`mysql`*** 部分将主要取决于您正在运行的操作系统以及 MySQL 的安装位置。我已经根据[附录 A](#app01.html#app01)中安装的 MAMP（在 Mac OS X 上）或 XAMPP（在 Windows 上）提供了两个选项。

基本前提是您正在运行 mysql 客户端，以 *username* 身份连接，并请求提示输入密码。不想过分强调这一点，但您使用的用户名和密码值必须已在 MySQL 中建立为有效用户（请参阅[附录 A](#app01.html#app01)）。

**3.** 在提示符下输入密码并按 Return/Enter 键。

此处使用的密码应为前一步中指定的用户的密码。如果您使用了正确的用户名/密码组合（即具有有效访问权限的人），您应该会看到如 ![Image](graphics/circle-e.jpg) 所示的欢迎信息。如果拒绝访问，您可能使用的值不正确（请参阅[附录 A](#app01.html#app01) 了解创建用户的说明）。

![Image](graphics/04_figure_05_e.jpg)

![Image](graphics/circle-e.jpg)如果您成功登录，将看到如下欢迎消息。

**4.** 选择要使用的数据库 ![Image](graphics/circle-f.jpg)。

```
USE test;
```

![Image](graphics/04_figure_06_f.jpg)

![Image](graphics/circle-f.jpg)进入 mysql 客户端后，运行 `USE` 命令以选择要使用的数据库。

**`USE`** 命令选择用于每个后续命令的数据库。*test* 数据库是 MySQL 默认安装的数据库。假设它存在于您的服务器上，所有用户都应该能够访问它。

**5.** 退出 mysql ![Image](graphics/circle-g.jpg)。

```
exit
```

![Image](graphics/04_figure_07_g.jpg)

![Image](graphics/circle-g.jpg)输入 `exit` 或 `quit` 以终止 MySQL 会话并离开 mysql 客户端。

您也可以使用命令 **`quit`** 离开客户端。此步骤——与您在 mysql 客户端中输入的大多数其他命令不同——不需要在末尾加分号。

**6.** 退出终端或 DOS 控制台会话。

```
exit
```

命令 **`exit`** 将终止当前会话。在 Windows 上，它还将关闭 DOS 提示符窗口。

