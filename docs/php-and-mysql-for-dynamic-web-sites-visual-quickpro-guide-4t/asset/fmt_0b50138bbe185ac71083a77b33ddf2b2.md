### Paginating Query Results

*Pagination* is a concept you're familiar with even if you don't know the term. When you use a search engine like Google, it displays the results as a series of pages and not as one long list. The `view_users.php` script could benefit from this feature.

Paginating query results makes extensive use of the `LIMIT` SQL clause introduced in [Chapter 5](#ch05.html#ch05). `LIMIT` restricts which subset of the matched records is actually returned. To paginate the returned results of a query, each iteration of the page will run the same query using different `LIMIT` parameters. The first page viewing will request the first *X* records; the second page viewing, the second group of *X* records; and so forth. To make this work, two values must be passed from page to page in the URL, like the user IDs passed from the `view_users.php` page. The first value is the total number of pages to be displayed. The second value is an indicator of which records the page should display with this iteration (i.e., where to begin fetching records).

Another, more cosmetic technique will be demonstrated here: displaying each row of the table—each returned record—using an alternating background color ![Image](graphics/circle-a.jpg). This effect will be achieved with ease, using the ternary operator (see the sidebar "The Ternary Operator").
