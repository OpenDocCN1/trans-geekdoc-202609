### 使用隐藏表单输入

在前面的示例中，编写了 `view_users.php` 脚本的新版本。该版本现在包含指向 `edit_user.php` 和 `delete_user.php` 页面的链接，通过 URL 传递每个用户的 ID。下一个示例 `delete_user.php` 将接收传递的用户 ID，并允许管理员删除该用户。虽然你可以让此页面在被访问时立即执行 `DELETE` 查询，但出于安全考虑（并防止意外删除），应该分多个步骤进行 ![Image](graphics/circle-a.jpg)：

1.  页面必须检查是否接收到了数字用户 ID。
2.  一条消息将确认是否应删除该用户。
3.  用户 ID 将存储在隐藏表单输入中。
4.  提交此表单后，用户将实际被删除。

![Image](graphics/10_figure_03_c.jpg)

![Image](graphics/circle-a.jpg)此图概述了用户删除脚本将执行的步骤。

#### 使用隐藏表单输入

1.  在文本编辑器或 IDE 中开始一个新的 PHP 文档，命名为 `delete_user.php`（**[脚本 10.2](#ch10.html#ch10ex02)**）：

    ```php
    <?php # Script 10.2 - delete_user.php
    ```

2.  包含页面页眉：

    ```php
    $page_title = 'Delete a User';

    include ('includes/header.html');

    echo '<h1>Delete a User</h1>';
    ```

    该文档将使用与应用程序中其他页面相同的模板系统。如有需要，请参阅[第 9 章](#ch09.html#ch09)和[第 3 章](#ch03.html#ch03)以获取说明。

3.  检查有效的用户 ID 值：

    ```php
    if ( (isset($_GET['id'])) && (is_numeric($_GET['id'])) ) {
        $id = $_GET['id'];
    } elseif ( (isset($_POST['id'])) && (is_numeric($_POST['id'])) ) {
        $id = $_POST['id'];
    } else {
        echo '<p class="error">This page has been accessed in error.</p>';
        include ('includes/footer.html');
        exit();
    }
    ```

---

该脚本依赖于拥有一个有效的用户 ID，以便在 `DELETE` 查询的 `WHERE` 子句中使用。首次访问此页面时，用户 ID 应通过 URL 传递（页面 URL 将以 `delete_user.php?id=X` 结尾），这是在 `view_users.php` 页面中点击 *Delete* 链接后发生的。第一个 `if` 条件检查此类值是否存在且该值是否为数字。

正如你将看到的，脚本随后会将用户 ID 值存储在隐藏表单输入中。当表单提交（回到这个同一页面）时，脚本将通过 `$_POST` 接收该 ID。第二个条件检查这一点，并再次确认 ID 值为数字。

如果这两个条件都不为 TRUE，则页面无法继续，因此会显示一条错误消息并终止脚本的执行 ![Image](graphics/circle-b.jpg)。
