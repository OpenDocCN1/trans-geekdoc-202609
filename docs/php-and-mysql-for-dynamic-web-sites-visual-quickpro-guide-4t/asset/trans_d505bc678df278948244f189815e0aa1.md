### 按类型验证文件

[第 11 章](#ch11.html#ch11)包含一个在 PHP 中处理文件上传的示例。由于上传文件允许用户在您的服务器上放置比通过表单发送的文本更强效的内容类型，因此在处理文件上传时，对安全性的重视程度再怎么强调都不为过。在该特定示例中，通过检查其 MIME 类型来验证上传的文件。具体来说，对于上传的文件，`$_FILES['upload']['type']` 指的是上传浏览器提供的 MIME 类型。这是一个好的开始，但恶意用户很容易欺骗浏览器提供虚假的 MIME 类型。确认文件类型的更可靠方法是使用 Fileinfo 扩展。

Fileinfo 扩展在 PHP 5.3 中加入，它通过在文件中搜索“魔术字节”或“魔术数字”来确定文件的类型（和编码）。例如，构成 GIF 图像的数据必须以代表 *GIF89a* 或 *GIF87a* 的 ASCII 码开头；构成 PDF 文件的数据以 *%PDF* 开头。

要使用 Fileinfo，首先创建一个 Fileinfo 资源：

```
$fileinfo = finfo_open(kind);
```

*kind* 值将是几个常量之一，指示您要创建的资源类型。要确定文件类型，该常量为 `FILEINFO_MIME_TYPE`：

```
$fileinfo = finfo_open(FILEINFO_MIME_TYPE);
```

接下来，调用 `finfo_file()` 函数，提供 Fileinfo 资源和对要检查的文件的引用：

```
finfo_file($fileinfo, $filename);
```

该函数根据文件实际的魔术字节返回文件的 MIME 类型（给定已创建的资源）。

最后，完成后，您应该关闭 Fileinfo 资源：

```
finfo_close($fileinfo);
```

下一个脚本将使用此信息来确认上传的文件是 RTF（富文本格式）。请注意，只有当您使用 PHP 5.3 或更高版本时，才能测试此示例 ![Image](graphics/circle-a.jpg)。如果您使用的是早期版本，则需要通过 PECL（PHP 扩展社区库，[http://pecl.php.net](http://pecl.php.net)）安装 Fileinfo 扩展。在 Windows 上，如果您使用的是 PHP 5.3 或更高版本，Fileinfo DLL 文件应包含在您的安装中，但您可能需要在 `php.ini` 配置文件中启用它（从 peachpit.com 下载[附录 A](#app01.html#app01)“[安装](#app01.html#app01)”）。
