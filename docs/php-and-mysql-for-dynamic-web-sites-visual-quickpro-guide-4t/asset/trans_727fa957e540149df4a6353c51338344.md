

# 在 Mac OS X 上安装 MAMP

我将在接下来的步骤中介绍安装过程。如果您遇到任何问题，可以使用本书的配套论坛 (www.LarryUllman.com/forums/)，但您可能会发现直接求助 MAMP 官网更有效（毕竟这是他们的产品）。此外，安装程序运行良好且并不难用，因此我不会详述过程中的每一步，而是重点介绍最重要的注意事项。

## 在 Mac OS X 上安装 MAMP

**1.** 从 www.mamp.info 下载最新版本的 MAMP。

在首页上，点击 *Downloads*，然后点击 *Download: MAMP & MAMP PRO 1.9.6.1* ![Image](graphics/circle-a.jpg)。（随着 MAMP 新版本的发布，链接和文件名显然会相应变化。）

![Image](graphics/20_figure_06_a.jpg)

![Image](graphics/circle-a.jpg) 从 www.mamp.info 的此页面下载 MAMP。

同一个下载文件同时包含这两个产品。事实上，MAMP Pro 只是一个用于控制和自定义同一 MAMP 软件的更友好的界面。

**2.** 在您的电脑上，双击下载的文件以挂载磁盘映像 ![Image](graphics/circle-b.jpg)。

![Image](graphics/20_figure_07_b.jpg)

![Image](graphics/circle-b.jpg) 下载的 MAMP 磁盘映像的内容。

**3.** 将磁盘映像中的 `MAMP` 文件夹复制到您的 `Applications`（应用程序）文件夹中。

如果您认为可能更倾向于商业版 MAMP PRO，请也复制该文件夹（同样，它是 MAMP 的一个界面，因此需要两个文件夹）。MAMP PRO 附带 14 天免费试用期。

无论您选择哪个文件夹，请注意您**必须**将其放置在 `Applications` 文件夹内。它不能放在子文件夹或电脑上的其他目录中。

**4.** 打开 `/Applications/MAMP`（或 `/Applications/MAMP PRO`）文件夹。

**5.** 双击 MAMP（或 MAMP PRO）应用程序以启动程序 ![Image](graphics/circle-c.jpg)。

![Image](graphics/20_figure_08_c.jpg)

![Image](graphics/circle-c.jpg) 简单的 MAMP 应用程序，用于控制和配置 Apache、PHP 和 MySQL。

启动服务器可能只需片刻，但随后您将看到类似于 ![Image](graphics/graycircle-c.jpg)（针对 MAMP）或 ![Image](graphics/circle-d.jpg)（针对 MAMP PRO）的结果。

![Image](graphics/20_figure_09_d.jpg)

![Image](graphics/circle-d.jpg) MAMP PRO 应用程序，用于控制和配置 Apache、PHP、MySQL 等。

启动 MAMP 时，起始页面也应在您的默认 Web 浏览器中打开 ![Image](graphics/circle-e.jpg)。通过此页面，您可以查看正在运行的 PHP 版本及其配置方式，并使用 phpMyAdmin 与 MySQL 数据库进行交互。

![Image](graphics/20_figure_10_e.jpg)

![Image](graphics/circle-e.jpg) MAMP Web 起始页面。

使用 MAMP PRO，您可以通过点击 WebStart 按钮 ![Image](graphics/circle-d.jpg) 访问同一页面。

**6.** 要启动、停止和配置 MAMP，请使用 MAMP 或 MAMP PRO 应用程序 ![Image](graphics/circle-c.jpg) 或 ![Image](graphics/circle-d.jpg)。

MAMP 应用程序本身没有太多内容（这是一件好事），但如果您点击 Preferences（偏好设置），可以调整应用程序的行为 ![Image](graphics/circle-f.jpg)、设置要运行的 PHP 版本等。

![Image](graphics/20_figure_11_f.jpg)

![Image](graphics/circle-f.jpg) 这些选项决定了启动和停止 MAMP 应用程序时会发生什么。

MAMP PRO 还可以轻松创建不同的*虚拟主机*（即不同的站点；稍后在本附录中单独讨论）、调整 Apache 的配置和运行方式、使用动态 DNS、更改邮件发送方式等。

**7.** 立即更改 root MySQL 用户的密码。

如何执行此操作将在本附录后面解释。

# 管理 MySQL 用户

一旦您成功安装了 MySQL，就可以开始创建 MySQL 用户。MySQL 用户是一个基本的安全概念，用于限制对存储数据的访问和影响。为了澄清，您的数据库可以有多个不同的用户，就像您的操作系统可能有多个用户一样。但 MySQL 用户不同于操作系统用户。在您自己的电脑上学习 PHP 和 MySQL 时，不一定需要创建新用户，但实际生产站点需要拥有具有适当权限的专用 MySQL 用户。

初始 MySQL 安装附带一个用户（名为 `root`），且未设置密码（使用 MAMP 时除外，MAMP 会设置默认密码为 `root`）。至少，您应该在安装 MySQL 后为 root 用户创建一个新的、安全的密码。之后，您可以创建其他权限更有限的用户。作为一条规则，您不应该将 root 用户用于正常的日常操作。

在接下来的几页中，我将引导您完成这两个过程。请注意，如果您使用的是托管服务器，他们很可能会为您创建 MySQL 用户。这些说明需要使用命令行 mysql 客户端或 phpMyAdmin。如果您不知道如何在电脑上访问其中任何一个，请快速阅读[第 4 章](#ch04.html#ch04)“[MySQL 简介](#ch04.html#ch04)”中的 *Accessing MySQL*（访问 MySQL）部分。

## 设置 root 用户密码

当您安装 MySQL 时，root 用户没有设置任何值——或没有安全密码。这当然是一个安全风险，应该在您开始使用服务器之前解决（因为 root 用户拥有无限权限）。

只要 MySQL 服务器正在运行，您就可以使用 phpMyAdmin 或 mysql 客户端设置任何用户的密码。如果 MySQL 当前未运行，请立即使用附录前面概述的步骤启动它。

其次，您必须以 root 用户身份连接到 MySQL，才能更改 root 用户的密码。

## 通过 MySQL 客户端为 root 用户分配密码

**1.** 连接到 MySQL 客户端。

如有需要，请参阅[第 4 章](#ch04.html#ch04)获取详细说明。

**2.** 输入以下命令，将 `thepassword` 替换为您想要使用的密码 ![Image](graphics/circle-a.jpg)：

```
SET PASSWORD FOR 'root'@' localhost' = PASSWORD ('thepassword');
```

![Image](graphics/20_figure_13_a.jpg)

![Image](graphics/circle-a.jpg) 在 MySQL 客户端中使用 SQL 更新 root 用户的密码。

请记住，MySQL 中的密码区分大小写，因此 `Kazan` 和 `kazan` 不能互换。`PASSWORD` 一词位于实际引用的密码之前，告诉 MySQL 加密该字符串。并且 `PASSWORD` 和左括号之间不能有空格。

**3.** 退出 MySQL 客户端：

```
exit
```

**4.** 通过再次登录 MySQL 客户端来测试新密码。
