#### 创建模板

**1.** 在文本编辑器或 IDE 中新建一个文档，命名为 `header.html`（**[脚本 17.1](#ch17.html#ch17ex01)**）：

```php
<?php # Script 17.1 - header.html

header ('Content-Type: text/html; charset=UTF-8');
```

由于该脚本需要进行相当数量的数据验证和检索，因此它以一个 PHP 代码块开始。该脚本还通过 `header()` 函数向 Web 浏览器指明其编码——UTF-8。通过 `header()` 函数调用设置编码的想法在[第 11 章](#ch11.html#ch11)“[Web 应用程序开发](#ch11.html#ch11)”的一个提示中提到过。

**2.** 启动会话：

```php
$_SESSION['user_id'] = 1;
$_SESSION['user_tz'] = 'America/New_York';
// $_SESSION = array();
```

为了在用户登录后跟踪用户，站点将使用会话。由于本章中站点没有注册和登录功能，两行代码即可虚拟地让用户登录。通常，这两个值都来自数据库，但为了测试目的，它们在此处被设置。要虚拟地让用户登出，请取消第三行的注释。

**3.** 包含数据库连接：

```php
require ('../mysqli_connect.php');
```

与本书中的许多其他示例一样，这里假设 `mysqli_connect.php` 脚本存储在当前目录的上一级目录中，位于 Web 根目录之外。如果您的情况并非如此，请相应地更改此代码。
