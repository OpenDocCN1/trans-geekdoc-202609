### 7. 显示图像

显示图像：

```php
if ($image = @getimagesize ("../uploads/$pid")) {
    echo "<div align=\"center\"><img src=\"show_image.php?image=$pid&name=" . urlencode($row['image_name']) . "\" $image[3] alt=\"{$row['print_name']}\" /></div>\n";
} else {
    echo "<div align=\"center\">No image available.</div>\n";
}
```

由于图像被安全地存储在 Web 根目录之外，因此需要另一个 PHP 脚本向浏览器提供图像（**`show_image.php`** 脚本被用作 *代理脚本*）。图像本身的名称就是版画 ID，该 ID 已通过 URL 传递给此页面。

该脚本部分将首先尝试使用 **`getimagesize()`** 函数检索图像的尺寸。如果成功，则显示图像。该过程略显特殊，因为图像的来源调用了 **`show_image.php`** 页面。**`show_image.php`** 脚本（稍后编写）期望在 URL 中传递版画 ID，以及存储在数据库中的图像文件名（添加版画时存储）。这种使用 PHP 脚本显示图像的方式与 [第 11 章](#ch11.html#ch11) 中 **`show_image.php`** 的用法完全相同，只是现在它发生在另一个页面内部，而不是在独立的窗口中。

![Image](graphics/19_figure_26_h.jpg)

`view_print.php` 页面的 HTML 源代码显示了 `img` 标签的 `src` 属性如何调用 `show_image.php` 脚本，并向其传递所需的值。

如果脚本无法检索图像信息（因为服务器上没有该图像或未上传图像），则改为显示一条消息。

## 编写 `show_image.php`

### 1. 创建新 PHP 文档

在文本编辑器或 IDE 中开始一个新的 PHP 文档，命名为 **`show_image.php`**（**[脚本 19.8](#ch19.html#ch19ex08)**）：

```php
<?php # Script 19.8 - show_image.php
$image = FALSE;
$name = (!empty($_GET['name'])) ? $_GET['name'] : 'print image';
```

该脚本将执行与 [第 11 章](#ch11.html#ch11) 中的 **`show_image.php`** 相同的操作，不同之处在于有两个值被传递给此页面。服务器上实际图像的文件名将是一个数字，对应版画 ID。原始图像文件名存储在数据库中，将在向 Web 浏览器发送图像时使用。此页面不包含任何 HTML，且在此开启 PHP 标签之前，不能向 Web 浏览器发送任何内容。

**脚本 19.8.** 此脚本由 `view_print.php` ([脚本 19.7](#ch19.html#ch19ex07)) 调用，并显示存储在 **`uploads`** 目录中的图像。
