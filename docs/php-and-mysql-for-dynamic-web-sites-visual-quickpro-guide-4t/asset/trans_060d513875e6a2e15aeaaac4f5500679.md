### 使用修饰符

本章介绍了可在正则表达式模式中使用的大多数特殊字符。最后一种特殊字符是模式修饰符。**[表 14.4](#ch14.html#ch14table04)** 列出了这些修饰符。模式修饰符与其他元字符不同，它们位于结束定界符之后。

**表 14.4. 模式修饰符**

![Image](graphics/14tab04.jpg)

其中最重要的是 `i`，它启用不区分大小写的搜索。前面一系列步骤中使用 `for` 变体的所有示例都不会匹配单词 `For`。然而，`/for.*/i` 将会匹配。请注意，我在该模式中包含了定界符，因为修饰符位于结束定界符之后。同样，前面序列中的最后一步引用了侧边栏“[减少贪婪](#ch14.html#ch14sb02)”，并说明了 `for.*?` 如何执行惰性搜索。`/for.*/U` 也是如此。

多行模式很有趣，因为你可以让脱字符和美元符号表现得不同。默认情况下，它们各自应用于整个值。在多行模式下，脱字符匹配任意行的开头，美元符号匹配任意行的结尾。

#### 使用修饰符

**1.** 在 Web 浏览器中加载 `matches.php`（如果尚未加载）。

**2.** 验证电子邮件地址列表 ![Image](graphics/circle-a.jpg)。

![Image](graphics/14_figure_21_a.jpg)

![Image](graphics/circle-a.jpg)每行一个的电子邮件地址列表可使用多行模式进行验证。每个有效地址均存储在 `$matches` 中。

为此，请使用 `/^[\w.-]+@[\w.-]+\.[A-Za-z]{2,6}\r?$/m` 作为模式。你会看到我在美元符号前添加了一个可选的回车符 (`\r?`)。这是必要的，因为某些行将包含回车符而其他行则不会。而在多行模式下，美元符号匹配行的结尾。（为了更灵活，你可以改用 `\s?`。）

Tip

要始终匹配模式的开头或结尾，而不受多行设置的影响，可以使用快捷方式。在模式中，快捷方式 `\A` 仅匹配值的最开始，`\z` 匹配最末尾，而 `\Z` 匹配任意行尾，类似于单行模式下的 `$`。

### 匹配和替换模式

本章要讨论的最后一个主题是如何在值中匹配和替换模式。虽然 `preg_match()` 和 `preg_match_all()` 可以为你查找内容，但如果你想执行搜索和替换，则需要使用 `preg_replace()`。其语法为

```
preg_replace(pattern, replacement, subject);
```

该函数接受一个可选的第四个参数，用于限制替换的次数。

要将所有 `cat` 实例替换为 `dog`，你可以使用

```
$str = preg_replace('/cat/', 'dog', 'I like my cat.');
```

此函数返回修改后的值（如果未进行匹配则返回未修改的值），因此你可能需要将其赋值给变量，或将其作为参数传递给另一个函数（如通过调用 `echo` 来打印）。此外，提醒一下，上面只是一个示例：你永远不应该使用正则表达式将一个字面字符串替换为另一个，应改用 `str_replace()`。

还有一个相关概念涉及此函数，即*反向引用*。在邮政编码匹配模式——`^(\d{5})(-\d{4})?$`——中，括号内有两个分组：前五位数字和可选的连字符加四位扩展数字。在正则表达式模式中，PHP 会自动为括号分组编号，从 1 开始。反向引用允许你通过使用 `$` 加上相应的数字来引用各个部分。例如，如果你用此模式匹配邮政编码 `94710-0001`，引用 `$2` 将得到 `-0001`。代码 `$0` 指代整个初始字符串。这就是为什么 ![Image](graphics/graycircle-b.jpg) 上一节中显示 `$matches[0]` 包含完整的邮政编码匹配，`$matches[1]` 包含匹配的前五位数字，`$matches[2]` 包含匹配的连字符加四位数字。
