
本章中的前两个脚本——实际上几乎所有脚本——都需要连接到 MySQL 数据库。无需从头编写新脚本，只需将 [第 9 章](#ch09.html#ch09) “[将 PHP 与 MySQL 结合使用](#ch09.html#ch09)” 中的 `mysqli_connect.php`（脚本 9.2）复制到该站点文件的相应目录中。然后编辑其中的信息，使其连接到名为 `ecommerce` 的数据库，并使用拥有适当权限的用户名/密码/主机名组合。

此外，这两个管理脚本将使用*预处理语句*，该技术在 [第 13 章](#ch13.html#ch13) “[安全方法](#ch13.html#ch13)” 中已介绍，旨在让您积累更多使用经验。如果您对预处理语句的语法或函数感到困惑，请回顾该章。

#### 创建 add_artist.php

```html
<?php # Script 19.1 - add_artist.php
```

通常，网站的管理端会使用模板系统（可能与前台使用不同的模板），但由于本章只有两个管理脚本，因此不会开发模板。

**2.** 检查表单是否已提交：

```php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
```

**3.** 验证艺术家的名和中间名：

```php
$fn = (!empty($_POST['first_name'])) ? trim($_POST['first_name']) : NULL;
$mn = (!empty($_POST['middle_name'])) ? trim($_POST['middle_name']) : NULL;
```

艺术家的名和中间名是可选字段，而姓氏则不是（因为有些艺术家仅用一个名字称呼）。为了验证前两个名字输入，我使用*三元*运算符（在 [第 10 章](#ch10.html#ch10) “[常见编程技术](#ch10.html#ch10)” 中介绍）减少了代码量。此处的代码等同于

```php
if (!empty($_POST['first_name'])) {
$fn = trim($_POST['first_name']);
} else {
  $fn = NULL;
}
```

因为本脚本将依赖预处理语句，所以用于查询的值无需通过 `mysqli_real_escape_string()` 处理。

**4.** 验证艺术家的姓氏：

```php
if (!empty($_POST['last_name'])) {
$ln = trim($_POST['last_name']);
```

姓氏值是必填的。为了更严格的验证，您可以使用正则表达式。为了增加安全性，您可以应用 `strip_tags()` 函数。

**5.** 包含数据库连接：

```php
require ('../../mysqli_connect.php');
```

管理文件夹将位于主文件夹（`htdocs`）内部，因此比连接脚本高两级目录。包含文件时请牢记您的目录结构 ![Image](graphics/circle-b.jpg)。

![Image](graphics/19_figure_08_b.jpg)

![Image](graphics/circle-b.jpg)该 Web 应用程序的站点结构。MySQL 连接脚本和 `uploads` 目录（存储图像的位置）不在 Web 目录内（无法通过 *http://* 访问）。

**6.** 将艺术家添加到数据库：

```php
$q = 'INSERT INTO artists (first_name, middle_name, last_name) VALUES (?, ?, ?)';
$stmt = mysqli_prepare($dbc, $q);
mysqli_stmt_bind_param($stmt, 'sss', $fn, $mn, $ln);
mysqli_stmt_execute($stmt);
```

要将艺术家添加到数据库，查询语句类似于 `INSERT INTO artists (first_name, middle_name, last_name) VALUES ('John', 'Singer', 'Sargent')` 或 `INSERT INTO artists (first_name, middle_name, last_name) VALUES (NULL, NULL, 'Christo')`。查询使用预处理语句执行，详见 [第 13 章](#ch13.html#ch13)。
