

#### 编写配置文件

**1.** 在文本编辑器或 IDE 中新建一个 PHP 文档，命名为 **`config.inc.php`** (**[脚本 18.3](#ch18.html#ch18ex03)**)：

```php
<?php # Script 18.3 - config.inc.php
```

**2.** 为错误报告建立两个常量：

```php
define('LIVE', FALSE);
define('EMAIL', 'InsertRealAddress Here');
```

**`LIVE`** 常量的用法与 [第 8 章](#ch08.html#ch08) 中相同。如果为 `FALSE`，详细错误消息将发送到 Web 浏览器。网站上线后，应将此常量设置为 `TRUE`，以便永远不向 Web 用户显示详细错误消息。**`EMAIL`** 常量是网站上线时发送错误消息的地址。显然，您应使用自己的电子邮件地址作为该值。

**3.** 为全站设置建立两个常量：

```php
define ('BASE_URL', 'http://www.example.com/');
define ('MYSQL', '/path/to/mysqli_connect.php');
```

定义这两个常量只是为了让在其他脚本中执行某些操作更加容易。第一个 **`BASE_URL`** 指的是根域名 (*http://www.example.com/*)，并带有结尾斜杠。如果在自己的电脑上开发，这可能是 *http://localhost/* 或 *http://localhost/ch18/*。当脚本重定向浏览器时，代码可以简单地写成：

```php
header('Location: ' . BASE_URL . 'page.php');
```

第二个常量 **`MYSQL`** 是 MySQL 连接脚本（接下来要编写）的绝对路径。通过将其设置为绝对路径，任何文件都可以通过引用此常量来包含连接脚本：

```php
require (MYSQL);
```

将这两个值都更改为与您的环境相对应。例如，在 Windows 上使用 XAMPP 时，**`MYSQL`** 常量的正确值可能是 **`C:\\xampp\mysqli_connect.php`**。

如果将网站从一台服务器或域迁移到另一台，只需更改这两个常量，应用程序仍可正常工作。

**4.** 建立其他全站设置：

```php
date_default_timezone_set ('US/Eastern');
```

正如 [第 11 章](#ch11.html#ch11) “[Web 应用程序开发](#ch11.html#ch11)” 中所述，任何使用 PHP 日期或时间函数的情况（自 PHP 5.1 起）都要求设置时区。请将此值更改为匹配您的时区（请参阅 PHP 手册获取时区列表）。

**5.** 开始定义错误处理函数：

```php
function my_error_handler ($e_number, $e_message, $e_file, $e_line, $e_vars) {
  $message = "An error occurred in script '$e_file' on line $e_line: $e_message\n";
```

函数定义将与 [第 8 章](#ch08.html#ch08) 中解释的非常相似。该函数预期接收五个参数：错误编号、错误消息、发生错误的脚本、PHP 认为发生错误的行号，以及错误发生时存在的变量数组。然后函数开始定义 **`$message`** 变量，从传递给该函数的信息入手。

**6.** 添加当前日期和时间：

```php
$message .= "Date/Time: " . date('n-j-Y H:i:s') . "\n";
```

为了使错误报告更有用，消息中将包含当前日期和时间。换行符终止字符串，使生成的显示更易读。

**7.** 如果网站未上线，详细显示错误消息：

```php
if (!LIVE) {
  echo '<div class="error">' . nl2br($message);
  echo '<pre>' . print_r ($e_vars, 1) . "\n";
  debug_print_backtrace( );
  echo '</pre></div>';
```

如前所述，如果网站*未*上线，对于任何类型的错误，都会打印完整的错误消息。消息放置在 **`<div class="error">`** 内，将根据网站 CSS 文件中定义的规则对消息进行格式化。错误消息的第一部分是已定义的字符串，并额外将换行符转换为 HTML 换行标签。然后，在预格式化标签内，显示错误发生时存在的所有变量，以及一个*回溯*（函数调用历史等）。有关更多解释，请参阅 [第 8 章](#ch08.html#ch08)。

**8.** 如果网站已上线，将详细信息通过电子邮件发送给管理员，并为访客打印一条通用消息：

```php
} else { // Don't show the error:
  $body = $message . "\n" . print_r ($e_vars, 1);
  mail(EMAIL, 'Site Error!', $body, 'From: email@example.com');
  if ($e_number != E_NOTICE) {
    echo '<div class="error">A system error occurred. We apologize for the inconvenience.</div><br />';
  }
} // End of !LIVE IF.
```

除了具体的错误消息外，所有现有变量以及当前日期和时间也将显示出来。错误报告将被格式化以适应网站的模板。在网站的生产或上线阶段，错误将得到更优雅的处理。那时，详细错误消息不会在 Web 浏览器中打印，而是发送到电子邮件地址。

如果网站上线时发生错误，用户将只看到如下消息（但详细错误消息将通过电子邮件发送给管理员）。

最后，此脚本可以定义网站中可能多次使用的任何函数。本网站没有此类函数，但这也是此类文件的另一个合乎逻辑的用途。
