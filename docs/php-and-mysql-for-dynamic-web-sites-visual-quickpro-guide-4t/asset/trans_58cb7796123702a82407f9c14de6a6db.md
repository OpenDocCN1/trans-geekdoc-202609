
如果您不想执行简单的相等性测试，可以将条件写入 **`CASE()`** 中：

```sql
SELECT message_id, CASE WHEN date_entered > NOW() THEN 'Future' ELSE 'PAST' END AS Posted FROM messages
```

![Image](graphics/07_figure_24_c.jpg)

`CASE()` 可像 `IF()` 一样使用，以自定义返回值。

同样，您可以根据需要添加多个 **`WHEN...THEN`** 子句，并在不必要时省略 **`ELSE`**。

为了练习使用这些函数，让我们在 *forum* 数据库上运行更多查询（提前提醒，它们会变得有点复杂）。

#### 执行高级选择

**1.** 连接到 MySQL 并选择 *forum* 数据库。

**2.** 对于每个论坛，查找最新帖子的日期和时间，如果论坛没有帖子则返回 *N/A* ![Image](graphics/circle-d.jpg)：

```sql
SELECT f.name,
COALESCE(MAX(m.date_entered), 'N/A') AS last_post
FROM forums AS f
LEFT JOIN messages AS m
USING (forum_id)
GROUP BY (m.forum_id)
ORDER BY m.date_entered DESC;
```

![Image](graphics/07_figure_25_d.jpg)

![Image](graphics/circle-d.jpg) `COALESCE()` 函数用于将 `NULL` 值转换为字符串 *N/A*（请参阅最后一条记录）。

首先，为了同时查找论坛名称和该论坛中最新帖子的日期，需要进行连接。具体来说，需要外连接，因为可能存在没有帖子的论坛。为了查找每个论坛中最新的帖子，将聚合函数 **`MAX()`** 应用于 *date_entered* 列，并且结果必须按 *forum_id* 分组（以便 **`MAX()`** 应用于每个论坛内的每个帖子子集）。

此时，如果不调用 **`COALESCE()`** 函数，结果将为没有任何消息的论坛返回 **`NULL`**。最后一步是应用 **`COALESCE()`**，以便当 **`MAX(m.date_entered)`** 的值为 **`NULL`** 时，返回字符串 *N/A*。

**3.** 对于每条消息，如果该消息是对另一条消息的回复，则在主题后追加字符串 *(REPLY)* ![Image](graphics/circle-e.jpg)：

```sql
SELECT message_id,
CASE parent_id WHEN 0 THEN subject
ELSE CONCAT(subject, ' (Reply)') END AS subject
FROM messages;
```

![Image](graphics/07_figure_26_e.jpg)

![Image](graphics/circle-e.jpg) 在这里，字符串 *(Reply)* 会被追加到作为回复的任何消息的主题后。

*messages* 表中 *parent_id* 不为 0 的记录是对现有消息的回复。对于这些消息，让我们在主题值后追加 *(REPLY)* 以示区别。为此，**`CASE`** 语句在 *parent_id* 值等于 0 时仅返回未经修改的主题。如果 *parent_id* 值不等于 0，则再次借助 **`CASE`** 将字符串 *(REPLY)* 连接到主题后。整个结构被赋予 *subject* 别名，因此它仍以原始的“subject”标题返回。

**4.** 对于每个用户，查找他们发布的消息数量，将零值转换为字符串 *None* ![Image](graphics/circle-f.jpg)：

```sql
SELECT u.username,
IF(COUNT(message_id) > 0, COUNT(message_id), 'None') AS Posts
FROM users AS u
LEFT JOIN messages AS m
USING (user_id)
GROUP BY (u.user_id);
```

![Image](graphics/07_figure_27_f.jpg)

![Image](graphics/circle-f.jpg) 多亏了 `IF()` 调用，未发布任何消息的用户的发帖数将显示为 *None*。

这在某种程度上是第 2 步查询的变体。左连接桥接 *users* 和 *messages*，以同时获取用户名和发布的消息计数。为了执行计数，结果按 *users.user_id* 分组。到此为止，查询将为从未发帖的每个用户返回 0 ![Image](graphics/circle-g.jpg)。为了将这些零转换为字符串 *None*，同时保留非零计数，应用了 **`IF()`** 函数。该函数的第一个参数设定条件：如果计数大于零。第二个参数表示条件为真时返回计数。第三个参数表示条件为假时返回字符串 *None*。

![Image](graphics/07_figure_28_g.jpg)

![Image](graphics/circle-g.jpg) 如果不使用 `IF()`，查询结果将如图所示（与 ![Image](graphics/graycircle-f.jpg) 对比）。

***

提示

**`IFNULL()`** 函数有时可代替 **`COALESCE()`** 使用。其语法为：

```sql
IFNULL(value, return_if_null)
```

如果第一个参数（如命名列）的值为 **`NULL`**，则返回第二个参数。如果参数值不为 NULL，则返回该参数的值。

#### 创建 FULLTEXT 索引

首先，**`FULLTEXT`** 搜索需要 **`FULLTEXT`** 索引。正如第 6 章“[数据库设计](#ch06.html#ch06)”中预览的那样，这种索引类型只能在 MyISAM 表上创建。接下来的示例将使用 *forum* 数据库中的 *messages* 表。因此，第一步是在 *body* 和 *subject* 列上添加 **`FULLTEXT`** 索引。向现有表添加索引需要使用 **`ALTER`** 命令，如侧边栏所述。

#### 添加 FULLTEXT 索引

**1.** 连接到 MySQL 并选择 *forum* 数据库（如果尚未选择）。

**2.** 确认 *messages* 表的类型 ![Image](graphics/circle-a.jpg)：

```sql
SHOW TABLE STATUS\G
```

![Image](graphics/07_figure_29_a.jpg)

![Image](graphics/circle-a.jpg) 要确认表的类型，请使用 `SHOW TABLE STATUS` 命令。

**`SHOW TABLE STATUS`** 查询返回数据库中每个表的大量信息，包括表的存储引擎。由于查询返回大量信息，命令以 **`\G`** 结尾，而不是分号。这会指示 mysql 客户端以垂直列表而不是表格形式返回结果（有时更易于阅读）。如果您使用 phpMyAdmin 或其他界面，可以省略 **`\G`**（就像可以省略结束分号一样）。

要仅查找 *messages* 表的信息，可以使用查询 **`SHOW TABLE STATUS LIKE 'messages'`**。

**3.** 如果 *messages* 表不是 MyISAM 类型，请更改存储引擎：

```sql
ALTER TABLE messages ENGINE = MyISAM;
```

同样，仅当表当前不是正确类型时才需要此步骤。

**4.** 向 *messages* 表添加 **`FULLTEXT`** 索引 ![Image](graphics/circle-b.jpg)：
