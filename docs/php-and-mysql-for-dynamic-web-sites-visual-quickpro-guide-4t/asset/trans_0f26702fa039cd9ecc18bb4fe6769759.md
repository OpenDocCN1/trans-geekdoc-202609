
接下来，使用 `mysqli_fetch_array()` 循环遍历结果并打印每一行获取的数据。请注意，在 `while` 循环内部，代码使用正确的别名来引用每个返回的值：`$row['name']` 和 `$row['dr']`。脚本无法引用 `$row['first_name']` 或 `$row['date_registered']`，因为查询并未返回这些字段名 ![Image](graphics/graycircle-a.jpg)。

    %Y') AS dr FROM users ORDER BY registration_date ASC";

    // Table header.

    while ($row = mysqli_fetch_array($r, MYSQLI_ASSOC)) {

        ';

### 确保 SQL 安全

关于 PHP 的数据库安全性归结为三大问题：

**1.** 保护 MySQL 访问信息

**2.** 不泄露过多关于数据库的信息

**3.** 运行查询时保持谨慎，特别是涉及用户提交数据的查询

你可以通过将 MySQL 连接脚本放在 Web 目录之外来实现第一个目标，这样它就永远无法通过 Web 浏览器查看（参见 ![Image](graphics/graycircle-c.jpg) "[连接到 MySQL](#ch09.html#ch09lev1sec2)"）。本章前面已对此进行了详细讨论。第二个目标通过不让用户看到 PHP 的错误消息或你的查询来实现（在这些脚本中，这些信息是为你的调试目的而打印的；在实际网站上你绝不希望这样做）。

对于第三个目标，你可以并且应该采取许多步骤，所有步骤都基于**永不信任用户提供的数据**这一前提。首先，验证是否已提交某个值，或者其类型是否正确（数字、字符串等）。其次，使用正则表达式确保提交的数据符合你的预期（该主题将在 [第 14 章](#ch14.html#ch14) "[Perl 兼容正则表达式](#ch14.html#ch14)" 中介绍）。第三，你可以对某些值进行类型转换以确保它们是数字（将在 [第 13 章](#ch13.html#ch13) "[安全方法](#ch13.html#ch13)" 中讨论）。第四个建议是将用户提交的数据通过 `mysqli_real_escape_string()` 函数处理。该函数通过转义可能有问题的字符，使数据在查询中使用时变得安全。用法如下：

```php
$safe = mysqli_real_escape_string($dbc, data);
```

要了解为什么这很有必要，请参见 ![Image](graphics/graycircle-e.jpg) "[执行简单查询](#ch09.html#ch09lev1sec3)"。用户姓氏中的撇号使查询在语法上无效：

```sql
INSERT INTO users (first_name, last_name, email, pass, registration_date) VALUES ('Peter', 'O'Toole', 'pete@example.net', SHA1('aPass8'), NOW())
```

在这个特定示例中，有效的用户数据破坏了查询，这是不好的。但如果你的 PHP 允许这种可能性，恶意用户可以故意提交有问题的字符（撇号只是一个例子）来入侵或破坏你的数据库。出于安全考虑，`mysqli_real_escape_string()` 应用于表单中的**每一个**文本输入。为了演示这一点，让我们改造 `register.php`（[脚本 9.3](#ch09.html#ch09ex03)）。

**2.** 将 `mysqli_connect.php` 文件的引入（[脚本 9.3](#ch09.html#ch09ex03) 第 48 行）移至主条件判断之后（[脚本 9.5](#ch09.html#ch09ex05)）。
