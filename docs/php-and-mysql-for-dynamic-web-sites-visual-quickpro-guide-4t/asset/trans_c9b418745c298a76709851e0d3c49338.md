
一般来说，`GET` 用于请求信息，例如从数据库获取特定记录或搜索结果（搜索几乎总是使用 `GET`）。当预期会执行某个操作时，则使用 `POST` 方法：例如更新数据库记录或发送电子邮件。基于这些原因，我将在本书中主要使用 `POST`，特殊情况会另行说明。

#### 创建 HTML 表单

**1.** 在文本编辑器或 IDE 中新建一个 HTML 文档，命名为 `form.html`（**[脚本 2.1](#ch02.html#ch02ex01)**）：

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
  <title>Simple HTML Form</title>
  <style type="text/css" title="text/css" media="all">
  label {
    font-weight: bold;
    color: #300ACC;
  }
  </style>
</head>
<body>
<!-- Script 2.1 - form.html -->
```

该文档使用与上一章相同的基本 HTML 页面语法。我添加了一些内联 CSS（层叠样式表），以便稍微美化表单（具体来说，让 `label` 元素变粗并变蓝）。

CSS 是处理 HTML 页面中许多格式和布局问题的首选方式。你将在本书中看到一些 CSS 片段；如果你不熟悉该主题，请查阅专门的 CSS 参考资料。

最后，一个 HTML 注释标明了文件的名称和编号。

**2.** 添加初始 `form` 标签：

```html
<form action="handle_form.php" method="post">
```

由于 `action` 属性决定表单数据将提交到哪个脚本，你应该给它一个合适的名称（`handle_form` 以对应此页面：`form.html`）和 `.php` 扩展名（因为将由 PHP 脚本处理该表单的数据）。

**3.** 开始 HTML 表单：

```html
<fieldset><legend>Enter your information in the form below:</legend>
```

我使用 `fieldset` 和 `legend` HTML 标签，因为我喜欢它们让 HTML 表单呈现的效果（它们在表单周围添加一个带有顶部标题的边框）。不过，这与表单功能本身无关。

**4.** 添加两个文本输入框：

```html
<p><label>Name: <input type="text" name="name" size="20" maxlength="40" /></label></p>
<p><label>Email Address: <input type="text" name="email" size="40" maxlength="60" /></label></p>
```

这些只是简单的文本输入框，允许用户输入姓名和电子邮件地址 ![Image](graphics/circle-a.jpg)。如果你想知道，每个输入标签末尾额外的空格和斜杠是有效 XHTML 所要求的。在标准 HTML 中，这些标签将以 `maxlength="40">` 结尾。`label` 标签只是将每个文本标签与相关联的元素绑定起来。

![Image](graphics/02_figure_01_a.jpg)

![Image](graphics/circle-a.jpg) 两个文本输入框。

**5.** 添加一组单选按钮：

```html
<p><label for="gender">Gender:</label><input type="radio" name="gender" value="M" /> Male <input type="radio" name="gender" value="F" /> Female</p>
```

这两个单选按钮 ![Image](graphics/circle-b.jpg) 具有相同的名称，意味着两者只能二选一。但它们的值不同。

![Image](graphics/02_figure_02_b.jpg)

![Image](graphics/circle-b.jpg) 如果多个单选按钮具有相同的 `name` 值，用户只能选择其中一个。

**6.** 添加一个下拉菜单：

```html
<p><label>Age:
<select name="age">
  <option value="0-29">Under 30</option>
  <option value="30-60">Between 30 and 60</option>
  <option value="60+">Over 60</option>
</select></label></p>
```

`select` 标签启动下拉菜单，然后每个 `option` 标签将在选项列表中创建另一行 ![Image](graphics/circle-c.jpg)。

![Image](graphics/02_figure_03_c.jpg)

![Image](graphics/circle-c.jpg) 下拉菜单提供三个选项，其中只能选择一个（在本例中）。

**7.** 添加一个用于评论的文本域：

```html
<p><label>Comments: <textarea name="comments" rows="3" cols="40"></textarea></label></p>
```

文本域不同于文本输入框；它们呈现为一个方框 ![Image](graphics/circle-d.jpg)，而不是单行。它们允许输入更多信息，适用于接收用户评论。

![Image](graphics/02_figure_04_d.jpg)

![Image](graphics/circle-d.jpg) textarea 表单元素类型允许输入大量文本。

**8.** 完成表单：

```html
</fieldset>
<p align="center"><input type="submit" name="submit" value="Submit My Information" /></p>
</form>
```

第一个标签关闭第 3 步中打开的 `fieldset`。然后创建一个提交按钮，并使用 `p` 标签将其居中。最后，关闭表单。

**9.** 完成 HTML 页面：

```html
</body>
</html>
```

**10.** 将文件保存为 `form.html`，将其放入 Web 目录，并在 Web 浏览器中查看 ![Image](graphics/circle-e.jpg)。

![Image](graphics/02_figure_05_e.jpg)

![Image](graphics/circle-e.jpg) 完整的表单，请求用户提供一些基本信息。
