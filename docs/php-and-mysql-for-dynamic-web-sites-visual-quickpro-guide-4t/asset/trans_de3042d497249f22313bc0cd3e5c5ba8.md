#### 匹配模式

**1.** 在文本编辑器或 IDE 中新建一个 PHP 文档，命名为 `pcre.php`（**[脚本 14.1](#ch14.html#ch14ex01)**）。

```html
  <title>Testing PCRE</title>

<body>
<?php // Script 14.1 - pcre.php
```

**2.** 检查表单提交：

```php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
```

**3.** 处理传入的值：

```php
$pattern = trim($_POST['pattern']);
$subject = trim($_POST['subject']);
```

表单将向同一脚本提交两个值。两者都应进行修剪，以确保多余空格的存在不会扭曲结果。我省略了检查每个输入是否为空的步骤，但如果你愿意可以包含该检查。

请注意，如果你的服务器启用了 Magic Quotes，你将看到表单数据中添加了额外的斜杠 ![Image](graphics/circle-c.jpg)。为了解决这个问题，你也需要在此处应用 `stripslashes()`：

```php
$pattern = stripslashes(trim($_POST['pattern']));
$subject = stripslashes(trim($_POST['subject']));
```

![Image](graphics/14_figure_03_c.jpg)

![Image](graphics/circle-c.jpg)如果服务器启用了 Magic Quotes，脚本将向某些字符添加斜杠，极有可能导致正则表达式失败。

**4.** 打印标题：

```php
echo "<p>The result of checking<br /><b>$pattern</b><br />against
<br />$subject<br />is ";
```

正如你所见 ![Image](graphics/graycircle-b.jpg)，该脚本的表单处理部分将首先打印提交的值。

**5.** 运行正则表达式：

```php
if (preg_match ($pattern, $subject) ) {
  echo 'TRUE!</p>';
} else {
  echo 'FALSE!</p>';
}
```

要测试模式与字符串是否匹配，将两者都传递给 `preg_match()` 函数。如果该函数返回 1，则表示匹配成功，此条件为 `TRUE`，并将打印 *TRUE*。如果未匹配，则条件为 `FALSE` 并会显示该结果 ![Image](graphics/circle-d.jpg)。

![Image](graphics/14_figure_04_d.jpg)

![Image](graphics/circle-d.jpg)如果模式与字符串不匹配，将出现此结果。此提交和响应也表明正则表达式默认区分大小写。

表单包含两个文本框，两者均为粘性的（使用修剪后的值）。因为这两个值可能包含引号和其他会与表单的“粘性”冲突的字符，所以每个变量的值也都通过了 `htmlentities()` 处理。

### 定义简单模式

使用 PHP 的正则表达式函数非常容易；难的是定义要使用的模式。创建模式有许多规则。你可以单独或组合使用这些规则，使你的模式变得非常简单或非常复杂。首先，你将了解用于定义简单模式的字符。作为格式规则，我将用**粗体**定义模式，并用*斜体*指示模式匹配的内容。这些解释中的模式不会放在定界符或引号中（在 `preg_match()` 中使用时两者都需要），只是为了保持整洁。

你将用于定义模式的第一种字符是*字面量*。字面量是完全按照其解释方式书写的值。例如，模式 **a** 将匹配字母 *a*，**ab** 将匹配 *ab*，依此类推。因此，假设执行不区分大小写的搜索，**rom** 将匹配以下任意字符串，因为它们都包含 *rom*：

- CD-ROM
- Rommel crossed the desert.
- I’m writing a roman à clef.
