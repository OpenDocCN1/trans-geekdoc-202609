Fortunately, the form of the optimal choice $q^\star$ can be derived easily. The optimal $q^\star$ corresponds to what is called optimal importance sampling.

Because of the identity shown in equation $\ref{eq:17.8}$, any Monte Carlo estimator

```
$\hat{s}_p = \frac{1}{n}\sum_{i=1, \mathbf{x}^{(i)} \sim p}^n f(\mathbf{x}^{(i)})$ (17.9)
```

can be transformed into an importance sampling estimator

```
$\hat{s}_q = \frac{1}{n}\sum_{i=1, \mathbf{x}^{(i)} \sim q}^n \frac{p(\mathbf{x}^{(i)}) f(\mathbf{x}^{(i)})}{q(\mathbf{x}^{(i)})}.$ (17.10)
```

We see readily that the expected value of the estimator does not depend on $q$:

```
$\mathbb{E}_q[\hat{s}_q] = \mathbb{E}_q[\hat{s}_p] = s.$ (17.11)
```

The variance of an importance sampling estimator, however, can be greatly sensitive to the choice of $q$. The variance is given by

```
$\operatorname{Var}[\hat{s}_q] = \operatorname{Var}[\frac{p(\mathbf{x}) f(\mathbf{x})}{q(\mathbf{x})}]/n.$ (17.12)
```

The minimum variance occurs when $q$ is

```
$q^\star(\mathbf{x}) = \frac{p(\mathbf{x})|f(\mathbf{x})|}{Z},$ (17.13)
```

where $Z$ is the normalization constant, chosen so that $q^\star(\mathbf{x})$ sums or integrates to 1 as appropriate. Better importance sampling distributions put more weight where the integrand is larger. In fact, when $f(\mathbf{x})$ does not change sign, $\operatorname{Var}[\hat{s}_{q^\star}] = 0$, meaning that *a single sample is sufficient* when the optimal distribution is used. Of course, this is only because the computation of $q^\star$ has essentially solved the original problem, so it is usually not practical to use this approach of drawing a single sample from the optimal distribution.

Any choice of sampling distribution $q$ is valid (in the sense of yielding the correct expected value), and $q^\star$ is the optimal one (in the sense of yielding minimum variance). Sampling from $q^\star$ is usually infeasible, but other choices of $q$ can be feasible while still reducing the variance somewhat.
