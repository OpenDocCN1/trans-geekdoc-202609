In general, we may wish to continue to model larger vectors y containing more variables, and to impose richer and richer structures on these output variables. For example, if we want our neural network to output a sequence of characters that forms a sentence, we might continue to use the principle of maximum likelihood applied to our model p(y; ω(x)). In this case, the model we use to describe y would become complex enough to be beyond the scope of this chapter.
