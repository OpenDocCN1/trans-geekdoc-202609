Continuing with the relay race example from section 16.1, suppose we name Alice’s finishing time $t_0$, Bob’s finishing time $t_1$, and Carol’s finishing time $t_2$. As we saw earlier, our estimate of $t_1$ depends on $t_0$. Our estimate of $t_2$ depends directly on $t_1$ but only indirectly on $t_0$. We can draw this relationship in a directed graphical model, illustrated in figure 16.2.

Formally, a directed graphical model defined on variables **x** is defined by a directed acyclic graph $G$ whose vertices are the random variables in the model, and a set of **local conditional probability distributions** $p(x_i \mid Pa_G(x_i))$, where $Pa_G(x_i)$ gives the parents of $x_i$ in $G$. The probability distribution over **x** is given by

$$p(\mathbf{x}) = \prod_i p(x_i \mid Pa_G(x_i)). \tag{16.1}$$

In our relay race example, this means that, using the graph drawn in figure 16.2,

$$p(t_0,t_1,t_2) = p(t_0)p(t_1 \mid t_0)p(t_2 \mid t_1). \tag{16.2}$$

This is our first time seeing a structured probabilistic model in action. We can examine the cost of using it, to observe how structured modeling has many advantages relative to unstructured modeling.

Suppose we represented time by discretizing time ranging from minute 0 to minute 10 into 6-second chunks. This would make $t_0$, $t_1$ and $t_2$ each be a discrete variable with 100 possible values. If we attempted to represent $p(t_0,t_1,t_2)$ with a table, it would need to store 999,999 values (100 values of $t_0$ × 100 values of $t_1$ × 100 values of $t_2$, minus 1, since the probability of one of the configurations is made redundant by the constraint that the sum of the probabilities be 1). If instead, we make a table only for each of the conditional probability distributions, then the distribution over $t_0$ requires 99 values, the table defining $t_1$ given $t_0$ requires 9,900 values, and so does the table defining $t_2$ given $t_1$. This comes to a total of 19,899 values. This means that using the directed graphical model reduced our number of parameters by a factor of more than 50!
