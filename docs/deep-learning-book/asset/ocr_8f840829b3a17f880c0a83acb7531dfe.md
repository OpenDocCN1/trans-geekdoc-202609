We can thus determine whether ℳ_A is a better model than ℳ_B without knowing the partition function of either model but only their ratio. As we will see shortly, we can estimate this ratio using importance sampling, provided that the two models are similar.

If, however, we wanted to compute the actual probability of the test data under either ℳ_A or ℳ_B, we would need to compute the actual value of the partition functions. That said, if we knew the ratio of two partition functions, r = Z(θ_B) / Z(θ_A), and we knew the actual value of just one of the two, say Z(θ_A), we could compute the value of the other:

Z(θ_B) = r Z(θ_A) = [ Z(θ_B) / Z(θ_A) ] Z(θ_A). (18.40)
