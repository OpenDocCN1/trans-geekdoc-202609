where $\hat{T}_{a}$ is the reverse of the transition operator defined by $T_{a}$ (via an application of Bayes’ rule):

```
\hat{T}_{a}(\bm{x}'\,|\bm{x})=\frac{p_{a}(\bm{x}')}{p_{a}(\bm{x})}T_{a}(\bm{x}\,|\bm{x}')=\frac{\tilde{p}_{a}(\bm{x}')}{\tilde{p}_{a}(\bm{x})}T_{a}(\bm{x}\,|\bm{x}'). \tag{18.56}
```

Plugging the above into the expression for the joint distribution on the extended state space given in equation \textbf{18.55}, we get:

```
\tilde{p}(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1}) \tag{18.57}\nonumber\nonumber

\begin{aligned}
&\tilde{p}(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1})\\
&\quad=\tilde{p}_{1}(\bm{x}_{1})\frac{\tilde{p}_{\eta_{n-1}}(\bm{x}_{\eta_{n-1}})}{\tilde{p}_{\eta_{n-1}}(\bm{x}_{1})}T_{\eta_{n-1}}(\bm{x}_{1}\,|\bm{x}_{\eta_{n-1}})\prod^{n-2}_{i=1}\frac{\tilde{p}_{\eta_{h}}(\bm{x}_{\eta_{h}})}{\tilde{p}_{\eta_{h}}(\bm{x}_{\eta_{h+1}})}T_{\eta_{h}}(\bm{x}_{\eta_{h+1}}\,|\bm{x}_{\eta_{h}})
\end{aligned} \tag{18.58}\nonumber\nonumber

\begin{aligned}
&\quad=\frac{\tilde{p}_{1}(\bm{x}_{1})}{\tilde{p}_{\eta_{n-1}}(\bm{x}_{1})}T_{\eta_{n-1}}(\bm{x}_{1}\,|\bm{x}_{\eta_{n-1}})\tilde{p}_{\eta_{h}}(\bm{x}_{\eta_{h}})\prod^{n-2}_{i=1}\frac{\tilde{p}_{\eta_{h+1}}(\bm{x}_{\eta_{h+1}})}{\tilde{p}_{\eta_{h}}(\bm{x}_{\eta_{h+1}})}T_{\eta_{h}}(\bm{x}_{\eta_{h+1}}\,|\bm{x}_{\eta_{h}}).\end{aligned} \tag{18.59}
```

We now have means of generating samples from the joint proposal distribution $q$ over the extended sample via a sampling scheme given above, with the joint distribution given by

```
q(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1})=p_{0}(\bm{x}_{\eta_{h}})T_{\eta_{h}}(\bm{x}_{\eta_{h}}\,|\bm{x}_{\eta_{1}})\dots T_{\eta_{n-1}}(\bm{x}_{1}\,|\bm{x}_{\eta_{n-1}}). \tag{18.60}
```

We have a joint distribution on the extended space given by equation \textbf{18.59}. Taking $q(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1})$ as the proposal distribution on the extended state space from which we will draw samples, it remains to determine the importance weights:

```
w^{(k)}=\frac{\tilde{p}(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1})}{q(\bm{x}_{\eta_{h}},\dots,\bm{x}_{\eta_{n-1}},\bm{x}_{1})}=\frac{\tilde{p}_{1}(\bm{x}_{1}^{(k)})}{\tilde{p}_{\eta_{n-1}}(\bm{x}_{\eta_{n-1}}^{(k)})}\dots\frac{\tilde{p}_{\eta_{2}}(\bm{x}_{\eta_{2}}^{(k)})\tilde{p}_{\eta_{h}}(\bm{x}_{\eta_{h}}^{(k)})}{\tilde{p}_{1}(\bm{x}_{\eta_{h}}^{(k)})\tilde{p}_{0}(\bm{x}_{0}^{(k)})}. \tag{18.61}
```

These weights are the same as proposed for AIS. Thus we can interpret AIS as simple importance sampling applied to an extended state, and its validity follows immediately from the validity of importance sampling.
