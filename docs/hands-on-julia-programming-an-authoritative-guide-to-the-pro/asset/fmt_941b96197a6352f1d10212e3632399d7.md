
# Client Sends Request Code (Foreground Task)

```julia
for i = 1:5
    println(c, "Client Msg id: $i")
end
```

Server Response: Client Msg id: 1
Server Response: Client Msg id: 2
Server Response: Client Msg id: 3
Server Response: Client Msg id: 4
Server Response: Client Msg id: 5

```julia
close(c)
```

The sample code can be considered to have three parts.

## 1. The server is running in the background and listening to port 3000.

1. Once a client connects on the port 3000 the server accepts the connection and gets a socket to respond to the client through that connection.
2. The server spawns another parallel task so that client and server can communicate over it while the main server task keeps listening on the port 3000 indefinitely waiting for the next client to communicate.
3. In the new task, the server reads the client request and appends its own message and writes it back to the socket for the client to read.

## 2. The client connects to the server on port 3000.

1. On connection success, it reads continuously whatever the server writes on the socket and writes to the `stdout`.

## 3. The client sends the server a request over the foreground task.

Once the communication task is completed, the client can `close` the connection with the server. The server shall continue to run the background waiting for other clients to connect.

In the chapter on Strings we realized, the Strings being immutable make them unsuitable for modifications. However, one may need to continuously modify large chunks of memory or append new data to it. Here is a simple way to use memory as an IO that can be later aggregated as a `String`.

```julia
io = IOBuffer()
println(io, "This is Line 1")
println(io, "This is Line 2")
str = String(take!(io))
```

```
"This is Line 1\nThis is Line 2\n"
```

The reverse scenario is of memory mapping. A file can be mapped to a memory address. The data in the file can be accessed as if one accesses a memory location. Memory mapping often improves access speed to the file data and is also helpful where large a chunk of data may not fit into the computer memory. Mapped memory can be utilized as a shared memory for inter-process communications. Memory-mapped functions are defined in the standard library module `Mmap`.

### Step 1: Creating a file that we will like to memory map.

```julia
A = fill(10, (5, 20))
A[2, 3] = 20
open("mmap.bin", "w+") do f
    write(f, size(A, 1))
    write(f, size(A, 2))
    write(f, A)
end
```

### Step 2: Memory mapping the file and read value and ensure the correct data is populated.

```julia
using Mmap
f = open("mmap.bin", "r")
nr = read(f, Int)
nc = read(f, Int)
A2 = Mmap.mmap(f, Matrix{Int}, (nr, nc))
println("A2[1, 1]: ", A2[1, 1], " A2[2, 3]: ", A2[2, 3])
close(f)
```

### Step 3: Cleaning Up

```julia
A2 = nothing
GC.gc()
rm("mmap.bin")
```

In operating systems like Windows, where files are locked for reading and writing, the file cannot be removed till the array allocated with mmap is not reclaimed. Calling `GC.gc()` ensures the garbage collector is called to clean up the unreferenced array `A2`. However, calling the garbage collector manually is not considered an efficient practice in Julia and should be kept to a minimum.

The standard library has many additional modules that can be beneficial to programmers as they provide utility functions. We outline a few commonly used ones here.

## `Dates` Module

The `Dates` module provides user presentation of date and time functionalities. While we saw `@time` macro in the earlier chapter that helps debugging and profiling of `code`, `Date`, and `DateTime` types represent the time in user presentation formats. For example, `Date` has the ability to present with day, month, and year and `DateTime` can additionally present with hours, minutes, and seconds. However, these representations are devoid of any time zone information. Anyone needing to use time zone with date and time will need to use the `TimeZones.jl` package. `Date` and `DateTime` both internally keep track of time in elapsed `Int64` and are immutable types. For example, a function `now` reports the current time as a `DateTime` object.

```julia
using Dates
now()
```

```
2020-11-27T22:52:36.318
```

`DateTime` and `Date` constructors can be constructed by providing a part of the data. Defaults to first day and first month when those are not provided. Any time parameter not provided defaults to 0s.

```julia
DateTime(2020)
```

```
2020-01-01T00:00:00
```

```julia
t = DateTime(2020, 10, 31, 01, 02, 03)
```

```
2020-10-31T01:02:03
```

```julia
Date(2020)
```

```
2020-01-01
```

`Date` and `DateTime` types can be converted from one another. Time data are set to zeros when `DateTime` is converted to `Date`.

```julia
d = Date(t)
```
