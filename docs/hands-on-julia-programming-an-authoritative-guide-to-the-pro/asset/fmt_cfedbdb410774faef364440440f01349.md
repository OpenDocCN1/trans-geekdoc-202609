
Similar to reading, writing also requires the output to be displayed as a text where the terminal supports.

```julia
julia> print(stdout, 0x61)
97
```

```julia
julia> write(stdout, 0x61);
a
```

In the preceding example, while `print` tries to display the numeric value of the `UInt8`, the `write` method does a text output to the terminal.

## `read()` and `write()` Operations

`read()` and `write()` operations are generally used to read and write binary streams of data into object arrays where they wait for a specific size of data to be read or till the end of file is reached.

```julia
julia> read(stdin, 4)
abcd
4-element Array{UInt8,1}:
 0x61
 0x62
 0x63
 0x64
```

In the preceding example, only 4 bytes are read from the `stdin`. `read` method has many other variations as well including `read(io, String)` that will read a complete `io` as a single string and `read(filepath)` that will read the whole file represented by a `filepath` as a single byte array.

## File I/O in Julia

File I/O in Julia is very similar to stream operations. Following are some of the generic steps in a Julia file operation:

1.  Open the file and obtain the relevant stream handle.
2.  Access the relevant location in the stream.
3.  Read from or write data into the file.
4.  Close the stream handle.

While the file may not be buffered the streams are buffered with a small memory in the cache for a look ahead or rollback. While streams in Julia have interfaces to many operations, they may be limited by the internal capabilities of the device. For example, if a file is read only it cannot be opened for write. Thus write operations on a read only stream shall fail.

```julia
julia> write("hello.txt", "Hello World")
11

julia> f = open("hello.txt", "r");

julia> data = read(f);

julia> write(f, "This is second line")
ArgumentError: write failed, IOStream is not writeable
Stacktrace:
 [1] unsafe_write(::IOStream, ::Ptr{UInt8}, ::UInt64) at .\iostream.jl:363
 [2] write(::IOStream, ::String) at .\strings\io.jl:183
 …

julia> close(f)

julia> write(stdout, data)
Hello World
11
```

In the preceding example shown:

1.  `write(filename, data)` will create a new file and write `data` into it. The number of bytes written is returned by the function.
2.  Subsequently, we open the file in the read only mode by `open(filename, mode)` and read the data from the file as a byte array.
3.  Try to write additional data into the read only stream, which fails as expected.
4.  Close the stream.
5.  Write the data read into `stdout` to be printed.

`open(fn, filename, mode)` is an alternate method that closes the opened file handle.

```julia
julia> open("hello.txt", "r") do f
           data = read(f)
           write(stdout, data);
       end
Hello World
11
```

For many data science problems, files are used for archiving. Reading from and writing to files based on file path is considered convenient as the code shown as follows:

```julia
julia> write("hello.txt", "Hello World");

julia> data = read("hello.txt");

julia> write(stdout, data);
Hello World
```

File position-based operations like `seek`, `seekstart`, `seekend`, and `position` are supported by the APIs as well. We used `read` method that would read till the EOF in one shot. While convenient it may not be most memory efficient. Some applications like parsers may read a file byte by byte like the following code:

```julia
julia> open("hello.txt", "r") do f
           while !eof(f)
               b = read(f, 1)
               write(stdout, b)
           end
       end
Hello World
```

In the preceding example, `eof(f)` provides the necessary check to stop the file traversal.

## Delimited Files (CSV)

Julia **standard library** (`stdlib`) contains a module `DelimitedFiles` that helps read and write data in delimited values where each row represents a record. **Comma separated values** (**CSV**) used extensively in spreadsheets to export and import data is one such format. Following code can help write data into a CSV like format with a line of header:

```julia
julia> using DelimitedFiles

julia> x = collect(1:100);

julia> y = Float64.(collect(101:200));

julia> open("values.csv", "w") do f
           println(f, "X,Y")
           writedlm(f, [x y], ',')
       end
```

Similarly, the data can be read back into variables `data` and `header` by the following code:

```julia
julia> data, header = readdlm("values.csv", ',', header=true)

julia> size(data, 1)
100

julia> header
1×2 Array{AbstractString,2}:
 "X"  "Y"
```

## Network I/O

When the system has `curl`, `fetch`, or `wget` installed, Julia provides a `download(url, [localfile])` method to download files over ftp, http, or SSL-based communication channels. However, it cannot be used for generic network communications needed for internet-based application development. The API returns the local file to which the downloaded file was written to.

```julia
julia> download("https://github.com/JuliaLang/julia/releases/download/v1.5.3/julia-1.5.3.tar.gz", "julia-1.5.3.tar.gz")
"julia-1.5.3.tar.gz"
```

TCP sockets are used for client-server communications and application development over the internet. While in most cases you may not need to use raw sockets for communication and may be able to use protocol-specific APIs available with Julia packages like `HTTP.jl`, it may be worthwhile to be aware of the `Sockets` module in the standard library.

The basics of networked client–server communication can be described in the following basic workflow:

1.  A server binds to a communication end (port) and listens on it continuously.
2.  A client connects to the same port and obtains a communication socket handle.
3.  Client writes a request to the server as commands.
4.  The server responds back with response data.
5.  When the client obtains the data it needed it closes the connection.
6.  On exceptional conditions, the server may also terminate the connection as well.

Both client and server running as background tasks are shown as follows:

### Server Code (Background Task-1)

```julia
julia> using Sockets

julia> @async begin
           server = listen(3000)
           while true
               s = accept(server)
               @async while isopen(s)
                   msg = readline(s, keep=true)
                   write(s, "Server Response: $msg")
               end
           end
       end
```

### Client Reads Server Response (Background Task-2)

```julia
julia> c = connect(3000)

julia> @async while isopen(c)
           println(stdout, readline(c, keep=true))
       end
```
