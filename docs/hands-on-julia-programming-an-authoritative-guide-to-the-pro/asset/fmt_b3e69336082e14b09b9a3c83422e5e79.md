
# Integrated Development Environments (IDE)

**Integrated development environments** (**IDE**) are becoming common in today's application development. As much as they provide a wide variety of views of multiple files and their interrelations, they also help in accomplishing tasks like compilation, running the code and viewing results with visualizations. As a scientific computing language, algorithm-driven applications are developed in Julia. `REPL` is used extensively to try out small chunks of code before they are finally added to the larger application. Debugging line by line using a line debugger is also carried out in some circumstances. We will look at Julia's integration with editors like `emacs` and `vi`. Also, work with `Atom` and `Microsoft Code` for a complete IDE experience.

# Code Organization and Package Management

Although named as package management, this chapter is about code organization for easier management and deployment of applications. Managing code may become complex as it may depend on other components. There may be dependency issues due to version incompatibilities. The code needs to be tested automatically on check-in, continuous integration frameworks should be able to run and any version management needed should be carried out with ease. In Julia, code is typically composed of projects, packages, and modules. Packages are well-defined organizations of code that help manage continuous integration, automated testing, document creation, and deployment with the least effort. There is an inherent structure between package management and `git` APIs that makes the package management part of the development process. Moreover, Julia provides environments that can be used to establish an isolated and consistent package sets for specific application requirements.

# Installation

Pre-built binary packages for Julia are available in the Julia language website at: <https://julialang.org/downloads/>

While certain Linux distributions may be packaging Julia as a part of their releases, please ensure you are installing the latest releases from Julia Language website.

Julia binaries are typically named as: `julia-<version>-<arch>.<package-ext>`

For example, Julia 1.6.1 Linux x86 64-bit package is named as: `julia-1.6.1-linux-x86_64.tar.gz`

Similarly, the Windows 64-bit version is named as: `julia-1.6.1-win64.exe`

Julia Platform is evolving continuously. Hence, it may be advisable to use the latest minor version while learning from this book. The current stable version released is `Julia 1.6`. Julia minor releases introduce a lot of new features and worthwhile to take a look at periodically. However, `Julia 1.0.x` version is a long term supported version for Julia. The blog article provides a detailed explanation of the versioning process for Julia: <https://julialang.org/blog/2019/08/release-process/>

> **Note:** This book is written based on the Julia version 1.6.x, which is the current released version of Julia. The concepts described in the book are generic in nature and are applicable to a later version of the language. However, it is possible some of the outputs from a later version of Julia may not match to the results and examples provided in this book. Hence, the sources used in the book are provided as Jupyter notebooks in a GitHub repository at: <https://github.com/bpbpublications/Hands-on-Julia-Programming>. Readers are requested to access the repository for the latest updates to the source code.

## Linux Installation

Julia binaries being mere `.tar.gz` packages, they can be easily installed in the user's home directory. We suggest the following instructions for a simple installation in your home directory.

1.  Open a terminal with a bash shell.
2.  Use the following commands to create a directory `julia-versions` and enter into the directory:
    ```
    $ mkdir ~/julia-versions
    $ cd ~/julia-versions
    ```
3.  Now un-archive the package downloaded in the Julia-versions folder.
    ```
    $ tar -xvzf julia-x.y.z-linux-x86_64.tar.gz
    ```
4.  Now change the directory to the home directory and create a symbolic link to the Julia version installed.
    ```
    $ cd
    $ ln -s ~/julia-versions/julia-x.y.z julia
    ```
5.  Add Julia bin directory to the bash startup script (`.bashrc` or `.bash_profile`) `PATH` variable by following this command:
    ```
    $ export PATH="/home/user/julia/bin:$PATH"
    ```
6.  Re-launch the bash shell again.

## Windows Installation

Julia provides an installer for the Windows platform. The installer can be launched by a user without any administrator privileges. Here are the recommended steps on a Windows platform:

1.  Click on the installer executable to launch it.
2.  Browse to the path where you will like to install Julia:
    ![](n4upl4fndqb.jpeg)
    **Figure 1.1:** Julia Windows Installer
    The default path is: `%LOCALAPPDATA%\Programs\Julia x.y.z`
3.  Add the Julia bin directory: `%LOCALAPPDATA%\Programs\Julia x.y.z\bin` to the environment variable following steps described in the link: <https://julialang.org/downloads/platform/#windows>

# Verifying Installation

Now that you have installed and configured the variables as suggested in the previous steps, on the command prompt type `julia`. You should see the version information of Julia and a `julia` prompt. This is called as a **REPL** which you can use for typing your code and quickly verifying the results.
