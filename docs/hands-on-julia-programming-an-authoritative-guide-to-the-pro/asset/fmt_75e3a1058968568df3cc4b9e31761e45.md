# Compound Statements

Any set of statements between a block of `begin` and `end` are considered a large compound execution unit.

```
julia> z = begin
           x = 1
           y = 2
           x + y
         end
3
julia> z
3
```

The value of the final expression in the block is considered as the value of the compound block. The same expression can be written as a single line using semicolons and braces.

```
julia> z = (x = 1; y = 2; x+y)
3
```

The following are valid compound statements as well.

```
julia> z = (x = 1;
           y = 2;
           x + y)
3
```

```
julia> z = begin x=1; y=2; x+y end
3
```

# Conditional Statements

Conditional statements are the heart of any programming language. They provide avenues to define branching in the code and are foundations for iterative programming. Branching with local `goto` is good enough to emulate any iterative model in a programming language.

## `if…else`

`if…else` are the most common form of conditional execution in Julia. A typical if condition may look as shown as follows:

```
if <Boolean condition>
    #do something
else
    #do the something else
end
```

The `else` part is optional. The condition has to be Boolean. An integer with the same value as Boolean true or false are not substitutes for the same.

```
julia> if 1
           println("I am here")
       end
ERROR: TypeError: non-boolean (Int64) used in boolean context
```

```
julia> if Bool(1)
           println("I am here")
       end
I am here
```

The `if` expression returns the value of that branch which got executed.

```
julia> i = 1
1
julia> str = if i > 1
               "Greater"
           else
               "Less"
           end
"Less"
julia> str
"Less"
```

The same expression is also represented as a ternary operator using `?` and `:`:

```
julia> str = i > 1 ? "Greater" : "Less"
"Less"
```

While whitespaces are normally not expected in most expressions, here whitespaces are mandated around `?` and `:`.

```
julia> str = i > 1? "Greater" : "Less"
ERROR: syntax: space required before "?" operator
julia> str = i > 1 ? "Greater": "Less"
ERROR: syntax: space required before colon in "?" expression
```

## `switch…case` Alternative

`switch…case` expressions are typically used when a large number of comparisons are needed as a multiple branching operation. An example `switch…case` statement in C/C++ may look something like this:

```
res = ""
switch (val) {
case 1: res = "One"; break;
case 2: res = "Two"; break;
case 3: res = "Three"; break;
case 4: res = "Four"; break;
...
default: res = "Unknown"; break
}
```

Java and other languages have similar constructs as well. However, such expressions do not exist in Julia. There has been a large number of debates around the inclusion or exclusion of similar structures in Julia. While a concise representation, two significant issues are known about the `switch…case` construct: the fallback to the next case needing a specific break statement; second, the C/C++ switch statement works only on integral types.

Julia addresses the need for such construct with `if…else if…else` structure. The following can clarify the syntax:

```
julia> val = 3
3
julia> if val == 1
           "one"
       elseif val == 2
           "two"
       elseif val == 3
           "three"
       elseif val == 4
           "four"
       else
           "unknown"
       end

"three"
```

### `else if` vs. `elseif`

Let us look at the following code snippet:

```
julia> if val == 1
           "one"
       elseif val == 2
           "two"
       elseif val == 3
           "three"
       elseif val == 4
           "four"
       else if val >= 5
ERROR: syntax: use "elseif" instead of "else if"
```
