如此精心设计的异常对象架构增加了什么价值？它们会影响执行速度，因为每次发生栈展开时，都需要验证异常对象。它们提供的主要优势之一是能够跟踪异常发生时的堆栈。因此，可以获得错误传播的追踪。其次，异常对象的形成提供了提供关于错误的足够信息的能力。

```
Dict{String,Int64} with 3 entries:
  "c" => 2
  "b" => 3
  "a" => 1
julia> d["b"]
3
julia> d["a"] = 5
5
julia> println(d)
Dict("c" => 2,"b" => 3,"a" => 5)
```
