# Random Numbers

Random numbers are used extensively in data sciences to initialize data. They are also useful as sample creation for various probability distributions. A cryptographically secured random number is also a requirement for encryption and decryption algorithms. Here are some examples:

```julia
julia> using Random

julia> rand(Int, 2)
2-element Array{Int64,1}:
 -6387591687841801404
 -5718816187088355789

julia> rand(2, 3)
2×3 Array{Float64,2}:
 0.395316  0.413728  0.738543
 0.505417  0.0773799 0.560448

julia> rand!(zeros(2, 3))
2×3 Array{Float64,2}:
 0.30912   0.797688  0.324596
 0.586434  0.0213767 0.110147

julia> rand(1:4, (2, 3))
2×3 Array{Int64,2}:
 2  3  1
 2  2  4
```

`rand()` methods generate uniform random numbers of a specific type, data range or any shape or output desired. Given a pre-allocated array `rand!()` function can fill new random values into the same array. Similar to `rand` methods, `randn` methods fill random numbers in a normal distribution and `randexp` in an exponential distribution of data.

The first parameter of `rand` methods is optional and is called the random engine (`rng`). Julia utilizes *Mersenne Twister* library for random number generation. One can initialize own *Mersenne Twister* with enough entropy such that the pseudo-random sequence generated by the random number generators is secured enough. Not providing an engine shall use the engine initialized as part of Julia runtime. Julia also provides methods for random permutations, random subsequences and random cyclic permutations, and so on.
