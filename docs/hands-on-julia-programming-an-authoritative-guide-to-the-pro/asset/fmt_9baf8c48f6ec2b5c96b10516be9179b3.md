# Debugging Tools for Code Generation

These are debugging tools that give insights into the code at various stages of code generation. These tools are named as `@code_XXX` where `xxx` stands for a specific stage. Julia’s code translation happens in stages. The code gets translated to an abstract structure tree, then to a LLVM code to a final native output. Different macros help us peek into various stages of this code generation process. Julia internally does not use them for actual code generation.

We will add a type to the declaration for the parameter `x` and see how that affects the type inferences.

```julia
julia> function sindegmemo(m::MemoLookup, x::Float64)
           s, lookup = step(m), m.lookup
           i = 1
           while x >= s
               x -= s
               i += 1
           end
           iszero(x) && return lookup[i, 1]
           x = deg2rad(x)
           sinx, cosx = x, 1 - x*x/2
           return lookup[i, 1]*cosx + lookup[i, 2]*sinx
       end
```

The change affects minimally to the type inferences. Only the variable `x` is interpreted properly to a `Float64`. However, the majority of the temporary variables are assigned to the type `Any`. `Any` being an ambiguous type, any operation over a type of `Any` is likely to result into an `Any`.
