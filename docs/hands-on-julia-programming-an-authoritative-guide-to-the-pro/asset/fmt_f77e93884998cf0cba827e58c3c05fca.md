
While `show` is used to display the data on any kind of output device, `print` can be used to output the textual representation only. When no specific `print` routine is introduced, `show` is used internally when `print` is called.

```
julia> print(a)
a1: 1 a2: 2.0
```

This function can be used to convert any type to its string representation. When no proper conversion method is provided, the `print` function is internally invoked to get a textual representation of the data type.

```
julia> string(a)
"a1: 1 a2: 2.0\n"
```
