
Let us try few experiments at the REPL prompt.

```
julia> 2 + 2
4
julia> 2.0 + 2
4.0
julia> println("Hello, World!!!")
Hello, World!!!
```

The examples are rather trivial save after every computation the results are printed. If you do not want to print something in the REPL use a semicolon (`;`) symbol at the end of the sentence. However, using a semicolon will have no effect where explicit `println` is used. Now let’s look at the same samples using semicolons.

```
julia> 2 + 2;
julia> 2.0 + 2;
julia> println("Hello, World!!!");
Hello, World!!!
```

Why is this behavior then? We will keep the answer to the next chapter when we discuss data types and the concept of nothing.

## Running Julia Programs

While interactive expressions are quick ways to try something on a terminal and review the outputs, real-world applications require large chunks of code pieces be run. In Julia, you type all the relevant code in a file. The Julia programs conventionally have an extension of `.jl`. Open the text editor of your choice and type in the following code in a file and save as `example01.jl`.

```
# example01.jl
println("2 + 2 = ", 2+2)
println("2 + 2.0 = ", 2+2.0)
println("Hello World!!!")
```

The code we wrote earlier is provided. A `println` command is used in every line to showcase the line is run and output is printed on the terminal.

At the command prompt run `julia`. Then at the julia prompt invoke the command as shown and you should see the output:

```
$ julia
julia> include("example01.jl")
2 + 2 = 4
2 + 2.0 = 4.0
Hello World!!!
```

Another way to run a Julia program will be to run at the command line as shown:

```
$ julia example01.jl
2 + 2 = 4
2 + 2.0 = 4.0
Hello World!!!
```

We will learn more details about how to write complex programs and organize them in a later chapter. `include` is also used to embed the code from one julia file into another.
