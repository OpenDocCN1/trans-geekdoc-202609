
When a resource is in use, an exceptional situation may force exit the function execution abruptly; the resources in such cases cannot be reclaimed. The `finally` clause ensures the code is executed in normal execution as well as exceptional conditions, ensuring the resources are reclaimed. In the sample, the file handle `f` will be closed even when there is an exception as it is otherwise.

```
julia> f = open("file")
julia> try
           b = read(f)
       finally
           close(f)
       end
```
