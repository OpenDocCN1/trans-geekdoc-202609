A. *Linear Discriminate Analysis (LDA)*: The objective of the LDA method (Fig. 12) is to identify a horizontal collection of characteristics that may differentiate unique drugs from each other. It helps to minimize the space dimensionality and improves the classification accuracy.

B. *Principal Component Analysis (PCA)*: It is a good way to reduce the data dimension with a lot of interconnected variables. However, the PCA (Fig. 13) is not suitable for feature extraction for sparse distribution and noise information.

C. *Genetic Algorithms-Based Optimization (GABO)*: It is a robust search optimization algorithm based on fundamental selection principles. It adjusts to model parameters by employing prior knowledge and using selection for survival. The characteristics that are related to the fitness assessment are represented as binary strings.
