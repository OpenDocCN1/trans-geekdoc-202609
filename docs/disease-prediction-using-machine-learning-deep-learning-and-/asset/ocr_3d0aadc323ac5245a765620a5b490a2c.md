It has been observed from the review of literature that a number of DL techniques have been employed for the automatic scanning of medical images for disease diagnosis and severity detection. Although these techniques provide higher accuracy, they have some limitations. Also, the efficacy of each technique is highly dependent on the quality, type, and size of datasets used for training the DL-based model. The comparative analysis of these techniques is shown in the subsequent section in Table 2.

# Table 2. Comparative analysis of deep learning techniques employed for disease severity detection.

| Authors, Year, and Citation | Technique Applied | Dataset Used | Performance | Challenges |
| :--- | :--- | :--- | :--- | :--- |
| Bodapati et al. 2021 [14] | Deep Neural Network architecture with gated-attention mechanism to automatically diagnose the Diabetic Retinopathy. | Asia Pacific Tele-Ophthalmology Society (APTOS) dataset from Kaggle. | Highest accuracy of 97.32%. | Faces the problem of over fitting and multiple channels. |
| Grover et al. 2018 [15], | DNN and adaptive neuro-fuzzy inference system with Support vector regression | 5875 biomedical voice measurements of 42 patients. | Severity prediction of Parkinson’s Disease with accuracy of 81.6% using DNN | Low accuracy, conclusions based on patients from one geographical location. |
| Kermany et al. 2018 [16], | Deep learning based diagnostic tool the AI system. | Screening of treatable blinding retinal diseases using 108,312 OCT images for training and 1000 images for testing | Maximum accuracy, sensitivity and specificity of 96.6%, 97.8%, and 97.4%, respectively. | Requires dataset of the same organ for pre-training of the system. |
| Chithra et al. 2020 [17] | Self-Adaptive Fractional Crow Search-based Deep Convolutional Neural Network (AFC-SVNN) model for the severity detection and infection level identification of Tuberculosis (TB) disease. | Dataset comprising 75 images including 50 images of bacilli and 25 images of non-bacilli classes. | Best accuracy of 96.39% by using KNN. | Implemented on a small dataset, thus less reliable for practical use. |
