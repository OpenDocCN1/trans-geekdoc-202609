# FIGURE 2.3 A deep learning network diagram for BSN.

The sensor attached to the heart for EEG can be represented as:

$$C = (C1, C2)$$ (2.3)

Hence, all the features captured by various sensors on the body can be represented as:

$L = F_j \| E \| C$. These features are then fed to a model for evaluation. To enhance the features a kernel-based discriminant analysis (KDA) is used, which is based on the eigenvalue problem to find the non-linear feature space. This works as follows, the sensors attached to different parts of the body are captured through a Gaussian kernel obtained from the maximization of the following equation:

$$S = \frac{|S^T C_w S|}{|S^T C_B S|}$$

where $S$ represents discriminant features of class $C_B$ with class $C_w$. KDA provides a clustering technique that demonstrates features based on groups of clusters.
