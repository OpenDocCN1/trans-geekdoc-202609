# Centralised vs Decentralised Cryptocurrency Exchanges

2.62 In a centralised exchange, the ownership of the coins is held by the exchange completely. However, by holding on to the keys by the exchange execution of the transaction is a faster since the user does not need to provide key access. However, this can be an avenue of crypto fraud.

2.63 A centralised exchange would operate similar to the banks:

+   - An asset owner.
+   - Is KYB, KYC and identification/provenance checked.
+   - They adhere to the exchange rules and regulations.
+   - They are permitted to transact.

2.64 The risks associated with the centralised exchange are:

+   - They can be hacked easily through which funds could be lost.
+   - The entire exchange can disappear fast.

2.65 Although centralised exchanges are in existence where you are the true owner of your assets, the concept of decentralised exchanges are far more commonly appreciated.

2.66 A decentralised exchange works as below:

+   - A token owner places the order in order to exchange his/her assets with another asset available on DEX. The token owner specifies the number of units they have to sell, the cost of the token and until which time bids for their assets are allowed.
+   - Once the selling order is set, other users can submit bids by signalling a buy order.
+   - Once the time set by the sellers has expired, all the bids are reviewed and the highest bid executed by both the parties.

2.67 Externally facing, as a user placing an order:

+   - One is using one’s own wallet address to sign in to block chain decentralized exchange.
+   - One can submit a buy or sell request.
+   - The smart contracts get executed and transfer of assets is completed.
+   - A termination of further transaction occurs.

With this popularity, many start-ups are interested in knowing how to build a decentralized exchange and use the information to formulate a whitepaper to induce investment.
