
# 海合会关键网络安全事件

围绕某一问题出现的治理结构通常是*被动反应式的*，往往跟随特定事件而产生，尽管此类结构采取的形式取决于现有的概念和政治资源。因此，海合会的网络安全治理只能在关键网络安全事件的背景下才能被理解。虽然下文所述事件并非都能轻易归入网络安全的单一定义，但它们均被描述为属于这一范畴；因此，我将网络安全视为“野外发现”的现象。尽管由于互联网的全球覆盖性，网络安全事件在某种意义上无法被本地化，但仍可识别出区域视角，前提是它们符合更广泛的全球模式。

与海合会相关的首个关键事件是“震网”恶意软件，该软件于2010年7月被发现，据报道由美国和以色列情报机构构建，旨在针对伊朗的一处核浓缩设施。[^(18)](#c02.xhtml#c2-note-0018) “震网”不仅证明了恶意软件能产生物理效应，还向网络安全行业展示了中东是一个潜在市场。2011年底至2012年初，又发现了更多归因于美国和以色列的恶意软件，[^(19)](#c02.xhtml#c2-note-0019) 这些软件中的“擦除”组件被逆向工程，并于2012年8月用于攻击沙特国家石油公司阿美石油和卡塔尔公司拉斯天然气。[^(20)](#c02.xhtml#c2-note-0020) 很难过分强调此次攻击的影响，该攻击常被称为“沙蒙”。如果美国政府——进而全球网络安全界——将其描述为“警钟”，[^(21)](#c02.xhtml#c2-note-0021) 那么对这些国家而言，其冲击则强烈得多。[^(22)](#c02.xhtml#c2-note-0022) 尽管该恶意软件缺乏复杂性，“沙蒙”迅速被业界贴上了“高级持续性威胁”（APT）的标签。

“沙蒙”事件后，海合会地区的网络安全事件大幅增加。著名的APT攻击包括：被区域行为体重新利用于政治目的的中国间谍恶意软件[^(23)](#c02.xhtml#c2-note-0023)；由一名科威特人编写并在该地区流行、支持阿拉伯语用户界面的恶意软件[^(24)](#c02.xhtml#c2-note-0024)；以及针对能源行业的特定恶意软件。[^(25)](#c02.xhtml#c2-note-0025)^,[^(26)](#c02.xhtml#c2-note-0026) 泄露、“篡改网页”及拒绝服务事件与巴以冲突[^(27)](#c02.xhtml#c2-note-0027)^,[^(28)](#c02.xhtml#c2-note-0028)、声称隶属于叙利亚伊斯兰国的组织[^(29)](#c02.xhtml#c2-note-0029)以及更广泛的群体（如“匿名者”）有关。[^(30)](#c02.xhtml#c2-note-0030)

2013年，阿曼的马斯喀特银行和卡塔尔的拉希德银行被一个跨国犯罪网络攻破，数百万现金被取走，海合会金融部门也迎来了属于自己的“警钟”。[^(31)](#c02.xhtml#c2-note-0031) 泄露事件变得更加常见，包括沙特外交部[^(32)](#c02.xhtml#c2-note-0032)和卡塔尔国家银行[^(33)](#c02.xhtml#c2-note-0033)的泄露。网络安全也成为一个具有区域文化维度的社会问题，缘于整个地区利用智能手机剥削儿童和青少年的现象。[^(34)](#c02.xhtml#c2-note-0034) 最后，“沙蒙”于2016年底和2017年初卷土重来，再次被归因于伊朗。[^(35)](#c02.xhtml#c2-note-0035) 改进后的“沙蒙”恶意软件将原始事件的日期作为其擦除程序的一部分，并持续了数月。此次受影响的组织更多，包括许多沙特政府实体，民航局运营一度暂停。[^(36)](#c02.xhtml#c2-note-0036)

这一简要概述表明，网络安全事件与区域政治和安全局势深度纠缠。尽管后续章节将表明多种因素塑造了网络安全治理，但其最初是由那些既源于又根据区域背景被解读的事件所催化的。[^(37)](#c02.xhtml#c2-note-0037)

## 2.4 政府组织

海合会网络安全治理组织的发展首先必须置于国际互联网治理的更广泛背景中。互联网治理常被描述为自由主义的“多利益相关方”观点（政府、公民社会和企业均参与其中）[^(38)](#c02.xhtml#c2-note-0038) 与威权主义对更大国家主权和政府跨境控制信息流动的渴望之间的二元选择。[^(39)](#c02.xhtml#c2-note-0039) 事实上，这一图景复杂得多，两个阵营中均存在多种互联网治理路径。[^(40)](#c02.xhtml#c2-note-0040) 海合会国家常被归入后一类，原因在于其更宽泛的安全观，以及2012年12月在阿联酋迪拜举行的世界信息技术大会（WCIT）上的事件。

会上，有人提议让国际电信联盟（ITU）负责互联网的命名和编号职能，并通过国家层面的监管实施互联网安全措施。最初的口头提议由东道主提出，并获巴林、沙特阿拉伯、俄罗斯和伊拉克支持，而书面版本由阿联酋和沙特阿拉伯签署，俄罗斯和中国等国也在签署国之列。[^(41)](#c02.xhtml#c2-note-0041) 西方媒体广泛将该提议描述为威权政权的“权力攫取”。[^(42)](#c02.xhtml#c2-note-0042) 鉴于峰会上讨论的其他标准聚焦安全，安全顾虑极有可能至少部分推动了该提议，[^(43)](#c02.xhtml#c2-note-0043) 尽管该提议被包装为“纠正历史失衡”和“美国主导地位”的手段。[^(44)](#c02.xhtml#c2-note-0044)

通过考察国际电信联盟在建立区域网络安全组织中的作用，互联网治理的二元叙事可以变得更细致。在国际电信联盟介入海合会之前，公共网络安全职能表面上由国家计算机应急响应小组（CERT）履行。[^(45)](#c02.xhtml#c2-note-0045) 国际电信联盟自1865年起即提供电信（最初为电报）标准，并首次尝试通过“国际多边反网络威胁伙伴关系”（IMPACT）将网络安全纳入其职权范围，该组织于2008年在马来西亚资助和设立。[^(46)](#c02.xhtml#c2-note-0046) IMPACT于2011年被指定为国际电信联盟网络安全领域的官方“执行机构”。2012年全年，其与阿曼政府进行谈判，[^(47)](#c02.xhtml#c2-note-0047) 后者同意出资200万美元在马斯喀特建立首个“区域网络安全中心”，于2013年3月正式启动。[^(48)](#c02.xhtml#c2-note-0048) 加上沙特阿拉伯对国际电信联盟提供相对高额的资助——仅为美国的一半，但与俄罗斯和中国相当[^(49)](#c02.xhtml#c2-note-0049)——海合会与国际电信联盟存在一系列紧密联系，确保它们会支持世界信息技术大会的提议。
