
# 网络安全治理：简介

网络空间并非一个位于法律、制度和权力之外的无政府空间。正如乔·奈、劳拉·德纳迪斯、杰克·戈德史密斯、蒂姆·吴等人所恰当指出的，在网络空间中存在着丰富繁杂的组织和机构，它们提供结构、形态和界限。[³](#f05.xhtml#c0-note-0003) 网络领域与物理领域之间存在着至关重要且持久的类比关系。[⁴](#f05.xhtml#c0-note-0004) 数字设备和网络的世界遍布着控制点。[⁵](#f05.xhtml#c0-note-0005) 这一见解在审视网络安全治理这一更具体的问题时同样有用。安全空间并非一片无序之地。远非如此。它是一个由相互竞争的组织和机构所定义的空间，它们试图以安全之名施加某种形式的控制。安全究竟意味着什么，始终是一个开放且有争议的问题。在某些情境下，它可能意味着保护设备、数据或网络；在其他情境下，安全可能转化为对被视为政治上不可接受的言论或表达形式的控制；在又其他领域，安全可能意味着免受非国家行为体的侵害，却很少涉及政府为颠覆个人数据技术保护所做的努力。关于网络安全的问题——正如广义上关于安全的问题一样——总是开放给多种解读的。两个问题始终萦绕在空气中，无论显性还是隐性：安全*保护什么？*以及安全*防范谁？*

本文集旨在梳理网络安全治理的脉络。它通过各种案例研究，探讨了一些试图保障网络空间安全的相互竞争的组织努力和机构。本书不着眼于未来——即应对一组先前未知问题的假设性新可能性——而是着眼于近期过去和当下。它审视了一些现有的且正在展开的制度性和组织性努力，以应对网络安全挑战。本书并非仅通过一个纯粹狭隘的规范性视角——即“有没有用？”——来审视这些努力，而是考虑这些努力的更广泛含义。它追溯了不同网络安全观念如何被部署并融入稳定的常规和实践中，这可称为“风险的官僚化”。在此过程中，本书汇集的各章共享一组共同关注点：对*网络不安全*的恐惧是如何被提炼为组织努力和制度框架的？重要的是，这些组织实践和框架对工人、企业、公众以及相互竞争的价值观组合有何更深远的影响？安全一直是且长期以来一直是通信技术和网络决策所依赖的关键轴心。将这些努力视为治理形式——即控制和管理被视为难以驾驭的事物的努力——进行仔细审视，有助于清晰地勾勒出利害所在：网络安全努力正在（并且已经有一段时间了）重塑作为当代生活基础的数字技术。更仔细地审视后续章节中记录的各种努力，能为这些努力的展开方式以及我们在过程中获得和失去的东西提供一个部分图景。

在后续页面中，鼓励读者思考各个致力于定义和应对网络安全问题的社区的深度参与。同时，读者也可以思考定义许多案例研究的孤立垂直领域的影响和重要性。随着网络安全专业人员数量以指数级速度持续增长，未能不仅从近期过去，而且从我们身边正在发生的事情中吸取教训的风险变得愈发明显。这并不是说在每种情况下都必须打破这些孤岛——虽然有进取心的读者或许能为网络安全政策拼凑出自己的“大统一场论”，但编辑们抱有希望（并认为这或许更有可能），即这些深度剖析能为“网络安全问题”的各个侧面提供有用的政策、法律和技术视角。案例研究在评论中刻意采取了不同的方法，但三条共同的主题线索贯穿全书。

## I.2 连接组织：共同主题

### I.2.1 网络安全具有情境性

网络安全并非存在于真空中。它始终具有情境性。网络安全努力植根于特定的时间和地点。这些努力由预先存在的政治组织和制度轮廓、产业生态系统，以及更大范围的地区和国际政治竞争与联盟所塑造。要理解某些问题如何被构建为网络安全挑战，以及应对这些挑战的特定方法如何被开发和部署，将这些努力置于这些更大的情境中至关重要。伊莱恩·塞登伯格和吉姆·邓普西的《网络安全信息共享治理结构：多样性、信任与权衡的生态系统》（[第1章](#c01.xhtml)）提供了一个冷静的叙述，说明忽视情境会发生什么。在对网络安全信息共享努力和2015年《网络安全信息共享法案》（CISA）的分析中，塞登伯格和邓普西认为，缺乏历史记忆的政策注定会失败。CISA是一个雄心勃勃的尝试，旨在启动新的信息共享努力。但它忽视了早已存在的制度迷宫和信息共享机制。信息共享远不止是一个技术问题。正如该章所指出的，未能考虑这一更广泛的情境限制了CISA的功效。

在《海合会（GCC）中的网络安全治理》（[第2章](#c02.xhtml)）中，詹姆斯·夏尔斯详细阐述了海湾阿拉伯国家合作委员会（GCC）六国的网络安全状况。夏尔斯展示了国家和地区政治如何塑造网络安全治理。通过梳理地区事件、关键政府组织和网络安全公司，以及相关战略、法律和标准，该章论证了网络安全具有地区特殊性。网络安全的轮廓受到更大范围流动的文化观念和压力的影响，但国家和地区政治在塑造网络安全如何被理解和应对方面起着决定性作用。夏尔斯的工作为地区和国家专业化发出了呼吁。这一呼吁得到了莱奥妮·玛丽亚·坦泽、伊琳娜·布拉斯、迈尔斯·埃尔斯登、马德琳·卡尔和杰森·布莱克斯托克在《英国新兴物联网（IoT）政策格局》（[第3章](#c03.xhtml)）中的有力回应。坦泽等合著者探讨了英国如何应对物联网的安全挑战，物联网是传感器和连接技术部署的巨变，它迅速出现且很大程度上缺乏监管指导。他们探讨了英国物联网努力如何与密集的制度格局相联系并由其定义。他们提出了一个引人深思的注记：随着英国准备退出欧盟，这一政治重组将如何冲击现有的网络安全努力尚不清楚。
