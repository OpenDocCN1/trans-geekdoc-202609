
# 英国数据保护法与物联网影响

同样，英国当前的数据保护法律已经发生了将影响物联网的变化。英国目前正在依据1995年数据保护指令（95/46/EC）运作。然而，2016年4月，欧洲议会和欧盟理事会通过了《通用数据保护条例》（GDPR；2016/679），该条例废除了先前的1995年数据保护指令。该条例将于2018年5月25日起在英国以及所有其他欧盟成员国适用，英国政府已确认，脱欧决定“将不影响GDPR的生效。”[^(50)](#c03.xhtml#c3-note-0050) 英国正在依据2018年数据保护法案运作，该法案最近取代了1998年数据保护法案。最新法案于2018年5月获得御准，并实施了全欧盟范围的《通用数据保护条例》（GDPR；2016/679）。该条例引入了两项关键原则：“设计中的数据保护”和“默认的数据保护”，要求从开发的最早阶段就将数据完整性保障构建到产品和服务中。数据最小化和隐私友好的默认设置也是必需的，并正成为常态。所有这些方面将直接关系到物联网生态系统中的隐私和数据管理，因为GDPR将影响该生态系统的大多数要素，从物联网设备的设计方式到物联网服务提供商收集、存储和处理数据的方式。

正如上述回顾所示，英国政府的网络安全政策仍与欧盟的政策相互关联，但一旦该国正式退出欧盟，政策可能会发生变化。在此之前，既定政策保持完好。未来政策实施的形式和范围将很大程度上取决于英国和欧盟达成的协议——这意味着脱欧可能对未来的物联网安全和隐私计划构成重大问题。

除了这些立法措施外，英国政府还制定了专门的网络安全计划和战略。英国建设有韧性的网络安全部门的主要举措由其国家网络安全战略（NCSS）驱动。第一个战略（2011-2016）侧重于经济繁荣、国家安全保护，以及通过建设更受信任和有韧性的数字环境来保障公众的生活方式。[^(51)](#c03.xhtml#c3-note-0051) 该战略由英国政府8.6亿英镑（约合12亿美元）的国家网络安全计划提供支持。在其最新版本（2016-2021）中，英国将投资增加到19亿英镑（26亿美元），并现在专注于国防、威慑和发展领域的政策和举措，与2011年不同的是，还涉及进攻性网络能力和物联网。[^(52)](#c03.xhtml#c3-note-0052) 尽管如此，对联网设备和服务的重视程度仍相当有限，在许多情况下主要关注工业物联网，而非其在各种应用领域的广泛使用。

尽管在IoTUK等倡议上投入了巨资，英国网络安全政策格局仍然碎片化，尚未对不断演变的互联环境形成明确的关注。许多部门仍然重视传统的网络安全和数据保护，这些领域正在发生变化，最终将为上述不同的政府机构和部门创造新的信息共享和协调挑战。物联网在英国许多网络安全相关文件中均未出现，包括用于政府采购的网络基础计划；[^(53)](#c03.xhtml#c3-note-0053) 2016年网络安全法规和激励审查，该审查评估了在更广泛的经济中加强网络风险管理的额外法规或机制的必要性；[^(54)](#c03.xhtml#c3-note-0054) 以及英国2017年数字战略，该战略提供了一个框架以增加数字基础设施并提升英国的数字技能。[^(55)](#c03.xhtml#c3-note-0055) 为了应对新出现的物联网风险和机遇，英国政府将需要考虑一个适应性框架来指导未来行动，并警惕这一新生态系统带来的独特问题。

## 3.5 物联网及其治理挑战

英国针对新兴物联网环境隐私和安全的政策框架简要概述指出了一些根本性的治理缺口。这些缺口范围从数据保护原则“自由给予、具体、知情且明确的同意指示”（GDPR，第32条理由）的实施——由于物联网生态系统的无处不在和渗透性，这变得极其复杂——到不同利益相关者之间责任和义务的分配。相关参与者将包括消费者、服务提供商、制造商、网络运营商和国家。

从安全角度来看，当前的监管框架尚未具备适应技术快速发展和物联网及相关技术（如先进机器人和机器学习）广泛应用的能力。这一问题与企业将充分的安全措施纳入物联网产品缺乏经济激励相互纠缠。[^(56)](#c03.xhtml#c3-note-0056) 在商业领域，用户在购买、设置、维护和安全处置物联网产品时，仍面临许多期望。[^(57)](#c03.xhtml#c3-note-0057) 欧盟层面已提出物联网的认证计划和相关信任标签的开发，这也可能影响英国市场。[^(58)](#c03.xhtml#c3-note-0058) 这些措施包括2017年提出的欧盟网络安全法案（COM/2017/0477）和2017年欧盟网络与信息安全局（ENISA）关于“物联网基线安全建议”的研究，可为物联网利益相关者提供评估其系统准备程度的工具。批评者也强调认证计划的局限性，例如执行评估所需的时间和精力。[^(59)](#c03.xhtml#c3-note-0059)

关于将在物联网产品和服务的安全开发和维护方面演进的标准、指南和最佳实践的类型，还有进一步的问题，特别是涉及软件更新时。在复杂系统和物联网支持的供应链中，设备相互连接且经常相互依赖，这尤其具有挑战性。

首先，在隐私、数据保护和处理方面，关于源自“联网”对象的所有数据在多大程度上被视为个人数据，仍存在疑问。这些问题在第29条数据保护工作组的一个“意见”中提出，[^(60)](#c03.xhtml#c3-note-0060) 该工作组是一个专注于数据保护的欧洲咨询机构，以及毛里求斯宣言（国际数据保护和隐私专员会议）中提出。[^(61)](#c03.xhtml#c3-note-0061) 根据这两个机构的观点，能够识别特定个人或家庭生活模式的数据应被视为个人数据。此外，第29条数据保护工作组认识到，“物联网背景下自动处理的大量数据带来了再识别的风险。”[^(62)](#c03.xhtml#c3-note-0062) 这种做法被视为扩大了“个人数据”原则，以反映与个人所处环境相关的数据，以及专门匿名化的数据。它进一步构成了一种立场，被认为通过泛化“个人数据”原则而造成不确定性，需要进一步澄清。[^(63)](#c03.xhtml#c3-note-0063)
