Let’s take one more example to calculate the value of coordinate (1, 2) of the matrix \(P_{90}\), again we will do pairing as shown in Figure 7.11. As the pair (1, 2) /= (2, 1) , therefore, only one direction arrow will be there. The total number of pairs with gray tone (1, 2) will be 3, so we assign the value 3 in \(P_{90}\) at the same coordinate position. In this way, all the coordinate positions in \(P_{90}\) will be assigned with the number of occurrences of vertical pair pixels with the same gray tone values as the coordinate position in \(P_{90}\).
