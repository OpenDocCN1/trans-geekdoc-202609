Dictionary learning is well-established in the statistics and signal processing communities$^{35,36}$, and sparse coding has many applications beyond neuroscience. Dictionary coding was was first introduced by Olshausen and Field to learn early layers of visual processing. Subsequent work has applied sparse code to model functional connectivity and extract features of early sensory systems. Moreover, sparse code has been used in transcriptomics to learn representations of gene expression$^{99,100}$. In the neuroscience literature, sparse code appears in various contexts, including EEG signal analysis, calcium imaging$^{102,103}$, auditory encoding, spike sorting$^{105,106}$, and assembly detection$^{118}$ among others.

**Alternating minimizing**
A bi-convex optimization problem can be solved using an alternating-minimization algorithm$^{108}$ / In each iteration $n$, the algorithm alternates between two steps: sparse coding, which computes an estimate of the codes $\mathbf{x}_k^j^{(n)}$, given the current dictionary estimate $\mathbf{D}^{(n-1)}$, and a *dictionary*-update step, that uses the current codes to refine the kernel elements. Mathematically, these two steps can be expressed as:

```
$$\mathbf{x}_k^j^{(n)} = \arg \min_{\{\mathbf{x}_k^j\}_{k=1}^K} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j\}_{k=1}^K\right) + \sum_{k=1}^K ||\mathbf{x}_k^j^{(n)}\|_2^2$
```

```
$$\mathbf{D}^{(n)} = \arg \min_{\mathbf{D}} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j^{(n)}\}_{k=1}^K\right) + \sum_{k=1}^K \frac{\lambda}{2} ||\nabla H(\mathbf{x}_k^j^{(n)})|_2^2$ (Equation 3)
```

subject to $|\{\mathbf{x}_k^j\|_1 = 0$ for $k=1,\dots K$

The first step describes the sparse coding process, which is separable across trials and neurons. For group sparsity, where the code is jointly optimized across neurons, this step involves solving a modified objective:

```
$$\mathbf{x}_k^j^{(n)} = \arg \min_{\{\mathbf{x}_k^j\}_{k=1}^K} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j\}_{k=1}^K\right) + \sum_{k=1}^K ||\mathbf{x}_k^j^{(n)}\|_2^2$, for $j=1,\dots J$
```

Compared to classical sparse coding, both the sparse- and dictionary-update steps in our model incorporate a convolutional structure. This convolutional structure enables the identification of patterns that occur locally across time.

**Sparse coding step**
The sparse-coding step can be solved using the shrinkage-thresholding algorithm (ISTA)$^{119,120}$ where the variance is implicitly absorbed into the sparse regularizer. This iteration of proximal gradient descent algorithm proceeds as follows:

```
$$\mathbf{x}_k^j^{(n)} = S_{\alpha_n}(\mathbf{x}_k^j^{(n-1)} + \alpha_n \nabla log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j^{(n-1)}\}_{k=1}^K\right)) = S_{\alpha_n}(\mathbf{x}_k^j^{(n-1)} + \alpha_n (\mathbf{y}^j - \sum_{k=1}^K \mathbf{x}_k^j^{(n-1)} * \mathbf{h}_k^j))$
```
