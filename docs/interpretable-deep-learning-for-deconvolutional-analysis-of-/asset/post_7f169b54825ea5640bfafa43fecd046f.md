# DUNL extracts salience and value signals from dopamine neurons

We applied DUNL to decode multiplexed signals in dopamine neurons. Midbrain dopamine neurons, particularly the ventral tegmental area, are crucial for modulating behaviors and during TD reinforcement learning.^54–59. A transient RPS signals an increase in unexpected value. Reward neurons have been identified with two overlapping representations: one representing salience and the other the subjective value (utility) of reward. This is significant, as the value-like component aligns with the Rew driving learning. However, unlike other methods, the overlapping representations of reward responses can be separated.^20–21 or using ad-hoc windows to isolate these constituents.^43 Using DUNL we investigated reward can be decomposed into these two components and whether they are differently modulated by value.

We showed using an ad-hoc window to exclude attributed salience, the representation of reward size (rew) remained, the ad-hoc window excludes the first 125 ms for expected trials and 150 ms for unexpected trials from reward. However, even with this inspection, DUNL's code still contains information about reward size.

DUNL's successful deconvolution of noisy responses to ad-hoc windows, demonstrates that the amplitudes from the kernel size are powerful measures of turning reward to size. We showed that the inferred reward sizes from this experiment under different initial conditions obtained results consistent with those in Figure 2 (Figures S1D, S1E, and S1F). Overall, DUNL provides a powerful tool to precisely quantify the relationship between the salience-like component and the response of individual neurons in an unbiased manner.

We performed electrophysiology from 40 identified dopamine neurons.^62 recorded in a mimicking task as part of a previous study.^66. In "unexpected" trials of variable size (rew), the reward was delivered without a cue. In "expected" trials, an odor preceded reward delivery by 1 s (Figure 2A and 2B). We used either the value code or the rew response to model the response to reward (Figures 2C and 2D). The kernels were aligned by shifting the reward and population jointly across neurons. DUNL was built with the timing of the cue and expected events but not the trials (except, the rewards).

# DUNL decodes salience

To demonstrate DUNL's flexibility with modalities beyond dopamine neurons in spikes, we applied it to two-photon calcium imaging. We recorded data from 55 dopamine neurons using calcium imaging with a graded feedback interval (GRI) rank (Figure 3A) during a classification task. This task showed the structure of a sensory behavior.^64^. In unexpected trials, rewards of varying sizes (0.3-1 s) were expected. Expected trials had a longer delay between cue and reward delivery.
