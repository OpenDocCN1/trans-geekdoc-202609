# Dopamine spiking experiment

The dataset consists of $N = 40$ recorded dopamine neurons, the number of trials from $J = 121$. For surprise trials, we use data from 1 second before the reward to 2 seconds after the reward. For expected trials, we use data from 1 second before the kernel to cover 0.8 seconds after the reward. For more details on data acquisition, see ⁶⁵.

We used the Binomial distribution with a time-bin of 25ms for ms decoding. We set $K = 3$ to learn the neural response to the reward, and the other two to represent salience and the reward prediction error responses. The baseline rate, $r_i$, is estimated for each trial. For stability, with rates lower than 0.001 are set to 0.001. We learned the three kernels, we for each kernel through the log function. In addition to the projection $p$, we apply ReLU($$) projection after backpropagation to enforce non-negativity. To enforce sparsity for each kernel indicator, the kernel value $c_i$ is set to 1 at the event onset and trial, with the event indicators set to zero at all time. The data, model, and training parameters are summarized in Table S2. For the attempted scenario, 685 out of the 780 trials were used for training; in this case, the kernel sparsity is set to 0.005.

# Dopamine calcium experiment

The data is captured from three sessions, with $N = 62$, and 30 trials. Data, model, and training are summarized in Table S3. Below, we provide a detailed explanation of the methodology. Given the continuous nature of calcium activity, we modeled the data using a Gaussian distribution. We use $K = 5$ kernels: one kernel to characterize neural activity in response to the odor with a reward (referred to as reward), another for the odor in expected trials prior to reward, and three kernels to model reward prediction error responses (RPEs). For RPEs, we use one with a non-negative kernel to model salience and two kernels to model value (one with a non-negative code and with a non-positive code). Additionally no not constraints are imposed on the kernels to explicitly model valence or value; the decomposition emerges during training. Each kernel spans 4 seconds in time. The baseline firing rate is estimated from the 1-second data interval preceding the first event in each trial.

To attribute the kernels to specific interests, we set the indicator vector for the regret code $e_t^R$ to 1 at the cue onset and 0, otherwise. Furthermore, $e_t^r$ is set to 1 at the cue onset and 0, otherwise. This assigns kernel $h_t$ to normalize the response to the cue as baseline of a reward, and $h_t$ to represent the response to the cue in experiments. Furthermore, $e_t^R$ and $e_t^r$ are 1 for all trials with a reward, being non-zero only at the reward onset.

We used the representation optimization formulation described earlier to regularize $x_t^i$, where $x_t^i$ captures the penalty of the nonzero entry of each code, $i$.

```
$x_t^i = [\|x_t^1||, \|x_t^2||, \|x_t^3||, \|x_t^4||, \|x_t^5||, \|x_t^6||].$
```

Additionally, we set $Q_{4,5} = Q_{5,4} = 2.5$, while all other entries of $Q$ are set to zero.

# Olfactory experiment

Each experimental session consisted of 250 trials. During each trial, a device delivered 50 odor pulses of the same peak frequency of 0.5 pulses/sec for 5 seconds. In the animal anterior cortex we recorded using a custom-built 32-channel tetrode at 30 kHz sampling rate in the Open EGL recording system.1-recording-system$^{142}$. The data were downsampled to 1 ms resolution for analysis. Single-unit activities were identified using Kilosort2$^{41}$.

The analysis involved sorting of 50-41 neurons per recording. At the end of each session, the bundle of bottles was moved by 40 $\mu m$ to capture a set of neurons for the subset. In each trial, we recorded $c=770$ neurons across 17 behavioral sessions. The data, model, and training parameters are summarized in Table S6.
