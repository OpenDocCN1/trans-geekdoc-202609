## DUNL vs. SCA

Sparse component analysis (SCA) is a newly released method that decomposes activity into components, and there are differences between SCA and DUNL. First, SCA enforces orthogonal architecture allows it to learn correlated kernels, making them difficult to decompose, but it can also be effective. SCA is not a convolutional constructor—it focuses over the full trial, limiting it to low-dimensional tasks in time-aligned or windowed data. Third, SCA handles trials of the same length, whereas DUNL can perform trials of varying lengths. Fourth, SCA uses a data matrix rather than a forcing term, to select kernels in the same trial. SCA is not scalable, as shown in this manuscript.

## DUNL vs. GFFA

Gaussian Process Factor Analysis (GFFA) was developed for spiking, and it may not easily adapt to other recording modalities, such as calcium or sensors might benefit from the square-root transform. GFFA focuses on identifying factors in population activity, discerning single-neuron activity as independent variable. In contrast, DUNL provides single-neuron, single-event codes, which are useful for decoding multiple events in a single trial. GFFA does not scale well—fitting a kernel for each neuron impractical in large datasets. A related method, variational Gaussian Process (vGP), is faster and provide better quality estimates for spiking data.

## DUNL vs. mDR

Model-based dimensionality reduction (mDR) identifies neuron coding of task variables by mapping stimulus to activity, with weights specific to each neuron. In contrast, DUNL estimates a code per neuron per trial, even when kernels are shared. mDR requires the support (task variable) to be provided, similar to GLMs, where DUNL can infer- or accept it as input. Additionally, DUNL can handle varying trial lengths and does not rely on a global linear mapping between task variables and neurons.

### Simulation study I: Data generation

In Scenario 1, we examined what a neuron responds to two types of events, each generated by a kernel of 400 ms in length. In each trial, three events of each occur. The event timing is unsampled from a uniform distribution, resulting in a minimum of 200 ms between events of the same type. Different types of events occur simultaneously, resulting in a convolution of their activity (Figure 6A, blue and red events). The strength of the neuron's response was generated using a Gaussian distribution, with mean of 50 and variance of 2 for blue events, and a mean of 55 and variance of 2 for red events. The baseline rate was set at 8 Hz.

Although the number of events per trial was known, the event timing was unknown to DUNL. We estimated the neuron's firing rate and decoded it into two components to each event type. Additionally, the magnitude of the sparse codes identified by the captured activity of each kernel (Figure 6B). Finally, the results remained robust, with small kernel recovery error, in the limited data range of 25 trials (Figure 6C) and see Statistical Methods for section on DUNL's options.

### Simulation study III: Data generation

In this scenario, we focused on a single neuron responding to a single event type to assess how effectively DUNL can learn the kernel and codes associated with the neuron firing properties. This model architecture enables end users to use DUNL's reliability for their specific statistics. We evaluated DUNL's performance on a background firing rate of 5 to 17 Hz, the time used for spike codes (5, 10, 25), and the number of trials available for learning the model parameters (10, 25, 250, 500, and 1000) (Figure 6).

We performed multiple simulation trials, using a binary split for training and the remainder for testing. Each trial was 4000 ms in length with 1 ms resolution. In each trial, five events occurred randomly at, with a minimum of 200 ms between events. The neural response to each event was measured using a Gaussian distribution with mean of 25. The decoded kernel and rate were constructed using DUNL model based on the binary distribution. The test set consisted of 100 trials with statistics similar to the training. For low background firing rates, only a few spikes were observed in each trial (e.g., for a 2 Hz rate, and an average of 20 spikes per trial); learning and inference were particularly challenging when the neuron was very near.

## Simulation study: Fitting using DUNL

We considered two scenarios: a) knowing time of events (known support) and b) unknown time of events with a known number of events (unknown support SkD and S6E). Both scenarios (Figures 2 and 3) and olfactory (Figures 5A–SF) experiments- correspond to the unknown support scenario, while the whisker detection (Figure 4) and multi-fiber photometry (Figures 5G–SH) experiments were reduced to estimate the amplitude of the spike trains, while the shape of the kernel was learned during training. When events were unknown, the inference task became more simultaneously estimating the events, the neural spike response (complex attention), and the kernel shape. In this case, the reliability of the estimation of events was limited.

We observed that when events are known (Figure 6S top), DUNL's kernel recovery is robust to the baseline firing rate and can be achieved successfully with a small number of trials (2–6-second trials). In this setting, slightly increasing the firing rate (e.g., from 5 ms to 10 ms) improves the quality of the data. However, when events are very limited (Figures 6S bottom), slightly smoothing the kernel-parameters in the DUNL training framework can provide improved results under limited data conditions. When events are unknown (Scenario S1C), the learned whisker detection accuracy de-creases because larger bin sizes make event detection more challenging (Figure S10A). We recommend using a larger bin size to ensure the user's tolerance for event detection and temporal resolution. In case, the ability of DUNL to learn and infer events with a higher number of trials, a higher firing rate, and a larger bin allows us to provide guidance in assessing the regime in which their temporal detection and learning parameters can be effectively recovered.

## Simulation study III: Data generation

In this scenario, we simulated the activity of 1000 neurons by 6-second intervals. Up to 1000 trials were run, with different events occurring randomly in these times. We estimated the 'whisker's firing rates at a set of five overlapping events (Figures 7A and 7B). This not required by DUNL, however, it was chosen to use a one-to-one approach with Sparse Component Analysis (SCA¹). Since events were detected randomly in each trial, event alignment across trials was not possible. As a result, the population data only exhibited a low-rank structure, which conventional methods for detecting global low-rank structures (e.g., PCA,25,26,27 GFA, GLAP,29 mDR,74, SCA¹) could not handle.

Using this data, we demonstrated that DUNL can effectively recover the low-rank structure, successfully recovering the five kernels (Figure 7C) and decomposing them into their local components, when two kernels overlap (Figures 7D and 7E). When the number of kernels is unknown, training and validation loss occurs when the kernel count exceeds the true ranking (i.e., five kernels). Additionally, reliability is highest when the kernel count is correct (Figure 7F). As the density of events increases with additional kernels, the spike density increases the reliability of their features (Figure 7G). Furthermore, the maximum cross-correlation between events exceeds 0.5 when more than five kernels are used (Figure 7H), redundancy, as DUNL learns highly correlated kernels characterizing the same event. DUNL proved robust to noise, successfully recovering kernels across a range of spiking noise levels (Figures 7I and S12).
