# Generative Model

We follow the perspective of analysis-by-synthesis and Bayesian modeling.$^{47}$ For each neuron $n$, we impose a generative level $a_n$ on the neuron's activity (the firing rate in spiking trial) as a function of a mean activity $a_n$, and a set of localized kernels ($h_{n,k}^i$) which characterize the neuron's response to events that occur sparsely in the time. The spike vector $x^{n,i}$ enters the entries associated with times when events occur, and their amplitudes represent the strength of the $k^{th}$'s $k^{th}$ kernel's contribution to the neuron's response. Similar to $y^{n,i}$, the entries of the spike code $x^{n,i} \in \mathbb{R}^T$ and the filter $h_{n,k}^T$ are both indexed. Here, $T_n$ is chosen based on the likelihood of the neural responses and the sampling rate, $T_n$ is independent of $T$ and increase in the duration of the trial should not affect the kernel of length $L_n$. Mathematically, we can express this convolution spike model as

```
$mu^{n,i} = g(\sum_{k=1}^{L_n} h_{n,k} * x^{n,i} + a_n)$
```

Although the model provides an estimate of each neuron's firing rate on a trial-by-trial, the kernels capture characteristics that are shared across trials and can either exist for each neuron or shared across the neural population. At times, we consider the kernels as dictionary elements. In scenarios where kernels are shared across neurons, we simply simplify the notation to $h$.
