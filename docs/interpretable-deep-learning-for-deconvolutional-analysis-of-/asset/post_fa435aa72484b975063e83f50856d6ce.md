## 6. Model characterization with kernels in an unstructured experiment
(A) Test from the unstructured experiment: raster rate of spiking events (top), smoother raster (middle), and even onsets (bottom).
(B) Example trial: firing rate (top), DUN-estimated firing rate, estimated codes and kernels).
(C) Estimated kernels: 25, 50, 100, 400, 1600 trials. Gray traces represent kernels used to generate the data. $R^2$ fit scores for true kernels are 0.66, 0.71, 0.74, 0.76, 0.77.

(D) Recovery error $\sqrt{1-cosine^2}$ as a function of the number of trials. Maximum cross-correlation was used to compute similarity, accounting for shifted kernels. The event detection hit rate was 82.02% and 80.68% for the smallest and largest datasets respectively, with a tolerance of 2-bins. With a 3-bin tolerance, the hit rate increased to 91.58% and 93.54%. Hits are reported with tolerance to shifted kernels (see supplemental information—STAR Methods for details of DUNL's shift property).

DUNL, using a probabilistic model to link kernels with firing rates, LFADS relies on a recurrent network with encoder and decoder, providing a better connection between spiking and data. For further comparison of DUNL with SCA and its ability to learn temporal low-rank streaks, see Figure 7K.

DUNL handles varying lengths through its convolutional, batch-based approach. It uses gradient-based optimizers like Adam and is scalable, processing batches of data on GPUs. To demonstrate scalability, we compare DUNL's training times with SeNMF (Figure 7N). SeNMF, which uses a neurons $\times$ trial length matrix, limits its ability to handle varying or multiple trials without concatenation.

### Choice of basis
Finally, we explain how DUNL enables users to learn sparse representations that characterize neural responses. We discuss two key points: (1) it eliminates the need to learn basis functions and (2) it provides a highly flexible set of kernels (e.g., one or two per event), enhancing interpretability. (A) Five kernels used to generate synthetic data for an unsupervised experiment, with each kernel appearing around once per time point in the runs.

(B) Kernels reconstructed by DUNL using 100 trials and decoded rates. Baseline rates and amplitudes vary across runs, but all kernels are reconstructed to true rates and amplitudes with one mean in the test runs.

(D) Loss per epoch for the training dataset (left) and validation dataset (right), for multiple kernels requested (3-7) in a single run.

(E) Average loss, number of kernels for the training (left) and validation datasets, computed over 30 runs with varying counts (20, 50, 100, 200, 250, 500, and 1000).

(F) Kernel consistency runs across runs as a function of the number of kernels.

(G) $R^2$ number of kernels decoded by DUNL.

(H) Maximum correlation between kernel pairs reconstructed by DUNL as a function of the number of kernels. Correlation approaches 1 when the kernel count exceeds the threshold.

(I) Mean correlation between true and estimated kernels, noise-related (right), with two overlapping kernels reconstructed by DUNL (Bottom).

(J) Example trial: true plot (top) and decoded rate from one neuron (middle), with two overlapping kernels reconstructed by DUNL (Bottom). Despite kernel orthogonality, SCA fails to deconvolve local kernels within single trials.
