Kernel regularization
This parameter is used during training. Larger values promote the smoothness of learned kernels. Kernel regularization is highly recommended for spiking data when the bin size B is small. However, increasing the alrate or the bin size for spikes may improve detection, but at the cost of kernels with lower resolution. We recommend setting λ to a small value. As the kernel bin size B pre-processes the data used during training and inference, a validation set can be used to tune this; however, the correlation between filters can help identify when the correlation is maximized, indicating the learning of stable and less noisy kernels.

Interpretability in depth
In deep learning, interpretability methods are categorized into two types: interpretable and understandable. The former also referred to as mechanically interpretable model, focuses on developing to explain black-box models. For example, in computer vision, saliency maps highlight the input pixels that are most descriptive with respect to the output prediction. A more general approach is Local Model-Agnostic Explanations (LIME), which explains predictions of a black-box model by local learning to make it interpretable. However, this class of models fails because there is no direct mapping from the embedding to the data. For example, the explanation might focus on features that are not relevant to the objective, leading to a lack of understanding of the “black-box” system. Second, this approach does not guarantee the network architecture for non-generalizable features for description. The depth of deep neural networks makes it hard to interpret.

In contrast, model-based interpretable deep learning (Figure 2) is a sub-category of deep learning designing neural networks that are inherently interpretable. This creates deep neural networks whose weights and representations can be interpreted as parameters and variables of underlying interpretability, as the mappings are inherently interpretable. This one-to-one mapping between neural weights and latent representations provides interpretability. The architecture generates detailed details about the data; instead, it provides domain knowledge without overstrict the network's output, ensuring that important data features are not followed.
