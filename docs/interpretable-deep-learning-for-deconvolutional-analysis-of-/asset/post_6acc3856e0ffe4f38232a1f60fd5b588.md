# Generative Model

We follow the perspective of analysis-by-synthesis and Bayesian modeling.$^{47}$ For each neuron $n$, we impose a generative level $a_n$ on the neuron's activity (the firing rate in spiking trial) as a function of a mean activity $a_n$, and a set of localized kernels ($h_{n,k}^i$) which characterize the neuron's response to events that occur sparsely in the time. The spike vector $x^{n,i}$ enters the entries associated with times when events occur, and their amplitudes represent the strength of the $k^{th}$'s $k^{th}$ kernel's contribution to the neuron's response. Similar to $y^{n,i}$, the entries of the spike code $x^{n,i} \in \mathbb{R}^T$ and the filter $h_{n,k}^T$ are both indexed. Here, $T_n$ is chosen based on the likelihood of the neural responses and the sampling rate, $T_n$ is independent of $T$ and increase in the duration of the trial should not affect the kernel of length $L_n$. Mathematically, we can express this convolution spike model as

```
$mu^{n,i} = g(\sum_{k=1}^{L_n} h_{n,k} * x^{n,i} + a_n)$
```

Although the model provides an estimate of each neuron's firing rate on a trial-by-trial, the kernels capture characteristics that are shared across trials and can either exist for each neuron or shared across the neural population. At times, we consider the kernels as dictionary elements. In scenarios where kernels are shared across neurons, we simply simplify the notation to $h$.

# Optimization

Given the set of observations from all trials, $\{y^{n,i}\}$ for each neuron $n$, we learn the kernels and by minimizing the log-likelihood with a prior on the kernels, i.e.,

$\min_{\{\mathbf{x}_k^j\}_{k=1}^K} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j\}_{k=1}^K\right) + \sum_{k=1}^K R\left(\mathbf{x}_k^j\right) + \frac{\lambda}{2} ||\nabla H(\mathbf{x}_k^j)||_2^2$

subject to $|\{\mathbf{x}_k^j\|_1 = 0$ for $k=1,\dots K$ (Equation 2)

where $\mathbf{x}_k^j$ controls the regularization of the codes. For example, setting $R(\mathbf{x}_k^j) = ||\mathbf{x}_k^j||_1$, regularizes the sparsity of the codes (i.e., the for event $k$ and type $j$). This regularization can also be defined as group sparsity$^{77-79}$ at each step ($t$, $\dots, T$), where $R(\{\mathbf{x}_k^j\}_{k=1}^K) = ||{\{\mathbf{x}_k^j\|_1\}_{k=1}^K$ encourages neurons to ensure they fire and detect concurrently. Additionally, $\mathbf{x}_k^j$ controls the smoothness of the kernels, augmenting by regularizing the first derivative of the kernel with respect to time $t$^{48,50}$. In this work, we use the term "sparsity" to refer to both sparsity and group sparsity. We refer to the above optimization framework as sparse deconvolutional learning (SSDL). Dictionary learning is well-established in the statistics and signal processing communities$^{35,36}$, and sparse coding has many applications beyond neuroscience. Dictionary coding was was first introduced by Olshausen and Field to learn early layers of visual processing. Subsequent work has applied sparse code to model functional connectivity and extract features of early sensory systems. Moreover, sparse code has been used in transcriptomics to learn representations of gene expression$^{99,100}$. In the neuroscience literature, sparse code appears in various contexts, including EEG signal analysis, calcium imaging$^{102,103}$, auditory encoding, spike sorting$^{105,106}$, and assembly detection$^{118}$ among others.

**Alternating minimizing**
A bi-convex optimization problem can be solved using an alternating-minimization algorithm$^{108}$ / In each iteration $n$, the algorithm alternates between two steps: sparse coding, which computes an estimate of the codes $\mathbf{x}_k^j^{(n)}$, given the current dictionary estimate $\mathbf{D}^{(n-1)}$, and a *dictionary*-update step, that uses the current codes to refine the kernel elements. Mathematically, these two steps can be expressed as:

```
$$\mathbf{x}_k^j^{(n)} = \arg \min_{\{\mathbf{x}_k^j\}_{k=1}^K} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j\}_{k=1}^K\right) + \sum_{k=1}^K R\left(\mathbf{x}_k^j\right) + \frac{\lambda}{2} ||\nabla H(\mathbf{x}_k^j)||_2^2
```

subject to $|\{\mathbf{x}_k^j\|_1 = 0$ for $k=1,\dots K$ (Equation 3)

The first step describes the sparse coding, which is separable across trials. For group sparsity, where the code is jointly optimized across neurons, this step involves:

```
$$\mathbf{D}^{(n)} = \arg \min_{\mathbf{D}} \sum_{j=1}^J -\log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j\}_{k=1}^K\right) + \frac{\lambda}{2} ||\nabla H(\mathbf{x}_k^j)||_2^2
```

Compared to classical sparse coding, both the sparse- and dictionary-update steps incorporate a convolutional structure. This convolutional structure enables the identification of patterns that occur locally across time.

**Sparse coding step**
The sparse-coding step can be solved using the shrinkage-thresholding algorithm (ISTA)$119,120}$ where the variance is implicitly absorbed into the sparse regularizer. This iteration of proximal gradient descent proceeds as follows:

```
$$\mathbf{x}_k^j^{(n)} = S_{\alpha_n}(\mathbf{x}_k^j^{(n-1)} + \alpha_n \nabla log p\left(\mathbf{y}^j |\{\mathbf{x}_k^j^{(n-1)}\}_{k=1}^K\right)) = S_{\alpha_n}(\mathbf{x}_k^j^{(n-1)} + \alpha_n (\mathbf{y}^j - \sum_{k=1}^K \mathbf{x}_k^j^{(n-1)} * \mathbf{h}_k^j))
```

(Equation 4)
