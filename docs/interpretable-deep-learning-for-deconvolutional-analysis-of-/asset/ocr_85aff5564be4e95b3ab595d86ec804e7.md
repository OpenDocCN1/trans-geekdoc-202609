Network parameters
In this section, we describe the parameters and their impact on the performance of UNL.

Unrolled step size:
The step size is used within the unrolled network. For stability, $\alpha < l_{max}(H)$, where $l_{max}$ is the maximum singular value, $H=\{H_1,\dots,H_T\}$, and $H$ is the Lipschitz constant matrix mapping the codes $h_k$. The step size $\alpha$ can be approximated using the iterative power method, as shown in Algorithm 1. We notice that performance is not highly sensitive to this parameter, as the networks remain stable.

Sparse regularization:
This is a parameter used to enforce sparsity on the latent representation of the encoder. When event occurs, its presence becomes scarce and enforced by the $\lambda^j$ at the unrolled layers, this parameter can be set to zero or a small value. However, in case of group sparsity, $\lambda^j$ operates on the activation of code nodes when events are unknown (ae., without prior knowledge). Increasing $\lambda$ in this scenario sparsifies the activation for individual neurons when most neurons are inactive.

Baseline:
Our model assumes a baseline activity that remains constant over time within each trial for each neuron. This baseline can be estimated by calculating the mean activity at the beginning of each trial, prior to the appearance of events of interest, and applying the inverse link function $g'(\cdot)$.
