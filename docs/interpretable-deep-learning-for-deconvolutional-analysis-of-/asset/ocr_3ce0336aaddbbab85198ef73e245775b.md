FIGURE 7, model convolutional used with 5 orthogonal kernels

(A) Five kernels used to generate synthetic data for an unsupervised experiment, with each kernel appearing around once per time point in the runs.

(B) Kernels reconstructed by DUNL using 100 trials and decoded rates. Baseline rates and amplitudes vary across runs, but all to the kernels are reconstructed to true rates and amplitudes with one mean in the test runs.

(D) Loss per epoch for the training dataset (left) and validation dataset (right), for multiple kernels requested (3-7) in a single run.

(E) Average loss, number of kernels for the training (left) and validation datasets, computed over 30 runs with varying counts (20, 50, 100, 200, 250, 500, and 1000).

(F) Kernel consistency runs across runs as a function of the number of kernels.

(G) $R^2$ number of kernels decoded by DUNL.

(H) Maximum correlation between kernel pairs reconstructed by DUNL as a function of the number of kernels. Correlation approaches 1 when the kernel count exceeds the threshold.

(I) Mean correlation between true and estimated kernels, noise-related (right), with two overlapping kernels reconstructed by DUNL (Bottom).

(J) Example trial: true plot (top) and decoded rate from one neuron (middle), with two overlapping kernels reconstructed by DUNL (Bottom). Despite kernel orthogonality, SCA fails to deconvolve local kernels within single trials.
