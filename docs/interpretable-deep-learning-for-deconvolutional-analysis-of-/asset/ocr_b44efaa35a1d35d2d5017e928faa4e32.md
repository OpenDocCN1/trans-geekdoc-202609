Each kernel spans 4 seconds in time. The baseline firing rate is estimated from the 1-second data interval preceding the first event in each trial.

To attribute the kernels to specific interests, we set the indicator vector for the regret code $e_t^R$ to 1 at the cue onset and 0, otherwise. Furthermore, $e_t^r$ is set to 1 at the cue onset and 0, otherwise. This assigns kernel $h_t$ to normalize the response to the cue as baseline of a reward, and $h_t$ to represent the response to the cue in experiments. Furthermore, $e_t^R$ and $e_t^r$ are 1 for all trials with a reward, being non-zero only at the reward onset.

# Olfactory experiment

Each experimental session consisted of 250 trials. During each trial, a device delivered 50 odor pulses of the same peak frequency of 0.5 pulses/sec for 5 seconds. In the animal anterior cortex we recorded using a custom-built 32-channel tetrode at 30 kHz sampling rate in the Open EGL recording system.1-recording-system$^{142}$. The data were downsampled to 1 ms resolution for analysis. Single-unit activities were identified using Kilosort2$^{41}.

The analysis involved sorting of 50-41 neurons per recording. At the end of each session, the bundle of bottles was moved by 40 $\mu m$ to capture a set of neurons for the subset. In each trial, we recorded $c=770$ neurons across 17 behavioral sessions. The data and modeling parameters for this experiment are summarized in Table S6.

Table S6: Details of the experimental parameters for the olfactory experiment.

The clustering analysis was performed k-means. Figure S7 illustrates k-means clustering results with 3, 4, 5, and 6 kernels. We randomly sampled 90% of the neurons (400 times) to compute clustering using random index (ARI). The ARI values were 0.94, 0.96, 0.93, and 0.77 for 3, 4, 5, and 6 kernels, respectively. Hence, the suggested number of clusters is 3 or 4. A similar clustering was also observed with the whisker kernel.

# Dopamine multi-fiber experiment

The training and modeling parameters for the multi-fiber experiment are summarized in Table S4. The original dataset contains simultaneously recorded traces from 14 fibers and a control patch during a session of heavily beating whisker, resulting in 15 independent runs of DUNL, all using the same parameters.

In our analysis, we performed event detection and characterization with a single kernel per fiber to identify specific features of the behavior reported. For more refined characterization, additional kernels could be learned, which is the focus of an ongoing work in another section of this manuscript.
