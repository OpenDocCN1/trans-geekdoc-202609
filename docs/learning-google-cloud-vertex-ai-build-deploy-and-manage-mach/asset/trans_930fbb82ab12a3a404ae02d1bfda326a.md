
核对完数据统计信息后，用户可点击“完成”，如[图 2.9](#ch02.xhtml#fig2-9)所示，以导航至训练阶段，如[图 2.10](#ch02.xhtml#fig2-10)所示：

![](images/Figure_2.10.png)

**图 2.10：表格 AutoML 模型训练启动**

1.  点击“训练新模型”。

### 步骤 2：训练方法选择

模型训练的第一步是选择数据集和目标，如[图 2.11](#ch02.xhtml#fig2-11)所示：

![](images/Figure_2.11.png)

**图 2.11：训练方法选择**

1.  选择已创建的数据集。
2.  选择目标为分类（因为目标列是分类型的）。
3.  选择 AutoML。
4.  点击“继续”。

### 步骤 3：模型详情选择

模型详情允许用户在训练新模型或已训练模型的新版本之间进行选择，如[图 2.12](#ch02.xhtml#fig2-12)所示：

![](images/Figure_2.12.png)

**图 2.12：模型选择详情**

1.  选择“训练新模型”。
2.  如果模型已训练，且用户因数据变更想要重新训练模型，则此选项允许他们使用新版本训练模型。
3.  为模型提供名称。
4.  为模型提供描述。
5.  选择目标列。
6.  如果选中该选项，数据集的测试拆分可导出到 BigQuery。
7.  点击“高级选项”可让用户选择数据拆分方式。

### 步骤 4：训练数据拆分

点击高级选项将提供有关数据拆分的更多选项，如[图 2.13](#ch02.xhtml#fig2-13)所示：

![](images/Figure_2.13.png)

**图 2.13：模型选择详情（数据拆分）**

1.  80% 的数据用于训练，10% 分别用于验证和测试。此拆分是随机进行的。
2.  用户也可提供一个额外的列，指明数据集中每条记录的拆分情况。
3.  如果选择按时间顺序分配，前 80% 的数据将用于训练，接下来的 10% 用于验证，最后 10% 的数据用于测试。
4.  高级选项 - 用于加密。
5.  点击“继续”。

### 步骤 5：训练选项

为用户提供转换选项，如[图 2.14](#ch02.xhtml#fig2-14)所示：

![](images/Figure_2.14.png)

**图 2.14：训练选项（数据转换）**

1.  已分配目标列。
2.  AutoML 并不总是选择要应用的正确转换。最好手动检查并更改转换类型。点击箭头以更改转换类型。
3.  如果需要从训练中排除任何列，则需选择该列。
4.  选中列后，点击"`-`"。
    （在我们的用例中，我们考虑所有列进行训练，因此无需执行步骤 3 和 4）。
5.  点击“高级选项”。

### 步骤 6：选择优化目标

将为用户提供额外的训练设置选项，如[图 2.15](#ch02.xhtml#fig2-15)所示：

![](images/Figure_2.15.png)

**图 2.15：训练选项（优化目标）**

1.  默认情况下，AutoML 认为所有列同等重要，但用户可选择为所需列增加更多重要性。
2.  根据用例，为用户提供选择优化目标的选项。
3.  点击“继续”。

### 步骤 7：计算资源和定价

模型训练的最后一步如[图 2.16](#ch02.xhtml#fig2-16)所示：

![](images/Figure_2.16.png)

**图 2.16：训练启动**

1.  用户可指定训练的最大节点小时数，表格数据集的最小值为 1。节点小时数代表虚拟机用于训练模型的时间。
2.  可启用早停，如果模型无法进一步训练，则停止训练。
3.  点击“开始训练”。

### AutoML 推荐的表格数据结构（分类和回归）

*   数据必须不超过 100 GB
*   列数必须大于 2 且不超过 1000
*   行数必须大于 1000 且小于 100000000

## 模型评估

我们衡量模型预测质量的方法称为模型评估。为此，AutoML 会在数据集的测试拆分上评估训练模型的性能，10% 的训练数据将用于评估（参考[图 2.13](#ch02.xhtml#fig2-13)）。

### 步骤 1：检查模型训练

训练状态可在[图 2.17](#ch02.xhtml#fig2-17)中查看：

![](images/Figure_2.17.png)

**图 2.17：训练完成**

1.  模型训练完成后，将以绿色勾号高亮显示。
2.  模型训练也将列在 Vertex AI 的训练部分中（点击它）。

### 步骤 2：模型训练结果

训练作业将列在训练部分下，如[图 2.18](#ch02.xhtml#fig2-18)所示：

![](images/Figure_2.18.png)

**图 2.18：训练作业下列出的训练作业**

1.  训练流水线将列出 AutoML 的训练作业。
2.  自定义作业将列出自定义模型的训练作业。
3.  超参数调优作业将列出带有超参数调优的自定义模型的训练作业。
4.  前面步骤中训练的 AutoML 模型（点击它）。训练好的模型也将列在 Vertex AI 的模型部分下。

### 步骤 3：模型评估

点击模型将导航至模型部分，如[图 2.19](#ch02.xhtml#fig2-19)所示：

![](images/Figure_2.19.png)

**图 2.19：训练模型评估**

1.  模型训练完成后，它将成为模型的第一个版本。当训练多个模型时，它提供选择特定模型版本的选项。
2.  训练好的模型可导出为 Tensorflow 软件包，且模型可导出到 Cloud Storage。
3.  “评估”提供关于目标变量类别信息的详情。用户可选择任意特定类别，分别查看每个类别的评估指标。
4.  列出不同的评估指标，并附带部分指标的可视化信息。可调整置信度阈值，以在不同置信度水平下检查图表。
5.  评估指标的图形表示（随置信度阈值变化而变化）。
6.  “批量预测”提供批量预测选项。
7.  “部署和测试”提供在线预测选项。
8.  “版本详情”提供模型版本的各种详情（点击“版本详情”）。

## 批量预测

批量预测请求是异步的。旨在单个任务中管理大量实例并执行更复杂的模型。每个请求可处理一个或多个实例。预测结果将写入您在 Cloud Storage 中选择位置的输出文件中。请按以下步骤进行批量预测：

### 步骤 1：创建批量预测

创建批量预测时，用户需输入所有详情，如[图 2.22](#ch02.xhtml#fig2-22)所示：

![](images/Figure_2.22.png)

**图 2.22：模型的批量预测**

1.  点击“创建批量预测”。
2.  为预测提供名称。
3.  选择用于预测的模型。
4.  用于预测的数据可从 Cloud Storage 存储桶或 BigQuery 获取。
