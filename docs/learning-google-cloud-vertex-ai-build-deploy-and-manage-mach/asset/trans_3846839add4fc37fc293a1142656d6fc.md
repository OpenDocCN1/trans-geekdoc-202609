# 前言

在当今世界，数据爱好者需要具备一项或多项云平台的专业知识。在云端通过数据解决业务问题，不仅需要全面理解算法，还需要全面了解云平台及其组件。

本书旨在通过实际案例帮助您理解 `Google Cloud Platform (GCP)` 的 `Vertex AI` 组件。在深入探讨 `Vertex AI` 之前，本书将让您对 Google Cloud Platform 及其组件有一定了解，以及 `Vertex AI` 的定位。本书所有示例的模型训练数据均上传至 `google cloud storage (GCS)` 或 `big query`，因此我们将从 `GCS`、`big query` 以及 `Identity access and management (IAM)`（身份与访问管理）开始介绍。`Vertex AI` 拥有众多组件，涵盖数据集、`Workbench`、`Pipelines`、训练、实验、模型、端点和特征等。本书的主要目标是通过实际用例学习这些 `Vertex AI` 概念功能。

[第 1 章：Google Cloud Platform 基础](#ch01.xhtml)：本章从基本理解 `Google Cloud Platform` 入手。涵盖 `GCP` 的覆盖范围、层级结构、平台，以及我们如何与 `GCP` 组件交互。`GCP` 的多种云服务模型（`IAAS`、`PAAS`、`SAAS`）。`GCP` 各组件的高层概览。我们还将了解 `GCP` 的存储能力，包括如何设置 `Google Cloud Storage` 并上传文件。如何使用 `Google` 的 `BigQuery`。我们将理解事件与访问管理（`IAM`）在平台中的必要性和重要性。

[第 2 章：Vertex AI 和 AutoML Tabular 简介](#ch02.xhtml)：本章将讨论 `GCP Vertex AI` 组件。介绍 `automl` 和自定义模型功能如何整合到单个 `GCP` 组件中。我们还将理解 `automl` 和自定义模型之间的关键区别。我们将从演示如何为结构化数据创建数据集以及如何为其训练 `automl` 模型开始。我们将探讨如何部署模型并获取批量预测和在线预测。
