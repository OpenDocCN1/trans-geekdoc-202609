
# AutoML 图像数据工作流

处理 AutoML 图像数据的步骤与 AutoML 表格数据类似，但在创建数据集和模型训练时略有不同。对于表格数据，我们可以直接使用上传到云存储的 `.csv` 文件创建数据集；但对于图像数据，用户需要创建一个 CSV 文件，其中包含图像所属的训练/验证/测试集信息、图像的完整路径以及其所属的类别。

虽然我们这里只处理属于三个类别的 150 张图像，手动创建包含所需信息的 CSV 很容易。但如果处理大量图像，手动创建 CSV 就不是可行的方案了。不过，在 Cloud Shell 中运行几行命令就能轻松搞定。

```
for f in $(gsutil ls gs://AutoML_image_data/Cruise_ships/); do echo UNASSIGNED,$f,Cruise_ships;done>>class_labels.csv
```

```
for f in $(gsutil ls gs://AutoML_image_data/Ferry_boat/); do echo UNASSIGNED,$f,Ferry_boat;done>>class_labels.csv
```

```
for f in $(gsutil ls gs://AutoML_image_data/Kayak/); do echo UNASSIGNED,$f,Kayak;done>>class_labels.csv
```

这些命令将创建一个包含三列的 CSV 文件：

*   设置图像用于训练/验证/测试。在本例中我们使用了 `UNASSIGNED`；平台将自动选择用于训练、验证和测试的图像。
*   图像的完整路径。
*   图像所属的类别。

使用以下命令将 CSV 文件推送到云存储桶：

```
gsutil cp class_labels.csv gs://AutoML_image_data/class_labels.csv
```

## 图像数据集创建

只有创建数据集后，才能启动 AutoML 模型训练。请按照以下步骤创建用于图像分类的图像数据集：

### 步骤 1：创建数据集

导航至 Vertex AI 的数据集模块，如[图 3.4](#ch03.xhtml#fig3-4)所示：

![](images/Figure_3.4.png)

**图 3.4：** 数据集着陆页

1.  点击**创建**。

### 步骤 2：选择目标

数据集创建标签页将出现，如[图 3.5](#ch03.xhtml#fig3-5)所示：

![](images/Figure_3.5.png)

**图 3.5：** 图像数据集选择

1.  选择**图像**标签页。
2.  选择**图像分类（单标签）**。
3.  为数据集提供名称。
4.  点击**创建**。

### 步骤 3：选择数据

数据可从云存储或本地系统中选择。按照[图 3.6](#ch03.xhtml#fig3-6)中提到的步骤从云存储上传图像：

![](images/Figure_3.6.png)

**图 3.6：** 图像数据集的数据选择

1.  标签存储在与模型目标关联的标注集中，将自动填充。
2.  选择从云存储导入文件。
3.  点击**浏览**。
4.  选择创建的 CSV 文件（参考[图 3.6](#ch03.xhtml#fig3-6)）。
5.  点击**选择**。
6.  点击**继续**。

### 步骤 4：数据导入完成

数据导入完成后，数据（图像）将如[图 3.7](#ch03.xhtml#fig3-7)所示显示：

![](images/Figure_3.7.png)

**图 3.7：** 图像数据集数据导入完成

1.  导航至**浏览**标签页。
2.  上传的图像根据输入的 CSV 文件进行分类。
3.  点击**训练新模型**以开始模型训练。

数据集创建后，将列在 Vertex AI 的数据集模块中，如[图 3.8](#ch03.xhtml#fig3-8)所示：

![](images/Figure_3.8.png)

**图 3.8：** Vertex AI 数据集下创建的图像数据集

> **注意：**
>
> *   GCP 建议每个标签至少拥有 1000 张图像（每个标签最少 10 张）。
> *   最大文件大小为 30MB。

## 图像模型训练

数据集创建完成且数据上传到数据集后，我们可以开始训练 AutoML 模型。请按照以下步骤启动模型训练：

### 步骤 1：模型训练方法

点击**训练新模型**后，用户将导航至如[图 3.9](#ch03.xhtml#fig3-9)所示的页面：

![](images/Figure_3.9.png)

**图 3.9：** 图像训练方法选择

1.  创建的数据集将自动填充。
2.  标注集也将自动选中。
3.  创建数据集时选择的目标会自动选中。
4.  选择 **AutoML** 进行训练。
5.  点击**继续**。

### 步骤 2：模型详情

模型训练的第二步是用户提供模型详情。请按照[图 3.10](#ch03.xhtml#fig3-10)所示步骤操作：

![](images/Figure_3.10.png)

**图 3.10：** 图像模型训练的模型详情

1.  选择**训练新模型**（如果要训练现有模型的新版本，请选择下方选项）。
2.  提供模型名称。
3.  提供模型描述。
4.  选择**随机分配**（因为我们在创建 CSV 文件时指定了 unassigned）。
5.  默认情况下，80% 的数据用于训练，10% 用于验证，10% 用于测试。不过，用户可根据需求进行更改。
6.  点击**继续**。

### 步骤 3：可解释性

模型可解释性是用户可选择的选项；目前我们不选择该选项。可解释性将在本书后面详细讨论。用户可跳过选择并点击**继续**，如[图 3.11](#ch03.xhtml#fig3-11)所示：

![](images/Figure_3.11.png)

**图 3.11：** 图像模型可解释性

1.  点击**继续**。

### 步骤 4：计算和定价

填写训练的计算时长，如[图 3.12](#ch03.xhtml#fig3-12)所示：

![](images/Figure_3.12.png)

**图 3.12：** 图像模型训练的计算和定价详情

1.  指定模型训练时长（图像数据最少训练时长为 8 节点小时）。
2.  启用提前停止（如果观察到无进一步改进则停止训练）。
3.  点击**开始训练**。

### 步骤 5：模型训练完成

模型训练完成后，数据集页面将更新，如[图 3.13](#ch03.xhtml#fig3-13)所示：

![](images/Figure_3.13.png)

**图 3.13：** 数据集页面上的图像模型训练状态

1.  绿色对勾表示模型训练完成。
2.  点击**模型注册表**。

### 步骤 6：模型注册表

训练好的模型将列在模型注册表中，如[图 3.14](#ch03.xhtml#fig3-14)所示：

![](images/Figure_3.14.png)

**图 3.14：** 模型注册表中列出的训练好的图像模型

1.  训练好的模型以用户提供的模型名称列出。点击模型名称。
2.  **模型 ID**，即模型的唯一 ID，将用于在线预测。

### 步骤 7：模型版本选择

模型版本列在模型注册表下，如[图 3.15](#ch03.xhtml#fig3-15)所示：

![](images/Figure_3.15.png)

**图 3.15：** 模型注册表上的图像模型版本

1.  选择模型版本（因为我们训练了一个新模型，所以有一个版本可用）。点击**1**。

> **注意：** 训练好的模型也将作为训练流水线列在 Vertex AI 的训练模块下。
