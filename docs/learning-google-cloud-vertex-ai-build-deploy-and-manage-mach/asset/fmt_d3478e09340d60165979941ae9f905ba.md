## Creation of Dockerfile

A Dockerfile is a text file that is read from top to bottom by Docker. It comprises a series of instructions that instruct Docker how to build the Docker image. A Dockerfile is a recipe for creating Docker images and executing a separate build command that generates the Docker image from that recipe.
