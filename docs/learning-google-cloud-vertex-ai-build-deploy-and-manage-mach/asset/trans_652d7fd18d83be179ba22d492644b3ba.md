## 镜像创建

现在我们已经完成了用于模型构建的 Dockerfile 和 Python 代码的创建。我们可以继续进行镜像创建。

### 步骤 1：使用 docker build 创建镜像

按照 [图 4.19](#ch04.xhtml#fig4-19) 所示输入以下命令以创建镜像：

```bash
IMAGE_URL="gcr.io/$PROJECT_ID/price:v1"
```

## 提交自定义模型训练作业

为了让模型得到训练，它会从上传到云存储存储桶的 `.csv` 文件中获取数据。默认情况下，Workbench 资源将拥有对云存储的读写访问权限。然而，当我们提交训练作业时，训练代码将在一个或多个由 Google Cloud 管理的虚拟机实例上执行。这些虚拟机将无法访问云存储存储桶，因此我们将使用服务账号。请按照以下步骤提交训练作业：

### 步骤 1：Vertex AI 的训练模块

按照 [图 4.26](#ch04.xhtml#fig4-26) 所示打开 Vertex AI 的训练模块：

![](images/Figure_4.26.png)

Figure 4.26: 训练模块

1.  选择训练模块。
2.  选择自定义作业。
3.  点击创建。

### 步骤 2：选择训练方法

将出现“训练新模型”页面，如 [图 4.27](#ch04.xhtml#fig4-27) 所示。按照图中提到的步骤配置训练方法：

![](images/Figure_4.27.png)

Figure 4.27: 自定义模型的训练方法选择

1.  选择训练方法。
2.  在数据集选择下选择**非托管数据集**。
3.  选择自定义训练。
4.  点击继续。

### 步骤 3：模型详情

按照 [图 4.28](#ch04.xhtml#fig4-28) 所示选择模型详情以训练模型：

![](images/Figure_4.28.png)

Figure 4.28: 自定义模型的模型详情

1.  选择训练方法后，我们必须输入模型详情。
2.  选择训练新模型。
3.  为模型提供名称。
4.  提供模型描述。
5.  必须为模型训练选择服务账号。点击浏览。
6.  由于代码将被推送到 Google Cloud 虚拟机实例，因此需要服务账号来从云存储访问数据并将模型存回云存储。
7.  选择与计算关联的服务账号（用户也可以选择我们在 [第 2 章](#ch02.xhtml) 中创建的服务账号，但需要添加访问云存储的角色）。
8.  点击选择。
9.  点击继续。

### 步骤 4：训练容器详情

按照 [图 4.29](#ch04.xhtml#fig4-29) 中提到的步骤配置训练容器：

![](images/Figure_4.29.png)

Figure 4.29: 自定义模型的容器详情

1.  选择模型详情后，我们必须输入训练容器详情。
2.  选择自定义容器。
3.  点击浏览以选择上一节中创建的镜像。
4.  选择创建的镜像。
5.  点击选择。
6.  选择用于存储模型工件的云存储存储桶（因为我们已经在代码中选择了存储桶，此处可以留空）。
7.  点击继续。

### 步骤 5：超参数调优

下一步是超参数。超参数将在后续章节中详细介绍。按照 [图 4.30](#ch04.xhtml#fig4-30) 所示的步骤暂时跳过此步骤：

![](images/Figure_4.30.png)

Figure 4.30: 超参数调优 – 可选

1.  选择训练容器后，可选设置超参数可以被配置。
2.  点击继续（不要启用超参数调优）。

### 步骤 6：计算和定价

下一步是提供计算和定价详情。按照 [图 4.31](#ch04.xhtml#fig4-31) 所示的步骤选择用于训练的机器类型：

![](images/Figure_4.31.png)

Figure 4.31: 自定义模型的计算和定价

1.  选择计算和定价。
2.  选择模型训练发生的区域。
3.  选择用于模型训练的机器类型（根据模型训练的复杂程度选择机器类型）。
4.  加速器类型是可选的，可为复杂的模型训练选择。
5.  磁盘类型可在标准和 SSD 之间选择。
6.  必须输入虚拟机的磁盘大小。
7.  如果模型复杂，可以为模型训练添加更多工作节点。
8.  点击继续。
