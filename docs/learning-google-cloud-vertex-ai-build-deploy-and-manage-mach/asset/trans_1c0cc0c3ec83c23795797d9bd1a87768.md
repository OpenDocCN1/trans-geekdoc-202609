### 模型导入

通常，自定义训练的模型不会列在模型注册表中。请遵循给定步骤将模型导入模型注册表。

#### 步骤 1：选择模型注册表

在 Vertex AI 上选择模型注册表。请参阅 [图 5.21](#ch05.xhtml#fig5-21)：

![](images/Figure_5.21.png)

**图 5.21：** Vertex AI 的模型注册表

请遵循相应的要点：

1.  选择模型注册表。
2.  点击 `IMPORT`（导入）。

#### 步骤 2：为模型选择名称和区域

请参阅 [图 5.22](#ch05.xhtml#fig5-22)：

![](images/Figure_5.22.png)

**图 5.22：** 导入训练模型的名称和区域信息

请遵循相应的要点：

1.  选择名称和区域。
2.  选择 `Import as new model`（作为新模型导入）。
3.  为模型提供名称。
4.  提供模型的描述。
5.  选择保存模型的区域。
6.  点击 `CONTINUE`（继续）。

#### 步骤 3：选择模型设置

请参阅 [图 5.23](#ch05.xhtml#fig5-23)：

![](images/Figure_5.23.png)

**图 5.23：** 导入训练模型的模型设置

请遵循相应的要点以配置要导入的模型：

1.  选择模型设置。
2.  选择 `Import model artifacts into a new pre-built container`（将模型工件导入新的预构建容器）（预构建容器仅可用于使用 TensorFlow、sklearn 和 XGBoost 训练的模型）。如果模型是使用任何其他包训练的，请选择 `Import an existing custom container`（导入现有自定义容器）选项。
3.  选择模型训练所基于的框架。
4.  选择包的版本（`sklearn`）。
5.  选择包含导出模型的存储桶。
6.  点击 `CONTINUE`。

#### 步骤 4：可解释性（可选）

请参阅以下 [图 5.24](#ch05.xhtml#fig5-24)：

![](images/Figure_5.24.png)

**图 5.24：** 设置模型的可解释性

请遵循相应的要点以配置要导入的模型：

1.  启用模型的可解释性是可选的；我们将在本章中忽略它。
2.  点击 `IMPORT`。

#### 步骤 5：模型已导入模型注册表

#### 步骤 6：来自 Python 的在线预测

模型已部署到 GCP 端点。用户可使用本地机器上的 Python 从已部署模型获取预测。（在我们的示例中，我们使用 PyCharm IDE 获取预测，预测可从任何 IDE 获取，或可在工作台上使用相同代码进行预测）。

代码需要服务账号的完整路径、端点 ID、端点位置和 `api_endpoint` 以获取预测。（下方代码包含所有详细信息，执行代码前请确保根据需要更改输入）。代码输出如 [图 5.31](#ch05.xhtml#fig5-31) 所示。

通过以下命令安装 `google-cloud-aiplatform` Python 包：

```
pip install google-cloud-aiplatform
```

可从以下链接获取有关该包的更多信息。

<https://pypi.org/project/google-cloud-aiplatform/>

#### 用于预测的 Python 代码

```
#Install google-cloud-aiplatform

import os

from google.cloud import aiplatform

from google.protobuf import json_format

from google.protobuf.struct_pb2 import Value

#Working code for hyperparameters

def online_custom_models(project, endpoint_id, instance_dict, location, api_endpoint):
    client_options = {"api_endpoint": api_endpoint}
    client = aiplatform.gapic.PredictionServiceClient(client_options=client_options)
    instance = json_format.ParseDict(instance_dict, Value())
    instances = [instance]
    parameters_dict = {}
    parameters = json_format.ParseDict(parameters_dict, Value())
    endpoint = client.endpoint_path(project=project, location=location, endpoint=endpoint_id)
    print(endpoint)
    response = client.predict(endpoint=endpoint, instances=instances)
    predictions = response.predictions
    print(predictions)

#For GCP authentication.
```
