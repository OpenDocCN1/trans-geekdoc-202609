## 摘要：

目标：动脉脉狭窄 (AS) 是一种变性瓣膜疾病，目前诊断不足且治疗不足。利用有限的 2D 超声心图检测 AS 可以实现筛查，并改善该疾病的适当转诊和治疗。我们旨在开发从有限成像数据自动检测 AS 的方法。

方法：使用有限的 2D 经胸超声心图 (TTE) 数据对卷积神经网络进行训练、验证和测试。开发的网络用于完成两个顺序任务：1) 视图识别和 2) AS 的疾病级分级。使用平衡准确率和受者工作特征曲线下面积 (AUROC) 作为性能指标。

结果：包含了 577 名患者的标注图像。神经网络在来自 338 名患者的数据（平均 N = 10,253 张标注图像）上进行训练，在 119 名患者上进行验证（平均 N = 3,505 张标注图像），并在 120 名患者的测试集上（平均 N = 3,511 张标注图像）评估性能。实现了 AUROC 为 0.96 的 AS 全自动筛查。网络能以 AUROC = 0.86 区分无显著（无、轻度、轻/中度）AS 与显著（中度或严重）AS，并以 0.75 的 AUROC 区分早期（轻度或轻度/中度 AS）与显著（中度或严重）AS。在 8502 例门诊 TTE 队列中对这些网络的外部验证显示，仅需胸旁长轴成像即可实现 AUROC 为 0.91 的 AS 筛查。

结论：使用现代神经网络利用有限的 2D 数据实现 AS 全自动检测是可行的。这些方法为新型 AS 筛查方法奠定了基础。

## 引言

动脉脉狭窄 (AS) 是一项巨大的公共卫生问题，影响着 1260 万成年人，在全球范围内每年导致估计 10,200 人死亡。7 近期，对 AS 的早期识别引起了兴趣，且证据表明许多患者未得到适当治疗。2,3 这些观察促使我们研究识别 AS 的新型机器学习 (ML) 方法。

传统上，AS 的准确分级依赖于多个平面的结构和血动力学参数的整合。4 从筛查的角度来看，AS 的某些特征（如瓣膜厚度和钙负荷）在 2D 图像上显而易见。虽然深度学习方法在某些医学图像分类任务中已经超过人类5,6，常见的分类器仅以单个图像作为输入，且在超声心图中的应用目前主要关注视图识别、分割以及心脏功能和心肌疾病的评估。7-10 目前 AS 的 ML 方法限于使用超声报告（因此需要专家对图像进行解读才能工作）11,12，或者限于仅关注严重疾病的小样本13。14 尚未研究关注利用有限图像评估 AS 的连续性，以建立适用于筛查的工具。

## 方法

一家大型三级医疗中心（马州波士顿塔夫茨医学中心）。心血管成像中心已获得国际学会认证委员会 (IAC) 认证，并配备了主要供应商（Philips, Toshiba, Siemens）的超声设备。

### 超声图

本工作已获得塔夫茨医学中心伦理委员会 (IRB) 的批准。超声图源于 2011-2020 年间作为常规护理实施的 TTE。通过使用标准的医学数字影像和通信 (DICOM) 图像，这些方法旨在独立于设备。根据是否存在 AS 纳入超声图。未根据图像质量选择图像。排除既往过动脉瓣置换的患者。其他心脏发现，包括其他结构性心脏疾病和心律异常（如房颤）均未排除。

### 图像采集与预处理

图像由经过培训的超声技师采集，方法与现美国超声心学会 (ASE) 指南一致。15。对于本研究，我们使用元数据来识别
并舍弃频谱多普勒、彩色血流多普勒和 M 模式记录，仅保留 2D 心脏经声心动图（TTE）图像。为了最小化计算时间并增强可传输性，并为这些网络用于未来的筛查环境做好准备，系统自动选择了 PLAX 或 SAX AoV（主动脉瓣）循环的第一帧用于预测模型。如果一项研究中存在多个 PLAX 或 SAX AoV 获取（这通常很常见），预测将使用每次获取的第一帧来得出研究级的 AS（主动脉瓣狭窄）预测。所有图像均标准化为 112x112 像素分辨率。与常规临床护理一致，在收集图像时，没有可用的视图或诊断标签标注。

### 去标识化 (De-identification)

利用 DICOM 存储格式中编码的已知区域位置，开发了专用软件来自动识别包含保护健康信息（PHI）的图像刻字区域。通过从数据拷贝中排除这些成像区域，实现了可靠的图像去标识化。我们对包含的去标识化图像的 10% 样本进行了人工审核，以确认未包含任何 PHI。

### 有限视图标签 (Limited View labels)

研究设置遵循通过超声心动图诊断 AS 的认知步骤（图 1），具体为视图识别后进行视图解释。我们收集了少数类型视图的专家标注，其目标是：1) 评估和验证自动化视图分类网络；2) 将优先考虑的视图用于后续的 AS 诊断模型。标签被分配给胸骨旁长轴（PLAX）和主动脉瓣水平的胸骨旁短轴（PSAX AoV）示例。选择这些视图是经过特意考虑的，因为它们是能够可视化 AoV 的标准视图，并且在有限的筛查环境中可以优先考虑。为了评估视图分类任务，我们还对心尖二腔（A 2C）和心尖四腔（A4C）视图进行了标注。我们还收集了涵盖其他 2D 视图的“其他（Other）”超类分类标签。本研究未包含多普勒成像，因为这些获取在点旁超声（POCUS）成像研究中并非常规采集，而且多普勒图像的获取需要高水平的技能，这种技能通常只有在专业的超声心动图实验室才能获得。

建立了一个超声心动图标注工具以方便视图标注（附图 1）。标注者（经认证的超声心动图专家或美国诊断医学声学协会认证声声师）为我们标记集中包含 599 项研究中的每项研究的每个成像视图分配了 ≥ 2 个示例。我们在一组 50 份重复标注的超声心动图上评估了标注者之间致性（附表 1，附表 2）。

### 诊断标签 (Diagnostic labels)

AS 是否存在（如果存在）由一位具有超声心动图专业培训的心脏病医生分配。AS 分类在临床护理期间按照当前指南推荐的标准方法，通过整合方法进行（即整合给定患者所有类型视图的所有可用图像的信息）。4 本研究的 AS 参考分级直接取自临床影像报告。这些实验的 AS 标签所示表 1。研究特意包含了代表整个 AS 病理谱的超声心动图。为了使这项工作专注于潜在的自动化筛查用例，并考虑到读者之间对疾病严重程度的一致性有限，我们将标准的严重程度分成了 3 个诊断类：“无 AS”、“早期 AS”（合并了轻度和轻中度）和“显著性 AS”（合并了中度和重度）。

在筛查环境中（传统超声心动图实验室的上游），主要的临床问题是哪些个体应该转诊进行超声心动图和 AS 相关护理。

### 用于视图和诊断分类的深度神经网络 (Deep Neural Nets for View and Diagnosis)

上述的图像到视图和图像到诊断分类网络，我们的目标是自动分配研究级的 AS 严重程度：一个总结研究中所有图像整体解释的向量。为了实现这一点，我们应用了一种称为优先视图权重的方法（19），我们在早期、较小的数据集上开发。直观动机是，来自显示主动脉瓣图像的诊断预测应该是比视图类型更有力的证据。主要输出是指示诊断的 3 类概率向量（无、早期或显著），辅助输出是指示视图的 5 类概率向量。我们使用多任务训练，损失函数是 3 类诊断交叉熵和所有视图标注图像的5 类视图熵之和。我们发现这种多任务训练带来了更好的诊断性能。多任务训练后，仅使用 3 类诊断输出。每个模型通过随机梯度下降训练，直到其主要任务的验证平衡准确率至少30个 epoch没有提高。所需的 epoch 根据所用方法在150-1000 不等。

### 来自大量图像的单研究诊断 (One Study-Level Diagnosis from Many Images)

上述图像到视图和图像到诊断分类网络，我们的目标是自动分配研究级的 AS 严重程度：一个总结研究中所有图像整体解释的向量。具体而言，我们的优先视图程序通过三个步骤获得研究级的概率预测。首先，使用图像到诊断分类器产生研究中每幅图像的 3 类 AS 概率向量。其次，使用图像到视图分类器预测每幅图像的相关视图（PLAX 或 PSAX）的概率。最后，对第一步的 3 类向量进行加权平均，以第二步的概率作为权重。我们将这种优先视图方法与另一种简单平均法进行比较，后者不通过视图分类器权重地处理所有图像。

### 性能指标 (Performance Metrics)

感兴趣的性能指标。当数据类别分布不平衡时（在视图和诊断任务中均如此），标准准确率无法充分评估性能。平衡准确率通过两个步骤计算：计算每个类别中被正确识别的真实成员比例，然后对所有类别取平均值。

为了进一步协助我们方法作为筛查工具的用途，我们使用了受试者工作曲线（ROC）分析，并报告了几个潜在用例的曲线下面积：（A）无 AS 与任何 AS（早期和显著），B）早期 AS 与显著性 AS，以及 C）


区分非显著（无主动瓣狭窄或早期主动瓣狭窄）与显著（中度、重度）主动瓣狭窄。

# 外部验证

使用 Stanford EchoNet Dynamic 数据集对视图分类器进行了外部验证。²20 该数据集包含 10,030 张 A4C 视图图像，这些图像是通过与我们专注于 Tufts 的数据集完全不同的患者群体、临床团队和标签分配所收集的。由于所有 10,030 张图像均为 A4C 视图，我们报告了我们的视图分类器在该数据集上的准确率。我们使用了该集中所有可用的 A4C 图像，其分辨率为 112x112（与我们的图像分辨率相同）。

我们进行了两项针对主动瓣狭窄诊断分类器的外部验证研究。第一项是对 Tufts 医学中心在 2022 年 5 月至 7 月期间进行的经声心动图（TTE）进行的时间外部验证。这些研究代表了临床指征性的 TTE，其主动瓣狭窄分类经过本研究的独立审查（无主动瓣狭窄、早期主动瓣狭窄、显著主动瓣狭窄，定义方式与模型推导任务相同）。

接下来，我们对 iCardio.ai 提供的数据进行了外部验证研究。该数据由一家门诊诊断影像公司在 2018-2020 年间执行的 TTE 组成。对于这项验证，我们获得了单一成像视图（PLAX）和该研究的主动瓣狭窄诊断标签。该验证旨在测试模型在有限 2D 采集上的性能。该队列的 TTE 是在美国超过 13 个州的州的独立医疗机构和诊所进行的，数据使用来自 4 家主要供应商（GE®、Philips®、Teratech®、Acuson®）的超声设备采集。主动瓣狭窄分级由 COCATS III 级心动图专家分配。

## 结果

本研究纳入的患者临床特征如表 3a 所示。主要标记队列包括 577 名患者。中位年龄为 74 岁（IQR 63-82），43% 的患者为女性。研究人群中 86% 为高加索人。心动图的血液动力学参数见表 3b。主动瓣膜中位速度为 2.89 m/s（2.29-3.67），中位峰值差为 34.6 mmHg（21.0-54.0 mmHg），平均压力差为 18.1 mmHg（11.9-30.6 mmHg）。平均左心室射血分数为 60%（55-65%）。

数据集的划分如表 2 所示。全标记集包含诊断和视图标签（599 名学生代表 577 名患者，共 43,823 张图像，其中 17,270 张具有视图标签）。经过预处理后，我们数据集中的中位研究包含 70 张图像（第 5-95 百位数范围 48-105，最小-最大范围 15-181）。具有视图标签的图像中位数为 19 张（5-95 百位数范围 4.9-71，最小-最大范围 1-107）。全标记数据被分为训练集（60%，360 项研究）、验证集（20%，119 项研究）和测试集（20%，120 项研究）。

在 TMED-2 的 3 个分区上平均后，我们的视图分类器在测试集上实现了 97% 的平衡准确率。随着可用训练和验证数据规模的增加，视图任务的平衡准确率显著提高：从仅 56 项研究的 90.3%（95% 自助采样 CI 87.5-90.4%）增加到所有 476 项研究的 97.0%（95% 自助采样 CI 95.9-97.5%）。

使用有限 2D 数据集（嵌入在医院或诊所的心声图实验室内部或上游）的自动筛查程序可能会改进病例和转诊。虽然这些模型的判别性能表现优异，但其阳性预测值有限。这在一定程度上源于主动脉狭窄（AS）的患病率较低，并且应该结合极高的阴性预测值来考虑（即漏诊的病例极少）。

这些工具使研究能够针对严重 AS 患者$^{25,26}$ 之间巨大的治疗差异进行研究，或者探究关于“许多严重 AS 患者未接受治疗”的这一新兴证据$^{3,27,28}$。自动筛查可以允许对主动脉狭窄的自然史进行大规模研究，并可能揭示该疾病患者护理路径中的潜在偏差。无疑，还需要额外的研究来评估能够有效筛查和及时转诊的自动化工具是否能改善 AS 患者的预后。AS 的自动检测还可能支持早期干预的研究，以阻止疾病进展。$^{29}$ 传统上，由于早期 AS 通常没有症状，研究早期疾病一直是一项挑战。如果出现了有效的治疗方法，或者为了实现早期疾病治疗的试验招募，对有限的心声图进行全自动解释可能是有价值的。这里介绍的方法没有使用多普勒图像，因此可能非常适用于床旁超声检查（POCUS）设备。

本文研究的现代网络对心声图领域具有吸引力，因为它们可以从小标记数据集中学习到具有竞争力的模型。这些模型使用了循环帧（cine loops）中的单帧。然而，使用随变化的特征集几乎肯定包含额外信息，但这种增加的信息也必须与处理更复杂数据集所需的计算需求之间进行平衡。该网络旨在具有可扩展性，并且仅需要具有临床价值所需的最少信息。

此外，正如外部验证研究所示，这些网络可以摄完整或部分研究并分配诊断标签。这种灵活性使得这些方法适用于筛查环境中的有限采集数据。研究级诊断是通过使用一种新的视图优先方法实现的，该方法使用视图分类器来识别被认为与目标诊断任务（此处为 A.S.）相关的视图。然后，这些相关视图的诊断分类器预测结果通过加权平均进行优先级排序，以预测一个一致的研究级诊断标签。我们展示了序列视图和诊断任务的验证研究，以强调我们在此使用的分层方法，我们认为这种方法可以应用于自动化其他复杂的影像诊断。

这些研究中使用的数据作为我们 Tufts 医学心声图数据库第 2 版本（TMED-2）的一部分发布（代码可在 https://tmed.cs.tufts.edu/ 获取）。与我们较小的早期版本相比，TMED-2 大幅增加了公开发的研究数量，将分辨率从 64x64 提高到 112x112，并增加了可用的视图类型¹19。该数据库涵盖了多种 AS 病变，并将支持开发用于复杂影像诊断自动筛查的新方法。在数据集规模增加 3 倍的情况下，在外部数据上可能实现的显著准确率提升，说明了向全球研究人员提供标记数据集的紧迫需求。

这项工作存在一些必须承认的局限性。提供的心声图来自单一学术中心，且诊断标签作为常规临床护理的一部分分配的。非白人患者在该队列中代表性不足，尽管基于心声图的 AS 影像诊断不应因种族产生任何生物学差异。本研究未包含结果数据或其他影像学态的信息来确认疾病严重程度。虽然标记的心声图数量有限，但这些网络值得关注的特点是它们可以从小标记集中进行学习。这对于标记昂贵且耗时的未来模型开发至关重要。

虽然更复杂的低流/低梯度亚型可能会被误分类，但我们通过将中度和严重 AS 合并为一个“显著性 AS”类别来降低这种风险，该类别应被转诊以全面的研究和治疗。这是设计初衷，对于未来的筛查试验至关重要。之前仅关注高流/高梯度亚型¹十四的努力将漏掉许多代表低流特征严重疾病病例。随着我们代码和图像的发布，我们鼓励对我们的工作进行额外的外部验证。我们预计随着更高的图像分辨率、更大的神经网络或使用循环帧的所有帧（而非仅第一帧），性能将会提高；我们保持了适中的分辨率（112 x 112 像素）并仅使用一帧是为了在准确性和训练时间之间实现可行的平衡。在现代 GPU 上，我们训练的每个神经网络在最大版本的数据集上都需要几十小时的时间。

## 结论

针对心声图优化的机器学习（ML）方法可以利用有限的 2D 数据成功识别 AS。这些方法为该疾病的全自动筛查和未来的研究奠定了基础。

## 补充图 3 视图分类器误差率随样本量的预测

![img/9e83ae159ad9802ed604394e24f29_50_0.png]

**补充图 3.** 视图分类器误差率随训练集规模变化的预测。随着可用标注数据的增加，使用幂律尺度规则 $an^{-\beta}$ 来最小所示测量值的平方误差。根据此预测，训练和验证可用 1000 个标注研究（我们当前发布数量的两倍）将产生 1.5% 的平衡误差率，等同于 98.5% 的平衡准确率。
