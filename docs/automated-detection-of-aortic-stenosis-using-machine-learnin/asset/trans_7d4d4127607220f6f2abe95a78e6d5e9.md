

使用有限 2D 数据集（嵌入在医院或诊所的心声图实验室内部或上游）的自动筛查程序可能会改进病例和转诊。虽然这些模型的判别性能表现优异，但其阳性预测值有限。这在一定程度上源于主动脉狭窄（AS）的患病率较低，并且应该结合极高的阴性预测值来考虑（即漏诊的病例极少）。

这些工具使研究能够针对严重 AS 患者$^{25,26}$ 之间巨大的治疗差异进行研究，或者探究关于“许多严重 AS 患者未接受治疗”的这一新兴证据$^{3,27,28}$。自动筛查可以允许对主动脉狭窄的自然史进行大规模研究，并可能揭示该疾病患者护理路径中的潜在偏差。无疑，还需要额外的研究来评估能够有效筛查和及时转诊的自动化工具是否能改善 AS 患者的预后。AS 的自动检测还可能支持早期干预的研究，以阻止疾病进展。$^{29}$ 传统上，由于早期 AS 通常没有症状，研究早期疾病一直是一项挑战。如果出现了有效的治疗方法，或者为了实现早期疾病治疗的试验招募，对有限的心声图进行全自动解释可能是有价值的。这里介绍的方法没有使用多普勒图像，因此可能非常适用于床旁超声检查（POCUS）设备。

本文研究的现代网络对心声图领域具有吸引力，因为它们可以从小标记数据集中学习到具有竞争力的模型。这些模型使用了循环帧（cine loops）中的单帧。然而，使用随变化的特征集几乎肯定包含额外信息，但这种增加的信息也必须与处理更复杂数据集所需的计算需求之间进行平衡。该网络旨在具有可扩展性，并且仅需要具有临床价值所需的最少信息。

此外，正如外部验证研究所示，这些网络可以摄完整或部分研究并分配诊断标签。这种灵活性使得这些方法适用于筛查环境中的有限采集数据。研究级诊断是通过使用一种新的视图优先方法实现的，该方法使用视图分类器来识别被认为与目标诊断任务（此处为 A.S.）相关的视图。然后，这些相关视图的诊断分类器预测结果通过加权平均进行优先级排序，以预测一个一致的研究级诊断标签。我们展示了序列视图和诊断任务的验证研究，以强调我们在此使用的分层方法，我们认为这种方法可以应用于自动化其他复杂的影像诊断。

这些研究中使用的数据作为我们 Tufts 医学心声图数据库第 2 版本（TMED-2）的一部分发布（代码可在 https://tmed.cs.tufts.edu/ 获取）。与我们较小的早期版本相比，TMED-2 大幅增加了公开发的研究数量，将分辨率从 64x64 提高到 112x112，并增加了可用的视图类型¹19。该数据库涵盖了多种 AS 病变，并将支持开发用于复杂影像诊断自动筛查的新方法。在数据集规模增加 3 倍的情况下，在外部数据上可能实现的显著准确率提升，说明了向全球研究人员提供标记数据集的紧迫需求。

这项工作存在一些必须承认的局限性。提供的心声图来自单一学术中心，且诊断标签作为常规临床护理的一部分分配的。非白人患者在该队列中代表性不足，尽管基于心声图的 AS 影像诊断不应因种族产生任何生物学差异。本研究未包含结果数据或其他影像学态的信息来确认疾病严重程度。虽然标记的心声图数量有限，但这些网络值得关注的特点是它们可以从小标记集中进行学习。这对于标记昂贵且耗时的未来模型开发至关重要。

虽然更复杂的低流/低梯度亚型可能会被误分类，但我们通过将中度和严重 AS 合并为一个“显著性 AS”类别来降低这种风险，该类别应被转诊以全面的研究和治疗。这是设计初衷，对于未来的筛查试验至关重要。之前仅关注高流/高梯度亚型¹十四的努力将漏掉许多代表低流特征严重疾病病例。随着我们代码和图像的发布，我们鼓励对我们的工作进行额外的外部验证。我们预计随着更高的图像分辨率、更大的神经网络或使用循环帧的所有帧（而非仅第一帧），性能将会提高；我们保持了适中的分辨率（112 x 112 像素）并仅使用一帧是为了在准确性和训练时间之间实现可行的平衡。在现代 GPU 上，我们训练的每个神经网络在最大版本的数据集上都需要几十小时的时间。

## 结论

针对心声图优化的机器学习（ML）方法可以利用有限的 2D 数据成功识别 AS。这些方法为该疾病的全自动筛查和未来的研究奠定了基础。
