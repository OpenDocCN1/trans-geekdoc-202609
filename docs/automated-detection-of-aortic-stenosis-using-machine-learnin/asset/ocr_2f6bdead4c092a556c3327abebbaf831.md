**Table 2: AS Diagnosis Label Cohorts across Train/Test Splits in TMED-2.** We show the number of echocardiogram studies assigned to train/valid/test sets across all 3 possible aortic (AS) severity levels for the fully-labeled dataset of 599 studies. Image counts represent the mean over 3 splits, as the exact number of images per study differs across splits. No split deviates more than 12% from the reported mean here.
