# 亮点

- 主动脉狭窄 (AS) 的自动检测是一种新的诊断方法。
- 机器学习方法通过有限的 2D 图像检测 AS。
- 使用有限数据集实现 AS 全自动筛选是可行的。
- 发布 TTE 数据库将促进协作。
