## 去标识化 (De-identification)

利用 DICOM 存储格式中编码的已知区域位置，开发了专用软件来自动识别包含保护健康信息（PHI）的图像刻字区域。通过从数据拷贝中排除这些成像区域，实现了可靠的图像去标识化。我们对包含的去标识化图像的 10% 样本进行了人工审核，以确认未包含任何 PHI。

## 用于视图和诊断分类的深度神经网络 (Deep Neural Nets for View and Diagnosis)

上述的图像到视图和图像到诊断分类网络，我们的目标是自动分配研究级的 AS 严重程度：一个总结研究中所有图像整体解释的向量。为了实现这一点，我们应用了一种称为优先视图权重的方法（19），我们在早期、较小的数据集上开发。直观动机是，来自显示主动脉瓣图像的诊断预测应该是比视图类型更有力的证据。主要输出是指示诊断的 3 类概率向量（无、早期或显著），辅助输出是指示视图的 5 类概率向量。我们使用多任务训练，损失函数是 3 类诊断交叉熵和所有视图标注图像的5 类视图熵之和。我们发现这种多任务训练带来了更好的诊断性能。多任务训练后，仅使用 3 类诊断输出。每个模型通过随机梯度下降训练，直到其主要任务的验证平衡准确率至少30个 epoch没有提高。所需的 epoch 根据所用方法在150-1000 不等。

## 来自大量图像的单研究诊断 (One Study-Level Diagnosis from Many Images)

上述图像到视图和图像到诊断分类网络，我们的目标是自动分配研究级的 AS 严重程度：一个总结研究中所有图像整体解释的向量。具体而言，我们的优先视图程序通过三个步骤获得研究级的概率预测。首先，使用图像到诊断分类器产生研究中每幅图像的 3 类 AS 概率向量。其次，使用图像到视图分类器预测每幅图像的相关视图（PLAX 或 PSAX）的概率。最后，对第一步的 3 类向量进行加权平均，以第二步的概率作为权重。我们将这种优先视图方法与另一种简单平均法进行比较，后者不通过视图分类器权重地处理所有图像。
