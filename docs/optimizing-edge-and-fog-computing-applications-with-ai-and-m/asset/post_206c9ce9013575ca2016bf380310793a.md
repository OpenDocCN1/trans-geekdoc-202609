## Edge Server-Based Cloudlet Offloading

Edge computing is growing significantly. The need for today's mobile applications to be onboarded needing computation, low latency, high bandwidth, etc., leads to a scenario where fast edge computation is needed, and a general server with high latency cannot cater to the needs of such high demands. Thus, to mitigate this resources are selected. In this study, the proposition of EP-MCPHS allows the use of multi-processing techniques to reduce the workload from unutilized edge servers, enhance resource utilization, reduce latency, and increase bandwidth to cater the service request. This follows when the effective flow rate of the network drops per our experiments in Section 11.4.

The final comparison with the first model showcases the superiority of the modeling architecture of EP-MCPHS over current state-of-the-art techniques for placement of cloudlet in edge servers. The algorithm increases bandwidth from 3.81828 to 6.428571 in comparison to 4.91 for MMFA, and reduces the inherent data transfer.

This study aims to create a dynamic architecture capable of managing the load, reducing latency, increasing bandwidth, and decreasing network flow for cloud offloading into edge server. The future scope of this research can be showcased by the enhancement of DRL mechanisms wherein simulation can be drawn and tested via neural agents. The simulation could allow to reduce latency and resource utilization for the calculation of algorithm fitness like feature selection.
