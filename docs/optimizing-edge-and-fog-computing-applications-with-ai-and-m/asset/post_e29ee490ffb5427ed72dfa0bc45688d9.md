## 10.7 CNNS in Federated Learning

A CNN is a category of ML models, namely a type of deep learning algorithm well suited to analyzing visual data. CNNs – sometimes referred to as convnets – use principles from linear algebra, particularly convolution operations, to extract features and identify patterns within images. CNNs are highly adaptable and continue to evolve as researchers develop more complex architectures for the increasingly complex tasks. Algorithms such as transfer learning allow pre-trained CNNs to be fine-tuned for specific tasks, reducing the amount of data and resources required for training from scratch.

In the context of FL, CNNs can be deployed across multiple clients, allowing each of them to train the CNN locally using its own data. It would be a natural fit for FL applications where visual data from distributed clients, such as medical images or surveillance videos, need to be collaboratively processed without promising victory. Techniques like personalized learning and domain adaptation are used to address problems such as data heterogeneity. Communication from large CNNs is mitigated through gradient compression, pruning, and feathered dropout. Security concerns such as adversarial attacks and data leakage can be countered using secure aggregation, homomorphic encryption, and differential privacy – particularly local DP to secure client-side communication [32].

CNN architectures like Network in Network (NIN), Visual Geometry Group-9 Layer Network (VGG-9), and Extended Modified National Institute of Standards and Technology–Merged (EMMNIST) can be used for classification tasks, implementing adversarial training methods and aggregation to optimize performance and convergence [33]. In addition, image segmentation using 3D U-Net can be used to combine multiple CNN models to improve accuracy and uncertainty estimation. The most accuracy can be recovered for the global model when FedCC is applied against targeted attacks. FedCC also preserved test accuracy nullifying attack confidence against targeted backdoor attacks [22].

Moreover, an application of FL and DP can be explored through privacy-preserving framework [36]. Medical data are sensitive and cannot be easily shared across institutions due to privacy regulations like GDPR and Health Insurance Portability and Act (HIPAA). FL allows collaborative learning by training models locally on distributed datasets without centralization.
