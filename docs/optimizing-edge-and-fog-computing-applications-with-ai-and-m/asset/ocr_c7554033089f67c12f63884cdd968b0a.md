The paper “Deep Reinforcement Learning Algorithms for Low Latency Edge Computing Systems” investigates the use of DRL models—Q-Learning, Double Q-Learning, DQN, and DDQN–improve resource allocation and task scheduling in EC settings, with an emphasis on latency reduction. It solves issues such task scheduling complexity caused by diverse resource needs, high latency from extensive task queues, and the requirement for intelligent decision-making in dynamic, low-latency environments. Using MDP to represent the problem, the study demonstrates the improved performance of DDQN, which separates action selection and assessment to increase stability and decrease Q-value overestimations. Neural networks and approaches such as experience replay are used to improve training and decision-making. While Q-Learning and DQN delivers efficient, resource allocation with lower average latency (0.97–1.03 seconds) throughout simulations. The results show that DDQN can give greater rewards and more consistent outcomes, making it a viable option for intelligent EC systems. However, the paper identifies limits such as scalability and computational complexity of DRL models, recommending the future inclusion of advanced algorithms such as DQN for more improvement. Finally, the article finds that DRL models, particularly DDQN, greatly improve the performance of edge system [25].

The paper “Decentralized Scheduling for Concurrent Tasks in Mobile Edge Computing via Deep Reinforcement Learning” provides a decentralized task scheduling technique for MEC that reduces latency and lost job ratios in dynamic, resource-constrained contexts. The paper tackles issues such as communication costs in centralized techniques, problems with concurrent execution, and heterogeneous edge networks. The proposed technique treats task offloading as a delay-aware optimization problem that is solved using DRL. Techniques such as Double DQN,ing DQN, Prioritizedplay Memory, and Recursive Neural Networks (RNNs) are used to improve flexibility and convergence. The Distributed Optimization and Scheduling Algorithm (DOSA) divides the DRL network into user devices and servers, enabling each device to make offloading decisions with little complexity. Simulation findings show that DOSA greatly decreases task delay and drop tasks when compared to baseline methods (such as greedy, random, and centralized DRL approaches). However, disadvantages include large training costs, difficulty in achieving decentralized environments, and a lack of consideration for real-world complications such as task dependency graphs and varied server caches. The identified needs could expanding the model to handle divisible tasks and using edge caches to improve scheduling performance.
