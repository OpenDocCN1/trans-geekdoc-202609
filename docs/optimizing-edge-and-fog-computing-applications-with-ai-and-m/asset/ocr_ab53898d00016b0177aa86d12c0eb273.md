# Chapter 9
Deep Reinforcement Learning-Based Task Scheduling in Edge Computing

Shristi Sonam, Pratik Gupta, and Saanch Sapra





Edge computing has transformed data processing by shifting computational tasks closer to data sources, reducing latency, minimizing bandwidth usage, and improving real-time responsiveness. However, resource constraints such as limited computational power, storage, and energy at edge nodes introduce significant challenges in task scheduling and resource management. Efficiently distributing tasks while considering dynamic workloads, varying network conditions, and heterogeneous resource availability is crucial for maintaining system performance.
