# Optimizing Edge and Fog Computing Applications with AI



All the tools and technologies selected were chosen to align with the current needs of the cybersecurity world, ensuring that the research's setup would implement the practical cases while maintaining the academic relevance well.

+   Suricata (IDS): This IDS being an open-source and highly customizable system emerges to have prominence to perform a real-time network traffic analysis. It generates detailed logs of the captured network activity which is primary need of the research. It also supports emerging threat rule sets real-detection of not only DDoS and attack patterns but also hundreds of other attacks. Due to all these benefits, especially by its ability to handle the high-volume efficiently its native multi-threading techniques made it a better choice than any other open-source IDS (viz. Snort IDS) [17] (Waleed, Jamali and Masood, 2022).

+   ML models (RF and XGBoost): Both being ensemble learning models have improved classification rate and can reduce overfitting notably. While RF is a robust ML model usually used to handle large datasets, XGBoost provides optimum performance over unbalanced datasets, making both an ideal selection for adaptive detection in real-time environment considering their speed and effectiveness.

+   Node-RED: Being user-friendly with flow-based interface, Node-RED was chosen to simulate the IoT devices because it aids in quick prototyping and visualizing the IoT data flows. It gives a simple platform to create the functions of real devices such as temperature sensors, motion detectors and humidity monitors and also save them to the MQTT broker.

+   MQTT Broker: The primary advantage of MQTT broker is its lightweight protocol that is designed for artificial devices and low-bandwidth high-latency environment; therefore, it was chosen as a hub for communication of IoT. Unlike HTTP-based communication, MQTT offers a better messaging with a lower overhead that makes it suitable for IoT cases where devices are flooded with real-time data.
