## 9.6.1.3 Throughput

**Definition:** Evaluates the number of successfully executed tasks per unit time, indicating system efficiency.

- Formula: Throughput = $\frac{\text{Number of Completed Tasks}}{\text{Total Time taken}}$

- Why It Matters: High throughput ensures that more tasks are processed within a given time frame, which is crucial for real-time applications like video surveillance and industrial automation.

- Example:
  - In an edge-based surveillance system, multiple cameras stream video feeds to edge nodes for real-time motion detection.
  - A traditional round-robin scheduler may assign tasks evenly but overload weaker nodes.
  - A DRL-based scheduler dynamically assigns tasks based on node capabilities, improving throughput by 40%.

## 9.6.1 Task Completion Rate

Definition: Measures the percentage of tasks that are successfully completed before a deadline.

- Formula: Completion Rate = $\frac{\text{Tasks Completed on Time}}{\text{Total Tasks Submitted}} \times 100\%$

- Why Matters: Many applications have strict time constraints, such as predictive maintenance in manufacturing or emergency response in healthcare.

- Example:
