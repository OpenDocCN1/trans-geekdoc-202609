The paper “Deep Reinforcement Learning Based Task Scheduling in Edge Computing Networks” focuses on reducing task scheduling delays in cloud-edge networks, specifically the nondeterministic polynomial time (NP)-hard Task Scheduling for Delay Optimization algorithm, which is based on the Asynchronous Advantage Actor-Critic (CECS-A3C) DRL architecture. This approach dynamically distributes resources and optimizes task offloading decisions, taking into account edge and cloud resource limits. Existing systems that frequently rely on online-synchronous training may utilize experience replay mechanisms, CECS-A3C uses asynchronous with parallel agents, which eliminates the requirement for replay and improves scalability. Tasks are planned using real-time status changes to maximize cumulative rewards on task delay sensitivity. Experimental results reveal CECS-A3C decreases delays by 28.3% and 46.1% when compared to DQN and RL-G algorithms, respectively, while also attaining faster convergence and improved scalability under various tasks. However, its dependence on decentralized decision-making may limit scalability in highly distributed systems, and real-world implementation include unexpected network dynamics and the ability to collect reliable state information. Overall, the proposed framework improves scheduling efficiency, resulting in timely task execution and optimal resource usage in EC networks [23].

The paper “Deep Reinforcement Learning-Based Approach for Online Service Placement and Computation Resource Allocation in Edge Computing” provides an innovative strategy for optimizing service placement and resource allocation in 5G-enabled EC systems, with the goal of minimizing task delay. It handles issues such as dynamic and unexpected task arrivals, limited edge resources, service migration overhead, and the interdependence of placement and resource decisions. The problem is expressed as an MDP with bidirectional continuous action spaces, in which latency components (switching, serving, and offloading) impact the reward function. The proposed PDQN combines two neural networks—one for resource allocation and the other for assessing hybrid action Q-values—employs techniques such as double-network topologies and experience replay to improve stability. Extensive show that the methodology outperforms baseline approaches in lowering latency across a variety of system characteristics, CPU capacity, service diversity, and storage limits.
