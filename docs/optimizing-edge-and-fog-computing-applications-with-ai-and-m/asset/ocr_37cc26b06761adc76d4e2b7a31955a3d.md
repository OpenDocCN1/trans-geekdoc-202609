# 11.3.3 Edge Priority Placement Using Multi-Core and Parallel Heap Structures (EP-MCPHS)

EP-MCHPS combines multi-latent processing to benefit from the degeneracy minimum optimization of the heap function. The algorithm is divided into three segments: Parallel heap creation (PhC), Provisioning, and PhC combination with parallel processing.

# 11.3.3.1 Parallel Heap Creation for Priority-Based Resource Allocation

A priority queue is utilized as a provisioning mechanism for the minimum optimization which implements a minimum heap to allow the least possible resource to be allocated to the cloudlet, ensuring the least wastage of resources. The PhC algorithm uses Equation 11.8. The heap used is a min heap for the edge section based on the cloudlet computational needs.

```
$H_i = Heapify\left(\{\left(h_{\text{CPU,Memory,Disk}}\right)\}_{\ell}, e_i\in ES\right)\quad\forall i\in\{1,2,\dots,n\}.\quad (11.8)
```

Equation 11.8 describes the heap function which is responsible for priority-based distinction of resource allocation. The function notes the minimum required edge server that can successfully offload the cloudlet. This allows the edge servers to be optimized, the resource utilization to be maximized, and the migration flow rate of data to be as low as the edge servers were working at maximum capacity in comparison to the MinMax fairness algorithm. Thus, the priority-based allocation not only reduces latency, and data flow rate, but maximizes resource optimization and bandwidth, but also caters to creating high operational edge server unit that can cater to on-demand service requests based on resource priority task allocation.
