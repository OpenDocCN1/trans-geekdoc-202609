Since software, hardware, and wireless communication technologies have advanced rapidly in recent decades, the number of Internet of Things (IoT) devices has skyrocketed, enabling data analysis and measurement from physical to cyber work [1]. The process of moving processing, data storage, and application software to cloud data centers has already been seen. An application can thus request access to shared processing and storage resources. The cloud computing approach offers a number of benefits, including high scalability, availability, accessibility, and inexpensive deployment costs [2].
