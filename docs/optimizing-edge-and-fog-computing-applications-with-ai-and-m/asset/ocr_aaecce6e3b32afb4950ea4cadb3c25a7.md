In the DDoS attack, it heavily relies on huge volume of traffic with repetitive patterns, as SYN flood attempt, resulting in a lower score from the model. Thus, logs with a score less than 0.3 are tagged as DDoS. To minimise false positive, the logs which lack the distinguished patterns for the attacks are classified as benign. The processed logs which contain the prediction classifications are indexed back to Elasticsearch in a new index pattern as ml-predictions-YYYY.MM.DD* using bulk API operations. The date-based naming system was introduced for a better organisation of logs and predictions. The system continuously processes the available logs in a continuous loop every 5 seconds, and if the system encounters connectivity issues, it gracefully handles it through retry mechanism. Thus, this approach optimised data gain and scalability without real-time prediction efficiency.
