# 11.3.2.2 Placement Algorithm

The EdgeSimPy framework is built with the resource allocation mechanism consisting of multiple units. The placement algorithm is the rudimentary backbone of the resource allocation unit as it is responsible for placing the cloudlets from the respective user requests to the edge servers with the help of the network switches in transit. It is essential in optimizing the performance and resource utilization of the edge servers and orchestration as a whole.
