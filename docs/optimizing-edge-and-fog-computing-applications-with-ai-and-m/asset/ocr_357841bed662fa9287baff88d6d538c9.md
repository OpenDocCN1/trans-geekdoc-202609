Edge computing on the other hand processes and stores the data at the network's edge where the data is generated and consumed. This enables faster decision-making and quicker real-time analysis, reducing the latency. It also leads to lower bandwidth consumption. Edge computing enables devices like gateways, edge servers, IoT sensors and mobile devices. Only the critical data and the data that need more processing like advanced analytics and deep learning models are set to the cloud [4]. The future of edge computing AI-powered edge analytics involving real-time image recognition and predictive analytics. Edge computing as services allows businesses to leverage computing resources without major infrastructure investments. Edge computing integrated with blockchain forms a tamper-proof network and enhances data authentication and integration.
