# 10.5 Algorithmic Impacts

The algorithms through which concepts like FL and DP are implemented play a salient role as they have the potential to impact various model parameters. FL algorithms like SCAFFOLD [11, 12] are specifically designed to handle the challenges of heterogeneity across different devices. These algorithms improve the stability and efficiency of model training by employing techniques like “control variates” to reduce discrepancies, or “drift”, which can arise from variations in local datasets. Furthermore, such as FedAvg with DP introduce random noise to model updates to protect user privacy [13]. DP-SCAFFOLD [14] is an extension of the SCAFFOLD framework by integrating DP mechanisms to local model updates while addressing data heterogeneity. Its convergence analysis utilized a particular initialization of the algorithm and focused on different quantities compared to the original proof. This algorithm operates like standard FL approaches like FedAvg. Overall, it has demonstrated a better performance both theoretically and empirically, outperforming the baseline DP-FedAvg in various scenarios.
