The proposed work consists of three parts: IoT edge network, fog networks and cloud networks integrated with the blockchain services. The case study discusses the use of smart building construction that involves various contractors and sub-contractors. The builder further allocates various tasks of the contractors. The main requirement of the use case is that it requires low latency services, trusted data sharing, optimized scalability, secure process monitoring, secure offloading and authenticated access control.

The various elements used here are different types of IoT nodes available at the local device level. Next, there are IoT clusters who include sub-contractors who provide services according to the agreement. The edge nodes have a greater number of resources when compared to other nodes of the network. The system uses a lightweight blockchain model for data sharing. The fog nodes have more capability for processing data when to to other nodes. It use of centralized cloud for storage. Figure 4.3 shows the architecture of the system.

Another system uses Hyperledger fabric to track the hash of medical data. These values are calculated using the SHA256 algorithm to define the authentication of data. Hyperledger fabric is based on blockchain systems which open-source and use plug play components. This Hyperledger fabric along consensus upholds the data in protection mode. It also supports peer-to-peer network and maintains a common ledger to record transactions.

The architecture comprises three layers: smart contracts, consensus and a distributed ledger. The fog layer acts as a connecting layer between the end user and cloud layer and supports distributed computing to link peripheral nodes to the cloud. The fog layer processes the data at the data sourcing nodes to reduce the architecture of the system. It is also connected with the Hyperledger fabric. Figure 4.4 shows the architecture of the system. The hash value is computed in the cloud and compared with the values of the ledger.

The flow of the system is as follows: first, the fog collects the data from the IoT devices. Next, the hash value is computed at the fog and compared with the Hyperledger along with the original data is transmitted to the cloud. Next, the cloud computes the hash value of the data and compares with the value of Hyperledger. If both values match, then no tampering of data has occurred.

The model exhibits a storage overhead involving additional costs because of generation of private keys.
