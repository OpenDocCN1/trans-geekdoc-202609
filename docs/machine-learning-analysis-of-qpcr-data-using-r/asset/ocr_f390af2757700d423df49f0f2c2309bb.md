The SVM model is carried out with the function ksvm by passing the outcome field as a function of both MR and FCN (Figure 3.6). The procedure will be run for classification purposes (type = C-svc) — although it could be used also for regression and novelty detection — the kernel trick will be the Gaussian algorithm (kernel = “rbfdot”) with parameters automatically set for it (kpar = “automatic”), the cost of constraints violation (C) is set to 1, and the modeling will calculate class probabilities. It is also possible to plot the resulting model with the function plot.

```
Listing 3.8
library(kernlab)
mod = ksvm(outcome ~ MR+FCN, data = train_set,
    type = "C-svc", kernel = "rbfdot", kpar = "automatic", C = 1, prob.model = TRUE)
    plot(mod, data = train_set)
pred_prob = predict(mod, test_set, type = "probabilities")
prediction = predict(mod, test_set)
serial = test_set$Index
rating= test_set$Outcome
OUT = data.frame(serial, rating, prediction, stringsAsFactors = FALSE)
```

The model is applied classify the test set’s reactions. Specifically, a data frame is created containing the serial numbers of the testing reactions with their assigned label (‘rating’) and their predicted values (‘prediction’). The parameters of the assignment are saved into specific vectors.
