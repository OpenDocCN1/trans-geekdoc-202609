# Listing 3.4.

Real-life data are loaded from a tab-delimited files. The files are saved on the author's ResearchGate site (https://www.researchgate.net/publication/360568958_SIV_overall and https://www.researchgate.net/publication/360568853_SIV_results). Once downloaded on a local directory, files can be loaded into the R environment using `read.table`. This function takes a pointer to the file in the form of a complete path to the local directory (absolute). Otherwise, unless the local directory where the files have been downloaded in R's default directory, it is possible to set the working directory using `setwd` and access the files from there avoiding to write the whole path (relative) path. In the listing, not knowing the local directory, the current directory has been determined with the function `getwd` and passed as an argument to `setwd`. This procedure, essentially, simplifies R’s default directory as the working directory. In real life, the user can set the preferred directory and avoid writing down the all path to the downloaded files. Alternatively, `read.table` takes a complete URL. Moreover, `read.table` is a generic function where the different parameters are as generic as possible. Other related function such as `read.csv` and `read.delim` are specifically designed to read comma separated values (csv) and tab separated values (tsv) by setting the argument `sep` to comma (",") and tabulator ("\t"), respectively. The file `SIV_overall.tsv` file contains the amplification data obtained from the thermal-cycler whereas `SIV_results.tsv` contains the quantitative cycles of all reactions. Each reaction is identified by a unique index. The `SIV_overall.tsv` files is loaded into the object *amplification* and `SIV_results.tsv` files is loaded into the object *validation*.

```
Determining the current (more properly: working) folder where R reads and writes file
is given by the function `getwd`, which does not require an argument. It is possible to
set the current folder with `setwd`.

`getwd()`
    x
        the path to a folder

`read.table(file, header, sep, quote, dec, row.names, col.names, na.strings, skip,
fill, strip.white, blank.lines.skip, comment.char, encoding, skipNul,
stringsAsFactors)`
    file
        name of the data file. If it does not contain an absolute path, the file name is
        relative to the current working directory. The file can also be a complete URL.

    header
        logical indicating whether the file contains the names of the variables as its
        first line.
    sep
        field separator character (default = "").
    quote
        quoting character (default = "\"").
    dec
        character used for decimal points (default = ",").
    row.names, col.names
        vector of row or column names.
    na.strings
        vector of strings to be interpreted as NA values.
    skip
        number of lines of the data file to skip before beginning to read data.
    fill
        if TRUE, blank fields are implicitly added.
    strip.white
        logical to determine whether leading and trailing white space from unquoted
        character fields should be removed.
    blank.lines.skip
        if TRUE, blank lines are ignored.
    comment.char
        comment character (default = "#"). details see scan.
    encoding
        type of text encoding (default = UTF-8).
    skipNul
        logical to determine whether NULL values should be skipped.
    stringsAsFactors
        logical to determine whether strings should be converted to factors.
```
