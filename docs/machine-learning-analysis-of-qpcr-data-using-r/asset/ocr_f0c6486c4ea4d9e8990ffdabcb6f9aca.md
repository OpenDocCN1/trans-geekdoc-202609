The maxRatio transform is obviously one element shorter than the original signal:

```
length(amp)
> [1] 45

length(amp_maxRatio)
> [1] 44
```

Figure 2.5A shows that maxRatio produces two values, defined by the peak of the obtained curve, for each reaction instead of the single one generated by either the fit-point or second derivative methods. The first value is the maximum of the ratio series (MR); the second value is the intersect of MR over the abscissa, that is the fractional cycling number (FCN) where MR occurs:

```
> max(amp_maxRatio)
[1] 0.1092542

> which(amp_maxRatio == max(amp_maxRatio))
[1] 29
```
