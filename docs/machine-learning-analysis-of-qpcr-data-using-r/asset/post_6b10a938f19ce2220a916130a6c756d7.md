It is now possible to determine the initial load of the two real-life reactions using the standard curve. The problem is that the profile of the actual reactions does not overlap completely with the logistic function defined to simulate the PCR. Consequently, it is not possible to apply the function find_cycle as shown in the previous chapter. However, a little trial and error allows to estimate the cycle at which these reactions had reached a certain level of fluorescence. The definition of such a level is central in qPCR because it is functional in the assessment of the qPCR. Despite its importance, there are no set rules to define this level, which is known as cut-off or threshold level. It is accepted to set it just above the background signal, but that is all. In this example, a level of 1000 fluorescence units (FU) has been chosen as threshold. The quantification is done as follows. From Equation 2 it can be seen the quantification described so far relies on the assumption that the efficiency of amplification is the same for all reactions. However, in real-life, organic molecules present in the biological sample might affect the DNA polymerase reducing the PCR efficiency.
