The package openPrimeR is part of Bioconductor, a development software project for genomic data analysis that is linked but independent from the R core development group. Thus, it is not available from the R repository and the install.package function will return an error. Bioconductor's packages can be installed with the function install of the package BiocManager - which is shortened in the form BiocManager::install(package) - that is available from the R repository. The sequence is:
install.packages("BiocManager")
library("BiocManager")
BiocManager::install("openPrimeR")
However, openPrimeR needs a series of libraries for the operative system itself, hence the user will need to personalize the installation according to the system at hand. More information on the installation of openPrimeR can be found at https://www.bioconductor.org/packages/release/bioc/html/openPrimeR.html. Once the installation has been successfully completed, openPrimeR can be opened as any other R library. The R function system/file finds the full file names of files in packages, in this case openPrimeR.
system.file("file", package = "openPrimeR", lib.loc, mustWork)
file
the file to be searched. More than one file can be passed.
package
the package containing the file. "base" is used for R native files.
lib.loc
the path where to look for the files; the default is NULL.
mustWork
logical, returns an error if the file is not found.
design_primers(template.df, mode.directionality, settings, init.algo, opti.algo, required.cvg, timeout, max.degen, conservation, sample.name, cur.results.loc, primer.df, updateProgress)
template.df
object containing the template sequences with annotated primer.
mode.directionality
template strand for which primers shall be designed, forward strands ("fw"), reverse strands ("rev"), or for both ("both").
primer.length
numeric providing the target length of the designed primers.
primer.estimate
number of required primers shall be estimated (default=FALSE).
required.cvg
desired ratio of of covered template sequences (default=1).
sample
character vector providing an identifier for the templates.
primer.lengths
numeric vector of length 2 providing the minimal and maximal allowed lengths for generated primers.
allowed.region.definition
character vector providing the definition of region where primers are to be constructed, "within" (default) if the primers lie within the allowed binding region, "any", otherwise.
init.algo
algorithm to be used for initializing primers, either "naive" (default) or "free".
max.degen
maximal degeneracy of primer candidates (default = 16).
conservation
rate of conservation (default = 1).
updateProgress
verbose option (default = NULL).
settings
object specifying the constraint settings for designing primers.
opti.algo
algorithm to be used for solving the primer set covering problem, either "Greedy" (default) or "ILP".
timeout
seconds before timeout for the "ILP" option (default = Inf).
sample.name
identifier for the primer design task (default = NULL).
cur.results.loc
directory for storing the results.
