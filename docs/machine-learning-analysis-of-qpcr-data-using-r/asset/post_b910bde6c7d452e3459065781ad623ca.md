
The elements of a vector can be accessed by their index, which starts from 1. For instance, supposing a vector a of 10 elements (a<-1:10), the 5th element is accessed by a[5]. Multiple elements can be selected using a colon. For instance, the elements 5, 6, and 7 are selected with a[5:7]. Alternatively, the combine operator can be used: a[c(5,6,7)]. The minus operator '-' deselects the element. Thus, ignoring the 5th element is given by a[-5]. Mathematical operators allow to select the vector's elements based on a logical statement. For instance, assuming that a's elements are numeric, it is possible to select the elements below a given number n: a[a<n]. The vector's elements can be named with the function names and then accessed by name. For instance, the built-in vector letters stores the 26 lower-case letters of the Roman alphabet (and LETTERS their capitalized version); thus: names(a) <- letters[1:10] and the 5th element is selected by a['e']. A named vector can be reverted to one without names with the function unname(a).

Like a vector, the elements of the list can have no name, whereas a named list is defined by assigning a value to a named level, for instance l = list(a="string", b=0, c=TRUE). The level of a list can be accessed using its index, for instance l[1], or - if present - its name, as in l$a. The actual values, without the name or index of the level, are accessed by double square brackets, for instance l[1][1]. As mentioned, each level can have more values, as in l = list(a=c(a="A", b=0, c=TRUE), b=c(a="B", b=1, c=FALSE, d=NULL, e=(NA)). The actual values of a level are accessed adding the wanted index, as in l[1][1][1], which gives "A". If the level contains a matrix, the selection of the element follows the [row, column] convention.

The listing simulates the reduction in copy number amplification observed in actual PCR. A given amount of initial template stored in the variable I is duplicated at a rate defined by the variable D (in this case the duplication is considered perfect) and with a carrying capacity defined by K. The copy numbers are stored in the vector ROI whose initial value is set by I. The for loop simulates 44 rounds of amplification and accesses the copy numbers at cycle i-1, duplicates it according to D and reduces the amount according to K. The resulting value is stored in the element i. The vector ROI is then printed on screen and plotted.

In the listing continuation, actual amplification data are stored in the vectors L(low input) and H (high input) and the first 45 values are stored in the vectors low and high. The for loop is generalized into the function emitter, which returns a vector of values normalized by the light emission, and applied to the initial copy number from the previous listing A4_0. The returned amplification vector is visually compared to low and high.
