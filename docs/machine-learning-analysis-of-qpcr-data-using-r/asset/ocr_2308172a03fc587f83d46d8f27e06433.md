Figure 2.6. Impact of threshold on the determination of the quantitative cycle. The signal threshold has different impacts on the fit-point and maxRatio methods. A. The MR threshold (solid line) in maxRatio separates non-reactive (negative, ○) from reactive (positive, ●) samples. The FCN is unaffected by doubling the threshold value (dashed line). The FCN of the positive sample with the lowest FCN, for example, remains the same (dotted line). B. The fluorescence threshold (solid line) determines the Cq (dotted line) directly by calculating the fractional cycle at which this line meets the amplification plot. The intersection point happens at a later cycle when the threshold value (dashed line) is doubled. Since the Cq is associated with the initial copy number of the sample, the quantification is altered. The arrows make it easier to grasp the process.
