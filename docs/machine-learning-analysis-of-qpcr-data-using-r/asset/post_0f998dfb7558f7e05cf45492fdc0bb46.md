
## Listing 2.4.

An array of 100 random hypothetical PCR efficiencies ranging between 99% and 110% is stored in the variable e and built with the function runif. The variable index stores the e's indices. Two random e's elements are changed to values outside the assigned range. The mean and standard deviation of e are computed and stored in the variables m and s, respectively. A plot is built upon the data and lines corresponding to one (m±s) or two (m±2s) standard deviations from the mean are depicted.

## Listing 2.5.

A data frame containing concentrations and the positivity rate (that is: the percentage of samples that returned a reactive reaction) is set and a regression model is built using a logit model. The regression model stored in model, allows to get a y-value (percentage of success) given an x-value (concentration). Since the operation needed is the opposite (determine the concentration given a percentage of success of 95%), an inverse logit function is obtained using the dose.p function of the package MASS. To increase the shape of the curve, more data points are stored in the data frame newdata, using the seq function, linearly distributed between a maximum and minimum provided by the data frame's range of concentrations. The y-values of the new data points are generated by regression using the predict function. The results are plotted.

## Listing 2.6.

The maxRatio function excludes the first cycle from the amplification vector passed to it as the argument A. A corresponds to the amplification at the cycle n, stored in the vector n. The amplification at the cycle n-1 is obtained by excluding the last element of the vector A, stored in the vector n_minusOne. The ratio, diminished by one, between these vectors is stored in the object R. Since the computation is on vectors, the operation is done element by element on n and n_minusOne, returning a vector. When the vectors undergoing the operation are not of the same length, the shortest vector is recycled. That is: having the vectors x <- c(2, 3) and y <- c(8, 9, 10, 12), the vector w <- y/x will contain [4, 3, 5, 4]. In other words, x has been recycled in the operation to obtain 8/2, 9/3, 10/2 and 12/3.

The function maxRatio is called on a vector amp containing real-life fluorescence data. The results are plotted.

## Listing 2.7.

The mrPlotter function re-implements the maxRatio function described in listing 2.6 in a more compact fashion. The exclusion of the first cycle is obtained using the function tail; the resulting series is stored in ratiox. The first and last cycle of ratiox are stored in MINx and MAXx, respectively. MINx will, therefore, store the value 2 and MAXx will store 45. This approach allows to apply mrPlotter to qPCR data with any cycling range. To increase the resolution of the plotting, a sequence of values between MINx and MAXx is generated with distances between values of 0.01 cycles instead of 1 cycles and stored in Xint.

The background_compensation variable is an optional parameter required to remove a chosen amount from the fluorescence data. For instance, it is possible to compensate the high value by decreasing the fluorescence at one cycle by a moving average of fluorescence based on five cycles and the constant value given by background_compensation. This trick can reduce the bias introduced by reactions with high background, but it is optional. Since in this listing this option is not used, background_compensation is set to zero and the smoothing of the data is skipped altogether.

The fluorescence vectors of the cycle n and n-1 are stored in the objects x and w and their ratio diminished by one is stored in the vector r. The ratio itself is smoothed by using a moving average based on five points. The values of the moving average are stored in the vector rf, but the first element of the vector (rf[1]) is set as non-filtered by assigning it the corresponding value r (rf[1]). Similarly, the last cycle is also left unfiltered (rf[MAXx-1] <- r[MAXx-1]). The second element of rf is set to the mean of the first two cycles while the second to last is set to the mean of the last two cycles. Essentially, rf stores the smoothed y values of the amplification. There are now 4301 x values instead of the original 45. The interpolation between the x values stored in ratiox and the y values stored in rf allows to draw a plot with a smooth line.

The mrPlotter function returns the x values (cycles) or the y values (fluorescence) of the computation using the parameter give. By calling mrPlotter once with give="cycle" (x) and once with give="fluo" (y) it is possible to draw the maxRatio transform of the amplification.

The function mrCalc is implemented in the same way as mrPlotter but calculates the MR by selecting the maximum of the smoothed y values stored in rint. The corresponding x value is found by selecting the index of the element of the x series (Xint) that matches the maximum element of rint. The selected x value provides FCN. FCNA is also calculated. The trio of MR, FCN, and FCNA is exported as a vector. A plot is drawn on the amplification data provided in listing 2.6, storing the x values and y values in cycles and fluorescence, respectively. First, the actual amplification is drawn and then the maxRatio transform is superimposed. The FCN is highlighted by adding a vertical line in correspondence of MR.

## Listing 2.8.

A population of negative (non-reactive) samples is instantiated by randomly generating 10 values in the range 0-0.99 (for the MR parameter) and 5-25 (for the FCN parameter). The positive (reactive) samples will range 0.2-0.5 and 15-35, respectively. The points are plotted and separated by a line representing the MR cut-off for the two populations. A shift in this cut-off will not alter the clustering of the data. The second panel of the plot draws instead an amplification profile of a reaction. The solid line depicts a threshold level that intersects the curve at a given x value. Shifting the threshold (TH) causes a shift in the intersecting x value altering the results. The initial cut-offs are depicted by solid lines; shifting is represented by arrows; the resulting cut-offs are indicated by dashed lines. X-values are depicted by dotted lines.
