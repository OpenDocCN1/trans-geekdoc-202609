A visual inspection of the data (Figure 3.2A) shows that there was a difference in sample distribution at FCN = 10. This split is obviously due to how the data for this example were created in the first place, but real data sets have similar discontinuities (Marongiu et al., 2016a; Marongiu et al., 2021a) — and the data was designed to include this breakup. The FCN = 10 can be used to further stratify the reactions: samples below this values will have one MR threshold, whereas the EM-derived threshold will be applied to those above this value.
