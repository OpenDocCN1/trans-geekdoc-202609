B. The simulation using parameters obtained by regression is more laborious but more accurate than the PCR function. The qpcR package provides an accurate alternative. In panel A, the number of molecules is plotted against the amplification cycle. In real life, though, the number of molecules cannot be counted but only assayed. In panel B, light is used as a proxy to the number of molecules assuming that light is proportional to the number of targets.

It can be seen in the inset of Figure 1.2 that Equation 1 models a never-ending amplification. In reality, the reaction will eventually stall. Liu et al. stated, therefore, that their model was valid only for the initial phases of the PCR. As mentioned in the preceding paragraphs, about 1 µM of primers corresponds to about 10^13 oligonucleotides, hence only 10^13 amplicons can be generated; after that, the reaction simply won’t go any further. The same applies for the triphosphate-nucleotides. In addition, the DNA-pol will become inhibited by the byproducts of the amplification, hence it will amplify with less and less efficiency at each cycle. To cut a long story short, the EF at the end of the PCR will show samples with the same quantity of amplicons. This type of PCR is known as ‘end-point PCR’.

```r

  ROI[i] <- ROI[i-1] * D * (1 - ROI[i-1]/K)

```

In this script, D represents the rate of amplification of the ROI, which is two because of the duplication characteristics of the PCR. K represents the maximum amount of amplicons that can be produced, using the number of primers as limiting reagent. The logistic term acts as follows. When the number of amplicons is much lower than K, the ratio of ROI_t over K is about zero, thus the number of ROI_{t+1} is about twice ROI_t. However, when the number of amplicons approaches K, the ratio is one and the whole term becomes zero. The result is that the reaction slows at each amplification cycle.

This logistic simplification is not the most exact representation of the PCR amplification curve. This can be demonstrated by comparing the curves obtained by this simulation with actual amplification profiles. To prove the point, real amplification data from two reactions obtained from an HIV assay will be used (Marongiu et al., 2021a). Since these PCR assays were run for 50 cycles, only the first 45 data points will be collected. To compare them with the simulated data, the latter must be reshaped to provide an output in light units rather than copy numbers as such. The PCR function described in the previous chapter will be modified to take into account that the output is in light units and not in target’s copies. Since the actual reactions ran for 50 cycles, only the first 45 will be used.

Figure 1.2A clearly shows that the profiles are different. A more realistic description than the logistic equation is to use a model with four parameters (Rutledge, 2004):

F_C = F_M / (1 + e^{-(C - C_h)/s}) + F_B   (2)

where F_C is the fluorescence at a cycle C, F_M is the maximum fluorescence, C_h is the cycle when half of F_M is reached, F_B is the background fluorescence, and s is the slope of the curve. None of these parameters are known beforehand, so the process relies heavily on parametric estimation. The first step in the procedure is to provide some starting values. Considering F_M as the maximum of the amplification series, ½F_M could be used to visually identify C_h, while F_B was set as the fluorescence of the first cycle because it had the highest background value of the entire series. Desmos (https://www.desmos.com/calculator) was used to estimate s by passing the data and the equation (note that Desmos also provides all the other parameters automatically). The second step in parametrization is to pass the equation and a function that subtracts the value obtained by such equation with the actual value. The function nls.lm can extract the parameters directly; these are then stored in objects to model the data.
