It is now possible to determine the initial load of the two real-life reactions using the standard curve. The problem is that the profile of the actual reactions does not overlap completely with the logistic function defined to simulate the PCR. Consequently, it is not possible to apply the function find_cycle as shown in the previous chapter. However, a little of trial and error allows to estimate the cycle at which these reactions had reach a certain level of fluorescence. The definition of such a level is central in qPCR because it functional in the assessment of the qPCR. Despite its importance, there are not set rules to define this level, which is known as cut-off or threshold level. It is accepted to set it just above the background signal, but that is all.
