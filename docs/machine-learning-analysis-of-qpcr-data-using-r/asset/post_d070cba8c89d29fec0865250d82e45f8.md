
The package openPrimeR is part of Bioconductor, a development software project for genomic data analysis that is linked but independent from the R core development group. Thus, it is not available from the R repository and the install.packages function will return an error. Bioconductor's packages can be installed with the function install of the package BiocManager - which is shortened in the form BiocManager::install(package) - that is available from the R repository. The sequence is:
install.packages("BiocManager")
library("BiocManager")
BiocManager::install("openPrimeR")
However, openPrimeR needs a series of libraries for the operating system itself, hence the user will need to personalize the installation according to the system at hand. More information on the installation of openPrimeR can be found at https://www.bioconductor.org/packages/release/bioc/html/openPrimeR.html. Once the installation has been successfully completed, openPrimeR can be opened as any other R library. ## Listing 2.2.

A hypothetical standard curve is built by generating, using the user-defined function PCR, a series of signals with a tenfold higher amount of initial target; the amplification is stored in the A1-A6 objects. The crossing-over point is obtained by using the custom-defined function find_cycle (listing 2.1) by providing the amplification signal (the A1-A6 objects), the x-axis series (1 to 45 cycles) and the estimated cycle where the exponential phase of amplification is starting. Such a starting point can roughly be determined by looking at the amplification graph plotting the amplification cycle against the logarithm of the fluorescence signal: the exponential phase is linear. A data frame is then built upon the obtained values. A plot is then drawn showing the crossing-over (Cq) points. The colors of the points are user-provided shades of gray. It is possible to use the library RcolorBrewer to obtain automatically a series of colors to avoid the manual selection of shades and maximize the visual separation between elements. The colors sets are known as palettes and are selected by the function brewer.pal. The palette can be assigned to an object and the colors are assigned using the col argument of the plot function.

Among the additional elements that can be controlled in a plot are the axis. The function axis defines where and what to place the axis's legends and their corresponding tick marks, and in what orientation. The function brewer.pal selects predefined color shades to maximize the visualization of the data. The function unique returns the unique elements of a vector.

## Listing 2.3.

The cycles above the chosen cut-off of 1000 light units are retrieved from the fluorescence signal of the high-input sample; the first value of the series is saved in the variable crossOverH. A blow-up of the amplification profile of this sample is plotted together with the cut-off line. The amplification points before and after the cut-off line are also plotted, corresponding to crossOverH and crossOverH – 1. The Cq is visually determined on the intersection between the amplification curve and the cut-off line, and the value stored in the variable cq_high. The procedure is repeated for the low-input sample. In the continuation of the listing, the copy numbers are calculated and the standard curve is plotted alongside the two samples. Arrows are used to show the interpolation that allows the quantification of the unknown samples.

The function which determines which elements of a vector fulfill a specified condition.
For instance, given the vector x <- c(-2, -1, 0, 1, 2), which(x > 0) returns the index of the x's elements fulfilling the condition. These indices can be applied to directly select the elements of x that fulfill the condition by using indexing: x[which(x > 0)] will return [1, 2].
