# Listing 3.2.

Since real-life data from qPCR display high fluorescence at low amplification cycles, ten elements are added to the simulation from the previous listing. All the generated data in this and the previous listing are stored in the data frame df, which is then plotted coloring the data according to their groups (positive, negative, uncertain).

The threshold to separate the reactive and non-reactive reactions is obtained by using the model object generated by normalmixEM (listing 3.1). Specifically, the standard deviation from the mean MR value of the second population (the non-reactive) is used as a threshold (model$sigma[2]). The samples with high fluorescence at low amplification cycles will be above such threshold, thus, a second threshold is set-up by considering that visual inspection or data exploration indicated that these samples have an FCN below 10. The thresholds are depicted on he plot with the segments functions.

It is possible to write single line function (known in other programming languages as lambda or anonymous functions) that implements a simple if... else statement. The value returned from the one liner function can be stored into an object with the following syntax:
variable <- function(parameters) (return (if(parameters)))
variable <- ifelse(condition, value_if_true, value_if_false)
In the first case, a computation based on the values present in parameters is returned. For instance, f(x) = a * b+c, when x = [a, b, c]. In the second case, variable takes either value if true or value if false according to the result of the condition clause. For instance, a <- ifelse(x>0, "positive", "negative") applied to x <- c(-2, -1, 0, 1, 2) will return a = ["negative" "negative" "negative" "positive" "positive"].
