The FCNA corrects for such a shift by combining FCN with the emission ratio:

FCNA = FCN − log₂(MR). (2.8)

maxRatio is implemented on the idea that all the amplification response values are positive. In practice, the probe’s signal is never completely quenched, and there should always be a positive background fluorescence signal. As a result, it is critical to work with raw or normalized, but not base-lined, responses. This is advantageous for maxRatio because the base-lining process is prone to errors. When working with responses that have very low background fluorescence or that have been base-lined, a reaction shift can be used to avoid potential division by zero. This shifting, however, limits maxRatio’s self-normalization property. An MR threshold can be set to distinguish reactive from non-reactive reactions. This threshold is commonly generated during the qPCR assay’s setup step by multiplying the MR standard deviation of non-reactive responses (negative samples) by a predetermined number (typically 5 or 10). This threshold, once established, can be maintained throughout the analysis. Changing the MR threshold, unlike the fit-point threshold, has no effect on the related quantitative cycle.
