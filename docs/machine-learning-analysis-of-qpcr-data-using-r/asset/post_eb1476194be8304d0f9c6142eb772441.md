## Listing 3.8

An SVM model is built on the training data frame (train_set) using the column "outcome" as a z value and the combination of FCN and MR as x and y values, respectively. The model will, therefore, maximize the separation of clusters of data with the same z value based on x and y. The model is generated with the function ksvm of the package kernlab and it is stored in the object mod and applied to the testing data frame (test_set). The prediction of z (the label of reactivity) is based on the provided x (FCN) and y (MR) values using the predict function. The vector pred_prob contains the probability of the classification; prediction contains the actual label. A new data frame (OUT) is built using the index of the testing data frame and prediction.

## Listing 3.10

Once the kernel and costs for the SVM model have been selected (listing 3.9), the procedure is run on a set of five sets. To better visualize the hyperplane, the number of points to be analyzed by the SVM model is increased using the function *make.grid*. This takes a vector of x values (parameter x) and applies the function range to generate a sequence of values.

The list *plot_list* is instantiated to contain the hyperplane from each iteration. The implementation is the same as shown in before listings (listings 3.8–3.9), but in this case the function *make.grid* is called to generate the matrix *xmat* that will contain 1000 × 1000 data points ranging from the minimum and maximum MR and FCN values. The matrix xmat is converted into a data frame (*xgrid*) and names (“MR” and “FCN”) are assigned to its columns. The SVM model is applied to *xgrid* to generate the vector of predicted labels (*z_values*) and a combination data frame is generated by combining *xgrid* and *ygrid* (*xyz_dat*). The contour of the areas of equal label is obtained with the function *contourplot*, which is saved as an element of the *plot_list* object.

The plot of the classification is stored in the object P, but the operator ‘+’ provided by the package *latticeExtra* allows to add the hyperplanes in the form of graphical objects stored in *plot_list*. Each element of *plot_list* is superimposed individually to P with the *lattice*’s function *as.layer*. The resulting plot is drawn and the characteristics of the analysis are computed.

To better understand the concept of SVM classification, the area delimited by a hyperplane is drawn rather than the hyperplane itself. An element from the xyz_dat data frame is drawn shading the area according to the reaction’s labels.
