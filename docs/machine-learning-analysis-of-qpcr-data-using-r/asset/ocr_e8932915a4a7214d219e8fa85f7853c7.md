# Listing 3.6.

The amplification data cleaned from entries missing data, stored in the file amplificationCleand.tsv in listing 3.5, is re-loaded into the R environment. The function callingShots allows the operator to visually inspect the amplification plot of a given reaction, input a coded label to it as either positive (1), negative (0), or uncertain (-1) and then move to the next sample. The implementation of the function is as follows. It is possible to choose the reaction number from where to start; thus, allowing the operator to screen the data in multiple sessions. The number of reactions from where to start is obtained from the terminal as direct input with the readline function and stored in the variable set_start. If set_start is empty, it is assumed that the operator wants to begin anew and the variable Start is set to one, otherwise Start takes the value stored in set_start. The vector that will contain the labels provided by the operator (shot_calling) is instantiated and the variable stopper will allow the operator to stop the function at will. The variables k and M are counters, with the latter being set to the number of reactions known to be present in the data set (120).
