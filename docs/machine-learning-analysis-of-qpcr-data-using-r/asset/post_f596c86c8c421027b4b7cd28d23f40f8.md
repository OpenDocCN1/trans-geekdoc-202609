amp = read.delim("validationCleaned.tsv")
callingShots = function(data) {
    set_start = readline(prompt="Enter starting run:")
    Start = ifelse(set_start == "", 1, set_start )
    shot_calling = vector()
    stopper = FALSE
    k=0
    M = nrow(data)
    for (i in Start:max(unique(data$Run))) {
        plate = data[data$Run == i,]
        for (j in unique(plate$Index)) {
            if(stopper == TRUE) {
                break
            } else {
                k = k+1
                well = plate[plate$Index == j,]
                plot(well$FAM ~ well$Cycle, type = "l", lwd=2, col="blue",
                    ylim=c(0,6000),
                    xlab="Cycle", ylab="Fluorescence",
                    main=paste("Run ", i, ", well ", j, sep = ""))
                abline(v=35, lwd=2)
                grid(nx = 20, ny = NULL, lty = 1, col = "gray", lwd = 1)
                PROMPT = paste("Classification? (", k, "/", M, ") [0|1, to exit] ",
                    sep = "")
                shot = readline(prompt=PROMPT)
                if(shot == "") {
                    print(toupper("Stopping classification"))
                    stopper = TRUE
                    break
                } else {
                    shot_calling = append(shot_calling, as.numeric(shot))
                }
            }
        }
    }
}
return(shot_calling)
}

The second step in the analysis is the implementation of a k-fold cross-classification (Ounpraseuth et al., 2012). In this approach, the whole data set is split into training and testing sets but only unanimous samples will be retained. The machine learning algorithm will use the samples’ labels of the former set to the hyperplane and then allocate the samples of the latter set. The procedure is repeated k times, and the mean values are used to generate an accurate classification procedure. The raw amplification data is split into a training set containing 80% of the samples in the following listing. The sampling procedure involves sampling the samples’ index to generate a vector (train_id) that will be used to select the samples in the SVM procedure; the samples not present in this vector are stored in another vector (test_id) that will define the testing reactions. The vectors are stored as R objects into a specific directory (data) to tidy the workspace.

Figure 3.6. SVM classification plot. Classification plot generated by the package kernlab. The shading indicates the strength of association with one class (circles) or the other (triangles). The black icons indicate the support vectors of the model.

The SVM model is carried out with the function ksvm by passing the outcome field as a function of both MR and FCN (Figure 3.6). The procedure will be run for classification purposes (type = C-svc) — although it could be used also for regression and novelty detection — the kernel trick will be the Gaussian algorithm (kernel = “rbfdot”) with parameters automatically set for it (kpar = “automatic”), the cost of constraints violation (C) is set to 1, and the modeling will calculate class probabilities. It is also possible to plot the resulting model with the function plot.

### Listing 3.8
