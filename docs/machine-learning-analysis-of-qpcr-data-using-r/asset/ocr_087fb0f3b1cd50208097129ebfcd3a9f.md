# Listing 1.3

The listing simulates the reduction in copy number amplification observed in actual PCR. A given amount of initial template stored in the variable I is duplicated at a rate defined by the variable D (in this case the duplication is considered perfect) and with a carrying capacity define by K. The copy numbers are stored in the vector ROI whose initial value is set by I. The for loop simulates 44 rounds of amplification and accesses the copy numbers at cycle i-1, duplicates it according to D and reduces the amount according to K. The resulting value is store in the element i. The vector ROI is then printed on screen and plotted.

In the listing continuation, actual amplification data are stored in the vectors L(low input) and H (high input) and the first 45 values are stored in the vectors low and high. The for loop is generalized into the function emitter, which returns a vector of values normalized by the light emission, and applied to the initial copy number from the previous listing A4_0. The returned amplification vector is visually compared to low and high.
