```
e <- runif(100, 0.990, 1.10)
index <- 1:length(e)
e[round(runif(1, 1, 100),0)] <- 0.880
e[round(runif(1, 1, 100),0)] <- 1.150
m <- mean(e)
s <- sd(e)
plot(e~index, ylim=c(0.8, 1.2), xlab=expression(bold("Reaction")), ylab=expression(bold("Efficiency")))
abline (h=m)
abline (h=m+s, lty = 2)
abline (h=m-s, lty = 2)
abline (h=m+2*s, lty = 3)
abline (h=m-2*s, lty = 3)
legend("bottomleft", legend = c("Mean", "1SD", "2SD"), lty = c(1, 2, 3))
upper <- e[e > m+2*s]
index_upper <- which(e > m+2*s)
points(upper ~ index_upper, pch=16, col="grey")
lower <- e[e < m-2*s]
index_lower <- which(e < m-2*s)
points(lower ~ index_lower, pch=16, col="black")
```

Figure 2.3. Monitoring of PCR's efficiency variation. By plotting the efficiency of each PCR run over time, it is possible to determine whether a specific run has been affected by amplification problems. The abscissa can either consider the date of the run or an index of the run (as in this case). The mean of the efficiency is plotted (solid line) together with one (dashed lines) and two (dotted lines) standard deviations (SD) from the mean. It is evident how the majority of the data lies within one SD from the mean, with the efficiencies being evenly distributed above and below the mean. In two occurrences, the efficiency lies above (gray dot) and below (black dot) the 2SD boundaries. These two runs should be carried out again.
