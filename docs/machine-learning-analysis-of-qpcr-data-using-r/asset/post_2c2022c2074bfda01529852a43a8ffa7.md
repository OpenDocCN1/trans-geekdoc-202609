## Extending the SVM Classification

The overall accuracy attained in this example is not exceptional; by comparison, it was 1 ± 0 on the study mentioned above (Marongiu, 2020). However, it must be considered that:

- The data set was small (0.76% of the data analyzed in 2020).
- There was quite an overlap between reactions classified as positive and negatives.

Regardless of the quality of the initial data, the value of the analysis relies in its capability to cluster the samples according to their reactivity. Such a feature will be tested in the following listing.
