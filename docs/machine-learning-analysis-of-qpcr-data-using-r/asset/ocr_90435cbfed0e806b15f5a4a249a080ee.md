# Listing 2.4.

An array of 100 random hypothetical PCR efficiencies ranging between 99% and 110% is stored in the variable e and built with the function runif. The variable index stores the e's indices. Two random e's elements are changed to values outside the assigned range. The mean and standard deviation of e are computed and stored in the variables m and s, respectively. A plot is built upon the data and lines corresponding to one (m±s) or two (m±2s) the standard deviations from the mean are depicted.

# Listing 2.5.

A data frame containing concentrations and the positivity rate (that is: the percentage of samples that returned a reactive reaction) is set and a regression model is built using a logit model. The regression model stored in model, allows to get a y-value (percentage of success) given an x-value (concentration). Since the operation needed is the opposite (determine the concentration given a percentage of success of 95%), an inverse logit function is obtained using the dose.p function of the package MASS. To increase the shape of the curve, more data points are stored in the data frame newdata, using the seq function, linearly distributed between a maximum and minimum provided by the data frame's range of concentrations. The y-values of the new data points are generated by regression using the predict function. The results are plotted.

# Listing 2.6.

The maxRatio function excludes the first cycle from the amplification vector passed to it as the argument A. A corresponds to the amplification at the cycle n, stored in the vector n. The amplification at the cycle n-1 is obtained by excluding the last element of the vector A, stored in the vector n_minusOne. The ratio, diminished by one, between these vectors is stored in the object R. Since the computation is on vectors, the operation is done element by element on n and n_minusOne, returning a vector. When the vectors undergoing the operation are not of the same length, the shortest vector is recycled. That is: having the vectors x <- c(2, 3) and y <- c(8, 9, 10, 12), the vector w <- y/x will contain [4, 3, 5, 4]. In other words, x has been recycled in the operation to obtain 8/2, 9/3, 10/2 and 12/3.

The function maxRatio is called on a vector amp containing real-life fluorescence data. The results are plotted.
