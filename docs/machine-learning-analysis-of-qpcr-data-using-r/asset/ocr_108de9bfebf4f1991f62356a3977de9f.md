Figure 1.2A clearly shows that the profiles are different. A more realistic description than the logistic equation is to use a model with four parameters (Rutledge, 2004):

F_C = F_M/(1+e^{-(C - C_h)/s}) + F_B

(2)

where F_C is the fluorescence at a cycle C, F_M is the maximum fluorescence, C_h is the cycle when half of F_M is reached, F_B is the background fluorescence, and s is the slope of the curve. None of these parameters are known beforehand, so the process relies heavily on parametric estimation. The first step in the procedure is to provide some starting values. Considering F_M as the maximum of the amplification series, ½F_M could be used to visually identify C_h, while F_B was set as the fluorescence of the first cycle because it had the highest background value of the entire series. Desmos (https://www.desmos.com/calculator) was used to estimate s by passing the data and the equation (to note that Desmos also provides all the other parameters automatically). The second step in parametrization is to pass the equation and a function that subtracts the value obtained by such equation with the actual value. The function nls.lm can extract the parameters directly; these are then stored in objects to model the data.

library("minpack.lm")
MaxFluo <- max(high)

rutledge <- function(p, x) {
  Ch = p$half_fluorescence
  s = p$slope
  Fm = p$max_fluorescence
  Fb = p$back_fluorescence
  y = (Fm / ( 1 + exp(-(x-Ch)/s))) + Fb
  return(y)
}
rutledge_param <- function(p, x, y) ((p$Fm / ( 1 + exp(-(x-p$Ch)/p$Ss))) + p$SFb ) - y
estim <- nls.lm(par = list(Ch = halfCycle, s = 2.77, Fm = MaxFluo, Fb = high[1]),
