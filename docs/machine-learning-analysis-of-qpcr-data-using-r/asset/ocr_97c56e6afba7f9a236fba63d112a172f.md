# Conclusion

The data presented in this work showed that the combination *maxRatio*/SVM-filtering has several advantages over the fit-point method:

+   - *Adaptability.* The model adapts to the data set under evaluation, automatically incorporating the peculiarities (inhibitions, chemical tweaks and so on) of experimental method.
+   - *Flexibility.* The number of classes can be defined according to the operator’s needs.
+   - *Extensibility.* The model can be trained with an ever increasing number of data points, increasing the accuracy of the method.
+   - *Dissimilarity.* The combination of the classification with the fit-point method helps identify reactions that requires the operator’s full attention in the validation phase.
+   - *Independency.* The thesis of the present and previous work (Marongiu, 2020) is that the classification provided by SVM can pin-point reactions with problematic amplification profiles even in absence of the fit-point method pre-classification.
+   - *Portability.* Because the SVM analysis can be performed using a high-level computer language — in this case *R*, but other platforms (notably *Python* or *Julia*) can carry out machine learning procedures — the classification demonstrated in this work does not require the patented software associated with the thermal-cycler. In contrast, the operators almost never re-run the Cq value determination using *ad hoc* computational analysis, instead relying on the output (albeit adjusted) provided by the thermal-cyclers’ software. As a result, without this patented software, it is impossible to analyze the data.
