# Filtering maxRatio with the Expectation-Maximization Method

As for the fit-point method, also maxRatio necessitates the establishment of a threshold to distinguish between reactive (positive) and non-reactive (negative) reactions (samples). As mentioned in the preceding section, this threshold was determined by multiplying by 5-10 the standard deviation of the MR values of a set of negative samples (Shain and Clemens, 2008). The scale of the multiplier was the operator’s choice. Recently, however, attempts were made to improve the procedure by providing an objective separation of the samples. The objectivity of the procedure, in this context, means that the operator would not choose a value — statistical methods will select the best parameters according to the data at hand. Such objective approach, in theory, would provide an analytical tool specific for the qPCR assay at hand, compensating for possible inhibitors in the samples’ matrices, performances of the chemical used, and quirks of the thermal-cyclers. Unlike the fit-point method, maxRatio allows the use of multiple thresholds to stratify the samples into specific subclasses (for instance, weakly reactive positive samples).

A first approach towards data-oriented setting of the threshold was the implementation of expectation-maximization (EM) algorithm (Marongiu et al., 2016a). The EM algorithm identifies peaks in sample distribution and then a cut-off to separate them (Dempster et al., 1977). The following listing will describe this procedure:
