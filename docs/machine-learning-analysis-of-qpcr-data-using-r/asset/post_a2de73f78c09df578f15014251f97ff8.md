It is possible to write single line function (known in other programming languages as lambda or anonymous functions) that implements a simple if... else statement. The value returned from the one liner function can be stored into an object with the following syntax:
variable <- function(parameters) (return (if(parameters)))
variable <- ifelse(condition, value_if_true, value_if_false)
In the first case, a computation based on the values present in parameters is returned. For instance, f(x) = a * b+c, when x = [a, b, c]. In the second case, variable takes either value if true or value if false according to the result of the condition clause. For instance, a <- ifelse(x>0, "positive", "negative") applied to x <- c(-2, -1, 0, 1, 2) will return a = ["negative" "negative" "negative" "positive" "positive"].
