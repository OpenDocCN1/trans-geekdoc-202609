# Listing 1.5.

The previously defined *PCR* function is applied to a set of four initial input samples. The normalization parameter between copy numbers and fluorescence is stored in *r* (more convenient values can be used). The output of the simulation is stored in four vectors (*A1-A4*) and then concatenated into the data frame *ROI*. The latter is built the vectors *Sample* (that names the samples from 1 to 4 and repeats these value for the number of cycles), *Cycle* (that repeats the values 1 to 45 for the four samples), and *Fluorescence* (that takes the actual fluorescence values). The results are plotted, to avoid actual drawing, type “n” is used. The different steps of the PCR are shaded using rectangles. In the continuation, all samples are plotted and an arrow is used to show the maxim level of fluorescence attained.

# Listing 1.6.

The *find_cycle* function selects the first *N* cycle of the amplification, where *N* is visually chosen to lie in the exponential phase of PCR. Since the amplification is exponential, it becomes a line in a semi-logarithm space and linear regression is used to predict the point when the model reaches the chosen point of 1 000 light units. The plot blows out the initial amplification cycles to highlight the exponential phase and the crossing-over points.
