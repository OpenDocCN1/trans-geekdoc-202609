Data exploration is an essential preparatory step that cannot be overlooked. Only when data has been cleaned it is possible to proceed to the actual analysis.

The first step in the maxRatio analysis is to generate the MR/FCN values for each reaction, employing the mrCalc function defined in the preceding sections. Since the SIV data was characterized by a high background (that is the lowest fluorescence values had already a high number), a compensation was introduced by setting the ‘background_compensation’ parameter to increase the MR values. Without such correction, the MRs would have been very small and could have introduced bias. The correction is, however, optional. Data visualization will employ the lattice package; the plot will not be plotted immediately but saved to an object P that is then drawn with the call print(P) (Figure 3.5).

**Listing 3.5**

```r
MRs = vector()
FCNs = vector()
for(i in unique(validation$Run)){
    run <- subset(validation, Run == i)
    for(j in run$Well) {
        well <- subset(amplification, Run == i & Well == j)
        x <- mrCalc(well$Cycle, well$FAM, background_compensation = 1000)
        MRs <- append(MRs, x[1])
        FCNs <- append(FCNs, x[2])
    }
}
validation$MR <- MRs
validation$FCN <- FCNs
library(lattice)
P <- xyplot(MR ~ FCN, group = Content, data = validation, cex=1.5, pch=c(0, 0, 1, 4), col = "black",
    key = list(space="top", columns=3, col = "black", points=list(pch=c(0, 1, 4), col="black"),
    text=list(c("Neg Ctrl/NTC", "Pos Ctrl", "Unkn"))))
print(P)
COLS = ifelse(is.na(validation$FAM) == TRUE, 1, 16)
plot(MR ~ FCN, validation, cex=1.5, pch=COLS, xlab="FCN", ylab="MR")
legend("topleft", legend = c("Positives", "Negatives"), pch=c(1,16))
write.table(validation, file = "validationCleaned.tsv", append = FALSE)
```
