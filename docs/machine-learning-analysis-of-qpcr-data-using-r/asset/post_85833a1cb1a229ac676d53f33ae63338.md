The following function, written in collaboration with Mr. Eric Shain, uses a filtering function in addition to a cubic spline interpolation to get sub-cycle resolution and smooth the curve (Figure 2.5B):

### Listing 2.7

```r
mrPlotter <- function(Cycles, FluoData, give = NULL) {
  background_compensation=0
  ratiox <- tail(Cycles, -1)
  MINx = min(ratiox)
  MAXx = max(ratiox)
  Xint = seq(MINx,MAXx,0.01)
  if (background_compensation > 0) FluoData = FluoData - mean(FluoData[4:6]) + background_compensation
  x = tail(FluoData, -1)
  w = head(FluoData, -1)
  r <- (x/w) - 1
  rf <- filter(r, rep(0.2,5))
  rf[1] <- r[1]
  rf[MAXx-1] <- r[MAXx-1]
  rf[2] <- mean(head(r,2))
  rf[MAXx-2] <- mean(tail(r,2))
  rint <- splinefun(ratiox,rf)
  if (give == "cycle") {
    return(Xint)
  } else if (give == "fluo") {
    return(rint)
  } else {
    return(NA)
  }
}
```

```r
mrCalc <- function(Cycles, FluoData, background_compensation=0) {
  ratiox <- tail(Cycles, -1)
  MINx = min(ratiox)
  MAXx = max(ratiox)
  Xint = seq(MINx,MAXx,0.01)
  m = FluoData
  if (background_compensation > 0) rm = m - mean(m[4:6]) + background_compensation
  x = tail(rm, -1)
  w = head(rm, -1)
  r <- (x/w) - 1
  rf <- filter(r, rep(0.2,5))
  rf[1] <- r[1]
  rf[MAXx-1] <- r[MAXx-1]
  rf[2] <- mean(head(r,2))
  rf[MAXx-2] <- mean(tail(r,2))
  SPLINE = splinefun(ratiox,rf)
  rint <- SPLINE(Xint, deriv = 0)
  mr <- max(rint, na.rm = TRUE)
  fcn <- Xint[match(mr, rint)]
  fcna = fcn - log2(mr)
  return(c(mr, fcn, fcna))
}
```

FCNA is an adjusted FCN that takes into account possible suppression in the signal of low template samples. In such samples, the ROI might compete with other non-specific nucleic acids for their access to the DNA-pol causing the accumulation of not-amplicon dsDNA that increases the light signal and decreases the Cq.

The FCNA corrects for such a shift by combining FCN with the emission ratio:

FCNA = FCN − log₂(MR). (2.8)

maxRatio is implemented on the idea that all the amplification response values are positive. In practice, the probe’s signal is never completely quenched, and there should always be a positive background fluorescence signal. As a result, it is critical to work with raw or normalized, but not base-lined, responses. This is advantageous for maxRatio because the base-lining process is prone to errors. When working with responses that have very low background fluorescence or that have been base-lined, a reaction shift can be used to avoid potential division by zero. This shifting, however, limits maxRatio’s self-normalization property. An MR threshold can be set to distinguish reactive from non-reactive reactions. This threshold is commonly generated during the qPCR assay’s setup step by multiplying the MR standard deviation of non-reactive responses (negative samples) by a predetermined number (typically 5 or 10). This threshold, once established, can be maintained throughout the analysis. Changing the MR threshold, unlike the fit-point threshold, has no effect on the related quantitative cycle. This occurrence can be visualized as follows (Figure 2.6):

Figure 2.6. Impact of threshold on the determination of the quantitative cycle. The signal threshold has different impacts on the fit-point and maxRatio methods. A. The MR threshold (solid line) in maxRatio separates non-reactive (negative, ○) from reactive (positive, ●) samples. The FCN is unaffected by doubling the threshold value (dashed line). The FCN of the positive sample with the lowest FCN, for example, remains the same (dotted line). B. The intersection point happens at a later cycle when the threshold value (dashed line) is doubled. Since the Cq is associated with the initial copy number of the sample, the quantification is altered. The arrows make it easier to grasp the process.

Additionally, multiple thresholds can be applied to separate different subclasses of samples.

The *maxRatio* algorithm was initially employed to quantify HIV RNA, and *Chlamydia trachomatis* and *Neisseria gonorrhoeae* DNA (Shain and Clemens, 2008). That study demonstrated that *maxRatio* provided a better definition of a reactive and non-reactive reactions than the fit-point method, thus providing better compensation for PCR inhibition. In a subsequent study (Zhao *et al.*, 2010), *maxRatio* was applied to the quantification of the nematode *Meloidogyne incognita*. Even in this case, *maxRatio* outperformed the fit-point method, for the former provided counts of second-stage juveniles closer to the gold standard (microscopical examination) than the latter (r² = 0.906 and r² = 0.851, respectively, both with a p-value < 0.001 and n = 10).

Another aspect that distinguishes *maxRatio* from other commonly used analytical approaches (such as the fit-point and second derivative) is that it delivers a pair of values for each response. The values generated by *maxRatio* can be plotted on an MR-FCN space, however the Cq generated by fit-point can only be aligned on a line. The benefit in the latter instance is that machine learning techniques can be used to further analyze the data. Machine learning is already being employed in the analysis of qPCR data (Gunay *et al.*, 2016), but *maxRatio* has the advantage over other algorithm of a simple implementation and to provide a visualization of the data (suitable to support-vector machines analysis) that makes it intuitive.
