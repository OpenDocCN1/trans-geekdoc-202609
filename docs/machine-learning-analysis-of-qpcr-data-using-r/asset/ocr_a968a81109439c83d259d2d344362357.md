The mrPlotter function re-implement the maxRatio function described in listing 2.6 in a more compact fashion. The exclusion of the first cycle is obtained using the function tail; the resulting series is stored in ratiox. The first and last cycle of ratiox are stored in MINx and MAXx, respectively. MINx will, therefore, store the value 2 and MAXx will store 45. This approach allows to apply mrPlotter to qPCR data with any cycling range. To increase the resolution of the plotting, a sequence of values between MINx and MAXx is generated with distances between values of 0.01 cycles instead of 1 cycles and stored in Xint.

The background_compensation variable is an optional parameter required to remove a chosen amount from the fluorescence data. For instance, it is possible to compensate the high value by decreasing the fluoresce at one cycle by the a moving average of fluorescence based on five cycles and the constant value given by background_compensation. This trick can reduce the bias introduced by reactions with high background, but it is optional. Since in this listing this option is not used, background_compensation is set to zero and the smoothing of the data is skipped altogether.

The fluorescence vectors of the cycle n and n-1 are stored in the objects x and w and their ratio diminished by one is stored in the vector r. The ratio itself is smoothed by using a moving average based on five points. The values of the moving average are store in the vector rf, but the first element of the vector (rf[1])is set as non-filtered by assign it the corresponding value r (rf[1]). Similarly, the last cycle is also left unfiltered (rf[MAXx-1] <- r[MAXx-1]). The second element of rf is set to the mean of the first two cycles while the second to last is set to the mean of the last two cycles. Essentially, rf stores the smoothed y values of the amplification. There are now 4301 x values instead of the original 45. The interpolation between the x values stored in ratiox and the y values stored in rf allows to draw a plot with a smooth line.

The mrPlotter function returns the x values (cycles) or the y values (fluorescence) of the computation using the parameter give. By calling myPlotter once with give="cycle" (x) and once with give="fluo" (y) it is possible to draw the maxRatio transform of the amplification.

The function mrCalc is implemented in the same way as mrPlot but calculates the MR by selecting the maximum of the smoothed y values stored in rint. The corresponding x value is found by selecting the index of the element of the x series (Xint) that matches the maximum element of rint. The selected x value provides FCN. FCNA is also calculated. The trio of MR, FCN, and FCNA is exported as a vector. A plot is drawn on the amplification data provided in listing 2.6, storing the x values and y values in cycles and fluorescence, respectively. First, the actual amplification is drawn and then the maxRatio transform is superimposed. The FCN is highlighted by adding a vertical line in correspondence of MR.
