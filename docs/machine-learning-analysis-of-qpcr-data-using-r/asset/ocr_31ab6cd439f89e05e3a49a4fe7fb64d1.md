The standard deviation can be used as a threshold between the two populations. Optionally, a multiplier can be applied to better separate the data (Marongiu et al., 2016a) — however, because the operator selects the magnitude of the multiplier, this approach introduces a further subjective step. The problem is that on many occasions, real-life data contain samples with a spike in MR values at low FCN. The previous listing can be updated to take into account such an occurrence:
