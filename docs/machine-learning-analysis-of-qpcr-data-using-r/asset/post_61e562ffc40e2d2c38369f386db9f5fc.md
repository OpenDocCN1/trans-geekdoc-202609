### Application of Machine Learning to maxRatio qPCR Analysis

### Filtering maxRatio with the Expectation-Maximization Method

As for the fit-point method, also maxRatio necessitates the establishment of a threshold to distinguish between reactive (positive) and non-reactive (negative) reactions (samples). As mentioned in the preceding section, this threshold was determined by multiplying by 5–10 the standard deviation of the MR values of a set of negative samples (Shain and Clemens, 2008). The scale of the multiplier was the operator’s choice. Recently, however, attempts were made to improve the procedure by providing an objective separation of the samples. The objectivity of the procedure, in this context, means that the operator would not choose a value — statistical methods will select the best parameters according to the data at hand. Such an objective approach, in theory, would provide an analytical tool specific for the qPCR assay at hand, compensating for possible inhibitors in the samples’ matrices, performances of the chemical used, and quirks of the thermal-cyclers. Unlike the fit-point method, maxRatio allows the use of multiple thresholds to stratify the samples into specific subclasses (for instance, weakly reactive positive samples).

A first approach towards data-oriented setting of the threshold was the implementation of the expectation-maximization (EM) algorithm (Marongiu et al., 2016a). The EM algorithm identifies peaks in sample distribution and then a cut-off to separate them (Dempster et al., 1977). The following listing will describe this procedure:

```

Specifically, a mixture model for parametric distributions is built using the library mixtools. The summary of the model provides the characteristics of the parameters describing the two overlapping distributions (that of the positive and the negative samples). The standard deviation can be used as a threshold between the two populations. Optionally, a multiplier can be applied to better separate the data (Marongiu et al., 2016a) — however, because the operator selects the magnitude of the multiplier, this approach introduces a further subjective step. The problem is that on many occasions, real-life data contain samples with a spike in MR values at low FCN. The previous listing can be updated to take into account such an occurrence:

A visual inspection of the data (Figure 3.2A) shows that there was a difference in sample distribution at FCN = 10. This split is obviously due to how the data for this example were created in the first place, but real data sets have similar discontinuities (Marongiu et al., 2016a; Marongiu et al., 2021a) — and the data was designed to include this breakup. The FCN = 10 can be used to further stratify the reactions: samples below this value will have one MR threshold, whereas the EM-derived threshold will be applied to those above this value.

Nevertheless, the EM approach to filtering maxRatio has some pitfalls:

- The choice of the FCN threshold is still subjective.
- The use of two MR thresholds (and one FCN threshold) is confusing and inelegant.
- The definition of further subclasses (such as weak positives) is complicated to design and remains subjective.

### Filtering maxRatio with Support-Vector Machine

Support-vector machines (SVM) are supervised learning models used for classification and regression analysis as part of machine learning algorithms. SVM was developed at AT&T Bell Laboratories by Vladimir Vapnik and colleagues between the 1960s and the 1990s (Cortes and Vapnik, 1995). SVM, in essence, finds a separation line (‘maximum margin hyperplane’ or simply hyperplane) between groups of samples known as items or elements. Linearly separable groups are non-overlapping groups. The SVM algorithm finds the hyperplane with the greatest degree of separation between the groups, meaning that the least number of elements from one group will be re-classified in the other group. Instead of using all elements from each group, SVM uses a subset of items closest to the hyperplane, which reduces the procedure’s complexity and computational requirements. When the groups are not linearly separable, SVM applies ‘margins’: some of the elements in proximity of the hyperplane are allowed to be clustered in the opposite group. The proportion of samples that can be ‘misclassified’ is defined by a cost parameter C, corresponding to the width of the margins around the hyperplane. The following section will describe the SVM algorithm in more detail.

This initial classification designates the term ‘supervised’: the operator supervises the procedure by assigning labels to each element; the machine, then, will improve the classification based on some algorithm.
