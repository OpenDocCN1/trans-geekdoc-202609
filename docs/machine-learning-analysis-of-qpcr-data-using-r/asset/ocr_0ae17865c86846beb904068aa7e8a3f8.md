# Listing 2.2.

A hypothetical standard curve is built by generating, using the user-defined function PCR, a series of signals with a tenfold higher amount of initial target; the amplification is stored in the A1-A6 objects. The crossing-over point is obtained by using the custom-defined function find_cycle (listing 2.1) by proving the amplification signal (the A1-A6 objects), the x-axis series (1 to 45 cycles) and the estimated cycle where the exponential phase of amplification is starting. Such a starting point can roughly be determined by looking at the amplification graph plotting the amplification cycle against the logarithm of the fluorescence signal: the exponential phase is linear. A data frame is then built upon the obtained values. A plot is then drawn showing the crossing-over (Cq) points. The colors of the points are user-provided shades of gray. It is possible to use the library RcolorBrewer to obtain automatically a series of colors to avoid the manual selection of shades and maximize the visual separation between elements. The colors sets are known as palettes and are selected by the function brewer.pal. The palette can be assigned to an object and the colors are assigned using the col argument of the plot function.
