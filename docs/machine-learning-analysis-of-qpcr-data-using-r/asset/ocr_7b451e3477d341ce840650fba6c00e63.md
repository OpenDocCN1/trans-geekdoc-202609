becomes zero. The results is that the reaction slows at each amplification cycle. This logistic simplification is not the most exact representation of PCR amplification curve. This can be demonstrated by comparing the curves obtained by this simulation with actual amplification profiles. To prove the point, as real amplification data from two reactions obtained from an HIV assay will be used (Marongiu et al., 2021a). Since these PCR assays were run for 50 cycles, only the first 45 data points will be collected. To compare them with the simulated data, the latter must be reshaped to provide an output in light units rather than copy numbers as such. The PCR function described in the previous chapter will be modified to take into account that the output is in light units and no in target’s copies. Since the actual reactions ran for 50 cycles, only the first 45 will be used.
