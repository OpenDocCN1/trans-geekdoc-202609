# ***maxRatio***

The *maxRatio* algorithm has been introduced as an alternative to the fit-point method to determine whether a reaction is truly reactive and to produce a more reliable quantification (Shain and Clemens, 2008). The *maxRatio* algorithm is currently included in the Abbott Molecular *m2000 RealTime System* to identify reactive results. The *maxRatio* algorithm is computationally simple, for it consider the ratio between the amplification signal *A* at the cycle *n* and *n-1*:

$R_n = \frac{A_n}{A_{n-1}} - 1.$

(2.7)

In absence of amplification, the signal is constant; thus, $A_n=A_{n-1}$, $A_n/A_{n-1}=1$, and the reduction of one unit in Equation 2.7 forces $R$ to zero. $R$ is not only dimensionless but also self-normalized. In fact, by decomposing $A$ into a part related to the actual amplification ($a$), and a part accounting for noise or background ($b$), it is immediately observable that $a' b / a b = a' / a$, where $a'$ and $a$ are the short for $a_n$ and $a_{n-1}$. The noise $b$ is equal in both the dividend and divisor because it comes from the same reaction. Unlike the fit-point method, therefore, *maxRatio* inherently accounts for individual amplification inhibition overcoming one of the major pitfalls of PCR quantification. $R$ can be computed on either baseline-corrected ($\Delta R_n$) or raw fluorescent signal; the latter allows for a better evaluation since it does not cover-up possible inhibition in the reaction.

Whereas the qPCR amplification curve built using the fit-point method is sigmoid, the *maxRatio* transform is Gaussian. The following listing will prove it using data from a PCR targeting *Campylobacter jejuni* previously analyzed by *maxRatio* (Marongiu, 2016a, 2016b).

maxRatio <- function(A) {
  n = A[2:length(A)]
  n_minusOne = A[1:length(A)-1]
  R <- (n/n_minusOne) - 1
  return(R)
}
