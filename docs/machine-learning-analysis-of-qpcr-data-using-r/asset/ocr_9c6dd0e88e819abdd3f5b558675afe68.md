Additionally, multiple thresholds can be applied to separate different subclasses of samples.

The *maxRatio* algorithm was initially employed to quantify HIV RNA, and *Chlamydia trachomatis* and *Neisseria gonorrhoeae* DNA (Shain and Clemens, 2008). That study demonstrated that *maxRatio* provided a better definition of a reactive and non-reactive reactions than the fit-point method, thus providing better compensation for PCR inhibition. In a subsequent study (Zhao *et al.*, 2010), *maxRatio* was applied to the quantification of the nematode *Meloidogyne incognita*. Even in this case, *maxRatio* outperformed the fit-point method, for the former provided counts of second-stage juveniles closer to the gold standard (microscopical examination) than the latter (r² = 0.906 and r² = 0.851, respectively, both with a p-value < 0.001 and n = 10).

Another aspect that distinguishes *maxRatio* from other commonly used analytical approaches (such as the fit-point and second derivative) is that it delivers a pair of values for each response. The values generated by *maxRatio* can be plotted on an MR-FCN space, however the Cq generated by fit-point can only be aligned on a line. The benefit in the latter instance is that machine learning techniques can be used to further analyze the data. Machine learning is already being employed in the analysis of qPCR data (Gunay *et al.*, 2016), but *maxRatio* has the advantage over other algorithm of a simple implementation and to provide a visualization of the data (suitable to support-vector machines analysis) that makes it intuitive. The following chapter will go in further detail into the application of *maxRatio*.
