It is possible to find out at what cycle the different sample crossed the cut-off set the previous paragraphs (one million light units) assuming that each amplicons emits one light unit.

It is evident that the sample with the lowest initial load reached the threshold at a later cycle than those with higher initial inputs. It is possible to calculate the actual cycle when the threshold value was reached with a little interpolation as follows:

find_cycle <- function(Y, X, N) {
  n = 45 - N
  y = log10(Y)[1:n]
  x = X[1:n]
  raw_value <- predict(lm(x~y), newdata = data.frame(y=log10(1000)))
  answer <- unname(raw_value[is.na(raw_value)])
  return(answer)
}
cq_1 <- find_cycle(ROI[ROI$Sample == 1,]$Fluorescence, 1:45, 37)
cq_2 <- find_cycle(ROI[ROI$Sample == 2,]$Fluorescence, 1:45, 35)
