For instance, the early studies focused on demonstrating the presence of human papillomavirus in cervical cancer samples where based on the use of radioactive-marked probes purified from other cancer samples (Boshart et al., 1984).

The hybridization between the target NA and a probe is an essential tool for both research and diagnostic. Hybridization can be carried out directly within cells and, if the probe has been linked to a fluorophore, the procedure is known as fluorescent in situ hybridization (FISH). FISH is generally assessed by microscopy, which is a low-throughput procedure, but its greatest problem is sensitivity for each cell must contain a large amount of target to produce a visible fluorescence. A solution to the ISH’s shortcoming is electrophoresis (Kroczek, 1993). With electrophoresis, the genomes from a set of cells are fractionated using either physical or chemical approaches. The fragments then migrate when exposed to an electric field, usually on poly-acrylamide matrices (but agarose is also popular) to achieve high resolution of the fragments. This version of electrophoresis goes under the name of PAGE. Urea or formamide are used to denature the NAs’ tridimentional structures, facilitating their migration (Summer et al., 2009; Petrov et al., 2013). The fragments are then stained with intercalator dyes such as EtBr. PAGE provides a series of bands that act as a sort of bar code (fingerprint) that can be used to specifically identify species. PAGE is good for small genomes such as bacterial ones, but it is cumbersome for human genomes. To reduce the number of bands, probes can be used. In this way, only the portions of the target genome that bind to the probe can be visualized. To improve the annealing of the probe with the target NA, the fragments are transferred to a nylon membrane. The probes are marked with enzymes to display the hybrids, and the procedure is known as either Southern (for DNA targets) or Northern (for RNA) blotting (Kroczek, 1993; Southern, 2000).
