the difference between the observed and expected values. The best fitting values for the five parameters are stored into the *estim* object and can visually inspected with *summary(estim)*, which are then manually inserted into the *rutledge* function. The object *mod_h* contains the amplification model obtained using the best fitting parameters.
In the continuation of the listing, a more compact and PCR-specific function (*pcrfit*) is used from the package *qpcR*. The function estimates the best parameters based on a data frame composed on the amplification cycles and the actual fluorescence values stored in *high*. The cycles are generated with the function *seq_along*, which takes a vector as an input.
