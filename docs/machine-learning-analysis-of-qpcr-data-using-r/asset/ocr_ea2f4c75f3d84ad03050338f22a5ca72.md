Essentially, the description of the data remains the same but there are now 5040 data points instead of 5304 and the amplification is performed within 42 cycles. Data exploration is an essential preparatory step that cannot be overlooked. Only when data has been cleaned it is possible to proceed to the actual analysis.

The first step in the maxRatio analysis is to generate the MR/FCN values for each reaction, employing the mrCalc function defined in the preceding sections. Since the SIV data was characterized by a high background (that is the lowest fluorescence values had already a high number), a compensation was introduced by setting the ‘background_compensation’ parameter to increase the MR values. Without such correction, the MRs would have been very small and could have introduced bias. The correction is, however, optional. Data visualization will employ the lattice package; the plot will not be plot immediately but save on an object P that is then drawn with the call print(P) (Figure 3.5).

MRs = vector()
FCNs = vector()
for(i in unique(validation$Run)){
    run <- subset(validation, Run == i)
    for(j in run$Well) {
        well <- subset(amplification, Run == i & Well == j)
        x <- mrCalc(well$Cycle, well$FAM, background_compensation = 1000)
        MRs <- append(MRs, x[1])
