## Discussion

We found the AtomAI framework easy to use and amenable to future code extensions. We verified its applicability on four different datasets: two obtained from the original AtomAI work, one from the literature and an original additive manufacturing dataset. Although the AtomAI framework offers several capabilities, here we restrict our focus to the two primary tasks of image segmentation and Im2Spec. Not only did we achieve model accuracies reported in these works, but we were able to improve the model performance further by extending the AtomAI framework to include ES, optimization of the classification threshold value, instance segmentation and other deep network architectures. Our extensions to the AtomAI code were straightforward and did not require major alterations in its basic structure. A few minor bugs were discovered in the original code and were fixed in our implementation. We believe that the AtomAI framework will be a very useful tool for the microscopy and spectroscopy communities, especially helping those who perform high-throughput experimentation or deal with the optimization of materials microstructure.

## Future directions

A significant bottleneck in the domain of automated microstructural image segmentation using AI is the availability or generation of ground-truth labels. Thus, the effectiveness of the AtomAI framework can be significantly enhanced through the incorporation of software tools that facilitate semi-automatic data generation. For instance, recently, a few works^10,11 have used either pretrained models or initial versions of low-accuracy machine learning (ML) models to obtain an approximate segmentation map of the image. These low-fidelity segmentation maps can then be easily and quickly edited by an expert user to create more accurate ground-truth data to be further used for fine-tuning the ML models. Following this scheme in an iterative closed-loop fashion, users can quickly train accurate ML models without spending too much time generating accurate image labels. In one such work in the area of grain analysis, Gorynski et al.^12 employed two versions of Mask region-based CNNs, one for generating ground-truth labels and the other for the inference task. They built a user-friendly graphical user interface where the user can enter the bounding box around an individual grain. A pretrained Mask region-based CNN model then utilizes these bounding box data to generate pixel-perfect grain masks, which are, in turn, used to train a specialized Mask region-based CNN for grain detection. Since the annotation of a bounding box (just two points) is much faster than the annotation of a precise object (or grain) outlines, the authors were able to generate a large number of training data, which allowed them to train ML models with higher accuracy in terms of grain properties, such as the area, the circumference, the centre of mass and the minimum/ maximum Feret diameter.

In this regard, the CVAT (Computer Vision Annotation Tool) library^13 could be a valuable resource for integrating semi-automatic segmentation tasks with the AtomAI framework. CVAT is a free, open-source digital image annotation tool written in Python and JavaScript. Integrating CVAT into AtomAI can provide users with a graphical interface to quickly perform annotation tasks directly in the regions where ML predictions are below par, thereby allowing the generation of new data labels for conditions where ML models need improvement.
