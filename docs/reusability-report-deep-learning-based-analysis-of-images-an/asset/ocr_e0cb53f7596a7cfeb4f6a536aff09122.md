For the additive manufacturing dataset, a similar strategy was adopted. The dataset consists of 12 images, of which 3 images were initially selected as the test set. For the remaining 9 images, 500 patches of size 256 × 256 were extracted from each image, after which augmentation was carried out to result in a total of 4,500 images. This was further split in an 80:20 ratio to produce the training and validation sets, respectively. The initial 12 images were manually segmented into three classes, namely the background, the gas-induced porosity and the lack-of-fusion porosity. We note that two images had an additional scale bar, which was removed by replacing the associated pixel values with the average of the background class pixel value. A few example images from the different datasets are included in Fig. 1b.

Several augmentation strategies, such as Poisson noise, Gaussian noise, blur, image rotation and flips, were utilized on the training data to improve the model generalization. In terms of model architecture, AtomAI utilizes a U-Net adjacent network with six convolution blocks, three upsampling blocks and skip connections for efficient model training and information preservation. Two versions of the model, with and without ES, were trained in each case. The model with the lowest log-loss error on the validation set was selected as the final model and was used to make predictions on the test set and other new unseen images.

A few additional studies that go beyond the original publication of the AtomAI framework were also performed to gain important insights. For the BFO dataset, we focused on the robustness of the trained model against Poisson noise and image scaling, the key idea being that the trained model is most useful if it performs well on images of similar samples that have different levels of noise, contrast or are acquired at slightly varying magnification levels, scenarios that are commonly encountered during imaging. To evaluate the model performance for such conditions, we add different levels of Poisson noise to the images in the test set and scale them at various magnifications (×1.1–2). Similarly, the effect of different combinations of augmentation strategies and determination of a threshold value for class labelling that improves the model performance was studied for the nanoparticle dataset.

For the Im2Spec task, the scanning transmission electron microscopy (STEM) images and electron energy loss (EEL) spectrum data present in the original AtomAI work was utilized. Several encoder–decoder architectures were attempted, including recurrent neural networks with long short-term memory (LSTM) and a modified version of the recently published Mat2Spec, which uses the concept of supervised contrastive learning and the Gaussian mixture model to represent probabilistic feature embeddings. All the architectures attempted have been included in the updated AtomAI library.

Beyond the original AtomAI framework included in the manuscript, another strategy that was adopted to improve the performance of the models on the nanoparticle dataset was the use of a better classification threshold value. The last layer of the U-Net model predicts the probability of each pixel belonging to a certain class. For example, for a two-class problem, U-Net gives a pixel-wise probability map, wherein a value greater than a threshold of 0.5 is (generally) chosen to belong to the nanoparticle class and otherwise belongs to the background class. However, on the basis of our experiments, we find that AtomAI’s default threshold value of 0.5 is not optimal and model performance can be improved by optimizing the precision–recall trade-off. As seen in Table 2, more optimal threshold values, as determined from the validation set, could be used to improve the model performance. The performance boost in the case of the CdSe dataset was observed to be higher where the contrast between the background and the particle dataset was low. We also expect the θ tuning to particularly improve performance in the case of unbalanced datasets. It should be noted that θ is tuned after the U-Net model training is completed. Thus, another important code improvement that we performed to the AtomAI framework is the inclusion of a module that allows the determination of the optimal threshold value. We also used the AtomAI framework to optimize the number of layers in the U-Net model and the dropout rate; however, it did not result in performance improvement over the model trained using the optimal threshold strategy.
