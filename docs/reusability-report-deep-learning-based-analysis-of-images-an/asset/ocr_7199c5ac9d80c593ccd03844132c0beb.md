In addition to automatic threshold selection and ES, we extended AtomAI's capabilities to allow for instance segmentation and demonstrate its advantage using the additive manufacturing dataset. Instance segmentation not only classifies each pixel of the image (similar to semantic segmentation), but also groups pixels together to identify different instances of objects. The effort required to create a training dataset for an instance segmentation model can be huge. Thus, we use the concept of connected components and watershed segmentation that allows us to convert a semantic segmentation model into an instance segmentation model. The additive manufacturing dataset consists of optical images of alloys containing defects of two types: gas-induced and lack-of-fusion porosities. To highlight the advantage of instance segmentation, two types of segmentation model were trained using the AtomAI framework: a three-class model that classifies pixels into gas induced, lack of fusion or background, and a two-class model that classifies pixels into porosity and background. The latter model was further extended using our instance segmentation module to differentiate between the two types of porosity. Specifically, the output predictions from the two-class model are processed using the watershed algorithm to obtain masks associated with individual instances of defects. Once the defects are identified, their shape characteristics, such as perimeter, area, major axis length and solidity, can be computed using scikit-image. These defect characteristics not only are important from the point of view of unveiling structure–property relations, but also can be used to classify defects of different types. For instance, gas-induced porosities are spherical, while lack-of-fusion porosities have irregular boundaries and are elongated in a particular direction. Thus, here, we used a combination of major axis length, solidity and equivalent diameter (Supplementary Information) to define a function that can differentiate between porosity defects as lack of fusion or gas induced.
