

# 练习题答案解析

## 第 16 章：安全策略与合规（续）

**8. B**  
所有这些组织都制定安全标准和基准。然而，只有互联网安全中心（CIS）以制定涵盖各种软硬件的独立基准而闻名。

**9. C**  
行为准则通常用作员工行为问题的底线保障，这些问题未被其他策略直接解决。

**10. B**  
安全策略通常不包含指令性的技术指导，例如要求使用特定加密算法。此类细节通常见于安全标准中。

**11. A**  
审计师不评估控制措施的有效性，这意味着这是 Type 1 报告，而非 Type 2 报告。仅在 NDA 下共享意味着这是 SOC 2 评估。

**12. B**  
组织的可接受使用策略（AUP）应包含什么构成公司资源允许和不允许使用的信息。该策略应包含指导 Tonya 后续步骤的信息。

**13. D**  
支付卡行业数据安全标准（PCI DSS）提供了关于存储、处理和传输信用卡和借记卡信息的详细规则。PCI DSS 不是法律，而是适用于信用卡商户和服务提供商的合同义务。

**14. D**  
数据保留策略概述了组织将维护哪些信息，以及不同类别的信息在销毁前将保留多长时间。

**15. D**  
强制休假旨在迫使个人离开办公室一段时间，以便在其缺席期间暴露欺诈活动。此处列出的其他控制措施（职责分离、最小权限和双人控制）旨在预防而非检测欺诈。

**16. D**  
指南是安全策略框架中唯一可选的要素。遵守策略、标准和程序是强制性的。

**17. D**  
这些术语中的任何一个都可以合理地描述此项工作。然而，“审计”一词最能描述此工作，因为审查的正式性质以及是由董事会要求的。

**18. B**  
标准描述了组织必须具备的具体安全控制。Allan 不会在高层策略文档中包含可接受的机制，而这些信息作为程序来说太笼统。指南不是强制性的，因此不适用于此场景。

**19. D**  
NIST 网络安全框架旨在帮助组织描述其当前的网络安全状况、描述网络安全目标状态、识别并优先考虑改进机会、评估进度，并与利益相关者沟通风险。它不创建具体的技术要求。

**20. C**  
安全策略例外请求通常不包括对策略的建议修订。例外是因特定技术和/或业务需求而产生的、有文档记录的偏离策略的行为。它们不改变原始策略，该策略对未被例外覆盖的系统仍然有效。

# 第 17 章：风险管理与隐私

**1. C**  
通过应用补丁，Jen 从服务器中移除了漏洞。这也消除了这一特定风险。Jen 无法控制攻击者试图访问其服务器的外部威胁。

**2. C**  
安装 Web 应用防火墙降低了攻击到达 Web 服务器的概率。Web 应用中可能仍存在漏洞，外部攻击的威胁也未改变。成功的 SQL 注入攻击的影响也不会因 Web 应用防火墙而改变。

**3. C**  
本案例中处于风险中的资产是客户数据库。失去对数据库的控制将导致 500,000 美元的罚款，因此资产价值（AV）为 500,000 美元。

**4. D**  
攻击将导致数据库中存储的客户数据完全丢失，使暴露因子（EF）为 100%。

**5. C**  
我们通过将资产价值（AV）（500,000 美元）和暴露因子（EF）（100%）相乘，计算出单次损失期望值（SLE）为 500,000 美元。

**6. A**  
Aziz 的威胁情报研究确定该威胁每年发生的可能性为 5%。这是年化发生率（ARO）为 0.05。

**7. B**  
我们通过将 SLE（500,000 美元）和 ARO（0.05）相乘，计算出年化损失期望值（ALE）为 25,000 美元。

**8. C**  
安装新控制或升级现有控制是降低风险概率或幅度的努力。这是风险缓解活动的一个例子。

**9. B**  
更改业务流程或活动以消除风险是风险规避的一个例子。

**10. D**  
保险单通过将部分或全部财务风险从组织转移给保险公司，采用了风险转移策略。

**11. A**  
当组织决定不再采取进一步行动解决剩余风险时，他们选择的是风险接受策略。

**12. A**  
根据 GDPR，数据保护官（DPO）是被指派直接负责执行组织隐私计划的个人。

**13. A**  
在本案例中，医生保持数据所有者角色。他们选择将数据处理外包给 Helen 的组织，使该组织成为数据处理者。

**14. C**  
恢复时间目标（RTO）是组织在系统修复前能容忍系统停机的时间长度。这是 Gene 在此场景中确定的指标。

**15. B**  
这是一个棘手的问题，因为患者记录中可能包含所有这些类别的信息。然而，它们最有可能包含受保护的健康信息（PHI）。PHI 也可被描述为个人可识别信息（PII）的一个子类别，但 PHI 是更好的描述。记录也可能包含支付卡信息（PCI）或个人财务信息（PFI），但可能性低于 PHI。

**16. C**  
组织应仅将数据用于收集该数据时披露的目的。在本案例中，组织为技术支持目的收集数据，现将其用于营销目的。这违反了目的限制原则。

**17. C**  
Top Secret（绝密）是美国分类体系中的最高级别，因此需要最高级别的安全控制。

**18. A**  
令牌化技术使用查找表，设计为可逆的。如果正确实施，掩码和哈希技术用无法还原为原始数据的值替换数据。碎纸销毁如果操作得当，会物理销毁数据，使其无法恢复。

**19. B**  
数据控制者是决定处理个人信息的原因并指导处理该数据方法的实体。该术语主要用于欧洲法律，作为“数据所有者”一词的替代，以避免假设收集数据的任何人都对该数据拥有所有权。

**20. D**  
剩余风险是组织实施了旨在缓解、规避和/或转移固有风险的控制措施后仍然存在的风险。
