让我们逐节查看此报告，从左上角开始，按逆时针方向进行。

在报告的最顶端，我们看到两个关键细节：*漏洞名称*，它提供了一个描述性标题；以及漏洞的*总体严重性*，以通用类别表示，如低、中、高或严重。在本示例报告中，扫描器报告称一台服务器正在运行过时且不安全的 SSL 协议版本。它被归类为高严重性类别。

接下来，报告提供了漏洞的*详细描述*。在本例中，报告详细描述了 SSL 协议中的缺陷，并解释了 SSL 不再被认为可接受使用。

报告的下一节提供了漏洞的*解决方案*。在可能的情况下，扫描器会提供关于系统管理员、安全专业人员、网络工程师和/或应用程序开发人员如何修复漏洞的详细信息。在本例中，指示读者禁用 SSL 2.0 和 3.0，并用安全版本的 TLS 协议替代其使用。

在标题为“另请参阅”的报告部分中，扫描器提供了*参考资料*，管理员可在其中找到报告中描述的漏洞的更多详细信息。在本例中，扫描器将读者引向多篇博客文章、Nessus 文档页面以及互联网工程任务组（IETF）文档，这些资料提供了关于该漏洞的更多详细信息。

报告的*输出*部分显示了在探测漏洞时远程系统返回的详细信息。此信息对分析师极具价值，因为它通常提供命令返回的逐字输出。分析师可利用此信息更好地理解扫描器报告漏洞的原因、确定漏洞位置，并有可能识别误报。在本例中，输出部分显示了正在使用的特定不安全加密套件。

*端口/主机*部分提供了包含漏洞的服务器以及该服务器上存在漏洞的特定服务的详细信息。在本例中，出于隐私原因服务器的 IP 地址被遮盖，但我们可以看到该服务器在 443 和 4433 端口上均运行着不安全版本的 SSL。

*漏洞信息*部分提供了关于漏洞的一些杂项信息。在本例中，我们看到该 SSL 漏洞曾出现在新闻报道中。

*风险信息*部分包含用于评估漏洞严重性的有用信息。在本例中，扫描器报告该漏洞的总体风险因子为高（与漏洞标题旁的标签一致）。它还提供了使用通用漏洞评分系统（CVSS）评级时的详细情况。你会注意到有两个不同的 CVSS 评分和向量。我们将使用 CVSS 3.0 版本的信息，因为它是更新的评级标准。在本例中，该漏洞的 CVSS 基础评分为 7.5，CVSS 向量为：

```
CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N
```

我们将在本章的下一节讨论 CVSS 评分的详细细节。

漏洞报告的最后一部分提供了检测到该问题的漏洞扫描器插件的详细信息。该漏洞由 Nessus 插件 ID 20007 报告，该插件于 2005 年 10 月发布，并于 2019 年 3 月更新。

## 理解 CVSS

*通用漏洞评分系统（CVSS）* 是评估安全漏洞严重性的行业标准。它提供了一种根据多种度量对每个漏洞进行评分的技术。网络安全分析师通常使用 CVSS 评级来确定响应行动的优先级。

分析师在对新漏洞评分时，首先根据八个不同的度量对漏洞进行评级。每个度量都会获得一个描述性评级和一个数值评分。前四个度量评估漏洞的可利用性，而后三个度量评估漏洞的影响。第八个度量讨论漏洞的范围。

### 攻击向量度量

*攻击向量度量* 描述攻击者如何利用该漏洞，并根据 [表 5.1](#c05.xhtml#c05-tbl-0001) 所示标准进行赋值。

[**表 5.1**](#c05.xhtml#R_c05-tbl-0001) CVSS 攻击向量度量

| 值 | 描述 | 评分 |
| --- | --- | --- |
| 物理 (P) | 攻击者必须物理接触易受攻击的设备。 | 0.20 |
| 本地 (L) | 攻击者必须拥有对受影响系统的物理或逻辑访问权限。 | 0.55 |
| 相邻网络 (A) | 攻击者必须拥有受影响系统所连接的本地网络的访问权限。 | 0.62 |
| 网络 (N) | 攻击者可通过网络远程利用该漏洞。 | 0.85 |

### 攻击复杂性度量

*攻击复杂性度量* 描述利用该漏洞的难度，并根据 [表 5.2](#c05.xhtml#c05-tbl-0002) 所示标准进行赋值。

[**表 5.2**](#c05.xhtml#R_c05-tbl-0002) CVSS 攻击复杂性度量

| 值 | 描述 | 评分 |
| --- | --- | --- |
| 高 (H) | 利用该漏洞需要难以满足的“特殊”条件。 | 0.44 |
| 低 (L) | 利用该漏洞不需要任何特殊条件。 | 0.77 |

### 所需权限度量

*所需权限度量* 描述攻击者利用漏洞所需的账户访问类型，并根据 [表 5.3](#c05.xhtml#c05-tbl-0003) 中的标准进行赋值。

[**表 5.3**](#c05.xhtml#R_c05-tbl-0003) CVSS 所需权限度量

| 值 | 描述 | 评分 |
| --- | --- | --- |
| 高 (H) | 攻击者需要管理员权限才能发起攻击。 | 0.270（若范围已改变则为 0.50） |
| 低 (L) | 攻击者需要基本用户权限才能发起攻击。 | 0.62（若范围已改变则为 0.68） |
| 无 (N) | 攻击者无需认证即可利用该漏洞。 | 0.85 |

### 用户交互度量

*用户交互度量* 描述攻击者是否需要让另一个人参与攻击。用户交互度量根据 [表 5.4](#c05.xhtml#c05-tbl-0004) 中的标准进行赋值。

[**表 5.4**](#c05.xhtml#R_c05-tbl-0004) CVSS 用户交互度量

| 值 | 描述 | 评分 |
| --- | --- | --- |
| 无 (N) | 成功利用不需要攻击者以外的任何用户采取行动。 | 0.85 |
| 需要 (R) | 成功利用需要攻击者以外的用户采取行动。 | 0.62 |

### 机密性度量
