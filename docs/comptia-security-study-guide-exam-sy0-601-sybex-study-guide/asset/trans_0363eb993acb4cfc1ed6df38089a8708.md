

# 社会工程学技术

## 钓鱼攻击变体

特定术语也用于描述针对特定目标的钓鱼攻击尝试。**鱼叉式网络钓鱼**针对组织中的特定个人或群体，试图收集所需的信息或获取访问权限。**鲸钓攻击**与鱼叉式网络钓鱼非常相似，也针对特定人员，但鲸钓攻击的目标是高级员工，如 CEO 和 CFO——公司里的“大鱼”，因此得名“鲸钓”。

与大多数社会工程学技术一样，针对所有类型钓鱼攻击最常见的防御手段之一是提高意识。教育员工了解钓鱼攻击以及如何识别和应对钓鱼攻击，甚至定期进行演练，都是降低钓鱼攻击成功风险的常用手段。技术手段也同样存在，包括利用信誉工具、关键字和文本模式匹配以及其他检测潜在钓鱼邮件、电话或短信的技术方法的过滤机制，这些都有助于防止钓鱼攻击。

## 凭证收集

**凭证收集**是收集用户名和密码等凭证的过程。凭证收集通常通过钓鱼攻击实施，但也可能通过系统入侵导致用户数据库和密码被获取、使用设置为窃取凭证的登录或远程访问工具，或任何其他能为攻击者收集凭证的技术来完成。

一旦凭证被收集，攻击者通常会利用它们发动进一步攻击，其中金融攻击是首要目标。虽然很难完全阻止凭证收集，但多因素认证（MFA）仍然是一种强有力的控制措施，有助于限制成功的凭证收集攻击的影响。用户意识、能够阻止钓鱼邮件等收集攻击的技术工具，以及强有力的监控和响应流程，都有助于应对凭证收集和被收集凭证的滥用。

## 网站攻击

针对网站的攻击也被社会工程师所利用，**域名劫持**就是一个例子。域名劫持攻击将流量从合法网站重定向到恶意版本。域名劫持通常需要一次成功的技术攻击，以便更改本地 PC 或受信任的本地 DNS 服务器上的 DNS 条目，从而实现流量重定向。

拼写抢注者使用拼写错误且与合法网站 URL 相似但略有不同的域名来实施**拼写抢注**攻击。拼写抢注者依赖于这样一个事实：人们会输错 URL 并最终进入他们的网站，从而带来广告流量，甚至有时利用基于拼写错误的网站来推销类似但非正规的产品。

与域名劫持不同，**水坑攻击**不会重定向用户；相反，它们利用目标经常访问的网站来攻击目标。这些经常被访问的网站就像动物的水坑一样，让攻击者能够部署攻击，因为他们知道受害者会访问该网站。一旦知道目标会使用哪个网站，攻击者就可以专注于攻破它，要么直接攻击该网站，要么通过其他方式（如广告网络）部署恶意软件。

## 垃圾邮件

**垃圾邮件**，有时称为未经请求或垃圾电子邮件，乍一看可能不像是一种社会工程学技术，但垃圾邮件通常采用社会工程学技术，试图诱使收件人打开邮件或点击其中的链接。事实上，垃圾邮件依赖于一个许多社会工程师会利用的潜在真理：如果你发送足够多的诱人信息，很可能就会有人上当！

Security+ 考试大纲还包括即时通讯垃圾邮件（SPIM）。虽然该术语出现在考试大纲中，但 SPIM 从未真正成为安全行业广泛使用的术语。你仍应确保为了考试而了解它，并明确知道它专门描述即时通讯垃圾邮件。

## 面对面技术

尽管我们迄今为止讨论的许多技术依赖技术来实现，但面对面的社会工程学和渗透测试技术也很重要。Security+ 考试大纲包括多种面对面技术，如翻垃圾桶、偷窥和尾随。

虽然它并不真正是一种社会工程学技术，但**翻垃圾桶**是一种非常有效的信息收集技术。它正如其名：从垃圾桶中检索潜在的敏感信息。翻垃圾桶可以提供大量关于组织的信息，包括文档和笔记。想要避免这种情况的组织会保护他们的垃圾桶，使用文档安全销毁服务，并以其他方式确保他们的垃圾真的是垃圾，不包含任何有用的东西。

**偷窥**是指从一个人肩膀上方窥视以获取密码或其他数据等信息的过程。虽然偷窥通常意味着实际上从一个人肩膀上方窥视，但其他类似的攻击（如看一个人身后镜子中输入凭证的倒影）也会被视为偷窥。防止偷窥要求潜在目标保持警惕，尽管像笔记本电脑等移动设备上的偏振安全镜片等工具可以帮助防止在公共场所发生偷窥。

**尾随**是一种物理入侵攻击，只需跟随拥有授权访问权限的人进入某个区域，这样当他们打开安全门时，你也可以跟着通过。与偷窥一样，尾随最好通过个人警惕来防止。如果有人试图跟着你通过安全门，你应该让他们出示自己的凭证，而不是放他们进去，或者立即报告入侵行为！

**套取信息**，通常称为诱导，是一种在目标未意识到的情况下收集信息的技术。奉承、假装无知，甚至充当顾问或倾听者等技术都是诱导工作的常见要素。引导目标谈论事情、故意发表错误陈述以便他们用所需信息纠正诱导者，以及其他技术都是诱导过程的一部分。理想情况下，经历过诱导攻击的社会工程学目标永远不会意识到他们提供的信息超出了预期，或者只会在事后很久才意识到。

**前置**可以指三件事之一：

1.  添加表达或短语，例如在一组电子邮件标题中添加“SAFE”，试图欺骗用户认为它已通过反垃圾邮件工具
2.  作为另一次攻击的一部分添加信息以操纵结果
3.  通过社会工程学对话建议话题，引导目标走向社会工程师正在寻找的相关信息

## 身份欺诈和冒充

假装成别人是社会工程师工具箱中的关键工具，与我们讨论的所有其他社会工程学技术一样，它可用于恶意目的。这些技术中的每一种都将目标相信冒充者的意愿与社会工程学原则相结合，创造出一种场景，让社会工程师获得他们想要的访问权限、数据或其他结果。

**借口攻击**是利用编造的场景来证明你接近某个人的合理性的过程。借口攻击通常用作冒充工作的一部分，使冒充者更可信。有意识的目标可以通过提问或要求验证来帮助挫败借口攻击和冒充攻击。在许多情况下，仅仅进行一次验证电话就能挫败此类尝试。
