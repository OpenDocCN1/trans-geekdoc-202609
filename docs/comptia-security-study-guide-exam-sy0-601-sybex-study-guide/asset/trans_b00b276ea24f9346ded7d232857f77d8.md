

## 第 8 章：身份与访问管理

### 问题 10-20

**10. B.** 在非对称加密算法中，每位员工仅需两个密钥：一个公钥和一个私钥。向系统添加新用户仅需为该用户添加这两个密钥，而无论已存在多少其他用户。

**11. D.** 扩展验证（EV）证书提供最高级别的可信度保证。签发 EV 证书的 CA 证明其已验证证书主体的身份和真实性。

**12. C.** 通配符证书保护所列域名及其所有一级子域名。`dev.www.mydomain.com` 是 `mydomain.com` 的二级子域名，因此不在此证书的保护范围内。

**13. A.** 根 CA 受到高度保护，通常不用于证书签发。根 CA 通常作为离线 CA 运行，将授权委派给作为在线 CA 运行的中间 CA。

**14. C.** PFX 格式最常与以二进制格式存储证书的 Windows 系统相关联，而 P7B 格式用于以文本格式存储文件的 Windows 系统。

**15. A.** 硬件安全模块（HSM）提供了一种管理加密密钥的有效方式。这些硬件设备以安全的方式存储和管理加密密钥，防止人员需要直接处理密钥。

**16. C.** 降级攻击有时用于针对 TLS 等安全通信，试图诱使用户或系统无意中切换到安全性较低的加密模式。其思路是欺骗用户切换到协议的一个安全性较低的版本，该版本可能更容易被破解。

**17. C.** 使用非对称加密算法加密消息时，执行加密的人使用接收者的公钥进行加密。

**18. D.** 在非对称加密算法中，消息的接收者使用自己的私钥来解密收到的消息。

**19. B.** 消息的发送者可以通过使用发送者自己的私钥加密消息摘要，对消息进行数字签名。

**20. A.** 经过数字签名的消息的接收者，可以通过使用签名者的公钥对其进行解密，来验证数字签名。

### 问题 1-18

**1. D.** Angela 的组织充当身份提供商（IdP）。联邦中的其他成员在允许其用户访问其服务时，可充当服务提供商或信赖方。认证提供商不是典型联邦活动中的命名角色。

**2. A.** 密码复杂性要求无法防止复杂密码的共享，这使其成为列表中效果最差的选项。生物识别认证措施要求注册用户必须到场，尽管在某些情况下（如指纹系统），多个用户均可为单个账户注册有效的指纹。两种类型的一次性密码均可共享，但会使共享账户变得更困难、不便。

**3. B.** 大多数云服务为其服务提供身份和授权工具。大多数（尽管并非全部）允许客户设置部分甚至许多将要使用的账户策略，且大多数主流供商支持某种形式的多因素认证功能。

**4. A.** 在所有列出的选项中，只有 RADIUS 是一种认证、授权和审计服务。

**5. B.** 短信不安全，可能通过克隆 SIM 卡或重定向 VoIP 流量等方式被获取，此外还存在其他可能的威胁模型。基于 HOTP 和 TOTP 的令牌和应用程序以及生物识别因素通常被认为比基于短信的因素更安全。

**6. B.** 地理围栏设置地理边界，可用作规则集的一部分。在本例中，Samantha 应将规则集设置为：当设备位于地理围栏区域之外时，阻止用户使用该设备。时间限制和基于时间的登录均是相关的账户策略，用于确保用户在不应工作的时间无法登录。这可以防止泄露凭证的重复使用和非工作时间内的内部威胁滥用。最后，不可能的旅行时间是一种地理登录数据用法，它记录登录发生的时间并将其与登录地点间的距离进行比较。如果时间不可能（例如，在中国登录 5 分钟后又在美国登录），则可能会报告并阻止该登录。

**7. B.** 图片密码要求用户点击图片上特定的、自定义的部分。这意味着点击这些点是“你能做的事”（Something you can do）。“你所在的地方”涉及位置，“你表现出的特征”典型指个性特征，“你认识的人”涉及第三方，当某人无法以其他方式证明身份时，这对验证很有用！

**8. B.** 硬件安全模块（HSM）用于创建、安全存储和管理数字签名、加密密钥对及其他加密功能。它们不用于生物识别注册数据、启用联邦或生成一次性密码。

**9. C.** 基于角色的访问控制（RBAC）根据个人的角色设置权限，角色通常与其工作相关联。基于属性的访问控制（ABAC）通常匹配除工作角色以外的属性。自主访问控制（DAC）和强制访问控制（MAC）通常在操作系统层面实现。

**10. D.** 指纹扫描仪广泛存在于移动设备和笔记本电脑上，使其成为部署最广泛的生物识别技术之一。面部识别也广泛部署，但未作为选项提供。

**11. B.** LDAP（轻量级目录访问协议）是目录服务的开放行业标准。LDAP 本身不是联邦或认证服务，也不提供生物识别认证服务。

**12. A.** PIN 码和密码都是“你知道的”（Something you know）的示例。“你设置的东西”不是一种因素类型。生物识别因素是“你是谁”（Something you are）的示例，物理 USB 令牌是“你拥有的”（Something you have）的常见示例。

**13. C.** 較低的交叉错误率可确保较低的误拒率和较低的误纳率。其他选项均包含较高的指标，这是不可取的。

**14. D.** 账户锁定策略在特定次数的登录失败尝试后锁定账户。这种响应类型通过阻止攻击者反复尝试直到成功登录，有助于防止暴力破解攻击。

**15. B.** 账户策略包括密码复杂性要求；防止密码重用的密码历史记录；以及一天中的时间、地理位置和控制账户要素的类似设置。账户审核检查设置和账户状态。访问策略确定谁可以使用系统或设备及其他相关项目。凭证属性是本题编造的短语，该短语未出现在 Security+ 考试大纲中。

**16. D.** OAuth 是一种协议，旨在允许用户授予第三方网站访问其信息的权限，而无需向该网站提供其密码。它通常由 OpenID 身份提供商用于提供认证和授权。Kerberos 和 RADIUS 均不符合这些要求。

**17. C.** Google Authenticator 实现基于时间的一次性密码，持续生成提供给用户的代码，这些代码会过期并持续刷新。

**18. D.** 通过上传到 GitHub 等服务导致私钥意外泄露；用户目录中私钥处理不当；使用弱密码或重复使用密码/密语；以及密钥蔓延（即密钥在组织内广泛使用），这些都是常见问题。弱加密通常不是使用 SSH 时的典型顾虑，因为 SSH 实现了现代强加密。
