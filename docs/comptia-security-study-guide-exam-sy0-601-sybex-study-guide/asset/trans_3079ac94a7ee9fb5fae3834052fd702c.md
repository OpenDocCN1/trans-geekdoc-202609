

## 第 12 章：网络安全

1.  **A.** SSL 剥离攻击的最初实现严重依赖未加密的 HTTP 连接，而 SSLStrip+ 的更新版本继续利用 HTTP 连接，并增加了将 HTTPS 链接重写为 HTTP 链接的能力，使其能更广泛地访问未加密链接。DNSSEC 和 ARP 不涉及此技术。

2.  **C.** 蜜网是一组故意暴露漏洞的系统，以便防御者可以观察攻击者的行为、技术和工具，从而帮助他们设计更好的防御措施。

3.  **B.** Telnet 提供远程命令行访问，但不安全。SSH 是 Telnet 最常见的替代品，它运行在端口 22 上。

4.  **A.** 广播风暴发生在网络中的交换机接收并重新传输广播数据包时，这会放大流量并导致严重的流量负载。生成树协议、环路预防功能和限制 VLAN 大小都可以降低广播风暴的可能性。在网络上禁用 ARP 不是 TCP/IP 网络的推荐解决方案。

5.  **D.** 不幸的是，BGP 没有原生的安全方法，BGP 劫持事件仍频频见诸报端。两种解决方案 SIDR 和 RPLS 尚未被广泛采用。

6.  **D.** Windows `pathping` 工具专门设计用于显示路由中每一跳的网络延迟和丢包情况。`tracert` 工具用于标识到远程系统的路径，`route` 命令可用于查看、添加和删除路由。`traceroute` 用于 Linux，而非 Windows。

7.  **A.** 在 Windows 系统上，`arp` 命令将使用 `/a` 标志显示系统的 ARP 缓存。其他标志包括：`/d` 用于删除缓存或单个地址（如果提供），`/s` 允许您添加条目。在大多数情况下，安全专业人员最常使用 `/a` 标志来查看系统 ARP 缓存中存在的内容。

8.  **C.** `tcpdump` 是一个命令行工具，允许 Bart 捕获并分析来自 Windows 工作站的流量。如果他没有看到三次握手，他将需要确定流量发生了什么。Wireshark 是 GUI（图形化）程序，`tcpreplay` 用于重放流量，`dd` 用于克隆驱动器。

9.  **D.** 传输层安全性 (TLS) 通常用于封装（保护）其他不安全的协议。事实上，许多安全协议只是添加了 TLS 来保护它们。ISAKMP 和 IKE 都用于 IPSec，可用于封装不安全协议，但它们不单独使用。SSL 不再使用；TLS 已几乎完全取代了它，尽管 SSL 仍常被随意称为 TLS。

10.  **A.** LDAP 的安全版本运行在 TCP 端口 636 上。IMAPS 运行在 993，SRTP 运行在 UDP 5004，SNMPv3 运行在所有版本协议使用的标准 UDP 161 和 162 端口上。

11.  **D.** 列出的协议均无法完成 Randy 的任务。事实上，不存在安全的 DHCP 或 ARP 版本，安全 LDAP 也不影响 DHCP 服务。

12.  **C.** 最终用户可以使用安全 POP (POPS)、安全 IMAP (IMAPS) 和安全 HTTP (HTTPS) 来检索电子邮件。SPF、DKIM 和 DMARC 用于识别和验证电子邮件服务器，而非供最终用户访问电子邮件。

13.  **C.** IPv6 不包含网络地址转换 (NAT)，因为可用的 IP 地址非常多。这意味着不存在 NAT 实现，因此 IPv6 不可能有不安全版本。基于静态 IPv6 地址的规则可能不起作用，因为动态地址在 IPv6 网络中被大量使用；信誉服务对于 IPv6 流量而言仍相对罕见且作用较小；IPv6 流量可能绕过许多现有的 IPv4 安全工具。

14.  **B.** 主动/主动设计将流量分散在活动节点之间，有助于确保单个节点不会不堪重负。主动/被动设计对于灾难恢复和业务连续性很有用，但它们不能直接解决单个节点上的重负载问题。存在许多负载均衡方案，但雏菊链和“鸭子、鸭子、鹅”游戏不在其中。

15.  **A.** 基于代理的准入前 NAC 将为 Isaac 提供关于机器的最大量信息，以及关于什么连接到网络和什么可能影响其他系统的最大控制权。由于系统在经过验证之前甚至不会连接到网络（甚至不会连接到隔离区或准入前区域），Isaac 将拥有更大的控制权。

16.  **C.** 虽然 `tcpdump` 可用于查看作为 VoIP 连接一部分发送的数据包，但 Wireshark 具有内置的 VoIP 分析和特定协议工具。Danielle 使用这些内置工具将获得更大的成功。网络 SIPper 是一个虚构的工具，`netcat` 不是数据包嗅探器。

17.  **B.** 中间人浏览器攻击利用恶意浏览器插件或代理在浏览器级别修改流量。它们不涉及被攻陷的路由器或服务器，修改 hosts 文件更可能涉及中间人攻击。

18.  **A.** 安全实时传输协议用于许多 VoIP 实现中的媒体流传输。UDP/S 不是实际协议，S/MIME 用于电子邮件，SFTP 是 FTP 的替代品，通常不与 VoIP 系统相关联。

19.  **A.** DNSSEC 不加密数据，但依赖数字签名来确保 DNS 信息未被修改，且来自域名所有者信任的服务器。DNSSEC 不保护机密性，这是将其作为安全选项讨论时必须记住的关键点。TLS、IPSec VPN 或通过 AES 加密都是保护网络数据机密性的潜在解决方案。

20.  **C.** 带外管理将交换机、路由器或其他设备的管理接口放在单独的网络上，或要求直接连接到设备以访问和管理它。这确保了拥有网络访问权限的攻击者无法更改网络设备。NAC 和端口安全有助于保护网络本身，而汇聚链路用于将多个接口、VLAN 或端口组合在一起。

## 第 13 章：无线与移动安全

1.  **B.** microSD 规格的硬件安全模块 (HSM) 允许 Android 手机等移动设备安全地存储和管理证书。Alyssa 还需要一个应用程序来访问和使用 HSM，但她将拥有一个完整、便携且安全的解决方案来满足她的 PKI 需求。SEAndroid 允许在 Android 设备上强制执行强制访问控制。TPM 连接到系统，通常集成在主板上或作为插拔模块添加，而非无线组件。MDM 不是安全的硬件解决方案，而是用于管理移动设备的软件解决方案。

2.  **D.** 使用容器化系统可以允许 Fred 的用户在安全环境中运行企业应用程序并使用企业数据，该环境无法被设备上容器外的其他应用程序访问。移动设备的容器化方案通常使用加密和其他隔离技术来确保数据和应用程序不发生跨越。生物识别和上下文感知认证有助于确保正确的用户正在使用设备，但不提供这种隔离。全设备加密有助于降低设备被盗或丢失导致数据泄露的风险。
