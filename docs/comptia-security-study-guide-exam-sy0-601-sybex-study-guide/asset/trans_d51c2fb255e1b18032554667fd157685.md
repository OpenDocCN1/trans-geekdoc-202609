
# 保护嵌入式和专用系统

由于 ICS 和 SCADA 系统将运行通用操作系统的通用计算机与带有嵌入式系统和传感器的工业设备相结合，因此它们呈现出复杂的安全概况，供安全专业人员进行评估。在许多情况下，必须将它们作为单独的组件来处理，以确定其独特的安全需求，包括定制的工业通信协议和专有接口等。一旦这些单独的组件被绘制并理解，它们的交互以及整个系统或主要组件的安全模型就可以被设计和管理。

在保护此类复杂系统时，需要牢记的一个关键点是，它们在设计时往往未考虑安全性。这意味着增加安全措施可能会干扰其功能，或者安全设备可能不适合添加到该环境中。在某些情况下，隔离和保护 ICS、SCADA 和嵌入式系统是你能采用的最有效的安全模型之一。

## 保护物联网

物联网 是一个宽泛的术语，用于描述用于自动化、传感、安全和类似任务的网络连接设备。IoT 设备通常是一种嵌入式系统，但许多设备利用机器学习、AI、云服务和类似功能等技术来提供“智能”特性。

IoT 设备带来许多安全和隐私问题，安全分析师必须了解这些常见问题：

*   不良的安全实践，包括弱默认设置、缺乏网络安全（防火墙）、暴露或易受攻击的服务、数据传输缺乏加密、弱认证、使用嵌入式凭据、不安全的数据存储，以及其他各种不良实践。
*   短暂的支持生命周期——IoT 设备可能不会被修补或更新，导致它们在大部署生命周期内都可能处于易受攻击状态。
*   供应商数据处理实践问题，包括许可和数据所有权顾虑，以及在设备所有者不知情的情况下，向供应商的员工和合作伙伴以及政府和其他机构泄露数据的可能性。

尽管存在这些安全顾虑，传感器、楼宇和设施自动化设备、可穿戴设备以及其他智能设备等 IoT 设备仍在持续普及。安全专业人员必须同时考虑其组织采购的 IoT 设备，以及员工和访客可能带入其设施的设备。

## 专用系统

你需要为 Security+ 考试考虑的嵌入式系统的最后一类是专用系统：

*   **医疗系统**，包括医院和医生办公室中的设备，可能联网或具有嵌入式系统。心脏起搏器、胰岛素泵和其他体外或植入式系统等医疗设备也可能遭到攻击，针对通过蓝牙攻击心脏起搏器的漏洞利用代码已在野外存在。
*   **智能电表**被部署用于追踪公用事业使用情况，并带有由公用事业公司管理的无线控制网络。由于电表现在可以远程访问和控制，它们提供了新的攻击面，可能会干扰电力、水或其他公用事业，或提供有关设施或建筑物的信息。
*   **车辆**，从汽车到飞机甚至海上船舶，现在都已联网，且经常直接连接互联网。如果它们没有得到妥善保护，或者支持它们的后端服务器和基础设施存在漏洞，攻击者可以接管、监控或以其他方式严重影响它们。
*   **无人机和自动驾驶汽车**，以及类似的车辆，可能通过互联网或无线指挥信道进行控制。加密其指挥和控制信道，并确保它们在连接互联网或网络时具有适当的控制措施，对其安全至关重要。
*   **VoIP 系统**包括后端服务器以及部署在组织内各办公桌和工作地点的 VoIP 电话和设备。电话本身是一种嵌入式系统，拥有可成为攻击目标且可能易受攻击的操作系统。一些电话还提供允许直接远程登录或管理的接口，使其容易受到来自 VoIP 网络的攻击。分割网络以保护潜在易受攻击的 VoIP 设备、定期更新它们以及应用设备的基线安全标准，有助于保持 VoIP 系统安全。
*   **打印机**，包括多功能打印机（MFP），通常内置网络连接。无线和有线网络接口提供对打印机的直接访问，且许多打印机具有不良的安全模型。打印机已被用作访问受保护网络的入口点、反射和放大攻击的工具，以及收集信息的手段。事实上，MFP、复印机和其他扫描并可能存储来自传真、打印件和复印件信息的设备，使这些设备除了作为易受攻击的网络设备可充当攻击中的反射器和放大器，或作为攻击者的跳板点的风险外，还成为潜在的重大数据泄露风险。
*   **监控系统**，如摄像头系统和用于安全但也联网的相关设备，可能为攻击者提供窥视设施或组织内部情况的视角。摄像头提供通常可通过 Web 界面访问的嵌入式接口。
*   默认配置、漏洞、缺乏修补等问题在专用系统中很常见，这与其他嵌入式系统非常相似。当你评估专用系统时，既要考虑如何限制这些潜在问题的影响，也要考虑为你的组织处理它们所需的管理、行政和事件响应流程。

## 通信考量

许多嵌入式和专用系统运行在传统有线和无线网络不可用的环境中。作为安全专业人员，你可能需要考虑用于嵌入式系统的不同类型的连接。

蜂窝连接，包括现有的 LTE 和其他第四代技术以及较新的 5G 网络连接，可以在 Wi-Fi 网络无法工作的许多位置为嵌入式系统提供高带宽访问。由于第三方蜂窝供应商负责连接，使用蜂窝连接的嵌入式系统需要得到保护，以使蜂窝网络不对其运行构成威胁。确保它们不通过蜂窝连接暴露易受攻击的服务或应用程序，对其安全至关重要。构建保护措施以防止网络漏洞利用跨越内部安全边界（如无线连接与本地控制总线之间的边界）也是一项必要的设计特性。

物理上保护内置在蜂窝设备中的用户身份模块（SIM）可能非常重要。关于 SIM 卡被取出并被重新利用的案例（包括被获取后产生巨额数据费用）经常见诸媒体。SIM 卡克隆攻击还可能允许攻击者冒充嵌入式系统，从而以受信任系统的身份发送和接收信息。
