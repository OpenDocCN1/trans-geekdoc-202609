
# 身份欺诈

*身份欺诈*，或称身份盗窃，是指使用他人的身份。虽然身份欺诈通常被恶意行为者用于谋取经济利益，但它也可能作为渗透测试或其他安全工作的一部分被使用。事实上，在某些情况下，*冒充*，即表现得好像你是另一个人，可以是一种有限形式的身份欺诈。在其他情况下，冒充则不那么具体，使用它的社会工程师或攻击者可能只是假装成一名快递员或服务提供商的员工，而不是声称拥有某个特定身份。

除了这些更直接的个人互动外，*骗局*也是常见现象。骗局是故意的谎言，形式多样，从病毒骗局到假新闻。社交媒体在许多现代骗局中扮演着重要角色，攻击者和社会工程师可能会利用当前的骗局来辅助他们的社会工程尝试。

最后一种欺诈类型是*发票诈骗*，即向组织发送虚假发票，希望收到付款。发票诈骗可以是实体的，也可以是电子的，它们依赖于收件人不去核实发票是否合法。

## 侦察与冒充

社会工程学是收集信息的绝佳方式，因此常被用作侦察工作的一部分。社会工程学可用于电话、电子邮件和其他联系方式中，以获取比公开可用信息更多的目标信息。同时，现场和面对面的侦察工作使用社会工程学技术来获取访问权限、收集信息，并绕过安全系统和流程。

## 影响力战役

随着网络战和传统战争以更深层、更有意义的方式持续交叉重叠，在线*影响力战役*（传统上专注于*社交媒体*、电子邮件和其他在线为中心的媒介）已成为所谓*混合战争*的一部分。尽管混合战争的正式定义仍在演变，但普遍认为它包括低于冲突门槛的竞争，这可能包括网络战等主动措施，以及宣传和信息战。

然而，影响力战役本身并非网络战的专属领域。个人和组织开展影响力战役，以将舆论引导至他们期望的方向。甚至广告活动也可被视为一种影响力战役，但总体而言，大多数影响力战役都与虚假信息战役相关联。针对 Security+ 考试，你应该了解影响力战役与社交媒体作为各类民族国家行为体混合战争努力一部分时紧密耦合的角色。

# 密码攻击

虽然社会工程学常被用于获取密码或访问权限，但还有其他攻击密码的方法。从在暴力破解攻击中逐个尝试密码，到利用预计算密码哈希的查找系统将获取的密码哈希与已知数据库进行核对的技术性攻击，均可帮助攻击者和渗透测试人员攻击密码。

Security+ 考试重点关注几种关键的密码相关攻击：

*   **暴力破解攻击**，即遍历密码直到找到有效的一个。实际的暴力破解方法可能比单纯使用密码列表更复杂，通常涉及使用常见密码的字典、专门挑选的目标可能使用的词汇，以及用于应对复杂性规则的修改规则。无论其输入多么优雅或经过深思熟虑，暴力破解归根结底只是一个尝试不同变体直到成功的过程。

*   **密码喷射**攻击是一种暴力破解攻击形式，它尝试对许多账户使用单个密码或一小组密码。如果你知道目标使用特定的默认密码或一组密码，这种方法可能特别有效。例如，如果你要攻击一支运动队的粉丝网站，粉丝的常见口号、知名球员的名字以及其他与该队相关的常用术语可能是密码喷射攻击的良好候选对象。

*   **字典攻击**是另一种暴力破解攻击形式，它使用单词列表进行尝试。常见的暴力破解字典广泛可用，像 `John the Ripper` 这样流行的开源密码破解工具内置了单词列表（字典）。许多渗透测试人员会在其情报收集和侦察过程中构建自己的自定义字典。

无论采用何种密码攻击机制，攻击方法之间的一个重要区别在于它们是**在线**发生（因此针对可能设有防御措施的实时系统），还是**离线**针对被攻破或捕获的密码存储进行。如果你能从密码存储中捕获哈希密码，**彩虹表**等工具会非常有用。彩虹表是一个易于搜索的数据库，包含使用与捕获的密码文件相同哈希方法预计算的哈希值。因此，如果你捕获了一组使用 MD5 哈希的密码，你可以为大多数合理的密码长度计算甚至购买一整套密码，然后只需在表中查找这些密码的哈希值即可。

如果你捕获了密码文件，也可以对其使用**密码破解器**。如[图 4.1](#c04.xhtml#c04-fig-0001)所示，`John the Ripper` 等密码破解器尝试通过针对多种常见密码存储格式进行暴力破解和字典攻击来破解密码。

**图 4.1** John the Ripper

`John the Ripper` 等密码破解工具也可用作密码评估工具。一些组织继续定期使用密码破解器对其密码存储进行测试，以检查弱密码和易被破解的密码。在许多情况下，MFA 的使用配合密码复杂性要求已很大程度上取代了这一评估过程，这一趋势可能会持续下去。

当然，并非每个系统都维护良好，渗透测试人员或攻击者最喜欢的机会是找到**明文**或**未加密密码**以获取。如果没有某种形式的保护，仅以列表形式维护的密码很容易被即使是最随意的攻击者获取并重复使用。如前所述，使用强密码哈希机制，以及使用盐和胡椒（在哈希前添加到密码中的额外数据，使得彩虹表等工具更难使用）等技术，有助于保护密码。事实上，密码存储的最佳实践不依赖加密；它们依赖于永不存储密码，而是使用精心构造的密码哈希在登录时验证密码。

# 物理攻击

社会工程学和现场渗透测试往往相辅相成，因此社会工程学的物理层面拥有自己的一套工具和技术。Security+ 考试大纲涵盖了几个最常见的示例，你需要了解其中的每一个以备考。

**恶意闪存驱动器**攻击主要分为两类。渗透测试人员（以及潜在的攻击者）可能会在目标组织毫无戒备的受害者容易捡到并插入的位置丢弃驱动器。有时会通过在驱动器上贴上引人注目的标签来增加一层社会工程学手段，使其更有可能被插入：绩效评估、财务规划或其他会诱惑受害者的关键词。
