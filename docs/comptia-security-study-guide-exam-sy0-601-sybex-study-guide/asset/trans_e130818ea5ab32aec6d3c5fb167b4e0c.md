

# 端点安全：专用系统与嵌入式系统

端点安全的最后一个组成部分是组织如何保护专用系统和嵌入式系统。物联网、SCADA、ICS 及其他设备无处不在，广泛分布于组织的医疗系统、智能电表、车辆、工业流程与制造设备、无人机、智能设备以及许多其他场所。鉴于这些设备通常能力有限、采用不同的安全模型，且拥有许多其他特殊需求，保护嵌入式系统需要额外的关注和规划，以确保其保持安全状态。

## 考试要点

**系统加固与保护依赖安全工具和技术来维持系统安全。** 保护端点设备需要考虑设备的方方面面：其启动方式、数据如何保护、如何配置、提供何种服务、通信是否安全，以及如何防御网络威胁。幸运的是，安全专业人员拥有大量工具，包括安全启动和可信启动，可用于防范针对启动过程或驱动程序的攻击。`Antivirus`（防病毒）、`antimalware`（反恶意软件）、`sandboxes`（沙箱）、`allow lists`（允许列表）和 `deny lists`（拒绝列表）可控制在端点上运行的应用程序和程序。`Endpoint detection and response`（端点检测与响应）和 `data loss prevention`（数据丢失防护）工具等，能深入洞察系统活动及潜在问题所在，同时增加管理员和安全专业人员可用的控制手段，以保障系统和数据安全。`host intrusion prevention and detection systems`（主机入侵防御与检测系统）、`host firewalls`（主机防火墙）等网络安全工具能检测并通常能阻止来自网络的攻击。

**端点加固还依赖配置、设置、策略和标准来确保系统安全。** 虽然工具和技术对保护端点很重要，但配置和设置也是该过程的重要组成部分。禁用不必要的服务、更改 `Windows registry`（Windows 注册表）中的设置或 `Linux` 中的操作系统设置，以及以其他方式使用内置配置选项，使安全配置与设备的风险概况相匹配，至关重要。组织还使用命名和 `IP` 寻址标准来管理、追踪和控制其环境中的端点。最后，对操作系统和设备上安装的应用程序进行 `patch management`（补丁管理），可防范已知漏洞和问题。

**驱动器加密和清理有助于防止数据泄露。** 加密驱动器和介质有助于在它们被盗或丢失时保持其安全。`Full-disk encryption`（全盘加密）覆盖整个驱动器，而 `volume`（卷）或 `file encryption`（文件加密）则保护内容的特定部分。对驱动器和介质进行清理涉及使用安全删除流程擦除它们，或将其销毁，以确保数据无法恢复。根据数据的安全要求以及所涉及的驱动器或介质类型使用适当的流程，对于确保数据被妥善移除至关重要。

**安全分析师需要熟悉命令行工具、Shell 和安全传输协议。** `Security+` 考生需要了解命令行工具的基础知识，包括 `head`、`tail`、`cat` 和 `grep`，这些工具允许你操作和查看文本文件。使用 `chmod` 管理权限以及通过 `logger` 向日志文件添加信息，也是安全专业人员需要熟悉的任务。除了这些工具，同样重要的是通过 `SSH` 使用安全 Shell、使用 `OpenSSL` 保护传输中的数据，以及了解 `Python` 和 `PowerShell` 等脚本语言，以及何时以及为何可能会使用它们。

**SCADA、ICS 和 IoT 系统等专用系统遍布整个组织，需要独特的安全解决方案。** `SCADA` 和 `ICS`（工业控制系统）用于管理和监控工厂、发电厂以及现代企业的许多其他主要组件。`IoT`（物联网）系统是连接互联网的设备，执行从监控到家庭自动化等各种任务。它们可能由第三方控制，或具有其他安全隐患，必须将其作为安全计划的一部分加以解决，以保持每个端点的安全。

**嵌入式系统具有独特的安全约束。** 嵌入式系统通常比传统系统拥有更少的计算能力、内存和存储。有限的资源意味着嵌入式系统可能没有资源提供加密、防病毒或其他安全功能，并且可能无法记录数据。某些嵌入式系统没有网络连接，或者它们可能使用专用通信协议进行通信，这使得远程修补和管理变得困难。嵌入式系统使用的操作系统和软件通常不具备桌面或移动操作系统的相同功能，并且可能缺乏身份验证能力或传统系统中预期的其他关键功能。

## 复习题

1.  Charles 想通过命令行实时监控日志文件的变化。以下哪种 Linux 命令行工具能让他看到日志文件变化时的最后几行？
    1.  `logger`
    2.  `tail`
    3.  `chmod`
    4.  `head`

2.  Naomi 在一台想要加固的系统上发现了以下开放的 TCP 端口。哪些端口用于不安全服务，因此应被禁用以允许其安全的替代服务继续使用？
    *   21
    *   22
    *   23
    *   80
    *   443
    1.  21, 22, and 80
    2.  21 and 80
    3.  21, 23, and 80
    4.  22 and 443

3.  Frank 的组织正准备部署数据丢失防护 (DLP) 系统。在部署前，他们应进行哪项关键流程？
    1.  为所有非敏感数据定义数据生命周期。
    2.  加密所有敏感数据。
    3.  实施并使用数据分类方案。
    4.  使用创建者或所有者的名称标记所有数据。

4.  Theresa 所在的公司部署了带有内置蜂窝调制解调器的 IoT 传感器，用于通信回传至中央服务器。如果攻击者能够访问这些设备，可能会发生什么问题？
    1.  攻击者可能会更改设备使用的基带频率，导致其失效。
    2.  攻击者可能会将设备切换到窄带无线电模式，从而限制蜂窝调制解调器的范围。
    3.  攻击者可能会从设备中窃取 SIM 卡并将其用于自己的目的。
    4.  攻击者可能会克隆设备中的 SIM 卡，以对一次性密码系统发起攻击。

5.  以下哪项不是 MFP 的典型安全顾虑？
    1.  复印和扫描导致的敏感数据泄露
    2.  充当网络攻击的反射器
    3.  充当网络攻击的放大器
    4.  使用弱加密

6.  Michelle 想防止未经授权的应用程序被安装在系统上。她可以使用哪类工具仅允许安装获许可的应用程序？
    1.  加固应用程序
    2.  允许列表应用程序
    3.  拒绝列表应用程序
    4.  HIPS

7.  以下哪个术语用于描述专注于检测和响应桌面、笔记本电脑和移动设备等端点上可疑活动的工具？
    1.  EDR
    2.  IAM
    3.  FDE
    4.  ESC

8.  以下哪项通常不是 SoC 的组成部分？

    2.  显示器

    1.  Python

10. Amanda 正在评估一辆车的内部网络。她最有可能发现哪种总线连接着其内部传感器和控制器？
     1.  窄带总线
