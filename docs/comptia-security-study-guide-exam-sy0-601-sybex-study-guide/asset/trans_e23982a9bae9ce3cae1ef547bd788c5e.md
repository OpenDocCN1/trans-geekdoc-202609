# 作者简介

**Mike Chapple, Ph.D., CISSP, Security+** 是畅销书 *CISSP (ISC)² Certified Information Systems Security Professional Official Study Guide*（Sybex, 2021）和 *CISSP (ISC)² Official Practice Tests*（Sybex, 2021）的作者。他是一位拥有二十年高等教育、私营部门和政府领域经验的信息安全专业人士。

Mike 目前担任圣母大学 Mendoza 商学院 IT、分析与运营系的教学教授，讲授网络安全、数据管理和商业分析的本科及研究生课程。

在重返圣母大学之前，Mike 曾担任 Brand Institute 的执行副总裁兼首席信息官，该公司是一家总部位于迈阿密的营销咨询公司。Mike 还曾在国家安全局的信息安全研究组工作四年，并曾在美军空军担任现役情报官。

Mike 是 *Information Security Magazine* 的技术编辑，著有 25 余本书。他获得了圣母大学计算机科学与工程学士和博士学位。Mike 还拥有爱达荷大学计算机科学硕士学位和奥本大学 MBA 学位。Mike 持有网络安全分析师+ (CySA+)、Security+、注册信息安全经理 (CISM)、注册云安全专家 (CCSP) 和注册信息系统安全专家 (CISSP) 认证。

在他的网站 `CertMike.com` 了解更多关于 Mike 及其其他安全认证材料的信息。

**David Seidl** 是迈阿密大学的信息技术副总裁兼 CIO。在他的 IT 职业生涯中，他曾担任多种技术和信息安全角色，包括担任圣母大学的校园技术服务高级总监，在那里他共同领导了圣母大学的云迁移，并监督云运营、ERP、数据库、身份管理以及广泛的其他技术和服务。他还曾担任圣母大学的信息安全总监，领导圣母大学的信息安全计划。他曾作为圣母大学 Mendoza 商学院的讲师教授信息安全和网络本科课程，并撰写了关于安全认证和网络战的书籍，包括合著 *CISSP (ISC)² Official Practice Tests*（Sybex, 2021）以及本书和配套书籍 *CompTIA CySA+ Practice Tests: Exam CS0-001* 的前几个版本。

David 拥有东密歇根大学的通信技术学士学位和信息安全硕士学位，以及 CISSP、CySA+、Pentest+、GPEN 和 GCIH 认证。
