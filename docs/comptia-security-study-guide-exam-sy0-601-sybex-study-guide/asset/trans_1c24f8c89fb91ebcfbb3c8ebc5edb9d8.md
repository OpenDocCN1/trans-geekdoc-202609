框架实施评估组织在多大程度上能够满足网络安全目标。[表 16.1](#c16.xhtml#c16-tbl-0001) 显示了框架实施层级及其标准。这种方法是*成熟度模型*的一个示例，它描述了组织在进步连续体上的当前和期望定位。在 NIST 成熟度模型中，组织被分配到四个成熟度模型层级之一。

框架概况描述了特定组织可能如何处理框架核心所涵盖的安全功能。组织可能使用框架概况来描述其当前状态，然后使用单独的概况来描述其期望的未来状态。

NIST 网络安全框架为组织提供了一种合理的方法，用于开发和评估其网络安全计划的状态。

### NIST 风险管理框架

除了 CSF，NIST 还发布了风险管理框架 (RMF)。RMF 是联邦机构的强制性标准，提供了一个正式化流程，联邦机构必须遵循该流程来选择、实施和评估基于风险的安全和隐私控制。[图 16.5](#c16.xhtml#c16-fig-0005) 提供了 NIST RMF 流程的概览。更多详情请参阅 NIST SP 800-37《信息系统和组织风险管理框架》 (`nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-37r2.pdf`)

### ISO 标准

*国际标准化组织 (ISO)* 发布了一系列标准，为网络安全和隐私提供最佳实践。在备考 Security+ 考试时，你应该熟悉四个特定的 ISO 标准：ISO 27001、ISO 27002、ISO 27701 和 ISO 31000。

#### ISO 27001

*ISO 27001* 是一份标准文件，标题为“信息技术——安全技术——信息安全管理体系——要求”。该标准包含涵盖 14 个类别的控制目标：

*   信息安全策略
*   信息安全组织
*   人力资源安全
*   资产管理
*   访问控制
*   密码学
*   物理和环境安全
*   运营安全
*   通信安全
*   系统获取、开发和维护
*   供应商关系
*   信息安全事件管理
*   业务连续性管理的信息安全方面
*   符合内部要求（如策略）和外部要求（如法律）

ISO 27001 标准曾是最常用的信息安全标准，但在要求 ISO 合规的高度监管行业之外，其普及度正在下降。这些行业中的组织可以选择正式采用 ISO 27001 并寻求*认证*计划，由外部评估机构验证其对标准的合规性，并认证其按照 ISO 27001 运行。

#### ISO 27002

*ISO 27002* 标准超越了控制目标，描述了组织可为满足网络安全目标而实施的实际控制措施。ISO 设计这份补充文档是为了满足以下组织的需求：

*   选择信息安全控制措施
*   实施信息安全控制措施
*   制定信息安全管理指南

#### ISO 27701

ISO 27001 和 ISO 27002 侧重于网络安全控制措施，而 *ISO 27701* 包含管理隐私控制措施的标准指南。ISO 将此文档视为其 ISO 27001 和 ISO 27002 安全标准的扩展。

#### ISO 31000

*ISO 31000* 为风险管理计划提供指南。该文档不特定于网络安全或隐私，而是以通用方式涵盖风险管理，以便应用于任何风险。
