# 第 12 章 网络安全

网络是组织的核心，负责传输数据并支持我们赖以开展业务的服务。这使它们成为攻击者的主要目标，也是防御架构和设计中的关键层。

在本章中，您将了解安全网络设计中的重要概念和要素，例如基于风险和安全要求的网络分段和区域划分。您还将探索保护措施，如端口安全、端口跨越和镜像以进行数据收集，以及如何使用 VPN 保护网络流量，即使在遍历不受信任的网络时也是如此。

接下来，您将了解网络设备和安全设备。跳板机/跳板服务器、负载均衡器及其调度技术和功能模型、代理服务器、URL 和内容过滤器，以及各种其他网络安全工具和选项构成了本章的中间部分。

了解了设备和设计概念后，您将继续学习如何在管理层面上管理和保护网络，包括带外管理技术、访问控制列表和服务质量选项。您还将了解路由安全问题对安全专业人员和网络管理员的意义。随后，您将探索 DNS 安全、传输层安全的作用及其利用临时密钥实现完美前向保密的机制，以及监控在网络安全中的作用。最后，您将研究欺骗和中断策略，这些策略可以帮助您了解攻击者将在您的网络中尝试什么，以及当他们捕获并试图提取数据时如何检测他们。

在了解了管理工具之后，您将继续探索安全协议及其用途，包括用于实时流媒体、安全邮件和 Shell 访问的协议，以及各种其他选项。您将学习如何根据其服务端口和协议识别安全协议，它们能做什么和不能做什么，以及它们在现代网络中如何被频繁使用。

一旦涵盖了工具和技术，您将回顾常见的网络攻击，如中间人攻击、DNS 攻击、第 2 层攻击、分布式拒绝服务 (DDoS) 攻击和运营技术 DDoS 攻击，以及如何检测并有时阻止它们。

本章的最后一部分将向您介绍各种用于网络侦察和发现的重要工具，以及利用这些工具的技术。您将探索如何追踪数据包路由、收集有关系统和设备及其网络配置和流量模式的信息、扫描服务和漏洞、传输数据、收集开源情报，以及捕获和分析数据包和网络流量。

## 设计安全网络

作为安全专业人员，您必须理解并能够实施企业网络中关键的设计和架构要素，以便妥善保护它们。您需要知道部署了哪些工具和系统以及原因，还要知道如何将它们作为分层安全设计的一部分进行部署。

大多数环境中的安全设计依赖于**纵深防御**的概念。换句话说，它们围绕多重控制构建，旨在确保单个控制（甚至多个控制）的失效不太可能导致安全漏洞。在备考时，请考虑如何使用这些组件构建有效的纵深防御设计，以及如何实施它们以确保故障或错误不会使组织面临更大的风险。

牢记纵深防御，了解网络也是分层构建的会有所帮助。开放系统互连 (OSI) 模型用于概念性地描述设备和软件如何通过网络协同工作。除了概念层面，设计人员还将使用在信任边界分离网络的设备创建安全区域，并部署适合每个安全区域的威胁和安全要求的保护措施。
