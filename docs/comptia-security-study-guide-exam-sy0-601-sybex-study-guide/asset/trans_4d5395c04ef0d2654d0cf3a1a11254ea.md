
IP 扫描工具还有许多其他选择，范围从使用 `netcat` 测试开放端口的简单选项，到 Angry IP Scanner 和 Spiceworks IP Scanner 等完整工具。还有许多其他工具存在，并且可能在你合作的组织中被使用。它们都基于相似的原则运行：它们尝试连接系统，然后连接到它们配置扫描的每个 IP 地址或系统上的每个端口，并报告发现的内容。

### 数据传输和通用工具

`netcat` 常被称为网络界的“瑞士军刀”，因为它可用于多种用途。它也是一个非常小的程序，这意味着它可以轻松传输到可能需要 `netcat` 这类工具的系统上。`netcat` 可用于抓取横幅以确定服务类型等简单用途。它可以提供本地或远程 Shell，允许与服务建立原始连接，传输文件，并允许你与 Web 服务器交互。

使用 `netcat` 连接服务非常简单：

```
nc [hostname] [port]
```

随后可以直接发出 SMTP 或 HTTP 等命令。

`netcat` 既可以充当监听器，也可以充当客户端，从而允许执行 Shell 操作或文件传输。使用 `netcat` 进行文件传输首先需要设置一个监听器：

```
nc -lvp [port] > /home/example/file.txt
```

然后使用 `netcat` 下载文件很简单：

```
nc [listener IP] [port] < /file/location/for/download/file.txt
```

`netcat` 用途广泛，意味着它可用于许多目的。你甚至可以用 `netcat` 进行端口扫描！

`curl` 实用程序常见于 Linux 系统，用于通过 URL 传输数据。这意味着它常被用于手动执行 HTTP `get` 等 HTTP 命令，或获取 HTTP 头部。它也可用于通过 FTP、FTPS 和 SFTP 传输文件，以及用于各种使用 URL 的协议的通用目的。使用 HTTP `get` 检索页面的示例 `curl` 命令如下：

```
curl --request GET https://www.example.com
```

此类别中的最后一个通用工具是 `hping`，一种用于组装和分析 TCP/IP 数据包的工具。渗透测试人员和安全分析师有时需要构建自定义数据包来测试问题或漏洞，或查看防火墙是否会正确响应。使用 `hping` 进行分析还可以提供操作系统指纹识别等信息，或根据数据包详情帮助推测系统上线时长。它适用于 Linux 和 Windows，使其成为在各种情况下都有用的工具。

### OSINT 和数据收集工具

`theHarvester` 是一款开源情报收集工具，可利用 LinkedIn、Google、Bing 和百度等搜索引擎、PGP 服务器及其他来源，检索电子邮件账户、域名、用户名和其他详细信息。`theHarvester` 可从命令行运行，并提供域名或 URL 以及要使用的搜索引擎。[图 12.8](#c12.xhtml#c12-fig-0207) 显示了我们的出版商 Wiley（Sybex 的母公司）的结果。Google 搜索提供主机列表，使用 LinkedIn 会返回员工姓名，其他搜索引擎可能提供额外数据。

![FIGURE 12.8 theHarvester output for wiley.com](images/c12f008.png)

[**图 12.8**](#c12.xhtml#R_c12-fig-0207) `wiley.com` 的 `theHarvester` 输出

收集情报的另一种方法是使用 `scanless`，这是一种利用第三方扫描器收集信息的端口扫描器。`scanless` 工具利用 viewdns、yougetsignal 和 spiderip 等端口扫描器。`scanless` 随后使用这些工具运行端口扫描，而不会暴露运行扫描的系统作为扫描源。基本命令行很简单，返回的端口扫描数据非常类似于 `nmap` 扫描，输出取决于你选择的扫描工具：

```
scanless -s [chosen scanning site] -t target
```

重要的是要注意，`scanless` 将从组织外部运行，而非内部，因此结果看起来会与从受信任或安全边界内的工作站运行扫描时不同。

列表中的下一个工具是 `Sn1per`，一款自动化扫描工具，它为渗透测试人员结合了多种工具，包括通过 WhoIs、DNS 和 ping 进行侦察；端口扫描和枚举；Metasploit 和 `nmap` 自动化；以及暴力破解以尝试自动获取目标访问权限。`theHarvester` 专注于开源情报，而 `Sn1per` 旨在执行自动化渗透测试。

Security+ 考试大纲中用于信息收集的最后一个工具是 `DNSEnum`。该工具用于查找域的 DNS 服务器和条目，可指定查询特定 DNS 服务器，或默认使用运行该工具的系统所依赖的 DNS 服务器。[图 12.9](#c12.xhtml#c12-fig-0008) 显示了针对 `wiley.com` 的 `dnsenum` 命令。请注意，你可以看到主域名服务器、`wiley.com` 的主机地址，以及依赖 FireEye 云服务过滤邮件的 MX 服务器。正如通常从妥善保护的 DNS 服务器预期的那样，两个主域名服务器都拒绝允许 `DNSEnum` 执行区域传送。

此类信息收集工具可以帮助网络管理员和安全专业人员检查其自身网络的配置，也可以帮助渗透测试人员（或攻击者）收集有关目标的信息。作为安全专业人员，你应该了解这些工具及其提供的信息类型，以便选择合适的工具收集所需信息。

### 数据包捕获和重放

对于需要识别攻击、执行被动侦察，并在渗透测试期间记录其在网络上自身行动的安全专业人员来说，捕获和分析网络流量的能力非常重要。许多 Linux 和 Unix 系统默认提供 `tcpdump`，这是一款命令行数据包捕获工具。它可以使用各种过滤和输出选项捕获数据包。由于网络流量可能很大，使用 `tcpdump` 捕获到文件通常是个好主意。一个典型的 `tcpdump` 命令行，用于将 Linux 系统主网络接口上 TCP 端口 80 的流量捕获到 PCAP 文件，如下所示：

```
tcpdump -w capture.pcap -i eth0 tcp port 80
```

[**图 12.9**](#c12.xhtml#R_c12-fig-0008) `DNSEnum` 输出 `wiley.com`

你还可以按源和目标 IP 捕获数据包、从文件读取，并执行其他对安全从业者有用的操作。[图 12.10](#c12.xhtml#c12-fig-0888) 显示了使用 `tcpdump` 捕获 `nmap` 对系统进行端口扫描期间流量片段的示例。请注意，`nmap` 会随机化扫描中的端口以避免线性扫描，但这样的捕获文件允许你快速注意到系统正在接收一系列连接，这些连接快速测试端口然后结束，而没有后续流量。
