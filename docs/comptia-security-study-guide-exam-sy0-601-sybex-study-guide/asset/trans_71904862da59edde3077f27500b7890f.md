

# Wi-Fi

Wi-Fi 设备最常部署在自组网模式或基础设施模式下。自组网模式允许设备直接相互通信，而基础设施模式则通过基站或接入点发送流量。Wi-Fi 网络使用服务集标识符（`SSIDs`）来标识其网络名称。`SSIDs` 可以广播，也可以设为私有。

## Bluetooth

**蓝牙**是一种短距离无线标准。与 Wi-Fi 和许多其他技术一样，它在 2.4 GHz 频段运行，该频段被许多不同的无线协议使用。蓝牙主要用于低功耗、短距离（小于 100 米，通常为 5–30 米）的连接，这些连接没有很高的带宽需求。蓝牙设备通常采用点对点模式而非客户端-服务器模式进行连接。

由于蓝牙的设计和实现旨在易于发现、配置和使用，因此它也相对容易受到攻击。蓝牙确实支持加密，但加密依赖于双方设备使用的 PIN 码。耳机等设备的固定 PIN 码会降低其连接的安全性。针对认证以及协商加密密钥的攻击意味着蓝牙可能容易受到窃听以及其他攻击。

## NFC

**近场通信（NFC）**用于设备之间极短距离的通信。您可能见过 NFC 用于支持 Apple Pay 或 Google Wallet 的支付终端，通过手机进行支付。NFC 的范围限制在约 4 英寸左右，这意味着它不用于构建设备网络，而是主要用于低带宽、设备对设备的用途。这并不意味着 NFC 不会受到攻击，但这确实意味着威胁通常会来自靠近 NFC 设备的近距离。拦截 NFC 流量、重放攻击和欺骗攻击都是 NFC 实现需要考虑的问题。同时，NFC 设备必须确保仅在期望时响应查询，以免攻击者仅将接收器移入范围内即可激活 NFC 事务或响应。

## RFID

**射频识别（RFID）**是一种相对短距离（从某些被动标签的不到一英尺，到主动标签的约 100 米）无线技术，它使用标签和接收器来交换信息。RFID 可以使用主动标签、半主动标签或被动标签部署。主动标签拥有自己的电源，并始终发送信号供读取器读取；半主动标签有电池为其电路供电，但由读取器激活；被动标签则完全由读取器供电。

RFID 标签还使用三个频段之一。低频 RFID 用于短距离、低功耗标签，常用于门禁和身份识别，由附近的读取器扫描。低频 RFID 在世界各地并不统一，这意味着标签可能不符合其他国家的频率或功率要求。高频 RFID 标签在正常情况下可读范围较长，可达一米，且通信速度更快。事实上，高频 RFID 用于近场通信，许多标签支持只读、只写和可重写标签。最后一个频段是超高频 RFID，读取速度最快，范围最长。这意味着高频 RFID 标签用于读取器需要更远距离的场景。高频标签已广泛应用于库存管理和防盗目的，以及许多其他需要从几米外远程查询标签的用途中。

由于体积小、形态灵活，RFID 标签可以嵌入贴纸、用于识别宠物的小型可植入芯片，以及收费站标签等设备形式中。RFID 标签可能以多种方式受到攻击，从简单的破坏或损坏标签使其无法读取，到修改标签（某些标签可重新编程）。标签可能被克隆、修改或欺骗；读取器可能被冒充；流量可能被捕获。

## Infrared

与本章中的其他无线技术不同，**红外（IR）**网络连接仅在视线范围内工作。IR 网络规范支持从极低带宽模式到千兆速度的各种模式，包括：

*   `SIR`，115 Kbit/s
*   `MIR`，1.15 Mbit/s
*   `FIR`，4 Mbit/s
*   `VFIR`，16 Mbit/s
*   `UFIR`，96 Mbit/s
*   `GigaIR`，512 Mbit/s-1 Gbit/s

由于处于视线范围内的任何设备都可以捕获 IR 流量，因此如果区域内有设备，流量就可能被捕获。当然，这也意味着与 Wi-Fi 和蓝牙流量不同，处于设备视线范围之外的设备通常无法捕获 IR 流量。

红外连接最常用于单个设备之间的点对点连接，但也存在用于创建网络和设备组的 IR 技术。尽管如此，红外连接在现代系统和设备中已较少见，很大程度上已被蓝牙和 Wi-Fi 取代。

## GPS

**全球定位系统（GPS）**与迄今为止描述的其他技术不同，它不用于创建设备传输的网络。相反，它利用一组卫星发射 GPS 信号，由兼容的 GPS 接收器接收。虽然美国 GPS 系统最常被提及，但其他系统（包括俄罗斯的 GLONASS 系统和较小的区域性系统）也存在。GPS 导航可将设备定位在其实际位置一英尺范围内，从而为地理围栏和其他 GPS 用途提供高精度定位。GPS 还提供一致的时间信号，这意味着 GPS 接收器可集成到网络时间系统中。

与其他基于射频的系统一样，GPS 信号可能被干扰或欺骗，尽管在正常使用中针对 GPS 的攻击并不常见。在美国，GPS 干扰是非法的，但有说法称 GPS 欺骗曾被用于针对军用无人机，导致其坠毁，且现实世界的概念验证工作已被演示。

## USB

虽然本章讲的是无线网络和移动设备，但 USB 是许多移动设备的重要连接方式。由于 USB 是直接有线连接，它不面临无线网络的那些风险，但也有自己的隐患。USB 连接给移动设备带来的最重大风险之一是：连接的设备可以访问移动设备，通常作为直接挂载的文件系统，还可能执行软件或固件更新，或以其他方式更改或收集移动设备的数据。一些组织禁止连接到 USB 充电器，或使用组织未预先批准或发放的线缆或系统进行充电。一些组织会发放仅充电 USB 线缆，这种线缆允许充电，但 USB 线缆内部未连接数据引脚。
