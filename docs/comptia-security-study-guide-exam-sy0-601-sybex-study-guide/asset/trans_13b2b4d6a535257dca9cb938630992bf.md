
# 高弹性需求

当数据保存至关重要且在加密操作期间绝不能意外销毁时，就会存在高弹性需求。在弹性极其重要的情况下，解决该问题最简单的方法是数据发送方保留一份副本，直到接收方确认成功接收并解密了数据。

## 同态加密

隐私顾虑也为加密引入了一些专用用例。特别是，我们有时会遇到这样的应用场景：我们想要保护个人隐私，但仍想对其数据执行计算。`Homomorphic encryption`（同态加密）技术使这成为可能，它以一种保留在该数据上执行计算能力的方式对数据进行加密。当你使用同态算法加密数据，然后对该数据执行计算时，你会得到一个结果，该结果在解密后，与你最初对明文数据执行计算所获得的结果相匹配。

## 量子计算

`Quantum computing`（量子计算）是一个新兴领域，旨在利用量子力学执行计算和通信任务。它目前仍主要是一个理论领域，但如果它发展到理论可付诸实施的程度，量子密码学可能会攻破那些依赖于大素数分解的加密算法。

同时，量子计算可用于开发更强大的加密算法，其安全性将远超现代方法。我们将拭目以待，看这些技术如何发展，以便在后量子时代为我们提供强大的量子通信。

# 摘要

密码学是当今最重要的安全控制之一，它几乎涉及安全的每个其他领域，范围从网络到软件开发。密码学的使用支持在各种应用中提供机密性、完整性、认证和不可抵赖性的目标。

对称加密技术使用共享密钥为静态数据和动态数据提供安全保护。只要用户能够克服密钥交换和维护问题，对称加密就是快速且高效的。非对称密码学和公钥基础设施（`PKI`）提供了一种可扩展的方式来安全通信，特别是在通信双方没有先前关系的情况下。

# 考试要点

**理解密码学的目标。** 密码学的四个目标是机密性、完整性、认证和不可抵赖性。机密性是使用加密来保护敏感信息免受窥探。完整性是使用密码学确保数据未被恶意或无意地篡改。认证是指使用加密来验证个人身份。不可抵赖性确保个人能够向第三方证明消息来自其声称的发送者。

**解释对称加密和非对称加密的区别。** 对称加密使用相同的共享密钥来加密和解密信息。用户必须拥有某种机制来交换这些共享密钥。`Diffie–Hellman`（迪菲-赫尔曼）算法提供了一种方法。非对称加密为每个用户提供一对密钥：一个公钥，可自由共享；一个私钥，必须保密。用该对中的一个密钥加密的任何内容，都可以用该对中的另一个密钥解密。

**解释数字签名如何提供不可抵赖性。** 数字签名通过允许第三方验证消息的真实性来提供不可抵赖性。发送方通过使用哈希函数生成消息摘要，然后用自己的私钥加密该摘要来创建数字签名。其他人可以通过用发送方的公钥解密数字签名，并将解密后的消息摘要与他们自己使用哈希函数对消息计算出的摘要进行比较，来验证数字签名。

**理解数字证书的目的和用途。** 数字证书提供了一种可信机制，用于与其他个人共享公钥。用户和组织从证书颁发机构（`CA`）获取数字证书，`CA` 通过应用其数字签名来表明对该证书的信任。如果接收方信任颁发 `CA` 并验证 `CA` 的数字签名，他们就可以依赖数字证书中包含的公钥。

**展示对密码学新兴问题的熟悉程度。** `Tor` 使用完美前向保密来允许在互联网上进行匿名通信。`blockchain`（区块链）是一种通过密码学实现的不可变分布式公共账本。`Homomorphic encryption`（同态加密）允许在保护敏感数据的同时，仍以保护隐私的方式促进对该数据的计算。`Quantum computing`（量子计算）挑战现代密码学方法，未来可能成为一种颠覆性力量。
