

# 移动设备安全

最后，必须保障移动设备的安全。部署模式范围从允许用户自带设备的 BYOD 流程，到完全由企业拥有的模式，后者将为特定目的锁定的设备部署到最终用户手中。设备还需要被管理，这正是移动设备管理工具发挥作用的地方。它们提供广泛的功能，作为安全专业人员，你需要了解这些功能。

## 考试要点

**现代企业依赖多种类型的无线连接。** 组织和个人有许多无线连接选项。设备可能通过蜂窝网络连接，这将网络控制权交给了蜂窝提供商。`Wi-Fi` 广泛用于以高速将设备连接到组织网络，在提供企业安全协议的安全性的同时，允许轻松移动。`NFC` 和 `RFID` 提供短距离、相对低带宽的数据交换，用于支付、ID 卡和库存标签等许多其他用途。红外线虽然在某些领域仍在使用，但由于其视线要求和在许多情况下的带宽限制，不太流行。

**针对无线网络的常见攻击利用协议和人为行为中的漏洞。** 邪恶双生伪装成合法网络，而流氓接入点是连接在您网络内部的设备，允许攻击者绕过您的安全边界。`Bluejacking` 向 `Bluetooth` 设备发送未经请求的消息，而 `bluesnarfing` 侧重于窃取联系人和其他数据。针对 `Wi-Fi` 的协议攻击可能导致取消关联，导致系统重新连接，并允许攻击者捕获有用数据或欺骗用户或系统连接到邪恶双生。`Jamming` 攻击用噪声或不需要的信号淹没网络，导致中断或断开连接。

**安全的无线网络设计考虑现有网络和物理空间。** 现场勘测包括使用工具对设施进行实地巡查，这些工具可以识别现有的无线网络和接入点以及信号强度和其他有助于绘制位置的详细信息。网络设计考虑信道间距、接入点放置，甚至在放置接入点时考虑建筑物的构成。

**加密和认证协议提供无线安全。** 现代 `Wi-Fi` 网络中同时使用 `WPA2` 和 `WPA3`。这些协议提供简单的认证模型（如 `WPA2` 的预共享密钥模式）和依赖 `RADIUS` 服务器使用组织凭据提供用户登录的企业认证模型。设备经常被配置为使用可扩展认证协议（`EAP`）的一种变体，该变体支持组织的安全需求，并受部署的无线设备支持。

**保护底层无线基础设施需要强大的网络设备管理和安全实践。** 除了这些协议之外，控制器和接入点必须受到保护。与其他网络设备一样，控制器和 `AP` 需要定期打补丁和更新，并必须安全配置。它们还必须具有受保护的管理接口，并应配置为记录和报告网络、其自身状态以及安全问题或潜在问题。

**管理移动设备依赖部署方法和管理工具。** 部署方法包括自带设备（`BYOD`）；自选设备（`CYOD`）；企业拥有、个人启用（`COPE`）；和企业拥有（`COBO`）。组织在选择部署模型时，需要评估每种方法的风险和收益。一旦做出决定，可以使用移动设备管理（`MDM`）或统一端点管理（`UEM`）工具以多种方式配置、保护、管理和控制设备，从部署应用程序到在设备丢失或被盗时安全擦除设备。您需要了解 `MDM` 和 `UEM` 产品的功能和局限性，以及它们可以管理的设备和操作系统。

**专用移动安全技术可以提供专门的功能。** 专用硬件和软件可以为移动设备增加额外的功能和能力。考生需要熟悉移动硬件安全模块，包括那些使用 `microSD` 卡外形因子为移动设备提供加密功能的模块。`SEAndroid` 是用于 `Android` 的 `SELinux` 版本，允许 `Android` 设备以类似于 `SELinux` 为其他 `Linux` 发行版提供的方式实现强制访问控制（`MAC`）功能。使用 `SEAndroid` 的 `Android` 设备可以更有效地执行安全策略，包括默认拒绝策略以及文件系统和应用程序环境的分离。

## 复习题

1.  Alyssa 想要使用她的 `Android` 手机存储和管理加密证书。她可以选择哪种解决方案使用安全硬件来实现此目的？

    1.  `SEAndroid`
    2.  **microSD HSM**
    3.  无线 `TPM`
    4.  `MDM`

2.  Fred 的公司采用 `BYOD` 模式发放设备。这意味着 Fred 希望确保企业数据和应用程序与设备上的个人应用程序保持分离。哪种技术最适合满足这一需求？

    1.  生物识别
    2.  全设备加密
    3.  上下文感知认证
    4.  **容器化**

3.  Michelle 向在公司工厂车间工作的员工部署了 `iPad`。她希望确保设备仅在工厂内工作，如果带回家则无法访问业务数据或服务。哪种解决方案最适合她的需求？

    1.  上下文感知认证
    2.  **电子围栏**
    3.  地理定位
    4.  统一端点管理（`UEM`）

4.  哪种无线技术常用于门禁卡？

    1.  `Wi-Fi`
    2.  红外线
    3.  蜂窝网络
    4.  **`RFID`**

5.  在现场勘测期间，Chris 发现广播其组织 `SSID` 的接入点比预期的要多。他可能发现了哪种类型的无线攻击？

    1.  相同双生
    2.  备用接入点
    3.  **邪恶双生**
    4.  分裂 `SSID`

6.  Daniel 知道 `WPA3` 增加了一种方法，以确保针对弱预共享密钥的暴力破解攻击不太可能成功。这项技术叫什么？

    1.  **`SAE`**
    2.  `CCMP`
    3.  `PSK`
    4.  `WPS`

7.  Isabelle 需要选择将与其无线网络一起使用的 `EAP` 协议。她想使用一种安全协议，不要求客户端设备拥有证书，但确实要求双向认证。她应该使用哪种 `EAP` 协议？

    1.  `EAP-FAST`
    2.  **`EAP-TTLS`**
    3.  `PEAP`
    4.  `EAP-TLS`

8.  Theresa 实施了一项技术，使员工使用的移动设备上个人用途的数据与公司数据保持分离。这个概念叫什么？

    1.  存储分段
    2.  多因素存储
    3.  全设备加密
    4.  **容器化**

9.  什么标准允许将相机、键盘和闪存驱动器等 `USB` 设备插入移动设备并像平常一样使用？

    1.  `OG-USB`
    2.  `USB-HSM`
    3.  **`USB-OTG`**
    4.  `RCS-USB`

10.  Madhuri 在她组织的手机上禁用了 `SMS`、`MMS` 和 `RCS`。她阻止了什么被发送？

     1.  电话和短信
     2.  **短信和多媒体消息**
     3.  短信和固件更新
     4.  电话和多媒体消息

11.  通过 `MDM` 工具禁用 `GPS` 标记，一些公司最常见的担忧是什么？

     1.  保管链
     2.  支持电子围栏的能力
     3.  **隐私**
     4.  上下文感知认证
