

## 上下文感知身份验证

上下文感知身份验证超越了 PIN 码、密码和生物识别技术，以更好地反映用户行为。上下文可能包括位置、使用时间以及其他各种行为要素，这些要素可以决定用户是否应该能够登录。

## 容器化

容器化是处理设备上工作与个人使用场景分离的日益普遍的解决方案。使用安全容器来运行应用程序、存储数据，并以其他方式保持设备使用的独立性，可大大降低交叉污染和暴露的风险。在许多 MDM 模型中，应用程序使用封装器来运行，有助于保持它们的独立性和安全性。在其他模型中，则会根据需要运行完整的容器化环境。

## 存储分段

存储分段也可用于将个人数据和业务数据分开。这可能是单独的卷，甚至是需要特定应用程序、封装器或容器才能访问的单独加密卷。事实上，存储分段和容器化或封装技术通常结合使用，以更好地实现应用程序和分离。

## 全设备加密 (FDE)

全设备加密 (FDE) 仍然是确保被盗或丢失的设备不会导致数据泄露的最佳方式。当与远程擦除功能和强身份验证要求相结合时，FDE 可以提供设备抵抗数据盗窃的最大可能性。

## 推送通知

推送通知在这里似乎是个奇怪的入选项，但向设备发送消息在许多场景中都很有用。您可能需要提醒用户注意某个问题，或要求他们执行某项操作。或者您可能想与捡到丢失设备的人沟通，或告诉小偷该设备正在被追踪！因此，从中心位置发送消息的能力可以成为 MDM 或 UEM 系统中的一个有用工具。

## MDM 和 UEM 控制

MDM 和 UEM 工具还为用户行为提供了一套丰富的控制。它们可以启用封闭或受管的第三方应用商店，或限制用户从操作系统或您部署的设备原生应用商店下载和使用的内容。它们还可以监控固件更新和版本，包括固件空中下载 (OTA) 更新是否已应用，以确保打补丁工作的发生。

当然，用户可能会尝试通过为其设备获取 Root 权限或越狱来绕过这些控件，以便旁路加载（从 microSD 卡手动安装或通过 USB 线缆安装）程序，甚至安装自定义固件。MDM 和 UEM 工具将通过检查已知良好的固件和软件来检测这些活动，并且它们可以对设备上安装的应用程序应用允许列表或阻止列表。

## 服务和功能控制

控制可以使用哪些服务和设备功能，甚至可以在哪里使用它们，也是许多组织依赖的一项功能。限制或禁止使用摄像头和麦克风以及 SMS、MMS 和富通信服务 (RCS) 消息，有助于防止安全区域的数据泄露。限制外部媒体和 USB On-The-Go (OTG) 功能的使用（该功能允许设备充当 USB 外部设备（如相机或存储设备）的主机）也有助于限制设备被滥用的可能性。MDM 和 UEM 工具通常还允许管理员控制照片和其他可能嵌入有关拍摄或创建位置的 GPS 数据的文档的 GPS 标记功能。使用位置数据的能力可以是一个有用的隐私控制，也可能是组织文档流程的一部分要求。

## 无线连接控制

管理员可能还想控制设备如何使用其无线连接。这可以采取限制设备可以连接到哪些 Wi-Fi 网络、阻止它们形成或加入自组无线网络，以及禁用网络共享和成为无线热点的能力的形式。蓝牙和 NFC 控制也有助于防止设备以不符合组织安全模型的方式被使用，例如用作支付方式或访问设备。

## 运营商解锁

Security+ 考试大纲中列出的执行和监控的最后一项是运营商解锁。`Carrier unlocking` 允许手机与其他蜂窝网络提供商一起使用。监控设备的运营商解锁状态不是常见的 MDM 功能，通常在运营商层面处理。

## 专用移动设备安全工具

保护移动设备还涉及操作系统和硬件安全。Security+ 考试列出了两种特定的安全技术，它们是移动设备安全功能的具体示例。

### microSD 硬件安全模块 (HSM)

第一种是 microSD 硬件安全模块 (HSM)。就像本书其他地方讨论的硬件安全模块一样，microSD HSM 是一种采用极小外形规格的硬件密钥管理和公钥基础设施 (PKI) 工具。事实上，此类 HSM 不仅以 microSD 卡的形式提供，还以 USB、SIM 和其他外形规格提供。

与其他 HSM 一样，这些设备提供密钥创建、备份和恢复以及管理服务，并支持公钥身份验证和其他加密工具。当然，这些设备本身并无用处，需要配合应用程序使用。

### SEAndroid

考试涉及的第二种特定技术是 SEAndroid。SEAndroid 是适用于 Android 设备的安全增强型 Linux 版本。SEAndroid 提供了在 Android 设备上强制实施强制访问控制的能力。这意味着所有类型的 Android 进程都可以得到更好的隔离，从而限制漏洞利用，并有助于保护系统服务、系统和应用程序数据以及日志。

像许多安全系统一样，任何未明确允许的操作都会被拒绝——这是一种默认拒绝系统。SEAndroid 在强制模式下运行，该模式会记录发生的任何权限拒绝事件，并强制执行它们。SEAndroid 允许在 Android 设备上实施广泛的策略。

## 摘要

构建安全网络始于了解组织可能选择部署的无线连接选项。虽然 Wi-Fi、蜂窝网络和蓝牙几乎无处不在，但其他技术如 RFID、红外和 NFC 也内置在设备和系统中。这些技术可以构建成点对点或点对多点网络，了解哪些技术在发挥作用以及它们如何连接设备，是设计网络的第一步。

一旦知道需要保护哪种无线技术，您必须了解针对无线技术和协议的常见攻击，以及针对网络的特定常见攻击。非法接入点、邪恶双生和解关联攻击是攻击 Wi-Fi 网络的方法，蓝牙窃取和蓝牙骚扰针对蓝牙。干扰攻击，或向网络发送大量流量使其无法通过，可针对大多数射频甚至红外网络实施。

考虑到技术和攻击，接下来进行网络设计，包括使用现场勘测来了解网络将要部署的环境。热力图显示信号传播，有助于设备放置。如何保护控制器和接入点也很重要，关注点范围从补丁和维护到通过受保护的通道或网络进行安全远程访问。

网络设计完成后，安全性和身份验证选项是设计的下一层。WPA2 和 WPA3 提供加密功能和部署模型，允许用户使用预共享密钥 (WPA2-PSK) 或唯一密码，以及连接到 RADIUS 服务器以允许使用组织凭据的企业模型。EAP 及其众多变体允许根据硬件支持和特定的身份验证需求进行选择。
