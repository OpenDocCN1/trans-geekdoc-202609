
虽然按需动态生成的一次性密码更为常见，但有时也需要一种不需要设备或连接的一次性密码。在这种情况下，`static codes`（静态代码）仍然是一个有用的选项。静态代码与其他一次性密码一样也是通过算法生成的，但它们是预先生成的，通常打印出来或存储在安全的位置。这创造了一种新的风险模型：即打印它们的纸张可能被盗，或者如果它们是电子存储的，存储它们的文件可能会丢失或被访问。这相当于丢失了一个按键激活的令牌或一部未锁定的智能手机，因此如果静态代码没有得到妥善保管，它们可能会很危险。

## 生物特征

生物特征因素是“你是谁”因素的一个例子，它们依赖用户独特的生理特征来验证其身份。某些生物特征技术也算作 Security+ 考试大纲中描述的因素之一，因为它们属于“你表现出的东西”，如声纹或步态。一些最常见的生物特征技术包括以下内容：

*   `Fingerprints`（指纹），使用光学、超声波或电容式扫描仪检查指尖上脊和谷的独特模式。指纹扫描已在 Windows 中广泛部署（使用笔记本电脑上的指纹扫描仪），以及使用指纹读取器的 Android 和 Apple 设备中。
*   `Retina scanning`（视网膜扫描）利用视网膜中血管的独特模式来区分用户。
*   `Iris recognition`（虹膜识别）系统使用模式识别和红外成像来唯一识别个人的眼睛。虹膜识别可以比视网膜扫描在更远的距离完成，使其在许多情况下更受青睐。
*   `Facial recognition`（面部识别）技术将特定特征与数据库中的原始图像进行匹配。面部识别广泛用于 Apple iPhone 的 FaceID，使其成为一种广泛部署的生物特征技术。
*   `Voice recognition`（语音识别）系统依靠用户声音本身的模式、节奏和声音来识别用户。
*   `Vein recognition`（静脉识别），有时称为静脉匹配或血管技术，使用可以看到静脉模式的扫描仪，通常是用户手指的静脉。与指纹扫描仪不同，静脉扫描仪不需要接触用户，因此不太可能受到污垢或皮肤状况等因素的影响。
*   `Gait analysis`（步态分析）通过测量一个人的行走方式来识别他们。

生物特征技术基于四个主要指标进行评估。第一是 I 类错误，即 `false rejection`（误拒）率（FRR）。误拒错误意味着提交了合法的生物特征度量，但系统拒绝了它。II 类错误，或 `false acceptance`（误纳）错误，以误纳率（FAR）来衡量。当提交生物特征因素并被接受（但本不该被接受）时，就会发生这些错误。这些通过一种称为 `relative operating characteristic (ROC)`（相对工作特征曲线）的指标进行比较。ROC 将系统的 FRR 与 FAR 进行比较，通常以图表形式呈现。对于大多数系统，随着降低误拒的可能性，误纳率会增加，确定系统准确性应设置在何处以最小化误纳并防止误拒，是生物特征系统配置中的一个重要要素。

## 基于知识的认证

您可能遇到的另一种认证选项是 `knowledge-based authentication (KBA)`（基于知识的认证）。KBA 经常以安全问题的形式用于密码重置。基于知识的认证问题也用于验证创建账户的用户，方法是动态生成账户请求者预期知道的问题。一个例子是在登录美国国税局（IRS）网站时，询问您上一年的纳税申报金额。国税局知道您应该已经知道此信息，而且极少数其他人应该知道。银行和其他机构将使用类似的问题，涉及抵押贷款余额、以前的地址或其他详细信息，以帮助验证您的身份。

在任何 KBA 实施中，重要的是他人无法轻易发现答案，答案是唯一的，并且答案是用户应该能够轻松记住或很可能知道的事情。密码问题越来越多地摒弃了询问您最喜欢的宠物或第一辆汽车等固定的特定问题，因为这些信息更有可能通过社交媒体或其他方法被找到。允许用户设置自己的问题或询问更冷门的信息是一个更安全的选项。

## 管理认证

管理密码和其他认证数据可能具有挑战性，尤其是当您运营一个拥有大量设备和账户的大型企业时。

对于个人而言，提供高级别安全性的一种选择是 `password key`（密码密钥，通常称为安全密钥）。这些是支持一次性密码、用于安全证书的公钥加密以及 FIDO 和通用第二因子（U2F）等各种安全协议的硬件设备。它们有多种外形规格和不同类型的连接方式；大多数提供 USB 和/或蓝牙。

`Password vaults`（密码保管库，通常称为密码管理器）是认证管理的另一种常见解决方案。它们是存储、管理和保护密码及其他信息的软件解决方案，允许用户使用强密码，而无需记住数十个甚至数百个单独的复杂密码。企业密码管理器应用程序在组织中广泛部署，以帮助管理服务器、应用程序和设备，它们还具有日志记录和审计等附加功能，以及管理工具以确保密码得到适当轮换并监控使用和滥用情况。

计算机还可以拥有内置或附加的安全模块，如 `Trusted Platform Module (TPM)`（可信平台模块）标准。TPM 模块或芯片具有内置的加密处理器，用于存储由系统所有者设置的密码保护的 RSA 密钥对。TPM 模块可以帮助防止未经授权的固件和软件更改，作为可信或安全启动过程的一部分，并且它们受操作系统支持，允许驱动器加密和其他基于加密的安全功能。虽然一些系统（包括许多企业级笔记本电脑）内置了 TPM 芯片，但它们也可以作为附加模块添加到支持它们的系统中。

您应该了解的最后一个选项是使用 `hardware security modules (HSMs)`（硬件安全模块）。HSMs 通常以独立的物理设备或计算机的插入式扩展卡的形式出现，集成了加密处理器，以安全地创建、存储和管理加密密钥；提供加密和解密服务；并以安全的方式执行其他加密处理。云提供商现在提供 HSM 即服务，允许以安全的方式将 HSM 添加到云基础设施中。

HSM 设计的一个重要部分是设备本身的安全性，HSM 通常带有第三方安全认证，以证明它们已通过评估和验证，符合 FIPS-140 等标准，即美国政府的加密安全标准。
