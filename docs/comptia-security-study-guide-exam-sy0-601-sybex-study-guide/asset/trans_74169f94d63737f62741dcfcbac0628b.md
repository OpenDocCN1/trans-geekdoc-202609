
# 减少系统攻击面的最快方法之一是减少其提供的开放端口和服务的数量

毕竟，如果攻击者无法远程连接到系统，他们直接利用系统漏洞的难度将大大增加。端口扫描器常用于快速评估网络上系统的开放端口，使安全从业人员能够识别并确定加固目标的优先级。加固的简单经验法则是：只有必须可用以提供必要服务的服务和端口才应开放，并且这些端口和服务应仅限于它们需要交互的网络或系统。不幸的是，对许多服务器而言，这可能意味着系统需要面向全球开放。

[表 11.1](#c11.xhtml#c11-tbl-0001) 列出了 Linux 和 Windows 系统中一些最常见的开放端口和服务。

## 表 11.1 常见端口和服务

| 端口和协议 | Windows | Linux |
| --- | --- | --- |
| **22/TCP – Secure Shell (SSH)** | 不常见 | 常见 |
| **53/TCP 和 UDP – DNS** | 常见（服务器） | 常见（服务器） |
| **80/TCP – HTTP** | 常见（服务器） | 常见（服务器） |
| **125-139/TCP 和 UDP – NetBIOS** | 常见 | 偶见 |

虽然使用防火墙阻止服务是一种可行的选择，但对于不需要的服务，最好的选择是彻底禁用它们。在 Windows 中，你可以使用 [图 11.3](#c11.xhtml#c11-fig-0003) 中所示的 `Services.msc` 控制台来禁用或启用服务。请注意，此处远程桌面服务设置为手动启动，这意味着除非系统用户启动它，否则无法访问。

在 Linux 中启动和停止服务需要知道你的 Linux 发行版如何处理服务。对于 Ubuntu Linux 系统，可以通过使用 `service –status-all` 命令来检查正在运行的服务。启动和停止服务可以通过多种方式完成，但 `service` 命令是一种简便的方法。发出 `sudo service [`*`服务名称`*`] stop` 或 `start` 命令将启动或停止一项服务，只需使用 `service -status-all` 命令提供的信息来识别你要关闭的服务即可。然而，永久停止服务将要求你进行其他更改。对于 Ubuntu，将调用 `update-rc.d` 脚本，而 RedHat 和 CentOS 系统则使用 `chkconfig`。

幸运的是，对于 Security+ 考试，你不需要知道特定操作系统的命令。相反，你应该理解禁用服务以减少系统攻击面的概念，并且了解需要持续的审查和维护，以确保新的服务和应用程序不会随着时间的推移而出现。

## 操作系统加固

操作系统加固依赖于更改设置以匹配给定系统所需的安全态势。流行的基准和配置标准可用作基础，并根据组织需求进行修改，从而允许在整个组织中使用诸如 CIS 基准之类的工具。幸运的是，存在一些工具和脚本可以帮助更轻松地应用这些设置。

CIS 基准针对 Windows 10 推荐的配置设置类型示例包括以下内容：

*   将密码历史记录设置为记住 24 个或更多密码
*   将最大密码使用期限设置为“60 天或更少，但不为 0”，防止用户仅通过更改 24 次密码就恢复使用相同的密码，同时要求每 2 个月更换一次密码
*   将最小密码长度设置为 14 个或更多字符
*   要求密码必须符合复杂性要求
*   禁用使用可逆加密存储密码

上面的列表只是一份包含超过 1,300 页信息的文档中的一个章节，该文档详细介绍了如何锁定 Windows，包括每个设置的描述、推荐理由、推荐设置的影响，以及如何设置和审核该设置的信息。好消息是，考试不要求你了解加固 Windows、Linux 或 macOS 的所有细节。你需要知道的是：操作系统加固使用系统设置来减少操作系统的攻击面，存在工具和标准来协助该过程，并且为组织评估、审核和维护操作系统加固是整体安全管理过程的一部分。

### 加固 Windows 注册表

Windows 注册表是 Windows 跟踪系统状况的核心。因此，注册表是攻击者的重要目标，他们可以利用它来自动启动程序、收集信息，或在目标计算机上采取其他恶意行动。加固 Windows 注册表涉及配置注册表权限、在不需要特定需求时禁止远程注册表访问，以及限制对 `regedit` 等注册表工具的访问，以便攻击者即使获得了系统访问权限，也更难更改或查看注册表。

### 配置、标准和模式

要在企业环境中加固系统，你需要通过组织来管理系统的配置。事实上，*配置管理*工具是安全专业人员和系统管理员确保其组织中众多系统具有正确安全设置并帮助保护它们安全的最强大选项之一。第三方配置管理系统（如用于 macOS 的 Jamf Pro）、供商提供的工具（如用于 Windows 的 Configuration Manager），甚至开源配置管理工具（如 CFEngine），都有助于强制执行标准、管理系统，并报告系统不符合预期设置的领域。

配置管理工具通常从组织中具有代表性的系统或操作系统类型的*基线配置*开始。例如，你可以选择为 Windows 10 桌面、Windows 10 笔记本电脑和 macOS 笔记本电脑配置基线配置。然后，根据需要，通过将它们放入具有这些修改后设置的组中，可以针对特定群组、团队、部门甚至个人用户修改这些标准。基线配置是构建的理想起点，有助于降低复杂性，并使配置管理和系统加固能够跨多台计算机（甚至数千台）成为可能。

除了配置管理标准和工具外，文档也是配置管理的重要组成部分。图表（包括架构图、网络图和数据流图）用于理解和记录组织的技术和系统是如何设置的。建立制作系统和架构图的组织习惯，确保它们符合质量标准，并在事物发生变化时进行更新，有助于确保部署符合组织标准。在执行事件响应和灾难恢复操作时，这些相同的图表至关重要，因为它们使响应人员能够快速了解基础设施和系统的配置方式、互连方式、数据流向、数据如何从一处传送到另一处，以及系统或应用程序架构中存在哪些依赖关系。图表和文档也可提供给审计员，作为评估设计的有用工件。
