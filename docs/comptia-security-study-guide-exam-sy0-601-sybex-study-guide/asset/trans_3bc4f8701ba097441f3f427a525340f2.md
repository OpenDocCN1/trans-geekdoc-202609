# 评估测试答案

## 1. C
禁用自动修补的最常见原因是避免有问题或有缺陷的补丁和更新带来的问题。在大多数环境中，定期修补的需求已被接受，且对于办公人员的处理不会造成重大干扰。如果被修补的系统是工业流程或工厂生产环境的一部分，这种担忧就会有所不同。来自合法来源（如自动更新存储库）的恶意补丁极其罕见，并不是这种行为的常见顾虑或驱动因素。

## 2. D

## 3. C
近场通信（NFC）是无线支付系统最常用的技术。NFC 提供了极短距离、低带宽的无线连接，非常适合支付系统。无线 USB 确实存在，但未被广泛使用。蜂窝网络和蓝牙不常用于无线支付系统，尽管确实存在一些蓝牙实现。

## 4. B

## 5. A

## 6. D

## 7. D

## 8. B

## 10. B

## 13. A
