# SY0-601 考试目标

CompTIA 竭尽全力确保其认证计划准确反映 IT 行业的最佳实践。他们通过为每个考试项目建立委员会来实现这一点。每个委员会由一小组 IT 专业人员、培训提供商和出版商组成，负责确定考试的基础能力水平并确定适当的目标受众水平。

一旦确定这些因素，CompTIA 会将此信息分享给一组精心挑选的主题专家（SME）。这些人是认证计划背后的核心智囊。SME 审查委员会的调查结果，对其进行完善，并将其塑造成本节后面的目标。CompTIA 称此过程为工作任务分析（JTA）。

最后，CompTIA 进行调查以确保目标和权重真实反映工作要求。只有在那时，SME 才能着手编写考试所需的数百道题目。即便如此，在考试准备好以最终状态上线之前，他们在许多情况下仍需回到起点进行进一步完善。请放心，您即将学习的内容将在您参加考试后长期为您服务。

CompTIA 还发布了每个考试目标的相对权重。下表列出了五个 Security+ 目标领域及其在考试中的占比。
