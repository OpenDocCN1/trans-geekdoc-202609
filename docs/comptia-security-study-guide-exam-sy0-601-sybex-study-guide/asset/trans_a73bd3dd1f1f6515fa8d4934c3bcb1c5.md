# 第 1 章：当今的安全专业人员

安全专业人员在当今复杂的威胁环境中发挥着保护组织的关键作用。他们负责保护其组织使用的信息和信息系统的机密性、完整性和可用性。履行这一职责需要深入了解其组织面临的威胁环境，并致力于设计和实施一套能够应对挑战、回应这些威胁的控制措施。

在本章的第一节中，您将了解网络安全的基本目标：运营的机密性、完整性和可用性。在后续章节中，您将了解可以采取的一些控制措施，以保护最敏感的数据免受窥探。本章为本书其余部分奠定了基础，您将在其中深入探讨网络安全的许多不同领域。

## 网络安全目标

当大多数人想到网络安全时，他们会想象黑客试闯入组织的系统并窃取敏感信息，范围涵盖从社会安全号和信用卡到最高机密军事信息。尽管防止敏感信息未经授权的披露当然是网络安全计划的一个要素，但重要的是要理解网络安全实际上有三个互补的目标，如[图 1.1](#c01.xhtml#c01-fig-0001)所示。

![FIGURE 1.1 网络安全计划的三个关键目标是机密性、完整性和可用性。](images/c01f001.png)

**图 1.1** 网络安全计划的三个关键目标是机密性、完整性和可用性。

*机密性* 确保未经授权的个人无法访问敏感信息。网络安全专业人员开发和实施安全控制，包括防火墙、访问控制列表和加密，以防止未经授权访问信息。攻击者可能试图破坏机密性控制以实现其目标之一：未经授权披露敏感信息。

*完整性* 确保信息或系统没有未经授权的修改，无论是有意还是无意的。完整性控制，如哈希和完整性监控解决方案，旨在强制执行此要求。完整性威胁可能来自寻求未经授权篡改信息的攻击者，也可能来自非恶意来源，例如电源浪涌导致信息损坏。

*可用性* 确保信息和系统随时准备好在合法用户请求时满足其需求。可用性控制，如容错、集群和备份，旨在确保合法用户能够按需获得访问权限。与完整性威胁类似，可用性威胁可能来自寻求中断访问的攻击者，也可能来自非恶意来源，例如火灾摧毁了包含宝贵信息或服务的数据中心。

网络安全分析师在执行工作时经常提及这三个目标，称为 *CIA 三要素*。在描述风险、攻击和安全控制时，他们通常将其描述为满足 CIA 三要素的三个目标中的一个或多个。

## 数据泄露风险

当组织遭遇信息或信息系统的机密性、完整性和/或可用性被破坏时，就会发生 *安全事件*。这些事件可能是恶意活动的结果，例如攻击者以组织为目标并窃取敏感信息；也可能是意外活动的结果，例如员工将未加密的笔记本电脑遗留在网约车后座上；还可能是自然活动的结果，例如地震摧毁了数据中心。

安全专业人员负责了解这些风险，并实施旨在将风险管理在可接受水平的控制措施。为此，他们首先必须了解泄露可能对组织产生的影响，以及可能产生的持续影响。

### DAD 三要素

本章前面介绍了 CIA 三要素，用于描述网络安全的三个主要目标：机密性、完整性和可用性。[图 1.2](#c01.xhtml#c01-fig-0002) 展示了一个相关模型：*DAD 三要素*。该模型解释了对网络安全工作的三大关键威胁：*泄露*、*篡改* 和 *拒绝*。这三大威胁分别直接对应网络安全的三大主要目标。

![FIGURE 1.2 对网络安全计划的三大关键威胁是泄露、篡改和拒绝。](images/c01f002.png)

**图 1.2** 对网络安全计划的三大关键威胁是泄露、篡改和拒绝。

- **泄露** 是指敏感信息暴露给未经授权的个人，也称为 *数据丢失*。泄露违反了机密性原则。攻击者获得敏感信息并将其从组织中移出，被称为实施 *数据渗漏*。泄露也可能意外发生，例如管理员错误配置访问控制或员工丢失设备时。
