## 第 3 章：恶意代码

### 1. C. 逻辑炸弹是在满足特定条件后激活的一种恶意软件。此处，开发人员不再出现在工资单中、未输入特定输入或其他激活方案均可能被使用。RAT 是远程访问木马，PUP 是潜在的不需要程序，键盘记录器会窃取用户输入。

### 2. D. PowerShell 是此类漏洞利用最可能使用的工具。VBScript 将在应用程序内部使用，而 Bash 和 Python 更可能存在于 Linux 系统上。

### 3. C. Scott 所见到的行为具有僵尸程序感染的特征。该僵尸程序很可能正在联系命令与控制主机，随后下载更新和/或附加包，然后上传其组织的数据。他需要确定敏感或重要的业务信息是否存在于该系统上或可从中访问。键盘记录器将捕获按键和用户输入，但通常需要额外的恶意软件包才能表现出这种行为。逻辑炸弹可能在事件发生后激活，但场景未描述事件，后门用于远程访问。

### 4. A. Amanda 很可能发现了一个僵尸网络的命令与控制（C&C）通道，她正在监控的系统很可能正使用 IRC 作为 C&C 通道。RAT 更可能使用不同的控制通道，蠕虫通过攻击易受攻击的服务进行传播，被劫持的 Web 浏览器可能会在常见的 HTTP 或 HTTPS 端口（80/443）上运行。

### 5. D. 对系统的远程访问通常由后门提供。后门也可能出现在固件甚至硬件中。列出的其他项目默认均不提供远程访问，尽管它们可能作为功能更强大的恶意软件包的一部分包含后门。

### 6. C. 要求第三方审查 ML 算法并非常见要求，但确保使用高质量的源数据、保持工作环境安全、对变更进行审查和测试，这些都是 ML 算法安全的常见最佳实践。

### 7. C. 广告软件通常被归类为一种潜在的不需要程序（PUP）。后门和 Rootkit 肯定是恶意的，而广告软件可能只是不需要且令人讨厌。DOG 不是描述恶意软件的常用术语。

### 8. D. 安全从业者在尝试识别恶意软件时面临的挑战之一是，不同的防病毒和反恶意软件供应商对恶意软件包和家族的命名不同。这意味着 Matt 可能需要查看不同的名称来弄清楚他面对的是什么。

### 9. D. 虽然键盘记录器通常专注于键盘输入，但其他类型的输入也可能被捕获，这意味着 Nancy 应担心键盘记录器安装期间发生的任何用户输入。键盘记录器通常不以系统上的文件为目标，尽管如果 Nancy 发现键盘记录器，她可能需要检查是否存在具有额外功能的其他恶意软件包。

### 10. C. 加密恶意软件是一种勒索软件，通常要求付款以解密关键文件或整个驱动器。PUP 是间谍软件和广告软件等潜在的不需要程序，而 Rootkit 用于在不被检测的情况下控制系统，蠕虫则通过利用漏洞自我传播。

### 11. B. Rootkit 旨在躲避反恶意软件扫描器，通常能击败本地运行的扫描。以只读模式将驱动器挂载到另一系统中，或从 USB 驱动器启动并使用受信任的、已知良好的操作系统进行扫描，可以有效地确定潜在受感染系统上存在什么恶意软件。

### 12. B. 如果 Tracy 担心为网络建立基线并产生受污染的数据，她需要确保在运行基线数据采集时没有发生恶意活动。这样，机器学习算法将仅使用正常的流量模式和行为，随后便可对异常情况进行检测和警报。
