
*   **计量服务**。您在云中所做的一切都会由提供商进行计量。提供商会跟踪您消耗的处理时间秒数、您占用的存储空间量、您生成的日志条目数量以及许多其他指标。他们利用这些信息根据您的使用情况来评估费用。您只需为您所用的内容付费——不多也不少。

*   **敏捷性**和**灵活性**。预配云资源的速度以及短期使用它们的能力，为技术组织提供了极大的敏捷性和灵活性。希望尝试新想法的开发人员和工程师可以快速启动测试环境，评估该方法，并以最小的工作量和成本决定是否将其移入生产环境。

### 云角色

在任何云计算环境中，不同的组织扮演不同的角色。云中有五个关键角色：

*   **云服务提供商**是向客户提供云计算服务的公司。他们可能会建立自己的数据中心，或者与其他云提供商紧密合作以提供服务，但他们的决定性特征是他们提供云服务供销售。

*   **云消费者**是从云服务提供商处购买云服务的组织和个人。他们使用这些服务来满足自身的业务需求。

*   **云合作伙伴**（或云代理）是提供辅助产品或服务以支持或集成云服务提供商产品的组织。云合作伙伴可能提供培训或咨询以帮助客户使用云服务，提供软件开发和集成服务，或执行任何其他促进云产品使用的服务。

*   **云审计员**是对云服务和运营提供第三方评估的独立组织。根据审计业务的范围，他们可能会对云环境提供总体评估，或专注于特定范围运营的安全控制。

*   **云承载商**充当中介，提供连接服务，使云服务能够从提供商交付给消费者。

### 云服务模型

我们根据产品/服务的性质，将云服务提供商提供的服务类型分为几类。云中可用的各种服务通常被称为“一切即服务”，或缩写为 **XaaS**，其中 **X** 表示特定服务的性质。尽管有许多不同类型的云服务，但我们通常使用三种主要服务模型来描述它们：**基础设施即服务**、**软件即服务** 和 **平台即服务**。

#### 基础设施即服务

**基础设施即服务** 产品允许客户购买技术基础设施的基本构建模块并与之交互。这些包括计算、存储和网络。然后，客户可以灵活地以任何他们喜欢的方式配置和管理这些服务，以满足自己的业务需求。客户无需担心底层硬件的管理，但他们确实有能力自定义组件以满足其需求。在 **IaaS** 模型中，云服务提供商负责管理物理设施和底层硬件。提供商还必须实施安全控制，以防止客户互相窃听或干扰彼此对基础设施环境的使用。

尽管市场上有数十家 **IaaS** 提供商，但目前市场由三大主要参与者主导：**Amazon Web Services (AWS)**、**Microsoft Azure** 和 **Google Cloud Platform (GCP)**。这三家提供商服务于绝大多数 **IaaS** 客户，并提供广泛的计算、存储和网络产品，以及位于堆栈更高层的补充服务，例如安全监控、内容分发网络和应用流式传输。

#### 软件即服务

**软件即服务** 产品为客户提供对在云中运行的完全托管应用程序的访问。提供商负责从物理数据中心的运营到应用程序本身的性能管理的一切事务，尽管其中一些任务可能会外包给其他云服务提供商。在 **SaaS** 模型中，客户仅负责应用程序本身的有限配置、选择他们希望与云解决方案一起使用的数据，以及使用应用程序提供的访问控制来限制对该数据的访问。

**SaaS** 模型广泛用于交付从基于 Web 的电子邮件到企业资源规划 (**ERP**) 和客户关系管理 (**CRM**) 套件等各类应用程序。客户可持续访问尖端软件，并通常使用订阅模式支付 **SaaS** 服务费用。产品用户通常通过标准 Web 浏览器访问应用程序，甚至可能使用瘦客户端设备，例如 [图 10.2](#c10.xhtml#c10-fig-0002) 所示的 **Google Chromebook**。

#### 平台即服务

**平台即服务** 产品处于 **SaaS** 和 **IaaS** 解决方案之间的中间地带。在 **PaaS** 产品中，服务提供商提供一个平台，客户可以在其中运行他们自己开发的应用程序。云服务提供商构建并管理基础设施，并为客户提供执行环境，其中可能包括促进代码执行的代码库、服务和工具。

![图 10.2 瘦客户端，如这款三星 Google Chromebook，足以访问 SaaS 应用程序。](images/c10f002.png)

**[图 10.2](#c10.xhtml#R_c10-fig-0002)** 瘦客户端，如这款三星 Google Chromebook，足以访问 SaaS 应用程序。

**函数即服务** 平台是 **PaaS** 计算的一个示例。这种方法允许客户将自己的代码函数上传到提供商，然后提供商将按计划、响应事件和/或按需执行这些函数。**AWS Lambda** 服务（如 [图 10.3](#c10.xhtml#c10-fig-0003) 所示）是 **FaaS/PaaS** 产品的一个示例。**Lambda** 允许客户使用 **Python**、**Java**、**C+**、**PowerShell**、**Node.js**、**Ruby**、**Go** 和其他编程语言编写代码。[图 10.3](#c10.xhtml#c10-fig-0003) 中所示的 **Lambda** 函数是一个 **Python** 函数，旨在从 **物联网** 温度传感器读取当前温度。

由于 **FaaS** 环境不会向客户暴露执行其代码的实际服务器实例，因此它们通常被称为 **无服务器计算** 环境。然而，这在一定程度上是一个误称，因为 **FaaS** 环境确实有运行代码的服务器，但它们以对 **FaaS** 客户透明的方式进行。

### 云部署模型

云部署模型描述了云服务如何交付给客户，以及用于向一个客户提供服务的资源是否与其他客户共享。

#### 公有云

当我们想到“云”时，通常首先想到的是 **公有云** 产品。公有云服务提供商部署基础设施，然后以多租户模式使其可供任何希望利用它的客户访问。单个客户可能在分布在一个或多个数据中心的服务器上运行工作负载，而这些服务器可能同时为许多不同的客户运行工作负载。
