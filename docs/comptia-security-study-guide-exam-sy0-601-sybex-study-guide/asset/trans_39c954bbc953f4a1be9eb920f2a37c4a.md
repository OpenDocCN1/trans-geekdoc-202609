
# 账户类型和访问控制方案

账户类型繁多，但几乎所有类型都可以归纳为以下几种基本账户类型：

*   **用户账户**，权限范围涵盖从对系统、设备或应用程序的基本访问，到拥有广泛权利和特权的高级用户。
*   **特权或管理账户**，如 Linux 和 Unix 系统上的 `root` 账户或 `wheel` 组成员，以及 Windows 默认的 `Administrator` 账户。
*   **共享和通用账户或凭证**，通常被安全策略所禁止。尽管共享账户可能很有用，但许多组织会构建委派功能，允许多个用户以相同方式或拥有相同权利行事，以避免共享账户问题，例如无法确定是谁登录了共享账户，或共享该账户的每个用户采取了什么操作。
*   **来宾账户**，提供给临时用户，通常具有非常有限的特权，但也很可能几乎没有（或完全没有）使用该账户用户的相关信息。
*   **服务账户**，与应用程序和服务相关联。服务账户不应用于交互式登录，许多组织都制定了特定的安全策略来确保服务账户安全。

## 账户策略和控制

账户策略旨在提供控制，规定账户如何以及何时可以使用，控制密码复杂度、生命周期及其他细节。让我们探讨几个常见的账户策略设置，这些是你参加 Security+ 考试时需要准备实施的内容。

**密码复杂度**决定了密码的组成。在 MFA（多因素认证）技术广泛实施之前，密码复杂度是最常用的控制措施之一，旨在防止简单密码被暴力破解。密码复杂度设置将规定密码可使用哪些字符、不可使用哪些字符、最小长度、是否可包含单词或包含特定禁用单词，以及决定密码复杂程度的任何相关设置。密码复杂度的权衡在于：要求额外的复杂度可能会降低用户记住密码的可能性，并可能在密码重置支持上花费额外的时间和金钱。复杂度还可能导致用户记录密码（可能存放在不安全的位置），或重复使用复杂密码，以免记忆过多密码。

**密码生命周期**也曾被普遍使用，尽管 MFA 的使用日益增加，导致许多组织不再要求定期更换密码。当密码是账户的唯一保护时，密码生命周期被视为一种限制密码在泄露后最大暴露时间的方法。这引发了关于生命周期与用户行为的各种实验，许多研究指出：要求更换越频繁，密码越有可能只是在旧密码基础上做微小更改。**密码历史记录**设置用于防止**密码重用**。基本的密码历史记录会跟踪管理员设定的特定迭代次数内的过往密码。更高级的密码历史记录系统可能能够识别密码是否与之前的条目过于相似，以确保未使用仅做微小更改的密码。

除了与密码相关的控制外，账户控制还可以利用登录过程中的其他信息。常见控制包括：

*   **一天中的时间**，可防止员工在轮班结束后访问系统，从而潜在地减少攻击者在账户所有者不会察觉时利用账户的机会，或内部人员滥用特权。**基于时间的登录**对于轮班制或小时工更为常见。
*   **正在认证的系统的网络位置**。这有助于防止数据从错误的网络被访问，或通过确保系统仅从受保护网络内部进行认证来帮助维护信任边界。
*   **地理位置数据**可用于仅允许来自地理围栏区域（基于预定 GPS 数据的位置）的登录。地理标记有时也会与此结合使用，以标记可在特定位置使用的特定数据或系统。地理信息还用于判断是否发生**不可能的旅行时间**问题，即用户从一个地点登录，随后又从另一个地点登录，两地距离足以确保用户不可能在给定时间内抵达新位置。此类技术可识别高风险登录，最有可能使用安全信息和事件管理（`SIEM`）工具或类似工具实现，这些工具能协调来自多个系统的数据。

尽管密码控制、地理位置和网络位置设置以及基于时间的控制都有助于确保用户以安全方式登录，但**账户审计**有助于确保账户得到良好管理、账户拥有适当的权限，且已实施适当的控制。账户审计（可能是手动或自动的）侧重于确保账户按预期配置，根据用户角色或组织针对该类账户或用户的规则和标准，拥有适当的权限和权利。

最后，当账户遇到问题时，账户可以被锁定或禁用。账户锁定通常是自动化的，基于错误的登录尝试。锁定可能需要人工干预，也可能在一段时间后自动解锁。经过设定时期后自动解锁的锁定称为**退避算法**，存在各种退避算法设计，旨在减缓或阻止暴力破解攻击者，同时仍允许合法用户有机会登录其账户，而无需联系支持部门。

在因泄露或生命周期变更（如离职或退休）或其他问题导致需要终止账户的情况下，禁用账户是一个重要选项。**禁用账户而非删除账户**可能令人担忧，因为它们可能仍保留特权，如果账户被有意或意外恢复，攻击者可能利用这些特权。因此，账户审计通常会审查禁用账户，以查看其是否得到妥善管理，以及组织是否有重新启用它们的习惯，或是否验证了重新启用的原因。

### 特权访问管理

**特权访问管理（PAM）**工具可用于处理本节前面提到的管理和特权账户。PAM 工具专注于通过帮助管理员仅指定角色或任务所需的最小特权集，来确保**最小权限**概念得以维持。PAM 工具通常提供更详细、更细粒度的控制；增强的审计能力；以及对特权账户状态的额外可见性和报告。

## 访问控制方案

用户账户和账户控制固然重要，但系统还实施**访问控制方案**，以确定哪些用户、服务和程序可以访问它们托管的各种文件或其他对象。Security+ 考试涵盖许多常见的访问控制方案，我们接下来将进行探讨。

**基于属性的访问控制（ABAC）**依赖于由用户属性驱动的策略。这允许基于属性组合的复杂规则集，授予用户与其拥有的属性相匹配的特定权利。由于属性可以在特定上下文中设置，这也意味着 ABAC 方案可以非常灵活。ABAC 策略的缺点是，由于其灵活性，管理起来也可能非常复杂。
