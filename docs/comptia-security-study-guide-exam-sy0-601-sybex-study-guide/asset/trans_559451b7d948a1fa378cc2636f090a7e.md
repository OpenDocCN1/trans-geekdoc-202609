

# 采集工具与取证套件

采集工具和取证套件提供收集取证镜像和数据的能力，并利用强大的功能（如图像和文档的自动识别、时间线分析等）对其进行分析。哈希计算和验证可确保获取的镜像完好无损，而与源数据匹配有助于确保取证数据在法庭上具有可采性。

报告发生在取证分析的最后阶段，必须完整无缺，并记录针对取证证据得出的每个结论或陈述的推理依据。标准的取证报告格式有助于确保读者知道预期内容，并能轻松理解所呈现的信息。

取证技术的用途不仅限于调查和事件响应。它们在情报和反情报活动中也发挥着作用。情报机构可能会使用取证技术获取信息，或通过检查其他组织留下的工具和痕迹来对抗其活动。

## 考试要点

**法律保留和电子取证驱动部分取证活动。** 组织面临法律诉讼，需要响应法律保留，这要求它们为正在进行或待决的案件保存和保护相关信息。电子取证流程也要求将取证数据和其他数据作为法律案件的一部分提供。组织必须建立相应的能力和技术，以适当的方式响应这些要求，从而避免在法庭上败诉。

**易失性顺序用于确定优先采集的内容。** 在取证采集过程中，不同的系统组件和资源被更改或丢失的可能性各不相同。因此，取证从业者参考易失性顺序来确定什么最易失、什么最不易失。`CPU cache`（CPU 缓存）和寄存器通常最易失，其次是进程表、`ARP cache`（ARP 缓存）、内核统计数据等。接下来是系统 `RAM`；临时文件和交换空间、硬盘上的数据；远程日志；最后是备份，这些都属于易失性较低的数据。你的取证采集流程应考虑易失性顺序，并结合采集过程的具体情况来决定优先捕获的内容。

**必须在需要取证响应之前解决云环境问题。** 由于云环境通常托管在第三方基础设施中，直接进行取证的能力往往不可用。组织可能需要在合同中约定相关能力，包括审计权条款、监管和管辖权选择，以及数据泄露通知要求和时限。

**采集工具有很多选择，选择合适的工具需要结合技术需求和技能组合。** 镜像采集工具提供使用逐位复制方法复制磁盘和卷的能力，这将捕获完整的镜像，包括未使用的空间（即松散空间）。工具的复杂程度从内置的 Linux `dd` 实用程序，到可以处理驱动器和内存采集的免费工具如 `FTK Imager` 不等。商业工具 `WinHex` 除了采集功能外，还提供额外的驱动器分析功能。当需要采集网络数据时，`Wireshark` 和其他网络分析器可发挥作用以捕获和分析数据。最后，采集虚拟机和容器可能需要专门的工具和实践，这些实践和程序需要在取证检查变得必要之前就被识别和演练，以确保工具和能力到位。

**取证套件提供的功能使调查更轻松、更完整。** 取证套件（如 `Autopsy`）提供管理和组织调查的工具，以及一套完整的工具集。这些工具通常包括摄入、分析和自动识别常见取证目标（如图像、Office 文档、文本文件和类似痕迹）的能力。它们还提供时间线分析功能、协助报告和取证数据标记的工具，以及广泛的其他对取证检查有用的功能。虽然 `Autopsy` 只是一个例子，但市面上广泛提供具有高级功能的商业工具。

**验证获取的数据有助于保持其可采性。** 对驱动器和镜像进行哈希计算可确保获取的数据与其源匹配。尽管 `MD5` 和 `SHA1` 都存在问题，取证从业者仍普遍继续使用它们，因为对抗性技术在取证检查中很少出现。校验和可用于确保数据未被更改，但它们无法创建哈希值用于为取证痕迹提供的唯一指纹。

**取证报务必条理清晰、切中要害。** 取证分析并不在设备和驱动器的技术检查结束时终止。取证报告总结关键发现，然后解释流程、程序和工具，以及影响调查的任何局限性或假设。接下来，它们用适当的证据和细节详述取证发现，以解释结论是如何得出的。最后，它们给出比摘要更详细的建议或总体结论。

1.  Cynthia 想要使用 Linux 命令行工具制作驱动器的精确副本。她应该使用什么命令？

    1.  `df`
    2.  `cp`

    4.  `ln`

2.  Greg 想要使用一种可直接编辑磁盘用于取证目的的工具。他可以从该列表中选择哪个商业工具？

    1.  `dd`
    2.  `memdump`
    3.  `WinHex`
    4.  `df`

3.  Gabby 想要捕获系统的页面文件。她将在哪里找到存储的页面文件？

    1.  在内存中
    2.  在磁盘上
    3.  在 CPU 寄存器中
    4.  在设备固件中

4.  以下哪项是包含 `memdump` 的内存取证工具包？

    1.  `FTK Imager`
    2.  `WinHex`
    3.  `dd`
    4.  `Volatility`

5.  Charles 想要获取正在运行的虚拟机的取证副本。他应该使用什么技术来捕获镜像？

    1.  在正在运行的机器内部运行 `dd`。
    2.  从虚拟机宿主机使用 `FTK Imager`。
    3.  使用虚拟机宿主机创建快照。
    4.  在正在运行的机器内部使用 `WinHex` 创建副本。

6.  Melissa 想要为取证目的捕获网络流量。她应该使用什么工具来捕获它？

    1.  取证套件
    2.  `Wireshark`
    3.  `dd`
    4.  `WinHex`

7.  Frank 担心其取证数据的可采性。以下哪项不是他应关注的要素？

    1.  取证源数据是否保持未被篡改
    2.  做法和程序是否经得起专家审查
    3.  证据是否与案件相关
    4.  取证信息是否包含时间戳

8.  记录证据保管或控制情况的文件叫什么？

    1.  证据日志
    2.  审计日志
    3.  事件报告
    4.  保管链

9.  Isaac 正在对同一设施中同一事件中被攻破的两个系统进行取证分析。在分析过程中，他注意到该事件在一个系统上发生的时间似乎比另一个系统早几乎整整一小时。他最可能遇到的问题是什么？

    1.  攻击者花了一小时才到达第二个系统。
    2.  一个系统设置了错误的时区。
    3.  攻击者更改了系统时钟以干扰取证人员。
    4.  取证工具错误地读取了时间戳。

10. 什么法律概念根据位置决定涉及案件的执法机构？

    1.  关联性
    2.  不可抵赖性
