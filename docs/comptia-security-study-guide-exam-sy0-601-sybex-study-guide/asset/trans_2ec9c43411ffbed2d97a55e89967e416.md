

# 恶意软件

在本章中，您将探索各种类型的恶意软件，以及每种恶意软件类型的区别要素、行为和特征。您将了解应寻找的指标、组织用于应对每种恶意软件的响应方法，以及有助于防范它们的控制措施。

最后，您将探索针对旨在防止恶意软件攻击的防护技术和系统的攻击。您将了解对抗性人工智能的概念、针对机器学习（`ML`）系统的攻击，以及 `ML` 算法如何防范对抗性攻击。

术语 `malware` 描述了一系列有意设计用于对系统和设备、网络或用户造成危害的软件。恶意软件还可以收集信息、提供非法访问，并采取广泛的行动，而这些行动可能是系统或网络的合法所有者不希望发生的。`SY0-601 Security+` 考试目标包含许多最常见的恶意软件类型，您需要熟悉其中的每一种，如何区分它们，如何识别它们，以及对抗它们的常用技术。

## 勒索软件

`Ransomware` 是一种接管计算机然后索要赎金的恶意软件。勒索软件有多种类型，包括加密恶意软件，它会加密文件，然后将其作为人质，直到支付赎金为止。其他勒索软件技术包括：威胁因盗版软件或色情内容向执法部门举报用户，或威胁暴露受害者硬盘或设备中的敏感信息或图片。

防范勒索软件最重要的防御措施之一，是一个有效的备份系统，它将文件存储在一个单独的位置，这样即使被其备份的系统或设备遭到勒索软件感染并加密，备份也不会受影响。准备应对勒索软件的组织需要确定其响应策略；在某些情况下，支付赎金导致文件被返还，而在其他情况下，攻击者只是索要更多钱财。

## 特洛伊木马

`Trojans`（特洛伊木马）是一种通常伪装成合法软件的恶意软件。之所以称它们为特洛伊木马，是因为它们依赖毫无戒心的个人运行它们，从而为攻击者提供了一条进入系统或设备的路径。`远程访问特洛伊木马` 为攻击者提供对系统的远程访问权限。一些合法的远程访问工具被用作 `RATs`，这使得很难判断一个工具是合法的远程支持工具，还是攻击者用于远程访问的工具。反恶意软件工具在发现可能被用作 `RATs` 的远程访问工具时，也可能导致误报，但禁用此检测功能可能导致 `RATs` 未被检测到。安全从业者通常结合使用安全意识培训——鼓励用户不下载不可信软件——以及能够检测特洛伊木马和 `RAT` 类行为及已知恶意文件的反恶意软件工具，来对抗特洛伊木马和 `RATs`。

## 蠕虫

与需要用户交互的特洛伊木马不同，`worms`（蠕虫）会自我传播。虽然蠕虫通常与利用脆弱服务进行传播联系在一起，但任何类型的自动化传播手段都是可能的，这意味着蠕虫也可以通过电子邮件附件、网络文件共享或其他方法进行传播。蠕虫还会自我安装，而不需要用户点击它们，这使它们非常危险。

## Rootkit（Rootkit/隐藏型恶意软件）

`Rootkits` 是专门设计用于允许攻击者通过后门访问系统的恶意软件。许多现代 Rootkit 还包含旨在通过多种技术隐藏自身以逃避检测的功能，这些技术范围从利用文件系统驱动程序确保用户无法看到 Rootkit 文件，到感染磁盘主引导记录（`MBR`）中的启动代码，从而允许针对全盘加密系统发起攻击。

Rootkit 检测具有挑战性，因为感染了此类恶意软件的系统不再可信。这意味着检测 Rootkit 的最佳方法是从受信任的系统或设备测试疑似系统。在无法做到这一点的情况下，Rootkit 检测工具会寻找 Rootkit 典型的行为和特征码。完整性检查和针对预期响应的数据验证等技术对于 Rootkit 检测也很有用，反 Rootkit 工具通常结合使用这些技术来检测复杂的 Rootkit。

一旦发现 Rootkit，清除工作可能很棘手。虽然一些反恶意软件和反 Rootkit 工具能够清除特定的 Rootkit，但只要条件允许，最常见的建议是重建系统或从已知良好的备份中恢复。随着虚拟机、容器、系统镜像和软件定义环境变得更加普遍，它们简化了恢复流程，在许多情况下，恢复速度可能与确保感染 Rootkit 的系统已被正确且彻底清理的速度一样快，甚至更快。

与您将在此处读到的许多恶意软件类型一样，防范 Rootkit 的最佳方法是常规安全实践，包括打补丁、使用安全配置，并确保使用权限管理。安全启动等工具以及可验证实时系统和文件的技术，也可用于帮助防止 Rootkit 成功安装或持久驻留。

## 后门

`Backdoors`（后门）是绕过正常身份验证和授权程序、允许攻击者访问系统、设备或应用程序的方法或工具。后门可以基于硬件或软件，但在 `Security+` 考试的大多数场景中，您将关注基于软件的后门。

与我们在此讨论的许多恶意软件类型一样，恶意软件感染可能包含多种恶意软件工具。事实上，特洛伊木马和 Rootkit 通常包含后门，以便攻击者访问它们已感染的系统。

正如 Rootkit 一样，软件和硬件制造商有时也会使用后门为系统和软件提供持续访问权限。制造商安装的后门令人担忧，因为它们可能未被披露，如果被攻击者发现，它们可以提供您可能不知情的访问权限。

检测后门有时可以通过检查意外开放的端口和服务来完成，但更复杂的后门工具可能利用现有服务。示例包括基于 Web 的后门，它们在现有 Web 服务下需要不同的 `URL`，以及通过使用加密或混淆通道隧道传输到远程控制主机来隐藏其流量的后门。

## 僵尸程序

`Bots`（僵尸程序/受控端）是感染了恶意软件的受远程控制系统或设备。僵尸程序组被称为 `botnets`（僵尸网络），攻击者控制僵尸网络以执行各种操作，范围从进一步的入侵和感染，到拒绝服务攻击或充当垃圾邮件中继。大型僵尸网络可能涉及数十万个僵尸程序，有些总数甚至达到数百万。

许多僵尸网络 `命令与控制`（`C&C`）系统以客户端-服务器模式运行，如[图 3.1](#c03.xhtml#c03-fig-0001)所示。在此模型中，它们将联系中央控制系统，后者提供命令和更新，并跟踪僵尸网络中有多少系统。互联网中继聊天（`IRC`）过去常用于管理客户端-服务器僵尸网络，但许多现代僵尸网络依赖安全 `HTTP`（`HTTPS`）流量来帮助隐藏 `C&C` 流量，并防止防御者轻松监控和分析。
