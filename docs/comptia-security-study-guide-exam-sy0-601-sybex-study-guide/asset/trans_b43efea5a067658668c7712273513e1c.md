

# 移动设备部署模型

## CYOD（自选设备）

在 CYOD 模型中，组织支付设备费用，通常也支付蜂窝网络套餐或其他连接费用。用户选择设备，有时从首选选项列表中选择，而不是自带他们想用的任何设备。在此类 CYOD 设计中，支持更容易，因为只会遇到有限数量的设备类型，这也可以使安全模型更容易建立。由于 CYOD 仍将设备留在用户手中，安全性和管理可能仍不那么标准化，尽管这可能会有所不同。

## 部署选项对比

| | 谁拥有设备？ | 谁控制和维护设备 | 描述 |
|---|---|---|---|
| **BYOD** (自带设备) | 用户 | 用户 | 用户自带个人拥有的设备。这提供了更多的用户自由和更低的组织成本，但风险更大，因为组织不控制、保护或管理该设备。 |
| **CYOD** (自选设备) | 组织 | 用户 | 组织拥有设备，但允许用户选择并维护它。 |
| **COPE** (企业拥有，个人启用) | 组织 | 组织 | 企业提供的设备允许合理的个人使用，同时满足企业安全和控制需求。 |
| 企业拥有 | 组织 | 组织 | 企业拥有提供最大的控制权，但灵活性最低。 |

## COPE（企业拥有，个人启用）

在 COPE 模型中，设备归公司所有并由公司管理。COPE 认识到用户不太可能想随身携带两部手机，因此允许在企业设备上进行合理的个人使用。该模型允许组织更全面地控制设备，同时仍允许个人使用。

## 完全企业拥有

完全由企业拥有和管理的设备是受控程度最高的环境，通常更类似于带有完整控制和管理套件的企业 PC。这是选项中最不友好的，因为企业选择和管理的设备将满足企业需求，但通常缺乏更以最终用户为中心的设计的灵活性。

## 实施考量

尽管这些是常见的描述，但实际实施差异很大，每种解决方案之间的界限可能很模糊。这些不是硬性规定，而是组织移动设备部署模型的起点示例，可以帮助推动安全、管理和运营实践的讨论。在实际使用中，审视这些实践的最佳方式是将其视为基于组织需求、能力和实际使用情况的一个光谱的一部分。

## 支持技术

一项可以帮助使移动设备部署更安全的关键技术是使用 `virtual desktop infrastructure (VDI)`（虚拟桌面基础设施），允许相对低安全性的设备访问安全的托管环境。使用 `VDI` 允许设备用户连接到远程环境，执行操作，然后返回设备的正常使用。容器化工具也可以帮助将设备在工作和个人使用环境之间分隔开，允许在设备上运行工作容器或个人容器，而不会混合数据和访问权限。

# 移动设备管理

移动设备可能难以管理，特别是由于操作系统限制、硬件制造商之间的差异、运营商设置和操作系统版本。许多移动设备旨在供个人使用，没有更多面向业务的设备和软件通常拥有的广泛内置控制。当你加上各种各样的设备部署模型时，安全从业者在日益以移动设备为中心的环境中面临真正的挑战。

因此，当管理员和安全专业人员需要管理移动设备时，他们经常求助于 `mobile device management (MDM)`（移动设备管理）或 `unified endpoint management (UEM)`（统一端点管理）工具。`MDM` 工具专门针对 Android 和 iOS 手机、平板电脑和其他类似系统等设备。`UEM` 工具将移动设备、台式机和笔记本电脑以及许多其他类型的设备结合在一个管理平台中。

第三类工具称为 `mobile application management (MAM)`（移动应用程序管理）工具，专门关注部署到移动设备上的应用程序。常见功能包括应用程序交付、配置、更新和版本管理、性能监控和分析、日志记录和数据收集，以及与用户和身份验证相关的各种控制。尽管一些组织在使用 `MAM` 产品，但随着功能更全面的 `MDM` 和 `UEM` 工具接管市场以提供对移动设备的更多控制，它们变得不那么常见。

无论你选择哪种类型的工具，你的组织都可以使用许多功能来确保移动设备及其包含的数据安全。虽然以下列表不是 `MDM`、`UEM` 和 `MAM` 工具中每个可用功能的完整列表，但你需要了解它们每一个，以及为什么你可能想要拥有它，以便为考试做好准备。

## 关键 MDM/UEM/MAM 功能

### 应用程序管理

应用程序管理功能对于允许企业控制应用程序非常重要。这些功能可能包括将特定应用程序部署到所有设备；限制可安装的应用程序；远程添加、删除或更改应用程序及其设置；或监控应用程序使用情况。

### 内容管理

内容管理（有时称为 `MCM`，即移动内容管理）确保对组织文件（包括移动设备上的文档和媒体）的安全访问和控制。移动设备部署的一个主要关注点是组织数据和个人数据在 `BYOD` 和共享使用设备上的混合。内容管理功能将业务数据锁定在受控空间中，然后帮助管理对该数据的访问。在许多情况下，这需要使用 `MDM` 在移动设备上的应用程序来访问和使用数据。

### 远程擦除功能

当设备丢失或被盗，或所有者不再受雇于组织时，会使用远程擦除功能。了解完全设备擦除与只能擦除部署到设备上的组织数据和应用程序的擦除工具之间的区别很重要。在个人拥有设备的环境中，如果使用远程擦除并擦除了设备，可能会产生责任和其他问题。同时，带有确认流程（让你在成功时知道）的远程擦除是帮助保护组织数据的重要组成部分。

### 地理定位和地理围栏

地理定位和地理围栏功能允许你利用手机的位置来决定其操作。一些组织可能只允许企业平板电脑在企业设施内使用，以减少在其建筑物外被盗或数据访问的可能性。其他组织可能希望设备在离开已知区域时自行擦除。除了我们在日常生活中习惯的地图和类似工具的许多地理定位用途外，地理定位还可以帮助定位丢失的设备。

### 屏幕锁、密码和 PIN 码

屏幕锁、密码和 PIN 码都是防止未经授权访问的正常设备安全模型的一部分。屏幕锁定时间设置是基本移动设备安全中最常设置的安全选项之一。就像台式机和笔记本电脑一样，移动设备管理工具还设置密码长度、复杂度以及密码或 PIN 码必须更改的频率等内容。

### 生物识别

生物识别技术在现代设备上广泛可用，指纹和面部识别是最广泛采用和部署的。生物识别可以集成到移动设备管理功能中，以便你可以为特定设备部署用户的生物识别认证，并利用生物识别因素实现额外的安全性或易用性。
