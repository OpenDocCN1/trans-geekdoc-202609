# 第 13 章 无线与移动安全

大多数组织网络的重要部分现在都是无线的，与有线网络相比，无线网络面临许多安全挑战。它们广播信号，且经常可以从组织拥有和管理的空间之外访问。蜂窝网络和点对点商用无线网络甚至完全不在客户的控制范围内，这意味着它们承载的流量可能需要被视为正在遍历潜在的敌对网络路径。

在本章中，您将了解常见的无线连接选项——从蓝牙和蜂窝到 Wi-Fi——以及它们最常使用的网络模型。随后您将深入了解无线攻击。考虑到这一点，您将探索无线网络设计和安全的最佳实践。在此过程中，您还将了解无线认证、多种形式的 EAP，以及如何保护无线控制器和接入点的安全。

本章的后半部分侧重于移动设备管理。移动设备部署模型（如自带设备 [BYOD] 和企业自有、个人启用 [COPE]）是组织关于如何将设备交到最终用户手中的决策的关键部分。一旦部署了这些设备，您还需要对其进行管理，您将了解移动设备管理工具、常见功能和重要的控制能力。通过周密的规划，您可以确保设备在发放或注册时是安全的，在其整个生命周期中得到良好管理，并能处理盗窃、丢失或使用寿命结束的情况。

## 构建安全的无线网络

无线网络遍布我们的组织。从使用强大工具对用户进行认证、管理和监控的企业网络，到家庭和小型企业中用于为住户、客户或访客提供连接的简单无线路由器，Wi-Fi 无处不在。然而，Wi-Fi 网络并非您将遇到的唯一网络类型——蓝牙、蜂窝、Zigbee 和其他类型的连接也存在于组织中。与有线网络不同，这些无线网络不会在组织的墙壁之外停止，这使得无线网络安全成为一个截然不同的挑战。许多设备都有能力创建自组网，或桥接其有线和无线网络连接，这意味着组织中的设备最终也可能成为恶意行为者通往网络或设备本身的路径。

### 连接方式

设计安全网络通常始于对您将要部署或保护的网络连接类型的基本了解。Security+ 考试大纲列出了一系列无线连接类型，将在以下各节中介绍。

#### 蜂窝网络

*蜂窝*网络通过将地理区域划分为“小区”，利用塔的覆盖实现设备与塔或基站之间的无线通信，为手机等移动设备提供连接。现代蜂窝网络使用 LTE（长期演进）4G 及相关技术，以及正在全球稳步部署的新型 5G 网络。5G 需要更高的天线密度，但也提供更大的带宽和吞吐量。蜂窝服务提供商和需要蜂窝连接的组织过去倾向于在 4G 网络需要覆盖的地方放置塔，而 5G 网络将需要更多地关注天线部署，这意味着组织未来可能需要将 5G 天线布局作为建筑和设施设计工作的一部分。

蜂窝连接通常由蜂窝运营商提供，而非组织自身，这与 Wi-Fi 或其他公司可能选择自行实施的技术不同。这意味着蜂窝网络在组织外部是安全的、受管理的和受控的，通过蜂窝连接发送的流量会经过第三方网络。因此，蜂窝数据需要像对待外部网络连接一样对待，而不是自己的企业网络。

#### Wi-Fi

*Wi-Fi* 一词涵盖了一系列用于提供无线联网的无线协议。Wi-Fi 主要依赖 2.4 GHz 和 5 GHz 无线电频段，并在这些频段内使用多个信道以允许多个网络共存。Wi-Fi 信号可以达到相当长的距离，尽管 Wi-Fi 运行的频率会被墙壁和树木等常见障碍物阻挡或削弱。尽管存在这些阻碍，Wi-Fi 网络最重要的安全顾虑之一是它们会超出组织拥有或控制的空间。

表 13.1 列出了当前和历史上的 Wi-Fi 标准，范围从首个广泛部署的 Wi-Fi 标准 802.11b，到目前部署最广泛的标准 802.11ac。802.11ax（即 Wi-Fi 6）正稳步普及，但组织可能仍会广泛部署现有的 802.11ac 设备，直到将其作为正常升级的一部分进行替换。在许多环境中，仍可能遇到 802.11n、802.11g 甚至更旧的标准。

**表 13.1 Wi-Fi 标准、最大理论速率和频率**

| Wi-Fi 标准 | 最大速率 | 频率 |
| :--- | :--- | :--- |
| 802.11b | 11 Mbit/s | 2.4 GHz |
| 802.11a | 64 Mbit/s | 5 GHz |
| 802.11g | 54 Mbit/s | 2.4 GHz |
| 802.11n | 600 Mbit/s | 2.4 GHz 和 5 GHz |
| 802.11ac | 6933 Mbit/s | 5 GHz |
| 802.11ax | 9608 Mbit/s | 2.4 GHz 和 5 GHz<br>6 GHz 频段的额外频率范围 |

幸运的是，WPA2 和 WPA3 等 Wi-Fi 协议提供了安全特性和功能，有助于保护无线信号安全。这些功能包括加密选项、网络帧保护和认证选项。
