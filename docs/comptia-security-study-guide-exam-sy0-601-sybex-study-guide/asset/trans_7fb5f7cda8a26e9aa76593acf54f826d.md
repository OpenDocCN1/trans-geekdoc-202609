# 第 6 章

安全编码

软件无处不在，从面向客户的应用程序和服务到较小的程序，再到为支持业务需求而编写的最小自定义脚本。设计、创建、支持和维护该软件的过程称为软件开发生命周期（`SDLC`）。作为安全从业者，您需要了解 `SDLC` 及其安全影响，以确保组织使用的软件在其整个生命周期内编写良好且安全。

在本章中，您将了解主要的软件开发生命周期模型及其选择原因，示例包括瀑布模型和螺旋模型以及敏捷开发方法。接下来，您将回顾软件开发安全最佳实践和安全软件编码指南。作为其中的一部分，您将回顾软件如何被测试和审查，以及这些流程如何融入 `SDLC`。

最后，您将了解软件中常见的漏洞，包括客户端-服务器和基于 Web 的应用程序。您将学习如何识别和防御软件安全漏洞利用。

## 软件保障最佳实践

构建、部署和维护软件需要在整个软件生命周期中都有安全参与。安全软件开发生命周期包括在软件开发过程的每个阶段纳入安全关注点。
