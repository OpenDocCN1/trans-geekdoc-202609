

# 网络安全服务与管理技术

网络安全服务和管理技术有助于确保网络保持安全。带外管理将管理接口置于单独的 VLAN 或物理网络上，或要求直接连接，以帮助防止攻击者访问管理接口。访问控制列表用于网络设备，根据端口、协议或 IP 地址等信息阻止或允许特定流量。服务质量协议和设置可用于确定流量优先级，以确保重要流量能够通过网络，同时限制攻击和错误配置的影响。由于路由协议缺乏重要的安全功能，路由安全颇具挑战性。经过身份验证的路由协议确实存在，它们有助于限制针对路由协议的攻击所造成的某些影响。DNS 安全也有限，但 DNSSEC 有助于验证 DNS 服务器和响应。必须正确配置 DNS 服务器，以防止区域传送和其他 DNS 攻击。TLS 广泛用于保护网络流量，充当许多其他协议的封装层。监控服务和系统有助于确保它们保持在线和可访问，但由于可生成的信息量巨大，且如果验证和监控未完全验证服务响应，则可能出现误报，因此需要谨慎操作。文件完整性监视器检查文件是否已更改，并可针对更改发出警报，或将现有文件恢复到更改前或删除前的状态。蜜罐和蜜网用于收集有关攻击者的信息，蜜文件和虚假遥测数据用于识别潜在的入侵以及从您环境中的系统收集信息的攻击者。

# 安全协议

安全协议提供了安全发送和接收信息的方法。许多原始的互联网协议是不安全的——它们不提供加密或身份验证，并且可能被捕获、分析或修改。使用协议的安全版本或使用替代的安全服务和协议，是确保网络安全的重要组成部分。关键协议包括语音和视频协议（如 `SRTP`）；电子邮件协议（如 `IMAPS` 和 `POPS`）；以及安全协议（如 `DMARC`、`DKIM` 和 `SPF`）。文件传输可以通过 `SFTP` 或 `FTPS` 完成，而不使用 `FTP`；目录服务可以从 `LDAP` 迁移到 `LDAPS`。某些协议没有那么多或那么完整的安全选项。事实上，`DNS`、路由和 `DHCP` 都缺乏安全通信选项。网络管理员在设计和运营网络时必须考虑到这些因素。

# 用于网络评估的命令行工具

安全专业人员必须知道如何使用命令行工具来收集网络和系统信息。命令行工具是您网络评估和管理工具包的重要组成部分。路由信息可以使用 `ping`、`tracert`、`traceroute` 和 `pathping` 来收集。DNS 信息由 `dig` 和 `nslookup` 提供。关于网络和流量的系统信息可以由 `ipconfig`、`ifconfig`、`netstat`、`arp` 和 `route` 提供。端口扫描通常涉及 `nmap` 和 `Nessus`，但也可以使用一系列其他工具，包括其他基于 IP 的扫描器。`netcat` 是许多安全专业人员使用的多功能工具，因为它体积小、可移植且功能广泛。`curl` 根据 URL 检索信息，`hping` 允许进行数据包构造和分析。OSINT 工具如 `theHarvester`、`Sn1per` 和 `DNSEnum` 允许在不直接与目标系统通信的情况下收集信息。最后，数据包捕获工具如 `tcpdump` 和 `Wireshark` 允许在命令行或 GUI 环境中分析和审查流量，沙箱（如 `Cuckoo`）可用于在安全环境中测试恶意软件的存在。
