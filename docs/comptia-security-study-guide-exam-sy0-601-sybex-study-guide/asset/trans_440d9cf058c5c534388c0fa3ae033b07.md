**7. C.** `Nmap` 是一种端口扫描工具，用于枚举系统上的开放网络端口。`Nessus` 是一种漏洞扫描器，旨在检测系统上的安全问题。`Nslookup` 是一种 DNS 信息收集实用程序。这三种工具都可用于收集信息和检测漏洞。`Metasploit` 是一种利用框架，用于执行攻击，更适合渗透测试的攻击与利用阶段。

**8. A.** 此漏洞可通过 Microsoft 于 2017 年发布的补丁修复。强大的补丁管理程序本应识别并修复缺失的补丁。

**9. B.** 入侵检测系统不检测漏洞；它们检测攻击。其余三种工具都可能发现跨站脚本（XSS）漏洞，但 Web 应用程序漏洞扫描器最有可能检测到它，因为它专门设计用于测试 Web 应用程序。

**10. A.** 从一台受损系统移动到同一网络上的其他系统称为横向移动。权限提升攻击增加攻击者对已受损系统的访问级别。足迹分析和 OSINT 是侦察技术。

**11. A.** 红队在尝试访问目标网络上的系统时使用进攻性黑客技术。蓝队负责管理组织的防御。白队作为演习的中立仲裁者。紫队演习在演习后进行，旨在将红队和蓝队聚集在一起进行知识共享。

**12. C.** 漏洞赏金计划旨在允许外部安全专家测试系统并发现先前未知的漏洞。漏洞赏金计划为成功的测试人员提供经济奖励，以激励他们的参与。

**13. D.** 后门是一种持久化工具，旨在确保攻击者的访问权限在原始漏洞被修复后依然保留。Kyle 可以在未来使用此后门访问系统，即使他用于获取访问权限的原始漏洞利用不再有效。

**14. C.** `WHOIS` 查询使用外部注册库，是开源情报（OSINT）的一个示例，属于被动侦察技术。端口扫描、漏洞扫描和足迹分析都需要与目标进行主动交互，因此属于主动侦察。

**15. B.** 常见漏洞披露（CVE）为描述与安全相关的软件缺陷提供了标准命名法。通用配置枚举（CCE）为讨论系统配置问题提供了标准命名法。通用平台枚举（CPE）为描述产品名称和版本提供了标准命名法。通用漏洞评分系统（CVSS）为衡量和描述与安全相关的软件缺陷严重程度提供了标准化方法。

**16. C.** 白盒测试在完全了解构成目标的底层技术、配置和设置的情况下执行。黑盒测试旨在复制攻击者会遇到的情况。测试人员不获得对环境的访问权限或信息，而是必须像攻击者一样收集信息、发现漏洞，并穿越基础设施或系统。灰盒测试是黑盒和白盒测试的混合。蓝盒测试不是一种渗透测试类型。

**17. C.** 交战规则提供了测试参数的技术细节。这种详细程度通常不会在合同或工作说明书中找到。经验教训报告是在测试后才产生的。

**18. B.** 所有这些技术都可能为 Grace 提供有关设备上运行的操作系统的信息。然而，足迹分析是专门设计用于获取此信息的技术。

**19. B.** CVSS 基础分在 4.0 到 6.9 之间的漏洞属于中等风险类别。

**20. C.** 所需权限（PR）指标指示攻击者执行攻击所必须具备的系统访问类型。
