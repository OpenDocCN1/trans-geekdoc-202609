

# 第 15 章：数字取证

数字取证为组织提供了调查和分析工具及技术，以确定系统或设备上发生了什么。数字取证可能用于响应法律保全和电子取证要求、支持内部调查，或作为事件响应流程的一部分。数字取证在情报和反情报工作中甚至也发挥着作用。

在本章中，您将首先了解驱动取证工作的因素、提供高质量取证数据所需做的工作，以及云环境给这些流程带来的一些挑战。首先，您将了解法律保全、对方律师发出的保存和保留数据的通知，以及它们在电子取证流程中的作用。了解了一些您可能需要取证能力的原因后，您将探索取证数据获取，包括易失性顺序，它标识了面临最大丢失风险的取证工件，因此也确定了需要优先获取的要素。接下来，您将阅读如何确保获取的数据可在法庭上被采纳并作为有用证据，以及必须具备哪些工具和协议来处理从云服务提供商获取取证数据的需求。

本章的后半部分重点介绍取证工具，包括获取工具，如 `dd`、`FTK Imager` 和 `WinHex`。您将探索基本命令和实践，了解验证的重要性以及如何手动执行镜像验证。掌握镜像制作后，取证套件及关键取证套件功能是下一个主题，重点介绍 `Autopsy`，一款开源取证套件。最后，您将回顾取证报告需要包含的内容，以及取证在情报和反情报活动中所扮演角色的详细信息。

## 数字取证概念

组织使用数字取证技术执行的任务范围广泛，从响应法律案件到进行内部调查和支持事件响应流程。作为安全专业人员，您需要了解数字取证背后的基本概念；数字取证的能力；以及组织为建立数字取证能力而采用的工具、流程和程序。

数字取证的一个关键要素是数字取证数据的获取和分析。这些数据可以是驱动器、文件、实时内存副本，以及我们在正常使用计算机和网络过程中创建的其他众多数字工件的形式。由于取证信息可能存在于许多不同的地方，规划取证信息收集对于拥有完整、完整的事件全貌至关重要。收集这些取证数据只是一个涉及仔细记录和详细分析的流程的开始。

在整个过程中，创建文档——包括您观察到的内容、从数据中得出的结论以及支持这些结论的证据——对于取得成功是必要的。您将记录时间线和事件序列，寻找关于发生了什么以及为什么发生的线索，并将使用时间戳、文件元数据、事件日志和大量线索来拼凑出一幅完整的图景。
