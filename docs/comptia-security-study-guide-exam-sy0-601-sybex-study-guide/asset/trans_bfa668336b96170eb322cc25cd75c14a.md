

# 第 4 章：社会工程学、物理攻击和密码攻击

社会工程学技术侧重于信息安全的人为因素。使用社会工程学技术，安全专业人员和攻击者可以完成各种任务，范围从获取信息到进入建筑物、系统和网络。

本章探讨社会工程学技术和相关实践，从垃圾箱翻找到肩窥和鲸钓。我们将讨论社会工程学攻击的基本原则，以及现代影响力活动如何利用社会工程学概念和社交媒体来左右观点和反应。

社会工程学和网络钓鱼攻击通常先于密码攻击，本章后面你将回顾密码攻击方法，如暴力破解攻击、彩虹表和字典攻击。渗透测试人员和攻击者可亲自实施的物理攻击，将完成你对这些攻击方法的探索。

## 社会工程学

社会工程学是通过各种策略操纵他人以实现预期行动的做法。社会工程师致力于影响其目标，使其采取原本可能不会采取的行动。

有许多关键原则被用来成功地实施社会工程学攻击，尽管原则列表及其名称因参考来源而异，但 Security+ 考试重点关注以下七项：

*   **权威**，依赖于大多数人会服从看似掌权或知识渊博之人的命令这一事实，无论他们实际上是否如此。利用权威原则的社会工程师可能会声称自己是经理、政府官员，或其他在他们所处情境中拥有权威的人。
*   **恐吓**依靠恐吓或欺凌个人使其采取预期行动。被针对的个人会感到受到威胁，并通过做社会工程师希望他们做的事来回应。
*   **共识**型社会工程学利用人们倾向于做别人正在做的事情这一事实来说服他们采取行动。基于共识的社会工程学攻击可能会指出某部门的其他所有人都已经点击了某个链接，或者可能提供关于产品的虚假推荐，使其看起来很安全。在某些分类体系中，共识被称为“社会认同”。
*   **稀缺性**用于社会工程学场景，通过让某物看起来像是最后一个可用的而使其更具吸引力。
*   **熟悉度**型攻击依赖于你喜欢该个人，甚至该个人声称代表的组织。
*   **信任**，很像熟悉度，依赖于与被针对个人的联系。与熟悉度不同，信任依赖于目标相信社会工程师是诚实的，并且会兑现他们的承诺或威胁。
*   **紧迫性**迫使目标快速行动，通常没有时间进行批判性思考或验证请求。紧迫性通常与其他原则结合使用，例如权威或恐吓。

这些原则很少单独使用。当社会工程师结合使用它们时——例如，声称自己是高级领导（权威），然后坚持该高级领导有紧急需求（紧迫性），并告知目标如果不立即采取行动可能会失去工作（恐吓）——在许多情况下，他们比仅使用单一原则更有可能成功。社会工程学的一个关键部分是了解目标、人类如何反应，以及如何利用压力反应来达到目的。

### 社会工程学技术

社会工程学不仅涉及你刚读到的原则。还有技术性和非技术性攻击，它们利用这些原则来实现攻击者和渗透测试人员想要的结果。作为安全专业人员，你需要了解这些技术、它们包含的内容，以及是什么让它们彼此不同。

#### 网络钓鱼

**网络钓鱼**是一个广义术语，用于描述欺诈性地获取信息，通常专注于用户名和密码等凭证，以及信用卡号码和相关数据等敏感个人信息。网络钓鱼最常通过电子邮件进行，但存在各种网络钓鱼技术，包括**短信钓鱼**，即通过短信进行的网络钓鱼，以及**语音钓鱼**，即通过电话进行的网络钓鱼。
