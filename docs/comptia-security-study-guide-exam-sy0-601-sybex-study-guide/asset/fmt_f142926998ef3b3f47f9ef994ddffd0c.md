
# 恶意软件概述

恶意软件有多种形式。

- **勒索软件**：加密您的文件，或威胁在您不付款或不执行某项操作时泄露您的数据。
- **特洛伊木马**：外观看似合法软件，实则为恶意程序。
- **蠕虫**：自我传播，通常以易受攻击的应用程序或服务为目标。
- **Rootkit**：帮助攻击者访问系统并长期维持访问权限。
- **后门**：绕过身份验证和系统安全，允许攻击者（有时甚至是合法用户）通过隐蔽的访问方法进入系统。
- **僵尸程序**：使系统成为命令与控制网络的一部分，允许攻击者同时控制大量系统执行诸如发起 DDoS 攻击等操作。
- **键盘记录器**：捕获按键，以便攻击者窃取密码或其他敏感数据。
- **逻辑炸弹**：等待特定事件发生后才造成损害或执行其他不需要的操作。
- **病毒**：自我复制和自我传播。
- **无文件病毒**：驻留在内存中，不驻留在磁盘上，因此更难发现和清除。

除了真正的恶意软件，**间谍软件**是一种监视用户并将信息提供给广告商或其他人的恶意软件。**潜在有害程序（PUP）**不像其他类型的恶意软件那样危险，但它们可能会令人讨厌，例如广告软件或大多数用户不希望其系统上安装的其他软件。

像脚本和宏这样的恶意代码也会对系统构成威胁，攻击者经常利用内置脚本语言（如 `PowerShell` 或 `Bash`），以及常见编程语言（如 `Python` 和 `Perl`）来进行恶意活动。确保恶意代码无法轻易运行，是保护系统免受此类攻击的组成部分。

最后，对抗性 AI 领域出现了新的攻击者。随着机器学习和人工智能变得越来越普遍，新的方法侧重于如何通过提供错误数据或修改其编程来利用 AI 和 ML 系统，以产生预期的恶意效果。

## 考试重点

**存在多种类型的恶意软件。** 恶意软件包括勒索软件、特洛伊木马、蠕虫、潜在有害程序、无文件病毒、僵尸程序及其相关的命令与控制系统、加密恶意软件、逻辑炸弹、间谍软件、键盘记录器、远程访问特洛伊木马、Rootkit 和后门。每种类型的恶意软件都有独特的元素，您需要了解什么标识每种类型的恶意软件、如何识别它、通常部署哪些控制措施来对抗它，以及遇到它时该怎么做。

**脚本和其他代码可能是恶意的。** 内置脚本语言和工具（如 `PowerShell`、`Python`、`Bash`）以及宏语言（如 `Visual Basic for Applications (VBA)`）都可能被攻击者利用。无文件恶意软件通常利用 `PowerShell` 在利用浏览器或插件中的缺陷访问 Windows 系统后下载并执行自身。攻击者可以使用 `Python` 等语言运行难以在 Linux 系统上检测到的代码，从而实现远程访问和其他活动。Office 文档中包含的宏要求用户启用它们，但社会工程学可以帮助攻击者绕过默认安全设置。

**对抗性人工智能是一种新兴威胁。** 随着人工智能和机器学习在整个行业中变得越来越普遍，攻击者也开始研究如何将它们作为攻击的一部分加以利用。将错误或受污染的数据引入机器学习环境，可以帮助攻击者隐藏恶意软件，或以其他方式降低 ML 工具和基于 AI 的检测及安全系统的有效性。同时，用于 AI 和 ML 工具的算法也可能受到攻击，对这些算法的修改可能会使攻击者受益。

## 复习题

1.  Gurvinder 被要求协助一家最近解雇了一名开发人员的公司。该开发人员被解雇后，其为组织编写的关键应用程序停止工作，并显示一条消息：“You shouldn't have fired me!” 如果该开发人员的访问权限已被终止，且组织认为他们离开后无法访问任何系统或代码，Gurvinder 应寻找哪种类型的恶意软件？

    1.  RAT
    2.  PUP
    3.  逻辑炸弹
    4.  键盘记录器

2.  Naomi 认为攻击者使用无文件恶意软件包攻破了一台 Windows 工作站。最有可能用于下载和执行恶意软件的 Windows 脚本工具是什么？

    1.  VBScript
    2.  Python
    3.  Bash
    4.  PowerShell

3.  Scott 发现其网络上的一台系统通过加密的 Web 流量联系了多个系统，下载了少量文件，然后向远程系统上传了大量数据。他应寻找哪种类型的感染？

    1.  键盘记录器
    2.  后门
    3.  僵尸程序
    4.  逻辑炸弹

4.  Amanda 发现其系统与已知恶意主机之间在 TCP 6667 端口上存在流量。她最有可能检测到哪种类型的流量？

    1.  命令与控制
    2.  被劫持的 Web 浏览器
    3.  RAT
    4.  蠕虫

5.  Mike 发现攻击者在其公司网络中的一台计算机上留下了允许他们远程访问系统的软件。他应如何描述或分类此恶意软件？

    1.  蠕虫
    2.  加密恶意软件
    3.  特洛伊木马
    4.  后门

6.  Naomi 希望为如何保护其组织的新机器学习工具提供指导。以下哪项不是保护机器学习算法的常用手段？

    1.  了解源数据的质量
    2.  为 ML 开发人员构建安全的工作环境
    4.  要求第三方审查 ML 算法中的偏见
    5.  确保对 ML 算法的更改经过审查和测试

7.  广告软件通常被归类为哪种类型的恶意软件？

    1.  DOG
    2.  后门
    3.  PUP
    4.  Rootkit

8.  Matt 将恶意软件样本上传到一个使用多个反恶意软件和防病毒引擎扫描样本的第三方恶意软件扫描网站。他收到了几个不同的答案来标识该恶意软件包。发生了什么？

    1.  该包包含不止一段恶意软件。
    2.  该服务配置错误。
    3.  恶意软件具有多态性，在测试过程中发生了变化。
    4.  不同供应商对恶意软件包使用不同的名称。

9.  Nancy 担心她正在调查的系统上存在软件键盘记录器。可能被窃取了哪些数据？

    1.  系统上的所有文件
    2.  所有键盘输入
    3.  键盘记录器处于活动状态时用户访问的所有文件
    4.  用户的键盘和其他输入

10. 加密恶意软件属于哪种类型的恶意软件？

     1.  蠕虫
     2.  PUP
     3.  勒索软件
     4.  Rootkit

11. Rick 认为他负责的一台系统已被使用 Rootkit 获取并保持访问权限的恶意软件攻破。当他运行病毒扫描时，系统未显示任何恶意软件。如果他有其他数据表明系统已被感染，为了确定系统上可能存在什么恶意软件，他的下一步应该是什么？

     1.  重新运行反恶意软件扫描。
     2.  将驱动器挂载到另一台系统上并以那种方式扫描。
     3.  禁用系统的防病毒软件，因为它可能导致误报。
     4.  系统未被感染，他应该继续处理其他事务。

12. Tracy 担心针对其组织用于评估网络的机器学习算法的攻击。为确保其基线数据未被污染，她应采取什么步骤？

     1.  她应扫描网络上的所有系统以查找漏洞，并在使用算法前进行修复。
     2.  只有在她认为网络安全的情况下，才应在网络上运行 ML 算法。
