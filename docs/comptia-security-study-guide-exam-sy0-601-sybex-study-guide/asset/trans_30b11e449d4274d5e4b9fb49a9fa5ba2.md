

# 网络工具和实用程序

## Traceroute 和 Pathping

在 Windows 中，该命令称为 `tracert`，而在 Linux 中称为 `traceroute`。这两个命令的功能非常相似。[图 12.5](#c12.xhtml#c12-fig-0007) 显示了针对 `www.wiley.com` 的 Windows `tracert` 命令。Wiley 使用亚马逊提供的 CloudFront 内容分发系统来分发其网页，这意味着 Wiley 网站解析到一个 CloudFront 主机。前 11 跳中的每一跳都显示了流量经过的设备的主机名或 IP 地址。首先是一个家用路由器，然后显示各种 Time Warner Cable（`rr.com`）地址。第 12-23 跳无法解析，最后到达 CloudFront 目标。

![图 12.5 www.wiley.com 的示例 tracert](images/c12f005.png)

**图 12.5** `www.wiley.com` 的示例 `tracert`

`traceroute` 与 `tracert` 在一个关键方面表现不同：`traceroute` 发送 UDP 数据包，而 Windows 上的 `tracert` 发送 ICMP 数据包。这意味着您可能会收到路径上主机的不同响应。然而，每个测试过程的基本功能是相同的：生存时间 (TTL) 值从 1 开始设置，并随每个发送的数据包递增。路由器将 TTL 减 1，丢弃 TTL 为 0 的数据包，并针对这些数据包发回 ICMP 超时消息。这会告诉 `traceroute` 路径中每一步的路由器是哪个。您还会注意到显示了延迟信息，这有助于识别是否存在缓慢或有问题的链路。

`pathping` 是一种 Windows 工具，它也可以追踪到目标的路由，同时提供延迟和丢包信息。`pathping` 在一段时间内计算数据，而不是单次路径遍历，从而提供关于网络上可能发生情况的更多见解，但它可能会慢得多，因为每一跳都有 25 秒的时间来收集统计数据。[图 12.6](#c12.xhtml#c12-fig-0006) 显示了针对 `www.wiley.com` 的 `pathping`。

除了路径信息，技术人员通常还需要 DNS 信息。这就是 `nslookup` 和 `dig` 的用武之地。两者都可以执行 IP 地址查找以返回域名，或执行域名查找以返回 IP 地址。两者还可以查找特定的 DNS 信息，如 MX（邮件服务器）、A 记录和其他 DNS 记录。用户可以手动选择特定的 DNS 服务器或配置其他选项。

![图 12.6 www.wiley.com 的示例 pathping](images/c12f006.png)

**图 12.6** `www.wiley.com` 的示例 `pathping`


您可能想知道为什么要选择使用 `dig` 而不是输出简单、清晰的 `nslookup`。`dig` 提供更多数据，您可以用它来执行诸如使用 `dig @server example.com ns` 请求域的所有名称服务器，或使用 `dig @server example.com axfr` 执行区域传输等操作。这意味着当需要更强大的工具时，经常会使用 `dig`。

## 系统级网络信息

收集关于系统的网络信息是技术人员的另一项常见任务。Security+ 考试重点关注四种常在本地系统上运行以收集其网络配置和状态信息的工具：

*   `ipconfig` (Windows) 和 `ifconfig` (Linux) 显示其运行所在主机的当前 TCP/IP 网络配置。这将包括系统上存在的接口、IPv4 和 IPv6 IP 地址、与这些接口关联的 MAC 地址、连接速度、网络掩码、广播域以及关于连接的其他详细信息。这两个命令也可用于启用和禁用接口、刷新或释放 DHCP 地址以及控制网络接口。

*   `netstat` 按协议提供网络统计信息，包括每个连接的本地地址和远程地址，以及 TCP 连接的状态。其他统计信息（如按进程 ID 列出的开放端口、网络接口列表和服务）在不同版本中的可用性各不相同。

*   `arp` 提供关于本地主机 ARP 缓存的信息。在 Windows 系统上，使用 `-a` 标志将显示系统上每个接口的当前 ARP 缓存，但在 Linux 系统上，相同的标志将显示 ARP 信息的另一种格式。`arp` 可用于从 ARP 表中添加和删除主机，并作为被动侦察工作的一部分。

*   `route` 用于显示和修改系统的路由表。与此处列出的许多其他工具一样，`route` 的功能和标志在 Windows 和 Linux 之间有所不同。尽管命令行有差异，但这两个工具都具有添加、显示和删除路由的相似底层功能。

## 端口和漏洞扫描

扫描系统、端口和漏洞是安全从业者和网络管理员的常见任务。发现设备、识别它们提供的服务以及存在的任何漏洞，对于防御者、渗透测试团队和攻击者来说都是必要的。许多工具可以执行这些功能，但 Security+ 考试重点关注两种常用工具和一类通用工具：`nmap`、Nessus 和 *IP 扫描器*。

`nmap` 是一款非常流行的端口扫描工具，适用于 Windows 和 Linux。它可以扫描主机、服务、服务版本和操作系统，并可通过脚本提供额外功能。基本的 `nmap` 用法非常简单：`nmap [` *`主机名`* 或 *`IP 地址`* `]` 将扫描一个系统或网络范围。其他标志可以控制扫描类型，包括 TCP 连接、SYN 和其他扫描类型、端口范围以及许多其他功能。

[图 12.7](#c12.xhtml#c12-fig-0007) 显示了对一个开放多种服务的示例系统的 `nmap` 扫描。您会立即注意到潜在的脆弱服务，如 FTP、两个数据库服务、IRC 以及各种其他有趣的服务。管理员可以使用端口扫描来识别意外的系统和服务，并检查他们可能无法直接访问的系统上的配置更改。

![图 12.7 来自系统的示例 nmap 扫描](images/c12f007.png)

**图 12.7** 来自系统的示例 `nmap` 扫描

*Nessus* 是一款漏洞扫描工具。虽然 `nmap` 只会识别正在运行的服务的端口、协议和版本，但 Nessus 会尝试识别该服务是否存在漏洞，并提供这些漏洞的完整报告及有用信息，包括文档和修复程序的参考。Nessus 的替代品（如开源的 OpenVAS 和商业工具 Rapid7 的 Nexpose）也常与 Nessus 一起部署，但 Security+ 考试大纲重点关注 Nessus。
