

# 数字取证中的人为因素

数字取证中的人为因素也可能很重要；对涉案人员的访谈可以提供重要线索。这意味着在某些情况下，你不能仅仅是一名技术取证专家——相反，你必须利用你对技术和人类行为的双重知识来完成你的取证工作。

## 法律保全与电子取证

在许多情况下，当诉讼正在进行或预期将会发生时，取证工作便随之开始。法律顾问可以发送**法律保全通知**或诉讼保全通知，这是一份通知，告知组织必须保留在正常运营过程中可能会被销毁或修改的数据和记录。各类备份、纸质文档和电子文件都必须得到保存。

法律保全通知通常是电子取证或**电子发现**流程的首要环节之一。发现程序允许法律案件的各方从对方及其他涉案方获取证据，而电子发现就是电子化的发现程序。除了法律案件，发现程序也常用于公共记录、《信息自由法》请求和调查。使用框架来审视电子发现会有所帮助，**电子发现参考模型 (EDRM)** 就是一个有用的模型。EDRM 模型通过九个阶段来描述发现程序：

1.  **信息治理**：事前进行，以评估存在哪些数据，并允许对需要提供的数据进行范围界定和控制。
2.  **识别**：识别电子存储信息，以便了解拥有什么数据以及数据存储在何处。
3.  **保全**：保全信息，确保其不被更改或销毁。
4.  **收集**：收集信息，以便将其作为收集过程的一部分进行处理和管理。
5.  **处理**：处理数据以移除不需要或无关的信息，并通过格式化或整理使其做好审查和分析的准备。
6.  **审查**：审查数据以确保其仅包含应有的内容，且不包含不应共享的信息。
7.  **分析**：分析信息以识别关键要素，如主题、术语、个人或组织。
8.  **生成**：生成数据，向第三方或法律程序相关方提供信息。
9.  **呈现**：呈现数据，既用于法庭作证，也用于与专家或相关方进行进一步分析。

这一过程中最重要且同时最具挑战性的要求之一，可能是电子信息的保全，特别是当法律保全或发现程序涵盖的数据频繁被组织内的用户使用或修改时。电子发现和法律保全支持工具可以提供帮助，它们具备为处于诉讼保全状态的用户或群组捕获数据的能力。这些工具通常带有桌面、移动设备和服务器代理，可收集数据、跟踪变更，并在整个法律保全时间范围内记录数据的适当处理情况。在频繁处于法律保全状态的组织中，CEO、总裁等常成为诉讼目标的高管，长期处于近乎持续的法律保全和发现状态并不罕见。

云运营使电子发现变得更加复杂。云供应商提供服务，但不会允许你在其云服务中植入侵入式的法律保全和发现代理。这意味着在采用云服务时，你必须解决如何应对这些服务的法律保全问题。像 **Google Vault** 这样的工具同时提供电子邮件归档和发现支持，帮助组织满足其发现要求。

## 实施数字取证

取证数据是使用取证工具获取的，如磁盘和内存成像工具、镜像分析和时间线工具、可显示磁盘上数据内容和结构详细信息的低级编辑器，以及其他专用工具。Security+ 考试重点关注获取的关键方面，包括易失性顺序，以及如何以及为何从常见位置和设备获取数据的详细信息。

### 获取取证数据

当取证从业者计划获取数据时，他们要审查的第一件事之一是**易失性顺序**。易失性顺序记录了因系统操作或正常进程而最可能丢失的数据。[图 15.1](#c15.xhtml#c15-fig-0001) 展示了一个典型的易失性顺序图表。请注意，CPU 寄存器和缓存状态等频繁变化的信息排在首位，因此易失性最高；随后是路由信息、进程和内核统计信息。随着列表往下，每个项目迅速消失的可能性逐渐降低，备份数据最不可能发生变化。遵循易失性顺序进行获取——除非有令人信服且紧迫的理由偏离该列表——将使取证分析师最大程度地完整捕获数据。重要的是要记住，当系统关机或重启时，哪些项目会消失。一般来说，在该列表中，临时文件和交换空间位于第 4 位会发生这种情况。能否恢复完整的临时文件和交换空间中的数据，取决于系统是如何关闭的，以及之后是否成功重启。

Security+ 考试要求你熟悉针对以下取证目标获取信息的基本概念：

*   **CPU 缓存和寄存器**极少作为常规取证工作的一部分被直接捕获。尽管可以使用专用硬件或软件捕获其中一些信息，但大多数调查不需要这种级别的细节。随着处理过程的进行，CPU 缓存和寄存器在不断变化，因此具有极高的易失性。
*   **临时性数据**，如进程表、内核统计信息、系统的 **ARP 缓存** 等，可以通过内存和磁盘获取相结合的方式捕获，但必须记住，捕获只能反映获取那一刻的时间点状态。如果事件发生在过去，这些数据可能无法反映事件发生时系统的状态。
*   **随机存取存储器 (RAM)** 的内容对调查和事件响应都非常有帮助。内存中可能包含加密密钥、来自应用程序的临时性数据，以及可能未写入磁盘但对调查有用的信息。
*   **交换空间和页面文件** 信息是用于补充物理内存的磁盘空间。与从 RAM 捕获信息非常相似，捕获交换空间和页面文件可以深入了解运行中的进程。由于系统会主动使用它，特别是在内存较小的机器上，它的变化速度也比磁盘上的许多文件要快。
*   **磁盘上的文件和数据** 变化较慢，但却是许多调查的主要焦点。重要的是要捕获整个磁盘，而不仅仅是复制文件，以便查看仍驻留在磁盘上的已删除文件和其他残留痕迹。
*   **操作系统** 本身可能包含有用信息。**Windows 注册表** 是分析的常见目标，因为 Windows 中的许多活动都会修改或更新注册表。
*   **设备**，如智能手机或平板电脑，也可能包含作为取证目标的数据。
*   **固件** 是较少成为取证目标的工件，但如果固件作为事件的一部分被修改，或者固件可能包含取证相关数据，则知道如何从设备复制固件可能是必要的。固件通常可通过硬件接口（如串行电缆或直接 USB 连接）或通过内存取证技术访问。
