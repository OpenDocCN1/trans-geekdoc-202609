
由于擦除驱动器可能会出现问题，因此销毁驱动器是希望消除数据丢失或泄露风险的组织的常用选择。将驱动器粉碎、粉碎或焚烧，使得无法恢复任何数据，这是一种选择，第三方供应商专门提供此类服务，并为每个被销毁的资产（驱动器或系统）提供文档记录。尽管这会导致部分潜在可回收价值的损失，但对于做出此决定的组织来说，在风险计算中，较旧驱动器的剩余价值远低于单次违规的成本。

### 文件操作和其他有用的命令行工具

与 Linux 和 Unix 系统及设备上的文件进行交互是许多安全专业人员熟悉的任务。快速从文件收集信息、操作文件、更改其权限或仅仅是搜索文件的能力，可以在成功处理事件、识别问题或加快操作任务方面发挥关键作用。Security+ 考试重点关注六种命令行工具：

*   `head` 是一个显示文件开头部分的命令。默认情况下，它将显示文件的前 10 行，使其成为快速查看文件内容的实用工具。您可以使用 `-n` 标志更改显示的行数，并通过在命令行中包含多个文件来显示多个文件的行。要查看名为 `example.txt` 的文件的前 15 行，请输入：`head -n 15 example.txt`。

*   `tail` 与 `head` 命令非常相似，但默认情况下它显示文件的最后 10 行。`tail` 常用于查看最近的日志条目或文件中正在变化的其他数据。与 `head` 一样，您可以添加 `-n` 标志来显示任意数量的行，但在许多情况下最有用的模式是 `-f` 标志，它会跟踪变化。使用 `tail -f` 将显示文件随变化而更新的内容。与 `head` 一样，您也可以同时监控多个文件。

*   `cat` 是 concatenate（连接）的缩写，可用于将文件输出到标准输出（您的控制台）或将文件追加到其他文件。输入 `cat example.txt` 将在控制台显示 `example.txt` 的内容。输入 `cat more.txt > example.txt` 将把 `more.txt` 的内容添加到文件 `example.txt` 中。`cat` 命令还有许多其他有用的功能，您可以通过 [shapeshed.com/unix-cat](http://shapeshed.com/unix-cat) 上通俗易懂的示例了解它们。

*   `grep` 是一种搜索工具，允许您搜索与提供的文本或正则表达式匹配的模式。在其最基本的形式中，您可以通过输入 `grep 'word' /file/location` 来搜索单词，将 `word` 替换为您要查找的单词或文本字符串，将 `/file/location` 替换为您要搜索的文件或目录位置。`grep` 命令有许多方便的功能，例如 `-A` 和 `-B` 选项，当提供一个数字作为输入时，它们将在匹配模式之后或之前打印指定数量的行。这使得 `grep` 成为快速搜索日志和其他文本文件以查找特定信息的理想工具。还有许多其他有用的 `grep` 标志，因此如果您还不熟悉 `grep` 的基础知识，我们建议您花些时间阅读手册页或 `grep` 教程。

*   `chmod` 允许您使用符号或数字表示法设置文件和目录的权限。要为 `example.txt` 设置读、写和执行权限，您可以发出命令 `chmod 777 example.txt`。您也可以通过输入 `chmod +rwxrwxrwx example.txt` 设置相同的权限。了解如何设置特定权限以及如何读取权限（参见[图 11.4](#c11.xhtml#c11-fig-0004)），对于确保文件和目录安全至关重要。

*   `logger` 是 Security+ 考试包含的命令中最不为人知的一个。`logger` 命令会将您提供的任何输入信息追加到系统上的 `/var/log/syslog` 文件中。`logger` 还可以通过调用其他命令或文件，将来自它们的信息添加到 syslog 文件中。

### 脚本、安全传输和 Shell

您端点安全工具包中的另一组有用工具是 Shell 和脚本语言。连接到命令行界面或在本地系统上使用它，然后执行我们刚才探讨的文件操作命令等，提供了控制和管理系统的强大能力。Security+ 考试关注远程访问以及您应该了解的两种脚本环境。

安全 Shell，或 `SSH`，是一种用于连接系统的加密协议，通常通过命令行进行。SSH 也是使用 SSH 协议创建该连接的客户端的名称。一旦通过 SSH 连接，您就可以在您正在使用的系统所运行的任何 Shell 环境中发出命令。

Windows 系统拥有一个内置的管理、自动化和脚本语言工具，称为 PowerShell。PowerShell 脚本和命令允许从命令行管理和配置 Windows 系统。PowerShell 可以报告系统的当前状态，对本地和远程系统进行更改，并具有许多其他功能，使其成为攻击者和防御者都青睐的工具。

像 Python 这样的脚本语言也被用于系统管理和维护任务，以及通过自动化为用户提供解决复杂任务的强大方式。尽管 Python 变得越来越普遍，但 Perl 和其他语言仍然被用于脚本编写和作为软件包的一部分，特别是针对 Linux 和基于 Unix 的系统。

Security+ 考试在本节中重点关注的最后一个工具是 OpenSSL。OpenSSL 不是 Shell，也不是脚本语言。相反，就像 SSH 一样，OpenSSL 是 TLS 协议的一种实现，常用于保护其他服务。OpenSSL 的 TLS 实现用于 HTTPS 流量；每当需要以受保护的方式通过网络发送流量，而通过 SSH 或 VPN 连接建立隧道并不合适时，OpenSSL 很可能是一个合理的替代方案。作为安全专业人员，您需要知道 OpenSSL 经常被用来封装这种流量，因此您会在许多地方遇到嵌入式的 OpenSSL。

Security+ 考试期望您知道如何使用 OpenSSL 作为评估组织安全性的一部分。对于安全分析师来说，这通常包括寻找需要安全通信但缺失的地方，或 OpenSSL 配置错误的地方。这意味着您需要了解为什么要使用它，并了解它带来的有助于提高组织通信安全性的功能。TLS 协议的关键要素之一是它提供了临时 RSA 密钥交换以创建完美前向保密。换句话说，只有在知道密钥时才能解密会话，并且临时密钥是在两个系统之间通信开始时生成的。因此，当两个以前可能从未通信过的系统需要安全通信时，使用 OpenSSL 和 TLS 是理想的解决方案。网站一直在为此目的使用 TLS，您对托管网站或其他服务的系统进行的安全评估——在这些系统中，系统可能需要在没有额外配置或事先通信的情况下安全通信——应将 OpenSSL 和 TLS 识别为一种安全选项。
