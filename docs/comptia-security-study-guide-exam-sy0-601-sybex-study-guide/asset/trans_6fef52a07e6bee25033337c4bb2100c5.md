

# 安全评估与测试

## 攻击阶段

*   **初始访问**是指攻击者利用漏洞获取对组织网络的访问权限。
*   **权限提升**使用黑客技术将攻击者获得的初始访问权限转变为更高级的权限，例如在同一系统上的 root 访问权限。
*   **跳板攻击**，或**横向移动**，是指攻击者利用初始系统的沦陷来获取对目标网络上其他系统的访问权限。
*   攻击者通过安装后门和使用其他机制在被攻陷的网络上建立**持久性**，这些机制将允许他们重新获得对网络的访问权限，即使最初的漏洞已被修补。

## 利用框架

渗透测试人员在执行工作时会使用许多真实攻击者使用的相同工具。**利用框架**（如 Metasploit）通过提供模块化的方法来配置和部署漏洞利用代码，简化了漏洞的利用过程。

## 清理工作

渗透测试结束时，测试人员会执行收尾活动，包括向管理层汇报结果并清理其工作留下的痕迹。测试人员应移除其安装在系统上的任何工具以及其建立的任何持久性机制。收尾报告应向目标方详细说明测试期间发现的漏洞，并就改善组织网络安全态势提供建议。

## 培训与演练

组织开展各种培训计划，旨在帮助员工了解其在网络安全方面的角色。网络安全分析师经常参加以竞赛形式设置的演练类培训计划，让一支攻击团队对抗一支防御团队。

开展演练有助于识别组织系统、网络和应用程序中的漏洞，其效果类似于渗透测试的结果。演练还为员工提供了攻击和防御系统的实战经验。这有助于提升技术人员的网络安全技能和意识。

进行演练时，参与者通常分为三组：

*   **红队**成员是攻击者，他们尝试获取对系统的访问权限。
*   **蓝队**成员是防御者，他们必须保护系统和网络免受攻击。蓝队在演练期间还会监控环境，实施主动防御技术。蓝队通常会获得先发优势，在演练攻击阶段开始前拥有一些时间来加固系统。
*   **白队**成员是观察员和裁判。他们作为仲裁员解决关于规则的争议，并观察演练以记录测试中的经验教训。白队能够观察红队和蓝队双方的活动，还负责确保演练不会导致生产环境问题。

### 夺旗 (CTF) 演练

夺旗 (CTF) 演练是实现培训目标的一种有趣方式。在 CTF 演练中，红队从设定的目标开始，例如破坏网站、从安全系统中窃取文件或导致其他安全故障。演练根据红队达成的目标数量与蓝队阻止其执行的目标数量进行评分。

### 演练环境

演练不必使用生产系统。在许多情况下，组织可能会专门为演练目的搭建一个特殊环境。这为测试提供了一个安全的沙箱，并最大限度地降低了攻击破坏生产系统的可能性。其他演练甚至可能完全不使用真实系统。**桌面推演**只是将参与者聚集在同一房间，演练他们对�构场景的响应。

## 总结

安全评估与测试在网络安全计划的持续管理中发挥着至关重要的作用。本章讨论的技术有助于网络安全专业人员维护有效的安全控制，并及时了解可能改变其安全态势的环境变化。

漏洞扫描可识别系统、应用程序和设备中潜在的安全问题，使团队能够在攻击者利用这些问题之前进行修复。这些扫描期间可能检测到的漏洞包括补丁管理不当、弱配置、默认账户以及不安全协议和密码的使用。

渗透测试让安全专业人员扮演攻击者的角色，要求他们对目标发起进攻性行动，以发现安全问题。渗透测试的结果为改进安全控制提供了路线图。

## 考试要点

**现代计算环境中存在许多漏洞。** 网络安全专业人员应时刻关注本地部署和云环境中漏洞带来的风险。不当或薄弱的补丁管理可能是许多漏洞的根源，为攻击者提供了利用操作系统、应用程序和固件的路径。造成漏洞的弱配置设置包括开放权限、不安全的 root 账户、错误、弱加密设置、不安全协议使用、默认设置以及开放的端口和服务。当扫描检测到一个并不存在的漏洞时，该报告称为**误报**。当扫描未能检测到实际存在的漏洞时，该报告称为**漏报**。

**威胁狩猎发现现有的妥协/沦陷。** 威胁狩猎活动假定组织已经遭到入侵，并搜寻这些入侵的指标。威胁狩猎工作包括在情报融合计划中使用通告、公告和威胁情报源。它们搜寻攻击者获取网络初始访问权限，随后在该网络上进行机动活动的迹象。

**漏洞扫描探测系统、应用程序和设备中的已知安全问题。** 漏洞扫描利用应用程序、网络和 Web 应用程序测试来检查已知问题。这些扫描可以采用有凭据或无凭据的方式进行，根据组织需求可以是侵入式或非侵入式的。审查扫描的分析师还应审查日志和配置以获取额外上下文。漏洞使用通用漏洞披露 (CVE) 标准进行一致性描述，并使用通用漏洞评分系统 (CVSS) 进行评级。

**渗透测试让安全专业人员扮演攻击者的角色。** 渗透测试可以采用测试前向测试人员提供完全信息（白盒）、完全不提供信息（黑盒）或介于两者之间（灰盒）的方式进行。测试人员在交战规则范围内进行测试，通常从侦察工作开始，包括无线网络侦察、无人机侦察、足迹采集和开源情报 (OSINT)。他们利用这些信息获取对系统的初始访问权限。随后，他们寻求实施权限提升以提高访问级别，并通过横向移动/跳板攻击扩大对其他系统的访问范围。他们力求实现持久性，以便在最初利用的漏洞被修补后仍能保持访问权限。测试结束时，他们执行清理活动以将系统恢复正常工作秩序并清除其活动痕迹。
