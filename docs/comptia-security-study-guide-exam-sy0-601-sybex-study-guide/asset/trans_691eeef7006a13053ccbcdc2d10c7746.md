

# 安全协议

## 路由协议

*   **开放最短路径优先 (OSPF)** 确实集成了一些安全特性，包括基于 MD5 的认证，尽管它默认未开启。与其他经过认证的协议一样，OSPF 并不保护实际数据，但它确实验证数据是完整的，且来自预期的路由器。

*   **增强型内部网关路由协议 (EIGRP)** 是一种思科专有协议，提供认证功能，有助于防止攻击者或其他人发送伪造的路由消息。

网络管理员需要了解他们部署的路由协议，以及如何配置它们以尽可能防止更多问题。不幸的是，由于 BGP 缺乏安全性等问题，路由安全仍然是一项挑战。

## DNS

**域名系统 (DNS)** 服务器和服务可能成为攻击者的诱人目标，因为系统依赖 DNS 来告知它们在尝试使用人类可读名称访问站点时将流量发送到何处。

DNS 本身并非安全协议——事实上，与许多最初的互联网协议一样，它以未加密、无保护的状态传输，且内置无认证能力。幸运的是，可以使用 **域名系统安全扩展 (DNSSEC)** 来帮助弥补其中一些安全漏洞。DNSSEC 提供 DNS 数据的认证，允许验证 DNS 查询，即使它们未加密。

正确配置 DNS 服务器本身是 DNS 安全的关键组成部分。防止区域传输等技术，以及确保开启 DNS 日志记录并阻止对恶意域的 DNS 请求，是常见的 DNS 安全技术。

### DNS 沉坑

用于帮助防范 DNS 问题的一种工具是 **DNS 沉坑**。DNS 沉坑是一种 DNS 服务器，配置为对特定 DNS 查询提供错误答案。这允许管理员使恶意和不需要的域名解析到无害地址，并可记录这些查询以帮助识别受感染或被攻陷的系统。

## 安全套接字层/传输层安全

在传输过程中加密数据的能力是许多协议安全的关键。虽然脑海中浮现的第一个例子可能是通过 HTTPS 实现的安全 Web 流量，但 **传输层安全 (TLS)** 广泛用于封装现代系统和网络中的各种协议。

Security+ 考试的一个关键概念是在 TLS 中使用 **临时密钥**。在临时 Diffie-Hellman 密钥交换中，每个连接都会接收一个唯一的临时密钥。这意味着即使密钥被泄露，过去发生的通信，或新会话中未来的通信也不会暴露。临时密钥用于提供 **完美前向保密**，这意味着即使用于密钥交换的秘密被泄露，通信本身也不会被泄露。

## 监控服务和系统

没有服务，系统和网络几乎无事可做。确保组织的服务在线且可访问需要监控和报告能力。虽然检查服务是否响应可能很简单，但验证服务是否按预期运行可能更复杂。

组织通常使用多层级的服务监控。第一层也是最简单的一层验证服务端口是否开放并响应。这种基本功能有助于识别重大问题，例如服务无法加载、崩溃或被防火墙规则阻止。

下一级监控要求与服务交互，并对有效响应的样子有所了解。这些事务需要额外的功能，并且可能还会使用验证性能和响应时间的指标。

最后一级监控系统寻找可能故障的指标，并使用广泛的数据来识别潜在问题。

服务监控工具内置于许多运维监控工具、SIEM 设备和其他组织管理平台中。配置服务级监控可以为安全管理员提供对持续问题的洞察，因为服务故障或问题可能是事件的指标。

## 文件完整性监视器

构成网络的基础设施和系统是攻击者的目标，他们可能会更改配置文件、安装自己的服务，或以其他方式修改需要值得信赖的系统。检测这些更改并对其进行报告或将其恢复正常是 **文件完整性监视器** 的职责。虽然市场上有许多产品可以处理文件完整性监控，但最古老且最知名的之一是 **Tripwire**，这是一款拥有商业版和开源版本的文件完整性监控工具。

像 Tripwire 这样的文件完整性监控工具为文件创建签名或指纹，然后监控文件和文件系统中受监控文件的更改。它们集成了许多功能以允许修补或用户交互等正常行为，但重点关注意外和非预期的更改。文件完整性监视器可以成为系统安全设计的关键要素，但如果未仔细设置，配置和监控它也可能具有挑战性。由于文件在网络和系统上不断变化，文件完整性监视器可能会产生大量噪音，并需要时间和精力来设置和维护。

## 欺骗与破坏

最后一类网络相关工具是那些旨在捕获攻击者及其技术信息并破坏正在进行的攻击的工具。捕获攻击者信息可以为防御者提供关于其工具和流程的有用细节，并帮助防御者基于现实经验构建更好、更安全的网络。

Security+ 考试大纲中包含三种主要类型的信息收集工具。第一种也是最常见的是 **蜜罐** 的使用。蜜罐是故意配置为看似脆弱的系统，但实际上是经过大量仪表化和监控的系统，它们会记录攻击者的所有行为，并保留其使用的每个文件和命令的副本。它们看起来是合法的，并且可能包含诱人的虚假信息。与蜜罐非常相似，**蜜网** 是为收集网络攻击信息而设置和仪表化的网络。本质上，蜜网是一组蜜罐，设置得更具说服力，并由于通过系统网络所需的各种系统和技术，能提供关于攻击者工具的更多细节。

与用于对抗研究的蜜网和蜜罐不同，**蜜文件** 用于入侵检测。蜜文件是一个故意设置的诱人目标文件，包含唯一的、可检测的数据，放置在攻击者若攻击成功可能会访问的区域。如果蜜文件中包含的数据被检测到离开网络，或稍后在网络外被发现，组织就知道系统已被攻破。

你需要了解的该类别中 Security+ 考试的最后一个概念是提供 **虚假遥测数据** 的做法。虚假遥测是欺骗工作的一部分，为攻击者提供额外目标。虚假遥测的概念非常类似于蜜文件——它为攻击者提供一个目标，要么误导他们，要么让你检测到对该信息的访问。
