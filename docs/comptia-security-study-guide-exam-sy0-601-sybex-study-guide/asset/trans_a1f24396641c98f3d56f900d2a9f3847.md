
# 端点检测与响应

当反恶意软件工具不足以应对威胁时，可以部署端点检测与响应（EDR）工具。EDR 工具将使用客户端或软件代理在端点设备和系统上的监控能力，与网络监控和日志分析能力相结合，以收集、关联和分析事件。EDR 系统的关键功能包括搜索和探索收集到的数据并将其用于调查的能力，以及检测可疑数据的能力。

随着安全分析工具的持续发展，EDR 系统倾向于使用自动化规则和检测引擎来查找异常和妥协指标（IoC），同时也允许人工调查。EDR 系统的强大之处在于，它能让处理海量安全数据的组织也能轻松使用并受益于这种检测和报告能力。

如果您正在考虑部署 EDR，您需要关注组织需求，例如：事件响应能力；处理来自各种来源的威胁的能力，范围涵盖从恶意软件到数据泄露；以及在组织更广泛的背景下过滤和审查大量端点数据的能力。

## 数据丢失防护

保护组织数据免遭窃取和无意泄露，是驱动使用 `data loss prevention`（DLP）工具的原因。DLP 工具可以以客户端或应用程序的形式部署到端点。这些工具通常也具有网络和服务器驻留组件，以确保数据在其整个生命周期和各种处理过程中都得到管理。

DLP 系统的关键要素包括：对数据进行分类的能力，以便组织了解哪些数据应受保护；数据标记或标记功能，以支持分类和管理实践；用于按照组织设定的标准管理数据的策略管理和执行功能；以及监控和报告能力，以便快速通知管理员或安全从业人员有关问题或潜在问题。

某些 DLP 系统还提供额外功能，在数据发送到受保护区域之外时对其进行加密。此外，它们可能包含旨在允许共享数据而不造成潜在泄露的功能，通过令牌化、擦除或以其他方式修改数据，以允许在不违反 DLP 环境中设定的数据策略的前提下使用数据。

绘制组织数据图谱，然后根据数据分类系统或策略应用适当的控制，对于 DLP 系统的成功至关重要。与反恶意软件和 EDR 系统非常相似，某些 DLP 系统还会跟踪用户行为，以识别可疑行为或常见错误，例如给文件分配过于宽泛的权限，或通过电子邮件或云文件服务共享敏感文档。

当然，即使部署了 DLP，也很可能存在绕过系统的方法。拍摄屏幕照片、剪切和粘贴、或打印敏感数据，都可能让恶意或粗心的用户从环境中提取数据，即使已部署有效且管理良好的数据丢失防护工具。因此，DLP 系统是分层安全基础设施的一部分，它将技术和管理解决方案（如数据丢失防护）与基于组织及其数据所面临风险的策略、意识和其他控制相结合。

## 网络防御

可以使用基于主机的防火墙来阻止不需要的流量，从而保护端点免受网络攻击。基于主机的防火墙内置于大多数现代操作系统中，且通常默认启用。当然，基于主机的防火墙无法深入洞察其过滤的流量，因为它们通常只是简单地阻止或允许特定的应用程序、服务、端口或协议。更高级的过滤需要更深入地了解被分析流量的本质，这正是基于主机的入侵防御系统或入侵检测系统发挥作用的地方。

基于主机的入侵防御系统（HIPS）会在主机上的服务或应用程序处理流量之前对其进行分析。HIPS 可以对该流量采取行动，包括过滤掉恶意流量或阻断接收到的数据中的特定元素。HIPS 会检查分散在多个数据包中或贯穿整个通信系列的流量，从而能够捕获可能分散或复杂的恶意活动。由于 HIPS 可以主动阻断流量，将合法流量误判为恶意、配置错误或其他问题可能导致合法流量被阻断，从而潜在地造成中断。如果您选择部署 HIPS 或任何其他可以主动阻断流量的工具，您需要考虑如果出现问题会发生什么。

基于主机的入侵检测系统（HIDS）执行类似的功能，但像传统的入侵检测系统（IDS）一样，它无法采取行动阻断流量。相反，HIDS 只能报告问题并发出警报。因此，HIDS 在实时安全方面用途有限，但它导致问题的可能性要低得多。

在部署和管理基于主机的防火墙、HIPS 或 HIDS 之前，请确定如何管理它们、单个配置的复杂程度如何，以及如果基于主机的保护出现问题会发生什么。这并不意味着您不应该部署它们！细粒度控制是零信任设计的重要组成部分，强化主机有助于确保安全边界后的受损系统不会给组织带来更广泛的问题。

# 强化端点和系统

确保系统安全启动只是保持其安全的第一步。强化端点和其他系统依赖于多种技术，以保护系统及其上运行的软件。

## 强化

强化系统或应用程序涉及更改系统上的设置，以提高其整体安全级别并降低其受攻击的脆弱性。系统攻击面的概念（即可能受到攻击的位置）在执行系统强化时非常重要。强化工具和脚本是对系统执行基本强化过程的常用方法，互联网安全中心（CIS），网址为 [`www.cisecurity.org/cis-benchmarks`](http://www.cisecurity.org/cis-benchmarks)，以及国家安全局，网址为 [`apps.nsa.gov/iaarchive/library/ia-guidance/security-configuration/?page=3`](http://apps.nsa.gov/iaarchive/library/ia-guidance/security-configuration/?page=3)，为操作系统、浏览器和各种其他强化目标提供强化指南。
