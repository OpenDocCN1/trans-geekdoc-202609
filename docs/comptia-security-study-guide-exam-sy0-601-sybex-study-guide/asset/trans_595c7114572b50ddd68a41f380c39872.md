

# 安全区域与数据销毁

组织经常需要特定区域的安全性高于其其他空间或区域。数据中心是大多数组织最明显的安全区域之一，金库和保险箱也是如此，它们受到保护以确保未经授权的人员无法进入。金库通常为房间大小且就地建造，而保险箱则较小且便携，或者至少是可移动的。数据中心和金库通常设计有安全且冗余的环境控制、访问控制以及额外的安全措施，以确保其持续安全。

除了内置于数据中心的安全功能外，环境控制（包括使用`热通道`和`冷通道`）也关乎其安全容纳服务器和其他设备的能力。`热通道/冷通道`设计将进气口和排气口交替放置在相邻通道，以确保气流正常，使数据中心设计人员知道在哪里提供冷气以及在哪里处理排气。

在某些情况下，会实施双人完整性控制方案等管理控制来保护保险箱或金库。在双人控制方案中，两名受信任的员工必须协同工作以提供访问权限——使用双钥匙、密码或访问控制因素的两个部分。这一策略可能让你从许多军事电影中感到熟悉，在这些电影中，核武器只有在两个人同时插入钥匙并转动后才能发射。

物理控制（如`法拉第笼`）可为系统提供额外的隔离，它能屏蔽电磁场。`法拉第笼`是由导电网格构成的外壳，可分散无线设备信号的电荷，从而阻断信号。高安全设施可能被建造为`法拉第笼`，或者内部设有`法拉第笼`，以防止手机和其他电子及无线通信发生。`法拉第笼`有时也用于允许在内部测试无线设备，而不影响其他生产网络和设备。

网络安全在安全区域中也发挥作用，包括使用屏蔽子网（也常称为非军事区[`DMZ`]）。屏蔽子网可以是网络的逻辑或物理段，用于容纳可被外部世界或其他安全性较低的群体访问的系统。屏蔽子网依赖防火墙等网络安全设备提供分段，限制进出屏蔽子网的流量，从而保持高安全区域的安全。[图 9.3](#c09.xhtml#c09-fig-0003) 展示了一个屏蔽子网的示例。

组织使用的网络和其他电信线路也容易受到攻击。这就是`受保护的电缆分发`方案发挥作用的地方。如果组织担心攻击者窃听电缆或试图通过任何方式访问电缆，他们可能会部署各种电缆保护技术。尽管这些技术在大多数环境中相对罕见，但政府设施和其他极高安全级别的设施可能会使用锁具、安全电缆管道和槽道、防篡改密封，甚至能通过压力变化、屏蔽导电性变化或其他技术检测访问尝试的管道和电缆。

当网络安全不足时，可采用`气隙`设计。`气隙`设计物理隔离网络段，从而防止网络连接。`气隙隔离`的网络要求数据必须物理传输，通常在经过仔细检查和批准后才能进入安全区域。

## 安全数据销毁

当数据达到其生命周期末期时，销毁包含该数据的介质是一项重要的物理安全措施。安全数据销毁有助于防止数据泄露，包括垃圾箱搜寻等故意攻击，以及通过重复使用介质、系统或其他数据存储设备导致的无意丢失。[表 9.2](#c09.xhtml#c09-tbl-0002) 列出了纸质记录以及硬盘、磁带、基于闪存的设备甚至完整计算机等介质最常见的销毁选项。

[**表 9.2**](#c09.xhtml#R_c09-tbl-0002) 安全数据销毁选项

| 销毁方法 | 说明 | 备注 |
| --- | --- | --- |
| **焚烧** | 通常在高温焚烧炉中进行。主要用于纸质记录，尽管某些焚烧炉可能支持电子设备。 | 通常通过第三方服务在场外进行；不留下可恢复的材料。 |
| **粉碎** | 可在现场进行；使用工业粉碎机可处理纸张或设备。 | 传统碎纸机可能允许恢复文档，即使是交叉切割粉碎的文档。对于高安全环境，可能需要焚烧或制浆。 |
| **制浆** | 将纸质文档分解为木浆，去除墨水。材料可回收。 | 彻底销毁文档以防止恢复。 |
| **粉粹** | 将设备分解为极小碎片以防止恢复。 | 输出材料的大小决定了数据恢复的可能性；粉粹通常产生极小的材料碎片。 |
| **消磁** | 从磁带和硬盘等传统磁性介质中磁性擦除数据。 | 仅对磁性介质有效；对固态硬盘、闪存介质、光学介质或纸张无效。 |

物理销毁是确保数据销毁最安全的方式，但在商业环境中，非破坏性选项通常更受青睐，以便重复使用介质或设备。当潜在暴露风险较低，或残留数据暴露风险对组织而言并非重大关切时，可使用安全驱动器或介质擦除选项。

许多组织选择实施的用于安全销毁的最后一个选项是使用第三方解决方案。合同文档和设备销毁公司将取走敏感文档和介质并在其设施内粉碎，或在现场执行相同服务。组织可选择经过详尽记录的销毁流程，包括设备照片和按设备出具的销毁认证，具体取决于其安全需求。第三方销毁服务适合许多具有典型安全需求的组织，因为它们确保适当的销毁，而无需内部投资工具和时间来安全销毁介质和系统。

## 摘要

构建弹性基础设施是确保系统和服务可用性的关键部分。冗余系统、网络及其他基础设施和能力有助于提供这种弹性。同时，地理分散、电源保护，甚至技术和供应商的多样性等技术，在保持组织在线和运行方面可发挥关键作用。

存储弹性可能涉及`RAID`，了解常见的`RAID`级别及其含义对安全分析师很有用。备份（无论是到磁带、磁盘还是第三方存储服务）有助于确保在系统或驱动器发生故障时数据不丢失。你应该了解完全备份、差异备份和增量备份的区别。快照（复制某一时间点的系统状态）和镜像（用于复制完整系统）也被用作备份和克隆系统的方式。
