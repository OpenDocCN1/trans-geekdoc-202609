

# 间谍软件

**间谍软件**是一种旨在获取个人、组织或系统信息的恶意软件。间谍软件有多种类型，每种类型针对不同类型的信息。许多间谍软件包会追踪用户的浏览习惯、已安装软件或类似信息，并将其回传至中央服务器。有些间谍软件相对无害，但也存在恶意间谍软件，它们以敏感数据为目标，允许远程访问网络摄像头，或以其他方式为其安装所在的系统提供非法或不需要的访问权限。间谍软件与身份盗窃和欺诈、广告及流量重定向、数字版权管理（DRM）监控以及**跟踪软件**相关联，后者是一种用于非法监控伴侣关系中另一半的间谍软件。

间谍软件最常使用反恶意软件工具来对抗，尽管用户意识有助于防止安装包含在软件安装程序中的间谍软件（从而充当一种特洛伊木马），或通过间谍软件可能看起来像有用工具或无害实用程序的其他途径进行安装。

## 潜在有害程序 (PUP)

虽然许多类型的恶意软件感染具有恶意性，但**潜在有害程序 (PUP)** 是用户可能不需要但不像其他类型恶意软件那样危险的程序。PUP 通常在用户不知情的情况下安装，或作为软件捆绑包或其他安装过程的一部分进行安装。PUP 包括广告软件、浏览器工具栏、Web 浏览器追踪程序等。大多数杀毒软件和反恶意软件程序都可以检测并移除潜在有害程序，组织可以限制用户权限以防止安装额外软件，或限制可安装的软件，从而防止在组织拥有的 PC 上安装 PUP 和其他不需要的应用程序。

如果你确实在系统上看到了 PUP 报告，请记住，你不应立即假定系统已被攻陷，就像你对待本章讨论的其他恶意软件那样。与最终用户讨论安全意识和最佳实践，使用适当的工具进行移除，并恢复正常操作，这可能就是你处理大多数 PUP 安装所需做的一切。

# 恶意代码

恶意软件并非你可能遇到的唯一类型的恶意代码。非恶意软件的脚本和自定义构建的代码也可能被恶意行为者利用。这些攻击可以通过网络连接在本地或远程发生，并且通常利用内置工具，如 `Windows PowerShell` 和 `Visual Basic`，或 Linux 系统上的 `Bash` 和 `Python`。甚至内置于 Microsoft Office 套件中的宏也可能被攻击者利用。

`PowerShell` 是 Windows 内置的脚本语言，因其提供的强大功能而成为恶意行为者的热门目标。`PowerShell` 允许远程和本地执行、网络访问以及许多其他功能。此外，由于它默认可在 Windows 系统上使用且通常不受严格监控，攻击者可以利用它以多种不同方式发起攻击，包括无文件恶意软件攻击，即一旦浏览器或插件被攻破，就在本地执行 `PowerShell` 脚本。

针对 `PowerShell` 攻击的防御措施包括使用受限语言模式，该模式限制 `PowerShell` 中的敏感命令；以及使用 `Windows Defender` 内置的应用程序控制工具或 `AppLocker` 来验证脚本，并限制可运行的模块和插件。开启 `PowerShell` 日志记录以及 Windows 命令行审核也是一个好主意。

许多 Windows 系统都安装了 Microsoft Office，用 `Visual Basic for Applications (VBA)` 编写的 Microsoft Office 宏是攻击者的另一个目标。尽管宏病毒不再像过去那样普遍，但嵌入 Office 文档中的宏以及其他应用程序中的类似功能仍是攻击者的潜在目标，如果在 Office 中发现新漏洞，宏病毒的流行度可能会上升。

对防御者而言幸运的是，Microsoft Office 默认禁用宏。这意味着针对基于宏的恶意软件的主要防御措施是教育用户不要在未知或不可信的文档上启用宏，并对组织通过电子邮件或其他方式接收的任何 Office 文档进行适当的扫描。

`PowerShell`、`VBA` 和宏都在 Windows 系统上很流行，但 Linux 系统也成为攻击目标。攻击者可能将 `Python`、`Perl` 和 `Bash` 等常见语言和工具作为其攻击过程的一部分。这些语言可用于创建使用绑定或反向 Shell 的持久远程访问，以及许多其他有用的漏洞利用工具。`Metasploit` 是一种流行的漏洞利用工具，包含利用上述每种语言的 Rootkit。

防止使用编程语言和 Shell 等内置或预先存在的工具可能很困难，因为它们是用户与其所在系统进行交互和使用的重要组成部分。这使得防止攻击者通过漏洞、被攻陷的账户和其他方式访问系统的安全措施成为最重要的防御层之一。

值得庆幸的是，现有工具如 `chkrootkit` 和 `rkhunter` 可用于搜索 Rootkit，帮助防御者搜索和识别 Rootkit。基于行为的安全工具也可以监控系统日志和网络流量，帮助防御者识别被攻陷的系统。

# 对抗性人工智能

**对抗性人工智能**是一个新兴领域，攻击者利用人工智能 (AI) 实现恶意目的。对抗性 AI 攻击的重点目前倾向于数据投毒，向安全和分析 AI 及 ML 算法提供服务于攻击者目的的对抗性输入，或针对隐私的攻击。

了解此处使用的两个关键术语会有所帮助。第一个是**人工智能**，其重点是通过结合机器学习、深度学习及旨在模拟人类智能的相关技术来完成“智能”任务。第二个是**机器学习**，它是 AI 的一个子集。ML 系统在演进过程中会自我修改，以更好地完成其设定的任务。

随着 AI 和 ML 在安全工具集和企业分析工具中变得越来越普遍，驱动机器学习系统的训练数据被有意或无意地污染，从而提供错误响应的危险也在持续增长。一个简单的例子是：组织部署了一个网络监控工具，研究典型网络流量以建立正常行为的基线。如果网络上的系统已经被攻陷，那么基线将包含一个假设，即被攻陷系统的行为是正常的！

每项新技术都为攻击者提供了新的攻击面，ML 也不例外。**机器学习算法的污染训练数据**将成为目标，而**机器学习算法本身的安全性**将变得越来越重要。同时，随着 ML 工具和技术使用的增加，新的攻击和防御技术也将随之开发。作为安全分析师，你现在可以采取一些基本步骤：

*   了解源数据的质量和安全性。
*   与 AI 和 ML 开发人员合作，确保他们在安全环境中工作，并且数据源、系统和工具以安全的方式进行维护。
*   确保对 AI 和 ML 算法的更改经过审查、测试和记录。
*   鼓励审查以防止算法中出现有意或无意的偏见。
*   尽可能聘请领域专家。
