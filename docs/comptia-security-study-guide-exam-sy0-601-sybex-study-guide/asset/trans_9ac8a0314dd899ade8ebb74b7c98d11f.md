
虽然 `tcpdump` 是一个非常有用的工具，但在带有图形用户界面 (GUI) 的工具中捕获和分析数据包通常更有用。Wireshark 提供了 GUI 以及广泛的过滤、协议分析和检查工具，使分析师能够以自动化或工具辅助的方式对网络流量执行更复杂的分析。[图 12.11](#c12.xhtml#c12-fig-0009) 显示了 Wireshark 捕获的同一网络端口扫描。请注意，流量经过颜色编码，数据按可排序的列对齐，并且 Wireshark 提供了各种工具，包括分析工具、统计工具，以及用于处理电话 (VoIP)、无线和其他数据包捕获的专用功能。

来自 `tcpdump` 或 Wireshark 等工具的数据包捕获可以使用 `tcpreplay` 进行重放。默认情况下，它只会以捕获时的速度将流量发送回去，但 `tcpreplay` 可用于修改速度、拆分输出，或应用过滤器或修改。这些对于测试安全设备都非常有用。作为分析师，你可能会使用 `tcpreplay` 重放已知攻击，以检查新编写的 IPS 规则是否会触发，或者防火墙是否会阻止拒绝服务攻击。

## 摘要

安全专业人员需要了解企业安全网络中使用的关键安全概念，以及如何实施安全网络设计。网络分段和网络访问控制等关键要素确保系统和设备位于适当的安全区域中，并且只有期望的系统连接到网络。端口安全等保护措施可防止已连接机器发起的攻击影响网络，而 VPN 则通过公共或不受信任网络中的隧道连接网络和系统。

许多安全工具都可作为安全设备和装置使用。通过跳板机进行安全访问，让管理员能够安全地跨越安全边界。负载均衡器、代理、NAT 网关和内容过滤器都为网络设备提供保护，而防火墙、IDS 和 IPS 设备以及 DLP 工具则提供专注的安全功能。安全和设备管理设计选项包括带外管理技术、访问控制列表、服务质量功能、路由协议安全选项、DNS 安全配置、广泛使用 TLS 和启用 TLS 的服务、监控工具，甚至包括用于捕获和分析攻击者工具及技术的工具。

使用安全协议和服务代替不安全版本，以及了解每种协议和服务的局限性和实施要求也很重要。一旦攻击者进入网络，他们将尝试访问网络流量，安全协议将有助于确保攻击者拦截的流量不易被其访问。安全电子邮件、FTP、HTTP 和 Secure Shell 等选项都是安全网络设计工具包的一部分。

即使所有这些防御措施都已到位，你仍需能够识别多种攻击：中间人攻击、第 2 层攻击、DNS 攻击和分布式拒绝服务攻击，包括运营技术攻击。这些攻击各自具有可识别的特征，范围从流量模式到交换机行为。

成功分析、评估和防御网络需要一套广泛的工具。分析师必须了解可评估路由、路径和延迟的工具的用途和基本用法。你应该能够收集有关系统网络接口、流量统计、路由以及网络上其他本地系统的信息。端口和漏洞扫描工具也可以帮助评估网络，开源情报收集工具可以在不实际扫描目标网络的情况下提供详细信息。`netcat` 和 `curl` 等实用程序有助于传输和获取数据；`hping`、`tcpdump` 和 Wireshark 允许你创建、捕获和分析数据包及网络流量。

## 考试要点

**网络安全的基础是安全设计。** 基于风险或安全要求划分不同的安全区域有助于保护网络。DMZ、内部网和外部网都是常见的网络分段选项，零信任网络将分段概念扩展到使每个系统都能自我防御。NAC 可保护网络免受不受信任设备连接的影响，而端口安全和环路防护、广播风暴防护等端口级保护可确保恶意或配置错误的系统不会导致网络问题。端口跨越和镜像通过创建其他端口流量的副本来实现数据包捕获。VPN 用于将网络流量通过隧道传输到另一位置，它们可以是加密的，也可以只是简单的隧道传输。

**网络设备用于为网络和系统提供安全服务。** 网络设备有多种类型。跳板服务器和跳板机提供了一种安全的方式来访问另一安全区域中的系统。负载均衡器将负载分散到各个系统中，并可以使用不同的调度选项以及主动/主动或主动/被动设计等运行模式。代理服务器要么将一组客户端的连接集中转发到服务器，要么将一组服务器的连接集中转发到客户端，通常作为一种负载均衡策略。内容和 URL 过滤器根据规则限制可进出网络的信息，数据丢失防护系统监控以确保不应离开系统或网络的数据被识别并标记、安全发送或阻止。NAT 网关允许多个系统使用单个公共地址，同时防止未经特殊配置的入站连接。IDS 和 IPS 设备根据恶意行为、签名或流量异常进行识别并采取行动。HSM 创建、存储和管理加密密钥和证书，也可用于卸载加密处理。传感器和收集器等数据收集设备有助于数据收集。防火墙用于构建安全区域，并放置在信任边界处。UTM 设备将这些安全功能和能力中的许多结合到单个设备或系统中。
