

# 威胁情报

**威胁情报** 是网络安全专业人员为了解威胁环境变化而可利用的活动和资源集合。建立威胁情报计划是任何组织网络安全方法的关键部分。如果您不熟悉当前的威胁，就无法建立适当的防御来保护组织免受这些威胁的侵害。威胁情报信息还可用于**预测性分析**，以识别组织面临的潜在风险。

威胁情报来源多种多样，从您可以从公开来源收集的开源情报（OSINT），到提供专有或闭源情报信息的商业服务。越来越多的产品和服务具备消费威胁源数据的能力，使您能够在整个基础设施和系统中利用这些数据。

无论其来源如何，威胁源旨在以组织可利用的方式提供最新的威胁详情。威胁源通常包含关于威胁的技术细节，例如 IP 地址、主机名和域名、电子邮件地址、URL、文件哈希值、文件路径、CVE 编号以及其他威胁详情。通常还会包含其他信息，以帮助使信息更具相关性和可理解性，包括可能使您的组织成为目标或易受威胁的详细信息、威胁行为者的描述，甚至包括他们的动机和方法论的细节。

**漏洞数据库** 也是组织威胁情报计划的重要组成部分。漏洞报告当然有助于指导组织的防御工作，但它们也为研究人员发现的漏洞利用类型提供了宝贵的见解。

威胁情报来源还可能提供**妥协指标**。这些是攻击已发生的明显迹象，可能包括文件签名、日志模式以及攻击者留下的其他证据。IoC 也可能在提供威胁情报信息的**文件和代码仓库**中找到。

## 开源情报

**开源威胁情报** 是从公开可用来源获取的威胁情报。许多组织已经认识到开放共享威胁信息的实用性，开源威胁情报已变得广泛可用。事实上，现在的挑战往往在于决定使用哪些威胁情报来源，确保它们可靠且最新，并善加利用。

许多网站维护着广泛的开源威胁信息来源列表：

*   `Senki.org` 提供了一个列表：`www.senki.org/operators-security-toolkit/open-source-threat-intelligence-feeds`
*   AT&T 运营的开放威胁交换平台是全球安全专业人员和威胁研究人员社区的一部分：`https://cybersecurity.att.com/open-threat-exchange`
*   MISP 威胁共享项目，`www.misp-project.org/feeds`，提供来自多个来源的标准化威胁源，并拥有社区驱动的收集集。
*   Threatfeeds.io 托管了一个开源威胁情报源列表，包含添加和修改时间、维护者及其他有用信息的详情：`threatfeeds.io`

除了开源和社区威胁数据来源外，还有许多政府和公共威胁情报数据来源。例如，[图 2.3](#c02.xhtml#c02-fig-0003) 显示了来自网络安全和基础设施安全局（CISA）网站的最近警报列表。

**政府网站：**

*   美国国防部网络犯罪中心网站：`www.dc3.mil`

**供应商网站：**

*   微软威胁情报博客：`www.microsoft.com/security/blog/tag/threat-intelligence`
*   思科威胁安全网站（`tools.cisco.com/security/center/home.x`）包含专家博客，提供威胁研究信息，以及思科 Talos 信誉查找工具，`talosintelligence.com`

**公共来源：**

*   SANS 互联网风暴中心：`isc.sans.org`
*   VirusShare 包含上传到 VirusTotal 的恶意软件详情：`virusshare.com`
*   Spamhaus 专注于封锁列表，包括通过 Spamhaus 封锁列表（SBL）传播的垃圾邮件、Exploits 封锁列表（XBL）上的被劫持和受感染计算机、策略封锁列表（PBL）、不路由或不对等列表（DROP）列出您可能不希望允许流量来源的网段，以及各种其他信息：`www.spamhaus.org`

这些只是安全从业者可用的开源情报资源的一小部分，但它们能让您对可用资源有个很好的了解。

## 专有和闭源情报

商业安全供应商、政府组织和其他以安全为中心的组织也会创建和使用专有或**闭源情报**。它们进行自己的信息收集和研究，并可能使用自定义工具、分析模型或其他专有方法来收集、策划和维护其威胁源。

使用专有威胁情报有多种原因。组织可能希望保持其威胁数据的机密性，可能希望出售或授权该数据，且其方法和来源属于商业机密，或者他们可能不愿冒险让威胁行为者知晓他们正在收集的数据。

商业闭源情报通常作为服务产品的一部分，这对安全专业人员来说可能是一个极具吸引力的资源。通过开源威胁情报源获得的海量数据可能会让许多组织应接不暇。梳理威胁源以识别相关威胁，然后确保它们定义明确且适合您的组织适当应用，可能需要付出巨大的努力。在许多情况下，验证威胁数据可能很困难，一旦您完成了确保拥有高质量威胁数据的工作，您仍然必须对其采取行动！

**威胁地图** 提供威胁情报的地理视图。许多安全供应商提供高层级地图，可实时洞察网络安全威胁态势。例如，FireEye 在 `www.fireeye.com/cyber-map/threat-map.html` 提供了[图 2.4](#c02.xhtml#c02-fig-0004) 所示的公共威胁地图。

组织也可能使用威胁地图信息，深入了解直接针对其网络的攻击来源。然而，威胁地图信息应始终持保留态度，因为地理归因以极其不可靠而著称。攻击者通常通过云服务和其他受感染网络中转攻击，向威胁分析工具隐藏其真实地理位置。

## 评估威胁情报

无论您的威胁情报信息来源如何，您都需要对其进行评估。当您评估威胁情报来源或特定威胁情报通知时，有许多常见因素会发挥作用。

1.  它及时吗？运行在延迟上的源可能导致您错过威胁，或在威胁不再相关后才做出反应。
