

# 您如何应对中断或问题以及如何从中恢复，可能意味着快速恢复在线与长时间离线之间的区别。

现代基础设施通常依赖非持久化系统，这些系统使用软件或镜像定义的原始版本来构建和扩展系统，并在不需要时将其关闭并销毁。最后已知的良好保存点和镜像也可用于恢复到事件或问题发生之前的时间点。

可扩展性可以是垂直的，即上线更大、更强大的系统或设备；也可以是水平的，即增加更多较小的系统。云和虚拟化环境的使用日益增加，意味着越来越多的基础设施被设计为利用水平可扩展性。水平可扩展的基础设施通常利用负载均衡器和其他工具将流量导向系统，从而允许升级、替换和移除可能存在问题的系统。

灾难恢复站点用于恢复运营，其中热站点已构建完毕并完全准备就绪，温站点等待数据和人员投入运营，冷站点提供电力和连接但需要付出巨大努力和部署技术才能上线。在任何恢复事件中，了解恢复顺序将有助于根据依赖关系和关键性，以合理的顺序将系统和服务恢复上线。

保持组织的物理安全也有助于保护它们。为了威慑潜在的恶意行为者同时保护组织，站点安全涉及使用工业伪装使设施不太可能成为目标，以及物理安全控制，如围栏、防撞柱、照明、工牌和入口访问系统、警报、灭火系统，甚至标识。即使是数据中心、机房和保险柜等区域也会接受额外的控制，以满足其更高的安全需求。

## 考试要点

### 冗余构建弹性。

冗余系统、网络甚至数据中心是确保可用性的关键要素。冗余设计需要解决组织面临的风险和优先级，以确保在成本和能力之间做出最佳权衡。地理分散；多路径网络；负载均衡器；网卡组合；电源保护和冗余；RAID；备份；以及技术、系统和平台的多样性，都是构建和确保弹性的方法。

### 当故障发生时，响应和恢复至关重要。

故障不可避免，因此您需要知道如何响应。非持久化和最后已知的良好配置允许您返回到受信任或之前的状态。可扩展性，无论是通过更多系统实现水平扩展，还是通过更强大的系统实现垂直扩展，都能提供更多资源来处理负载。水平可扩展性允许您添加和移除更多系统或服务，从而提供额外的灵活性。拥有灾难恢复站点，如热、温或冷站点，或冗余的云或托管位置，可以帮助确保您的组织能更快地恢复运营。拥有预先确定的恢复顺序可提供指导，说明基于依赖性或对组织的重要性，什么需要优先恢复上线。

### 物理安全控制是第一道防线。

保护站点安全涉及使用工业伪装等技术，以及围栏、照明、警报、标识、防撞柱、访问控制门禁通道、摄像头和其他传感器等安全控制。通过使用锁、工牌和警卫确保只有获许可的人员才能进入，有助于防止未经授权的访问者。灭火和其他环境控制可使系统和设备免受自然灾害或人为灾害造成的风险。

### 数据生命周期的终结可能需要安全销毁。

当设备或介质报废时，可能需要安全销毁以防止数据丢失。存在多种技术，包括焚烧、粉碎或制浆纸质介质，或粉碎、粉碎消磁设备和磁性介质。使用适当的解决方案将有助于防止系统或介质报废或出售时数据泄露。第三方执行这些服务，并可提供销毁收据和其他文档，以确保销毁工作妥善完成，而无需组织自行维护该能力。
