# Network Mapping with SYN (Half-Open) Scan

Probing Host sends SYN on TCP port 143. Target responds with SYN/ACK and RST. Conclusion: Target services IMAP (mail).

Probing Host sends SYN on TCP port 143. Target responds with RST. Conclusion: Target doesn't service IMAP.
