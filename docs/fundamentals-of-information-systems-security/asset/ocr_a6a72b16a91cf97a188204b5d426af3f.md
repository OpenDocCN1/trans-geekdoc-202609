# Spyware

Spyware is any unsolicited background process that installs itself on a user’s computer and collects information about the user’s browsing habits and website activities. These programs usually affect privacy and confidentiality. They typically install when users download freeware programs.

A cookie is a small text file that stores information about a browser session. The server side of a user connection to a web server can place certain information in the cookie and then transfer that cookie to the user’s browser. Later the same server can ask the browser for the cookie and retrieve the information the browser previously stored. This becomes useful in any intelligent interaction between browser and website, because the browser does not maintain a connection with the server between requests.
