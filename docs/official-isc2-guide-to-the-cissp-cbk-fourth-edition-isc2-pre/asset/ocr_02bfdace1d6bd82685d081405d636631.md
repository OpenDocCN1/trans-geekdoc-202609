Subject 1 has been assigned a clearance level of secret and the ability to write only to a set of objects. In order to prevent disclosure, the subject may write information to objects classified as secret or top secret but is prevented from writing information classified as public.

In the strong * property (Figure 3.9), they consider the same subject with the ability to read or write to objects in the model system. To be mathematically certain that the subjects could never disclose information, they must be restricted to objects at a similar classification level and not be allowed to interact with any other objects in the model system.
