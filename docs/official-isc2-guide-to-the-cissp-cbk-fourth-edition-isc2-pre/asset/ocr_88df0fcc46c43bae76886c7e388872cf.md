# The Programming Procedure

In the beginning, programmers created object (machine or binary) files directly. (Some programmers have retained this skill. It is possible to enter data directly from the keyboard of a common desktop computer, using only printable characters, and create a usable program. However, this activity is now relegated to the level of a game and has little relation to modern, commercial software development.) The operating instructions (opcodes) for the computer and any necessary arguments or data were presented to the machine in the form that was needed to get it to process properly.
