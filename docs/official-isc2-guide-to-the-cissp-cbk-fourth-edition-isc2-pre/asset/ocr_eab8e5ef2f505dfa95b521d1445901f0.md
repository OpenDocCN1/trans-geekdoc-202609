# Mobile Sites

Another option available is the mobile site, meaning the data center of an organization is housed in a mobile trailer or possibly a standard sea cargo shipping container. Should disaster strike, an organization can simply load up the cargo container data center and move it to another location that has the power, resources, and connectivity required to continue operations.
