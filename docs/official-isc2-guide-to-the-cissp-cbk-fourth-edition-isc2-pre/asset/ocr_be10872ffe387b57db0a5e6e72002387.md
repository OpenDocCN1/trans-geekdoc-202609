# # 需求规格说明书

**项目名称：** 在线考试系统

**文档版本：** v1.0

**编写日期：** 2025年3月15日

# ## 1. 引言

本文档定义了在线考试系统的功能与非功能需求，供设计、开发、测试及验收使用。

# ## 2. 总体描述

+   - 用户角色：管理员、教师、考生
+   - 核心流程：考生在线答题，系统自动评分

# ## 3. 功能需求

| 编号 | 功能描述 | 优先级 |
|------|----------|--------|
| FR-1 | 考生登录 | 高 |
| FR-2 | 自动组卷 | 中 |
| FR-3 | 成绩查询 | 高 |
