# Ring

A ring is a closed-loop topology. Data is transmitted in one direction only, based on the direction that the ring was initialed to transmit in, either clockwise or counter-clockwise. Each device receives data from its upstream neighbor only and transmits data to its downstream neighbor only. Typically, rings use coaxial cables or fiber optics. +   - Because rings use tokens, one can predict the maximum time that a node must wait before it can transmit (i.e., the network is deterministic).
