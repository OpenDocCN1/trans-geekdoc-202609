The key is also placed into a similar square table or matrix.

The Rijndael operation consists of four major operations.

+   1. **Substitute Bytes** — Use of an S-box to do a byte-by-byte substitution of the entire block.
+   2. **Shift Rows** — Transposition or permutation through offsetting each row in the table.
+   3. **Mix Columns** — A substitution of each value in a column based on a function of the values of the data in the column.
+   4. **Add Round Key** — XOR each byte with the key for that round; the key is modified for each round of operation.

# Substitute Bytes

The substitute bytes operation uses an S-box that looks up the value of each byte in the input and substitutes it with the value in the table. The S-box table contains all possible 256 8-bit word values, and a simple cross-reference is done to find the substitute value using the first half of the byte (4-bit word) in the input table on the x-axis and the second half of the byte on the y-axis. Hexadecimal values are used in both the input and S-box tables.
