6. 故障排除

在使用代码或访问仓库时遇到问题：

1. 检查“Issues”标签：

GitHub 仓库的“Issues”部分讨论了许多常见问题。您可以搜索现有 issues，看是否有人遇到并解决了类似问题。

2. 新建 Issue：

如果未找到解决方案，请在“Issues”标签页点击“New Issue”，提供清晰的问题描述、错误信息以及复现步骤。

3. 查阅文档：

`docs` 文件夹包含关于环境设置、故障排除等详细指南。在寻求进一步帮助前，请先查看文档。
