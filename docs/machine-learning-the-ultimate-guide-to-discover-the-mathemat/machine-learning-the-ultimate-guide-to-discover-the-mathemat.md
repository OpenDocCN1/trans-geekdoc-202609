# 引言

机器学习的概念源于人工智能，是一个完整的研究领域。它专注于开发自动化程序，从数据中获取知识，以做出诊断或预测。机器学习依赖于这样一个概念，即机器可以学习、识别趋势并在最少人工干预的情况下提供决策。这些机器随着经验而改进，并构建支配学习过程的原则。

机器学习有许多用途，例如营销、语音和图像识别、智能机器人、网络搜索等。机器学习需要大型数据集来训练模型并获得准确的预测。存在不同类型的机器学习，通常分为两类：监督学习或无监督学习。其他算法可以被标记为半监督学习或强化学习。

监督学习主要用于从分类或已标记的数据集中学习，而不是预测未知数据集的标签。相比之下，当训练数据集既未分类也未标记时，使用无监督学习，用于研究函数如何描述数据集中的隐藏模式。半监督学习结合使用了分类和未分类的数据集。强化是一种依赖试错过程的方法，通过识别环境中最准确的行为来提高其性能。

理解机器学习不是解决任何当前问题的万能方法至关重要。某些问题可以通过稳健的方法解决，而不需要依赖机器学习。对于数据较少且目标值可以通过确定性方法轻松定义的问题，在这种情况下，当很容易确定并编写驱动目标值的规则时，机器学习不是最佳遵循方法。

当无法制定规则来定义目标值时，机器学习的使用效果最好。例如，图像和语音识别就是机器学习最佳用例的完美范例。例如，图像具有许多特征和像素，简单的人类任务很难实现以识别图像。人类可以在视觉上识别并对图像进行分类。但是如何

另一个问题是——如果机器学习最早在 1959 年就被提到，为什么花费了这么长时间才成为主流？其主要原因是机器学习需要巨大的计算能力，更不用说能够存储海量数据的硬件了。直到最近几年，我们才实现了实践机器学习所需的。

## 机器学习与传统编程有何不同？

传统编程涉及将输入数据馈给机器，连同一个编写好的、经过测试的程序，以生成某些输出。而在机器学习中，输入数据和输出数据会在初始阶段（称为学习阶段）被输入机器。从那里开始，机器将自己完成编程工作。

## 为什么我们需要机器学习

如今，机器学习受关注的程度远超你的想象。它的主要用途之一是自动化需要人类智能的任务。机器只能通过机器学习来复制这种智能。

企业使用机器学习来自动化任务，以及自动化处理和创建数据分析模型。某些行业严重依赖海量数据，并利用这些数据来优化运营和做出正确的决策。机器学习使得创建模型来处理和分析大量的复杂数据并提供准确的结果成为可能。这些模型是可扩展且精确的，并且运行快速，允许企业在利用其巨大力量和提供的机会的同时，规避已知和未知的风险。

机器学习在现实世界中的许多用途包括文本生成、图像识别等，这些范围不断扩大，确保了机器学习专家成为极受追捧的人才。

### 机器学习是如何工作的？

机器学习模型被喂入历史数据，称为训练数据。它们从数据中学习，然后构建一个预测算法，对一组完全不同的数据（称为测试数据）进行输出预测，这些测试数据是作为输入给系统的。模型的准确性完全取决于数据的质量以及提供的数据量——优质数据越多，结果和准确性就越好。

假设我们有一个需要预测的非常复杂的问题。与其编写复杂的代码，不如将数据交给机器学习算法。这些算法会开发逻辑并提供预测。

### 机器学习从过去到现在的

如今，我们看到了许多机器学习运行的证据，例如自然语言处理和自动驾驶汽车（仅举两例）。尽管，机器学习已经存在了 70 多年，但一切都追溯到 1943 年。神经心理学家沃伦·麦卡洛（Warren McCulloch）和数学家沃尔特·皮茨（Walter Pitts）发表了一篇关于神经及其工作方式的论文。他们随后创建了一个电路模型，产生了第一个神经网络。

艾·图灵（Alan Turing）在 1950 年了图灵测试。这项测试用于判断计算机是否拥有真正的智能，通过测试需要计算机欺骗人类使其相信自己是一个人类。

亚瑟·塞缪尔（Arthur Samuel）在 1952 年编写了第一个计算机学习程序，这是一个跳棋游戏，计算机玩得越多就会变得越好。它通过研究动作，确定哪些动作属于获胜策略，然后将这些动作应用于自己的程序。

1957 年，弗兰克·罗森布特（Frank Rosenblatt）设计了感知器，这是一种模拟人类大脑思维过程的计算机神经网络。十年后，创建了一种名为“最近邻”的算法。这种算法允许计算机开始模式识别，尽管在当时非常基础。这对于销售员规划路线是非常理想的，确保他们所有的访问都能最短时间内完成。

巨大的变化是在 20 世纪 90 年代显而易见的。工作正在从几乎完全由知识驱动的方法转向更多数据驱动的方法。科学家们开始创建程序，允许计算机分析海量数据，从结果中学习并得出结论。

1997 年，由 IBM 创建的“深蓝”（Deep Blue）成为第一个在自己擅长领域击败世界冠军的计算机象棋手手。该程序搜索了可能的步法，利用其计算能力选择最佳方案。仅仅十年后，杰弗里·辛顿（Geoffrey Hinton）创造了“深度”学习一术语，用以描述允许计算机识别图像和视频中文本和物体的新算法。

2012 年，亚历克斯·克里泽夫斯基（Alex Krizhevsky）与伊利亚·苏特斯维弗（Ilya Sutskever）以及杰弗里·辛顿共同发表了一篇论文。这篇具有影响力的论文描述了一种可以显著降低识别系统中错误率的计算模型。与此同时，Google 的 X Lab 开发出可以自主浏览 YouTube 视频并选择其中含有猫视频的算法。

2016 年，Google DeepMind 的人员创建了 AlphaGo 来下中国古代游戏——围棋，并与世界冠军李世石进行对决。AlphaGo 在五场比赛中击败了现任世界冠军四。

最后，2020 年发布了 GPT-3，这可能是世界上最强大的语言模型。该模型由 OpenAI 发布，可以生成功能完备的代码、编写创意小说、撰写良好的业务备忘录等等，其应用场景仅限于想象力。

## 机器学习基本概念

机器学习提供了许多功能，最突出的是以下这些：

- 自动化 —— 大多数邮箱账户都有垃圾邮件文件夹，你所有的垃圾邮件都会出现在那里。你可能会质疑邮箱提供商是如何知道哪些邮件是垃圾邮件的，答案是机器学习。在算法被教会识别垃圾邮件后，整个过程就是自动化的。
- 能够自动化重复任务是机器学习最出特性之一。全球许多企业正在使用它来处理文书自动化。以金融领域为例，每天都需要执行大量数据密集且重复的任务，而机器学习承担了大部分工作，通过自动化提高了速度，并为重要的任务释放了员工时间。
- 更好的客户体验 —— 良好的客户关系对企业至关重要，有助于提升品牌忠诚度和提高参与度。企业实现这一点的最佳方式是提供更好的服务和客户体验。机器学习在这两个方面都发挥了作用。想想你在网上看到广告或访问购物网站时。大多数时候，这些广告与你搜索过的内容有关，购物网站会根据之前的搜索或购买推荐产品。机器学习是这些极其准确的推荐系统的背后，并确保我们能为每个用户定制体验。在服务方面，大多数企业使用聊天机器人来确保 24/7 全天候。有些机器人非常智能，客户甚至没有意识到不是在真人聊天。
- 自动化数据可视化 —— 如今，个人和企业每天产生海量数据，例如 Google、Facebook 和 Twitter。想想这些公司每天产生的数据量是巨大的。这些数据可以用于可视化关系，使企业能够做出有利于及其客户的决策。通过自动化数据可视化平台，企业可以从数据中获得有用见解，并利用它们改进客户体验和服务。
- BI（商业智能） —— 当机器学习的特性与数据分析（特别是大数据）相结合时，公司更容易找到问题的解决方案，并利用其发展业务和增加利润。几乎每个行业都在使用这种机器学习来提高运营效率。

## Pandas

Pandas 是一个用于管理和展示数据的库。“Pandas”这个名称源于术语“面板数据”（panel data），指的是 Pandas 创建类似于表格的序列的能力。

Pandas 可以将结构化数据组织为 dataframe（数据帧），这是一个二维数据结构（表格数据集），带有标记的行和列，类似于电子表格或 SQL 表。你还可以使用 Pandas 将外部数据集导入为 dataframe 而不影响源文件，因为修改是在你的开发环境中进行的。

## NumPy

NumPy 经常与 Pandas 结合使用，是“数值型 Python”的缩写。单独使用时，NumPy 用于管理多维数组和矩阵、合并和切分数据集，并提供了一系列数学函数，包括最小、最大、标准差和方差。

## Scikit-learn

Scikit-learn 是通用机器学习的核心库。它提供了一个丰富的浅层算法库，包括逻辑回归、决策树、线性回归、梯度提升等，以及广泛的评估指标（如平均绝对误差），以及数据划分方法（包括划分验证和交叉验证）。

Scikit-learn 还用于执行许多项重要的机器学习任务，包括训练模型以及使用训练好的模型预测测试数据。

## Matplotlib

Matplotlib 是一个可视化库，你只需要几行代码即可生成散点图、直方图、饼图、柱图、误差图和其他可视化图表。虽然 Matplotlib 提供了对线条样式、字体属性、颜色、轴和属性的详细控制，但默认的视觉呈现没有其他可视化库那样突出和专业，通常与 Seaborn 主题配合使用。

## Seaborn

Seaborn 是一个基于 Matplotlib 的流行 Python 可视化库。该库带有许多内置可视化主题和复杂的视觉技术，包括因变量和自变量的颜色可视化、复杂的热图、聚类图和矩阵对图（pairplots）。Seaborn 的预格式化视觉设计与 Matplotlib 的定制性相结合，生成出版级的可视化变得简单。

其他流行的可视化库还包括 Plotly（一个交互式可视化 Python 库）和 Cufflinks（直接与 Pandas 数据帧连接以创建图形和图表）。

## TensorFlow

如果不介绍 Google 的 TensorFlow，对流行机器学习库的总结将是不完整的。虽然 Scikit-learn 提供了一系列广泛的流行浅算法，但 TensorFlow 是深度学习和人工神经网络（ANN）的首选库。

TensorFlow 创建于 Google，支持各种先进的数值计算技术。通过在具有多达数个 GPU 实例的网络上分布计算，TensorFlow 支持高级算法，包括无法在单个服务器上运行的神经网络。

遗憾对于 Mac 用户来说，TensorFlow 仅兼容 Nvidia 显卡，而 Mac OS X 现在已不再提供此类显卡。Mac 用户仍然可以在 CPU 上运行 TensorFlow，但需要在云端运行工作负载以访问 GPU。

## 为什么用 Python 进行机器学习？

Python 是一种广泛使用的编程语言，原因有很多。主要原因之一是它是免费开源语言，这意味着每个人都可以使用。虽然它是免费的，但它是基于社区的，这意味着它由社区开发和支持以改进该语言。人们使用 Python 的其他原因包括：
1) 作为语法简单的可读语言，质量很高，
2) 可以可以到到任何操作系统（例如 Windows、Unix）而无需极少修改，
3) 执行速度：Python 不需要编译，运行速度比类似的语言更快，
4) 集成：这意味着 Python 可以与其他程序集成，并被 C 和 C++ 调用。

Python 的另一个优势是自动的内存管理，且不需要声明变量。此外，Python 允许开发图形用户界面（GUI）、数据库编程、互联网脚本等许多应用程序。在本节中，我们将重点关注如何进行机器学习应用以及如何开始 Python。

## 如何开始 Python

Python 是一种脚本语言，与任何其他编程语言一样，需要一个解释器。后者是一个执行其他程序的程序。正如其名称所示，它作为计算机硬件的解释器来执行 Python 语言的指令。Python 以软件软件包的形式提供，可以从 Python 网站下载：www.python.org。在安装 Python 时，解释器通常是一个可执行程序。注意，如果你使用 UNIX 和 Linux，Python 可能已经安装，并且可能在 /usr 目录下。现在你已经安装了 Python，让我们探索一下如何运行一些基础代码。

类似于瑞士或日本手表的设计，良好的机器学习模型应该运行顺畅且不包含额外的零件。这意味着避免防止代码执行的语法或其他错误，并移除可能阻塞模型决策路径的冗余变量。

这种对简单性的追求延伸到了开发第一个模型的初学者。例如，在处理新算法时，创建一个最小可行模型并向代码添加复杂性。如果你发现自己陷入了僵局，查看麻烦的元素并问：“我需要它吗？”如果模型无法处理缺失值或多种变量类型，最快的治疗方法是移除麻烦的元素。这应该帮助受影响的模型恢复活力并正常呼吸。一旦模型运行，你就可以返回并在代码中添加复杂性。

## 什么是数据清洗？

数据清洗是为分析准备数据而处理数据的总术。某些算法（例如）不识别某些数据类型，或者在响应缺失值或非数字输入时返回错误消息。变量也需要根据大小缩放或转换为更兼容的数据类型。

数据中的重复信息、冗余变量和错误也可能共同作用，破坏模型提供有价值见解的能力。

在处理数据（特别是私有数据）时，另一个潜在的考虑因素是移除个人标识符，这些标识符可能会违反相关数据隐私法规或损害客户、用户和其他利益相关者的信任。对于公开数据集来说，这不是一个大问题，但在处理私有数据时需要注意。

## 删除缺失值

另一个常见但更复杂的数据清洗任务是决定如何处理缺失数据。

缺失数据可以分为三个大类：完全随机缺失 (MCAR)、随机缺失 (MAR) 和不可忽略缺失 (nonignorable)。虽然不常见，但当缺失数据点与数据集中的其他值之间没有关系时，就会发生 MCAR。

随机意味着意味着值与其自身的值无关，但与分析中其他变量的值有关，例如因为在之前的问题中已经输入了相关信息，而跳过了某个开放式回答问题。

不可忽略意味着缺失与缺失数据本身的特定特征有关。这通常发生在高收入人群不太报告其收入的情况下。

为了处理缺失值，我们有几种策略，例如删除或插补。删除是最简单的方法，但可能导致信息丢失和偏差。插补涉及用估计值（如平均值、中位数或众数）填充空隙。

从这里我们可以看到有四个变量包含缺失值，分别是 `last_review` (3908) 和 `reviews_per_month` (3914)。虽然这对于所有算法都不是必要的，但我们有几种方案可以考虑修复缺失值。种方法是使用 `fillna` 方法用变量的平均值填充缺失值。

```python
df['reviews_per_month'].fillna(df['reviews_per_month'].mean()), inplace=True)
```

此行代码将 `reviews_per_month` 变量的缺失值替换为平均值，该平均值为 `1.135525`。我们还可以使用 `fillna` 方法用众数（最常见值）来近似缺失值。

```python
df['reviews_per_month'].fillna(df['reviews_per_month'].mode()[0]), inplace=True)
```

在我们的数据集中，该变量的众值为 ‘NAN’（非数字），我们没有可靠的众数可以使用。这在变量值以浮点数而非整数表示时很常见。

此外，平均值法不适用于字符串等非数值数据。独热编码变量和表示为 `o` 或 `1` 的布尔变量也不应使用平均值法填充。对于表示为 `o` 或 `1` 的变量，将这些值聚合为 `0.5` 或 `0.75` 是不，因为这些值会改变变量类型的含义。

要用自定义值（如 ‘o’）填充缺失值，我们可以在括号内指定目标值。

```python
df['reviews_per_month'].fillna('o')
```

更激进的措施是删除行（案例）或列（变量）。




由于分析中存在大量的缺失数据，当平均值和众数不可靠且不适用于寻找人工值的方法时，删除缺失值就变得必要了。当缺失值仅占案例的较小比例，或者该变量本身对你的分析并非核心时，这些操作是可行的。[12]

删除缺失值主要有两种方法。第一种是如前文所示，使用 `del` 方法手动删除受缺失值影响的列。第二种方法是 `dropna` 方法，它可以自动删除包含缺失值的列或行。

```python
df.dropna(axis=0, how='any', thresh=None, subset=None, inplace=True)
```

## K-Means 聚类 (K-Means Clustering)

聚类最常用的算法之一是 k-means 聚类。该算法背后的直觉非常简单。

要执行 k-means 聚类，我们必须首先确定想要簇的数量 (k)。接下来，我们随机选择这些簇的质心，并反复执行以下步骤：

- 首先，我们根据每个训练实例与其簇质心的接近程度将其分配到一个簇中。接着，我们计算分配给某个簇的所有数据点的平均值，并用它来更新质心。在更新所有簇的质心后，我们重新分配点并重复更新和分配步骤，直到所有质心都停止变化。

让我们用一个包含五个点的小数据集——(2,2), (3,2), (3,1), (1,1) 和 (0,0) 来说明。

如果我们想将这些点聚类为两个簇，我们需要随机选择两个质心。假设我们选择 (1.5, 1.5) 和 (3, 1.5) 为质心，并分别命名为 C1 和 C2。

现在，我们需要将每个数据点分配到具有最近质心的簇。为了确定一个点到质心有多远，我们通常使用欧几里得距离公式。下表显示了每个点到两个质心的距离。

## 质心初始化 (Centroid Initialization)

```python
from sklearn.cluster import KMeans
inertias = []
for k in range(2, 20):

    kmeans.fit(df).append(kmeans.inertia_)

plt.xticks(range(0, 20), 'Number of Clusters')

```

在这里，我们首先从 `sklearn.cluster` 模块导入 `KMeans` 类。接下来，我们声明了一个名为 `inertias` 的空列表。

声明列表后，我们使用 for 循环运行 18 次 k-means 算法（从 k = 2 到 k = 19）。我们为每次运行实例化一个 `KMeans` 对象，并将 `n_clusters=k` 传递给构造函数以指定簇的数量，并将 `random_state = 0` 以确保结果的可重复性。

我们还传递了 `init = 'k-means++'` 来指定质心初始化方法。此指定是可选的，因为 `k-means++` 是 sklearn 使用的默认初始化方法。然而，如果我们想使用随机初始化方法，则需要向构造函数传递 `init = 'random'`。

实例化 `KMeans` 对象后，我们使用它来训练模型，并将生成的惯性（存储在 `inertia_` 属性中）添加到 `inertias` 列表中。

在训练完所有模型后，for 循环结束。在循环外部，我们使用 `plot()` 方法将惯性绘制在 y 轴，将簇的数量绘制在 x 轴。

## 图 5：手部图

该图清楚地显示惯性随着簇数量的增加而下降。事实上，如果我们有 500 个簇，惯性将为零。这是因为我们的数据集中有 500 个数据点。如果每个点都是自己的簇，我们将不会有任何惯性。

然而，拥有 500 个簇是没用的，而且违背了聚类的初衷。因此，我们的目标不是追求惯性为零，而是努力寻找一个最佳的簇数量，使得惯性的下降从非常显著变为不再那么显著。

## 决策树

决策树的构建方式类似于支持向量机，这意味着它们是一类监督学习机器学习算法，能够解决回归和分类问题。在处理海量数据时，它们非常强大且有用。

你需要学习超越基础知识的知识，以便能够处理大型且复杂的数据集。此外，决策树还用于构建随机森林，而随机森林被认为是最强大的学习算法。

## 决策树概述

决策树本质上是一种支持受其他决策影响的决策的工具。这意味着从预测结果到后果以及资源使用，一切都将以某种方式受到影响。请注意，决策树通常以图的形式表示，可以描述为某种图表，其中训练测试作为一个节点。例如，该节点可以是抛硬币，可以有两个不同的结果。此外，分叉生长出来分别代表各个结果，它们还有叶子，叶子就是类别标签。现在知道为什么这种算法被称为决策树了。它的结构类似于一棵真实的树。正如你可能猜到的那样，随机森林正如其名。它们是决策树的集合，但关于它们的介绍到此为止。

决策树你可以使用的最强大的监督学习方法之一，特别是对于初学者来说。与其他复杂的算法不同，它们相当容易实现，并且提供了很多优势。决策树可以执行任何常见的数据科学任务，而且你在训练过程结束时获得的结果是非常准确的。考虑到这一点，让我们分析其他一些优点和缺点，以更好地理解它们的用法和实现。

## 让我们从优点开始：：

- 1. 决策树的设计非常简单，因此即使你是一个没有数据科学或机器学习正式教育的初学者，也很容易实现。这种算法背后的概念可以总结为一种遵循常见编程语句类型的公式：如果（If），那么（then），否则（else）那样。此外，你将获得的结果非常易于解释，特别是归功于图形化表示。
- 2. 第二个优势是决策树是探索、确定最重要变量以及发现它们之间联系的最有效方法之一。此外，你还可以轻松构建新特征以获得更好的测量和预测。不要忘记，数据探索是处理数据时最重要的阶段之一，特别是当涉及许多变量时。你需要检测出最有价值的变量以避免耗费时间的过程，而决策树在这方面表现出色。
- 3. 实现决策树的另一个好处是它们非常擅长清除数据中的离群值。不要忘记离群值是降低预测准确性的噪声。此外，决策树受噪声的影响很大。在很多情况下，离群值对这种算法的影响非常小，以至于如果你不需要最大化准确率评分，甚至可以选择忽略它们。

最后，决策树可以同时处理数值变量和类别变量。记住，我们已经讨论过的某些算法只能用于其中一种数据类型。另一方面，决策树被证明是多用途的，可以处理许多多样的任务。

正如你所看到的，决策树强大、多功能且易于实现，那么我们为什么要费心考虑其他的呢？像往一样，没有什么是完美的，所以让我们讨论一下使用这类算法的负面影响：

- 1. 实现决策树过程中遇到的最大问题之一是过拟合。请注意，由于复杂性，该算法有时会创建具有泛化数据的非常复杂的决策树。这被称为过拟合，在实现其他学习算法时也会遇到，但程度不同。幸运的是，这并不意味着你应该远离使用决策树。你只需要花一些时间来实现某些参数限制来减少过拟合。
- 2. 决策树在连续变量上可能会出现问题。当涉及连续数值变量时，决策树会丢失一定的信息。这个问题当变量被分类时出现。如果你不熟悉这些变量，连续变量可以是某个数字范围内的一个值。例如，假设 18 到 26 岁之间的人被认为是学生年龄。在这种情况下，这个数值范围变成了一个连续变量，因为它可以包含声明最小值和最大值之间的任何值。
- 3. 虽然某些缺点会增加决策树的额外工作，但其优点远大于这些。

## 分类与回归树

我们之前讨论过决策树既用于回归任务也用于分类任务。然而，这并不意味着你在两种情况下都实现相同的决策树。决策树需要分为分类树和回归树。它们处理不同的问题；但由于它们都是决策树，所以它们是相似的。

请注意，当存在类别因变量时实现分类决策树。相反，回归树仅在连续因变量的情况下实现。此外，在分类树的情况下，训练数据的结果是所有相关观测值的众数。这意味着任何无法定义的观测值将根据该值进行预测，该值代表我们最频繁识别观测值。另一方面，回归树的工作方式略不同。训练阶段产生的值不是众数值，而是所有观测值的平均值。这样，未识别的观测值就被声明为已知观测值产生的平均值。

两种类型的决策树都经过二分分裂，但是从上到下。这意味着一个区域的观测值将在预测空间内产生两个分支。这也被称为贪婪算法，因为学习算法寻求分裂中变异最大的。正如你所看到的，两者之间也有一些差异。然而，你从这一切中应该注意到分裂会影响决策树的准确率评分。无论什么类型的树，决策树节点都被划分为子节点。这种树划分是为了产生更多的节点。现在你理解了决策树的基本原理，让我们深入探讨一下过拟合。

## 过拟合问题

你之前学过，过拟合是处理决策树时的主要问题之一，它有时会对结果产生严重影响。如果我们不实施限制，决策树可能会导致训练集达到 100% 的准确率。然而，这里主要的缺点是过拟合会在算法消除训练误差时出现，增加了测试误差。这种不平衡尽管评分很高，但导致了糟糕的预测。在这种情况下，决策树生长了许多分支，这就是过拟合的原因。为了解决这种用法，你限制限制树的发展程度和产生的分支数量。此外，你还可以修剪树以控制它，就像你对真实的树这样做使其产生许多果实一样。

为了限制决策树的大小，你需要在定义树时确定新参数。让我们分析这些参数：

- Min_Samples_Split: 你可以的第一件事是更改此参数，以指定节点分裂需要多少观测值。你可以声明从一个样本到最大样本的任何值。
- Min_Samples_Leaf: 这是你需要调整的参数，用于确定节点（或者说叶子）需要多少观测值。过拟合控制机制与样本分裂参数相同。
- Max_Features: 调整此参数以控制随机选择的特征。这些特征是

通常用于执行最佳拆分。为了确定最有效的值，你应该计算总特征数的平方根。只需记住，值越高越容易导致我们正试图解决的过拟合问题。因此，你应该对你设置的值进行实验。此外，并不是所有情况都是相同的。有时候，较高的值会有效，而不会导致过拟合。

- 4. **Max_Depth（最大深度）：** 最后，我们有深度参数，它由决策树的深度值组成。然而，为了限制拟拟问题，我们只对最大深度感兴趣。请注意，高值意味着更多的分裂，因此意味着大量的信息。通过调整此值，你将控制训练模型学习样本之间连接的方式。

修改这些参数只是控制决策树以减少过拟合、提高性能和准确性的方面方面。在应用这些限制之后，下一步是对树进行剪枝。

## 机器学习 VS 深度学习

现在，我们需要看看机器学习和深度学习是如何协同工作的。我们可以在人工智能中使用、且最常用的技术之一（特别是在处理所有大数据时）是机器学习。记住之前的观点，机器学习是一种自自适应算法，随着它获得更多经验或添加一些新数据，它会教自己如何在分析和寻找模式方面变得更好。

深度学习作为机器学习的一个子集，将发挥作用，因为它能够利用分层的人工神经网络。这些人工神经网络的设置类似于人类大脑，神经元之间相互连接，形成一个类似网的结构。许多程序员倾向于使用线性方式来构建分析，但这种深度学习函数能够让机器以非线性方法处理数据。

在过去，检测洗钱或欺诈等问题的传统方法之一是客户依赖交易的金额。这意味着只有真正巨大的交易会被捕获，并且只有这些交易会发出巨大的警报。

当然，这些并不是所有坏的交易。有时，试图进行欺诈的人可能会在短时间内进行大量小额交易，而不是大额交易。当这种情况发生时，此人可以在短时间内完成许多不同的交易并逃脱，但不会被发现，因为单笔交易的金额足够小，系统不会捕捉。这导致金融机构多年来在欺诈费用上损失了大量资金。

机器学习的奇之处在于，通过深度学习的非线性方法，我们在尝试检测欺诈时可以查看不仅仅是金额。例如，算法可以被设置为查看如零售商类型、IP 地址、地理位置和时间，以判断这是否是客户可能参与的购买或交易。

当神经网络尝试处理原始数据输入（如交易金额）时，我们看到的第一层，然后将其传递给下一层，这些信息作为输出。神经网络的第二层将能够处理从上层获取的信息，并包含一些额外信息（如用户的 IP 地址），并将结果传递下去。这种情况一直持续到所有的层。




神经网络的计算已经完成。

接下来的这一层将获取第二层的信息，并包含一些你拥有的原始数据（如地理位置），从而使机器的模式更加完善。这一过程将持续到该神经网络包含的所有层级。神经网络的层数取决于你正尝试完成的过程。

## 提示 #1 记住逻辑

当你处理机器学习时，请记住成功并不仅仅是选择正确的算法或工具。这需要更多努力。你需要为特定问题找到良好的匹配和设计。

这意味着，在你开始使用想要使用的项目之前，你需要花一些时间来弄清楚对于你想要做的事情，哪种物流方案最有意义。我们讨论了许多不同的算法，可以根据你想要关注的项目类型或程序来选择。每种算法都向我们展示了某些与众不同的东西。学习这些工具是如何工作的并为任务选择正确的工具，对于获得你想要的结果至关重要。

## 提示 #2 注意数据

我们需要关注的另一个选项是你输入到算法中的数据。要确保你交付的所有算法都能提供价值的见解，最大的考虑因素之一就是你必须给它提供正确类型的数据。如果你发现你正在通过算法运行数据，但结果没有按照你想象的那样出现，那么很可能是你使用的数据不对，而不是算法的问题。

有很多程序员或业务所有者会非常自负，固执于某一个特定的算法。但由于市上有许多不同的工具，存在出现过多的算法的可能。虽然选择正确的算法对整个过程确实很重要，但这里更重要的事情是确保你选择了正确类型的数据来帮助你。

如果你正在研究一个更困难或更复杂的问题，比如语音识别甚至计算机视觉之类的领域，那是一回事了。这个领域（无论我们在迷失其中时如何想）其实是我们处于一个数据驱动的领域。在我们可能会遇到的大多数场景中，调整输入的数据而不是算法，将会产生差异。

每当算法没有给你提供符合逻辑的结果，或者没有提供你在尝试时本应该应该得到的结果时，就是时候做出一些改变了。也许是你输入了太多的数据，或者类型错误的数据，甚至是数据不足。稍微调整并看看这对你得到的预测产生什么影响，可能正是你寻找的改变。

## 提示 #3 算法并不总是正确的

在本文指南中，我们花了大量时间观察你可以关注的各种算法。这些都是极好的工具，可以帮助你获得想要的正确结果，但它们并不总是正确的。如果我们把它们看作是能够解决我们所有问题的“灵丹妙药”，那么这可能是一件坏事。

机器学习的实现在持续的试错过程中会发挥最大的作用。无论你认为你使用的算法有多好，如果系统与另一个人或多人进行任何形式的交互，那么它就必须随着时间的推移进行某些调整。企业需要不断衡量其实施的有效性，并找出任何变量和变化会让情况变好还是变差。

这听起来工作量很大，而且当你刚进入机器学习领域时，可能看起来有些困惑。但这是你需要关注的。很少有企业在这样做。相反，他们假设自己的算法是完美的，永远不需要。这会让情况变得糟糕，随着时间的推移，算法将落后非常远，至于无法给你提供准确的结果。

想要用算法部署你的系统，并希望它完美地工作，而永远无需做任何工作来保持这种状态，这是很正常的。虽然那是理想世界，但它并不是我们任何一个可以依靠的现实。没有任何算法或用户界面设计能够长期存在。也没有任何数据收集方法不会被取代。

这意味着，无论你决定使用哪种算法，它都需要随着时间的推移进行一些调优和调整。如果你跟上这一点并且不让它被搁置，那么你需要完成的调整可能很小，不需要大量工作。最大的问题将出现在你开始忽略这一步时，然后问题会开始相互累积。记住，没有任何算法（无论它看起来有多完美）是完美的，你确实需要偶尔检查它。

## 提示 #4 选择多样化的工具集

正如你从本指南以及你可能对机器学习所做的其他研究中可以想象到的，这个领域有许多不同的工具可供你使用，其中许多工具是免费提供的！这是一件很棒，因为它允许你访问无数可以帮助你起步的各种资源。

但考虑到这一点，不要让自己被粘在某一种工具上。你可能有一个你喜欢的工具，并想一直使用它。但现实中，当你处理机器学习时，你需要拿出好几种工具才能取得成功。如果周围有人试图说服你只有一种工具是有效的，而其他都不行。虽然选择正确的算法对整个过程确实很重要，但这里更重要的事情是确保你选择了正确类型的数据来帮助你。

如果你正在学习一个更困难或更复杂的问题，比如语音识别甚至计算机视觉，那是一回事了。这个领域（无论我们在迷失其中时如何想）其实是我们处于一个数据驱动的领域。在我们可能会遇到的大多数场景中，调整输入的数据而不是算法，将会产生差异。

每当算法没有给你提供符合逻辑的结果，或者没有提供你在尝试时本应该应该得到的结果时，就是时候做出一些改变了。也许是你输入了太多的数据，或者类型错误的数据，甚至是数据不足。稍微调整并看看这对你得到的预测产生什么影响，可能正是你寻找的改变。

## 提示 #5 尝试混合学习

你可以尝试的另一件事是混合学习的想法。你可以将深度学习与廉成本学习结合起来产生混合体。一个例子是，你可以获取一个已经存在的视觉模型，然后重构顶层，即包含你想要做的决策的层。从那里开始，你可以采用现有的框架并将其用于案例。

这对于你来说是创造事物的一种极佳方法，无需从头开始创建。你可以使用已经存在的技术和框架，然后添加其中存在的某些规范和更多内容以获得你想要的结果。

这可能需要一些工作。但请思考你想要开展的项目。将其拆分成较小的部分，并确定是否有任何现有的平台或框架可以让你启动。一旦你有了这些，你就可以检查并进行所需的更改，也许可以使用我们上面讨论过的某些算法来实现这一目标。

这在许多方面都是好处。首先，这些框架在某些情况下是免费的，或者至少不会花费你太多钱。这意味着你可以使用它们，并与从头开始你想要的东西相比，节省资金。在业务中，能够省钱总是一件好事。你仍然可以在过程中使用所需的深度学习，但在不需要独特的特性部分获得了省钱的好处。

这里的另一个好处是你可以自己节省一些时间。许多你将使用的框架需要大量时间创建。如果你每次开始时都想出一个全新的，完成项目将需要永远的时间。当你可以使用或购买你喜欢的那个时，你最终可以节省大量时间，并加快你想要完成的项目进度。

## 结论

机器学习是一个令人兴奋且快速发展的领域。虽然精通该领域可能涉及多年的学习，但通过对机器学习方法和目标获得一些基础熟悉，就可以快速上手。

尽管该领域周围环绕着神秘的色彩，但许多机器学习方法都是相对简单的数学工具，这些工具已经存在了几个世纪。直到现在，它们才被应用到公司和其他大型组织收集的海量数据（所谓的大数据）中。

前进的道路实际上是进行更多的实践和学习。从完成你能找到的任何涵盖机器学习中所有主要算法的练习开始。同时使用监督和无监督机器学习是非常重要的，因为任何想要理解机器学习的人都需要对两者都非常熟悉。你还应该通过使用线性回归和 k-近邻等许多标准算法来练习。

我们建议的一点是避免陷入仅使用生成的测试数据的陷阱。为了增强你的学习和发展，请获取一些真实的数据集并在上面运行你的算法，以便对数据科学的实践获得更深的熟悉。

许多初接触机器学习概念的人会询问进入该领域所需的特定教育背景。虽然有一些通用的指南，但事实是并没有特定的规则。我们可以开始说，在很大情况下，任何从事科学或技术研究领域的人都有机会参与机器学习。这对于电气工程师或计算机工程师无疑适用。

然而，一些可能更适合进入机器学习的人是精通统计和概率的数学家。一些交叉知识可能会有所帮助，但在某些方面，当涉及到数据科学家的日常实践时，机器学习是一个统计学领域。无疑，高水平的统计学和概率知识是有帮助的。

由于它被认为是一门交叉学科，计算机科学背景会有帮助。理想的候选人应该具有深厚的计算机科学背景，并在统计学方面也展现出高水平的教育。你的教育程度越高，进入该领域的深度就越深，包括进行 AI 研究和设计更先进的系统。如果你只是在玩一些模型，你将不会为某些新的机器人系统设计机器学习系统。那需要计算机科学的高级教育。

从这里开始去哪里？第一步是继续学习。你应该通过构建更多模型和使用不同的工具来构建模型来继续练习。然而，机器学习不仅仅是玩玩工具。你应该尽可能多阅读期刊并观看来自权威来源的视频，这样你就可以学习机器学习概念背后的理论和基础。

对于那些刚刚接触该领域并希望以此选择职业路径的人来说，获得计算机科学或相关学科的大学学位可能是你最好的前进道路，特别是如果你希望获得就业的话。数据科学和机器学习不太可能是让太多人在没有相关领域大学学位的情况下就能就业的领域。如果可能，请找一所能让你专注于人工智能和机器学习的学校。

我还建议参加许多侧重于统计和概率的数学课程。通常建议具备“商业敏锐度”，所以上一些管理课程也无益无处。尽管许多技术人员对商学院并不那么热情，但仍然建议这样做。你去那里不是为了成为 MBA。尽管如此，你应该对大型公司的业务运营有一定的了解，并学习许多业务概念，如商业智能、预测性分析和数据挖掘，因为这些对公司来说是有用的概念。他们倾向于招募理解这些内容的人加入他们的团队，以便快速上手工作。

我希望这本书激发了你对机器学习的兴趣，并且它将帮助你在这一兴奋的领域继续你的教育和发展。
