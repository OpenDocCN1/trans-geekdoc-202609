# Exercise 1 Solution

To rewrite the "Changing Nodes and Attributes" example to use childNodes, you only need to alter a few lines of code. Here's the relevant section of the code:

```
// Change the unit price of beetroot
if ( $child = $beetroot->firstChild ) {
do {
    if ($child->tagName == "unitPrice") {
    $child->firstChild->replaceData(0, 10, "0.79");
    break;
    }
} while ($child = $child->nextSibling);
```

And here's the same code rewritten to use childNodes:

```
// Change the unit price of beetroot
$children = $beetroot->childNodes;
for ($i=0; $i < $children->length; $i++) {
    if ($children[$i]->item($i) == "unitPrice") {
    $children[$i]->item($i)->replaceData(0, 10, "0.79");
    }
}
```

As you can see, the revised code is more compact. It retrieves the element's children using theNodes property and stores them in $children. It loops through each child as the child node, the node's tag name is unitPrice, which replaces its contents in the same way as the original.

How does the loop work? Well, by that DOMNodeList has a length property containing the number of nodes, and an item() method that returns the node at a specified index in the list. The code uses these two pieces of information to construct a for loop to iterate through each.
