
## Part II: Learning the Language

The first time the function is called, the variable is set to its initial value (zero in this example). However, if the variable's value is changed within the function, the new value is remembered the next time the function is called. The value is remembered only as long as the script runs, so the next time you script the variable is reinitialized.

So when you use static variables? Here's a situation where a local variable isn't much use:

```
function nextNumber() {
  $counter = 0;
  return ++$counter;
}

echo "I've counted to: " . nextNumber() . "<br/>";
echo "I've counted to: " . nextNumber() . "<br/>";
echo "I've counted to: " . nextNumber() . "<br/>";
```

This code outputs the following:

```
I've counted to: 1
I've counted to: 1
I've counted to: 1
```

Each time the nextNumber() function is called, its $counter local variable is re-created and initialized to zero. Then it is incremented to 1 and is returned to the calling code. how many times it's called. However, by making a small change to turn $counter into a static variable, the script produces the expected output:

```
function nextNumber() {
  static $counter = 0;
  return ++$counter;
}
```

```
echo "I've counted to: " . nextNumber() . "<br/>";
echo "I've counted to: " . nextNumber() . "<br/>";
echo "I've counted to: " . nextNumber() . "<br/>";
```

Now the code displays:

```
I've counted to: 1
I've counted to: 2
I've counted to: 3
```

You probably won't use static variables often, and you can achieve the same effect (albeit greater) using global variables. However, when you really need to create a static variable you'll probably thankful they exist. They're often used with recursive functions (which you learn later in this chapter) to remember values throughout the recursion.

## Creating Anonymous Functions

PHP lets you create anonymous functions — that is, functions that have no name. You might want to create anonymous functions for two reasons:

- To create functions dynamically — You can customize the code within an anonymous function at the time you create it. Although you'll really need to do this, it can make your code flexible in certain situations
- To create short-term, disposable functions — Commonly, when you do this with built-in functions that require you to create a callback or event handler to work. Examples include array_walk(), which you meet in Chapter 7, and functions such as usort(), which lets you apply a function to each value in an array and sorts an array's elements according to a comparison function that you create

To create anonymous function, you use create_function(). It expects two arguments: a separated list of parameters (if any), and the code for the function body (minus the curly braces, semicolon at the end of each code). It returns a unique, randomly generated string that you can use to return the function:

```
$MyFunction = create_function('$param1, $param2', 'return $param2');
```

Here's a typical example that creates an anonymous function based on a value of the variable:

```php
$mode = "+";
$processNumbers = create_function('$a, $b', 'return $a $b');
echo $processNumbers(2, 3); // Displays 5
```

This code uses the $mode variable as the operator to process its two arguments, $a and $b. For example, if you change $mode to "+", the code displays "6" (instead of 2). In this case is rather pointless, but if you can imagine a more complex function, whose contents are determined by external factors as user input, then that's a potentially powerful feature of PHP.
