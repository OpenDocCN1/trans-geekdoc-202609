# Part II: Learning the Language

+   - $numLines: Contains the number of lines of text, by counting the number of newline characters in the text with the substr_count() function

+   - $start: Points to the index position within $myText the start of the current line being processed

Now that the script has initialized these variables, the text can be processed. To do this, the script sets up a for loop that moves through each line of the text:

```
for ($i=0; $i < $numLines; $i++) {
```

Within the loop, the script computes the length of the original, unadjusted line. It does this by subtracting the newline character after the start of the current line, then subtracting strpos() to find the index position of the newline character from the start of the line:

```
$originalLineLength = strpos($myText, "\n", $startLine) - $startLine;
```

Now that the script knows the length of the line, it starts to copy the line to a new variable, $justifiedLine, that will hold the justified version of the line. Another variable, $justifiedLength, is set up to track the length of the justified:

```
$justifiedLine = substr($myText, $startLine, $originalLineLength);
$justifiedLength = $originalLineLength;
```

The next block of code makes up the meat of the adjustment. The script uses a while loop to run the adjustment until the desired line is reached. Note that the while loop also skips the last line of text, which you don't want to be justified:

```
while ($i < $numLines && $justifiedLength < $lineLength) {
```

Within the loop, a for loop works through $justifiedLine, by character. If the current character is a space, and the line is still less than the desired length, the script uses substr_replace() to insert an extra space at that point. It then increments $justifiedLength to keep track of the current, and also increments the loop, $j, to skip over the extra space that's been created:

```
for ($j=0; $j < $justifiedLength; $j++) {
  if ($justifiedLength < $lineLength && $justifiedLine[$j] == "") {
    $justifiedLine = substr_replace($justifiedLine, " ", $j, 0);
    $justifiedLength++;
  }
}
```

The result of these two loops is that the script moves through the line from left to right, adding extra space between words, until the desired line length is reached. If the desired length isn't reached by the end of the line's, the algorithm starts again from left to right, adding additional spaces. This way the words are spaced as evenly as possible to produce a smooth justification.
