# Returning Values From Your Functions

Earlier in the chapter, you saw that functions can return values as well as accept them. For example, the
-in sqrt() function shown earlier accepts an argument (a number) and returns a value (the square
root of number).

> Note that both accepting arguments and returning values are optional. A function can do either, or
neither of these things.

To get your function return a value, you — guessed it — PHP’s return statement:

```
function myFunc() {
    // (do stuff here)
    return value;
}
```

value can be any expression, you can use a literal (such as 1 or false), a variable name (such
as $result), or a more complex expression (for example, $x * 3 / 7).
