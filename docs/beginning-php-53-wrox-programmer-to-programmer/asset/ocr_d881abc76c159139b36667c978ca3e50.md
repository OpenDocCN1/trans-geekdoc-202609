How It Works
After including the standard XHTML header, the script creates three event handler functions. The startElementHandler() displays the element name, and if the element has any attributes, it displays their names and values, one after the other. The endElementHandler() function notices the end of an element and displays its name, and the characterDataHandler() displays any data that doesn't consist of whitespace, using PHP's htmlspecialchars() function to ensure that only valid HTML is produced:

```
function startElementHandler($ parser, $element, $attributes )
    echo \"Start of element: \$element\"\n    if ($attributes) echo \" attributes: \"\ echo \"$name=\$value\"\n    foreach ($attributes as $name => \$value)
        echo \"n";


function endElementHandler($ parser, $element)
{
    echo \"End of element: \$element\"
";
}

function characterDataHandler($ parser, $data)
{
    if (trim($data)) echo \" Character data: \" htmlspecialchars($data) \"n";
}
```

The next function in the script is parseError(). It's called in the script if there was an error parsing the XML file, and it uses the XML Parser functions xml_get_error_code(), xml_error_string(), xml_get_current_line_number(), and xml_get_current_column_number() to display the error message and the location of the error:

```
function parseError($ parser)
{
    $error = xml_error_string(xml_get_error_code($parser));
    $errorLine = xml_get_current_line_number($parser);
    $errorColumn = xml_get_current_column_number($parser);
    return "<error>Error at line $errorLine column $errorColumn</error>";
}
```

Now that the functions are out of the way it's time to create the parser with xml_parser_create(). The script also uses PHP's xml_parser_set_option() function to set the XML_OPTION_CASE_FOLDING parser option to false. By default, XML Parser converts all data to uppercase, but this isn't useful because XML is case-sensitive, so the script turns this off:

```
$parser = xml_parser_create();
xml_parser_set_option($parser, XML_OPTION_CASE_FOLDING, false);
```
