# Drawing Circles and Ellipses

To draw circles and ellipses in PHP, use the imageellipse() function. It works differently from the imagagerectangle() and imageline() functions, in that you do not provide the outer limits of the shape. Rather, you describe an ellipse by providing its center point, and then specifying how high and wide the ellipse should be.

Here's an example:

```
imageellipse($myImage, 90, 60, 160, 50, $myBlack );
```

This ellipse, shown in Figure 17-8, has its center on the pixel at (90,60). The width of the ellipse is 160 pixels and the height is 50 pixels.

To draw a circle, simply describe an ellipse that has the same width and height (Figure 17-9):

```
imageellipse($myImage, 90, 60, 70, 70, $myBlack );
```
