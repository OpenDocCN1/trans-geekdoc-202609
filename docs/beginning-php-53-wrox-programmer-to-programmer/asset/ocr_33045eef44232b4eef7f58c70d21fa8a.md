# Exercise 2 Solution

The Circle has five aspects to test: its ability to store its color, its filled status, its not-filled status, radius, and its ability to calculate its area correctly. The following script puts the class through its paces:

```
<?php

require_once("inheritance.php");
require_once("PHPUnit/Framework.php");
require_once("PHPUnit/TextUI/TestRunner.php");

class CircleTest extends PHPUnit_Framework_TestCase
{
    public function testColor() {
        $circle = new Circle();
        $circle->setColor("red");
        $this->assertEquals("red", $circle->getColor());
    }

    public function testFill() {
        $circle = new Circle();
        $circle->fill();
        $this->assertTrue($circle->isFilled());
    }

    public function testHollow() {
        $circle = new Circle();
    }
}
```
