# Chapter 5: Strings

+   - str() tells you whether the search text is within the string

+   - strpos() and strrpos() return the index of the first and last occurrence of the search text respectively

+   - substr_count() tells you how many times the search text occurs within the string

+   - strspk() searches a string for any of a list of characters

# Searching Strings with strstr()

If you just want to find out some texts within a string, use strstr(). This takes two parameters: the string to search through, and the search text. If the text is found, strstr() returns the portion of the string from the start of the found text to the end of the string. If the text isn't found, it returns false. For example:

```
$myString = "Hello, world!";
echo strstr($myString, "wor") ? "br />"; // Displays 'world!'
echo (strstr($myString, "xyz") ? "Yes" : "br />\ // Displays 'No'
```

As of PHP 5.3, you can also pass an optional boolean argument. The default value is false. If you pass a value of true, strstr() instead returns the portion from the start of the character before the found text:

```
$myString = "Hello, world!";
echo strstr($myString, "wor", true ); // Displays 'Hello, world'
```

# Locating Text with strstr() and strpos()

To find out a string of text within another string, use strpos(). This function takes the same two parameters as strstr(): the string to search, and the search text to look for. If the text is found, strpos() returns the index of the first character of the text. If it's not found, strpos() returns false:

```
$myString = "Hello, world!";
echo strpos($myString, "wor") // Displays '7'
echo strpos($myString, "xyz") // Displays (false)
```

```
$myString = "Hello, world!";
if ( strpos($myString, "Hel") )) echo "Not found";
```

If you need to test for a false return value, if that's what you're checking for. The following code works:

```
$myString = "Hello, world!";
if ( strpos($myString, "Hel") === false ) echo "Not found";
```
