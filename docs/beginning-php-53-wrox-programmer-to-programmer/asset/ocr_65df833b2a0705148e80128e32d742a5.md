# Part III: Using PHP Practice

The first line opens the data.txt for writing, which erases any existing data in the file. (If the file doesn't exist, PHP attempts to create it.) The second line writes the string "ABCxyz" to the beginning of the file. As with fread(), the file pointer moves to the position after the written string; if you repeat the second line, fwrite($handle) appends the same characters again, so that the file contains characters "ABCxyzABCxyz".

You can limit the number of characters written by specifying an integer as the third argument. The function stops writing how many characters (or when it reaches the end of the string, whichever occurs first). For example, the following code writes the first four characters of "abcdefghi" (that is, "abcd") to the file:

```
fwrite($handle, "abcdefghi", 4 );
```

# A Simple Hit Counter

One very popular for Web scripts is a hit counter, which shows how many times a Web page has been visited and therefore how the Web site is. Hit counters can be in different forms, the simplest of which is a text counter. Here's a simple script for a counter:

```
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml/html-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>Hit counter</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>A simple hit counter</h1>

<?php
$counterFile = \./count.dat";

if (! file_exists($counterFile)) {
  if (! ($handle = fopen($counterFile, "w\ )) {
    die("Cannot create the counter file.");
  } else {
    fwrite($handle, 0 );
    fclose($handle);
  }
}

if (! ($handle = fopen($counterFile, "r\ )) {
  die("Cannot read the counter file.");
}

$counter = (int) fread($handle, 20 );
fclose($handle);

$counter++;
```
