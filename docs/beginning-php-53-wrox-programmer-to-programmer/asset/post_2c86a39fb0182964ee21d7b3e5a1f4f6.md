
# Part III: Using PHP in Form

By default, HTML_QuickForm can work with 23 different element types. All elements derive from the HTML_QuickForm_element class. Following is a list of the most common element types, along with code showing how to add elements to your form.

You can find a complete list of HTML_QuickForm element types at http://pear.php.net/manual/en/package.html.html-quickform.intro-elements.php.

| Element Type | Code to Add the Element to the Form |
| --- | --- |
| button | $form->addElement("button", "field name", "field value", $attrs); |
| checkbox | $form->addElement("checkbox", "field name", "field label", "text to display after checkbox", $attrs); |
| file | $form->addElement("file", "field name", "field label", $attrs); |
| hidden | $form->addElement("hidden", "field name", "field value", $attrs); |
| image | $form->addElement("image", "field name", "image URL", $attrs); |
| password | $form->addElement("password", "field name", "field label", $attrs); |
| radio | $form->addElement("radio", "field name", "field label", "text to display after button", "field value", $attrs); |
| reset | $form->addElement("reset", "field name", "field value", $attrs); |
| select | $form->addElement("select", "field name", "field label", array("optionValue"=>"optionLabel", ...), $attrs); |
| submit | $form->addElement("submit", "field name", "field value", $attrs); |
| text | $form->addElement("text", "field name", "field label", $attrs); |
| textarea | $form->addElement("textarea", "field name", "field label", $attrs); |

The $attrs variable is a list of attributes to add to the tag. It can be in the form of an associative array, or a simple string (like 'name' = 'value').

You can see that some elements are created with a value (such as buttons, where the value is the button label), whereas others are created with a field label (displayed to the left of the field by default). You can always set your own value or label by calling the element setValue() method after you've created the object - for example:

```
$textarea = $form->addElement("textarea", "field name", "field label", $attrs);
$textarea->setValue("Default text");
```

After displaying the page header, the script includes the HTML/QuickForm.php class file, then creates a new `HTML_QuickForm` object with a blank name attribute, a method="post" attribute, empty action and target attributes, no additional attributes, and the $trackSubmit property to true so that the script can detect when the form has been submitted.

```php
require_once("HTML/QuickForm.php");
$form = new HTML_QuickForm("*", "post", "*", null, true);
```

Next, the script adds a username text field to the form, with a label of "Username":

```php
$form->addElement("text", "username", "Username");
```

A password input field is also added, with a label of "Password". By storing the returned element in a variable, $password, the script can then set the field's value to an empty string:

```php
$password = $form->addElement("password", "password", "Password");
$password->setValue("");
```

It is a good idea to prevent the password being sent back to the browser — and therefore being viewable in the page source — if the form is redisplayed.

Finally, two buttons are created: a submit button and a reset button. So that these two buttons appear side by side, they are placed into an element group, separated by a non-breaking space:

```php
$buttons = array();
```

# Using Validation Rules

HTML_QuickForm comes with a number of built-in validation rule types, or you can create your own. Here's a list of the built-in rule types that you can use with the addRule() method (described in "Working with HTML_QuickForm" earlier in the chapter):

| Rule Type | Value of $format Argument | Description |
| --- | --- | --- |
| required | N/A | The value must not be empty. |
| maxLength | $max (integer) | The value's string length must not exceed $max characters. |
| minlength | $min (integer) | The value's string length must not exceed $min characters. |
| rangelength | $min, $max (integers) | The value's string length must be between $min and $max. |
| regex | $regex (string) | The value must match the regular expression. |
| email | $domainCheck (Boolean) | The value must be a valid email address. |
| callback | $functionName | Runs a callback function $functionName to check the value. |
| uploaded | N/A | The uploaded file must have been uploaded. |
| maxfilesize | $max | The uploaded file must not exceed $max bytes. |
| mimetype | $type | The uploaded file must be MIME type. |
| filename | $regex | The uploaded file's name must match the regular expression. |
| numeric | N/A | The value must be numeric. |
| nopunctuation | N/A | The value must not contain punctuation. |
| nonzero | N/A | The value must not be zero. |
| compare | $comparisonType | Compares two fields. |

Allowed values for $comparisonType:
| --- | --- |
| eq | == | Values are equal. |
| neq | != | Values are not equal. |
| gt | > | First value is greater than second. |
| gte | >= | First value is greater than or equal to second. |
| lt | < | First value is less than second. |
| lte | <= | First value is less than or equal to second. |

# Try Out A Registration Form using HTML_QuickForm

To show how powerful and useful HTML_QuickForm is, in this example you rewrite the register.php book club script from Chapter 14, using HTML_QuickForm to handle the form display and validation.

Before you start, install an PEAR package called HTML_QuickForm_Renderer_Tableless. By default, HTML_QuickForm outputs each form using an table to hold the form fields and labels. HTML forms created without using tables are more flexible and can be easier to render. With what's more, the tables-based forms produced by HTML_Quick aren't valid XHTML. HTML_QuickForm_Renderer_Tableless is a renderer class that replaces the default HTML_QuickForm_Renderer and generates XHTML-compliant, tables-free markup.

At the time of writing, HTML_QuickForm_Renderer_Tableless is a beta package, which means it can't be installed using a default PEAR setup:

```
$ install --alldeps HTML_QuickForm_Renderer_Tableless
Failed to download pear/HTML_QuickForm_Renderer_Tableless within preferred state "stable"
```

By the time you read that the package is no longer in beta, in which case you can install it in the normal way — that is, using pear install --alldeps HTML_QuickForm_Renderer_Tableless. If the package is still in beta, you can install it by specifying the channel explicitly, as follows:

```
$ install --alldeps channel://pear.php.net/HTML_QuickForm_Renderer_Tableless-0.6.1
downloading HTML_QuickFormRenderer_Tableless-0.6.1.tgz ...
Starting to download HTML_QuickFormRenderer_Tableless-0.6.1.tgz (6,828
```
