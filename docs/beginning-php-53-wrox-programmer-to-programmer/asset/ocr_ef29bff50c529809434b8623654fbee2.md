Usage: `pear [options] command [command-options] <parameters>`
Type "pear help options" to list all options.
Type "pear help shortcuts" to list all command shortcuts.
Type "pear help <command>" to get the help for the specified command. $

These are all the commands you can give the PEAR package manager. For example, install new packages to your system, and uninstall packages.

# Testing PEAR using Mac OS and MAMP

If you're using MAMP on Mac OS X, the process is similar, but you should make sure you're running the version of the PEAR package manager that works with MAMP, rather than the default Mac OS X one. First open a Terminal window (Applications ⇨ Terminal) and change to your MAMP installation's PHP binaries folder.

```
cd /Applications/MAMP/bin/php5/bin/
```
