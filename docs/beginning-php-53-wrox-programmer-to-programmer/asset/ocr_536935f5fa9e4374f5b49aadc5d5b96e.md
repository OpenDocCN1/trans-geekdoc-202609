# Try Out A Registration Form with Multi-Value Fields

Here are the registration form and handler you created earlier, but this form includes a multi-select list box for the "favorite widget" selection and two checkboxes to allow the user to sign up for two different newsletters. The form handler deals with these multi-value fields, displaying their values within the Web page.

Save the following form as registration_multi.html in your document root folder:

```
<DOCTYPE html PUBLIC "-//W3C//DTD HTML 1.0 Strict//EN"

"http://www.w3.org/TR/DTD/html1-strict.dtd">

<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>Membership Form</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>Membership Form</h1>
```
