## Exercise 1 Solution

Writing a regular expression to extract the domain name from a Web URL is fairly straightforward, because URLs follow a consistent syntax. You have many ways to create such an expression. Here’s one approach:

```
|(http(s)?://)?(www\.)?([a-zA-Z0-9\-\.]+)|
```

This expression reads as:

- 1. If present in the URL, match "http" or "https" followed by a colon and two slashes.
- 2. Match "www." if present.
- 3. Match the following characters until a character isn't a letter, digit, hyphen, or dot is found.

This expression contains a number of subpatterns, you'd extract the domain name portion as:

```php
$url = "http://www.example.com/hello/there.html";
preg_match("/(http(s)?:\/\/)?www\.)?([a-zA-Z0-9\-\.]+)/", $url, $matches);
echo "Domain name: " . $matches[4] . " Displays Domain name: example.com";
```

## Exercise 1 Solution

To rewrite the "Changing Nodes and Attributes" example to use childNodes, you only need to alter a few lines of code. Here's the relevant section of the code:

```php
// Change the price of root
if ($child = $root->firstChild) {
    do {
        if ($child->tagName == "price") {
            $child->firstChild->replaceData(0, "0.79");
            break;
        }
    } while ($child = $child->nextSibling);
}
```

And here's the same code rewritten to use childNodes:

```php
// Change the price of root
$children = $root->childNodes;
for ($i=0; $i < $children->length; $i++) {
    if ($children[$i]->item($i) == "price") {
        $children[$i]->item($i)->replaceData(0, "0.79");
    }
}
```

As you can see, the revised code is more compact. It retrieves the element's children using nodes property and stores them in $children. It loops through each child as the child node, the node's tag name is price, which replaces its contents in the same way as the original.

How does the loop work? Well, that DOMNodeList has a length property containing the number of nodes, and an item() method that returns the node at a specified index in the list. The code uses these two pieces of information to construct a for loop to iterate through each.
