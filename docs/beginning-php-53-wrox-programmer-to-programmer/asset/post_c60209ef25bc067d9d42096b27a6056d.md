In a real-world situation, make sure you don't transmit sensitive information such as usernames or passwords as plain text strings if there's a chance the data might be intercepted or read by untrusted parties.

If you need to preserve all your object's properties, you can use the built-in get_object_vars() function to get an associative array of all the properties in the object, then use the array_keys() function to get just the properties as an name, which you can then return from `__sleep()` method:

```php
class User {
    public $username;
    public $password;
    public $loginToday;

    public function __sleep() {
        // (close database handles, etc)
        return array_keys(get_object_vars($this));
    }
}
```

class User {

$user = new User;

## Determining an Object's Class

Earlier in the chapter you learned that you can use hints in method and function arguments to ensure that the correct class of object is being passed. Sometimes, you might want to explicitly check the class of a particular object you're working with. For example, you might want to check that all the objects in an array are of a certain class, or treat objects differently on their class.

To find the class of an object, you can use PHP's built-in get_class() function, as follows:

```php
class MyClass {
}

$obj = new MyClass();
echo get_class($obj); // Displays "MyClass"
```

## Part II: Learning the Language

get_class() is useful if you want to find out exactly class an object belongs to. However, often it's more useful to know if an object is descended from a given class. Consider the following example:

```php
class Fruit {
}
```

```php
class SoftFruit extends Fruit {
}
```

```php
class HardFruit extends Fruit {
}
```

```php
function someFruit( array $fruitToEat) {
  foreach($fruitToEat as $itemOfFruit) {
    if ( get_class($itemOfFruit) == "SoftFruit" || get_class ($itemOfFruit) == "HardFruit") {
      echo "Eating the fruit - yummy!<br />";
    }
  }
}
```

```php
$banana = new SoftFruit();
$apple = new HardFruit();
$someFruit( array($banana, $apple ) );
```

In this situation, the someFruit() function is to eat any fruit, soft or hard, so it really cares about that the objects it is passed descend from the Fruit class. However, get_class() only returns the specific class of an object, so someFruit() has to resort to a rather unwieldy expression to determine the object it's dealing with is a fruit.

Fortunately, PHP provides a useful instanceof operator, which you can use as follows:

```php
if( $object instanceof ClassName ) { ... }
```

If Object's class is ClassName, or if $object's class is descended from ClassName, then instanceof returns true. Otherwise, it returns false.

So you now rewriting the someFruit() function in a more elegant fashion:

```php
function someFruit( array $fruitToEat) {
  foreach($fruitToEat as $itemOfFruit) {
    if ( $itemOfFruit instanceof Fruit ) {
      echo "Eating the fruit - yummy!<br />";
    }
  }
}
```
