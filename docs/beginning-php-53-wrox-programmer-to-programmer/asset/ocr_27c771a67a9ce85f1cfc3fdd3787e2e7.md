# Updating Records

As you saw in Chapter 12, you can alter the data within an existing table row by using SQL UPDATE statement:

```
mysql UPDATE fruit name = 'grapefruit', color = 'yellow' WHERE id = 2;

Query OK, 1 row affected (0.29 sec)
Rows matched: 1 Changed: 1 Warnings: 0

mysql SELECT * from fruit;
------+------+------n| id | name     | color |
+------+------++
| 1 | banana | yellow |
| 2 | grapefruit | yellow |
| 3 | plum   | purple |
+------+------+
3 rows in set (0.00 sec)
```

As inserting new records, updating records via your PHP script is a simple case of using PDO::query() if you are passing values in the UPDATE statement, or PDO::prepare() with placeholders if you are passing variable. For example, the following script changes the email address field in the "Derek Winter" record that was added in the following section:

```
<?php
$dsn = "mysql:dbname=database";
$username = "root";
$password = "myapp";

try {
    $conn = new PDO($dsn, $username, $password);
    $conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    echo "Connection failed: " . $e->getMessage();
}

$id = 8;
$newEmailAddress = "derek.winter@example.com";

$sql = "UPDATE members SET emailAddress = :emailAddress WHERE id = :id";

try {
    $stmt = $conn->prepare($sql);
    $stmt->bindValue(":id", $id, PDO::PARAM_INT);
    $stmt->bindValue(":emailAddress", $newEmailAddress, PDO::PARAM_STR);
    $stmt->execute();
} catch (PDOException $e) {
    echo "Query failed: " . $e->getMessage();
}

?>
```
