# Chapter 4: Decisions and Loops

The first line of the script creates a variable, $widgets, and sets its value to 23. Then if an statement
uses the == operator to check if the value stored in $widgets does equal 23. If it does — and it
should!— the expression evaluates to true and the script displays the message: "We exactly 23
widget in stock! If $widgets doesn't hold the value 23, the code between the parentheses— that is,
the echo () statement is skipped. (You can test this for yourself by changing the value in the first line
of code and re-running the example.)

Here's another example that uses >= (greater than equal) and <= (less than or equal) comparison
operators, as we use the && (logical) operator:

```
$widgets = 23;

if ($widgets >= 10 && $widgets <= 20 ) {
  echo "We have between 10 and 20 widgets in stock."
}
```

This example is similar to the previous one, but the test expression the parentheses is slightly
more complex. If the value in $widgets is greater than or to 10, and it's also less than
to 20, the expression evaluates to true and the message "We have between 10 and 20 widgets in
stock." is displayed. If either of the comparison operations evaluates to false, the overall expression
eates to false, the echo () statement is skipped, and nothing is displayed.

The key point to remember is, that no how complex your test expression is, if the
expression evaluates to true the code inside the braces is run; otherwise the code inside the braces is
skipped and continues with the first line of code after the closing brace. In fact, here's the previous

You can have many lines of code between the braces as you like, and the code can do anything,
as display something in the browser, call a function, or even exit the script. In fact, here's the previous
example rewritten to use an if statement inside another if statement:

```
$widgets = 23;
if ($widgets >= 10 ) {
  if ($widgets <= 20 ) {
    echo "We have between 10 and 20 widgets in stock."
  }
}
```

The code block between the braces of the first if statement is itself another if statement. The first if
statement runs its code block if $widgets >= 10, whereas the inner statement runs its code block—
t echo () statement—if $widgets <= 20. Because both expressions need to evaluate to true for
t echo () to run, the result is the same as the previous example.

If you have only one line of code between the braces you can, in fact, omit the braces altergol:

```
$widgets = 23;
if ($widgets == 23 ) {
  echo "We have exactly 23 widgets in stock!";
```

However, if you do this, take care to add braces if you add additional lines of code to the code
block. Otherwise, your code will not run as expected!
