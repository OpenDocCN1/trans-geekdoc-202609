# ## Adding and Removing Array Elements

You already know that you can add elements to an array using square bracket syntax. For example:

```
$myArray[] = "new value";
$myArray["newKey"] = "new value";
```

This syntax is fine for simple scenarios. However, if you need something more powerful, PHP has five useful functions that you can use to add and remove:

+   - array_unshift() — Adds one or more elements to the start of an array
- array_shift() — Removes one or more elements from the start of an array
- array_push() — Adds one or more elements to the end of an array
