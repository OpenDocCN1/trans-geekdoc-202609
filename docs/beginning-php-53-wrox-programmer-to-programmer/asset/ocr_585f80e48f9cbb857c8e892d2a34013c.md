# Dealing with Multi-Value Fields

You learned earlier that you can create form fields that send multiple values, rather than a single value. For example the following form fields are capable of sending multiple values to the server:

```
<label for="favoriteWidgets">What are your favorite widgets?</label>
<select name="favoriteWidgets" id="favoriteWidgets" size="3"
multiple="multiple">
<option value="superWidget">The SuperWidget</option>
<option value="megaWidget">The MegaWidget</option>
<option value="wonderWidget">The WonderWidget</option>
</select>
```

```
<label for="newsletterWidgetTimes">Do you want to receive our
<input type="checkbox" name="newsletter" id="newsletterWidgetTimes"
value="widgetTimes" />
<label for="newsletterFunWithWidgets">Do you want to receive our
Fun with Widgets'</label>
<input type="checkbox" name="newsletter" id="newsletterFunWithWidgets"
value="funWithWidgets" />
```

The first form field is a list box, allowing the user to pick one or more (or no) options. The second form fields are checkboxes with the same name (newsletter) but different values (widgetTimes and funWithWidgets). If the user checks both then the values, widgetTimes and funWithWidgets, are sent to the server field name.

So how can you handle multiple-value fields in your PHP scripts? The trick is to add square brackets [] after the field name in your HTML form. Then, when the PHP engine sees a submitted form field with square brackets, it creates a nested array of values within the $_GET or $_POST superglobal array, rather than a single value. You can pull the individual values out of that nested array. You might create a multi-select control as follows:

```
<select name="favoriteWidgets[]" id="favoriteWidgets" size="3"
multiple="multiple" ... </select>
```

You'd then retrieve the following field values as follows:

```
$favoriteWidgetValuesArray = $_GET["favoriteWidgets"]; // If using get method
$favoriteWidgetValuesArray = $_POST["favoriteWidgets"]; // If using post method
```
