# # Building a Text Editor

With the basics of PHP's file directory handling capabilities under your belt, it's time to create a simple Web-based text editor application. The editor will display a list of text files in a designated folder, inviting the user to edit a file by clicking its name. The edit page will simply display the file's contents in an HTML text area field, with buttons for saving or canceling edits.

The user will also be able to create new text files to work with. For the sake of simplicity the editor will only handle text files with the .txt filename extension.
