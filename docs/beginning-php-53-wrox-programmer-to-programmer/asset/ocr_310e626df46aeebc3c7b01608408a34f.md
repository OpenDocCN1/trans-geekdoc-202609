Next comes checkDateBirth(), the callback function to check that the entered date is valid. You might expect this uses PHP's checkdate() function to do the checking. Because the element be checked contains multiple field values, HTML_Form provides an associative array of the values, by key name. checkDateBirth() extracts these three values and passes them to checkdate() for checking, passing checkdate()'s return value (true or false) back to the calling code:

```
function checkDateBirth($value) {
    return checkdate($value["M"], $value["d"], $value["Y"]);
}
```

The last function, calculateDays(), is called when it is processed. It creates two timestamps: $currentDate, which stores the current date and time; and $dateOfBirth, which stores the entered date. Both timestamps are created using mktime(). The month, day, and year components of the date are extracted from the associative array stored in the form's dateOfBirth field:

```
$currentDate = mktime();
$dateOfBirth = mktime(0, 0, 0, $values["dateOfBirth"]["M"],
$values["dateOfBirth"]["d"], $values["dateOfBirth"]["Y"]);
```

Now that dates are stored in timestamps, it is easy to work out the number of seconds between the two, and the number of days:

```
$secondsOld = $currentDate - $dateOfBirth;
$daysOld = (int) ($secondsOld / 60 / 60 / 24);
```
