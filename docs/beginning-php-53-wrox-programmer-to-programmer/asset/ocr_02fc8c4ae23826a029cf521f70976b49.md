# How It Works

After displaying an XHTML page header, the script sets up a $myText variable that holds the text whose words are to be sorted. (Feel free to replace the text with your own.) It then displays the text within a fixed-width HTML div element.

Next, the script gets to work processing the text. First it uses PHP's preg_replace() function to strip out commas and periods from the text.

```
$myText = preg_replace("/\\,\/+", "", $myText);
```

(This line of code uses a simple regular expression to do your job; you learn more about preg_replace() and regular expressions in Chapter 18.
Next line of code calls the PHP function preg_split() to split the string into an array of words, using any of the whitespace characters PHP's \n, \r and space to determine the word boundaries. It processes the array through PHP's handy array_unique() function, which removes any duplicate words from the array:

```
$words = array_unique(preg_split("/\\n|\\r|+\+", $myText));
```

> preg_split() splits a string by using a regular expression to locate the points at which to split. Find out more about preg_split() in Chapter 18.

Next comes the sorting logic, this is where anonymous functions come into play. The script uses PHP's sort() function to sort the array of words. sort() expects an array to sort, followed by a callback comparison function. All functions need to accept two values — $a and $b — and return one of three:

+   - A negative number if $a is considered to be "less than" $b
- Zero if $a is considered to be "equal to" $b
- A positive number if $a is considered to be "greater than" $b

In this case, the comparison function needs to determine if the length of the string $a is less, to, or greater than the length of the string $b. It can do simply by subtracting the length of $a from the length of $b and returning the result. (Remember from Chapter 5 that PHP's strlen() function returns the length of a string.)

Here, is the complete line of code to sort the array:

```
sort($words, create_function('$a, $b', 'return strlen($a) - strlen($b);'));
```

Notice that this line of code uses the create_function() function to create an anonymous comparison function, which is in used by sort() to sort the array.
