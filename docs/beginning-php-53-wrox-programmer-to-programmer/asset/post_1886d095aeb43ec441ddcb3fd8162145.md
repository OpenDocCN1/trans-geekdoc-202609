
## Chapter 20: Writing High-Quality Code

If you worked through the Try It Examples in previous chapters, you're probably already familiar with include(), require(), include_once(), and require_once(). Essentially, they allow you to include the code contained in a library inside a script file, just as if it had been copied and pasted into the script file.

Here's a simple example. Say you created a simple function animalSpeak() that returns the sound made by a cat, a dog, or a mouse:

```php
function animalSpeak($animal ) {
$sounds = array ( "cat" => "meow", "dog" => "woof", "mouse" => "squeak" );

  if ( array_key_exists($animal, $sounds ) ) {
    return $sounds[$animal];
  } else
    return false;
}
```

```php
echo animalSpeak("mouse") . "<br />"; // Displays "squeak"
echo animalSpeak("cat") . "<br />"; // Displays meow
```

Here, the function and the code that uses it are both contained within the same script. This is all well, but what if you wanted to call animalSpeak() from within a different script or application? You'd have to copy and paste the code that defines the animalSpeak() function from one script to the other—clearly not the best approach, you'd end up with duplicate versions of animalSpeak() lying about.

This is where the include() function comes in. By storing the animalSpeak() function definition in a separate file, you can include to include the function from within as many other script files as you like. For example, you might store it in a file called animal_functions.php:

```php
<?php
function animalSpeak($animal ) {
$sounds = array ( "cat" => "meow", "dog" => "woof", "mouse" => "squeak" );

  if ( array_key_exists($animal, $sounds ) ) {
    return $sounds[$animal];
  } else
    return false;
}
?>
```

Note that you need to place the <?php ?> around any PHP code in the included file. If you don't do this, the included file will be treated as HTML markup, and sent straight to the browser.

## Part III: Using PHP Practice

You might then use the function from within a mouse.php script file in the same folder, as follows:

```php
<?php
include("animal_functions.php");
echo animalSpeak("mouse") . "<br />"; // Displays squeak;
?>
```

You can then use the same function inside a cat.php script file:

```php
<?php
include("animal_functions.php");
echo animalSpeak("cat") . "<br />"; // Displays "meow";
?>
```

A close cousin of include() is require(), which does more or less the same thing:

```php
<?php
require("animal_functions.php");
echo animalSpeak("cat") . "<br />"; // Displays "meow";
?>
```

The difference is that include() merely raises a PHP warning if the file to be included is not found, whereas require() fails a fatal and stops the script. Use require() if you're including library that are essential to the running of your application.

## Including a File Only Once

A file that uses include() or require() to include a file can be included in another file — a process known as nested includes. For example the mouse.php and cat.php files, which themselves include the animal_functions.php file, might be included within a higher-level display_animal_sounds.php script, as follows:

```php
<?php
require("mouse.php");
require("cat.php");
?>
```

running this script generates the following fatal error:

```
Cannot redeclare animalspeak(previously declared in animal_functions.php:3) in animal_functions.php on line 11
```

What's causing this error? First, display_animal_sounds.php includes mouse.php. This file in turn includes animal_functions.php, which causes the animalspeak function to be defined. Next, display_animal_sounds.php includes cat.php. This file also includes animal_functions.php. Because a function is quite a common scenario when you start building large applications with nested includes. To get around this, use PHP's include_once() and require_once() functions. These work just like their include() and require() counterparts, except that they include the specified file once during the current script execution. If you call include_once() or require_once() again to include the same file, nothing happens.

So the previous problem can be solved by making a couple of small adjustments to the mouse.php and cat.php files:

mouse.php:

```php
<?php
include_once("animal_functions.php");
echo animalSpeak("mouse") . "<br/>"; // Displays "squeak";
?>
```

cat.php:

```php
<?php
include_once("animal_functions.php");
echo animalSpeak("cat") . "<br/>"; // Displays "meow";
?>
```

Now, animal_functions.php will be included only once (in mouse.php), therefore the animalSpeak() function will be defined only once. The display_animal_sounds.php script will now run correctly, displaying the following output:

squeak
meow

## Working with Include Paths

Another issue when working with large applications is tracking the locations of files. Say you organized all your common code, including animal_functions.php, into a centrally located /home/joe/lib directory. This is a string containing a list of paths to include. Each path is separated by a colon (on Linux servers) or a semicolon (on Windows servers). The PATH_SEPARATOR constant contains the separator in the current system. The paths are searched in the order they appear. You can display the current include_path value — which is usually pulled from the php.ini configuration file — calling the get_include_path function():

```php
echo get_include_path(); // Displays e.g. :/usr/local/php
```

In this example, the include_path contains two paths: the current directory (.) and /usr/local/php. To set a new include_path value, you guessed it — set_include_path():

```php
set_include_path:/home/joe/lib");
```

> It's a good idea to include your path with the current directory (.), as just shown. This means that PHP always searches the current directory for the file in question first (which is usually what you want).

You'd usually set your include path once, at the start of your application. Once you set the include path, you can include any file's in the path by specifying its name:

```php
include_once("animal_functions.");
```

In this example, the PHP engine looks in the current directory for animal_functions.php. Because it's not there, it looks in /home/joe/lib, and finds it there.

You can organize your code library by creating subfolders within your include path. Say you put your animal_functions.php file into a subfolder called animals. The absolute path to the file would then be:

```
/home/joe/lib/animals/animal_functions.php
```

To include this file in your script, you'd write, for example:

```php
require("animals/animal_functions.php");
```

Notice that your script is now more portable. To move your application to a new server with different paths, all you need to do is specify a new path in your set_include_path() call.
