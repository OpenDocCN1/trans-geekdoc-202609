# Appendix B: Configuring PHP

```
; from PHP at some point in the near future. The acceptable method for passing a
; value by reference to a function is by declaring the reference in the functions
; definition, not at call time. This directive will not disable this feature, it
; only determines whether PHP will warn you about it or not. These warnings
; should be enabled in development environments only.
; Default Value: Off (Suppress warnings)
; Development Value: Off (Issue warnings)
; http://php.net/allow-call-time-pass-reference
allow_time_pass_reference = off
```

```
; Safe Mode
; http://php.net/safe-mode
safe_mode = Off
```

```
; By default, Safe Mode does a UID check compare when
; opening files. If you want to relax this to a GIT compare,
; then turn on safe_mode_gid.
; http://php.net/safe-mode-gid
safe_mode_gid = Off
```

```
; When safe-mode is on, UID/GID checks are bypassed when
; including files from this directory and subdirectories
; (directory may also be in include_path or full path must
; be used when using)
; http://php.net/safe-mode-include-dir
safe_mode_include_dir = _
```

```
; When safe-mode is on, only executables in the safe-mode_exec_dir
; will be executed via the exec function of functions.
; http://php.net/safe-mode-exec-dir
safe_mode_exec_dir = _
```

```
; Setting environment variables may be a potential security breach.
; In Safe Mode,
; this directive contains a comma-delimited list of prefixes.
; the user may only allow environment variables whose begin with the
; prefixes supplied by. Default, users will only be able to set
; environment variables that begin with PHP (e.g., PHP_FOO=BAR).
; Note: If this directive is empty, PHP the user may modify ANY
; environment variables!
; http://php.net/safe-mode-allowed-env-vars
safe_allowed_env_vars = PHP
```

```
; This directive contains a comma-delimited list of environment variables that
; the end user won't be able to change putenv(). These variables will be
; protected if safe_mode_allowed_env_vars is set to allow to change them.
; http://php.net/safe-mode-protected-env-vars
safe_mode_protected_env_vars = LD_LIBRARY_PATH
```
