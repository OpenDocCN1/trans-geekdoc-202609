# Modifying an HTTP Response

Because the PHP engine interacts with the Web server, your PHP scripts can influence the HTTP response headers sent by the server. This can be very useful.

To get the Web server to send a custom HTTP header as part of the response, you use PHP's header function. This simply takes the header line output, then injects it into the response headers:

```
header("Server: Never you mind");
```

By default, header() replaces any HTTP header field with the same name. In the example shown, if the response already contains a Server header, that is replaced with the one passed in. However, some header fields can be included more than once in the response. If you want to include the same header several times, pass it in false as the second argument to header():

```
header("Set-Cookie: name=Fred; expires=Mon, 05-Jan-2009 10:22:21 GMT;
path=/;domain=example.com")
header("Set-Cookie: age=33; expires=Mon, 05-Jan-2009 10:22:21 GMT;path=;domain=example.com", false);
```

Generally speaking, when you pass a header line to header(), PHP fully injects the header line-into the response. However, there are two special cases:

+   - If the header starts with HTTP/, PHP assumes you want to set the status line, rather than add or replace the header line. This allows you to set your HTTP status lines:

```
// To see here, move along
header("HTTP/1.1 404 Not Found");
```

+   - If you pass in a Location string, PHP automatically sends a 302 Found status line as well as the Location header:

```
// Redirect to the login page
header("Location: http://www.example.com/login.php");
```

+   - This makes it easy to page redirects (as you saw in Chapter 9). If you would render a different status line, simply specify the status line as well:

```
header("HTTP/1.1 301 Moved Permanently");
header("Location: http://www.example.com/newpage.php");
```
