
## Chapter 6: Arrays

## How It Works

After displaying the standard XHTML page header, the script starts by defining the $myBooks-dimensional array. Each element of the associative array contains information about a specific book.

Next, the script sets a counter variable, $bookNum, to zero and sets up the foreach loop. This loop moves through each elements of the top-level myBooks array. For each element, it increments $bookNum and displays the current book number, then starts a new list (dl) XHTML element.

The inner foreach loops through the elements of the associative array stored in the counter. For each element, it displays the element's key ("title", "author", or "pubYear") within an XHTML dt element. After the inner loop runs, the dd element is closed.

Once the outer loop has completed, the script ends the XHTML page.

## Manipulating Arrays

You've learned the essentials of PHP arrays: what arrays are, how to create them, how to access their elements, how to loop through them, and how to work with multidimensional arrays.

PHP's array support doesn't stop there, as you saw with strings in Chapter 5, PHP comes with a huge number of array-processing functions that you can use to make arrays even more useful.

## Sorting Arrays

One powerful feature of arrays in most languages is that you can sort the elements in any order you like. For example, if you've just read 100 books from a file into an array, you can sort the titles alphabetically before you display them. Or you might create a multidimensional array containing information, then sort the array by number of purchases to see your most loyal customers are.

When comes to sorting arrays, PHP provides no less than twelve functions that you can use to sort an array. The common ones are:

- sort() — For sorting indexed arrays
- asort() and arsort() — For sorting associative arrays
- ksort() and rsort() — For sorting associative arrays by key rather than by value
- array_multisort() — A powerful function that can sort arrays at once, or for multidimensional arrays

## Sorting Indexed Arrays with sort() and rsort()

The simplest are sort() and rsort(). sort() sorts the values of the array in ascending order (alphabetically for letters, numerically for numbers, before numbers) and rsort() sorts the values in descending order. To use either function, simply pass the array to be sorted. The function then sorts the array. As all the sorting functions covered in this chapter, the function returns true if it managed to sort the array or false if there was a problem.

Here's an example that sorts a list of authors alphabetically in ascending order, and then in descending order:

```php
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens");

// Displays Array [0] => Dickens [1] => Kafka [2] => Steinbeck [3] => Tolkien;
sort($authors);
print_r($authors);

// Displays Array [0] => Tolkien [1] => Steinbeck [2] => Kafka [3] => Dickens; 
rsort($authors);
print_r($authors);
```

## Sorting Associative Arrays with asort() and asort()

Take another look at the previous sort() and rsort() code examples. Notice how the values in the sorted arrays have different keys from the values in the original array. For example, "Steinbeck" has an index of 0 in the original array, 2 in the second array, and 1 in the third array. The sort() and rsort() functions are said to reindex the original array.

For indexed arrays, this is usually what you want to happen: need the elements to appear in the correct order, and at the same time you expect the indices in an indexed array to start at zero. For associative arrays, this can cause a problem. Consider the following scenario:

```php
$myBook = array("title" => "Bleak House",
"author" => "Dickens",
"year" => 1853);

sort($myBook);

// Displays Array [0] => Bleak House [1] => Dickens [2] => 1853;
print_r($myBook);
```

Notice how sort() has reindexed the associative array, replacing the original string keys with numeric keys and effectively turning the array into an indexed array. This renders the sorted array practically useless, because there's no longer an easy way to find out which element counts, say, the book title.

This is where sort() and asort() come in. They work just like sort() and rsort(), but they preserve the association between each element's key and its value:

```php
$myBook = array("title" => "Bleak House",
"author" => "Dickens",
"year" => 1853);

// Displays Array ([title] => Bleak House [author] => Dickens [year] => 1853])
asort($myBook);
print_r($myBook);

// Displays Array ([year] => 1853 [author] => Dickens [title] => Bleak House])
rsort($myBook);
print_r($myBook);
```

Note that although you can use asort() and sort() on indexed arrays, they're commonly used with associative arrays.

## Sorting Associative Array Keys with ksort() and rsort()

ksort() and rsort() behave in the same way as asort() and rsort(), respectively, preserving the associations between keys and values in ascending and descending order. The only difference is that, whereas asort() and rsort() sort elements by value, ksort() and rsort() sort the elements by their keys:

```php
$myBook = array("title" => "Bleak House",
"author" => "Dickens",
"year" => 1853);

// Displays Array ([author] => Dickens [title] => Bleak House [year] => 1853])
ksort($myBook);
print_r($myBook);

// Displays Array ([year] => 1853 [title] => Bleak House [author] => Dickens])
rsort($myBook);
print_r($myBook);
```

In this example, ksort() has sorted the array by key in ascending order ("title", "year"), whereas rsort() has sorted by key in the opposite order.

> As asort() and rsort(), ksort() and rsort() tend to be used mainly with associative arrays.

## Multi-Sorting with array_multisort

array_multisort() lets you sort multiple arrays at the same time, preserving the relationship between the arrays. To use it, simply pass a list of all the arrays that you want to sort:

```php
array_multisort( $array1, $array2, ... );
```

Consider the following example. Rather than storing book information in a multidimensional array, this stores it in three arrays: one for the books' authors, one for their titles, and one for their years of publication. By passing all three arrays to array_multisort(), the arrays are all sorted according to the values in the first array:

```php
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens");
$titles = array("The Grapes of Wrath", "The Trial", "The Hobbit", "A Tale Two Cities");
$pubYears = array(1939, 1925, 1937, 1859);
```

```php
array_multisort($authors, $titles, $pubYears);

// Displays Array { [0] => Dickens [1] => Kafka [2] => Steinbeck [3] => Tolkien }
print_r($authors);
echo "<br>";
```

```php
// Displays Array { [0] => A Tale of Two Cities [1] => The Trial [2] => The Grapes of Wrath [3] => The Hobbit }
print_r($titles);
echo "<br>";
```

```php
// Displays Array { [0] => 1859 [1] => 1925 [2] => 1939 [3] => 1937 }
print_r($pubYears);
```

Notice how the authors array is sorted alphabetically, and the $titles and $pubYears arrays are rearranged so their elements are in the same order as the corresponding elements in the $authors array. If you want to sort by title, just change the order of the arguments passed to array_multisort():

```php
array_multisort($titles, $authors, $pubYears);
```

In fact, array_multisort() is a bit clever than that. It actually sorts by the values in the first array, by the values in the next, and so on. Consider this example:

```php
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens");
``` (corrected "Dickens" from OCR)

```php
$pubYears = array(1939, 1925, 1937, 1859);
```

```php
array_multisort($authors, $titles, $pubYears);

These arrays contain information on three books by Steinbeck. You can see that array_multisort sorted all the array by author in ascending order as before. However it has also sorted the Steinbeck books — East of Eden, Of and Men, and Grapes of Wrath — into descending order.

You can also use array_multisort() to sort multi-dimensional arrays. This works in the same way as for multiple arrays, except that you only pass one in array. The function then sorts the array by the first element of each nested array, then by the second element of each nested array, and so on. The orders in the nested array is untouched.
