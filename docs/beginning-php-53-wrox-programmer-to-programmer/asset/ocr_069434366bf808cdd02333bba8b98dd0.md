# Chapter 2: Your First PHP Script

This script is very simple, but let's break down line-by-line to explore a few features of PHP.

The first line tells the PHP engine to expect some PHP code to follow:

```
<?php
```

Why do you need this line? This is due to the fact that PHP can be embedded in HTML Web pages. When the PHP engine starts processing the page, it assumes it's dealing with plain old HTML until told otherwise. By using the PHP delimiter, <?php, you are telling the PHP engine to treat anything following it<?php as PHP code, rather than HTML.

The next line displays the message "Hello, world!"

```
echo "Hello, world!";
```

PHP's echo() statement takes a string of text — in this case,"Hello, world!" and sends it as part of the Web page to the browser. The browser then displays "Hello, world!" to the visitor. The semicolon at the end of this line tells PHP that you've reached the end of the statement, and it should look for a new statement (or the end of the PHP code) to follow.

echo() doesn't have to be given a string of text; it can display anything that be displayed, as numbers or the results of expressions. You find out more about data types and expressions in the next chapter.

An alternative to echo() is the print() statement, which works in the exactly same way except that it returns a value (true). Generally speaking, you can use print() instead of echo() in your code if you prefer.

The final line of your script tells the PHP engine that it's reached the end of the current section of PHP code, and the following lines (if any) contain plain HTML again:

```
??>
```

# Embedding PHP within HTML

As you've gathered by, one of the nice things about PHP is that you can embed PHP code within HTML. In fact, .php script that you write is essentially treated as an HTML page by default. If the pages contain <?php ... ?> tags, the PHP engine sends the contents of the file as is to the browser.
