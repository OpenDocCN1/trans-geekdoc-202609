## How It Works

After creating an XHTML page header — including additional CSS rules to style the table — the script includes the HTML_Table PEAR package:

```php
require_once("HTML/Table.php");
```

Next, the script sets up an associative array of attributes for the <table> tag, then creates a new HTML_Table object with these attributes:

```php
$attrs = array("cellspacing" => 0, "border" => 0, "width" => "20em; border: 1px solid #666;");
$table = new HTML_Table($attrs);
```

The two-cell table header is created by calling the addRow() method, passing in an array of cell data. Notice that the $type argument is set to "th" to ensure header cells are created:

```php
$table->addRow(array("Sequence #", "Value", null, "th"));
```

The rest of the script is much like the chapter 4, with calls to HTML_Table methods replacing the old HTML markup. After setting up the iterations and the two variables, the first two rows of the table are created:

```php
$table->addRow(array("<th>0</th>", "0"));
$table->addRow(array("<th>1</th>", "1"));
```

Within the loop, new rows are added to the table, by calling addRow():

```php
$table->addRow(array("<th>$num2</th>", $num2));
```

After the loop, the altRowAttributes() method is called to set the alternate table rows. Counting from the row after the header row, every second row is given a CSS class of "alt":

```php
$attrs = array("class" => "alt");
$table->altRowAttributes(1, null, $attrs, true);
```

Finally, it's just of calling the table object's toHtml() method to display the table markup:

```php
echo $table->toHtml();
```

You can see from this example how easy it is to create tables with HTML_Table. The resulting PHP code is also clean and easy to modify. Furthermore, once you start using HTML_Table methods such as setAutoGrow() and setCellContents() you can create — and modify — quite complex tables in just a few lines of code.

# Chapter 15: Making Your Job Easier with PEAR

## Web Forms the Easy Way with HTML_QuickForm

Just as HTML_Table allows you to create HTML tables programmatically — thereby making your code clean and flexible — the HTML_QuickForm package provides a class for creating Web forms without needing to include a single line of HTML in your scripts. What's more, HTML_QuickForm can process the forms it creates, relieving you of the burden of writing (and testing) your validation, filtering, and error-reporting code.

In the following sections you take a look at the functionality in the HTML_QuickForm package, and then you create a membership form script using the power of HTML_QuickForm.

## Working with HTML_QuickForm

To use HTML_QuickForm, first create a new HTML_QuickForm object, and then call various methods to add elements — such as fields and labels — to the form. You can also add validation rules to make sure that the data entered for each field is correct, and use methods to remove unacceptable data from each field. You can then call various methods to validate the form, process the form, or display the form in the page (including any error messages to display to the user).

Here are some of the most useful methods of the HTML_QuickForm class:

| Method | Description |
| --- | --- |
| HTML_QuickForm($formName, $method, $action, $target, $trackSubmit) | The HTML_QuickForm constructor. All arguments are optional. $formName is the name of the form, included in the <form> tag attribute. $method is the form sending method ("get" or "post"); defaults to "post". $action is the form attribute — that is, the URL to send the form to. Leave blank to send the form back to the current script. $target is the target attribute, which lets you open the form handler URL in a new window, for example. An array of HTML attributes (name/value pairs) to add to the opening tag. $trackSubmit, if set to true, adds a hidden field to the form to track if it has been submitted or not. |
| add() | Adds an element to the form, and returns the element object that was created. The arguments that you need to pass in depend on the element you're creating. For example, to add a text input control with a name of "text" and a label of "Your Age", you might write: $form->addElement("text", "age", "Your Age"). You can also pass in an HTML_QuickForm_element object created with createElement(). |
| createElement() | Creates and returns an element as an HTML_QuickForm_element object. You can then pass this to addElement() to add it to the form, or addGroup() to add it to a group in the form. The exact arguments to pass depend on the type of element you're creating. |
| addGroup($elements, $name, $groupLabel, $separator, $appendName) | Adds groups of elements to the form. Element groups allow you to treat a bunch of elements like a single element. They're very useful for grouping elements in a form, and also for logical grouping (such as creating a group of related radio buttons). $elements is the array of elements to add. $name is the name of the group, and $groupLabel is the label to display the group in the form. $separator is the marker to use to separate elements in the group. Set $appendName to include the group name in each element name in the group (for example, *myGroup[element]* instead of just *element). This setting defaults to false. All arguments except $elements are optional. |
| addRule( $element, $message, $type, $format, $validation, $reset, $force ) | Adds a validation rule to the form element with $element. $message is the error message to display to the form field if the entered data is invalid, and $type is the rule type to use (for, 'required' to check that the field contains data, or 'alphanumeric' to check that the data in the field is alphanumeric). $format is required by some rules (for example, 'regex' type expects a regular expression). $validation can be 'server' or 'client'. Forms are usually validated in the PHP script (that is, server-side). By specifying 'client' here, HTML_QuickForm also includes JavaScript in the form for additional client-side validation. $reset resets with the 'client' $validation setting; if set to true, the form element resets to its original value if there was an error (The default is false). Finally, $force forces the validation rule to be applied if the element in question does not exist in the form. The default is false. |
| applyFilter( $element, $filter ) | Applies a filter to an element's data. The filter is a callback function. $element is the element to filter, and $filter is the callback name. For example, to trim whitespace from a form field called 'username', you could use $form->applyFilter('username', 'trim'). To run fields you can write your own filter callback functions. |
| isSubmitted() | Returns true if the form has been sent back to the user, or false if this is the first time the form is being displayed. Only works if you created the form with $trackSubmit set to true. |
| validate() | Runs all validation rules on the submitted form data, returning true if the form is valid and false otherwise. In addition, error messages are automatically inserted into the form, next to the invalid form fields. |
| process( $callback, $mergeFiles ) | Processes the submitted form by passing the form data to the function called $callback. You need to create this function yourself, and it should expect an associative array containing the submitted form fields and values. Any uploaded files are also passed to the callback function by default (turn this feature off by setting $mergeFiles to false). |
| toJson() | Returns the HTML markup to display the form. Call this method once you've created the form to retrieve the HTML for inserting into the Web page. |
