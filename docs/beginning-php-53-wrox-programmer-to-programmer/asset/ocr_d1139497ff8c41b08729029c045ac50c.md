This code displays:

```
Array
(
  [0] =>
  [1] => hello
  [2] =>
  [3] =>
  [4] =>
  [5] => goodbye
  [6] =>
)
```

This is because the regular expression causes any of the apostrophe, comma, and space characters to be treated as delimiters. The string is split at the start and end the first and last characters and it is also split three times between "hello" and "goodbye" because `preg_split()` "sees" three empty strings between the apostrophe, comma, and space characters in the input string.

Naturally these empty strings are unwanded. By setting the PREG_SPLIT_NO_EMPTY flag you can easily remove these strings from the resulting array:

```
$text = 'hello', 'goodbye';
$letters = preg_split('/[/ ]/', $text, -1, PREG_SPLIT_NO_EMPTY);
echo '<pre>';
print_r($letters );
echo '</pre>';
```

This code produces the desired result:

```
Array
(
  [0] => hello
  [1] => goodbye
)
```
