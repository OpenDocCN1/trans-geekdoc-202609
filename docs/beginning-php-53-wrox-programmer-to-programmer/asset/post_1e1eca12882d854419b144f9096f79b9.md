
# Chapter 8: Objects

## Try It Out

The following example shows how `__get()` and `__set()` can be used to store "nonexistent" properties in a private array. This effectively creates a class with a potentially unlimited number of "virtual" properties that are kept safe away from any real properties of the class. This technique can be useful for creating classes that do not hold arbitrary data.

Save the following as set_get.php in your document root folder and run it in your browser. You should see the result in Figure 8-3.

```php
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
http://www.w3.org/TR/xhtml/DTD/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:en lang="en">
<head>
  <title>Using __get() and __set()</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>Using __get() and __set()</h1>
</body>
</html>

<?php
class Car {
  public $manufacturer;
  public $model;
  public $color;
  private $_extraData = array();

  public function __get($propertyName) {
    if (array_exists($propertyName, $this->_extraData)) {
      return $this->_extraData[$propertyName];
    } else {
      return null;
    }
  }

  public function __set($propertyName, $propertyValue) {
    $this->_extraData[$propertyName] = $propertyValue;
  }
}

$car = new Car();
$car->manufacturer = "Volkswagen";
$car->model = "Beetle";
$car->color = "red";
$car->engineSize = 1.8;
$car->otherColors = array("green", "blue", "purple");

echo "<p>My car's manufacturer is " . $car->manufacturer . "</p>";
echo "<p>My car's engine size is " . $car->engineSize . "</p>";
echo "<p>My car's fuel type is " . $car->fuelType . "</p>";
echo "<h2>The $car Object:</h2><pre>";
print_r($car);
echo "</pre>";
?>
```

## __get() and __set()

Some properties:

- My car's manufacturer is Volkswagen.
- My car's engine size is 1.8.
- My car's fuel type is.

The $car Object:

```text
(
    [manufacturer] => Volkswagen
    [model] => Beetle
    [color] => red
    [_extraData:private] => Array (
        [engineSize] => 1.8
        [otherColors] => Array (
            [0] => green
            [1] => blue
            [2] => purple
        )
    )
)
```

### It Works

This script creates the familiar Car class containing some fixed properties - $manufacturer, $model, and also adds a private array, $_extraData. The Car class also contains a `__get()` method that looks up the requested property name in the keys of the $_extraData array, returning the corresponding value (if found).

To test these methods, the script then creates a new $car object, and sets properties. The first three are actual properties — $manufacturer, $model, and $color — so these properties get to "Volkswagen", "Beetle", and "red". The fourth property, $engineSize, doesn't exist in the class, so `__set()` method is called; this creates an array in $_extraData with a value of 1.8.

Similarly, the fifth property, $otherColors, also doesn't exist in the class, so `__set()` is called, creating an array in $_extraData with a key of "otherColors" that contains the strings "green", "blue", and "purple".

Next, the script displays some of the properties of $car object. Notice that, to the calling code, the $engineSize property doesn't exist. The script also tries to retrieve the value of a property called $fuelType because it doesn't exist in the class or in $_extraData array, the `__get()` method returns null to the calling code. This is why no value is displayed on the page.

Finally, the script dumps the contents of $car object using `print_r()`. Notice that the extra "properties" — $engineSize and $otherColors — are in the $_extraData array. (You can see that print_r() displays properties inside an object, which is useful for debugging.)

Although nonexistent properties were stored in a private array in this, they could easily have been stored in a file or database, or passed via an API (application programming interface) to `__get()` and `__set()`. This gives you some idea of the power of these two methods.

## Overloading Method Calls with __call()

Just as you can use `__get()` and `__set()` to handle reading and writing properties, you can also use `__call()` to handle nonexistent methods of a class. Create a method named `__call()` in your class that accepts the method name as a string, and any arguments passed as an array. The method should return a value (if any) back to the calling code:

```php
public function __call($methodName, $arguments) {
    // (do stuff here)
    return $returnValue;
}
```

`__call()` is very useful if you want to create a "wrapper" class that doesn't contain functionality of its own, but stands for method calls to external functions or APIs for processing.

## Try It Out a Wrapper Class

The following example shows how you can use `__call()` to create a wrapper class. In this case, the class provides an object-oriented interface to PHP's built-in string functions. Save the script as `clever_string.php` in your document root folder, then run it in your browser:

```php
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/html/DTD/html-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>Creating a Wrapper Class with __call()</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>Creating a Wrapper Class with __call()</h1>
</body>
<?php
class CleverString {

  private $theString = "";
  private static $_allowedFunctions = array("strlen", "strtoupper", "strpos");

  public function setString($stringVal) {
    $this->theString = $stringVal;
  }

  public function getString() {
    return $this->theString;
  }

  public function __call($methodName, $arguments) {
    if (in_array($methodName, CleverString::$_allowedFunctions)) {
      array_shift($arguments, $this->theString);
      return call_user_func_array($methodName, $arguments);
    } else {
      die("<p>CleverString::$methodName' doesn't exist</p>");
    }
  }
}

$myString = new CleverString();
$myString->setString("Hello!");
echo "<p>The string is: " . $myString->getString() . "</p>";
echo "<p>The length of the string is: " . $myString->strlen() . "</p>";
?>
```

When run, the script produces the output shown in Figure 8-4.

## How It Works

The CleverString class serves two purposes: it stores a string to be operated on, and it provides method-based access to three built-in string functions that operate on the stored string:

- `strlen()` for calculating the length of the string
- `strtoupper()` for converting the string to uppercase
- `strpos()` for finding the occurrence of a character in the string

As mentioned earlier, for security it's a good idea to check methods of this nature against a list of allowed methods. If $methodName is not one of the functions, the script terminates with an error message.

The `__call()` method is where the meat of the class lies: the next method checks if $methodName is contained in the static `allowedFunctions` array. This ensures that only the three functions can be called.

Once $methodName has been successfully validated, the method adds the object's stored string value, $this->theString, to the start of the $arguments array. This is because built-in functions—including the three that this is capable of calling—expect the string to be passed on the first argument.

Finally, the `__call()` method is ready to call the appropriate string function. It does use the PHP function `call_user_func_array()`, which expects the function name as the first argument, and the argument list—as an array—the `__call()` method returns the return value from the string function back to the method's calling.
