# Chapter 15: Making Your Job Easier with PEAR

| Method | Description |
| --- | --- |
| addRow($contents, $attrs, $type, $inTR, $body ) | Adds a row of cells to the table. $contents holds the row data as an indexed array, where each element is the data for a single cell. the optional $attrs argument contains attributes to apply the row, and the optional $type argument can be either 'th' (for header cells) or 'td' (for data cells) - the default is 'td'. Set the $inTR argument to true apply the attributes to the tr element rather than the td/th elements (default). If you're using tbody elements, specify the tbody group as the $body argument. (Use addBody() to add a new body - see the online documentation for details.) |
| addCol($contents, $attrs, $type, $body ) | Adds a column of cells. The parameters work in the same as addRow(). |
| altRowAttributes($start, $attrs1, $attrs2, $inTR, $body ) | Allows you to set different attributes for every other table row, so you can create alternating rows. $start is the index of the row to start alternating and $attrs1 and $attrs2 are associative arrays or strings holding the attributes to apply to each alternate row. The optional $inTR and $body arguments work in the same way as in addRow(). |
| setCell($row, $col, $contents, $type, $body ) | Allows you to set or change the contents of an arbitrary cell. The cell is specified by $row and $col (numeric starting from zero), and $contents contains the string to place in the cell. The optional $type and $body arguments work in the same way as in addRow(). |
| setHeaderContents($row, $col, $contents, $body ) | Allows you to set or change a header cell. In a similar way you may setCellContents(). |
| setAutoGrow($grow, $body ) | With $grow set to true, auto-grow is enabled. This means that, when you use setCellContents() or setHeaderContents() to populate non-existent cells, empty cells are created as necessary to fill the gap between the existing cells and the new cells. The default value for $grow is false. The $body argument works like its counterpart addRow().
