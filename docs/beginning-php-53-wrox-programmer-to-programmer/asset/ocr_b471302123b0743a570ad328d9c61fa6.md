# Summary

This chapter concluded the three-chapter series on building database-driven applications with PHP and MySQL. Whereas the last chapter concentrated on reading data from MySQL databases, in this chapter you learned how to alter MySQL data.

First you explored the SQL INSERT, UPDATE, and DELETE statements and learned how to execute these statements from your PHP scripts using PDO.

The rest of the chapter concentrated on practical examples, showing how to use PDO to manipulate MySQL data:

+   - First you wrote a script that allows new members to register for your fictional book club database.
