```
<label for="genderFemale">Female</label>

<label for="favoriteWidget">What's your favorite widget?</label>
<select name="favoriteWidget" id="favoriteWidget" size="1">

<option value="megaWidget"><?php setSelected("favoriteWidget", "megaWidget") ?>?MegaWidget</option>
<option value="wonderWidget"><?php setSelected("favoriteWidget", "wonderWidget") ?>?The WonderWidget</option>

```

By including (and populating) all the fields — whether or hidden — in each of the steps, the script ensures the entire signup data is sent back to the server each time a form is submitted, thereby allowing the data to be carried across three steps.

Steps 2 and 3 also include Back and Next buttons, where step 1 includes a Next button. Finally, displayThanks() simply displays the message to the user.
