# Introduction

Chapter 2 walks you through installing a copy of the PHP engine on Ubuntu Linux, Windows, and Mac OS X; looks at other ways you can install or use PHP; and shows how to write a simple PHP script.

Chapter 3 looks at some PHP language concepts. You look at variables, data types, operators, expressions, and constants.

Chapter 4 shows how to change the flow of your scripts by creating decisions and loops. You explore the `if`, `else`, and `switch` statements; the ternary operator; and the `do`, `while`, `for`, `break`, and `continue` statements. You also learn to use nest loops, and how to mix decisions and loops with HTML.

Chapter 5 explores PHP's handling of strings, or sequences of characters. You learn how to create strings; how to retrieve characters from a string; and how to manipulate strings with functions such as `strlen()`, `substr()`, `strstr()`, `strpos()`, `str_replace()`, and `printf()`, to name a few.

Chapter 6 covers arrays — variables that can hold values. You learn the difference between indexed and associative arrays, and find out how to create arrays and access their individual elements. The rest of the chapter focuses on array manipulation, including functions as `print_r()`, `array_slice()`, `count()`, `array_merge()`, and `list()`. You also learn to foreach loops, and how to work with multidimensional arrays.

Chapter 7 looks at the concept of functions — blocks of code that you can use and again. You learn how to call built-in functions, and how to work with variable functions. You also study how to create your own functions, including defining parameters, returning values, understanding scope, and using anonymous functions. Other function-related topics such as references and recursion are explored.

Chapter 8 delves into the world of object-oriented programming. You learn the advantages of an object-oriented approach, and learn how to build classes, properties, and methods, and how to create and use objects. You also explore advanced topics such as overloading, inheritance, interfaces, constructors and destructors, and namespaces.

Chapter 9 shows how to use PHP to create interactive Web forms. You learn how to create HTML forms, how to capture data in PHP, and how to use PHP to generate dynamic forms. You also explore file upload forms and page redirection.

Chapter 10 looks at how to preserve an application's state between page views. You explore three different strategies: query strings, cookies, and PHP sessions. The chapter includes an example user system.

Chapter 11 takes a look at PHP's file and directory handling. You learn how to open and close files; how to find out more information about a file; how to read and write to files; how to work with file permissions; how to copy, rename, and delete files; and how to manipulate directories. The chapter includes a simple text editor as an example.

Chapters 12-14 explore databases in general and MySQL in particular, You learn how to MySQL databases using PHP. You learn some database and SQL theory; look at how to connect to MySQL from PHP; and learn how to retrieve, insert, update, and delete data in a MySQL database.
