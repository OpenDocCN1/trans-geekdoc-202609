
## Creating File Upload Forms

As well as sending textual data to the server, Web forms can be used to upload files to the server. If you've used a Web-based email service such as Yahoo! Mail or Gmail, chances you've sent email with attachments. To add an attachment, you generally click the Browse in the Web page to select a file on your computer. Then, when you submit the form, your browser sends the file to the server along with the other data.

You've already seen how to create a file select field at the start of this chapter:

```html
<label for="fileSelectField">A file select field</label>
<input type="file" name="fileSelectField" id="fileSelectField" value="" />
```

In addition, a form file select field must use the post method, and it must also have an enctype="multipart/form-data" attribute in the <form> tag, as follows:

```html
<form action="form_handler.php" method="post" enctype="multipart/form-data">
```

This ensures that the form data is encoded as multipart MIME data — the same format that's used for encoding attachments in email messages — which is required for uploading binary data as files.

You can have as many file select fields as you like within your form, allowing your users to upload multiple files at once.

## Accessing Information on Uploaded Files

Once the form data hits the server, the PHP engine recognizes that the form contains an uploaded file or files, and creates a superglobal array $_FILES containing various pieces of information about the file or files. Each file is described by an element in the $_FILES array keyed on the name of the field that was used to upload the file.

For example, say your form contained a file select field called photo:

```html
<input type="file" name="photo" value="" />
```

If the user uploaded a file using this field, its details would be accessible via PHP array element:

```php
$_FILES["photo"]
```

This array element is itself an associative array that contains information about the file. For example, you can find out the uploaded file's filename like:

```php
$filename = $_FILES["photo"]["name"];
```

## Part III: Using PHP Practice

Here's a full list of the elements stored in each nested array within the $_FILES array:

| Array Element | Description |
| --- | --- |
| name | The filename of the uploaded file. |
| type | The MIME type of the uploaded file. For example, a JPEG image would probably have a MIME type of image/jpeg, whereas a QuickTime movie file would have a MIME type of video/quicktime. |
| size | The size of the uploaded file, in bytes. |
| tmp_name | The full path to the temporary file on the server that contains the uploaded file. (All uploaded files are stored as temporary files until they are needed.) |
| error | The error or status code associated with the file upload. |

The error element contains an integer value that corresponds to a built-in constant that explains the status of the uploaded file. Possible values include:

| Constant | Value | Meaning |
| --- | --- | --- |
| UPLOAD_ERR_OK | 0 | The file was uploaded successfully. |
| UPLOAD_ERR_INI_SIZE | 1 | The file is bigger than the allowed size specified in the upload_max_filesize directive in the php.ini file. |
| UPLOAD_ERR_FORM_SIZE | 2 | The file is bigger than the allowed size specified in the MAX_FILE_SIZE directive in the form. |
| UPLOAD_ERR_NO_FILE | 4 | No file was uploaded. |
| UPLOAD_ERR_NO_TMP_DIR | 6 | PHP doesn't have access to a temporary folder on the server to store the file. |
| UPLOAD_ERR_CANT_WRITE | 7 | The file couldn't be written to the server's hard disk for some reason. |
| UPLOAD_ERR_EXTENSION | 8 | The file was stopped by one of the currently loaded PHP extensions. |

Most of these error codes are self-explanatory. UPLOAD_ERR_INI_SIZE and UPLOAD_ERR_FORM_SIZE are explained in the following section.

## Limiting the Size of File Uploads

Often's a good idea to prevent unusually large files being sent to the server. Apart from consuming bandwidth and hard disk space on the server, a large file can cause your PHP script to overload the server's CPU. For example, if your PHP script is designed to work on an uploaded 10-kilobyte text file, uploading a 100-megabyte text file might cause your script some problems.

## Chapter 9: Handling HTML Forms with PHP

PHP allows you to limit the size of uploaded files in a few ways. If you have access to your `php.ini` file, you can add or edit a directive `upload_max_filesize` in the file:

```ini
; Maximum allowed size for uploaded files.
upload_max_filesize = 32M
```

Then, if a user tries to upload a file larger than this (32 megabytes), the file upload is cancelled and the corresponding `error` array element is set to `UPLOAD_ERR_INI_SIZE`.

You can find out about editing your `php.ini` file in Appendix B.

If you don't access your server's `php.ini` file, you can add a hidden form field `MAX_FILE_SIZE` that specifies the maximum size (in bytes) of an uploaded file. This should be done before the file you upload:

```html
<input type="hidden" name="MAX_FILE_SIZE" value="10000" />
<input type="file" name="fileSelect" id="fileSelect" value="" />
```

If the uploaded file is larger than this, the file is cancelled and the corresponding `error` array element is set to `UPLOAD_ERR_FORM_SIZE`. In theory, a browser can also look at the `MAX_FILE_SIZE` field in the form and prevent the user from uploading a file bigger than the first place. In practice, hardly any browsers support this technique.

It's also relatively easy to modify your work file and alter the value of the `MAX_FILE_SIZE` field if it's too large (or even remove the field altogether). For this reason, it's best to use `upload_max_filesize` to limit your files, if possible.

Of course, you can also check the size of an uploaded file manually and reject it if it's too large:

```php
if ( $_FILES["photo"]["size"] > 10000 ) die("File too big!");
```

## Try Out Create a File Upload Script

You now have all the knowledge required to create file upload forms and PHP scripts that can handle them. In this example, you create a script that allows the user to upload a JPEG photo, which is then displayed to them in your document.

First, save the following script as photo_upload.php in your document root:

```php
<?php
function displayForm() {
?>
<h1>Uploading a Photo</h1>

  <p>Please enter your name and choose a photo, then click Send Photo.</p>

  <form action="photo_upload.php" method="post" enctype="multipart/form-data">
    <div style="width: 30em;">
      <input type="hidden" name="MAX_FILE_SIZE" value="50000" />

      <label for="visitorName">Your name</label>
      <input type="text" name="visitorName" id="visitorName" value="" />

      <label for="photo">Your photo</label>
      <input type="file" name="photo" id="photo" value="" />

      <div style="clear: both;">
        <input type="submit" name="sendPhoto" value="Send Photo" />
      </div>
    </div>
  </form>
<?php
}

function displayThanks() {
?>
<h1>Thank You</h1>
  <p>Thanks for uploading your photo<?php if ($_POST['visitorName']) echo "," . $_POST['visitorName']; ??>!</p>
  <p>Here's your photo:</p>
  <p><img src="photos/<?php echo $_FILES['photo']['name'] ?>" alt="Photo" /></p>
<?php
}

if (move_uploaded_file($_FILES["photo"]["tmp_name"], "photos/photo.jpg")) {
    echo "Your file was successfully uploaded.";
} else {
    echo "There was a problem uploading your file.";
}

if (isset($_POST['sendPhoto'])) {
    displayThanks();
} else {
    displayForm();
}
?>
```

Next, create a photos folder in the same directory as your Web server (the document root). This folder is to store the uploaded photos. You will need to give your Web server the ability to create files in this folder. On Linux or Mac OS you can do this in a Terminal window as follows:

```
cd /path/to/document/root
chmod 777 photos
```
