# Dealing with Multi-Value Fields

You learned earlier that you can create form fields that send multiple values, rather than a single value. For example the following form fields are capable of sending multiple values to the server:

```html
<label for="favoriteWidgets">What are your favorite widgets?</label>
<select name="favoriteWidgets" id="favoriteWidgets" size="3"
multiple="multiple">
  <option value="superWidget">The SuperWidget</option>
  <option value="megaWidget">The MegaWidget</option>
  <option value="wonderWidget">The WonderWidget</option>
</select>
```

```html
<label for="newsletterWidgetTimes">Do you want to receive our
<input type="checkbox" name="newsletter" id="newsletterWidgetTimes"
value="widgetTimes" />
<label for="newsletterFunWithWidgets">Do you want to receive our
Fun with Widgets'</label>
<input type="checkbox" name="newsletter" id="newsletterFunWithWidgets"
value="funWithWidgets" />
```

The first form field is a list box, allowing the user to pick one or more (or no) options. The second form fields are checkboxes with the same name (newsletter) but different values (widgetTimes and funWithWidgets). If the user checks both then the values, widgetTimes and funWithWidgets, are sent to the server field name name.

So how can you handle multiple-value fields in your PHP scripts? The trick is to add square brackets [] after the field name in your HTML form. Then, when the PHP engine sees a submitted form field with square brackets, it creates a nested array of values within the $_GET or $_POST superglobal array, rather than a single value. You can pull the individual values out of that nested array. You might create a multi-select control as follows:

```html
<select name="favoriteWidgets[]" id="favoriteWidgets" size="3"
multiple="multiple" ... </select>
```

You'd then retrieve the following field values as follows:

```php
$favoriteWidgetValuesArray = $_GET["favoriteWidgets"]; // If using get method
$favoriteWidgetValuesArray = $_POST["favoriteWidgets"]; // If using post method
```

Now save the following script as process_registration_multi.php in your document folder:

```php
<!DOCTYPE PUBLIC "-//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/html1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>Thank You</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>Thank You</h1>
  <p>Thank you for registering. Here is the information you submitted:</p>

  <?php
  $favoriteWidgets = "";
  $newsletters = "";

  if (isset($_POST["favoriteWidgets"])) {
      foreach ($_POST["favoriteWidgets"] as $widget) {
          $favoriteWidgets .= $widget . ", ";
      }
  }
  if (isset($_POST["newsletter"])) {
      foreach ($_POST["newsletter"] as $newsletter) {
          $newsletters .= $newsletter . ", ";
      }
  }

  $favoriteWidgets = preg_replace("/, *$/", "", $favoriteWidgets);
  $newsletters = preg_replace("/, *$/", "", $newsletters);
  ?>

  <dl>
    <dt>First name</dt><php echo $_POST["firstName"];?></dd>
    <dt>Last name</dt><php echo $_POST["lastName"];?></dd>
    <dt>Password</dt><php echo $_POST["password1"];?></dd>
    <dt>Retype password</dt><php echo $_POST["password2"];?></dd>
    <dt>Gender</dt><php echo $_POST["gender"];?></dd>
    <dt>Favorite widgets</dt><php echo $favoriteWidgets;?></dd>
    <dt>You want to receive the following newsletters?</dt><php echo $newsletters;?></dd>
    <dt>Comments</dt><php echo $_POST["comments"];?></dd>
  </dl>
</body>
</html>
```
