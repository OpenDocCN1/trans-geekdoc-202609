# Chapter 2: Your PHP Script

How It Works
This example shows how you can embed PHP within an HTML page. The PHP code itself is exactly the same — echo "Hello, world!" — by surrounding the PHP with HTML markup, you created a well-formed HTML page styled with CSS.

First, a DOCTYPE tag is used to declare that the page is an HTML 1.0 Strict Web page:

```
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
```
```

Next, the head of the Web page gives the page title — “Hello” and links to a style sheet, common.css:

```
<head>
<title>Hello</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
```
```

Finally, the body element includes an h1 (top-level heading) element containing the output from the PHP code — echo "Hello, world!" — and the page is finished with a closing HTML tag:

```
<body>
<h1><?php echo "Hello, world!\ ?></h1>
</body>
</html>
```
```

Note that you don't have to have the <php ?> tags on separate lines. In this case, the tags and enclosed PHP code are all part of a single line.

Meanwhile, the common.css style sheet file contains selectors to style some common HTML elements — including the h1 heading used in the page — to produce the nicer-looking result.

> Keep this common.css file in your root folder, because it's used throughout other examples in this book.

If you view the source of the resulting Web page in your browser, you can see that the final page is identical to the original HTML markup, except that the PHP code — <?php echo "Hello, world!"; ?> — has been replaced with the code’s output (“Hello, world!”). The PHP engine only touches the parts of the page that are enclosed by the <?php ... ?> tags.
