# Exploring Regular Expression Syntax

Although a complex regular expression can look like Greek to the newcomer, regular expressions are nothing more than a set of simple rules encoded in a string. Once you understand how the rules work you'll be able to read any regular expression with relative ease.

In the following sections you learn some useful regular expression rules. Though this list of isn’t 100 percent complete, it’s more than adequate for most matching scenarios. (For a seriously in-depth treatment of regular expressions, try the book Mastering Regular Expressions by Jeffrey E. F. Friedl, published by O’Reilly, ISBN 1-5692-257-3).

# Matching Literal

The simplest form of regular expression pattern is a literal string. In this situation, the string stored in the target string, with no additional rules applied.

As you’ve already, alphabetical characters such as “hello” are treated as literal strings in regular expressions. The string “hello” in a regular expression matches the text “hello” in the target string. Similarly, many other characters — as digits, spaces and double quotes, and the %, &, @ and # symbols — treated literally by the regular expression engine.

However, as we will see, some characters have special meanings within regular expressions. These nineteen special characters:

```
\ + * ? [ ^ ] $ ( ) { } = < =
```
