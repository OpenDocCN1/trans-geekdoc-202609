# Appendix B: Configuring PHP

```
; E_COMPILE_ERROR|E_RECOVERABLE_ERROR|E_ERROR|E_CORE_ERROR (Show only errors)
; E_ALL |E_STRICT (Show all errors, warnings and notices including coding
standards.)
; Default Value: E_ALL &~E_NOTICE
; Development Value: E_ALL | E_STRICT
; Production Value: E_ALL &~E_DEPRECATED
http://php.net/error-reporting
error_reporting = E_ALL
```

; This directive controls whether or not when PHP will output errors,
; notices and warnings too. Error output is very useful during development, but
; it could be very dangerous in production environments. Depending on the code
; which is triggering them sensitive information could potentially leak
out of your application database usernames and passwords.
It's recommended that errors be logged on production servers rather than having them set to STDOUT.

+   - Possible Values:
- Off = not display any errors
- stderr = Display errors to STDERR (affects all CGI/CLI binaries!)
- Or stdout = Display errors to STDOUT
- Default Value: On
- Development Value: On
- Production Value: Off
http://php.net/display-errors
display_errors = On

The display of errors which occur during PHP's startup sequence are handled separately from display_errors. PHP's default behavior is to suppress those errors from clients. Turning the display of startup errors can be useful in debugging configuration problems. But, it's strongly recommended that you leave this off on production servers.
- Default Value: On
- Development Value: On
- Production Value: Off
http://php.net/display-startup-errors
display_startup = On

Besides desiring errors, PHP can also log errors to locations such as a server-side script, STDERR, or a location specified by the error_log directive bool. While errors should not be displayed on productions they should be monitored and logging is a great way to do that.
- Default Value: On
- Development Value: On
- Production Value: On
http://php.net/log-errors
log_errors = On

Set maximum length of log_errors. In error_log information about the source is added: The default is 1024 and 0 allows to not apply any maximum length at all.
http://php.net/log-errors-max-len
log_errors_max_len = 1024

Do not log repeated messages. Repeated errors must occur in same file on same line unless ignored_source is set true.
