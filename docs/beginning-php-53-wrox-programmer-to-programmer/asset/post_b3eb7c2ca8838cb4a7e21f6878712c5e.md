# How It Works

First, the script creates a blank image and allocates two colors:

```php
<?php
$textImage = imagecreate(200, 120);
$white = imagecolorallocate($textImage, 255, 255, 255);
$black = imagecolorallocate($textImage, 0, 0, 0);
```

Then, the string is drawn on the image by calling imagehtext():

```php
imagehtext($textImage, 16, 0, 10, 50, $black, "/usr/share/fonts/ttf-bitstream-vera/Vera.ttf", "Vera, 16 pixels");
```

Finally, the script outputs the resulting image:

```php
header("Content-type: image/png");
imagepng($textImage);
imagedestroy($textImage);
?>
```

To demonstrate how to draw rotated text, change the line:

```php
imagehtext($textImage, 16, 0, 10, 50, $black, "/usr/share/fonts/ttf-bitstream-vera/Vera.ttf", "Vera, 16 pixels");
```

to:

```php
imagehtext($textImage, 16, -30, 10, 30, $black, "/usr/share/fonts/ttf-bitstream-vera/Vera.ttf", "Vera, 16 pixels");
```

All that changed is you're now drawing the text in a -30-direction, rather than zero degrees. The direction of rotation is counterclockwise; a negative number angles the text in a clockwise direction. If zero degrees is three o'clock, 30 degrees in a clockwise direction is the four o'clock position on a clock. You can see the results in Figure 17-25.

# String Matching with Regular Expressions

In Chapter 5 you explored many of PHP's powerful string functions, such as `strstr()` for finding text within a string and `str_replace()` for searching and replacing text within a string. In this chapter you learn about PHP's even more powerful regular expression functions. These give you a lot more flexibility than the string-matching functions because they let you compare a string against a pattern. For example, you can search for a string of characters comprising exactly three digits, followed by either a comma or a dot, followed by four letters. With regular expressions you use special symbols like `^` and `$` to specify a pattern. Patterns can get quite complex, and can be hard to decipher when you start out. However, with a bit of practice, as well as some hints in this chapter, you'll find that you can read regular expressions quickly and easily.

Although regular expressions aren't essential to PHP programming — you can do a job with string matching functions and a loop—they're your best bet when you need to match patterns. For one single, regular expression is usually more compact and intuitive than a whole series of string matches. The expression will often run quicker, too. By the time you read this chapter you'll know:

- Matching strings against regular expressions: Explore PHP's `preg_match()` and `preg_match_all()` functions that let you apply regular expressions to strings to find matches
- The ins and outs of regular expression syntax: You learn all the special characters used in regular expressions, as well as how to match character types, several characters at once, alternative groups of characters, and much more
- Searching entire arrays of strings: You can use PHP's `preg_grep()` function to walk through an array of strings looking for text that matches a regular expression
- Replacing text: You look at PHP's `preg_replace()` and `preg_replace_callback()` functions for replacing matched text in a string with different text
- Pattern modifiers: You can make regular expressions even more flexible by adding certain patterns to an expression
- Splitting strings: Just as you can `explode()` to split a string using a fixed delimiter, you can use `preg_split()` to split strings based on regular expressions

You also learn how to use regular expressions to match Web pages for linking URLs, and to validate input (a very common use of regular expressions) as well as manipulate strings. This chapter works exclusively with a type of PHP regular expression known as PCREs, or Perl-compatible regular expressions. Older versions of PHP supported another type of regular expressions known as POSIX. This included functions as `ereg()`, `ereg_replace()`, and `split()`. As of PHP 5.3, POSIX regular expressions are deprecated, and if you have existing code that uses the POSIX Extended functions, now is a good time to replace them with the PCRE equivalents.

# What is a Regular Expression?

Regular expressions provide you with a special syntax for searching patterns of text within strings. At its simplest, a regular expression is simply a string of search text as you would pass to `strstr()` (Chapter 5). Regular expressions are enclosed in delimiters (usually slashes). For example, this simple expression searches for the word “world” anywhere within your target string:

```
/world/
```

This, however, is a trivial example (in fact you would be better off the faster `strstr()` in this case). Regular expressions start to become useful once you insert additional characters that have special meanings. For example, the caret (`^`) character at the start of the expression means “the following characters must appear at the start of the target string:

```
/^world/
```

This will match the string “world”, but not the string “hello, world” (because “world” isn’t right at the start of the string).

Here are some examples of the kind of searches you can perform with regular expressions:

- The word “train” but not the word “training”
- At one digit, followed by a single letter A, B, C
- The word “hello” followed by five and ten other characters, followed by “world"
- One or two digits, followed by the letters “st”, “nd”, “rd”, or “th”, followed by a space, followed by three letters (good for identifying dates embedded within strings)
