## How It Works

You can see that the structure of this register.php script is quite different than that of the Chapter 14 version. First of all, the script includes the common code file, along with the two PEAR packages, HTML_QuickForm and HTML_QuickForm_Renderer_Tableless.

It then creates a HTML_QuickForm object with an empty name attribute, a method="post" attribute, an action attribute that points the form back to the script(register.php), an empty target attribute, no additional attributes, and the onSubmit to true that the script knows when the form has been submitted. The HTML_QuickForm object has been created, its name attribute is removed from the element (this is to ensure that the page is fully XHTML 1.0 compliant).

```php
$form = new HTML_QuickForm( "post", "register.php", array("style" => "width:300px;"), );
$form->removeAttribute("name");
```

The script calls addElements and addRules(), that add several elements and validation rules to the $form object (you see how these work in a moment). It also calls the object's setRequiredNode() method to remove the default "*" denotes field message; because the script already displays its own, similar message in the Web page:

```php
addElements( $form );
addRules( $form );
$form->setRequiredNode( "*" );
```

The main decision logic of the script follows. If the form was submitted, it passes validation, it is processed by calling the $form object's process() method, passing in the name of the function that will handle the data(processForm()). Then a thank you message is displayed:

```php
if ($form->submitted() && $form->validate()) {
    $form->process("processForm");
    displayThanks();
}
```

If the form was not submitted, or it was submitted but didn't validate, the form is displayed. To do this, the first script displays the page header by calling the displayPageHeader() function in the common.php file. It creates a new HTML_QuickForm_Renderer_Tableless renderer, sets the object's renderer to this object by calling the $form object's accept() method, and outputs the form by calling the toHTML() method of the renderer object, sending the marker to the browser.
