# Chapter 9: Handling HTML Forms with PHP

Next the script defines some helper functions, validateField() is used within the form to display a red error box around a form field label if the required field hasn't been filled. It passed a field name, and a list of all the required fields that weren't filled in. If the field name is within the list, it displays the marker for the error box:

```
function validateField($fieldName, $missingFields) {
    if (in_array($fieldName, $missingFields)) {
        echo "class=error";
    }
}
```

setValue() is used to refill the text input fields and text area in the form. It expects to be passed a field name. It looks up the field name in the $_POST superglobal array, and if found, it outputs the field's value:

```
function setValue($fieldName) {
    if (isset($_POST[$fieldName])) {
        echo $_POST[$fieldName];
    }
}
```
