# Part III: Using PHP Practice

\A and \z are similar to ^ and $ which will match at the beginning and end of a line, respectively, matching a multi-line string in multi-line mode (explained in the "Altering Matching Behavior with Pattern Modifiers" section in the chapter). \A and \z only match at the beginning and end of the target string, respectively.

\Z is used when reading lines from a file that may or not have a newline character at the end.

\b and \B are used when searching for complete words:

```
echo preg_match("/.*", "My hovercraft is full of eels"); //
Displays "1"
echo preg_match("\\bover\\b", "My hovercraft is full of eels"); //
Displays "0"
echo preg_match("\\bover\\b", "One flew over the''s nest"); //
Displays "1"
```

When using \b, the beginning or end of the string is also considered a word boundary:

```
preg_match("\\bover\\b", "over and under"); // Displays "1"
```

By using \b anchor, with alternatives within a subexpression, it's possible to enhance the "early date" selection, so that it matches only two or four-digit years (and not three-digits):

```
preg_match("\\b(jan|feb|mar|apr|may|jul|aug|sep|oct|nov|dec)*\\/\\d{1,2}\\/\\d(2)|d(4))\\b", "jul/15/2006"); // Displays "1"

preg_match("\\b(jan|feb|mar|apr|may|jul|aug|sep|oct|nov|dec)*\\/\\d{1,2}\\/\\d(2)|d(4))\\b", "jul/15/2006"); // Displays "0"
```

The last part of the expression reads, "either two digits or four digits, followed by a word boundary (or the end of the string)",

```
\d(2)\\d(4)\b
```

You can create your own types of anchor, for example, you can match only when it comes before an ampersand, or only when it follows a capital letter (without actually including the ampersand or capital in the match). These kinds of custom anchors are known as lookahead and lookbehind assertions, and they're out of the scope of this chapter; however, you can read them in the PHP manual at http://www.php.net/manual/en/regexp.reference.assertions.php.
