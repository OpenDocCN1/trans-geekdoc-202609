# Data Handling

This section deals with how PHP handles data entering and leaving a script. Interests of interest include variables_order and request_order, which allow you to customize superglobals populated and in what order, and post_max_size, which limits the amount of data that can be sent in a post (note that this limits the size of file uploads — see the section "Uploads" later in this appendix for more details).

If you're used to older versions of PHP, notice that the magic quotes and register features are now deprecated in PHP 5.3, and will be removed from PHP 6.
