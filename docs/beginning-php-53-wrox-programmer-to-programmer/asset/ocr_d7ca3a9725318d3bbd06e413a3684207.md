# Exercises

+   1. Write a Calculator class that can store two values, add them, subtract them, multiply them together, or divide them on request. For example:

```
$calc = new Calculator( 3, 4 );
echo $calc->add(); // Displays "7"
echo $calc->multiply(); // Displays "12"
```

+   2. Create another class, CalAdvanced, that extends (inherits from) the Calculator class. CalAdvanced should be capable of storing either one or two values:

```
$ca = new CalAdvanced( 3 );
$ca = new CalAdvanced( 3, 4 );
```

CalAdvanced should also add the following methods:

+   - pow() that returns the result of raising the first number (the base) to the power of the second number

+   - sqrt() that returns the square root of the first number

+   - exp() that returns e raised to the power of the first number

(Hint: PHP contains built-in functions called pow(), sqrt(), and exp().
