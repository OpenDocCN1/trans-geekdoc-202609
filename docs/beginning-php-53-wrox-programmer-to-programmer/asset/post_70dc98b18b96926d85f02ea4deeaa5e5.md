### Adding and Removing Array Elements

You already know that you can add elements to an array using square bracket syntax. For example:

```php
$myArray[] = "new value";
$myArray["newKey"] = "new value";
```

This syntax is fine for simple scenarios. However, if you need something more powerful, PHP has five useful functions that you can use to add and remove:

- array_unshift() — Adds one or more elements to the start of an array
- array_shift() — Removes one or more elements from the start of an array
- array_push() — Adds one or more elements to the end of an array
- array_pop() — Removes the last element from an array
- array_splice() — Removes element(s) from and/or adds element(s) to any point in an array

## Chapter 6: Arrays

### Adding and Removing Elements at the Start and End

You can use array_unshift() to insert an element at the start of an array. You pass the array, followed by one or more elements to add. The function returns the new number of elements in the array. For example:

```php
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens");
echo array_unshift($authors, "Hardy", "Melville") . "<br>"; // Displays "6"
```

```php
// Displays Array ([0] => Hardy [1] => Melville [2] => Steinbeck [3] => Kafka [4] => Tolkien [5] => Dickens)
print_r($authors);
```

You can add key/value pairs to associative arrays using array_unshift() or its counterpart, array_pop(). However, you can work around this using array_merge(), which is discussed later in the chapter.

array_shift() removes the first element from an array, and returns its value (but not its key). To use it, pass the array to array_shift():

```php
$myBook = array("title" => "The Grapes of Wrath",
"author" => "John Steinbeck",
"pubYear" => 1939);
```

```php
echo array_shift($myBook) . "<br>"; // Displays "The Grapes of Wrath"
// Displays Array ([author] => John Steinbeck [pubYear] => 1939)
print_r($myBook);
```

To add an element to the end of an array, you can use the square bracket syntax mentioned previously. You can use array_push(), which allows you to add multiple elements at once and also tells you the new length of the array. You use it in the same way as array_unshift(): pass the array, followed by the value(s) to add. Here's an example:

```php
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens");
echo array_push($authors, "Hardy", "Melville") . "<br>"; // Displays "6"
```

```php
// Displays Array ([0] => Steinbeck [1] => Kafka [2] => Tolkien [3] => Dickens [4] => Hardy [5] => Melville)
print_r($authors);
```

By the way, with both array_unshift() and array_push(), if you include an array as one of the values to add, the array is added to the original array as an element, turning the original array into a multidimensional array:

```php
$authors = array( "Steinbeck", "Kafka", "Tolkien", "Dickens" );
$newAuthors = array( "Hardy", "Melville" );
echo array_push( $authors, $newAuthors ) . "<br>"; // Displays "5"

Displays:

print "<pre>";
```

If you want to add the elements of an array individually to the original array, use array_merge() (discussed later in this chapter).

array_pop() is the counterpart to array_shift(); it removes the last element from an array and returns the element's value. You can use it, pass the array that you want to remove the element from:

```php
$myBook = array( "title" => "The Grapes of Wrath",
"author" => "John Steinbeck",
"pubYear" => 1939 );
```

```php
echo array_pop( $myBook ) . "<br>"; // Displays "1939"

// Displays [title] => The Grapes of Wrath [author] => John Steinbeck
print_r( $myBook );
```

array_push() and array_pop() are handy for creating a last-in, first-out (LIFO) stack of values. You now add values onto the "top" of the stack with array_push(), retrieve the most recently added value with array_pop(). Stacks are very useful if you write a lot of recursive code. (Recursion is covered in Chapter 7).

### Adding and Removing Elements in the Middle

If you want to do a bit more than just add or remove values at the beginning or end of an array, you need the more powerful array_splice() function. This function is array equivalent of the string-manipulation function substr_replace(). (You learned about substr_replace() in Chapter 5.)

array_slice() removes a range of elements in an array and replaces them with elements from another array. Both the removal and replacement are optional, you can just remove elements without adding ones, or just insert elements without removing.

array_slice() takes the array to be manipulated, and the position of the first element (counting from zero) to start the slice operation. (Remember that all arrays, even associative arrays, have a concept of element positioning). Next, you pass in an optional argument that specifies many elements to remove; if omitted, the function removes all elements from the start point to the end of the array. Finally, you can pass another optional argument, which is the array of elements to insert.

array_slice() returns an array containing the extracted elements (if any).
