; Output buffering is a mechanism for controlling how much output data
; (excluding headers and cookies) PHP should keep internally,before pushing that
; date to the client. If your application's output exceeds this setting, PHP
; will send that in chunks of roughly the size you specify.
; Turning on this and setting his maximum buffer size can yield some
; interesting side-effects on your application and web server.
; You may be able to send headers and cookies after you've already sent output
; through point or echo. You may see performance benefits if your server is
; emitting,less packets to buffered output versus PHP streaming the output
; as it gets it. On production servers, 4096 bytes is a good setting for
performance

; Note: Output buffering can also be controlled via Output Buffering Control
functions.
; Possible Values:
; On = Enabled and buffer is limited. (Use with caution)
; Off = Disabled
; Integer = Enables the buffer and sets its maximum size in bytes.
; Note: This directive is hardcoded to Off for the CLI API
; Default Value: 4096
; Development Value: 4096
; Production Value: 4096
; http://php.net/output-buffering
output_buffering = 4096

; You can redirect all the out of your scripts to a function. For

; Setting any output handler turns on output buffering.

directive. Instead, explicitly set the output using ob_start().
