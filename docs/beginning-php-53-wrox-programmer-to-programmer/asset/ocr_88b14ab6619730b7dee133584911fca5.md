# Setting Up the MySQL root Password

Now that the MySQL database engine is running on your computer, it's time to configure the root user.

MySQL, like most networked systems, requires you to log in with a specific user account before doing anything else. It is a fairly obvious security measure, and limits access to the data by specifying permissions for each account. For example, one user may only have permission to view existing data, whereas another may have permission to add new data, and perhaps even change others' permissions.

root is the name traditionally given to a system user, who automatically has permission to modify and view all data and settings; a powerful position to be. When MySQL installs, it creates the root account automatically but doesn't set a password for it. This means that anyone can connect to your server as root! So your pristine MySQL server could be open to use and abuse by anyone with a MySQL client and a network connection to the server, and you need to do something about that.

The process of setting a root password can seem a bit long-winding, especially if you're unfamiliar with MySQL, but it's fairly straightforward, and you only have to do it once

To set a root password, follow these steps:

+   Bring up a shell prompt — On Ubuntu, choose Applications ⬞ All Programs ⬞ Accessories ⬞ Terminal. On Windows, choose Start -> double-click the icon inside Applications/Utilities folder.

+   Change to the correct folder — In the Terminal or Command prompt, use cd to change to the directory containing the MySQL command-line tool, mysql. With WampServer on Windows, this would be something like C:\wamp\bin\mysql\mysql5.0.51\bin. So you'd type:

```
cd \wamp\bin\mysql\mysql5.0.51\bin
```

and press Enter.

When using MAMP on Mac OS, assuming you installed MAMP your Applications folder, the correct directory should be /Applications/MAMP/library/bin. If you are using Ubuntu, you should be able to skip this step, because mysql is usually installed in the standard path /usr/bin.

+   3. Start the MySQL command-line tool — On Ubuntu and Windows, type

```
mysql -u root
```
