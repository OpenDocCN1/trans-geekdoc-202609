# Part III: Using PHP Practice

| Method | Description |
| --- | --- |
| setAutoFill ($fill, $body ) | This function tells HTML_Table to pre-populate newly created empty table cells with a string value. $fill is the string to insert into empty cells when they're created. The optional $body-argument works like its counterpart in addRow(). |
| setTo() | Returns the HTML markup to display the table. Call this method once you've created your table to retrieve the HTML for inserting into the Web page. |

You can find a complete list of HTML_Table methods at http://pear.php.net/manual/en/package.html-table-php.

To create a table, you first create a new HTML_Table object to store the table and other settings, then call various methods of object to add data cells, format the table, and so on. When you're done, call the object's toHtml() to retrieve the markup for displaying the table.

# Try It Out Displaying Fibonacci Numbers with HTML_Table

Chapter 4 featured a script that looped to display the first few numbers of the Fibonacci sequence. The numbers were displayed in an HTML table by outputting the HTML markup for the table directly.
