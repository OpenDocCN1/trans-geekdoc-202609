Lastly, the sendMessage() function deals with the actual email sending. It first constructs the
recipient string from the owner's first name, name and address, and sets the From: address
details to supply to the visitor in the outside world:

```
$recipient = OWNER_FIRST_NAME '' OWNER_LAST_NAME '' < OWNER_EMAIL_
ADDRESS "*">
$Sheaders = "From: " $values["firstName"] " " $values["lastName"] "
<" $values["emailAddress"] "*">
```

Then the function calls the built-in mail() function, in the recipient string, the supplied
message body and subject, and the additional header (that is, the From: address):

```
if ( mail($recipient, $values["subject"], $values["message"], $Sheaders ) )
```

If the message was sent successfully, an acknowledgment is displayed; otherwise an error message is
shown and the visitor is to try again.

This example shows how easy it is to construct form-to-emails in PHP, thanks to PHP's mail()
function. You can use the same techniques for creating other email functions, such as "tell a friend"
scripts and password reminder functions.
