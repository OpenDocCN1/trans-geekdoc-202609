# Chapter 16: PHP and the Outside World

| Date/Time String | Meaning |
| --- | --- |
| tomorrow 1:30pm | The day after the current date at 1:30 pm |
| Today | Midnight on the current date |
| Yesterday | Midnight on the day before the current date |
| last Thursday | Midnight on the Thursday before the current date |
| +2 days | The day after tomorrow at the current time of day |
| -1 year | One year ago at the current time of day |
| +3 weeks 4 days 2 hours | 3 weeks, 4 days, and 2 hours from now |
| 3 days | 3 days after the current date at the current time |
| 4 days ago | 4 days after the current date at the current time |
| 3 hours 15 minutes | The current time plus 3 hours 15 minutes |

As mktime(), strtotime() assumes by default that the string you pass represents a date time in the computer's time zone, and converts to UTC. However, you can specify a time in a different time zone by adding an offset from UTC, using a plus or minus sign followed by a four-digit number two digits. The first two digits represent the hours component of the offset, and the second two digits represent the minutes. For example:

```
$t = strptime("February 15th 2004, 9:30am +0000"); // GMT
$t = strptime("February 15th 2004, 9:30am +0100"); // 1 hour ahead of GMT
$t = strptime("February 15th 2004, 9:30am -0500"); // Indianapolis time
$t = strptime("February 15th 2004, 9:30am +1000"); // Sydney time (not DST)
$t = strptime("February 15th 2004, 9:30am +1100"); // Sydney time (with DST)
```

strtotime() calculates relative dates (as "tomorrow 1:30pm") based on the current date. If you want to calculate a relative date based on a different date, pass that date as a second argument to strptime(), in timestamp format:

```
$localTime = strptime("tomorrow 1:30pm", 0); // January 2nd 1970, 1:30:00 pm
```
