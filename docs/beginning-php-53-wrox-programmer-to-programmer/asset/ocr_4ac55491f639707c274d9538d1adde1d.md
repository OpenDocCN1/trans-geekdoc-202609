# Part III: Using PHP in Practice

The getTagName() method of the DOMDocument object returns a list of all elements that matched the tag name—in this case, "stockList". The list is returned as a NodeList object, which has just one element—item(0)—that is used to extract the item from a specified position in the list, with 0 pointing to the first item. You know that there's only one element called $stockList in the document, you retrieve the first element (index 0) and store it in the $stockList variable for future use.

The rest of the script behaves much the easier script for creating an XML document from scratch. A new item is created—along with its attribute and child nodes—and is appended to the end of the stockList element using $stockList->appendChild(). Finally, the resulting document is displayed in the browser.

# Removing Elements from a Document

Removing elements is even easier than adding them. The key method here is the removeChild method of the DOMNode class:

```
$node->removeChild($child);
```

removeChild($child) expects a DOMNode $child as an argument. It removes that node from the parent node, $node.

In this example, the stock_list.xml file is located in the "beetroot" item element identified (in the same way as stocklist element) and the resulting XML is displayed:

// Load the XML file
$doc = new DOMDocument();
$doc->preserveWhiteSpace = false;
$doc->load(".*/stock_list.xml");
$doc->formatOutput = true;

// Get the stockList root element
$stockListElements = $doc->getElementsByTagName("stockList");
$stockList = $stockListElements->item(0);

// Get the "beetroot" item element
