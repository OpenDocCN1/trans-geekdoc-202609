In this example, the variable values are hard-coded in the script. In a real-world application, you would receive these values from outside the script, such as via submitted values in the $_POST superglobal array.

Remember that, although using prepared statements and placeholders gives you some protection against SQL attacks, you should always check or filter user input before doing anything with it, such as storing it in a database. You can find out more about this and security-related issues in Chapter 20.

## Updating Records

As you saw in Chapter 12, you can alter the data within an existing table row by using SQL UPDATE statement:

```sql
mysql UPDATE fruit SET name = 'grapefruit', color = 'yellow' WHERE id = 2;

Query OK, 1 row affected (0.29 sec)
Rows matched: 1 Changed: 1 Warnings: 0

mysql SELECT * from fruit;
```

| id | name | color |
| :--- | :--- | :--- |
| 1 | banana | yellow |
| 2 | grapefruit | yellow |
| 3 | plum | purple |

3 rows in set (0.00 sec)

As inserting new records, updating records via your PHP script is a simple case of using PDO::query() if you are passing values in the UPDATE statement, or PDO::prepare() with placeholders if you are passing variable. For example, the following script changes the email address field in the "Derek Winter" record that was added in the following section:

```php
<?php
$dsn = "mysql:dbname=database";
$username = "root";
$password = "myapp";

try {
    $conn = new PDO($dsn, $username, $password);
    $conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ATTR_ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    echo "Connection failed: " . $e->getMessage();
}

$id = 8;
$newEmailAddress = "derek.winter@example.com";

$sql = "UPDATE members SET emailAddress = :emailAddress WHERE id = :id";

try {
    $stmt = $conn->prepare($sql);
    $stmt->bindValue(":id", $id, PDO::PARAM_INT);
    $stmt->bindValue(":emailAddress", $newEmailAddress, PDO::PARAM_STR);
    $stmt->execute();
} catch (PDOException $e) {
    echo "Query failed: " . $e->getMessage();
}

?>
```

## Deleting Records

Deleting rows via PHP is a similar process to updating. Chapter 12 showed you how to delete rows from a table using the SQL DELETE keyword:

```sql
mysql> DELETE FROM fruit WHERE id = 2;
Query OK, 1 row affected (0.02 sec)
```

Deleting rows using PHP, you pass a DELETE statement directly via PDO::query(), or create the statement using PDO::prepare() with placeholders, passing in values (the criteria for the WHERE clause) with PDOStatement::bindValue() and running the query with PDOStatement::execute().

The following script deletes the member record with the ID of 8 from the members table:

```php
<?php
$dsn = "mysql:dbname=mydatabase";
$username = "root";
$password = "myapp";

try {
  $conn = new PDO($dsn, $username, $password, array(PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION));
} catch (PDOException $e) {
  echo "Connection failed: " . $e->getMessage();
}

$id = 8;
$sql = "DELETE FROM members WHERE id = :id";

try {
  $stmt = $conn->prepare($sql);
  $stmt->bindValue(":id", $id, PDO::PARAM_INT);
  $stmt->execute();
} catch (PDOException $e) {
  echo "Query failed: " . $e->getMessage();
}

?>
```

Incidentally, rather than binding the value of a variable to a placeholder with PDOStatement::bindValue(), you can use PDOStatement::bindParam() to bind the variable itself. If you change the value of the variable after the call to bindParam(), the placeholder value is automatically updated to the new value (in other words, by reference rather than by value). This can be useful if you're not sure what value you're going to pass in the the time you prepare the statement. Find out more about bindParam() in the online PHP manual at http://www.php.net/manual/en/pdostatement.bindparam.php.

    if (in_array($fieldName, $missingFields)) {
        echo ' class="error";';
    }
}

function setChecked($obj, $fieldName, $fieldValue) {
    if ($obj->getValue($fieldName) == $fieldValue) {
        echo ' checked="checked";';
    }
}

function setSelected($obj, $fieldName, $fieldValue) {
