# Part II: Learning the Language

# How It Works

This script creates an interface, Sellable, that contains three method declarations:

```
public function addStock($numItems);
public function sellItem();
public function getStockLevel();
```

Next, two classes—Television and TennisBall—are created. These classes are unrelated and contain different properties and methods; for example, Television contains a private $_screenSize property to access it, whereas TennisBall contains a private $_color property with associated methods.

However, both classes implement the Sellable interface. This means they provide the code to implement the three methods—addStock(), sellItem(), and getStockLevel()—declared in Sellable. They do correctly. Notice, by the way, each class has a different way of recording its stock; Television records the stock level in a $_stockLevel, whereas TennisBall has a $_ball property. This doesn't matter at all; from the perspective of the outside world, the important thing is that the classes correctly implement the three methods in the Sellable interface.

Next, the script creates a Manager class to store and handle products for sale in the online store. This class contains a private $_productList to store different types of products; addProduct() method to add product to the product list, and a stockUp() method that iterates through the product list, adding 100 to the stock level of each product type.

stockUp() calls the addStock() method of add object to the stock; it knows that such a method must exist because it deals with the Sellable interface. Notice that addProduct() uses type hinting to ensure that all objects that it is passed implement the Sellable interface (you can use type hinting with interface names instead as class names):

```
public function addProduct( Sellable $product ) {
```

Finally, the script tests the interface and classes. It creates a Television object, $tv, and sets its screen to 42 inches. Similarly, it creates a TennisBall, $ball, and sets its color to yellow. The script creates a Manager object, $manager, and adds both the $tv and $ball products to the stock list using the addProduct() method. The products are added, $manager->stockUp() is called to fill the warehouse with 100 units of each item. It displays information about each product, calling functions specific to the Television and TennisBall classes (getScreenSize() and getColor(), respectively) as the getStockLevel() function declared by the Sellable interface.

The script then sells some by calling the sellItem() method of the $tv and $ball objects—again, remember that this method is required by the Sellable interface—and redisplays information about products, including their new stock levels.
