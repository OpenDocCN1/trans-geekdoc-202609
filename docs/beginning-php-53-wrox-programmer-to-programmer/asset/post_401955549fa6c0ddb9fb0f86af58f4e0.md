## Exercise 1 Solution

To write a function that calculates the number of weekdays in a given month, you can use the following approach:

1. Calculate the total number of days in the month.
2. Loop through each day and test whether it is a weekday. If so, increment the counter.
3. Return the counter value.

Here is a solution:

```php
<!DOCTYPE html PUBLIC "//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en">
<head>
<title>Number of weekdays in a month</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<h1>Number of weekdays in a month</h1>
<?php

function weekdaysInMonth($year, $month) {
$date = mktime(0, 0, 0, $month, 1, $year);
$daysInMonth = date("t", $date);
$weekdays = 0;

for ($d = 1; $d <= $daysInMonth; $d++) {
$date = mktime(0, 0, 0, $month, $d, $year);
$dayOfWeek = date("w", $date);
if ($dayOfWeek != 0 && $dayOfWeek != 6) $weekdays++;
}

return $weekdays;
}

$weekdays = weekdaysInMonth(1997, 3);
echo "<p>March 1997 contained $weekdays weekdays.</p>";
?>
</body>
</html>
```

The only trick to successfully complete this exercise is to remember that the top-left corner of an image is (0,0). This means you must remember to subtract 1 from the width and height of the image to get the rightmost and bottommost position, respectively. Here's the code to draw the black border:

```php
<?php
$myImage = imagecreatefromjpeg('hook.jpg');
$black = imagecolorallocate($myImage, 0, 0, 0);
$width = imagesx($myImage);
$height = imagesy($myImage);
imagerectangle($myImage, 0, 0, $width-1, $height-1, $black);
header('Content-type: image/jpeg');
imagejpeg($myImage);
imagedestroy($myImage);
?>
```

## Exercise 2 Solution

There are two obvious ways that you can graphically display disk space. The quickest and easiest way is to create a simple horizontal scale: a rectangular shape made up of two blocks of color, one representing the used space on the disk and the other representing free space. This gives you a quick overview of your disk usage.

It's always good practice to store the width and height of your images in variables. If you want to change the size of the image you can do so easily at the beginning of the script and any calculations you do with the width and height are automatically updated.

```php
$iWidth = 500;
$iHeight = 500;
```

Create the image and allocate black and white. Because white is the first color allocated, it will be the background color of the image. Black will be used to add a border to the image.

```php
$myImage = imagecreate($iWidth, $iHeight);
$white = imagecolorallocate($myImage, 255, 255, 255);
$black = imagecolorallocate($myImage, 0, 0, 0);
```

In this example, red and green are used to represent used space and free disk space, respectively. You can use any colors you like.

```php
$red = imagecolorallocate($myImage, 255, 0, 0);
$green = imagecolorallocate($myImage, 0, 255, 0);
```

Get the total amount of space on the disk and the amount of space that you have free. Both of these values are returned in bytes. The actual values are irrelevant — all you need them for is to get a proportion that you can draw the border.

```php
$diskTotal = disk_total_space();
$diskFree = disk_free_space();
```

Then draw a one-pixel black border around the outside of the image.

```php
imagereangle($myImage, 0, 0, $iWidth - 1, $iHeight - 1, $black);
```

The $threshold variable will be used to mark the position on the x-axis where you move from the used disk space to the free disk space in your diagram. Because used disk space is usually represented on the left side of such diagrams, you need to calculate that space — it is the disk space minus the free disk space. Divide by the total amount of disk space to get a number between 0 and 1, which you then multiply by the width of the image. Subtract 2 from the width of the image because you already used 2 pixels drawing the image border; add 1 to the overall threshold because pixels start at 0.

```php
$threshold = intval(($diskTotal - $diskFree) / $diskTotal) * ($iWidth-2) + 1;
```

For example, if your disk was 400 bytes and had 200 bytes, you divided 400 equals 0.5. If your image width was 500 pixels, you would multiply the 0.5 and 498 (width minus 2 for the border) to get 249. Then you'd add 1 to 250: the x position that is halfway across the image.

Fill with a red rectangle that extends right from the left-hand side to the threshold to represent the used disk space:

```php
imagefilledrectangle($myImage, 1, 1, $threshold, ($iHeight-2), $red);
```

And a green rectangle from the threshold onward for the free disk space:

```php
imagefilledrectangle($myImage, $threshold+1, 1, $iWidth-2, $iHeight-2, $green);
```

Finish the script in the usual manner.

```php
header("Content-type: image/png");
imagepng($myImage);
imagedestroy($myImage);
?>
```

The alternative solution to this exercise is to draw the space as a pie chart. The following code does exactly that.

Instead of working out threshold, you work out a number of degrees. The calculations work the same you don't multiply by the width of the image, you multiply by 360 — the number of degrees in a circle.

```php
<?php
$iWidth = 200;
$iHeight = 200;
$myImage = imagecreate($iWidth, $iHeight);
$white = imagecolorallocate($myImage, 255, 255, 255);
$red = imagecolorallocate($myImage, 255, 0, 0);
$green = imagecolorallocate($myImage, 0, 255, 0);
$diskTotal = disk_total_space();
$diskFree = disk_free_space();
$usedDegrees = intval(($diskTotal - $diskFree) / $diskTotal) * 360);
```

The imagefilledarc() function works in the same way as the imagearc() function, except that it takes an additional argument specifying how the arc should be filled. The PHP constant IMG_ARC_EDGED causes to connect the two end points of the arc to the center point of the arc and fill it with the color specified. You start at 0 degrees and draw the arc through the degree that you worked out for usedDegrees.

To draw the arc that represents the free space, simply start where the user left off at usedDegrees and draw the arc through 360 degrees, the end of the circle:

```php
imagefilledarc($myImage, $iWidth/2, $iHeight/2, $iWidth-2, $iHeight-2, $usedDegrees, 360, $green, IMG_ARC_EDGED);
```

And then finish as usual:

```php
header("Content-type: image/png");
imagepng($myImage);
imagedestroy($myImage);
?>
```
