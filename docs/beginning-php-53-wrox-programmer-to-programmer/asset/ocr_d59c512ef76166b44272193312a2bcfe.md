# # Part III: Using PHP Practice

| Assertion Method | Test Succeeds If... |
|---|---|
| assertNotEquals($a, $b ) | $a$ and $b$ are not equal |
| assertGreaterThan($a, $b ) | $b$ is greater than $a$ |
| assertGreaterOrEqual($a, $b ) | $b$ is greater than or equal to $a$ |
| assertLessThan($a, $b ) | $b$ is less than $a$ |
| assertLessOrEqual($a, $b ) | $b$ is less than or equal to $a$ |
| assertTrue($ x ) | $x$ evaluates to true |
| assertFalse($ x ) | $x$ evaluates to false |
| assertContains($a, $b ) | $a$ is an element of array $b |

For all assertions, you can include an explanatory message (usually as the last argument). If the test fails, this message will help to identify failed tests when working with large test suites. For example:

```
$this->assertEquals(0, $car->getSpeed(),Car's initial speed is not 0");
```

Once the Car and CarTest classes are defined, the script creates a new test suite (that is, bunch of tests), adds the three tests to the suite, and runs it:

```
$testSuite = new PHPUnit_Framework_TestSuite();
$testSuite->addTest(new CarTest("testInitialSpeedIsZero\));
$testSuite->addTest(new CarTest("testAccelerate\));
$testSuite->addTest(new CarTest("testMaxSpeed\));
```

```
PHPUnit_TestRunner::run($testSuite);
```

This example barely scratches the surface of PHPUnit. It is a powerful framework allowing you to do advanced things such as:

+   - Create self-contained environments specifically for testing database code
- Use simulated objects to test methods that are being called correctly within your application
- Generate code reports that test any lines of code in your application that are not tested

Creating unit tests with PHPUnit might seem like a lot of work, but it can save you time in the long run. For example, once you've written a test case, you can run it against your application each time you develop a new version of it to make sure the code still works as expected (this is known as regression testing). As ever, a good place to start learning PHPUnit is the documentation, available online at http://www.phpunit.de/wiki/Documentation.
