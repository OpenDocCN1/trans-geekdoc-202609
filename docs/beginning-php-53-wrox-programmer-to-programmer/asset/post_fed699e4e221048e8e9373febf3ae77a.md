You can also pass an array of target strings to preg_replace() to work on, much like using preg_grep(). If you do this, preg_replace() returns the array of strings with any matched text replaced by the replacement text:

```php
$text = array(
```

This code displays:

```
Array(

[2] => Screen protector: Only $5.99
```

preg_replace() has a couple of tricks up its sleeve. You can pass an array of regular expression strings to the function, and it will replace each expression in the turn with the replacement string:

```php
$text = "The wholesale price is $89.50. The product will be released on Jan 16, 2010.";

$patterns = array(
    "/\$d+\.\d(2)/",
    "/\w(3) \d(1,2), \d(4)/"
);

echo preg_replace($patterns, "[CENSORED]*", $text);
```

This script outputs the following:

The wholesale price is [CENSORED]. The product will be released on [CENSORED].

If you also pass an array of replacement strings, the matched text from each expression in the expressions is replaced by the corresponding string in replacements array:

```php
$text = "The wholesale price is $89.50. The product will be released on Jan 16, 2010.";

$patterns = array(
    "/\$d+\.\d(2)/",
    "/\w(3) \d(1,2), \d(4)/"
);

$replacements = array(
    "[PRICE CENSORED]",
    "[DATE CENSORED]"
);

echo preg_replace($patterns, $replacements, $text);
```

This script displays:

- The wholesale price is [PRICE CENSORED]. The product will be released on [DATE CENSORED].

If your replacements array contains fewer elements than your expressions array, matched text for any expression without a corresponding replacement is replaced with an empty string. For example:

```php
$text = "The wholesale price is $89.50. The product will be released on Jan 16, 2010.";

$patterns = array(

    "/\w(3)\d(1,2), \d(4)/"
);

$replacements = array(
    "[PRICE CENSORED]"
);

echo preg_replace($patterns, $replacements, $text);
```

displays:

preg_replace() supports two optional arguments. The first argument, an integer, lets you restrict how many times the pattern (or patterns) is replaced in the target string (or strings):

```php
// Displays "71%, 88%"
echo preg_replace("/\\d+%,|)/", "", "14, 59, 71%, 88%", 2);
```

This pattern replaces a figure (followed by optional commas and spaces) with an empty string. As a limit argument of 2 was supplied, only the first two matches are replaced.

The second argument is a variable to hold the number of replacements performed. (If you want to use this argument but not to limit the number of replacements, pass -1 for the first argument.) # Replacing Text using a Callback Function

preg_replace() is a powerful, flexible function, offering a multitude of ways to search and replace text. However, if you need more flexibility you can use preg_replace_callback(), which lets you create a callback function to handle the replacement side of the string.

```
preg_replace_callback() works in the same way as preg_replace(), and accepts all the same arguments, except that of passing a replacement string (or array of strings) as the second argument, you pass the name of your callback function as a string.
```

Your callback needs to accept an array of matches. The first element of the array (at index 0) contains the whole matched text, and additional elements contain any matched subpatterns. The string your function returns is used as the replacement text.

Here's an example. You have a large amount of copy that mentions various products in your online store, and you want to increase all your products by a dollar. You can't do arithmetic in regular expressions, but when you use preg_replace_callback() and a callback function to add numbers:

```php
$text = "High-quality mouse mat is just $3.99, while our keyboard covers sell for $4.99";

function addDollar($matches) {
    return "$" . ((float)$matches[1] + 1);
}

echo preg_replace_callback("/\$(\d+\.\d{2})/", "addDollar", $text);
```

The callback function returns the replacement text. This string is used by preg_replace_callback() to replace the matched text, is just $4.99, while our keyboard covers sell for $5.99.

# Altering Behavior with Pattern Modifiers

By placing a single letter, known as a pattern modifier, directly after the delimiter of an expression, you can change the way the expression behaves. Here's a list of the more useful modifiers:

| Modifier | Description |
|---|---|
| i | Causes the matching to be case insensitive: letters in the pattern match both uppercase and lowercase |
| m | Causes the target string to be treated as separate lines if it contains newlines. This means that ^ and $ characters in the expression match not only the beginning and end of the string, but also the beginning and end of each line |
| s | Normally, the (.) character in an expression matches any character except newlines. By adding this modifier you can make the dot match newlines too |
| x | This modifier changes whitespace characters in the pattern to be ignored, rather than treated as ignored. This allows you to split your expression over lines and indent it, much like regular code. You can also include comments in the expression by preceding them with a # symbol. If you explicitly want to match whitespace when using this, use \t (for a tab) or \s (for any space) |
| e | Only used by preg_replace(). This allows you to use PHP code in your replacement string. Any backreferences ($1, $2, and so on) in the replacement string are first replaced by their matched text. Then the string is used as PHP code |
| U | Inverts the "greediness" of quantifiers within the expression: any non-greedy quantifiers become greedy, and any greedy quantifiers become non-greedy

For example, you can make an expression case insensitive by adding i after the delimiter of the expression:

```php
$text = "Hello, world!";
echo preg_match(/hello/, $text); // Displays "0"
echo preg_match(/hello/i, $text); // Displays "1"
```

The following example shows how the m modifier works. The first expression matches the characters "world" followed by the end of the string. Because "world" is not at the end of the target string, the match fails. However, the second expression uses the m modifier. This causes the $ character to match the newline after "world":

```php
$text = "Hello,\nworld are you today?";
echo preg_match(/world/$, $text); // Displays "0"
echo preg_match(/world/$/m, $text); // Displays "1"
```

The m modifier is useful if you're working with a multiline string (like that read from a file or database query) that you want to treat as multiple lines of text rather than one long string.
