# Translating Characters with strtr()

A common requirement — especially with Web programming — is able to replace certain characters in a string with certain other characters. For example, you might want to make a string "URL friendly" by replacing spaces with (plus) and apostrophes with (hyphen) symbols.

This is where strtr() comes in. This function takes three arguments: the string to work on, a list of characters to translate, and a string containing the characters to use instead. The function returns a translated copy of the string. So you could write a simple script to make a "URL friendly" string as:

```
$myString = "Here-s+a+little+string"

// Displays "Here-s-little-string"
echo strtr($myString, "+", "-") . "br/>";
```

strtr() is especially useful if you need to translate a string from one character to another, because you can easily map hundreds of characters to their equivalents in the new character set by passing a couple of strings.

You can also use strtr() to replace strings with strings, rather than characters. To do this, pass just two arguments: the string to work on, and an array of key/value pairs, where each key is the string to search for and each corresponding value is the string to replace it with.
