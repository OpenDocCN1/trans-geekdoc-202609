## Arithmetic Operators

In PHP, the arithmetic operators (plus, minus, and so on) work as much as you would expect, enabling you to write expressions as though they were simple. For example, $c = $a + $b adds $a and $b$ assigns the result to $c. Here a list of PHP's arithmetic operators:

| Operator | Example Equation |
| --- | --- |
| + (addition) | 6 + 3 = 9 |
| - (subtraction) | 6 - 3 = 3 |
| * (multiplication) | 6 * 3 = 18 |
| / (division) | 6 / 3 = 2 |
| % (modulus) | 6 % 3 = 0 (the remainder of 6/3) |

## Assignment Operators

You've already seen how the basic assignment operator (=) can be used to assign a value to a variable:

```
$test_var = 8.23;
```

It's also worth noting that the preceding expression evaluates to the assignment: 8.23. This is because the assignment operator, like most operators in PHP, produces a value as well as carrying out the assignment operation. This means you can write code as:

```
$another_var = $test_var = 8.23;
```

means: "Assign the value 8.23 to $test_var, then assign the result of expression (8.23) to $another_var." So both $test_var and $another_var now contain the value 8.23.

The equals (=) can be combined with other operators to give you a combined assignment operator that makes it easier to write clean expressions. The combined assignment operators (such as +=, -=, and on) simply give you a shorthand method for performing arithmetic operations, so that you don't have to write out the variable name times. For example, you can write:

```
$first_number += $second_number;
```

rather than:

```
$first_number = $first_number + $second_number;
```

This also works for other kinds of operators. For example, the concatenation operator (described later in this chapter) can be combined with the equals sign (= .=), causing the value on the right side to be appended to the value of the left, like this:

```
$a = "Start a sentence ";
$b = "and finish it.";
$a .= $b; // a now contains "Start a sentence and finish it."
```

The main arithmetic, string, and bitwise operators support combination in this fashion; find out more at http://www.php.net/manual/en/language.operators.assignment.php.

## Bitwise Operators

PHP's bitwise operators let you work on the individual bits within integer variables. Consider the integer value 1234. For a 16-bit integer, this value is stored as two bytes: 4 (the most significant byte) and 210 (the least significant), 4 * 256 + 210 = 1234.

Here's how two bytes look as a string of bits:

```
00000100 10100100
```

A bit with value 1 is said to be set, whereas a bit with value 0 is unset (or not set).

PHP's bitwise operators let you manipulate these bits directly, as shown in the following table. Each example includes decimal values and their binary equivalents, so you can see how the bits are altered:

| Operator | Description | Example |
| --- | --- | --- |
| & (And) | Only bits set in both values are set in the result | 14 & 3 = 2<br>00001110 & 00000011 = 00000010 |
| | (Or) | Bits set in either value are set in the result | 14 | 3 = 15<br>00001110 | 00000011 = 00000111 |

| Operator | Description | Example |
| --- | --- | --- |
| ^ (Xor) | Bits set in either value (but not both) are set in the result | 14 ^ 3 = 13<br>00001110 | 00000011 = 00001101 |
| ~ (Not) | Bits that are not set in the result, and vice versa | ~14 = -15<br>-0000000000000000000000001110=<br>11111111 |
| << (Shift left) | Shifts bits to the left, filling the right with zeros | 14 << 2 = 56<br>00001110 << 00000010 = 00111000 |
| >> (Shift right) | Shifts bits to the right, filling the left with zeros | 14 >> 2 = 3<br>00001110 >> 00000010 = 00000011 |

## Comparison Operators

As you might imagine from the name, comparison operators are used to compare two values. They return a boolean value (true or false). Here's a list of the comparison operators:

| Operator | Description |
| --- | --- |
| == (equal) | True if two operands are equal |
| != (not equal) | True if two operands are not equal |
| === (identical) | True if two operands are equal and of the same type |
| !== (not identical) | True if two operands are not equal or not the same type |
| < (less than) | True if the left operand is less than the right |
| > (greater than) | True if the left operand is greater than the right |
| <= (less than or equal) | True if the left operand is less than or equal to the right |
| >= (greater than or equal) | True if the left operand is greater than or equal to the right |

The following examples show comparison operators in action:

```
$x = 23;
```

```
echo ($x < 24) . "br />"; // Displays 1 (true)
echo ($x < "24") . "br />"; // Displays 1 (true)
// PHP converts the string to the integer
echo ($x == 23) . "br />"; // Displays 1 (true)
echo ($x === 23) . "br />"; // Displays 1 (true)
echo ($x != "23") . "br />"; // Displays 1 (false)
// $x and '23' are not the same data type
echo ($x > 23) . "br />"; // Displays 1 (true)
echo ($x > 24) . "br />"; // Displays 1 (false)
```

As you can see, comparison operators are commonly used to compare two numbers (or strings) converted to numbers.

## Incrementing/Decrementing Operators

Sometimes it's useful to add or subtract a value (one) over again. This situation occurs frequently—for example, creating loops—that special operators are used to perform this task: the increment and decrement operators. They are written as two plus or two minus signs, respectively, prefixing or suffixing a variable name, like so:

```
++x; // Adds one to $x and returns the result
$x++; // Returns $x and adds one to it
--x; // Subtracts one from $x and then returns the result
$x--; // Returns $x and then subtracts one from it
```
