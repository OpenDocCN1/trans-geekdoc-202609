# Changing Nodes and Attributes

Say there's a beetroot, and you want to change the unit price of beetroot from $1.39 to $0.79. How would you go about this?

As you have already seen, the unitPrice elements are represented as DOMElement objects in the DOM, and their text nodes are represented as child DOMText objects. The DOMText class has various methods allow you to manipulate the node's content, including appendData() to add to the end of the existing string, deleteData() to remove one or more characters from the string, insertData() to add text at a given point in the string, replaceData() to replace text at a given point, and substring() to extract a substring from the text.

In this case you use replaceData() to replace the 1.39 value with 0.79. Here's a script that does exactly that. At the same time, change the "beetroot" item's type attribute from vegetable to rootBy using the setAttribute() method of the DOMElement object:
