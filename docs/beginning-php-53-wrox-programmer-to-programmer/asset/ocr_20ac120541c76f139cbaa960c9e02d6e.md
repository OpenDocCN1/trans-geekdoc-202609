# Reading and Writing Session Data

Working with session data in PHP is also simple. You store all your session data as keys and values in the $_SESSION superglobal array. So you store the user's first name using:

```
$_SESSION["firstName"] = "John";
```

You could display the user's first name — whether in the same page request or during a later request — as follows:

```
echo (\$_SESSION["firstName"]);
```

You can store any type of data in sessions, including arrays and objects:

```
$userDetails = array("firstName" => "John", "lastName" => "Smith", "age" => 34,
);
$_SESSION["userDetails"] = $userDetails;
```

However, if storing objects make sure you include your class definitions (or class definition files) before trying to retrieve the objects from the $_SESSION array, that the PHP engine can correctly identify the objects when they're retrieved:

```
session_start();
```

```
class WebUser {
    public $firstName;
    public $lastName;
}
```

```
if ( isset(\$_SESSION["user"])) {
    // Make sure the WebUser class is defined by this point
    print_r(\$_SESSION["user"]);
} else {
    echo "Creating user...";
    $user = new WebUser();
    $user->firstName = "John";
    $user->lastName = "Smith";
    $_SESSION["user"] = $user;
}
```
