# Chapter 20: Writing High-Quality Code

How It Works
Functionally, this application is pretty much the same as registration.php from Chapter 9. The main difference is that the presentation code has been separated from the application code and stored in separate template files in the templates folder.

Take a look at the registration.php script. Unlike the Chapter 9 script, the displayForm() and displayThanks() functions no longer contain embedded HTML. Instead, use require() to include the relevant page templates from the templates folder:

```
function displayForm($mingFields) {
  $results = array (
    "pageTitle" => "Membership Form",
    "scriptUrl" => "registration.php",
    "missingFields" => $mingFields,
    "firstNameAttr" => validateField('firstName', $mingFields),
    "firstNameValue" => setValue('firstName'),
    "lastNameAttr" => validateField('lastName', $mingFields),
    "lastNameValue" => setValue('lastName'),
    "gender" => validateField('gender', $mingFields),
    "merChecked" => setChecked('gender', "M"),
    "genderFChecked" => setChecked('gender', "F"),
    "favoriteWidgetOptions" => array (
      "superWidget" => setSelected('favoriteWidget', 'superWidget'),
      "megaWidget" => setSelected('favoriteWidget', 'megaWidget'),
      "windowWidget" => setSelected('favoriteWidget', 'windowWidget')
    ),
    "newsletterChecked" => setChecked('newsletter', 'yes'),
    "commentsValue" => setValue('comments')
  );

require("templates/registration_form.php");
```

```
function displayThanks() {
```

Each function creates a $results array containing information to display on the page. The page template then uses this array to display between the application and presentation code. For example, registration_form.php uses the firstNameAttr element to insert any attributes (such as 'class="error"') into the firstName label's tag, and the firstNameValue element to display any properly typed value in the firstName field:

```
<label for="firstName">?php echo $results["firstNameAttr"] ?? ??></label>
First name *
<input type="text" name="firstName" id="firstName" value="<?php echo $results["firstNameValue"] ?? "" />
```
