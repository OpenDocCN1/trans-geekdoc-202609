# Part III: Using PHP Practice

By comparing the nodeType property against constants, you can determine the type of the node, and exactly what the traverseDocument() function does. If it's an element node, it displays the name using the tagName property of the DOMElement object. If the element contains attributes (using the hasAttributes() method), loops through the array of DOMAttr attribute (stored in the elements property), displaying each attribute's name and value properties:

```
case XML_ELEMENT_NODE:
echo "Found element: \$node->tagName";

if ($node->hasAttributes() ) {
    echo with "attributes";
    foreach ($node->attributes as $attribute) {
        echo "$attribute->name=\$attribute->value\";
    }
}

echo "\n";
break;
```

If the node is a text node, the function tests to see if the node contains anything other than whitespace (this avoiding any formatting whitespace that might be in the XML document). If the function displays the node's text content, which is stored in the DOMText object's wholeText property:

```
case XML_TEXT_NODE:
if (trim($node->wholeText)) {
    echo "Found text node: \$node->wholeText\";
}
break;
```

If the node is a character data node, again, the function displays the character data provided it doesn't just contain whitespace. The data is stored in the DOMCharacterData's data property. Also, because character data can contain markup characters as "<" and "&", the function calls htmlspecialchars() to encode any markup characters as required:

```
case XML_CDATA_SECTION_NODE:
if (trim($node->data)) {
    echo "Found character data node: \$htmlspecialchars($node->data) \n";
}
break;
```

Finally, the function tests to see if it's dealing with any children, using the hasChildNodes() method of the DOMElement object. If it does, the function loops through each child—stored in the childNodes property of the DOMNode object—and calls itself for each child, continuing the recursion process:

```
if ($node->hasChildNodes()) {
    foreach ($node->childNodes as $child) {
        traverseDocument($child);
    }
}
```
