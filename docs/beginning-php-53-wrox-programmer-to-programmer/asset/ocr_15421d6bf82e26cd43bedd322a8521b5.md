# Chapter 16: PHP and the Outside World

You can send this email message much the same way as a plain text email; the only difference is that you need to include two additional headers in the message :

```
MIME-Version: 1.0
Content-Type: text/html; charset=utf-8
```

MIME-Version: tells the mail reader to expect a message in MIME format (as well as the content of MIME being used), and Content-Type: specifies the type of content to expect. In this case, text/html charset=utf-8 tells the mail reader to expect an HTML encoded in the UTF-8 (Unicode) character set

To send the HTML email just you could write:

```
$headers = "From: The Widget Company <widgets@example.com>\r\n"
$headers = "MIME-Version: 1.0\r\n"
$headers = "Content-Type: text/html; charset=utf-8\r\n"
$recipient = "John Smith <johnsmith@example.com>"
$subject = "Thank you for contacting us;"
mail($recipient, $subject, $message, $headers);
```

If you want to send more than one component in the message — for example, an alternate plain text version of the message, or several images — you need to create a multipart MIME message. Multipart content types are outside the scope of this book and are more complex than sending a single-part email message. However, the Mail_MIME PEAR package makes this process very easy. For more information see http://pear.php.net/package/Mail_Mime.
