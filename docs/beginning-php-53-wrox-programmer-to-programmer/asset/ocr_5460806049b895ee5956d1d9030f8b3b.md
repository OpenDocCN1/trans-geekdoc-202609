Notice that in both cases the MySQL tool reports that there is only one row in the result set. Although the first example selects seven rows from the members table, the count () aggregate function takes those seven rows and returns a single value (7). The final result set contains only one row. Similarly, the second count () query reduces the three-row result to a value of 3.

The remaining aggregate functions work just as you'd expect. For example, this query returns the total number of visits to the club web site across all members:

```
mysql> SELECT SUM( numVisits ) FROM accessLog;
+-----------------------+
| SUM(numVisits) |
+-----------------------+
|          9      |
+-----------------------+
1 row in set (0.00 sec)
```

You can use functions like min() and max() on dates. This query returns the date that the first member joined the club:

```
mysql> SELECT MIN( joinDate ) FROM members;
+----------------------+
| MIN(joinDate)|
+----------------------+
| 2006-03-03 |
+----------------------+
1 row in set (0.02 sec)
```
