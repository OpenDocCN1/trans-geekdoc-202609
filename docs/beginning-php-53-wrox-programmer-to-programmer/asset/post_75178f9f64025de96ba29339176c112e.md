# Sending HTML Emails

Your message body doesn't have to be plain text; you can send an HTML web page as well and more attractively. This allows you to format your message however you need but bear in mind that not all email applications display HTML emails in the same way (or at all).

To send an HTML email body, you may need to do two things:

1. Create the HTML markup for your message body.
2. Send the message using the mail() function, passing in additional MIME headers to indicate that the message body is in HTML format.

MIME stands for Multipurpose Mail Extensions, and it's an extension to the standard email protocols that follow, among other things, messages to contain multiple text and non-text attachments. MIME is also used in other protocols; in fact you've already seen the Content-Type: MIME header in the "Working with HTTP" section earlier in the chapter.

First, create your HTML message body. At the time of writing, most email applications only understand a subset of the HTML standard, so it's best to make your markup as simple as possible. CSS support is particularly bad, so you may need to eschew CSS in favor of table-based layouts.

You can find out about creating HTML emails, as well as download free email templates, at http://www.mailchimp.com/resources/templates/. Another useful site is the Email Standards Project (http://www.email-standards.org/) that tracks the state of Web standards support across various email applications.

Here's a simple HTML email message:

```php
$message = <<END_HTML
<html>
<body>
<h1 style="color: #AA3333;">Thank You</h1>
<p>Thank you for contacting us <a href="http://www.example.com/">The Widget Company</a></a>. We'll be in touch shortly.</p>
</body>
</html>
END_HTML;
```

# Chapter 16: PHP and the Outside World

You can send this email message much the same way as a plain text email; the only difference is that you need to include two additional headers in the message:

```
MIME-Version: 1.0
Content-Type: text/html; charset=utf-8
```

MIME-Version: tells the mail reader to expect a message in MIME format (as well as the content of MIME being used), and Content-Type: specifies the type of content. In this case, text/html charset=utf-8 tells the mail reader to expect HTML encoded in UTF-8 (Unicode) character set.

To send the HTML email you could write:

```php
$headers = "From: The Widget Company <widgets@example.com>\n";
$headers .= "MIME-Version: 1.0\n";
$headers .= "Content-Type: text/html; charset=utf-8\n";
$recipient = "John Smith <john@example.com>";
mail($recipient, $subject, $message, $headers);
```

If you want to send more than one component in the message — for example, an alternate text version of the message, or several images — you need to create a multipart message. Multipart types are outside the scope of this book and are more complex than sending a single-part email. However, Mail PEAR makes this process easy. For more information see http://pear.net/package/Mime.

# Try Create a Contact Form

A common requirement for a Web site is a "contact us" form that allows visitors to contact the owner. In this example you create a form, along with PHP code to process the form and email the results to the owner. Save the following as contact.php in your document root:

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 1.0 Strict//EN" "http://www.w3.org/TR/HTML41/strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en">
<head>
    <title>Contact Us</title>
    <link rel="stylesheet" type="text/css" href="style.css" />
    <style>
        error { background: #d33; color: white; padding: 0.2em; margin: 0.2em 0; }
        fieldset { border: none; padding: 0; margin: 0; }
        input, select, textarea { float: none; margin: 1em 0 0; }
        .element { float: right; width: 70%; }
        .element label { display: inline; float: none; }
        select { margin-right: 0.5em; }
        span.required { display: none; }
    </style>
</head>
<body>
<?php
require_once("HTML/QuickForm.php");
require_once("HTML/QuickForm/Renderer_Tableless.php");
define("OWNER_FIRST_NAME", "Michael");
define("OWNER_LAST_NAME", "Brown");
define("OWNER_EMAIL_ADDRESS", "michael@example.com");
$form = new HTML_QuickForm("form", "get", "contact.php", array(
    "style" => "width:30cm;"
));
$form->removeAttribute("name");
$form->setRequired("firstName");
$form->addElement("text", "firstName", "First Name");
$form->addElement("text", "lastName", "Last Name");
$form->addElement("text", "emailAddress", "Email address");
$form->addElement("text", "subject", "Message subject");
$form->addElement("textarea", "message", "Message", array("rows" => 10));
$form->addElement("submit", "sendButton", "Send Message");
$form->addRule("firstName", "Please enter your name", "required");
$form->addRule("firstName", "The First name can contain only letters, digits, spaces, apostrophes, and hyphens", "regex" => "/^[a-zA-Z0-9 '-]+/");
$form->addRule("lastName", "Please enter your name", "required");
$form->addRule("lastName", "The Last name can contain only letters, digits, spaces, apostrophes, and hyphens", "regex" => "/^[a-zA-Z0-9 '--]+/");
$form->addRule("emailAddress", "Please enter an email address", "required");
$form->addRule("emailAddress", "Please enter a valid email address", "required");
$form->addRule("subject", "Please enter a message", "required");
$form->addRule("subject", "Your subject can contain only letters, digits, spaces, commas, periods, and hyphens", "regex" => "/^[a-zA-Z0-9,.]+/");
$form->addRule("message", "Please enter your message", "required");

if ($form->isSubmitted() && $form->validate()) {
    $form->process("sendMessage");
} else {
    echo "<p>Please fill in all the fields below, then click Send Message to us at an email.</p>";
    $renderer = new HTML_QuickForm_Renderer_Tableless();
    $form->accept($renderer);
    echo $renderer->toHTML();
}

function sendMessage($values) {
    $recipient = OWNER_FIRST_NAME . " " . OWNER_LAST_NAME . " <" .
    OWNER_EMAIL_ADDRESS . ">";
    $headers = array("From" => " " . $values["firstName"] . " " . $values["lastName"] .
    " <" . $values["emailAddress"] . ">");
    if (mail($recipient, $values["subject"], $values["message"], $headers)) {
        return true;
    }
}
?>
<h1>Contact Us</h1>
</body>
</html>
```
