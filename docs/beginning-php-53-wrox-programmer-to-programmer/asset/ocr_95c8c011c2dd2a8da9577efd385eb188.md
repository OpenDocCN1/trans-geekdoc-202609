# Chapter 13: Retrieving Data from MySQL with PHP

You might be wondering what the point of LIMIT is, because you can just loop through the result in PHP to extract the rows you're interested in. The main reason to use LIMIT is that it reduces the amount of data that has to flow between MySQL and your PHP script.

Imagine that you want to retrieve the first 100 rows of a million-row table of users. If you use LIMIT 100, only 100 rows are sent to your PHP script. A LIMIT clause (and your query also contains WHERE clause), all 1,000,000 rows of data will be sent to your PHP script, where they will need to be stored as PDOStatement object you loop through to extract the first 100. Storing the details of a million users in your script will quickly bring the script to a halt, due to the large amount of memory required to do so.

LIMIT is particularly useful when you're building a paging search function in your PHP application. For example, if the user requests the second page of search results, and you display 10 results per page, you can use SELECT ... LIMIT 10 to retrieve the second page of results. You are building a system using LIMIT in the "Creating a Member Viewer" section later in the chapter.

# Sorting Results

One of the powerful features that really separate databases from text files is the speed and ease with which you can retrieve data in any order. Imagine that you have a text file that stores the first and last names of a book club members, ordered by first name. If you wanted to retrieve a list of all the members ordered by last name, you would need to rearrange an awful lot of rows in your text file.

With SQL retrieving records in a different order is as simple as using the keywords ORDER BY to your query, followed by the column you want to sort by:

```
mysql SELECT username, firstName, lastName FROM members ORDER BY firstName;
+-----------+------------+----------+
| username  | firstName | lastName |
+-----------+------------+----------+
| jamesbill | Bill       | Swan     |
| janesfield| Jane       | Field    |
| jojo       | Jo         | Scrivener|
| sparky     | John       | Sparks   |
| marty      | Mary       | Pareene  |
| mary       | Mary       | Newton   |
| nickb      | Nick       | Bakery |
+-----------+------------+----------+
7 rows in set (0.00 sec)
```
