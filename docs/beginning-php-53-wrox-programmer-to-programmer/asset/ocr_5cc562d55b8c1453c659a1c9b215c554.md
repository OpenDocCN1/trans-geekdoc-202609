# Chapter 10: Preserving State With Query Strings

The script starts by calling session_start() to create a new session, or pick up an existing session if one exists for this user. The script defines a Product class to hold the products in the store, and a global $products array containing three Product objects, keyed by the numeric IDs of products. (In a real-world scenario you'd probably store the products in a database).

The code then initializes the user's cart to an empty array if it doesn't exist. The array is stored as an element, cart, inside the $_SESSION superglobal. As the $products array, this array will hold the products by the user, keyed by product ID:

```
if (!isset($_SESSION['cart']) && $_GET['cart'] = array());
```

The next few lines of code handle the main decision logic of the script, addItem() if the user chose to add an item to his cart, removeItem() if the user opted to remove a product, or displayCart() if neither option was chosen by the user:

```
if (isset($_GET['action']) && $_GET['action'] == "addItem") {
    addItem();
} else if (isset($_GET['action']) && $_GET['action'] == "removeItem") {
    removeItem();
} else {
    displayCart();
}
```

The addItem() function looks for a productID field in the query string and, if valid, adds the corresponding Product to the user's cart by inserting an element into the $_SESSION['cart'] array, keyed by product ID. It then sends a Location: header to reload the shopping cart:

```
function addItem() {
    global $products;
    if (isset($_GET["productID"]) && $_GET["productID"] >= 1 && _
GET["productID"] <= 3) {
        $productID = (int)$_GET["productID"];
    }
    if (isset($_SESSION['cart'][$productID])) {
        $_SESSION['cart'][$productID] = $products[$productID];
    }
}

session_write_close();
header("Location: shopping_cart.php");
}
```

Note that the function calls the PHP function session_write_close() just before sending the Location: header. This forces the data in the $_SESSION array to be written to the session file on the server's hard disk. Although PHP usually does this anyway when redirecting or reloading the browser to ensure that it's a good idea to call session_write_close() before redirecting to ensure that the $_SESSION data is written to and available for the next browser request.
