# Appendix B: Configuring PHP

Although .user_ini is the default filename for per-directory configuration files, you can choose a different name using the user_ini.filename directive in php.ini. See the "php.ini Options" section later in this appendix.

+   - From within script files using ini_set(): This makes your work more portable because the settings are stored in the application's script files, rather than in server-side configuration files.

```
ini_set("display_errors", 1 )
```

Whereas all directives can be changed in a php.ini file, only some can be changed in a .htaccess file or using ini_set(). To find out where a directive can be changed, see the Changeable column in the table at http://www.php.net/manual/en/ini_list.php.

The php.ini file contains all the directives in one place, it's worth browsing through it to see what sort of configuration changes you can make. This appendix guides you through each of the sections in the php.ini file.

You can find all your current configuration settings by calling phpinfo() from a PHP script and viewing the output.

Two versions of the php.ini are delivered with the current distribution of PHP: php.ini-development and php.ini-production. The php.ini-development file is suitable for a development environment, whereas the php.ini-production file is suitable for production (that is, a live Web site).

This appendix lists and describes all the contents of the php.ini-development file supplied with PHP version 5.3.0, which is likely to be very close to the one you have installed.

All of the settings in php.ini-development are the built-in default settings. In other words, if the PHP engine can't find any configuration files, it will use the same settings that are used in php.ini-development.

# # About PHP

The first section of the php.ini-development file describes the purpose of php.ini files and explains how the PHP engine locates a php.ini file to use. It also describes the basic syntax of directives in the, which is essentially:

```
directive_name = directive_value
```

Some directives can be constructed using the bitwise operators OR (|), AND (&), and NOT (~). Flags can be turned using any of the values 1, On, True, or Yes (and off with 0, Off, False, or no). Comment lines begin with a semicolon (;

