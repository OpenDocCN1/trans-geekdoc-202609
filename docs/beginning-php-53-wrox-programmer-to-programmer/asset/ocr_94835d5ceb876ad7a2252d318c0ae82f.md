```
foreach ($logEntries as $logEntry) {
  $rowCount++;
  <tr><?php if ($rowCount % 2 == 0) echo 'class=alt*'; ?></td>

  <td><?php echo $logEntry->getValueEncoded("numVisits") ?></td></td>

  </tr>
<?php
}
?>
</table>

<div style="width:30em; margin-top: 20px; text-align: center;">
  <a href="javascript:history.go(-1)">Back</a>
</div>

<?php
displayPageFooter();
?>
```

This script expects to be passed a member query parameter specifying the member to be displayed. This is passed to Member::getMember() to retrieve the record as a Member object. If nothing is returned from the call to getMember(), the member could not be found in the members table, an error message is displayed and the script exits.

Assuming the member was found and retrieved, the script calls LogEntry::logEntries(), again passing the member ID, in order to retrieve the rows in the accessLog table associated with this member (if any).

Next, the script displays all of the members inside an HTML definition list (dl) element. Mostly this is a simple case of using Member::getValueEncoded() for each field, passing in the name of the field to retrieve, and displaying the returned value. For the special cases of gender and favorite genre, the getGenderString() and getFavoriteGenre() methods are called to display the field values in a more human-friendly format.

After the member comes the access entries. They are displayed in a similar way to the members in view_members.php script. For each entry, the page URL, number of visits, and access date are displayed in a table row. Finally, at the end of the page, a JavaScript link is created to allow the user to go to the member list page.
