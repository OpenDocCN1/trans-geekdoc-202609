# Exercise 2 Solution

To extend the Calculator class to constructor to allow the CalcAdvanced child class, use the extend keyword. You then need to override Calculator's constructor to use the special __call() method to create virtual "methods" pow(), sqrt(), and exp() that simply call their respective built-in math functions, use the clever_string.php example earlier in the chapter.

The following solution creates a static associative array of function names. The keys of the array are the function names, and the values are the number of arguments of each function. This allows the __call() method to pass the correct number of arguments to the appropriate built-in math function. Notice that the $_val1 and $_val2 of the original Calculator class have changed from private to protected in order to allow the subclass to access them:

<?php
class Calculator {
  protected $_val1, $_val2;

  public function __construct($val1, $val2) {
    $this->$_val1 = $val1;
    $this->$_val2 = $val2;
  }

  public function add() {
    return $this->$_val1 + $this->$_val2;
  }
}
