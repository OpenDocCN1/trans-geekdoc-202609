As you can see, you use two keys within sets of square brackets. The first key is the index of an element in the top-level array, and the second key is the index of an element in the nested array. # Looping Through Multidimensional Arrays

You know how to use foreach to loop through one-dimensional arrays, but how do you loop through multidimensional arrays? Well, because multidimensional arrays are basically nested inside others, you can loop through them using nested loops!
