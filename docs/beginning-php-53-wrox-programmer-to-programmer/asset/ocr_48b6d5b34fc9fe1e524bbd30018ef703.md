# Web Forms the Easy Way with

# HTML_QuickForm

Just as HTML_Table allows you to create HTML tables programmatically — thereby making your code clean and flexible — the HTML_QuickForm package provides a class for creating Web forms without needing to include a single line of HTML in your scripts. What's more, HTML_QuickForm can process the forms it creates, relieving you of the burden of writing (and testing) your validation, filtering, and error-reporting code.

In the following sections you take a look at the functionality in the HTML_QuickForm package, and then you create a membership form script using the power of HTML_QuickForm.

# Installing HTML_QuickForm

Installation of HTML_QuickForm is much as you'd expect. On Ubuntu, for example, just run pear install --alldeps HTML_QuickForm:


# Working with HTML_QuickForm

To use HTML_QuickForm, first create a new HTML_QuickForm object, and then call various methods to add elements — such as fields and labels — to the form. You can also add validation rules to make sure that the data entered for each field is correct, and use methods to remove unacceptable data from each field. You can then call various methods to validate the form, process the form, or display the form in the page (including any error messages to display to the user).
