# Returning References from Your Own Functions

As well as passing variables by functions, you can also get functions to return references, rather than values. To do this, when you return a variable with an ampersand before the function name in your function definition. Then, when you pass a reference to that variable back to the calling code, rather than the variable's value:

```
function &Func() {
    // (do stuff)
    return $var; // Returns a reference to $var
}
```

Here's an example that shows return-by-reference in action:

```
$number = 5;

function &getMyNumber() {
    global $number;
    return $number;
}

$numberRef = &getMyNumber();
echo "$number = $numberRef<br/>"; // Displays "6"
echo "$numberRef = $numberRef<br/>"; // Displays "6"
```

Here's how it works. First, a global variable, $number, is created and given the value 5. Next, a function, getMyNumber(), is defined. This function returns global $number. Because getMyNumber() has an ampersand before its name, then returns a reference to $number, rather than the value that $number holds.

Next, the script calls getMyNumber(). The value of getMyNumber() — that is, the reference to $number — is assigned to a new variable, $numberRef. Notice the ampersand after the equals sign; this ensures that $numberRef takes the reference returned by getMyNumber(), rather than taking the value that the reference points to.

At this point, $numberRef and $number both point to the same contents. To prove this, the code increments $numberRef, then outputs the values of both $number and $numberRef. Notice that they both hold the same value — 6 — because they point to the same piece of data.

Return-by-reference is used quite often in languages like C++, because it's the easiest way to return complex data structures such as arrays and objects. However, PHP lets you return pretty anything with its return statement, and automatically returns objects by reference anyway (as you will see in the next chapter), you probably won't ever use return-by-reference that much in PHP.
