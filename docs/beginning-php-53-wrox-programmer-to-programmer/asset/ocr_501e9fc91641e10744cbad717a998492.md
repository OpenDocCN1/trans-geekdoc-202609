# Replacing Text using a Callback Function

preg_replace() is a powerful, flexible function, offering a multitude of ways to search and replace text. However, if you need more flexibility you can use preg_replace_callback(), which lets you create a callback function to handle the replacement side of the string.

```
preg_replace_callback() works in the same way as preg_replace(), and accepts all the same arguments, except that of passing a replacement string (or array of strings) as the second argument, you pass the name of your callback function as a string.
```

Your callback needs to accept an array of matches. The first element of the array (at index 0) contains the whole matched text, and additional elements contain any matched subpatterns. The string your function returns is used as the replacement text.

Here's an example. You have a large amount of copy that mentions various products in your online store, and you want to increase all your products by a dollar. You can't do arithmetic in regular expressions, but when you use preg_replace_callback() and a callback function to add numbers:

```
$text = "High-quality mouse mat is just $3.99,
while our keyboard covers sell for $4.99 and our
screen protectors for only $5.99";

function addDollar($matches) {
    return "$" . ($matches[1] + 1);
}

echo preg_replace_callback("/\\$(\d+\\\.\d(2))/", "addDollar", $text);
```

The addDollar() callback function takes the second element in the matches array, which contains the matched text from the subpattern in the regular expression (that is, the price without the dollar symbol), and adds one to it. It returns new value, preceded by a dollar symbol. This string is then used by preg_replace_callback() to replace the matched text, producing the following result:

> Our high-quality mouse mat is just $4.99, while our keyboard covers sell for $5.99 and our screen protectors for only $6.99.
