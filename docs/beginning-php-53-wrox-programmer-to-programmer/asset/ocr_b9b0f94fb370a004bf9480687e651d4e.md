# Generating Web Forms with PHP

So far, the forms you've created been embedded in static HTML pages. However, because PHP scripts can create and output HTML, it's perfectly possible to combine both the form and the form handler in a single PHP file. This gives you a couple of advantages: if the users haven't filled in the form correctly, you can redisplay them so they can correct the errors. Second, because the form is created within a PHP script, you can dynamically set various parts of the form at the time it runs, adding a lot of power and flexibility to your forms.

As with any HTML markup, you can use two approaches to generate a form within PHP: you can use echo or print statements to output the markup for the form, or you can separate the PHP code from the markup using `<?php ?> tags. You can also use a mixture of the two techniques within the same script.
