+   A list box — This works like a pull-down menu, except that it displays several options at once. To turn a pull-down menu into a list box, change the size attribute from 1 to the number of options to display:

```
<label for="listBox">A list box</label>
<select name="listBox" id="listBox" size="3">
<option value="option1">Option 1</option>
<option value="option2">Option 2</option>
<option value="option3">Option 3</option>
</select>
```

+   A multi-select list — This works like a list box, but it also allows the user to select items by holding down Ctrl (on Windows and Linux browsers) or Command (on Mac browsers). To turn a normal list into a multi-select box, add the attribute multiple (with a value of "multiple") to the select element. If the user selects more than one option, all selected values are sent to the server (you) can handle multiple field values in the chapter:

```
<label for="multiListBox">A multi-select list box</label>
<select name="multiListBox" id="multiListBox" size="3" multiple="multiple">
<option value="option1">Option 1</option>
<option value="option2">Option 2</option>
<option value="option3">Option 3</option>
</select>
```

You can preset an option in any type of element by adding the attribute selected="selected" to the <option> tag — for example: <option value="option1" selected="selected">.

A text area — This is similar to a text field, but it allows the user to enter multiple lines of text. Unlike other controls, you specify an initial value (if any) by placing the text between the <textarea> tags, rather than in an attribute. A textarea element must include attributes for the height of the control in rows (rows) and the width of the columns:

```
<label for="textareaField">A text area field</label>
<textarea name="textareaField" id="textareaField" rows="4" cols="50"></textarea>
```
