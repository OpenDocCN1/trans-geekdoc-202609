### Exercise 1 Solution

In order to extract the total number of page views made by male and female visitors, you need to join the members table with the accessLog table. You can then use the `sum()` function to total the numVisits count, and group the results by a GROUP BY clause. Using table and column aliases helps to make the query and result set readable:

```mysql
mysql> SELECT m.gender, sum(al.numVisits) AS totalPageView FROM members m, accessLog al WHERE m.id = al.memberId GROUP BY m.gender;

+--------+----------------+
| m      | 6 |

2 rows in set (0.00 sec)
```

### Exercise 2 Solution

To allow the `getMembers()` method to filter by interest, you only have to change a few lines of code. First, specify an optional parameter, `$interest`, with a default value (such as an empty string). Within the method, check if a value was supplied for `$interest`. If a value was supplied, add a WHERE clause to the SELECT query to filter on the otherInterests field. Remember to use the LIKE operator to search the entry for the interest, and to use a placeholder for the `$interest` value for security reasons.

In addition, if a value was supplied for `$interest`, make an additional call to `PDOStatement::bindValue()` to pass the `$interest` value into the query, wrapping the value in `% ...%` wildcards so that the entire field is searched.

The following code shows the `getMembers()` method with the added or changed lines highlighted:

```php
public static function getMembers($startRow
$stmt->bindValue( :startRow, $startRow, PDO::PARAM_INT );
$stmt->bindValue( :numRows, $numRows, PDO::PARAM_INT );
if ( $interest ) $stmt->bindValue( :interest, "%$interest@%", PDO::PARAM_STR );
$stmt->execute();

return array($members, $row['totalRows']);
```

In order to get a list of genres ordered by popularity, you need to count how many members list each genre as their favorite. Then it's just a case of grouping the results by genre with a GROUP clause, and sorting the results with an ORDER BY clause:

## Chapter 15

### Exercise 1 Solution

Numbers_Roman is a very simple package. You can find its documentation at http://pear.net/package/Numbers_Roman/latest/.

The first step is to install the package in the usual way:

```bash
pear install Numbers_Roman
downloading Numbers_Roman-1.0.2 (2110 bytes)
...done: 2110 bytes
install ok channel=pear.php.net/Numbers_Roman-1.0.2
```

The package provides a class with two static methods:

- Numbers_Roman::toNumber() converts the Roman number to its Arabic equivalent.
- Numbers_Roman::toNumerical() converts the number supplied as first argument to Roman numerals. The second argument defaults to true, which displays the numerals in uppercase; set it to false to display them in lowercase. The third argument also defaults to true, and specifies HTML markup for displaying the numbers with underscore should be output if the number is over 3999 (as required by the Roman system). Set it to false to turn off any underscore.

For this exercise you want to use Numbers_Roman::toNumerical(). All you need to do is create a loop that moves through the integers 1 to 100, calling Numbers_Roman::toNumerical() for each integer and outputting the result:

```html
<!DOCTYPE html "-//W3C//DTD HTML 1.0 Strict//EN">
"http://www.w3.org/TR/html1/DTD/html1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml-lang="en" lang="en">
<head>
<title>1 to 100 in Roman numerals</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<h1>1 to 100 in Roman numerals</h1>
<p>
<?php
require_once("Numbers/Roman.php");

for ($i=1; $i<=100; $i++) {
echo Numbers_Roman::toNumerical($i, true, true ) . "<br />";
}
?>
</p>
</body>
</html>
```

### Exercise 2 Solution

Now that you know how to use both HTML_Form (from the example earlier in the chapter) and Numbers_Roman (from the previous exercise), you have no problems with this exercise. You need to create a new HTML_Quick object, populate with a field for the number to convert and a Convert button, and adds a validation rule to check whether the user has entered. It is simply a case of checking whether the entered number is Arabic or Roman (you can use PHP's `is_numeric()` function for this), and running the appropriate conversion.

Here's an example. This script includes a couple of extra lines of code in the `convertNumber()` to filter the user input for security reasons:

```html
<!DOCTYPE PUBLIC "-//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml-lang="en" lang="en">
<head>
<title>Roman numbers converter</title>
</head>
<body>
<h1>Roman numbers converter</h1>
<?php
require_once("HTML/QuickForm.php");
require_once("Numbers/Roman.php");
$form = new HTML_QuickForm("ConvertForm", "get", "", null, true);
$form->addElement("text", "number", "Number (in Arabic or Roman format)");
$form->addElement("submit", "convertButton", "Convert");
$form->addRule("number", "Please enter a number", "required");

if ($form->submitted() && $form->validate()) {
    $form->process("convertNumber");
}

function convertNumber($values) {
$originalNumber = $values["number"];

if (is_numeric($originalNumber)) {
$numerals = "Roman";
$originalNumber = (int)$originalNumber;
$convertedNumber = Numbers_Roman::toNumeral($originalNumber, true, true);
} else {
$numerals = "Arabic";
$originalNumber = preg_replace("[^IVXLCM]/i", "", $originalNumber);
$convertedNumber = Numbers_Roman::toNumber($originalNumber);
}

echo "<p>$originalNumber in $numerals is: $convertedNumber</p>";
}

?>
</body>
</html>
```
