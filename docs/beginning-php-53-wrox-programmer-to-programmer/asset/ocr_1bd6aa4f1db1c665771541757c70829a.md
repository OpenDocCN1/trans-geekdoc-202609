# Using Variables in PHP

Variables are a fundamental part of any programming language. A variable is simply a container that holds a certain value. Variables get their name because certain value can change throughout the execution of the script. It's this to contain changing values that make variables so useful.

For example, consider the following simple PHP script:

```
echo 2 + 2;
```
