## Pattern Matching in PHP

PHP's main pattern-matching function is `preg_match()`. This function takes the following arguments:

- The regular expression to search for (as a string)
- The string to search through
- An optional array to store any matched text in. (The matched text is stored in the first element).
- An optional integer offset and any flags for the match operation. Currently only one flag is supported: `PREG_OFFSET_CAPTURE`. Pass this constant to get `preg_match()` to return the position of any match in the array as well as the text matched. (If you need to pass a fifth argument to `preg_match()` and you want to turn off this feature, use value of zero instead.)

`preg_match()` returns zero if the pattern doesn't match, or one if it did match. `preg_match()` only finds the first match within the string. If you need to find all the matches in a string, use `preg_match_all()`, described in the next chapter.

For example, to match the word "world" anywhere in the string "Hello, world!" you can write:

```php
echo preg_match("/world/", "Hello, world!"); // Displays "1"
```

To match "world" only at the start of the string, you'd write:

```php
echo preg_match("/world/", "Hello, world!"); // Displays "0"
```

To access the text matched, pass an array variable as the third argument:

```php
echo preg_match("/world/", "Hello, world!", $match) // Displays "1"
echo $match[0]; // Displays "world"
```

To find out the position of the match, pass `PREG_OFFSET_CAPTURE` as the fourth argument. The array contains a nested array whose first element is the matched text and second element is the position:

```php
echo preg_match("/world/", "Hello, world!", $match, PREG_OFFSET_CAPTURE); // Displays "1"
echo $match[0][0]; // Displays "world"
echo $match[0][1]; // Displays "7"
```

## Exploring Regular Expression Syntax

Although a complex regular expression can look like Greek to the newcomer, regular expressions are nothing more than a set of simple rules encoded in a string. Once you understand how the rules work you'll be able to read any regular expression with relative ease.

In the following sections you learn some useful regular expression rules. Though this list isn't 100 percent complete, it’s more than adequate for most matching scenarios. (For a seriously in-depth treatment of regular expressions, try the book Mastering Regular Expressions by Jeffrey E. F. Friedl, published by O’Reilly, ISBN 1-5692-257-3).

## Matching Literal

The simplest form of regular expression pattern is a literal string. In this situation, the target string is compared with no additional rules applied.

As you’ve already seen, alphabetical characters such as “hello” are treated as literal strings in regular expressions. The string “hello” in a regular expression matches the text “hello” in the target string. Similarly, many other characters — as digits, spaces and double quotes, and the %, &, @ and # symbols — are treated literally by the regular expression engine.

However, as we will see, some characters have special meanings within regular expressions. These nineteen special characters:

```
\ + * ? [ ^ ] $ ( ) { } = <
```

If you want to include any character from this list within your regular expression, you need to escape it by placing a backslash (\) in front of it, like \.

Because the backslash is itself a special character, you need to escape it with another backslash (\\) if you want to include it literally in an expression. What’s more, because a backslash followed by another character within a string is itself an escaped character in PHP, you will need to add a third backslash (\\). Phew!

In addition, if you use your delimiter within your expression, you need to escape it:

```php
echo preg_match("/\*http:\\/\\/*", "http://www.example.com"); // Displays "1"
```

Slashes are commonly used as regular expression delimiters, but you can use any symbol you like (provided you use the same symbol at both start and end of the expression). This is useful if your expression contains a lot of slashes. By using a different delimiter, such as the | (vertical bar) character, you avoid having to escape the slashes in the expression:

```php
echo preg_match("|http:\\/.*|", "http://www.example.com"); // Displays "1"
```

Although some of these special characters are sometimes treated literally in certain contexts, it's a good idea to escape them. (However, don't try to escape letters and digits by placing a backslash in front of them, because this conveys a different meaning, as you see.)

Luckily, PHP provides a handy function `preg_quote()` that escapes any characters that might be used as delimiters in the expression:

| Escape Sequence | Meaning |
|---|---|
| \n | Line feed |
| \r | Carriage return |
| \t | Horizontal tab |
| \e | Escape character |
| \f | Form feed |
| \a | Bell |
| \xdd | Character with hex code dd |
| \ddd | Character with octal code ddd |
| \cx | Control character |

### Matching Types of Characters using Character Classes

Rather than searching for a literal character, often it's useful to search for a class or type of character. For example, you might only care that the character is a digit, or that it is one of the letters A, B, or C.

By placing a set of characters in square brackets, you can search for a single character that matches any of the characters in the set. For example, the following expression matches "a", "b", "c", "1", "2", or "3":

```php
echo preg_match("[abc123]/", "b"); // Displays "1"
```

You can specify ranges of characters using the hyphen (-) symbol. The following example matches the same set of characters as the previous example:

```php
echo preg_match(/[a-c-3]/", "b"); // Displays "1"
```

So you can match any letter or digit using:

```php
echo preg_match(/[a-zA-Z0-9]/", "H"); // Displays "1"
```

To negate the sense of a character class — is, to match a character that is not one of the characters in the set — place a caret (^) at the start of the list:

```php
echo preg_match("[^abc]/", "e"); // Displays "0"
echo preg_match("[^abc]/", "e"); // Displays "1"
```

You don't need to escape most of the previously mentioned special characters when they're inside a character class. The exceptions are the caret, which still needs to be escaped (unless you're using it to negate the class as just shown), and the backslash, which is used for specifying shorthand character classes, as you see in a moment.

You can also use various shorthand character classes comprising a backslash followed by letters, as follows:

| Character Class | Meaning |
|---|---|
| \d | A digit |
| \D | Any character that isn't a digit |
| \w | A word character (letter, digit, or underscore) |
| \W | Any character that isn't a word character |
| \s | A whitespace character (space, tab, line feed, carriage return, or form feed) |
| \S | Any character that isn't a whitespace character |
