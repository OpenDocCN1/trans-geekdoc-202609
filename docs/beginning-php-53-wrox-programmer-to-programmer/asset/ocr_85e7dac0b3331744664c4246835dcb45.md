```
<?php
require("animal_functions.php");nechoSpeak("cat") . "br />'; // Displays "meow";
?>
```

The difference is that include() merely raises a PHP warning if the file to be included is not found, whereas require() fails a fatal and stops the script. Use require() if you're including library that are essential to the running of your application.

# Including a File Only Once

A file that uses include() or require() to include a file can be included in another file — a process known as nested includes. For example the mouse.php and cat.php files, which themselves include the animal_functions.php file, might be included within a higher-level display_animal_sounds.php script, as follows:

```
<?php
require("mouse.php");nrequire("cat.php");
?>
```
