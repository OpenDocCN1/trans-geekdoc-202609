If you want, you can call xml_get_current_line_number() and xml_get_current_column_number() at any point during the parse process, not only when an error has occurred. This can be useful for finding how far through the document the parser has reached.

# Try Out Parsing an XML File

Here's a simple example of XML Parsing in action. You're going to open an XML document on the hard drive and parse it, displaying its elements and attributes as you go. You can try this on any XML document, but this example uses the stockList document created early in the chapter:

```
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE stockList SYSTEM "http://www.example.com/dtd/stockList.dtd">
<stockList>
  <item type="fruit">
    <name>apple</name>
    <unitPrice>0.99</unitPrice>
    <quantity>412</quantity>
    <description><![CDATA[Apples are >>>yummy]]></description>
  </item>
  <item type="vegetable">
    <name>beetroot</name>
    <unitPrice>1.39</unitPrice>
    <quantity>67</quantity>
    <description><![CDATA[Beetroots are lovely & purple]]]></description>
  </item>
</stockList>
```

Save this file as stock_list.xml in your document root folder so it's ready for reading by your parser script.
