Next, the change in the script to show your name and email address:

```
define("OWNER_FIRST_NAME", "Michael");
def("OWNER_LAST_NAME", "Brown");
def("OWNER_EMAIL_ADDRESS", "michael@example.com");
```

The script uses the HTML.QuickForm and HTML.QuickForm_Renderer_Tableless PEAR packages to display and handle the contact form, if you haven't already done, you will need to install these two packages before you run the script. You can find instructions for this in Chapter 15.

Now run the script by visiting its URL in your web browser. You should see a form like the one in Figure 16-4. Enter your details into the form, along with a message and the message itself, and then click the Send button to send the email. If all goes well you'll see an acknowledgement page, and the email should arrive in your inbox in a few minutes.
