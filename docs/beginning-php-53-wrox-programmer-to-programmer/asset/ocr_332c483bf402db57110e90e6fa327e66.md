# # Installing on Mac OS X

Mac OS X comes with a version of Apache and PHP already installed. It's likely that installed version is somewhat out of date. Furthermore, Mac OS X doesn't come with a MySQL package installed by default, although (You'll need MySQL or a similar database system to build database-driven web sites, as described in later book.)

As would have it, just as Windows has? Mac OS X has MAMP — an all-in-one, easy-to-package to get you Apache, MySQL, and PHP setup on your Mac. The great thing about MAMP (and its Windows MAMP equivalents, for that matter) is that it's self-contained. This means it won't mess up any existing server software installed; all its files are stored under a single folder; and it's easy to install if you want.

To install MAMP on your Mac, follow these steps:

+   1. Download the latest MAMP version from www.mamp.info/en/. At the time of writing, two versions are available: MAMP and MAMP PRO. The regular MAMP is fine for the purpose of developing PHP applications on your Mac.
2. Open the MAMP .dmg file that you downloaded.
3. In the window that pops up, drag the MAMP folder on top of the Applications folder to install it.
4. Open the MAMP folder inside your Applications folder in Finder, then double-click the MAMP icon to launch the application.
