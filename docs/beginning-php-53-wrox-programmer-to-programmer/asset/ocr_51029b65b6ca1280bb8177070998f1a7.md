That's it! You should now have a working Apache Web server with PHP and MySQL installed. Skip to the “Testing Your Installation” section to make sure everything's working.

The packages you've installed give you a basic PHP installation with the functionality to follow the contents of this book. However, you can use Synaptic to install extra PHP packages (or remove packages) as easily as you want.

In fact, as Ubuntu 7.04, there is an even easier way to install Apache, PHP and MySQL in one go. Simply open a terminal window (Applications -> Accessories -> Terminal), then type:

```
sudo tasksel install lamp-server
```

and press Enter. This installs all the packages needed to have a fully functioning LAMP (Linux, Apache, MySQL, PHP) Web server. You'll be prompted to choose a root password for MySQL during the installation, but from that, the process is fully automated. Again, you'll probably need to restart the Web server after installation, as shown in Step 6 in the preceding list. And who said Linux was hard!
