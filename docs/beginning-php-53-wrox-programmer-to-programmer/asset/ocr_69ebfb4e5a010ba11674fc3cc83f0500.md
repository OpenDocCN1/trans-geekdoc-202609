# Appendix B: Configuring PHP

```
; runs. $argv contains an array of all the arguments passed to a script
; is invoked. $argc contains an integer representing the number of PHP arguments
; that passed when the script was invoked. These arrays are extremely
; useful when running scripts from the command line. When this directive is
; enabled, registering the variables consumes CPU cycles and memory each time
; a script is executed. For performance reasons, this feature should be disabled
; on production servers.
; Note: This directive is hardcoded to On for the CLI API
; Default Value: On
; Development Value: On
; Production Value: Off
; http://php.net/register-argv
register_argv = Off
```

```
; When enabled, the SERVER and ENV variables are created when they're first
; used (Just In Time) instead of when the script starts. If these variables
; are not used within a script, having this directive will result in a
; performance gain. The PHP registers_globals, register_long_arrays,
; and register_ARGV_jit must be disabled for this directive to have any affect.
; http://php.net/auto-globals-jit
auto_globals_jit = On
```

```
; Maximum size of POST data that PHP will accept.
; http://php.net/post-max-size
post_max_size = 8M
```

```
; Magic quotes are a preprocessing feature of PHP where PHP will attempt to
; escape any sequences in GET, POST, COOKIE and ENV data which might
; otherwise quote data being placed in resources such as databases before
; making that available to you. Because of character encoding issues and
; non-standard SQL implementations across many databases, it's not currently
; possible for this feature to be 100% accurate. PHP's default behavior is to
; enable the feature. We strongly recommend using the escaping mechanisms
; designed specifically for the database using your instead of relying on
; feature. also, this feature has been deprecated as of PHP 5.3.0 and is
; scheduled for removal in PHP.
; Default Value: On
; Development Value: Off
; Production Value: Off
; http://php.net/magic-quotes-gpc
magic_quotes_gpc = Off
```

```
; Magic quotes for runtime-generated data, e.g. from SQL, from exec(), etc.
; http://php.net/magic-quotes-runtime
magic_quotes_runtime = Off
```

```
; Use Sybase-style magic quotes (escape ' ' instead of \').
; http://php.net/magic-quotes-sybase
magic_quotes_sybase = Off
```
