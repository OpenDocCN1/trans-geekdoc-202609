# Chapter 7: Functions

To create functions dynamically — You can customize the code within an anonymous function at the time that you create it. Although you'll really need to do this, it can make your code flexible in certain situations

To create short-term, disposable functions — Commonly, when you do this with built-in functions that require you to create a callback or event handler to work. Examples include xml_element_handler(), which you meet in Chapter 19, and functions such as array_walk(), which lets you apply a function to each value in an array and usort(), which sorts an array's elements according to a comparison function that you create

To create an anonymous function, you use create_function(). This expects two arguments: a separated list of parameters (if any), and the code for the function body (minus the curly braces, semicolon at the end of each code). It returns a unique, randomly generated string value that you can use to return the function:

```
$$MyFunction = create_function('$param1, $param2', 'function code here');
```

Here's a typical example that creates an anonymous function based on a value of the variable:

```
$mode = "+";
$processNumbers = create_function('$a, $b', 'return $a \$b');
echo $processNumbers(2, 3); // Displays $5
```

This code uses the $mode variable as the operator to process its two arguments, $a and $b. For example, if you change $mode to "+", the code displays "6" (instead 2 times). In this case is rather pointless, but if you can imagine a more complex function, whose contents are determined by external factors such as user input, then that's a potentially powerful feature of PHP.
