### Exercise 1 Solution

You could write this script many ways. The following solution creates a for loop to count the numbers, then uses the (ternary) operator to determine if a number is odd, even, or prime.

```php
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en">
<head>
  <title>Testing the Numbers 1-10</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<h1>Testing the Numbers 1-10</h1>

<table border="1">
<tr>
<th>Number</th>
<th>Odd or Even?</th>
<th>Prime?</th>
</tr>
<?php
for ($i = 1; $i <= 10; $i++) {
  $oddEven = ($i % 2 == 0) ? "Even" : "Odd";
  switch ($i) {
    case 2:
    case 3:
    case 5:
    case 7:
      $prime = "Yes";
      break;
    default:
      $prime = "No";
      break;
  }
?>
<tr>
<td><?php echo $i;?></td>
<td><?php echo $oddEven;?></td>
<td><?php echo $prime;?></td>
</tr>
<?php
}
</table>
</body>
</html>
```

### Exercise 2 Solution

The trick is to store two sets of pigeon representing the two pigeons,, and expand both the "flying" logic to allow for both pigeons. The first do... while loop should only exit when both pigeons are positioned more than half the map size away from the home base, and the second do... while loop should allow both pigeons have flown home. The loop conditions and decisions within the script need to be a bit complex:

```php
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/html/DTD/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en">
<head>
<title>Homing Pigeons Simulator</title>
<link rel="stylesheet" type="text/css" href="common.css" />
<style type="text/css">
div.map { left; text-align: center; border: 1px solid #666;
background-color: #ffffff; margin: 5px; padding: 1em; }
span.home, span.pigeon { font-weight: bold; }
span.empty { color: #666; }
</style>
</head>
<body>
<?php
$mapSize = 10;
// Position the home and the pigeons
do {
$homeX = rand ( 0, $mapSize-1 );
$homeY = rand ( 0, $mapSize-1 );
$pigeon1X = rand ( 0, $mapSize-1 );
$pigeon1Y = rand ( 0, $mapSize-1 );
$pigeon2X = rand ( 0, $mapSize-1 );
$pigeon2Y = rand ( 0, $mapSize-1 );
} while ( abs ( $homeX - $pigeon1X ) < $mapSize/ 2 ) && ( abs ( $homeY - $pigeon1Y < $mapSize/2 ) ) && ( abs ( $homeX - $pigeon2X ) < $mapSize/ 2 ) && ( abs ( $homeY - $pigeon2Y ) < $mapSize/2 ) );
do {
// Move the pigeons closer to home
if ( $pigeon1X < $homeX )
$pigeon1X++;
elseif ( $pigeon1X > $homeX )
$pigeon1X--;
if ( $pigeon1Y < $homeY )
$pigeon1Y++;
elseif ( $pigeon1Y > $homeY )
$pigeon1Y--;

if ( $pigeon2X < $homeX )
$pigeon2X++;
elseif ( $pigeon2X > $homeX )
$pigeon2X--;
if ( $pigeon2Y < $homeY )
$pigeon2Y++;
elseif ( $pigeon2Y > $homeY )
$pigeon2Y--;

// Display the current map
echo '<div class="map" style="width: ' . $mapSize . '">';
for ( $y = 0; $y < $mapSize; $y++) {
    for ( $x = 0; $x < $mapSize; $x++) {
        if ( $x == $homeX && $y == $homeY ) {
            echo '<span class="home">H</span>';
        } elseif ( $x == $pigeon1X && $y == $pigeon1Y ) || ( $x == $pigeon2X && $y == $pigeon2Y ) {
            echo '<span class="pigeon">P</span>';
        } else {
            echo '<span class="empty">.</span>';
        }
    }
    echo '<br>';
}
echo '</div>';

?>
```

### Exercise 2 Solution

The `str_pad()` function, in its basic form, all you need to do is a loop to keep adding spaces until the length is reached. To display the results, make sure you wrap them in tags. Here's an example:

```php
$authors = array("Tolkien", "Kafka", "Dickens", "Milton", "Orwell", "Steinbeck");
foreach ($authors as $author) {
    $padded = str_pad($author, 20, " ", STR_PAD_RIGHT);
    echo "<li>$padded</li>";
}
```
