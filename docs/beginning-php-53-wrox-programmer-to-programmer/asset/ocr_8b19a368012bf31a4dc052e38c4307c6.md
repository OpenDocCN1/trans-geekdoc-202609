# Chapter 6: Arrays

array_slice() removes a range of elements in an array and replace them with the elements from another array. Both the removal and the replacement are optional, you can just remove elements without adding ones, or just insert elements without removing any.

Here's how it works. array_slice() takes the array to be manipulated, and the position of the first element (counting from zero) to start the slice operation. (Remember that all arrays, even associative arrays, have a concept of element positioning). Next, you pass in an optional argument that specifies many elements to remove; if omitted, the function removes all elements from the start point to the end of the array. Finally, you can pass another optional argument, which is the array of elements to insert.

array_slice() returns an array containing the extracted elements (if any).
