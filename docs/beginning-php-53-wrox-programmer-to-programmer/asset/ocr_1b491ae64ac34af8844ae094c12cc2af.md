# # Why Use PHP?

One of the best things about PHP is the large number of Internet service providers (ISPs) and Web hosting companies that support it. Hundreds of thousands of developers are using PHP, and it's not surprising that there are so many, considering several million sites are reported to have PHP installed.

Another great feat of PHP is that it's cross-platform — you can run PHP programs on Windows, Linux, FreeBSD, Mac OS X and Solaris. What others? The PHP engine can integrate with common web servers, including Apache, Internet Information Services (IIS), Zeus, and lighttpd. This means you can develop and test your PHP site on one, then deploy on a different type of system without having to change your code. Furthermore, it's easy to move your PHP Web site onto another server, if you ever need to.

How does PHP compare with other Web programming technologies? At the time of writing, the following technologies are presented:

+   - ASP (Server Pages): This venerable Microsoft technology has around since 1997, and was one of the first Web application technologies to integrate closely with the Web server, resulting in fast performance. ASP scripts are usually written in VBScript, a language derived from BASIC. This contrasts with PHP's C-like syntax. Both languages have the same fans, I personally find that it's easier to write structured, modular code in PHP than in VBScript.
- ASP.NET: This is the latest iteration of ASP; in fact it has been built from the ground up. Actually it's a framework that can be used to build Web sites, and you have a choice of languages to use, including C#, VB.NET (Visual Basic), and Java. Because ASP.NET gives you a large library of code for things like making HTML forms and searching database tables, you can get a Web application up and running very quickly. PHP although has a rich standard library of functions, doesn't give you a structured framework to the extent that ASP.NET does. On the other hand, plenty of free framework and libraries are available for PHP, such PEAR (discussed later in this book) and the Zend Framework. Many argue that C# is a nicer, better-organized language to program in than PHP; although C# is arguably harder to learn. Another advantage of ASP.NET is that C# is a compiled language, which generally means it runs faster than PHP's interpreted scripts (although PHP are available).

ASP and ASP.NET have a couple of other disadvantages to PHP. First of all, they have a commercial license, which can mean spending additional money on server software, and hosting is more expensive as a result. Secondly, ASP.NET are fairly heavily tied to the Windows platform, whereas the other technologies in this list are more cross-platform.
