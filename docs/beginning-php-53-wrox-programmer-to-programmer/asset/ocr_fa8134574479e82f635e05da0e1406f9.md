# How It Works

After displaying a page header, the scripts store the filename of the file that will hold the hit count:

```
$counterFile = "./counter.dat";
```

Next, the script will check if the counter file exists. If it doesn’t, it is created by opening the file for writing, writing to it (thereby initializing the hit counter to zero), then closing it:

```
if ( file_exists($counterFile) ) {
    if ( ! $handle = fopen($counterFile, "w" ) ) {
        die("Cannot create the counter file.");
    } else {
        fwrite($handle, 0);
    }
    fclose($handle);
}
```
