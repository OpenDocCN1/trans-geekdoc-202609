For each element, the code inspects the element's tagName property until it finds the element's Once it's found, the code retrieves the text node inside the unitPrice element using the element's firstChild property (you know that the unitPrice element contains one child: the text node containing the price).

Finally, it's just calling the text node's replaceData() to change the price of $1.39 to $0.79.replaceData() takes three arguments: the character position at which to starting data, the number of characters to replace, and the string to replace the data with. If the number of characters replace is greater than the total number of characters in the string, the whole string is replaced. The script uses a value of 10 to make sure all characters are replaced (no vegetable is likely to cost more than $999999999). Once it's replaced, the job is done, so it breaks out of the loop.
