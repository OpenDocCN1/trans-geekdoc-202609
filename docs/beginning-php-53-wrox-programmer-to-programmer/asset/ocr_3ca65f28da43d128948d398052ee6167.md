# Scheduling PHP Command-Line Scripts

Because command-line scripts don’t need a request from a Web browser to start running, they can be scheduled at predetermined times of the day or week. Scheduled scripts have a number of uses, including:

+   - Backing up data
- Periodic cleanup of database tables and log files
- Sending regular email messages, such as newsletters or to users or administrators
- Retrieving published data, as RSS feeds

Scheduling a command-line PHP script on Windows is easy:

+   1. Create a batch file for your PHP script in the same folder as the script, as described earlier in “Running Command-Line PHP Scripts.”
2. Click the Start menu and choose Control Panel.
3. In the Control Panel window, double-click Scheduled Tasks.
4. Double-click Add Scheduled Task.
5. Click Next in the wizard, and then Browse.
