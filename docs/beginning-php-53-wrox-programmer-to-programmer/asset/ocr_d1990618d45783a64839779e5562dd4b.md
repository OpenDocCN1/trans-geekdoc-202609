# Creating Thumbnails

Creating a thumbnail of an image uses a similar method to applying a watermark, except that you copy the other direction — instead of copying the smaller image into the larger image, you copy the image into a new smaller image, scaling it down as you go. Here's an example script to create a thumbnail:

```
<php
$mainImage = imagecreatefromjpeg("lucky.jpg");
```
