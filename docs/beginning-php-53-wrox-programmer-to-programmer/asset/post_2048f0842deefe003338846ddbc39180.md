### Try Out Calculate the Properties of a Circle

Save this simple script as circle_properties.php in your Web server's document root folder, then open its URL (for example, http://localhost/circle_properties.php) in your Web browser to run it:

```php
<?php
$radius = 4;

$diameter = $radius * 2;
$circumference = M_PI * $diameter;
$area = M_PI * pow($radius, 2);
```

```
echo "This circle has...<br />";
echo "A radius of " . $radius . "<br />";
echo "A diameter of " . $diameter . "<br />";
echo "A circumference of " . $circumference . "<br />";
echo "An area of " . $area . "<br />";
?>
```

### How It Works

The first scripts store the radius of the circle to test in a $radius variable. Then it calculates the diameter—twice the radius and stores it in a $diameter variable. Next it works out the circle's circumference, which is π (pi) times the diameter, and stores the result in a $circumference variable. It uses the built-in PHP constant, M_PI, which stores the value of π.

Then the script calculates the circle's area, which is $\pi$ times the radius squared, and stores it in an $area variable. To get the value of the radius squared, the script uses the built-in `pow()` function, which takes a base number, `base`, followed by an exponent, `exp`, and returns `base` to the power of exp.

Finally, the script outputs the results of its calculations, using the string concatenation operator (.) to join strings together.

## Decisions and Loops

So far, you've learned that PHP lets you create dynamic Web pages, and you've explored some fundamental language concepts such as variables, data types, operators, expressions, and constants.

However, all the scripts you've worked in in a linear fashion: the PHP engine starts at the first line of the script, and works its way down until it reaches the end. Things get a lot interesting when you start introducing decisions and loops.

A decision lets you run one section of code or another, based on the results of a specific test. Meanwhile, a loop lets you run the same section of code over and over again until a specific condition is met.

By using decisions and loops, you add a lot of power to your scripts, and you can make them truly dynamic. Now you can display different page content to your visitors based on where they live, or what buttons they've clicked on your form, or whether not they're logged in in your site.

- Creating decision code with the ternary operator

- Altering loops with the break and continue statements
- Nesting loops inside each other

Once you've learned the concepts in this chapter, you'll be well on your way to building useful, adaptive PHP scripts.

## Making Decisions

Like most programming languages, PHP lets you write code that can make decisions based on the result of an expression. This allows you to do things like if a variable matches a particular value, or if a string is of a certain length. In essence, if you create a test in the form of an expression that evaluates to either true or false, you can use that test to make decisions in your code.

You studied expressions in Chapter 3, you might like to quickly review the "Operators and Expressions" section in chapter to give yourself an idea of the kind of expressions you can create. You can see that, thanks to the wide range of operators available in PHP, you can construct some pretty complex expressions. This means that you can use almost any test as the basis for decision-making in your code.

PHP gives you statements that you can use to make decisions:

- The if statement
- The elseif statements
- The switch statement

### Simple Decisions with the if

The easiest decision-making to understand is the if. The basic form is:

```php
if ( expression ) {
    // code
}
```

If the expression evaluates to true, the code inside the braces is run; if it evaluates to false, the code inside the braces is skipped. Here's a simple real-world example:

```php
$widgets = 23;
if ($widgets == 23 ) {
    echo "We have exactly 23 widgets!";
}
```

The first line of the script creates a variable, $widgets, and sets its value to 23. Then it uses the == operator to check if $widgets does equal 23. If it does, the script displays the message "We have exactly 23 widgets!". If it doesn't, the echo statement is skipped.

This example is similar to the previous one, but the test expression is slightly more complex. If the value in $widgets is greater than 10, and it's also less than 20, the expression evaluates to true and the echo () statement is executed.

The key point to remember is, that no how complex your test expression is, if the expression evaluates to true, the code inside the braces is run; otherwise the code inside the braces is skipped.

Here's another example that uses >= (greater than equal) and <= (less than equal) comparison operators, as we use the && (logical) operator:

```php
$widgets = 23;
if ($widgets >= 10 && $widgets <= 20 ) {
  echo "We have between 10 and 20 widgets in stock.";
}
```

The code block between the braces of the first if statement is itself another if statement. The first if statement runs its code block if $widgets >= 10, whereas the inner statement runs its code block—the echo () statement—if $widgets <= 20. Because both expressions need to evaluate to true for the echo () to run, the result is the same as the previous example.

If you have only one line of code between the braces you can, in fact, omit the braces:

```php
$widgets = 23;
if ($widgets == 23 )
  echo "We have exactly 23 widgets in stock!";
```

However, if you do this, take care to add braces if you add additional lines of code to the code block. Otherwise, your code will not run as expected!
