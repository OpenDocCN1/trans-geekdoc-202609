# Part III: Using PHP Practice

If you want to insert only some values, leaving NULLs or default values in the remaining fields, use:

```
INSERT INTO table field1, field2, ... VALUES (value1, value2, ... );
```

The first approach is correct, and perfectly valid if you want to populate all the fields in the row, the second approach is generally more flexible and readable.

So do you insert records using your PHP script? You pass INSERT statements to MySQL via PDO in the same way you pass SELECT statements. If you don't want to pass data from any PHP variables, you can use the PDO::query() method — for example:

```
php
$dsn = "mysql:dbname=mydatabase";
$username = "root";
$password = "mypass";
```

```
try {
  $conn = new PDO($dsn, $username, $password);
  $conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
  echo "Connection failed: " . $e->getMessage();
}

$sql = "INSERT INTO members VALUES (8, 'derek', password('mypass'), 'Derek', 'Winter', '2008-06-25', 'm', 'crime', 'derek@example.com', 'Watching TV, motor racing')";

try {
  $conn->query($sql);
} catch (PDOException $e) {
  echo "Query failed: " . $e->getMessage();
}
?>
```

Note that, the call to $conn->query() still returns a PDOStatement object, the object is discarded in this case. There's no result to set ever, so there's no need to hold the PDOStatement object.

However, if you want to insert data that is stored in PHP variables, if a member has just registered using a registration form, you'll want to pass the data to the INSERT statement to add the member. The safest way is to create a prepared statement using PDO::prepare(), as you did with SELECT queries in the previous chapter. You can then use placeholders in the query string for each of the fields you want to insert, and pass the data into the query using calls to PDOStatement::bindValue(). For example:

```
php
$dsn = "mysql:dbname=mydatabase";
$username = "root";
$password = "mypass";
```
