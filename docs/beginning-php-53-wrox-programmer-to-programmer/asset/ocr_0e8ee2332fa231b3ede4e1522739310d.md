# How It Works

The script starts by creating a new session (or picking up an existing one) with session_start().
Then defines a couple of constants, USERNAME and PASSWORD, to store the predefined login details. (In a real web site you would probably store a separate username and password for each user in a database table or text file.)

```
session_start();
define("USERNAME", "john");
define("PASSWORD", "secret");
```
