# Chapter 10: Preserving State With Queries

The getInfo() function sets the firstName and location expiry times to one hour ago, effectively deleting them from the browser. It then sends a location header to reload the remember_me.php script. The browser won't set the cookies to the script if they've been deleted

The final function, displayPage(), displays the output to the visitor. It starts by creating two variables to hold the values from the user's info (cookies)

```
$firstName = (isset($_COOKIE['firstName']) ? $_COOKIE['firstName'] : "");
$location = (isset($_COOKIE['location']) ? $_COOKIE['location'] : "");
```

Next, after displaying the page, the footer contains the values of $firstName and $location. If either variable contains a non-empty value, the function displays a greeting page, including the visitor info, a short nursery rhyme, and the "About me" link that links back to remember_me.php script. This links a query string, action=forget to the script that the user wants to delete information:
