fpassthru() and readfile() both take a file and output its unmodified contents straight to the Web browser. fpassthru() requires the handling of an open file to work with:

```
```
$nums = fpassthru($handle);
```
```

readfile() instead works on an opened file:

```
```
$nums = readfile("myfile.txt");
```
```

As you can see, both functions return the number of characters (or false if there was a problem). fpassthru() reads from the file pointer position, so if you've already read some of the file only the remaining portion of the file will be sent.

You can make readfile() search the path for the file by passing true as the second argument. Incrementally, readfile() is handy for sending binary files — such as images and PDF documents — to the Web for displaying or downloading. You can see an example of this in Chapter 16.

# # Random Access to File Data

Using the functions you've met so far, you can only manipulate data sequentially, that is, in the same order that it is arranged in the file. However, sometimes you might need to skip over the contents of an open file. For example, you might want to read a file once to search for a particular string, then return to the start of the file in order to search for another string. Of course, this is easy if you read the entire file using, for example, file_get_contents(). However, this isn't practical for large files.

Fortunately, it's possible to move the file pointer around within an open file, so that you can start reading or writing at any point in the file. PHP gives you three functions that work with the file pointer:

+   - fseek() — Repositions the file pointer to a specified point in the file
- rewind() — Moves the file pointer to the start of the file
- ftell() — Returns the current position of the file pointer
