# Exercise 2 str_pad()

To emulate str_pad() in its most basic form, all you need to do is a while loop to keep adding spaces to the string until the desired length is reached. To display the results, make sure you surround the strings in the HTML `<pre>...</pre>` tags so that you can see the padding. Here's an example:

```
<!DOCTYPE html "//W3C//DTD HTML 1.0 Strict//EN">
"http://www.w3.org/TR/html1/dtd/html-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en">
<head>
<title>Emulating str_pad()</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<h1>Emulating str_pad()</h1>

<?php

$myString = "Hello, world!";
$desiredLength = 20;

echo "<pre>Original string: $myString</pre>";

while (strlen($myString) < 20) {
$myString .= " ";
}

echo "<pre>P string: $myString</pre>";
?>

</body>
</html>
```
