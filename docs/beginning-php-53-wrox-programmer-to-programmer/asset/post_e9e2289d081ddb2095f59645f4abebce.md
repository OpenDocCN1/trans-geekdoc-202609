## How It Works

After displaying a page header, the scripts store the filename of the file that will hold the hit count:

```php
$counterFile = "./counter.dat";
```

Next, the script will check if the counter file exists. If it doesn’t, it is created by opening the file for writing, writing to it (thereby initializing the hit counter to zero), then closing it:

```php
if ( file_exists($counterFile) ) {
    if ( ! $handle = fopen($counterFile, "w" ) ) {
        die("Cannot create the counter file.");
    } else {
        fwrite($handle, 0);
    }
    fclose($handle);
}
```

## Part III: Using PHP Practice

Next the counter file is opened for reading:

```php
if ( (! (fopen($counterFile, "r")) )) {
    die("Cannot read the counter file.");
}
```

The script now uses the file handle to read the hit counter value from the open file. As you can see, the script calls `fread()` to read up to 20 bytes from the file (enough to store a large integer):

```php
$counter = (int) fread($handle, 20);
```

Because `fread()` contains a string value, and the counter needs to be an integer value, the return value is cast into an integer using `int`. (See Chapter 3 for more on type casting.)

The call to `fclose()` closes the file referenced by the file handle `$handle`, freeing up the file for reading or writing by other processes:

```php
fclose($handle);
```

After closing the file, the script increments the counter and tells the visitor how many times the page has been accessed:

```php
$counter++;
echo "<p>You're visitor No. $counter.</p>";
```

The next script writes the new counter value back to the file data. This opens the file in write mode (w), which calls `fwrite()` to write the `$counter` variable's value to the file, followed by `fclose()` to close the open file:

```php
if ( (! (fopen($counterFile, "w")) ) {
    die("Cannot open the counter file for writing.");
}

fwrite($handle, $counter);
fclose($handle);
```

## Testing for the End of a File

The `eof()` function serves a simple purpose: it returns `true` when the file pointer has reached the end of the file (or if an error occurs) and returns `false` otherwise. It takes one argument — the file handle to test. Notice that `eof()` only returns true once the script has read one or more characters past the last character in the file:

```php
// hello.txt contains the characters "Hello, world!"
$handle = fopen("hello.txt", "r");
$hello = fread($handle, 13);
echo $hello . "<br />"; // Displays "Hello, world!"
echo eof($handle) . "<br />"; // Displays "false"
$five_more_chars = fread($handle, 5);
```

```php
echo $five_more_chars . "<br/>"; // Displays " (or possibly a newline)"
echo feof($handle) . "<br/>"; // Displays "1" (true)
feof($handle);
```

feof() is useful with getc() in a while loop when you don't know how the file is:

```php
// hello_world.txt contains the characters "Hello, world!"
$handle = fopen("hello_world.txt", "r");
$text = ""; 

while (!feof($handle)) {
    $text = fread($handle, 3); // Read 3 characters at a time
}

echo $text . "<br/>"; // Displays "Hello, world!"
fclose($handle);
```

## Reading One Line at a Time

It's useful to read text from a file line at a time. A line is a nice manageable chunk of text to process or display. For example, data files and configuration files often contain one chunk of information per line, such as a data record or a configuration setting.

To read a line of text from an open file, call the fgets() function, passing in the file handler. The function reads from the current file pointer to the end of the current line, and returns the characters as a string (or false if there was a problem, such as the end of the file being reached). Note that any end-of-line character (or characters) at the end of the line is also included in the string.

You can limit the number of characters read by passing in a second argument, in which case fgets() stops when it reaches that number of characters minus one (unless the end of the line is reached). It's a good idea to include this argument when reading large files that might not contain line breaks.

The following example uses fgets() to read a three-line file, one line at a time. The while loop exits when fgets() returns false (which means it reached the end of the file):

```php
/*
milton.txt contains:
The mind is its place, and
in heaven itself can make hell of hell,
and heaven of heaven.
*/

$handle = fopen("milton.txt", "r");
$lineNumber = 1;

while ($line = fgets($handle)) {
    echo $lineNumber++ . ":$line<br/>";
}
fclose($handle);
```

## Part III: Using PHP Practice

The code produces the following output:

```
1: The mind is its place, and
2: in heaven itself can make hell of hell,
3: and heaven of heaven
```

## Reading CSV Files

If you've done any work with importing and exporting data, you probably know about comma-separated (CSV) data format. CSV has its own extension (.csv). In CSV files, each record sits on its line, and the fields within each record are separated by commas. String values are often enclosed within double quotes:

```
"John", "Smith", 45
"Anna", "Clark", 37
"Bill", "Murphy", 32
```

To read csv files, you can use fcsv(). This function reads a line of CSV-formatted data from an open file starting from the file pointer, and puts the data into an array, with one field per element. Once you have an array of data you can easily manipulate it. To call fcsv(), you pass the file handle of an open file. You can also specify:

- The maximum number of characters to read. You can leave this value out, or set 0, in which case PHP reads as many characters as necessary to read the whole line. However, specifying a value makes the function slightly quicker.
- The delimiter that is used to separate each value. The default is a comma (,). If youre reading a tab-separated (TSV) file, specify "\t" (the tab character) for this argument instead.
- The character that is used to enclose string values. The default is the double quote (").
- The character used to escape special characters. The default is a backslash (\).

fcsv() returns false if there was a problem reading the line, or if the end of the file has been reached. The following code snippet shows how you might retrieve three lines of data from a file in CSV format:

```php
/*
people.csv contains:
"John", "Smith", 45
"Anna", "Clark", 37
"Bill", "Murphy", 32
*/

$handle = fopen("people.csv", "r");
while ($record = fcsv($handle, 1000)) {
    echo "Name: {$record[0]} {$record[1]}, Age: {$record[2]}<br />";
}
fclose($handle);
```

This code displays:

```
Name: John Smith, 45
Name: Anna Clark, 37
Name: Bill Murphy, 32
```

PHP 5.3 introduces a new function, str_getcsv(), that reads CSV data from a string instead of a file. This is handy if you already have your CSV data in memory. For details see http://www.php.net/manual/en/function.str-getcsv.php.

## Reading and Writing Files

Writing code to read a file by line, or by string, can be tedious. Frankly, PHP provides you with some functions that can access the complete contents of a file in one go:

- file() — For reading a whole file into array, without needing to open it
- file_get_contents() and file_put_contents() — For reading and writing the contents of a file without needing to open it
- fpassthru() — For displaying the contents of an open file
- readfile() — For displaying the contents of a file without needing to open it

Because these functions read the entire file into memory in one go, they should really be used for relatively small files (a few MB at most). If youre working with a 100MB text file, it's probably best to use fread() or fgets() to read and process the file in chunks

file() reads the contents of a file into an array, with each element containing a line from the file — a string containing the name of the file to read — and returns the array containing the lines of the file:

```php
$lines = file("/home/chris/myfile.txt");
```

The newline character remains attached at the end of each line in the array.

> This function, like most of the others described in this section, doesn't require you to specify a file handle. All you need to do is pass in the filename of the file to read. The function automatically opens, reads, and, once itss done, closes the file.

You can optionally specify some useful flags as the second parameter to file():

| Flag | Description |
| :--- | :--- |
| FILE_USE_INCLUDE_PATH | Look for the file in the include path (see Chapter 20 for more on include paths) |
| FILE_IGNORE_NEW_LINES | Remove newline characters from the end of each line in the array |
| FILE_SKIP_EMPTY_LINES | Ignore empty lines in the file |
