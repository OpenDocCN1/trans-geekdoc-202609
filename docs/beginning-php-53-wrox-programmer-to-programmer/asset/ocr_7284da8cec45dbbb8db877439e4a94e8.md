Setting the PDO::ATTR_ERRMODE attribute to PDO::ERRMODE_EXCEPTION tells PDO to throw exceptions whenever a database error occurs, as you will see in the following chapter.

The disconnect() function merely takes a PDO object, stored in $conn, and assigns an empty string to $conn, thereby destroying the object and connection to the MySQL database.
