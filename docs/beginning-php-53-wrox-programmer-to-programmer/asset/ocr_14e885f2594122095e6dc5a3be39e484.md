# # Other Databases Supported by PHP

Thanks to the wide range of extensions available, PHP can talk to many other database engines — some well known and some quite obscure — such as dBase, Firebird, Firebird, Informix, Ingres, mSQL, Paradox, and Sybase. You can view the full list at http://www.php.net/manual/en/refs.database.php.

In addition, PDO supports a decent range of database systems. As well as the systems already mentioned in this appendix, you can use PDO to communicate with Firebird and Informix databases. So you should have no problem getting your PHP applications to work with pretty much any popular database engine currently on the market!
