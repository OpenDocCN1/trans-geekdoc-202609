# Part III: Using PHP Practice

Next, the three select fields for the month, day and year are added to the form. Such fields are quite tedious to generate, even when using a scripting language like PHP. Fortunately, HTML_QuickForm includes a date element that automatically generates the three select fields for you.

The first script creates an array of options for the date fields. format specifies both the format of each of the month, day, and year fields, as well as their order in the form. In this case, "Mdy" specifies the month as a three-letter abbreviation, followed by the day with a leading zero, and the four-digit year. The range of years in the third select is set with minYear and maxYear; in this case the script sets lowest year to 1902 and highest to the current year:

```
$options = array("date" => "Mdy", "minYear" => 1902, "maxYear" => "Y");
```

You can find a list of formatters for the date option in the HTML_QuickForm documentation at http://php.php.net/package/HTML_QuickForm/docs/latest/HTML_QuickForm/HTML_QuickForm_date#methodHTML_QuickForm_date.

Due to the limits of 32-bit operating systems, timestamp handling on most current machines is usually limited to dates and times between Friday, Dec 13 1901 20:45:54 GMT and Thursday, Jan 19 2038

Next's a simple case of adding the dateBirth element, as well as an element for the Calculate button:

```
$form->addElement("date", "dateBirth", "Your date of birth", $options);
$form->addElement("submit", "calculateButton", "Calculate");
```

The dateBirth field is validated with two rules. The first is a simple rule to check that the month, day, and year fields are filled. Rather than using the add addRule() method, the script uses addRule(), which checks that all fields within the dateBirth element contain the data. The second rule checks that the date specified by the three fields is in fact a valid date. It does this by using a callback function (described in a moment):

```
$form->addGroupRule("dateBirth", "Please enter your date of birth",
"required");
$form->addRule("dateBirth", "Please enter a valid date", "callback",
"checkDateBirth");
```

The next section of code checks whether the form has already been submitted. If so, and the supplied data is valid, the form is processed by calling the calculateDays() function:

```
if ($form->isSubmitted() and $form->validate()) {
$form->render("calculateDays");
}
```

Regardless of whether the form is processed, it is output to the browser using the HTML_
QuickForm_Renderer_Tableless renderer:

```
$renderer = new HTML_QuickForm_Renderer_Tableless();
$form->accept($renderer);
echo $renderer->toHtml();
```
