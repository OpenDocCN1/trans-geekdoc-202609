# Part II: Learning the Language

PHP allows you to create three “magic” methods that you can use to intercept property and method accesses:

+   - __get() is called whenever the calling code attempts to read an invisible property of the object

+   - __set() is called whenever the calling code attempts to write an invisible property of the object

+   - __call() is called whenever the calling code attempts to call an invisible method of the object

What is meant by “invisible”? In this context, invisible means that the property or method isn't visible to the calling code, but can also mean that the property or method is private or protected, and hence is inaccessible to the code outside the class.

# Overloading Property Accesses with __get() and __set()

To intercept access to an invisible property, you create a method called __get() within your class. (That's underscores, for you). Your __get() method should expect a single argument: the name of the requested property. It should return a value; this value then passed back to the calling code as the retrieved property value.

Here's an example:

```
class Car {
    public function __get($propertyName) {
        echo "The value of '$propertyName' was requested<br />";
        return "blue";
    }
}
```

```
$car = new Car;
$x = $car->color; // Displays "The value of 'color' was requested"
echo "The Car's color is $x-color<br />"; // Displays "The Car's color is blue"
```

In this example, the class contains no properties, but it does contain a __get() method. This method simply displays the value of the requested property name, and returns "blue". The rest of the script creates a new object, and attempts to retrieve the nonexistent property $car->color, storing the result in a new variable, $x. This triggers the object's __get() method, which displays the requested property name ("color") and returns the literal string "blue". This string is then passed back to the calling code and stored, as shown by the last line of code.

Similarly, to catch an attempt to set an invisible property to a value, use __set(). Your __set() method needs two parameters: the property name and the value to set it. It does not need to return a value:

```
public function __set($propertyName, $pValue) {
    // (do whatever needs to be done to set the property value)
}
```
