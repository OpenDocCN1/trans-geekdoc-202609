# Part III: Using PHP in Practice

Next comes the main decision logic of the script. This code examines the $_POST and \$_GET superglobal arrays, depending on what field it finds, it calls an appropriate function to handle the request:

```
if ( isset(\$_POST['saveFile'])) ) {
    saveFile();
} else if (isset(\$_GET['filename'])) ) {
    displayEditForm();
} else if (isset(\$_POST['createFile'])) ) {
    createFile();
} else {
    displayFileList();
}
```

If the saveFile form was submitted, the user wants to save edits, so the saveFile() function is called. If the filename field is found in the query string, the user has clicked a file to edit it; displayEditForm() is called to let the user edit. If the createFile form was found, the user has clicked the Create button to make a new file, createFile() is called to create the new file. Finally, if none of these fields exists, the file list is displayed calling displayFileList().

# The DisplayFileList() Function

When the first runs,, displayFileList() is called to display the list of files to edit, along with a form to allow the user to add a new file (see Figure 11-4). This function accepts one optional argument, $message, containing any error message to display to the user in the form.

First the calls the displayPageHeader() helper function (described in a moment) to generate a standard page header. It then checks that the text directories exists (if not, the script exits with an error message) and attempts to open the directory and retrieve a Directory object by calling the dir() function), if there's a problem then the script exits:

```
displayPageHeader();
if ( !exists( PATH_TO_FILES ) ) die("Directory not found ");
if ( $dir = dir(PATH_TO_FILES) ) ) die("Can't open directory ");
```

After displaying any error message passed to the function, and clicking an HTML table to display the file list, the function uses a while construct along with $dir->read() method to loop through the text directories. For each entry, the script checks that the entry's filename is not "." and that the file is not a directory and its file extension is ".txt". If the entry matches all criteria, it is displayed as a row. Notice that the loop stores the complete path to each file in a $filepath variable for convenience:

```
while ($filename = $dir->read()) {
    $filepath = PATH_TO_FILES . "$filename";n    if ($filename != "." && $filename != "." && !is_dir($filepath) &&
    strr($filename, ".txt") == ".txt") {
        echo '<tr><a href="text_editor.php?filename=' .
        $filename ) . '"' . $filename . '</a></td>';
    }
```
