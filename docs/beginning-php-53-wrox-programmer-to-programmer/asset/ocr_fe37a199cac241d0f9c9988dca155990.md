# Part III: Using PHP Practice

removeItem() does the opposite of addItem(): after verifying productID field, it removes the corresponding product from the user's cart, it refreshes the browser.

```
function removeItem() {
    global $products;
    if (isset($_GET['productID']) && $_GET['productID'] >= 1 && $_GET['productID'] < 3) {
        $productId = $_GET['productID'];
    }

    if (isset($_SESSION['cart'][$productId])) {
        unset($_SESSION['cart'][$productId]);
    }
}

session_write_close();
header("Location: shopping_cart.php");
```

Finally, displayCart() displays the user's cart, as well as the list of available products. After displaying an XHTML page header, the function loops through each item in the cart, displaying the product name, and a Link allows the user to remove the product from his cart. It also totals the prices of all the products in the cart it goes, then displays the total below:

```
<ol>
<?php
$totalPrice = 0;
foreach ($_SESSION['cart'] as $product) {
    $totalPrice += $product->getPrice();
}

<dt><?php echo $product->getName(); ?></dt>
<dd><td><?php echo number_format($product->getPrice(), 2 ) ?></td>
<td><a href="shopping_cart.php?action=removeItem&productID=<?php echo $product->getId(); ?>">Remove</a></td></dd>
<?php }
<dt>Cart Total:</dt>
<dd><td>$<?php echo number_format($totalPrice, 2 ) ?></td></dd>
</ol>
```

The displayCart() function then lists the available products, along with their prices. Each product has a corresponding Add Item list that the shopper can add to the product:

```
<ol>
<?php
foreach ($products as $product) {
<dt><?php echo $product->getName(); ?></dt>
<dd><td>$<?php echo number_format($product->getPrice(), 2 ) ?></td>
<td><a href="shopping_cart.php?action=addItem&productID=<?php echo $product->getId(); ?>">Add Item</a></dd>
<?php }
</ol>
```
