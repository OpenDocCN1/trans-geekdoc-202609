# Creating Nested Loops

There's nothing to stop creating a loop inside another loop. In fact, this can be quite a useful technique. When you nest one loop inside another, the inner loop runs through all its iterations. Then the outer loop iterates, causing the inner loop to run through all its iterations, and so on.

Here's a simple example of nested loops:

```
for ($tens = 0; $tens < 10; $tens++) {
  for ($units = 0; $units < 10; $units++) {
    echo $tens . "<br />";
  }
}
```

This example displays all the numbers from 0 to 99 (with a leading zero for the numbers 0 through 9). To do this, we set up two loops: an outer "tens" loop and an inner "units" loop. Each loop counts from 0 to 9. For every iteration of the "tens" loop, the "units" loop iterates 10 times. With each iteration of the "units" loop, the current number is displayed by $units value over the $tens value.

Note that the outer loop iterates 10 times, whereas the inner loop ends up iterating 100 times: 10 for each iteration of the outer loop.

Nested loops are great for working with multidimensional data structures like nested arrays and objects. You're not limited to two levels of nesting; you can create loops inside loops inside loops and so on.

When using the break statement with nested loops, you can pass an optional numeric argument to indicate how many levels of nesting to break out of. For example:

```
// Break out of the inner loop when $units == 5
for ($tens = 0; $tens < 10; $tens++) {
  for ($units = 0; $units < 10; $units++) {
    if ($units == 5 ) break 1;
    echo $tens . "<br />";
  }
}
```

```
// Break out of the outer loop when $tens == 5
for ($tens = 0; $tens < 10; $tens++) {
  for ($units = 0; $units < 10; $units++) {
    if ($units == 5 ) break 2;
    echo $tens . "<br />";
  }
}
```
