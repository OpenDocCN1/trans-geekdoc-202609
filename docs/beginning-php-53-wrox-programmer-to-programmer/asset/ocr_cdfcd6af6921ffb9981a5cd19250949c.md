# Try It Out Create a Multi-Step Form

You can use hidden fields to create a series of forms that guide the user through the entry process step by step. Within each form, you can store the current step — so the script knows what stage the user has reached — as well as the data entered by the user in other steps.

Here's an example that splits the registration.php form into three steps:

+   - First name/last name
- Gender/favorite widget
- Newsletter preference/comments

Save the following script as registration_multistep.php in your document root folder and run the script in your Web browser. Try filling in some values and using the Back and Next buttons to jump between the steps. Notice how the field values are preserved when you return to a previously completed step. Figure 9-8 shows the first step of the form, and Figure 9-9 shows the second step.
