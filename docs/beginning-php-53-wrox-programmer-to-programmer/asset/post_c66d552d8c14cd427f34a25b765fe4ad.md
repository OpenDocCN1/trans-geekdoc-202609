## Accessing Characters within a String

You might be wondering how you can access the individual characters of a string. PHP makes this easy for you. To access a character at a particular position, or index, within a string, use:

```
$character = $string[index];
```

In other words, the index between square brackets accesses the string variable name. String starts from 0, so the first character in the string has an index of 0, the second has an index of 1, and so on. You can both read and change characters. Here are some examples:

```
$myString = "Hello, world!";
echo $myString[0] . "<br/>"; // Displays 'H'
echo $myString[7] . "<br/>"; // Displays 'w'
$myString[12] = '?';
echo $myString . "<br/>"; // Displays 'Hello, world?'
```

If you need to extract a sequence of characters from a string, you can use PHP's substr() function. This function performs the following:

- The string to extract the characters
- The position to start extracting the characters. If you use a negative number, substr() counts backward from the end of the string
- The number of characters to extract. If you use a negative number, substr() misses that many characters from the end of the string instead. This parameter is optional; if left out, substr() extracts from the start position to the end of the string

Here are a few examples of how to use substr():

```
$myString = "Hello, world!";
echo substr($myString, 0, 5) . "<br/>"; // Displays 'Hello'
echo substr($myString, 7) . "<br/>"; // Displays 'world'
echo substr($myString, -1) . "<br/>"; // Displays '!'
echo substr($myString, -5, -1) . "<br/>"; // Displays 'orld'
```

You can't modify strings within using substr(). If you need to change characters within a string, use substr_replace() instead. This function is described later in the chapter.

## Searching Strings with strstr()

If you just want to find out some texts within a string, use strstr(). This takes two parameters: the string to search through, and the search text. If the text is found, strstr() returns the portion of the string from the start of the found text to the end of the string. If the text isn't found, it returns false. For example:

```
$myString = "Hello, world!";
echo strstr($myString, "wor") ? "<br/>"; // Displays 'world!'
echo (strstr($myString, "xyz") ? "Yes" : "br/>"); // Displays 'No'
```

As of PHP 5.3, you can also pass an optional boolean argument. The default value is false. If you pass a value of true, strstr() instead returns the portion from the start of the character before the found text:

```
$myString = "Hello, world!";
echo strstr($myString, "wor", true ); // Displays 'Hello, world'
```

## Locating Text with strstr() and strpos()

To find out a string of text within another string, use strpos(). This function takes the same two parameters as strstr(): the string to search, and the search text to look for. If the text is found, strpos() returns the index of the first character of the text. If it's not found, strpos() returns false:

```
$myString = "Hello, world!";
echo strpos($myString, "wor") // Displays '7'
echo strpos($myString, "xyz") // Displays (false)
```

```
$myString = "Hello, world!";
if ( strpos($myString, "Hel") ) echo "Not found";
```

If you need to test for a false return value, if that's what you're checking for. The following code works:

```
$myString = "Hello, world!";
if ( strpos($myString, "Hel") === false ) echo "Not found";
```

## Finding the Number of Occurrences with substr_count()

Occasionally you might need to know how many times text occurs within a string. For example, if
you were writing a simple search engine, you could search a string of text for a keyword to see how
relevant the text is for that keyword; the more occurrences of the, the greater the chance that the
text is relevant.

You could find the number of occurrences easily enough using strpos() and a loop, but PHP, as most other things, gives you a function to do the job: substr_count(). To use it, simply pass the string and the text to search for, and the function returns the number of times the text was found in string.

```
$myString = "I say, nay, nay, and thrice nay!";
echo substr_count($myString, "nay"); // Displays '3'
```

You can also pass an optional argument to specify the index position to search, and an optional fourth to indicate how many characters the function should search before giving up. Here are some examples that you use these third and fourth arguments:

```
$myString = "I say, nay, nay, and thrice nay!";
echo substr_count($myString, "nay") . "<br/>"; // Displays '2'
echo substr_count($myString, "nay", 9, 6) . "<br/>"; // Displays '1'
```

## Searching for a Character with strbrk()

If you need to find out if a string contains any of set characters (for example, you might want to make sure a submitted form field does not contain characters for security reasons). PHP gives you a function, strbrk(), that lets you easily carry such a search. It takes two arguments: the string to search, and a string containing the list of characters to search for. The function returns the portion of the string from the first matched character to the end of. If none of the characters are set in the string, strbrk() returns false.

Here are some examples:

```
$myString = "Hello, world!";
echo strbrk($myString, "abcdef"); // Displays 'ello, world!'
```

## Replacing Text Within Strings

As well as able to search for text within a larger string, you can also replace portions of a string with different text. This section discusses three useful PHP functions for replacing text:

- str_replace() replaces all occurrences of the search text within the target string
- substr_replace() replaces a specified portion of the target string with another string
- str_replace() replaces certain characters in the target string with other characters
