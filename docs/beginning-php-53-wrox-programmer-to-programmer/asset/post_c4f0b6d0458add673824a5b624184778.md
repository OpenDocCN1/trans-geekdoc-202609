# Translating Characters with strtr()

A common requirement — especially with Web programming — is able to replace certain characters in a string with certain other characters. For example, you might want to make a string "URL friendly" by replacing spaces with (plus) and apostrophes with (hyphen) symbols.

This is where strtr() comes in. this function takes three arguments: the string to work on, a list of characters to translate, and a string containing the characters to use instead. The function returns a translated copy of the string. So you could write a simple script to make a "URL friendly" string as:

```php
$myString = "Here-s+a+little+string";

// Displays "Here-s-little-string"
echo strtr($myString, "+", "-") . "<br/>";
```

strtr() is especially useful if you need to translate a string from one character to another, because you can easily map hundreds of characters to their equivalents in the new character set by passing a couple of strings.

You can also use strtr() to replace strings with strings, rather than characters. To do this, pass just two arguments: the string to work on, and an array of key/value pairs, where each key is the string to search for and each corresponding value is the string to replace it with. # Dealing with Upper- and Lowercase

Most Western character sets have a concept of upper- and lowercase letters. PHP converts strings between upper- and lowercase in a variety of ways.

# Part II: Learning the Language

To convert a string to all lowercase, `strtolower()`. This function takes a string to convert, and returns a converted copy of the string:

```php
$String = "Hello, world!";
echo strtolower($String); // Displays 'hello, world!'
```

Similarly, you can `strtoupper()` to convert a string to all uppercase:

```php
$String = "Hello, world!";
echo strtoupper($String); // Displays 'HELLO, WORLD!'
```

ucfirst() makes just the first letter of a string

```php
$String = "hello, world!";
echo ucfirst($String); // Displays 'Hello, world!'
```

lcfirst() — introduced in PHP 5.3 — makes the first letter of a string lowercase:

```php
$String = "Hello, World!";
echo lcfirst($String); // Displays 'hello, World!'
```

Finally, ucwords() makes the first letter of each word in a string:

```php
$String = "hello, world!";
echo ucwords($String); // Displays 'Hello, World!'
```

Speaking of upper- and lowercase, most of the search and replacement functions described earlier in the chapter are `case-sensitive`. This means they'll only match letters of the same case. For example:

```php
$String = "Hello, world!";

// Displays "Not found"
if ( strpos($String, "hello") )
    echo "Found";
else
    echo "Not found";
```

However, PHP has `case-insensitive` versions of many string functions, which means they'll work even if the strings don't match. For example, a case-insensitive version of `strpos()`,

```php
$String = "Hello, world!";

// Displays "Found"
if ( strpos($String, "hello") )
    echo "Found";
else
    echo "Not found";
```

# Formatting Strings

Often, a script's internal representation of a string can look fairly ugly or unreadable to a person using the script. For example, "$143,834.12" is much easier to understand than "143834.12". Fortunately, PHP gives you a number of functions that you can use to format strings in ways that are human friendly. In this section you explore some of the more common string formatting functions in PHP.

# General-Purpose Formatting with printf() and sprintf()

printf() and its close cousin, sprintf() — are powerful functions that you can use to format strings in all of different ways. printf() takes a string argument called a format string, usually followed by one or more arguments containing the string or strings to format. It outputs the result.

The format string contains ordinary text interleaved with one or more conversion specifications. The conversion specification requires an additional argument to be passed to printf(), and it formats the argument as required and inserts it into the format string. The resulting formatted string is displayed. Conversion specifications always start with a (% ) symbol.

This probably sounds a little overwhelming at first glance, here's a simple example to illustrate

```php
// Displays PI rounded to a whole number is 3
printf("PI rounded to a whole number is: %d", M_PI);
```

In this example, "PI rounded to a whole number is: %d" is the format string, and the "%d" within it is a conversion specification. In this case, the conversion specification tells printf() to read an additional argument and format it, as a decimal number. The additional argument is the PHP constant M_PI, which represents an approximation of pi to a number of decimal places (14 by default). The set result of the function call is to print the format string with the "%d" replaced by the value of pi rounded to a whole number.

Here's another example that uses multiple conversion specifications:

```php
// Displays 2 times 3 is 6.
printf("%d times %d is %d.", 2, 3, 2 * 3);
```

This code displays different numbers within the output string: 2, 3, and the result of the expression 2 * 3.

# Using Type Specifiers

The d in the conversion specification, "%d", is called a type specifier; it tells printf() to format the argument as a decimal integer. You can format in other ways using different type specifiers, as follows:

| Type Specifier | Meaning |
| --- | --- |
| b | Treat the argument as an integer and format it as a binary number. |
| c | Treat the argument as an integer and format it as a character with that ASCII value. |
| d | Treat the argument as an integer and format it as a signed decimal number. |
| e | Format the argument in scientific notation (for example, 3.45e+2). |
| f | Format the argument as a floating-point number, taking into account the current locale settings (for example, many European locales use a comma for the decimal point, rather than a period). |
| F | Format the argument as a floating-point number, ignoring the locale settings. |
| o | Treat the argument as an integer and format it as an octal number. |
| s | Format the argument as a string. |
| u | Treat the argument as an integer and format it as an unsigned decimal number. |
| x | Treat the argument as an integer and format it as a lowercase hexadecimal number. |
| X | Treat the argument as an integer and format it as an uppercase hexadecimal number. |
| % | Display a literal (%) symbol. This doesn't require an argument. |

Here's an example that displays the same argument — 123.45 — different type specifiers:

# Specifying Signs

By default, printf() displays negative numbers with a minus ( ) symbol in front of them, but doesn't put a plus (+ ) symbol in front of positive numbers. To change printf() 's behavior so that it always displays a sign, use the sign specifier, +, in front of the type specifier. Here's an example:

```php
printf( "%d<br>", 123 ); // Displays "123"
printf( "%d<br>", -123 ); // Displays "-123"
printf( "%+d<br>", 123 ); // Displays "+123"
printf( "%+d<br>", -123 ); // Displays "-123"
```
