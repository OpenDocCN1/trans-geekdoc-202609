Next, create a photos folder in the same directory as your Web server (the document root). This folder is to store the uploaded photos. You will need to give your Web server the ability to create files in this folder. On Linux or Mac OS you can do this in a Terminal window as follows:

```
cd /path/to/document/root
chmod 777 photos
```
