This chapter does not go into the ins and outs of XSLT — many other good books on the subject are available — but the example should be fairly self-explanatory. Essentially it creates an unordered list (li) element inside an XHTML document, and then it displays all the list elements in the XML document using `<xsl:apply-templates select="*">`.

Meanwhile, the `<xsl:template match="*">` rule formats each element. It creates a list item (li) element, and then defines a definition list (dl), displaying each field inside the XML element as an item definition list. Note the use of `<xsl:value-of select="element">` to display the quantity and unitPrice in the opposite order to the XML document, and also adds extra text to the dollar ($) to the final page. Such is the flexibility of XSLT.

Now you have an XML document, and an XSL style to transform it. You can now use PHP’s XSLTProcessor to apply the style to the document, converting it into an easy-to-read XHTML Web page. Here is the code to do that:

```
php
$doc = new DOMDocument();
$proc = new XSLTProcessor();

$doc->load('./stock_list_to_xhtml.xslt' );
$proc->importStyleSheet($doc);

$doc->load('./stock_list.xml' );
echo $proc->transformToXML($doc);

?
```

As you can see, it's pretty easy to use XSLTProcessor. The first line creates a new DOMDocument object, $doc, and the second creates a new XSLTProcessor object, $proc. The next, loads the XSLT sheet into the $doc object, then imports it into the XSLTProcessor object, $proc, using the importStyleSheet() method of the XSLTProcessor class.

Now that the XSLTProcessor object has been primed with the sheet, the stock_list.xml file into the $doc DOMDocument object. This overwrites the XSLT sheet that was previously in the $doc object, but that's all the script no longer needs.

Finally, the script calls the proc object’s transformToXML() method, passing the DOMDocument object containing stock list data. As you probably guess, this does the actual XSLT transformation, applying the style to the XML data to produce the new XHTML page, which is then displayed in the browser.

To see this in action, save it as xs_transform.php in your document root folder, and visit the URL in your Web browser. You should see a nicely formatted XHTML page similar to Figure 19.
