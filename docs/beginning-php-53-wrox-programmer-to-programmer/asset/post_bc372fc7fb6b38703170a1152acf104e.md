
## Part III: Using PHP Practice

| Digit Value | Permission |
|---|---|
| 3 | Can write to and execute the file |
| 4 | Can only read the file |
| 5 | Can read and execute the file |
| 6 | Can read and write to the file |
| 7 | Can read, write to, and execute the file |

Here are some commonly used examples to make the concept of file modes clearer:

```php
// Owner can read and write the file; everyone else can just read it:
chmod("myfile.txt", 0644 );

// Everyone can read and write the file:
chmod("myfile.txt", 0666 );

// Everyone can read and execute the file, but only the owner can write to it:
chmod("myfile.txt", 0755 );

// Only the owner can access the file, and they can only read and write to it:
chmod("myfile.txt", 0600 );
```

> Note that you can only change the permissions of a file or directory if you own it, or if you're the superuser (which is highly useful for PHP scripts running on a Web server).

So how modes work with directories? Well, to read the files in a directory, you need to have both read and execute permissions on that directory. Meanwhile, to create and delete files and subdirectories inside the directory, you need to have write and execute permissions on the directory.

## Checking File Permissions

Before you're allowed to read a file, it is useful to know what kinds of things your script can do with the file. PHP provides three handy functions to help you out.

To check if you're allowed to read a file, use is_readable(), passing the filename of the file to check. Similarly, you can check that you're allowed to write to a file with is_writable(), and see if you can execute a file with is_executable(). Each function returns true if the operation is allowed, or false if it's disallowed.

```php
if ( is_readable("myfile.txt") ) {
    echo "I can read myfile.txt";
}

if ( is_writable("myfile.txt") ) {
    echo "I can write to myfile.txt";
}

if ( is_executable("myfile.txt") ) {
    echo "I can execute myfile.txt";
}
```

You can also use the fileperms() function to return an integer representing the permissions that are set on a file or directory. For example, to print the permissions of a file you might use:

```php
chmod("myfile.txt", 0644);
echo substr(sprintf("%o", fileperms("myfile.txt")), -4); // Displays 0644
```

(The call to substr()) is used to return just the last four digits)

## Copying, Renaming, and Deleting Files

PHP lets you copy, rename, and delete files. The functions to perform these operations are copy(), rename(), and unlink(), respectively.

The copy() function takes two string arguments: the first is the path to the file to copy, and the second is the path to copy to. It returns true if the file was successfully copied, false if there was a problem copying the file. The following example copies the source file copy.txt to the destination file copied.txt in the same folder:

```php
copy("./copy.txt", "./copied.txt");
```

The rename() function is used to rename (move) a file. It works in much the same way as copy(). For example, to rename a file within a folder you could:

```php
rename("/address.dat", "./address.backup");
```

To move a file to a directory, you might use:

```php
rename("/home/joe/myfile.txt", "/home/joe/archives/myfile.txt");
```

The unlink() function lets you delete files from the server. To use it, pass the filename of the file you want to delete. For example, if you wanted to say adios to the file trash.txt in the current directory, you could write:

```php
unlink("/trash.txt");
```

copy(), rename(), and unlink() raise warning-level errors if the file or directory isn't found. Make sure the file or directory exists first (for example, by using file_exists()) to avoid such errors.

## Working with Directories

PHP lets you work with directories the same way as files, using a variety of equivalent functions. Some directory functions use a directory handle, others use a string containing the name of the directory with which you want to work. A directory handle is similar to a file handle; it's a special pointer to directory, which you can obtain via the opendir() function:

```php
$handle = opendir("/home/james");
```

If there's a problem opening the directory (for example, if the directory doesn't exist), opendir() returns false instead of the directory handle. As you may have guessed, you can close a directory by passing the directory handle to the function closedir():

```php
closedir($handle);
```

The readdir() function expects a directory handle for an opened directory, and returns the filename of the next entry in the directory:

```php
$filename = readdir($handle);
```

Each directory contains a list of entries for each of the files and subdirectories inside it, as well as entries for . (representing the directory) and .. (the parent of directory). PHP maintains an internal pointer referring to the next entry in the list, just as a file handle.

### Try It Out

Each directory contains a list of entries for each of the files and subdirectories inside it, as well as entries for . (representing the directory) and .. (the parent of directory). PHP maintains an internal pointer referring to the next entry in the list, just as a file handle.

Here's how to list the entries in a directory:

```php
<!DOCTYPE html>
<html>
<head>
  <title>Listing the contents of a directory</title>
</head>
<body>
  <h1>Listing the contents of a directory</h1>
  <?php
  $dirPath = "/home/james";
  if (!($handle = opendir($dirPath))) {
    die("Cannot open the directory.");
  }
  <ul>
  <?php
  while ($filename = readdir($handle)) {
    if ($filename != "." && $filename != "..") {
      echo "<li>$filename</li>";
    }
  }
  closedir($handle);
  ?>
  </ul>
</body>
</html>
```
