The addRule() function uses the addRule method to add validation rules to the fields of the form. All required fields are checked against the required rule, and the alphanumeric rule is used on the username and password fields to make they contain only letters and/or digits. In addition, the compare rule is used to check that both password fields contain the same value:

```
$form->addRule(array("password1", "password2", "Please make sure you
enter your password correctly in both password fields.", "compare");
```

The email field is, of course, checked using the email rule. The remaining fields --nfirstName, lastName, genre, favoriteGenre, and otherinterests -- are checked against various regular expressions using the regex rule.

For interest we create thefavoriteGenre. This creates a temporary $member object and calls its getGenres() method to retrieve the associative array of allowed genres. It then extracts the genre values with PHP's array_keys() function (which returns an index containing all the keys in a given array), and uses the implode() function to turn the resulting array into a string of |-separated values for plugging into the regular expression:

```
$member = new Member(array());
$form->addRule("favoriteGenre", "The Favorite Genre field can contain only
allowed genre values", "regex", . implode("|", array_keys($member\ngetGenres()) ) . \$/);
```
