## Checking Date Values

Open a script to work with dates that have been entered by visitors to the site. For example, a Web form might contain select allowing visitors to enter the month, day, and year of birth. However, in this scenario there's nothing to stop the visitors entering a date that doesn't exist, such as February 31, 2009. Obviously it would be a good idea to validate the date fields entered by the users to make sure they have supplied a legitimate date.

PHP's checkdate function takes the month (1–12), day number (1–31), and year components of a date, and returns true if the date is valid, or false if it's invalid:

```php
echo checkdate(2, 31, 2009) . "<br />"; // Displays "false"
echo checkdate(2, 28, 2009) . "<br />"; // Displays "1" (true)
```

It's a good idea to call checkdate() on any user-entered date before passing it to, say, microtime() for conversion to timestamp.

## Working with Microseconds

The date and time functions you've seen so far in this chapter work with integer timestamps—that is, timestamps representing numbers of seconds. Most of the time this is all you need. If you need extra precision, use PHP's microtime() function. With time(), microtime() returns a timestamp representing the current time, allowing you to determine the current time more precisely:

```php
// Displays, for example, "0.45968200 1230613358.46"
echo microtime();
```

As you can see, microtime() returns a string consisting of two numbers separated by a space. The first number is the number of microseconds component, represented as a fraction of a second, and the second number is the whole number of seconds—that is, the standard integer timestamp. So the example shown in the preceding code snippet represents 1,230,613,358.459682 seconds after midnight, Jan 1, 1970 (UTC).

If you prefer, you can get microtime() to return a floating-point of seconds, rather than a two-number string, by passing in an argument of true:

```php
// Displays, for example, "1230613358.46"
echo microtime(true);
```

# Part III: Using PHP Practice

Note that using echo() only displays the number of seconds to two decimal places. To see the floating-point number more precisely, you can use printf():

```php
// Displays, for example, "1230613358.459682"
printf("%0.6f", microtime(true));
```

One common scenario where microtime() value is before and useful when benchmarking your code to find speed bottlenecks, and after subtracting one value from the other, you can find how long the operation took to execute. Here's an example:

```html
<!DOCTYPE html PUBLIC "//W3//DTD HTML 1.0 Strict//EN"
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>Timing script execution</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
  <h1>Timing script execution</h1>
  <?php
  // Start timing
  $startTime = microtime(true);

  // Perform the operation
  for ($i=0; $i<10; $i++) {
    echo "<p>Hello, world!</p>";
  }

  // Stop timing
  $endTime = microtime(true);
  $elapsedTime = $endTime - $startTime;
  printf("<p>The operation took %0.6f seconds to execute.</p>", $elapsedTime);
  ?>
</body>
</html>
```

## Try Out Calculate Your Age in Days

You can use your knowledge of PHP’s date handling functions to write a script that calculates the user's age in days. The script presents a form asking the user to input his or her date of birth, then calculates the difference (in days) between this date and the current date.

Save the script as days_old.php in your document root folder. Because the script uses the HTML_QuickForm and HTML_QuickForm_Renderer_Tabeless PEAR packages, make sure you install them as well. You can find detailed information on installing these packages in the previous chapter.

```html
<!DOCTYPE html "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/html1/DTD/html-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
  <title>many days old are you?</title>
  <link rel="stylesheet" type="text/css" href="common.css" />
  <style type="text/css">
    .error { background: #333; color: white; padding: 0.2em; margin: 0.2em 0 0em; font-size: 0.9em; }
    fieldset { border: none; }
    ol [list-style-type: none; }
    input, select, textarea { float: none; margin: 1em 0 0 0; width: auto; }
    div.element { float: right; width: 57%; }
    div.element label { display: inline; float: none; }
    select { margin-right: 0.5em; }
  </style>
span.required { display: none; }
</style>
</head>
<body>
<h1>How many days are old you?</h1>
<?php
require_once("HTML/QuickForm.php");
require_once("HTML/QuickForm/Renderer/Tableless.php");
$form = new HTML_QuickForm("form", "days_old.php", "",
array("style" => "width:30em;", true));
$form->removeAttribute("name");
$form->setRequiredNote("");
$opt->addAttribute(format => "MDY", "minYear" => 1902, "maxYear" => date("Y"));
$form->addAttribute("dateOfBirth", "Your date of birth");
$form->addAttribute("submit", "Calculate");
$form->addRule("dateOfBirth", "Please enter a valid date", "callback", checkdate);

if ($form->isSubmitted() && $form->validate()) {
$renderer = new HTML_QuickForm_Renderer_Tableless();
$form->accept($renderer);
echo $renderer->toHtml();
}

function checkdate($value) {
$currentDate = mktime();
$dateOfBirth = mktime(0, 0, 0, $value["M"], $value["d"], $value["Y"]);
$secondsOld = $currentDate - $dateOfBirth;
$daysOld = (int) ($secondsOld / 60 / 24);
echo "<p>You were born " . date("j S, Y", $dateOfBirth) . ".</p>";
echo "<p>You are " . number_format($daysOld) . " day" . ($daysOld != 1 ? "s " : " ") . "old.</p>";
}
?>
</body>
</html>
```

## How It Works

This script demonstrates how use PHP date functions, as well as some advanced features of the HTML_QuickForm PEAR package. First the script outputs the XHTML page header, linking to the common style sheet, common.css (from Chapter 2), and including extra CSS rules to style the form.

The PHP code begins by including the two PEAR packages, creating a new HTML_QuickForm object. This form uses the HTTP get method and sends its data to the same script (days_old.php). The form's trackSubmit property is also set to true so the script can detect when the form has been submitted:

```php
require_once("HTML/QuickForm.php");
require_once("HTML/QuickForm/Renderer/Tableless.php");
$form = new HTML_QuickForm("form", "days_old.php", "",
array("style" => "width:30em;", true));
```

A couple more properties of the $form object are then set. The form's name attribute is removed, in order to make the markup HTML-compliant, and the "* denotes required field" is not disabled, because the form has only one field next to the field label is hidden by the span.required CSS rule at the top of the script:

```php
$form->removeAttribute("name");
$form->setRequiredNote("");
```
