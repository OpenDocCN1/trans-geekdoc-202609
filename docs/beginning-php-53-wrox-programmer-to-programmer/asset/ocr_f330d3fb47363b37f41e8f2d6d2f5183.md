5. Add passwords for the root users — Type the following lines, replacing mypass with the password you want to use and mattcomputer with the host name of your computer (shown in the Host column in the table), and pressing Enter after each line:

```
SET PASSWORD FOR 'root'@'localhost' = PASSWORD('mypass');
SET PASSWORD FOR 'root'@'mattcomputer' = PASSWORD('mypass');
SET PASSWORD FOR 'root'@'127.0.0.1' = PASSWORD('mypass');
```

You only need to enter the lines that correspond to the root entries shown in the table. For example, if your table doesn't include the line with the 127.0.0.1 host, you can omit the third PASSWORD line.

Make sure you choose a secure password. At a minimum, this should be at least 7 characters long, and contain a mixture of letters and numbers.

6. Check that the passwords have been set — RETYPE the SELECT line from 4 and press Enter. You should see that the root users have their password columns sets:

| Host | User | Password |

| 127.0.0.1 | root | *D8DECEC10529EEFEC43008E1D420E1AA06B19E0 |
| localhost | | |
| mattcomputer | | |

7. Exit the MySQL command-line tool — Type exit and press Enter to return to the shell prompt.

Now that you've added a password for the root account, your MySQL server is relatively secure. To test the new password, run the mysql command again, but add a -p (hyphen followed by *) to the end of the command, as:

```
mysql -u root -p   # Ubuntu, Windows
./mysql -u root -p   # Mac OS X
```

MySQL will prompt you for the root password that you previously entered. Type it now, then press Enter. If all goes well you should be back at the mysql> prompt. Type exit and press Enter to exit the program.

You can now use this root user to create and work with databases in your MySQL system. This is for development and testing purposes, you should not use the root user to connect to your MySQL database. Though this is for a development server, a live server. Instead, create a new MySQL user that has only the privileges that your scripts need (If you're running your site on a shared server, your hosting company will probably give you a username and password to use.)
