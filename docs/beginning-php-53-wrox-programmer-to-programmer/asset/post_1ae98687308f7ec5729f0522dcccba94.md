At the time of writing, these classes were relatively experimental and not feature-complete; however, they are already useful. They provide a number of advantages over the traditional PHP date and time functions, including:

- Elegant handling of time zones
- The ability to store and handle dates before 1901 and 2038
- Easier date manipulation

For example, the following code creates a new DateTime object representing the 13th Feb 1948 in the Los Angeles time zone, then subtracts three months from the date, displaying the result:

```php
$dt = new DateTimeZone("America/Los_Angles");
$dt = new DateTime("13-Feb-1948", $dt);
$dt->modify("-3 months");

// Displays "Thu, 13 Nov 1947 00:00:00 -0800"
echo $dt->format(DateTime::RFC2822);
```

The first code creates a new DateTime object representing the Los Angeles time zone, then it creates a new DateTime object representing 13th Feb 1948 in that time zone. The next code calls the DateTime object's modify() method. This very handy method accepts a modification string in the same format as strtotime() and adjusts the date and time correctly.
