# # Part I: Getting Up and Running with PHP

+   > Perl was one of the first languages used for creating dynamic Web pages, initially through the use of CGI scripting and later, integrating tightly with Web servers with technologies like the Apache mod_perl module and ActivePerl While Perl is a powerful scripting language, it's harder to learn than PHP. It's also more of a general-purpose language than PHP, although Perl's CPAN library includes excellent modules for Web development.

+   > Java: Like Perl, Java is another general-purpose language that is commonly used for Web development. Technologies like JSP (JavaPages) and servlets, Java is a great platform for building large-scale, robust Web applications. With such software as Apache Tomcat, you can easily build and deploy Java-based sites on virtually any server, including Windows, Linux, and FreeBSD. The downside of Java compared to PHP is that it has a steep learning curve, you have to write a fair bit of code to get even a simple Web site going (though JSP helps a lot in this). In contrast, PHP is a simpler language to learn, and it's quicker to get a basic site up and running with PHP. Another drawback of Java is that it's harder to find a Web hosting company that will support JSP, nearly all hosting companies offer PHP.

+   > Python: Created in the late 1990s, Python is another general-purpose programming language that is now commonly used to build dynamic Web sites. Although it doesn't have much in the way of Web-specific features but many useful modules and frameworks, such as Zope and Django, are making Web applications relatively painless. Popular sites like Google and YouTube are built using Python, and Python is starting to become more common (though it's not nearly as common as PHP hosting). You can even build and host your Python apps on Google's server with Google Engine. Python is very powerful, but PHP is currently a lot more popular, and has a lot more built-in functionality to help with Web sites.

+   > Ruby: Like Python, Ruby is another general-purpose language that has gained a lot of traction with Web developers in recent years. This is largely due to the extent on Rails application framework, which uses the Model-View-Controller (MVC) pattern, along with Ruby's extensive object-oriented programming features, to make it easy to build a complete Web application very quickly. As with Python, Ruby is becoming a popular choice among Web developers, but for now, PHP is more popular.

+   > ColdFusion: With ASP, ColdFusion is one of the first Web frameworks available, initially released in 1995. ColdFusion's main selling points are that it's easy to learn, it lets build Web applications very quickly, and it's really easy to create database-driven sites. An additional plus is its tight integration with Flex, another Adobe technology that allows you to build complex Flash-based Web applications. ColdFusion's disadvantages compared to PHP include the fact that it's not as popular (so it's harder to find hosting and developers), it's not as flexible as PHP for certain tasks, and the server software to run your apps can be expensive (PHP and Apache are, free, and open source.)

In summary, PHP occupies something of a middle ground when it comes to Web programming languages. On the one hand, it's not a general-purpose language like Python or Ruby (although it can be used as one). This makes PHP highly suited to its main job: building Web sites. On the other hand, PHP doesn't have a complete Web application framework like ASP.NET or Ruby on Rails, meaning that you're left to build your Web sites "from the ground up" (or add-on extensions, libraries, and frameworks).
