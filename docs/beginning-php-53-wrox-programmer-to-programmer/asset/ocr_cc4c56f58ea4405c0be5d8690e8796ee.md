# Padding Strings with str_pad()

You've already seen how you can use printf() to add padding to the beginning or end of a string. However, PHP has a dedicated function, str_pad(), that is both more flexible than the printf() approach and easier to work with.

To use str_pad(), pass the string to be padded, and the desired width of the final string. The function returns the string padded on the right using space characters (by default):

```

```

To use characters other than space, pass a string to use as an optional third argument. Note that this can be either a single character or a string of characters; in the latter case, the string is repeated as needed to pad the output string:

```
// Displays "Hello, world!*****"
echo str_pad("Hello, world!", 20, "*\*") . "\n";
```

```
// Displays "Hello, world!1231231"
echo str_pad("Hello, world!", 20, "123") . "\n";
```

You can also make str_pad() add padding to the left of the string, or to both the left and the right of the string. To do this, pass an optional fourth argument comprising of the built-in constants:

+   - STR_PAD_RIGHT to pad the string on the right (the default setting), left-aligning the string
- STR_PAD_LEFT to pad the string on the left, right-aligning the string
- STR_PAD_BOTH to pad the string on both the left and the right, centering the result as possible

# Wrapping Lines of Text with wordwrap()

Sometimes you need to display a large amount of text to a user, such as in a Web page or in an email message.
