# Part III: Using PHP Practice

Next, you took a closer look at the SQL SELECT statement. You learned how to use LIMIT to restrict the number of rows returned from a query, and how to sort the rows of a result set using the ORDER clause. You saw how to make queries more flexibly by using the LIKE and NOT LIKE operators, and how to use functions such as count(), sum(), min(), max(), and avg() to summarize columns in table

Duplicate rows can be a problem in result sets, and you saw how to solve this by using the DISTINCT keyword. You also learned how to group results by a specified column or columns through the use of GROUP BY

One of the advantages of a relational database is that you can pull data from one table at a time — a process known as joining tables. You learned how to do this, and how to use aliases to make both queries and result sets more readable

To round off on SELECT queries, you explored few of the myriad MySQL operators and functions that you can use to add even power to your queries

In the second half of the chapter you will build a member viewer application that was capable of listing all the members in the fictional book club database, as well as viewing detailed information about each member. In the process you worked with classes, you saw how to create classes to deal with database access, using some most useful features of PDO as prepared queries, and discovered how to use MySQL SQL_CALC_FOUND_ROWS keyword to help you display table contents over several pages.

You now have a solid foundation on how to construct queries and communicate with MySQL from your PHP scripts. The next chapter takes things further and looks at how to manipulate data in a database from PHP.

Meanwhile, try the following two exercises, which test both your SQL query skills and your PHP programming skills. You can find the solutions to these exercises in Appendix A.
