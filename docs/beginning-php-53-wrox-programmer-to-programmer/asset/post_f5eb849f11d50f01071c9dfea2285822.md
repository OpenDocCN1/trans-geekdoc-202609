It is worth pointing out that having a complex loop expression can seriously slow down your script, because the test expression is evaluated every single time the loop repeats. In the example just shown, the expression needs to be processor-intensive because it has to retrieve the current time — an ever-changing value. However, generally it's better to pre-compute much of the test expression as you enter the loop. For example:

```php
$secondsInDay = 60 * 60 * 24;
for ($seconds = 0; $seconds < secondsInDay; $seconds++ ) {
    // Loop body here
}
```

is generally going to be a bit faster than:

```php
for ($seconds = 0; $seconds < 60 * 60 * 24; $seconds++) {
    // Loop body here
}
```

You can actually leave out of the expressions within a for statement, as long as you keep the semicolons. Say you've already initialized a variable called $i elsewhere. Then you could miss out the initializer for the loop, as follows:

```php
for (; $i <= 10; $i++) {
    // Loop body here
}
```

You can even leave out all three expressions if you so desire, creating an infinite loop:

```php
for (; ; ;);
```

Of course, such a loop is pretty pointless unless you somehow exit the loop in another way! Fortunately, you can use the break statement — discussed in the next section — to just do that.

## Part II: Learning the Language

## Escaping from Loops with the break Statement

Normally, a while, do while, or for loop will continue looping as long as its test expression evaluates to true. However, you can exit a loop at any point while the loop's executing by using the break statement. This works just like a switch construct (described earlier in this chapter) — it exits the loop and moves to the first line of code outside the loop.

Why would you want to do this? Well, in many situations it's useful to break out of a loop. The infinite for loop discussed earlier is a good example; if you don't break out of an infinite loop somehow, it will just keep running and running, consuming resources on the server. For example, although the following loop is ostensibly an infinite loop because its test expression is always true, in fact it counts to 10 and then exits the loop:

```php
$count = 0;
while ( true ) {
    $count++;
    echo "I've counted to: $count<br />";
    if ($count == 10 ) break;
}
```

Another reason to break out of a loop is that you want to exit the loop prematurely, because you've finished processing whatever you need to do. Consider the following tricky example:

```php
$randomNumber = rand(1, 1000);

for ($i=1; $i <= 1000; $i++) {
    if ($i == $randomNumber) {
        echo "Hooray! I guessed the random number. It was: $i<br />";
        break;
    }
}
```

This code uses PHP rand() function to generate and store a random integer between 1 and 1000, loops from 1 to 1000. Once it's the number, it displays a success message and exits the loop with break. Note that you could omit the break statement and the code would still work; however, there's no point in continuing once the number has been guessed, using break to exit the loop avoids processor time.

This type of break statement usage is common when working with potentially large sets of data such as arrays and database records, as you see later in this book.

## Skipping Loop Iterations with the continue Statement

Slightly drastic than the break statement, continue lets you prematurely end the current iteration of a loop and move to the next iteration. This can be useful if you want to skip the current item of data you're working; maybe you don't want to change or use that data item, or maybe the data item can be used for some reason (for example, if it would cause an error).

The following example counts from 1 to 10, but it misses out the number 4 (which is considered unlucky in many Asian cultures):

```php
for ($i=1; $i <= 10; $i++) {
  if ($i == 4 ) continue;
  echo "I've counted to: $i<br />";
}
echo "All done!";
```

Though break and continue are useful beasts when you need them, it's best not to use them unless you have to. They can make looping code quite hard if they're overused.

## Creating Nested Loops

There's nothing to stop a loop inside another. In fact, this can be quite a useful technique. When you nest one loop inside another, the inner loop runs through its iterations for each iteration of the outer loop. Here's a simple example:

```php
for ($i=1; $i <= 3; $i++) {
    for ($j=1; $j <= 3; $j++) {
        echo "i=$i, j=$j\n";
    }
}
```
