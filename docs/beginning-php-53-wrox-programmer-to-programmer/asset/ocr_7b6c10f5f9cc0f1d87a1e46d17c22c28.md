To test these methods, the script then creates a new $myCar object, and sets five properties. Similarly, the fifth property, $otherColors, also doesn't exist in the class, so __set() is called, creating an array in $_extraData with a key of "otherColors" that are stored in the private value, which in this case is an array containing the strings "green", "blue", and "purple".

Next, the script displays the values of some of the properties of the $myCar object. Notice that, to the calling code, the $engineSize property is "real" as the $engineSize property doesn't exist in the class. The script also tries to retrieve the value of a property called $fuelType because it doesn't exist in the class or in the $_extraData array, the __get() method returns null to the calling code. This is why no value is displayed in the page.

Finally, the script dumps the contents of the $myCar object using print_r(). Notice that the extra "properties" — $engineSize and $otherColors — are the private $_extraData array. (You can see that print_r() displays properties inside an object, which is useful for debugging.)

Although the nonexistent properties were stored in a private array in this, they could easily have been stored in a file or database table, or passed via an API (application programming interface) to __get() and __set() to another application. This gives you some idea of the power of __get() and __set().

# Overloading Method Calls with __ __call()

Just as you can use __get() and __set() to handle reading and writing nonexistent properties, you can also use __call() to handle nonexistent methods of a class. Create a method named __call() in your class that accepts the nonexistent method name as a string, and any arguments passed to the nonexistent method as an array. The method should return a value (if any) back to the calling code:

```
public function __call($methodName, $arguments) {
    // (do stuff here)
    return $returnValue;
}
```

__call() is very useful if you want to create a "wrapper" class that doesn't contain functionality of its own, but stands off method calls to external functions or APIs for processing.
