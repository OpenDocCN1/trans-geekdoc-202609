# Part III: Using PHP Practice

SimpleMLElement object contains each of its element value properties, as well as the element's attributes as an associative array. This feature makes SimpleXML a very easy way to read and extract data from XML files. For example, if you wanted to display the unit price of beetroot, you would simply write:

```
echo $stockList->item[1]->unitPrice;
```

You can also use the xpath() method to search for elements in an XML document. This is great for finding a particular element within a large XML file, especially if you don't know the position of the element before. For example, the following code retrieves the unit price of beetroot, without needing to know that the "beetroot" is the second child of stockList:

```
$unitPriceElement =
$stockList->xpath("child:item[name=beetroot]/child::unitPrice");
echo $unitPriceElement[0];
```

The string passed to xpath() is known as an XPath string. Translated into English, this string says, "Get the child element item that itself contains a name child with the value beetroot, then retrieve the order of the item element. This returns a SimpleMLElement object that represents the unit price inside the "beetroot" item, which is stored in $unitPriceElement. It's then a simple case of displaying the first array value in $unitPriceElement, which is the text node you value (1.39).

XPath is a very powerful way of representing any node in XML as a string, but it takes some getting used to. You can read the full specification at http://www.w3.org/TR/xpath.
