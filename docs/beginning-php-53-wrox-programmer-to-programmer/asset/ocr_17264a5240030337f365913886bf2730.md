The next three functions — setValue(), setChecked(), and setSelected() — are identical to
counterparts in registration.php.

Next come the three functions to process the forms from each of the three steps.
processStep1() simply displays step 2:

```
function processStep1() {
    displayStep2();
}
```

processStep2() checks to see if the user clicked the Back button. If he, step 1 is redirected;
otherwise it's assumed the user clicked the Next button, so step 3 is displayed:

```
function processStep2() {
    if ( isset($_POST["submitButton"]) && \$_POST["submitButton"] ==
"Back") {
        displayStep1();
    } else {
        displayStep3();
    }
}
```

In a similar fashion, processStep3() displays step 2 if the Back button was clicked, or the thank-you
page if Next was clicked:

```
function processStep3() {
    if ( isset($_POST["submitButton"]) && \$_POST["submitButton"] ==
"Back") {
        displayStep2();
    } else {
        displayThanks();
    }
}
```
