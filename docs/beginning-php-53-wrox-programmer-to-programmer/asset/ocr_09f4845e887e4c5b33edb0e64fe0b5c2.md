By the way, you've probably spotted an obvious security flaw in this application: anybody can run the view_members.php and view_member.php script to view member information! In a real-world situation, you could do the following:

+   Place the view_members.php and view_member.php scripts inside the members' area, so you need to be logged in to use them.

+   Create an additional BIT field, admin, in the members table. A value of 1 for this field signifies that the member is a regular user.

+   From the view_members.php and view_member.php scripts, check the status of the admin field for the currently logged-in member. If it's set to 1, let them use the scripts; otherwise, redirect them to the members' area homepage.
