# Enhancing the Member Class

The next thing is to add some functionality to your Member class. Add a couple of extra methods for retrieving Member objects from the database. getByUsername() retrieves the member with the supplied username, and getByEmailAddress() retrieves the member with the given email address. These will be used to ensure that a possible member doesn't accidentally register with a username or email address that is already in the database.

Open up the Member.class file that you created in Chapter 13 and add the following code to the file, after the get() method:

```
public static function getByUsername($username) {
    $conn = parent::connect();
    $sql = "SELECT * FROM TBL_MEMBERS WHERE username = :username";

    try {
        $stmt = $conn->prepare($sql);
        $stmt->bindValue(\:username, $username, PDO::PARAM_STR);
        $stmt->execute();
        $row = $stmt->fetch();
        parent::disconnect($conn);
        if ($row) return new Member($row);
    } catch (PDOException $e) {
        parent::disconnect($conn);
        die("Query failed: " . $e->getMessage());
    }
}
```
