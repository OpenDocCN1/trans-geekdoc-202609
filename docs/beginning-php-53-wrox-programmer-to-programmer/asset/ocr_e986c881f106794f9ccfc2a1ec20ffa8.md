Next the function checks if the file exists; if it writes the content to the file by calling file_put_contents(), which redraws the file page by calling displayList(). If there was a problem, an error message is displayed and the script exits. The function that uses the == or != operator to test the return value of file_put_contents() exactly equals false. Merely using the == != operator would not do the job. Because file_put_contents() returns the number of characters written successful. This value will be zero if the file contents happen to be empty and == false, using == or would incorrectly exit the script with an error in this situation:

```
if ( file_exists($filepath) ) {
  if ( file_put_contents($filepath, $_POST["fileContents"] ) === false )
    die("Couldn't save file");
  displayList();
  } else {
    die("File not found");
}
```
