# Try It Out Find All Links in a Web Page

In this example use preg_match_all() with a regular expression to extract and display all links in an HTML Web page. Save the following script as find_links.php in your document root folder:

```php
<!DOCTYPE PUBLIC "-//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
<head>
<title>Find Linked URLs in a Web Page</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<h1>Find Linked URLs in a Web Page</h1>

<?php

displayForm();

if ( isset($_POST['submitted']) ) {
    processForm();
}

function processForm() {
<h2>Enter a URL to scan:</h2>
<form action="" method="post" style="width:30em;">
<div>
<input type="hidden" name="submitted" value="1" />
<label for="url">URL:</label>
<input type="text" name="url" id="url" value="" />
<label></label>
<input type="submit" name="submitButton" value="Find Links" />
</div>
</form>

<?php
function processForm() {
$url = $_POST['url'];
if ( preg_match(/http(s)?:\//, $url) ) $url = "http://$url";
$html = file_get_contents($url);
preg_match_all("/<a href=\"[^\"]+\">(.+?)<\/a>/i", $html, $matches);

echo "<div style=\"clear:both;\"></div>";
echo "<h2>Linked URLs found at " . htmlspecialchars($url) . ":</h2>";
echo "<ul>";

for ($i = 0; $i < count($matches[1]); $i++) {
    echo "<li>" . htmlspecialchars($matches[1][$i]) . "</li>";
}

echo "</ul>";
?>
}
}
?>
</body>
</html>
```

Run the script by visiting your URL in your Web browser. In the form that appears, enter the URL of a known site and click Find Links. After a short time you should see a list of all the URLs linked to that page, as shown in Figure 18-1.

# How It Works

After displaying the XHTML page header, the script calls display() to display a simple form requesting a URL to scan. If the form has already been submitted, it is processed by calling processForm():

```php
displayForm();

if ( isset($_POST["submitted"]) ) ) {
    processForm();
}
```

display() outputs an HTML form that sends its data back to the find_links.php script. This form contains two controls: a url field for the user to enter a URL and a Link button to submit the form.

processForm() first performs some validation on the submitted URL: if it doesn't begin with http:// or https://, then it is assumed and prepended to the URL. Notice the use of a regular expression to determine if the URL begins with http:// or https://. This expression is delimited by bars (|) rather than the usual slashes; this saves having to escape the double slashes in the expression:

```php
if ( preg_match('|^http(s)?://|', $url) ) $url = "http://$url";
```

Once the URL is validated, it is fetched by the built-in file_get_contents() which requests URL and returns the contents of the page at that URL, just as if it were reading a file. This is a quick and easy way to read the HTML of a Web page.

The meat of the function is in the call to the preg_match_all() function, which uses a regular expression to extract all the links in the URL:

```php
preg_match_all('/<a href=\'(.+?)\>.*?<\/a>/ $html, $matches);
```

This regular expression reads as follows:

- 1. Match an opening bracket (<) and letter "a" followed by zero or more whitespace characters.
- 2. Match the characters "href=", followed by either a single or double quote character (either can be used in HTML).
- 3. Match at least one character by another single or double quote. The question mark ensures that the matching is non-greedy (otherwise text up to the last single or double quote in the page would be matched). The pattern is enclosed in parentheses to capture the resulting URL.
- 4. Match zero or more characters, followed by a closing bracket. This ensures that the <a> tag is matched. Again, non-greedy matching is used, otherwise all text would be matched up to the last angle bracket in the page.

Notice the letter 'i' after the closing delimiter. This is a pattern modifier, and causes the matching to be case-insensitive (because HTML can be written in upper- or lowercase). For more details, see the "Altering Matching Behavior with Pattern Modifiers" section at the end of the chapter.

Now that all the URLs have been extracted, it's simple to display them as an unordered list. Note that, for both security and XHTML compatibility reasons, htmlspecialchars() is called to escape any markup characters in the output:

```php
echo '<div style="color:blue;"> </div>';
echo '<h2>Linked URLs found at " . htmlspecialchars($url) . ":</h2>";
echo '<<ul>>';
```

```php
for ($i = 0; $i < count($matches[1]); $i++) {
    echo '<li>' . htmlspecialchars($matches[1][$i]) . '</</li>';
}
echo '</ul>';
```

# Searching Arrays with preg_grep()

preg_match() and preg_match_all() search individual strings of text. If you want to search an entire array of strings, you can use preg_grep(). This function takes three arguments — the regular expression, the array of strings, and optional flags — and returns an array of elements that matched.

```php
$words = array(
    "apple",
    "banana",
    "cherry",
    "date",
    "elderberry"
);

$result = preg_grep("/^a/", $words);
print_r($result);
// Output:
// Array
(
//     [0] => apple
// )

$result = preg_grep("/e/", $words);
print_r($result);
// Output:
// Array
(
//     [0] => apple
//     [3] => date
//     [4] => elderberry
// )

$result = preg_grep("/a/", $words, PREG_OFFSET);
print_r($result);
// Output:
// Array
(
//     [0] => Array
//         (
//             [0] => apple
//             [1] => 0
//         )
//     [1] => Array
//         (
//             [0] => banana
//             [1] => 0
//         )
//     [2] => Array
//         (
//             [0] => date
//             [1] => 3
//         )
//     [3] => Array
//         (
//             [0] => elderberry
//             [1] => 4
//         )
// )

$result = preg_grep("/a/", $words, 0, PREG_SET_MATCH);
print_r($result);
// Output:
// Array
(
//     [0] => Array
//         (
//             [0] => apple
//             [1] => a
//         )
//     [1] => Array
//         (
//             [0] => banana
//             [1] => a
//         )
//     [2] => Array
//         (
//             [0] => date
//             [1] => a
//         )
//     [3] => Array
//         (
//             [0] => elderberry
//             [1] => a
//         )
// )
```

preg_grep() is also useful for finding elements that *do not* match a pattern, using the PREG_NOT_MATCH flag:

```php
$result = preg_grep("/^a/", $words, PREG_NOT_MATCH);
print_r($result);
// Output:
// Array
(
//     [0] => banana
//     [1] => cherry
//     [2] => date
//     [3] => elderberry
// )
```

# Replacing Text

As you know from Chapter 5, searching strings is only half the story. Often you need to replace a portion of a string with new text.

Simple search-and-replace functions like str_replace() are useful for replacing literal strings. However, if you need to replace complex patterns of text, you can use PHP's regular expression replacement functions, preg_replace() and preg_replace_callback(). You explore these two functions in the following sections:

## Replacing Text with preg_replace()

`preg_replace()` lets you match a pattern against a target string, like preg_match(), and replace the matched text with different text. In its most basic form, preg_replace() takes three arguments:

- The regular expression to search for (as a string).
- The replacement text to replace any matched text.
- The target string to search through.

`preg_replace()` returns the target string with any matched text replaced by a replacement text. Here's a simple example that searches for a dollar symbol followed by a number of digits, and two more digits, and replaces this string with the string "[CENSORED]":

```php
$text = "The wholesale price is $89.50;";

// Displays "The wholesale price is [CENSORED]."
echo preg_replace("/\\d+\\d(2)/", "[CENSORED]", $text );
```

Remember backreferences from preg_match earlier in the chapter? You can also use backreferences within the replacement string — simply write a dollar ($) symbol followed by the backreference number:

```php
$text = "Author: Steinbeck, John";

// Displays "Author: John Steinbeck"
echo preg_replace("/(\\w+),\\s(\\w+)/", "$2 $1", $text);
```

If you want to include the entire matched text in the replacement string, use $0 (a dollar followed by zero):

```php
$text = "Mouse mat: $3.99";

// Displays "Mouse mat: Only $3.99"
echo preg_replace("/\\d+\\d(2)/", "Only $0", $text );
```
