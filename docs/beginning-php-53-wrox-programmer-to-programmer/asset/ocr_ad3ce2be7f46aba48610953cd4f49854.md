# Part II: Learning the Language

To convert a string to all lowercase, `strtolower()`. This function takes a string to convert, and returns a converted copy of the string:

```
$String = "Hello, world!";
echo strtolower($String); // Displays 'hello, world!'
```

Similarly, you can `strtoupper()` to convert a string to all uppercase:

```
$String = "Hello, world!";
echo strtoupper($String); // Displays 'HELLO, WORLD!'
```

ucfirst() makes just the first letter of a string

```
$String = "hello, world!";
echo ucfirst($String); // Displays 'Hello, world!'
```

lcfirst() — introduced in PHP 5.3 — makes the first letter of a string lowercase:

```
$String = "Hello, World!";
echo lcfirst($String); // Displays 'hello, World!'
```

Finally, ucwords() makes the first letter of each word in a string:

```
$String = "hello, world!";
echo ucwords($String); // Displays 'Hello, World!'
```

Speaking of upper- and lowercase, most of the search and replacement functions described earlier in the chapter are `case-sensitive`. This means they'll only match letters of the same case. For example:

```
$String = "Hello, world!";

// Displays "Not found"
if ( strpos($String, "hello") )
necho "Found";
else
echo "Not found";
```

However, PHP has `case-insensitive` versions of many string functions, which means they'll work even if the strings don't match. For example, a case-insensitive version of `strpos()`,

```
$String = "Hello, world!";

// Displays "Found"
if ( strpos($String, "hello") )
echo "Found";
else
echo "Not found";
```
