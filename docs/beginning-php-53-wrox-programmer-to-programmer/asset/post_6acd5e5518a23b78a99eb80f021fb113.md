
## Chapter 2: Your First PHP Script

This script is very simple, but let's break down line-by-line to explore a few features of PHP.

The first line tells the PHP engine to expect some PHP code to follow:

```php
<?php
```

Why do you need this line? This is due to the fact that PHP can be embedded in HTML Web pages. When the PHP engine starts processing the page, it assumes it's dealing with plain old HTML until told otherwise. By using the PHP delimiter, <?php, you are telling the PHP engine to treat anything following it <?php as PHP code, rather than HTML.

The next line displays the message "Hello, world!"

```php
echo "Hello, world!";
```

PHP's echo() statement takes a string of text — in this case, "Hello, world!" and sends it as part of the Web page to the browser. The browser then displays "Hello, world!" to the visitor. The semicolon at the end of this line tells PHP that you've reached the end of the statement, and it should look for a new statement (or the end of the PHP code) to follow.

echo() doesn't have to be given a string of text; it can display anything that be displayed, as numbers or the results of expressions. You find out more about data types and expressions in the next chapter.

An alternative to echo() is the print() statement, which works in the exactly same way except that it returns a value (true). Generally speaking, you can use print() instead of echo() in your code if you prefer.

The final line of your script tells the PHP engine that it's reached the end of the current section of PHP code, and the following lines (if any) contain plain HTML again:

```php
?>
```

## Embedding PHP within HTML

As you've gathered by, one of the nice things about PHP is that you can embed PHP code within HTML. In fact, any .php script that you write is essentially treated as an HTML page by default. If the pages contain <?php ... ?> tags, the PHP engine sends the contents of the file as is to the browser.

## Chapter 2: Your PHP Script How It Works

This example shows how you can embed PHP within an HTML page. The PHP code itself is exactly the same — echo "Hello, world!" — by surrounding the PHP with HTML markup, you created a well-formed HTML page styled with CSS.

First, a DOCTYPE tag is used to declare that the page is an HTML 1.0 Strict page:

```html
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">
```

Next, the head of the Web page gives the page title "Hello" and links to a style sheet, common.css:

```html
<head>
<title>Hello</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
```

Finally, the body element includes an h1 (top-level heading) element containing the output from the PHP code — echo "Hello, world!" — and the page is finished with a closing HTML tag:

```html
<body>
<h1><?php echo "Hello, world!"; ?></h1>
</body>
</html>
```

Note that you don't have to have the <?php ?> tags on separate lines. In this case, the tags and enclosed PHP code are all part of a single line.

Meanwhile, the common.css style file contains selectors to style some elements — including the h1 heading used in the page — to produce the nicer-looking result. Keep this common.css file in your root folder, because it's used throughout examples in this book.

If you view the source of the resulting Web page in your browser, you can see that the final page is identical to the original HTML markup, except that the PHP code — <?php echo "Hello, world!"; ?> — has been replaced with the code’s output ("Hello, world!"). The PHP engine only touches the parts of the page that are enclosed by the <?php ... ?> tags.

## Part I: Getting Up and Running with PHP: Enhancing the Script

The “Hello, world!” example shows how you can write a simple PHP script; the code does nothing useful—you could easily achieve the same effect with a simple HTML page. In this section you enhance the script to display the current time. In doing so, you move from creating a static web page to a dynamic page; a page that changes each time you view it.

Here’s the modified “Hello, world!” script:

```html
<!DOCTYPE html PUBLIC "//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="en" lang="en">
<head>
<title>Hello world</title>
<link rel="stylesheet" type="text/css" href="common.css" />
</head>
<body>
<?php
$currentTime = date("g:i:s a");
echo "Hello, world! The current time is $currentTime";
?>
</body>
</html>
```

## Chapter 2: Your First PHP Script

The majority of the code is exactly the same as before. The only difference is the PHP code itself:

```php
<?php
$currentTime = date("g:i:s a");
echo "Hello, world! The current time is $currentTime";
?>
```

The first line of PHP code takes the current time and formats it as a readable string, then stores this string in a variable $currentTime (Variables can store data. You will learn all about them in the next chapter). To format the time the script uses the built-in date() function. The string of characters within the quotation marks tells PHP how to format the time, as follows:

- g, i, and s tell PHP to output the current time, minute, and second, respectively
- a tells PHP to display "am" or "pm" as appropriate
- The colons (:) and the space are not processed by the date() function, they're displayed as-is
