# Relational Databases

Relational databases offer more power and flexibility than simple databases, and for this reason they tend to be a more popular choice. They are also known as RDBMSs (Relational Database Management Systems). You'll be concentrating on RDBMSs over the next three chapters.

RDBMSs are expensive to set up and admin. The widely acknowledged big three in this field are Oracle, DB2 (from IBM), and SQL Server (from Microsoft). All are massive, feature-systems, capable of just about any kind of data storage and processing that a modern business could need. The flip side of the coin is that these systems are big and expensive, and may contain more functionality than you will ever require.

Fortunately, alternatives are available, as PostgreSQL and MySQL, which are both open source relational databases that have proven very with PHP developers for many years. They’re fast, easily meet the needs of most small-to-medium sized projects, and to top it off, they’re free!

# Choosing a Database

In principle, you can use any of these database systems in your PHP applications. You can hook one application to several different database engines. To keep these chapters to a reasonable length, you’ll focus on just one database engine: MySQL.

Compared to the other choices, it offers several advantages:

+   - It’s one of the most popular databases being used on the Web today
- It’s freely available as a download to install and run on your own machine
- It’s easy to install on a wide range of operating systems (including UNIX, Windows, and Mac OS X)
- It’s available as a relatively cheap feature in many Web hosting packages
- It’s simple to use and includes some administration tools
- It’s a fast, powerful system that cops well with large, complex databases, and should stand you in good stead when it comes to larger projects

If you’re not concerned about the last criterion (and particularly if you don’t want to pay extra for database functionality on your Web hosting account!) you might well find that an embedded database such as SQLite a perfectly good job. PostgreSQL is also a great choice, and is similar in performance and features to MySQL.

Although these three chapters focus on MySQL, many of the techniques you can learn easily be transferred to other database systems.
