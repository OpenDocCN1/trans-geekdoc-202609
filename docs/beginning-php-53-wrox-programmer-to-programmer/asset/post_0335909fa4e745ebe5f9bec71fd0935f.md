# The displayEditForm() Function

When the user clicks a file to edit, the `displayEditForm()` function is called to display the file contents for editing. It can take an optional `$filename` argument containing the filename of the file to edit; if this isn't passed, it looks up the filename in the query string, using `basename()` to ensure that no absolute path information is in the filename; this is a good security measure, because it thwarts any attempt to edit files outside the designated folder. Furthermore, if the filename is empty for some reason, the script exits with an error:

```php
function displayEditForm($filename=$ )
if (!$filename) $filename = basename($_GET["filename"]);
if (!$filename) die("Invalid filename");
```

The next function stores the full path to the file in a `$filepath` variable (because this path is needed many times in the function), and checks to make sure the file to edit exists — if it doesn't, it exits with a "File not found":

```php
$filepath = PATH_TO_FILES . "./$filename";
if (!file_exists($filepath)) die("File not found ");
```

The rest of the function calls `displayPageHeader()` to output the standard page header markup, displays the name of the file being edited, as well as the HTML form for editing the file. The form consists of a hidden field storing the filename of the file being edited; a text area for the file contents; Save File and Cancel buttons. The file's contents are displayed in the text area by calling `file_get_contents()` and outputting the result.

# Summary

In this chapter you learned how to work with files and explored PHP’s various file-handling functions. You looked at:

- How files and directories work, and the differences between file paths on UNIX-like and Windows servers
- Retrieving information on files using `file_exists()`, `filesize()`, `fileatime()`, `filetime()`, `basename()`, and `dirname()`
- Using `fopen()` and `fclose()` to open and close files for reading
- Reading and writing to files using `read()`, `fwrite()`, `fgetc()`, `feof()`, `fgets()`, `fgetcsv()`, `file()`, `file_get_contents()`, `file_put_contents()`, `passthru()`, `readfile()`, `fseek()`, `ftell()`, and `rewind()`
- Setting file permissions with `chmod()`, and checking permissions with `is_readable()`, `is_writable()`, and `is_executable()`
- Copying files with `copy()`, renaming and moving files with `rename()`, and deleting files with `unlink()`
- Reading directories with `opendir()`, `closedir()`, `readdir()`, `rewdir()`, and `dir()`
- Manipulating directories with `chdir()`, `mkdir()`, and `rmdir()`
- Testing for files and directories with `is_file()` and `is_dir()`

Along the way you learned how to use recursion to move through a directory tree, and you also built a simple text editor to illustrate many of the functions and concepts covered in the chapter.

Some functions rarely used in Web applications were discussed. For a full list of PHP’s file and directory functions, refer to the online PHP function list at: http://www.php.net/manual/ref/filesystem.php.
