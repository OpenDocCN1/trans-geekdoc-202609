# Chapter 13: Retrieving Data from MySQL PHP

# Creating the view_member.php Script

The very last PHP file you need to create is the script to view an individual member's details. Save the following code as view_member.php in your book_club_folder:

```
<?php
require_once ( "common.inc.php" );
require_once ( "config.php" );
require_once ( "Member.class.php" );
require_once ( "LogEntry.class.php" );

$memberId = isset($_GET["memberID"]) ? (int)$_GET["memberID"] : 0;

if (!$member = Member::getMember($memberId)) {
    displayHeader(" Error ");
    echo "<div>member not found.</div>";
    displayPageFooter();
    exit;
}
$logEntries = LogEntry::getEntries($memberId);
displayHeader(" View member: " . $member->getValueEncoded("firstName") .
    " " . $member->getValueEncoded("lastName"));\n
?>
<dl style="width:30em">
<dt>Username<?php echo $member->getValueEncoded("username") ?>?></dt>
<dt>FirstName<?php echo $member->getValueEncoded("firstName") ?>?></dt>
<dt>Last name<?php echo $member->getValueEncoded("lastName") ?>?></dt>
<dt>Joined on<?php echo $member->getValueEncoded("joinDate") ?>?></dt>
<dt>Gender<?php echo $member->getGender() ?>?></dt>
<dt>Favorite genre<?php echo $member->getFavoriteGenreString() ?>?></dt>
<dt>Email address<?php echo $member->getValueEncoded("emailAddress") ?>?></dt>
<dt>Other interests<?php echo $member->getValueEncoded("otherInterests") ?>?></dt>
</dl>
<h2>Log access</h2>

<table cellspacing="0" style="width: 30em; border: 1px solid #666;">
<tr>
<th>Web page/</th>
<th>Number of visits/</th>
<th>Last visit/</th>
</tr>
</table>
<?php
```
