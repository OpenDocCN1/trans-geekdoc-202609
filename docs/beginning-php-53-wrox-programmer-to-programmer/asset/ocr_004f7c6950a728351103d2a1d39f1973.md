# Chapter 9: Handling HTML Forms with PHP

PHP allows you to limit the size of uploaded files in a few ways. If you have access to your `php.ini` file, you can add or edit a directive `upload_max_filesize` in the file:

```
; Maximum allowed size for uploaded files.
upload_max_filesize = 32M
```

Then, if a user tries to upload a file larger than this (32 megabytes), the file upload is cancelled and the corresponding `error` array element is set to `UPLOAD_ERR_INI_SIZE`.

You can find out about editing your `php.ini` file in Appendix B.

If you don't access your server's `php.ini` file, you can add a hidden form field `MAX_FILE_SIZE` that specifies the maximum size (in bytes) of an uploaded file. This should be done before the file you upload:

```
<input type="hidden" name="MAX_FILE_SIZE" value="10000" />
<input type="file" name="fileSelect" id="fileSelect" value=" />
```

If the uploaded file is larger than this, the file is cancelled and the corresponding `error` array element is set to `UPLOAD_ERR_FORM_SIZE`. In theory, a browser can also look at the `MAX_FILE_SIZE` field in the form and prevent the user from uploading a file bigger than the first place. In practice, hardly any browsers support this technique.

It's also relatively easy to modify your work file and alter the value of the `MAX_FILE_SIZE` field if it's too large (or even remove the field altogether). For this reason, it's best to use `upload_max_size` to limit your files, if possible.

Of course, you can also check the size of an uploaded file manually and reject it if it's too large:

```
if ( $_FILES["photo"]["size"] > 10000 ) die("File too big!");
```

# Storing an Uploaded File

Once a file has been successfully uploaded, it is automatically stored in a temporary folder on the server. To use the file, or store it on a more permanent basis, you need move it out of the temporary folder. You do this using PHP's `move_uploaded_file()` function, which takes two arguments: the path of the file and the path to move it to. You can determine the existing path of the file using the `tmp_name` array element inside the nested array `$_FILES`. move_uploaded_file returns true if the file was successfully moved, or false if there was an error (such as the path to the file being incorrect). Here's an example:

```
if ( move_uploaded_file( $_FILES["photo"]["tmp_name"], "/home/matt/photos/photo.jpg" ) {
    echo "Your file was successfully uploaded.";
} else {
    echo "There was a problem uploading your file - please try again.";
}
```
