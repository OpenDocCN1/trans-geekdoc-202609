To manipulate the pointer and the elements it points to, using the following functions:

| Function | Description |
| --- | --- |
| current() | Returns the value of the current element pointed to by the pointer, without changing the pointer position. |
| key() | Returns the index of the current element pointed to by the pointer, without changing the pointer position. |
| next() | Moves the pointer forward to the next element, and returns element's value. |
| prev() | Moves the pointer backward to the previous element, and returns element's value. |
| end() | Moves the pointer to the last element in the array, and returns element's value. |
| reset() | Moves the pointer to the first element in the array, and returns element's value. |

Each of these functions takes one argument — the array — and returns the required value or index, or false if an element couldn't be found (for example, if you use next() when the pointer is at the end of the array, or if you use current() on an empty array).

## Looping Through Arrays with foreach

- In fact, there's an even easier way: you can use foreach.

## Part II: The Language

foreach is a special kind of looping statement that works only on arrays (and objects). You can use it in two ways. You can either retrieve the value of each element, or you can retrieve the element's key and value.

### Using foreach to Loop Through Values

The simplest way to use foreach to retrieve each element, as follows:

```
foreach ( $array as $value ) {
  // (do something with $value here)
}

// (rest of script)
```

As you might imagine, the foreach loop continues to iterate until it has retrieved all the variables in the array, from the first to the last. On each pass through the loop, the $value variable gets set to the value of the current element. You can do whatever you need to do with the value within the loop's code block. Then, the loop repeats again, getting the next variable's value, and so on.

Here's an example:

```
$authors = array("Steinbeck", "Kafka", "Tolkien", "Dickens" );

foreach ($authors as $val) {
  echo $val . "<br/>";
}
```

This code displays:

```
Steinbeck
Kafka
Tolkien
Dickens
```

Note that you can use any variable name you like to store the value. Essentially, any variable that you place after the as in the foreach statement assigns the current element's value.

### Using foreach to Loop Through Keys and Values

To use foreach to retrieve both keys and values, using the following syntax:

```
foreach ( $array as $key => $value ) {
  // (do something with $key and/or $value)
}

// (rest of script)
```

This behaves exactly like the previous foreach construct; the only difference is that the element's key is also stored in the $key variable. (Again, you can use any variable names you like; they don't have to be $key and $value).
