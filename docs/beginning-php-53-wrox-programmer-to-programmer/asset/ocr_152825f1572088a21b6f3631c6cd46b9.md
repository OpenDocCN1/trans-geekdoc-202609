# Creating an XML File with the DOM Extension

```
<xml version="1.0" encoding="UTF-8"?>
<stock>
  <item type="fruit">
    <name>apple</name>
    <unitPrice>0.39</unitPrice>
    <quantity>5</quantity>
    <description><![CDATA[Apples are >>>yummy<<]]]]></description>
  </item>
```
