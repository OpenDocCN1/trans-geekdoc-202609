# Getting the Directory Path

The dirname() function returns the directory of a given path. It complements the basename() function, which returns the filename portion of a given path (see the section "Retrieving a Filename from a Path" earlier in the chapter).

For example:

```
$path = "/home/james/docs/index.html";n$directoryPath = dirname ($path);
$filename = basename ($path);
```

After running this code, $directoryPath contains "/home/james/docs", and $filename holds "index.html".

# Working with Directory Objects

PHP offers an alternative object-oriented mechanism for working with directories: the Directory class. To use it, create a Directory object by calling the dir() function with the name of the directory you want to work with, as:

```
$dir = dir("/home/james/docs");
```

The Directory object provides two properties: handle and path. These refer to the directory handle and the path to the directory, respectively:

```
echo $dir->handle // <br />'; // Displays the directory handle
echo $dir->path // <br />'; // Displays "/home/james/docs"
```

You can use the handle property with other directory functions such as readdir(), redir(), and closedir(), just as if you were using a regular directory.
