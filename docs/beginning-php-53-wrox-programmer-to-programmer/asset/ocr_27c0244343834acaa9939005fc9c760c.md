# Chapter 9: Handling HTML Forms with PHP

The square brackets tell the PHP engine to expect multiple values for these fields, and to create corresponding nested arrays within the relevant superglobal arrays `$_POST` and `$_REQUEST` in this case.

The form handler, `process_registration_multi.php`, displays the user's submitted form data in the page. Most fields contain just one value, it's a simple case of displaying the `$_POST` values using the `echo()` statement.

For the multi-value fields, the script needs to be a bit smarter. It creates two string variables to handle the list of field values to display:

```
$favoriteWidgets = "";
$newsletters = "";
```

Next, for the `favoriteWidgets` field, the script checks to see if the `$_POST` array exists (Remember that, for certain unselected form controls such as multi-select lists and checkboxes, PHP doesn't create a `$_POST/$_GET/REQUEST` array element). If the `$_POST["favoriteWidgets"]` array element exists, the script loops through each of the elements in the array, concatenating their values onto the end of the `favoriteWidgets` string, with a comma and space to separate them:

```
if ( isset($_POST["favoriteWidgets"])) {
  foreach ($_POST["favoriteWidgets"] as $widget) {
    $favoriteWidgets = $widget . ", ";
  }
}
```

The script then repeats this process for the newsletter field field:

```
if ( isset($_POST["newsletter"])) {
  foreach ($_POST["newsletter"] as $newsletter) {
    $newsletters = $newsletter . ", ";
  }
}
```
