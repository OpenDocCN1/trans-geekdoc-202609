# Part III: Using PHP Practice

| Character | Description |
| --- | --- |
| Z | The time zone offset from GMT, in seconds. For example, the offset in seconds for the "America/Indiana/Indianapolis" time zone is -18000, because -5 hours x60 minutes x60 seconds = -18000 seconds |
| I (capital "I*") | 1 if the current time zone is daylight saving time; 0 otherwise |

Note that the time zone formatting characters differ with the script's time, because the timestamp is in UTC. Usually the script's time zone is set by the date.timezone directive in the php.ini file, but you can use PHP's date_default_timezone_set() function to change the time zone within your script, if necessary.

As well as the date and time formatting characters mentioned, date() gives you three more formatting characters that return the date and time in one:

| Character | Description |
| --- | --- |
| C | The date and time as an ISO 8601 date. For example, 2006-03-28T19:42:00+1100 March 28, 2006 at 7:42 in the evening, in a time zone that is 11 hours ahead of GMT |
| r | The date and time as an RFC 2822 date. For example, Tue, 28 Mar 2006 19:42:00 +1100 March 28, 2006 at 7:42 in the evening, in a time zone that is 11 hours ahead of GMT. RFC 2822 dates are commonly used in Internet protocols to Web and email |
| U | The timestamp that was passed to date(), and the timestamp representing the current time if no timestamp was passed

For example, you could format a date and time in a nice, easy-to-read fashion like:

```
$d = strftime("March 28, 2006 9:42am");

// Displays The 28th of March, 2006, at 9:42 AM
echo("T\h\e $s \\l F, Y, \\t g:i $A ");
```

Notice that non-formatting characters in the string format need to be escaped with a backslash, and some special characters—l for the form field character and \t for the tab character—need an additional backslash to escape them.

date() converts the UTC supplied to your server's time zone. If you want to keep the date in UTC, use gmdate() instead:

```
// Set the current time zone to 5 hours behind GMT
date_default_timezone_set("America/Indiana/Indianapolis");

// Set $d to the timestamp representing March 28, 2006 2:42 PM UTC
```
