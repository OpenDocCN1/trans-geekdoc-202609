# Part I: Getting Up and Running with PHP

Namespaces bear some resemblance to folders on a hard disk, in that they let you keep one set of function, class and constant separate from another. The same name can appear in many namespaces without the clashes.

PHP 5.3's features are fairly comprehensive, and include support for sub-namespaces, as well as namespace aliases. You'll learn more about using namespaces in Chapter 20.

# The goto Operator

PHP 5.3 also introduces a goto operator that you can use to jump directly to a line of code within the same file.(You can only jump around within the current function or method.) For example:

```
goto jumpToHere;
echo 'Hello';

jumpToHere:
echo 'World';
```

Use goto sparingly—if at all—as it can make your code hard to read, as well as introduce thorny errors if you're not careful. However, it can be useful in some situations, such as breaking out of deeply nested loops.

# Nowdoc Syntax

In PHP 5.3 you can quote strings using nowdoc syntax, which complements the existing heredoc syntax. Whereas heredoc-quoted strings are parsed — replacing variable names with values and so on — nowdoc-quoted strings are untouched. The nowdoc syntax is useful if you want to embed a block of PHP code within your script, the code being processed at all.

Find out more about nowdoc and heredoc syntax in Chapter 5.

# Shorthand of the Ternary Operator

The ternary operator — introduced in Chapter 4 — lets your code use the value of one expression or another, based on whether third expression is true or false:

```
( expression1 ) ? expression2 : expression3;
```

In PHP 5.3 you can omit the second expression in the list:

```
( expression1 ) ?: expression3;
```

This code evaluates to the value of expression1 if expression1 is true; otherwise it evaluates to the value of expression3.
