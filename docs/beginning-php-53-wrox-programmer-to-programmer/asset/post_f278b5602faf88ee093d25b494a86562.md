
## Chapter 10: Preserving State With Query Strings

### Accessing Cookies in Your Scripts

Accessing cookies in PHP is very easy: You simply read values from the `$_COOKIE` global array. As you'd imagined, this associative array contains a list of all the cookie values set by the browser in the current request, keyed by cookie name.

So to display the `pageViews` cookie set in the previous example, you could use:

```php
echo $_COOKIE["pageViews"]; // Displays "8"
```

With `$_GET` and `$_POST`, in a real-world situation you shouldn't directly output data from the `$_COOKIE` array without filtering or validating it. It's easy for attackers to inject malicious data into the cookies sent to the server.

It's important to realize that a newly created cookie isn't available to your scripts via `$_COOKIE` until the next browser request is made. This is the first time the script is run, it merely sends the cookie to the browser. The browser doesn't return the cookie until the next request for a URL from the server. For example:

```php
setcookie("pageViews", 7, 0, "", false, true );
echo isset($_COOKIE["pageViews"]);
```

This code displays nothing (false the first time it's run, `$_COOKIE["pageViews"]` doesn't exist). However, if the user reloads the page to the script again, the script displays 1 (true) because the browser has sent the `pageViews` cookie back to the server, so it's available in the `$_COOKIE` array.

Similarly, if you update a cookie, the `$_COOKIE` array still contains the old value during the execution of the script. Only when the script is run again by the user reloading the page does the `$_COOKIE` array update with the new value.

### Removing Cookies

If you no longer need a cookie stored on the user's browser, you can instruct the browser to delete it. To delete a cookie, you call `setcookie()` with the cookie name and any value (as an empty string), and pass an `expires` argument that is in the past. This immediately expires the cookie on the browser. You should also pass exactly the same path, domain, and other fields that you used when you first created the cookie to ensure the correct cookie is deleted:

```php
setcookie("pageViews", "", time() - 3600, "/", "example.com", false, true);
```

This example sets the cookie expiry time to one hour in the past, which effectively deletes it from the browser. As creating and updating cookies, deleting a cookie via `setcookie()` doesn't delete it from the `$_COOKIE` array while the script is running. However, the next time the browser visits the page, it will no longer send the cookie to the server and the corresponding `$_COOKIE` array element will not be created.

### Part III: Using Practice

In this example, you create a script that can store the visitor's first name and location in cookies, retrieve the information from the cookies, and delete the cookies on request. Save the following script as `remember_me.php` in your root folder, then run the script in your browser. You'll see a form asking for your name and location. Enter the information and click Info. You'll see a page similar to Figure 10-2. Try reloading the page in your browser, or reopening the URL in a new browser. Notice how the script remembers your information even though you sent a fresh request to the server. You can even restart your browser and return to the page, and the script still remembers your details. Click the "About me" link to delete the cookies.

```php
<?php
if (isset($_POST["sendInfo"])) {
  storeInfo();
} else if (isset($_GET["action"]) && $_GET["action"] == "forget") {
  forgetInfo();
} else {
  displayPage();
}

function storeInfo() {
  if (isset($_POST["firstName"])) {
    setcookie("firstName", $_POST["firstName"], time() + 60 * 24 * 365, "", false, true);
  }

  if (isset($_POST["location"])) {
    setcookie("location", $_POST["location"], time() + 60 * 24 * 365, "", false, true);
  }

  header("Location: remember_me.php");
}

function forgetInfo() {
  setcookie("firstName", "", time() - 3600, "", false, true);
  setcookie("location", "", time() - 3600, "", false, true);
  header("Location: remember_me.php");
}

function displayPage() {
  $firstName = (isset($_COOKIE["firstName"])) ? $_COOKIE["firstName"] : "";
  $location = (isset($_COOKIE["location"])) ? $_COOKIE["location"] : "";
}
?>
```
