# Exercises

Here are some exercises to help you practice some of the techniques that you learned in this chapter. You can also extend these exercises to apply to real-world examples. You'll find solutions to the exercises in Appendix A.

+   1. Create a PHP script that opens an image file, adds a one-pixel black border to the image, and outputs the resulting image to the browser.

+   2. Using the `disk_total_space()` and `disk_free_space()` functions, show how much disk space you have used on your Web server's hard drive in a graphical way.
