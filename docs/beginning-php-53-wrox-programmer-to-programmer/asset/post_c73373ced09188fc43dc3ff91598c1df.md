# Working with References

You've already learned that you can pass information to a function in the form of arguments, as well as return information from a function to its calling code using the return statement. When you do either of these things, PHP actually passes copies of the information to and from the function; this is known as passing and returning by value.

Most of the time this isn't a problem, but sometimes you want your function to work on the original information rather than a copy. Consider the following example:

```php
function resetCounter( &$c ) {
  $c = 0;
}

$counter = 0;
$counter++;
$counter++;
echo "$counter"; // Displays "3"
resetCounter($counter);
echo "$counter"; // Displays "3"
```

This code defines a function, resetCounter(), which resets its argument to zero. A $counter variable is initialized and incremented three times. As you'd expect, the value of $counter at this point is 3. However, as the second echo shows, $counter has not been reset by the function because the parameter $c inside resetCounter only holds a copy of the information.

Fortunately, PHP provides a mechanism known as references that you can use to work around issues. A reference is like a shortcut or alias to your variable. When you create a reference to a variable, you now have two ways to read or change the contents: you can use the variable name, or you can use the reference. Here's a simple example that creates a reference to a variable:

```php
$myVar = 23;
$myRef = &$myVar;
$myRef++;
echo "$myRef"; // Displays "24"
echo "$myVar"; // Displays "24"
```

# Chapter 7: Functions

First a new variable, $myVar, is initialized with the value 23. Next, a reference to $myVar is created, and the reference is stored in the variable $myRef. Note the ampersand (&) alters the equals sign; this creates the reference. The next line of code adds one to the value of $myRef. Because $myRef points to the same data as $myVar, both $myRef and $myVar contain the value 24, as shown by the two echo statements.

Now that you know what references are, and how to create them, it's time to look how you can pass references into and out of functions.

# Passing References to Your Own Functions

By passing a reference to a variable as an argument to a function, rather than the variable itself, you pass the argument by reference rather than by value. This means that the function can alter the original value rather than on a copy. To get a function to accept an argument as reference rather than by value, put an ampersand (&) before the parameter name within the function:

```php
function myFunction(&$aReference) {
    // (do stuff with $aReference)
}
```

Now, when a variable is passed to myFunction(), PHP actually passes a reference to that variable so that myFunction() can work directly with the contents of the variable, rather than a copy. Now that you know, you can fix the earlier counter example by using a reference:

```php
function resetCounter(&$c) {
    $c = 0;
}

$counter = 0;
$counter++;
$counter++;
echo "$counter"; // Displays "3"
resetCounter($counter);
echo "$counter"; // Displays "0"
```

The only change in the script is in the first line:

```php
function resetCounter(&$c) {
```

Adding the ampersand before $c makes the $c parameter a reference to the passed argument ($counter in this example). Now, when the function sets $c to zero, it alters the value of $counter to zero, as can be seen by the echo statement.

Many built-in PHP functions accept references in this way. For example, PHP's sort() function, which you met in the previous chapter, changes the array you pass to it, sorting its elements in order. The array is passed in by reference rather than by value, so that the function can change the array itself, rather than a copy of it.

# Returning References from Your Own Functions

As well as passing variables by functions, you can also get functions to return references, rather than values. To do this, you return a variable with an ampersand before the function name in your function definition. Then, when you pass a reference to that variable back to the calling code, rather than the variable's value:

```php
function &Func() {
    // (do stuff)
    return $var; // Returns a reference to $var
}
```

Here's an example that shows return-by-reference in action:

```php
$number = 5;

function &getMyNumber() {
    global $number;
    return $number;
}

$numberRef = &getMyNumber();
echo "$number = $numberRef"; // Displays "6"
echo "$numberRef = $numberRef"; // Displays "6"
```

Here's how it works. First, a global variable, $number, is created and given the value 5. Next, a function, getMyNumber(), is defined. This function returns global $number. Because getMyNumber() has an ampersand before its name, it returns a reference to $number, rather than the value that $number holds.

Next, the script calls getMyNumber(). The value of getMyNumber() — that is, the reference to $number — is assigned to a new variable, $numberRef. Notice $numberRef points to the same data as $number.

# Writing Recursive Functions

In Chapter 4, you learned how to use loops to manage large amounts of data. Looping is often known as iteration. Recursion is another technique that you can use if you need to work on set of values. Generally speaking, it's usually easier to iteration than recursion; however, in certain situations recursion makes sense. Practically any loop can be converted to recursion instead, and vice-versa.

Here's a quick overview of how recursion operates:

- The recursive function is called by the calling code
- If the base, or condition, is met, the function does any processing required, then exits
- Otherwise, the function does any processing required, then calls itself to continue the recursion

Of course, you have to make sure that the base case is eventually reached, otherwise the function will keep itself indefinitely (causing an infinite loop).
