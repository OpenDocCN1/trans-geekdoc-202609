imagecolorarc($image, ($x2 - $curveDepth), ($y1 + $curveDepth), (2 *

That's the end of the rounded rectangle function, so now we can draw the image.

The first script creates the image and allocates two colors to the image. The first color allocated
(gray) is the background color for the image, and the second color (black) is used for the rectangle:

```
$myImage = imagecreate(200, 100 );
$myGray = colorallocate($myImage, 204, 204, 204 );
$myBlack = colorallocate($myImage, 0, 0, 0 );
```

The next code calls the roundedRectangle() function, passing the arguments previously discussed:

```
roundedRectangle($myImage, 20, 10, 180, 90, $myBlack );
```

Finally, the image is sent to the Web browser by calling header() followed by imagepng(). To
finish up, the imagedestroy() function is used to clean up memory:

```
header( "Content-type: image/png ");
imagepng($myImage);
imagedestroy($myImage);
?>
```
