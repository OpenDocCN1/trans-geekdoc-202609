# Chapter 5: Strings

```
$String = "But think not that famous town has only harpooners
```

```
echo <pre>
echo wordwrap ( $String );
echo </pre>
```

This code displays the following output:

But think not that this famous town has only harpooners, cannibals,
bumpkins to show her visitors. Not at all. Still New Bedford is a queer
place. Had it not been for us whalemen, tract of land would this day
perhaps have been in as howling condition as the cost of Labrador.

By default, wordwrap() makes each line be no longer than 75 characters, but you can change this by
passing an optional argument:

```
$String = "But think not that this famous town has only harpooners
```

```
echo <pre>
echo wordwrap ( $String, 40 );
echo </pre>
```

Here's the result:

But think not that this famous town has
only harpooners, cannibals, and
umpkins to show her visitors. Not at
hall. Still New Bedford is a queer place.
Had it not been for us whalemen, that
tract of land would this day perhaps
have been in as howling condition as the
cost of Labrador.

If you'd rather using a different character or characters to pass the character(s) you'd like to use as an optional third argument. For example, by splitting the lines with
tHTML line break <br />, the example script needs only to encode the output in
<pre>...</pre> tags:

```
$String = "But think not that this famous town has only harpooners,
cannibals, and bumpkins to show her visitors. Not at all. Still New Bedford
is a queer place. Had it not been for us whalemen, tract of land would
this day perhaps have been in as howling condition as the cost of
Labrador.",
```

```
echo wordwrap ( $String, 40, "<br />" );
```
