## Parsing the XML Document

Now you're ready to actually parse the document. First, if the document is a file on disk or at a URL, you need to read its contents into a string variable, for example, PHP's `file_get_contents()` function. Once you have your XML in a string variable, call `xml_parse()`, passing the parser resource you created, as as the string variable. For example:

```php
$xml = file_get_contents("xml_document.xml");
xml_parse($parser, $xml);
```

The parser processes the contents of the string variable, calling your event handler functions as appropriate, until it's finished reading all the data. If the parser to parse all the data successfully returns `true`; otherwise it returns `false`.

You can find more about `file_get_contents()` and other file-related functions in Chapter 11.

You can parse XML in chunks if you prefer; this is useful if you have a lot of XML data and you'd rather not read it all into memory. One way to do this, just keep calling `xml_parse()`. When parsing the last chunk of data, pass a value of `true` to `xml_parse()` to tell it it's reached the end of the XML:

```php
xml_parse($parser, $xml, true);
```

Once you've parsed your XML, it's a good idea to let the parser free up memory. To do this, use `xml_parser_free()`, as follows:

```php
xml_parser_free($parser);
```

# Dealing with Parse Errors

If the call to `xml_parse()` returns false, there was a problem parsing the XML document. You can find the exact cause of the problem by calling various XML Parser functions:

| Function | Description |
|---|---|
| `xml_error_code($parser)` | Returns an error code indicating the last error |
| `xml_error_string($code)` | Returns the error string associated with the supplied error code |
| `xml_get_current_line_number($parser)` | Returns the line number of the currently parsed line in the XML document (this will be the line where the error occurred) |
| `xml_get_current_column_number($parser)` | Returns the currently parsed column number in the XML document (the point where the error occurred) |

For example, you can display the last error message with:

```php
echo xml_error_string( xml_get_error_code($ parser ) );
```

If you want, you can call xml_get_current_line_number() and xml_get_current_column_number() at any point during the parse process, not only when an error has occurred. This can be useful for finding how far through the document the parser has reached.

## How It Works

After including the standard XHTML header, the script creates three event handler functions. The startElementHandler() displays the element name, and if the element has any attributes, it displays their names and values, one after another. The endElementHandler() notices the end of an element, and the characterDataHandler() displays any data that consist of whitespace.

The next function in the script is parseError(). It's called if there was a parse error, and it uses the XML Parser functions xml_get_error_code(), xml_error_string(), xml_get_current_line_number(), and xml_get_current_column_number() to display the error message and the location of the error.

Now that the functions are out of the way it's time to create the parser with xml_parser_create(). The script also uses xml_parser_set_option() to set the XML_OPTION_CASE_FOLDING option to false. By default, XML Parser converts all data to uppercase, but this isn't useful because XML is case-sensitive, so the script turns this off.

As well as XML_OPTION_CASE_FOLDING, you can use XML_OPTION_SKIP_TAG to skip a specified number of characters at the start of a tag name, XML_OPTION_WHITE to skip values that consist of whitespace, and XML_OPTION_ENCODING to set the encoding of characters that are set to the event handlers. See the online manual at: http://www.php.net/manual/en/book.xml

The next scripts use xml_set_element_handler() and xml_set_character_data_handler() to register the three event handlers created. Finally, the script to parse the file into a variable, calls xml_parse() to parse the variable's contents. If xml_parse() returns false, the script exits with die(), displaying the problem by calling the parseError() function. If the parse was successful, the script destroys the parser resource before freeing the XHTML page.

## Writing and Manipulating XML Documents with PHP

Although XML Parser is a very useful extension, it can read only XML documents; it can't documents create new documents. Furthermore, the event-based parsing approach isn't always the easiest to work with.

An alternative approach is to use the DOM extension. DOM stands for Document Object Model, and it's a way of expressing the various nodes (elements, attributes, and so on) of an XML document as a tree of objects. If you've done any work with the DOM in JavaScript then you're in luck — the PHP DOM classes work in a very similar way.
