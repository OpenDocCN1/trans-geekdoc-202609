# Chapter 7: Functions

When the PHP engine encounters the return statement, it immediately exits the function and returns value back to the code that called the function, which can then use the value as required.

The example script shows how to define and use a function that returns a value:

```
<?php

function makeBold($text) {
  return "<b>$text</b>";
}

$normalText = "This is normal text.";
$boldText = makeBold("This is bold text.");
echo "<p>$normalText</p>";
echo "<p>$boldText</p>";

?>

</body>
</html>
```

This script defines a function, makeBold(), which accepts a string argument and returns the string enclosed by HTML <b>...</b> (bold) tags. It creates a variable, $normalText, containing an unformatted string of text. Then it calls the makeBold() function, passing some text to format, and stores the return value from makeBold() in another variable, $boldText. Finally, the script outputs both $normalText and $boldText to the browser.
