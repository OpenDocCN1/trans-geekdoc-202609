# Chapter 6: Arrays

Here's an example:

```
$authors = array("Steinbeck", "Kafka");
$moreAuthors = array("Tolkien", "Milton");

// Displays Array ( [0] => Steinbeck [1] => Kafka [2] => Tolkien [3] =>
Milton )\nprint_r (array_merge($authors, $moreAuthors));
```

Note that array_merge() joins the elements of arrays to produce the final array. It contrasts with array_push(),array_shift(), and the square bracket syntax, all insert array arguments are to produce multiple

```
$authors = array("Steinbeck", "Kafka");
$moreAuthors = array("Tolkien", "Milton");
array_push($authors, $moreAuthors);

// Displays Array ( [0] => Steinbeck [1] => Kafka [2] => Array [0] =>
Tolkien [1] => Milton )\nprint_r ($authors);
```

A feature of array_merge() is that it preserves the keys of associative arrays, so you can use it to add new key/value pairs to an associative array:

```
$myBook = array("title" => "The Grapes of Wrath",
"author" => "John Steinbeck",
"pubYear" => 1939);
```

```
$myBook = array_merge($myBook, array("numPages" => 464 ));
```

```
// Displays Array ( [title] => The Grapes of Wrath [author] => John
Steinbeck [pubYear] => 1939 [numPages] => 464 )\nprint_r ( $myBook );
```

If you add a key/value using a string that already exists in the array, the original element gets overwritten. This makes array_merge() handle for updating associative arrays:

```
$myBook = array("title" => "The Grapes of Wrath",
"author" => "John Steinbeck",
"pubYear" => 1939);
```

```
$myBook = array_merge($myBook, array("title" => "East of Eden", "pubYear"\n=> 1952 );
```

```
// Displays Array ( [title] => East of Eden [author] => John Steinbeck
[pubYear] => 1952 )\nprint_r ( $myBook );
```
