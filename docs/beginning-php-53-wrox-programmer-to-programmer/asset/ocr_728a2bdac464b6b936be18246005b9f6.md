# Destroying a Session

As mentioned earlier, by default PHP sessions are automatically deleted when users quit their browser, because the PHPESSID cookie's expires field is set to zero. However, sometimes you might want to destroy a session manually. For example, if a shopper has checked out and placed an order over your online store, you might have wiped shopping cart by destroying that session.

To destroy a session, you can simply call the built-in session_destroy() function:

```
session_destroy();
```

Note, however this merely erases the session data from the disk. The data is still in the $_SESSION array until the current execution of the script ends. To make sure that all session data has been erased, you should also initialize the $_SESSION array:

```
$SESSION = array();nsession_destroy();
```

Even however, a trace of the session remains in the form of the PHPESSID cookie in the user's browser. When the next visitor visits your site, PHP will pick up the PHPESSID cookie and re-create the session (though the session won't contain any data when it's re-created). To make sure you have wiped the session from the server and the browser, you should also destroy the session code:

```
if ( isset($_COOKIE[session_name()]) ) {
setcookie(session_name(), "*", time()-3600, "*/");
}
```

```
$SESSION = array();nsession_destroy();
```

This snippet makes use of another PHP function, session_name(). This function simply returns the name of the session (PHPESSID by default).

PHP actually lets work with more than one session in the same script by using session_name() to create different named sessions. This topic is outside the scope of this look, but you can find out more in the "Session Handling" of the PHP manual at http://www.php.net/session.

# Passing Session IDs in Query Strings

As you know, PHP session IDs are saved in cookies. However, if a user has disabled cookies in their browser? One obvious approach is to add some text to your page asking the user (nicely) to turn on cookies. Another alternative is to pass the session ID inside links between the pages of your site.
