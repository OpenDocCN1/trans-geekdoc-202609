# Chapter 4: Decisions and Loops

# Doing Repetitive Tasks with Looping

You can see that the ability to make decisions — running different blocks of code based on certain criteria — can add a lot of power to your PHP scripts. Looping can make your scripts even more powerful and useful.

The basic idea of a loop is to run the same block of code again and again, until a condition is met. With decisions, that condition must take the form of an expression. If the expression evaluates to true, the loop continues running. If the expression evaluates to false, the loop exits, and execution continues on the first line following the loop's code.

You look at three main types of loops in this chapter:

- * while loops
- do...while loops
- for loops

You explore foreach() loops, which work specifically with arrays, in Chapter 6.

# Simple Looping with the while statement

The simplest type of loop to understand uses the while statement. A while construct looks very similar to an if construct:

```php
while ( expression ) {
    // Run this code
}

// More code here
```

Here's how it works. The expression inside the parentheses is tested; if it evaluates to true, the code block inside the braces run. Then the expression is tested again; if it's still true, the code block is run again, and so on. However, at any point the expression is false, the loop exits and continues with the line after the closing brace.

Here's a simple, practical example of a while loop:

```php
<?php
$widgetsLeft = 10;

while ($widgetsLeft > 0) {
    echo "Selling a widget... ";
    $widgetsLeft--;
    echo "done. There are $widgetsLeft widgets left.<br />";
}

echo "We're right out of widgets!";
?>
```

First a variable, $widgetsLeft, is created to record the number of widgets in stock (10). Then the while loop loops through the widgets, "selling" them one at a time (represented by decrementing the $widgetsLeft counter) and displaying the number of widgets remaining. Once $widgetsLeft reaches zero, the expression in the parentheses ($widgetsLeft > 0) becomes false, and the loop exits. Control is then passed to the echo() statement outside the loop, and the message "We're out of widgets!" is displayed.

# Testing at the End: The do ... while Loop

Take another look at the while loop in the previous example. You will notice that the expression is tested at the start of the loop, before any of the code inside the braces has a chance to run. This means that, if $widgetsLeft was set to 0 before the while statement was first, the expression would evaluate to false and would skip to the first line after the closing brace. The code inside the loop would never be executed.

Of course, this is not what you want to happen; you can't sell a widget when there are no widgets to sell! However, sometimes it's useful to run the loop at least once before checking the expression, and this is exactly what do...while loops let you do. For example, if the expression you're testing relies on setting a variable inside the loop, you need to run that loop at least once. Here's an example of a do...while loop:

```php
<?php
$width = 1;
$length = 1;

do {
    $width++;
    $area = $width * $length;
} while ($area < 1000);

echo "The smallest square over 1000 sq ft in area is $width x $length ft";
?>
```

# Neater Looping with the for Statement

The for statement is a bit more complex than do...while, but it's a neat and compact way to write certain types of loops. Typically, you use a for loop when you know how many times you want to repeat. You use a counter variable within the for loop to keep track of how many times you've looped. The general syntax of a for loop is:

```php
for ( expression1; expression2; expression3 ) {
  // Run this code
}
```

As while and do...while loops only need one line of code in the body to omit braces, a for loop can contain three expressions. These expressions, in order:

- The Initializer — This is run once, when the loop is first encountered. Typically, it is used to initialize a counter variable (for example, $counter = 1)
- The loop test — This fulfills the same purpose as the single expression in a do...while loop. If this expression evaluates to true, the loop continues; if it's false, the loop exits.
- The counter expression — This is run after each iteration of the loop, and is usually used to change the counter variable (for, $counter++)

Here is a typical example of a for loop in action. This script counts from 1 to 10, displaying the counter value each time the loop:

```php
for ($i = 1; $i <= 10; $i++) {
  echo "I've counted to: $i<br />";
}

echo "All done!";
```

The loop sets up a new variable, $i, and sets its value to 1. The code within the loop displays the counter value. Each time the loop repeats, $i is incremented. The loop test expression checks to see if $i$ is still less than 10. It's perfectly possible to write any for loop using a while statement instead. Here's the previous for loop rewritten using while:

```php
$i = 1;
while ($i <= 10) {
  echo "I've counted to: $i";
  $i++;
}

echo "All done!";
```

However, as this clearly shows, a for loop is generally neater and more compact. There's a lot to the for statement than meets the eye. For example, you don't have to use it for simple counting, nor does the loop expression involve the same variable in the counting expression. Here's an example:

```php
$startTime = microtime( true );
for ($num = 1; microtime(true) < $startTime + 0.0001; $num = $num * 2 ) {
  echo "Current number: $num";
}

echo "Out of time!";
```

You're probably wondering what on earth this script does. Well, it races the PHP engine in a variable, $startTime.

First, the script stores the current Unix timestamp, in microseconds, in a variable. To do this, it uses PHP's microtime function with an argument of true, which returns the timestamp as a floating-point number (with the number of seconds before the decimal point and the fraction of a second after the decimal point).

Next, the for loop goes into action. The initializer sets a variable, $num, with a value of 1. The loop test expression checks if the current time — retrieved using microtime() — is still earlier than 1/10000 of a second (100 microseconds) after the start time; if so the loop continues. The counting expression, rather than simply incrementing a counter, multiplies the $num variable by 2.

To summarize, the for loop sets $num to 1, keeps multiplying $num by 2, displaying the result each time, until 100 microseconds have elapsed. The script displays an "Out of time!" message.

To try this, save the code as race.php and open the script's URL in your Web Browser. How fast this script will depend on the speed of your Web server! On my computer it made it up to 8 before running out of time, as shown in Figure 4-3.
