Now, rewrite the register.php script in the book_club_2 folder to use HTML_QuickForm. Replace the code in the script with the new code:

```
<?php
require_once( "common.inc.php" );
require_once( "HTML/QuickForm.php" );
require_once( "HTML/QuickForm/Renderer/Tableless.php" );

$form = new HTML_QuickForm( "","post","register.php", "",
array(array("width" => "300em", true), true);
$form->removeAttribute("name")
addElements($form);
addRules($form);
$form->setRequiredNote(" "");
```
