# How It Works

After displaying an XML header, the script sets two variables: $hour, holding the current hour of the day, and $year, holding the current year. Its PHP's date() function passing "H" returns the hours in 24-hour clock format, and passing "y" returns the year.

> You can find out more about the workings of the date() function in Chapter 16.

Next, the script uses an if...else construct to display an appropriate greeting. If the current hour is between 5 and 12 the script displays "Good morning!"; if it's between 12 and 18 displays "Good afternoon!" and so on.

Finally, the script works out if the current year is a leap year. It creates a new $leapYear variable, set to false if the current year is divisible by 4 but not 100, or if it's divisible by 400. The script outputs a message, using the ternary operator (?) to insert "not" into the message if $leapYear is false.
