
# 系统漏洞与密码安全

系统漏洞可能导致所有哈希版本被窃取，但由于数字哈希的特性，无法直接将这些哈希值映射回生成它们的密码。遗憾的是，虽然成本较高，但确实存在推算出原始密码的方法。用于创建哈希密码的标准数字哈希算法只有几种，因此攻击者可以从将这些算法应用于“a”、再应用于“b”开始，依此类推使用越来越长的单词。最终，某个单词会映射到已知的哈希值，该单词即为密码。

这就是为什么密码建议设置得较长（因为必须尝试许多可能的文本字符串才能找到正确的那个）并包含不常用字符（因为这增加了必须检查的文本字符串的多样性）。攻击者无需太高的技巧即可先尝试常见的密码选择，然后是字典中的单词，接着是日期，最后才诉诸暴力搜索。这就是为什么常见的建议是创建不属于这些可预测类别的密码。请注意，攻击者可以预先计算出所有短于特定长度的潜在单词的哈希值，因此攻入新账户的边际成本非常低。

因此，攻击者不断增长的计算能力与随之而来的密码复杂度要求增加之间存在一场军备竞赛。目前，不断增长的计算能力正在帮助攻击者，而记忆日益晦涩密码的需求则对普通用户不利。这种情况因许多用户拥有多个网站的密码（可能甚至有数百个），且不可能全部记住而变得更加复杂。毫不奇怪，用户会求助于在许多网站使用相同密码、使用短密码，或将密码写在他人可访问的地方。由于对复杂密码的需求与其对用户认知能力的要求之间存在错位，即使有密码管理器等辅助工具，使用密码作为认证机制的方法也已接近失效。

## 认证中介

一些社交媒体企业正试图成为认证中介。许多网站允许您使用社交媒体凭据登录。然而，这远非无私之举。对这些社交媒体网站而言，这成为它们在您访问互联网上其他网站时追踪您的又一途径。

许多企业试图通过包含只有您（理论上）知道答案的问题，来增强基于“您所知”的认证强度。最初，这些问题是诸如您母亲的娘家姓之类，但在线上世界这往往很容易被发现。现在通常使用更广泛的问题，但用户必须决定是使用正确答案（这使其更易被猜测），还是使用虚构答案（甚至他们自己可能都记不住）。

**密钥分享** 是 “您所知” 的一种发展。在此机制中，您和您要向其认证的系统知道 **不同** 的信息片段，这些片段必须组合在一起才能创建允许认证的 “您所知”。举个简单的例子，系统可以在 -90 到 +90 之间生成一个随机值，您的秘密是一个字母，正确的响应是说出一个城市名称，其纬度由该随机值给定，且名称中包含您的那个字母。

# 您所拥有的东西

这种方法要求用户拥有并/或出示某个物体以进行认证。此类设备范围广泛，复杂程度各异。

我们的物理钥匙是一个简单的例子。拥有钥匙是您解锁并访问现实世界中的门或容器所需的唯一认证。

您可以将可通过轻触支付的信用卡视为另一种基于 “您所拥有的东西” 的简单认证形式。您仅因拥有该卡而将自己认证为允许在该卡上产生账单的人（这也是为什么您无法产生 **巨额** 账单的原因）。

另一大类例子是常用于车辆和门禁的无钥匙设备。当这些设备足够接近读取器时，读取器允许访问相关系统。读取器可能连接到计算机系统（例如插在 USB 插槽中），只要设备足够接近，系统就会允许访问。由于手机在世界许多地方普及，手机本身可以充当其他计算机的无钥匙访问设备，或用于物理访问控制。

更复杂的设备通常称为 **安全加密狗**，可插入 USB 插槽，并可被不同种类的软件询问，不仅认证计算机的使用，甚至认证该计算机上特定软件的使用。加密狗充当允许访问软件的物理许可证。例如，它可能包含软件的许可证代码和唯一识别号，以便跟踪访问记录。

由于加密狗与软件之间的通路可能受到攻击，或加密狗本身可能被软件或硬件复制，加密狗通常包含安全处理器，并加密软件与加密狗之间的通信，即使这种通信仅发生在单个系统内部。

当认证针对远程系统时，使用 “您所拥有的东西” 进行认证变得更具挑战性。这需要从读取器到远程系统建立一条安全路径，虽可行但需谨慎操作。

使用 “您所拥有的东西” 作为认证机制的另一风险是您可能丢失它或将其落在家中，从而被锁定在其保护的资源之外；它也可能被盗并被他人用来冒充您。

这些设备也可能被给予或借给他人，后者随即获得随设备附带的所有访问权限。这有时虽方便，但也带来安全风险。

# 您本身的特征

这种方法使用您身体的属性——**生物特征**——作为认证机制，例如您的指纹、手掌纹、耳纹、虹膜、面部或声音。乍一看这似乎很有吸引力，因为这些生物特征始终伴随您，您不会忘记它们（如 “您所知”）也不会把它们落在家里（如 “您所拥有的东西”）。

生物特征必须转换为可存储在计算机系统中的形式，且像密码一样，生物特征的新呈现必须以相同方式映射，并将结果与先前存储的结果进行比较。这种生物特征的存储编码具有与存储密码哈希相同的一些问题——它们成为攻击目标——并额外存在映射通常不是数字哈希因此可能可逆的问题。生物特征编码必须设计为对微小变化不变：手指位置略有不同、长老茧或留胡须等。这意味着它们进行的是粗略匹配，从而阻碍了真正的数字哈希。

生物特征认证系统有两个被低估但严重的缺陷。第一个缺陷是它们通常相对容易被欺骗。指纹于 20 世纪初开始用于识别罪犯，侦探小说《红拇指印》（1909 年）在几年内首次指出了其易于伪造的特性。在某些系统中，即使在今天，在指纹读取器上覆盖塑料薄膜并按压，会导致其记录最近一次真实的指纹。虹膜可通过将某人眼睛的高质量照片放在白纸的一个孔后进行欺骗。面部识别本身准确度不高，但可通过从照片衍生的面具进行欺骗。语音识别也不太准确，且同一人在感冒或过敏时会发生变化。
