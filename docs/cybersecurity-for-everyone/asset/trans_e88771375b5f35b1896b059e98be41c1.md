
# 节点

节点是通过网络相互连接的对象，它们执行计算、存储数据、与人类交互以及与物理世界交互。

最明显的节点类型是计算机，范围从大型强大的服务器到个人计算机。但还有其他更常见的节点类型。例如，大多数人使用手机与网络空间交互，手机只是一种专用计算机。越来越多的还有**物联网设备**，这些节点通常不直接与人类交互，但具有实用功能：视频摄像头、灯光开关、恒温器、运动探测器和医疗设备。不太明显的是**网络物理系统**，例如现代生产线中使用的机器人和机械，以及控制管道和电网的设备。

之所以存在这系列设备——它们都包含计算能力并连接到网络——是因为从通用计算设备入手并对其进行编程以特定方式运行，几乎总是比直接构建专用设备来实现该功能更容易。结果是，网络空间几乎已成为一种单一文化，因为只有少数计算机制造商、操作系统提供商（`Windows`、`Mac`、`Linux`）、手机系统（`Android`、`iOS`）和网络交换机提供商（`Ericcson`、`Cisco`、`Huawei`）。

这引入了与任何单一文化相关的漏洞：针对特定类型系统的攻击可以同时对许多目标取得成功。攻击者可以迅速扩大攻击规模并造成严重破坏。他们还可以对特定类型的所有节点尝试撒网式攻击，指望至少能攻破一些目标。

# 管道

管道是将节点相互连接的连接器。它们传输多种形式的数据：电子邮件、网页请求、网页内容本身、数字编码的语音、视频、音频、软件、许多其他类型的数据传输，以及管理管道网络本身的控制消息。

管道可以硬连线以在两个固定端点之间移动数据。例如，海底电缆连接大陆并能承载海量数据；大容量网络在国家内部移动数据，光纤和同轴电缆将数据传入和传出企业、住宅和公寓楼。

其他管道无线传输数据。这些包括将手机与本地基站连接的蜂窝网络、几百平方米范围内的 Wi-Fi、蓝牙及连接约两米短距离的类似系统，以及用于 RFID 标签和近场设备的厘米级超短距离无线连接。

# 管理基础设施

管理基础设施管理节点和管道的组织方式，以便数据能找到通往其预期目的地的路径，并确保资源按照商定的规则共享。节点和管道都会随着用户移动、系统故障或更换而加入或离开网络，因此该基础设施还必须应对动态情况。网络空间的规模决定了其中大部分管理必须实现自动化。

# 网络空间中的人

从某种意义上说，人也可以被视为网络空间的一部分，原因有二。首先，网络空间中流动的大量数据之所以移动，是因为它们要发往特定的个人。因此，网络空间必须有方法发现每个人在何处以及如何连接到网络——人必须拥有从网络空间内部向外看讲得通的地址或接入点。

其次，个人在网络空间中行动，我们通常希望他们对这些行为负责。这是一个艰难的权衡：我们有时希望能像在现实世界中那样匿名行动，但所有国家已有机制在匿名性助长犯罪时加以限制，类似的机制也需要迁移到网络空间。大型在线企业渴望收集关于每个人的大量数据以建立模型，从而（据称）改进定制广告投放，这使情况变得模糊不清。结果是，个人在网络空间行动时对被识别持警惕态度，因为他们不信任政府或跨国企业不会滥用通过观察已知个人及其行为而获得的信息。

# 2.3 节点

由于网络空间包含数十亿个节点，必须有方法识别哪个是哪个。这个问题比看起来更复杂，因为同一个物理对象（比如一部手机）可能随时间出现在多个地方，有时甚至同时出现在多个地方。例如，无论你何时移动（有时甚至只是乘电梯上楼），你的手机都会连接到不同的基站以维持与蜂窝网络的连接。

识别设备依赖于每个设备拥有唯一标识符。对于手机，有一个唯一号码，即**IMEI**（国际移动设备识别码），它与手机硬件绑定。蜂窝网络可以在手机连接网络时检查 `IMEI`，从而绝对确定是哪部手机。

其他手机标识符与其**SIM 卡**相关联。SIM 卡是物理手机与为该手机提供服务的运营商之间的关联。它们可以在大多数手机中插拔更换，因此它们不标识手机本身，但对于想要接听电话的用户来说，它们更接近于用户的标识符。与 SIM 卡关联的第一个标识符是**国际移动用户识别码（IMSI）**，它包含国家、运营商和关联个人的详细信息（如果明确售予实名登记的个人，某些国家要求如此）。例如，`IMSI` 用于确定手机是否在另一家公司的网络上拥有漫游权限。

与手机 SIM 卡关联的第二个标识符是电话号码。加上国家和地区代码，每个号码在全球范围内都是唯一的。这是将来电连接到被叫特定手机的主要方式。

蜂窝网络必须跟踪连接到其基站的所有手机的这些标识符，以便将来电发送到正确的位置并正确计费。

与手机系统并行的是规模大得多的互联网，它连接计算机（各种大小和复杂度）以及使用 Wi-Fi 连接功能的手机。每个设备由一个称为 **MAC**（介质访问控制）地址的唯一地址标识，它是六组十六进制数对。

虽然 MAC 地址描述了每个物理设备是什么，但用另一个执行相同工作的设备替换它通常很方便，有时甚至必要，且要求无缝切换。因此，为了在纯物理层面之上提供一个抽象层级，所有联网设备都被分配 **IP 地址**。在最初的版本（称为 `IPv4`）中，这些是 32 位地址，写作四组 0 到 255 之间的数字（每组基于地址的 8 位），例如 `64.233.160.1`。然而，由于连接到互联网的设备数量庞大，新版本 `IPv6` 于 2000 年代中期推出。它使用 128 位，地址写作 8 组十六进制数字。

IP 地址是分层的。例如，在 `IPv4` 中，第一组数字指定互联网的一个高层区域（通常由单一大型企业或互联网服务提供商拥有），下一组指定子区域，再下一组指定更小的区域，最后一组指定一组本地计算机的地址。因此，知道 IP 地址提供了一种自然的分层方式来查找拥有该地址的特定设备。
