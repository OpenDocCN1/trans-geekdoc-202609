

# 恶意软件部署的动机

## 牟利
部署恶意软件最明显的动机是罪犯利用它来牟利。这比看起来要难，但罪犯很有创造力，他们已经找到了方法。到目前为止最成功的是**勒索软件**。此类恶意软件使用仅攻击者知道的密钥加密目标机器的文件。然后恶意软件会告知用户需要支付多少钱才能再次解密文件系统。

在有完善备份的系统中，勒索软件只不过是个麻烦，但令人惊讶的是，有大量系统并非如此。毫不奇怪，针对中小企业的勒索软件攻击持续不断，英国国家医疗服务体系等大型目标也遭受了攻击。

正如大多数勒索案例一样，响应攻击支付赎金不是好主意。实施勒索软件攻击的网络机制可以作为黑盒被低级罪犯购买，实施勒索软件攻击的大多数罪犯甚至可能无法真正解密文件系统，即使他们想这样做。

## 知识产权窃取
许多企业拥有对其竞争对手或潜在竞争对手有价值的信息。这可能包括新设备的细节或计划，以及他们计划在合同上投标的金额。竞争对手有动机使用恶意软件发现此类数据并将其发送到目标组织之外供其使用（称为**知识产权窃取/数据渗出**）。与勒索软件不同，这类恶意软件试图保持尽可能不显眼，以便在不被发现的情况下进行渗出。完成工作后甚至可能删除自身，以留下尽可能小的痕迹。

## 抗议
网络空间为抗议他人（尤其是组织）的行为提供了现实世界的替代方案。一种流行的方法是通过将恶意软件插入 Web 服务器来篡改网页，因为这些是许多组织最显眼的在线部分。恶意软件也可用于更改密码，将合法用户拒之门外，或删除随机文件。这些影响不大，但很恼人，因为系统人员必须进行补救。某些形式的抗议针对国家政府，其适当性取决于你对政府合法性的看法。

## 拒绝服务
一种更严重的技术，通常由抗议或经济压力驱动，即**拒绝服务攻击**。其思路是用大量虚假流量淹没网络空间服务，使合法用户无法使用其服务。在现实世界中，这相当于以一种实际顾客无法进入的方式向商店派遣人群。这种攻击在现实世界中代价高昂，但在网络空间中却容易得多，因为制造虚假流量很便宜。

**直接拒绝服务攻击**由生成足够的流量到特定目标组成，导致目标或其周围的网络环境因过载而失效。直接生成足够的流量很难（且这种攻击可追溯到其源头），因此更常见的做法是在许多其他计算机上植入恶意软件。这组计算机的唯一目的是从许多不同方向大量生成流量。这些计算机上的恶意软件旨在保持隐藏，仅在需要其作为流量生成器的角色时才行动；此类系统称为**僵尸网络节点**。物联网系统是将其变为僵尸网络节点的特别热门目标，因为它们通常保护不力，有足够的能力生成流量，且没有人足够密切地监视它们以检测行为变化。

**分布式拒绝服务攻击**通过让所有这些僵尸网络节点同时开始向目标系统发起请求来触发。罪犯通常会随着时间的推移收集僵尸网络节点，并将其作为服务出租给任何想要用于拒绝服务攻击的人。创建和管理僵尸网络节点网络（**僵尸网络**）是将恶意软件货币化的另一种方式。

分布式拒绝服务攻击的目标通常通过呈现一个可以动态映射到后台不同服务器的地址来响应。早期的分布式拒绝服务攻击是成功的，但动态切换实际响应下一个服务请求的服务器的能力使得产生足够流量以压垮目标变得越来越难。

## 直接金融盗窃
某些恶意软件旨在用户（例如）登录其银行网站时收集凭证。罪犯随后可以使用这些凭证直接将资金转移到他们控制的账户。这代表了直接将恶意软件货币化的最简单方法之一，但银行往往对欺诈很老练，很可能迅速阻止可疑转账。这种盗窃也会留下可追溯到罪犯的痕迹，因为他们必须能够访问被盗资金转入的账户。

被盗凭证也可用于网上购物，使用不同的送货地址供罪犯取走购买的产品，但这风险更大，因为送货需要时间，在此期间欺骗可能被发现。当然，罪犯不使用自己的地址，而是使用方便的地址或空房子，跟踪送货以便知道包裹何时到达。（这是在线购物网站在你购买东西时发送电子邮件的原因之一——以确保是你本人操作。）

比特币等加密货币的兴起为罪犯提供了一种不可追踪地获取资金的方式，但这需要普通人将其金融体系货币转换为加密货币并发送给罪犯。

### 情报收集
由于几乎所有通信都通过网络空间传输，观察它是国家进行**信号情报**的主要方式。独立（军事）网络传输的数据较难收集，但由于它们与所谓的安全屏障之间存在泄露，以及直接窃听这些专用网络，仍然可能收集。在海底进行此操作是首选，因为可以在国际水域进行，且更难被发现。

网络空间中的信号情报问题与历史上相反——过去必须寻找*任何*有趣的数据，现在可以收集如此多的数据，以至于难以从中分离出有价值的部分。植入高价值目标的计算机、手机或至少其周边网络的恶意软件减轻了这个问题，因为那里收集的大多数数据推测都将是相关的。

情报也可使用用于知识产权窃取的数据渗出技术，从存储在其他国家的数据中收集。在某些国家，政府机构为国家目的和支持其本地产业都进行数据渗出。
