

# 前言

网络空间是我们所有人生活中至关重要的一部分。尽管我们都在使用它，但其大部分基础设施和运作机制对我们而言却是不可见的。

这一无处不在的系统起源于美国政府高级研究计划局（ARPA）开发的一个网络，该网络最初旨在连接政府和大学的研究实验室。参与者彼此信任且负责，因此安全性几乎未受到任何重视。

其后果延续至今。这个小型网络如野草般疯狂生长，直到连接起全球数十亿计算设备。在每一个阶段，设计决策的制定都优先考虑“下一个伟大的事物”，而安全性仍然几乎未受到任何重视。

于是我们发现自己身处这样一个环境——网络空间——它对我们许多人而言近乎一项基本服务，却需要付出巨大努力，以防范犯罪活动的负面后果、将网络空间视为廉价武力倍增器的政府行为，以及无聊和粗心大意者的不假思索的行为。

使网络空间更加安全是我们这个时代面临的挑战之一。这不仅（或许甚至主要）不是一项技术挑战。它要求政府和企业在可能的情况下鼓励安全，并确保其自身行为不破坏安全。

遗憾的是，一些有能力推动网络安全改进的人——律师、政治家——并不具备充分理解这些问题的技能。本书旨在通过以非技术背景读者也能理解的方式描述这些问题，来帮助改善这一状况。

这不是一篇研究专著，因此我未收录研究文献的参考文献。对于希望更深入探究特定主题的读者，有大量网站可提供进一步信息。我希望您在此阅读的内容足以让您理解那些更具技术性的阐述。

当今成功的书籍，其标题似乎要么包含三个动词，模仿《吃、祷告、爱》的模式；要么包含“女孩”一词。我想不出符合第二种类型的标题，也觉得“计算、攻击、防御”作为第一种类型的标题并不合适。

# 第一章

# 简介

网络空间——计算机系统、设备及连接它们的网络的组合——无处不在。网络空间最显而易见的部分，也是大多数人接触过的部分，是互联网，但网络空间还有许多其他组成部分：自动化生产线、独立的军事网络，以及技术上属于互联网一部分但普通用户难以访问的暗角。我们作为个体，显性地利用网络空间进行工作、购物和娱乐；但它在不那么显性却更重要的层面上，被用于维持我们社会的运转，涉及制造业、服务业、金融市场和政府。

尽管网络空间无处不在，但即使我们在使用它时，其大多数结构对我们而言也是不可见的。我们通过手机或电脑与它交互，但为网站提供动力、让我们能够管理银行账户、预订行程和酒店、使用电子邮件或社交媒体通信的服务器，并不容易被察觉。连接我们的接口设备与这些服务的“管道”也几乎完全隐藏。从用户角度来看，使这个庞大、复杂的系统如此不显山露水、行云流水，是一项重大成功。

然而，从安全角度来看，网络空间的不可见性造成了一个问题——人们对其运作方式缺乏直觉，因此无法轻易判断哪些行为潜在危险。这有点像游览一个以旅游为主的城市，却因未意识到贫民窟的存在而误入歧途。在网络空间中，很难评估任何特定行为的风险，许多“规则”都缺乏解释，或者至少缺乏有意义的解释，使用户无法理解规则在何种情况下有合理的例外。例如，一条常见规则是“不要打开陌生人的电子邮件附件”，但在实践中这往往行不通。如果你不知道 `From:` 电子邮件地址可以被伪造，那么看似相反的规则“打开熟人发来的附件没问题”有时会导致不幸的后果。
