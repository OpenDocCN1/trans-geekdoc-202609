

# 生物识别系统与认证

生物识别系统也会失效，因为并非每个人都有手指、手、耳朵、眼睛、面部或声音，因此必须始终存在备用认证机制。这增加了成本，因为在使用生物识别认证的每个地方都需要提供第二种机制。

第二个缺点是，我们通常每种生物特征只*有一个*。如果某生物特征（通常是其编码版本）被泄露，则无法签发一个新的。

当生物识别认证必须远程进行（例如允许访问网站）时，生物特征的编码必须在采集点完成，然后将编码版本传输到网站进行匹配。这在采集点造成了漏洞，因为编码版本可能被拦截，随后在稍后或不同的接入点重放。这可以像密码一样通过变通方法解决，但采集生物特征的设备并不总是成熟的，因此可能容易被滥用。

“你所知”（知识因素）能提供温和的保证，即正在认证的是授权人员。“你所是”（生物因素）能提供大得多的保证，尽管并非完全可靠。“你所有”（拥有因素）的弱点在于，其使用与被授权使用它的人之间没有必要的联系。

这些机制可以组合使用（称为*双因素认证*），以试图取长补短。然而，认证通道越多，对人类用户来说就越麻烦，他们也就越有可能感到恼火并寻找变通办法。

# 4.2 恶意软件

如果只有经过适当认证的用户才能使用其计算设备和软件，那么许多网络攻击将变得困难得多。不幸的是，人们经常做着网络空间中相当于“为怀有恶意者打开大门”的事情，允许他们获得对自己环境的认证访问。

允许恶意软件（*malware*）被植入计算机，当然不是普通用户故意为之，但有许多途径会导致这种情况发生。通常，这是用户无意识操作的结果。发生这种情况时，指责用户是常见的做法，毫无疑问教育能产生巨大影响；但网络空间的大部分设计使得攻击者太容易诱导普通用户做一些不安全的事情了。

常见途径之一是用户下载了包含隐蔽恶意软件的软件或应用程序，这些恶意软件隐藏在其公开功能内部。对于下载到手机上的应用，应用商店会尝试确保可用应用不含恶意软件，但其过滤流程并不总是奏效。对于个人电脑，从任何网站下载软件都很容易，因此相应地存在更大的风险。操作系统开发商正试图转向一种对下载软件提供更多审核的模式，但这尚不普遍，而且制造商正利用这种额外的安全性作为借口，收集更多用户数据转卖给社交媒体企业。

另一种常见的植入恶意软件的方式是将其附加在电子邮件中，伪装成数据。例如，电子邮件附件可能看起来像某种文档，但实际上包含可执行代码，这些代码本身就是恶意软件或会安装恶意软件。当此类恶意软件附加在随机发送给大量电子邮件地址的邮件中时，被称为*网络钓鱼*。电子邮件也可能包含链接，点击这些链接会跳转到下载恶意软件的网站。

越来越多的携带恶意软件的邮件针对特定收件人，这被称为*鱼叉式网络钓鱼*。攻击者可能会花费大量精力使邮件看似合理：伪造发件人地址为收件人可能预期的地址，并确保附件的表面内容是真实的，以便在打开时收件人甚至可能没有意识到已安装恶意软件。鱼叉式网络钓鱼还可能利用社会工程学，使其看起来像是来自收件人的老板，甚至是公司 CEO。

网络钓鱼邮件日益泛滥，严重影响了沟通，因为无论技巧多么高超，人们仍有可能被骗。我们可以看到这种开端：人们通过另一种方式（如短信）联系对方，询问电子邮件附件是否合法。

某些形式的恶意软件，称为*蠕虫*，可以利用控制网络空间流量的底层机制在系统间传播。当这种情况发生时，系统无需用户做任何操作就能感染恶意软件。因此，蠕虫可以传播得非常快。

从某种意义上说，恶意软件也可以针对人而非节点——网络霸凌、通过电子邮件发起的诈骗以及错误信息的传播。

# 4.3 恶意软件有什么作用？

大多数计算机系统将其操作分为三类：任何用户均可执行的操作；仅操作系统可执行的操作（因此需要具有特殊权限的管理员账户）；以及系统首次开机时执行的操作。任何用户可执行的操作受限最多；用户可以使用计算机上的软件，但通常无法安装某些类型的新软件，也无法查看或更改关键文件。操作系统可以在整个运行中的系统内执行任何操作。因此，操作系统账户（管理员账户）仅限受过培训（包括安全培训）的系统工作人员使用。在手机系统中，操作系统功能完全不对用户开放，始终由操作系统开发商控制（除非手机被 Root）。最后，设备开机时执行的操作权力最大，因为它们发生在任何检查之前。

恶意软件可以针对这三层中的任意一层。用户空间恶意软件最容易植入，因为普通用户的操作可能创造机会将其秘密安装，但因此它拥有的机会最小。这就是为什么通常建议用户始终使用此类账户进行日常工作，即使他们完全控制自己的系统，本可以对所有事情使用管理员账户。

针对操作系统层面的恶意软件较难植入，因为它需要更高级别的权限，但提供了更大的机会。针对设备开机时执行代码的恶意软件最难植入，但当然也是最强大的，因为它控制着设备的配置方式。

恶意软件的清除难易程度也反映了其最初植入的难度。恶意软件检测软件通常能发现用户空间恶意软件，也常能发现操作系统中的恶意软件，但发现并清除设备开机时运行的代码中的恶意软件要困难得多。

恶意软件也可能被植入硬件本身。这类恶意软件需要在制造过程中植入，成本高得多，但也难以检测得多。这通常是国家级行为体的领域。
