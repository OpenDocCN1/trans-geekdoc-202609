

# 网页浏览与网络空间

网页浏览是最直观的。网页内容存储在大型计算机系统上，称为 Web 服务器。每当有人打开浏览器并输入 URL（或点击链接）时，请求就会被发送到相应的服务器，然后网页被发送回浏览器。虽然界面给人一种我们在访问网站的印象，但现实是网站的页面在访问我们。

## Web 服务器

在 Web 早期，Web 服务器向浏览器提供预构建的网页，随后由浏览器负责在用户使用的任何设备上显示它们。超文本标记语言（HTML）描述了网页每个部分是什么类型的内容（标题、段落），这使得 Web 浏览器能够以在用户特定设备上产生最佳效果的方式显示页面。例如，浏览器可以将显示的页面适配至可用的屏幕尺寸。

当 Web 服务器获得在请求时动态创建页面的能力后，出现了更多有趣的可能性。现在，特定用户看到的网页可以为该用户定制——也许针对不同国家或地区的用户有所不同。

当用户的浏览器能够向服务器传达个性化信息时，这种能力变得更加强大。其显而易见的用途是搜索——用户输入搜索词，搜索引擎（一种专门的 Web 服务器）返回一个包含与上传搜索词匹配结果的定制页面。用户可以与银行 Web 服务器通信，并看到一个包含其个人账户余额的页面。

下一阶段发生在浏览器具备下载小段软件（连同页面内容）的能力时。Web 服务器利用这一机制，可以让浏览器代表其执行某些操作。这是网上银行、网上购物以及所有其他双向交互（用户既输入信息又查看内容）的关键。

这些机制也有负面作用——它们可以且确实被用来在浏览器中存储信息（`cookies`），这些信息可以识别同一用户何时再次访问同一 Web 服务器，以及越来越多的其他服务器。换句话说，这个丰富的通信通道成为了追踪用户行为的渠道。

在某些交互中，重点更多在于从用户到网站的信息流，而非相反；例如，上传视频到 YouTube。机制是相同的——服务器下载代码，建立一个从浏览器到服务器的通信通道来控制上传。

社交媒体网站使用这一相同的基本机制，但它们不是使用（通用的）浏览器，而是将交互打包在一个应用程序中，并尽可能让用户下载该应用。对社交媒体网站或企业的优势在于，应用程序可以运行*任意*代码，而非浏览器中运行的受限代码。因此交互可以更丰富。这种更丰富的交互不一定是好事——正是它使得详细收集每个用户（有时甚至包括其系统）的数据成为可能。

许多其他企业也做同样的事：创建一个直接与其 Web 服务器交互的应用程序，而不是让用户使用浏览器访问其网站。该应用程序只不过是其网站的一个专用前端，但它允许同类型的更丰富交互。这主要有利于企业而非用户。此类所有应用程序的风险在于，它们可能实现粗糙，因而存在自身严重的安全弱点，且无法利用大多数现代浏览器内置的安全措施。

## 通信工具

用户遇到网络空间的另一个主要方式是作为通信工具：电子邮件、即时通讯（多种形式）和视频聊天。其中一些是一用户设备与另一用户设备之间的对称交互，但一些通信应用将所有通信路由通过服务器。第一种选择更难实现但更私密，但大多数工具使用第二种选择。

区分同步通信（消息立即传送到另一端），如视频聊天和即时通讯；以及缓冲或异步通信，即可存储在某个中间位置直到接收者可用（电子邮件），这也很有用。

## 业务与基础设施

网络空间还有许多方面对普通用户并不明显。许多企业与其员工保持通信，尤其是那些不在办公室工作的员工。它们还收集数据，通常是实时的，关于其业务活动。例如，交通系统随时跟踪每一列火车或每一架飞机的位置，以及它们性能表现的许多其他细节和何时可能需要维护。为了实现在线酒店预订网站，酒店连锁必须持续准确地记录哪些房间在何时可用。零售店精确跟踪其每家门店售出的商品，以便装载并调度送货卡车，使其恰好在需要时到达，且车上装载的正是所需产品。电网和油气管道必须跟踪其输送系统的全程性能，并能控制远程设备调高或调低、开启或关闭。

企业还利用网络空间相互通信，提供供应链信息或以我们从在线零售商购物的相同方式相互采购。与消费者网购不同，这些交互通常是自动化的。例如，汽车装配线基于所有组件从供应商的准时制交付，以便零件在需要时刚好到达装配线。这降低了仓储所需的成本和空间。

## 政府用途

政府面向公民地使用网络空间，在线提供服务，如更新驾照、征收税款等。

政府还将网络空间作为权力工具使用。几乎所有通信都在网络空间中传输，因此大量情报收集已从无线电拦截转移到网络空间拦截。政府还将网络空间作为武器系统，规划（有时实施）针对其他国家的网络攻击。

## 犯罪活动

罪犯利用网络空间，既作为收集信息的方式，也作为实施犯罪的手段。直到最近，除了直接攻击金融机构和金融转账外，很难直接在网络空间赚钱，但 `cryptocurrencies`（加密货币）的兴起使得从个人和企业勒索钱财成为可能，且无法追踪，这在网络空间中创造了一类新的犯罪。

## 总结

因此，普通人看到的网络空间部分只是冰山一角。组织之间以及网络空间内部存在大量其他通信和交互。整个系统过于复杂，无法直接由人工管理，因此幕后还有一层自我管理，确保即使用户采取的行动发生变化，连接仍能保持运行。

个人在网络空间面临安全问题，但在网络空间其他不太可见的部分也存在许多其他漏洞。

# 2.2 什么是网络空间？

网络空间是世界上所有连接的数字基础设施的总和。最明显的部分是互联网，以及其中的万维网。但也存在各种其他网络，主要是军事网络，它们未显式连接到互联网，还有所有连接到互联网但未被人类显式使用、且我们往往会忽略的设备。
