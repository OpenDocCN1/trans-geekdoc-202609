
正如现实世界的高速公路一样，必须有机制来处理边缘故障，以便流量能够绕过故障点进行路由。因此，路由表必须不断更新以反映不断变化的网络拓扑，这也需要控制消息。

流量的变异性也意味着整个区域可能变得拥塞，因此可能需要将流量绕过整个区域以避免拥塞。正如现实世界中那样，这可能会造成一种动态局势，导致不稳定发生——将流量引导至拥塞区域周围会产生新的拥塞区域，而原来的区域则变得不那么拥塞。随后这一过程会反向进行。拥塞控制机制可能被颠覆（现实世界中也是如此），以制造人为拥塞，或将流量引向特定地点以便对手进行分析。

特定节点或节点集可能希望阻止来自世界某些部分的流量，或阻止特定类型的流量，因此网络中也包含称为 `firewalls`（防火墙）的网关。例如，这些网关可以封锁整个国家，即所谓的“中国防火墙”，但它们更常用于仅阻止特定类型的流量进入企业或政府的子网络。换句话说，它们充当流量过滤器，允许某些流量通过而丢弃其他流量。

个人也会在手机或个人电脑上使用一种网关。这些被称为 `malware detection systems`（恶意软件检测系统）或 `antivirus systems`（杀毒系统），用于阻止特定类型的流量进入。

除了维持流量流动且方向正确的控制功能外，网络管理的另一个方面是将人类可读的地址（如 `cnn.com`）映射为 IP 地址，以便访问。实现这一机制的是 `Domain Name Service`（DNS，域名服务）。它由一组维护两种名称之间映射关系的特殊系统组成。

互联网是目前地球上规模最大的网络，连接着所有国家的设备。然而，还有其他网络（至少在理论上）未连接到互联网。大多数军队拥有自己独立、更安全的网络，这些网络与互联网没有直接连接。尽管这些网络在物理上是隔离的，但它们使用与互联网相同类型的节点、管道和控制机制，因为否则做法既不切实际又成本高昂。这使得它们一旦被攻击者访问，就会面临与普通互联网相同的许多攻击——单一文化问题再次显现。

网络之间的隔离可能是虚幻的，有时可以跨越它们之间的“气隙”。例如，用于破坏伊朗铀离心机的 Stuxnet 恶意软件，是通过从互联网加载的 USB 密钥引入的，随后这些密钥被插入控制离心机的隔离网络计算机中。这是这些隔离网络的常见弱点——必须有机制更新其中节点上的软件，而这创造了一个桥接通道。

每当互联网上的设备与这些隔离网络上的设备彼此靠近时，它们还可能利用人耳听不到的高频音频进行通信，或利用一台设备的摄像头拍摄另一台设备的屏幕图像。

## 2.7 流量类型

使互联网成为可能的关键发展是 `packet switching`（分组交换）的概念。发明分组交换的原因，正如银行等机构不再使用多队列，转而采用单一大队列配合多服务窗口一样。如果数据传输是先传完第一整批数据，再传第二批，依此类推，小批量数据将不得不等待，潜在时间很长，直到大批量数据传输完成。想象一下一条短信卡在电影下载后面的情景。

相反，发送到网络连接上的每一批数据都被分割成相当小的片段，每个片段独立发送。这意味着小数据传输不会卡在大数据传输后面，因为无论片段来自哪一批数据，它们以大致相同的速率向目的地推进。小数据批次会比大批次更早传完所有片段，但将所有数据都分割开能公平地利用管道容量。（正如我们将看到的，这种技术在分割和重组数据块时引入了开销，这本身也带来了问题。）

虽然分组交换是平等的，但也意味着某些类型的数据得不到良好服务。例如，如果数据传输是实时观看的大型视频（而非单纯下载），关键在于新帧必须以足够快的速率出现以供观看。此类流量面临着持续不断的截止日期要求，其他干扰这些截止日期的流量会产生直接、可观察的性能影响。

语音通常通过转换为数据（称为 `Voice Over IP`，即 VOIP）在网络上传输，这也有相同的问题。如果下一段语音数据未能及时到达以便按适当速度播放，音频质量会听起来断断续续，体验不佳。作为人类，我们能察觉毫秒级的延迟，即使无法有意识地感知。

为了处理这些特殊流量，仅使用移动数据包的机制，需要额外的协议层。这增加了管道操作的复杂性，管道必须对紧急流量特殊对待；节点也必须确保有足够的空闲缓冲容量以维持其流动。

## 2.8 深网

互联网中有部分内容并非对所有人常规可访问。我们已提到过那些（至少在理论上）未连接到互联网的网络。

另一个对普通用户不太可访问的网络空间部分称为 `deep web`（深网）。它包含未被搜索引擎索引的节点和内容，因此大多不可见，因为无法直接找到它们。

深网包含两类不同的内容。第一类是隐藏内容，指不能通过简单访问包含它的网页来获取。当你登录网站时，你获得了访问该站点数据存储中内容的权限，这些内容通常是个性化的。例如，登录银行网站时，你可以看到账户余额。此类内容他人不可见，也无法被搜索引擎索引，因为它仅在你个人查看时才存在。

深网的第二部分由没有公共访问路径的节点组成。搜索引擎查找万维网所有页面的方式是从显而易见的地方开始，然后顺着链接发现新地方。如果一个网站建立后没有任何链接指向它，就无法通过常规方式发现。但该网站仍可通过将地址分享给可信赖的朋友来发挥作用。（这是 `security by obscurity`（隐匿性安全）的一个例子，因为它依赖于包含地址的邮件不被邮件提供商扫描，从而提取地址并搜索。）
