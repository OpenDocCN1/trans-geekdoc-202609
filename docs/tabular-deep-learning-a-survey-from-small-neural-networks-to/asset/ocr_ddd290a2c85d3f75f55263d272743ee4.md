Unfortunately, tabular data is heterogeneous, posing challenges such as mismatch between features, change of distribution, and so on. Nevertheless, there are various examples in literature. For example, sTab shows how a model trained on organic or generic datasets can be used for other smaller datasets [287]. sTabNet shows that a tabular representation can be learned and then can be used to extract features for other tasks. Levin [199] uses pseudo-features to solve the problem between the pre-training and fine-tuning. This approach works well for small datasets with increased performance. TransTab [355] treats both rows and features and creates a common embedding space to solve the problem of heterogeneity of tabular data. TabTab [371] is suggested instead of embedding a single cell at a time (the cell is seen as a key-value pair between row and column name). The authors conduct pretraining on a huge dataset (and can thus learn a generalizable representation) that can then be used for various tasks. These approaches are attractive for fine-tuning a model.
