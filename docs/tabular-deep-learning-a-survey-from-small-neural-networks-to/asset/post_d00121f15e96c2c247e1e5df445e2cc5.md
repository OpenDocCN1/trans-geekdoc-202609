SAINT [121] is a specialized variant of SAINT for medical tabular data. SAINT inherits its attention mechanism but focuses on being robust to noise and values, using Mix and Cutmin. FT-Transformer [113] also uses an embedding block, providing a better representation. In fact, although it seems counter, embedding features helps [111]. In the FT-Transformer, a special CLS token is used before encoding the input into the transformer. The CLS is contextualized, and it will be used for prediction (Its representation is then passed into a final MLP). Modified attention is used to learn relationships between figures that are difficult to learn with other models. For the authors, this model is superior to other tabular learning models such as TabNet, Node, and MIF. Subsequently, the FT-Transformer has been used for several applications with fair success, example, has been applied to data clinic or network intrusion [270, 176, 298]. The LF-Transformer [246] introduces a latent feature mechanism within the transformer architecture to achieve complex feature interactions in tabular data. This approach is inspired by matrix factorization techniques commonly used in recommendation systems, where goal is to decompose a matrix into latent factors that capture underlying patterns. It uses column and row features to capture latent relationships in columns and rows, observing that this embedding is then passed into the transformer. The latent feature mechanism of the LF-Transformer effectively capture complex and model interactions between features and achieve a more abstract and informative representation of the data. AMFT [371] introduced additive and multiplicative attention mechanisms to capture relationships that are diverse in tabular data. TabTransformer [355] is a Transformer-based model for learning across tabular datasets with different structures. TabTrans, using a dedicated embedding space, tries to solve the transferability problem in learning learning, especially when different datasets have varying columns and features distributions. TabTrans does not assume fixed input dimension but processes each (at the same incorporating the column description into the model to better contextualize (the examples) and used a gated mechanism to control the flow of information. TransTab trained with both labeled and unlabeled data to improve generalization, and self-supervised pruning allows for better representation when there are few or no labels. TransTab is an interesting idea for transfer learning with tabular data, feature re-attention automatically, but requires a high computational cost and a clear description of features. Non Parametric Transformers (NPT) [185] use the entire dataset and predict the interactions between learned data. To do this, it exploits both parametric and nonparametric approaches, learning to balance these two. Using self-attention and stochastic masking allows the model to learn the causal hidden data generation. MambaTab [55] adapts state-space models (SSMs) for tabular data. SSMs are capable of modeling long-range dependencies, improving efficiency, and handling complex data. MambaTab utilizes the Mamba architecture for end-to-end training, allowing it to capture dependencies across features with fewer parameters than similar models, making it a promising approach for tabular learning tasks. There are also other ways to use the mamba architecture for tabular data, either alone or in combination with transformers. Tab [353] is a framework designed to handle tables with varying numbers of columns and tables, enabling cross-table features. It achieves this by using independent features and federated learning-techniques (such as FT-Transformer). XTab learns from multiple tabular datasets, simultaneously processing them from different datasets with enhanced features before merging. This design, which integrates information from different sources, allows the model to handle heterogeneous feature spaces. The features are then fed into a shared transformer-based model. This approach allows XTab to minimize and improve transferability across datasets in inference, and is more robust than other methods at handling new data. The model is not easily scalable (the current limits with up to 10,000 data points and 500 features), although it is slower than traditional models, and it depends on the quality and diversity of the synthetic data used during pretraining (IV). UseTab [371] is designed to handle the complexity of real-world data by using multiple tables through a single training and testing pattern on large datasets (the authors collected 13 billion examples spanning from different domains to learn generalizable patterns). In UseTab, the key represents the column name and value represents the center entry, after it is concatenated to pass in a single cell embedding. Next, a transformer is used as encoder and decoder to learn relationships and handle shallow dependencies. Tabular data adaptation for the transformer.
