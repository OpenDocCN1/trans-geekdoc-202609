In general, there are three possible strategies for obtaining an ensemble of models: varying the data for each model, varying the output of individual models, and combining the output differently (fig. 6).

**Data variation.** In the simplest case, one can obtain an ensemble with k-fold cross-validation in which each model is trained on only one fold. Or one can sample without replacement (bagging), where each model is trained on only one subset of the data. Dropout can be seen as a kind of regularization [102]. Boosting is an alternative in which each model tries to correct the errors of the previous ones, giving greater importance to examples misclassified by the previous model. Boosting has been used with CNNs with interesting results. An interesting approach to tabular data modeling is HyperTab, a hypernetwork method [360]. A hypernetwork generates the weights of multiple targets, each specializing in a subset of features, effectively learning the data. The model operates by applying a mask to select which features will be used for each target. On this mask, the hypernetwork generates weights dynamically, using a featured input. The network then processes only the subset of features, producing an output, and the final is obtained by aggregating the outputs of multiple targets. A key distinction of HyperTab is weight optimization, where the target is dynamically learned rather than explicitly. This reduces the number of parameters, which is particularly advantageous for small datasets. The use of dropout through stochastic binary masks acts as a form of data augmentation, improving generalization by exposing the model to diverse feature combinations and perspectives of the dataset. Beta [218] is a variant of TabPFN that uses multiple lightweight encoders and bagging to reduce variance. Taking advantage of an

ensemble-like approach improves the performance and scalability of the model for high-dimensional data and larger datasets, while maintaining computational efficiency.

**Model variation.** Given the stochastic nature of neural networks, each training leads to a different model with slightly different performance. To get more models, one can vary hyperparameters (such as learning rate). Hyperparameter variation leads to independent errors, making the ensemble of models stronger [109]. Techniques such as bagging are computationally expensive, an alternative approach is to train an independent ensemble. For example, approaches that train a single model and dectate layers to create different models via seeds [144, 310]. During training, one can obtain several snapshots of the model and use them as ensembles [143]. Using models trained at different epochs could be considered as a snapshot ensemble [361]. Other approaches have shown diversity, for instance using trees where different branches are built to obtain an ensemble [197, 125, 350]. Or one can use a pre-trained model and knowledge distribution to obtain different models. Heterogeneous ensembles can also be created in a neural network along with additive learning models [201], which solution is often effective. HyperFast [156] attempts to solve the traditional hyperparameter tuning for tabular classification. HyperFast is a hypernetwork to generate a task-specific classifier. HyperFast uses a hypernetwork to generate the parameters of a neural network for each class. In this way, each dataset leads to a different instantiation of the model (a new set of weights). By training the model on different datasets, the free explores a diverse space of potential classifiers, allowing different models to be generated, tailored for the dataset at hand.
