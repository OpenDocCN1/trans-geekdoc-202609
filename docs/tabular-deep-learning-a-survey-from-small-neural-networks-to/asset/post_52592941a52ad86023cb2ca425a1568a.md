# Abstract

Tabular data are ubiquitous in several real-world domains, including finance, healthcare, cybersecurity, and ecommerce. In spite of the dominance of deep learning for homogeneous data (such as computer vision and natural language processing), gradient-boost decision trees (GBDT) remain the state of the art for tabular data tasks. Several models have been developed over the years that have attempted to address the shortcomings of deep learning, narrowing the gap with GBDTs. This survey provides a comprehensive review of deep learning for tabular data, covering a systematic taxonomy and a set of resources. We discuss the strengths and limitations of the most recent models, we examine the role of self-supervised learning, pretraining strategies, and AutoML in tabular deep learning. In addition to architectures, we discuss practical considerations including interpretability, scalability, suggestions for model choice and discuss open issues and future trends. This survey is a practical resource for researchers and practitioners, offering insights into the current landscape and trajectory of deep learning for tabular data.

**Keywords:** tabular data, deep learning, neural networks, transformers, large language models

# 1. Introduction

Tabular data is the dominant data format in real-world applications, including finance, healthcare, Ecommerce, and cybersecurity. Deep learning's dominance in structured domains like images and language has not extended as effectively to tabular data, where traditional methods still prevail. In fact, for long-term, tree-based models (such as XGBoost, GBM, and CatBoost) have outperformed deep learning in most tabular data tasks. This is due to the complexity of tabular data (number of features, small size diversity, required preprocessing, lack of inductive bias, or overfitting), which has allowed them to define a winning architecture for deep learning. However, over the years, several architectures have developed specifically for tabular data that have improved the performance of deep learning models. This survey provides a comprehensive and up-to-date review of learning for tabular data, covering the following points:

- Challenges and limitations of both neural networks and decision trees.
- A taxonomy of deep learning models that takes into account recent developments, both new architectures and adaptation of models previously developed for others.
- Trends that are occurring within the tabular data and surveys comparing models.
- Challenges and open research questions.
- Resources specific to tabular deep learning.

# 2. A definition of tabular data

Tabular data can be defined as a sub-branch of structured data. Any data that can be defined as a table in, by convention, the rows represent examples and the columns represent features. Unlike unstructured data, in their real-world applications, most data are in tabular format (they are dominant in finance, medicine, climate science, and manufacturing).

In contrast to images, text, or audio (all homogeneous because they have only one type of feature, since they can contain multiple types of features, tabular data is heterogeneous (fig: 1):

- Categorical values: A particular type of feature that contains qualitative (or discrete) values, which represent a limited set of terms, without an intrinsic order. Examples include gender, class, and product class.
- Binary values: A special case of categorical features, where the feature can have only two values (generally 0 or false). An example is the vital status of a patient, which can be either alive or dead.
- Ordinal values: A special type of categorical feature, where the values are discrete, there is an intrinsic order. Examples include the frequency of gym activity (sometimes > rarely) or highly expressed in discrete values (age > short).
- Continuous values: A feature that contains continuous values.

For a linear model, the relationship is typically given by:

```
$f(X) = WX + \mathbf{b}$
```

where $W \in \mathbb{R}^{d \times n}$ is a matrix of weights, and $\mathbf{b} \in \mathbb{R}^d$ is the bias.

In the case of a neural network with a single hidden layer (a multilayer perceptron), a non-linear function $\sigma$ is introduced:

```
$f(X) = \sigma(WX + \mathbf{b})$
```

where $W \in \mathbb{R}^{d \times n}$ and represents the number of neurons in the hidden layer.

In a multilayer perceptron (MLP) with multiple layers, the representation at layer $l+1$ is:

```
$H^{(l+1)} = \sigma(W^{(l)}H^{(l)} + \mathbf{b}^{(l)})$
```

For a neural network training, the difference between the predictions and the labels is minimized by a loss function:

```
$\min_{\theta} \sum_{i=1}^{N} L(f(x_i; \theta), y_i)$
```

In some cases, a regularization term (where $\theta$ is a generic function) may be added to training:

```
$\min_{\theta} \sum_{i=1}^{N} L(f(x_i; \theta), y_i) + \lambda \Omega(\theta)$
```

The specific definition of $\hat{y}$ and $y$ depends on the task, such as cross-entropy for classification and mean squared error for regression.

## 2.1. Background

More formally, a tabular dataset is described as consisting of $n$ instances and $d$ features, respectively denoted as $X \in \mathbb{R}^{n \times d}$ (sometimes denoted as $X \in \mathbb{R}^d$), and $x_j$ denotes the $j$-th feature of the $i$-th example. This definition applies to both unsupervised and supervised learning. In supervised learning, each case is associated with a label, $y$. The target value is a single value (vector) given below:

## 2.2. Tabular data

Regression and classification tasks are unique. The simplest but most common case of classification task is binary classification. The starting point of classification evaluation is the confusion matrix (a matrix representing all possible combinations of real labels). Next, a single value is obtained from the confusion matrix by aggregating statistics. These metrics capture a particular aspect of the task, and each has its own flaws.

However, it is useful to reduce the confusion matrix to a single metric [25]. Accuracy, Area Under the Curve (AUC), and F1 score are the most widely used metrics, as it can be thought of as the probability of observing a correct prediction in testing.
