While MLP layers can learn features implicitly, DCN uses encoder-decoder components to learn feature interactions. DCN V2 extends this, improving efficiency while capturing more complex feature interactions. Transformer [146] introduces a deep learning model designed to enhance performance on tabular data. The model uses learnable permutation mechanism, targeted attention, and an adaptive feedforward network to address specific MLP challenges (lack of relational variance property, large data, over-smoothness problem). TabTransformer [159] introduces an encoder-decoder architecture, where the encoder inputs to embeddings and the decoder reconstructs the data from the embeddings. This facilitates the separation of temporal (shared) and relational features among all columns through the use of separate parameters. Feature decoding allows capturing many and unique features of data, thus obtaining much better performance than using autoencoders (AE). The system can be trained with a self-supervised learning objective to handle unlabeled data and then for classification or regression. It also uses feature corruption to improve learning and interpretability. The Bidirectional Sparse Hopfield Network (BiShop) [363] is a framework inspired by the brain's memories, where different regions overlap to form and retrieve memories. BiShop uses models (an extension of Hopfield networks with enhanced sparsity and embedding capacity) to find good column-wise and row-wise patterns. After encoding for categorical and numerical variables, there are stacked BiShop models (consisting of two connected GSH for columns and one for others), allowing between-feature and intra-feature interactions at different hierarchical scales.
