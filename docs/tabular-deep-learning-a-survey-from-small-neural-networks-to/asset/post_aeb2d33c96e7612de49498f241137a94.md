Graph encoding. Tabular data can be encoded as graphs, where different methods transform tabular data into graphs. Once a graph is obtained, Graph Neural Networks (GNNs) can be used. One of the advantages of this approach is the flexibility; it is possible to design different types of graphs to represent the data (graphs, bi-partite, hyper-graph, multi-graph, and so on). This reduces feature engineering by being able to select the type of best feature from data and task. GNNs handle the relationship between features without the need to be explicitly coded (e.g., building a feature that is part of two features). For example, TabGNN [66] extends GNNs to learn similarity with the correlation and the interaction between features. In addition, these approaches work well when there are several columns linked together, as in relational databases. For example, in this work [66] uses a GNN to contain the data in relational databases to reduce feature engineering with good performance. There are similar approaches that use similarity measures (e.g., cosine similarity, Jacobi index, correlation, or Euclidean distance) to refer to edges. Another interesting approach is to connect data into a graph; this study [71] exploits metadata to connect to nodes and leverage prior knowledge. GNNs also have other interesting, as the fact that they can be used for classified nodes in semi-supervised learning, propagate the information of similar examples (message passing), and learn embedding where similar examples are near. Similar approaches have been used for applications such as anomaly detection, Click Through Rate (CTR) prediction, missing data imputation, medical prediction, and more. CARTE (Attention-based Representation of Tabular) [77] uses tabular transformation to solve two types of schemes data change (variations in columns, orders, or naming) and entity matching (terminologies or representations). CARTE represents each table as a graph where nodes connect entries to the respective column names and neighboring entries within the same row. Both table and column names are embedded similarly and captured within both rows and columns. After, the system uses a graph-attention network (GAT) to generalize the entities and relationships. The model is pre-trained on a large knowledge base to align entities, thus being able to learn a wide range of problems. The model, once pre-trained, CARTE simplifies the integration of different datasets, with a wide array of representations and relations, improves performance, and can be used for small datasets. ## 7.2. Neural ensembles

Neural networks have bias but high variance. Tree ensembles (such as XGBoost) reduce variance and achieve higher performance than MLPs. In addition, random initialization of a neural network leads to a different model each time the architecture is trained.

In general, there are three possible strategies for obtaining an ensemble of models: varying the data for each model, varying the output of individual models, and combining the output differently (fig. 6).

**Data variation.** In the simplest case, one can obtain an ensemble with k-fold cross-validation in which each model is trained on only one fold. Or one can sample without replacement (bagging), where each model is trained on only one subset of the data. Dropout can be seen as a kind of regularization [102]. Boosting is an alternative in which each model tries to correct the errors of the previous ones, giving greater importance to examples misclassified by the previous model. Boosting has been used with CNNs with interesting results. An interesting approach to tabular data modeling is HyperTab, a hypernetwork method [360]. A hypernetwork generates the weights of multiple targets, each specializing in a subset of features, effectively learning the data. The model operates by applying a mask to select which features will be used for each target. On this mask, the hypernetwork generates weights dynamically, using a featured input. The network then processes only the subset of features, producing an output, and the final is obtained by aggregating the outputs of multiple targets. A key distinction of HyperTab is weight optimization, where the target is dynamically learned rather than explicitly. This reduces the number of parameters, which is particularly advantageous for small datasets. The use of dropout through stochastic binary masks acts as a form of data augmentation, improving generalization by exposing the model to diverse feature combinations and perspectives of the dataset. Beta [218] is a variant of TabPFN that uses multiple encoders and bagging to reduce variance. Taking advantage of an ensemble-like approach improves the performance and scalability of the model for high-dimensional data and larger datasets.

**Model variation.** Given the stochastic nature of neural networks, each training leads to a different model with slightly different performance. To get more models, one can vary hyperparameters (such as learning rate). Hyperparameter variation leads to independent errors, making the ensemble of models stronger [109]. Techniques such as bagging are computationally expensive, an alternative approach is to train an independent ensemble. For example, approaches that train a single model and dictate layers to create different models via seeds [144, 310]. During training, one can obtain several snapshots of the model and use them as ensembles [143]. Using models trained at different epochs could be considered as a snapshot ensemble [361]. Other approaches have shown diversity, for instance using trees where different branches are built to obtain an ensemble [197, 125, 350]. Or one can use a pre-trained model and knowledge distribution to obtain different models. Heterogeneous ensembles can also be created in a neural network along with additive learning models [201], which solution is often effective. HyperFast [156] attempts to solve the traditional hyperparameter tuning for tabular classification. HyperFast is a hypernetwork to generate a task-specific classifier. HyperFast uses a hypernetwork to generate the parameters of a neural network for each class. In this way, each dataset leads to a different instantiation of the model (a new set of weights). By training the model on different datasets, the free explores a diverse space of potential classifiers, allowing different models to be generated, tailored for the dataset at hand.
