Once you get different models, you can consider different types of elements by aggregating the outputs of the individual models in different ways to get the final prediction (7). Majority voting is the simplest, in which the final prediction is the majority prediction. Soft voting is a variant in which probabilities assigned to each class are considered instead of the predicted class or label. Voting by a weighted average of the modes obtained from the submodels is conducted [150]. These probabilities can be weighted during averaging, for example as function of model accuracy. More sophisticated approaches use a grid search to find the best weights for the submod-

els or a linear search to learn the best weights. Another other approach is to use a meta-learner to learn how to merge outputs into the final output. The meta-learner is another model that is trained in a second stage and learns to combine the outputs of the submodels. Each ensemble has been shown to perform well in various scenarios on Kaggle, although they also bring more complexity and computational cost [41, 362, 75]. Cascades use a subset of ensembles in instead of training all parts. Cascaded models are trained sequentially to improve you performance only when you have enough complexity [351, 390]. A mixture of experts is another approach to creating ensembles, for suitable neural networks. The idea is to decompose it into a set of, train a model for each subset (expert) and learn a model that decides which expert to use to predict an input and how to combine the predictions [235].
