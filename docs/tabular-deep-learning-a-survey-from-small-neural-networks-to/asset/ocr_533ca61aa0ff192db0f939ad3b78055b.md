The evolution of models has allowed them to learn progressively more complex representation of data and be adaptable to more complex tasks. Statistical models are not generally used for tabular learning, neural language models have been integrated into neural networks to achieve a homogeneous representation of data (categorical and continuous embedding). With the advent of transformers, pre-trained knowledge was used to apply to a new dataset. These models allowed LLMs to generate general capabilities including reasoning. While large models are used for predictive tasks, LLMs can be used for reasoning about tables.

Retrieval-augmented generation (RAG) has also been used to extend the capabilities of LLMs to answer questions about tables which are longer than the context length. Similarly, the flexibility of using agents and persona has been tested (where role play is used), providing the LLM with a specific role, "Suppose you are an expert in statistics analysis" [403, 76]. These systems make it possible to handle end-to-end tasks and can also run Python code and produce table models [3, 219, 395, 271, 401]. LLMs can be used in inference only or by fine-tuning (further training to fit the tabular data). Inference-only methods have low computational costs, but LLMs struggled with attributes because they were trained on only. In inference, LLMs can be used to enhance reasoning capabilities to produce predictions or to be the first step in an algorithm. In this paper, we explore the use of generating extra summaries (extract relevant information), some summaries are then used to train a boosting algorithm [231]. Fine-tuning can be conducted through the use of various adapters or as Low-Rank Adaptation (LoRA). For tabular data, we fine-tune [74] LoRA on various datasets using LoRA for fine-tuning. These methods seem to increase performance for dataset, but the results are also dataset-dependent. To improve generalization capabilities, in this study [348] fine-tuned a single model (GPT2) on more than 60 datasets. The model seems general to other datasets, although it shows limitations when there are not enough features or too many columns.
