Multimodal tabular learning. One of the advantages of deep learning models is that they can be integrated into multimodal systems, where tabular data and images can be used with a single deep learning architecture. Another advantage of deep learning models is that they can learn representations of data that are unseen. By using a multimodal model, the model can relate the information present in various modalities for better performance. There are several ways in which these modalities can be integrated (early, late, or hybrid fusion) (fig. 17). The most widely used approaches in which the raw data are merged into a single representation space from the beginning. This can be achieved by the use of embedding by a classifier [180]. In contrast, late fusion involves treating each modality independently to be combined in the final step (one model for each modality, followed by a meta-learner learning the combined representation). Late fusion can be seen as having individual experts for each modality and finding a way to combine them by averaging or with another meta-expert. Hybrid fusion is a middle ground where common layers between the encoders are shared. For example, using cross-attention attention mechanism for transformer-based models. Early proposed methods for early fusion were methods where features from tabular and text modalities are combined (for example, DocV2 or BERT is combined with multiple features and fed into a shared network [40]. Early fusion, however, is disadvantaged by the fact that modality features are in very different latent spaces, leading to different methods of fusion. An additional advantage of late fusion is that using pretrained encoders can be used (for example, we use BERTs for text data, ResNet or Vision Transformer for images, and Transformers for tabular data). This captures information and integrated representations.

An additional advantage of late fusion is that the encoders allow for the possibility of learning information across other modalities. Another example, LISTER tabular data to be integrated via various encoders (e.g., a text Transformer, Transformer, and tabular Transformer) whose outputs are generated and concatenated via a multimodal encoder (which uses cross-attention for sharing). [111] used an LSTM to capture both uncond and multimodal data. ModFuse is specifically designed for when the modalities are not paired and need to handle data in some modalities. Fusion [83] instead used attention to handle the missing data by using tabular data, to add CNN to the EHR features. This has been shown to show advantages in performance, as shown by a review of medical applications [190]. A multimodal model is superior to unimodal models [83]. This was shown for value information tasks, where combining tabular and textual data led to a constant increase in comparison to a baseline use [194]. This was shown for applications such as stock price prediction, credit scoring, and recommendation [344, 344].
