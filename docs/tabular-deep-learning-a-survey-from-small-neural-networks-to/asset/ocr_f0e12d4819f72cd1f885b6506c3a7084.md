# 3.3. Preprocessing in tabular data

Preprocessing is required when working with tabular data. For this task, preprocessing requires one of the following: deep preprocessing when a neural network is applied to heterogeneous data [109]. The heterogeneous nature of tabular data means preprocessing is more complex and should be conducted with care. In fact, imputation of missing values can lead to loss of information, and incorrect preprocessing can lead to data leakage. It is common for incorrect preprocessing to lead to biased performance of the model [168]. Handling of categorical variables requires synthesis that does not exist. In addition, preprocessing is often algorithm-specific (e.g., neural networks require imputing missing values, transforming categorical variables to numerical values, and scaling features to reduce computational cost or lead to suboptimal). The complexity of preprocessing tabular datasets also makes it difficult to create effective techniques for data augmentation. Tabular learning has not benefited from any of the architectures that have a great impact on other types of data.

# 3.5. Overfitting in tabular data

Overfitting is the phenomenon in which a model is unable to generalize and learns patterns specific to the training data. Although there are several reasons for overfitting in tabular data, the small dataset size and limited input set in representing patterns prevents generalization. This phenomenon is particularly dramatic for deep learning because neural networks with many parameters tend to overfit the dataset. The proper solution is to use regularization, which techniques have been proposed, such as L1/L2, dropout, and others. Additionally Data augmentation is a regularization technique used efficiently for heterogeneous data, but there are no effective techniques for tabular data.

# 3.6. Complex boundaries

Several observations show that neural networks tend to produce smooth solutions, which can make them perform poorly, especially on datasets with irregular decision boundaries [117]. Many deep learning models use techniques such as weight decay, dropout, and batch normalization to prevent overfitting, but these may also lead to smoother solutions. Additionally, activation functions like ReLU, Sigmoid, and Tanh can cause gradient attention, or vanishing gradients in the data.
