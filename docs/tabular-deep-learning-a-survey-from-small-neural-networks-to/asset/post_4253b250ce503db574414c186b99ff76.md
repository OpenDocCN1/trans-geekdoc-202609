Missing data can be randomly distributed and unrelated to other dataset variables (Missing completely at MCAR), nonrandomly distributed and related to other variables (Missing at MAR), or caused issues related to the values themselves (Missing at random, MNAR) [283]. Missing values reduce prediction power, especially in small datasets, introducing sampling bias. While statistical methods for imputing missing values have been traditionally used, in this section we will mainly discuss generative methods. Traditional methods are based on dropping others with null values, simple imputation, or using summary statistics (mean imputation, median, and so on) [283]. Imputation is especially important for neural networks because its output varies with the number of missing values (variable imputation). Multivariate imputation, on the other hand, exploits the other variables (the information contained in) to produce a prediction (classification if categorical, regression if conditional) that replace the missing input [12, 167]. Traditionally, gradient-boosting decision tree (GBDT) models have outperformed deep learning (DL) models on tabular data. Recent advances in architectures have narrowed the gap, making DL models competitive with GBDT, especially when effectively handling categorical variables. While DL models have strong performance in classification and regression, with regression, neural networks often fail to model complex target functions effectively. Well-tuned neural networks can compete with GBDT in specific real-world scenarios or domain-specific applications. Notably, even small networks can be competitive, reducing the need for data augmentation and regularization techniques to mitigate overfitting. However, GBDT models require significantly less to perform well. LightGBM remains the best-performing GBDT model. On the DL side, modified versions of MLP, SAINT, NOTE, and Transformer show promising results. In general, there is no single best, and the choice depends on the characteristics and specific dataset. Many previous benchmarks suffer from data leakage, outdated datasets, or oversampled datasets, highlighting the need for more, representative benchmarks. Additionally, many evaluations on a limited set of data, repeating the same limitations, without considering newer architectures.

Diffusion models are a class of generative models that support high fidelity generation, and some models have explored the possibility of using them to impute missing data. The models learn distribution by sampling a diffusion process that progressively transforms noise into data. Typically, these consider missing data as noise. During training, noise is added and the models they generate in during denoising process [397, 411, 352, 329, 258]. Transformers have also been used to impute missing values. The transformer has advantage of learning complex, non-linear relationships and dependencies among features, making it effective for this task. In addition, the transformer is to predict the next token in a sequence (in which case the missing value can be the token to predict) or using masked (the masked token is the missing value). ## 9.2. Tabular data generation

Tabular data generation is essentially for several types of objects. It can be used as a form of regularization (data augmentation) and to prevent overfitting. Or it can be used for anonymization, where the model is trained only on synthetic data. If a dataset is unbalanced, synthetic data has been used to train models in self-supervised learning [11].
