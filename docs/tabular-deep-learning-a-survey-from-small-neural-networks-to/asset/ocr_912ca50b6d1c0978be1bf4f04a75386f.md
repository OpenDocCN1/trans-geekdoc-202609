Non Parametric Transformers (NPT) [185] use the entire dataset and predict the interactions between learned data. To do this, it exploits both parametric and nonparametric approaches, learning to balance these two. Using self-attention and stochastic masking allows the model to learn the causal hidden data generation. MambaTab [55] adapts state-space models (SSMs) for tabular data. SSMs are capable of modeling long-range dependencies, improving efficiency, and handling complex data. MambaTab utilizes the Mamba architecture for end-to-end training, allowing it to capture dependencies across features with fewer parameters than similar models, making it a promising approach for tabular learning tasks. There are also other ways to use the mamba architecture for tabular data, either alone or in combination with transformers. Tab [353] is a framework designed to handle tables with varying numbers of columns and tables, enabling cross-table features. It achieves this by using independent features and federated learning-techniques (such as FT-Transformer). XTab learns from multiple tabular datasets, simultaneously processing them from different datasets with enhanced features before merging. This design, which integrates information from different sources, allows the model to handle heterogeneous feature spaces. The features are then fed into a shared transformer-based model. This approach allows XTab to minimize and improve transferability across datasets.

Tabular data adaptation for the transformer.

Other approaches try to fit tabular datasets to the transformer, usually by using preprocessing. The principle behind these approaches is to transform the table into serialization which can be considered four types: (I) Scanning the table by row (a special token [CLS] is added to each row and the row is used as a sequence), (II) Scanning the table by column (the column is serialized), (III) Compressing the information into a single serialization vector (using average pooling, feature aggregation, and of every row and column embeddings), and (IV) Using a template (sentences in natural language or a sample). After serialization, the data can be used with a vanilla transformer (without de-pretrained model) that has already been trained. In this way, the knowledge gained from a transformer can be used to handle different amounts of text. One way is to concatenate the context to adapt the template during inference. There are also various ways to improve the ability to process tabular data. These can be grouped into three strategies: positional-encoding modification, transformer block modification, and training variation. One can be modified by identifying the position of a cell in a table.
