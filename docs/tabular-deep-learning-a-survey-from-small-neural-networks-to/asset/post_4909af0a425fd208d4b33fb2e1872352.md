Some of the most widely used techniques are label or ordinal encoding, binary encoding, ordinal encoding, and function. For example, label encoding assigns an integer to each possible category: (Italy, France, Germany) will be mapped as [0:2]. Due to its simplicity, it inherits non-sequential order details if they are not ordinal features, handles high cardinality poorly (to many different categories), and can be inflexible. One-hot encoding is a technique that converts categorical values into a binary representation (one-hot vectors). Each category encoding is represented by a vector of elements for a single category that corresponds to the index of a specific category: Italy, France, Germany will be mapped as [[1,0],[0,1],[0,1]]. One-hot encoding does not imply similarity, solving one problems of label encoding, and works well with machine learning models because it does not imply a relationship between features, and it represents each category explicitly, maintaining distinction (the variables are also more interpretable). One-hot encoding does not scale well, it increases the dimensionality of the dataset, and leads to sparse matrices for which high cardinality (with an associated risk of overfitting, slow training, and inference). It is also complex to handle when there is new data and new columns to be added, necessitating retraining. Dummy encoding is a technique that avoids duplicate categories: (Italy, France, Germany) will be mapped as [[0,0],[1,0],[0,1]]. Alternatively, Ever Encoding is a very similar technique (also called Decision Encoding) where using of 0 and 1 is used to represent categories. Binary encoding, on the other hand, uses a binary representation, where each category has assigned a numerical value (as in table encoding), and then this is converted to a separate column. (Italy, France, Germany will be assigned a numerical value (Italy=1, France=2, Germany=3), converted to binary (n columns). The advantage is, considering a n number of columns (more efficient and scalable), which does not imply ordinal and works well with many algorithms. On the other hand, it is less interpretable, creates related features, does not handle new categories, and does not work with small datasets. Frequency encoding replaces each category with the frequency of its occurrence in the dataset. This technique is scalable and can be simple if there is unbalanced algorithm techniques. Target encoding, on the other hand, replaces the categories with a statistical value such as the mean, allowing information about the target variable to be incorporated into the encoding. This approach is prone to overfitting because it learns categorical variables from the target variable. Target encoding is an in which the global value of the target is also considered with weight.
