Since the predictive model, encoder, and decoder are trained jointly, this enables end-to-end learning, seamlessly with neural networks and avoids the pitfalls of manual discretization methods. ReConfTab [51] uses an symmetric autoencoder trained via regularized contrast to extract information from raw features and enable automatic feature engineering. In this way, low-dimensional embeddings serve as input for downstream tasks. These are a good choice, especially if one wants to use the learned representation from the model. TabM [378] transforms data into a continuous format using neighborhood distances and labels. Each label is then represented by a function of nearest neighbors, labeling in a consistent representation space that captures local structures and relationships inherent in data. In addition, the method is trained on different datasets to obtain a unified representation and can be used to transfer knowledge. space (Space). The projections represent the core information of the data, and PtRL favors prototype independence and that the representation of is distinct, better capturing the underlying distribution. The disentangled representations help models to generate more effectively to unseen data.

Image embedding techniques. Methods that transform data into images are less popular but serve to capture the capacity of convolutional neural networks (CNNs) (fig. 5).
