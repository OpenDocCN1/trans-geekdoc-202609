Extensive pre-training, may model acquire bias from a small fine-tuning deate, or poorly in the case of an unbalanced dataset. If the data is too far from the original distribution, then supervised learning (SSL) and foundation models may be an answer to these problems. In SSL, a model learns from unlabeled data by creating its own labels. In other words, it generates "supervisory signals" from the data itself, without needing labels. For example, it uses pretext tasks (predicting the next token in a sequence, a part of an image, a mask of the data, and so on). By this method, the model learns a representation of the data that can be used for subsequent tasks. SSL has been used in NLP and computer vision, revolutionizing the way models are trained.

With the scaling of models (by parameters and number of data used for training), however, models (pretrained on large and diverse datasets for different tasks, and showing emergent capabilities) can be used in inference. For example, LLMs show their ability to perform tabular tasks for which they were not explicitly trained without the need for fine-tuning and to perform. Unlike textual or images (spatial), tabular data does not have a consistent structure across datasets. While not all of the same type, they have different meanings and scales, making generalization across various tables complex. In addition, tabular data are heterogeneous, belonging to different domains (finance, retail, etc.), are much smaller and not standardized, have different preprocessing, and lack large repositories that researchers have have tried to solve some of these problems. In example, there has been data augmentation and imputation, but many approaches are not directly useful for SSL models. So both the models benefit from the increase in data and statistics.

Although techniques for the construction of new examples have been used for increasing data and variety of training, alternatively, other models focus directly on synthetic data to generate large datasets that have similar data manner. TabFF [138] builds a large synthetic dataset to address such problems as privacy and copyright constraints. During the generation process, they experiment with different parameters and the final model is trained on the generated data. Other approaches have focused on creating a pretext task that is specific to tabular data. This task should allow the model to learn patterns in the data (relationships between features or examples, other hidden concepts) so that it can generalize [349]. For example, several approaches focus on learning sample elements like Transformer and VIME try to predict from an input that is random or masked [145]. This masking, as in SSL, SEKS focuses on masking features that are highly correlated [193, 385]. SubTab [333] instead of dividing the data into subsets, and then the model would reconstruct this features in an SSL framework. The advantage of this approach is that it does implicit tabular labeling. STUNT [248] selects columns from unlabeled tables to serve as pseudo-labels, treating different features that enable the model to learn generalizable representations through meta-learning. This approach is advantageous when data is sparse or there is not labeled data. LF [321] uses a pretext task to reconstruct projections. These projections are generated by randomly initialized neural networks that transform the data into a series of projections. The model is trained to capture the structure and pattern behind the data, which is not dependent on the data. Instead of imputing the input, Minifup [59] finds hidden representations rather than just input from hidden layers. This way, SSL is able to learn more robust and generalizable features. Also, Minifup can be extended with feature regularization.

Contrastive learning is a self-supervised learning (SSL) technique which allows a model to distinguish between similar (positive) and dissimilar (negative) examples. As SSL, it does not have the limitation of labeled data, but allows the model to learn a representation of the data. SCARP [15] uses contrastive learning to learn a representation and allows the model to learn a lossless representation which can then be used for downstream tasks. Estab [123] use stochastic regularization methods (such as dropout) during training, introducing noise directly into the hidden layers. By doing this, it uses two MLP-encoders to learn models that have different representations under SSL. This is similar to multi-view contrastive learning where it compares similarity using contrast distance.

## Tree-based models versus deep learning
