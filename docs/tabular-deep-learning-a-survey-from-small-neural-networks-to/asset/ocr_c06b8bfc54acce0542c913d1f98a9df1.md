If the data is too far from the original distribution, then supervised learning (SSL) and foundation models may be an answer to these problems. In SSL, a model learns from unlabeled data by creating its own labels. In other words, it generates "supervisory signals" from the data itself, without needing labels. For example, it uses pretex tasks (predicting the next token in a sequence, a part of an image, a mask of the data, and so on). By this method, the model learns a representation of the data that can be used for subsequent tasks. SSL has been used in NLP and computer vision, revolutionizing the way models are trained. With the scaling of models (by parameters and number of data used for training), however, models (pretrained on large and diverse datasets for different tasks, and showing emergent capabilities) can be used in inference. Unlike textual or images (spatial), tabular data does not have a consistent structure across datasets. While not all of the same type, they have different meanings and scales, making generalization across various tables complex.
