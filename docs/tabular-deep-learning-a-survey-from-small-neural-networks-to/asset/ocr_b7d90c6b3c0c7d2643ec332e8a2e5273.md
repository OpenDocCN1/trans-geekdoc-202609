The LF-Transformer [246] introduces a latent feature mechanism within the transformer architecture to achieve complex feature interactions in tabular data. This approach is inspired by matrix factorization techniques commonly used in recommendation systems, where goal is to decompose a matrix into latent factors that capture underlying patterns. It uses column and row features to capture latent relationships in columns and rows, observing that this embedding is then passed into the transformer. The latent feature mechanism of the LF-Transformer effectively capture complex and model interactions between features and achieve a more abstract and informative representation of the data. AMFT [371] introduced additive and multiplicative attention mechanisms to capture relationships that are diverse in tabular data. TabTransformer [355] is a Transformer-based model for learning across tabular datasets with different structures. TabTrans, using a dedicated embedding space, tries to solve the transferability problem in learning learning, especially when different datasets have varying columns and features distributions.
