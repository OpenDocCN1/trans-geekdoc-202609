Data augmentation is generally considered a prior to model training, under the assumption that this step will help extract more information from the data (especially when the data is small, reducing the risk of overfitting and the cost of collecting more data).

**Data oversampling.** Most classifiers are designed with an equal split between classes in mind (similarity frequency). Decision depends on how unbalanced a dataset is, favoring the class with the most examples. The strategies used to balance the dataset are undersampling (removing examples from the minority class) or oversampling (adding examples to the minority class). Recent studies use the generation of synthetic examples, but it can be used to reduce overfitting [187]. Synthetic Minority Over-Sampling Technique (SMOTE [43]) is the most widely used technique, taking a data point from the minority class, interpolating with its neighbors, and multiplying it by a random number to generate a new point. SMOTE is fast but not accurate, it considers all neighbors to be false. There are many variants (ADASYN, SMOTE-ENC, KADASYN [34]) that try to reduce imbalance by oversampling, [132, 244, 79]. Alternatively, MOKAS (or SOMO and GAN) uses generative models (SOM) to map the class to space that will be used to generate synthetic examples [208, 80, 71]. SAE AE approach was proposed to address class imbalance; various strategies (focusing on the minority class, learning distribution and generator) generate better examples. GANs (as as CGAN or GAN) have also been used to replace SMOTE; they can learn the underlying distribution, but a high computational cost and complexity in training [7, 8]. # 9.2. Tabular data generation

Tabular data generation is essentially for several types of objects. It can be used as a form of regularization (data augmentation) and to prevent overfitting. Or it can be used for anonymization, where the model is trained only on synthetic data to balance it. If a dataset is unbalanced, synthetic data has been used to train models in self-supervised learning [11].

**Tabular augmentation.** As data augmentation, some approaches not use machine learning and instead conduct feature engineering or other methods of examples. Mixup and Nonlinear Mixup (NL-Mixup [96]) use interpolation to generate new examples, while Multiple Mixup [95] generates synthetic data from a neural network encoder. Cellforme [46] uses with Mixup, to vary the target object in the tabular data trying to ensure feature imputation that is even more robust to noise features. MODALS [58] starts from the latent space and utilizes a feature extraction step, along with a specifically designed for the task. Both autoencoders and GANs have been proposed for data augmentation.
