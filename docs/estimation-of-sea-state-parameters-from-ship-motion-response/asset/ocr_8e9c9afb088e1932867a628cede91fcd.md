# 3.3. Discussion

In our study, we have re-implemented the models proposed by Mak and Düz (2019) and enhanced them by scaling their number of filters resulting in an enhanced version of the models. As discussed in the end Section 2.4, the motivation behind enhancements and each model mechanism are well justified. The same goes for the novel model proposed in this research. The experiments have shown that the enhanced version of the original models performs better than the original models. The enhancement is evident in the box plot diagrams of the MSE and MAE results on the test set in Fig. 15. The figure also shows that the proposed model AT-NN performed better than the original and enhanced models, becoming a new state-of-the-art model for estimating sea state parameters from ship motions responses. The excellence of the proposed model based on the attention mechanism is confirmed

even by the NSE metric of NSE(AT − NN) = 976.067 · 10⁻³ on the test set (Table 4). If we compare the results on the test set between the best performing original model (which was CNN-REG-ORG with MSE(MLSTM − CNN − ORG) = 3.533 · 10⁻³) to the proposed model (MSE(AT − NN) = 0.457 · 10⁻³), the error is reduced by 3.076 · 10⁻³ which when put in a ratio is near ≈ 7.73 times lower error rate. Also, upon analyzing the radar diagrams presented in Figs. 12 and 13, it was determined that there is no specific range of angles where the suggested model consistently underperforms in estimating the sea state parameters. Furthermore, the introduced uncertainty estimation of the model's sea state parameters prediction raises the trustworthiness of the proposed model to an even higher level, which is essential for developing applications that utilize machine learning models. The next research step would be testing the proposed method on various real-life datasets. We believe that similar results could be achieved with adequate pre-processing of the input data, but it has to be further investigated for different sea state measurements.
