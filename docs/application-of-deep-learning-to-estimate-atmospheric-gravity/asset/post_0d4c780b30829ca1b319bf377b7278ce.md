Amplitude is the most important quantity for parameterization, but it is not sufficient on its scale. Wavenumbers and phase speed at certain level are necessary to describe the momentum deposit in the upper atmosphere. These parameters can be obtained using the linear theory of gravity waves each component of the wind fluctuations is successfully estimated. In addition, the wind fluctuations are easy to compare to the ground truth.

The analysis domain was a rectangular area (~1,000 km × 1,000 km), which included the Hidaka Mountains as shown in Figure 1m. The DSJR-55 data were cut out into 128 × 128 uniform grids to fit its grid system, and to better facilitate the deep learning process, the JRA-55 data were converted into the same grids using bicubic interpolation.

## 2.2. Deep Convolutional Neural Network

Using the data described above, our model was designed to learn the transformation of the physical quantities in the troposphere (300, 700, and 850 hPa) to each component of the fluctuations ($u'$, $v'$, and $w'$) in the lower stratosphere (100 hPa). Treating each component independently may disrupt the initialization that gravity waves have, only the estimation error needs to be minimized, which makes it easier to train. Additionally, to convert the input data, a U-Net convolutional network which was originally designed for image segmentation (Ronneberger et al., 2015) was trained to learn the relationship between the input data and the output data using contracting path to capture the context for each image and a symmetric expansive path as shown in Figure 2. The contracting path consisted of convolutional operations that captured local features (feature maps) using 3 x 3 filters ('Conv 3 x 3', blue arrows in Figure 2) and 2 x 2 pooling ('Pool 2 x 2', red arrows in Figure 2). The expansive path consisted of deconvolution operation using convolutional filters and upsampling operations to recover the feature maps with the help of upsampling ('Upconv 2 x 2', green arrows in Figure 2). Context information is then merged with the corresponding feature maps from encoder-side via skip-connections ('Copy 1', yellow arrows in Figure 2). The output value of each grid was calculated using final filters ('Conv 1', cyan arrows in Figure 2). Parameter settings such as the number of layers, as well as filter size, were the same as reported by Matsuka et al. (2019).

With supervised machine learning, we learned a training and validation set for model performance measurement. For training and validation, 29-year JRA-55 data (time interval 6 hr; total time 42,364 hr) from 1997-2025 period were used, and for testing, the 5-year data (7,308 days) from 2008-2012 period were used. During the training and validation phase, the error between the output of U-Net and ground truth (previously stated as correct output data) was measured, and the model was repeatedly optimized using these training data until its predictive error on the validation data converged to a certain threshold. The error function was calculated using the Tanaka coefficient representing the similarity between the two, as follows:

$$y = \frac{\sum x_i y_i}{\sum x_i^2 + \sum y_i^2}$$

where $u'$, $v'$, and $w'$ of the $i$-th grid are ground truth and output data, respectively. The Tanaka coefficient is usually applicable when the values are positive, and ranging from 0 to 1. However, it can also be extended to negative values without any constraints except one of the estimated value and the ground truth is negative. After the training and validation phase, the test data were then fed into the U-Net for the evaluation phase.

The source code for deep learning was implemented in Python 3.6 using keras (TensorFlow 2.1), which ran on an NVIDIA station with four Tesla V100 graphical processing units (GPUs). The training of 29-year data over one epoch lasted 89 s, and the number of iterations of $u'$, $v'$, and $w'$ that were required to converge the errors were 33, 46, and 93, respectively, and for errors with respect to the test data there was 0.764, 0.835, and 0.696. For the estimation using the 5-year test data, it took approximately 16.6 ms on average. This computational cost seems reasonable to develop a new gravity wave parameterization, the direct implementation of the proposed method to an atmospheric model or to gravity wave parameterization would be made in future studies.

## 3. Results and Discussion

In this section, the results of the evaluation of the test data for the trained U-Net for a period of 5 years are presented and discussed. Figure 1 gives an example of input data for the trained U-Net and the ground truth output at 00:00 UTC on 22 November 2021. Estimation results (i.e., outputs) from the U-Net with the ground truth data are shown in Figure 2.

Maps of the momentum flux $\rho u'v'$ are shown in Figures 3a–3c. The observed structures of $u'$, $v'$, and $w'$ are consistent with those of ground truth on land and south coast. Particularly, the negative and positive stripes from the Hidaka Mountains in central Hokkaido to the southeast were, with similar structures to those of ground truth. The larger amplitudes of $u'$ and $w'$ are observed on the sea, which were not well represented.

Figure 3g show line plots of $u'$, $v'$, and $w'$ along $A'$–$B'$. The wave vector direction of gravity waves on the south coast of the analysis region. Its structures observed of $u'$, $v'$, and $w'$ values are similar to that of ground truth. The maximum amplitudes of $u'$, $v'$, and $w'$ along the U-Net were -4.58, -4.2, and 1.17 m, respectively. The values of $w'$ are consistent with ground truth although the amplitudes are larger, except for the slight difference in $v'$.

The fluctuations and magnitude of $\rho u'v'$ and $\rho v'w'$ are shown along $C'$–$D'$ in Figures 3p–3r. The negative values of $\rho u'v'$ and $\rho v'w'$ were -0.83 and -0.49 m/s², respectively. The maximum of the momentum magnitude $|\rho u'v'|$, $|\rho v'w'|$ was 0.87 mPa for the estimation result and 0.93 mPa for the ground truth. The slight difference of the maximum $|\rho u'v'|$, $|\rho v'w'|$ is attributable to a phase shift in $v'$ between the estimate and the ground truth (Figure 3h).
