# ## 2.2. Deep Convolutional Neural Network

Using the data described above, our model was designed to learn the transformation of the physical quantities in the troposphere (300, 700, and 850 hPa) to each component of the fluctuations ($u'$, $v'$, and $w'$) in the lower stratosphere (100 hPa). Treating each component independently may disrupt the polar layer initialization that the linear gravity waves have, only the estimation error for error needs to be minimized, which makes it easier to train. Additionally, to convert the input data, a U-Net convolutional neural network which was originally designed for image segmentation/partitioning (Ronneberger et al., 2015) was trained to learn the relationship between the input data and the output data using a contracting path to capture the context for each image and a symmetric expansive path as shown in Figure 2. The contracting path consisted of convolutional operations that captured local features (feature maps) using 3 x 3 filters ('Conv 3 x 3', blue arrows in Figure 2) and 2 x 2 pooling ('Pool 2 x 2', red arrows in Figure 2). The expansive path consisted of the deal operation, using the convolutional filters and upsampling operations to recover the feature maps with the help of upsampling ('Up-conv 2 x 2', green arrows in Figure 2). The context information is then merged with the corresponding feature maps from the encoder-side via skip-connections ('Copy 1 x 1', yellow arrows in Figure 2). The output value of each grid was calculated using the final filters ('Conv 1 x 1', cyan arrows in Figure 2). The parameter settings such as the number of layers, as well as the filter size, were the same as reported by Matsuka et al. (2019).

With supervised machine learning, we learned a training and validation set for model fitting and performance measurement. For the training and validation, the 29-year JRA-55 and DSJ-55 data (time interval, 6 hr; total time, 42,364) from the 1997-2025 period were used, and for testing, the 5-year data (7,308 days) from the 2008-2012 period were used. During the training and validation phase, the error between the output of the U-Net and the ground truth (previously stated as the correct output data) was measured, and the model was repeatedly optimized using these training data until its predictive error on the validation data converged to a certain threshold. The error function was calculated using the Tanimoto (1958) coefficient, representing the similarity between the two, as follows:

> $y = \frac{\sum x_i y_i}{\sum x_i^2 + \sum y_i^2 - \sum x_i y_i}$

where $u'$, $v'$, and $w'$ of the ith grid are ground truth and output data, respectively. The Tanimoto coefficient is usually applicable when the values are positive, and ranging from 0 to 1. However, it can also be extended to negative values without any constraints except when one of the estimated value and the ground truth is negative. After the training and validation phase, the reserved test data were then fed into the U-Net for the evaluation phase.

The source code for deep learning was implemented in Python 3.6 using keras (TensorFlow 2.1), which ran on an NVIDIA DG station with four Tesla V100 graphical processing units (GPUs). The training of the 29-year data over one epoch lasted -89 s, and the number of iterations of $u'$, $v'$, and $w'$ that were required to converge the errors were 33, 46, and 93, respectively, and for errors with respect to the test data there was 0.764, 0.835, and 0.696. For the estimation using the 5-year test data, it took approximately 16.6 ms per meter on average. This computational cost seems be reasonable to develop a new gravity wave parameterization, the direct implementation of the proposed method to an atmospheric model or to gravity wave parameterization would be made in future studies.
