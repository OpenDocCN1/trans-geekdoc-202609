```
metadata:
  name: my-model-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: my-model-deployment
  minReplicas: 1
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 80
```

This HPA configures automatic scaling based on CPU utilization. If the average CPU utilization of the my-model-deployment pods exceeds 80%, the HPA automatically scales the deployment by adding more replicas (containers).

These examples showcase various aspects of containerizing and orchestrating machine learning workflows.
