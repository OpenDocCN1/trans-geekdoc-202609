## 1.2. Preprocessing: Preparing Your Data for Success

Data in its raw form is rarely ready for machine learning algorithms. Preprocessing plays a vital role in transforming raw data into a clean and usable format that optimizes the performance of your machine learning models. Here, we'll explore common preprocessing techniques and provide code examples to illustrate their application:

### 1.2.1. Handling Missing Values:

Missing values can significantly impact model performance. Here are some common approaches:

- **Removal:** This involves removing rows or columns containing missing values. However, this might lead to data loss, especially if the missing data percentage is high.
- **Imputation:** This involves filling in missing values with estimates. Common techniques include:
  - **Mean/Median imputation:** Replace missing values with the mean or median of the respective feature.
  - **K-Nearest Neighbors (KNN) imputation:** Use the values of the k nearest neighbors (data points) to predict the missing value.

```python
import pandas as pd
from sklearn.impute import SimpleImputer, KNNImputer
# Sample data with missing values
data = {"A": [1, 2, None, 4], "B": [5, None, 7, 8]}
df = pd.DataFrame(data)
# Impute missing values with mean strategy (SimpleImputer)
imputer = SimpleImputer(strategy="mean")
df["A"] = imputer.fit_transform(df[["A"]])
```

```python
# Impute missing values with KNN (KNNImputer)
imputer = KNNImputer(n_neighbors=5)
df["B"] = imputer.fit_transform(df[["B"]])
print(df)
```

### 1.2.2. Encoding Categorical Data:

Machine learning algorithms typically work better with numerical features. Categorical data (e.g., text labels) needs to be converted into numerical representations. Common techniques include:

- **Label encoding:** Assign unique integer values to each category.
- **One-hot encoding:** Create a new binary feature for each category, with a value of 1 for the corresponding category and 0 for others.

```python
# Sample data with categorical feature
data = {"Name":["Alice", "Bob", "Charlie", "Alice"], "Age":[25, 30, 22, 25]}
df = pd.DataFrame(data)
# Label Encoding (using scikit-learn)
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df["Name_encoded"] = le.fit_transform(df["Name"])
print(df)
# One-Hot Encoding (using pandas)
df_encoded = pd.get_dummies(df, columns=["Name"])
print(df_encoded)
```

### 1.2.3. Feature Scaling:

Feature scaling ensures all features contribute equally to the model's learning process. This is crucial when features have different scales or units. Common techniques include:

- **Standardization:** Scales features to have a mean of 0 and a standard deviation of 1 (z-score).
- **Normalization:** Scales features to a specific range (e.g., 0-1 or -1 to 1).

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
# Sample data
data = [[100, 1], [50, 2], [20, 3]]
df = pd.DataFrame(data, columns=["feature1", "feature2"])
# Standardization (using StandardScaler)
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df)
# Normalization (using MinMaxScaler)
scaler = MinMaxScaler(feature_range=(0, 1))
df_normalized = scaler.fit_transform(df)
print(df_scaled)
print(df_normalized)
```

Remember, these are just a few examples, and the specific preprocessing techniques you'll use will depend on your data and the chosen machine learning model. Experiment with different approaches and evaluate their impact on your model's performance to find the optimal strategy for your specific task.

### 2. Preprocessing:

- **Cleaning:** Remove irrelevant characters like punctuation or special symbols:

```python
import string
def clean_text(text):
    text = text.lower() # Convert to lowercase
    text = text.translate(str.maketrans("", "", string.punctuation)) # Remove punctuation
    return text
cleaned_data = data["text"].apply(clean_text)
```

- **Normalization:** Apply techniques like stemming or lemmatization to reduce words to their base forms:

```python
from nltk.corpus import stopwords
```
