# 2. Deploying a Containerized Model with Docker Compose:

This example demonstrates using a docker-compose.yml file to deploy both a containerized web application and its corresponding containerized model:

```
```yaml
version: "3.8"
services:
  web-app:
    build: ./web-app
    ports:
      - "5000:5000"
    environment:
      MODEL_URL: http://model:8501/v1/models/my_model
  model:
    image: my-model-image # Replace with your container image
    ports:
      - "8501:8501"
```
```

This configuration defines two services: web-app and model. The web-app service uses environment variables to access the model endpoint running in the model service container.
