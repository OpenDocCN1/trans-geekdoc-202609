# 1.2.2. Encoding Categorical Data:

Machine learning algorithms typically work better with numerical features. Categorical data (e.g., text labels) needs to be converted into numerical representations. Common techniques include:

+   - **Label encoding:** Assign unique integer values to each category.
+   - **One-hot encoding:** Create a new binary feature for each category, with a value of 1 for the corresponding category and 0 for others.

```
Python
# Sample data with categorical feature
data = {"Name":["Alice", "Bob", "Charlie", "Alice"], "Age":[25, 30, 22, 25]}
df = pd.DataFrame(data)
# Label Encoding (using scikit-learn)
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df["Name_encoded"] = le.fit_transform(df["Name"])
print(df)
# One-Hot Encoding (using pandas)
df_encoded = pd.get_dummies(df, columns=["Name"])
print(df_encoded)
```
