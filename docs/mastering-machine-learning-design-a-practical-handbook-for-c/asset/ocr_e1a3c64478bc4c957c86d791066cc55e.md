# 2. Automating Deployment:

+   - **Containerization:** Packaging your model and its dependencies into a container using tools like **Docker** ensures consistent and portable deployments across different environments. This allows you to seamlessly move your model between development, testing, and production environments.

# Code Example (Dockerfile to create a container for a Python script):

```
```dockerfile
FROM python:3.9
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "my_script.py"]
```
