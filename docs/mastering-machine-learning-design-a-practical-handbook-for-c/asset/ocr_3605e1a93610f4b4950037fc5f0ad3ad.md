# Code Example (calculating accuracy for binary classification in Python):

```
```python
from sklearn.metrics import accuracy_score
# True labels and predicted labels
y_true = [0, 1, 0, 1]
y_pred = [0, 1, 1, 0]
# Calculate accuracy
accuracy = accuracy_score(y_true, y_pred)
print(f"Accuracy: {accuracy:.4f}")
```
```

• **Precision:** This measures the proportion of true positives among all positive predictions. It's calculated by dividing the number of correctly predicted positive cases (true positives) by the total number of predicted positive cases (true positives + false positives).

# Code Example (calculating precision in Python):

```
```python
from sklearn.metrics import precision_score
# Same `y_true` and `y_pred` from previous example
# Calculate precision
precision = precision_score(y_true, y_pred, pos_label=1)
print(f"Precision: {precision:.4f}")
```
```

• **Recall:** This measures the proportion of actual positives that the model correctly identified. It's calculated by dividing the number of correctly predicted positive cases (true positives) by the total number of actual positive cases (true positives + false negatives).
