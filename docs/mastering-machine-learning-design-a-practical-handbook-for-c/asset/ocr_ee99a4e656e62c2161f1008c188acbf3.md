# 1. Containerizing a Machine Learning Model with TensorFlow Serving:

This example showcases how to create a Docker container for a TensorFlow model using TensorFlow Serving:

```
Dockerfile
FROM tensorflow/tensorflow:2.10.0-gpu
WORKDIR /app
COPY saved_model saved_model
CMD ["tensorflow_serving","--model_spec=.saved_model","--port=8501"]
```

This container utilizes the TensorFlow Serving base image and copies your saved model into the container. The CMD instruction specifies the command to run the TensorFlow Serving binary with the saved model directory and port configuration.
