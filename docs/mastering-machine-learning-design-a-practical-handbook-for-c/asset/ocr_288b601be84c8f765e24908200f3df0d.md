Feature scaling ensures all features contribute equally to the model's learning process. This is crucial when features have different scales or units. Common techniques include:

+   - **Standardization:** Scales features to have a mean of 0 and a standard deviation of 1 (z-score).
+   - **Normalization:** Scales features to a specific range (e.g., 0-1 or -1 to 1).
