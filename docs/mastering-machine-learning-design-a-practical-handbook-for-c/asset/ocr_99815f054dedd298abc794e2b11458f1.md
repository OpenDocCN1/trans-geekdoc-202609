Here, we'll explore common preprocessing techniques and provide code examples to illustrate their application:

# 1.2.1. Handling Missing Values:

Missing values can significantly impact model performance. Here are some common approaches:

+   - **Removal:** This involves removing rows or columns containing missing values. However, this might lead to data loss, especially if the missing data percentage is high.
+   - **Imputation:** This involves filling in missing values with estimates. Common techniques include:
+     - **Mean/Median imputation:** Replace missing values with the mean or median of the respective feature.
+     - **K-Nearest Neighbors (KNN) imputation:** Use the values of the k nearest neighbors (data points) to predict the missing value.

```
```python
import pandas as pd
from sklearn.impute import SimpleImputer, KNNImputer
# Sample data with missing values
data = {"A": [1, 2, None, 4], "B": [5, None, 7, 8]}
df = pd.DataFrame(data)
# Impute missing values with mean strategy (SimpleImputer)
imputer = SimpleImputer(strategy="mean")
df["A"] = imputer.fit_transform(df[["A"]])
