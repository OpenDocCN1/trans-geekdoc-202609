# 12.17 Theorem.

Let $\mathcal{C}$ be a linear code over $F = \mathbb{F}_{q^r}$ and $tr : F \to \mathbb{F}_q$ the trace. Assume $\mathcal{C}$ is Galois closed $(\mathcal{C}^q = \mathcal{C})$. Then the following hold:

+   - $tr(\mathcal{C}) = \mathcal{C}_{\mathbb{F}_q}$.
+   - The $\mathbb{F}_q$-dimension of $tr(\mathcal{C})$ equals the $F$-dimension of $\mathcal{C}$.
+   - The minimum distance of $tr(\mathcal{C})$ equals the minimum distance of $\mathcal{C}$.
+   - The strength of $tr(\mathcal{C})$ equals the strength of $\mathcal{C}$.

# PROOF

The definition of the trace shows that $tr(\mathcal{C}) \subseteq \mathcal{C}_{\mathbb{F}_q}$. Exercise 12.3.6 implies $dim_{\mathbb{F}_q}(\mathcal{C}_{\mathbb{F}_q}) \le dim_F(\mathcal{C})$. The last link in the chain is provided by Theorem 12.14. If the length of $\mathcal{C}$ is $n$, then

$dim(tr(\mathcal{C})) = dim(((\mathcal{C}^\perp)_{\mathbb{F}_q})^\perp) = n - dim((\mathcal{C}^\perp)_{\mathbb{F}_q}) \ge n - dim_F(\mathcal{C}^\perp)$

$= dim_F(\mathcal{C}) \ge dim(\mathcal{C}_{\mathbb{F}_q})$.

It follows that we have equality all along.

As $tr(\mathcal{C})$ is a subcode of $\mathcal{C}$, its minimum distance is at least as large as that of $\mathcal{C}$. Let $x \in \mathcal{C}$ of weight $w \ne 0$. After suitable scalar multiplication, we can assume that $x$ has an entry with a nonzero trace. It follows that $tr(x)$ has nonzero weight $\le w$. This shows the equality of the minimum distances. The equality of the strengths follows from Delsarte's theorem.

# The strategy

Let $\mathcal{B}$ be an $F$-linear code $(F = \mathbb{F}_{q^r})$, obtained by puncturing a Reed-Solomon code of dimension $t$. We have all the ingredients to determine the parameters of $\mathcal{C} = tr(\mathcal{B})^\perp$, the dual of the trace code of $\mathcal{B}$. By Delsarte's theorem, we can describe $\mathcal{C}$ alternatively as $\mathcal{C} = (\mathcal{B}^\perp)_{\mathbb{F}_q}$, the subfield code of the dual of $\mathcal{B}$. As $\mathcal{B}$ has strength $t$, it follows from duality that $\mathcal{C}$ has minimum distance $d \ge t + 1$.

Theorem 12.17 suggests how the dimension can be determined: find the Galois closure $\tilde{\mathcal{B}}$ of the $F$-linear code $\mathcal{B}$. By Theorem 12.17 the $F$-dimension of $\tilde{\mathcal{B}}$ equals the $\mathbb{F}_q$-dimension of $tr(\mathcal{B})$.

The dimension of $\mathcal{C}$ follows by duality. In the beginning of the next chapter we consider an example for this procedure.
