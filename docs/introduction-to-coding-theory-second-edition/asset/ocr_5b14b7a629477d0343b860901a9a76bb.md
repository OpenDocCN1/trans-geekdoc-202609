# 15.41 Lemma.

Let $f_i(X)$, $i = 0,1,\dots$ be real polynomials of degree $i$, where $f_0(X)=C>0$, $f_1(X)=Ax+B$ ($A>0$) and for $i \ge 2$

$f_i(X) = (A_i X + B_i) f_{i-1}(X) - C_i f_{i-2}(X),\; A_i > 0,\; C_i > 0.$

Then $f_i(X)$ has $i$ different real zeroes, and the zeroes of $f_i(X)$ **interlace** those of $f_{i-1}(X)$. This means that, if $\alpha_1 > \dots > \alpha_i$ are the zeroes of $f_i(x)$ and $\beta_1 > \dots, \beta_{i-1}$ are those of $f_{i-1}(X)$, then

$\alpha_1 > \beta_1 > \alpha_2 > \beta_2 > \dots > \beta_{i-1} > \alpha_i.$

# PROOF

Use induction from $f_i$ to $f = f_{i+1}$. Observe that $f$ has leading coefficient $>0$. We have $f(\alpha_j) = -C_{i+1} f_{i-1}(\alpha_j)$, $f(\alpha_{j+1}) = -C_{i+1} f_{i-1}(\alpha_{j+1})$. These numbers have different signs, as $f_{i-1}$ has exactly one (simple) zero between $\alpha_j$ and $\alpha_{j+1}$. The same argument applies to $\alpha_1$ and $\alpha_i$.

Using $K_0(X)=1$, $K_1(X)=-v\cdot X + n(v-1)$ (see Lemma 15.28) and the recursion formula, we see that $(-1)^k K_k(X)$, $k=0,1,2,\dots,n$ satisfy the conditions of the preceding lemma. Recall $K_k(0)=\binom{n}{k}(v-1)^k>0$, $K_k(n)=\binom{n}{k}$. We obtain the following:

# 15.42 Theorem (Interlacing of zeroes).

$K_k(X)$, $k=0,1,\dots,n$ has $k$ different real zeroes between $0$ and $n$. If these zeroes are $v_1 < v_2 < \dots < v_k$, and the zeroes of $K_{k-1}$ are $u_1 < u_2 < \dots, u_{k-1}$, then

$0 < v_1 < u_1 < v_2 < u_2 < \dots < u_{k-1} < v_k < n.$
