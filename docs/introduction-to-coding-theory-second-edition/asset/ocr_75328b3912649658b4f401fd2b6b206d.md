# FIGURE 3.1: Principle of duality

|  |  |  |
|---|---|---|
| code $C$ | $\longrightarrow$ | dual code $C^\perp$ |
| length $n$ | $\longrightarrow$ | length $n$ |
| dimension $k$ | $\longrightarrow$ | complementary dimension $n - k$ |
| strength $t$ | $\longrightarrow$ | distance $t + 1$ |
