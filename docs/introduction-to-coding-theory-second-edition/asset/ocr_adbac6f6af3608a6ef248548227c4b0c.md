These are essentially the cyclic codes. Start from a certain (punctured) Reed-Solomon code ℬ defined over F. We aim at the code 𝒞 = (ℬ⊥)𝔽_q, the subfield code of the dual. By Delsarte’s theorem, 𝒞 can also be described as the dual of the trace code. As we know the strength of ℬ, we know the strength of the trace code by Theorem 12.11. By duality we know the minimum distance of 𝒞. The remaining problem is to determine the dimensions of these codes.

+   1. Let 𝒞 be a linear code over F = 𝔽_{q^r}.
+   2. The trace code tr(𝒞) is linear over 𝔽_q and has at least the strength of 𝒞.
+   3. The subfield code 𝒞_{𝔽_q} consists of the codewords of 𝒞 all of whose entries are in 𝔽_q. It has at least the minimum distance of 𝒞.
+   4. Trace code and subfield code are related by Delsarte’s theorem: the dual of the trace code equals the subfield code of the dual.
