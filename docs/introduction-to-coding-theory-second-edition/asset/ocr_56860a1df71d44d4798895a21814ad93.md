# Exercises 8

8.1. What is the relationship between H(p1,p2,p3,p4) and H(p1/2, p1/2, p2/2, p2/2, p3/2, p3/2, p4/2, p4/2)?

8.2. What is larger (contains more information), H(1/2, 1/4, 1/8, 1/8) or H(1/3, 1/3, 1/9, 1/9)? Compute both entropies and compare.

8.3. Compare the following experiments:

+   - A: Three possible events with probabilities 0.5, 0.25, 0.25
+   - B: Three possible events, each with probability 1/3.

Which of these experiments yields a larger amount of information? Compute the entropies and compare.

8.4. Same type of problem as before, with

+   - A: Five possible events occur with probabilities 1/4, 1/4, 1/4, 1/8, 1/8.
+   - B: Three possible events occur with probabilities 1/2, 1/3, 1/6.

8.5. Prove the statement concerning the case of equality in Jensen's inequality (Theorem 8.7).

8.6. In the language of Theorem 8.2 prove A(s^m) = A(s^{m-1}) + A(s) for natural numbers s,m and conclude A(s^m) = m A(s).

8.7. Given natural numbers s,t,n define m such that s^m ≤ t^n < s^{m+1}. With this notation prove m/n ≤ A(t)/A(s) < (m+1)/n and also m/n ≤ log(t)/log(s) < (m+1)/n. Conclude A(t)=log(t), where log is the binary logarithm.
