# 15.9 Theorem.

*If Q has a minimum in M, then this minimum is attained in a vertex.*

**PROOF** There is a difficulty only when M is unbounded. Let x0 be a minimal point which is not a vertex, x1, x2, …, xp the vertices of M. The trick is to consider the sum C_i of the coordinates of each x_i, i = 0, 1, …, p. Let C be the maximum of these numbers. If C = 0, then 0 is the only vertex and minimal point. So assume C > 0. Consider a new LP in standard form: add a new indeterminate x_{n+1}, do not change the old conditions, add a new row to A which corresponds to the condition x1 + x2 + … x_{n+1} = 2C, do not change Q. The corresponding space M~ of admissible points is certainly bounded because of the last condition. The projection onto the first n coordinates maps M~ onto a corresponding bounded part of M, while preserving the objective function Q. In particular, x~0 (x0 with last coordinate chosen such that the sum of the coordinates is 2C) is a minimal point. We distinguish two classes of vertices in M~. The x~i, i = 1, 2, …, p are those with last coordinate > 0. The remaining vertices x~i, i = p+1, …, r have vanishing last coordinate. Express x~0 = sum_j alpha_j x~j as a convex combination of the vertices. The last coordinate shows that there must be j ≤ p such that alpha_j > 0. It follows that x~j is a minimal point of M~ and vertex x_j is a minimal point of the original LP.

# 15.10 Definition.

*Let x be a vertex (we know wt(x) ≤ m). A basis of x is a set of m independent columns of A containing the support of x. Observe that the basis is uniquely determined if x is nondegenerate.*

# The vertex exchange

Let x0 be a vertex with coordinates x_k^{(0)}, Z the set of indices of a basis of x0. We have sum_{k∈Z} x_k^{(0)} c_k = b. Each column-vector of A can be represented in terms of this basis. There must therefore exist constants α_{ki} such that

$$c_i = \sum_{k∈Z} α_{ki}·c_k,\quad i=1,2,…,n.\tag{15.1}$$

If j ∈ Z, then certainly α_{kj}=δ_{kj}. Assume there is an α_{\hat{k}j}>0, where \hat{k}∈Z, j∉Z. For every δ≥0, consider x(δ) with the following coordinates:

$$x_k(δ)=\begin{cases}x_k^{(0)}-δ·α_{kj}&\text{if }k∈Z\\δ&\text{if }k=j\\0&\text{otherwise.}\end{cases}\tag{15.2}$$
