Let x, y ∈ 𝔽₂ⁿ. We say that x and y are **orthogonal** (x ⊥ y) if x · y = 0. It is obvious that, for every subset U ⊆ 𝔽_qⁿ, the set

U^⊥ = {x | x ∈ 𝔽₂ⁿ, x · u = 0 for all u ∈ U}

is a subspace of 𝔽₂ⁿ. The following rules hold for all x, y, z ∈ 𝔽₂ⁿ and λ ∈ 𝔽₂

x · y = y · x
(x + y) · z = x · z + y · z
(λx) · y = x · (λy) = λ(x · y).

The dot product is an example of what are called **symmetric bilinear forms** in general (another topic of linear algebra). Here is a basic fact, which will be proved in the more general context of symmetric bilinear forms in Proposition 17.33.

# 2.9 Lemma.

Let U ⊆ 𝔽₂ⁿ be a linear subspace. Then

dim(U) + dim(U^⊥) = n.

In particular we see that, when C is a linear k-dimensional binary code of length n, then the dual code C^⊥ has dimension n − k.

# 2.10 Lemma.

Let U ⊆ 𝔽_qⁿ be a linear subspace. Then

U^⊥⊥ = U.

**PROOF**  By definition U^⊥⊥ ⊇ U. It follows from Lemma 2.9 that these spaces have the same dimension.
