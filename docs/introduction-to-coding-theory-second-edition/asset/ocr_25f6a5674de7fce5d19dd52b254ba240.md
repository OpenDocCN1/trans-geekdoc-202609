Assume **b** ≥ 0 (meaning that the entries of **b** are nonnegative). Consider column vectors **x** of length *n* satisfying

**x** ≥ 0 and *A* · **x** = **b**.

Under these conditions minimize *Q*(**x**) = **p** · **x**.

Let

$\mathcal{M} = \{\mathbf{x} \mid \mathbf{x} \ge 0, A \cdot \mathbf{x} = \mathbf{b}\}$

be the set of admissible points in *n*-dimensional space $\mathbb{R}^n$.

# A toy example

Consider the case *m* = 2, *n* = 3, matrix $A = \begin{pmatrix}2 & 0 & 1/2 \\ -5 & 1 & 0\end{pmatrix}$ and **b** = (3,5/3), **p** = (3,8,-11). What does $\mathcal{M}$ look like? We have **x** = (*x*₁,*x*₂,*x*₃) and the conditions are *x*₁,*x*₂,*x*₃ ≥ 0 and

$2x_1 + 0.5x_3 = 3$
$-5x_1 + x_2 = 5/3$

Use *x*₁ as parameter. Then *x*₂,*x*₃ can be expressed in terms of *x*₁ :

$x_2 = 5/3 + 5x_1,\; x_3 = 6 - 4x_1.$

The conditions are *x*₁ ≥ 0, *x*₁ ≥ -1/3, *x*₁ ≤ 1.5, equivalently 0 ≤ *x*₁ ≤ 1.5. It follows that $\mathcal{M}$ is a line segment:

$\mathcal{M} = \{(x_1,5/3 - 5x_1,6 - 4x_1)\mid 0 \le x_1 \le 1.5\}$

# Obtaining standard form

Let us convince ourselves that any problem involving nonnegative unknowns and linear equations and inequalities can be transformed into the standard form of Definition 15.1. If the maximum is searched instead of the minimum, it suffices to replace **p** by -**p**. If **b** should not satisfy the non-negativity condition, we should change the sign of the negative entries, at the same time replacing the corresponding row of *A* by its negative.
