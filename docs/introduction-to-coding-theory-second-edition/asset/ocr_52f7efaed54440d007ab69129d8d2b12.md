# 9.6 Theorem (Bose-Bush). If an OA_λ(2, n, q) exists, then

n(q - 1) + 1 ≤ q² λ

(the number of rows is at least n(q-1)+1, where n is the number of columns).

# An OA₂(2, 8, 4)

We illustrate with case OA_λ(2, 8, 4). By Theorem 9.6 we have λ ≥ 2. Can OA₂(2, 8, 4) be constructed? Choose 𝔽₄ as the alphabet. There can be no linear construction, as λ = 2 is not a power of 4. Our OA will have 32 = 2⁵ rows. The maximum in the way of linearity is linearity with respect to 𝔽₂. This would mean we write a “generator matrix” consisting of five rows. The rows of the OA will all be 𝔽₂-linear combinations (equivalently all sums) of these five rows.

It can be expected that linear mappings Φ : 𝔽₈ → 𝔽₄ will come in. Here we view 𝔽₄ and 𝔽₈ as vector spaces over 𝔽₂, and Φ is a mapping from a three-dimensional space onto a two-dimensional space, described by a (3,2)-matrix with entries in 𝔽₂.

# 9.7 Proposition.

Let Φ : 𝔽₈ → 𝔽₄ be a surjective (onto) 𝔽₂ linear mapping. Consider a (32,8)₄ array 𝒜, where the columns are indexed by x ∈ 𝔽₈, the rows are indexed by pairs (a,b) where a ∈ 𝔽₈, b ∈ 𝔽₄, and with entry Φ(ax)+b ∈ 𝔽₄ in row (a,b), column x. Then 𝒜 is an OA₂(2,8,4).

# PROOF

Let two columns x₁, x₂ and a pair (c₁, c₂) of entries be given. We have to show that there are precisely two rows (a,b) with entry c₁ in column x₁ and entry c₂ in column x₂. This means that we have to count the solutions (a,b) of the system of equations Φ(ax₁)+b = c₁, Φ(ax₂)+b = c₂. Form the difference of the two equations and use the additivity of Φ to obtain the equation Φ(a(x₁−x₂)) = c₁−c₂. For each solution a of this equation there is precisely one b such that (a,b) is a solution of the system. As Φ is 𝔽₂ linear and onto, each element in 𝔽₄ has precisely two preimages. It follows that there are precisely two elements u₁,u₂ ∈ 𝔽₈ such that Φ(u₁)=Φ(u₂)=c₁−c₂. It follows that a(x₁−x₂) ∈ {u₁,u₂}. As x₁ ≠ x₂ (we are considering different columns), we obtain two solutions for a : a₁ = u₁/(x₁−x₂), a₂ = u₂/(x₁−x₂).

Choose Φ such that Φ(1)=1, Φ(ε)=ω, Φ(ε²)=0, hence

Φ : 1, ε³ ↦ 1 , ε⁵ ↦ ω   ε⁴, ε⁵ ↦ ω   0, ε² ↦ 0.
