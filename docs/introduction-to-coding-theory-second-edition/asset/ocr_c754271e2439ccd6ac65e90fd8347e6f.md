Let us collect information concerning the weights of codewords.

# 23.20 Definition.

Let U,V ⊂ {1, …, 10}, U ∩ V = ∅, |U| = u, |V| = v. Let ν(U,V) be the number of blocks B ∈ ℬ which satisfy that |B ∩ U| and |B ∩ V| have the same congruence c mod 3. Here c ∈ {0,1,2}.

The weights of arbitrary codewords are described as follows:

# 23.21 Lemma.

Let z_i, 1 ≤ i ≤ 10 be the rows of the generator matrix G. The codeword Σ_{i∈U} z_i − Σ_{j∈V} z_j has weight 66 − ν(U,V).

# PROOF

The number of zeroes in codeword Σ_{i∈U} z_i − Σ_{j∈V} z_j is by definition α + β where α is the number of blocks B such that ∞, * ∉ B and |B ∩ U| and |B ∩ V| have the same congruence mod 3 and β is the number of blocks B such that * ∉ B, ∞ ∈ B and |B ∩ U| and |B ∩ V| have the same congruence mod 3. Working with the complement, this shows that α + β is the number of blocks such that ∞ ∉ B and |B ∩ U| and |B ∩ V| have the same congruence. Replacing ∞ by *, we arrive at the statement of the lemma.

In order to show that the minimum distance is d = 36, we need to show that ν(U,V) ≤ 30 for all (U,V) ≠ (∅,∅). We will consider here only some cases when the codeword weights can be determined directly. Case u = 1, v = 0 corresponds to the rows z_i. We have ν(U,V) = i(0,3)+i(1,2) = 12+18 = 30. This confirms the observation that the rows of G have weight 36. The sums of two rows correspond to u = 2, v = 0. In this case, ν(U,V) = i(1,3)+i(0,4) = 8+4 = 12, so the sums of two rows have weight 54. Let u = 8, v = 2. Then ν(U,V) = 2i(2,2)+i(0,4) = 20+4 = 24, so those codewords have weight 42. In the case u = 7, v = 3, we obtain ν(U,V) = 3i(3,2)+1+i(3,2) = 1+4×5 = 21, leading to codewords of weight 45. Not in all cases are the codeword weights easily determined.
