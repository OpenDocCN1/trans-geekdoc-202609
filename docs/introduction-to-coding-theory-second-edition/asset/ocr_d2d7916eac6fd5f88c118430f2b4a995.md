# 8.8.

Prove the formula for $H$ in the case of rational probabilities. It is clear that, because of continuity, this suffices. So let $p_i = m_i/m$, where $m_i$ and $m$ are natural numbers, $\sum_{i=1}^r m_i = m$.

Hint: Use the central property of $H$ in an appropriate situation to obtain

$A(m) = H(p_1,\dots,p_r) + \sum_{i=1}^r p_i A(m_i).$

# 8.9.

The multinomial coefficient $\binom{n}{m_1,m_2,\dots,m_k}$ is defined as

$\displaystyle \frac{n!}{m_1! m_2! \dots m_k!}$ (here $m_1 + m_2 + \cdots + m_k = n$).

Prove that

$\displaystyle \lim \bigl(\log\bigl(\binom{n}{m_1,m_2,\dots,m_k}\bigr)\bigr)/n = H(p_1,p_2,\dots,p_k)$

where $n, m_i \longrightarrow \infty$ such that $m_i/n \longrightarrow p_i$.
