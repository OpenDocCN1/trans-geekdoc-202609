# Direct constructions

Next we construct a family of nonlinear codes which have a large minimum distance and also yield interesting OA of strength 2. One member of the family was constructed in Proposition 9.7 as an illustration of the Bose-Bush bound.

Let Φ : 𝔽_{q^a} ⟶ 𝔽_q^b be a mapping, which is linear over 𝔽_q and onto (this simply is a mapping from an a-dimensional to a b-dimensional vector space. It is described by an (a,b)-matrix of rank b). Clearly the assumption a ≥ b is needed. We construct a q^b-ary code of length n = q^a with q^{a+b} codewords, as follows:

+   - The coordinates are parametrized by u ∈ 𝔽_{q^a},
+   - The codewords are parametrized by pairs (x,y), where x ∈ 𝔽_{q^a}, y ∈ 𝔽_q^b.
+   - The entry of word (x,y) in position u is Φ(ux) + y. Here ux is the product in the field 𝔽_{q^a}.

Let us determine the minimum distance of this code. Let (x1,y1) ≠ (x2,y2). These codewords agree in coordinate u if and only if Φ(u(x1 − x2)) = y2 − y1. Here we have used the 𝔽_q linearity of Φ. If x1 = x2, then y1 ≠ y2. The codewords are at distance n = q^a in this case. Assume x1 ≠ x2. As the kernel of Φ has dimension a − b over 𝔽_q, the number of u satisfying this equation is precisely q^{a−b}. It follows that our code has minimum distance d = q^a − q^{a−b}.

We leave it to the reader to check that this code also is an orthogonal array of strength 2; see Exercise 16.7.2.

**16.29 Theorem.** *For every prime-power q and natural numbers a ≥ b, there is an OA_{q^{a−b}}(2, q^a, q^b) whose rows form a code with minimum distance d = q^a − q^{a−b}.*

In particular, we obtain an (q^{a+b}, q^a)_{q^b} hash family, which is q^{−b} U and even q^{−b} SU.

In terms of mappings, we have q^{a+b} mappings from a q^a set to a q^b set, and this family is q^{−b} strongly universal. As a toy example we can use the OA_2(2,8,4) from Proposition 9.7 (case q = 2, b = 2, a = 3). Its rows describe a family of 32 mappings from an 8 set to a 4 set. It is 1/4 SU.

**16.30 Theorem.** *Let q be a prime-power and k, a ≥ b natural numbers. There is a (q^{a+b}, q^{ka})_{q^b} hash family, which is k/q^b SU.*
