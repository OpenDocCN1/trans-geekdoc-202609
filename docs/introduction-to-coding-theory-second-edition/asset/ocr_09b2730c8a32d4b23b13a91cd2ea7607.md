Why is this code M12 invariant? In order to see this, we start from an M12-invariant code and identify it with the code just constructed. We start from the simple group M12 in its 5-transitive action on Ω. Consider the natural module of M12 on a 12-dimensional ternary vector space V(12,3) by choosing a basis b_i, i ∈ Ω and letting M12 act by permuting this basis. This module contains two obvious submodules, the 11-dimensional module I = {∑_{i∈Ω} a_i b_i | ∑ a_i = 0} and the one-dimensional submodule generated by the diagonal Δ = ∑_{i∈Ω} b_i. A basis of I is the u_i = b_i − b_∞, i = 1,2,…,10,∞. As we are in characteristic 3, we have Δ ∈ I and M12 acts on the 10-dimensional factor space V = I/⟨Δ⟩. A natural basis of V consists of the v_i = u_i, i = 1,…,10, where u_∞ = −∑_{i=1}^{10} v_i. This defines an embedding of M12 in GL(10,3). For each orbit we consider the 10-dimensional ternary code whose generator matrix has representatives of the projective points of the orbit as columns. This is then an M12 invariant code.

For each 6-subset B ⊂ Ω, let u_B = ∑_{i∈B} b_i. We have u_B ∈ I as |B| = 6. Let v_B = u_B ∈ V. The group M12 permutes the v_B where B varies over the blocks of the S(5,6,12). If B is the complement of B in Ω, then u_B + u_B = Δ. It follows that the projective points generated by the v_B where B varies over the blocks form an M12 orbit of length 66. The Pace code as defined in [163] is equivalent to the [66,10]_3 code whose generator matrix has as columns representatives of this orbit. In order to identify it with the code generated by G, it suffices to express the v_B where B varies over the blocks not containing * in terms of the basis v_i, i = 1,…,10 of V. If B ⊂ {1,2,…10}, we have u_B = ∑_{i∈B} b_i = ∑_{i∈B} u_i and we obtain the corresponding column of G. Let B be a block such that ∞ ∈ B, * ∉ B. Then

u_B = ∑_{i∈B} b_i = ∑_{i∈B} u_i = ∑_{i∈B,i≠∞} u_i − ∑_{i=1}^{10} u_i = − ∑_{i≤10,i∉B} u_i.

This is the negative of the corresponding column of our matrix G.
