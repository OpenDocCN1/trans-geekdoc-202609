# Artin-Schreier equations

In earlier chapters we used the additive version of Hilbert’s theorem 90 only in characteristic 2. We need it for general finite fields:

19.4 Theorem. Let tr : F = 𝔽_q^r ⟶ 𝔽_q be the trace. For an element b ∈ F we have that tr(b) = 0 if and only if there is a ∈ F such that b = a − a^q.

The reader is asked in Exercise 19.2.2 to provide the easy proof; compare Exercise 12.1.6. It helps us to understand the following class of examples:

19.5 Definition. Consider the polynomial

h(X, Y) = Y^q − Y − f(X)

defined over F = 𝔽_q^r, where f(X) is a polynomial.

This type of equation is interesting because of the link to the trace. Consider the solutions of this affine equation over F = 𝔽_q^r. Whenever f(x) does not have trace 0, there is no solution (x, y). Let tr(f(x)) = 0. Then, by Theorem 19.4, there is a solution y0 ∈ F, and of course the whole coset y0 + 𝔽_q yields solutions. As a nonzero polynomial of degree q cannot have more than q roots, this accounts for all affine solutions.

19.6 Proposition. The number of solutions of the homogenization of the affine equation h(X, Y) = Y^q − Y − f(X) from Definition 19.5 is 1 + qt, where t is the number of x ∈ F such that tr(f(x)) = 0.

PROOF The number of solutions of the affine equation is qt. There is precisely one solution at infinity. Assume, for example, n = deg(f(X)) > q. After filling up with powers of Z and putting Z = 0, it follows that X = 0. The solution at infinity is then (0 : 1 : 0). The other two cases are similar.

Knowledge of the number of solutions of Artin-Schreier equations is equivalent to knowledge of the number of field elements α ∈ K such that f(α) has trace = 0.

# Function fields

With a little luck, we can associate a field to a homogeneous polynomial. The starting point is the rational function field:

19.7 Definition. Let K be a field. The rational function field K(x) is the field whose elements are the quotients (rational functions) f(x)/g(x) where f, g are polynomials with coefficients in K and g(x) is not the 0 polynomial.

Clearly K(x) contains the polynomial ring K[x] and therefore is an infinite-dimensional vector space over K.
