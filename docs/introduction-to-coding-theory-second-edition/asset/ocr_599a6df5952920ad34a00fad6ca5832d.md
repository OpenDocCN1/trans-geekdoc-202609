i = 1, …, t. It follows that tr(x) has the required entries c_i in coordinates i = 1, …, t. The fact that each such tupel occurs equally often follows from 𝔽_q-linearity.

We will consider the trace code when we wish to control the strength. In contrast, the minimum distance of the trace code is not that easily controlled in general.

The trace code is in close relationship with another method of “going down”, the subfield code.

**12.12 Definition.** Let F = 𝔽_q^r and 𝒞 be an F-linear code of length n. The subfield code 𝒞_{𝔽_q} consists of the codewords of 𝒞 all of whose entries happen to be in 𝔽_q, formally 𝒞_{𝔽_q} = 𝒞 ∩ 𝔽_q^n.

It is obvious that trace codes and subfield codes are linear codes over the ground field 𝔽_q, and it is equally obvious how to control the minimum distance of the subfield code.

**12.13 Theorem.** The minimum distance of the subfield code of 𝒞 is at least as large as the minimum distance of 𝒞 itself.

**PROOF** This does not really merit a proof. Observe simply that each word of the subfield code 𝒞_{𝔽_q} is also a word of 𝒞.

The relationship between trace code and subfield code is clarified by a famous theorem due to Delsarte, which is the main result of the present section. There is a relation of duality.

**12.14 Theorem (Delsarte).** Let F = 𝔽_q^r and 𝒞 an F-linear code of length n. Then the following holds: tr(𝒞)^⊥ = (𝒞^⊥)_{𝔽_q}.

**PROOF** Let c = (c₁, c₂, …, cₙ) ∈ 𝔽_q^n. Then c ∈ tr(𝒞)^⊥ if and only if ∑_{i=1}^n c_i tr(x_i) = 0 for all x = (x₁, x₂, …, xₙ) ∈ 𝒞.

Because of the linearity of the trace, this is equivalent to tr(∑_{i=1}^n c_i x_i) = 0. We claim that this is equivalent to ∑_{i=1}^n c_i x_i = 0. In fact, if this was not the case, then, because of the F-linearity of 𝒞, it would follow that tr is the 0 mapping, a contradiction. We conclude that c ∈ tr(𝒞)^⊥ if and only if c ∈ 𝒞^⊥ and all c_i ∈ 𝔽_q. This is our claim.
