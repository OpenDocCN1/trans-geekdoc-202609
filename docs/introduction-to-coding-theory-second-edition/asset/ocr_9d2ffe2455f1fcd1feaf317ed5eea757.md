Why is this true and why is W' the maximal divisor satisfying it for all α ∈ A_{F'|F}(W')?

Fix some x ∈ F such that v_P(x) = v_P(W). Let P' | P and e = e(P' | P). Then

v_{P'}(xα_{P'}) = e · v_P(W) + v_{P'}(α_{P'}) ≥ e · v_P(W) − v_{P'}(W').

By definition of W', this shows v_{P'}(xα_{P'}) ≥ −d(P'), which, as we know, is equivalent to xα_{P'} ∈ D_P. Now use the definition of the complementary module: tr(xα_{P'}) = x tr(α_{P'}) ∈ O_P. As this is true for all P', the claim (tr(α)) + W ≥ 0 follows. The details of the proof are in Section 3.4 of [198].

There is a close relationship between the ramification index e(P' | P) and the different exponent d(P' | P) = d(P'). We use only the most fundamental statement:

# 21.23 Theorem (Dedekind's different theorem). For each finite separable extension F' | F of the function field F and each P' | P, the following hold:

+   - d(P') ≥ e(P' | P).
+   - Equality holds if and only if e(P' | P) is not divisible by the characteristic.
