+   3. $y,y' \in \mathbb{F}_q^n$ are in the same **coset** of $\mathcal{C}$ if $y-y' \in \mathcal{C}$, equivalently if $\sigma(y)=\sigma(y')$.
+   4. A leader of a coset is a vector of smallest weight.
+   5. **syndrome decoding:**
+   6. Establish a list of leaders of all $q^{n-k}$ cosets.
+   7. Decode $y \mapsto x = y - z$, where $z$ is the leader of the coset containing $y$.
