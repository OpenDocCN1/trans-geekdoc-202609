The trace gives us a method to go down from a code defined over an extension field to a code defined over the ground field. As in Section 12.1, consider the field extension $\mathbb{F}_q \subset \mathbb{F}_{q^r} = F$, with the corresponding trace $\operatorname{tr}$. Let $x = (x_1,x_2,\dots,x_n)$ be a codeword of a linear code of length $n$ defined over $F$. Applying the trace in each coordinate yields the codeword $\operatorname{tr}(x) = (\operatorname{tr}(x_1),\operatorname{tr}(x_2),\dots,\operatorname{tr}(x_n))$, still of length $n$ but with entries in $\mathbb{F}_q$. We apply this to every codeword and obtain the trace code.

12.10 Definition. Let $F = \mathbb{F}_{q^r}$ and $\mathcal{C}$ be an $F$-linear code of length $n$. Let $\operatorname{tr} = \operatorname{tr} : F \longrightarrow \mathbb{F}_q$ be the trace. The trace code $\operatorname{tr}(\mathcal{C})$ is defined as the set of all $(\operatorname{tr}(x_1),\operatorname{tr}(x_2),\dots,\operatorname{tr}(x_n))$ where $(x_1,x_2,\dots,x_n) \in \mathcal{C}$.

The parameter we can control is the strength:
