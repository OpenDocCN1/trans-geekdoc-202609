+   1. **Hash families** may be viewed either as arrays
+   or as families of mappings from a large set to a small set.
+   2. **Universal hash families** are formally equivalent to codes. The **relative minimum distance** is the central parameter.
+   3. **Strongly universal hash families** are a
+   generalization of strength 2 orthogonal arrays.
+   4. Stinson composition uses as ingredients universal families
+   (hence codes) and strength 2 orthogonal arrays.
+   5. An important application is **unconditional authentication**.
