+   1. Let $\mathbb{F}_q \subset \mathbb{F}_{q^r} = F$ and $\mathcal{C}$ be an $F$-linear code.
+   2. The **Galois closure** $\tilde{\mathcal{C}}$ is the smallest code containing $\mathcal{C}$ which is mapped to itself by $g_1$, where $g_1(x) = x^q$.
+   3. Equivalently, $\tilde{\mathcal{C}}$ is the code generated by all images of $\mathcal{C}$ under the Galois group.
+   4. We have $tr(\tilde{\mathcal{C}}) = \tilde{\mathcal{C}}_{\mathbb{F}_q} = tr(\mathcal{C})$, and the $\mathbb{F}_q$-dimension of this code equals the $F$-dimension of $\tilde{\mathcal{C}}$.
+   5. The minimum distance and strength remain unchanged when passing from a Galois closed code to its trace code.
