If aiming at eight-dimensional codes, one should instead apply standard lengthening to the images of $\mathcal{C}_1 \supset \mathcal{C}_2$ obtained in the first step. We obtain a chain

$[q^3 + 1,8,q(q^2 - q - 1)] \supset [q^3 + 1,4,q^2(q - 1)]$

# Reed-Muller codes

Consider the binary primitive case $q = 2$, $n = 2^r - 1$. The numbers between 0 and $2^r - 2$ can be identified with their duadic representation: if $x = \sum_{i=0}^{r-1} x_i 2^i$, then $x$ is described by the binary $r$-tuple $(x_{r-1},\dots,x_1,x_0)$. The number $2x$ is represented by the cyclic shift $(x_{r-2},\dots,x_0,x_{r-1})$. It follows that a set of exponents is Galois closed if the corresponding duadic representations are closed under cyclic shifts. Choose $A$ to consist of the exponents whose duadic representations have weight at most $b$, for some $b < r$. Then $A$ is Galois closed and the cyclic code $\mathcal{C}(A)$ therefore has dimension

$n - |A| = 2^r - 1 - \sum_{i=0}^{b} \binom{r}{i} = \left(\sum_{i=0}^{r-b-1} \binom{r}{i}\right) - 1.$
