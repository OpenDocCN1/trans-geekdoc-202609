# 22.4 The automorphism group

22.10 Definition. The automorphism group Aut(F | K) is the group of automorphisms of the function field F which leave K elementwise invariant.

Automorphisms are often best described as polynomial invariants:

22.11 Definition. Let h(X,Y,Z) ∈ K[X,Y,Z] be a homogeneous polynomial and σ ∈ GL(3,K). Define the image of h under σ as (σh)(X,Y,Z) = h(σ(X),σ(Y),σ(Z)). Call h(X,Y,Z) a relative invariant of σ if there is a constant such that (σh)(X,Y,Z) = c·h(X,Y,Z).

It is clear that (σh)(X,Y,Z) always is a homogeneous polynomial of the same degree as h(X,Y,Z).

22.12 Theorem. Let F = K(x,y) be a function field and h(X,Y,Z) the homogenization of the minimal polynomial of y over K(x). Then each relative invariant σ of h(X,Y,Z) defines an automorphism of F | K.
