# 𝔽₆₄

has been constructed in Section 22.4 as a quadratic extension $\mathbb{F}_8(\rho)$ of $\mathbb{F}_8$, with equation $\rho^2 = \rho + \epsilon$ and $\epsilon \in \mathbb{F}_8$ such that $\epsilon^3 + \epsilon^2 + 1 = 0$.
