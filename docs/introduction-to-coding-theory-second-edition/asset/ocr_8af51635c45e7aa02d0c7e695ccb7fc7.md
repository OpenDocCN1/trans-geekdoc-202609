Let P(a1, w1), P(a2, w2), P(a3, w3) be different points of K_q which are collinear. Let 1, λ, λ + 1 be the coefficients of an affine linear combination, where λ ∈ F_q \ F2. This yields the equation

(λ + 1)a1 w1 = a2 w2 + λ a3 w3.

Assume at first a_i = a_j for some i ≠ j. We can assume a2 = a3 = 1 and w3 = 1. The equation is

(λ + 1)a1 w1 = w2 + λ.

As the second and third points are different, it follows that w2 ≠ 1. Application of the norm (N(x) = x^{q^2+1}) to both sides yields (λ^2 + 1)a1^2 = λ^2 + 1 + λ α, where α = T(w2). We have α ≠ 0 as w2 ≠ 1. It follows that a1 ≠ 1. The equation

1/α (a1^2 + 1) = λ/(λ^2 + 1) = 1/(λ + 1) + 1/(λ + 1)^2

shows, after application of Tr,

(a1^2 + 1)Tr(1/α) = Tr(1/(λ + 1) + 1/(λ + 1)^2) = tr(1/(λ + 1))

(the last equation follows from the definition of the trace). The transitivity of the trace shows that tr factorizes over tr_{K|F_q}. As tr_{K|F_q} vanishes on F_q, it follows that (a1^2 + 1)Tr(1/α) = 0, hence Tr(1/α) = 0, contradicting Lemma 17.56.

Assume now the a_i are pairwise different (and nonzero) elements of F4. We can choose notation such that

(λ + 1)w1 = ω w2 + λ ω.

Application of N yields λ^2 + 1 = ω + λ^2 ω + λ α, where α = T(w2). We have α ≠ 0, as otherwise λ ∈ F4, which is impossible, as F_q ∩ F4 = F2. An equivalent form of the equation is λ^2 ω + λ α + ω = 0. Multiplication by ω/α^2 yields x^2 + x + 1/α^2 = 0, where x = λ ω/α. This yields tr(1/α) = 0, contradicting Lemma 17.56 again.
