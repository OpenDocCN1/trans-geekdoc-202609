
The smallest number having a duadic representation of weight > b is 2^{b+1} - 1. It follows that A contains the interval [0, 2^{b+1} - 2] of length 2^{b+1} - 1, and C(A) therefore has minimum distance ≥ 2^{b+1}. Applying construction X to the chain C(A) ⊂ C(A \ {0}), we obtain a code with parameters [2^r, sum_{i=0}^{r-b-1} binom{r}{i}, 2^{b+1}]_2. It is more customary to use parameter a, where r = a + b + 1. The corresponding code parameters are

[2^r, sum_{i=0}^{a} binom{r}{i}, 2^{r-a}]_2.

These are the Reed-Muller codes RM(a, r), which were constructed in Exercise 5.2.9 using the (u, u + v)-method. The Reed-Muller codes are a classical family of codes, first studied by D. E. Muller [156] and I. S. Reed [172], with close ties to affine geometry. They are also popular because they possess an effective decoding algorithm.

## Generalized concatenation

The method of concatenation, as discussed in Chapter 5, can be generalized in various ways. A far-reaching generalization is the Zinoviev codes [227]. As an illustration we give here just one example of a Zinoviev code.

The cyclic theory provides us with a chain of binary cyclic codes B1 = [15, 4, 8]_2 ⊂ B2 = [15, 5, 7]. Let A1 = [16, 1, 16]_2 be the repetition code and A2 = [16, 3, 14]_{16} an F16 linear Reed-Solomon code. Consider the space of matrices M = \begin{pmatrix} u1 & v1 \\ u2 & v2 \\ \dots & \dots \\ u16 & v16 \end{pmatrix} where u_i ∈ F2, v_i ∈ F16 and u = (u1, ..., u16) ∈ A1, v = (v1, ..., v16) ∈ A2. The number of matrices obtained is 2 × 16^3 = 2^13 and they form a binary vector space of dimension 13. Let α : F2 × F16 ⟶ B2 such that α(u, v) ∈ B1 if and only if u = 0. The binary code C we aim at consists of the codewords (α(u1, v1), ..., α(u16, v16)) where M varies over our space of matrices. Clearly C is a linear code [16 × 15, 13, d]_2. What can we say about d? Assume at first u1 = ... = u16 = 1. Then α(u_i, v_i) ≠ 0 for all i and the weight of our codeword is ≥ 16 × 7 = 112. The remaining case is u1 = ... = u16 = 0. If the codeword is nonzero, then at least 14 of the v_i are nonzero. As α(0, v_i) ∈ B1, we obtain weight ≥ 14 × 8 = 112. We conclude that we obtained a [240, 13, 112]_2 code.

## Lengthening and the covering radius

The following parameter is important in its own right:

14.6 Definition. The covering radius ρ(C) of the code C is the smallest number ρ such that every n-tuple in the ambient space 𝔽_q^n has distance ≤ ρ from some codeword.

Expressed in different words: the covering radius is the smallest number ρ such that the balls of radius ρ centered at the codewords cover all 𝔽_q^n. Yet another way of expressing this: each coset C + x of C contains a vector of weight ≤ ρ. It follows that ρ is the maximum among the weights of coset leaders (compare Section 3.7).

Yet another description of the covering radius involves the check matrix H of C, a matrix with n − k rows and n columns. Recall that the syndrome vector σ is defined by σ(x) = x H^t ∈ 𝔽_q^{n−k}, where we think of x ∈ 𝔽_q^n as a row vector. The coordinates of σ(x) are the dot products with the rows of H. All these dot products vanish if and only if x ∈ C. We have σ(x) = σ(x') if and only if x, x' are in the same coset (we know all this from Section 3.7). How can we read off the covering radius after applying σ? Let z ∈ 𝔽_q^{n−k}; write z = σ(x). We can find x' of weight ≤ ρ such that z = σ(x'). This shows that z is a linear combination of at most ρ columns of H. It is clear that the reverse is also true.

## 14.7 Theorem. For an [n,k]_q code C, the following are equivalent:

- The balls of radius i cover all 𝔽_q^n.
- Each coset of C contains a vector of weight ≤ i.
- Each vector in 𝔽_q^{n−k} can be written as a linear combination of at most i columns of a check matrix of C.

The covering radius ρ is the smallest number i satisfying the equivalent conditions in Theorem 14.7. The concept of the covering radius represents an idea which is different from what we have seen thus far. It is not an intrinsic parameter of the code, like the dimension, minimum distance and strength.

Rather it describes how the code is embedded in its ambient space F_q^n. If we are interested primarily not in the distance or strength of a code, but in its covering radius, we also speak of a covering code. Covering codes are the subject of Cohen, Honkala, Litsyn, Lobstein [55].

Fix the field F_q, length n and dimension k. In order to maximize the minimum distance, the codewords have to be spread out such that any two of them are fairly far from each other. In order to minimize the covering radius, the codewords have to be placed such that no vector from the ambient space is very far from a codeword. So the aims are slightly different. In the case of the minimum distance, we do not worry about the vectors outside the code at all, whereas in the case of the covering radius, we are not allowed to leave a vector behind (at a large distance from all codewords). However, it can be expected that these two optimization problems will be closely related. In both cases the codewords have to be spread out in a uniform way. For example, in order to construct a good covering code, how could it be helpful to use codewords which are very close to one another? So we suspect that a good covering code will typically have large minimum distance and vice versa. In one instance we have had occasion to observe this phenomenon already.

Recall the sphere-packing bound from Section 1.6. It relies on the observation that, for a code of minimum distance d, the balls of radius e = ⌊(d−1)/2⌋ are pairwise disjoint. This shows that the covering radius certainly satisfies ρ ≥ e. Equality will happen precisely when the sphere-packing bound is met with equality, that is, when the code is a perfect code.

## 14.8 Proposition. The covering radius ρ of a code with minimum distance d satisfies ρ ≥ e = ⌊(d−1)/2⌋, with equality if and only if the code is perfect.

In particular, the Hamming codes have covering radius ρ = 1, the ternary Golay code [11,6,5]_3 has ρ = 2 and the binary Golay code [23,12,7]_2 satisfies ρ = 3.

Proposition 14.8 shows that in some sense the covering radius is extremely small if and only if the minimum distance is extremely large. What happens at the other end of the spectrum? If ρ ≥ d, then C is not maximal. This means that we can pick an element x ∈ F_q^n \ C at distance ≥ d from C. If the parameters of C are [n,k,d]_q, then C + F_q x has parameters [n,k+1,d]_q. We have seen the following trivial fact:

## 14.9 Lemma. Let C be an [n,k,d]_q code. If ρ(C) ≥ d, then C can be embedded in an [n,k+1,d]_q code.

## 14.10 Proposition. Let C be an [n,k,d]_q-code. Then the following are equivalent:

- ρ(C) ≥ d − 1.
- C can be extended to an [n+1,k+1,d]_q code.
