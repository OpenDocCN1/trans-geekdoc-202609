# Remarks

Reed-Solomon codes were introduced in Reed and Solomon [173]. They are among the most widely used codes. Some applications are discussed in Wicker and Bhargava [219]. There is an attractive application in compact disc technology, where shortened Reed-Solomon codes [32,28,5]256 and [28,24,5]256 play a key role. This is also described in Hoffman et al. [116].

+   1. Pick a prime-power q and a dimension k ≤ q. The Reed-Solomon code RS(k,q) is defined as follows:
+   2. The coordinates are parametrized by the elements u ∈ Fq.
+   3. The codewords are parametrized by the polynomials p(X) with coefficients in Fq, of degree < k.
+   4. The codeword parametrized by p(X) has as entries the evaluations p(u).
+   5. RS(k,q) is a code [q,k,q−k+1]q and an orthogonal array OA1(k,q,q).
