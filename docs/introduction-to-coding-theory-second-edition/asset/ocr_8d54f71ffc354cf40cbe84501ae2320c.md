# 15.45 Theorem.

Consider a family of binary codes C_n such that the lengths n ⟶ ∞ and the relative minimum distances d_n / n ⟶ δ. Then the rate 1/n log₂|C_n| is asymptotically bounded by h(1/2 − √δ(1 − δ)). Here

h(x) = −x log₂(x) − (1 − x) log₂(1 − x)

is the binary entropy function. In particular, asymptotic rates R > 0 are possible only when δ < 1/2.

Our basic observation shows that a corresponding statement holds for binary orthogonal arrays. Instead of the relative minimum distance, we have to consider the relative dual distance δ′ = d′/n (asymptotically equivalent to the relative strength of the array). This yields the following:

# 15.46 Theorem.

Consider a family of binary orthogonal arrays C_n such that the lengths n ⟶ ∞ and the relative dual distances d′_n / n ⟶ δ′. Then the rate 1/n log₂|C_n| is asymptotically lower bounded by 1 − h(1/2 − √δ′(1 − δ′)). In particular, asymptotic rates R < 1 are possible only when δ′ < 1/2.

The statement shows which asymptotic statement is needed: If x₁^{(t_n)}/n ⟶ δ, then t_n/n ⟶ τ = 1/2 − √δ(1 − δ). The transformation δ ⟶ τ is in fact involutorial: δ < 1/2 is expressed as δ = 1/2 − √τ(1 − τ) in terms of τ. It suffices therefore to prove the following lemma (in Appendix A of [140]):

# 15.47 Lemma.

Let v = 2. If t_n/n ⟶ τ, then limsup(x₁^{(t_n)}/n) ≤ 1/2 − √τ(1 − τ).

+   1. All LP problems can be brought into standard form:
+   2. x = (x₁, ..., xₙ) ≥ 0, Ax = b = (b₁, ..., bₘ) ≥ 0, Q(x) = p · x = p₁x₁ + ⋯ + pₙxₙ ⟶ Min.
+   3. Let M = {x ≥ 0 | Ax = b}.
+   4. A vertex is a point x ∈ M such that the columns of A where x_k > 0 are independent.
+   5. The minimum (if it exists) is reached in a vertex.
+   6. The Simplex algorithm walks from vertex to vertex and finds the minimum.
+   7. Duality theorems: the min of the original problem is the max of the dual problem (if both exist).
