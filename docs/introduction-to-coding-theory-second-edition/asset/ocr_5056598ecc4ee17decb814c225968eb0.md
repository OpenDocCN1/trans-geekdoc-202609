Consider the random variable $F(y)$, the number of errors. We have $F = \sum_{i=1}^n F_i$, where $F_i = \begin{cases}1 & \text{if symbol } y_i \text{ is incorrect},\\0 & \text{if symbol } y_i \text{ is correct.}\end{cases}$ By definition, $E(F_i)=p$. Because of the additivity of the expectation (see Exercise 9.1) $E(F)=np$. We have $\sigma^2 = Var(F)=npq$ (see Exercise 9.2).

For some small fixed $\epsilon > 0$, choose $b = \sqrt{\sigma^2 / \epsilon/2}$. Theorem 9.10 proves that $Prob(|F - np| > b) \le \epsilon/2$. We can choose $n$ large enough such that $\rho = |np + b| < n/2$.

Introduce the function $$f(u,v)=\begin{cases}0 & \text{if } d(u,v) > \rho\\1 & \text{if } d(u,v) \le \rho\end{cases}$$

(the points at distance $> \rho$ are taken care of by Tschebyscheff). Each $x \in \mathcal{C}$ defines a function $g_x$, where $$g_x(y)=1 - f(y,x) + \sum_{x'\neq x} f(y,x').$$

The main property of $g_x$ is the following: $$g_x(y)=\begin{cases}0 & \text{if } x \text{ is the only codeword at distance } \le \rho \text{ from } y\\\ge 1 & \text{otherwise}\end{cases}$$

This property shows that the probability $P(x)$ that $x$ is not decoded correctly is bounded by $\sum_y P(y|x)g_x(y)$. It follows that $$P(x) \le \sum_y P(y|x)(1 - f(y,x)) + \sum_y \sum_{x'\neq x} P(y|x)f(y,x').$$

The first summand is $Prob(d(y,x) > \rho) \le \epsilon/2$. We have $$P(\mathcal{C}) \le \frac{\epsilon}{2} + \frac{1}{M} \sum_x \sum_y \sum_{x'\neq x} P(y|x)f(y,x').$$

In these sums $x, x'$ vary in the code, $y$ in $\mathbb{F}_2^n$. So far we have worked with a fixed code $\mathcal{C}$. Consider now the average of this expression when $\mathcal{C}$ varies over all such codes. Rewrite the second sum above as $$\frac{1}{M} \sum_y\left(\sum_{x'} f(y,x') \sum_x P(y|x)\right).$$ Then $\sum_{x'} f(y,x')$ has an average value of $V_2(\rho,n)(M-1)/2^n$ (here $V_2(\rho,n)$ is the volume of the ball of radius $\rho$; see Definition 1.11), and the average value of the sum is therefore bounded by $$\frac{1}{M} V_2(\rho,n)(M-1)/2^n \sum_x \sum_y P(y|x) = V_2(\rho,n)(M-1)/2^n.$$
