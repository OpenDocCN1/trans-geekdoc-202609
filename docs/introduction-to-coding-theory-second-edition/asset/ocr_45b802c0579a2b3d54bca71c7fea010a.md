# The vertices

It can be assumed that the rows of A are linearly independent. In fact, if a row is a linear combination of others, then the corresponding condition is either automatically satisfied or it contradicts the others. In the first case we can forget about that condition, reducing m by 1; in the second case ℳ is empty.

**15.2 Definition.** A convex combination of two points P, Q ∈ ℝⁿ is x(t) = tP + (1 − t)Q where 0 ≤ t ≤ 1.

A point set ℳ ⊆ ℝⁿ is convex if it is closed under convex combinations: any convex combination of two points in ℳ is in ℳ.

The geometric intuition is: x(t) is a point on the line segment between P and Q. In fact, x(0) = Q, x(1) = P. Think of x(t) as a parametric curve, a point moving in space as time t increases from 0 to 1.

The set ℳ of admissible points is convex. Formally this follows directly from the conditions

x ≥ 0 and A · x = b

describing ℳ : if points x, x′ satisfy them, then also convex combinations do.

This suggests how to define those special points, the vertices, where we think max and min will be reached:

**15.3 Definition.** In the situation of Definition 15.1 a point x ∈ ℳ is a vertex of ℳ if x cannot be written as a convex combination of two different points in ℳ.

This means that there is no line segment which is completely contained in ℳ and has x in its interior.

**15.4 Lemma.** Let the columns of A be c₁, …, cₙ, and let

x = (x₁, x₂, …, xₙ)ᵗ ∈ ℳ.

Then x is a vertex of ℳ if and only if the columns cₖ where xₖ > 0 are linearly independent.

**PROOF** Let x ∈ ℳ, and assume without restriction that x₁, x₂, …, xᵣ are the positive coordinates of x.

Let x be a vertex. Assume the first r columns of A are dependent: ∑ₖ₌₁ʳ dₖ cₖ = 0 for some (d₁, …, dᵣ) ≠ 0. Choose δ small enough such that xₖ ± δ·dₖ > 0, k = 1, 2, …, r. Then ∑ₖ₌₁ʳ cₖ(xₖ ± δ·dₖ) = b. It follows that we can write x = ½(x₁ + x₂) as a convex combination of vectors x₁ and x₂, where

x₁ = { xₖ + δ·dₖ k ≤ r; 0 k > r }, x₂ = { xₖ − δ·dₖ k ≤ r; 0 k > r }.
