If the witnesses should be on a segment of length |W| + n − 1 on this circle, then the escape probability will be (2^n − 1 − |W| − k + 1)/2^n = ε − k/2^n.

Spenser [197] suggests using field arithmetic in F = 𝔽_{2^n}. The structure underlying this method is RS(2, q), the two-dimensional Reed-Solomon code, where q = 2^n. If k test vectors are to be used, we restrict to the first k columns of the Reed-Solomon code. The random seed (2n bits) is used to determine a row of the array at random. The k entries in this row are then used as test vectors. The analysis leading to the desired bound on the escape probability does not make use of the structure of the Reed-Solomon code. All it uses is the fact that we have an orthogonal array of strength 2 and index 1.

# 16.16 Theorem.

Let 𝒜 be an OA₁(2,k,q) with a set of entries Q. Let W ⊂ Q, |W| = m and ε = 1 − m/q. Choose a row of 𝒜 uniformly at random. Then the probability that the row does not contain any element of W is at most

$1 + (k - 1)(1 - \epsilon)$

# PROOF

We will use quadratic counting. Let x_i be the number of rows precisely i of whose entries are from W. The escape probability is x_0/q². Using the defining properties of an OA of strength 2, we obtain three equations for the x_i :

$\sum_{i=0}^{k} x_i = q^2$
$\sum_{i=0}^{k} i x_i = k m q$
$\sum_{i=0}^{k} i(i - 1) x_i = k(k - 1) m^2.$

For any real number z, we have $\sum_{i=1}^{k} (i - z)^2 x_i \ge 0$. Using the above equations, we can rewrite this as

$z^2 \sum_{i=1}^{k} x_i + k(k - 1) m^2 + k m q - 2 z k m q \ge 0.$
