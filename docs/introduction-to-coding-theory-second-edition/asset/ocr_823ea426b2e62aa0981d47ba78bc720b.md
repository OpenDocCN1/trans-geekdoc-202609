# 22.5 AG codes and universal hashing

Recall Chapter 6, where we saw that error-correcting codes and ε-universal hash families are identical objects: an (n,M,d)_q-code yields an ε-universal (n,M)_q hash family where ε = 1 − d/n (Theorem 6.4). We saw in Section 16.7 how ε-universal (n,M)_q hash families can be used in the construction of authentication codes.

In the present section we want to interpret AG codes as universal hash families. In fact, we consider only the Hermitian one-point codes. The ground field is 𝔽_{q²}, and the number of rational points is q³ + 1. As we use one of those rational points P for the one-point code construction, our codes have length n = q³. Instead of the generic bound (Singleton defect at most g), we now use more precise information. Let D = P₁ + ⋯ + P_{q³}, where P₁, …, P_{q³} are the rational points different from P. The pole orders form the semigroup S generated by q and q + 1. In fact, we saw in an exercise that there are precisely (q choose 2) natural numbers outside S. This is the genus of the Hermitian curve, as it has to be.

Now let

u₁ = 0, u₂ = q, u₃ = q + 1, u₄ = 2q, u₅ = 2q + 1, u₆ = 2q + 2, u₇ = 3q, …

be the pole orders in ascending order. We have dim(u_j P) = j. The corresponding 𝔽_{q²} linear code 𝒞(D, u_j P) has length q³, dimension j and minimum distance ≥ q³ − u_j. Specialize now to j = (i+1 choose 2)+1 and use u_{(i+1 choose 2)+1} = i q, which was proved in an easy exercise. This yields a code [q³, (i+1 choose 2)+1, q³ − i q]_{q²}. The relative minimum distance is 1 − i/q² where i ≤ q. In terms of universal hashing, this is an i/q²-universal (q³, q^{i²+i+2})_{q²} hash family.
