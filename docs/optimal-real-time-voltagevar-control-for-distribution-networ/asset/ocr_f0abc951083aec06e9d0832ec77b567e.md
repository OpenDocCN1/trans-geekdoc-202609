# 5.3. DC-MADRL online test performance

With utilizing MADRL, the agents share the critic network and select the actions via their actor network during the training process, and during the execution, each agent determines the optimal action based on the local observation and trained actor network. After the training, the DC-MADRL performance is verified through the test data. The test set is constructed with the random sample of 120/480 scenarios, then the remaining 360 scenarios are used for training. The online decision speed of the proposed DC-MADRL is 19.63ms, which implies that it meets the real-time VCC requirement.

Aiming at verifying the effectiveness of the proposed method compared with the traditional Q-V drop control (QVDTC) (28), the the drop control single-agent deep reinforcement learning (DC-SAD) is constructed. The TVQDC has a fixed drop curve and parameters, which is not adaptable to changing environments. The proposed method is fully data-driven, so it is easier to compare with the data-driven method. The DC-SAD is used to verify the accuracy of proposed distributed VCC scheme, as the only difference between DC-SAD and DC is distributed method.
