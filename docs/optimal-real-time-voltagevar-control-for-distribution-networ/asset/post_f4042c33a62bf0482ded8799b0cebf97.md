## 2. Real-time VVC scheme

The paper proposes an ORT-VVC scheme to reduce loss with mitigating voltage fluctuations for distribution network as shown in Fig. 1. The proposed scheme is superior in its real-time response and high global optimization ability, which is integrated in an “off-line training, online execution” process. Moreover, the proposed scheme is applicable to distribution network framework which can be decomposed into several sub-networks of which is ruled by an agent. Each agent can communicate with its adjacent agents and determine strategies for network stability.

With consideration of time, the ORT-VVC scheme is implemented by the hierarchical coordination system to operate the “minutes-level dispatch” strategy and the dynamic load procedure. For the static procedure, each agent collects the information of network topology, resources, device installations, etc., then then optimizes the controlling parameters of the Q-V droop group. For the dynamic procedure, the reactive output is determined based on the real-time operation status.

The scheme is realized via the MADPG method which the multiple agents are based on deep neural network (DNN). Moreover the DNN is trained through the offline training stage, and then employed in the online execution stage to determine the reactive power according to the real-time system constraints. During the procedure, the input includes the PV active power demand, load consumption, voltage within the network and also the load transmitted from its agents. For the executions, the optimized Q-droop control model and the system status variables, such as PV active power and the load, then the output is the reactive power setting.

### 3.2. ORC-VTC model

The simplified distribution network with PV is shown in Fig. 3, based on which the distribution network model is established. For sub-network ruled by $m$, $B_m$ and $M_m$ are utilized to represent the branch and node respectively. For branch $ij$ where $r_{ij}$ and $x_{ij}$ represent the resistance and reactance, $P_{ij}$ and $Q_{ij}$ are the active and reactive power flow respectively. $P_i$ and $Q_i$ are the active power, reactive power and current respectively for node $i$ where $P_i^m$ and $Q_i^m$ denote the active and reactive power injection of sub-network $m$. $V_i$ indicates the voltage magnitude. The power flow model of the distribution network can be constructed as:

$p_i = -V_i\sum_{j\in\mathcal{N}_i} V_j(r_{ij}\cos\theta_{ij} + x_{ij}\sin\theta_{ij}) + Q_i\sum_{j\in\mathcal{N}_i} V_j(x_{ij}\cos\theta_{ij} - r_{ij}\sin\theta_{ij})$
$q_i = -V_i\sum_{j\in\mathcal{N}_i} V_j(x_{ij}\cos\theta_{ij} - r_{ij}\sin\theta_{ij}) + P_i\sum_{j\in\mathcal{N}_i} V_j(r_{ij}\cos\theta_{ij} + x_{ij}\sin\theta_{ij})$
$p_i^m = Re\left(\frac{(V_i - V_m)^*}{Z_{im}}\right)$
$q_i^m = Im\left(\frac{(V_i - V_m)^*}{Z_{im}}\right)$

Where $N_j \in\mathcal{B}_m$ is the set of nodes, $\theta_{ij}$ is the phase difference between node $i$ and $j$, $g_{ij}$ and $b_{ij}$ stands for conductance and susceptance of branch $ij$.

## 4. Deep reinforcement learning formulation

### 4.1. Partially observable Markov game formulation

In this paper, the ORC-VTC model can be reformulated into a partially observable Markov Game (POMG), which addresses the priority issues inherent in the Markov decision process [29].

In this formulation, the controller of each sub-network is modeled as an agent that interacts with the environment. Since POMG operates only on an incomplete layer, the underlying state can then be protected by the POMG. The observation space $\mathcal{O}_1, \dots, \mathcal{O}_m$ and action space $\mathcal{A}_1, \dots, \mathcal{A}_m$ are

each agent in it acts with action $a_i$, with reward $r_i$ corresponding to the observation $o_i$ after taking the action. After all, the agent receives the reward and observations while it aims to maximize the expected state transition reward.
