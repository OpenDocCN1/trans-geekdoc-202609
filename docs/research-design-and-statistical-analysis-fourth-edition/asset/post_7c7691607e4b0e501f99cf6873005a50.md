## 18.2.6 Testing Independent Correlations Differ

Another question is to ask about relationships between two variables is whether they differ in magnitude. For example, the relationship between high school GPA and college GPA differ for people who identify as men and those who identify as women or nonbinary? It is possible to test whether the correlation between X and Y is the same in two different populations. We can test $H_0$: $\rho_1 = \rho_2$ by using the test statistic

$$z = \sqrt{\frac{1}{N_1-3} + \frac{1}{N_2-3}}$$  (18.4)$$

As an example of using Equation 18.4 with real data, the correlation between subtraction and multiplication accuracy for the 28 third-graders in the Royer data set is .594; for the 25 fifth-graders, it is .225. To determine whether these correlations are significantly different at $\alpha = .05$, we can substitute in Equation 18.4. If we do so, we obtain

$$z = (.684 - .229) / .292 = 1.56$$

This is less than the upper critical value of $z_{crit} = 1.96$, so we do not have sufficient evidence to reject the null hypothesis that the correlations in the populations of third- and fifth-graders are equal.

Suppose we want to run the study again with a larger sample. We can readily do a priori power calculations for this test if we are willing to specify the size of the effect, $q = Z_1 - Z_2$. For example, if we assume that the two population correlations are .594 and .225, so that $q = .684-.229 = .455$, we can use G*Power 3.1 to show that the sample size necessary to have power = .90 for a two-tailed test of $H_0: $\rho_1 = \rho_2$ at $\alpha = .05$ in each group (see Figure 18.4). However, we should be cautious using these calculations when we design research using correlations from small samples. The 95% CI for the correlation between subtraction and multiplication accuracy for third-graders extends from .284 to .792, and the 95% CI for fifth-graders extends from -.206 to .583. In this situation, we should perform several different power calculations to assess the magnitude of the task before us.

## 18.2.7 Testing Hypotheses About Dependent Correlations

In the previous section, we focus on comparisons of correlations across different groups. In this section, our concern is evaluating multiple correlations on the same set. We have questions of interest: First, which variables are correlated? Second, which correlations differ in magnitude? When several variables have been collected from the same set, the correlations may be displayed as a *correlation matrix*. The variables are $X_1, X_2, X_3, X_4$, and $X_5$; the correlation matrix is

| | $X_1$ | $X_2$ | $X_3$ | $X_4$ |
|---|---|---|---|---|
| $X_1$ | 1 | $r_{12}$ | $r_{13}$ | $r_{14}$ |
| $X_2$ | $r_{21}$ | 1 | $r_{23}$ | $r_{24}$ |
| $X_3$ | $r_{31}$ | $r_{32}$ | 1 | $r_{34}$ |
| $X_4$ | $r_{41}$ | $r_{42}$ | $r_{43}$ | 1 |

If are $k$ variables, the correlation matrix consists of $k^2$ elements. The $k$ elements on the major diagonal (the one that goes from the upper to the lower right) are all equal to 1 because any variable is perfectly correlated with itself. The $k^2-k=k(k-1)$ off-diagonal elements can be divided into a set of $k(k-1)/2$ correlations around the diagonal and a set of equal size. The matrix is symmetric because correlations on opposite sides of the diagonal are identical; $r_{ij}=r_{ji}$ for all $i$ and $j$.

When k is large, the number of correlations will be large. For example, if $k=20$, $k(k-1)/2=190$. If we tested each correlation for significance at $\alpha=.05$, the Type 1 error rate for the entire family of correlations would be very high. Although most software packages will dutifully provide the significance level for each correlation coefficient as though it were the only tested, it is necessary to control Type 1 error here as when we perform multiple $t$ tests on the differences between means.
