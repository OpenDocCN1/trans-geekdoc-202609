# The Standard Errors of $\hat{Y}_j$ and $e_j$

In Appendix 19.1, we found that

$b_1 = \sum f_i Y_i$ where $f_i = \frac{X_i - \bar{X}}{SS_X}$

and

$b_0 = \sum g_i Y_i$ where $g_i = \frac{1}{N} \frac{\bar{X}(X_i - \bar{X})}{SS_X}$

Putting these together, we see

$$\hat{Y}_j = b_0 + b_j X_j = \sum g_i Y_i + X_i \sum f_i Y_i$\n
$= \sum (g_i + X_i f_i) = \sum (\frac{1}{N} \frac{\bar{X}(X_i - \bar{X})}{SS_X} + X_i \frac{X_i - \bar{X}}{SS_X}) Y_i$

$= \sum (\frac{1}{N} \frac{(X_i - \bar{X})(X_i - \bar{X})}{SS_X}) Y_i$

so,

$\hat{Y}_j = \sum b_{hj} Y_h$ where $b_{hj} = \frac{1}{N} \frac{(X_j - \bar{X})(X_h - \bar{X})}{SS_X}$

And

$\hat{Y}_j = b_{hj} Y_h + \sum h_{ij} Y_i$ where $b_{hj} = \frac{1}{N} \frac{(X_j - \bar{X})^2}{SS_X}$ is the leverage of case $j$.

Then,

$var(\hat{Y}_j) = var(\sum h_{ij} Y_i) = \sigma_e^2 \sum h_{ij}^2$

But expanding and simplifying reveals that

$\sum h_{ij}^2 = b_{jj}$
