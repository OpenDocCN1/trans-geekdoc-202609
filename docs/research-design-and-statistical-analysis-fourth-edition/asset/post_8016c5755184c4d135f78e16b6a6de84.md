## 18.2.3 Using the Fisher Z Transformation

Although the $t$ test for the null hypothesis $\rho=0$ is quite robust with respect to the assumption of normality (see, for example, Edgell & Noon, 1984), it cannot be used to test null hypotheses $\rho$ other than $\rho = 0$, nor can it be used to develop confidence intervals for $\rho$. This is because the shape and the standard error of the sampling distribution of $r$ depend on $\rho$, the very value we are trying to estimate. When $\rho$ differs from 0, the sampling distribution of $r$ is skewed, even for large samples. The sampling distribution of $r$ is negatively (left) skewed if $\rho$ is positive and positively (right) skewed if $\rho$ is negative; an appropriate transformation of $\rho$ will allow us to test these hypotheses and to find confidence intervals for $\rho$.

Fisher showed that if bivariate normality can be assumed, a logarithmic transformation

$$Z_r = \frac{1}{2}\log_e\frac{1+r}{1-r} \quad (18.2)$$

where $\log$ is the natural logarithm, is approximately normally distributed with mean

$$Z_\rho = \frac{1}{2}\log_e\frac{1+\rho}{1-\rho}$$

and standard error

$$\sigma_r = \frac{1}{\sqrt{N-3}}$$

for sample as small as $N = 10$. The effect of this Fisher Z transformation³ is to stretch the right tail of the sampling distribution for values of $\rho$ and to stretch the left tail for negative values of $\rho$ to make the transformed distribution more symmetric. Thus, we can calculate confidence intervals for $\rho$ by first using the normal distribution to find the confidence interval for $Z_\rho$, and then transforming back to $r$$. The transformation also allows us to test null hypotheses of the form $H_0: \rho = \rho_{hyp}$ where $\rho_{hyp}$ is not equal to 0⁴.

Given an observed correlation $r$, we can find the value of the Fisher transformation, $Z_\rho$, using Appendix Table C.10, or the transformation menu found in most statistical packages. The $100(1-\alpha)\%$ confidence interval for $\rho$ is then given by

$$Z_\rho \pm\sigma_r$$

where $z$ is the value that cuts off the upper $\alpha/2$ of the standard normal distribution; for the 95% confidence interval, $z_{025} = 1.96$. For the 28 third-graders in the Royer data set, the correlation between subtraction and multiplication accuracy is .594. The Fisher transformation of .594 is approximately .684. The 95% confidence interval for $Z_\rho$ is given by

$$.684 \pm(1.96)\frac{1}{\sqrt{25}} = .684\pm.392$$

That is, the confidence interval extends from $Z$ values of .292 to 1.076. Transforming back to $r$ scores using Appendix Table C.10 (or the hyperbolic tangent function of a calculator) yields 95% confidence intervals of .284 and .792 for $\rho$. Note that because the Fisher Z transformation is a nonlinear function of $r$, the upper and lower limits of the confidence interval are not equidistant from the observed value of $r$.

We can reject the null hypothesis $H_0: \rho = \rho_{hyp}$ at $\alpha = .05$ for all values of $\rho_{hyp}$ that fall in the confidence interval; that is, for all hypothesized values of $\rho$ less than $.284$ or greater than $.792$. We can also reject the hypothesis $H_0: \rho = \rho_{hyp}$ by using the test statistic

$$z = \frac{Z_r - \rho_{hyp}}{\sqrt{N-3}} \quad (18.3)$$

Even though we can reject the null hypothesis $\rho = 0$ for the example in which we have $r = .594$ in a sample of size $N=28$, we cannot be certain about the exact value of $\rho$ because the 95% confidence interval is quite wide. It is sobering to consider how large confidence intervals for $\rho$ are, even for moderately large sample sizes. If we had obtained a $t$ correlation of .594 from a sample of $N=100$, the 95% confidence interval would extend from approximately .45 to .71 – still quite large. We strongly recommend finding confidence intervals for correlation coefficients.

We can calculate the power and sample sizes necessary to achieve desired levels of power. For example, suppose we want to test the hypothesis $H_0: \rho = .30$, $H_1: \rho \neq .30$ at $\alpha = .05$, with power = .80, using Equation 18.3. In G Power 3, the t-based point biseral test was used in Section 18.2.2 no longer applies because the null hypothesis type for $\rho$ is not zero. To enter a non-zero null hypothesis for $\rho$ and a specific alternative value, we use the Exact test and the *Correlation*: Bivariate normal model statistical test. Click on the Options button and select the radio button to use large sample approximation (*Fisher Z*). If we assume that the true value of $\rho$ ($H_1$) is .50, G Power determines that the required sample size is $N=140$. A medium sample size is found if we use the distribution to calculate power from the distribution of $r$.

It is important to note that if a priori power calculations are based on a correlation, the results may be misleading if the true correlation is different from the assumed value. Therefore, it is better to report a range of possible correlation values and the corresponding sample sizes.

## 18.2.5 What If the Assumption of Bivariateality is Violated?

The model underlying statistical inference in this chapter assumes bivariate normality (see Section 18.2.1). However, we know that in real data sets, distributions follow ideal normal (e.g., Miller, 1989). There are two easily detected conditions that indicate a violation of normality. The first, bivariate normality assumption requires that both X and Y are normally distributed, so it is obviously violated if the marginal distributions are not; the second, if there is any nonlinear relation between X and Y. Recall that Q-Q plots are useful in detecting these. As with violations of the assumptions of a test, our concern is either the I error rate will be inflated, power will be reduced, or both. There have been several studies to investigate the robustness of significance tests under violations of normality (e.g., Eddington & Noon, 1984; Havlicek & Peterson, 1977; Lee & Rodgers, 1998). The results show that tests of the hypothesis $H_0: \rho = 0$ are quite robust with respect to Type I error. Type I error rates are close to their nominal values, even for skewed distributions.

If Type error is well controlled when the assumption of normality is violated, the loss of power can be substantial. Lee and Rogers (1998) calculated the power for the test of $H_0:\rho =0$ when the rho was .4. They compared the power when samples were drawn from a normal population to the power when samples were drawn from a heavily skewed population. For sample sizes of both 30 and 60, sampling from the skewed population cut power by more than half compared to sampling from the normal population. This severe decline in power suggests that when the normality assumption is violated, we should consider alternatives.

An alternative procedure that may be useful when the normality assumption is not satisfied. Bootstrapping is a general procedure, computationally intensive approach to inference (see, for example, Efron & Diaconis, 1983; Efron, 1988) in which the sampling distribution of any statistic can be obtained by repeatedly sampling, with replacement, the observed sample.
