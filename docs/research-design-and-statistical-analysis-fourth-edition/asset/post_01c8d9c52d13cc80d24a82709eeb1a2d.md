The ANOVA tables are the same for both analyses. (d) The interpretation of the coefficients depends on coding scheme. For effect coding, $b_0$ = mean of groups of $Y_i$; $b_1$ = mean of group 1 - $b_0$; $b_2$ = mean of group 2 - $b_0$. For dummy coding, the reference group was set to $Y_3$, $b_0$ = mean of group 3; $b_1$ = mean of group 1 - $b_0$; $b_2$ = mean of group 2 - $b_0$.

- Set 1 is appropriate – effect coding.
- Set 2 is appropriate – dummy coding.
- Set 3 is appropriate using the proposed dummy variables which will result in $SS_{between}$ although the coefficients are two variables, which would be interpretable.
- Set 4 is not appropriate because the values on $X_i$ are just constant 3. $X_1$ and $X_2$ are perfectly correlated so we effectively have one dummy variable.
- Set 5 is not appropriate. There is only one dummy variable, $SS_{between}$ will equal $SS_{within}$ only if condition means are correlated with the values of $X_1$.
- Set 6 is not appropriate because there are three dummy variables, but two degrees of freedom for the effect of the condition. Regressing $Y$ on any two of $X_1$, and $X_2$ will yield $SS_{between}=SS_{between}$.
