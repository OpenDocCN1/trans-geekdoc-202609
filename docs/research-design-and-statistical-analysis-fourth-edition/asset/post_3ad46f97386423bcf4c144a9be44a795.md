```
> anova(lm(data=dat,Y~X))

```

Response: Y

Regressing Y on X, and the dummy variables for A,

```
> anova(lm(data = dat, Y~ X+X1+X2))
Analysis of Variance Table
```

Response: Y

| Df | Sq Mean Sq F value | Pr(>F) |
|---|---|---|---|---|---|
| X | 1 | 610.23 | 610.23 | 186.159 | 1.771e-09 *** |
| X1 | 1 | 140.77 | 140.77 | 42.945 | 1.284e-05 *** |
| X2 | 1 | 42.05 | 42.05 | 12.828 | 0.003007 ** |
| Residuals | 14 | 45.89 | 3.28 | | |

From the first analysis, we have $R_{Y,X}^{SS} = 610.23$. And from the second analysis, we have $R_{Y,X,A}^{SS} = 610.23+140.77+42.05 = 793.05$ so that that

> $SS_{A(adj)} = (1 - R_{Y,X,A}^2)SS_{YY} = 793.05 - 610.23 = 182.82$

And

> $SS_{S/A(adj)} = (1 - R_{Y,X}^2)SS_{SY} = 45.89$

The ANCOVA test statistic is $F(2,14) = \frac{MS_{A(adj)}}{MS_{S/A(adj)}} {(a-1)/(N-a-1)} = 27.886$.

This is the F as we calculated in 24.2.

## Chapter 25

25.3 $f^2 = \frac{\Delta R^2}{1-R^2} = .021$ because the regression of depression (sqrtBdiplus) on occupational and household physical activity for women yields $R^2 = .024$. Adding leisure-time physical activity increases $R^2$ to .044. Cohen's guidelines are .02, .15. and .35 for small, medium, and large effects, so this effect is medium to medium-large.

We could use a chi-squared test of independence, finding employment status and sex are not independent:

```
> chisq_test(dat$employed,dat$sex)
# A tibble: 1 x 6
n statistic p df method p.signif

```

Or, we can use correlation. Testing the correlation does not usually test independence, but it does when both variables are dichotomous:

```
> cor.test(dat$employed,dat$sex)
```
