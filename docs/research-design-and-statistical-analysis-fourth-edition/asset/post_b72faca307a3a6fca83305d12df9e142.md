## 10.7.2 Tukey's (1953) HSD Test

Tukey's HSD (honestly significant difference) test controls the $FWE$ for the set of all possible pairwise comparisons. It is a simultaneous method for testing hypotheses or constructing confidence intervals, meaning that a single value is used to evaluate all contrasts in a set. If the procedure is carried out with the help of software, it is helpful to compare differences against a critical difference. a critical value of $q$ is selected from Appendix Table C.8 (or value is multiplied by the standard error of the mean to find the critical difference between the two means that must be exceeded for significance. In many studies, only a few of the possible pairwise comparisons will be of interest. In such cases, the Tukey test or the Dunn-Bonferroni procedure the better choice for con- FWE? Dunn (1961) demonstrated that when all pairwise comparisons are tested, the Tukey procedure has the narrower confidence interval and is the more powerful. However, the advantage of the Tukey procedure declines as the FWE decreases, the df increases, or K decreases. Furthermore, if a subset of all possible pairwise comparisons are planned and tested, a point is reached which the Dunn-Bonferroni procedure is more powerful. For example, if there are four groups but only four or few of the six comparisons are tested, the Dunn-Bonferroni method requires a smaller value of t for significance than Tukey’s method.

If the researcher plans to test a subset of all possible pairwise comparisons, the power of the Dunn–Bonferroni and Tukey methods is easily assessed by comparing the critical values of the two procedures when expressed as t statistics: Calculate the critical values of the Dunn–Bonferroni to the Tukey method:

```
$D - B = \frac{t_{FWE,K}}{q_{FWE,K} / \sqrt{2}} \quad (10.19)$
```

where K is the number of comparisons, and the t and q statistics are the values required for significance when K are made. When the ratio is less than 1, the Dunn-Bonferroni requires a smaller critical value and will therefore be the preferred method.

In summary, the researcher carefully plans only those pairwise comparisons that are truly of interest, power may be gained by using methods that focus only on the planned comparisons. Equation 10.19 provides a basis for deciding between the methods.

## 10.7.3 The Fisher-Hayter Test

The tests considered so far do not require a preliminary test of the omnibus null hypothesis; they control the FWE at or below its nominal level. In fact, requiring a significant omnibus F prior to these tests is likely to result in a loss of power. However, there are procedures for controlling the FWE that include an omnibus F as a first stage; pair-wise comparisons are conducted only if the initial F is significant. In Fisher’s (1935) LSD (least difference procedure), the pairwise comparisons are tested by the usual t test in the second stage. Because the LSD test has shown to have an inflated FWE for $a > 3$, Hayter (1986) modified the test. The result-Fisher-Hayter test maintains the FWE at or below its nominal level. In this, a significant F in the first stage is followed by tests of all pairwise comparisons using a standard t test, but each test is evaluated against the criterion $q_{FWE-1,dt} / \sqrt{2}$. Note that in Table C.8, the column corresponding to $a - 1$ provides the critical value, and if qtukey in R (see Section 10.7.1), the nmeans parameter should also be $a - 1$.
