A confidence interval provides several advantages over a hypothesis test:

- 1. It provides a bounded estimate of the population parameter, focusing attention on a range of plausible values rather than asking whether that parameter equals one specific value.
- 2. The confidence interval permits tests of all possible null hypotheses simultaneously, thus providing considerably more information than the hypothesis test.
- 3. The interval width provides information about the precision of the research. A significant result, with a narrow interval, may suggest that power was so great as enable us to reject a trivial effect. On the other hand, a nonsignificant result, together with a wide interval, suggests that our experiment lacked precision, pointing to the need for either less variable, more careful application of experimental procedures, or a larger sample.

If you recall the discussion from Chapter 4 of factors that influence power, you will find that the width of the interval is influenced by the same variables that influence power. The narrower the interval, the more powerful a test of any null hypothesis will be. As $n$ increases and $s$ decreases, the confidence interval narrows, and power increases. Furthermore, increasing $\alpha$ and decreasing confidence have parallel effects. An increase in $\alpha$ increases power at the cost of increasing the Type 1 error rate. There is a significant tradeoff between confidence level and the interval width; decreasing confidence yields a narrower interval, providing a more precise estimate but with less confidence in that estimate.

In Section 5.4.3, we use the $pnorm$ function in R and the $CDF.NORMAL$ function in SPSS to compute the probability of a score less than the observed $z$ score. There are corresponding functions to do the opposite task, namely to identify the critical value of $z$ that has a particular probability of scores falling below it.

In R, the $qnorm$ function in `stats` package performs that task. For example, the command $qnorm(.95)$ returns the critical value of $z$, 1.645, which has 95% of scores below it and 5% above it. Like the $pnorm$ function described in Section 5.4.3, $qnorm$ can also take different means and standard deviations as input: $qnorm(.95, mean = 500, sd = 15)$ returns 524.7, the value of the variable at the 95th percentile of an $N(500, 15)$ population distribution.

In SPSS, we begin by creating a variable, $x$, with value 0.95. This value is the probability for which we seek a critical value. Next, use the Transform and Compute Variable pull-down menus and then select the Inverse DF function group. Within this group, choose the `inv.Normal` function, clicking on the “up” arrow to move the function to the Numeric Expression box. The `inv.Normal` function has three inputs, the probability ($x$) and the mean and standard deviation of the normal distribution. Entering `inv.Normal(0.95, 0, 1)` and OK will store the result, 1.645, in the variable named Target Variable. This result is the critical value of $z$ that has 95% of scores below it and 5% above it. We can also identify the $x$ with a certain proportion of data below it in the population. For example, $Normal(0.95,500,15)$ will return 524.7, the value of $x$ at the 95th percentile of an $N(500, 15)$ distribution.
