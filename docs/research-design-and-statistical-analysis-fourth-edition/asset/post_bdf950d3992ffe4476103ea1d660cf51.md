If we want to reject the null hypothesis that both groups have the C effect, we must directly test that the C effect is significantly different for A₁ and A₂—that is, we must test the A x C interaction. 18. Performing multiple statistical tests can increase the overall Type 1 error rate to unacceptable levels. If we perform more statistical tests on the same data set, we are increasingly likely to commit Type 1 errors—that is, we are more likely to find significant results. Procedures for controlling Type 1 error are well developed for certain kinds of tests, which are virtually nonexistent for others. In Chapter 10 we discussed procedures for controlling Type 1 error for families of contrasts. We distinguished between planned (i.e., theory-driven) and unplanned contrasts and methods for controlling Type 1 error in both cases. However, there are areas where such control is less common. For multi-factor ANOVAs, testing each main and interaction at the same level results in a great potential inflation of Type 1 error in design with many factors. Furthermore, we note that the control of Type 1 error is explicitly addressed in multiple regression even when predictors are extremely volatile to Type 1 error, especially when predictors added to the equation have been selected from larger pools of variables. In the regression chapters we distinguish between theory-driven analyses and what might be called ad hoc fitting, the assembling of collectors that just happen to account for large values of R². We also discussed Steiger's (1980) recommendation to perform an omnibus test of the individual correlations (Chapter 18). This is useful because with, say, 15 variables, there are (15)/2 = 105 pairwise correlations. There is nothing wrong with looking at your data very carefully and in different ways—as the saying goes, if you torture your data enough, they will confess! The problem is that if you perform a large number of tests without taking Type 1 error into account, you may confess almost anything.

19. Note that even a nonsignificant result can add to the cumulative evidence for an effect. Suppose a researcher runs a study with 60 participants and finds an unexpected effect that is fairly large and statistically significant. Further, suppose that the effect of theoretical importance and was not predicted, suppose a second researcher needs to repeat the study with 40 participants in an attempt to confirm its existence. If the effect is significant, then there has been a successful revelation and we have added confidence that the effect exists. But suppose the effect in the second study is not significant; the estimated effect is in the same direction, but only about two-thirds of the size of the effect found in the original study. In fact, how do we explain the “discrepancy” between the estimated effect size and, in fact, we would expect sampling variability in the estimate results with the second study because it was run with fewer participants. It is true that we now have two different estimates for the effect size, and that our best estimate of effect size is some average of the effect.

## Some Final Thoughts, Suggestions, and Cautions

It is important to note that although changing one variable while holding constant several others is easy enough to understand in terms of the sample regression equation, it may not correspond to any plausible manipulation in the real world. Despite its limitations, regression analyses can be a very useful component of a program to advance knowledge and theory about a research problem by providing useful descriptions of the data and by suggesting questions and causal speculations that can be pursued by a variety of research techniques.
