
# Additional Topics in Multiple Regression

Now consider measurement error in the predictor variables. The usual regression inference (see Chapters 19 and 21) assumes that predictor variables are fixed and measured without error. However, in many applications, values of the predictors are sampled and measured with error. Measurement error in the predictors may result in serious problems, especially when some of the measurement error is systematic.

If the measurement error in the predictors is random, then at least the error component for the model increases. The presence of random measurement error in any predictor will attenuate the estimate of the corresponding unstandardized coefficient, simply because the presence of noise in the predictor variable weakens its relationship to Y. Figure 22.1 demonstrates this effect using the statistics exam data introduced in Chapter 17: The left panel shows the regression of exam scores on the pretest scores, assuming they are measured without error; the right panel shows the regression after the pretest scores have been “smeared” by adding a random value sampled from N(0, 3); $R^2$ drops from 0.526 when the pretest scores are error-free to 0.134 when they are measured with error.

If the predictors are uncorrelated, the presence of random measurement error in one predictor will not systematically influence the estimated regression coefficient of any other predictor. If, on the other hand, in a multiple regression the predictors are correlated, as is usually the case, the result is more complicated.

The coefficient of any predictor, $X_n$, is the rate of change of $\hat{Y}$ with $X_n$, partialing out the effects of the other predictor variables in the regression equation. When there is measurement error in predictors correlated with $X_n$, it is possible that too much or too little the effects of the other variables will be partialed out. So, depending on the details, unstandardized (b) and standardized (b*) coefficients may be too large or too small.

The situation is at worst when there is systemic error in the measurement of the predictors (e.g., when there are reporting biases as consistently underreporting weight or overreporting hours worked; see Chapter 19), so that there are correlations between these predictors and the error component. If this happens, the OLS estimates of the coefficients will be neither unbiased nor consistent.

Some possible remedies are available. We can try to use variables that are correlated with our predictors but not with the error component (so-called instrumental variables, see Berk, 2004). Or we can use structural equation modeling, a statistical technique for testing and estimating causal relationships that use multiple understandings of concepts and explicitly models error. However, detailed discussion of both procedures is needed for the scope of the current discussion. At the level of coverage in this book, the best advice is to keep the issue of mind and to use the best (cleanest) possible measures available. It should go without saying that if we use error-ridden measures, we have little confidence in the results of our statistical analyses: This is a clear example of the adage that "garbage in garbage out."

# 22.4 Missing Data in Multiple Regression

In designing research, we should use measuring instruments and data collection processes that minimize the occurrence of missing data, especially in the dependent variable. Depending on the details, the presence of missing data will result in our analyses reducing power and may well result in biased parameter estimates and tests. The three options offered by SPSS to deal with missing data in the regression module are (a) exclude listwise (i.e., listwise deletion), (b) exclude data pairwise (i.e., pairwise deletion), and (c) replace with mean (i.e., mean substitution).

If we conduct multiple regressions using a set of variables and have some missing data, software allows us to use the listwise deletion option; that is, each regression is conducted using only those cases with complete data on all the variables used in the regression. However, this approach may lead to different regressions performed on somewhat subsets of the data. For example, if we use the Seasons data from the website and regress on sex, age, and BMI, the regression is performed by using the data from 416 participants with complete data on all four variables. If Beck_d is the mean score on Beck Depression Scale over the four seasons, the regression is now based on the data from the 313 cases with complete data on all five variables. If it is important to compare the results of the regressions, we may want to specify that only the data from the 313 participants with complete data on all variables are used in both analyses.

If there are modest amounts of missing data, listwise deletion can have good properties. If the missing data are MCAR (that is, missing completely at random – see the discussion of missing data in Chapter 13), the data from complete cases can be thought of as randomly selected from the original sample. If so, estimates of the regression coefficients obtained by listwise deletion is unbiased if all the regression assumptions are satisfied. The standard errors, of course, e.g., will be larger because they are based on fewer observations.

It can be shown (e.g., see Allison, 2002) that missing data on the dependent variable, Y, are associated with values of Y and/or missing data on the predictors are associated with the values of Y; then regression will yield biased estimates (in this case, we can think of the missing data as an extreme of systematic measurement error). However, as Allison points out, regression with listwise deletion is quite robust with respect to violations of the MAR assumption when the probability of missing data on Y and the predictors does not depend on the values of Y.

Pairwise deletion is not recommended. The idea behind pairwise deletion is to use as much data as possible. Multiple regression can be performed, using the means, standard deviations, and correlations of all the variables in the regression equation. In pairwise deletion, these quantities are calculated using whatever data are available. For example, if Y is the dependent variable and there are two predictors X1 and X2, we can obtain the correlation between Y and X1, without regard to X2, and the correlation between X1 and X2, without regard to Y. The problem is that if we use the pairwise deletion option in the standard statistics, the parameter estimates and test statistics may be biased unless the missing data is MCAR. In some cases, it may not be possible to perform certain higher-order analyses as. Given pairwise deletion, the constraints normally expected in a correlation matrix (see Section 18.3.5) may not hold because different correlations may be obtained from substantial subsets of cases and may be based on different numbers of observers.

Replacing scores by a variable mean (e.g., mean imputation) is also not recommended because it is well known that this procedure biases estimates of variances and correlations. As mentioned in Chapter 13, there are other, more sophisticated methods of imputing missing data that can unbiased estimates if the missing data is MCAR or MAR. Also, when they are repeated-measures, for example, in the case of depression scores measured at each season of the year, hierarchical modeling procedures that use all the available data can be used instead (see Section 29.9).

# 22.5 Multicollinearity

Multicollinearity occurs when predictor variables included in a regression equation are correlated. In this case, the correlated predictors themselves be predicted from the other predictors in the equation; they may not provide much, if any, unique information that is predictive of Y. If at least one predictor can be predicted from the others, then there is perfect multicollinearity. Given perfect multicollinearity, an infinite number of regression equations will fit the data equally well, so the statistical software cannot identify a solution to the regression analysis. A useful way to think about the problem is to consider Figure 20.8, which showed the regression plane for TC predicted from age and BMI, and Figure 22.2. If Y is regressed on X1 and X2, the points (Y, X1, X2) satisfy the equation

```
Y = b0 + b1X1 + b2X2
```
