# ### The Variance of combination of n observations, L, has the general form.

$L = w_1Y_1 + w_2Y_2 + \dots + w_nY_n$

where the weights, the $w_i$ are any real numbers. A special case is one in which $n=2$ and the weights are both 1, in which $L$ is a sum, or 1 and -1, in which $L$ is a difference. We consider this case first.

Variances of Sums and Differences. The variance of a sum or difference of two random variables depends on the variances of the variables and on their covariance. The covariance is a function of the variances and the correlation coefficient; as we stated in Chapter 2, the sample correlation coefficient of two variables, $X$ and $Y$, is defined as

```
$r_{XY} = \frac{\Sigma(X - \bar{X})(Y - \bar{Y}) / (n-1)}{S_X S_Y}$
```

and the covariance is defined as the numerator, $\Sigma(X - ar{X})(Y - ar{Y})/(n-1)$. We will denote the covariance as $s_{xy}$. First consider the variance of $X+Y$; by definition of the sample variance,

```
$s_{X+Y}^2 = \frac{1}{n-1}\Sigma_i[(X+Y) - (ar{X}+ar{Y})]^2$
```

But

```
$\overline{X+Y} = (1/n)\Sigma_i(X_i+Y_i) = \bar{X}+ar{Y}$
```

Therefore,

```
$s_{X+Y}^2 = \frac{1}{n-1}\Sigma_i[(X+Y) - (ar{X}+\bar{Y})]^2\n= \frac{1}{n-1}\Sigma_i[(X_i-\ar{X})+(Y_i-\ar{Y})]^2\n= \frac{1}{n-1}\Sigma_i[(X_i-\ar{X})^2+(Y_i-\ar{Y})^2+2(X_i-\ar{X})(Y_i-\ar{Y})]\n= s_X^2+s_Y^2+2s_{xy}$
```

where $s_{xy} = r_{xy}s_Xs_Y$, the covariance of $X$ and $Y$. Therefore,

```
$s_{X+Y}^2 = s_X^2+s_Y^2+2r_{XY}s_Xs_Y$
```

The variance of the difference scores has a similar form:

```
$s_{X-Y}^2 = s_X^2+s_Y^2-2r_{XY}s_Xs_Y$
```
