# Using ANCOVA

ANCOVA is straightforward to run using software. In SPSS, use the General Linear Model option in the Analyze pull-down menu, select Univariate. For the example data in Table 24.2, move Y to the dependent variable, text to the Fixed Factor(s) box, and X to the Covariate(s) box. If you want to test the homogeneity of slopes, click on the Model button and create main effects for X and text, as well as their interaction. Then Click OK. If you do not build a model, SPSS will test only the main effects of X and text.

In R, be sure that the treatment effect (text) is a factor (as.factor if necessary). The lm function we are familiar with from previous chapters will perform the ANCOVA if you include the covariate in the model: lm(data = dat, Y ~ text + X). Store the result in ancova.out (or whatever name you prefer), and use that as input to Anova with Type III sums of squares: Anova(ancova.out, type = 3). To test the homogeneity of slopes, you must tell R that text and X may interact: Anova(lm(data = dat, Y ~ text * X), type = 3).
