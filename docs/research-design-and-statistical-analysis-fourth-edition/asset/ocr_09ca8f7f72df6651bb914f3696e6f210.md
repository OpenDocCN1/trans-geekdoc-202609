# 3.2.4 Combining Events in the ESP Experiment

To illustrate the potential usefulness of some of the concepts introduced to this point, suppose that Rachel does not have ESP and randomly guesses on every trial. If so, we would expect her to be 25% of the time in the long run because there are equally likely choices on each trial. In evaluating the strength of the evidence against guessing, we want be able to translate our hypothesis that she is guessing on each trial into the probability that she makes a specific number of correct responses in a given number of trials. To do this, we need to consider all the possible sequences of correct and incorrect guesses that might occur. A useful conceptual tool for this purpose is a tree diagram like the one in Figure 3.1. Each branch of the diagram in Figure 3.1 represents a distinct combination of possible outcomes for a four-trial experiment.

Suppose that we want to compute the probability that Rachel makes exactly one correct in a four-trial experiment (i.e., 25% correct). To do this, we must analyze the various ways in which individual trial outcomes produce one correct result in four trials. Looking at Figure 3.1, we can distinguish four sequences of trial outcomes that correspond to one correct response: Rachel can be correct on the first trial, but wrong on the second trials 2 through 4 (call this "sequence 1"), or correct on the second trial (sequence 2), or on the third (sequence 3), or the fourth (sequence 4). Each of these sequences represents a joint event; e.g., (correct on trial 1) and (error on trial 2).
