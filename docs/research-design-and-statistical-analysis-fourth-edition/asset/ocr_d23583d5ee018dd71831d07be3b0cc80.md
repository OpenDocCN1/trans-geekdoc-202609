# 9.6.1 Eta-Squared ($\eta^2$) for the Multi-Factor Between-Subjects Design

The first criterion is readily met. For example, in a three-factor experiment in which all the factors have been manipulated, the statistic would

```
$$\eta_p^2(Effect) = \frac{SS_{Effect}}{SS_{Effect} + SS_{Sicells}}$$ (9.11)$
```

As have seen, this statistic is referred to as partial “p” in the notation to distinguish partial $\eta^2$ defined in Chapter 8. $\eta_p^2$ is an appropriate measure of effect size in a design that contains only extrinsic factors. It is not appropriate, if the design contains intrinsic factors, as in the next example.

Assume that one of the three factors in the experiment is the participant's experience with the task. Factors as experience, age, and level of ability are intrinsic to the subject so they should be retained in the denominator of our calculation of $\eta^2$. Olejnik and Algina (2003) propose a statistic that general eta-squared, which we will denote with a “g” in the subscript to distinguish it from classical and partial eta-squared. In a design with two extrinsic factors, (A, B) and intrinsic one, C, for A now would be

```
$$\eta_g^2(A) = \frac{SS_{A}}{SS_{A} + SS_{C} + SS_{AC} + SS_{BC} + SS_{ABC} + SS_{Sicells}}$$ (9.12a)
```

which is equivalent to

```
$$\eta_g^2(A) = \frac{SS_{A}}{SS_{total} - SS_{B} - SS_{AB}}$$ (9.12b)
```

The reasoning behind this equation is that if we were comparing this statistic with one based on a one-factor design, the error variance in the one-factor design would include variability due to the intrinsic factor, C, and its interaction with other factors. Therefore, to have comparable values of $\eta^2$ for the two designs, we include the intrinsic sources of variability in the denominator of the statistic for the three-factor design.

Now we want a measure of effect size for the intrinsic factor, C, in a three-factor design. Then,

```
$$\eta_g^2(C) = \frac{SS_{C}}{SS_{C} + SS_{AC} + SS_{BC} + SS_{ABC} + SS_{Sicell}}$$ (9.13a)
```

which can be rewritten as

```
$$\eta_g^2(C) = \frac{SS_{C}}{SS_{total} - SS_{A} - SS_{B} - SS_{AB}}$$ (9.13b)
```

We summarize developments as follows:

The denominator of $\eta_g^2$ includes the sums of squares for the effect of interest, the within cell error term, and for all intrinsic factors and their interactions.
