# 10.4 Extending Cohen's d to Contrasts

In Section 6.8, we introduced Cohen's d, a measure of the effect when there are two levels of the independent variable. This measure can be extended to contrasts in which several group means are involved. Assuming homogeneous variances, the general form of the standard-effect size for a contrast is

```
$d = \hat{\mu}/\sqrt{MS_{SIA}} \quad (10.11)$
```

Using the memory data summarized in Table 10.1, and the contrast illustrated there,

```
$d = 0.9/\sqrt{17.944} = 0.21$
```

Thus, the standardized contrast is of small size according to Cohen's (1988) guidelines. Without consideration of confidence bounds, it is difficult to evaluate this statistic, but it leaves open the possibility that power may have been low in the original test.

# 10.5 The Proper Unit for the Control of Type 1 Error

# 10.5.1 Defining a Family of Tests

As stated in the Introduction, the probability of a Type 1 error increases with the number of significance tests. If, there the probability of each significance test is set without regard to how many tests might be conducted, the error rate for the entire collection of tests may rise to an unacceptable level. Statisticians and researchers generally agree that the proper unit for control of the Type 1 error is not the individual test but a set of contrasts called *family*. Before we address the question of how to limit the Type 1 error rate for the family, we should clarify the definition of a family of contrasts.

FWE = p(at least one Type 1 error in the family)
= 1 - p(no Type 1 errors in the family)
= 1 - p(no Type 1 error on a single test)$K$

The probability of a Type 1 error on a single test is the EC. Therefore,

```
$FWE = 1 - (1 - EC)^K \quad (10.12)$
```
