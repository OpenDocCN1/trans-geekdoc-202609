For any two events, $E_1$ and $E_2$, there is an important relationship between $p(E_1 \mid E_2)$ and $p(E_2 \mid E_1)$. From Equation 3.15, we know that

```
$p(E_1 \mid E_2)p(E_2) = p(E_2 \mid E_1)p(E_1)$
```

We can divide both sides by $p(E_2)$ to obtain Bayes' rule:

```
$p(E_1 \mid E_2) = \frac{p(E_2 \mid E_1)p(E_1)}{p(E_2)} \quad (3.16)$
```

Earlier, we computed the probability of a psychology major earning an A in a statistics class, using the data in Table 3.1: $p(A \mid \text{psychology major}) = 15/60 = .25$. Using the same data, we computed $p(\text{psychology major} \mid A) = 15/27 = .55$. Now, let's use Bayes' rule to find the conditional probability of a psychology major earning an A:

```
$p(A \mid \text{psychology}) = \frac{p(\text{psychology} \mid A)p(A)}{p(\text{psychology})} = \frac{\frac{15}{27}}{\frac{60}{100}} = 0.25$
```

Bayes' rule allows us to calculate probabilities we care about — like the probability that we have a disease if we receive a positive test result — from what we know: the base rate of the disease in the population and the probability of a positive test result for individuals who do not have the disease (see Exercise 3.5). Bayes' rule also provides the foundation for Bayesian statistics, an approach that allows the researcher to decide how much to believe a hypothesis after observing some data, $p(\text{hypothesis} \mid \text{data})$, given a set of prior beliefs about the world, and a probability model, $p(\text{data} \mid \text{hypothesis})$.

### 3.3.10 Computing Probabilities of Events in the ESP Experiment

Let's apply what we have learned about probability to calculate the probability of one correct guess in a four-trial ESP experiment. In Section 3.2, we established that there were four sequences of trials corresponding to the experimental outcome of exactly one correct guess in four trials. If C and E are used to denote guesses that are "correct" and "error," and we use subscripts to denote trials, then the four sequences of interest are:

$<C_1, E_2, E_3, E_4>$, $<E_1, C_2, E_3, E_4>$, $<E_1, E_2, C_3, E_4>$, and $<E_1, E_2, E_3, C_4>$. 

Each of these sequences represents a joint event, and it is reasonable to assume that outcomes are independent. If we hypothesize that Rachel guesses every trial, then $p(C) = .25$ and $p(E) = 1 - .25 = .75$. Applying the multiplicative rule, the probability of each sequence is $(.25)(.75)(.75)(.75)=.105$. However, we are not interested in the probability of a specific sequence, but in the probability of any one of the sequences occurring. That is, we wish to compute

```
$p(|C_1, E_2, E_3, E_4> + |E_1, C_2, E_3, E_4> + |E_1, E_2, C_3, E_4> + |E_1, E_2, E_3, C_4>)$
```

Since the sequences are mutually exclusive and we want the probability of their union, we may apply the additive rule and sum their probabilities. Thus, the probability of one correct guess in four trials if Rachel is guessing is $(.105+.105+.105+.105)=.42$. In general, if Rachel is guessing from four equally likely alternatives, then the probability that she will be correct exactly once is .42.

## 3.4 Probability Distributions

We are not interested in just one possible outcome of an experiment. It is possible that Rachel will get 0, 1, 2, 3, or 4 correct in our four-trial ESP experiment. The probabilities of each of these possible outcomes based on a statistical model—a set of assumptions about how the responses are generated—can be used to calculate the probabilities—is referred to as a probability distribution or probability model.

### 3.4.1 Random Sampling, Random Variables, and Distributions of Random Variables

In any experiment, we consider our observations to be a sample from a much larger infinite population of observations. We attempt to obtain a sample that is representative of the population from which the observations are drawn. In calculating probabilities, we assume random sampling. Random sampling means that each of these potential trials has an equal opportunity of being sampled. Although the goal of random sampling is to obtain a representative set of observations, samples will differ from one another and thus are not perfect mirrors of the population from which they are drawn. Put another way, statistics are variables because they can take on different values for different samples. When the numerical value of a variable is determined by a chance event, that variable is called a random variable. Therefore, statistics as well as outcomes of chance events, such as throwing a pair of dice or guessing the identity of a card (scored 1 correct and 0 wrong), are random variables.

### 3.4.2 Discrete Random Variables

In many situations, a random variable may take only a limited number of values within its range. In our ESP experiment, if the random variable of interest is the number of correct responses in 20 trials, the possible values are the 21 integers from 0 to 20. Alternatively, we might characterize the results of the ESP experiment in terms of the proportion of correct responses, in which case the possible values of our random variable would be each of the integers divided by 20. In either case, there is a relatively small number of possible values so the variable is discrete. This contrasts with other variables such as the amount of time taken to make a response. Time is a continuous variable that can take an infinite number of possible values if measured precisely.

We will encounter many situations involving discrete variables that are of interest. We have already given a great deal of attention to the number (or proportion) of correct guesses in an ESP experiment. Probability calculations for discrete random variables are often simple. With just a basic knowledge of probability, we were able to compute the probability that Rachel makes exactly one correct guess in a four-trial ESP experiment by randomly guessing. We would similarly calculate the probability of each other potential outcome of the four-trial experiment and we will do so in Chapter 4. The graph of the resulting probability distribution is given in Figure 4.1. In general, a probability distribution associates with every possible value of a random variable.

### 3.4.3 Continuous Random Variables

Imagine that we are interested in the distribution of times it takes healthy adults in the 20 to 40 year age range to complete a 1-mile run. The range of times will be finite (i.e., between 3.75 and 5.5 minutes). However, if we could measure time to any degree of precision, then any value between the extremes might be observed. Unlike our example of correct guesses in an ESP experiment, the random variable of time to complete a mile run is a continuous random variable.

Although we deal only with discrete random variables in practice because there are always limits to the precision of our measurements, however, continuous functions provide excellent approximations to distributions of discrete random variables, so they will turn out to be very useful in many inferential applications. It is important to develop a basic understanding of the properties of distributions of continuous random variables.

In general, the probability of occurrence of any exact value of a continuous random variable is essentially zero. For this reason, we do not talk about the probability of a value of a continuous random variable. Instead, we refer to the probability density at a particular value of a continuous random variable. We will symbolize the probability density of a variable Y at a by

```
f(a) = probability density of Y at a
```

Graphically, the probability density at a particular value of a continuous random variable is the height of the probability distribution at that value.
