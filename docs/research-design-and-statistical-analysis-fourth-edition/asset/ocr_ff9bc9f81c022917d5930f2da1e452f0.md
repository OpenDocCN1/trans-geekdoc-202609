# 9.3.6 Using Software for Two-Factor-Between-Participants ANOVA With Equal n

Two-factor-participants ANOVAs are straightforward when the sample sizes are equal in all cells. In R, the `anova` function in the [stats] package works the same way as for one-factor designs; the only modification is to include both factor names. For example, `summary(anova(data = Frame, DV ~ A*))` requests an ANOVA on the data in the data frame named `Frame`. The `anova` requests the ANOVA and summary requests the output in the form of an ANOVA table. The dependent variable, DV, is analyzed as a function of factors A, B, and their interaction.

In SPSS, we select the General Linear Model from the Analyze pull-down menu, and Univariate. Move the dependent variable from the list to the left of its on the right, and move the factor variables to the box labeled “Fixed Effects” before clicking okay. By default, the ANOVA will include all main effects and interactions.
