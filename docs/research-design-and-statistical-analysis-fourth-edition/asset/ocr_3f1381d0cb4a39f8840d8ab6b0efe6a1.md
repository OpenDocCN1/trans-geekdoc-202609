usually the case, the result is more complicated. The coefficient of any predictor, X_n, is the rate of change of \hat{Y} with X_n, partialing out the effects of the other predictor variables in the regression equation. When there is measurement error in predictors correlated with X_n, it is possible that too much or too little the effects of the other variables be partialed out. So, depending on the details, unstandardized (b) and standardized (b*) coefficients may be too large or too small.

The situation is at worst when there is systemic error in the measurement of the predictors (e.g., when there are reporting biases as consistently underreporting weight or overreporting hours worked; see Chapter 19), so that there are correlations between these predictors and the error component. If this happens, the OLS estimates of the coefficients will be neither unbiased nor consistent.

Some possible remedies are available. We can try to use variables that are correlated with our predictors but not with the error component (so-called instrumental variables, see Berk, 2004). Or we can use structural equation modeling, a statistical technique for testing and estimating causal relationships that use multiple underings of concepts and explicitly models error. However, detailed discussion of both procedures is needed for the scope of the current discussion. At the level of coverage in this book, the best advice is to keep the issue of mind and to use the best (cleanest) possible measures available. It should go without saying that if we use error-ridden measures, we have little confidence in the results of our statistical analyses: This is a clear example of the adage that "garbage in garbage out."

# 22.4 Missing Data in Multiple Regression

In designing research, we should use measuring instruments and data collection processes that minimize the occurrence of missing data, especially in the dependent variable. Depending on the details, the presence of missing data will result in our analyses reducing power and may well result in biased parameter estimates and tests. The three options offered by SPSS to deal with missing data in the regression module are (a) exclude listwise (i.e., listwise deletion), (b) exclude data pairwise (i.e., pairwise deletion), and (c) replace with mean (i.e., mean substitution).

If we conduct multiple regressions using a set of variables and have some missing data, software allows us to use the listwise deletion option; that is, each regression is conducted using only those cases with complete data on all the variables used in the regression. However, this approach may lead to different regressions performed on somewhat subsets of the data. For example, if we use the Seasons data from the website and regress on sex, age, and BMI, the regression is performed by using the data from 416 participants with complete data on all four variables. If Beck_d the mean score on Beck Depression Scale over the four seasons the regression is now based on the data from the 313 cases with complete data on all five variables. If it is important to compare the results of the regressions, we may want to specify that only the data from the 313 participants with complete data on all variables are used in both analyses.

If there are modest amounts of missing data, listwise deletion can have good properties.
