# 12.6 The Latin Square Design

### 12.6.1 An Example of the Design

Suppose we wish to measure accuracy on five tasks of varying strength. We intend to present each task for a block of trials, recording percent correct for each block. Because a trial block requires little time to complete, we decide to present the tasks in a series of five blocks that will be a score for each participant in each trial block. We have two options with respect to the design. If we have n participants, we may construct n random sequences of the five trial blocks, assigning each participant to a sequence. For five participants, the sequences in this repeated-measures design might look more often than others in some sequential positions. Note that some treatments appear more often than others on the left side of Table 12.6. For example, the fifth condition (λ) is presented first to two participants and second to another. If there is an improvement with time in the sequence, performance on this task would be at a disadvantage because its average position is early in the sequence of trial blocks. Although randomization ensures that the average sequential positions of the tasks will be equal over replications of the experiment, the practice effect does introduce error variance, rendering the design less efficient than it would be if we could somehow remove these effects from the error variance.

The right side of Table 12.6 presents a balanced design in which each treatment appears in each row (participant) and column (the numbers in a game of Sudoku). Columns represent blocks of trials, as in the preceding example, or sets of materials, as in many studies of language processing. The independent variable in this Latin square design and we can now separate its effects from the error variance. Therefore, this design has the potential to be more efficient than the repeated-measures design in which treatments are randomly assigned to trial blocks, or material sets. Although the design on the right is potentially a very efficient one, therefore promising considerable power and precision of estimates, there are some potential drawbacks, in the following:
