# 20.6 Multiple Regression Analyses of the TC Data

We have identified and discussed the components of the regression equation, and we have explained how to use software to generate the analyses. We now illustrate the computations using data from the TC study for which preliminary analyses were presented in Section 20.2. 20.7 presents the R output for the regression of TC on both age and BMI.

Breaking down the analysis presented in Figure 20.7:

+   1. The Estimate column in the coefficients panel provides the least-squares estimates of the Y intercept (b₀) and the unstandardized regression coefficients (or unstandardized partial slope coefficients) for X₁, and X₂, b₁ and b₂. These entries will show that the best least-squares regression equation includes both age and BMI as predictors

```
Ŷ = 92.239 + 1.737X₁ + 1.474X₂ (20.9)
```

The plot of Equation 20.9 is displayed in Figure 20.8, along with the data points; residuals are denoted by lines connecting each data point with its predicted value. Instead of the regression line that we obtained using bivariate regression, we now have a two-dimensional regression plane. If BMI held constant, a one-unit (i.e., 1-year) change in age corresponds to an increase of 1.737 units in predicted TC.
