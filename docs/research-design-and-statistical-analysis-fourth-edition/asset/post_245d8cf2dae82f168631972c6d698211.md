The study is a specific example of a general design in which there are n participants, of whom are nested with b different stimuli at each a levels of A; in the prior example, n = 8, a = 3 (moods), and b = 5 (faces within each mood). ## 15.2 Partitioning Sum of Squares and Degrees of Freedom

In the example represented by the data of Table 15.1, there are a a x b, or 3 x 5, pictures of faces so there are ab-1, or 14, degrees of freedom for items. The part of variability the scores on the ab items is due to the moods. This accounts for a-1, or 2, of the 14 df for items. The remaining ab-1, or 12, df for the B/A term (within moods). In addition, each of n, or participants is shown all of the pictures representing all three moods, participants cross with A: SA, with (n-1)(a-1) = 14 df. Participants also are nested within levels of A and are written SIB/A. This notation expresses that the combination of participants and items is different for each of the levels of A. The SB interactions each have (n-1)(b-1) = 28 df, and there are three levels of A in which those interactions nest, so the SB/A df = 3(28) or 84. Summing all these degrees of freedom, 2 + 12 + 14 + 84, 7 more for the participants, equals 119, accounting for the total degrees of freedom in the experiment, nab-1. ## 15.2.4 Using Software for the Hierarchical Design

Several statistical packages provide analyses for designs in which one or more variables are nested within levels of other variables. For example, in R, we can use the `aoov` function in the [stats] package. The statement in `aoov` specifies the dependent and independent variables. For example, $Y - A + B$ specifies an additive model and $Y^*$ specifies a nonadditive model (factors A, B, and their interaction are included). One way to specify nested variables is to use the `%in` operator: $Y \sim S^* + B \in A$ specifies a model that includes S, A, and their interaction, as well as B, which is nested in A. Putting this together, for data in a data frame, the command `summary(aoov(data))` will show all factors are fixed, and additional calculations are required to test the main effect of A with F (see Box 15.1).

In SPSS, we begin with a similar process: with data in long form (one observation per row, as in Table 15.1.xlsx) choose the Univariate option from General Linear Model in the Analyze pull-down menu. Move variables to their appropriate boxes: By the dependent variable, A is a fixed-effect variable, and S and B are random-effects variables. Next, click on the Model button to build a structural model that includes them. Select the radio button “Build terms,” and choose Main Effects from. Select A and S from the Factor list and move them to the Model box. Select “Interaction,” A*S. To add the nested terms, B/A and SB/A, select and move them to the Model box, which will now contain three components: A, S, and A*S. Select the “Build custom terms” radio button. Then, select B and move it down to the “Build Term” box, then click the (“Within”) button followed by selecting A and moving it down to the same box. You should now see B(A) in the Build Term; box; click “Add” to include it in the model.
