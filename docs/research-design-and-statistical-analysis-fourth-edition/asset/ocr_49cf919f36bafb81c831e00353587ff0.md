Although this measure seems a straightforward way to identify outlying data points, it has the important limitation that a data point $(X, Y)$ is far from the other data points, it may have a strong influence on the regression line (see the next section). An influential data point will pull the regression line itself, reducing its residual, but in doing so, it will increase the residuals for many of the other data points. Because of this interdependence of the residuals, a better way to obtain an index of the extent to which a data point is an outlier is to determine its distance from a regression line that does not depend on the point under consideration, but rather based on the $N-1$ data points.

The predicted residual for the $j$th case is defined as

```
$\hat{Y}_j^{(-j)} = b_0^{(-j)} + b_1^{(-j)}X_j \quad (19.19)$
```

where $\hat{Y}_i^{(-j)}$ is the predicted of $Y$ from $X$, using the regression equation in which the $Y$ intercept and slope, $b_0^{(-j)}$ and $b_1^{(-j)}$, are obtained from the $N-1$ cases that remain when the data point $(X, Y)$ is not included (i.e., it is "deleted" from the analysis).

The deleted residual for the $j$th case, $e_j^{(-j)}$, is defined as the difference between $Y_j$ and its deleted prediction,

```
$e_j^{(-j)} = Y_j - \hat{Y}_j^{(-j)} = \frac{e_j}{1-b_{jj}} \quad (19.20)$
```

The ratio of the deleted residual to its standard error is called the externally Studentized residual, and can be expressed as

```
$t_j^{(-j)} = \frac{e_j^{(-j)}}{SE(e_j^{(-j)})} = \frac{e_j}{s_{Y,X}\sqrt{1-b_{jj}}} \quad (19.21)$
```

where the deleted standard error of estimate

```
$s_{Y,X}^2 = \frac{\sum_{i \neq j}(Y_i - \hat{Y}_i^{(-j)})^2}{N-3} \quad (19.22)$
```

is based on $N-1$ data points that remain after case $j$ has been deleted.

We recommend using of externally Studentized residuals to identify outlying residuals because they can be tested by the $t$ statistic defined in Equation 19.21. However, as usual, when a large number of significance tests are performed, Type 1 error rate should be controlled.
