*Locating Outlying Values of the Predictor.* The measures considered to this point are concerned with the extent to which $Y$ differs from its predicted value. We might also be interested in the extent to which $X$ differs from the mean of the $X$ scores. Some practical cases provide the *Mahalanobis distance*, which for bivariate regression is a squared z score,

```
$D_j = \sqrt{\frac{(X_j-ar{X})^2(N-1)(X_j-ar{X})^2}{SS_X}} \quad (19.23)$
```

Another measure for identifying outliers in the $X$ distribution that is commonly available in the regression output is the *leverage* that we discussed earlier:

```
$h_j = \frac{1}{N} + \frac{(X_j-ar{X})^2}{SS_X}$
```
