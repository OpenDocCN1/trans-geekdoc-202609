If the linear model is appropriate, the conditional Y means (i.e., the means of the TC values for different ages) all fall on a straight line. In this case, the variability about the line is the same as the variability about the means, so $SS_{residual}$ consists only of pure error.

If the linear model is not appropriate, $SS_{residual}$ consists of not only a pure error component that reflects variability around the conditional means, but also a "nonlinearity" component that reflects the extent to which the conditional means are not a perfect linear function of X. The nonlinearity SS obtained by subtracting $SS_{residual}$ has 2 df used in estimating the slope and intercept of the linear equation; equivalently, $(N-2) - (N-a) = a$. The corresponding mean square estimates a quantity that is the sum of $pure error$ and a component that reflects the departure from linearity. Therefore, the linearity assumption may be tested using

$F = \frac{MS_{nonlinearity}}{MS_{pure error}}$ with $a - 2$ and $N - a$ df.

# 19.7.4 Independence

We assume that the error components, $\epsilon_i$ are independent of one another. If they are positively correlated, perhaps because some important variables have been omitted from the model, standard errors calculated by the usual ordinary least-squares procedures may underestimate the true standard errors of the regression coefficients and the confidence intervals, and hypothesis tests based on them will not be appropriate. The residuals cannot be strictly independent because they are all based on the same estimates of $b_0$ and $b_1$. Nonetheless, if $N$ is reasonably large, this unavoidable dependency will be very small so that residuals can meaningfully examined for evidence of lack of independence. This is typically done by examining the pattern of residuals as a function of time observation. The rationale for this is that data is collected and recorded sequentially. If the error components are independent, the residuals should not vary systematically. Systematic variation may reflect changes in participants, measuring devices, or surroundings. When the residuals are plotted against time or case, the result should again look like the top panel of Figure 19.5.

It is possible for error components to exhibit different kinds of serial correlations. For example, the residual correlation to case $i$ may tend to be similar (or dissimilar) to those residuals to case $i-1$ or $i-2$. Several package values of the Durbin-Watson statistic forms the basis for a test of serial correlation in adjacent residuals.
