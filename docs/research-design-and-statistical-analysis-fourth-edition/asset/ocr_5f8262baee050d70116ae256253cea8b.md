We now consider the three types of power calculations:

+   Case 1 – power for tests that all regression coefficients are equal to zero in the population. The test that all regression coefficients zero is equivalent to the test that the population squared multiple correlation, p², equals zero. For case 1, p = k, so N* = N, the required sample size, whether we have fixed or random-effects predictors.

As an example, suppose we want to estimate the size required to have power .90 at α = .05 for the test of the hypothesis that all population regression coefficients are zero. If R² = .20 when we regress the criterion variable over four predictors, the effect size is

```
f² = \frac{\Delta R^2}{1 - R^2} = \frac{R^2}{1 - R^2} = .25
```

In G*Power 3.1, select

+   1. F tests as the Test family.
2. Linear Multiple Regression: Fixed model, R deviation from zero as the Statistical test, and
3. A priori: Compute required sample size – given α, power, and effect size as the Type of power analysis.

Then insert the values f² = .25, Power = .90, α = .05, and Number of predictors = 4 and click on Calculate. G*Power 3.1 indicates that the required sample size is 67.

+   Case 2 – power calculations for the test that a particular coefficient is zero in the population. Here k = 1, so for random predictors N* = N - p + 1, so that N = N* + p - 1. As an example, we plan to test whether adding a predictor to a regression equation that already contains three predictors significantly improve the predictability of the dependent variable. This is the same as the significance of the coefficient of the predictor in a regression that contains all four predictors. Suppose that we want to find the N required to have power .80 if R² with predictors is .25 and we find the fourth predictor to increase R² to .30, so that f² = .05/(1 - .30) = .071. In G*Power 3.1 (see Figure 21.9)

+   1. F tests as the Test family,
2. Multiple Regression: Linear Multiple Regression: Fixed model, R² increase as the Statistical test, and
3. A priori: Compute required sample size given α, power, and effect size as the Type of power analysis.

Then, insert f² = .071, α = .05, Power = .80, Number of tested predictors = 1, and Total number of predictors = 4. If we click on Calculate, we find N* = 113. If the predictors are fixed, N = 113. If they are random, N = 113 + p - 1 = 116.
