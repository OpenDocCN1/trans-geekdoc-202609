# 14.5.2 Mixed Design With Two Random-Effects Factors

The $S \times A \times B$ example can undergo further complications. We might have several groups of participants, quizás differing in reading ability or grade level. In general we consider of an experiment with a between-participants variance, $A$, having fixed effects (e.g., grade level); a within-participants variance, $B$, also having fixed effects (e.g., font); and a within-participants variance, $C$, having random effects (e.g., words). All combinations of the factors appear in the design. To summarize the design under: there are $a$ groups of $n$ participants and all participants are tested on the same $c$ items at each of $b$ levels of a fixed-effects factor, $B$. We presented this design in Table 14.9 under the assumption that all three factors $-A$, $B$, and $C$ had fixed effects. Table 14.11 reproduces much of Table 14.9; the difference is that $C$ is now assumed to have random effects, the EMS now include additional terms. Those added terms are underlined in Table 14.11.

Table 14.11 Expected squares for a mixed design where C is assumed to have random effects; A and B have fixed effects

| SV | df | EMS* |
|---|---|---|
| A | $a - 1$ | $\sigma^2 + bs\sigma^2_{CS/A} + bc\sigma^2_{S/A} + bn\sigma^2_{AC} + ncl\sigma^2_{ABC}$ |
| S/A | $a(n - 1)$ | $\sigma^2 + \sigma^2_{CS/A} + bc\sigma^2_{S/A}$ |
| B | $b - 1$ | $\sigma^2 + co\sigma^2_{BS/A} + na\sigma^2_{BC} + ncl\sigma^2_{BGS/A}$$ |
| AB | $(a - 1)(b - 1)$ | $\sigma^2 + C\sigma^2_{BS/A} + an\sigma^2_{ABC} + ab\sigma^2_{BGS/A} + acl\sigma^2_{AB}$ |
| BXS/A | $a(n - 1)(b - 1)$ | $\sigma^2 + \sigma^2_{BGS/A} + cb\sigma^2_{BC/A}$ |
| C | $c - 1$ | $\sigma^2 + \sigma^2_{CS/A} + nab\sigma^2_{AC}$ |
| AC | $(a - 1)(c - 1)$ | $\sigma^2 + \sigma^2_{BC/A} + nb\sigma^2_{AC}$ |
| CxS/A | $a(n - 1)(c - 1)$ | |
| BC | $(b - 1)(c - 1)$ | $\sigma^2 + \sigma^2_{BC/A} + na\sigma^2_{BC}$ |
| ABC | $(a - 1)(b - 1)(c - 1)$ | $\sigma^2 + \sigma^2_{BC/A} + nab\sigma^2_{ABC}$ |
