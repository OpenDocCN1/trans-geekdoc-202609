# 21.4.4 Partial F Tests: Procedures for Testing a Subset of the $\beta s$

We can use partial F tests to determine whether adding one or more predictors to a regression equation already contains $p$ predictors significantly increases the predictability of $Y$. If we consider just one predictor, $X_{p+1}$, the test of the model

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_pX_p + \beta_{p+1}X_{p+1} + \varepsilon$
```

against the restricted model

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_pX_p + \varepsilon$
```

is equivalent to testing the hypothesis $H_0: \beta_{p+1} = 0$. This approach provides a basis for comparing any models where the restricted model includes a subset of the predictors in the full model.

We can represent the variability in $Y$ accounted for by regression on the variables of the restricted model

```
$SS_{Y12..p} = RY_{Y12..p}SS_{SY}$
```
