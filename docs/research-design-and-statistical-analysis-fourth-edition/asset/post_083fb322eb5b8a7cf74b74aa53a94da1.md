## 4.4.2 One- and Two-Tailed Tests

The test we just discussed is an example of a one-tailed or directional test. Because we were interested in whether performance was better than change, the rejection region consists of only the largest possible values of Y (the upper tail of the binomial distribution). Not all hypothesis tests are directional. There are many situations in which a departure from the null hypothesis in either direction would be of interest. For example, in the case of Roy's data on arithmetic skills (see Chapter 2), we might wish to know whether there is a significant difference in performance for addition or subtraction; if there were, it might influence the way in which these skills were taught. To test for a difference, we could assign a plus to each student who had a higher addition score and a minus to each student who had a higher subtraction score. Then we could ask whether the probability of a plus (or a minus) was significantly different from .5. A result either (i.e., addition better than subtraction or subtraction than addition) would be of interest. As another example, University of Massachusetts Medical School researchers collected data on seasonal variation in clinical states as depression and anxiety. Comparing depression scores in winter and summer, we might assign a plus if the winter score was higher, and a minus if it was lower. In both of these examples, $H_0$ would be

$H_0 : \pi = .5$

The alternative hypothesis would be

$H_1 : \pi \neq .5$

In this case, $H_0$ is nondirectional; so that we reject $H_0$ if we find evidence that $\pi$ is greater than or less than .5. We may want $\alpha$ to be .05, but then the rejection region is split in half—in the upper tail and half in the lower tail of the distribution. Turning to the column labeled $\pi=.50$, assuming equal weight is given to both directions, and that $\alpha$ is to be close to .05, $H_0$ would be rejected if $Y \leq 5$ or $Y \geq 15$. This is usually referred to as a two-tailed or nondirectional test. Note that if we use these rejection, the actual probability of a Type 1 error is .021+.021=.042. If we found Y=16, we would reject $H_0$ because the statistic falls in the rejection region. Using Table 4.2, we find $p(Y\geq16|\pi=.50)=.0040+.0011+.0020+0=.0059$. But because $H_1$ is nondirectional, we must also consider equally extreme results in the lower tail of the distribution, so that the $p$-value is equal to $p(Y\geq16|\pi=.50) + p(Y\leq4|\pi=.50) = 2 \times 0.0059 = 0.0118$. The procedure we have just outlined (using the binomial distribution to test the hypothesis $H_0: \pi = .50$) is called the sign test.

## Developing the Fundamentals of Hypothesis Testing

### 4.4.3 Using Software to identify Rejection Regions

We can use software to identify the rejection region or regions under the null hypothesis. Doing so has several advantages, including the speed of the calculations, as well as a much larger range of possible parameters (Y, n, π) than are summarized in Table C.1. In R, the qbinom function in the [stats] package computes critical values of the binomial distribution. The input parameters are the size of the sample (n), the probability of success (π), and a value related to α. By default, the return function returns values for the lower tail of the distribution. We consider three cases:

- 1. Directional hypothesis with lower critical value (e.g., H$_0; $\pi < .5$). In this case, qbinom provides the critical value directly. For example, if n = 8 and $\alpha = .05$, qbinom(.05, size = 8, prob = .5) returns the 2. This means we can reject $H_0$ when $Y < 2$, or equivalently, when $Y \leq 1$.
- 2. Directional hypothesis with upper tail critical value (e.g., H$_0; $\pi > .5$). Here, we use the option lower.tail = FALSE to compute upper-tail probabilities: qbinom(.05, size = 8, prob = .5, lower.tail = FALSE) returns 6, meaning we can reject the null when $Y > 6$, or equivalently, when $Y \geq 7$.
- 3. Two-sided alternative hypothesis (e.g., H$_0; $\pi \neq .5$). In this case, we divide half of the probability in each tail. We then apply qbinom, once for the lower and once for the upper rejection region, following the same guidance as directional tests. For example, with n = 8 and $\alpha = .05$, we use $\alpha/2$ to identify the lower critical value: qbinom(.025, size = 8, prob = .5) = 1, meaning we can reject when $Y < 1$, or equivalently, when $Y = 0$. For the upper critical value, qbinom(.025, size = 8, prob = .5, lower.tail = FALSE) = 7, meaning that we can reject the null when $Y > 7$ or equivalently, when $Y = 8$.

## 4.5 The Power of a Test

### 4.5.1 Errors in Decision Making

In deciding to reject or not reject a null hypothesis, we can make two types of errors. If the null hypothesis is true, rejecting it is a false positive we call Type 1 error. As we have just discussed, the probability of such an error is $\alpha$, the significance level. This means that the Type 1 error rate is under the control of the researcher. If the null hypothesis is false, we can make another kind of error by failing to reject it; this is a false negative. Failure to reject a null hypothesis when it is false is called Type 2 error, and its probability, $p(\text{fail } H_0 | H_1)$, is referred to as $\beta$ (Greek letter beta). The complementary probability, that is, $p(\text{reject } H_0 | H_1)$, is called the power of the test. When $H_1$ is false, only two decisions are possible: fail to reject (with probability $\beta$) or reject it (with probability $1 - \beta$). Therefore, power = $1 - \beta$. The following table may help to clarify the meanings of $\alpha$, $\beta$, and power:

| Decision in the Population | Reject $H_0$ | Fail to reject $H_0$ |
| :--- | :--- | :--- |
| $H_0$ True | $\alpha$ = Type 1 error rate | $1 - \alpha$ |
| $H_1$ False | power = $1 - \beta$ | $\beta$ = Type 2 error rate |

### 4.5.2 Computing Power

Power is a conditional probability: it is the probability of rejecting the null hypothesis given the null hypothesis is false. The first step in computing power is to determine the conditions under which the null hypothesis will be rejected (see Box 4.2). Once the rejection region for $H_0$ is found, we must compute the probability of observing a result in the rejection region assuming $H_a$ and that some alternative hypothesis, $H_A$, is correct. It is important to be clear about the distinction between $H_a$ and $H_A$; the class of alternative hypotheses determines where the rejection region is placed (right, left, or tails). In contrast, $H_a$ is a specific alternative hypothesis; power is calculated for the test of $H_0$ assuming $H_A$ to be true. Course, the true value of the population parameter is never known. However, if some value of the parameter is assumed, the power of the test against alternative can be calculated.

Let's illustrate the calculation of power for our ESP experiment. Suppose we wish to test $H_0: \pi = .25$ against the alternative hypothesis $H_a: \pi > .25$. Further, let's assume that Rachel has weak ESP abilities; specifically, we will assume that her abilities permit her to correctly identify a card 35% of the time. In this example, this is our specific alternative hypothesis,

$H_a: \pi = .35$

The $H_0$ and $H_A$ specify different sampling distributions for our experiment, as illustrated in Figure 4.4. Our example assumes that $H_1$ correctly describes the probabilities of different outcomes for the experiment; the extensive overlap between the two distributions means that the two hypotheses will not be able to discriminate. Thus, we can expect that power will be low.

The general steps in computing power are all the statistical tests. These steps are summarized in Box 4.3. Applying this to our example:

- 1. Calculate the theoretical distribution of Y assuming $H_0$ to be true. In this example, the distribution is presented in the .25 column of Table 4.2.
- 2. Determine the rejection region. In this example ($n = 20, \alpha = .05; H_a: \pi > .25$), the region is $Y \ge 9$. As we see in Figure 4.4, the outcomes are discrete, we choose the largest possible $\alpha$ that does not exceed 0.05; in this case, $\alpha = .0409$.

- 4. Sum the probabilities for $Y \ge 9$ (the rejection region) in the .35 column. This is the conditional probability $p(Y \ge 9 | H_A = .35)$ and is the power of the test of $H_0$ against $H_A$. In this case, power = .1158 + .0686 + .0336 + .0136 + .0045 + .0012 + .0003 = .2376.
