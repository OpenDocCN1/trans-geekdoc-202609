# Research Design and Statistical Analysis

In general, given a dependent variable Y and a predictor X, we can test for a quadratic component by regressing Y on $X^2$ as well as X, so that the regression equation is

```
$\hat{Y} = b_0 + b_1X + b_2X^2$ (22.2)
```

If the regression coefficient of the squared term is significant, we can then test for the presence of a cubic component by regressing Y on $X^3$, as well as X and $X^2$, yielding the equation

```
$\hat{Y} = b_0 + b_1X + b_2X^2 + b_3X^3$ (22.3)
```

and so on. We cannot test for the presence of a higher-level component without including the lower-level components as well. For example, we cannot test the presence of quadratic component by regressing only on $X^3$, because $X^2$ will usually be highly correlated with X. The regression would reflect linear and quadratic effects, and we might get significance if there was no quadratic component. If we wish to test for the presence of a quadratic component, we must partial out the linear component. If we regress TC on BMI and $BMI^2$ for all women aged 65 or less in the Seasons data set, we find the equation

```
$TC = 79.561 + 8.118BMI - 0.112BMI^2$ (22.4)
```

Both the coefficients of BMI and $BMI^2$ are significant; $b_1 = 8.118, t(187) = 3.060, p = .003$ and $b_2 = -0.112, t(187) = -2.735, p = .001$, respectively.

There is one bound in quadratic function. Because the partial regression coefficient of $BMI$ is negative, the rate of change of TC with BMI is negatively accelerated. As the amount by which TC increases as BMI becomes less as BMI gets larger, and for large values of BMI, TC starts decreasing as BMI increases. Had the coefficient of the quadratic component been positive, this would indicate that the rate of change of TC increases as BMI gets larger.

A significant quadratic coefficient in a regression equation implies that the slope is different at different values of X. For example, assuming a causal relationship between BMI and TC, a doctor might prioritize weight loss as a mean of reducing cholesterol for patients with BMI in a lower range where BMI changes more strongly predict TC changes and might prescribe more medication for patients with higher BMI values. For Equation 22.2, we can show that the slope for any value of X is equal to $b_1 + 2b_2X$. Therefore, the slope of the curve at BMI = 25 is $8.118 + 2(-0.112)(25) = 2.518$, and the slope at BMI = 35 is negative. A much larger influence on the predicted value of TC than changing BMI from 35 to 34. The maximum of the curve is found at $BMI = -b_1/2b_2 = -8.118/2(-0.112) = 36.241$. Substituting this value into the regression equation, we obtain $TC \approx 227$.
