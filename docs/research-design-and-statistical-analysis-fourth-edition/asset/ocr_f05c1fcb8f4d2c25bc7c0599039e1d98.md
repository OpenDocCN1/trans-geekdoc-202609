Using Cohen's Guidelines

If there is no empirical basis for selecting a value of $d$ on which to base power calculations, the researcher may rely on Cohen's guidelines for small, medium, and large effect sizes. Although Cohen's guidelines refer to $d$ rather than $d_s$, there is a relation between $d$, and $d$ that can be exploited to obtain an estimate of $d$ from denominators. Comparing Equations 6.19 and 6.21, we see that $d$ and $d'$ differ in their denominators. The relation between the standard deviation of the treatment populations, $\sigma$, and the standard deviation of the population difference scores is

```
$\sigma_{Y_1-Y_2} = \sqrt{\sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2} \quad (6.25)$
```

where $\rho rho$ is the population correlation between scores in the two conditions. Assuming homogeneous variances, this can be rewritten as

```
$\sigma_{Y_1-Y_2} = \sigma\sqrt{2(1-\rho)} \quad (6.26)$
```

Substituting Equation 6.26 into Equation 6.21 and solving for $d_s$,

```
$d_s = \frac{\mu_1 - \mu_2}{\sqrt{2(1-\rho)}} = d / \sqrt{2(1-\rho)}} \quad (6.27)$
```

As an example of work from a value of $d$, suppose that we conducted an experiment with an independent-groups design. Despite a reasonable effect size of $.5$, the experiment failed to produce a significant effect. To try again, but we choose a correlated-scores design for the follow-up. We wish to compute the $n$ for $.8$ assuming the same effect size found in the first experiment. We need to translate our $d$-value of $.5$ to a value of $d_s$. We need to assume a value of $\rho$ to the conversion. In the absence of any information, we will assume a relatively low correlation of $.3$. Substituting in Equation 6.25, we compute $d=.42$. Using G*Power 3.1 for $d_s=.42, \alpha=.05, \rho=.8$, and a one-tailed test, we calculate that $n$ should be 37.

Cohen's guidelines for small, medium, and large values of $d$ have been widely adopted, so it may be useful to translate these scores into values of $d$.
