# Notes

+   1 The term "dummy variables" is used to refer to the variables that code a categorical variable by any of the coding procedures. The term "dummy coding" is used to refer to a specific kind of coding in which each dummy variable takes the values 0 and 1 as described in the text.
2 This example points out that the use of overlapping circles to represent overlapping variabilities, as in Figure 23.6, is of limited utility.
