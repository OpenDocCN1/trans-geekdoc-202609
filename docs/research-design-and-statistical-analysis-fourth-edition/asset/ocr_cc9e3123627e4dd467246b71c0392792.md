# 23.2 Effect and Dummy Coding

Although the variables X1 and X2 in our example appropriately partition the variability in Y into components with A and S/A, the coefficients associated with X1 and X2 are not particularly meaningful. Two more common approaches to coding categorical variables, effect coding and dummy coding, produce more interpretable regression coefficients. Both methods allow us to specify group membership so that a regression of the dependent variable on the dummy variables will produce an analysis identical to the ANOVA. The only difference between them is that the regression coefficients produced by the two coding systems have different interpretations.
