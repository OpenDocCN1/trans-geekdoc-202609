# 23.2 Effect and Dummy Coding

Although the variables X1 and X2 in our example appropriately partition the variability in Y into components with A and S/A, the coefficients associated with X1 and X2 are not particularly meaningful. Two more common approaches to coding categorical variables, effect coding and dummy coding, produce more interpretable regression coefficients. Both methods allow us to specify group membership so that a regression of the dependent variable on the dummy variables will produce an analysis identical to the ANOVA. The only difference between them is that the regression coefficients produced by the two coding systems have different interpretations.

# Effect Coding

In discussing ANOVA as a special case of multiple regression, we may find it useful to consider the type of dummy variable coding called effect coding because, as we show next,

Effect coding represents group membership with dummy variables that contain 1s, 0s, and -1s, as illustrated by $X_{E1}$ and $X_{E2}$ in Panel $b$ of Table 23.1. Dummy variables for effect coding are defined as:

- $X_{Ej} = 1$ for scores at level $A_j$
- $-1$ for scores at some arbitrary level of $A$
- $0$ otherwise

Because there are three levels of A in Table 23.1, we require two dummy variables to account for all between-group variability. The coding of $X_{E1}$ and $X_{E2}$ is presented in Panel $b$ of Table 23.1. As can also be seen, the regression of $Y$ on $X_{E1}$ and $X_{E2}$ produces a value of $SS_{regression}$ that is equal to the $SS_A$ obtained from the standard ANOVA, and an overall $F$ statistic for the regression that is equal to the ANOVA $F$.

The statistics for regression of $Y$ on $X_1$ and $X_2$ on $X_{E1}$ and $X_{E2}$ or $R = .740$; $SS_{regression} = 28.583$; $MS_{regression} = 5.435$. The regression coefficients based on effect coding are

$b_{01} = 4.94 - \tilde{Y}_1 - \tilde{Y}_2 = 2.06$; $b_{02} = \tilde{Y}_3 - \tilde{Y}_1 = -1.64$;

And the regression coefficients based on dummy coding are

b_{01} = 4.50, \tilde{Y}_1 - \tilde{Y}_2 = 2.50$; $b_{02} = \tilde{Y}_3 - \tilde{Y}_2 = -1.17$.

We have stated that the regression coefficients resulting from effect coding correspond to the effects estimated in ANOVA. We can readily demonstrate this correspondence, first noting that the scores predicted by the regression equation for each of the groups beats the group mean. For $A_1$, we have $\hat{Y} = \tilde{Y}_1$, $X_{E1} = 1$, and $X_{E2} = 0$. Substituting into the regression equation that predicts $Y$ from $X_{E1}$ and $X_{E2}$ we obtain

$\tilde{Y}_1 = b_{E0} + b_{E1}(1) + b_{E2}(0) = b_{E0} + b_{E1} \quad (23.1)$

Similarly, for $A_j$ and $A_{j'}$, respectively, we have

$\tilde{Y}_2 = b_{E0} + b_{E1}(0) + b_{E2}(1) = b_{E0} + b_{E2} \quad (23.2)$

and

$\tilde{Y}_3 = b_{E0} + b_{E1}(-1) + b_{E2}(-1) = b_{E0} - b_{E1} - b_{E2} \quad (23.3)$

Adding Equations 23.1-23.3, we obtain $3b_{E0} = \tilde{Y}_1 + \tilde{Y}_2 + \tilde{Y}_3$, so that

$b_{E0} = \frac{\tilde{Y}_1 + \tilde{Y}_2 + \tilde{Y}_3}{3} = \tilde{Y}_U$

Here, $\tilde{Y}_U$ is the weighted average of the group means. If there are equal numbers of scores in each of the groups, $\tilde{Y}_U$ will equal $\tilde{Y}_j$, the grand mean of all scores. We can now write the coefficients of the dummy variables as deviations from the unweighted mean of the group means. Substituting $b_{E0} = \tilde{Y}_U$ into Equations 23.1 and 23.2, and solving, we obtain formulas and numerical results for $b_{E1}$ and $b_{E2}$ that are presented in Panel $b$ of Table 23.1. For equal designs, the regression coefficients correspond exactly to the estimated components of the ANOVA, $\alpha_j$. That is, because $\tilde{Y}_j = \mu_j$, and $\tilde{Y}_U = \mu$,

$b_{E1} = \tilde{Y}_1 - \tilde{Y}_U = \mu_1 - \mu = \alpha_1$

and

$b_{E2} = \tilde{Y}_2 - \tilde{Y}_U = \mu_2 - \mu = \alpha_2$

Furthermore, because of the requirement $\sum \alpha_j = 0$, $\alpha_3$ can be found as

$\alpha_3 = -\alpha_1 - \alpha_2 = -b_{E1} - b_{E2}$

# Dummy Coding

A second way to code variables is to use dummy coding, for which the dummy variables take on the values 0 and 1, as illustrated by $X_{D1}$ and $X_{D2}$ in Panel $b$ of Table 23.1. For dummy coding, the dummy variables are defined as

$X_{Dj} = 1$ for scores at level $A_j$
- 0 otherwise

Note that we only need $a-1$ dummy variables to code groups; one group, referred to as the reference group, will receive 0 on all the dummy variables. Because there are three levels of A in the current example, we require two dummy variables to account for all between-group variability. Scores at $A_1$ receive 1 on $X_{D1}$ and 0 on $X_{D2}$; scores at $A_2$ receive 0 on $X_{D1}$ and 1 on $X_{D2}$; scores at $A_3$ receive values of 0 on both $X_{D1}$ and $X_{D2}$. As we see in panel $b$ of Table 23.1, the regression of $Y$ on $X_{D1}$ and $X_{D2}$ also produces a $SS_{regression}$ equal to the $SS_A$ obtained the standard ANOVA. Although the variance accounted by the regression is the same whether we use dummy or effect coding, the regression coefficients are different. If we use dummy coding, the intercept, $b_{D0}$, takes on the value of the mean of the reference group (the group that has 0 on all indicator variables). For example, in Table 23.1, the value of the intercept is equal to the mean of $A_1$. The regression coefficients for each of the dummy variables, $b_{D1}$ and $b_{D2}$, take on values equal to the differences between the group coded as 1 on the dummy variable and the mean of the reference group. We can see this by noting that because the regression accounts for all the between-group variability, the prediction for each score will be its mean.

For the scores at $A_1$, each dummy variable has the value 0 so that

$\tilde{Y}_3 = b_{D0} + b_{D1}(0) + b_{D2}(0) = b_{D0}$

Therefore, $b_{D0} = \tilde{Y}_3$. For scores at $A_1$, we have $\hat{Y} = \tilde{Y}_1$. Substituting $X_{D1} = 1$, and $X_{D2} = 0$ into the equation for the regression of $Y$ on $X_{1}$ and $X_{D2}$ we obtain

$\hat{Y}_1 = b_{D0} + b_{D1}(1) + b_{D2}(0) = b_{D0} + b_{D1}$

Therefore, $b_{D1} = \hat{Y}_1 - b_{D0} = \tilde{Y}_1 - \tilde{Y}_3$. Similarly, for scores at $A_2$ we have

$\hat{Y}_2 = b_{D0} + b_{D1}(0) + b_{D2}(1) = b_{D0} + b_{D2}$

so that $b_{D2} = \hat{Y}_2 - b_{D0} = \tilde{Y}_2 - \tilde{Y}_3$.

Dummy coding might be particularly useful if the design contains a control group. If so, we let the control group serve as the reference group, and the regression coefficients would then equal the differences between the treatment and control means. There are many other possible ways to code categorical variables. For example, categorical variables may be coded such that regression coefficients take on values of contrasts of possible interest. Detailed discussions of these methods may be found in sources such as Cohen et al. (2003).

No matter coding procedure is used to code a factor A, when the dependent variable $Y$ is regressed on the $a - 1$ dummy variables,

$SS_{between} = R_{Y,A}^2 SS_Y$

where $R_{Y,A}^2$ is the square of the multiple correlation when $Y$ is regressed on the $a - 1$ dummy variables that code factor A, and

$SS_{within} = SS_{S/A} = (1 - R_{Y,A}^2) SS_Y$

so that the test statistic for $A$ is given by

$F = \frac{R_{Y,A}^2 SS_Y / (a - 1)}{(1 - R_{Y,A}^2) SS_Y / (N - a)}$
