## 23.6 Summary

The two goals we have in this chapter were to discuss how categorical variables can be coded so that they can be incorporated into the multiple regression framework and to recover, within this framework, several of the ANOAs that we had discussed earlier. We did not include this goal to encourage our readers to perform ANOAs by coding categorical variables in terms of dummy variables and using multiple regression – although they could do so if the standard ANOVA programs were available. Rather, we believe that considering ANOAs from the multiple regression perspective allows us to gain a deeper understanding of these analyses.

The generality and flexibility of the multiple regression framework offer some clear advantages. The standard ANOVA approach breaks down for disproportionate-n designs. Thinking in terms of multiple regression – a system in which nonorthogonality is the rule rather than the exception – facilitates consideration of the kinds of adjustments that might be made. To provide appropriate analyses of nonorthogonal designs, the standard “ANOVA” programs are really multiple regression programs. We hope that this chapter provides some understanding of how these programs work and what options they offer. Finally, the ability to include categorical and continuous variables in the same analysis not only is not necessary – indeed, it is wrong – to transform inherently continuous variables into categorical ones (by, for example, using median splits) in order to analyze the data (see, for example, Fitzsimons, 2008).

# ANCOVA as a Special Case of Multiple Regression

## 24.1 Overview

In Chapter 12, we briefly introduced analysis of covariance (ANCOVA) as one of several procedures that used information about a covariate (sometimes called a concomitant variable) to account for some of the error variance, thereby increasing the power of statistical tests on the factors. Because ANCOVA is a procedure for analyzing data for a design that involves both categorical and quantitative variables, it is more naturally discussed as a type of regression rather than terms of ANOVA. Therefore, we return to ANCOVA in this chapter to develop it more fully. Our goals are the following:

## 24.2 The ANCOVA Model

Treatments of ANCOVA from an analysis of variance perspective are notoriously opaque, primarily because regression is used to reduce variability in the dependent variable predictable from the covariate. In Chapter 23, we showed that we can use dummy variables to code a categorical variable (say, factor A) and then use regression to perform an ANOVA. The ANOVA can be thought of as a comparison between two models, a full model that contains information about group membership

$$Y_{ij} = \mu + \alpha_j + \varepsilon_{ij}(ANCOVA)$$

and a restricted model that does not,

$$Y_{ij} = \mu + \varepsilon_{ij}$$
