The A, C, and AC sources of variance can be coded as S/A in a factorial between-participants design, separately at each level of A, as indicated in Table 23.7. It is not really necessary to code SC/A because SSSC/A can be obtained as a residual

```
SS_{SC/A} = SS_{Y/A}(1 - R^2_{Y,A,S/A,AC,C,AC})
```
