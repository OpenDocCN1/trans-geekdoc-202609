# Using ANCOVA

ANCOVA is straightforward to run using software. In SPSS, use the General Linear Model option in the Analyze pull-down menu, select Univariate. For the example data in Table 24.2, move Y to the dependent variable, text to the Fixed Factor(s) box, and X to the Covariate(s) box. If you want to test the homogeneity of slopes, click on the Model button and create main effects for X and text, as well as their interaction. Then Click OK. If you do not build a model, SPSS will test only the main effects of X and text.

In R, be sure that the treatment effect (text) is a factor (as necessary). The lm function we are familiar with from previous chapters will perform the ANCOVA if you include the covariate in the model: lm(data = dat, Y ~ text + X). Store the result in ancova.out (or whatever name you prefer), and use that as input to Anova with Type III sums of squares: Anova(ancova.out, type = 3). To test the homogeneity of slopes, you must tell R that text and X may interact: Anova(lm(data = dat, Y ~ text * X), type = 3).

# 24.3 Adjusting the Group Means in Y for Differences in X and Testing Contrasts

In the previous section, we showed how $SS_A$ and $SS_{s/A}$ could be adjusted for differences in the covariate. Similarly, in certain situations, it is both possible and desirable to adjust the group means for differences. To do this, we predict what the group means for Y would be if the value of the covariate was held constant. We define the *adjusted mean* of scores for group $j$, $\tilde{Y}_{j(adj)}$, as the score predicted in group $j$, using the within-group regression equation with common slope $b_{s/A}$ if the value of the covariate is equal to the grand mean of the covariate; that is, if $X_{ij} = \bar{X}$.

Because of bivariate regression of Y on X,

```
hat{Y} = \bar{Y} + b_1(X - \bar{X})
```

the regression equation for scores in group $j$ is

```
hat{Y}_{ij} = \bar{Y}_j + b_1(X_{ij} - \bar{X})
```

Substituting $b_{s/A}$ for $b_1$ and $X$ for $X_{ij}$, we have

```
tilde{Y}_{ij(adj)} = \bar{Y}_j + b_{s/A}(X_{ij} - \bar{X}_j)
```

or

```
tilde{Y}_{ij(adj)} = \bar{Y}_j - b_{s/A}(X_{ij} - \bar{X}_j)
```

The adjusted group means for the S, LE, and HE conditions introduced in Section 24.2 are

```
tilde{Y}_{1(adj)} = .369 - (.0072)(59.188 - 62.355) = .419
```

```
tilde{Y}_{2(adj)} = .406 - (.0072)(65.938 - 62.355) = .380
```

and

```
tilde{Y}_{3(adj)} = .531 - (.0072)(61.938 - 62.355) = .534
```

These adjusted group means are the means predicted for each group for a covariate value equal to the grand mean on the covariate (i.e., 62.355 in this data set).

If the assumptions for ANCOVA are met, we can test contrasts based on the adjusted means generally be more powerful than those using unadjusted means. Suppose working within the ANOVA framework, we wished to test the null hypothesis

```
H_0 : \psi = \frac{\mu_{HE} + \mu_{LE}}{2} = 0
```

Using the procedures in Chapter 10, we would use the test statistic

```
t = \frac{\hat{\psi}}{\hat{s}_{\psi}} = \frac{\frac{\bar{Y}_S + \bar{Y}_L}{2}-\frac{.396+.406}{2}}{\sqrt{MS_{S/A}\Sigma^2/n_j}(.031)(1 / 16)}} = .130 / .054 = 2.411 with 45 df
```

and could reject the null hypothesis at $p = .019$.

An alternative approach to testing the contrast is to base it on the adjusted means (Huitema, 1980). The procedure is essentially the same as that for the unadjusted means, except that the comparison is among adjusted means and the error term contains corrections for the covariate. For a completely randomized design, the recommended test statistic is

```
\hat{\Psi}_{\psi(adj)} = \frac{\hat{Y}_{HE(adj)} + \hat{Y}_{LE(adj)}}{2}
\hat{S}_{\psi(adj)} = \sqrt{\frac{\sum w_i^2}{n_j} (1 + \frac{MS_{S(A)}}{MS_{S/X))}}
```

where $MS_{S(A)}$ and $SS_{S/X)}$ are the between-participant mean square and within-participant sum of squares when an ANOVA is with the covariate as the dependent variable and A as the treatment factor. Substituting into the equation, we have

```
\hat{t}_{\psi(adj)} = \frac{.534 - .419/2}{\sqrt{(.020)(1.5/16)}} = .135 / .044 = 3.089 with 44 df
```

We can reject the null hypothesis at $p = .003$. We observed a larger value of the test statistic using the adjusted means, although we lost one error degree of freedom. In this example, the numerator of the $t$ ratio is slightly larger for the adjusted means than for unadjusted means. However, the main source of the difference in the $t$ values is attributable to the smaller error term after adjusting for the covariate (.044) than before the adjustment (.054).

The implication for performing analysis is that researchers must select the error term that is appropriate to their research design. For a good discussion of these issues, see Huitema (1980).
