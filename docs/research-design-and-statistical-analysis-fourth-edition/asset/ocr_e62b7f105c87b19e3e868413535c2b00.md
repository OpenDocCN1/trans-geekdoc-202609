However, plots like the one in Figure 9.3 are misleading with respect to the three-factor interaction. The following of means should help convey this point.

| | $C_1$ | $C_2$ |
|---|---|---|
| $B_1$ | 22 | 34 |
| $B_2$ | 11 | 23 |
| $A_1$ | 20 | 23 |
| $A_2$ | 14 | 17 |

Panel (a) of Figure 9.4 presents a plot of the eight cells under consideration. If there were populations, would you think that there is a cross in the $C_3$ second-order interaction? The pattern of means looks different at $C_1$ than $C_2$. The lines cross in the $C_3$ panel, but not in the $C_2$ panel. As a result, students usually believe that an ABC interaction is present. In fact, if we calculate the contrast interaction, we find it is exactly zero, so there is no ABC interaction. For example, calculating the AB contrast at each level of $C$, and subtracting,

```
$I_{ABC} = I_{AB/C_1} - I_{AB/C_2} = [[22 - 11] - (20 - 14)] = [[34 - 23] - (23 - 17)] = 0$.
```

Sometimes plotting the data in ways is helpful. In Panel (b) of Figure 9.4, the data from Panel (a) have been reotted. Several panels are now clearer than in Panel (a). It should be evident that there is no BC interaction, something that was not all clear in Panel (a). It also appears that there is an AB interaction because because the difference between the $B_1$ and $B_2$ lines are greater in the $A_1$ panel, than in the $A_2$ panel. Finally, it appears that there is no second-order interaction because the BC interaction is zero in both panels. Of course, these are idealized points, lacking the variability present in real data. However, the point still stands that it is often helpful to plot data in several ways. Different patterns may become evident, making clearer which certain effects in the ANOVA were significant others were not.

The example of Panel (a) of Figure 9.4 demonstrates that the pattern of means can be deceptive. If the lines in an AB plot are approximately parallel (i.e., there is no AB interaction) at one or more levels of $C$, but there is an interaction at at least one level of $C$, an ABC interaction is indicated. Also, if the lines in one panel converge whereas in other panels diverge, an AB interaction is indicated. If the two AB plots are the same (or shifted by a constant amount), for one point, there is reason to expect a three-factor interaction. Plotting the data several ways could reveal these patterns.

# 9.4.4 Using Software for Higher-Order Between-Participants
ANOVA With Equal in I

For three-factor between-participants ANOVA, SPSS works exactly as for two-factor ANOVAs (see Section 9.3.6). The only difference is that more factors are included in the "fixed effects" box. In R, the analysis command is also modified only to reflect the additional factor: Rather than the DV ~ A*B for the two-factor design, the three-factor design is DF ~ A*B*C.
