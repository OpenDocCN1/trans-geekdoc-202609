Fisher's protected t procedure applied to ANOVA is as follows. First test for the significance of a categorical independent variable with $a$ levels using $\alpha$ as the significance level. If the overall test is significant, then each of $(a-1)/2$ pairwise comparisons between the levels of the variable may be tested at significance level $\alpha$. Tests of the individuals are said to be “protected” by the overall test. If the overall test is not significant, we are not allowed to perform significance tests on any of the pairwise comparisons in the set (unless, presumably, specified them $a\ priori$). As applied to multiple regression, a significant $R^2$ or increment in $R^2$ for a meaningful set of predictors would allow us to look at the significance tests for each of the regression coefficients in the set the same level of significance. If the overall test for the set of predictors is not significant, we cannot consider the tests for the individual predictors in the set, no matter how large their $t$ statistics might be. This means that the researcher must resist the temptation to rely on the regression output provided by software, which routinely includes a value of $t$ for each of the predictor variables. Instead, those individual test results must be reviewed only after a statistically significant family-wise assessment.

The hierarchical strategy inherent in defining predictor variables has limitations. Most obviously, if no related sets of predictors are included in the regression analysis, then no families of predictors can be identified. Additionally, the Fisher protected test does not completely control Type 1 error in ANOVA when the independent variable has more than three levels (Hayter, 1986), and Cohen et al. (2003) acknowledge some problems with this procedure. Nevertheless, the modified Fisher procedure acknowledges the issue of inflation of Type 1 error in multiple regression and offers an easily applied, imperfect, control for it.

## 21.6 Inferences About the Predictions of Y

In some situations, the goal of a regression analysis is to make predictions. For example, a university admissions office might want to know the expected year GPA for all students entering the university with a high school GPA of 3.0. In this case, we would want to get a confidence interval on the predicted mean university GPA for all students with a high school GPA of 3.0. Alternatively, an individual student with a high school GPA of 3.0 might want to estimate her first year GPA.

In bivariate regression, the expected value of Y corresponding to a value $X$, of $X$ is given by $\mu_{Y,X} = \beta_0 + \beta_1X_i$, which can be estimated by $\hat{Y}_i = \hat{\mu}_{Y,X_i} = b_0 + b_1X_i$. We showed in Chapter 19 that bivariate regression, the estimated standard error associated with the prediction of $Y$ at $X=X$, is given

$$SE(\hat{\mu}_{Y,X}) = s_e\sqrt{b_{jj}}$$

and that the standard error with an individual score is

$$SE(\hat{Y}_i) = s_e\sqrt{1+b_{jj}}$$

where $s_s$ is the standard error of estimate and $h_{ij}$ the leverage of $X_n$, is

$$h_{ij} = \frac{1}{N} \frac{(X_i - \bar{X})^2}{SS_X}$$

In multiple regression, we can find the estimated standard error for the prediction of Y associated with any combination of the $p$ predictor variables in the regression equation. There is more than one predictor, the standard errors are most easily presented as matrix expressions. Although the expression for $h_j$ will be more complicated because there is more than one predictor, it can be thought of and used in the same way as in bivariate regression. If we want to find confidence intervals for the conditional means or individual scores representing combinations of predictor values in our data set, we do not have to compute the leverage; we can use software to compute the confidence bounds directly or obtain the leverage that we can then use in Equations 21.2 and 21.3.

If we wish to find the standard error for the prediction of Y based on a combination of values of the $p$ predictors, $X_{i1}, X_{i2}, \dots, X_{ip}$ that did not occur in our sample, the estimated standard errors for $\hat{\mu}$ and $\hat{Y}$ are not directly available in the SPSS output but must be calculated. We will not present the relevant matrix expressions or their derivation here.

For example, let's generate a confidence interval for the conditional mean of TC from the regression on age and BMI, assuming a new group of 40-year-old women with BMI of 30. We will use the analysis from Chapter 20 with $N=181$, assuming the output is saved in an object called "twoped". In R, the predict(twoped, newdata,data.frame(age=40, bmi=30), interval="confidence") returns a predicted TC of 205.94 and a CI of [198.21, 213.66], see Figure 21.8. The same command, using the option interval="prediction", returns the prediction interval for an individual 40-year-old woman with BMI of 30, which includes the same predicted TC but a wider interval, [139.18, 272.69], because predictions are more uncertain than predictions for means. We can also predict the cholesterol level of someone whose age and BMI are not included in our observed data, but for a 67-year-old woman with BMI of 45. ## 21.7 Power Calculations in Multiple Regression

There are several kinds of power calculations that can be performed for multiple regression, pairing the various hypotheses that can be tested (see Section 21.4). Here, given the model

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_jX_j + \dots + \beta_pX_p + \epsilon$
```

we consider power for the test of the null hypotheses

- All $p$ of the regression coefficients are equal to 0 in the population,
- A particular coefficient is equal to 0,
- $k$ of the $p$ regression coefficients are equal to 0.

Most programs for calculating power require an estimate of the noncentrality parameter for the noncentral $F$ distribution, defined as

$$\hat{\lambda} = N^*f^2$$

where Cohen's effect statistic for regression, $f^2$, is given by

$$f^2 = \frac{\Delta R^2}{1 - R^2}$$

Here, $\Delta R^2$ is the increment in $R^2$ when $k$ predictors are added to a set of $p - k$ predictors, and $R^2$ is the squared multiple correlation calculated for the full set of $p$ predictors. Thus, Cohen's $f^2$ tells us the proportion by which the unexplained variance in Y is reduced by the addition of $k$ predictors, and the noncentrality parameter multiplies the effect size by a sample-size related variable, $N^*$. When the predictors are fixed-effects variables, $N^*$ is equal to the sample size, $N$; when the predictors are random variables, $N^*$ is defined by Cohen (1988)

$$N^* = \frac{df_{numerator} + df_{denominator}}{k(N-p-1)+1} = N - p + k$$

Maxwell (2000, p. 436) comments that Cohen's (1988) formulation appears to provide a small adjustment for the random nature of predictors that are usually encountered in psychological research.
