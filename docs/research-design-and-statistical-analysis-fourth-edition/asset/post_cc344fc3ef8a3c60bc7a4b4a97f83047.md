## Box 19.1 Testing for the Equality of Two Independent Regression Slopes

We wish to test whether the slopes are identical in populations 1 and 2; that is, $H_0: \beta_{11} - \beta_{12} = 0$. We can estimate the difference in the population slopes by $b_{11} - b_{12}$, and because under the usual regression assumptions the $bs$ can be expressed as linear combinations of the $Y_s$, the ratio

$$\frac{(b_{11} - b_{12}) - (\beta_{11} - \beta_{12})}{SE(b_{11} - b_{12})}$$

is distributed as $t$ with $df = N_1 + N_2 - 4$ if the null hypothesis is true. From Table 19.3 or Appendix 19.1, we know that $Var(b_{ij}) = \sigma^2/SS_{X_j}$. Further, because the groups are independent,

$$Var(b_{11} - b_{12}) = Var(b_{11}) + Var(b_{12}) = \sigma_c^2 \left(\frac{1}{SS_{X_1}} + \frac{1}{SS_{X_2}}\right)$$

where $SS_{X_1}$ and $SS_{X_2}$ are the sums of squares of $X$ in groups 1 and 2. Therefore, we can estimate the standard error of $b_{11} - b_{12}$ by $SE(b_{11} - b_{12}) = s_{Y,X} \sqrt{\frac{1}{SS_{X_1}} + \frac{1}{SS_{X_2}}}$ where the best estimate of $\sigma_r^2$, is given by the weighted average of the estimates from group 1 and group 2:

Combining with this, the test statistic

$$t = \frac{b_{11} - b_{12}}{\sqrt{SS_{X_1}^{-1} + SS_{X_2}^{-1}}} \sqrt{N_1 + N_2 - 4}$$

can be used to test the null hypothesis $H_0: \beta_{11} = \beta_{12}$.

Before leaving this topic, we note that the test of whether independent slopes differ depends on the assumption that the two-group error variances are equal in the population. If this assumption is violated, the power of the test can be seriously affected, even when the sample sizes are equal. Dechon and Alexander (1996) and Overton (2001) discuss this problem and offer some possible remedies.

## 19.3 Using Regression to Make Predictions

In this section, we discuss inference about predictions of (1) the mean of the distribution of Y scores at a given value of X and (2) a single Y score in this distribution.

### 19.3.1 Obtaining a Confidence Interval for a Conditional Mean

There are occasions when it is useful to find the confidence interval for the predicted Y score for a given value of X. For example, a admissions director might be interested in predicting the mean of freshman grade point averages (GPA) for students with a high school GPA of 3.0; this information might inform their admissions decisions. According to the regression model, the expected value of Y at $X=X$ (i.e., conditional mean) is $\mu_{Y,X} = \beta_0 + \beta_1X_i$. We can show that

$$\hat{Y}_i = \hat{\mu}_{Y,X} = b_0 + b_1X_i$$

is an unbiased estimator of $\mu_{Y,X}$, and the estimated standard error is given by

$$SE(\hat{\mu}_{Y,i}) = s_{Y,X}\sqrt{h_i} \quad (19.10)$$

where $h_i = \frac{1}{N} + \frac{(X_i - \bar{X})^2}{SS_X}$ is the so-called leverage of X, a measure of how much of an outlier the case is with respect to the distribution of X (See Appendix 19.2 for more detail.). For the search experiment, the best estimate for the conditional mean of Y at $X = 4$, $\mu_{Y,X} = 4$, is given by $\hat{\mu}_{Y,X=4} = 381.90 + (23.92)(4) = 477.58$, and the estimated standard error

$$SE(\hat{\mu}_{Y,X=4}) = 31.452 \sqrt{1 + \frac{(4-5)^2}{100}} = 7.70$$

Therefore, the 95% confidence interval for $\hat{\mu}_{Y,X}$ is

$$\hat{\mu}_{Y,X} \pm t_{025,18}(7.70) = 477.58 \pm 93.77$$

As we see from Equations 19.1 and 19.11, the standard error and therefore confidence interval are smallest when $X_j = \bar{X}$, and increase the more $X$ deviates from $\bar{X}$. This is seen in Figure 19.1, which is the scatterplot for the experiment data, with the regression line and 95% confidence interval also displayed. Hypothesis tests may be conducted in the same way as in the previous section.

### 19.3.2 Obtaining a Confidence Interval for a New Value of Y at $X_j$

We showed how to find a confidence interval for the conditional mean of the Y scores at $X = \bar{X}$. We showed how to find a confidence interval for the Y score of a new individual who has $X = X_j$. That is, we wish to estimate one score from the population of scores with mean $\mu_{Y,X}$, where $Y_{new} = \mu_{Y,X} + \epsilon$. In our college admissions example, this situation is relevant to decide about the admission of a particular applicant to the college. The estimate of the conditional mean, $\hat{\mu}_{Y,X} = b_0 + b_1X_j$, is an unbiased estimate of $Y_{new}$. Therefore, if we wish to find the confidence interval for $Y_{new}$, the variability associated with $\hat{\mu}_{Y,X}$ contributes to our error estimate. We must also consider the variance of the individual Y scores around the conditional mean. By combining these two sources of variability, $s_{Y,X}^2 + s_{Y,X}^2b_j^2 = s_{new}^2(1+b_j^2)$, so the standard error of $Y_{new}$ is given by $s_{Y,X}\sqrt{1+b_j^2}$ where $b_j$, the leverage, was defined by Equation 19.1.

For the experiment data, the predicted reaction for a new participant with array size of 4 is $381.90 + (23.92)(4) = 477.58$, as the predicted conditional mean. The estimated standard error

$$31.452 \sqrt{1 + \frac{(4-5)^2}{100}} = 32.38$$

so that the 95% confidence interval for $Y_{new}$ is $477.58 \pm (2.101)(32.38) = 477.58 \pm 68.03$. This interval is much wider than the 95% confidence interval for the conditional mean that we previously found to be $477.58 \pm 16.19$: predicting an individual is harder than predicting a mean.

Note that this 95% confidence interval does not allow us to conclude that 95% of the population of Y scores corresponding to $X = 4$ is $477.58 \pm 68.03$.

As always, the correct interpretation of the confidence interval is based on what would be expected to happen during repeated sampling: Assume that:

1. We select many samples of size N, using the same values of X in each sample.
2. For each sample, find the 95% confidence interval for the Y score of a new individual with $X = 4$.
3. For each sample, we observe whether the Y score falls within the confidence interval.

Then, if the assumptions are valid, the 95% confidence intervals will contain the actual scores in 95% of the samples.
