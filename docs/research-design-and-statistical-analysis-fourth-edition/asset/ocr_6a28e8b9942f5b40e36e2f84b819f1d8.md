Analogous arguments hold when we consider population parameters. The population variances for X + Y and X - Y are

```
$\sigma_{X+Y}^2 = \sigma_X^2 + \sigma_Y^2 + 2\rho_{XY}\sigma_X\sigma_Y$
```

The General Case. We previously defined $L = w_1Y_1 + w_2Y_2 + \dots + \\dots + w_nY_n$. The variance of $L$ can be shown by an extension of the formulas for two observations:

```
$s_L^2 = \sum_{i} w_i^2s_i^2 + \sum_{i}\sum_{j} w_iw_jr_{ij}s_is_j$,
```

For example, given two tests, T1 and T2, and a final exam score, F, and supposing the grade is calculated by weighting the two exams by 1/4 and each by 1/2, the variance of the grade is

The Variance of the Mean. An important consequence of these developments is that we can readily derive an expression for the variance of the mean of $n$ independently distributed scores. The mean is $(1/n)(Y_1 + Y_* + \\dots + Y_n)$. We view the variance of a score as the variance of scores in that sample over many independent samples. Then $s_1^2 = \dots = s_n^2 = s^2$ and each value of $w$ is $1/n$. Because the scores are independently distributed, all covariances equal zero, and substituting into Equation 5.18,

```
$var(\bar{Y}) = n\times s^2 / n = s^2 / n$
```

and the standard error of the mean is (defined in Chapter 2).

```
$SEM = \sqrt{s^2 / n}$
```
