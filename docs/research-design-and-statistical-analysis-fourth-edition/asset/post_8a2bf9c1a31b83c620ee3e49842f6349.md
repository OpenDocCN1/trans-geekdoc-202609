
## 18.3.4 Using Software for Partial and Semipartial (or Part) Correlation

Partial correlations are straightforward to calculate in SPSS. Simply select Correl from the Analyze menu, and then choose Partial. Select the variables to correlate (X and Y in Section 18.3.1) and move the variable to be partial (W in the prior equations) to the "controlling" for and click OK. For the 207 female-identifying participants in the Seasons data set with the age, bmi, ic, and height variables, the partial correlation of age with bmi is partial 0.509.

Computing a semi-partial or part correlation in SPSS requires first regressing X on W to obtain the results: Select Regression from the Analyze menu, then Linear. With the regression of X on W, click the "save" bar, and tick the box to save standardized residuals; these will be stored in window data. Finally, compute the correlation of Y with the file name RES_1 (assuming this is the first residual you have saved). Following the steps described in Section 18.3.2, the result will be the semipartial correlation, $r_{XY(W)} = 0.504$.

In R, the [ppcor] package provides functions for partial correlation (pcor or ptest) and semipartial correlation (sportest). For partial correlation, pcor can take a data frame as input (e.g., pcor(dat)), in which case the output will be a matrix of partial correlations of each pair with all the other variables partialed out, as well as a matrix of p-values. To compute a simple partial correlation, pcortest(X, Y) returns $r_{XY}$. For example, if the data described above are saved in a data frame called datWSc, then pcortest(datWSc, dat$age, dat$bmi) = .509. The function sportest(Y, W) returns $r_{XY(W)}$. For example, sportest(datWSc, dat$bmi) = .503. Note that any cases with missing data will be deleted by these functions to work; the na.omit function in the [base] package deletes rows with missing data on any variable.

## 18.3.5 Constraints in Sets of Correlation Coefficients

Given three variables X, Y, and W, there are three correlation coefficients, $r_{XY}$, $r_{XP}$ and $r_{YW}$. The range of possible values taken by any one of these correlations is constrained by the values taken by the other two. As the most extreme example, if W has a perfect linear relationship with both X and Y, then X and Y must have a perfect linear relationship. That is, if $r_{XY} = r_{YW} = 1$, however, what can we say about the possible values of $r_{XY}$ if $r_{XW}$ and $r_{YW}$ are both equal to some other value between -1 and .7?

Because $r_{XY}$ is a correlation, it must take on a value between -1 and +1. If we have Equation 18.9 for $r_{XY}$

$$$r_{XY} = r_{XW}r_{YW} + \sqrt{(1-r_{XW}^2)(1-r_{YW}^2)}$$

Therefore, the value of $r_{XY}$ must lie between

$$$r_{XY} - \sqrt{(1-r_{XW}^2)(1-r_{YW}^2)} = r_{XW}r_{YW} + \sqrt{(1-r_{XW}^2)(1-r_{YW}^2)}$$

Substituting into these expressions, we see that if $r_{XW} = r_{YW} = .7$, $r_{XY}$ must have a value between -.02 and 1.00. A strong negative correlation between X and Y is not possible if X and Y have large positive correlations with W. Violating these constraints – either because of missing data (see later) or because of adjustments to the correlations – may cause complications if the correlations are used as inputs to multivariate procedures such as factor analysis or principal components analysis.

## 18.4 Missing Data in Correlation

The constraint discussed Section 18.3.5 assumes that all correlations are calculated with data from the same cases. In other words, if a case is missing on any of X, Y, or W, the case is dropped when any of the correlations are calculated (i.e., listwise deletion). If, instead the correlation for any two variables is calculated without regard to whether there are missing data on other variables (i.e., pairwise deletion), then different correlations may depend on different subsets of the sample. This can result in inconsistent correlations, especially if the missing data are nonparametric. We should also note that if pairwise deletion is used and the missing data are MCAR (completely at random; see Chapter 13), pairwise deletion produces estimates that are consistent and therefore approximately unbiased in large samples. In contrast, if the missing data is MAR (missing at random) or MNAR (missing not random), pairwise deletion can lead to seriously biased parameter estimates. The practical implication of these observations is that listwise deletion should be used when observations are missing from data sets containing three or more variables.

## 18.5 Other Measures of Correlation

In this section, we introduce several classes of correlation measures other than the usual Pearson-moment coefficient. We discuss two measures when one or both variables are dichotomous (i.e., they can take on only two possible values). Next, we discuss measures of correlation used with ranked data.

### 18.5.1 The Point-Biserial and the Phi Correlation Coefficients

We are frequently confronted with dichotomous data (e.g., pass/fail, correct/error, experimental/control). Even though these are each categorical variables with two levels and there is nothing inherently quantitative about them, we can express this dichotomy as levels of a quantitative variable that may be correlated with other variables. For example, we can correlate a dichotomous variable with a continuous variable (e.g., passing or failing an individual test), or correlate two dichotomous variables (e.g., did not take training/fail on a driver license exam). We find the correlation by assigning any two numbers to the categories that make up the dichotomy. When the Pearson r formula is applied to a data set in which one variable is continuous and the other variable takes on the values 0 and 1, the result is called the point-biserial correlation coefficient. There are specialized formulas for the correlation that take advantage of the fact that one of the variables is dichotomous, but they will give the same numerical result as the Pearson r applied to the same variables. ## More About Correlation

Given data from two independent groups, we could test the null hypothesis that the group population means are equal by a t test. If we do this, we get the same observed t and test of $H_0$: $\rho = 0$ as if we

- 1. formed $N = n_1 + n_2$ data points (X, Y) in which Y score was paired with either $X = 1$ if the score belonged to group 1, or $X = 0$ if the score belonged to group 2, and
- 2. found $r_{x,y}$ and $\hat{\rho}_0 = 0$ by using Equation 18.1.

Solving Equation 18.1 for $r$

$$$r = \frac{\frac{t^2}{N-2}}{\sqrt{t^2+1}} \quad (18.12)$$

Because of this relationship, some authors recommend that $r$ be used as a measure of effect to acquaint $t$ tests, and because $F(1, df_{error}) = \hat{t}^2$, $r$ be used as the measure of effect size for $F$ tests where $df_1 = 1$ (see, for example, Rosenthal, 1991).

When both X and Y are dichotomous variables and we apply the Pearson formula, the result is called the $\phi$ coefficient ($\phi$). is the case for the point-biserial coefficient, specialized formulas for $\phi$ exist, but these always gives the same result as applying the Pearson $r$ to the dichotomous variables. If there are cases for both X and Y are 1, $b$ cases for which X is 0 and Y is 1, $c$ cases for which X is 1 and Y is 0, and $d$ cases for which X and Y are both 0, then the $\phi$ coefficient may be calculated as

$$$\phi = \frac{ad-bc}{\sqrt{(a+b)(c+d)(a+c)(b+d)}}$$
