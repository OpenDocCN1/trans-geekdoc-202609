b) Perform an ANOVA with format and test between-participants variables and test (SVT vs IVT) as the within-participants variable. Discuss the results, relating your discussion to the table of means.

14.17 [Cohen's f, confidence intervals, and power for real data] In 14.16, there is a significant difference between format and the type of test (SVT vs IVT). We may better understand this if we calculate some additional measures.

+   a) Estimate Cohen's f for the effect of format on the difference between test scores.
b) Calculate a 95% confidence interval for the interaction of format and test.
c) We wish to have a measure of the effect of instructions on the difference between SVT and IVT scores. Estimate Cohen's f statistic for that difference (i) in the text and (ii) in the web condition.
d) Using Cohen's f from part (c), determine how many participants would be required for power = .8 in the test condition.
