Now, expanding the numerator (or “sums of squares”) of this quantity, we get

```
$$\sum_{j=1}^a \sum_{i=1}^n (Y_{ij} - \bar{Y}_j)^2 = \sum_{j=1}^a \sum_{i=1}^n (Y_{ij}^2 + \bar{Y}_j^2 - 2Y_{ij}\bar{Y}_j)$
```

Using the distributive property, we “multiply through” by $\Sigma_n$, noting that $\bar{Y}_j$ varies only with $j$; it is constant when $i$ is the index of summation. Terms are also rearranged so that sums are pre-multiplied by constants:

```
$$\sum_{i} (Y_{ij} - \bar{Y}_j)^2 = \sum_{j} [\sum_{i} Y_{ij}^2 + n\bar{Y}_j^2 - 2\bar{Y}_j\sum_{i} Y_{ij}]$
```

Note that $\Sigma_i \bar{Y}_j = n\bar{Y}_j$. Although $\bar{Y}_j$ is a variable relative to the index $j_s$, it is a constant relative to $i$, which we index over $y_i$ currently summing; therefore, Rule 2 applies.
Substituting square-formula for the group means

```
$$\sum_{j} (Y_{ij} - \bar{Y}_j)^2 = \sum_{j} [\sum_{i} Y_{ij}^2 + n\frac{(\Sigma_i Y_{ij})^2}{n^2} - 2\frac{(\Sigma_i Y_{ij})^2}{n}] \text{ (simplified)}$
```

Simplifying gives

```
$$\sum_{j} (Y_{ij} - \bar{Y}_j)^2 = \sum_{j} Y_{ij}^2 - \frac{(\Sigma_i Y_{ij})^2}{n}$
```

which can also be written

```
$$\sum_{j} Y_{ij}^2 - \frac{\Sigma_j (Y_{i,j_j})^2}{n}$
```

To simplify, we can use $T$ (for “total”) to replace $\Sigma Y$. The sum of scores, for example, for group $j$ is

```
$T_j = \sum_i Y_{ij}$
```

and the raw-score expression derived can be rewritten as

```
$$\sum_j Y_{ij}^2 - \frac{\Sigma_j T_j^2}{n}$
```
