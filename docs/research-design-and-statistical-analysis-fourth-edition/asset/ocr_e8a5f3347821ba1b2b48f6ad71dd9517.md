# 19.3.1 Obtaining a Confidence Interval for a Conditional Mean

There are occasions when it is useful to find the confidence interval for the predicted Y score for a given value of X. For example, a admissions director might be interested in predicting the mean of freshman grade point averages (GPA) for students with a high school GPA of 3.0; this information might inform their admissions decisions. According to the regression model, the expected value of Y at X=X (i.e., the conditional mean) is $\mu_{Y,X_i} = \beta_0 + \beta_1X_i$. We can show that

```

```
