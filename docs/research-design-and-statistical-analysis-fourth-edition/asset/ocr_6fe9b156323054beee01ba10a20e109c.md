# Box 15.2 Quasi-F Test of C for the Data of Table 15.4 (C Is Between Participants, B Is Nested in Levels of A)

To test the effect of experience (C),

> $F' = MS_{SIC} / (MS_{SIC} + MS_{C,B/A} - MS_{Residual})$

Substituting values of mean squares from Table 15.5 into the preceding equation, we have

> $F' = 94.70 / (5.22 + 2.81 - .26) = 12.19$

The numerator degrees of freedom = c - 1, or 1, and the denominator degrees of freedom are

```
$\frac{(MS_{SIC} + MS_{C,B/A} - MS_{Residual})^2}{MS_{SIC} / df_{SIC} + MS_{C,B/A} / df_{C,B/A} + MS_{Residual} / df_{Residual}} = (5.22 + 2.81 - .26)^2 / (5.22 / 8 + 12.81 / 9 + .26^2 / 72) = 14.09$
```

p=.004; with α=.05, we can conclude that more experienced problem solvers require significantly less time to solve.
