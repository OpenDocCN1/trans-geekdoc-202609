7.3 (a) On each trial there four options. If the participant is guessing at random, the probability of choosing correctly on one trial is 0.25.

(b) We compute the probability of $k$ successes out of $n$ trials, where $k=0, 1, \dots, 6$, $n=6$, and $p=p(success)=0.25$. $P(y=k)=inom{n}{k}p^k(1-p)^{n-k}$, so for $k=0$, prob=$0.25^0(1-0.25)^6=0.178$. In R, the `binom(k,n)` function will help (remember to subtract from the probability that $y<k$), or use Table C.1.

| Number Count | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---||}{
| Probability | 0.178 | 0.356 | 0.297 | 0.132 | 0.033 | 0.004 | 0.000 |

(c) There are 100 participants in the study, so the expected number of participants with each possible correct number is $100 	imes p(k)$. For example, we expected 132 participants to have exactly three correct responses.

(d) Each participant sees six trials with 0.25 chance of being correct on. So the expected number correct is $6 	imes 0.25 = 1.5$.

$p(y>1.5) = p(y=2) + p(y=3) + \dots + p(y=6) = 0.297 + 0.132 + 0.033 + 0.004 + 0.000 = 0.466$.

7.5 (a) For Group 1, the critical value of $t$ area above 0 is $t(95,d=11)=2.201$ and $s_1/\sqrt{n_1}=6.6/\sqrt{12}=1.91$. Then the 95% CI for the mean is $10.7\pm2.201$ or $[6, 14.9]$. For Group 1, 0 is not in the interval so we can conclude that the Change scores are significantly greater than 0 in that group with $\alpha=.05$. Similarly for Group 2, the 95% CI for the mean is $5.42\pm2.567$ or $[-2.6, 12.3]$. In Group 2, 6 is not in the CI and so we cannot reject the null hypothesis that the change scores have an average of 0.

```
$t = \frac{change_1 - change_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} = 5.28 / 3.27 = 1.61$.
```

Use Equation 6.17 to calculate df, or use $t.test$ in R. We find $df=10.24$ and $p$-value=$0.066$ for the one-tailed alternative hypothesis that the mean is “greater” than 0, which is not significant. We conclude that the difference in the change scores as a function of group is not significant. Note that this is true even though two of the groups has a mean that is itself different from zero while the other does not.
