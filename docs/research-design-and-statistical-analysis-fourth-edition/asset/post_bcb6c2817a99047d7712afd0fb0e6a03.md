## 20.5 Using Software for Multiple Regression and Cross-Validation

Using software for multiple regression is similar to the bivariate regression approaches detailed in Section 17.6.6. Additional predictors are simply added to the Independent variable list in SPSS. In R, additional predictors are included in the regression equation in the `lm` function with a + between them; `reg_out <- lm(data = dat, Y ~ X1 + X2)`; confidence intervals for the intercept and partial slope parameters can be obtained using the `confint` function in the `{stats}` package, which takes the output of regression as input: `confint(reg_out)`.

Cross-validation involves several steps that can be done quickly in R:

- 1. Identify a training set of data by randomly sampling a percentage of the cases and saving the sample case numbers. The `sample` function in `{base}` R is a good tool to use. Having 126 cases and wanting to sample 25% of them, `train.index <- sample(seq(1:126), 32)` will store a random sample of 32 integers from the set 1 to 126.
- 2. Assign those cases to a training set, `train.set <- datcv(train.index)`, and complete the cases to a test set, `test.set <- datcv(train.index)`.
- 3. Run the regression on all predictor variables, and see the results: `model.cv <- lm(tc ~ ., data = train.set)`. At this point, you can run step regression (Chapter 21) on these predictors using the `step` function in `{stats}`, although that is not a necessary part of cross-validation. If you include this, be sure to store the results: `model.cv <- step(model.cv, scope = lower(Y ~ 1), upper = lm(Y ~), direction = "both")`. The scope parameters specify the range of models under consideration, where `Y ~ 1` indicates a model with an intercept, and `Y ~` indicates a model with all predictors included.
- 4. Compute and store the Y values for the test cases (Section 19.3), using the model generated with the training cases: `predictions.cv <- predict(model.cv, test.set)`.
- 5. Finally, compute $R^2$ for the predicted and observed values: `cor(predictions.cv, test.set)^2`. Additional cross-validation methods in R are described by Rooij and Witten (2020).

In SPSS, cross-validation is not automated but can be easily achieved by the following steps:

- 1. Select a random sample of cases using the Select Cases option from the Data pull-down menu, and then clicking the radio button for Random sample size.
- 2. Run the regression on the selected sample, which is the training set.
- 3. Use the Transform menu to compute a new variable, Y by typing in the Numeric Expression the regression you obtained. Instead of clicking OK, click on If... bar at the bottom and select the radio button Case satisfies condition, then type "filter=0" in the box. This will compute the predicted value of Y only for the cases that were not in the training set.
- 4. Finally, select all cases and compute the square of the correlation between the observed and newly predicted values of Y; this will be $R^2$ for the test cases.

## 20.6 Multiple Regression Analyses of TC

We have identified and discussed the components of the regression equation and have explained how to use software to generate the analyses. We now illustrate the computations using data for which preliminary analyses were presented in Section 20.2. 20.7 presents the R output for the regression of TC on both age and BMI. Breaking down the analysis presented in Figure 20.7:

- 1. The Estimate column in the coefficients panel provides the least-squares estimates of the Y intercept ($b_0$) and the unstandardized regression coefficients (or partial slope coefficients) for $X_1$, $X_2$, $b_1$ and $b_2$. These entries show that the least-squares regression equation includes both age and BMI as predictors: $\hat{Y} = 92.239 + 1.737X_1 + 1.474X_2$.
- 2. The plot of Equation 20.9 is displayed in Figure 20.8, with the data points; residuals are denoted by lines connecting each data point with its predicted value. Instead of the regression line we obtained using bivariate regression, we now have a two-dimensional regression plane. If BMI held constant, a one-unit change in age corresponds to an increase of 1.737 units in predicted TC. Similarly, if age held constant, a one-unit change corresponds to an increase of 1.474 units in predicted TC.

- Compare these coefficients to the values found for the multiple and bivariate coefficients in the preliminary analyses of Section 20.2: for *age*, the coefficient was 1.812 and for *BMI* the coefficient was 1.934. The difference between multiple and bivariate regression coefficients is due to the fact that *age* and *BMI* are correlated ($r=.12$), so the multiple regression coefficients change when each predictor's coefficient is adjusted for the other predictor.
- 2. Near the bottom of the output in Figure 20.7, we see that the squared multiple correlation coefficient, *Multiple R-squared*, is .272. This means that the TC values predicted by Equation 20.9 have a correlation of $\sqrt{.272}=.522$ with the actual TC values in the sample. Multiple R-squared is sometimes called the coefficient of multiple determination, and it tells us the proportion of variance accounted for by the regression. The standard error of the estimate, 33.6, provides a measure of how well the regression predicts TC.

- If the underlying model for the population is $Y_i = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_pX_p + \varepsilon_i$, the standard error of the estimate provides an estimate of the standard deviation of $\varepsilon$.
- 4. The ANOVA table from R, shown in Figure 20.9, allows us to calculate the total sum of squares accounted with cholesterol levels, 276,210. We also see that it can be partitioned into two components: the sum of squares accounted for by the regression, $SS_{regression}$ equals the sum of $SS$ for *age* and BMI, and the sum of squares unaccounted for, $SS_{residual}$ where

```
$SS_{regression} = \sum(Y_i - \hat{Y}_i)^2 = R^2SS_Y = 75,221$
```

and

```
$SS_{residual} = \sum(Y_i - \hat{Y}_i)^2 = (1-R^2)SS_Y = 200,989$
```
