To estimate the population variance of the Beck Depression means as a function of educational level, substitute the mean squares from Table 8.6 into Equation 8.14, and with $\sum n_j = 128$,
$\hat{\sigma}_A^2 = (3)(62.167 - 17.452)/128 = 1.048$

We can now estimate $\omega^2$ using Equation 8.16 with N replacing an. Then
$\hat{\omega}^2 = \frac{(a-1)(F_A-1)}{(a-1)(F_A-1)+N} = \frac{(3)(2.562)}{(3)(2.562)+128} = .057$

The same estimate can be obtained from the $omega\_squared$ function in R's {effectsize} package, or using SPSS as described in Section 8.5.5. We use the same variance estimate to estimate Cohen's f:
$\hat{f} = \hat{\sigma}_A / \hat{\sigma}_e = \sqrt{1.048/17.245} = 0.245$

Whether we view $\omega^2$ or f, Cohen's guidelines suggest that the effect is of medium size.
