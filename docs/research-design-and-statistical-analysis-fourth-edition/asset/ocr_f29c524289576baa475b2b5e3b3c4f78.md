# Notes

+   1 When standard statistical software is used, high correlations among predictors will not generally result in much difficulty if the only goal is prediction. However, multicollinearity can result in errors in the computational algorithms employed in spreadsheets as Excel when one attempts to use them to perform multiple regression. Centering the variables (the third remedy after Section 22.8.4) can reduce the correlations among predictors, and also reduce the sizes of the numbers used in calculations, thereby reducing rounding error. Nonetheless, spreadsheets and other nonstandard statistical software should not be used to perform serious statistical analyses, especially multiple regression.
