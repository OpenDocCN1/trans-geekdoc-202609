# 21.7 Power Calculations in Multiple Regression

There are several kinds of power calculations that can be performed for multiple regression, pairing the various hypotheses that can be tested (see Section 21.4). Here, given the model

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \beta_jX_j + \dots + \beta_pX_p + \epsilon$
```

we consider power for the test of the null hypotheses

+   1. All $p$ of the regression coefficients are equal to 0 in the population,
2. A particular coefficient is equal to 0, or
3. $k$ of the $p$ regression coefficients are equal to 0.

Most programs for calculating power require an estimate of the noncentrality parameter for the noncentral $F$ distribution, defined as

```
$$\hat{\lambda} = N^*f^2$ (21.4)
```

where Cohen's effect statistic for regression, $f^2$, is given by

```
$f^2 = \frac{\Delta R^2}{1 - R^2}$ (21.5)
```

Here, $\Delta R^2$ is the increment in $R^2$ when $k$ predictors are added to a set of $p - k$ predictors, and $R^2$ is the squared multiple correlation calculated for the full set of $p$ predictors. Thus, Cohen's $f^2$ tells us the proportion by which the remaining unexplained variance in Y is reduced by the addition of $k$ predictors, and the noncentrality parameter multiplies the effect size by a sample-size related variable, $N^*$. When the predictors are fixed-effects variables, $N^*$ is equal to the sample size, $N$; when the predictors are random variables, $N^*$ is defined by Cohen (1988)

```
$N^* = \frac{df_{numerator} + df_{denominator}}{k(N-p-1)+1} = N - p + k (21.6)
```

Maxwell (2000, p. 436) comments that Cohen's (1988) formulation appears to provide a small adjustment for the random nature of predictors that are usually encountered in psychological research. Therefore, a convenient way to perform *a priori* power calculations is to use $G^*$ Power 3.1 to determine the $N^*$ required to achieve the desired level of power.
