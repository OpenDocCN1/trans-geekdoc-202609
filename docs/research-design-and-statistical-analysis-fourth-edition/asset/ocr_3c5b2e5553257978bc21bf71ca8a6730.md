# 21.4 Testing Hypotheses in Multiple Regression

# 21.4.1 Testing the Hypothesis $\beta_1 = \beta_2 = \dots = \beta_p = 0$

As indicated in Section 20.4.2, if the $p$ regression coefficients $\beta_1, \beta_2, \dots, \beta_p$ all have the value $0$ in the population, the

$$\frac{MS_{regression}}{MS_{residual}} = \frac{R^2 SS_Y / p}{(1-R^2) SS_Y / (N-1-p)}$

will be distributed with $F$ with $p$ and $N-1-p$ df under standard assumptions. Therefore, $MS_{regression}/MS_{residual}$ can serve as the statistic to test the null hypothesis that the $p$ regression coefficients are all zero in the population. This test asks whether we have sufficient evidence to conclude that the model

$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p + \varepsilon$

accounts for $Y$ in the population better than the restricted model

$Y = \beta_0 + \varepsilon$\n$\\mu_Y + \varepsilon$

If the restricted model is appropriate, then $\beta_1 = \beta_2 = \dots = \beta_p = 0$, so that the best predictor for $Y$ is $\hat{\beta}_0 = \hat{\mu}_Y$ and the multiple correlation coefficient in the population has value 0.
