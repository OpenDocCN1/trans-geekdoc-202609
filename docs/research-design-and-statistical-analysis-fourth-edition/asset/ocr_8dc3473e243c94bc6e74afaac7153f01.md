# 18.2.7 Testing Hypotheses About Dependent Correlations

In the preceding section, we focus on comparisons of correlations of the same variables across different groups (e.g., the correlation between subtraction and multiplication scores for third- versus-graders). In this section, our concern is evaluating multiple correlations on the same set of participants. We have questions of interest: First, which variables are correlated? Second, which correlations differ in magnitude? We first consider the question of evaluating individual correlation coefficients.

When on several variables have been collected from the same set of Participants, the correlations may be displayed as a *correlation matrix*. The variables are $X_1, X_2, X_3, X_4$, and $X_5$; the correlation matrix is

| | $X_1$ | $X_2$ | $X_3$ | $X_4$ |
|---|---|---|---||}{
| $X_1$ | 1 | $r_{12}$ | $r_{13}$ | $r_{14}$ |
| $X_2$ | $r_{21}$ | 1 | $r_{23}$ | $r_{24}$ |
| $X_3$ | $r_{31}$ | $r_{32}$ | 1 | $r_{34}$ |
| $X_4$ | $r_{41}$ | $r_{42}$ | $r_{43}$ | 1 |

If are $k$ variables, the correlation matrix consists of $k^2$ elements. The $k$ elements on the major diagonal (the one that goes from the upper to the lower right) are all equal to 1 because any variable is perfectly correlated with itself. The $k^2-k=k(k-1)$ off-diagonal elements can be divided into a set of $k(k-1)/2$ correlations around the diagonal and a set of equal size. The matrix is symmetric because correlations on opposite sides of the diagonal are identical; $r_{ij}=r_{ji}$, and $r_{ij}=r_{ji}$ for all $i$ and $j$.

When k is large, the number of correlations will be large. For example, if $k=20$, $k(k-1)/2=190$. If we tested each correlation for significance at $\alpha=.05$, the Type 1 error rate for the entire family of correlations would be very high. Although most software packages will dutifully provide the significance level for each correlation coefficient as though it were the only tested, it is necessary to control Type 1 error here as when we perform multiple $t$ tests on the differences between means.
