Several important points should be noted about the logic of hypothesis testing. First, a statistically significant result means that a value of the test statistic has occurred that is unlikely. However, "unlikely" is not the same as "impossible," and we sometimes reject a null hypothesis even when it is true. Incorrect rejections of the null hypothesis are called Type 1 errors; these are false positives. The significance level α is the probability of rejecting H0 as true, α = p(reject H0 | H0 is true), the conditional probability of rejecting H0, given that H0 is true. A useful way to conceptualize this is if the responses were generated by random guessing (H0, true), and if we were to replicate the experiment many times, we can expect Y ≥9 in .041 of these experiments. If we obtain Y greater or equal to 9 when H0 is true, we will incorrectly reject H0. By setting α at a particular level, we specify the risk of a Type 1 error that we are willing to tolerate.

The p-value of the observed data gives whether the null hypothesis is true, or p(observed data | H0). Two types of errors are often made in interpreting p-values. First, it is common to confuse this conditional probability with its opposite, p(H0 | observed), the probability that the null hypothesis is true given the results of the experiment. This is not correct. It would be nice if a significance test gives us the probability that H0 was true, but it does not.
