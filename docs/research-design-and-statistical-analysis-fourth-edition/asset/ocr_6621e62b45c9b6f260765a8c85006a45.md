# 4.5.6 Using Software to Compute Power

In Box 4.3, we showed the steps involved in calculating power in a binomial distribution. Those steps including determining the rejection region of the sampling distribution assuming $H_0$ is true and computing the probability of observing an outcome in the rejection region within a specific alternative, $H_a$. The tools presented in Sections 4.3.4 and 4.4.3 allow us to use different calculators for these steps in computing power.

We use R to identify the region under the null hypothesis, as described in Section 4.4.3. For example, using $H_0: \pi=25, \pi=.25; H_a: \pi=.35$, and $n=20$. We start by using the qbinom function to identify the one-tailed rejection region of the sampling distribution assuming the null hypothesis is true: the qbinom(size = 20, prob = .25) returns the value of Y, above which only 5% of the sampling distribution falls when $n=20$ and $\pi=.35$. Using that value of Y and the $H_a: \pi=.35$, the tools described in Section 4.3.4 allow us to compute the probability of observing many successes (or more) assuming the specific alternative hypothesis is true: pbinom(x=8, prob=.35, tail=FALSE)=.236. This means that for a power of size 20, $p(y\ge9|n=.35)$ is equal to .237. Of course, this equals the power we computed in Section 4.2 using Table C.1.

Another helpful tool designed specifically for computing power is a free, convenient and flexible program G*Power 3.1 (Faul et al., 2007). "To calculate post hoc power for a sample of 20, with $y\ge2$ and $H_a: \pi=.35$, open G*Power 3.1 and select Exact as the Test family, then select Proportions: Difference from Constant (one sample case) as the Statistical test, then, for Type of power analysis, select Post hoc: Compute power - given a, sample size, and effect size. Here, the constant power is .25; the effect size, g, is the difference between $H_a$ and $H_0$ or .1=.35-.25, and $\alpha=.05$ with a one-tailed test. Insert those values and then click the Button in the lower right of the dialog box. The results are displayed in Figure 4.6. We see that power =0.2376, as we calculated previously. Also notice that the critical value is "critical N =9," defining the same rejection region we calculated previously.

The figure at the top of the results in Figure 4.6 gives some explanation: The distribution on the left is the binomial for $n=20$ and $\pi=.25$ and has a larger area of $\pi=(20).(.25)=5.0$. The distribution on the right is for $\pi=.35$ and has a larger area of $\pi=(20).(.35)=7.0$. The critical N of 9 shows that if Rachel gets 9 or more in 20 trials, we reject the null hypothesis for $\alpha=.05$.

A important advantage of G*Power is that we can easily calculate the sample size we need to achieve a minimum *a priori* power level. Let's see how many trials we need Rachel to complete the ESP experiment for power of .8. Within the test family, select Proportions: Difference from Constant (one sample case) and the *A priori*: Compute required sample size - given a, power, and effect size power analysis. Enter the parameters as before: one-tailed test with effect size 0.1, constant power =.25, $\alpha=.05$, and desired power =.8, and click Calculate. This reveals we need a total of 129 trials, a much larger study than we have conducted so far.
