# Influential Points

In SPSS, we again begin the regression as described in Section 17.6.6, then click on the Save button. Measures of influence are available by ticking the DBetas and Standardized DBetas (saved as DF0_1, DF1_1, and SDDB_1, SDBF_1, respectively), as well as Dfits and Standardized Dfits (saved as DF_1 and SDF_1). Cook's distance is an option in the Distance section of the same window; results saved as Coo_1.

In R, with regression results stored in reg_out, the function influence.measures(reg_out) in the [stats] package will return dfbetas (standardized dbeta values, for intercept and for one slope), dfits (standardized differences in fit), Cook's distance, and leverage (called hat). Each of these measures is also available as its own function (dfbetas, dfits.distance, hatvalues) and takes as input the output of regression analysis (e.g., reg_out). The unstandardized difference in beta can also be calculated with the dbeta function.
