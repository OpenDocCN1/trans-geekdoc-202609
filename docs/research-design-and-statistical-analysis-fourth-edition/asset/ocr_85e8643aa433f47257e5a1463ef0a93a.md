An ANOVA table containing these terms is given in SPSS output in Figure 19.3 and detailed in Table 19.2. If you test the regression results in regr.out, then an() returns the same ANOVA table. In either case, the $F$ is the ratio $MS_{regression}/MS_{residual}$. A significant $F$ indicates that both $r$ and $eta_i$ are significantly different from zero; the null hypotheses $H_0: \beta_1=0$ and $H_0: \beta_2=0$ can be rejected. The $F$ can be used to test the significance of the correlation coefficient if it can be expressed as the square of the $t$ that was presented in Chapter 17 or as the $t$ statistic for the null hypothesis $H_0: \beta_i=0$. Also, the $F$ can be written as the square of $t=b_i/SE(b_i)$, the test statistic for the null hypothesis $H_0: \beta_i=0$. Note that the square of the $t$ for $b_1(7.605)^2=57.836$, within rounding error, is the same as the value of $F$ in the ANOVA table.

We can use the standard errors in Equations 19.6 and 19.7 to find confidence intervals and tests about the Y intercept and slope of the regression line. For the slope of the regression, the 95% confidence interval for $\beta_1$ is given by

$b_1 \pm t_{025,18}SE(b_1) = 23.92 \pm (2.101)(3.145) = 17.31, 30.53$

We can test the null hypothesis $H_0: \beta_1=\beta_{1byp}$ using the test statistic

$t = \frac{b_1-\beta_{1byp}}{SE(b_1)} \text{ with } N-2 \text{ df}$

If we wish to test the null hypothesis $H_0: \beta_1=0$, a two-tailed test for the slope is equivalent to the $F$ in the ANOVA table. This may be shown by squaring the expression for $t$,

$t^2 = \frac{b_1^2}{SE(b_1)^2} = \frac{b_1^2 SS_X}{SS_{Y,X}^2/SS_Y} = \frac{MS_{regression}}{MS_{residual}} = F$

Suppose we wish to test the hypothesis $H_0: \beta_1=20$ against the alternative hypothesis $H_1: \beta_1 > 20$. The value of the test statistic is

$t = \frac{23.92-20}{3.145} = 1.246$

This result is of, consistent with the confidence interval limits previously calculated; those informed us that a two-tailed test cannot reject any hypothesized value of the slope between 17.31 and 30.53.
