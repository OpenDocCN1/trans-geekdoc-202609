# 9.3 Two-Factor Designs: The Analysis of Variance

The analysis of the variability in the data for the two-factor design follows the same logic developed for the one-factor design presented in Chapter 8. The structural model (Equation 9.6) suggests a way to partition the deviation of a score from the grand mean, $\hat{Y}_{...}$, into several components. We derive these components in Section 9.3.1, and then develop formulas for the sum of squares based on them in Section 9.3.2. We construct mean squares and, subsequently, $F$ statistics to test null hypotheses about main and interaction effects.

# 9.3.1 Components of the Scores

In Section 9.2.1, we assumed the structural model

$Y_{ijk} = \mu + \alpha_j + \beta_k + (\alpha\beta)_{jk} + \varepsilon_{ijk}$

After subtracting $\mu$ from both sides and substituting treatment population means, we have

