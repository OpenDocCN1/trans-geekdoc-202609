Summing the squared deviations, we have $\Sigma(Y - ar{Y})^2 = 112$. Then, $s^2 = 112/6 = 18.667$. In words, the variance of the scores is 18.667 squared units.

As a descriptive scale, the variance is rather awkward because it expresses the variance on a different scale (i.e., squared units) than the data being described. Because of this, the preferred measure for descriptive purposes is the *standard deviation*, which is simply the square root of the variance. In the preceding example, $s = \sqrt{18.667} = 4.320$. Two properties of the standard deviation should be:

+   1. If $Y' = Y + k, s_{Y'} = s_Y$. When a constant is added to all scores, the standard deviation is unchanged. Each score is increased (or decreased) by the same amount so the spread of scores changes. The range and the H-spread are also unchanged when a constant is added, and it is a desirable property of any measure of variability.
2. If $Y' = kY, s_{Y'} = |k|s_Y$, where $|k|$ indicates the absolute value of $k$. When each score is multiplied by $k$, the standard deviation of the new scores is the absolute value of $k$ times the old standard deviation. Thus, the standard deviation of the transformed distribution is changed by multiplication or division.

These properties are proven in Appendix A.
Although the standard deviation is less intuitive than other measures of variability (e.g., H-spread), it has two advantages. First, the standard deviation is important in drawing inferences about populations. It is a component of formulas for many significance tests, for procedures estimating population parameters and the bounds on them, and for measures of relations among variables. Second, the standard deviation (and the variance) can be manipulated arithmetically in ways that other measures cannot. For example, if we know the standard deviations, means, and sizes of two sets, we can calculate the standard deviation of the combined data set without individual scores. This relation between the variability within groups of scores and the variability of the total set plays an important role in data analysis. Both properties of the standard deviation provide some flexibility throughout this book.

The main drawback of the standard deviation is, like the mean, it can be greatly influenced by a single outlying score. Recall that for $Y = \{1, 2, 3, 5, 9, 10, 12\}$, $ar{Y} = 6$ and $s = 4.320$. Suppose we add one more score. If that score is 8, a value within the range of the scores, the mean and standard deviation are 6.25 and 4.062, a fairly small change. However, if the additional score is 20, we now have $ar{Y} = 7.75$ and $s = 6.364$. The standard deviation increased by almost 50% with the addition of one extreme score. In contrast, the H-spread is resistant to extreme scores and is often a useful measure for describing the variability in a data set. We again emphasize that there is no single best measure of variability (or of location or shape), but there is a choice, and that different measures prove useful for different purposes and may supplement each other.
