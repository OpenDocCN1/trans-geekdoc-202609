Therefore, the increment in variability associated with the predictor $X_{p+1}$ is given by

$SS_{increment} = SS_{Y_{p+1..12..p}} = (R_{Y_{12..p+1}}^2 - R_{Y_{12..p}}^2) SS_Y$

This increment is accounted with a single $df$ because only additional regression coefficient must be estimated in the larger model. Table 21.1 presents these results in the form of an ANOVA table where the SS accounted for Y is first partitioned into the SS accounted for the larger model with $p+k$ predictors and error variance (residual); then, the SS for the larger model is partitioned into the SS for the smaller model with $p$ predictors and the SS for the increment due to the remaining $k$ predictors. The hypothesis $H_0: \beta_{p+1} = 0$ is tested using the ratio

```
$F = \frac{MS_{increment}}{MS_{residual}}$
```

where the denominator is the smaller mean square with the variability not accounted for by the larger model; when $k=1$

```
$MS_{residual} = \frac{(1 - R_{Y_{12..p+1}}^2) SS_Y}{N-p-2}$
```

The numerator of the $F$ is associated with $1 df$ if a single predictor is added ($k=1$) and the denominator with $N-2-p$ $df$.
