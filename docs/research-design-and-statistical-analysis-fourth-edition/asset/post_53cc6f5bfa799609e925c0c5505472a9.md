$F_w = \frac{A}{B}$

## A Robust F Test Based on Trimmed Means

The normality and homogeneity of variance assumptions $ns$ are often violated in the same data set. This is particularly a problem when $ns$ are unequal, as in the Beck Depression data we analyzed, or when the experimental conditions have differently shaped distributions. A promising approach is to apply Welch's $F$ test to means based on data from which the highest and lowest 20% have been trimmed (Cribbie et al., 2012; Keselman, Wilcox, Oman, & Fradette, 2002; Lix & Keselman, 1998). The test is described in Box 8.4. In $R_s$, the *welch.test* function in [onetaways] computes $F_w$ using trimmed means and winsorized variances when the *rate* = 0.2 option is employed to trim percentage of the data from each tail (here, 20%). For the depression data, this robust $F$ test statistic equals 1.58 with 3 and 30 degrees of freedom. The reduction in degrees of freedom results in a larger $p$-value of 0.24.

## Partitioning the Total Variability in the One-Factor Design

The following developments involve two indices of summation: $i$ indexes a value from 1 to $n$ within each group, where $n$ is the number of individuals in a group; $j$ indexes a value from 1 to $a$, where $a$ is the number of groups. Appendix A provides an explanation of the use of this notation, using several examples.

Squaring both sides of Equation 8.1

```
$(\tilde{Y}_i - \tilde{Y}_j)^2 = (\tilde{Y}_i - \tilde{Y}_i)^2 + (\tilde{Y}_j - \tilde{Y}_j)^2 + 2(\tilde{Y}_i - \tilde{Y}_j)(\tilde{Y}_i - \tilde{Y}_j)
```

Summing over $i$ and $j$, and applying the rules of Appendix A, we have

```
$$\sum_{i=1}^n \sum_{j=1}^a (\tilde{Y}_i - \tilde{Y}_j)^2 = \sum_{i=1}^n \sum_{j=1}^a (\tilde{Y}_i - \tilde{Y}_i)^2 + n\sum_{j=1}^a (\tilde{Y}_j - \tilde{Y}_j)^2 + 2\sum_{i=1}^n \sum_{j=1}^a (\tilde{Y}_i - \tilde{Y}_j)(\tilde{Y}_i - \tilde{Y}_j)$$
```

Rearranging terms, we find that the right-most (cross-product) term equals 0:

```
$$\sum_{i=1}^n \sum_{j=1}^a (\tilde{Y}_i - \tilde{Y}_j)(\tilde{Y}_i - \tilde{Y}_j) = 2\sum_{j=1}^a (\tilde{Y}_j - \tilde{Y}_j)\sum_{i=1}^n (\tilde{Y}_i - \tilde{Y}_j)$$
$$\sum_{j=1}^a (\tilde{Y}_j - \tilde{Y}_j)(0) = 0$$
```

The last result follows because the sum of deviations about their mean is zero.
