# Research Design and Statistical Analysis

We can obtain $SS_{between}$ as

```
$SS_{between} = SS_A = R_{Y,A}^2 SS_{Y}$
```

where $R_{Y,A}^2$ is the square of the multiple correlation coefficient that results when Y is regressed on a complete set of $a - 1$ dummy variables that code factor A. The within-group variability can be obtained

```
$SS_{within} = (1 - R_{S/A}^2) SS_{Y}$
```

so that the test for A is given

```
$F = \frac{MS_A}{MS_{S/A}} = \frac{R_{Y,A}^2 SS_Y / (a-1)}{(1-R_{Y,A}^2) SS_Y / (N-a)}$
```

The null hypothesis is tested that the population means of Y are identical for each of the levels of the factor A. Performing a one-factor ANCOVA can be thought of as determining the categorical factor A has effects over and above those of a covariate, X, that is correlated with the dependent variable; or, equivalently, there are effects of A if we statistically adjust for differences in. The hypothesis we test is that the Y population means would be identical for each of the $a$ levels of the factor A if each participant had the same value on X. The ANCOVA can be thought of a comparison between two models in which Y is regressed on the covariate X:

+   1. A full ANCOVA model that also contains information about group membership
$Y_{ij} = \mu + \alpha_j + eta_{S/A}(X_{ij} - 	ilde{X}_j) + \varepsilon_{ij}$ (ANCOVA)

where $eta_{S/A}$ equals the weighted average of the slopes that would be obtained in separate regressions for each of the groups; i.e.,

```
$b_{S/A} = \frac{\sum b_j SS_j}{\sum SS_j}$
```

+   2. A restricted model that does not include information about group membership

```
$Y_{ij} = \mu + eta_{tot}(X_{ij} - 	ilde{X}) + \varepsilon_{ij}$
```

where $eta_{tot}$ is estimated by the slope of the regression of Y on X, ignoring group membership. The test statistic for the ANCOVA does not contain $SS_A$ or $SS_{S/A}$ but rather the corresponding sums of squares that have been adjusted for the covariate, called the adjusted sums of squares:

```
$SS_{A(adj)} = (R_{Y,X,A}^2 - R_{Y,X}^2) SS_Y$
```
