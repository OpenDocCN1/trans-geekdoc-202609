Equation 18.4 also provides a basis for obtaining confidence intervals for $Z_{ho_1}-Z_{ho_2}$. The 95% confidence is given by

```
$Z_{ho_1}-Z_{ho_2} = \pm 1.96\sqrt{\frac{1}{N_1-3}+\frac{1}{N_2-3}}$
```

Although 18.5 can be used to find a confidence interval for $\rho_1-\rho_2$, we cannot transform back to obtain a confidence interval because the Fisher Z transformation is not linear, so $Z_{ho_2}$ is not the same as $Z_{ho_1}-Z_{ho_2}$. This nonlinearity is not a problem for hypothesis testing because if $Z_{ho_1} \neq Z_{ho_2}$, then $ho_1 \neq \rho_2$.

Zou (2007) provided a procedure for finding the confidence interval for the difference between two independent correlations. To find, the 95% confidence interval for $\rho_1-\rho_2$, we start by finding the 95% CI for each correlation, using the Fisher Z transformation as showed earlier. In the data for the previous example, the 95% CI for the correlation between age and TC for participants who identify as women, $\rho_1$, extends from .403 to .604. We denote the lower of the interval by $l_1$ and the upper limit by $u_1$. Then we find the 95% CI for the corresponding correlation for participants who identify as men, $\rho_2$, as the interval from -.072 to .192. We denote the lower limit by $l_2$ and the upper limit by $u_2$. Then, the lower and upper limits of the 95% CI for the correlations, $\rho_1-\rho_2$, are given by

```
$L = r_1-r_2-\\sqrt{(r_1-l_1)^2+(u_2-r_2)^2}$
```

and

```
$U = r_1-r_2+\sqrt{(u_1-r_1)^2+(r_2-l_2)^2}$
```

Substituting the values we find that the 95% CI for the difference between the two correlations extends from .28 to .61.
