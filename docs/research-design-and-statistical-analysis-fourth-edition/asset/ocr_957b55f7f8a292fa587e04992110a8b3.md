If the linear model is appropriate, the conditional Y means (i.e., the means of the TC values for different ages) all fall on a straight line. In this case, the variability about the line is the same as the variability about the means, so $SS_{residual}$ consists only of pure error.
If the linear model is not appropriate, $SS_{residual}$ consists of not only a pure error component that reflects variability around the conditional means, but also a "nonlinearity" component that reflects the extent to which the conditional means are not a perfect linear function of X.
