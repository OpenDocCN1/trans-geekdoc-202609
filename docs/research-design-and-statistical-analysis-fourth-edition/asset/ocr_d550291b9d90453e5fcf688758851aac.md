In the long run (i.e., if the experiment were repeated many times), the proportion of experiments with four A and six A should equal .2051, if the binomial model is correct. Several points should be noted about these distributions. First, when $\pi=.5$, the distributions are more symmetric than for values of $\pi$ closer to 0 or 1. When $\pi=.25$ and skewness (asymmetry) is present, as $n$ increases, the distribution becomes more symmetric about the value of $P=Y/n$. Third, the distributions appear more continuous as $n$ increases. These observations are important because $n$ is sufficiently large, particularly when $\pi$ is near $.5$, the binomial distribution looks like the normal distribution. In that case, a normal distribution can be used to get binomial probabilities with considerably easier calculations.

A fourth point to note Figure 4.2 is that the probability of getting a value of $Y/n$ close to $\pi$ as $n$ increases. This illustrates Bernoulli's theorem in action. For example, consider the probability that $Y$ lies in the range from 4 to 6, which is, $p(4 \le Y \le 6)$ when it actually. When $n$ is 10, $p(4 \le Y \le 6)$ is the probability that $Y$ is 4, 5, or 6, which is $.2051+.2461+.2051=.6563$. When $n$ is 20, $p(4 \le Y \le 6)$ is the probability that $Y$ is 8, 9, 10, 11, or 12, which is $.1201+.1602+.1762+.1201=.7368$. When $n$ is 40, the probability is $.8461$. This is very important; it means that as $n$ grows, the proportion of A responses observed in a simple experiment is more likely to be close to the proportion of A responses in the population. We prefer larger data sets smaller ones not because of deeply ingrained ethic; we larger data sets are more likely to produce sample statistics that are closer to the corresponding parameters. Statistics that have a higher probability of being within any fixed range of the population parameter as $n$ increases are called *consistent estimators* of the parameter. We will have more to say about this desirable property of sample statistics, and about other properties important to estimation parameters, in Chapter 5.

# 4.3.3 Using Software to Compute the Binomial Function

In 4.3.1 we calculated the probability of exactly $Y$ successes out of $n$ independent trials, each with probability of success equal to $\pi$ (see Equation 4.3). We showed how Table C.1 presents specific binomial distributions for selected values of $\pi$ and $n$. The values, as well as their sums, can also be obtained with distribution calculators in software such as R. For example, in R, the probability of observing exactly $Y$ correct responses out of $n$ trials, each of which has a probability of $\pi$ occurring, is calculated by the `binom` in [stats] package. The function has three input parameters, one for $Y$ (called x), $n$ (called size), and $\pi$ (called prob). For example, `binom(x=1, size=4, prob=.05)` returns 0.17145, which when rounded to four decimal places, can verify the entry in Table C.1; Figure 4.3 shows this example.

```
> dinom(x = 1, size = 4, prob = .05)
[1] 0.17145
>|
```
