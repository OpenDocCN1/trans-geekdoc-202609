**RULE 4.** IF X and Y are independently distributed, then $E(XY) = E(X)E(Y)$. To prove this, we again begin with the definition of an expectation:

```
$E(XY) = \sum_{x} \sum_{y} xy(x,y)\n= \sum_{x} \sum_{y} xp(x)p(y)$
```

because the joint probability $p(x,y) = p(x)p(y)$ if X and Y are independently distributed. Rearranging terms

```
$E(XY) = [\Sigma xp(x)][\Sigma yp(y)] = E(X)E(Y)$
```

A useful implication of this is that $E(X - \tilde{X})(Y - \tilde{Y}) = 0$ if X and Y are independent. This follows because $E(X - \tilde{X})(Y - \tilde{Y})$ must equal $[E(X-\tilde{X})][E(Y-\rho)]=0$. Therefore, if X and Y are independent, their covariance (and consequently $ho$) must equal zero.
