Both reports include the standard error of the estimate for the regression of Y on X,

```
$s_{Y.X} = \sqrt{\frac{\sum(Y - \hat{Y})^2}{N-2}} = \frac{SS_{residual}}{N-2}} = 31.452$
```

a measure of the variability around the regression line that we discussed in Chapter 17. In the R output, this value is called "Residual standard error." As we see, the standard error of the estimate is a component of the parameter estimates we consider. As developed in Section 17.6.5, the total variability in Y scores, $SS_{YY} = \sum(Y - \bar{Y})^2$, can be partitioned into two components, the variability accounted for by the regression equation,

```
$SS_{regression} = \sum(\hat{Y} - \bar{Y})^2 = b_1^2 SS_{XX} = r^2 SS_{YY}$
```

and the variability not accounted for by the regression,

```
$SS_{residual} = \sum(Y - \hat{Y})^2 = (1 - r^{2})SS_{YY}$
```

### Table 19.2 Explanation of the ANOVA table in the regression output for bivariate regression

| SV | SS | df | F |
|---|---|---|---|
| Regression | $\sum(\hat{Y} - \bar{Y})^2 = r^2 SS_x$ | 1 | $\frac{MS_{regression}}{MS_{residual}}$ |
| Residual | $\sum(\hat{Y} - \hat{Y})^2 = (1-r^2)SS_y$ | N -2 | $\frac{MS_{regression}}{MS_{residual}}$ |
| Total | $\sum(Y - \bar{Y})^2 = SS_y$ | N -1 | |

An ANOVA table containing these terms is given in SPSS output in Figure 19.3 and detailed in Table 19.2. If you test the regression results in R then returns the same ANOVA table. In either case, $F$ is the ratio $MS_{regression}/MS_{residual}$. A significant $F$ indicates that both $r$ and $\beta_i$ are significantly different from zero; the null hypotheses $H_0: \beta_1=0$ and $H_0: \beta_2=0$ can be rejected. The $F$ can be used to test the significance of the correlation coefficient if it can be expressed as the square of $t$ that was presented in Chapter 17 or as the $t$ statistic for the null hypothesis $H_0: \beta_i=0$. Also, the $F$ can be written as the square of $t=b_i/SE(b_i)$, the test statistic for the null hypothesis $H_0: \beta_i=0$. Note that the square of the $t$ for $b_1(7.605)^2=57.836$, within rounding error, is the same as the value of $F$ in the ANOVA table.

We can use the standard errors in Equations 19.6 and 19.7 to find confidence intervals and tests about the Y intercept and slope of the regression line. For the slope of the regression, the 95% confidence interval for $\beta1$ is given by

$b_1 \pm t_{02,18}SE(b_1) = 23.92 \pm (2.101)(3.145) = 17.31, 30.53$

We can test the null hypothesis $H_0: \beta_1=\beta_{1i}$ using the test statistic

$t = \frac{b_1-\beta_{1i}}{SE(b_1)} \text{ with } N-2 \text{ df}$

If we wish to test the null hypothesis $H_0: \beta_1=0$, a two-tailed test for the slope is equivalent to the $F$ in the ANOVA table. This may be shown by squaring the expression for $t$,

$t^2 = \frac{b_1^2}{SE(b_1)^2} = \frac{b_1^2 SS_X}{SS_{Y,X}^2/SS_Y} = \frac{MS_{regression}}{MS_{residual}} = F$

Suppose we wish to test the hypothesis $H_0: \beta_1=20$ against the alternative hypothesis $H_1: \beta_1 > 20$. The value of the test statistic is

$t = \frac{23.92-20}{3.145} = 1.246$

This result is consistent with the confidence interval limits previously calculated; those informed us that a two-tailed test cannot reject any hypothesized value of the slope between 17.31 and 30.53.

If we are concerned with the Y intercept, we can find confidence intervals and test hypotheses $f^2$ as we did for the slope. For example, the 95% confidence interval for $\beta_0$ is

```
$b_0 \pm t_{02,18}SE(b_0) = 381.90 \pm (2.101)(17.227) = 345.71, 418.099$
```

We know that the test of $H_0: \beta_0 = 350$ against $H_1: \beta_0 \neq 350$ at $\alpha = .05$ will not be significant because 350 lies within the 95% confidence interval for $\beta_0$.

### 19.2.3 Power Calculations

We can use GPower*3.1 to perform *a priori* power tests for $H_0: \beta_1=0$ by entering information about $\alpha$, the desired level of power, and the effect size,$^2$

```
$f^2 = \frac{R^2}{1-R^2}$
```

Where R is the correlation coefficient. According to Cohen guidelines for regression, $f^2$ values of .02, .15, and .35 are considered "small," "medium," and "large." To run this analysis, it is helpful to view the options in the *Correlation and Regression* list of the Tests pull-down menu. Look for linear regression with a *fixed model*; the only options are for multiple regression, but we can reduce the number of predictors to 1. Next, consider the test of interest, which in this case focuses on the difference of $R^2$ from 0; selecting that option will take you to a window like the one shown in Figure 19.4. Given $f^2 = .15, \alpha = .05$, and desired power = .80, GPower*3.1 indicates that a sample of size $N = 55$ is required for a "medium" effect size with one predictor variable. Similarly, sample sizes of 395 and 25 are required to obtain power = .80 for "small" and "large" in bivariate regression.
