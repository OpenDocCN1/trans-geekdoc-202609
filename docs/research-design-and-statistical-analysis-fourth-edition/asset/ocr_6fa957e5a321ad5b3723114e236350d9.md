To do, we regress Y first on X, then on X and X^2$, then on X, X^2$, and $X^3$, and so on,
we test the increments in variability accounted for when higher-order components
added to regressions that already contain the lower-order components.

For example, consider the addition accuracy scores for grade one to five in the Royer data
that are presented in Table 22.1 and plotted in Figure 22.4. Accuracy increases with grade,
and levels off. We would expect to find both a linear trend, because the best-fitting straight
ine has a positive slope, and quadratic trend, because we have a negatively curved.
The steps in the analysis are illustrated in Table 22.1. If we regress (Y) on grade (X),
the variability accounted for by regression is $R^2_{Y}=SS_{linear}=4,690.170$. If we regress Y on
X and $X^2$, the increment is $SS_{regression}$ that results when $X^2$ is added to a regression equation
that already contains X. Similarly, if we regress Y on X, $X^2$, and $X^3$, the increment is
$SS_{regression}$ that results when $X^3$ is added to a regression equation that already contains X and $X^2$.
All of these trend components have 1 df and can be tested against the groups-within error,
$MS_{error}$. The ANOVA table in Panel b of Table 22.1 presents the results of the
tests. We expect, with $F(1, 135)=8.495, p=.004$, respectively. We should note that there are
five levels of grade, and 4 df if we treat grade as a categorical variable there, the regress-
