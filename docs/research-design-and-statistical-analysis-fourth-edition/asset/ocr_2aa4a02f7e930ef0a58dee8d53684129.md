If the treatments are *qualitatively* different from one another, we want a coding system which specifies that the treatments are different from one another without imposing any type of ordering. As we see, for a factor with $a, a-1$ predictor variables are required to be the coding. In practice, we almost never have to generate these coding variables ourselves. Rather, the statistical software does it for us in ANOVA or GLM (General Linear Model) models. Here we describe some ways of coding categorical variables because this allows greater insight into the analyses, and in some cases, allows us to better understand the options and output provided by software.

Any qualitative categorical variable can be defined by one or more dummy (indicator or code) variables that take on numerical values. These numerical values are not measures of the categorical values; rather they are best thought of as labels that collectively membership. The coding is particularly simple when a categorical variable, $A$, has only two levels (e.g., pass/fail on it). If factor A has two levels, the dummy variable $X$ could take any value at one level and any different value at the other. For the moment, these values are 1 and 2. The overall test of the regression of the dependent variable $Y$ on $X$ would be exactly equivalent to the ANOVA F test for the categorical variable, $A$.

To be specific, if we regress $Y$ on $X$, the least-squares regression line must pass through the points $(1, \hat{Y}_1)$ and $(2, \hat{Y}_2)$, as seen in Figure 23.1. This is because the regression minimizes the mean squared deviations of $Y$, and the group means minimize the mean squared deviations of each. Because the regression line passes through the two group means, it accounts for all the variance in the group means, so $SS_{regression}$ must equal the regression-variance, $SS_A$. Also, $SS_{residual}$ the variance unaccounted for the regression, must equal $SS_A$.

However, if a factor has more than two levels, the regression on a single dummy variable will not, in general, account for all of $SS_A$. Consider what if factor has three levels: *Panel a* of Table 23.1 presents scores at $A_1, A_2$, and $A_3$ of the factor A. *Panel b* of the table, we code A with a single dummy variable $X_1$, that takes on the values 1, 2, and 3. The points represent the group mean in the space defined by $X$ and $Y$ will be $(1, \hat{Y}_1), (2, \hat{Y}_2), (3, \hat{Y}_3)$, as shown in (*Panel a*) of Figure 23.2. In general, these three points will not perfectly fit by a straight line. If $Y$ is regressed on $X_1$, the regression will not account for the variance in the group means, and $SS_{regression}$ will be less than $SS_A$. However, we can account for all of $SS_A$, if we define another dummy variable, $X_2$, that is not perfectly correlated with $X_1$ – the variable that takes on the values given in *Panel b* of Table 23.1. Therefore, if $Y$ is regressed on dummy variables, the between-group variance will be accounted for by the regression, so $SS_{regression} = SS_A$ and the F test for the overall regression of $Y$ on $X_1$ and $X_2$ is exactly equivalent to the ANOVA F test for the effect of the categorical factor, A.

This reasoning can be extended to factors with more levels by adding dummy variables. In general, it will take as many dummy variables to code a factor as the number of degrees of freedom associated with it; for example, five dummy variables will be required to code a categorical variable with six levels.
