If we replace the population variances with our unbiased estimates, we have

```
$R_{adjusted}^{2} = 1 - \frac{SS_{residual}/(N-1-p)}{SS_{Y}/(N-1)}$
```

which can be rewritten as

```
$R_{adjusted}^{2} = 1 - \frac{SS_{residual}}{SS_{Y}} \frac{N-1}{N-p}$
```

But $SS_{residual}/SS_{Y} = 1 - R^{2}$, Therefore, substituting into the last equation, we have Wherry's formula,

```
$R_{adjusted}^{2} = 1-(1-R^{2})\frac{N-1}{N-p}$ (20.6)
```

The adjusted (or "shrunken") squared multiple correlation coefficient is provided in the regression output of most statistical analysis. For the regression of TC over age and BMI, Equation 20.6 yields an adjusted $R^{2}$ of $1-(.272)(180/178) = .264$. Note that if we set the adjusted $R^{2}$ to zero and solve Equation 20.6 for $R^{2}$, we get

```
$R^{2} = \frac{p}{N-1}$
```

This gives the value of $R^{2}$ for which the adjusted $R^{2}$ will be 0. Using this, we can see that if we have 10 predictors and 50 cases, an $R^{2}$ value of .204 (or multiple $R$ of .452) would correspond to an adjusted $R$ of 0. In short, unadjusted values of $R$ and $R^{2}$ could severely overestimate the strength of the relationship between Y and a set of predictors when the $N/p$ ratio is small!

If our interest is prediction, the Adjusted adjustment may not be ideal because we are interested in how a regression equation fits the population than how well the equation fits another sample drawn from the same population. Herzberg (1969) gives two adjustment equations to estimate $R^{2}$ if we want to use the regression equation developed in sample 1 to make predictions for the data of sample 2. If the predictors are random variables, as is usual in non-experimental research, the adjustment is

```
$R_{adjRP}^{2} = 1-\frac{N-1}{N-p-1}\frac{N-2}{N-p-2}\frac{N+1}{N}(1-R^{2})$ (20.7)
```

If the predictors are fixed, the adjustment is

```
$R_{adjFP}^{2} = 1-\frac{N-1}{N}\frac{N+p+1}{N-p-1}(1-R^{2})$ (20.8)
```
