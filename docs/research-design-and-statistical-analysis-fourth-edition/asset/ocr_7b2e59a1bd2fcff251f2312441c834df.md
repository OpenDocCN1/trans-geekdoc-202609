# 4.4.2 One- and Two-Tailed Tests

The test we just discussed is an example of a one-tailed or directional test. Because we were interested in whether performance was better than change, the rejection region consists of only the largest possible values of Y (the upper tail of the binomial distribution). Not all hypothesis tests are directional. There are many situations in which a departure from the null hypothesis in either direction would be of interest. For example, in the case of Roy's data on arithmetic skills (see Chapter 2), we might wish to know whether there is a significant difference in performance for addition or subtraction; if there were, it might influence the way in which these skills were taught. To test for a difference, we could assign a plus to each student who had a higher addition score and a minus to each student who had a higher subtraction score. Then we could ask whether the probability of a plus (or a minus) was significantly different from .5. A result either (i.e., addition better than subtraction or subtraction than addition) would be of interest. As another example, University of Massachusetts Medical School researchers collected data on seasonal variation in clinical states as depression and anxiety. Comparing depression scores in winter and summer, we might assign a plus if the winter score was higher, and a minus if it was lower. In both of these examples, $H_0$ would be

```
$H_0 : \pi = .5$
```

The alternative hypothesis would be

```
$H_1 : \pi \neq .5$
```

In this case, $H_0$ is nondirectional; so that we reject $H_0$ if we find evidence that $\pi$ is greater than or less than .5. We may want $\alpha$ to be .05, but then the rejection region is split in half—in the upper tail and half in the lower tail of the distribution. Turning to the column labeled $\pi=.50$, assuming equal weight is given to both directions, and that $\alpha$ is to be close to .05, $H_0$ would be rejected if $Y \leq 5$ or $Y \geq 15$. This is usually referred to as a two-tailed or nondirectional test. Note that if we use these rejection, the actual probability of a Type 1 error is .021+.021=.042. If we found Y=16, we would reject $H_0$ because the statistic falls in the rejection region. Using Table 4.2, we find $p(Y\geq16|\pi=.50)=.0040+.0011+.0020+0=.059$. But because $H_1$ is nondirectional, we must also consider equally extreme results in the lower tail of the distribution, so that the $p$-value is equal to $p(Y\geq16|\pi=.50) + p(Y\leq4|\pi=.50) = 2 \times 0.0059 = 0.0118$. The procedure we have just outlined (using the binomial distribution to test the hypothesis $H_0: \pi = .50$) is called the sign\u203 test.
