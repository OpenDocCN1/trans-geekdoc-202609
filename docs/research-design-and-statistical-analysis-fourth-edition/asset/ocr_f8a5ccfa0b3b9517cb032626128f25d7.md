# Notes

+   1 We use $\pi$ (the Greek letter pi) to represent the proportion of correct responses in the population from which the sample was selected and $p$ to represent the proportion of correct responses in the sample. We typically use Greek letters to represent population parameters and Latin letters in the sample, to reduce confusion between them. Do not confuse $p$, the proportion in the sample, with $\pi(A)$, the probability of an outcome.
2 With four trials each with two possible outcomes, the tree diagram shows $2^4 = 16$ branches. With 20 trials, there would be $2^{20} = 1,048,576$ branches.
3 Note that the trial outcomes generally need not come from the same individual. For example, each $A$ or $A$ could represent a success or failure by $n$ different participants on a single trial. Then each pattern would represent a possible set of outcomes for the $n$ subjects and $\pi$ would be the proportion of correct responses in the population from which the sample of subjects was selected. From now on, we will use the more general term combination to refer to a pattern of $A$ and $A$ responses.
