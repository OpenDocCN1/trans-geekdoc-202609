Both reports include the standard error of the estimate for the regression of Y on X,

```
$s_{Y.X} = \sqrt{\frac{\sum(Y - \hat{Y})^2}{N-2}} = \frac{SS_{residual}}{N-2}} = 31.452$
```

a measure of the variability around the regression line that we discussed in Chapter 17. In the R output, this value is called "Residual standard error." As we see, the standard error of the estimate is a component of the standard errors of most of the parameter estimates we consider in this chapter.

As developed in Section 17.6.5, the total variability in the Y scores, $SS_{YY} = \sum(Y - \bar{Y})^2$, can be partitioned into two components, the variability accounted for by the bivariate regression equation,

```
$SS_{regression} = \sum(\hat{Y} - \bar{Y})^2 = b_1^2 SS_{XX} = r^{2} SS_{YY}$
```

and the variability not accounted for by the regression,

```
$SS_{residual} = \sum(Y - \hat{Y})^2 = (1 - r^{2})SS_{YY}$
```
