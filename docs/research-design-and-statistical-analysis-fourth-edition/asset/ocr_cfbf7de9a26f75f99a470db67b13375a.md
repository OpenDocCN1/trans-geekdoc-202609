# 12.6.1 An Example of the Design

Suppose we wish to measure accuracy on five tasks of varying strength. We intend to present each task for a block of trials, recording percent correct for each block. Because a trial block requires little time to complete, we decide to present the tasks in a series of five blocks that will be a score for each participant in each trial block. We have two options with respect to the design. If we have n participants, we may construct n random sequences of the five trial blocks, assigning each participant to a sequence.
