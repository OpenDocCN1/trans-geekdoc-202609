21.5 [Planning sample size] Suppose we wish to add a seventh predictor to a regression equation and expect it to increase $R^2$ from .30 to .35. How many cases are required to have power = .90?

21.6 [Planning sample size] Find the number of cases required to yield power = .80 for a test of a medium-sized effect ($f^2 = .15$) for a predictor to be added to a regression equation already containing five predictors.

21.7 [Interpreting the contribution of a predictor] Suppose we conduct a multiple regression analysis on data from an observational study with four predictor variables and N = 40. We find that adding variable $X_4$ to the other predictors increases $R^2$ from .21 to .27. Can we reject the null hypothesis that the coefficient of variable $X_4$ has the value 0 in population? Estimate how many cases do we need to have a power of .80 to reject the null hypothesis if $\alpha = .05$.

21.8 [Testing contribution of a group of predictors] Suppose we conduct a multiple regression analysis on data from an observational study with six predictor variables and N = 80. We find that adding both $X_5$ and $X_6$ to the first four predictors increases $R^2$ from .31 to .37.

+   a) Can we reject the null hypothesis that the coefficients of $X_5$ and $X_6$ equal zero in the population at $\alpha = .05?

+   b) Estimate how many cases do we need to have a power of .90 to reject the null hypothesis if we were to rerun the study.

21.9 [Interpreting regression coefficients in real data] Consider the data set tcforwomen on the book's website. If we regress TC on schooly, a measure of years of education, we find that schooly is a significant predictor of TC, $b = 1.42$, $t(178) = -3.02$, $p = .03$; more education is associated with lower cholesterol levels. This fits well with our stereotype that more educated people take better care of themselves and have better diets. However, there may be alternate explanations for this education effect. Try to think of one or more, and explore your account(s) by using the data set.

# Note

Note that for cases 2 and 3 later, our recommended procedure for random-effects predictors produces estimates of the required sample size that are slightly too large. This is because $G^*$Power 3.1 bases the $df$ of the $F$ statistic on $N^*$ instead of $N$, and so the $df$ will be too small by $p - k$. This can be ignored unless $N$ is small and $p - k$ is large.
