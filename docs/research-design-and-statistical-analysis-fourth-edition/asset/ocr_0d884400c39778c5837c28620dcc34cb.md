We now summarize the rationale underlying hypothesis testing. We begin by assuming that chance, and chance alone, determines outcomes in an experiment. That hypothesis, called the null hypothesis, is used to generate the sampling distribution of possible outcomes. Some outcomes would be unlike if the chance-based model is valid. If one of these unlikely outcomes is obtained in the experiment, then we conclude that the model is not valid and that something else is involved.
