## RULE 2. The expectation of a constant is the constant:

$E(C) = C$

If several events have the same numerical value C, their average value will equal C.

## RULE 3. $E$ follows the distributive law and acts just like a multiplier. For example,

$E(X + Y) = E(X) + E(Y)$

To prove this, we begin with the definition of $E(X + Y)$:

```
$E(X + Y) = \sum_{x} \sum_{y} (x + y)p(x,y)$
```

when the expression on the right indicates that each possible value of $X + Y$ is multiplied by its joint probability, and these products are then summed. Distributing this expression, we obtain

```
$E(X + Y) = \sum_{x} \sum_{y} xp(x,y) + \sum_{x} \sum_{y} yp(x,y)
= \sum_{x} x \sum_{y} p(x,y) + \sum_{y} y \sum_{x} p(x,y)
= \sum_{x} xp(x) + \sum_{y} yp(y) = E(X) + E(Y)$
```

A special case of this expression occurs when one variable is replaced by a constant; then

$E(Y + C) = E(Y) + E(C) = E(Y) + C$

This equation allows us to assert that

$E(Y - \mu) = 0$

because

$E(Y - \mu) = E(Y) - \mu = \mu - \mu = 0$

Another application of Rule 3

```
$E(X + Y)^2 = E(X)^2 + E(Y)^2 + 2E(XY)$
```

This leads to a proof of the statement in Chapter 2 that the variance of $Y$, $E(Y - \mu)^2$, equals $E(Y^2) - \mu^2$:

$E(Y - \mu) = E(Y^2) + E(\mu) - 2E(Y\mu)$
$= E(Y^2) + \mu^2 - 2\mu E(Y), \quad because \mu \text{ is a constant}$
$= E(Y^2) - 2\mu^2, \quad because \mu \text{ and } E(Y) \text{ are the same entity}$
$= E(\tilde{Y}^2) - \mu^2$

**RULE 4.** IF X and Y are independently distributed, then $E(XY) = E(X)E(Y)$. To prove this, again begin with the definition of expectation:

```
$E(XY) = \sum_{x} \sum_{y} xy(x,y)$
= \sum_{x} x \sum_{y} yp(x,y)$
```

because the joint probability $p(x,y) = p(x)p(y)$ if X and Y are independently distributed. Rearranging terms

```
$E(XY) = [\sum xp(x)][\sum yp(y)] = E(X)E(Y)$
```

A useful implication of this is that $E(X - \tilde{X})(Y - \tilde{Y}) = 0$ if X and Y are independent. This follows because $E(X - \tilde{X})(Y - \tilde{Y})$ must equal zero.

## B.3 The Mean and Variance of the Binomial Distribution

Consider a series of $n$ Bernoulli trials let $X=1$ or $0$, depending upon the outcome was a success or failure; $p(X=1)=p$ and $p(X=0)=q$. The total number of successes in the $n$ trials is $Y=\sum X$. We want derive expressions for $E(Y)$ and $Var(Y)$, the mean and variance of the binomial distribution. We have

```
$E(Y) = E[\sum X] = \sum E(X) = \sum [(1)(p)+(0)(q)] = \sum p = np$
```

$Var(Y) = Var(\sum X)$

Section 2.5.2: The variance of a sum of independent variables is the sum of their variances; therefore,

$Var(Y) = Var(\sum X) = \sum Var(X)$

The variance of $X$ is $E[X-E(X)]^2 = E(X^2)-E(X)^2$; see the development under Rule 3, preceding Rule 4. We showed above that $E(X)=p$, and

```
$E(X^2) = (1^2)(p)+(0^2)(q) = p$
```

by definition of an expected value. Therefore, $Var(X)=E(X^2)-E(X)^2=p-p^2=p(1-p)=pq$. Finally, we have

```
$Var(Y) = \sum Var(X) = \sum pq = npq$
```
