# Table 14.1 Rules of Thumb for Obtaining Expected Mean Squares

+   1. Decide for each variable, including participants, whether it has fixed or random effects. Assign a letter to represent the variable (e.g., S, A, B, C) and a letter to represent the number of levels (e.g., $n, a, b, c$).

+   2. Each EMS contains $\sigma^2$.

+   3. For each EMS, for consideration all components whose subscripts include all the letters in the score under consideration. For example, for the EMS for $AB$ in Table 14.10, we would list $nc	heta^2_{AB}$, $cs\sigma^2_{SB/ABC}$, and $\sigma^2_{SB/CA}$. Note that a component has three parts:

+   a) A coefficient as $bc$ or $nac$ representing the number of scores at each level of the variable.

+   b) A $\sigma^2$ or $	heta^2$ term depending on whether the variable is assumed to have random or fixed effects.

+   c) Subscripts designating the variable under consideration.

+   4. Define essential subscripts. If there is a slash, as in $SB/A$, only those letters to the left of the slash are considered essential. For example, only $SB$ is essential in the subscript $SB/A$. (In some designs, there can be levels of nesting–e.g., students within schools; only the letters to the leftmost-most subscript are essential subscripts.)

+   5. Among the essential subscripts, if any letters that are not part of the source represent fixed effects from the expected mean square. For example, under Rule 4 we would have listed $\sigma^2_{SB/CA}$ when considering the expectation for the $AB$ source. Among the essential subscripts–$S, B$, and $C–C$ is not part of the source designation (i.e., $AB$) and does have fixed effects. Therefore $\sigma^2_{SB/CA}$ does not contribute to the $EMS$ for $AB$.

The box illustrates the rules using the $EMS$ for the $AB$ source of variance in the design of Table 14.9. As a second example, consider how the rules of thumb might be used to find $E(MS)$. First, list $\sigma^2$, because it contributes to every $EMS$. Then add every additional component of variance containing $B$, multiplying each component by its appropriate coefficient result.

```
$\sigma^2 + nac	heta^2_B + nc	heta^2_{AB} + cs\sigma^2_{SB/A} + na	heta^2_{ABC} + \sigma^2_{SB/CA}$
```

Rules 4 and 5 dictate deletion of the $nc	heta^2_{ABC}$ and $n	heta^2_{ABC}$ components once $B$ is deleted from the subscripts, we are left with $A, C$, or both; these subscripts denote fixed-effects variables. We also delete $\sigma^2_{SB/CA}$ because when $B$ we have $C$ among the essential subscripts. However, $nc	heta^2_{SB/A}$ is retained when $B$ is deleted from the essential subscripts of that component, we are left only with $S$, a subscript that denotes a random-effects variable. The result is given in the $B$ line of Table 14.9.
