# 14.6.5 Using For Quasi-F Statistics

The calculation of a quasi-F and the df for the combination of mean squares is cumbersome. Fortunately, some software packages will calculate both the quasi-F statistic and the degrees of freedom.

In SPSS, the data must be organized differently than the more conventional repeated-measures design with all fixed-effects. Rather than each participants' data appearing on a single row, similar to Table 14.12, the quasi-F analysis in requires requires each observation appear in a separate row of the data. In "long format", there is a column for each of the data (Subject, Font (A), and Item (B)), and a column for the dependent measure (e.g., RT). The file labeled FontUni contains the data of Table 14.12 in this format. To calculate $F_1$, select the General Linear Model from the Analyze pull-down menu, choose Univariate. Move RT to the Dependent Variable box, move A to the Box for Factors, and both B and S to the Box for random. Then click OK. The results will include $F_1$, and a definition of the error term for each factor in the EMS. Take care to confirm the appropriate term is used for each effect of interest: For the example data in Table 14.12, SPSS computes $F_1$ properly for A but computes another $F$ for B.

In R, the data must be in the long format, with one observation per row. We begin running the ANOVA. One option for doing is to use the aov_ev function in the [af] package, which handles the within- and between-participants factors particularly straightforward. For example, the data in FontUni (and Table 14.12) can be analyzed with this command: `aov_ev(data = data, "Subject", "RT", within = c("Font", "Item")`. Any between-between factor could be included by using the option between=$c("FactorName")$. The aov_ev function yields Greenhouse-Geisser corrected df and $p$-values by default; using the option anova_table=list("none") yields the uncorrected values. The function also reports standard F values by default, on the default assumption that all factors are fixed-effects variables. $F$ for the effect of font (factor A) must be calculated by extracting the MS terms from the output, and then applying Equation 14.4.
