A similar situation results if the effect of over stimuli. In that case, $\sigma_{AB}^2$ equals zero and $MS_{SA}$ then provides an inappropriate error term for the test of A. This suggests a preliminary test of the SA and AB terms against $MS_{SAB}$. For example, if the test of $MS_{SA}$ against $MS_{SAB}$ does not yield a significant result, we might conclude that $\sigma_{SA}^2$ is zero and tested against $MS_{AB}$.

We stated at the outset this approach is not completely satisfactory. One limitation is that the SA and AB interactions will be significant; in those instances, the approach is not applicable. Less obviously, even when a nonsignificant interaction is observed, it is possible that the preliminary test will produce a Type 2 error; we wrongly conclude that $\sigma_{AB}^2$ equals zero. In that case, the Type 1 error rate in testing A AB will be exceeded the nominal level. In studies related to this issue, Type 1 errors have ranged from .07 to .11 when the nominal value is .05 (Janky, 2000), preliminary tests to justify F tests of all orders we would prefer to avoid.

# 14.6.2 Separate Tests Against $MS_{SA}(F_A)$ and $MS_{AB}(F_B)$

A frequent approach to the problem of lacking a single mean square to use as an error term is to test two ratios: $F$ tested against $MS_{SA}$ and $MS_{AB}$ with being required on both to conclude that A has an effect. The presumed logic of this is that the test against $MS_{SA}$ allows generality to the participant population and the test item. It is true that our goal is to generalize results to both population of participants and the population of items from which we have sampled. Even if both F tests are significant, we cannot claim kind of generality. To see, suppose our null hypothesis is true (i.e., $	heta_{AB}^* = 0$) but A interacts with S and B. Then the ratio of expected means means when we test A against SA is

```
$\sigma_e^2 + \sigma_{AB}^2 + bo_{SA}^2 + \sigma_{AB}^2$\n\sigma_e^2 + \sigma_{AB}^2 + bo_{SA}^2$
```

which is greater than one. Similarly, if we test A against AB the S x A variance will spuriously inflate the F ratio. In short, even if there is no effect of A in the population, the F1 and F2 tests could be significant if A interacts with both participants and items. This would lead to the erroneous conclusion that there were main effects. A more defensive approach is to calculate an F statistic such that the ratio of means is 1 when the null hypothesis is true. We consider such a statistic.

# 14.6.3 Quasi-F (F') Tests

We have established that a test of A in the S x A x B design in Table 14,10 requires that we identify an error term whose expectation is $\sigma_e^2 + bo_{SA}^2 + n\sigma_{SB}^2 + \sigma_{AB}^2$. Given the expected mean squares of Table 14,10, no single mean square has the appropriate expected value, but we can form a combination of mean squares with the appropriate expectation that meets criterion; thus we create a quasi-F ratio whose numerator and denominator are equal if the null hypothesis is true. That ratio is:
