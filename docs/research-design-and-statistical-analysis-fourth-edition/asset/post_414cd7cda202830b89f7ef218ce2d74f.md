Here is example code to bootstrap 1,000 correlations of X and Y in a data frame called dat, saving the results in Boot.output:

```R
Boot.output <- # save the results in Boot.output
boot(data = dat
```

The resulting values are a bootstrapped sampling distribution of $r_{XY}$ stored in Boot.output. An example distribution of $r_{XY}$ is shown in Figure A18.2, with the correlation in the original sample (r = .59) marked with a solid line and the sampled correlations at the 2.5 and 97.5 percentiles denoted with dashed lines. These boundaries were identified with the boot.ci function in the [boot] package, which takes the output of boot as its input (e.g., boot.ci(Boot.output)) and returns the boundaries of a 95% CI defined in several ways. To use percentiles to define the boundaries, use option type = "perc."
