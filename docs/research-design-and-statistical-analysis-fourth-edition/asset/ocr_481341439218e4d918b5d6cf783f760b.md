# 15.2.4 Using Software for the Hierarchical Design

Several statistical packages provide analyses for designs in which one or more variables are nested within levels of other variables. For example, in R, we can use the familiar `aoov` function in the [stats] package. The function statement in `aoov` that the dependent and independent variables also specifies the structure of the design. For example, $Y - A + B$ specifies an additive model and $Y^*$ specifies a nonadditive model (factors A, B, and their interaction are included). One way to specify nested variables is to use the `%in` operator: $Y \sim S^* + B \in A$ specifies a model that includes factors S, A, and their interaction, as well as factor B, which is nested in A. Putting this together, for data in a data frame call, the command `summary(aoov(data = data, Y ~ S* + B %in% A))` will provide the ANOVA table for the nested design in Table 15.1. Note that `aoov` shows all factors are fixed, and additional calculations are required to test the main effect of A with F* (see Box 15.1).

Next, click on the Model button to build a structural model that includes them. Select the radio button labeled “Build terms,” and choose Main Effects from the.
