Having specified the structure of the sample space for the experiment, we want to use our
analysis to compute the probability of each possible value of Y. The probability distribution
of Y is obtained by using a statistical model, which is a set of assumptions about how the
responses are generated that can be used to calculate the probabilities. In the current exam-
desirable model would one capture the essential features of what we mean by
random guessing and allows us to calculate the probability of each possible value of Y. We
employ the following model for the simplified ESP experiment:

2. The responses are independent of one another; that is, the probability of a correct
