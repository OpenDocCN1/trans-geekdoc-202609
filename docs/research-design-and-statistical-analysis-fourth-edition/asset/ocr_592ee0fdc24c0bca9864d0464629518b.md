Partial F tests can also be used to test hypotheses that some of the $\beta s$ is equal to zero. Suppose, for example, we start with a model containing $p$ predictor variables

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_pX_p + \varepsilon$
```

and we add $k$ more predictor variables so that the model is now

```
$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_pX_p + \beta_{p+1}X_{p+1} + ... + \beta_{p+k}X_{p+k} + \varepsilon$
```

Again, the appropriate ANOVA is given in Table 21.1. This general approach can be used to assess the effect of adding any set of predictors to the equation and tests the hypothesis that the regression coefficients for these added predictors are all equal to zero in the population.
