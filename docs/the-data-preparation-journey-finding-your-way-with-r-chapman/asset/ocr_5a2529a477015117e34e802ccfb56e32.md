There are a variety of other approaches to defining the data rectangle in a read_excel() function, which might be more appropriate in a different context. For example, if the sheet is continually having new rows added at the bottom, using the range = anchored("B5", dim =c(NA, 4)) specification might be prefered. This will start at cell B5, then read as many rows as there are data (the “NA” inside the c() function and four columns¹.

```
df_HR_main <- 
  read_excel(
    path = dpjr::dpjr_data("cr25/cr25_human_resources.xlsx"),
    sheet = "df_HR_main",
    range = anchored("B5", dim =c(NA, 4))
  )
```
