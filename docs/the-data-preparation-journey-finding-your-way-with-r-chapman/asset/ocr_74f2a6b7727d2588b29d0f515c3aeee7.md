+   - generate a detailed record-by-record account of which records have failed our test.

First, we assign the syntax of our tests using validator() to an object “penguin_tests”.

```
penguin_tests <- validator(
  island %in% island_list,
  year >= 2007 & year <= 2009,
  body_mass_g <= 8500
)

penguin_tests
```
