The recurse = argument specifies how deep into the directory structure the diagram will be drawn. Specifying recurse = FALSE limits what is shown to the files and sub-folders within the current directory.

```
fs::dir_tree(path = "project_template", recurse = FALSE)
```

```
## project_template
## +-- data
## +-- data-raw
## +-- figs
## +-- output
## +-- readme.md
## \-- scripts
```

It’s also possible to specify how many layers, by using an integer rather than FALSE or TRUE.

```
fs::dir_tree(path = "project_template", recurse = 2)
```

```
## project_template
## +-- data
## |   \-- readme.md
## +-- data-raw
## |   +-- readme.md
## |   \-- source_data.xlsx
## +-- figs
## |   \-- readme.md
## +-- output
## |   \-- readme.md
```
