For R users, the package {forecast} has time series-oriented imputation fill functions. (Hyndman et al., 2023; Hyndman and Khandakar, 2008)

The na.interp() function from {forecast} gives us a much better way to fill the missing values in our time series than simply extending known values. This function, by default, uses a linear interpolation to calculate values between two non-missing values. Here’s a simple example:

```
x <- c(1, NA, 3)
x
```

## [1]  1 NA  3

The series from 1 to 3 has an NA value in the middle. The na.interp() function fills in the missing value.

```
forecast::na.interp(x)
```

For longer series, a similar process occurs:

```
y <- c(1, NA, NA, 3)
y
```

## [1]  1 NA NA  3

```
forecast::na.interp(y)
```

## Time Series:
## Start = 1
