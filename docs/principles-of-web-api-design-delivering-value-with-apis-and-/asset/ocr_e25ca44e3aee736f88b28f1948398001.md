It is recommended to generate human-readable documentation using a tool such as graphql-docs.^8 Be sure to offer an interactive interface using GraphQL Playground^9 to enable developers to craft requests directly in the browser before writing their integration code.

All examples provided in this chapter are based on the API workshop examples^10 available on GitHub.

#  Summary

REST is not the only API style available. RPC- and query-based APIs provide additional interaction styles that help developers integrate with an API product or platform quickly. They may also be combined with REST-based APIs to provide robust query operations for reporting and fast code generation options.

While the design process is slightly different for each API style, all styles build upon the investment of aligning the needs of business, customers, and developers. The next step in the design process is to determine if one or more asynchronous APIs would benefit the API consumer. This topic is discussed in detail in Chapter 9, “Messaging, Streaming, and Event-Based Async APIs."
