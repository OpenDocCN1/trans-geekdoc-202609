Some developers find the complexity of adopting the OData specification too much for simple APIs. However, the mixture of REST-based API design with robust query options makes OData a popular choice for larger API products and platforms.
OData has considerable support and investment from companies such as Microsoft, SAP, and Dell. The Microsoft Graph API,6 unifies the Office 365 platform under a single API, is built on OData and is an excellent example of constructing data-centric REST-based APIs with advanced query support.

+   6. Microsoft, "Overview of Microsoft Graph," June 22, 2021, https://docs.microsoft.com/en-us/graph/
