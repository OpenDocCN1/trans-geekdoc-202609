When building an API product or platform, it is important to have an API testing strategy established. Selecting the right approach for API testing contributes to the success of an API program's supportability. It also contributes to faster delivery while avoiding one of the costly aspects of software development: defect removal. Finally, it offers another perspective on the developer experience of an API because of the consumer-oriented nature of automated testing.

# Acceptance Testing

Acceptance testing, also called *solution-oriented testing*, ensures that the API supports the captured job stories. It seeks to answer the following questions:

+   - Does the API solve real problems that our customers have?
- Does it produce the desired outcomes for the jobs to be?

Acceptance testing verifies the coloration of API operations required to achieve a desired outcome. Composing acceptance tests using only the API interface to verify that the system meets all end-to-end functionality. The internals of the API can and likely change over the course of development, but this should not affect the results of the acceptance tests.

Acceptance testing is the most valuable style of testing for an API. The process of writing acceptance tests helps identify poor developer experience for a single API operation or the end-to-end integration. It is where the most testing effort should be spent, after code testing, when limited time is available.

# Automated Security Testing

Each week, a new headline indicates that a company has been hacked and private information exposed. Security is a process, not a product, and a continual one at that. Security testing aims to answer the following questions:

+   - Is the API protected against attacks?
- Does the API offer opportunities for sensitive data to be leaked?
- Is someone scraping my API and compromising business intelligence through data?

While not typically associated with automated testing, security testing is an active process that includes design-time review processes, development-time static and dynamic code analysis, and runtime monitoring.
