# REST API Design Process

Next, capture the details of each operation. For OAS v3, this begins with the path, followed by each HTTP method supported at the path. It is also recommended to to add an operationId property to each operation. Use the operation name from the API profile, defined in Chapter 6. This makes the documentation process effortless and helps to map the OAS description back to the API profile.

Using the details deatils captured in the associated job stories created in Chapter 3, “Identify Digital Capabilities,” write a short summary of the API to help readers understand its purpose. Expand the details in the design field using the information captured in the API profile in Chapter 6. Also, ensure all path parameters and query arguments are captured. This is shown in Figure 7.9.

```
paths:
  books:
    get:
      tags:
        - Books
      summary: Returns a paginated list of available books based on the search criteria
      description: Returns a paginated list of available books based on the search criteria. If no search criteria is provided, books will be returned in alphabetical order. 
      operationId: ListBooks
      parameters:
        - name: q
          in: query
          description: A query string to use for filtering books by title and description. If not provided, all available books will be listed. Note that the query argument 'q' is a common standard for general search queries
          style: form
          explode: true
          schema:
            type: string
        - name: daysSinceBookReleased
          in: query
          description: A query string to use for filtering books within the last number of days, e.g. 7 means in the last 7 days. The default value of 0 indicates no filtering is applied. Maximum number of days to filter is 30 days since today
          style: form
          explode: true
          schema:
            type: integer
            format: int32
        - name: offset
          in: query
          description: An offset from which the list of books are retrieved, where an offset of 0 means the first page of results. Default is an offset of 0
          style: form
```
