# Part IV

# Designing APIs

Now that APIs have been modeled as part of the Define phase, the team has a better understanding of the scope of each API and the operations it needs to support to realize the desired outcomes. The next phase of the Align-Define-Design-Refine (ADDR) process is to migrate the modeled API profiles into API designs.

There are many choices of API styles, from REST to RPC and beyond. This section details a step-by-step process on producing a high-level design using the artifacts created during the Align and Define phases of the process. Feel free to jump to the specific chapter needed to apply the API style of choice.
