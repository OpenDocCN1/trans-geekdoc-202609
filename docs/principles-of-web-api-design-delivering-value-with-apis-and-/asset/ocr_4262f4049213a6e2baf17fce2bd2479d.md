# API Versioning Methods

There are three popular methods of implementing API versioning: header-based, URI-based, and hostname-based versioning.

Header-based versioning places the desired version as part of the Accept header in the HTTP request (c.g., Accept: application/vnd.github.v3+json). Many consider the preferred form of versioning, as the URI remains the same across versions, and the media type defines which version of the resource representation is desired.
