# Developing a Culture of Reuse

API consumers are an essential ingredient of any program. However, many organizations focus on strategy, objectives, and governance to create APIs without addressing the need to adoption of APIs easy through discovery.

For most organizations, API documentation is an afterthought. This is unfortunate, as it leads to serious consequences for API discovery and adoption, resulting in reduced reuse of valuable APIs. Organizations implementing effective API discovery subscribe to the following mantra: Digital capabilities when possible; build them when necessary.
