# Listing 7.4 UBER Semantic Hypermedia Messaging Format

```
{
  "uber" : 
  {
    "version" : "1.0",
    "data" : 
    [
      {"rel" : ["self"], "url" : "http://example.org/},
      {"rel" : ["profile"], "url" : "http://example.org/profiles/books",
      {
        "name" : "searchBooks",
        "rel" : ["search", "collection],
        "url" : "http://example.org/books/search?q={query}\n        "templated" : "true"
      },
      {
        "id" : "book-12345",
        "rel" : ["collection", "http://example.org/rels/books],
        "url" : "http://example.org/books/12345",
        "data" : [
          "name" : "bookId",
          "value" : "12345",
          "Label" : "Book ID"
        ]
      }
    ]
  }
}
```
