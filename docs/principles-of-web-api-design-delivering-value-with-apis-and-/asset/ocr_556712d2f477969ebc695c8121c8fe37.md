# CHAPTER 8 RPC AND Query-Based API DESIGN

| Operation Type | Operation Name | Description | Request | Response |
|---|---|---|---|---||
| Query | listBooks() | List books by category or release date | query (categoryId, releaseDate) { ... } Book (categoryId, releaseDate) { ... } | Book[] | |
| Query | searchBooks() | Search for books by author, title | query (searchQuery) { ... } Book (searchQuery) { ... } | Book[] |
| Query | viewBook() | View book details | query (bookId) { ... } Book (bookId) { ... } | Book |
| Query | viewCart() | View the current cart and total | query (cart) { ... } Cart | Cart |
| Mutation | clearCart() | Remove all books from the customer's cart | query (cartId) { ... } Cart | Cart |
| Mutation | addItemToCart() | Add a book to the customer's cart | query (cartId, quantity) { ... } Cart | Cart |
| Mutation | removeItemFromCart() | Remove a book from the customer's cart | query (cartId) { ... } Cart | Cart |
| Query | getAuthorDetails() | Retrieve the details of an author | query (authorId) { ... } BookAuthor (authorId) { ... } | BookAuthor |
