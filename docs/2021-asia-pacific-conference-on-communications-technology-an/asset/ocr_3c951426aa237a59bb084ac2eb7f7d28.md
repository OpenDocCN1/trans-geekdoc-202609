When using attention, the output map of F is used as input U, and then enters the attention module, which is used with three operations:

+   1. The two-dimensional compression (H*W) of each channel is compressed to a number z by pooling the values[19]. See formula 7. It is a feature that has a global receptive field, in spatial dimension, and the number of channels unchanged after operation, which is 1 * C.

