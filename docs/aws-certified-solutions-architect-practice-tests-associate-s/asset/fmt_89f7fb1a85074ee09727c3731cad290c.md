### 101. 您已设置 CloudFront 分发，但用户未看到性能优势。可能的原因有哪些？（选择两项）
1.  用户的客户端应用程序未启用 CloudFront，因此无法获得 CloudFront 分发的优势。在其客户端应用程序中启用 CloudFront。
2.  过期时间设置过低，导致缓存不足以使用户受益。增加过期时间。
3.  您的源服务器集合太小，被来自 CloudFront 的请求淹没。考虑增加源服务器的数量或处理能力。
4.  用户距离边缘位置不够近，无法从 CloudFront 获益。

### 102. 为什么要将 CloudFront 分发的过期时间设置为 0？
1.  使所有现有边缘位置上的所有内容过期
2.  为确保最大吞吐量而确保不发生缓存
3.  降低边缘位置遭受 DDoS 攻击的几率
4.  确保始终在所有边缘位置提供最新内容

### 103. 如何从边缘位置删除文件？（选择两项）
1.  使用 AWS 控制台导航到边缘位置并删除文件。
2.  将分发的过期时间设置为 0。
3.  从源服务器中移除文件。
4.  使用 AWS CLI 从 CloudFront 分发中删除文件。

### 104. 以下步骤中，哪个顺序可以立即从边缘位置删除文件，且对现有服务中断最小？
1.  首先将 CloudFront 分发的过期时间设置为 0；然后从源服务器中移除文件。
