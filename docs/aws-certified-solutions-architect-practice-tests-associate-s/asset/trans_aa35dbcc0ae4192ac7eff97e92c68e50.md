# 290. A, C

# 291. A

# 292. C

# 293. C

# 294. A, D
首先，要意识到这些答案中的几乎任何一个都可能是更大解决方案的一部分。然而，题目询问的是最简单或最直接的解决方案。鉴于此，最佳解决方案是为实例分配公有 IP 地址 (D) 并向 VPC 添加互联网网关。您可能还需要进出的路由、安全组等。

# 295. B, C

# 296. D

# 297. B

# 298. D

# 299. D

# 300. A

# 301. A

# 302. A

# 303. A, C

# 306. A, D

# 307. B

## 领域 2：定义高性能架构

### 1. D
无法通过推理得出此题答案；这属于死记硬背的内容。在此场景下，数据复制不收取费用。

### 2. C, D
所有这些都是有效选项。虽然不太常见，但您可以在本地实例中设置只读副本。此外，只读副本通常在与主实例不同的区域中创建，以提高靠近不同区域的客户端的性能（相对于主实例而言）。

### 3. C

### 4. D
这三种数据库都支持只读副本。RDS 支持的大多数其他数据库（例如 Oracle 或 Aurora）提供其他方法来获得类似只读副本的功能，但不支持 AWS 只读副本功能。
