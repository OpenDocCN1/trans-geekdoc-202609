# 作者简介

我的资历源于一生的教学经历，即使在我未曾意识到的时候。四岁开始阅读，上小学时，我就在“编写”使用手册。我仍清晰记得五年级时整理的那本精心绘制的魔尺解法指南。

![](images/author.jpg)

高中时，我自学编程。（Turbo Pascal 是我除 Basic 之外学的第一门语言；谁还记得那本封面上有保时捷的书？）不久后，我开始给同龄人讲授编程课。毕业前，我已经在教两个不同班次的计算机课了——主要因为真正的老师喜欢午餐时喝酒，下午上课时基本都醉醺醺的！

拿到计算机科学学士学位后，我在科技行业工作，主要在电信公司。但我从未放弃最热爱的事物：我不仅是一名程序员和系统管理员。我是那个能将客户需求转化为用户故事的人。我是那个会*说话*……而且*一直说*的人。我还发现写作也是一种对话形式。我撰写了畅销技术书籍《Java and XML》，随后为 O'Reilly Media 写了其他多本书，并最终加入了该公司。

最近，我回归开发者本源，在 NASA 地球科学小组工作了近八年。从未有过如此多的时间用于教学、翻译和解释——将一群人的语言转译给另一群人，最终通过一个旗舰网站，继而通过一个庞大的全组织云平台，讲述 NASA 的故事。无论我学了多少关于 Amazon Web Services (AWS)、EC2 或 Lambda 的知识，讲故事始终是最有趣的部分；更妙的是，讲故事似乎总是最能引起客户兴趣的部分。我能用他们听得懂的方式与他们交流，这是件好事（TM）。

现在，我全职教学和讲故事。我录制 AWS 认证视频课程，编写考试备考书籍，其方式比死记硬背更有助于通过考试。我构建大大小小的网站和应用程序，大多为有自己故事要讲给用户听的客户服务。我写书记录所学，以及如何按我的方式讲故事。
