

# AWS 认证练习题

## 43. 哪种实例类型适合具有长时间运行的计算作业且无法中断，但使用模式有显著波动的应用程序？

1. Spot 实例
2. **按需实例**
3. 专用主机
4. 预留实例

## 44. 以下哪些是购买专用主机的有效方式？（选择两项。）

1. **按需按小时**
2. 预付全部费用
3. 分期付款
4. **作为预留**

## 45. 以下哪些是考虑预留实例的理由？（选择两项。）

1. 您正在运行涉及大量短期计算作业的应用程序。
2. **您正在运行具有稳态使用的应用程序。**
3. **您的业务保证至少在未来 18 个月内需要云计算。**
4. 您希望将对 AWS 的承诺降至最低。

## 46. 以下哪项不是考虑 Spot 实例的理由？

1. 您的应用程序具有灵活的开始和结束时间。
2. 您的应用程序只有在计算成本因 CPU 利用率而低时才能运行。
3. 您预计会有大量的计算需求，并可能需要大量额外容量。
4. **您预计晚间使用量会大幅增加，并需要支持该使用量。**

## 47. 您受邀向一个组织介绍云。他们有几个适合云托管的应用程序，但不想做任何预先承诺。此外，他们担心云“不可靠”，因此您需要确保应用程序平稳运行。您会推荐哪种实例类型？

1. Spot 实例
2. **按需实例**
3. 专用主机
4. 预留实例

## 48. 以下哪些是 Spot 实例的优势？（选择两项。）

2. **与按需定价相比，成本降低。**
3. 同一硬件将在应用程序的整个生命周期中使用。
4. **它们可以毫无问题地处理使用高峰。**
