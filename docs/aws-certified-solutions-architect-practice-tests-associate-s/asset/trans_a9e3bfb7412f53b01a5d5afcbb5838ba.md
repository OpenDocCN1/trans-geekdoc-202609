## 问题 196
您想要添加一小组位于与主开发办公室不同区域的开发人员。您将如何处理向该新区域扩展用户和权限？

1.  在第二个区域中创建新用户。
2.  在主区域中创建新用户，然后将它们复制到新区域。
3.  在主区域中创建新用户，设置 IAM 复制，然后将正确的权限应用到新区域中的复制用户。
4.  创建新用户，它们将应用于所有区域。

## 问题 197
为确保您的策略文档能在整个组织和 AWS 资源集中扩展，您需要考虑什么？

1.  确保每个策略都有一个在其适用区域内唯一的名称。
2.  确保每个策略文档都具有 `region: *` 属性，以便其应用于所有区域。
3.  无需任何操作，策略文档会自动适用于账户内的所有 AWS 资源。
4.  创建策略文档时，确保选择“避免区域冲突”选项。
