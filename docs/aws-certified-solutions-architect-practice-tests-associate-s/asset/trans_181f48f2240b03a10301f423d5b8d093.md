1.  为 NAT 实例的安全组添加一条允许流量出站到互联网的规则
2.  将 NAT 实例设置为使用带有预置 IOPS 的 EBS 卷
3.  将包含 EC2 实例的子网上的 NACL 设置为允许来自互联网的入站流量
4.  确保 NAT 实例上的**源/目标检查**选项已禁用

## 26. 你正在致力于提高一个应用程序的性能，该程序每天晚上美国东部时间下午 6 点到 8 点之间例行出现流量高峰。那时，即使有 Auto Scaling 策略，负载增加得如此之快，以至于响应时间慢得像爬行一样。在仅知道这些流量激增信息的情况下，如何能最轻松、最高效地确保你的应用程序能应对这些激增？

1.  在 Auto Scaling 组中设置较低的缩容阈值；考虑从 50% 开始。
2.  每天晚上 7:30 登录并手动扩展应用程序。
3.  在应用程序上设置 CloudWatch 监控。编写一个触发扩容的 Lambda 函数。将 Lambda 函数连接到 CloudWatch 监控并设置触发阈值。
4.  设置计划扩缩容，使应用程序在每晚 7:45 扩容，在 8:30 缩容。
