## 8. 关于 NAT 实例和 NAT 网关，以下哪些陈述是错误的？（选择两项。）

1.  NAT 实例和 NAT 网关都是高可用的。
2.  创建 NAT 网关时必须选择实例类型和大小，但创建 NAT 实例时不需要。
3.  修补 NAT 实例是你的责任，而修补 NAT 网关是 AWS 的责任。
4.  你可以向 NAT 实例分配安全组，但不能向 NAT 网关分配。

## 9. 以下哪项陈述是正确的？

3.  安全组是无状态的。
4.  允许进入 NACL 的流量会自动被允许流出。

## 11. 以下哪项陈述是正确的？

## 13. 如何启用 EBS 卷的加密？

1.  使用带有 `aws security` 命令的 AWS CLI。
2.  对 EBS 卷创建快照并将其复制到加密的 S3 存储桶。
3.  创建 EBS 卷时选择加密选项。
4.  使用已挂载 EBS 卷的 EC2 实例的操作系统加密工具对卷进行加密。

## 15. 关于安全组，以下哪些说法是正确的？（选择两项。）

1.  你可以指定拒绝规则，但不能指定允许规则。
2.  默认情况下，安全组包含一条允许所有出站流量的出站规则。

4.  安全组是无状态的。

## 16. 关于安全组，以下哪些说法是不正确的？（选择两项。）

1.  允许规则优先于拒绝规则。
2.  对允许的入站流量的响应被允许流回出站。
3.  你可以为入站和出站流量指定特定的单独规则。
4.  如果没有出站规则，则允许所有出站流量流出。
