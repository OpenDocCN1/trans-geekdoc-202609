## 89. 你是设计数据库驱动应用套件的架构师。作为项目的一部分，你需要将一个大型 Oracle 数据库实例迁移到云中。此外，你正在从 Oracle 迁移到 PostgreSQL。如何以最少的支出最有效地完成此迁移？

1.  将 Oracle 数据复制到 `Snowball`，将数据发送到 AWS，移入 `S3`，然后导入到 `RDS` 中的 PostgreSQL。
2.  在 AWS 中创建一个 `RDS` Oracle 实例，将数据从现有 Oracle 实例迁移到新的 `RDS` 实例，然后将 `RDS` 实例转换为 PostgreSQL。
3.  使用 `Database Migration Service` 将 Oracle 数据直接导入新的 PostgreSQL 实例。
4.  在本地创建一个 PostgreSQL 实例，在本地将数据从 Oracle 迁移到 PostgreSQL，然后将 PostgreSQL 实例移入 AWS。
