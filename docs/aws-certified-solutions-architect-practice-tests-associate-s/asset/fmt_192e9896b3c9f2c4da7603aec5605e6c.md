## 12. 你在上一个 DevOps 冲刺中花费了数天时间构建了一个 AMI，开发团队的应用程序所有实例都应基于此 AMI。该应用程序将部署到多个区域并与多个 S3 存储桶交互，你现在需要在 `us-east-2` 和 `us-west-2` 中也提供该新 AMI，除了创建 AMI 的 `us-east-1` 区域外。如何使新 AMI 在 `us-east-2` 和 `us-west-2` 中可用？

1.  **将 AMI 从 `us-east-1` 复制到 `us-east-2` 和 `us-west-2`。使用复制的 AMI 启动新实例。**
2.  确保所有应用程序实例共享一个安全组。AMI 对安全组内的所有实例可用，无论 AMI 在哪个区域创建。
3.  你可以立即启动 AMI，因为所有 AMI 都通过 AWS 控制台出现在所有区域中。
4.  将 AMI 从 `us-east-1` 复制到 `us-east-2` 和 `us-west-2`。应用启动权限和 S3 存储桶权限，然后使用更新后的 AMI 启动新实例。

## 17. 你终止了一个 EC2 实例，发现附加在该实例上的 EBS 根卷也被删除了。如何纠正此问题？

1.  你无法纠正。根卷在附加的 EC2 实例被删除时总是会被删除。
2.  在 EC2 实例运行时对 EBS 卷进行快照。然后，当 EC2 实例终止时，你可以从快照恢复 EBS 卷。
3.  从 EC2 实例中移除终止保护。
4.  **使用 AWS CLI 将 EBS 卷的 `DeleteOnTermination` 属性更改为 “false”。**
