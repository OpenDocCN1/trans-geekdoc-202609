## VPC 对等连接

### 29. 以下关于对等 VPC 的陈述哪项是正确的？

1. 两个 VPC 需要位于同一区域。
2. 两个 VPC 需要位于同一 AWS 账户中。
3. 每个 VPC 必须使用唯一的安全组。
4. **两个 VPC 不能有重叠的 CIDR 块。**

### 30. VPC 对等连接是什么类型的关系？

1. 子网之间的一对一关系
2. **VPC 之间的一对一关系**
3. 子网之间的一对多关系
4. VPC 之间的一对多关系

### 31. VPC A 同时与 VPC B 和 VPC C 对等。如何允许流量从 VPC B 流向 VPC C？

1. **无法实现；AWS 不允许传递性对等关系。**
2. 必须在 VPC A 中启用路由转发。
3. 必须将 VPC B 与 VPC C 对等。
4. 必须在 VPC B 上启用路由转发。

### 32. VPC C 与 VPC D 具有重叠的 CIDR 块。基于此，以下哪些陈述是正确的？（选择两项。）

1. VPC C 和 VPC D 可以直接建立对等连接。
2. **VPC C 和 VPC D 无法直接建立对等连接。**
3. **要使 VPC C 和 VPC D 对等，必须消除其 CIDR 块中的重叠部分。**
4. 要使 VPC C 和 VPC D 对等，必须将其中一个切换为使用 IPv6 地址。

### 33. 两个 VPC 之间允许多少个对等连接？

1. **一个**
2. 两个
3. 每个 VPC 中的每个子网一个
4. 与每个 VPC 关联的每个 NACL 一个

### 34. 单个 VPC 可以参与多少个对等连接？

1. 一个
2. **无限制，在 AWS 总体账户限制范围内**
3. 每个 VPC 中的每个子网一个
4. 与每个 VPC 关联的每个 NACL 一个

### 35. AWS 如何促进传递性对等 VPC 关系？

1. 仅当使用堡垒主机时才允许传递性 VPC 关系。
2. 仅当使用中心辐射型网络模型时才允许传递性 VPC 关系。
3. **AWS 不支持；AWS 中不允许传递性 VPC 对等连接。**
4. 它使用 IPv4 从源 VPC 连接到中心 VPC，使用 IPv6 从中心连接到源 VPC。

### 36. AWS 如何在 VPC 对等关系中支持 IPv6 通信？（选择两项。）

1. AWS 不支持 VPC 对等连接中的 IPv6 通信。
2. **必须为两个 VPC 关联 IPv6 地址，然后设置路由以使用这些地址。**
3. 必须为两个 VPC 关联 IPv6 地址，然后设置安全组以使用这些地址。
4. **必须确保两个 VPC 位于同一区域。**
