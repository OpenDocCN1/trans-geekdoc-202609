2. 上传大对象以减少与这些对象相关的入站流量成本
3. **在不稳定的网络上上传任意大小的文件以提高弹性**
4. 上传必须追加到现有文件的文件

## 62. 预签名 URL 与普通 URL 有何不同？（可多选）

1. **预签名 URL 具有由 URL 创建者提供的、与特定对象关联的权限。**
2. 预签名 URL 具有由 URL 使用者提供的、与特定对象关联的权限。
3. **预签名 URL 允许在不需要 AWS 凭证的情况下访问私有 S3 存储桶。**
4. 预签名 URL 包含作为 URL 一部分的加密凭证。

## 66. 以下哪种行为符合 S3 处理存储桶对象操作的方式？

3. 进程删除一个对象并立即列出存储桶中的键。S3 返回的列表包含已删除的对象。

## 77. 什么是 AWS Storage Gateway？

1. 驻留在客户站点的设备，作为本地站点与 AWS 之间 VPN 连接的一部分
2. 使本地站点能比通过公共互联网更快地将文件上传到 S3 的设备
3. 促进大量数据迁移到 S3 的设备
4. **可用于在本地站点缓存 S3 存储对象的设备**

## 78. 关于 AWS Storage Gateway，以下哪项陈述不正确？

1. 它是一个虚拟设备。
2. **它既作为物理设备也作为虚拟设备提供。**
3. 它在客户站点本地缓存数据。
4. 它与 S3 存储桶交互。
