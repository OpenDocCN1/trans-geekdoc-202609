## 34. 您希望为 S3 对象存储中的数据提供最大保护，防止意外删除。您应该采取哪些步骤？（选择两项。）

## 35. 您希望在 US East 1 区域的 S3 存储桶上启用 MFA Delete。在启用 MFA Delete 之前，您必须采取什么步骤？

3. 将存储桶移动到支持 MFA Delete 的区域，例如 US West 1。
4. 在您想要启用 MFA Delete 的存储桶上启用版本控制。

## 39. AWS Trusted Advisor 可能会提出以下哪些建议？（选择两项。）

4. 将 NAT 实例更新为 NAT 网关。

## 40. 以下哪项无法使用 IAM 策略实现？

3. 禁用组中用户的 S3 访问权限
4. 将对 EC2 实例的 SSH 访问限制为特定用户

## 41. 关于 S3 加密，以下哪些说法是不正确的？（选择两项。）

1. 启用服务端加密时，S3 对数据应用 AWS-256 加密。
2. 如果随数据提供了客户端密钥，S3 加密将使用该客户端密钥。
3. 仅当启用服务端加密时，才能存储加密的 EBS 卷。
4. 如果启用了客户端加密，S3 将接受本地加密的数据。

## 42. 当您创建加密的 EBS 卷时，哪些类型的数据会被加密？（选择两项。）

1. 卷内静态数据
2. 卷与附加实例之间移动的数据
3. 存储加密实例的 S3 存储桶内的数据
4. 附加到该卷的实例上 EFS 中的数据

## 43. 当您创建加密的 EBS 卷时，哪些类型的数据**不会**自动加密？（选择两项。）

1. 从 EBS 卷创建的快照
2. 附加到与加密卷相同实例上的其他卷上的任何数据
3. 在附加了加密卷的实例上创建的数据
4. 卷与附加实例之间移动的数据

## 44. 当加密的 EBS 卷附加到 EC2 实例时，以下哪种类型的数据**不会**自动加密？

1. 传输到卷的数据
2. 卷上的静态数据
3. 从卷传输出的数据
4. 所有这些都已加密。

## 45. 加密的 EBS 卷使用哪种加密服务？

1. S3-KMS
2. S3-C
3. KMS
4. 客户托管密钥

## 47. 如果您对加密的 EBS 卷创建快照，以下哪项将为真？（选择两项。）

## 49. 如何加密 RDS 实例？

1. 通过 CLI 在正在运行的实例上启用加密。
2. 通过控制台在正在运行的实例上启用加密。
3. 通过控制台在正在运行的实例上运行加密过程。
4. 在创建实例时启用加密。

## 50. 以下哪项将确保 RDS 实例上的数据被加密？

1. 使用客户端加密密钥。
2. 通过 AWS API 在正在运行的 RDS 实例上启用加密。
3. 加密 RDS 运行所在的实例。
4. 这些都无法加密实例上的所有数据。

## 51. 以下哪项将允许您将未加密的 RDS 实例纳入“所有数据必须静态加密”策略的合规范围？

1. 对 RDS 实例创建快照并在恢复时对新副本进行加密。
2. 使用 AWS Database Migration Service 将数据从该实例迁移到加密实例。
3. 创建一个新的加密实例并手动将数据移入其中。
4. 这些都无法加密实例上的所有数据。

## 52. 以下哪项将允许您将未加密的 EBS 卷纳入“所有数据必须静态加密”策略的合规范围？

1. 停止卷，对其创建快照，并加密快照的副本。然后从加密快照恢复。
2. 停止卷，选择“开启加密”，然后重启卷。
3. 通过 AWS API 加密卷并开启“加密现有数据”标志。
4. 这些都无法加密卷上的所有数据。

## 53. 以下哪项将允许您将未加密的 EBS 卷纳入“所有数据必须静态加密”策略的合规范围？

1. 停止卷，创建快照，并从快照重启，选择“加密此卷”。
2. 停止卷，选择“开启加密”，然后重启卷。
3. 通过 AWS API 加密卷并开启“加密现有数据”标志。
4. 这些都无法加密卷上的所有数据。

## 54. 以下哪项将允许您将未加密的 EBS 卷纳入“所有数据必须静态加密”策略的合规范围？

1. 创建一个新卷，将新卷附加到 EC2 实例，将数据从未加密卷复制到新卷，然后加密新卷。
2. 创建一个开启加密的新卷，将新卷附加到 EC2 实例，并将数据从未加密卷复制到新卷。
3. 创建一个新卷，将新卷附加到 EC2 实例，并使用 encrypted-copy 命令将数据从未加密卷复制到新卷。
4. 这些都无法加密卷上的所有数据。
