

# 57. 以下哪些是基于容器的应用程序和基于 Lambda 的应用程序之间的区别？（选择两项。）

1. 容器根据负载和使用情况进行扩展；Lambda 根据事件进行扩展。
2. 容器运行在底层计算实例上；Lambda 代码不运行在底层计算实例上。
3. 容器的可扩展性不如 Lambda 高。
4. 容器可以运行整个应用程序堆栈；Lambda 只能运行隔离的代码块。

### 1. 您负责优化电影流媒体网站的性能。目前，您正在处理搜索功能，发现每当搜索标题库数据库时，数据库负载都会达到峰值。您当前的架构由一个运行在超大实例上的 PostgreSQL 数据库组成。您将如何更新架构以更好地处理负载？（选择两项。）

1. 使用预置 IOPS 的 EBS 卷作为卷类型，在更大的实例上重新创建数据库实例。
2. 添加 RDS Multi-AZ 部署以提高媒体库数据库的读取性能。
3. 添加 ElastiCache 存储来缓存数据，因为搜索通常会在多次读取中返回通用数据。
4. 将数据库分片为安装在多个实例上的多个副本。

### 4. 您加入了一个拥有 20 多个不同 AWS 账户的新组织。您的任务是改善组织的成本管理，并希望推荐使用 AWS Organizations 和合并账单功能。以下哪些是合并账单的优势，可用于支持您的建议？（选择两项。）

1. 多个账户可以合并，通过这种组合，获得可能降低所有账户总成本的折扣。
2. 如果这些账户都在 AWS Organizations 中，账户之间的流量将不收取数据传输费用。
3. AWS Organizations 中的所有账户在合并账单中将获得 5% 的账单减免。
4. 所有账户都可以单独跟踪，也可以通过单一工具进行跟踪。

### 5. 您的任务是改善最近开始使用云的组织的安全性。该组织有五名开发人员、一名财务经理和两名支持工程师。目前，所有八名员工都在使用 AWS 根用户进行操作。您会做出哪些更改来提高安全性？（选择两项。）

1. 让所有用户下载 AWS CLI 并更改根密码。
2. 为八名员工中的每一位创建一个新的 IAM 用户，并向每位用户提供凭证。
3. 将五名开发人员放入 Power Users 组，将财务经理放入 Billing 组，将支持工程师放入 Support User 组。
4. 创建一个具有 IAM 服务访问权限的新组，并确保至少有一名开发人员在该组中。

### 7. 您负责一个大型 AWS 环境，特别是自定义 VPC 中的几个子网。该 VPC 包含公有子网和私有子网。一个私有子网中大约有 300 个 EC2 实例，它们使用 NAT 设备访问互联网。每天晚上 11 点，实例将当天的数据推送到 AWS 外部的外部数据存储，该存储可通过互联网访问的 API 访问。但是，您发现并非所有数据都能在每天晚上传出，并且有几个实例显示向外部 API 传输失败。假设 API 本身没有问题，在尝试修复此问题时应考虑什么？（选择两项。）

1. 实例使 VPC 的互联网网关饱和。考虑向 VPC 连接额外的互联网网关。
2. NAT 设备可能是一个实例规格太小、无法处理流量的 NAT 实例。在具有更多 CPU 的更大实例规格上重新预置 NAT 实例。
3. 设置一个 SQS 队列，将所有所需的传输作为队列中的条目。让 EC2 实例轮询队列并传输数据，直到队列完全清空。添加一个 Lambda 作业来检测失败的传输，并将失败的操作重新添加到 SQS 队列中。
4. 实例无法支持所需的吞吐量。重新预置实例以使用预置 IOPS 的 EBS 卷作为卷类型。

### 12. 您正在排查一个包含两个子网的自定义 VPC。一个子网包含数据库实例，无法从互联网访问。另一个子网运行 Web 服务器的 EC2 实例。这些实例分配了带有公有 IP 地址的弹性网络接口。但是，您无法从互联网访问这些实例，它们也无法访问互联网资源。什么可能导致这些问题？（选择两项。）

1. 实例需要使用公有 IP 地址，但不需要弹性网络接口。移除弹性网络接口。
2. VPC 需要一个互联网网关。连接互联网网关并更新 VPC 的路由表，通过互联网网关路由来自实例的互联网流量。
3. 实例因被分配的默认安全组而无法访问互联网。向该组添加允许出站互联网流量的权限。
4. 更新包含 EC2 实例的子网的 NACL，以允许入站 HTTP 和 HTTPS 流量到达公有子网中的 EC2 实例。
