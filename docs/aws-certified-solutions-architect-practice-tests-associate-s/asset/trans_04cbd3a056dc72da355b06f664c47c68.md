### 171. 就 IAM 角色而言，什么是高级用户访问权限？

1. AWS 对根用户的称呼
2. 所有 IAM 用户都被视为高级用户。
3. 一种用户类型，拥有对所有 AWS 服务和资源的完全访问权限，但不具备用户组或用户管理权限
4. 可以访问应用程序部署配置文件的用户

### 172. 以下哪项是根用户**无法**执行的？

1. 创建用户。
2. 移除用户对控制台的访问权限。
3. 删除角色。
4. 根用户可以执行所有这些操作。

### 173. 以下哪项是高级用户**无法**执行的？

1. 创建用户。
2. 创建新的 SNS 主题。
3. 停止由其他用户创建的正在运行的 EC2 实例。
4. 高级用户可以执行所有这些操作。

### 174. 处理根用户访问密钥的最佳实践是以下哪项？

1. 仅将它们存储在实例受保护的 `.aws/` 目录中。
2. **删除它们**，改用不同用户的 IAM 凭证。
3. 仅将它们用于 API 访问，但避免控制台访问。
4. 当它们与 S3 关联使用时，启用 MFA Delete。
