# 12.1 INTRODUCTION

The presence of unwanted particles in the atmosphere, as water droplets, fog, and haze [24], makes it very difficult to get a clear image in an outdoor scene. The image becomes unclear because of the absorption and scattering of lights by these atmospheric particles. As a result, sometimes the contrast of images taken outside reduced and their visibility may also be affected. This, in turn, can cause a major problem in different areas like photography, surveillance, navigation, and monitoring systems. Therefore, some measures to remove fog or haze have become an important concern in commercial as well as scientific applications. Here, we focus on removing haze, which occurs due to the presence of water droplets in the atmosphere.

It can generally be described as the union of airlight, where airlight occurs when light gets scattered and reflected back. The following model is used to describe the hazy image formation:

```
I(x) = J(x) * t(x) + A * (1-t(x)) (12.1)
```

where the input hazy image is $I(x)$, $t(x)$ is the transparency ranging from 0 to 1, $A$ is the airlight, and $J(x)$ is the color of the image. The transmission factor $t(x)$ decreases with increasing depth, which is expressed as:

```
t(x) = e^(-beta * d(x)) (12.2)
```

where $\beta$ stands for the scattering coefficient and $d(x)$ is the scene depth.

The technique which is used to recover the original image from the hazy image is called dehazing. The conventional technique to remove haze involves two steps: first to remove airlight and second to recover the lost information by image. Basically, dehazing methods can be classified into two categories: multiple image-based dehazing methods and single image-based dehazing methods. Some relevant work based on machine learning and image processing are described in [4, 31, 40]. Multiple image-based methods require multiple images of the same scene to execute, whereas single image-based methods need only one image to carry out the process.

Multiple image-based methods can be extended into the following categories: A weather-condition-based method [21, 25] which depends on the variation of the same image taken during different weather conditions. Although this method can enhance visibility, it cannot work for dynamic images. For the polarization-based method [29, 30], multiple images having different polarization filters are considered. This polarization filter can be adjusted by the attached polarization filter present in the camera. The limitation with this method is that it cannot work properly when the haze is thick or dense. Similarly for the map-based method [14, 23], some depth information [29, 30] is used to dehaze an image. This works on a 3D model, and the appearance of the input scene depth gives and helps in removing haze from the image. This technique needs user interaction, that is, not automatic.

To cope with the limitation of the multiple image-based method, single image-based methods are used: the Contrast Maximization method [35], which helps in enhancing the contrast of the input hazy image. The output images will have a large value of saturation as the proposed method only enhances visibility but does not improve the overall.
