## 3.2 背景

### 3.2.1 通用 OCR 阶段

通常，完整的 OCR 过程分为多个阶段。图像采集是任何计算机视觉应用的第一步也是关键的一步。对于字符识别，通过平板扫描仪捕捉图像。也可以使用强大的手机摄像头获取文档的数字图像，但这需要额外的处理。在图像采集后，通过预处理步骤去除已知错误。图像增强、去噪、倾斜检测与修正、页面分割、二值化和字体检测是 OCR 模型中使用的若干预处理方法。分割是分离行、单词和字符的过程，在手写和触摸式字符识别中对确定识别准确率具有更高的意义。每个分离的字符都被输入到模型中以确定类别标签。模型可以通过各种学习和分类方法以及特征匹配模型（特征+模板）推导出。识别出字符类别后，必须将相应的 ASCII 或 Unicode 代码写入文本文件。在此阶段，同时处理单词和行的分离至关重要。从分割步骤获得的信息在此处文中使用，尽管识别过程可能无法产生预期结果。标点和错误的存在可能导致某些不必要的字符，这可以通过后字典匹配和上下文信息来解决。通用模型的概述如图 3.2 所示。

### 3.2.2 结构相似性

人眼关注图像的结构而非亮度和对比。SSIM [47] 通过给图像质量一个类似于人类主观评价的值来解释这一点。这在公式 3.1 和 3.2 中用数学表达式表示。SSIM 的整体展示如图 3.3 所示。

```
$SSIM = [l(x,y)]^c [c(x,y)]^c [s(x,y)]^c \quad (3.1)$
```

其中 $s$ 代表结构，$c$ 代表对比，$l$ 代表局部亮度。该表达式与人类视觉系统相关，通过取 $a = \beta = \gamma = 1$ 可以简化为：

```
$SSIM = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)} \quad (3.2)$
```

其中 $C_1 = (K_1 L)^2，$C_2 = (K_2 L)^2，$L$ 代表最高强度。$K_1$ 和 $K_2$ 的值通过哲学研究计算，并分别设置为 0.01 和 0.03。

SSIM 在结构域而非误差域评估图像。因此，对于每个模板，目标图像的分数不同。它的范围从 0 到 1，较高的值表示匹配良好。实验观察到，211 类字符的识别性能非常对于
