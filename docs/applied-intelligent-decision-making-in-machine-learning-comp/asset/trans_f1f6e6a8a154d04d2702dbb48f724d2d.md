### 4.2.5.2.2 局部 DE/BBO

通过局部拓扑结构对 BBO 进行改进。DE/BBO 结合局部拓扑被认为是混合 BBO 的可靠预测器，它分为三类：RingDB、SquareDB 和 RandDB。RingDB 包含环形拓扑，而 SquareDB 和 RandDB 分别对应方形拓扑和随机拓扑（Zheng 等，2019）。这种局部算法在函数维度上比 DE/BBO 更有效。

```
DE mutation = u_i(d) = Hr2(d) + F * (Hr2(d) - Hr3(d)) (4.5)
```

### 4.2.5.2.3 自适应 DE/BBO

自适应 DE/BBO 是 DE 的升级形式，该模型的主要功能是处理多个变异并选择合适的。合适的变异在函数分析中非常有效。从初始值获取信息的通用方法为：

```
V = V + t/t_max * (V_max - V_min) (4.6)
```

其中 $t$ 是当前值，$max$ 是最大值，$min$ 是算法的最小值。

迁移概率估计为：

```
P_k(G) = \frac{S_k(G)}{\sum_{k\in S} S_k(G)} (4.7)
```

在 HSDB 中，我们将 $F_{\mu}$ 设置为 0.5，$F_{\sigma}$ 设置为 0.3，并将 $F$ 的值限制在 $[0.05, 0.95]$ 范围内：

### 4.2.6 模型验证

为了验证训练数据集，考虑了带有受者工作特征（ROC）曲线的 AUC 值以获得真实结果。在这里，ROC 曲线的值能够预测最佳模型。科学计算为：

```
$S_{AUC} = \sum_{k=1}^n (X_{k+1} - X_k) \left( \frac{S_k + S_{k+1}}{2} \right) (12)
```

$S_{AUC}$ 被视为特异性，$S_k$ 是弹性。

## 4.3 结果与讨论

### 4.3.1 因素对滑坡发生的影响

在进行初步分析之后，利用频率比法评估了所有成因因素及其相关子因素的重要性。在距离方面，确认高权重位于 0 到 4619.772 (1.033) 之间以及 4619.772 到 9349.540 (1.272) 之间。对于地质，高重要性与花岗岩（1.243）和变质岩（1.080）有关。对于地貌，高重要性与冰川湖和角冰山（8.704）、中度切割的丘陵和山谷（1.083）以及河流/水体有关。对于岩性，高重要性与石英岩（7.588）、糜棱岩（3.442）和片麻岩（3.789）有关。对于土地利用类型（LULC），高重要性与荒地（1.502）、建筑区（1.404）和水体（2.068）有关。对于土壤质地，高重要性与：粘土骨质土（1.169）、细粘质河流土（1.305）、粗粘质腐殖土（1.106）、细粘质旱土（1.260）和钙盐土（1.458）有关。对于坡向，高重要性与东南（1.159）、西南（1.335）、东北（1.039）和正北（1.064）有关。对于滑坡点而言，最近距离如 0-629.755 米（1.377）利于滑坡发生。极高排水密度 1.371–2.106（1.613）利于滑坡发生。对于海拔，高重要性与 272–1165 米（1.103）、1165–1180 米（1.087）以及 2561–3453 米（1.149）有关。对于护岸密度，高重要性与 0.0170–0.049 平方公里（1.237）有关，这对于滑坡发生是非常乐观的。对于 NDVI，高重要性与 -0.357 到 -0.071（1.184）、-0.071 到 0.143（2.048）以及 0.143 到 0.400（1.294）有关。这里，NDVI 低值意味着滑坡发生概率较高。对于平面曲率，高重要性与 -1.645（1.105）、-0.488 到 0.436（1.053）以及 1.593 到 -13.390（1.021）有关。对于剖曲率，高重要性与 -16.123 到 -2.106（1.396）有关。
