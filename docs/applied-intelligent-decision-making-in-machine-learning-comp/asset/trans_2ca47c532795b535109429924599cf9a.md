# 12.1 引言

大气中存在的不良颗粒、雾、雾霾 [24]，这使得图像变得模糊。由于光的吸收和散射，在摄影、监控等系统等领域产生了一个大问题。因此，消除这些雾的措施在商业和科学应用中都变得非常重要。

# 230 机器学习中的应用决策

它通常被描述为光反射时产生的空气结合。以下模型用于描述雾图像的形成：

```
I(x) = J(x) * t(x) + A * (1-t(x))
```

其中雾图像为 $I(x)$，$t(x)$ 是范围从0到1的透明度，$A$ 是空气光，$J(x)$ 是图像的颜色。传输因子 $t(x)$ 随深度增加而减小，表示为：

```
t(x) = e^(-beta * d(x))
```

其中 $\beta$ 代表散射系数，$d(x)$ 是场景深度。

从雾图中恢复图像的技术被称为去雾。传统的去雾技术包括两个步骤：首先消除空气光，其次恢复丢失的信息。基本上，去雾方法分为两类：多图像去雾方法和单图像去雾方法。基于机器学习的相关工作见 [4, 31, 40]。

多图像去雾方法需要多个场景图像来执行，而单图像去雾方法只需要一张图像。

多图像去雾方法可以扩展为以下类别：基于天气条件的方法 [21, 25]，它取决于在不同天气下拍摄的同一图像。虽然这种方法可以提高可见度，但并不适用于动态图像。对于偏振方法 [29, 30]，考虑了具有不同偏振滤镜的多幅图像。偏振滤镜可以通过相机上附的偏振滤镜进行调整。该方法的局限性是当雾厚或浓密运行时无法正常运行。同样对于基于地图的方法 [14, 23]，使用了一些深度信息来去雾图像。这种方法在3D模型上运行，输入的场景深度提供了并有助于消除图像中的雾。这种技术需要用户交互，即不是自动的。

为了应对多图像去雾方法的局限性，使用了单图像去雾方法：对比度最大化方法 [35]，它有助于增强输入雾图像的对比度。输出图像将具有较大的饱和度，因为所提方法仅提高了可见度而没有改善整体。
