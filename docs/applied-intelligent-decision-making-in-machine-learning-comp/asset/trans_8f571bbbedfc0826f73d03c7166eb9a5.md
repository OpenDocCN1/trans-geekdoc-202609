## 2.4.6 与标准鸢尾花（IRIS）数据集的对比

机器学习模型（LDA 和 kNN）使用用户编码算法（算法 2.2 和 2.3）的性能，以及相应的“黑盒”方法（现有的软件包），在针对鸢尾花、大豆蚜和杂草物种的估计中，产生了具有可比性的结果（见表 2.5）。在准确率和 F 分数（使用召回率和精确率计算）性能参数之间，选择准确率进行比较，因为所有三个数据集在类别分布上都是平衡的。除了准确率外，还考虑了计算过程时间来比较模型和方法的性能。使用 `caret` 包中的 R 函数 `train()` 来进行 LDA 和 kNN 模型的开发。用于鸢尾花数据集的 LDA 和 kNN 方法表现良好，使用用户编码算法的准确率分别为 98% 和 96%，使用黑盒方法分别为 100% 和 93%。由于数据点呈正态分布（p = 0.08），LDA 在鸢尾花数据集上略优于 kNN。

尽管 LDA 具有正态性，但 kNN 也被用于比较。正如预期的，对于大豆蚜数据集，无论使用用户编码算法还是黑盒方法，LDA 的表现（92%）均优于 kNN（84%）。两种方法的准确率在大豆蚜数据集上是一致的。同样，在没有正态性的杂草物种数据集上采用 kNN 方法中，也测试了 LDA 方法的性能。因为 kNN 的表现（用户编码 90%，黑盒 92%）优于 LDA（用户编码 81%，黑盒 79%）。LDA 的用户编码算法在大豆蚜和杂草物种数据集上产生了更好或相当的准确率，而用户编码的 kNN 则在鸢尾花和大豆蚜上产生了更好或相当的准确率。

用户编码算法和黑盒方法的另一个重要性能参数是用中央处理器（CPU）时间（秒）衡量的计算过程时间，该时间是通过 R 语言的 `Sys()` 函数记录的。通过恰当放置系统时间函数，并在代码块之后捕获开始和结束时间，就可以评估开发、训练或评估整个过程中的特定代码块的 CPU 时间。由于 KNN 是一种基于实例的学习器，没有训练阶段，因此在用户编码算法中，KNN 的计算时间平均比 LDA 减少了 42%。然而，这种 CPU 时间缩短的趋势仅在用户编码算法中中被观察到，而对于黑盒方法，KNN 的时间始终高于 LDA，平均增加了 29%。此外，还可以观察到，用户编码算法的 CPU 时间始终比黑盒方法的 LDA 平均低了 35%，比 kNN 平均低了 94%。这一有趣的结果可能是由于用户编码方法采取了更直接的方法，而黑盒方法存在相关的开销。这种用户编码方法性能的提升在大型数据集上将产生更大的影响，并支持了开发自定义用户编码算法而非黑盒方法的合理性。

## 2.5 结论
