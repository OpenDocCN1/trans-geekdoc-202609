## 6.3 DATASET DESCRIPTIONS

The dataset is a collection of pollutants for eight places, namely Tirupati, Vishakhapatnam, Gaya, Velachery, Ahmedabad, BTM Layout, Nagpur, and Agra in India. The data is taken from the Central Pollution Control Board (CPCB) (2019), which records data every 15 minutes from various air stations located in different states in India. For a particular place and year, the daily values of these pollutants have been recorded. The recorded data in the CPCB website consists of various parameters among which the pollutant parameters are chosen and air quality index is identified. Details about the pollutant parameters are given in Section 6.4.

To add the control measures in place, the administration of India has also implemented sources to measure and record air pollution data. The sources include: the Centre for Geographic Analysis (CGA), which is maintained by Harvard University; the Central Pollution Control Board (Ministry of Environment, India); the Central Pollution Control Board Ministry of Environment (Historical Ambient AQI); the World AQI Project; the Delhi Pollution Control Committee, and the EPoD India-Air Pollution and Health Project.

The data was consolidated for the years 2016–2018. The pollutant parameters are included PM2₂, SO₂, CO, and O₃. The pre-processing involves handling missing values and identifying outliers:

- Missing values in the data are imputed with the overall mean value.

## Forecasting Air Quality in India

Year-wise data is consolidated and three clustering algorithms, namely hierarchical clustering, fuzzy C clustering, and K-means, are applied. For each set of data, the optimal number of clusters was determined to be two, using the elbow method. The overall procedure for weighted ensemble graph clustering is:

1. The air pollution dataset is loaded.

4. The outliers are identified and replaced with the mean value.
5. Similarly, the missing values in the data will be imputed with the mean value.
6. In the final pre-processing step, the data for the various regions in India are consolidated, based on the year.
