# 12.4 PROPOSED METHODOLOGY

The proposed algorithm is explained in the following steps:

+   1. Initially, a hazy image is taken as an input image.
2. The white balancing procedure, as given in Algorithm 12.1, is applied to the hazy image so as to adjust the color of the input image with reference to a white color, so as to make the image look more natural.
3. To improve the visibility of the hazy image, CLAHE procedure, as given in Algorithm 12.2, is applied to the white balanced image. In this procedure, the image is divided into non-overlapping blocks, and a histogram of each block is calculated. After that a clip limit is chosen to clip the parts of the histogram that are exceeding the limit.
4. Finally, the histogram of every region is bounded with bilinear interpolation and image gray-scale values are changed according to the new histograms.
5. Due to clipping of the histogram in CLAHE, some of the information of the image may get lost. For GF, a guidance image $(l)$ is considered, using which the filtering process is done.
6. The mean of $(l)$, of the CLAHE output $(p)$, and the mean of $(I \times p)$ is calculated.
7. Co-variance of $(I,p)$ is calculated as

```
$cov\_Ip = mean\_Ip - mean\_I.*mean\_p \quad (12.8)$
```

8. The variance of $(I)$ is obtained to get linear coefficients $a$ and $b$ using:

```
$var\_I = mean\_II - mean\_l.*mean\_l \quad (12.9)$
```

9. The values of $a$ and $b$ are important to get the final result, which can be obtained by:

```
$a = (cov\_Ip)/(var\_I + \epsilon) \quad (12.10)$
```

```
$b = mean\_p - a*mean\_l \quad (12.11)$
```

where $\epsilon$ is the regularizing parameter.
The mean of $a$ and $b$ is calculated and the final output of the image, i.e., $q$, is obtained as:

```
$q = mean\_a.*I + mean\_b \quad (12.12)$
```
