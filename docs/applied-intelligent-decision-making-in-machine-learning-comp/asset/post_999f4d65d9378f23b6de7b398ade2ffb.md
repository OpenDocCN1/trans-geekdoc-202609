## 11.4 PROPOSED MODEL

In this section, the working method of the FSTLO approach is presented with a detailed explanation. In this approach, the algorithm starts by random initial population generation (both for the teacher and students). The population is the set of binary solutions, which helps to select or reject the features, based on the value 1 or 0. Here, we have inculcated this teaching-learning-based optimization technique along the concept of a wrapper FS technique. The underlying concept in wrapper-based feature-subset selection is that it randomly selects a set of features among all the features in the original dataset. Over several iterations, it chooses different sets and evaluates the fitness for individual selection. The one with maximum fitness is chosen and selected as the feature. There are three types of wrapper-selection techniques, forward selection, backward selection, and bidirectional elimination. After implementing the wrapper-selection technique along teaching-learning optimization, performance is evaluated. The overall methodology includes the following steps:

(1) the data is collected from different sources;
(2) this raw data contains a lot of inconsistencies, and irrelevant and null values;
(3) the redundant data are removed by FS methods. Here we have used the wrapper-selection method, hence converting the higher dimensional data to lower dimensional data and removing unnecessary information. The mathematical reason behind this is to extract the significant features that have the maximum correlation with the prediction variable.
(4) Then we apply our classification method and evaluate the accuracy and precision value.

The detailed working of the FSTLB method for finding the optimal features will now be described. This is a two-phase process, such as teacher and student, in which the teacher trains the students. Let us use the dataset $X=\{X_1, X_2, \dots, X_m, D\}$, where $D$ is the dimensions (subjects) of the problem and $i = 1, 2, 3, \dots m$ is the number of instances. Initially, a random population is generated and combined with the training data to generate the new feature set. The fitness (error) of the newly constructed feature set is computed by using a classification algorithm. Here, the KNN algorithm is used for computation of the fitness with the value of $k=5$. This fitness is to be minimized to increase the performance of the model.

In the teacher phase, the individual having the minimum fitness is treated as the teacher. The teacher tries to increase the performance of the students by sharing its knowledge. The knowledge of the student is updated by based on the difference between the student's fitness and the teacher's fitness. The student's fitness is updated by:

$X_{student} = X_{student} + w \times (X_{teacher} - X_{student})$

where $w$ is a learning rate between 0 and 1. This process is repeated for all students in the population. After all students are updated, the teacher is updated by selecting the student with the best fitness. This process is repeated for several iterations until the stopping criterion is met.

In the student phase, the students interact with each other to improve their knowledge. The knowledge of each student is updated based on the difference between its fitness and another student's fitness. The student's fitness is updated by:

$X_{student} = X_{student} + w \times (X_{other} - X_{student})$

where $w$ is a learning rate between 0 and 1. This process is repeated for all students in the population. After all students are updated, the teacher is updated by selecting the student with the best fitness. This process is repeated for several iterations until the stopping criterion is met.
