## 2.3.5.3 Embedded Methods

The embedded method of feature selection learns the features that contribute the most to the accuracy of the model. These methods are also known as the regularization or penalization methods, where the coefficients of irrelevant features are penalized and removed from the model. Some of the examples of the regularization algorithms are Lasso (Li et al., 2006), elastic net (Zou and Hastie, 2005), and ridge regression (Engleman, 2011).

Among these feature selection methods, the Relief algorithm, which is mathematically straightforward, provides a measure of the influence for features, and can deal with multi-classes in the output variable. Moreover, it is the only feature selection method that is capable of detecting the feature dependencies using the simplest nearest neighbor approach (Urbanowicz et al., 2018). The Relief algorithm was chosen for feature selection in the two considered agricultural applications.

## 2.3.5.4 Relief Algorithms

The Relief algorithm is a family of three algorithms, such as basic Relief, ReliefFF, and RReliefF. The basic Relief algorithm can only handle the classification of two classes; ReliefFF, which is an extension of basic Relief, can handle multi-classes that are categorical, only the RReliefF can handle continuous regression classes. All three algorithms have the same underlying mechanism. This chapter details classification with ML for a dataset containing multi-classes, only the RReliefF method was appropriate. However, to follow the algorithm working principle, a manual example using the basic Relief for binary class data is demonstrated in this section since the main demonstration using ReliefFF for multi-classes is tedious. Studies detailing the Relief algorithm can be found elsewhere (Kononenko, 1994; Robnik-Sikona and Kononenko, 2003).

The pseudocode (Algorithm 2.1) decodes the basic Relief algorithm. Weights are initialized to zero for all the features in the data. The Relief algorithm identifies the two nearest neighbor, hit (H) and miss (M), using Manhattan distance (rectilinear distance as sum of projections) instead of Euclidean distance as the direct line distance between points) calculated between the selected instance (R) and the other instances in the data. The H refers to the instance that belongs to the same class and at the least distance to the random instance. The M refers to the instance that belongs to a different class and at the nearest instance to the random instance. The weight revisions are divided by the number of iterations (z) to normalize the weights between -1 +1. As a rule of thumb, z is calculated as the square root value of the total number of observations in the dataset (n).

## Algorithm 2.1 The pseudocode of the basic Relief algorithm

```
1: procedure BASIC_RELIEF(dataset)
2:   W[Fj] = 0
3:   ξ = √π
4:   for (i to z) do
5:     select a random instance (Ri)
6:     find nearest hit (H) and nearest miss (M)
7:     for (1 to j) do
8:       W[Fj] = W[Fj] - diff(Fj, Ri,H) + z*diff(Fj, Ri, M)/z
9:     end
10:  end for
11: end procedure
while,
  diff(Fj, Ri,H) = |value(Fj, Ri) - value(Fj, H)| / max(Fj) - min(Fj)
  diff(Fj, Ri,M) = |value(Fj, Ri) - value(Fj, M)| / max(Fj) - min(Fj);
```

where, Fj, are the different features in the data set: Fj = F1, F2, ..., Fn.

The idea of revising the weights with H and M is based on the dissimilarity of the random instance and the random instance indicates that the features separate two instances belonging to the same class, which is not desirable; however, the weights are decreased. A significant difference between the nearest miss and the random instance implies that the features separate two instances belonging to different classes, is desirable; therefore, the weights are increased.

The following R program developed and based on the decoded Relief algorithm (Algorithm 2.1) estimates the weights of the features as outcomes (Figure 2.4). For comparison, the direct black-box approach was also used as an illustration. These weights are further used to determine the most significant features.

For demonstration (Figure 2.4), consider a sample dataset with 20 total observations (n = 20), two classes (classes 1 and 2), and five instances (R1, R2, ... Rn). The Relief algorithm is employed to this sample dataset to determine the most influential features, among F1, F2, and Fn, ranked according to the weights used in classifying the dataset in classes 1 and 2.

The features producing the highest weights are considered to be the most influential. In the case of sample data, the feature ranked the highest, based on is F4(0.93), followed by F1(0.60) and F3(-0.50), respectively. The feature ranking using the in-built (black-box) function attrEval(), under the R package CORElearn developed and based on the Relief algorithm, produced different weights (Figure 2.4).

Therefore, in ML, the available labeled datasets are partitioned into training and testing datasets. The training data subset is used to train the ML model by recognizing the pattern in the dataset and the relationship between the features and their class labels, while the testing dataset, which serves as a proxy to the new data in the future, is used to estimate the generalization quality of the ML model (prediction accuracy) beyond the training dataset (Das et al., 2020c).

There are different splitting methods, such as random sampling, trial-and-error, cross-validation, systematic sampling, and stratified sampling. Among these methods, the simple random sampling is as easy to use and implement; however, the simple random sampling works efficiently for datasets that have uniform distribution (Reitmana, 2010). The Kolmogorov-Smirnov test conducted, using the R function ks.test(), revealed that most of the features selected from the datasets of soybean aphids, weed species, and iris were uniformly distributed (p > 0.01), making dataset subsetting valid for analysis. Therefore, in this simple random sampling method was used to select the data for training and testing from the original dataset.

Random sampling was performed using the R function createDataPartition() under the caret package. The split ratio of the dataset for training and testing usually is in the range of 60-90% and 40–10%; respectively. The split ratio is selected based on the prediction accuracy of the ML classifier using the validation data. The iris dataset used to demonstrate the working of the function createDataPartition() in splitting the original dataset into training and testing subset.

## 2.3.7 The ML Methods

The major categories of ML classification are unsupervised and supervised algorithms. Unsupervised ML performs classification on the unlabeled data (only input variables and no output variables with identified labels passed to the algorithm). The unsupervised algorithm learns the underlying structure and distribution in the data and clusters them as groups (e.g., clustering and association), while the supervised ML performs classification and regression tasks on the labeled data (input variables and labeled output variables passed to the algorithm), which helps the models to understand the relation between the input and output variables (Das et al., 2015, 2018).
