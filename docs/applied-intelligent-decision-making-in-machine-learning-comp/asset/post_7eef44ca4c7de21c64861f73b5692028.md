
After the shuffling process, the frog with the worst fitness of the whole population substituted by the best solution searched by PSO, which aids the population to evolve more efficiently.

### 7.4.1 SHUFFLED FROG-LEAPING ALGORITHM AND PARTICLE SWARM OPTIMIZATION (SFLA-PSO)

The Shuffled Frog-Leaping Algorithm (SFLA) is a recent evolutionary algorithm (EA) or meta-heuristic algorithm proposed by Eussuf and Lansey in 2003. It is a combination algorithm of both social behavior PSO and genetic-based mimetic algorithm. A population of NP frogs represents the initial solution. Individual solution $X_i$ is represented by Z dimensional vector $x_i = (x_{i1}, x_{i2}, ..., x_{iZ})$ where $i \in \{1, 2, ..., NP\}$. Evaluation of the objective function of each frog is defined, and according to their fitness value frogs are arranged in decreasing order. The whole population is divided into m number of memplexes. This is a totally cyclic type of activity where the first frog goes to the first memplex; the second frog goes to the second memplex, ..., the mth frog goes to the m memplex, and the m + 1th frog goes to the first memplex [18]. While searching for food, communication between frogs occurs in two ways, either as inter-cluster or intra-cluster. Intra-cluster communication is also called local exploration, and inter-cluster communication is called global communication [19]. The frog with the best fitness is denoted $x_b$ and the worst $x_w$ according to its fitness value. During the evolution process the frog having the worst fitness updates its position so that it can move towards an optimal solution.

```
$Z = r*(x_0 - x_w)
```

```
$x_{w(update)} = x_w + Z_i \leq Z_{max}
```

Here $r$ represents a random number that varies between 0 and 1, $Z_{max}$ is the maximum length to consider for the frog's position, and $x_{w(new)}$ gets an update with respect to the old value of $x_{w(old)}$. If there is no improvement then $x_w$ remains constant and is replaced by randomly generated solutions. Each memplex follows $L_{max}$ number of iterations after the shuffling is carried out.

Kennedy and Eberhart [2005] proposed a population-based optimization algorithm. Each population consists of NP particles called a swarm. The position and value of the ith position are represented in dimension Z, which determines the search space. The position value is represented as $x_i = (x_{i1}, x_{i2}, \dots, x_{iz})$ and the velocity value is represented as $v_i = (v_{i1}, v_{i2}, \dots, v_{iz})$. The objective function is the main criterion for evaluating the performance of each particle. The particle's previously visited position is represented as $p_i = (p_{i1}, p_{i2}, \dots, p_{ic})$ and the best previous position of each individual swarm is represented as $p_g = (p_{g1}, p_{g2}, \dots, p_{gc})$. Let "itr" be the iteration number. So the swarm velocity can be represented as:

```
$v_i^{itr+1} = w * v_i^{itr} + c_1 * r_1 * (p_i^{itr} - x_i^{itr}) + c_2 * r_2 * (p_g^{itr} - x_i^{itr})
```

```
$x_i^{itr+1} = x_i^{itr} + v_i^{itr+1}
```

where $i$ is $1, 2, 3, \dots,$ NP, $w$ is the inertia weight within the range (0, 1), $c_1, c_2$ represent constants and learning factors, and $r_1, r_2$ represents a random number varying between (0, 1). Equation (7.3) represents the velocity (new) calculated from the previous velocity and the distance between the best and current position of the particles within the population.

Equation (7.4) presents a new position if the particle changes its position in the population. The value of $w$ (local exploration) can be computed as:

```
$w = 0.4 + 0.5 * \frac{itrmax - itr}{itr}
```

where $itr$ represents the current iteration number and $itmax$ represents the number of iterations allowed.

### 7.4.2 THE ADVANTAGE OF SFLA

SFLA is a very simple algorithmic structure because it has less controlling parameters, but it suffers from limitations: the population searching decreases; the worst solution is updated instead of the best; and the convergence speed of the algorithm is very slow. To avoid the limitations of basic SFLA by improving frog mapping size the search learning coefficient (S) is used to change the movement of the frog during a local search. The rule of leaping the frog is:

```
$x_w (new) = x_w + stp
```

```
$stp = \varphi * stp^{-1} + S * rand()*(x_w - x_w) - Stp_{max} \leq stp \leq Stp_{max}
```

$stp$ represents step $t$ at instance of the frog step's previous position iteration, $\varphi$ represents the inertia required to balance the search process. The value $\varphi$ decreases repeatedly from greater to smaller.

Binary shuffled-frog leaping encoding (0/1) is used for the presence and absence of the frog respectively. Each frog has two basic components such as velocity and position. The position of the frog gets updated with respect to its position and the position of the other frogs. The updated frog position is changed into a continuous value, and frogs are sorted into their fitness value. Accordingly, the whole population is divided into memplexes and the updating of the frog in the inter-cluster occurs throughout the population.

### 7.4.3 ALGORITHM FOR BSFLA-PSO

For this algorithm, we considered the parameters of population size (200), number of iterations (500), and step size (0.1).

- Step 1: Initialize the population with random solutions.
- Step 2: Evaluate the fitness of each solution.
- Step 3: Divide the population into memplexes.
- Step 4: For each memplex, perform local search using SFLA.
- Step 5: Perform global search using PSO.
- Step 6: Update the population with the best solutions.
- Step 7: Repeat until the stopping criterion is met.
