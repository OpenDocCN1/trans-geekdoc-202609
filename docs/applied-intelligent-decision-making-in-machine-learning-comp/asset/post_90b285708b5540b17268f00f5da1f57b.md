GRU network has memory blocks in the place of neurons. These blocks contain gates that decide which hidden state value must choose. The recurrent networks take inputs sequentially and transform them into machine-readable vectors, while the previous output of the hidden state acts as a memory. Input and the previous hidden state are fed into the network and activated using sigmoid and tanh activation functions, which give outputs between 0 and 1 from sigmoid, and -1 and 1 from tanh. $r_t=\sigma\left(W_r\cdot x_t+U_r\cdot h_{t-1}+b_r\right) \quad (10.2)$

Now, to change the current memory content, activated aggregate calculation $a$, is carried out using previous information and the current input data. In this step, the input data $x_t$, and the product of the hidden state data and the value of the reset gate are multiplied with the corresponding weight variables $W_a$ and $U_a$. The obtained result is then activated using the hyperbolic tangent (tanh) activation function:

$$\tanh\left(\frac{e^x-e^{-x}}{e^x+e^{-x}}\right)$$

$a_t=\tanh\left(W_a\cdot x_t+U_a\cdot h_{t-1}+b_a\right) \quad (10.3)$

Finally, the memory or the hidden state data is changed with the help of the above calculated results:

$h_t=(1-z_t)\cdot h_{t-1}+z_t\cdot a_t \quad (10.4)$

The calculated $h_t$ of this work states the memory or previous state data $(h_{t-1})$ for the next state. # 10.2.1 Performance Measure

We employ the Mean Absolute Percentage Error (MAPE), the Root Mean Square Error (RMSE), the Coefficient of Determination ($R^2$), Average Relative Variance (ARV), Theil's U, and Directional Accuracy (DA) to evaluate the performance characteristics of the proposed neural network models as follows:

$MAPE=\frac{1}{n}\sum\frac{|A-P|}{|A|}\cdot 100 \quad (10.5)$

$RMSE=\sqrt{\frac{1}{n}\sum(A-P)^2}} \quad (10.6)$

Where $A$ is the actual value, $P$ is the predicted value, and $n$ is the number of the predictions carried out. The values of MAPE and RMSE are greater than zero, and the closer the result is to zero, the more accurate will be the performance.

Another equation we apply for the performance measure is the coefficient of determination, denoted by $R^2$ and as “R-squared.” This is the proportion calculated from actual and predicted variables:

```
$$\bar{A} = \frac{1}{n} \sum_{i=1}^{n} A_i$$
$$ss_{tot} = \sum_{i} (A_i - \bar{A})^2$$
$$ss_{res} = \sum_{i} (A_i - P_i)^2$$
$$R^2 = 1 - \frac{ss_{res}}{ss_{tot}}$$ (10.7)
```

where $A$ and $P$ are actual and predicted variables, $\bar{A}$ is the mean of $A$, and $ss_{tot}$ and $ss_{res}$ are the total sum of squares and the residual sum of squares. The value of $R^2$ lies between 0 and 1, and the closest to 1 is the more accurate.

```
$DA = \frac{100}{n} \sum_{i=1}^{n} d_i \text{ where } d_i = \begin{cases} 1, & (P_i - P_{i-1})(A_i - A_{i-1}) \geq 0 \\ 0, & \text{otherwise} \end{cases}$ (10.8)
```

where $d_i$, is the direction accuracy, $P_i$ and $A_i$, are the predicted data and actual data. This measures the number of correct decisions made when forecasting whether the next values will increase or decrease during the subsequent steps. The values of DA fall between 0 and 100; the closer the values are to 100, the more accurate the prediction of the model. Performance-measuring approach is more important to the model. # 10.2.2 DATA PREPARATION

The historical exchange rates data downloaded from The Forecast Center (www.forecasts.org), for 1570 daily samples of five currencies (the Australian dollar (AUD), the British pound (GBP), the Canadian dollar (CAD), the Indian rupee (INR), and the Japanese yen (JPY) against US dollar (USD), were obtained over the period 2012 to 2018. The daily samples were normalized in the range of [0, 1], dividing each value by the maximum value. The input patterns and the corresponding output values are extracted by using the concept of sliding window size, one step at a time. N number of patterns equal to (N-W+1). In this feature extraction technique, the number of input variables (or the size of the extracted column) is taken similarly to the size of sliding windows, in which the first column of the extracted dataset starts from the first index, the second column starts from the second index, and so on. The generated pattern to input model is further divided into two datasets; the first 80% of samples are used for training purposes and the remaining 20% for testing.
