# A Multi-Stage Hybrid Model for Odia Compound Character Recognition

# 3.3 PROPOSED METHOD

The proposed prediction model consists of three stages. The first phase uses SSIM based template matching to reduce the number of possible prediction labels to 20. These probable character classes are further reduced to ten based on their geometrical. In this stage, we used projection profile matching to match the similar characters geometrically. The final prediction of character is performed in the last stage by a machine learning approach. We employed LFD features and GRNN to predict the final class. The overall block diagram of the proposed three-stage hybrid model is depicted in Figure 3.7. Each stage of the model is described in Algorithms 3.1 to 3.3.

# **Algorithm 3.1:** Stage I detection algorithm

```
**Data:** Template images $\{I_1, I_2, \dots, I_m\}$ and Test character image $(T)$ in preprocessed format
**Result:** Best 20 probable characters
**for** $I_k \leftarrow \{I_1, I_2, \dots, I_m\}$ **do**
	Resize $I_k$ and $T$ to $60 \times 60$;
	$S_k \leftarrow SSIM(I_k, T)$;
**end**
Return 20 character classes that have maximum $S_k$
```
