

## 机器学习中类智能决策的应用

![](img/d1bf16e7dc1fe5d49ee33c2dfa5cdb06_134_0.png)

**图 6.5** 二次函数 $y(x)=x(1-x)$。

我们使用公式 6.5 添加了一个平滑项，通过确保权重值不等于 0 来避免不稳定性。

```
w_i = \frac{W_j + e}{1 + e} \quad (6.5)
```

其中在我们的实验中将 0.01 这样的小正数作为 $e$。结果是 $w_i \in [0,1]$。每个聚类的权重分配是通过公式 6.6 给出的二值 Jaccard 度量计算的，该度量提供了 $C_i$ 和 $C_j$ 之间对象交集大小与并集大小之间的相似比例，以及相关的权重。

```
S_{ij} = \frac{\sum_{x_k \in C_i \cap C_j} w_k}{\sum_{x_k \in C_i \cup C_j} w_k} \quad (6.6)
```

从图 6.6 所示，聚类对之间的权重给出：

```
S_{ij} = \frac{3 \times 0.8 + 0.2 + 0.6}{4 \times (0.8 + 0.2) + 0.4 + 0.6} = 0.64
```

其中第 $k$ 个对象表示为 $w_k$，$S_{ij}$ 根据公式 6.2–6.5 计算得出，$S_{ij} \in [0,1]$。如果 $S_{ij}=0$，则图 G 中 $C_i$ 和 $C_j$ 之间没有边。$S_{ij}$ 是相似性度量，我们用它将元图划分为 $k^*$ 元聚类。采用的划分算法是 METIS，它由 Karypis 和 Kumar (1998) 开发。METIS 的输出是根据对象在每个聚类中的参与比例将每个对象分配到一个元聚类。最后，将对象分配给具有最高比例的聚类。从聚类相似性矩阵找到最佳聚类数量为三个。METIS 函数将此作为输入。接下来的章节将解释 METIS 结果的样本输出。

### 6.4.1 最终聚类标记

METIS 函数以元组的形式给出两个输出。第一个是被最小化的目标值，第二个是划分索引列表。我们的方法关注于集成聚类，这涉及分配对象权重，我们用这些权重来确定聚类权重，并将其转换为邻接列表，METIS 函数将其作为输入。划分索引列表的输出给为了获得最终类别标签而必须合并的二进制表示列。一旦合并了这些列，就会对它们的值进行比较，并根据最终的投票值分配聚类。

### 6.4.2 METIS 函数

与各种谱划分算法相比，METIS 算法已知在图划分方面能产生好 10%–50% 的结果（Karypis 和 Kumar 1998）。它是用于稀疏矩阵排序、有限元划分以及图划分的系列程序。多约束划分、多级划分和多级递归二分方案构成了 METIS 实现的基础，在划分无向图中方向性不起任何作用。这是因为如果边 (u, v) 被切割，边 (v, u) 也会被切割。为了让 METIS 划分有向图，首先需要通过添加 (v, u) 将其转换为无向图。

### 6.4.2.1 METIS 算法

- 给定图 G = (N, E, EW)
- 其中节点或顶点由 N 表示；
- 边由 E 表示；
- 权重由 EW 表示
- 其中 N 代表聚类，E 中的边 (j, k) 意味着对象 j 与对象 k 有关。
