tagged patterns are generated collectively for every single entity and sequence of entities. For matrix calculation, every POS tag is assigned with a different value, as shown in Table 8.1. The frequency of each pattern among the different pattern sets of gold annotations are then ascertained. For obtaining frequent pattern sets, a user-defined minimum threshold greater than or equal to 2 is required. These different frequent pattern sets are then applied as elements for the trained matrix.
The trained matrix has $k$ number of pattern sets, where every row represents one pattern set. The shortest and shortest pattern length are $maxl$ and $min$, respectively. In $a(M \times N)$, $\alpha$ is a trained matrix, $M$ is $k$ (number of pattern sets), and $N$ is $maxl$. When the location of the elements is lacking, “0” is entered in the columns of the matrix.

# 8.3.2.3 Test Matrix Formation

The test matrix $\langle\beta\rangle$ is created using test data for every file independently. POS tagged test data with assigned value is applied to the matrix. The number of rows and columns are the same as the trained matrix $\alpha$. Every complete sentence in its converted form is passed to the matrix, which changes dynamically at the entrance of every new sentence after comparison with the trained matrix.
