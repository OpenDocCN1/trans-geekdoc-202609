## 2.3.3 SHAPE FEATURES EXTRACTION

Shape features are dimensionless parameters, which are not affected by image resolution, and were used as measures in classifying objects. Image offers four shape features, such as aspect ratio, circularity, roundness, and solidity (Equations (2.1)–(2.4)), along with various other measurements. Those measurements were used for deriving other shape features reported in the literature (Igathinathe et al., 2008; Sunoj et al., 2017; Di and Sun, 2004) and are presented as follows (Equations (2.5)–(2.13)):

$$Aspect ratio = \frac{a}{b} (2.1)$$

$$Circularity = \frac{4\pi A}{P^2} (2.2)$$

$$Roundness = \frac{4}{\pi} (2.3)$$

$$Solidity = \frac{A}{H} (2.4)$$

$$Reciprocal = \frac{b}{a} (2.5)$$

$$Rectangularity = \frac{A}{P} (2.6)$$

$$Diameter = \frac{P}{\pi} (2.7)$$

$$Eccentricity = \sqrt{1 - \frac{b^2}{a^2}} (2.8)$$

$$Area = \frac{P^2} (2.9)$$

$$Hollowness = 1 - \frac{A}{H} (2.10)$$

$$Ratio = \frac{A}{W} (2.11)$$

$$Shape = \frac{A}{L} (2.12)$$

$$Value = \frac{A}{C} (2.13)$$

## 2.3.4 DATA CLEANING

Cleaning the dataset is essential because ML models are sensitive to noise, outliers, and incomplete data (Chu et al., 2016). On average, about 60% of the time is spent on cleaning, filtering, and editing the data to make it easier to explore, understand, and model.

The common steps involve:
- Checking for missing values.
- Replacing missing values.
- Oitting incomplete records.
- Modifying data types into the appropriate format.

In R, the presence of missing values was checked using `is.na()` and `is.nan()`. If present, the user may choose to replace the data with a specified value (e.g., 0) or omit it using `na.omit()`. Once the data is cleaned, it is desirable to convert data types using `as.numeric()`, `as.integer()`, `as.character()`, or `as.factor()`.

## 2.3.5 Feature Selection

Datasets considered for ML modeling consist of features (predictor variables) and an outcome (dependent variable). Most only a group of features are relevant, while the remaining are irrelevant. Developing ML models using all available features results in computational burden and reduced accuracy. Therefore, relevant features must be carefully identified and selected to build the models while discarding others.

Feature selection is often confused with dimensionality reduction. Both methods seek to reduce the number of features or attributes in the dataset. However, dimensionality reduction achieves this by creating new combinations of all features (Das et al., 2020a), while feature selection methods the irrelevant features which are less useful in predicting the outcome. In general, fewer relevant features are desirable since they produce simpler and more cost-effective models. Feature selection methods can be classified into three general methods: filter, wrapper, and embedded methods.

### 2.3.5.1 Filter Methods

The filter method of feature selection assigns a score to each feature in the dataset by applying statistical information and correlation measure. The features are ranked based on the score, which implies the order of the output variable. The features are either selected or discarded based on the rank. Some examples of filter methods are information gain (Joachims, 1998), chi-square test (Jin et al., 2006), and Relief (Kira and Rendell, 1992).
