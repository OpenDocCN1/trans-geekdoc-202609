# 6.5.3 DAVIES-BOULDIN INDEX

The third evaluation metric is the Davies-Bouldin Index which signifies the average similarity between the clusters by comparing the distance between them with their size (Table 6.12). A better separation between the clusters is represented by a lower Davies-Bouldin Index. The lowest possible score is zero and a better partition is indicated by values closer to zero.
