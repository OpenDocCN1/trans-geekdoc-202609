$$p(c|D) = \frac{P(D/c)p(c)}{p(D)} \text{ posterior} \propto \text{likelihood} \times \text{prior}$$

When $D$ and $c$ denote the data and class labels. A change can be attributed to:

+   - Class prior $p(c)$ may change over time;
- Likelihood $p(D/c)$ might change;
- Posterior $p(c/D)$ can change.

The first two changes changed are called *virtual* concept drift whereas the last one is called a *real* concept drift. A further illustration of the three cases is given in Figure 1.7.
