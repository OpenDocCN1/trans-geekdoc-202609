## 12.3.2 CLAHE

直方图均衡化是增强图像最简单的方法之一。它有助于在不确定退化实际原因的情况下提高图像质量。只有当图像的像素值分布相同时，它的效果才良好。CLAHE [26] 是 AHE [13] 的改进版本，旨在限制后者所面临的问题。CLAHE 的工作方式与 AHE 相同，唯一的区别在于裁剪限制（clip limit）的计算，它规定了对比度增强的限制。裁剪限制的值越高，图像的对比度越高。裁剪限制基于归一化直方图，包含了邻域区域的大小。

最初，将图像划分为多个相同大小的互不重叠块。接着，计算每个区域的直方图，并获得一个所需的裁剪限制以对直方图进行裁剪。重新分配直方图，使其高度不超过裁剪限制。这个重新分配过程可能需要对裁剪因子进行多次迭代。最后，使用双线性插值合并所有相邻块，并根据修改后的直方图改变其灰度值。CLAHE 程序的伪代码如算法 12.2 所示。

这里，$N_{average}$ 是纹理区域平均灰度数。$NrX$ 是上下文区域 $X$ 维度上的像素数，$NrY$ 是上下文区域 $Y$ 维度上的像素数，$N_{CLIP}$ 是实际裁剪限制，$N_{clip}$ 是范围 $[0,1]$ 内的归一化裁剪限制，$N_{total}$ 是被裁剪像素的总数，$N_{vremain}$ 是待分配的平均像素数，$N_{remain}$ 是待分配的像素数，$H(i)$ 是每个区域在第 $i$ 个灰度级的原始直方图，$H_{clip}(i)$ 是每个区域在第 $i$ 个灰度级的裁剪直方图。

## 12.3.3 GF

GF 使用另一幅图像（例如引导图像）的属性来执行滤波过程。GF 在许多方面都有帮助，例如消除图像中的伪边缘和阶梯效应，以及用于图像平滑和去噪。从数学上讲，GF 可以表示为：

```
$q_i = a_k l_i + b_k, \forall i \in \omega_k$$
```

其中，引导图像表示为 $I$，输入图像表示为 $p$，输出图像可以定义为 $q_i$，$\omega_k$ 是以像素 $k$ 为中心的窗口大小，$(a_k, b_k)$ 是常数。值的计算为：

```
$a_k = \frac{\sum_{i \in \omega_k} l_i p_i - \mu_k \Gamma_k}{\sigma_k^2 + \varepsilon}$
```

```
$b_k = \Gamma_k - a_k \mu_k$
```

# 使用 CLAHE 和引导滤波的增强去雾程序

### 算法 12.2 CLAHE

输入：$Input_{img}$
输出：$Enhanced_{img}$

1. 将原始强度图像划分为 $M$ 个重叠的上下文区域。图像块的总数等于 $M \times N$。
2. 根据数组图像中的灰度级计算每个上下文区域的直方图。
3. 通过裁剪限制值计算上下文区域的对比度自适应直方图如下：

```
$N_{average} = (Nx \times Ny) / N_{levels}$
N_{CLIP} = N_{clip} \times N_{gray}$
```

重新分配的平均像素数由 $N_{avggray} = N_{total} / N_{levels}$ 给出。

4. 像素裁剪程序：
if $H(i) > N_{CLIP}$ 则
$H_{clip} = N_{CLIP}$
else
if $H(i) + N_{avggray} > N_{CLIP}$ 则
$H_{clip} = N_{CLIP}$
else
$H_{clip} = H(i)$
end if

5. 重新分配剩余像素直到分配完毕。重新分配步骤由 $N_{levels} / N_{remain}$ 给出。
6. 使用插值计算子区域内像素的新灰度级分配

其中 $\omega$ 是块中的像素数，$\mu_k$ 和 $\sigma_k^2$ 是 $I$ 的平均值和方差，$\varepsilon$ 是避免 $a_k$ 值最大化的正则参数，$p$ 是窗口 $\omega_k$ 内 $p$ 的平均值。

线性模型可以应用于整个图像的每个局部窗口。但包含该像素的每个窗口 $\omega_i$ 找到输出图像 $q_i$ 每个可能像素平均值的简单方法可以所示：

```
$q_i = \frac{1}{|\omega|} \sum_{k \in \omega} a_k l_i + b_k \quad (12.6)$
```

```
$=\overline{a_i} l_i + \overline{b_i} \quad (12.7)$
```

其中 $\overline{a_i}$ 和 $\overline{b_i}$ 分别是块 $a_k$ 和 $b_k$ 的平均值。

## 12.4 方法

所提算法解释如下：

1. 首先，取雾图作为输入图像。
2. 将算法 12.1 给出的白平衡程序应用于雾图，以白色调整输入图像的颜色，使其看起来自然。
3. 为了提高雾图的可见性，将算法 12.2 给出的 CLAHE 程序应用于白平衡图像。在此过程中，将图像划分为互不重叠的块，并计算每个块的直方图。之后选择一个裁剪限制来裁剪超出限制的部分。
4. 最后，使用双线性插值对每个区域的直方图进行限制，并根据新的直方图改变灰度值。
5. 由于 CLAHE 对直方图的裁剪，图像的一些信息可能会丢失。对于 GF，考虑引导图像 $(l)$ 并进行滤波过程。
6. 计算 $(l)$、CLAHE 输出 $(p)$ 以及 $(I \times p)$ 的平均值。
7. 计算 $(I,p)$ 的协方差为：

```
$cov\_Ip = mean\_I.*mean\_p \quad (12.8)$
```

8. 获取 $(I)$ 的方差以获得线性系数 $a$ 和 $b$：

```
$var\_I = mean\_l.*mean\_l \quad (12.9)$
```

9. $a$ 和 $b$ 的值对于获取最终结果非常重要，可以通过获得：

```
$a = (cov\_Ip)/(var\_I + \epsilon) \quad (12.10)$
```

```
$b = mean\_p - a*mean\_l \quad (12.11)$
```

其中 $\epsilon$ 是正则化参数。
计算 $a$ 和 $b$ 的平均值并获得图像的最终输出即 $q$：

```
$q = mean\_a.*mean\_b \quad (12.12)$
```

## 12.6 图像质量评估标准

### 12.6.1 峰值信噪比 (PSNR) 和均方误差 MSE

峰值信噪比 (PSNR) 和均方误差 (MSE) [17, 18, 27, 41] 是比较去雾图像质量常用的两种误差矩阵。改进去雾图像与原始图像之间的累计平方误差由 MSE 表示，其数学表示可以为：

```
MSE = \left[ \frac{1}{M \times N} \right]_{M,N} \sum [I_t(m,n) - I_z(m,n)] \quad (12.13)
```

这里，$I_t(m,n)$ 和 $I_z(m,n)$ 分别是雾图和改进图像，$M \times N$ 是图像的大小，$m, n$ 表示图像像素的 $x, y$ 位置。
