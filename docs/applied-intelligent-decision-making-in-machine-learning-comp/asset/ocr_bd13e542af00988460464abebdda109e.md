Some researchers have modeled domain knowledge as taxonomy, ontology, and concept networks. Liang et al. built a semantic network based on visited documents, where links between each semantic tree represent the inheritance relationship between concepts (Liang, Yang, Chen, and Ku 2008). Cantador et al. proposed a cluster-based recommendation method where each cluster in a semantic network represents users with similar preferences (Cantador and Castells 2006). De de developed an adaptive ontology based on the user's reading behaviors. The user's action was retrieved from the ontology, and recommendations were based on similar patterns (De Gemmis, Lops, Semararo, and Musto 2015).

Meschenmoser et al. define web scraping as an automated technique to extract and retrieve data at range (Meschenmoser, Meuschke, Hotz, and Gipp 2016). A variety of tools and interfaces to build personalized scrapers, as well as customizable equipped scraping frameworks, exist. Glez-Peña et al. and Haddaway et al. present ample summaries of frameworks and tools for various extraction tasks, namely DataToolBar, Helium Scraper, Screen Scraper, and FMiner (Glez-Peña, López Fernández, Rebeiro-Jato, and Fdez-Riverola 2013; However), but there are very few scrapers for mining scientific records and bibliographic data. Smith-Union et al. recommend a ContentMine framework that allows building personalized tools and other data mining elements (Smith-Union and Murray-Rust 2014). Tang et al. propose an Aminer framework that collects and integrates heterogeneous social data from many web data sources for researchers (Tang, Zhang, Yao, Li, Zhang, and Su 2008), but the framework provides no provision for personalized content mining.
