In the second loop, we iterate the experts, making a prediction for each data point and decreasing its weight if it makes a mistake (lines 7–10). In line 11, we update the prediction. Line 13 sets the global prediction of η. In the part (14–22), we normalize the weights. If the global prediction differs from the true label, that means the whole set of experts is not good and this is the time to create a new expert. One can use any online algorithm as the base learner, such as a decision tree, naive Bayes, or a neural network, within the framework.
