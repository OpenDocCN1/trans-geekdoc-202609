Another equation we apply for the performance measure is the coefficient of determination, denoted by $R^2$ and as “R-squared.” This is the proportion calculated from actual and predicted variables:

```
$$\bar{A} = \frac{1}{n} \sum_{i=1}^{n} A_i$$
$$ss_{tot} = \sum_{i} (A_i - \bar{A})^2$$
$$ss_{res} = \sum_{i} (A_i - P_i)^2$$
$$R^2 = 1 - \frac{ss_{res}}{ss_{tot}}$$ (10.7)
```

where $A$ and $P$ are actual and predicted variables, $ar{A}$ is the mean of $A$, and $ss_{tot}$ and $ss_{res}$ are the total sum of squares and the residual sum of squares. The value of $R^2$ lies between 0 and 1, and the closest to 1 is the more accurate.

```
$DA = \frac{100}{n} \sum_{i=1}^{n} d_i \text{ where } d_i = \begin{cases} 1, & (P_i - P_{i-1})(A_i - A_{i-1}) \geq 0 \ 0, & \text{otherwise} \end{cases}$ (10.8)
```

where $d_i$, is the direction accuracy, $P_i$ and $A_i$, are the predicted data and actual data. This measures the number of correct decisions made when forecasting whether the next values will increase or decrease during the subsequent steps. The values of DA fall between 0 and 100; the closer the values are to 100, the more accurate the prediction of the model. Performance-measuring approach is more important to the model. This performance-measuring approach is more important to stock market analysis because of the direction of the time-series data.

```
$Theil's U = \frac{\sqrt{\frac{1}{2} \sum_{i=1}^{n} (A_i - P_i)^2}}{\sqrt{\frac{1}{2} \sum_{i=1}^{n} A_i^2 + \sqrt{\frac{1}{2} \sum_{i=1}^{n} P_i^2}}$ (10.9)
```

The model is unable to predict if value of Theil's U approaches zero. Another performance measure, the ARV, is defined as:

```
$ARV = \frac{\sum_{i=1}^{n} (P_i - A_i)^2}{\sum_{i=1}^{n} (P_i - \bar{A})^2}$ (10.10)
```

The model is practical if the ARV value is between 0 and 1, where the closer the value is to zero, the better is the result.
