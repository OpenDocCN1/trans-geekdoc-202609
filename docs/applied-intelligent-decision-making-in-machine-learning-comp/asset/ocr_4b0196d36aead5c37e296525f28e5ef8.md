Of several agricultural applications, the motivation for choosing these two datasets is due to the complexity of the problems. In the soybean aphid dataset, the other objects (exkeletons and leafposts) exhibit features similar to aphids; class classification is complex and requires the selection of suitable features (individual or a combination). In the weed dataset, the classification of weeds into grassy and clover-shaped species at the "just merged" stage is a difficult and tedious task, as both species display similar shape (to two merged leaves). The datasets used in this chapter were primarily in the form of images, which were processed using ImageJ (Rasband, 2019; Schindelin et al., 2012), an open source and free image processing software, to extract features suitable for ML application.

Even though ML classification using available packages is simple and plug-and-play methodology, it is vital to realize that it is a blind approach. The users supply input data to the model and receive output while oblivious of the process behind the packaged ML methods. In such packages, commonly referred as "black-boxes," are built with the highest efficiency specific to their ecosystem, and when required it is not always possible to customize them to a different ecosystem. It is always desirable to decode and reconstruct the ML methods to overcome these limitations.

The primary advantage of such user-coded models is that the user is fully aware of the mechanism, the mathematical principles behind the algorithm, and the models' limitations. The models when reconstructed in open source software will be cost-effective and have less constraint and complexity. Furthermore, user-coded models can be customized based on the data, could potentially improve the ML performance more than the black-box approaches, and provide knowledge and training to the users (e.g., students and researchers) as it developed from scratch.

Given this background and requirement to develop decoded ML algorithms, the objectives of this chapter were: (i) decode two of the ML classification methods using open source software ImageJ (image processing and data extraction) and R (data handling and model development); (ii) employ the decoded algorithm for demonstrating classification using field data of agricultural applications, such as soybean aphid identification and weed species classification; and (iii) compare the performances of the decoded algorithm with the existing black-box approaches.
