考虑到这些因素。然而，与表 3.2 所示的单阶段模型相比，这些模型的准确率有所降低。这是因为第一阶段对于具有几何结构的字符具有相似的概率值。在这里，我们设计了一个三阶段混合模型来克服两阶段模型的局限性。在这里，我们使用了模板匹配和排序方法来减少预测字符类别的数量。然后，我们采用 SSIM 匹配和轮廓排序来进一步减少极低概率的字符，并使用 LED 和 GRNN/SVM 预测最终类别。混合模型的结果如图 3.2 所示。观察到，使用 LED 和 GRNN 的三阶段模型与其它混合模型和最先进的方法相比，提供了最高的识别性能（即 90.6%）。

# 3.6 结论与展望

在本章中，我们提出了一种用于奥里亚语复合字符识别的三阶段混合模型。该模型利用了模板匹配和相似性索引来处理奥里亚语手写数字。与现有方法相比，该方案实现了 90.6% 的更高准确率。未来，需要进行研究以提高模型性能并达到人类水平的精度。
