# 1.6 DISCUSSION

Data mining is a challenging task because of the complex dynamics involved. In this chapter, I have presented some algorithms for basic problems in streaming data such as filtering and counting. We also discussed how to sample from a data stream efficiently as well as handling concept drift. Since sampling and concept drift are some of the fundamental problems affecting other stream mining tasks such as classification, clustering, and novelty detection. Therefore, having a good sampler for streaming data out-the-shelf makes downstream tasks easier without worrying about devising a new algorithm for handling them. The other hand, concept drift is another problem often comes with class imbalance or novelty detection. DWM and CUSUM are classic algorithms that can be used to track concept drifts efficiently. Higia is state-of-the-art model for such problems. There are still unsolved problems in big streaming data such as privacy preservation, handling incomplete and delayed information, and analysis of complex data to name a few (Krempl et al., 2014).
