
where $s(S_d, D_j)$ is defined as the cosine similarity between document embeddings cos-sim$(D_d, D_j)$. Here $\alpha$ is the hyper-parameter of the model and tuned to get the best result. Choosing a positive sample for training is straightforward, any pair of $(S_d, D^{cited})$ is selected, where a document $S_d$ in the training set cites $D^{cited}$. But, a careful selection of the not-cited sample is needed for training the model to show better performance. The documents that are not cited in a document but are near to it in the embedding space are chosen as negative samples to train the model.

## 5.4 EXPERIMENTAL RESULTS AND DISCUSSIONS

In this section, we compare the experimental results of our proposed method with the following methods:

- Latent Dirichlet Allocation (LDA) (Blei, Ng, and Jordan 2003): This method handles the topic distribution among papers.
- Collaborative Topic Regression (CTR) (Wang and Blei 2011): This method combines matrix factorization and probabilistic topic model for user affinity.
- User-Article based Graph with Tags (UAGT) (Cai, Cheng, Luo, and Zhou 2016): This method maps the recommendation problem into a bipartite graph and solves by considering text contents and intents.
- MPRec (Ma, Zhang, and Zeng 2019): This method uses meta-path-based topological features and resolves the problem in heterogeneous information networks.
- HIPRec (Ma, Zhang, and 2019): This method fuses different topological features from the meta-path and graph and uses these combined features as prediction model.

**Evaluation:** The efficiency of the proposed domain-specific recommendation method and existing recommendation methods are evaluated using a prediction accuracy rate, which is defined as:

$$\text{Accuracy} = \frac{R_{id}}{N_j}$$

where $R_{id}$ represents the number of recommended papers for the query and $N_j$ indicates the total number of tested papers.

### 5.4.1 CONFIGURATIONS

To find similar papers that are close to a given query in the embedding space, we used the approximate nearest neighbors (https://github.com/spotify/annoy) search algorithm. This algorithm works by building a binary tree of points in higher dimension by choosing random hyper-planes that allow searching of nearby in O(log n) time. To optimize various hyper-parameters, such as the size of hidden layers, learning rate, and regularization strength, we used the python library “hyperopt."
