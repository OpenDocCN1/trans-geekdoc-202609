Considering the complexity of this naive method, the proposed de-duplication method uses an alternative by reducing the number of comparisons by creating blocks based on YEAR of publication, so that only records of the specific block need to be compared, resulting in a lower number of comparisons.

The proposed method recommends a new document to the user finding nearby candidates by embedding a seed document into the linear space. As a second step, re-ranking of the documents is done using a model that is enough to distinguish between cited and uncited references. The entire process of encoding and embedding the textual content of each document into a linear space is done through a neural network. We treat paper recommendations as a ranking problem. Given a seed document S₀ and a large corpus of integrated papers, the task is to rank documents so that the document with a higher rank could be recommended to the user working in a particular domain. The advantage of crawling and scraping the documents that are relevant to a specific domain is that the number of published papers in the scientific web archives can be significantly large and that it is computationally expensive to rank each document as a candidate concerning seed document S₀.
