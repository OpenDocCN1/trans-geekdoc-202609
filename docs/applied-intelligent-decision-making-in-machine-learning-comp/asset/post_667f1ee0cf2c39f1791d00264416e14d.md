Higia is given in Algorithm 1.1. We will illustrate the algorithm more formally. Input to the algorithm is $X_{tr}$ which is the new test point. $T$ and $k$ are user parameters. In the second step, $w_i$ is the label of $k$ nearest micro-clusters. If the majority of the clusters have the same label, we label the new point with the centroid $c_j$ of the nearest micro-cluster $C_j$ and denote its radius by $radius(C_j)$. If the Euclidean distance of the point from the centroid to the new point is within the radius, update the cluster with the new point and classify the label of this cluster (lines 7–10). Otherwise, if the Euclidean distance is larger than $T$ times the radius of the cluster, then create an extension of the cluster and classify the new point with the same label (lines 11–13). If both two scenarios have failed, the new data point in the buffer needs to classify the new data point as an unknown cluster level (lines 15–16).

### 1.5.2.3 Dynamic Weighted Majority Algorithm

## Data Stream Mining for Big Data (Header repetition/Contextual)

Dynamic weighted majority (Kolter and Maloof, 2007) abbreviated as DWM is an algorithm for concept-drift tracking. It is based on the majority voting of experts. The fundamental idea behind DWM is it dynamically creates and removes weighted experts based on their performance. The algorithm works according to four ideas: a train ensemble of learners; weighting them based on their performance; removing experts from the performance; and adding new learners on the global performance.

The DWM algorithm is presented in Algorithm 1.3. I will explain each step of the algorithm. There are m experts. The training pair is denoted by {x, y} and there are c classes. {e, w} denotes the expert and its weight. In lines 1–3, we initialize the number of experts, create a new expert, and set its weight to 1. In the outermost loop, we iterate over the stream by one by one. First, we set the vector $\sigma$ which denotes the sum of weighted predictions to 0 (line 5). In the second loop, we iterate the experts, making a prediction for each data point and decreasing its weight if it makes a mistake (lines 7–10). In line 11, we update the prediction. Line 13 sets the global prediction of $\eta$. In the part (14–22), we normalize the weights. The reason for doing this is that some experts might be right and their weights can go high (due to the addition of weights in line 11). If the weight of an expert falls below the threshold $\alpha$, it is removed from the set of experts (line 16). If the global prediction differs from the true label, that means the whole set of experts is not good and this is the time to create a new expert. Finally, in lines 23–25, we train the new experts and return the global prediction weight in line 26. DWM is a general algorithm for concept drift. One can use any online algorithm as the base learner, such as a decision tree, naive Bayes, or a neural network, within the framework.

### Algorithm 1.3: Dynamic Weighted Majority

```
input $\{x, y\}_j^1$: training data, $c \in \mathbb{N}, c \geq 2$: number of classes, $\alpha$:threshold for deleting expert, $\beta$:for decreasing weights, $q$: time for decreasing weight update, $\{e, w\}^1_m$: set of experts and their weights, $\eta_g, \eta_l$: global and local predictions, $\sigma \in \mathbb{R}$: sum of weighted predictions for each class
$m \leftarrow 1$
$e_m \leftarrow Create\New\Expert()$
$w_m \leftarrow 1$
for $i \in \{1, \dots, n\}$ do
$\sigma \leftarrow 0$
for $j \in \{1, \dots, m\}$ do
$\eta_l \leftarrow Classify(e_j, x_i)$
if $\eta_l \neq y_i$ and $i \mod q==0$ then
$w_j \leftarrow \beta w_j$
$\eta_g \leftarrow argmax \sigma_j$
if $w_j < \alpha$ then
$Remove(\{e, w\})$
$m \leftarrow m - 1$
if $\eta_g \neq y_i$ then
$m \leftarrow m + 1$
$e_m \leftarrow Create\New\Expert()$
$w_m \leftarrow 1$
return $\eta_g$
```
