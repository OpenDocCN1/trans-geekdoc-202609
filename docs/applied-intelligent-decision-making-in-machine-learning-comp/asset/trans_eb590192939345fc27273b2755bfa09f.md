## 2.3.5.3 嵌入式方法

特征选择的嵌入式方法学习对模型准确性贡献最大的特征。这些方法也被称为正则化或惩罚方法，其中无关特征的系数会受到惩罚并从模型中移除。正则化算法的一些示例包括 Lasso（Li et al., 2006）、弹性网（Zou and Hastie, 2005）和岭回归（Engleman, 2011）。

在这些特征选择方法中，Relief 算法在数学上是直观的，它提供了一种对特征影响力的度量，并可以处理输出变量中的多分类。此外，它是唯一能够使用最简单的最近邻方法检测特征依赖性的特征选择方法（Urbanowicz et al., 2018）。在两个考虑的农业应用中，选择了 Relief 算法进行特征选择。

## 2.3.5.4 Relief 算法

Relief 算法是一个包含算法算法家族，例如基础 Relief、ReliefFF 和 RReliefF。基础 Relief 算法只能处理两个类的分类；ReliefFF 是基础 Relief 的扩展，可以处理分类多分类，而只有 RReliefF 可以处理连续回归类。三个算法具有相同的底层机制。本章详细介绍了针对包含多分类的数据集使用 ML 进行分类，其中只有 RReliefF 方法是合适的。然而，为了遵循算法的工作原理，本节演示了一个使用基础 Relief 对二分类数据的手动示例，因为使用 ReliefFF 进行多分类的主流演示过于繁琐。详细阐述 Relief 算法的研究可以在其他地方找到（Kononenko, 1994; Robnik-Sikona and Kononenko, 2003）。

伪代码（算法 2.1）解码了基础 Relief 算法。数据中所有特征的权重初始化为零。Relief 算法使用曼哈顿距离（投影之和的直形距离）而不是欧几里得距离（点之间的直线距离）来计算所选实例（R）与数据中其他实例之间的两个最近邻：命中（hit, H）和缺失（miss, M）。H 指属于同一类且距离随机实例最近的实例。M 指属于不同类且距离随机实例最近的实例。权重的修订除以迭代次数（z），以将权重归一化在 -1 到 +1 之间。根据经验，z 的计算值为数据集中总观测数（n）的平方根值。

## 算法 2.1 基础 Relief 算法的伪代码

```
1: procedure BASIC_RELIEF(dataset)
2:   W[Fj] = 0
3:   ξ = √π
4:   for (i to z) do
5:     select a random instance (Ri)
6:     find nearest hit (H) and nearest miss (M)
7:     for (1 to j) do
8:       W[Fj] = W[Fj] - diff(Fj, Ri,H) + z*diff(Fj, Ri, M)/z
9:     end
10:  end for
11: end procedure
while,
  diff(Fj, Ri,H) = |value(Fj, Ri) - value(Fj, H)| / max(Fj) - min(Fj)
  diff(Fj, Ri,M) = |value(Fj, Ri) - value(Fj, M)| / max(Fj) - min(Fj);
```

其中，Fj 是数据集中不同的特征：Fj = F1, F2, ..., Fn。

使用 H 和 M 修订权重的想法基于随机实例与随机实例之间的差异性，这种差异表明特征分离了两个属于同一类的实例，这是不理想的；然而，权重会减少。最近缺失与随机实例之间的显著差异意味着特征分离了两个属于不同类的实例，这是理想的；因此，权重会增加。

以下基于解码的 Relief 算法（算法 2.1）开发的 R 程序估算了了特征作为结果的权重（图 2.4）。作为比较，还使用了直接的黑盒方法作为说明。这些权重进一步用于确定最显著的特征。

为了演示（图 2.4），考虑一个具有 20 个总观测值（n = 20）、两个类（类 1 和 2）和五个实例（R1, R2, ... Rn）的样本数据集。在该样本数据集上采用 Relief 算法来确定 F1、F2 和 Fn 中影响最大的特征，并根据在分类数据集为类 1 和类 2 时使用的权重进行排名。

# 机器学习中的智能决策

因此，在机器学习中，可用标记数据集被分为训练数据集测试数据集。训练数据子集通过识别数据集中的模式以及特征与其类别标签之间的关系来训练 ML 模型，而测试数据集作为未来新数据的代理，用于估计训练数据集之外的 ML 模型的泛化质量（预测准确率）（Das et al., 2020c）。

有不同的划分方法，如随机采样、试错法、交叉验证、系统采样和分层采样。在这些方法中，简单随机采样最容易使用和实施；然而，简单随机采样对于具有均匀分布的数据集有效（Reitmana, 2010）。使用 R 函数 `ks.test()` 进行的 Kolmogorov-Smirnov 检验显示，从大豆蚜、杂草物种和鸢尾数据集中的大多数特征都是均匀分布的（p > 0.01），使得数据集子集的分析是有效的。因此，在这种简单随机采样方法中，使用了从原始数据集中选择训练和测试的数据。

随机采样使用 caret 包下的 R 函数 `createDataPartition()` 执行。用于训练和测试的数据集划分比例通常分别在 60-90% 和 40–10% 范围内。这种划分比例是根据使用验证数据的 ML 分类器的预测准确率选择的。鸢尾数据集用于演示 `createDataPartition()` 函数将原始数据集划分为训练和测试子集的工作。

```

# 70% 划分的数据分区
```

## 2.3.7 机器学习方法

ML 分类的主要类别是无监督算法和监督算法。无监督机器学习在未标记数据上进行分类（仅传递输入变量，没有通过识别标签的输出变量）。无监督算法学习数据中的底层结构和分布并将其聚类（例如聚类和关联），而监督机器学习在标记数据上执行分类和回归任务（算法传递输入变量和带有标签的输出变量），这有助于模型理解输入与输出变量之间的关系（Das et al., 2015, 2018）。
