## 3.2 BACKGROUND

### 3.2.1 GENERAL OCR Stages

Generally, a complete OCR process is divided into multiple stages. Image acquisition is the first and essential step for any computer vision application. For character recognition images are captured by a flatbed scanner. A digital image of the document can also be obtained with powerful mobile cameras, which they need additional processing. After image acquisition, the known errors are to be removed by the pre-processing step. Image enhancement, noise removal, skew detection and correction, page segmentation, binarization, and font detection are examples of a few pre-processing methods that are used in OCR models. Segmentation is the process of separating lines, words, and characters and has higher significance in determining the recognition accuracy in the case of handwriting and touched character recognition. Each separated character is fed into the recognition model to determine the class label. Models can be derived by various learning and classification methods and feature matching models (feature + template). After recognizing the character class, its corresponding ASCII or Unicode-code must be written into a text file. Handling both word and line separation is essential in this stage. The information obtained from the segmentation step is used in this context, though the recognition process may not lead to the desired result. The presence of punctuation and errors may also result in some unnecessary characters, which can be solved with post-dictionary matching and contextual information. ### 3.2.2 STRUCTURAL SIMILARITY

Human eyes focus on the structure of an image rather than luminance, contrast, and structure comparison. The SSIM [47] explains this by giving ranking value to image quality that is very similar to a subjective human evaluation standard. This is expressed mathematically in Equations 3.1 and 3.2. The overall presentation of the SSIM evaluation is shown in Figure 3.3.

```
$SSIM = [l(x,y)]^c [c(x,y)]^c [s(x,y)]^c \quad (3.1)$
```

where $s$ denotes structure, $c$ denotes contrast, and $l$ indicates local luminance. The expression correlates to the human visual system and by taking $a = \beta = \gamma = 1$ it can be simplified as

```
$SSIM = \frac{(2\mu_{max_y}\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)} \quad (3.2)$
```

where $C_1 = (K_1 * L)^2, C_2 = (K_2 * L)^2$, and $L$ denotes the highest intensity level. The values of $K_1$ and $K_2$ are computed by philosophical study and are set to 0.01 and 0.03 respectively.

SSIM evaluates images on a structural domain rather than an error domain. Hence, for each template image, the score with respect to the target image becomes different. It ranges from 0 to 1 and a higher value indicates better matching. It has been observed from experiment that the recognition performance of all 211 classes is very high for

where $N_{cp}$ is the number of concordant pairs and $N_{dp}$ is the number of discordant pairs. Let $\{X_1,...,X_n\}$ be the observed target and $\{Y_1,...,Y_n\}$ be the reference vector, then a pair $(X_i,Y_i)$ and $(X_j,Y_j)$ is said to be concordant if $X_i > X_j$ and $Y_i > Y_j$ or $X_i < X_j$ and $Y_i < Y_j$. Similarly a pair $(X_i,Y_i)$ and $(X_j,Y_j)$ is discordant if $X_i > X_j$ and $Y_i < Y_j$ or $X_i < X_j$ and $Y_i > Y_j$. If $X_i = X_j$ or $Y_i = Y_j$ then the pair is neither concordant discordant. The KRCC value varies from -1 to 1, where -1 represents completely out of agreement, 1 represents exactly the same, and zero represents the two vectors being independent. For matching characters, the value closest to 1 is preferred.

### 3.2.4 LOCAL DESCRIPTOR

A local descriptor [23] has been derived from LFD [22]. Here we consider neighbor pixels with radius $R$. Let LCF = $\{f_1,...,f_p\}$ be the set of neighbor pixels that are located around the centre. The local frequency descriptor can be expressed as:

```
$LFD(n) = \sum_{k=1}^{P} f_k e^{\frac{-2\pi(k-1)}{P}}, \qquad for(n=1,...,P)$ \qquad (3.4)
```

where LFD(n) is a vector of $1 \times P$ corresponding to the frequency component of the neighbor pixels in LCF. Among P components, LDF(2) contains the most edge information. The local frequency frequency gradient descriptor (LDFG) is calculated by setting $n = 2$:

```
$LDFG = \sum_{k=1}^{P} f_k e^{\frac{-2\pi(k-1)}{P}}$ \qquad (3.5)
```

LDFG is a complex value; to use it in a neural network Equation 3.5 can be decomposed into real and imaginary parts as:

```
$Re(LDFG) = \sum_{k=1}^{P} f_k \cos(\frac{-2\pi(k-1)}{P})$ \qquad (3.6)
```

```
$Im(LDFG) = -\sum_{k=1}^{P} f_k \sin(\frac{-2\pi(k-1)}{P})$ \qquad (3.7)
```
