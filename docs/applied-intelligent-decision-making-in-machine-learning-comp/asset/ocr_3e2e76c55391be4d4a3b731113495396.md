between each cluster $C_i$ for $i=1, \dots,$ and its most similar $C_j$. The measure $R_{ij}$ in the context of this index, is the similarity that trades off

+   - The cluster diameter is defined as the mean distance between the centroid of the cluster and every other point in the cluster and $i$ and $j$ of the cluster is taken as $s_i$.
- The distance between centroids of the cluster is taken as $d_{ij}$.

$R_{ij}$ is non-negative and symmetric is given by

```
$R_{ij} = \frac{s_i + s_j}{d_{ij}}$$
```

The Davies-Bouldin Index can be defined as:

```
$DB = \frac{1}{k} \sum_{i=1}^k \max_{j \neq i} R_{ij}$$
```
