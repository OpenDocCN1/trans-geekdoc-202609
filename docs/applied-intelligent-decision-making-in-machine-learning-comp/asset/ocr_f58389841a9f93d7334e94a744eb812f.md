**Evaluation:** The efficiency of the proposed domain-specific recommendation method and existing journal paper recommendation methods are evaluated using a prediction accuracy rate, which is defined as:

```
$$\text{Accuracy} = \frac{R_{id}}{N_j}$
```

where $R_{id}$ represents the number of recommended papers for the query researcher and $N_j$ indicates the total number of tested journal papers.

# 5.4.1 CONFIGURATIONS

To find similar papers that are close to a given query in the embedding space, we used the approximate nearest neighbors (https://github.com/spotify/annoy) search algorithm. This algorithm works by building a binary tree of points in higher dimension by choosing random hyper-planes that allow searching of nearby candidates in O(log n) time. To optimize various hyper-parameters, such as the size of hidden layers, learning rate, and regularization strength, we used the python library “hyperopt."
