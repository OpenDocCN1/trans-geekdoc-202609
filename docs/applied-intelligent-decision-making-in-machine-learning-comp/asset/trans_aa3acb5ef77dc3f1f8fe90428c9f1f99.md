# 前言

关于印度的污染物浓度信息。在第7章中，作者探讨了改进的二进制洗牌跳跃算法以及用于生物标志基因判定的元启发式方法。在第8章中，作者介绍了一种识别多词实体并将其分类为相应概念类型的方法。该方法使用了基于矩阵的多模式匹配的概念来生成模式频率。第9章应用了不同的机器学习技术，如决策树、随机森林、极端梯度提升和支持向量回归，对澳大利亚的碳排放进行建模。第10章分析了 1 美元兑五种不同货币（澳元、加加元、英镑、印度卢比和日元）的日外外汇数据；通过使用深度学习技术，准确且高效地预估了超过 1600 个样本。第11章探讨了基于教学-学习的特征选择（FS）优化，通过用强特征更新弱特征来寻找最优特征。第12章使用了去雾技术、对比度限制自适应直方图均衡化以及引导滤波，来恢复图像的原始质量。

本书汇集的主题是独特的，而且也是基于贡献作者尚未发表的工作。我们试图传达机器学习、决策科学及其多样化应用领域所取得的所有新实验和方向。我们相信，这本书为从业者、系统架构师、研究人员和开发者等广大读者提供了参考。

## 1.1 引言

学习分为两种类型，取决于数据处理方式。批量学习是分块处理数据，通常是离线的。另一种学习类型是在线学习，通常在流数据上进行。在线学习的另一个名称是增量学习。本章的重点是针对流数据进行增量学习。

数据流具有某些特性（根据 Gama, 2010）：

- 无界大小：
  - 瞬态（仅持续几秒或几分钟）；
  - 单次通过数据；
  - 只能存储摘要；
  - 实时处理（内存中）。
