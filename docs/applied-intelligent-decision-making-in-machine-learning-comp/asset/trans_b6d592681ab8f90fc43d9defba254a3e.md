MSE 值越小表示误差越小，也就是说 MSE 值越低，图像质量越好。

峰误差的衡量标准由 PSNR 表示，它可以描述为 MSE 的倒数。在数学上，它可以表述为：

```
PSNR = 10 \times \log_{10} \frac{(2^B-1)^2}{MSE} \quad (12.14)
```

$B$ 表示每个样本的比特，范围在 0 到 255 之间。PSNR 的单位是分贝（dB）。如果方法产生了低 MSE 和高 PSNR 值，则认为该方法是良好的。

## 12.6.2 熵

图像的熵可以识别其纹理以及图像的随机性。低熵表示区域是均匀的，与雾较大的图像相比，模糊图像具有较低的熵值。在数学上，它可以被估计为：

```
$H = -sum p_i \log_2 p_i \quad (12.15)
```

其中 $p_i$ 表示一个灰度级强度出现的概率。

## 12.6.3 结构相似性指数

该指数有助于衡量由各种处理引起引起的图像退化。其计算需要一张参考图像。在数学上，

```
$SSIM(x,y) = \frac{(2\mu_x\mu_y + c_1)(2\sigma_{xy} + c_2)}{\mu_x^2 + \mu_y^2 + c_1(\sigma_x^2 + \sigma_y^2 + c_2)} \quad (12.16)
```

$\mu_x$ 和 $\mu_y$ 分别是 $x$ 和 $y$ 的平均值，$\sigma_x^2$ 和 $\sigma_y^2$ 分别是 $x$ 和 $y$ 的方差，$\sigma_{xy}$ 是 $x$ 的协方差，$c_1$ 和 $c_2$ 是用于稳定偏差的变量。

## 12.6.4 对比度增益

对比增益是增强图像与原始图像（雾图）对比之间的平均差异 [6]。它可以通过以下方式计算：

```
$C_{gain} = C_j - C_i \quad (12.17)
```

其中 $C_j$ 是输出增强图像的平均对比度，$C_i$ 是原始雾图的对比度。

## 12.7 实验结果与讨论

同样，在图 12.3 中，考虑了雾浓度为 100 的情况。在图 12.3(c) 中，给出了白平衡图像的输出。在对其应用 CLAHE 后，结果似乎并不理想，如图 12.3(d) 所示。为了改进结果，使用了引导滤波（GF），结果如图 12.3(e) 所示。观察到该结果在去除背景中的雾气方面非常成功。

实验在从 HazeRD 数据集中收集的雾图像上进行了执行和测试。对于图 12.2，考虑了雾浓度为 50 的情况。图 12.2(b) 显示图像相当模糊。通过白平衡处理来调整图像颜色，应用 CLAHE 后的白平衡图像输出在图 12.2(e) 中所示，可以观察到，图像中没有观察到视觉上的改进。因此，在图 12.2(f) 中对图像应用 GF 进行测试，观察到虽然雾图像的可视性有所提高，但雾气并未完全从背景中移除。考虑到图 12.4 的雾浓度为 200，观察到在应用 CLAHE 后获得的结果（如图 12.4(d) 所示）与图 12.4(c) 中的白平衡结果图像相比，没有得到太大改进。因此，为了提高结果，应用了 GF，最终结果图像如图 12.4(e) 所示，其中可以看到雾气已被去除，获得的结果也非常吸引人。与之前的结果相比，图像的对比度也得到了提高。
