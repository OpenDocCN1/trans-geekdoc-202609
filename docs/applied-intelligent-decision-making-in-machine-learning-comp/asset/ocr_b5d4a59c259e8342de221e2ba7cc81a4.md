# 8.3.2.5 Pruning Non-Medical Concepts

The system generates several medical or non-medical single entities or sequences of entities because of the parallel pattern matching between two matrices because the precision of non-medical concepts drops off. For improving the precision of the system, non-medical concepts are pruned according post-processing rules. For this, a few rule patterns are shown below in which a medical concept's semantic type is one feature which is presented in the UMLS Metatheaurus [2]. UMLS shows some categories of semantic types of the database which is used for three medical concepts: procedure, test, and treatment.
