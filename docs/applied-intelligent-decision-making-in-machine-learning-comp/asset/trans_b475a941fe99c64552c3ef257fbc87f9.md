## 2.3.7 线性判别分析

LDA 是一种流行的降维和监督分类技术，最初是为了解决二分类问题而开发的（Fisher, 1936）。它提供了两个由直线分隔的区域，这有助于数据和区域的分类，而分隔线由线性判别评分函数定义。该方法后来被推广到多分类问题（Rao, 1948）。LDA 方法采用线性判别评分函数来预测测试数据实例的类别标签。判别评分函数源于贝叶斯定理，该定理根据每个类别的概率以及测试数据属于该类的概率来确定类别标签（2.14）。

```
$P(\pi|\vec{x})=\frac{P(\pi,\vec{x})}{P(\vec{x})}$
```

其中 $P(\pi|\vec{x})$ 是测试数据实例 $\vec{x}$ 属于 $\pi$ 类的概率，$P(\pi,\vec{x})$ 是 $\pi$ 和 $\vec{x}$ 的联合概率，$P(\vec{x})$ 是 $\vec{x}$ 的先验概率。贝叶斯定理的线性判别评分函数表示为 $y=ax+b$，其中 $a$ 和 $b$ 是从训练数据中获得的参数，$x$ 是测试数据实例。从贝叶斯定理推导线性评分函数的详细过程可参见其他处（Konishi, 2014; Naik and Kiran, 2019）。类别 $i$ 的线性判别评分函数（$L_i$）给出：

```
$L_i=-\frac{1}{2}\vec{\mu}_i^T\Sigma^{-1}\vec{\mu}_i+\vec{x}^T\Sigma^{-1}\vec{x}+\log p_i$
```

其中 $\vec{\mu}_i$ 是训练集中每个类的平均向量，$\Sigma$ 是训练集中每个类的协方差矩阵，$\vec{x}$ 是测试数据实例，$p_i$ 是类别 $i$ 的先验概率。执行 LDA 的一些主要假设是：(i) 训练和测试数据呈正态分布；(ii) 每个类的协方差矩阵相等。然而，在现实中，各类的协方差矩阵是不相等的，因此为了考虑数据集中的差异，使用了合并协方差矩阵（$\hat{S}_p$）：

```
$\hat{S}_p=\frac{\sum_{i=1}^m\Sigma_i}{\sum_{i=1}^m(n_i-1)}$
```

$\hat{S}_p$ 是所有类的合并协方差矩阵，$m$ 是数据集中的类别数量，$n_i$ 是每个类中的观测数量。将方程 (2.16) 代入方程 (2.15)，得到该类别的 $L_i$ 函数为：

```
$L_i = -\frac{1}{2}\vec{\mu}_i^T\hat{S}_p^{-1}\vec{\mu}_i+\vec{x}^T\hat{S}_p^{-1}\vec{x}+\log p_i$ (2.17)
```

对数据集中所有类别 $(m)$ 评估 $L_i$，以预测待测试测试数据的类别。产生最大 $L_i$ 评分的类别即为该测试数据的类别。LDA 涉及的相关过程以伪代码（算法 2.2）的形式给出。开发的 R 程序演示了 LDA 识别鸢尾花数据集的工作（图 2.5）。花瓣长度、宽度以及花萼长度等特征是根据使用 LDA 的结果选择的。

**LDA 的优点：**
- 数据应呈正态分布。
- LDA 假设各类别具有相等的协方差。

  }
}
