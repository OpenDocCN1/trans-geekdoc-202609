It can generally be described as the union of airlight and attenuation, where airlight occurs when light gets scattered and reflected back in the direction of the source, which causes the whiteness in the image, and attenuation is the diminishing effect of the image contrast.

The following model is used to describe hazy image formation [7, 9, 25, 35]:

```
$I(x) = J(x) \times t(x) + A \times (1-t(x)) \quad (12.1)$
```

where the input hazy image is expressed as $I(x)$, $t(x)$ is the transparency of haze ranging from 0 to 1, which works by blending atmospheric light (A) and the original color of the image $J(x)$. The $J(x) \times t(x)$ is called attenuation and $A \times (1-t(x))$ is called airlight. The transmission factor $t(x)$ is decreased with increasing depth of the object, which is expressed as:

```
$t(x) = e^{-\beta d(x)} \quad (12.2)$
```

where $eta$ stands for the scattering coefficient of the atmosphere and $d(x)$ is the scene depth.

The technique which is used to recover the original image from the hazy image is called a dehazing technique. The conventional technique to remove haze involves two steps: first to remove the airlight and second to recover the lost information by image. Basically, dehazing methods can be classified into two categories: Multiple image-based dehazing methods and single image-based dehazing methods. Some relevant work based on machine learning and image processing are described in [4, 31, 40].

Multiple image-based methods require multiple images of the same scene to execute, whereas single image-based methods need only one image to carry out the process.

Multiple image-based methods can be extended into the following categories: A weather-condition-based method [21, 25] which depends on the variation of the same image taken during different weather conditions. Though this method can enhance the visibility it cannot work for dynamic images. For the polarization-based method [29, 30], multiple images having a different filter of polarization are considered. This polarization filter can be adjusted by the attached polarization filter present in the camera. The limitation with this method is that it cannot work properly when the haze is thick or dense. Similarly for the map-based method [14, 23], some depth information [29, 30] is used to dehaze an image. This works on a 3D model, and the appearance of the input scene depth gives and helps in removing haze from the image. This technique needs user interaction, that is, not automatic.
