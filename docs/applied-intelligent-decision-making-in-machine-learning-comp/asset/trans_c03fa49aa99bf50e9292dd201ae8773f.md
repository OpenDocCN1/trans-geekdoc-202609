```
$z_t = \sigma(W_z \cdot x_t + U_z \cdot h_{t-1} + b_z)$
```

同样，重置门 $r$ 从输入数据集和隐藏状态数据接收输入，然后与权重矩阵 $W_r$ 和 $U_r$ 相乘，并分别使用 sigmoid 函数激活：

$r_t=\sigma\left(W_r\cdot x_t+U_r\cdot h_{t-1}+b_r\right) \quad (10.2)$

现在，为了更改当前的内存内容，使用之前的信息和当前输入数据执行激活的聚合计算 $a$。在这一步中，输入数据 $x_t$ 以及隐藏状态数据与重置门值的乘积与相应的权重变量 $W_a$ 和 $U_a$ 相乘。所得结果使用双曲正切（tanh）激活函数进行激活：

$$\tanh\left(\frac{e^x-e^{-x}}{e^x+e^{-x}}\right)$$

$a_t=\tanh\left(W_a\cdot x_t+U_a\cdot h_{t-1}+b_a\right) \quad (10.3)$

最后，通过上述计算结果更改内存或隐藏状态数据：

$h_t=(1-z_t)\cdot h_{t-1}+z_t\cdot a_t \quad (10.4)$

此处计算出的 $h_t$ 表示下一个状态的内存或之前的状态数据 $(h_{t-1})$。众所周知，sigmoid 函数的值在 0 到 1 之间；数据的丢弃和更新取决于 $z_t$ 的值。这两个变量是关联的；一个变量的值越大，另一个的值越小。

# 10.2.1 性能衡量

我们采用平均百分比误差（MAPE）、均方根误差（RMSE）、决定系数（$R^2$）、平均相对差（ARV）、Theil U 和方向准确率（DA）来评估所提神经网络的性能特征，如下：

$MAPE=\frac{1}{n}\sum\frac{|A-P|}{|A|}\cdot100 \quad (10.5)$

$RMSE=\sqrt{\frac{1}{n}\sum(A-P)^2} \quad (10.6)$

其中 $A$ 是实际值，$P$ 是预测值，$n$ 是预测次数。MAPE 和 RMSE 的值大于零，结果越接近零，性能越准确。

另一个用于性能衡量的方程是决定系数，记为 $R^2$ 并称为“R-squared”，它是从实际变量和预测变量计算计算的：

```
$$\bar{A} = \frac{1}{n} \sum_{i=1}^{n} A_i$$
$$ss_{tot} = \sum_{i} (A_i - \bar{A})^2$$
$$ss_{res} = \sum_{i} (A_i - P_i)^2$$
$$R^2 = 1 - \frac{ss_{res}}{ss_{tot}}$$ (10.7)
```

其中 $A$ 和 $P$ 是实际和预测变量，$\bar{A}$ 是 $A$ 的平均值，$ss_{tot}$ 和 $ss_{res}$ 是总和和残差和。R^2$ 的值位于 0 到 1 之间，越接近 1 越准确。

```
$DA = \frac{100}{n} \sum_{i=1}^{n} d_i \text{ where } d_i = \begin{cases} 1, & (P_i - P_{i-1})(A_i - A_{i-1}) \geq 0 \\ 0, & \text{otherwise} \end{cases}$ (10.8)
```

其中 $d_i$ 是方向准确率，$P_i$ 和 $A_i$ 是预测数据和实际数据。这衡量了在预测后续步骤中下一个值是增加还是减少时所做的正确决策数量。DA 的值落在 0 到 100 之间；值越接近 100，模型的预测越准确。性能衡量方法对模型很重要。这种性能衡量方法对模型非常重要。

# 10.2.2 数据准备

从预测中心 (www.forecasts.org) 获取了 2012 年至 2018 年期间五种货币（澳元 AUD、英镑 GBP、加加元 CAD、印度卢比 INR 和日元 JPY）兑美元（USD）的汇率，共 1570 个每日样本的历史汇率数据。每日样本被归一化到 [0, 1] 范围内，将每个值除以最大值。通过滑动窗口大小的概念，每次移动一步提取输入模式和相应的输出值。模式的数量 N 等于 (N-W+1)。在这一特征提取技术中，输入变量的数量（或提取列的大小）取值与滑动窗口的大小相似，其中提取的数据集的第一列从第一个索引开始，第二列从第二个索引开始，依此类推。生成的输入模式的模式被进一步分为两个数据集；前 80% 的样本用于训练，其余 20% 用于测试。
