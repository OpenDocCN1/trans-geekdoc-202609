# 6.2.3 ENSEMBLE CLUSTERING

Now, moving on the clustering techniques, many domains have proven that in comparison to individual classification techniques, a classifier ensemble is more accurate in most cases. This has initiated research work in the area of ensemble methods for clustering. Fred and Jain (2002) generated base clustering results with different initialization of centroids in a K-means clustering algorithm. Similarity between samples is measured by the co-association matrix, which the K-means results are mapped onto. The work was extended by Kuncheva and Hadjitodorov (2014), in which a number of clusters was chosen for each member that was part of the ensemble clustering. A procedure for meta-clustering, consisting of two steps, was introduced by Zeng, Tang, Garcia-Frias, and Gao (2012). Initially, all the clusters are converted into a distance matrix. Next, the various distances from the clustering are combined using a hierarchical clustering method, introducing consensus clustering for computing. Hu (2008) generated combined clustering results using a graph-based partitioning approach. Ayad and Kamel (2013) introduced a graph approach with vertices and edges. Data points are represented by vertices and when a certain number of neighbors are shared between two data points, there random projection of data points is combined with a cluster ensemble by Fred and Jain (2002). Clustering is carried out using the expectation maximization approach and agglomerative clustering is applied to obtain the results. Greene, Tysbal, Bolshakova, and Cunningham (2014) focused on generating integration techniques for clustering. The dataset used was medical diagnostic. Base clustering was generated using fast, K-medioids and K-means clustering. The aggregation of results is generated by a co-occurrence matrix, upon which hierarchical clustering schemes are applied for consensus clustering. Different hierarchical methods, such as single linkage, complete linkage, mean, median, and ward, were used to cluster the Denge data (Vandhana and Anuradha 2018). The base clustering results can also be produced from various hierarchical methods.

The normalized mutual information between the results is measured by Strehl and Ghosh (2012), combining the clustering results using a novel consensus function. The three heuristics represent the ensemble clustering as a hyper-graph. Here the partitionings is represented as a meta-clustering algorithm (MCLA), a hyper-graph partitioning algorithm (HGPA), and a cluster-based similarity partitioning algorithm (CPA). In CSPA, the inputs for clustering are converted into a similarity matrix. For each pair of points, the value is 1 if it belongs to the same cluster, 0 otherwise. A similarity matrix S is generated using the average of all the matrices. The results are re-clustered from S, with a graph-based partitioning approach. The generated similarity matrix consists of vertices corresponding to data, and edges represent the weight of similarity between vertices. Karypis and Kumar (1998) use METIS for final partitioning.
