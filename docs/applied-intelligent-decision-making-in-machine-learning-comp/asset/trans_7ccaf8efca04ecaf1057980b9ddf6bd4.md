

## 机器学习中的应用智能决策

它基本上遵循一种贪心算法。之前提到的评估标准是适应度（fitness），但性能衡量取决于其所处理的问题类型。某些回归标准包括 p 值、$R$ 平方的调整后的 $R$ 平方。某些分类评估标准包括准确率（accuracy）、精确率（precision）、召回率（recall）和 F1 分数。最后，为有用特征选择最合适的组合。这种特征组合为所应用的机器学习算法提供了最优结果。

封装方法（wrapper methods）下最常用的技术包括：(1) 前向选择、(2) 后向选择和 (3) 双向消除（逐步选择）。我们强调上述封装方法中的这些技术。基本上，前向选择从截距项开始。对各种变量进行测试是为了检查其相关性。将“最佳”变量（其中“最佳”由某些预定义的标准确定）加入到模型中。我们继续这一过程，每次添加一个变量并在每一步中进行测试，同时模型不断改进。一旦模型停止改进，我们便停止添加更多变量。我们判断是否考虑某个变量的标准各不相同。通过寻找交叉验证中的最低分、最低 p 值或任何其他准确性测试来实现。与前向选择不同，后向选择从一个包含所有预测器的最小二乘模型开始，然后通过迭代方法逐个移除最不重要的预测器。后向选择适用于观测值多于变量数量的问题。如果出现相反的情况，我们将无法拟合最小二乘模型，但在当变量之间发现相关性时（如后向消除），在每个阶段都有检测到所选变量的可能性。它主要用于选择某些选择性子集，定义为从整个特征空间中选择某些特征的过程。文献中关于特征选择（FS）方法有许多多样化的概念。某些概念主要处理所选数据的大小，而其他概念则关于提高预测准确率。本质上，FS 构建了一个能有效代表原始数据的数据集。主要目标是在保持分类过程中较高准确率的同时，找到最数量的特征。我们的研究围绕上述领域展开，我们主要处理了在整个特征空间中选择最合适子集所面临的挑战。

## 11.4 提议模型

在本节中，将详细解释 FSTLO 方法的工作原理。在该方法中，算法从随机生成初始种群开始（包括教师和学生）。种群是二进制解的集合，有助于根据值 1 或 0 来选择或拒绝特征。在这里，我们将这种基于教学学习的优化技术融入封装特征选择（FS）技术的概念中。基于封装的特征子集选择的底层理念是从原始数据集的所有特征中随机选择一组特征。通过多次迭代，它会选择不同的集合并评估个体选择的适应度。选择适应度最大的一个并将其选为特征。封装选择技术有三种：前向选择、后向选择和双向消除。在结合教学学习优化实现封装选择技术后，将对性能进行评估。整体方法论包括以下步骤：

(1) 从不同来源收集数据；
(2) 这些原始数据包含许多不一致性、无关值和空值；
(3) 通过 FS 方法移除冗余数据。在这里我们使用了封装选择方法，因此将高维数据转换为低维数据并移除不必要的信息。背后的数学原理是提取与预测变量具有最大相关性的显著特征。
(4) 然后我们应用分类方法并评估准确率和精确率值。

现在将描述用于寻找最优特征的 FSTL 方法的具体工作。这是一个双阶段过程，例如教师和学生，由教师训练学生。让我们使用数据集 $X=\{X_1, X_2, \dots, X_m, D\}$，其中 $D$ 是问题的维度（主题），$i = 1, 2, 3, \dots m$ 是实例数量。起初，生成随机种群并与训练数据结合生成新特征集。使用分类算法计算新构建特征集的适应度（误差）。在这里，使用 KNN 算法计算适应度，取值为 $k=5$。需要最小化该适应度以提高模型性能。

在教师阶段，适应度最小的个体被视为教师。教师试图通过共享知识来提高学生的性能。学生的知识根据学生适应度和教师适应度之间的差异进行更新。学生的适应度更新为：

$X_{student} = X_{student} + w \times (X_{teacher} - X_{student})$

其中 $w$ 是 0 到 1 之间的学习率。此过程适用于种群中的所有学生。所有学生更新后，通过选择适应度最好的学生来更新教师。此过程重复多次，直到满足停止标准。

在学生阶段，学生之间相互交互以改进知识。每个学生的知识根据其适应度另一个学生适应度之间的差异进行更新。学生的适应度更新为：

$X_{student} = X_{student} + w \times (X_{other} - X_{student})$

其中 $w$ 是 0 到 1 之间的学习率。此过程适用于种群中的所有学生。所有学生更新后，通过选择适应度最好的学生来更新教师。此过程重复多次，直到满足停止标准。
