# 3.5 RESULTS AND DISCUSSION

From Table 3.1, it can be observed that the existing models obtain higher accuracy for 47 classes; they perform poorly while dealing with 211 character classes. A hybrid model helps in increasing the recognition using multiple stages. In this study, we proposed two types of hybrid models based on the number of stages required: a two-stage hybrid model and a three-stage hybrid model. In the two-stage feature-based model, the recognition of the first stage are further refined using LFD and GRNN.
