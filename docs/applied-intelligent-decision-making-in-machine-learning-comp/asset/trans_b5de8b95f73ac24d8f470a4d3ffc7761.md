因此，引入了暗通道先验（DCP）[10, 22, 39]，该方法假设图像的某些像素在任何颜色通道中具有较低的强度，其最小值为暗像素。这些暗像素有助于雾的传输。这是去雾输入雾天图像最常用的方法之一 [15]，但它无法从与白雾相似的图像中去除雾气，例如白色物体或汽车大灯。在各向异性扩散 [36] 中，可以从图像的任何部分（线条、边缘等）去除雾气，尽管结果的可视性较差。

在本章中，提出了一种高效的基于图像的去雾方法，使用对比限制直方图均衡化（CLAHE）和引导滤波（GF）从雾天图像中去除雾气。直方图均衡化是最常用的图像增强技术之一，它只有在图像中像素分布均匀时才能良好地工作。自适应直方图均衡化（AHE）可以克服这个问题。然而，该方法的问题仍然是它倾向于过度放大图像的对比度。因此，引入了 AHE 的变体 CLAHE。该过程与 AHE 类似，但使用 [0, 1] 范围的归一化裁剪来消除噪声和对比度的过度放大。虽然它可以减少过度放大的问题，但可能会因为裁剪直方图而丢失某些信息。为了从 CLAHE 输出的图像中获得最后的信息，对结果图像应用了边缘保持引导滤波。

## 12.2 文献综述

在 [20] 中，通过考虑大气颗粒在不同天气条件下会发生散射，建立了一种大气散射模型。此后，目前已经提出了多种基于多图像 [29, 30]、基于天气条件的方法 [21, 22, 25] 以及基于暗通道先验的去雾方法。

基于物理的去雾技术 [15, 34] 也也得到了发展，其中可以使用估计的天气信息来恢复图像对比度。但它仅适用于某些已知的场景深度。另一种基于图像的去雾技术是基于深度图的方法 [14, 23]，它根据用户输入的深度信息来对图像进行去雾。这种方法的问题是它不是自动的，需要用户交互。另一种对图像去雾的有效方法是基于小波的融合方法 [8]，它可以去除图像中的模糊效果。

基于多图像去雾方法的唯一局限性是它需要同一场景的多个图像，这在许多场景中（例如任何移动物体）可能非常难以获取。因此，基于单图像的去雾方法变得越来越流行，因为它只需要一个输入图像，从而解决了多图像去雾方法所面临的问题。

论文 [40] 提出了一种使用对比限制 AHE 的去雾方法。该方法将 RGB 图像转换为 HSI 颜色模型，然后使用 CLAHE 处理图像的强度分量。所提方法的缺点是某些图像信息可能会丢失，图像的对比度可能会受到干扰。图像处理的一些先进技术描述如下：

Jackson 等人在 [11] 中描述的最有效的去雾方法之一是基于暗通道先验 [2]，该方法假设无雾图像中的某些斑块具有非常低的强度。通过使用 DCP，可以获得雾的厚度，从而提高雾图像质量。然而，DCP 方法有两个局限性：首先，它无法去除类似于大气光的物体，例如雪地或汽车大灯；其次，其实时性较高。Chaudhary 等人在 [1] 中提出了一种计算大气光的方法。在 [2] 中，使用高斯分布提出了一种大气光估计方法，其时间复杂度低于其他方法。DCP 结合高斯滤波器用于 [9]，尽管该方法适用于具有均匀雾的图像，但在保留边缘方面存在不足。

[16] 中提出的新方法结合了 DCP 和 亮度通道先验（BCP），该方法有效地实现了图像清除，但由于 DCP 和 BCP 是一种统计量，在某些特定图像上可能无法产生预期结果。基于非局部颜色先验（NLCP）的方法被提出 [17]。此外，[18] 引入了基于快速暗通道先验（FDCP）的方法以提高速度。基于引导通道先验（GCP）的方法被提出 [19] 以增强边缘。最后，基于引导滤波（GF）的方法被用于 [20] 以提高去雾图像的质量。

## 12.3 背景研究

### 12.3.1 白平衡 (WB)

在初始阶段，对输入的雾天图像应用白平衡。相对于白色识别或调整图像的实际颜色，使其看起来更自然。雾天图像通常具有较高的温度，即较冷的光。由于由于，可能会产生颜色偏差（特定的不需要色调），影响图像质量。在输入的雾天图像上应用 WB 进行校正。白平衡程序的伪代码如算法 12.1 所示。

Output: 白平衡图像

  [M, Scale] ← Scale(Img)
  if Scale > 1 then
    R_avg ← mean(mean(Img(:, :1)), :1))
    G_avg ← mean(mean(Img(:, :2)))
