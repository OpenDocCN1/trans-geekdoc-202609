An output gate is missing in this approach and the modified network consists of two gates, known as an update and a reset gate, that make it simpler in architecture and faster in execution; it reduces calculation complexity. The remaining gates handle the function of the missing gate. An update gate acts similarly to a forget and input gate: it decides which information to discard and which to throw away. How many values are decided by the reset gate. In this way, it can keep only the relevant data for a prediction problem and forget non-relevant information. GRU network has memory blocks in the place of neurons. These blocks contain gates that decide which hidden state value must choose. The recurrent networks take inputs sequentially and transform them into machine-readable vectors, while the previous output of the hidden state acts as a memory. Input and the previous hidden state are fed into the network and activated using sigmoid and tanh activation functions, which give outputs between 0 and 1 from sigmoid, and -1 and 1 from tanh. The input variables from the daily exchange rate dataset are passed through the GRU block (Figure 10.1). The update gate $z_t$ takes input $x_t$, and hidden state data $h_{t-1}$ as input, which are multiplied with their respective weight matrix ($W_z$ and $U_z$) and the obtained result is activated using the sigmoid activation function ($\sigma$):

```
$z_t = \sigma(W_z \cdot x_t + U_z \cdot h_{t-1} + b_z)$
```
