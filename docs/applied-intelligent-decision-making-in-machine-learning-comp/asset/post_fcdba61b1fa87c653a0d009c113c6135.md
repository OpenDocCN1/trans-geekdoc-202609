## 2.3.7 Linear Discriminant Analysis

The LDA is a popular technique for dimensionality reduction and supervised classification was originally developed to address the two-class problem (Fisher, 1936). It provides two regions separated by a line which aids in the classification of data and the regions, and the separation line is defined by the linear discriminant score function. This method was later generalized for multiclass problems (Rao, 1948). A linear discriminant score function is employed by the LDA method to predict the class labels following the test data instance. The discriminant score function is derived from Bayes theorem, which determines the class labels based on the probability of each class and the probability of the test data belonging to the class (2.14).

```
$P(\pi|\vec{x})=\frac{P(\pi,\vec{x})}{P(\vec{x})}$
```

where $P(\pi|\vec{x})$ is the probability of test data instance $\vec{x}$ belonging to $\pi$ class, $P(\pi,\vec{x})$ is the joint probability of $\pi$ and $\vec{x}$, and $P(\vec{x})$ is the prior probability of $\vec{x}$. The linear discriminant score function of Bayes theorem is expressed in the form of $y=ax+b$, where $a$ and $b$ are the parameters obtained from the training data and $x$ is the test data instance. A detailed derivation of linear score function from Bayes theorem can be found elsewhere (Konishi, 2014; Naik and Kiran, 2019). The linear discriminant score function for the class $i$ ($L_i$) is given as:

```
$L_i=-\frac{1}{2}\vec{\mu}_i^T\Sigma^{-1}\vec{\mu}_i+\vec{x}^T\Sigma^{-1}\vec{x}+\log p_i$
```

where $\vec{\mu}_i$ is the mean vector of each class in the training dataset, $\Sigma$ is the covariance matrix of each class in the training dataset, $\vec{x}$ is the test data instance, and $p_i$ is the prior probability of class $i$. Some of the major assumptions of performing LDA are: (i) the training and test data are normally distributed, and (ii) the covariance matrix of each class is equal. However, in reality, covariance matrix of classes is not equal, therefore to account for the variances in the dataset, a pooled covariance matrix ($\hat{S}_p$) is considered instead:

```
$\hat{S}_p=\frac{\sum_{i=1}^m\Sigma_i}{\sum_{i=1}^m(n_i-1)}$
```

$\hat{S}_p$ is the pooled covariance matrix for all classes, $m$ is the number of classes in the dataset, and $n_i$ is the number of observations in each class. Substituting Equation (2.16) in Equation (2.15), the $L_i$ function for a class is:

```
$L_i = -\frac{1}{2}\vec{\mu}_i^T\hat{S}_p^{-1}\vec{\mu}_i+\vec{x}^T\hat{S}_p^{-1}\vec{x}+\log p_i$ (2.17)
```

The $L_i$ evaluated for all classes $(m)$ in the dataset to predict the class of the incoming test data. The class that yields the maximum $L_i$ score is the class for the test data. ### Finding mean of vectors (Sepal length, petal length, and petal width) in each class
```
mu_1 <- mean(cls1[,SepalLength]), mean(cls1[,PetalLength]), mean(cls1[,PetalWidth])
mu_2 <- mean(cls2[,SepalLength]), mean(cls2[,PetalLength]), mean(cls2[,PetalWidth])
mu_3 <- mean(cls3[,SepalLength]), mean(cls3[,PetalLength]), mean(cls3[,PetalWidth])
```

### Finding variance
```
cov_mat <- as.data.frame(cov(cls1[,1:2]), cov(cls2[,1:2]), cov(cls3[,1:2]))
cov_mat[1,3] <- PetalWidth
cov_mat[2,3] <- PetalWidth
cov_mat[3,3] <- PetalWidth
```

### Finding pooled variance
```
sum <- 0
for (i in 1:3) {
  sum <- sum(cls[[i]][,1,1]]-cov_mat[i,i]); sum <- sum + (n-1)
}
sum/sum
```

### Training data: LDA predictions

```
require(MASS) # for inverse function
Creating an array for storing predicted classes
ans <- array(0, n, 1)
```

### Creating the predicted classes
```
L1 <- (1/2)*t(mu_1)*inv(Sp_1)*mu_1 + log(n/1)
L2 <- (1/2)*t(mu_2)*inv(Sp_2)*mu_2 + log(n/2)
L3 <- (1/2)*t(mu_3)*inv(Sp_3)*mu_3 + log(n/3)
ans_max <- max(L1, L2, L3)
for (i in 1:n) {
  if (ans_max == L1) {
    ans[i] <- 1
  } else if (ans_max == L2) {
    ans[i] <- 2
  } else {
    ans[i] <- 3
  }
}
```
