We add a smoothing term using Equation 6.5 to avoid instability by making sure the weight value is not equal to 0.

```
w_i = \frac{W_j + e}{1 + e} \quad (6.5)
```

where a small positive number like 0.01 is given as $e$ in our experiment. The result is $w_i \in [0,1]$. The weight assignment of each cluster is computed using a binary Jaccard measure given in Equation 6.6 which provides the similarity of proportion between the size of intersection and size of the union for objects within each pair of clusters $C_i$ and $C_j$ and associated weights.

```
S_{ij} = \frac{\sum_{x_k \in C_i \cap C_j} w_k}{\sum_{x_k \in C_i \cup C_j} w_k} \quad (6.6)
```

From Figure 6.6, the weight between the pair of clusters is given by:

```
S_{ij} = \frac{3 \times 0.8 + 0.2 + 0.6}{4 \times (0.8 + 0.2) + 0.4 + 0.6} = 0.64
```

where the $k$-th object is represented as $w_k$ and $S_{ij}$ is calculated from Equations 6.2–6.5 $S_{ij} \in [0,1]$. If $S_{ij}=0$, then there is no edge between $C_i$ and $C_j$ in Graph G. $S_{ij}$ is a similarity measure which we use to partition the meta-graph into $k^*$ meta-clusters. The partitioning algorithm adopted is METIS, which was developed by Karypis and Kumar (1998). The output of METIS is the assignment of each object to a meta-cluster based on the ratio of participation in each cluster. Finally, the object is assigned to the cluster which has the highest ratio. The optimal number of clusters from the cluster similarity matrix is found to be three. The METIS function takes this as an input. The sample output of the METIS results are explained in the following section.

### 6.4.1 FINAL CLUSTER LABELING

The METIS function gives two outputs in the form of a tuple. The first is the objective value that was minimized and the second one is a list of partition indices. ### 6.4.2 METIS Function

In comparison to various spectral partitioning algorithms, the METIS algorithm is known to consistently produce 10–50% better results for graph partitioning (Karypis and Kumer 1998). It is a group of serial programs used to reduce the orderings for sparse matrices, to partition finite element meshes, and to partition graphs. Multi-constraint partitioning, multi-level k-way, and multi-level recursive bisection schemes form the basis of the algorithms implemented in METIS, which is used to partition undirected graphs where the directionality of an edge does not play any role during partitioning. This is because if an edge (u, v) is cut, the edge (v, u) also is. For a directed graph to be partitioned by METIS, it first needs to be converted into an undirected graph by adding an edge (v, u) for each directed edge (u, v).

### 6.4.3 PHASES

METIS incorporates a multi-level approach which includes three phases:
1. **Coarsening Phase**: A series of graphs, $G_0, G_1, \dots, G_n$, can be generated to coarsen the graph.
2. **Initial Partitioning Phase**: The smallest graph is partitioned.
3. **Uncoarsening Refinement Phase**: The partition is then projected back onto the original graph and refined.

### 6.4.4 ADVANTAGES

METIS is chosen as the graph partitioning algorithm as it is known to provide high quality. Very large-scale (VLSI), linear programming, transportation, and other domains in which experiments have been conducted show that it is consistently better than widely used algorithms. Another advantage of METIS is that it is orders of magnitude faster. It can partition graphs with almost no time.
