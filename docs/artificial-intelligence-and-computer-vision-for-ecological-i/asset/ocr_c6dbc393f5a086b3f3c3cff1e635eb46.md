# ***Radiometric Correction***

Radiometric correction involves adjusting pixel values for sensor noise, atmospheric conditions, and lighting variations. Techniques like dark object subtraction, atmospheric models, and radiometric calibration standardize the reflectance values (Escandón-Panchana et al., 2024). This correction ensures the data accurately represents the observed features’ true spectral characteristics, facilitating reliable interpretation and analysis (Afxentiou et al., 2021).

# ***Image Enhancement***

Image enhancement techniques improve the visual appearance of RS data, making it easier to identify and analyze specific features (Zhang et al., 2023a). Histogram equalization, contrast adjustment, and edge enhancement are commonly used. Enhanced images can reveal details that are not readily visible in raw data, aiding in detecting and interpreting regional features (Escandón-Panchana et al., 2024).

# ***Image Classification***

Image classification categorizes pixels into different land cover classes based on spectral properties (Sachithra and Subhashini, 2023). Supervised classification techniques, such as Random Forest and Support Vector Machines (SVM), require labeled training data to guide the classification process (Singh et al., 2022). Unsupervised classification methods, like k-means clustering, group pixels into classes based on similarities in their spectral signatures without prior labeling. DL approaches, such as Convolutional Neural Networks (CNNs), offer advanced capabilities for automated classification with high accuracy (Afxentiou et al., 2021).

# ***Data Fusion***

Data fusion integrates information from multiple sources to enhance the overall accuracy and completeness of agricultural mapping (Omyatov et al., 2023). Techniques such as multisensor fusion combine data from different sensors, temporal fusion integrates observations over time, and spatial fusion merges data from various spatial resolutions. Effective data fusion provides a comprehensive view of agricultural conditions, supporting informed decision-making (Escandón-Panchana et al., 2024).
