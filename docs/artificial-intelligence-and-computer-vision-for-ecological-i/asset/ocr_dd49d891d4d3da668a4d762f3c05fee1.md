# Literature Review

Machine learning (ML) uses data and algorithms to learn, and gradually improve the performance of a system as suggested by Samuel (1959) and Alpaydin (2020). Benos (2021) suggested that machine learning methods can be applied in agriculture allowing for more efficient and precise farming since machine learning can help establish knowledge-based farming systems. ML algorithms can analyze large datasets of agricultural data, such as crop yields, soil, and weather data, to identify patterns and gain knowledge of agricultural data. Liakos (2018) analyzed the use of ML for different agricultural areas: water management, soil management, livestock production and management, and crop management. Deep learning (DL) is a subset of machine learning (ML). LeCun (2015) and Schmidhuber (2022) recommended that DL extends classical ML by incorporating depth and complexity into models, which enables learning through multiple levels of abstraction. DL consists of multiple processing layers that enable hierarchical learning as suggested by Schmidhuber (2015). Jain (1999) in turn proposed that recurrent neural networks (RNNs) model temporal dynamic behavior. They contain loops, and connections between nodes create cycles, allowing the outputs from some nodes to affect subsequent inputs to the same nodes.
