# ### Support Vector Machine (SVM)

SVM aims to find the optimal hyperplane that separates data into distinct classes. (Fan et al., 2018) Support Vector Machine (SVM), a supervised machine learning technique, is used for both regression and classification tasks, excelling particularly in regression. Identifying the ideal hyperplane in an N-dimensional space to divide data points into different classes inside the feature space is its main goal. The hyperplane’s layout aims to optimize the separation between each class’s closest points. The number of features dictates the hyperplane’s dimensionality. SVM performs effectively in high-dimensional spaces. However, understanding and interpreting the final SVM model, variable weights, and individual impacts can be challenging due to the black-box nature of the technique.

# ### Extreme Gradient Boosting (XGBoost)

The traditional gradient boosting decision tree methodology is not the same as XGBoost, an upgraded decision tree approach. XGBoost adds the second-order Taylor expansion to the loss function, using both first and second-order derivatives, whereas regular GBDT only uses first-order derivative information for the optimization issue (Chen and Guestrin, 2016). A regularisation term is also included in the loss function to manage the model’s complexity and avoid over fitting. Through boosting, XGBoost enhances the performance of underachieving students. While XGBoost’s iterative refining process and SVM’s structural complexity increase their predictive potential, they also bring uncertainty, particularly when it comes to identifying complex patterns and non-linear correlations.
