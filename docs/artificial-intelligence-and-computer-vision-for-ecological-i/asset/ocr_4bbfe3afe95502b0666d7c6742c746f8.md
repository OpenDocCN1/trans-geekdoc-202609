Once sufficiently trained, however, they should be able to provide correct outputs for inputs that have never been seen before (Palani et al., 2008). ANN processes inputs by multiplying them by a sequence of weights, adding a constant value, and processing the resultant data through a transfer function, as seen in the figure. The input layer, middle layer, and output layer make up the three layers that make up a neural network. The input layer is in charge of supplying the network with inputs (Fig. 2). The majority of calculation is done by the intermediate layer, which may consist of one or more hidden layers. Within the centre layer, these concealed layers function as sublayers. The output layer compiles the outcomes of the middle layer’s parallel calculations. Each neuron’s output can be compared with observed data or utilized as an input for neurons in a layer below it. Through a training procedure, the network’s weights and biases are modified (Haghiabi et al., 2016).
