# K-Nearest Neighbor

KNN is a non-parametric and robust technique that is utilized to address classification and regression difficulties. It does not rely on hypotheses regarding the fundamental data dissemination. The K-Nearest Neighbor (KNN) approach operates on the principle of similarity. Through the examination of the numerical values of its K nearest neighbors in the training dataset, it predicts the value for a new data point (Uddin et al., 2023). There is no need to make any conjectures about the allocation of data. The K value denotes the total quantity of nearest neighbors. KNN aims to ascertain the precise category for the test data by computing the proximity that exists between the test data and each training point (Zhang et al., 2021). There are several techniques available for computing this distance, with the most widely recognized ways being Euclidean distance (continuous data), Manhattan distance (continuous data), and Hamming distance (categorical data). The computational cost of updating distance measures with every loop is high, which is why KNN is considered a lazy learning algorithm.

The KNN algorithm is both time-consuming and resource-intensive. The algorithm encounters difficulty in accurately categorizing the data points when the number of dimensions is very large. It is also susceptible to the issue of excessive fitting.
