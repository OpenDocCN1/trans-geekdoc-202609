# Wrapper Methods

These are used in assessing feature subsets by measuring their influence on model performance, resulting in higher computational complexity compared to filter methods. These methods evaluate the quality of feature subsets by directly training and testing a predictive model using various combinations of features (Singh et al., 2022). Recursive Feature Elimination (RFE) is a widely used technique that systematically eliminates the least significant features in a model based on performance indicators like accuracy or error rate. Forward and backward selection are alternative wrapping approaches that begin with either an empty or complete set of features. They progressively include or exclude features based on their impact on the model's performance (Nadeem et al., 2022). Wrapper approaches have the advantage of considering feature interactions, but they can be computationally expensive, particularly for datasets with various dimensions.

# Embedded Methods

Embedded methods incorporate feature selection directly into training the model, providing a smooth and integrated approach to feature selection. These strategies utilize regularization techniques or inherent feature importance measures in the predictive model to choose relevant features (Tey et al., 2024). Lasso, also known as the Least Absolute Shrinkage and Selection Operator, is a widely used embedded method that uses L1 regularization to penalize the absolute magnitude of feature coefficients. This regularization technique effectively forces some coefficients to become zero, resulting in selecting a subset of features. Tree-based approaches, such as decision trees and Random Forests, naturally conduct feature selection by dividing nodes according to feature relevance metrics such as Gini impurity or information gain (Kumar et al., 2024b).
