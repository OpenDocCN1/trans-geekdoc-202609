# Multiple Linear Regression

Multiple linear regression is the leeway of simple linear regression that contains multiple predictor variables. This model is useful when there are multiple factors that influence crop yields, such as temperature, precipitation, and soil type. The equation for multiple linear regression is:

$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n$ (7)

where $\hat{y}$ is the predicted crop yield, $\beta_0$ is the intercept, $\beta_0, \beta_1, \beta_2, ... \beta_n$ are the slopes for each predictor variable, and $x_1, x_2, ..., x_n$ are the predictor variables.

**Example:** Application of multiple linear regression in crop yield estimation, consider the following example where we use three predictor variables: Temperature (°C), Rainfall (mm), and Soil pH.

In this example, we aim to estimate the crop yield (Y) based on Temperature (X₁), Rainfall (X₂), and Soil pH (X₃).

The multiple linear regression model can be represented as:

$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 X_3 + \epsilon$ (8)

where Y is the crop yield, X₁ is the temperature, X₂ is the rainfall, X₃ is the soil pH, β₀ is the intercept, β₁, β₂, and β₃ are the coefficients for the predictor variables, and ε is the error term.
