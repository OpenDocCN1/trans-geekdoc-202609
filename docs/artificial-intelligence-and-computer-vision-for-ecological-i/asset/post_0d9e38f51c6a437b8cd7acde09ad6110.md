
## Decision Trees

Decision trees are the simplest and most commonly used supervised learning algorithms for soil-moisture prediction. The basic architecture of decision trees relies on the segmentation of the input data into multiple groups based on the values of the input features, which results in a tree-like model with decision rules (Fig. 3). At every tree node, a decision related to a certain feature is made, and the next tree branch is considered as a result of this decision until we reach a leaf node in which the soil moisture level is to be predicted (Pekel, 2020). A key benefit of using decision trees is their simplicity and interpretability. Decision trees are a good illustrative way to gain insight into how a model arrives at its prediction. ## Random Forest

Random forest can be seen as a powerful ensemble learning technique that addresses the overfitting problem typically found in individual decision trees. By combining the wisdom of several decision trees, random forests build a solid and versatile prediction model to estimate soil moisture. The key concept of the random forest model is to build multiple uncorrelated trees by introducing randomness at different stages of tree generation (Breiman, 2001). During the training phase, every decision tree in the random forest is trained with a random subset of training data and a random subset of input features. This randomness allows each tree to capture different aspects of the underlying data distribution, thereby reducing the risk of overfitting to some subset of the training data that might be present. Bootstrapping (sampling with replacement) contributes to further diversity in individual trees and therefore strengthens the ensemble model.

To make the final prediction using a random forest, the different trees agglomerate the different predictions from individual trees. This ensemble method specifically solves the problem associated with individual high-variance predictions, thus enhancing the generalization of the model to new data (Fig. 4). Furthermore, random forests can handle a large number of input features. This makes them ideal for soil moisture prediction, which typically involves complex and high-dimensional data (Hengl et al., 2015). Random forests have several advantages over other

## Support Vector Machines (SVMs)

Among the wide array of supervised learning algorithms, Support Vector Machines (SVMs) are a prominent candidate for soil moisture prediction. SVMs find the best hyperplane to separate data into classes, effectively distinguishing ‘dry,’ ‘moist,’ and ‘wet’ soil based on features like temperature, humidity, soil type, and remote sensing indices (Fig. 5). They excel in high-dimensional spaces by using kernel functions to transform input data into a feature space where linear separation is feasible, aiding both linear and nonlinear classification tasks (Adankon and Cheriet, 2009). Applying supervised learning for soil moisture prediction involves several key steps to achieve accurate and reliable models (Karthikeyan et al., 2020). Labelled datasets containing input features and corresponding soil moisture measurements are initially collected. Data preprocessing addresses issues like missing values, normalizing features, and partitioning the dataset into training and test sets. Feature selection methods, such as feature-importance scoring and correlation analysis, identify the most relevant features (Guyon and Elisseeff, 2003).

## K-Nearest Neighbors

K-nearest neighbors (KNN) is a simple yet powerful algorithm for classifying soil moisture levels (Gounaridis et al., 2019). It classifies data points based on the majority vote of their k-nearest neighbors in the feature space, using distance measures like Euclidean, Manhattan, or Minkowski (Nurdiwan et al., 2021; Ratih et al., 2021). The input features for KNN models typically include variables like temperature, humidity, soil type, and remote sensing indices such as NDVI (Valavi et al., 2019).

KNN is a non-parametric model, meaning it does not assume an underlying data distribution, making it flexible for various classification tasks (Fig. 6). This flexibility is advantageous for soil moisture classification, where relationships between input features and moisture levels can be complex and non-linear. Despite its simplicity and ease of implementation, KNN has high computational costs, especially with large datasets, due to the need to calculate distances for all data points. Moreover, KNN’s performance is sensitive to the choice of k and the scaling of input features. Cross-validation can help determine the optimal k, and proper feature scaling is necessary to avoid biased classifications.

KNN helps classify fields into “dry,” “moist,” or “wet” conditions, aiding farmers in planning irrigation practices efficiently. An ensemble of Kernel K-nearest neighbors (KKNN) models has been used to predict daily soil surface moisture (SSM) at a 100-meter resolution, showing a 27% reduction in spatial error and improved temporal predictive performance compared to coarse resolution datasets (Warner et al., 2021). However, these models still struggle with accurately estimating SSM in wetland areas, highlighting the need for better in situ SSM monitoring across diverse landscapes.

## Regression Models for Soil Moisture Prediction

Regression models are key to predicting continuous soil moisture levels based on different input characteristics. It was designed to determine any observed relationship between the independent variables, such as temperature, humidity, soil type, and remote sensing indices, and the dependent variable (soil moisture content). By modeling these relationships (Fig. 7), regression techniques permit the optimal quantification of soil moisture, which is important in applications that require forceful numerical predictions.

### Linear Regression

Linear regression is perhaps one of the most simple and common types of linear models that are used for regression operations. It builds relationships between the input features and soil moisture content using a linear equation. The underlying concept is to identify the best-fitting straight line—also referred to as the regression line—so that the residual sum of squares between the observed and those predicted by the line soil moisture values is minimized. This method is implemented when the assumption of a linear relationship between the input features and target variable holds. As linear regression is implemented and interpreted without difficulty, it constitutes an easy approach to soil moisture prediction. However, its simplicity could become a drawback when there is an occurrence of complicated, non-linear relationships observed in the data (Paul and Singh, 2021).

Polynomial regression extends the linear model to address the limitations of linear regression; it introduces the polynomial term of the input features. This enables a model to fit a polynomial equation to a dataset, thus enabling it to capture relations that might be more complex. For instance, a quadratic regression will have squared terms of input features, which will enable the model to handle the curvature of the data. Polynomial regression is particularly helpful when the relationship between the input features and soil moisture is non-linear.
