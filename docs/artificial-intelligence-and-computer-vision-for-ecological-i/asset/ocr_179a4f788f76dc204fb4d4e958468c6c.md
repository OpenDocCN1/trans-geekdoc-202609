# Decision Trees

Decision trees are the simplest and most commonly used supervised learning algorithms for soil-moisture prediction. The basic architecture of decision trees relies on the segmentation of the input data into multiple groups based on the values of the input features, which results in a tree-like model with decision rules (Fig. 3). At every tree node, a decision related to a certain feature is made, and the next tree branch is considered as a result of this decision until we reach a leaf node in which the soil moisture level is to be predicted (Pekel, 2020). A key benefit of using decision trees is their simplicity and interpretability. Decision trees are a good illustrative way to gain insight into how a model arrives at its prediction.
