# Logistic Regression

Logistic regression is generally used for classifying soil moisture due to its probabilistic approach. Unlike linear regression, logistic regression calculates the probability of an input fitting to a specific class using a logistic function (sigmoid function), transforming predictions into probabilities ranging from 0 to 1. The logistic function transforms the regression output into class probabilities, making them interpretable. It estimates the relationship between input features and the log odds of the target variable through an iterative optimization algorithm, fitting the model to the data. It can handle binary classification (e.g., “dry” vs. “not dry”) and multi-class classification using extensions like multinomial logistic regression to predict probabilities for multiple categories (e.g., “dry,” “moist,” “wet”). One of the strengths of logistic regression is its interpretability. The model coefficients indicate the strength and direction of the relationships between input features and class probabilities, helping analysts understand which features are significant for classifying soil moisture levels (De Figueiredo et al., 2021).

However, logistic regression assumes a linear connection between input features and the log odds of the target variable, which might not be valid for complex datasets with nonlinear relationships. Thus, it might not perform well on complex data. Despite this, logistic regression is commonly used in agriculture for soil moisture classification, aiding land managers and farmers in irrigation scheduling and crop management by predicting the probability of different soil moisture levels. It helps interpret the factors influencing soil moisture, leading to better management strategies.

# Neural Networks

Deep learning, a subset of machine learning, includes neural networks (NNs) that process large, high-dimensional data for soil moisture prediction (Shen, 2018). Neural networks excel at uncovering hidden patterns and relationships that traditional machine learning models often miss (Rakshitkhajuria et al., 2018). For instance, feedforward neural networks can be trained on diverse input features to capture the processes generating soil moisture values (Zhou et al., 2023). Inspired by the human brain, neural networks are well-suited for deep learning tasks in remote sensing (Fig. 8). These architectures, comprising multiple layers, learn hierarchical representations of input features, such as temperature, humidity, soil type, and remote sensing indices, to predict soil moisture content. An important advantage of deep learning is its ability to automatically generate features from raw data, capturing subtle and nonlinear interactions.
