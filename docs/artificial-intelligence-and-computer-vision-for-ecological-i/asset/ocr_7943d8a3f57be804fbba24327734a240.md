# Overview on Machine Learning

A subtype of artificial intelligence (AI) called machine learning enable systems or computers to acquire knowledge through the analysis of data or personal encounters. Instead of depending just on pre-programmed rules or equations (Rani et al., 2022). Processing data, choosing appropriate algorithms, training models, and testing them are all steps that must be taken before machine learning is applied in real-world situations (Zhu et al., 2022). Before employing any machine learning (ML) algorithms, users must assemble data and ensure its significance. Subsequently, they choose a suitable machine learning method that aligns with their intended goal. The chosen technique is then used on the training set to produce a model that accurately depicts the dataset. The correctness and effectiveness of the model are evaluated by utilizing testing data. If the model’s quality is not satisfactory, users might experiment with alternative methodologies, expand the dataset, or enhance the data’s quality. The model is deployed to accomplish its intended goal after it performs satisfactorily. Categorically, machine learning algorithms are grouped into three primary categories: supervised learning, unsupervised learning, and Reinforcement learning (Berry et al., 2019; Mosaffa et al., 2022). In supervised learning: models are trained on labeled datasets with predetermined output. By analyzing input data, the model learns to anticipate desired outputs and is improved until it reaches the required accuracy (Han et al., 2011). It uses techniques including support vector machine, linear regression, and neural networks, which are often employed, mainly for classification and regression applications (Sarker et al., 2020). Unsupervised learning focuses mostly on grouping and association tasks by using unlabeled data to find hidden patterns and group related data (Han et al., 2011). Algorithms like hierarchical clustering and k-means are commonly used. Reinforcement learning uses response in the structure of incentives or penalties to repeatedly make judgements that lead algorithms through unpredictable settings. Since data is generated by the algorithm’s interaction with the environment, predefined data is not given (H. Jhaveri et al., 2021). Well-known algorithms are SARSA, Q-learning, and Deep Deterministic Policy Gradient (DDPG) Algorithm, and more (Rani et al., 2022). However, it is less commonly applied in the realm of water environments compared to the other two classes of machine learning.
