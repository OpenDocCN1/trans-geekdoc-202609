First, we calculate the mean of the crop yield and temperature:

$\underline{y}=\frac{2.5+3.0+3.5+4.0+4.5+5.0}{6}=3.5$

$x=\frac{15+16+17+18+19+20}{6}=17.5$

Next, we calculate the deviations from the mean:

$y_i - \underline{y}= y_i - 3.5$

$x_i - \underline{x}= x_i - 17.5$

Then, we calculate the covariance between the deviations:

$Cov(y,x)=\frac{\sum_{i}(y_i-\underline{y})(x_i-\underline{x})}{n-1}$

$Cov(y,x)=\frac{(2.5-3.5)(15-17.5)+(3.0-3.5)(16-17.5)+\cdots+(5.0-3.5)(20-17.5)}{6-1}$

$Cov(y,x)=\frac{-0.5\times-2.5+0.0\times-0.5+\cdots+1.5\times2.5}{5}$

$Cov(y,x)=\frac{1.25+0.75+\cdots+1.25}{5}$

$Cov(y,x)=\frac{-5.0}{5}=1.0$

Finally, we calculate the slope and intercept using the following formulas:

$\beta_1=\frac{Cov(y,x)}{Var(x)}$

$\beta_0=\underline{y}-\beta_1\underline{x}$

$\beta_1=\frac{1.0}{Var(x)}$

$\beta_0=3.5-\beta_1\times17.5$

$\beta_1=\frac{1.0}{(20-15)^2\times6}=0.05$

$\beta_0=3.5-0.05\times17.5=2.25$

The simple linear regression model for crop yield estimation based on temperature is:

$\hat{y}=2.25+0.05x$

This model can be used to predict crop yields based on temperature. For example, if the temperature is 18°C, the predicted crop yield would be:

$\hat{y}=2.25+0.05\times18=4.0$
