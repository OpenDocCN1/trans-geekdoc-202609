# 1. Scanning Multichannel Microwave Radiometer (SMMR):

+   - Launch Date: 1978–1987.
+   - Frequency: Operates on multiple bands, including 6.6 GHz, 10.7 GHz, 18 GHz, 21 GHz, and 37 GHz.
+   - Swath Width: 822 km.
+   - Polarization: Horizontal and Vertical (H & V).
+   - Temporal Resolution: Not specified.

# 2. Special Sensor Microwave/Imager (SSM/I):

+   - Launch Date: 1987/1992/1995.
+   - Frequency: Operates on 19 GHz, 22 GHz (Vertical polarization), 38 GHz, and 85.5 GHz.
+   - Swath Width: 1,400 km.
+   - Polarization: H & V.
+   - Temporal Resolution: 1 day.

# 3. Multifrequency Scanning Microwave Radiometer (MSMR):

+   - Launch Date: 1999–2001.
+   - Frequency: Bands include 6.6 GHz, 10.65 GHz, and 18.21 GHz.
+   - Swath Width: 1,360 km.
+   - Polarization: H & V (excluding 22.23 GHz).
+   - Temporal Resolution: 2 days.

# 4. Soil Moisture and Ocean Salinity (SMOS):

+   - Launch Date: 2009.
+   - Frequency: 1.4 GHz.
+   - Swath Width: Not specified.
+   - Polarization: H & V.
+   - Temporal Resolution: 3 days.

# 5. Advanced Microwave Scanning Radiometer for EOS (AMSR-E):

+   - Launch Date: 2002–2011.
+   - Frequency: Multiple bands, including 6.6 GHz, 10.65 GHz, 18.7 GHz, 23.8 GHz, 36.5 GHz, and 89 GHz.
+   - Swath Width: 1,445 km.
+   - Polarization: H & V.
+   - Temporal Resolution: 2 days.

# 6. Tropical Rainfall Measuring Mission (TRMM):

+   - Launch Date: 1997–2001.
+   - Frequency: 10.65 GHz, 19.35 GHz, 22.24 GHz, 37 GHz, and 85.50 GHz.
