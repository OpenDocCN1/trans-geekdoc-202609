### Overview on Machine Learning

A subtype of artificial intelligence (AI) called machine learning enables systems or computers to acquire knowledge through the analysis of data or personal encounters, instead of depending just on pre-programmed rules or equations (Rani et al., 2022). Processing data, choosing appropriate algorithms, training models, and testing them are all steps that must be taken before machine learning is applied in real-world situations (Zhu et al., 2022). Before employing any machine learning (ML) algorithms, users must assemble data and ensure its significance. Subsequently, they choose a suitable machine learning method that aligns with their intended goal. The chosen technique is then used on the training set to produce a model that accurately depicts the dataset. The correctness and effectiveness of the model are evaluated by utilizing testing data. If the model’s quality is not satisfactory, users might experiment with alternative methodologies, expand the dataset, or enhance the data’s quality. The model is deployed to accomplish its intended goal after it performs satisfactorily. Categorically, machine learning algorithms are grouped into three primary categories: supervised learning, unsupervised learning, and Reinforcement learning (Berry et al., 2019; Mosaffa et al., 2022). In supervised learning, models are trained on labeled datasets with predetermined output. By analyzing input data, the model learns to anticipate desired outputs and is improved until it reaches the required accuracy (Han et al., 2011). It uses techniques including support vector machine, linear regression, and neural networks, which are often employed, mainly for classification and regression applications (Sarker et al., 2020). Unsupervised learning focuses mostly on grouping and association tasks by using unlabeled data to find hidden patterns and group related data (Han et al., 2011). Algorithms like hierarchical clustering and k-means are commonly used. Reinforcement learning uses response in the structure of incentives or penalties to repeatedly make judgements that lead algorithms through unpredictable settings. Since data is generated by the algorithm’s interaction with the environment, predefined data is not given (H. Jhaveri et al., 2021). Well-known algorithms are SARSA, Q-learning, and Deep Deterministic Policy Gradient (DDPG) Algorithm, and more (Rani et al., 2022). However, it is less commonly applied in the realm of water environments compared to the other two classes of machine learning.

### Advanced Machine Learning Models for Evaluation of the Quality of the Water

Accurately predicting the Water Quality Index (WQI) has been contingent significantly on integrating artificial intelligence (AI) forecasting models, notably machine learning classifiers like Random Forest, SVM, XGBoost, KNN, and Decision Trees.

#### Random Forest

The tree-based Random Forest (RF) method is a classification technique that consists of many decision trees and operates as a supervised machine learning methodology (Fig. 1). As the number of trees in the forest rises, RF, as an ensemble approach, limits and reduces generalization mistakes by using the best results from several decision trees (Breiman, 1999).

#### Support Vector Machine (SVM)

SVM aims to find the optimal hyperplane that separates data into distinct classes (Fan et al., 2018). Support Vector Machine (SVM), a supervised machine learning technique, is used for both regression and classification tasks, excelling particularly in regression. Identifying the ideal hyperplane in an N-dimensional space to divide data points into different classes inside the feature space is its main goal. The hyperplane’s layout aims to optimize the separation between each class’s closest points. The number of features dictates the hyperplane’s dimensionality. SVM performs effectively in high-dimensional spaces. However, understanding and interpreting the final SVM model, variable weights, and individual impacts can be challenging due to the black-box nature of the technique.

#### Extreme Gradient Boosting (XGBoost)

The traditional gradient boosting decision tree methodology is not the same as XGBoost, an upgraded decision tree approach. XGBoost adds the second-order Taylor expansion to the loss function, using both first and second-order derivatives, whereas regular GBDT only uses first-order derivative information for the optimization issue (Chen and Guestrin, 2016). A regularisation term is also included in the loss function to manage the model’s complexity and avoid overfitting. Through boosting, XGBoost enhances the performance of underachieving students. While XGBoost’s iterative refining process and SVM’s structural complexity increase their predictive potential, they also bring uncertainty, particularly when it comes to identifying complex patterns and non-linear correlations.
