Q 表示每个状态下动作的质量。因此，我们不再使用每个状态的值，而是使用状态和动作的一对，即 Q(s, a)。Q 值指定哪个动作比其他动作更有效，并且根据最佳 Q 值，智能体采取下一步行动。贝尔曼方程可用于推导 Q 值。

要执行任何动作，智能体将获得奖励 R(s, a)，并且会到达某个状态，因此 Q 值方程如下：

```
Q(s, a) = R(s, a) + \gamma \sum_{s'} P(s, a, s') V(s')
```

因此，我们可以说，V(s) = max [Q(s, a)]

Q(s, a) = R(s, a) + \gamma \sum_{s'} (P(s, a, s') \max Q(s', a'))

上述公式用于在 Q-Learning 中估计 Q 值。

## Q-Learning 中的“Q”？

Q 在 Q-Learning 中代表质量，这意味着它指定了智能体采取的动作的质量。

### Q 表：

在执行 Q-Learning 时会创建一个 Q 表或矩阵。该表遵循状态和动作的一对，即 [s, a]，并将值初始化为零。每次动作后，表将被更新，Q 值将存储在表中。

RL 智能体使用此 Q 表作为参考表，根据 Q 值选择最佳动作。

## 7.4 用于软物质工艺和材料设计优化的强化学习技术

机器学习的一个替代分支，无需预先生成训练数据集，即强化学习（RL）。在 RL 范式中，目标是训练智能体在交互式环境中通过对其性能提供反馈（奖励）来学习完成特定任务或一组任务。智能体本质上是在学习如何为给定任务求解最优控制问题。近年来，RL 在游戏、蛋白质折叠、机器人控制等领域取得了突破性成就。

RL 智能体在工程设计过程中可能有助于解决多个复杂的优化挑战。传统的设计自动化方法，如拓扑优化（TO），要求对目标和约束进行正式的数学表示，这对于许多工艺来说可能难以制定。此外，如果可以开发目标和约束函数，它们应当是连续和平滑的，以提高收敛能力。能够使用黑盒模拟的优化器将很有帮助。虽然启发式优化工具可以解决其中一些挑战并与黑盒模拟工具配合使用，但 RL 智能体在许多领域已显示出优于启发式方法的性能。

RL 相对于其他机器学习方法，在工程设计自动化方面提供了独特的优势。设计师无需依赖预先制作的训练集，可以在学习过程中利用 RL 创建训练数据。设计师必须创建一个 RL 环境来捕捉设计问题的关键信息。RL 智能体现在可以通过与环境交互来学习满足给定的设计目标。环境指定智能体可以采取的动作，并对其性能提供反馈。环境可以使用几乎任何工程分析工具的组合来生成此反馈，例如偏微分方程求解器、状态机、解析方程，甚至基于现实世界数据的模型。

使用 RL，工程设计问题从“给定一组输入提取最优设计”转变为“寻找一系列能够最优满足设计问题的动作的最优控制问题”。这种差异使智能体能够发挥创造力，探索人类设计师不易察觉的设计域区域。此外，最优序列可能需要经过若干个次优设计，而梯度优化器在达到最佳设计之前可能会陷入局部最小值。RL 智能体的创造力在寻找游戏中的独特策略并利用游戏环境中的漏洞来最大化奖励函数方面广为人知。因此，RL 智能体可以学习在设计空间中探索或利用哪些区域以找到最佳设计，这在复杂的设计空间中对人类来说可能很困难。

RL 目前正在用于辅助工程设计和优化，包括用于流场塑造的微流体器件设计、微芯片平面布局、3D 形状建模和超表面设计。应用范围表明 RL 在工程设计领域具有泛化能力。然而，RL 技术用于设计优化拓扑的应用鲜有研究。

### 7.4.1 将拓扑优化作为强化学习问题

离散化的拓扑优化（TO）问题需要重新制定为序列 RL 任务，具体来说，是马尔可夫决策过程（MDP）。MDP 是控制中使用的离散时间随机过程。MDP 基于四个要素构建，即状态空间（S）、动作空间（A）、转移概率函数（P）和奖励函数（R）。如果 TO 问题可以用 S、A、P 和 R 来表示，那么设计最优拓扑可以是一个 MDP。

正式地，拓扑优化（TO）问题可以被视为寻找材料分布 G，以最小化目标函数 F，且受体积约束 G₀≤0 以及可能的 M 个其他约束 Gᵢ≤0（i=1⋯M）的限制。材料分布由密度变量 ρ 描述，在设计域 Ω 的任何点上，ρ 可取值 0（空隙）或 1（固体材料）。该优化问题的数学形式如 Eq. (5) 所示：

```
min F
F(u(ρ), ρ) = ∫_Ω f(u(ρ), ρ)dV
s.t. : G₀(ρ) = ∫_Ω ρdV - V₀ ≤ 0
: ρ(x) = 0 or 1, ∀x ∈ Ω
(5)
```

其中状态场 u 满足线性或非线性状态方程。对于本应用，目标函数 F(u(ρ), ρ) 为柔度，最小化柔度可最大化结构的刚度。目标函数依赖于每个位置的材料密度 u(ρ)，其值将取 1（材料）或 0（空隙）。目标函数还依赖于预定义的约束 Gᵢ(u(ρ), ρ)，这些约束可能因不同的应用而异。最后，设计空间 Ω 指示允许的体积 V，设计可以在该体积内存在。

#### 状态空间

环境的状态空间 S 表示智能体在与环境交互时可能经历的所有观测组合。智能体的当前观测取决于边界条件、加载条件和当前拓扑。构成状态空间的各个观测被构建为 N×N×3 数组，其中 N 表示一个维度中的元素数量。

观测数组的第一通道是每个元素的归一化逆 von Mises 应力 σ_VM。该通道描述了拓扑中的当前应力分布。von Mises 应力常用于工程设计中以描述物体的当前应力状态。每个 2D 元素的 von Mises 应力可在任何工况下使用 Eq. (6) 求得：

```
\(\sigma_{VM} = \sqrt{\sigma_x^2 + \sigma_y^2 - \sigma_x\sigma_y + 3\tau_{xy}}\) (6)
```

其中 σ_x、σ_y 和 τ_xy 使用 2D 平面应力有限元分析求解器求得。有限元分析求解器通过调用当前拓扑的刚度矩阵以及有界和加载元素，在每个设计步骤自动计算 von Mises 应力。刚度矩阵通过根据当前拓扑为每个元素分配材料或空隙的弹性模量来定义。这种“闭环”有限元分析求解器可以替换为训练好的代理模型，以提高计算效率。Eq. (6) 仅用于拓扑中的材料元素。空隙元素被赋予 0 值，以隔离空隙元素的位置。每个元素的逆 von Mises 应力被用于帮助智能体的深度神经网络区分载荷较小的
