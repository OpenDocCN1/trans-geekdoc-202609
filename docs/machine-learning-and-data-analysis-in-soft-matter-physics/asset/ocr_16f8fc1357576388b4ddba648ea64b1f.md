# State Space

The state-space, S, of an environment represents all the combinations of observations that an agent can experience while interacting with the environment. The agent’s current observation depends on the boundary conditions, loading conditions, and current topology. The individual observations that comprise the state-space were built as N x N x 3 arrays, where N represents the number of elements in one dimension.

The first channel of the observation array is the normalized inverse Von Mises Stress, \(\sigma_{VM}\), of each element. This channel describes the current stress distribution within the topology. The Von Mises stress is commonly used in engineering design to describe an object’s current stress state. The Von Mises stress for each 2D element can be found under any load case using Eq. (6):

```
\(\sigma_{VM} = \sqrt{\sigma_x^2 + \sigma_y^2 - \sigma_x\sigma_y + 3\tau_{xy}}\) (6)
```

where \(\sigma_x\), \(\sigma_y\), and \(\tau_{xy}\) are found using a 2D plane stress FEA solver. The FEA solver automatically calculates the Von Mises stress at each design step by calling the current topology’s stiffness matrix and bounded and loaded elements. The stiffness matrix is defined by assigning each element the material or void modulus of elasticity depending on the current topology. This “in the loop” FEA solver could be replaced by a trained surrogate model to improve computational efficiency. Eq. (6) is only used for material elements within the topology. Voided elements are assigned a value of 0 to isolate the location of the voided elements.
