
让你担任气象学家。根据季节和当前天气状况，你猜测明天的温度将是 72°F (22°C)。

现在想象一下，小组里的每个人都对明天的天气做出了自己的预测：有人听了气象预报；有人在网上查看了多普勒雷达报告；有人问了父母；而你则根据当前状况做出了预测。

你认为你，这个小组指定的气象学家，会做出最准确的预测，还是四个人的平均猜测更接近明天的实际天气？集成学习表明，综合来看，你们的预测可能会分布在正确答案周围。平均值很可能比你个人的猜测更接近实际情况。

在技术术语中，这种在数据分析中经常使用的机器学习模型被称为*随机森林方法*：通过在数据点的随机子集上训练决策树，并在训练程序本身中加入一些随机性，你构建了一片多样化的树林，其平均值比任何单棵树都更稳健。

## 支持向量机

你是否曾苦于区分两个物种——也许是短吻鳄和鳄鱼？经过一段时间，你终于学会了如何区分：短吻鳄有 U 形吻部，而鳄鱼的嘴巴纤细且呈 V 形；而且鳄鱼的笑容比短吻鳄更露齿。但去大沼泽地旅行时，你遇到了一只爬行动物，令人困惑的是，它同时具有两者的特征——那么你如何区分它们呢？支持向量机（SVM）算法可以帮助你解决这个问题。

首先，让我们画一张图，将一个区别特征（吻部形状）作为 x 轴，另一个（笑容露齿程度）作为 y 轴。我们会在图表中为两种物种填充大量数据点，然后寻找分隔这两个类别的可能平面（或者，在此 2D 情况下，是直线）。

我们的目标是找到一个单一的“超平面”，通过最大化分离平面与每个类别最近点（称为支持向量）之间的距离来划分数据。不再混淆鳄鱼和短吻鳄：一旦 SVM 找到这个超平面，你就可以通过查看每只爬行动物落在哪一侧，轻松地对度假照片中的爬行动物进行分类。

SVM 算法只能用于分类数据，但并不总是可以用 2D 图表来区分类别。为了解决这个问题，你可以使用*内核*：一种将数据映射到更高维度的既定模式。通过组合使用内核并调整其参数，你将能够找到非线性超平面，并继续区分爬行动物。

## 线性回归

如果你曾经使用过散点图来查找两组数据之间的因果关系，那么你已经使用过线性回归了。这是一种在数据分析中用于预测和寻找变量之间相关性的建模方法。

例如，假设你想查看疲劳与某人工作小时数之间是否存在关联。你收集了一组工作时间安排各异的人的数据并绘制出研究结果。在寻找自变量（工作小时数）和因变量（疲劳）之间的关系时，你发现一条斜率为正的直线最能模拟这种相关性。

## 逻辑回归

与寻找天然连续变量之间相关性的线性回归算法不同，逻辑回归非常适合对分类数据进行分类。我们的短吻鳄与鳄鱼问题，实际上是一个逻辑回归问题。与可以使用非线性内核的 SVM 模型不同，逻辑回归仅限于（并且擅长）线性分类。

## 1.1.5 机器学习与深度学习与神经网络

由于深度学习和机器学习经常被互换使用，值得注意两者之间的细微差别。机器学习、深度学习和神经网络都是人工智能的子领域。然而，神经网络实际上是机器学习的一个子领域，而深度学习是神经网络的一个子领域。

深度学习和机器学习的区别在于每种算法的学习方式。“深度”机器学习可以使用标记数据集（也称为受监督学习）来指导其算法，但不一定需要标记数据集。深度学习可以以原始形式（例如，文本或图像）摄入非结构化数据，并能自动确定区分不同数据类别的特征集。这消除了部分人工干预需求，并使使用更大的数据集成为可能。

经典的或“非深度”机器学习更依赖人工干预来学习。人类专家确定特征集以理解数据输入之间的差异，通常需要更多结构化数据来学习。

神经网络，或人工神经网络（ANN），由节点层组成，包含输入层、一个或多个隐藏层和输出层。每个节点，或人工神经元，都与另一个节点相连，并具有关联的权重和阈值。如果任何单个节点的输出高于指定的阈值，则该节点被激活，将数据发送到网络的下一层。否则，该节点不会将数据传递到网络的下一层。深度学习中的“深度”只是指神经网络中的层数。一个由超过三层（包括输入层和输出层）组成的神经网络可以被视为深度学习算法或深度神经网络。一个只有三层的神经网络只是一个基本神经网络。深度学习和神经网络被认为加速了计算机视觉、自然语言处理和语音识别等领域的进步。

## 1.1.6 机器学习的工作原理

机器学习系统从历史数据中学习，构建预测模型，并在收到新数据时为其预测输出。预测输出的准确性取决于数据量，因为大量数据有助于构建更好的模型，从而更准确地预测输出。

机器学习算法的学习系统可分为三个主要部分。

- 1. **决策过程**：一般来说，机器学习算法用于进行预测或分类。基于一些输入数据（可以是标记的或未标记的），你的算法将对数据中的模式产生一个估计值。

- 2. **误差函数**：误差函数用于评估模型的预测。如果存在已知示例，误差函数可以进行比较以评估模型的准确性。

- 3. **模型优化过程**：如果模型能更好地拟合训练集中的数据点，则会调整权重，以减少已知示例与模型估计值之间的差异。算法将重复这一“评估和优化”过程，自主更新权重，直到达到一定的准确性阈值。

假设我们有一个复杂的问题，需要进行一些预测，因此不再为其编写代码，只需将数据输入通用算法，在算法的帮助下，机器根据数据构建逻辑并预测输出。机器学习已经改变了我们思考问题的方式。

## 1.1.7 数据分析与机器学习的关系

数据分析与机器学习密切相关。在应用机器学习算法之前，必须彻底分析和预处理数据，以确保其质量和相关性。数据分析为数据集提供了关键洞察，有助于识别潜在挑战，并帮助选择最合适的 ML 技术。

当数据被分析并准备好后，机器学习模型可以在数据集上进行训练和评估。这个过程是迭代的，因为数据分析师和 ML 从业者通常会共同努力，改进和完善数据和模型。

总之，数据分析和机器学习是数据驱动决策过程的组成部分。数据分析通过准备和理解数据奠定了基础，而机器学习算法则利用这些数据，在广泛的应用和行业中进行预测、推荐和做出明智的决策。
