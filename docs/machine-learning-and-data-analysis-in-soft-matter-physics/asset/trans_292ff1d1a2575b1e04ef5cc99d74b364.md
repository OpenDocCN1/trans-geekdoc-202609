- 输入数据向量的长度 L 必须是 2 的整数幂。必要时可通过在数据向量末尾填充零来满足此条件（L ≥ n）。
- 每次变换涉及应用两个函数。第一个函数执行某种数据平滑，如求和或加权平均。第二个函数执行加权差分，旨在凸显数据的详细特征。
- 这两个函数应用于 X 中的数据点对，即所有测量值对 (x₂ᵢ, x₂ᵢ₊₁)。这会产生两组长度为 L/2 的数据。通常，这些分别代表输入数据的平滑或低频版本及其高频内容。
- 这两个函数会递归地应用于上一轮得到的数据集，直到得到的数据集长度为 2。
- 上述迭代得到的数据集中的选定值被指定为变换数据的小波系数。

等价地，可对输入数据应用矩阵乘法以获得小波系数，所用矩阵取决于给定的 DWT。该矩阵必须是标准正交的，即其列为单位向量且两两正交，因此矩阵的逆即其转置。尽管此处无法详细讨论，但此属性允许从平滑和平滑差分数据集中重建数据。通过将所用矩阵分解为若干稀疏矩阵的乘积，得到的“快速 DWT”算法对长度为 n 的输入向量的复杂度为 O(n)。小波变换可应用于多维数据，例如数据立方体。方法是先对第一个维度应用变换，再对第二个维度应用，依此类推。所涉计算复杂度与立方体中单元数量呈线性关系。小波变换对稀疏或偏态数据以及具有有序属性的数据效果良好。据称，基于小波的有损压缩优于当前商业标准的 JPEG 压缩。小波变换有许多现实应用，包括指纹图像压缩、计算机视觉、时间序列数据分析和数据清洗。

## 2.3.3 主成分分析

假设待缩减的数据由由 n 个属性或维度描述的元组或数据向量组成。主成分分析（PCA，也称为 Karhunen-Loeve，或 K-L 方法）搜索 k 个 n 维正交向量，这些向量最能用于表示数据，其中 k ≤ n。因此，原始数据被投影到一个更小的空间，从而实现降维。与通过保留初始属性子集来减小属性集大小的属性子集选择不同，PCA 通过创建一个更小的备用变量集来“组合”属性的本质。然后可以将初始数据投影到这个更小的集合上。PCA 常常揭示先前未曾怀疑的关系，从而允许原本不会得出的解释。基本步骤如下：

- 输入数据经过归一化，使每个属性都落在相同的范围内。此步骤有助于确保具有较大域的属性不会主导具有较小域的属性。
- PCA 计算 k 个标准正交向量，为归一化后的输入数据提供基。这些是单位向量，各自指向与其他向量垂直的方向。这些向量称为主成分。输入数据是主成分的线性组合。
- 按“重要性”或强度递减顺序对主成分进行排序。主成分本质上充当数据的新坐标轴，提供关于方差的重要信息。也就是说，排序后的坐标轴使得第一个坐标轴显示数据中最大的方差，第二个坐标轴显示次大的方差，依此类推。例如，图 2 显示了给定数据的前两个主成分 $Y_1$ 和 $Y_2$，这些数据最初映射到坐标轴 $X_1$ 和 $X_2$。此信息有助于识别数据中的组或模式。
- 由于按“重要性”递减顺序对组件进行排序，因此可以通过消除较弱的组件（即方差较低的组件）来减小数据大小。使用最强的主成分，应该可以重建原始数据的良好近似。

PCA 可应用于有序和无序属性，并能处理稀疏数据和偏态数据。超过两个维度的多维数据可以通过将问题简化为二维来处理。主成分可用作多元回归和聚类分析的输入。与小波变换相比，PCA 更擅长处理稀疏数据，而小波变换更适合高维数据。

## 2.3.4 属性子集选择

用于分析的数据集可能包含数百个属性，其中许多可能与挖掘任务无关或冗余。例如，如果任务是根据客户对音乐 CD 折扣优惠做出积极反应的概率来分类客户，则客户电话号码等属性可能无关，而年龄或音乐品味等属性则相关。尽管领域专家可能能够挑出一些有用属性，但这可能是一项困难且耗时的任务，尤其是在数据行为不甚了解时（因此才需要分析！）。遗漏相关属性或保留不相关属性可能有害，会导致所采用的挖掘算法产生混淆。这可能导致发现的模式质量较差。此外，不相关或冗余属性的增加会减慢挖掘过程。

属性子集选择通过移除不相关或冗余属性（或维度）来减小数据集大小。属性子集选择的目标是找到一个最小属性集，使得数据类的生成概率分布尽可能接近使用所有属性时得到的原始分布。在缩减的属性集上进行挖掘还有一个额外好处：它减少了发现的模式中出现的属性数量，有助于使模式更易于理解。

“我们如何找到原始属性的一个‘良好’子集？” 对于 n 个属性，存在 $2^n$ 个可能的子集。对最优属性子集进行穷举搜索的成本可能极高，尤其是当 n 和数据类数量增加时。因此，通常使用探索缩减搜索空间的启发式方法来进行属性子集选择。这些方法通常是贪心的，即在搜索属性空间时，它们总是做出当时看起来最好的选择。其策略是做出局部最优选择，希望这能导致全局最优解。此类贪心方法在实践中有效，并可能接近估计最优解
