```
\(\sigma_k^* = \lambda_k^*(\tau) = e^{-\tau/t_k^*} \text{,}\)

\(\phi_k(\mathbf{x}) = \psi_k(\mathbf{x})\mu(\mathbf{x}) \text{.}\)

(12)
```

因此，方程 11 简化为：我们只需要一组函数，即特征函数 \(\psi_k\)。真特征值 \(\lambda_k^*\) 为实值，并随时间 \(\tau\) 指数衰减，其特征弛豫时间 \(t_i^*\) 直接与动力学实验可观测量相关联。方程 11 中的近似是由于截断所有弛豫时间短于 \(t_n^*\) 的项。

一种相当成熟的方法是从给定的轨迹数据集中学习分子动力学（方程 11）。为了获得易于解释和分析的低维分子动力学模型，这通常涉及两个步骤：（a）使用编码器 E 找到集体变量的低维潜在空间表示 \(y = E(x)\)；（b）在该空间中学习动力学传播器 P：

```
MD   x_t   --E-->   y_t
          |                | P
          v                v
         x_t+tau --E--> y_t+tau .

(13)
```

在 MD 以及动力学系统和流体力学等其他领域中，一种常见的方法是寻找一对 (E,P)，使得 P 是一个小矩阵，以马尔可夫（无记忆）方式传播状态向量。这受到动力学谱分解（方程 11）的启发：如果 \(\tau\) 足够大以过滤快速过程，则少量函数足以描述系统的动力学，并且如果 E 将空间映射到这些函数所张成的空间，则 P 可以是一个线性的马尔可夫模型。

如果对 P 没有施加特定约束，则 \(y_{t+\tau} = Py_{t'}\) 的最小回归误差、马尔可夫过程变分方法（VAMP）和极大似然估计都会导出相同的估计量，

```
\(\mathbf{P} = \mathbf{C}_{00}^{-1}\mathbf{C}_{0\tau} \text{,}\)

(14)
```

使用潜在空间协方差矩阵

```
\(\mathbf{C}_{00} = \frac{1}{T} \sum_{t=1}^{T-\tau} \mathbf{y}_t \mathbf{y}_t^\top \text{,} \quad \mathbf{C}_{0\tau} = \frac{1}{T} \sum_{t=1}^{T-\tau} \mathbf{y}_t \mathbf{y}_{t+\tau}^\top \text{,} \quad \mathbf{C}_{\tau\tau} = \frac{1}{T} \sum_{t=1}^{T-\tau} \mathbf{y}_{t+\tau} \mathbf{y}_{t+\tau}^\top \text{.}\)
```

如果 E 执行指示系统处于哪个状态的独热编码，则该对 (E,P) 被称为马尔可夫状态模型，P 是在时间 t 系统处于状态 i 的条件下，在时间 t + τ 处于状态 j 的条件概率矩阵。

学习嵌入 E 比学习 P 更困难，因为通过最大似然或潜在空间中的最小回归误差优化 E 会导致 E 坍缩到平凡、无趣的解。可以通过采用变分方法来近似谱分解的主导项（方程 10）来避免此问题。构象动力学的变分方法指出，对于遵循详细平衡的动力学，通过任意编码 y = E(x) 传播器矩阵 P 的特征值 \(\lambda_k\) 在统计极限下是真实 \(\lambda_k^*\) 的下界。VAMP 变分原理更一般，因为它不要求详细平衡（参见方程 21）并适用于奇异值 \(\sigma_k\)：

\(\lambda_k \le \lambda_k^* \text{ (具有详细平衡),}\)
\(\sigma_k \le \sigma_k^* \text{ (无详细平衡).}\)

由于 VAMP 是更一般的原理，我们可以用它来定义分子动力学模型的损失函数：

\(\mathcal{L}_{\text{VAMP-2}}((\mathbf{y}_t^0, \mathbf{y}_t^\tau)) = - \left\| (\mathbf{C}_{00})^{-\frac{1}{2}} \mathbf{C}_{0\tau} (\mathbf{C}_{\tau\tau})^{-\frac{1}{2}} \right\|_F^2 \quad (15)\)

如果动力学遵循详细平衡，我们可以使用 \(C_{\tau\tau} = C_{00}\) 并代入 \(C_{0\tau}\) 的对称估计。

## 8.2.5 采样与热力学

MD 时间步长约为一飞秒 (10^-15s)，而控制分子功能的构型变化通常是罕见事件，可能需要 10^-3 到 10^3s。即使单个蛋白质折叠和展开产生的势能和力被快速评估，通过直接 MD 模拟模拟这些过程在超级计算机上也可能需要数年到数世纪。为了避免此采样问题，可以采用机器学习方法更高效地学习从 \(\mu(x)\) 生成平衡样本，甚至一次生成统计独立样本。

学习采样概率分布是生成式学习的领域。在过去几年中，定向生成网络，如变分自编码器、生成对抗网络和流模型，备受关注。此类网络经过训练，可将易于采样的概率分布（如高斯噪声）中的样本转换为感兴趣对象的真实样本。这些方法已被用于绘制逼真图像、生成语音或音乐音频，以及生成化学结构以设计具有特定性质的分子或材料。如果目标是从采样数据（密度估计）学习概率分布，或学习从给定概率分布高效采样，通常面临将训练模型的概率分布与参考分布匹配的挑战。匹配概率分布可以通过最小化概率距离来实现。最常用的概率距离是库尔贝克–莱布勒（KL）散度，也称为两个分布 q 和 p 之间的相对熵：

```
KL(q || p) = \int q(x) [log q(x) - log p(x)] dx. (16)
```

在玻尔兹曼生成中，目标是高效采样由其能量函数 u(x)（方程 1）定义的多体系统的平衡分布 \(\mu(x)\)。我们可以通过使神经网络生成的分布与目标平衡分布相似，来学习从分布 \(p_X(x; \theta)\) 生成样本的神经网络的参数 \(\theta\)。在方程 16 中选择 \(q \equiv p_X(x)\) 和 \(p \equiv \mu(x)\)，我们可以使用能量损失（EL）来最小化 \(KL_\theta[q_X || \mu_X]\)：

```
EL = E_{x ~ p_X(x; \theta)} [log p_X(x; \theta) + u(x)] (17)
```

由于网络从能量面 \(u(x; \theta) = - \log p_X(x; \theta) + \text{const}\)（方程 1）采样，此损失正在执行能量匹配。为了评估损失（方程 17），我们不仅需要能够从网络生成样本 \(x \sim p_X(x; \theta)\)，还需要能够计算每个样本 x 的 \(p_X(x; \theta)\)。相反的情况是密度估计。假设我们有模拟数据 x，并且希望训练概率分布 \(p_X(x; \theta)\) 以使其与数据分布相似。我们在方程 16 中选择 q(x) 作为数据分布，\(p \equiv p_X(x; \theta)\)，并利用 \(E_{x \sim \text{data}}[\log q(x)]\) 是一个不依赖于参数 \(\theta\) 的常数。然后我们可以最小化损失：

```
NL = -E_{x ~ data} [log p_X(x; \theta)]. (18)
```

此损失是模型生成观测样本的负似然（NL）；因此，最小化它对应于最大似然方法。似然最大化在机器学习中被广泛使用。

## 8.3 用于跨不同软物质系统迁移知识的域自适应技术

域自适应技术在跨不同软物质系统迁移知识和洞察方面起着关键作用，即使在实验条件或数据分布存在显著差异时也是如此。

这些技术使研究人员能够利用一个软物质系统中的预先存在的知识并将其应用到另一个系统，从而促进准确且高效模型的开发。以下是一些常用于跨不同软物质系统迁移知识的域自适应技术：

- **对抗域自适应**：对抗域自适应涉及在主模型旁训练域判别器，以区分源域和目标域。主模型（如神经网络）旨在生成域判别器无法区分的特征。这种对抗过程有助于对齐源域和目标域之间的特征表示，减少域偏移的影响。

- **特定域自适应**：特定域自适应涉及为每个软物质系统分别微调或调整模型。通过训练特定域自适应，模型可以专注于捕捉每个系统的特定特征和特性，将其知识迁移定制到目标域。

- **集成方法**：集成方法结合多个模型的预测，每个模型都在不同的软物质系统上预训练。通过融合这些模型的输出，研究人员可以从它们的集体知识中受益，并减少与单个模型相关的偏差。

- **自监督域自适应**：自监督学习技术可用于域自适应，模型从数据本身学习而不依赖显式注释。通过制定特定于每个软物质系统的自监督任务，模型可以提取可跨域迁移的有意义表示。
