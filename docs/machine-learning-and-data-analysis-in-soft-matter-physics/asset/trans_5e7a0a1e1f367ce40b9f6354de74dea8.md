

可以使用非饱和非线性函数（如ReLU）进行稳健训练。使用跳跃连接，可以训练深层网络。

## 递归

递归神经网络是通过在拓扑顺序下遍历可微图状结构，递归地应用同一组权重来创建的。此类网络通常也通过自动微分的反向模式进行训练。它们可以处理结构的分布式表示，例如逻辑项。递归神经网络的一种特殊情况是RNN，其结构对应于线性链。递归神经网络已被应用于自然语言处理。递归神经张量网络使用基于张量的组合函数处理树中所有节点。

## 神经历史压缩机

神经历史压缩机是一个无监督的RNN堆栈。在输入层，它学习从前序输入预测下一个输入。只有层级中某些RNN的不可预测输入才会成为下一级更高RNN的输入，因此该更高级RNN很少重新计算其内部状态。因此，每个更高级RNN研究下层RNN中信息的压缩表示。这样做是为了使输入序列可以从最高级的表示中精确重建。

该系统有效地最小化描述长度或数据概率的负对数。在传入数据序列中存在大量可学习的可预测性的情况下，最高级RNN可以使用监督学习来轻松分类即使是在重要事件之间有长间隔的深层序列。

可以将RNN层级提炼为两个RNN：“有意识”的分块器（高级）和“潜意识”的自动化器（低级）。一旦分块器学会了预测和压缩自动化器无法预测的输入，那么自动化器在下一阶段学习中就可以被迫通过额外单元来预测或模仿变化较慢的分块器的隐藏单元。这使得自动化器容易学习适当的、长间隔很少变化的记忆。反过来，这有助于自动化器使其许多曾经不可预测的输入变得可预测，从而让分块器能够专注于剩余的不可预测事件。

1992年，生成模型部分克服了神经网络中自动微分或反向传播的梯度消失问题。1993年，这样的系统解决了一项“非常深度学习”任务，该任务需要在展开时间的RNN中包含超过1000个后续层。

## 二阶RNNs

二阶RNNs使用更高阶权重w_jk，而不是标准的w_ij权重，状态可以是乘积。这允许在训练、稳定性和表示方面直接映射到有限状态机。长短期记忆是这种情况的一个示例，但没有这样的正式映射或稳定性证明。

## 6.5 长短期记忆

长短期记忆（LSTM）是一种避免梯度消失问题的深度学习系统。LSTM通常由称为“遗忘门”的循环门增强。

LSTM防止反向传播的错误消失或爆炸。相反，错误可以向后流经展开在空间中无限数量的虚拟层。也就是说，LSTM可以学习需要记住数千甚至数百万个离散时间步之前发生的事件的任务。

可以进化出针对特定问题的类LSTM拓扑。即使在重要事件之间存在长延迟的情况下，LSTM也能工作，并且可以处理混合低频和高频分量的信号。

许多应用使用LSTM RNN的堆栈，并通过联结时序分类（CTC）对其进行训练，以找到一个RNN权重矩阵，在给定相应输入序列的情况下，最大化训练集中标签序列的概率。CTC同时实现对齐和识别。LSTM可以学习识别上下文相关语言，这不同于基于隐马尔可夫模型（HMM）及类似概念的早期模型。

### LSTM架构

在长短期记忆的介绍中，我们了解到它解决了RNN面临的梯度消失问题，因此现在，我们将通过学习LSTM的架构来了解它如何解决这个问题。从高层次来看，LSTM的工作方式非常类似于RNN单元。以下是LSTM网络的内部工作原理。

LSTM网络架构由三个部分组成，如下图所示，每个部分执行单独的功能。

![](img/c4a53cbbd40023d194b7887dddf3293b_192_0.png)

就像简单的RNN一样，LSTM也具有隐藏状态，其中H(t-1)表示前一个时间步的隐藏状态，Ht表示当前时间步的隐藏状态。除此之外，LSTM还具有单元状态，分别由C(t-1)和C(t)表示前一个和当前时间步。

这里隐藏状态称为短期记忆，单元状态称为长期记忆。

![](img/c4a53cbbd40023d194b7887dddf3293b_192_1.png)

值得注意的是，单元状态随所有时间步携带信息。

![](img/c4a53cbbd40023d194b7887dddf3293b_192_2.png)

让我们举个例子来理解LSTM的工作原理。这里有两个句子，用句号分隔。第一个句子是“Bob是一个好人，”第二个句子是“另一方面，Dan是邪恶的”。非常清楚，在第一个句子中，我们在谈论Bob，一旦遇到句号（,），我们就开始谈论Dan了。

当我们从第一个句子移动到第二个句子时，我们的网络应该意识到我们不再谈论Bob。现在我们的主题是Dan。在这里，网络的遗忘门允许它忘记它。让我们了解这些门在LSTM架构中所扮演的角色。

### 遗忘门

在LSTM神经网络的一个单元中，第一步是决定是否保留前一时间步的信息或忘记它。以下是遗忘门的方程。

```
f_t = σ(x_t * U_f + H_{t-1} * W_f)
```

让我们尝试理解这个方程，这里

- X_t: 当前时间步的输入。
- U_f: 与输入相关的权重
- H_{t-1}: 前一时间步的隐藏状态
- W_f: 它是与隐藏状态相关的权重矩阵

之后，对其应用sigmoid函数。这将使f_t成为0到1之间的一个数。随后，这个f_t与前一时间步的单元状态相乘，如下所示。

```
C_{t-1} * f_t = 0 ....if f_t = 0 (forget everything)
C_{t-1} * f_t = C_{t-1} ....if f_t = 1 (forget nothing)
```

### 新信息

现在需要传递到单元状态的新信息是前一时间步t-1的隐藏状态和时间步t的输入x的函数。这里的激活函数是tanh。由于tanh函数，新信息的值将在-1到1之间。如果Nt的值为负，则从单元状态中减去该信息；如果值为正，则将该信息添加到当前时间步的单元状态中。

但是，Nt不会直接添加到单元状态。以下是更新后的方程：

$C_t = f_t * C_{t-1} + i_t + N_t$

这里，C_{t-1}是当前时间步的单元状态，其余的是我们计算出的值。

## 6.6 使用时间序列数据预测软物质系统动力学

使用时间序列数据进行软物质系统动力学的预测与预估是各种科学和工程领域（包括材料科学、生物物理学和纳米技术）中的一项基本任务。软物质是指一类表现出介于常规液体和固体之间特性的材料，包括聚合物、胶体、凝胶、泡沫和生物系统。时间序列数据是指随时间变化的变量的序列测量值。

以下是使用时间序列数据预测和预估软物质系统动力学的一些常规步骤和方法：

### 数据收集

第一步是从实验或模拟中收集相关的时间序列数据。这些数据可能包括材料性能、粒子轨迹或任何其他随时间变化的感兴趣变量的测量值。

### 数据预处理

清洁和预处理时间序列数据，以去除可能影响预测准确性的噪声、异常值或任何不一致之处。常见的预处理技术包括数据插值、平滑和归一化。

### 时间序列分析

执行探索性数据分析以了解时间序列数据中的底层模式、趋势和相关性。自相关分析、功率谱密度估计和傅里叶分析等技术可以帮助揭示周期性和其他相关特性。
