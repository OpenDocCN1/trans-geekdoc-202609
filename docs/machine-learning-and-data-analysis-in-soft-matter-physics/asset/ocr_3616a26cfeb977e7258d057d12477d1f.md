Formally, the TO problem can be viewed as finding the material distribution G that minimizes an objective function, F, subject to a volume constraint G₀≤0 and possibly M other constraints Gᵢ≤0, i=1⋯M. The material distribution is described by the density variable r that can take either the value 0 (void) or 1 (solid material) at any point in the design domain Ω. The mathematical form of this optimization problem is shown in Eq. (5) :

```
min F
F(u(ρ), ρ) = ∫_Ω f(u(ρ), ρ)dV
s.t. : G₀(ρ) = ∫_Ω ρdV - V₀ ≤ 0
: ρ(x) = 0or1, ∀x ∈ Ω
(5)
```

where the state field u satisfies a linear or nonlinear state equation. For this application, the objective function, F(u(ρ), ρ), is compliance, where minimizing compliance leads to maximizing the stiffness of the structure. The objective function is dependent on the density of the material at each location, u(ρ), which will take the value of 1 (material) or 0 (void). The objective function is also dependent on predetermined constraints, Gᵢ(u(ρ), ρ), which can be subject to change for different applications. Finally, the design space, Ω, indicates the allowable volume, V, within which the design can exist.
