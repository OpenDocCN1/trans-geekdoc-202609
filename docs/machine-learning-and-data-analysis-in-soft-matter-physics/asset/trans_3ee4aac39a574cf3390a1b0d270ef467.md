

区分良好混合状态与分离状态。然而，正如我们将展示的，主要结果不受奖励函数选择的影响，因此，计算密集型奖励函数可以替换为更简单的函数。特别是，我们使用测量张量 M，它描述每个 bin 中带有特定标签的粒子计数。因此，M 的索引为 (tag, x-bin, y-bin)，其中 tag \(\in \{l, r\}\)，x-bin 和 y-bin \(\in \{1, 2, ..., N_g\}\)。然后，我们在特定时间步定义混合奖励为

```
\tau_m = -\frac{1}{\mathscr{N}_m} \sum_{x=1}^{N_g} \sum_{y=1}^{N_g} (\mathscr{M}_{l,xy} - \mathscr{M}_{r,xy})^2 \in \left[ -\frac{N_g^2}{2}, 0 \right], \quad (2)
```

此处我们抑制了 M 和 \(\tau_m\) 的时间依赖性，以简化记号。在等式 (2) 中，负号确保良好混合状态的奖励更大，并且 \(N_m = (N_p/N_g)^2\) 被选取，使得初始状态的平均奖励为 -1。应注意的是，\(\tau_m\) 的最小值远小于 -1，当所有“左”粒子在一个 bin 中，所有“右”粒子在另一个 bin 中时达到该值。

由于仅使用等式 (2) 会导致将所有粒子坍缩到密集簇中的退化解，我们使用一个额外的（时间步）同质性奖励，其构造与等式 (2) 类似：

```
\tau_h = -\frac{1}{\mathscr{N}_h} \sum_{x=1}^{N_g} \sum_{y=1}^{N_g} \left[ \frac{N_p}{N_g^2} - (\mathscr{M}_{l,xy} + \mathscr{M}_{r,xy}) \right]^2 \in [-1, 0], \quad (3)
```

但不同于比较每个 bin 中每个标签的粒子计数，同质性奖励比较每个 bin 中的粒子数（\(\mathscr{M}_{l,xy} + \mathscr{M}_{r,xy}\)）与每个 bin 的平均粒子数 \(\frac{N_p}{N_g^2}\)。这里，\(\mathscr{N}_h = N_p^2 \left( 1 - \frac{1}{N_g^2} \right)，因此最不均匀的解（即所有粒子在单个 bin 中）的奖励为 -1。应注意的是，\(N_m\) 和 \(N_h\) 被选取，使得 \(\tau_m\) 和 \(\tau_h\) 在它们应避免的典型情况下分别为 -1，即分离初始状态和完全坍缩状态。因此，使用这些 \(N_m\) 和 \(N_h\) 的值提供了一种自然归一化。

我们将整个回合的奖励定义为时间步奖励的平均值：

```
\Re_m = \frac{1}{N_t} \sum_{t=1}^{N_t} \tau_m^{(t)}, \text{ and } \Re_h = \frac{1}{N_t} \sum_{t=1}^{N_t} \tau_h^{(t)}, \quad (4)
```

这里 \(\tau_m^{(t)}\) 和 \(\tau_h^{(t)}\) 分别是时间 t 时混合和同质性的时间步奖励。最后，两个奖励贡献组合为 \(\Re = \alpha \Re_m + (1 - \alpha)\Re_h\)，使用参数 \(\alpha \in [0, 1]\) 来连续调整对更均匀或更混合解的权重。

## 7.2.3 强化学习框架

由于动作空间很大（对于组合相互作用，\(3^{4 \times 4} \approx 43 \times 10^6\)），传统的控制理论技术由于贝尔曼的维度灾难而难以处理。同样，动作空间对于基于值的强化学习方法也太大，因此我们使用基于策略的算法。特别是，我们使用 Proximal Policy Optimization (PPO) 的 rllib 实现。

在强化学习智能体中，我们使用一个将张量 M 作为输入的神经网络。神经网络本身包含三个卷积层（通道数分别为 32、64 和 256，卷积核大小分别为 3、3 和 4）以及一个具有 \(N_g \times N_g\) 个输出神经元的全连接层。模拟使用这些输出神经元的值，通过阈值判断是否应激活某个 bin。

PPO 的超参数在训练期间使用 ray tune 的基于人口的训练 (PBT) 自动调制，包含 16 个智能体。使用 PBT，不稳定的解可以被克服，并且在所有训练情况下我们都观察到了收敛策略。

### 引力相互作用

在实验中，一种具有引力相互作用的可控活性物质系统已经可用，因此首先分析此情况。在图 2a 中，我们显示 16 个智能体的平均回合奖励随训练时间的变化，以实线表示，批次期间的最小和最大回合奖励作为误差带。应注意的是，虽然训练带来了一些平均奖励增加，但奖励范围仍然很大。此外，我们还可以观察到，因某些不稳定性（表现为奖励急剧下降）而失败的智能体，可以通过使用 PBT 恢复。因此，数据允许定性分析，但视觉检查需要确认特定情况下策略的质量。在图 2b 中，显示了一个收敛策略的典型时间序列，其中出现的策略将所有粒子坍缩到一个密集簇中。虽然这种策略在常规意义上不是良好的混合器，但该解优化了等式 (2)。特别是，如果所有粒子坍缩到单个 bin 中的一个簇，那么该 bin 具有平衡数量的“左”和“右”，因此对于该单元 \(\mathscr{M}_{l,ij} = \mathscr{M}_{r,ij} = N_p/2\)，差值为 0。所有其他单元为空，因此对于这些单元 \(\mathscr{M}_{l,ij} = \mathscr{M}_{r,ij} = 0\)，再次导致差值消失，因此 \(\tau = 0\cdot\tau_h + 1\cdot\tau_m = 0\) 是最优的。

图 2：仅使用引力相互作用的训练仅实现坍缩簇：在 (a) 中，显示了 16 个在 \(\alpha = 1\) 时训练的智能体的平均回合奖励，以实线表示，最小和最大回合奖励作为误差带。可以观察到，虽然训练收敛，但奖励变化仍然显著，并且多次奖励下降通过 PBT 得到了恢复。在 (b) 中，显示了仅专注于混合训练（\(\alpha = 1\)）的典型时间序列，其中可以观察到粒子密度的坍缩。各面板从 1 到 4 编号，分别对应时间步 0、20、40 和 60。在 (c) 中，显示了不同 \(\alpha\) 值下出现策略的组成，所有中间出现策略都在连续接管。然而，没有出现策略显示均匀混合。

为了克服平凡的“坍缩所有”解，可以降低 \(\alpha\) 以引入同质性权重。对于极端情况 \(\alpha = 0\)，算法仅优化同质性，由于初始条件已经具有高同质性，因此几乎没有粒子被激活。我们将这种出现的策略称为“少量激活”，它也未导致均匀混合。我们通过在另外 7 个 \(\alpha\) 值（总共 9 个）上进行额外模拟，分析了中间 \(\alpha\) 值下的行为，并对 16 个 PBT 智能体的每个最后验证视频进行了手动标记。应注意的是，手动标记产生了可解释的策略，但对激活动态的定量分析表明，激活模式可以大致分类为与我们的手动标记程序一致的组。出现策略组成的结果在图 2c 中作为 \(\alpha\) 的函数绘制。在那里我们可以观察到，对于中间值的 \(\alpha\)，我们观察到了两种额外策略。首先，对于 \(0 \le \alpha < 0.5\) 的某些模拟，出现了一种“坍缩一些”策略，该策略专注于收集相反标签的密集粒子簇以改善最差的 bin，但将系统的大部分其他部分保持未激活。其次，对于各种 \(\alpha\) 值，我们观察到一种“坍缩所有，谨慎”策略，它类似于“坍缩所有”策略，试图将所有粒子收集到单个 bin 中。然而，它在更长的时间段内这样做（通常超过模拟时间的一半），以避免中间密集簇，特别是当这些密集簇为单一颜色时。作为这种策略的额外特征，由于给予系统更长的反应时间，“坍缩所有，谨慎”策略倾向于比主要关注速度的“坍缩所有”策略更彻底地将所有粒子坍缩到单个 bin 中。虽然确切细节，_即，_ 哪种策略针对哪个 \(\alpha\) 值出现，将取决于多种因素，例如 bin 的数量 \(N_g \times N_g\)、初始条件以及手动标记过程中的主观评估，但我们可以观察到两个主要结果：首先，通过调整 \(\alpha\)，策略会连续地从一种转变为另一种。其次，没有观察到的策略实现均匀混合状态。

因此，仅使用引力相互作用，即使改变 \(\alpha\)，也没有出现提供类似图 1c 所示目标解决方案的策略。事实上，我们将在第 4 节中证明，没有奖励塑造可以克服这一问题，因为引力相互作用不足以达到均匀混合状态。

### 斥力相互作用

虽然在实验平台上尚未实现，但通过引入另一种运动蛋白类型，可以设计斥力相互作用系统。仅使用斥力相互作用，比仅引力情况存在一种更均匀的混合策略：图 3a 显示了混合聚焦 \(\alpha = 1\) 情况的典型时间序列，其中我们观察到出现的策略是“激活一侧”策略。对于 \(N_g = 4\) 且带有周期性边界条件，每个 bin 都是初始配置两侧之间的边界 bin。因此，从一侧驱逐的每个粒子进入另一侧而不收缩成簇。这种混合解决方案的两个特征应予以强调：第一，这种策略再次通过降低系统的同质性来最大化 \(\Re_m\)。第二，混合仅通过利用边界条件来促进。
