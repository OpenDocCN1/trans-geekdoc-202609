### 3.3.2 支持向量机的优势

- 模型训练相对容易
- 该模型对高维数据的扩展性相对较好
- SVM 是神经网络的有用替代方案
- 分类器复杂度与误差之间的权衡可以显式控制
- 它对线性可分数据和非线性可分数据都有用
- 保证最优性：由于凸优化的特性，解被保证是全局最小值

### 3.3.3 支持向量机的劣势

- 选择合适的核函数和参数可能计算量很大
- 在自然语言处理（NLP）中，文本的结构化表示能够获得更好的性能。然而，SVM无法容纳此类结构（词嵌入）

### 3.3.4 SVM 应用

核技巧有多种应用，其中包括：

- **地质统计学：** 它是统计学的一个分支，专注于空间或时空数据集。它最初是为预测矿山作业中矿石品位的概率分布而创建的。现在它被应用于包括石油地质学、水文地质学、水文学、气象学、海洋学、地球化学、地质冶金学、地理学、林学、环境控制、景观生态学、土壤科学和农业（特别是精准农业）在内的多个学科。
- 反距离加权：一种用于已知散点集的多元插值的确定性方法。未知点的值是通过已知点处现有值的加权平均计算得出的。
- 3D 重建：捕捉真实物体形状和外观的过程。
- 生物信息学：一个涉及分子生物学、遗传学、计算机科学、数学和统计学的交叉学科。开发软件工具和方法以更好地理解生物数据。
- 化学信息学：将计算和信息技术应用于化学领域以解决各种问题。
- 信息提取：缩写为 IE，它是一种从非结构化和半结构化文本文档、数据库和网站中自动提取或检索结构化信息的方法。
- 手写识别：缩写为 HWR，它是计算机系统从不同来源（如信纸文档、照片、触摸屏和其他设备）全面接收和解释手写输入的能力。

### 3.3.5 核方法

核或核方法（也称为核函数）是用于模式分析的不同类型算法的集合。它们通过使用线性分类器来解决非线性问题。核方法用于 SVM（支持向量机），后者用于分类和回归问题。SVM 使用所谓的“核技巧”，其中数据被转换并为可能的输出找到最优边界。

## 核方法的必要性及其工作原理

在深入了解核方法的工作原理之前，理解支持向量机（SVM）更为重要，因为核是在 SVM 模型中实现的。因此，支持向量机是用于分类和回归问题的监督机器学习算法，例如将苹果归类为水果类，而将狮子归类为动物类。

为了演示，以下是支持向量机的示意图：

![](img/c4a53cbbd40023d194b7887dddf3293b_106_0.png)

在这里，我们可以看到一个超平面将绿色点与蓝色点分开。超平面比环境空间少一个维度。例如，在上图中，我们有 2 个维度代表环境空间，但分割或分类空间的直线比环境空间少一个维度，称为超平面。

但是，如果输入如下所示：

![](img/c4a53cbbd40023d194b7887dddf3293b_106_1.png)

使用线性分类器很难解决这个分类问题，因为不存在一条能够将红点和绿点分开的好的线性直线，因为这些点是随机分布的。这时核函数就派上用场了，它将点映射到更高维度，在那里解决问题并返回输出。可以这样理解：我们可以看到绿点被包围在某个周边区域内，而红点则位于其外部；同样，可能存在其他场景，其中绿点可能分布在梯形区域内。

所以我们要做的是将最初由一维超平面（“或一条直线”）分类的二维平面转换为三维区域，在这里我们的分类器即超平面将不再是一条直线，而是一个二维平面，它将切割该区域。

为了从数学上理解核，让我们了解 Lili Jiang 的核方程，即：K(x, y)=<f(x), f(y)> 其中，
K 是核函数，
X 和 Y 是维度输入，
f 是从 n 维到 m 维空间的映射，
< x, y > 是点积。

### 举例说明。

假设我们有两个点，x = (2, 3, 4) 和 y = (3, 4, 5)
如我们所见，K(x, y) = < f(x), f(y) >。

让我们先计算 < f(x), f(y) >
f(x)=(x1x1, x1x2, x1x3, x2x1, x2x2, x2x3, x3x1, x3x2, x3x3)
f(y)=(y1y1, y1y2, y1y3, y2y1, y2y2, y2y3, y3y1, y3y2, y3y3)

因此，
f(2, 3, 4)=(4, 6, 8, 6, 9, 12, 8, 12, 16) 且
f(3, 4, 5)=(9, 12, 15, 12, 16, 20, 15, 20, 25)

因此点积，
f(x)·f(y) = f(2,3,4)·f(3,4,5)=
(36 + 72 + 120 + 72 + 144 + 240 + 120 + 240 + 400)=
1444

并且，
K(x, y) = (2*3 + 3*4 + 4*5) ^2=(6 + 12 + 20)^2=38*38=1444。

如我们所发现，f(x)·f(y) 和 K(x, y) 给出相同的结果，但前一种方法需要大量计算（因为将 3 维投影到 9 维），而使用核则容易得多。

### 3.3.6 SVM 中的核类型和方法

让我们看看 SVM 中使用的一些核函数或类型：

- 1. **线性核：** 假设我们有两个名为 x1 和 x2 的向量，则线性核定义为这两个向量的点积：K(x1, x2) = x1 . x2
- 2. **多项式核：** 多项式核由以下方程定义：K(x1, x2) = (x1 . x2 + 1)^d，其中 d 是多项式的次数，x1 和 x2 是向量
- 3. **高斯核：** 该核是径向基函数核的一个示例。其方程如下：k(xi,xj) = exp(-γ || xi - xj ||^2) 给定的 sigma 在高斯核的性能中起着非常重要的作用，既不应高估也不应低估，应根据问题仔细调整。
- 4. **指数核：** 这与前一核（即高斯核）关系密切，唯一的区别是去除了范数的平方。指数函数的函数为：k(x,y) = exp( - || x - y || / 2σ^2 ) 这也是一个径向基核函数。
- 5. **拉普拉斯核：** 这种类型的核对变化不太敏感，并且与之前讨论的指数函数核完全相等，拉普拉斯核的方程如下：

```
k(x, y) = exp(-||x - y|| / \sigma)
```

- **双曲或 Sigmoid 核：** 该核用于机器学习的神经网络领域。Sigmoid 核的激活函数是双向 Sigmoid 函数。双曲核函数的方程为：k(x, y) = tanh(αx^T y + c)。该核在支持向量机中应用非常广泛且深受欢迎。
- **ANOVA 径向基核：** 该核在多维回归问题中表现非常好，类似于高斯核和拉普拉斯核。它也属于径向基核类别。ANOVA 核的方程为：k(x, y) = \sum_{k=1}^n exp(-\sigma(x^k - y^k)^2)^d。核方法有很多种类型，我们已讨论了最常用的核。它纯粹取决于问题类型，这将决定使用哪种核函数。
