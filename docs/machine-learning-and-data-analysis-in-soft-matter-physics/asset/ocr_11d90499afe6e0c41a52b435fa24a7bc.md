In particular, we show how the two entities, the RL agent and the simulation, shown by blue boxes, interact with each other by passing information. In particular, the RL agent communicates to the simulation which activation pattern A should be used in the next time-step, and the simulation communicates the number of particles per tag and bin back to the RL agent using the measurement tensor M.
