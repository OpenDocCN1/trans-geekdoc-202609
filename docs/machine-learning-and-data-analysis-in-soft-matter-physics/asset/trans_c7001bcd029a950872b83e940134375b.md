

机器学习算法使用计算方法，直接从数据中“学习”，而不依赖作为模型的预设方程。随着可用于学习的样本数量增加，算法会自适应调整以提升性能。深度学习是机器学习的一种特殊形式。

机器学习（ML），或深度学习，依赖算法来确定采取哪些行动，然后生成推断函数。未来，我们可能会看到机器实现真正的自我意识，并独立于受数据影响的人类输入进行操作。但目前，人类和数据将继续在塑造机器驱动的预测中发挥关键作用。指导机器学习模型有两种主要方法——监督学习和无监督学习。根据可用的数据和提出的问题，算法将使用这两种方法之一进行训练，以生成结果。两者的区别在于，监督学习在训练期间使用一整套标记数据。在无监督学习中，提供数据集时没有关于如何处理数据的明确说明；机器基本上是即兴发挥。

机器学习模型分为三大类：

### 1.2.2.1 监督机器学习

监督学习（又称监督机器学习）的定义特征在于：使用标记数据集来训练算法，以准确分类数据或预测结果。当输入数据被送入模型时，模型会调整其权重，直至得到适当的拟合。这是交叉验证过程的一部分，用于确保模型避免过拟合或欠拟合。监督学习帮助组织大规模解决各种实际问题，例如将垃圾邮件分类到收件箱外的单独文件夹中。监督学习中使用的一些方法包括神经网络、朴素贝叶斯、线性回归、逻辑回归、随机森林和支持向量机（SVM）。

监督学习算法构建一组包含输入和所需输出的数据的数学模型。这些数据称为训练数据，由一组训练示例组成。每个训练示例有一个或多个输入以及所需输出，也称为监督信号。在数学模型中，每个训练示例由数组或向量表示（有时称为特征向量），训练数据由矩阵表示。通过对目标函数的迭代优化，监督学习算法学习一个可用于预测新输入相关输出的函数。最优函数将使算法能够正确确定不属于训练数据的输入的输出。随着时间的推移，输出或预测精度不断提高的算法被认为已经学会了执行该任务。

监督学习算法的类型包括主动学习、分类和回归。当输出限制在有限的一组值时使用分类算法，当输出可能为某个范围内的任何数值时使用回归算法。例如，对于过滤电子邮件的分类算法，输入为收件邮件，输出为存放邮件的文件夹名称。

相似性学习是受监督机器学习的一个领域，与回归和分类密切相关，但其目标是使用相似性函数从示例中学习，该函数衡量两个对象有多相似或相关。它应用于排序、推荐系统、视觉身份跟踪、面部验证和扬声器验证。

### 1.2.2 无监督机器学习

无监督学习（又称无监督机器学习）使用机器学习算法来分析和聚类未标记的数据集。这些算法无需人工干预即可发现隐藏模式或数据分组。这种发现信息中相似性和差异性的能力使其非常适合探索性数据分析、交叉销售策略、客户细分以及图像和模式识别。它还用于通过降维过程减少模型中的特征数量。主成分分析（PCA）和奇异值分解（SVD）是这种方法的两种常见方法。无监督学习中使用的其他算法包括神经网络、K-Means聚类和概率聚类方法。

无监督学习算法接收仅包含输入的一组数据，并在数据中寻找结构，例如对数据点进行分组或聚类。因此，这些算法从未标记、分类或分类的测试数据中学习。无监督学习算法不是响应反馈，而是识别数据中的共同点，并根据每个新数据中这些共同点的存在或不存在做出反应。无监督学习的一项核心应用是统计学中的密度估计，例如寻找概率密度函数。尽管无监督学习还涵盖涉及总结和解释数据特征的其他领域。无监督学习算法简化了从泛基因组中调查和绘制感兴趣基因的基于大片段插入或缺失的单倍型的过程。

聚类分析是将一组观测值分配到子集（称为簇）中，使得同一簇内的观测值根据一个或多个预定标准相似，而来自不同簇的观测值不相似。不同的聚类技术对数据结构做出不同的假设，通常由某些相似性度量定义，并例如通过同一簇成员之间的相似性（内部紧凑性）或簇之间的差异（分离度）来评估。其他方法基于估计密度和图连接性。

### 1.2.3 半监督学习

半监督学习在监督学习和无监督学习之间提供了一个折中方案。在训练期间，它使用较小的标记数据集来指导从较大的未标记数据集中进行分类和特征提取。半监督学习可以解决监督学习算法缺乏足够标记数据的问题。

半监督学习介于无监督学习（没有任何标记训练数据）和监督学习（具有完全标记训练数据）之间。一些训练示例缺少训练标签，但许多机器学习研究人员发现，当未标记数据与少量标记数据结合使用时，可以显著提高学习准确性。在弱监督学习中，训练标签可能存在噪声、有限或不精确；但是，这些标签通常更便宜，从而产生更大的有效训练集。

### 1.2.4 强化机器学习

强化机器学习是一种与监督学习相似的机器学习模型，但该算法不是使用示例数据进行训练的。该模型通过试错法在过程中学习。一系列成功的结果将得到强化，以针对给定问题开发最佳建议或策略。

强化学习是机器学习的一个领域，关注软件代理人在环境中应如何采取行动，以最大化某种累积奖励概念。由于其通用性，该领域在许多其他学科中被研究，例如博弈论、控制理论、运筹学、信息论、基于仿真的优化、多代理系统、群体智能、统计学和遗传算法。在强化学习中，环境通常表示为马尔可夫决策过程（MDP）。许多强化学习算法使用动态规划技术。强化学习算法不假设对MDP的精确数学模型有知识，在精确模型不可行时使用。强化学习算法用于自动驾驶汽车或学习与人类对手对弈。

### 1.2.5 降维

降维是通过获取一组主变量来减少考虑中的随机变量数量的过程。换句话说，这是减少特征集维度的过程，也称为“特征数量”。大多数降维技术可被视为特征消除或特征提取。降维的一种流行方法是主成分分析（PCA）。PCA涉及将高维数据（例如，3D）转换到较小的空间（例如，2D）。这会导致数据维度减小（2D 而非 3D），同时在不改变数据的情况下保留模型中的所有原始变量。流形假设提出，高维数据集位于低维流形上，许多降维技术都做出此假设，从而发展出流形学习和流形正则化领域。
