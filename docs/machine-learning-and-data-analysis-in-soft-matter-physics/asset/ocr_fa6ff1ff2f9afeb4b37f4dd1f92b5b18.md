RL offers a unique advantage over the other ML methods for engineering design automation. Instead of relying on a pre-made training set, a designer can utilize RL to create training data during the learning process. The designer must create an RL environment to capture salient information about the design problem. The RL agent can now learn to satisfy a given design objective by interacting with the environment. The environment specifies the actions the agent can make and provides feedback on its performance. The environment can generate this feedback using nearly any combination of engineering analysis tools such as partial differential equation solvers, state machines, analytical equations, and even models based on real-world data.

Using RL, the engineering design problem is flipped from extracting the optimal design given a set of inputs to the optimal control problem of finding a sequence of actions that optimally satisfies the design problem. This difference allows the agent to be creative and explore regions of the design domain that would not be obvious to a human designer. In addition, the optimal sequence may require passing through several sub-optimal designs, where a gradient optimizer would get stuck in a local minimum before reaching the best design. The creativity of RL agents is well known for finding unique strategies within games and exploiting loopholes in game environments to maximize a reward function. As a result, the RL agent can learn what regions within the design space to explore or exploit to find the best design, which can be difficult for humans in complex design spaces.

RL is currently being used to aid in engineering design and optimization, including microfluidic device design for flow sculpting, microchip floor planning, 3D shape modeling, and metasurface design. The range of applications shows the generalization capabilities of RL within the engineering design field. However, the application of RL techniques to design optimized topologies is sparsely investigated.

# 7.4.1 Topology Optimization as a Reinforcement Learning Problem

The discretized TO problem needs to be reformulated as a sequential RL task, specifically, a Markov Decision Process (MDP). An MDP is a discrete-time stochastic process used in controls. An MDP is built upon four elements, state-space (S), action space (A), transition probability function (P), and reward function (R). If the TO problem can be expressed in terms of S, A, P, and R, then designing optimal topologies can be an MDP.
