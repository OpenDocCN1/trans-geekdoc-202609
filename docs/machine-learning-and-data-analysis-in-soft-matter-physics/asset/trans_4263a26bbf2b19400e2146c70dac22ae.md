## DBSCAN 中使用的术语：

- **核心点**：在其自身距离内具有最少点数的点
- **边界点**：在给定距离内具有至少一个核心点的点。
- **噪声点**：在给定距离内具有少于 m 个点的点。该点既不是核心点也不是边界点。
- **minPts**：一个阈值，表示最少点数，用于判断簇是否密集。
- **eps ε**：用于将点置于任何其他数据点区域内的距离度量。
- **可达性**：密度分布，用于识别点是否位于距离 eps 处，从而可从其他点到达。
- **连通性**：基于传递性的链式方法，用于确定指定簇中任意点的位置。

## 步骤：

- 从一个随机点开始，访问空间中的所有点。
- 使用距离 epsilon ε 计算邻域，以确定它是核心点还是异常值。如果是核心点，则在其周围形成簇。
- 通过添加近邻半径内可达的点来扩展簇。
- 重复上述步骤，直到所有点都加入簇或被标记为异常值。

## 5. BIRCH 算法

基于层次结构的平衡迭代缩减与聚类（BIRCH）是一种用于超大型数据集的聚类技术。这是一种快速算法，可在一次遍历中扫描整个数据集。它专注于稠密占用空间并创建精确摘要，以解决大型数据集聚面临的问题。

BIRCH 可适应任意给定的内存容量并尽量降低 I/O 复杂度。该算法仅用于处理度量属性，即没有分类变量的属性，或其值可以在欧几里得空间中以显式坐标表示的属性。该算法的主要参数是 CF 树和阈值。

- CF 树：聚类特征树是一种树结构，其中每个叶子节点包含一个子簇。CF 树中的每个条目包含指向子节点的指针。CF 条目由子节点中 CF 条目的总和组成。
- 阈值：每个叶子节点中条目的最大数量

### BIRCH 算法步骤

- 步骤 1 - 构建聚类特征 (CF) 树：从大型数据集中构建小型且密集的区域。可选地，在第 2 阶段将 CF 树压缩为更小的 CF。
- 步骤 2 – 全局聚类：将聚类算法应用于 CF 树的叶子节点。
- 步骤 3 – 如有需要，细化簇。

### 4.1.4 聚类的应用

聚类广泛应用于各个领域，以便为各种机器学习过程准备数据。聚类的一些应用如下。

- 市场细分：企业需要将市场细分为更小的群体以了解目标受众。聚类考虑邻域将志同道合的人群分组，以生成相似推荐，并有助于模式构建和洞察开发。
- 零售营销与销售：营销利用聚类来了解客户的购买行为，以便调节供应链和推荐。它将具有相似特征和购买概率的人群分组，有助于触达合适的客户细分群体并提供有效的促销
- **社交网络分析：** 使用网络和图论来考察定性和定量的社会安排。需要聚类来观察参与者之间的交互，以获取关于网络中各种角色和分组的洞察。
- **无线网络分析或网络流量分类：** 聚类将网络流量来源的特性组合在一起。形成簇以分类流量类型。掌握关于流量来源的精确信息有助于增长站点流量并有效规划容量。
- **图像压缩：** 聚类有助于以压缩形式存储图像，在不损失任何质量的前提下减小图像大小。
- **数据处理与特征加权：** 数据可以表示为簇 ID。这节省了存储空间并简化了特征数据。可以使用日期、时间和人口统计信息来访问数据。
- **流媒体服务监管：** 识别具有相似行为和兴趣的观众。Netflix 和其他 OTT 平台根据类型、每天观看分钟数和总观看会话等参数对用户进行聚类，将用户分为高使用量和低使用量等群体。这有助于为用户投放广告和相关推荐。
- **基于共现的标签建议：** 了解搜索行为，并在重复搜索时为其打上标签。为数据集输入内容，并每次搜索关键词时维护日志，将其与某个词标记在一起。两个标签同时出现的次数可以使用某些相似度指标进行聚类。
- **生命科学与医疗保健：** 聚类用于创建动植物分类学以组织具有类似功能的基因。它还用于使用医学图像分割检测癌细胞。
- **识别良好或不良内容：** 聚类有效地过滤假新闻，并通过使用来源、关键词和内容等属性来检测欺诈、垃圾信息或粗劣内容。

### 4.2.1 高维数据的散点图

可视化是从数据中获取洞察的关键步骤。我们可以从可视化中了解是否可以观察到模式，从而估计哪种机器学习模型合适。

描述二维事物很容易。通常带有 x 轴和 y 轴的散点图是二维的。描述三维事物有些挑战但并非不可能。例如，在 matplotlib 中，可以绘制 3D 图。唯一的问题是，在纸上或屏幕上，我们一次只能查看一个视口或投影下的 3D 图。在 matplotlib 中，这由仰角和方位角的度数控制。描述四维或五维事物是不可能的，因为我们生活在三维世界中，无法想象如此高维的事物是什么样子。这时，像 PCA 这样的降维技术就派上用场了。我们可以将维度降低到两维或三维，以便进行可视化。让我们从一个示例开始。
