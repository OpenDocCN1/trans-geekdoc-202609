Q represents the quality of the actions at each state. So instead of using a value at each state, we will use a pair of state and action, i.e., Q(s, a). To perform any action, the agent will get a reward R(s, a), and also he will end up on a certain state, so the Q-value equation will be:

Q(s, a) = R(s, a) + \gamma \sum_{s'} (P(s, a, s') \max Q(s', a'))

The above formula is used to estimate the Q-values in Q-Learning.

## 'Q' in Q-learning?

Q stands for quality in Q-learning, which means it specifies the quality of an action taken by the agent.

### Q-table:

A Q-table or matrix is created while performing the Q-learning. The table follows the state and action pair, i.e., [s, a], and initializes the values to zero. After each action, the table is updated, and the Q-values are stored within the table.

The RL agent uses this Q-table as a reference table to select the best action based on the Q-values.

## 7.4 REINFORCEMENT LEARNING TECHNIQUES FOR OPTIMIZING SOFT MATTER PROCESSES AND MATERIALS DESIGN

An alternative branch of ML, which does not rely on generating a training dataset ahead of time, is reinforcement learning (RL). Within the RL paradigm, the goal is to train an agent to learn to complete a particular task or set of tasks within an interactive environment by giving the agent feedback (reward) on its performance. The agent is essentially learning how to solve the optimal control problem for a given task. In recent years, RL has shown groundbreaking achievements in the fields of game-play, protein folding, and robotic control, among others.

RL agents in the engineering design process may help solve several complex optimization challenges. Traditional design automation methods, such as TO, require a formal mathematical representation of the objectives and constraints, which can be difficult to formulate for many processes. Furthermore, if the objective and constraint functions can be developed, they should be continuous and smooth to improve convergence capabilities. An optimizer that can use a black-box simulation would be helpful. While heuristic optimization tools can solve some of these challenges and operate with black-box simulation tools, RL agents have shown superior performance over heuristic approaches in many domains.

RL offers a unique advantage over the other ML methods for engineering design automation. Instead of relying on a pre-made training set, a designer can utilize RL to create training data during the learning process. The designer must create an RL environment to capture salient information about the design problem. The RL agent can now learn to satisfy a given design objective by interacting with the environment. The environment specifies the actions the agent can make and provides feedback on its performance. The environment can generate this feedback using nearly any combination of engineering analysis tools such as partial differential equation solvers, state machines, analytical equations, and even models based on real-world data.

Using RL, the engineering design problem is flipped from extracting the optimal design given a set of inputs to the optimal control problem of finding a sequence of actions that optimally satisfies the design problem. This difference allows the agent to be creative and explore regions of the design domain that would not be obvious to a human designer. In addition, the optimal sequence may require passing through several sub-optimal designs, where a gradient optimizer would get stuck in a local minimum before reaching the best design. The creativity of RL agents is well known for finding unique strategies within games and exploiting loopholes in game environments to maximize a reward function. As a result, the RL agent can learn what regions within the design space to explore or exploit to find the best design, which can be difficult for humans in complex design spaces.

RL is currently being used to aid in engineering design and optimization, including microfluidic device design for flow sculpting, microchip floor planning, 3D shape modeling, and metasurface design. The range of applications shows the generalization capabilities of RL within the engineering design field. However, the application of RL techniques to design optimized topologies is sparsely investigated.

### 7.4.1 Topology Optimization as a Reinforcement Learning Problem

The discretized TO problem needs to be reformulated as a sequential RL task, specifically, a Markov Decision Process (MDP). An MDP is a discrete-time stochastic process used in controls. An MDP is built upon four elements, state-space (S), action space (A), transition probability function (P), and reward function (R). If the TO problem can be expressed in terms of S, A, P, and R, then designing optimal topologies can be an MDP.

Formally, the TO problem can be viewed as finding the material distribution G that minimizes an objective function, F, subject to a volume constraint G₀≤0 and possibly M other constraints Gᵢ≤0, i=1⋯M. The material distribution is described by the density variable ρ that can take either the value 0 (void) or 1 (solid material) at any point in the design domain Ω. The mathematical form of this optimization problem is shown in Eq. (5):

```
min F
F(u(ρ), ρ) = ∫_Ω f(u(ρ), ρ)dV
s.t. : G₀(ρ) = ∫_Ω ρdV - V₀ ≤ 0
: ρ(x) = 0 or 1, ∀x ∈ Ω
(5)
```

where the state field u satisfies a linear or nonlinear state equation. For this application, the objective function, F(u(ρ), ρ), is compliance, where minimizing compliance leads to maximizing the stiffness of the structure. The objective function is dependent on the density of the material at each location, u(ρ), which will take the value of 1 (material) or 0 (void). The objective function is also dependent on predetermined constraints, Gᵢ(u(ρ), ρ), which can be subject to change for different applications. Finally, the design space, Ω, indicates the allowable volume, V, within which the design can exist.

#### State Space

The state-space, S, of an environment represents all the combinations of observations that an agent can experience while interacting with the environment. The agent’s current observation depends on the boundary conditions, loading conditions, and current topology. The individual observations that comprise the state-space were built as N x N x 3 arrays, where N represents the number of elements in one dimension.

The first channel of the observation array is the normalized inverse Von Mises Stress, σ_VM, of each element. This channel describes the current stress distribution within the topology. The Von Mises stress is commonly used in engineering design to describe an object’s current stress state. The Von Mises stress for each 2D element can be found under any load case using Eq. (6):

```
\(\sigma_{VM} = \sqrt{\sigma_x^2 + \sigma_y^2 - \sigma_x\sigma_y + 3\tau_{xy}}\) (6)
```

where σ_x, σ_y, and τ_xy are found using a 2D plane stress FEA solver. The FEA solver automatically calculates the Von Mises stress at each design step by calling the current topology’s stiffness matrix and bounded and loaded elements. The stiffness matrix is defined by assigning each element the material or void modulus of elasticity depending on the current topology. This “in the loop” FEA solver could be replaced by a trained surrogate model to improve computational efficiency. Eq. (6) is only used for material elements within the topology. Voided elements are assigned a value of 0 to isolate the location of the voided elements.
