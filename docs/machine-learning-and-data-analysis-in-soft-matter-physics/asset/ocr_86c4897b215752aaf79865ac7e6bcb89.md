Because this cycle typically occurs multiple times, we call these strategies oscillatory, and they emerge in different flavors. For large \(\alpha\), the emergent strategy still collapses particles to a dense cluster (see Fig. 4a) in a strategy we term "oscillation w/collapse". For smaller \(\alpha\), the strategies still use oscillations but avoid very dense clusters in a strategy we call "oscillations w/o collapse", depicted in Fig. 4b.
