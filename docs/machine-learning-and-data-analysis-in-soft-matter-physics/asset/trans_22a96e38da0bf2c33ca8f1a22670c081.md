- **准确性:** 企业数据库中的所有数据必须高度准确。验证其准确性的一种方法是将其与不同来源进行比较。如果找不到来源或来源存在错误，存储的信息也会有相同的问题。

- **一致性:** 数据之间必须保持一致，因此可以确保个人或主体的信息在所使用的不同存储形式中是相同的。

- **有效性:** 存储的数据必须遵循某些规定或既定限制。同样，必须对信息进行验证以证实其真实性。

- **数据验证:** 必须随时验证该过程，包括程序的适当性和有效性。上述验证通过研究、设计和验证阶段的各个实例来进行。缺点通常在数据应用于一定数量的更改后才显现出来。

## 2.2 处理缺失数据

处理缺失数据是任何科学领域（包括软物质物理学）中数据预处理的关键部分。缺失数据可能由于各种原因出现，例如测量错误、设备故障或不完整的模拟。处理缺失数据需要仔细考虑，以确保最终数据集保持可靠并能代表底层现象。以下是一些常见的缺失数据处理技术：

### 删除缺失数据

一种直接的方法是移除包含缺失数据的行或样本。这种方法称为“逐条删除”或“完整案例分析”。虽然简单，但这种方法可能导致有价值信息的丢失，特别是当缺失数据的比例较大时。

### 插补

插补涉及根据数据集中可用的信息估计缺失值。存在多种插补技术，例如：

- a. 均值/中位数/众数插补: 使用相应特征的均值、中位数或众数替换缺失值。这种方法快速简便，但可能无法捕捉数据中的真实潜在关系。
- b. 线性插值: 对于顺序或时间序列数据，可以使用线性插值对缺失值进行插值，假设相邻数据点之间存在线性关系。
- c. 多重插补: 多重插补基于统计模型创建多个合理的插补数据集，并合并其结果以获得更稳健的估计。这种方法考虑了插补相关的不确定性。
- d. K近邻（KNN）插补: KNN插补基于特征空间中最近邻域的值来估计缺失值。
- e. 期望-最大化（EM）插补: EM插补基于数据的概率模型迭代估计缺失值。

### 标记缺失值

与其插补缺失值，不如为每个特征创建二进制标志或指示变量，指示值是存在还是缺失。这样，关于缺失的信息会被保留，并可在分析中作为单独的特征使用。

### 领域特定插补

在软物质物理学中，领域知识可能有助于制定针对数据物理背景量身定制的特定插补方法。例如，可以根据系统的已知动力学推断模拟中缺失的粒子位置。

### 基于模型的插补

如果数据集包含足够信息，可以根据数据集中的其他特征为缺失值构建预测模型。这些模型可以是回归模型或机器学习算法。

仔细评估所选插补方法及其对下游分析的潜在影响至关重要。此外，在选择最合适的插补策略时，还应考虑缺失数据的数量和根本原因。始终记录缺失数据的处理过程，以确保结果的透明度和可重复性。请记住，插补会引入一定程度的不确定性，可能需要进行敏感性分析以评估不同插补方法下研究结果的稳健性。

## 2.3 数据缩减

可以应用数据缩减技术来获得数据集的缩减表示，其体积小得多，同时紧密保持原始数据的完整性。也就是说，对缩减后的数据集进行挖掘应更高效，并产生相同（或近乎相同）的分析结果。

### 2.3.1 数据缩减策略

数据缩减策略包括维度缩减、数量缩减和数据压缩。

### 维度缩减

维度缩减是减少所考虑的随机变量或属性数量的过程。维度缩减方法包括小波变换和主成分分析，它们将原始数据转换或投影到更小的空间。属性子集选择是一种维度缩减方法，用于检测和删除不相关、弱相关或冗余的属性或维度。

### 数量缩减

数量缩减技术使用替代的、更小的数据表示形式来替换原始数据量。这些技术可以是参数的或非参数的。

对于参数方法，使用模型来估计数据，因此通常只需存储数据参数，而不需要存储实际数据。（异常值也可能被存储。）回归和对数线性模型是示例。用于存储数据缩减表示的非参数方法包括直方图、聚类、采样和数据立方体聚合。

### 数据压缩

在数据压缩中，应用变换以获得原始数据的缩减或“压缩”表示。如果可以从压缩数据中重建原始数据而没有任何信息丢失，则该数据缩减称为无损。相反，如果只能重建原始数据的近似值，则该数据缩减称为有损。存在多种用于字符串压缩的无损算法，但是，它们通常只允许对数据进行有限操作。维度缩减和数量缩减技术也可以被视为数据压缩的形式。

组织数据缩减方法还有许多其他方式。花费在数据缩减上的计算时间不应超过或“抵消”在缩减数据集规模上进行挖掘所节省的时间。

### 2.3.2 小波变换

离散小波变换（DWT）是一种线性信号处理技术，当应用于数据向量 X 时，将其转换为一个在数值上不同的向量 X'，即小波系数。两个向量长度相同。在将此技术应用于数据缩减时，我们将每个元组视为一个 n 维数据向量，即 X = (x₁, x₂ ... xₙ)，表示从 n 个数据库属性对元组进行的 n 次测量。

“如果小波变换后的数据与原始数据长度相同，这项技术如何对数据缩减有用？” 其有用性在于，小波变换后的数据可以被截断。通过仅存储最强小波系数的一小部分，可以保留数据的压缩近似值。例如，可以保留所有大于用户指定阈值的小波系数。所有其他系数均设置为 0。因此，得到的数据表示非常稀疏，如果在小波域中执行，可以利用数据稀疏性的操作在计算上非常快速。该技术还可以在不平滑数据主要特征的情况下去除噪声，因此也对数据清洗有效。给定一组系数，可以通过应用所使用的 DWT 的逆变换来构建原始数据的近似值。

DWT 与离散傅里叶变换（DFT）密切相关，后者是一种涉及正弦和余弦的信号处理技术。然而，一般来说，DWT 能够实现更好的有损压缩。也就是说，对于给定的数据向量，如果 DWT 和 DFT 保留相同数量的系数，DWT 版本将提供对原始数据的更准确近似。因此，对于等效近似，DWT 所需空间少于 DFT。
