

受控的情况下，可以实现各种目标，例如在不同雷诺数下通过流体导航，以及在多智能体环境中解决多种任务时出现的自组织现象，利用微观系统实现宏观行为具有挑战性。

诚然，曾实现一些有限控制，例如能够产生简单的流体流动、实现全局粒子动量，并加速原本呈玻璃态的系统达到平衡，但更复杂场景的控制策略仍然缺失。

这种具有挑战性的行为之所以出现，是因为活性物质系统以相互作用为主导，因此控制策略必须通过智能体之间的相互作用来施加间接控制，而非依赖于单个智能体的属性。因此，要找到实现宏观目标的成功策略，需要采用先进的控制方法，包括基于策略的强化学习。

本节要解决的关键问题是，利用基于蛋白质的活性物质系统，为宏观混合任务寻找控制策略。具体来说，我们的重点是通过将强化学习（RL）应用于我们最近的数值活性物质模型，来寻找活性颗粒的混合策略。如果能为活性颗粒找到良好的混合方案，这些策略随后可实验实施，以诱导周围介质发生混合，例如通过流体-物质相互作用。对于我们的活性颗粒模型，我们观察到，当仅可用吸引或排斥相互作用时，RL无法学到良好的策略；而如果吸引和排斥相互作用可以结合，RL则能找到良好的策略。

我们利用动力系统理论（特别是双曲动力学理论和Anosov微分同胚理论）来分析这种令人困惑的行为，以证明混合相互作用确实是使问题可解所必需的。因此，我们的结果为使基于蛋白质的活性物质具有应用性提供了指导，并回答了最近一篇综述中提出的不同相互作用如何导致宏观行为的问题。

### 7.2.1 仿真与强化学习环境

在本工作中，我们将首先将强化学习（RL）应用于特定的活性物质微观模型。具体来说，我们希望选择一个足够简单的模型，既适合RL，同时又能描述与微观材料传输和活性物质核心相关的各种问题。微观模型通常由阻力主导，并可分为连续理论和基于颗粒的模型。虽然连续理论因其解析特性通常更受青睐，但我们选择了基于颗粒的模型，因为它们模拟小型和中型系统通常更快，因此更适合需要大量仿真的RL。此外，由于我们关注的是一般性质，一个现象学模型就足够了，我们使用了仿真平台。需要指出的是，我们的结果将在第4节推广到更广泛的一系列模型中。

我们的模型只需要吸引相互作用来描述现有实验平台。然而，这一限制将被发现会限制混合。因此，引入了如下扩展模型：系统由二维中的\(N_p\)个颗粒组成，按\(i\)索引，可以处于三种状态之一：吸引激活状态（\(p_i^a = 1, p_i^r = 0\)）、排斥激活状态（\(p_i^a = 0, p_i^r = 1\)）或非激活状态（\(p_i^a = 0, p_i^r = 0\)）。如果颗粒之前处于非激活状态，当其位于相应的激活区域（这将构成我们的控制输入）时，可以被激活，并以速率\(\lambda\)去激活回非激活状态。激活的颗粒通过弹簧势与其他相似激活的颗粒相互作用。系统的动力学由运动方程描述

\(\vec{x}_i(t+\Delta t) = \vec{x}(t) + \frac{\Delta t^2}{m}\vec{F}_i,\)  
(1a)

\(\vec{F}_i = \vec{F}_i^a + \vec{F}_i^r,\)  
(1b)

\(\vec{F}_i^a = -\nabla_i \left[ \frac{k}{2} \sum_{j \neq i}^{r_c < |\vec{x}_i - \vec{x}_j| < R_c} p_i^a p_j^a |\vec{x}_i - \vec{x}_j|^2 \right],\)  
(1c)

\(\vec{F}_i^r = -\nabla_i \left[ \frac{k}{2} \sum_{j \neq i}^{r_c < |\vec{x}_i - \vec{x}_j| < R_c} p_i^r p_j^r (|\vec{x}_i - \vec{x}_j| - R_c)^2 \right],\)  
(1d)

其中，\(\vec{x}(t)\)是时间\(t\)时颗粒\(i\)的位置，\(\vec{F}_i\)是作用在它上的总力。总力\(\vec{F}_i\)被分为吸引和排斥两部分贡献，并且在每个时间步中，至少有一部分为零，因为\(p_i^a\)和\(p_i^r\)中至少有一个为0。需要注意的是，吸引力和排斥力包含相同的弹簧常数\(k\)、下截断\(r_c\)和上截断\(R_c\)，两者仅在静长方面有所不同：吸引力的静长为0，排斥力的静长为\(R_c\)。需要指出的是，公式(1)描述了阻力主导的颗粒，因为虽然这些方程是从惯性描述导出的，但采用了无穷大阻力极限，以确保大时间步的数值稳定性。

利用这一具有可控成对弹簧相互作用的阻力主导颗粒动力学模型，我们使用OpenAI gym构建了一个RL环境。具体来说，\(N_p = 96\)个颗粒在具有周期性边界条件的盒子中随机初始化，确保系统两半的颗粒数量相等（为便于今后参考，标记为“左”和“右”）。然后系统按照公式(1)进行积分，时间步为\(\Delta t = 0.05\)，共\(N_t = 100\)个时间步。初始条件的草图见图1b，目标状态示例如图1c所示。观测空间和控制空间通过一个\(N_g \times N_g = 4 \times 4\)方形网格引入，如图1d所示。具体来说，通过为每个标签（对应图1b和c中的橙色和蓝色）和每个箱提供单独的计数，将观测值提供给算法。系统通过将每个分箱方格关联为激活区域或不关联任何区域来进行控制，因此，如果包含两种相互作用，每个时间步的动作空间维度为\(3^{4 \times 4} \approx 43 \times 10^6\)。

需要注意的是，单个仿真规模相对较小，仅有96个颗粒和一个 \(4 \times 4\) 网格的粗分箱。我们选择如此小的系统尺寸，是因为单个仿真要运行数千次，因此需要运行得非常快。尽管如此，由于单个仿真的缩放仅为\(O(N_p^2)\)，未来工作可以很容易地扩展到更多的颗粒数量。相比之下，由于动作空间与网格分辨率呈指数级缩放，提高空间分辨率会减慢学习速度，并且可能需要实施诸如课程学习等更先进的方法才能实现精细控制。然而，本节的主要结果，即两种相互作用的必要性，将继续成立，而不论颗粒数量或网格分辨率如何。
