

## 无监督学习技术

### 简介

无监督学习，也称为无监督机器学习，使用机器学习算法来分析和聚类未标记的数据集。这些算法在无需人工干预的情况下发现隐藏的模式或数据分组。其发现信息中相似性和差异性的能力，使其成为探索性数据分析、交叉销售策略、客户细分和图像识别的理想解决方案。

### 4.1 用于模式识别和数据探索的聚类算法

聚类是一种识别数据中相似性组（称为簇）的技术。即，它将相互相似（相近）的数据实例归为一类，并将彼此差异很大（相距很远）的数据实例归入不同的类别。由于事先未指定表示数据实例先验分组的类别值（如受监督学习中所做的那样），聚类通常被称为无监督学习任务。出于历史原因，聚类通常被视为与无监督学习同义。

### 4.1.1 什么是聚类？

聚类或聚类分析是基于相似性对实体进行分组的方法。它被定义为一种无监督学习问题，旨在使用给定的一组输入但没有任何目标值来构建训练数据。这是在一组未标记的数据中寻找相似结构的过程，以使其更易于理解和操作。

它揭示了可用异构数据集中的子群，使得每个单独的簇比整体具有更高的同质性。简单来说，这些簇是相似对象的组，与其他簇中的对象不同。

在聚类中，机器在没有提供输入-输出映射的情况下自行学习属性和趋势。聚类算法从数据对象的类型中提取模式和推断，然后将其适当地聚为离散的类。

### 4.1.2 聚类方法的类型

聚类有助于对非结构化数据进行表面级分析。簇的形成取决于不同的参数，如最短距离、图形和数据点的密度。通过基于称为相似度量的某些指标来查找对象之间的相似度量，来进行簇分组。在特征数量较少时，更容易找到相似度量。随着特征数量的增加，创建相似度量会变成一个复杂的过程。数据挖掘中不同类型的聚类方法使用不同的方法来对数据集中的数据进行分组。各种聚类类型如下：

- 基于连接性的聚类（层次聚类）
- 基于质心的聚类（划分方法）
- 基于分布的聚类
- 基于密度的聚类（基于模型的方法）
- 模糊聚类
- 基于约束的（受监督聚类）

- **1. 基于连接性的聚类（层次聚类）：** 层次聚类，也称为基于连接性的聚类，基于这样一个原理：每个对象都根据其邻近距离（关系程度）与其邻居连接。簇以广泛的层次结构表示，结构由连接簇部分所需的最大距离分隔。簇表示为树状图，其中 X 轴表示不合并的对象，而 Y 轴表示簇合并的距离。相似的数据对象具有最小距离并落在同一簇中，而不相似的数据对象在层次结构中被放置得更远。映射的数据对象对应于一个簇，涉及多维缩放、数据变量之间的定量关系或某些方面的交叉表等离散属性。层次聚类可能在所选数据流的以下类别中有所不同。

### *分割方法*

层次聚类的这种方法遵循自上而下的方法，我们认为所有数据点都属于一个大簇，并尝试基于终止逻辑或不再划分数据点的点，将数据分为较小的组。这种终止逻辑可以基于簇内误差平方和的最小值，或者对于分类数据，指标可以是簇内的 GINI 系数。

因此，我们迭代地将曾经被归为一个大簇的数据，分割为数据点现在所属的“n”个较小簇。必须注意的是，该算法在分割簇时具有高度的“刚性”——意味着，一旦在循环中完成一次聚类，该任务就无法撤销。

### *聚合方法*

聚合方法与分割方法恰恰相反，其中所有“N”个数据点都被视为数据组成的“N”个簇中的单个成员。我们迭代地将这些众多的“N”个簇合并为较少数量的簇，假设为“k”个簇，从而相应地将数据点分配给这些簇。这是一种自下而上的方法，并且在合并簇时也使用终止逻辑。这种逻辑可以是基于数量的标准（超过此点不再有簇）或基于距离的标准（簇不应相距太远以无法合并）或基于方差的标准（合并簇的方差增加不应超过阈值，Ward 方法）

- **2. 基于质心或划分聚类：** 基于质心的聚类是数据挖掘中所有聚类类型中最容易的一种。它基于数据点与所选中心值的接近程度。数据集被划分为给定数量的簇，每个簇引用一个值向量。输入数据变量与向量值进行比较，并进入差异最小的簇。

在初始阶段预定义簇的数量是聚类方法中最关键但也最复杂的阶段。尽管存在缺点，它是一种广泛使用的聚类方法，用于发现和优化大型数据集。K-Means 算法属于此类别。

这些聚类方法组通过使用各种距离度量，迭代地测量簇与特征质心之间的距离。这些度量可以是欧氏距离、曼哈顿距离或明可夫斯基距离。

这里的主要缺点是，我们应该要么凭直觉，要么科学地（肘部法）定义簇的数量“k”，以便开始任何聚类机器学习算法的迭代，以开始分配数据点。

此外，由于其实现和解释的简单性，这些算法具有广泛的应用领域，例如市场细分、客户细分、文本主题检索、图像分割等。

- **3. 基于密度的聚类（基于模型的方法）：** 上文讨论的前两种方法都依赖于距离（相似性/邻近性）度量。簇的定义本身就是基于这个度量的。

基于密度的聚类方法将密度置于距离之上。数据通过高浓度数据对象区域（由低浓度数据对象区域包围）进行聚类。形成的簇被组合为连接数据点的最大集合。

形成的簇具有任意的形状和大小，并且由于密度相似而具有最大程度的同质性。这种聚类方法有效地包括了数据集中的噪声和离群点。

在执行大多数聚类时，我们做出两个主要假设：数据中没有任何噪声，并且形成的簇形状是纯粹几何的（圆形或椭圆形）。

事实是，数据总是存在某些程度的不一致性（噪声），不能忽视。除此之外，我们不应将自己局限于固定的属性形状。

采用任意形状是可取的，以免忽略任何数据点。基于密度的算法正是在这些领域证明了自己的价值！
