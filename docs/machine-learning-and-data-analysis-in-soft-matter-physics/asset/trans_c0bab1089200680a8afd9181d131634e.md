### 3.2.1 线性回归

线性回归是源自监督学习的最简单的机器学习算法之一，主要用于解决回归问题。

线性回归的用途是在自变量的辅助和知识下，对连续因变量进行预测。线性回归的总体目标是找到最佳拟合线，该线能够准确预测连续因变量的输出。连续值的示例包括房价、年龄和薪水。

简单线性回归是一种回归模型，使用直线来估计一个单一自变量与一个因变量之间的关系。如果有超过两个自变量，则称之为多元线性回归。

使用最佳拟合线的策略有助于我们理解因变量和自变量之间的关系，这种关系应为线性关系。

### 线性回归的公式

如果你还记得高中数学，你会记得公式：y = mx + b，它表示直线的斜截式。‘y’和‘x’表示变量，‘m’描述直线的斜率，‘b’描述y轴截距，即直线与y轴交叉的点。

对于线性回归，’y’表示因变量，’x’表示自变量，β0表示y轴截距，β1表示斜率，用于描述自变量与因变量之间的关系。

### 3.2.2 逻辑回归

逻辑回归也是一种非常流行的机器学习算法，源自监督学习。逻辑回归可用于回归和分类任务，但主要用于分类。如果你想了解更多关于用于分类任务的逻辑回归的信息，请点击此链接。逻辑回归预测今天是否会下雨的示例，使用0或1，是或否，或真和假。逻辑回归的用途是在自变量的辅助和知识下，预测分类因变量。逻辑回归的总体目标是对输出进行分类，其结果只能在0和1之间。

在逻辑回归中，输入的加权和将通过一个称为Sigmoid函数的激活函数，该函数将值映射到0到1之间。

![](img/c4a53cbbd40023d194b7887dddf3293b_92_1.png)

### Sigmoid函数的公式

$$f(x) = \frac{1}{1+e^{-(x)}}$$

逻辑回归基于最大似然估计，这是一种在给定一些观测数据的情况下，估计假设概率分布参数的方法。

### 3.2.3 线性回归与逻辑回归对比

### 3.2.4 线性回归和逻辑回归在机器学习中如何工作？

线性回归和逻辑回归都是属于监督学习模型的机器学习算法。由于两者都属于监督模型，因此它们使用标记数据进行预测。线性回归用于回归或预测连续值，而逻辑回归既可用于分类也可用于回归问题，但广泛用作分类算法。回归模型旨在基于独立特征预测值。使两者彼此不同的主要区别在于：当因变量为二元时考虑逻辑回归，而当因变量为连续值时则使用线性回归。

### 线性回归

每个人在学校时都一定接触过线性模型。数学教会了我们关于线性模型的知识。它就是目前广泛用于预测分析的同一模型。它主要讲述了使用直线表示的因变量（目标）与预测变量之间的关系。线性回归基本分为两种类型：简单线性回归和多元线性回归。

![](img/c4a53cbbd40023d194b7887dddf3293b_94_0.png)

X轴上的经验与Y轴上的薪水

在上图中，薪水是位于Y轴上的因变量，自变量位于X轴上，即经验。经验越多，薪水越高。回归线可以写成：

Y1 = a0 + a1X + ε

其中系数为a0和a1，误差项为ε。

线性回归的自变量可以是连续的，也可以是离散的，但因变量必须是连续的。线性回归中的最佳拟合线是使用均方误差计算的，用于找出因变量Y与自变量X之间的关系。两者之间始终存在线性关系。

线性回归只有一个自变量，而在多元回归中可以有多个自变量。
