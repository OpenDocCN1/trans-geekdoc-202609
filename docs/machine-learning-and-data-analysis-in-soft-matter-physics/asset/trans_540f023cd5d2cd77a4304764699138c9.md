

## 特征选择的类型：

- Filter Method：基于特征与目标变量之间关系的统计度量。选择相关性高的特征。

- Wrapper Method：基于使用特定机器学习算法对特征子集进行评估。选择性能最好的特征子集。

- Embedded Method：基于将特征选择作为机器学习算法训练过程的一部分。

### 特征选择的优势：

- Reduces Overfitting：仅使用最相关的特征，模型可以更好地泛化到新数据。

- Improves Model Performance：选择合适的特征可以提高模型的准确率、精确率和召回率。

- Decreases Computational Costs：特征数量减少需要的计算和存储资源更少。

- Improves Interpretability：通过减少特征数量，更容易理解和解释模型的结果。

## 5. 特征缩放

特征缩放是将特征进行转换，使其具有相似尺度的过程。这在机器学习中很重要，因为特征的尺度会影响模型的性能。

### 特征缩放的类型：

- Min-Max Scaling：通过减去最小值并除以范围，将特征重新缩放到特定范围（例如 0 到 1 之间）。

- Standard Scaling：通过减去均值并除以标准差，将特征重新缩放为均值为 0、标准差为 1。

- Robust Scaling：通过将特征除以四分位距，使其对异常值具有鲁棒性。

### 特征缩放的优势：

- Improves Model Performance：通过将特征转换为相似尺度，模型可以平等地学习所有特征，避免被少数大值特征主导。

- Increases Model Robustness：通过将特征转换为对异常值具有鲁棒性，模型可以对异常值更加鲁棒。

- Improves Computational Efficiency：许多机器学习算法（例如 k-近邻）对特征的尺度敏感，使用缩放后的特征表现更好。

- Improves Model Interpretability：通过将特征转换为相似尺度，更容易理解模型的预测。

### 缺失值填充

缺失值填充是处理缺失值的过程，这是在准备机器学习数据时最常见的问题之一。缺失值是指某一行的某些单元格中缺少信息的地方。

缺失值可能有多种原因，包括人为错误、数据流中断、跨数据集错误等。由于数据完整性影响机器学习模型的表现，因此缺失值填充非常重要。

以下是解决缺失值问题的一些方法：

- 如果某一行的完整度低于 20-30%，建议丢弃该记录。

- 为缺失单元格赋值的标准方法是计算某一列的众数、均值或中位数，并用其替换缺失值。

- 在其他情况下，可以根据其他条目重建数值。例如，如果我们知道某个城市和行政单位的名称，可以找出国家的名称。反之，我们通常可以通过邮政编码确定国家/城市。

您可以在本文中找到更复杂的缺失值填充方法。

### 独热编码

类别值（通常称为名义数据），如性别、季节、宠物、品牌名称或年龄段，通常需要转换，具体取决于所使用的机器学习算法。例如，决策树可以处理类别数据。然而，许多其他算法需要引入具有二进制表示的额外人工类别。二进制表示意味着如果特征有效则赋值为 1，否则赋值为 0。

独热编码是机器学习模型中类别特征预处理的一种技术。对于每个类别，它都会设计一个新的二进制特征，通常称为“虚拟变量”。

### 对数变换

此方法可以将偏态分布近似为正态分布。对数变换（或 log 变换）将每个变量 x 替换为 log(x)。

![](img/c4a53cbbd40023d194b7887dddf3293b_77_0.png)

### 对数变换的优势：

- 范围内数据的量级通常有所不同。例如，10 至 20 岁的量级与 60 至 70 岁的量级不同。这种类型的数据差异通过对数变换进行归一化。

- 归一化量级差异并提高模型鲁棒性，同时也减少了异常值的负面影响。

例如，尽管楼层数值较小，但建筑物中的楼层数与面积同样重要。

另一个例子是，如果我们使用行星之间的比例而不是实际直径来归一化数值，则更容易进行行星的比较分析。

## 2.5.5 特征工程工具

有多种可用于特征工程的工具。以下是一些流行的工具：

### 1. Featuretools

Featuretools 是一个 Python 库，可用于结构化数据的自动特征工程。它可以从多个表中提取特征（包括关系数据库和 CSV 文件），并根据用户定义的原语生成新特征。其功能包括：

- 使用机器学习算法进行自动特征工程。

- 支持处理时间相关数据。

- 与流行的 Python 库集成，例如 pandas 和 scikit-learn。

- 用于探索和分析生成特征的可视化工具。

- 供入门使用的详细文档和教程。
