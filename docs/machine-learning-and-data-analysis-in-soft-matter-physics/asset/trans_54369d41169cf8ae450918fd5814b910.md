## 异常检测

在数据挖掘中，异常检测（也称为离群点检测）是指识别那些因与数据绝大部分显著不同而引起怀疑的罕见项目、事件或观察。通常，异常项目代表诸如银行欺诈、结构缺陷、医疗问题或文本错误等问题。

异常也被称为离群点、新奇项、噪声、偏差和例外。

特别是在滥用和网络入侵检测的背景下，感兴趣的对象通常不是罕见对象，而是意外的非活动突增。

这种模式不符合将离群点定义为罕见对象的常见统计定义。许多离群点检测方法（特别是无监督算法）在处理此类数据时会失败，除非进行适当的聚合。相反，聚类分析算法可能能够检测由这些模式形成的微聚类。

存在三大类异常检测技术。无监督异常检测技术在无标签测试数据集中检测异常，前提是数据集中的大多数实例都是正常的，通过寻找与数据集其余部分最不匹配的实例来实现。

有监督异常检测技术需要一个标记为“正常”和“异常”的数据集，并涉及训练分类器（与许多其他统计分类问题的关键区别在于离群点检测本质上不平衡的特性）。半监督异常检测技术从给定的正常训练数据集构建表示正常行为的模型，然后测试测试实例由该模型生成的可能性。

机器人学习受到多种机器学习方法的启发，从有监督学习、强化学习，最终到元学习（例如 MAML）。

## 关联规则

关联规则学习是一种基于规则的机器学习方法，用于在大型数据库中发现变量之间的关系。它旨在使用某种“趣味性”度量来识别在数据库中发现的强规则。

基于规则的机器学习是任何用于识别、学习或演化“规则”以存储、操作或应用知识的机器学习方法的统称。基于规则的机器学习算法的定义特征是识别和利用一组关系规则，这些规则共同表示系统所捕获的知识。这与通常识别一个可普遍应用于任何实例以进行预测的单一模型的其他机器学习算法形成对比。基于规则的机器学习方法包括学习分类器系统、关联规则学习和人工免疫系统。

例如，超市销售数据中发现的规则 {onions, potatoes} => {burger} 表示，如果顾客同时购买洋葱和土豆，那么他们也可能购买汉堡肉。此类信息可用于促销定价或产品摆放等营销活动决策的基础。除了购物篮分析外，关联规则目前还应用于 Web 使用挖掘、入侵检测、连续生产和生物信息学等应用领域。与序列挖掘不同，关联规则学习通常不考虑事务内部或事务之间项目的顺序。

学习分类器系统（LCS）是一类基于规则的机器学习算法，将发现组件（通常是遗传算法）与学习组件相结合，执行有监督学习、强化学习或无监督学习。它们旨在识别一组上下文相关规则，这些规则以分段方式共同存储和应用知识，以便进行预测。

归纳逻辑编程（ILP）是一种规则学习方法，使用逻辑编程作为输入示例、背景知识和假设的统一表示。给定已知背景知识的编码以及一组表示为事实逻辑数据库的示例，ILP 系统将推导出一个假设的逻辑程序，该程序蕴含所有正例且不包含负例。归纳编程是一个相关领域，它考虑用于表示假设的任何种类的编程语言（而不仅仅是逻辑编程），例如函数式程序。

归纳逻辑编程在生物信息学和自然语言处理中特别有用。戈登·普洛特金和埃胡德·夏皮罗在逻辑环境中为归纳机器学习奠定了最初的理论基础。夏皮罗于 1981 年构建了他们的第一个实现（模型推理系统）：一个 Prolog 程序，它从正例和负例中归纳推断逻辑程序。这里的术语 *归纳* 指的是哲学归纳，即提出一种理论来解释观察到的事实，而不是数学归纳，即证明一个属性对良序集合的所有成员都成立。

## 模型

执行机器学习可以涉及创建一个模型，该模型在一些训练数据上进行训练，然后可以处理其他数据以进行预测。各种类型的模型已被用于机器学习系统并进行研究。

## 人工神经网络

人工神经网络（ANN），或连接主义系统，是受动物大脑组成的生物神经网络模糊启发的计算系统。此类系统通过考虑示例来“学习”执行任务，通常无需针对特定任务进行编程。

ANN 是基于称为“人工神经元”的连接单元或节点集合的模型，这些单元大致模拟生物大脑中的神经元。每个连接（如生物大脑中的突触）都可以将信息（即“信号”）从一个人工神经元传输到另一个人工神经元。接收信号的人工神经元可以对其进行处理，然后向连接到它的其他人工神经元发送信号。在常见的 ANN 实现中，人工神经元之间连接处的信号是实数，每个人工神经元的输出由其输入之和的某个非线性函数计算得出。人工神经元之间的连接称为“边缘”。人工神经元和边缘通常具有随着学习进展而调整的权重。权重增加或减少连接处信号的强度。人工神经元可能具有一个阈值，只有当总信号超过该阈值时才会发送信号。通常，人工神经元被聚集到层中。不同的层可能对其输入执行不同类型的变换。信号从第一层（输入层）传输到最后一层（输出层），可能在途中多次遍历这些层。

ANN 方法的原始目标是以人脑的同样方式解决问题。然而，随着时间的推移，注意力转向执行特定任务，导致与生物学的偏差。人工神经网络已应用于各种任务，包括计算机视觉、语音识别、机器翻译、社交网络过滤、玩棋盘和视频游戏以及医疗诊断。

深度学习包含人工神经网络中的多个隐藏层。这种方法试图模拟人脑将光和声音处理为视觉和听觉的方式。深度学习的一些成功应用是计算机视觉和语音识别。

## 决策树

决策树学习使用决策树作为预测模型，从关于项目的观察（在分支中表示）得出关于项目目标值的结论（在叶子中表示）。它是统计学、数据挖掘和机器学习中使用的预测建模方法之一。目标变量可以取离散值集合的树模型称为分类树；在这些树结构中，叶子代表类别标签，分支代表导致这些类别标签的特征组合。目标变量可以取连续值（通常是实数）的决策树称为回归树。在决策分析中，决策树可以用于直观且明确地表示决策和决策过程。在数据挖掘中，决策树描述数据，但生成的分类树可以作为决策制定的输入。
