

## 逻辑回归

它是一种可用于回归任务和分类任务的算法，但广泛用于分类任务。响应变量是二进制的，属于其中一个类别。它用于在因变量的帮助下预测分类变量。

假设有两个类别，需要检查新的数据点属于哪个类别。然后算法计算范围在 0 到 1 之间的概率值。

例如，今天是否会下雨。在逻辑回归中，输入的加权和通过 sigmoid 激活函数传递，得到的曲线称为 sigmoid 曲线。

![](img/c4a53cbbd40023d194b7887dddf3293b_97_0.png)

逻辑函数即 sigmoid 函数是一种“S”形曲线，它接受任何实数值并将其转换为 0 到 1 之间。如果 sigmoid 函数的输出大于 0.5，则输出被分类为 1；如果小于 0.5，则输出被分类为 0。如果图像趋向负端，则预测的 y 将为 0，反之亦然。

如果得到的 sigmoid 输出为 0.75，则说明该事件发生的概率有 75%，比如抛硬币。

![](img/c4a53cbbd40023d194b7887dddf3293b_97_1.png)

上图展示了基于一个或多个自变量（可为连续型或分类型）的输入，以及二元因变量在两个类别之间结果的概率。就像我们借助 sklearn 实现线性回归的方式一样，现在我们将实现逻辑回归。

## 3.3 支持向量机（SVM）与核方法

核方法是机器学习中用于分析数据的数学技术。该方法使用核函数，将数据从一个空间映射到另一个空间。

它通常用于支持向量机（SVM）中，算法通过寻找分离不同类别数据点的超平面来对数据进行分类。

核方法最重要的优点是它可以处理非线性可分数据，并且根据数据类型可使用多种核函数。由于线性分类器只能解决非常有限的一类问题，因此采用核技巧来增强线性分类器，使 SVM 能够解决更广泛的一类问题。

支持向量机是一种监督学习算法，主要用于分类，但也可用于回归。其主要思想是基于标记数据（训练数据），算法试图找到可用于分类新数据点的最优超平面。在二维空间中，超平面是一条简单的直线。

通常，学习算法试图学习类别的最常见特征（即区分一个类别与另一个类别的特征），分类基于所学习的这些代表性特征（因此分类基于类别之间的差异）。SVM 的工作方式则正好相反。它寻找类别之间最相似的样本。这些样本将成为支持向量。

支持向量机（SVM）是一种监督机器学习算法，可用于分类和回归问题。它广泛用于分类问题。SVM 在高维或无限维空间中构建一条直线或一个超平面，用于分类、回归或异常值检测等其他任务。SVM 确保数据以最宽边距分开。

![](img/c4a53cbbd40023d194b7887dddf3293b_101_0.png)

SVM 最大化分离超平面周围的边距。

![](img/c4a53cbbd40023d194b7887dddf3293b_101_1.png)

![](img/c4a53cbbd40023d194b7887dddf3293b_101_2.png)

**支持向量：** 支持向量是位于决策面（或超平面）最远处的数据点。它们是最难分类的数据点。它们对决策面的最优位置有直接影响。

线性与非线性：在平面上，线性函数是图像为直线的函数。直线可以向任何方向延伸，但始终是直线。然而，非线性函数的形状不是直线。

![](img/c4a53cbbd40023d194b7887dddf3293b_102_0.png)

![](img/c4a53cbbd40023d194b7887dddf3293b_102_1.png)

维度：简单来说，事物的一个维度是其某个特定方面。例如：宽度、深度和高度是维度。平面上的一条直线是一维，考虑其边缘，正方形有两个维度，立方体有三个维度。

![](img/c4a53cbbd40023d194b7887dddf3293b_102_2.png)

![](img/c4a53cbbd40023d194b7887dddf3293b_102_3.png)

平面与超平面：在一维空间中，超平面称为点。在二维空间中，它是直线。在三维空间中，它是平面，在更高维空间中，我们称其为超平面。

![](img/c4a53cbbd40023d194b7887dddf3293b_103_0.png)

核：核是将二维平面放入更高维空间的方法，使其在更高维空间中呈曲线。（简单来说，核是一个从低维空间到高维空间的函数。）
