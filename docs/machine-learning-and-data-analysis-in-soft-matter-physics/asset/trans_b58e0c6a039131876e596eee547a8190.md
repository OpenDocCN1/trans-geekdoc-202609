### 回归分析

回归分析包含大量用于估计输入变量及其相关特征之间关系的统计方法。其最常见的形式是线性回归，即根据普通最小二乘等数学准则绘制一条最佳拟合给定数据的直线。后者通常通过正则化方法扩展，以减轻过拟合和偏差，例如岭回归。在处理非线性问题时，常用模型包括多项式回归（例如，用于 Microsoft Excel 中的趋势线拟合）、逻辑回归（常用于统计分类）甚至核回归，它利用核技巧隐式地将输入变量映射到高维空间，从而引入非线性。

### 贝叶斯网络

贝叶斯网络、信念网络或有向无环图模型是一种概率图模型，它使用有向无环图（DAG）表示一组随机变量及其条件独立性。例如，贝叶斯网络可以表示疾病与症状之间的概率关系。给定症状后，网络可用于计算各种疾病存在的概率。存在可执行推理和学习的高效算法。用于建模变量序列（如语音信号或蛋白质序列）的贝叶斯网络称为动态贝叶斯网络。可在不确定性下表示和求解决策问题的贝叶斯网络推广称为影响图。

### 高斯过程

高斯过程是一种随机过程，其中过程中的每一组有限随机变量都服从多变量正态分布，并且它依赖于一个预定义的协方差函数（或核），该函数根据点的位置建模点对之间的相关性。

给定一组观测点或输入输出示例，新点的（未观测）输出作为其输入数据的函数的分布，可以通过查看观测点以及这些点与新未观测点之间的协方差来直接计算。高斯过程是贝叶斯优化中用于超参数优化的常用代理模型。

### 遗传算法

遗传算法（GA）是一种搜索算法和启发式技术，模拟自然选择过程，使用变异和交叉等方法生成新的基因型，希望为给定问题找到良好解。在机器学习中，遗传算法在 1980 年代和 1990 年代被使用。相反，机器学习技术已被用于提高遗传和进化算法的性能。

### 训练模型

通常，机器学习模型需要大量可靠数据才能进行准确预测。在训练机器学习模型时，机器学习工程师需要有针对性地收集大量且具有代表性的数据样本。训练集数据可以包括文本库、图像集合、传感器数据以及服务单个用户收集的数据。在训练机器学习模型时，需要警惕过拟合。源自有偏或未经评估数据的训练模型可能导致偏差或不希望的预测。有偏模型可能导致有害结果，从而进一步加剧对社会或目标的负面影响。算法偏差是数据未充分为训练做准备的潜在结果。机器学习伦理正在成为一门研究领域，并显著融入机器学习工程团队。

### 联邦学习

联邦学习是一种用于训练机器学习模型的分布式人工智能改良形式，它去中心化了训练过程，使用户无需将数据发送到中央服务器即可保持隐私。这还通过将训练过程分散到许多设备来提高效率。例如，Gboard 使用联邦机器学习在用户的手机上训练搜索查询预测模型，而无需将单个搜索发送回 Google。

## 1.3 机器学习在理解复杂软物质系统中的应用

- **预测建模：** 可使用机器学习算法来预测软物质系统的行为和特性。例如，可以构建预测模型来估计复杂软材料的相变、流变特性或自组装行为，这些行为在解析上难以描述。
- **结构预测：** 机器学习可以帮助预测软物质系统的结构和构型。在直接观察或实验测定结构具有挑战性或耗时的情况下，这尤其有用。
