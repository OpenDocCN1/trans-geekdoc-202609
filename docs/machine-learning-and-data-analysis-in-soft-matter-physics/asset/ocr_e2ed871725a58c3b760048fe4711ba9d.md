Q(S, a) = R(s, a) + \mathcal{G} \sum_{s'} (P(s, a, s') \max Q(s', a'))

The above formula is used to estimate the Q-values in Q-Learning.

# 'Q' in Q-learning?

The Q stands for quality in Q-learning, which means it specifies the quality of an action taken by the agent.

Q-table:

A Q-table or matrix is created while performing the Q-learning. The table follows the state and action pair, i.e., [s, a], and initializes the values to zero. After each action, the table is updated, and the q-values are stored within the table.

The RL agent uses this Q-table as a reference table to select the best action based on the q-values.

# 7.4 REINFORCEMENT LEARNING TECHNIQUES FOR OPTIMIZING SOFT MATTER PROCESSES AND MATERIALS DESIGN

An alternative branch of ML, which does not rely on generating a training dataset ahead of time, is reinforcement learning (RL). Within the RL paradigm, the goal is to train an agent to learn to complete a particular task or set of tasks within an interactive environment by giving the agent feedback (reward) on its performance . The agent is essentially learning how to solve the optimal control problem for a given task. In recent years, RL has shown groundbreaking achievements in the fields of game-play , protein folding , and robotic control , among others.

RL agents in the engineering design process may help solve several complex optimization challenges. Traditional design automation methods, such as TO, require a formal mathematical representation of the objectives and constraints, which can be difficult to formulate for many processes. Furthermore, if the objective and constraint functions can be developed, they should be continuous and smooth to improve convergence capabilities. An optimizer that can use a black-box simulation would be helpful. While heuristic optimization tools can solve some of these challenges and operate with black-box simulation tools, RL agents have shown superior performance over heuristic approaches in many domains.
