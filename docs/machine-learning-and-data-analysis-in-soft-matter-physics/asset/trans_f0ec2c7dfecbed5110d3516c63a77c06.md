

## 1.1.1 什么是机器学习？

机器学习是设计能够从数据中自主学习并无需人工纠正即可适应的算法的科学。当我们向这些算法输入数据时，它们会构建自己的逻辑，进而创建出与我们世界中方方面面（如欺诈检测、网页搜索、肿瘤分类和价格预测）相关的解决方案。

在深度学习（机器学习的一个子集）中，程序通过由简单概念构建复杂概念来发现精妙的概念。这些算法通过将多层（因此称为“深度”）神经网络暴露于海量数据来工作。机器学习应用（例如自然语言处理）通过使用深度学习，性能得到了显著提升。

## 1.1.2 什么是数据分析？

数据分析涉及操作、转换和可视化数据，以便从结果中推断出有意义的洞察。个人、企业甚至政府通常都会根据这些洞察来制定方向。

数据分析师可能会使用基本线性回归来预测客户行为、股价或保险索赔。他们可能会使用分类和回归树（CART）创建同质聚类，或者通过使用图表可视化金融科技公司的投资组合来获得一些有影响力的洞察。

直到20世纪末，在数据中发现模式方面，人类分析师仍然是不可替代的。今天，在向学习算法输入正确类型的数据并从算法输出中推断意义方面，他们仍然必不可少，但机器可以并且确实承担了大部分分析工作。

数据分析是使用各种统计和逻辑方法及技术来收集、建模和分析数据的过程。企业依赖分析流程和工具来提取支持战略和运营决策的洞察。

深入了解定量研究中的不同技术和方法以及定性洞察，将使您的分析工作有更清晰明确的方向，因此值得花时间让这些特定知识深入脑海。此外，您将能够创建一份全面的分析报告，这将使您的分析水平直线提升。

除了定性和定量类别外，在划分为复杂的数据分析流程之前，您还应该了解其他一些类型的数据。这些类别包括：

- **Big data：** 指的是需要使用高级软件进行分析以揭示模式和趋势的大规模数据集。它被认为是最佳分析资产之一，因为它以更快的速度提供更大的数据量。
- **Metadata：** 简单来说，元数据是提供其他数据洞察的数据。它总结了特定数据的关键信息，使其更容易查找并用于后续目的。
- **Real time data：** 顾名思义，实时数据在获取后立即呈现。从组织角度来看，这是最有价值的数据，因为它可以帮助您根据最新动态做出重要决策。我们关于实时分析的指南将为您介绍更多相关内容。
- **Machine data：** 这是更复杂的数据，完全由机器（如手机、计算机，甚至网站和嵌入式系统）生成，无需先前的人机交互。

### 数据分析类型

如今，有大约半打流行的数据分析类型，通常在技术和商业领域使用。它们包括：

- **Descriptive Analysis：** 描述性分析涉及汇总和描述数据集的主要特征。它侧重于以有意义的方式组织和呈现数据，通常使用均值、中位数、众数和标准差等度量。它提供数据的概览，并帮助识别模式或趋势。
- **Inferential Analysis：** 推断性分析旨在基于样本数据对更大总体进行推断或预测。它涉及应用假设检验、置信区间和回归分析等统计技术。它有助于将样本结果推广到更大的总体。
- Exploratory Data Analysis (EDA)：探索性数据分析侧重于在没有先入为主的假设的情况下探索和理解数据。它涉及可视化、汇总统计和数据剖析技术，以发现模式、关系和有趣的特征。它有助于为进一步分析生成假设。
- Diagnostic Analysis：诊断性分析旨在理解数据中的因果关系。它调查导致特定结果或行为的因素或变量。回归分析、方差分析（ANOVA）或相关性分析等技术在诊断性分析中常被使用。
- Predictive Analysis：预测性分析涉及使用历史数据来对未来结果进行预测或预报。它利用统计建模技术、机器学习算法和时间序列分析来识别模式并构建预测模型。它通常用于预测销售、预测客户行为或估计风险。
- Prescriptive Analysis：规范性分析在预测性分析的基础上，根据预测结果推荐行动或决策。它结合历史数据、优化算法和业务规则，提供可操作的洞察并优化结果。它有助于决策和资源分配。

## 1.1.3 机器学习在数据分析中为何有用

机器学习构成了数据分析的模型构建自动化。当我们将分类、聚类和异常检测等数据分析核心任务分配给机器时，我们正在使用机器学习。

我们可以设计自我改进的学习算法，以数据作为输入并提供统计推断。无需依赖硬编码编程，算法在检测到模式变化时即可做出决策。

在研究具体的数据分析问题之前，让我们先讨论一下用于对不同类型机器学习算法进行分类的术语。首先，我们可以将大多数算法视为基于分类（机器将数据分为不同类别）或基于回归（机器预测数值）。

监督算法在用足够数据进行训练后提供目标值。相比之下，指导无监督机器学习算法的信息不需要输出变量来指导学习过程。例如，监督算法可能会在回顾类似房屋的价格（输出变量）后估算房屋价值，而无监督算法可能会寻找待售房屋中的隐藏模式。尽管这些机器学习模型很受欢迎，但我们仍然需要人类来推导数据分析的最终含义。理解结果或决定（例如）如何清理数据仍然取决于我们人类。

## 1.1.4 数据分析中的机器学习算法

现在让我们来看看数据分析中使用的六种知名机器学习算法。除了回顾其结构外，我们还将介绍一些实际应用。

### 聚类

在当地的旧货出售会上，您购买了70件单色衬衫，每件颜色都不同。为了避免决策疲劳，您设计了一个算法来帮助您对衣柜进行颜色编码。该算法以每件衬衫的照片作为输入，通过比较每件衬衫与其他衬衫的颜色，创建涵盖每件衬衫的类别。我们称之为 *聚类*：一种无监督学习算法，它寻找输入值之间的模式并相应地将它们分组。

### 决策树学习

您可以将 *决策树* 视为一棵倒置的树：您从“顶部”开始，在不断缩小的选项范围中移动。这些学习算法采用单个数据集，并通过创建规则来区分观察到的特征，逐步将其划分为更小的组。最终，它们会创建出足够小的集合，以便用特定标签来描述。例如，它们可能会采用一般汽车数据集（根节点），并将其分类为品牌，然后分类为具体型号（叶子节点）。
