### Action Space

The action space defines all the possible actions the agent can take at each time step. Actions define how an agent can interact with an environment, taking the agent from its current observation to the next. Within the TO environment, an action corresponds to toggling an element from material to void, leading to a new topology. For an NxN topology environment, the action space size is N². The action of toggling an element from material to void can be represented as changing an element’s modulus of elasticity from 1 to 10⁻⁴.

Figure 7: Element removal sequence of 6 × 6 topology.

Designing topologies (Fig. 7) is accomplished by sequentially selecting elements for removal from a starting solid block topology until a termination criterion is reached or the agent attempts an illegal action. The illegal actions, illustrated in Fig. 8, include removing a bounded, loaded, or previously voided element, or trying to remove an element that would lead to a non-singular body. A non-singular body arises when the topology is held together by a hinge point. This single-node connection at a hinge point artificially inflates the stiffness of the topology and does not represent a feasible part of the design solution.

### Reward

Formulating the reward function of an MDP can be difficult and is the subject of considerable research. The reward function controls the feedback given to an agent after taking an action. Therefore, the RL agent seeks to maximize its reward and should learn what action sequences need to be taken to accumulate the most reward while avoiding penalties. In the presented environment, the reward function should be built to minimize structural compliance under certain volume constraints.

Minimizing the compliance is accomplished by minimizing the increase in strain energy of the current topology compared to the starting solid block topology. Strain energy is a standard measurement in traditional TO methods to assess compliance. The strain energy of a topology increases as more elements are removed, so the agent should receive more reward if it removes elements that lead to a minimal increase. The quadratic mathematical function used to represent this proposed reward function, \( r_t \), at a time step, \( t \), is shown in Eq. (8):

\( r_t = \left( \frac{c_s}{c_t} \right)^2 + \left( \frac{\alpha_t}{N^2} \right)^2 \) (8)

where \( c_s \) is the initial strain energy of the solid block topology, \( c_t \) is the strain energy of the current topology at the time step, \( t \), and \( \alpha_t \) is the number of voided elements at timestep \( t \).

Eq. (8) shows that the agent is assigned more reward if the topology exhibits minimal increases in strain energy while reducing volume fraction. The quadratic representation of the function was selected through experimentation to help magnify the optimal rewards during the later stages of the design process.

While other reward function alternatives are possible, the effectiveness of the function in Eq. (8) is demonstrated in the following sections. A graphical representation of Eq. (8) can be found in Fig. 9.

The reward function of Eq. (8) was only used if the agent takes an action that is deemed "legal." If one of the illegal actions in Fig. 8 is taken, the agent is penalized -1.

This penalty teaches the agent to avoid taking illegal steps as it diminishes the accumulated reward of a designing episode. A magnified salatory reward algorithm was utilized to account for the threat of reward saltation brought on by combining positive and negative rewards. The reader is directed to for a detailed description of this algorithm.

### Transition Probability Function

Given the state, $s_t$, at the current time step, the agent needs to select the action, $a_t$, within the action space, that will lead to the largest value, $Q(s_t, a_t)$, where $Q(s_t, a_t)$, is defined as the total expected future reward if $a_t$ is chosen. The transition probability function, also called the value function, maps state-action tuples, $(s_t, a_t)$, to values for each action. If $Q(s_t, a_t)$, is known for all actions at a given state, then selecting the argmax($a_t$) is the best action. However, even for a simple representation of the TO environment with 6x6 topologies, the number of possible states for a single load case is large (≈6.87×10^10) which makes the value function challenging to model. Therefore, $Q(s_t, a_t)$ is approximated using a deep neural network (DNN). The value function is found using the Double Q-learning algorithm, as shown in Eq. (9):

```
$Q(s_t, a_t) = r(s_t, a_t) + \gamma max_a Q(s_{t+1}, argmax Q(s_{t+1}, a_t))$
(9)
```

where $r(s_t, a_t)$ is the reward for taking the action, $a_t$ at the current state, $s_t$ and $\gamma$ is the future reward discount factor. Double Q learning uses two DNN models, a main and an auxiliary model. The main model selects the action to take by predicting the action with the largest value, $Q(s_t, a_t)$. The auxiliary model predicts the value of the next state if that maximum value action was taken, $max_a Q'(s_{t+1}, argmax Q(s_{t+1}, a_t))$. The auxiliary model helps to address the overestimation of future value, which is commonly seen in the generic Q learning algorithm. This change in Double Q learning has been shown to improve algorithm stability.

The main and auxiliary models consist of four convolutional neural networks (CNN) layers, each with a varying number of 3x3 convolutional filters. The results for each layer are passed through a ReLU activation function before proceeding to the subsequent layer. The CNN architecture shows that the agent's NxNx3 observation of the current state is passed through four convolutional layers comprising 16, 8, 4, and 1 convolutional filters to produce an output of the predicted value of taking each action. The action associated with the highest value is selected, and the element corresponding to that action is removed, resulting in a new topology and corresponding next observation.

### 7.4.2 Training the Agent

Earlier section defined the TO problem as an MDP, and therefore, the RL agent should be able to learn to design optimized topologies. The agent's performance is dependent on its ability to approximate the value function in Eq. (9). The agent needs to undergo episodic interactions with the proposed environment to collect experiences and update its DNN weights for better value approximations. The DNN weights are updated to minimize the error between the agent's prediction of Q(s_t, a_t) and the actual value, which is realized after the agent has taken a_t. An episode in this environment is defined as a sequence of element removal actions starting at the initial solid block topology and continuing until one of the illegal moves of Fig. 8 is made. In this section, 'training' means the agent's episodic interactions with the environment to collect experiences to improve value predictions. During training, so long as the agent does not attempt to remove a bounded, loaded, or voided element, the agent can continue to take actions to remove elements from the topology until a non-singular body is ultimately produced.
