## 监督学习方法

### 简介

监督学习是机器学习的一种类型，其中机器使用带有良好“标签”的训练数据进行训练，并基于这些数据预测输出。标记数据意味着某些输入数据已经贴上了正确输出的标签。

在监督学习中，提供给机器的训练数据充当监督者，教导机器正确预测输出。它采用了与学生在教师监督下学习相同的概念。

监督学习是向机器学习模型提供输入数据和正确输出数据的过程。监督学习算法的目标是寻找一个映射函数，将输入变量(x)映射到输出变量(y)。

在现实世界中，监督学习可用于风险评估、图像分类、欺诈检测、垃圾邮件过滤等。

### 3.1 监督学习定义

监督学习是一种机器学习范式，用于基于给定成对输入输出训练样本集获取系统的输入输出关系信息。由于输出被视为输入数据的标签或监督，输入输出训练样本也称为标记训练数据或监督数据。偶尔，它也被称为有教师学习（Haykin 1998）、从标记数据学习或归纳机器学习。监督学习的目标是构建一个人工系统，该系统可以学习输入与输出之间的映射，并在给出新输入时预测系统的输出。如果输出采用表示输入类标签的有限离散值集，则学习到的映射会导致输入数据的分类。如果输出采用连续值，则会导致输入的回归。输入输出关系信息通常用学习模型参数表示。当这些参数无法直接从训练样本中获得时，学习系统需要经历一个估计过程来获取这些参数。与无监督学习不同，监督学习的训练数据需要监督或标记信息，而无监督学习的训练数据是无监督的，因为它们未被标记（即，仅包含输入）。如果算法同时使用监督和无监督训练数据，则称为半监督学习算法。如果算法在训练过程中主动向用户/教师查询标签，则这种迭代监督学习称为主动学习。

### 图 1. 说明监督学习形式的框图

图 1 显示了一个说明监督学习形式的框图。在此图中，(xi, yi) 是一个监督训练样本，其中‘x’表示系统输入，‘y’表示系统输出（即输入 x 的监督或标记），‘i’是训练样本的索引。在监督学习过程中，训练输入 xi 被馈送到学习系统，学习系统生成输出 Ŷi。然后，学习系统输出 Ŷi 由一个仲裁者与基准标记 yi 进行比较，仲裁者计算它们之间的差异。该差异（在此图中称为误差信号）随后被发送到学习系统以调整学习者的参数。此学习过程的目标是获得一组最优学习系统参数，以最小化所有 i 之间 \(\tilde{\mathbf{Y}}_i\) 和 \(y_i\) 的差异，即最小化整个训练数据集上的总误差。

一个值得注意的现象是，最小训练误差不一定意味着测试性能良好。训练是指基于所见基准监督数据估计学习者参数的学习过程，而测试是评估学习者对未见数据（即未包含在训练过程中的数据）的预测。因此，即使学习者在训练数据集上实现了最小误差，也不保证能在未见数据上表现良好。这主要是由于可能对训练数据过拟合，即学习者在学习映射时具有不必要的复杂度。

此问题称为泛化性能。一个好的学习算法必须具有良好的泛化性能。为了在设计学习者时考虑泛化性能，学习算法需要平衡最小化训练误差的目标和学习者的复杂度（例如，学习者的结构和阶数）。例如，在支持向量机中，学习者的泛化性能由学习到的判别边界的间隔来表征。间隔越大，泛化性能越好。支持向量机在训练集上学习最大间隔分类器，因此自然会带来良好的泛化性能。

监督学习范式不限制输入或输出数据的来源。输入或输出可能属于向量空间或一组离散值。学习范式对仲裁者也没有特殊限制。如果 \(y_i\) 来自连续空间，误差信号通常通过 \(y_i - \tilde{\mathbf{Y}}_i\) 计算。如果 \(y_i\) 属于一组离散值，仲裁者通常根据 \(y_i\) 和 \(\tilde{\mathbf{Y}}_i\) 之间的相等性输出误差信号。例如，当 \(y_i\) 和 \(\tilde{\mathbf{Y}}_i\) 相等时，仲裁者可能输出 0，当它们不同时输出 1。

在监督学习中，学习系统的设计有不同的方法。一些著名的方法包括基于逻辑的方法、多层感知机方法、统计学习方法、基于实例的学习方法、支持向量机和提升方法。
