
估计的其他可能方法包括极大似然估计。有两种不同的极大似然变体可用：在一种（大致等同于前向预测最小二乘方案）中，考虑的似然函数是对应于在系列中给定初始p个值的情况下，系列中较后值的条件分布；在第二种中，考虑的似然函数是对应于观测系列中所有值的无条件联合分布。如果观测系列较短，或者过程接近非平稳性，这些方法的结果可能会出现显著差异。

## 6.4 循环神经网络（RNN）

循环神经网络（RNN）是一种非常适合时间序列数据的神经网络类型。RNNs按步骤处理时间序列，从一个时间步到下一个时间步维护内部状态。

循环神经网络（RNN）是一类人工神经网络，节点之间的连接可以形成循环，允许某些节点的输出影响同一节点的后续输入。这使其能够表现出时间动态行为。派生自前馈神经网络，RNNs可以利用其内部状态（记忆）来处理可变长度的输入序列。这使其适用于未分割连续手写识别或语音识别等任务。循环神经网络在理论上是图灵完备的，可以运行任意程序来处理任意输入序列。术语“循环神经网络”用于指代具有无限冲激响应的网络类别，而“卷积神经网络”则指代具有有限冲激响应的网络类别。这两类网络都表现出时间动态行为。有限冲激循环网络是一个有向无环图，可以展开并替换为严格的前馈神经网络，而无限冲激循环网络是一个有向环图，无法展开。

有限冲激和无限冲激循环网络都可以具有额外的存储状态，存储可以直接由神经网络控制。如果存储包含时间延迟或具有反馈回路，也可以用另一个网络或图替换。这种受控状态被称为门控状态或门控记忆，是长短期记忆网络（LSTMs）和门控循环单元的一部分。这也称为反馈神经网络（FNN）。

### 6.4.1 历史

由威廉·伦兹和恩斯特·伊辛提出的Ising模型是第一个不学习的RNN架构。Shun'ichi Amari在1972年使其具有自适应性。这也被称为霍普菲尔德网络。另请参见大卫·鲁梅尔哈特在1986年的工作。1993年，一个神经历史压缩系统解决了一个“非常深度学习”任务，该任务需要在RNN随时间展开时具有超过1000个后续层。

### LSTM

长短期记忆（LSTM）网络由Hochreiter和Schmidhuber于1997年发明，并在多个应用领域创下了准确率记录。

大约在2007年，LSTM开始彻底改变语音识别，在某些语音应用中优于传统模型。2009年，经过连接主义时序分类（CTC）训练的LSTM网络成为第一个赢得模式识别竞赛的RNN，当时它在连续手写识别中赢得了几项比赛。2014年，中国公司百度使用经过CTC训练的RNNs打破了2009年Switchboard Hub5’00语音识别数据集基准，未使用任何传统语音处理方法。

LSTM还改进了大词汇量语音识别和文本转语音合成，并应用于Google Android。2015年，据报道，Google的语音识别通过经过CTC训练的LSTM实现了49%的显著性能提升。

LSTM在改进机器翻译、语言建模和多语言语言处理方面打破了纪录。LSTM与卷积神经网络（CNNs）相结合，改进了自动图像字幕。

### 6.4.2 架构

RNNs有多种变体。

### 完全循环

完全循环神经网络（FRNN）将所有神经元的输出连接到所有神经元的输入。这是最一般的神经网络拓扑，因为其他所有拓扑都可以通过将某些连接权重设置为零来表示，以模拟这些神经元之间没有连接的情况。右侧的插图可能会让许多人误解，因为实际的神经网络拓扑经常被组织成“层”，而绘制呈现出这种外观。然而，看起来像层的实际上是同一完全循环神经网络在不同时间步。插图中最左侧的项目将循环连接显示为标记为‘v’的弧。它在时间上被“展开”，以产生层的外观。

### Elman网络和Jordan网络

Elman网络是一个三层网络（在插图中水平排列为x、y、z），并添加了一组上下文单元（插图中的u）。中间（隐藏）层与这些上下文单元相连，权重固定为1。在每个时间步，输入被前馈并应用学习规则。固定的反馈连接将隐藏单元的先前值的副本保存在上下文单元中（因为它们在应用学习规则之前通过连接传播）。因此，网络可以维持一种状态，使其能够执行标准多层感知器无法完成的任务，例如序列预测。

Jordan网络与Elman网络类似。上下文单元来自输出层，而不是隐藏层。Jordan网络中的上下文单元也称为状态层。它们具有指向自身的循环连接。

Elman和Jordan网络也称为“简单循环网络”（SRN）。

### Elman网络

```
h_t = σ_h(W_h x_t + U_h h_t-1 + b_h)
y_t = σ_y(W_y h_t + b_y)
```

### Jordan网络

```
h_t = σ_h(W_h x_t + U_h y_t-1 + b_h)
y_t = σ_y(W_y h_t + b_y)
```

### 变量和函数

- x_t: 输入向量
- h_t: 隐藏层向量
- y_t: 输出向量
- W, U 和 b: 参数矩阵和向量
- σ_h 和 σ_y: 激活函数

### 霍普菲尔德

霍普菲尔德网络是一种跨层所有连接大小相等的RNN。它需要平稳输入，因此不是一般RNN，因为它不处理模式序列。然而，它保证会收敛。如果连接使用赫布学习进行训练，则霍普菲尔德网络可以作为强健的内容寻址内存，能够抵抗连接改变。

### 双向联想记忆

由Bart Kosko提出，双向联想记忆（BAM）网络是霍普菲尔德网络的一种变体，它将联想数据存储为向量。双向性来自于通过矩阵及其转置传递信息。通常，优先使用双极编码而不是联想对的二进制编码。最近，使用马可夫步进的随机BAM模型已针对提高网络稳定性和与实际应用的相关性进行了优化。

BAM网络有两个层，其中任意一个层都可以作为输入来调用联想，并在另一层上产生输出。

### 回声状态

回声状态网络（ESN）具有一个稀疏连接的随机隐藏层。输出神经元的权重是网络中唯一可以改变（可训练）的部分。ESN在复现某些时间序列方面表现良好。针对峰值神经元的一个变体被称为液态状态机器。

### 独立RNN（IndRNN）

独立循环神经网络（IndRNN）解决了传统完全连接RNN中的梯度消失和爆炸问题。一层中的每个神经元仅接收其自身的过去状态作为上下文信息（而不是与该层中所有其他神经元完全连接），因此神经元彼此独立于对方的历史。梯度反向传播可以受到调节，以避免梯度消失和爆炸，从而保持长期或短期记忆。跨神经元信息在下一层中进行探索。IndRNN
