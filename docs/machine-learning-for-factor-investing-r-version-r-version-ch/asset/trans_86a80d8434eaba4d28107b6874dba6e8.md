### 宗旨与范围：

金融数学领域构成金融领域不断扩大的一个分支。本丛书旨在捕捉该领域的新发展，并概括该领域全方位的已有知识。丛书将包括面向学术界和从业者的广泛教材、参考著作和手册。强烈鼓励包含数值代码和具体的现实世界示例。
