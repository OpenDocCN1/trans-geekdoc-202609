In terms of machine learning models, this is also true. Below, we estimate a pure characteristic regression with one predictor, the market capitalization averaged over the past 6-months ($r_{t+1,n} = \alpha + \beta x_{t,n}^{cap} + \epsilon_{t+1,n}$). The label is the 6-month forward return and the estimation is performed over every calendar year.

```
data_ml %>%
mutate(year = year(date)) %>%         # Create a year variable
group_by(year) %>%                # Group by year
summarize(beta_cap = lm(R6M_USd ~ Mkt_Cap_6M_USd) %>%  # Perform regression
       coef() %>%                  # Extract coefs
       t() %>%                     # Transpose
       data.frame() %>%            # Format into df
       pull(Mkt_Cap_6M_USd)) %>%   # Pull coef (remove intercept)
ggplot(aes(x = year, y = beta_cap)) + geom_col() +   # Plot
theme_grey()
```
