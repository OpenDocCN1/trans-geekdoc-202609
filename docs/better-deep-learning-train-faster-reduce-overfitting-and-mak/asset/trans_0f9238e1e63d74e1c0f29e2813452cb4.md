
- l2: 活动计算为平方值之和。
- l1_l2: 活动计算为绝对值之和与平方值之和。

l1 和 l2 正则化器各取一个超参数来控制每个活动对总和的贡献量。l1_l2 正则化器取两个超参数，分别对应 l1 和 l2 方法。正则化器类必须先导入然后实例化；例如：

```
# import regularizer
from keras.regularizers import l1
# instantiate regularizer
reg = l1(0.001)
```

## 14.2.2 层上的活动正则化

在 Keras 中，活动正则化是在层上指定的。这可以通过将层的 activity_regularizer 参数设置为已实例化并配置好的正则化器类来实现。正则化器应用于层的输出，但你可以控制层的输出实际含义。具体来说，你可以灵活选择正则化是在激活函数之前还是之后应用。例如，你可以在层上指定函数和正则化，在这种情况下，激活正则化应用于激活函数的输出，在本例中为 relu。

```
...
model.add(Dense(32, activation='relu', activity_regularizer=l1(0.001)))
...
```

另外，你可以指定线性激活函数（默认值，不执行任何转换），这意味着激活正则化应用于原始输出，然后可以将激活函数添加为后续层。

```
...
model.add(Dense(32, activation='linear', activity_regularizer=l1(0.001)))
model.add(Activation('relu'))
...
```

## 14.3 活动正则化案例研究

在本节中，我们将演示如何使用活动正则化来减少 MLP 在简单二元分类问题上的过拟合。虽然活动正则化最常用于在自编码器和编码器-解码器模型中鼓励稀疏学习表示，但它也可以直接用于普通神经网络中以实现相同的效果并提高模型的泛化能力。此示例为将活动正则化应用于你自己的分类和回归问题的神经网络提供了一个模板。

我们将使用一个标准的二元分类问题，该问题定义了两个二维同心圆观测，一个圆对应每个类别。每个观测有两个尺度相同的输入变量和一个类别输出值，为 0 或 1。该数据集被称为圆圈数据集，因为在绘制时每个类别的观测形状为圆。我们可以使用 make_circles() 函数从该问题生成观测。我们将向数据添加噪声并设置随机数生成器的种子，以便每次运行代码时生成相同的样本。

```python

X, y = make_circles(n_samples=100, noise=0.1, random_state=1)
```

## 14.3.2 过拟合多层感知机

我们可以开发一个 MLP 模型来解决这个二元分类问题。模型将有一个隐藏层，其节点数可能比解决该问题所需的多，提供过拟合的机会。我们还将训练模型的时间比所需更长，以确保模型过拟合。在定义模型之前，我们将把数据集拆分为训练集和测试集，使用 30 个示例来训练模型，70 个示例来评估拟合模型的性能。

