
动量被用作加速学习，特别是在梯度较小、曲率高、且一致或有噪声的情况下。它累积近期梯度的指数衰减移动平均值，并沿其方向移动。如[图 6.9](#ch13.xhtml#f95)所示，考虑一个包含噪声数据的场景。尽管这些点看起来彼此接近，但它们并不共享 `x` 坐标。在这种情况下，应使用对数据去噪的移动平均，使数据点更接近原始函数。例如，当超参数取较小值时，序列会波动，因为平均的样本数较少，且会更接近噪声数据。当超参数取较大值时，曲线会更平滑，但会向右偏移，因为它对大量样本进行平均。因此，应选择介于这两个极端之间的值，以获得超参数的平衡值。

## 6.6.2 基于梯度的优化算法

让我们讨论一下机器学习中使用的一些基于梯度的优化技术。

*   **梯度下降** 通过考虑学习率和当前梯度并遍历搜索空间来优化学习模型。它找出使成本最小化的函数参数值。它一次性处理整个数据集，从而实现快速收敛。然而，一次性处理整个数据集需要更多资源。梯度下降寻找可微函数的局部最小值，如[图 6.10](#ch13.xhtml#f96)所示。当数据点很多时，它需要更多时间在一组迭代中产生最优向量。在简单的机器学习模型（如线性回归模型）中，梯度下降考虑整个数据集并在前向传播期间计算损失。然后在反向传播期间更新权重。此过程需要更多资源和大量计算。

    ![图 6.10 梯度下降的表示。](html/images/9781032473246_C006_010.jpg)

    [图 6.10](#ch13.xhtml#f96b) 梯度下降的表示。

*   **随机梯度下降 (SGD)** 仅使用一部分数据点来识别局部极小值。因此，它通过消耗更少时间解决了梯度下降法的问题。然而，由于它一次只考虑一条记录，并在线性回归模型中进行前向和反向传播，训练变得非常缓慢。因此，收敛需要更多时间。SGD 优化器通过获取学习率与基于梯度的因子的乘积来更新学习率。

*   **小批量梯度下降**：通常，当数据集很大时，一次性训练整个数据集是不可行的，因为它需要更多资源（这反映了 GD 的问题）。此外，一次只加载一个数据点可能也是不可能的，因为这需要时间（这反映了 SGD 的问题）。因此，小批量 SGD 一次考虑一小组随机实例（其中 `k` < 学习率），将通过之字形路径收敛，如[图 6.4](#ch13.xhtml#f90)所示。它收敛需要相当长的时间，但它是大型数据集广泛使用的方法。这通过使用 GPU 等高性能计算机来提升性能。小批量 SGD 对小批量使用前向和反向传播。虽然这需要较少的资源和时间，但它会受到噪声的影响。

*   **带动量的 SGD** 是一种流行的优化算法，用于减少小批量中的噪声并高效训练。动量或带动量的 SGD 加速前向方向的梯度向量，从而实现高效收敛。它使用指数移动平均 (EMA) 来去除噪声并平滑曲线。正如我们上面讨论的，EMA 在不同时间间隔内为最近的数据点分配较高的权重和重要性，并测量一段时间内的趋势方向。这对观测值的数量进行加权并使用其平均值。带动量的 SGD 还能在不使用批量归一化时避免陷入局部最小值。

正如[图 6.11](#ch13.xhtml#f97)所示，看到基于梯度的方法的比较很有趣。批量梯度下降利用整个训练数据集计算每一步的梯度。因此，当训练数据集很大时，此过程会变慢。SGD 为每一步考虑训练集中的任意数据点并生成梯度。由于每次迭代只需在内存中存储一个数据点，因此该过程执行高效。这使得它可以应用于大型数据集。然而，SGD 的随机性不如批量梯度下降法广泛使用。在 SGD 中，成本函数波动，仅平均下降，而不逐渐减少到最小值。虽然它接近极小值，但继续波动而不达到稳定点。波动将防止局部最优点，最终值表现更好，但可能不是最优解。可以使用学习率调度器来解决这个问题，它在接近全局极小值时减小步长。

## 6.6.3 其他优化算法

其他优化算法（如 Adagrad、Adadelta 和 RMSprop）比上述优化器优化得更好。Adam 是一种广泛使用的优化器，它结合了带动量的 SGD 和 RMSprop。

*   **Adagrad (自适应梯度)**

    Adagrad 使用特定于参数的学习率，在模型训练期间，学习率根据参数更新的速率进行调整。该技术背后的思想是为每个隐藏层、每个神经元在不同的迭代或周期使用不同的学习率。此过程将学习率除以当前和先前平方梯度累积和的平方根。与 SGD 一样，梯度不会改变。该技术通过保持逐参数学习率，支持提高稀疏梯度任务的性能。因此，主要计算机视觉和 NLP 任务使用 Adagrad。然而，当迭代次数增加时，它会获得非常小的学习率并减少权重更新。因此，将没有显著值来更新权重。因此它会延迟收敛。此问题可以使用 AdaDelta 和 RMSProp 优化器来解决。

*   **AdaDelta (自适应增量)**

    Adadelta 是 AdaGrad 优化器的扩展，也是一种 SGD 方法。术语 delta 表示两次连续权重更新之间的差异。它使用每维自适应学习率作为解决方案，解决了局限性，即训练期间学习率的持续下降和手动选择全局学习率的要求。AdaDelta 不使用学习率作为参数，而是利用参数变化的频率来调整学习率。此外，该技术将梯度的二阶矩和参数的变化作为变量保留。
