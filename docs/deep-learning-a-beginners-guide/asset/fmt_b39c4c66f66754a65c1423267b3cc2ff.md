
# 正则化技术

L1 正则化使权重更接近零的特性有助于高效学习。然而，由于该技术会丢弃不重要的特征，这可能导致移除特征之间的某些连接，因此模型往往泛化能力较弱。相比之下，L2 通过保留特征间的连接来尝试保留特征。结果是，虽然 L2 泛化能力更强，但它会变成一个稠密网络。考虑到 L1 和 L2 正则化技术的优势，弹性网络方法将两者结合，如[图 6.2](#ch13.xhtml#f88)所示。

*   **早停法**

早停法用于采用迭代方法（如梯度下降）的模型学习中。由于这些技术可能降低模型泛化能力，早停机制规定了在模型过拟合之前训练应执行的最大迭代次数。该方法最初设置许多轮次进行训练，当学习曲线的性能开始下降时，它会停止在验证数据上的训练。模型通过调整参数，试图在训练数据上详尽地遵循损失函数。因此，通过监控验证数据上的损失函数，如果验证集没有改善，则学习停止，而不处理所有轮次。[图 6.3](#ch13.xhtml#f89)展示了早停法的示意图。早停正则化在为提升算法（如 Adaboost）提供一致性方面非常有用。

![Figure 6.3 Early stopping representation.](html/images/9781032473246_C006_003.jpg)

[图 6.3](#ch13.xhtml#f89b) 早停法表示。

*   **Dropout**

Dropout 技术在训练期间的不同节点随机忽略或丢弃一定数量的层输出。随后，这被视为一个拥有多样化节点和与前一层连接的层，支持使用不同架构同时进行模型训练。因此，每当梯度更新时，都会根据超参数生成一个不包含被丢弃节点的新稀疏模型。这种变化可能帮助网络层纠正前几层的错误并产生一个鲁棒模型。Dropout 可能会根据节点对输入的影响导致训练过程变得嘈杂。[图 6.4](#ch13.xhtml#f90)展示了一个 Dropout 网络的实例。

![Figure 6.4 Neural network architecture before and after dropout is performed.](html/images/9781032473246_C006_004.jpg)

[图 6.4](#ch13.xhtml#f90b) 执行 Dropout 前后的神经网络架构。

使用 Dropout 的模型在测试数据上可能具有较低的分类误差，因为它们的表示简洁且泛化能力强。由于 Dropout 技术可以解决过拟合问题，它降低了不同隐藏层节点间的相互依赖性，从而导致较低的误差值。然而，这种技术可能需要更多训练时间。这可以通过使用正则化器来解决，正则化器类似于 Dropout 层。例如，Dropout 可被视为线性回归模型中 L2 正则化的一种扩展。

## 6.3 数据增强

通常，很难获得一个数据量适合机器学习模型训练的完美数据集。虽然许多公共数据集支持目标检测和图像分类，但对于特定应用领域，获取足够的数据来训练模型仍然很困难。使用不足的数据进行训练会导致模型过拟合和欠拟合。由于数据种类有限，模型学习到了目标应用的隐藏特性，从而在测试数据集上准确率较低。

数据增强是一种广泛应用的技术，它通过利用真实且随机的变换来扩展训练数据的多样性。通过对现有数据集进行微小改动，模型将这些机器生成的图像识别为不同的图像，从而增加训练的变异性。这有助于模型识别数据集的特性，并在未见数据上表现良好。

以下策略支持数据增强。

*   **基本数据操作**：这对输入空间中的数据应用几何变换。该类别相关的技术包括：将图像缩放到给定的缩放因子、随机翻转（水平和垂直）、随机旋转、裁剪、剪切、平移（高度平移和宽度平移）、改变亮度、改变对比度、平移变换、图像颜色修改、图像混合以将两幅图像融合为单幅图像。

*   **特征空间扩展**：这对特征空间应用变换。例如，可以使用自编码器获得原始数据单元的潜在表示，并添加噪声以转换原始数据。

*   **生成对抗网络（GAN）增强**：考虑一种自然选择来增加数据，因为它在数据合成方面效果极好。一些广泛使用的技术是 pix2pix 和 cycleGAN。Pix2Pix GAN 是一种条件 GAN（cGAN），它利用真实数据、噪声和标签来创建图像。CycleGAN 通过利用训练好的对齐图像对将源域映射到目标域，解决了图像到图像的转换问题。然而，并不总能获得成对图像。

*   **元学习**：神经网络模型可用于通过超参数调优优化其他模型以扩展其布局。在这里，分类网络可用于增强增强模型（如 GAN）以生成图像。然后，将原始图像和增强图像都发送给另一个模型以比较和评估增强图像。

在大多数情况下，在单次数据增强中结合使用多种技术以生成更好的新图像是合适的。然而，应用不同增强技术时应考虑数据集的类别。例如，在数字识别模型中，对数字 3 的图像应用绕 *y* 轴翻转并不能代表一个有意义的数据实例，如[图 6.5](#ch13.xhtml#f91)所示。

## 6.4 归一化

在深度学习中，应用归一化技术来转换数据，使数据集中的所有特征处于相似的尺度上。通常，我们使用 0 到 1 之间的范围来归一化数据。如果数据未归一化，会导致处于较低尺度上的重要属性有效性被稀释。归一化层支持高效且稳定的模型学习。让我们讨论一些归一化技术，例如批量归一化，用于在没有循环连接的情况下使用大批次进行训练，以及用于小批次训练的技术，如权重归一化、权重标准化、组归一化和层归一化。

*   **批量归一化**

批量归一化标准化给定层的输入。通常，神经网络学习过程试图沿梯度给出的方向减小权重参数，这取决于当前的输入。由于网络层堆叠在一起，前一层的微小权重更新会导致从输入层到其他层的连接发生巨大变化。这会导致当前梯度产生次优输出。由于批量归一化限制了给定层的输入（如来自前一层的激活值），权重可以用更好的梯度进行更新，从而实现稳定高效的训练。
