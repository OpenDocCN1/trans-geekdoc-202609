
# 深度学习的演进与基础

深度学习可被视为机器学习的一种演进。早期，机器学习算法被用于为不同应用开发模型。许多机器学习算法被开发出来用于学习数据并随时间改进，至今仍被用于做出智能决策。深度学习是机器学习的一个子领域，拥有多层神经网络，能够自主学习并做出智能决策。深度学习模型能自行从数据中学习高层特征，而机器学习模型则需要领域专家识别的、人工设计的特征。这些技术的演进如[图 1.2](#ch08.xhtml#f2)所示。尽管深度学习的概念早已被理论化，但最近才在数据科学家中变得流行。主要原因在于近期大数据和高算力 GPU 的出现。随着大量数据的可用性、廉价的数据存储和计算能力，大多数在计算上不可行的算法和模型在技术和概念上都变得可行了。因此，深度学习模型被广泛用于解决涉及图像识别、语音识别和自然语言处理等任务的现实问题。

深度学习被定义为一系列机器学习模型，其特征在于深度性和通用性。这些模型能够学习输入数据元素与相应输出之间复杂的非线性关系。这些模型的实现使用了具有多个隐藏层的人工神经网络；因此被定义为深度神经网络（DNN）。当数据通过这些多个隐藏层转换时，每一层都学习输入数据并将其转换为略微抽象和复合的表示，最终捕捉复杂的关系。请看[图 1.3](#ch08.xhtml#f3)所示的图像识别应用。例如，输入可以是矩阵中的一组像素。第一层可能提取与边缘相关的像素。第二层可能组合这组边缘。第三层可能将边缘排列成不同的形状。第四层可能预测图像。同样，深度学习过程提取可在不同层级学习的特征。在此过程中，需要通过改变层数和层的大小来调整参数，以获得最佳结果。因此，深度学习通过渐进式学习来提取特征并做出最佳预测。

![图 1.3 深度学习模型内的整体过程。](html/images/9781032473246_C001_003.jpg)

[图 1.3](#ch08.xhtml#f3b) 深度学习模型内的整体过程。

总体而言，在 DNN 中，数据从输入层以前馈方向流向输出层。神经网络主要由三种类型的层组成，即输入层、隐藏层和输出层。最初，DNN 在神经元之间建立连接，并为连接分配随机数值权重。在此过程中，权重值与输入相乘，生成 0 到 1 范围内的输出。算法调整权重，直到达到预期的预测准确度。随后，算法使隐藏层中的若干参数更加突出，直到获得处理所有数据的最优方程。

考虑到输入与输出之间的数据转换，机器学习需要适合算法转换为输出的必要数据表示。然而，深度学习模型学习多层转换，而每一层提供一级表示。例如，靠近输入的层包含较少的数据细节，而靠近输出的层具有用于数据区分的概念的高层数据表示。深度学习模型可被视为多层表示学习。这些具有许多层的模型比其他模型更能提取低层感知数据。这不仅比其他浅层模型表现更好，而且通过消除自然语言处理、计算机视觉和语音识别等领域的许多界限，实现了准确且自动化的特征工程过程。

在了解深度学习概念的概览后，识别数据处理阶段以产生洞察和预测、从而在实践中获得结果非常重要。如[图 1.4](#ch08.xhtml#f4)所示，深度学习过程的生命周期主要包括数据获取、预处理、训练、测试、评估、部署和监控。我们了解到模型的整体有效性主要取决于数据。通常，数据可以是私有或公开的，并通过调查或实验收集。有了数据可用性，数据科学家需要通过探索数据的结构、相关性、类型和适用性来理解数据。虽然数据准备是一项耗时的任务，但它在生命周期中起着重要作用，可从现有数据中衍生新特征。在实际模型设计之前，需要进行这种探索性数据分析，以利用不同特征变量之间的数据分布来识别影响因素。因此，在数据流管道中，数据应经过预处理以进行清洗、移除异常值、处理缺失数据、归一化和增强，然后再输入训练模型。考虑到深度学习管道，特征工程技术与数据预处理相协调，以提取和识别数据的信息特征。

训练算法的选择可考虑数据类型、应用性质和资源可用性等不同因素。模型训练和测试过程致力于调整超参数并应用优化以产生更好的结果。这些模型应被设计为能够学习数据并在新数据上也表现良好，通过确保性能与泛化能力之间的平衡。一旦模型通过在未见数据上测试进行评估，建模过程应重复进行，直到达到所需的指标水平。这些概念和技术的详细描述将在本书后续章节中讨论。一旦最终模型部署，应用将被监控以进行进一步改进。在实践中，有多种框架和技术可用于简化深度学习生命周期中的过程。此外，还会利用不同的工具和框架来完成这些过程。

深度学习仍在不断演进，结合大数据处理与人工智能的新思路。因此，你需要更好地理解深度学习技术及其关键概念，以开发创新应用。本书将为你提供基本深度学习技术、神经网络、深度学习模型、深度学习方法类型、架构增强和评估技术的理论背景。
