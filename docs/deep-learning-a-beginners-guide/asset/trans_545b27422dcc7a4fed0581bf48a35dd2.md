

# 梯度消失问题

可以通过模型训练期间的以下观察来识别梯度消失问题。

* 在训练阶段，模型改进缓慢，并且有可能提前停止训练。这意味着进一步的训练不会带来模型性能的提升。
* 靠近输出层的权重获得更多的变化，而靠近输入层的层可能不会发生太大变化。
* 在模型训练期间，权重呈指数级减小并变得非常小。
* 在训练期间，权重变为零。

现在，让我们看看如何解决梯度爆炸问题和梯度消失问题。

1. **减少隐藏层的数量**：此解决方案同时适用于梯度爆炸和梯度消失问题。然而，减少层数会降低模型的复杂度。
2. **梯度裁剪**：此解决方案可应用于梯度爆炸，当梯度超过预期的数值范围时，将梯度大小限制在特定范围内。
3. **权重初始化**：应用谨慎的权重初始化方法可以解决随机初始化中的这两个问题。因此，可以遵循 `He 初始化` 或 `Xavier 初始化`，或根据需要通过调整机制以符合数据来进行修改。

为了进一步解释，请考虑 [图 2.20](#ch09.xhtml#f28) 中所示的 Sigmoid 激活函数及其导数。在这里，某些激活函数将输入空间压缩到 0 和 1 之间的输出区域。因此，当 Sigmoid 函数的值非常高或非常低时，导数输出会变低。这导致梯度消失和模型性能低下。然而，随着层数的增加，梯度变得非常小并有效地执行（注：原文此处表述可能存歧义，直译为“perform effectively”）。

![图 2.20 Sigmoid 函数及其导数的表示。](html/images/9781032473246_C002_020.jpg)

[图 2.20](#ch09.xhtml#f28b) Sigmoid 函数及其导数的表示。

通常，当模型层数较少时，会使用 Sigmoid 激活函数。因此，当层数很多时，不会在每一层都使用 Sigmoid。在这种情况下，会使用不会导致导数变小的激活函数，例如 `ReLU`。作为另一种解决方案，可以使用残差模型，因为它们提供了直接通往早期层的残差连接。克服梯度消失问题最推荐的方法是逐层预训练。

## 3.1 神经网络概述

本章讨论不同的深度学习技术及其设计概念。首先，我们需要了解深度学习算法相对于机器学习的必要性。为此，重要的是要识别神经网络相对于传统机器学习技术的优势，因为神经网络需要更多的计算能力。让我们看看不同类型的神经网络与现实世界应用的交互。在 [第 2 章](#ch09.xhtml#c2) 中，我们讨论了神经网络的组成，它由相互连接的节点层组成，其方式模仿人类神经元。我们了解到神经网络执行数学运算以检测数据中的模式。使用深度学习而非机器学习的主要原因如下。

* **决策边界**：分类算法学习模型以确定给定数据点属于哪个类别。例如，考虑 [图 3.1](#ch10.xhtml#f29) 中所示的逻辑回归。这里使用 Sigmoid 函数通过线性决策边界将数据点分为两类。它不支持学习非线性数据的决策边界。因此，机器学习算法无法学习所有函数。因此，并非所有具有复杂关系的问题都能由机器学习算法解决。因此，深度学习技术应运而生。

    ![图 3.1 线性数据（左）与非线性数据（右）的决策边界。](html/images/9781032473246_C003_001.jpg)

    [图 3.1](#ch10.xhtml#f29b) 线性数据（左）与非线性数据（右）的决策边界。

* **特征工程**：该过程包含特征提取和特征选择。例如，考虑一个图像分类问题。手动特征提取过程需要对主题和图像领域有深入的了解，且消耗更多的时间和精力。然而，深度学习技术如 [图 3.2](#ch10.xhtml#f30) 所示自动化了特征工程过程。

    ![图 3.2 机器学习与深度学习流程的对比。](html/images/9781032473246_C003_002.jpg)

    [图 3.2](#ch10.xhtml#f30b) 机器学习与深度学习流程的对比。

主要的深度学习模型类型如下：

* **人工神经网络 (ANN)**：用于解决回归和分类任务。
* **卷积神经网络 (CNN)**：用于图像和视频数据的分类。主要用于目标识别、目标检测和目标分类。与 `ANN` 相比，`CNN` 具有用于卷积和最大池化的额外层。
* **循环神经网络 (RNN)**：数据向任意方向流动，用于目标检测和语言建模等应用。长短期记忆对此用途有效，涉及嵌入层和独热实现。

## 3.2 人工神经网络

人工神经网络 (`ANN`) 旨在模拟人脑。它由输入空间、隐藏层和输出层以及连接的节点组成，以模拟人脑。在一个节点中，加权输入被求和，并应用激活函数以获得结果，如 [图 3.3](#ch10.xhtml#f31) 所示。输入层从输入空间获取输入并传递给隐藏层进行处理，每一层学习特定的权重，输出层给出结果。这是一个前馈网络，数据通过输入、隐藏和输出节点移动，网络中没有任何循环。这些主要用于表格数据、图像数据和文本数据的回归和分类。

![图 3.3 ANN 示例。](html/images/9781032473246_C003_003.jpg)

[图 3.3](#ch10.xhtml#f31b) ANN 示例。
