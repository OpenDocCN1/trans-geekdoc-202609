

# 均方根误差 (RMSE)

均方根误差 (RMSE) 计算公式 (7.17) 中均方误差的平方根。该项量化了模型预测值与实际值之间的差异，也称为均方根偏差。虽然 MAE 赋予所有误差相同的权重，但 RMSE 通过赋予绝对值较大的误比绝对值较小的误差更大的权重来惩罚不确定性。由于所有指标均被评估，RMSE 永远不会小于 MAE。

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum\limits_{i = 1}^{n}\left( {y - \hat{y}} \right)^{2}} \tag{7.17}$$

其中 `n`、`y` 和 `ŷ` 分别表示数据点总数、实际输出和预测输出。

## 对数损失

对数损失表示预测概率与实际/对应真实值的接近程度。最大化似然等价于最小化 MSE。它通过惩罚错误预测来考虑模型预测中的不确定性。这在多分类任务中表现良好，且数值越低性能越好，如 [图 7.7](#ch14.xhtml#f109) 所示。此处，模型为每个类别设定一个概率。这支持比较两个模型的性能。对数损失位于 `[0, ∞)` 区间内，且无上界。接近零的对数损失表示较高的准确性，而远离零的对数损失则表明较低的准确性。一般来说，当对数损失最小化时，分类器更准确。这可以定义为公式 (7.18) 或 (7.19)。

![图 7.7 对数损失误差的表示。](html/images/9781032473246_C007_007.jpg)

[图 7.7](#ch14.xhtml#f109b) 对数损失误差的表示。

$$\text{Log loss} = - \frac{1}{\text{N}}\sum\limits_{\text{i} = 1}^{\text{n}}\left( {\text{log}\left( \text{p}_{\text{i}} \right)\text{*y}_{\text{i}}} \right) + \left( {\left( {1 - \text{y}_{\text{i}}} \right)\text{*log}\left( {1 - \text{p}_{\text{i}}} \right)} \right) \tag{7.18}$$

其中，`N` 为观测数，`p` 为观测 `i` 为 1 的预测概率，`y` 为观测 `I` 的真实标签（0 或 1），用于二分类。

也可以表示为

$$\text{Log loss} = - \frac{1}{N}\sum\limits_{i = 1}^{N}\sum\limits_{j = 1}^{M}\left( {\text{log}\left( p_{ij} \right)\text{*}y_{ij}} \right) \tag{7.19}$$

其中 `N` 个样本属于 `M` 个类别，

`y[ij]` 表示样本 `i` 是否属于类别 `j`

`p[ij]` 表示样本 `i` 属于类别 `j` 的概率

## R 平方误差

R 平方或决定系数显示模型预测与实际数据的拟合程度。其计算公式如 (7.20) 所示。R 平方具有可理解的数值，不受实际输出影响，且不提供关于预测误差的任何洞见。

$$\text{R squared error} = 1 - \frac{\sum_{i = 1}^{n}\left( {y_{i} - {\hat{y}}_{i}} \right)^{2}}{\sum_{i = 1}^{n}\left( {y_{i} - \overline{y}} \right)^{2}} \tag{7.20}$$

其中 `y`、`ŷ` 和 `ȳ` 分别表示实际值、预测值和实际值的均值。

# 7.2.13 性能指标总结

性能指标的有效性取决于数据类型、应用领域和其他约束条件。表 7.1 给出了性能指标的总结。

## 表 7.1 性能指标总结

| 技术 | 描述 |
| --- | --- |
| 准确率 | 主要用于所有类别同等重要且问题平衡的情况 |
| 精确率 | 对于负样本显著多于正样本的极度不平衡数据集至关重要，因为这类数据集易获得高准确率（始终预测为负类即可获得高准确率）。 |
| 召回率 | 当假阴性的代价较高时，应使用召回率。 |
| F1 度量 | 为了在不均衡的类别分布中寻找精确率和召回率之间的平衡，可使用 F1 分数来利用包含大量 TN 的任务。 |
| 平均绝对误差 (MAE) | 当使用连续数据评估性能时，通常使用 MAE。它生成一个线性数值，均匀加权个体差异并取其平均。数值越低，模型性能越好。 |
| 均方误差 (MSE) | MSE 用于评估预测数值型因变量的回归模型，同时对自变量和因变量或目标变量进行建模。 |
| ROC | 数据严重不平衡时请勿使用。 |
| AUC | 当同等关注正类和负类时使用。 |
| PR-AUC | 当数据不平衡且更关注正类而非负类时使用。 |
| 留出法 | 留出法仅需要一次训练-测试划分。因此，留出法的得分取决于数据如何划分为训练集和测试集。当数据集非常大时，此方法很有用。 |
| `k` 折交叉验证 | `k` 折交叉验证是一种重采样方法，用于在数据较少时评估模型并检验学习模型的有效性。 |
| 留一法交叉验证 | 当数据集较小，或准确评估模型性能比方法的计算成本更重要时，留一法交叉验证程序是合适的。 |
| 混淆矩阵 | 当分类器输出包含两个或更多类别时，使用混淆矩阵。混淆矩阵中的相关 TP、TN、FP、FN 值用于可视化准确率、召回率、精确率和特异性等重要的预测分析指标。 |
| 敏感性 | 准确分类的正例百分比即为敏感性。它评估数据不平衡时分类的表现。 |
| 特异性 | 准确分类的负例百分比称为特异性。这可用于不平衡数据。 |
| Kappa 系数 | Kappa 系数计算预测结果与真实类别的一致性。 |
| 对数损失 | 对数损失可比较两个模型的性能，从而决定哪个模型表现更好。 |
