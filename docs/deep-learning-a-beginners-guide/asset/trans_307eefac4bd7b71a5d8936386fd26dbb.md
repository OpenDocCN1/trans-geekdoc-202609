
# 线性回归的基本原理

让我们使用数学表示法来学习线性回归的基本原理。设模型预测值为 `ŷ`，实际输出为 `y`。我们可以将输出定义为 `ŷ = w^T x`，其中 `w ∈ R^n` 是参数向量。这些参数是一组控制系统行为的值。在本例中，`w` 被定义为一组权重（`w[i]`），用于决定每个特征（`x[i]`）对最终预测的影响。如果特征 `x[i]` 获得正权重 `w[i]`，这意味着特征 `x[i]` 的增加会增加模型最终预测值 `ŷ` 的数值。同样，如果特征获得负权重，特征的增加会导致预测值减小。如果权重为零，则不影响最终预测。线性回归通常与截距项 `b` 一起使用，称为偏置。这定义了在没有任何输入值的情况下，术语偏向于 `b`。线性回归的基本原理可用于开发复杂和高级的学习算法。

## 2.2.2 逻辑回归

我们讨论了线性回归，它将连续值量作为自变量的线性函数进行预测。然而，它不是预测二值标签的好方案。逻辑回归通过使用 Sigmoid 函数来表示二值上的概率分布，预测给定样本属于特定类别的概率，从而解决了这个问题。因此，一个没有隐藏层且输出层相关神经元使用 Sigmoid 激活函数的神经网络被称为逻辑回归。这是一种在分类中使用概率概念的机器学习方法。当目标变量是离散的（即 0 或 1）时使用此回归，Sigmoid 函数表示预测变量与目标变量之间的关系，如 [图 2.5](#ch09.xhtml#f13) 所示。

当逻辑回归用于多标签类别时，我们使用 Softmax 激活函数，称为 Softmax 回归或多项式逻辑回归。因此，它常被用作分类器的输出，以表示多个类别上的概率分布。当数据集较大时使用逻辑回归。此外，自变量特征之间不应存在任何相关性。

## 2.2.3 其他回归方法

有几种类型的回归技术，如 Lasso 回归（L1）、岭回归（L2）、多项式回归和贝叶斯线性回归。本节概述了其他回归方法。L1 和 L2 用于减少线性回归中的过拟合并减少最小二乘误差。当预测变量与目标变量之间存在更多相关性时使用这些方法。L1 和 L2 正则化方法将在 2.5.5 节进一步讨论。通常，当许多特征集提供稀疏解时使用 L1 正则化。它同时执行正则化和特征选择。当自变量高度共线时，L1 回归仅保留一个变量并使其他变量收缩为零，从而减少过拟合。

在多项式回归中，变量之间的关系由 `n` 次多项式给出。虽然它试图通过减小均方误差（MSE）来获得穿过所有数据点的最佳拟合曲线，但这可能导致过拟合，即模型仅在训练集上表现良好，而无法泛化。贝叶斯回归是另一种使用贝叶斯定理来识别系数的技术。在这里，它找到的特征后验分布比线性回归更稳定。

## 2.3 分类

现在，让我们看看回归和分类的区别。分类是一种监督学习算法，使用带标签的数据集进行预测。虽然它用于与回归相同的任务，但区别在于应用场景。例如，回归技术用于预测温度、商品价格、薪资和年龄等连续值；而分类则对狗或猫、健康或不健康等离散值进行分类。[图 2.6](#ch09.xhtml#f14) 和 [图 2.7](#ch09.xhtml#f15) 展示了分类和回归的可视化表示。

## 2.4 超参数

### 2.4.1 概述

超参数是定义模型网络结构的变量。这些变量指定模型的训练参数。超参数（如学习率）是在模型训练期间优化权重和偏置之前设置的。其他一些超参数包括隐藏层数量、批次大小、训练轮数（epochs）和每层节点数量，这些都用于训练过程。我们可以将超参数调优的步骤列举如下。此外，[表 2.1](#ch09.xhtml#t3) 说明了不同假设的影响。

*   步骤 1 — 确定网络结构。
*   步骤 2 — 调整学习率。
*   步骤 3 — 选择优化器和损失函数。
*   步骤 4 — 确定批次大小和训练轮数。
*   步骤 5 — 随机重启。

[表 2.1](#ch09.xhtml#t3b) 列出不同类型的超参数及其大致敏感度

| 超参数 | 大致敏感度 |
| --- | --- |
| 学习率 | 高 |
| 优化器类型 | 低 |
| 优化器参数 | 低 |
| 批次大小 | 低 |
| 权重初始化 | 中 |
| 损失函数 | 高 |
| 模型深度 | 中 |
| 层大小 | 高 |
| 层参数（核大小） | 中 |
| 正则化权重 | 中 |
| 非线性 | 低 |
