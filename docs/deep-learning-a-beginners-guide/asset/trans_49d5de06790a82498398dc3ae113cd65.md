

# 集成学习技术

我们可以使用机制来改变集成学习中每个模型的训练数据。作为一种简单的技术，*k*折交叉验证可用于测量泛化误差。在此，训练数据集被划分为*k*个子集，每个子集使用唯一的模型进行训练。Bootstrap聚合（Bagging）是另一种技术，它使用有放回重采样的训练数据集来训练模型，从而产生不同的泛化误差。随机训练子集集成是另一种技术。

## 改变模型

用于集成的每个模型的配置可以各不相同。例如，模型因层数或节点数、学习率或正则化类型而异。因此，集成模型学习一个异构映射函数，并导致输出中的相关性较小。

## 改变组合方式

集成模型结果的组合方法可以多样化。作为一种简单的技术，可以使用模型融合来计算每个模型预测的平均值。这种加权平均集成可以通过采用优化权重技术（如留出验证）来改进。此外，还可以使用堆叠等技术学习新模型。作为一种扩展技术，可以使用Boosting。它在集成学习过程中一次引入一个模型，以解决前一个模型训练期间发生的错误。模型权重平均是另一种方法，它结合了几个结构相似模型的权重。

## 5.4.3 集成学习技术

我们已经了解到，集成学习的目标是通过合并多个学习模型的输出，来降低预测结果的方差和泛化误差。如上所述，通过改变训练数据、模型以及预测的组合机制，可以获得不同的集成学习技术。集成技术的选择取决于具体应用。以下描述了Bagging、Boosting和Stacking等高级集成学习技术。

### Bagging（Bootstrap聚合）

Bagging方法多次选择单个数据点，并对训练数据进行随机采样，以减少嘈杂数据集中的预测方差。此处，使用替换技术创建数据集的随机子集，这些子集作为独立数据集并行训练模型。因此，给定的数据点可以属于许多数据子集。测试阶段考虑使用给定数据集的不同子集训练的模型的输出，如[图 5.13](#ch12.xhtml#f83)所示。最终结果通过将多个模型输出传递给聚合过程来获得。Bagging表现出较高的偏差，使得预测器之间的相关性较低，从而降低了集成的方差。

### Boosting

通常，每个模型在整个数据集上的表现可能不佳；然而，它们在数据集的某些部分确实具有高性能。Boosting按顺序处理数据集，将整个数据集输入初始模型并分析结果。模型错误分类的数据点随后被传递给第二个模型。因此，第二个子模型专注于特征空间的挑战性区域并学习适用的决策边界。顾名思义，每个模型都将有助于提升整个集成的性能。随后，遵循相同的过程，并使用所有先前模型的组合在未见数据上生成最终结果，如[图 5.14](#ch12.xhtml#f84)所示。此处，每个模型都依赖于前一个模型，因为后续模型旨在纠正给定数据子集上先前模型训练的错误。因此，Boosting算法将一组不足的模型集成为一个鲁棒的学习模型，并使用多数投票权重提升整体预测。此方法降低了集成预测中的偏差。因此，所选分类器应为具有较少可训练参数的简单模型，从而导致低方差和高偏差。

### Stacking

Stacking技术使用Bootstrap数据子集，并像Bagging技术一样并行训练多个模型。所有这些模型的输出被用来通过一个元分类器组合多个模型，从而产生总体预测。此处，使用两层分类器以确保适当的训练。下一层中的元分类器可能会捕捉第一层模型集合中缺失的特征。例如，第一层模型产生的输出类别分配概率可以通过某些权重进行平均以组合模型输出。然后，对平均预测类别概率使用`argmax`可用于最终预测。单层Stacking如[图 5.15](#ch12.xhtml#f85)所示。此外，还有多层Stacking的集成模型，其中包含额外的分类层。然而，与性能结果的相对较低提升相比，此类方法消耗更多的计算成本。

以下是在相似数据上运行的集成学习基本技术。

*   **最大值规则**：该技术基于每个模型产生的概率分布。集成模型的预测是在分类器中输出置信度得分最高的类别标签，因此它也可应用于多分类。
*   **多数投票**：该方法考虑一组随机分类器模型，并计算每个样本的预测。许多模型预测最多的类别标签被视为集成学习的输出。由于选择了多数投票的类别，该技术非常适合二分类。在多分类中，如果两个或更多类别具有相同的最高票数，则随机选择一个类别作为最终预测。
*   **概率平均**：该方法首先分别计算所有模型的概率得分（即预测的置信度）。然后计算所有涉及模型的平均得分，考虑给定数据集中的所有类别标签。在平均得分中，概率最大的类别标签被视为集成模型的预测类别。
