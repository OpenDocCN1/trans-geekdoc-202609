

# 6.6 模型优化

## 6.6.1 模型优化概述

优化过程通过在每次迭代中调整超参数来迭代地训练模型，直到出现最优结果。优化算法会改变模型参数，如学习率和权重，这些参数在每个 epoch 或迭代中更新，以减少损失函数（误差函数）或最大化生产效率。通常，网络规模与速度之间存在权衡，因此当层数增加时，很难应用优化器。梯度下降（`GD`）和随机梯度下降（`SGD`）等不同技术被用作优化算法。

让我们重温以下概念。

*   函数的最大值和最小值分别用极大值和极小值表示。[图 6.6](#ch13.xhtml#f92) 显示了给定曲线的全局极大值、局部极大值、局部极小值和全局极小值的位置。全局点是针对函数的整个定义域获得的，而局部点则基于函数的给定范围。在学习模型中，存在单个全局最小值和全局最大值的点。然而，可能存在许多局部最小值和局部最大值的位置。

    ![图 6.6 极小值和极大值位置。](html/images/9781032473246_C006_006.jpg)

    [图 6.6](#ch13.xhtml#f92b) 极小值和极大值位置。

*   学习率表示每次迭代的步长，是一个可调参数。[图 6.2](#ch13.xhtml#f88) 显示了学习率的行为。由于偏差和方差之间的权衡受超参数影响，较小的学习率可能导致模型过拟合并具有较大的方差。相反，当学习率较高时，模型可能欠拟合并导致较大的偏差。可以使用交叉验证来识别具有最小损失的最优值。

    图 6.7 学习率的表示。

*   梯度衡量函数的斜率，该斜率考虑基于损失的权重更新。通常，斜率在极小值处将其符号从正变为负。作为一种最小化算法，当点的斜率向极小值移动时，斜率会减小，如[图 6.3](#ch13.xhtml#f89) 所示。当梯度增加时，斜率变得更陡峭，模型学习效率更高。

*   **指数移动平均（EMA）**

    神经网络中的权重需要用一个值来更新。仅考虑当前梯度可能无法获得高性能结果。这可以通过聚合所有当前梯度和过去梯度的平均值来解决；然而，这会导致梯度具有相等的权重。为了解决这个问题，采用了梯度的指数移动平均。在此过程中，为过去和最近的梯度分配更高的权重值，以表示其更高的重要性。

*   **具有自适应学习率的权重更新过程**

    当最近几次迭代的梯度平均值接近零时，模型变成一个近似平坦的表面。为了收敛并达到全局最小值，应找到一个具有加速效果的向下斜率。在这里，当梯度值较低时，应增加学习率组件以加快学习速度。通过将固定学习率除以平均梯度值来建立反比关系。当存在较高的自适应学习率时，会导致较大的权重更新，因为它乘以了梯度。相反，当存在较高的平均梯度值时，模型训练处于陡峭的斜坡上。为了达到全局最优点，我们需要通过执行相同的除法并谨慎移动来迈出小步子。
