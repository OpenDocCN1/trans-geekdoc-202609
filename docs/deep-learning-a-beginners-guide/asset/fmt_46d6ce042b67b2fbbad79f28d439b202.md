
## 30. How to select an evaluation technique?

Every machine learning problem can be categorized into two categories: classification and regression. Based on the category, the evaluation metric can be different to be applied.

### Classification metrics
Confusion matrix representing, Accuracy, precision, and recall, F-score.

### Regression metrics
Explained variance, Mean squared error, R2 coefficient.

### Common metrics
Learning curves, Validation curves.
