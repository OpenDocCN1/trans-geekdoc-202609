
# ResNet 和梯度消失问题

让我们看看 ResNet 是如何解决梯度消失问题的。ResNet 允许深度神经网络使用替代的捷径路径让梯度流过。残差块中的这些跳跃连接有助于学习函数，确保高层和低层都能表现良好。因此，ResNet 模型利用恒等映射处理梯度消失问题。它包含作为梯度“高速公路”的跳跃连接，允许梯度自由流动。它使梯度能够在变得微弱或归零之前传播到更深的层。模型训练中优化的另一个问题是宽参数空间的使用。这可能导致盲目增加层数并增加训练损失。

## 4.4.2 Inception 模型

我们期望神经网络在大规模和多尺度卷积层上表现良好。模型学习基于 Hebb 原理，即神经元激活、与其他神经元连接并创建神经网络以学习新的方面。因此，Inception 模型认为，为了使神经网络高性能，它们应该在各个方面都能良好扩展。

Inception-v3 模型由 Google 于 2015 年推出，包含 42 层。它是一种常用的 CNN 模型，主要用于图像分类。该模型以较低的错误率在 CNN 上提供了高性能增益。它能以极小的计算负载增长高效利用资源。此外，它支持使用各种尺寸的卷积滤波器在不同尺度上进行特征提取。它能够处理梯度消失问题。

Inception 模型是一种具有重复组件的 DNN，如[图 4.8](#ch11.xhtml#f52)所示。此处，为了数据的降维，使用了 `1×1` 卷积。它能够扩展网络的深度和宽度。`3×3` 和 `5×5` 卷积导致不同的卷积滤波器尺寸，使模型能够在输入的深度和宽度所有维度上学习各种尺度的空间模式。Inception 模型架构如[图 4.9](#ch11.xhtml#f53)所示，Inception 模型的优势可列举如下。

## 4.4.3 GoogLeNet

GoogLeNet 是一种 CNN，包含 22 层深度卷积层和池化层，作为 Inception 模型的一种修改而支持。它是一个具有并行拼接的网络，广泛用于物体分类。该架构的重要性在于，它在保持计算预算恒定的同时，以更高的计算复杂度达到了与最先进模型相当的性能。在实际应用中，用于图像识别或物体检测任务的模型应该是高效的，并能嵌入到资源较低的设备（如手机）中，以实现应用的实际使用。我们了解到，神经网络层数的增加通常会带来高性能增益，然而，它计算密集。更重要的是，大型网络容易过拟合，并面临梯度消失或梯度爆炸问题。GoogLeNet 模型通过利用 Inception 模块提高计算效率，解决了大型网络的挑战。如[图 4.10](#ch11.xhtml#f54)所示，该架构有 22 层，若包含池化层则延伸至 27 层。其中一部分层由九个 Inception 模块组成。

![Figure 4.10 GoogleNet architecture.](html/images/9781032473246_C004_010.jpg)

[图 4.10](#ch11.xhtml#f54b) GoogLeNet 架构。

GoogLeNet 架构交替使用卷积层和最大池化层。第一个卷积层使用相对较大的 `7×7` 滤波器尺寸。这有助于在使用大尺寸滤波器的情况下减少输入维度，而不丢失空间细节。在此，图像的宽度和高度在第二个卷积层处减少四倍。随后，在传递给第一个 Inception 模块之前，再减少八倍。然而，它生成了更多的特征图。GoogLeNet 的最终预测组件由一个平均池化层、一个 40% 的 Dropout 层、线性分类器和 Softmax 分类器组成。通常，平均池化层计算最后一个 Inception 网络生成的特征图的平均值，并将输入尺寸减小到 `1×1`。然后在线性层之前使用 Dropout 层进行正则化，以解决数据过拟合问题。

## 4.4.4 Xception 模型

## 4.4.5 DenseNet 模型

DenseNet 架构由层之间的密集连接组成，如[图 4.12](#ch11.xhtml#f56)所示。此处，密集块直接连接每个具有相同尺寸特征图的层。这一特性解决了高深度模型中的梯度消失问题，并提高了下降的准确率。如[图 4.12](#ch11.xhtml#f56)所示，每一层从所有先前层获取额外输入，并将其特征图传递给所有后续层。此处，`c` 表示通道维度拼接。

![Figure 4.12 DenseNet model architecture.](html/images/9781032473246_C004_012.jpg)

[图 4.12](#ch11.xhtml#f56b) DenseNet 模型架构。

DenseNet 的优势之一是其强大的梯度流。此处，损失容易且直接地传递给先前层，先前层从最终层隐式地获得直接监督。在 DenseNet 中，每一层获得来自所有先前层的特征图的组合知识。这可能导致网络变得更窄且更密集。该模型提供高效的计算和内存利用，因为它可以拥有较少的通道和参数。此外，它支持扩展特征和复杂的数据模式，因为每一层都获得所有先前层作为输入。因此，DenseNet 提供平滑的决策边界。因此，即使输入数据量较少，也支持高性能值。尽管有许多优势，但 DenseNet 由于拼接操作需要大量 GPU 内存。
