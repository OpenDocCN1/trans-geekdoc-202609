

# 激活函数

总之，神经元的激活由激活函数决定。它决定了输入对预测输出的重要性，并将某层中节点输入的加权和转换为输出。因此，在前向传播过程中，激活函数通过在每一层创建一个额外的任务，为模型增加了非线性。

通常，神经网络中的所有隐藏层使用相同的激活函数。该函数应可微分，以便在反向传播期间学习参数。隐藏层中使用的激活函数是根据模型类型选择的。在大多数情况下，隐藏层使用 `ReLU` 激活函数。`Sigmoid` 和 `Softmax` 激活函数分别用于二分类和多分类的输出层。激活函数的选择应考虑梯度消失和梯度爆炸问题。

以下是一些广泛使用的非线性激活函数。

## 1. ReLU (线性修正单元)

线性修正激活函数（`ReLU`）是一种默认激活函数，一次仅激活一组神经元。它是一个分段线性函数。如果输入为正值，函数直接输出该输入。如果输入为负值，则输出零，表示失活。如[图 2.8](#ch09.xhtml#f16)所示，这给出了 `max(x, 0)`。因此，在反向传播过程中，某些神经元的权重和偏置不会更新，从而提高了计算过程的效率。由于易于计算、不饱和等特性，`ReLU` 常用于隐藏层。以下是与 `ReLU` 函数相关的优点（+）和缺点（–）。

*   **+** 计算效率高，因为只激活一组神经元。
*   **+** 相关的线性和非饱和特性加速了梯度下降向损失函数全局最小值的收敛。
*   **+** 由于导数为 1 或 0，权重得到更新并达到收敛；因此不会导致梯度消失问题。
*   **–** `ReLU` 失活问题（死激活函数）。由于 `ReLU` 的导数为 0 或 1，如果导数为零，则新权重与旧权重相同。
*   **–** 由于 `ReLU` 不是以零为中心对称的，且对所有负输入输出均为零，因此某些神经元无法学习。

## 2. Leaky ReLU

`Leaky ReLU` 是 `ReLU` 的扩展。如[图 2.9](#ch09.xhtml#f17)所示，它在负区域包含一个轻微的正斜率，从而解决了 `ReLU` 失活问题。Leaky `ReLU` 的设计扩展了 `ReLU` 激活函数的范围，使其对负输入更敏感，以解决范围有限和冲动行为的问题。此外，它保留了 `ReLU` 的单调性和可微性。

## 3. Sigmoid/Logistic 激活函数

对于任意实数输入，Sigmoid 函数输出 0 到 1 之间的值。当输入较大（更正）时，输出趋近于 1。对于负输入，输出趋近于 0。该函数主要用于二分类的输出层。通常，在正态分布（或高斯分布）中，数据以零为中心，均值为 0，方差为 1，呈钟形曲线。然而，如[图 2.10](#ch09.xhtml#f18)所示，在 Sigmoid 中，数据不是以 0 为中心的；因此消耗更多计算时间，且收敛到全局最小值需要更长时间。

![Figure 2.10 Sigmoid activation function.](html/images/9781032473246_C002_010.jpg)

[图 2.10](#ch09.xhtml#f18b) Sigmoid 激活函数。

以下是 Sigmoid 函数的优缺点。

*   **+** 常用于需要预测概率作为输出的模型。由于任何事物的概率仅存在于 0 到 1 的范围内，Sigmoid 凭借其输出范围成为正确的选择。
*   **+** 该函数可微，并通过防止输出值跳变，提供平滑的 S 形梯度。
*   **–** 对于大于 3 或小于 -3 的值，Sigmoid 函数获得的梯度可忽略不计。因此，当梯度值接近 0 时，模型无法学习并面临梯度消失问题。
*   **–** 难以训练且模型变得不稳定，因为输出不是以零为中心对称的，且所有神经元的输出将具有相同的符号。
*   **–** 收敛耗时较长。

## 4. Softmax 激活函数

`Softmax` 函数用于多分类任务中神经网络的最后一层。它可以描述为一组 Sigmoid 函数，返回每个类别的概率。该激活函数是 Sigmoid 函数的一种广义形式，产生 0–1 范围内的值。它将全连接层 *K* 个单元的（未归一化）输出转换为概率分布（归一化输出）。

## 5. Tanh 激活函数

如[图 2.11](#ch09.xhtml#f19)所示，`Tanh` 激活函数比 `ReLU` 和 Sigmoid 更有效，因为它是以零为中心的。在 Tanh 图中，负输入和零输入分别映射到强负值和接近零的值。这主要用于具有二分类任务的前馈神经网络。`tanh` 函数主要用于两类之间的分类。`tanh` 激活函数的优缺点如下。

![Figure 2.11 Tanh activation function.](html/images/9781032473246_C002_011.jpg)

[图 2.11](#ch09.xhtml#f19b) Tanh 激活函数。

*   **+** 由于函数输出以零为中心，输出值被映射为强负、中性或强正。
*   **+** 取值介于 –1 和 1 之间，`tanh` 通常用于隐藏层。由于隐藏层的均值变为 0 或接近 0，它支持数据的中心化，使下一层的学习过程更容易。
*   **+** 虽然这面临梯度消失问题，但由于函数以零为中心，梯度可以向特定方向移动。因此在实践中被广泛使用。
*   **–** `tanh` 激活函数的梯度面临梯度消失问题。该梯度比 Sigmoid 函数的梯度陡峭得多。

# 2.4.4 学习率

学习率是一个影响模型训练的超参数。它针对模型权重更新时的估计损失，处理模型的变化。因此，学习率支持调整权重更新，以减小损失。学习率的传统默认值为 0.1 或 0.01。当学习率设置得非常低时，训练过程会缓慢推进，权重更新幅度很小，如[图 2.12](#ch09.xhtml#f20)所示。同样，当学习率非常高时，损失函数的表现会有所不同。
