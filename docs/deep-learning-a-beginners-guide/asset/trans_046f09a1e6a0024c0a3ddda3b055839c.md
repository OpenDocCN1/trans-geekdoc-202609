

# 数据集划分与模型选择

如果我们有充足的可用数据，可以按照有效的比例将数据集划分为三个主要部分：训练集、测试集和验证集。训练集可用于训练具有各种模型超参数组合的不同候选模型。这些模型将在验证数据集上进行评估，并从所有候选模型中选择最佳模型。该模型将通过调整模型参数在训练集和验证集上进行训练。然后在测试集上评估模型的泛化误差。如果该误差与验证误差非常相似，则模型在未见数据上也有更高的概率表现良好。即使在训练完模型后，我们还可以进一步使用模型学习曲线作为模型预测性能的度量。这将有助于根据训练和验证分数识别过拟合和欠拟合模型。此外，学习曲线阐释了方差和偏差的概念。偏差是指模型的错误性，会导致其欠拟合数据。另一方面，模型的高方差会导致模型过拟合。因此，所有这些模型复杂度的度量都可用于进行适当的模型选择。

## 2.5.2 模型收敛

当额外的训练无法改进模型时，模型即达到收敛。当模型的损失以递减趋势向最小值（局部或全局）移动时，模型即达到收敛。[图 2.16](#ch09.xhtml#f24) 展示了一个具有最小值和最大值点的非凸函数。局部最小值是指损失函数在局部区域内的最低值。全局最小值是指损失函数在整个定义域内全局获得最低值。

在深度学习模型中，我们需要避免局部极小值。在此处，鞍点处的导数为零，因为权重将保持不变而不进行更新。可以使用动量值来解决局部极小值点。换句话说，通过在给定方向上提供冲量，损失函数可防止局部极小值点。我们可以使用随机梯度下降优化来识别局部极小值并达到全局极小值，这将在[第 5 章](#ch12.xhtml#c5)中讨论。此外，改变激活函数、学习率以及使用批量归一化有助于避免局部极小值。

## 2.5.3 过拟合与欠拟合

在模型训练中，我们期望获得最优拟合，即训练误差略低于测试误差。过拟合和欠拟合的概念会影响模型性能。在过拟合中，模型在训练数据集上表现良好，但在问题领域的新数据上表现不佳。即模型欠拟合在训练和测试数据集上均表现不佳。[图 2.17](#ch09.xhtml#f25) 展示了不同模型类型下的欠拟合、最优拟合和过拟合场景。

在深入探讨这些概念的细节之前，我们将复习一下偏差和方差的知识。偏差是使输出倾向于或背离期望值的系统误差。如果模型对训练数据给出低误差，而对测试数据给出高误差，这可以解释为方差。准确率和损失等性能指标用于识别训练中的缺陷，如过拟合和欠拟合。

### 模型过拟合

当学习算法试图拟合数据集中的所有数据点或超出所需的数据点时，就会发生过拟合。结果，模型学习到了噪声（导致模型性能下降的无关和不必要的数据）和数据集中的不准确特征，从而对模型的整体性能产生负面影响。这意味着，当模型使用数据进行训练时，它会捕捉数据集中的噪声或其他随机波动，并试图从中学习。由于噪声和过多的细节，这将降低模型泛化和在未见数据上良好表现的能力。因此，过拟合模型在训练数据上表现良好，但在未见数据上表现不佳，如[图 2.17](#ch09.xhtml#f26) 深度学习类别所示。这些模型具有低偏差和高方差。考虑[图 2.17](#ch09.xhtml#f25) 中回归模型的过拟合。模型本身试图覆盖图中的所有数据点。你可能会认为这非常高效，然而，回归的目的是找到最佳拟合线，而不是覆盖所有数据点。因此，该模型在未见数据上将表现不佳。因此，过拟合模型的特征是具有较低的训练损失（低于测试损失）和高方差。

![图 2.18 模型训练中的早停法。](html/images/9781032473246_C002_018.jpg)

[图 2.18](#ch09.xhtml#f26b) 模型训练中的早停法。

在神经网络的早期，公认的智慧认为参数数量不能超过训练样本数量。随着深度学习技术的发展，这条规则似乎已被抛诸脑后。如果参数多于样本，模型就会对训练数据过拟合。然后它将失去泛化数据的能力。也就是说，它会非常好地记住训练数据并适用于训练数据，但对于一组新的相关数据不会给出好的结果。既然我们已经知道模型过拟合的原因，让我们了解一下可以在学习模型中用来避免过拟合的机制。

过拟合减少方法列举如下。

*   执行正则化。
*   增加训练数据集大小。
*   降低模型复杂度：通过使用更少的变量和参数保持模型更简单。这消除了与训练集相关的噪声以减少方差。
*   在模型训练中执行早停法，当损失开始增加时停止，如[图 2.18](#ch09.xhtml#f26) 所示。
*   训练时使用 Dropout：它将在训练期间随机丢弃一些连接和节点。从而变成一个简单且小型的网络。
*   应用正则化，如岭正则化和 Lasso 正则化，它们会忽略导致过拟合的一些模型参数。
*   使用交叉验证技术进行评估。

在解释减少过拟合的可能方法时，使用更多数据进行训练将在一定程度上有助于避免模型过拟合，因为它为模型提供了学习数据潜在模式的机会。可以使用不同的增强方法，如裁剪和旋转，来增加数据集大小，从而解决过拟合问题。然而，如果我们向数据集中添加更多噪声数据，这种技术将无助于避免模型过拟合。因此，有必要确保额外的数据是干净且相关的。此外，可以减少训练数据中的特征数量以降低网络的复杂度。

交叉验证是通过生成多个训练-测试划分来避免模型过拟合的有效方法。在 `k` 折交叉验证中，我们将数据集划分为 `k` 个子集，并在 `k`-1 个折上迭代训练模型，同时保留剩余的一个折用于测试。这种方法有助于在训练数据上调整模型超参数，并将测试数据作为未见数据集保留下来以选择最佳最终模型。您可以在[第 7 章](#ch13.xhtml#c6)中阅读更多关于交叉验证的内容。
