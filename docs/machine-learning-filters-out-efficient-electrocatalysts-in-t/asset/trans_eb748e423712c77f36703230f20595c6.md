## 2.2. ML 模型开发

对于 SGNN，图是基于两层掺剂和吸附物的结构构建的。系统中每个第 $i^{th}$ 个原子（节点）的元素输入到向量 $v_i$ 中，该向量包含元素表中可用的信息。在这项工作中，我们使用了一个包含原子特征及其范围、颜色的向量 $v_i$。边（第 $i^{th}$ 个原子与第 $j^{th}$ 个原子之间的键合）用 $d_{ij} < r_{\delta}$ 表示，其中 $d_{ij}$ 是 $r_i$ 和 $r_j$ 之间的距离，$\delta$ 是化学键的长度。该化学键表示为向量 $u_{ij} = e_k$，其中 $k$ 是第 $i^{th}$ 个中心节点，$j$ 是邻居节点。我们还在消息向量中包含了方向 $j$。由于具有距离不变性，$u_{ij}$ 和 $d_{ij}$ 的值是通过公式数值化生成的。

```
$v_i^{(l+1)} = \sigma(W_v^{(l)} \sum_{j \in \mathcal{N}(i)} W_u^{(l)} u_{ij} \odot v_j^{(l)} + b^{(l)})$
```

其中卷积层和滤波器分别由 $l$ 和 $f$ 表示，$W_v^{(l)}$、$W_u^{(l)}$ 和 $b^{(l)}$ 是第 $l^{th}$ 层和第 $f^{th}$ 个滤波器的卷积权重和偏置。$\odot$ 表示元素级乘法，$\sigma$ 是 sigmoid 函数，$EL$ 是指数线性激活函数 [40]。第 $l^{th}$ 层所有原子向量的归一化和表示为 $S_i^{(l)} = \sum_{j \in \mathcal{N}(i)} v_j^{(l)}$。

模型使用池化阶段进行训练。池化后的向量与分子的吸附能连接。优化后的值在括号中显示：卷积和滤波器的数量 (1, 2)，层数 (3)，学习率 ($5 \times 10^{-3}$)，递减学习率 (每 100 个 epoch 为 0.99)，滤波器数量 (4-6)，以及每个中随机分布原子的数量 (1000)，批大小 (31, 64) 和总 epoch 数 (800)。使用均方误差 (MSE) 来评估损失函数 $J$。使用 Adam 优化器训练模型。为了减少过拟合，采用了 $L^2$ 正则化技术。表 S2 包含了优化过程的超参数和参数列表。

## 2.3. 溅射法制备 CuAu

制备好的 Ni 电极放置在直流 (DC)溅射系统的真空腔中。为了形成 CuAu 薄膜，使用了 99.99% 纯 3-Cu 靶和 99.99% 纯 Au 靶。将金箔交叉压在阴极、两个靶和阳极上，然后进行工艺。真空腔的压力为 $2.5 \times 10^{-5}$ Torr。通过通入 Ar (15 sccm) 气体将压力维持在 2.5 mTorr。对溅射靶施加 150 W 的直流溅射功率持续 30 分钟，在基底上形成纳米级厚度的 CuAu（例如，Ni 电极，Si）。

## 2.4. 原子层沉积 (ALD) 制备 Pt 层

使用脉冲溅射系统 (ULVAC, ARJ-300) 在室温和 $100^{\circ}C$ 温度下将 Pt 沉积在基底（Ni 电极上的 Au 薄膜，Si）上。在真空腔内，放置一个 Pt 靶阴极和一个电极，使用圆形腔进行溅射。脉冲引起从阴极到靶的放电。测量了靶的平均沉积速率，通常持续 1 分钟。在此期间，通过汽化阴极材料产生高动能离子，温度升高了数十度 ($^{\circ}C$)。放电过程的可控参数为电压 V、阴极压力 C 和脉冲数 n。控制 Pt 的沉积。

## 2.5. 电化学测量

所有电化学测量均在电位计 (Autolab, PGStat) 的三电极旋转盘系统中进行。使用面积为 $1.96 cm^2$ 的镍圆电极作为电极。Ag/AgCl (3 M KCl) 作为参考电极和对电极。通过以下方程测量电位以评估逆氢反应 (HER)：

```
$E = E_{Ag/AgCl} + E'_{Ag/AgCl} + 0.0591 V$
```

其中 E 是相对于 RHE 的转换电位，$E'_{Ag/AgCl} = 0.210 V$，E 是相对于 Ag/AgCl 的实验测量电位。在 0.1 M KOH 中以 $mV/s$ 的扫描速度和 1000 rpm 记录电流。电流密度为：

```
$i = J$
```

其中 j 是实验测量的电流密度，J 是扩散限制密度。

## 3. 结果与讨论

### 3.1. 作为燃料电池性能描述符的吸附能

第一步是识别 ORR 和 HER 性能的描述符。对于 O2 分子通过四电子途径还原为 H2O 的 ORR（图 1A），速率决定步骤 RDS 是电化学势 (1.23 V vs RHE) 下从 O 到 H2O 最大的上坡步。ORR 标放关系表明以下机制之一存在限制：(+E) - O* (O2* - OH*) 或 (1.23 V) - OH* (H2O - OH*) 或 (1.45 V) - OH* (H2O - OH*)（图 1B）。

另一方面，HER 是一个涉及双电子途径和中间步骤 (H*) 的简单反应。H2 分子吸附在金属表面，吸附在催化表面的 H 分离成氢原子 (H*)，最后重组释放出 H2。在这里，需要一个小于 0.24 eV（在 Pt(111) 上）的电位差。因此，催化表面的 CO 中毒对于阳极不是问题；然而，CO 中毒是瓶颈 [56,57]。因此，HER 的前景区域由图 1D 定义，$\Delta G_H$ 为 0.24 eV 和 -1.4 eV（两个值均对应于纯 Pt）。

### 3.2. 数据库生成与 ML 开发
