# mysql_field_len

```
mysql_field_len(result_id, field_position)
```

Returns the length of the specified field (field_position) in a result set (result_id). mysql_fieldlen() may also be used, but is deprecated.

# mysql_field_seek

```
mysql_field_seek(result_id, field_position)
```

Sets the default field position for the next call to mysql_fetch_field().

# mysql_field_table

```
mysql_field_table(result_id, field_position)
```

Returns the name of the table containing the specified field (field_position) of the specified result set (result_id). mysql_fieldtable() may also be used, but is deprecated.

# mysql_field_type

```
mysql_field_type(result_id, field_position)
```

Returns the type of the specified field (field_position) in the specified result set (result_id). mysql_fieldtype() may also be used, but is deprecated.
