# MySQL Functions

MySQL provides a sizeable library of functions to format and combine data within SQL queries in order to produce the desired results in the desired format. This appendix provides a reference to the most useful of these functions, as implemented in MySQL as of version 3.23.39 (current as of this writing).

For a complete, up-to-date reference to supported SQL functions, see the MySQL Reference Manual at http://www.mysql.com.

# Control Flow Functions

```
IFNULL(expr1,expr2)
```

Returns expr1 unless it is NULL, in which case it returns expr2.

```
NULLIF(expr1,expr2)
```

Returns expr1 unless it equals expr2, in which case it returns NULL.

```
IF(expr1,expr2,expr3)
```

If expr1 is TRUE (that is, not NULL or 0), returns expr2; otherwise, returns expr3.

```
CASE value WHEN [compare-value] THEN result [WHEN ...] [ELSE result] END
```

Returns result when value=compare-value (note that several compare-value/result pairs can be defined); otherwise, returns the ELSE result, or NULL if none is defined.

```
CASE WHEN [condition] THEN result [WHEN ...] [ELSE result] END
```

Returns result when condition is TRUE (note that several condition/result pairs can be defined); otherwise, returns the ELSE result, or NULL if none is defined.
