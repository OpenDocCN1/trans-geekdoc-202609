Of course, if this is the first page, we don't need a link to the previous page. We know we're on the first page if $page equals zero.

Likewise, we don't need a link to the next page on the last page of content. To detect the last page, we need to use the count function that I introduced briefly in Chapter 6. count takes an array, and returns the number of elements in that array. When count is passed our array of pages, it will tell us how many pages there are. If there are 10 pages, then $textarray[9] will contain the last page. Thus, we know we're on the last page if $page equals count($textarray) minus one.

The code for the links that will turn our pages looks like this:

```
if ($page != 0) {
    $prevpage = $page - 1;
    echo("<p><a href='$PHP_SELF?id=$id&page=$prevpage'>".
        "Previous Page</a></p>");
}

// output page content here...

if ($page < count($textarray) - 1) {
    $nextpage = $page + 1;
    echo("<p><a href='$PHP_SELF?id=$id&page=$nextpage'>".
        "Next Page</a></p>");
}
```
