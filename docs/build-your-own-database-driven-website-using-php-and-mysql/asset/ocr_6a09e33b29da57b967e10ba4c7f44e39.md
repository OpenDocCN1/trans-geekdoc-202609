# # mysql_fetch_object

```
mysql_fetch_object(result_id [,result_type])
```

Returns the next result row from result_id in the form of an object, and advances the internal row pointer of the result set to the next row.
result_type may be set to MYSQL_NUM, MYSQL_ASSOC, or MYSQL_BOTH (the default) to retrieve the fields as numerical properties ($row->0 for the first field in the row), named properties ($row->user for the value of the user field in the result set), or both, respectively.

# # mysql_fetch_row

```
mysql_fetch_row(result_id)
```

Fetch a result row as numerical array. Identical to mysql_fetch_array() called with the MYSQL_NUM parameter.

# # mysql_field_flags

```
mysql_field_flags(result_id, field_position)
```

Returns a string containing the flags associated with the specified field (field_position) in the specified result set (result_id). The flags are separated by spaces in the returned string. Possible flags are: not_null, primary_key, unique_key, multiple_key, blob, unsigned, zerofill, binary, enum, auto_increment, and timestamp.
mysql_fieldflags() may also be used, but is deprecated.

# # mysql_field_name

```
mysql_field_name(result_id, field_position)
```

Returns the name of the specified field (field_position) in a result set (result_id). mysql_fieldname() may also be used, but is deprecated.
