MONTHNAME(date)
Returns the name of the month for date (e.g. "April").

QUARTER(date)
Returns the quarter of the year for date.
E.g.:
QUARTER("2001-04-12") = 2

WEEK(date)
WEEK(date,first)
Returns the week of the year for date (from 1 to 53), assuming by default that the first day of the week is Sunday (if first is not specified or 0), or Monday (if first is 1).

YEAR(date)
Returns the year for date (from 1000 to 9999).

YEARWEEK(date)
YEARWEEK(date,first)
Returns the year and week for date in the form YYYYWW. Note that the first or last day or two of the year may often belong to a week of the year before or after, respectively.
E.g.:
YEARWEEK("2001-12-31") = 200201

HOUR(time)
Returns the hour for time (from 0 to 23).

MINUTE(time)
Returns the minute for time (from 0 to 59).

SECOND(time)
Returns the second for time (from 0 to 59).

PERIOD_ADD(period,num_months)
Adds num_months months to period (specified as YYMM or YYYYMM) and returns the value in the form YYYYMM.

PERIOD_DIFF(period1,period2)
Returns the number of months between period1 and period2 (each of which should be specified as YYMM or YYYYMM).
