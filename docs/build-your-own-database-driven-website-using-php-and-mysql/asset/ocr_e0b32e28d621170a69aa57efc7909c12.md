The WHERE clause in the above code might be somewhat confusing. The idea
here is for us to be able to build on this basic SELECT statement, depending
on which constraints are selected in the form. These constraints will require
us to add to the FROM and WHERE clauses (portions) of the SELECT statement.
But if there were no constraints specified (i.e. the administrator wanted a list
of all jokes in the database), there would be no need for a WHERE clause at
all! Because it's difficult to add to a WHERE clause that doesn't exist, we
needed to come up with a "do nothing" WHERE clause. Thus, we have
introduced the requirement that Jokes.ID be greater than zero. This fits the
bill nicely, as the AUTO_INCREMENT feature of MySQL (which is responsible
for assigning the values in this column) will always choose integers that are
greater than zero.
