One final trick we can add to this code is to allow a file to be downloaded, instead of viewed, if the user so desires. By sending a MIME type of application/octet-stream, you can force some browsers (but not MSIE, unfortunately) to prompt the user to save the file. Here’s the modified code, which checks if the variable $action equals “dnld”, which would indicate that this special file type should be sent:

```
$sql = "SELECT FileName, MimeType, FileData
FROM filestore WHERE ID = 'id'";
$result = @mysql_query($sql);
if (!$result) die("database error: " . mysql_error());

$filename = mysql_result($result,0,"FileName");
$mimetype = mysql_result($result,0,"MimeType");
$filedata = mysql_result($result,0,"FileData");

if ($action == "dnld")
  $mimetype = "application/octet-stream";

header("Content-disposition: filename=$filename");
header("Content-Type: $mimetype");
header("Content-Length: " . strlen($filedata));

echo($filedata);
```

MSIE tries to be smart and will attempt to display a file of type application/octet-stream anyway. If we send it a non-standard MIME type, however (e.g. application/x-download), MSIE dutifully offers to download the file immediately. Other browsers either display an ugly “unrecognized file type” message that we’d like to avoid (Netscape 4), or try to display the non-standard file as a plain text file (Opera 5). To ensure the correct behavior in all browsers, we can detect MSIE by checking the built-in HTTP_USER_AGENT variable, to see if it contains the string “MSIE”. If it does, we send the application/x-download MIME type; otherwise, we send application/octet-stream. Here’s the code:

```
if ($action == "dnld") {
  if (strpos(HTTP_USER_AGENT,"MSIE"))
    $mimetype = "application/x-download";
  else
    $mimetype = "application/octet-stream";
}
```

The only remaining problem now is that, by default, Opera 5 identifies itself as MSIE 5.0. To get around this sticky issue would require that we use some clever JavaScript to check the actual features of the browser, and identify whether it’s really MSIE, or just Opera posing as MSIE. The JavaScript would then send its findings to the PHP script, along with the request to download the file. However, the code involved in this solution is beyond the scope of this book.
