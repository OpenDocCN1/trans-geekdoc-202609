# Date and Time Functions

```
DAYOFWEEK(date)
```

Returns the weekday of date in the form of an integer, according to the ODBC standard (1 = Sunday, 2 = Monday, 3 = Tuesday, ... 7 = Saturday).

```
WEEKDAY(date)
```

Returns the weekday of date in the form of an integer (0 = Monday, 1 = Tuesday, 2 = Wednesday, ... 6 = Sunday).

```
DAYOFMONTH(date)
```

Returns the day of the month for date (from 1 to 31).

```
DAYOFYEAR(date)
```

Returns the day of the year for date (from 1 to 366 - remember leap years!).

```
MONTH(date)
```

Returns the month for date (from 1, January, to 12, December).

```
DAYNAME(date)
```

Returns the name of the day of the week for date (e.g. "Tuesday").
