SHOW STATUS [LIKE wild]

Displays detailed statistics for the server. See the MySQL Reference Manual for details on the meaning of each of the figures.

```
SHOW VARIABLES [LIKE wild]
```

Lists the MySQL configuration variables and their settings. See the MySQL Reference Manual for a complete description of these options.

```
SHOW [FULL] PROCESSLIST
```

Displays all threads running on the MySQL server, and the queries being executed by each. If you don’t have the ‘process’ privilege, you will only see threads executing your own queries. The FULL option causes the complete queries to be displayed, rather than only the first 100 characters of each (the default).

```
SHOW GRANTS FOR user
```

Lists the GRANT queries that would be required to re-create the privileges of the specified user.

```
SHOW CREATE TABLE table_name
```

Displays the CREATE TABLE query that would be required to reproduce the specified table.

## UPDATE

```
UPDATE [LOW_PRIORITY] [IGNORE] tbl_name
SET col_name=expr, ...
[WHERE where_definition]
[ORDER BY ...]
[LIMIT #]
```

The UPDATE query updates existing table entries by assigning new values to the specified columns. Columns that are not listed are left alone, with the exception of the TIMESTAMP column (see page 219).

The WHERE clause lets you specify a condition (where_definition) that rows must satisfy if they are to be updated, while the LIMIT clause lets you specify a maximum number of rows to be updated. IMPORTANT: If WHERE and LIMIT are not specified, then every row in the table will be updated!

The ORDER BY clause lets you specify the order in which entries are updated. This is most useful in combination with the LIMIT clause - together they let you create queries like “update the 10 most recent rows”.

An UPDATE operation will fail with an error if the new value assigned to a row clashes with an existing value in a PRIMARY KEY or UNIQUE column unless the IGNORE option is specified, in which case the query will simply have no effect on that particular row.

The LOW_PRIORITY option instructs MySQL to wait until there are no other clients reading the table before it performs the update.

## USE

```
USE db_name
```

This simple query sets the default database for MySQL queries in the current session. Tables in other databases may still be accessed as db_name.tbl_name.

## MySQL Functions

MySQL provides a sizeable library of functions to format and combine data within SQL queries in order to produce the desired results in the desired format. This appendix provides a reference to the most useful of these functions, as implemented in MySQL as of version 3.23.39 (current as of this writing).

For a complete, up-to-date reference to supported SQL functions, see the MySQL Reference Manual at http://www.mysql.com.

### Control Flow Functions

`IFNULL(expr1,expr2)`

Returns expr1 unless it is NULL, in which case it returns expr2.

`NULLIF(expr1,expr2)`

Returns expr1 unless it equals expr2, in which case it returns NULL.

`IF(expr1,expr2,expr3)`

If expr1 is TRUE (that is, not NULL or 0), returns expr2; otherwise, returns expr3.

`CASE value WHEN [compare-value] THEN result [WHEN ...] [ELSE result] END`

Returns result when value=compare-value (note that several compare-value/result pairs can be defined); otherwise, returns the ELSE result, or NULL if none is defined.

`CASE WHEN [condition] THEN result [WHEN ...] [ELSE result] END`

Returns result when condition is TRUE (note that several condition/result pairs can be defined); otherwise, returns the ELSE result, or NULL if none is defined.

### Mathematical Functions

`ABS(expr)`

Returns the absolute (positive) value of `expr`.

`SIGN(expr)`

Returns -1, 0, or 1 depending on whether `expr` is negative, zero, or positive, respectively.

`MOD(expr1, expr2)`

Returns the remainder of dividing `expr1` by `expr2`.

`FLOOR(expr)`

Rounds down `expr` (i.e. returns the largest integer value that is less than or equal to `expr`).

`CEILING(expr)`

Rounds up `expr` (i.e. returns the smallest integer value that is greater than or equal to `expr`).

`ROUND(expr)`

Returns `expr` rounded to the nearest integer. Note that the behavior when the value is exactly an integer plus 0.5 is system dependant. Thus, you should not rely on any particular outcome when migrating to a new system.

`ROUND(expr, num)`

Rounds `expr` to a number with `num` decimal places, leaving trailing zeroes in place. Use `num=2`, for example, to format a number as dollars and cents. Note that the same uncertainty about the rounding of 0.5 applies as discussed for `ROUND()` above.

`EXP(expr)`

Returns `e^expr`, the base of natural logarithms raised to the power of `expr`.

`LOG(expr)`

Returns `ln(expr)`, or `log_e(expr)`, the natural logarithm of `expr`. Remember, a log with an arbitrary base B can be calculated as `LOG(expr)/LOG(B)`.

`LOG10(expr)`

Returns the base-10 logarithm of `expr`.

`POW(expr1,expr2)`
`POWER(expr1,expr2)`

Returns expr1 raised to the power of expr2.

`SQRT(expr)`

Returns the square root of expr.

`PI()`

Returns the value of π (pi).

`COS(expr)`

Returns the cosine of expr in radians (e.g. COS(PI()) = -1).

`SIN(expr)`

Returns the sine of expr in radians (e.g. SIN(PI()) = 0).

`TAN(expr)`

Returns the tangent of expr in radians (e.g. TAN(PI()) = 0).

`ACOS(expr)`

Returns the arc cosine (cos-1 or inverse cosine) of expr (e.g. ACOS(-1) = 3.141593).

`ASIN(expr)`

Returns the arc sine (sin-1 or inverse sine) of expr (e.g. ASIN(0) = 3.141593).

`ATAN(expr)`

Returns the arc tangent (tan-1 or inverse tangent) of expr (e.g. ATAN(0) = 3.141593).

`ATAN2(expr1,expr2)`

Converts the angle made at the origin between the positive x axis and the point (expr1,expr2).

`COT(expr)`

Returns the cotangent of expr.

`RAND()`
`RAND(expr)`

Returns a random floating point number between 0.0 and 1.0. If expr is specified, a random number will be generated based on that value, which will always be the same.

`LEAST(expr1,expr2,...)`

Returns the smallest of the values specified. In MySQL version 3.22.5 or earlier, you must use MIN() instead.

`GREATEST(expr1,expr2,...)`

Returns the largest of the values specified. In MySQL version 3.22.5 or earlier, you must use MAX() instead.

`DEGREES(expr)`

Returns the value of expr (in radians) in degrees.

`RADIANS(expr)`

Returns the value of expr (in degrees) in radians.

`TRUNCATE(expr,num)`

Returns the value of floating point number expr truncated to num decimal places (i.e. rounded down).

### String Functions

`ASCII(str)`

Returns the ASCII code value of the leftmost character in str, 0 if str is an empty string, or NULL if str is NULL.

`ORD(str)`

Returns the ASCII code of the leftmost character in str, taking into account the possibility that it might be a multi-byte character.

`CONV(expr, from_base, to_base)`

Converts a number (expr) in base from_base to a number in base to_base. Returns NULL if any of the arguments are NULL.

`BIN(expr)`

Converts expr to binary, equivalent to CONV(expr,10,2).

`OCT(expr)`

Converts expr to octal, equivalent to CONV(expr,10,8).

`HEX(expr)`

Converts expr to hexadecimal, equivalent to CONV(expr,10,16).

`CHAR(expr, ...)`

Creates a string composed of characters, the ASCII code values of which are given by the expressions passed as arguments.

`CONCAT(str1,str2,...)`

Returns a string made up of the strings passed as arguments joined end-to-end. If any of the arguments are NULL, NULL is returned instead.

`CONCAT_WS(separator,str1,str2,...)`

CONCAT "With Separator" (WS). Same as CONCAT, except the first argument is placed between each of the additional arguments when they are combined.

`LENGTH(str)`
`OCTET_LENGTH(str)`
`CHAR_LENGTH(str)`
`CHARACTER_LENGTH(str)`

All of these return the length in characters of str. CHAR_LENGTH and CHARACTER_LENGTH, however, take multi-byte characters into consideration when performing the count.

`LOCATE(substr,str)`
`POSITION(substr IN str)`

Returns the position of the first occurrence of substr in str (1 if it occurs at the beginning, 2 if it starts after one character, and so on). Returns 0 if substr does not occur in str.

`LOCATE(substr,str,pos)`

Same as LOCATE(substr,str), but begins searching from character number pos.

`INSTR(str,substr)`

Same as LOCATE(substr,str), but with argument order swapped.

`LPAD(str,len,padstr)`

Shortens or lengthens str so that it is of length len. Lengthening is accomplished by inserting padstr to the left of the characters of str (e.g. LPAD("!","5",".") = ".....!").

`RPAD(str,len,padstr)`

Shortens or lengthens str so that it is of length len. Lengthening is accomplished by inserting padstr to the right of the characters of str (e.g. RPAD("!","5",".") = "!.....").

`LEFT(str,len)`

Returns the leftmost len characters of str. If str is shorter than len characters, str is returned with no extra padding.
