# POW(expr1,expr2)
POWER(expr1,expr2)

Returns expr1 raised to the power of expr2.

# SQRT(expr)

Returns the square root of expr.

# PI()

Returns the value of π (pi).

# COS(expr)

Returns the cosine of expr in radians (e.g. COS(PI()) = -1).

# SIN(expr)

Returns the sine of expr in radians (e.g. SIN(PI()) = 0).

# TAN(expr)

Returns the tangent of expr in radians (e.g. TAN(PI()) = 0).

# ACOS(expr)

Returns the arc cosine (cos-1 or inverse cosine) of expr
(e.g. ACOS(-1) = 3.141593).

# ASIN(expr)

Returns the arc sine (sin-1 or inverse sine) of expr
(e.g. ASIN(0) = 3.141593).

# ATAN(expr)

Returns the arc tangent (tan-1 or inverse tangent) of expr
(e.g. ATAN(0) = 3.141593).

# ATAN2(expr1,expr2)

Converts the angle made at the origin between the positive x axis and
the point (expr1,expr2).

# COT(expr)

Returns the cotangent of expr.

# RAND()
RAND(expr)

Returns a random floating point number between 0.0 and 1.0. If
expr is specified, a random number will be generated based on that
value, which will always be the same.
