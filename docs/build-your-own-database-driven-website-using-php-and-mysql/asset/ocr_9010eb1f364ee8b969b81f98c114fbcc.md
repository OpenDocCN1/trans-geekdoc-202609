# Mathematical Functions

`ABS(expr)`
Returns the absolute (positive) value of `expr`.

`SIGN(expr)`
Returns -1, 0, or 1 depending on whether `expr` is negative, zero, or positive, respectively.

`MOD(expr1, expr2)`
Returns the remainder of dividing `expr1` by `expr2`.

`FLOOR(expr)`
Rounds down `expr` (i.e. returns the largest integer value that is less than or equal to `expr`).

`CEILING(expr)`
Rounds up `expr` (i.e. returns the smallest integer value that is greater than or equal to `expr`).

`ROUND(expr)`
Returns `expr` rounded to the nearest integer. Note that the behavior when the value is exactly an integer plus 0.5 is system dependant. Thus, you should not rely on any particular outcome when migrating to a new system.

`ROUND(expr, num)`
Rounds `expr` to a number with `num` decimal places, leaving trailing zeroes in place. Use `num=2`, for example, to format a number as dollars and cents. Note that the same uncertainty about the rounding of 0.5 applies as discussed for `ROUND()` above.

`EXP(expr)`
Returns `e^expr`, the base of natural logarithms raised to the power of `expr`.

`LOG(expr)`
Returns `ln(expr)`, or `log_e(expr)`, the natural logarithm of `expr`. Remember, a log with an arbitrary base B can be calculated as `LOG(expr)/LOG(B)`.

`LOG10(expr)`
Returns the base-10 logarithm of `expr`.
