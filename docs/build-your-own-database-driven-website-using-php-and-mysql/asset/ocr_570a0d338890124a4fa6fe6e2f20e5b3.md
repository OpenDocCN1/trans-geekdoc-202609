# The Complete Script

Below you'll find the complete example script. This combines all the elements given above with some simple code that will list the files in the database and allow them to be deleted. As always, this file is available in the code archive (located at http://www.sitepoint.com/books/).

As you look at the code, you may notice two spots where I’ve used this command:

```
header("Location: $PHP_SELF");
```

As described above, the header function sends an HTTP header to the browser. We’ve seen the content-type, content-length, and content-disposition headers already. The above line sends a location header, which redirects the browser to the specified URL. As it specifies $PHP_SELF as the URL, this line redirects the browser to the same page.

“What’s the point of that?” you might wonder. Well, I use this line after the script adds or deletes a file in the database. In such cases, the action - add or delete - is specified by a query string in the page’s URL. If the script simply took the requested action and immediately displayed the updated list of files, the user could inadvertently repeat that action by refreshing the page! To avoid this kind of error, we instead re-direct the browser after it completes each action to a url that’s identical in every way, except that it doesn’t contain a query string ($PHP_SELF). Thus, the user can refresh the file list that’s produced with no ill effects.
