# TIME_FORMAT(time, format)

Same as DATE_FORMAT, except the format string may only contain symbols referring to hours, minutes, and seconds.

# CURDATE()
CURRENT_DATE

Returns the current system date in the SQL date format "YYYY-MM-DD" (if used as a date) or as YYYYMMDD (if used as a number).

# CURTIME()
CURRENT_TIME

Returns the current system time in the SQL time format "HH:MM:SS" (if used as a time) or as HHMMSS (if used as a number).

# NOW()
SYSDATE()
CURRENT_TIMESTAMP

Returns the current system date and time in SQL date/time format "YYYY-MM-DD HH:MM:SS" (if used as a date/time) or as YYYYMMDDHHMMSS (if used as a number).

# UNIX_TIMESTAMP()
UNIX_TIMESTAMP(date)

Returns either the current system date and time, or the specified date/time as the number of seconds since 1970-01-01 00:00:00 GMT.

# FROM_UNIXTIME(unix_timestamp)

The opposite of UNIX_TIMESTAMP(), converts a number of seconds from 1970-01-01 00:00:00 GMT to "YYYY-MM-DD HH:MM:SS" (if used as a date/time) or YYYYMMDDHHMMSS (if used as a number), local time.

# TO_DAYS(date)

Converts date to a number of days since year 0. Allows you to calculate differences in dates (i.e. TO_DAYS(date1) - TO_DAYS(date2) = days_in_between).

# FROM_DAYS(days)

Given the number of days since year 0 (as produced by TO_DAYS), returns a date.
