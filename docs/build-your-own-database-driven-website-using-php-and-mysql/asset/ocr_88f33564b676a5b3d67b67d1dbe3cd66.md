RENAME TABLE query that fails to complete halfway through will be automatically reversed, so that the original state is restored.

# REPLACE

```
REPLACE [LOW_PRIORITY | DELAYED] [IGNORE] [INTO] tbl_name
{ [(col_name, ...)] VALUES (expression, ...), ...
| [(col_name, ...)] SELECT ...
| SET col_name=expression, col_name=expression, ... }
```

REPLACE is identical to INSERT, except that if an inserted row clashes with an existing row in a PRIMARY KEY or UNIQUE column, the old entry is replaced with the new.

# REVOKE

```
REVOKE priv_type [(column_list)], ...
ON {tbl_name | * | *.* | db_name.*}
FROM user_name, ...
```

Removes access privileges from a user account. If all privileges are removed form an account, the user will still be able to log in, though he or she simply won’t be able to access any information.

See page 116 for a complete description of this query.

# SELECT

```
SELECT [select_options]
select_expression, ...
[INTO {OUTFILE | DUMPFILE} 'file_name' export_options]
[FROM table_refs
[WHERE where_definition]
[GROUP BY {col_name | col_pos } [ASC | DESC], ...]
[HAVING where_definition]
[ORDER BY {col_name | col_pos } [ASC | DESC], ...]
[LIMIT [offset,] rows]]
```
