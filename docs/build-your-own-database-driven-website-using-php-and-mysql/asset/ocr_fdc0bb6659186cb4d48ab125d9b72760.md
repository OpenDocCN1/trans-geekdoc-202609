Sends a MySQL query to the currently selected database. Works the same as
mysql_db_query() except that it does not change databases first. See the
description of that function on page 223 for more information.

# mysql_unbuffered_query

```
mysql_unbuffered_query(query [,link_id [,result_mode]])
```

Sends an SQL query to MySQL, without fetching or buffering the result rows
automatically, as mysql_query() and mysql_db_query() do. This has
two advantages: PHP does not need to allocate a large memory buffer to store
the entire result set, and you can begin to process the results as soon as PHP
receives the first row, instead of having to wait for the full result set to be
received.

The downside is that functions that require information about the full result
set (such as mysql_num_rows() are not available for result sets produced
by mysql_unbuffered_query(), and you must use mysql_fetch_*
functions to retrieve all of the rows in the result set before you can send
another query using that MySQL connection.

# mysql_result

```
mysql_result(result_id, row [,field])
```

Returns the value of a particular field of the specified row (row) of the
specified result set (result_id). The field argument may be the name of
the field (either fieldname or dbname.fieldname), or its numerical
position, where the first field in a row is at position 0. If field is not
specified, then 0 is assumed.

# mysql_select_db

```
mysql_select_db(db_name [,link_id])
```

Selects the default database (db_name) for the current or specified (link_id)
MySQL connection. mysql_selectdb() may also be used, but is
deprecated.
