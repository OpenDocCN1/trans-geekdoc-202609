CONCAT(str1,str2,...)

Returns a string made up of the strings passed as arguments joined end-to-end. If any of the arguments are NULL, NULL is returned instead.

CONCAT_WS(separator,str1,str2,...)

CONCAT "With Separator" (WS). Same as CONCAT, except the first argument is placed between each of the additional arguments when they are combined.

LENGTH(str)
OCTET_LENGTH(str)
CHAR_LENGTH(str)
CHARACTER_LENGTH(str)

All of these return the length in characters of str. CHAR_LENGTH and CHARACTER_LENGTH, however, take multi-byte characters into consideration when performing the count.

LOCATE(substr,str)
POSITION(substr IN str)

Returns the position of the first occurrence of substr in str (1 if it occurs at the beginning, 2 if it starts after one character, and so on). Returns 0 if substr does not occur in str.

LOCATE(substr,str,pos)

Same as LOCATE(substr,str), but begins searching from character number pos.

INSTR(str,substr)

Same as LOCATE(substr,str), but with argument order swapped.

LPAD(str,len,padstr)

Shortens or lengthens str so that it is of length len. Lengthening is accomplished by inserting padstr to the left of the characters of str (e.g. LPAD("!","5",".") = ".....!").

RPAD(str,len,padstr)

Shortens or lengthens str so that it is of length len. Lengthening is accomplished by inserting padstr to the right of the characters of str (e.g. RPAD("!","5",".") = "!.....").

LEFT(str,len)

Returns the leftmost len characters of str. If str is shorter than len characters, str is returned with no extra padding.
