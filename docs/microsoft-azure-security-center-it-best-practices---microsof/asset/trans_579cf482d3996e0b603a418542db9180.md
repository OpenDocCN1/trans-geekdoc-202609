## Azure Storage 高级威胁保护

当你为 Azure Storage 启用高级威胁保护 (ATP) 时，发生异常访问和数据外泄活动时，你可以通过警报收到通知。这些警报包括此类检测，例如：

- 从异常位置访问
- 异常数据提取
- 异常的匿名访问
- 意外删除
- 访问权限更改
- 上传 Azure 云服务包

你只需在想要保护的存储账户上将其“开启 (ON)”，即可启用此功能，如图 1-11 所示。Azure 警报的高级威胁保护 (ATP) 将流到 Azure 安全中心，允许你在一个位置保留所有与安全相关的警报。

## 身份

Azure 身份保护是 Azure Active Directory (AD) 的一部分，因为它能够检测潜在的身份相关漏洞以及与用户身份相关的可疑操作而被广泛使用；它也因其调查事件的能力而被广泛使用。Azure AD 身份保护警报也将流到 Azure 安全中心。

> **重要** 有关 Azure AD 身份保护的详情，请访问 http://aka.ms/AzureADIdentityProtection。

## Azure 安全中心简介

鉴于第 1 章介绍的威胁格局，显然需要一个能够统一安全管理，并为运行在 Azure、本地和其他云提供程序的工作负载提供高级威胁保护的系统。

Azure 安全中心为组织提供了混合云工作负载安全的完全可见性和控制，包括计算、网络、存储和应用程序工作负载。通过积极监控这些负载，安全中心增强了云部署的整体安全态，并减少了资源面临威胁的风险。安全中心还利用智能威胁检测帮助你保护环境免受快速演变的网络攻击。

安全中心不仅检测威胁。它还会评估你的混合云工作负载的安全性并提供建议以缓解威胁。它还提供集中的策略管理，以确保符合公司或监管要求。

在本章中，你将学习如何在安全操作中使用安全中心、采用时的关键考虑以及如何入站资源。

## 部署场景

随着企业开始云端之旅，他们将在尝试将本地工具适配到云端模型时面临许多挑战。在由于有不同工具需要管理的云环境中，确保验证和纠正措施是至关重要的，以确保这些工作负载的安全态始终处于可能的最高水平。

安全中心具有多种功能，可用于两类云解决方案：

- 云安全态势管理 (CSPM)：CSPM 允许组织评估其云基础设施，以确保符合行业合法规，并帮助识别其云工作负载中的安全漏洞。
- 云工作负载保护平台 (CWPP)：CWPP 允许组织评估其云工作负载的风险，并检测针对其基础设施即服务 (IaaS)、容器、平台即服务 (PaaS) 数据库和存储的威胁。它还允许组织识别错误配置并使用安全最佳实践配置进行修复。

## 理解 Azure 安全中心

由于 Azure 安全中心是一项 Azure 服务，你必须拥有 Azure 订阅才能使用它——即使只是试用订阅。

拥有 Azure 订阅会自动启用安全中心的免费层。此免费层监控 Azure 中的计算、网络、存储、身份、IoT 和应用程序资源。它还提供安全策略、安全评估和安全建议，并允许你与其他安全合作伙伴解决方案连接。即使是从在 Azure 中开始使用 IaaS 的组织也可以从此免费服务中受益，因为它将提高他们的安全态。

除了免费层外，安全中心还提供基于付费的标准层。该层为需要更多控制的组织提供完整的安全功能。具体来说，将你的安全中心订阅从免费层迁移到标准层将启用以下功能：

- 安全事件收集
- 网络地图
- 即时虚拟机访问
- 自适应应用程序控制（应用程序白名单）
- 监管合规报告
- 文件完整性监控
- 网络安全组 (NSG) 加固
- 安全警报
- 威胁情报
- 剧本

标准层的另一个优势是它允许你监控本地服务器和由其他云供应商托管的虚拟机。你通过在目标机器上手动安装安全代理来实现这一点（本将在稍后部分进行详细介绍）。

当你升级到标准层时，可以免费使用 30 天。这是一个评估这些功能、查看你的当前环境将从中受益并决定它们是否值得投入的的好机会。有关 Azure 安全中心定价的最新信息，请访问 http://aka.ms/aspricing。在这 30 天内，我们建议通过概念验证 (PoC) 验证你需要的所有场景。阅读有关如何有效地执行 Azure 安全中心 PoC 的文章以获取更多信息 http://aka.ms/ascpoc。
