The output of this assessment is a series of recommendations that will vary according to the type of resources that the subscription has. There are situations in which a recommendation may not be applicable for your scenario. For example, Security Center might recommend that you enable Multi-Factor Authentication (MFA), but this wouldn't be helpful if you are already using a third-party MFA in your environment. Because Security Center doesn't take into consideration the third-party implementation of MFA, this recommendation becomes a false positive. To disable a particular recommendation, follow these steps:

+   1. Open the Azure Portal and sign in with a user who has Security Admin privileges.
2. In the left navigation pane, click Security Center.
3. In the Security Center left navigation pane, click Security Policy.
4. On the Policy Management blade, click in the subscription that you want to change policy and the Policy blade appears, as shown in Figure 3-5. (Note that the Subscription ID has been hidden.)
