For machines located on-premises or in different cloud providers, the onboarding process is basically the same; the only difference is that you will need to manually install the MMA on the target machine. To enable this integration, follow the steps below:

+   1. Open the Security Center

+   2. In the left pane under Policy & Compliance, click Security Policy.

+   3. Click Edit Settings for the subscription that you want to enable this integration.

+   4. Under Settings, click Threat Detection, the Enable Integrations blade appears.

+   5. Select the Allow Windows Defender ATP to Access My Data option and click Save. Once the integration is enabled and the servers are fully onboarded, the Windows Defender ATP sensing on the server will report telemetry to the Microsoft Defender ATP cloud service. Once an indicator of attack is triggered by Microsoft Defender ATP, an alert is published in Security Center and in the workspace (see Figure 9-2).
