# 4. The Azure Security Center for IoT settings page appears, as shown in Figure 7-4.

![](bbox=[0.115, 0.05335, 0.835, 0.6233500000000001])

**FIGURE 7-4** Configuring the initial settings to enable Security Center for IoT

5. Click the Enable button, select the **Subscription** that you want to monitor, and the **Workspace** on which the data should be stored. Security Center for IoT will store recommendations and alerts in this workspace. You can also control whether twin metdata collection should be performed and whether you want to store raw device security events in the workspace.

6. Click **Save.**

7. After saving it, the **Overview** page appears. You may need to refresh the page to see the current status, which should be similar to the example shown in Figure 7-5 for a brand new IoT deployment.
