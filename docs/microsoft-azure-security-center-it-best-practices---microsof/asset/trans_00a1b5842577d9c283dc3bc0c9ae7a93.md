

## 集中式管理

负载所有者通常需要管理特定的云工作负载及其相关资源。此外，负载所有者还负责根据公司安全策略实施并维护保护措施。由于这些要求，将安全管理员（Security Admin）角色分配给工作负载的所有者是合适的。

**重要** 只有订阅所有者、贡献者安全管理员可以编辑安全策略。只有订阅所有者、资源组所有者和资源组贡献者可以为资源应用安全建议。要了解更多关于 Azure 中基于角色的访问控制 (RBAC)，请参阅 http://aka.ms/azurerbac。

拥有不同业务部门且以非协作方式采用 Azure 的大型组织在尝试采用安全中心（Security Center）时可能会遇到挑战，因为它们无法看到其租户下的所有订阅。因此，在启用安全中心之前，你需要与 IT 团队协作，识别属于该租户的所有订阅，并验证你是否有权管理安全中心。在某些情况下，同一家公司可能拥有多个租户，每个租户上都有不同的订阅。

当多个订阅属于同一个租户，且你需要在跨订阅集中管理策略时，可以使用 Azure 组（Management Groups）。通过将多个订阅聚合到管理组下，你可以在管理组上创建一个基于角色的访问控制 (RBAC) 分配，该权限将继承到所有订阅。这节省了管理时间，因为你可以让用户访问所需的所有内容，而不是在不同的订阅之间编写脚本来处理 RBAC。安全中心还支持将安全策略分配给管理组。

在计划采用安全中心时，请确保确定需要监控的内容。你必须确定安全中心提供的默认策略是否足够你的组织使用，或者你是否需要创建新的定义。你将在第 3 章“策略管理”中学习更多关于安全策略的知识。

## 建议

安全中心将识别需要安全建议的资源（计算、网络、存储、身份、IoT 和应用程序），并将自动建议更改。你可以在一个地方看到所有建议，这些位于“资源安全防护/建议”（Resource Security Hygiene / Recommendations）下，如图 2-6 所示；或者你可以按类别单独查看。在计划采用安全中心时，确保在探索安全中心的更多功能之前，对所有建议进行一次全面的复审。你应该使用安全中心的安全评分（Security score）来确定需要处理的建议的优先级。你将在第 4 章“增强你的安全态”中学习更多关于安全评分的知识。

## 自动化

可以使用 Azure 资源管理器 (ARM) 模板和 PowerShell 实现安全中心部署和配置的自动化。在附录 A “规模化管理安全中心”中，你将学习更多关于使用 ARM 模板进行安全中心大规模部署的知识。在本章后面的部分，你将学习如何使用 PowerShell 进行任务自动化。

## 将安全中心整合到你的安全运营中

你的 IT 安全部门和 IT 运营部门不断协作以提供更好的保护、检测和响应至关重要。安全运营 (SecOps) 描述了这种支持功能。许多组织已经拥有专门的 SecOps 团队来维护公司资产的安全运营。

在使用安全中心监控资源之前，你必须审查组织的 SecOps流程，并识别如何将安全中心整合到日常工作中。图 2-7 显示了典型安全运营中心 (SOC) 执行的任务，以及哪些安全中心功能可以协助这些任务。

![](img/4b11e95292819ab1a383a41ef73aedb4_49_0.png)

图 2-7 安全中心安全运营映射

以下是将安全中心整合到你的安全运营中的关键点：

- 安全中心将持续评估计算、网络、存储、身份、IoT 和应用程序资源的合规性。负责持续安全评估的团队应持续跟踪并应用安全中心发布的建议。
- 安全中心提供的安全角色——结合 Azure 的 RBAC 能力——可以帮助 SOC 管理控制谁有权访问什么。
- 事件响应 (IR) 团队可以在攻击的检测和分拣阶段使用安全告警和事件功能，对事件进行早期评估。如果需要对攻击进行更深入的研究，团队可以使用安全中心的调查和搜索功能。最后，当团队准备好进行响应时，可以使用安全剧本（Security Playbook）功能对特定告警进行自定义响应。

**重要** 在虚拟机 (VMs) 上进行的安全评估还将检查安全配置是否存在。此安全配置基于 CCE（通用配置）规则。这些规则可以在 https://aka.ms/asccerules 下载。

在将安全中心作为 SecOps 的一部分时，另一个重要的考虑因素是建立负责审查这些告警的团队将如何消费这些数据。某些组织可能已经将安全信息和事件管理 (SIEM) 系统作为其安全运营的一部分，它们可能不想引入新的工具。

为了充分利用安全中心的所有功能，你首先需要将订阅升级到标准层。你可以通过查看“概述”（Overview）仪表板中的订阅覆盖情况来查看订阅的当前状态。

![](img/4b11e95292819ab1a383a41ef73aedb4_50_0.png)
