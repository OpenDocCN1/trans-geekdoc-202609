At Microsoft, we have Incident Response and Threat Analysis teams that go through these large amounts of data from different offerings as part of their jobs. Azure Sentinel brings Microsoft's knowledge and capabilities, both from specific detections and queries to the cloud-scale automation. Some of these include the following:

+   - Investigation visualization. While it's great to have access to all the data in a form that can be queried, it's sometimes more effective to have a visual representation of the attack and the relationship between different entities and events. Azure Sentinel provides graph visualizations to show insights, timelines, and relationships at a glance. Now, so can defenders.

+   - Proactive hunting. While alerts and ML models are powerful ways of identifying and investigating potential compromises, we know that sometimes you need to look through the data for suspicious activity. We've worked closely with the teams that do proactive hunting at Microsoft to provide a set of queries and Azure Notebooks that are the starting point of those hunts.

+   - Automated Remediation. By integrating with Azure Logic Apps, you can automate the remediation actions. Azure Logic Apps has many connectors already available, so there are many actions available to you. For example, you can do any of the following:

+   - You can create or update a ticket in your Case Management system.
- You can send a notification to your team's Slack or Teams channel.
- You can block an IP from your firewall.

+   - You can request a multi-factor authentication for a user. You can also combine all these actions.

+   - GitHub community. Azure Sentinel has a GitHub community where we will continue to provide detections, hunting queries, Azure Notebooks, parsers, and dashboards. And so can you.

Azure Sentinel reduces the time it takes to understand what's happening in your environment, prioritize where you need to act first, and determine the right remediation. We have just started this journey, and we look forward to your feedback and input.
