Because each subscription has its own policy, there will be scenarios for which you want to deploy a single policy for multiple subscriptions. When this occurs, you can use Azure management group. The idea is that you can organize subscriptions into containers (called "management groups") and apply your governance conditions to the management groups, as shown in Figure 3-8. For more information on how to manage policy at scale, see Appendix A, "Managing Security Center at Scale."
