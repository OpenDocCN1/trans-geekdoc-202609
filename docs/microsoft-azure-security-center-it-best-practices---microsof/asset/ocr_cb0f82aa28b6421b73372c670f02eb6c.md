When you enable ATP for Azure Storage, you will be able to identify attacks under the following conditions:

+   - When there is a change in the access pattern to a storage account
- When there is an unusually large amount of data getting extracted compared to recent activity on this storage account
- When an unexpected deletion occurs in a storage account
- When unusual storage enumeration occurs
- When usual changes to the storage account occurs
