# IoT security

IoT solutions can be divided into four, security-relevant zones—Device, Field Gateway, Cloud gateways, and Applications. Managing and monitoring of the IoT solution requires addressing the security of all four zones.

Azure Security Center for IoT unifies security posture and threat detection across an entire IoT solution, from low resource leaf devices, field gateways, and all the way to the service device of cloud gateways. It does this by delivering unified visibility and control, adaptive threat prevention, and intelligent threat detection and response across IoT workloads that run on Edge, on-premises, and on Azure and other clouds.

Because of its immense density and scale, IoT introduces unique security challenges as well as opportunities. IoT devices are deployed and managed at scale behavior. This combined with AI allows deep modeling of device routine behavior. Azure Security Center for IoT uses seamless integration with Azure resources to trace and model IoT devices and identify any deviation from routine behavior. It enables real-time impact on customer business logic by allowing automatic workflows to take security into account. For example, it prevents a rogue sensor from causing the entire system to malfunction by flagging it as potentially malicious or malfunctioning.

For devices that play a critical role in the IoT solution, Azure Security Center for IoT offers a set of open source security agents. Security agents are designed to work in a constrained IoT environment, and they are highly customizable in terms of value they provide when compared to the resources they consume. They allow enhanced security capabilities, such as monitoring remote connections, active applications, login events, and OS best practices.

# Configuring Security Center for IoT

To enable Security Center for IoT, you need to have an Azure IoT Hub already operational. If you don't have an operational Azure IoT Hub, use the steps found at http://aka.ms/AzureloTDeployment to create an IoT Hub, an IoT Edge, and install an IoT Edge Simulation device. After the Azure IoT environment is fully configured, follow the steps below to enable Security Center for IoT.

# Monitoring alerts

The data received by Security Center for IoT will also be used to trigger alerts when necessary. Security Center for IoT uses advanced analytics and threat intelligence to generate alerts about malicious activity. An alert is an indication of compromise or attack; therefore, alerts should be investigated and remediated. Some of the built-in alerts include:

- Binary Command Line
- Disable on-host firewall
- Reverse shells
- Suspicious IP address communication
- Crypto coin miner

Besides the built-in alerts, you can also create custom alerts based on your knowledge of expected device behavior.
