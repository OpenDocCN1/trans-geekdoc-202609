# # Integration SQL ATP

Security Center integration with SQL Advanced Threat Protection (ATP) provides a new layer of security to help customers to detect and respond to potential threats, such as suspicious database activities, potential vulnerabilities, and SQL injection attacks, as well as anomalous database access and queries patterns.

This integration makes it simple to address potential threats to the database without needing to be an expert or manage advanced security monitoring systems. When SQL ATP is enabled, the following alerts will be available:

+   - **Vulnerability To SQL Injection**: This alert may indicate a possible vulnerability to SQL injection attacks.
- **Potential SQL Injection**: This alert is triggered when an active exploit happens against an identified vulnerability to SQL injection.
- **Access From Unusual Location**: This alert is triggered when there is a change in the access pattern to SQL server; for example, this alert would be triggered when someone has logged on to the SQL server from an unusual geographical location.
- **Access From Unusual Azure Data Center**: This is another alert that is triggered based on changes in access pattern to SQL server. However, in this case, it occurs when someone has logged on to the SQL server from an unusual Azure data center that was not seen during the recent period.
- **Access From Unfamiliar Principal**: This is another alert that is triggered based on changes in access patterns to the SQL server, but this scenario applies to a situation in someone has logged on to the SQL server using an unusual principal (SQL user).
- **Access A Potentially Harmful Application**: This alert is triggered when a potentially harmful application is used to access the database.
- **Brute Force SQL Credentials**: This alert is triggered when there is an abnormally high number of failed logins with different credentials.
