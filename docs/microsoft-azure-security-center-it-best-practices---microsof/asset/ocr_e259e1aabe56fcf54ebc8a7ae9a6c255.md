7. After selecting Disabled for the recommendation that is not applicable to your scenario, click the Save button, which is located at the bottom of this page.

8. Once the change is committed, go back to Security Center Overview page.

Now that the recommendation has changed, you may need to wait for the dashboard to refresh. Security Center typically scans for new data every hour and refreshes the recommendations accordingly. Some other items in the dashboard may take a little longer to update:

+   * Operating system security configurations: up to 48 hours
* System updates: up to 24 hours
* Endpoint Protection issues: up to 8 hours
