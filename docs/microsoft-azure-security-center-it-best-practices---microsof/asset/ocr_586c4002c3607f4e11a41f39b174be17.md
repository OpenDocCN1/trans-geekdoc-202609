Also, these alerts leverage additional data that already exists in the MCAS detection engine to help speed up the investigation process and contain ongoing threats. To enable this integration, follow these steps:

+   1. Open the Security Center dashboard.
2. In the left pane under **Policy & Compliance**, click **Security Policy**.
3. Click **Edit settings** for the subscription on which you want to enable this integration.
4. Under **Settings**, click **Threat Detection**: the **Enable Integrations** blade appears.
5. Select the **Allow Microsoft Cloud App Security To Access My Data option** and click **Save**.

This integration will enable the following alerts to be surfaced in the Security Alerts dashboard in Security Center:

+   * Impossible Travel
* Activity From Infrequent Country
* Activity From Anonymous IP Address
