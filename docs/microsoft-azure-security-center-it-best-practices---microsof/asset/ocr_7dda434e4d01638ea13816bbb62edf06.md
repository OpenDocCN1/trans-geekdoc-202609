Security Center for IoT automatically identifies other Azure services that are also connected to your IoT Hub and related to your IoT solution. # Security recommendations

Security Center scans your Azure resources and IoT devices to provide security recommendations. By remediating these recommendations, you reduce your attack surface and automatically increase your Secure Score. To see the security recommendations for IoT, open the Security Center dashboard under Resource Security Hygiene and click IoT hubs & resources.
