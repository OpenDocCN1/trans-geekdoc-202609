As explained previously, the agent will collect information and send it to the workspace. If you are using the Standard tier, you have up to 500 MB per day across nodes. If the uploaded data exceeds 500MB per day, additional charges will apply.

When planning Security Center adoption, consider the fact that workspaces that were created by Security Center have the data retained for 30 days. For existing workspaces, retention is based on the workspace pricing tier.

# Recommendations

Security Center will identify resources (compute, network, storage, identity, IoT and applications) that need security recommendations, and it will automatically suggest changes. You can see all recommendations in a single place, which is available under Resource Security Hygiene / Recommendations, as shown in Figure 2-6, or you can see them individually, by category. When planning your Security Center adoption, make sure to include a full revision of all recommendations before exploring more capabilities in Security Center. You should use Security Center’s Security score to prioritize which recommendations should be addressed. You will learn more about Secure Score in Chapter 4, "Strengthen your security posture."
