Azure Policy provides you with governance controls for your Azure environment. It can stop (deny) from creating non-compliant resources, and it can audit compliance (audit and auditIfNotExists). It can even remediate (deployIfNotExists) non-compliant resources, either upon creation or for existing resources. The Azure Policy definition example shown in Figure A-2 stops the creation of websites in Azure that are not HTTPS enabled.
