# # Unified Endpoint Detection and Response (EDR)

Microsoft Defender Advanced Threat Protection (Microsoft Defender ATP) is a unified security platform that provides endpoint protection platform (EPP) and endpoint detection and response (EDR) capabilities for Windows clients, Windows Server, and third-party systems like Mac OS. In Windows, Server Microsoft Defender ATP is deeply integrated with Azure Security Center, which ensures that organizations maximize the usage of their existing Microsoft security investments. With this deep integration, customers benefit from an automated onboarding experience of supported Windows Servers to Microsoft Defender ATP.

This allows security analysts to see their entire environment and they do not need to switch between portals during an active investigation. Therefore, the Microsoft Defender ATP and Azure Security Center integration helps organizations spot abnormalities. Also, organizations can detect and respond to advanced attacks on server endpoints monitored by Azure Security Center.

Milad Aslan, Senior Security Program Manager, Microsoft Defender ATP R&D

# # Integration with Microsoft Cloud App Security

The integration with Microsoft Cloud App Security (MCAS) enables Security Center to receive alerts that are based on anomalies in user behavior, on user and entity behavioral analytics, and machine learning (ML). With this integration, you have immediate detections, which targets numerous anomalies across the users and resources associated with your subscription.
