# Identical Authentication Credentials

Description Identical authentication credentials to the IoT Hub used by multiple devices. This could indicate an illegitimate device impersonating a legitimate device. It also exposes the risk of device impersonation by an attacker

General Information

| Recommendation score | 0/25 |
| --- | --- |
| Recommendation impact | +25 |
| User impact | High |
| Implementation cost | High |

+   - Data exfiltration
- Data spillage
- Threat resistance

Remediation steps

Review the devices in question and make sure they are all valid. Replace any duplicated credentials and make sure all device authentication credentials are unique.
