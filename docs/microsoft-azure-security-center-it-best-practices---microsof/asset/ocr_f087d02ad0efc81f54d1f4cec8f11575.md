# Application whitelisting (adaptive application controls)

Application whitelisting has always been a goal of on-premises security. The idea behind whitelisting is that if you can define and control a predefined list of applications that should, and run, on a particular operating system, then any other process that runs on the machine represents a potential threat.

This capability existed for many years with Windows Server. While there were some strong advocates of the application whitelisting solution in Windows Server, the basic problem of complexity for configuration and maintenance prevented it from being the success it could have been.

One of the implicit goals of the cloud is to make infrastructure transparent to the end user. The cloud would provide resources desired by the user, and the user could consume these resources without making large investments to understand how and where the resources are run and maintained. Also, users would not need to understand complex constructs that could take hundreds of hours to gain highly specific professional expertise.

These are still the goals of the cloud, but in most cases, we are still quite a way from from vision because many IT Pros tell us that the cloud is often more complex than on-premises computing. I tell them IT Pros to be patient. Over time, the cloud will fulfill the true vision of the cloud, and getting stuff done in the cloud will be much easier to do than it ever on-premises.
