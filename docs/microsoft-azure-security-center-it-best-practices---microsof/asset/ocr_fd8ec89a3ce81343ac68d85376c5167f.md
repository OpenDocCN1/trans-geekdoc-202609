# Leveraging the power of the cloud, Machine Learning, and Microsoft’s experts to defend your environment

Microsoft Azure Sentinel is the first cloud-native SIEM + SOAR solution built into a major cloud provider. It supports data sources from Microsoft offerings and Azure, as well as from on-premises, partners, and other cloud providers.

For the defender, Azure Sentinel makes threat detection, investigation, and response smarter and faster. By having all the relevant data in a single place, you can quickly correlate signals from your environment, gain insights, and initiate remediation—all within Azure Sentinel. We have Machine Learning (ML) models that identify attacks through multiple stages (for example, a suspicious log followed by setting a mail forwarding rule). We also fuse related alerts together and adjust their severity, which not only helps reduce the volume of alerts but also helps defenders focus and prioritize the alerts. And we support bringing your own ML models.
