# Integration with Microsoft Defender ATP

Security Center extends its Cloud Workload Protection Platforms (CWPP) offering integration with Windows Advanced Threat Protection (ATP) and bringing Endpoint Detection and Response (EDR) capabilities. The Microsoft Defender ATP sensor is automatically enabled for supported Windows Servers that are onboarded to Security Center.

> IMPORTANT: This feature supports detection on Windows Server 2012 R2, Windows Server 2016, and only servers with Standard Tier subscriptions. By the time we were writing this chapter, the support for Windows Defender ATP in Windows Server 2019 was not available yet.

The onboarding process is seamless from the user's perspective. If the machine is in Azure and Auto Provision is configured to On, the Microsoft Monitoring Agent (MMA) will be deployed. After the MMA is deployed, it will check whether the operating system is supported to receive Windows Defender ATP. If it is enabled, the Microsoft Defender sensor is deployed to the VM. This whole onboarding process can take up to 24 hours.

For machines located on-premises or in different cloud providers, the onboarding process is basically the same; the only difference is that you will need to manually install the MMA on the target machine. To enable this integration, follow the steps below:

- 1. Open the Security Center
- 2. In the left pane under Policy & Compliance, click Security Policy.
- 3. Click Edit Settings for the subscription that you want to enable this integration.
- 4. Under Settings, click Threat Detection, the Enable Integrations blade appears.
- 5. Select the Allow Windows Defender ATP to Access My Data option and click Save. Once the integration is enabled and the servers are fully onboarded, the Windows Defender ATP sensing on the server will report telemetry to the Microsoft Defender ATP cloud service. Once an indicator of attack is triggered by Microsoft Defender ATP, an alert is published in Security Center and in the workspace (see Figure 9-2).
