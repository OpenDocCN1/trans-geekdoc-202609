# Placing the event hub shared access key in Azure Key Vault

Again, start by opening the Key Vault blade and confirming that the ContosoSub subscription for the SIEMpipe pipe is selected in the filter at the top. Then follow the steps below:

+   1. Select the SiemPipeKV key vault.

+   2. Click Secrets.

+   3. In the Secrets blade that opens, click Add.

+   4. The Create a secret blade opens, in which you can configure the new secret, as shown in Figure 8-29.

![](bbox=[0.143, 0.246, 0.706, 0.584])

FIGURE 8-29 Configure the new secret

+   5. From the Upload options drop-down menu, select Manual.

+   6. Enter a name for the secret in the Name field. In this example, use ProdEventHub Credential.

+   7. Under Value, paste the value you copied from the AAD app creation process, which is EventHubPrimaryKey.

+   8. Under Content Type, enter ListOnlySharedAccessKey (Make sure that you enter it exactly as it is written here because it is case sensitive) Leave the Set Activation Date and Set Expiration Date check boxes unselected.

+   9. Confirm that Enabled is set to Yes.

+   10. Click the Create button at the bottom of the Create Secret blade.
