# Containers detections

By the time we were writing this chapter (March 2019), the Containers detection in Security Center was focused in three major areas:

+   - Privileged container execution
- Exposed Docker daemon
- SSH server runs in container

While these were dedicated to the container's scenario, it is important to mention that in general, if even processes are running inside containers, they are still visible to the MOM agent on the host. Therefore, the Linux detections will also be effective.

# Azure SQL detections

Security Center resource analysis focuses on platform as a service (PaaS) services, such as the integration with Threat Detection for Azure SQL Database and Azure SQL Data Warehouse. SQL Threat Detection detects anomalous activities indicating unusual and potentially harmful attempts to access or exploit databases and trigger the following alert.
