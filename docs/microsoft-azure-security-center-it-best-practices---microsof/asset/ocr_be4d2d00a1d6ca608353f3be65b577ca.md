To enable data collection for Adaptive Application Controls, Security Center configures a local Appocker policy in Audit mode to allow all applications. This will cause Appocker to generate events, which are then collected and leveraged by Security Center. It is important to note that this policy will not be configured on any machines where there is already a configured Appocker policy. To collect Windows Filtering Platform Event ID 5156, you need to enable Audit Filtering Platform Connection:
(Auditpol /set /subcategory:"Filtering Platform Connection" /Success:Enable).

NOTE for details the event ID that is collected for Windows, visit http://aka.ms/ascdatallection.

# Onboard virtual machines located on-premises or in a different cloud provider

As previously explained, VMs that are located in Azure will be provisioned automatically, which means that the monitoring agent will be automatically installed. If you need to onboard computers on-premises or VMs located on a different cloud provider, you will need to install the agent manually. Follow the steps below to onboard non-Azure computers or VMs:

+   1. Open Azure Portal and sign in with a user who has Security Admin privileges.
2. On the left navigation pane, click Security Center.
3. On the Security Center left navigation pane, under General, click the Getting Started option, and click the Get Started tab.
4. Under non-Azure computers, click the Configure button, as shown in Figure 2-15.
