# Azure Resource detections

Security Center also has security alerts to detect unusual or potentially harmful operations using the Azure Resource Manager (ARM) service layer. This threat protection logic allows the detection of known common cloud-environment reconnaissance toolkits that are used to map Azure resources, identify insecure configurations, or secure persistence for an attacker. Below, you have the most recent attacks that can be detected by Security Center:

+   * MicroBurst toolkit run: This is detection for the cloud-environment reconnaissance toolkit called MicroBurst. (See https://github.com/NetSPI/MicroBurst.)
* Azure toolkit run: This is detection for the cloud-environment reconnaissance toolkit called Azure. (See https://github.com/mwrlabs/Azure.)
* Suspicious management session using an inactive account: This detects suspicious behavior based on the subscription's activity logs.
* Suspicious management session using PowerShell: This detects suspicious Power-Shell activity based on the subscription's activity logs.

# The cyber kill chain and fusion alerts

The cyber kill chain is a threat model described in 2011 by analysts from Lockheed Martin. The model was designed to help security teams and researchers organize their thinking detecting and responding to threats. The model is now generally accepted and is part of the general lexicon of all security professionals.

The original cyber kill chain was divided into seven phases:

+   1. **Reconnaissance** During this phase, the attacker identifies the best targets.
2. **Weaponization** Here, files are altered to weaponize them against a target system and are used to install malicious code.
3. **Delivery** At this point, weaponized files are placed on the target.
4. **Exploitation** During this phase, weaponized files are detonated—that is, they run on the victim system.
5. **Installation** At this point, a back door is installed on the compromised system, giving the attacker persistent access.
6. **Command and control (C&C)** Here, malware on the compromised system communicates with a C&C system that gives the attacker access to the resources required to carry out his or her objective.
7. **Actions on objectives** At this point, the attacker carries out his or her objectives, which may be predefined or have evolved based on discovery.
