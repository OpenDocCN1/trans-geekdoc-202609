You can use the Search capability in Security Center to access your workspace. Follow these steps to start your investigation:

+   1. In the left pane of the Security Center dashboard, under **General**, click **Search**.
2. Select the workspace that you want to investigate (the location to which the IoT device is sending data), and the Log Analytics **New query** page opens.
3. On this page, you can change the **Time range** to accommodate the timeline you want to analyze. You can start your first query from a specific point of reference using the IoT alert triggered in Security Center as reference, or you can just query alerts for all IoT devices, as shown in Figure 7-9.

5. Expand the alert you want to investigate and review the data in the query result. At this point of the investigation, what you are trying to identify will vary according to the type of investigation or the type of the alert itself. Sometimes, one good approach can be to investigate events that happened right before the alert was triggered. This can reveal actions that were done prior to Security Center's detection triggered.
