# Integration with other Microsoft solutions

One of the advantages of using Azure Security Center as your cloud protection platform is the capability to natively integrate with other Microsoft security solutions. The intent is to broaden the threat detection capability to cover other scenarios while leveraging the threat intelligence provided by Microsoft's other solutions. By integrating instead of reinventing, Security Center can keep focusing on providing a great threat-detection experience with shared signals that can be streamed to other platforms, such as a SIEM. In this chapter, you will learn how to integrate Security Center with Windows Server Defender ATP, Microsoft Cloud App Security, SQL Advanced Threat Protection (ATP), and Advanced Threat Protection (ATP) for Storage Accounts.

# Increasing threat detection scope

In Chapter 2, "Azure Security Center," you learned about Cloud Security Posture Management (CSPM) and Cloud Workload Protection Platform (CWPP). You also learned about Security Center's native integration with some Azure workloads, as AppServices, Containers, and others. The integration with Windows Server Defender ATP complements Security Center coverage for the CWPP scenario. For native Azure workloads, Security Center can also leverage the Advanced Threat Protection solution for SQL and Storage Accounts.

Security Center integrates with Microsoft Cloud App Security—Microsoft's Cloud Access Security Broker (CASB) solution—to bring alerts based on user and entity behavioral analytics for your Azure resources and users. The diagram in Figure 9-1 shows this integration.

The threat detection generated by these solutions will be streamed to Security Center and appear in the Security Alert dashboard. As you learned in Chapter 8, "SIEM Integration," the security alerts in Security Center are stored in the workspace and can be streamed to supported SIEM solutions, including Azure Sentinel.
