# Leveraging machine learning and cloud scale to protect against DDoS attacks

Sophistication and frequency of DDoS attacks continue to increase, hitting nearly two in five businesses. DDoS attacks are the prevalent cause of service outages and deues to be an ever-growing problem. More importantly, DDoS attacks are often used as a "smokescreen", masking more malicious and harmful infiltration of resources. The technology to create DDoS attacks continues to increase in sophistication while the cost and ability to instigate these attacks gets more and more accessible. Therefore, the ease and frequency at which criminals can wreak havoc on businesses and is driven up.

Azure DDoS Protection leverages machine learning to automatically build adaptive and customized protection policies for each protected application. As the traffic flows through the network, Azure's proprietary machine-learning algorithm picks up anomalies in the protected applications are being accessed and initiates DDoS mitigation instantaneously. This is made possible by creating unique DDoS protection policies for each protected application and protocol (TCP, TCPSYN, and UDP) combination, based on the ML algorithms. The service accomplishes this customization using two insights:

+   - Automatic learning of per-customer (per-IP) traffic patterns for Layer 3 and 4.
- Minimizing false positives, considering that the scale of Azure allows it to absorb a significant amount of traffic.

When an anomaly is detected in the network pattern (with high enough confidence), we send the traffic to our mitigation pipeline for further inspection; there, we drop malicious flow and pass only good traffic to the backend application, maintaining its availability and performance. We also enrich our algorithms with insights gained from other environments in Azure, including our first-party services, such as Xbox and Office 365.

Anupam Vij, Principal Program Manager, Azure Networking
