When JIT is configured, the deny rule created by JIT will have a priority greater or equal to 1,000. The allow rule created by JIT will have a priority greater or equal to 100, and less equal to 999. During JIT configuration, rules created by the user will change such that the JIT rules will always apply. For example, if a rule with priority of 1,000 already exists on an NSG, and JIT is configured for a single port, the existing rule’s priority will change to 1,001 and the new JIT rule is created with priority 1,000.
