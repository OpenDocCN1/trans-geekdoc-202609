# Make the most of Azure Security Center by enabling data collection agents

To receive alerts and recommendations, agents must be installed on your virtual machines for data collection

+   - Install agents automatically
  The Microsoft Monitoring agent will be automatically installed on all the virtual machines in selected subscriptions.
- Select subscriptions on which agents will be installed Managed resources
- Install agents manually
  If you ready another contact you, you may want to install the agent manually on your machines.
- Continue without installing agents
  Main security features work without agents, limited
