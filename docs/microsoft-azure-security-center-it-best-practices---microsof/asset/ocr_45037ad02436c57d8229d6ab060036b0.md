# Visualizing changes

Now that you have FIM enabled, you can start tracking the changes that occurred from the time FIM was enabled forward. Keep in mind that FIM will not show the changes immediately; the data collection frequency for FIM may vary according to the data type:

+   - **Windows registry**: The frequency is 50 minutes.
- **Windows files**: The frequency is 30 minutes.
- **Linux files**: The frequency is 15 minutes.

To visualize the changes to the registry, follow these steps:

+   1. In Security Center dashboard, under **Advanced Cloud Defense**, click **File Integrity Monitoring**. The **File Integrity Monitoring** blade appears. Click the workspace to which you want to make the changes.
