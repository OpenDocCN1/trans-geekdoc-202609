In the **Path Type** field, you can select whether you want to monitor a file or a directory. The **Use Sudo** option can be set to On, which means **Sudo** will be used when checking for the item, or it can be set to Off (don't use **Sudo**). The **Link** field determines how symbolic links are dealt with when traversing directories. The available options are:

+   **Ignore**: This option ignores symbolic links, and it will not include the files/directories referenced.

+   **Follow**: This option follows the symbolic links during recursion, and it will include the files/directories referenced.

+   **Manage**: This option follows the symbolic links and allows altering of returned content.
