Run the commands below, and make sure to replace the <subscription ID> field with your subscription number, which can be obtained using the command Get-AzSubscription.

```
Set-AzContext -Subscription "subscription ID"
Register-AzResourceProvider -ProviderNamespace 'Microsoft.Security'
```

At this point you can start performing operations that you need to onboard Security Center in your subscription. Usually the first one is to upgrade from Free to Standard tier. You will set the context for the subscription that you want to upgrade, and then you perform the upgrade using the following commands:

```
Set-AzContext -Subscription "subscription ID"
Set-AzSecurityPricing -Name "default" -PricingTier "Standard"
```

You can use Get-AzSecurityPricing to verify if your subscription was correctly upgraded to standard. If you already have a workspace and want to connect Security Center to this workspace, use Set-AzSecurityWorkspaceSetting command. You will need the Workspace ID to perform this operation, and you can retrieve this ID using Get-AzSecurityWorkspaceSetting. Another common operation to perform at this stage is to enable auto provisioning, for that use the following command:

```
Set-AzAutoProvisioningSetting -Name "default" -EnableAutoProvisioning
Set-AzSecurityContact -Name "YourName" -Email "youremailaddress" -Phone "yourphone"
-AlertAdmin -NotifyOnChange
```
