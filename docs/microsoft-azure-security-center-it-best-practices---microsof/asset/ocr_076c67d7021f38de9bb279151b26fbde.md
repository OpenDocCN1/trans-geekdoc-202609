# Protect your IoT solution with Azure Security Center

According to a study conducted by Ericsson, the number of IoT devices with cellular connections in 2016 was 400 million, and this number will be 1.5 billion by 2022. This represents a huge opportunity for many organizations to leverage IoT to enable their business to do more. However, it also represents a more challenging threat landscape that needs to be addressed from the ground up. Most of the companies are far under their current IoT security posture. According to a study led by Gemalto, 48 percent of businesses can detect if their IoT devices suffered a breach. It comes down again to visibility and control, and that's where Azure Security Center for IoT can assist organizations in their journey to embrace IoT in a secure manner.

In this chapter, you will learn how to use Security Center to monitor your IoT solution, detect threats, and investigate suspicious activities on IoT devices.

# Understanding Security Center for IoT solution

Security Center for IoT leverages IoT Hub (requires IoT Hub Standard Tier) to perform security assessment for IoT devices. Azure IoT is a managed service that acts as a central message hub for bidirectional communication between IoT application and the device it manages. IoT Hub enables communications from the device to the cloud and from the cloud to the device. To accomplish that, IoT Hub supports multiple patterns, such as device-to-cloud telemetry, file upload from devices, and request-reply methods to control your devices from the cloud.

The intent of Security Center for IoT is to enable you to see the security state of the Azure IoT Solution, with end-to-end analysis and management of security posture.
