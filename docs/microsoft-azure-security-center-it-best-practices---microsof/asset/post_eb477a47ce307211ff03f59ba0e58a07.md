## Unified Endpoint Detection and Response (EDR)

Microsoft Defender Advanced Threat Protection (Microsoft Defender ATP) is a unified security platform that provides endpoint protection platform (EPP) and endpoint detection and response (EDR) capabilities for Windows clients, Windows Server, and third-party systems like Mac OS. In Windows, Server Microsoft Defender ATP is deeply integrated with Azure Security Center, which ensures that organizations maximize the usage of their existing Microsoft security investments. With this deep integration, customers benefit from an automated onboarding experience of supported Windows Servers to Microsoft Defender ATP.

This allows security analysts to see their entire environment and they do not need to switch between portals during an active investigation. Therefore, the Microsoft Defender ATP and Azure Security Center integration helps organizations spot abnormalities. Also, organizations can detect and respond to advanced attacks on server endpoints monitored by Azure Security Center.

Milad Aslan, Senior Security Program Manager, Microsoft Defender ATP R&D

## Integration with Microsoft Cloud App Security

The integration with Microsoft Cloud App Security (MCAS) enables Security Center to receive alerts that are based on anomalies in user behavior, on user and entity behavioral analytics, and machine learning (ML). With this integration, you have immediate detections, which targets numerous anomalies across the users and resources associated with your subscription.

Also, these alerts leverage additional data that already exists in the MCAS detection engine to help speed up the investigation process and contain ongoing threats. To enable this integration, follow these steps:

1. Open the Security Center dashboard.
2. In the left pane under **Policy & Compliance**, click **Security Policy**.
3. Click **Edit settings** for the subscription on which you want to enable this integration.
4. Under **Settings**, click **Threat Detection**: the **Enable Integrations** blade appears.
5. Select the **Allow Microsoft Cloud App Security To Access My Data** option and click **Save**.

This integration will enable the following alerts to be surfaced in the Security Alerts dashboard in Security Center:

- Impossible Travel
- Activity From Infrequent Country
- Activity From Anonymous IP Address

## Integration SQL ATP

Security Center integration with SQL Advanced Threat Protection (ATP) provides a new layer of security to help customers to detect and respond to potential threats, such as suspicious database activities, potential vulnerabilities, and SQL injection attacks, as well as anomalous database access and queries patterns.

This integration makes it simple to address potential threats to the database without needing to be an expert or manage advanced security monitoring systems. When SQL ATP is enabled, the following alerts will be available:

- **Vulnerability To SQL Injection**: This alert may indicate a possible vulnerability to SQL injection attacks.
- **Potential SQL Injection**: This alert is triggered when an active exploit happens against an identified vulnerability to SQL injection.
- **Access From Unusual Location**: This alert is triggered when there is a change in the access pattern to SQL server; for example, this alert would be triggered when someone has logged on to the SQL server from an unusual geographical location.
- **Access From Unusual Azure Data Center**: This is another alert that is triggered based on changes in access pattern to SQL server. However, in this case, it occurs when someone has logged on to the SQL server from an unusual Azure data center that was not seen during the recent period.
- **Access From Unfamiliar Principal**: This is another alert that is triggered based on changes in access patterns to the SQL server, but this scenario applies to a situation in someone has logged on to the SQL server using an unusual principal (SQL user).
- **Access A Potentially Harmful Application**: This alert is triggered when a potentially harmful application is used to access the database.
- **Brute Force SQL Credentials**: This alert is triggered when there is an abnormally high number of failed logins with different credentials.

## Integration with ATP for Azure Storage

Security Center integration with Advanced Threat Protection (ATP) for Azure Storage is very similar to the integration with SQL ATP. You will also need to manually enable this capability in your Pricing tier and pay extra for this. You can use the same steps that you used to enable SQL ATP, and you will see the option to enable storage accounts. To generate alerts, ATP for Azure Storage ingests diagnostic logs of read, write, and delete requests to Blob storage for threat detection.

When you enable ATP for Azure Storage, you will be able to identify attacks under the following conditions:

- When there is a change in the access pattern to a storage account
- When there is an unusually large amount of data getting extracted compared to recent activity on this storage account
- When an unexpected deletion occurs in a storage account
- When unusual storage enumeration occurs
- When usual changes to the storage account occurs
