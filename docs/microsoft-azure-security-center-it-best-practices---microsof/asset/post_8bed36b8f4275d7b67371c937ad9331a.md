## Connecting the event hub to Azure Monitor

This is the last part of the configuration from the Azure perspective, after that the configuration needs to be done on the Splunk side. Be aware that the SIEM must be configured on a per-subscription basis, so each subscription has data to transmit to the SIEM will need to be configured manually. To finalize this configuration, follow the steps below:

1. Open the Azure Portal Monitor blade and click Activity Log.
2. Click the Export option at the top of the Monitor blade.
3. A new blade opens on which you can configure the data streaming to a SIEM (see Figure 8-30).
4. Select the ContosoSub subscription.
5. Under Regions, make sure that all regions are selected.

> It is recommended that you keep this check box as is (meaning to have all regions selected). The filter is exclusive regarding the regions selected. Any selection means that only activities marked for those selected regions will arrive. Most activities do not note region and are reported globally, and so any specific selection will negate the arrival of global items.

6. Select the check box Export to an event hub to enable the data stream into the event hub (from an activity log).
7. Select the Service Bus Namespace button and select the event hub created in the previous step.
