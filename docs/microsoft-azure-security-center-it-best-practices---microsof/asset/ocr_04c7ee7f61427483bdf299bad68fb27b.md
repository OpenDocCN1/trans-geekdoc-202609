# **IMPORTANT** The security assessment done on the VMs will also look for the presence of security configuration. This security configuration is based on CCE (Common Configuration) rules. These rules are available for download at https://aka.ms/asccerules.

Another important consideration when incorporating Security Center as part of SecOps is to establish how the data will be consumed by the team responsible for reviewing those alerts. Some organizations may already have a Security Information and Event Management (SIEM) system as part of their security operations, and they may not want to introduce another dashboard to their teams to query alerts. In this case, it is very common to export Security Center alerts to their SIEMs. You will learn how to perform this operation in Chapter 8, "Exporting Logs to a SIEM Solution."
