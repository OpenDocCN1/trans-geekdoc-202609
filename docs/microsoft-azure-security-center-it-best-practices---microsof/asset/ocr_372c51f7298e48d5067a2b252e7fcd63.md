# SIEM integration

Security Information and Event Management (SIEM) is highly utilized by many organizations as the main source of truth when the subject is data security. The data ingested in this platform is highly utilized by the Security Operations (SOC) team. For large organizations that already have a SIEM solution in place, it is almost a requirement to integrate Security Center with their current SIEM solutions. These SIEM solutions will help the SOC team rationalize all the data that is ingested from platforms and perform data correlation across this data. In 2019, Microsoft launched its own SIEM solution, called Azure Sentinel, which can also be integrated with Security Center.

In this chapter, you will learn how to integrate Security Center with Azure Sentinel, and Splunk.

# Streaming logs to a SIEM solution

Azure Security alerts are published to the Azure Monitor, which enables you to use Event Hub to route Security Center alerts to an on-premises or cloud-based SIEM solution. The general process occurs in three major phases:

+   - Create an event hub that will be the destination for your Security Center data.
- Stream Azure Monitor logs into the event hub.
- Install and configure the SIEM solution vendor's connector to stream the data from the Event Hub to your SIEM solution.

While this is the general process for most of the third-party SIEM solutions, the for Azure Sentinel is much simpler, and it will be covered in the next section.
