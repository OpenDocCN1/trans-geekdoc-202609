# Accessing alerts in Azure Sentinel

The alerts generated by Security Center could appear in Azure Sentinel as part of a case, which is an aggregation of all the relevant evidence for a specific investigation and can include multiple alerts coming from different data sources, as shown in Figure 8-5.

![](bbox=[0.09375, 0.14375, 0.75625, 0.43925])

FIGURE 8-5 Azure Sentinel performs data aggregation using alerts from multiple data sources

In the diagram shown in Figure 8-5, the Suspicious PowerShell Activity Detected was raised by Security Center, as you can see in the Product Name field. Because this alert is in the workspace used by Azure Sentinel, you can leverage the searching capabilities in Azure Sentinel to obtain more information about this. Go to the Azure Sentinel main page, click Logs in the left navigation pane, and you will see the Logs page, as shown in Figure 8-6.
