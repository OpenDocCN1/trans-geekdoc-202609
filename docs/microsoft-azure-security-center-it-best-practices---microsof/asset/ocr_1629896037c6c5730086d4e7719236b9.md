# Azure App Services detections

Azure App Service is a service for hosting web applications, REST APIs, and mobile back ends. It enables you to develop in many languages, such as .NET, .NET Core, Java, Ruby, Node.js, PHP, or Python. Applications run and scale on Windows and Linux. Security Center leverages the scale of the cloud to identify attacks on App Service applications while focusing on emerging attacks while attackers are in the reconnaissance phase, scanning to identify vulnerabilities across multiple websites hosted on Azure.

Security Center's App Service detection includes analytics and machine-learning models that cover all interfaces allowing customers to interact with their applications, whether it's over HTTP or through one of the management methods.

# App Services detections in Azure Security Center

Azure recently announced that it leverages the scale of the cloud to identify attacks targeting customers' applications. With web applications being practically in any modern network, attackers probe to find and exploit weaknesses.

Before being routed to specific environments, requests to applications running go through several gateways when they are inspected and logged. This data is then used to identify exploits and attackers and to learn new patterns that will be used later. By leveraging Azure's visibility as a cloud provider, Security Center analyzes App Service internal logs to identify attack methodology on multiple targets, as widespread scanning and distributed attacks.

These types of attacks typically come from a small subset of IPs, and they exhibit patterns of crawling to similar endpoints on multiple hosts and searching for a particular vulnerable page or plugin. This can easily be detected using cloud capabilities but cannot be identified from a single host. Security Center also has access to the underlying sandboxes and VMs. Together with memory forensics, the infrastructure can tell the story, from a new attack circulating in the wild to compromises in customer machines. Thus, Security Center can detect attacks against web applications long after being exploited.
