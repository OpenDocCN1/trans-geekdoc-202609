To enable this capability, you need to enable SQL Server monitoring in your subscription, which adds an extra cost. Follow these steps:

+   1. Open the Security Center dashboard.

+   2. In the left pane under Policy & Compliance, click Security Policy.

+   3. Click Edit Settings for the subscription on which you want to enable this integration.

+   4. Under Settings, click Pricing Tier.

+   5. Click Select pricing tier by resource type to expand this option and click the Enabled toggle next to SQL Servers, as shown in Figure 9-6.

# Integration with ATP for Azure Storage

Security Center integration with Advanced Threat Protection (ATP) for Azure Storage is very similar to the integration with SQL ATP. You will also need to manually enable this capability in your Pricing tier and pay extra for this protection. You can use the same steps that you used to enable SQL ATP, and you will see the option to enable storage accounts. To generate alerts, ATP for Azure Storage ingests diagnostic logs of read, write, and delete requests to Blob storage for threat detection.
