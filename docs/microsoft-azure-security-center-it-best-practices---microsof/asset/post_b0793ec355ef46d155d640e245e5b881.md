# Understanding Security Center for IoT

Security Center for IoT is a managed service that acts as a central hub for communication between IoT application and the cloud. IoT Hub enables multiple patterns, such as device-to-cloud telemetry, file upload from devices, and request-reply methods to control devices from the cloud. To accomplish that, IoT Hub requires Standard Tier.

The intent of Security Center for IoT is to enable you to see the security state of Azure IoT, with end-to-end analysis and management. It provides actionable recommendations and real-time threat detection. The diagram shown in Figure 7-1 shows this architecture.

![](img/4b11e95292819ab1a383a41ef73aedb4_155_0.png)

Figure 7-1 Core components

Security Center for IoT requires an agent to be deployed on the device. This agent was developed as an open-source project and is available from GitHub. The diagram shown in Figure 7-1 assumes that the agent is already installed, and that the communication workflow occurs in the following phases:

- 1. This agent collects raw security events from the underlying operating system (Linux or Windows), aggregates raw security events into messages, and sends the messages to Security Center (via IoT Hub).

- 2. IoT Hub picks up this information from multiple devices, processes it, and forwards it to Security Center for service for analysis. This data includes device-cloud operation logs, device identities, and IoT Hub configuration. This information is necessary for the ASC for IoT analytics pipeline.

- 3. Using the analytics pipeline, Security Center for IoT combines all streams of information to generate actionable recommendations and alerts.

> Visit https://github.com/Azure/Azure-IoT-Security-Agent-C for the agent in C, and see https://github.com/Azure/Azure-IoT-Security-Agent-CS for the agent in C.

Security Center for IoT will aggregate and analyze security data from your operating system and container system available in Azure IoT Edge. (At the time of writing, only Linux is supported.) This information will be converted into actionable security recommendations and alerts. The Security Center IoT security module for IoT Edge runs in a privileged mode under IoT Edge. This is required to allow the module to monitor the operating system and other IoT Edge modules.
