## Appendix 2
### Cybersecurity Performance Measures

Cybersecurity performance can be measured along different dimensions. Here is a sample set of measures that can be suitably modified to meet an organization's needs.

| Category | Measures |
|---|---|
| Business Value Impact | - Dollar amount of damages and losses from security breaches<br>- Dollar amount of savings from prevention of security attacks<br>- Dollar amount spent on resolving security issues |
| Productivity Impact | - Number of worker hours spent on resolving security issues<br>- Number of worker hours lost due to disruption of operations |
| Nature of Incidence and Frequency of Occurrence | - Number of security breaches<br>- Types of security breaches |
| Extent of Preparedness | - Frequency of review of third-party accesses<br>- Percentage of business partners with effective cybersecurity policies<br>- Mean-Time-to-Detect and Mean-Time-to-Respond<br>- Number of days to deactivate former employee credentials |
| Audit and Compliance | - Extent of compliance with ISO 27001 guidelines<br>- Number of outstanding high-risk findings open from last audit |
| Vulnerability Assessment | - Number of systems with known vulnerabilities<br>- Number of SSL certificates configured incorrectly<br>- Volume of data transferred using the corporate network<br>- Number of users with “super user” access level<br>- Number of communication ports open during a period of time<br>- Frequency of access to critical enterprise systems by third parties |
