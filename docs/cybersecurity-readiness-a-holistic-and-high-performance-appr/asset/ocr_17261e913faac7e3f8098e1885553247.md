|  |  | **Record Keeping**
Maintaining a record of changes to the Active Directory databases and other information architecture components.

Maintaining an updated record of hardware and software. The records should indicate when the changes were made and who made them.

**Backups**
Backup systems should be in place to protect sensitive data. Data centers containing backed-up data including those stored off-site or by a third party are subject to the same SOX compliance requirements as those hosted on premises. |  |
