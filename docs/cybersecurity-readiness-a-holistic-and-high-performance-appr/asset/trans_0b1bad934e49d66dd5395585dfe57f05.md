## 附录 2
### 网络安全绩效指标

网络安全绩效可沿不同维度进行衡量。以下是可根据组织需求适当修改的示例指标集。

| 类别 | 指标 |
|---|---|
| 业务价值影响 | - 安全漏洞造成的损害和损失金额<br>- 预防安全攻击节省的金额<br>- 解决安全问题所花费的金额 |
| 生产力影响 | - 用于解决安全问题的工时数<br>- 因运营中断而损失的工时数 |
| 事件性质及发生频率 | - 安全漏洞数量<br>- 安全漏洞类型 |
| 准备程度 | - 第三方访问审查频率<br>- 具有有效网络安全政策的业务合作伙伴百分比<br>- 平均检测时间与平均响应时间<br>- 注销前员工凭证的天数 |
| 审计与合规 | - 遵守 ISO 27001 指南的程度<br>- 上次审计以来仍未解决的高风险发现数量 |
| 漏洞评估 | - 存在已知漏洞的系统数量<br>- 配置不正确的 SSL 证书数量<br>- 使用企业网络传输的数据量<br>- 具有“超级用户”访问级别的用户数量<br>- 特定期间内开放的通信端口数量<br>- 第三方访问关键企业系统的频率 |

## 附录 3A
### 网络安全准备度
评分卡：承诺

该评分卡可用于从组织承诺的角度衡量组织的网络安全准备状态。评分将揭示优势领域和改进机会。评估模板旨在作为指南，可根据组织的独特需求进行适当定制。

| 高层管理亲力亲为 | 1. 高层管理对组织的 安全漏洞点 了解程度如何？<br>0 = 完全不 1 = 较小程度 2 = 一定程度 3 = 中等程度 4 = 很大程度 5 = 非常大程度 |
| 高层管理亲力亲为 | 2. 高层管理对组织的信息安全防御机制了解程度如何？<br>0 = 完全不 1 = 较小程度 2 = 一定程度 3 = 中等程度 4 = 很大程度 5 = 非常大程度 |
| 高层管理亲力亲为 | 3. 高层管理在网络安全规划和战略制定中积极参与的程度如何？<br>0 = 完全不 1 = 较小程度 2 = 一定程度 3 = 中等程度 4 = 很大程度 5 = 非常大程度 |
| 高层管理亲力亲为 | 4. 高层管理团队成员是否担任网络安全治理委员会成员？<br>0 = 否 1 = 是 |
| 高层管理亲力亲为 | 5. 高层管理在确保强大的网络安全治理方面承担领导、所有权或责任的程度如何？<br>0 = 完全不 1 = 较小程度 2 = 一定程度 3 = 中等程度 4 = 很大程度 5 = 非常大程度 |
