
## 附录 4
### 网络安全与隐私法律法规

以下表格汇编并总结了规范网络安全和信息隐私实践的各种法律法规。本概述旨在作为一个起点，以便深入探讨组织网络安全和信息隐私责任的法律影响和后果。

| 法律与法规 | 适用范围 | 合规指南 | 处罚与执行 |
|---|---|---|---|
|  | COPPA适用于面向13岁以下儿童的网站和在线服务。如果网站明知13岁以下儿童在使用该网站，也适用。本法的目的是规范这些网站收集、使用和/或披露有关儿童的个人信息的方式。 | 不得将儿童参与游戏、提供奖品或其他活动作为提供信息的条件。提供合理的程序以保护从儿童处收集的个人信息的保密性、安全性和完整性。 |  |
| 商品期货交易委员会 (CFTC) 衍生品清算组织条例 17 CFR 第39部分、附属部分B、17 CFR 39.18—系统保障 | CFTC条例适用于衍生品清算组织。这些实体充当商品期货或商品期权交易清算的中介。全球约有27家。这些市场是全球金融体系的核心。 | 为保护自身，衍生品清算组织必须制定一套广泛而健全的信息安全计划，其中包括以下内容：必须发送给董事会和CFTC的年度合规报告，每季度两次对独立承包商进行漏洞测试 | 违反本条例的民事罚款最高可达1,098,190美元或非法获利的三倍。本规则可由证券交易委员会 (SEC) 行动或金融业监管局 (FINRA) 执行。 |
| 2017年消费者隐私保护法 | 旨在确保敏感个人信息的隐私和安全，防止和减轻身份盗窃，提供涉及敏感个人信息的fiy安全漏洞通知，并加强执法协助以及对安全漏洞、欺诈性访问和个人信息滥用的其他保护。它适用于在任何12个月期间收集、使用、访问、传输、存储或处置10,000名或以上美国公民敏感个人身份信息的组织。 | 内部和外部渗透测试至少每年一次<br>控制测试每三年一次<br>年度安全事件响应计划测试<br>年度企业技术风险评估 | 民事处罚罚款不超过500万美元，除非违规行为被认定为故意或蓄意，在此情况下可额外处以500万美元罚款。 |
| **国防联邦采购条例 (DFAR)** | DFAR是一项适用于美国国防部 (DoD) 承包商的网络安全法规。 | 拥有、存储或传输“受保护的国防信息”的国防部 (DoD) 承包商和分包商必须提供充分的安全措施，以保护非密信息系统上的受保护国防信息。条例要求遵守特定的网络安全标准：国家标准与技术研究所 (NIST) 特刊 (SP) 800-171，“在非联邦信息系统和组织中保护受控非密信息”（请参阅 NIST 800-171 的附录 D，了解其他网络安全框架的参考，包括 ISO 27001）。该条例提供了调查网络事件并向 DoD 和主承包商（或下一级分包商）报告的详细流程，包括保护和保存包括恶意软件在内的证据以供可能的取证分析。 | 未能遵守可能导致取消资格。 |
| **《电子通信隐私法》(ECPA) 和《存储通信法》(SCA)** | ECPA 与 SCA 合称《窃听法》，是隐私法规。<br><br>最初旨在限制无搜查令的监视，这些法律禁止未经授权故意使用、披露或访问任何有线、口头或电子通信。 | 政策应禁止在未获得双方同意的情况下录制或披露任何口头或电子通信。<br><br>政策应禁止在未获得同意的情况下对非员工进行监视。<br><br>如果有正当的商业理由，政策允许对员工进行监视，包括视频和电子邮件拦截。 | 这些法律规定了刑事处罚，可用于监禁恶意黑客。 |
| **欧盟-美国隐私盾** | 欧洲委员会于2016年7月12日通过了欧盟-美国隐私盾框架，并于同日生效。<br><br>隐私盾的制定旨在保护由美国组织持有和处理的欧盟居民数据。个人数据在美国的保护程度远不及欧盟认为的充分水平。 | 要自行认证隐私盾，公司必须采取以下措施：<br><br>确认其符合资格。大多数金融部门以外的公司均符合资格。<br><br>制定符合隐私盾的隐私政策声明，并确保组织的隐私政策符合隐私盾原则。<br><br>确定组织执行隐私政策的独立救济机制。确保隐私政策公开可用。确保组织具有合规验证机制。在组织内指定有关隐私盾的联系人。向商务部提交组织的自我认证。 | 对于未能遵守某些 GDPR 要求的公司，罚款最高可达全球年营业额的2%或4%，或1000万欧元或2000万欧元，以较高者为准。 |
| 1974年联邦隐私法 | FPA 仅适用于美国联邦政府机构。它规范联邦机构在记录系统中保存的关于个人的可识别个人信息的收集、维护、使用和传播。<br><br>它禁止在未经当事人书面同意的情况下披露由联邦机构控制的记录系统中的信息，除非披露符合十二项法定例外之一。直到最近，它仅适用于美国合法居民。<br><br>经《司法救济法》修订，该法允许由总检察长（经财政部长、国务院、Homeland 安全部长同意）确定的“受覆盖国家”的公民，因联邦机构故意披露可识别个人信息而在联邦法院提起诉讼。 | 所有美国联邦机构必须：不得通过任何通信方式向任何人或另一机构披露记录系统中的任何记录，除非获得个人的书面请求或该记录所涉个人的事先书面同意。<br><br>允许任何个人获取其记录或系统中与其有关的任何信息，并允许他们以及如果他们要求，可由其自行选择的人员陪同，查阅记录并复印。<br><br>维护有关任何个人的任何记录，并作出合理努力确保此类记录准确、相关、及时和完整。<br><br>确保与个人的资格、品格、权利或机会或利益有关的任何决定中的公平性。 | 受覆盖人员，包括美国合法居民和由美国国务卿指定的某些外国国家的公民，可在美国联邦地区法院提起诉讼，要求赔偿实际损失或1,000美元（以较高者为准）、律师费和诉讼费用。<br><br>法院还可要求联邦机构修改或更正有关受覆盖人员的任何存档信息。 |
| 联邦贸易委员会 (FTC) 法 | 该法于1914年颁布，旨在取缔不公平的贸易和商业行为。 | 组织应采用所有“合理且必要”的安全实践。 | FTC 可以并且已经施加民事责任。最近，Facebook 被罚款50亿美元。 |
